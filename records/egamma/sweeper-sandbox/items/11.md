# Issue #11 — Command to copy the current stats to the clipboard

[https://github.com/egamma/sweeper-sandbox/issues/11](https://github.com/egamma/sweeper-sandbox/issues/11)

## Summary

Keep open: copying document statistics is an in-scope capability that current main does not provide. The newer copy-stats request confirms additional demand but cannot replace this older report as the canonical issue.

## Change summary

Add a Note Stats: Copy Stats command that copies the current document's word and character counts as plain text for pasting elsewhere.

## Best solution

Use this issue to own the plain-text clipboard command, with command contribution in package.json, editor and clipboard wiring in src/extension.ts, and independently testable text formatting in src/stats.ts. Settle the clipboard number-format contract before implementation; Markdown-table export remains separate work.

## Plan brief

- **Likely files:** `package.json`, `src/extension.ts`, `src/stats.ts`, `test/stats.test.ts`, `README.md`
- **Validation:** After implementation, run npm test with cases pinning the agreed plain-text output for empty and nonempty documents and counts above 999. In an Extension Development Host, invoke Note Stats: Copy Stats on a known document, paste into another editor, and verify both counts, the absence of status-bar icon markup, and that the source document remains unchanged.
- **Behavior:**

  > Users need a keyboard-reachable command that copies the active document's word and character counts as plain text for pasting into submission forms. The clipboard text must contain both measurements without status-bar icon markup, and invoking the command must not edit the document. Acceptance checks should cover empty documents, ordinary text, and sufficiently large counts to exercise the agreed number formatting.
- **Trace:**

  > package.json and activate() in src/extension.ts expose only toggle, timestamp insertion, and slugification; no clipboard command exists. refresh() already obtains document text and uses computeStats from src/stats.ts, whose TextStats contains both required measurements. formatStats is specifically a status-bar formatter, with icon markup and existing tests that must retain their current behavior. Pure formatting belongs within the repository's existing pure-helper boundary, while VS Code interactions belong in the extension wiring. https://github.com/egamma/sweeper-sandbox/issues/41 corroborates demand but is newer; https://github.com/egamma/sweeper-sandbox/issues/42 owns separate Markdown-document export. The goal is established, but the example's 'something like' wording leaves exact clipboard number formatting unspecified; unrelated counting defects and additional export formats are outside this request.
- **Open decisions:**
  - Should clipboard numbers use locale-aware digit grouping or a stable locale-independent representation for pasting into submission forms?

## Evidence

- **Existing-capability check:** package.json contributes only noteStats.toggle, noteStats.insertTimestamp, and noteStats.slugifyHeading. Its settings control status-bar character visibility and timestamp formatting; neither provides clipboard export.
