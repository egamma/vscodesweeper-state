# Issue #7 — noteStats.timestampFormat is ignored, Insert Timestamp always inserts ISO

[https://github.com/egamma/sweeper-sandbox/issues/7](https://github.com/egamma/sweeper-sandbox/issues/7)

## Summary

The defect is conclusively present on current main: the Insert Timestamp command reads and passes noteStats.timestampFormat, but formatTimestamp ignores that argument and always returns an ISO string. The issue is correctly classified and should remain open for a bounded helper fix with unit coverage.

## Change summary

Make Insert Timestamp honor the iso, date, and datetime values of noteStats.timestampFormat.

## Best solution

Implement all three documented formats in formatTimestamp in src/stats.ts, preserving the existing full UTC ISO output while producing YYYY-MM-DD and local YYYY-MM-DD HH:mm for the other modes. Pin each mode with deterministic cases in test/stats.test.ts.
