# Issue #7 — noteStats.timestampFormat is ignored, Insert Timestamp always inserts ISO

[https://github.com/egamma/sweeper-sandbox/issues/7](https://github.com/egamma/sweeper-sandbox/issues/7)

## Summary

The defect remains on current main: Insert Timestamp passes the configured format to formatTimestamp(), but that helper ignores it and always returns an ISO string. No open canonical issue or open implementation PR owns the remaining work.

## Change summary

The Insert Timestamp command should honor all three noteStats.timestampFormat values instead of always inserting a full ISO timestamp.

## Best solution

Correct the pure timestamp-formatting behavior in src/stats.ts and pin the documented iso, date, and local datetime outputs in test/stats.test.ts. The command wiring in src/extension.ts already reads and passes the setting correctly and should remain unchanged.
