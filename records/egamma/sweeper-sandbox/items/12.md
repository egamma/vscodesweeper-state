# Issue #12 — Add a line and paragraph count

[https://github.com/egamma/sweeper-sandbox/issues/12](https://github.com/egamma/sweeper-sandbox/issues/12)

## Summary

This is an unimplemented, explicitly in-scope statistics request. Current main computes only words and characters, no older open issue owns line and paragraph counts, and all six referenced implementation PRs were closed without merging; add the missing status-bar area classification and keep the request open.

## Change summary

Expose line and paragraph counts for the active document, potentially in the status bar tooltip to preserve the compact label.

## Best solution

Extend the pure statistics model in `src/stats.ts` with well-defined line and paragraph counts, pin their boundary cases in `test/stats.test.ts`, and expose them through the status item in `src/extension.ts` without making its primary text overly busy.
