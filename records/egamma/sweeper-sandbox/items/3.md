# Issue #3 — Word count is wrong when words are separated by more than one space

[https://github.com/egamma/sweeper-sandbox/issues/3](https://github.com/egamma/sweeper-sandbox/issues/3)

## Summary

The defect is confirmed on current main: computeStats splits only on a literal single space, so repeated spaces create empty entries and other whitespace is not treated as a separator. The issue is already correctly labeled and should remain open for a bounded helper fix with regression tests.

## Change summary

Word counts are incorrect when document words are separated by repeated spaces, newlines, or other whitespace.

## Best solution

Update computeStats in src/stats.ts to count tokens separated by runs of whitespace while preserving the existing character count, then add regression cases in test/stats.test.ts for repeated spaces and blank-line-separated paragraphs.
