# Issue #3 — Word count is wrong when words are separated by more than one space

[https://github.com/egamma/sweeper-sandbox/issues/3](https://github.com/egamma/sweeper-sandbox/issues/3)

## Summary

The defect is directly reproducible from current source: computeStats splits only on a literal space, so repeated spaces and newline-separated text create incorrect entries. The issue is owner-authored, remains unfixed on main, and already has the correct bug and status-bar labels.

## Change summary

Word counts are inflated when words are separated by repeated spaces, newlines, or other whitespace.

## Best solution

Update computeStats in src/stats.ts to split non-empty trimmed text on contiguous whitespace, and add test/stats.test.ts cases covering repeated spaces, blank lines, and mixed whitespace.
