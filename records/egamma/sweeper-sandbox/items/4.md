# Issue #4 — Changing noteStats.showCharacters has no effect until the window is reloaded

[https://github.com/egamma/sweeper-sandbox/issues/4](https://github.com/egamma/sweeper-sandbox/issues/4)

## Summary

The defect is confirmed on current main: `noteStats.showCharacters` is captured once during activation, so changing the setting cannot affect subsequent status-bar refreshes. The issue is already correctly classified as a settings bug and should remain open for a fix.

## Change summary

Changes to `noteStats.showCharacters` should update the status-bar character count immediately without reloading the VS Code window.

## Best solution

Update the configuration wiring in `src/extension.ts` so `refresh()` uses the current `noteStats.showCharacters` value and a relevant configuration change triggers a refresh. Preserve the existing toggle, editor-change, and document-change behavior.
