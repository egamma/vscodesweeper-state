# Issue #31 — Slugify leaves a trailing hyphen and drops accented letters

[https://github.com/egamma/sweeper-sandbox/issues/31](https://github.com/egamma/sweeper-sandbox/issues/31)

## Summary

The current slugify implementation conclusively produces both reported defects: punctuation becomes an untrimmed edge hyphen, while accented letters are removed by the ASCII-only character class. This is a valid, well-routed command bug that remains open on current main.

## Change summary

Slugify should produce clean slugs without leading or trailing hyphens and should preserve the meaning of accented letters.

## Best solution

Define the Unicode policy for slugs, then update `slugify` in `src/stats.ts` so edge punctuation cannot leave hyphens and accented Latin letters produce meaningful output. Pin leading/trailing punctuation and accented-heading cases in `test/stats.test.ts` while preserving heading-marker removal, lowercasing, and separator collapsing.
