# Issue #17 — Is there a keyboard shortcut for Insert Timestamp?

[https://github.com/egamma/sweeper-sandbox/issues/17](https://github.com/egamma/sweeper-sandbox/issues/17)

## Summary

This is a support question rather than an actionable defect: Note Stats contributes the Insert Timestamp command but no default keybinding, and users can assign one through VS Code's Keyboard Shortcuts editor.

## Change summary

Clarify whether Insert Timestamp has a default keyboard shortcut and how to assign one.

## Best solution

Keep the command unbound by default and direct users to assign a shortcut to `Note Stats: Insert Timestamp` (`noteStats.insertTimestamp`) in VS Code's Keyboard Shortcuts editor.

  > Thanks for asking. Note Stats does not provide a default keybinding for this command. In VS Code, open **Preferences: Open Keyboard Shortcuts**, search for **Note Stats: Insert Timestamp**, and use the pencil icon to enter your preferred shortcut. The command ID is `noteStats.insertTimestamp` if you prefer to add it directly to `keybindings.json`.
