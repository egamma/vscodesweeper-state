# Issue #42 — Export stats as a Markdown table

[https://github.com/egamma/sweeper-sandbox/issues/42](https://github.com/egamma/sweeper-sandbox/issues/42)

## Summary

Keep this request open: exporting a formatted statistics table is not implemented, and no older open issue owns that outcome. The overlapping export request is newer and less detailed; plain-text clipboard copying does not satisfy this request.

## Change summary

Add a Note Stats: Export Stats command that opens an untitled Markdown document containing a table of words, characters, paragraphs, and estimated reading time.

## Best solution

Provide an on-demand, document-local Markdown export, with command contributions in package.json, document handling in src/extension.ts, and pure statistics and formatting logic in src/stats.ts. Agree on paragraph and reading-time semantics before implementation; preserve this issue as the older, better-described export request.
