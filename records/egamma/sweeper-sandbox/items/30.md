# Issue #30 — Word count is wrong when words are separated by more than one space

[https://github.com/egamma/sweeper-sandbox/issues/30](https://github.com/egamma/sweeper-sandbox/issues/30)

## Summary

The defect is directly confirmed in current source: computeStats splits only on a literal single space, so repeated spaces and newline-separated paragraphs create empty entries that are counted as words. The issue already has the correct bug and status-bar labels and should remain open for a bounded helper fix with regression tests.

## Change summary

Word counts are inflated when words are separated by repeated spaces, newlines, or blank lines.

## Best solution

Correct whitespace-delimited counting in src/stats.ts and add regression cases in test/stats.test.ts for repeated spaces, newlines, and blank lines while preserving the documented treatment of numbers and standalone punctuation as words.
