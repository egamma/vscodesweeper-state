# Issue #50 — Export stats as a Markdown table

[https://github.com/egamma/sweeper-sandbox/issues/50](https://github.com/egamma/sweeper-sandbox/issues/50)

## Summary

Keep open: no existing command exports a Markdown table to an untitled document. The older export request is related but does not establish ownership of the specified table, four metrics and output destination; plain-text clipboard copying is a separate capability.

## Change summary

Add a Note Stats: Export Stats command that opens an untitled document containing a Markdown table of words, characters, paragraphs and estimated reading time.

## Best solution

Plan a document-local Markdown export with computation and formatting in src/stats.ts, command wiring in src/extension.ts and registration in package.json. Coordinate with the related export and statistics requests while retaining this issue's explicit table and untitled-document requirements.

## Plan brief

- **Likely files:** `src/stats.ts`, `src/extension.ts`, `package.json`, `test/stats.test.ts`, `README.md`
- **Validation:** After implementation, run npm test with cases for the agreed paragraph and reading-time rules and the Markdown table output. In an Extension Development Host, invoke Note Stats: Export Stats on a known document and verify that a new unsaved document contains the four requested metrics in a Markdown table while the original document remains unchanged.
- **Behavior:**

  > Note Stats: Export Stats should create a new untitled document containing a small Markdown table with words, characters, paragraphs and estimated reading time for the source document. The table should be usable in a README or status report without manually transcribing the measurements. The command must not alter the source document or substitute plain-text clipboard copying for the requested output.
- **Trace:**

  > package.json and activate() in src/extension.ts expose only toggle, timestamp and slug commands; no existing command covers this request. computeStats() in src/stats.ts returns only words and characters, and formatStats() renders a status-bar label rather than reusable Markdown. Paragraph counting and reading-time semantics are not established by the source or tests. https://github.com/egamma/sweeper-sandbox/issues/43 corroborates export demand but does not specify this full contract; https://github.com/egamma/sweeper-sandbox/issues/8 and https://github.com/egamma/sweeper-sandbox/issues/12 are related metric work, not export owners. Preserve the existing commands, settings and status-bar behavior, and keep the pure computation boundary documented in vision.md. The existing whitespace-count defect is separate from this feature's scope.
- **Open decisions:**
  - What constitutes a paragraph in the exported count, including blank lines and whitespace-only separators?
  - What reading speed, rounding and empty/short-document display should the exported reading-time value use?
