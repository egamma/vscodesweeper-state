# Issue #855 — Consider supporting/merging with the `cancellationtoken` npm package

[https://github.com/microsoft/vscode-languageserver-node/issues/855](https://github.com/microsoft/vscode-languageserver-node/issues/855)

## Summary

The requested cancellationtoken interoperability remains absent from current main; existing adapters and cancellation strategies provide extension points, not automatic compatibility. This team-authored request is accepted work in On Deck with help wanted, and no verified fix or canonical duplicate supports closing it.

## Change summary

Allow vscode-jsonrpc to accept cancellationtoken package tokens and supply request handlers with tokens compatible with both APIs.

## Best solution

Define a backward-compatible interoperability contract in jsonrpc/ covering outgoing token recognition and incoming handler tokens, while preserving existing VS Code cancellation behavior. Decide whether compatibility belongs in the core API or a supported adapter layer, including subscription disposal and the treatment of package-specific cancellation reasons.
