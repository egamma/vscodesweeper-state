# Issue #1669 — Support refreshing single files in diagnostic pull

[https://github.com/microsoft/vscode-languageserver-node/issues/1669](https://github.com/microsoft/vscode-languageserver-node/issues/1669)

## Summary

Keep open: streaming workspace results improved the reporter's original analysis problem, but server-directed refresh of individual files remains unsupported. This is a team-authored Backlog request with maintainer interest, and no verified fix or canonical duplicate was found.

## Change summary

Allow a language server to request diagnostic pulls for specific files instead of refreshing all matching documents.

## Best solution

Define server-directed, URI-scoped diagnostic refresh semantics in microsoft/language-server-protocol, then implement the agreed contract in protocol/, server/, and client/ while preserving document/workspace result coordination. Long-running workspace partial results remain the available workaround, not coverage of targeted refresh.
