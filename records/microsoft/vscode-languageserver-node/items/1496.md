# Issue #1496 — Stopped client can recreate its OutputChannel

[https://github.com/microsoft/vscode-languageserver-node/issues/1496](https://github.com/microsoft/vscode-languageserver-node/issues/1496)

## Summary

The reported late-process-exit logging path no longer recreates a stopped client's output channel. A concrete fix guards logging after shutdown, so this can be closed as completed despite the bug label and On Deck milestone.

## Change summary

Prevent a stopped client's delayed server-exit log from recreating its disposed output channel and leaving duplicate entries after client replacement.

## Best solution

Treat the report as fixed by https://github.com/microsoft/vscode-languageserver-node/commit/0217674defa6a05c3cc4f9936a68669b47173555; retain the stopped-state logging guard, available from client 10.0.0-next.19 and in stable 10.0.0.
