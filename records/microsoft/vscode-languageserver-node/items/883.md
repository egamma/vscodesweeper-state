# Issue #883 — Incremental mode for documentSymbolProvider

[https://github.com/microsoft/vscode-languageserver-node/issues/883](https://github.com/microsoft/vscode-languageserver-node/issues/883)

## Summary

Incremental document-symbol responses remain unsupported in the current implementation. Keep this accepted Backlog request open: it requires a protocol-level result contract and corresponding library support, not merely a client configuration change.

## Change summary

Support document-symbol deltas so repeated requests avoid transferring the complete symbol tree, especially for large documents in web extensions.

## Best solution

Define capability negotiation, result identity, and symbol-tree delta semantics in microsoft/language-server-protocol, then implement the agreed contract in protocol/, server/, and client/. Preserve full-result compatibility for clients and servers that do not support deltas.
