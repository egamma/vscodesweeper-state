# Issue #1419 — `NotebookCell` is missing `outputs` field 

[https://github.com/microsoft/vscode-languageserver-node/issues/1419](https://github.com/microsoft/vscode-languageserver-node/issues/1419)

## Summary

Notebook output synchronization and server-driven structural edits remain unsupported in the current libraries. Keep this team-authored request open: the related NotebookEdit proposal covers structural editing, but does not establish how existing outputs are preserved or whether outputs must reach the server.

## Change summary

Enable language-server-driven notebook cell insertion, deletion and restructuring while preserving the appropriate existing cell outputs.

## Best solution

Define the notebook extension contract discussed in the thread, including cell identity and output preservation, in coordination with https://github.com/microsoft/vscode-languageserver-node/issues/1336. Protocol standardization likely belongs in microsoft/language-server-protocol; custom features can prototype the contract before corresponding protocol types and client mappings are adopted here.
