# Issue #1860 — markupMessageSupport is hard-coded to false, what would it take to enable it?

[https://github.com/microsoft/vscode-languageserver-node/issues/1860](https://github.com/microsoft/vscode-languageserver-node/issues/1860)

## Summary

Keep open: the maintainer accepted mirroring the markup capability for push diagnostics, and both linked implementation and specification PRs remain open. Rendering markdown diagnostic messages still depends on VS Code support; neither part of the request is fully delivered on current main.

## Change summary

Enable markdown diagnostic messages in the VS Code client and define capability negotiation for push-only servers.

## Best solution

Review and land https://github.com/microsoft/vscode-languageserver-node/pull/1861 alongside https://github.com/microsoft/language-server-protocol/pull/2318 to define the push capability. Once VS Code provides diagnostic markdown support through https://github.com/microsoft/vscode/pull/214051, adapt the shared client converter and advertise support on both paths; the editor change alone does not complete this repository's work.
