# Issue #1187 — Triggering on type formatting on deletions

[https://github.com/microsoft/vscode-languageserver-node/issues/1187](https://github.com/microsoft/vscode-languageserver-node/issues/1187)

## Summary

Keep open: deletion-triggered structural edits remain distinct from the existing on-type formatting API, and the maintainer said this would require a new request. The Backlog milestone also rules out declining this accepted request as a usage question.

## Change summary

Allow language servers to remove matching braces, tags, or other structural tokens automatically when the user deletes their counterpart.

## Best solution

Define deletion-triggered automatic editing semantics in microsoft/language-server-protocol, then implement the agreed request and triggering behavior in protocol/ and client/. Coordinate with https://github.com/microsoft/language-server-protocol/issues/715, but retain this issue because that insertion-focused discussion does not establish coverage of deletion triggers.
