# Issue #1185 — Language Client to should log `stderr` on launch failures

[https://github.com/microsoft/vscode-languageserver-node/issues/1185](https://github.com/microsoft/vscode-languageserver-node/issues/1185)

## Summary

Current main provides configurable stderr handlers that can mirror server output to the console for CI, but does not do so automatically or attach stderr to start() errors. Keep this team-authored, accepted request open: the related implementation references a different issue, so it does not meet the factual-close bar here.

## Change summary

Make language-server startup diagnostics available in CI console logs as well as the VS Code output channel.

## Best solution

Use the node client's stdioOptions.stderr handler to forward server diagnostics to both the output channel and the console in CI, retaining output-channel-only behavior elsewhere. The maintainer should decide whether this explicit extension-controlled mechanism satisfies the request or whether coordinated VS Code CI-mode support is still needed.
