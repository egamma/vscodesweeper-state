# Issue #1366 — Consider Adding a `ExtensionVersion` to `ClientInfo`

[https://github.com/microsoft/vscode-languageserver-node/issues/1366](https://github.com/microsoft/vscode-languageserver-node/issues/1366)

## Summary

Keep open: standardized extension-version metadata is still missing, and the maintainer accepted considering it subject to a specification change. The related open spec discussion enables this work but does not replace the implementation request here.

## Change summary

Add extension-version metadata, or an extensible metadata object, to ClientInfo.

## Best solution

Agree on extension-identification fields in microsoft/language-server-protocol, coordinated with https://github.com/microsoft/language-server-protocol/issues/1299, then expose the agreed contract in protocol/ and wire extension-supplied values into client/ without replacing the editor's existing name and version.
