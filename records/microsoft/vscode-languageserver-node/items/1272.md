[https://github.com/microsoft/vscode-languageserver-node/issues/1272](https://github.com/microsoft/vscode-languageserver-node/issues/1272)

## Summary

The requested interception mechanism was implemented by the merged contribution and remains available on current main as middleware.workspace.handleApplyEdit. Propose closing as completed; the Backlog milestone and help wanted label do not block a factual implementation close.

## Change summary

Expose workspace/applyEdit middleware so extensions can customize edit handling, including saving affected documents after applying changes.

## Best solution

Use LanguageClientOptions.middleware.workspace.handleApplyEdit to await next(params), save the affected documents when application succeeds, and return the apply-edit result. The implementation in https://github.com/microsoft/vscode-languageserver-node/commit/84285312d8d9f22ee0042e709db114e5415dbdde covers the requested mechanism without requiring automatic saving for every client.
