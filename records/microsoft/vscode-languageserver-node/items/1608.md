# Issue #1608 — Error handler unable to intercept and suppress error notification

[https://github.com/microsoft/vscode-languageserver-node/issues/1608](https://github.com/microsoft/vscode-languageserver-node/issues/1608)

## Summary

Consolidate this request into the older, open all-errors customization request. The missing interception remains on main, but the canonical's maintainer-defined scope covers both shutdown-time notifications and forced restart-failure dialogs.

## Change summary

Allow extensions managing server availability themselves to intercept and suppress lifecycle error notifications, including during stopping and failed automatic restart.

## Best solution

Track comprehensive lifecycle-error interception in https://github.com/microsoft/vscode-languageserver-node/issues/1262, carrying over this issue's stopping-state trigger and websocket reconnection evidence. Preserve existing default behavior and the maintainer's compatibility guidance while providing control over every client-generated error dialog.
