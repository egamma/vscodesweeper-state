Keep this accepted request open and add the VS Code dependency marker. Stable document URIs explain the missing close/open notifications, but the later trace exposes an unresolved interaction between that identity and case-changing filesystem events.

Preserving the original URI is acceptable under the maintainer's stated contract, but the resulting watcher/document interaction still needs resolution.
