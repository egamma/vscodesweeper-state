# Issue #1195 — Add LanguageClient `onDispose`

[https://github.com/microsoft/vscode-languageserver-node/issues/1195](https://github.com/microsoft/vscode-languageserver-node/issues/1195)

## Summary

Keep open: current client APIs do not provide a disposal-specific callback for locally registered cleanup. The maintainer questioned its necessity, but did not decline the clarified use case; the Backlog milestone also bars a judgment close.

## Change summary

Expose a LanguageClient disposal event so extension components can register cleanup alongside their notification handlers instead of modifying a central stop function.

## Best solution

Decide whether client/ should expose a disposal-specific lifecycle event for extension-owned resources, distinct from stopping or restarting the server. Existing state events and feature cleanup cover different lifetimes, so retain this request pending that API decision.
