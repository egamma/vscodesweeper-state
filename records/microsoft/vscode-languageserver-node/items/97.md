# Issue #97 — Add support to shutdown a language server when idle

[https://github.com/microsoft/vscode-languageserver-node/issues/97](https://github.com/microsoft/vscode-languageserver-node/issues/97)

## Summary

Idle shutdown remains missing: current main contains suspension scaffolding, but its configuration, timer and idle checks are disabled. Keep this team-authored Backlog request open; no verified canonical or issue-linked implementation was found.

## Change summary

Allow language servers to shut down automatically after a period of inactivity.

## Best solution

Provide a supported idle-shutdown lifecycle in client/, with an explicit definition of inactivity and a decision about how language services become available again. The existing stop API supplies shutdown mechanics, but does not provide automatic inactivity detection or a suspension policy.
