# Issue #336535 — Very high CPU usage with all extensions disabled unless "Disable AI features" is enabled

[https://github.com/microsoft/vscode/issues/336535](https://github.com/microsoft/vscode/issues/336535)

## Summary

Fresh, well-diagnosed report: Copilot Chat's workspace semantic indexing (code search / external ingest) scans an entire large secondary workspace folder (e.g. an Unreal Engine source tree) on startup, pegging a CPU core and causing heavy disk I/O; the reporter confirmed the cause by toggling `github.copilot.chat.workspace.enableCodeSearch` / `codeSearchExternalIngest.enabled` and per-folder `search.exclude`. Too new (posted hours ago, no maintainer triage yet) to close on my own read, but the root cause is plausible and localized to real in-repo code.

## Change summary

With Copilot's codebase semantic indexing enabled, opening a multi-root workspace that includes a very large secondary folder (e.g. a full game-engine source tree) causes sustained near-100% single-core CPU usage and heavy disk activity, apparently from indexing/ingesting that entire tree; disabling AI features or the code-search settings resolves it.

## Best solution

Investigate whether workspaceFileIndex/codeSearch external ingest in extensions/copilot/src/platform/workspaceChunkSearch should respect a size/file-count threshold per workspace folder, throttle harder on large folders, or better honor `search.exclude` scoping before core indexing begins, so a huge secondary folder doesn't dominate CPU/disk on startup.
