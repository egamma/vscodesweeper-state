# Issue #227771 — Split right when previewing markdown files results in an empty tab

[https://github.com/microsoft/vscode/issues/227771](https://github.com/microsoft/vscode/issues/227771)

## Summary

Still present on main: the markdown preview custom editor registers without `supportsMultipleEditorsPerDocument`, making it a Singleton. The `splitEditor` function skips copying Singleton editors but still creates the new empty group, leaving an empty tab.

## Change summary

Splitting a markdown preview tab via 'Split Right' creates an empty tab instead of duplicating the preview.

## Best solution

Either (a) the `splitEditor` function in `src/vs/workbench/browser/parts/editor/editorCommands.ts` should avoid creating an empty group when the editor is Singleton (don't call `addGroup` if all editors are Singleton), or (b) the markdown preview registration in `extensions/markdown-language-features/src/preview/previewManager.ts` should set `supportsMultipleEditorsPerDocument: true` to allow the preview to be split. Option (a) is likely the better fix as it addresses the problem for all Singleton editors.
