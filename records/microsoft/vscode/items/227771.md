# Issue #227771 — Split right when previewing markdown files results in an empty tab

[https://github.com/microsoft/vscode/issues/227771](https://github.com/microsoft/vscode/issues/227771)

## Summary

The empty editor group follows an explicit limitation still present in current source: Markdown webview previews cannot be copied by Split Right. Keep this accepted report open as an improvement request; no verified open canonical or landed fix was found, and historical explanations do not override this issue's existing bug triage.

## Change summary

Make Split Right on a Markdown preview provide a meaningful result instead of opening an empty editor group.

## Best solution

Give Markdown previews a coherent split interaction, either supporting a second rendered preview or making the unsupported operation unavailable. The maintainer should settle that observable behavior before implementation.
