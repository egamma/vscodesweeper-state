# Issue #282697 — Chat welcome: make local session more clear

[https://github.com/microsoft/vscode/issues/282697](https://github.com/microsoft/vscode/issues/282697)

## Summary

The local welcome remains less explicit than the provider-specific background and cloud welcomes, and maintainers have agreed that its text and icon should convey more information. The exact treatment remains under discussion, so this should stay open as tracked UX polish.

## Change summary

## Best solution
