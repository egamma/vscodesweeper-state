# Issue #237053 — Emmet: Wrap with Abbreviation text on its own new line not working

[https://github.com/microsoft/vscode/issues/237053](https://github.com/microsoft/vscode/issues/237053)

## Summary

Still reproduces on main: the Wrap with Abbreviation command only sets `output.inlineBreak` to 1 for multi-line selections (line 679 of abbreviationActions.ts), so the user's `emmet.preferences["output.inlineBreak"]` setting is not honored when wrapping a single-line selection.

## Change summary

Emmet's Wrap with Abbreviation ignores user's `output.inlineBreak` preference when wrapping single-line text, so the wrapped content doesn't appear on its own new line.

## Best solution

In `extensions/emmet/src/abbreviationActions.ts`, the `expandAbbr` function should respect the user's configured `output.inlineBreak` preference from `emmet.preferences` regardless of whether the selection is single-line or multi-line, rather than only applying it as a forced override for multi-line selections. The fix likely involves checking the user preference before applying the hardcoded override at line 679.
