# Issue #287523 — Bad rename suggestion

[https://github.com/microsoft/vscode/issues/287523](https://github.com/microsoft/vscode/issues/287523)

## Summary

Team-authored issue (MEMBER) about NES incorrectly suggesting renames in type reference positions — must keep open per policy. The issue describes a real UX problem in the NES feature where changing a type reference triggers a rename suggestion rather than recognizing the user wants a different type.

## Change summary

NES suggests renaming an interface when the user replaces a type reference with a different interface name, rather than recognizing the intent to use a different type.

## Best solution

Add logic to NES to distinguish type declarations from type references — avoid suggesting renames in type reference positions where the user is more likely switching to a different type than renaming the current one. As dbaeumer noted, filtering out type references from rename suggestions is the right direction but needs care to avoid over-filtering.
