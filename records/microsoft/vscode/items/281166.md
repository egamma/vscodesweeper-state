# Issue #281166 — Prompt md: continue in ... icon color is reversed

[https://github.com/microsoft/vscode/issues/281166](https://github.com/microsoft/vscode/issues/281166)

## Summary

Still reproduces on main: line 285 of chatContinueInAction.ts still uses ThemeIcon.asClassName(Codicon.forward), which themes the icon and reverses its color. An external PR (#281242) exists but hasn't merged.

## Change summary

The forward icon in the 'Continue in...' prompt markdown action has its color reversed because ThemeIcon theming is applied when it shouldn't be.

## Best solution

Remove theme-icon coloring from the forward codicon in the editor-location renderLabel path of chatContinueInAction.ts. The open PR https://github.com/microsoft/vscode/pull/281242 attempts this but uses raw class strings instead of the codicon API — a team member should land a proper fix or review that PR.
