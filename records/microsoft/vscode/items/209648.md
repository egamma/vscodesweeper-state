# Issue #209648 — Accessible diff viewer

[https://github.com/microsoft/vscode/issues/209648](https://github.com/microsoft/vscode/issues/209648)

## Summary

The requested staging button is still missing from the Accessible Diff Viewer. Keep this accepted Backlog request open under its existing accessibility and diff-editor labels; regular diff-editor staging actions do not cover the requested surface.

## Change summary

Expose a keyboard-accessible button to stage the current change directly from the Accessible Diff Viewer.

## Best solution

Provide a discoverable staging action within the Accessible Diff Viewer for eligible Git working-tree comparisons, preserving existing staging semantics and leaving unrelated comparisons unaffected. The accessibility and diff-editor owners should settle the integration with Git-contributed actions.
