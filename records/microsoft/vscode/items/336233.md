## Summary

Multiple independent reporters (author, WilliamSmithEdward, datho7561, bencefr) consistently confirm the extension-host utility process crashes with exit code 134 within ~1s of F5-launch on the js-debug auto-attach path, while Ctrl+F5 and CLI+manual-attach are stable — but no canonical duplicate or fix commit exists yet, so this stays open pending real diagnosis (likely by someone with Windows access and a way to capture the abort).
