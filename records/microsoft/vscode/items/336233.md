## Summary

Keeping open: this is a well-corroborated extension-host utility-process crash (exit 134) tied to the F5/js-debug auto-attach path, confirmed by four independent reporters with matching logs. A plausible upstream fix (vscode-js-debug 1.140.0, already pinned in this checkout's product.json) may cover it, but the maintainer explicitly asked for a native crash report after that release shipped — signaling the team hasn't confirmed the crash itself is resolved, only a related timeout bug.

## Change summary

Pressing F5 to launch an Extension Development Host intermittently (now near-always on 1.139.x) crashes the extensionHost utility process with exit code 134 within ~1s, before any extension code runs; Ctrl+F5 and CLI+attach launches are stable.
