# Issue #227105 — Editor GPU: Make first glyph in first page 0x0 without wasting space in the texture

[https://github.com/microsoft/vscode/issues/227105](https://github.com/microsoft/vscode/issues/227105)

## Summary

The first-page initialization still sends the empty sentinel through the slab allocator, reserving texture capacity unnecessarily. Keep this bounded cleanup open; the related GPU tracking and memory issues do not replace it.

## Change summary

Preserve the empty glyph at page 0, glyph 0 without allocating texture space for it.

## Best solution

Represent the empty sentinel without consuming texture capacity, while preserving glyph-index alignment and invisible rendering of zeroed cells after initialization and atlas clearing.
