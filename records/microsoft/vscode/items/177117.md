# Issue #177117 — Toggle cell toolbar position does nothing if toolbar is currently hidden

[https://github.com/microsoft/vscode/issues/177117](https://github.com/microsoft/vscode/issues/177117)

## Summary

Still reproduces on main: the togglePosition logic handles the 'hidden' value by toggling to 'right', but the action guard (`context.ui`) may prevent execution when the toolbar is hidden and the action is invoked from the cell context menu. Additionally, the reporter's expectation of a quickpick with 3 options (left/right/hidden) is unimplemented — the action only binary-toggles between left and right.

## Change summary

The 'Toggle Cell Toolbar Position' context menu action does nothing when the cell toolbar is currently set to hidden, and lacks a quickpick to choose between all three positions.

## Best solution

Rework the action to show a quickpick with all three options (left/right/hidden) when invoked from the cell context menu, regardless of current toolbar visibility. The fix lives in `src/vs/workbench/contrib/notebook/browser/contrib/layout/layoutActions.ts`.
