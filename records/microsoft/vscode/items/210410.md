# Issue #210410 — editor/title/run doesn't always switch the default action when selected from dropdown

[https://github.com/microsoft/vscode/issues/210410](https://github.com/microsoft/vscode/issues/210410)

## Summary

Still open on main — the togglePrimaryAction logic in DropdownWithDefaultActionViewItem only updates the default when the dropdown's private ActionRunner fires onDidRun, but certain menu item executions (e.g. 'Run File in Interactive Window' the first time the IW isn't open) may not flow through that runner, so the primary action doesn't toggle. No fix commit references this issue.

## Change summary

The editor title Run button's dropdown doesn't always switch the default/primary action to the item the user just selected.

## Best solution

Investigate why certain actions executed from the dropdown don't fire the dropdown's private ActionRunner's onDidRun event, preventing the togglePrimaryAction logic in DropdownWithDefaultActionViewItem (src/vs/platform/actions/browser/menuEntryActionViewItem.ts ~line 483) from updating the stored default. The fix likely belongs in the action runner plumbing or the listener registration for that submenu.
