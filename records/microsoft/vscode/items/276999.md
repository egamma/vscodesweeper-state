# Issue #276999 — Dragging-n-dropping a file with tilde in the name into terminal

[https://github.com/microsoft/vscode/issues/276999](https://github.com/microsoft/vscode/issues/276999)

## Summary

Still reproduces on main: `escapeNonWindowsPath` wraps paths in quotes but still strips banned characters (line 69-70), silently corrupting file names. Multiple open PRs attempt a fix but none have merged yet.

## Change summary

Dragging a file with shell-special characters (tilde, backtick, dollar, etc.) into the terminal silently drops those characters from the path, producing an invalid file reference.

## Best solution

Remove or rework the `bannedChars` stripping in `escapeNonWindowsPath` (src/vs/platform/terminal/common/terminalEnvironment.ts line 69-70) — since paths are already single-quoted, these characters are safe inside quotes. One of the open community PRs should land after review. The fix must preserve all valid filename characters while still protecting against injection in unquoted contexts.
