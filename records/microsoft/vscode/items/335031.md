# Issue #335031 — Slow switching speed between Files and Changes

[https://github.com/microsoft/vscode/issues/335031](https://github.com/microsoft/vscode/issues/335031)

## Summary

Team-authored perf/UX report (hediet, MEMBER) about the Agents Window single-pane layout: switching from the Files tab to Changes appears slow because the old file-tree view stays visible until the multi-diff editor finishes resolving. No fix commit referencing this issue exists on main, so it stays open per the team-authored hard-close bar; the `On Deck` milestone is a holding bin and doesn't itself block keeping this open.

## Change summary

Switching from the Files tab to the Changes tab in the Agents Window keeps showing the old file tree until the diff list finishes loading, making the tab switch feel slow.

## Best solution

Investigate the docked-tab switch path in singlePaneDockedTabsCoordinator.ts / changesView.ts and the async ChangesMultiDiffSourceResolver.resolveDiffSource flow to see whether the tab switch can show a loading/skeleton state (or the diff list can be pre-warmed) instead of leaving the previous tab's content on screen while the multi-diff source resolves.
