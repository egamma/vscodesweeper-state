# Issue #259670 — Terminal auto approve settings editor integration

[https://github.com/microsoft/vscode/issues/259670](https://github.com/microsoft/vscode/issues/259670)

## Summary

Valid open feature request: the terminal auto-approve setting (`chat.tools.terminal.autoApprove`) still forces JSON editing on current main — no settings editor UI integration exists yet. Two related issues were closed as duplicates of this one, and the PR attempt (#261218) was closed without merging.

## Change summary

Provide a proper settings editor UI for the `chat.tools.terminal.autoApprove` setting instead of forcing users to edit settings.json directly.

## Best solution

Add an object-with-boolean-value renderer in the settings editor (similar to `files.exclude` / `search.exclude`) for `chat.tools.terminal.autoApprove`, allowing users to add/remove/toggle patterns without manual JSON editing.
