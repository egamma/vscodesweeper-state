# Issue #161063 — Cannot read properties of null (reading 'startLineNumber')

[https://github.com/microsoft/vscode/issues/161063](https://github.com/microsoft/vscode/issues/161063)

## Summary

Still reproducible on main: `location.range` is not null-guarded before being passed to `Range.getStartPosition()` in inlayHintsLocations.ts — if an extension provides a Location with a null range, the crash occurs.

## Change summary

Clicking an inlay hint label part that resolves to a Location with a null range causes a TypeError.

## Best solution

Add a null guard for `location.range` in both `showGoToContextMenu` (line 53) and `goToDefinitionWithLocation` (line 111) in `src/vs/editor/contrib/inlayHints/browser/inlayHintsLocations.ts`, early-returning or showing an error when the range is unexpectedly null.
