# Issue #88813 — Please address the security of vscode and plugins when opening files with secrets

[https://github.com/microsoft/vscode/issues/88813](https://github.com/microsoft/vscode/issues/88813)

## Summary

Keep open for human security review: Workspace Trust does not establish a confidentiality boundary between sensitive files and enabled extensions. The broader extension-permissions proposal is relevant, but this credential-exposure concern is protected by the security-sensitive keep-open rule.

## Change summary

Clarify how files containing secrets are protected from installed extensions reading their contents and transmitting them remotely.

## Best solution

Provide an explicit explanation of the extension security boundary and have maintainers assess whether additional protection for sensitive files is warranted. Coordinate any permissions or isolation design with https://github.com/microsoft/vscode/issues/52116 without treating Restricted Mode as protection against malicious enabled extensions.
