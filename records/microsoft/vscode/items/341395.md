# Issue #341395 — Agents can't interact with Jupyter Notebooks

[https://github.com/microsoft/vscode/issues/341395](https://github.com/microsoft/vscode/issues/341395)

## Summary

Thanks for the detailed report. The new Fusion agent runs on the agent-host/Copilot CLI harness, and I found no notebook tool exposure for it in the agent-host code. That would explain the agent falling back to shell edits that bypass the editor's tracked, undoable edits. I could not run it to confirm, so this stays open and should be checked by the chat/notebook owners.

## Change summary

After the Fusion/agent-host update, agents no longer edit or run Jupyter notebook cells through the editor and instead edit files via the shell, losing tracked edits.

## Best solution

Make the agent-host-backed agent sessions expose the notebook edit/run tools, or route them through the editor's tools, so notebook edits are tracked and cells run on the kernel. Alternatively, document how to use the previous agent mode for notebooks.
