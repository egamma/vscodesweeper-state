# Issue #236523 — Expanding references in quick chat should grow picker

[https://github.com/microsoft/vscode/issues/236523](https://github.com/microsoft/vscode/issues/236523)

## Summary

Keep open: expanding references can still discard Quick Chat's scroll-expanded height and shrink the picker. The issue is already correctly routed, and neither a verified fix nor an older canonical covering this exact symptom was found.

## Change summary

Expanding references in Quick Chat should grow the picker when space permits rather than reset its scroll-expanded height.

## Best solution

Make Quick Chat's dynamic sizing accommodate reference expansion without discarding the additional history space revealed by scrolling. Preserve the existing maximum-height limit, manually fixed sash height, and intentional reset when submitting another question.
