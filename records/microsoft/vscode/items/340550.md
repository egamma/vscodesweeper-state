# Issue #340550 — Side chats in Copilot Agent Window do not maintain the same "thinking effort".

[https://github.com/microsoft/vscode/issues/340550](https://github.com/microsoft/vscode/issues/340550)

## Summary

Thanks for the report. The side chat creation path (the /btw command and the selection-based Ask) has no code that carries over the source session's model or thinking-effort choice. A new side chat therefore starts from defaults, which matches the report. A maintainer should decide the inheritance semantics.

## Change summary

Side chats opened from an Agents window session reset the thinking effort (and possibly context size) to the default instead of inheriting the parent session's selection.

## Best solution

When a side chat is created from a session, seed its model, thinking effort and context selection from the parent session's current picker state. This likely belongs in the Agents window side-chat orchestration and provider code.
