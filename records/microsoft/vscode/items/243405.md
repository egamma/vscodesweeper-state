# Issue #243405 — Pre-optimize all TM grammars for performance

[https://github.com/microsoft/vscode/issues/243405](https://github.com/microsoft/vscode/issues/243405)

## Summary

Valid, well-supported feature request (74 upvotes, Backlog milestone) to optimize TM grammar regexes via oniguruma-parser/optimizer as a build step. Not a duplicate of the closed #237537 (JS transpilation), which is a distinct approach. No implementation work found on main.

## Change summary

Pre-optimize all bundled TextMate grammar regexes via oniguruma-parser/optimizer as a build step, reducing grammar sizes and improving syntax highlighting performance (up to ~30% for complex grammars like C++).

## Best solution

Add a build step that runs oniguruma-parser/optimizer over all bundled TM grammar JSON files before packaging. This is a straightforward, low-risk integration — Shiki already battle-tests it across 220+ grammars. The grammar area owner should evaluate adoption, potentially starting with the largest/slowest grammars (C++, TypeScript) and validating that highlighting output is identical.
