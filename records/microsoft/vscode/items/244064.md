# Issue #244064 — Enhance scoping for MCP severs

[https://github.com/microsoft/vscode/issues/244064](https://github.com/microsoft/vscode/issues/244064)

## Summary

Team-authored feature request (MEMBER) for glob-based MCP server scoping in mono-repos. Workspace folder-level MCP servers were implemented via PR #244066, but the broader glob-pattern scoping discussed here remains unimplemented. Keeping open per hard keep-open rule for team-authored issues.

## Change summary

Allow glob patterns in mcp.json to dynamically scope MCP servers to specific sub-folders in mono-repo setups, beyond the current per-workspace-folder granularity.

## Best solution

Implement glob-pattern support in the MCP configuration schema (mcpConfiguration.ts / mcpRegistry) so that MCP servers can be scoped to file patterns rather than just workspace folders, enabling mono-repo teams to target multiple sub-folders without fragmenting configs. This involves design decisions around how dynamic tool-list changes interact with in-flight chat requests.
