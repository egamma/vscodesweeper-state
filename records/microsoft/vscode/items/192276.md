# Issue #192276 — Control + Space creates a double quote character (") in VS Code Portable

[https://github.com/microsoft/vscode/issues/192276](https://github.com/microsoft/vscode/issues/192276)

## Summary

Keep open: the reporter confirmed this also affects system installations, and a newer independent report confirms the same double-quote symptom. Current source contains conditional keyboard workarounds and experimental Windows input support, but neither establishes that the reported path is fixed.

## Change summary

Ctrl+Space inserts a double quote instead of invoking PowerShell completion with a German keyboard layout in the integrated terminal.

## Best solution

Make native PowerShell Ctrl+Space completion independent of keyboard layout, including when shell integration is unavailable. Diagnose the terminal-to-Windows input translation alongside the experimental win32-input-mode work, preserving existing PSReadLine bindings.
