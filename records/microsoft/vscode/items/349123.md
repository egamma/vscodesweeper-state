# Issue #349123 — Visually separate and highlight the "Delete" option in the File Explorer context menu

[https://github.com/microsoft/vscode/issues/349123](https://github.com/microsoft/vscode/issues/349123)

## Summary

Keep open for design consideration: Rename and Delete still share an Explorer context-menu group, and existing deletion confirmation does not provide the requested visual distinction. No verified duplicate or maintainer decision supports closing this request.

## Change summary

Visually distinguish Explorer deletion actions from Rename using separation and destructive-action styling.

## Best solution

Have the Explorer and menu UX owners assess a clearer destructive-action boundary while preserving consistent menu treatment, theme contrast, and keyboard focus visibility. Decide whether separation alone is sufficient before introducing action-specific coloring.
