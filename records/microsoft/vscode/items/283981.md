[https://github.com/microsoft/vscode/issues/283981](https://github.com/microsoft/vscode/issues/283981)

## Summary

VS Code provides the `keyboard.dispatch` setting specifically to handle non-QWERTY keyboard layouts on Linux. Setting it to `keyCode` resolves the reported behavior, as the commenter already identified. This is working as designed — the setting exists for this exact use case.

## Change summary

Keyboard shortcuts on Linux use QWERTY physical key positions instead of the active Dvorak layout's logical key positions.

## Best solution

Close as designed — the `"keyboard.dispatch": "keyCode"` setting in `settings.json` is the intended mechanism for users with non-QWERTY layouts on Linux who want shortcuts to follow the logical layout rather than the physical key code. The commenter already provided this solution.

  > ```
