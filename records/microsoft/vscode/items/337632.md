# Issue #337632 — Extension host fails to start (1.139)

[https://github.com/microsoft/vscode/issues/337632](https://github.com/microsoft/vscode/issues/337632)

## Summary

Fresh, high-impact regression report: extension host (and Extension Development Host via F5) fails to start in 1.139 on macOS, with a second independent reporter confirming the same symptom (extension host process exits immediately, never reaching activation) and the original reporter confirming rollback to 1.138 fixes it. No fix or root cause is visible on main yet, so this needs maintainer triage/bisection rather than a close.

## Change summary

After upgrading to VS Code 1.139, the extension host (including the Extension Development Host launched via F5) never finishes starting, timing out with 'Extension host did not start in 10 seconds' and no extension ever reaching activate().

## Best solution

Needs a version bisect between 1.138 and 1.139 (Electron 43.6.0 bump, extension host bootstrap, or startup timing changes are the likely suspects) to pin the exact regressing commit; route to the extension host area for triage and correlate with the other open F5/extension-host-startup reports to see if they share a root cause.
