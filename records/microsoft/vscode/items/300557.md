# Issue #300557 — Subject: Severe Data Loss in Copilot Chat Sidebar History After Update/State Reset

[https://github.com/microsoft/vscode/issues/300557](https://github.com/microsoft/vscode/issues/300557)

## Summary

Verified duplicate of the older open chat-history-loss issue: both report previously available Copilot Chat sessions disappearing from the history UI after restarting or updating VS Code. This report adds useful evidence that persisted session filters can hide the sessions and that resetting those filters restores them.

## Change summary

Copilot Chat sessions disappeared from the Agent Sessions sidebar after an update because persisted filter state hid the available history.

## Best solution

Consolidate the investigation in https://github.com/microsoft/vscode/issues/278442 and preserve this report's filter-state diagnosis there. The session list should not become unexpectedly empty after an update, and an active filter should remain clearly visible and recoverable.
