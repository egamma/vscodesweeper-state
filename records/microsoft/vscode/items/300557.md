The conversations were hidden by persisted session filters rather than deleted. The shipped empty-filter recovery UI exposes this state and clears the filters, so the reported failure is resolved.

## Change summary

Copilot Chat sessions appeared to be lost after an update or restart because active session filters hid the entire history.
