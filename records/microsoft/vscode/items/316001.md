# Issue #316001 — Opção de colar arquivo desabilitada no menu de contexto

[https://github.com/microsoft/vscode/issues/316001](https://github.com/microsoft/vscode/issues/316001)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/199421 reports the same observable symptom—external files leave Explorer's Paste context-menu item disabled while Ctrl/Cmd+V works—and current source confirms the shared cause.

## Change summary

Enable the Explorer Paste context-menu command when the operating-system clipboard contains files, including when the destination is a remote SSH workspace.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/199421 and align the Explorer context-menu enablement with the existing keyboard/native-clipboard paste path.

## Evidence

- **canonical issue:** https://github.com/microsoft/vscode/issues/199421 is open, predates this issue, and reports the same user-visible behavior. Its maintainer comments explicitly confirm that Paste is disabled for external files and folders while Ctrl/Cmd+V works.
- **current source:** In src/vs/workbench/contrib/files/browser/fileActions.contribution.ts, the Explorer context-menu command requires both ExplorerResourceWritableContext and FileCopiedContext, but the Ctrl/Cmd+V binding requires only ExplorerResourceWritableContext. FileCopiedContext represents an Explorer-internal copy rather than native clipboard contents.
- **paste capability:** src/vs/workbench/contrib/files/browser/fileActions.ts implements getFilesToPaste for native FileList data and clipboardService.readResources(), while src/vs/workbench/contrib/files/browser/views/explorerView.ts forwards native paste events to filesExplorer.paste. The handler therefore supports the reporter's external-file paste even though the menu precondition disables it.
- **unique context retained:** This report adds a Windows Explorer/OneDrive source and a Remote-SSH Linux destination, but the platform-independent menu precondition explains the same symptom and does not indicate a distinct remote-specific root cause.
