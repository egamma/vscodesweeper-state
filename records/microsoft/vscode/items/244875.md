# Issue #244875 — Stopping hanging hot restart in Flutter breaks F5 start debugging key

[https://github.com/microsoft/vscode/issues/244875](https://github.com/microsoft/vscode/issues/244875)

## Summary

Keep open as a confirmed core debug-state bug: a pending Debug Adapter Protocol restart request can survive session termination and leave F5 ineffective even though starting from the debug UI still works. The discussion includes a cross-platform MockDebug reproduction, while the related Dart-Code issue does not supersede this core report.

## Change summary

Stopping a debug session while an unanswered restart request is pending can leave the F5 start-debugging command unusable.

## Best solution

Ensure VS Code cancels or detaches pending restart work when the debug session terminates and returns the global debug state to inactive, then cover the stop-during-pending-restart sequence in the debug test suite.
