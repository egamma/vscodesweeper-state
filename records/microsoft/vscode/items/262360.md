# Issue #262360 — Invisible autostash

[https://github.com/microsoft/vscode/issues/262360](https://github.com/microsoft/vscode/issues/262360)

## Summary

Confirmed bug: autostash entries are invisible because the stash-parsing regex requires `on <branch>:` which autostash reflog entries lack. An open PR (https://github.com/microsoft/vscode/pull/325762) directly addresses this — keeping open for that PR to land.

## Change summary

Autostash entries created during failed pull/rebase operations are not shown in the VS Code stash list because the parsing regex filters them out.

## Best solution

Land or refine the open PR https://github.com/microsoft/vscode/pull/325762, which fixes the `stashRegex` in `extensions/git/src/git.ts` to also match branchless autostash entries and adds conflict notification on autostash pop failure.
