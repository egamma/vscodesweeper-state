# Issue #323359 — Opening a link from a staged .md file causes the wrong document to open

[https://github.com/microsoft/vscode/issues/323359](https://github.com/microsoft/vscode/issues/323359)

## Summary

The source trace explains the wrong-content result: relative Markdown links retain the staged document's Git query while changing its visible path. Keep this open; the bundled Markdown language service does not reconcile that query with the linked target.

## Change summary

Opening a relative source-file link from staged Markdown displays the linked filename but loads the Markdown document's contents.

## Best solution

Make Markdown link resolution from Git-backed documents produce a target whose displayed path and content identity agree, coordinated between the Markdown language service and VS Code's Git URI integration. Preserve same-document fragment navigation and ordinary working-tree links.
