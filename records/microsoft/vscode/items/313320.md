# Issue #313320 — Show customization token usage in context window widget

[https://github.com/microsoft/vscode/issues/313320](https://github.com/microsoft/vscode/issues/313320)

## Summary

Valid feature request from a team member to surface customization token usage as a percentage in the context window widget. The category-breakdown infrastructure (`IChatUsagePromptTokenDetail` with `category`/`percentageOfPrompt`) already exists in the widget, but customizations are not yet reported as a distinct category. Stays open as a Backlog item.

## Change summary

Show the percentage of context window tokens consumed by customizations (instructions, prompts, etc.) in the context usage widget.

## Best solution

Ensure the prompt-token-detail data flowing through `IChatUsage.promptTokenDetails` includes a "Customizations" category (covering custom instructions, prompt files, etc.), so the existing `ChatContextUsageDetails.renderTokenDetails` breakdown in `src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatContextUsageDetails.ts` renders it. The data originates from the agent host / Copilot extension side and needs to be populated there before the widget can display it.
