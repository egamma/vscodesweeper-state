# Issue #335668 — Automations are disabled by default when imported

[https://github.com/microsoft/vscode/issues/335668](https://github.com/microsoft/vscode/issues/335668)

## Summary

Real UX observation about the new Automations feature, but the thread shows a maintainer disagreeing with the premise (preferring imported automations stay disabled until the workspace is configured) — this is an open design question, not a settled bug, so it stays open under discussion.

## Change summary

Imported automations are disabled by default, and the 'Disabled' badge is easy to miss next to an otherwise identical enabled card.

## Best solution

A maintainer should settle whether imported automations should default to enabled or stay disabled-with-clearer-affordance; if disabled-by-default remains the design, improve the visual prominence of the disabled badge/state in automationsView.ts and automationsCards.css.
