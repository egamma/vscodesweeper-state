# Issue #335668 — Automations are disabled by default when imported

[https://github.com/microsoft/vscode/issues/335668](https://github.com/microsoft/vscode/issues/335668)

## Summary

Fresh UX design discussion about whether imported automations should default to disabled; a team member already pushed back with a differing preference in the very first comment, so this is an active, unresolved product decision, not something to close.

## Change summary

When automations are imported, they're disabled by default, and the disabled state is hard to notice in the UI, risking users missing that an automation isn't active.

## Best solution

Let the chat/aiCustomization team settle the default-enabled-vs-disabled question for imported automations (src/vs/workbench/contrib/chat/common/automations/) and, regardless of the outcome, improve the visual affordance for the disabled state on the automation card so it's clearly distinguishable at a glance.
