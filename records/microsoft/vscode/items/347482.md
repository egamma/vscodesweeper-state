# Issue #347482 — Scope Automations to the Inbox workspace and environment filters

[https://github.com/microsoft/vscode/issues/347482](https://github.com/microsoft/vscode/issues/347482)

## Summary

Keep open: the merged Inbox-filter PR explicitly deferred Automations scoping, and current source still displays its catalog independently of those selections. This remains a distinct, team-authored feature request.

## Change summary

Make the Automations catalog follow Inbox workspace and environment selections without changing automation configuration or execution.

## Best solution

Apply the selected Inbox scope to Automations presentation using exact workspace and environment identities, preserving each picker's independent All option and leaving provider-owned definitions and jobs untouched.
