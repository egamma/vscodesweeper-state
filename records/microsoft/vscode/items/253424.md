# Issue #253424 — Add "confirmation pending"  to window title

[https://github.com/microsoft/vscode/issues/253424](https://github.com/microsoft/vscode/issues/253424)

## Summary

Keep open: current notifications and titlebar session indicators provide attention cues, but neither identifies pending confirmations in native window titles or the Switch Window picker. The issue already has the appropriate area labels; the remaining choice is how to expose window-specific status.

## Change summary

Identify windows with pending agent confirmations through their window title or a status indicator in the window quick pick.

## Best solution

Provide a window-specific pending-confirmation cue usable when choosing between VS Code windows. Agree on the native-title or window-picker presentation and its clearing semantics, while retaining existing session indicators and notifications.
