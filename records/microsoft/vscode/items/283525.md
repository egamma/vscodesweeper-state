# Issue #283525 — No validation or logs on adding a private MCP registry (that fails)

[https://github.com/microsoft/vscode/issues/283525](https://github.com/microsoft/vscode/issues/283525)

## Summary

Keep open for human handling: the accepted registry-policy bug includes a security-sensitive fail-open report, and current source still treats an unreachable configured registry as available rather than validating it. Main now normalizes a trailing slash and logs request failures, but no issue-referencing fix commit or current verification establishes that the reported official-registry fallback is resolved.

## Change summary

A private MCP registry configured with registry-only policy can fail without clear UI validation and may expose the default registry contents instead of failing closed.

## Best solution

Make registry-only operation fail closed when the configured private registry cannot be validated or queried, never substituting the product registry, and surface the configured registry and failure in the MCP management UI while retaining diagnostic logging.
