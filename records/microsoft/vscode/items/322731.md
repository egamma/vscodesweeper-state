# Issue #322731 — Copilot chat Tools definition context bloat

[https://github.com/microsoft/vscode/issues/322731](https://github.com/microsoft/vscode/issues/322731)

## Summary

Confirmed on main: the context-usage widget inflates segment percentages on Responses-API requests that use `previous_response_id`, because `percentageOfPrompt` is computed against locally-sent tokens while the widget rescales by server-reported `prompt_tokens` (which includes cached history). No fix has landed.

## Change summary

The context window breakdown widget over-reports tool-definition and other segment percentages (~8× in the reporter's case) for BYOK/Responses-API chats that use `previous_response_id`.

## Best solution

Fix the denominator mismatch: use `usage.prompt_tokens` (the server-reported total) as the base when computing `percentageOfPrompt` in `stateToProgressAdapter.ts`, or pass the server-reported total into the breakdown computation so segments sum correctly. The gap (cached history tokens) should appear as "Uncategorized" in the breakdown.
