# Issue #335943 — Comment thread widget is clipped by the minimap in the diff editor

[https://github.com/microsoft/vscode/issues/335943](https://github.com/microsoft/vscode/issues/335943)

## Summary

Real, well-documented layout bug: the comments zone widget doesn't account for the diff editor's minimap the way it does in a normal editor. The report has precise repro steps, version info, and a screenshot, so it doesn't need more info from the reporter — it needs an engineer to dig into the diff-editor layout path.

## Change summary

In a diff editor with the minimap enabled, the comment thread zone widget (header actions, resolve/collapse buttons, reply textarea) is drawn under the minimap and partly hidden, instead of stopping at its left edge like other zone widgets.

## Best solution

Have someone familiar with the diff editor's rendering pipeline trace why the minimap area isn't excluded for zone widgets attached to the diff editor's sub-editors, and align it with the normal single-editor path in src/vs/editor/contrib/zoneWidget/browser/zoneWidget.ts.
