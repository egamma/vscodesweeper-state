# Issue #335943 — Comment thread widget is clipped by the minimap in the diff editor

[https://github.com/microsoft/vscode/issues/335943](https://github.com/microsoft/vscode/issues/335943)

## Summary

Well-documented visual clipping bug: the comment thread zone widget's right edge, header actions, and reply box render under the minimap in a diff editor, but only there — with the minimap off it renders correctly. Base `ZoneWidget._getWidth()` already subtracts `info.minimap.minimapWidth`, so the defect is likely specific to how the diff editor's modified-side editor reports layout or stacks the minimap/zone-widget DOM, which I can't confirm further without running the app.

## Change summary

In the diff editor (single or multi-file), an expanded `vscode.comments` thread widget on the modified side is partially hidden under the minimap, unlike the same widget in a regular editor.

## Best solution

Comments/diff-editor owners should check whether the modified-side editor's zone widget picks up the correct `EditorLayoutInfo` (including minimap width) in the diff-editor rendering path, since the same widget behaves correctly in a normal editor; likely files are `src/vs/workbench/contrib/comments/browser/commentThreadZoneWidget.ts` and the diff editor's modified-editor/zone-widget wiring under `src/vs/editor/browser/widget/diffEditor`.
