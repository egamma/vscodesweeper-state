# Issue #335943 — Comment thread widget is clipped by the minimap in the diff editor

## Summary

Detailed, plausible report that the comment zone widget isn't respecting the minimap's reserved width in a diff editor, but I couldn't confirm the defect from source alone — the base ZoneWidget already subtracts minimap width in `_getWidth`, so the diff-specific failure path isn't obvious from a code read, and there's no confirming comment or screenshot yet.
