# Issue #186332 — Diff Editor - hidden lines bar

[https://github.com/microsoft/vscode/issues/186332](https://github.com/microsoft/vscode/issues/186332)

## Summary

Keep open: current controls address drag-direction feedback and support incremental revealing, but do not provide the requested configurable bar with explicit directional and reset actions. This team-authored Backlog item has no verified fixing commit or qualifying duplicate.

## Change summary

Offer an optional hidden-lines bar with explicit actions to reveal more lines above, reveal more below, and collapse the unchanged region.

## Best solution

Provide a discoverable, keyboard-operable alternative to the sash-based controls in the diff editor, preserving the existing default interaction. Use the existing theme colors for bar customization rather than adding a separate color setting.

Acceptance includes directional reveal and reset checks in both side-by-side and inline diffs.
- **Trace:**

  > HideUnchangedRegionsFeature constructs CollapsedCodeOverlayWidget for original and modified view zones. The widget's top and bottom handlers already call UnchangedRegion.showMoreAbove and showMoreBelow; bottom-side updates use a scroll anchor. Preserve region calculation, scroll anchoring, existing default interactions, and theme tokens. The unresolved design boundary is whether the optional action presentation replaces the drag affordances or retains them alongside the actions. https://github.com/microsoft/vscode/issues/186333 concerns related action placement but is not a duplicate canonical.
