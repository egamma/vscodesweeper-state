# Issue #297422 — Auto-completions with `all` value don't seem to be attributed

[https://github.com/microsoft/vscode/issues/297422](https://github.com/microsoft/vscode/issues/297422)

## Summary

Team-authored bug about inline completions not being attributed when `git.addAICoAuthor` is set to `all`. The tracking infrastructure exists (AiContributionFeature checks for `category === 'ai'` edits), but the editor-side tracking of accepted completions may not be wiring into that system correctly. A team member confirmed further investigation of editor tracking is needed.

## Change summary

Accepting an inline completion and committing does not add the AI co-author trailer when `git.addAICoAuthor` is set to `all`.

## Best solution

Investigate whether the `DocumentEditSourceTracker` in `src/vs/workbench/contrib/editTelemetry/browser/aiContributionFeature.ts` properly receives tracked ranges for accepted inline completions (category `'ai'`, kind `'completion'`). The `_hasAiContributions` logic at line 85-96 looks correct for `level === 'all'`, so the gap is likely in how inline completion acceptance flows into the annotated-documents pipeline.
