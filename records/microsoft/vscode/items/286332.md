# Issue #286332 — VS Code Feature Request: Extension API: Control Tree Item Expansion During Drag Operations

[https://github.com/microsoft/vscode/issues/286332](https://github.com/microsoft/vscode/issues/286332)

## Summary

Valid, well-scoped API request that passed the community upvote process and was promoted to Backlog by a team member. The internal tree infrastructure already has an `autoExpand` property on `ITreeDragOverReaction`, but it is not exposed to extensions — a genuine API gap remains.

## Change summary

Extension API should let tree views control whether collapsible items auto-expand when hovered during drag-and-drop.

## Best solution

Expose the existing internal `autoExpand` flag from `ITreeDragOverReaction` (in `src/vs/base/browser/ui/tree/tree.ts`) through the extension API — likely via an `autoExpand` return value from `TreeDragAndDropController.handleDrag` or a new `handleDragOver` callback. This requires the Extension API process as confirmed by @alexr00. Issue #324498 (manual collapsibleState handling) is related but distinct.
