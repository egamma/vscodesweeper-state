# Issue #288907 — Do not hide away thinking output if user is reading it

[https://github.com/microsoft/vscode/issues/288907](https://github.com/microsoft/vscode/issues/288907)

## Summary

Team-authored polish request for thinking output UX — the related PR #288908 was closed without merging, and no implementation landed on main. Active team discussion with no consensus yet; stays open for a design decision.

## Change summary

Prevent thinking output from auto-hiding while the user is actively reading it (e.g., mouse hovering over the widget).

## Best solution

The team should decide on a UX pattern (Twitch-style pause-on-hover with a 'scroll to latest' bubble, or a manual 'Hide' button when hovered) and implement it in the chat thinking block renderer. The `collapsed` thinkingStyle setting partially addresses this but was reported as insufficient.
