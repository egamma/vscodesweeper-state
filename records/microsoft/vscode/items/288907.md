# Issue #288907 — Do not hide away thinking output if user is reading it

[https://github.com/microsoft/vscode/issues/288907](https://github.com/microsoft/vscode/issues/288907)

## Summary

Keep open: current thinking display modes still do not preserve content merely because someone is reading it with the pointer over the widget. The proposed implementation was closed without merging, and the discussion leaves the interaction design unresolved.

## Change summary

Prevent thinking content from automatically disappearing while the user is actively reading it.

## Best solution

Agree on a discoverable way to preserve actively read thinking content while retaining quiet automatic progress presentation otherwise. Resolve whether pointer hover should defer collapse or whether an explicit reading interaction should keep the section open.
