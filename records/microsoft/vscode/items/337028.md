## Summary

Same root cause as the older, open https://github.com/microsoft/vscode/issues/285388: the inline New File/Folder input never receives keyboard focus when the VS Code window itself wasn't focused before the right-click. This report's extra detail (input becomes unclickable/vanishes) is the same underlying focus-not-granted defect, just described from a slightly different starting state (app never focused vs. regained focus).

## Change summary

Right-clicking the Explorer and choosing New Folder/File while VS Code's window is unfocused shows the rename input box but it never gains keyboard focus and cannot be clicked into.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/285388 (oldest, same-symptom report) — fixing the input-box focus timing there (likely in the explorer's inline rename/InputBox creation path, ensuring the editor/window is focused before or alongside creating the input) resolves this report too.
