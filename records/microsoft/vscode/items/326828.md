[https://github.com/microsoft/vscode/issues/326828](https://github.com/microsoft/vscode/issues/326828)

## Summary

Keep open for human security review: the desktop task API still exposes extension-supplied ranges to the affected vendored semver parser. The underlying defect is upstream, and the security-sensitive keep-open rule applies regardless of potential fixes.

## Change summary

Prevent excessive semver parsing time from freezing the desktop UI when an extension supplies a long task-version filter.

## Best solution

Adopt the upstream semver security correction in the vendored implementation and verify the reported input through the desktop task API while preserving normal version-filter behavior. A maintainer should assess the security boundary and coordinate resolution here.
