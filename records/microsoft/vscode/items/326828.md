## Summary

Keep open for human security review: the desktop Tasks API still forwards the supplied version range to the affected vendored semver implementation. The report provides sufficient steps to retest, but the duration and UI impact were not verified by executing the payload; security-sensitive reports are protected from closure.

## Change summary

An extension-provided task version range can reportedly freeze the desktop UI during synchronous semver parsing.

## Best solution

Ensure desktop task-version compatibility checks cannot stall the workbench on pathological range input while preserving valid filter behavior. Maintainers should assess the vendored semver exposure and confirm the reported impact through the task API.
