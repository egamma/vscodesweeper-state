# Issue #326828 — Exploitable DOS from extension, CVE-2022-25883

[https://github.com/microsoft/vscode/issues/326828](https://github.com/microsoft/vscode/issues/326828)

## Summary

The vulnerable path remains present on current main, and the report is security-sensitive, so it must remain open for human security review.

## Change summary

Prevent extensions from freezing the desktop renderer by passing an oversized semver range to `tasks.fetchTasks`.

## Best solution

Update or replace the vulnerable inlined semver implementation and validate `TaskFilter.version` before synchronous renderer-side parsing in the desktop task service.

## Evidence

- **extension API path:** `src/vs/workbench/api/common/extHostTask.ts` and `src/vs/workbench/api/browser/mainThreadTask.ts` pass the extension-controlled task filter into the task service.
- **vulnerable sink:** `src/vs/workbench/contrib/tasks/electron-browser/taskService.ts` synchronously calls `semver.satisfies(taskDefinition.version, filter.version)` without a range-length bound.
- **affected dependency:** `src/vs/base/common/semver/cgmanifest.json` identifies the inlined implementation as semver 5.5.0, which is affected by https://github.com/advisories/GHSA-c2qf-rxjj-qqgw.
- **security protection:** The issue describes an extension-triggerable renderer denial of service; security-sensitive issues require human handling and must not be closed by sweeper triage.
