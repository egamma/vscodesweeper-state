# Issue #341333 — Agent Mode: Missing "Show and Focus Terminal" button and inability to interrupt (Ctrl+C) running commands due to isPty: false

[https://github.com/microsoft/vscode/issues/341333](https://github.com/microsoft/vscode/issues/341333)

## Summary

Keep open for terminal-area review: the missing focus action reflects the SDK shell's output-only execution model, not merely a missing toolbar button. Existing PTY overrides and background-shell stop controls provide partial alternatives, but do not fully deliver interactive access to the default executing shell.

## Change summary

Allow users to inspect and interrupt individual agent shell commands without cancelling the entire chat turn.

## Best solution

Provide supported per-command inspection and interruption for SDK-owned shell executions, with an explicit decision about interactive terminal access. Preserve the distinction between genuine PTYs and output-only streams rather than exposing a focus action that has no interactive terminal behind it.
