# Issue #335822 — Manual automations can be disabled even though they remain runnable

[https://github.com/microsoft/vscode/issues/335822](https://github.com/microsoft/vscode/issues/335822)

## Summary

Keep open: manual automations still expose scheduling enablement controls and a misleading Disabled presentation. Manual execution while disabled is intentional; the remaining work is to make the manual-only UI reflect that distinction.

## Change summary

Remove meaningless Enable/Disable actions and disabled presentation from manual-only automations while preserving manual execution.

## Best solution

Manual-only automation cards should consistently present themselves as Manual, without scheduling enablement actions. Preserve Enable/Disable for scheduled automations and preserve Run Now independently of scheduled execution.
