# Issue #322833 — Agent Debug Logs Flow Chart unusable with long chat history

[https://github.com/microsoft/vscode/issues/322833](https://github.com/microsoft/vscode/issues/322833)

## Summary

Valid feature request from a team member: the Agent Debug Logs Flow Chart paginates chronologically from the oldest events, forcing users with long sessions to click 'Show more' many times to reach recent events. No reverse-sort or newest-first option exists on current main.

## Change summary

Add a reverse/newest-first sort option to the Agent Debug Logs Flow Chart so recent events are accessible without repeated pagination through older entries.

## Best solution

Add a sort-order toggle (newest-first / oldest-first) to `ChatDebugFlowChartView` in `src/vs/workbench/contrib/chat/browser/chatDebug/chatDebugFlowChartView.ts`. The pagination already uses `sliceFlowNodes` with a `visibleLimit` starting from the beginning — a reverse mode would slice from the end instead, or reverse the node array before slicing. The same UX improvement could benefit `chatDebugLogsView.ts` and `chatDebugHomeView.ts` which share the same pagination pattern.
