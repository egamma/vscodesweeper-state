# Issue #275451 — Ask mode sometimes thinks it can edit

[https://github.com/microsoft/vscode/issues/275451](https://github.com/microsoft/vscode/issues/275451)

## Summary

The Ask-mode contract remains inconsistent on current main: the legacy experimental Ask path exposes only search tools but gives Codex agent/task-oriented instructions without explicitly prohibiting edits. This team-authored issue should remain the canonical report; later issues describe the same observable confusion but cannot serve as older duplicate targets.

## Change summary

Ask mode can claim that it modified a file, and may show edit-like progress, despite being intended to remain read-only.

## Best solution

Make every Ask-mode path communicate and enforce the same read-only contract: requested modifications may be explained or shown as suggestions, but no edit progress or claims of applied changes should be emitted.
