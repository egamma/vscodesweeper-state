# Issue #328292 — GitHub Copilot `file_search` and `grep_search` support an undocumented workspace-folder-name scope prefix, and reject a wrong one silently

[https://github.com/microsoft/vscode/issues/328292](https://github.com/microsoft/vscode/issues/328292)

## Summary

The discoverability and diagnostic gap remains in current source: both tools support configured workspace-folder names, but their public descriptions document only absolute-path scoping. Keep this open; ordinary relative globs are also valid inputs, so an unfamiliar leading segment cannot universally be treated as an invalid workspace scope.

## Change summary

Make configured workspace-folder scope names discoverable and help callers distinguish likely scope-name mistakes from genuine empty search results.

## Best solution

Expose the relationship between configured workspace-folder names and paths, and document name-prefix scoping consistently for both search tools. Define targeted, non-misleading diagnostics for likely directory-name/configured-name confusion without rejecting legitimate root-relative glob patterns.
