# Issue #328292 — GitHub Copilot `file_search` and `grep_search` support an undocumented workspace-folder-name scope prefix, and reject a wrong one silently

[https://github.com/microsoft/vscode/issues/328292](https://github.com/microsoft/vscode/issues/328292)

## Summary

Current source confirms the contract mismatch and silent failure path: configured workspace names are accepted but undocumented, while an unmatched prefix falls through as an ordinary glob. This remains a valid Copilot core bug.

## Change summary

Make multi-root search scope names discoverable and distinguish invalid workspace-folder prefixes from legitimate searches with no matches.

## Best solution

Document configured-name scoping for both search tools, pair workspace folder names with their paths in prompt context, and add targeted validation or diagnostics for recognizable invalid root prefixes without rejecting valid relative globs.
