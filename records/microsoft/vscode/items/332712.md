# Issue #332712 — Cannot toggle Copilot reasoning sections while running

[https://github.com/microsoft/vscode/issues/332712](https://github.com/microsoft/vscode/issues/332712)

## Summary

Real, reproducible interaction bug in the 'fixedScrolling' thinking display (the current default, though experimental, value of `chat.agent.thinkingStyle`): the header's onDidClick handler in ChatThinkingContentPart (chatThinkingContentPart.ts, lines ~598-609) short-circuits with only a CSS-class tweak while streaming is active and returns without letting the row expand, even though the setting's own description promises 'click header to expand to full height.' A collaborator (justschen) already confirmed on the thread that this whole UX is slated to be replaced next iteration, so this is acknowledged but not yet fixed.

## Change summary

Clicking the reasoning/thinking section header to expand it has no effect while the Copilot response is still streaming (fixedScrolling thinking display mode); it only becomes toggleable after the response finishes.

## Best solution

Either fix the click handler in ChatThinkingContentPart (src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatThinkingContentPart.ts, the `fixedScrollingMode` branch around line 598) so the header toggles expansion during streaming as the setting description promises, or — per the collaborator's comment — let this resolve naturally when the fixedScrolling UX is replaced next iteration; no fix commit exists yet so this should stay open until one lands.
