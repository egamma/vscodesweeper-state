# Issue #333484 — Codicon background jumps when resizing

[https://github.com/microsoft/vscode/issues/333484](https://github.com/microsoft/vscode/issues/333484)

## Summary

Team-authored, reproduced bug in the codicon chat-background renderer: the grid is fully recomputed whenever the container's pixel width/height crosses a cell-size boundary, causing icon positions to jump discontinuously instead of transitioning smoothly.

## Change summary

When resizing the window with a Codicons chat background set, the icon pattern pops/jumps instead of transitioning smoothly as the grid dimensions change.

## Best solution

Rework `renderCodicons` in chatBackgroundRenderer.ts so that resizing doesn't discretely recompute row/column counts and re-hash every cell position — e.g. animate/interpolate between layouts or use a denser, size-independent placement scheme — so the pattern shifts smoothly rather than popping when the grid size changes.
