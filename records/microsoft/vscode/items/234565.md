# Issue #234565 — Git commands do not work if the profile folder name does not contain ASCI characters

## Summary

The reported Windows SSH failure warrants investigation, but current reproduction and the responsible Git/SSH environment are unconfirmed. Request updated reproduction details rather than proposing a fix or duplicate close.

## Change summary

Git pull, push, and clone through VS Code fail to locate SSH credentials when the Windows user-profile directory contains non-ASCII characters, although console commands succeed.

## Best solution

Establish whether VS Code launches the same Git and SSH executables with equivalent home-directory and locale settings as the working console. If the difference causes the failure, correct the built-in Git process environment without changing authentication behavior for other users.
