## Plan brief

- **Likely files:** `extensions/git/src/git.ts`, `extensions/git/src/main.ts`, `extensions/git/src/askpass.ts`
- **Validation:** On Windows with a non-ASCII user-profile directory and working SSH credentials, use the same Git executable and SSH remote to compare console pull/push/clone with VS Code Git actions on the current build. Acceptance: the VS Code operations succeed without a malformed .ssh path or an authentication failure absent from the console; repeat with an ASCII profile as a control.
- **Behavior:**

  > The reporter can perform SSH-based Git operations from a console but cannot perform pull, push, or clone from VS Code under a Windows profile containing non-ASCII characters. VS Code-launched Git should use the correct SSH home directory and existing credentials, matching the successful console behavior. Retest the supplied scenario on current Windows builds with a controlled Git executable and remote, and retain normal behavior for ASCII profile paths.
- **Trace:**

  > Git.spawn in extensions/git/src/git.ts merges the inherited process environment with extension environment providers, forces English UTF-8 locale variables, and invokes the selected Git executable. extensions/git/src/main.ts assembles the provider environment, while Askpass in extensions/git/src/askpass.ts supplies SSH authentication helpers and forces SSH askpass use. The malformed directory message comes from the external Git/SSH process; source inspection does not establish which component converts or resolves the profile path incorrectly. Diagnosis should compare executable selection, SSH implementation, and relevant environment values between the successful console and VS Code invocation before attributing the fault. Older reports https://github.com/microsoft/vscode/issues/24434 and https://github.com/microsoft/vscode/issues/25524 corroborate the symptom historically but are closed without a verified fixing commit. Keep unrelated authentication behavior and global locale policy outside the scope unless reproduction demonstrates their causal role.
