# Issue #187622 — Default log level does not work in vscode.dev

[https://github.com/microsoft/vscode/issues/187622](https://github.com/microsoft/vscode/issues/187622)

## Summary

The bug remains source-reproducible on current main: vscode.dev constructs its active logger from environment options before the persisted default in `argv.json` is loaded, and the later hydration path updates only the displayed default. The issue was also reopened after its previous closure, with no post-reopen fixing commit found.

## Change summary

Persisted default log levels in vscode.dev are displayed after reload but are not applied as the active log level.

## Best solution

On web startup, apply the persisted global and extension default log levels once user data is available, while preserving any explicit active-level overrides. The command should then report the persisted default as active after a reload.
