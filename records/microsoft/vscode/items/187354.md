# Issue #187354 — Git - "Add to .gitignore" feature shows up for `.gitignore` file in Source Control tab

[https://github.com/microsoft/vscode/issues/187354](https://github.com/microsoft/vscode/issues/187354)

## Summary

Still reproduces on main: the 'Add to .gitignore' context menu entry appears for the .gitignore file itself in the Source Control view because neither the `when` clauses in package.json nor the command implementation filter it out. An open community PR (#243245) already addresses this — it should be reviewed and landed.

## Change summary

The 'Add to .gitignore' context menu item shows on the .gitignore file itself in the Source Control tab, allowing users to add '.gitignore' to .gitignore repeatedly.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/243245 which adds a `when`-clause guard and a runtime filter to exclude `.gitignore` from the `git.ignore` command. The fix touches `extensions/git/package.json` (when clauses) and `extensions/git/src/repository.ts` (runtime guard).
