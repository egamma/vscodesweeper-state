# Issue #318552 — Allow pinning/unpinning Copilot Chat sessions from within the session itself

[https://github.com/microsoft/vscode/issues/318552](https://github.com/microsoft/vscode/issues/318552)

## Summary

Keep open: the regular Copilot Chat surface still lacks an active-session pin/unpin affordance. The Agents window has header pinning, but that does not cover the reported workflow, and no verified older canonical issue owns the remaining request.

## Change summary

Allow users to pin or unpin the currently viewed Copilot Chat session without navigating to the session list.

## Best solution

Expose the existing session pin state through an action targeting the currently viewed session in regular Copilot Chat, accessible from its header or the Command Palette. Preserve existing persistence and archived-session restrictions.

- **Fit:** aligned
- **Reason:** Making an existing chat action accessible in its working context reduces navigation friction without introducing a new capability or configuration.
