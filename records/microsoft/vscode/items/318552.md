# Issue #318552 — Allow pinning/unpinning Copilot Chat sessions from within the session itself

[https://github.com/microsoft/vscode/issues/318552](https://github.com/microsoft/vscode/issues/318552)

## Summary

Valid feature request. The Agents window (src/vs/sessions/) already has a pin/unpin toggle in the active session's toolbar and header context menu (TogglePinSessionAction on SessionBarToolbar), but the workbench chat panel/editor (src/vs/workbench/contrib/chat/) only surfaces pin/unpin on the session list (AgentSessionItemToolbar), not from within an active chat session. Whether the reporter is using the workbench chat or the Agents window is unclear — if they're on the Agents window, this may already be addressed.

## Change summary

Add a pin/unpin action accessible from within an active chat session, without requiring navigation to the session list.

## Best solution

If the reporter uses the Agents window, this is already implemented (TogglePinSessionAction on SessionBarToolbar). If they use the workbench chat panel, expose the existing PinAgentSessionAction/UnpinAgentSessionAction on a menu visible from within the active chat editor (e.g. EditorTitle or a chat widget toolbar). Ask the reporter to verify whether this is already covered by the Agents window experience.
