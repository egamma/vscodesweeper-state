# Issue #175388 — Error notification shown in addition to modal error dialog

[https://github.com/microsoft/vscode/issues/175388](https://github.com/microsoft/vscode/issues/175388)

## Summary

Team-authored bug report — keeping open per policy. The duplicate error notification alongside a modal dialog when reconnecting to a remote-SSH host without internet appears to still be an unresolved UX issue; no fix commit was found on main for the VS Code core side of the problem.

## Change summary

When reopening a remote-SSH window without internet, both a modal error dialog and a separate error notification are shown, when only the modal should appear.

## Best solution

The core-side error display path (likely in editor restoration or remote agent connection handling) should suppress the notification when a modal error dialog is already shown for the same remote connection failure. The remote-SSH extension sets `err.handled = true`, but something else in the workbench (possibly editor restoration) surfaces a second, unhandled copy of the error. A fix would need to trace which component shows the notification and ensure it respects the handled flag or deduplicates against the modal.
