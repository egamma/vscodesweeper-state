# Issue #175388 — Error notification shown in addition to modal error dialog

[https://github.com/microsoft/vscode/issues/175388](https://github.com/microsoft/vscode/issues/175388)

## Summary

Team-authored bug still open — the duplicate error UI (modal dialog + notification) when reopening a remote-SSH window without internet is not yet fixed on main. The `isHandled` flag mechanism exists but the error propagation path through `_setResolvedAuthorityError` and the editor-restore flow may bypass the handled check, causing the extra notification.

## Change summary

When reopening a remote-SSH window without internet, both a modal error dialog (from the resolver extension) and an error notification (from VS Code core) are shown, when only one should appear.

## Best solution

Ensure the `isHandled` flag on `RemoteAuthorityResolverError` is preserved through the `_setResolvedAuthorityError` / `ErrorNoTelemetry.fromError` path and that the workbench editor-restore flow (which triggers when reconnecting to a machine with prior session state, per alexdima's comment) also respects it. The fix likely touches `src/vs/workbench/services/extensions/electron-browser/nativeExtensionService.ts` and possibly `src/vs/platform/remote/common/remoteAgentConnection.ts`.
