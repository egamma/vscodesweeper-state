# Issue #238667 — `editor.actions.findWithArgs` doesn't work in notebook

[https://github.com/microsoft/vscode/issues/238667](https://github.com/microsoft/vscode/issues/238667)

## Summary

Still a gap on main: the notebook find contribution hooks into StartFindAction via addImplementation but StartFindWithArgsAction is a standalone EditorAction with no notebook-level override, so it never opens the notebook find widget.

## Change summary

Running `editor.actions.findWithArgs` in a notebook does nothing because the notebook find contribution doesn't intercept it.

## Best solution

Add a notebook-level implementation for StartFindWithArgsAction (similar to the existing StartFindAction.addImplementation in notebookFind.ts) that opens the notebook find widget and applies the provided args (searchString, isRegex, etc.) to the notebook find controller.
