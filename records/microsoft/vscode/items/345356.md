[https://github.com/microsoft/vscode/issues/345356](https://github.com/microsoft/vscode/issues/345356)

## Summary

Keep open: current main confirms that a legacy single-scope GitHub session can leave the Copilot harness without models while suppressing sign-in guidance. The updated report supplies a concrete reproduction and a working scope-upgrade workaround.

## Change summary

Explain and recover from insufficient GitHub authentication scopes before users must send a prompt into an empty Copilot harness.

## Best solution

The Copilot harness should distinguish an existing GitHub account from authentication that satisfies its advertised resource requirements, and offer an actionable authorization upgrade before the first prompt. Preserve required scopes, account preferences, and working BYOK behavior.
