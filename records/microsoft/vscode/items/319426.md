# Issue #319426 — Image attachment thumbnails should be downscaled images, not full res ones

[https://github.com/microsoft/vscode/issues/319426](https://github.com/microsoft/vscode/issues/319426)

## Summary

Keep open: verification of the merged thumbnail optimization failed, and the issue was reopened after the reporter reproduced attachment-dependent typing stalls. The current `verification-found` label also categorically blocks closure while the issue remains in the verification lifecycle.

## Change summary

Large image attachments cause repeated chat-input UI stalls despite attachment thumbnails being downscaled.

## Best solution

Retain downscaled previews, then profile and eliminate the attachment-dependent work reached by the chat input's `_setValue` path so editing the prompt never decodes, transforms, or unnecessarily rerenders large image data.
