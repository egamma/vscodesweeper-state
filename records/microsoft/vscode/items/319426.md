# Issue #319426 — Image attachment thumbnails should be downscaled images, not full res ones

[https://github.com/microsoft/vscode/issues/319426](https://github.com/microsoft/vscode/issues/319426)

## Summary

Mid-verification (`verification-found`) and team-authored — must stay open. PR #319780 (commit 84f87309fd8) landed a downscale fix on June 3, but the reporter confirmed on June 8 that UI stuttering persists when attaching large images, indicating the fix was incomplete. The issue was moved to On Deck as a leftover.

## Change summary

Attaching large images to chat causes UI stuttering because thumbnails use full-resolution data; the initial downscale fix did not fully resolve the performance regression.

## Best solution

Investigate the residual ~108 ms `_setValue` call per keystroke when large image attachments are present (see comment 3's profiling screenshot). The downscale in `chatImageUtils.ts` / `chatAttachmentWidgets.ts` may not be applied in all code paths, or the chat input model's value-setting path may be re-encoding full-res data. A follow-up fix in the chat attachment pipeline is needed.
