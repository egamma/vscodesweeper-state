# Issue #329337 — Make agent-host tool search model allowlist configurable (or auto-trim tools for BYOK models like DeepSeek)

[https://github.com/microsoft/vscode/issues/329337](https://github.com/microsoft/vscode/issues/329337)

## Summary

Well-researched and verified against current source: `agentHostModelSupportsToolSearch` in toolSearchDeferral.ts is a hardcoded allowlist (GPT-5.4/5.5/5.6, Claude 4.5+), so BYOK models like DeepSeek never get tool deferral and hit provider-side function-count limits (502). This is a real, actionable gap best routed to the agent-host owners rather than closed.

## Change summary

BYOK/third-party models are excluded from the agent host's tool-search allowlist, so with >128 enabled tools the model provider rejects the request (502), and the reporter wants the allowlist made configurable or auto-trimmed for BYOK models.

## Best solution

An agent-host maintainer should decide the direction (configurable allowlist, default-enable tool search for BYOK, or advertising a per-model tool-count limit via `IByokLmModelInfo` for the SDK to trim/group tools) — the reporter's option 3 looks like the most general fix since it needs no per-model allowlist maintenance.
