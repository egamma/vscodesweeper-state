# Issue #299566 — PreCompact does not trigger off of `/compact`

[https://github.com/microsoft/vscode/issues/299566](https://github.com/microsoft/vscode/issues/299566)

## Summary

Confirmed from source: the `/compact` slash command handler in agentIntent.ts bypasses the hook system entirely — it never fires `PreCompact`. The `PreCompactHookInput.trigger` type is also restricted to `'auto'`, with no `'manual'` variant. This is a real gap, still present on main.

## Change summary

The `PreCompact` hook does not fire when the user triggers compaction manually via `/compact` or the compact button — only on auto-compaction.

## Best solution

Wire the `PreCompact` hook into the `handleSummarizeCommand` method in `extensions/copilot/src/extension/intents/node/agentIntent.ts` (and the compact button path if separate), adding a `'manual'` trigger variant to `PreCompactHookInput` in `chatHookService.ts`. The hook should fire before the summarization begins, consistent with how it fires on auto-compaction.
