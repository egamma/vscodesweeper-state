# Issue #174338 — Diff / Compare does not honor ignore trailing/leading whitespace settings

[https://github.com/microsoft/vscode/issues/174338](https://github.com/microsoft/vscode/issues/174338)

## Summary

The whitespace toggle now reads and writes language-specific settings, but its checked state still reads the global setting. Keep this open for the remaining mismatch confirmed in the discussion and current source.

## Change summary

Make the diff editor's whitespace toggle accurately reflect the effective leading/trailing whitespace comparison mode.

## Best solution

The diff title action should reflect the active comparison's effective whitespace setting, including language overrides, and stay synchronized after toggling or switching comparisons. Preserve the existing language-sensitive defaults and resource-aware setting updates.
