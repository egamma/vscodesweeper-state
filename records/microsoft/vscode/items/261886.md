# Issue #261886 — Git: Apply Stash picker, worktree is shown when closed

[https://github.com/microsoft/vscode/issues/261886](https://github.com/microsoft/vscode/issues/261886)

## Summary

Confirmed on current main: none of the stash commands pass a `repositoryFilter` to `pickRepository`, so worktree repositories appear in the picker even though worktrees share the same stash list as their parent. The fix is small and localized.

## Change summary

The 'Git: Apply Stash' (and other stash commands) repository picker shows worktree repositories alongside the parent, even though worktrees share the same git stash list.

## Best solution

Add `repositoryFilter: ['repository', 'submodule']` to all stash `@command` decorators in `extensions/git/src/commands.ts` (lines ~4542–4692), mirroring what `git.createWorktree` and `git.deleteWorktree` already do. This excludes worktrees from the picker since their stash list is identical to the parent repository's.
