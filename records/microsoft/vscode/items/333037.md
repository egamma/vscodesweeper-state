- **Behavior:**

  > For a repository with no prior clone history, Git: Clone must let the user choose a destination before cloning. The report says both URL entry and GitHub selection instead offer to open a repository without creating one. Acceptance requires a destination picker, an actual clone into the selected parent, and an opening prompt only after successful cloning. Cancelling destination selection must stop the operation without an opening prompt.
- **Trace:**

  > The git.clone command in extensions/git/src/commands.ts delegates to CloneManager.clone in extensions/git/src/cloneManager.ts. Read-only inspection did not explain the reported uncached bypass, so diagnosis starts with reproducing on Windows and establishing which runtime branch executes.
