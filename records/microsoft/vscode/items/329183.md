# Issue #329183 — GitHub Copilot chat web request confirmation dialog does not correctly linkify URLs with spaces

[https://github.com/microsoft/vscode/issues/329183](https://github.com/microsoft/vscode/issues/329183)

## Summary

The defect remains source-reproducible on current main: the fetch confirmation passes an unencoded bare URL to the Markdown renderer, so whitespace terminates the clickable portion. This is a bounded chat confirmation bug with clear expected behavior.

## Change summary

Make URLs containing spaces fully clickable in the web-fetch confirmation while preserving the complete URL as visible text.

## Best solution

Render each requested URL as an explicit Markdown link whose visible label contains the complete URL and whose destination is safely percent-encoded, without changing URL approval or fetch semantics.
