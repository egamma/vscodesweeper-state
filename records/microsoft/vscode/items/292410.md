# Issue #292410 — Support `.agents` directory for skills, custom agents, and AI customization files

[https://github.com/microsoft/vscode/issues/292410](https://github.com/microsoft/vscode/issues/292410)

## Summary

Keep this team-authored umbrella open: workspace and home skill locations are supported, but unified default discovery for other customization types remains incomplete. The newer scoped proposal does not supersede this broader tracking issue, which has 25 community upvotes.

## Change summary

Support .agents as a shared workspace and user-level customization root, including nested skills and additional customization primitives.

## Best solution

Retain this issue as the umbrella for consistent .agents discovery and creation defaults, with explicit decisions about supported primitives and file conventions. Coordinate the instructions, agents, and hooks portion with https://github.com/microsoft/vscode/issues/326789 while preserving existing customization locations.

- **Existing skill support:** src/vs/workbench/contrib/chat/common/promptSyntax/config/promptFileLocations.ts defines .agents/skills and ~/.agents/skills in DEFAULT_SKILL_SOURCE_FOLDERS. https://github.com/microsoft/vscode/pull/292414 merged on 2026-02-03; https://github.com/microsoft/vscode/issues/292427 explicitly describes itself as a skills-only child of this issue.
- **Remaining default-discovery gap:** In promptFileLocations.ts, DEFAULT_INSTRUCTIONS_SOURCE_FOLDERS, DEFAULT_AGENT_SOURCE_FOLDERS, DEFAULT_PROMPT_SOURCE_FOLDERS, and DEFAULT_HOOK_FILE_PATHS do not include corresponding .agents locations. Existing skill support therefore does not satisfy the unified-root request.
- **Existing settings are partial workarounds:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts registers chat.instructionsFilesLocations, chat.agentFilesLocations, chat.agentSkillsLocations, and chat.hookFilesLocations. These permit configurable locations, but do not establish the requested shared defaults; instructions and agents retain their documented filename conventions, and hook-location configuration is explicitly limited to the Local agent harness.
- **Nested skill discovery remains incomplete in this path:** src/vs/workbench/contrib/chat/common/promptSyntax/utils/promptFilesLocator.ts: findAgentSkillsInFolder checks SKILL.md directly inside each immediate child directory without descending further. Despite its recursive-traversal comment and the reporter discussion describing recursion as available, this source path does not establish arbitrary nested discovery.
- **Discussion adds distinct requirements:** https://github.com/microsoft/vscode/issues/292410#issuecomment-4346286303 requests canonical ~/.agents/instructions files without Copilot-specific wrappers and discusses optional plain .md filenames and typed subdirectories. Configuring another search folder alone does not satisfy these naming and organization requirements.
