# Issue #307895 — Keybinding `cmd+^` won't work with French keyboard layout on macOS because of dead key

[https://github.com/microsoft/vscode/issues/307895](https://github.com/microsoft/vscode/issues/307895)

## Summary

This is an upstream Chromium/Electron issue on macOS: when Cmd is held with a dead key (like ^ on French layout), the keydown event for the non-modifier key is never delivered to VS Code's dispatcher — the OS/Chromium dead key composition swallows it. Ctrl and Alt work because Chromium passes the keydown through in those cases. VS Code's soft dispatch correctly identifies the binding but never gets the actual keydown to invoke the command.

## Change summary

Cmd+^ keybinding on French macOS keyboard doesn't fire because macOS/Chromium swallows the dead key's keydown event when Cmd is held.

## Best solution

Classify as upstream (Chromium/Electron dead key handling on macOS with Cmd modifier) and link to https://github.com/nicolo-ribaudo/tc39-proposal-structs if a Chromium bug is found. A workaround in VS Code's keybinding dispatch layer (intercepting the soft dispatch result when the actual keydown is missing) might be possible but would require careful design to avoid breaking IME/composition flows. The reporter could use a different key or modifier as a workaround.
