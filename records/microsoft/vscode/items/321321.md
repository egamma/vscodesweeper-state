# Issue #321321 — Toggle commrnting keyboard shortcut conflict with Agent window

[https://github.com/microsoft/vscode/issues/321321](https://github.com/microsoft/vscode/issues/321321)

## Summary

Confirmed conflict still present on main: the Agents window's OpenVSCodeWindowAction binds Ctrl+Shift+A globally without a when-clause, stealing the Toggle Block Comment shortcut on Linux. Team members have acknowledged and agreed on the fix approach (add editor-focus guard) but the fix has not landed yet.

## Change summary

Ctrl+Shift+A opens the Agents window instead of toggling block comments when editor has focus, breaking a long-standing keyboard shortcut.

## Best solution

Add a `when` clause to the `OpenVSCodeWindowAction` keybinding in `src/vs/sessions/electron-browser/actions/vscodeActions.ts` so it only fires when focus is NOT in the editor area, letting the editor's Toggle Block Comment command take precedence as sandy081 and benibenj agreed.
