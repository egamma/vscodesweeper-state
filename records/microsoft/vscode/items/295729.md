# Issue #295729 — Copilot extension fails to log into Github

[https://github.com/microsoft/vscode/issues/295729](https://github.com/microsoft/vscode/issues/295729)

## Summary

Keep open: the reporter supplied a concrete browser sign-in flow and logs showing that Copilot never obtains a session, despite working account login. Session selection and token handling have changed since the report, but the supplied steps suffice to retest; neither a matching fix nor a same-root-cause canonical was established.

## Change summary

Copilot Chat remains signed out after the user completes GitHub authorization in the browser, while VS Code account login works.

## Best solution

Restore the transition from completed GitHub authorization to an authenticated Copilot Chat session. Diagnose session availability and authentication-change handling before treating missing permissive permissions as the cause of the failed basic login.
