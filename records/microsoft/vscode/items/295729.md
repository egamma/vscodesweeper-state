# Issue #295729 — Copilot extension fails to log into Github

[https://github.com/microsoft/vscode/issues/295729](https://github.com/microsoft/vscode/issues/295729)

## Summary

Multiple users confirmed that Copilot Chat remains unusable after completing GitHub authentication. The logs establish a recurring authentication failure, but the accompanying permissive-session error appears secondary and the root cause remains unresolved.

## Change summary

Copilot Chat returns to a signed-out state after the user completes GitHub authentication in the browser.

## Best solution

Treat this older report as the canonical authentication-failure cluster and investigate why a completed GitHub sign-in does not produce a usable Copilot token. Diagnosis should distinguish the actual `GitHubLoginFailed` path from optional permissive-session failures.
