# Issue #241881 — Support checkboxes for boolean object values

[https://github.com/microsoft/vscode/issues/241881](https://github.com/microsoft/vscode/issues/241881)

## Summary

The requested UI improvement is still missing: editable boolean values in dynamic-key objects explicitly render as true/false dropdowns. Existing object checkboxes cover fixed-property schemas, and the older related reports concern different observable problems.

## Change summary

Use checkboxes instead of true/false dropdowns when editing boolean values in object settings.

## Best solution

Give boolean values in the general object-setting editor a checkbox control while preserving editable keys, add/remove operations, and existing confirmation/cancellation behavior. Keep string and enum values, and the separate fixed-property checkbox renderer, unchanged.

- **Reason:** Using the established boolean control consistently across Settings improves uniformity without introducing another setting or feature surface.

The requested checkbox is therefore not supplied by the current general object editor.
- **Existing capability and its boundary:** src/vs/workbench/services/preferences/common/preferencesModels.ts:690–695 sets allKeysAreBoolean only for objects with declared properties and no additionalProperties. settingsTreeModels.ts selects BooleanObject for that flag; ObjectSettingCheckboxWidget in settingsWidgets.ts renders checkboxes but deliberately disables adding entries.
