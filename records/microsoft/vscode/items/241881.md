# Issue #241881 — Support checkboxes for boolean object values

[https://github.com/microsoft/vscode/issues/241881](https://github.com/microsoft/vscode/issues/241881)

## Summary

Still reproduces on main: the `allKeysAreBoolean` check in `preferencesModels.ts` only fires for settings with predefined `properties` (and `!additionalProperties`), so object settings with `additionalProperties: { type: "boolean" }` fall through to the dropdown-based Object renderer instead of the checkbox-based BoolObject renderer.

## Change summary

Object settings with dynamic boolean values (via `additionalProperties: { type: "boolean" }`) render a true/false dropdown instead of a simple checkbox in the settings editor.

## Best solution

Extend the `allKeysAreBoolean` detection in `src/vs/workbench/services/preferences/common/preferencesModels.ts` (around line 707) to also recognize objects where `additionalProperties` is `{ type: "boolean" }` (no predefined `properties` required). Then ensure the `SettingBoolObjectRenderer` and `ObjectSettingCheckboxWidget` handle the dynamic-key case.
