# Issue #182672 — Curly brace matching with Perl split command

[https://github.com/microsoft/vscode/issues/182672](https://github.com/microsoft/vscode/issues/182672)

## Summary

The bundled Perl grammar still fails to recognize a bare regex immediately after split, leaving its braces visible to bracket matching. Keep this open as an upstream grammar issue; no applicable fix or verified duplicate canonical was found.

## Change summary

Recognize the regex in `my @objInst = split /}}/, $line;` so its literal braces do not interfere with code bracket matching.

## Best solution

Correct bare-regex recognition after split in textmate/perl.tmbundle, then adopt the corrected grammar in VS Code. Preserve the editor's existing behavior of ignoring brackets inside correctly classified strings and regexes.

## Evidence

The reporter's `split /}}/` does not satisfy that lookbehind, so the regex does not receive the intended string.regexp.find.perl scope.
