# Issue #208406 — Option for sticky scroll to prioritize inner blocks

[https://github.com/microsoft/vscode/issues/208406](https://github.com/microsoft/vscode/issues/208406)

## Summary

Keep open: current sticky-scroll settings do not provide inner-scope prioritization, and an open PR explicitly targets this request. A maintainer deliberately accepted it into Backlog after the community bot closed it.

## Change summary

Add an option for sticky scroll to retain the nearest enclosing scopes instead of the outermost scopes when its line limit is exceeded.

## Best solution

Review and resolve the implementation proposed in https://github.com/microsoft/vscode/pull/273312, preserving existing outer-scope behavior by default while offering inner-scope prioritization. Keep this issue open until a suitable implementation lands.
