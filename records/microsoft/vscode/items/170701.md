# Issue #170701 — Menus: improve rendering of (1) badge

[https://github.com/microsoft/vscode/issues/170701](https://github.com/microsoft/vscode/issues/170701)

## Summary

The actionable count is still rendered as a plain `(1)` suffix on current main, while native menu APIs provide no trailing-adornment or alignment field. Keep this open as an upstream-dependent menu-polish gap; the thread has already rejected automatic preselection and retained improved count rendering as the goal.

## Change summary

Render activity-bar notification counts as a distinct, consistently aligned menu adornment instead of appending `(1)` to the item label.

## Best solution

Introduce a semantic trailing badge or count adornment for custom menus, and adopt equivalent Electron support when native menus expose a right-aligned accessory. Preserve ordinary initial menu focus and expose the count through the menu item's accessible label.
