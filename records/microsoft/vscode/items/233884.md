# Issue #233884 — Vscode doesn't respect the login shell on MacOS

[https://github.com/microsoft/vscode/issues/233884](https://github.com/microsoft/vscode/issues/233884)

## Summary

Current source still selects the first detected profile with the same executable name, even when its absolute path differs from the user's login shell. Keep this open: the two xonsh installations expose a concrete terminal-profile resolution defect.

## Change summary

The integrated terminal launches a different xonsh installation instead of the configured system login-shell executable.

## Best solution

When no terminal default profile is explicitly configured, preserve the identity of the system-shell executable rather than substituting another installation with the same name. Keep explicit profile selection and existing profile options working as before.
