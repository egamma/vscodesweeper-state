# Issue #105935 — Interactive playground eats arrow keys

[https://github.com/microsoft/vscode/issues/105935](https://github.com/microsoft/vscode/issues/105935)

## Summary

The trace establishes that playground commands intercepted arrows in Peek References, but the focus transition that caused this remains unknown. Request that missing reproduction detail; current source still contains the implicated bindings, and no verified fix or canonical duplicate was found.

## Change summary

Playground arrow-key bindings unexpectedly intercept navigation in a TypeScript Peek References tree.

## Best solution

Playground navigation should apply only while its own surface has focus, leaving Peek References tree navigation unaffected. Establish the triggering focus transition before changing the walkthrough focus lifecycle or keybinding conditions.
