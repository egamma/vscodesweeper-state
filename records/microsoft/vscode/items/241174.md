# Issue #241174 — Ctrl+Shift+C does not open external terminal on Linux snap

[https://github.com/microsoft/vscode/issues/241174](https://github.com/microsoft/vscode/issues/241174)

## Summary

Keep open pending the existing fix candidate: the reporter confirmed the failure on Snap 1.109.5, and an open PR explicitly targets this issue. Current source still passes Snap's GTK_PATH to the external terminal.

## Change summary

Opening an external GNOME terminal from the Linux Snap installation fails because the child inherits Snap-specific GTK library paths.

## Best solution

Review and land the environment-restoration changes in https://github.com/microsoft/vscode/pull/298237, then verify Ctrl+Shift+C on an affected native Ubuntu Snap installation rather than relying on WSL alone.
