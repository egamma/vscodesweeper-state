# Issue #347102 — moving a side chat back to the agents window does not give it focus

## Change summary

Returning a side chat from its own window to the Agents window should focus the returned chat.

## Best solution

Ensure Move to Main Window transfers keyboard focus to the returned active chat, including when its parent session is already active. Preserve background placement of the window's other chats and editors.
