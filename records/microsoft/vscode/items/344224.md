# Issue #344224 — Custom agents: all-tools wildcard (*) has an empty hover

[https://github.com/microsoft/vscode/issues/344224](https://github.com/microsoft/vscode/issues/344224)

## Summary

The missing wildcard explanation remains in current source: the tool catalogue registers `*` without a description, so its hover falls back to the wildcard itself. Keep this team-authored report open; no explicit fix or verified canonical duplicate was found.

## Change summary

Show useful all-tools explanatory hover text for both `tools: [*]` and `tools: ["*"]` in GitHub Copilot custom agents.

## Best solution

Make the supported wildcard explain that it enables all available tools, consistently with static tool aliases in the prompt language providers. Preserve wildcard acceptance and existing tool availability semantics.
