# Issue #324188 — Remote SSH:  oom Issue in versions newer than 1.120.0 when connected via ssh

[https://github.com/microsoft/vscode/issues/324188](https://github.com/microsoft/vscode/issues/324188)

## Summary

Multiple independent reporters describe the same version-bisected regression (works at 1.120.0, broken above it) causing runaway CPU/memory on the remote host over Remote-SSH, with one reporter finding disabling AI features avoids it — this needs an owner to bisect further, so routing to the remote area rather than closing.

## Change summary

Remote-SSH sessions on versions newer than 1.120.0 show a remote-side 'MainThread' process pinning ~100% CPU and growing memory until the connection OOMs, a regression not present at 1.120.0.
