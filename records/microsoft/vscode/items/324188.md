# Issue #324188 — Remote SSH:  oom Issue in versions newer than 1.120.0 when connected via ssh

[https://github.com/microsoft/vscode/issues/324188](https://github.com/microsoft/vscode/issues/324188)

## Summary

Credible regression report with multiple confirmations: VS Code server processes (MainThread) consume excessive CPU/memory after connecting via Remote SSH on versions newer than 1.120.0. The high CPU is in the VS Code server process itself, so this may be a core server regression rather than purely a Remote SSH extension issue. Needs routing to the remote area for investigation.

## Change summary

VS Code server processes on the remote host consume excessive CPU (~100%) and memory after SSH connection, eventually causing OOM, in all versions after 1.120.0.

## Best solution

The remote/server team should bisect the regression between 1.120.0 and the next release to identify the offending change. The reporter should be asked for a CPU profile from the remote server process and the list of installed extensions to narrow the root cause. If the regression is in the Remote SSH extension itself rather than the core server, the issue should be moved to microsoft/vscode-remote-release.
