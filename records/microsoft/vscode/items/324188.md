# Issue #324188 — Remote SSH:  oom Issue in versions newer than 1.120.0 when connected via ssh

[https://github.com/microsoft/vscode/issues/324188](https://github.com/microsoft/vscode/issues/324188)

## Summary

Multiple independent reporters confirm a genuine regression: Remote-SSH sessions on 1.120.0 are stable, but every later release shows a runaway 'MainThread' process pegging CPU on the remote host until it OOMs/gets SIGKILLed. One reporter's workaround (disabling AI/Copilot features before upgrading) points at the agent-host/Copilot rollout as a likely contributor, but no maintainer or fix commit has confirmed the exact cause yet, so this needs routing rather than a close.
