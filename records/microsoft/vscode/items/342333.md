# Issue #342333 — terrible mcp ui

[https://github.com/microsoft/vscode/issues/342333](https://github.com/microsoft/vscode/issues/342333)

## Summary

Keep open as usability feedback: existing MCP controls and edit-review actions address individual tasks, but do not establish that the broader discoverability, migration-explanation, and workflow-stability concerns are resolved.

## Change summary

Make AI edit-review workflows more stable and MCP startup, configuration scopes, and migration requirements easier to understand.

## Best solution

Have the MCP and chat UX owners assess the first-use and upgrade experience together, making server lifecycle, configuration location, and migration consequences understandable while keeping edit-review actions discoverable. Use the existing controls rather than assuming that adding more settings addresses the reported confusion.
