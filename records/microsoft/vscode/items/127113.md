# Issue #127113 — Command to change the state of a markdown cell

[https://github.com/microsoft/vscode/issues/127113](https://github.com/microsoft/vscode/issues/127113)

## Summary

Still a valid gap: the notebook cell edit state (editing vs preview for markdown cells) is internal only — not exposed via the extension API — so Live Share (and other extensions) cannot detect or command it. Keeping open as a backlog feature request.

## Change summary

Expose notebook markdown cell edit/preview state transitions to extensions so Live Share can sync them across participants.

## Best solution

Add an extension API surface (event + command or property) that lets extensions observe and set the edit/preview state of markdown cells. The internal machinery exists (`CellEditState`, `notebook.cell.edit`, `notebook.cell.quitEdit` in `src/vs/workbench/contrib/notebook/browser/controller/editActions.ts`), but nothing is exposed in `vscode.d.ts`. Whether this belongs in a proposed API or a Live Share–specific hook is a team decision.
