# Issue #276131 — Auto switch model when model provider has an incident

[https://github.com/microsoft/vscode/issues/276131](https://github.com/microsoft/vscode/issues/276131)

## Summary

Keep open: this is a protected plan item for incident-aware model failover, and current main only switches to Auto for a specific user rate-limit response. The older language-model-unavailable meta issue collects broader availability failures but does not own this same requested behavior.

## Change summary

Automatically retry with Auto or another available model when the selected model provider has a known service incident.

## Best solution

Define which service signal establishes an active provider incident and whether failover should be automatic, prompted, or limited to requests already using Auto. The eventual implementation should preserve the existing rate-limit flow while adding incident-specific retry behavior in the Copilot request path.
