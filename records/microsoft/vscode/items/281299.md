# Issue #281299 — `Authorize Visual Studio Code` doesn't distinguish VS Code from VS Code insider

[https://github.com/microsoft/vscode/issues/281299](https://github.com/microsoft/vscode/issues/281299)

## Summary

Keep open: distinguishing Insiders on GitHub's authorization screen remains an accepted authentication improvement. A maintainer identified a possible separate OAuth identity, but GitHub Enterprise Server compatibility needs agreement before implementation.

## Change summary

Distinguish VS Code Insiders from stable VS Code in the name and logo shown on GitHub's authorization screen.

## Best solution

Provide channel-appropriate authorization branding without breaking existing GitHub or GitHub Enterprise Server sign-in. First settle the OAuth application identity and compatibility requirements with GitHub; changing a local extension icon cannot address this screen.
