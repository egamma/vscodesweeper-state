## Summary

Valid feature request — the `autoApproveWorkspaceNpmScripts` setting currently only covers npm/yarn/pnpm run commands; `npx` is not handled by `NpmScriptAutoApprover` on current main. Worth routing to the terminal-agent-tools area.

## Change summary

Extend the auto-approve workspace npm scripts setting to also cover `npx` commands when the target binary exists in `node_modules/.bin` or as a package.json script.

## Best solution

Add `npx` pattern(s) to `npmRunPatterns` in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/commandLineAnalyzer/autoApprove/npmScriptAutoApprover.ts`, matching `npx <package>` against workspace `node_modules/.bin` entries or package.json scripts. Update the setting description to mention `npx`. Related: https://github.com/microsoft/vscode/issues/325635 tracks the similar `npm exec` case.
