# Issue #315237 — chat.tools.terminal.autoApproveWorkspaceNpmScripts allow npx as well

[https://github.com/microsoft/vscode/issues/315237](https://github.com/microsoft/vscode/issues/315237)

## Summary

The workspace-aware approval setting still covers package scripts, not npx binaries. Keep this request open and route it to the terminal area for a decision on extending automatic approval to locally installed tools.

## Change summary

Automatically approve npx commands when the invoked tool is declared in the workspace package.json and installed in node_modules/.bin.

## Best solution

Define whether workspace-aware approval should include locally installed dependency binaries, distinguishing npx execution from package.json scripts. Any accepted behavior should preserve explicit denial rules and avoid automatically approving commands that resolve to downloaded packages.
