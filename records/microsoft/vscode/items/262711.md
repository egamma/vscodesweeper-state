# Issue #262711 — MCP view leaks

[https://github.com/microsoft/vscode/issues/262711](https://github.com/microsoft/vscode/issues/262711)

## Summary

The leak is still present on current main — `DefaultBrowseMcpServersView.show()` can lose an in-flight `DisposableStore` from `query()` when re-entered during the async gap. An open PR (#266174) exists but has not merged; keeping open.

## Change summary

MCP servers view leaks `DisposableStore` instances when `show()` is called concurrently during rapid AI-state toggling.

## Best solution

Land a fix that serializes or cancels overlapping `query()` calls in `DefaultBrowseMcpServersView.show()` (in `src/vs/workbench/contrib/mcp/browser/mcpServersView.ts`). The open PR https://github.com/microsoft/vscode/pull/266174 attempts this but needs human review — it was filed by the coding agent and has not been reviewed or merged.
