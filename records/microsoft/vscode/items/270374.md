# Issue #270374 — Linkified path in Test Results panel converts to windows path in WSL

[https://github.com/microsoft/vscode/issues/270374](https://github.com/microsoft/vscode/issues/270374)

## Summary

Keep open: the Test Results detached terminal still omits the remote authority and operating system, causing link handling to use Windows-local assumptions in a WSL window. The source supports a testing-specific defect rather than the local-window limitation suggested in the discussion.

## Change summary

Paths clicked in Test Results in a WSL workspace should resolve as remote Linux paths instead of becoming Windows-style quick-access queries.

## Best solution

Make Test Results link handling honor the workspace's remote filesystem and operating system, consistently with the integrated terminal. Preserve local-window behavior and keep the separate local-Windows/WSL-terminal limitation outside this change.
