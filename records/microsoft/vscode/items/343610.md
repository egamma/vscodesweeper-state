# Issue #343610 — Invalid css warning top: NaNpx when opening marker navigation widget

[https://github.com/microsoft/vscode/issues/343610](https://github.com/microsoft/vscode/issues/343610)

## Summary

The invalid CSS assignment is reproducible from current source: constructing the marker widget lays out its sash before the widget has a height, producing NaNpx. Keep this open as a bounded editor-widget initialization bug; the report already supplies sufficient reproduction steps.

## Change summary

Opening marker navigation in the Monaco playground generates an invalid top: NaNpx CSS warning in Firefox.

## Best solution

Ensure zone-widget sash positioning remains finite before the first layout, while preserving its established position after the widget receives a height. Address this in the shared editor zone-widget implementation rather than treating Firefox's warning as an upstream defect.
