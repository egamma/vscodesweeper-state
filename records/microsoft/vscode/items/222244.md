# Issue #222244 — Search in markdown preview panel not working in current main branch local build

[https://github.com/microsoft/vscode/issues/222244](https://github.com/microsoft/vscode/issues/222244)

## Summary

Keep open: desktop OSS builds still depend on an Electron frame-search API unavailable in stock Electron. The current source retains that dependency, and the related merged IME fix explicitly confirms this separate limitation.

## Change summary

Make Markdown preview search work in locally built desktop VS Code using stock Electron.

## Best solution

Upstream the frame-scoped search capability into Electron and adopt it in VS Code so OSS desktop builds can search webview contents without the private Electron patch.
