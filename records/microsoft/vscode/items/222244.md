# Issue #222244 — Search in markdown preview panel not working in current main branch local build

[https://github.com/microsoft/vscode/issues/222244](https://github.com/microsoft/vscode/issues/222244)

## Summary

Still unfixed on main: webview find-in-frame depends on a custom Electron API (`WebFrameMain.findInFrame`) that only exists in Microsoft's proprietary Electron build, not in standard OSS Electron (currently v42.5.0). The upstream Electron PR (electron/electron#28274) remains unmerged.

## Change summary

Search (Ctrl+F) in webview-based panels (e.g. Markdown preview) does not work in OSS/local builds because the required `findInFrame` API is missing from standard Electron.

## Best solution

Upstream the `findInFrame` implementation to Electron proper (electron/electron#28274) or implement an alternative find mechanism that works without the custom API (e.g. IPC-based DOM search in the webview frame). Until then, this only works in official VS Code builds that ship the patched Electron.
