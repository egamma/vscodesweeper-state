# Issue #324412 — Sticky scroll indentationModel doesn't work if no line is present after the indented block

[https://github.com/microsoft/vscode/issues/324412](https://github.com/microsoft/vscode/issues/324412)

## Summary

The EOF failure is confirmed in current source: folding-backed sticky ranges extend one line beyond the block, and candidate validation rejects that endpoint when the block ends at EOF. Keep this open in editor-sticky-scroll; the supplied two-line example is sufficient and the defect is bounded.

## Change summary

Sticky Scroll should retain an indented block's header when the block reaches EOF without an additional line.

## Best solution

Make folding-backed Sticky Scroll handle blocks ending at EOF consistently with otherwise identical blocks followed by another line, preserving existing scope boundaries and hidden-region filtering.
