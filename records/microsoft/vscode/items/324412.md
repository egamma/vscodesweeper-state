# Issue #324412 — Sticky scroll indentationModel doesn't work if no line is present after the indented block

[https://github.com/microsoft/vscode/issues/324412](https://github.com/microsoft/vscode/issues/324412)

## Summary

Confirmed on current main: indentation folding produces the EOF range, but Sticky Scroll rejects it because its exclusive end line is one beyond the model. This is a localized editor bug that should remain open for a fix.

## Change summary

Sticky Scroll's indentation model omits an indented block when that block reaches the end of the file.

## Best solution

Allow Sticky Scroll folding ranges whose exclusive end is `lineCount + 1`, while retaining validation that their actual document lines are valid.
