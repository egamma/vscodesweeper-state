# Issue #298198 — Show badge on Other Models once there is a new model added

[https://github.com/microsoft/vscode/issues/298198](https://github.com/microsoft/vscode/issues/298198)

## Summary

Verified duplicate: the older open model-awareness issue tracks the same user-visible badges and broader discoverability flow, including dismissing the affordance after it is seen.

## Change summary

Show a badge on Other Models when a new non-BYOK model arrives, mark the new model inside the picker, and dismiss the badges after they are seen.

## Best solution

Consolidate this redesigned-picker requirement on https://github.com/microsoft/vscode/issues/277097, preserving the specific constraint that Other Models should flag new Copilot models but exclude high-volume BYOK providers.
