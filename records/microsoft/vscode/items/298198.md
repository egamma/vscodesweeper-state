# Issue #298198 — Show badge on Other Models once there is a new model added

[https://github.com/microsoft/vscode/issues/298198](https://github.com/microsoft/vscode/issues/298198)

## Summary

Still a valid feature request — the model picker has badge infrastructure (info/warning) but no 'new model' badge on the Other Models section or individual models. An earlier tip-based approach (`tip.tryNewModel`) was implemented and then removed; the badge-based discoverability requested here has not been implemented.

## Change summary

Show a badge on the "Other Models" section and on individual newly added models in the model picker to improve discoverability of new models.

## Best solution

Extend the existing model picker badge infrastructure in `chatModelPicker.ts` to track newly added (non-BYOK) model IDs and render a 'new' badge on the Other Models section header and on matching model items, clearing it once the user views the section. The earlier `getNewModelIds`/`hasNewModels` approach in the tip system was removed — a badge-based approach in the picker itself is the right lane.
