# Issue #27157 — PreLaunchTask: support passing parameters from configuration to preLaunchTask

[https://github.com/microsoft/vscode/issues/27157](https://github.com/microsoft/vscode/issues/27157)

## Summary

Well-supported, long-standing feature request (94 upvotes) from a team member. No implementation exists on current main — preLaunchTask still resolves by name only with no parameter-passing mechanism. Stays open as the canonical tracker.

## Change summary

Allow passing parameters (e.g. port, build config, IP address) from a launch.json configuration to its preLaunchTask, avoiding duplicate input prompts.

## Best solution

Implement a mechanism in the debug task runner (src/vs/workbench/contrib/debug/browser/debugTaskRunner.ts) and the task variable resolution pipeline to forward launch-configuration values — or at minimum share resolved `${input:…}` values — to the preLaunchTask. The community discussion suggests a `preLaunchTaskInputs` map or cross-file input deduplication as viable designs. Related closed issues #95158 and #201785 both redirect here, confirming this is the canonical tracker.
