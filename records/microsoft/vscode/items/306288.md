# Issue #306288 — Prompted to reload window after enabling troubleshooting settings

[https://github.com/microsoft/vscode/issues/306288](https://github.com/microsoft/vscode/issues/306288)

## Summary

The reload requirement still exists, and current logging initialization explains why removing the message alone would be insufficient. Keep this team-authored, On Deck improvement open; no verified fix or same-symptom canonical was found.

## Change summary

Enable troubleshooting logging without requiring a window reload.

## Best solution

Make local troubleshooting logging respond to enablement changes during the running session, then align the troubleshooting message and setting description with that behavior. Preserve the distinction between newly captured events and historical events that were never logged.
