# Issue #306288 — Prompted to reload window after enabling troubleshooting settings

[https://github.com/microsoft/vscode/issues/306288](https://github.com/microsoft/vscode/issues/306288)

## Summary

Valid polish issue: the `ChatDebugFileLoggerService` only reads its enabled-config at construction time, so toggling the debug-log settings requires a reload. The author requests making the setting take effect dynamically without a reload. Still unfixed on main.

## Change summary

Enabling the troubleshooting/debug-log settings prompts an unnecessary window reload.

## Best solution

Make `ChatDebugFileLoggerService` watch `onDidChangeConfiguration` for `ChatDebugFileLogging` and dynamically start/stop logging without requiring a window reload. The fix lives in `extensions/copilot/src/extension/chat/vscode-node/chatDebugFileLoggerService.ts`.
