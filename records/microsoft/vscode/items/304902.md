[https://github.com/microsoft/vscode/issues/304902](https://github.com/microsoft/vscode/issues/304902)

## Summary

This was the confirmed duplicate-disposal regression that removed streamed chat code blocks from the rendered response. The fix merged in commit 95a8c9f2ea2d091a4112db3f3b1d929af5a3aaa2 and shipped in 1.114.0, so this can close as completed.

## Change summary

Keep generated YAML code blocks visible in Copilot Chat instead of collapsing them while retaining the complete response in clipboard data.

## Best solution

Retain the shipped single-disposal guard in the chat editor pools; it prevents recycled code-block editors from being released more than once and disappearing from rendered responses. Continue tracking the distinct residual blank-code-block behavior in https://github.com/microsoft/vscode/issues/280071.
