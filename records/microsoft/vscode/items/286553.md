# Issue #286553 — Copilot Chat extension corrupts remote $PATH on Linux by injecting Windows-style path with semicolon

[https://github.com/microsoft/vscode/issues/286553](https://github.com/microsoft/vscode/issues/286553)

## Summary

Valid, confirmed bug with multiple reporters and a team member acknowledging it. An open PR (https://github.com/microsoft/vscode/pull/296268) exists to fix it — keeping open pending that PR's review and merge.

## Change summary

Copilot Chat injects a Windows-style path with semicolon separator into the remote Linux terminal's $PATH, corrupting it and breaking the `code` CLI command.

## Best solution

Land https://github.com/microsoft/vscode/pull/296268, which filters out Windows-style paths from the environment variable collection when applied to a non-Windows remote terminal. The fix belongs in the terminal environment variable resolution layer.
