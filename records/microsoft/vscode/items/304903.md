# Issue #304903 — Problems pane constantly re-evaluates frontmatter diagnostics for custom agent/instruction/skill/prompt files — excessive CPU and memory

[https://github.com/microsoft/vscode/issues/304903](https://github.com/microsoft/vscode/issues/304903)

## Summary

Keep open: the initial refresh-loop fix improved the behavior, but a maintainer explicitly confirmed that full parsing still occurs on every change notification and said further work is needed. The issue is team-authored and was reopened because the performance problem persisted.

## Change summary

Custom-agent frontmatter diagnostics repeatedly reparse hundreds of agent, instruction, skill, and prompt files, causing sustained CPU and memory use, amplified by symlink duplicates.

## Best solution

Make custom-agent diagnostics refresh incrementally and coalesce change notifications, while avoiding duplicate work for files that resolve to the same underlying resource. Preserve prompt discovery and validation correctness across workspace, user, and extension-provided customizations.
