# Issue #304903 — Problems pane constantly re-evaluates frontmatter diagnostics for custom agent/instruction/skill/prompt files — excessive CPU and memory

[https://github.com/microsoft/vscode/issues/304903](https://github.com/microsoft/vscode/issues/304903)

## Summary

Team-authored performance bug with partial fixes landed (reduced change events, avoided excessive calls, avoided client-side parsing). The maintainer (aeschli) acknowledged remaining work ('still parsing on every change notification') and has been iterating. Keep open for continued work.

## Change summary

The Problems pane constantly re-evaluates frontmatter diagnostics for custom agent/instruction/skill/prompt files, causing a CPU/memory-burning refresh loop in workspaces with many such files (especially with symlink duplicates).

## Best solution

Continue the incremental work aeschli has been doing: the remaining gap is per-change-notification parsing rather than incremental/dirty-file-only parsing, and symlink deduplication. The promptsServiceImpl.ts area has seen three rounds of optimization already; the next step is making parse incremental to changed files only.
