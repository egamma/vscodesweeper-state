# Issue #169166 — Multi-Process Debugger isn't working on VSC 1.74

## Summary

Thanks for the report. A maintainer reproduced this with a compound launch config whose configs share a `preLaunchTask`: the second config skipped the running task. Later task-system changes may have fixed it, but I can't confirm that from source alone, and an earlier proposed fix was refuted. The issue stays open.

## Change summary

With compound debug configs that share a preLaunchTask, only the first waits for the task; the others start debugging immediately.

## Best solution
