# Issue #340748 — Agent Customizations shows default MCP Marketplace servers when chat.mcp.gallery.enabled is false

[https://github.com/microsoft/vscode/issues/340748](https://github.com/microsoft/vscode/issues/340748)

## Summary

Keep open: current source still includes the default MCP registry in customization discovery without consulting chat.mcp.gallery.enabled. The independent confirmation on 1.143.1 supports the report; moving discovery into Marketplace does not eliminate the underlying gap.

## Change summary

Honor chat.mcp.gallery.enabled=false in customization discovery while retaining servers from the configured enterprise registry.

## Best solution

Default-registry discovery should respect its existing enablement setting in both legacy Available and the newer Marketplace surface, without disabling enterprise-registry discovery or changing installed-server and runtime authorization behavior.
