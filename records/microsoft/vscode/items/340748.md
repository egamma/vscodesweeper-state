# Issue #340748 — Agent Customizations shows default MCP Marketplace servers when chat.mcp.gallery.enabled is false

[https://github.com/microsoft/vscode/issues/340748](https://github.com/microsoft/vscode/issues/340748)

## Summary

Thanks for the detailed report. The Customizations MCP list always queries the product's default Marketplace manifest in addition to the active registry, so it ignores chat.mcp.gallery.enabled=false when a private registry is configured.

## Change summary

Chat: Open Customizations > MCP Servers lists default Marketplace servers under Available even though chat.mcp.gallery.enabled is false.

## Best solution

In mcpListWidget.queryLegacyGallery, query only the active manifest, and add the default manifest as a fallback only when the default Marketplace is enabled. That makes the view consistent with the Extensions MCP Servers view.
