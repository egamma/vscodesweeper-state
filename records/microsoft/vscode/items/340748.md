# Issue #340748 — Agent Customizations shows default MCP Marketplace servers when chat.mcp.gallery.enabled is false

[https://github.com/microsoft/vscode/issues/340748](https://github.com/microsoft/vscode/issues/340748)

## Summary

Thanks for the detailed report. Source confirms it: the Customizations MCP list always queries the default marketplace manifest as a fallback, regardless of chat.mcp.gallery.enabled.

## Change summary

Chat: Open Customizations > MCP Servers lists default-marketplace servers under Available even when chat.mcp.gallery.enabled is false.

## Best solution

In queryLegacyGallery, skip the default-manifest fallback when chat.mcp.gallery.enabled is false, so only the active (enterprise registry) manifest is queried. Gate the default marketplace on the setting wherever else it is used.
