# Issue #247715 — Settings Editor fails to find a setting with simple substring search

[https://github.com/microsoft/vscode/issues/247715](https://github.com/microsoft/vscode/issues/247715)

## Summary

Still reproduces on main: the settings search filter drops settings whose key match is lower-tier even when both contain the query substring. An open PR (#310898) exists to fix it — keeping open until it merges.

## Change summary

Settings Editor drops valid search results when one setting scores a higher key-match tier than another, even though both contain the query as a substring.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/310898 which relaxes the top-key-match filter when at least one result has a contiguous substring match, preserving the noise filter for purely fuzzy queries.
