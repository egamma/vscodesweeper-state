# Issue #248435 — Debug on cwd path with exclamation mark and space will fail on second try (when terminal is CWD)

[https://github.com/microsoft/vscode/issues/248435](https://github.com/microsoft/vscode/issues/248435)

## Summary

The current source still generates the incorrectly escaped working-directory command on terminal reuse. Keep this open: the failure is in VS Code's debug command preparation, not specific to the Python Debugger extension.

## Change summary

Repeated debugging in a reused Command Prompt terminal fails when the working-directory path contains an exclamation mark and a space.

## Best solution

Preserve the literal working-directory path when preparing the reused CMD terminal's directory-change command, without changing the separate escaping requirements of the launched command and its environment wrapper.
