## Summary

Keep open: current Welcome source still explicitly focuses a document-role container whose stylesheet suppresses its outline without a replacement. This team-authored accessibility report has no verified fix or canonical duplicate supporting closure.

## Change summary

Opening or keyboard-navigating Welcome can leave focus on a document container without a visible focus cue.

## Best solution

Resolve the Welcome page's initial and return-focus behavior so keyboard users land on a meaningful target with a visible, high-contrast-compatible focus indicator, while preserving screen-reader access to the page. Have the accessibility tester verify the reported Windows scenario before closure.
