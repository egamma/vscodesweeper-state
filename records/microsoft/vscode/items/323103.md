# Issue #323103 — agentHost: make multi-chat session changes diff (computeUnionedDiffs) incremental

[https://github.com/microsoft/vscode/issues/323103](https://github.com/microsoft/vscode/issues/323103)

## Summary

The performance debt remains on current main: multi-chat Session Changes still reads every source database and recomputes every file after each completed turn. This team-authored On Deck item has a bounded implementation path and focused existing test surfaces, so it should remain open.

## Change summary

Make multi-chat session diff aggregation reuse previous results and query only the completed turn's owning source when possible.

## Best solution

Extend the existing incremental diff contract with source ownership, preserve full-history fallback for cross-source edits and renames, and pass the completed chat source through the changeset lifecycle without changing full-compute correctness.
