# Issue #327466 — Feature Request: Allow folding single physical lines that are soft-wrapped via wordWrap

## Summary

A real editor capability gap remains, but the request is still in the Backlog Candidates voting period and has no community upvotes. Keep it open under discussion for the established community process rather than preempting that process.

## Change summary

Allow a single physical line split into soft-wrapped display lines to expose a folding control and collapse into a shortened preview.

## Best solution

If demand warrants implementation, design a view-model-level folding capability that can hide part of a physical line while preserving a visible preview, then decide whether soft wrapping should automatically expose that capability in the gutter. Coordinate that design with the broader inline-folding work tracked by https://github.com/microsoft/vscode/issues/50840 without treating the two requests as identical.
