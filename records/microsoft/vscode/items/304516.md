# Issue #304516 — 'GitHub Copilot Suggestions' webview does not have a global keyboard listener that captures every key press

[https://github.com/microsoft/vscode/issues/304516](https://github.com/microsoft/vscode/issues/304516)

## Summary

VS Code already provides a global setting for this intentional menu-mnemonic conflict. Disabling `window.enableMenuBarMnemonics` reserves Alt-key combinations such as Alt+H for user keybindings without requiring the Copilot webview to capture every keypress.

## Change summary

Prevent Alt+H from opening the Help menu while invoking a user keybinding from the focused GitHub Copilot Suggestions webview.

## Best solution

Use `"window.enableMenuBarMnemonics": false` when Alt-letter combinations should invoke editor commands rather than application-menu mnemonics; the Copilot Suggestions webview should not install a feature-specific global listener that swallows unrelated keyboard input.

## Evidence

- **existing capability:** src/vs/workbench/browser/workbench.contribution.ts registers `window.enableMenuBarMnemonics` for Windows and Linux and explicitly states that disabling it allows Alt-key shortcuts to be bound to editor commands.
- **menu implementation:** src/vs/platform/menubar/electron-main/menubar.ts reads `window.enableMenuBarMnemonics` and passes its inverse to `mnemonicMenuLabel`, removing native menu mnemonics when the setting is disabled.
- **webview forwarding:** src/vs/workbench/contrib/webview/browser/pre/index.html forwards trusted inner keydown events to the host, and src/vs/workbench/contrib/webview/browser/webviewElement.ts redispatches them to the workbench keybinding service; the absence of a Copilot-specific catch-all listener is therefore intentional.
- **canonical search:** https://github.com/microsoft/vscode/issues/241801 is related but not a valid duplicate under the re-review bar: it reports commands firing twice from webview and menu-accelerator dispatch on macOS, whereas this report observes one command invocation plus the Windows Help mnemonic.
