# Issue #238564 — Braces colouring is off inside Dart multiline strings

[https://github.com/microsoft/vscode/issues/238564](https://github.com/microsoft/vscode/issues/238564)

## Summary

Keep open as a confirmed cross-language bracket-colorization defect, not a Dart extension problem. The discussion supplies a language-switch reproduction, and the inspected source identifies a relevant tokenization lifecycle boundary but does not establish a fix or a verified duplicate.

## Change summary

Brackets inside string tokens can retain bracket-pair colors after changing the document language instead of displaying the string color.

## Best solution

Ensure bracket decorations converge to the token-aware result after language changes and grammar initialization, excluding ordinary string contents while preserving brackets in actual interpolation expressions. First isolate the reported language-switch sequence in the editor model lifecycle.
