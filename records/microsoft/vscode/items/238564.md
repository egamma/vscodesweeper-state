# Issue #238564 — Braces colouring is off inside Dart multiline strings

[https://github.com/microsoft/vscode/issues/238564](https://github.com/microsoft/vscode/issues/238564)

## Summary

Keep open in bracket-pair-colorization: two commenters independently confirmed incorrect bracket colors inside strings, including JavaScript after language switching. Source inspection identifies a plausible tokenization-lifecycle problem, but establishes neither a landed fix nor a verified duplicate.

## Change summary

Bracket pair colors sometimes persist inside correctly tokenized strings after opening a file or switching its language.

## Best solution

Make bracket colorization converge to the syntactic token classification after language changes and tokenization completion, without disabling colorization elsewhere. First pin the reported language-switch sequence in a deterministic model regression test and establish which lifecycle transition leaves the displayed bracket tree stale.
