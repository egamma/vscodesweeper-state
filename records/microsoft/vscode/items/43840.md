# Issue #43840 — [folding] Code folding does not respect multi-cursor

[https://github.com/microsoft/vscode/issues/43840](https://github.com/microsoft/vscode/issues/43840)

## Summary

Current main implements the requested multi-cursor folding behavior: the Fold command collects every active selection's line and folds the corresponding regions. The original implementation commit directly changed folding from the primary cursor to all cursors.

## Change summary

Make the Fold command collapse the folding region at every active cursor instead of only the primary cursor.
