# Issue #43840 — [folding] Code folding does not respect multi-cursor

[https://github.com/microsoft/vscode/issues/43840](https://github.com/microsoft/vscode/issues/43840)

## Summary

The requested multi-cursor folding behavior is already the designed behavior: both the reported 1.20.1 source and current main apply Fold to every selection's start line. A later maintainer-confirmed report documents the same workflow and was closed as designed.

## Change summary

Make the Fold command collapse the folding region at every active cursor rather than only the primary cursor.

## Best solution

Keep the existing behavior and use one empty cursor on the start line of each region before invoking Fold or Fold Recursively; the folding commands already process all such cursors.
