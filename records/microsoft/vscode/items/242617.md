## Summary

Team-authored accessibility feature request with active contributor discussion (last activity Dec 2025); must stay open for maintainer judgment.

## Change summary

Add active editor state information (e.g. file name, modification status) to the editor text area's ARIA label so screen readers announce context when switching editors.

## Best solution

The team should finalize the design discussed in comments — likely adding editor state to the text area ARIA label with a setting to disable it to avoid verbosity — and implement it in the editor accessibility contribution area. Roberto's alternative suggestion of ARIA announcements for existing signals (chat edits, code actions) could complement or replace the label approach.
