# Issue #152852 — Git - Seed proposed branch name from commit message

[https://github.com/microsoft/vscode/issues/152852](https://github.com/microsoft/vscode/issues/152852)

## Summary

Keep open: the protected-branch commit flow still does not seed the branch suggestion from the commit message. Existing prefix and random-name settings cover only part of the request, and the related naming requests are newer, not valid duplicate targets for this re-reviewed item.

## Change summary

Suggest an editable branch name using the issue reference in the pending commit message and the user's configured branch prefix.

## Best solution

The built-in Git protected-branch commit prompt should offer a meaningful, editable suggestion derived from the pending commit message while preserving branch validation, cancellation, and existing naming behavior when no suitable reference is present.
