# Issue #152852 — Git - Seed proposed branch name from commit message

[https://github.com/microsoft/vscode/issues/152852](https://github.com/microsoft/vscode/issues/152852)

## Summary

Valid, unimplemented feature request. The branch-protection "create branch" prompt does not extract issue references from the commit message to seed the branch name — the code at line 2555 of commands.ts calls `promptForBranchName(repository)` without passing any commit-message-derived suggestion. No commits reference this issue.

## Change summary

When committing to a protected branch triggers the 'create new branch' prompt, seed the suggested branch name from issue references found in the commit message.

## Best solution

In the branch-protection commit path in `extensions/git/src/commands.ts`, extract issue references (e.g. `#12345`) from the commit message and pass a derived name like `<user>/<prefix>-<issue>` to `promptForBranchName()` as the `initialValue` parameter. This would complement the existing `git.branchPrefix` and `git.branchRandomName` settings.
