# Issue #336370 — Inconsistent scrollbar thumb size and radius across panels

[https://github.com/microsoft/vscode/issues/336370](https://github.com/microsoft/vscode/issues/336370)

## Summary

Fresh, single-report cosmetic-consistency ask; tracing the source confirms the underlying widgets genuinely use different scrollbar defaults, but reconciling them across editor/list/terminal is a design decision, not a simple bug fix, so this should stay open for design/maintainer triage.

## Change summary

Scrollbar thumb width/radius differs visually between the editor/minimap, Debug Console (list widget), and the integrated terminal.

## Best solution

A design/workbench maintainer should decide whether to unify default `verticalScrollbarSize` across `AbstractScrollableElement`-based widgets (base default vs. the editor's 14px override in src/vs/editor/common/config/editorOptions.ts) and the xterm-derived terminal scrollbar CSS in src/vs/workbench/contrib/terminal/browser/media/xterm.css, or leave them as per-widget choices.
