# Issue #336370 — Inconsistent scrollbar thumb size and radius across panels

[https://github.com/microsoft/vscode/issues/336370](https://github.com/microsoft/vscode/issues/336370)

## Summary

Real, verifiable inconsistency: different surfaces (editor, debug console, terminal, notebooks, chat widgets) each hard-code their own `verticalScrollbarSize` (14, 10 default, 7, 6, etc.) with no shared visual treatment, but this is a cosmetic polish request with zero upvotes and no maintainer signal yet, so it stays open rather than closing.

## Change summary

Scrollbar thumb width/border-radius differs visibly between the editor/minimap, Debug Console, and the integrated terminal.

## Best solution

If maintainers want visual parity, standardize `verticalScrollbarSize`/thumb radius defaults across the base `ScrollableElement` consumers (editor default 14 in src/vs/editor/common/config/editorOptions.ts vs the base default of 10 in src/vs/base/browser/ui/scrollbar/scrollableElement.ts, plus per-widget overrides like chatInputPart.ts using 7) — otherwise this is intentional per-surface tuning and could be closed as *as-designed.

## Evidence

- **base scrollbar default:** src/vs/base/browser/ui/scrollbar/scrollableElement.ts line 787 falls back to `globalDefaultScrollbarSize` (10) when a consumer doesn't override it — Debug Console and the terminal (xterm.js scrollbar, src/vs/workbench/contrib/terminal/browser/media/xterm.css lines 252-320) don't set an explicit size, so they use this smaller default while the main editor explicitly requests 14.
