# Issue #336370 — Inconsistent scrollbar thumb size and radius across panels

[https://github.com/microsoft/vscode/issues/336370](https://github.com/microsoft/vscode/issues/336370)

## Summary

The cross-panel consistency request remains relevant: current main shares a corner-radius token but still uses different scrollbar widths for the editor, workbench lists, and terminal. Keep this open for a design decision about consistent visible thumbs while preserving each surface's navigation affordances.

## Change summary

Give editor, Debug Console, and terminal scrollbar thumbs a consistent visual treatment without losing scrollbar indicators or usability.

## Best solution

Agree on a shared visible-thumb treatment for Modern UI, with explicit exceptions for minimap and overview-ruler functionality. Preserve proportional thumb lengths, existing user width overrides, and usable drag targets rather than making every scrollbar dimension identical.
