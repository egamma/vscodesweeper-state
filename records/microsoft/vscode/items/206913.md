# Issue #206913 — responsive GUI regarding `search.smartCase`

[https://github.com/microsoft/vscode/issues/206913](https://github.com/microsoft/vscode/issues/206913)

## Summary

Keep open: this is an accepted Backlog polish request for clearer UI when `search.smartCase` changes search behavior, and current main still does not appear to expose that state in the Search view UI.

## Change summary

Make the Search view communicate when `search.smartCase` is actively making a search case-sensitive or case-insensitive.

## Best solution

Implement the smaller agreed direction first in the Search view: add a clear message or tooltip when smart case is enabled/active, likely near the search input or result count, and leave the ternary toggle redesign for separate design discussion.
