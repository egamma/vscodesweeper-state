# Issue #273003 — Chat: Resolve Merge Conflict doesn't reset tools that it needs

[https://github.com/microsoft/vscode/issues/273003](https://github.com/microsoft/vscode/issues/273003)

## Summary

Still present on main: the merge conflict resolution flow opens a chat session via `workbench.action.chat.open` without resetting or specifying the required tools, so it inherits whatever restricted tool set the current chat has. No fix has landed.

## Change summary

The 'Resolve Conflicts with AI' action fails when invoked from a chat session that has a restricted tool set, because the opened agent chat inherits the session's limited tools instead of resetting to defaults.

## Best solution

The `resolveMergeConflicts` method in `extensions/copilot/src/extension/git/vscode/mergeConflictServiceImpl.ts` should either open a new chat session (rather than reusing the current one) or explicitly reset/specify the required tools when calling `workbench.action.chat.open`. The `workbench.action.chat.open` command options may need a `tools` or `resetTools` property, or the flow should always start a fresh session.
