# Issue #273003 — Chat: Resolve Merge Conflict doesn't reset tools that it needs

[https://github.com/microsoft/vscode/issues/273003](https://github.com/microsoft/vscode/issues/273003)

## Summary

Team-authored issue, still unfixed on main. The merge conflict resolution flow reuses the current chat session's tool configuration instead of ensuring its required tools are available. The infrastructure to fix this (`toolsInclude`/`toolsExclude` on `workbench.action.chat.open`) now exists but hasn't been wired into `MergeConflictServiceImpl`.

## Change summary

"Resolve Conflicts with AI" fails when invoked from a chat session that has a restricted tool set, because it doesn't reset or specify the tools it needs.

## Best solution

Update `extensions/copilot/src/extension/git/vscode/mergeConflictServiceImpl.ts` to pass a `toolsInclude` (or no tool restriction, i.e. reset to defaults) in the options object passed to `workbench.action.chat.open`, using the `toolsInclude`/`toolsExclude` API added in https://github.com/microsoft/vscode/commit/10d87ddb3d2. This ensures the merge conflict agent flow always has the tools it needs regardless of the current chat session's tool configuration.
