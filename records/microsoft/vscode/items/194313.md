# Issue #194313 — Command center - make it leaner?

[https://github.com/microsoft/vscode/issues/194313](https://github.com/microsoft/vscode/issues/194313)

## Summary

A real UX gap remains: the Command Center still forces a 35px title bar, and no title-bar density setting exists. This is the canonical discussion and should remain open for a cross-platform design decision.

## Change summary

Reduce the Command Center title-bar height by default or provide a compact density option.

## Best solution

Define a platform-safe compact title-bar density, preferably through the existing `window.density` model, while retaining usable controls and draggable regions on Windows, macOS, Linux, and web.

- **Fit:** aligned
- **Reason:** Reducing persistent chrome or providing coherent density behavior supports a lightweight, consistent workbench.
- **Evidence:** Public values emphasize a lightweight and fast editor with simple, uniform UI; Workbench and core UX is also a durable investment theme.
