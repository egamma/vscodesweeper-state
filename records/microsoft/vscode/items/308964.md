# Issue #308964 — Copilot Chat should support cross-device cloud conversation memory for repository workflows

[https://github.com/microsoft/vscode/issues/308964](https://github.com/microsoft/vscode/issues/308964)

## Summary

Legitimate feature request for cloud-synced Copilot Chat conversation history across devices and sessions. No existing implementation or duplicate found — the current memory tool stores local instruction-style memories, not full conversation context. Routes to the Copilot Chat area for product consideration.

## Change summary

Persist Copilot Chat conversation history in the cloud so users can resume context seamlessly across devices and sessions, with optional repository scoping and retention controls.

## Best solution

Product decision needed on whether cross-device chat history belongs in VS Code core (via Settings Sync or a new cloud service) or in the Copilot backend. The existing local memory tool (`copilot-memories`) stores structured instructions but does not address full conversation continuity. A phased approach could start with opt-in cloud persistence of chat sessions tied to the signed-in GitHub account, then layer on repo-scoped memory and retention controls. This likely requires collaboration between the Copilot service team and the VS Code chat team.
