# Issue #327755 — setting workbench.editorAssociations does not applyToAllProfiles

[https://github.com/microsoft/vscode/issues/327755](https://github.com/microsoft/vscode/issues/327755)

Confirmed on current main: editor association resolution ignores settings stored in the application configuration layer by `workbench.settings.applyToAllProfiles`.

## Change summary

Make `workbench.editorAssociations` from the default profile apply when another profile is active.
