# Issue #327755 — setting workbench.editorAssociations does not applyToAllProfiles

[https://github.com/microsoft/vscode/issues/327755](https://github.com/microsoft/vscode/issues/327755)

## Summary

Confirmed root cause on main: getAllUserAssociationsForSetting in editorResolverService.ts merges default/workspace/user inspect values for workbench.editorAssociations but never reads applicationValue, so an association applied to all profiles via workbench.settings.applyToAllProfiles is silently dropped in any non-default profile that has no local override.

## Change summary

workbench.editorAssociations entries configured via workbench.settings.applyToAllProfiles are ignored in non-default user profiles.

## Best solution

In src/vs/workbench/services/editor/browser/editorResolverService.ts, include inspectedEditorAssociations.applicationValue in the merge inside getAllUserAssociationsForSetting so profile-wide associations are honored the same way workspace/user/default associations are.
