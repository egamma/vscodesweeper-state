# Issue #194816 — Command to open view container doesn't toggle properly

[https://github.com/microsoft/vscode/issues/194816](https://github.com/microsoft/vscode/issues/194816)

## Summary

Still reproduces on main: webview view pane never calls `setParentFlowTo` to bridge the overlay container (mounted at document root) back to the sidebar part, so `layoutService.hasFocus(part)` always returns false for webview views, preventing toggle.

## Change summary

The command to toggle a sidebar view container back to the editor doesn't work when the focused view is a webview, because the webview iframe lives outside the sidebar DOM tree.

## Best solution

Add a `setParentFlowTo(webview.container, this._container)` call in `webviewViewPane.ts` (similar to what `webviewEditor.ts` already does at line 168), so that `isAncestorUsingFlowTo` can trace focus from the overlay webview container back to the sidebar part.
