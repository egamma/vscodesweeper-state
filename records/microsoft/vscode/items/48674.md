# Issue #48674 — Revamp findFiles

[https://github.com/microsoft/vscode/issues/48674](https://github.com/microsoft/vscode/issues/48674)

## Summary

Keep open: the revamped file-search API exists, but remains proposed rather than available through the stable extension API. This api-proposal tracking issue must remain open until the API owners finalize or explicitly abandon it.

## Change summary

Provide an options-based file-search API that supports search.exclude, files.exclude, and ignore files without breaking existing callers.

## Best solution

Complete API-owner review and stabilization of the existing findFiles2 proposal, preserving the legacy findFiles contract. The remaining work is stable API availability, not another implementation of the proposed search behavior.
