# Issue #241867 — Notebook globaltoolbar leak (right)

[https://github.com/microsoft/vscode/issues/241867](https://github.com/microsoft/vscode/issues/241867)

## Summary

The disposable leak is still present on current main. The related PR #251015 was closed without merging, and the `NotebooKernelActionViewItem` instances created by `actionProvider` in `notebookEditorToolbar.ts` are not tracked for disposal.

## Change summary

NotebooKernelActionViewItem instances created by the notebook global toolbar's actionProvider are never disposed, causing a disposable leak.

## Best solution

Track NotebooKernelActionViewItem instances in a DisposableStore on NotebookEditorWorkbenchToolbar, clearing it before toolbar recreation and on dispose — the approach from the closed PR #251015 was correct in principle and should be re-applied cleanly.
