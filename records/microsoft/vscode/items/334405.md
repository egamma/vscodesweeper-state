# Issue #334405 — Claude BYOK broken in 1.136: SDK download deadlock for signed-in users

[https://github.com/microsoft/vscode/issues/334405](https://github.com/microsoft/vscode/issues/334405)

## Summary

Careful, well-documented bug report, but tracing the exact code paths on current main shows the described deadlock no longer exists: there is now a dedicated `AgentHostSdkSetupNotificationContribution` (registered and active) whose `getAgentSdkSetupState` offers the SDK download unconditionally whenever `download === 'notDownloaded'`, before any signed-in/entitlement check runs.

## Change summary

On 1.136, signed-in-but-no-Copilot-subscription users hitting a Claude SDK version bump get permanently stuck: no automatic download and no reachable manual download trigger, because the download-offer notification was gated behind `!signedIn`.

## Best solution

No further change needed in this area of main — the SDK-setup notification (src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostSdkSetupNotification.ts) already offers the download to signed-in users; the earlier `AgentHostSignedOutModelsNotificationContribution` gating (which still requires `!signedIn`) is a separate, Copilot-scoped banner not implicated in the deadlock the reporter hit.
