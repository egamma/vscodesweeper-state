# Issue #270403 — cannot open UNC file links in Markdown

[https://github.com/microsoft/vscode/issues/270403](https://github.com/microsoft/vscode/issues/270403)

## Summary

Still reproduces on main: the Markdown preview click handler silently drops `file:` scheme links because they match the scheme regex (so aren't delegated to VS Code) but aren't in `passThroughLinkSchemes` either. An open PR (#307976) addresses this.

## Change summary

Clicking UNC file links (file:////server/share/...) in Markdown preview does nothing because the click handler drops file-scheme URLs silently.

## Best solution

Land or refine the open PR https://github.com/microsoft/vscode/pull/307976 which adds `file:` scheme to the delegation condition so these links are posted back to VS Code for resolution. The fix is small and localized to `extensions/markdown-language-features/preview-src/index.ts`.
