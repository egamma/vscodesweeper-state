# Issue #321656 — Accessibility: Built-in VSCode webviews  fails with WCAG 2.1 SC 2.4.2 Page Titled (Level A) - Missing <title> element in <head> element

[https://github.com/microsoft/vscode/issues/321656](https://github.com/microsoft/vscode/issues/321656)

## Summary

The missing document titles remain evident in current main: extension-details HTML and the shared webview shell omit <title>, while the existing title plumbing only names an iframe. Keep this open; the related ARIA-role report describes a different accessibility failure.

## Change summary

Provide descriptive document titles for built-in webviews, including the extension-details content and its hosting document.

## Best solution

Ensure built-in extension-details webview documents have meaningful page titles, distinct from iframe accessible names. Preserve author-provided titles and existing webview behavior rather than treating iframe title attributes as document-title coverage.
