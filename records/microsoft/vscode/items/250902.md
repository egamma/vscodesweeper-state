# Issue #250902 — Debug Toolbar missing project in command center

[https://github.com/microsoft/vscode/issues/250902](https://github.com/microsoft/vscode/issues/250902)

## Summary

The requested session switcher is still missing: current source explicitly excludes it when the debug toolbar is in the Command Center. Keep this accepted Backlog request open; the related requests inspected do not establish an older canonical for the same symptom.

## Change summary

Allow switching between active debug sessions directly from the Command Center debug toolbar, as the floating toolbar allows.

Provide an accessible active-session indicator and switcher within the Command Center debug toolbar, preserving the ability to target debug controls without returning to the floating toolbar or another view.
