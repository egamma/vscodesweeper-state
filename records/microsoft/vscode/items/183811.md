# Issue #183811 — 'Share...' shouldn't overwrite clipboard automatically

[https://github.com/microsoft/vscode/issues/183811](https://github.com/microsoft/vscode/issues/183811)

## Summary

The requested behavior remains missing on main: Share writes its result to the clipboard before showing the dialog. This team-authored Backlog request should stay open, especially with `continue-working-on` indicating ongoing ownership.

## Change summary

Make Share present the generated link with explicit Copy, Open Link, and Close actions instead of automatically replacing clipboard contents.

## Best solution

Update `workbench.action.share` in `src/vs/workbench/contrib/share/browser/share.contribution.ts` so generating a share result does not mutate the clipboard; expose an explicit Copy action alongside Open Link and Close.
