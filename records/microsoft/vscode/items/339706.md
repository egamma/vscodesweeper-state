# Issue #339706 — "hidden" MenuBar becomes visible again when pressing Alt+F

[https://github.com/microsoft/vscode/issues/339706](https://github.com/microsoft/vscode/issues/339706)

## Summary

Confirmed real bug: on Windows/Linux with native title bar and `window.menuBarVisibility: hidden`, Electron reveals the menu bar on a mnemonic key press (Alt+F) and never re-hides it. An open PR already contains the exact fix, so this stays open pending merge rather than being closed as completed.

## Change summary

With `window.menuBarVisibility: hidden` and native title bar, pressing Alt+F permanently reveals the menu bar with no way to hide it again short of restart or toggling the setting.

## Best solution

Land https://github.com/microsoft/vscode/pull/340245, which disables native menu mnemonics in `src/vs/platform/menubar/electron-main/menubar.ts` (`currentEnableMenuBarMnemonics`) whenever the configured menu bar visibility is `hidden`, matching the root cause (Electron's mnemonic-triggered reveal never gets undone).

## Evidence

- **root cause confirmed:** src/vs/platform/menubar/electron-main/menubar.ts `currentEnableMenuBarMnemonics` getter currently always reads `window.enableMenuBarMnemonics` without checking menu bar visibility, so Alt-key mnemonics stay active even when the bar is set to hidden.
- **open fixing PR:** https://github.com/microsoft/vscode/pull/340245 adds a check: `if (!isMacintosh && getMenuBarVisibility(this.configurationService) === 'hidden') { return false; }`, explicitly citing this issue (#339706) in its code comment, but is not yet merged (no commit for this change found via `git log` on the file).
- **not yet on main:** `git log --oneline -- src/vs/platform/menubar/electron-main/menubar.ts` shows no recent commit touching this mnemonic logic, confirming the fix hasn't landed yet.
