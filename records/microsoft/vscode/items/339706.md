# Issue #339706 — "hidden" MenuBar becomes visible again when pressing Alt+F

[https://github.com/microsoft/vscode/issues/339706](https://github.com/microsoft/vscode/issues/339706)

## Summary

Traced to a real gap on main: the global Alt+mnemonic keydown listener in MenuBar opens a top-level menu without checking whether `options.visibility === 'hidden'`, so a user with `window.menuBarVisibility: hidden` still gets the File menu popping open on Alt+F with no way back except restart/toggling the setting.

## Change summary

With window.menuBarVisibility set to hidden, pressing Alt+F still opens the File menu and the menu bar stays visible afterward, with no way to re-hide it short of restarting or toggling the setting.

## Best solution

Guard the mnemonic KEY_DOWN handler in MenuBar (src/vs/base/browser/ui/menu/menubar.ts) to no-op when `this.options.visibility === 'hidden'`, matching the existing guard already present in the Alt modifier-key-status handler a few hundred lines below (`if (this.options.visibility === 'hidden') { return; }`).

## Evidence

- **unguarded mnemonic listener:** src/vs/base/browser/ui/menu/menubar.ts lines ~182-196: the window KEY_DOWN listener only checks `!this.options.enableMnemonics || !e.altKey || e.ctrlKey || e.defaultPrevented` before calling `this.onMenuTriggered(menuIndex, false)` for a matched mnemonic — it never checks `this.options.visibility`.
- **existing precedent guard:** The separate modifier-key-status handler in the same file (around line 930) already has `if (this.options.visibility === 'hidden') { return; }` before doing alt-focus handling — the mnemonic listener lacks the equivalent check, which is the inconsistency causing this bug.
- **mnemonics not gated by visibility:** src/vs/workbench/browser/parts/titlebar/menubarControl.ts `currentEnableMenuBarMnemonics` getter only checks the `window.enableMenuBarMnemonics` setting and web/fullscreen state — not `currentMenubarVisibility === 'hidden'` — so mnemonics remain registered and active even when the bar is configured hidden.
