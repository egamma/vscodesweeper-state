## Change summary

Valid union-typed MCP arguments are reportedly rejected before invocation, and updated tool schemas can retain stale validators after server restart.

## Best solution

Ensure validation uses the tool's current schema and accepts arguments satisfying any union branch. First isolate the fresh-server anyOf case from the independently traceable stale-validator case; reverse stringification is not required merely because another union branch expects a string.
