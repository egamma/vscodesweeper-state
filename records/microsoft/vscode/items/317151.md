# Issue #317151 — When pointer events are disabled, add element to chat doesn't work

[https://github.com/microsoft/vscode/issues/317151](https://github.com/microsoft/vscode/issues/317151)

## Summary

Still reproduces on main: the ElementPicker relies on `document.elementsFromPoint()` which skips elements with `pointer-events: none`, so those elements cannot be picked for 'Add to Chat'. No fix has landed.

## Change summary

Elements with `pointer-events: none` cannot be selected via the integrated browser's 'Add Element to Chat' feature — the entire page gets selected instead.

## Best solution

The `_pickElementAt` method in `preload-browserView.ts` needs to work around the `pointer-events: none` limitation — e.g. by temporarily overriding `pointer-events` on the target during the `elementsFromPoint` call, or by walking the DOM with `elementFromPoint` after temporarily setting `pointer-events: all` on the page. The context menu path (`event.target`) has a similar gap since the event won't target a `pointer-events: none` element.
