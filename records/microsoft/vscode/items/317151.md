# Issue #317151 — When pointer events are disabled, add element to chat doesn't work

[https://github.com/microsoft/vscode/issues/317151](https://github.com/microsoft/vscode/issues/317151)

## Summary

The defect remains in the current source: both selection paths rely on pointer hit-testing that excludes elements with pointer-events: none. Keep this open in browser-integration; no verified canonical or fixing commit was found.

## Change summary

Allow Add Element to Chat to select a visible webpage element even when its CSS disables pointer events.

## Best solution

Make the integrated browser's element selection identify the intended visible element through both the toolbar picker and right-click attachment flow, without changing the webpage's normal pointer behavior.
