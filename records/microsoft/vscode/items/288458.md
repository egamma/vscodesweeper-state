# Issue #288458 — Adopt the new chat sessions controller API for copilot cloud sessions

[https://github.com/microsoft/vscode/issues/288458](https://github.com/microsoft/vscode/issues/288458)

## Summary

The cloud-session migration is still necessary: current main registers the deprecated item provider and returns unmanaged session items. The related CLI migration concerns a separate implementation and does not absorb this work.

## Change summary

Migrate Copilot cloud session items from the provider-based API to the managed ChatSessionItemController API.

## Best solution

Have cloud sessions participate in the managed controller model while preserving their existing discovery, refresh, resource identity, metadata, and content behavior. Keep API finalization and new cloud archive-side effects outside this migration.
