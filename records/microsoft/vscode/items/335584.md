# Issue #335584 — Move failed MCP servers to the top of the MCP server list

[https://github.com/microsoft/vscode/issues/335584](https://github.com/microsoft/vscode/issues/335584)

## Summary

The requested failure-first ordering remains absent: current Customizations preserves server order and groups by source rather than error state. Related diagnostic improvements do not bring failed servers above the fold, so keep this separately scoped request open.

## Change summary

Prioritize MCP servers that failed to start so their error state and recovery actions are visible without scrolling.

## Best solution

Make failed installed MCP servers immediately discoverable in the Customizations MCP list. The area owner should settle how failure prioritization interacts with source groups and stable ordering during live status changes.
