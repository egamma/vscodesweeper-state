# Issue #347171 — Toggle Chat Conversation unexpectedly activates the main Agents window

[https://github.com/microsoft/vscode/issues/347171](https://github.com/microsoft/vscode/issues/347171)

## Summary

Keep open: the merged chat-window routing PR explicitly excludes this focus problem. Related window behavior has changed since the report, but the supplied Windows steps suffice to retest; the unsuccessful macOS attempt does not establish resolution.

## Change summary

Toggling the conversation in a detached stacked chat window unexpectedly foregrounds the main Agents window.

## Best solution

Preserve the detached window's foreground focus while toggling its conversation, without activating or navigating the main Agents window. First reproduce on Windows using the supplied steps and the invocation variants requested by the maintainer.
