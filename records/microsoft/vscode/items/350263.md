# Issue #350263 — Agent Host: a signed-out token stays readable in the authentication store until all providers have handled the sign-out

[https://github.com/microsoft/vscode/issues/350263](https://github.com/microsoft/vscode/issues/350263)

## Summary

The shared authentication store still exposes a withdrawn credential while providers process sign-out. Keep this security-sensitive, team-authored issue open; the merged fallback workaround does not fix the shared-store ordering.

## Change summary

Make signed-out credentials unavailable to authentication-store readers before awaiting provider sign-out handling.

## Best solution

Commit credential withdrawal and its change notification before provider fan-out, preserving previous-entry bookkeeping and request supersession behavior. Cover concurrent-client and superseded sign-outs without changing handling of non-empty credentials still in flight.
