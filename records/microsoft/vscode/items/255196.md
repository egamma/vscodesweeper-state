# Issue #255196 — Copilot instructions in multi-root should apply per folder

[https://github.com/microsoft/vscode/issues/255196](https://github.com/microsoft/vscode/issues/255196)

## Summary

Keep open: this Backlog Candidates request captures an unresolved product decision about whether multi-root instructions should all be loaded or selected recursively by the files an agent touches. Maintainers expressed opposing expectations, so the current behavior is not established as designed.

## Change summary

Scope Copilot instruction files in a multi-root workspace to the folder containing each file the agent reads, creates, or edits instead of applying every folder's instructions to every session.

## Best solution

Define and implement a customization-scoping contract for multi-root workspaces: retain workspace-wide context where appropriate while applying folder instructions recursively when work enters that folder. The design must specify behavior for turns that inspect or modify files across multiple roots.
