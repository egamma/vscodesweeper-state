# Issue #95992 — Can't click to set/clear breakpoint when a gutter decoration exists

[https://github.com/microsoft/vscode/issues/95992](https://github.com/microsoft/vscode/issues/95992)

## Summary

Verified duplicate: current source still intentionally prevents adding a breakpoint where a non-debug glyph decoration is present, and the open glyph-margin tracking issue explicitly owns the dedicated breakpoint-lane work needed to resolve this scenario.

## Change summary

Allow users to set and clear breakpoints by clicking the glyph margin even when an extension contributes another gutter decoration on the same line.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/179725 and complete its dedicated breakpoint-lane work so breakpoint interaction remains available alongside extension-contributed glyphs; the narrower adoption task at https://github.com/microsoft/vscode/issues/185814 can support that implementation.
