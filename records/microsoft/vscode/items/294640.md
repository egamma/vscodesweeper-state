# Issue #294640 — Feature Request: Add Optional "response_structure" Field to .agent.md Files (Custom Agents)

[https://github.com/microsoft/vscode/issues/294640](https://github.com/microsoft/vscode/issues/294640)

## Summary

Genuine feature request for a `response_structure` field in `.agent.md` files to enforce structured (JSON schema) outputs from custom agents. No existing header attribute covers this; the request has no traction yet and needs product discussion on whether structured output enforcement belongs in the agent file header or should be handled differently.

## Change summary

Add an optional `response_structure` field to `.agent.md` frontmatter so custom agents can declare a JSON schema for their output, enabling automated validation and reliable downstream parsing.

## Best solution

This needs a product decision on whether structured output belongs in the `.agent.md` header (as proposed) or in the agent body/instructions (as @aeschli suggested), and whether VS Code should enforce the schema at the platform level (via model-provider `response_format` parameters) or leave it advisory. The relevant code is in `src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptFileAttributes.ts` where agent header attributes are defined. The distinction the reporter draws — header-level enforcement via API `response_format` vs. body-level prompting — is meaningful and worth resolving before implementation.
