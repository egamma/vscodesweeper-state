- **current architecture:** ChatCustomAgentsService and its reported error string are absent from current main. - **remaining invalidation risk:** PromptFilesLocator.createFilesUpdatedEvent fires when IFileService reports a change affecting any configured agent root, and CachedPromise invalidates and emits onDidChangePromise for every such event without comparing the resulting agent inventory. This is a plausible repeated-rescan path, but the source alone does not establish recurring WSL events for unchanged files.
- **diagnostics changed:** src/vs/workbench/contrib/chat/browser/promptSyntax/promptFileContributions.ts now tracks and validates only prompt models visible in open code editors, with a 200 ms delay; it does not directly revalidate all discovered files on every custom-agent discovery event.
