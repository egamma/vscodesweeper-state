# Issue #333577 — If customizations only has one path as an option a quickpick should not be used

[https://github.com/microsoft/vscode/issues/333577](https://github.com/microsoft/vscode/issues/333577)

## Summary

Confirmed in source: `CustomizationLocationPicker.resolveTargetDirectoryWithPicker` in customizationCreatorService.ts has a commented-out single-folder shortcut, so the quickpick always shows even when there's only one matching folder — exactly the behavior the reporter (the code's own author) describes.

## Change summary

The 'select a directory for the new customization file' quickpick appears even when only one target folder is available to choose from.

## Best solution

Uncomment the `matchingFolders.length === 1` early-return at lines 168-170 of customizationCreatorService.ts so the picker is skipped and the single folder's URI is returned directly.
