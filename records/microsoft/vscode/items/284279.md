# Issue #284279 — Stupidly difficult to select text from the beginning of line; cursor icon inconsistent with behavior

[https://github.com/microsoft/vscode/issues/284279](https://github.com/microsoft/vscode/issues/284279)

## Summary

The cursor and gutter event paths can produce the reported inconsistency, but the available evidence does not confirm that their boundaries overlap on current main. Request confirmation on the latest Insiders build plus the display and editor settings needed to reproduce the apparent pixel-boundary mismatch.

## Change summary

At the editor's left content boundary, the pointer can show a text-selection cursor while dragging is still treated as a non-selectable gutter interaction.

## Best solution

Make the text-cursor region and editor hit-testing use the same effective content boundary, including fractional scaling and zoom. Treat additional selectable padding as separate feature work already tracked by https://github.com/microsoft/vscode/issues/206914.
