# Issue #284279 — Stupidly difficult to select text from the beginning of line; cursor icon inconsistent with behavior

[https://github.com/microsoft/vscode/issues/284279](https://github.com/microsoft/vscode/issues/284279)

## Summary

The cursor icon mismatch claim — caret shown in the gutter where clicking doesn't select text — cannot be verified from source alone; the margin DOM and content DOM are separate, and CSS cursors should differ at the boundary. Needs a screenshot or screen recording to confirm, especially on Linux where window-manager/toolkit cursor behavior can vary. The broader difficulty of selecting from line beginnings is tracked by the open feature request #206914.

## Change summary

Mouse cursor shows a text-selection caret in the gutter area between line numbers and content, but clicking there does not select text, making it difficult to select from the beginning of a line.

## Best solution

If the cursor mismatch is confirmed, add an explicit `cursor: default` to the line-decorations or margin-view-overlays CSS to prevent the browser from showing a text caret in the non-clickable gutter strip. The broader request for more clickable space at line beginnings is already tracked by https://github.com/microsoft/vscode/issues/206914.
