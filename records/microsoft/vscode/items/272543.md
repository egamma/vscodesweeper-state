## Change summary

Ensure `vscode.lm.selectChatModels({ vendor: 'copilot' })` waits for and returns available Copilot models when called from an extension running in a dev-container extension host.

## Best solution

Reproduce with Pylance in the remote extension host and Copilot in its normal host, then make model selection return complete `LanguageModelChat` objects only after the requesting host has the corresponding metadata. Preserve normal local-host selection and avoid reintroducing recursive resolution or model-change feedback loops.
