# Issue #43046 — Add command to select all next occurrences for all cursors

[https://github.com/microsoft/vscode/issues/43046](https://github.com/microsoft/vscode/issues/43046)

## Summary

Keep open: current commands do not add the next occurrence independently for every existing selection. A maintainer explicitly supported exploring a separate command while preserving Cmd+D's existing behavior.

## Change summary

Provide a command that adds the next matching occurrence for each existing cursor or selection.

## Best solution

Offer a separate multicursor command for advancing each existing selection's occurrence search, without changing Cmd+D or its skip-match workflow. Settle the new command's matching and repeated-invocation semantics before implementation.
