# Issue #43046 — Add command to select all next occurrences for all cursors

[https://github.com/microsoft/vscode/issues/43046](https://github.com/microsoft/vscode/issues/43046)

## Summary

A real multicursor capability remains missing on current main. The existing Cmd+D behavior should remain unchanged, while a separate command could support this accepted Backlog request.

## Change summary

Add a command that selects the next occurrence independently for every existing cursor.

## Best solution

Add a separate editor command in the multicursor contribution that computes the next match from each pre-existing selection, preserving `editor.action.addSelectionToNextFindMatch` and its skip-over-false-positives workflow.
