# Issue #325355 — Switching from Autopilot to Plan erases draft and automatically sends “Start implementation”

[https://github.com/microsoft/vscode/issues/325355](https://github.com/microsoft/vscode/issues/325355)

## Summary

Verified duplicate of the open, broader issue #307385: the same auto-send-handoff code path fires whenever the chat mode changes while Autopilot permission is active, and here it also overwrites the compose box, wiping the user's unsent draft.

## Change summary

Switching from Autopilot to Plan mode wipes the typed-but-unsent draft prompt and auto-submits 'Start implementation' without user consent.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/307385, which already tracks the core defect (auto-send handoff firing on a mode switch while Autopilot is enabled) with maintainer engagement; any fix there (e.g. gating the auto-send on an explicit user action, or not clobbering unsent input) resolves this report's draft-loss symptom too.
