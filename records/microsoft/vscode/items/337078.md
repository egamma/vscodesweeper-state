# Issue #337078 — Local Chat: Agent mode resets to Ask after restart in 1.138

[https://github.com/microsoft/vscode/issues/337078](https://github.com/microsoft/vscode/issues/337078)

Fresh (0-day-old), already maintainer-labeled regression (`bug`, `recent-regression`) with clear, specific repro steps and a customer report backing it; no fix or comment yet, so it stays open. I traced a plausible mechanism in the local chat input's mode-persistence/session-restore flow but this checkout is a shallow single-commit clone (no history to pinpoint the introducing commit), so I can't cite a fix or fully confirm the exact trigger.

## Change summary

After restarting VS Code and reopening local Copilot Chat, the previously-selected Agent mode silently reverts to Ask instead of persisting.

## Best solution

Ensure the last-selected chat mode from the persisted empty-input-state memento is honored when a chat session is treated as 'new'/empty on window restart, rather than being overridden or skipped in `_setEmptyModelState()`.
