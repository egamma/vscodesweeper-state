# Issue #30925 — Add support for different fonts in the same file

[https://github.com/microsoft/vscode/issues/30925](https://github.com/microsoft/vscode/issues/30925)

## Summary

Implemented and shipped in VS Code 1.108: TextMate token rules can now select different font families within one editor.

## Change summary

Allow selected syntax elements to use a different font family and ligatures from the editor's default font.

## Best solution

Use `editor.tokenColorCustomizations.textMateRules` to assign `fontFamily` to the desired operator scopes while retaining the default `editor.fontFamily`; enable `editor.fontLigatures` for ligature rendering.
