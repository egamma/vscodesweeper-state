# Issue #30925 — Add support for different fonts in the same file

[https://github.com/microsoft/vscode/issues/30925](https://github.com/microsoft/vscode/issues/30925)

## Summary

The requested per-token font selection is implemented on current main through TextMate customization rules. This supports a primary font for letters and a different font for operator ligatures without modifying VS Code's application files.

## Change summary

Allow different font families within one file, including Operator Mono letters with Fira Code operator ligatures and separately styled comments.

## Best solution

Close as completed by commit 79e3994280ff914844114eb9a28a725a4f16780a. Use editor.tokenColorCustomizations.textMateRules with scoped settings.fontFamily overrides and editor.fontLigatures enabled for the operator font.
