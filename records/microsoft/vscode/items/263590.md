# Issue #263590 — Run in terminal should prefer winget over install scripts

[https://github.com/microsoft/vscode/issues/263590](https://github.com/microsoft/vscode/issues/263590)

## Summary

Keep open: the requested availability-aware WinGet preference is not present in the inspected terminal-tool guidance, and no verified canonical or fixing commit was found. This is an enhancement to agent command selection rather than a demonstrated failure of terminal execution.

## Change summary

Prefer WinGet over installation scripts for Windows application dependencies when WinGet and the required package are available.

## Best solution

Make agent installation choices aware of the terminal host's available package managers, preferring WinGet for supported Windows packages while preserving an appropriate fallback when it is unavailable. Establish model-level acceptance checks before treating a prompt change as sufficient.
