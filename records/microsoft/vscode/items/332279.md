# Issue #332279 — Auto‑replace quote pairs on key press

[https://github.com/microsoft/vscode/issues/332279](https://github.com/microsoft/vscode/issues/332279)

## Summary

The requested quote-pair replacement remains distinct from built-in selection wrapping, but maintainers previously reviewed this behavior and explicitly placed it in extension territory. Propose closing as an extension candidate based on that established decision, not as a duplicate of the closed report.

## Change summary

Replace an existing matching quote pair with the newly typed quote pair while preserving the selected text, including asymmetric typographic quotes.

## Best solution

Provide quote-pair conversion through an extension without changing the editor's existing surround-selection behavior, following the maintainer decision in https://github.com/microsoft/vscode/issues/874.

## Evidence

- **Established maintainer precedent:** https://github.com/microsoft/vscode/issues/874 requests the same observable behavior: selecting quoted text and typing another quote should replace the old delimiters instead of wrapping them. In https://github.com/microsoft/vscode/issues/874#issuecomment-366493193, the response explicitly describes changing surrounding characters as a language-agnostic feature best provided through an extension. A team member agrees in https://github.com/microsoft/vscode/issues/874#issuecomment-420198533; the issue is closed with *extension-candidate. That rationale also covers the additional asymmetric quote pairs requested here.
- **Existing capability does not cover replacement:** src/vs/editor/common/config/editorOptions.ts registers editor.autoSurround with languageDefined, quotes, brackets, and never options; these control wrapping, not delimiter conversion. SurroundSelectionOperation in src/vs/editor/common/cursor/cursorTypeEditOperations.ts delegates to SurroundSelectionCommand, whose getEditOperations in src/vs/editor/common/commands/surroundSelectionCommand.ts inserts delimiters at the selection boundaries without removing an existing pair.
