# Issue #332279 — Auto‑replace quote pairs on key press

[https://github.com/microsoft/vscode/issues/332279](https://github.com/microsoft/vscode/issues/332279)

## Summary

Reasonable, well-scoped enhancement to the editor's auto-surround behavior; current main only ever wraps a selection with a new pair and never detects/replaces an existing surrounding quote pair, so this is a real gap worth routing to the editor area.

## Change summary

When a selection is already wrapped in a quote pair and the user presses a different quote key, replace both existing quotes with the new pair instead of doing nothing.

## Best solution

Extend `SurroundSelectionOperation._isSurroundSelectionType`/`_runSurroundSelectionType` in src/vs/editor/common/cursor/cursorTypeEditOperations.ts to detect when the selection's first/last characters are already a matching quote/bracket pair and, in that case, replace them with the newly typed pair rather than wrapping a second time; needs an editor-team design decision on which pairs (straight quotes, «», „“, etc.) qualify.
