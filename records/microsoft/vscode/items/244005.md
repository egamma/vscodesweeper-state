# Issue #244005 — Weird Arrow Rendering Problem

[https://github.com/microsoft/vscode/issues/244005](https://github.com/microsoft/vscode/issues/244005)

## Summary

Linux-specific font rendering issue where mixing Unicode characters from different blocks causes inconsistent glyph sizing — likely rooted in Chromium's font fallback/shaping on Linux. No fix found on main, no other confirmations in 493 days, but the reporter provided video evidence on their platform.

## Change summary

Unicode character ➜ (U+279C) renders at a different size when placed on the same line as 🠚 (U+1F81A) on Linux.

## Best solution

This is likely a Chromium text-shaping issue on Linux where fallback fonts for different Unicode blocks have mismatched metrics. The fix would need to come from upstream Chromium or from the system's fontconfig setup. If it can be narrowed to a VS Code font-measurement issue, it would live in `src/vs/editor/browser/viewParts/lines/` or `src/vs/editor/common/config/fontInfo.ts`, but more likely this is system/Chromium-level.
