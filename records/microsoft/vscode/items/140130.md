# Issue #140130 — Show all options in settings.json hovers

[https://github.com/microsoft/vscode/issues/140130](https://github.com/microsoft/vscode/issues/140130)

## Summary

Keep open: the JSON hover path still selects the current value's description rather than listing all available options when hovering a setting ID. No verified canonical covers this exact request; the existing settings-editor routing is appropriate.

## Change summary

Show every available option and its description when hovering a settings.json property name, while preserving current-value descriptions on value hovers.

## Best solution

Make setting-name hovers expose the available enum values and their descriptions without requiring an edit or completion interaction, while keeping value hovers focused on the selected value. Coordinate this with the JSON language service that supplies the hover content.
