# Issue #337314 — Extensions search: Marketplace proxy returns empty results with nonzero totals, causing undefined identifier crash

[https://github.com/microsoft/vscode/issues/337314](https://github.com/microsoft/vscode/issues/337314)

## Summary

Real, well-diagnosed bug reported by a team member: the Marketplace proxy can return an inconsistent paging response (nonzero total, empty extensions array), and the client's PagedModel trusts that data, dereferencing an undefined extension. An open PR already targets the client-side guard, so this stays open pending that fix and the service-side proxy investigation.

## Change summary

Marketplace proxy sometimes returns a nonzero total with an empty extensions array for a page, and VS Code's extension search crashes trying to render the missing (undefined) extension instead of guarding against the inconsistency.

## Best solution

Land the guard against incomplete/inconsistent paged Marketplace responses (per open PR https://github.com/microsoft/vscode/pull/337423) so the UI degrades gracefully instead of crashing, while the proxy-side inconsistency is tracked separately as a service issue.
