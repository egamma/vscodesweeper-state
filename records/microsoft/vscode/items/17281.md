# Issue #17281 — Add support for capture groups in onEnterRules

[https://github.com/microsoft/vscode/issues/17281](https://github.com/microsoft/vscode/issues/17281)

## Summary

This feature request for capture group support in onEnterRules is still unimplemented on main — the onEnter matching code uses `.test()` (discarding captures) rather than `.exec()`. Filed by a team member with a clear design discussion and 12 upvotes; keeping open on its merits.

## Change summary

Allow onEnterRules to reference regex capture groups (e.g. `$1`) in `appendText`, so extensions can preserve comment prefixes and custom indentation when pressing Enter.

## Best solution

Implement capture group support in `src/vs/editor/common/languages/supports/onEnter.ts` by switching from `.test()` to `.exec()` when matching `beforeText`/`afterText`/`previousLineText`, then substituting `$1`, `$2`, etc. in `appendText`. The design direction (use `$1`/`$2` syntax, no snippet mode) was agreed upon by alexdima and jrieken in the comments. Related issue https://github.com/microsoft/vscode/issues/66235 is a broader request for more powerful onEnterRules but is distinct enough to remain separate.
