# Issue #333097 — Jupyter/Python extension hangs indefinitely when a notebook is restored on startup, but works fine when opened manually

[https://github.com/microsoft/vscode/issues/333097](https://github.com/microsoft/vscode/issues/333097)

## Summary

The reported hang is about the Jupyter/Python extensions failing to activate and connect a kernel in time when a notebook is restored on startup — that activation/connection logic lives in the Jupyter and Python extensions, not VS Code core, so this belongs on their tracker rather than here.

## Change summary

On Windows, restoring a previously-open .ipynb tab at VS Code startup leaves the kernel unconnected indefinitely, while manually reopening the same notebook after a cold start works fine.

## Best solution

Move this to microsoft/vscode-jupyter (with a note that ms-python.python's activation timing is also implicated) so the extension owners can investigate the restore-time activation race between the notebook editor and the extension host.
