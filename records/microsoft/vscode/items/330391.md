# Issue #330391 — Agents Window: Skills from custom folder are not available

[https://github.com/microsoft/vscode/issues/330391](https://github.com/microsoft/vscode/issues/330391)

## Summary

Plausible, unresolved bug in how the Agent Host's Copilot harness resolves `chat.agentSkillsLocations` entries set in project `settings.json` — the reporter sees global/personal skill locations picked up but workspace-relative ones dropped, which is consistent with the resolution code path but not yet conclusively pinned down.

## Change summary

Custom skill folders configured via `chat.agentSkillsLocations` in a workspace's `.vscode/settings.json` don't show up as available skills in the Agents Window / Copilot agent harness, though they work when explicitly invoked in the classic Chat panel.

## Best solution

Trace why `resolveSkillConfigLocations` (extensions/copilot/src/extension/chatSessions/common/skillConfigLocations.ts), consumed by `CopilotCLISkills.getSkillsLocations` (extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCLISkills.ts), fails to resolve relative/workspace-scoped `chat.agentSkillsLocations` entries in the Agent Host/Copilot-harness execution context even though it does resolve `~/`-rooted and absolute entries — likely `IWorkspaceService.getWorkspaceFolders()` returning empty or stale results in that context.

## Evidence

- **resolution code:** extensions/copilot/src/extension/chatSessions/common/skillConfigLocations.ts resolveSkillConfigLocations() expands `~/`-prefixed and absolute paths directly, but relative paths are joined against `workspaceService.getWorkspaceFolders()` — if that call returns nothing in the agent-host/background execution context, project-relative settings.json entries would silently vanish while global (`~/`) entries keep working, matching the reporter's exact symptom.
- **consumer:** extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCLISkills.ts getSkillsLocations() feeds these resolved URIs (plus promptsService.getSkills() results) into what's surfaced by the 'Agent Customizations for Copilot' debug/discovery view (src/vs/workbench/contrib/chat/browser/chatDebug/chatCustomizationDiscoveryRenderer.ts).
