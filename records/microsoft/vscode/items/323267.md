# Issue #323267 — AI: Show the VS Code extension that introduced each MCP server, tool, agent, skill, instruction, and plugin

[https://github.com/microsoft/vscode/issues/323267](https://github.com/microsoft/vscode/issues/323267)

## Summary

Current main already provides extension attribution and contribution summaries for several customization types, but not the complete bidirectional provenance requested here. Keep this open for the remaining coverage and scope decision; the verified related issues do not own the full request.

## Change summary

Expose the originating extension for every AI customization and provide an extension-side inventory, distinguishing user and workspace configuration.

## Best solution

Build on existing customization source displays and the extension Features tab to make known extension ownership consistently discoverable, particularly for extension-provided plugins and their contents. Explicitly distinguish registered provenance from files merely discovered in user or workspace folders, whose creating extension may be unknown.
