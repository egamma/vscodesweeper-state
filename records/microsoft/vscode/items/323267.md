# Issue #323267 — AI: Show the VS Code extension that introduced each MCP server, tool, agent, skill, instruction, and plugin

[https://github.com/microsoft/vscode/issues/323267](https://github.com/microsoft/vscode/issues/323267)

## Summary

Valid polish/transparency request. The Customizations view already tracks extensionId and shows it in hover tooltips and group headers for some item types (tools, MCP servers), but the coverage is inconsistent across item types, and the reverse direction (extension → list of contributed items) is not implemented. Keeping open as a real gap remains.

## Change summary

Show the originating VS Code extension for every MCP server, tool, agent, skill, instruction, and plugin in the Customizations view, and show a reverse summary on each extension.

## Best solution

Unify extension-provenance display across all item types in the Customizations view (agents, skills, instructions, prompts currently show extensionId only in the hover tooltip, while tools and MCP servers have richer rendering). The reverse direction — listing contributed items on the extension detail page — would likely need work in `src/vs/workbench/contrib/extensions/` and coordination with the aiCustomization item model. This is a reasonable improvement for the Customizations editor area.
