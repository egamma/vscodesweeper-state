# Issue #340054 — Untitled custom-editor switching can strand text and blocks safe Reopen With transitions

[https://github.com/microsoft/vscode/issues/340054](https://github.com/microsoft/vscode/issues/340054)

## Summary

Keep open: current main still clears untitled text after handing bytes to a provider that does not consume them, and separately blocks safe text-backed Reopen With transitions. Related reports cover only parts of this team-authored issue; none establishes a fix or a full-scope canonical duplicate.

## Change summary

Preserve authoritative untitled text during editor switching, allow shared-text-model transitions, and reject unsupported ownership transfers without discarding content.

## Best solution

Make untitled editor transitions preserve text ownership consistently across Reopen With, resolver selection, and programmatic opens. Supported custom-document transfers must retain initial-data and backup behavior without duplicate dirty prompts; unsupported or unsuccessful transfers must leave the original document intact.
