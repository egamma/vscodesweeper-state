# Issue #293758 — Shell integration breaks grml-zsh-config by setting ZDOTDIR

[https://github.com/microsoft/vscode/issues/293758](https://github.com/microsoft/vscode/issues/293758)

## Summary

The startup-order incompatibility remains in current source: system zsh configuration runs while ZDOTDIR points to VS Code's injection directory, so grml misses the user's .zshrc.local. Route this to terminal shell integration; the Remote SSH connection is not the owning code path.

## Change summary

Preserve grml-zsh-config's loading of user customizations when automatic zsh shell integration is enabled.

## Best solution

Make automatic zsh shell integration preserve normal system and user startup configuration semantics, including grml's .zshrc.local lookup, without requiring users to duplicate sourcing in .zshrc. Establish a startup-order regression check before changing the injection mechanism.
