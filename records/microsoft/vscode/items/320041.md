# Issue #320041 — Git extension falsely detects repository in empty/new window after updating to latest version

[https://github.com/microsoft/vscode/issues/320041](https://github.com/microsoft/vscode/issues/320041)

## Summary

Thanks for the report. The source does not establish why a completely blank window would discover this repository; current-build confirmation and Git logs are needed to distinguish unexpected discovery from detection triggered by an opened or restored file.

## Change summary

Opening a new window without a folder or workspace unexpectedly activates a parent or home Git repository and displays thousands of changes.

## Best solution

A genuinely blank window should not discover an unrelated repository, while folderless windows containing files should retain their supported Git integration. Identify the initiating resource or event in the built-in Git extension's logs before deciding which discovery path needs correction.
