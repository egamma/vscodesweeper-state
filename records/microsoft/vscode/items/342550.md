# Issue #342550 — Browser action should open browser tab in preview mode and focus URL bar

[https://github.com/microsoft/vscode/issues/342550](https://github.com/microsoft/vscode/issues/342550)

## Summary

The reported inconsistency remains in current source: the Session Activity Bar and Agents: Browser shortcut always create a fresh, pinned browser editor without invoking the URL picker. The duplicate-tab behavior also has an independent confirmed reproduction, so this remains actionable.

## Change summary

Make the Agents browser entry point reuse an existing browser tab and give newly opened tabs the preview and URL-entry behavior of the standard browser command.

## Best solution

The Session Activity Bar Browser action and its keyboard shortcut should reveal an existing browser tab rather than accumulate duplicates; when creating a blank tab, they should match the standard browser command's preview and URL-entry behavior. Preserve the explicit New Tab command as a way to create additional browser tabs.
