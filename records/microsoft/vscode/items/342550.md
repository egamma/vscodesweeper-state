# Issue #342550 — Browser action should open browser tab in preview mode and focus URL bar

[https://github.com/microsoft/vscode/issues/342550](https://github.com/microsoft/vscode/issues/342550)

## Summary

The Sessions Browser action still creates a fresh pinned tab on every invocation and omits the URL-input activation used by the standard browser commands. This contradicts the linked test plan's expectation that an already-open activity-bar tab is focused rather than duplicated.

## Change summary

Make the Session Activity Bar Browser action and its keyboard shortcut open a preview browser with URL-input focus instead of accumulating pinned blank tabs.

## Best solution

Align the Sessions browser entry points with the established preview and URL-input behavior, while preserving intentionally opened browser tabs and normal navigation/pinning behavior.
