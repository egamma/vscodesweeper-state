# Issue #120270 — dragging tabs to remote-ssh teminal window pastes paths with backslashes

[https://github.com/microsoft/vscode/issues/120270](https://github.com/microsoft/vscode/issues/120270)

## Summary

Fixed on current main: terminal drag-and-drop now preserves the resource URI until the terminal backend formats it for its operating system, preventing Windows separators from being pasted into a remote Linux shell.

## Change summary

Dragging a remote editor tab from a Windows client into a Linux Remote-SSH terminal pasted the path with backslashes.

## Best solution

Keep the URI-based terminal drop path introduced by commit f00b25eff8b37d3c07a706efc4cec8bc3993d3c6, which lets terminal path preparation select separators using the backend OS.
