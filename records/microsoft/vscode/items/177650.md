[https://github.com/microsoft/vscode/issues/177650](https://github.com/microsoft/vscode/issues/177650)

## Summary

Team-authored exploration issue for refactoring icon-theme CSS matching to use attribute selectors. Not yet implemented on main — two open PRs (#174286 and #311376) are active implementation attempts. Keeping open as valid ongoing work.

## Change summary

Refactor icon-theme file matching from CSS class selectors to attribute selectors (e.g. `[data-basename^="hello"]`) to simplify implementation and enable name patterns/glob support.

## Best solution

Land one of the open PRs (https://github.com/microsoft/vscode/pull/174286 or https://github.com/microsoft/vscode/pull/311376) after resolving the multi-segment extension design question (how to handle `.test.ts` etc.). The attribute selector approach would simplify the icon-theme CSS generation in `src/vs/workbench/services/themes` and enable glob-like pattern matching for icon theme authors.
