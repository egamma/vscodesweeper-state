# Issue #224338 — Codelens references for properties of object in root module scope

[https://github.com/microsoft/vscode/issues/224338](https://github.com/microsoft/vscode/issues/224338)

## Summary

Valid, community-backed feature request (28 upvotes, in Backlog with `help wanted`). The gap is real and clearly locatable in the `extractSymbol` method — object-literal properties in root scope are intentionally excluded today. No fix or PR exists.

## Change summary

Show CodeLens references for properties of root-scope (especially exported or `as const`) object literals, similar to how enum members already get them.

## Best solution

Extend `extractSymbol` in `extensions/typescript-language-features/src/languageFeatures/codeLens/referencesCodeLens.ts` (lines 136–141) to also show CodeLens for `memberVariable` children of root-scope `const`/`let`/`variable` parents — likely gated by the parent being exported or `as const`, and possibly behind an additional setting. The `help wanted` label is appropriate; a community PR would be welcome.
