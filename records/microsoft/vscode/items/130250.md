# Issue #130250 — [folding] Show number of lines folded

[https://github.com/microsoft/vscode/issues/130250](https://github.com/microsoft/vscode/issues/130250)

## Summary

This remains a well-supported Backlog feature request: current main still renders a fixed ellipsis for folded ranges, and the open implementation PR references this issue but has not merged. The issue should remain open while that PR is reviewed or superseded.

## Change summary

Show the number of hidden lines, or an equivalent useful count, beside a collapsed editor range instead of only an ellipsis.

## Best solution

Resolve the collapsed-text infrastructure proposed in https://github.com/microsoft/vscode/pull/170447, then provide a core folding summary that displays the hidden-line count while preserving the existing folding interaction and styling.
