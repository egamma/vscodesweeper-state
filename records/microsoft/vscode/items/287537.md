# Issue #287537 — Copying additional files to the worktree is slow on Linux

[https://github.com/microsoft/vscode/issues/287537](https://github.com/microsoft/vscode/issues/287537)

## Summary

Keep open: the Windows commenter independently confirms expensive copying when starting background agents. Current source already uses bounded parallel copying and directory collapsing, but neither establishes that the reported Linux/WSL slowdown is resolved.

## Change summary

Copying additional files into background-agent worktrees causes substantial startup delays on Linux/WSL and Windows.

## Best solution

Measure file discovery and copying separately on representative Linux/WSL and Windows repositories, then address the demonstrated bottleneck without changing worktree isolation or which files are included. Existing parallelism and directory collapsing should be evaluated before assuming sequential copying is the cause.
