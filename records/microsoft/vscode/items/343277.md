# Issue #343277 — Private marketplace: workbench gallery requests send Electron's User-Agent, so the Marketplace answers 403

[https://github.com/microsoft/vscode/issues/343277](https://github.com/microsoft/vscode/issues/343277)

## Summary

The configured-marketplace header gap remains in current source: renderer requests explicitly discard User-Agent, and main-process reinjection covers only the product gallery and vsassets.io. Keep this open; the report supplies concrete reproduction steps and request captures.

## Change summary

Workbench requests to a configured private marketplace should carry VS Code's marketplace User-Agent rather than Electron's browser User-Agent.

## Best solution

Ensure configured-gallery requests receive the intended marketplace User-Agent through a main-process mechanism that remains correct across windows and restarts, while preserving default-gallery behavior and leaving unrelated requests unchanged.
