# Issue #340860 — Agent Host: generic ACP provider for the Agents window

[https://github.com/microsoft/vscode/issues/340860](https://github.com/microsoft/vscode/issues/340860)

## Summary

Generic ACP integration remains missing from the checked-out main branch, and an open contribution already addresses it. Keep this proposal open for a maintainer direction decision and review of that PR.

## Change summary

Allow configured ACP-compatible agent CLIs to run as providers in the Agents window.

## Best solution

Decide whether ACP integration belongs in a built-in provider or an extension registration API, then review https://github.com/microsoft/vscode/pull/340863 against that direction. Resolve the experimental enablement contract and explicitly separate initial provider support from native-session discovery.
