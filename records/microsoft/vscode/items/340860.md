## Summary

Thanks for the detailed proposal. This is a design/go-no-go question for the Agent Host owners, and an open PR (https://github.com/microsoft/vscode/pull/340863) already references it. A maintainer should decide on the direction (in-core provider vs. extension API) before anything else happens, so this stays open.

## Change summary

Add an experimental, off-by-default generic ACP (Agent Client Protocol) provider to the Agent Host so ACP-speaking CLI agents can be used in the Agents window.

## Best solution

Have the Agent Host owners decide whether generic ACP support belongs in core as an experimental provider or should be exposed through an extension registration API (https://github.com/microsoft/vscode/issues/325827). Then review or land the linked PR accordingly.
