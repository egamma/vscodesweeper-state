# Issue #255314 — Copilot Chat: No option to remove file chips above chat panel (missing "X" button)

[https://github.com/microsoft/vscode/issues/255314](https://github.com/microsoft/vscode/issues/255314)

## Summary

The per-file dismiss ("X") button for changed file chips above the chat input was removed and has not been restored on current main. The team mitigated by collapsing the list by default, but the ability to dismiss individual file entries is still missing — keeping open for the assignee to address.

## Change summary

Changed file chips above the Copilot Chat input no longer have an "X" button to remove them individually, so accepted/completed file entries persist and consume space.

## Best solution

Add a dismiss/remove action to the per-file toolbar (`ChatEditingWidgetModifiedFilesToolbar`) for file entries in the `Accepted` state, or provide a "clear all" action for session-file entries. The collapsible list mitigates but does not fully replace the ability to remove stale entries.
