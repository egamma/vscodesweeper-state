# Issue #299106 — File got deleted despite denying the tool call

[https://github.com/microsoft/vscode/issues/299106](https://github.com/microsoft/vscode/issues/299106)

## Summary

More information is required to distinguish a denied command executing incorrectly from a separate permitted tool deleting the same file. Current source cancels the denied invocation itself, while the reporter's follow-up says the agent may have used another authorized path.

## Change summary

Denying an agent's terminal command did not prevent the agent from subsequently deleting the targeted file.

## Best solution

Use the request log to identify the invocation that actually deleted the file. If that invocation bypassed a required confirmation, fix that tool's approval boundary; if it was independently permitted, consider clarifying in the confirmation UI that denial applies to the specific invocation rather than the agent's overall intent.
