# Issue #86223 — Proxy configuration doesn't allow URLs with port number AND pac files

[https://github.com/microsoft/vscode/issues/86223](https://github.com/microsoft/vscode/issues/86223)

## Summary

The `http.proxy` setting is designed for proxy server addresses (scheme://[auth@]host[:port]), not PAC file URLs with paths. The regex intentionally disallows path components because this setting specifies the proxy endpoint, not a PAC configuration URL. This is as-designed behavior.

## Change summary

Allow the `http.proxy` setting to accept PAC file URLs that include both a port number and a path (e.g., `https://user:password@proxy:8080/file.pac`).

## Best solution

Close as designed — the `http.proxy` setting is for proxy server addresses, not PAC file URLs. PAC configuration is handled at the OS level or via environment variables. If PAC support were added, it would need a dedicated `http.proxyPacUrl` setting rather than overloading the existing proxy address field.
