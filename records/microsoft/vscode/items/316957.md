# Issue #316957 — Beaker icon on the Remote tab is wierd

[https://github.com/microsoft/vscode/issues/316957](https://github.com/microsoft/vscode/issues/316957)

## Summary

The inconsistent icon treatment remains on current main: Remote alone has a beaker while neighboring workspace-picker tabs are text-only. This team-authored polish issue should stay open pending a decision on the tab icon policy.

## Change summary

Make the Remote workspace-picker tab visually consistent with the other tabs instead of showing an unexplained beaker icon.

## Best solution

Adopt one consistent tab treatment in the Agents Window workspace picker, preferably text-only unless each tab has a meaningful, recognizable icon; retain an understandable indication if Remote must still be marked experimental.
