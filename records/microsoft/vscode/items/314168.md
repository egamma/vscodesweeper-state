# Issue #314168 — Agents app modals have unexpected tab behavior in MacOS

[https://github.com/microsoft/vscode/issues/314168](https://github.com/microsoft/vscode/issues/314168)

## Summary

Team-filed accessibility bug — the Agent Customizations modal in the Agents window lacks a focus trap, so Tab cycles through background elements. No fix has landed on main; keeping open per team-author policy.

## Change summary

Opening the Agent Customizations modal in the Agents app allows Tab to reach UI elements behind the modal instead of trapping focus within it.

## Best solution

Add a focus trap to the Agent Customizations modal (the customizations editor overlay in `src/vs/sessions/`) so that Tab and Shift+Tab cycle only through focusable elements inside the modal. The automation dialog already uses a focus trap pattern (`src/vs/sessions/contrib/automations/browser/automationDialog.ts`) that could serve as a reference.
