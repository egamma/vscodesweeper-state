# Issue #314168 — Agents app modals have unexpected tab behavior in MacOS

[https://github.com/microsoft/vscode/issues/314168](https://github.com/microsoft/vscode/issues/314168)

## Summary

Still unfixed on main: the Agent Customizations modal in the Agents window lacks a focus trap, so Tab escapes the modal into background UI. No commits reference this issue, and no focus-trap logic exists in the customization views. The linked PR #314770 was confirmed by a team member not to address this.

## Change summary

Tabbing in the Agent Customizations modal escapes to background UI elements instead of being trapped within the modal.

## Best solution

Add a focus trap to the Agent Customizations modal/overlay so that Tab cycles only within the modal while it is open. The fix likely belongs in `src/vs/sessions/contrib/aiCustomizationTreeView/` or the sessions dialog/overlay infrastructure under `src/vs/sessions/browser/parts/`. The automation dialog (`src/vs/sessions/contrib/automations/browser/automationDialog.ts`) already has focus-trap awareness and could serve as a pattern.
