# Issue #337002 — Allow customizing the connected active editor tab outline in light and dark themes

[https://github.com/microsoft/vscode/issues/337002](https://github.com/microsoft/vscode/issues/337002)

## Summary

Fresh, team-authored feature request describing a real gap: the connected active-tab outline is only themeable in high-contrast (via focusBorder/contrastBorder), and no dedicated theme color exposes it for regular light/dark themes yet. Kept open per the maintainer's own filing; no existing color covers this today.

## Change summary

Expose a theme color for the connected active editor tab outline (Modern UI) in regular light/dark themes, not just high-contrast.

## Best solution

Introduce a new theme color (e.g. something like `modernUI.connectedTabBorder` / a variant distinguishing active vs inactive groups) consumed by connectedEditorTabs.css outside the `:is(.hc-black, .hc-light)` gate, falling back to the current tab-surface color when unset to preserve existing appearance.
