# Issue #244814 — Tests that are hidden by default

[https://github.com/microsoft/vscode/issues/244814](https://github.com/microsoft/vscode/issues/244814)

## Summary

The extension-controlled default visibility gap remains: existing hide actions require user interaction and do not provide the requested API. Keep this under discussion while testing API owners assess generalizability; neither a covering implementation nor a verified open canonical was found.

## Change summary

Allow extensions to hide test items from Test Explorer by default while retaining their editor gutter actions and testing integration.

## Best solution

Resolve whether default-hidden items are a generalizable Testing API capability, considering both the go:generate workflow and the additional tagged-test use case. Any accepted contract should preserve editor access and distinguish default visibility, user overrides, and bulk-run exclusion without expanding this into a new Task API.
