# Issue #337788 — Checks tab has inconsistent padding in the redesigned left-hand panel

[https://github.com/microsoft/vscode/issues/337788](https://github.com/microsoft/vscode/issues/337788)

## Summary

Real, low-risk visual polish item in the Agents window's redesigned Changes panel: the Checks section header doesn't line up with the file tree/rows once the panel's own padding is removed for the dock layout — worth keeping open as a bounded CSS fix.

## Change summary

In the redesigned left-hand session panel, the collapsible "Checks" section header has different left/right padding than the surrounding file-tree rows and toolbar, so its content doesn't line up with the rest of the panel.

## Best solution

Align `.ci-status-widget-header`'s horizontal padding (currently a flat `padding: 4px` in checksWidget.css) with whatever inset the file tree rows and files-header use in `dock-detail-panel` mode, where `.changes-view-body` padding is zeroed out (changesView.css lines 10-16).
