# Issue #346861 — Commit, refresh and more action buttons hidden until hover.

[https://github.com/microsoft/vscode/issues/346861](https://github.com/microsoft/vscode/issues/346861)

## Summary

The existing setting fully addresses header-action visibility, and the area maintainer explicitly confirmed this behavior is intentional. The separate concern about Copilot edits not appearing needs its own reproduction and Git log, as requested in the thread.

## Change summary

Keep Source Control header actions visible without hovering so Commit, Refresh, and More remain discoverable.

## Best solution

Preserve the shared hover/focus behavior and use workbench.view.alwaysShowHeaderActions for persistent visibility. Investigate any remaining automatic-refresh failure separately without treating it as intentional behavior.
