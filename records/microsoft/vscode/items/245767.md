# Issue #245767 — Support checking for updates without automatically downloading

[https://github.com/microsoft/vscode/issues/245767](https://github.com/microsoft/vscode/issues/245767)

## Summary

The requested separation of checking from downloading remains missing for explicit macOS update checks, but the older, verified-open issue https://github.com/microsoft/vscode/issues/137344 already tracks that exact behavior. Consolidate this request there; metered-connection support is only a partial workaround.

## Change summary

Allow users to check whether an update is available without downloading it until they explicitly consent.

## Best solution

Track the check-only capability in https://github.com/microsoft/vscode/issues/137344, preserving this report's request for download consent independent of whether the connection is metered.
