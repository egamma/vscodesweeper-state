# Issue #245767 — Support checking for updates without automatically downloading

[https://github.com/microsoft/vscode/issues/245767](https://github.com/microsoft/vscode/issues/245767)

## Summary

Valid feature request acknowledged by a team member (dmitrivMS) who confirmed the gap exists and expressed intent to address it. Metered-connection support added the underlying `checkForUpdateNoDownload` code path, but no user-facing setting exposes it for non-metered connections.

## Change summary

Allow users to check for updates without automatically downloading them, via an explicit setting or changed default behavior for the 'Check for Updates' command.

## Best solution

Expose a new `update.mode` value (or a separate setting like `update.downloadOnCheck`) that reuses the existing `checkForUpdateNoDownload` code path on macOS/Windows/Linux regardless of metered-connection status, so 'Check for Updates' only informs without downloading. The plumbing already exists in `updateService.darwin.ts` and `updateService.win32.ts`.
