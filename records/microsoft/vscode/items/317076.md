# Issue #317076 — Visible editor does not refresh document links until tab switch or reopen

[https://github.com/microsoft/vscode/issues/317076](https://github.com/microsoft/vscode/issues/317076)

## Summary

This is a confirmed extension API gap already classified for the Backlog: document-link providers cannot invalidate their results when external state changes.

## Change summary

Add a supported mechanism for extensions to refresh document links in an unchanged, visible document.

## Best solution

Add an optional change event to `DocumentLinkProvider`, analogous to code lenses and inlay hints, and have the editor link contribution recompute decorations when it fires.
