# Issue #271232 — Typescript signature help provider does not update the activeSignature while typing

[https://github.com/microsoft/vscode/issues/271232](https://github.com/microsoft/vscode/issues/271232)

## Summary

Still reproduces on main: the TypeScript signature help provider's `getActiveSignature` method unconditionally preserves the previously active signature on retrigger, overriding TypeScript's `selectedItemIndex` even when the server correctly identifies a different matching overload.

## Change summary

When typing arguments that match a different overload, the signature help tooltip stays on the original signature instead of switching to the correct one.

## Best solution

Fix `getActiveSignature` in `extensions/typescript-language-features/src/languageFeatures/signatureHelp.ts` to only preserve the previous signature when the user manually navigated (up/down arrows), not when TypeScript's server reports a different `selectedItemIndex`. The guard on line 55 (`context.isRetrigger`) is too broad — it should also check whether `info.selectedItemIndex` differs from the previous selection, and defer to the server when it does.
