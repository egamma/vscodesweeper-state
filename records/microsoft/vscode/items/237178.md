# Issue #237178 — Please add an option to have word wrap toggled off for every editor by default

[https://github.com/microsoft/vscode/issues/237178](https://github.com/microsoft/vscode/issues/237178)

## Summary

Valid, acknowledged feature request: the user wants wordWrapColumn-style wrapping to apply only when toggled on via Alt+Z, not by default on file open. alexdima understood and documented the ask in detail (comment 10). The gap is real and unimplemented on current main — this belongs in the Backlog.

## Change summary

Add an option so that editor.wordWrap modes like 'wordWrapColumn' or 'bounded' can start with wrapping OFF by default, activating only when Alt+Z is pressed.

## Best solution

Introduce a new setting (or extend the existing `editor.wordWrap` enum) that decouples the *type* of wrapping from the *initial state*. The toggle word wrap action in `src/vs/workbench/contrib/codeEditor/browser/toggleWordWrap.ts` already uses `wordWrapOverride2` to flip state — the implementation would need to set an initial transient override to 'off' when the new option is active, so Alt+Z toggles into the configured wrap mode (e.g. column 80) rather than viewport wrapping. The wrapping configuration lives in `src/vs/editor/common/config/editorOptions.ts`.
