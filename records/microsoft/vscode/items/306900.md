# Issue #306900 — Folders in Windows are based on Linux and modern Mac OS expectations

[https://github.com/microsoft/vscode/issues/306900](https://github.com/microsoft/vscode/issues/306900)

## Summary

Keep open as a request for Windows-appropriate handling of application-owned home directories. Existing relocation controls only partially cover the request, and the older folder-structure discussion does not establish coverage of both native hiding and .copilot.

## Change summary

Automatically hide the home-directory .vscode and .copilot folders on Windows, or place their contents under AppData.

## Best solution

Establish a Windows policy for the visibility and location of these application-owned directories while preserving existing data and launch compatibility. Coordinate the VS Code storage portion with https://github.com/microsoft/vscode/issues/3884, retaining the explicit .copilot and native Hidden-attribute requirements here.
