# Issue #306900 — Folders in Windows are based on Linux and modern Mac OS expectations

[https://github.com/microsoft/vscode/issues/306900](https://github.com/microsoft/vscode/issues/306900)

## Summary

Current behavior is deliberate rather than a broken Windows code path, but a real platform-integration question remains: whether these state directories should be hidden or relocated by default on Windows.

## Change summary

Hide or relocate the `.vscode` and `.copilot` home directories on Windows.

## Best solution

Decide whether Windows should receive platform-specific default locations or hidden attributes without breaking cross-tool compatibility. Existing relocation mechanisms (`--extensions-dir`/`VSCODE_EXTENSIONS` and `COPILOT_HOME`) should remain supported regardless of that decision.
