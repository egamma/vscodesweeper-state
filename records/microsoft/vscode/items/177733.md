# Issue #177733 — Watch variable window not wrapping lines

[https://github.com/microsoft/vscode/issues/177733](https://github.com/microsoft/vscode/issues/177733)

## Summary

This remains a well-supported backlog feature request: long values are still truncated in the Variables and Watch views, and the existing hover and panel-placement workarounds do not provide inline wrapping. The 101 community upvotes substantially exceed the backlog threshold, and neither closed related issue can serve as a duplicate canonical.

## Change summary

Allow long debugger variable and watch values to wrap, or otherwise expose their significant trailing content without mouse-dependent workarounds.

## Best solution

Add an opt-in wrapping mode for long values in the debugger Variables and Watch tree while preserving the current compact single-line presentation by default; separately clarify whether the Debug Console should share that behavior.
