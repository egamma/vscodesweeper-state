# Issue #266693 — Improve Manage Trusted Extensions Settings Dialog

[https://github.com/microsoft/vscode/issues/266693](https://github.com/microsoft/vscode/issues/266693)

## Summary

Keep open: the current dialog manages account access permissions but still does not show each extension's preferred account or let users change it inline. The existing account-preference command only partially addresses the request, and the verified related issues cover different behavior.

## Change summary

Display each extension's preferred account and allow account changes within the Manage Trusted Extensions dialog without opening a separate picker for every extension.

## Best solution

Provide a clear distinction between permission to access an account and the extension's preferred account, with preference visibility and editing available from the authentication management surface. Preserve the existing access controls and workspace preference semantics.
