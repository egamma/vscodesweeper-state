# Issue #202083 — Terminal cannot be dragged out to a new window directly

[https://github.com/microsoft/vscode/issues/202083](https://github.com/microsoft/vscode/issues/202083)

## Summary

This remains the canonical request for dragging a panel terminal directly into a new window. Current main provides a command but still lacks the requested drag-out behavior.

## Change summary

Allow a terminal tab in the bottom panel to be dragged directly into a new auxiliary window.

## Best solution

Extend the terminal tab drag-and-drop path in `terminalTabsList.ts` to recognize a drag ending outside the workbench and move the terminal into an auxiliary editor window, reusing the editor-tab window-detachment behavior where possible.

## Vision fit

- **Fit:** aligned
- **Reason:** Matching editor-tab drag behavior improves consistency in a core workbench workflow without adding persistent UI.
- **Evidence:** Public values favor simple, uniform UI interactions, and workbench layout flexibility is a durable theme.
