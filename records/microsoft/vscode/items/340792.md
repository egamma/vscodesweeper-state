[https://github.com/microsoft/vscode/issues/340792](https://github.com/microsoft/vscode/issues/340792)

## Summary

Keep open: the report supplies concrete triggers for MCP configuration failures and session-opening recovery, but neither defect is confirmed resolved. MCP editing has since gained a form, while the available checkout predates the reported build; the supplied steps suffice to retest both remaining failures.

## Change summary

Malformed or empty Copilot MCP configuration produces insufficiently actionable errors, and opening an unavailable Copilot CLI session can leave chat navigation unrecoverable without restarting.

## Best solution

Ensure MCP configuration failures identify the affected file and offer a repair path without overwriting existing configuration, and ensure a failed session open leaves session navigation and retry usable. Retest both paths against the newer configuration UI before determining which changes remain necessary.
