# Issue #280648 — Allow dragging chat editors to the chat panel

[https://github.com/microsoft/vscode/issues/280648](https://github.com/microsoft/vscode/issues/280648)

## Summary

Team-authored feature request, not yet implemented on main. The ChatEditorInput still lacks `toUntyped` and ChatDragAndDropType has no session enum value — the work outlined by commenters remains to be done.

## Change summary

Allow dragging chat editor tabs back into the chat panel to restore sessions there.

## Best solution

Implement `toUntyped` on `ChatEditorInput` (src/vs/workbench/contrib/chat/browser/chatEditorInput.ts), add a session drag type to `ChatDragAndDropType` in src/vs/workbench/contrib/chat/browser/widget/chatDragAndDrop.ts, and wire up `guessDropType`/`drop` to open the session in the panel. Comment #4 from @benibenj outlines the concrete steps.
