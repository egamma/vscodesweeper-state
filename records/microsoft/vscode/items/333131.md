# Issue #333131 — Agents window: unable to create PR when remote is not origin

[https://github.com/microsoft/vscode/issues/333131](https://github.com/microsoft/vscode/issues/333131)

## Summary

The reported failure remains in current main: creating a PR for a branch without an upstream still pushes to origin, even when the repository's remote has another name. Keep this correctly routed, team-authored bug open.

## Change summary

Agents window PR creation fails when a branch has no upstream and the repository has no remote named origin.

## Best solution

PR creation should use the appropriate configured GitHub remote for an unpublished branch and keep the push destination consistent with the PR repository. Preserve existing tracked-branch and fork behavior, and ensure push failures are visible to the user.
