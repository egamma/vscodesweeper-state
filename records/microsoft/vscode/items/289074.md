# Issue #289074 — Remove WebWorkerDescriptor Duplication (esmModuleLocation vs esmModuleLocationBundler)

[https://github.com/microsoft/vscode/issues/289074](https://github.com/microsoft/vscode/issues/289074)

## Summary

Team-authored engineering debt issue; the duplication between esmModuleLocation and esmModuleLocationBundler is still present on current main across all WebWorkerDescriptor call sites. Keeping open per policy.

## Change summary

Remove the need for maintaining both esmModuleLocation and esmModuleLocationBundler in WebWorkerDescriptor by using esbuild's esmUrlPlugin to rewrite paths at bundle time.

## Best solution

Implement the proposed esbuild esmUrlPlugin approach so that bundling rewrites the relative URL paths, eliminating the esmModuleLocationBundler field entirely from WebWorkerDescriptor and all call sites (~7 files).
