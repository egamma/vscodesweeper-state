# Issue #292892 — Code Review - doesn't well work with Claude

[https://github.com/microsoft/vscode/issues/292892](https://github.com/microsoft/vscode/issues/292892)

## Summary

The defect remains source-reproducible on current main: Code Review inserts the review comment as a completed request without an agent, while chat history excludes that request when Claude handles the follow-up. The issue should remain open and be routed to the chat review and Claude agent owners.

## Change summary

Opening a Code Review comment in the Chat Panel does not provide that comment as context when the follow-up is sent to Claude.

## Best solution

Define the inserted review comment as participant-independent context so the selected agent receives both the comment and the user's follow-up, while preserving normal participant-specific history isolation.
