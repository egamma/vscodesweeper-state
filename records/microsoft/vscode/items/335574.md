# Issue #335574 — Created plan is not run by "Start Implementing"->"Continue in Copilot"

[https://github.com/microsoft/vscode/issues/335574](https://github.com/microsoft/vscode/issues/335574)

## Summary

The defect remains source-reproducible on current main: the plan handoff's Continue in Copilot branch submits only the generic "Start implementation" prompt to the target agent and bypasses the existing conversation-import path that would carry the approved plan.

## Change summary

Continuing an approved Plan-mode handoff in Copilot starts an unrelated task instead of implementing the plan.

## Best solution

Route the Plan-mode Continue in Copilot handoff through the existing cross-session continuation path so the prior conversation, including the approved plan, is imported into the new Copilot session before the implementation prompt is submitted.
