# Issue #343904 — 'expand' focused item on small screens

[https://github.com/microsoft/vscode/issues/343904](https://github.com/microsoft/vscode/issues/343904)

## Summary

Keep open: current compaction follows available width and right-to-left ordering, not the focused picker. The linked merged PR adds neighboring improvements but does not implement this team-authored Backlog request.

## Change summary

On narrow new-session composers, expand the focused picker’s label while other pickers collapse to icons.

## Best solution

Make the focused new-session picker readable within the available width without losing access to neighboring controls. Agree how temporary focus expansion interacts with explicit icon-only preferences and the normally preserved workspace label.
