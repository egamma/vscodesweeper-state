# Issue #329955 — SDK `permissions`: Workspace path is not detected correctly

[https://github.com/microsoft/vscode/issues/329955](https://github.com/microsoft/vscode/issues/329955)

## Summary

Team-authored bug with a confirmed root cause and an open, not-yet-merged fix PR in the copilot-agent-runtime repo — this stays open until that PR lands and VS Code consumes the updated CLI/runtime.

## Change summary

Managed-settings workspace-root path selectors (e.g. `Edit(/managed-allow/**)`) are matched against the wrong internal session directory instead of the real workspace path, causing incorrect allow/ask/deny behavior for SDK permissions.

## Best solution

Land and merge https://github.com/github/copilot-agent-runtime/pull/15396 (the immutable managed workspace-root fix), then have VS Code consume the resulting @github/copilot CLI release; keep this issue open to track that consumption and the in-product regression test.
