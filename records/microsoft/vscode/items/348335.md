VS Code adoption would still require its own workspace-history integration after upstream support becomes available.
- **Reporter correction:** The author's follow-up on https://github.com/microsoft/vscode/issues/348335 explains that Plasma opens recent directories in the default file manager without directory MIME ownership. resources/linux/code.desktop confirms Exec=@@EXEC@@ %F and only application/x-@@NAME@@-workspace MIME registration; publishing entries alone does not fix folder launching.
