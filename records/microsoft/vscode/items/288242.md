# Issue #288242 — Currently active worktree more visible

[https://github.com/microsoft/vscode/issues/288242](https://github.com/microsoft/vscode/issues/288242)

## Summary

Keep open as an SCM feature request: current worktree entries distinguish worktree types, but do not persistently identify the active worktree. The reporter supplied the screenshot requested by the maintainer; the remaining question is which active-state semantics and presentation the SCM owner wants.

## Change summary

Make the currently active worktree easier to identify in the Source Control Repositories worktree list.

## Best solution

Provide a consistent, theme-aware active-worktree cue in the existing SCM list, with a non-color indication accessible to screen readers. First establish whether active means the SCM-selected repository, the active editor's repository, or the worktree opened in the window; arbitrary per-worktree colors need not be part of the solution.
