# Issue #241975 — Very large set of details in terminal suggestions for `Where-object`

[https://github.com/microsoft/vscode/issues/241975](https://github.com/microsoft/vscode/issues/241975)

## Summary

Keep open: current source still passes PowerShell's full command definition into suggestion details, without a concise parameter-set preview. The issue was reopened after the terminal maintainer accepted improving this presentation, superseding the initial out-of-scope decision.

## Change summary

Make terminal suggestion details for PowerShell commands such as Where-Object concise enough that repetitive parameter sets do not overwhelm the help view.

## Best solution

Provide a compact, readable command-syntax preview in terminal suggestions, following the maintainer's truncation direction without changing PowerShell's parameter-set semantics. Settle the preview limit and how users access omitted syntax before implementation.
