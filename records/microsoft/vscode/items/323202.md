# Issue #323202 — terminal.integrated.cwd:${fileDirname} confuses copilot

[https://github.com/microsoft/vscode/issues/323202](https://github.com/microsoft/vscode/issues/323202)

## Summary

Keep open: current source still allows command preparation to assume the workspace directory while a new agent terminal honors terminal.integrated.cwd. This also explains the reporter's follow-up: an explicit corrective cd can be removed against the assumed directory before the terminal starts elsewhere.

## Change summary

Keep Copilot terminal commands and command simplification consistent with the actual starting directory when terminal.integrated.cwd is ${fileDirname}.

## Best solution

Make the directory used for command preparation agree with the execution terminal, and preserve explicit directory changes unless they are redundant for that terminal. Retain ordinary user-terminal cwd behavior and existing foreground-session directory reuse.
