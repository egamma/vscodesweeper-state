# Issue #323202 — terminal.integrated.cwd:${fileDirname} confuses copilot

[https://github.com/microsoft/vscode/issues/323202](https://github.com/microsoft/vscode/issues/323202)

## Summary

The current source still permits the reported mismatch: preparation assumes the workspace root for a fresh terminal, while launch honors terminal.integrated.cwd, allowing a necessary cd prefix to be removed. Keep this open; the older background-terminal report does not cover the full settings-dependent behavior.

## Change summary

Copilot terminal commands use incorrect relative paths, and command simplification can discard a necessary directory change when terminal.integrated.cwd is ${fileDirname}.

## Best solution

Make the agent's initial-directory context and command-rewriting assumptions agree with the directory where its terminal actually starts. Decide whether agent terminals honor the configured cwd or deliberately use the workspace/session root, while ensuring explicit directory changes retain their meaning.
