# Issue #212812 — Clarify that highlighting non-basic ASCII characters is done for security

[https://github.com/microsoft/vscode/issues/212812](https://github.com/microsoft/vscode/issues/212812)

## Summary

The settings still omit the security rationale, although release documentation and a maintainer comment explicitly establish it. Keep this request under discussion: the related banner issues do not own the same settings-description improvement, and lack of upvotes is not grounds for a decline close.

## Change summary

Explain the security purpose of non-basic ASCII highlighting in its settings description, with a separate suggestion to show a warning even for a few highlighted characters.

## Best solution

Explain in the Unicode Highlight settings that highlighting helps reveal potentially deceptive characters, without implying that all non-ASCII text is malicious or that highlighting detects every attack. Treat the suggested always-visible warning as a separate product decision rather than silently changing banner thresholds or highlighting defaults.
