# Issue #229941 — Editor `z-index` challenges

[https://github.com/microsoft/vscode/issues/229941](https://github.com/microsoft/vscode/issues/229941)

## Summary

The editor still lacks a coherent stacking contract: current main assigns unrelated raw z-index values across many editor surfaces, while linked issues continue to demonstrate conflicting requirements. Keep this as the editor-wide debt umbrella; the older open sticky-scroll issue covers only one part of the broader inventory and hierarchy work.

## Change summary

Inventory editor stacking contexts and define consistent z-index assignments for the minimap, scrollbars, sticky scroll, zone widgets, and other overlays.

## Best solution

Document an editor-wide stacking hierarchy, distinguish DOM overlay stacking from model-decoration ordering, and make editor surfaces consume that shared contract. Validate representative conflicts involving sticky scroll, zone widgets, scrollbars, minimap, find/suggest, and widgets outside the editor.
