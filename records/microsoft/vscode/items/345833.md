[https://github.com/microsoft/vscode/issues/345833](https://github.com/microsoft/vscode/issues/345833)

## Summary

Keep open for investigation of Copilot SDK history persistence across container rebuilds. Current main uses a remote Agent Host and host-local Copilot storage; the supplied comparison steps suffice to retest, but source inspection cannot establish whether the history is deleted or merely no longer listed.

## Change summary

Preserve access to Copilot SDK conversations after rebuilding a devcontainer, matching Local harness session restoration.

## Best solution

Ensure SDK conversations and their Agent Host restoration metadata survive container replacement and remain discoverable afterward. First distinguish ephemeral container storage loss from a session-list or connection-identity restoration failure; this remains an in-scope Copilot issue.
