# Issue #345833 — Copilot SDK agent sessions are lost after rebuilding a devcontainer

## Summary

Keep open: the maintainer explains that rebuilding deletes the container-resident SDK sessions, but does not decline persistence improvements. Current main still uses execution-host storage; the supplied comparison steps suffice to retest, although a container rebuild was not executed.

## Change summary

Preserve Copilot SDK conversation history across devcontainer rebuilds, matching the reported Local harness behavior.

## Best solution

Establish a rebuild-safe persistence contract for container-hosted Copilot SDK sessions, covering both provider-native conversation data and Agent Host metadata. Coordinate the Agent Host and container lifecycle boundaries rather than treating a restored list entry alone as recovery.
