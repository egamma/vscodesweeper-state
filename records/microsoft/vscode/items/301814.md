# Issue #301814 — Primary/secondary sidebar change

[https://github.com/microsoft/vscode/issues/301814](https://github.com/microsoft/vscode/issues/301814)

## Summary

Verified duplicate: the older open canonical issue already requests placing the primary and secondary sidebars on the same side, specifically for using AI Chat alongside other views. This report contributes an important low-vision and glare-related use case that should be carried into that discussion.

## Change summary

Allow Chat and extension views to remain accessible on the left by permitting the primary and secondary sidebars to occupy the same side.

## Best solution

Consolidate the layout work on https://github.com/microsoft/vscode/issues/281828 and ensure its design accounts for users who cannot comfortably read content on one side of the display. The existing Move View command remains a partial workaround when simultaneous visibility is not required.

- **same underlying work:** This report's trigger is moving Chat to the left, which currently moves the primary sidebar and its extension views to the right. - **partial existing capability:** The Chat view is movable (`canMoveView: true` in src/vs/workbench/contrib/chat/browser/chatParticipant.contribution.ts), and `workbench.action.moveView` in src/vs/workbench/browser/actions/layoutActions.ts can create a primary-side-bar entry.
