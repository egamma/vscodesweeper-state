# Issue #182011 — Copy & Paste support for Simple Browser

[https://github.com/microsoft/vscode/issues/182011](https://github.com/microsoft/vscode/issues/182011)

## Summary

The Simple Browser is no longer available on desktop (Electron) as of commit b4018e320b8 (March 2026) — it was replaced by the integrated browser. Since the reported issue only affected Electron builds (comment 15 confirmed web was fine), the problem is effectively resolved by the architectural change.

## Change summary

Copy and paste (Cmd+C, context menu) did not work in the Simple Browser on desktop due to cross-origin iframe event isolation.

## Best solution

Close as completed — the Simple Browser command is now gated to `isWeb` only, and on desktop the integrated browser replaces it. The cross-origin iframe clipboard issue that affected the old Simple Browser on Electron no longer applies to the shipping desktop experience.
