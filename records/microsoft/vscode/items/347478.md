# Issue #347478 — Agents Window: snooze a session

[https://github.com/microsoft/vscode/issues/347478](https://github.com/microsoft/vscode/issues/347478)

## Summary

Keep open for the scheduled 1.150.0 work. Inbox already supports snoozing, but snoozing outside Inbox and a separate Snoozed group remain distinct requirements whose scope the maintainer has asked the author to clarify.

## Change summary

Allow sessions to be snoozed into a Snoozed group above Done, like snoozing email.

## Best solution

Resolve whether snoozing should work across all session-list grouping modes and whether Snoozed should be separate from On hold, then extend the existing list-owned snooze behavior to that agreed scope.
