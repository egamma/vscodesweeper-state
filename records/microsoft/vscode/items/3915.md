# Issue #3915 — Render errors & warnings in gutter

[https://github.com/microsoft/vscode/issues/3915](https://github.com/microsoft/vscode/issues/3915)

## Summary

The requested built-in gutter indicators remain absent on current main, and existing extensions do not resolve coexistence with breakpoints. This team-authored Backlog request also has 106 community upvotes, so it should remain open.

## Change summary

Optionally display error and warning indicators in the editor gutter for easier file scanning.

## Best solution

Add an optional editor diagnostic-gutter mode in the marker decoration path, with themed severity icons and defined coexistence with breakpoint and extension glyphs. The design should use the editor's glyph-margin lanes rather than allowing diagnostic marks to overwrite other gutter decorations.
