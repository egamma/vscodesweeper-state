# Issue #78893 — [html] autoclose not working properly with multicursor

[https://github.com/microsoft/vscode/issues/78893](https://github.com/microsoft/vscode/issues/78893)

## Summary

The defect remains present on current main: HTML auto-insertion computes one closing-tag snippet from the final multicursor change and inserts that same snippet at every cursor. Keep this open while the related Volar integration PR remains an active implementation candidate.

## Change summary

HTML auto-closing should generate the matching closing tag independently at each cursor instead of repeating one cursor's tag everywhere.

## Best solution

Ensure each multicursor content change receives position-specific HTML tag completion, with a regression test covering different tag names. Review whether https://github.com/microsoft/vscode/pull/171547 provides that behavior before landing a competing fix.
