# Issue #248759 — Sidebar "Run" Button Fails with command not found: npm on Linux (works on macOS)

[https://github.com/microsoft/vscode/issues/248759](https://github.com/microsoft/vscode/issues/248759)

## Summary

Keep open for a focused Linux shell-environment investigation. Current main explicitly supplies shell-resolved environment to tasks, but that does not establish that this launch-dependent failure is fixed; the report's GUI-versus-CLI comparison and Run-versus-Debug steps suffice to retest.

## Change summary

NPM Scripts Run cannot find version-manager-installed npm on Linux when VS Code starts from the desktop, although manual terminal execution and Debug work.

## Best solution

Identify where npm's PATH entry is lost between GUI startup, shell-environment resolution, and task launch, then preserve the intended resolved environment for npm tasks. Do not assume that making all tasks interactive or login shells is the correct solution.
