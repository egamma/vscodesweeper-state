# Issue #272233 — Powershell 7 Ctrl + G from Terminal fails for paths with space

[https://github.com/microsoft/vscode/issues/272233](https://github.com/microsoft/vscode/issues/272233)

## Summary

Still reproduces on main: the Ctrl+G 'go to recent directory' quick pick builds `cd ${preparePathForShell(path)}`, but for PowerShell paths with spaces `preparePathForShell` returns `& 'path'`, producing invalid `cd & 'path'`. A team member reactivated this with a concrete fix approach; it remains open.

## Change summary

Ctrl+G in terminal produces an invalid `cd & 'path with space'` command for PowerShell when the selected directory path contains spaces.

## Best solution

In `terminalRunRecentQuickPick.ts` (line ~355), the CWD path should not go through `preparePathForShell` (which adds `& ` for PowerShell). Instead, use `getUriLabelForShell` to get the display-format path, then apply CWD-appropriate quoting (single-quoting without the `& ` prefix) before embedding it in `cd`. dmitrivMS's comment 3 outlines this approach.
