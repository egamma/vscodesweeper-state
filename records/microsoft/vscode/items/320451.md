# Issue #320451 — Background send: Holding alt should show UX that pressing enter will do a background send

[https://github.com/microsoft/vscode/issues/320451](https://github.com/microsoft/vscode/issues/320451)

## Summary

Team-authored polish request that remains unimplemented on main. The background send feature exists, but there is no dynamic visual indicator when the user holds Alt to signal that Enter will perform a background send. Keeping open.

## Change summary

Show a visual UX indicator on the send button (or similar) when the user holds Alt, signaling that pressing Enter will start a background send.

## Best solution

Add a keydown/keyup listener for Alt in the new-chat input widget (`src/vs/sessions/contrib/chat/browser/newChatInput.ts`) that dynamically updates the send button's label, icon, or tooltip to indicate background-send mode while Alt is held. The static tooltip hint already exists (line 646); this would make it a live, dynamic affordance.
