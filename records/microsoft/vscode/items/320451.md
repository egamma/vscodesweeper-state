# Issue #320451 — Background send: Holding alt should show UX that pressing enter will do a background send

[https://github.com/microsoft/vscode/issues/320451](https://github.com/microsoft/vscode/issues/320451)

## Summary

The discoverability gap remains on current main: Alt+Enter performs a background send, but holding Alt does not change the visible Send control to communicate that alternate action. This team-authored On Deck polish item should remain open.

## Change summary

Make the new-session composer visibly communicate that Enter will send in the background while Alt is held.

## Best solution

Use the established modifier-aware chat action pattern so the Send control changes its visible and accessible presentation while Alt is held, without changing foreground or background send semantics.
