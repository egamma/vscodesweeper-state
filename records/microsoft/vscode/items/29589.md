# Issue #29589 — Auto indent on pasting does not satisfy indentation for braces in JS/TS

[https://github.com/microsoft/vscode/issues/29589](https://github.com/microsoft/vscode/issues/29589)

## Summary

The reported defect remains in the current paste-indentation path: an indentation offset computed for the second line is also applied to the closing brace. Keep this issue as the canonical report; maintainers explicitly consolidated two related reports here.

## Change summary

Pasting unindented JavaScript or TypeScript should indent block contents without incorrectly indenting their closing braces.

## Best solution

Correct the editor's paste-indentation behavior for the supplied function and nested-class examples while preserving already-correct relative indentation, comments, strings, and non-leading whitespace. Keep this distinct from the broader exploration of formatter-backed indentation.
