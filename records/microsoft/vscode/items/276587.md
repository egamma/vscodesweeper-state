# Issue #276587 — Restore/Undo last message doesn't update todos

[https://github.com/microsoft/vscode/issues/276587](https://github.com/microsoft/vscode/issues/276587)

## Summary

Keep open: current source restores workspace edits and disables undone requests, but does not restore the session's TODO state. The reported steps are sufficient, and the inspected related issues do not own this rollback defect.

## Change summary

Restoring a chat checkpoint or undoing a request should also revert TODO changes made by the undone work.

## Best solution

Make the active session TODO state correspond to the restored conversation point, including after stopping an incomplete request. Ensure rendering historical tool invocations cannot overwrite that restored state, while preserving existing workspace-edit restoration.
