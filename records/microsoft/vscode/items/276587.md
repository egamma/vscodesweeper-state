# Issue #276587 — Restore/Undo last message doesn't update todos

[https://github.com/microsoft/vscode/issues/276587](https://github.com/microsoft/vscode/issues/276587)

## Summary

Still reproduces on main: the ChatTodoListService stores todos in a memento independently of the chat model's request history, so when removeRequest undoes a turn, the todo state is never reverted.

## Change summary

Using restore/undo on a chat message does not revert the TODO list progress that the undone turn caused.

## Best solution

When a request is removed (ChatRequestRemovalReason.Removal or Resend), the todo list for that session should be rolled back to its state before the removed turn's tool invocations executed. This likely requires snapshotting the todo list before each turn's ManageTodoListTool calls and restoring it on undo, coordinated between chatServiceImpl.ts and chatTodoListService.ts.
