Keep this as the canonical report for Linux editor freezes after copying a filename from the native Save As dialog. A maintainer and independent users confirmed the reproduction, the reporter confirmed persistence in 1.106.2, and no verified fix or older matching canonical was found.

## Change summary

Pasting a filename copied from a dismissed native Save As dialog freezes VS Code on Linux.

## Best solution

Make the native-dialog-to-editor clipboard flow complete without freezing, while preserving normal paste handlers and resource pasting. Reproduce on current Linux first and isolate the blocking operation across the editor paste controller, native clipboard service, and Electron before choosing the fix.
