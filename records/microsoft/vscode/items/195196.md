# Issue #195196 — VS Code in Linux freezes when copying file name from file dialog and pasting it into the editor

[https://github.com/microsoft/vscode/issues/195196](https://github.com/microsoft/vscode/issues/195196)

## Summary

Confirmed freeze bug on Linux when pasting clipboard content copied from a native file dialog into the editor. Still reproduces as of Nov 2025 (v1.106.2), no fix commit found on main. This is the canonical issue — other reports (211981, 246824) were closed as duplicates of it.

## Change summary

VS Code freezes on Linux when text copied from a native file dialog (e.g. Save As) is pasted into the editor.

## Best solution

Investigate the interaction between the native GTK/KDE file dialog clipboard content and the editor paste handler on Linux. The workaround (enabling Simple Dialog) suggests the native dialog places clipboard data in a format that causes the paste handler to hang. The fix likely lives in the clipboard read path (src/vs/platform/clipboard/ or src/vs/editor/contrib/clipboard/) — a timeout or format validation when reading clipboard data that originated from a native dialog could prevent the freeze.
