# Issue #212334 — Terminal file link detection can't detect paths containing spaces

[https://github.com/microsoft/vscode/issues/212334](https://github.com/microsoft/vscode/issues/212334)

## Summary

Still reproduces on current main — the suffix-anchored link regex in `terminalLinkParsing.ts` excludes `\s`, so paths with embedded spaces are truncated at the first space. An open PR (#316927) is in flight to fix this; keeping open pending its review and merge.

## Change summary

Terminal file link detection truncates paths at the first space character, so paths like `/Users/me/My Project/file.ts:10` only highlight the trailing segment after the last space.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/316927, which extends `detectLinksViaSuffix` to emit an additional candidate that walks leftward through whitespace for absolute paths, validated by filesystem resolution. The fix is localized to `terminalLinkParsing.ts`.
