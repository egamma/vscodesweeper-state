# Issue #154988 — List widget - add api for a list item to specify not to receive focus

[https://github.com/microsoft/vscode/issues/154988](https://github.com/microsoft/vscode/issues/154988)

## Summary

Team-authored feature request for a list widget API allowing items to opt out of receiving focus. No implementation found on current main — the list widget has no per-item focusability API. The SCM view works around this today with custom focus management. Keeping open as a valid enhancement request.

## Change summary

Allow list widget items to declare they should not receive focus, useful for the SCM view's commit input field and action button rows.

## Best solution

Add an optional per-item focusability predicate to the list/tree widget API (likely in `src/vs/base/browser/ui/list/listWidget.ts` or `src/vs/base/browser/ui/tree/abstractTree.ts`) so items like the SCM commit input can declaratively skip list-level focus, removing the need for custom workarounds in `scmViewPane.ts`.
