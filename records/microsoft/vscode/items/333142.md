# Issue #333142 — Cursor disappearing in edit workspace

[https://github.com/microsoft/vscode/issues/333142](https://github.com/microsoft/vscode/issues/333142)

## Summary

Cursor disappearing while hovering the editor with hardware/GPU compositing is a known class of Electron/Chromium GPU-rendering quirk — the confirmed workaround is the existing `disable-hardware-acceleration` argv flag, which points to the root cause living in the GPU compositor, not VS Code's own rendering code.

## Change summary

The mouse cursor becomes invisible while hovering over the editor area, reappearing once moved outside it.

## Best solution

Keep this open as an upstream GPU/hardware-acceleration rendering issue; two commenters confirm the same symptom is resolved by `disable-hardware-acceleration`, so the underlying defect is in Electron/Chromium's GPU compositor rather than something traceable in this repo's source.
