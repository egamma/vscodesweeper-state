[https://github.com/microsoft/vscode/issues/328764](https://github.com/microsoft/vscode/issues/328764)

## Summary

Keep open to investigate why disabling Modern UI did not persist into a new window. The setting now defaults to true and supports experiment-controlled defaults, so configuration behavior has moved since the report; the supplied enable-disable-new-window steps suffice to retest.

## Change summary

Modern UI becomes enabled in a new window after the user previously turned it off.

## Best solution

Ensure an explicit Modern UI opt-out remains effective across new windows in the same profile and configuration scope. Investigate whether the Settings editor discarded a default-equal false choice, rather than treating this as general opposition to the UI redesign.
