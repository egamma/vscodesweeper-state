# Issue #300116 — Agent using gh CLI always opens alt buffer

[https://github.com/microsoft/vscode/issues/300116](https://github.com/microsoft/vscode/issues/300116)

## Summary

Still open on main: the in-editor chat agent tool terminal path (`toolTerminalCreator.ts`) does not set `GH_PAGER` to suppress the pager, so `gh` CLI commands open the alt buffer. The agent host path (`agentHostTerminalManager.ts`) already sets `GH_PAGER=''` but the in-editor path does not. An open WIP PR (#300525) exists but has not merged.

## Change summary

The `gh` CLI opens the alt buffer (pager) when run by an agent in the terminal, causing chaotic output.

## Best solution

Add `GH_PAGER: 'cat'` (or `''`) to the env block in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/toolTerminalCreator.ts` alongside the existing `GIT_PAGER` entry, mirroring what `agentHostTerminalManager.ts` already does. The open PR https://github.com/microsoft/vscode/pull/300525 is the right vehicle — land it once ready.
