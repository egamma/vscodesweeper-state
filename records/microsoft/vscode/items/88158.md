# Issue #88158 — Provide a way to debug extensions to hint syntax for advanced breakpoints

[https://github.com/microsoft/vscode/issues/88158](https://github.com/microsoft/vscode/issues/88158)

## Summary

The adapter-specific hint capability remains absent on current main, while the generic UI guidance only partially addresses the request. This team-authored, under-discussion feature request should remain open pending a debug/DAP design decision.

## Change summary

Allow debug adapters to provide syntax guidance or documentation for hit conditions and logpoints in the advanced-breakpoint editor.

## Best solution

Decide whether advanced-breakpoint syntax should be fully standardized by DAP or whether adapters may advertise concise, localizable help metadata; if adapter-specific syntax remains valid, surface that metadata without replacing the existing generic guidance.
