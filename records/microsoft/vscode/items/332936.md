# Issue #332936 — Agents can not output more than 500 characters in task_complete

[https://github.com/microsoft/vscode/issues/332936](https://github.com/microsoft/vscode/issues/332936)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/332898 reports the same Agents window behavior, where a long task-completion response is saved to a temporary file and only its first 500 characters are shown.

## Change summary

Keep long `task_complete` summaries readable in the chat UI instead of replacing them with a temporary-file notice and a 500-character preview.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/332898 and preserve the complete `task_complete` summary as user-facing chat Markdown, without routing it through large tool-output offloading.
