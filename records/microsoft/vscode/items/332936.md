# Issue #332936 — Agents can not output more than 500 characters in task_complete

[https://github.com/microsoft/vscode/issues/332936](https://github.com/microsoft/vscode/issues/332936)

## Summary

Confirmed by two independent users on the latest stable build: when the Copilot CLI agent's task_complete summary exceeds ~500 characters, it gets treated as generic tool output and offloaded to a temp file instead of staying visible in chat. The truncation logic isn't in VS Code's own `taskCompleteTool.ts` (which just passes the summary through), so it most likely lives in the `@github/copilot-sdk` dependency that drives the Copilot CLI agent session — routing to the team that owns that integration rather than closing.

## Change summary

Copilot CLI agent completion summaries longer than ~500 characters are truncated/offloaded to a file instead of shown in the chat UI.

## Best solution

Whoever owns the Copilot CLI / `@github/copilot-sdk` agent-session integration (src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts consumes that SDK) should ensure task_complete's user-facing summary is exempted from the generic large-tool-output-to-file handling, or expose a setting to raise/disable that threshold specifically for completion summaries.
