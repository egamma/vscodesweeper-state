# Issue #302387 — Submenu item focus suddenly disappears

[https://github.com/microsoft/vscode/issues/302387](https://github.com/microsoft/vscode/issues/302387)

## Summary

Valid bug — the mouseover handler on the menu's actionsList uses the bubbling phase, causing a focus conflict when the mouse moves quickly between submenu items. An open PR (#302389) proposes the fix but hasn't merged yet.

## Change summary

Submenu items briefly gain then immediately lose focus when the mouse moves quickly between menu items due to mouseover event bubbling.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/302389 which switches the mouseover listener to capture phase, resolving the parent-child focus conflict in `src/vs/base/browser/ui/menu/menu.ts`.
