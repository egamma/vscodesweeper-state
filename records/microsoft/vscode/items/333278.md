# Issue #333278 — Duplicate model entries in Language Models management view ("Sprachmodelle") – second group uses versioned model ID (@1.0)

[https://github.com/microsoft/vscode/issues/333278](https://github.com/microsoft/vscode/issues/333278)

## Summary

Confirmed bug: Manage Language Models groups models by provider group id but displays a shared group label ('Copilot'), so distinct agent-host-backed providers (regular Copilot Chat vs. Claude agent host vs. Copilot CLI agent host) render as separate, identically-labeled groups. An open PR (#335363) already targets exactly this, so this should stay open pending that PR landing rather than being closed now.

## Change summary

Manage Language Models shows the same models twice under two separate 'Copilot' provider groups, one using a plain model ID and the other an '@1.0'-suffixed agent-host model ID.

## Best solution

Land (or iterate on) https://github.com/microsoft/vscode/pull/335363, which preserves agent/host identity in the group label (e.g. 'ChatGPT: Codex [Local]' vs '[WSL: Ubuntu]') so groups sharing the 'Copilot' vendor name but backed by different agent hosts are visually distinguishable instead of appearing as unlabeled duplicates.
