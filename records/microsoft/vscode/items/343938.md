# Issue #343938 — Open worktree cleanup calculates evertytime

[https://github.com/microsoft/vscode/issues/343938](https://github.com/microsoft/vscode/issues/343938)

## Summary

Keep open: the cleanup service already caches measurements, but opening the editor explicitly bypasses that cache. This team-authored request identifies a real improvement; the freshness behavior needs agreement because an existing test deliberately requires fresh measurements on every opening.

## Change summary

Avoid recalculating worktree storage every time Open Worktree Cleanup is opened.

## Best solution

Make repeated openings reuse recent worktree measurements while retaining a clear way to obtain current sizes and cleanup status. Agree on the acceptable freshness behavior before changing the editor's existing fresh-on-open contract.
