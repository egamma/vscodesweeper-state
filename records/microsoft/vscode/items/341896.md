# Issue #341896 — Copilot's background `git fetch --dry-run` runs with an empty environment, ignores user git config, and triggers macOS Keychain prompts

[https://github.com/microsoft/vscode/issues/341896](https://github.com/microsoft/vscode/issues/341896)

## Summary

The environment-replacement defect remains in current source: Copilot's fallback fetch discards inherited Git configuration variables even for an unsupported HTTPS remote. Keep this report open; the related SSH-agent reports do not cover the same observable failure.

## Change summary

Copilot repository discovery ignores the inherited Git environment and unexpectedly invokes macOS Keychain credentials instead of the user's configured helper.

## Best solution

Ensure background repository discovery respects the user's Git environment and credential configuration without requiring AI features to be disabled. Preserve supported remote discovery; treat broader changes to unattended fetching separately.
