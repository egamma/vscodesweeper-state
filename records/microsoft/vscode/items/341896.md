[https://github.com/microsoft/vscode/issues/341896](https://github.com/microsoft/vscode/issues/341896)

## Summary

The environment-replacement defect remains in current main: Copilot's remote-resolution fallback supplies only GIT_SSH_COMMAND, discarding the inherited environment. Keep this open; the source confirms the defect, although the resulting macOS Keychain dialog was not independently exercised.

## Change summary

Copilot's background remote-discovery fetch discards the inherited environment, potentially bypassing the user's Git configuration and triggering unwanted credential prompts.

## Best solution

Make Copilot's remote-discovery subprocess respect the inherited Git environment while retaining noninteractive SSH discovery. Address the confirmed environment defect independently of the optional proposal to restrict fallback fetches or introduce a setting.
