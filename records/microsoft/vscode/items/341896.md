# Issue #341896 — Copilot's background `git fetch --dry-run` runs with an empty environment, ignores user git config, and triggers macOS Keychain prompts

[https://github.com/microsoft/vscode/issues/341896](https://github.com/microsoft/vscode/issues/341896)

## Summary

Thanks for the detailed report. The source confirms the diagnosis: the fallback `git fetch --dry-run` passes `env` containing only GIT_SSH_COMMAND, which replaces the whole environment (no HOME/PATH), so user git config and credential helpers are ignored.

## Change summary

Copilot's fallback `git fetch --dry-run` runs with a replaced environment, ignoring user git config and triggering macOS Keychain prompts.

## Best solution

Spread process.env into the env passed to exec in getGithubRemoteFromSshConfig, so user git config and credential helpers apply. Optionally also set GIT_TERMINAL_PROMPT=0.
