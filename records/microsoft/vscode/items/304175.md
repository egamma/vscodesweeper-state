# Issue #304175 — Apply/try action from the customization

[https://github.com/microsoft/vscode/issues/304175](https://github.com/microsoft/vscode/issues/304175)

## Summary

Valid feature request from a team member. A 'Run Prompt' action exists in the customization view but is scoped only to prompts — agents, instructions, and skills lack an equivalent apply/try action. The gap is real and the request remains unimplemented.

## Change summary

Add a run/try/apply action in the AI customization view for all customization types (agents, instructions, skills), not just prompts.

## Best solution

Extend the existing 'Run Prompt' pattern in `aiCustomizationManagement.contribution.ts` to cover agents, instructions, and skills — each type should have a contextual action that closes the customization view and sets up chat in the appropriate mode. The `when` clause at line 504 currently restricts the menu item to `PromptsType.prompt`; broadening it and adapting the run command per type is the natural path.
