# Issue #270016 — Selected launch option changes when more than one source exists and either changes

[https://github.com/microsoft/vscode/issues/270016](https://github.com/microsoft/vscode/issues/270016)

## Summary

The bug remains source-reproducible on current main: any `launch` configuration change reselects a launch source from the last active workspace root instead of preserving the user's still-valid workspace-file or folder selection.

## Change summary

Editing either of two launch configuration sources unexpectedly switches the selected debug configuration to a folder launch.

## Best solution

Preserve the selected launch source and configuration name when a `launch` change leaves that selection valid, while retaining the existing fallback behavior when the selected source or configuration has actually disappeared.
