# Issue #327380 — Allow attaching screenshots/videos to issue reporter from clipboard/drag and drop

[https://github.com/microsoft/vscode/issues/327380](https://github.com/microsoft/vscode/issues/327380)

## Summary

Team-authored feature request (never judgment-closed) describing a real, unimplemented gap: the issue reporter's Attachments step only supports capturing new screenshots/recordings, with no clipboard-paste or drag-and-drop path for existing images.

## Change summary

Let users attach an existing screenshot/video to the issue reporter via clipboard paste or drag-and-drop, not just via the in-app capture flow.

## Best solution

Add paste (clipboard) and drop event handlers to the Attachments step container in src/vs/workbench/contrib/issue/browser/issueReporterOverlay.ts, feeding into the existing addScreenshot()/attachment pipeline (respecting MAX_ATTACHMENTS) alongside the current camera-capture button.
