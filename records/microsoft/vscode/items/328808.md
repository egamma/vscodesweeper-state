# Issue #328808 — Why are there 3 commands for Dictation in the Editor/Terminal/Chat?

[https://github.com/microsoft/vscode/issues/328808](https://github.com/microsoft/vscode/issues/328808)

## Summary

Keep open: current source still exposes surface-specific dictation commands rather than one focus-aware entry point. A maintainer endorsed improving this behavior, and the related issues inspected do not own the same request.

## Change summary

Provide one Start Dictation command that targets the focused editor, terminal, or chat input instead of unexpectedly dictating into another surface.

## Best solution

Provide a consistent, focus-aware dictation entry point across editor, terminal, and chat, with an explicit policy for invocation from the Command Palette or when no supported input has focus. Decide how existing surface-specific commands and keybindings remain available before implementation.
