# Issue #328808 — Why are there 3 commands for Dictation in the Editor/Terminal/Chat?

[https://github.com/microsoft/vscode/issues/328808](https://github.com/microsoft/vscode/issues/328808)

## Summary

Team-authored design discussion (author TylerLeonhardt, MEMBER) about consolidating three separate dictation entry points (editor, terminal, chat) into one focus-aware command; a fellow maintainer already agreed it's a historical artifact worth improving, but no fix exists yet, so this stays open.

## Change summary

Consolidate the editor, terminal, and chat dictation commands into a single 'Start Dictation' command that targets whatever has active focus, instead of three separate commands that can be triggered from any context.

## Best solution

Design a unified dictation entry point (likely in a shared speech/dictation service consumed by src/vs/workbench/contrib/codeEditor/browser/dictation/editorDictation.ts, src/vs/workbench/contrib/terminalContrib/voice/browser/terminalVoiceActions.ts, and src/vs/workbench/contrib/chat/browser/actions/chatSpeechToTextActions.ts) that dispatches based on current focus rather than exposing three always-available commands.
