# Issue #238214 — Jupyter Notebook: Affordance to display cell output of long cells

[https://github.com/microsoft/vscode/issues/238214](https://github.com/microsoft/vscode/issues/238214)

## Summary

Valid feature request acknowledged by the notebook team (rebornix confirmed the pain point). While viewport-height capping of cell editors was added (bf56edffb59), no specific affordance to display cell output alongside a long cell while editing has been implemented. Stays open in Backlog.

## Change summary

Request for a design affordance to display notebook cell output while editing long cells that exceed the viewport.

## Best solution

Implement a sticky or floating output preview for long notebook cells — likely in the notebook cell parts system (src/vs/workbench/contrib/notebook/browser/view/cellParts/). The viewport-limiting work in codeCell.ts is a foundation, but a deliberate output-visibility mechanism (pinned output panel, split view, or sticky output region) is still needed.
