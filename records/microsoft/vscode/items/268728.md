Still reproduces on current main — the parameter hints model does not update the active overload when typed arguments narrow the overload set. An open PR (https://github.com/microsoft/vscode/pull/320980) already targets this issue with a fix.

## Change summary

Signature help for TypeScript function overloads does not switch to the matching overload as the user types arguments that narrow the candidate set.

Review and land the open PR https://github.com/microsoft/vscode/pull/320980, which fixes the active overload selection in the parameter hints model. The fix is localized to `src/vs/editor/contrib/parameterHints/browser/parameterHintsModel.ts`.
