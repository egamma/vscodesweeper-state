# Issue #327937 — Feature Request: Export /compact session summary to a physical workspace file for deterministic context curation

[https://github.com/microsoft/vscode/issues/327937](https://github.com/microsoft/vscode/issues/327937)

## Summary

The reviewed compaction and export commands do not provide a summary-only Markdown file for user curation and fresh-session handoff. Keep this request open for product consideration; the verified related issues do not own the same requested capability.

## Change summary

Provide an explicit command to save a compacted conversation summary as editable workspace Markdown for reuse in a fresh chat.

## Best solution

Consider a user-invoked summary export in the Copilot compaction and chat-export surfaces, with an explicit destination and no automatic clearing of the original session. Treat editable context handoff as the goal, without promising cache savings or deterministic model behavior.
