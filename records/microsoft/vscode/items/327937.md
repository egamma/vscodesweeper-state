# Issue #327937 — Feature Request: Export /compact session summary to a physical workspace file for deterministic context curation

[https://github.com/microsoft/vscode/issues/327937](https://github.com/microsoft/vscode/issues/327937)

## Summary

A real capability gap remains: VS Code can export the full chat and maintain internal memory, but it cannot expose `/compact` output as a reviewable Markdown handoff artifact. Route this new request to chat summarization.

## Change summary

Add a command that writes a compacted session summary to a workspace Markdown file for review and reuse in a fresh chat.

## Best solution

Expose the `/compact` summary as a reviewable artifact with an explicit save-to-workspace action, preserving the existing compaction behavior while enabling curated fresh-session handoffs.
