# Issue #293468 — weird zooming behavior in mermaid editor

[https://github.com/microsoft/vscode/issues/293468](https://github.com/microsoft/vscode/issues/293468)

## Summary

Keep open: the current Mermaid editor wheel handler still contains a scale calculation that can collapse the diagram to minimum zoom in one downward wheel event. The reporter supplied the requested Windows and mouse details; this team-authored report has neither a verified fixing commit nor a qualifying older duplicate.

## Change summary

Ctrl+mousewheel zoom-out in a Mermaid diagram editor can shrink the diagram dramatically in a single wheel notch.

## Best solution

Make Mermaid editor wheel zoom incremental and stable for standard Windows mice while preserving trackpad pinch zoom and cursor anchoring. Equal opposing wheel movements should approximately restore the previous scale rather than collapse it to the minimum.
