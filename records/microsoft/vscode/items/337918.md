# Issue #337918 — Workspace creation operation prevents active webviews to post message

[https://github.com/microsoft/vscode/issues/337918](https://github.com/microsoft/vscode/issues/337918)

## Change summary

Keep an active webview's extension messaging functional when adding the first folder creates a workspace and reloads the extension host.

## Best solution

Resolve the extension-host reload lifecycle in https://github.com/microsoft/vscode/issues/70656 so surviving webviews are either reconnected through their registered serializer or otherwise given a defined usable lifecycle after the workspace transition.
