# Issue #291098 — Copilot Cloud agent does not remember previously selected custom agent on new session creation

[https://github.com/microsoft/vscode/issues/291098](https://github.com/microsoft/vscode/issues/291098)

## Summary

Keep this accepted polish request open: current cloud-provider selection state is session-specific, and creating another session still falls back to the default agent. No verified older canonical or issue-referencing fix was found; the team-authored item cannot be declined.

## Change summary

Remember the selected cloud custom agent when the user creates another chat session with the + button.

## Best solution

New cloud sessions in the same repository should retain the previously selected custom agent when it remains available, while existing sessions retain their own selections. This belongs in the cloud provider's new-session option initialization, without expanding scope to local-to-cloud agent transfer.
