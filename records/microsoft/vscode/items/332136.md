## Summary

The report's central claim (VS Code injects `DEBUG=release` into the markdown-language-features worker, which then leaks to Delve) doesn't match current main: VS Code actively strips `DEBUG` from forked/utility processes via `removeDangerousEnvVariables`, and there is no `DEBUG=release` assignment anywhere in the source or build scripts.

## Change summary
