# Issue #339718 — At high zoom, welcome phrase overlaps with aquarium button

[https://github.com/microsoft/vscode/issues/339718](https://github.com/microsoft/vscode/issues/339718)

## Summary

Fresh, team-filed visual bug (0 days old) in the brand-new Agents Window aquarium/welcome-phrase feature — a real layout gap, not a close candidate; it just needs the fix.

## Change summary

At high browser/OS zoom, the centered new-session welcome phrase text visually overlaps the absolute-positioned aquarium toggle button pinned to the top-left corner of the chat widget.

## Best solution

Reserve layout space for the aquarium toggle (e.g. padding/margin on `.new-session-welcome-message` or constrained width) so the centered welcome title never extends under the fixed top-left button at any zoom level; fix lives in the Sessions chat widget / aquarium CSS.
