## Change summary

Unable to manually edit commands in the Copilot agent-mode terminal confirmation dialog when the sandbox setting is enabled.

## Best solution

Request the specific command that cannot be edited. If the command triggers a presentation override (e.g., `python -c '...'`), read-only is by design (the displayed content differs from the actual wrapped command). If the user's command is a plain shell command wrapped by the sandbox and still read-only, that would be a bug in `chatTerminalToolConfirmationSubPart.ts` around the `isReadOnly` logic.

## Evidence

- **readOnly logic:** In `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/chatTerminalToolConfirmationSubPart.ts` line 109, `isReadOnly` is set to `!!terminalData.presentationOverrides`. This triggers for commands that go through a presenter (e.g., Python -c extraction), not for sandbox wrapping in general.
- **sandbox wrapping:** The sandbox rewriter (`commandLineSandboxRewriter.ts`) sets `forDisplay` but does not set `presentationOverrides`. So sandbox wrapping alone should not cause read-only, unless the command also triggers a presenter.
