# Issue #330371 — Weird focus outline on collapsed chat response button

[https://github.com/microsoft/vscode/issues/330371](https://github.com/microsoft/vscode/issues/330371)

## Summary

The visual defect remains on current main: keyboard focus is outlined on a zero-padding summary wrapper rather than matching the padded collapsed-response control surface. This is a bounded CSS polish fix and should remain open.

## Change summary

Correct the sizing and spacing of the keyboard focus outline around the collapsed completed-response control in Chat.

## Best solution

Make the keyboard-only focus indicator follow the visible padded control surface, using the existing focus-border and control-radius tokens, without changing disclosure behavior or reducing focus visibility.
