# Issue #230230 — Markdown should not split up words in backticks that end in `/` when wrapping

[https://github.com/microsoft/vscode/issues/230230](https://github.com/microsoft/vscode/issues/230230)

## Summary

Team-authored polish request about editor word-wrapping behavior for inline code spans containing paths ending in `/`. No fix commit found on main; the issue remains valid and open.

## Change summary

Editor word wrap splits words inside backticks at trailing `/` characters, breaking folder-path readability in Markdown.

## Best solution

Adjust the editor's word-wrap break-point logic (likely in `src/vs/editor/common/viewModel/characterHardWrappingLineMapper.ts` or equivalent wrapping infrastructure) so that `/` inside inline code spans is not treated as a preferred break opportunity. Alternatively, if this is about the Markdown preview, adjust the CSS `word-break` rules for `<code>` elements in the preview renderer.
