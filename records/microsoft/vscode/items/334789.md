# Issue #334789 — Markdown editor cannot (easily) edit an empty file

[https://github.com/microsoft/vscode/issues/334789](https://github.com/microsoft/vscode/issues/334789)

## Summary

Plausible, specific UX bug in the newer experimental WYSIWYG Markdown editor (`vscode.markdown.editor`, backed by the `@vscode/markdown-editor` npm package): with an empty document the editable region appears to collapse to a tiny area, so clicks anywhere except the exact top-left corner don't place a cursor. I can't execute the webview to confirm the exact cause, so this needs routing/triage rather than a code-verified close.

## Change summary

Opening an empty .md file in the (experimental) Markdown Editor leaves no visible cursor, and clicking most of the editor area does nothing except one small spot in the top-left.

## Best solution

Route to the markdown-language-features area owners to reproduce; likely fix is ensuring the ProseMirror-backed editable region (rendered by the external `@vscode/markdown-editor` package, mounted into `#editor` in extensions/markdown-language-features/markdown-editor-src/markdownEditor.css) fills the full container height/width even when the document is empty, so clicking anywhere focuses it.
