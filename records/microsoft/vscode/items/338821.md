# Issue #338821 — Local agent: automatic retry after a dropped stream keeps the abandoned attempt's reasoning and tool calls

[https://github.com/microsoft/vscode/issues/338821](https://github.com/microsoft/vscode/issues/338821)

## Summary

Confirmed on current main: the tool-calling loop's `finishedCb` in toolCallingLoop.ts never checks `delta.retryReason`, so an automatic retry after a dropped stream keeps the abandoned attempt's `toolCalls`/`thinkingItem`/`statefulMarker` and appends the retry's data on top, matching the reporter's traced code paths and reproduced replay.

## Change summary

After the local agent automatically retries a dropped stream, the abandoned attempt's reasoning and tool calls are kept and merged with the retry's, instead of being discarded.

## Best solution

In toolCallingLoop.ts's `finishedCb`, reset `toolCalls`, `thinkingItem`, `statefulMarker`, `phase`, and `compaction` when `delta.retryReason` is present, mirroring the existing reset in `pseudoStartStopConversationCallback.ts`'s `applyDelta` (stagedDeltasToApply/currentStartStop/nonReportedDeltas reset on `delta.retryReason`).
