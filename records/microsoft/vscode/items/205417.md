# Issue #205417 — Launching External Terminal Changes Ctrl+C Handling Of Programs

[https://github.com/microsoft/vscode/issues/205417](https://github.com/microsoft/vscode/issues/205417)

## Summary

Keep open: multiple reporters confirmed that programs lose Ctrl+C handling in externally launched Windows terminals, and current main retains the launch option implicated by two successful workaround confirmations. This older report should remain the canonical item rather than be closed against the newer matching report.

## Change summary

Restore normal Ctrl+C handling for programs run in a Windows command prompt opened through VS Code's external-terminal command.

## Best solution

Make the Windows external-terminal launch preserve normal interrupt handling without requiring users to patch installed files or relaunch through Windows Terminal. Keep the change bounded to the external-terminal launch path and preserve the separate debugger launch behavior.
