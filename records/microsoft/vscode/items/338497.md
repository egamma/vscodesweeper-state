# Issue #338497 — Private plugin marketplace doesn't refresh on sign out

[https://github.com/microsoft/vscode/issues/338497](https://github.com/microsoft/vscode/issues/338497)

## Summary

The sign-out gap remains in current source: authentication changes do not invalidate marketplace discovery, and even a forced refresh serves the cached private repository after authentication fails. Keep this team-authored report open for the plugin marketplace owner.

## Change summary

Private plugin marketplace entries remain visible after signing out of the GitHub account used to access them, including after explicitly refreshing marketplaces.

## Best solution

Make available plugin discovery reflect loss of the authentication that enabled private marketplace access. Preserve independently authenticated Git access, installed plugins, and the existing offline-cache behavior rather than treating every refresh failure as a reason to remove content.
