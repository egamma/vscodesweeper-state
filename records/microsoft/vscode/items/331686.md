# Issue #331686 — Explorer context menu fails to load on Server 2025

[https://github.com/microsoft/vscode/issues/331686](https://github.com/microsoft/vscode/issues/331686)

## Summary

The 'Open with Code' Explorer context-menu entry is implemented by a separate shell-extension DLL from the microsoft/vscode-explorer-command repo (fetched prebuilt during the Windows build), not by code in this repository — reporter's own procmon trace and the linked source line point at that DLL's `explorer_command.cc`. This should be moved to that repo's tracker rather than closed here.

## Change summary

On Windows Server 2025, the 'Open with Code' Explorer right-click context menu entry briefly shows 'Loading...' then disappears, never appearing, while it works fine on Windows 11.

## Best solution

Move this issue to https://github.com/microsoft/vscode-explorer-command, the repo that owns the context-menu shell extension DLL (fetched via build/win32/explorer-dll-fetcher.ts from that repo's releases) — the reporter's procmon trace shows the failure happens before the DLL even opens its registry key, which is specific to that native component's behavior on Server 2025.
