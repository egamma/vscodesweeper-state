# Issue #178715 — Cannot save untitled notebook file with `notebook.formatOnSave.enabled` = true

[https://github.com/microsoft/vscode/issues/178715](https://github.com/microsoft/vscode/issues/178715)

## Summary

Team-authored bug with a landed mitigation (commit 50dc8079efa, 'Re #178715') that addresses the dirty-notebook case via `canDispose`, but the underlying lifecycle issue — working copies created without ref-counting during Save As — remains unresolved per the discussion. The 'mitigated' label reflects this intentional partial state.

## Change summary

Saving an untitled notebook with `notebook.formatOnSave.enabled` creates a blank file and leaves the untitled editor open because the format-on-save participant disposes the new working copy before Save As completes.

## Best solution

The deeper fix is to teach the notebook working copy collection about the +1 reference created inside fileWorkingCopyManager during Save As (or pass the model through save participants like text files do), so the lifecycle is correct regardless of dirty state. The mitigation in PR #180560 covers the dirty case only.
