# Issue #315784 — Context menu background colors blend into the agents window session background

[https://github.com/microsoft/vscode/issues/315784](https://github.com/microsoft/vscode/issues/315784)

## Summary

Still present on main: the agents window context menu CSS explicitly sets its background to `--vscode-agentsPanel-background` (the same panel surface color), causing the menu to blend into the session background with no visual separation.

## Change summary

Context menus in the agents window are hard to read because their background color matches the session panel background.

## Best solution

The context menu override in `src/vs/sessions/browser/media/style.css` (lines 749–753) should use a distinct elevated surface color (e.g. `--vscode-menu-background` or a new agents-specific menu surface token) instead of `--vscode-agentsPanel-background`, and add a border or shadow for visual separation.
