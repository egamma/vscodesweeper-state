# Issue #210186 — reopen "Keyboard shortcut for copy of line doesn't work on Linux" #6197

[https://github.com/microsoft/vscode/issues/210186](https://github.com/microsoft/vscode/issues/210186)

## Summary

The linked discussion documents an intentional decision to preserve Linux defaults and support customization where desktop shortcuts conflict. Current source retains those defaults, and this report supplies no new evidence that the commands fail when VS Code receives the shortcut.

## Change summary

Reconsider the Linux Copy Line Up/Down default shortcuts because they can conflict with desktop window-management bindings.

## Best solution

Retain the established defaults and use custom keybindings for affected desktop environments. Reconsider the underlying diagnosis only if there is evidence that VS Code receives the complete shortcut but fails to invoke the command.
