# Issue #337524 — File list order differs from multi-diff editor

[https://github.com/microsoft/vscode/issues/337524](https://github.com/microsoft/vscode/issues/337524)

## Summary

Real, confirmed ordering bug between the SCM changes list and the multi-diff editor, with an open PR (#337565) that directly targets this issue with a code fix and regression test — keep open until that PR lands rather than closing now.

## Change summary

The multi-diff editor shows changed files in resource-group order while the SCM changes list sorts them by path, so the same files appear in different positions in the two views.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/337565, which sorts SCM multi-diff resources with the same `comparePaths` ordering used by the changes list in src/vs/workbench/contrib/multiDiffEditor/browser/scmMultiDiffSourceResolver.ts.
