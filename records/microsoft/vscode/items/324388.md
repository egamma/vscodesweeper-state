# Issue #324388 — No easy way to submit my feedback

[https://github.com/microsoft/vscode/issues/324388](https://github.com/microsoft/vscode/issues/324388)

## Summary

The discoverability gap remains visible in current source: the session-level Submit Feedback action is contributed to the Changes toolbar, so closing that view removes its persistent entry point. This team-authored issue must remain open, and no older issue reports the same observable symptom.

## Change summary

Keep pending feedback visible and easy to submit after the Agents Window Changes view is closed.

## Best solution

Expose the pending-feedback count together with reveal and submit actions on a persistent Agents Window surface, while retaining the contextual controls in the Changes view and editor.
