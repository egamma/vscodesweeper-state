# Issue #324388 — No easy way to submit my feedback

[https://github.com/microsoft/vscode/issues/324388](https://github.com/microsoft/vscode/issues/324388)

## Summary

Team-authored bug (alexdima) already correctly labeled bug/agents-window; traced in source that the 'Submit Feedback' action only lives in the Changes editor's toolbar, so closing that editor removes the only affordance to see or submit pending feedback — a real gap that needs a design decision on where else to surface it.

## Change summary

In the Agents Window, once the Changes editor is closed there is no remaining UI to view or submit accumulated feedback comments on a session's changes.

## Best solution

Add a persistent surface for pending feedback outside the Changes editor (e.g. a badge/entry in the session title bar or chat widget) so users aren't forced to keep the Changes tab open; likely touches src/vs/sessions/contrib/agentFeedback/browser/agentFeedback.contribution.ts (where the 'Submit Feedback (N)' menu item is registered only for MenuId.AgentsChangesPrimaryActionSubMenu) and/or sessionsTitleBarWidget.ts.
