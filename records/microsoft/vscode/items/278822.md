# Issue #278822 — Azure AI Foundry BYOK provider

[https://github.com/microsoft/vscode/issues/278822](https://github.com/microsoft/vscode/issues/278822)

## Summary

Valid feature request from a team member with positive discussion from multiple MEMBERs. The existing Azure BYOK provider requires manual per-model endpoint configuration; this asks for automatic model discovery via Azure AI Foundry credentials. Not yet implemented — keeping open.

## Change summary

Automatically discover and surface all models from a user's Azure AI Foundry account on sign-in, instead of requiring manual per-endpoint configuration.

## Best solution

Implement an Azure AI Foundry BYOK provider (alongside the existing providers in `extensions/copilot/src/extension/byok/`) that leverages EntraId authentication to enumerate available models from the user's Foundry project. The Azure AI Toolkit team (comment discussion with @yaoleo34) may already have parts of this flow — coordinate to avoid duplication.
