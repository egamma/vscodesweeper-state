# Issue #346353 — Copilot Fusion sometimes doesn't tell you which model it selected

[https://github.com/microsoft/vscode/issues/346353](https://github.com/microsoft/vscode/issues/346353)

## Summary

Keep open as the maintainer-classified feature request for per-turn model disclosure in Fusion High and Max. The current footer intentionally identifies the orchestration level, and the newly started community-review period should continue.

## Change summary

Show which constituent model or models handled each Copilot Fusion High or Max turn.

## Best solution

Provide discoverable per-turn constituent-model information without misrepresenting an orchestrated turn as a single-model response. Preserve the Fusion effort-level identity and existing pricing information.

Preserve routing, billing attribution, and provider-neutral behavior; https://github.com/microsoft/vscode/issues/342875 is related configuration work, not a verified duplicate.
