# Issue #346353 — Copilot Fusion sometimes doesn't tell you which model it selected

[https://github.com/microsoft/vscode/issues/346353](https://github.com/microsoft/vscode/issues/346353)

## Summary

Keep open for the existing community-review process. A maintainer explicitly accepted model disclosure for High and Max as a feature request; current phase-level attribution provides partial coverage but does not establish consistent turn-level disclosure.

## Change summary
