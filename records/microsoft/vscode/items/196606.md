# Issue #196606 — Terminal quick fix should go away when a command is run

[https://github.com/microsoft/vscode/issues/196606](https://github.com/microsoft/vscode/issues/196606)

## Summary

The quick fix still survives while a subsequent non-empty command runs: current source clears it on command completion, not execution. Keep this open in terminal-quick-fix, preserving the explicitly requested behavior for empty commands.

## Change summary

Dismiss the previous terminal quick fix when a non-empty command begins executing, while retaining it when an empty command is submitted.

## Best solution

Make the terminal quick-fix lifecycle invalidate the previous suggestion at non-empty command execution rather than waiting for completion. Preserve empty-command retention and allow newly completed commands to produce their own suggestions.

## Evidence

Thus an existing suggestion is not cleared when a subsequent non-empty command starts; it remains until that command finishes.
