# Issue #295578 — Support differential updates on macOS

[https://github.com/microsoft/vscode/issues/295578](https://github.com/microsoft/vscode/issues/295578)

## Summary

Keep open: the inspected macOS updater and packaging paths do not implement the requested blockmap-based differential downloads. The related update-performance issue explicitly tracks this work as an unchecked task, rather than replacing this older, team-authored request.

## Change summary

Support incremental macOS update downloads using archive blockmaps instead of downloading the complete application archive.

## Best solution

Design an end-to-end differential-update path spanning macOS artifact generation, update-feed metadata, and client download/install handling. Preserve existing update controls and reliable full-download fallback when differential updating is unavailable.
