Keep open as an upstream Chromium remote-X11 rendering issue. The reporter confirmed that the Electron 9 update did not resolve it, while disabling MIT-SHM worked; no verified subsequent fix establishes completion.

## Change summary

Launching VS Code through a remote X server produces a blank window or crashes unless X shared-memory rendering is disabled.
