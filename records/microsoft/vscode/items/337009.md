# Issue #337009 — Markdown Editor: right-to-left (RTL) text is not supported

[https://github.com/microsoft/vscode/issues/337009](https://github.com/microsoft/vscode/issues/337009)

## Summary

Keep this open and route it to the Markdown Editor area: the bundled renderer lacks paragraph-level direction handling, and the older RTL issue concerns a different editor surface.

## Change summary

Make RTL paragraphs in the WYSIWYG Markdown Editor use the appropriate base direction, including punctuation ordering and caret/selection behavior.

## Best solution

Address paragraph direction and editing geometry in the shared @vscode/markdown-editor renderer, then adopt the corrected package in VS Code. Preserve independent directions for mixed-language paragraphs without changing Monaco settings or globally mirroring editor controls.
