# Issue #337009 — Markdown Editor: right-to-left (RTL) text is not supported

[https://github.com/microsoft/vscode/issues/337009](https://github.com/microsoft/vscode/issues/337009)

## Summary

Fresh, well-diagnosed report with clear repro steps; the wrapper code this repo owns (extensions/markdown-language-features/markdown-editor-src/) has no bidi/RTL handling at all, consistent with the reported LTR-only rendering, but the actual block rendering is produced entirely by the external @vscode/markdown-editor npm package, which is not vendored in this checkout, so the underlying defect and likely fix location can't be fully confirmed or bounded here. Routing to the markdown area rather than closing.

## Change summary

The new WYSIWYG Markdown Editor renders RTL text (Arabic/Hebrew/Persian) as left-to-right, unlike the Markdown preview which handles bidi correctly.

## Best solution

Add RTL/bidi handling (e.g. `dir="auto"` or `unicode-bidi: plaintext` on block elements) — most likely in the @vscode/markdown-editor package itself, with a possible CSS-only mitigation in extensions/markdown-language-features/markdown-editor-src/markdownEditor.css if the DOM structure permits; a maintainer with visibility into that package needs to confirm the right layer.
