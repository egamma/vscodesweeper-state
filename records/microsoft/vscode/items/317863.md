# Issue #317863 — Copilot Inline Suggestions block IntelliSense suggestions to automatically pop up when pressing letters

[https://github.com/microsoft/vscode/issues/317863](https://github.com/microsoft/vscode/issues/317863)

## Summary

This is an intentional default-setting change (editor.quickSuggestions.other → offWhenInlineCompletions) that the team chose to keep after briefly reverting and re-reverting. The issue serves as an active community discussion channel with 25 upvotes and strong feedback about regressions in auto-imports, symbol discovery, and non-AI workflows. A maintainer explicitly asked to keep it open for discussion.

## Change summary

The default for editor.quickSuggestions.other was changed to offWhenInlineCompletions in 1.121.0, suppressing the suggest widget when inline completions are active, which breaks auto-import workflows and symbol discovery for many users.

## Best solution

The team should consider a more nuanced default — e.g. suppressing quick suggestions only when an inline completion is actually visible rather than when the provider is merely registered, or preserving auto-import trigger behavior. The community feedback consistently highlights auto-imports and symbol discovery as regressions the current blanket suppression doesn't address. A notification or migration prompt for existing users would also reduce confusion.
