# Issue #317863 — Copilot Inline Suggestions block IntelliSense suggestions to automatically pop up when pressing letters

[https://github.com/microsoft/vscode/issues/317863](https://github.com/microsoft/vscode/issues/317863)

## Summary

Intentional default change to `editor.quickSuggestions.other` from `"on"` to `"offWhenInlineCompletions"` in 1.121.0; maintainer alexdima explicitly asked to keep this open for discussion. The current default remains `offWhenInlineCompletions` on main (the revert was itself reverted). With 25 upvotes and ongoing community feedback, this stays open as an active discussion.

## Change summary

The default for `editor.quickSuggestions.other` was changed to suppress the suggest widget when inline completions are active, breaking auto-import and IntelliSense workflows for many users.

## Best solution

The team should evaluate the community feedback — especially around auto-imports and symbol discovery workflows — and decide whether to refine the `offWhenInlineCompletions` behavior (e.g. still showing the suggest widget for import completions or trigger characters) or revert the default. The discussion is active and a maintainer is engaged.
