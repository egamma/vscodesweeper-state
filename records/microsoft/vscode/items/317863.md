# Issue #317863 — Copilot Inline Suggestions block IntelliSense suggestions to automatically pop up when pressing letters

[https://github.com/microsoft/vscode/issues/317863](https://github.com/microsoft/vscode/issues/317863)

## Summary

Keep this open as the active discussion about the intentional `offWhenInlineCompletions` default. The behavior remains on current main, has substantial community feedback and 28 upvotes, and a maintainer explicitly reopened the issue after the temporary revert was itself reverted.

## Change summary

Reconsider or refine the default behavior that suppresses automatic IntelliSense suggestions while inline completions are available, especially for symbol discovery and auto-import workflows.

## Best solution

Choose a default or context-aware interaction that preserves measurable inline-completion gains without hiding deterministic language completions needed for auto-imports, parameter discovery, and browsing unfamiliar symbols. The previous behavior must remain readily configurable, and any default change should be clearly communicated.
