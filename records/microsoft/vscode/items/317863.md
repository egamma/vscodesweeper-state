# Issue #317863 — Copilot Inline Suggestions block IntelliSense suggestions to automatically pop up when pressing letters

[https://github.com/microsoft/vscode/issues/317863](https://github.com/microsoft/vscode/issues/317863)

## Summary

Keep open as an active product discussion: current main intentionally suppresses automatic quick suggestions while inline completions are visible, but the maintainer explicitly retained this issue for feedback after the attempted default restoration was reverted. The 28 upvotes and reports across TypeScript, Luau, PowerShell, auto-imports, and symbol discovery demonstrate meaningful demand for reconsidering the default or improving coexistence and messaging.

## Change summary

Reconsider how automatically triggered IntelliSense suggestions interact with Copilot inline suggestions, especially the default behavior while typing letters.

## Best solution

Choose a product policy that preserves the measured benefits of inline completions without unexpectedly hiding language-service discovery, auto-imports, and parameter suggestions. A maintainer should decide between restoring the previous default, making suppression more context-sensitive, or providing clear first-use configuration UX while retaining manual and trigger-character completion behavior.

Commit ef680109cc39490c016783b3d7e3758358fee877 introduced the default; https://github.com/microsoft/vscode/pull/318789 temporarily restored `on`, and commit f08b0cab721efb62b881aafccbadc031366fdcb6 reverted that restoration. ## Evidence

- **current default:** src/vs/editor/common/config/editorOptions.ts sets `EditorQuickSuggestions.defaultValue.other` to `offWhenInlineCompletions`; users can recover the previous behavior by configuring `editor.quickSuggestions.other` to `on`.
- **suppression path:** src/vs/editor/contrib/suggest/browser/suggestModel.ts detects `offWhenInlineCompletions`, waits for registered inline completions, and returns without triggering quick suggestions when an inline suggestion is present.
