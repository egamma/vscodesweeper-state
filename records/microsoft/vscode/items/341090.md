# Issue #341090 — Automations: Improve navigating automations

[https://github.com/microsoft/vscode/issues/341090](https://github.com/microsoft/vscode/issues/341090)

## Summary

Team-authored report from a heavy automations user. Opening a run's session from Automations > History shows a chat that doesn't indicate it is an automation run and drops the automations list context, so the user has to go back through History for every run. I did not inspect the code for this review, so it stays open for the owning team.

## Change summary

Make it clear that a session is an automation run, and keep the automation context so the user can move between runs without going back through History.

## Best solution

Mark automation-run sessions as such in the session chat UI, for example with a header badge or a link back to the automation. Also keep the automation's run list visible, or provide next/previous run navigation, when a run is opened from History.
