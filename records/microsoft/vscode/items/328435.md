# Issue #328435 — agents window displays copilot cli even when disabled

[https://github.com/microsoft/vscode/issues/328435](https://github.com/microsoft/vscode/issues/328435)

## Summary

The two Copilot CLI entries are intentionally controlled separately. The Agents window already provides a dedicated setting to hide the Extension Host entry when using the Agent Host implementation.

## Change summary

Hide the unusable Extension Host Copilot CLI option from the Agents window when that provider is disabled.

## Best solution

Keep the separate provider controls and configure `chat.agentHost.enabled: true` with `chat.agents.copilotCli.hideExtensionHost: true` to expose only the Agent Host Copilot CLI.

  > Thanks for the report. These settings control separate Copilot CLI providers. `github.copilot.chat.backgroundAgent.enabled` controls the Extension Host contribution in the normal workbench; to use only the Agent Host implementation in the Agents window, enable `chat.agentHost.enabled` and set `chat.agents.copilotCli.hideExtensionHost` to `true`. The latter setting removes the disabled Extension Host entry from the Agents window picker.
