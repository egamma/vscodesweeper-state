# Issue #339326 — Agent Host telemetry counts HydraFusion phase chats as subagent launches

[https://github.com/microsoft/vscode/issues/339326](https://github.com/microsoft/vscode/issues/339326)

## Summary

Team-authored, well-diagnosed telemetry bug confirmed in the current checkout: HydraFusion phase chats are routed through the same subagent telemetry path as real task-tool subagents, inflating subagent counts and leaving model/source fields empty. The fix design (new schema field vs. suppressing telemetry vs. backfilling model) needs a maintainer decision, so this stays open for planning rather than a direct implementation.

## Change summary

Agent Host telemetry (agentHost.turnCompleted and related isSubagentSession-derived events) misclassifies HydraFusion phase chats as task-tool subagent launches, inflating subagent metrics and breaking before/after comparisons since #337621.

## Best solution

Add a bounded subagentKind ('task' | 'fusionPhase') to agentHost.turnCompleted and the other isSubagentSession-derived events so Fusion phase chats are distinguishable from real task-tool subagents, or otherwise stop phase chats from flowing through the generic subagent turn-telemetry path; a schema decision a maintainer should make before implementation.
