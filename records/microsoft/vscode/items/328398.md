# Issue #328398 — Agents: Too easy to archive a session by mistake

[https://github.com/microsoft/vscode/issues/328398](https://github.com/microsoft/vscode/issues/328398)

## Summary

Confirmed on main: archiving/marking a single agent session as done skips confirmation unless it has pending edits, while the bulk-archive actions always confirm — a real, unaddressed inconsistency worth routing to the Agents window area, though the report itself is thin (no logs, no repro steps beyond the screenshot).

## Change summary

Single-session archive/'Mark as done' has no confirmation dialog, so a misclick can archive a session with no easy way to recall what was lost.

## Best solution

Add a lightweight confirmation (or an undo toast) to the single-session archive/mark-done action in agentSessionsActions.ts, matching the confirmation already shown by BaseArchiveAllAgentSessionsAction and BaseArchiveAgentSessionSectionAction; sessions aren't actually deleted (they move to the Archived/Done section and can be restored), so this is about discoverability/safety, not data loss.
