# Issue #328398 — Agents: Too easy to archive a session by mistake

[https://github.com/microsoft/vscode/issues/328398](https://github.com/microsoft/vscode/issues/328398)

## Summary

Current main immediately archives an individual session without confirmation, while bulk archive actions already confirm. This is a valid Agents window safety polish request and should be routed to that area.

## Change summary

Make accidental session archival less likely when nearby session rows move while the user is clicking an approval action.

## Best solution

Add a single-session confirmation naming the targeted session, or prevent row reordering while its inline actions are engaged. Reuse the existing archive-confirmation pattern in `sessionsViewActions.ts` while keeping restoration available from Done.
