# Issue #174616 — Allow adjusting search text box width in title bar to accommodate long path and file names.

[https://github.com/microsoft/vscode/issues/174616](https://github.com/microsoft/vscode/issues/174616)

## Summary

Valid feature request with 69 upvotes, promoted to backlog. The command center width is hardcoded in CSS (38vw, max 600px) with no user-facing setting to adjust it. Not yet implemented on main.

## Change summary

Allow users to configure the width of the command center search box in the title bar to accommodate long file paths.

## Best solution

Add a setting (e.g. `window.commandCenterWidth`) or make the command center resizable/responsive so long title text is visible. Related issue https://github.com/microsoft/vscode/issues/85374 covers widening the command palette itself — the two could share implementation if the command center and quick-pick width become configurable together.
