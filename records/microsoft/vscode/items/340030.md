# Issue #340030 — Thumbs-up/thumbs-down feedback buttons are missing from some Copilot Chat responses

[https://github.com/microsoft/vscode/issues/340030](https://github.com/microsoft/vscode/issues/340030)

## Summary

Keep open: another user confirms responses with Copy but no feedback controls, including an accessibility-related feedback need. Current source contains intentional visibility gates and a replacement survey, but neither establishes why these conversations lack any feedback action.

## Change summary

Copilot Chat responses inconsistently omit thumbs-up/down controls while other response actions remain visible.

## Best solution

Ensure eligible sidebar responses expose a discoverable, keyboard-accessible response-feedback action, whether standard voting or its survey replacement. Diagnose the affected response's eligibility and rendering state before changing intentional feedback restrictions.
