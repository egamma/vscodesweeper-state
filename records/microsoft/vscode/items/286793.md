# Issue #286793 — Worktree view doesn't show base repository worktree

[https://github.com/microsoft/vscode/issues/286793](https://github.com/microsoft/vscode/issues/286793)

## Summary

The missing main worktree was fixed, matching the reporter's confirmation after upgrading to 1.109. Keep this open for the remaining repository/worktree presentation feedback; the linked hierarchy PR is still open, and showing worktrees in both representations has an explicit maintainer rationale.

## Change summary

Show the main worktree when browsing from a linked worktree, and make the relationship between worktree entries and opened repositories understandable.

## Best solution

Retain the implemented main-worktree listing and distinguish worktree-management entries from opened SCM repositories without implying filesystem containment. Evaluate the remaining feedback alongside the linked hierarchy PR, preserving access to each opened worktree's SCM state.
