# Issue #199703 — Should resizing the diff in the multidiff change it for all diffed files

[https://github.com/microsoft/vscode/issues/199703](https://github.com/microsoft/vscode/issues/199703)

## Summary

Keep open: current source still maintains an independent original/modified split for each embedded diff, rather than resizing all files together. No verified older canonical issue covers this request.

## Change summary

Allow dragging the original/modified sash to resize every file's split in a multi-diff view at once.

## Best solution

Provide a multi-diff-wide resizing interaction that applies a consistent split ratio across files, including entries rendered later by virtualization. Decide whether synchronization is the default or an explicit option, without changing standalone diff-editor behavior.
