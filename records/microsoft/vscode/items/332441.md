# Issue #332441 — Automations: add Archive action to hover actions of an automation history entry

[https://github.com/microsoft/vscode/issues/332441](https://github.com/microsoft/vscode/issues/332441)

## Summary

Legitimate, well-traced feature request: the Automations history hover toolbar only registers Stop/Delete actions, with no quick Archive action, matching current main. Keeping open for a maintainer/area owner to decide on adding the action.

## Change summary

Add an Archive action to the hover toolbar of an automation history entry so sessions can be archived without opening them first.

## Best solution

Add a third menu item to `Menus.AutomationsHistoryItem` in `registerAutomationHistoryItemActions()` (src/vs/sessions/contrib/sessions/browser/views/automationsView.ts) that calls `sessionsManagementService.archiveSession(session)`, handled in `handleSessionToolbarAction`, gated with a `SessionIsArchivedContext.negate()`-style when clause mirroring the existing Stop/Delete conditions.
