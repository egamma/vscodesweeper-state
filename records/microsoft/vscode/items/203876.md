# Issue #203876 — Webviews don't preserve focus when the context menu is opened

[https://github.com/microsoft/vscode/issues/203876](https://github.com/microsoft/vscode/issues/203876)

## Summary

Still reproduces on main: when a webview's context menu is dismissed, focus is not restored to the previously focused element inside the webview iframe. The existing code only toggles a CSS class on the webview body — no focus restoration logic exists.

## Change summary

Dismissing a context menu opened from within a webview does not restore focus to the previously focused element in the webview.

## Best solution

Save the active element reference inside the webview iframe before the context menu opens (in the `did-context-menu` handler or via the `set-context-menu-visible` message), and restore focus to it when the context menu is hidden. The fix spans `src/vs/workbench/contrib/webview/browser/webviewElement.ts` (host side) and `src/vs/workbench/contrib/webview/browser/pre/index.html` (iframe side, around line 1230).
