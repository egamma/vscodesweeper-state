## Change summary

Editing an untitled document after reopening it in Cat Scratch unexpectedly opens a synchronized default text-editor tab.

## Best solution

An untitled document already displayed in a custom text editor should remain in that editor when modified, without spontaneously opening a text-editor tab. Retest the original first-edit flow and establish whether the dirty-model tracker still misses the existing custom editor before deciding on a fix or completion.

- **Trace:**

  > TextFileEditorTracker in src/vs/workbench/contrib/files/browser/editors/textFileEditorTracker.ts listens to untitled dirty events and attempts to ensure every dirty model has an editor after an 800 ms delay.
