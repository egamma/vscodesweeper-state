# Issue #349876 — "Help -> About" Should also include info about the 'remote'

[https://github.com/microsoft/vscode/issues/349876](https://github.com/microsoft/vscode/issues/349876)

## Summary

Help → About still reports client-side information only. Remote diagnostics exist in the issue reporter, but do not cover the requested copy-from-About workflow; no verified duplicate was found.

## Change summary

Include remote-host details in the information displayed and copied by Help → About.

## Best solution

Consider a clearly distinguished remote-host section in About and its copied text. First establish which remote context and diagnostic fields to include, especially when an agent host differs from the workspace remote.

- **Reason:** Making remote context available alongside client details supports remote-development troubleshooting through a consistent built-in surface.

In src/vs/workbench/electron-browser/parts/dialogs/dialog.contribution.ts, its dialog details come from createNativeAboutDialogDetails(productService, nativeHostService.getOSProperties()); both native and custom dialogs receive that same client-only payload.
- **Current output:** src/vs/platform/dialogs/electron-browser/dialog.ts constructs displayed and copied details from client product metadata, Electron/Node versions, bundled Copilot versions, and local OS properties. src/vs/workbench/browser/parts/dialogs/dialog.ts likewise constructs browser About details without remote-host information.
- **Partial alternative:** src/vs/workbench/contrib/issue/browser/issueReporterModel.ts already includes remote.machineInfo.os through getRemoteOSes() and remote diagnostics tables. This helps reports generated through the issue reporter, but does not add remote details to About or its Copy output.
