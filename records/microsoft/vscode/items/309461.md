# Issue #309461 — Copilot CLI session log lists wrong github branch

[https://github.com/microsoft/vscode/issues/309461](https://github.com/microsoft/vscode/issues/309461)

## Summary

Still open — the root cause (ChatWorkspaceContextProvider injecting stale branch info into CLI sessions that use worktrees) is identified and agreed upon by the team, but no fix commit is visible on main.

## Change summary

Copilot CLI receives incorrect branch name from ChatWorkspaceContextProvider because CLI uses worktrees where the branch context differs from the original workspace.

## Best solution

Exclude ChatWorkspaceContextProvider-sourced context variables from Copilot CLI sessions, since CLI creates worktrees where the injected branch/repo info is stale and misleading to the model.
