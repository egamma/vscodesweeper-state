# Issue #309461 — Copilot CLI session log lists wrong github branch

[https://github.com/microsoft/vscode/issues/309461](https://github.com/microsoft/vscode/issues/309461)

## Summary

Keep open: current source still permits workspace-provider context into Copilot CLI prompts, despite the agreed exclusion. The existing repository-context filter applies only with isolation enabled and does not implement the maintainer-approved boundary.

## Change summary

Copilot CLI receives stale workspace repository context and answers with a previously reviewed PR branch instead of its actual working branch.

## Best solution

Honor the agreed exclusion of ChatWorkspaceContextProvider contributions from Copilot CLI requests while preserving ordinary chat context and explicitly attached resources. Verify both isolated worktree sessions and sessions running directly in the workspace.
