# Issue #306294 — Easier change of selection for "Find in selection"

[https://github.com/microsoft/vscode/issues/306294](https://github.com/microsoft/vscode/issues/306294)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/284007 reports the same inability to replace the Find widget's cached search scope with the editor's current selection. This proposal supplies a specific interaction design that should be carried into that canonical discussion.

## Change summary

Let one action replace the Find widget's previous search scope with the current editor selection, enabling or disabling Find in Selection based on whether that selection is empty.

## Best solution

Resolve https://github.com/microsoft/vscode/issues/284007 by providing a predictable way to refresh the cached Find in Selection scope from the current editor selection; consider this report's one-click and empty-selection semantics when choosing the interaction.
