# Issue #119103 — Type ahead should turn off temporarily when it fails on a line

[https://github.com/microsoft/vscode/issues/119103](https://github.com/microsoft/vscode/issues/119103)

## Summary

Still unfixed on main. The type-ahead addon rolls back failed predictions but does not temporarily disable predictions for the remainder of that line after a failure. The feature is now off by default (PR #239335), which reduces exposure but does not address the core request. Keeping open.

## Change summary

Terminal type-ahead (local echo) should temporarily stop predicting on the current line after a prediction failure, rather than continuing to produce wrong predictions.

## Best solution

Add logic in `PredictionTimeline` (in `terminalTypeAheadAddon.ts`) to suppress new predictions for the remainder of a line after a `MatchResult.Failure`, resuming on the next prompt. This would also help with password-input scenarios. The feature is off by default and tagged preview, so this is low-urgency but would be needed before re-enabling the feature.
