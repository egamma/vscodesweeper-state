# Issue #119103 — Type ahead should turn off temporarily when it fails on a line

[https://github.com/microsoft/vscode/issues/119103](https://github.com/microsoft/vscode/issues/119103)

## Summary

Keep open: current source rolls back failed predictions but does not suppress further prediction on the affected line. Disabling local echo by default mitigates exposure without fixing this behavior; the thread also incorporates password-exposure concerns requiring human handling.

## Change summary

Temporarily stop terminal type-ahead on a line after a prediction fails, rather than continuing speculative echo.

## Best solution

Make explicitly enabled local echo stop predicting on a failing line while preserving authoritative terminal output and normal prediction on subsequent input lines. Review the password-input implications separately; failure suppression alone should not be presented as complete protection for confidential input.
