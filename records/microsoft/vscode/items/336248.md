# Issue #336248 — Hovering over a PR link could show rich PR preview as on github.com

[https://github.com/microsoft/vscode/issues/336248](https://github.com/microsoft/vscode/issues/336248)

## Summary

Reasonable, fresh feature request (0 days old, no traction yet) asking for a richer GitHub PR hover; keeping open for the normal community/feature-request process while noting the team has already built substantial adjacent infrastructure that could support it.

## Change summary

Show a rich PR preview (title, status, checks) when hovering a PR link, similar to github.com, instead of a plain link tooltip.

## Best solution

Extend the existing GitHub link-presentation infrastructure (src/vs/workbench/contrib/github/browser/githubLinkPresentation.contribution.ts, ILinkPresentationService in src/vs/platform/dataChannel/common/dataChannel.ts) — currently used to render rich inline PR/issue chips in chat responses — to also drive a hover widget for PR/issue links encountered elsewhere (editor, terminal), reusing the same GitHubService PR/issue subscription and status/checks logic.
