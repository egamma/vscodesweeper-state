# Issue #207713 — Multi-line highlight

[https://github.com/microsoft/vscode/issues/207713](https://github.com/microsoft/vscode/issues/207713)

## Summary

Implemented and shipped in VS Code 1.103.0. The `editor.selectionHighlightMultiline` setting now provides the requested behavior.

## Change summary

Highlight repeated exact matches when the editor selection spans multiple lines.

## Best solution

Use `"editor.selectionHighlightMultiline": true`; for blocks exceeding the default 200-character limit, adjust `editor.selectionHighlightMaxLength` or set it to zero for unlimited length.
