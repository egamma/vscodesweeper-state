# Issue #207713 — Multi-line highlight

[https://github.com/microsoft/vscode/issues/207713](https://github.com/microsoft/vscode/issues/207713)

## Summary

The requested multiline selection highlighting is implemented through editor.selectionHighlightMultiline, with a configurable length limit. Propose closing as completed, rather than declining this accepted Backlog request.

## Change summary

Highlight other occurrences of an exactly matching selected multiline block in the same file.

## Best solution

Use editor.selectionHighlightMultiline: true to enable the implemented behavior, and increase editor.selectionHighlightMaxLength or set it to 0 for blocks exceeding the default 200-character limit.
