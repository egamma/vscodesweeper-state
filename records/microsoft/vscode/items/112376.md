# Issue #112376 — [json] Relative path wrongly resolved

[https://github.com/microsoft/vscode/issues/112376](https://github.com/microsoft/vscode/issues/112376)

## Summary

The report identifies a confirmed JSON language-service defect in resolving nested relative `$ref` values, and the current record contains no valid evidence that it has been fixed. It should remain open as an upstream dependency issue.

## Change summary

Nested relative JSON Schema `$ref` paths are resolved against the root schema location after schemas are merged, producing incorrect file paths.

## Best solution

Correct reference resolution in `microsoft/vscode-json-languageservice` so every nested `$ref` retains and uses the URI of the schema document that declared it, then adopt the fixed language-service version in VS Code.
