The maintainer-confirmed asynchronous `$ref` resolution defect has been fixed upstream and the corrected language-service version is consumed on current VS Code main, so this can close as completed.

## Change summary

Nested relative JSON Schema references were resolved against the root schema after asynchronous merging, producing paths one directory too high or too deep.

## Best solution

Keep the ordered reference traversal from upstream commit a6bcde72e46908c56fae1a9f837ef50548b900e1, which ensures references cannot observe or inherit partially resolved schema state.
