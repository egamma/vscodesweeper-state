# Issue #325064 — Single Detail Panel: Tab titles do not need bold font weight

[https://github.com/microsoft/vscode/issues/325064](https://github.com/microsoft/vscode/issues/325064)

## Summary

Legitimate, still-open UI polish request: the Agents window's single-detail-panel tab title uses `--vscode-agents-fontWeight-semiBold`, unlike regular editor tabs (which have no bold override), and two more users have since piled on saying the bold weight reads as an unintended "needs attention" signal.

## Change summary

The Single Detail Panel tab title in the Agents window is rendered in a semi-bold font weight, unlike normal editor tabs, which reads as visually distracting/misleading.

## Best solution

Drop or soften the `font-weight: var(--vscode-agents-fontWeight-semiBold, 600)` on `.custom-view-header-title` in src/vs/sessions/browser/parts/media/customViewGridPart.css (and the analogous session-view header title styling) to match the regular (non-bold) weight used by standard editor tabs, per the maintainer's own comment about consistency.
