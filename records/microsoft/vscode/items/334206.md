# Issue #334206 — Agent merge button doesn't show it's enabled

[https://github.com/microsoft/vscode/issues/334206](https://github.com/microsoft/vscode/issues/334206)

## Summary

Fresh, well-formed report with a screenshot; traced in the source: the Agent Merge primary button's menu item registration carries no `toggled` state or other visual cue tied to `SessionAgentMergeEnabledContext`, so the button looks identical whether Agent Merge is enabled or disabled for the session.

## Change summary

The Agents window's Agent Merge primary button gives no visual indication (spinner, checkmark, etc.) of whether Agent Merge is actually enabled for the active session.

## Best solution

In src/vs/sessions/contrib/providers/agentHost/browser/agentMergeActions.ts, the submenu item registered on Menus.ChangesOperationsDropdown (around line 205) could set a `toggled` condition on `SessionAgentMergeEnabledContext` so the button renders a distinct pressed/checked state when enabled — the codebase already supports `toggled` on menu items (see platform/actions/common/actions.ts) for exactly this kind of indicator, though the maintainers should decide the precise visual treatment (checkmark vs. spinner vs. icon swap).
