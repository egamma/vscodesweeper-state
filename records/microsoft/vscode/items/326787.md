# Issue #326787 — New issue reporter should support pasting images in the issue description

[https://github.com/microsoft/vscode/issues/326787](https://github.com/microsoft/vscode/issues/326787)

## Summary

The requested paste workflow remains absent on current main and should be routed to the issue-reporter area. This team-authored request has no verified duplicate or merged implementation supporting a close.

## Change summary

Allow images pasted into the new issue reporter's description field to be uploaded and included in the resulting GitHub issue.

## Best solution

Support image clipboard data in the issue description while preserving ordinary text paste, existing screenshot and recording flows, attachment limits, and upload-failure handling. The area owner should first settle whether pasted images appear at the cursor like github.com or in the reporter's generated attachments section.
