# Issue #326787 — New issue reporter should support pasting images in the issue description

[https://github.com/microsoft/vscode/issues/326787](https://github.com/microsoft/vscode/issues/326787)

## Summary

Reasonable, unimplemented request — the issue reporter's description field is a plain textarea with no paste/image handling, and the UI text explicitly defers screenshots to editing on GitHub after submission. Routing to the issue-reporter area for a maintainer decision.

## Change summary

Allow pasting images directly into the issue description field in the built-in issue reporter, similar to github.com.

## Best solution

If pursued, add clipboard-paste image handling in src/vs/workbench/contrib/issue/browser/baseIssueReporterService.ts's description textarea that reuses the existing GitHub upload path (src/vs/workbench/contrib/issue/browser/githubUploadService.ts / electron-browser/nativeGitHubUploadService.ts) to upload the pasted image and insert a Markdown image link — mirroring the screenshot attach flow already present.
