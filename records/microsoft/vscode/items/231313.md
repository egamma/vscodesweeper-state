# Issue #231313 — Custom HISTFILE not being honored

[https://github.com/microsoft/vscode/issues/231313](https://github.com/microsoft/vscode/issues/231313)

## Summary

Verified duplicate of #169264, which is the older canonical issue tracking the same HISTFILE-override bug with maintainer discussion and a proposed fix approach. The defect is still present on current main.

## Change summary

VS Code's zsh shell integration unconditionally overwrites HISTFILE, ignoring any custom value set in .zshenv or other early-sourced files.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/169264 — the fix is to preserve an existing HISTFILE value (e.g. `HISTFILE=${HISTFILE:=$USER_ZDOTDIR/.zsh_history}`) in shellIntegration-rc.zsh line 22. This report's .zshenv detail and the commenter's suggested fix diff are useful evidence to carry over.
