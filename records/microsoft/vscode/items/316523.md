# Issue #316523 — Copilot New Session Warning

[https://github.com/microsoft/vscode/issues/316523](https://github.com/microsoft/vscode/issues/316523)

## Summary

Already fixed on main and shipped in 1.122.0. The PowerShell parsing error when running hooks with `session-start` was caused by improper shell invocation on Windows when ComSpec is cmd.exe; the fix adds `-ExecutionPolicy Bypass -Command` arguments so PowerShell properly interprets the hook command string.

## Change summary

Starting a new Copilot session on Windows triggers a PowerShell parsing error ('Unexpected token session-start') from the hook runner.

## Best solution

Keep the shipped fix in commit 1f7db286554 (1.122.0); no further change needed. The reporter should update to VS Code 1.122.0+.
