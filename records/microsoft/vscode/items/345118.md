# Issue #345118 — [GB Cert][VS Code]: The constant name defined using GB characters is split when code completion is triggered.

[https://github.com/microsoft/vscode/issues/345118](https://github.com/microsoft/vscode/issues/345118)

## Summary

The supplied Group9 sequence is not a valid JavaScript identifier: it includes an ASCII closing parenthesis and other non-identifier characters. Splitting document-word suggestions at that parenthesis is intentional, not evidence that supported GB characters are being corrupted.

## Change summary

Show the complete mixed-character Group9 sequence as one completion instead of separate fragments.

## Best solution

Preserve JavaScript identifier rules and language-defined word boundaries. Test identifier completion with a valid Unicode identifier at a variable-reference position; keep the unrestricted Group9 sequence in a string value.
