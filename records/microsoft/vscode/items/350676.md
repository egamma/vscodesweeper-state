# Issue #350676 — P1 Outline view rebuilds its whole symbol tree on every cursor move (affectOnlyActiveElement is ignored)

[https://github.com/microsoft/vscode/issues/350676](https://github.com/microsoft/vscode/issues/350676)

## Summary

The defect remains in current main: cursor-only outline events trigger a full tree refresh regardless of Follow Cursor. Keep this issue open; the event handling and repeated symbol-filter configuration lookups are bounded, actionable performance defects.

## Change summary

Avoid rebuilding the Outline tree for active-element-only changes and repeated resource-configuration resolution for every symbol during filtering.

## Best solution

Preserve the Outline tree on cursor-only changes while retaining existing Follow Cursor behavior and full refreshes for substantive outline updates. Filtering should avoid redundant configuration resolution without losing resource-specific settings or configuration-change responsiveness.
