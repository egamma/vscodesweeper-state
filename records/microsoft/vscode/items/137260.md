# Issue #137260 — Scope Emmet custom snippets to their respective workspaces

[https://github.com/microsoft/vscode/issues/137260](https://github.com/microsoft/vscode/issues/137260)

## Summary

Still unimplemented on main: emmet.extensionsPath is scoped as machine-overridable and the configuration retrieval doesn't pass a resource URI, so custom snippets still bleed across workspace folders in multi-root workspaces.

## Change summary

Scope Emmet custom snippets so each workspace folder only sees its own snippets in a multi-root workspace.

## Best solution

Change emmet.extensionsPath scope to resource and pass the active document's URI when reading the configuration, then update the helper's snippet resolution to be per-folder rather than global.
