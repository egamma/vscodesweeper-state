# Issue #323964 — .gitignore will prevent an extension from launching.

[https://github.com/microsoft/vscode/issues/323964](https://github.com/microsoft/vscode/issues/323964)

## Summary

Confirmed in source: `checkGlobFileExists` in `workspaceContains.ts` delegates to `QueryBuilder.file()` without passing `disregardIgnoreFiles: true`, so glob-based `workspaceContains` activation events respect `.gitignore` and `files.exclude`, silently preventing extension activation. No fix has landed on main.

## Change summary

Extensions using `workspaceContains` glob activation events fail to activate when the target file path matches a `.gitignore` pattern, because the file search respects ignore files by default.

## Best solution

Pass `disregardIgnoreFiles: true` (and likely `disregardExcludeSettings: true`) in the `queryBuilder.file()` call inside `checkGlobFileExists` in `src/vs/workbench/services/extensions/common/workspaceContains.ts`, so that extension activation glob searches are not filtered by `.gitignore` or `files.exclude`. Related issue https://github.com/microsoft/vscode/issues/326423 covers the `files.exclude` facet of the same root cause — the two should be consolidated.
