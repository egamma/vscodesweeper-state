## Summary

Valid feature request for drag-and-drop reordering of sub-session (chat) tabs in the Agents window. Not yet implemented on main — the existing drag-and-drop work covers session list items, not chat tabs within a session. Team-authored; keeping open.

## Change summary

Allow users to drag-and-drop sub-session (chat) tabs to reorder them within an Agents window session.

## Best solution

Add drag-and-drop reordering support to the chat tab bar in `src/vs/sessions/browser/parts/chatCompositeBar.ts`, likely leveraging the existing ActionBar or CompositeBar drag infrastructure already used for session list reordering. The tab order would need to be persisted through the session management service.
