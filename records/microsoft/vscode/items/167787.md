# Issue #167787 — Settings editor scrolls when checking box

[https://github.com/microsoft/vscode/issues/167787](https://github.com/microsoft/vscode/issues/167787)

## Summary

Still reproduces on main: toggling a checkbox in settings like `autoLockGroups` fires `_onDidFocusSetting` which calls `setFocus` on the tree, and the combination of dynamic height support and focus changes can cause unwanted scrolling. No fixing commit found.

## Change summary

Settings editor scrolls unexpectedly when toggling a checkbox in a bool-object setting like `workbench.editor.autoLockGroups`.

## Best solution

Guard the `setFocus` call in the `onDidFocusSetting` handler (settingsEditor2.ts:1183) to avoid triggering a reveal/scroll when the setting is already visible in the viewport, or suppress scroll-on-focus when the focus change originates from a user click within the same setting row.
