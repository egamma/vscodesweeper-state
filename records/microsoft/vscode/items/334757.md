# Issue #334757 — Support cursor in decoration attachments (before / after)

[https://github.com/microsoft/vscode/issues/334757](https://github.com/microsoft/vscode/issues/334757)

## Summary

Attachment-specific cursor styling remains unsupported in the current API and rendering path. Keep this correctly routed request open through the Backlog Candidates process; it has 12 upvotes and its community voting window is still active.

## Change summary

Allow extensions to specify a mouse cursor independently for before/after decoration attachments.

## Best solution

Have the editor API owners consider attachment-specific cursor styling without changing the cursor over the decorated text. The public attachment options, extension-host conversion, and attachment CSS rendering would all need to support the accepted contract.
