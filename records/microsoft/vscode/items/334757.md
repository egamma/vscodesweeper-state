# Issue #334757 — Support cursor in decoration attachments (before / after)

[https://github.com/microsoft/vscode/issues/334757](https://github.com/microsoft/vscode/issues/334757)

## Summary

Legitimate small API gap — ThemableDecorationAttachmentRenderOptions has no cursor property, so extensions can't style the pointer for interactive before/after attachments. Brand-new, unrouted request; needs an editor-team decision on adding the property.

## Change summary

Add a `cursor` property to `ThemableDecorationAttachmentRenderOptions` so decoration attachments (before/after) can set their own CSS cursor.

## Best solution

If accepted, this is a small, well-scoped API addition: add `cursor?: string` to `ThemableDecorationAttachmentRenderOptions` in vscode.d.ts, thread it through extHostTypeConverters.ts (ThemableDecorationAttachmentRenderOptions.from) into IContentDecorationRenderOptions, and apply it in the decoration CSS builder alongside the existing textDecoration/border/color properties.
