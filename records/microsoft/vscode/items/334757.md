# Issue #334757 — Support cursor in decoration attachments (before / after)

[https://github.com/microsoft/vscode/issues/334757](https://github.com/microsoft/vscode/issues/334757)

## Summary

Confirmed gap: `ThemableDecorationAttachmentRenderOptions` in vscode.d.ts has no `cursor` property, while `ThemableDecorationRenderOptions` (for the decorated text itself) already has one — this is a real, narrow API asymmetry worth a maintainer look rather than a close.

## Change summary

Add a `cursor` CSS property to decoration attachment (`before`/`after`) render options so extensions can style the cursor over inline icons/indicators.

## Best solution

Add `cursor?: string;` to `ThemableDecorationAttachmentRenderOptions` in src/vscode-dts/vscode.d.ts and thread it through the attachment CSS builder in the editor (mirroring how `cursor` is already applied for `ThemableDecorationRenderOptions`) and the ext host decoration type converter.
