# Issue #190013 — Provide a more visible menu for the important actions

[https://github.com/microsoft/vscode/issues/190013](https://github.com/microsoft/vscode/issues/190013)

## Summary

Keep open: current main supports a floating editor toolbar with multiple actions, but its extension contribution point remains proposed. The remaining gap is a supported extension-facing contract, not another toolbar implementation; this team-authored Backlog request has no verified fixing commit or canonical duplicate.

## Change summary

Expose a discoverable in-editor action surface so extensions can offer actions such as attaching sources alongside decompilation.

## Best solution

Evaluate and finalize an extension-facing editor/content contribution contract using the existing floating toolbar, with defined behavior for multiple actions. Keep language-specific source attachment logic in the Java extension.
