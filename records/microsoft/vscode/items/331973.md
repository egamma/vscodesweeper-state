# Issue #331973 — Find human comments in chat history

[https://github.com/microsoft/vscode/issues/331973](https://github.com/microsoft/vscode/issues/331973)

## Summary

Reasonable, unaddressed feature request: there's no existing way to jump between your own messages in a long chat transcript, and the codebase's similarly-named "Question Carousel" navigation (workbench.action.chat.previousQuestion/nextQuestion) is an unrelated MCP/elicitation feature, not chat-history navigation.

## Change summary

Add a way to quickly locate and jump between the user's own past messages in a chat conversation, since verbose (especially reasoning-model) responses make scrolling back to find them tedious.

## Best solution

Belongs in the chat widget/transcript area (src/vs/workbench/contrib/chat/browser/widget/chatWidget.ts and its list renderer) as a lightweight prev/next-user-turn navigation command or a chat outline, similar in spirit to the existing 'Previous/Next Question' carousel actions but scoped to actual user requests in the transcript.
