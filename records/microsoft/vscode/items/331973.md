# Issue #331973 — Find human comments in chat history

[https://github.com/microsoft/vscode/issues/331973](https://github.com/microsoft/vscode/issues/331973)

## Summary

This exact capability already ships: VS Code has dedicated 'Next User Prompt' / 'Previous User Prompt' commands (Ctrl+Alt+Down / Ctrl+Alt+Up) that jump focus straight to each of the user's own chat messages, skipping the verbose assistant output in between.

## Change summary

Requests a quick way to jump between the user's own comments in a long, verbose chat transcript.

## Best solution

Point the reporter at the existing 'Chat: Next User Prompt' / 'Chat: Previous User Prompt' commands (workbench.action.chat.nextUserPrompt / workbench.action.chat.previousUserPrompt, bound to Ctrl+Alt+Down / Ctrl+Alt+Up while a chat session is focused) — this already delivers the requested navigation.

## Evidence

- **existing commands:** src/vs/workbench/contrib/chat/browser/actions/chatPromptNavigationActions.ts registers 'workbench.action.chat.nextUserPrompt' and 'workbench.action.chat.previousUserPrompt', filtering the chat view model to request items (isRequestVM) and focusing/revealing the next or previous one relative to the current focus.
- **keybindings:** Both commands are bound by default to Ctrl+Alt+Down / Ctrl+Alt+Up when ChatContextKeys.inChatSession is true, and are also exposed via the Command Palette (f1: true) under the 'Chat' category.
- **registration:** registerChatPromptNavigationActions() is wired up in src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts, so the commands are active in the shipped product, not dead code.
