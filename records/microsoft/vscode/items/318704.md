# Issue #318704 — Error - Failed during initial scan: Could not find ripgrep binary in ZooCode extension after update vscode

[https://github.com/microsoft/vscode/issues/318704](https://github.com/microsoft/vscode/issues/318704)

## Summary

This is an extension compatibility failure, not a VS Code core defect: Zoo Code and other affected extensions relied on VS Code's undocumented internal ripgrep package path. The exact regression was previously closed as caused by an extension, and Zoo Code subsequently released its own fix.

## Change summary

Zoo Code codebase indexing fails after VS Code 1.122 moved its bundled ripgrep binary to a new internal package path.

## Best solution

Extensions that need ripgrep should bundle or resolve their own executable rather than depend on VS Code's private node_modules layout; users of Zoo Code should update to a version containing its migration fix.
