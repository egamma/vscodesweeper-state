# Issue #163432 — IntlBackslash swapped with Backquote on ISO keyboards on Chrome & Firefox

[https://github.com/microsoft/vscode/issues/163432](https://github.com/microsoft/vscode/issues/163432)

## Summary

Confirmed upstream bug in both Chromium and Firefox where IntlBackslash and Backquote scan codes are swapped on macOS ISO keyboards. VS Code team has already identified and linked both upstream bugs; no VS Code-side fix is possible without the browser vendors correcting their KeyboardEvent.code values.

## Change summary

On macOS with ISO keyboards, Chrome and Firefox swap IntlBackslash and Backquote scan codes, breaking keybindings like Ctrl+` in VS Code web.

## Best solution

Wait for upstream fixes in Chromium (crbug.com/1296783) and Firefox (bugzilla.mozilla.org/1755096). No VS Code-side workaround is feasible since the browser sends incorrect scan codes. The issue is correctly tracked here as upstream.
