# Issue #334669 — agentHost: Require explicit SDK download on metered connections

[https://github.com/microsoft/vscode/issues/334669](https://github.com/microsoft/vscode/issues/334669)

## Summary

Legitimate, still-open follow-up feature request (filed same day as its parent #334316) asking that automatic Agent SDK downloads be gated on metered-connection detection; nothing in the current agentSdkDownloader implementation does this yet, so the gap is real and there's no reason to close it.

## Change summary

Skip the automatic Claude/Codex Agent SDK download-on-use while the connection is metered, and instead surface a notification with an explicit Download action.

## Best solution

Wire the existing `IMeteredConnectionService` (already consumed by `postUpdateWidget.ts` and `pluginAutoUpdate.ts` for exactly this pattern: skip automatic work while metered, keep an explicit action available) into the agent-SDK download-on-use path in `src/vs/platform/agentHost/node/agentSdkDownloader.ts`, likely by having the workbench-side caller check metered state before invoking the automatic download and falling back to a setup notification with a Download action.
