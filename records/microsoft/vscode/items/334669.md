# Issue #334669 — agentHost: Require explicit SDK download on metered connections

[https://github.com/microsoft/vscode/issues/334669](https://github.com/microsoft/vscode/issues/334669)

## Summary

Keep open: current SDK resolution still downloads on a cache miss without checking metered-connection state, and remembered consent hides the explicit download offer. The existing metered-connection setting does not cover this path; no matching canonical or fixing PR was found.

## Change summary

Require an explicit Download action for missing or outdated Claude and Codex SDKs when the connection is metered, even after earlier download consent.

## Best solution

Make automatic SDK acquisition respect metered connections while preserving cached SDK use and an explicit per-agent Download action with explanatory setup messaging. Establish which connection state governs downloads on remote or standalone Agent Hosts before implementation.
