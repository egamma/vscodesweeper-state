# Issue #49588 — [Emmet] Include should be more like DocumentSelector

[https://github.com/microsoft/vscode/issues/49588](https://github.com/microsoft/vscode/issues/49588)

## Summary

The filename-pattern request remains unimplemented: current Emmet mappings still select by language ID, so they cannot distinguish .cfm templates from .cfc classes sharing the CFML language. Keep this accepted Backlog request open; the historical scheme restriction has changed, but that does not resolve the primary ask.

## Change summary

Allow Emmet language mappings to target filename patterns without changing a document's language ID.

## Best solution

Support filename-scoped Emmet mappings consistently across completion providers and abbreviation commands while preserving existing language-ID mappings. Settle the configuration representation and collision precedence before implementation.
