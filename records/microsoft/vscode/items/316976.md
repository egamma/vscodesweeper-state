# Issue #316976 — Agent Host Terminal: Streaming output rendering buggy in chat pane

[https://github.com/microsoft/vscode/issues/316976](https://github.com/microsoft/vscode/issues/316976)

## Summary

Team-authored bug report describing inconsistent streaming output rendering and output duplication/disappearance in the chat pane when running terminal commands via the agent host. No fix commit references this issue, and no related commits address the described streaming or duplication behavior — the bug appears still open on main.

## Change summary

Agent host terminal streaming output in the chat pane sometimes renders line-by-line as expected, other times only after command completion, and occasionally duplicates then disappears.

## Best solution

Investigate the streaming data flow in `chatTerminalCommandMirror.ts` and `chatTerminalToolProgressPart.ts` to find why terminal output updates are sometimes batched until completion and why duplicate rendering occurs. The duplication/disappearance pattern suggests a race between multiple update listeners or a buffer snapshot being replayed. A community commenter also reports persistent duplication with MCP server output, suggesting the issue may be broader than the original ping scenario.
