# Issue #305636 — "Configure Tools" rewrites YAML block sequence as inline array, corrupting .agent.md frontmatter

[https://github.com/microsoft/vscode/issues/305636](https://github.com/microsoft/vscode/issues/305636)

## Summary

Still reproduces on main: the rewriteTools method in promptFileRewriter.ts always serializes tools as an inline `[...]` array regardless of whether the original YAML used block sequence format, producing invalid or destructively reformatted YAML.

## Change summary

The "Configure Tools" UI rewrites YAML block sequences (`- item`) as inline arrays (`[item]`), corrupting `.agent.md` frontmatter format.

## Best solution

Extend the YAML parser to distinguish block-sequence vs inline-sequence style, and have `rewriteTools` in promptFileRewriter.ts preserve the original style (emit `\n  - item` lines for block sequences, `[item, ...]` for inline). The fix lives in `src/vs/workbench/contrib/chat/browser/promptSyntax/promptFileRewriter.ts` and possibly the parser types in `promptFileParser.ts`.
