- **Partial recovery is not a full fix:** https://github.com/microsoft/vscode/issues/295299#issuecomment-4800421513 reports an Arch Linux SIGSEGV with Electron 42 but not Electron 39. https://github.com/microsoft/vscode/issues/295299#issuecomment-5390008744 reports recovery with Code 1.131.0 and Electron 42.9.3 on that system only; neither comment establishes recovery on Enterprise Linux 8 or identifies a behavior-changing fix commit.
- **Current source boundary:** src/vs/workbench/services/dialogs/electron-browser/fileDialogService.ts delegates native open/save operations to the native host. src/vs/platform/native/electron-main/nativeHostMainService.ts forwards them to DialogMainService, whose showOpenDialog, showSaveDialog, and showMessageBox methods in src/vs/platform/dialogs/electron-main/dialogMainService.ts invoke Electron's native dialog APIs. This identifies an investigation boundary, not a conclusively faulty source path. Current .npmrc targets Electron 43.7.7; that version change does not prove resolution.
