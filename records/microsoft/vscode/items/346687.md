[https://github.com/microsoft/vscode/issues/346687](https://github.com/microsoft/vscode/issues/346687)

## Summary

Keep open: current source recognizes internal session links for pills and chat-window navigation, but not the product-protocol URLs generated by the session list's Copy Link action. This is a concrete remaining gap in a team-authored bug, not insufficient reproduction information.

## Change summary

Make copied session URLs render as session pills and open in the chat window where they are clicked, like equivalent internal session links.

## Best solution
