# Issue #333346 — Add plus button to add file on the fly

[https://github.com/microsoft/vscode/issues/333346](https://github.com/microsoft/vscode/issues/333346)

## Summary

Reasonable request that the Quick Open (Ctrl+P) picker offer a way to create the file when no match is found; current main's AnythingQuickAccessProvider only shows a static 'No matching results' item with no create-file action, so the gap is real and no canonical issue was found to fold it into.

## Change summary

When Ctrl+P finds no matching file, add a button/action to create the typed filename as a new file on the fly.

## Best solution

Extend AnythingQuickAccessProvider's no-results state (src/vs/workbench/contrib/search/browser/anythingQuickAccess.ts, NO_RESULTS_PICK around line 104) to offer a 'Create file <name>' action using the typed query, similar to how some other pickers offer inline creation.
