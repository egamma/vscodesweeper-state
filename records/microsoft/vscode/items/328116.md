# Issue #328116 — Markdown editor (preview) doesnt use stylesheet like markdown preview

[https://github.com/microsoft/vscode/issues/328116](https://github.com/microsoft/vscode/issues/328116)

## Summary

This is a valid customization gap in the experimental Markdown editor, not a regression: `markdown.styles` explicitly targets the preview and the new editor does not consume it. Route it to the Markdown editor owners as a feature request.

## Change summary

Allow the experimental Markdown editor to customize rendered Markdown styling, particularly heading colors, similarly to the standard preview.

## Best solution

Define a supported theming surface for the Markdown editor, preferably reusable CSS variables or theme colors for headings and other rendered elements; only reuse `markdown.styles` if preview styles can be loaded securely and mapped reliably onto the editor's different DOM.

- **theming surface:** `extensions/markdown-language-features/markdown-editor-src/editor.ts` selects the fixed `md-theme-vscode-default` theme, and `markdownEditor.css` only supplies general layout and editor-background styling.
