# Issue #292825 — Old extensions versions consuming disk space when using profiles

[https://github.com/microsoft/vscode/issues/292825](https://github.com/microsoft/vscode/issues/292825)

## Summary

Team-authored issue (alexdima, MEMBER) — must stay open for maintainer judgment. The existing cleanup mechanism in extensionsWatcher.ts#deleteExtensionsNotInProfiles should remove extension versions not referenced by any profile, but old versions are clearly persisting on disk when profiles are used.

## Change summary

Old extension versions accumulate on disk and are not cleaned up when using VS Code profiles, wasting disk space.

## Best solution

Investigate why `deleteExtensionsNotInProfiles` in `src/vs/platform/extensionManagement/node/extensionsWatcher.ts` fails to remove old extension versions. The `allExtensions` map tracks extension-version-to-profile mappings, and `deleteExtensionsNotInProfiles` should delete versions not in any profile — the gap is likely in how the map is populated during profile switches/updates, or in timing relative to extension updates.
