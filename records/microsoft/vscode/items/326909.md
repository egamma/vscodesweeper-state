# Issue #326909 — Allow grouping terminal profiles into nested submenus

[https://github.com/microsoft/vscode/issues/326909](https://github.com/microsoft/vscode/issues/326909)

## Summary

A real terminal-profile UX gap remains on current main. The Backlog Candidates community window is still active, so this should remain open as under discussion.

## Change summary

Allow users to organize configured terminal profiles into nested groups in the terminal dropdown.

## Best solution

Add optional grouping metadata to terminal profile configuration and render grouped profiles as submenus while preserving the existing flat behavior for ungrouped profiles.
