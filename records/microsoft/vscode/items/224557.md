# Issue #224557 — `when` condition set to `false` upon configuring keybinding

[https://github.com/microsoft/vscode/issues/224557](https://github.com/microsoft/vscode/issues/224557)

## Summary

Still reproduces on main: when editing a keybinding in the UI, the `when` clause is read from the serialized (constant-inlined) expression, so static keys like `isDevelopment` reduce the whole clause to `false` before it's written back to keybindings.json.

## Change summary

Editing a keybinding in the Keybindings Editor UI writes `"when": "false"` because static context keys (e.g. `isDevelopment`) are inlined during parsing and the serialized result replaces the original expression.

## Best solution

When persisting the `when` clause during a keybinding edit, use the original string expression from the keybinding source (the raw `when` text from the contribution or defaults) rather than the serialized form of the reduced `ContextKeyExpression`. The fix likely involves preserving the original `when` string on `ResolvedKeybindingItem` and using it in `keybindingsEditorModel.ts` line 283 and `keybindingsEditor.ts` line 226.
