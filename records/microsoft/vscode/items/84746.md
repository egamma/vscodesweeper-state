# Issue #84746 — Enable breadcrumbs for unsaved files

[https://github.com/microsoft/vscode/issues/84746](https://github.com/microsoft/vscode/issues/84746)

## Summary

Keep open: current source still excludes untitled editors before creating their symbol breadcrumbs. The earlier implementation attempt was closed without merging, and the maintainer explicitly supported a dynamic solution that avoids an empty bar.

## Change summary

Show symbol breadcrumbs in unsaved, untitled files without displaying a file path.

## Best solution

Support symbol breadcrumbs for untitled editors when outline content becomes available, while keeping empty or unsupported untitled editors free of an empty breadcrumb bar. Preserve existing saved-file navigation and breadcrumb settings.
