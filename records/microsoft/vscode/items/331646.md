# Issue #331646 — Modern UI: Editor tab description and icon colors do not match the filename color

[https://github.com/microsoft/vscode/issues/331646](https://github.com/microsoft/vscode/issues/331646)

## Summary

Confirmed in the current source: Modern UI's tabs.css only re-colors the tab filename (`a.label-name`) with `modernEditorTab.*Foreground`, while the description span and icon are separate DOM siblings that keep inheriting the classic `tab.*Foreground` set at the `.tab` element level — exactly the mismatch the reporter describes. This is a real, narrow CSS gap worth fixing, not a close.

## Change summary

In Modern UI, editor tab descriptions and icons keep using classic `tab.*Foreground` colors while the filename uses the new `modernEditorTab.*Foreground` colors, producing mismatched foreground colors within the same tab.

## Best solution

Extend the modernUI override rules in tabs.css (around the `.tab-label:not(.monaco-decoration-itemColor) a` selectors) to also target `.label-description` and the icon element (`.monaco-icon-label::before` / `.monaco-icon-label-iconpath`), so the whole tab label consistently uses `modernEditorTab.*Foreground` instead of falling back to the inherited classic `tab.*Foreground`.
