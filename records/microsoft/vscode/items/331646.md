# Issue #331646 — Modern UI: Editor tab description and icon colors do not match the filename color

[https://github.com/microsoft/vscode/issues/331646](https://github.com/microsoft/vscode/issues/331646)

## Summary

Confirmed in source: Modern UI's tab CSS only overrides the filename anchor's color, so the tab description and unthemed icons keep inheriting the classic `tab.*Foreground` color set on the outer `.tab` element, producing mismatched colors within one tab.

## Change summary

In Modern UI, editor tab description text and icons use `tab.*Foreground` theme colors while the filename uses `modernEditorTab.*Foreground`, so they don't match.

## Best solution

Extend the modern-tab foreground overrides in src/vs/workbench/contrib/modernUI/browser/media/tabs.css so they apply to the whole `.tab-label` (which wraps the icon, name, and description), not just the nested `a`, so description/icon inherit the same modern color as the filename.
