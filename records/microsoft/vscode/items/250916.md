# Issue #250916 — Terminal is extremely sluggish when using fish shell with `fish-async-prompt` extension

[https://github.com/microsoft/vscode/issues/250916](https://github.com/microsoft/vscode/issues/250916)

## Summary

The sluggishness and `^[[I` (focus-in) escape sequence flooding is caused by the interaction between the third-party `fish-async-prompt` fish shell plugin and VS Code's terminal shell integration prompt wrapping. The root cause likely involves the async prompt plugin re-rendering the prompt in a way that triggers rapid focus state changes. An open PR exists in the fish-async-prompt repo (acomagu/fish-async-prompt#89), but it's unclear whether VS Code's shell integration should also be hardened against this pattern. Keeping open as the interaction may warrant investigation on the VS Code side.

## Change summary

Terminal becomes extremely sluggish with 100% CPU and floods of `^[[I` focus-in escape sequences when using the fish shell with the `fish-async-prompt` plugin.

## Best solution

Investigate whether VS Code's fish shell integration prompt wrapping (in `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.fish`) can be made more resilient to third-party prompt plugins that asynchronously replace `fish_prompt`. The `__preserve_fish_prompt` mechanism copies `fish_prompt` once, but async prompt plugins continuously replace it, potentially causing conflicts. A fix on the fish-async-prompt side (https://github.com/acomagu/fish-async-prompt/pull/89) may also resolve this. The terminal team should determine whether hardening is needed on the VS Code side or if this is purely a third-party plugin compatibility issue.
