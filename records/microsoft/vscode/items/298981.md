# Issue #298981 — New Chat Shows Agent Prompts of Custom Agent

[https://github.com/microsoft/vscode/issues/298981](https://github.com/microsoft/vscode/issues/298981)

## Summary

Keep open as a feature request: existing prompt recommendation configuration does not automatically surface prompts associated with the selected custom agent, and handoff suggestions require a completed response. No verified older canonical owns this specific request.

## Change summary

Show agent-specific prompt files or handoff prompts as suggestions when starting a new chat with a custom agent selected.

## Best solution

Consider agent-aware starter suggestions in the chat empty state, with a product decision on whether handoffs intended for transitions should also serve as starting prompts. Preserve existing explicit recommendation controls and post-response handoff behavior.
