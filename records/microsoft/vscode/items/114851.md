# Issue #114851 — VIM mode like sublime

[https://github.com/microsoft/vscode/issues/114851](https://github.com/microsoft/vscode/issues/114851)

## Summary

Keep open: this Backlog request has 1,370 community upvotes, and current VS Code still provides no built-in modal editing mode. Extensions cover much of the workflow, but documented platform limitations leave meaningful performance and editor-integration gaps.

## Change summary

Provide a responsive, reliable Vim-style modal editing experience comparable to Sublime Text's built-in mode.

## Best solution

Prefer improving the extension platform so Vim, Neovim, and Helix extensions can deliver native-quality modal editing without adding a Vim implementation to core. Continue the concrete work in the open performance, search API, and block-cursor issues, then reassess whether any central capability remains impossible for extensions.

## Vision fit

- **Fit:** rejected
- **Reason:** A bundled Vim implementation conflicts with the project's preference for a lightweight core and powerful extensions, although underlying extension API gaps remain legitimate core work.
- **Evidence:** Values and guardrails: “Out of the box, VS Code is a text editor: lightweight and fast” and “The power lives in extensions.”
