## Summary

The missing GPG passphrase prompt is already covered by an older, verified open issue with the same GUI-commit failure and terminal-unlocking workaround. Consolidate there, preserving this report's Remote-SSH reproduction details.

## Change summary

Signed commits from the Source Control UI fail without prompting for the GPG passphrase, particularly over Remote-SSH, until the key is unlocked through a terminal.

## Best solution

Track the missing interactive GPG signing support in https://github.com/microsoft/vscode/issues/43809, including this Windows-to-Ubuntu Remote-SSH case. Successful signing should not require a preliminary terminal signing operation.
