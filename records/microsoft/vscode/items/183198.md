# Issue #183198 — While draging to create mutipile-cursors the start point is where the cursor used to be rather than the position where I clicked.

[https://github.com/microsoft/vscode/issues/183198](https://github.com/microsoft/vscode/issues/183198)

## Summary

This is a duplicate of the long-standing canonical issue #5402, which tracks the same request: column selection (Alt+Shift+drag) should anchor from the click position, not the current cursor position. Both issues describe identical behavior and cite the same editor comparisons.

## Change summary

Alt+Shift+drag to create multiple cursors anchors from the cursor's original position instead of the mouse click position, unlike Sublime, Xcode, and JetBrains editors.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/5402, which is the canonical tracker for improving column selection to start from the click position. The second part of this report (full-width character alignment) is a separate concern but also a known limitation of column selection.
