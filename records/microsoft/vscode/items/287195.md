# Issue #287195 — Copilot Chat - all files are "sensitive", apparently

[https://github.com/microsoft/vscode/issues/287195](https://github.com/microsoft/vscode/issues/287195)

## Summary

Current main still classifies every file in a workspace beneath a hidden home-directory folder as a system file. The defect is source-reproducible and should remain open; the newer report https://github.com/microsoft/vscode/issues/336722 describes the same symptom but cannot be the canonical for this re-reviewed older issue.

## Change summary

Copilot repeatedly requests sensitive-file approval for ordinary files when the workspace is nested beneath a dot-prefixed directory in the user's home directory.

## Best solution

Honor the existing workspace exception for projects opened beneath hidden home-directory paths, while retaining confirmation for protected files outside the workspace and explicitly sensitive workspace files.
