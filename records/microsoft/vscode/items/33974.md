# Issue #33974 — Smart Tabs - Feature Request

[https://github.com/microsoft/vscode/issues/33974](https://github.com/microsoft/vscode/issues/33974)

## Summary

This accepted Backlog request remains necessary: current main still cannot distinguish indentation tabs from alignment spaces. Its 45 community upvotes also preclude a staleness close.

## Change summary

Add smart tabs that use tabs for block indentation while preserving spaces used for alignment.

## Best solution

Implement an explicit smart-tabs mode in the core editor that preserves the tab indentation prefix and subsequent alignment spaces consistently across Enter, reindent, paste, and deletion operations.
