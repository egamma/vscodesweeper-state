# Issue #337732 — Chat asks for approval to read an image explicitly pasted as context

[https://github.com/microsoft/vscode/issues/337732](https://github.com/microsoft/vscode/issues/337732)

## Summary

Team-authored (sbatten, MEMBER) and only hours old, so this stays open regardless — but it's also a real, source-confirmed gap: the confirmation layer already auto-approves reads of session-attachment paths, yet the actual OS-level sandbox never grants read access to that directory, so a sandboxed session still hard-denies reading a pasted image.

## Change summary

When the agent sandbox is enabled, reading an image explicitly pasted into chat as context is blocked by the OS-level sandbox even though the chat confirmation flow is designed to auto-approve it.

## Best solution

Grant the session's attachments directory (`ISessionDataService.getSessionDataDir(session)/attachments`) as a readonly path in the sandbox config the same way the shell-init-script directory is granted, so the sandbox floor matches the confirmation layer's existing auto-approval.
