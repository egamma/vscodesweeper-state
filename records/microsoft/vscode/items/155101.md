# Issue #155101 — [json] Show key value pairs of JSON Array in `Outline` view

[https://github.com/microsoft/vscode/issues/155101](https://github.com/microsoft/vscode/issues/155101)

## Summary

Keep open as an upstream JSON language-service enhancement: current main still emits each array element's numeric index as its Outline name without including the value. The issue is already routed to the JSON area, and no older open canonical matching this observable behavior was found.

## Change summary

Show JSON array element values alongside or instead of numeric indexes in the Outline view.

## Best solution

Define concise Outline labeling semantics for primitive and structured array elements, implement them in `JSONDocumentSymbols.findDocumentSymbols2` in `microsoft/vscode-json-languageservice`, add document-symbol tests there, and then update VS Code's language-service dependency.

The requested capability therefore remains absent.
