# Issue #339943 — Agents window Settings editor says "Modified in Workspace" though the tab is named "Agents Window"

[https://github.com/microsoft/vscode/issues/339943](https://github.com/microsoft/vscode/issues/339943)

## Summary

Confirmed on main: the scope-override indicator hardcodes the localized string "Workspace" for the workspace scope, ignoring the custom workspace name ("Agents Window") that the settings tab itself already uses, so the indicator text doesn't match the visible tab label in the Agents window.

## Change summary

In the Agents window, the Settings editor's "Modified in Workspace" indicator should say "Modified in Agents Window" to match the actual tab label.

## Best solution

Have getInlineScopeDisplayText / getAccessibleScopeDisplayText / getAccessibleScopeDisplayMidSentenceText in settingsEditorSettingIndicators.ts use the workspace's display name (contextService.getWorkspace().name) for the workspace scope, the same way preferencesWidgets.ts already builds the workspace tab label (`this.contextService.getWorkspace().name || localize('workspaceSettings', "Workspace")`).
