# Issue #329024 — Modern UI workbench styling feels visually noisy and less usable

[https://github.com/microsoft/vscode/issues/329024](https://github.com/microsoft/vscode/issues/329024)

## Summary

This is active design feedback on the still-experimental `workbench.experimental.modernUI` setting, which is under active development (dedicated `src/vs/workbench/contrib/modernUI/` contribution with several CSS files for rounded corners, shadows, tabs, padding, etc.) — it's a legitimate discussion thread for the design owners, not something to close.

## Change summary

Feedback that the experimental Modern UI's floating-card styling (rounded corners, gaps, reduced tab distinction) is visually noisy, plus a request to either keep a durable opt-out or revisit the visual treatment before any default change.

## Best solution

Route this to the workbench/UX design owners as consolidated feedback on the still-experimental Modern UI (src/vs/workbench/contrib/modernUI/browser/*) — a workaround already exists (`workbench.experimental.modernUI: false`), so the open question is whether that opt-out stays durable if/when Modern UI becomes default, and whether specific complaints (tab distinguishability, pane contrast) get addressed before graduation.
