# Issue #329024 — Modern UI workbench styling feels visually noisy and less usable

[https://github.com/microsoft/vscode/issues/329024](https://github.com/microsoft/vscode/issues/329024)

## Summary

Legitimate design feedback on an active, opt-in experiment; the core ask (a durable way to keep the current UI) is already satisfied since `workbench.experimental.modernUI` defaults to `false` and is fully toggleable, but the broader design critique is genuine subjective feedback the team should weigh before any default change — keeping open as under-discussion.

## Change summary

Reporter and several commenters find the experimental Modern UI (floating cards, rounded corners, gaps) visually noisy/cluttered compared to the current workbench, and ask for a durable opt-out or a redesign before any default-value change.

## Best solution

No action needed for the opt-out ask itself — `workbench.experimental.modernUI` (src/vs/workbench/browser/workbench.contribution.ts:814) already defaults to `false` and can be left off indefinitely. The remaining ask (reconsider spacing/rounding before promoting to default) is a live design decision for the workbench/UX team to weigh against the mixed feedback already visible in this thread (comments both praising and criticizing the change).
