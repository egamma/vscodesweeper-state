# Issue #57633 — Allow changing triple-click (and double-click) behaviour

[https://github.com/microsoft/vscode/issues/57633](https://github.com/microsoft/vscode/issues/57633)

## Summary

Keep this accepted, well-supported request open: current source still hard-codes triple-click to select a line, with no option to retain word selection. The older mouse-shortcut customization issue is related, but does not establish the same observable symptom required to consolidate this re-reviewed item.

## Change summary

Allow users to disable triple-click selection expansion or customize multi-click selection behavior.

## Best solution

Provide an opt-in editor behavior that prevents an accidental third click from expanding a word selection to the entire line, preserving current defaults. Settle the behavior of subsequent clicks and dragging before extending this into general mouse-action customization.
