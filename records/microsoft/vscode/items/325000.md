# Issue #325000 — Dropping a URL into the editor from Firefox requires holding shift

[https://github.com/microsoft/vscode/issues/325000](https://github.com/microsoft/vscode/issues/325000)

## Summary

Legitimate bug: `isDragIntoEditorEvent` in `editorDropTarget.ts` only checks `e.shiftKey`, so Firefox URL drags (which include a `Files` data transfer type) are treated as file drops rather than text drops. An open PR (#325015) proposes a fix by detecting `text/x-moz-url`.

## Change summary

Dragging a URL from Firefox's address bar into a VS Code editor on Windows requires holding Shift, unlike Chrome which pastes directly.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/325015, which updates `isDragIntoEditorEvent` in `src/vs/workbench/browser/parts/editor/editorDropTarget.ts` to detect the `text/x-moz-url` MIME type so Firefox URL drags bypass the shift requirement.
