# Issue #319956 — editor.showUnused in .js is not working

[https://github.com/microsoft/vscode/issues/319956](https://github.com/microsoft/vscode/issues/319956)

## Summary

This is as-designed: `editor.showUnused` only controls the visual fading of diagnostics already reported by a language service — it does not generate them. For plain `.js` files without a `jsconfig.json` or `js/ts.implicitProjectConfig.checkJs` enabled, the TypeScript language service does not perform the semantic analysis needed to report unused variables or unreachable code.

## Change summary

Unused variables and unreachable code are not grayed out in plain .js files when only `editor.showUnused` is enabled.

## Best solution

Close as designed. The reporter needs to enable `js/ts.implicitProjectConfig.checkJs` in settings (or create a `jsconfig.json` with `"checkJs": true`) to get unused-variable diagnostics in JavaScript files. The `editor.showUnused` setting is only the presentation layer.

  > Thanks for the report. The `editor.showUnused` setting only controls whether code *already diagnosed as unused* by a language service gets visually faded — it doesn't generate those diagnostics itself.
  > 
  > For plain `.js` files (without a `jsconfig.json` or `tsconfig.json`), the TypeScript language service does not perform semantic analysis by default, so no unused-variable or unreachable-code diagnostics are reported. To enable this:
  > 
  > 1. Set `"js/ts.implicitProjectConfig.checkJs": true` in your VS Code settings, **or**
  > 2. Add a `jsconfig.json` at your project root with `{ "compilerOptions": { "checkJs": true } }`
  > 
  > Once enabled, unused variables and unreachable code will be faded as expected. This is the same behavior discussed in https://github.com/microsoft/vscode/issues/321979.
