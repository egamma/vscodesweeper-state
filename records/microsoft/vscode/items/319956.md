# Issue #319956 — editor.showUnused in .js is not working

[https://github.com/microsoft/vscode/issues/319956](https://github.com/microsoft/vscode/issues/319956)

## Summary

This is expected behavior for the sample: `editor.showUnused` only controls fading for unused symbols, while the shown `const b = 1` after `return` is unreachable code, not an unused declaration diagnostic. JavaScript/TypeScript unreachable-code reporting is controlled by `allowUnreachableCode`, and the built-in TypeScript language features extension registers `typescript.reportStyleChecksAsWarnings` for surfacing that class of check.

## Change summary

The reporter expects `editor.showUnused` to gray out JavaScript code after a `return` statement.

## Best solution

Keep the existing split between unused-symbol fading and unreachable-code diagnostics; users who want unreachable JavaScript code reported should configure TypeScript/JavaScript checking behavior rather than `editor.showUnused`.
