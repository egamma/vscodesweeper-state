# Issue #340186 — Support background execution for the built-in runSubagent tool

[https://github.com/microsoft/vscode/issues/340186](https://github.com/microsoft/vscode/issues/340186)

## Summary

Real, well-specified gap confirmed on main — the built-in runSubagent tool is synchronous only (its own system message says 'Agents do not run async or in the background') — and an open PR (#340194) already implements background execution, so this should stay open as a human-owned review/land candidate rather than being closed or handed to an agent.

## Change summary

Make the built-in runSubagent tool support background execution by default (return an agent ID immediately, add read_agent-style status/cancel, support up to 10 concurrent agents per chat, persist results across reloads) instead of always blocking until the child agent finishes.

## Best solution

Review and land (or iterate on) the linked PR https://github.com/microsoft/vscode/pull/340194, which already implements this against the runSubagentTool.ts source referenced in the issue.
