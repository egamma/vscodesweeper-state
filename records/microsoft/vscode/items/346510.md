# Issue #346510 — Remove option for vscode-pet

[https://github.com/microsoft/vscode/issues/346510](https://github.com/microsoft/vscode/issues/346510)

## Summary

A persistent off switch already exists: /vscode-pet toggles Blobby off and remembers that choice across restarts. The Agents window also exposes this through its checked Pet background-menu item.

## Change summary

Provide a way to permanently disable Blobby rather than temporarily sending it away.

## Best solution

Use the existing /vscode-pet toggle or uncheck Pet (/vscode-pet) in the new-session background context menu; neither requires a new removal option.
