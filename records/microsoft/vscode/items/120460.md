# Issue #120460 — [Gutter] Git Decorations bounding box and appearing

[https://github.com/microsoft/vscode/issues/120460](https://github.com/microsoft/vscode/issues/120460)

## Summary

The accidental-click portion was fixed in 2023, but the hover portion remains on current main: hovering anywhere in the editor margin reveals Source Control decorations, including while targeting folding controls.

## Change summary

Keep Source Control gutter decorations from intercepting folding clicks or appearing when the pointer is over the folding-control area.

## Best solution

Retain the disjoint folding and Source Control click regions introduced by https://github.com/microsoft/vscode/pull/184339, and decide whether `scm.diffDecorationsGutterVisibility: "hover"` should reveal decorations only over their own gutter strip rather than the entire editor margin.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/scm/browser/media/dirtydiffDecorator.css`, `src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts`, `src/vs/workbench/contrib/scm/browser/quickDiffWidget.ts`
- **Validation:** With `scm.diffDecorationsGutterVisibility` set to `hover`, verify that hovering and clicking a folding control does not reveal or activate the Source Control decoration, hovering the intended Source Control gutter target does reveal it, and both folding and quick-diff clicks continue to work at their boundary.
- **Behavior:**

  > When Source Control gutter decorations use hover visibility, moving the pointer over a folding control should not reveal or activate the Source Control decoration. Moving over the intended Source Control gutter target should reveal it and allow opening the quick diff. Folding controls must remain easy to activate, including on modified lines.
- **Trace:**

  > Commit 30092f40a370863c15d0e6066e0af152d3e327f3 from https://github.com/microsoft/vscode/pull/184339 already separated the click ranges after the same collision was confirmed in https://github.com/microsoft/vscode/issues/184338. Current click handling is in QuickDiffController.onEditorMouseDown in src/vs/workbench/contrib/scm/browser/quickDiffWidget.ts and FoldingController.onEditorMouseDown in src/vs/editor/contrib/folding/browser/folding.ts. The remaining path is visual: QuickDiffWorkbenchController sets opacity to zero for hover mode, but dirtydiffDecorator.css reveals decorations through `.margin:hover`, which includes the folding area. Preserve the existing click boundaries and non-hover visibility modes.
- **Open decisions:**
  - Should hover visibility activate only over the Source Control decoration strip, or over a larger discoverability target that explicitly excludes folding controls?
