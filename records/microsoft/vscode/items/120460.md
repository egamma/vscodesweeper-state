# Issue #120460 — [Gutter] Git Decorations bounding box and appearing

[https://github.com/microsoft/vscode/issues/120460](https://github.com/microsoft/vscode/issues/120460)

## Summary

Still reproduces on main: the dirty-diff gutter click hitbox overlaps the folding area, and hover-mode decorations appear when hovering anywhere in the margin (not just the decoration strip). The code itself has a TODO acknowledging the collision.

## Change summary

Clicking the folding gutter area accidentally triggers the SCM dirty-diff peek widget because the decoration click hitbox is wider than the visible indicator; additionally, hover-mode decorations appear when hovering over the folding area.

## Best solution

Tighten the hit-test in `quickDiffWidget.ts` so it only activates within the actual decoration strip (the existing ±3px guard on line 708 is evidently not narrow enough in practice), and scope the CSS `.margin:hover` rule in `dirtydiffDecorator.css` to only the lines-decoration lane rather than the entire margin. The TODO on line 707 (`TODO@joao TODO@alex TODO@martin`) confirms the team is aware of the collision.
