# Issue #323430 — Cannot connect to ***: Client offered protocol versions [0.5.0], none of which are compatible with this server's version 0.4.0 (server accepts ^0.4.0).

[https://github.com/microsoft/vscode/issues/323430](https://github.com/microsoft/vscode/issues/323430)

## Summary

Keep open: multiple users confirmed protocol mismatches that Update Server could not resolve, and the current upgrade path still permits that dead end. One user's recovery on 1.138.0 is encouraging, but does not establish a fix for this team-authored report; the verified related open issues are newer and cannot replace it under the re-review rules.

## Change summary

Opening the Agents Window fails protocol negotiation, while Update Server reports that the incompatible server is already current.

## Best solution

Make the remote agent-host recovery flow distinguish channel-latest from client-compatible, with an actionable outcome when updating cannot restore compatibility. Coordinate the remaining work with https://github.com/microsoft/vscode/issues/325721 and separately account for stale-supervisor reuse described in https://github.com/microsoft/vscode/issues/334296.
