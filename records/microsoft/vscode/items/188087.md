# Issue #188087 — Undoing a file move creates bogus import updates

[https://github.com/microsoft/vscode/issues/188087](https://github.com/microsoft/vscode/issues/188087)

## Summary

Team-authored bug report about a race condition between undoing a file move and the async TypeScript import-path update — no fix found on main, stays open.

## Change summary

Undoing a file move before import updates complete produces corrupted edits across many files.

## Best solution

The undo of a file move should either wait for the pending workspace edit (import updates) to complete before reversing, or the import-update workspace edit should be grouped with the move so they undo atomically. Likely involves coordination between the file-move undo path and the `willRenameFiles` participant mechanism in the working copy file service.
