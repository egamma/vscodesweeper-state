# Issue #328397 — Remote agent host is provisioned over SSH regardless of opt-out (the #326902 fix does not reach the CLI)

[https://github.com/microsoft/vscode/issues/328397](https://github.com/microsoft/vscode/issues/328397)

## Summary

Confirmed on current main: CLI remote entry points start the agent-host supervisor unconditionally, so the workbench opt-out cannot prevent remote provisioning. This is a distinct remaining CLI path not covered by the earlier workbench fix.

## Change summary

Remote-SSH provisions and updates a separate remote agent host even when AI and remote agent hosts are disabled.

## Best solution

Propagate the client's AI opt-out through the Remote-SSH `command-shell` invocation and make both CLI remote startup paths skip `ensure_supervisor_running`; normal editor and extension-host startup should continue without `agentHostProxy`.
