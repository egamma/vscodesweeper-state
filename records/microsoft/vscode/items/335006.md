# Issue #335006 — `${PLUGIN_ROOT}` / `${PLUGIN_DATA}` never expanded for Agent Plugins 1.0 (canonical schema) plugins — pluginRootTokens empty for format 3

[https://github.com/microsoft/vscode/issues/335006](https://github.com/microsoft/vscode/issues/335006)

## Summary

Confirmed on main: the Agent Plugins 1.0 (canonical schema) format config in pluginParsers.ts ships empty `pluginRootTokens`/`pluginRootEnvVars` arrays, so `${PLUGIN_ROOT}`/`${PLUGIN_DATA}` are never expanded for that format's mcp.json. An open PR already targets this exact fix, so the issue should stay open pending review/merge rather than being closed now.

## Change summary

For plugins using the canonical Agent Plugins 1.0 `$schema`, `${PLUGIN_ROOT}`/`${PLUGIN_DATA}` placeholders in mcp.json args/env/cwd are never expanded and the corresponding env vars are never injected into the MCP server subprocess.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/336889 (or an equivalent fix) that populates format-aware token/env-var expansion for AGENT_PLUGIN_FORMAT, scoped to stdio args/env/cwd as the issue's root-cause analysis recommends.
