# Issue #335006 — `${PLUGIN_ROOT}` / `${PLUGIN_DATA}` never expanded for Agent Plugins 1.0 (canonical schema) plugins — pluginRootTokens empty for format 3

[https://github.com/microsoft/vscode/issues/335006](https://github.com/microsoft/vscode/issues/335006)

## Summary

Partially fixed: merged PR #338995 (commit 4fee1b66c, milestone 1.141.0) now expands `${PLUGIN_ROOT}` for Agent Plugins 1.0 MCP servers, confirmed on main in src/vs/platform/agentPlugins/common/pluginParsers.ts. The `${PLUGIN_DATA}` half of the report is still unaddressed — the project's own tests show it is deliberately left literal — and an open community PR (#336889) already targets exactly that gap, so this should stay open pending that work, not close.

## Change summary

For Agent Plugins 1.0 (canonical schema) plugins, `${PLUGIN_ROOT}` and `${PLUGIN_DATA}` placeholders in mcp.json were never expanded in stdio args/env/cwd.

## Best solution

Review/land (or supersede) PR https://github.com/microsoft/vscode/pull/336889, updated to avoid re-doing the now-merged PLUGIN_ROOT work, so it adds `${PLUGIN_DATA}` expansion with a lazily-created, client-managed persistent storage directory per plugin.
