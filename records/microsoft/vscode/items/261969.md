# Issue #261969 — `git` staged changes are harder to undo

[https://github.com/microsoft/vscode/issues/261969](https://github.com/microsoft/vscode/issues/261969)

## Summary

Keep open as a request to revert staged hunks directly from the editor gutter. Current source still lacks that action; the discussion establishes a longstanding limitation rather than a confirmed regression.

## Change summary

Allow staged changes to be reverted from the editor's quick-diff UI without first visiting Source Control to unstage them.

## Best solution

Provide a direct staged-hunk revert workflow in the Git quick-diff UI, with explicit semantics for overlapping staged and unstaged edits. Preserve the distinction between reverting working-tree edits and removing staged changes.
