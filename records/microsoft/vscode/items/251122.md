# Issue #251122 — Respect explorer.excludeGitIgnore in Multi-root Workspace Folders

[https://github.com/microsoft/vscode/issues/251122](https://github.com/microsoft/vscode/issues/251122)

## Summary

The bug remains source-reproducible on current main: Explorer maintains a separate ignore tree for each workspace root, so a nested root does not inherit the applicable `.gitignore` from its enclosing root. This issue is the canonical report and should remain open for a bounded Explorer fix.

## Change summary

Make `explorer.excludeGitIgnore` honor an enclosing workspace root's `.gitignore` when displaying a nested folder that is also a multi-root workspace entry.

## Best solution

Explorer filtering should apply all relevant Git ignore rules to nested workspace roots while preserving per-resource configuration, nested `.gitignore` precedence, negation rules, and existing behavior for unrelated roots.
