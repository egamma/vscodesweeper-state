# Issue #165748 — Re-explore turning on transform optimization in notebook

[https://github.com/microsoft/vscode/issues/165748](https://github.com/microsoft/vscode/issues/165748)

## Summary

The performance debt remains on current main: notebook lists still explicitly disable the list's default transform optimization. Recent overlay-layout improvements make reassessment timely, but no change has enabled or benchmarked the optimization.

## Change summary

Reassess and, if widget behavior permits, enable transform-based layout and paint optimization for notebook scrolling.

## Best solution

Benchmark notebook scrolling with `transformOptimization` enabled, verify context menus and editor overlay widgets are not clipped or misplaced, then remove the explicit opt-out in `notebookEditorWidget.ts` if those checks pass.
