# Issue #325608 — Sessions with two chats only explains first chat

[https://github.com/microsoft/vscode/issues/325608](https://github.com/microsoft/vscode/issues/325608)

## Summary

Still reproducible from current source: a session-level `get_session_context` request reads only the default chat, so work recorded in peer chats is omitted. The maintainer-confirmed bug remains open and has no canonical issue or landed fix.

## Change summary

Make explanations of a multi-chat session account for work performed across all of that session's chats.

## Best solution

Session-level context should expose every peer chat sufficiently for the model to explain the complete session, while an explicit chat link should continue to return only that selected chat.
