Legitimate, well-upvoted feature request (89 👍) for tmux control mode integration in the terminal. No implementation exists on main; a third-party extension now covers this. The request remains valid for native support and sits correctly in Backlog.

## Change summary

Add native support for tmux's control mode (-CC flag) so VS Code can manage tmux windows/panes through its own UI and persist terminal sessions across reloads.
