# Issue #318260 — Scroll issues in markdown with mermaid

[https://github.com/microsoft/vscode/issues/318260](https://github.com/microsoft/vscode/issues/318260)

## Summary

Legitimate bug report with the built-in mermaid preview causing scroll jumping in markdown editor. The reporter provided the requested info (file content and extensions-disabled confirmation), and multiple users confirm. The `info-needed` label appears outdated — routing to the markdown area for investigation.

## Change summary

Editing a markdown file with mermaid diagrams and preview open causes the editor scroll to jump between the cursor and the beginning of the file.

## Best solution

Investigate how the built-in mermaid extension's asynchronous rendering in the preview webview interacts with the markdown scroll sync mechanism. The mermaid diagram rendering likely changes element heights after initial layout, causing the scroll sync in `extensions/markdown-language-features/preview-src/scroll-sync.ts` and `index.ts` to miscalculate positions. A fix would likely need to suppress or debounce scroll sync during mermaid re-renders, similar to the existing `scrollDisabledCount` pattern.
