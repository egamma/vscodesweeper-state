# Issue #300314 — Add Built-in "Review" Agent Mode to GitHub Copilot

[https://github.com/microsoft/vscode/issues/300314](https://github.com/microsoft/vscode/issues/300314)

## Summary

VS Code already ships a comprehensive built-in Review capability in GitHub Copilot — including a review agent, review commands for staged/unstaged/file changes, selection review, custom review instructions, and a dedicated comment controller — covering everything this request asks for.

## Change summary

Request for a built-in 'Review' agent mode in GitHub Copilot for structured code review of quality, security, style, and bugs.

Keep the shipped review functionality (`github.copilot.chat.review.*` commands, `github.copilot.chat.reviewAgent.enabled` setting, review intent in chat modes). The request is fully addressed by what shipped in 1.116.0 and has been continuously improved since.

  > Thanks for the feature request! Since this was filed (against 1.111.0-insider), VS Code has shipped a comprehensive built-in Review capability in Copilot. You can:
  > 
  > - Use the **review intent** in chat to trigger structured code reviews
  > - Review staged, unstaged, or all changes via SCM context menu actions (`Copilot: Review Changes`)
  > - Review a selection directly from the editor context menu
  > - Customize review behavior with `.copilot-review-instructions.md` files or the `github.copilot.chat.reviewSelection.instructions` setting
  > - Navigate, apply, or discard individual review suggestions inline
  > 
  > This is controlled by the `github.copilot.chat.reviewAgent.enabled` setting. Please update to the latest VS Code and give it a try — I believe this covers what you were looking for. If something is still missing, please open a new issue with specifics.

## Evidence
