# Issue #300314 — Add Built-in "Review" Agent Mode to GitHub Copilot

[https://github.com/microsoft/vscode/issues/300314](https://github.com/microsoft/vscode/issues/300314)

## Summary

Built-in code-review commands already provide structured reviews without custom setup, but they do not establish the requested selectable Review agent mode. Keep this open for a product decision about that remaining experience; maintainers have already expressed interest in the work.

## Change summary

Provide a built-in Review agent mode for structured code-quality, security, style, and bug reviews without user-authored instructions.

## Best solution

Make structured review discoverable from the chat agent picker, with an explicit review scope and findings experience that complements the existing review commands. Decide whether this is a conversational review agent or a picker entry into the existing review workflow before implementation.
