## Summary

This is a specific manifestation (on restart) of the same root cause tracked by #150257 — custom editors on untitled files trigger the untitled working copy system to open a duplicate text editor tab. Proposing duplicate close against the older, broader canonical issue.

## Change summary

Custom editors for untitled files open twice (once as custom editor, once as text editor) when VS Code restarts.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/150257 which tracks the broader problem of custom editors + untitled files producing duplicate tabs. The fix needs to ensure the untitled working copy system respects custom editor ownership and doesn't independently restore/create a text editor for the same resource.
