# Issue #326529 — Workspace keybindings in keybindings.json are not being loaded/applied in this window, while the same entries in User/keybindings.json work

[https://github.com/microsoft/vscode/issues/326529](https://github.com/microsoft/vscode/issues/326529)

## Summary

This is not a bug: VS Code has no workspace-level keybindings.json feature at all — keybindings are only ever loaded from the user-level file, so "no keybinding entries" is expected, not a regression. This is exactly the long-standing feature request tracked by the open canonical issue, already flagged by a commenter as a duplicate.

## Change summary

Reporter expected a workspace-level keybindings.json (in the workspace/.vscode folder) to be loaded the same way user keybindings.json is, but workspace bindings are silently ignored.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/23757 ("Allow project specific keybindings"), which tracks adding a genuine workspace-scoped keybindings file; nothing here adds a distinct requirement beyond that request.
