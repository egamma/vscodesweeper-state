# Issue #17977 — Preserve undo/redo buffer when saving a file "as" or untitled file

[https://github.com/microsoft/vscode/issues/17977](https://github.com/microsoft/vscode/issues/17977)

## Summary

A real gap remains on current main: Save As copies content into a new model but does not transplant undo/redo state. This accepted Backlog request has 26 community upvotes and remains the canonical issue.

## Change summary

Preserve the source model's undo and redo history when saving under another URI, including saving an untitled editor.

## Best solution

Add supported undo-stack transplantation between resources in `IUndoRedoService`, accounting for single- and multi-model elements and version IDs, then use it from the text-file Save As flow.
