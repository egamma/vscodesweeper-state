# Issue #317510 — Agents: Session list sidebar filter should show sessions matching folder name

[https://github.com/microsoft/vscode/issues/317510](https://github.com/microsoft/vscode/issues/317510)

## Summary

This accepted Agents Window request remains necessary: current Find filtering matches the workspace section label but independently filters its child sessions, leaving a matching folder header empty. The issue is team-authored, assigned to Backlog, and already carries the correct area label.

## Change summary

Make the Agents Window session filter show every session under a folder whose name matches the search pattern.

## Best solution

When Find matches a workspace section label, keep that section's session descendants visible while preserving ordinary title matching for sections that do not match. Cover both paths with a focused Sessions list test.
