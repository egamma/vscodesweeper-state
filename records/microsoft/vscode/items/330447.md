# Issue #330447 — Support enablement for walkthrough steps

[https://github.com/microsoft/vscode/issues/330447](https://github.com/microsoft/vscode/issues/330447)

## Summary

Well-scoped, verified gap: the walkthroughs contribution point only supports `when` (visibility) for steps, not a separate `enablement` for command availability, unlike `viewsWelcome` which already has both.

## Change summary

Add `enablement` support to walkthrough steps so commands/links can be disabled without hiding the step content, mirroring `viewsWelcome`'s `when`/`enablement` split.

## Best solution

Extend the `walkthroughs` contribution point schema and renderer (src/vs/workbench/contrib/welcomeGettingStarted/browser/gettingStartedExtensionPoint.ts and gettingStarted.ts) to add a per-step `enablement` context-key expression that disables step buttons/links without hiding the step, analogous to how `viewsWelcome` implements `enablement` alongside `when`.
