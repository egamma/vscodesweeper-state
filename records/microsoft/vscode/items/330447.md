# Issue #330447 — Support enablement for walkthrough steps

[https://github.com/microsoft/vscode/issues/330447](https://github.com/microsoft/vscode/issues/330447)

## Summary

The requested capability is still missing: walkthrough steps support conditional visibility, but not step-wide command enablement while preserving their content. Route this unlabelled feature request to the getting-started area for consideration; no matching canonical was identified.

## Change summary

Support a walkthrough-step enablement expression that disables its command buttons and inline command links without hiding the step.

## Best solution

Extend the walkthrough contribution contract to distinguish step visibility from command availability, consistent with viewsWelcome. Preserve step content as context changes and apply the availability state consistently to command buttons and inline command links.
