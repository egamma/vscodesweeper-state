# Issue #270617 — VS Code looks for local paths during remote sessions

[https://github.com/microsoft/vscode/issues/270617](https://github.com/microsoft/vscode/issues/270617)

## Summary

The error originates from the third-party `mkhl.direnv` extension (v0.17.0), not from VS Code core — direnv integration is not part of the VS Code codebase. The extension is responsible for resolving the direnv binary path in remote contexts.

## Change summary

VS Code references a local direnv binary path during an SSH remote session instead of the remote path.

## Best solution

File this against the direnv extension's repository (https://github.com/direnv/direnv-vscode) — the extension needs to handle remote sessions by resolving the direnv binary on the remote host rather than using locally-configured paths.
