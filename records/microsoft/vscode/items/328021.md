# Issue #328021 — Agent Host session customizations are not scoped to the session's working directory in multi-root workspaces

[https://github.com/microsoft/vscode/issues/328021](https://github.com/microsoft/vscode/issues/328021)

## Summary

Current main confirms that customization bundles are resolved per session type and broadcast unchanged to every active session. This team-authored, security-sensitive scoping defect should remain open for a session-aware fix.

## Change summary

Scope Agent Host customizations and workspace MCP servers to each session's selected working-directory set in multi-root workspaces.

## Best solution

Resolve and dispatch customizations per session, retaining appropriately global user/remote entries while filtering folder-scoped prompts, plugins, and MCP servers to the session's primary and additional roots. Add multi-root coverage for new, resumed, external-folder, and workspace-less sessions.
