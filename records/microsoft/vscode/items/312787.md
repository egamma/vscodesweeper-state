# Issue #312787 — Model picker has wrong state for 1-2 seconds after reload

[https://github.com/microsoft/vscode/issues/312787](https://github.com/microsoft/vscode/issues/312787)

## Summary

Still reproduces per the latest comment (June 8). Related model-selection work has landed (PR #320036, PR #324843) but neither explicitly targets or fixes this reload-timing issue, and the reporter confirmed it still repros after the first PR merged.

## Change summary

Model picker momentarily shows the wrong model for 1–2 seconds after a window reload before settling on the correct persisted selection.

## Best solution

The model selection restore path in chatInputPart.ts / chatModelSelectionLogic.ts needs to either defer rendering until the persisted model is resolved, or initialise with the correct cached value synchronously. The `shouldWaitForSessionModel` logic added in PR #324843 may partially address this but hasn't been confirmed against this scenario.
