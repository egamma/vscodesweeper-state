Thanks for the report. A team-authored, same-day bug about a workspace MCP server landing in the Built-in group after uninstall from the Customizations UI. The steps are enough to retest, but I could not confirm it without running the UI.

## Change summary

After uninstalling a workspace MCP server from the Customizations editor, the server appears under the Built-in section instead of disappearing.

## Best solution

Find out why the uninstalled workspace server still produces a list entry that falls through to the 'builtin' fallback in getMcpEntryGroup (mcpListWidget.ts). Either remove the stale entry after uninstall, or group it correctly, for example by workspace scope for a session or agent-host server.
