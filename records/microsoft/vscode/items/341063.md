[https://github.com/microsoft/vscode/issues/341063](https://github.com/microsoft/vscode/issues/341063)

## Summary

Thanks for the report. A maintainer explained that after uninstall the server is still advertised by the active agent-host session until the next interaction, so it is grouped as Built-in. The report is complete and the cause is known, so it stays open.

## Change summary

After uninstalling a workspace MCP server in the customizations UI, it briefly shows under the Built-in section.

## Best solution

Stop classifying a session-advertised server that was just uninstalled as Built-in. Either hide it or show it as pending removal until the session refreshes, in mcpListWidget.ts grouping (getMcpEntryGroup / createBuiltinActiveSessionMcpEntries).
