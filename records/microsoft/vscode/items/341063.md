# Issue #341063 — Uninstalling a malfunctioning MCP sends it to built-in section

[https://github.com/microsoft/vscode/issues/341063](https://github.com/microsoft/vscode/issues/341063)

## Summary

A team member filed this bug and a maintainer confirmed the cause. After a workspace MCP is uninstalled, the agent host keeps advertising it until the session is next used, so the Customizations UI files it under Built-in. This is team-authored and acknowledged, so it stays open.

## Change summary

After uninstalling a workspace MCP server from the Customizations UI, the server briefly appears in the Built-in section.

## Best solution

Stop classifying an MCP server that the agent host still advertises as Built-in when it was just uninstalled from the workspace. For example, track recently removed servers, or hide them until the host stops advertising them, in the agent-host customizations code.
