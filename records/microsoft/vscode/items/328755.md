# Issue #328755 — Single microphone results in blank box

[https://github.com/microsoft/vscode/issues/328755](https://github.com/microsoft/vscode/issues/328755)

## Summary

Already fixed on main: the single-microphone empty picker box was a CSS specificity bug (a class selector overriding the `[hidden]` UA rule), fixed with an explicit `[hidden] { display: none }` override plus a regression test asserting the computed style — closing as completed.

## Change summary

With only one physical microphone, the dictation/voice-mode onboarding card showed an empty bordered picker box instead of hiding it.

## Best solution

Keep the shipped fix — `.dictation-onboarding-picker[hidden]`/`.voice-mode-onboarding-microphone-picker[hidden]` now force `display: none`, and dictationOnboarding.test.ts asserts `microphonePickerDisplay: 'none'` for the single-mic case; no further change needed beyond verifying on the next build.
