# Issue #331672 — Electron 42.8.1 regresses Windows renderer layout and startup performance

[https://github.com/microsoft/vscode/issues/331672](https://github.com/microsoft/vscode/issues/331672)

## Summary

Well-documented, team-authored regression tracing a real Windows startup slowdown to Electron 42.8.1's renderer layout cost; root cause lives in Electron/Chromium/V8, not VS Code's own code, and it's already correctly labeled and routed — nothing to close here.

## Change summary

Bumping Electron from 42.8.0 to 42.8.1 (and later 42.9.x) regresses Windows renderer forced-layout performance by ~32%, adding tens of milliseconds to VS Code startup.

## Best solution

Track/report this upstream to the Electron project (it persists through 42.9.3), and have the VS Code Electron-bump owners decide whether to pin at 42.8.0 or a patched build until Electron resolves the Blink layout regression; commit 1fc102e9ae7264920fcc41986d7c4d8231f557f7 (bump electron@42.8.1, PR #330244) is the introducing change to reference in any upstream report or revert discussion.
