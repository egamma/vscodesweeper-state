# Issue #338291 — Black boxes appearing over text when using OpenCode in terminal

[https://github.com/microsoft/vscode/issues/338291](https://github.com/microsoft/vscode/issues/338291)

## Summary

This matches a known pattern of WebGL-terminal-renderer glyph-atlas corruption on certain Linux GPU/driver combos (ANGLE GLES + Mesa), previously reported in https://github.com/microsoft/vscode/issues/321007 and https://github.com/microsoft/vscode/issues/321027 with glyph-dense TUIs like fzf — here triggered by the OpenCode CLI instead. Both prior reports were closed as duplicates of each other/upstream without a cited VS Code fix, so this is kept open as an upstream GPU-driver issue rather than closed against either (closed) report.

## Change summary

Running the OpenCode TUI in the integrated terminal randomly covers glyphs with solid black rectangles that persist across sessions.

## Best solution

Confirm whether gpuAcceleration is auto/on and collect the reporter's ANGLE/GPU backend (Help > About / `--status`); if it matches the ANGLE-GLES-on-Mesa pattern from #321007, the fix lives upstream in ANGLE/Mesa or in avoiding the GLES path, with `terminal.integrated.gpuAcceleration: off` as the interim workaround already validated on that issue.
