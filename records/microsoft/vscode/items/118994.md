# Issue #118994 — Please provide a function in API to get horizontal pixel coordinate of any character in any line.

[https://github.com/microsoft/vscode/issues/118994](https://github.com/microsoft/vscode/issues/118994)

## Summary

The extension API gap remains on current main, and this accepted Backlog request has 133 community upvotes. Route it to the editor API owners for API design rather than closing it.

## Change summary

Expose an extension API that returns the rendered horizontal pixel offset of a text position, including proportional fonts and inline content such as inlay hints.

## Best solution

Design a proposed editor API with explicit semantics for visibility, wrapping, scrolling, and injected text, backed by the editor's existing internal coordinate conversion. The API should accurately cover rendered positions without exposing editor internals or requiring extensions to approximate font metrics.
