# Issue #315643 — UX is very buggy when reading extended chats

[https://github.com/microsoft/vscode/issues/315643](https://github.com/microsoft/vscode/issues/315643)

## Summary

Current main is designed to stop following streamed content once the reader leaves the bottom, and later scroll-anchoring work covers collapsing progress content, but this checkout cannot confirm the reported interaction end to end. Ask the reporter to retest on the latest build and provide the missing VS Code version and a recording if the viewport still jumps.

## Change summary

Scrolling upward in a long streaming Agent response does not reliably hold the chosen reading position as tokens, tool calls, and later turns update the transcript.

## Best solution

Preserve the current follow-while-at-bottom behavior, but keep the transcript anchored whenever the user has scrolled away; if the latest build still jumps, isolate which streamed content or collapse transition bypasses the guards in `chatListWidget.ts` and add a regression test for that sequence.
