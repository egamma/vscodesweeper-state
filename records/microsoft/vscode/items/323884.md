# Issue #323884 — Recent Opens in New Window

[https://github.com/microsoft/vscode/issues/323884](https://github.com/microsoft/vscode/issues/323884)

## Summary

A real discoverability gap remains on the Welcome page: Ctrl/Cmd-click opens a Recent entry in a new window, but no visible or explicitly labeled action exposes that behavior. The issue is already in the Backlog holding milestone and has no open canonical, so it should remain open for a UX decision.

## Change summary

Expose an option or action on Welcome-page Recent entries that opens the selected workspace or folder in a new window.

## Best solution

Provide a clearly labeled, keyboard-accessible secondary action for each Welcome-page Recent entry while preserving normal click for the current window and Ctrl/Cmd-click for the existing shortcut. The action should remain quiet at rest and become available on hover and keyboard focus, consistent with the existing remove action.
