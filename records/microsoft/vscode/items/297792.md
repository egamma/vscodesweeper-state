# Issue #297792 — GitHub Copilot adds incorrect links in the in-chat conversation.

[https://github.com/microsoft/vscode/issues/297792](https://github.com/microsoft/vscode/issues/297792)

## Summary

Still reproduces on main: the file linkification system in multi-root workspaces resolves relative paths to the first workspace folder that contains a match, which can be the wrong root. The displayed label is also reduced to basename, hiding the path context. This is a distinct defect from the related copy-paste issue #280165.

## Change summary

In multi-root workspaces, Copilot Chat inline file references link to the wrong file (first-match-wins across roots) and show only the basename, hiding the path the LLM produced.

## Best solution

Fix the file resolution in `extensions/copilot/src/extension/linkify/common/filePathLinkifier.ts` (`resolveInWorkspaceFolders`) to prefer the workspace root matching the chat's working directory or context, rather than returning the first stat hit. Also preserve the relative path the LLM emitted as the display label in `src/vs/workbench/contrib/chat/common/widget/annotations.ts` instead of reducing to `basename`. The broader linkification accuracy work in https://github.com/microsoft/vscode/issues/313533 may subsume the resolution fix, but the label truncation is a separate concern.
