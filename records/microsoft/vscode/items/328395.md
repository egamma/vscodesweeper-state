# Issue #328395 — copy selected text but Ignore the folding part

[https://github.com/microsoft/vscode/issues/328395](https://github.com/microsoft/vscode/issues/328395)

## Summary

This is a valid, currently unsupported editor-copy mode: copying a selection still includes text hidden by folded regions. Route it to the folding and clipboard owners for a product decision.

## Change summary

Allow copying a selection while excluding lines hidden inside folded regions.

## Best solution

Decide whether visible-only copying should be an editor setting or a separate command, then reuse the hidden-area filtering approach proposed in https://github.com/microsoft/vscode/pull/287164 within the core clipboard pipeline.

## Evidence

- **existing behavior:** https://github.com/microsoft/vscode/issues/72422 documents the inverse folding-selection behavior and contains maintainer confirmation that folded content is currently copied only when the selection extends across its model range; it does not cover excluding folded content from a larger selection.
- **related implementation:** Open PR https://github.com/microsoft/vscode/pull/287164 proposes opt-in hidden-area filtering for clipboard operations, but targets https://github.com/microsoft/vscode/issues/287127 and is not merged; current main therefore still lacks this capability.
