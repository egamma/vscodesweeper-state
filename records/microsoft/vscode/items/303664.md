# Issue #303664 — Can't commit when git config is `~/.config/git/config`

[https://github.com/microsoft/vscode/issues/303664](https://github.com/microsoft/vscode/issues/303664)

## Summary

The reported XDG configuration discrepancy needs investigation, not dismissal as missing Git identity. Current source delegates configuration discovery to Git; matching executable, environment, and failure logs are needed to establish why Source Control differs from the shell.

## Change summary

Source Control fails to read identity and global ignore configuration from ~/.config/git even though shell Git reads them.

## Best solution

Ensure Source Control's Git process honors the applicable XDG configuration and ignore files without requiring a proxy ~/.gitconfig. First establish whether the discrepancy comes from executable selection, launch environment, or another configuration override.
