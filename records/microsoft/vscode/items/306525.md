# Issue #306525 — Sessions: The sidebars provide "Move to" actions that don't actually work

[https://github.com/microsoft/vscode/issues/306525](https://github.com/microsoft/vscode/issues/306525)

## Summary

Still present on current main: the shared pane-composite context menu unconditionally offers relocation actions in the Agents Window, although its part positions are fixed and the actions cannot produce a supported layout. This team-authored, accepted bug should remain open.

## Change summary

Remove nonfunctional “Move To” actions from Sessions, Files/Artifacts, and bottom-panel context menus in the Agents Window.

## Best solution

Keep view-container relocation available in the standard workbench, but suppress it for the Agents Window's fixed Sidebar, Auxiliary Bar, and Panel composition.
