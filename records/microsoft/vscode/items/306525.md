# Issue #306525 — Sessions: The sidebars provide "Move to" actions that don't actually work

[https://github.com/microsoft/vscode/issues/306525](https://github.com/microsoft/vscode/issues/306525)

## Summary

Team-authored bug still present on main: the Sessions window's sidebar and panel parts inherit the "Move To" context menu from the shared PaneCompositeBar without overriding or hiding it, so the actions appear but don't work in the Agents window layout.

## Change summary

Right-clicking sidebar tabs (Artifacts, Files) or panel tabs in the Agents/Sessions window shows a non-functional "Move To" submenu inherited from the workbench's PaneCompositeBar.

## Best solution

Override `getContextMenuActionsForComposite` (or the pane-composite-bar options that control it) in `src/vs/sessions/browser/parts/sidebarPart.ts` and `src/vs/sessions/browser/parts/panelPart.ts` to either hide the "Move To" submenu entirely or filter out locations that aren't meaningful in the Sessions window layout.
