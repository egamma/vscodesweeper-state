# Issue #274770 — Bring chat.tools.edits.autoApprove logic to core

[https://github.com/microsoft/vscode/issues/274770](https://github.com/microsoft/vscode/issues/274770)

## Summary

Still valid debt: the `chat.tools.edits.autoApprove` logic lives in two places — the Copilot extension (`editFileToolUtils.tsx`) and the agent host core (`sessionPermissions.ts`) — and the extension path has not yet been consolidated into core. Keeping open.

## Change summary

Move the `chat.tools.edits.autoApprove` glob-matching logic from the Copilot extension into VS Code core so all edit-confirmation paths (workbench tools, agent host, terminal file writes) share a single implementation.

## Best solution

Consolidate the extension's `makeUriConfirmationChecker` in `extensions/copilot/src/extension/tools/node/editFileToolUtils.tsx` into a shared core service (likely adjacent to the existing agent host implementation in `src/vs/platform/agentHost/node/sessionPermissions.ts` or a new platform-level edit-approval service), then have both the workbench tools path and the agent host path delegate to it.
