# Issue #340540 — Active tab is not scrolled into view after turning off `wrapTabs` if a tab was closed while tabs wrapped

[https://github.com/microsoft/vscode/issues/340540](https://github.com/microsoft/vscode/issues/340540)

## Summary

Thanks for the detailed report. The source matches the diagnosis: blockRevealActiveTabOnce() sets blockRevealActiveTab, but only the non-wrapping layout path consumes it, so a close while tabs wrap leaves it set until wrapping stops. An open PR (https://github.com/microsoft/vscode/pull/340548) already targets this, so it stays open pending that PR.

## Change summary

Active tab is not revealed after disabling wrapTabs if a tab was closed while tabs were wrapped.

## Best solution

Land or review https://github.com/microsoft/vscode/pull/340548, which clears or ignores the stale block-reveal flag when the layout is wrapping, so the first non-wrapping layout reveals the active tab.
