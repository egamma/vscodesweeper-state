# Issue #335297 — Copilot permissions cannot be revoked while running

[https://github.com/microsoft/vscode/issues/335297](https://github.com/microsoft/vscode/issues/335297)

## Summary

Reproduced in code and by the reporter: the permission level used for tool confirmations (e.g. auto-answering questions) is snapshotted onto the chat request at send time (`request.modeInfo.permissionLevel`) and never re-read for the rest of that turn, so downgrading from Autopilot to Default mid-execution has no effect until the next request.

## Change summary

Changing chat agent permissions from Autopilot to Default while a turn is still executing does not take effect — the in-flight turn keeps using the original (Autopilot) permission level.

## Best solution

Have tool-confirmation call sites (starting with askQuestionsTool.ts, and any other tools gating on permission level) read the live/current permission level for the session rather than the value captured on the originating IChatAgentRequest, so a mid-turn downgrade is honored on the next tool call.
