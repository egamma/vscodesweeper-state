# Issue #347916 — Nested chats should follow their target directory when selecting changes set kind

[https://github.com/microsoft/vscode/issues/347916](https://github.com/microsoft/vscode/issues/347916)

## Summary

Keep open: the current Changes pill unconditionally selects Session Changes for nested chats, even when their effective working directory differs from the parent's. The source confirms the reported selection and reactivity gap.

## Change summary

Select Branch Changes for nested chats targeting a different directory from their parent, and update the selection reactively when that target changes.

## Best solution

Make the Changes pill's selected changeset, counts, and label consistently reflect the nested chat's target relative to its parent, while preserving existing same-directory behavior.
