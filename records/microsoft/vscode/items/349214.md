# Issue #349214 — Automations: show interrupted run status and offer Keep going on the run entry

[https://github.com/microsoft/vscode/issues/349214](https://github.com/microsoft/vscode/issues/349214)

## Summary

Keep open: the existing in-session Keep Going action does not cover recovery directly from an automation run entry. Current history actions lack that continuation affordance, and no canonical issue or fixing commit was established.

## Change summary

Show interrupted automation runs distinctly and offer the existing Keep Going continuation directly on their run entries.

## Best solution

Expose an accessible interrupted state and continuation action in automation history, preserving the existing session resume semantics and distinguishing resumable interruptions from ordinary failures or completed runs.
