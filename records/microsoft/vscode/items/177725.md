# Issue #177725 — Regex disabled when disabling output on Notebook Find Widget

[https://github.com/microsoft/vscode/issues/177725](https://github.com/microsoft/vscode/issues/177725)

## Summary

The regex toggle still depends on whether notebook search filters differ from their initial values, rather than whether the selected search surfaces support regex. This disables regex even for source-only searches; the related default-state behavior needs a consistent product decision.

## Change summary

Correct notebook Find regex availability when output and rendered-content search filters are changed.

## Best solution

Make regex availability reflect the actual selected search surfaces, independently of the filter button's modified indicator. Resolve the default mixed source/output behavior consistently with https://github.com/microsoft/vscode/issues/177747 without adding regex support to rendered outputs as part of this fix.
