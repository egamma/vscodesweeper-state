## Summary

Still present on main: the regex toggle disabling logic in `setEnabled()` incorrectly disables regex when outputs are toggled off due to an interaction between `setEnabled` and `updateFilterState`. No fix commit found.

## Change summary

Regex toggle in the Notebook Find Widget is incorrectly disabled when the 'search in outputs' filter is toggled off.

## Best solution

Fix the interaction between `setEnabled()` and `updateFilterState()` in `notebookFindReplaceWidget.ts` so that disabling output search does not incorrectly disable the regex toggle. The regex toggle should only be disabled when output search is active (since webview search doesn't support regex).
