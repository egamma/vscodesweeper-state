# Issue #161987 — WorkspaceEdit: confirmation preview does not reflect the create content

[https://github.com/microsoft/vscode/issues/161987](https://github.com/microsoft/vscode/issues/161987)

## Summary

Keep open: current main previews file-creation contents, but still combines creation and subsequent snippet edits against the old model rather than applying them sequentially. The supplied example remains sufficient to exercise this gap; the later partial fix does not establish completion of this team-authored issue.

## Change summary

Make WorkspaceEdit confirmation previews reflect newly created or overwritten contents before previewing subsequent snippet edits.

## Best solution

The bulk-edit preview should match the eventual result of creating or overwriting the file and then applying its text edits, both when the target is absent and when it already exists. Preserve confirmation selection behavior and the original file on the comparison side.
