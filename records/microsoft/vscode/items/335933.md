# Issue #335933 — Claude in the chat window doesn't show free text option when display decision choices

[https://github.com/microsoft/vscode/issues/335933](https://github.com/microsoft/vscode/issues/335933)

## Summary

Real bug confirmed in source — Claude's AskUserQuestion defaults `allowFreeformInput` to false, unlike the Claude Code extension — but an open PR already targets exactly this fix, so this stays open pending that PR landing rather than being treated as agent-ready or closed.

## Change summary

When Claude (via the built-in agent host) asks a multiple-choice question, VS Code's chat UI never offers a free-text/'Other' fallback the way the standalone Claude Code extension does.

## Best solution

Land (or review) https://github.com/microsoft/vscode/pull/336285, which changes the default for `allowFreeformInput` on Claude's AskUserQuestion so single/multi-select prompts include a free-form option by default.
