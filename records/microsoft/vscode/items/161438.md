# Issue #161438 — Use new code action widget in problems view

[https://github.com/microsoft/vscode/issues/161438](https://github.com/microsoft/vscode/issues/161438)

## Summary

The requested migration remains necessary on current main: Problems quick fixes still open through the legacy context-menu service rather than the shared action widget. The debt is accepted in the Backlog and has a clear, bounded implementation path.

## Change summary

Adopt the shared code-action widget when users open quick fixes from a Problems view lightbulb.

## Best solution

Use the shared IActionWidgetService for Problems quick fixes in both tree and table presentations, while preserving the existing marker-specific code-action lookup, editor reveal, and ApplyCodeActionReason.FromProblemsView behavior.

- **Fit:** aligned
- **Reason:** Using the common action widget makes code-action interactions more uniform across core VS Code surfaces.
- **Evidence:** Value and guardrail: "Simple, uniform UI and UI interactions."
