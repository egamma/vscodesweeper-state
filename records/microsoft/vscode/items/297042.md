# Issue #297042 — Quick pick session covers content when you click back

[https://github.com/microsoft/vscode/issues/297042](https://github.com/microsoft/vscode/issues/297042)

## Summary

Keep open: the current session-navigation path leaves the title picker visible when closeOnFocusLost is disabled, obscuring the session reached by Back. No verified duplicate or issue-referencing fix was found; this team-authored report remains actionable.

## Change summary

Dismiss the session-title quick pick when clicking Back so it does not obscure the previous session.

## Best solution

Treat explicit Back navigation as ending the session-selection interaction, while preserving the global closeOnFocusLost preference for ordinary focus changes and intentional background acceptance.
