# Issue #345606 — Plugin on remote machine is shown as "Local"

[https://github.com/microsoft/vscode/issues/345606](https://github.com/microsoft/vscode/issues/345606)

## Summary

Keep open: the Plugins list still labels every non-marketplace installation “Local,” including configured remote paths. This team-authored report identifies a presentation ambiguity, not a plugin-loading failure.

## Change summary

Avoid presenting a plugin installed on the remote machine as locally installed.

## Best solution

Make the plugin source badge distinguish installation provenance without implying the wrong machine, consistently across installed-plugin renderers; preserve remote discovery and loading behavior.
