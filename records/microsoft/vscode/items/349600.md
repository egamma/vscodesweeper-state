# Issue #349600 — Agent Host: work delegated with `create_session` always runs as the default agent, so it can't be handed to a custom agent

[https://github.com/microsoft/vscode/issues/349600](https://github.com/microsoft/vscode/issues/349600)

## Summary

The custom-agent selection gap remains on main. This requests a new delegation capability, rather than a deviation from the tool's existing contract; selecting a harness does not select a custom agent.

## Change summary

Allow create_session to start resumable delegated conversations with an explicitly selected custom agent and its instructions and tool restrictions.

## Best solution

Support explicit custom-agent selection at delegated-chat creation, with unambiguous resolution and default-agent behavior when omitted. Coordinate follow-up agent retention with https://github.com/microsoft/vscode/pull/345120, which addresses a separate part of the workflow.
