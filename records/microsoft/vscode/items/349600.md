# Issue #349600 — Agent Host: work delegated with create_session always runs as the default agent, so it can't be handed to a custom agent

[https://github.com/microsoft/vscode/issues/349600](https://github.com/microsoft/vscode/issues/349600)

## Summary

Keep open as a feature request: create_session supports selecting a harness and model, but not a custom agent. Existing automation support and related follow-up work do not cover selecting a specialist for a fresh delegated conversation.

## Change summary

Allow create_session to select a custom agent whose instructions and tool restrictions apply to a resumable delegated chat.

## Best solution

Expose explicit custom-agent selection through the existing AgentSelection contract, preserving default-agent behavior when omitted and rejecting unknown or ambiguous selections. Keep custom-agent selection distinct from harness selection and retain the selected agent during subsequent delegated messages.
