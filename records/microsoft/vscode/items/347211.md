# Issue #347211 — Connector suggestions do not account for existing MCP servers

[https://github.com/microsoft/vscode/issues/347211](https://github.com/microsoft/vscode/issues/347211)

## Summary

Current source confirms that connector tips ignore configured MCP servers, so redundant recommendations remain possible. Keep this open; equivalence and migration behavior need agreement before implementation.

## Change summary

Account for equivalent existing MCP integrations when suggesting connectors, distinguishing migration from missing setup.

## Best solution

Make composer recommendations reflect integrations already available to the selected session. Suppress equivalent recommendations unless an intentional migration experience explicitly explains the transition.
