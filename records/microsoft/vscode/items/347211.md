# Issue #347211 — Connector suggestions do not account for existing MCP servers

[https://github.com/microsoft/vscode/issues/347211](https://github.com/microsoft/vscode/issues/347211)

## Summary

Keep open: current connector recommendations do not consult existing MCP integrations. The assignee supports an explicit upgrade experience, with suppression as an acceptable interim behavior; equivalence and migration semantics still need definition.

## Change summary

Make connector recommendations recognize equivalent configured MCP servers and distinguish migration from first-time setup.

## Best solution

Provide an MCP-aware recommendation experience that explains the connector's managed-authentication benefit and offers a confirmed transition without losing the existing working integration. Suppress equivalent recommendations temporarily if that transition cannot yet be completed reliably.
