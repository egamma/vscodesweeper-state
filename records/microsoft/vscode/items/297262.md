# Issue #297262 — Chat customisations search should be able to search across all customistations

[https://github.com/microsoft/vscode/issues/297262](https://github.com/microsoft/vscode/issues/297262)

## Summary

Valid feature request: the customizations search currently filters only items in the active section (`this.allItems` is scoped to `currentSection`). Cross-section search with grouped results is not yet implemented on main.

## Change summary

Allow the Chat Customizations editor search to search across all customization categories (agents, instructions, tools, etc.) and show grouped results with category indicators.

## Best solution

Extend `filterItems()` in `aiCustomizationListWidget.ts` to optionally query items from all sections (via `itemsModel.getItems()` for each section), merge matches into grouped display entries with their section label, and navigate to the appropriate section on click.
