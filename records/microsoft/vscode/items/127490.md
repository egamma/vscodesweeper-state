# Issue #127490 — iframe find highlights look out of place

[https://github.com/microsoft/vscode/issues/127490](https://github.com/microsoft/vscode/issues/127490)

## Summary

Still reproduces on main: general webview find uses `window.find()` with browser-native highlight colors rather than the CSS Highlight API with VS Code theme colors. The notebook webview solved this, but the fix was never ported to the general webview.

## Change summary

Find highlights in webview iframes use browser-native colors instead of matching VS Code's editor find highlight theme colors.

## Best solution

Port the CSS Highlight API approach from notebook webview (`src/vs/workbench/contrib/notebook/browser/view/renderers/webviewPreloads.ts` CSSHighlighter class) into the general webview find implementation in `src/vs/workbench/contrib/webview/browser/pre/index.html`, replacing the raw `window.find()` usage with a TreeWalker + CSS.highlights approach that applies themed `--vscode-editor-findMatchHighlightBackground` colors.
