[https://github.com/microsoft/vscode/issues/342232](https://github.com/microsoft/vscode/issues/342232)

## Summary

The headless BYOK capability is already covered by the open Agent Host BYOK issue, which explicitly owns removing the renderer/extension-host dependency. Consolidate there while preserving this report's GitHub sign-in symptom.

## Change summary
