# Issue #342232 — Agent Host: headless BYOK still requires GitHub sign-in

[https://github.com/microsoft/vscode/issues/342232](https://github.com/microsoft/vscode/issues/342232)

## Summary

Headless BYOK remains a capability gap: current Agent Host integration depends on renderer-provided models, and the signed-out opt-in does not supply a missing model catalog. Keep this report open because the verified related issues do not establish a duplicate covering the same headless sign-in symptom.

## Change summary

Support BYOK agent sessions in a headless or detached Agent Host without requiring GitHub sign-in.

## Best solution

Provide a host-owned BYOK configuration and inference lifecycle that survives renderer absence, consistent with the direction in https://github.com/microsoft/vscode/issues/340335. Distinguish an unavailable BYOK configuration from authentication required for a Copilot-hosted model.
