# Issue #344373 — Should have a way to delete an automation from the edit screen

[https://github.com/microsoft/vscode/issues/344373](https://github.com/microsoft/vscode/issues/344373)

## Summary

The edit dialog still lacks a delete action. Existing deletion from an automation card does not cover the requested in-dialog workflow; keep this team-authored request open.

## Change summary

Allow users to delete an existing automation directly from its edit dialog, preferably from the left side of the footer.

## Best solution

Provide a discoverable secondary delete action when editing an existing automation, preserving deletion confirmation, provider capability checks, and clear failure feedback without competing with Save.
