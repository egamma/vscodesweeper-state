# Issue #344373 — Should have a way to delete an automation from the edit screen

[https://github.com/microsoft/vscode/issues/344373](https://github.com/microsoft/vscode/issues/344373)

## Summary

The edit dialog still lacks a delete action; deletion from the automation card does not cover the requested in-dialog workflow. Keep this team-authored request open for an edit-dialog design decision.

## Change summary

Allow deleting an existing automation directly from its edit dialog.

## Best solution

Provide a discoverable, keyboard-accessible delete affordance within the edit dialog, preserving existing deletion confirmation, provider permissions, and run-history semantics.
