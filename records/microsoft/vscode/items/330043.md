# Issue #330043 — Agents window titlebar icons can easily collide in general

[https://github.com/microsoft/vscode/issues/330043](https://github.com/microsoft/vscode/issues/330043)

## Summary

Fresh, credible bug report from a collaborator with screenshots showing titlebar icon overlap at zoom level 2 in a narrow Agents window; already correctly labeled bug/agents-window, so it just needs a fix, not any triage change.

## Change summary

In the Agents window titlebar, right-side icons visually collide when the window is narrow at zoom level 2, independent of whether the update button is present.

## Best solution

Extend the titlebar's overflow handling (currently `updateUpdateToolBarOverflow` in src/vs/sessions/browser/parts/titlebarPart.ts only hides the update button based on `rootContainer.scrollWidth > clientWidth`) to also collapse or reflow the session-actions/layout-actions toolbars in `.titlebar-right` so icons never overlap at narrow widths and higher zoom.
