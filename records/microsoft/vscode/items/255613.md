# Issue #255613 — How many times do I have to reject a suggestion before it stops suggesting it in exactly the same place?

[https://github.com/microsoft/vscode/issues/255613](https://github.com/microsoft/vscode/issues/255613)

## Summary

Acknowledged NES rejection-cache bug — the client-side rejection cache exists (RejectionCollector + NextEditCache) but team member @hediet confirmed it didn't work in this case. No fix has landed since; the issue remains valid.

## Change summary

NES repeatedly re-suggests the same inline edit immediately after the user dismisses it with Escape, despite a rejection cache existing.

## Best solution

Investigate why the rejection cache in `extensions/copilot/src/extension/inlineEdits/common/rejectionCollector.ts` and `extensions/copilot/src/extension/inlineEdits/node/nextEditCache.ts` fails to suppress re-serving cached edits marked as rejected. The cached edit's `rejected` flag and the `RejectionCollector.isRejected()` check may not cover all re-trigger paths (e.g., automatic re-trigger after Escape). The fix likely lives in the inline edit triggerer or the cache lookup path.
