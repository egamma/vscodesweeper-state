# Issue #255613 — How many times do I have to reject a suggestion before it stops suggesting it in exactly the same place?

[https://github.com/microsoft/vscode/issues/255613](https://github.com/microsoft/vscode/issues/255613)

## Summary

Still reproducible from current source: an explicit rejection within one second of display is deliberately excluded from the rejection cache, allowing the same edit to be offered again. The maintainer discussion confirms that client-side rejection memory is expected here.

## Change summary

Quickly dismissing a next edit suggestion with Escape does not prevent the identical suggestion from repeatedly reappearing at the same location.

## Best solution

Treat an explicit Escape rejection as sufficient to suppress the same edit at that document location, including when the suggestion was visible for less than one second, while preserving normal handling of genuinely superseded or ignored suggestions.
