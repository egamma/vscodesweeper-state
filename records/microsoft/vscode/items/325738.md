## Summary

Legitimate feature request for BYOK parity in remote/SSH agent-host sessions, confirmed as not-yet-supported by a team member. The issue bundles three related gaps (SSH BYOK, protocol version mismatch, extension allow-listing); routing to the relevant area owners.

## Change summary

BYOK custom model providers do not work in SSH-based Agents Window sessions, the agent-host protocol version can mismatch over SSH, and enabling third-party model provider extensions requires undocumented manual settings.
