# Issue #350064 — window.restoreWindows: all may restore only the Agents window, not the main VS Code window

[https://github.com/microsoft/vscode/issues/350064](https://github.com/microsoft/vscode/issues/350064)

## Summary

The current restoration path can retain only the last-closed Agents window and suppress opening a regular editor window. Keep this open while the linked fix proposal is reviewed.

## Change summary

Restore a regular editor window when restarting with window.restoreWindows set to all after closing the Agents window last.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/350091, ensuring that closing the Agents window last does not discard regular-editor restoration state or leave startup with only an Agents window.

- **State recording on current main:** src/vs/platform/windows/electron-main/windowsStateHandler.ts:283-312 records lastClosedState only when getWindowCount() === 1, without excluding sessions windows. - **Restoration fallback on current main:** src/vs/platform/windows/electron-main/windowsMainService.ts:1077-1129 restores saved workspaces without distinguishing the Agents workspace. getPathsToOpen() at lines 918-923 adds EMPTY_WINDOW only when no paths remain; doOpen() at lines 752-760 suppresses its empty-window fallback once any window has opened. An Agents-only restoration therefore does not guarantee a regular editor window.
