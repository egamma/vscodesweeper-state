# Issue #194122 — Flag, report document selectors that use notebookType and cell-scheme

[https://github.com/microsoft/vscode/issues/194122](https://github.com/microsoft/vscode/issues/194122)

## Summary

Still unimplemented on main: no warning is emitted when an extension registers a document selector combining `notebookType` with the `vscode-notebook-cell` scheme, a combination that silently never matches. The debt item remains valid.

## Change summary

Add a warning when extensions register document selectors that combine `notebookType` with a cell scheme, since this combination never matches.

## Best solution

Add a validation check in the `_doTransformDocumentSelector` function in `src/vs/workbench/api/common/extHostTypeConverters.ts` (or at registration time in `extHostLanguageFeatures.ts`) that detects when `notebookType` is set alongside `scheme: 'vscode-notebook-cell'` and logs a clear warning to the extension host output, explaining that `notebookType` uses the notebook file's scheme, not the cell scheme.
