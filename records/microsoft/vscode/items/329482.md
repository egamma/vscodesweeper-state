## Summary

Active, confirmed investigation: a VS Code collaborator (deepak1556) has reproduced the bug independently, traced it to an Electron/Chromium runtime rendering issue triggered by near-simultaneous window-highlight notifications (e.g. two chat responses arriving close together), and is preparing a runtime-level fix — this stays open pending that fix landing.
