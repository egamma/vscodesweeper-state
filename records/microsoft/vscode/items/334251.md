# Issue #334251 — Agent sessions: memory tool not provisioned — agent sessions have no access to the memory tool available in editor chat (surface toolset parity gap)

[https://github.com/microsoft/vscode/issues/334251](https://github.com/microsoft/vscode/issues/334251)

## Summary

Keep open for shared-memory support between editor chat and Copilot agent sessions. Current main offers opt-in Agent Host memory, but its documented storage differs from editor chat's /memories/ store, so it does not establish the requested parity.

## Change summary

Let Copilot agent sessions read and write the editor chat memory store, with explicit documentation of intentional toolset differences.

## Best solution

Define a supported shared-memory contract between editor chat and Copilot agent sessions, including user, repository, and session scope boundaries. Existing SDK memory settings should not be presented as equivalent to editor chat memory unless interoperability is implemented.
