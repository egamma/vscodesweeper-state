# Issue #350206 — Support opt-in command links in the built-in Markdown preview

[https://github.com/microsoft/vscode/issues/350206](https://github.com/microsoft/vscode/issues/350206)

## Summary

Keep open for maintainer review of the proposed command-execution permission boundary. Current preview settings do not cover the request, and the linked implementation PR remains open.

## Change summary

Allow explicitly authorized command links in the built-in Markdown preview, restricted to trusted workspaces and user-controlled exact command grants.

## Best solution

Have the Markdown owners assess the permission model and review https://github.com/microsoft/vscode/pull/350209 before deciding whether to support this opt-in. Preserve disabled-by-default behavior and existing link handling pending that decision.
