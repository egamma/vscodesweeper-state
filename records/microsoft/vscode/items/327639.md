# Issue #327639 — Agent Sessions sidebar: per-session status freezes for Copilot CLI sessions (both directions); mark-as-read and rename inert

[https://github.com/microsoft/vscode/issues/327639](https://github.com/microsoft/vscode/issues/327639)

## Summary

Confirmed status-synchronization bug affecting Copilot CLI sessions. Independent evidence shows both stale and falsely actionable sidebar states, so it should remain open and route to the Agents window and Copilot CLI owners.

## Change summary

Copilot CLI session rows can freeze or report the wrong status while mark-as-read, rename, permission prompts, and message delivery also become ineffective.

## Best solution

Make Copilot CLI session updates ordered and last-write-wins across full-list refreshes and per-session pushes, then ensure permission state, read state, title, and turn status derive from the same current snapshot. Add instrumentation and race-focused tests before selecting a localized fix.
