## Change summary

Prevent a valid but differently represented notebook URI from creating a second document that leaves notebook execution and extension mappings unusable.

## Best solution

Define and enforce a consistent URI-identity contract between the file service, notebook model resolver, editor service, and extension host so conflicting notebook representations cannot corrupt the active document mapping.
