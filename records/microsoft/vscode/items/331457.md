# Issue #331457 — terminal-suggest: PATH is resolved once at activation, so a replaced PATH directory stops updating completions until reload

[https://github.com/microsoft/vscode/issues/331457](https://github.com/microsoft/vscode/issues/331457)

## Summary

Keep open: current source still establishes PATH watchers only at activation and reuses executable lists without checking directory identity. An independent commenter confirmed the stale-completion reproduction; the related Windows CPU issue does not cover this remaining behavior.

## Change summary

Terminal executable suggestions should recover when a PATH directory is replaced and remain fresh for directories introduced through the terminal's current environment.

## Best solution

Ensure terminal-suggest's executable cache and watch coverage follow the effective terminal PATH and recover from same-path directory replacement without a window reload. Coordinate with the contributor who already offered a patch, while keeping the upstream watcher CPU defect separate.
