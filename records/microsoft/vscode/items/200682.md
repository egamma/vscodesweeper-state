# Issue #200682 — Connecting to Live Share session causes NPE in workspace trust subsystem

[https://github.com/microsoft/vscode/issues/200682](https://github.com/microsoft/vscode/issues/200682)

## Summary

The bug is still present on main: `getCanonicalUri` accesses `uri.scheme` without a null guard, and `getWorkspaceUris()` can return undefined entries when workspace folders aren't fully initialized (as in Live Share). No fix commit found.

## Change summary

Connecting to a Live Share session triggers an NPE in workspace trust when a workspace folder URI is undefined during the trust dialog.

## Best solution

Add a defensive filter in `getWorkspaceUris()` or `setUrisTrust()` to skip undefined URIs, preventing the NPE when folders aren't yet fully resolved. The fix belongs in `src/vs/workbench/services/workspaces/common/workspaceTrust.ts`.
