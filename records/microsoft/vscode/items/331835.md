# Issue #331835 — Too many ways to pick mode for Claude harness

[https://github.com/microsoft/vscode/issues/331835](https://github.com/microsoft/vscode/issues/331835)

## Summary

Keep open as Claude chat UX polish: agent selection and Claude permission modes have distinct semantics, but their overlapping Plan terminology leaves a legitimate clarity problem. The older picker-styling issue does not report the same two-selector symptom and is not a verified duplicate.

## Change summary

Make the relationship between the agent picker and Claude's permission-mode picker understandable when both offer planning choices.

## Best solution

Make agent identity and Claude's approval/planning policy clearly distinguishable in the chat input, without silently equating them or removing custom-agent capabilities. The chat UX owner should settle whether clearer terminology and explanations suffice or the controls need a different presentation.
