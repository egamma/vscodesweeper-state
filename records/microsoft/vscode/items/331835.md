# Issue #331835 — Too many ways to pick mode for Claude harness

[https://github.com/microsoft/vscode/issues/331835](https://github.com/microsoft/vscode/issues/331835)

## Summary

The overlap is real and confirmed in source: the agent-host chat input has a separate 'Agent Mode' picker (Agent/Plan) and a Claude 'Approvals' picker whose permission-mode options also include 'Plan Mode' — exactly the double-Plan confusion shown in the screenshots. This is UX polish for a very new feature that needs a design decision, not a mechanical bug fix.

## Change summary

In the Claude agent-host harness, mode/plan selection is split across two separate pickers (an Agent Mode picker with an Agent/Plan choice, and a Claude Approvals picker with a distinct Plan Mode permission option), which is confusing.

## Best solution

Reconcile the two pickers in agentHostChatInputPicker.contribution.ts / agentHostChatInputPicker.ts — either merge Claude's 'Plan Mode' permission option into the single Agent Mode picker, or rename/restructure so 'Agent Mode' and 'Approvals' don't both surface a 'Plan' concept; this is a UX design call for the chat/agent-sessions owners.
