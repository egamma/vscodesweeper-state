# Issue #290272 — Skill changes in skill.md don’t apply until VS Code restart or new chat session

[https://github.com/microsoft/vscode/issues/290272](https://github.com/microsoft/vscode/issues/290272)

## Summary

Valid improvement request from a team member: skill.md edits should apply mid-conversation without requiring a restart. pwang347 confirmed this is by-design (skills are immutable once loaded via read_file) but expressed interest in revisiting. No fix has landed on main.

## Change summary

Editing and saving skill.md mid-conversation does not pick up changes until VS Code restart or a new chat session.

## Best solution

Implement mid-conversation skill hot-reload so that when a skill.md file changes on disk, subsequent skill invocations in the same session use the updated content. The `onDidChangeSkills` event infrastructure already exists in the prompts service layer; the gap is in re-reading skill content when re-invoked rather than serving the cached read_file result. Competitors (Claude Code, Gemini CLI) already support this.
