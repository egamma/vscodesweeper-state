# Issue #296089 — Unclear how to reopen diff from Copilot CLI in terminal

[https://github.com/microsoft/vscode/issues/296089](https://github.com/microsoft/vscode/issues/296089)

## Summary

Keep open: the terminal CLI integration still discards the session-specific diff state when its tab closes, and no verified older canonical owns reopening it. The team-authored request and supporting comment warrant a focused design discussion about returning to review without changing acceptance semantics.

## Change summary

Provide a discoverable way to reopen a Copilot CLI session's diff after closing its editor.

## Best solution

Make the original comparison accessible again from the associated terminal session, with explicit semantics for whether review is still pending. Treat the comment's request to undo acceptance as a separate scope decision rather than implicitly making reopening reverse an accepted change.
