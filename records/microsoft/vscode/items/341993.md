# Issue #341993 — Slack-Style Nested Sub-Threads in Copilot Chat

[https://github.com/microsoft/vscode/issues/341993](https://github.com/microsoft/vscode/issues/341993)

## Summary

Current main has selection-anchored side chats, but the inspected workbench implementation opens a separate editor rather than a collapsible thread attached to a message. Keep this request open for that remaining interaction-design gap; no canonical issue covering the same request was verified.

## Change summary

Support collapsible, message-attached Copilot Chat sub-threads with isolated conversation context.

## Best solution

Evaluate a message-attached, collapsible presentation using the existing side-chat infrastructure rather than introducing another conversation mechanism. Preserve the existing source-turn and origin-navigation capabilities, and decide whether the remaining presentation belongs in the main Chat pane.
