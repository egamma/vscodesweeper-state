# Issue #341993 — Slack-Style Nested Sub-Threads in Copilot Chat

[https://github.com/microsoft/vscode/issues/341993](https://github.com/microsoft/vscode/issues/341993)

## Summary

Existing side-chat actions address isolated follow-up questions, but they open a separate chat editor rather than a collapsible thread attached to a message. Keep this request open for consideration of that remaining presentation and navigation gap; no qualifying older duplicate was verified.

## Change summary

Support collapsible, message-attached Copilot Chat subthreads that inherit context through the selected message without adding their discussion to the parent conversation.

## Best solution

Evaluate a message-attached, collapsible presentation for the existing side-chat capability rather than introducing a separate conversation-branching mechanism. The remaining product decision is whether that inline interaction belongs alongside the current side-by-side chat experience.

This covers part of the context-management goal, subject to session support.
- **Existing message-specific entry point:** src/vs/workbench/contrib/chat/browser/responseSelectionSideChatController.ts provides Ask in Side Chat for selected assistant-response text and passes the selected response's requestId as sourceTurnId. src/vs/workbench/contrib/chat/common/chatSideChatService.ts represents the source conversation, source turn, and optional selected excerpt.
- **Remaining observable gap:** EditorSideChatProviderContribution.askInSideChat in src/vs/workbench/contrib/chat/browser/chatSideChatProvider.ts calls createSideChat and opens the result in a side editor group using openSession(..., target, { pinned: true }).
