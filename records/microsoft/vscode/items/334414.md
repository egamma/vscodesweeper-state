# Issue #334414 — macOS Vietnamese Telex IME causes line/cursor jump in integrated terminal (not editor, not Terminal.app)

[https://github.com/microsoft/vscode/issues/334414](https://github.com/microsoft/vscode/issues/334414)

## Summary

Well-isolated report pointing to the terminal's composition/IME rendering rather than VS Code's own editing surface; the integrated terminal delegates all composition handling to the bundled xterm.js library, so this is most likely rooted in that dependency rather than in VS Code's own terminal code.

## Change summary

Typing with macOS Vietnamese Telex IME in the integrated terminal causes a spurious line/cursor jump, while the same input works fine in the Monaco editor and in Terminal.app/iTerm2.

## Best solution

Investigate xterm.js's composition-view/composition-helper handling (the bundled @xterm/xterm dependency) for the source of the mispositioned/overflowing composition text; if confirmed upstream, track or file against xterm.js and reference this issue, since VS Code's terminal contrib code has no custom composition logic of its own to patch.
