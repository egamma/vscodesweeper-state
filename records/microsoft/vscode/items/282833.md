# Issue #282833 — Update terminology/labels around 'worktree' vs 'workspace'

[https://github.com/microsoft/vscode/issues/282833](https://github.com/microsoft/vscode/issues/282833)

## Summary

Keep open: maintainers supported simplifying the isolation choice, but current source still exposes Worktree/Workspace terminology. The verified related reports are newer and cannot replace this previously reviewed, team-authored request.

## Change summary

Make background-session working locations and change destinations understandable without requiring users to distinguish unexplained worktree and workspace concepts.

## Best solution

Complete the maintainer-supported simplification: choose an isolated worktree for Git repositories and the workspace for non-Git folders, with clear wording about where session changes live. Reconcile that direction with the newer Agents Window isolation controls rather than treating a renamed or optional control as completion.
