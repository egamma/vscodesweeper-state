# Issue #282833 — Update terminology/labels around 'worktree' vs 'workspace'

[https://github.com/microsoft/vscode/issues/282833](https://github.com/microsoft/vscode/issues/282833)

## Summary

Keep open: current UI partially explains worktree isolation, but the background-session provider still exposes the unexplained Workspace/Worktree choice discussed here. No issue-referencing fix was established, and the verified related requests are newer, so they cannot replace this re-reviewed, team-authored report.

## Change summary

Make agent-session working locations and change destinations understandable without requiring users to know the distinction between a workspace and a Git worktree.

## Best solution

Carry forward the maintainers' agreed simplification—automatic worktree use for Git repositories and workspace use otherwise—and make the active location and change destination clear. Reconcile that direction with the newer Agents Window's explicit, remembered isolation choice before changing current behavior.
