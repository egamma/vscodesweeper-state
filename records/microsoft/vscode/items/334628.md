# Issue #334628 — Implement keyboard shortcut to pin selection to Github Copilot Chat as context

## Summary

Legitimate gap: pinning the implicit selection context in Copilot Chat is currently only available via a mouse-click button, with no command ID or keybinding — worth routing to the chat area for a maintainer decision on adding a keybindable command.

## Change summary

Add a keyboard shortcut (with a default keybinding) to pin the current editor selection as chat context, instead of requiring a click on the 'Pin selection' button.

## Best solution

Expose `pinSelection` in ImplicitContextAttachmentWidget (src/vs/workbench/contrib/chat/browser/attachments/implicitContextAttachment.ts) as a registered command/action with `CommandsRegistry`/`registerAction2` so it can carry a default keybinding, scoped to when a chat implicit selection context exists.
