# Issue #334628 — Implement keyboard shortcut to pin selection to Github Copilot Chat as context

[https://github.com/microsoft/vscode/issues/334628](https://github.com/microsoft/vscode/issues/334628)

## Summary

The selection can already be pinned through a keybindable command, but it has no default keybinding, so the request remains a real keyboard-access and discoverability gap. Route it to Chat and Accessibility rather than closing it against the older GUI-pinning issue.

## Change summary

Provide a default keyboard shortcut for pinning the editor selection as persistent Chat context.

## Best solution

Decide whether `workbench.action.chat.attachSelection` should receive a conflict-free default keybinding or whether pinning needs a distinct command with different focus behavior. Any adopted shortcut should also be documented in Chat's accessibility help.

## Evidence

- **existing command:** src/vs/workbench/contrib/chat/browser/actions/chatContextActions.ts registers the keybindable `workbench.action.chat.attachSelection` command as “Add Selection to Chat”; it converts the active editor selection into an explicit attachment but declares no default keybinding.
- **pin behavior:** src/vs/workbench/contrib/chat/browser/attachments/implicitContextAttachment.ts implements the visible “Pin selection” button through the private `pinSelection()` method, which adds the provisional selection to the regular attachment model.
- **related issue:** https://github.com/microsoft/vscode/issues/265954 is older and led toward the existing GUI pin affordance, but it does not own this report's remaining request for a default keyboard shortcut; its author explicitly contrasted the desired button with the already-known attach-selection command.
- **remaining gap:** The existing command makes custom user keybindings possible, so that half of the request is already supported; the requested default binding and its intended focus behavior remain undecided.
