# Issue #291002 — Toggle to show the number of tokens in context window widget

[https://github.com/microsoft/vscode/issues/291002](https://github.com/microsoft/vscode/issues/291002)

## Summary

Current main shows aggregate used/total tokens alongside a percentage, but each context-breakdown row remains percentage-only and has no unit toggle. This team-authored request therefore remains open; no explicitly referencing implementation or older canonical with the same observable request was found.

## Change summary

Let users switch the context-window breakdown between percentages and token counts, and clarify what the System Instructions value represents.

## Best solution

Provide an accessible unit control for the context-window breakdown that presents either percentages or token counts with clearly defined rounding and persistence. Clarify that System Instructions represents the composed system-context attribution for that request, which can vary with agents, tools, skills, and other session inputs rather than being only a model-constant paragraph.
