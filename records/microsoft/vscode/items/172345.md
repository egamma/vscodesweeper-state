# Issue #172345 — Optimize IPC traffic when saving notebooks (large notebooks slow over Remote-SSH?)

[https://github.com/microsoft/vscode/issues/172345](https://github.com/microsoft/vscode/issues/172345)

## Summary

Keep open: the experimental remote-save path reduced IPC traffic, but multiple users subsequently reproduced severe delays with it enabled, and current main still leaves it experimental and disabled by default on stable.

## Change summary

Reduce notebook save and output IPC traffic that saturates Remote-SSH connections and stalls large notebooks.

## Best solution

Reproduce the remaining large-output case against current main, distinguish notebook document synchronization from save serialization traffic, and make the reduced-communication path reliable enough to enable by default in stable.
