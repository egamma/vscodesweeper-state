## Change summary

Add interactive context attribution, pre-send request previews, selective optimization, protected context, and optional workspace exclusions to Copilot Chat.

## Best solution

Evaluate a scoped extension of the existing context-usage and request-inspection surfaces, starting with contributor-level attribution and clearly distinguishing estimated upcoming context from requests already sent. Selective removal, pinning, and exclusions need explicit product semantics before implementation, particularly during multi-step agent requests.
