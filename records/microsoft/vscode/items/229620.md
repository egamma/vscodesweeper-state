Keep open: this team-authored, accepted backlog bug has no issue-referencing fix commit or verified older canonical duplicate. The image-preview implementation has changed substantially since the report, so the current keyboard-focus behavior needs to be reproduced before choosing a fix.

## Change summary

Keyboard focus resets to the start of the window when tabbing out of an attached-image preview opened from panel chat.

## Best solution
