# Issue #243338 — Add a grammar for js doc: {@link ...} doesn't get color in jsdoc with tree sitter

[https://github.com/microsoft/vscode/issues/243338](https://github.com/microsoft/vscode/issues/243338)

## Summary

Keep open. Current main still has no JSDoc support in tree-sitter highlighting. Tree-sitter can now inject one language into another, and the TypeScript queries already inject regex, but there is no JSDoc grammar or injection yet, so {@link ...} in doc comments is still coloured only as a plain comment. The item is team-authored and parked in Backlog with no fix commit.

## Change summary

Add a JSDoc tree-sitter grammar and inject it into JS/TS doc comments so tags like {@link ...} get their own colours, as TextMate does today.

## Best solution

Add a JSDoc grammar to @vscode/tree-sitter-wasm. Then add a jsdoc highlights query, inject it from comment nodes in src/vs/editor/common/languages/injections/typescript.scm, and add 'jsdoc' to TREESITTER_ALLOWED_SUPPORT in treeSitterLibraryService.ts.
