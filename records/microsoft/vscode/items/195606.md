# Issue #195606 — [Bug] Color picker broken if monaco-editor is inside shadow dom

[https://github.com/microsoft/vscode/issues/195606](https://github.com/microsoft/vscode/issues/195606)

## Summary

Keep open: the current mouse-leave monitor still mistakes shadow-DOM event retargeting for movement outside the editor. The linked fix PR remains open and should be reviewed rather than treating the issue as completed.

## Change summary

Monaco's color picker disappears on mouse movement when the editor is embedded in a shadow root.

## Best solution

Preserve color-picker interaction inside shadow-root editors while retaining genuine mouse-leave detection. Review the existing implementation candidate at https://github.com/microsoft/vscode/pull/195608 against both behaviors before landing a fix.

## Evidence

- **Concrete reproduction:** https://github.com/microsoft/monaco-editor/issues/3845 supplies a playground example using an open shadow root, CSS containing a color declaration, explicit reproduction steps, and a video showing the picker disappearing on mouse movement.
- **Current source defect:** In src/vs/editor/browser/controller/mouseHandler.ts, the MouseHandler constructor installs an ownerDocument mousemove listener that calls _onMouseLeave whenever viewDomNode.contains(e.target) is false. For movement inside a shadow-root editor, the document listener receives the retargeted shadow host rather than the internal element, so this containment check incorrectly reports an editor exit.
- **Hover dismissal path:** src/vs/editor/contrib/hover/browser/contentHoverController.ts subscribes to editor.onMouseLeave. Its _onEditorMouseLeave cancels pending hover work and calls hideContentHover unless a keep-visible condition applies, connecting the false editor-exit event to the reported disappearing picker.
- **Open implementation candidate:** Verified https://github.com/microsoft/vscode/pull/195608 is OPEN with mergedAt null. Its body explicitly links this issue, and its diff changes the same document-level containment check to suppress synthetic mouse-leave handling for shadow-root editors. This is an unmerged proposal, not a landed fix.
