# Issue #115626 — Microsoft Auth Provider should support overriding client id and tenant id

[https://github.com/microsoft/vscode/issues/115626](https://github.com/microsoft/vscode/issues/115626)

## Summary

Keep open: custom client and tenant overrides already work through special scopes, and proposed APIs now offer explicit options, but the stable extension-facing contract remains unfinished. The api-proposal label independently prohibits a cleanup close.

## Change summary

Allow extensions to select their own Microsoft authentication client ID and tenant through supported authentication API options.

## Best solution

Have the authentication API owners reconcile this request with the authIssuers and authProviderSpecific proposals and decide the stable client/tenant override contract. Preserve existing special-scope compatibility and document the required application redirect URIs.
