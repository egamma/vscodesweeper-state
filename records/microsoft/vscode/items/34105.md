# Issue #34105 — Selection, highlighting and search colors conflict with each other

[https://github.com/microsoft/vscode/issues/34105](https://github.com/microsoft/vscode/issues/34105)

## Summary

Keep this accepted, well-supported editor-theming request open: transparency improves visibility but does not provide the requested selection precedence. Current source has explicit decoration priorities and selection-overlap filtering, so the historical cases need reassessment before choosing the remaining behavior.

## Change summary

Make selection, occurrence and find highlighting interact predictably, keeping selected text distinguishable across Ctrl+D, find navigation and closing the find widget.

## Best solution

Establish a consistent selection-versus-highlight precedence contract in the editor renderer, then address the original cases that still violate it. Preserve supported transparent theme colors and existing default-theme appearance rather than treating transparency workarounds as completion.
