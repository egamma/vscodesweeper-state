# Issue #34105 — Selection, highlighting and search colors conflict with each other

[https://github.com/microsoft/vscode/issues/34105](https://github.com/microsoft/vscode/issues/34105)

## Summary

Keep open as the canonical request for deterministic priority between selections and overlapping editor decorations. Transparency and border customization mitigate the problem, but current main still lacks the proposed recency or priority model.

## Change summary

Ensure text selections remain distinguishable when they overlap find matches, word highlights, and other editor decorations.

## Best solution

Define a consistent ordering or recency model in the editor rendering pipeline, with active selections remaining distinguishable from find and highlight decorations. Preserve transparent colors as a supported styling option rather than requiring them as the workaround.
