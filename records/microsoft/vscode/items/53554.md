# Issue #53554 — Editor/terminal only anti aliasing

[https://github.com/microsoft/vscode/issues/53554](https://github.com/microsoft/vscode/issues/53554)

## Summary

Keep this open as the canonical request for independently controlling editor, terminal, and workbench font aliasing. Current main still exposes only a macOS-wide workbench setting, while renderer limitations leave the central request unresolved.

## Change summary

Allow font aliasing to be configured independently for the editor, integrated terminal, and remaining workbench UI.

## Best solution

Decide whether reliable per-surface controls can be supported across the editor's DOM/GPU renderers and xterm.js. If not, document the renderer and platform limitations here; narrower terminal-wide support remains tracked by https://github.com/microsoft/vscode/issues/36249.

## Evidence

- **current implementation:** src/vs/workbench/browser/workbench.contribution.ts registers only `workbench.fontAliasing`, restricted to macOS, while src/vs/workbench/browser/workbench.ts applies one aliasing class to the entire main workbench container.
- **editor renderer gap:** src/vs/editor/browser/gpu/raster/glyphRasterizer.ts still contains `TODO: Support workbench.fontAliasing correctly` and selects antialiasing internally rather than through a per-editor setting.
- **terminal limitation:** https://github.com/microsoft/vscode/issues/36249 remains open for terminal support. Its upstream xterm.js issue https://github.com/xtermjs/xterm.js/issues/2464 was closed after maintainers concluded antialiasing control is unreliable across renderers.
- **canonical status:** Maintainers closed https://github.com/microsoft/vscode/issues/128917 and https://github.com/microsoft/vscode/issues/208633 as duplicates of this issue, indicating that this remains the canonical report for the broader per-surface problem.
- **distinct from narrower issue:** https://github.com/microsoft/vscode/issues/36249 asks the terminal to honor the global workbench setting; it does not cover this issue's requirement to leave workbench UI aliasing independent.
