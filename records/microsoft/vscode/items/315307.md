# Issue #315307 — Add skill for creating plugins

[https://github.com/microsoft/vscode/issues/315307](https://github.com/microsoft/vscode/issues/315307)

## Summary

Keep open: the built-in customization skills still omit plugin authoring and plugin-scoped skill locations. The existing Create Plugin command packages customizations, but does not supply the agent guidance requested here; no verified canonical or issue-referencing fix was found.

## Change summary

Teach the built-in customization skills to create agent plugins and place newly authored skills inside them.

## Best solution

Provide discoverable plugin-authoring guidance alongside the built-in customization skills, consistent with the plugin formats supported by VS Code. It should support creating a skill within a plugin without requiring the user to supply an example repository.
