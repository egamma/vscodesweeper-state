## Change summary

Add a builtin Copilot coding-agent skill that teaches the agent how to create plugins (the VS Code customization concept), so it doesn't fall back to creating normal skills or claiming ignorance.

The chat-customizations-editor skill already documents plugin concepts at the UI level; the new skill would cover authoring.
