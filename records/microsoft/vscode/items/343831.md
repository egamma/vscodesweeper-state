## Summary

The installed-state mismatch remains in current main: recommendations exclude Copilot CLI installations from their installed inventory, and the recommended-results view cannot recognize those installations. Keep this open as a bounded bug; the related discovery and migration requests do not replace this specific correction.

Recognize CLI-installed agent plugins as installed in workspace recommendation notifications and recommended plugin results, avoiding a second installation.

## Best solution

Make recommendation counting, recommended installed rows, and marketplace installation matching consistently recognize the same CLI-managed plugin. Preserve installation ownership and enablement semantics rather than requiring migration or another installation.
