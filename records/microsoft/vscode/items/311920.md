# Issue #311920 — Agent profiles and namespacing for Copilot custom agents

[https://github.com/microsoft/vscode/issues/311920](https://github.com/microsoft/vscode/issues/311920)

## Summary

Valid feature request for agent namespacing and profile-based scoping. A team member (aeschli) engaged constructively and agreed that qualifying agent names would be valuable. An open community PR (#326247) partially addresses the picker UX by grouping agents by storage, but the core asks — a namespace/publisher identity field and named activation profiles — are not yet implemented on main.

## Change summary

Add namespace/publisher identity fields and named activation profiles for user-level Copilot custom agents to prevent naming collisions and reduce picker noise at scale.

## Best solution

The two asks should be considered independently: (1) a `namespace` or `publisher` field in agent YAML frontmatter for qualified identity and collision resolution — this aligns with aeschli's comment and the related enterprise agent naming discussion in https://github.com/microsoft/vscode/issues/312256; (2) named agent profiles for activation scoping — a larger design question that may benefit from the ongoing AI customization work. The open community PR https://github.com/microsoft/vscode/pull/326247 addresses a narrower grouping UX and is worth reviewing on its own merits. The area owner should decide the scope and priority of a formal namespacing scheme.
