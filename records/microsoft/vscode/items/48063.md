# Issue #48063 — Search and replace across files corrupts files with CR line endings

[https://github.com/microsoft/vscode/issues/48063](https://github.com/microsoft/vscode/issues/48063)

## Summary

Keep open: current source still allows disk-search coordinates that ignore CR-only line breaks to drive replacements in an editor model that recognizes those breaks, corrupting unrelated text. This team-authored, confirmed report tracks replacement safety, not merely the broader request for CR support.

## Change summary

Prevent Search and Replace across files from modifying unrelated text when files contain CR-only line endings.

## Best solution

Make search replacements and their previews safe when disk-search coordinates disagree with the resolved text model: only apply replacements to verified matching text, or explicitly reject unsafe replacements. Address this search-specific safety defect independently of full CR-only editing support.
