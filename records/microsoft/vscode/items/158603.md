# Issue #158603 — Sidebar defaultWidth, View-Specific Sidebar widths, & View-Specific Sidebar defaultWidths

[https://github.com/microsoft/vscode/issues/158603](https://github.com/microsoft/vscode/issues/158603)

## Summary

This remains the canonical, highly supported request for per-view sidebar widths. Current main persists only one shared sidebar width, so switching Activity Bar views still leaves a meaningful gap.

## Change summary

Remember and optionally configure sidebar widths independently for each built-in or extension-contributed view container.

## Best solution

Persist a bounded width keyed by view-container ID for the primary and secondary sidebars, restoring it when containers switch and using the shared default for unseen containers. This should cover extension-contributed containers without registering a separate setting for every extension.

- **Fit:** aligned
- **Reason:** Remembering view-specific dimensions improves layout flexibility in a mainstream workbench workflow without adding permanent UI.
