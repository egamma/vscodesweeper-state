# Issue #132085 — Editor hint in new file can't be reached by tabbing

[https://github.com/microsoft/vscode/issues/132085](https://github.com/microsoft/vscode/issues/132085)

## Summary

The empty-editor hint actions remain inaccessible by Tab in current source, and maintainers explicitly agreed they should be focusable. Keep this issue open while the existing linked implementation proposals are reviewed.

## Change summary

Make the action links in a new untitled editor's hint reachable and operable using the keyboard.

## Best solution

Provide keyboard navigation and activation for the visible hint actions without inserting text or prematurely dismissing the hint. Review the existing open proposals, particularly https://github.com/microsoft/vscode/pull/219274 and https://github.com/microsoft/vscode/pull/308138, rather than starting another competing implementation.
