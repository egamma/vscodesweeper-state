# Issue #299075 — Copilot not respecting excludeAgent flag in instructions file

[https://github.com/microsoft/vscode/issues/299075](https://github.com/microsoft/vscode/issues/299075)

## Summary

The observed behavior is intentional: `excludeAgent` distinguishes Copilot cloud agent and Copilot code review on GitHub.com; it does not exclude instructions from local VS Code Chat.

## Change summary

Make the `excludeAgent` instruction-file attribute prevent selected instructions from being used by local VS Code agents.

## Best solution

Keep `excludeAgent` scoped to the GitHub.com `code-review` and `cloud-agent` consumers rather than treating local VS Code Chat as one of those agent identifiers.
