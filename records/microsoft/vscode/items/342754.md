# Issue #342754 — Show a visible warning when none of the models pinned in a custom agent are available

[https://github.com/microsoft/vscode/issues/342754](https://github.com/microsoft/vscode/issues/342754)

## Summary

The requested warning remains a real gap: current source preserves fallback behavior without explicitly telling users that every configured model was unavailable. The related model-precedence and alias requests do not cover both the runtime notice and stronger agent-file diagnostics.

## Change summary

Make all-unavailable custom-agent model pins visible in chat and report them as warnings in the agent file.

## Best solution

Preserve the usable fallback while clearly identifying the affected agent and actual fallback model when no configured model resolves. Make that condition a warning in agent-file diagnostics without treating a partially available ordered model list as a total failure.
