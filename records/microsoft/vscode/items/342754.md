# Issue #342754 — Show a visible warning when none of the models pinned in a custom agent are available

[https://github.com/microsoft/vscode/issues/342754](https://github.com/microsoft/vscode/issues/342754)

## Summary

The requested fallback warning remains missing in the inspected paths, including the newer harness-aware file diagnostics. Related reports concern different observable behavior and do not justify consolidating this re-reviewed request.

## Change summary

Make unavailable custom-agent model pins visible in chat and promote file diagnostics when the entire model preference list is unavailable.

## Best solution

Preserve usable fallback behavior while explicitly identifying the affected agent and effective model, with warning-level file diagnostics when no configured model resolves. Plan this against the effective harness's authoritative catalogue rather than treating loading or discovery failures as model unavailability.
