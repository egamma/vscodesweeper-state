# Issue #229572 — disambiguate links in chat with the same name

[https://github.com/microsoft/vscode/issues/229572](https://github.com/microsoft/vscode/issues/229572)

## Summary

Same-named file links still receive indistinguishable labels in current source; paths are available only on hover. Keep this accepted, team-authored bug open as the canonical issue, including the attachment case consolidated into it.

## Change summary

Make links and attachments referring to distinct files with the same basename distinguishable without hovering.

## Best solution

Show enough path context to distinguish colliding file labels while preserving compact labels for non-colliding files. Cover response links and the attachment case consolidated here, with consistent behavior as responses stream and rerender.
