# Issue #281871 — NES hidden behind the refactoring dialog

[https://github.com/microsoft/vscode/issues/281871](https://github.com/microsoft/vscode/issues/281871)

## Summary

The overlap remains possible on current main: focus stays within the editor widget while the rename input is open, and the inline-edit controller does not use the rename-visible context to suppress or reposition NES. This team-authored Backlog bug should remain open while the intended coexistence behavior is decided.

## Change summary

Prevent a next edit suggestion from being obscured by the inline rename refactoring widget.

## Best solution

Define how NES and rename should coexist—temporarily suppress NES while rename is active or place the two surfaces without overlap—then enforce that behavior through the rename and inline-completions integration.
