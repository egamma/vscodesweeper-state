# Issue #251352 — Bug: Profile Extensions UI incorrectly displays extensions after switching source under that profile.

[https://github.com/microsoft/vscode/issues/251352](https://github.com/microsoft/vscode/issues/251352)

## Summary

The display bug remains source-reproducible on current main: extension children bypass the selected source flag even though changing that flag refreshes the contents tree. The issue should remain open as a bounded user-profiles bug.

## Change summary

Switching an existing profile's Extensions source between Default and the profile itself leaves the expanded extension list showing entries from the wrong source.

## Best solution

Make the existing-profile Extensions list resolve children from the source currently selected for that resource, while preserving application-scoped extension actions and the behavior of other profile resources.
