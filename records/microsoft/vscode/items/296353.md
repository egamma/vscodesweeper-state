# Issue #296353 — Feature Request: Add "wait" or "sleep" builtin tool for AI agents

[https://github.com/microsoft/vscode/issues/296353](https://github.com/microsoft/vscode/issues/296353)

## Summary

Keep open and route to chat tools. Current terminal tooling handles command completion, but no generic cancellation-aware delay tool covers rate limiting or non-terminal polling; as a team-authored request, it also cannot receive a judgment close.

## Change summary

Add a built-in agent tool that pauses for a specified duration and optionally coordinates a subsequent tool call.

## Best solution

Evaluate a bounded, cancellation-aware delay primitive in the chat tool layer for cases without an event-driven completion signal. Keep follow-up execution in the model's normal tool loop rather than embedding arbitrary nested tool invocation, while retaining automatic terminal completion notifications for terminal workflows.
