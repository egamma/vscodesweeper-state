# Issue #228110 — SCM Graph - Hover does not escape markdown in commit message

[https://github.com/microsoft/vscode/issues/228110](https://github.com/microsoft/vscode/issues/228110)

## Summary

The reported heading rendering remains reproducible from current source: commit messages reach the hover renderer without escaping heading syntax. Keep this team-authored Backlog issue open; no referenced fix or verified canonical duplicate was found.

## Change summary

Prevent Markdown syntax such as '# First Commit' in commit messages from becoming a heading in the SCM Graph hover.

## Best solution

Display commit-message heading markers literally in the SCM Graph hover while preserving provider-generated links and the hover's structured metadata. Establish the intended treatment of other Markdown formatting before changing the shared Git hover behavior.
