# Issue #241870 — Disable shell env via `terminal.integrated.shellIntegration.environmentReporting` does apply to existing terminal

[https://github.com/microsoft/vscode/issues/241870](https://github.com/microsoft/vscode/issues/241870)

## Summary

Still reproduces on main: the `shellIntegrationEnvironmentReporting` setting is read once at terminal construction (terminalInstance.ts:421) and never updated on configuration change, so toggling it has no effect on existing terminals. Team discussion in the comments suggests either updating the API-side gating or documenting the restart requirement — both remain undone.

## Change summary

Disabling `terminal.integrated.shellIntegration.environmentReporting` does not take effect for already-running terminals.

## Best solution

Either gate the environment-reporting data at the API layer (so disabling the setting stops exposing env data even for existing terminals, per jrieken's suggestion in comment 2), or update the setting description to mention that terminals must be restarted (per Tyriar's comment 1). The team should decide which approach based on the discussion in the comments.
