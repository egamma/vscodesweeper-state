## Evidence

- **Reported trigger and isolation:** https://github.com/microsoft/vscode/issues/205894 describes monitor blackouts after switching window focus, changing zoom, or opening Help: About. The reporter confirms reproduction with extensions disabled and no reproduction with code --disable-gpu.
- **Independent confirmations and upstream boundary:** The supplied discussion confirms similar behavior on Windows 10 and 11, NVIDIA and AMD configurations, and other Electron/Chromium applications including Discord, Azure Storage Explorer, Chrome, and Brave. Disabling G-SYNC or FreeSync helps some users, but another reports G-SYNC was already disabled; no single driver or refresh-rate cause is established.
- **Persistence across runtime upgrades:** The supplied February 17, 2026 comment reports continued symptoms on VS Code 1.109.2 with Electron 39.3.0 and Chromium 142.0.7444.265, with disabled GPU acceleration still effective.
