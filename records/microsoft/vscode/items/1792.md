# Issue #1792 — Proposal: Add mnemonics to context menu items

[https://github.com/microsoft/vscode/issues/1792](https://github.com/microsoft/vscode/issues/1792)

## Summary

Still not implemented: the menu widget supports `enableMnemonics` but the context menu handler never passes this option. A team member acknowledged in 2018 it's possible but not yet enabled. Keeping open as a valid feature request.

## Change summary

Add mnemonic/accelerator key support (underlined letters for keyboard access) to context menu items.

## Best solution

Wire up `enableMnemonics: true` in `src/vs/platform/contextview/browser/contextMenuHandler.ts` when constructing the menu widget for context menus, possibly gated behind a setting or platform check (Windows/Linux). The base `Menu` class in `src/vs/base/browser/ui/menu/menu.ts` already supports mnemonics — this is a plumbing gap, not a design gap.
