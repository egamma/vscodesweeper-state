# Issue #318095 — [feat] Allow Terminal in panel and Secondary Side Bar simultaneously

[https://github.com/microsoft/vscode/issues/318095](https://github.com/microsoft/vscode/issues/318095)

## Summary

Valid feature request with 17 upvotes. The current view container architecture only allows a view to exist in one location at a time; this asks for multi-instance terminal views across panel and sidebar, similar to the existing panel+editor coexistence. No duplicate found; not yet implemented on main.

## Change summary

Allow the Terminal view to appear in both the panel and a side bar simultaneously, with independent terminal tabs in each location.

## Best solution

This would require changes to the view container system (views are currently singleton per container) to support multi-instance views, or a dedicated second terminal view registration for the sidebar. The terminal already has a panel+editor split model (via `terminalEditingService`); extending that pattern to sidebars is the natural path. Area: `terminal` and `workbench-views` — needs design input on whether this should be terminal-specific or a general multi-location view capability.
