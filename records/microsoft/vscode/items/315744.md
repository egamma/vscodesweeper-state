# Issue #315744 — "Expand" button on plan widget should expand more

[https://github.com/microsoft/vscode/issues/315744](https://github.com/microsoft/vscode/issues/315744)

## Summary

Team-authored issue, must keep open. The expand button on the plan widget only increases max-height from min(420px, 50vh) to min(720px, calc(100vh - 240px)), which on many screens gives only ~100px extra — the bug is confirmed in CSS on current main with no fix landed.

## Change summary

The plan widget's expand button should use more of the available viewport space instead of giving only a small height increase.

## Best solution

Change the expanded max-height in chatPlanReview.css (line 68) to use more of the viewport (e.g. calc(100vh - 120px) or similar), or consider the suggestion from a commenter to open the plan in an editor modal for truly long plans.
