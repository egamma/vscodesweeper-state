# Issue #315744 — "Expand" button on plan widget should expand more

[https://github.com/microsoft/vscode/issues/315744](https://github.com/microsoft/vscode/issues/315744)

## Summary

The expanded plan remains capped at 420px or half the viewport on current main, leaving substantial usable space unavailable for long plans. This team-authored, accepted On Deck bug must stay open, and the maintainer discussion leaves a product choice between a larger responsive inline view and an editor modal.

## Change summary

Make the plan widget's Expand action provide substantially more room for reading long plans.

## Best solution

Let long plans use the available chat or Agents window height when expanded, or deliberately move the expanded experience into an editor modal; preserve a compact collapsed state and accessible keyboard behavior.
