# Issue #285951 — GitHub Copilot frequently stalls at "Working" after editing previous prompt

[https://github.com/microsoft/vscode/issues/285951](https://github.com/microsoft/vscode/issues/285951)

## Summary

Legitimate perf bug with multiple confirmations. Related fixes landed (#286660 for edit-mode slowness, #285251 for session persistence freezes), but the core complaint — minutes-long 'Working...' stall after resubmitting an edited prompt in very long sessions — was acknowledged as distinct by roblourens and has no dedicated fix commit. Already properly labeled; should stay open.

## Change summary

Editing and resubmitting a previous chat prompt in a very long conversation causes Copilot to stall at 'Working...' for minutes, even though new prompts process immediately.

## Best solution

Investigate the request-submission pipeline for edited prompts in long sessions — the stall is likely in async pre-request work (history summarization, context assembly, or token counting) that scales with conversation length. Profile the extension host and renderer during the 'Working...' phase for a 100K+ line session. The fix in https://github.com/microsoft/vscode/commit/86db4eb05db addressed entering edit mode but not the post-submit stall.
