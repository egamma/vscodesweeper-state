# Issue #206101 — A way to open a file in hex editor from Terminal

[https://github.com/microsoft/vscode/issues/206101](https://github.com/microsoft/vscode/issues/206101)

## Summary

Keep open: current CLI registrations still lack an explicit editor-selection option, and existing association settings do not cover choosing Hex Editor for an arbitrary file on a single invocation. Maintainers welcomed this capability; the linked implementation was closed without merging, so its closure does not establish that the request was delivered.

## Change summary

Allow a terminal invocation to open an arbitrary file directly in Hex Editor without changing persistent editor associations.

## Best solution

Provide a generic CLI editor-selection capability using registered editor IDs rather than a Hex Editor-specific flag. Before reviving implementation, reconcile the issue's accepted direction with the later out-of-scope closure of its proposed PR, including the unresolved custom-editor registration concerns.
