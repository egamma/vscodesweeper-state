The reported Windows installation instead fails managed-settings and model discovery at the authenticated GitHub user endpoint, while regular Chat and connectivity probes succeed. - **Trace:**

  > NetworkDiagnosticsService.fetch in src/vs/platform/agentHost/node/networkDiagnosticsService.ts uses IRequestService, whereas resolveCopilotManagedSettings in node/copilot/copilotManagedSettings.ts and CopilotAgent._listModels in node/copilot/copilotAgent.ts invoke SDK RPCs. The trace establishes separate request paths, not the native failure's root cause. The Ubuntu workaround resembles the packaging failure fixed by https://github.com/microsoft/vscode/pull/348621, but that Linux-only change cannot explain or repair Windows.
