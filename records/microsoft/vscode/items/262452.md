[https://github.com/microsoft/vscode/issues/262452](https://github.com/microsoft/vscode/issues/262452)

## Summary

The entire local workspace indexing mechanism has been removed from Copilot in commit b36aed58183 (shipped in 1.116.0). The "Updating local workspace index..." state no longer exists — Copilot now uses grep and file search instead, which work reliably across WSL and remote scenarios.

## Change summary

Copilot's local workspace index gets stuck forever in "Updating local workspace index..." when using WSL Remote or VS Code Remote.

## Best solution

No further change needed. The local index concept was removed entirely in favor of grep/file search (commit b36aed58183, issue https://github.com/microsoft/vscode/issues/292972), which resolved this class of stuck-indexing bugs. Users on 1.116.0+ will not see this issue.
