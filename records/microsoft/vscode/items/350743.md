# Issue #350743 — P1 Outline re-applies markers in O(symbols × markers) on every diagnostics update, so multi-cursor typing in a large file freezes (1k cursors ≈ 2 s per key, 10k hung > 9 min)

[https://github.com/microsoft/vscode/issues/350743](https://github.com/microsoft/vscode/issues/350743)

## Summary

Keep open: current source confirms a full marker-array scan for every outline element, including elements that consume no markers. This is a distinct, bounded performance defect; the reported nine-minute hang has additional possible contributors.

## Change summary

Diagnostics updates repeatedly scan the shared marker array across large symbol trees, delaying multi-cursor editing.

## Best solution

Make marker application avoid full-array compaction for symbols that consume no diagnostics while preserving marker attribution, counts, severity propagation, and clearing. Treat event coalescing, cross-instance sharing, and other multi-cursor costs as separate follow-up work.
