# Issue #309506 — Should the model be encouraged to use a small subagent for multi-stage inputs?

[https://github.com/microsoft/vscode/issues/309506](https://github.com/microsoft/vscode/issues/309506)

## Summary

Keep open: current prompts encourage execution-subagent delegation, but the subagent hands input-needed commands back to the main agent rather than handling multi-stage terminal interaction. The related merged changes do not establish completion of this team-authored request.

## Change summary

Consider delegating multi-stage terminal input handling to a small, fast subagent instead of repeatedly involving the main agent.

## Best solution

Define whether execution subagents should own interactive terminal conversations through completion, including input and completion notifications, while preserving user control over answers. General execution delegation already exists; the remaining decision concerns interactive ownership and continuation.
