# Issue #328985 — [Error] unhandlederror-Model is disposed!

[https://github.com/microsoft/vscode/issues/328985](https://github.com/microsoft/vscode/issues/328985)

## Summary

Reproducible use-after-dispose bug in the notebook diff view's source diff editor initialization, and it already has an open fixing PR referencing this issue, so the issue should stay open until that PR merges rather than being closed now.

## Change summary

The notebook diff view throws an unhandled 'Model is disposed!' error when a diff cell component is disposed while `_initializeSourceDiffEditor()` is still awaiting `vm.waitForDiff()`, so `setModel` is later called on an already-disposed model.

## Best solution

Land (or review) the open fix in https://github.com/microsoft/vscode/pull/328993, which adds an `_isDisposed` re-check in `_initializeSourceDiffEditor()` (src/vs/workbench/contrib/notebook/browser/diff/diffComponents.ts, ~line 2003) right after `await vm.waitForDiff()`, mirroring the existing guard used after the earlier `await Promise.all([...createModelReference...])` in the same method.
