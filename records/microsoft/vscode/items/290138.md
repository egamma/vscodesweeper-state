# Issue #290138 — Minimap behaves strangely when scrolling past large section of code deleted in chat

[https://github.com/microsoft/vscode/issues/290138](https://github.com/microsoft/vscode/issues/290138)

## Summary

Keep open under discussion: current main intentionally omits view-zone content from the minimap, but its whitespace-aware slider calculation produces the unstable one-line indicator shown in the report. The remaining question is which representation best preserves useful location feedback while scrolling through a large deleted-code zone.

## Change summary

Make the minimap viewport indicator remain spatially stable while scrolling through a large block of deleted code rendered as an editor view zone.

## Best solution

Define a stable minimap representation for viewports dominated by view-zone whitespace, ideally preserving the indicator's relationship to the model lines bordering the zone without rendering deleted content as real minimap lines.
