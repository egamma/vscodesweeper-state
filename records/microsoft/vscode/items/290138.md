# Issue #290138 — Minimap behaves strangely when scrolling past large section of code deleted in chat

[https://github.com/microsoft/vscode/issues/290138](https://github.com/microsoft/vscode/issues/290138)

## Summary

Still unfixed on main — the minimap viewport slider does not account for view zones (used by chat inline diffs for deleted code), causing the slider to jump erratically when the viewport contains only view zones. alexdima acknowledged the behavior is strange and the issue is under active discussion between editor team members.

## Change summary

Minimap viewport slider jumps erratically when scrolling through large sections of deleted code rendered as view zones in chat inline diffs.

## Best solution

The minimap slider logic in src/vs/editor/browser/viewParts/minimap/minimap.ts needs to handle the case where the viewport contains only view zones — either by keeping the slider position stable (as Tyriar suggested) or by representing view zone gaps in the minimap. This is an editor-rendering design decision that alexdima and Tyriar are actively discussing.
