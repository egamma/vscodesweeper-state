# Issue #107360 — append option for vscode.workspace.fs.writeFile

[https://github.com/microsoft/vscode/issues/107360](https://github.com/microsoft/vscode/issues/107360)

## Summary

The public extension API still lacks append support, despite core gaining an internal append path in 2026. Keep this open for API design discussion because exposing append across filesystem providers requires an explicit compatibility decision.

## Change summary

Allow extensions to append bytes through `vscode.workspace.fs.writeFile` without reading and rewriting the entire file.

## Best solution

Consider an optional append mode on the public `workspace.fs.writeFile` API, defining behavior for providers without append capability and coordinating it with the broader streaming/chunk API tracked at https://github.com/microsoft/vscode/issues/84515.
