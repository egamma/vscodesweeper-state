# Issue #324149 — Copilot Chat: Draft in new chat is lost after switching conversations

[https://github.com/microsoft/vscode/issues/324149](https://github.com/microsoft/vscode/issues/324149)

## Summary

Valid bug — confirmed in source. New local chat sessions are deleted on dispose (when switching away) without checking for draft input, whereas external sessions do preserve drafts via hasDraftInput(). This asymmetry causes the reported data loss.

## Change summary

Draft text typed in a new (empty) Copilot Chat conversation is lost when switching to another conversation and back.

## Best solution

In `src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts` line 253, the `willDisposeModel` handler for local sessions should also check `hasDraftInput(model)` before deleting — mirroring the external session path at line 260. When draft input exists, the session should be stored rather than deleted.
