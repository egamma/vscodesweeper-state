# Issue #324149 — Copilot Chat: Draft in new chat is lost after switching conversations

[https://github.com/microsoft/vscode/issues/324149](https://github.com/microsoft/vscode/issues/324149)

## Summary

Verified duplicate of the older, open New Chat Prompt Lost report: both describe losing an unsent draft in a new sidebar chat after visiting an existing conversation and returning.

## Change summary

Preserve unsent drafts in new Copilot Chat conversations when switching between conversations.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/322890 and address draft retention for new conversations there, preserving the existing behavior for ongoing conversations.
