# Issue #346531 — Agents window: cannot reference another session from the active chat input

[https://github.com/microsoft/vscode/issues/346531](https://github.com/microsoft/vscode/issues/346531)

## Summary

The active-chat picker and completion wiring remain broken on current main. Session-link pills now have an implementation, but that partial coverage does not resolve the missing session-selection entry points.

## Change summary

Allow an active Agents-window chat to attach another session through the Sessions picker, completion, or a pasted session link.

## Best solution

Make active-chat session selection use the Agents window's available sessions consistently with its new-chat composer. Preserve existing link-pill handling and verify that the resulting references supply the supported session context.
