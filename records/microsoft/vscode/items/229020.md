# Issue #229020 — `xdg-open <folder>` opens folder in VSCode instead of file browser since Ubuntu 24

[https://github.com/microsoft/vscode/issues/229020](https://github.com/microsoft/vscode/issues/229020)

## Summary

The root cause — snap mime database pollution registering VS Code as a handler for inode/directory — was addressed by commit 4e7b53c5a07 (October 2024) which disabled mime db creation in the snap, and earlier by commit f1c007109d0 which removed inode/directory from the .desktop file. The issue has been pending confirmation for over a year.

## Change summary

xdg-open from VS Code's integrated terminal opens folders in a new VS Code window instead of the file manager, due to snap mime database pollution.
