## Change summary

Opening a directory with xdg-open from the integrated terminal selects VS Code instead of the system file manager after upgrading to Ubuntu 24.

## Best solution

Make directory opening from the integrated terminal honor the same desktop association as the system terminal. First distinguish terminal environment differences from MIME association or desktop-portal behavior, including the reporter's Debian-package result opening VLC.

Current resources/linux/code.desktop does not register inode/directory. An assertion that current code never restores these variables would therefore be incorrect.
