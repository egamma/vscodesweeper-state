# Issue #336684 — Need to provide a reasonable way to allow the user to keep track of launched processes

[https://github.com/microsoft/vscode/issues/336684](https://github.com/microsoft/vscode/issues/336684)

## Summary

A one-day-old, team-authored feature request from kieferrm proposing a way to track processes (e.g. servers) launched by agent sessions so they aren't forgotten after a session ends; no existing UI does this today and the design (Agents window artifacts drop-down, plus an editor-window equivalent) is not yet settled.

## Change summary

Add a way to surface and track processes an agent session has launched (e.g. a lingering dev server) in the Agents window (and editor window), similar to the existing subagent listing.

## Best solution

Design a process-tracking UI in the Agents window artifacts section (chatArtifactsWidget.ts area) modeled on the existing subagent list, plus an equivalent surface for the plain editor window; needs a maintainer decision on where launched-process state is tracked and how it's surfaced before implementation.
