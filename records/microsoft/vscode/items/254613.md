# Issue #254613 — Support Windows package identity to ensure device permissions

[https://github.com/microsoft/vscode/issues/254613](https://github.com/microsoft/vscode/issues/254613)

## Summary

Thanks for the context. Support for package identity landed in https://github.com/microsoft/vscode/pull/257741, but a follow-up (https://github.com/microsoft/vscode/pull/258275) disabled it for system setup. Identity is therefore not yet enforced on every Windows install, and a prior fix citation was refuted. The issue stays open, and no new fix commit was verified.

## Change summary

Always register Windows package identity for VS Code installs so device permissions such as the microphone for VS Code Speech are retained.

## Best solution

Finish and confirm package identity for all Windows install types (user and system setup). That means resolving the sandbox-process crash when identity is registered, and confirming that VS Code appears in the Windows microphone privacy settings.
