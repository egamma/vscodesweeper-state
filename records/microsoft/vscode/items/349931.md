# Issue #349931 — Manage remote environments: Offer restart distribution in more menu

[https://github.com/microsoft/vscode/issues/349931](https://github.com/microsoft/vscode/issues/349931)

## Summary

Keep open: Restart Distribution remains absent from More Actions, while the Available status deliberately reflects connectability rather than whether WSL is running. This team-authored feedback needs a UX decision, not a judgment close.

## Change summary

Expose Restart Distribution directly in the environment menu and clarify the status shown for stopped WSL distributions.
