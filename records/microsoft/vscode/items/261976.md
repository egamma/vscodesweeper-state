# Issue #261976 — Bot should not close issues without human input

[https://github.com/microsoft/vscode/issues/261976](https://github.com/microsoft/vscode/issues/261976)

## Summary

Keep open for an engineering-process decision about human oversight of automated closures. Maintainers acknowledged mistaken closures and proposed better handling of reporter replies, but that does not resolve the broader request to require human input.

## Change summary

Require human input before bots close issues rather than relying on automated information requests and inactivity deadlines.

## Best solution

Have the engineering owners explicitly decide which closure paths require human review and distinguish unanswered information requests from reports with substantive replies. Record that decision alongside the documented triage policy and the automation improvements already discussed.
