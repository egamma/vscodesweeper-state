# Issue #348902 — MCP authentication button does nothing in Copilot side chat, only works in main chat

[https://github.com/microsoft/vscode/issues/348902](https://github.com/microsoft/vscode/issues/348902)

## Summary

Keep open: current source confirms that side-chat authentication can fail because the customization service resolves session resources but not their child-chat resources. The newer matching report does not meet the stronger canonical-ownership bar for this re-reviewed issue.

## Change summary

Make MCP authentication accessible from Agents-window side chats instead of requiring authentication through the main chat.

## Best solution
