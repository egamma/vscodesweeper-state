# Issue #146556 — SCM - Ability to change background of rows that are new or changed

[https://github.com/microsoft/vscode/issues/146556](https://github.com/microsoft/vscode/issues/146556)

## Summary

Keep this accepted SCM request open: current diff decorations do not provide backgrounds across added or modified editor lines. It has 24 community upvotes, and no verified older issue was found that owns the same requested behavior.

## Change summary

Allow added and modified lines in the normal editor to have change-type-specific full-line background highlighting.

## Best solution

Provide optional, theme-aware full-line highlighting through SCM quick-diff decorations while preserving the current default appearance. Agree on the user-facing enablement and color-customization contract before implementation.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts`, `src/vs/workbench/contrib/scm/browser/quickDiff.contribution.ts`, `src/vs/workbench/contrib/scm/common/quickDiff.ts`, `src/vs/workbench/contrib/scm/browser/media/dirtydiffDecorator.css`
- **Validation:** After implementation, open a Git-tracked file, add one line and modify another, and enable the agreed highlighting mechanism. Verify distinct full-line backgrounds in the normal editor, removal when changes are reverted, unchanged appearance when disabled, and readable selection/text in light, dark, and high-contrast themes. Add targeted decoration-option coverage for the agreed enablement states.
- **Behavior:**

  > Users want to identify added and modified lines through backgrounds across the editor rows, rather than only narrow gutter indicators. The feature should distinguish the two change types and follow the live SCM diff as edits are added or reverted. Existing editor appearance should remain unchanged unless users opt into the capability. Acceptance must check the normal editor, not only the separate diff editor, and preserve text and selection readability.
- **Trace:**

  > QuickDiffDecorator in src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts converts QuickDiffModel changes into added, modified, and deleted decorations. createDecoration currently targets the gutter, overview ruler, and minimap; its isWholeLine flag does not supply a content-background style. Configuration is registered in quickDiff.contribution.ts, colors in common/quickDiff.ts, and gutter styles in media/dirtydiffDecorator.css. These source reads establish the missing capability without executing the checkout. Preserve existing gutter patterns, navigation, provider visibility, and deletion markers; the requested scope is backgrounds for added and modified lines. The related https://github.com/microsoft/vscode/issues/146442 addresses gutter striping, not this behavior. Uncertainty starts at the public enablement and color contract, not the location of the rendering path.
- **Open decisions:**
  - Should full-line highlighting be enabled through an explicit SCM setting or solely by configuring optional theme color tokens?
  - Should full-line backgrounds have independently customizable added/modified colors, or derive translucent colors from the existing gutter colors?

## Evidence

- **Existing capability does not cover the request:** src/vs/workbench/contrib/scm/browser/quickDiff.contribution.ts registers scm.diffDecorations with all, gutter, overview, minimap, and none. Its other decoration settings control gutter width, visibility, click behavior, and patterns; none enables editor-line background highlighting.
- **Current decoration path:** In src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts, QuickDiffDecorator.createDecoration assigns linesDecorationsClassName, overviewRuler, and minimap options, but no content-background class. Added and modified options use isWholeLine: true, which does not itself paint a background across the editor content.
- **Theme boundary:** src/vs/workbench/contrib/scm/common/quickDiff.ts defines editorGutter.addedBackground and editorGutter.modifiedBackground for gutter indicators. src/vs/workbench/contrib/scm/browser/media/dirtydiffDecorator.css applies these colors to gutter borders, patterns, and pseudo-elements, not full editor rows.
