# Issue #284773 — Split (duplicate) Explorer View

[https://github.com/microsoft/vscode/issues/284773](https://github.com/microsoft/vscode/issues/284773)

## Summary

This duplicates a previously declined request for simultaneous Explorer views. Maintainer precedent indicates that multiple Explorer panels are outside the planned core experience.

## Change summary

Allow the file Explorer to be split into multiple simultaneous views for navigating and moving files between folders.

## Best solution

Keep one movable Explorer view and use multi-root workspaces for independently organized folder roots rather than adding duplicated Explorer surface to the workbench.

## Vision fit

- **Fit:** rejected
- **Reason:** Duplicating a core workbench view for a specialized workflow conflicts with the lean, uniform default UI guardrails.
- **Evidence:** Values and guardrails: “Out of the box, VS Code is a text editor: lightweight and fast” and “Simple, uniform UI and UI interactions.”
