# Issue #162503 — Virtual F13-F19 keys is not recognised

[https://github.com/microsoft/vscode/issues/162503](https://github.com/microsoft/vscode/issues/162503)

## Summary

Correctly triaged as upstream — Chromium does not propagate Windows registry scancode remappings (F13–F19) through its keyboard event API, confirmed by the reporter's own test that vscode.dev in Edge also fails. No VS Code code change can address this.

## Change summary

Windows registry-remapped F13–F19 keys are not recognized by VS Code because Chromium's keyboard events do not reflect the remapping.

## Best solution

This remains a Chromium bug. The fix must come from Chromium propagating registry scancode remaps into `KeyboardEvent.keyCode` / `KeyboardEvent.key`. If a Chromium bug is filed, linking it here would help track resolution. VS Code has no actionable code change.
