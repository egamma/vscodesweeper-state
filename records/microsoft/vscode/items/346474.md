# Issue #346474 — Migrate to GPUI

[https://github.com/microsoft/vscode/issues/346474](https://github.com/microsoft/vscode/issues/346474)

## Summary

Keep open for an explicit architecture decision: current VS Code does not provide the requested GPUI backend, and no verified duplicate or maintainer decision establishes grounds to close it. The resource-use motivation does not by itself establish that replacing Electron would resolve the reported costs.

## Change summary

Replace VS Code's Electron-based desktop UI with GPUI to reduce memory consumption and installation footprint.

## Best solution

Evaluate the migration against measured resource savings, desktop/web compatibility, accessibility, and extension compatibility before accepting a rewrite. Distinguish renderer overhead from language-server memory and remote installation storage so any accepted work targets the actual costs.
