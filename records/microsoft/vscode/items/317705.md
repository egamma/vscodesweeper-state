# Issue #317705 — Trim the existing Copilot Chat session

[https://github.com/microsoft/vscode/issues/317705](https://github.com/microsoft/vscode/issues/317705)

## Summary

Valid feature request to let users trim an existing chat session (discarding old messages while keeping recent context). The underlying performance problem with long conversations is tracked separately by virtualization requests, but this asks for a distinct user-facing action — no existing issue fully owns the 'trim session' capability, so it stays open.

## Change summary

Allow users to trim an existing Copilot Chat session by discarding older messages while preserving recent context and project familiarity.

## Best solution

Implement a user-facing 'Trim Session' or 'Fork from here' action in the chat UI that creates a new session seeded with a summarized or truncated subset of the current conversation. This is distinct from the rendering virtualization tracked in https://github.com/microsoft/vscode/issues/297349 (which addresses DOM performance) and from the existing /compact command (which compresses the LLM context window). The feature belongs in the chat contribution area (`src/vs/workbench/contrib/chat/`).
