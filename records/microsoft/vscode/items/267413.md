# Issue #267413 — When using user defined tool sets shows wrong count

[https://github.com/microsoft/vscode/issues/267413](https://github.com/microsoft/vscode/issues/267413)

## Summary

The maintainer-confirmed duplicate rows are intentional, but the issue still identifies a distinct counting and interaction defect: aliases for one underlying tool are counted separately and do not mirror state while the picker remains open. Multiple commenters confirmed the observable behavior, and no older canonical issue with the same symptom is identified.

## Change summary

User-defined tool sets duplicate underlying tools in the picker count and expose temporarily inconsistent checkbox states for aliases of the same tool.

## Best solution

Preserve the intentional expanded rows for built-in tools and user-defined tool sets, while deriving the displayed selected count and threshold behavior from unique underlying tool IDs and synchronizing alias checkbox state immediately.
