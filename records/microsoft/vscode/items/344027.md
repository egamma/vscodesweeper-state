# Issue #344027 — Plugin discovery ignores COPILOT_HOME, causing install activation to fail

[https://github.com/microsoft/vscode/issues/344027](https://github.com/microsoft/vscode/issues/344027)

## Summary

Keep open: current main still reads and watches the default Copilot config and rejects plugin cache paths outside the default installed root, independently of COPILOT_HOME. The report provides sufficient reproduction details, and the path mismatch is confirmed in source.

## Change summary

Plugin discovery should honor COPILOT_HOME so successful installations are discovered and can activate.

## Best solution

Use the effective Copilot home consistently for installed-plugin inventory, watching, and cache-root validation in the workbench discovery path. Preserve default-home behavior, cache containment checks, and existing installation enablement semantics.
