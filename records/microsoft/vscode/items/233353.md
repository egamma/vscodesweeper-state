# Issue #233353 — Git output containing .../ file links should be linkified

[https://github.com/microsoft/vscode/issues/233353](https://github.com/microsoft/vscode/issues/233353)

## Summary

Valid feature request from a terminal team member: Git's truncated `…/` path prefixes in output aren't linkified. Not yet implemented on main — the terminal link detectors have no handling for ellipsis-prefixed paths. Keeping open per team-authored item rules and Backlog milestone.

## Change summary

Terminal should detect and linkify file paths in Git output that use `…/` or `.../` truncation prefixes.

## Best solution

Extend the terminal local link detector (likely `terminalLocalLinkDetector.ts` and/or `terminalLinkResolver.ts`) to recognize `…/`-prefixed paths, resolve them against the workspace, and produce clickable links. The resolver would need to search for matching suffixes under the cwd or workspace folders.
