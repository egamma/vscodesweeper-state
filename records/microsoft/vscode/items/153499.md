# Issue #153499 — Git - git.terminalGitEditor should return focus to the terminal after being closed

[https://github.com/microsoft/vscode/issues/153499](https://github.com/microsoft/vscode/issues/153499)

## Summary

Keep open: the built-in Git editor still completes its terminal request without restoring terminal focus. The existing code --wait focus behavior uses a separate path and does not cover git.terminalGitEditor.

## Change summary

Return keyboard focus to the integrated terminal after closing a commit-message editor opened through git.terminalGitEditor.

## Best solution

Give terminal-initiated Git editing the same keyboard-continuation experience as code --wait, while preserving SCM-initiated commit behavior. Investigate the newer general code --wait complaint separately rather than assuming both paths share a defect.
