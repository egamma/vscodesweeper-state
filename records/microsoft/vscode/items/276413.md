# Issue #276413 — Git - changes tool should avoid context blowout

[https://github.com/microsoft/vscode/issues/276413](https://github.com/microsoft/vscode/issues/276413)

## Summary

Team-authored, On Deck feature request to make the `#changes` tool progressively disclose git diffs instead of dumping all context at once. The author re-confirmed in April 2026 that large changesets still blow out context (~80k tokens). Partial mitigation exists (tool result compression, removing references) but the core ask — progressive disclosure or file-based context storage — remains unimplemented.

## Change summary

The `#changes` chat tool dumps the entire git diff into the conversation context at once, causing token blowout on large changesets instead of progressively disclosing changes.

## Best solution

Implement progressive disclosure in the changes tool (likely `extensions/copilot/src/extension/prompts/node/git/gitChanges.tsx`): for large changesets, return a file-list summary first and let the agent drill into individual file diffs on demand — similar to how the agent naturally uses `git diff` via the terminal. The existing `IToolResultCompressor` infrastructure could also be extended with a git-diff-aware filter, but the core fix is upstream in the tool's own output strategy.
