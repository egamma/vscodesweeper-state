# Issue #335153 — Copilot diff incorrect - shows old changes of mine as its own changes

[https://github.com/microsoft/vscode/issues/335153](https://github.com/microsoft/vscode/issues/335153)

## Change summary

Resuming an older Copilot conversation can show previously committed user changes as newly generated agent edits.

## Best solution

Ensure resumed-chat review distinguishes subsequent user changes from agent edits while preserving legitimate session history and pending edits. Diagnose restoration and edit attribution together before changing baseline behavior.
