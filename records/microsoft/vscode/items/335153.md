# Issue #335153 — Copilot diff incorrect - shows old changes of mine as its own changes

[https://github.com/microsoft/vscode/issues/335153](https://github.com/microsoft/vscode/issues/335153)

## Summary

A second user independently confirmed this on a newer build (1.137.0), describing the same symptom (agent review diff showing stale/old changes as new, sometimes marking whole files green) as an intermittent but frequent problem — this is a real defect in the chat editing review/diff baseline, not a one-off fluke, so it should be routed to the chat editing area rather than closed.

## Change summary

When resuming an old chat session and asking Copilot for a new edit, the Keep/Undo review diff sometimes uses a stale baseline snapshot (from the session's earlier state) instead of the actual current file content, showing old already-committed changes as if newly made by the agent.

## Best solution

Investigate how the chat editing session's working-set/document snapshot baseline is restored when reopening an old session (src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingSessionStorage.ts and chatEditingSession.ts) — likely the stored snapshot from session restore isn't reconciled against the file's actual on-disk content before diffing new edits.
