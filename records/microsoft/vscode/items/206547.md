# Issue #206547 — Improve localization experience of WebViews

[https://github.com/microsoft/vscode/issues/206547](https://github.com/microsoft/vscode/issues/206547)

## Summary

A real localization API gap remains for ordinary extension webviews. The existing workaround is valid, but a maintainer explicitly agreed that localization should ideally be initialized automatically.

## Change summary

Automatically make an extension's localization bundle available to its webview application.

## Best solution

Provide a supported Webview API or bootstrap contract that initializes webview localization from the owning extension's language and bundle, without requiring each extension to pass `vscode.l10n.uri` through generated HTML and CSP configuration.

- **Reason:** Reducing bespoke localization plumbing improves extension API usability while keeping specialized webview applications in extensions.
