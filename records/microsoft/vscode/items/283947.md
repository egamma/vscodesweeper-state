# Issue #283947 — Include extension info in chat session export

[https://github.com/microsoft/vscode/issues/283947](https://github.com/microsoft/vscode/issues/283947)

## Summary

Keep open: current chat exports preserve conversation content and attachments but do not capture the extension environment requested here. The related evaluation plan explicitly calls for an extensions.json artifact; the older available-tools request does not cover extension-provided diagnostics or extension identity.

## Change summary

Include information about extensions contributing tools or diagnostic context when exporting a chat session.

## Best solution

Provide extension-environment metadata alongside exported sessions so evaluation consumers can identify the extensions relevant to the conversation. First settle which extensions and metadata belong in that artifact, and whether it describes the session-time environment or the environment at export.
