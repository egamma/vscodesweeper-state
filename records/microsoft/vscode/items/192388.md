# Issue #192388 — Find cancels the selection

[https://github.com/microsoft/vscode/issues/192388](https://github.com/microsoft/vscode/issues/192388)

## Summary

The default cursor movement is intentional and configurable; disabling `editor.find.cursorMoveOnType` preserves the original selection while typing a query.

## Change summary

Preserve the editor selection while entering a Find query so it can subsequently become the Find in Selection scope.

## Best solution

Keep the configurable behavior: users who need the selection preserved should set `editor.find.cursorMoveOnType` to `false`; multiline-selection workflows can additionally use `editor.find.autoFindInSelection: "multiline"`.
