- **Exact failing source path:** src/vs/editor/contrib/find/browser/findWidget.ts:1027-1032 propagates typed search text with moveCursor=true. findModel.ts:234-235 then navigates to a match when cursorMoveOnType is enabled, and _setCurrentFindMatch at lines 255-264 calls editor.setSelection(match). The Find in Selection button at findWidget.ts:1112-1127 subsequently reads the editor's current selections, which now contain the match rather than the originally selected block.
