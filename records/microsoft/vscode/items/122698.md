# Issue #122698 — Make a single Windows installer

[https://github.com/microsoft/vscode/issues/122698](https://github.com/microsoft/vscode/issues/122698)

## Summary

Legitimate feature request to unify Windows installers. A community PR (#238042) attempted it but was closed without merge in Dec 2025 due to AppId migration complexity. The request remains valid but unresolved; keeping open for the community process.

## Change summary

Combine the separate Windows system and user installers into a single installer that asks the user which mode to use.

## Best solution

The Inno Setup `PrivilegesRequiredOverridesAllowed=dialog` approach explored in PR #238042 is technically viable but requires solving the AppId migration problem (different AppIds for system vs user installs). A maintainer decision is needed on whether the migration cost is worth the UX improvement.
