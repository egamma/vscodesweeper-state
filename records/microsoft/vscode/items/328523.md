# Issue #328523 — Agent plugin marketplace: private repo marketplaces never refresh (new plugins don't show up)

[https://github.com/microsoft/vscode/issues/328523](https://github.com/microsoft/vscode/issues/328523)

## Summary

Confirmed on current main: existing cloned marketplaces are returned without fetching or pulling, permanently preserving stale private-marketplace metadata. This team-authored bug should remain open for a cache-refresh fix.

## Change summary

Private repository marketplaces never discover plugins added after their initial clone.

## Best solution

Give cloned marketplace repositories an eight-hour freshness policy equivalent to the raw GitHub cache, refreshing an expired non-local clone before reading its marketplace metadata while preserving offline/error behavior.
