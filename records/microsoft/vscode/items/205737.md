# Issue #205737 — Adopt Editor Hover for "Revert Change" action

[https://github.com/microsoft/vscode/issues/205737](https://github.com/microsoft/vscode/issues/205737)

## Summary

Keep open: the legacy diff revert arrow still uses a native tooltip rather than the editor glyph hover. The newer gutter menu avoids that surface by default, but does not complete the requested adoption for configurations that retain the arrow.

## Change summary

Integrate the diff editor's Revert Change tooltip with the editor hover so it does not compete with breakpoint hover content.

## Best solution

Use the editor's coordinated glyph-hover presentation for the retained revert-arrow surface while preserving its existing revert actions and breakpoint behavior. Verify the reported overlap with the legacy arrows enabled before choosing the integration.
