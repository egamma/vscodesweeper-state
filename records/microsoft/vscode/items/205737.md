# Issue #205737 — Adopt Editor Hover for "Revert Change" action

[https://github.com/microsoft/vscode/issues/205737](https://github.com/microsoft/vscode/issues/205737)

## Summary

Keep open: the legacy diff-margin revert action still uses a native tooltip rather than the editor hover. The newer gutter avoids that surface in its enabled configuration, but does not complete the requested adoption; no qualifying fix or canonical duplicate was established.

## Change summary

Use the editor glyph-margin hover for Revert Change so its tooltip does not appear independently alongside a breakpoint hover.

## Best solution

Give the remaining glyph-margin revert actions coordinated editor-hover behavior while preserving their click actions and breakpoint interactions. First verify the reported overlap with the legacy arrows enabled, since the newer gutter changes which configurations expose this surface.
