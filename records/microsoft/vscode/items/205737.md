# Issue #205737 — Adopt Editor Hover for "Revert Change" action

[https://github.com/microsoft/vscode/issues/205737](https://github.com/microsoft/vscode/issues/205737)

## Summary

Team-authored polish request to adopt the editor's glyph margin hover system for the dirty diff 'Revert Change' action, fixing a dual-hover conflict with breakpoints. Not yet implemented on main — the quick diff decorations in quickDiffWidget.ts still use their own hover mechanism without glyphMarginHoverMessage.

## Change summary

The dirty diff 'Revert Change' gutter decoration should use the editor's glyph margin hover system instead of a custom hover, to avoid showing two overlapping hovers when breakpoints are also present.

## Best solution

Refactor the dirty diff decoration in `src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts` and `quickDiffWidget.ts` to set `glyphMarginHoverMessage` on the decoration options (as breakpoints do in `breakpointEditorContribution.ts`), so the editor hover system manages the revert action tooltip and prevents dual-hover conflicts.
