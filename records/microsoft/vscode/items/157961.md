# Issue #157961 — Allow to return an exit code from `--wait` invocations

[https://github.com/microsoft/vscode/issues/157961](https://github.com/microsoft/vscode/issues/157961)

## Summary

The requested capability remains absent on current main: `--wait` only detects closure and cannot communicate whether a merge succeeded. This is the canonical, explicitly retained Backlog request and should remain open.

## Change summary

Allow `code --wait` to return a nonzero exit code when a merge editor closes with unresolved or discarded conflicts.

## Best solution

Extend the CLI wait protocol to carry a completion status from the merge editor to the waiting process, returning success only for a completed merge while preserving existing generic `--wait` behavior.
