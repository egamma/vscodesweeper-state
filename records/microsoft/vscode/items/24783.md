# Issue #24783 — vscode reads AltGr key as cursor-left move through X11 connections

[https://github.com/microsoft/vscode/issues/24783](https://github.com/microsoft/vscode/issues/24783)

## Summary

The bug remains active across current remote Linux desktop scenarios, with repeated independent confirmations through July 2026. The `keyboard.dispatch: keyCode` workaround avoids the spurious cursor movement but breaks legitimate shortcuts such as Ctrl+/ and therefore does not resolve the issue.

## Change summary

AltGr delivered through X11 or remote desktop is interpreted both as character composition and a cursor-left command.

## Best solution

Correct Linux keyboard-event dispatch for AltGr under forwarded X11, RDP, XRDP, and WSLg without requiring users to switch globally to keyCode dispatch; preserve layout-dependent shortcuts such as Ctrl+/.
