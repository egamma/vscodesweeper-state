# Issue #319286 — [folding] Format large file unfold all code

[https://github.com/microsoft/vscode/issues/319286](https://github.com/microsoft/vscode/issues/319286)

## Summary

This is the known, intentional fallback for formatting edits larger than 100,000 characters: VS Code skips the expensive minimal-diff calculation, and the resulting full-document replacement cannot reliably preserve folding decorations.

## Change summary

Formatting a sufficiently large JavaScript or Python file expands folds and moves the cursor because the format operation becomes a full-document replacement.

## Best solution

Keep the existing performance safeguard and treat fold loss for oversized formatting edits as an accepted limitation unless a future implementation can preserve folding state without performing the expensive large-text diff.
