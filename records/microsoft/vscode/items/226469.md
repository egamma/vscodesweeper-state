# Issue #226469 — Behavioral change in quick pick with selected items

[https://github.com/microsoft/vscode/issues/226469](https://github.com/microsoft/vscode/issues/226469)

## Summary

The reported selection-reset path remains in current source: refreshing the same multi-select items rebuilds unchecked elements and emits an empty selection. Keep this team-authored regression open with the quick-pick owner; replacing the Profiles UI did not resolve the shared component behavior.

## Change summary

Reassigning quick-pick items to refresh their descriptions unexpectedly clears checked items and fires onDidChangeSelection with an empty array.

## Best solution

Refreshing descriptions on existing multi-select items should preserve their checked state without emitting a spurious empty selection. Resolve this in the quick-input component while retaining correct selection clearing when items are genuinely replaced or removed.
