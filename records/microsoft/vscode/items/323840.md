The requested global theme-variable setting remains absent on current main, and no older canonical issue owns the same request. With no community or maintainer traction after 81 days, it should remain open under discussion rather than receive a judgment close.

## Change summary

Expose Mermaid `themeVariables` as user configuration for customizing diagrams rendered by the built-in Mermaid Markdown extension.

## Best solution

Decide whether arbitrary global Mermaid styling belongs in VS Code settings or should remain diagram-authored; if accepted, define a validated configuration contract and apply it consistently across Markdown previews, notebooks, chat output, and standalone Mermaid previews.
