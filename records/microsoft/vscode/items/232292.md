# Issue #232292 — Extension packs with only 1 walkthrough should open on that walkthrough registration

[https://github.com/microsoft/vscode/issues/232292](https://github.com/microsoft/vscode/issues/232292)

## Summary

Still unfixed on main: the getting-started service unconditionally skips walkthroughs for all pack-installed extensions via the EXTENSION_INSTALL_DEP_PACK_CONTEXT flag, with no special case for packs containing exactly one walkthrough.

## Change summary

Extension packs with a single walkthrough should open that walkthrough on install instead of suppressing it.

## Best solution

In `gettingStartedService.ts` around line 248, add logic to check whether the installing extension pack contributes exactly one walkthrough, and if so, allow it to be added to `sessionInstalledExtensions` instead of unconditionally skipping.
