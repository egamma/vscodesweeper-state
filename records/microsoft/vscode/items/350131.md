# Issue #350131 — Chat attachment picker does not distinguish selections from the same file

[https://github.com/microsoft/vscode/issues/350131](https://github.com/microsoft/vscode/issues/350131)

## Summary

The picker ambiguity is confirmed in current source: distinct selections retain separate identities but receive identical filename-only completion labels. Keep this open; the verified related reports concern different observable problems.

## Change summary

Distinguish attached selections from the same file by displaying their line ranges in chat attachment completions.

## Best solution

Make each selection identifiable in the attached-context completion list while preserving its existing attachment identity and reference semantics. Treat the model's reported inability to see exact lines as a separate, unconfirmed concern rather than assuming a display change resolves it.
