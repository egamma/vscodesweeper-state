# Issue #350131 — Chat attachment picker does not distinguish selections from the same file

[https://github.com/microsoft/vscode/issues/350131](https://github.com/microsoft/vscode/issues/350131)

## Summary

The picker ambiguity is confirmed in current source: separately stored selections retain their ranges but receive identical filename-only completion labels. Related reports concern different surfaces or attachment loss and do not subsume this issue.

## Change summary

Distinguish attachments containing different selections from the same file in chat's # completion picker.

## Best solution

Show each selection's line range in its attached-context completion presentation while preserving attachment identity and resolution. Investigate the model's reported inability to see exact lines separately; identical picker labels do not establish lost context.
