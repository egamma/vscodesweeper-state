# Issue #350131 — Chat attachment picker does not distinguish selections from the same file

[https://github.com/microsoft/vscode/issues/350131](https://github.com/microsoft/vscode/issues/350131)

## Summary

Keep open: current source gives separately stored selections identical completion labels. This is a bounded identification improvement; neither verified related issue owns this same picker symptom.

## Change summary

Visibly distinguish attached selections from the same file in the chat input’s # completion list.

## Best solution

Show each selection’s line range alongside its filename in attached-context completions while preserving attachment identity and reference semantics. Investigate the model’s reported inability to see exact lines separately rather than assuming label disambiguation fixes it.
