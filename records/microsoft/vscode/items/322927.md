# Issue #322927 — Study participants wanted to see changes that were made per chat/session

[https://github.com/microsoft/vscode/issues/322927](https://github.com/microsoft/vscode/issues/322927)

## Summary

Team-authored UX research finding requesting per-chat/session scoping of changes. Active development is underway (last-turn changes pill scoped per chat, changes view polish), but the broader exploration — inline turn summaries, full changes-view filtering by stream — remains open work with no commit referencing this issue.

## Change summary

Users working with multiple chats in the Agents window want to see which changes were made by each chat/session, not just a workspace-wide diff.

## Best solution

Continue the exploration in `src/vs/sessions/contrib/changes/` and the session chat input toolbar: the last-turn changes pill is now per-chat (commit 9053cb21fbf), but the broader asks — a filterable Changes view by stream, inline turn-level change summaries, and a toggle between scoped and workspace-wide views — still need design and prototyping. This issue should stay open as the tracking item for that work.
