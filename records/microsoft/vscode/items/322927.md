# Issue #322927 — Study participants wanted to see changes that were made per chat/session

[https://github.com/microsoft/vscode/issues/322927](https://github.com/microsoft/vscode/issues/322927)

## Summary

Current main provides inline turn summaries and active-chat changeset selection, but these do not establish complete cumulative attribution across parallel chats sharing a workspace. Keep this team-authored UX exploration open for its owner to assess the remaining scope and attribution requirements.

## Change summary

Make agent edits attributable and reviewable by chat or session instead of requiring users to inspect undifferentiated workspace changes.

## Best solution

Evaluate the existing turn summaries and Changes picker against the study's parallel-chat tasks, particularly cumulative edits from one chat in a shared workspace. Establish whether additional chat-scoped review is needed and how manual or externally generated edits should be represented, while preserving the single-stream experience.
