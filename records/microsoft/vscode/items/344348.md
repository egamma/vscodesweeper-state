# Issue #344348 — "Duplicate" message is probably a bit extranous

[https://github.com/microsoft/vscode/issues/344348](https://github.com/microsoft/vscode/issues/344348)

## Summary

Keep open for an Automations UX decision: current main still displays the persistent duplication notice when editing a cloud automation. The team-authored feedback proposes quieter guidance or different edit semantics; neither has been established as completed.

## Change summary

Reduce redundant duplication guidance in the cloud automation editor, or consider supporting currently immutable edits through safe replacement.

## Best solution

Make routine cloud automation edits quieter while keeping immutable settings understandable. Decide whether this is presentation-only polish or an explicit replacement workflow before introducing any delete-and-recreate behavior.
