# Issue #308575 — Session memory files not automatically listed in user prompt (sessionMemory) after creation

[https://github.com/microsoft/vscode/issues/308575](https://github.com/microsoft/vscode/issues/308575)

## Summary

Still reproduces on main: MemoryContextPrompt is gated by `isNewChat` (history.length === 0) so session memory files created mid-conversation are never listed in subsequent turns. No fix commit references this issue.

## Change summary

After creating a session memory file via the memory tool, the <sessionMemory> section in subsequent turns still shows 'empty' because MemoryContextPrompt is only rendered on the first turn.

## Best solution

Remove or relax the `isNewChat` gate on MemoryContextPrompt in GlobalAgentContext so that session memory file listings are refreshed on every turn (or at least after a memory-tool write). The fix lives in `extensions/copilot/src/extension/prompts/node/agent/agentPrompt.tsx` around line 359.
