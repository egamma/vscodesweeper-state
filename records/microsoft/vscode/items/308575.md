[https://github.com/microsoft/vscode/issues/308575](https://github.com/microsoft/vscode/issues/308575)

Keep open: current source still freezes memory context at the first turn, so files created later remain absent from the automatic listing. This team-authored report identifies a concrete contract violation, and no verified canonical or completed fix was found.
