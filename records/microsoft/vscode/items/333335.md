# Issue #333335 — `createMultiFileDiffEditor` is exported in monaco-editor but the returned widget has no methods

[https://github.com/microsoft/vscode/issues/333335](https://github.com/microsoft/vscode/issues/333335)

## Summary

Confirmed real bug: the monaco.editor build's tree-shaking strips MultiDiffEditorWidget's methods because build/monaco/monaco.usage.recipe has no MultiDiff entries, and createMultiFileDiffEditor never calls registerEditorContainer. An open PR (#333336) already targets this exact fix, so the right move is reviewing/landing that PR rather than closing the issue.

## Change summary

monaco.editor's createMultiFileDiffEditor returns a MultiDiffEditorWidget whose public methods (createViewModel, setViewModel, layout) are stripped by the usage-recipe tree-shaker, and the widget never gets themed.

## Best solution

Land https://github.com/microsoft/vscode/pull/333336, which adds MultiDiffEditorWidget/MultiDiffEditorViewModel members to build/monaco/monaco.usage.recipe and adds the missing themeService.registerEditorContainer() call in createMultiFileDiffEditor (src/vs/editor/standalone/browser/standaloneEditor.ts:103).
