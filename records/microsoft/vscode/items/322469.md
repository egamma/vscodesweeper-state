# Issue #322469 — Chat view cannot correctly render inline code containing a command with arguments

[https://github.com/microsoft/vscode/issues/322469](https://github.com/microsoft/vscode/issues/322469)

## Summary

Confirmed bug on current main: the linkifier splits inline code on whitespace and runs file-path linkifiers on each accumulated segment, causing path-like substrings to be consumed and partially lost in the rendered output. An open PR (#322473) targets this but hasn't merged.

## Change summary

Inline code containing file paths with arguments loses content because the linkifier matches and replaces path substrings inside backtick-delimited text.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/322473, which treats multi-token inline code content atomically during linkification to prevent partial path matching from consuming content.
