# Issue #18239 — Multiselect via ctrl+d case insensitivity makes it useless

[https://github.com/microsoft/vscode/issues/18239](https://github.com/microsoft/vscode/issues/18239)

## Summary

A meaningful gap remains on current main: Ctrl+D still inherits Find's case-sensitivity when starting from selected text. With 108 upvotes and a Backlog milestone, this established feature request should remain open.

## Change summary

Decouple Ctrl+D case matching from the Find widget so multicursor selection can consistently use case-sensitive matching.

## Best solution

Add a dedicated multicursor case-matching preference and consume it in `MultiCursorSession.create`, while preserving the existing case-sensitive behavior for an initially collapsed selection.
