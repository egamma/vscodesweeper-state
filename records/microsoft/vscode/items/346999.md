# Issue #346999 — Agents window: setting to start /btw side chats in the background

[https://github.com/microsoft/vscode/issues/346999](https://github.com/microsoft/vscode/issues/346999)

## Summary

Keep open: starting /btw without revealing its side chat remains distinct from the newer side-panel presentation experiment. A maintainer explicitly welcomed chat.btw.reveal, and no issue-referencing fix or competing linked PR was found.

## Change summary

Allow /btw side chats to run without opening a view or taking focus, while remaining discoverable afterward.
