# Issue #346999 — Agents window: setting to start /btw side chats in the background

[https://github.com/microsoft/vscode/issues/346999](https://github.com/microsoft/vscode/issues/346999)

## Summary

Keep open as a feature request: current side-chat orchestration still reveals and splits the chat unless navigation intervenes. No existing setting covers deliberately starting /btw invisibly.

## Change summary

Allow /btw side chats to start in the background without opening a split or moving focus.

## Best solution

Provide an opt-in background-start preference for /btw in the Agents window, preserving foreground behavior by default and making completed side chats discoverable without interrupting the source conversation.
