# Issue #335403 — Copilot Chat shows "Sign in to use GitHub Copilot" modal when chat activates before the token source is ready

[https://github.com/microsoft/vscode/issues/335403](https://github.com/microsoft/vscode/issues/335403)

## Summary

Reporter gave a credible, detailed reproduction (two startups, two versions, timestamped logs showing the sign-in modal firing while entitlement is still 'Unknown' and never auto-dismissing once the token arrives). A maintainer already asked for confirmation on Insiders/next stable against a recently merged auth fix (#336344), and nobody has confirmed the result for this specific report yet — keep it in needs-info per that open ask.

## Change summary

The 'Sign in to use GitHub Copilot' modal appears spontaneously during normal startup while entitlement/token resolution is still in flight, and is never dismissed once the token arrives.

## Best solution

Once confirmed still reproducing, the fix likely belongs in chatSetupRunner.ts's doRun/showDialog path: today the only guard against a stale 'Unknown' entitlement (whenChatExtensionActivated) is scoped to the just-granted-workspace-trust case, not the general startup race, and the existing `autoDismissOnSignIn` option is defined but not wired to whichever call site auto-triggers the dialog on normal activation.
