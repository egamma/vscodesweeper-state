# Issue #309519 — Better UI/UX to get back to agent debug log menu

[https://github.com/microsoft/vscode/issues/309519](https://github.com/microsoft/vscode/issues/309519)

## Summary

The session overview still relies on the Agent Debug Logs breadcrumb for in-view navigation back to the session list. A command also opens that list, but it does not address the requested discoverability improvement; keep this team-authored Backlog item open for a navigation design decision.

## Change summary

Make returning from an agent debug session to the session list more discoverable than the existing root breadcrumb.

## Best solution

Provide a clear, consistent return-to-session-list affordance in the agent debug editor without cluttering its session views. Decide whether the improvement belongs alongside the breadcrumb or in a shared navigation control, retaining existing breadcrumb and command behavior.
