# Issue #336546 — Thinking Phrases are extremely unprofessional and should not be enabled by default!

[https://github.com/microsoft/vscode/issues/336546](https://github.com/microsoft/vscode/issues/336546)

## Summary

The occasional whimsical 'working' phrase (like 'Bribing the hamster') is an intentional, low-frequency easter egg (~1 in 50 picks) in chatThinkingContentPart.ts, and VS Code already ships a setting to fully replace or remove these phrases, so this is as-designed rather than a bug.

## Change summary

Reporter wants the occasional playful 'thinking/working' loading phrases (e.g. 'Bribing the hamster') disabled by default, calling them unprofessional.

## Best solution

Point the reporter at `chat.agent.thinking.phrases` — setting `{"mode": "replace", "phrases": ["Thinking"]}` fully replaces the default phrase pool (including the fun ones) so they never appear; no code change needed.
