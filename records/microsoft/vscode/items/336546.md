# Issue #336546 — Thinking Phrases are extremely unprofessional and should not be enabled by default!

[https://github.com/microsoft/vscode/issues/336546](https://github.com/microsoft/vscode/issues/336546)

## Summary

The phrase is intentional flavor text rather than model reasoning, but the request to make playful phrases opt-in remains valid and is not covered by the existing customization setting. Keep this open as a feature request for the chat UX owners to decide the professional default.

## Change summary

Use professional agent progress phrases by default and make whimsical loading messages opt-in.

## Best solution

Default agent progress indicators to descriptive, professional phrases while retaining `chat.agent.thinking.phrases` for users who want custom or playful text. The UI should also continue distinguishing these client-side loading messages from actual model reasoning.

## Evidence

- **existing workaround:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts registers `chat.agent.thinking.phrases`; using `mode: "replace"` with professional phrases suppresses the fun defaults, as covered by src/vs/workbench/contrib/chat/test/browser/widget/chatContentParts/chatThinkingContentPart.test.ts.
- **maintainer precedent:** A maintainer previously explained that these messages can be removed or controlled through `chat.agent.thinking.phrases`: https://github.com/microsoft/vscode/issues/317024#issuecomment-4493800419. That workaround does not resolve this issue's request to change the default.
- **remaining gap:** Current main still defaults the setting to `mode: "append"` with no custom phrases, so the whimsical message pool remains enabled without user opt-in.
