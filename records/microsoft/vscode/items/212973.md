# Issue #212973 — 'Folders' menu item is disabled in the explorer

[https://github.com/microsoft/vscode/issues/212973](https://github.com/microsoft/vscode/issues/212973)

## Summary

The defect remains on current main: the Folders view descriptor explicitly disables visibility toggling, which leaves its Explorer menu item disabled. A maintainer accepted allowing this behavior, and this team-authored, bug-labeled issue should remain open for that bounded change.

## Change summary

Allow users to toggle the Folders view from the Explorer views menu instead of presenting a permanently disabled item.

## Best solution

Make the Folders view toggleable through the standard view visibility mechanism while preserving its existing move-view behavior and the rule that a container cannot hide its sole visible view.
