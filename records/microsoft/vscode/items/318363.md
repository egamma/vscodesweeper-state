## Summary

A real CLI capability gap remains, and the issue is still within the Backlog Candidates voting period. Keep it open under discussion rather than preempting the community process.

## Change summary

Allow the VS Code CLI and coding agents to format files through installed extension-provided document formatters.

## Best solution

Add a supported headless CLI operation that loads the applicable installed formatter extension, selects the configured document formatter, applies its edits, and reports failures clearly. The work belongs in the CLI/workbench integration while reusing the existing formatting-provider pipeline.
