# Issue #135865 — Git - large change improvements

[https://github.com/microsoft/vscode/issues/135865](https://github.com/microsoft/vscode/issues/135865)

## Summary

Keep open: telemetry is implemented, but the limit warning still does not guide users to increase git.statusLimit. This team-authored, accepted Backlog request retains a concrete unfinished requirement; related reports do not own the same work.

## Change summary

Improve the experience for repositories that exceed git.statusLimit, including actionable guidance for increasing the limit.

## Best solution

Make the built-in Git extension's limit warning explain the truncation and provide a direct path to git.statusLimit. Treat changes to the default limit or warning timing as separate owner decisions, preserving safeguards for accidentally discovered repositories.
