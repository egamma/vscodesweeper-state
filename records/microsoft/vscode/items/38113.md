# Issue #38113 — SCM - Support keyboard shortcuts for inline change review commands

## Summary

Implemented-on-main close gated off (the cited commit 602f3f9b46 only bumps dependency versions — it delivers a fix that lives upstream; cite the upstream fix commit, or keep the issue open with the lead in evidence). Original assessment: Already implemented: current main ships default keybindings for every inline change-review action the reporter asked about (revert/stage/unstage the hunk under the cursor, navigate next/previous change, toggle widget focus, close the peek) — verified directly in the checkout and independently confirmed by a contributor three months ago.

## Change summary

Give the SCM inline diff/quick-diff review widget (revert, stage, navigate changes, close) keyboard shortcuts, since binding `git.revertChange` did nothing.

## Best solution

Treat as resolved — keep the shipped default keybindings (stage/unstage/revert selected ranges, next/previous change, focus toggle, escape-to-close); the one remaining gap (toolbar buttons inside the widget aren't tab-focusable) is cosmetic since every action they trigger already has a keybinding, and isn't worth reopening this old thread for.
