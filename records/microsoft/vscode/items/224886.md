# Issue #224886 — No way to score a generic language feature above `'*'` but below a selector match

[https://github.com/microsoft/vscode/issues/224886](https://github.com/microsoft/vscode/issues/224886)

## Summary

Team-authored design discussion about introducing intermediate scoring tiers for language feature providers; the scoring system (0/5/10) remains unchanged on main and the discussion between team members is unresolved.

## Change summary

Allow language feature providers to score between the wildcard '*' match (5) and an exact selector match (10), enabling alternative providers to rank above the default textual fallback without overriding precise matches.

## Best solution

Resolve the design discussion: either introduce an intermediate score tier (e.g. score 1 for the built-in textual fallback, leaving 5 for new heuristics) or add a setting to disable the default textual provider as jrieken suggested. The scoring logic lives in src/vs/editor/common/languageSelector.ts.
