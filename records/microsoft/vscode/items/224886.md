# Issue #224886 — No way to score a generic language feature above `'*'` but below a selector match

[https://github.com/microsoft/vscode/issues/224886](https://github.com/microsoft/vscode/issues/224886)

## Summary

Keep open: current provider scoring still lacks an intermediate generic priority, and the textual fallback remains registered with '*'. Existing highlight-merging controls partially address provider coexistence but do not deliver the requested ordering.

## Change summary

Allow a generic highlight provider to rank above the built-in textual fallback while remaining below a language-specific provider.

## Best solution

Establish a supported precedence contract for generic providers and the built-in textual fallback, preserving language-specific precedence. Resolve whether that requires a scoring tier or a fallback-specific control, building on the setting alternative already discussed in the thread.
