# Issue #213110 — Project Tabs on Windows

[https://github.com/microsoft/vscode/issues/213110](https://github.com/microsoft/vscode/issues/213110)

## Summary

The Windows project-tab request is covered by the older, open multiple-workspaces-in-one-window issue, whose discussion explicitly requests tabbed workspaces and identifies the macOS-only limitation. Consolidate there while preserving this report's Windows-specific demand.

## Change summary

Allow multiple independent projects to open in tabs within one VS Code window on Windows, comparable to macOS native window tabs.

## Best solution

Track Windows project tabs under https://github.com/microsoft/vscode/issues/43188, preserving independent workspace contexts rather than substituting multi-root folders or ordinary file tabs.
