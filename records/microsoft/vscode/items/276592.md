## Summary

Still reproduces on main: the tsconfig extends link resolution in `resolveNodeModulesPath` does not consult `package.json` exports fields, so subpath remapping is never applied. An open PR (#308156) is attempting a fix.

## Change summary

Cmd+click on tsconfig `extends` specifiers fails when the target package uses package.json `exports` subpath remapping.
