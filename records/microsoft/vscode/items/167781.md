# Issue #167781 — Pressing cmd with hover open does not  peek symbol

[https://github.com/microsoft/vscode/issues/167781](https://github.com/microsoft/vscode/issues/167781)

## Summary

The reported gap remains in current source: pressing Cmd can add the definition-preview decoration without updating an already-visible hover. Keep this reopened issue open; the earlier fix was explicitly reverted, and the subsequent linked proposals are closed without merging.

## Change summary

Update an already-visible symbol hover to include its definition preview when the navigation modifier is pressed without moving the mouse.

## Best solution

Refresh the visible hover when definition-preview content becomes available for its hovered symbol, without restoring unconditional rerenders on decoration changes. Preserve configurable navigation modifiers, ordinary hover stability, and the existing keyboard preview command.
