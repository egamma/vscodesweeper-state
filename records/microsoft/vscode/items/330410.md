# Issue #330410 — Breadcrumbs render UUID for session files

[https://github.com/microsoft/vscode/issues/330410](https://github.com/microsoft/vscode/issues/330410)

## Summary

Real, team-filed bug already carrying a concrete release milestone (1.136.0), which is a scheduling decision — the hard keep-open rule for assigned milestones applies, so no close is proposed regardless of author association.

## Change summary

When Copilot creates a file (e.g. a markdown trip plan) inside an agent session, the editor breadcrumb shows the raw UUID-based path segment instead of a readable name.

## Best solution

In the Agents Window / editor breadcrumbs area, either suppress the breadcrumb for session-scoped virtual resources or substitute a friendly label for the UUID path segment; likely touches the breadcrumb model/provider used by the sessions editor part alongside the session file-naming code that mints `/untitled-${generateUuid()}` style resources.
