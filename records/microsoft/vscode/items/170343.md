# Issue #170343 — Add a setting to automatically detect the language of a new file no more than once.

[https://github.com/microsoft/vscode/issues/170343](https://github.com/microsoft/vscode/issues/170343)

## Summary

Keep open: current source still permits repeated automatic language changes, and existing controls do not provide a general detect-once option. The request remains accepted, unscheduled work in Backlog; no verified canonical owns this specific capability.

## Change summary

Allow an untitled file's language to be detected automatically once, without subsequent typing changing the detected language.

## Best solution

An opt-in detect-once policy for untitled editors would preserve the initial automatic selection while leaving continuous detection as the default. The language-detection owner should assess demand and settle the policy before implementation.
