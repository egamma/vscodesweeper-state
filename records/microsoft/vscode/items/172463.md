# Issue #172463 — WorkspaceEdit API didn't delete the created folder when undo. 

[https://github.com/microsoft/vscode/issues/172463](https://github.com/microsoft/vscode/issues/172463)

## Summary

The reported gap remains in current source: creating a file implicitly creates missing parent folders, but undo records only the explicitly created file. Keep this open under the existing workspace-edit label; the related deletion-undo issue concerns a different failure.

## Change summary

Undoing a WorkspaceEdit file creation should remove the empty parent folders created implicitly by that edit.

## Best solution

Make bulk file-edit undo restore the previous directory structure for this creation case, while preserving pre-existing folders and unrelated files added afterward. Redo should recreate the file and its required folders.
