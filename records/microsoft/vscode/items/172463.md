# Issue #172463 — WorkspaceEdit API didn't delete the created folder when undo. 

[https://github.com/microsoft/vscode/issues/172463](https://github.com/microsoft/vscode/issues/172463)

## Summary

Still reproducible on main: when WorkspaceEdit.createFile creates intermediate parent directories, undo deletes only the file — not the folders. Contributors discussed the gap in Dec 2023 but no fix landed.

## Change summary

Undoing a WorkspaceEdit.createFile that created intermediate parent directories does not remove those directories.

## Best solution

Track which parent directories were created during file creation (either by having the file service return that info, or by pre-checking for non-existing ancestors in bulkFileEdits.ts as jrieken suggested) and include them in the undo's DeleteEdit list. The fix spans `src/vs/workbench/contrib/bulkEdit/browser/bulkFileEdits.ts` and possibly `src/vs/platform/files/common/fileService.ts`.
