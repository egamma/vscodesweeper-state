# Issue #251714 — [LEAKED DISPOSABLE]: selectbox custom markdown

[https://github.com/microsoft/vscode/issues/251714](https://github.com/microsoft/vscode/issues/251714)

## Summary

Verified duplicate: the leaked disposable in `SelectBoxList.renderDescriptionMarkdown` was fixed via commit 82873d9d1e3 ("Fix leak in selection box md rendering"), which closed #269352 — the same leak reported here. Proposing duplicate close.

## Change summary

The rendered markdown from `renderDescriptionMarkdown` in the select box was never disposed, causing a disposable leak.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/269352 which received the fix (commit 82873d9d1e3) that adds a `DisposableStore` to properly clear and track the rendered markdown lifecycle.
