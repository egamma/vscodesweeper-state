# Issue #239417 — Inconsistent and confusing display of newlines in file paths

[https://github.com/microsoft/vscode/issues/239417](https://github.com/microsoft/vscode/issues/239417)

## Summary

The inconsistent rendering remains source-reproducible on current main: Explorer and editor tabs pass raw newline-containing names into single-line labels and hover titles without using the existing newline-escape support.

## Change summary

Display newline characters in Linux file names consistently without clipping labels, collapsing the character invisibly, or adding misleading hover line breaks.

## Best solution

Represent embedded newlines with the existing visible return marker across Explorer rows, editor tabs, and their hover titles while preserving the real resource name for filesystem operations and accessibility.
