# Issue #307574 — Allow SCM diff view to be opened in Modal

[https://github.com/microsoft/vscode/issues/307574](https://github.com/microsoft/vscode/issues/307574)

## Summary

Keep open: current main has modal editor infrastructure, but no SCM-specific way to open diffs there while leaving ordinary editors in the editor area. The linked implementation PR was closed without merging.

## Change summary

Allow Source Control diffs to open in a modal overlay for comfortable change review on smaller screens.

## Best solution

Provide an opt-in SCM diff modal experience that preserves ordinary file-opening behavior and respects the existing modal-editor opt-out. Decide whether this is a per-open action or an SCM-specific opening preference before implementation.
