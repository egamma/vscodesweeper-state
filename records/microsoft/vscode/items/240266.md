# Issue #240266 — SCM - Binary File Diff does not show in Combined Working Diff, Combined Staged Diff or Commit Diff

[https://github.com/microsoft/vscode/issues/240266](https://github.com/microsoft/vscode/issues/240266)

## Summary

Still reproduces on main: binary files are silently excluded from combined/staged/commit diffs because the multi-diff editor input catches the binary-file error and returns undefined, filtering the entry out entirely. The issue is on the On Deck milestone, so keeping open.

## Change summary

Binary files are missing from the combined working tree diff, combined staged diff, and commit diff in the SCM view — showing "No Changed Files" when only binary files changed.

## Best solution

In `src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditorInput.ts` (around line 201), instead of returning `undefined` when a file is binary, produce a document diff item that renders a binary-file placeholder (similar to how individual binary file diffs already work). The SCM multi-diff source should propagate binary entries rather than swallowing them.
