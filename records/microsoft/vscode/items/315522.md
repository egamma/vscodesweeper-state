# Issue #315522 — Feature Request: Custom Background Colors for Chat Sessions

[https://github.com/microsoft/vscode/issues/315522](https://github.com/microsoft/vscode/issues/315522)

## Summary

A real per-session customization gap remains: current main supports one Agents window background per light/dark theme, not colors persisted independently for each chat. The request has no demonstrated demand or settled UX direction, so it should remain open as under discussion rather than be implemented or closed automatically.

## Change summary

Allow each Copilot Chat session or tab to retain a custom background color for quick visual identification.

## Best solution

If the area owners accept the concept, use a small theme-aware session color treatment that persists with session metadata and remains legible in high-contrast themes; they should first decide whether that treatment is a full chat background, a tab/list accent, or a session-group color.

## Evidence

- **current capability:** src/vs/sessions/services/chatBackground/browser/chatBackgroundService.ts stores only machine-scoped `chat.agentSessions.preferredDarkBackgroundImage` and `chat.agentSessions.preferredLightBackgroundImage` settings. Its API has no session identifier or per-session color state.
- **rendering scope:** src/vs/sessions/browser/parts/sessionsPart.ts creates one `SessionsChatBackgroundRenderer` for the entire sessions part and updates it from the shared background service, so switching sessions cannot select a distinct persisted background.
- **partial existing UI:** src/vs/sessions/contrib/chat/browser/chat.contribution.ts provides Set Chat Background choices for none, Codicons, recent images, or an image file. It does not provide a color palette or associate the selection with an individual chat session.
- **canonical search:** The older open https://github.com/microsoft/vscode/issues/308516 concerns folders, nested groups, bulk organization, and color support in the session list, not individual chat-window backgrounds. The newer https://github.com/microsoft/vscode/issues/338822 concerns colored groups and collections and cannot be the canonical for this re-reviewed older item.
- **demand:** The request has no comments or community upvotes after 144 days, leaving the product and accessibility tradeoffs without enough signal for an agent-led design session.
