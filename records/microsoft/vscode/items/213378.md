# Issue #213378 — Cleanup/remove `interactive.transferActiveChat` 

[https://github.com/microsoft/vscode/issues/213378](https://github.com/microsoft/vscode/issues/213378)

## Summary

The proposed `interactive.transferActiveChat` API still exists on current main with its full implementation chain (proposed DTS, ext-host protocol, main-thread handler). The cleanup/redesign described in this issue has not been done.

## Change summary

Remove or redesign the `interactive.transferActiveChat` proposed API so that transferring a chat session is coupled with opening a workspace rather than being a standalone fire-and-forget call.

## Best solution

Redesign the transfer flow as part of `vscode.openFolder` (accepting a ChatResult or session reference) and then remove the standalone `transferActiveChat` API and its protocol plumbing in `extHostChatAgents2.ts` / `mainThreadChatAgents2.ts`.
