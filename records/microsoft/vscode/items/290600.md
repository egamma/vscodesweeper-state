# Issue #290600 — Mismatch between cloud session changed files in chat output vs review

[https://github.com/microsoft/vscode/issues/290600](https://github.com/microsoft/vscode/issues/290600)

## Summary

Keep open: current source excludes newly added files from cloud-session review, conclusively explaining why three changed files become one. The command-center readiness calculation also overlooks sessions containing only added files.

## Change summary

Cloud-session review should include newly created files alongside modified and deleted files so its contents match the session's changed-file list.

## Best solution

Make the projection review and command-center readiness calculation recognize valid one-sided changes, preserving the complete cloud-session file set. Keep existing local-session acceptance behavior and projection working-set restoration unchanged.
