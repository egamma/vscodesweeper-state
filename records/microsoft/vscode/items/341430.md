# Issue #341430 — window.tabGroups.activeTabGroup does not follow the active editor group across windows

[https://github.com/microsoft/vscode/issues/341430](https://github.com/microsoft/vscode/issues/341430)

## Summary

Thanks for the detailed report. The source on main matches the analysis: mainThreadEditorTabs.ts only rebuilds the model on group add/remove and handles GROUP_ACTIVE only for the already-active group, with no listener for onDidChangeActiveGroup, so switching between windows doesn't update tabGroups.activeTabGroup.

## Change summary

tabGroups.activeTabGroup/isActive does not update when focus moves between the main and auxiliary windows.

## Best solution

In MainThreadEditorTabs, listen to IEditorGroupsService.onDidChangeActiveGroup and call _onDidGroupActivate, next to the add/remove listeners.
