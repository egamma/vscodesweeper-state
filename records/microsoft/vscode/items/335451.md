# Issue #335451 — Assisted permissions: compound command containing a local script path always requires explicit approval (1.137.0 regression)

[https://github.com/microsoft/vscode/issues/335451](https://github.com/microsoft/vscode/issues/335451)

## Summary

Keep open as an upstream Copilot runtime permission-classifier regression. Current VS Code still enables script safety and relies on the runtime's assisted-approval result, while no concrete upstream fix or current-main resolution could be identified.

## Change summary

Compound shell commands containing a local script path bypass the assisted-permission judge and require explicit approval, although the same script and compound command are accepted separately.

## Best solution

The Copilot runtime should retain script-safety path analysis while allowing the assisted judge to evaluate classifier non-verdicts for compound local-script commands. VS Code should then adopt the fixed runtime and add a provider integration regression covering `./x; echo done` without weakening managed-permission enforcement.
