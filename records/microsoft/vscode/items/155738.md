# Issue #155738 — Support CompletionList.isIncomplete=true on empty lists (or at least, clearly document current behaviour)

[https://github.com/microsoft/vscode/issues/155738](https://github.com/microsoft/vscode/issues/155738)

## Summary

Still valid on main: the suggest model explicitly requires items.length > 0 before honoring the incomplete flag, so empty completion lists with isIncomplete=true are never retriggered. Multiple language servers are affected and have documented workarounds. The issue has 11 upvotes and remains under-discussion.

## Change summary

When a completion provider returns an empty list with isIncomplete=true, VS Code ignores the incomplete flag and never retriggers the provider on further typing.

## Best solution

Modify `getIncompleteProvider()` in `completionModel.ts` and the retrigger logic in `suggestModel.ts` to track providers that returned incomplete=true even with zero items, so they are re-queried as the user types. The fix is localized to the suggest contribution but needs careful design to avoid infinite retrigger loops when a provider genuinely has nothing.
