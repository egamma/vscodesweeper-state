# Issue #44697 — Feature request: Add support for modifier keys like right ctrl and right alt

[https://github.com/microsoft/vscode/issues/44697](https://github.com/microsoft/vscode/issues/44697)

## Summary

Keep open: current main still collapses left and right modifiers, and this canonical Backlog request has 83 community upvotes.

## Change summary

Allow keybindings to distinguish left and right Ctrl, Alt, Shift, and Meta keys.

## Best solution

Extend the keybinding parser, chord model, and event dispatch to preserve modifier-side identity while retaining generic modifier bindings as fallback. The design must handle AltGr and missed key events consistently across platforms.
