Keep open as a confirmed GPU-rendering bug. The reporter supplied the requested GPU data, and an independent user reproduced the flicker on Linux, so `info-needed` is no longer the appropriate state.

## Change summary

Hovering and opening workbench UI elements can subtly change or flicker the editor background brightness.

## Best solution

GPU owners should isolate whether hardware compositing triggers the cross-platform flicker by comparing normal operation with `--disable-gpu` and `--disable-gpu-compositing`, then route it upstream if Chromium/Electron owns the faulty rendering path.
