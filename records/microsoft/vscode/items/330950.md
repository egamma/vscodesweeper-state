# Issue #330950 — Missing a list of comments to go through

[https://github.com/microsoft/vscode/issues/330950](https://github.com/microsoft/vscode/issues/330950)

## Summary

This team-authored polish request remains necessary: current main can retrieve and render PR review comments inline and show per-file counts, but it does not expose those comments as a navigable cross-file list. No older issue reports the same Agents Window symptom, and no fixing commit explicitly references this issue.

## Change summary

Provide an editor-style list for stepping through all pull-request review comments in an Agents Window session.

## Best solution

Surface the active session's unresolved PR review comments through a list that opens each affected file and reveals the selected thread, preferably by integrating with the existing Comments view rather than creating a parallel navigation model.
