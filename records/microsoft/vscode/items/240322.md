# Issue #240322 — SCM - Setting for adjusting branch names/tags

[https://github.com/microsoft/vscode/issues/240322](https://github.com/microsoft/vscode/issues/240322)

## Summary

Keep open: graph badges still truncate long branch names at a fixed width, and the existing badge setting does not address readability. This team-authored, Backlog-accepted request needs a UX decision rather than a decline close.

## Change summary

Allow long branch and tag names in the Source Control Graph to remain distinguishable without hovering.

## Best solution

Make graph reference badges distinguish branches with shared prefixes while preserving space for commit messages. The SCM UX owner should decide whether this is delivered through adjustable badge width or a consistent truncation treatment.
