Team-authored report with a real milestone (1.138.0) assigned, so it stays open regardless; the underlying mechanism is confirmed in source — the Copilot SDK's `/fleet` compatibility path synthesizes a `user.message` event whose visible `content` is the literal string "Fleet deployed" while `transformedContent` carries the full injected fleet-mode system prompt, and this is rendered as if it were the user's own chat message.
