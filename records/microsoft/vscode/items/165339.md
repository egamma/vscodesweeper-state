# Issue #165339 — Blocked popups are not handled in Chrome on Github Codespace

[https://github.com/microsoft/vscode/issues/165339](https://github.com/microsoft/vscode/issues/165339)

## Summary

Keep open: current source still excludes ordinary Chrome, Edge, and Firefox sessions from external-link popup-block detection and the Retry dialog. The existing web and opener labels correctly identify the owning area.

## Change summary

Detect blocked extension-initiated external browser windows in non-Safari browsers and provide a user-triggered retry instead of silently reporting success.

## Best solution

Make the web workbench's default external opener provide reliable blocked-popup recovery across supported browsers, while preserving opener isolation and embedded-host compatibility. Verify the actual browser behavior before choosing the detection technique.
