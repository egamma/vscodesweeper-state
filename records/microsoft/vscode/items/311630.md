# Issue #311630 — Sessions should be sorted by date

[https://github.com/microsoft/vscode/issues/311630](https://github.com/microsoft/vscode/issues/311630)

## Summary

Still reproduces on main: the session picker sorts by locale-formatted date strings (alphabetical) rather than by actual timestamps, producing incorrect ordering. No fix commit found.

## Change summary

The 'add context → session' picker in the chat view sorts sessions alphabetically by their formatted date string instead of chronologically.

## Best solution

In `src/vs/workbench/contrib/chat/browser/actions/chatContext.ts` (the `ChatContextSessions.asPicker` method), replace the `localeCompare`-based sort with a numeric comparison on the raw timestamp values (e.g. `item.timing.lastRequestEnded ?? item.timing.created`). The description string can remain `toLocaleString()` for display; the sort key just needs to be the underlying number.
