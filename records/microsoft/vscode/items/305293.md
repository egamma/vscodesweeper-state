# Issue #305293 — Expose more Copilot Chat APIs for third-party model providers

[https://github.com/microsoft/vscode/issues/305293](https://github.com/microsoft/vscode/issues/305293)

## Summary

Current main now exposes provider-defined model settings and structured thinking/tool-call response parts, addressing much of the reported friction, but it does not expose Copilot's protocol stream parser or otherwise settle the broader API-boundary request. Keep this open as under discussion so the remaining provider-neutral API gap can be defined.

## Change summary

Expose additional Copilot Chat capabilities so third-party language-model providers can reuse model configuration UX and structured streaming support instead of rebuilding them.

## Best solution

Finalize a provider-neutral extension contract for model configuration and structured thinking/tool-call response parts, then decide explicitly whether reusable wire-format parsing belongs in the public API or remains provider-specific. Narrow follow-up issues should track concrete gaps that remain after the current proposed APIs.
