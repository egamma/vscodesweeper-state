# Issue #332182 — Integrated Browser: Element picker does not highlight during mobile emulation

[https://github.com/microsoft/vscode/issues/332182](https://github.com/microsoft/vscode/issues/332182)

## Summary

Legitimate, well-diagnosed bug in the Integrated Browser element picker under Mobile Emulation, already traced by the reporter to CDP's mouse-to-touch conversion suppressing pointermove; an open PR (#332183) already fixes it, so this stays open pending review/merge rather than any triage close.

## Change summary

The element-picker hover highlight stops following the pointer while Mobile Emulation is enabled in the Integrated Browser, because Chrome's mouse-to-touch conversion suppresses pointermove events.

## Best solution

Review and land the linked fix in https://github.com/microsoft/vscode/pull/332183, which pauses mouse-to-touch conversion during active element selection while preserving the emulated viewport, touch capability, and pointer:coarse state.
