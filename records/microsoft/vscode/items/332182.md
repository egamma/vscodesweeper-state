# Issue #332182 — Integrated Browser: Element picker does not highlight during mobile emulation

[https://github.com/microsoft/vscode/issues/332182](https://github.com/microsoft/vscode/issues/332182)

## Summary

Real, well-diagnosed bug in the Integrated Browser's element picker under Mobile Emulation, and an open PR (not yet merged) already targets this exact issue — per policy this stays open until the fix lands, rather than being closed now.

## Change summary

With Mobile Emulation enabled in the Integrated Browser, the element-picker hover highlight (used by 'Add Element to Chat') doesn't follow the pointer because mouse-to-touch conversion suppresses pointermove events.

## Best solution

Land https://github.com/microsoft/vscode/pull/332183, which pauses mouse-to-touch conversion while the element picker is active (restoring it afterward) so hover highlighting works while mobile emulation stays otherwise intact; close this issue once that PR merges.
