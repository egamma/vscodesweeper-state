# Issue #332182 — Integrated Browser: Element picker does not highlight during mobile emulation

[https://github.com/microsoft/vscode/issues/332182](https://github.com/microsoft/vscode/issues/332182)

## Summary

Real bug in the Integrated Browser's element picker, and a fix is already in flight — https://github.com/microsoft/vscode/pull/332183 — so this stays open pending that PR landing rather than being closed now.

## Change summary

When Mobile Emulation is enabled in the Integrated Browser, the element-picker hover highlight stops following the pointer during Add Element to Chat.

## Best solution

Land https://github.com/microsoft/vscode/pull/332183, which appears to address exactly this (the preload-based picker relies on real `pointermove` events, but Chromium's touch/mobile emulation suppresses those in favor of touch events); once merged this and the related https://github.com/microsoft/vscode/issues/332180 report can close together.
