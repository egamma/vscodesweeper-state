# Issue #332085 — Copilot Harness: BYOK custom-endpoint model not selectable for Remote Scenarios (WSL, Dev Containers, SSH etc)

[https://github.com/microsoft/vscode/issues/332085](https://github.com/microsoft/vscode/issues/332085)

## Summary

Keep open: remote Copilot-harness BYOK support remains explicitly unavailable on current main, and the maintainer has designated this issue to track that gap across WSL, SSH, and Dev Containers. The Local-harness workaround and the separate restored-session fix do not deliver the requested remote behavior.

## Change summary

Make custom-endpoint BYOK models selectable and usable in Copilot-harness sessions running on remote workspaces.

## Best solution

Deliver remote BYOK model discovery and inference without changing the session to local execution, coordinated with the host-owned provider direction in https://github.com/microsoft/vscode/issues/340335. Retain this issue's remote-workspace acceptance cases while the provider lifecycle and configuration integration are designed.
