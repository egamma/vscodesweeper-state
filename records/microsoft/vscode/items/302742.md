# Issue #302742 — No information about rate-limit quotas and reset points

[https://github.com/microsoft/vscode/issues/302742](https://github.com/microsoft/vscode/issues/302742)

## Summary

Keep open as a request for clearer Copilot rate-limit information. Current UI provides some quota and reset information, but it does not fully cover the request for concrete rate-limit allowances and reset points.

## Change summary

Show the applicable Copilot rate-limit quota and when it resets after a request is limited.

## Best solution

Make rate-limit messages distinguish the exhausted allowance and display authoritative reset information when available, separately from monthly usage quotas. When the service supplies no reset information, communicate that uncertainty rather than implying a short wait.
