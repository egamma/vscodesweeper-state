# Issue #226728 — `SettingsEditor2` shows progress when opening raw settings file

[https://github.com/microsoft/vscode/issues/226728](https://github.com/microsoft/vscode/issues/226728)

## Summary

Still reproduces on main: the `onDidChangeConfiguration` handler in `settingsEditor2.ts` (line 308) fires `onConfigUpdate` without a `this.isVisible()` guard, causing spurious progress bars when the settings editor is not active.

## Change summary

Opening a raw settings.json file triggers a progress indicator in the editor because the Settings Editor's `onConfigUpdate` runs even when the editor is hidden.

## Best solution

Add an `isVisible()` guard in the `onDidChangeConfiguration` handler (lines 308–318) so that `onConfigUpdate` is either skipped or deferred until the settings editor becomes visible again, consistent with `refreshTree`/`refreshTOCTree`/`refreshSingleElement` which already have such guards.
