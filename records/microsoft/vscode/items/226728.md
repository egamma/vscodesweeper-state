# Issue #226728 — `SettingsEditor2` shows progress when opening raw settings file

[https://github.com/microsoft/vscode/issues/226728](https://github.com/microsoft/vscode/issues/226728)

## Summary

Keep open: a hidden Settings editor can still restart searches after settings-schema updates and report progress into the editor group's currently visible file. Current source retains this path; the existing 800 ms progress delay reduces its visibility but does not address the hidden-editor activity.

## Change summary

Prevent background Settings editor refreshes from displaying search progress over unrelated text editors.

## Best solution

Make Settings editor refresh and search activity respect its visibility, while ensuring settings and search results are current when the editor is shown again. Preserve legitimate progress for visible Settings searches and unrelated editor operations.
