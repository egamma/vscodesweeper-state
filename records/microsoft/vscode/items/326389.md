# Issue #326389 — 1.129.0 Regression: BYOK (ollama extension provider) fails without login

[https://github.com/microsoft/vscode/issues/326389](https://github.com/microsoft/vscode/issues/326389)

## Summary

Valid regression: extension-provided language models (BYOK via Ollama, etc.) are blocked when no GitHub session exists because `_getToken()` in `languageModelAccess.ts` gates all model access on `hasCopilotTokenSource`. Already assigned to two team members.

## Change summary

BYOK/extension-provided language models (e.g. Ollama) fail with 'Language model unavailable' when the user is not logged into GitHub, which is a regression from 1.129.0.

## Best solution

The language model access path in `extensions/copilot/src/extension/conversation/vscode-node/languageModelAccess.ts` should not require a Copilot token for extension-provided BYOK models. The `_getToken()` gate needs a bypass when the selected model is served by an extension provider rather than the Copilot backend.
