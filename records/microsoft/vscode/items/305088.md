# Issue #305088 — nes: patch-based: ClippedDocument.keptRange includes tag lines, causing out-of-bounds access in pseudoEditWindow

[https://github.com/microsoft/vscode/issues/305088](https://github.com/microsoft/vscode/issues/305088)

## Summary

The bug is still present on main — `ClippedDocument` has no `originalDocumentLineRange` field and `keptRange` still includes tag lines, causing the out-of-bounds index in `xtabProvider.ts`. Team-authored issue; keeping open.

## Change summary

ClippedDocument.keptRange includes tag lines (AREA_AROUND/EDIT_WINDOW markers), causing pseudoEditWindow in xtabProvider.ts to index past the end of currentDocument.lines.

## Best solution

Add an `originalDocumentLineRange` field to `ClippedDocument` (in `extensions/copilot/src/extension/xtab/common/promptCrafting.ts`) that stores `rangeToKeep` in original-document coordinates, and use that field instead of `keptRange` in `xtabProvider.ts` for the pseudoEditWindow computation.
