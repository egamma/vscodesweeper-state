# Issue #252530 — Make `security.promptForPromptProtocolHandling` a real setting and an allow list

[https://github.com/microsoft/vscode/issues/252530](https://github.com/microsoft/vscode/issues/252530)

## Summary

A real gap remains: current `main` always displays the security confirmation and provides no editable host allowlist. The issue was explicitly classified into the Backlog after the earlier per-host checkbox was removed, so it should remain open pending a product and security decision.

## Change summary

Expose prompt-install protocol trust decisions as an editable string-array setting containing hosts that may bypass the confirmation dialog.

## Best solution

If the security tradeoff is accepted, provide an application-scoped host allowlist that defaults to empty and is consulted by `PromptUrlHandler`, while preserving confirmation for every host not explicitly listed.
