# Issue #333529 — charts.orange defaults to semi-transparent #EA5C0055 due to minimap.findMatchHighlight fallback

[https://github.com/microsoft/vscode/issues/333529](https://github.com/microsoft/vscode/issues/333529)

## Summary

Confirmed on current main: `charts.orange` still falls back to `minimap.findMatchHighlight` → `editor.findMatchHighlightBackground`, whose default is `#EA5C0055` (33% alpha), while the analogous `charts.green`/`charts.purple` tokens have explicit opaque default objects — this is an inconsistency worth fixing.

## Change summary

charts.orange resolves to a semi-transparent orange by default instead of an opaque color like the other chart tokens.

## Best solution

Give `chartsOrange` an explicit opaque default color object (dark/light/hcDark/hcLight) in src/vs/platform/theme/common/colors/chartsColors.ts, matching the pattern already used for `chartsGreen` and `chartsPurple`, instead of delegating to `minimapFindMatch`.
