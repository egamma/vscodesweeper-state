# Issue #297338 — Ctrl+scroll wheel zoom jumps around

[https://github.com/microsoft/vscode/issues/297338](https://github.com/microsoft/vscode/issues/297338)

## Summary

The report has detailed steps, two recordings, and an independent cross-platform confirmation with Logitech mice. It should remain open and be routed to the editor scrolling/zoom owners rather than closed as non-reproducible.

## Change summary

Ctrl/Cmd+mouse-wheel editor zoom can also move the viewport, with repeated zoom cycles eventually causing large jumps through the file.

## Best solution

Ensure mouse-wheel zoom consumes the wheel gesture without applying ordinary editor scrolling, while preserving the intended cursor-relative viewport anchor as font size changes.
