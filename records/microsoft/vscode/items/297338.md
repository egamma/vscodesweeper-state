# Issue #297338 — Ctrl+scroll wheel zoom jumps around

[https://github.com/microsoft/vscode/issues/297338](https://github.com/microsoft/vscode/issues/297338)

## Summary

Still present on main: the editor mouse-wheel zoom path in mouseHandler.ts does not anchor the scroll position relative to the cursor when zooming, so rapid Ctrl+scroll cycles cause the viewport to drift and jump. No fix has landed.

## Change summary

Using Ctrl+scroll wheel to zoom in the editor causes the scroll position to jump erratically, especially when repeatedly zooming in and out in a large file.

## Best solution

The zoom handler in `src/vs/editor/browser/controller/mouseHandler.ts` (lines 159–166) changes the zoom level without anchoring the scroll position to the mouse cursor's location in the document. The fix should save the line at the mouse cursor before zooming, then restore the scroll position to keep that line stable after the layout reflow triggered by the zoom-level change. This is a localized change in the editor mouse handler and the editor scroll management.
