# Issue #193660 — Put density related options under the same namespace: tabs, notebooks

[https://github.com/microsoft/vscode/issues/193660](https://github.com/microsoft/vscode/issues/193660)

## Summary

The tab-setting rename landed, but notebook compactness still uses notebook.compactView, so the namespace cleanup remains incomplete. Keep this accepted On Deck work open; the newer layout-density setting also warrants clarifying whether the remaining scope includes an aggregate density control.

## Change summary

Group tab and notebook compactness settings under window.density, potentially with a shared density preset.

## Best solution

Complete the agreed notebook density namespace cleanup while preserving existing notebook preferences and defaults. Distinguish that migration from any aggregate density preset, whose interaction with component overrides and window.density.layout needs a product decision.
