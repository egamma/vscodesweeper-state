## Summary

The chat submission teardown race remains reachable on current main: the view model can be cleared during an awaited operation and then dereferenced without revalidation. The linked closed item contains an unmerged patch proposal, not evidence that the defect was fixed.

## Change summary

Prevent chat submission from throwing when its session model is cleared during asynchronous preparation.

## Best solution

Make ChatWidget submission stop safely when its originating session disappears during preparation, without submitting the abandoned request to another session. Cover the lifecycle race with deterministic tests in the existing submission suite.
