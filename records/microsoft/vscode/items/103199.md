# Issue #103199 — Preserve open documents word wrap settings on restart

[https://github.com/microsoft/vscode/issues/103199](https://github.com/microsoft/vscode/issues/103199)

## Summary

This remains the canonical backlog request for persisting per-document word-wrap overrides. Current main still stores Alt+Z state only in memory, and the request has 44 community upvotes.

## Change summary

Preserve each open document's temporary word-wrap override when VS Code restarts.

## Best solution

Extend the word-wrap toggle state in `src/vs/workbench/contrib/codeEditor/browser/toggleWordWrap.ts` to participate in editor/session restoration while retaining its model-wide behavior across multiple editors. Language-specific `editor.wordWrap` settings should remain the preferred solution for file-type defaults.
