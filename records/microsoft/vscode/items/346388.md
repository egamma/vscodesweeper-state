# Issue #346388 — "Install Plugin From Source" has long delay with no feedback

[https://github.com/microsoft/vscode/issues/346388](https://github.com/microsoft/vscode/issues/346388)

## Summary

Keep open: the source-install action hides its busy indicator before awaiting installation, leaving the provider-owned path without visible installation feedback. This team-authored report identifies a concrete gap, not grounds for a judgment close.

## Change summary

Show installation feedback between submitting a plugin source and opening Chat Customizations.

## Best solution

Keep installation visibly in progress throughout the source-install command, including provider-owned installation, while preserving trust prompts, error recovery, and navigation after success.
