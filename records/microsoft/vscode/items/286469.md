This requests an alternative Remote - SSH bootstrap path for Windows hosts whose endpoint protection blocks Base64-encoded PowerShell. Remote - SSH is maintained by the VS Code team in microsoft/vscode-remote-release, so the thread should be transferred rather than closed.
