# Issue #312716 — Integrated Browser - Show In Title Bar is not working as expected

## Summary

Keep open as a title-bar UX inconsistency: the default 'whenOpen' intentionally hides the browser button when no browser is open, but the context-menu checkbox remains checked. Setting true already provides the reporter's preferred static button, without resolving how the conditional mode is represented.

## Change summary

Make the Integrated Browser title-bar menu accurately communicate its conditional visibility mode.

## Best solution

Keep the supported always, never, and when-open behaviors while making the title-bar menu distinguish conditional visibility from always-visible state. The area owner should settle the menu semantics; removing 'whenOpen' is not necessary to provide a static button.
