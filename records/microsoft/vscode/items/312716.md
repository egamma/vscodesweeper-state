# Issue #312716 — Integrated Browser - Show In Title Bar is not working as expected

[https://github.com/microsoft/vscode/issues/312716](https://github.com/microsoft/vscode/issues/312716)

## Summary

Still reproduces on main: the ToggleTitleBarConfigAction base class assumes a boolean setting, but `workbench.browser.showInTitleBar` is a tri-state (`true`/`false`/`'whenOpen'`). The default `'whenOpen'` is truthy, so the context menu checkmark shows, but the globe icon correctly hides (no browser editor open), creating inconsistency. Additionally, toggling from `'whenOpen'` sets `false` and the `'whenOpen'` state is irreversibly lost.

## Change summary

When `workbench.browser.showInTitleBar` is at its default `'whenOpen'`, the title bar context menu shows a checkmark but the globe icon is hidden, and toggling destroys the `'whenOpen'` state.

## Best solution

The `ToggleBrowserTitleBarButton` should not extend `ToggleTitleBarConfigAction` (which only handles booleans). It needs a custom `toggled` expression that distinguishes `'whenOpen'` from `true`, and a custom `run()` that cycles through the tri-state or treats `'whenOpen'` as the 'on' state in the toggle (e.g. toggling off → `false`, toggling on → `'whenOpen'`). The fix is localized to `browserTabManagementFeatures.ts`.
