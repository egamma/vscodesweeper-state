## Summary

This was fixed on current main: user toolsets now resolve qualified MCP references such as `github/*`, so selecting that toolset through prompt-file frontmatter includes its MCP tools.

## Change summary

Prompt-file `tools` frontmatter selected a user toolset but omitted MCP members while retaining built-in members.

## Best solution

Keep the qualified-reference resolution added in commit a387da08dcea0cd5096e59d5d31991b0e3b0e5ae; it aligns user-toolset loading with the names emitted by the tool picker and used by prompt files.
