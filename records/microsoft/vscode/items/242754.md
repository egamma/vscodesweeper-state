# Issue #242754 — SCM Graph - Open git graph in editor window

[https://github.com/microsoft/vscode/issues/242754](https://github.com/microsoft/vscode/issues/242754)

## Summary

Valid feature request to open the built-in SCM Graph as an editor tab rather than only in the sidebar. The graph currently lives as a ViewPane (scmHistoryViewPane.ts); no editor-based rendering exists on current main. Not a duplicate of #193267 (aux window detaching) — the reporter explicitly clarified they want a tab, like the Git Graph extension.

## Change summary

Allow the built-in SCM Graph to open as an editor tab in the main editor area, similar to how the Git Graph extension renders its view.

## Best solution

Implement an EditorPane + EditorInput for the SCM graph so it can be opened as a tab in the editor area. This would involve creating a new editor contribution in `src/vs/workbench/contrib/scm/browser/` that wraps the existing graph rendering. The community process should determine demand (currently 3 upvotes).
