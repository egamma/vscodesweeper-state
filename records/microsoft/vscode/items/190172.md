# Issue #190172 — Autocomplete is too aggressive in its default setting

[https://github.com/microsoft/vscode/issues/190172](https://github.com/microsoft/vscode/issues/190172)

## Summary

The user requests context-aware quick suggestions in HTML — suppressing the suggest widget when typing prose content outside of tags. The default for `quickSuggestions.other` was recently changed to `offWhenInlineCompletions` (ef680109cc3), which partially reduces noise but doesn't address the core ask of context-sensitive triggering. The existing workaround (setting `other` to `off`) is available but the discoverability and default-experience concern remains valid as a feature request.

## Change summary

Quick suggestions in HTML files trigger too aggressively when writing prose content, suggesting tags like `<a>` or `<div>` when typing ordinary English words.

## Best solution

Consider making the HTML language service contribute smarter trigger logic that suppresses suggestions when the cursor is in text content (outside of `<` contexts). Alternatively, improve discoverability of the `quickSuggestions.other` setting for content-heavy file types. The `suggest` area owns this.
