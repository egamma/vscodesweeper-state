# Issue #190172 — Autocomplete is too aggressive in its default setting

[https://github.com/microsoft/vscode/issues/190172](https://github.com/microsoft/vscode/issues/190172)

## Summary

Keep open for a decision on less intrusive HTML completion defaults. Existing settings mitigate the interruption, but they do not deliver the requested context-sensitive default behavior.

## Change summary

Make default HTML suggestions less intrusive while writing prose, including avoiding unintended completion acceptance when pressing Enter.

## Best solution

Decide whether HTML prose should suppress automatic abbreviation suggestions by default while preserving useful markup completions. Treat the existing quick-suggestion and Enter-acceptance settings as workarounds, not completion of the requested defaults change.
