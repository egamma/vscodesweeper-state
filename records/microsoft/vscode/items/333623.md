# Issue #333623 — Chat session emptied by checkpoint restore becomes permanently unreachable and flickers in the sessions list

[https://github.com/microsoft/vscode/issues/333623](https://github.com/microsoft/vscode/issues/333623)

## Summary

The defect is conclusively present on current main, and the author's open PR directly addresses it with regression coverage. Keep the issue open while https://github.com/microsoft/vscode/pull/333629 is reviewed and landed or otherwise resolved.

## Change summary

Restoring the first checkpoint can empty a previously used chat session, causing it to flicker while loaded and disappear permanently from the sessions list after eviction.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333629, which preserves the distinction between never-used sessions and previously used sessions whose requests were later removed, including synchronous shutdown persistence and regression tests.
