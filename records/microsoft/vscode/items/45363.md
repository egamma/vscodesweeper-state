# Issue #45363 — Settings editor should search known keys in object type settings

[https://github.com/microsoft/vscode/issues/45363](https://github.com/microsoft/vscode/issues/45363)

## Summary

Still valid: the settings editor search (LocalSearchProvider / SettingMatches) does not index known property keys within object-type settings. Searching 'editor active line number' won't surface `workbench.colorCustomizations` because `editorActiveLineNumber.foreground` is a sub-key of that object, not the setting's own key or description.

## Change summary

The settings editor should search known property keys of object-type settings (e.g. keys defined in `patternProperties` or `properties` of a setting's schema) so users can find the parent setting by searching for a sub-key name.

## Best solution

Extend `SettingMatches._doFindMatchesInSetting` in `src/vs/workbench/contrib/preferences/browser/preferencesSearch.ts` to also match against property names defined in the setting's JSON schema (from `properties`, `patternProperties`, or `additionalProperties` definitions) for object-type settings. This would let searches like 'editorActiveLineNumber' surface `workbench.colorCustomizations`.
