# Issue #52855 — VS Code was lost on shutdown with pending update

[https://github.com/microsoft/vscode/issues/52855](https://github.com/microsoft/vscode/issues/52855)

## Summary

The root cause — Inno Setup unable to close VS Code during a background update, leaving a broken installation — was directly addressed by CloseApplications=force in the installer (shipped 1.96.0), plus multiple follow-up hardening commits. The related canonical issue #246809 was closed in Dec 2025, and this long-standing tracker can be closed as completed.

## Change summary

VS Code disappears after shutdown with a pending update because the Inno updater deletes old files but fails to install new ones when it cannot properly close the running application.

## Best solution

Keep the shipped fix (CloseApplications=force in code.iss) and the follow-up hardening (skip concurrent Inno spawns, terminate COM surrogate before update, cross-app IPC coordination). No further change needed — reporters should be on 1.96+ where this is resolved.
