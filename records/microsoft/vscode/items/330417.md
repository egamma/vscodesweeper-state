# Issue #330417 — Agents window does not show the TODO checklist in Agent mode

[https://github.com/microsoft/vscode/issues/330417](https://github.com/microsoft/vscode/issues/330417)

## Summary

Traced conclusively in source: the agent-host adapter that feeds the Agents window has no mapping for todo/plan tool calls into the `toolSpecificData.kind === 'todoList'` shape that `ChatTodoListWidget` requires, so the checklist can never render for Agent-mode sessions, while the extension-host built-in `manageTodoListTool` does produce that shape for the local harness.

## Change summary

The Agents window shows no TODO checklist/progress list while an agent works in Agent mode, even though the same checklist renders correctly for local-harness chat sessions.

## Best solution

Add todo/plan-tool recognition to the agent-host tool-call pipeline: extend `ToolKind` in src/vs/platform/agentHost/common/meta/agentToolCallMeta.ts (currently only 'terminal' | 'subagent' | 'search' | 'read') and add a branch in src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/stateToProgressAdapter.ts (where 'terminal'/'search'/'subagent' toolSpecificData are already built) that emits `{ kind: 'todoList', todoList }` from the agent host's todo tool call, mirroring src/vs/workbench/contrib/chat/common/tools/builtinTools/manageTodoListTool.ts.
