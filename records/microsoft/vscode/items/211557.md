# Issue #211557 — BUG: TypeScript: Wrong indentation when pasting multiline code starting with comment

[https://github.com/microsoft/vscode/issues/211557](https://github.com/microsoft/vscode/issues/211557)

## Summary

Still reproduces on main: the auto-indent-on-paste logic in indentation.ts calculates incorrect indentation for pasted multiline code starting with a block comment (`/**`), because `getGoodIndentForLine` matches `/**` against the `increaseIndentPattern` and adjusts subsequent lines' indentation incorrectly.

## Change summary

Pasting multiline code starting with a block comment (`/** ... */`) produces wrong indentation for subsequent lines.

## Best solution

Fix the auto-indent-on-paste logic in `src/vs/editor/contrib/indentation/browser/indentation.ts` to handle pasted content whose first line is a block comment opener — the `getGoodIndentForLine` call should not treat `/**` as an indent-increase trigger when computing the offset for remaining pasted lines. The skipped test for issue #181065 in the test suite is closely related and should be unskipped as part of the fix.
