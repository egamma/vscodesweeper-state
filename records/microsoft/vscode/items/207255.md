# Issue #207255 — Incorrect editor.fontFamily causes VSCode and the host OS to hang on Linux

[https://github.com/microsoft/vscode/issues/207255](https://github.com/microsoft/vscode/issues/207255)

## Summary

Still reproducible on main: the editor.fontFamily setting accepts a trailing backslash without sanitization, which creates a malformed CSS font-family value that hangs the Chromium CSS parser, freezing VS Code and potentially the host OS on Linux.

## Change summary

A trailing backslash in editor.fontFamily causes VS Code and the host OS to hang on Linux because the invalid CSS value is passed unsanitized to the DOM.

## Best solution

Add input sanitization in the fontFamily validation path (EditorStringOption or BareFontInfo.getMassagedFontFamily) to strip or reject trailing backslashes before the value reaches the DOM style assignment in domFontInfo.ts.
