# Issue #350675 — Git: every change in .git reloads all loaded git originals, even unchanged ones

[https://github.com/microsoft/vscode/issues/350675](https://github.com/microsoft/vscode/issues/350675)

## Summary

The redundant reload path remains in current source: repository changes invalidate every cached original and change their shared etag inputs, even when their content is unchanged. Keep this open as a Git performance bug; the related tab-switching PR does not address this invalidation.

## Change summary

Avoid re-reading unchanged Git originals and spawning per-original Git processes after unrelated repository changes.

## Best solution

Make Git-original invalidation content-aware, with batched repository queries whose cost does not grow by spawning processes for each unchanged original. Preserve prompt updates for genuinely changed index and HEAD content; longer quick-diff retention is separate follow-up work.
