# Issue #348405 — Assisted permissions prompt despite matching saved allow rules

[https://github.com/microsoft/vscode/issues/348405](https://github.com/microsoft/vscode/issues/348405)

## Summary

Current source confirms that an Assisted reviewer can bypass evaluation of saved host allow rules. Keep this open to settle the precedence contract and documentation mismatch; existing tests establish intentional confirmation behavior but do not settle the saved-rule case.

## Change summary

Clarify whether matching saved allow rules should take precedence over an Assisted permissions reviewer requesting confirmation.

## Best solution

Establish and document the precedence between explicit saved grants and Assisted review across URL and file permissions. Preserve managed approval requirements and denials, and distinguish explicit grants from implicit workspace or sandbox defaults.
