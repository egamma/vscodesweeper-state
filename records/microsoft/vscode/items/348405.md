# Issue #348405 — Assisted permissions prompt despite matching saved allow rules

[https://github.com/microsoft/vscode/issues/348405](https://github.com/microsoft/vscode/issues/348405)

## Summary

The reported precedence is intentional in current VS Code: an Assisted reviewer’s requireApproval decision prevents host auto-approval. Current VS Code documentation describes this behavior and scopes saved approvals to Manual permissions.

## Change summary

Clarify whether saved URL allow rules should override an Assisted permissions reviewer’s request for confirmation.

## Best solution

Retain the explicit-confirmation requirement and explain the distinction between Manual and Assisted permissions. Any documentation promising different precedence should distinguish its applicable product and permission mode.
