# Issue #213214 — Hidden lines affordance should take entire editor width, in inline diff mode

[https://github.com/microsoft/vscode/issues/213214](https://github.com/microsoft/vscode/issues/213214)

## Summary

The requested full-width separator remains missing: inline diff layout reserves a separate gutter outside the editors that host the hidden-lines widgets. Keep this request open in the already-correct diff-editor area; the maintainer's explanation identifies the architectural boundary, not a decision to reject the improvement.

## Change summary

Extend hidden-lines separators across the external diff gutter in inline mode so they span the entire editor width.

## Best solution

Provide a visually continuous hidden-region affordance across the inline diff gutter and editor content, preserving gutter actions and existing reveal interactions. Keep side-by-side presentation unchanged.
