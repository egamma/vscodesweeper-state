# Issue #336722 — Workspace exception does not cover hidden home directories such as `~/.julia/dev`

[https://github.com/microsoft/vscode/issues/336722](https://github.com/microsoft/vscode/issues/336722)

## Summary

Confirmed on current main: hidden-home path matchers bypass the workspace exception and return a system-file result before normal edit-approval settings are evaluated. This is a bounded Copilot edit-confirmation bug that should remain open and route to the chat area.

## Change summary

Copilot repeatedly requests system-file approval when editing ordinary project files in a workspace beneath a hidden home directory such as `~/.julia/dev`.

## Best solution

Apply the existing approved-workspace exception consistently to hidden-home-directory protection while retaining confirmation for paths outside the workspace and for explicitly sensitive files.
