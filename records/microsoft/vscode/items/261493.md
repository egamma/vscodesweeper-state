# Issue #261493 — Chat in Editor should have same background as chat in panel

[https://github.com/microsoft/vscode/issues/261493](https://github.com/microsoft/vscode/issues/261493)

## Summary

Still reproduces on main: the chat editor explicitly uses `editorBackground` for its list background, whereas the panel uses the view pane's location-based background color. This mismatch causes accessibility contrast failures for elements designed against the panel's darker background.

## Change summary

Chat in Editor uses the standard editor background color instead of the same background used in Chat in Panel, breaking contrast ratios and visual consistency.

## Best solution

Align the chat editor widget's background color with the panel's by replacing `editorBackground` with the appropriate panel/sidebar background token (or a dedicated chat background color) in `src/vs/workbench/contrib/chat/browser/widgetHosts/editor/chatEditor.ts`, ensuring all chat elements meet contrast requirements regardless of host location.
