# Issue #261493 — Chat in Editor should have same background as chat in panel

[https://github.com/microsoft/vscode/issues/261493](https://github.com/microsoft/vscode/issues/261493)

## Summary

The background mismatch remains in current source: Chat in Editor uses editor.background, while the Chat view uses its panel or sidebar background. Keep this team-authored accessibility report open; the older related issue covers only input-border visibility, not the full surface mismatch.

## Change summary

Opening or moving Chat into an editor changes its background and disrupts component styling and foreground/background contrast.

## Best solution

Make equivalent Chat surfaces retain consistent, theme-aware backgrounds when moved into an editor, without changing embedded code-editor semantics. Verify todo, checkpoint, and input styling across dark, light, and high-contrast themes.
