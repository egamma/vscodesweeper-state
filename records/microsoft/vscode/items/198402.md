# Issue #198402 — Code OSS resets locale arg after update

[https://github.com/microsoft/vscode/issues/198402](https://github.com/microsoft/vscode/issues/198402)

## Summary

Keep open: multiple reporters confirmed the failure, and a maintainer identified a broken Code OSS restart with mismatched command-line arguments. Current source still routes language changes through application relaunch, but inspection does not establish whether today's Arch/Manjaro package reproduces it or contains a fix.

## Change summary

Changing the display language in Arch/Manjaro Code OSS fails to apply the locale and can restart into the default Electron application.

## Best solution

Make the language-change restart reopen Code OSS with the selected locale under the distribution's system-Electron launcher. First reproduce with the current package and distinguish application relaunch argument handling from distribution packaging and language-pack loading.
