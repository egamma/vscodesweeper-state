# Issue #156630 — Can the inputbox show a red outline for invalid filenames?

[https://github.com/microsoft/vscode/issues/156630](https://github.com/microsoft/vscode/issues/156630)

## Summary

Still valid on current main: the "New File..." quick pick does not validate filenames — typing an invalid name (e.g. containing `*`, `?`, `<`, etc.) shows a "Create New File (…)" entry with no warning, and accepting it proceeds without a red outline or error. Filed by a team member as polish; no commit has addressed it.

## Change summary

The "New File..." quick pick should show a red outline / error message for invalid filenames and block submission while the name is invalid.

## Best solution

Add filename validation in `src/vs/workbench/contrib/welcomeViews/common/newFile.contribution.ts` inside the `onDidChangeValue` handler: reuse the existing `validateFileName` helper from `src/vs/workbench/contrib/files/browser/fileActions.ts` to check the typed value, and when invalid, either hide the "Create New File" item or show a validation message on the quick pick. Also block `onDidAccept` from proceeding when the current text is invalid.
