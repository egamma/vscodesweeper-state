# Issue #321334 — Feature Request: Respect metered network connections on Linux (NetworkManager)

[https://github.com/microsoft/vscode/issues/321334](https://github.com/microsoft/vscode/issues/321334)

## Summary

VS Code already has metered connection support via the `network.meteredConnection` setting (auto/on/off), shipped in 1.110. In `auto` mode on Linux, it uses Chromium's Network Information API which reads from NetworkManager. Update downloads are suspended on metered connections.

## Change summary

Request to detect and respect metered network connections on Linux (NetworkManager) to suspend automatic updates.

## Best solution

Close as already implemented. The `network.meteredConnection` setting (default: `auto`) detects metered connections via Chromium's Network Information API, which integrates with NetworkManager on Linux. The update service, extension downloads, and Settings Sync all respect this. If the reporter finds it isn't working for their specific NetworkManager configuration, a new bug report with reproduction details would be appropriate.
