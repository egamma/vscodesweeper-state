# Issue #324560 — terminal tool resize doesn't resize like it does in the actual terminal

[https://github.com/microsoft/vscode/issues/324560](https://github.com/microsoft/vscode/issues/324560)

## Summary

Team-filed bug: the chat terminal tool mirror uses a fixed column count from the source terminal and doesn't reflow text on resize, unlike the actual terminal. The detached terminal mirror in chatTerminalCommandMirror.ts is created with a snapshot of the source cols and never updates on container resize. Still open on main.

## Change summary

Terminal output in chat tool cards doesn't reflow text when the chat panel is resized, unlike the real terminal which reflows properly.

## Best solution

The DetachedTerminalCommandMirror/DetachedTerminalSnapshotMirror should respond to container width changes by updating the detached terminal's column count and triggering a reflow, similar to how the real terminal's FitAddon works. The fix likely lives in chatTerminalCommandMirror.ts (resize the detached xterm on container resize) and chatTerminalToolProgressPart.ts (_handleResize should propagate new dimensions to the mirror).
