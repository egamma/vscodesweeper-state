# Issue #178994 — `terminal.goToRecentDirectory` is not shell-aware

[https://github.com/microsoft/vscode/issues/178994](https://github.com/microsoft/vscode/issues/178994)

## Summary

Valid feature request — the "Go to Recent Directory" command hardcodes `cd $path` (line 355 of terminalRunRecentQuickPick.ts), with no mechanism for non-shell REPLs (Julia, Python, etc.) to register a custom cd template via shell integration properties. Not yet implemented on main.

## Change summary

Allow REPL-like programs using shell integration to register a custom cd template string (e.g. `cd("$dir")`) so that "Go to Recent Directory" sends the correct command instead of always `cd $dir`.

## Best solution

Add support for a new shell integration property (e.g. `cdTemplate` via `OSC 633 ; P ; CdTemplate=... ST`) and consume it in `terminalRunRecentQuickPick.ts` where the cd command is constructed (currently hardcoded at line 355). The template would replace the hardcoded `cd ${path}` pattern, letting REPLs like Julia or Python customize directory-change syntax.
