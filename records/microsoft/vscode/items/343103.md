# Issue #343103 — Remote SSH agent host OOM when activating Agent conversations with large untracked binary files

[https://github.com/microsoft/vscode/issues/343103](https://github.com/microsoft/vscode/issues/343103)

## Summary

Confirmed agent-host crashes when opening Changes with large untracked binaries; current source still performs whole-file Base64 transfers. Keep this open while the two linked implementation candidates are reviewed and landed.

## Change summary

Opening Changes in an SSH-connected Agents window eagerly reads large untracked binaries and exhausts the remote agent-host heap.

## Best solution

Review and land the complementary safeguards in https://github.com/microsoft/vscode/pull/345124 and https://github.com/microsoft/vscode/pull/345290 so Changes avoids oversized reads and binary detection transfers only bounded initial bytes. Coordinate the shared encoder improvement without treating it alone as resolving whole-file transfer costs.
