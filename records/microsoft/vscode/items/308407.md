# Issue #308407 — Is there a way to prevent duplicate browser tabs from opening in a plugin?

[https://github.com/microsoft/vscode/issues/308407](https://github.com/microsoft/vscode/issues/308407)

## Summary

Legitimate feature request for extension API to reuse/navigate existing integrated browser tabs instead of always opening new ones. Currently in the Backlog Candidates community upvote process (started July 6, 2026). Should stay open for the community process to run its course.

## Change summary

Extensions calling `workbench.action.browser.open` always open a new browser tab with no API to reuse or identify an existing one.

## Best solution

Extend the integrated browser command or `simpleBrowser.api.open` with an option to reuse an existing tab by URL or a returned tab identifier, similar to how the internal `OpenBrowserToolData` already supports page reuse for agent tools. The `SimpleBrowserManager` already reuses a single `_activeView` internally — the extension-facing API just doesn't expose control over this. This likely belongs in the browser-integration area and could be addressed via new command arguments or a proposed extension API.
