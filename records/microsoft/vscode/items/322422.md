# Issue #322422 — 'Mark as Done' has no undo functionality

[https://github.com/microsoft/vscode/issues/322422](https://github.com/microsoft/vscode/issues/322422)

## Summary

The accidental-action recovery gap remains on current main: the session-header Mark as Done command archives immediately without offering the Undo notification already used by bulk archive actions. This team-authored issue must remain open, and no canonical issue was found.

## Change summary

Provide an immediate way to undo accidentally marking an Agents Window session as done from the toolbar beside New Chat.

## Best solution

After a single session is marked done, expose the same time-limited Undo experience used by bulk Mark as Done actions, restoring that session without requiring users to find and filter archived sessions.
