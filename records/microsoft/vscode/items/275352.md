# Issue #275352 — Widget doesn't line break on words

[https://github.com/microsoft/vscode/issues/275352](https://github.com/microsoft/vscode/issues/275352)

## Summary

Keep open: terminal suggestion details still use character-level wrapping rather than preserving words, and no existing setting covers the request. The older related editor issue concerns preserving explicit newlines, not the same observable symptom.

## Change summary

Prefer word-boundary line breaks in terminal suggestion details so names such as JoshBot remain readable.

## Best solution

Make suggestion-detail wrapping preserve words when they fit on a line, while retaining a fallback for oversized tokens and preserving deliberately formatted content. Consider the equivalent editor details surface alongside the terminal widget to keep their behavior consistent.
