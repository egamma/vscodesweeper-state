# Issue #300498 — No pencil icon to rename Copilot CLI or Claude Agent sessions

[https://github.com/microsoft/vscode/issues/300498](https://github.com/microsoft/vscode/issues/300498)

## Summary

Keep open: current main provides picker rename buttons for agent-host sessions, but still excludes contributed Copilot CLI sessions. The related implementation does not reference this team-authored issue, and no verified canonical owns the remaining request.

## Change summary

Provide the same discoverable pencil-button rename action for Copilot CLI and Claude Agent sessions as for local sessions.

## Best solution
