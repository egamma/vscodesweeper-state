# Issue #176316 — `contribShareMenu` proposed menus

[https://github.com/microsoft/vscode/issues/176316](https://github.com/microsoft/vscode/issues/176316)

## Summary

Keep open: this is an api-proposal tracking issue, and current source still gates both the share menus and provider API behind proposals. The implemented sharing experience does not complete API finalization; that decision remains with the API owners.

## Change summary

Finalize the share-menu extension contribution points and resolve their relationship to the unified share-provider API.

## Best solution

Have the API owners settle the stable sharing contract, including context-sensitive menu contributions and resource/selection semantics, then finalize or explicitly retire the proposals. Preserve this issue as the finalization tracker until that decision is complete.
