# Issue #114319 — Add config option for image root in markdown preview

[https://github.com/microsoft/vscode/issues/114319](https://github.com/microsoft/vscode/issues/114319)

## Summary

Valid, well-supported feature request (56 upvotes, Backlog milestone) for a markdown preview image-root setting. Not yet implemented — the attempted PR #300913 was closed without merging, and no equivalent capability exists on main.

## Change summary

Allow configuring a custom root path for resolving absolute image paths in the built-in markdown preview, so static-site-generator workflows (Hugo, Jekyll, Zenn) display images correctly.

## Best solution

Implement a `markdown.preview.imageRoot` setting in the built-in markdown extension (extensions/markdown-language-features) that prepends a workspace-relative path when resolving absolute image references — the approach from the closed PR #300913 was sound, just needs a maintainer-accepted implementation.
