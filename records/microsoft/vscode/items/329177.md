# Issue #329177 — remove "Modern UI" and retain the classic high-density IDE interface.移除“现代界面”，保留经典的高密度IDE界面。

[https://github.com/microsoft/vscode/issues/329177](https://github.com/microsoft/vscode/issues/329177)

## Summary

Keep this as product feedback: current settings address density and allow disabling Modern UI, but do not satisfy the explicit request to remove it permanently. The thread also reports that disabling it failed to restore the classic appearance, which should not be dismissed as resolved by the toggle.

## Change summary

Remove Modern UI permanently and retain the classic, high-density workbench rather than offering only an opt-out.

## Best solution

Have the workbench design owners explicitly resolve the permanent-classic-interface request against the announced transition direction. Separately establish which styles remain after disabling Modern UI so any restoration defect can be evaluated independently of the broader design preference.
