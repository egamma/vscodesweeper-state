[https://github.com/microsoft/vscode/issues/349895](https://github.com/microsoft/vscode/issues/349895)

## Summary

Keep open: independent Windows and macOS reports confirm that optional TLS client-certificate requests block Agent Host MCP sign-in. The current source retains the implicated shared-process transport; newer same-symptom reports do not qualify as canonical replacements under the re-review rules.

## Change summary

Agent Host MCP OAuth discovery fails before opening the browser when an authorization server requests an optional TLS client certificate.

## Best solution

Make Agent Host metadata discovery succeed without a client certificate when the server permits it, while preserving certificate validation and failures for mandatory client authentication. Keep this report as the older, specifically diagnosed tracking point; investigate ServiceNow issuer mismatch separately.
