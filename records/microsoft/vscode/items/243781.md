# Issue #243781 — Command palette can be triggered from issue reporter

[https://github.com/microsoft/vscode/issues/243781](https://github.com/microsoft/vscode/issues/243781)

## Summary

Still relevant on current main: the legacy issue reporter (auxiliary window path, which is still the default) does not suppress F1/Cmd+Shift+P, so the command palette can appear in it. The new wizard editor-pane path sidesteps this by opening in the workbench, but it defaults to off (`issueReporter.wizard.enabled: false`).

## Change summary

Pressing F1 or Cmd+Shift+P in the legacy auxiliary-window issue reporter opens the command palette, and dismissing it with Escape hides the reporter window.

## Best solution

Either suppress command-palette keybindings in the legacy auxiliary-window issue reporter (in `baseIssueReporterService.ts` keyboard handler), or retire the legacy path entirely by making the wizard editor-pane the default. Once the wizard is default, this bug goes away since the issue reporter is a normal editor pane where the command palette is expected behavior.
