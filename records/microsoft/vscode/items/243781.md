# Issue #243781 — Command palette can be triggered from issue reporter

[https://github.com/microsoft/vscode/issues/243781](https://github.com/microsoft/vscode/issues/243781)

## Summary

The bug remains source-reproducible on current main: the global keybinding service processes shortcuts from every registered auxiliary window, while Show All Commands has unconditional F1 and Cmd/Ctrl+Shift+P bindings. The default legacy issue reporter still opens in such a window, so this team-authored Backlog bug should remain open.

## Change summary

Prevent command-palette shortcuts from opening the palette while focus is in the issue reporter auxiliary window, and avoid the confusing reporter-window behavior after Escape.

## Best solution

Keep ordinary workbench shortcuts out of the legacy issue reporter window while preserving its form-specific keyboard behavior; scope the correction to the issue-reporter auxiliary surface rather than disabling command shortcuts in auxiliary editor windows generally.
