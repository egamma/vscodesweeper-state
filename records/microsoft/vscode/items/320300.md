# Issue #320300 — Allow Risk Assessment model calls to route to non-copilot endpoints

[https://github.com/microsoft/vscode/issues/320300](https://github.com/microsoft/vscode/issues/320300)

## Summary

Valid feature request: the risk assessment model selection is hardcoded to `vendor: 'copilot'` in `chatToolRiskAssessmentService.ts` (line 121), preventing BYOK/custom endpoints. An open PR (#320302) from the issue author already addresses this. Keep open pending PR review.

## Change summary

Allow the tool risk assessment model setting to route requests to non-Copilot endpoints (BYOK), matching the flexibility already available for the utility model.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/320302 (or an equivalent change) that removes the hardcoded `vendor: 'copilot'` filter in `src/vs/workbench/contrib/chat/browser/tools/chatToolRiskAssessmentService.ts` line 121, so the configured model ID can resolve against any registered language-model provider. The utility-model BYOK pattern (`chat.byokUtilityModelDefault`) is a good reference for the implementation shape.
