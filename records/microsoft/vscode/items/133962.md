# Issue #133962 — Terminal toggle size to content width acts unexpectedly wrt viewport dimensions, scroll bar and padding

[https://github.com/microsoft/vscode/issues/133962](https://github.com/microsoft/vscode/issues/133962)

## Summary

Keep this accepted terminal-layout bug open: the reporter confirmed it after the historical fix and reopened the issue. The newer scrollbar reports cover related symptoms but cannot replace this older, broader report under the re-review rules.

## Change summary

Repeatedly toggling terminal content-width sizing causes viewport movement, incorrect scrollbar geometry, and extra bottom padding.

## Best solution

Make content-width toggling preserve consistent viewport geometry and restore normal terminal layout when wrapping is re-enabled. First reproduce the remaining symptoms on current main and distinguish them from the related scrollbar issues before making a bounded layout fix.
