## Summary

Legitimate, well-diagnosed request: the AI-profile grouping in the terminal dropdown is a hardcoded name-based heuristic with no opt-out, confirmed in source — routing to the terminal area for a maintainer product decision on whether to add a setting.

## Change summary

Add a setting (or per-profile flag) to disable the automatic grouping of terminal profiles whose name contains 'claude' or 'copilot' into a separate 'AI' section in the terminal dropdown.

## Best solution

Add an opt-out (e.g. a `terminal.integrated.profiles.aiGrouping` setting or a per-profile `aiGroup: false` flag) in src/vs/workbench/contrib/terminal/browser/terminalMenus.ts around `isAiProfileName`/`isAiContributedProfile`/`splitProfiles`/`splitContributedProfiles`, so name-based heuristics don't misclassify user-named profiles like 'Claude Code'.
