# Issue #346771 — cmd prompt

[https://github.com/microsoft/vscode/issues/346771](https://github.com/microsoft/vscode/issues/346771)

## Summary

The reporter confirmed Windows 10 version 1607, which predates the documented terminal requirement of version 1809. This matches the intentional removal of winpty support, rather than an unexplained launch failure on a supported Windows version.

## Change summary

Command Prompt fails to launch in the integrated terminal on Windows 10 version 1607, including after trying the suggested ConPTY DLL setting.

## Best solution

Use a newer Windows version supported by current VS Code; restoring the removed winpty backend is not needed to resolve this support question.
