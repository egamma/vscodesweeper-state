# Issue #320724 — Show Current Git Branch in AI Agent Window

[https://github.com/microsoft/vscode/issues/320724](https://github.com/microsoft/vscode/issues/320724)

## Summary

A real gap remains on current main: the Agents Window tracks the active session's branch but does not present it in the title-bar workspace control or session header. With no comments or upvotes and unresolved placement/switching scope, this should remain open under discussion.

## Change summary

Show the active AI agent session's current Git branch, keep it current as repository state changes, and optionally provide branch switching.

## Best solution

Expose the active session branch alongside the workspace identity in the Agents Window, updating it from session workspace state. Treat quick branch switching as a separate product decision because changing an active agent's checkout has broader safety implications than displaying its branch.
