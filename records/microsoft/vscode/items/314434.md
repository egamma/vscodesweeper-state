# Issue #314434 — UI Pass: Showing selection better on sessions list

[https://github.com/microsoft/vscode/issues/314434](https://github.com/microsoft/vscode/issues/314434)

## Summary

Keep open as a selection-affordance design discussion. Current source distinguishes selection and keyboard focus, but neither the public thread nor the inspected history establishes that the requested persistent selection treatment has been settled.

## Change summary

Consider retaining an outline on the selected session instead of using a tab-like left-edge indicator.

## Best solution

Agree on a consistent visual distinction between the selected session, keyboard-focused row, and sticky session in the Sessions list, including when focus moves into chat. Preserve visible keyboard focus and high-contrast support whichever selection treatment is chosen.
