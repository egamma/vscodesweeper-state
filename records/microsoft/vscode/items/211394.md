# Issue #211394 — DECSCUSR 0 should reset to the user-defined cursorStyle

[https://github.com/microsoft/vscode/issues/211394](https://github.com/microsoft/vscode/issues/211394)

## Summary

The upstream xterm.js fix (PR #5265) landed Dec 20, 2024 and was integrated into VS Code via commit 292d0bd51af8 on Jan 6, 2025, shipping in 1.97.0. DECSCUSR 0 now correctly resets to the user-configured cursor style.

## Change summary

DECSCUSR 0 (reset cursor style) should restore to the user's configured terminal.integrated.cursorStyle rather than defaulting to block.

## Best solution

Keep the shipped fix — the xterm.js rendering layer now uses `decPrivateModes.cursorStyle ?? optionsService.rawOptions.cursorStyle`, falling back to the VS Code-configured option on reset. No further change needed.
