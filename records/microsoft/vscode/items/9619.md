# Issue #9619 — Cursor Up and Down should place the cursor at end of line if it's current state is end of line

[https://github.com/microsoft/vscode/issues/9619](https://github.com/microsoft/vscode/issues/9619)

## Summary

The command API already supports opt-in sticky end-of-line navigation, but the default End and Cmd+Right bindings still preserve the previous column. Keep this team-authored request open: no issue-referencing implementation commit or verified canonical establishes a factual close.

## Change summary

After moving to the end of a line, subsequent Up and Down movements should follow the ends of destination lines rather than preserve the original column.

## Best solution

Use the existing cursorEnd command with {"sticky": true} for Vim-style navigation. The area owner should determine whether this satisfies the original API request or whether changing the default End/Cmd+Right behavior remains desired; no new movement primitive is needed for the opt-in case.
