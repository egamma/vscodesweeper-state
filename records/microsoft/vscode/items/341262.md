# Issue #341262 — Screen reader does not announce extension count for Installed, Recommended, Enabled, and Disabled collapsible sections:A11y_VisualStudioCode_Extensions_Keyboard

[https://github.com/microsoft/vscode/issues/341262](https://github.com/microsoft/vscode/issues/341262)

## Summary

Thanks for the report. In the source, the extension section headers get an aria-label built only from the title, so the visible count badge is never exposed to screen readers. This looks like a real accessibility gap that is still open.

## Change summary

Extension view section headers (Installed, Recommended, Enabled, Disabled) show a count badge visually, but screen readers announce only the name and expanded or collapsed state.

## Best solution

Include the count in the extension view header's accessible name, or link the badge with aria-describedby. Keep the count updated whenever the badge count changes.
