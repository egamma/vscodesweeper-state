## Summary

Thanks for the report. The count badge in the Extensions view section headers is rendered visually, but the section header's accessible name does not appear to include it, so screen readers don't announce the count.

## Change summary

Screen readers don't announce the extension count shown next to the Installed, Recommended, Enabled and Disabled section headers in the Extensions view.

## Best solution

Include the count in the accessible name or description of the section header, for example via aria-label or aria-describedby on the header. Use the CountBadge in extensionsViews.ts, or the shared ViewPane header, as the place to do it.
