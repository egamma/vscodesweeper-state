# Issue #344465 — Chat session recent interaction label doesn't update

[https://github.com/microsoft/vscode/issues/344465](https://github.com/microsoft/vscode/issues/344465)

## Summary

The reported behavior could reflect the default creation-time sorting rather than a failed activity update. Establish which session list and sorting mode are affected before treating this as a defect; current source provides a Sort by Updated mode that changes both ordering and the displayed timestamp.

## Change summary

Chat sessions reportedly retain their previous relative timestamp and list position after further interaction.

## Best solution

Use the existing Sort by Updated option for activity-based ordering and timestamps. If sending and completing a new message still leaves that view unchanged, investigate the affected session provider's timing updates and list refresh path.
