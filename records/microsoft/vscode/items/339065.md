# Issue #339065 — Dictation cleanup: allow any chat model available to the user/organization instead of a hard-coded model ID

[https://github.com/microsoft/vscode/issues/339065](https://github.com/microsoft/vscode/issues/339065)

## Summary

Keep open in Backlog Candidates: current source still restricts dictation cleanup to two model IDs, so selecting another organization-enabled chat model remains unsupported. The community-review period has only recently begun, and no verified canonical issue absorbs this request.

## Change summary

Allow dictation cleanup to use a user-selectable chat model available to the current account or organization, with an optional visible indication when fallback occurs.

## Best solution

If accepted through community review, let dictation cleanup resolve an explicitly configured model against the user's available, user-selectable chat models while preserving dedicated core-only aliases, organization restrictions, and safe transcript fallback. Decide how unavailable-model fallback should be communicated without adding repetitive notifications.
