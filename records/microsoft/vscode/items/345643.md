# Issue #345643 — Quick Pick: Escape from a link focused inside an item tooltip leaves focus on body

[https://github.com/microsoft/vscode/issues/345643](https://github.com/microsoft/vscode/issues/345643)

## Summary

Keep open as the independently confirmed keyboard-focus bug accepted by the area maintainer. The tooltip layout fix does not address Escape losing the original focus target.

## Change summary

Dismissing a Quick Pick with Escape while its tooltip link is focused leaves focus on the document body instead of the originating input or editor.

## Best solution

Restore the pre-picker focus target when Escape dismisses the picker from an item tooltip, while preserving intentional focus changes outside the picker and the existing tooltip layout behavior.
