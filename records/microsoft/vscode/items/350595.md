# Issue #350595 — [Bug] New-tab button overlaps tabs when scrolling through multiple tabs.

[https://github.com/microsoft/vscode/issues/350595](https://github.com/microsoft/vscode/issues/350595)

## Summary

The current source permits the sticky new-tab button to cover scrolling pill tabs and their close controls. Connected tabs have dedicated clipping, but pill tabs do not; no verified canonical owns this remaining behavior.

## Change summary

Prevent the new-tab button from obscuring tab titles and intercepting tab-close clicks during horizontal scrolling.

## Best solution

Keep the new-tab action and tab-close controls independently usable throughout horizontal scrolling in both modern tab styles. Resolve the overlap within editor-tab layout without adding a placement setting or changing unrelated tab behavior.
