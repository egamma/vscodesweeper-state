# Issue #104130 — Warn when 'add item' will override an existing value?

[https://github.com/microsoft/vscode/issues/104130](https://github.com/microsoft/vscode/issues/104130)

## Summary

Still unfixed on main: the settings editor's map widgets (e.g. files.associations) silently overwrite existing keys without any duplicate-key validation or warning.

## Change summary

Adding an item in the settings editor with a key that already exists silently overwrites the previous value without warning.

## Best solution

Add duplicate-key validation in the object/list setting widgets (settingsWidgets.ts) so that when a user enters a key that already exists, an inline validation message warns them before the overwrite occurs — similar to the suggestion in comment 1.
