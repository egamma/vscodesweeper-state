# Issue #104130 — Warn when 'add item' will override an existing value?

[https://github.com/microsoft/vscode/issues/104130](https://github.com/microsoft/vscode/issues/104130)

## Summary

The Settings UI still accepts an existing object key without warning and overwrites its value. Keep this accepted Backlog bug open; the reported path is confirmed in current source, and no verified open canonical was found.

## Change summary

Warn before adding an object-setting entry whose key already exists replaces the existing value.

## Best solution

Provide an inline duplicate-key warning in the object-setting editor before submission, preserving the ability to deliberately replace a value and the normal behavior of editing an existing entry.
