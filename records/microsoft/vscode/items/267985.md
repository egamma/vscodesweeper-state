# Issue #267985 — NES - better rendering for same word replacement across multiple lines

[https://github.com/microsoft/vscode/issues/267985](https://github.com/microsoft/vscode/issues/267985)

## Summary

The requested multi-line word-replacement presentation remains missing from the ordinary NES rendering path. Keep this team-authored Backlog request open: existing rendering settings do not deliver it, and the older related report does not establish the same observable multi-line problem.
