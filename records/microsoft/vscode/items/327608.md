# Issue #327608 — Cloud Session: There is no way to mark cloud session PR as ready to review

[https://github.com/microsoft/vscode/issues/327608](https://github.com/microsoft/vscode/issues/327608)

## Summary

A real capability gap remains on current main: cloud-session draft pull requests can be opened but not marked ready for review from the Agents window. The issue is already correctly routed and should remain open.

## Change summary

Add an Agents-window action that marks a cloud session's draft pull request ready for review.

## Best solution

Add a draft-only “Ready for Review” primary action through the shared sessions GitHub contribution, backed by GitHub's ready-for-review mutation and refreshed PR state. Keep the behavior consistent across cloud and agent-host sessions.
