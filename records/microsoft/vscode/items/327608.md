# Issue #327608 — Cloud Session: There is no way to mark cloud session PR as ready to review

[https://github.com/microsoft/vscode/issues/327608](https://github.com/microsoft/vscode/issues/327608)

## Summary

Keep open: the cloud-session integration still lacks the requested in-window action to mark an existing draft PR ready for review. Existing Open Pull Request actions provide an external workaround, not the requested capability; this team-authored request has no verified fixing commit or canonical duplicate.

## Change summary

Provide a primary action in the Agents Window to mark a cloud session's draft pull request ready for review.

## Best solution

Allow cloud sessions with an eligible draft PR to transition it to ready for review from the session action bar, consistently with Agent Host sessions. Preserve the ability to open the PR externally and reflect the resulting PR state in the session.
