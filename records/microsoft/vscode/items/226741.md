Keep open: the current source still disconnects the hover's completion counter from completions fetched while IntelliSense is visible. This team-authored, accepted Backlog bug has no verified fixing commit or qualifying canonical duplicate.

## Change summary

The inline-completion hover loses its suggestion count when IntelliSense and ghost text are visible together.

## Best solution
