# Issue #176666 — Split View: Allow Snap To Content Size

[https://github.com/microsoft/vscode/issues/176666](https://github.com/microsoft/vscode/issues/176666)

## Summary

Valid feature request from a team member for split view panes to dynamically bind their size to content height. The existing snap mechanism only handles visibility toggling, not content-size tracking — the requested capability remains unimplemented on main.

## Change summary

Allow split view panes to snap to and dynamically track their content size, so panes auto-resize as content changes.

## Best solution

Introduce an optional content-size signal on IView (a preferred/snap-to size plus an event for when it changes) and teach the SplitView layout algorithm to honor it when a sash has been snapped to that size. The implementation lives in src/vs/base/browser/ui/splitview/splitview.ts and would benefit the debug sidebar and other view containers with variable-height content.
