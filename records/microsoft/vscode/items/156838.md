# Issue #156838 — Multiple comment decorations rendered when word wrap is turned on

[https://github.com/microsoft/vscode/issues/156838](https://github.com/microsoft/vscode/issues/156838)

## Summary

Still reproduces on main: the comment glyph decoration uses `linesDecorationsClassName` which renders the icon on every visual wrapped line. The fix is to use `firstLineDecorationClassName` instead, as folding already does.

## Change summary

Comment gutter glyphs are duplicated on every visual wrapped line when word wrap is enabled.

## Best solution

In `src/vs/workbench/contrib/comments/browser/commentGlyphWidget.ts`, change the decoration from `linesDecorationsClassName` to `firstLineDecorationClassName` so the glyph only appears on the first visual line of a wrapped logical line, consistent with folding icons.
