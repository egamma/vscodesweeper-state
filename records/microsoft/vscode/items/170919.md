# Issue #170919 — Enable localization of notebook renderers

[https://github.com/microsoft/vscode/issues/170919](https://github.com/microsoft/vscode/issues/170919)

## Summary

Keep open as an API proposal: current renderer activation still lacks built-in localization support, and the api-proposal label reserves completion and finalization decisions for the API owners. The related webview request does not replace this renderer-specific contract.

## Change summary

Provide extension-specific localization APIs and string bundles to notebook renderer scripts.

## Best solution

Define and finalize a renderer-scoped localization contract consistent with vscode.l10n, including correct bundle selection when several extensions' renderers share a notebook webview. Use the import-map proposal and closed demonstration PR as design evidence, not as proof of implementation.
