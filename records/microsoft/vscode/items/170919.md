## Summary

This feature request to enable l10n for notebook renderers via import maps is still unimplemented on main. PR #171545 is open but unmerged (a demo/proof-of-concept by the issue author). The Safari blocker mentioned in comments was resolved in Safari 16.4, so the approach is unblocked. Keeping open as valid, unfinished API work with a prototype PR in flight.

## Change summary

Enable localization (l10n) support for notebook renderer scripts, similar to existing extension localization, likely via import maps providing a `vscode-notebook-renderer` module with l10n APIs.

## Best solution

Land or iterate on the open PR https://github.com/microsoft/vscode/pull/171545 which demonstrates the import-map approach for per-renderer l10n APIs in `src/vs/workbench/contrib/notebook/browser/view/renderers/webviewPreloads.ts` and `backLayerWebView.ts`. The Safari import-map blocker is resolved. A maintainer should decide whether to finalize this proposed API or revisit the design.
