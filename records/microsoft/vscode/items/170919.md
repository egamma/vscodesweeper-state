# Issue #170919 — Enable localization of notebook renderers

[https://github.com/microsoft/vscode/issues/170919](https://github.com/microsoft/vscode/issues/170919)

## Summary

Still unimplemented on main — no l10n API or import-map support has landed in the notebook renderer infrastructure. An open demo PR (#171545) exists but hasn't merged. The feature remains a valid API proposal tracked under On Deck.

## Change summary

Expose the l10n localization API to notebook renderer scripts so they can localize their UI strings.

## Best solution

Land the import-map-based l10n API in the notebook renderer webview (webviewPreloads.ts), shipping the `vscode-notebook-renderer` module with an `l10n` namespace matching the extension API shape. The open PR https://github.com/microsoft/vscode/pull/171545 is a starting point; a maintainer should decide whether to revive it or start fresh.
