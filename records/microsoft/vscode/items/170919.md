# Issue #170919 — Enable localization of notebook renderers

[https://github.com/microsoft/vscode/issues/170919](https://github.com/microsoft/vscode/issues/170919)

## Summary

Keep this API proposal open for the notebook and localization owners. Current renderer activation does not expose the requested localization API, and API-proposal tracking issues must remain open until their owners finalize or abandon the contract.

## Change summary

Enable notebook renderer scripts to access extension-specific localization with an API matching extension localization support.

## Best solution

Provide a supported, renderer-specific localization API that selects the owning extension's translation bundle and works across supported desktop and web environments. Resolve and finalize the public contract through this proposal, coordinating with the related webview localization work.
