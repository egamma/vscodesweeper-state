# Issue #225807 — cursor placement of TSX tags does not work with some tailwind properties 

[https://github.com/microsoft/vscode/issues/225807](https://github.com/microsoft/vscode/issues/225807)

## Summary

Valid, unfixed bug in TSX/JSX auto-indentation when tag attributes contain a `/` character. Already triaged with `help wanted` on the `On Deck` milestone; no fix commit references this issue on current main.

## Change summary

Pressing Enter between opening and closing JSX tags does not auto-indent correctly when a tag attribute value contains a `/` character (e.g. Tailwind's `w-1/2`).

## Best solution

The fix likely belongs in `extensions/typescript-basics/language-configuration.json` (indentation or onEnter rules) or in the `IndentationContextProcessor` / `OnEnterSupport` logic in `src/vs/editor/common/languages/supports/`. The `/` in a string-valued attribute is probably interfering with the regex-based indentation evaluation — the `indentNextLinePattern` or the token-processing pipeline may be mishandling it. A contributor should debug the `_enter` path in `cursorTypeEditOperations.ts` with both the working (`w-[50%]`) and broken (`w-1/2`) cases to pinpoint the divergence.
