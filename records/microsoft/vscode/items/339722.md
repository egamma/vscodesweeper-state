# Issue #339722 — Agents - synthesis instructions input is not rendered correctly

[https://github.com/microsoft/vscode/issues/339722](https://github.com/microsoft/vscode/issues/339722)

## Summary

Team-authored bug filed while testing the new synthesis-instructions panel (PR #339373); traced a plausible root cause in sessionComparisonResult.ts — the input's flexible-height measurement runs while the panel is still `hidden`, caching a near-zero height that is never recomputed when the panel becomes visible, matching the screenshot's collapsed sliver box.

## Change summary

The 'Additional synthesis instructions' input box in the session comparison result view renders as a collapsed, nearly invisible sliver instead of a normal multi-line textbox.

## Best solution

In `renderSynthesisInstructions`'s `toggle()`, recompute the InputBox's flexible height (e.g. call `input.layout()`/re-run `updateMirror()`) after `panel.hidden` is cleared, so the cached height from construction-time (made while hidden) is corrected once the panel is actually visible.
