# Issue #200609 — Improve settings UI for array based setting types

[https://github.com/microsoft/vscode/issues/200609](https://github.com/microsoft/vscode/issues/200609)

## Summary

Valid UX improvement acknowledged by two team members — the Settings UI should differentiate between JSON-file examples and plain-value input expected in the UI. No fix has landed on main.

## Change summary

Array-based settings in the Settings UI show JSON-style examples that confuse users into entering full JSON syntax in the Add Item field.

## Best solution

The settings editor should either strip or visually distinguish JSON-syntax examples from the plain values the UI expects, or provide separate UI-specific placeholder/hint text for array item input fields. Work lives in `src/vs/workbench/contrib/preferences/browser/settingsTree.ts` and `settingsWidgets.ts`.
