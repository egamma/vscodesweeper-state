# Issue #344284 — Modern UI: Tab colors are inconsistent across the editor, Agents views, panels, and Pet Customization

[https://github.com/microsoft/vscode/issues/344284](https://github.com/microsoft/vscode/issues/344284)

## Summary

Keep open: current source still confirms inconsistent color handling in Agents panel tabs. Some shared styling has evolved since the report, but the supplied comparison matrix is sufficient to retest; the related background-mismatch issue does not cover this report's full scope.

## Change summary

Make equivalent Modern UI tab states honor applicable theme colors and user color customizations consistently across editor, Agents, and Pet Customization surfaces.

## Best solution

Establish a consistent color-precedence contract across these tab implementations and resolve the remaining mismatches, preserving intentional differences for controls without editor-specific states. Decide whether inactive session views should adopt unfocused editor-tab colors.
