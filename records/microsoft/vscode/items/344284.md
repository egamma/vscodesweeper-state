# Issue #344284 — Modern UI: Tab colors are inconsistent across the editor, Agents views, panels, and Pet Customization

[https://github.com/microsoft/vscode/issues/344284](https://github.com/microsoft/vscode/issues/344284)

## Summary

Keep open: current source confirms inconsistent color handling between Modern UI editor-style tabs and Agents panel/chat tabs. The detailed reproduction matrix is actionable, although not every reported combination was independently verified.

## Change summary

Make applicable theme colors and explicit color customizations behave consistently across Modern UI editor-style tab surfaces.

## Best solution

Establish consistent color precedence and state handling across the shared tab styles and their Sessions-owned adaptations, preserving intentional connected-surface and high-contrast behavior. Decide whether inactive session views should inherit editor-group unfocused colors before treating that optional part of the report as a defect.

Check inactive, active, hovered, active-hovered, and action-hover states; confirm connected fills and shoulders agree, and repeat in light, dark, and high-contrast themes.
- **Behavior:**

  > Equivalent Modern UI editor-style tabs should honor the same applicable color customizations and state precedence. The reported active-panel hover and connected-chat background inconsistencies should disappear without changing tab selection, actions, or navigation. Validate the report's matrix while retaining genuinely inapplicable states, such as editor modified indicators on non-editor tabs. Whether unfocused session views acquire editor-style unfocused colors remains a product decision.
- **Trace:**

  > Shared defaults and editor-style tab rules live in tabs.css and connectedEditorTabs.css. Sessions panelPart.css adapts only part of that color state to composite tabs, whose shared hover rule excludes checked items; chatCompositeBar.css overrides connected active and action backgrounds with the session surface. Pet customization also consumes shared styles through chatPetAchievements.css. These paths establish representative mismatches, but the full matrix and customization precedence still need auditing. Preserve classic styling, high-contrast treatment, connected geometry, and Sessions/workbench layer direction. The narrower report https://github.com/microsoft/vscode/issues/342406 is related but does not absorb this scope.
- **Open decisions:**
  - Should chat tabs in inactive session views use tab.unfocused* colors, or retain session-view styling independent of editor-group focus?
