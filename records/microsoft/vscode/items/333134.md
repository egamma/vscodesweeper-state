# Issue #333134 — Allow disabling Copilot harness built-in tools in Chat: Open Customizations

[https://github.com/microsoft/vscode/issues/333134](https://github.com/microsoft/vscode/issues/333134)

## Summary

Well-reasoned, brand-new feature request to let users disable individual Copilot-harness built-in tools (e.g. `task`) from the existing Tools customization UI; no maintainer has weighed in and no exact duplicate exists, so this should be routed to the chat/customizations area rather than closed.

## Change summary

Allow toggling/disabling individual Copilot built-in tools (like `task`) from Chat: Open Customizations → Tools, and surface them in Manage Tool Approval, instead of showing them as read-only.

## Best solution

A maintainer decision is needed on whether Copilot-harness built-in tools should become toggleable/approval-configurable in the Tools customization UI (chat.tools.eligibleForAutoApproval currently doesn't recognize them); likely belongs with the chat customizations / agent-host tooling owners rather than being auto-closed.
