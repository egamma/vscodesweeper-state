# Issue #333134 — Allow disabling Copilot harness built-in tools in Chat: Open Customizations

[https://github.com/microsoft/vscode/issues/333134](https://github.com/microsoft/vscode/issues/333134)

## Summary

Fresh, well-articulated feature request (3 days old, no reactions yet) asking to make Copilot's built-in tools (e.g. `task`) toggleable and subject to approval gating in the existing Tools customization UI. Current read-only behavior is confirmed intentional in code, but no existing setting covers the requested capability, so this stays open as a genuine, unresolved product ask.

## Change summary

Allow users to enable/disable and require approval for Copilot's built-in runtime tools (like `task`) from Chat: Open Customizations → Tools → Copilot, instead of them being permanently read-only.

## Best solution

A maintainer decision is needed on whether Copilot built-in tools (surfaced via the static 'copilot-cli' tool set in toolsListWidget.ts) should become configurable — likely requiring the harness/SDK to accept a disabled-tools list and the enablement service to persist per-tool state for that set, plus wiring into chat.tools.eligibleForAutoApproval / Manage Tool Approval.
