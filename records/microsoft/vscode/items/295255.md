# Issue #295255 — Option + left-mouse click causes screen to go blank in interactive programs (like pagers, e.g. less), making copy/paste tedious

[https://github.com/microsoft/vscode/issues/295255](https://github.com/microsoft/vscode/issues/295255)

## Summary

Current behavior is intentional — Option+click sends cursor-repositioning escape sequences by default (`altClickMovesCursor`). The existing setting `terminal.integrated.macOptionClickForcesSelection` (disabled by default) is designed exactly for this use case: it forces regular selection mode when Option+clicking, even when mouse mode is active in programs like less/tmux.

## Change summary

Option+click in terminal interactive programs (pagers like less) causes screen to go blank because escape sequences are sent to reposition the cursor.

## Best solution

The reporter should enable `terminal.integrated.macOptionClickForcesSelection` (and optionally disable `terminal.integrated.altClickMovesCursor`). The existing settings cover this scenario by design. No code change needed.
