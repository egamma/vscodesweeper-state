# Issue #134322 — Git - git setting `core.excludesFile` is ignored if placed inside an include.path of ~/.gitconfig

[https://github.com/microsoft/vscode/issues/134322](https://github.com/microsoft/vscode/issues/134322)

## Summary

Still valid on main: VS Code never resolves `core.excludesFile` itself — it only toggles ripgrep's `--no-ignore-global` — so a value defined behind a gitconfig `include.path` is lost in ripgrep's own gitconfig parsing. Root cause is upstream, so this stays open and is better routed to search than git.

## Change summary

`core.excludesFile` set in a file pulled in via `[include] path = …` from ~/.gitconfig is not honored by VS Code search when `search.useGlobalIgnoreFiles` is enabled.

## Best solution

Fix belongs upstream in ripgrep's ignore crate (gitconfig `include.path` resolution); if the team wants a core-side mitigation, VS Code could resolve `git config --includes --global --path core.excludesFile` and pass the resulting file to ripgrep explicitly from src/vs/workbench/services/search/node/ripgrepFileSearch.ts / ripgrepTextSearchEngine.ts.
