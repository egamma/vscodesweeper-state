# Issue #293114 — Copilot Chat extension slows down VSCode operations in large git repos

[https://github.com/microsoft/vscode/issues/293114](https://github.com/microsoft/vscode/issues/293114)

## Summary

Keep open: the nodejs/node workspace and first-search/file-creation steps suffice to retest this performance regression. Copilot's search filtering has changed since the report, but neither the later filtering fix nor the related reports establish that this particular startup slowdown is resolved.

## Change summary

With Copilot enabled, initial workspace searches and file creation in large Git repositories become excessively slow and consume high CPU.

## Best solution

Reproduce the cold-workspace scenario and identify the busy process before changing Copilot's initialization, indexing, or repository-discovery path. Normal Search, file creation, and Git operations should remain responsive while background Copilot work runs, without weakening content exclusions.
