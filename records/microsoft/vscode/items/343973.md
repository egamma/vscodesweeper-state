# Issue #343973 — Changing the model in an already started bakeoff doesn't reflect the new model in the judge

[https://github.com/microsoft/vscode/issues/343973](https://github.com/microsoft/vscode/issues/343973)

## Summary

The Judge's manifest still identifies attempts using their launch-time model, even when the underlying session uses another model. Keep this team-authored report open; the source confirms stale attribution, while the documented fixed-model comparison contract needs reconciliation with model switching.

## Change summary

Make the Judge recognize when an attempt is continued with a different model instead of attributing the entire attempt to its original model.

## Best solution

Preserve the original comparison configuration while making changed-model attempts explicit in the Judge's evidence. Settle how mixed-model attempts are represented so a continuation is not misleadingly presented as a single-model result.
