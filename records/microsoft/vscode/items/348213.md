## Summary

Keep open: independent macOS and Linux reports confirm blocked work and incorrect human-rejection feedback. Current source deliberately keeps Assisted Autopilot unattended, but that does not resolve the reported assessment failures, malformed recovery evidence, or misleading attribution.

## Change summary

Investigate Assisted Autopilot permission failures that block routine work and incorrectly describe automatic denials as user rejections.

## Best solution

Separate intentional unattended denials from defective assessment, recovery, and attribution behavior across the Copilot runtime and Agent Host boundary. Preserve permission enforcement while ensuring unavailable approval is accurately reported and does not corrupt subsequent permission recovery.
