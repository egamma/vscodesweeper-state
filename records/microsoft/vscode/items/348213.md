# Issue #348213 — Autopilot with Assisted approvals denies tool calls without prompting since agent runtime 1.0.108

[https://github.com/microsoft/vscode/issues/348213](https://github.com/microsoft/vscode/issues/348213)

## Summary

Keep open to investigate malformed permission-recovery evidence and incorrect user-rejection attribution, independently confirmed on macOS and Linux. Current source deliberately keeps Assisted Autopilot unattended, so the absence of a prompt alone does not establish a defect.

## Change summary

Assisted Autopilot blocks tool execution after unattended denials, sometimes producing recovery errors and falsely attributing the denial to the user.

## Best solution

Preserve permission enforcement and deliberate unattended behavior while ensuring fallback denials carry accurate provenance and do not corrupt subsequent Assisted assessments. Diagnose the VS Code–SDK contract separately from judge-model recommendation quality.
