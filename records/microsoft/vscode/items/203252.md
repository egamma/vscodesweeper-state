# Issue #203252 — Running an extension via debugging does not include it in the Issue Reporter Dropdown

[https://github.com/microsoft/vscode/issues/203252](https://github.com/microsoft/vscode/issues/203252)

## Summary

The defect remains on current main: issue-reporter extension options are populated from installed-extension scans, which omit an unpacked extension running under development. This team-authored Backlog bug should remain open.

## Change summary

Include an extension running in an Extension Development Host in the Issue Reporter extension dropdown.

## Best solution

Include enabled runtime extensions under development in the Issue Reporter's extension data, alongside installed extensions and without duplicate entries, for both the wizard and classic reporter paths.
