# Issue #280698 — Not clear which chat items are expandable

[https://github.com/microsoft/vscode/issues/280698](https://github.com/microsoft/vscode/issues/280698)

## Summary

The disclosure affordance remains discoverable only through hover on collapsed chat items, and the maintainer discussion confirms this is an unresolved consistency concern. Keep this team-authored request open for a deliberate chat UX decision.

## Change summary

Make expandable chat activity items identifiable at a glance and consider replacing uniform completion checkmarks with tool-specific icons.

## Best solution

Define a consistent visual contract for expandable versus status-only chat rows, with a persistent collapsed-state disclosure affordance that does not depend on hover. Decide separately whether activity-type icons should replace or supplement completion status.

- **Open decisions:**
