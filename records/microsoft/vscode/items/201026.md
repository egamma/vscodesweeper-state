# Issue #201026 — Keyboard shortcuts should flash corresponding menubar command's menu

[https://github.com/microsoft/vscode/issues/201026](https://github.com/microsoft/vscode/issues/201026)

## Summary

This is a feature request for macOS-native menu flash behavior when keyboard shortcuts are used. VS Code's architecture intentionally handles keybindings in the renderer process rather than delegating to native menu accelerators, which prevents the flash. The current label 'bug' is inaccurate — this is expected behavior given the custom keybinding system.

## Change summary

On macOS, pressing a keyboard shortcut (e.g. Cmd+C) should cause the corresponding menu bar item to flash, matching native app behavior.

## Best solution

Reclassify as feature-request. The fix would require Electron-level support to programmatically flash a native menu item after VS Code processes a keybinding internally, or to route certain keybindings through the native accelerator path. This is a polish improvement that would need investigation into Electron's Menu API capabilities. Low community signal (0 upvotes) suggests parking in backlog.
