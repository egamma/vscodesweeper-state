# Issue #42786 — [json] Automatically add required fields to object

[https://github.com/microsoft/vscode/issues/42786](https://github.com/microsoft/vscode/issues/42786)

## Summary

A real gap remains: current JSON IntelliSense can use schema-authored default snippets, but it does not automatically construct an object from its required properties. The request should remain open under discussion rather than be closed for age or mistaken for an existing capability.

## Change summary

Generate JSON object completion snippets containing every property marked required by the applicable schema.

## Best solution

Enhance `vscode-json-languageservice` object-value completion to synthesize required properties when the schema provides no explicit default or `defaultSnippets`, with defined behavior for nested objects and schema combinators; then consume the updated service in VS Code.

## Evidence

- **current completion behavior:** Current `vscode-json-languageservice/src/services/jsonCompletion.ts` generates object value proposals from `default`, `examples`, or the VS Code-specific `defaultSnippets`; its fallback for an object is an empty `{$1}` snippet and it does not inspect the schema's `required` array.
- **existing capability is partial:** A schema author can explicitly provide `defaultSnippets`, but that does not satisfy the request to derive a snippet automatically from standard JSON Schema `required` properties.
