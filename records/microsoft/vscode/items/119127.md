# Issue #119127 — [Request] [Notebook] Allow notebook webview to have access to media devices

[https://github.com/microsoft/vscode/issues/119127](https://github.com/microsoft/vscode/issues/119127)

## Summary

Still valid: the permission handler in app.ts explicitly grants 'media' to the core window but not to webviews — notebook output webviews (vscode-webview:// scheme) are denied media device access. No fix has landed.

## Change summary

Allow notebook webview outputs to access media devices (microphone/camera) via getUserMedia, which is currently blocked by Electron's permission handler.

## Best solution

Add 'media' to `allowedPermissionsInWebview` in src/vs/code/electron-main/app.ts (or conditionally for notebook webviews), ideally with a user-consent prompt rather than a blanket allow, since webview content is extension-authored and less trusted than core UI.
