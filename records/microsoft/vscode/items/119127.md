# Issue #119127 — [Request] [Notebook] Allow notebook webview to have access to media devices

[https://github.com/microsoft/vscode/issues/119127](https://github.com/microsoft/vscode/issues/119127)

## Summary

Keep open: notebook outputs still lack a consent-gated path to microphone and camera access. This team-authored, accepted Backlog request has 41 upvotes; the related open webview proposal is newer and cannot replace it under the re-review duplicate rules.

## Change summary

Allow notebook output JavaScript to request microphone and camera access with explicit user consent.

## Best solution

Provide a notebook-compatible, consent-gated media-device capability while preserving denial for content without permission. Coordinate with https://github.com/microsoft/vscode/issues/323602, ensuring any general webview design also covers notebook outputs rather than only extension-owned panels.
