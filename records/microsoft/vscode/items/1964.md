# Issue #1964 — Add fuzzy search to commands in palette

[https://github.com/microsoft/vscode/issues/1964](https://github.com/microsoft/vscode/issues/1964)

## Summary

Keep open: current command matching and similar-command suggestions partially address the request, but do not provide general within-word fuzzy abbreviation matching. This accepted Backlog request has 30 upvotes and needs a matching-and-ranking decision, not a staleness close.

## Change summary

Allow shortened, non-contiguous character queries to find commands in the Command Palette without making relevant results harder to find.

## Best solution

Support within-word fuzzy abbreviations in the Command Palette while preserving useful full-word matches and predictable ordering. Settle how these additional matches interact with existing word matching, command history, and similar-command suggestions before implementation.
