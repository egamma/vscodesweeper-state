# Issue #186299 — Consider to bubble up partially checked state

[https://github.com/microsoft/vscode/issues/186299](https://github.com/microsoft/vscode/issues/186299)

## Summary

The partially-checked (indeterminate) state for tree view checkboxes has not been implemented — `TreeItemCheckboxState` still only has `Checked` and `Unchecked`. The issue is in the Backlog milestone and was authored by a core team member (bpasero); it should stay open.

## Change summary

Add support for an indeterminate/partially-checked checkbox state on parent tree items when some but not all children are checked.

## Best solution

Extend `TreeItemCheckboxState` in `src/vs/workbench/api/common/extHostTypes.ts` with an `Indeterminate` value, wire it through the tree view checkbox rendering in `src/vs/workbench/browser/parts/views/checkbox.ts` and the extension host tree views API, and expose it to extensions. The existing tree-views area label is correct routing.
