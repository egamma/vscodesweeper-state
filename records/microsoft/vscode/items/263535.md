# Issue #263535 — Copilot Autocomplete with local / custom models

[https://github.com/microsoft/vscode/issues/263535](https://github.com/microsoft/vscode/issues/263535)

## Summary

This remains a valid, highly supported Backlog request: current main still limits inline completions to Copilot-hosted completion models, while BYOK providers serve chat models. An exact implementation PR is open, so the issue should remain open while that work is reviewed.

## Change summary

Allow Copilot inline autocomplete to use local or custom OpenAI-compatible models, including while offline.

## Best solution

Review and either land or explicitly resolve the design concerns in https://github.com/microsoft/vscode/pull/322465, preserving the hosted completion path while adding a policy-aware custom endpoint path for suitable completion models. Keep this older, higher-signal issue as the request owner rather than moving it under the younger https://github.com/microsoft/vscode/issues/318545.
