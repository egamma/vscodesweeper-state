# Issue #263535 — Copilot Autocomplete with local / custom models

[https://github.com/microsoft/vscode/issues/263535](https://github.com/microsoft/vscode/issues/263535)

## Summary

Keep this accepted, strongly supported request open: the inspected completion pipeline does not offer supported local/custom model selection or tokenless offline operation. The overlapping request is newer, and an open implementation candidate should be reviewed rather than treating the capability as shipped.

## Change summary

Allow Copilot ghost-text autocomplete to use local or custom models, including completely offline operation.

## Best solution

Deliver supported custom-endpoint ghost-text completions with reliable insertion behavior and offline initialization, while preserving hosted completions and respecting enterprise controls. Evaluate https://github.com/microsoft/vscode/pull/322465 against those requirements and the maintainer's latency and model-compatibility concerns before starting another implementation.
