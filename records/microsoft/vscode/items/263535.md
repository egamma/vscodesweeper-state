# Issue #263535 — Copilot Autocomplete with local / custom models

[https://github.com/microsoft/vscode/issues/263535](https://github.com/microsoft/vscode/issues/263535)

## Summary

Valid, well-supported feature request (190 upvotes, promoted to Backlog) for BYOK/custom model support in inline completions. A team member acknowledged technical challenges but the request remains active with strong community interest. This is the canonical issue for the ask.

## Change summary

Allow users to configure custom or local models (via OpenAI-compatible API) for Copilot inline code completions, not just chat.

## Best solution

Implement BYOK model support for inline completions, reusing the OpenAI-compatible endpoint pattern already used for chat. The completion model selection logic in `extensions/copilot/src/extension/completions-core/` would need to accept custom model endpoints rather than silently falling back to the default. Consider #318545 as a satellite duplicate of this canonical issue.
