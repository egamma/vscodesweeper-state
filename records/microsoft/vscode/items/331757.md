# Issue #331757 — Floating left side bar is missing in version 1.134

[https://github.com/microsoft/vscode/issues/331757](https://github.com/microsoft/vscode/issues/331757)

## Summary

Current Modern UI intentionally presents the Activity Bar and Primary Side Bar as one connected floating surface rather than two separately floating cards, so the reported appearance is by design.

## Change summary

Restore the Primary Side Bar as a distinct floating card in Modern UI instead of visually joining it to the Activity Bar.

## Best solution

Retain the connected Activity Bar and Primary Side Bar cluster, which deliberately expresses the two related navigation surfaces as one floating unit.

## Evidence

- **intentional current design:** src/vs/workbench/browser/media/floatingPanels.css explicitly documents that the Primary Side Bar meets the Activity Bar flush so they read as one connected surface; the facing margin, border, and corner radii are deliberately removed.
- **layout implementation:** getFloatingPaneCompositeHorizontalMargins in src/vs/workbench/services/layout/browser/layoutService.ts mirrors the CSS and deliberately uses the inner margin when the Primary Side Bar meets a visible Activity Bar.
- **design commit:** https://github.com/microsoft/vscode/commit/cb2cfdc6c5c44466f2e289a0861f65a74a0261fe introduced the documented connected-surface treatment, including square facing corners and a shared seam between the Activity Bar and Primary Side Bar.
