# Issue #291160 — Agent Status toggle applies to all windows

[https://github.com/microsoft/vscode/issues/291160](https://github.com/microsoft/vscode/issues/291160)

## Summary

Still reproduces on main: the filter is stored via `StorageScope.PROFILE` (shared across windows), so toggling the unread filter from any window's title-bar badge writes to shared storage and affects all windows. The `_badgeFilterAppliedByThisWindow` guard only prevents auto-clearing cross-window, not the initial propagation.

## Change summary

Pressing the unread sessions button in the title bar applies the filter state to all open VS Code windows instead of only the current one.

## Best solution

Change `_storeFilter` to use `StorageScope.WORKSPACE` (or a window-scoped mechanism) so the badge-driven filter is local to the window that triggered it, or split the storage key per window ID.
