# Issue #291160 — Agent Status toggle applies to all windows

[https://github.com/microsoft/vscode/issues/291160](https://github.com/microsoft/vscode/issues/291160)

## Summary

Keep open: the unread title-bar button still writes a shared profile filter, which other windows consume and apply. The existing per-window guard prevents another window from automatically clearing the filter, but does not isolate the toggle itself.

## Change summary

Make the Agent Status unread-session toggle affect only the window where it is clicked.

## Best solution

Keep title-bar badge filtering and restoration local to the invoking window, with its Agent Sessions view and badge reflecting the same state. Preserve provider selections and avoid changing unrelated persisted filter preferences across the other session-list surfaces.
