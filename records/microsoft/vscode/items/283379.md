# Issue #283379 — Clean up streaming codeblocks + edits

[https://github.com/microsoft/vscode/issues/283379](https://github.com/microsoft/vscode/issues/283379)

## Summary

Keep open: current source still constructs edit codeblocks from separate markdown fences and URI parts, then parses that metadata during rendering. The cleanup remains relevant, but the stream contract and extension-facing scope need agreement before implementation.

## Change summary

Simplify streamed edit codeblocks so their URI, content, and asynchronous edits have an explicit association rather than depending on markdown sequencing.

## Best solution

Establish a coherent representation for streamed edit codeblocks across response production, model storage, and rendering while preserving asynchronous edit association and undo behavior. Settle whether this is an internal cleanup or an extension-facing API change before implementing it.
