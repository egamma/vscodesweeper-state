# Issue #323982 — I cannot not see worktree function

[https://github.com/microsoft/vscode/issues/323982](https://github.com/microsoft/vscode/issues/323982)

## Summary

This is a question about worktree availability, rather than an established subscription-related regression. Built-in Git worktree commands do not require Copilot, and the chat isolation picker is a separate, session-specific capability.

## Change summary

Clarify whether worktree functionality requires a Copilot subscription and why the isolation option appears in Copilot CLI sessions.

## Best solution

Answer the distinction between ordinary Git worktrees and agent-session isolation here: provide the subscription-independent Git command and explain the CLI session picker without claiming that every chat mode supports automatic isolation.

- **Proposed comment:**

  > Thanks for the question. Git worktrees themselves do not require a Copilot subscription: with a Git repository open, run **Git: Create Worktree** (`git.createWorktree`) from the Command Palette.
  > 
  > The **Workspace / Worktree** picker in Copilot CLI sessions controls isolation for that session type; it is separate from the built-in Git commands and is not an option shared by every chat mode. Seeing it in CLI mode but not another chat mode does not by itself indicate a subscription restriction.
