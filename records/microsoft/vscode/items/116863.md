# Issue #116863 — SCM - Action "Move to Next Change" not working in Open Source Control tab

[https://github.com/microsoft/vscode/issues/116863](https://github.com/microsoft/vscode/issues/116863)

## Summary

Still reproduces on main: GotoNextChangeAction and GotoPreviousChangeAction are registered as EditorAction (requiring editor focus), so they silently no-op when invoked from the command palette while the SCM viewlet is focused. The keybinding works because it has `kbExpr: EditorContextKeys.editorTextFocus`, which routes it to the last focused editor.

## Change summary

"Go to Next/Previous Change" commands do nothing when invoked from the command palette while the SCM view is focused, because they are EditorActions that require an active editor.

## Best solution

Migrate GotoNextChangeAction and GotoPreviousChangeAction from EditorAction to workbench-level actions (as alexdima suggested in the original thread) so they can resolve the active editor even when focus is in the SCM viewlet. The fix lives in src/vs/workbench/contrib/scm/browser/quickDiffWidget.ts.
