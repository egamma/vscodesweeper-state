# Issue #321162 — Feature request: Option to disable "Keep/Undo" confirmation popup when discarding Copilot Agent changes

[https://github.com/microsoft/vscode/issues/321162](https://github.com/microsoft/vscode/issues/321162)

## Summary

Keep open: existing settings suppress request-removal confirmation, but the bulk Undo action still asks for confirmation without an opt-out. The related requests do not satisfy the stronger duplicate bar for this re-reviewed item.

## Change summary

Allow users to suppress confirmation when explicitly discarding agent edits without automatically accepting those edits.

## Best solution

Provide an explicit opt-out for the remaining bulk-discard confirmation while preserving manual review and undo. First distinguish the reporter's popup from request-removal confirmation and the editor's Keep/Undo controls, which already follow different paths.
