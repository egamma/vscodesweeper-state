# Issue #339997 — Remote agent host: large chat history exceeds tunnel gateway frame limit and causes terminal timeout

[https://github.com/microsoft/vscode/issues/339997](https://github.com/microsoft/vscode/issues/339997)

## Summary

The gateway still uses default WebSocket limits and returns on forwarding errors without explicitly notifying the client. Keep this diagnosed, team-authored report open: the older large-snapshot report concerns a different size boundary and does not establish that its implementation work covers this gateway defect.

## Change summary

Large chat snapshots exceed the tunnel gateway's 16 MiB frame limit, interrupting the shared connection and surfacing as a misleading terminal timeout.

## Best solution

Make the CLI gateway and tunnel client honor consistent bounded payload limits, and surface forwarding failures promptly rather than through a terminal heartbeat timeout. Coordinate with the ongoing protocol fragmentation work while retaining explicit coverage for both TCP and socket gateway targets.
