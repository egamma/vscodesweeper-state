# Issue #339997 — Remote agent host: large chat history exceeds tunnel gateway frame limit and causes terminal timeout

[https://github.com/microsoft/vscode/issues/339997](https://github.com/microsoft/vscode/issues/339997)

## Summary

Keep open: the current tunnel gateway still relies on default WebSocket limits and drops forwarding after a target read error, matching the reported oversized-history rejection and timeout loop. The October 19 confirmation on Stable 1.142.0 includes gateway logs and a successful direct-WebSocket comparison.

## Change summary

Large Agent Host chat snapshots exceed the tunnel gateway's frame limit, preventing session loading and surfacing misleading terminal connection timeouts.

## Best solution

Make the gateway transport support the same bounded payload range as the tunnel client across TCP and socket targets, and make oversized-payload failures terminate promptly with a meaningful reason. Preserve conversation history; pagination or history-size optimization should not be prerequisites for correcting this transport mismatch.
