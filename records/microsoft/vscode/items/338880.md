# Issue #338880 — Subagent invoked by a custom agent reports `tool_search` unavailable and cannot load deferred tools

## Summary

Same author filed a more detailed root-cause report (https://github.com/microsoft/vscode/issues/336376) two weeks earlier describing exactly this defect — subagents get mandatory `tool_search`-before-use instructions even though the Responses API disables tool search/deferral for subagent requests, so the subagent stalls trying to discover a tool that was never deferred in the first place. That issue is open and already assigned to a maintainer, so this narrower report should consolidate there.
