# Issue #336171 — Feature: Support extraBody configuration for BYOK custom models

[https://github.com/microsoft/vscode/issues/336171](https://github.com/microsoft/vscode/issues/336171)

## Summary

Legitimate, well-specified feature request: BYOK custom-model config on main only supports `temperature`/`top_p` in `modelOptions`, with no generic body-merging mechanism, so users of OpenAI-compatible endpoints requiring extra fields (reasoning_effort variants, chat_template_kwargs, etc.) have no way to configure them.

## Change summary

Add an `extraBody` field to BYOK custom-model capabilities so arbitrary extra request-body fields can be merged in for OpenAI-compatible endpoints.

## Best solution

Extend `BYOKModelCapabilities`/`IChatModelRequestOptions` (or add a sibling field) with an `extraBody?: Record<string, unknown>` that `OpenAIEndpoint._applyConfiguredModelOptions` merges into the request body after existing options, with per-request params still taking precedence; belongs in `extensions/copilot/src/extension/byok/`.
