# Issue #343943 — Last used and storage headers should be clickable for sorting

[https://github.com/microsoft/vscode/issues/343943](https://github.com/microsoft/vscode/issues/343943)

## Summary

Keep open: the worktree cleanup editor still has static Last Used and Storage headers, with no user-selectable sorting. Existing filters and default size ordering only partially cover this team-authored request.

## Change summary

Allow users to sort worktree cleanup rows by clicking the Last Used and Storage column headers.

Provide accessible column sorting in the worktree cleanup editor so users can compare age and storage before selecting worktrees, while preserving cleanup eligibility and selection safeguards.
