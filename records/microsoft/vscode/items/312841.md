# Issue #312841 — Add a warning when a policy is set but it's value does not parse

[https://github.com/microsoft/vscode/issues/312841](https://github.com/microsoft/vscode/issues/312841)

## Summary

Valid enhancement request from a team member to surface a user-visible warning when a policy value fails to parse, rather than silently logging the error. Routing to the `gpo` area for visibility.

## Change summary

When a policy value fails to parse (e.g. malformed JSON), VS Code only logs the error — org admins debugging policy rollouts get no visible indication that their policy configuration is broken.

## Best solution

Add a user-visible notification (e.g. via `INotificationService.warn()`) in `PolicyConfiguration.update()` (src/vs/platform/configuration/common/configurations.ts, around line 254) when `this.parse(policyValue)` throws, so admins get an actionable warning instead of a buried log entry. The notification should name the offending policy and include the parse error.
