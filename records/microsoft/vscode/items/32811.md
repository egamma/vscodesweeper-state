# Issue #32811 — No way to have tab show as eight spaces, indent with something else

[https://github.com/microsoft/vscode/issues/32811](https://github.com/microsoft/vscode/issues/32811)

## Summary

Implemented and shipped in VS Code 1.74.0: `editor.indentSize` now allows indentation width to differ from rendered tab width.

## Change summary

Allow tabs to render at eight columns while inserting four-space indentation.

## Best solution

Use `editor.tabSize: 8`, `editor.indentSize: 4`, and `editor.insertSpaces: true`; disable `editor.detectIndentation` where automatic detection would override these values.
