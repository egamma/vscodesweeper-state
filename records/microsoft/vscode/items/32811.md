# Issue #32811 — No way to have tab show as eight spaces, indent with something else

[https://github.com/microsoft/vscode/issues/32811](https://github.com/microsoft/vscode/issues/32811)

## Summary

The requested separation of tab display width and space indentation size is implemented on current main. Propose closing as completed; the remaining mixed-indent conversion request in a related issue is distinct from this report's migration to spaces.

## Change summary

Allow existing tabs to display at eight-column tab stops while new indentation uses four spaces.

## Best solution

Use editor.tabSize: 8, editor.indentSize: 4, editor.insertSpaces: true, and editor.detectIndentation: false. This preserves the display of existing tabs while allowing four-space indentation without rewriting the codebase.
