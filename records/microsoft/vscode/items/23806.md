# Issue #23806 —  Line height and font size are too large by default

[https://github.com/microsoft/vscode/issues/23806](https://github.com/microsoft/vscode/issues/23806)

## Summary

Keep open for a product decision: current main retains the reported Windows defaults, while the Backlog milestone and maintainer discussion recognize that changing defaults safely would require preserving the existing appearance for upgrades.

## Change summary

Use a smaller default editor font size and line height, with a lighter effective font weight.

## Best solution

Decide whether denser defaults should apply only to new profiles, backed by a mechanism that preserves existing users' appearance across upgrades. Treat Chromium/font-specific weight rendering separately from the default-density decision.
