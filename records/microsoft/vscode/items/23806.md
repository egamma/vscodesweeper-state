# Issue #23806 —  Line height and font size are too large by default

[https://github.com/microsoft/vscode/issues/23806](https://github.com/microsoft/vscode/issues/23806)

## Summary

Keep open: Windows editor defaults still differ from the requested denser layout, and personal configuration does not satisfy a request to change defaults. The maintainer identified upgrade compatibility as a prerequisite; no verified canonical issue or completed change resolves that decision.

## Change summary

Reduce the default editor font size to 13 pixels and line height to 15 pixels, with lighter default font rendering.

## Best solution

Have the editor/configuration owners decide whether denser defaults are desirable and how existing installations would retain their appearance. Treat the reported Consolas weight difference as a separate rendering question rather than assuming a smaller numeric font weight guarantees a lighter face.
