# Issue #341668 — Tracking issue: update server fetches latest release by timestamp rather than by semver

[https://github.com/microsoft/vscode/issues/341668](https://github.com/microsoft/vscode/issues/341668)

## Summary

Keep this scheduled, team-authored tracking issue open. The linked whitespace change enables a newer replacement build, but does not correct the update server's release-selection behavior.

## Change summary

The update server selects a newer-timestamped 1.141.2 build instead of the higher stable version 1.142.0.

## Best solution

Make stable-release selection prefer the highest eligible semantic version even when an older release line receives a later recovery build. Track the replacement 1.142.0 build as mitigation, separately from correcting and validating server-side selection.
