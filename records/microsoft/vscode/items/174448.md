# Issue #174448 — Hover API does not match LSP specification: Strange Horizontal Line rendering

[https://github.com/microsoft/vscode/issues/174448](https://github.com/microsoft/vscode/issues/174448)

## Summary

Still reproduces on main: the `margin-bottom: -4px` on `.monaco-hover hr` causes cramped/overlapping rendering when a `MarkupContent` hover uses `---` separators, making the non-deprecated LSP approach look broken compared to the deprecated `MarkedString[]` array approach.

## Change summary

Horizontal rules (`---`) in hover MarkupContent render with incorrect negative margins, creating a visually broken separator compared to using the deprecated MarkedString array.

## Best solution

Fix the `margin-bottom: -4px` on `.monaco-hover hr` in `src/vs/base/browser/ui/hover/hoverWidget.css` so that `<hr>` elements render with appropriate spacing when used as content separators in single-MarkupContent hovers. The negative margin was likely intended to collapse spacing when multiple hover parts are joined, but it breaks the single-content case.
