# Issue #174448 — Hover API does not match LSP specification: Strange Horizontal Line rendering

[https://github.com/microsoft/vscode/issues/174448](https://github.com/microsoft/vscode/issues/174448)

## Summary

Keep open: an independent commenter confirmed cramped horizontal-rule spacing around fenced code blocks, and current hover CSS retains the implicated negative bottom margin. The related suggestion-preview report was closed into this issue, not the other way around; no verified fix or older canonical was found.

## Change summary

Render horizontal rules inside a single Markdown hover with appropriate separation from adjacent fenced code blocks.

## Best solution

Provide consistent, readable spacing around Markdown horizontal rules in the shared hover renderer, without requiring language servers to use deprecated MarkedString arrays. Establish a rendered-layout regression check before changing shared hover styles; changing the public Hover API is not necessary to address the reported rendering defect.
