# Issue #145200 — CTRL delete/backspace navigation is different from CTRL arrow navigation

[https://github.com/microsoft/vscode/issues/145200](https://github.com/microsoft/vscode/issues/145200)

## Summary

The behavioral difference is by design: `cursorWordLeft` uses `WordNavigationType.WordStartFast` which skips single-character separators, while `deleteWordLeft` uses `WordNavigationType.WordStart` which stops at every word boundary. The request to unify them is a valid feature request that remains under discussion with no traction.

## Change summary

CTRL+Left (cursor navigation) and CTRL+Backspace (delete word) treat punctuation boundaries differently because they use different word navigation types internally.

## Best solution

If aligning the behaviors, change `deleteWordLeft`'s default command to use `WordNavigationType.WordStartFast` (matching `cursorWordLeft`) in `src/vs/editor/contrib/wordOperations/browser/wordOperations.ts`, or vice versa — but this is a deliberate design trade-off that needs a maintainer decision on which behavior users expect for deletion vs. navigation. Keep open under `under-discussion`.
