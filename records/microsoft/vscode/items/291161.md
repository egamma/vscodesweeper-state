# Issue #291161 — Agent sessions filtering is very annoying when filtering multiple providers

[https://github.com/microsoft/vscode/issues/291161](https://github.com/microsoft/vscode/issues/291161)

## Summary

The reported interaction remains in current source: selecting a provider uses a conventional menu action that dismisses the filter menu. Keep this team-authored UX improvement open; no verified older duplicate or completed fix was found.

## Change summary

Allow multiple agent-session providers to be toggled without reopening the filter menu after every selection.

## Best solution

Make the agent-session filter support consecutive selections in one opening, with accurate selection indicators and explicit dismissal. Preserve existing filtering and persistence semantics, and leave ordinary menus elsewhere unchanged.
