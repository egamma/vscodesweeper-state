# Issue #291161 — Agent sessions filtering is very annoying when filtering multiple providers

[https://github.com/microsoft/vscode/issues/291161](https://github.com/microsoft/vscode/issues/291161)

## Summary

The repeated-dismissal behavior remains on current main: provider/session-type filters are ordinary submenu actions, so each selection closes the filter surface. The expected persistent multi-selection behavior is explicit and the issue should remain open for a bounded Sessions UI fix.

## Change summary

Keep the Agent Sessions filter surface open while users toggle multiple providers instead of requiring it to be reopened after every selection.

## Best solution

Use a persistent, anchored multi-selection surface for the Sessions filters that applies toggles immediately and closes only when the user accepts or dismisses it, without changing global context-menu behavior.
