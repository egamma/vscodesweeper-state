# Issue #340376 — Dialog Cancel Button Misplaced for >2 Options on Linux/Mac

[https://github.com/microsoft/vscode/issues/340376](https://github.com/microsoft/vscode/issues/340376)

## Summary

The reported custom-dialog ordering defect remains in current main. The maintainer's latest comment supports Cancel preceding the actions on Linux and macOS; the supplied reproduction is sufficient and the correction is bounded.

## Change summary

Custom horizontal dialogs with two or more actions place Cancel between the actions instead of at the leading edge on Linux and macOS.

## Best solution

Make custom horizontal dialogs follow the confirmed platform ordering: Cancel before the actions on Linux and macOS, with the primary action rightmost. Preserve Windows ordering, vertical layouts, and the original action identities returned to extensions.
