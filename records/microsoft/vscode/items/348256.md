# Issue #348256 — disable integrated browser cache toggle

[https://github.com/microsoft/vscode/issues/348256](https://github.com/microsoft/vscode/issues/348256)

## Summary

Keep open for the existing Backlog Candidates community-review process. Current source provides one-shot cache-bypassing reloads, but not the requested ongoing cache-disable toggle outside DevTools.

## Change summary

Allow integrated-browser network caching to be toggled without keeping DevTools open during CSS and JavaScript development.

## Best solution

Evaluate an opt-in cache-disable control for integrated-browser development workflows while preserving normal caching by default. Existing hard reload is a useful workaround, but does not cover subsequent navigation and requests.
