# Issue #266964 — Experimental GPU acceleration causes Rendering Issues with Word Wrap

[https://github.com/microsoft/vscode/issues/266964](https://github.com/microsoft/vscode/issues/266964)

## Summary

Duplicate close gated off (the cited canonical #238404 is already closed — a duplicate close would strand the report; if the canonical's fix landed, an implemented-on-main close citing the fix commit is the right shape). Original assessment: This is a duplicate of #238404, which was fixed in commit 8cc2f55d8e6 and shipped in 1.109.0. The fix corrects the wrapped-line indent offset in the GPU renderer — exactly the rendering issue described here.

## Change summary

GPU-accelerated editor renders wrapped lines without accounting for indentation offset, causing text misalignment.

## Best solution

Already fixed via https://github.com/microsoft/vscode/issues/238404 — the GPU render strategies now compute `absoluteOffsetX` from `lineData.minColumn` instead of zero, so wrapped lines respect indentation. Shipped in 1.109.0.
