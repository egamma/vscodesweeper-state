## Change summary

Selecting a session type for a GitHub repository could offer Copilot CLI and then throw an unhandled error because availability was computed from the session URI rather than the repository.

Keep the validation landed in https://github.com/microsoft/vscode/commit/9c2b70dc8af4fa68601b61dfcdb2dda95b85acca: recognize Cloud session URIs as Cloud-only and validate a selected type against the target workspace before creating the session.
