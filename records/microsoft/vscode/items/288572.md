[https://github.com/microsoft/vscode/issues/288572](https://github.com/microsoft/vscode/issues/288572)

## Summary

Valid exploratory feature request for a setting to force all runInTerminal terminals into background mode. The attempted PR #305766 was closed in favor of the different approach in #288566. The exploration question remains open — no setting exists on main today.

## Change summary

Add a setting that makes every `runInTerminal` terminal launch in background mode rather than being revealed in the panel.

## Best solution

Decide whether this global-force-background setting is still desirable now that #288566 (agent-driven push-to-background) is the preferred direction. If the per-invocation approach in #288566 fully covers the need, close this as superseded; otherwise, implement the setting in `terminalChatAgentToolsConfiguration.ts` alongside the existing `OutputLocation` and `DetachBackgroundProcesses` settings.
