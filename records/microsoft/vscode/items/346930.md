# Issue #346930 — Inbox mode: Snoozing a Done session has unclear behavior

[https://github.com/microsoft/vscode/issues/346930](https://github.com/microsoft/vscode/issues/346930)

## Summary

Snoozing a Done session has a useful, defined effect: it returns to Inbox when the timer expires. Keep this open for clearer pre-action wording; the current picker asks when sessions should return without naming their destination.

## Change summary

Make the destination of a snoozed Done session clear before the user confirms snoozing.

## Best solution

Keep the useful Snooze action and make its existing return-to-Inbox behavior explicit before confirmation, without changing triage or expiration semantics.
