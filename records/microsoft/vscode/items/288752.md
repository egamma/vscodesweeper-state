# Issue #288752 — CCR should support skills

[https://github.com/microsoft/vscode/issues/288752](https://github.com/microsoft/vscode/issues/288752)

## Summary

This remains a well-supported feature request: Copilot code review does not currently load repository skills alongside its review instructions, and 26 community upvotes clear the Backlog promotion threshold. The newer Agents Window skill-configuration issue does not qualify as a canonical duplicate for this re-reviewed item.

## Change summary

Make Copilot code review discover and apply relevant repository skills when reviewing changes.

## Best solution

Define how code review selects applicable skills, then include their instructions in the review context without loading unrelated skills or exceeding the context budget; this likely belongs in the Copilot code-review prompt and customization-discovery path.
