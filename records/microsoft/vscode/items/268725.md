# Issue #268725 — Support `#codebase` for remote  Azure Devops repos that use `vscode-vfs`

[https://github.com/microsoft/vscode/issues/268725](https://github.com/microsoft/vscode/issues/268725)

## Summary

Confirmed gap on current main: remote workspace indexing only supports GitHub remote repos (`vscode-vfs://github`), not Azure DevOps (`vscode-vfs://azurerepos`). A maintainer acknowledged this should be supportable. The feature request is valid and already labeled; keeping open.

## Change summary

Support remote workspace indexing (#codebase) for Azure DevOps remote repositories opened via `vscode-vfs://azurerepos/` URIs.

## Best solution

Extend the remote-indexing code path in `extensions/copilot/src/platform/` to recognize `vscode-vfs://azurerepos` URIs alongside `vscode-vfs://github`. The `isGitHubRemoteRepository` check in `remoteRepositories/common/utils.ts` and the code-search chunk search pipeline that gates on it need a parallel Azure DevOps path. The `repoTracker.ts` telemetry enum already has `AzureDevOps` (marked unsupported) — enabling it requires wiring up the indexing service for Azure DevOps repos. Open PRs in the deprecated vscode-copilot/vscode-copilot-chat repos may contain relevant implementation work to port.
