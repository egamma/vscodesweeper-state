# Issue #290705 — Being able to select workspace root folder with #

[https://github.com/microsoft/vscode/issues/290705](https://github.com/microsoft/vscode/issues/290705)

## Summary

Keep open for consideration: current hash completions search inside workspace roots but do not offer the roots themselves. A later report requests exactly this capability, but its community-process closure does not establish a product decision against it.

## Change summary

Allow selecting a workspace root folder as chat context by typing # followed by its name.

## Best solution

Make workspace roots discoverable alongside other folder references in chat, using the existing directory-attachment semantics. Selecting a root should provide context, not imply an enforced restriction on the agent's access to other folders.
