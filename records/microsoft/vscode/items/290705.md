# Issue #290705 — Being able to select workspace root folder with #

[https://github.com/microsoft/vscode/issues/290705](https://github.com/microsoft/vscode/issues/290705)

## Summary

Valid feature request to include workspace root folders as selectable items in the `#file:` completion picker, enabling users to scope Copilot context to an entire workspace root in multi-root scenarios.

## Change summary

Allow selecting workspace root folders via the `#` variable completion in Copilot Chat to restrict context to a specific root.

## Best solution

Add workspace root folder entries to the `#file:` completion list in `chatInputCompletions.ts` so they appear as top-level folder suggestions even without a search pattern, similar to how recently opened files are shown. This would let users in multi-root workspaces easily scope chat context.
