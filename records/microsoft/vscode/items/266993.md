# Issue #266993 — Chat Open File in Editor doesn't directly open file

[https://github.com/microsoft/vscode/issues/266993](https://github.com/microsoft/vscode/issues/266993)

## Summary

Still reproducible on main: the `run_vscode_command` tool validates commands via `getAllCommands` (command palette entries with labels), so API-only commands like `vscode.open` are not found; the model then falls back to the file-dialog command or quick open instead of directly opening the file.

## Change summary

When asked to open a file, chat's run_vscode_command tool cannot find `vscode.open` (a registry-only command) and the model falls back to opening a file dialog instead of directly opening the file in the editor.

## Best solution

Either allowlist `vscode.open` (with URI arg) in the `run_vscode_command` tool's `skipCheck` or no-confirmation paths, or provide a dedicated 'open file in editor' tool that directly calls `vscode.open` with the resolved file URI — avoiding the command-palette lookup entirely.
