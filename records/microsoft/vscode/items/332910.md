# Issue #332910 — Save confirmation dialog shown if file is closed while save is in progress

[https://github.com/microsoft/vscode/issues/332910](https://github.com/microsoft/vscode/issues/332910)

## Summary

Traced to a documented, intentional gap in `FileEditorInput.isSaving()`: it deliberately does not check the model's `PENDING_SAVE` state, so a save-in-progress can still trigger the close confirmation dialog on a slow filesystem.

## Change summary

Pressing Ctrl-S then Ctrl-W quickly on a slow save (e.g. NFS) can show the 'Do you want to save changes?' dialog even though a save is already running.

## Best solution

In src/vs/workbench/contrib/files/browser/editors/fileEditorInput.ts, `isSaving()` explicitly skips `TextFileEditorModelState.PENDING_SAVE` with a comment noting the editor currently lacks an event for that state transition, and naively checking it before caused editors to close before the save finished. The real fix is to wire a proper state-change event (or await the in-flight save via `model.joinState(PENDING_SAVE)` before deciding to close) so both directions of the race are handled correctly — this needs an editor-level event, not just flipping the guard back.
