# Issue #206284 — Quick search: flicker when typing

[https://github.com/microsoft/vscode/issues/206284](https://github.com/microsoft/vscode/issues/206284)

## Summary

Quick Search still has a source-confirmed path that replaces existing workspace results with only synchronous open-editor matches before asynchronous results arrive. Keep this open; the maintainer's suggested direction of avoiding disruptive intermediate result replacement remains relevant.

## Change summary

Prevent Quick Search results from disappearing and reappearing while the user refines the query.

## Best solution

Keep Quick Search's result list visually stable while a refined query is pending, without losing asynchronous workspace matches or allowing cancelled queries to replace newer results. The bounded change belongs in the Quick Search provider's result-publication path.

With an open-editor match and delayed workspace results, refining the query therefore contracts and repopulates the list.
