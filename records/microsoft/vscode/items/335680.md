# Issue #335680 — Document does not refresh in Markdown Editor

[https://github.com/microsoft/vscode/issues/335680](https://github.com/microsoft/vscode/issues/335680)

## Summary

Keep open: an independent commenter confirms stale Markdown Editor content through a remote tunnel on 1.139.1, despite local updates working. The existing report provides a usable retest scenario; neither a complete fix nor a canonical owning this editor-specific failure was verified.

## Change summary

The new Markdown Editor fails to reflect externally modified Markdown documents, including in read-only mode and remote-tunnel sessions.

## Best solution

Restore synchronization between the authoritative TextDocument and the Markdown Editor after external writes, including remote-tunnel writes. First reproduce the remote case and determine whether synchronization stops at document reload, extension-host notification, webview delivery, or model replacement.

- **Expected synchronization path:** extensions/markdown-language-features/src/preview/markdownEditorProvider.ts: MarkdownEditorProvider.#wireSingle subscribes to workspace.onDidChangeTextDocument, filters by document URI, suppresses matching editor-originated changes, and otherwise calls postAuthoritativeUpdate with document.getText() and a new edit epoch. This path is not gated on read-only mode.
- **Webview update handling:** extensions/markdown-language-features/markdown-editor-src/editor.ts: Editor handles authenticated 'update' messages by updating its edit epoch and calling model.replaceSourceText.
