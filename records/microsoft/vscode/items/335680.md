# Issue #335680 — Document does not refresh in Markdown Editor

[https://github.com/microsoft/vscode/issues/335680](https://github.com/microsoft/vscode/issues/335680)

## Summary

Fresh, untriaged report against the new (still experimental) Markdown Editor; the extension code does wire `vscode.workspace.onDidChangeTextDocument` to push content updates to the webview (`markdownEditorProvider.ts`), which is the same mechanism that normally picks up external file changes, so it's not obvious from source alone why a refresh would be missed — needs a confirmed repro before further action.

## Change summary

Editing a Markdown file externally does not refresh its content in the new Markdown Editor (including read-only mode), unlike the classic text editor.

## Best solution

Get a precise repro (exact steps to modify the file externally, whether the tab is focused/visible, single vs. multi-window) from the reporter, then trace whether `#wireSingle`'s `onDidChangeTextDocument` listener in `extensions/markdown-language-features/src/preview/markdownEditorProvider.ts` actually fires for out-of-band disk changes to this document, or whether the readonly/webview-visibility path suppresses the `update` postMessage.
