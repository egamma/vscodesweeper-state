## Summary

The reported behavior — a delay in 'Run Python File' output on the integrated PowerShell terminal — is implemented and owned by the ms-python.python extension (its terminal-run/activation logic), not VS Code core; this repo's bundled `extensions/python` folder only ships the language grammar/config, no run-file or terminal logic.
