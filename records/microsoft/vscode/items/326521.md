# Issue #326521 — Copilot Chat (Agents): allow starting a new chat with no workspace folder context

[https://github.com/microsoft/vscode/issues/326521](https://github.com/microsoft/vscode/issues/326521)

## Summary

The Agents window already ships workspace-less chats — the 'New Quick Chat' command (sessionsView.newQuickChat, Ctrl+K Ctrl+N) and the '+' affordance on the sidebar's 'Chats' section header — which is exactly the no-folder-context chat requested; it just isn't surfaced as an item inside the folder/repo picker dropdown itself.

## Change summary

Add a way to start a new Agents/Copilot Chat session without picking a workspace folder, from the new-chat folder picker.

## Best solution

Point the reporter at the existing 'New Quick Chat' command/keybinding and the '+' button in the Chats section header (src/vs/sessions/contrib/sessions/browser/views/sessionsViewActions.ts, NewQuickChatAction) — the underlying capability (a workspace-less session, handled throughout newChatWidget.ts via _isQuickChatComposer/openQuickChat) already exists; if maintainers still want a discoverability improvement, that would be a distinct, narrower polish request for the picker UI itself.
