# Issue #326521 — Copilot Chat (Agents): allow starting a new chat with no workspace folder context

[https://github.com/microsoft/vscode/issues/326521](https://github.com/microsoft/vscode/issues/326521)

## Summary

Genuine feature request: the Agents window's workspace picker has no "No folder" option, so users cannot start an agent session without workspace context from the main new-chat flow. The quick-chat path is workspace-less, but the full Agents window flow requires a folder selection. No duplicate found.

## Change summary

Allow starting a new Agents chat session without selecting a workspace folder, equivalent to an empty-window / global-context session.

## Best solution

Add a 'No Folder' / 'No Workspace' item to the workspace picker in `src/vs/sessions/contrib/chat/browser/sessionWorkspacePicker.ts` (the `_buildItems` method), wired to fire `onDidSelectWorkspace(undefined)` / call `clearSelection()` so the session starts without workspace context. The plumbing for `undefined` folder URIs already exists downstream (`_onWorkspaceSelected` handles `undefined` → `sessionsService.unsetNewSession`), so the change is primarily UI: adding the option and ensuring the session creation path gracefully handles no-workspace sessions.
