# Issue #336692 — Multiple steering messages visually replace each other

[https://github.com/microsoft/vscode/issues/336692](https://github.com/microsoft/vscode/issues/336692)

## Summary

Still present on current main: the generic chat model retains multiple steering requests, but Agent Host synchronization reduces them to one protocol steering message and removes the previously displayed row when that message is replaced.

## Change summary

Keep every successively submitted steering message visible while it is pending instead of showing only the latest one.

## Best solution

Preserve the ordered local steering-message rows until each message is admitted or consumed, while continuing to interoperate with the Agent Host protocol's singular steering slot and leaving ordinary queued-message behavior unchanged.
