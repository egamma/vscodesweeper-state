# Issue #55044 — Allow syntax colouring in parameters for SignatureHelp

[https://github.com/microsoft/vscode/issues/55044](https://github.com/microsoft/vscode/issues/55044)

## Summary

A real capability gap remains on current main: signature labels are rendered as plain text without syntax tokens. This is the canonical Backlog request with 70 community upvotes, so it should remain open.

## Change summary

Render language-aware syntax coloring in Signature Help labels and parameters.

## Best solution

Define language/token metadata for `SignatureInformation.label` across the extension API and language protocol, then use the editor tokenization pipeline when rendering `ParameterHintsWidget`; preserve the distinct active-parameter highlight.
