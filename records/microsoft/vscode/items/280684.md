# Issue #280684 — Selecting tools for custom agent always opens the md file

[https://github.com/microsoft/vscode/issues/280684](https://github.com/microsoft/vscode/issues/280684)

## Summary

The requested focus-preserving workflow remains absent on current main: changing a writable custom agent's tools still opens its Markdown file before rewriting the frontmatter. This member-authored request must remain open absent a verified duplicate or explicitly referencing fix, and neither was found.

## Change summary

Allow tool selections made from a chat editor to update the custom-agent definition without opening and focusing its Markdown file.

## Best solution

Persist custom-agent tool changes while retaining focus in the originating chat editor, with an explicit product decision about whether silent persistence applies in every host or only when chat is open as an editor.

- **Behavior:**

  > Changing the enabled tools for a writable custom agent from an editor-hosted chat must persist the selection to the agent definition without replacing or moving focus away from that chat editor. The selected tools must take effect exactly as they do today. Directly opening and editing an agent file must remain supported.
- **Trace:**

  > ConfigureToolsAction in src/vs/workbench/contrib/chat/browser/actions/chatToolActions.ts sends the picker result to ChatSelectedTools.set. For an agent-scoped writable selection, ChatSelectedTools.updateCustomModeTools in src/vs/workbench/contrib/chat/browser/widget/input/chatSelectedTools.ts invokes PromptFileRewriter.openAndRewriteTools. That method in src/vs/workbench/contrib/chat/browser/promptSyntax/promptFileRewriter.ts opens the agent URI through ICodeEditorService, selects the tools attribute, and then rewrites the model, which explains the focus change. PromptFileRewriter is also used for direct agent-file operations, so those editor-oriented paths must not lose their reveal and selection behavior. The report is https://github.com/microsoft/vscode/issues/280684; no older open issue with the same observable symptom was found.
- **Open decisions:**
  - Should changing custom-agent tools persist without revealing the agent file in every invoking surface, or only when the operation originates from an editor-hosted chat?
