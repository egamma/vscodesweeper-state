## Change summary

On macOS, pressing Ctrl+Comma in the keyboard shortcuts recorder fails to register the comma key, preventing the user from binding any command to that combination.

## Best solution

Investigate whether macOS system-level accessibility shortcut (Ctrl+, for 'Show Contextual Menu') is intercepting the keypress before Electron delivers it to VS Code.
