# Issue #333485 — Agents - chat tab still uses the old spinner progress indicator

[https://github.com/microsoft/vscode/issues/333485](https://github.com/microsoft/vscode/issues/333485)

## Summary

Confirmed on current main: the Agents Window chat tab indicator in chatCompositeBar.ts still renders the old spinning codicon instead of the new pixel spinner used elsewhere in the sessions UI. A team-authored bug already labeled `bug`, so it stays open for a fix rather than any decline close.

## Change summary

The in-progress indicator on an Agents Window chat tab uses the legacy spinning codicon (Codicon.loading 'spin') instead of the new pixel-spinner animation used elsewhere in the redesigned sessions UI.

## Best solution

Swap the manual `ThemeIcon.modify(Codicon.loading, 'spin')` indicator in chatCompositeBar.ts for the shared `SessionStatusIcon` widget (or `createPixelSpinner` directly), matching the pattern already used in sessionHeaderBar.ts and agentSessionsViewer.ts.
