# Issue #333485 — Agents - chat tab still uses the old spinner progress indicator

[https://github.com/microsoft/vscode/issues/333485](https://github.com/microsoft/vscode/issues/333485)

## Summary

Still reproduces on main: chat tab indicators in the sessions window render a plain spinning codicon instead of the modern pixel-spinner used by the rest of the session status UI. Milestone 1.140.0 is assigned, so this stays open regardless.

## Change summary

The chat tab in the Agents/sessions window shows the old codicon spin animation for in-progress status instead of the new pixel-spinner indicator used elsewhere.

## Best solution

Have chatCompositeBar.ts's tab indicator delegate to the existing SessionStatusIcon widget (src/vs/sessions/browser/sessionStatusIcon.ts), the same way sessionHeader.ts already does, instead of manually toggling ThemeIcon.modify(Codicon.loading, 'spin').
