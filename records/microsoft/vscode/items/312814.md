# Issue #312814 — Agents: Changes panel isn't populated on the new session screen

[https://github.com/microsoft/vscode/issues/312814](https://github.com/microsoft/vscode/issues/312814)

## Summary

Keep open for a maintainer decision on inspecting repository changes before the first message. Current draft support does not establish consistent coverage of this request, and the closest same-symptom report is newer, so it cannot replace this re-reviewed, team-authored issue.

## Change summary

Show existing repository edits in the Agents Window Changes surface while composing a new session, before sending a message.

## Best solution

Provide a clearly identified, read-only view of the selected repository's pending changes before first send, without presenting them as agent-authored changes. Establish the draft changeset and default-selection contract across providers before implementing remaining gaps.
