# Issue #313181 — Codebase Semantic Index does no longer work on multi-root workspaces

[https://github.com/microsoft/vscode/issues/313181](https://github.com/microsoft/vscode/issues/313181)

## Summary

Still reproduces on main: the Copilot extension's copied `resources.ts` utility constructs `ExtUri` with `() => false` for `ignorePathCasing`, making all repo-to-workspace-folder comparisons case-sensitive — breaking indexing on Windows when drive letter casing differs. An open PR (#317192) addresses this but has not merged.

## Change summary

Codebase Semantic Index fails to recognize workspace repos when path casing differs (common on Windows multi-root workspaces).

## Best solution

Land https://github.com/microsoft/vscode/pull/317192 (or an equivalent fix) to use case-insensitive path comparison on Windows/macOS in `codeSearchChunkSearch.ts`. The root cause is that `extensions/copilot/src/util/vs/base/common/resources.ts` exports `extUri = new ExtUri(() => false)`, making `isEqual`/`isEqualOrParent` always case-sensitive. On Windows, the workspace folder URI and the git repo URI often differ in drive-letter casing, causing `openGitRepo` to skip repos as 'not relevant'.
