# Issue #339554 — Command Centre input tooltip overlaps Commands tab; clicking closes the picker

[https://github.com/microsoft/vscode/issues/339554](https://github.com/microsoft/vscode/issues/339554)

## Summary

The current input-tooltip path can steal focus and dismiss the picker instead of activating the covered control. Keep this open for the Quick Input owner; no verified duplicate or fixing commit was found.

## Change summary

Prevent the Command Centre input tooltip from intercepting a tab click and dismissing the picker.

## Best solution

Make the Quick Input placeholder tooltip non-disruptive to picker controls: clicking the covered Commands tab should switch tabs without closing the picker. Preserve useful input instructions, keyboard accessibility, and normal dismissal when focus genuinely leaves the picker.

Thus clicking the input hover can focus outside the picker and dismiss it; the obscured tab does not receive that click.
