# Issue #339554 — Command Centre input tooltip overlaps Commands tab; clicking closes the picker

[https://github.com/microsoft/vscode/issues/339554](https://github.com/microsoft/vscode/issues/339554)

## Summary

Fresh, well-documented report (clear STR + screen recording) with a plausible source-level mechanism: the hover/tooltip widget is a real, clickable DOM element (`.monaco-hover` has no `pointer-events: none`) that can sit above the Commands tab header when it appears over the Command Center quick pick; clicking it triggers the quick input's blur/outside-click close path in `quickInputController.ts` instead of letting the click reach the tab underneath. No fix exists yet on main.

## Change summary

Clicking the native hover tooltip that appears above the Command Center's 'Commands' tab closes the whole Command Center popup instead of letting the click reach the tab.

## Best solution

Either suppress/reposition the hover while the Command Center quick pick is open so it can't overlap the tab header, or have the quick input's outside-click handling in quickInputController.ts treat clicks landing on an active hover widget as non-dismissing so they pass through to the underlying control.
