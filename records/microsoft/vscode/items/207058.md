# Issue #207058 — Inconsistent keyboard shortcut resolution

[https://github.com/microsoft/vscode/issues/207058](https://github.com/microsoft/vscode/issues/207058)

## Summary

Still present on main: Ctrl+Alt shortcuts fail on Czech keyboard because the Windows keyboard mapper doesn't properly reconcile AltGr (which Windows sends as Ctrl+Alt) with explicit Ctrl+Alt key combinations. The `mapAltGrToCtrlAlt` setting is an imperfect workaround that breaks character input.

## Change summary

Ctrl+Alt keyboard shortcuts fail to resolve on Czech keyboard layout in Windows, while AltGr-based character input conflicts with the workaround setting.

## Best solution

Improve the Windows keyboard mapper's handling of Ctrl+Alt vs AltGr disambiguation for non-US keyboard layouts so that explicit Ctrl+Alt shortcuts work without requiring `mapAltGrToCtrlAlt` (which breaks character input). The fix belongs in `src/vs/workbench/services/keybinding/common/windowsKeyboardMapper.ts`.
