# Issue #154348 — Unable to use outline with search editor

[https://github.com/microsoft/vscode/issues/154348](https://github.com/microsoft/vscode/issues/154348)

## Summary

Keep open: contributors reproduced the navigation failure and a maintainer accepted it as a bug. The newer matching report explicitly points back here, and current source still sends Outline navigation through generic resource opening rather than directly navigating the Search Editor.

## Change summary

Clicking a Search Editor Outline entry opens an erroneous resource editor instead of navigating the search results.

## Best solution

Make Outline entries navigate to their corresponding positions in the Search Editor without replacing it with an unresolved resource tab. Preserve the search configuration and results, and establish regression coverage across the Outline-to-editor navigation boundary.
