# Issue #207982 — There should be a prompt when clicking on the codelens(command) in the read-only editor

[https://github.com/microsoft/vscode/issues/207982](https://github.com/microsoft/vscode/issues/207982)

## Summary

Keep this accepted Backlog request open: merge-conflict CodeLens actions still bypass the existing read-only message path. The maintainer clarified the expected feedback, and no verified canonical issue or landed fix was found.

## Change summary

Show an explanatory error when a merge-conflict CodeLens action cannot modify a read-only file.

## Best solution

Provide visible read-only feedback for attempted conflict resolution while preserving the file contents and existing writable-file behavior. Prefer consistency with the editor's existing read-only feedback rather than introducing a separate interaction unnecessarily.
