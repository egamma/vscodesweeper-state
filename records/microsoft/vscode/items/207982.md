## Summary

Still unfixed on main: the merge-conflict extension's command handler has no read-only check, so codelens actions silently fail in read-only editors. Keeping open as a valid but low-traction feature request in the Backlog.

## Change summary

When clicking merge conflict codelens in a read-only editor, nothing happens — no error message or prompt is shown.

## Best solution

Add a read-only guard in the merge-conflict extension's command handler (`extensions/merge-conflict/src/commandHandler.ts`) that shows a notification when the document is read-only, similar to how the editor core shows 'Cannot edit in read-only editor'.
