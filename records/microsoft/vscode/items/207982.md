# Issue #207982 — There should be a prompt when clicking on the codelens(command) in the read-only editor

[https://github.com/microsoft/vscode/issues/207982](https://github.com/microsoft/vscode/issues/207982)

## Summary

The feedback gap remains on current main: merge-conflict CodeLens commands attempt the edit but do not report a false edit result for a read-only document. No older open issue with the same observable symptom was found, so this should remain the merge-conflict area's request.

## Change summary

Show an error message when a merge-conflict CodeLens action cannot modify a read-only document.

## Best solution

Provide consistent failure feedback from the merge-conflict command path when an accept action cannot edit the active document, while leaving the non-mutating Compare Changes action available.

## Evidence

- **unreported failure path:** extensions/merge-conflict/src/commandHandler.ts calls conflict.commitEdit(type, editor) without awaiting or checking its boolean result; extensions/merge-conflict/src/documentMergeConflict.ts returns the TextEditor.edit result, so a false result produces no warning.
- **CodeLens dispatch:** src/vs/editor/contrib/codelens/browser/codelensController.ts reports rejected command promises, but a merge command that resolves after an unsuccessful edit does not reject and therefore produces no notification.
- **maintainer clarification:** The maintainer summary at https://github.com/microsoft/vscode/issues/207982#issuecomment-2111931488 confirms the intended behavior: clicking the conflict CodeLens in a read-only file should show an error instead of doing nothing.
