# Issue #188134 — Inconsistent naming for WSL projects in right-click taskbar menu

[https://github.com/microsoft/vscode/issues/188134](https://github.com/microsoft/vscode/issues/188134)

## Summary

The inconsistency remains in current main: Windows jump-list entries retain the remote suffix only when the recent-history record already contains a display label; otherwise the title falls back to the URI basename and omits the remote identity. The existing remote and workbench-history labels route it appropriately.

## Change summary

Ensure Windows taskbar recent-folder entries consistently identify WSL and Remote-SSH folders instead of showing an ambiguous local-looking basename.

## Best solution

Make the core workspace-history/jump-list path preserve or derive a remote-aware label for every remote recent folder, while keeping local-folder and workspace labels unchanged.
