# Issue #149688 — The detail of QuickPick item is truncated by QuickPick separator

[https://github.com/microsoft/vscode/issues/149688](https://github.com/microsoft/vscode/issues/149688)

## Summary

Keep open: an inline separator still consumes width beside both item rows, unnecessarily truncating the detail below it. The source confirms the reported layout defect, and the maintainer already accepted the fix direction.

## Change summary

Prevent a long inline QuickPick separator label from reducing the available width of the following item's detail row.

## Best solution

Make the detail row independent of the inline separator's width while preserving the separator's placement beside the first row and existing item actions, filtering, and navigation.
