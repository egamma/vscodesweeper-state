# Issue #204043 — Semantic colorization customization applied even if `editor.semanticTokenColorCustomizations.enabled` is false.

[https://github.com/microsoft/vscode/issues/204043](https://github.com/microsoft/vscode/issues/204043)

## Summary

Still reproduces on main: `setCustomSemanticTokenColors` in `colorThemeData.ts` parses and stores custom semantic token rules in `customSemanticTokenRules` regardless of the `enabled` flag, so setting `enabled: false` disables semantic highlighting but still applies the custom color rules.

## Change summary

Custom semantic token color rules from `editor.semanticTokenColorCustomizations.rules` are applied even when `enabled` is explicitly set to `false`.

## Best solution

Gate the `readSemanticTokenRules` calls in `setCustomSemanticTokenColors` on `enabled !== false` so that disabling semantic token customizations also suppresses the custom rules. An experimental PR (https://github.com/microsoft/vscode/pull/325305) already proposes this fix but has not merged.
