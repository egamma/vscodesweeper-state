# Issue #312747 — The trust dialog should mention what you trust

[https://github.com/microsoft/vscode/issues/312747](https://github.com/microsoft/vscode/issues/312747)

## Summary

The gap remains on main: the trust confirmation triggered while changing the Agents window workspace does not identify the affected folder.

## Change summary

Show the folder path or label in the Agents window trust dialog.

## Best solution

Request trust for the session folder before mutating workspace folders, using the resource-trust flow that includes the URI label. This likely belongs in the Agents workspace-folder management path rather than changing the generic dialog alone.
