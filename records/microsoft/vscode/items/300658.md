# Issue #300658 — Gemini 3.1 Pro (Preview) ended long response with infinite loop of "Bye.\nDone."

[https://github.com/microsoft/vscode/issues/300658](https://github.com/microsoft/vscode/issues/300658)

## Summary

The reported behavior — Gemini 3.1 Pro generating a degenerate repetitive loop of 'Bye./Done.' — is a model-quality issue, likely server-side. VS Code already has token-level repetition detection (`anomalyDetection.ts`) that should catch and stop such patterns. The report is from March 2026 against Copilot 0.39.0 / VS Code 1.111.0, both significantly outdated; the model version has also been updated since. Without confirmation this still reproduces on current builds, requesting more info.

## Change summary

Gemini 3.1 Pro (Preview) entered an infinite text repetition loop ('Bye./Done.') requiring the user to manually stop the response.

## Best solution

Ask the reporter to confirm on the latest VS Code Insiders and current Copilot extension version. If still reproducible, the repetition detection in `extensions/copilot/src/util/common/anomalyDetection.ts` (used in `chatMLFetcher.ts`) may need its thresholds tuned for this particular pattern — the 'Bye./Done.' two-line cycle should be caught by the existing `max_token_sequence_length: 1, last_tokens_to_consider: 10` config, suggesting the detection may not be wired into the agent-mode streaming path that produced this output.
