# Issue #296713 — [BYOK Agent Mode] Gemini 3.1 Pro returns 400 "Function call is missing a thought_signature" — OpenAI-compatible client strips required field

[https://github.com/microsoft/vscode/issues/296713](https://github.com/microsoft/vscode/issues/296713)

## Summary

Keep open: the current OpenAI-compatible streaming path discards tool-call thought signatures, leaving the reported Gemini agent round-trip unsupported. A maintainer recently consolidated another report here; native Gemini support does not resolve this custom-endpoint path.

## Change summary

Preserve Gemini thought signatures across tool-call responses and subsequent requests when using an OpenAI-compatible BYOK endpoint.

## Best solution

Round-trip the provider's tool-call signature through the OpenAI-compatible response, conversation history, and request serialization paths. Preserve existing native Gemini behavior and treat the secondary URL-resolution concern separately.
