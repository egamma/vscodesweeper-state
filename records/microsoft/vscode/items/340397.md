# Issue #340397 — Touch scrolling in the editor stops, and momentum stops working, once the touched line scrolls out of view

[https://github.com/microsoft/vscode/issues/340397](https://github.com/microsoft/vscode/issues/340397)

## Summary

Thanks for the detailed report. The Gesture handling in src/vs/base/browser/touch.ts still matches the described flow on main, so this stays open.

## Change summary

Touch drag in the editor stops and inertia is lost once the touched line's DOM node is removed during scrolling.

## Best solution

Make Gesture robust to a detached touch target: handle touchend/touchmove for touches whose initialTarget is no longer in the document, and clear stale activeTouches so inertia works afterwards.
