# Issue #340397 — Touch scrolling in the editor stops, and momentum stops working, once the touched line scrolls out of view

[https://github.com/microsoft/vscode/issues/340397](https://github.com/microsoft/vscode/issues/340397)

## Summary

Thanks for the detailed report. The source matches the diagnosis: `Gesture` listens on `document` and resolves targets with `contains(initialTarget)`, so a touch that started on a removed line node loses its events. No fix or duplicate was found, so this stays open.

## Change summary

Touch scrolling in the editor stops, and later swipes get no momentum, once the touched line node is removed from the DOM.

## Best solution

Make `Gesture` resilient to a removed initial target. Options are to track the touch on a stable ancestor, or to clean up `activeTouches` when the target is detached. Inertia should still start for subsequent swipes.
