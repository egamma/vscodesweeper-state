# Issue #341108 — Auto migrate banner link is confusing

[https://github.com/microsoft/vscode/issues/341108](https://github.com/microsoft/vscode/issues/341108)

## Summary

Thanks for testing this. The banner keeps the link-styled "Move to Copilot" action visible but disabled while the auto-migration runs, so it looks clickable and isn't. The progress message is also short-lived. This is a valid polish item and should stay open.

## Change summary

While the chat is auto-migrating to Copilot, the read-only banner shows a link-styled action that can't be clicked, and the explanation disappears quickly.

## Best solution

Hide or visually de-emphasize the disabled action link while auto-migration is running, and keep the status message visible long enough to read. A failed migration should keep showing the retry hint.
