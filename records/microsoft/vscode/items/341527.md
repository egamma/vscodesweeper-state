# Issue #341527 — Image preview: right click > Copy sometimes doesn't copy anything

[https://github.com/microsoft/vscode/issues/341527](https://github.com/microsoft/vscode/issues/341527)

## Summary

Thanks for the detailed report. The source matches your diagnosis: copyImage retries only 5 times at 20ms (about 100ms) for document focus and then calls clipboard.write anyway, which throws NotAllowedError if focus hasn't returned yet.

## Change summary

Image preview's context menu Copy intermittently copies nothing because the document is not yet focused when the clipboard is written.

## Best solution

Make copyImage in the media-preview image preview wait for focus more robustly (a longer retry window or a focus-based wait). Alternatively, surface the failure instead of silently swallowing it.
