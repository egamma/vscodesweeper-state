# Issue #341367 — Closed PR is shown as "draft"

[https://github.com/microsoft/vscode/issues/341367](https://github.com/microsoft/vscode/issues/341367)

## Summary

Thanks for the report. This reproduces from source: the PR icon is computed as `isDraft ? 'draft' : state`, and GitHub keeps `draft: true` on a closed draft PR, so a closed draft is shown as draft. The issue needs an area owner.

## Change summary

A closed pull request that was a draft shows as 'draft' in the sessions list and PR pill instead of closed.

## Best solution

Treat a PR as draft only when its state is open, in every place that maps `isDraft` and `state` to a display state. Closed and merged PRs should always show their own state.
