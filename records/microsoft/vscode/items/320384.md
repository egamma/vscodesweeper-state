# Issue #320384 — Simple file dialog - change the name when creating a new folder

[https://github.com/microsoft/vscode/issues/320384](https://github.com/microsoft/vscode/issues/320384)

## Summary

Still reproduces on main: the `yesNoPrompt` in the simple file dialog dismisses on any keystroke via `onDidChangeValue`, so the user cannot edit the folder name in the create-folder confirmation prompt. No fix commit references this issue.

## Change summary

In the simple file dialog, typing in the create-folder confirmation prompt dismisses it instead of allowing the user to edit the path.

## Best solution

The `onDidChangeValue` handler in `yesNoPrompt` (src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts) unconditionally hides the prompt on any value change. The fix should either remove this handler or allow editing the value field so users can adjust the folder name before confirming creation.
