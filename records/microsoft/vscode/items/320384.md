## Summary

The reported editing interruption remains in current source: typing in the folder-creation confirmation dismisses it without carrying the edit back to the original path input. Keep this team-authored, accepted bug open; no verified canonical or fixing commit was found.

## Change summary

Allow users to change a proposed new folder name without losing the first edit when leaving the creation confirmation.
