# Issue #280091 — Support for `${userHome}` variable in `chat.promptFilesLocations` setting

[https://github.com/microsoft/vscode/issues/280091](https://github.com/microsoft/vscode/issues/280091)

## Summary

Current VS Code already supports the portable home-relative use case through `~/...` paths in `chat.promptFilesLocations`; adding `${userHome}` would duplicate the intentionally supported syntax.

## Change summary

Allow shared prompt-file directories to be configured relative to each user's home directory.

## Best solution

Use a home-relative entry such as `"~/shared/prompts": true`; keep `~/` as the single portable home-directory syntax rather than adding another variable-expansion mechanism. For future configuration, migrate prompt files through the Agent Customizations editor because this Local-agent setting is deprecated.
