# Issue #280091 — Support for `${userHome}` variable in `chat.promptFilesLocations` setting

[https://github.com/microsoft/vscode/issues/280091](https://github.com/microsoft/vscode/issues/280091)

## Summary

The requested portable home-relative prompt location is implemented on current main using `~/` rather than the literal `${userHome}` syntax, so the central use case is complete.

## Change summary

Allow prompt-file location settings to reference a shared directory relative to each user's home folder.

## Best solution

Use a portable entry such as `"~/shared-prompts": true` in `chat.promptFilesLocations`; current discovery expands it against the user's home directory.
