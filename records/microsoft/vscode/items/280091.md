# Issue #280091 — Support for `${userHome}` variable in `chat.promptFilesLocations` setting

[https://github.com/microsoft/vscode/issues/280091](https://github.com/microsoft/vscode/issues/280091)

## Summary

The requested portable home-relative prompt location is implemented through `~/` path expansion. Current source resolves these paths against the user's home directory for `chat.promptFilesLocations` and related customization-location settings.

## Change summary

Allow shared prompt-file locations to be configured relative to each user's home directory instead of using machine-specific absolute paths.

## Best solution

Use the shipped `~/shared-prompts` syntax in `chat.promptFilesLocations`; it provides the requested cross-machine home-directory behavior without adding a second `${userHome}` syntax.
