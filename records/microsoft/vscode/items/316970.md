## Summary

Team-authored testplan bug — the custom endpoint BYOK model renders under an empty group name in the Manage Language Models widget. No fix found on main; keeping open for the area owner.

## Change summary

A custom BYOK model (customendpoint provider) appears under a blank/empty category header in the Manage Language Models UI.

## Best solution

The `group.name` for custom endpoint models is empty or unset. The fix likely lives in the model registration path in `extensions/copilot` or the group-resolution logic in `src/vs/workbench/contrib/chat/common/languageModels.ts` — either supply a meaningful group name for custom endpoint models (e.g. "Custom Endpoint") or suppress the group header when the name is empty.
