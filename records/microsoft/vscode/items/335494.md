# Issue #335494 — Agent Host sandbox toggle uses client OS instead of remote host OS

[https://github.com/microsoft/vscode/issues/335494](https://github.com/microsoft/vscode/issues/335494)

## Summary

Fixed and merged same day: PR #335613 explicitly states 'fixes #335494' and its changes are present in the checkout — the permission picker and chat input picker now resolve the Agent Host's actual remote OS (via getAgentHostOperatingSystem/getNetworkDiagnosticsInfo) instead of assuming the renderer's local platform, which is exactly the reported bug and suggested fix.

## Change summary

The sandbox permission-picker toggle used the client's local OS instead of the connected Agent Host's OS, causing a mismatch between the displayed sandbox state and the setting actually enforced on a remote host (e.g. macOS client + Windows host).

## Best solution

Keep the shipped fix from PR https://github.com/microsoft/vscode/pull/335613 (merge commit a2abfe9056619001322c95a9761a6671d233de68) — the sandbox pickers now resolve the connected Agent Host's real OS before deriving the toggle setting id.
