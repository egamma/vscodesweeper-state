# Issue #335494 — Agent Host sandbox toggle uses client OS instead of remote host OS

[https://github.com/microsoft/vscode/issues/335494](https://github.com/microsoft/vscode/issues/335494)

## Summary

Already fixed on main: the permission picker now resolves the Agent Host's actual OS instead of the renderer's local platform before selecting the Windows vs. non-Windows sandbox setting, exactly as the issue requested.

## Change summary

The sandbox toggle/permission picker picked the client OS's sandbox setting (e.g. macOS) instead of the connected remote Agent Host's OS (e.g. Windows), causing the SDK sandbox to be misconfigured and terminal commands to fail.

## Best solution

Keep the shipped fix: `getAgentHostOperatingSystem` (src/vs/platform/agentHost/common/agentHostOperatingSystem.ts) resolves the connection's real OS via `getNetworkDiagnosticsInfo()`, and `AgentHostPermissionPickerDelegate.sandboxToggleSettingId` (src/vs/sessions/contrib/providers/agentHost/browser/agentHostPermissionPickerDelegate.ts) now derives the setting id from that resolved host OS rather than local `isWindows`.
