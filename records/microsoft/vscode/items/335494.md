# Issue #335494 — Agent Host sandbox toggle uses client OS instead of remote host OS

[https://github.com/microsoft/vscode/issues/335494](https://github.com/microsoft/vscode/issues/335494)

## Summary

Already fixed and merged: PR #335613 explicitly 'fixes #335494' and current main resolves the sandbox toggle from the connected Agent Host's actual OS rather than the local renderer platform, so this can be closed as completed.

## Change summary

Sandbox permissions picker showed/used the local client OS's sandbox setting instead of the connected Agent Host's OS, causing a Windows host to silently run with the wrong (and possibly unenforced/unsupported) sandbox config.

## Best solution

Keep the shipped fix: the new shared `getAgentHostOperatingSystem` connection-scoped resolver (src/vs/platform/agentHost/common/agentHostOperatingSystem.ts) plus the picker's `_resolveHostOperatingSystem` in agentHostPermissionPickerDelegate.ts replace the old client-platform assumption.
