# Issue #175130 — Terminal a11y help menu includes wrong keybinding

[https://github.com/microsoft/vscode/issues/175130](https://github.com/microsoft/vscode/issues/175130)

## Summary

The current accessibility-help renderer still resolves keybindings without the terminal's scoped context, allowing the fallback shortcut to replace the screen-reader shortcut. Keep this reopened, team-authored bug open; the discussion's diagnosis remains supported by current source.

## Change summary

Terminal accessibility help should display the context-appropriate Run Recent Command shortcut, including Ctrl+R on Windows and Command+R on macOS with screen-reader support enabled.

## Best solution

Make terminal accessibility help describe the shortcut applicable to the originating terminal workflow, including user overrides, without changing keyboard dispatch or globally changing keybinding fallback semantics.
