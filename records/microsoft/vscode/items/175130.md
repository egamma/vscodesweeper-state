# Issue #175130 — Terminal a11y help menu includes wrong keybinding

[https://github.com/microsoft/vscode/issues/175130](https://github.com/microsoft/vscode/issues/175130)

## Summary

Still present on main: `resolveContentAndKeybindingItems` in `accessibleViewKeybindingResolver.ts` calls `lookupKeybinding(commandId)` without passing a context, so the keybinding resolver falls back to the wrong binding when `terminalFocus` is undefined. The workaround fix in commit 7b1e98a64b2 addressed one path, but the underlying resolver issue persists.

## Change summary

Terminal accessibility help dialog shows `Ctrl+Alt+R` instead of `Ctrl+R` for 'Run Recent Command' because the keybinding lookup lacks terminal-focus context.

## Best solution

Pass a context to `keybindingService.lookupKeybinding()` in `accessibleViewKeybindingResolver.ts` that simulates the terminal-focused state — or use `enforceContextCheck` and handle the fallback — so the correct context-specific keybinding is displayed. Alternatively, refine the keybinding resolver's tie-breaking logic (as suggested in comment 16) so that when all when-clauses evaluate to false, it prefers the one whose context keys are merely missing over one with explicit negation.
