# Issue #188162 — Completion list is not filtered correctly when typing a number after a hyphen

[https://github.com/microsoft/vscode/issues/188162](https://github.com/microsoft/vscode/issues/188162)

## Summary

Confirmed bug, still present on main. When typing a number after a hyphen in a string completion context, `shouldAutoTrigger` returns false because the number check (`isNaN(Number(word.word))`) prevents retriggering, so the completion list is not updated.

## Change summary

Completion list filtering breaks when the user types a digit after a hyphen inside a quoted property name, because the suggest model treats the digit as a pure-number word and skips retriggering.

## Best solution

Fix the retrigger path in `suggestModel.ts` around lines 752–766: when suggestions are already showing and the user types into a new word that is numeric, the existing items should still be refiltered rather than silently dropped. The `shouldAutoTrigger` guard (line 83) correctly prevents *initial* triggering on numbers but should not block retriggering when suggestions are already active. jrieken acknowledged the bug in comment 5 and noted a good fix needs thought.
