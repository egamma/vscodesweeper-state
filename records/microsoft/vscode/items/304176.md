# Issue #304176 — Performance issues with git processes on large repo with old merge base from code search

[https://github.com/microsoft/vscode/issues/304176](https://github.com/microsoft/vscode/issues/304176)

## Summary

Still reproduces on main: the 2-minute interval timer in CodeSearchWorkspaceDiffTracker fires refreshRepoDiffs unconditionally with no in-flight guard, timeout, or repo-size check — for very large repos with distant indexed commits this queues unbounded expensive git diff processes.

## Change summary

CodeSearchWorkspaceDiffTracker's 2-minute refresh timer can stack unbounded expensive git diff operations on large repos when the indexed commit is far from HEAD.

## Best solution

Add an in-flight guard to refreshRepoDiffs (skip if a diff is already running), a timeout on the git diff call, and/or a heuristic to skip or limit diffs against very distant refs in huge repos. The fix lives in extensions/copilot/src/platform/workspaceChunkSearch/node/codeSearch/workspaceDiff.ts and the diffWithIndexedCommit method in codeSearchChunkSearch.ts.
