# Issue #304176 — Performance issues with git processes on large repo with old merge base from code search

[https://github.com/microsoft/vscode/issues/304176](https://github.com/microsoft/vscode/issues/304176)

## Summary

Keep open: current source still schedules indexed-commit diffs every two minutes without awaiting previous refreshes, and the file-count limit applies only after Git finishes. The older ADO throttling report is related but does not establish the same reporter-observable symptom required to close this re-reviewed, team-authored issue as a duplicate.

## Change summary

Prevent Copilot code-search background diffs against distant indexed commits from repeatedly consuming excessive resources in very large repositories.

## Best solution

Make code-search delta tracking resource-bounded without silently treating incomplete results as a complete workspace delta. Prevent overlapping refreshes and settle the search-freshness behavior when an indexed-commit comparison is too expensive.
