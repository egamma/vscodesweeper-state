# Issue #213761 — Need a way to get the notebook JSON to send to black

[https://github.com/microsoft/vscode/issues/213761](https://github.com/microsoft/vscode/issues/213761)

## Summary

Team-authored discussion about needing a more direct API to get serialized notebook JSON for formatting tools (black, ruff). A workaround via the ipynb extension's serializer was suggested but no resolution was reached. Stays open as under-discussion.

## Change summary

Extensions performing notebook formatting need access to the serialized notebook JSON (not just NotebookDocument) so formatters like black/ruff don't destroy outputs.

## Best solution

Either surface a first-class API for extensions to obtain the current notebook's serialized bytes (via the registered NotebookSerializer), or document the workaround of calling the ipynb extension's exported serialization utility. The discussion between karthiknadig and Yoyokrazy should reach a conclusion on whether the existing workaround suffices or a new API is needed.
