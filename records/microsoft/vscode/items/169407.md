# Issue #169407 — Exit code isn't handled correctly in fish shell integration

[https://github.com/microsoft/vscode/issues/169407](https://github.com/microsoft/vscode/issues/169407)

## Summary

Still reproduces on current main: `__vsc_fish_prompt_start` is called before the user's prompt function, overwriting `$status` and `$pipestatus`. The issue is labeled `help wanted` and awaiting a community fix — keep open.

## Change summary

Fish shell integration overwrites `$status`/`$pipestatus` before the user's prompt function runs, causing exit code display in right prompts to always show success.

## Best solution

In `shellIntegration.fish`, save the user's prompt output before calling `__vsc_fish_prompt_start`, so `$status`/`$pipestatus` are preserved for the user's prompt function. The reporter's suggested fix (capturing `__vsc_fish_prompt` output first, then emitting `__vsc_fish_prompt_start` before it) is a sound approach. The right-prompt misalignment (newline handling) may also need attention.
