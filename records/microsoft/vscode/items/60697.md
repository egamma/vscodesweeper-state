# Issue #60697 — Can't Install local user update due to `\\bin` folder being used by another process

[https://github.com/microsoft/vscode/issues/60697](https://github.com/microsoft/vscode/issues/60697)

## Summary

Keep open: multiple reporters confirmed locked-directory update failures that leave VS Code unusable, and no verified fix establishes that this case is resolved. The linked updater PR remains open and explicitly identifies this issue as a potentially helped variant, not a completed fix.

## Change summary

Windows updates fail when another process locks the installation's bin directory, sometimes leaving the application unusable.

## Best solution

Windows updates should either complete despite transient locks or fail without leaving the installation unusable. Review https://github.com/microsoft/inno-updater/pull/71 and verify whether it addresses this directory-lock case before deciding what additional installer work remains.
