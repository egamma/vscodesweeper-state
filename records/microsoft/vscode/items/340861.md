# Issue #340861 — Copilot SDK agent host loses disable-model-invocation restriction when forwarding infer: false

[https://github.com/microsoft/vscode/issues/340861](https://github.com/microsoft/vscode/issues/340861)

## Summary

Thanks for the detailed report. On current main the Copilot agent host converts `disable-model-invocation: true` only into the legacy `infer: false` field and never sets `disableModelInvocation`. If the bundled runtime only honors `disableModelInvocation`, as the report's probe shows, the restriction is lost. Whether the SDK should be fixed or VS Code should pass the new field cannot be settled from this checkout.

## Change summary

A custom agent with `disable-model-invocation: true` can still be delegated to by the model because the agent host forwards only the legacy `infer: false` field to the Copilot SDK.

## Best solution

Check the SDK version pinned in package.json (1.0.19-preview.0, newer than the reporter's 1.0.17) for the `disableModelInvocation` field on custom agent config. Then have `copilotPluginConverters.ts` pass it, keeping `infer` only if the SDK still accepts it. Add a converter test for the mapping.
