# Issue #325449 — Plan Mode silently discards the comprehensive plan when exporting for a separate implementation session

[https://github.com/microsoft/vscode/issues/325449](https://github.com/microsoft/vscode/issues/325449)

## Summary

Keep open: current source still distinguishes a persisted comprehensive plan from the displayed plan, but Open in Editor does not explicitly select the persisted artifact. The report's steps suffice to retest on current main; model-dependent omission has not been independently reproduced, and neither related issue owns this exact export-content defect.

## Change summary

Plan export can preserve only the displayed summary instead of the comprehensive session plan needed for a later implementation session.

## Best solution

Make the comprehensive persisted plan discoverable and reliably preservable outside its originating chat, with an explicit distinction from the review summary. Confirm the reported content mismatch, then settle the default export artifact and summary-selection behavior.
