# Issue #325449 — Plan Mode silently discards the comprehensive plan when exporting for a separate implementation session

[https://github.com/microsoft/vscode/issues/325449](https://github.com/microsoft/vscode/issues/325449)

## Summary

This is a feature request for Plan Mode's export flow to surface the comprehensive session-memory plan alongside the concise chat summary, letting users choose which version to save. The current behavior — showing only the chat summary in the export action — is working as designed, but the design could better serve the handoff-to-new-session workflow.

## Change summary

Plan Mode's export action only offers the concise chat-visible plan, hiding the more detailed /memories/session/plan.md from the normal export flow.

## Best solution

Add an explicit export option (or make it the default) that surfaces the comprehensive plan.md content when the user exports from Plan Mode, so the detailed implementation artifact isn't lost when the session ends. This belongs in the Copilot extension's plan agent / exit-plan-mode flow (extensions/copilot/src/extension/chatSessions/copilotcli/node/exitPlanModeHandler.ts and related).
