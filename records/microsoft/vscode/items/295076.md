# Issue #295076 — Allow extensions to handle agent hooks execution

[https://github.com/microsoft/vscode/issues/295076](https://github.com/microsoft/vscode/issues/295076)

## Summary

This requests that extensions handle the *execution* of hooks (running hook logic inside the extension runtime). The existing `ChatHookProvider` API (PR #307545) only lets extensions contribute hook *configuration* resources (JSON files) — it does not give extensions control over how hooks are executed. The central ask remains unaddressed on main, and the author is a team member.

## Change summary

Allow extensions to dynamically contribute agent hooks whose execution is handled within the extension rather than via shell commands.

## Best solution

Extend the proposed `chatPromptFiles` API surface (or introduce a new proposed API) so that extensions can register a hook execution handler — receiving hook events and returning results — alongside the existing `ChatHookProvider` that contributes hook definitions. This would live in `src/vs/workbench/api/common/extHostChatAgents2.ts` and the corresponding mainThread proxy, with a new `ChatHookExecutionProvider` (or similar) interface in the proposed d.ts.
