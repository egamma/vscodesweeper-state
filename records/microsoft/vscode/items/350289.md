# Issue #350289 — Change copilot icon color when unavailable

[https://github.com/microsoft/vscode/issues/350289](https://github.com/microsoft/vscode/issues/350289)

## Summary

Keep open: existing completion warnings do not fully provide the requested at-a-glance indication of temporary service unavailability on the main Copilot icon. The related status requests inspected do not clearly own this specific behavior.

## Change summary

Visibly distinguish the Copilot icon when inline completions are temporarily unavailable.

## Best solution

Make known temporary completion-service failures discoverable through the existing Copilot status surface, using theme-consistent warning styling and a textual or accessible explanation rather than color alone.
