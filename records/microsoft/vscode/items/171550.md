# Issue #171550 — Focused item in tree is never unfocused

[https://github.com/microsoft/vscode/issues/171550](https://github.com/microsoft/vscode/issues/171550)

## Summary

Still reproduces on main: the `onDidChangeFocus` handler in `treeView.ts` only updates `lastActive` when new focus elements exist, never clearing it when focus is removed (e.g., Escape or clicking away). Extensions see a stale `focusedNode` that never becomes undefined.

## Change summary

Once a tree item receives focus, `focusedNode` in extension commands never resets to undefined even after the user clears focus.

## Best solution

In `src/vs/workbench/browser/parts/views/treeView.ts`, the `onDidChangeFocus` handler (line ~778) should also handle the empty-elements case by resetting `lastActive` to `undefined` (or `this.root`) and firing `_onDidChangeSelectionAndFocus`. The downstream `setSelectionAndFocus` in `extHostTreeViews.ts` already handles an empty/undefined focused handle, so the fix is localized to the main-side handler.
