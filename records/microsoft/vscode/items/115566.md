# Issue #115566 — Mark same keybindings - Badge with the number of same keybinding

[https://github.com/microsoft/vscode/issues/115566](https://github.com/microsoft/vscode/issues/115566)

## Summary

The requested at-a-glance indication remains missing: current keybinding lookup and assignment-time counts require interaction and do not provide per-row badges or a duplicates-only view. Keep this accepted Backlog request open; it has 23 upvotes, and no qualifying older canonical was identified.

## Change summary

Show a count beside shared keyboard shortcuts in the Keyboard Shortcuts editor, optionally with a filter showing only shared shortcuts.

## Best solution

Provide an accessible, theme-consistent way to recognize shared shortcuts while browsing the Keyboard Shortcuts editor, preserving the existing Show Same Keybindings action. Settle the count semantics and whether the additional shared-shortcuts filter belongs in the initial scope before implementation.
