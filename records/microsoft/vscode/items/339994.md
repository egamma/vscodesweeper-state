# Issue #339994 — Active Tab Border Top color customization no longer working

[https://github.com/microsoft/vscode/issues/339994](https://github.com/microsoft/vscode/issues/339994)

## Summary

This is the same root cause as the open, older, more-discussed issue about `workbench.colorCustomizations` breaking under the new Modern UI tabs — this report is a specific instance (tab.activeBorderTop) of that general regression, so I'm proposing a duplicate close to consolidate.

## Change summary

After upgrading from 1.138.0 to 1.140.0, the `workbench.colorCustomizations` setting for `tab.activeBorderTop` no longer has any visible effect on the active tab's top border.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/326445 (oldest, 21 reactions, already assigned/being worked under the `modernization` effort) — fixing the general colorCustomizations-vs-Modern-UI regression there covers this tab-border case too.
