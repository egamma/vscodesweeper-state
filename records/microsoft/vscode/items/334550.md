# Issue #334550 — Claude Code and Codex icons in Activity Bar disappeared / not clickable over Remote-SSH

[https://github.com/microsoft/vscode/issues/334550](https://github.com/microsoft/vscode/issues/334550)

## Summary

This is a narrower instance of the broader, already-tracked regression: extension-contributed icons (activity bar, editor tabs, status bar) failing to render over Remote-SSH since 1.136.0 because the product icon font (glicons.woff2) fails to load under the vscode-remote scheme. That issue is open, well-diagnosed, and owns the full scope of this report.

## Change summary

Claude Code and Codex Activity Bar icons are missing/unclickable specifically in Remote-SSH sessions, with no local-window issue.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/334144, which tracks the root cause (glicons.woff2 failing to load with `net::ERR_FAILED` under the vscode-remote theme since 1.136.0) and already covers the same symptom for GitLens, Azure, and other extensions' icons — fixing the font-loading regression there resolves this report too.
