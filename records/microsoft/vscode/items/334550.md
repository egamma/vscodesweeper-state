# Issue #334550 — Claude Code and Codex icons in Activity Bar disappeared / not clickable over Remote-SSH

[https://github.com/microsoft/vscode/issues/334550](https://github.com/microsoft/vscode/issues/334550)

## Summary

Multiple independent reporters (including a contributor) confirm Activity Bar icons for various extensions are missing/unclickable specifically over Remote-SSH, with one commenter reporting a rollback to 1.135 restores them — this looks like a real, recurring core regression in remote resource loading rather than a one-off, so it should be routed to the right area rather than closed.

## Change summary

Over a Remote-SSH connection, Activity Bar icons for extensions (Claude Code, Codex, GitLens, others) intermittently go missing or become unclickable.

## Best solution

Investigate whether this is a repeat of the vscode-remote-resource/vscode-managed-remote-resource CORS/resource-loading regression fixed for https://github.com/microsoft/vscode/issues/318954 (PR https://github.com/microsoft/vscode/pull/319532) — current main already has corsEnabled set for both schemes in src/main.ts, so if the symptom is back it's likely a fresh Electron-version side effect rather than the same regression; a maintainer with remote-session repro access should confirm and bisect against the 1.135→1.136+ range the commenter flagged.
