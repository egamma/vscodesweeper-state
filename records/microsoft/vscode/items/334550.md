# Issue #334550 — Claude Code and Codex icons in Activity Bar disappeared / not clickable over Remote-SSH

[https://github.com/microsoft/vscode/issues/334550](https://github.com/microsoft/vscode/issues/334550)

## Summary

Real, multiply-confirmed regression, but the root cause and the working workaround (`remote.SSH.useExecServer: false`) point to the Remote-SSH extension's exec-server mode, not core VS Code code in this repo — that extension is VS Code-team-owned and tracked in microsoft/vscode-remote-release, so this should be moved there rather than fixed or closed here.

## Change summary

Extension-contributed Activity Bar and editor-tab icons (Claude Code, Codex, GitLens, others) render invisible/unclickable over Remote-SSH after a recent update.

## Best solution

Move this issue to microsoft/vscode-remote-release, where https://github.com/microsoft/vscode-remote-release/issues/11684 ("Extension icons present but not visible") already tracks the same symptom; the Remote-SSH team should investigate why enabling `remote.SSH.useExecServer` breaks icon rendering for remote-contributed views/tabs.
