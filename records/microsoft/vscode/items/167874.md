# Issue #167874 — Allow static contribution of status bar items

[https://github.com/microsoft/vscode/issues/167874](https://github.com/microsoft/vscode/issues/167874)

## Summary

Keep open: static status-bar contributions were implemented and tested, but remain a proposed API unavailable to ordinary extensions. The issue still tracks API finalization and the unresolved `when`-clause requirement.

## Change summary

Allow extensions to declare status-bar items in package.json without activating at startup.

## Best solution

Finalize `contributes.statusBarItems` after API review, including a decision on declarative visibility conditions, while preserving the existing transition from a static item to a dynamic `StatusBarItem`.

- **Fit:** aligned
- **Reason:** Declarative contributions avoid unnecessary extension activation while strengthening extension capabilities without adding bundled core functionality.
- **Evidence:** Public values: “Performance trumps functionality” and “The power lives in extensions.”
