# Issue #320066 — GitHub Copilot Chat view cannot be scrolled using Page Up/Page Down keys, only mouse wheel works

[https://github.com/microsoft/vscode/issues/320066](https://github.com/microsoft/vscode/issues/320066)

## Summary

The keyboard gap remains on current main when focus is in the chat composer: generic Page Up/Page Down list commands are explicitly unavailable while an input is focused. A maintainer already classified this as a bug and placed it in Backlog, so it should stay open while the focus and multiline-input semantics are designed.

## Change summary

Allow keyboard users to page-scroll a long Copilot Chat transcript without requiring the mouse or scrollbar.

## Best solution

Provide predictable Page Up/Page Down transcript scrolling from the normal post-request focus state while preserving intentional page navigation in multiline prompts. Document the resulting behavior in Chat Accessibility Help.
