# Issue #320066 — GitHub Copilot Chat view cannot be scrolled using Page Up/Page Down keys, only mouse wheel works

[https://github.com/microsoft/vscode/issues/320066](https://github.com/microsoft/vscode/issues/320066)

## Summary

Verified duplicate of the older open list-paging issue: both report that Page Up/Page Down cannot scroll within a long chat response because list paging navigates between rows rather than through an oversized row.

## Change summary

Make Page Up and Page Down scroll through long Copilot Chat responses for keyboard and screen-reader users.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/226194 and make list paging scroll the viewport when the focused row itself spans multiple pages; fixing the shared list behavior will cover Chat and other lists with oversized rows.
