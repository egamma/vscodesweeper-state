# Issue #98098 — API Proposal for multiline quick input

[https://github.com/microsoft/vscode/issues/98098](https://github.com/microsoft/vscode/issues/98098)

## Summary

Keep this API proposal open: current quick input APIs still lack multiline support, and the maintainer explicitly retained the request when closing the implementation attempt. The api-proposal label also protects this tracking issue from cleanup closes.

## Change summary

Expose multiline quick input to extensions so users can enter and preserve line breaks through showInputBox.

## Best solution

Provide an API-owner-approved multiline quick input contract, following the maintainer's stated preference for a Monaco-backed input. Preserve existing single-line behavior and retain this issue through API finalization.
