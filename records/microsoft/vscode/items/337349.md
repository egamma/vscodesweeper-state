# Issue #337349 — Diff editor toolbar can split Previous/Next Change actions when space is limited

[https://github.com/microsoft/vscode/issues/337349](https://github.com/microsoft/vscode/issues/337349)

## Summary

Keep open as a request for paired-action overflow behavior. Current source handles the two navigation commands independently, and the related toolbar requests do not own this specific requirement.

## Change summary

Keep Previous Change and Next Change together when diff-editor title actions overflow.

## Best solution

Treat the diff-navigation pair as one overflow unit in the editor-title toolbar, while preserving individual commands, keyboard shortcuts, and deliberate action hiding. This should not require changing the overall toolbar capacity or making unrelated menu groups indivisible.
