# Issue #250764 — onDidEndTerminalShellExecution not received for commands that contain newlines

[https://github.com/microsoft/vscode/issues/250764](https://github.com/microsoft/vscode/issues/250764)

## Summary

Still unfixed on main: the bash shell integration script does not emit the `]633;D` completion marker after multi-line commands, so `onDidEndTerminalShellExecution` and `read()` never fire. No fix commit exists; the bug is confirmed and well-understood.

## Change summary

Commands containing newlines executed via `shellIntegration.executeCommand()` never emit `onDidEndTerminalShellExecution` because the bash `]633;D` marker is not delivered for multi-line input sequences.

## Best solution

Fix the bash shell integration script (`src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-bash.sh`) so that the `__vsc_command_complete` / `__vsc_precmd` flow correctly emits the `]633;D` marker even when the executed command spans multiple lines. This likely involves ensuring PROMPT_COMMAND fires reliably after multi-line command execution. Issues https://github.com/microsoft/vscode/issues/316556 and https://github.com/microsoft/vscode/issues/324392 are satellites of the same root cause and should be consolidated once a fix lands.
