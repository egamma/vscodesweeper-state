# Issue #250764 — onDidEndTerminalShellExecution not received for commands that contain newlines

[https://github.com/microsoft/vscode/issues/250764](https://github.com/microsoft/vscode/issues/250764)

## Summary

Keep open: the report and subsequent reproduction evidence establish missing completion signals for multiline Bash executions, and no verified fix was identified. The related open reports are newer and cannot replace this re-reviewed issue as its canonical.

## Change summary

Commands containing literal newlines can execute successfully in Bash without delivering the expected terminal shell execution completion event.

## Best solution

Restore reliable completion reporting for the execution returned by executeCommand(), preserving output streaming and execution identity across multiline input. First distinguish missing shell markers from extension-host execution matching failures using the original quoted-newline example.
