# Issue #340573 — Agent sessions from Codex and Claude missing from Chat Sessions list

[https://github.com/microsoft/vscode/issues/340573](https://github.com/microsoft/vscode/issues/340573)

## Summary

Thanks for the detailed report and follow-ups. The reporter's own diagnostics split this into several causes: Codex was hidden by the `chat.editor.codex.preferAgentHost` setting, Claude needed its SDK downloaded, and newer Claude sessions are not found because discovery runs once at startup. Related open issues already cover the Claude parts, and I did not trace the code to confirm these causes, so this stays open.

## Change summary

Prior Codex and Claude sessions, and later new Claude sessions, are missing from the native Chat Sessions list.

## Best solution

Confirm the cause for each provider and fix it separately. Claude discovery should retry after the SDK becomes available, and it should rediscover new sessions after startup. The Codex agent-host and extension preference interaction should not silently hide the extension's sessions. Track the Claude rediscovery work in https://github.com/microsoft/vscode/issues/335215 and https://github.com/microsoft/vscode/issues/334170.
