# Issue #340573 — Agent sessions from Codex and Claude missing from Chat Sessions list

[https://github.com/microsoft/vscode/issues/340573](https://github.com/microsoft/vscode/issues/340573)

## Summary

Thanks for the detailed report and follow-up. The reporter found two separate causes. Codex history returned after setting chat.editor.codex.preferAgentHost to false. Claude history returned after downloading the Claude agent SDK, which matches the 'SDK not ready; deferring discovery' behavior in the related issue 334170. Because the Claude SDK was never downloaded, discovery stayed deferred and the user saw nothing, with no hint why. Nothing was executed here, so the code behavior is unverified. The report also overlaps related open issues without clearly being the same symptom, so it stays open.

## Change summary

Codex and Claude sessions stopped appearing in the native Chat Sessions list on 1.141.0 even though local session data still exists.

## Best solution

Make agent-host Codex/Claude discovery visibly recover. Download the Claude SDK automatically or prompt for it, and retry discovery once it is ready. Make the Codex agent-host preference and the OpenAI extension contribution (the 'openai-codex' session source from the Codex extension) fail gracefully or explain which implementation is active, so history does not silently disappear.
