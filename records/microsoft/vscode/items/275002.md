# Issue #275002 — Why does scm.repositories.selectionMode single exist?

[https://github.com/microsoft/vscode/issues/275002](https://github.com/microsoft/vscode/issues/275002)

## Summary

Keep open for the SCM owner's design decision: single selection affects initial repository visibility and repository exploration, not merely whether Shift-selection is allowed. The existing scm and under-discussion labels are appropriate, and the Backlog milestone rules out a judgment-based close.

## Change summary

Consider removing single-repository selection mode and permitting modifier-based multi-selection universally.

## Best solution

Resolve whether one selection model can preserve a focused Changes view while supporting repository exploration and deliberate multi-selection. Retain both modes until the SCM owner settles that user-visible behavior; changing the default alone does not answer the request.
