# Issue #208093 — add raiseWindow function

[https://github.com/microsoft/vscode/issues/208093](https://github.com/microsoft/vscode/issues/208093)

## Summary

The central capability is now implemented: extensions can invoke workbench.action.focusWindow to bring their editor window to the foreground. This supports closing the request as completed without changing LSP showDocument semantics.

## Change summary

Provide an extension-callable operation that raises the current editor window, enabling browser-originated source navigation to become visible.

## Best solution

Use vscode.commands.executeCommand('workbench.action.focusWindow') for explicit foreground activation alongside document navigation. Retain existing showDocument focus semantics rather than making every navigation request raise the application.
