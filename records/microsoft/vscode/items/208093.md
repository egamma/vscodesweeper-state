# Issue #208093 — add raiseWindow function

[https://github.com/microsoft/vscode/issues/208093](https://github.com/microsoft/vscode/issues/208093)

## Summary

This remains a valid, highly supported Backlog API request. Current main has internal foreground-focus support but no equivalent extension API.

## Change summary

Expose an extension API that can raise the current VS Code window after externally initiated navigation.

## Best solution

Design a narrowly scoped window-raising API with safeguards against unsolicited focus stealing, then use it for workflows such as gopls browser-to-editor navigation.
