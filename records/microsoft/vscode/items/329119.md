# Issue #329119 — Agents window becomes sluggish from responsive toolbar layout storm

[https://github.com/microsoft/vscode/issues/329119](https://github.com/microsoft/vscode/issues/329119)

## Summary

Well-diagnosed, real performance bug in the Agents window's use of the responsive ToolBar with a concrete DevTools trace and a detailed, technically sound fix plan; already correctly labeled `debt`/`perf` and just needs engineering time.

## Change summary

Running multiple concurrent agent sessions causes a layout-thrashing storm from the responsive toolbar's synchronous ResizeObserver callback, making the Agents window sluggish while scrolling.

## Best solution

Implement the proposed plan in src/vs/base/browser/ui/toolbar/toolbar.ts: switch the raw `ResizeObserver` to the existing `DisposableResizeObserver` helper (already on main in src/vs/base/browser/dom.ts) and coalesce responsive updates to one scheduled pass per animation frame, with the listed regression tests covering `kind: 'last'/'all'`, relayout, custom observedElement, and auxiliary-window realms.
