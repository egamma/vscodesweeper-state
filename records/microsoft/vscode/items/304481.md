# Issue #304481 — Markdown preview links with anchor to line-numbers does not work

[https://github.com/microsoft/vscode/issues/304481](https://github.com/microsoft/vscode/issues/304481)

## Summary

Confirmed bug: line-number anchors (#L44) in markdown preview links fall through to preview scroll logic (which only understands heading anchors), so the file opens at line 1. An open PR (#308428) addresses this directly.

## Change summary

Clicking a `#L<n>` anchor link in markdown preview opens the target file at line 1 instead of the specified line.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/308428, which gates the preview-open path on whether the fragment is a line-number pattern, falling through to `openDocumentLink` (which correctly parses line anchors) when it is.
