# Issue #343501 — Language Models: Copilot CLI configuration tries to recreate an existing settings-only group

[https://github.com/microsoft/vscode/issues/343501](https://github.com/microsoft/vscode/issues/343501)

## Summary

The reported settings-only group failure is confirmed in current source: model configuration attempts to recreate the persisted group. Keep this open for a bounded correction; the related reports concern different behaviors.

## Change summary

Opening configuration for a default-provided Copilot CLI model throws a duplicate-group exception when its settings-only group already exists.

## Best solution

Allow configuring the model through its existing persisted settings-only group without recreating it or losing overrides. Preserve group-specific ownership for providers that resolve models separately per configured group.
