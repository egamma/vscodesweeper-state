# Issue #343501 — Language Models: Copilot CLI configuration tries to recreate an existing settings-only group

[https://github.com/microsoft/vscode/issues/343501](https://github.com/microsoft/vscode/issues/343501)

## Summary

The reported settings-only group failure remains reproducible from current source: model configuration attempts to recreate an existing group. Keep this open for a bounded fix that preserves existing overrides.

## Change summary

Allow configuring a default-provided model when its vendor already has a settings-only configuration group.

## Best solution

Opening model configuration should reuse the appropriate persisted settings-only group without creating a duplicate or losing overrides, while preserving configured-provider model ownership.
