# Issue #343501 — Language Models: Copilot CLI configuration tries to recreate an existing settings-only group

[https://github.com/microsoft/vscode/issues/343501](https://github.com/microsoft/vscode/issues/343501)

## Summary

Keep open: current source confirms that configuring a default-provided model can attempt to recreate its existing settings-only group. The report supplies enough detail to diagnose this without requesting a fresh-profile reproduction.

## Change summary

Allow model configuration to reuse an existing settings-only provider group without throwing a duplicate-group exception or losing overrides.

## Best solution

Make the LanguageModelsService configuration flow recognize persisted settings-only groups while retaining correct ownership for models defined by configurable provider groups. Opening configuration should preserve existing settings and keep the JSON valid.
