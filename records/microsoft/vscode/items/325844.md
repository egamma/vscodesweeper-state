# Issue #325844 — Feature request: Support bring-your-own-model (BYO) routers (e.g. OpenRouter Fusion Router)

[https://github.com/microsoft/vscode/issues/325844](https://github.com/microsoft/vscode/issues/325844)

## Summary

Valid feature request from a team member for first-class support of BYO model routers (e.g. OpenRouter Fusion) in Chat/agent mode. Distinct from existing BYOK issues — this focuses on router-specific capabilities (server-injected tools, pass-through parameters, intermediate state). Routes to model-byok and chat-lm-management areas.

## Change summary

Support BYO model routers that alias multiple models behind a single endpoint, including router-specific parameters, server-injected tools, and streaming of intermediate router state.

## Best solution

Extend the BYOK custom-endpoint infrastructure to accommodate router endpoints: allow dynamic model slug registration, pass-through of provider-specific request parameters (plugins, preset, tool_choice), and handle server-injected tool types so tool calling works end-to-end. Related but distinct from https://github.com/microsoft/vscode/issues/319968 (model discovery) which covers one piece of this ask.
