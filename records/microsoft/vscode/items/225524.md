# Issue #225524 — Forward/Back buttons on mouse do not work in fullscreen/maximized window on macOS Sonoma

[https://github.com/microsoft/vscode/issues/225524](https://github.com/microsoft/vscode/issues/225524)

## Summary

Keep open as an upstream macOS mouse-navigation issue. The discussion confirms continuing failures, and related maintainer diagnostics identify missing Chromium mouse events; neither a verified fix nor an open canonical covering the fullscreen-specific symptom was found.

## Change summary

Logitech Back/Forward mouse actions should navigate editor history in macOS fullscreen as they do in windowed mode.

## Best solution

Establish whether Logi Options+ navigation actions reach Electron/Chromium in fullscreen and resolve the missing-event behavior at that boundary. Preserve VS Code's existing mouse navigation handling; keyboard remapping is an interim workaround, not fulfillment of the request.
