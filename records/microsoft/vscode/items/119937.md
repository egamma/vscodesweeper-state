# Issue #119937 — profile.allowCompactBoolean does not work with jsx

[https://github.com/microsoft/vscode/issues/119937](https://github.com/microsoft/vscode/issues/119937)

## Summary

Still reproduces on main — the root cause is in the upstream emmetio/emmet library which cannot support both allowCompactBoolean and XML selfClosingStyle simultaneously for JSX. The upstream issue remains open.

## Change summary

Emmet's `profile.allowCompactBoolean` preference has no effect in JSX because VS Code forces `selfClosingStyle: 'xhtml'` for JSX, and the upstream emmet library doesn't support compact booleans when selfClosingStyle is xml/xhtml.

## Best solution

Wait for the upstream fix in https://github.com/emmetio/emmet/issues/645 — once emmetio/emmet supports both compact booleans and XML self-closing style simultaneously, VS Code's emmet extension will inherit the fix. No local workaround is feasible without patching the upstream library.
