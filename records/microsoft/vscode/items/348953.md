# Issue #348953 — Agents window: Progress accessibility sound loops when opening certain idle chats

[https://github.com/microsoft/vscode/issues/348953](https://github.com/microsoft/vscode/issues/348953)

## Summary

Keep open: the report provides concrete steps for an idle-chat accessibility regression. Current main tracks request completion and model disposal, but those safeguards do not establish that the affected restored chats are fixed; the supplied steps suffice to retest.

## Change summary

Opening certain idle Agents-window chats starts a repeating Progress accessibility sound that persists after a completed reply.

## Best solution

Identify which progress scheduler starts when the affected chat is restored and reconcile its lifetime with actual request activity. Preserve progress feedback for genuinely running requests and silence completed or idle sessions.
