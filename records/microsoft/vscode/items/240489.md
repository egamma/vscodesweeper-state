# Issue #240489 — SCM Graph - add an action to manually set the merge base

[https://github.com/microsoft/vscode/issues/240489](https://github.com/microsoft/vscode/issues/240489)

## Summary

Valid feature request, already triaged by the area owner (lszomoru). The maintainer diagnosed the root cause — merge base detection is inherently error-prone when the branch was created on a different machine — and proposed adding a UI action to manually set the merge base. No implementation exists on current main. On Deck milestone; keeping open.

## Change summary

Add a UI action in the SCM Graph to let users manually set the merge base for a branch.

## Best solution

Implement a context menu or quick-pick action in the SCM Graph view that writes `branch.<name>.vscode-merge-base` to the local git config, letting users override the auto-detected base. The logic lives in `extensions/git/src/repository.ts` (merge-base detection) and `src/vs/workbench/contrib/scm/browser/scmHistoryViewPane.ts` (graph UI).
