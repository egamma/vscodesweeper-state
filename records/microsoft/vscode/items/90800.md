# Issue #90800 — Key binding condition for "is merging conflicts"?

[https://github.com/microsoft/vscode/issues/90800](https://github.com/microsoft/vscode/issues/90800)

## Summary

The requested capability — a context key for when merge conflicts are present — was implemented via the `mergeConflictsCount` context key in PR #97613, shipped in VS Code 1.56. Users can now use `mergeConflictsCount != 0` in keybinding `when` clauses.

## Change summary

Expose a keybinding `when`-clause context key indicating whether the active editor has merge conflicts, enabling conditional key bindings.

## Best solution

Keep the shipped `mergeConflictsCount` context key (landed in commit 96d0dc4154d, VS Code 1.56). The user can bind the same key to both 'next change' and 'next conflict' using `when: mergeConflictsCount != 0` to disambiguate. No further work needed.
