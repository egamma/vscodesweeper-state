# Issue #229174 — Window is often its minimum size after starting VS Code

## Summary

Keep open: maintainer analysis ties the startup minimum-size problem to Electron's mixed-DPI window bounds APIs. No verified fix or older canonical reporting the same startup symptom was found.

## Change summary

Preserve the intended window size across restarts after moving windows between Windows monitors using 100% and 200% scaling.

## Best solution
