# Issue #229174 — Window is often its minimum size after starting VS Code

[https://github.com/microsoft/vscode/issues/229174](https://github.com/microsoft/vscode/issues/229174)

## Summary

Root cause is in Electron's display/bounds APIs on Windows multi-monitor setups with different DPI scales. A team member (deepak1556) confirmed the issue traces to known Electron bugs and indicated need for a multi-monitor setup to investigate further. The issue remains valid upstream and should stay open.

## Change summary

VS Code window often restores at minimum size on startup when using Windows multi-monitor with different DPI scales (100% + 200%).

## Best solution

The fix belongs in Electron's display bounds APIs (electron/electron#10862, electron/electron#29605). VS Code may need a workaround in `serializeWindowState`/`restoreWindowState` in `src/vs/platform/windows/electron-main/windowImpl.ts` if the upstream fix does not land. deepak1556 was investigating whether the runtime calculates bounds with the wrong display between startup and shutdown — that investigation should continue on a multi-monitor test rig.
