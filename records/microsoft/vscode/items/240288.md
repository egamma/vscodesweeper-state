# Issue #240288 — ShellType API does not detect `gitbash` on windows

[https://github.com/microsoft/vscode/issues/240288](https://github.com/microsoft/vscode/issues/240288)

## Summary

Still reproducible on main: the `guessShellTypeFromExecutable` function in `terminalInstance.ts` uses regexes like `/^bash$/` that don't account for the `.exe` suffix on Windows, so the early shell-type guess fails. The `WindowsShellHelper` path does handle `.exe` correctly, but there may be a timing or propagation gap causing the extension API to see `undefined`.

## Change summary

The terminal ShellType API reports `undefined` instead of `gitbash` when a Git Bash terminal is opened on Windows.

## Best solution

Fix `guessShellTypeFromExecutable` in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts` to strip the `.exe` extension from `exeBasename` before matching on Windows. This aligns the early guess with the `WindowsShellHelper.getShellType()` logic that already handles `.exe` correctly. Additionally, verify that the `WindowsShellHelper` detection propagates to the extension host API (`$acceptTerminalShellType`) in all cases.
