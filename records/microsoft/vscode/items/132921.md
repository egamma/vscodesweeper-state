# Issue #132921 — Show underline warning in settings JSON file when value matches default

[https://github.com/microsoft/vscode/issues/132921](https://github.com/microsoft/vscode/issues/132921)

## Summary

Valid feature request not yet implemented — the UnsupportedSettingsRenderer in preferencesRenderers.ts already provides diagnostics for unsupported/policy/profile settings in JSON files, but there is no check for settings whose value matches the default. Keeping open as a reasonable enhancement to the existing diagnostics infrastructure.

## Change summary

Show a hint/warning underline in settings.json when a setting's value matches its default, indicating it is redundant.

## Best solution

Add a default-value comparison check in UnsupportedSettingsRenderer.generateMarkerData() (src/vs/workbench/contrib/preferences/browser/preferencesRenderers.ts) that emits a MarkerSeverity.Hint with MarkerTag.Unnecessary when the configured value equals the registered default. Could include a code action to remove the redundant entry.
