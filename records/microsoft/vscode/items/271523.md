# Issue #271523 — Support codicons in tree item label

[https://github.com/microsoft/vscode/issues/271523](https://github.com/microsoft/vscode/issues/271523)

## Summary

Codicon rendering is implemented behind a proposed API, but stable TreeItem labels still accept strings only. Keep this api-proposal tracking issue open until the API owners finalize or explicitly abandon the proposal.

## Change summary

Allow extension-provided tree item labels to contain codicons instead of relying on inconsistent emoji rendering.

## Best solution

Retain this issue as the tracking record for evaluating and finalizing treeItemMarkdownLabel, so extension authors can eventually use consistent inline icons through a stable API.
