# Issue #271523 — Support codicons in tree item label

[https://github.com/microsoft/vscode/issues/271523](https://github.com/microsoft/vscode/issues/271523)

## Summary

The initial implementation landed as a proposed API (`treeItemMarkdownLabel`) via PR #272435, but the API has not been finalized — `checkProposedApiEnabled` still guards it. This issue tracks the full feature lifecycle including finalization, so it should stay open.

## Change summary

Allow extensions to use codicons (via MarkdownString) in tree item labels instead of relying on emoji.

## Best solution

Finalize the `treeItemMarkdownLabel` proposed API so third-party extensions can use codicons and basic markdown formatting in tree item labels without needing the proposed API flag. The implementation infrastructure is already in place in `src/vs/workbench/browser/parts/views/treeView.ts` and `src/vs/workbench/api/common/extHostTreeViews.ts`.
