# Issue #167015 — Disabling Proxy support does not disable proxy agent redirection

[https://github.com/microsoft/vscode/issues/167015](https://github.com/microsoft/vscode/issues/167015)

## Summary

Still reproduces on current main: the node request service unconditionally applies the proxy agent (line 106 of requestService.ts) regardless of the `http.proxySupport` setting, which only controls extension proxy behavior. The reporter's request — that core requests also respect the 'off' setting — remains unaddressed.

## Change summary

Setting `http.proxySupport` to 'off' does not prevent VS Code's core node request service from using the proxy agent derived from environment variables.

## Best solution

Guard the proxy agent, strictSSL, and proxy-authorization header application in `src/vs/platform/request/node/requestService.ts` behind a check of the `http.proxySupport` setting so that when it is 'off', the core request service skips proxy agent creation from environment variables. The setting description should also be broadened beyond 'for extensions'.
