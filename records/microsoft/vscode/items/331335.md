# Issue #331335 — Customizations migration: 'No workspace skills folder is configured for the active harness'

[https://github.com/microsoft/vscode/issues/331335](https://github.com/microsoft/vscode/issues/331335)

## Summary

Team-authored bug from active testing of the Customizations-to-Agent-Host migration flow: the error message shown when no session is active is confusing and doesn't tell the user what to do; the reporter found the fix themselves (start an agent host session) and suggests better copy or a 'restart agent host' action.

## Change summary

During customization migration, if no active agent host session exists, the target-folder lookup returns empty and shows an unhelpful 'No workspace/global skills folder is configured for the active harness' error instead of guiding the user to start a session.

## Best solution

In aiCustomizationManagementEditor.ts's getMissingMigrationTargetFolderMessage/resolveCustomizationMigrationTargetFolders flow, detect the no-active-session case explicitly and either offer a command to start/restart the agent host session or word the message to say so, rather than a generic 'not configured for the active harness' message.
