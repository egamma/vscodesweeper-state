# Issue #331335 — Customizations migration: 'No workspace skills folder is configured for the active harness'

[https://github.com/microsoft/vscode/issues/331335](https://github.com/microsoft/vscode/issues/331335)

## Summary

Keep open: the reporter confirmed that starting an Agent Host session unblocked migration, exposing a confusing initialization prerequisite. Current source retains the missing-folder error, but does not conclusively establish whether the original session prerequisite still occurs; no issue-referencing fix was found for this team-authored report.

## Change summary

Customization migration reports missing workspace or global skills folders when the active harness has not yet been initialized through a session.

## Best solution

Make migration distinguish unavailable harness initialization from genuinely missing destinations, with an actionable recovery path in the Agent Customizations editor. Retest the first-session scenario before deciding whether recovery should initialize the harness automatically or explicitly guide the user.
