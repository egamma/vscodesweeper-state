# Issue #152518 — Find/Search inputs: Allow setting input font, like in SCM.

[https://github.com/microsoft/vscode/issues/152518](https://github.com/microsoft/vscode/issues/152518)

## Summary

Keep this accepted request open: configurable search-input typography remains missing in the inspected source, and maintainers explicitly retained this issue separately from workbench-wide and editor-find requests. Its 28 upvotes support retaining it in the Backlog.

## Change summary

Allow users to customize the font family and size of Search view inputs, with consistent consideration for editor find/replace inputs.

## Best solution

Provide supported input-font customization in the Search view while preserving existing defaults and reliable input sizing. Coordinate the editor find/replace behavior with https://github.com/microsoft/vscode/issues/101064 rather than treating that narrower request as a duplicate canonical.
