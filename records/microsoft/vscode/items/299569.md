# Issue #299569 — Move chat fork tip to be in session

[https://github.com/microsoft/vscode/issues/299569](https://github.com/microsoft/vscode/issues/299569)

## Summary

Keep open: current source still offers the clickable fork tip only in an empty chat, before there is a conversation to fork. The older contextual-tips issue provides a design dependency, but does not document the same fork-specific symptom required for a duplicate close on this re-reviewed item.

## Change summary

Show the fork tip during an existing conversation, when its command can actually branch the session.

## Best solution

Make fork guidance discoverable in a fork-capable conversation rather than exclusively in the empty state, using the contextual-tip design discussed in https://github.com/microsoft/vscode/issues/298997. Settle its placement and trigger without moving unrelated getting-started tips into active conversations.
