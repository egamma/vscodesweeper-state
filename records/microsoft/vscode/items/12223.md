# Issue #12223 — Possibility to display line endings in text area

[https://github.com/microsoft/vscode/issues/12223](https://github.com/microsoft/vscode/issues/12223)

## Summary

Keep open in the Backlog: current main still lacks native per-line EOL rendering, and 289 community upvotes strongly exceed the feature-request promotion threshold. This is the oldest and best canonical issue for the request.

## Change summary

Add optional editor glyphs that display and distinguish LF, CRLF, and CR line endings on each line.

## Best solution

Extend the editor rendering and text-buffer model to retain each line's original terminator and render distinct opt-in EOL glyphs. Coordinate with the normalization work in https://github.com/microsoft/vscode/issues/127; the narrower status-bar request at https://github.com/microsoft/vscode/issues/119025 does not replace per-line visualization.

## Evidence

- **current source gap:** On current main, `editor.renderWhitespace` in src/vs/editor/common/config/editorOptions.ts only offers none/boundary/selection/trailing/all, while src/vs/editor/browser/viewParts/whitespace/whitespace.ts renders characters from `lineData.content`; there is no per-line EOL glyph path.
- **text-buffer limitation:** src/vs/editor/common/model/pieceTreeTextBuffer/pieceTreeTextBufferBuilder.ts counts CR, LF, and CRLF but `create()` normalizes mixed terminators to the selected EOL by default, so their per-line identities are not retained for rendering.

- **workaround only:** Comments identify third-party extensions such as https://github.com/sohamkamani/code-eol and https://github.com/Steditor/vsce-line-endings, but current main still has no built-in capability covering the central request.
