[https://github.com/microsoft/vscode/issues/287616](https://github.com/microsoft/vscode/issues/287616)

Keep open to investigate incorrect edit attribution when resuming a chat around a branch checkout. Current source explicitly persists accepted baselines, but the reported restoration sequence remains unverified; the supplied workflow is sufficient to begin retesting without requesting basic information again.

## Change summary

Resuming an old chat and requesting a small edit marks an entire previously created and reportedly accepted file as AI-edited.

## Best solution

Preserve accepted edit attribution across session restoration and branch changes so subsequent review highlights only outstanding agent changes. Investigate the persisted baseline and restoration ordering before choosing a fix, while retaining attribution for genuinely unaccepted edits.
