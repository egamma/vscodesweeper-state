# Issue #256010 — Chat - make messages sticky

[https://github.com/microsoft/vscode/issues/256010](https://github.com/microsoft/vscode/issues/256010)

## Summary

Current main implements sticky user prompts by default, but this team-authored Backlog item cannot be closed as implemented because the implementing PR and commit do not reference it. The original action-access rationale also remains only partially covered because checkpoint controls are explicitly hidden in sticky rows.

## Change summary

Keep the active user message visible while its response scrolls, preserving context and convenient access to message actions.

## Best solution

Keep the shipped sticky-prompt behavior and have the chat owner decide whether sticky rows should also expose contextual actions such as Restore Checkpoint. If prompt pinning alone satisfies the intended scope, a maintainer can close this protected item after confirming that relationship; otherwise this issue should own the remaining action-access work.
