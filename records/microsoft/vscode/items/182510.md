# Issue #182510 — Git - Support the "push.default=current" strategy

[https://github.com/microsoft/vscode/issues/182510](https://github.com/microsoft/vscode/issues/182510)

## Summary

Push and Sync still explicitly target the tracked upstream branch, overriding push.default=current. Keep this open while the existing linked fix PR is reviewed; it has not merged.

## Change summary

Make default Push and Sync respect Git's configured push destination when the local and tracked upstream branch names differ.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/323650 so default Push and the push half of Sync honor Git's destination configuration while pull retains its upstream source and explicitly targeted push commands retain their semantics.
