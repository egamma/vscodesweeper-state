# Issue #202064 — Multi Diff Editor Tab Height not the same as Editor Tabs

[https://github.com/microsoft/vscode/issues/202064](https://github.com/microsoft/vscode/issues/202064)

## Summary

Keep this open: multi-diff headers still use variant-specific heights rather than following editor-tab density. The newer compact layout does not satisfy the requested density integration, and no verified canonical or referenced fix was found.

## Change summary

Align multi-diff file-header heights with editor tabs and make them respond to window.density.editorTabHeight.

## Best solution

Make workbench multi-diff headers follow the editor-tab density convention, with consistent rendered and virtualized heights. Clarify how that alignment applies to the newer card and modern-tab layouts before implementation.
