# Issue #253289 — MCP Server - uninstalling server leaves input behind

[https://github.com/microsoft/vscode/issues/253289](https://github.com/microsoft/vscode/issues/253289)

## Summary

Still reproducible from current source: MCP installation merges declared inputs into the profile configuration, while uninstallation removes only the server entry and preserves the complete input list. This older, team-authored Backlog issue should remain open as the canonical report.

## Change summary

Uninstalling a gallery MCP server removes its server configuration but leaves the input declarations added during installation in mcp.json.

## Best solution

Uninstallation should remove inputs introduced for the removed server when they are no longer referenced, while preserving user-authored inputs and inputs shared with remaining servers.
