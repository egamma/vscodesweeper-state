# Issue #349785 — secret management through keypass instead of vscode conf files

[https://github.com/microsoft/vscode/issues/349785](https://github.com/microsoft/vscode/issues/349785)

## Summary

Existing encrypted secret storage partially addresses this request, but does not provide a general KeePass-backed integration across extensions or replace plaintext configuration values automatically. Keep open for clarification of the integration boundary rather than treating the request as already satisfied.

## Change summary

Allow extensions to obtain API credentials from KeePass or another secret manager instead of storing them in plaintext configuration files.

## Best solution

Prefer a cooperating secret-manager extension and consumer extensions using secure credential APIs, preserving extension isolation. Identify any concrete extension-API gap before considering a new core provider or configuration mechanism.
