# Issue #332641 — Delete permanently doesn't ask for confirmation, but also doesn't delete permanently

[https://github.com/microsoft/vscode/issues/332641](https://github.com/microsoft/vscode/issues/332641)

## Summary

Confirmed real bug: with `explorer.confirmDelete` off, 'Delete Permanently' skips confirmation even though it bypasses Trash — an open, author-linked PR already fixes it, so this should stay open until that PR lands rather than being closed or auto-fixed now.

## Change summary

Delete Permanently in the Explorer respects the explorer.confirmDelete setting (meant for move-to-trash) and silently skips confirmation for true permanent deletion.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/334051 ("Always confirm permanent file deletion", already declares `Fixes #332641`), which changes fileActions.ts so `explorer.confirmDelete` only governs move-to-trash and permanent deletion always confirms.
