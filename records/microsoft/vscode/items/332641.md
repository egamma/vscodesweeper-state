# Issue #332641 — Delete permanently doesn't ask for confirmation, but also doesn't delete permanently

[https://github.com/microsoft/vscode/issues/332641](https://github.com/microsoft/vscode/issues/332641)

## Summary

Keep open for the existing implementation candidate: permanent deletion still shares the confirmation setting with move-to-trash, and the linked fixing PR remains open. The discussion resolves the original information request and accepts bounded Undo support.

## Change summary

Allow move-to-trash without confirmation while requiring confirmation for permanent deletion, even with explorer.confirmDelete disabled.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/334051 so disabling trash confirmations does not suppress permanent-deletion warnings. Preserve the existing bounded Undo behavior, which the reporter explicitly accepted.
