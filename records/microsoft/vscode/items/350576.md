# Issue #350576 — Ctrl+Shift+V is hijacked by .md files when pressed in copilot chat

[https://github.com/microsoft/vscode/issues/350576](https://github.com/microsoft/vscode/issues/350576)

## Summary

Keep open: current source confirms that an active Markdown preview can capture Ctrl+Shift+V while the chat input has focus. The preview shortcut's custom-editor branch lacks a focus requirement and outranks chat's Paste as Text binding.

## Change summary

Prevent Markdown preview toggling from intercepting Ctrl+Shift+V intended to paste plain text into Copilot Chat.

## Best solution

Make Markdown preview keyboard toggling respect focus while preserving toggling within Markdown source and preview editors, and retain chat's existing Paste as Text behavior.
