# Issue #299786 — paste is slow with copilot

[https://github.com/microsoft/vscode/issues/299786](https://github.com/microsoft/vscode/issues/299786)

## Summary

Keep open: several independent reporters confirm multi-second editor paste delays, including immediate improvement when Copilot is disabled. Current source exposes relevant paste-handler and inline-completion paths, but does not establish the bottleneck or a landed fix.

## Change summary

Pasting even small amounts of text can take several seconds and display a spinner when Copilot is enabled.

## Best solution

Restore responsive editor pasting while keeping Copilot available. Profile the confirmed scenario to distinguish time spent awaiting paste providers from inline-completion processing, and retain the browser-without-Copilot report as a potentially separate cause rather than assuming all delays share one defect.
