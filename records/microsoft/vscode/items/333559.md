# Issue #333559 — Migrating skills makes me pick a folder twice

[https://github.com/microsoft/vscode/issues/333559](https://github.com/microsoft/vscode/issues/333559)

## Summary

Team-authored bug (author is a maintainer) reporting a double folder-pick prompt during skill migration; traced a plausible cause in `resolveCustomizationMigrationTargetFolders`, but no fix has landed yet on main, so this stays open per the team-authored keep-open rule.

## Change summary

Migrating skills via the AI Customizations management editor prompts the user to pick a destination folder twice instead of once.

## Best solution

In `aiCustomizationManagementEditor.ts`'s `resolveCustomizationMigrationTargetFolders`, when a target type (e.g. skills) needs both a workspace and a global storage folder and both have multiple candidates, the loop currently calls `pickCustomizationMigrationTargetFolder` once per storage — collapse this into a single combined picker (or otherwise avoid two sequential quick-picks) for the same migration action.
