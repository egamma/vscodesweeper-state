# Issue #241262 — Debug Hover Widget Height Is Computed Inconsistently

[https://github.com/microsoft/vscode/issues/241262](https://github.com/microsoft/vscode/issues/241262)

## Summary

The inconsistent height remains source-reproducible on current main: asynchronous tree population suppresses content-size events without requesting a final layout, leaving the hover sized from stale content until a later tree change triggers layout.

## Change summary

Debug hovers for expandable variables can retain an undersized tree height and unnecessarily require scrolling to see a small number of child values.

## Best solution

Ensure the debug hover is laid out from the current expression's completed tree content while preserving its existing maximum-height, width, and cursor-avoidance behavior.
