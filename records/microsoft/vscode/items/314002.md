# Issue #314002 — Auto-rename integrated terminal based on Claude (or other chat) session name

[https://github.com/microsoft/vscode/issues/314002](https://github.com/microsoft/vscode/issues/314002)

## Summary

Already implemented before this issue was filed: VS Code detects agentic CLIs (Claude Code, Codex, Copilot CLI, Gemini CLI) and automatically uses their escape-sequence title as the terminal tab title, controlled by the `terminal.integrated.tabs.allowAgentCliTitle` setting (default: true). Shipped in 1.117.0.

## Change summary

Request to auto-rename integrated terminal tabs based on the active Claude (or other AI/chat) session name instead of generic shell names.

## Best solution

Keep the shipped behavior from commit b81fc85ac33 — no further change needed. The `terminal.integrated.tabs.allowAgentCliTitle` setting (enabled by default) already makes Claude Code's session title appear as the terminal tab name via escape sequences.
