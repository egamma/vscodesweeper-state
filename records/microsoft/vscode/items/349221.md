# Issue #349221 — Improve file separation visibility in Git: Changes view

[https://github.com/microsoft/vscode/issues/349221](https://github.com/microsoft/vscode/issues/349221)

## Summary

The existing experimental card layout provides the requested visual separation: filled filename headers and bordered file sections within the same scrollable multi-diff editor.

## Change summary

Make file boundaries and filename headers easier to distinguish while scrolling Git: Changes.

## Best solution

Use "multiDiffEditor.experimental.variant": "cards" for the existing separated-file presentation rather than adding another highlighting option.

## Evidence

- **Existing configurable capability:** src/vs/workbench/contrib/multiDiffEditor/common/multiDiffEditor.ts registers multiDiffEditor.experimental.variant with cards and noCards options. The ordinary workbench defaults to noCards; cards is explicitly described as the compact card-based variant.
- **Requested presentation is implemented:** src/vs/editor/browser/widget/multiDiffEditor/multiDiffEditorOptions.ts maps cards to multiDiffEditor-compact and multiDiffEditor-card. In style.css, the card rules give filename headers a sideBarSectionHeader.background fill, borders and rounded corners, and enclose each file's editor in a bordered section. This addresses the reported difficulty identifying file boundaries without leaving the single scrollable view.
- **Why header-color customization alone is insufficient:** colors.ts registers multiDiffEditor.headerBackground, but style.css uses it only for the standard variant. The default compact noCards variant instead has transparent header content over multiDiffEditor.background. The cards setting, rather than that legacy header token, is the relevant existing capability.
