# Issue #146334 — Markdown preview switches to latest open markdown document

[https://github.com/microsoft/vscode/issues/146334](https://github.com/microsoft/vscode/issues/146334)

## Summary

Still reproduces on main: the DynamicMarkdownPreview follows the active editor when unlocked (line 800 in preview.ts), causing the preview to switch documents when a different markdown file is opened. No fix commit exists.

## Change summary

An unlocked markdown preview switches to show a different file when a new markdown document becomes the active editor, even if the original file was closed and the user is just reading the preview.

## Best solution

The dynamic preview should not switch to a new resource when the previously-associated markdown file has been closed — either by tracking whether the original file was explicitly closed and treating that as an implicit lock, or by adding a heuristic that only follows the active editor when the preview's source file is still open. The fix lives in `DynamicMarkdownPreview`'s `onDidChangeActiveTextEditor` handler (~line 794 of extensions/markdown-language-features/src/preview/preview.ts).
