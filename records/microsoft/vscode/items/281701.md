[https://github.com/microsoft/vscode/issues/281701](https://github.com/microsoft/vscode/issues/281701)

## Summary

Keep this accepted Backlog request open: current built-in language contributions do not register Blade, and configurable associations alone cannot provide that language mode. No verified canonical issue or fixing commit was identified.

## Change summary

Recognize Laravel Blade files as Blade by default rather than HTML.

## Best solution

Decide whether Blade should be a bundled language contribution or remain extension-provided. The existing language-contribution and file-association mechanisms can support recognition once Blade is registered; changing detection alone would not supply the missing language mode.
