# Issue #272701 — Remove onDidWriteTerminalData usage in chat extension

[https://github.com/microsoft/vscode/issues/272701](https://github.com/microsoft/vscode/issues/272701)

## Summary

The requested cleanup remains necessary: Copilot still subscribes to onDidWriteTerminalData and uses the resulting buffer. The older terminal buffer API exploration is related, but does not establish that this consumer migration is a duplicate.

## Change summary

Remove Copilot Chat's reliance on the proposed onDidWriteTerminalData API.

## Best solution

Retire the raw-data subscription without silently losing terminal context used by existing Copilot consumers. Establish the replacement's output-coverage contract with the terminal owner before implementation.
