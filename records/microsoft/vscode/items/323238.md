# Issue #323238 — Option to display relative line numbers for virtual/wrapped lines

[https://github.com/microsoft/vscode/issues/323238](https://github.com/microsoft/vscode/issues/323238)

## Summary

Well-articulated feature request with 57 upvotes, already promoted to Backlog by the community process. The capability does not exist on current main — the line number renderer in `lineNumbers.ts` only handles physical lines, with no support for rendering relative numbers on wrapped/virtual lines. No duplicate found.

## Change summary

Display relative line numbers in the gutter for virtual (soft-wrapped) lines, not just physical lines.

## Best solution

Implement a new editor option (e.g. `editor.renderRelativeNumbersOnWrappedLines`) and extend `src/vs/editor/browser/viewParts/lineNumbers/lineNumbers.ts` to compute and render relative distances for wrapped lines. The view-line layout information is available via `ViewLineRenderingData`; the gutter rendering logic needs to iterate wrapped segments and assign relative offsets from the cursor's visual line.
