# Issue #341370 — Agents Window: Can only create PR when working on `main` directly

[https://github.com/microsoft/vscode/issues/341370](https://github.com/microsoft/vscode/issues/341370)

## Summary

Team-authored report, filed yesterday, so it stays open. Current main already has a Commit operation in the Changes editor header and a Sync Changes action once commits are outgoing. Neither is shown in the title bar, so on a `main` folder session the reporter only sees Create PR. The gap that remains is that this is hard to discover and there is no direct commit-and-push.

## Change summary

In a folder session on `main`, the Agents window offers only Create PR; the reporter wants a plain commit and push without using the terminal or spending tokens.

## Best solution

Surface Commit, followed by a push or Sync Changes, as a first-class primary or dropdown action next to Create PR for folder sessions on the default branch. Alternatively, add a single Commit and Push operation to the Changes actions.
