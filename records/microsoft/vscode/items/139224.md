# Issue #139224 — [Test UI] Support Update

[https://github.com/microsoft/vscode/issues/139224](https://github.com/microsoft/vscode/issues/139224)

## Summary

Current source appears to support reporting a parent-suite error through the original test run, but the public API documentation still prohibits updates outside the request's include list. Keep this accepted Backlog request open until that discrepancy and the reported error-peek behavior are resolved; no concrete fixing commit was identified.

## Change summary

Allow a single-test run to report BeforeAll/AfterAll failures on its parent suite without creating a separate run or losing access to the error.

## Best solution

Provide a documented, supported way to report fixture errors on ancestor suites within the original run, preserving individual-test execution scope and inspectable error messages. First establish whether the existing implementation already meets that contract before adding another run-profile option.
