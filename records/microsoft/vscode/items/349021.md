# Issue #349021 — Multi-cursor copy with mixed empty and non-empty selections copies entire unselected line (`editor.emptySelectionClipboard`)

[https://github.com/microsoft/vscode/issues/349021](https://github.com/microsoft/vscode/issues/349021)

## Summary

Keep open for an editor-owner decision: current source and an explicit unit test establish the reported mixed-selection behavior, but no existing setting delivers the requested blank-preserving alternative. The related empty-selection newline regression does not cover copying unselected prefixes.

## Change summary

Copy empty strings for empty cursors when other cursors have selected text, preserving their positions without copying unselected lines.

## Best solution

Have editor owners consider changing mixed-selection copy semantics to preserve empty entries without whole-line fallback, while retaining whole-line copying when all selections are empty. Coordinate with the separate newline-serialization fix without treating it as coverage of this request.
