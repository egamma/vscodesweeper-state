# Issue #327326 — API: Provide a stable terminal session ID across window reloads

[https://github.com/microsoft/vscode/issues/327326](https://github.com/microsoft/vscode/issues/327326)

## Summary

Well-written feature request for a stable terminal session ID across window reloads. No existing API or proposed API covers this; the internal `instanceId` is ephemeral and not exposed. No duplicate found. Leaving it to the community upvote process.

## Change summary

Expose a stable opaque session identifier on `Terminal` that persists across window reloads when the terminal is reattached.

## Best solution

Add a `sessionId` (or similar) readonly property to the `Terminal` extension API, backed by the persistent terminal reconnection ID already maintained internally. Start as a proposed API in `src/vscode-dts/vscode.proposed.terminalSessionId.d.ts`, surface the existing persistent process ID or a dedicated UUID through `ExtHostTerminalService`.
