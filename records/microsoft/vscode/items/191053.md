# Issue #191053 — Multiple untitled notebook editors with same name but different associated path do not distinguish

[https://github.com/microsoft/vscode/issues/191053](https://github.com/microsoft/vscode/issues/191053)

## Summary

Keep open: current source still suppresses the associated-path description until each notebook editor input resolves, leaving initially inactive, same-named tabs indistinguishable. The existing notebook label is appropriate; neither related report owns this tab-description defect.

## Change summary

Show distinguishing directory descriptions immediately for same-named untitled notebooks associated with different paths.

## Best solution

Make associated-path notebook descriptions available on initial tab presentation, including for inactive inputs, while preserving description-free behavior for untitled notebooks without an associated path.
