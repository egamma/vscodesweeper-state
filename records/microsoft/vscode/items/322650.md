# Issue #322650 — Native customization surface for rule packs and instructions

[https://github.com/microsoft/vscode/issues/322650](https://github.com/microsoft/vscode/issues/322650)

## Summary

The requested native customization surface for instructions and rule packs already exists on main as the AI Customization Management Editor — shipping since February 2026 — with dedicated sections for Instructions, Agents, Skills, Prompts, Hooks, and Plugins (reusable packages), all with workspace/user scoping and override support.

## Change summary

Request for a native UI surface to manage reusable agent instructions and rule packs with discoverability, override, and governance.

## Best solution

The AI Customization Management Editor (accessible via `aiCustomization.openManagementEditor`) already delivers all four asks: workspace-level instruction management, reusable plugin packages, visibility of active rules across sections, and local/user/extension storage scoping for overrides. No further core change is needed — if specific sub-features are missing (e.g. a particular governance workflow), those should be filed as narrower, targeted requests.
