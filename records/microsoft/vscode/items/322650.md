# Issue #322650 — Native customization surface for rule packs and instructions

[https://github.com/microsoft/vscode/issues/322650](https://github.com/microsoft/vscode/issues/322650)

## Summary

The Agent Customizations editor already covers instruction discovery and editing, but the requested control over shared rule packs and default overrides is not fully covered. Keep this open to define the remaining capability within the existing editor rather than introduce a second customization surface.

## Change summary

Provide native management of reusable instruction packs, their active rules, and explicit overrides across repositories.

## Best solution

Build on the existing Agent Customizations editor, retaining workspace and user instruction management and plugin-based sharing. Define the remaining instruction-pack and override behavior explicitly, including how users distinguish discovered instructions from those actually applied.
