# Issue #209475 — SCM Input - Allow configuring scm input as a specific language

[https://github.com/microsoft/vscode/issues/209475](https://github.com/microsoft/vscode/issues/209475)

## Summary

Keep this accepted Backlog request open: the SCM input still uses a fixed language mode, and existing configuration does not provide the requested Markdown support. The related Markdown-paste request depends on this capability rather than replacing it.

## Change summary

Allow users to configure the SCM input language so Markdown highlighting, snippets, bracket matching, and language features can apply.

## Best solution

Provide an opt-in language configuration for the embedded SCM input while preserving its current default behavior and SCM-specific integrations. The SCM owner should settle the configuration contract and compatibility expectations before implementation.
