# Issue #219906 — Adapt to the .yml standard templates for new Github issues

[https://github.com/microsoft/vscode/issues/219906](https://github.com/microsoft/vscode/issues/219906)

## Summary

Valid feature request to migrate GitHub issue templates from markdown (.md) to YAML issue forms (.yml). The templates are still markdown-based on current main. With only 1 upvote after over two years and VS Code's primary issue filing path being the built-in issue reporter (not the GitHub templates), this has low traction but remains a reasonable quality-of-life improvement for contributors who file via GitHub directly.

## Change summary

Migrate VS Code's GitHub issue templates from markdown format (.md) to the newer YAML issue forms format (.yml) for a more structured filing experience.

## Best solution

If the team decides to adopt YAML issue forms, convert `.github/ISSUE_TEMPLATE/bug_report.md`, `feature_request.md`, and `copilot_bug_report.md` to `.yml` equivalents with structured fields (dropdowns, required inputs, textareas). However, since VS Code's primary bug-reporting channel is the built-in issue reporter (`Help > Report Issue`), the GitHub templates are a secondary path — the team may intentionally keep them lightweight. This is a process decision for the engineering-system owners.
