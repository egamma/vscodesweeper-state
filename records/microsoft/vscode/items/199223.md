# Issue #199223 — Using 'function' in a Lua string causes wrong indentation

[https://github.com/microsoft/vscode/issues/199223](https://github.com/microsoft/vscode/issues/199223)

## Summary

The reported false indentation remains in the current source: Lua's indentation regex matches function inside quoted strings, and token preprocessing does not remove keywords. The proposed fix was closed without merging; retain this issue for a compatible solution that respects the maintainer's parser-based direction.

## Change summary

Pressing Enter after a Lua string containing the standalone word function incorrectly increases indentation.

## Best solution

Make Lua auto-indentation distinguish actual block-opening keywords from string and comment contents while preserving genuine block indentation. Develop the solution with the editor indentation owner, accounting for the rejected shared-preprocessing approach and Lua's long-bracket strings.
