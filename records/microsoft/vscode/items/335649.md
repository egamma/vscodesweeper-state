# Issue #335649 — Extend VS Code Pet compatibility to work with third-party AI agents (Cline, Kilo Code, etc.)

[https://github.com/microsoft/vscode/issues/335649](https://github.com/microsoft/vscode/issues/335649)

## Summary

This is a valid, still-open API request in its active Backlog Candidates voting period. Current VS Code already animates the pet for extension participants using the built-in Chat surface, but agents with custom chat UI have no public pet activity API, so a narrower gap remains.

## Change summary

Expose an opt-in extension API through which third-party AI agents can trigger appropriate VS Code pet reactions.

## Best solution

Keep generic built-in Chat activity automatic, and decide whether the experimental pet should expose a narrow, capability-oriented extension API for agents using custom UI. Any public contract should describe semantic agent activity rather than pet-specific animation states, allowing the presentation to evolve independently.

- **Reason:** An opt-in integration point for third-party AI agents supports both the extension ecosystem and AI-assisted development without adding mandatory default UI.
