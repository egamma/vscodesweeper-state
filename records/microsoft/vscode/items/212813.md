# Issue #212813 — VSCode started with `--extensionDevelopmentPath` crashes after the computer enters in sleep mode

[https://github.com/microsoft/vscode/issues/212813](https://github.com/microsoft/vscode/issues/212813)

## Summary

Still present on main: the remote extension host skips reconnection for extension-dev-host sessions on socket close, causing VS Code to terminate after sleep. A team member (alexdima) diagnosed the root cause and identified the exact code path but no fix has landed.

## Change summary

VS Code started with `--extensionDevelopmentPath` crashes after computer sleep when connected to a WSL remote, because reconnection is not attempted for debugged remote extension hosts.

## Best solution

Allow reconnection for remote extension hosts in extension development mode on socket close (lines 140–144 in `remoteExtensionHost.ts`), rather than immediately firing `_onExtHostConnectionLost`. The original reason for skipping reconnection is unclear per alexdima's comment; the fix should let the normal reconnection flow proceed for dev hosts as well.
