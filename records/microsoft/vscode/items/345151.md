# Issue #345151 — Add "AI features" filter to builtin changelog viewer

[https://github.com/microsoft/vscode/issues/345151](https://github.com/microsoft/vscode/issues/345151)

## Summary

The built-in release notes viewer does not currently offer AI-content filtering. Keep this as a feature request; disabling AI functionality or hiding release notes entirely does not satisfy the requested selective reading experience.

## Change summary

Allow readers to hide AI-related release note sections, optionally using chat.disableAIFeatures as the default preference.

## Best solution

Evaluate an optional content filter in the release notes viewer, including how sections are categorized and whether chat.disableAIFeatures should affect its default. Preserve access to non-AI changes and consistent heading and table-of-contents navigation.
