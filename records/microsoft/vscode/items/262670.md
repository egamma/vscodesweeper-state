# Issue #262670 — Give time for file saves before refreshing git

[https://github.com/microsoft/vscode/issues/262670](https://github.com/microsoft/vscode/issues/262670)

## Summary

Keep open under discussion: existing autosave modes do not provide the requested sidebar-pointer trigger or coordinate repository refresh with pending saves. The Backlog milestone also rules out a decline close without a later maintainer decision.

## Change summary

Make changes visible when refreshing Source Control while using focus-change autosave, potentially by saving when the pointer enters the sidebar.

## Best solution

Clarify whether Source Control refresh should wait for already-triggered saves or whether a new pointer-triggered autosave behavior is desired. Preserve focus-change autosave semantics rather than treating a fixed 500 ms pause as a guarantee that files have been saved.
