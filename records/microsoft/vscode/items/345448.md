# Issue #345448 — Android: Workbench Uninteractable permanently after opening and closing keyboard

[https://github.com/microsoft/vscode/issues/345448](https://github.com/microsoft/vscode/issues/345448)

## Summary

Keep open: the reporter supplies a concrete keyboard-dismissal trigger and confirms persistence in 1.146.0. The inspected checkout does not establish a fix or the cause; the existing steps suffice for device-level retesting.

## Change summary

Opening and closing the Android software keyboard leaves Explorer and the editor unresponsive to direct interaction until refresh.

## Best solution

Restore normal workbench interaction after keyboard dismissal and tablet-mode transitions. Diagnose touch dispatch and viewport hit-testing on the affected device before deciding whether the fix belongs in VS Code or the browser.
