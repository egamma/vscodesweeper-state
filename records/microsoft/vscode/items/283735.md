# Issue #283735 — Shortcuts are not working with AltGr on Windows

[https://github.com/microsoft/vscode/issues/283735](https://github.com/microsoft/vscode/issues/283735)

## Summary

The issue is real and still present on main — VS Code's keyboard mapper treats Ctrl+Alt and AltGr identically unless `mapAltGrToCtrlAlt` is toggled, which is a binary swap rather than a true disambiguation. Recent comments suggest a possible regression making this worse. The code in windowsKeyboardMapper.ts has not changed to address this.

## Change summary

On Windows with AltGr-capable keyboard layouts, Ctrl+Alt shortcuts and AltGr character input cannot coexist — the setting `keyboard.mapAltGrToCtrlAlt` is all-or-nothing.

## Best solution

Implement proper disambiguation between physical Ctrl+Alt (two separate key presses) and AltGr (single key) in the Windows keyboard mapper, likely by tracking whether the Ctrl modifier came from a real left-Ctrl keydown vs. the synthetic one Windows sends with AltGr. The fix would live in `src/vs/workbench/services/keybinding/common/windowsKeyboardMapper.ts` and possibly `src/vs/base/browser/keyboardEvent.ts`. The recent regression reports (May 2026) from users who previously had working setups may indicate a separate Electron/Chromium behavioral change worth investigating.
