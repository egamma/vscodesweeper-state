# Issue #294841 — [Copilot][Bug] Azure AI Foundry Deployment Url is not usable

[https://github.com/microsoft/vscode/issues/294841](https://github.com/microsoft/vscode/issues/294841)

## Summary

A real Azure BYOK capability gap remains: current main accepts Anthropic Messages URLs through the custom-endpoint provider, but the Azure provider still rejects them and assumes OpenAI-compatible request handling.

## Change summary

Support Claude deployments exposed through Azure AI Foundry's `/anthropic/v1/messages` endpoint in the Azure BYOK provider.

## Best solution

Extend the Azure BYOK provider in `extensions/copilot/src/extension/byok/vscode-node/azureProvider.ts` to recognize the Anthropic Messages API and use the corresponding request shape and Azure authentication, reusing the existing custom-endpoint Messages implementation where possible.
