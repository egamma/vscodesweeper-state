# Issue #230423 — git: Staging a selection stages entire block

[https://github.com/microsoft/vscode/issues/230423](https://github.com/microsoft/vscode/issues/230423)

## Summary

Keep open: the gutter's Stage Selection action still applies entire intersecting inner diff changes, which can include unselected lines. The context-menu workaround follows a different, selection-clipping path; no verified open canonical owns this discrepancy.

## Change summary

Staging selected lines through the diff gutter can stage the entire containing change instead.

## Best solution

Make the gutter's Stage Selection honor selected changed lines consistently with Git: Stage Selected Ranges, while preserving whole-block staging when no selection is active. Address this in the diff gutter's selection-to-edit path without expanding scope to independently staging deleted lines.
