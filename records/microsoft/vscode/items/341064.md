# Issue #341064 — Discover page: Don't install unsupported MCP servers

[https://github.com/microsoft/vscode/issues/341064](https://github.com/microsoft/vscode/issues/341064)

## Summary

Thanks for the report. The 'Unsupported' badge appears only after install, and the Discover page still offers Install. Whether to block install or just warn is a product call, and the issue is brand new from a team-adjacent contributor, so it stays open.

## Change summary

The Discover page lets users install MCP servers that the MCP page then flags as Unsupported; install should be blocked for them.

## Best solution

Compute compatibility for marketplace entries before install and disable or hide Install for unsupported servers, reusing the existing compatibility kinds.
