# Issue #213678 — Undo in notebooks should undo changes across multiple cells

[https://github.com/microsoft/vscode/issues/213678](https://github.com/microsoft/vscode/issues/213678)

## Summary

Still valid on main: workspace edits that touch multiple notebook cells don't merge into a single undo point. No fixing commit references this issue, and rebornix confirmed the expected behavior without resolving it.

## Change summary

Undo in notebooks should revert a multi-cell workspace edit (e.g. from a code action) as a single undo operation rather than requiring one undo per cell.

## Best solution

Ensure that when BulkCellEdits applies edits across multiple cells within the same notebook, and when text edits to cell content models happen alongside structural cell edits, they all share the same UndoRedoGroup so the undo service treats them as one atomic operation. The fix likely lives in the coordination between `BulkCellEdits` and `BulkTextEdits` in `src/vs/workbench/contrib/bulkEdit/browser/`.
