Keep open under discussion: the reporter wants an editor-only font-smoothing choice on Windows, which the existing macOS setting and application-wide runtime argument do not fully provide. ## Evidence

- **Reporter clarified the request:** In https://github.com/microsoft/vscode/issues/239038, the reporter says the suggested disable-lcd-text option did not produce the desired appearance, and the October 29 clarification explicitly requests ClearType on/off for the code editor only rather than reporting a general VS Code malfunction.
- **Existing setting is macOS-only:** src/vs/workbench/browser/workbench.contribution.ts:727–739 registers workbench.fontAliasing with default, antialiased, none, and auto, but includes it only when isMacintosh. In src/vs/workbench/browser/media/style.css, the corresponding font-smoothing rules require .monaco-workbench.mac. This does not satisfy the Windows request.
- **Runtime argument offers partial coverage:** src/mainImpl.ts forwards disable-lcd-text to Electron through app.commandLine.appendSwitch; src/vs/workbench/electron-browser/desktop.contribution.ts exposes it in the argv.json schema. This is an application-level Chromium switch, not an editor-scoped smoothing selector. The discussion at https://github.com/microsoft/vscode/issues/195256#issuecomment-2093091146 also distinguishes removing subpixel color fringing from disabling antialiasing entirely.
- **Older related request is not a verified full duplicate:** https://github.com/microsoft/vscode/issues/53554 is open, dates from 2018, and requests independent editor/terminal antialiasing instead of the existing workbench-wide setting. Its original examples concern macOS, where smoothing control already exists; its Windows comment concerns terminal rendering. It informs the scoping design but does not establish coverage of this report's missing Windows editor rendering modes, so the stronger duplicate bar for a re-reviewed item is not met.
- **Other leads do not resolve the central ask:** https://github.com/microsoft/vscode/issues/137013 requests Edge-style contrast enhancement, not disabling smoothing independently in the editor. https://github.com/microsoft/vscode/issues/27378 concerns typing latency. The closed https://github.com/microsoft/vscode/issues/322035 cites workbench.fontAliasing, whose current macOS restriction prevents treating that resolution as a Windows fix here.
