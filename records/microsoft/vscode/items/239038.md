# Issue #239038 — Font Cleartype

[https://github.com/microsoft/vscode/issues/239038](https://github.com/microsoft/vscode/issues/239038)

## Summary

Keep open as a feature request for editor-only font antialiasing control on Windows. Existing controls do not cover that scope, and the verified related issues do not qualify as duplicate canonicals.

## Change summary

Allow Windows users to select grayscale or unsmoothed font rendering for the code editor without changing the rest of the application.

## Best solution

Establish whether Electron/Chromium can support an editor-scoped rendering mode on Windows, then decide whether to expose it in editor settings. Preserve the distinction between disabling subpixel rendering and disabling all antialiasing; the existing application-wide runtime flag is only partial coverage.
