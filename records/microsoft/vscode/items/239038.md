## Summary

Request for a discoverable UI setting to control font antialiasing/ClearType in the editor. The existing `disable-lcd-text` argv.json option partially addresses this but the user finds it insufficient or hard to discover; the discussion is still open with a team member involved.

## Change summary

Add a user-facing setting to control font antialiasing (ClearType on/off) in the editor, similar to JetBrains IDEs.

## Best solution

The existing `disable-lcd-text` runtime argument covers the Chromium-level LCD text toggle. Whether to promote this to a first-class setting or whether finer-grained control is possible depends on Electron/Chromium capabilities. The team member's engagement suggests this is being evaluated — keep open for that discussion to conclude.
