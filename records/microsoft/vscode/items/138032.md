# Issue #138032 — Show the `vscode.DocumentSymbol.detail` in the breadcrumb UI instead of just the Outline UI

[https://github.com/microsoft/vscode/issues/138032](https://github.com/microsoft/vscode/issues/138032)

## Summary

The requested capability is still missing: current main explicitly hides document-symbol descriptions in the breadcrumb bar, with no setting to reveal them. Keep this team-authored Backlog request open; the older related hover request does not cover displaying detail inline.

## Change summary

Display DocumentSymbol.detail beside symbol names in the breadcrumb bar, potentially through an opt-in control.

## Best solution

Support secondary symbol detail in breadcrumbs without compromising compact navigation or changing extension-provided symbol names. A maintainer should first settle whether details appear by default or through a user-controlled opt-in.
