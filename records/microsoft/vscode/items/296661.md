# Issue #296661 — Autocomplete not working

[https://github.com/microsoft/vscode/issues/296661](https://github.com/microsoft/vscode/issues/296661)

## Summary

This was caused by the quick-suggestions experiment (#293443) that changed the default to `offWhenInlineCompletions`, which suppressed the suggest widget. The behavior was refined and fixed in commit 5a356d228e3 (shipped in 1.112.0), which enhances quick suggestions to work alongside inline completions. The canonical tracking issue #297224 is already closed as resolved.

## Change summary

Autocomplete (quick suggestions) stopped appearing while typing in VS Code Insiders because the `offWhenInlineCompletions` experiment suppressed the suggest widget by default.

## Best solution

Keep the shipped fix from commit 5a356d228e3 (1.112.0) which refined quick suggestions to coexist with inline completions. No further change needed — the reporter should update to a current build.
