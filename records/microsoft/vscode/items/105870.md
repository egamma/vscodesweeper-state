# Issue #105870 — Add streaming support in vscode

[https://github.com/microsoft/vscode/issues/105870](https://github.com/microsoft/vscode/issues/105870)

## Summary

This remains the canonical request for streaming language-feature results. Current main still waits for complete workspace-symbol arrays, and the team-authored Backlog request has 26 community upvotes, so it should remain open.

## Change summary

Support incremental LSP results so language features can display useful results before long-running providers finish.

## Best solution

Add an incremental result channel through the workspace-symbol extension API and extension-host RPC, then update Quick Open in batches while preserving selection and ordering. Workspace symbols are the strongest first scope before considering references, completion, and other providers.
