# Issue #336582 — Chat folder picker flickering, layout issues

[https://github.com/microsoft/vscode/issues/336582](https://github.com/microsoft/vscode/issues/336582)

## Summary

Reopened by the reporter (a VS Code team member) after PR #336593 landed: that fix addressed hover/click behavior and flyout sizing but not the flickering, which the reporter confirms is still happening — likely tied to devtunnel/VPN reconnect events re-rendering the picker. Keep open; the fix commit predates the reopen and cannot be cited as resolving it.

## Change summary

The unified workspace/folder picker's remote submenu flyout flickers and disappears repeatedly, especially during devtunnel reconnects, making it hard to pick a folder.

## Best solution

Diagnose why session/provider change events (e.g. onDidChangeProviders, onDidChangeSessionTypes in sessionWorkspacePicker.ts) fire repeatedly during a devtunnel/VPN reconnect and cause the flyout to rebuild/flicker; debounce or stabilize the re-render path instead of just re-touching layout/hover behavior.
