# Issue #235571 — clicking "Install formatter" points you to the Python extension

[https://github.com/microsoft/vscode/issues/235571](https://github.com/microsoft/vscode/issues/235571)

## Summary

Still reproduces on main: the 'Install Formatter' button uses a marketplace search query (`category:formatters python`) that surfaces the Python extension itself rather than dedicated formatter extensions like autopep8 or black. The query construction in formatActionsNone.ts has not been improved since the issue was filed.

## Change summary

Clicking 'Install Formatter' for Python files points users to the Python extension rather than dedicated Python formatter extensions.

## Best solution

Improve the search query in `src/vs/workbench/contrib/format/browser/formatActionsNone.ts` line 63 to better surface actual formatter-only extensions — e.g. by using `category:Formatters tag:${langName}` or adding a keyword filter. Alternatively, the formatter extensions (autopep8, black) could adjust their package.json metadata, but since the core query drives user experience, a core-side improvement is warranted.
