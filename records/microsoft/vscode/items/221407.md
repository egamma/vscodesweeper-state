# Issue #221407 — sudo reboot now shows the characters I typed in zsh for the password via remote SSH

[https://github.com/microsoft/vscode/issues/221407](https://github.com/microsoft/vscode/issues/221407)

## Summary

The root cause — local echo displaying password characters over high-latency remote connections — was mitigated by turning local echo off by default in commit 5c5cb3dc1fc (shipped in 1.98.0). The commit message explicitly cites password echoing as a motivating reason. This can be closed as completed.

## Change summary

Terminal local echo feature shows typed password characters in grey when using sudo over a remote SSH connection, especially when the connection drops during a reboot.

## Best solution

Keep the shipped default-off change (commit 5c5cb3dc1fc, 1.98.0). The underlying local echo feature remains available as an opt-in preview, but the dangerous default behavior that caused password exposure is resolved. No further change needed.
