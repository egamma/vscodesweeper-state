## Summary

Keep open: current sampling controls allow server-level permission and retrospective inspection, but do not provide the requested in-chat review and editing before dispatch. This team-authored, accepted request has neither a verified fixing commit nor an eligible canonical duplicate.

## Change summary

Let users inspect and edit an MCP server's sampling request in chat before it is sent to a language model.

## Best solution

Provide a designed pre-dispatch review flow for MCP sampling that exposes the request in chat and lets the user edit or decline it. Define how this interacts with existing server permissions and sampling outside an active chat before implementation.
