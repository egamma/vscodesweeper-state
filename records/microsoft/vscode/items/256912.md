# Issue #256912 — [Sampling] Display sampling request to users in chat before sent out

[https://github.com/microsoft/vscode/issues/256912](https://github.com/microsoft/vscode/issues/256912)

## Summary

Team-authored feature request for human-in-the-loop display of MCP sampling/createMessage requests in the chat UI. The current implementation in chatMcpAppModel.ts forwards sampling requests silently to the host-side handler without surfacing them to the user. Keeping open per team-member policy.

## Change summary

Display MCP sampling/createMessage requests to users in the chat UI and allow editing before they are sent, enabling human-in-the-loop control.

## Best solution

Extend the MCP sampling flow in `chatMcpAppModel.ts` (and the `_mcpToolCallUI.sampling` path) to render the sampling request content in the chat widget — similar to how tool call confirmations are shown — and let the user review/edit the message before it is forwarded to the model. This aligns with the MCP spec's human-in-the-loop guidance for sampling.
