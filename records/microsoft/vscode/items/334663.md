# Issue #334663 — Agent Merge: retry timed-out CI jobs once before giving up

[https://github.com/microsoft/vscode/issues/334663](https://github.com/microsoft/vscode/issues/334663)

## Summary

Legitimate, unimplemented feature request from a team member (dileepyavan, MEMBER) asking Agent Merge to auto-retry a timed-out required CI check once before giving up; existing workflow-rerun infrastructure (agentMergeController.ts deferredWorkflowReruns) is agent-tool-driven, not an automatic timeout-triggered bounded retry, so this stays open.

## Change summary

Agent Merge should automatically rerun a required CI job once when it fails due to a timeout, before reporting it cannot proceed, tracking the retry across turns to avoid loops.

## Best solution

Extend src/vs/platform/agentHost/node/agentMergeController.ts (and agentMergeCIEvidence.ts, which classifies check failures) to detect timeout-classified failures and trigger one automatic bounded rerun via the existing deferredWorkflowReruns/rerunWorkflow path, persisting a per-check retry counter in session/runtime state so a second timeout is reported rather than retried again.
