# Issue #334933 — Modern UI (Compact Density): Extra gaps between status bar item hover areas

[https://github.com/microsoft/vscode/issues/334933](https://github.com/microsoft/vscode/issues/334933)

## Summary

Confirmed in source: the Modern UI compact-density rule in statusBar.css overrides the base statusbar CSS's zeroed margins for compact-left/compact-right and has-background-color items with the same selector specificity, reintroducing gaps and misalignment that the base rules were designed to prevent.

## Change summary

In Modern UI with Compact layout density, adjacent status bar item hover areas show extra gaps, and items with a background color no longer align their hover area with their visible background.

## Best solution

Add compact/has-background-color exceptions to the `.modern-ui.modern-ui-compact ... > .statusbar-item-label` margin rule in src/vs/workbench/contrib/modernUI/browser/media/statusBar.css (mirroring the `.compact-left`/`.compact-right`/`.has-background-color` handling already present in the base statusbarpart.css), so Modern UI compact mode doesn't blanket-override the zero-margin cases.
