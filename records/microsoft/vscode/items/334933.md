# Issue #334933 — Modern UI (Compact Density): Extra gaps between status bar item hover areas

[https://github.com/microsoft/vscode/issues/334933](https://github.com/microsoft/vscode/issues/334933)

## Summary

Confirmed in source: the Modern UI compact-density override in statusBar.css re-applies margins/padding at the same specificity as the base compact-left/compact-right/has-background-color rules in statusbarpart.css, undoing the spacing/background-alignment logic those rules establish. Real, well-diagnosed CSS bug, still present on main.

## Change summary

In Modern UI with Compact layout density, status bar item hover areas show extra gaps and misaligned backgrounds because a compact-mode CSS rule overrides the base spacing rules.

## Best solution

Scope or reorder the `.modern-ui.modern-ui-compact ... .statusbar-item-label` margin/padding rule in src/vs/workbench/contrib/modernUI/browser/media/statusBar.css so it doesn't clobber the `.compact-left`/`.compact-right`/`.has-background-color` overrides in src/vs/workbench/browser/parts/statusbar/media/statusbarpart.css — e.g. exclude those modifier classes or raise specificity to match intent.
