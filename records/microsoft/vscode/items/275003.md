# Issue #275003 — SCM hover behavior isn't instant if the up/down change text is hovered

[https://github.com/microsoft/vscode/issues/275003](https://github.com/microsoft/vscode/issues/275003)

## Summary

Keep open: the recorded reproduction and discussion establish an inconsistent SCM hover transition, and the implicated action items still use managed hovers. No concrete fixing commit or older canonical reporting the same symptom was identified; verify the current interaction before implementing the accepted toolbar-level improvement.

## Change summary

SCM toolbar hovers should transition immediately between the branch, synchronization icon, and incoming/outgoing count text once a hover is visible.

## Best solution

Make hover transitions consistent across the complete SCM toolbar action, including its nested count text, while retaining the normal initial hover delay. Address the shared toolbar hover lifecycle rather than introducing an SCM-specific workaround through deprecated APIs.
