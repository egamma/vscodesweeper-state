# Issue #327563 — git bash unavailable 

[https://github.com/microsoft/vscode/issues/327563](https://github.com/microsoft/vscode/issues/327563)

## Summary

This is a configuration/support question rather than a VS Code defect: Git Bash appears only when Git for Windows is installed in a detectable location or explicitly configured.

## Change summary

The reporter cannot find Git Bash among the available Windows terminal profiles.

## Best solution

Install Git for Windows, restart VS Code, and run “Terminal: Select Default Profile.” For a nonstandard installation, configure its bash.exe path under `terminal.integrated.profiles.windows`.
