A team member (deepak1556) explicitly asked to keep this open as a sub-issue of #295579 to track making the macOS update client download architecture-specific builds instead of universal. The feature is not yet implemented on main.

## Change summary

Make the macOS update client download the ARM-specific build instead of the universal (2× larger) package when running on Apple Silicon.

## Best solution
