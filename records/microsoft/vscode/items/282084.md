# Issue #282084 — Agent and chat should use symbols list for search

[https://github.com/microsoft/vscode/issues/282084](https://github.com/microsoft/vscode/issues/282084)

## Summary

Valid feature request from a team member to use workspace symbols as a context source in Copilot Chat. The capability has not been implemented on main — individual symbol attachment exists, but bulk symbol-list search as automatic context does not. Keeping open in Backlog.

## Change summary

Chat/agent should search workspace symbols (not just source files) to find relevant context, especially for symbols from dependency packages exposed via extensions.

## Best solution

Add workspace symbol providers as an automatic context source for chat's retrieval pipeline, or expose a 'symbols' option in the context picker that searches all workspace symbols at once rather than requiring one-by-one attachment. The chat context-gathering logic in `src/vs/workbench/contrib/chat/browser/` would need to integrate `WorkspaceSymbolProvider` results alongside file-based search.
