# Issue #343767 — Terminal in Agent Window

[https://github.com/microsoft/vscode/issues/343767](https://github.com/microsoft/vscode/issues/343767)

## Summary

The Agents Window already supports opening integrated terminals through its Terminal action and the shared terminal commands. The requested capability is covered by existing intentional behavior.

## Change summary

Provide a way to open one or more terminals inside the Agents Window.

## Best solution

Use the existing Terminal action or workbench.action.terminal.focus to reveal the terminal, and workbench.action.terminal.new to create additional terminals; no new capability is needed for the stated request.
