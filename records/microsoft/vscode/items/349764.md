# Issue #349764 — Add an option to automatically show new repositories in Source Control

[https://github.com/microsoft/vscode/issues/349764](https://github.com/microsoft/vscode/issues/349764)

## Summary

Keep open: existing settings do not provide automatic selection of new repositories while preserving explicitly hidden ones. The related restoration bug overlaps, but its open fix proposal does not deliver this request's full behavior.

## Change summary

Offer automatic visibility for newly discovered repositories in multiple-selection mode without revealing repositories the user explicitly hid.

## Best solution

Make new-repository selection consistent in SCMViewService while preserving saved exclusions, then decide whether this needs an optional setting or should be the default. Coordinate with the existing restoration fix rather than introduce competing selection behavior.
