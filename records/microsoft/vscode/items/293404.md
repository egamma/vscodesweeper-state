# Issue #293404 — "Failed to serialize MCP servers" error from private MCP registry

[https://github.com/microsoft/vscode/issues/293404](https://github.com/microsoft/vscode/issues/293404)

## Summary

The defect remains source-reproducible on current main, but the open linked PR directly addresses it. Keep the issue open while that implementation is reviewed and landed.

## Change summary

Browsing an Azure API Center MCP registry fails because VS Code rejects otherwise valid server records whose description is an empty string.

## Best solution

Update and land https://github.com/microsoft/vscode/pull/295563 so both MCP registry schema serializers accept empty string descriptions while continuing to reject missing, null, or non-string values.

## Evidence

- **source reproduction:** On current main, `McpServerSchemaVersion_v0_1.toRawGalleryMcpServer` in src/vs/platform/mcp/common/mcpGalleryService.ts rejects the reported payload through `!from.server.description`; the supplied empty string therefore causes the server to be omitted and serialization to fail.
- **second affected path:** The v2025-07-09 serializer in the same file uses the equivalent `!from.description` validation, so empty descriptions are rejected there as well.
- **open fixing PR:** https://github.com/microsoft/vscode/pull/295563 is open, references this issue with closing syntax, changes both falsy checks to null checks, and adds coverage for empty, null, undefined, and non-empty descriptions across both schema versions.
