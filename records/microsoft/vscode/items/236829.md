# Issue #236829 — Snippet variables $LINE_COMMENT, $BLOCK_COMMENT_START, and $BLOCK_COMMENT_END not working in new C# file

[https://github.com/microsoft/vscode/issues/236829](https://github.com/microsoft/vscode/issues/236829)

## Summary

Thanks for the report. The problem is still confirmed: a maintainer-side contributor reproduced it in May 2026, and a prior fix claim was refuted. File-template snippets resolve comment variables to empty strings on first use, before the language configuration has loaded.

## Change summary

Comment snippet variables ($LINE_COMMENT, $BLOCK_COMMENT_START, $BLOCK_COMMENT_END) resolve empty when a file template is applied to a new file.

## Best solution

Make the file-template apply path wait for the target language's configuration to load before resolving comment variables. Alternatively, make the snippet variable resolver lazily load the configuration. Compare with the similar async-tokenization issue https://github.com/microsoft/vscode/issues/244217.
