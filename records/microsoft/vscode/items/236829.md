# Issue #236829 — Snippet variables $LINE_COMMENT, $BLOCK_COMMENT_START, and $BLOCK_COMMENT_END not working in new C# file

[https://github.com/microsoft/vscode/issues/236829](https://github.com/microsoft/vscode/issues/236829)

## Summary

Keep open: current source still allows first-use template expansion before the selected language's comment configuration finishes loading. The merged language-ordering change addresses only part of the report; the maintainer subsequently confirmed the first-use failure after reload.

## Change summary

Ensure file-template comment variables resolve correctly on the first use of a language after reload.

## Best solution

Make file-template expansion reliably use the selected language's loaded comment configuration, including cold first use. Preserve the existing language-before-expansion ordering and cover delayed configuration loading rather than only preloaded configurations.

First-use snippet expansion can therefore run before the comment configuration exists.
