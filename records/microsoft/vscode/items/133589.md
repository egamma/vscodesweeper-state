# Issue #133589 — Improve Buttons in SVC Conflict Resolution

[https://github.com/microsoft/vscode/issues/133589](https://github.com/microsoft/vscode/issues/133589)

## Summary

A real UX gap remains: current main still presents all inline conflict actions together as CodeLens commands rather than placing a concise Accept affordance beside each corresponding change. This team-authored Backlog item is protected from judgment-based closure and should remain under discussion.

## Change summary

Place each merge-conflict acceptance control beside the change it applies to and remove unrelated actions from that conflict-resolution surface.

## Best solution

Choose a consistent inline conflict-control design that visually associates each Accept action with its corresponding side while retaining clear access to Accept Both and Compare Changes. The obsolete Live Share concern needs no further work because that action is absent from current main.
