## Summary

Team-authored UX improvement request for inline merge conflict codelens buttons. The inline buttons ("Accept Current Change", "Accept Incoming Change", etc.) still exist in `extensions/merge-conflict/src/codelensProvider.ts` and remain unchanged from the described state. While the 3-way merge editor was introduced later, the inline conflict resolution UI is still active and the suggested improvements have not been implemented.

## Change summary

Improve the positioning and labeling of inline merge conflict resolution buttons so "Accept" appears next to each change rather than grouped together at the top.

## Best solution

Revisit the inline merge conflict codelens layout in `extensions/merge-conflict/src/codelensProvider.ts` — consider placing each "Accept" action adjacent to its corresponding change block (possibly via inline decorations rather than codelens) and evaluate whether the Live Share button belongs there. This may also be worth re-evaluating in light of the 3-way merge editor introduced since this issue was filed.
