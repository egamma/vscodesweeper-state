# Issue #333502 — Many color theme were messed, the split bars can not be seen

[https://github.com/microsoft/vscode/issues/333502](https://github.com/microsoft/vscode/issues/333502)

## Summary

Real, freshly-reported contrast bug in the new experimental Modern UI: the inter-panel sash indicator is intentionally drawn at very low contrast, and for some color themes (e.g. Tomorrow Night Blue) that renders as effectively invisible. A team member is already assigned, so this just needs to stay open for the design fix.

## Change summary

With `workbench.experimental.modernUI` enabled, the boundary/sash between side-panel blocks is nearly invisible for several color themes.

## Best solution

Increase the contrast (or make it theme-aware) of the sash grip in src/vs/workbench/contrib/modernUI/browser/media/sashHandles.css, which currently draws the grip at `color-mix(in srgb, var(--vscode-foreground) 30%, transparent)` with `opacity: 0.75` — too subtle against some theme backgrounds; a maintainer/design owner should pick a token or contrast floor that stays visible across themes.
