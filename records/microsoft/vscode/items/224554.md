# Issue #224554 — activeEditor == 'multiDiffEditor' and multiDiffEditorAllCollapsed not set when expected (context keys)

[https://github.com/microsoft/vscode/issues/224554](https://github.com/microsoft/vscode/issues/224554)

## Summary

A focus/context gap remains when clicking the multi-diff editor background: the container does not acquire keyboard focus, so inspecting its context can show values that keyboard dispatch does not see. Current header-focus improvements cover part of the report, but do not resolve this background-click case.

## Change summary

Keep multi-diff expand/collapse keybindings available after clicking the editor background, including when every diff is collapsed.

## Best solution

Make background interaction retain keyboard focus within the multi-diff editor's context without expanding a diff or changing collapse state. Preserve the existing context-key ownership and verify that the reporter's shared expand/collapse chord works without first selecting a collapse arrow.
