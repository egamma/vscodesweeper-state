# Issue #316531 — Copilot Chat fails to obtain token — `dial tcp 4.228.31.149:443: i/o timeout` — auth broken after Sign Out; reproduced on two machines and multiple networks

## Summary

The discussion strongly supports regional GitHub API reachability failures rather than corrupted sign-in state or a hardcoded Copilot backend IP. Keep the explicit authentication-resilience request open for a product decision: existing transport fallbacks do not establish coverage of the requested alternate-address behavior.

## Change summary

Make GitHub sign-in and Copilot token acquisition more resilient when a resolved GitHub API address is unreachable.

## Best solution

Evaluate supported recovery behavior for partial GitHub API reachability across GitHub Authentication and Copilot networking, while clearly distinguishing connectivity failures from invalid credentials. Preserve hostname-based requests and certificate validation; do not turn the thread's temporary IP overrides into a shipped endpoint list.
