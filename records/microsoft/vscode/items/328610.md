# Issue #328610 — GitHub Copilot constantly freezes for several seconds in long chats.

[https://github.com/microsoft/vscode/issues/328610](https://github.com/microsoft/vscode/issues/328610)

## Summary

Detailed, repeatedly-reproduced report of periodic stop-the-world freezes and stalled streaming once a Copilot Chat conversation grows very large (tens of thousands of lines); corroborated by a similarly-described open issue, but I found no fix commit on main and no maintainer trace of the root cause, so this should be routed to the chat/performance owners rather than closed.

## Change summary

Copilot Chat periodically freezes the UI for several seconds, and response streaming stalls to once-per-second chunking, once a conversation transcript becomes very large (~60,000 lines of copied Markdown).

## Best solution

Needs a maintainer-side performance investigation (heap/CPU profiling of the chat widget list renderer and the extension host's turn-history handling) to find what scales badly with transcript size — likely in src/vs/workbench/contrib/chat/browser/widget/chatListRenderer.ts or the extension's history/state serialization — rather than a quick source fix; the linked issues (#327906, #285598) should be triaged together as they may share the same root cause.
