# Issue #71461 — Task input parameters from showOpenDialog

[https://github.com/microsoft/vscode/issues/71461](https://github.com/microsoft/vscode/issues/71461)

## Summary

Keep open: built-in task and launch inputs still lack a configurable file/folder dialog that returns a path. This accepted Backlog request has 22 upvotes, maintainer interest, and several duplicates; the documented extension workaround does not supply the requested built-in capability.

## Change summary

Allow task and debug input variables to select a file or folder through a configurable open dialog, including file-extension filters.

## Best solution

Provide a supported, configurable path-selection surface usable from both tasks.json and launch.json without installing an extension. First settle whether the public configuration uses a built-in command input, as the maintainer suggested, or a dedicated input type.
