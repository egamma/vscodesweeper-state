# Issue #242167 — The strikethrough syntax in Markdown takes effect in the editing window but doesn't work in the Preview window.

[https://github.com/microsoft/vscode/issues/242167](https://github.com/microsoft/vscode/issues/242167)

## Summary

Fixed on main and shipped in 1.103.0 — the upstream markdown grammar was updated to handle strikethrough with adjacent underscores correctly.

## Change summary

Editor incorrectly highlighted strikethrough syntax when underscores appeared adjacent to the `~~` delimiters (e.g. `x~~_deleted~~_x`).

## Best solution

Keep the shipped grammar fix from commit f8bb386a48f (1.103.0); no further change needed.
