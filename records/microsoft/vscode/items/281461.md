# Issue #281461 — shellIntegration.ps1 caused Python Debugger with Garbled Text

[https://github.com/microsoft/vscode/issues/281461](https://github.com/microsoft/vscode/issues/281461)

## Summary

Still reproduces on main: the OSC 633;E sequence sends escaped command text on Windows 10, and the terminal echoes it for long commands. The nonce is already conditionally omitted for Windows 10, but the entire 633;E payload (including the escaped command line with \x5c substitutions) is still sent. An attempted fix (bf35773505a) was never merged.

## Change summary

On Windows 10, the VSCode integrated terminal displays garbled escaped text (e.g. \x5c for backslashes) from OSC 633;E shell integration sequences when running long PowerShell commands like Python debugger launches.

## Best solution

Extend the existing Windows 10 guard at line 225 in shellIntegration.ps1 to skip the entire OSC 633;E sequence on Windows 10, not just the nonce — exactly as the unmerged commit bf35773505a attempted. The command-executed (633;C) sequence should still be sent. This trades off command-line history tracking on Windows 10 for a clean terminal display.
