# Issue #210672 — Terminal Image display has low resolution

[https://github.com/microsoft/vscode/issues/210672](https://github.com/microsoft/vscode/issues/210672)

## Summary

Properly triaged upstream issue — the xterm.js image addon uses CSS pixels instead of device pixels, causing blur on high-DPI screens. The upstream issue (xtermjs/xterm.js#5035) remains open; no fix has landed there yet.

## Change summary

Terminal inline images (via imgcat/iTerm image protocol) render at half resolution on high-DPI screens because the xterm.js image addon sizes images in CSS pixels rather than accounting for devicePixelRatio.

## Best solution

Wait for the upstream fix in xtermjs/xterm.js#5035 to land (DPR-aware sizing in the image addon), then bump the @xterm/addon-image dependency. No VS Code-side code change can address this — it's in the addon's pixel measurement logic.
