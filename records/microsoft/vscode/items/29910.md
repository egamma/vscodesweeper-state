# Issue #29910 — CLI proxy support

[https://github.com/microsoft/vscode/issues/29910](https://github.com/microsoft/vscode/issues/29910)

## Summary

CLI extension installation already honors configured and environment proxy values; the reporter later identified the installation failure as an invalid TEMP environment variable and confirmed it worked after correcting that.

## Change summary

Support installing Marketplace extensions through a proxy from the `code --install-extension` CLI.

## Best solution

Keep the existing CLI behavior: load `http.proxy` from user settings and fall back to `HTTP_PROXY`/`HTTPS_PROXY`. Distinct authentication and certificate limitations remain tracked by narrower issues such as https://github.com/microsoft/vscode/issues/241683 and https://github.com/microsoft/vscode/issues/185135.

- **Fit:** aligned
- **Reason:** Reliable CLI operation behind enterprise proxies supports the unified editor-and-CLI configuration model and ongoing network robustness work.
- **Evidence:** Aligns with current unified-settings and network/proxy robustness priorities.
