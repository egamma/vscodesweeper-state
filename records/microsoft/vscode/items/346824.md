# Issue #346824 — Markdown preview editor and rendered Markdown diff never re-read a file whose change on disk was missed

[https://github.com/microsoft/vscode/issues/346824](https://github.com/microsoft/vscode/issues/346824)

## Summary

The missed-change recovery gap remains in current source: custom text editors reuse loaded models without requesting a disk reload, and Markdown refresh renders that same cached document. Keep this report open; the related preview issues do not establish a canonical covering custom editors, rendered diffs, and explicit refresh.

## Change summary

Custom text editors and rendered Markdown diffs retain stale file contents after missed filesystem notifications, even after reopening or refreshing the preview.

## Best solution

Restore clean-document disk synchronization when custom text editors and rendered diffs are opened or revealed, and make explicit Markdown refresh recover missed changes without discarding unsaved edits. Preserve existing watcher coverage and virtual-document behavior.
