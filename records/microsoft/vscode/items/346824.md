# Issue #346824 — Markdown preview editor and rendered Markdown diff never re-read a file whose change on disk was missed

[https://github.com/microsoft/vscode/issues/346824](https://github.com/microsoft/vscode/issues/346824)

## Summary

The missed-change recovery gap remains in current source: custom text editors reuse loaded models without requesting a disk reload, and Markdown Refresh Preview only re-renders that cached content. Keep this report open; the related preview reports do not establish a canonical covering both editor recovery and rendered diffs.

## Change summary

Recover current disk content in Markdown preview editors and rendered diffs after a file-watcher event was missed.

## Best solution

Make opening or revealing a custom text editor recover missed external changes, and make explicit Markdown refresh recover clean documents from disk. Preserve unsaved edits and distinguish this recovery from live updates that require watcher coverage.
