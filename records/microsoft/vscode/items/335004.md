Plausible core status-bar rendering glitch, but I can't confirm the exact defect from source alone since it's a rendering/visual issue — asking the reporter to confirm on the latest build and share a couple more details before triaging further.

## Change summary

The hover/active background on the SSH remote status bar item doesn't fully cover the item — a sliver of the item's own blue background peeks out on the left edge.

## Best solution

If reproduced, likely lives in src/vs/workbench/browser/parts/statusbar (statusbarItem.ts / statusbarpart.css) where `.has-background-color` items get a zero-margin, full-width label so the hover overlay matches the container background exactly — or, if the reporter has the experimental `workbench.experimental.modernUI` setting active (it can be auto-enabled via an experiment), in src/vs/workbench/contrib/modernUI/browser/media/statusBar.css, whose `.modern-ui-compact` rule resets that same label's margin without excluding `.has-background-color` items, which would reintroduce exactly this kind of edge gap.
