# Issue #341032 — Window state not preserved on session end (shutdown/logout) on Linux: only one window restored

[https://github.com/microsoft/vscode/issues/341032](https://github.com/microsoft/vscode/issues/341032)

## Summary

Thanks for the detailed report. The report has concrete steps and a plausible mechanism: on Linux the session manager closes windows one by one, so the lifecycle code may treat them as individual window closes instead of a quit. This depends on the desktop environment, and I could not run it here, so it stays open. The report is on VSCodium 1.135 rather than stock VS Code, so a retest on current VS Code would help.

## Change summary

On Linux, ending the desktop session (shutdown or logout) with several windows open restores only one window on the next start.

## Best solution

Check whether the window-state save path in windowsStateHandler.ts and lifecycleMainService.ts treats desktop-session window closes as individual closes on Linux. If it does, treat them as a quit, for example by snapshotting window state when the session-end signal arrives.
