## Summary

Keep open as under discussion: current code collects instructions in deterministic phases but does not establish the requested source-level precedence, and the thread contains an unresolved maintainer-level product decision about whether instructions should be hierarchical or equal. ## Change summary

Define, document, and test how organization, workspace, dynamic, user, custom-agent, and extension-provided instructions are ordered and prioritized in model context.

## Best solution

First settle a provider-independent precedence contract covering every instruction source, including custom agents and extension-provided instructions. Then represent that contract consistently in workbench collection and Agent Host provider handoff, document it for users, and add deterministic assembly tests plus model evaluations for conflicting instructions.
