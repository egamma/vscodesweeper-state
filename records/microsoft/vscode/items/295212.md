# Issue #295212 — Setting to make side by side diff view the default for changes made by copilot

[https://github.com/microsoft/vscode/issues/295212](https://github.com/microsoft/vscode/issues/295212)

## Summary

Keep this accepted, well-supported request open: current main defaults changed-file list selections to a diff editor, but does not provide the same preference for reviewing edits in an already-open regular editor. Related issues do not establish an older canonical covering this specific default-setting request.

## Change summary

Allow users to default Copilot change review to a side-by-side diff without toggling the diff editor separately for each file.

## Best solution

Provide a consistent review preference for Copilot-edited files, building on the existing changed-file opening setting and standard diff layout configuration. First settle whether that preference also switches already-open editors into diff review, rather than only controlling files opened from chat.
