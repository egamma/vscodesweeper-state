# Issue #284492 — Copilot search input should be natural language and not text search properties

[https://github.com/microsoft/vscode/issues/284492](https://github.com/microsoft/vscode/issues/284492)

## Summary

The Search view still shares its input and text-search controls with AI search, so the requested distinction remains unresolved. Keep this team-authored UX request open for a design decision; no verified canonical or issue-referencing fix was found.

## Change summary

Make the AI search input clearly invite natural-language queries without implying that case, whole-word, or regex options govern AI results.

## Best solution

Give semantic search a clearly understandable input contract while preserving conventional text search. Search and UX owners should decide whether that requires an explicit natural-language mode or a clearer distinction within the shared-input experience.
