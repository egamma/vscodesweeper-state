# Issue #296813 — Breakpoint hover transparency in new experimental themes clashes with code

[https://github.com/microsoft/vscode/issues/296813](https://github.com/microsoft/vscode/issues/296813)

## Summary

Already fixed on main: the hover wrapper now paints the editor hover background, which addresses the transparency that let code show through breakpoint hovers in the 2026 themes.

## Change summary

Breakpoint hover widgets in the experimental 2026 themes used a transparent wrapper that allowed editor text to show through.

## Best solution

Treat this as completed by commit 66aa46c943596e0ebda6b36186b3b13cfd3b6c8b, shipped in 1.112.0; no further change is needed unless the reporter can reproduce a different remaining transparency issue on current builds.
