# Issue #335176 — Chat Editor: custom agent resets to Agent on first send

[https://github.com/microsoft/vscode/issues/335176](https://github.com/microsoft/vscode/issues/335176)

## Summary

Team-authored bug with a traced root cause and an open PR already fixing it — keep open until #335177 merges rather than closing now.

## Change summary

When a fresh Chat Editor's first send materializes the real contributed session, the custom chat mode (e.g. a custom agent like Data) is not carried over to the real model, so the mode picker resets to default Agent even though the in-flight request still uses the correct mode.

## Best solution

Land the linked PR https://github.com/microsoft/vscode/pull/335177 ("Carry Chat Editor custom agent through first send"), which should make `_materializeUntitledSession` transfer the untitled model's chat mode onto the real model the same way it already transfers `intendedModel`.
