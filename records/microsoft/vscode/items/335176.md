# Issue #335176 — Chat Editor: custom agent resets to Agent on first send

[https://github.com/microsoft/vscode/issues/335176](https://github.com/microsoft/vscode/issues/335176)

## Summary

Confirmed on current main: `_materializeUntitledSession` only transfers the untitled model's intended language model to the real model (line 1411), never the input mode, so the widget's mode picker reverts to default Agent after the first send. Already properly labeled/routed; keeping open for a fix.

## Change summary

Selecting a custom agent (e.g. Data) in a fresh untitled Chat Editor and sending the first message resets the mode picker to default Agent once the real session materializes.

## Best solution

In `_materializeUntitledSession` (src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts, around line 1411), alongside `setIntendedModel`, also carry the untitled model's `inputModel.state.get()?.mode` onto `realModel.inputModel` (e.g. via `setState({ mode: ... })`), mirroring how `loadRemoteSession` backfills mode/model on restore.
