# Issue #312105 — fix(auth): OAuth2 redirect fails when "code" is the first query parameter

[https://github.com/microsoft/vscode/issues/312105](https://github.com/microsoft/vscode/issues/312105)

## Summary

The reported query-order defect remains in current main: the authorization-code parser rejects a valid callback when code is the first query parameter. Keep this open; the failure is confirmed from source and suitable for a bounded implementation session.

## Change summary

Accept OAuth authorization codes appearing first in the web callback query string.

## Best solution

Make DynamicAuthProvider accept the code parameter regardless of its position while preserving the existing encoded-value handling and rejection of missing or empty codes. Cover this through the existing authentication unit-test suite without changing callback transport or other OAuth behavior.
