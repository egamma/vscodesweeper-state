# Issue #340104 — Agents window: allow attaching sessions as context in workspaceless chats

[https://github.com/microsoft/vscode/issues/340104](https://github.com/microsoft/vscode/issues/340104)

## Summary

Keep open: the new-chat composer still lacks the normal Sessions attachment picker, and its existing #session completion is not equivalent general-purpose context attachment. This team-authored request has neither a verified fixing commit nor an older canonical established to report the same workspaceless first-message limitation.

## Change summary

Allow attaching prior sessions as context before sending the first message in a workspaceless Agents Window chat.

## Best solution

Give the workspaceless new-chat composer the same supported session-context attachment behavior as an ongoing chat, including delivering the selected context with the first request. Preserve existing provider eligibility and host-access restrictions rather than expanding supported session types as part of this request.
