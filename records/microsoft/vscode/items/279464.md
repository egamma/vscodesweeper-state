# Issue #279464 — The completions in the front matter is influenced by the space after the `:`

[https://github.com/microsoft/vscode/issues/279464](https://github.com/microsoft/vscode/issues/279464)

## Summary

The reopened completion defect remains on current main: scalar front-matter value suggestions omit `filterText`, so the suggest widget scores the separator space against each label and can reorder or remove valid choices. The fix is bounded to the prompt-header completion provider and its tests.

## Change summary

Keep all valid front-matter value completions available when a space follows the property colon.

## Best solution

Make scalar front-matter value completions treat the YAML separator space as neutral during filtering while preserving normal filtering once the user types the value itself.
