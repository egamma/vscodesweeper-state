# Issue #279464 — The completions in the front matter is influenced by the space after the `:`

[https://github.com/microsoft/vscode/issues/279464](https://github.com/microsoft/vscode/issues/279464)

## Summary

Still present on main: front matter completion items in promptHeaderAutocompletion.ts don't set a `filterText` that accounts for the space after `:`, so the completion widget re-ranks/filters unexpectedly when the user types a space. No fix commit found.

## Change summary

Typing a space after `:` in front matter completions causes the suggestion list to be re-filtered/re-ranked incorrectly, showing only a subset of valid completions.

## Best solution

Set `filterText` on each completion item in `promptHeaderAutocompletion.ts` (around line 256) to include a leading space (e.g. ` ${entry.name}`) so the space typed after `:` matches the filter text and doesn't cause incorrect re-ranking. This aligns with jrieken's suggestion in comment #5.
