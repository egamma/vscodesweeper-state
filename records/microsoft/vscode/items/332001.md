# Issue #332001 — Modern UI compact density

[https://github.com/microsoft/vscode/issues/332001](https://github.com/microsoft/vscode/issues/332001)

## Summary

The central ask — a supported way to opt into a denser Modern UI layout without disabling it — has been delivered: PR #332330 (merged, by the same author) added a `window.density.layout` setting (`default`/`compact`) that removes gaps and reduces internal spacing between floating workbench parts.

## Change summary

Investigate a workbench density setting (compact/default/comfortable) to reclaim editor space in the Modern UI floating-card layout without requiring users to disable Modern UI.

## Best solution

Treat as implemented: `LayoutSettings.MODERN_UI_DENSITY` (`window.density.layout`) with `ModernUIDensity.Default`/`Compact` is wired through `layout.ts` (`isModernUICompact()`, `MODERN_UI_COMPACT` class) and `floatingPanels.css` (extensive compact-mode rules removing gaps/padding for sidebar, panel, auxiliary bar, activity bar, status bar). Remaining ideas from the issue (a 'comfortable' tier, granular per-property controls) are enhancements that can be filed as new, narrower requests if still wanted.
