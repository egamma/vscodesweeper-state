# Issue #332001 — Modern UI compact density

[https://github.com/microsoft/vscode/issues/332001](https://github.com/microsoft/vscode/issues/332001)

## Summary

The core ask — a compact density option so users don't have to disable Modern UI entirely — has already landed via a merged PR from the same author, but the issue keeps collecting concrete, unaddressed follow-up asks (menu/status bar height, uniform component heights, vertical centering, a possible 'Comfortable' tier, fullscreen padding), so it's still doing useful work as the tracking thread for ongoing density refinement.

## Change summary

Add a supported density setting (e.g. Compact/Default/Comfortable) for Modern UI so users can reclaim editor space without disabling the new UI outright.

## Best solution

Keep this as the umbrella thread for Modern UI density polish: the initial Compact mode shipped in https://github.com/microsoft/vscode/pull/332330 (merge commit 0b8153e), but the still-open sub-asks (menu/status bar height parity, vertical alignment of status bar icons/text, a possible 'Comfortable' tier) belong here or in the more specific follow-ups like https://github.com/microsoft/vscode/issues/334933.
