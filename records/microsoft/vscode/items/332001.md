# Issue #332001 — Modern UI compact density

[https://github.com/microsoft/vscode/issues/332001](https://github.com/microsoft/vscode/issues/332001)

## Summary

This is the active umbrella issue for the Modern UI compact-density initiative — a first density setting already shipped, but several of the issue's own stated sub-goals (a third 'Comfortable' tier, per-part fine controls, uniform header/status-bar heights) remain open and under active iteration, so it should stay open rather than close.

## Change summary

Investigate a workbench density setting (Compact/Default/Comfortable) to reclaim editor space in Modern UI without disabling it entirely.

## Best solution

Keep this open as the tracking issue for the compact-density workstream in src/vs/workbench/contrib/modernUI: the core `window.density.layout` (default/compact) setting shipped in PR #332330, and follow-on work (connected tabs in PR #335605, status bar/tab height uniformity raised in comments) is still landing — close only once the full set of stated goals (including a 'Comfortable' tier and remaining height/spacing consistency) is resolved or explicitly descoped.
