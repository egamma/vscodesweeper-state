# Issue #284379 — Enterprise-Managed VS Code with Extensions Marketplace

[https://github.com/microsoft/vscode/issues/284379](https://github.com/microsoft/vscode/issues/284379)

## Summary

This requests an enterprise-managed VS Code hosting platform (containerized deployment at scale with managed marketplace and profiles) — a product/service concern outside the scope of the VS Code open-source editor project.

## Change summary

Enterprise-managed containerized VS Code deployment with curated extensions marketplace, scalable to thousands of users with profile-based settings.

## Best solution

This is addressed by existing products: GitHub Codespaces provides cloud-hosted VS Code environments with enterprise controls, and vscode.dev/code-server handle web-based scenarios. Extension marketplace curation and enterprise policy are covered by VS Code's existing enterprise policy settings and the Extensions: Allowed list. The request as stated is a deployment/platform concern, not a VS Code core feature.
