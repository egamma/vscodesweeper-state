[https://github.com/microsoft/vscode/issues/212083](https://github.com/microsoft/vscode/issues/212083)

## Summary

Keep this canonical API-proposal issue open: an initial embeddings API exists on main, but it remains proposed and unavailable as a stable extension API.

## Change summary

Expose an extension API for registering embedding providers and computing embeddings for NLP and local RAG scenarios.

## Best solution

Continue incubating `vscode.proposed.embeddings.d.ts`, resolve its namespace and model-selection design, and finalize it as a stable extension API when ready.
