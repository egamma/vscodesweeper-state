[https://github.com/microsoft/vscode/issues/338895](https://github.com/microsoft/vscode/issues/338895)

## Summary

Keep open: current main still truncates MCP tool IDs without preserving uniqueness, and a resulting registration error can prevent later tools from registering. The reporter's clarification limits this to the local harness; working Copilot-harness behavior does not resolve the reopened report.

## Change summary

Preserve distinct MCP tools when their generated IDs share the first 64 characters, and prevent one registration failure from dropping unrelated tools.

## Best solution

The local MCP path should expose and correctly invoke every valid distinct tool while respecting the 64-character ID limit. Registration failures should be reported explicitly without preventing unrelated tools from becoming available.
