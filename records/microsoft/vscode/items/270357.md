Keep open: typing a commit message and pressing Commit provides sufficient steps to retest the reported disappearance and empty-message warning. Current source preserves the message on the ordinary commit path, but does not establish that the reported failure is fixed or that Copilot caused it.

## Change summary

Preserve manually entered commit text so committing does not erase it and incorrectly report a missing message.
