# Issue #321773 — symbol-* codicons specified via `iconPath` aren't colored in quickpicks created by extensions

[https://github.com/microsoft/vscode/issues/321773](https://github.com/microsoft/vscode/issues/321773)

## Summary

The default symbol-color regression remains in current source: extension quick-pick item icons lack the coloring marker required by the workbench CSS. Keep this open; the linked fixes address inline labels and custom tree views, not this rendering path.

## Change summary

Restore default symbol colors for ThemeIcons supplied through extension quick-pick items' iconPath property.

## Best solution

Quick-pick item icons should use the same theme-defined default symbol colors as inline icons and custom tree-view icons. Address this bounded rendering regression without expanding it into explicit ThemeIcon.color support or URI-icon recoloring.
