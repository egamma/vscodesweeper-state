# Issue #139453 — iPad: Can't search for settings

[https://github.com/microsoft/vscode/issues/139453](https://github.com/microsoft/vscode/issues/139453)

## Summary

Keep open for the remaining hardware-keyboard focus improvement. The reporter confirmed that manually focusing and typing works; current source still suppresses automatic settings-search focus on iPad regardless of whether Settings was opened with Cmd+,.

## Change summary

Focus Settings search when an iPad hardware-keyboard user opens Settings with Cmd+, without bringing up the software keyboard on touch-driven opening.

## Best solution

Make settings-search focus respect keyboard versus touch invocation while preserving the existing protection against unwanted software-keyboard activation. The remaining work is an input-modality improvement, not evidence that manually focused search still rejects typing.
