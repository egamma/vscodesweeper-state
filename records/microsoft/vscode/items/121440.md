# Issue #121440 — Notebook cell focus feedback should disappear when clicking the empty view content or somewhere else

[https://github.com/microsoft/vscode/issues/121440](https://github.com/microsoft/vscode/issues/121440)

## Summary

The UX gap remains on current main: clicking empty notebook space attempts to clear list focus, but the notebook list deliberately rejects an empty focus while cells exist. Keep this open for a notebook focus-design decision.

## Change summary

Remove focused-cell feedback when the user clicks empty notebook content or moves focus elsewhere.

## Best solution

Define an explicit empty-area focus state for the notebook container, then clear the cell's visual focus without losing the active-cell context needed by commands or regressing keyboard and accessibility behavior.
