# Issue #326710 — Audit Copilot SDK events with agentId for subagent-safe handling

[https://github.com/microsoft/vscode/issues/326710](https://github.com/microsoft/vscode/issues/326710)

## Summary

Real, unfinished audit item authored by a team member: tracing the code confirms several of the listed handlers (`onIdle`/session.idle, `onSessionError`/session.error, and the start of `onAutoModeResolved`) still act unconditionally on root state without checking `e.agentId`, so subagent events can still corrupt root turn/model state exactly as described. Keep open — this is the remaining work after the merged `user.message` fix.

## Change summary

Audit remaining Copilot SDK event consumers in the agent host that may carry a subagent `agentId` and add explicit root/subagent routing or guards for each.

## Best solution

Continue the audit in src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts: add `agentId` guards to `onIdle` (~line 4162, unconditionally completes/aborts the root turn) and `onSessionError` (~line 4290, unconditionally emits a root `ChatError`), and verify `onAutoModeResolved`/`onSessionModelChange`/`onUsage`/MCP inventory handlers per the acceptance criteria, with regression tests per changed path.
