# Issue #339806 — Clicking into a migration entry should also have a migrate button

[https://github.com/microsoft/vscode/issues/339806](https://github.com/microsoft/vscode/issues/339806)

## Summary

Team-authored (lramos15, MEMBER), same-day follow-up to the actively-developed customization migration dashboard (building on #339525 testing). This is a self-filed UX improvement request and is hard-protected from any judgment close.

## Change summary

Clicking a migration entry in the AI Customization migration dashboard opens its details but offers no direct migrate action there; the user has to go back to the list to migrate.

## Best solution

Add a migrate action to the migration-item detail/preview view opened by `openMigrationItem` in customizationMigrationDashboard.ts, mirroring the migrate affordance already on the list/group row.
