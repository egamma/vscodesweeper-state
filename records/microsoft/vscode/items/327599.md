# Issue #327599 — Focus on files explorer command doesn't focus

[https://github.com/microsoft/vscode/issues/327599](https://github.com/microsoft/vscode/issues/327599)

## Summary

Current main still targets the default Explorer container rather than the Files view's current container, so the command focuses the wrong view after Files is moved. Route this confirmed, localized bug to the file explorer area.

## Change summary

Make “Focus on Files Explorer” focus the Files tree after that view has been moved to another view container.

## Best solution

Update `FocusFilesExplorer.run` to open and focus the registered Files view through `IViewsService`, which resolves its current container, instead of opening the hard-coded default Explorer container.
