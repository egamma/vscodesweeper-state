# Issue #327599 — Focus on files explorer command doesn't focus

[https://github.com/microsoft/vscode/issues/327599](https://github.com/microsoft/vscode/issues/327599)

## Summary

The defect remains on current main: the command opens the default Explorer container instead of locating the Files Explorer view after it has been moved, so focus can land on an unrelated view. Route this confirmed, bounded bug to the file-explorer area.

## Change summary

Make “Focus on Files Explorer” focus the Files Explorer view in its current container and location.

## Best solution

Have the command resolve and focus the Files Explorer view wherever the user placed it, while preserving the existing behavior for the default Explorer layout.
