# Issue #294957 — MCP refresh showing when I don't have any enabled?

[https://github.com/microsoft/vscode/issues/294957](https://github.com/microsoft/vscode/issues/294957)

## Summary

Keep open for the existing UX discussion: undiscovered extension-provided MCP collections can still produce a new-tools indicator before any actual servers or tools are known. The maintainer explains the discovery constraint, but that does not settle whether the indicator communicates it appropriately.

## Change summary

Avoid implying that MCP tools are available when extension-provided collections have not yet been discovered and may contain no servers.

## Best solution

Make the MCP chat-input indicator distinguish undiscovered extension collections from known servers with new tools, while preserving explicit discovery. The area owner should settle the intended presentation before implementation.
