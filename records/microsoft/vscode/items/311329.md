# Issue #311329 — Custom subagent resolves to model outside its configured model list

[https://github.com/microsoft/vscode/issues/311329](https://github.com/microsoft/vscode/issues/311329)

## Summary

The issue remains actionable: the supplied Copilot Chat logs confirm repeated subagent executions with Claude Sonnet despite an explicit model list that excludes Sonnet. There is no verified duplicate, merged fix, or indication that the configured list is intentionally advisory.

## Change summary

Ensure custom subagent model fallback remains within the subagent's ordered configured model list and respects the parent model's cost-tier ceiling.

## Best solution

Treat the configured subagent model list as an allowlist during model resolution: select the first listed model allowed by the parent cost tier, or return the existing unavailable-model error when none qualify. Add coverage for repeated invocations so fallback cannot silently select a globally available unlisted model.
