# Issue #307216 — Electron fetch in the utility process doesn't respect HTTP cache headers

[https://github.com/microsoft/vscode/issues/307216](https://github.com/microsoft/vscode/issues/307216)

## Summary

Team-authored upstream bug: Electron's utility process URLLoader uses a system network context that disables disk cache. The root cause is in Electron, and a fix PR (electron/electron#51279) has merged. Keeping open per team-member policy — the team will decide when to close (likely after upgrading to the Electron version carrying the fix).

## Change summary

Electron's fetch in the utility process ignores HTTP cache headers because the system network context disables disk cache, causing redundant network requests (e.g. repeated model-list fetches in Copilot).

## Best solution

Upgrade to the Electron version that includes electron/electron#51279 (session support for utility process requests). A Node-side workaround (commit 9cd7264dd10, opt-in undici HTTP cache for the Node fetch path) already mitigates this for Copilot's extension-host fetcher, but the Electron-level fix is the proper solution for all utility-process network requests.
