# Issue #329092 — Compact chat control bar doesn't respect command center's background

[https://github.com/microsoft/vscode/issues/329092](https://github.com/microsoft/vscode/issues/329092)

## Summary

Real theming bug, confirmed in source: the compact chat/agent control bar uses agentStatusIndicator.background instead of commandCenter.background, breaking themes that only style the latter. An open PR (#329294, 'Fixes #329092') already implements the fix, so this should stay open pending merge rather than being closed.

## Change summary

In compact agent-control mode, the titlebar bar's background/foreground colors don't fall back to the command center's theme colors, breaking compatibility with themes that don't specify the newer agentStatusIndicator.background color.

## Best solution

Land the linked PR https://github.com/microsoft/vscode/pull/329294, which switches the compact agent control to commandCenter.background/commandCenter.activeForeground while preserving agentStatusIndicator.background outside compact mode; the two follow-on asks (customizable chat icon color and 'Open in Agents' text color) can be tracked separately if not covered by that PR.
