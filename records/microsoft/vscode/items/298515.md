# Issue #298515 — inlineChat.defaultModel schema validation fails when models are updated.

[https://github.com/microsoft/vscode/issues/298515](https://github.com/microsoft/vscode/issues/298515)

## Summary

Confirmed on current main: removed models disappear from the strict enum, invalidating persisted values even though runtime already handles unavailable models by falling back. This remains a real settings-schema defect.

## Change summary

Keep inline-chat model preferences valid when available model names or versions change.

## Best solution

Give `inlineChat.defaultModel` stable semantics similar to `chat.defaultModel`: accept stable model IDs or families without strict catalog validation, resolve them at runtime, and retain the existing fallback when unavailable.
