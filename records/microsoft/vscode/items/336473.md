# Issue #336473 — Agents Window in PWA: 'Work in Repository...' does nothing

[https://github.com/microsoft/vscode/issues/336473](https://github.com/microsoft/vscode/issues/336473)

## Summary

Freshly filed, plausible-looking bug: tracing the code shows the 'Work in Repository...' browse action calls a command that is only registered in the extension's `vscode-node` (Node-host) code path, and the caller silently swallows any command-execution failure — exactly matching 'workspace picker closes, nothing happens' in a web/PWA context with no Node extension host.

## Change summary

In the Agents PWA, choosing 'Work in Repository...' from the workspace picker closes the picker but opens no repository selector.

## Best solution

Either give the Copilot Chat sessions extension a web-compatible registration of `github.copilot.chat.cloudSessions.openRepository` for PWA/browser hosts, or at minimum surface a user-visible error/notification in `_executeBrowseAction` (src/vs/sessions/contrib/chat/browser/sessionWorkspacePicker.ts) instead of silently swallowing the failure — the Agents Window/Copilot Chat sessions owners should decide which.
