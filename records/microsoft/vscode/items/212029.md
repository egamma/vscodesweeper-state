# Issue #212029 — Run command on save feature

[https://github.com/microsoft/vscode/issues/212029](https://github.com/microsoft/vscode/issues/212029)

## Summary

Keep this accepted Backlog request open: 81 upvotes demonstrate demand, and current built-in task triggers do not provide extension-filtered command execution on save. Maintainers should reconcile the request with existing watch-task guidance and resolve the security boundary for repository-provided commands before implementation.

## Change summary

Provide configurable commands triggered by saving matching file types, with execution status and explicit approval of repository-provided configuration changes.

## Best solution

Resolve whether existing tasks should gain a save trigger or this workflow should remain extension-provided, considering the accepted demand and prior performance guidance. Any repository-configured execution must preserve workspace trust and settle the requested review-and-reapproval contract before introducing a separate configuration format.
