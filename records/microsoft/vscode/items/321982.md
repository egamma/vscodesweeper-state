# Issue #321982 — run error

[https://github.com/microsoft/vscode/issues/321982](https://github.com/microsoft/vscode/issues/321982)

## Summary

This is a support question about locating the run button in VS Code, not a bug or performance issue. The run button is a standard feature provided by the Python extension when a Python file is open.

## Change summary

User cannot find the run button for running a Python file in VS Code.

## Best solution

Direct the user to the relevant documentation: the run button appears in the editor title bar when a Python file is open (provided by the Python extension, which is installed). If it's missing, the user should check that a Python interpreter is selected via the Python: Select Interpreter command.

This looks like a support question rather than a bug — the run button (▶️) should appear in the top-right corner of the editor title bar when you have a Python file open and a Python interpreter selected.
