# Issue #263528 — Resizing chat session editors is choppy

## Summary

Still open and likely still reproduces: no commit references this issue, and the related architectural fix (#263499 — split chat response parts to list rows) is also still open. The underlying layout perf problem during chat editor resize appears unresolved on main.

## Change summary

Resizing a chat session editor with medium-length responses causes ~200ms relayout per frame, making the resize interaction feel choppy.

## Best solution

The structural fix is tracked in https://github.com/microsoft/vscode/issues/263499 (splitting response parts into list rows to avoid over-rendering). The NativeEditContext fix (#263525) helped one contributor but didn't solve the full layout cost. Completing #263499 would likely resolve this as well.
