[https://github.com/microsoft/vscode/issues/338861](https://github.com/microsoft/vscode/issues/338861)

## Summary

Keep open: current source intentionally supplies different Agents-window defaults, but the existing Settings indicators do not explain that distinction. The related report concerns inherited values at different settings scopes, not this missing default provenance.

## Change summary

Explain window-specific defaults and the scope of edits in Settings, with a separate request to reconsider whether the two windows should share defaults.

## Best solution
