# Issue #338861 — Settings editor gives no indication when the Agents window overrides a setting's default (same setting shows different values in each window)

[https://github.com/microsoft/vscode/issues/338861](https://github.com/microsoft/vscode/issues/338861)

## Summary

Thanks for the detailed report. The per-window default override is intentional, but the Settings editor has no indicator for it, so the request remains valid and stays open.

## Change summary

Show an indicator in the Settings editor when the Agents window overrides a setting's default, or align the defaults across windows.

## Best solution

Add a settings indicator for Agents-window default overrides, alongside the existing read-only indicator in settingsEditorSettingIndicators.ts. Separately, a maintainer should decide whether the dialog and menu style defaults should differ between windows.
