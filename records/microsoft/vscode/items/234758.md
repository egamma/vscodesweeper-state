# Issue #234758 — Right-clicking injected text caused funny selection

[https://github.com/microsoft/vscode/issues/234758](https://github.com/microsoft/vscode/issues/234758)

## Summary

Still appears unfixed on main — no commit references this issue, and the CSS `user-select: none` on `.view-line`/`.view-lines` does not seem to fully cover injected text elements (ghost text, inlay hints) during right-click, allowing native DOM selection to leak through.

## Change summary

Right-clicking on injected text (ghost text, inlay hints) causes a native DOM selection highlight instead of only triggering the editor context menu.

## Best solution

Ensure injected text elements (ghost text spans, inlay hint decorations) inherit or explicitly set `user-select: none` so right-click context menus don't produce a stray native selection. The fix likely belongs in the CSS for injected text rendering or in the contextmenu event handler to clear any native selection.
