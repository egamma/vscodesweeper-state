[https://github.com/microsoft/vscode/issues/333313](https://github.com/microsoft/vscode/issues/333313)

## Summary

Genuine gap: VS Code's plugin marketplace detection currently recognizes OpenPlugin, Copilot, and Claude marketplace.json conventions but not Codex's vendor-neutral `.agents/plugins/marketplace.json` format — worth routing to the active plugin-marketplace work.

## Change summary

Add support for detecting/parsing Codex's `.agents/plugins/marketplace.json` marketplace metadata format, alongside the existing OpenPlugin/Copilot/Claude formats.

## Best solution

Add a fourth entry to `MARKETPLACE_DEFINITIONS` in src/vs/workbench/contrib/chat/common/plugins/pluginMarketplaceService.ts (and the corresponding single-plugin manifest detection / AGENTS_PLUGINS.md doc) for `.agents/plugins/marketplace.json`, mirroring how OpenPlugin/Copilot/Claude are already handled.
