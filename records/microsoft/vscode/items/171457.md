## Change summary

Allow selected or language-identified lines, such as Markdown tables, to remain unwrapped while surrounding lines wrap normally.

## Best solution

Extend the editor wrapping model to support per-line wrap exclusions, then expose an appropriate selection command or language-aware integration while preserving horizontal scrolling for excluded lines.
