## Change summary

Tabs sometimes enter multi-select mode without a deliberate user action, and closing one tab in that state closes all selected tabs at once.

## Best solution

Ask the reporter for a reliable trigger (keyboard layout, whether AltGr/international characters are typed right before the click, exact modifier keys held) since `multiEditorTabsControl.ts` decides Ctrl/Shift-click selection purely from the raw `MouseEvent.ctrlKey`/`shiftKey`/`metaKey` flags (lines ~1018-1036) with no AltGr-awareness, unlike the keybinding layer which explicitly maps AltGr to Ctrl+Alt for keyboard shortcuts (`WindowsKeyboardMapper` `mapAltGrToCtrlAlt`) — if confirmed, the fix would live in that click handler.
