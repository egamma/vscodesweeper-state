# Issue #333321 — Tabs intermittently enter multi-select mode, causing accidental bulk tab closure  

[https://github.com/microsoft/vscode/issues/333321](https://github.com/microsoft/vscode/issues/333321)

## Summary

The reported behavior was the stale Alt-triggered “Close Others” tab action rather than multi-selection. Current main clears and revalidates that modifier state before a tab action can execute, and the fix was backported to VS Code 1.137.

## Change summary

Prevent a stale modifier-key state from turning an ordinary tab-close click into a bulk “Close Other Editors” action.

## Best solution

Keep the safeguards and regression tests from https://github.com/microsoft/vscode/commit/17c5935aa72fa5bfb3ea2c6f07c49280cc276a3c; no additional setting or code change is needed for the reported failure mode.
