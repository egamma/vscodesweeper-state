# Issue #180472 — `editor.action.moveLinesDownAction` doesn't work properly with vertical selection

[https://github.com/microsoft/vscode/issues/180472](https://github.com/microsoft/vscode/issues/180472)

## Summary

This is the same cursor-loss symptom already tracked by the open, older canonical issue https://github.com/microsoft/vscode/issues/11809. The canonical covers coordinated multi-cursor line movement, including the selection preservation and indentation concerns raised here.

## Change summary

Moving lines up or down with consecutive multi-cursor selections should move the selected lines together without discarding secondary cursors.

Consolidate this report into https://github.com/microsoft/vscode/issues/11809, preserving its last-line exception and detailed coordination analysis. Review the existing implementation candidate https://github.com/microsoft/vscode/pull/68695 against those requirements.
