# Issue #275222 — Markdown escapes don't work in tree view item label

[https://github.com/microsoft/vscode/issues/275222](https://github.com/microsoft/vscode/issues/275222)

## Summary

Still reproducible on main: the `processLabel` method in treeView.ts strips markdown syntax markers (`**`, `*`, etc.) but has no handling for backslash escape sequences, so escaped markers like `\*` are treated as formatting rather than literal characters.

## Change summary

Markdown escape sequences (e.g. `\*`) are not respected in tree view item labels — escaped markers are still interpreted as formatting.

## Best solution

Add backslash-escape processing to the `processLabel` method in `src/vs/workbench/browser/parts/views/treeView.ts` so that `\*`, `\~`, `\_` etc. are treated as literal characters, not formatting markers. The escape stripping should happen after syntax detection or the syntax detection should skip escaped markers.
