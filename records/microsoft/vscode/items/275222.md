# Issue #275222 — Markdown escapes don't work in tree view item label

## Summary

The escape-handling defect remains in current source: tree labels recognize escaped trailing asterisks as formatting delimiters and retain literal backslashes. Keep this team-authored report open; no verified canonical or fixing commit was found.

## Change summary

Respect Markdown escapes in MarkdownString tree-item labels so escaped asterisks remain literal rather than activating bold formatting.

## Best solution

Make MarkdownString tree labels honor escaped punctuation and distinguish escaped delimiters from whole-label formatting markers, while preserving plain-string labels, supported formatting, icons, and highlight alignment.
