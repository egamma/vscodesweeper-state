# Issue #143643 — Git - `git.openFile` command doesn't work properly with Replace Preview

[https://github.com/microsoft/vscode/issues/143643](https://github.com/microsoft/vscode/issues/143643)

## Summary

Keep open: the command still forwards the replacement-preview URI instead of opening the underlying workspace file. Related requests for an Open File toolbar button do not cover this command's incorrect resource identity.

## Change summary

Calling git.openFile from Replace Preview opens the virtual preview as a separate editor, preventing normal file reuse and Explorer reveal.

## Best solution

Opening the file from Replace Preview should reach the real workspace document, reuse an already-open editor, and permit Explorer reveal without applying the proposed replacements. Keep the separate toolbar-feature discussion outside this bounded command correction.
