# Issue #330828 — MacOS Tahoe: broken local network access

[https://github.com/microsoft/vscode/issues/330828](https://github.com/microsoft/vscode/issues/330828)

## Summary

Verified duplicate: this describes the same macOS Local Network TCC/entitlement regression already tracked by the open canonical issue, which has more detail and multiple confirmations — consolidating there.

## Change summary

On macOS Tahoe, VS Code (and its integrated terminal/Remote-SSH child processes) can no longer reach local network/LAN devices even though the Local Network permission is granted, forcing a workaround via root privileges.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/328399, which tracks the same regression (LAN access broken since 1.131, works via 1.130, reproduces with ping/ssh from the integrated terminal) with several independent confirmations; the reporter's own issue text already links that issue as a ref.
