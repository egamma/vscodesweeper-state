# Issue #230506 — Git - VSCode Git extension doesn't ask for remote user password, when trying to clone via ssh

[https://github.com/microsoft/vscode/issues/230506](https://github.com/microsoft/vscode/issues/230506)

## Summary

The SSH password prompt still fails in current main: the Git askpass handler treats it as host-key confirmation and accesses a missing argument. Keep this issue open for a bounded fix; the linked merged PR added diagnostics rather than resolving authentication.

## Change summary

Git operations against SSH remotes requiring an account password fail without displaying a password input.

## Best solution

The built-in Git extension should display a masked account-password input for SSH password requests and return the entered response, while preserving existing key-passphrase and host-authenticity prompts.
