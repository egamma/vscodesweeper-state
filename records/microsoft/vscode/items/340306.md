# Issue #340306 — Copilot sandbox should allow to modify permissions on the fly

[https://github.com/microsoft/vscode/issues/340306](https://github.com/microsoft/vscode/issues/340306)

## Summary

Thanks for the report. The sandbox-denial dialog gives no way to retry outside the sandbox or to adjust the sandbox policy, so users turn the sandbox off. This is a UX gap that fits the agent-host direction and has no owning duplicate. It is parked in On Deck, so it stays open.

## Change summary

When a sandboxed agent-host session hits a denied out-of-workspace access, offer a one-time unsandboxed run or a policy change for this session or all sessions.

## Best solution

Extend the sandbox-denial confirmation in the Copilot agent-host session with actions to run once outside the sandbox and to add an allow rule to the session or user sandbox policy, then continue the turn. Permission-prompt plumbing is in src/vs/platform/agentHost/node/copilot (copilotSandboxPolicy.ts, sessionSandbox.ts).
