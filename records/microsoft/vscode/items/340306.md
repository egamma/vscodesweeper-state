Thanks for the report. This is a team-authored feature request, scheduled in milestone 1.142.0, for handling sandbox denials in the Copilot agent host chat. I did not inspect the code or search for an existing capability, so this stays open rather than being closed or planned from the issue text alone.

## Change summary

When the sandbox blocks an out-of-workspace file operation in a Manual-permissions agent host session, offer in-chat options to run it once outside the sandbox or to update the sandbox policy for this session or all sessions.

## Best solution

Extend the sandbox denial confirmation in the agent host chat with actions to allow once outside the sandbox and to add a session-scoped or persistent sandbox policy exception. The user can then continue without leaving the chat or disabling the sandbox entirely.
