# Issue #95425 — Improve rendering of find matches touching each other

[https://github.com/microsoft/vscode/issues/95425](https://github.com/microsoft/vscode/issues/95425)

## Summary

Keep this accepted editor-find request open: current rendering still merges touching matches, and configuring a border does not recover their individual boundaries. The replacement failure was split into a separate issue; the remaining work is clearer match rendering.

## Change summary

Make adjacent find matches visually distinguishable and show multiline matches as coherent individual ranges.

## Best solution

Preserve each find match's visual identity, with an outline that communicates multiline extent without misleading internal borders. Plan the rendering change with the editor owner because the current merging and per-line drawing live in shared decoration infrastructure.
