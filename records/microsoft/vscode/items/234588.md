# Issue #234588 — Not displaying completion items with empty string text labels

[https://github.com/microsoft/vscode/issues/234588](https://github.com/microsoft/vscode/issues/234588)

## Summary

Confirmed bug still present on main: completion items with empty-string labels are incorrectly marked as invalid because `!''` is truthy in JS. An open PR (#234589) addresses it but hasn't merged.

## Change summary

Completion items with empty-string text labels are filtered out because the validity check uses JS falsy semantics (`!this.textLabel`), treating empty string as invalid.

## Best solution

Land or review the open PR https://github.com/microsoft/vscode/pull/234589, which changes the guard from `!this.textLabel` to `typeof this.textLabel !== 'string'` — a one-line fix in `src/vs/editor/contrib/suggest/browser/suggest.ts`. The fix is correct and minimal; may also want to consider whether `undefined`/`null` labels should be handled upstream.
