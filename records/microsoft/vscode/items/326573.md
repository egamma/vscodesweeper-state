# Issue #326573 — VS Code does not automatically sync file changes.

[https://github.com/microsoft/vscode/issues/326573](https://github.com/microsoft/vscode/issues/326573)

## Summary

VS Code already reloads clean editor models after external file-change events, but this report lacks enough detail to identify why that path is not firing. More reproduction and environment information is required.

## Change summary

External file modifications are not reflected in an open editor until the file or window is reopened.

## Best solution

Determine whether the editor was dirty, the file was reached through a symlink, or watcher configuration/errors suppressed the event; then fix the watcher or text-file reload path if the failure reproduces.
