# Issue #224189 — Diffs panels are not splitted equally when Word Wrap option is enabled

[https://github.com/microsoft/vscode/issues/224189](https://github.com/microsoft/vscode/issues/224189)

## Summary

Keep open: current diff layout does not guarantee equal text viewport widths, so unchanged long lines can wrap differently despite a centered divider. Existing wrapping controls and the related reports do not cover this accepted Backlog request.

## Change summary

Give side-by-side diff panes matching usable text widths when word wrap is enabled, avoiding alignment filler caused solely by unequal wrapping.

## Best solution

Consider a coordinated layout for original and modified text viewports in the shared diff editor, covering both ordinary and multi-file diffs while preserving intentional alignment padding for actual changes and user-controlled resizing.
