# Issue #188779 — No progress if Notebook output coming in slow

[https://github.com/microsoft/vscode/issues/188779](https://github.com/microsoft/vscode/issues/188779)

## Summary

The UX gap between the execution-complete checkmark and delayed output rendering remains unaddressed on main — the progress bar is purely tied to execution state, not output rendering completion. Team-authored polish item; keeping open.

## Change summary

Notebook shows success checkmark before output finishes rendering when output arrives slowly, giving a jarring no-progress gap.

## Best solution

Extend the progress indication (in cellProgressBar.ts or the execution icon logic) to account for pending output rendering — keep showing progress until output is actually visible, not just until execution state transitions to complete.
