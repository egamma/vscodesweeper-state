# Issue #160442 — De-Indent code on paste into IW code cell

[https://github.com/microsoft/vscode/issues/160442](https://github.com/microsoft/vscode/issues/160442)

## Summary

Keep open: the Interactive Window input still excludes the editor contribution that implements format-on-paste, even though it reads the setting. This confirms the configuration gap acknowledged by the maintainer; enabling editor.formatOnPaste alone does not resolve it.

## Change summary

Honor paste-formatting settings in the Interactive Window input so copied, indented Python code can be adjusted automatically instead of requiring a manual format command.

## Best solution

Make the Interactive Window input honor the existing editor.formatOnPaste contract, including its requirement for a range-formatting provider. Preserve opt-in behavior and verify indentation adjustment both at the top level and inside an existing block.
