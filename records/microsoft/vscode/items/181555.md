## Summary

Team-authored API proposal for tagged template literal support in vscode.l10n.t — not yet implemented in core or the extension API, and the prerequisite core work (https://github.com/microsoft/vscode/issues/183566) is also still open. Keeping open as a valid backlog item.

## Change summary

Add a tagged template literal overload to vscode.l10n.t so extension authors can write `l10n.t`Hello ${name}!`` with compile-time safety instead of error-prone positional placeholders.

## Best solution
