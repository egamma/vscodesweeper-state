# Issue #181555 — Proposal: add tagged template literal support for `vscode.l10n`

[https://github.com/microsoft/vscode/issues/181555](https://github.com/microsoft/vscode/issues/181555)

## Summary

Keep this API proposal open for the API owners: current declarations and runtime do not support tagged localization templates. The thread explicitly defers the extension API until experimentation in core, and api-proposal tracking issues are protected from cleanup closes.

## Change summary

Allow vscode.l10n.t to be used as a template tag so interpolation arguments stay paired with localization placeholders.

## Best solution

Evaluate tagged-template localization in core through the related proposal, then decide whether to advance and finalize the extension API overload with compatible extraction tooling. Preserve the existing object-based API for translator comments, as agreed in the thread.
