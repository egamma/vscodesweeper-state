# Issue #181555 — Proposal: add tagged template literal support for `vscode.l10n`

[https://github.com/microsoft/vscode/issues/181555](https://github.com/microsoft/vscode/issues/181555)

## Summary

Keep this API proposal open: current declarations and runtime still lack tagged-template support, and the maintainer explicitly deferred it pending experimentation in core. The api-proposal label independently reserves closure for the API owners.

## Change summary

Allow vscode.l10n.t to tag template literals so substitutions stay attached to their localized message without manually numbered placeholders.

## Best solution

Have the API owners revisit the core experiment and decide whether to introduce tagged-template support across the extension API, runtime, and localization extraction tooling. Preserve the existing object-based API for messages requiring translator comments, as settled in the discussion.
