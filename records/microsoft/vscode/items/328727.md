# Issue #328727 — Allow configuring loudspeaker as well

[https://github.com/microsoft/vscode/issues/328727](https://github.com/microsoft/vscode/issues/328727)

## Summary

Genuine, unimplemented gap: current main only lets users select a microphone for dictation/Voice Mode (SELECT_MICROPHONE_COMMAND in micButtonMenuActions.ts) with no equivalent output/speaker device picker. It's a fresh, team-authored feature request just entered the Backlog Candidates upvote window, so it stays open per the feature-request process regardless of upvote count so far.

## Change summary

Add the ability to choose the audio output (speaker) device for Voice Mode, mirroring the existing microphone selection.

## Best solution

Extend the shared mic/voice device-picker infrastructure (src/vs/workbench/contrib/chat/browser/speechToText/micButtonMenuActions.ts and the dictation onboarding device picker) to also enumerate `audiooutput` devices and apply `setSinkId`-style output selection for Voice Mode playback; let the Backlog Candidates upvote process run its course before deciding whether it gets prioritized.
