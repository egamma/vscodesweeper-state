# Issue #332771 — Agents window on the "server" will list other remote sessions

[https://github.com/microsoft/vscode/issues/332771](https://github.com/microsoft/vscode/issues/332771)

## Summary

Keep open: current tunnel discovery can populate other hosts without an explicit connection request, but the exact three-machine session-list behavior remains unverified. Current code has disconnect/removal controls and hosted-tunnel suppression; the supplied steps suffice to retest whether those address the original concern.

## Change summary

Sessions from another remote machine unexpectedly appear in a hosting machine's Agents window, with unclear removal and cross-machine disconnect semantics.

## Best solution

Establish predictable machine-local session visibility when an Agents window also hosts remote connections, with a discoverable way to exclude another host without disrupting other clients. Retest the three-machine scenario and settle whether account-wide discovery should automatically expose those sessions or require local selection.
