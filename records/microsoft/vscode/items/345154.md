## Summary

A supported, workspace-scoped read-only runtime grant remains missing from the inspected Codex configuration surface. Keep this sandbox-permission request open for human review; existing writable-directory and skill-specific grants do not satisfy it.

## Change summary

Support read-only access to a pinned external Python runtime across Codex startup, thread resume, and subsequent turns without weakening other sandbox restrictions.

## Best solution

Establish a supported Codex read-only path configuration contract that survives lifecycle transitions while preserving protected paths, hook enforcement, disabled command networking, and denial of runtime writes. Review the permission boundary explicitly rather than recommending writable directories or Full Access.
