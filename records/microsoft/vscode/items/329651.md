# Issue #329651 — Markdown preview: no commands to scroll it, so keyboard scrolling can't be rebound (e.g. j/k)

[https://github.com/microsoft/vscode/issues/329651](https://github.com/microsoft/vscode/issues/329651)

## Summary

Well-researched request: neither markdown-language-features nor core webview commands expose any scroll command, so keybindings like j/k cannot drive the Markdown preview. Confirmed by inspecting extensions/markdown-language-features/package.json (only cursor/editor commands, no scroll) and src/vs/workbench/contrib/webviewPanel/browser/webviewCommands.ts (only find-related webview commands exist).

## Change summary

Add scroll commands (line/page/top/bottom) for the Markdown preview webview, or more generally for webview editors, so keyboard scrolling can be rebound.

## Best solution

Add scroll commands either in extensions/markdown-language-features (markdown.preview.scrollLineDown/Up, scrollPageDown/Up, scrollToTop/Bottom) or, more generally, generic webview scroll commands alongside the existing editor.action.webvieweditor.showFind family in src/vs/workbench/contrib/webviewPanel/browser/webviewCommands.ts, sending a scroll message to the webview.
