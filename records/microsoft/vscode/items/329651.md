# Issue #329651 — Markdown preview: no commands to scroll it, so keyboard scrolling can't be rebound (e.g. j/k)

[https://github.com/microsoft/vscode/issues/329651](https://github.com/microsoft/vscode/issues/329651)

## Summary

Real gap: confirmed on main that markdown-language-features and the webview editor commands (webviewCommands.ts) expose find but no scroll commands, so preview scrolling cannot be rebound. Reasonable, well-scoped ask worth routing to the markdown/webview area.

## Change summary

Add commands (e.g. scrollLineUp/Down, scrollPageUp/Down, scrollToTop/Bottom) for the Markdown preview webview so its scrolling can be bound to custom keybindings.

## Best solution

Add scroll commands scoped to the existing context keys (activeWebviewPanelId == 'markdown.preview', activeCustomEditorId == 'vscode.markdown.preview.editor'), likely in extensions/markdown-language-features/src/commands/ plus a webview-side message handler, mirroring the showFind/hideFind pattern in src/vs/workbench/contrib/webviewPanel/browser/webviewCommands.ts.
