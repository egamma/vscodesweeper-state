# Issue #329651 — Markdown preview: no commands to scroll it, so keyboard scrolling can't be rebound (e.g. j/k)

[https://github.com/microsoft/vscode/issues/329651](https://github.com/microsoft/vscode/issues/329651)

## Summary

The requested command surface is still missing in the inspected checkout: existing preview scrolling supports source synchronization, not independently rebindable keyboard motion. Keep this open as a feature request; no verified canonical or landed implementation was found.

## Change summary

Expose bindable commands for line, page, and top/bottom scrolling in Markdown previews, potentially through shared webview-editor commands.

## Best solution

Provide independently bindable scrolling commands that work in both Markdown preview editor modes without requiring focus in the source editor. Maintainers should decide whether this belongs in the Markdown preview extension or shared webview infrastructure, preserving native scrolling and existing scroll synchronization.
