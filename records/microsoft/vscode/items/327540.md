# Issue #327540 — Agents window Markdown editor: Empty paragraphs exist only as transient view state

[https://github.com/microsoft/vscode/issues/327540](https://github.com/microsoft/vscode/issues/327540)

## Summary

Confirmed experimental Markdown editor bug: pressing Enter can create visible state without updating the backing document. This team-authored report has a precise Insiders reproduction and should remain open.

## Change summary

Make newly inserted empty paragraphs immediately update the Markdown document, dirty state, undo history, selection, and save state.

## Best solution

Update the @vscode/markdown-editor Enter handling so creating an empty paragraph immediately edits `EditorModel.sourceText`; the existing VS Code adapter will then propagate it to the TextDocument.
