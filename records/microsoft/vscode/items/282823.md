# Issue #282823 — Privacy matter!

[https://github.com/microsoft/vscode/issues/282823](https://github.com/microsoft/vscode/issues/282823)

## Summary

Keep open as a security-sensitive privacy request: current main has `.copilotignore` plumbing, but local exclusions remain gated by the account token's content-exclusion entitlement. The closely related accepted request is newer than this re-reviewed issue, so it cannot serve as its duplicate canonical.

## Change summary

Provide user-controlled scoping that prevents GitHub Copilot from accessing sensitive files while retaining Copilot elsewhere in the workspace.

## Best solution

Provide an officially supported local exclusion contract, such as `.copilotignore`, available independently of organization-managed policy and enforced consistently across completions, chat context, workspace search, attachments, and agent file tools.
