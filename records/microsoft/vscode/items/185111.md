# Issue #185111 — Bug (?): auto-trim of trailing whitespace on the cursor line

[https://github.com/microsoft/vscode/issues/185111](https://github.com/microsoft/vscode/issues/185111)

## Summary

Keep this accepted feature request open: explicit saves still trim whitespace at the caret, and no existing setting provides the requested opt-in protection. It has 29 upvotes, reached the Backlog, and already serves as the canonical issue for a newer matching request.

## Change summary

Add an opt-in setting that preserves trailing whitespace at the caret during explicit saves without changing the default trimming behavior.

## Best solution

Provide optional caret protection in the whitespace save participant while retaining full-file trimming by default. Settle whether protection preserves the entire caret line or only whitespace preceding the caret, including consistent multi-cursor behavior.

Acceptance checks cover both reported examples, multiple cursors, unchanged automatic saves, and the chosen behavior when trailing whitespace extends beyond the caret.
- **Trace:**

The relevant configuration registrations are in src/vs/workbench/contrib/files/browser/files.contribution.ts, and existing test surfaces are saveParticipant.test.ts and trimTrailingWhitespaceCommand.test.ts. - **Open decisions:**
