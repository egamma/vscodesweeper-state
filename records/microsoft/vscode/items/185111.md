# Issue #185111 — Bug (?): auto-trim of trailing whitespace on the cursor line

## Summary

Keep open as the canonical backlog feature request. Current main intentionally preserves cursor lines only during auto-save, no setting covers explicit saves, and the request earned 29 community upvotes.

## Change summary

Add an option for trailing-whitespace trimming on explicit save to preserve the active cursor lines and avoid moving cursors.

## Best solution

Add a language-overridable setting beside `files.trimTrailingWhitespace` that optionally passes active cursor positions during explicit saves, while retaining the existing behavior by default. Cover both text editors and notebook cell editors consistently.
