# Issue #330579 — Option to filter navigation history to definition/symbol jumps only

[https://github.com/microsoft/vscode/issues/330579](https://github.com/microsoft/vscode/issues/330579)

## Summary

This is already shipped: VS Code maintains three separate navigation stacks (global/cursor, edits, and definition/symbol "navigation" jumps), and dedicated commands exist to go back/forward/previous within the navigation-only stack.

## Change summary

Requests a setting or dedicated command to filter Go Back/Go Forward so it only traverses definition/symbol jumps, excluding cursor moves, in-file search, and diagnostic jumps.

## Best solution

Point the reporter at the existing `workbench.action.navigateBackInNavigationLocations` / `workbench.action.navigateForwardInNavigationLocations` (and `workbench.action.navigatePreviousInNavigationLocations` / `workbench.action.navigateToLastNavigationLocation`) commands, which already filter to GoFilter.NAVIGATION entries produced by Go to Definition/Peek/References (TextEditorSelectionSource.JUMP); users can bind their own keybindings to them since no default keybinding is assigned.

- **Proposed comment:**

  > Thanks for the request! This already exists — VS Code keeps definition/symbol jumps in a separate navigation-history stack from plain cursor moves, in-file search, and edits. You can use the Command Palette (or bind your own keybinding) to `workbench.action.navigateBackInNavigationLocations` / `workbench.action.navigateForwardInNavigationLocations` (plus `workbench.action.navigatePreviousInNavigationLocations` and `workbench.action.navigateToLastNavigationLocation`), which only traverse entries created by Go to Definition / Peek / Find All References, skipping regular cursor movement and Ctrl+F searches. There's no default keybinding for these, so you'll want to add one in `keybindings.json` if you want to reuse Alt+Left/Alt+Right-style shortcuts for them.

- **existing commands:** src/vs/workbench/browser/parts/editor/editorActions.ts registers NavigateForwardInNavigationsAction (`workbench.action.navigateForwardInNavigationLocations`), NavigateBackwardsInNavigationsAction (`workbench.action.navigateBackInNavigationLocations`), NavigatePreviousInNavigationsAction, and NavigateToLastNavigationLocationAction — all calling historyService.go*(GoFilter.NAVIGATION), lines ~1623-1690.
- **definition jumps tagged distinctly:** src/vs/editor/contrib/gotoSymbol/browser/goToCommands.ts line 220 opens the target editor with `selectionSource: TextEditorSelectionSource.JUMP`, which historyService.ts maps to EditorPaneSelectionChangeReason.JUMP and routes into the navigationsStack (GoFilter.NAVIGATION), separate from plain cursor moves/searches (GoFilter.NONE) and edits (GoFilter.EDITS).
