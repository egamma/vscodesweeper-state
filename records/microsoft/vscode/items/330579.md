# Issue #330579 — Option to filter navigation history to definition/symbol jumps only

[https://github.com/microsoft/vscode/issues/330579](https://github.com/microsoft/vscode/issues/330579)

## Summary

A real navigation-history gap remains: the existing navigation-location commands exclude ordinary cursor movement but combine generic navigation and symbol jumps, so they cannot restrict history strictly to definitions or symbols. The request is still within its Backlog Candidates voting period and should be routed to workbench history.

## Change summary

Provide a setting or commands that traverse only definition and symbol jumps, excluding cursor movement, searches, and diagnostic navigation.

## Best solution

Extend the workbench history model with a definition/symbol-jump-only mode or command pair while preserving the existing all-location and navigation-location behavior.
