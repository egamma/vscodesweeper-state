# Issue #256592 — Ability to send to Coding Agent from prompt files

[https://github.com/microsoft/vscode/issues/256592](https://github.com/microsoft/vscode/issues/256592)

## Summary

Keep open: current source retains a separately gated prompt-file delegation overlay, while the Run menu exposes no explicit Coding Agent action. The discussion also identifies missing prompt-context handling, and the linked extension issue explicitly consolidates that work here.

## Change summary

Provide a discoverable prompt-file action that delegates the prompt and its relevant context to the Coding Agent.

## Best solution

Offer a supported Coding Agent entry point from the prompt-file Run menu, with defined handling of prompt contents, linked context, and applicable instructions. Preserve this issue as the owning discussion rather than treating the hidden overlay or manual chat delegation as complete coverage.
