# Issue #256592 — Ability to send to Coding Agent from prompt files

[https://github.com/microsoft/vscode/issues/256592](https://github.com/microsoft/vscode/issues/256592)

## Summary

The 'Delegate to Copilot coding agent' overlay for prompt files exists in source but remains gated behind an unreachable context key (`enableRemoteCodingAgentPromptFileOverlay`, default false). The feature is partially built but not yet enabled — the issue tracks making it accessible to users.

## Change summary

Add a visible entry point to send prompt files to the Copilot coding agent, e.g. in the prompt file's run menu dropdown.

## Best solution

Enable the `enableRemoteCodingAgentPromptFileOverlay` context key (or integrate the action into the prompt file run menu) when the coding agent UI integration setting is active. The overlay widget code is in `src/vs/workbench/contrib/chat/browser/promptSyntax/promptCodingAgentActionOverlay.ts`; the gating context key is in `chatContextKeys.ts:122`.
