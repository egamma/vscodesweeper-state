# Issue #328121 — Provide a migration path for existing agents during local harness migration

[https://github.com/microsoft/vscode/issues/328121](https://github.com/microsoft/vscode/issues/328121)

## Summary

Keep open: existing migration flows do not establish coverage for legacy tool references inside custom agents. The newer migration-readiness tracker explicitly retains this issue as the owner of that work; it is not a valid duplicate target for this re-reviewed, team-authored request.

## Change summary

Help users adapt existing custom-agent tool declarations when moving from the local harness to the Copilot harness.

## Best solution

Integrate tool-reference compatibility assessment and reviewed migration into the Agent Customizations migration experience. Preserve supported declarations, explain unresolved references, and avoid silently broadening an agent's tool access.
