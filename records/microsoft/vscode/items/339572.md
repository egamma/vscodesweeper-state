# Issue #339572 — No way to open a single-file diff from the chat "N Files +X -Y" summary — only the combined multi-file diff opens

[https://github.com/microsoft/vscode/issues/339572](https://github.com/microsoft/vscode/issues/339572)

## Summary

Traced the exact code path on main: the per-file disclosure list the reporter wants already exists in `ChatTurnPillsContentPart` (it shares `renderChangesSummaryFileList` with the checkpoint summary, and each row opens its own file's diff) — it's reached by clicking the header/chevron, not the `+X -Y` counts. The counts button is deliberately, and explicitly test-covered, wired to open the combined diff instead of toggling the disclosure, so this is intentional design, not a regression.

## Change summary

Clicking the chat turn's `+X -Y` counts pill always opens the combined multi-file diff instead of expanding a per-file list.

## Best solution

Keep the current split affordance (counts = quick jump to combined diff; rest of header/chevron = expand per-file list, each opening its own diff) — it's intentional and tested. If the reporter's confusion is common, the fix is clearer affordance/documentation (e.g. visually distinguish the counts button or update the linked docs), not a behavior change.
