# Issue #339572 — No way to open a single-file diff from the chat "N Files +X -Y" summary — only the combined multi-file diff opens

[https://github.com/microsoft/vscode/issues/339572](https://github.com/microsoft/vscode/issues/339572)

## Summary

The per-file diff disclosure still exists on main — clicking the '+X -Y' counts intentionally opens the combined diff, while clicking elsewhere on the header (the file-count label or chevron) expands the file list, from which each row opens its own diff. This split is deliberate and covered by a dedicated unit test, so this reads as as-designed rather than a regression.

## Change summary

Reporter wants clicking the chat turn's '+X -Y' summary pill to open (or expand to) a single-file diff instead of always opening the combined multi-file diff.

## Best solution

Keep the current split: the counts button is a fast path to the combined diff, and clicking the rest of the header (label text or chevron) expands the checkpoint-style file list where each row opens its own diff — consider only a discoverability tweak (e.g. a tooltip) if reporters keep missing it.
