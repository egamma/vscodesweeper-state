## Summary

Keep open: another user confirms disappearing sessions on stable, and the linked persistence-hardening PR remains open. Current source still aborts persistence on incremental serialization failure, but that failure has not been established as the cause of the immediate UI disappearance.

## Change summary

An active agent thread disappears from Sessions while its background task continues editing the workspace.

Review the targeted hardening in https://github.com/microsoft/vscode/pull/309286, then establish whether it addresses the live-session disappearance or only persistence loss. The finished behavior should retain a visible, accessible running session or an explicit recoverable failure state while background work continues.
