# Issue #121379 — Webviews disables Alt key menu navigation

[https://github.com/microsoft/vscode/issues/121379](https://github.com/microsoft/vscode/issues/121379)

## Summary

Still reproduces on main: the Alt-key menu activation doesn't trigger when a webview has focus because the synthetic KeyboardEvent re-dispatched by webviewElement's handleKeyEvent doesn't properly satisfy the ModifierKeyEmitter's Alt press-and-release detection logic. This is the canonical issue with three duplicates closed against it.

## Change summary

Pressing Alt to focus the menu bar does not work when a webview (e.g. Markdown preview, Extensions view) has focus.

## Best solution

Ensure the webview's re-dispatched keydown/keyup events for the Alt key properly trigger ModifierKeyEmitter's Alt press-and-release detection in src/vs/base/browser/dom.ts, so the menubar's onModifierKeyToggled in src/vs/base/browser/ui/menu/menubar.ts fires and focuses the menu. The fix likely involves either ensuring the synthetic events have the right properties or adding explicit Alt-menu-toggle handling in the webview key forwarding path.
