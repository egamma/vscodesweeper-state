# Issue #186726 — Use `useDefineForClassFields` compiler options

[https://github.com/microsoft/vscode/issues/186726](https://github.com/microsoft/vscode/issues/186726)

## Summary

Keep open: current main checks compatibility with defined class fields but still explicitly disables them in both the compiler configuration and the newer transpile/bundle paths. The preparation work does not complete the requested runtime adoption.

## Change summary

Adopt JavaScript-standard class-field initialization semantics without breaking constructor-dependent initialization.

## Best solution

Complete the runtime migration across the compiler and production build paths, preserving intended initialization behavior throughout VS Code. Use the existing shadow checks as prerequisites, not as proof that running with defined fields is safe.
