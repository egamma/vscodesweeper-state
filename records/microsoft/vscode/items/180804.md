# Issue #180804 — Can we save a couple more pixels in the glyph margin

[https://github.com/microsoft/vscode/issues/180804](https://github.com/microsoft/vscode/issues/180804)

## Summary

Verified duplicate: the open canonical issue already owns the multi-decoration glyph-margin layout, including concerns about the doubled gutter width. Current main still allocates one full line-height of horizontal space per lane, so the gap remains but should be consolidated there.

## Change summary

Make the two-lane editor glyph margin more compact without changing the appearance of a single lane.

## Best solution

Consolidate this spacing requirement on https://github.com/microsoft/vscode/issues/179725 and settle a compact multi-lane layout there that preserves the single-lane appearance and usable glyph targets.
