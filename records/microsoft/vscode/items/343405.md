Keep this as the canonical report for remote Copilot sessions ignoring the selected custom agent. An independent report supplies a minimal reproduction; current source contains selection handling but does not establish that this failure is resolved.

## Change summary

Selecting a workspace custom agent in a remote Copilot chat fails to activate its instructions and tool restrictions.

## Best solution
