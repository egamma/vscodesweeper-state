Keep open: the report provides concrete steps and session-event observations sufficient to retest the remote custom-agent selection failure. Current main has explicit agent-selection and customization-resolution handling, but source inspection does not establish that the reported failure is resolved.

## Change summary

A workspace custom agent selected in the chat picker is ignored by Copilot CLI agent-host sessions, leaving the default agent active without the selected instructions and tool restrictions.

## Best solution

Ensure the picker-selected workspace agent becomes the active agent for the remote Copilot conversation, including its instructions and tool restrictions on subsequent turns. Trace the remote selection and customization-resolution boundary before deciding whether the remaining defect is in VS Code forwarding or runtime application.
