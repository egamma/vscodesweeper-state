# Issue #343405 — Custom agent selected in chat picker is not applied to Copilot CLI agent-host sessions

[https://github.com/microsoft/vscode/issues/343405](https://github.com/microsoft/vscode/issues/343405)

## Summary

Keep open: the report provides sufficient steps and session-event observations to retest selected-agent activation. Current main explicitly forwards agent selections, but the remote selection-to-runtime path remains unconfirmed and no concrete fixing commit was established.

## Change summary

Ensure a custom agent selected in the chat picker actually supplies the instructions and tool restrictions for the main Copilot CLI agent-host conversation.

## Best solution

Diagnose the remote picker-to-message-to-SDK selection path and make the active conversation honor the selected custom agent on the first and subsequent turns. An unresolved explicit selection should not silently execute as the default agent.
