# Issue #293419 — The max prompt tokens always show 128K

[https://github.com/microsoft/vscode/issues/293419](https://github.com/microsoft/vscode/issues/293419)

## Summary

The 128K max prompt token limit is determined by the server-side model metadata (CAPI), not hardcoded in the VS Code client. The client correctly passes through whatever limit the server reports for the selected model. This is a service-side configuration question, not a VS Code bug.

## Change summary

Reporter expects a higher token limit when switching to GPT-5.2-Code in the Copilot cloud agent, but the server enforces 128K.

## Best solution

The max prompt token limit is set by the Copilot API server's model metadata, not by the VS Code client. The client code in `modelMetadataFetcher.ts` faithfully uses `max_prompt_tokens` from the server response. If the model truly supports a larger context window, that is a server-side configuration change the Copilot service team would need to make.
