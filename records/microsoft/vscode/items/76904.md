# Issue #76904 — Hirerarchical multi-root layout

[https://github.com/microsoft/vscode/issues/76904](https://github.com/microsoft/vscode/issues/76904)

## Summary

Keep open as the canonical request for hierarchical grouping of multi-root workspace folders. It has 125 upvotes, is accepted into the Backlog, and current source still supports only a flat folder list.

## Change summary

Allow folders in a multi-root workspace to be organized into named, nested groups in the Explorer.

## Best solution

Extend the workspace-file model with grouping metadata while preserving flat workspace-folder semantics for extensions, search, and configuration. Render that metadata as collapsible hierarchy in the Explorer.
