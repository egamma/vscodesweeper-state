# Issue #335749 — More prevalent workspace trust indicator

[https://github.com/microsoft/vscode/issues/335749](https://github.com/microsoft/vscode/issues/335749)

## Summary

Current main still has the reported UX gap: the model picker clearly explains Restricted Mode and offers a trust action, while the permissions picker presents ordinary choices without disclosing that Chat cannot run until the workspace is trusted.

## Change summary

Make Chat's untrusted-workspace state prominent from the permissions surface instead of exposing controls whose changes cannot make the session runnable.

## Best solution

Give the permissions picker the same clear Restricted Mode treatment as the model picker, including an accessible explanation and a keyboard-operable Trust Workspace action, while leaving permission-level semantics unchanged.
