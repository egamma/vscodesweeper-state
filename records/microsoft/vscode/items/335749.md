# Issue #335749 — More prevalent workspace trust indicator

[https://github.com/microsoft/vscode/issues/335749](https://github.com/microsoft/vscode/issues/335749)

## Summary

Team-authored UX request pointing out an inconsistency: the model picker clearly signals workspace-trust restrictions, but the tools/permissions picker silently no-ops instead. This is a legitimate polish item that needs a UI decision, not a close.

## Change summary

In an untrusted workspace, the chat tools/permissions picker allows clicks that silently do nothing instead of clearly indicating chat won't run until the workspace is trusted.

## Best solution

Add a clear, in-your-face workspace-trust indicator to the chat permissions/tools picker (mirroring the pattern already used in modelPickerWidget.ts) so users understand why chat is inert in an untrusted workspace — likely touches the chat input toolbar/tools picker UI in src/vs/workbench/contrib/chat/browser/widget/input/.
