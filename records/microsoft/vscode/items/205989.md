# Issue #205989 — Warning indication jumps up/down when scrolling

[https://github.com/microsoft/vscode/issues/205989](https://github.com/microsoft/vscode/issues/205989)

## Summary

The notebook overview-ruler positioning remains vulnerable to layout-height changes while scrolling, and no canonical issue or targeted fix was found. It is already correctly classified and routed as notebook layout polish.

## Change summary

Keep notebook warning markers stationary in the overview ruler while scrolling through executed cells.

## Best solution

Make marker positioning in `NotebookOverviewRuler` derive from stable notebook cell offsets and refresh when content height changes, rather than accumulating potentially changing cell layout heights.
