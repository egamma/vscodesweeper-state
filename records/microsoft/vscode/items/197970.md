# Issue #197970 — `"colorizedBracketPairs"` only supports lowercase, but matching is case insensitive

[https://github.com/microsoft/vscode/issues/197970](https://github.com/microsoft/vscode/issues/197970)

## Summary

The casing inconsistency remains in current source: uppercase configured delimiters cannot be retrieved, while lowercase delimiters also match uppercase text. Keep this report open; the related umbrella explicitly asks for separate issues.

## Change summary

Configured uppercase colorized bracket pairs fail to resolve, and case-insensitive matching can incorrectly treat OCaml's End constructor as an end delimiter.

## Best solution

Make alphabetic bracket configuration and matching internally consistent across the bracket tokenizers and matching paths. Settle the language-level case-sensitivity contract before changing existing case-insensitive behavior.
