# Issue #335889 — File references under sub agents should be clickable

[https://github.com/microsoft/vscode/issues/335889](https://github.com/microsoft/vscode/issues/335889)

## Summary

Team-authored bug report (kept open per policy regardless), but the codebase gives real, source-level evidence: file references shown in the sub agent prompt/result sections likely aren't converted into clickable file widgets, unlike other subagent UI spots that explicitly do this conversion.

## Change summary

File references shown inside sub agent transcript sections (prompt/result) aren't clickable the way file references elsewhere in chat are.

## Best solution

In src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatCollapsibleMarkdownContentPart.ts, call renderFileWidgets() on the rendered markdown element in initContent() (mirroring the pattern already used at chatSubagentContentPart.ts:843 for the collapsed title detail), so prompt/result markdown rendered via ChatCollapsibleMarkdownContentPart gets the same clickable file-widget treatment.
