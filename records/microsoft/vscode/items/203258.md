# Issue #203258 — Adopt the fs readonly message in notebook cell editor

[https://github.com/microsoft/vscode/issues/203258](https://github.com/microsoft/vscode/issues/203258)

## Summary

Keep open: notebook editors still discard the filesystem provider’s explanatory read-only message and propagate only a boolean. The maintainer’s adoption guidance remains applicable, and no verified canonical issue was found.

## Change summary

Show the filesystem provider’s custom read-only message when a user attempts to edit a notebook cell.

## Best solution

Notebook code and Markdown cell editors should display the provider-supplied Markdown explanation while preserving existing read-only enforcement and the default message when no custom explanation exists.

- **Fit:** aligned
- **Reason:** Using the same read-only explanation in text and notebook editors improves consistency across existing editor surfaces.
