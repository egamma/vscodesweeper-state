# Issue #203258 — Adopt the fs readonly message in notebook cell editor

[https://github.com/microsoft/vscode/issues/203258](https://github.com/microsoft/vscode/issues/203258)

## Summary

Still unimplemented on main: the notebook cell editor never passes the filesystem's readOnlyMessage through to the Monaco editor option, so cells show a generic readonly message instead of the provider-specific one.

## Change summary

Notebook cell editors should display the filesystem provider's custom readOnlyMessage instead of the generic readonly tooltip.

## Best solution

When setting the cell editor to readonly, also pass the `readOnlyMessage` from the notebook editor input's `isReadonly()` (which may return an `IMarkdownString`) through to the cell editor's `readOnlyMessage` option. The fix likely touches `src/vs/workbench/contrib/notebook/browser/notebookEditorWidget.ts` (where `_readOnly` is propagated) and potentially the cell editor options layer.
