Valid feature request with 37 upvotes, promoted to Backlog. The comments contribution on current main has no FileDecorationProvider — file-level decorations in the Explorer for files with comments remain unimplemented.

Implement an `IDecorationsProvider` (or `FileDecorationProvider`) in `src/vs/workbench/contrib/comments/browser/` that queries the comment model for files with active comment threads and surfaces a decoration in the Explorer.
