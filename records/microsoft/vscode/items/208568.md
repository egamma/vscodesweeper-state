# Issue #208568 — Clear automatically inserted repro steps

[https://github.com/microsoft/vscode/issues/208568](https://github.com/microsoft/vscode/issues/208568)

## Summary

The defect remains on current main: selecting another extension loads and appends its generated issue body without removing the previous extension's generated text. The fix should preserve user-authored or edited content while replacing only untouched extension-provided content.

## Change summary

Changing the selected extension in the issue reporter should remove automatically inserted reproduction steps belonging to the previous extension without clearing text the user authored.

## Best solution

Track the extension-provided portion of the description separately enough to replace it when the target extension changes, while retaining user-authored text and treating edited generated text conservatively as user content.
