# Issue #144211 — Debugger does not respect supportsDelayedStackTraceLoading false

[https://github.com/microsoft/vscode/issues/144211](https://github.com/microsoft/vscode/issues/144211)

## Summary

The bug remains on current main: VS Code skips delayed loading when the capability is false, but its resulting full-stack request still unconditionally includes `startFrame: 0` and `levels: 20`, contrary to the DAP contract.

## Change summary

Omit stack-frame paging arguments when a debug adapter does not advertise `supportsDelayedStackTraceLoading`.

## Best solution

Keep the existing paged behavior for adapters advertising delayed stack loading, while sending an unbounded `stackTrace` request to adapters that do not advertise it.
