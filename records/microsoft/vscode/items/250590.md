# Issue #250590 — Extension host manager caches activation events of uninstalled extensions

[https://github.com/microsoft/vscode/issues/250590](https://github.com/microsoft/vscode/issues/250590)

## Summary

The root defect remains on current main: an activation event with no matching installed extension is cached as a completed no-op, so reinstalling the extension cannot activate it through that event. The merged chat-side workaround does not correct the extension-host lifecycle behavior.

## Change summary

Do not cache activation events that have no corresponding installed extension, so the event can activate an extension installed later.

## Best solution

Ensure unmatched activation requests do not become permanently completed entries in `ExtensionHostManager`, while preserving deduplication for events that actually target extensions. Cover the uninstall, host restart, reinstall, and repeated activation sequence with a focused unit test.
