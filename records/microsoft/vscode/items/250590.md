# Issue #250590 — Extension host manager caches activation events of uninstalled extensions

[https://github.com/microsoft/vscode/issues/250590](https://github.com/microsoft/vscode/issues/250590)

## Summary

The root-cause bug remains on main: ExtensionHostManager._cachedActivationEvents still caches and replays activation events for uninstalled extensions on EH restart. Only a workaround in chatServiceImpl.ts was merged (PR #250551); the proper fix described in the issue has not landed.

## Change summary

ExtensionHostManager caches activation events without checking whether the target extension is still installed, causing stale activations after EH restart.

## Best solution

Filter _cachedActivationEvents in ExtensionHostManager.activateByEvent (or when replaying initialActivationEvents) to skip events whose corresponding extension is no longer installed, removing the root cause rather than relying on downstream workarounds.
