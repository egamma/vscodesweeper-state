# Issue #335683 — MCP configuration: Show where the server was configured

[https://github.com/microsoft/vscode/issues/335683](https://github.com/microsoft/vscode/issues/335683)

## Summary

Fresh, well-scoped feature request (filed same day, no traction yet to assess) asking the MCP server details view to show and link to the source of a server's configuration (workspace mcp.json, user mcp.json, extension, or setting); current UI only shows a scope badge icon, not the actual location, so a real gap remains.

## Change summary

Show, in the MCP server configuration UI, where a given MCP server was configured (file, setting, or extension) with a link to that source.

## Best solution

Extend the MCP server editor/details view (src/vs/workbench/contrib/mcp/browser/mcpServerEditor.ts, mcpServerWidgets.ts) to surface the concrete config source per server — file path for mcp.json entries with an 'open file' action, the owning extension for programmatically-registered servers, or the settings key for setting-driven servers — beyond the existing scope badge which only indicates User/Workspace/RemoteUser.
