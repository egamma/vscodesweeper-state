# Issue #248328 — Git extension API branch `upstream` is undefined when repo was cloned shallow

[https://github.com/microsoft/vscode/issues/248328](https://github.com/microsoft/vscode/issues/248328)

## Summary

Keep open: maintainers confirmed missing upstream metadata in the built-in Git extension, and current source retains the implicated behavior. An open PR explicitly targets this issue and should be reviewed before considering completion.

## Change summary

Preserve configured branch upstream metadata after creating and pushing a branch in a shallow clone so Git and pull-request features recognize its tracking relationship.

## Best solution

Review https://github.com/microsoft/vscode/pull/304980 for correct upstream resolution when shallow/single-branch fetch configuration prevents for-each-ref from reporting it. Preserve genuinely untracked branch behavior and accurate ahead/behind semantics before landing a fix.
