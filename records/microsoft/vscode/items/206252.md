# Issue #206252 — Stop stealing focus from other applications

[https://github.com/microsoft/vscode/issues/206252](https://github.com/microsoft/vscode/issues/206252)

## Summary

Keep open in the Backlog: this accepted feature request has 22 community upvotes, and current main still lacks a general mechanism preventing a launched window from taking focus after the user switches away.

## Change summary

Prevent VS Code windows and delayed initialization flows from taking focus from another application.

## Best solution

Window startup should remember when the user has moved focus elsewhere and complete initialization without reactivating VS Code, including delayed Remote SSH startup. This likely belongs in the Electron window lifecycle under `src/vs/platform/windows/electron-main/`.
