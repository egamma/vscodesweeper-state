- **current source:** extensions/copilot/src/extension/intents/node/agentIntent.ts counts tool tokens and computes `Math.max(1, Math.floor((baseBudget - toolTokens) * 0.9))`, so tool definitions larger than the context leave a one-token message budget rather than stopping with an actionable error.
- **tool-selection boundary:** extensions/copilot/src/extension/prompt/node/defaultIntentRequestHandler.ts returns all tools without virtual grouping when an endpoint advertises tool search; extensions/copilot/src/extension/tools/common/virtualTools/toolGrouping.ts otherwise trims by tool count, not total definition tokens. Either path can leave tool definitions larger than a smaller model budget.
- **independent confirmation:** A second reporter confirmed the input-too-large failure on 2026-07-22 even after disabling Foundry and Azure MCP components, supporting a shared aggregate tool-budget defect rather than one MCP server's behavior.
