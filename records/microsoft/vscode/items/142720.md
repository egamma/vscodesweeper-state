# Issue #142720 — Custom editor group contributions.configuration

[https://github.com/microsoft/vscode/issues/142720](https://github.com/microsoft/vscode/issues/142720)

## Summary

The requested cross-extension grouping is still missing: current Settings UI categories remain scoped to individual extensions. Keep this accepted Backlog request open; the closest matching report is newer and closed, not a valid duplicate target.

## Change summary

Allow multiple extensions in a company or extension pack to contribute settings beneath one shared Settings UI entry.

## Best solution

Support an explicitly shared Settings UI category across cooperating extensions while preserving each setting's extension ownership. A maintainer should first decide the contribution contract and shared-category ownership rules.
