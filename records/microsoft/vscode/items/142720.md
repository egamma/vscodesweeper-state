# Issue #142720 — Custom editor group contributions.configuration

[https://github.com/microsoft/vscode/issues/142720](https://github.com/microsoft/vscode/issues/142720)

## Summary

Valid feature request: the Settings editor groups settings by individual extension ID, with no mechanism to group multiple extensions from the same pack under a shared parent entry. No existing setting or capability covers this.

## Change summary

Allow extensions in an extension pack to have their settings grouped under a single parent entry in the Settings UI.

## Best solution

Support an optional `settingsCategory` or publisher-level grouping in the Settings editor so extension packs can present a unified settings hierarchy. The logic in `createTocTreeForExtensionSettings` (src/vs/workbench/contrib/preferences/browser/settingsTree.ts) groups by `extensionId` — it could additionally support grouping by a shared identifier declared by the pack or by publisher.
