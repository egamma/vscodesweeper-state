# Issue #330855 — Agents Window: Opening a side-by-side diff creates an unusable five-column layout on narrow screens

[https://github.com/microsoft/vscode/issues/330855](https://github.com/microsoft/vscode/issues/330855)

## Summary

Team-authored bug report with a real release milestone (1.135.0) — both independently bar a close. Traced in source: the Agents Window's diff editor contribution explicitly disables `useInlineViewWhenSpaceIsLimited`, so it never falls back to inline rendering regardless of available width, confirming the reported gap is real and unaddressed on main.

## Change summary

In the Agents Window, opening a diff with `diffEditor.renderSideBySide` enabled on a narrow screen produces five cramped columns instead of adapting layout to available width.

## Best solution

In src/vs/sessions/contrib/editor/browser/diffEditor.sessions.contribution.ts, make the diff editor's side-by-side vs. inline rendering responsive to the actual available editor width in the Agents Window (e.g. re-enable `useInlineViewWhenSpaceIsLimited`-style behavior or collapse an adjacent pane) rather than relying solely on the global `diffEditor.renderSideBySide` setting.
