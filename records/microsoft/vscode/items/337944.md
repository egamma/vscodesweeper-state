# Issue #337944 — `code tunnel prune` broken because of case mismatch

[https://github.com/microsoft/vscode/issues/337944](https://github.com/microsoft/vscode/issues/337944)

## Summary

Confirmed on current main: `code tunnel prune` writes server folders capitalized (e.g. `Stable-<commit>`) but the folder-name parser only accepts lowercase quality strings, so those folders are silently skipped and never pruned.

## Change summary

`code tunnel prune` fails to clean up installed server folders because the folder-name quality parsing is case-sensitive while the folders are written with a capitalized quality.

## Best solution

Make the quality lookup case-insensitive (or lowercase the parsed segment before matching) in `Quality::try_from` in cli/src/options.rs, so `get_all_servers` in cli/src/tunnels/paths.rs recognizes folders it itself created.
