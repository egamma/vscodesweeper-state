# Issue #223545 — Wrong LaTeX highlighting in markdown

[https://github.com/microsoft/vscode/issues/223545](https://github.com/microsoft/vscode/issues/223545)

## Summary

Still reproduces on current main: the `math_inline_block` pattern in the markdown-math grammar only matches `$$` (exactly two dollar signs), so multiline single-dollar math expressions lose highlighting. An open PR (#304800) proposes a fix but has not merged.

## Change summary

Multiline LaTeX math expressions using single `$` delimiters are not syntax-highlighted in markdown files because the grammar only supports `$$` for multiline blocks.

## Best solution

Land the fix in https://github.com/microsoft/vscode/pull/304800 (or an equivalent change) that updates the `math_inline_block` begin/end pattern in `extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json` to accept both `$` and `$$` delimiters with a backreference, as RedCMD's comment suggested.
