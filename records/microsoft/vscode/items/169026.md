# Issue #169026 — Consider less saturated terminal colors for Dark V2

[https://github.com/microsoft/vscode/issues/169026](https://github.com/microsoft/vscode/issues/169026)

## Summary

The requested softer default terminal palette remains absent from Dark Modern. Keep this open for a theme-owner decision: personal color overrides do not fulfill a request to change the bundled theme, and no verified canonical owns the same work.

## Change summary

Use less saturated terminal ANSI colors in Dark V2, closer to its editor palette.

## Best solution

Have the theme owner evaluate a softer Dark Modern terminal palette against editor-color consistency, ANSI color distinguishability, and readability. Any accepted palette change should remain theme-specific rather than altering shared defaults for other themes.
