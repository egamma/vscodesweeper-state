# Issue #169026 — Consider less saturated terminal colors for Dark V2

[https://github.com/microsoft/vscode/issues/169026](https://github.com/microsoft/vscode/issues/169026)

## Summary

This is still an open design request for the built-in Dark Modern terminal palette, not a bug or a close candidate. It has low community traction and no discussion, so the useful cleanup action is to keep it open as under-discussion for the themes/terminal owners rather than closing it for staleness.

## Change summary

Make Dark Modern's default terminal ANSI colors less saturated and closer to the editor palette.

## Best solution

Theme owners should decide whether Dark Modern should define its own terminal ANSI palette in `extensions/theme-defaults/themes/dark_modern.json`; if accepted, the change is a small theme-color update, with users still able to override locally through `workbench.colorCustomizations`.
