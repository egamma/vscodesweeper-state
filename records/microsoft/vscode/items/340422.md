# Issue #340422 — Local chat harness sandbox: Unix sockets are allowed when allowNetwork is true (now by default)

[https://github.com/microsoft/vscode/issues/340422](https://github.com/microsoft/vscode/issues/340422)

## Summary

Keep open for human security review: the reporter repeatedly confirmed that outbound-network permission also permits Docker socket access through the local sandbox, unlike the default Agent Host sandbox. This is a sandbox-boundary concern, which independently prohibits a close proposal; limited local-harness support does not resolve it.

## Change summary

Prevent general outbound-network permission from implicitly authorizing privileged local Unix sockets in sandboxed agent commands.

## Best solution

Have the sandbox owners establish and enforce separate outbound-network and local-IPC permissions across the local terminal sandbox and any Agent Host terminal override using it. Verify the Docker socket case on macOS against the actual runtime, preserving ordinary outbound access without silently granting host-daemon access.
