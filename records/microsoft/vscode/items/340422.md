# Issue #340422 — Local chat harness sandbox: Unix sockets are allowed when allowNetwork is true (now by default)

[https://github.com/microsoft/vscode/issues/340422](https://github.com/microsoft/vscode/issues/340422)

## Summary

Keep open for human security review: the reported permission-boundary problem remains supported by current source. Native Copilot sandboxing blocking Docker access does not resolve the Local/custom-terminal path, which shares a different sandbox configuration.

## Change summary

Prevent general outbound-network permission from implicitly permitting privileged local Unix-socket access through the macOS terminal sandbox.

## Best solution

Preserve filesystem confinement when outbound networking is permitted, with privileged local IPC governed explicitly rather than implicitly enabled. Evaluate the Local terminal and Agent Host custom-terminal paths together, while treating native Copilot sandboxing and its approval behavior separately.
