# Issue #91132 — Cannot drag/drop file from VS Code to other apps due to invalid data object

[https://github.com/microsoft/vscode/issues/91132](https://github.com/microsoft/vscode/issues/91132)

## Summary

Still valid: VS Code's explorer drag to external apps is limited to `text/uri-list` (set via standard web drag API), which many native Windows apps don't accept — they need `CF_HDROP`. No native file drag support has been added on main; the gap remains and likely requires Electron/Chromium-level support.

## Change summary

Dragging files from VS Code Explorer to native apps (Visual Studio, Outlook, Excel) fails because the drag data object doesn't properly provide CF_HDROP/FileDrop format.

## Best solution

Investigate Electron-level support for setting native CF_HDROP on drag operations from web content, or use Electron's `startDrag` API to provide a proper native file drag. The fix likely spans the explorer viewer drag handler (src/vs/workbench/contrib/files/browser/views/explorerViewer.ts) and possibly requires Electron IPC to invoke native drag from the main process. Upstream Electron progress should be tracked.
