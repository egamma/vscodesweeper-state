# Issue #186143 — File quick open should allow to trigger "Go to line"

[https://github.com/microsoft/vscode/issues/186143](https://github.com/microsoft/vscode/issues/186143)

## Summary

Keep open: file-and-line navigation already works on acceptance, but typing ':' still does not enter an interactive preview mode like '@' does. The linked implementation was closed without merging, and a maintainer explicitly supported the preview feature.

## Change summary

Allow ':' in File Quick Open to enter interactive line/column navigation for the selected file, analogous to '@' symbol navigation.

## Best solution

Provide transient line/column preview while File Quick Open remains focused, with cancellation restoring the previous editor state. Preserve existing path/range syntax and symbol navigation; follow the recorded preference for editor preview rather than an additional help-message row.

- **Behavior:**

  > File Quick Open should support interactive line/column navigation for a selected file when the user appends ':', analogous to existing '@' symbol navigation. Changing the location should preview it without accepting the picker or moving focus out of its input. Acceptance should retain the selected location, while explicit cancellation restores the prior editor state. Existing file-and-location opening syntax and symbol navigation must continue to work; the initial behavior on a bare ':' needs an explicit product contract.
- **Trace:**

  > AnythingQuickAccessProvider._getPicks in src/vs/workbench/contrib/search/browser/anythingQuickAccess.ts calls extractRangeFromFilter, records lastRange, and returns null when only the range suffix changes so file results are preserved. createAnythingPick uses lastRange when accepting or opening to the side, but the active-item decoration listener handles only IEditorSymbolAnythingQuickPickItem.
