# Issue #76505 — [json] format on save should remove last trailing comma in JSON with json-language-features

[https://github.com/microsoft/vscode/issues/76505](https://github.com/microsoft/vscode/issues/76505)

## Summary

The built-in JSON formatter intentionally limits itself to whitespace changes and does not repair syntax by adding or removing commas. A maintainer reaffirmed this boundary in 2025 and applied *out-of-scope to the same formatter-repair request.

## Change summary

Make the built-in JSON formatter add missing commas and remove trailing commas while formatting or saving malformed JSON.

## Best solution

Keep the built-in formatter whitespace-only and use an opt-in syntax-repair formatter such as the Prettier configuration already documented in the thread.

## Vision fit

- **Fit:** rejected
- **Reason:** Automatic syntax repair is an optional, behavior-changing formatter capability that can be provided by an extension without expanding the built-in formatter's intentionally narrow contract.
- **Evidence:** Public guardrail: “The power lives in extensions,” while VS Code remains a lightweight text editor out of the box.
