# Issue #207707 — Toggle Word Wrap in multi-file diff editor should enable word wrap in all files

[https://github.com/microsoft/vscode/issues/207707](https://github.com/microsoft/vscode/issues/207707)

## Summary

The reported command still changes only the focused file's diff, not every file in the multi-file diff editor. Keep this team-authored bug open under its existing area label; the related reports do not own the same behavior.

## Change summary

Make View > Toggle Word Wrap apply consistently to all files in the active multi-file diff editor.

## Best solution

Make the standard word-wrap command operate across the active multi-file diff editor, including files materialized later through virtualization, while preserving ordinary single-file and two-pane diff behavior.

## Evidence

- **Exact failing command path:** In src/vs/workbench/contrib/codeEditor/browser/toggleWordWrap.ts, the View menu invokes editor.action.toggleWordWrap. ToggleWordWrapAction.run writes transient state to the focused editor's model and, at most, the other model in its containing DiffEditorWidget. It neither enumerates the multi-file editor's documents nor updates its shared options, so focusing the first file and invoking the command leaves other files unchanged.
- **Propagation stops at one file:** src/vs/editor/browser/widget/diffEditor/commands.ts:286-300 implements findDiffEditorContainingCodeEditor by returning the single diff editor whose original or modified editor matches the focused editor. ToggleWordWrapController reads each model's own transient state; notification of another model's change does not give unrelated files the same override.
- **Existing shared capability is not command coverage:** src/vs/editor/browser/widget/multiDiffEditor/multiDiffEditorWidget.ts exposes setDiffWordWrap and setDiffLayoutOptions. Shared options flow through MultiDiffEditorWidgetImpl._optionsOverride into DiffEditorItemTemplate.setItem in src/vs/editor/browser/widget/multiDiffEditor/diffEditorItemTemplate.ts. These mechanisms can configure multiple files, but the standard View > Toggle Word Wrap action does not call them.
- **Related reports are not canonical duplicates:** Verified open https://github.com/microsoft/vscode/issues/224189 concerns unequal diff-panel layout with wrapping enabled, and mentions this issue separately. Verified open https://github.com/microsoft/vscode/issues/336491 concerns word-wrap menu placement. Both are newer than this re-reviewed issue and describe different observable symptoms.

It does not own propagation across different files in a multi-file diff editor. Open-issue searches for word wrap, multi-diff, and toggle/wrap/diff found no verified canonical covering this report.
