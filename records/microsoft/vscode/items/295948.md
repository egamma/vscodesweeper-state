# Issue #295948 — macOS: Overwriting updates sometimes returns no update after attempting to download the second one

[https://github.com/microsoft/vscode/issues/295948](https://github.com/microsoft/vscode/issues/295948)

## Summary

The overwrite-update flow on macOS can result in an idle state (no update found) when checking for a second update that should exist. Related fixes (fb010060088, c92ecf55694) address adjacent issues but none references this issue or definitively solves this exact race. Keeping open.

## Change summary

On macOS, when a newer update supersedes a downloaded-but-not-installed one, the overwrite check sometimes reports 'no update available' and returns to idle.

## Best solution

Investigate the race in `abstractUpdateService.ts` `checkForOverwriteUpdates` → `doCheckForUpdates` flow on macOS: the Electron autoUpdater's `update-not-available` event fires immediately after the overwrite triggers a new check, possibly due to a stale feed URL or caching. A retry or explicit feed-URL refresh after overwrite may be needed.
