# Issue #318380 — Github-Copilot slow suggestion preferedd over snippet autocomplete

[https://github.com/microsoft/vscode/issues/318380](https://github.com/microsoft/vscode/issues/318380)

## Summary

The broader snippets-with-Copilot issue was fixed via #318735 (closed/verified), but alexdima specifically narrowed this issue to the emmet + `-` trigger behavior under the `offWhenInlineCompletions` default, which has not been separately addressed. A team member intentionally parked it on On Deck as a 1.124 leftover — it should stay open for the emmet area owner.

## Change summary

Emmet abbreviation suggestions (e.g. with `-`) are suppressed or delayed when Copilot inline completions are active under the new `offWhenInlineCompletions` default.

## Best solution

Investigate whether emmet completion triggers (particularly `-`) need special handling under the `offWhenInlineCompletions` quick-suggestions mode so emmet abbreviations appear immediately alongside inline ghost text. The workaround (`editor.quickSuggestions.other: "on"`) is known but the default experience should work correctly for emmet users.
