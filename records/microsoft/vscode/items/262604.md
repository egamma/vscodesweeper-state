# Issue #262604 — Contributed Chat Participants don't work in Web Extensions

[https://github.com/microsoft/vscode/issues/262604](https://github.com/microsoft/vscode/issues/262604)

## Summary

A VS Code team member independently reproduced the failure using the standard web-extension generator and Chat Participant tutorial, so this remains a confirmed core API bug that needs investigation.

## Change summary

Chat participants contributed by web extensions register successfully but never invoke their request handler, leaving Chat indefinitely showing “Working...”.

## Best solution

Make contributed chat participants dispatch requests correctly to the web extension host, or explicitly reject registration with a documented diagnostic if the API cannot support that host; the likely ownership is the chat participant bridge between the workbench and extension host.
