# Issue #311014 — Make `diffEditor.ignoreTrimWhitespace` false by default

[https://github.com/microsoft/vscode/issues/311014](https://github.com/microsoft/vscode/issues/311014)

## Summary

The request to change the whitespace-diff default repeats an explicitly declined proposal with the same Git-parity rationale. Propose closing based on that maintainer decision, not inactivity; the related partial-staging problem remains separately tracked.

## Change summary

Show leading and trailing whitespace changes by default in Git diff editors by defaulting diffEditor.ignoreTrimWhitespace to false.

## Best solution

Retain the configurable default under the established maintainer decision, with diffEditor.ignoreTrimWhitespace set to false for users who want whitespace-inclusive diffs. Keep partial-staging behavior tracked separately at https://github.com/microsoft/vscode/issues/63397.
