# Issue #148093 — Language guessing: Allow paste contents to override `files.defaultLanguage`?

[https://github.com/microsoft/vscode/issues/148093](https://github.com/microsoft/vscode/issues/148093)

## Summary

Keep open: current main still prevents pasted source-language metadata from overriding files.defaultLanguage. The discussion supports revisiting that precedence, but leaves the configuration and scope of the override undecided.

## Change summary

Allow pasting into an otherwise empty untitled editor to select the pasted content's language despite a configured files.defaultLanguage.

## Best solution

Provide an opt-in paste-language override for untitled editors whose language comes only from files.defaultLanguage, while preserving explicit language choices and existing note-taking workflows. Settle whether this covers only known VS Code clipboard language metadata or also inferred languages before implementation.
