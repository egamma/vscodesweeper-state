# Issue #337637 — Agent host: pasted images lose their position in the prompt (no inline marker, all files named 'Pasted Image.png')

[https://github.com/microsoft/vscode/issues/337637](https://github.com/microsoft/vscode/issues/337637)

## Summary

Confirmed from source: neither the Claude nor Codex prompt resolvers insert an inline position marker for pasted images, and the pasted-image variable entries created in the chat widget don't appear to carry a text-position range today, so the model genuinely can't tell which image a prompt sentence refers to. A real, well-diagnosed gap — worth planning, not implementing blind.

## Change summary

Insert a stable inline placeholder (e.g. `[Image 1]`) at each image's paste position in the prompt text, with the references list using the same token, instead of only listing file paths after the text.

## Best solution

Have the chat input widget capture a text-position range for pasted images (the way inline `#file:` mentions already do via `IChatRequestVariableEntry.range` / `_toAttachmentReferenceRange`), then have each provider's prompt resolver (`claudePromptResolver.ts`, and `codexPromptResolver.ts` for consistency) render a `[Image N]` token at that offset and label the matching reference/attachment with the same token.

## Evidence

- **no inline marker on main:** src/vs/platform/agentHost/node/claude/claudePromptResolver.ts builds the prompt as a single unmodified text block plus a separate `<system-reminder>` block of `refLines` (file paths only) — no placeholder is inserted into the prompt text at the paste position, matching the report exactly.
- **protocol has a range field, but appears unused for pastes:** MessageAttachmentBase.range (src/vs/platform/agentHost/common/state/protocol/channels-chat/state.ts:703) is 'the range in Message.text that references this attachment', and agentHostSessionHandler.ts's `_toImageAttachment` accepts a `range` parameter — but that range comes from `IChatRequestVariableEntry.range` via `_toAttachmentReferenceRange`, which is populated for inline text mentions (e.g. `#file:`), not obviously for images attached via clipboard-paste in src/vs/sessions/contrib/chat/browser/newChatContextAttachments.ts.
- **same gap in the Codex path:** src/vs/platform/agentHost/node/codex/codexPromptResolver.ts also just appends image/text attachment chunks after the prompt text — no positional marker there either.
- **correction in issue body:** Reporter's 2026-09-25 correction narrows the ask to the inline-position-marker request only; the 'all files literally named Pasted Image.png' framing was already wrong for multi-image messages.
