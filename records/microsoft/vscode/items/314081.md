# Issue #314081 — Hitting the stop button between terminal prompts doesn't result in the command getting killed

[https://github.com/microsoft/vscode/issues/314081](https://github.com/microsoft/vscode/issues/314081)

## Summary

The prompt-handoff path still leaves the command running when chat is stopped: cancellation tears down notification listeners without interrupting the terminal process. Keep this accepted, team-authored bug open; no fixing commit or qualifying duplicate was identified.

## Change summary

Stopping chat between successive interactive terminal prompts should interrupt the command instead of leaving it waiting for input.

## Best solution

Preserve cancellation ownership of the interactive foreground command across input-needed handoffs in the terminal chat tools, so chat Stop interrupts that command. Preserve the independent lifetime of explicitly backgrounded servers and watchers.
