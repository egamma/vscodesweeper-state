# Issue #349772 — Remote Environment should include the Cloud

[https://github.com/microsoft/vscode/issues/349772](https://github.com/microsoft/vscode/issues/349772)

## Summary

Keep open: the Environment picker exposes Cloud, but Remote Environments does not represent that destination or offer its requested management actions. Existing remote visibility controls do not cover the central ask.

## Change summary

Include Cloud in Remote Environments with New Session and hide/show controls.

## Best solution

Provide a consistent Cloud destination in Remote Environments, with session creation and reversible picker visibility, while keeping it distinct from individual GitHub Environments and their connection controls.
