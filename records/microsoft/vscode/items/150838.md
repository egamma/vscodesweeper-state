# Issue #150838 — Explorer collapses folder when renamed

[https://github.com/microsoft/vscode/issues/150838](https://github.com/microsoft/vscode/issues/150838)

## Summary

The bug remains source-reproducible on current main: renaming changes the expanded folder's tree identity before its parent is refreshed, so the refresh creates a newly collapsed node. Keep this accepted Backlog bug open and preserve the folder's expansion state while still re-sorting it.

## Change summary

Renaming an expanded folder in the Explorer collapses it instead of preserving its expansion state.

## Best solution

Preserve the renamed directory's expanded or collapsed state across the Explorer model rename and parent refresh, while retaining the refresh needed to place it in the correct sort order.
