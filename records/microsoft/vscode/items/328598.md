# Issue #328598 — [Bug] Specific UI color tokens (sideBar.background, statusBar.background, etc.) are ignored when editor.background is set

[https://github.com/microsoft/vscode/issues/328598](https://github.com/microsoft/vscode/issues/328598)

## Summary

Verified duplicate: this is the same Modern UI regression already tracked, triaged, and assigned in the open canonical issue, which fully covers the affected UI parts (activity bar, status bar, title bar) — proposing consolidation there.

## Change summary

With `workbench.experimental.modernUI` enabled, color customizations for sideBar/activityBar/statusBar/titleBar backgrounds are ignored and the editor background bleeds through instead.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/326126, which already identifies the exact cause — the `floating-panels` style override CSS in src/vs/workbench/contrib/styleOverrides/browser/media/ forces `background-color: transparent !important` on `.part.activitybar`, `.part.statusbar`, and `.part.titlebar` — and is assigned to team members for a fix.
