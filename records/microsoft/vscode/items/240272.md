# Issue #240272 — cmd+d gets lost in markdown cells

[https://github.com/microsoft/vscode/issues/240272](https://github.com/microsoft/vscode/issues/240272)

## Summary

The bug remains open on current main. The only related fix (commit aa3933cf88f, PR #251157) addressed infinite looping when all matches are already selected — a different problem. The core issue of cmd+d getting stuck when the next match is in a non-editing markdown cell appears unresolved.

## Change summary

Cmd+D (Add Selection to Next Find Match) in notebooks gets stuck when the next match is in a markdown cell that is not in editing mode.

## Best solution

The notebook multicursor logic in `notebookMulticursor.ts` needs to handle the transition of markdown cells into editing mode before applying selections. The `findAndTrackNextSelection` method at line 591 already calls `focusNotebookCell(cell, 'editor')` for cross-cell matches, but something in the markdown cell lifecycle prevents the match from being tracked properly when the cell hasn't been switched to edit mode yet.
