# Issue #229027 — Cannot read properties of undefined (reading 'isVisible')

[https://github.com/microsoft/vscode/issues/229027](https://github.com/microsoft/vscode/issues/229027)

## Summary

The current notebook editor-pool path still permits selection updates during model-content event delivery, matching the reported reentrant editor stack. This is the oldest, best-supported report and should remain the canonical issue.

## Change summary

Editing a notebook cell whose focused editor is being preserved can trigger an undefined line-projection access while synchronizing selections.

## Best solution

Prevent NotebookCellEditorPool from round-tripping selections through an attached cell editor while its model-content event is being delivered, without losing the preserved cursor state. Add a focused-editor lifecycle regression test covering editing during cell virtualization.
