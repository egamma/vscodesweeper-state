# Issue #264341 — stage/revert changes options missing from menu when editor has lost focus

[https://github.com/microsoft/vscode/issues/264341](https://github.com/microsoft/vscode/issues/264341)

## Summary

The current source still hides the Git title-menu actions when the modified diff editor loses focus. Keep this report open: an older related issue concerns different context-menu behavior and does not meet the same-symptom duplicate bar for this re-reviewed item.

## Change summary

Keep Stage Selected Ranges and Revert Selected Ranges available when reopening the diff editor's title menu without changing the selected lines.

## Best solution

Make the diff editor's title-menu actions reflect the applicable editor and selection rather than transient toolbar focus. Preserve correct original-versus-modified context-menu behavior and investigate the previously reverted scoped-context approach before changing shared diff-editor context semantics.

Original-side context menus, staged-diff actions, and editor-group targeting must retain their correct behavior.
- **Trace:**

  > extensions/git/package.json gates the editor/title entries for git.stageSelectedRanges and git.revertSelectedRanges on isInDiffRightEditor. TextDiffEditor.scopedContextKeyService selects the modified editor's service when the original editor lacks text focus; EditorGroupView.createEditorActions consumes that service, and EditorTabsControl.updateEditorActionsToolbar rebuilds on menu changes.
