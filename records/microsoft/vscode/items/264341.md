# Issue #264341 — stage/revert changes options missing from menu when editor has lost focus

[https://github.com/microsoft/vscode/issues/264341](https://github.com/microsoft/vscode/issues/264341)

## Summary

Still reproduces on main: the `isInDiffRightEditor` context key is set to `false` on editor blur, causing stage/revert/unstage menu items to vanish when the editor title menu button steals focus from the diff editor.

## Change summary

Stage/revert changes options disappear from the editor title menu when the diff editor loses focus (e.g. by clicking the menu button a second time).

## Best solution

The `isInDiffRightEditor` context key in `src/vs/editor/browser/widget/diffEditor/components/diffEditorEditors.ts` is toggled on raw widget focus/blur events — it should either not clear on blur when the menu is the focus target, or the menu `when` clauses in `extensions/git/package.json` should use a stickier context key (e.g. one scoped to the active editor group rather than the inner editor's widget focus). The same pattern applies to `isInDiffLeftEditor`.

The fix should delay or debounce clearing the context key on blur so that a brief focus loss to the menu toolbar does not remove the items. A common pattern is to use a short `setTimeout` on blur and cancel it if focus returns quickly (similar to how other sticky focus keys work in the codebase). Only change the blur handler for these two context keys; do not restructure the diff editor focus system. Validate by verifying that the context key remains true when focus moves to the editor title toolbar and that it still correctly becomes false when focus moves to an entirely different editor or view.
