Keep open: the reported tab shrinkage and unintended scrolling have not been verified against current main. The find input and keyboard handling have evolved since 1.63, but the supplied key sequence and recording suffice for a current Windows retest.

## Change summary

Pressing Page Up or Page Down while the editor find input is focused unexpectedly shrinks the tabs and scrolls the editor.

## Best solution

Retest the recorded sequence on Windows and ensure paging inside the find input cannot unexpectedly scroll surrounding workbench containers or displace the tab strip. Preserve normal editor paging when editor text has focus.
