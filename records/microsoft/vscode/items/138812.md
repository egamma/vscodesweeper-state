# Issue #138812 — Strange things happen when using the keyboard button `Page Up` / `Page Down` in the search box

[https://github.com/microsoft/vscode/issues/138812](https://github.com/microsoft/vscode/issues/138812)

## Summary

The defect remains in the editor find widget on current main: Page Up and Page Down retain their browser defaults, allowing unintended layout scrolling. The existing editor-find routing is appropriate.

## Change summary

Page Up and Page Down in the editor search input resize or scroll the surrounding editor layout.

## Best solution

Handle Page Up and Page Down in the editor find and replace inputs, preventing the browser default and moving the input cursor consistently with the Search panel implementation.
