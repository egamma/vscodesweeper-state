# Issue #349143 — Model routers: allow a custom (BYOK) endpoint as the decision model instead of the fixed gpt-6-luna-decisions

[https://github.com/microsoft/vscode/issues/349143](https://github.com/microsoft/vscode/issues/349143)

## Summary

The requested decision-endpoint extensibility is absent from current main. Keep this as a feature request: existing BYOK route targets do not replace the GitHub-authenticated routing decision call.

## Change summary

Allow model routers to use a user-provided decision model endpoint independently of their destination chat models.

## Best solution

Evaluate a runtime-supported decision-provider contract that can use independently configured endpoints and credentials while preserving routing limits and enterprise controls. Decide the supported configuration surface before adding a setting or YAML field; changing the model ID alone would not satisfy this request.
