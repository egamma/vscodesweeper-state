# Issue #335571 — Copilot response links: add right-click Copy Path for files and folders

[https://github.com/microsoft/vscode/issues/335571](https://github.com/microsoft/vscode/issues/335571)

## Summary

Confirmed gap on main: right-clicking a file/folder link in a Copilot chat response only offers 'Add File to Chat' — there is no Copy Path action, even though the same command exists for the Explorer. Valid, small, well-scoped request; routing to the chat area.

## Change summary

Add a right-click 'Copy Path' command for file/folder links rendered inline in Copilot chat responses.

## Best solution

Register a new action on MenuId.ChatInlineResourceAnchorContext (alongside the existing AddFileToChatAction) in src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatInlineAnchorWidget.ts that copies the resource's filesystem path via ILabelService.getUriLabel + IClipboardService.writeText, mirroring the pattern in src/vs/workbench/contrib/files/browser/fileCommands.ts's copyPathCommandHandler.
