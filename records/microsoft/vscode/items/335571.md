# Issue #335571 — Copilot response links: add right-click Copy Path for files and folders

[https://github.com/microsoft/vscode/issues/335571](https://github.com/microsoft/vscode/issues/335571)

## Summary

Valid, well-scoped feature request: the file/folder resource anchors in chat responses have a right-click menu (MenuId.ChatInlineResourceAnchorContext in chatInlineAnchorWidget.ts) that currently only offers 'Add File to Chat' — no Copy Path action exists there yet, and the reporter correctly distinguishes this from the broader auto-link/copy-paste issue in #280165.

## Change summary

Add a 'Copy Path' context-menu item to file/folder links rendered inside Copilot chat responses.

## Best solution

Register a Copy Path action (reusing the existing COPY_PATH_COMMAND_ID='copyFilePath' handler from src/vs/workbench/contrib/files/browser/fileCommands.ts) on MenuId.ChatInlineResourceAnchorContext in chatInlineAnchorWidget.ts, alongside the existing AddFileToChatAction registration.
