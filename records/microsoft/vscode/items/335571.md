# Issue #335571 — Copilot response links: add right-click Copy Path for files and folders

[https://github.com/microsoft/vscode/issues/335571](https://github.com/microsoft/vscode/issues/335571)

## Summary

Keep open as a feature request: Copy Path already exists for structured chat file references, but ordinary response links use a different menu that offers Copy Link rather than a plain filesystem path. The related copying issue does not own this specific interaction.

## Change summary

Offer right-click Copy Path for file and folder links in Copilot responses while preserving their clickable behavior.

## Best solution

Make filesystem-backed response links consistently offer the existing Copy Path behavior, including ordinary Markdown links in Copilot sessions. Preserve Copy Link for URI copying and leave whole-response copying unchanged.
