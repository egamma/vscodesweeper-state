# Issue #329765 — Ctrl+A + Esc scrolls to bottom of file

[https://github.com/microsoft/vscode/issues/329765](https://github.com/microsoft/vscode/issues/329765)

## Summary

Keep open as an editor interaction improvement: current source explicitly produces the reported jump, and no verified duplicate or fixing commit was found. Preserving the viewport would change existing selection-cancellation behavior rather than repair a demonstrated implementation regression.

## Change summary

Preserve the editor viewport when Escape clears a Select All selection in a file longer than the viewport.

## Best solution

Have the editor owner consider viewport-preserving cancellation after Select All, while defining whether the caret should remain at the selection endpoint or return to its previous position. Preserve ordinary selection-cancellation behavior unless a broader change is explicitly intended.

  > Thanks for the report. Select All currently places the active end of the selection at the end of the file, and Escape clears the selection there and scrolls to reveal the caret.
