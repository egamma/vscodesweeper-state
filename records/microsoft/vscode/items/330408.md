## Summary

Real, multiply-confirmed bug: BYOK (OpenAI/custom endpoint) chat requests fail with an opaque `{"code":0,"message":"","metadata":{}}` error instead of a useful message; a maintainer is already engaged and one commenter supplied the reproduction detail the info-needed label was waiting on.

## Change summary

Using a BYOK (OpenAI or custom-endpoint) model provider fails on every request with an unhelpful, empty-message error instead of a working response.

## Best solution

Trace why the underlying BYOK provider's thrown error reaches the extension with an empty `.message` (likely the actual OpenAI/custom-endpoint fetch failure not being read before the SDK/error object is constructed), and improve `ExtChatEndpoint.makeChatRequest2`'s catch block in src/platform/endpoint/vscode-node/extChatEndpoint.ts so `toErrorMessage(e, true)` surfaces a real diagnostic instead of the JSON stringification of an empty error.
