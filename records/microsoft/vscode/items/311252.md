# Issue #311252 — Cannot type Shift+number symbols (!@#$%^&*()) in Neovim with integrated terminal

[https://github.com/microsoft/vscode/issues/311252](https://github.com/microsoft/vscode/issues/311252)

## Summary

Root cause is xterm.js's Kitty keyboard protocol encoding (bundled dependency), not a VS Code-owned defect; keep open as upstream. My own investigation found the fix is murkier than the prior (refuted) review assumed, so I'm not citing a fix commit.

## Change summary

With Neovim 0.12.1+ enabling the Kitty keyboard protocol (CSI > 3 u) in the integrated terminal, Shift+number keys produce the digit (e.g. '1') instead of the shifted symbol (e.g. '!').

## Best solution

Track resolution in xterm.js (upstream issue https://github.com/xtermjs/xterm.js/issues/5823, still open) and land a VS Code `@xterm/xterm` bump that explicitly references this issue once a maintainer confirms the exact flags=3 (disambiguate+report-event-types) + Shift+digit case is fixed; `terminal.integrated.enableKittyKeyboardProtocol: false` is a known partial workaround in the meantime.
