# Issue #311252 — Cannot type Shift+number symbols (!@#$%^&*()) in Neovim with integrated terminal

[https://github.com/microsoft/vscode/issues/311252](https://github.com/microsoft/vscode/issues/311252)

## Summary

Fixed on main and shipped: the root cause was in xterm.js's Kitty keyboard protocol handling, fixed upstream (xtermjs/xterm.js#5875) and picked up in VS Code via the xterm.js 6.1.0-beta.220 update (commit 103a85ad836), which shipped in 1.123.0.

## Change summary

Shift+number symbols (like !, @, #) produce the wrong character in terminal applications using the Kitty keyboard protocol (e.g. Neovim ≥ 0.12.1).

## Best solution

Keep the shipped xterm.js update; no further VS Code change needed. Users on 1.123.0+ should see the fix. The workaround of disabling `terminal.integrated.enableKittyKeyboardProtocol` is no longer necessary.
