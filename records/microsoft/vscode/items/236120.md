# Issue #236120 — Opening a `devcontainer.json` file in a codespace opens a prompt to install git locally

[https://github.com/microsoft/vscode/issues/236120](https://github.com/microsoft/vscode/issues/236120)

## Summary

Real bug, still open — the git extension (or a related component) tries to discover git locally on macOS when connected to a codespace, triggering the Xcode CLI tools install prompt for users who don't have git installed locally. A maintainer (lszomoru) is actively investigating. No fix found on current main.

## Change summary

Opening a devcontainer.json file in a codespace triggers a macOS prompt to install Xcode command-line tools when git is not installed locally.

## Best solution

The git extension's `findGitDarwin` function (extensions/git/src/git.ts:94) runs `which git` and `xcode-select -p` locally. In a remote/codespace session, either the local git discovery should be skipped entirely, or the `findSpecificGit` path (line 80) should avoid spawning `/usr/bin/git` when Xcode tools are missing. The maintainer is already investigating; the fix likely belongs in the git extension's activation path or in how the local git extension instance is managed during remote sessions.
