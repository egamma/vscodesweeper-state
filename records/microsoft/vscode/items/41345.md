# Issue #41345 — Heterogeneous DPI support on Linux

[https://github.com/microsoft/vscode/issues/41345](https://github.com/microsoft/vscode/issues/41345)

## Summary

Keep this open as the upstream heterogeneous-DPI tracking issue. Native Wayland launch support exists, but reports show mixed-DPI rendering remains incomplete, and the request has 49 community upvotes in the Backlog milestone.

## Change summary

Make VS Code rescale sharply when moved between Linux Wayland displays using different scale factors.

## Best solution

Track the Electron/Chromium per-display scaling behavior here until the runtime handles heterogeneous DPI reliably, then consume and verify that runtime in VS Code. The separate default-to-Wayland request at https://github.com/microsoft/vscode/issues/207033 does not absorb this rendering requirement.
