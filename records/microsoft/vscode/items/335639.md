# Issue #335639 — Microsoft authentication keeps using an expired refresh token after successful sign-in

[https://github.com/microsoft/vscode/issues/335639](https://github.com/microsoft/vscode/issues/335639)

## Summary

Well-documented, credible bug with a detailed regression-test reproduction and a matching open PR — keeping this open pending review/merge of the linked fix rather than closing or auto-fixing.

## Change summary

After a successful Microsoft sign-in, silent token refresh keeps retrying a rejected (family) refresh token instead of the fresh application refresh token, causing repeated auth failures such as Settings Sync showing 'Sign in to Sync Settings' after a real sign-in.

## Best solution

Review and land the linked PR https://github.com/microsoft/vscode/pull/335641, which reportedly fixes the stale-refresh-token persistence gap in extensions/microsoft-authentication; verify with the reporter's added regression suite (tokenCache.test.ts).
