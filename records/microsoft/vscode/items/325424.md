# Issue #325424 — Problem with COM port selection

[https://github.com/microsoft/vscode/issues/325424](https://github.com/microsoft/vscode/issues/325424)

## Summary

The COM port picker and upload workflow are provided entirely by the PlatformIO IDE extension — VS Code core has no serial port or COM port management. This belongs in the PlatformIO tracker.

## Change summary

COM port selection in PlatformIO's toolbar picker does not switch correctly between COM3 and COM4 after unplugging a device.

## Best solution

File the issue at the PlatformIO IDE extension's repository (https://github.com/platformio/platformio-vscode-ide) where the COM port picker, upload command, and device selection logic are implemented.
