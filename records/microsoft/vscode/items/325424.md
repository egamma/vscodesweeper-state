# Issue #325424 — Problem with COM port selection

## Summary

The failing COM-port selection and upload flow is owned by the third-party PlatformIO IDE extension, not VS Code core, so this should be redirected to PlatformIO's tracker.

## Change summary

PlatformIO continues uploading to a disconnected COM4 device after the user selects COM3 through its status-bar port picker.

## Best solution

PlatformIO should update its selected upload-port state when devices are disconnected or another COM port is chosen, and use that current state for subsequent uploads.
