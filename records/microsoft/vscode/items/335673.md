# Issue #335673 — Unable to DnD import multiple automations

[https://github.com/microsoft/vscode/issues/335673](https://github.com/microsoft/vscode/issues/335673)

## Summary

Multiple-file drag-and-drop import remains unsupported: current source explicitly rejects it, and the Import Automation command also accepts only one file. Keep this team-authored Backlog request open; no verified canonical or completed implementation was found.

## Change summary

Allow importing multiple Automation blueprint files in one drag-and-drop operation.

## Best solution

Support multiple-file drops in the Automations view while preserving explicit review, locally selected execution configuration, and disabled-by-default imports. Settle how review and cancellation work across the batch before implementation.
