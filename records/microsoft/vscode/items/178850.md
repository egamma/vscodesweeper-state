# Issue #178850 — Some way to provide an enum of suggested values, but still allow any value

[https://github.com/microsoft/vscode/issues/178850](https://github.com/microsoft/vscode/issues/178850)

## Summary

Still a valid, unimplemented feature request — the settings editor has no support for a hybrid enum+freetext input (combobox-style). The related issue #183601 was closed as a duplicate of this one, confirming this is the canonical tracker.

## Change summary

Allow settings with a JSON schema using anyOf (enum + free string) to render as a combobox with suggested values while still accepting arbitrary text.

## Best solution

Implement a combobox-style widget in the settings editor (settingsTree.ts) that renders enum suggestions as a dropdown but also allows arbitrary string input when a schema uses anyOf with both a plain string type and an enum string type. This is the canonical issue for this work.
