# Issue #316103 — Allow calling Copilot CLI from extension

[https://github.com/microsoft/vscode/issues/316103](https://github.com/microsoft/vscode/issues/316103)

## Summary

Keep open: the inspected extension API does not expose supported reuse of VS Code's bundled Copilot CLI runtime. This team-authored request describes a concrete deployment need for roughly 500 users; the related API issues do not own the same capability.

## Change summary

Allow extensions to invoke VS Code's managed Copilot CLI runtime without bundling it or requiring a separate user installation.

## Best solution

Define a supported extension-facing runtime-reuse contract, with explicit availability and compatibility behavior, rather than requiring extensions to discover private package paths. The owners should first decide whether this means executable access or managed session invocation.
