[https://github.com/microsoft/vscode/issues/233055](https://github.com/microsoft/vscode/issues/233055)

## Summary

Keep this accepted notebook multicursor request open: current source still lacks configurable matching for Ctrl+D. A maintainer explicitly consolidated the older missing-popup report here, and the related notebook Find-command issues do not establish a canonical covering the full request.

## Change summary

Allow notebook Ctrl+D selections to use configurable case-sensitive and whole-word matching through accessible toggles.

## Best solution

Provide discoverable matching controls for notebook multicursor selection and consistently honor their state when adding occurrences. Preserve notebook Find functionality; its filtered select-all path is a partial alternative, not coverage for incremental Ctrl+D selection.
