# Issue #326681 — [Chat] Timestamp in meta labels of chat response

[https://github.com/microsoft/vscode/issues/326681](https://github.com/microsoft/vscode/issues/326681)

## Summary

The defect remains source-reproducible on current main: hovering a same-day response timestamp replaces it with only the elapsed duration. The linked fixing PR was closed without merging, so this accepted Backlog bug should remain open.

## Change summary

Chat response timestamp hover should show the full completion date and time rather than only the response duration.

## Best solution

Make the response timestamp alternate consistently include the full completion date and time while retaining elapsed duration information, with coverage for both same-day and relative timestamps.
