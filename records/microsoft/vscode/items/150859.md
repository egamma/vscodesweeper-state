# Issue #150859 — Consider merging multiple diffs into one

[https://github.com/microsoft/vscode/issues/150859](https://github.com/microsoft/vscode/issues/150859)

## Summary

Keep open under discussion: the default diff algorithm already combines some changes across whitespace-only gaps, but its size thresholds do not guarantee the requested grouping. A maintainer should decide whether smaller neighboring changes should also become one actionable region.

## Change summary

Combine nearby merge-editor differences separated only by empty or whitespace-only lines to reduce fragmented conflict controls.

## Best solution

Establish the desired grouping policy for whitespace-only separators in the shared diff algorithm, then verify that both merge-editor conflict actions and ordinary diff-editor restoration honor it. Preserve separate regions across substantive unchanged code.
