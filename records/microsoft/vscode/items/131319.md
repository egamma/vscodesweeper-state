# Issue #131319 — Automatically hide panel when a file in the explorer is clicked

[https://github.com/microsoft/vscode/issues/131319](https://github.com/microsoft/vscode/issues/131319)

## Summary

This accepted Backlog feature request remains necessary: current main can maximize or manually hide the panel, but cannot automatically hide it when opening an editor. With 89 community upvotes, it should remain open in the layout backlog.

## Change summary

Add an option to hide a maximized panel automatically when opening a file from Explorer or another navigation surface.

## Best solution

Add an opt-in workbench layout setting that hides a maximized panel when navigation opens or reveals an editor, with consistent behavior across Explorer, Quick Open, search results, terminal links, and CLI file opens.
