# Issue #291224 — Make it easy to configure MCP servers at repo level and machine level

[https://github.com/microsoft/vscode/issues/291224](https://github.com/microsoft/vscode/issues/291224)

## Summary

The requested repository/global separation and guided setup are implemented: the Add Server flow now offers Workspace and Global destinations, including destination-aware assisted configuration.

## Change summary

Make repository-provided MCP servers coexist with personal machine-level servers without modifying committed configuration, and expose both scopes through guided UI and agent-assisted setup.

## Best solution

Use the shipped `MCP: Add Server...` flow: select Workspace for repository configuration or Global for personal servers, where Copilot Global is offered when available. The destination-aware assisted flow creates the configuration in the selected scope without requiring users to locate or edit the files manually.
