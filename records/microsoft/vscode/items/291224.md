# Issue #291224 — Make it easy to configure MCP servers at repo level and machine level

[https://github.com/microsoft/vscode/issues/291224](https://github.com/microsoft/vscode/issues/291224)

## Summary

Current VS Code already separates repository and personal MCP configuration through workspace and Global targets, with command-palette and MCP Servers UI entry points.

## Change summary

Make repository defaults coexist with personal MCP servers and provide discoverable UI for machine-level configuration.

## Best solution

Keep repository defaults in the workspace MCP configuration and add personal servers using the Global target; VS Code combines both scopes without modifying the committed file.
