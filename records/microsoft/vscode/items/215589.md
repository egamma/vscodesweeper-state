## Change summary

Go to Definition opens an additional text editor when the same file is already displayed in split text and custom editors.

## Best solution

Definition navigation should select the destination in the appropriate existing text editor without unexpectedly covering the custom editor. First establish the exact invocation, destination URI, and receiving group so the custom-editor and editor-navigation owners can identify the failing path.
