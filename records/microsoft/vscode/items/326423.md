# Issue #326423 — `workspaceContains` glob activation events are silently defeated by default `files.exclude` (`**/.git`, `**/.svn`, `**/.hg`), so extensions cannot activate on descendant SCM metadata

[https://github.com/microsoft/vscode/issues/326423](https://github.com/microsoft/vscode/issues/326423)

## Summary

Confirmed correctness bug on current main, but it must remain open while two referenced fixing PRs are under review.

## Change summary

Glob-based `workspaceContains` activation incorrectly honors default file exclusions, preventing activation on descendant SCM metadata.

## Best solution

Review and land one of the two linked PRs, ensuring glob activation ignores exclusions consistently with exact-path activation, then close the redundant PR.
