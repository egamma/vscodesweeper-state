# Issue #291316 — Chat buttons next to command center steal pointer events from window title

[https://github.com/microsoft/vscode/issues/291316](https://github.com/microsoft/vscode/issues/291316)

## Summary

Still reproducible on main: the center-adjacent-toolbar-container in the titlebar has `-webkit-app-region: no-drag` (line 403 of titlebarpart.css), so chat buttons next to the command center block window drag/resize. No fix has been committed referencing this issue.

## Change summary

Chat buttons next to the command center in the title bar steal pointer events, preventing window drag to resize.

## Best solution

The center-adjacent-toolbar-container needs to allow drag-through for areas not occupied by actual button hit targets — either via `pointer-events: none` on the container with `pointer-events: auto` on child action items, or by tightening the container's width to exactly fit its contents so it doesn't extend into the drag region.
