# Issue #349659 — Windows: Alt+Tab back to VS Code moves keyboard focus from a webview to the menu bar

[https://github.com/microsoft/vscode/issues/349659](https://github.com/microsoft/vscode/issues/349659)

## Summary

Keep open: current main retains the implicated modifier tracking and webview refocusing paths, without a verified fix for this behavior. The supplied fixture and event trace suffice to retest; Windows activation timing remains unverified on current main.

## Change summary

Returning to a focused webview with Alt+Tab transfers keyboard focus to the menu bar and can lose the first typed character.

## Best solution

Preserve the webview's inner focus and first input across Windows activation while keeping standalone Alt menu activation and Quick Pick focus protection intact. Evaluate the overlapping modifier-tracking work separately from the additional webview refocusing failure.
