# Issue #197544 — Merge Editor: Accept Combination When Edits replace same range with same new text

[https://github.com/microsoft/vscode/issues/197544](https://github.com/microsoft/vscode/issues/197544)

## Summary

Keep open: the merge editor still rejects overlapping identical replacements within otherwise different changes, so the requested combination capability remains missing. The completed equal-change issue does not cover this case, and no verified older canonical owns it.

## Change summary

Allow Accept Combination to apply a shared identical replacement once while retaining additional compatible edits from either input.

## Best solution

Extend the merge editor's combination behavior to recognize identical replacements of the same base range within unequal input changes. Preserve existing handling of genuinely conflicting replacements and order-sensitive insertions.
