## Change summary

Dragging the native Open File dialog on Ubuntu Wayland moves the main VS Code window instead of moving the dialog independently.

## Best solution

Preserve native dialog parenting and determine whether GNOME's modal-attachment preference explains the behavior. If independent movement remains broken with attachment disabled, investigate the native dialog integration using the confirmed desktop and display-backend configuration.
