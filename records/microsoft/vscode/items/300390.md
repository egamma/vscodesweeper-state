# Issue #300390 — Inline suggestions violate context exclusion on VS Code start

[https://github.com/microsoft/vscode/issues/300390](https://github.com/microsoft/vscode/issues/300390)

## Summary

Already fixed on main: commit 708647f0d83 addresses the exact race condition described — concurrent isIgnored() calls could cache stale 'not ignored' results when a content exclusion rule fetch was in progress at startup. The fix hasn't shipped in a tagged release yet but is on current main.

## Change summary

Inline suggestions appear briefly in content-excluded files during the first seconds after VS Code starts, before exclusion rules are fully fetched.
