# Issue #327945 — Ability to show the parent git folder name for git worktree sessions

[https://github.com/microsoft/vscode/issues/327945](https://github.com/microsoft/vscode/issues/327945)

## Summary

A real Agents window UX gap remains: sessions can fall back to the worktree directory name, obscuring their parent project. The related multi-root request overlaps but does not fully cover single-repository worktrees or customizable display names.

## Change summary

Show a worktree session's parent repository name alongside its worktree or branch name in the Agents session list.

## Best solution

Preserve the repository root and worktree as distinct display identities in the session workspace model, then render a concise label such as `meshcore-ts / feat-delete-message` in workspace sections and badges. Providers should populate project metadata consistently rather than relying on the working-directory fallback.
