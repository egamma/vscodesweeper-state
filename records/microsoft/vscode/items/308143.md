# Issue #308143 — Why No Hyperlink to Open a workspace on the Welcome page?

[https://github.com/microsoft/vscode/issues/308143](https://github.com/microsoft/vscode/issues/308143)

## Summary

This exact Welcome-page action was previously considered and declined to keep the Start section simple for users unfamiliar with workspace files. The established decision in https://github.com/microsoft/vscode/issues/42812 covers the full request, so this can be closed as out of scope.

## Change summary

Add an explicit hyperlink on the Welcome page for opening an existing `.code-workspace` file.

## Best solution

Keep the focused Welcome-page Start section and use the existing recent-workspaces list or the `workbench.action.openWorkspace` command, shown as “Open Workspace from File...”, for saved workspace files.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding another specialized Start action conflicts with the stated preference for a simple, uniform default UI when the capability already exists elsewhere.
- **Evidence:** Values and guardrails: “Simple, uniform UI and UI interactions” and a lean default experience.
