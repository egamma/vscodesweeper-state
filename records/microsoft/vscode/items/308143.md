# Issue #308143 — Why No Hyperlink to Open a workspace on the Welcome page?

[https://github.com/microsoft/vscode/issues/308143](https://github.com/microsoft/vscode/issues/308143)

## Summary

This is a usage question rather than a bug. The Welcome page already lists recently opened folders and workspaces under 'Recents', which are clickable links. The reporter appears to conflate 'folder' and 'workspace' — in VS Code, opening a folder is the standard workflow; multi-root .code-workspace files are a separate concept.

## Change summary

Reporter wants a hyperlink on the Welcome page to reopen an existing workspace/folder.

## Best solution

Close as a question. The Welcome page's 'Recents' section already lists recently opened folders and workspaces as clickable links. The reporter can also use File > Open Recent, or Ctrl+R to quickly switch. The warning about 'killing an existing workspace' is expected behavior when opening a new folder in the same window — use Ctrl+Click or 'Open in New Window' to avoid it.
