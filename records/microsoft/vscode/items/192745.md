# Issue #192745 — Language specific settings are not language specific anymore when applied to all profiles

[https://github.com/microsoft/vscode/issues/192745](https://github.com/microsoft/vscode/issues/192745)

## Summary

Keep open: current profile sharing still selects settings by key rather than language, although the current parser preserves language override blocks, so the reported promotion to all languages is not confirmed. The supplied JSON suffices to retest against today's configuration and Settings editor paths; neither a concrete fix nor a canonical duplicate was established.

## Change summary

Applying a Python-specific format-on-save setting to all profiles should preserve its language scope without also sharing the non-language-specific setting.

## Best solution

Establish separately whether the JSON configuration and the Settings editor action broaden the setting's scope, then ensure cross-profile sharing preserves the selected language-specific behavior. Keep this focused on language-scoped sharing rather than expanding it into general profile inheritance.
