# Issue #332896 — Claude plugins not loading skills correctly

[https://github.com/microsoft/vscode/issues/332896](https://github.com/microsoft/vscode/issues/332896)

## Summary

Native Claude plugin skills are loaded and invoked entirely by the `@anthropic-ai/claude-agent-sdk` runtime (via `settingSources: ['user','project','local']` passed straight through in claudeSdkOptions.ts) — VS Code's own scan of `.claude` plugins is documented as discovery-only for UI display, filtered post-materialize against the SDK's own `system/init.plugins` snapshot. The malformed-looking skill name and 'not found' behavior both point at the SDK's own plugin/skill resolution rather than VS Code code, but I can't execute the SDK to confirm conclusively from source alone.

## Change summary

Skills bundled in installed Claude (native `.claude`) plugins don't appear in the Agents skills list and fail with 'skill not found' when invoked, showing a malformed slash-command-style name instead.

## Best solution

If this reproduces against a newer `@anthropic-ai/claude-agent-sdk` release, bump the pinned version (currently 0.3.239 in package.json); otherwise file/track upstream with Anthropic, since actual plugin/skill loading for native Claude plugins is delegated to the SDK and not reimplemented in src/vs/platform/agentHost/node/claude.
