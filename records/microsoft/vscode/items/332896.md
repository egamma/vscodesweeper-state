# Issue #332896 — Claude plugins not loading skills correctly

[https://github.com/microsoft/vscode/issues/332896](https://github.com/microsoft/vscode/issues/332896)

## Summary

The issue remains necessary: current main surfaces Claude-native plugin children, but still constructs skill commands from the full `plugin@marketplace` source ID, reproducing the reported invalid `/mattpocock-skills@claude-plugins-official:grill-me` form. The older hooks report and newer model-download report have different observable symptoms, so neither is a valid duplicate canonical.

## Change summary

Claude-native plugin skills are missing from the expected customization surface and receive slash-command names that the Claude runtime cannot resolve.

## Best solution

Keep the stable `plugin@marketplace` source identity for discovery and matching, but expose the Claude SDK plugin name as the user-facing plugin namespace so bundled skills appear under their plugin and completions invoke the runtime-recognized command.
