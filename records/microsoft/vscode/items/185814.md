# Issue #185814 — Adopt `GlyphMarginWidget`s

[https://github.com/microsoft/vscode/issues/185814](https://github.com/microsoft/vscode/issues/185814)

## Summary

Keep open: diff revert buttons use glyph margin widgets, but testing and breakpoint decorations still use model decorations and editor-wide mouse handlers. The remaining adoption work is not completed, and the related issues do not establish a valid duplicate close.

## Change summary

Adopt glyph margin widgets for testing and breakpoint decorations so clicks target the intended decoration while preserving position tracking through edits.

## Best solution

Have the testing and debug owners reassess the remaining migrations against current lane-aware click handling and the requirement to track decorations through edits. Retain this adoption checklist until those requirements are addressed or the owners explicitly decide that migration is unnecessary.
