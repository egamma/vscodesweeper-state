# Issue #280595 — Add item settings UI should offer suggestions

[https://github.com/microsoft/vscode/issues/280595](https://github.com/microsoft/vscode/issues/280595)

## Summary

Still unimplemented on main: the settings editor's array-item add UI only offers suggestions when the setting schema declares a static `enum`; settings like tool names that lack an enum get no suggestions, leaving a real gap compared to JSON editing with IntelliSense.

## Change summary

The 'Add Item' UI in the settings editor should offer suggestions (like tool names) even for array settings that don't define a static enum.

## Best solution

Extend `createArraySuggester` (or the list widget's add-item flow) in `src/vs/workbench/contrib/preferences/browser/settingsTree.ts` to support dynamic suggestion providers — analogous to how the JSON language service provides completions for the same settings in `settings.json`. This would let settings like chat tool lists surface available tool names without requiring a hardcoded enum in the schema.
