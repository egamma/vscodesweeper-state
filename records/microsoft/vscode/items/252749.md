# Issue #252749 — Setting `workbench.panel.opensMaximized` behaves strangely

[https://github.com/microsoft/vscode/issues/252749](https://github.com/microsoft/vscode/issues/252749)

## Summary

The affected panel hide/show path was corrected after this report and shipped in 1.107.0. Current source preserves the pre-hide maximized state and restores it when `workbench.panel.opensMaximized` is `preserve`.

## Change summary

Hiding and reopening a maximized panel with `workbench.panel.opensMaximized` set to `preserve` reopened it at its normal size.

## Best solution

Keep the shipped ordering from commit 98aafb9faa4dc3a59e0b9bedf7900e11a6067e62, which records the maximized state before hiding and restores that state when the panel is shown.
