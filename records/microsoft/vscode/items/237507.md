# Issue #237507 — Several color defaults that "need transparency" are opaque

[https://github.com/microsoft/vscode/issues/237507](https://github.com/microsoft/vscode/issues/237507)

## Summary

Partially fixed: PR #283365 (merged Dec 2025) addressed the minimap color registration defaults, but opaque theme-level overrides in 5 built-in themes and the opaque terminal.findMatchBackground hcLight value remain on current main. An open PR #307251 targets the remaining items. Keeping open for that work to land.

## Change summary

Several color defaults that overlay content are opaque instead of semi-transparent, hiding underlying content in the minimap and terminal.

## Best solution

Land https://github.com/microsoft/vscode/pull/307251 (or an equivalent fix) to add alpha to the remaining opaque theme overrides for `minimap.selectionHighlight` in Abyss, Quiet Light, Red, Solarized Light/Dark, and Tomorrow Night Blue, plus the `terminal.findMatchBackground` hcLight default.
