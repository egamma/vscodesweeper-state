# Issue #219843 — WordOperations test failure on firefox

[https://github.com/microsoft/vscode/issues/219843](https://github.com/microsoft/vscode/issues/219843)

## Summary

Keep open as an upstream Firefox word-segmentation compatibility issue. Current main still skips both Japanese WordOperations tests on Firefox, so the merged PR suppressed the failures without resolving the underlying behavior.

## Change summary

Firefox does not produce the expected Japanese word boundaries for cursor-word navigation tests using `editor.wordSegmenterLocales`.

## Best solution

Determine whether Firefox's `Intl.Segmenter` behavior now satisfies the editor's Japanese word-navigation contract and re-enable the tests when it does; otherwise document or reconcile the intended cross-browser segmentation contract without weakening behavior on supported engines.
