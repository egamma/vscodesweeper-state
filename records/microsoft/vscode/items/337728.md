# Issue #337728 — Modern UI: editor tab icons disappear when the filename is short and tabSizing is set to "fit"

[https://github.com/microsoft/vscode/issues/337728](https://github.com/microsoft/vscode/issues/337728)

## Summary

Reproduced in source: the connected-tab 'narrow' heuristic in multiEditorTabsControl.ts assumes a truncated-name minimum width, but for tabSizing 'fit' the tab renders at its untruncated auto width (per the modern-ui override forcing `width: auto`), so a very short filename's real width can fall below that assumed minimum and the tab is wrongly flagged narrow, hiding the icon.

## Change summary

With Modern UI's connected tab style and tabSizing set to 'fit', the tab icon is hidden for editors with short filenames.

## Best solution

Fix the narrow-tab heuristic in `layoutConnectedTabLabels` (src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts) so it accounts for the actual auto/fit-content width of `sizing-fit` tabs (per the `width: auto !important` override in modernUI/browser/media/tabs.css) instead of comparing against a truncated-name minimum that doesn't apply to that sizing mode.
