## Summary

Valid bug report from a team member: selecting 'New Session' from the command palette while viewing a file full-screen in the Agents Window silently fails. No fix has landed on main referencing this issue. Keeping open for the area owner.

## Change summary

In the Agents Window, choosing 'New Session' from the command palette while viewing a file in full-screen mode closes the palette without opening a new session.

## Best solution

The `openNewSession` + `focusSession` flow in `sessionsActions.ts` (line ~165) likely needs to exit the editor-maximized state (or navigate back to the sessions part) before or after creating the new session, similar to how `setEditorMaximized(false)` is used elsewhere in the layout controller. The fix likely touches `src/vs/sessions/contrib/sessions/browser/sessionsActions.ts` and possibly `src/vs/sessions/browser/workbench.ts`.
