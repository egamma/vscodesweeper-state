# Issue #104966 — Can't input backslash.

[https://github.com/microsoft/vscode/issues/104966](https://github.com/microsoft/vscode/issues/104966)

## Summary

The requested warning in the keybindings editor (when a user defines a keybinding without a modifier that might produce a printable character) is still unimplemented on main. A team member (alexdima) explicitly asked for this feature, making it a valid, actionable request that should stay open.

## Change summary

Add a warning in the keybindings editor when a user defines a keybinding using only a printable-character key without a modifier.

## Best solution

Implement a warning in the keybinding recording widget (src/vs/workbench/contrib/preferences/browser/keybindingWidgets.ts) using IKeybindingService.mightProducePrintableCharacter to detect when the user is about to bind a bare printable key, and surface a visible caution before saving.
