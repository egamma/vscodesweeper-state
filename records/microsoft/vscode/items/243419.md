# Issue #243419 — Git - not obvious for will be commited (staged or changes)

[https://github.com/microsoft/vscode/issues/243419](https://github.com/microsoft/vscode/issues/243419)

## Summary

The primary commit button still does not distinguish staged-only commits when staged and unstaged changes coexist. Keep this accepted Backlog request open while the directly linked implementation PR is reviewed.

## Change summary

Make the Git commit button label and tooltip clearly indicate when only staged changes will be committed.

Review https://github.com/microsoft/vscode/pull/305711 for accurate commit-scope labeling across repository states and Smart Commit settings, then land the accepted implementation before closing this issue.
