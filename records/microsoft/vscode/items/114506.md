# Issue #114506 — Reconsider the whole 60 day upvote process for feature requests

[https://github.com/microsoft/vscode/issues/114506](https://github.com/microsoft/vscode/issues/114506)

## Summary

Keep open as an engineering-process discussion: the documented 60-day voting window remains in place, and the request to better capture accumulated interest has not been resolved by an authoritative maintainer decision.

## Change summary

Reconsider the feature-request voting window and how repeated requests contribute to evidence of long-term demand.

## Best solution

Engineering-process owners should explicitly decide whether to retain or revise the voting window and document how closed requests can accumulate renewed interest without fragmenting feedback. Any policy change should precede changes to triage automation.
