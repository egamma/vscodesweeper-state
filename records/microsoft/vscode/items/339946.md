# Issue #339946 — VoiceOver reads a "?" gremlin character before items in the Agents window branch picker

[https://github.com/microsoft/vscode/issues/339946](https://github.com/microsoft/vscode/issues/339946)

## Summary

Confirmed on main: `icon` and `submenuIndicator` in `ActionItemRenderer.renderTemplate()` (src/vs/platform/actionWidget/browser/actionList.ts) are created without `aria-hidden`, unlike the neighboring `badges`/`additionalBadges` elements which do set `aria-hidden: 'true'` — this lets the decorative codicon glyph leak to VoiceOver as a '?' gremlin. An open PR (#339952) already fixes this, so the issue stays open pending that merge.

## Change summary

VoiceOver reads an unrenderable codicon glyph before each branch-picker item in the Agents window action list.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/339952, which adds `aria-hidden` to the action list's icon and submenu-indicator elements, matching the existing badge treatment; close this issue once merged.
