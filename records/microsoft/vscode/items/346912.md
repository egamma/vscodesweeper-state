# Issue #346912 — Agents window: opening a PR link from Inbox doesn't reveal its session

[https://github.com/microsoft/vscode/issues/346912](https://github.com/microsoft/vscode/issues/346912)

## Summary

The session-context gap remains in current source: Inbox link handlers open the destination without revealing the originating session. Keep this report open; the existing steps identify a bounded navigation defect.

## Change summary

Opening an Inbox item's pull request or reference should reveal its session rather than attach the editor to the previously focused session.

## Best solution

Inbox-originated link navigation should reveal the owning session before opening its destination, while preserving contributed PR openers and existing URI-opening behavior.
