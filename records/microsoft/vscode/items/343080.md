# Issue #343080 — Markdown Preview Render does terrible job showing Copilot changes

[https://github.com/microsoft/vscode/issues/343080](https://github.com/microsoft/vscode/issues/343080)

## Summary

Keep open: rendered Markdown diffs already exist, but the reporter describes missing change indicators when the document was previously open. Preview lifecycle handling has changed since the report; the supplied steps and close/reopen comparison suffice to retest, but no fix for this exact Copilot flow was established.

## Change summary

Copilot change review should show Markdown additions and deletions even when the preview was already open.

## Best solution

Make the existing rendered diff reliably display the current Copilot changes without requiring the user to close the document or switch editor modes. First distinguish stale preview content from the chat review action opening a normal preview instead of a diff.
