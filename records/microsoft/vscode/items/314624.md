# Issue #314624 — Standardize the pull request template

[https://github.com/microsoft/vscode/issues/314624](https://github.com/microsoft/vscode/issues/314624)

## Summary

VS Code already has a PR template (`.github/pull_request_template.md`) that covers the key expectations (associate an issue, describe changes, explain how to test). Expanding it into a rigid multi-section form with checklists is a process decision the maintainers have deliberately kept lightweight — current design is intentional.

## Change summary

Standardize the pull request template with mandatory sections for description, motivation, related issue, testing, and a coding guidelines checklist.

## Best solution

The existing PR template already covers the essentials (link an issue, describe changes, explain testing). The team intentionally keeps it lightweight — a heavier mandatory-sections template would add friction for the hundreds of community and team PRs without proportional review benefit. Close as *as-designed.
