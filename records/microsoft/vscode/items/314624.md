# Issue #314624 — Standardize the pull request template

[https://github.com/microsoft/vscode/issues/314624](https://github.com/microsoft/vscode/issues/314624)

## Summary

VS Code already has a pull request template, but it does not provide the mandatory sections requested here. Keep this open for a maintainer decision on that remaining policy change; a closely related request was declined, but its explanation only establishes that a template already exists.

## Change summary

Replace the existing free-form PR guidance with a standardized description, motivation, related-issue, testing, and coding-guidelines structure.

## Best solution

Have maintainers explicitly decide whether fixed PR-description sections are desirable. If accepted, evolve the existing .github/pull_request_template.md rather than add a second template, and distinguish suggested structure from actual enforcement.
