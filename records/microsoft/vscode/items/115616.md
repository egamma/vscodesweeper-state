# Issue #115616 — Provide extension API to exclude ports from forwarding

[https://github.com/microsoft/vscode/issues/115616](https://github.com/microsoft/vscode/issues/115616)

## Summary

The port attributes API still lives in `vscode.proposed.portsAttributes.d.ts` — it has not been finalized to stable. The API is mature and has real consumers (JS Debug, Jupyter), but the finalization work tracked by this issue remains incomplete.

## Change summary

Provide and finalize extension API (`registerPortAttributesProvider`) so extensions can exclude or configure auto-forwarded ports.

## Best solution

Finalize the proposed `portsAttributes` API to stable in `vscode.d.ts`. The API shape is settled (last updated August 2023, PR #189976), and at least two extensions (JS Debug, Jupyter) already consume it. The remaining work is a final API review pass and the move from proposed to stable.
