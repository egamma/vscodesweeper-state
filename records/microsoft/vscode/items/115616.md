# Issue #115616 — Provide extension API to exclude ports from forwarding

[https://github.com/microsoft/vscode/issues/115616](https://github.com/microsoft/vscode/issues/115616)

## Summary

Keep open for API finalization: extensions can already exclude ports through the proposed portsAttributes API, but the API remains gated and absent from the stable declarations. The discussion explicitly shifted this issue from initial implementation to stabilization, which remains unfinished.

## Change summary

Provide an extension API for excluding internal communication ports from automatic forwarding.

## Best solution

Have the API owners complete the adoption and contract review for workspace.registerPortAttributesProvider, then decide whether to finalize it in the stable API. Preserve extension-provided exclusions and the documented precedence of user-configured port attributes.
