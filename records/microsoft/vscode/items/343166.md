# Issue #343166 — Extension details page does not identify whether Uninstall targets the local or remote installation

[https://github.com/microsoft/vscode/issues/343166](https://github.com/microsoft/vscode/issues/343166)

## Summary

The fresh-page path still replaces the clicked installation with the primary installation, while Uninstall does not name its server. Keep this open for reconsideration: the earlier maintainer agreement supports preserving the clicked target, and neither neighboring report covers the complete problem.

## Change summary

Preserve the local or remote installation selected when opening extension details and make the uninstall target clear before invocation.

## Best solution

Make a newly opened details page manage the installation the user selected and communicate the actual uninstall scope without changing backend removal semantics. Revisit the earlier wont-fix disposition before committing to the scope-labeling UI; an uninstall-all-locations option is not necessary to resolve the reported ambiguity.
