# Issue #150186 — Table: Support horizontal scrolling

[https://github.com/microsoft/vscode/issues/150186](https://github.com/microsoft/vscode/issues/150186)

## Summary

A real table-widget capability gap remains on main. This team-authored Backlog request has neither an explicitly linked implementation nor a verified open duplicate, so it must remain open.

## Change summary

Support synchronized horizontal scrolling of table headers and rows when columns exceed the available width.

## Best solution

Extend the base Table widget to retain column minimum widths beyond the viewport and horizontally scroll its header and body together, benefiting Problems, keybindings, disassembly, and other WorkbenchTable consumers.
