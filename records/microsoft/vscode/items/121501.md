# Issue #121501 — Views should use full name

[https://github.com/microsoft/vscode/issues/121501](https://github.com/microsoft/vscode/issues/121501)

## Summary

The bug remains on current main: an independently moved view's Activity Bar action is named only from its contextual/container title, so the required view name is absent from its hover and context-menu label.

## Change summary

Use a moved view's full display name rather than only its original container name in Activity Bar labels.

## Best solution

When a single view is moved into its own container, its Activity Bar-facing label should include both the contextual container title and the view name, consistent with the existing merged view-pane title behavior, while preserving labels for normal and multi-view containers.
