# Issue #140136 — Support Variable Substitution for Keyboard Binding Command Arguments

[https://github.com/microsoft/vscode/issues/140136](https://github.com/microsoft/vscode/issues/140136)

## Summary

Keep open in the Backlog: the generic substitution capability remains absent on main, and this canonical request has 47 community upvotes.

## Change summary

Resolve supported VS Code variables recursively within command arguments supplied by user keybindings.

## Best solution

Add centralized variable resolution to the workbench keybinding dispatch path before invoking commands, while preserving argument types and defining how interactive variables behave. This should replace command-specific substitution implementations.
