# Issue #265004 — Add a warning message in output window if mcp.json is not well formed.

[https://github.com/microsoft/vscode/issues/265004](https://github.com/microsoft/vscode/issues/265004)

## Summary

This accepted, team-authored Backlog request remains necessary: current main reports JSON syntax diagnostics but does not warn in MCP output that a connection may use configuration retained from before the malformed edit. The team-authored and Backlog protections also rule out a judgment close.

## Change summary

Warn in MCP output when malformed mcp.json content causes a server connection to use previously loaded configuration.

## Best solution

When an MCP server is started while its originating configuration has parse errors, its output should clearly identify the malformed file and state whether the active connection is using previously loaded configuration. Existing editor diagnostics and valid-configuration behavior should remain unchanged.

Existing JSON diagnostics remain visible, valid configuration changes continue to reload normally, and valid starts emit no warning.
- **Trace:**

ConfigurationModelParser in src/vs/platform/configuration/common/configurationModels.ts owns parse errors, while InstalledMcpServersDiscovery in src/vs/workbench/contrib/mcp/common/discovery/installedMcpServersDiscovery.ts receives enabled server values without parse-error provenance.
