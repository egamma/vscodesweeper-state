# Issue #343143 — add context window size and tokens used agents for codex

[https://github.com/microsoft/vscode/issues/343143](https://github.com/microsoft/vscode/issues/343143)

## Summary

The existing chat-input context indicator already provides this capability for Codex-backed agent sessions: it shows the percentage used, with used tokens and total context size available on hover or click.

## Change summary

Show context-window capacity and consumed tokens in the chat composer when using Codex agents.

## Best solution

Use the shared context-usage indicator controlled by chat.contextUsage.enabled rather than introduce a separate Codex-specific display. If the indicator is missing for a particular Codex session, investigate that as a provider/model-specific failure with the affected version and model identified.

## Vision fit

- **Fit:** aligned
- **Reason:** A shared context-usage display supports understandable agent workflows while preserving consistent UI across providers.
- **Evidence:** Public values: "Simple, uniform UI and UI interactions"; durable theme: AI-assisted development.
