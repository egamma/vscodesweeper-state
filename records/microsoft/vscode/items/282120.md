# Issue #282120 — Hide `Apply Changes to Workspace` button if there are no changes

[https://github.com/microsoft/vscode/issues/282120](https://github.com/microsoft/vscode/issues/282120)

## Summary

Keep open: the current multi-diff toolbar can still offer Apply Changes to Workspace when the editor displays No Changed Files. No issue-referencing fix or eligible older canonical was established for this team-authored report.

## Change summary

Hide Apply Changes to Workspace in an agent-session diff editor when there are no changed files.

## Best solution

Make the apply affordance reflect the resolved changes in the session diff editor, including transitions to an empty result, while preserving apply behavior for nonempty worktree changes. Keep session-stat alignment and workspace-mode apply availability as related but separate concerns.
