# Issue #135622 — Enable to comment out an entire block by simply placing the cursor on the first line of the block

[https://github.com/microsoft/vscode/issues/135622](https://github.com/microsoft/vscode/issues/135622)

## Summary

A real editor-comments gap remains on current main, and the request earned 22 upvotes and promotion to the Backlog. The related implementation PR closed without merging, while the older cursor-based uncomment request does not fully cover identifying and commenting an uncommented syntactic block.

## Change summary

Allow Toggle Block Comment to comment an entire code block from a cursor on its first line without requiring a selection.

## Best solution

Design a syntax-aware editor comment action that resolves the enclosing bracket or language block and toggles a block comment without a selection, while preserving the existing empty-selection behavior where appropriate. The implementation likely belongs in the editor comment contribution and should use editor bracket/language services rather than textual brace matching.
