# Issue #285075 — Skills are not working with gpt-* models

[https://github.com/microsoft/vscode/issues/285075](https://github.com/microsoft/vscode/issues/285075)

## Summary

The sample combines two intentional behaviors rather than demonstrating a GPT-specific skills defect: skills are unavailable when the agent omits the read tool, and standard-mode handoffs require user selection. Automatic selection of a `send: true` handoff is reserved for Autopilot.

## Change summary

Make custom-agent skills and multi-agent handoffs automatically continue across every model without user interaction.

## Best solution

Keep standard-mode handoffs user-triggered and use Autopilot with a non-empty `send: true` handoff when automatic continuation is desired; agents that need skills must expose the read tool.
