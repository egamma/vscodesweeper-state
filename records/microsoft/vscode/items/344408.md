# Issue #344408 — mcp.config.list Failed to read configuration from broken path

[https://github.com/microsoft/vscode/issues/344408](https://github.com/microsoft/vscode/issues/344408)

## Summary

Keep open: multiple users confirmed that an incorrect MCP configuration envelope blocks Copilot, and the reopened discussion includes a later writer-lock workaround. Current source still propagates configuration-read failures into sends; neither workaround establishes a complete fix.

## Change summary

Prevent MCP configuration setup or migration from leaving Copilot unable to send messages because its shared configuration is invalid or unreadable.

## Best solution

Diagnose which setup or migration path produces the incompatible configuration, then ensure it writes the destination-specific schema and provides actionable recovery without discarding existing servers. Investigate the later writer-lock report separately before assuming it shares the schema failure's root cause.
