# Issue #282783 — Terminal tool: Detect paths in command lines for common tools

[https://github.com/microsoft/vscode/issues/282783](https://github.com/microsoft/vscode/issues/282783)

## Summary

Keep open: current command analysis covers redirection and sed in-place writes, but not the requested general detection of file arguments for cat, grep, and similar tools. The originating discussion explicitly preserves this request, and its content-exclusion implications require human review rather than a cleanup close.

## Change summary

Extend terminal-tool path detection to common tools' file arguments and recognizable path-like arguments.

## Best solution

Provide best-effort file-argument detection in the terminal command-analysis path, with clearly defined read/write semantics and conservative handling of ambiguous arguments. Keep this distinct from sandbox enforcement: detecting common paths must not imply comprehensive filesystem isolation.
