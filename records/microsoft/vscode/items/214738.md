# Issue #214738 — Deleting itself

[https://github.com/microsoft/vscode/issues/214738](https://github.com/microsoft/vscode/issues/214738)

## Summary

Keep open in install-update: multiple reports confirm the macOS application disappearing during an update or subsequent shutdown. The installation-path question and missing updater logs remain unresolved; neither a fix nor an equivalent older canonical was verified.

## Change summary

Updating and restarting VS Code on macOS can remove the installed application without leaving a usable replacement.

## Best solution

Ensure macOS updates leave a usable application at the installation location, including when replacement fails. First establish the exact installation path and capture update-service and native updater diagnostics to distinguish installation problems from a failed application replacement.
