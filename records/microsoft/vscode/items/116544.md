# Issue #116544 — Active/Inactive tab have no different opacity (git decoration)

[https://github.com/microsoft/vscode/issues/116544](https://github.com/microsoft/vscode/issues/116544)

## Summary

The requested active/inactive distinction remains absent for decorated tab labels on current main. This accepted Backlog request should remain open as the canonical issue.

## Change summary

Preserve a visible foreground distinction between active and inactive editor tabs when file-decoration colors are applied.

## Best solution

Adjust decorated tab-label styling in the editor tab surface so decoration colors retain an active/inactive distinction, while preserving existing decoration semantics and theme colors.
