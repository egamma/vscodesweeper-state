# Issue #141801 — Untitled custom editor in web version

[https://github.com/microsoft/vscode/issues/141801](https://github.com/microsoft/vscode/issues/141801)

## Summary

The issue reports that untitled custom editors in the web version require the authority to be set correctly on the untitled URI for save to work, and that custom editors lack a way to provide a preferred save path. The `help wanted` label and Backlog milestone suggest this is acknowledged but unresolved; no commit referencing this issue exists, and the core ask (authority handling + preferred save path API for custom editors) appears unaddressed on main.

## Change summary

Untitled custom editors in the web version (github.dev) fail to save because the authority on the untitled URI isn't properly set, and custom editors lack an API to specify a preferred save path.

## Best solution

Either document that extensions must set the authority on untitled URIs for web custom editors, or fix the save code path to derive the correct authority automatically (as text editors do). Ideally, expose an API for custom editors to provide a suggested save path, achieving parity with text documents. Work lives in `src/vs/workbench/contrib/customEditor/browser/customEditorInput.ts` and the web file-dialog save flow.
