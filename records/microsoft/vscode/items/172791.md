# Issue #172791 — Uncaught Error: Illegal value for lineNumber

[https://github.com/microsoft/vscode/issues/172791](https://github.com/microsoft/vscode/issues/172791)

## Summary

Verified duplicate: this reports the exact same crash path as the open issue https://github.com/microsoft/vscode/issues/318008, which has an associated fix commit (not yet merged) that adds a lineNumber bounds guard in both contentHoverComputer and markdownHoverParticipant. The bug is still present on current main — the fix should land via #318008.

## Change summary

Hover operation crashes with 'Illegal value for lineNumber' when the debounced hover fires after lines have been deleted, leaving a stale anchor lineNumber that exceeds the model's line count.

## Best solution

Land the fix from https://github.com/microsoft/vscode/issues/318008 (commit cc1f5b21370, not yet merged) which adds a lineNumber bounds check before calling getLineMaxColumn in both contentHoverComputer.computeSync and markdownHoverParticipant.computeSync. Consolidate discussion on #318008.
