# Issue #172791 — Uncaught Error: Illegal value for lineNumber

[https://github.com/microsoft/vscode/issues/172791](https://github.com/microsoft/vscode/issues/172791)

## Summary

Still reproduces on main: the hover computeSync path in markdownHoverParticipant.ts calls model.getLineMaxColumn(lineNumber) without validating that lineNumber is within bounds — a stale anchor after model edits (e.g. line deletions) triggers the throw. Team-authored error-telemetry issue; keeping open.

## Change summary

Hovering after rapid model edits (line deletions) can throw 'Illegal value for lineNumber' because the debounced hover anchor's lineNumber exceeds the model's line count.

## Best solution

Add a lineNumber-bounds guard in contentHoverComputer.computeSync (before calling participants) and a redundant guard in markdownHoverParticipant.computeSync (before getLineMaxColumn), mirroring the existing guard in _getLineDecorations at contentHoverComputer.ts:37. Return early with an empty array when the anchor's lineNumber exceeds model.getLineCount().
