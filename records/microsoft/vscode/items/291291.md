# Issue #291291 — Clear links aren't getting linkified in agent response

[https://github.com/microsoft/vscode/issues/291291](https://github.com/microsoft/vscode/issues/291291)

## Summary

Still reproduces on main: the file path linkifier in the Copilot extension does not handle `:line` or `:line:column` suffixes (e.g. `file.ts:61`), and bold-wrapped paths (`**file.ts:61**`) are excluded by the regex that filters out `*`. A fix for the line-suffix case exists on a feature branch (commit 2660caf8232) but has not landed on main.

## Change summary

File references with line numbers (e.g. `terminalProfileResolverService.ts:61`) in agent chat responses are not turned into clickable links.

## Best solution

Land the line-suffix linkification fix (based on work in commit 2660caf8232 on the copilot branch) into main, and extend the `pathMatchRe` regex in `filePathLinkifier.ts` to handle bold-wrapped paths (`**file.ts**`). The `modelFilePathLinkifier.ts` already handles `#L` anchors in markdown link syntax — the gap is in the plain-text and inline-code path matchers.
