# Issue #284322 — Current line box thingy doesn't extend fully when switching between tabs

[https://github.com/microsoft/vscode/issues/284322](https://github.com/microsoft/vscode/issues/284322)

## Summary

Valid visual bug — the current line highlight width is computed from `Math.max(ctx.scrollWidth, this._contentWidth)` in `currentLineHighlight.ts`, and when switching tabs the scrollWidth from the rendering context can be stale (reflecting the previous tab's content), causing a too-narrow highlight. No fix has landed on main; the code path is unchanged.

## Change summary

The current line highlight box doesn't extend to the full editor width when switching between tabs with overflowing text; it fixes itself on cursor movement.

## Best solution

Fix the stale `scrollWidth` in the current line highlight render path so that the overlay picks up the correct scroll dimensions when a tab becomes visible. The likely fix is in `src/vs/editor/browser/viewParts/currentLineHighlight/currentLineHighlight.ts` line 211, ensuring a re-render with up-to-date scrollWidth on tab switch, or ensuring the view properly invalidates overlay dimensions on visibility change.
