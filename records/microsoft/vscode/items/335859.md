## Summary

Fresh team-authored bug report (found while testing #335590) about the customization-directory picker in the AI Customization migration dashboard giving no confirmation feedback after a non-default location is chosen. No fix or duplicate exists yet, so this stays open for a maintainer/assignee to pick up.

## Change summary

When a user picks a non-default 'User Skills' customization directory (e.g. .agents) via the migration dashboard's 'Change destinations for your Profile' flow, the UI gives no visible confirmation of the choice, and the follow-up location quick pick re-defaults to .copilot instead of reflecting the prior selection.

## Best solution

In src/vs/workbench/contrib/chat/browser/aiCustomization/customizationMigrationDashboard.ts, surface the chosen destination back in the dashboard UI after selection and pre-select the previously chosen folder when the location quick pick is reopened, rather than defaulting to .copilot.
