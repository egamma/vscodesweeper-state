# Issue #334157 — Cached skill not updated

[https://github.com/microsoft/vscode/issues/334157](https://github.com/microsoft/vscode/issues/334157)

## Summary

Keep open: current source still derives a plugin's cache revision solely from its root directory modification time, so editing a nested skill can leave new sessions using the persisted old copy. The older plugin-update reports examined do not establish the same local-edit failure, and this team-authored issue has no verified factual closing basis.

## Change summary

Edits to a skill in a locally configured plugin folder are not reflected in subsequent Copilot sessions, even after restarting the Agents window.

## Best solution

Make plugin synchronization recognize nested skill and resource changes so a newly started session receives the current local contents, while preserving cache reuse for unchanged plugins and revision isolation for existing sessions.
