[https://github.com/microsoft/vscode/issues/179633](https://github.com/microsoft/vscode/issues/179633)

## Summary

Still valid: the dev-vs-retail branching for activation error reporting remains unchanged on current main (lines 102–108 of mainThreadExtensionService.ts). Team discussion concluded with waiting for a new extension UI, which hasn't landed yet. Keep open as a team-authored feature request under discussion.

## Change summary

Show a UI notification when an extension fails to activate in retail mode, instead of only logging to the Developer Tools console.

## Best solution

Unify the activation-error reporting path in `src/vs/workbench/api/browser/mainThreadExtensionService.ts` so that retail mode surfaces the error in the Extensions view (or a notification) rather than silently logging to console. The team discussion (alexdima, isidorn) leaned toward making the error more prominent in the Extensions view rather than using a notification, to avoid drowning users in error popups. This could also tie into any future 'extension notification center' surface.
