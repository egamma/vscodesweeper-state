Keep open: independent commenters confirm the Windows multi-window blocker, and current source still contains the reported startup failure path. No verified older open canonical or concrete fixing commit establishes that this report can be closed.

## Change summary

Opening a second VS Code window on Windows fails with an administrator-instance warning.

## Best solution

Establish whether both launches have the same elevation and capture the failing main-process IPC connection. Same-elevation launches should support multiple windows; mixed-elevation launches need to be distinguished from that defect before choosing a product change.
