# Issue #340676 — ctrl+shift+click to open localhost terminal links in an external browser

[https://github.com/microsoft/vscode/issues/340676](https://github.com/microsoft/vscode/issues/340676)

## Summary

Thanks for the suggestion. The `workbench.browser.openLocalhostLinks` setting only turns the Integrated Browser on or off for localhost links globally. There is no per-click modifier to force the external browser, so the request is not covered today. Keeping it open for the community process.

## Change summary

Use Ctrl+Shift+click on a terminal localhost link to open it in the external browser instead of the Integrated Browser.

## Best solution

Let a modifier on the terminal link activation bypass the contributed localhost opener, so the link opens externally for that click only. The link opener in terminalLinkOpeners.ts would pass this through, and LocalhostLinkOpenerContribution would honor it. Which modifier to use depends on keybinding conflicts in the terminal.
