# Issue #6651 — Implement an overflow design for status bar entries

[https://github.com/microsoft/vscode/issues/6651](https://github.com/microsoft/vscode/issues/6651)

## Summary

This remains the canonical request for a responsive status-bar overflow design. Current main still clips excess entries, while manually hiding entries is only a workaround.

## Change summary

Provide an overflow affordance that keeps status-bar entries accessible when they do not fit.

## Best solution

Design an accessible overflow menu or equivalent responsive behavior in the status-bar part, preserving entry priority, commands, and keyboard navigation without increasing the bar's height.
