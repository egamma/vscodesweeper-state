# Issue #6651 — Implement an overflow design for status bar entries

[https://github.com/microsoft/vscode/issues/6651](https://github.com/microsoft/vscode/issues/6651)

## Summary

Keep open: current status bar layout still clips overflow without a built-in way to access the clipped entries. A maintainer explicitly reopened this request in September 2024 following another narrow-viewport report; the remaining work needs a UX decision.

## Change summary

Provide an accessible overflow mechanism for status bar entries that do not fit within the window.

## Best solution

Agree on a consistent status bar overflow interaction that keeps displaced entries and their actions accessible by mouse and keyboard, including at high zoom. Preserve deliberate item visibility choices and existing ordering rather than treating manual hiding or custom CSS as the solution.
