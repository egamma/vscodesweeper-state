# Issue #225628 — New lines after code blocks aren't showing as whitespace in test assertion decoration

[https://github.com/microsoft/vscode/issues/225628](https://github.com/microsoft/vscode/issues/225628)

## Summary

Still reproduces on main: the plaintext markdown renderer's `code` block handler omits a trailing newline, so text after code blocks loses its whitespace separation in test assertion decorations.

## Change summary

New lines after markdown code blocks are swallowed when rendering test assertion messages as plaintext, causing content to run together.

## Best solution

Add a trailing `'\n'` to the `renderer.code` return in `createPlainTextRenderer()` in `src/vs/base/browser/markdownRenderer.ts`, consistent with the other block-level renderers (blockquote, heading, paragraph, list). Verify with a unit test in `src/vs/base/test/browser/markdownRenderer.test.ts`.
