# Issue #263110 — Git - Users can't easily modify staged files

[https://github.com/microsoft/vscode/issues/263110](https://github.com/microsoft/vscode/issues/263110)

## Summary

Keep open: staged diff editing remains unavailable, and an open PR explicitly targets this request. Review that implementation before considering completion; the existing Open File action is a workaround, not editing within the staged diff.

## Change summary

Allow users to modify a staged file directly from its staged-changes diff editor.

## Best solution

Review https://github.com/microsoft/vscode/pull/323308, particularly whether saving should modify the Git index or the working-tree file, while preserving the distinction between staged and unstaged changes. Keep the issue open until the accepted behavior is implemented.
