## Evidence

- **Confirmed percentage defect:** src/vs/workbench/contrib/testing/browser/testCoverageView.ts:273–280 implements TestCoverageTree's accessibilityProvider. Its file label uses "{0} coverage: {0}%" with the filename as argument zero and the calculated percentage as argument one, so the accessible label repeats the filename instead of presenting the percentage.
- **Declaration coverage omitted:** In src/vs/workbench/contrib/testing/browser/testCoverageView.ts, DeclarationCoverageNode.label returns only this.data.name. The accessibility provider returns element.label for declaration nodes, omitting their available hit count and attributable coverage.
- **Existing capabilities provide partial coverage:** src/vs/workbench/contrib/testing/browser/codeCoverageDecorations.ts registers testing.coverage.goToNextMissedLine and testing.coverage.goToPreviousMissedLine. navigateToMissedLine moves the cursor to uncovered ranges and wraps around; coverage descriptions are also attached as decoration hoverMessage values. These mechanisms help navigation but do not correct the explorer's accessible labels or prove that coverage status is announced during NVDA reading.
