# Issue #73904 — Have `createQuickPick` no longer sort by label

[https://github.com/microsoft/vscode/issues/73904](https://github.com/microsoft/vscode/issues/73904)

## Summary

Keep open: createQuickPick still enables label-based sorting by default, and disabling it remains a proposed API rather than a stable extension capability. The api-proposal label independently bars closure; implementation of the proposed flag does not complete this tracking issue.

## Change summary

Preserve extension-provided QuickPick item ordering while filtering, without requiring a proposed API or sacrificing match highlighting.

## Best solution

API owners should settle and publish a stable ordering contract for createQuickPick, addressing the compatibility concerns around changing its default. Preserve filtering and highlighting independently of ordering; custom filtering and active-item behavior remain separate requests.
