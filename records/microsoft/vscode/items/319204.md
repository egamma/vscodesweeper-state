# Issue #319204 — [Feature Request] `LanguageModelChatProvider`: allow providers to grey out excluded message turns in the chat UI

[https://github.com/microsoft/vscode/issues/319204](https://github.com/microsoft/vscode/issues/319204)

## Summary

Keep open for API discussion: current provider response types do not expose a signal for marking retained conversation content as excluded from model context. No verified canonical covers this request; limited community traction is not grounds for a decline close.

## Change summary

Allow language model providers to identify excluded conversation content so VS Code can visibly distinguish it in chat history without deleting it.

## Best solution

Evaluate a typed provider-to-chat exclusion contract with reliable message-to-history correlation and an accessible indication of exclusion and its reason. Settle the API scope and lifecycle semantics before committing to the proposed index-range response part.
