## Summary

Legitimate feature request for a new LanguageModelChatProvider API surface — a compaction/exclusion signal so providers can tell VS Code which turns were dropped from context, rendered as greyed-out in the chat UI. Nothing like this exists on main. Low traction (1 upvote, no comments), needs routing to the API and chat area owners for a product decision.
