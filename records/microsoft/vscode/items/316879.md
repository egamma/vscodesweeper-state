# Issue #316879 — Regression in 0.48.1: TypeError "Cannot read properties of undefined (reading 'bind')" in agent mode on Remote-SSH

[https://github.com/microsoft/vscode/issues/316879](https://github.com/microsoft/vscode/issues/316879)

## Summary

Keep this canonical report open and route it to extension management and Chat: multiple users reproduced the failure when Copilot Chat 0.48.1 was installed with an incompatible VS Code version, but the path that allowed that remote update remains unexplained. Updating VS Code avoids the crash, but no fixing commit establishes that incompatible extension installation can no longer recur.

## Change summary

Prevent an incompatible built-in Copilot Chat version from being installed or auto-updated locally or on a Remote-SSH extension host.

## Best solution

Extension management should consistently select a Copilot Chat build compatible with the connected VS Code product version, including remote installation and update paths. Add a regression test representing VS Code 1.117 with gallery version 0.48.1 available and verify that the compatible 0.45.1 build is retained or selected.
