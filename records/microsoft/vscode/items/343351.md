# Issue #343351 — Agents: "Open in Agents Window" is too easy to activate accidentally

[https://github.com/microsoft/vscode/issues/343351](https://github.com/microsoft/vscode/issues/343351)

## Summary

Keep open: the title-bar button still deliberately expands on hover in the default source path, and the existing settings do not generally provide stable layout while retaining the button. The additional report of accidental activation when dragging the window supports addressing this interaction rather than treating hiding the button as a solution.

## Change summary

Keep title-bar controls and draggable space stable when hovering the Open in Agents Window button.

## Best solution

Retain a discoverable, keyboard-accessible Agents Window action without hover growth moving adjacent controls or consuming space users target for window dragging. Address the title-bar widget and verify the actual pointer interaction, not only its CSS classes.
