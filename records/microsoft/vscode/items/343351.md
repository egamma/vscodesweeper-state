# Issue #343351 — Agents: "Open in Agents Window" is too easy to activate accidentally

[https://github.com/microsoft/vscode/issues/343351](https://github.com/microsoft/vscode/issues/343351)

## Summary

Keep open: current source deliberately expands this button on hover, and the available workarounds do not provide a stable, visible button for all users. The independent report of accidental activation while dragging the window supports revisiting this interaction.

## Change summary

Keep the title bar layout and pointer targets stable when hovering the Open in Agents Window button.

## Best solution

Provide a stable title bar affordance that preserves intentional activation and keyboard accessibility without moving neighboring controls or consuming previously draggable space on hover.
