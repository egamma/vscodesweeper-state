# Issue #343351 — Agents: "Open in Agents Window" is too easy to activate accidentally

[https://github.com/microsoft/vscode/issues/343351](https://github.com/microsoft/vscode/issues/343351)

## Summary

Keep open as title-bar interaction polish: current source deliberately expands this button in normal layout on hover, so the reported layout shift remains possible. Existing settings hide the button or suppress expansion only for some users; neither fully delivers stable layout while retaining the action.

## Change summary

Keep the title-bar layout and adjacent click targets stable when hovering Open in Agents Window.

## Best solution

Retain the Agents Window action and its accessible identification without hover-driven movement of neighboring title-bar controls. The title-bar widget owner should settle how label discoverability works within that stable layout.
