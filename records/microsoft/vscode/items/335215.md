# Issue #335215 — Agents window: external agent sessions are only discovered at startup; add refresh/rediscovery

[https://github.com/microsoft/vscode/issues/335215](https://github.com/microsoft/vscode/issues/335215)

## Summary

Well-diagnosed gap confirmed in the Agent Host source: external session discovery only runs once at startup settle (or on an external-sessions-mode toggle/legacy migration), never periodically or via a filesystem watcher, so sessions started later in a terminal never appear without a full restart. Worth routing to the agent host / agents-window area as a feature request.

## Change summary

Add a way to re-discover external agent sessions (Claude Code CLI, etc.) created after VS Code startup, either via a manual refresh action or automatic rediscovery, instead of requiring a full restart.

## Best solution

Add discovery re-triggering to the existing Agents window refresh action (or a periodic/file-watcher-driven rescan) in src/vs/platform/agentHost/node/agentService.ts's `_setupChatDiscoveryForProvider`/`_startChatDiscovery` path; today `RefreshAgentSessionsViewerAction` (agentSessionsActions.ts) only re-lists the registry via `listSessions()`, which per the module's own architecture notes 'never enumerate[s] provider catalogs'.
