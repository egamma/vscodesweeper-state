# Issue #335215 — Agents window: external agent sessions are only discovered at startup; add refresh/rediscovery

[https://github.com/microsoft/vscode/issues/335215](https://github.com/microsoft/vscode/issues/335215)

## Summary

Keep open: current Claude discovery is deliberately memoized, so sessions created after its initial scan still lack automatic rediscovery. Existing refresh and SDK-setup paths do not fully cover the requested session-list behavior, and the verified older reports describe different symptoms.

## Change summary

Discover external agent sessions created while VS Code is running without requiring a restart, through explicit refresh or automatic rediscovery.

## Best solution

Provide a supported rediscovery path for newly created external Claude sessions while preserving provider-owned enumeration and existing visibility filters. Decide whether explicit refresh alone is sufficient or automatic discovery should provide parity with the continuous Copilot and Codex discovery mechanisms.
