# Issue #170937 — Support `runOn` with `folderOpen` when adding folder to workspace

[https://github.com/microsoft/vscode/issues/170937](https://github.com/microsoft/vscode/issues/170937)

## Summary

The missing automatic-task trigger remains in current source: adding a workspace folder refreshes task definitions but does not run folderOpen tasks. The issue is already correctly routed, and the discussion supplies sufficient context without requiring a window reload.

## Change summary

Tasks configured with runOptions.runOn: folderOpen do not start when a folder is added to an already-open workspace.

## Best solution

Make automatic task execution respond to folder additions without reloading the window, while preserving permission checks and avoiding duplicate running watchers. Settle whether workspace-file tasks, including the reporter's Sass task, should also be eligible on each addition rather than handling only tasks inside the new folder.
