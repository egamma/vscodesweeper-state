# Issue #293399 — "Cannot launch a terminal process in an empty workspace" restriction is problematic

[https://github.com/microsoft/vscode/issues/293399](https://github.com/microsoft/vscode/issues/293399)

## Summary

Still reproduces on main: the empty-workspace cwd restriction in terminalInstance.ts blocks legitimate extension-triggered terminal launches when cwd differs from userHome. A team member agreed the check should be removed.

## Change summary

Terminal process launch is blocked in an empty workspace when the requested cwd differs from userHome, even for trusted extension-initiated tasks.

## Best solution

Remove or relax the empty-workspace cwd restriction at line ~1601 of src/vs/workbench/contrib/terminal/browser/terminalInstance.ts. The check was a defensive measure from #141971 but overly restricts legitimate extension use cases. The area owner (meganrogge) already acknowledged this in the thread.
