# Issue #340848 — Modern UI: Active tab filename is truncated when `tabSizing` is `"fit"` and `tabActionReserveSpace` is `false`

[https://github.com/microsoft/vscode/issues/340848](https://github.com/microsoft/vscode/issues/340848)

## Summary

Thanks for the report. This looks like a side effect of the recent Modern UI tab change (#340635): the active tab now reserves space for its close button even with tabActionReserveSpace off. It is a brand-new, plausible regression, so it stays open for the owner of that change.

## Change summary

With tabSizing 'fit' and tabActionReserveSpace false, the active unpinned tab's filename is truncated because the close button now takes space instead of overlaying on hover.

## Best solution

In the Modern UI tabs stylesheet and its tab width measurement in multiEditorTabsControl.ts, don't reserve close-button width for the active tab when tabActionReserveSpace is false and the tab is not hovered or focused. Alternatively, decide that the new behaviour is intended and document it. Fix this together with the sibling hover-width issue https://github.com/microsoft/vscode/issues/340854.
