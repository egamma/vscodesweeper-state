# Issue #340848 — Modern UI: Active tab filename is truncated when `tabSizing` is `"fit"` or `"shrink"` and `tabActionReserveSpace` is `false`

[https://github.com/microsoft/vscode/issues/340848](https://github.com/microsoft/vscode/issues/340848)

## Summary

The short-filename improvement does not resolve the remaining report: current source still reduces active-tab label space for long fit labels and shrink tabs when action space is not reserved. Keep this open for the tabs owner to reconcile filename readability with compact sizing and persistent active-tab actions.

## Change summary

Prevent Modern UI active-tab actions from unnecessarily truncating filenames with fit or shrink sizing when tabActionReserveSpace is false.

## Best solution

Honor fit sizing's full-label contract and avoid active-only truncation in shrink mode when sufficient space exists. Settle how compact tabs should accommodate the active close action, while preserving legitimate truncation under actual space constraints.

- **Behavior:**

  > Modern UI can truncate a clean active tab's filename even though the inactive label fits, with tabActionReserveSpace=false and fit or shrink sizing. Fit should retain its full-label promise when the tab can fit in the available area, and shrink should not lose filename visibility merely because the tab becomes active when sufficient space exists. Acceptance must distinguish this unnecessary clipping from legitimate truncation in constrained layouts.
