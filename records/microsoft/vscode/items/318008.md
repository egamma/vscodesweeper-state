# Issue #318008 — [Error] unhandlederror-Uncaught Error: Illegal value for lineNumber

[https://github.com/microsoft/vscode/issues/318008](https://github.com/microsoft/vscode/issues/318008)

## Summary

Still reproduces on main: the hover debouncer can deliver a stale anchor after lines are deleted, causing an out-of-bounds lineNumber in markdownHoverParticipant.computeSync. An open PR (#318018) addresses it but has not merged yet.

## Change summary

Hovering triggers an unhandled 'Illegal value for lineNumber' error when the model changes (lines deleted) between the hover debounce and the sync computation.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/318018, which adds a lineNumber bounds check in both contentHoverComputer.computeSync and markdownHoverParticipant.computeSync. The fix is small and correctly placed — the main question is whether the guard belongs in the computer (catching all participants) or also redundantly in the participant.
