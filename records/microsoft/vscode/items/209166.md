# Issue #209166 — Notebook>Outline: Show Code Cell Markdown

[https://github.com/microsoft/vscode/issues/209166](https://github.com/microsoft/vscode/issues/209166)

## Summary

The notebook outline currently only sources headings from markdown cells and code cell symbols — it never inspects rendered cell outputs. The request for output-derived headings in the outline remains unimplemented on main.

## Change summary

Show markdown headings from code cell rendered outputs in the notebook outline, matching JupyterLab behavior.

## Best solution

Extend NotebookOutlineEntryFactory to optionally parse headings from code cell output (specifically text/markdown MIME outputs), gated by the existing notebook outline configuration. This likely lives in `src/vs/workbench/contrib/notebook/browser/viewModel/notebookOutlineEntryFactory.ts` and would need to observe output changes.
