# Issue #341002 — Markdown editor should have empty buffer at the bottom for nicer editing at document end

[https://github.com/microsoft/vscode/issues/341002](https://github.com/microsoft/vscode/issues/341002)

## Summary

Reasonable polish request for the experimental Markdown editor: the document end sits flush against the bottom edge, unlike the text editor's scrollBeyondLastLine behavior. No existing capability covers it, so it stays open.

## Change summary

Add empty space below the last line in the Markdown editor so editing at the document end is more comfortable.

## Best solution

Add bottom padding or a scroll-beyond-last-line equivalent in the Markdown editor's editor surface (extensions/markdown-language-features/markdown-editor-src), ideally honoring the editor.scrollBeyondLastLine setting.
