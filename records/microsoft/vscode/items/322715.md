# Issue #322715 — Agent adjacent scratchpad.

[https://github.com/microsoft/vscode/issues/322715](https://github.com/microsoft/vscode/issues/322715)

## Summary

Keep open as a feature request for personal notes attached to individual agent sessions. Existing per-session editor restoration and extension-provided canvases offer related building blocks, but neither establishes a built-in adjacent scratchpad that covers the request.

## Change summary

Provide a small, user-editable scratchpad beside each agent session for plans, reminders, and follow-up questions.

## Best solution

Consider a lightweight, opt-in session-notes experience using the existing session-associated editor or canvas infrastructure rather than a separate global notepad. Whether notes remain private to the user or become agent context requires a product decision; the report does not require agent access.
