# Issue #290868 — Agent sessions hover state is huge and inconsistent

[https://github.com/microsoft/vscode/issues/290868](https://github.com/microsoft/vscode/issues/290868)

## Summary

Keep open: current source still reserves a large fixed hover area and can retain an obsolete status when the same session's hover is reused. No verified older canonical or issue-referencing fix was found; this team-authored report remains necessary.

## Change summary

Agent-session hovers waste space on short previews and can report in-progress status for a completed session.

## Best solution

Keep the hover's status consistent with the session list across completion and repeated hovering, and size short previews to their content while retaining a bounded viewport for long conversations.
