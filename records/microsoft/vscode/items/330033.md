# Issue #330033 — agents window narrow window update dialog is cropped

[https://github.com/microsoft/vscode/issues/330033](https://github.com/microsoft/vscode/issues/330033)

## Summary

Team-authored, confirmed-fresh bug report; traced the likely cause in source (a fixed-width hover tooltip in a narrow window) but there's no fix commit yet, so this stays open per the team-authored keep-open rule.

## Change summary

In the Agents window, at the narrowest supported width, hovering the update indicator shows an update tooltip that renders cropped/cut off.

## Best solution

In src/vs/workbench/contrib/update/browser/media/updateTooltip.css, make `.update-tooltip`'s `min-width: 300px` responsive (e.g. clamp to the available viewport/window width) or ensure the hover's positioning logic keeps it fully within the Agents window bounds when the window is narrower than 300px.
