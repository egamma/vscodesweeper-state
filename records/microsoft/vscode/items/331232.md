# Issue #331232 — Agents window single pane: Switched to `Changes` tab even though no changes

[https://github.com/microsoft/vscode/issues/331232](https://github.com/microsoft/vscode/issues/331232)

## Summary

Team-authored, same-day report from active dogfooding of the new single-pane Agents window worktree-session flow; the hard keep-open rule for team-authored items applies regardless of staleness or reproduction depth, and no fix commit referencing this issue exists yet.

## Change summary

In the Agents window single-pane view, kicking off a new worktree session (with no actual file changes) auto-switches focus from the Files tab to the Changes tab partway through the session.

## Best solution

Trace the `_registerManagedTabsSupplement` activation logic in src/vs/sessions/contrib/layout/browser/singlePane/singlePaneExistingSessionStrategy.ts (gates `ensureChangesActive` on `session.changes.length > 0`) and singlePaneDockedTabsCoordinator.ts's `wantsChangesTab`/`isCreated` transition — likely a race where `session.changes` or `isCreated` reports transient/stale non-empty state right as the worktree session is created, before settling back to no changes.
