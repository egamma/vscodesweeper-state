# Issue #282200 — Vscode minimizes when titlebar is middle clicked

[https://github.com/microsoft/vscode/issues/282200](https://github.com/microsoft/vscode/issues/282200)

## Summary

Keep open for investigation of the focus/Alt+Tab behavior, not the intentional window-lowering action. The reporter supplied a recording and confirmed persistence after upgrading; neither the native-titlebar option nor the older related report establishes that the remaining defect is resolved.

## Change summary

After middle-click lowers VS Code on Cinnamon/X11, restoring it requires two Alt+Tab operations rather than the single operation needed for other windows.

## Best solution

Preserve the window manager's configured middle-click action while making subsequent window activation behave consistently with native applications. Isolate the focus/activation discrepancy between custom and native titlebars on Cinnamon/X11 before deciding whether the correction belongs in VS Code, Electron, or the window manager.
