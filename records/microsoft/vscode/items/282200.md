# Issue #282200 — Vscode minimizes when titlebar is middle clicked

[https://github.com/microsoft/vscode/issues/282200](https://github.com/microsoft/vscode/issues/282200)

## Summary

The recording confirms a distinct focus-order problem after X11 lowers VS Code. The custom title bar delegates its draggable region to Electron/Chromium, so this should remain open as an upstream platform issue.

## Change summary

Middle-clicking the custom title bar on Cinnamon/X11 lowers VS Code but leaves it first in the Alt+Tab order, requiring two switches to restore it.

## Best solution

Reproduce the focus-order behavior in Electron on Cinnamon/X11 and link or file the corresponding upstream issue. Keep `window.titleBarStyle: "native"` documented as the available workaround.
