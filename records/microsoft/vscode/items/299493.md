# Issue #299493 — Source Control pannel says GIT while on SVN

[https://github.com/microsoft/vscode/issues/299493](https://github.com/microsoft/vscode/issues/299493)

## Summary

The message describes the built-in Git provider's actual startup scan, not the SVN repository's type. Source Control switches from its welcome content to repository content when the SVN provider registers, so the reported sequence matches the designed behavior.

## Change summary

Avoid showing Git-specific startup scanning text when opening an SVN working directory.

## Best solution

Retain the provider-specific scan message because Git and SVN can coexist in a workspace. For SVN-only workspaces, users can set "git.enabled": false in workspace settings to prevent the built-in Git provider from scanning.
