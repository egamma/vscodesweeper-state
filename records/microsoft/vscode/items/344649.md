- **Proposed comment:**

  > Thanks for the report. That message means the saved chat session cannot access the project folder it previously used; it does not by itself mean your files have been lost.
  > 
  > Check in Finder whether the folder named in the error still exists. If you moved or renamed it, use File > Open Folder to open its current location and start a new chat there. To retry the old session, restore the original project folder and its contents to the location shown in the error, then reopen the session. Creating an empty folder will not recover your files.
  > 
  > If the original folder is already present and accessible in Finder, please share the steps that lead to the error and whether the folder was recently moved or renamed so we can investigate further.
