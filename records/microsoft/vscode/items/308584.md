# Issue #308584 — Visual Studio Code Agents (Preview) should gracefully handle PowerShell shell fallback on Windows

[https://github.com/microsoft/vscode/issues/308584](https://github.com/microsoft/vscode/issues/308584)

## Summary

The current agent-host shell path detects installed PowerShell executables and falls back to Windows PowerShell when PowerShell Core is unavailable. The landed shell-resolution change supports closing this as completed; the linked contributor PR itself was closed without merging.

## Change summary

Allow Windows agent terminal tasks to proceed using Windows PowerShell when pwsh is unavailable.

## Best solution

Retain the shared shell-resolution behavior introduced by https://github.com/microsoft/vscode/commit/8b28f914f2a310829efea3aa7974f9dc168a1ca6, including installed-shell detection and fallback rather than requiring pwsh on PATH.
