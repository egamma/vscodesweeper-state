# Issue #275176 — Excessive updateThinking calls when rendering thinking sections

[https://github.com/microsoft/vscode/issues/275176](https://github.com/microsoft/vscode/issues/275176)

## Summary

Active perf issue with multiple incremental improvements landed (thinking content perf #307878, layout thrashing #308122, leak fix #308939, reflow avoidance #316346) but still open — the core problem of O(n²) markdown re-rendering during thinking streaming remains, blocked on incremental markdown rendering (#275671). Team member authored and actively tracked.

## Change summary

Excessive updateThinking calls during chat thinking-section streaming cause redundant HTML sanitization, string parsing, and style recalculation, degrading renderer performance.

## Best solution

The remaining gap is incremental markdown rendering (#275671) — splitting on block-level elements to avoid re-rendering the entire thinking content on each token. Several palliative fixes have landed (batching, layout caching, leak fixes) but the architectural improvement is still needed. Keep open as the canonical tracker for thinking-stream rendering perf.
