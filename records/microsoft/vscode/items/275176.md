# Issue #275176 — Excessive updateThinking calls when rendering thinking sections

[https://github.com/microsoft/vscode/issues/275176](https://github.com/microsoft/vscode/issues/275176)

## Summary

The excessive polling remains source-reproducible on current main: the 50 ms progressive-render loop treats an active same-ID thinking part as changed even when its text is unchanged. This team-authored, accepted performance bug should remain open; the only directly referencing fix PR was closed without merging.

## Change summary

Avoid repeatedly updating and rendering an unchanged thinking section during progressive chat rendering.

## Best solution

Stop idle progressive-render polling once the active thinking text and timing state are fully rendered, while immediately resuming for genuine model changes and preserving trailing-part cleanup. Keep broader incremental Markdown parsing tracked separately by https://github.com/microsoft/vscode/issues/275671.
