# Issue #163748 — Repositories - svg icons stay dark when the repository row is selected.

[https://github.com/microsoft/vscode/issues/163748](https://github.com/microsoft/vscode/issues/163748)

## Summary

Confirmed visual bug: custom SVG icons (contributed via extension `iconPath`) rendered as CSS background-images cannot react to the list row's selected state, so they stay dark on the blue selection highlight in light themes. Team members confirmed this is a cross-cutting issue affecting any tree/list with custom SVG icons, not just SCM. Still reproduces on current main — the icon rendering path for `iconPath`-based SVGs uses `background-image` which has no CSS mechanism to switch fill color on selection, unlike codicons which inherit `currentColor`.

## Change summary

Custom SVG icons in tree/list views stay dark when the row is selected in light themes, instead of adapting to the selected-row foreground color.

## Best solution

The fix likely needs to render extension-contributed SVGs as CSS mask-images (instead of background-images) so they can be colored via `background-color: currentColor`, or switch to the light-variant icon when the row is selected. The relevant rendering paths are in the icon label and custom tree view node icon CSS (`src/vs/workbench/browser/parts/views/media/views.css`) and potentially the action-bar icon rendering. This is an architectural gap in how `iconPath`-based icons are handled vs codicons.
