# Issue #335117 — Opening a session that needs input from a fullscreen Browser preview does not show chat

[https://github.com/microsoft/vscode/issues/335117](https://github.com/microsoft/vscode/issues/335117)

## Summary

The defect remains present on current main: opening the blocked session activates and focuses it, but the maximized Browser editor continues hiding the Sessions Part. This team-authored bug should stay open for a focused attention-navigation fix.

## Change summary

Opening a needs-input session from the title-bar indicator while a Browser preview is maximized fails to reveal the target chat and its input request.

## Best solution

Opening a blocked session from the title-bar attention surface should leave editor maximization, reveal the Sessions Part, and focus the target session's relevant chat. Ordinary session switches should continue preserving the user's editor layout.
