# Issue #215941 — Support for command URIs in JSON schema hover cards

[https://github.com/microsoft/vscode/issues/215941](https://github.com/microsoft/vscode/issues/215941)

## Summary

Valid feature request — command URIs in JSON schema hover cards are not rendered because the JSON hover service produces plain markdown strings without command trust. Still unimplemented on main.

## Change summary

Command URIs in JSON schema `markdownDescription` fields should render as clickable links in settings.json hover cards, not just in the Settings UI.

## Best solution

The JSON language service hover path needs to produce MarkdownString content with `isTrusted` including `enabledCommands` (or a safe subset), similar to how the Settings UI already handles these. The fix spans the JSON language service (upstream `vscode-json-languageservice`) and the client middleware in `extensions/json-language-features/client/src/jsonClient.ts`.
