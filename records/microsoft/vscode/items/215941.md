# Issue #215941 — Support for command URIs in JSON schema hover cards

[https://github.com/microsoft/vscode/issues/215941](https://github.com/microsoft/vscode/issues/215941)

## Summary

Command links work in the Settings UI, but that capability does not extend to schema-driven JSON hovers. Keep this accepted Backlog request open: an older maintainer decision explains the trust boundary, but no verified open canonical or landed implementation was found.

## Change summary

Support command URI links in JSON schema markdown descriptions displayed in settings.json and other JSON editor hovers.

## Best solution

Resolve whether JSON hovers can safely distinguish trusted extension-contributed descriptions from arbitrary schema content before accepting command links. Preserve the existing restriction for untrusted schemas; the older decision against blanket support should inform that product decision.
