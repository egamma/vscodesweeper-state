# Issue #330301 — Prompt edits silently vanish if focus is changed

[https://github.com/microsoft/vscode/issues/330301](https://github.com/microsoft/vscode/issues/330301)

## Summary

Confirmed in source: clicking any other row while editing a request fires `onDidFocusOutside`, which calls `finishedEditing()` and unconditionally discards the in-progress inline edit text without saving or confirming — matching the reported repro exactly.

## Change summary

Clicking elsewhere in the chat log while editing a sent prompt silently discards the in-progress edit text with no confirmation or recovery.

## Best solution

In `chatWidget.ts`, `clickedRequest`/`finishedEditing` (around lines 1897-2123) and `chatListRenderer.ts`'s row-click listener (around line 1405) should not immediately discard unsaved edit text on an outside click — either persist the draft back onto the request/view model before tearing down the inline editor, or require an explicit confirm/discard action as the reporter suggests, before landing in the chat area.
