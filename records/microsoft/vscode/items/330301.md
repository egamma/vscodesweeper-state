# Issue #330301 — Prompt edits silently vanish if focus is changed

[https://github.com/microsoft/vscode/issues/330301](https://github.com/microsoft/vscode/issues/330301)

## Summary

The silent-loss path was fixed after this report: clicking away from a modified request now opens a discard confirmation, and declining preserves and refocuses the edited content.

## Change summary

Prevent edited chat request text and attachments from being silently discarded when focus leaves the inline editor.

## Best solution

Keep the guarded cancellation behavior implemented by https://github.com/microsoft/vscode/commit/8ba04220e3de2bb9699e672703846b7201fa56ac; it preserves modified request edits unless the user explicitly confirms discarding them.
