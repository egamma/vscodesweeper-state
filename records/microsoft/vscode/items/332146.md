# Issue #332146 — Agents chat input is covered by the on-screen keyboard on Android

## Summary

Team-authored, well-diagnosed report with an open fixing PR (#332148) already in flight — not yet merged, so this stays open until the PR lands.

## Change summary

On Android/mobile web, focusing the Agents chat composer opens the on-screen keyboard, which overlays the composer instead of the layout shifting to keep it visible.

## Best solution

Land https://github.com/microsoft/vscode/pull/332148 ('sessions: keep chat input above mobile keyboard'), which appears to build on the existing IMobileVisualViewport service in src/vs/sessions/browser/parts/mobile/mobileVisualViewport.ts to reposition the composer above the keyboard-occluded region; verify on both Android/Chromium and iOS/WebKit before closing.
