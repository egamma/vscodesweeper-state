# Issue #341302 — Terminal type-ahead latency stats are sorted as strings instead of numbers

[https://github.com/microsoft/vscode/issues/341302](https://github.com/microsoft/vscode/issues/341302)

## Summary

Thanks for the report. The bug is still on main: `.sort()` with no compare function orders the latency numbers as strings. An open PR already references this issue, so it stays open until that PR is reviewed and merged.

## Change summary

PredictionStats.latency sorts numbers lexicographically, so min, median and max are wrong when latencies have different digit counts.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/341303, which sorts the latencies numerically and adds a regression test.
