# Issue #300539 — Output pane stops updating

[https://github.com/microsoft/vscode/issues/300539](https://github.com/microsoft/vscode/issues/300539)

## Summary

Keep open: a team member provided repeatable steps and a recording showing an active Output channel becoming stale under sustained writes and language-server restarts. Current main still uses the asynchronous file-to-model synchronization path implicated by the recovery behavior, and no linked fix or canonical issue was found.

## Change summary

An active Output pane eventually stops displaying new extension output after repeated high-volume language-server restarts, while switching channels can restore it.

## Best solution

Diagnose the clear/append and file-read synchronization in the Output channel model, then ensure sustained writes and repeated clears cannot leave the visible text model behind the channel's backing file.
