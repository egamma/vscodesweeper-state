# Issue #324870 — [Agents window] prompts for SSH key passphrase despite `PubkeyAuthentication no`

[https://github.com/microsoft/vscode/issues/324870](https://github.com/microsoft/vscode/issues/324870)

## Summary

The Agents window SSH implementation still discards the host's authentication restrictions and can request a private-key passphrase despite PubkeyAuthentication no. Keep this open as an agent-host authentication bug; the existing server-method filtering does not enforce the client's SSH configuration.

## Change summary

Honor SSH host authentication restrictions so a password-oriented Agents window connection does not attempt disabled public-key authentication or prompt for a key passphrase.

## Best solution

Make the Agents window's SSH-config-host connection respect PubkeyAuthentication and PreferredAuthentications on initial connection and reconnection, while preserving existing authentication behavior when those restrictions do not apply.
