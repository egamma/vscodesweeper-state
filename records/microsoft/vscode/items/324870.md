# Issue #324870 — [Agents window] prompts for SSH key passphrase despite `PubkeyAuthentication no`

[https://github.com/microsoft/vscode/issues/324870](https://github.com/microsoft/vscode/issues/324870)

## Summary

Confirmed from source: the Agents window SSH implementation ignores `PubkeyAuthentication no` because `parseSSHGOutput` never extracts the `pubkeyauthentication` field and `_buildAuthAttempts` unconditionally queues agent + publickey attempts. This is a real gap versus OpenSSH and Remote-SSH behavior.

## Change summary

Agents window SSH connections attempt public-key auth (prompting for a passphrase) even when `PubkeyAuthentication no` is set in the SSH config.

## Best solution

Add `pubkeyAuthentication` to `ISSHResolvedConfig` / `parseSSHGOutput`, propagate it through `ISSHAgentHostConfig`, and have `_buildAuthAttempts` skip agent and publickey attempts when the resolved config says `pubkeyauthentication no`. Similarly, `PreferredAuthentications` should be respected to constrain the auth method ordering.
