# Issue #346855 — Option to let webviews receive dropped files without holding Shift

[https://github.com/microsoft/vscode/issues/346855](https://github.com/microsoft/vscode/issues/346855)

## Summary

Keep open: current webview drag handling still requires Shift, and no existing option covers the requested opt-in. The related fixes address different drag scenarios; maintainer input is needed on extension-controlled versus user-controlled behavior.

## Change summary

Allow opted-in webviews to receive file drops without Shift while preserving existing defaults.

## Best solution

Provide a supported opt-in for webviews that intentionally accept files, preserving ordinary workbench drag behavior elsewhere. Settle who controls that opt-in and its modifier semantics before implementation.
