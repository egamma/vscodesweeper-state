# Issue #296087 — When Copilot CLI in terminal is ready for input, focuses the diff but not the terminal

[https://github.com/microsoft/vscode/issues/296087](https://github.com/microsoft/vscode/issues/296087)

## Summary

Keep this as the canonical request for coherent background CLI-session diff presentation. Current code preserves keyboard focus when opening a diff, but does not coordinate that presentation with the originating terminal; no verified fixing commit or older same-symptom canonical was found.

## Change summary

Make a diff opened by a background Copilot CLI session clearly associated with that session instead of appearing alongside another session's terminal without explanation.

## Best solution

Define consistent background-session presentation semantics in the Copilot CLI integration: preserve the user's ongoing work while making the originating session identifiable and reachable. Decide whether reviewing a newly presented diff should also reveal its terminal or require an explicit session switch.
