# Issue #296087 — When Copilot CLI in terminal is ready for input, focuses the diff but not the terminal

[https://github.com/microsoft/vscode/issues/296087](https://github.com/microsoft/vscode/issues/296087)

## Summary

Valid team-authored feature request about improving focus behavior when a Copilot CLI terminal session completes — currently the diff takes focus but the originating terminal does not, which is disorienting with multiple concurrent sessions. No fix found on main.

## Change summary

When a Copilot CLI session in the terminal finishes, the associated diff is focused but the terminal is not, making it unclear which session completed.

## Best solution

When a Copilot CLI session completes and its diff is shown, either co-focus the terminal alongside the diff (split focus indication) or provide clear visual context linking the diff to its originating terminal session, so the user understands which session produced the result.
