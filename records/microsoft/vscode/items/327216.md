# Issue #327216 — Slash commands (e.g. /chronicle, plugin skills) not listed in AHP until first message — regression

[https://github.com/microsoft/vscode/issues/327216](https://github.com/microsoft/vscode/issues/327216)

## Summary

Still reproduces on main: agent-host-provided slash commands (like /chronicle) require an active session to resolve completions, but no session exists before the first message is sent, so they don't appear in the completion list until after that point.

## Change summary

Agent-host slash commands (e.g. /chronicle, plugin skills) are not listed in the Agents window input until after the first message is sent in a chat session.

## Best solution

The `AgentHostInputCompletionHandler._resolveContext()` in `src/vs/sessions/contrib/chat/browser/agentHostInputCompletions.ts` returns `undefined` when there is no active session (line 232–234). The fix should either pre-populate agent-host completions from the selected session type's capabilities before a session is established, or ensure that the session/content provider can serve completions without a fully established session. The `SlashCommandHandler` in `slashCommands.ts` already serves its static commands without a session — the agent-host path needs a similar pre-session strategy.
