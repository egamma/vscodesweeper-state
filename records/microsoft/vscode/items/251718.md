## Summary

The requested consolidation remains necessary on current main: terminal quick fixes still expose separate Copilot fix and explain actions, and the fix action still uses the older one-shot suggestion generator rather than agent mode.

## Change summary

Replace the terminal's legacy Copilot fix flow with an agent-mode handoff, potentially consolidating fix and explain under one Ask Copilot action.
