# Issue #330911 — "Quiet Light" theme appearance changed significantly in 1.133.0 update without mentioned

[https://github.com/microsoft/vscode/issues/330911](https://github.com/microsoft/vscode/issues/330911)

## Summary

The expanded title-bar color is intentional Modern UI behavior, as the reporter acknowledged. Current main also provides independent shell-color customizations that answer the remaining question without disabling Modern UI.

## Change summary

Explain Quiet Light's changed Modern UI background and how to recover a neutral backdrop.

## Best solution

Keep the intentional theme-color defaults and explain how to customize modernUI.shellBackground and modernUI.inactiveShellBackground through theme-specific workbench.colorCustomizations. These controls let the reporter choose neutral gutters while retaining Quiet Light's title-bar colors and Modern UI layout.

- **Proposed comment:**

  > Thanks for the context. Modern UI intentionally uses the theme's title-bar colors as the default backdrop between panels; Quiet Light defines those colors as lavender, which explains the larger colored area. This does not mean the theme designer's preference between the two layouts can be inferred from the screenshots.
  > 
  > Current builds provide independent backdrop controls under `workbench.colorCustomizations`. For example, the following gives Quiet Light neutral gutters while retaining Modern UI and its existing title-bar colors; it does not recreate every detail of the 1.132 appearance:
  > 
  > ```json
  > "workbench.colorCustomizations": {
  >   "[Quiet Light]": {
  >     "modernUI.shellBackground": "#F5F5F5",
  >     "modernUI.inactiveShellBackground": "#F5F5F5"
  >   }
  > }
  > ```
  > 
  > Both overrides are needed because the inactive backdrop otherwise defaults to the inactive title-bar color.

- **Intentional current defaults:** src/vs/workbench/common/theme.ts:795–797 registers modernUI.shellBackground and modernUI.inactiveShellBackground with titleBar.activeBackground and titleBar.inactiveBackground defaults. extensions/theme-quietlight/themes/quietlight-color-theme.json:539–540 defines those title-bar colors as #c4b7d7 and #D6CFE2. The lavender shell therefore follows explicit theme defaults rather than an unexplained rendering failure.
- **Existing customization covers the remaining ask:** src/vs/workbench/browser/parts/titlebar/titlebarPart.ts:854–857 resolves the title-bar and shell colors independently; src/vs/workbench/browser/media/floatingPanels.css:204–208 applies the shell color to the floating-card backdrop. src/vs/workbench/contrib/modernUI/README.md:173–174 and 205–211 documents both shell overrides and their active/inactive precedence. workbench.colorCustomizations supports theme-specific overrides in src/vs/workbench/services/themes/common/themeConfiguration.ts.
