# Issue #331534 — "The PR workflow skill is unavailable in this checkout"

[https://github.com/microsoft/vscode/issues/331534](https://github.com/microsoft/vscode/issues/331534)

## Summary

The immediate two-nonce failure was mitigated on main by retaining eight revisions, but active sessions still have no ownership relationship with cached paths, so either retention limit can delete a revision that remains callable. This broader lifetime issue remains necessary and should stay open.

## Change summary

Keep synchronized plugin revisions readable while any active session can still invoke skills advertised from them.

## Best solution

Give each synchronized revision an explicit lifetime tied to the session/client customization state that consumes it, and permit per-plugin or global LRU cleanup only after that ownership is released.
