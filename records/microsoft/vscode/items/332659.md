# Issue #332659 — Next/Previous word selection does not respect newlines correctly

[https://github.com/microsoft/vscode/issues/332659](https://github.com/microsoft/vscode/issues/332659)

## Summary

Keep open as a request for configurable newline stops in word navigation. Current source explicitly implements the reported movement; existing alternative commands change within-line navigation too, so they do not fully cover the requested option.

## Change summary

Allow word navigation and selection to stop immediately across a newline without also traversing a word on the adjacent line.

## Best solution

Evaluate an opt-in newline-boundary behavior for ordinary word movement and its selection variants, preserving existing defaults and accessibility behavior. Existing word-part commands provide a workaround, but should not be treated as equivalent to retaining whole-word navigation.
