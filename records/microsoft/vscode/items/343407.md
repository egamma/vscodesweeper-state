# Issue #343407 — Can't fork a session when it's running in copilot harness target

[https://github.com/microsoft/vscode/issues/343407](https://github.com/microsoft/vscode/issues/343407)

## Summary

Keep open: checkpoint forking fails during an active Copilot response, with independent confirmation on Windows alongside the macOS report. The reproduction steps are sufficient; source inspection identifies the contributed-session fork path but does not establish the blocking operation or a landed fix.

## Change summary

Allow a Copilot session to fork from an earlier checkpoint while its current response is still generating.

## Best solution

Make checkpoint forking work during an active Copilot turn without interrupting the original response or including conversation beyond the selected boundary. Diagnose the contributed-session handler and SDK interaction before choosing a bounded fix.

- **Behavior:**
