# Issue #167146 — Softlink icon is not updated for folder

[https://github.com/microsoft/vscode/issues/167146](https://github.com/microsoft/vscode/issues/167146)

## Summary

The stale symbolic-link decoration remains possible on current main, and an open PR directly addresses both the stale ExplorerItem state and decoration-cache invalidation. Keep the issue open while that human-owned fix is reviewed.

## Change summary

Replacing an existing folder with a symbolic link of the same name does not update its File Explorer icon until the window or folder is reloaded.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330393 after validating the Windows PowerShell replacement scenario and file-watcher performance; the Explorer should refresh visible items whose symbolic-link status changed and invalidate only their cached decorations.
