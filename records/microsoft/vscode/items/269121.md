# Issue #269121 — check next to "starting todo"

[https://github.com/microsoft/vscode/issues/269121](https://github.com/microsoft/vscode/issues/269121)

## Summary

Current main hides successful-tool checkmarks by default, addressing much of the original confusion, but retains the combination when accessibility.chat.showCheckmarks is enabled. Keep this team-authored design discussion open: no verified fix referencing this issue was found, and the thread's alternative presentations remain unsettled.

## Change summary

Clarify todo progress so a successful list-update invocation does not imply that the task it just started has finished.

## Best solution

Make successful todo-list updates and actual task completion distinguishable in the chat transcript, while preserving accessible completion feedback. Reconcile the thread's message-only and persistent-current-task proposals against the newer default-hidden checkmark behavior before deciding whether further UI changes are necessary.
