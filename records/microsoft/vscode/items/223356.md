# Issue #223356 — Show terminal selection in scroll bar/overview ruler 

[https://github.com/microsoft/vscode/issues/223356](https://github.com/microsoft/vscode/issues/223356)

## Summary

Keep open: ordinary terminal selections still lack the overview-ruler indication supplied for Find matches. The request is already correctly routed, and the terminal maintainer welcomed it; no verified canonical or fixing commit was found.

## Change summary

Show the location of an ordinary terminal selection in the scrollbar overview ruler without requiring Find.

## Best solution

Provide an overview-ruler indication for terminal selections while preserving existing search and command markers. Settle whether this represents the selected range or its active endpoint, and whether the request also includes the terminal cursor when nothing is selected.

- **Trace:**

  > In src/vs/workbench/contrib/terminal/browser/xterm/xtermTerminal.ts, the raw onSelectionChange handler broadcasts selection changes and updates context but creates no overview-ruler decoration.
