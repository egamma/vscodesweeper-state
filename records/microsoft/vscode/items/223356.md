# Issue #223356 — Show terminal selection in scroll bar/overview ruler 

[https://github.com/microsoft/vscode/issues/223356](https://github.com/microsoft/vscode/issues/223356)

## Summary

Genuine feature gap: the terminal overview ruler shows cursor position and find-match highlights but does not show text selection highlights, unlike the editor. No implementation exists on current main.

## Change summary

Show the terminal's text selection in the scrollbar overview ruler, matching the editor's behavior.

## Best solution

Add a selection highlight marker to the terminal overview ruler in the xterm integration layer (likely `xtermTerminal.ts` and `terminalColorRegistry.ts`), registering a new `terminalOverviewRuler.selectionForeground` color token and feeding xterm's overview ruler API the current selection range. This depends on xterm.js exposing selection ranges to the overview ruler — may need upstream xterm.js support.
