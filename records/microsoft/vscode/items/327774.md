# Issue #327774 — Enterprise strict plugin marketplaces should hide disallowed marketplaces and plugins

[https://github.com/microsoft/vscode/issues/327774](https://github.com/microsoft/vscode/issues/327774)

## Summary

This is a valid enterprise UX gap: strict policy prevents installation but the customization UI still advertises blocked plugins. Route it to the plugin, customization, and policy owners for an intentional filtering decision.

## Change summary

Hide plugin marketplaces and plugins disallowed by the enterprise strict-marketplace allowlist.

## Best solution

When strict marketplace policy is active, filter marketplace references before fetching or presenting their plugins, using the existing allowlist matcher. Prefer deriving this automatically from the policy rather than adding another enterprise setting.

- **Fit:** aligned
- **Reason:** Making enterprise marketplace policy consistent across enforcement and presentation advances unified configuration and enterprise management.
- **Evidence:** Aligns with current enterprise-management priorities by making centrally managed plugin restrictions coherent in the agent customization experience.
