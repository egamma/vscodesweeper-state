# Issue #327999 — File change summary is weird if you ask Copilot to merge main into your branch

[https://github.com/microsoft/vscode/issues/327999](https://github.com/microsoft/vscode/issues/327999)

## Summary

The behavior remains explainable on current main: a turn that merges a substantially newer main branch compares the complete pre- and post-turn trees, so every file introduced by the merge appears attributable to that Copilot turn. This team-authored issue should remain open while the intended attribution semantics are decided.

## Change summary

Copilot's turn change summary attributes all files brought in by merging main to the agent's turn, obscuring the files the agent meaningfully edited.

## Best solution

Make merge turns distinguish changes imported unchanged from the merged branch from changes authored while completing the turn, while preserving visibility into conflict resolutions and other agent edits.
