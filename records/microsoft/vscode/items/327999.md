# Issue #327999 — File change summary is weird if you ask Copilot to merge main into your branch

[https://github.com/microsoft/vscode/issues/327999](https://github.com/microsoft/vscode/issues/327999)

## Summary

Current main explains the misleading summary: per-turn checkpoints compare the pre-turn tree with the post-merge HEAD, so every incoming change from main is attributed to the Copilot turn. This team-authored bug should remain open and be routed to the Agents Window area.

## Change summary

Avoid presenting all upstream files introduced by a Copilot-performed merge as files edited during that turn.

## Best solution

Adjust agent-host turn changeset semantics to distinguish files imported unchanged by a merge from files actually authored or conflict-resolved during the turn, while retaining terminal-originated edits.
