  > Thanks for the detailed report and testing. To answer your main question: **GitHub Copilot Chat is only supported on official VS Code builds** (desktop, vscode.dev, and GitHub Codespaces). It is not supported on code-server or other VS Code OSS derivatives.
  > 
  > The missing API proposals (`chatDebug@2`, `chatHooks@6`, etc.) are proprietary to the official VS Code product build — they don't exist in the VS Code OSS source that code-server is based on, so they can't be resolved regardless of version matching.
  > 
  > For remote/server scenarios with Copilot, the recommended paths are:
  > - [VS Code Remote Tunnels](https://code.visualstudio.com/docs/remote/tunnels) — access VS Code from a browser with full Copilot support
  > - [VS Code Remote SSH](https://code.visualstudio.com/docs/remote/ssh)
  > - [GitHub Codespaces](https://github.com/features/codespaces)
  > 
  > Since this is a compatibility question about a third-party product rather than an actionable VS Code issue, I'm closing this. For code-server-specific questions, the best venue is https://github.com/coder/code-server.
