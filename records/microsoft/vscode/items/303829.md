# Issue #303829 — Does GitHub Copilot Chat officially support code-server? Getting API proposal errors   on v4.111.0

[https://github.com/microsoft/vscode/issues/303829](https://github.com/microsoft/vscode/issues/303829)

## Summary

This is a compatibility and support question about running Copilot Chat inside the third-party code-server distribution, not an actionable defect in an official VS Code build. The reported proposal and authentication failures are consistent with code-server not matching the VS Code product configuration and APIs required by its bundled Copilot version.

## Change summary

Clarify whether Copilot Chat and agent mode support code-server, and explain the missing proposed APIs and authentication failures.

## Best solution

Use an official VS Code desktop, web, or server-based environment for supported Copilot operation. A code-server release would need to match the corresponding VS Code API proposals, product configuration, and authentication integration for that exact Copilot build; selecting older extension combinations cannot provide reliable compatibility.

## Evidence

- **third-party environment:** The reporter explicitly reproduces only with code-server releases and states that official VS Code is not being used; the later confirmation likewise comes from code-server v4.116.0.
- **proposal coupling:** extensions/copilot/package.json declares extensive proposed API dependencies, including `chatDebug`, `chatHooks`, and `defaultChatParticipant`, so the extension must match the APIs provided by its corresponding VS Code build.
- **product configuration:** src/vs/workbench/services/extensions/common/extensionsProposedApi.ts reads `product.json#extensionEnabledApiProposals`, rejects proposals absent from the host's `allApiProposals`, and lets the product-specific proposal list override the extension manifest. A downstream distribution with mismatched sources or product configuration therefore produces the reported `proposal DOES NOT EXIST` and missing-agent behavior.
- **version testing:** The reporter tested several code-server and Copilot combinations: older versions worked without agent mode, one 2025 combination worked partially, and newer combinations failed on proposals or authentication. This supports host-version incompatibility rather than a single reproducible VS Code-core regression.
- **related issue distinction:** https://github.com/microsoft/vscode/issues/302590 concerned matching Copilot Chat versions to official VS Code releases and was resolved through the corresponding extension release; it does not establish support for code-server packaging.
