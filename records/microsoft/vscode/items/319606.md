## Summary

Valid bug: the MCP server's `app.listen(socketPath)` call has no error handler, so ENOTSUP on unsupported-socket filesystems becomes an unhandled error. An open PR (#319612) already addresses this — keep open pending that PR's review and merge.

## Change summary

MCP server socket listen emits an unhandled ENOTSUP error on Linux filesystems that don't support Unix domain sockets.

## Best solution

Land https://github.com/microsoft/vscode/pull/319612, which wraps `app.listen()` in a Promise that rejects on the 'error' event, letting the existing try/catch in `start()` handle it gracefully.
