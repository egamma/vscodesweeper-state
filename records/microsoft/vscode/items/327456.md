# Issue #327456 — Git extension keeps refs/remotes/<upstream>/<branch> permanently open, preventing atomic Git ref replacement on non-Unix filesystems

[https://github.com/microsoft/vscode/issues/327456](https://github.com/microsoft/vscode/issues/327456)

## Summary

The current built-in Git extension watches the active upstream ref file directly, matching the reported failure on filesystems that prohibit replacing open files. This should remain open and route to the Git area.

## Change summary

Avoid holding individual remote-ref files open so Git can atomically replace them on non-Unix filesystems.

## Best solution

Change `DotGitWatcher.updateTransientWatchers` to observe upstream changes without retaining the individual ref file, likely by watching the containing remote-ref directory while preserving prompt upstream-status updates.
