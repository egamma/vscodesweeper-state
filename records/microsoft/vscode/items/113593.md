# Issue #113593 — Git - Vscode swaps theirs/ours on deleted file during rebase

[https://github.com/microsoft/vscode/issues/113593](https://github.com/microsoft/vscode/issues/113593)

## Summary

The terminology inconsistency remains on current main and is already routed to Git. Raw Git “us/them” labels are technically accurate during rebase but conflict with VS Code's clearer Current/Incoming convention.

## Change summary

Use Current/Incoming terminology instead of confusing Us/Them labels for deletion conflicts during rebase.

## Best solution

Make deletion-conflict status text, diff titles, and staging prompts consistently map rebase sides to Current/Incoming in extensions/git. Keep this older, maintainer-acknowledged issue as the canonical report and consolidate https://github.com/microsoft/vscode/issues/316928 into it.
