# Issue #290969 — Seach Settings seems not working even with case matched

[https://github.com/microsoft/vscode/issues/290969](https://github.com/microsoft/vscode/issues/290969)

## Summary

Still reproduces on main: the `files.exclude` setting applies glob patterns case-sensitively because `glob.parse()` in `explorerViewer.ts` is called without `ignoreCase`, while the Search view's input box correctly uses `ignoreGlobCase`. No fix referencing this issue found.

## Change summary

The `files.exclude` setting does not respect case-insensitive glob matching on Linux/Windows, though the same pattern works in the Search view's 'files to exclude' input.

## Best solution

Pass `{ ignoreCase: true }` (or derive from filesystem capabilities) to `glob.parse()` in `FilesFilter.updateConfiguration()` at `src/vs/workbench/contrib/files/browser/views/explorerViewer.ts:1336`, mirroring the `ignoreGlobCase` logic already used in the search service.
