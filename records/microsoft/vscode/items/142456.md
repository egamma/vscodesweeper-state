# Issue #142456 — Inconsistent keyboard shortcuts between Windows and Linux

[https://github.com/microsoft/vscode/issues/142456](https://github.com/microsoft/vscode/issues/142456)

## Summary

Verified duplicate: the older open canonical issue tracks selecting another operating system's default keymap, including using Windows bindings on Linux. Consolidating there preserves the substantial demand and avoids splitting the same design decision.

## Change summary

Allow Linux users to select and sync the Windows default keyboard shortcuts instead of maintaining platform-specific overrides.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/27385 and design one platform-keymap selector that supports Windows, Linux, and macOS defaults in any direction, with the selection participating in Settings Sync.

## Evidence

- **canonical issue:** https://github.com/microsoft/vscode/issues/27385 is open, predates this report, has 97 upvotes, and tracks selecting one operating system's default keymap on another; its discussion explicitly requests Windows bindings on Linux and platform selection in either direction.
- **same remaining work:** Both issues require overriding the operating system used to select default keybindings rather than manually copying individual bindings or installing a keymap extension.
- **current source:** src/vs/platform/keybinding/common/keybindingsRegistry.ts selects `win`, `mac`, or `linux` bindings directly from the runtime OS in `bindToCurrentPlatform`; there is no user-selected default-keymap platform.
- **reported examples remain platform-specific:** Current main still assigns Linux overrides for Format Document and Copy Line Up/Down in src/vs/editor/contrib/format/browser/formatActions.ts and src/vs/editor/contrib/linesOperations/browser/linesOperations.ts, while navigation bindings also differ in src/vs/workbench/browser/parts/editor/editorActions.ts.
- **sync limitation:** The existing `settingsSync.keybindingsPerPlatform` setting in src/vs/platform/userDataSync/common/userDataSync.ts only controls whether user keybindings are synchronized separately per platform; it does not select or synchronize another platform's default keymap.
