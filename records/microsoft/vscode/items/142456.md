# Issue #142456 — Inconsistent keyboard shortcuts between Windows and Linux

[https://github.com/microsoft/vscode/issues/142456](https://github.com/microsoft/vscode/issues/142456)

## Summary

Verified duplicate: the older open canonical issue already tracks selecting another operating system's default keymap, explicitly including using Windows bindings on Linux. Consolidating there preserves this report's Linux-specific examples without splitting the same design work.

## Change summary

Allow Linux users to select and sync the Windows default keyboard mapping instead of relearning platform-specific shortcuts.

## Best solution

Consolidate the product decision and implementation under https://github.com/microsoft/vscode/issues/27385, covering a platform-independent keymap selector and its interaction with Settings Sync.
