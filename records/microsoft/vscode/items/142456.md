# Issue #142456 — Inconsistent keyboard shortcuts between Windows and Linux

[https://github.com/microsoft/vscode/issues/142456](https://github.com/microsoft/vscode/issues/142456)

## Summary

Legitimate feature request with 40 upvotes and active community discussion — asks for a way to use Windows-style keybindings on Linux (or switch between keybinding modes). No existing built-in mechanism addresses this; the third-party extension 'default-keys-windows' is a workaround but not a core solution. Stays open as under-discussion.

## Change summary

Provide a built-in way to use consistent keyboard shortcuts across Windows and Linux, or allow switching between platform keybinding presets.

## Best solution

Introduce a keybinding preset or profile system that lets users opt into Windows-style defaults on Linux (and vice versa), or at minimum align the most common keybindings (Alt+Shift+F for format, Alt+Left/Right for navigation) where no real Linux desktop conflict exists. The keybinding service in `src/vs/workbench/services/keybinding/` would need platform-preset support. Alternatively, a built-in keymap extension (like the Vim/Emacs keymaps) shipping a Windows-defaults-on-Linux mapping would address the gap without core changes.
