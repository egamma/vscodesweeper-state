# Issue #269591 — Unicode Highlight, allowedCharacters not working for some supplementary-plane characters (U+1D448, U+1D462, U+1D703)

[https://github.com/microsoft/vscode/issues/269591](https://github.com/microsoft/vscode/issues/269591)

## Summary

The reported behavior is a source-confirmed bug, not a feature request: the highlighter evaluates an incomplete surrogate pair at the end of a line and bypasses the allowed-character match. Keep this open and classify it as a bug in the existing unicode-highlight area.

## Change summary

Allowlisted supplementary-plane characters should remain unhighlighted when they occur at the end of a line.

## Best solution

Make UnicodeTextModelHighlighter honor allowed code points consistently at line boundaries, with regression coverage for the reporter's examples and unchanged highlighting of non-allowlisted characters.
