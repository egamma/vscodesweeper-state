# Issue #245610 — Alt Down Arrow to move */ comment is reformatting code

[https://github.com/microsoft/vscode/issues/245610](https://github.com/microsoft/vscode/issues/245610)

## Summary

Keep open: the discussion independently confirms the indentation regression, and current source still reindents lines crossed by Move Line Down. A later virtual-model refactor does not establish a fix; the supplied C++ example is sufficient for a current-build regression check.

## Change summary

Moving a C++ block-comment terminator downward unexpectedly changes the indentation of the code it passes.

## Best solution

Make moving the comment boundary preserve the existing relative indentation of the crossed code while retaining useful automatic indentation for ordinary line moves. Establish the exact current failure with tokenized C++ coverage in the Move Lines Command suite before choosing the implementation.
