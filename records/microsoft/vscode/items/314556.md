# Issue #314556 — Chat session persistence inlines image and tool binary data as base64, causing unbounded session growth

[https://github.com/microsoft/vscode/issues/314556](https://github.com/microsoft/vscode/issues/314556)

## Summary

Current main still persists attachment and tool binary payloads inline as base64. A serialization-size fallback mitigates some failures but does not provide resource-backed persistence; retain this issue for the storage and memory-lifecycle work acknowledged by maintainers.

## Change summary

Prevent image-heavy chat sessions from accumulating inline binary payloads while preserving locally readable images across reloads and follow-up requests.

## Best solution

Provide resource-backed binary persistence across chat attachments and tool results, preserving restoration and participant access while tying resource cleanup to session deletion and trimming. Plan this across serialization, rendering, request construction, and lifecycle management rather than treating payload truncation or changing harnesses as a complete fix.
