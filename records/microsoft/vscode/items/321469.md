# Issue #321469 — orphaned agent window session created when marked done too early

[https://github.com/microsoft/vscode/issues/321469](https://github.com/microsoft/vscode/issues/321469)

## Change summary

Marking a newly submitted agent session done immediately can leave a blank history entry that neither opens nor responds to another Mark Done action.

## Best solution

Ensure early archival remains effective across first-turn cancellation and session materialization, without leaving an unusable history entry. First establish which current provider path reproduces the reported race; preserve normal session history and active-session visibility.

- **Trace:**

  > Mark Done enters archiveSessionsWithUndo in src/vs/sessions/contrib/sessions/browser/views/sessionsViewActions.ts, then SessionsManagementService.archiveSession cancels active chats before delegating archival to the owning provider.
