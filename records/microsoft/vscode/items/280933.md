# Issue #280933 — Debugger has races and can show "Paused on Entry" shown for continued threads

[https://github.com/microsoft/vscode/issues/280933](https://github.com/microsoft/vscode/issues/280933)

## Summary

Keep open: current source still allows a delayed stopped-event thread lookup to restore paused state after a newer continued event has cleared it. The supplied Mock Debug reproduction is actionable, and the earlier fix does not cover this remaining race.

## Change summary

Prevent running debug threads from remaining labeled "Paused on Entry" after closely spaced started, stopped, and continued events.

## Best solution

Ensure asynchronous thread discovery cannot apply obsolete stopped state after a later continuation, while preserving genuinely newer stops and independent thread states. Pin the event-ordering behavior with deterministic DebugSession regression tests.
