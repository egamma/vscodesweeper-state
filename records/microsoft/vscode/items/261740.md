# Issue #261740 — Copilot Chat: grep_search fails with multiple folders

[https://github.com/microsoft/vscode/issues/261740](https://github.com/microsoft/vscode/issues/261740)

## Summary

Still open on main: the grep_search tool description in package.json still encourages regex alternation with `|` in the query description while only briefly warning against it in `includePattern`, causing models to conflate the two and produce invalid glob patterns like `src/**|test/**`. A team member acknowledged the issue and noted plans for iteration, but no fix has landed.

## Change summary

Models use pipe (`|`) alternation in the `includePattern` glob of the grep_search tool because the tool description encourages `|` for regex queries and the `includePattern` description doesn't provide clear multi-folder glob examples.

## Best solution

Improve the `includePattern` description in `extensions/copilot/package.json` (under `copilot_findTextInFiles`) and potentially also in the Responses API tool schema to provide clear brace-expansion or comma-separated examples for targeting multiple folders (e.g. `{src,test}/**`), replacing the negative-only instruction 'Do not use |'. As roblourens noted, piling up examples alone may not solve it — the team may also want to consider runtime sanitization of `|` in includePattern values in `extensions/copilot/src/extension/tools/node/findTextInFilesTool.tsx`.
