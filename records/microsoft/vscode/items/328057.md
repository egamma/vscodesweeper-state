# Issue #328057 — Feature Request: Text underlining for problems in the Markdown Preview Editor

[https://github.com/microsoft/vscode/issues/328057](https://github.com/microsoft/vscode/issues/328057)

## Summary

This is a valid, currently unimplemented Markdown preview enhancement. Route it to the Markdown extension area for design and prioritization.

## Change summary

Show source diagnostics as underlines with hover details in the rendered Markdown preview editor.

## Best solution

Add generic diagnostic rendering to the built-in Markdown preview so diagnostics from any provider can be mapped to rendered content and expose their messages on hover, rather than coupling the implementation to markdownlint.
