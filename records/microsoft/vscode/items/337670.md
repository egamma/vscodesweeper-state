## Summary

Fresh report (1 day old, only an automated version-check reply so far) claiming custom/BYOK models aren't offered in the Agents window for a WSL-backed project while they are for a Windows-local project. Plausible (BYOK models come from extensions, and WSL workspaces run a separate remote extension host), but there's no confirmation of which extension provides the custom model, whether it's installed/enabled on the WSL side, or whether this reproduces with other extensions disabled — the template's own 'disable extensions' question was left unanswered.

## Change summary

## Best solution
