# Issue #255164 — Ollama Log Truncation with Agent Mode - Context Length

[https://github.com/microsoft/vscode/issues/255164](https://github.com/microsoft/vscode/issues/255164)

## Summary

This is a support question already answered by two team members: Ollama's context window size is configured on the Ollama side (via `num_ctx` or Modelfile), not through the OpenAI-compatible API that VS Code uses. The current BYOK Ollama provider already reads the model's reported context length and sizes requests accordingly.

## Change summary

Request to allow VS Code to specify a larger context window size when connecting to Ollama in agent mode.

## Best solution

No VS Code change needed. The user should configure Ollama's context window via its own mechanisms (Modelfile `num_ctx` parameter or environment variable). VS Code's Ollama provider already reads the model's reported `context_length` from the Ollama `/api/show` endpoint and sizes input/output tokens accordingly (see `ollamaProvider.ts` line 149).
