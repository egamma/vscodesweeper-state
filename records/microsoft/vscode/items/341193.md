# Issue #341193 — Agents Window: Explorer retains the previous repository name after moving a chat

[https://github.com/microsoft/vscode/issues/341193](https://github.com/microsoft/vscode/issues/341193)

## Summary

Thanks for the detailed report. The steps are complete but need a live Agents Window and agent host, so I could not confirm the defect. The Explorer root name appears to be computed once from the session workspace label, which may not refresh after a chat move. Steps are sufficient to retest.

## Change summary

After moving a chat between repository folders, the Agents Window Files root keeps showing the previous repository name until reload.

## Best solution

Make sure the mounted workspace folder name is recomputed from the new workspace label after a chat move, probably in the Agents Window workspace-folder sync. Likely the same root cause as the stale header worktree name in #341048, so fix them together.
