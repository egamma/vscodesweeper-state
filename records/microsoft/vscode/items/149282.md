# Issue #149282 — indent guides highlight in HTML interrupted in script/style sections when "editor.guides.bracketPairs": true

[https://github.com/microsoft/vscode/issues/149282](https://github.com/microsoft/vscode/issues/149282)

## Summary

Keep open for guide-coexistence polish: current source intentionally suppresses active indentation highlighting where bracket guides appear, and the available override does not eliminate same-column replacement. This is accepted Backlog work, and a maintainer already consolidated the older interruption report into this issue.

## Change summary

Keep HTML indentation highlighting continuous through embedded script/style sections when bracket pair guides are enabled.

## Best solution

Define consistent coexistence and precedence for active indentation guides and embedded-language bracket guides in IndentGuidesOverlay. Preserve independent bracket-guide coloring; disabling bracket colorization should not implicitly disable or recolor guides.

This is a per-line condition, so embedded script/style bracket guides can interrupt highlighting otherwise present in surrounding HTML.
