# Issue #334891 — Agent Merge - we should make it more clear this this is clickable

[https://github.com/microsoft/vscode/issues/334891](https://github.com/microsoft/vscode/issues/334891)

## Summary

Current main still presents the collapsed Agent Merge enablement notice as quiet inline text whose chevron appears only on hover or focus, while the referenced Merge Conflicts disclosure has a persistent card and twistie affordance. This team-authored, bounded polish request should remain open.

## Change summary

Make the collapsed Agent Merge state notification visibly clickable by matching the compact disclosure treatment used for the Merge Conflicts card.

## Best solution

Present Agent Merge state-change notifications in the same compact card/disclosure visual language as the Agent Merge repair-status card, while preserving their existing keyboard operation, expanded details, accessible labels, and inline timing.
