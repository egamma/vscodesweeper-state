# Issue #269609 — Terminal dictation while typing overlaps text

[https://github.com/microsoft/vscode/issues/269609](https://github.com/microsoft/vscode/issues/269609)

## Summary

Keep open: current source still forwards typed input independently of pending terminal dictation, without clearing or accepting its ghost text. The report provides sufficient steps; the remaining product choice is whether ordinary typing accepts or discards the pending transcript.

## Change summary

Prevent pending terminal dictation from overlapping typed input, and make Enter accept the visible transcript and end dictation.

## Best solution

Define the typing handoff in terminal dictation so pending speech is resolved before manual input reaches the shell. Preserve the explicit Enter expectation: accept the currently displayed transcript, stop dictation, and prevent later recognition results from modifying subsequent input.
