# Issue #318605 — Dark Mode Support for Integrated Browser

[https://github.com/microsoft/vscode/issues/318605](https://github.com/microsoft/vscode/issues/318605)

## Summary

The existing `window.systemColorTheme` setting already controls `prefers-color-scheme` for the integrated browser via Electron's `nativeTheme`, but the reporter's real ask (comment #2) is for forced dark mode across all sites — including those that don't implement the media query. That's a genuine gap; keeping open as a valid enhancement.

## Change summary

Request a forced dark mode toggle for the integrated browser that applies dark rendering even to sites that don't respect `prefers-color-scheme`.

## Best solution

Consider exposing Chromium's Auto Dark Mode (`--enable-features=WebContentsForceDark`) or the DevTools `emulateVisionDeficiency`/`setEmulatedMedia` APIs as a per-browser-view setting, so the integrated browser can force dark rendering on pages that lack native dark mode support. The implementation would likely live in `src/vs/platform/browserView/electron-main/browserViewMainService.ts` and the contribution settings.

## Evidence

- **existing mechanism:** `window.systemColorTheme` setting (registered in src/vs/platform/theme/electron-main/themeMainServiceImpl.ts) controls Electron's `nativeTheme.themeSource`, which sets `prefers-color-scheme` for all BrowserViews. When set to `auto`, it follows the VS Code theme.
- **gap confirmed:** No code in src/vs/platform/browserView/ or src/vs/workbench/contrib/browserView/ emulates forced dark mode or injects dark-mode CSS. Pages that don't implement `prefers-color-scheme` remain light regardless of the setting.
- **member response:** VS Code team member @kycutler acknowledged the existing `window.systemColorTheme` workaround but the reporter confirmed in comment #2 that it only works for sites that implement the media query (e.g. google.com), not localhost or arbitrary sites.
