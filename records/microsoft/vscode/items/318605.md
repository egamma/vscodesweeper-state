# Issue #318605 — Dark Mode Support for Integrated Browser

[https://github.com/microsoft/vscode/issues/318605](https://github.com/microsoft/vscode/issues/318605)

## Summary

Keep open: the existing application-wide color preference only partially addresses the request. The reporter explicitly asks for browser-independent control and dark rendering on sites without their own dark theme; neither is covered by the cited setting.

## Change summary

Provide an integrated-browser dark-mode control independent of the OS and editor theme, including consideration of sites without native dark styling.

## Best solution

Retain this request for a browser-area product decision distinguishing a website color-scheme preference from forced dark rendering. Preserve ordinary website rendering by default; any browser-specific override needs clearly defined scope and behavior.
