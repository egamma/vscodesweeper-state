## Summary

The duplication remains explainable on current source: JavaScript Auto Attach embeds the inherited NODE_OPTIONS in its prepended value, then the terminal environment-variable machinery prepends that value to the original NODE_OPTIONS again. This should remain open and route to the debug area.
