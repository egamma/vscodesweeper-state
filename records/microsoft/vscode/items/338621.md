# Issue #338621 — Chat activity indicator dot flickers while chats are working

[https://github.com/microsoft/vscode/issues/338621](https://github.com/microsoft/vscode/issues/338621)

## Summary

Traced to a real defect in current main: the chat view's progress badge binds to `model.requestInProgress`, which by design goes false during tool confirmations/elicitations/plan reviews and true again once resolved — for a multi-step agent session that toggles rapidly, producing exactly the described flicker. `hasActiveRequest` already exists on ChatModel and stays true across those intermediate states.

## Change summary

The chat activity/progress badge dot flickers on/off repeatedly while an agent session is actively working through multiple tool calls.

## Best solution

Switch the badge autorun in chatViewPane.ts to key off `model.hasActiveRequest` instead of `model.requestInProgress`, since hasActiveRequest is documented to remain true through tool confirmations and other intermediate states where requestInProgress momentarily drops to false.
