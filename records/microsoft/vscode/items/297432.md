# Issue #297432 — Worktree repo doesn't align with scm multiroot repo

[https://github.com/microsoft/vscode/issues/297432](https://github.com/microsoft/vscode/issues/297432)

## Summary

Keep open: current source still defaults new background sessions to the last-used or first repository rather than the SCM-selected repository. A verified open PR explicitly targets this issue, so the next step is to evaluate that implementation rather than close the report or start competing work.

## Change summary

Default the background-agent repository picker to the SCM-selected repository in multi-root workspaces, avoiding repeated manual selection.

## Best solution

New background sessions without an existing repository selection should prefer the eligible SCM-selected repository while preserving explicit session choices and existing fallbacks. Review the implementation candidate at https://github.com/microsoft/vscode-copilot-chat/pull/3976 against the current in-repository Copilot code; the issue remains necessary until that behavior lands.
