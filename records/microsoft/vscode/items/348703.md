# Issue #348703 — Copilot Agent Host fails on snap (Ubuntu 22.04): core20 glibc 2.31 vs system libcrypto.so.3 (GLIBC_2.33 not found)

[https://github.com/microsoft/vscode/issues/348703](https://github.com/microsoft/vscode/issues/348703)

## Summary

Keep open: two reporters confirm Copilot failures caused by incompatible host OpenSSL libraries loading alongside snap core20 libc. Current packaging still uses core20, but the SDK/runtime layout has changed, so the existing reports provide a concrete regression case to retest rather than evidence of a completed fix.

## Change summary

Restore Copilot functionality in the Linux snap when host libcrypto requires a newer glibc than core20 supplies.

## Best solution

Ensure the packaged Copilot runtime loads ABI-compatible OpenSSL libraries on supported snap installations without weakening certificate validation. Investigate the current native runtime and snap packaging together before selecting the fix.
