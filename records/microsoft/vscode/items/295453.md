# Issue #295453 — [icon theme] Add support for secondary/fallback icon theme selection

[https://github.com/microsoft/vscode/issues/295453](https://github.com/microsoft/vscode/issues/295453)

## Summary

Selecting a secondary file icon theme remains unsupported. Keep this under discussion: the older identical request was closed through backlog cleanup, not a technical scope decision, and no open canonical was verified.

## Change summary

Allow a secondary file icon theme to supply missing file and folder icons while preserving the primary theme's coverage.

## Best solution

Evaluate explicit fallback-theme composition in the file icon theme service, with defined precedence between primary generic icons and secondary specific associations. Retain single-theme behavior by default; adding individual icons to Seti would address examples but not the requested capability.
