# Issue #295453 — [icon theme] Add support for secondary/fallback icon theme selection

[https://github.com/microsoft/vscode/issues/295453](https://github.com/microsoft/vscode/issues/295453)

## Summary

Valid feature request that is not currently covered by the file icon theme setting: current source models `workbench.iconTheme` as a single selected theme and applies one generated stylesheet. It should be routed to the themes area rather than closed; I could not verify a canonical duplicate because GitHub search was unavailable and the provided related item is unrelated.

## Change summary

Add support for configuring a secondary file icon theme whose icons are used when the primary icon theme has no matching file or folder icon.

## Best solution

Have the themes owners decide whether file-icon composition belongs in core, likely around the file icon theme loader and `workbench.iconTheme` configuration model; if accepted, it needs an explicit fallback setting or theme schema support rather than ad hoc icon merging.
