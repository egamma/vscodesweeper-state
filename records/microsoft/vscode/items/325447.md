# Issue #325447 — GitHub Copilot thinking effort purportedly used does not reflect thinking effort requested.

[https://github.com/microsoft/vscode/issues/325447](https://github.com/microsoft/vscode/issues/325447)

## Summary

The reported request-editing defect was fixed immediately after the report and shipped through the 1.129.0 milestone. Current main preserves the edited request's model configuration, including thinking effort, instead of reading configuration from the separate composer after the inline editor is torn down.

## Change summary

Editing or canceling an earlier prompt could make later prompts appear to use a different thinking-effort level from the one selected when they were submitted.

## Best solution

Keep the shipped editor-scoped model-configuration flow from commit 2d03be5f55db19f6cf24771fcb4446c171204a38, which records each request's selected thinking effort and restores that configuration when the request is edited.
