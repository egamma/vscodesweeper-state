# Issue #325447 — GitHub Copilot thinking effort purportedly used does not reflect thinking effort requested.

[https://github.com/microsoft/vscode/issues/325447](https://github.com/microsoft/vscode/issues/325447)

## Summary

The reported edit-history mismatch is addressed by a landed fix that captures each request's model configuration and restores it when editing. Current source preserves the submitted effort instead of displaying the edit input's last-used value.

## Change summary

Submitted chat prompts should retain their requested thinking effort when reopened for editing, including after another edit is resubmitted or canceled.

## Best solution

Treat the history/configuration mismatch as completed by commit 871d59690562a67017f2c36b4fbe812f5f56b665. Retain request-scoped configuration capture and restoration so the edit picker reflects the settings submitted for that turn.
