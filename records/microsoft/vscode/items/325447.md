# Issue #325447 — GitHub Copilot thinking effort purportedly used does not reflect thinking effort requested.

[https://github.com/microsoft/vscode/issues/325447](https://github.com/microsoft/vscode/issues/325447)

## Summary

A later fix now snapshots each request's model configuration and restores it when that request is edited, so changing or cancelling another edit no longer substitutes the wrong thinking effort.

## Change summary

Editing or cancelling a submitted prompt could make subsequent prompt edits display or reuse a different thinking effort from the one originally submitted.

## Best solution

Keep the request-scoped model configuration behavior implemented by https://github.com/microsoft/vscode/commit/871d59690562a67017f2c36b4fbe812f5f56b665; it preserves the submitted reasoning effort through serialization, synchronization, and later editing.
