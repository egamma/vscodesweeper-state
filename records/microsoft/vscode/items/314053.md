# Issue #314053 — Copilot CLI (handsoff) from VS Code fails with "model_not_supported" error since 1.119

[https://github.com/microsoft/vscode/issues/314053](https://github.com/microsoft/vscode/issues/314053)

## Summary

Verified duplicate of #304075: both report the same root cause — `getAuthInfo()` in `copilotCli.ts` hardcodes `host: 'https://github.com'` instead of using the GHE instance URL, causing `model_not_supported` errors for GHE users in Copilot CLI sessions.

## Change summary

Copilot CLI handsoff sessions fail with `model_not_supported` when authenticated via a GitHub Enterprise instance, because the SDK auth info hardcodes `github.com` as the host.

Consolidate on https://github.com/microsoft/vscode/issues/304075, which already has team engagement (DonJayamanne, TylerLeonhardt) and tracks the fix for GHE auth routing in `getAuthInfo()`.
