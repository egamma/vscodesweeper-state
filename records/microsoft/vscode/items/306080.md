# Issue #306080 — Feature Request: "Send to AI Chat" from Markdown/Text Editor Use Case

[https://github.com/microsoft/vscode/issues/306080](https://github.com/microsoft/vscode/issues/306080)

## Summary

The requested functionality already exists: VS Code ships "Add File to Chat" and "Add Selection to Chat" actions accessible via the editor context menu, editor title context menu, and command palette — covering all three proposed interaction points.

## Change summary

Request to add a way to send file content or selected text from the editor to AI Chat as context.

## Best solution

No change needed. The reporter can use the existing "Add File to Chat" (workbench.action.chat.attachFile) and "Add Selection to Chat" (workbench.action.chat.attachSelection) commands, available from the editor right-click context menu, the editor title context menu, and the command palette (F1). Additionally, #file references in the chat input box can attach files inline.

- **Proposed comment:**

  > Thanks for the suggestion! The functionality you're describing is actually already built into VS Code:
  > 
  > - **Add File to Chat** — right-click a file tab or use the editor context menu → "Add File to Chat", or run the command from the Command Palette (`workbench.action.chat.attachFile`). This attaches the entire file as context to the Chat view.
  > - **Add Selection to Chat** — select text in the editor, right-click → "Add Selection to Chat" (`workbench.action.chat.attachSelection`). This attaches just the selected portion.
  > - **Add Context…** — the `+` button / paperclip in the Chat input lets you pick files, folders, or selections to attach.
  > - **`#file` references** — type `#file:` in the Chat input to reference any file inline.
  > 
  > These work with any file type, including `.md` files, and attach the content as context for the AI conversation. Since this is already available, I'm closing this as already covered by the current design. If there's a specific gap these don't address, please feel free to open a new issue with details!
