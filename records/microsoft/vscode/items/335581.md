# Issue #335581 — Agent Host WorkIQ MCP remains Running after XAA assertion expires

[https://github.com/microsoft/vscode/issues/335581](https://github.com/microsoft/vscode/issues/335581)

## Summary

Well-diagnosed, current bug: WorkIQ/XAA-authenticated MCP servers keep showing 'Running' after their assertion expires because the expiry is never forwarded to the SDK and a tool-level auth failure never triggers an AuthRequired transition. Verified the cited code paths on main; already carries the right labels (bug, mcp, ai-customizations), so this stays open pending a design decision.

## Change summary

Enterprise-managed (XAA) MCP servers remain shown as authenticated/Running after their assertion expires, with tool calls failing AADSTS500133 and no sign-in action ever surfaced.

## Best solution

Design how expiry should be handled end-to-end — propagate AuthenticationSession.expiresIn into the SDK MCP auth resolution for proactive renewal and/or translate a recognized auth-failure tool result into an AuthRequired transition — then update mcpListWidget.ts so the UI can't show a stale server as Running once auth is unusable. Should be coordinated with the XAA refresh-token work in #330983.

## Evidence

- **resolveMcpAuthentication drops expiry:** src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts:2558 resolves the pending MCP auth request with `{ kind: 'token', accessToken: params.token }` only — no expiry field is forwarded to the SDK, matching the report exactly.
- **workbench does carry expiresIn:** src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostAuth.ts computes `expiresIn` (around line 509) from `AuthenticationSession.expiresAfter` when forwarding auth to Agent Host, but that value isn't threaded through to the MCP token resolution above.
- **UI maps Ready directly to Running:** src/vs/workbench/contrib/chat/browser/aiCustomization/mcpListWidget.ts renders sign-in only for AuthRequired, so a stale-but-connected server is visually indistinguishable from a healthy one, as described in the issue.
