# Issue #336155 — Agent skill frontmatter is not recognized when SKILL.md has a UTF-8 BOM

[https://github.com/microsoft/vscode/issues/336155](https://github.com/microsoft/vscode/issues/336155)

## Summary

Confirmed in current source: the frontmatter regex in promptFileParser.ts doesn't account for a leading UTF-8 BOM on the raw-read path, so BOM-prefixed SKILL.md files silently lose their frontmatter/description. A fixing PR is already open, so this should stay open pending that merge rather than being closed or auto-fixed now.

## Change summary

SKILL.md files saved with a UTF-8 BOM aren't reliably recognized as having YAML frontmatter, so the skill's description/metadata is dropped and discovery becomes non-deterministic.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/336158 which strips a leading BOM before parsing prompt/skill files; verify it covers the `PromptFileParser.parse()` path in src/vs/workbench/contrib/chat/common/promptSyntax/promptFileParser.ts and add the regression test suggested in the issue (`'\uFEFF---\nname: bom-test\n...'`).
