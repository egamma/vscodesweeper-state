# Issue #328319 — Agents window doesn't load global skills when no workspace is selected

[https://github.com/microsoft/vscode/issues/328319](https://github.com/microsoft/vscode/issues/328319)

## Summary

The workspace-less Agents window omits supported user-level skills until a workspace change forces discovery to refresh. Route this recent regression to the Agents window and prompt-customization owners.

## Change summary

Load skills from `~/.copilot/skills` in the Agents window even when no workspace is selected.

## Best solution

Make initial customization discovery in the Agents window resolve and display personal skill locations independently of workspace state, with coverage for startup with zero workspace folders.
