# Issue #259465 — Also use vscode.dev redirect link for dynamic auth providers

[https://github.com/microsoft/vscode/issues/259465](https://github.com/microsoft/vscode/issues/259465)

## Summary

The dynamic-auth loopback completion page still opens the application URI directly, so the requested vscode.dev redirect remains missing. Keep this team-authored, accepted Backlog request open; the linked GitHub-authentication fix does not cover this path.

## Change summary

Use the vscode.dev redirect intermediary when returning from dynamic-provider MCP authentication so browsers can remember permission to open VS Code.

## Best solution

Give dynamic authentication the same stable-origin return experience as GitHub authentication, for both automatic navigation and the fallback link, while preserving the existing loopback OAuth exchange.
