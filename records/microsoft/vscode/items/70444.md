# Issue #70444 — TerminalOptions.waitOnExit API

[https://github.com/microsoft/vscode/issues/70444](https://github.com/microsoft/vscode/issues/70444)

## Summary

Valid, well-supported API feature request (24 upvotes, above the backlog-promotion threshold). The internal infrastructure already exists — `WaitOnExitValue` type and `waitOnExit` on `IShellLaunchConfig` — but the capability is not surfaced in the public extension API (`vscode.d.ts`) or any proposed API. A real gap remains.

## Change summary

Expose `waitOnExit` on `TerminalOptions` in the VS Code extension API so extensions can control whether the terminal panel waits after the process exits.

## Best solution

Add `waitOnExit` to the proposed (then stable) `TerminalOptions` API surface. The plumbing already exists: `WaitOnExitValue` in `src/vs/platform/terminal/common/terminal.ts` (line 697) and the ext-host protocol already carries a boolean `waitOnExit` (line 657 of `extHost.protocol.ts`). The work is to widen the protocol field to accept the full `WaitOnExitValue` shape (boolean, string, or callback) and expose it in `vscode.d.ts` or a proposed-API file, with serialization for the callback variant.
