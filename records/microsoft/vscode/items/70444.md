# Issue #70444 — TerminalOptions.waitOnExit API

[https://github.com/microsoft/vscode/issues/70444](https://github.com/microsoft/vscode/issues/70444)

## Summary

Keep this API proposal open: internal terminal retention exists, but extensions still cannot request it through TerminalOptions. The api-proposal label protects the tracking issue from closure, and the discussion documents continuing demand beyond the original Maven scenario.

## Change summary

Expose terminal exit-retention options so extensions can preserve diagnostics after a process exits, optionally only on nonzero exit.

## Best solution

Have the terminal and API owners settle the public exit-retention contract and carry it through API finalization. Preserve terminated-process output without leaving a reusable shell or requiring extensions to substitute tasks or launcher processes.
