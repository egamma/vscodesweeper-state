# Issue #197823 — No "{}[]" symbols with "Alt Gr" key combo on a Android keyboard cover

[https://github.com/microsoft/vscode/issues/197823](https://github.com/microsoft/vscode/issues/197823)

## Summary

Still reproduces on main: Android Chrome reports AltGr as plain Alt (no AltGraph modifier state), so VS Code's keybinding dispatch intercepts AltGr+digit as Alt+digit shortcuts instead of allowing character input. No fix has landed.

## Change summary

On Android tablets with keyboard covers, AltGr+digit combos (for {}[] on German/French layouts) trigger keybinding shortcuts instead of typing the expected characters.

## Best solution

The keybinding dispatch on the web platform needs Android-specific handling: either detect that the platform is Android and suppress Alt+digit keybindings when the key event produces a printable character (the `key` field shows `{` not `8`), or use the existing `altGraphKey` detection path but handle the Android case where `getModifierState('AltGraph')` may not fire while `altKey` is still true. The fix likely belongs in `src/vs/workbench/services/keybinding/browser/keyboardLayoutService.ts` and possibly the fallback/MacLinux keyboard mappers.
