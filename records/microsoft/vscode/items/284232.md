# Issue #284232 — Git - Blame shows 2 weeks when it is 3 weeks minus 3 hours

[https://github.com/microsoft/vscode/issues/284232](https://github.com/microsoft/vscode/issues/284232)

## Summary

Team-authored issue with a confirmed bug in the built-in git blame relative date formatting — `Math.floor` truncates instead of rounding, and an open community PR (#306558) already targets the fix. Keeping open per team-author policy.

## Change summary

Git blame's relative date display uses `Math.floor` causing times just under a boundary (e.g. 3 weeks minus 3 hours) to show the lower unit (2 weeks instead of 3).

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/306558 which proposes changing `Math.floor` to `Math.round` in `extensions/git/src/util.ts`. The fix is small and localized — all the `Math.floor` calls in `fromNow()` should likely become `Math.round` for consistency with GitHub's own rounding behavior.
