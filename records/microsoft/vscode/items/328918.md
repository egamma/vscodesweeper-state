# Issue #328918 — New Modern UI is uncomfortable

[https://github.com/microsoft/vscode/issues/328918](https://github.com/microsoft/vscode/issues/328918)

## Summary

Real design feedback on the new experimental Modern UI, which is being rolled out via an A/B experiment (`experiment: { mode: 'auto' }` on `workbench.experimental.modernUI`) rather than a user opt-in — several independent commenters corroborate clutter/border/scrollbar complaints and one reports a performance regression, so this is substantive feedback for the workbench team, not a support question needing more info.

## Change summary

Reporter and multiple commenters dislike the new default-enabled 'Modern UI' styling (thick borders, scrollbar padding, tab-as-button look) and one reports it causing noticeable UI lag.

## Best solution

Route this design feedback to the workbench/UI team currently owning the Modern UI rollout (src/vs/workbench/browser/workbench.contribution.ts LayoutSettings.MODERN_UI, src/vs/workbench/contrib/styleOverrides/browser/styleOverrides.contribution.ts) so it feeds the design-system refresh iteration; the separate performance complaint in comment 4 may warrant its own perf investigation if it repros outside this thread.
