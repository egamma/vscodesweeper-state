# Issue #177895 — Test: Does not detect `orca` screen reader for Linux Mint or Ubuntu

[https://github.com/microsoft/vscode/issues/177895](https://github.com/microsoft/vscode/issues/177895)

## Summary

Still a valid upstream issue: VS Code relies entirely on Electron/Chromium's AT-SPI detection for screen readers on Linux, and no VS Code-side fix has been implemented. The detection gap for orca on Linux Mint/Ubuntu persists on current main.

## Change summary

VS Code does not detect the orca screen reader on Linux Mint or Ubuntu, so accessibility mode is not auto-enabled.

## Best solution

Either fix upstream in Electron/Chromium's AT-SPI integration, or add a VS Code-side fallback that checks for running orca (e.g. via D-Bus or process detection) and sets accessibility support accordingly. The entry point would be around the window environment setup that feeds `accessibilitySupport` into the renderer.
