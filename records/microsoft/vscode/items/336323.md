# Issue #336323 — Show thumbs-up and thumbs-down feedback actions in Agent Host chats

[https://github.com/microsoft/vscode/issues/336323](https://github.com/microsoft/vscode/issues/336323)

## Summary

Team-authored, freshly filed bug report; traced the cause in the checkout — the thumbsup/thumbsdown menu items are gated on `ChatContextKeys.extensionParticipantRegistered`, which Agent Host sessions never set, so the feedback controls are hidden even though nothing about vote handling depends on the harness.

## Change summary

Assistant responses rendered through Agent Host don't show the thumbs-up/thumbs-down feedback actions that other chat sessions get.

## Best solution

In src/vs/workbench/contrib/chat/browser/actions/chatTitleActions.ts, OR the existing `chatIsAgentHostSession`/`ChatContextKeyExprs.isAgentHostSession` context key into the four menu `when` clauses for MarkHelpfulAction/MarkUnhelpfulAction alongside `extensionParticipantRegistered`, so Agent Host responses show the same feedback UI.
