# Issue #188716 — Find/Replace indicates the tooltip "enter" is for both "next item" and "replace".  Actual behavior depends on which textbox has focus.

[https://github.com/microsoft/vscode/issues/188716](https://github.com/microsoft/vscode/issues/188716)

## Summary

The misleading tooltip remains on current main, and this issue is now the canonical report for improving it. Keep it open as editor-find polish under discussion.

## Change summary

Show unambiguous, non-focus-dependent shortcuts in the Find/Replace action tooltips while retaining Enter's contextual behavior.

## Best solution

Preserve the current focus-sensitive Enter commands, but have the Find widget advertise the independently usable bindings—F3 for Find Next and Ctrl/Cmd+Shift+1 for Replace—while respecting user keybinding customizations.
