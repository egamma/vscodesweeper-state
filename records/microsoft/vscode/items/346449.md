# Issue #346449 — Add a command/setting to uninstall the on-device dictation model (Nemotron 3.5 ASR)

[https://github.com/microsoft/vscode/issues/346449](https://github.com/microsoft/vscode/issues/346449)

## Summary

Keep open as a feature request: current source provides model installation and dictation enablement, but no supported removal operation. The related model-configuration proposal does not own this disk-space reclamation requirement.

## Change summary

Provide a supported way to remove downloaded on-device dictation files without immediately downloading them again.

## Best solution

Offer an explicit, confirmed removal operation for the built-in dictation model, with safe handling of active transcription and downloads; document whether the runtime is also removed. Reinstallation should occur only when the user next explicitly starts on-device dictation.
