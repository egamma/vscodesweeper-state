# Issue #346449 — Add a command/setting to uninstall the on-device dictation model (Nemotron 3.5 ASR)

[https://github.com/microsoft/vscode/issues/346449](https://github.com/microsoft/vscode/issues/346449)

## Summary

A real model-removal gap remains: current dictation settings and the local-package installation command do not reclaim downloaded files. Keep this request open; the related model-configuration proposal does not explicitly cover uninstalling dictation assets.

## Change summary

Provide a supported way to remove downloaded dictation assets and reclaim disk space without immediately downloading them again.

## Best solution

Offer a confirmed removal action for the on-device dictation model, with clearly defined runtime cleanup behavior and documented storage locations. Removal should leave dictation unprepared until the user explicitly starts it again.

## Evidence

- **Existing command does not cover removal:** src/vs/workbench/contrib/chat/electron-browser/actions/installDictationModelAction.ts registers workbench.action.chat.installDictationModel and calls importModel into environmentService.cacheHome/chatDictationModels. Searches of current command registrations and dictation source found no uninstall counterpart.
- **Settings do not reclaim disk space:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts registers dictation.enabled and dictation.model for availability and backend selection, not deletion. src/vs/platform/localTranscription/common/localTranscription.ts exposes importModel, start, stop, cancel and status methods, but no model-removal operation.
- **Current asset lifecycle:** src/vs/platform/localTranscription/node/localTranscriptionService.ts:529-623 retains the loaded model and manager, provisions chatDictationRuntime, and downloads the model when model.isCached is false during session preparation. A supported removal flow must account for those live resources; disabling dictation alone does not remove the caches.
- **Documentation gap:** https://code.visualstudio.com/docs/configure/accessibility/voice documents first-use downloading, dictation settings and installation from a local package, but provides neither an uninstall command nor cache-removal instructions.
- **Canonical candidate is related, not equivalent:** Read the complete proposal at https://github.com/microsoft/vscode/issues/342875. It concerns model-choice homes, shared pickers and model identity, including dictation selection, but does not explicitly request removal of downloaded dictation files. It therefore does not establish the same observable requirement needed for a duplicate close on this re-reviewed item.
- **Reporter-linked issues have different scope:** https://github.com/microsoft/vscode/issues/332537 describes blocked downloads, manual installation and the cache paths. https://github.com/microsoft/vscode/issues/335444 requests a stable enterprise distribution mechanism. Neither owns uninstalling already-installed assets.
- **Search scope:** An unauthenticated GitHub search for open dictation uninstall issues returned this issue and https://github.com/microsoft/vscode/issues/342875. A broader removal search was rate-limited; no verified canonical or concrete implementing commit was established.
