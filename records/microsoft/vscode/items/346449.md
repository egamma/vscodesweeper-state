# Issue #346449 — Add a command/setting to uninstall the on-device dictation model (Nemotron 3.5 ASR)

[https://github.com/microsoft/vscode/issues/346449](https://github.com/microsoft/vscode/issues/346449)

## Summary

The requested removal capability remains missing: current dictation settings select or disable transcription, but do not reclaim downloaded model files. Keep this request open; the related model-configuration proposal does not explicitly cover uninstalling dictation assets.

## Change summary

Provide a supported way to remove downloaded on-device dictation assets without downloading them again until dictation is explicitly started.

## Best solution

Provide a discoverable, confirmed removal action owned by the built-in dictation feature, with clear documentation of the assets removed and subsequent on-demand download behavior.

- **Existing settings do not reclaim storage:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts registers dictation.enabled and dictation.model for availability and transcription-model selection. Neither setting offers removal of cached model or runtime files.
