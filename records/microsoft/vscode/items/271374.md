# Issue #271374 — Code Review: "Illegal value for `line`" error after CCR in SCM

[https://github.com/microsoft/vscode/issues/271374](https://github.com/microsoft/vscode/issues/271374)

## Summary

The failure remains source-reproducible on current main: CCR converts an excluded service comment into a review comment without checking whether its line still exists in the edited document. This team-authored issue should remain open for a bounded fix and regression test.

## Change summary

Running Copilot code review after deleting code can fail with “Illegal value for `line`” when an excluded review reference points outside the edited document.

## Best solution

CCR should safely discard review references whose locations do not map to the current document, while continuing the review and preserving all valid generated or skipped comments.
