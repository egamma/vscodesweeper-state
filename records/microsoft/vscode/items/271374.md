# Issue #271374 — Code Review: "Illegal value for `line`" error after CCR in SCM

[https://github.com/microsoft/vscode/issues/271374](https://github.com/microsoft/vscode/issues/271374)

## Summary

Still reproduces on main: `createReviewComment` in `githubReviewAgent.ts` calls `document.lineAt(ghComment.data.line - 1)` without bounds checking — when the API returns a line number beyond the document's line count (e.g. after code removal), it throws "Illegal value for `line`". The bug is unguarded on current `main`.

## Change summary

Running Copilot Code Review after removing code from a file throws "Illegal value for `line`" when the API returns a comment referencing a line number that no longer exists in the document.

## Best solution

Guard `createReviewComment` in `extensions/copilot/src/extension/review/node/githubReviewAgent.ts` to clamp `ghComment.data.line` to the document's valid line range before calling `document.lineAt()`. Also update the `ExcludedComment.exclusion_reason` union type to include `'no_matched_diff_hunk'` to match the actual API response.
