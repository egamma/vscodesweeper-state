# Issue #346834 — Agents window: Changes view closes after switching to another session and back (sessions.experimental.layoutScope = chat)

[https://github.com/microsoft/vscode/issues/346834](https://github.com/microsoft/vscode/issues/346834)

## Summary

The reported Changes-only restoration failure remains in current source: per-chat restoration discards saved visibility unless a non-docked editor exists. Keep this accepted, team-authored regression open; the nearest related reports concern Files behavior rather than the same symptom.

## Change summary

Preserve an explicitly opened Changes pane when switching away from a chat and returning to it.

## Best solution

Restore the returning chat's explicitly opened Changes composition without revealing panes that were never opened or intentionally closed. Preserve the existing empty-owner and draft lifecycle safeguards.
