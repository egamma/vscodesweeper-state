[https://github.com/microsoft/vscode/issues/346834](https://github.com/microsoft/vscode/issues/346834)

## Summary

Keep this team-authored regression open: current source suppresses the saved Changes-only composition when returning to an existing chat. The suppression is also documented and tested, so the owner should reconcile that policy with preserving an explicitly opened Changes view.

## Change summary

An explicitly opened Changes pane disappears after switching away from and back to a session with layoutScope set to chat.

## Best solution

Preserve the user's explicitly opened Changes pane across session round trips without automatically opening panes the user never requested. Resolve this in desktop layout restoration, with coverage distinguishing explicit user intent from automatic docked-tab creation.
