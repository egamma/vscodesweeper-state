# Issue #346975 — Missing-source copy or rename deletes the existing overwrite destination

[https://github.com/microsoft/vscode/issues/346975](https://github.com/microsoft/vscode/issues/346975)

## Summary

Current source confirms that overwrite-enabled copy and rename can delete an existing destination before discovering a missing source. Keep open while the linked fix PR is reviewed and landed.

## Change summary

Preserve existing destination files and directories when an overwrite copy or rename fails because its source is already missing.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/346985 so missing-source failures preserve destination contents without changing atomic moves, case-only renames, or promising general transactional behavior.
