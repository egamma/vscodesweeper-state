# Issue #186425 — Keyboard shortcuts for showing/hiding unchanged regions

[https://github.com/microsoft/vscode/issues/186425](https://github.com/microsoft/vscode/issues/186425)

## Summary

Bulk show/collapse commands now exist, but they do not cover keyboard navigation and expansion of individual unchanged regions in the standard diff editor. Keep this team-authored Backlog request open for the interaction-design decision already requested by the maintainer.

## Change summary

Provide discoverable keyboard interactions for navigating, expanding, and collapsing individual unchanged regions in the diff editor.

## Best solution

Agree on a consistent per-region keyboard interaction in the diff editor, including how focus moves between text and collapsed indicators. Preserve the existing bulk commands while making individual region actions accessible without a mouse.
