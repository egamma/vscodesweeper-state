# Issue #192012 — Add option to turn off rich content notebook search results

[https://github.com/microsoft/vscode/issues/192012](https://github.com/microsoft/vscode/issues/192012)

## Summary

Keep open: the existing experimental setting controls closed notebooks only, so it does not provide the requested raw metadata search when notebooks are open. The stated prerequisite also remains unmet: closed-notebook rich-content search still defaults to false.

## Change summary

Provide an option to disable rich-content notebook search and retain raw-file search and replacement, including notebook metadata.

## Best solution

Preserve an explicit raw-file search mode for metadata workflows across both open and closed notebooks before making rich-content notebook search universal. Coordinate that behavior with result refresh and replacement so opening a notebook does not remove metadata matches.

## Evidence

- **Existing capability is partial:** src/vs/workbench/contrib/search/browser/search.contribution.ts:210-214 registers search.experimental.closedNotebookRichContentResults with default false and explicitly limits its description to closed notebooks. It does not cover the requested opt-out for open notebooks.
- **Current search path:** In src/vs/workbench/contrib/search/browser/notebookSearch/notebookSearchService.ts, notebookSearch always calls getLocalNotebookResults for existing notebook widgets; the experimental setting gates only getClosedNotebookResults. Local search uses widget.find with markup input, preview, code input, and output options, not raw serialized metadata.
- **Raw results are suppressed:** NotebookSearchService records locally scanned notebook resources even when no cell matches exist. SearchModel.search passes those resource sets to SearchService.textSearchSplitSyncAsync, whose provider-progress filtering in src/vs/workbench/services/search/common/searchService.ts:140-145 suppresses raw-file results for those resources.
- **Original metadata workflow:** https://github.com/microsoft/vscode/issues/190355#issuecomment-1699073716 confirms that disabling the experimental setting restores metadata search for closed notebooks, but opening the notebook removes the results. https://github.com/microsoft/vscode/issues/190355#issuecomment-1703123777 explicitly establishes this issue as the follow-up for an opt-out covering all notebooks.
