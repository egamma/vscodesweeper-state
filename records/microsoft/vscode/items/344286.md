# Issue #344286 — Testing: Ansi white icon color not visible in Solarized Light theme

[https://github.com/microsoft/vscode/issues/344286](https://github.com/microsoft/vscode/issues/344286)

## Summary

Keep open: the tester documented an invisible session-group icon, and current source directly uses Solarized Light's near-white ANSI token for the icon. The discussion leaves a real product decision about black/white color semantics across light, dark, and high-contrast themes; this team-authored report should not be declined.

## Change summary

Selecting ANSI White for a session-group icon makes it disappear in Solarized Light, while black/white choices behave inconsistently across theme variants.

## Best solution

Ensure session-group color choices remain recognizable across supported themes, with an explicit decision on whether Black and White represent literal hues or theme-adaptive foregrounds. Resolve the session-group presentation contract before considering changes to shared terminal ANSI colors.
