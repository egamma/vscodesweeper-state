# Issue #270731 — Editor can process e.g. `deleteLeft` out of order when command is sent from an extension keybinding function

[https://github.com/microsoft/vscode/issues/270731](https://github.com/microsoft/vscode/issues/270731)

## Summary

Legitimate race condition: when an extension keybinding intercepts a key and calls executeCommand asynchronously via the extension host, subsequent keystrokes from the system input queue can be processed before the command completes. No fix found on main.

## Change summary

Extension keybinding handlers that call commands like deleteLeft can have those commands execute out of order relative to subsequent keystrokes from the system input queue.

## Best solution

The keybinding dispatch path needs to either block subsequent keystroke processing until the extension command resolves, or queue keystrokes that arrive while an extension keybinding command is in flight. The fix likely involves src/vs/platform/keybinding/common/abstractKeybindingService.ts and the extension host command execution path.
