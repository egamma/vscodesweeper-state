# Issue #199613 — Multi diff editor does not support diff view for Notebooks

[https://github.com/microsoft/vscode/issues/199613](https://github.com/microsoft/vscode/issues/199613)

## Summary

Keep open: the SCM multi-diff editor still resolves notebook files as text rather than notebook-aware changes. Existing notebook diff capabilities cover a separate editor path, not this request.

## Change summary

Show notebook-aware diffs instead of raw notebook JSON within the multi-file diff editor.

## Best solution

Support notebook-aware change review alongside ordinary file diffs in the SCM multi-diff editor, reusing the existing notebook diff machinery where appropriate. Plan the integration with the multi-diff and notebook owners before implementation.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditorInput.ts`, `src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditor.ts`, `src/vs/editor/browser/widget/multiDiffEditor/diffEditorItemTemplate.ts`, `src/vs/workbench/contrib/notebook/browser/diff/notebookMultiDiffEditor.ts`, `src/vs/workbench/contrib/notebook/browser/diff/notebookMultiDiffEditorInput.ts`, `src/vs/workbench/contrib/notebook/browser/diff/notebookDiffViewModel.ts`
- **Validation:** In a Git workspace, commit a notebook and a text file, then modify notebook cell content and the text file. Open the SCM multi-file diff and verify that notebook changes are readable as notebook-aware changes alongside the normal text diff, rather than serialized JSON. Also review a newly added notebook containing an 'abcs' cell through View Untracked Changes and verify that its cell content is visible.
- **Behavior:**

  > The SCM multi-file diff should let users review notebook changes without interpreting serialized notebook JSON. A review containing both a notebook and an ordinary text file should retain normal text diff behavior while presenting notebook changes meaningfully. Newly added notebooks must expose their cell content in View Untracked Changes. Opening an individual notebook diff must continue to work.
- **Trace:**

  > MultiDiffEditorInput._createModel in src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditorInput.ts resolves every original and modified resource as an IResolvedTextEditorModel; DiffEditorItemTemplate renders those items with the shared text DiffEditorWidget. A separate notebook-aware path already exists: NotebookMultiTextDiffEditor.setInput resolves a notebook model, computes NotebookDiffViewModel, and passes its resources through NotebookMultiDiffEditorWidgetInput. That separate capability does not transform notebook file entries in the SCM multi-file model. The planning boundary is how notebook-aware resources participate in a mixed-file review and its shared navigation and layout, without disrupting ordinary text diffs or individual notebook diffs. https://github.com/microsoft/vscode/issues/211133 supplies the added-notebook case and was explicitly consolidated into https://github.com/microsoft/vscode/issues/199613. Source inspection established the missing integration, but did not establish a complete bounded design or enumerate all consumers of the shared widget.

## Evidence

- **Current multi-file model path:** In src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditorInput.ts, MultiDiffEditorInput._createModel resolves original and modified resource URIs through ITextModelService.createModelReference and constructs DiffItemSource objects from textEditorModel. There is no notebook-aware resource expansion in that path.
- **Current rendering boundary:** src/vs/editor/browser/widget/multiDiffEditor/diffEditorItemTemplate.ts constructs a DiffEditorWidget for each document item. Notebook JSON is treated as ordinary text; the alternative placeholder handles binary files, not notebook-aware diffs.
- **Existing capability does not cover the ask:** The setting notebook.diff.enablePreview is registered in src/vs/workbench/contrib/notebook/browser/notebook.contribution.ts. NotebookMultiTextDiffEditor.setInput in src/vs/workbench/contrib/notebook/browser/diff/notebookMultiDiffEditor.ts resolves a notebook pair, computes NotebookDiffViewModel, and supplies cell-level resources through NotebookMultiDiffEditorWidgetInput. This supports comparing an individual notebook, not automatically rendering notebooks inside the SCM multi-file input.
