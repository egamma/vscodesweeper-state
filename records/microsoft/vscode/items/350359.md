# Issue #350359 — Agents window: feedback overview ruler re-sets decorations in every editor on other sessions' feedback changes

[https://github.com/microsoft/vscode/issues/350359](https://github.com/microsoft/vscode/issues/350359)

## Summary

The cross-session decoration churn remains directly traceable on current main. Keep this open: the neighboring feedback-batching reports address event production, not this listener's unnecessary work for unrelated sessions.

## Change summary

Prevent feedback and visibility changes in unrelated sessions from resetting an editor's feedback overview-ruler decorations.

## Best solution

The overview-ruler contribution should update only for feedback events relevant to its displayed or currently resolved session, while preserving scope, model, configuration, and session-reassignment updates.
