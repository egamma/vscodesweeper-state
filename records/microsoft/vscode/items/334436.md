# Issue #334436 — Support prefix-based history navigation in the Search view

[https://github.com/microsoft/vscode/issues/334436](https://github.com/microsoft/vscode/issues/334436)

## Summary

The requested prefix-filtered history navigation remains absent from the Search view. Keep this open as a feature request; the existing history commands navigate all entries, and no older issue covering the same observable behavior was verified.

## Change summary

Filter Search view history navigation to entries beginning with the typed input, while preserving ordinary navigation when the input is empty.

## Best solution

Consider prefix-filtered navigation for the Search input while retaining unrestricted history navigation for empty input. Any change to the shared history widget should preserve other consumers' existing behavior unless broader adoption is explicitly approved.
