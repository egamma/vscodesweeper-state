# Issue #322609 — "Go To" Button Spinner is Eccentric While Executing

[https://github.com/microsoft/vscode/issues/322609](https://github.com/microsoft/vscode/issues/322609)

## Summary

Valid visual polish issue: the 'Go To' toolbar spinner uses `codicon-sync` with spin modifier; despite the `transform-origin: center center` fix shipped in 1.109.0, the sync glyph itself is asymmetric, causing visible wobble during rotation. Still present on main.

## Change summary

The notebook toolbar 'Go To' button spinner wobbles because the sync codicon glyph is not rotationally symmetric around its center.

## Best solution

Either adjust the codicon-sync SVG in vscode-codicons to be rotationally symmetric, or use a different icon (e.g. `codicon-loading` which is designed for spinning) for the notebook executing state toolbar item in `src/vs/workbench/contrib/notebook/browser/controller/executeActions.ts`.
