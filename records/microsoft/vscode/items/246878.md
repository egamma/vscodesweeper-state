# Issue #246878 — Accessible View for Copilot Agent: show file changes as one-liner instead of entire diff

[https://github.com/microsoft/vscode/issues/246878](https://github.com/microsoft/vscode/issues/246878)

## Summary

The accessibility mismatch remains in current source: file-edit markdown becomes a compact file card visually, but Accessible View renders the underlying code block in full. Keep this open; no verified canonical or fixing commit was found.

## Change summary

Present agent file edits in Chat Accessible View as concise filename and added/removed-line summaries rather than requiring navigation through the entire code block.

## Best solution

Make Chat Accessible View expose the same file-edit summary as the visual card while preserving access to detailed changes through Accessible Diff View. Settle whether summaries replace edit code blocks by default or are available through a verbosity toggle; ordinary explanatory code blocks should remain readable.
