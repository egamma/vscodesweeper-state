# Issue #248175 — Option to toggle vscode outline in python scripts to display markdown titles instead of function/class names

[https://github.com/microsoft/vscode/issues/248175](https://github.com/microsoft/vscode/issues/248175)

## Summary

Keep open: the existing notebook heading filters do not cover the requested outline for interactive Python source files. No verified fix or older canonical covering the same behavior was found, and the Backlog milestone rules out declining this accepted request merely for inactivity.

## Change summary

Allow interactive Python scripts to display Markdown section headings in the Outline instead of function and class names.

## Best solution

Provide an opt-in heading-based outline for interactive Python source files while preserving the normal symbol outline. Establish whether heading extraction belongs in the interactive Python integration or its document-symbol provider; notebook-only filters do not supply this capability.
