# Issue #248175 — Option to toggle vscode outline in python scripts to display markdown titles instead of function/class names

[https://github.com/microsoft/vscode/issues/248175](https://github.com/microsoft/vscode/issues/248175)

## Summary

Valid feature request for showing markdown headings in the outline when using Python interactive scripts (# %% cells). No existing capability covers this — the notebook outline supports markdown headers in .ipynb files but not in .py interactive scripts. Already triaged with correct labels and milestone.

## Change summary

Show markdown block titles in the VS Code outline view when working with Python interactive scripts (# %% cell mode) instead of only function/class names.

## Best solution

Extend the notebook outline entry factory to recognize markdown-style headers in interactive Python script cells (the `# %%` delimited blocks). The work likely belongs in `src/vs/workbench/contrib/notebook/browser/viewModel/notebookOutlineEntryFactory.ts` and the interactive editor's integration with the notebook outline system.
