# Issue #27905 — Have ctrl+click work the same way as in Visual Studio

[https://github.com/microsoft/vscode/issues/27905](https://github.com/microsoft/vscode/issues/27905)

## Summary

A real editor interaction gap remains: current main supports word selection by double-clicking and dragging, but not Visual Studio-style Ctrl+click and Ctrl+drag selection. With 26 community upvotes and a Backlog milestone, this established canonical request should remain open.

## Change summary

Add Visual Studio-style Ctrl+click, Ctrl+Shift+click, and Ctrl+drag word selection behavior.

## Best solution

Add a configurable word-selection mouse modifier in the editor input path, coordinating it with multi-cursor and go-to-definition gestures. The implementation likely belongs in the editor view controller and mouse gesture configuration, potentially as part of the broader mouse-shortcut work tracked by https://github.com/microsoft/vscode/issues/3130.
