# Issue #299550 — Hooks not visible in chat

[https://github.com/microsoft/vscode/issues/299550](https://github.com/microsoft/vscode/issues/299550)

## Summary

Valid request from a team member: successful hook executions are intentionally hidden in chat (line 2949 of chatListRenderer.ts renders them as no-content). No changes have landed since the issue was filed. Keeping open per team-authored rules.

## Change summary

Hooks that pass (no stopReason or systemMessage) should show a visible indicator in chat, such as a greyed-out 'UserPromptSubmit triggered' message.

## Best solution

Extend `renderHookPart` in `chatListRenderer.ts` to render a lightweight, muted indicator for successful hooks instead of calling `renderNoContent`. The `ChatHookContentPart` could gain a 'passed' rendering mode alongside the existing blocked/warning modes.
