## Evidence

- **Confirmed report and incomplete workaround:** https://github.com/microsoft/vscode/issues/176494 records a regression from 1.75.1 to 1.76 in Markdown math. The maintainer suggested "[markdown]": { "editor.language.brackets": [] }; the reporter confirmed that removes the problem but also removes bracket selection highlighting.
- **Current language configuration:** extensions/markdown-basics/language-configuration.json retains {}, [], and () in brackets while setting colorizedBracketPairs to []. This preserves matching and excludes complete Markdown bracket pairs from colorization; it does not prevent unmatched-bracket decorations.
