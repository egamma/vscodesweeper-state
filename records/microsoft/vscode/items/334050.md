[https://github.com/microsoft/vscode/issues/334050](https://github.com/microsoft/vscode/issues/334050)

## Summary

The stale username across reloads and restarts is supported by current source: persisted GitHub sessions reuse their stored account label without refreshing GitHub user information. Keep this correctly routed issue open; the additional failure after signing out and back in still needs diagnosis.

## Change summary

Refresh the GitHub username displayed in Accounts after the account is renamed on github.com.

Accounts should eventually display the current GitHub login for the same stable account identity, without requiring credential removal or disrupting existing authorization. Diagnose the reported sign-out/sign-in failure before settling the refresh and account-update behavior.
