# Issue #212363 — Support distinguishing workspace folders based on query param differences

[https://github.com/microsoft/vscode/issues/212363](https://github.com/microsoft/vscode/issues/212363)

## Summary

A confirmed capability gap remains on current main: workspace lookup intentionally ignores query and fragment components. Keep this Backlog request open for a consistent workspace-wide design rather than addressing individual UI symptoms.

## Change summary

Distinguish multi-root workspace folders whose URIs differ only by query parameters.

## Best solution

Define query-aware workspace-folder identity in `src/vs/platform/workspace/common/workspace.ts`, then validate all consumers of `IWorkspaceContextService.getWorkspaceFolder`, including breadcrumbs, titles, editor selection, and Explorer reveal behavior.
