# Issue #125227 — Hand mouse pointer is shown when drag and drop is disabled

[https://github.com/microsoft/vscode/issues/125227](https://github.com/microsoft/vscode/issues/125227)

## Summary

Keep open: this is mid-verification with verification-found, and the latest maintainer confirmation says the misleading drag cursor persists for code cells despite being fixed for markdown cells. Current source still contains an unconditional grab cursor on the cell gutter.

## Change summary

Notebook code-cell drag handles should not display a drag cursor when notebook.dragAndDropEnabled is false.

## Best solution

Complete verification of the remaining code-cell case and make the drag affordance reflect whether cell dragging is enabled. Preserve pointer feedback for actual clickable controls, including folding and output-collapse controls.
