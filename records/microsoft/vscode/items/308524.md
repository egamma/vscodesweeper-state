# Issue #308524 — Update fails with OS error 32 when renaming Code.exe (file locked by child process)

[https://github.com/microsoft/vscode/issues/308524](https://github.com/microsoft/vscode/issues/308524)

## Summary

Real update failure on Windows due to missing retry logic in the inno-updater rename step. An open fix PR exists in microsoft/inno-updater but hasn't merged yet; a team member is actively engaged. Keep open until the fix lands.

## Change summary

VS Code's Windows updater fails with OS error 32 when Code.exe is locked by a child process because the rename step has no retry logic.

## Best solution

Land the retry logic in https://github.com/microsoft/inno-updater/pull/69, and complement it with the COM surrogate / crashpad-handler termination work already underway in the VS Code repo (commit c2a42605f78 and issue https://github.com/microsoft/vscode/issues/320573) so child processes are cleaned up before the rename attempt.
