# Issue #318192 — Add official Mermaid chart extension as a recommended extension for .mmd and .mermaid file and markdown file with ```mermaid fence  types in product.json

[https://github.com/microsoft/vscode/issues/318192](https://github.com/microsoft/vscode/issues/318192)

## Summary

Keep this accepted feature request open: it has 26 upvotes and reached Backlog through the community process. Built-in Mermaid rendering partially addresses preview discovery, but does not deliver the requested recommendation of MermaidChart.vscode-mermaid-chart; recommending it, especially for Markdown with built-in rendering, still needs a product decision.

## Change summary

Recommend MermaidChart.vscode-mermaid-chart when users open .mmd or .mermaid files, or Markdown containing Mermaid fences.

## Best solution

Decide whether to recommend Mermaid Chart for standalone diagram files and whether that recommendation should also appear for Markdown already supported by the built-in renderer. Any approved recommendation should use the existing file-based recommendation system and preserve installed-extension filtering and notification preferences.
