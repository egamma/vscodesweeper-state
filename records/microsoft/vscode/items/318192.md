# Issue #318192 — Add official Mermaid chart extension as a recommended extension for .mmd and .mermaid file and markdown file with ```mermaid fence  types in product.json

[https://github.com/microsoft/vscode/issues/318192](https://github.com/microsoft/vscode/issues/318192)

## Summary

Valid request for file-based extension recommendations for `.mmd`/`.mermaid` files, but the landscape has shifted significantly since filing: VS Code now ships a built-in `mermaid-markdown-features` extension (commit ea086aed286, May 2026) that covers mermaid rendering in markdown, notebooks, and chat. The built-in does not register `.mmd`/`.mermaid` as language file extensions, so a gap remains for standalone mermaid files — but the right next step may be extending the built-in rather than recommending a third-party extension.

## Change summary

Request to add the MermaidChart marketplace extension as a recommended extension for `.mmd` and `.mermaid` file types in product.json.

## Best solution

Evaluate whether the built-in `mermaid-markdown-features` extension should be extended to handle standalone `.mmd`/`.mermaid` files (language registration, syntax highlighting, preview). If so, this recommendation request becomes moot. If standalone mermaid files remain out of scope for the built-in, then the recommendation could be considered — but the bar for recommending a specific third-party commercial extension in product.json is high.
