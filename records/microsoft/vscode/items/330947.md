# Issue #330947 — Markdown opened with md editor and can't see comment

[https://github.com/microsoft/vscode/issues/330947](https://github.com/microsoft/vscode/issues/330947)

## Summary

Real gap traced in source: navigating to a comment in a Markdown file can silently fail to reveal because the editor is opened without forcing the default text editor, so a custom editor association (e.g. Markdown Preview) for `.md` files takes over and there's no code editor control to reveal the comment widget in.

## Change summary

Navigating to the next/previous comment thread located in a Markdown file opens the file but doesn't show the comment.

## Best solution

In revealCommentThread (src/vs/workbench/contrib/comments/browser/commentsController.ts), force the default text editor via `override: DEFAULT_EDITOR_ASSOCIATION.id` when opening the resource, matching the pattern already used elsewhere (e.g. preferencesService.ts, notebookEditor.ts) to guarantee a code editor control is returned.
