# Issue #137484 — Optimize ripgrep glob patterns for file search

[https://github.com/microsoft/vscode/issues/137484](https://github.com/microsoft/vscode/issues/137484)

## Summary

The optimization gap remains on current main: file search forwards anchored include globs without the traversal-pruning rewrite used by text search. Keep this accepted, team-authored improvement open; the author also confirmed its relevance in December 2024.

## Change summary

Optimize file-search include globs so constrained workspaceContains and findFiles queries avoid traversing unrelated workspace subtrees.

## Best solution

Give the ripgrep file-search argument builder equivalent traversal pruning for constrained include globs while preserving file matches, exclusions, and platform-specific normalization.
