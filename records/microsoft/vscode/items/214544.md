## Evidence

- **Confirmed reproduction independent of extensions:** https://github.com/microsoft/vscode/issues/214544#issuecomment-2159454271 reports reproduction with every extension disabled. https://github.com/microsoft/vscode/issues/214544#issuecomment-2162759480 supplies a dump and the concrete sequence: fold code, hover over the folded line's '>' icon, crash.
- **Same-version packaging comparison:** https://github.com/microsoft/vscode/issues/214544#issuecomment-2162791770 reports that replacing Snap with the Debian package of the same VS Code 1.90.0 version resolves the problem; https://github.com/microsoft/vscode/issues/214544#issuecomment-2162934263 corroborates the Snap connection. This supports a native packaging/runtime problem, not attribution to an installed extension.
- **Linked issue and upstream diagnosis:** The discussion explicitly links https://github.com/microsoft/vscode/issues/212494. Its maintainer diagnosis at https://github.com/microsoft/vscode/issues/212494#issuecomment-2166941209 identifies an X11 software-compositor path accessing an unavailable resource bundle in the GPU process. That issue is now closed and verified, so it is not an eligible duplicate canonical.
- **Concrete upstream fix and shipping evidence:** Chromium commit https://chromium.googlesource.com/chromium/src/+/f8010390a47322ddfe62aba8f7e568a122240dcc changes ui/base/x/x11_display_util.cc to restrict localized display labels to the browser process, avoiding GPU-process resource-bundle access. https://github.com/microsoft/vscode/pull/215954 explicitly backports that change; https://github.com/microsoft/vscode/issues/212494#issuecomment-2177372049 records verification and integration into the 1.90.2 release. This proves a related fix, not that this report's dump has the same signature.
- **Comparable hover-triggered crash:** In https://github.com/microsoft/vscode/issues/214493#issuecomment-2155049063, a maintainer matches a Snap 1.90.0 hover-triggered crash dump to the linked runtime issue. This strengthens the connection but does not independently verify the folding-control case.
