# Issue #214544 — Crash when folding code

[https://github.com/microsoft/vscode/issues/214544](https://github.com/microsoft/vscode/issues/214544)

## Summary

This is the same snap-specific SIGTRAP crash as #212494, caused by the ANGLE GL backend attempting to load XRandr display info from an inaccessible resource pak. Fixed by forcing the software GL backend for snap in commit a7a94fbdbdf, shipped in 1.90.1. The canonical issue is closed and verified.

## Change summary

VS Code snap package crashes (turns white and disappears) when folding code or hovering over fold icons on Linux.

## Best solution

Keep the shipped fix (software GL backend for snap); no further change needed. This has been resolved since 1.90.1.
