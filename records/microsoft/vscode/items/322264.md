# Issue #322264 — how can I have the chat mode as the default one in copilot chat

[https://github.com/microsoft/vscode/issues/322264](https://github.com/microsoft/vscode/issues/322264)

## Summary

The requested preference already exists: `chat.newSession.defaultMode` selects Ask, Agent, Plan, or a custom agent for new chat sessions. It shipped before this report, so the central request is already covered by the intended configuration surface.

## Change summary

Allow users to choose Chat/Ask rather than Agent as the default mode for new Copilot Chat sessions.

## Best solution

Use `"chat.newSession.defaultMode": "Ask"` in user or workspace settings. If Ask or Plan remains absent from the picker, that availability problem should be reported separately with reproducible steps because it is distinct from choosing the default.
