# Issue #322264 — how can I have the chat mode as the default one in copilot chat

[https://github.com/microsoft/vscode/issues/322264](https://github.com/microsoft/vscode/issues/322264)

## Summary

The requested preference is already implemented and shipped: `chat.newSession.defaultMode` can select Ask as the default for new chat sessions.

## Change summary

Allow users to choose Ask rather than Agent as the default mode for new Copilot Chat sessions.

## Best solution

Use `"chat.newSession.defaultMode": "ask"`; the shipped setting resolves built-in and custom mode names case-insensitively.
