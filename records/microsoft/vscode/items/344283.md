# Issue #344283 — Testing: Focus color and application issues when changing group icon

[https://github.com/microsoft/vscode/issues/344283](https://github.com/microsoft/vscode/issues/344283)

## Summary

Keep open: current source applies the first icon's focus background while the search input owns keyboard focus, and the icon glyph does not inherit the matching focus foreground. This team-authored testing report identifies a concrete accessibility defect, not a stale or completed request.

## Change summary

Correct the group icon picker's initial focus presentation and ensure highlighted icon glyphs contrast with their backgrounds in light and dark themes.

## Best solution

Make the shared icon picker distinguish search focus from grid focus and consistently render contrasting icon foregrounds for its highlighted state. Preserve keyboard navigation, active-descendant announcements, selection, cancellation, reset, and high-contrast behavior.
