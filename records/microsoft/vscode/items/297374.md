# Issue #297374 — Support CDP connections

[https://github.com/microsoft/vscode/issues/297374](https://github.com/microsoft/vscode/issues/297374)

## Summary

Valid team-authored feature request to extend the integrated browser's CDP infrastructure to support external CDP connections (e.g., remote-controlling Code OSS or debug-target websites). No evidence of implementation on main — the existing CDP code handles internal Electron WebContents, not external WebSocket-based CDP connections.

## Change summary

Support CDP connections to external targets (Code OSS instances, debugged websites) from the integrated browser feature, beyond the current internal Electron WebContents CDP usage.

## Best solution

Extend the browser integration's CDP proxy layer (`src/vs/platform/browserView/common/cdp/proxy.ts`) to accept external CDP connections via WebSocket transport, enabling remote control of Code OSS and debug-session websites through the same tooling surface. This connects the integrated browser feature with the existing debug flow's CDP capabilities.
