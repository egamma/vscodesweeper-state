# Issue #206890 — Mac Option is meta => can't type \ (AltGr-+)

[https://github.com/microsoft/vscode/issues/206890](https://github.com/microsoft/vscode/issues/206890)

## Summary

This is a duplicate of the broader request in #127764 for smarter Option key handling on macOS terminals — the ability to use Option as Meta for escape codes while still allowing Option-based character input (like \ on Swedish keyboards). The current `macOptionIsMeta` setting is all-or-nothing by design, passed directly to xterm.js.

## Change summary

When macOptionIsMeta is enabled in the terminal, Option-key character combinations (like \ on Swedish keyboard) stop working, unlike iTerm2 which supports both.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/127764 which tracks supporting selective Option-as-Meta (like iTerm2's per-key approach). This requires upstream xterm.js work to allow Option to act as Meta for escape sequences while still producing characters for AltGr-equivalent combinations.
