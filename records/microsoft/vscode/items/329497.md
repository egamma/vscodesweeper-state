# Issue #329497 — Creating a new terminal in agents window worktree session doesn't open in the worktree

[https://github.com/microsoft/vscode/issues/329497](https://github.com/microsoft/vscode/issues/329497)

## Summary

Fresh, team-authored (sbatten) bug report with a clear repro; hard keep-open rule for team-authored issues applies regardless, and source inspection shows a plausible gap in how the Agents window worktree session's cwd is wired into terminal creation for the default ctrl+` flow.

## Change summary

In an Agents window session started with 'new worktree', pressing ctrl+backtick to open a terminal opens it in the wrong cwd (not the worktree) instead of the session's worktree path.

## Best solution

Trace and fix the cwd wiring in src/vs/sessions/contrib/terminal/browser/sessionsTerminalContribution.ts and src/vs/workbench/contrib/terminal/browser/agentHostTerminalService.ts so the default 'new terminal' flow (ctrl+`) resolves the session's worktree cwd the same way the explicit 'Open Session in Terminal' action does, especially for tunnel/remote-agent-host-backed sessions.
