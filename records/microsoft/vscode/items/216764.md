# Issue #216764 — VSCode "Open Editors" causing Logic Apps extension menu context issue

[https://github.com/microsoft/vscode/issues/216764](https://github.com/microsoft/vscode/issues/216764)

## Summary

The core Open Editors context-menu path remains vulnerable to stale resource context on current main, matching the reported disappearance of extension menu actions. This team-authored, accepted bug should remain open for a bounded Open Editors fix.

## Change summary

Opening a custom designer can leave the Open Editors context menu without the clicked workflow.json resource context until the file is focused again.

## Best solution

Ensure the Open Editors context menu evaluates resource and editor context keys from the row being invoked every time it opens, including when focus has left the list and returns to the same row.
