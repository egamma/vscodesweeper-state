# Issue #270585 — Task commands retrieved from a command won't be recognized as absolute

[https://github.com/microsoft/vscode/issues/270585](https://github.com/microsoft/vscode/issues/270585)

## Summary

Verified duplicate: this is the same bug as the canonical issue #160891 — process-type tasks prepend the workspace folder to a command variable's resolved absolute path because `_resolveAndFindExecutable` calls `resolveAsync` which does not resolve `${command:…}` variables, so the unresolved string fails the `path.isAbsolute` check.

## Change summary

Process-type tasks prepend the workspace folder path to the command when the command is resolved from a `${command:…}` variable returning an absolute path.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/160891 — the fix is in `_resolveAndFindExecutable` (and the `findExecutable` path in the extension host), which must resolve command variables before checking `path.isAbsolute`. That issue already carries `help wanted` and is in Backlog.
