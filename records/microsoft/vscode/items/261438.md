# Issue #261438 — Consider adopting a new Python grammar

[https://github.com/microsoft/vscode/issues/261438](https://github.com/microsoft/vscode/issues/261438)

## Summary

Team-authored request to replace the unmaintained MagicPython grammar. The current grammar (MagicStack/MagicPython) was last updated in VS Code in October 2022 and the upstream repo is inactive. The linked Pylance issue discusses alternatives. Stays open as a valid backlog item.

## Change summary

Replace the unmaintained MagicPython TextMate grammar with an actively maintained alternative for Python syntax highlighting.

## Best solution

Evaluate the alternative grammar discussed in microsoft/pylance-release#5824, adopt it in extensions/python/syntaxes/, and update the update-grammar script in extensions/python/package.json accordingly. Python is one of the most popular languages in VS Code, so an actively maintained grammar is important for highlighting quality.
