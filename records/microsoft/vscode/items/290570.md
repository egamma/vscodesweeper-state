# Issue #290570 — Allow support for different editor types of the same file in GoTo/LocationLink

[https://github.com/microsoft/vscode/issues/290570](https://github.com/microsoft/vscode/issues/290570)

## Summary

A real custom-editor API gap remains on current main, and the request has qualified for the Backlog with 24 upvotes. Route it to the custom-editor API owners for design.

## Change summary

Allow definition links to select a specific custom editor type when navigating to a resource.

## Best solution

Design an API-compatible way for a definition target to identify its intended editor type, then propagate that choice through symbol navigation while preserving existing URI-only behavior.
