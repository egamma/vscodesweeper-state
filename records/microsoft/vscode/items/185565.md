# Issue #185565 — Accessibility: Cannot turn off audio cues on a language level

[https://github.com/microsoft/vscode/issues/185565](https://github.com/microsoft/vscode/issues/185565)

## Summary

Keep open: language-specific suppression of editor error sounds remains unsupported in current source. The settings have moved from audioCues to accessibility.signals, but neither their configuration scope nor the playback path implements the requested language override.

## Change summary

Allow error sounds to be disabled for Markdown while remaining enabled for other languages.

## Best solution

Support language-specific sound preferences for editor error signals using the editor model's language and resource context, preserving global defaults and unrelated signal behavior.
