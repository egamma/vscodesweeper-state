## Summary

Keep open for an upstream SDK fix: current VS Code source prevents a corrupt resume from being replaced with an empty session, but the bundled Copilot SDK still owns the event serialization and validation that reject this history. ## Change summary

Prevent negative `data.tokensRemoved` accounting metadata from making a compacted Copilot session unloadable.

## Best solution
