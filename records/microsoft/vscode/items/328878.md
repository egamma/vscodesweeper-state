# Issue #328878 — Outdated "Explore" subagent fallback model list

[https://github.com/microsoft/vscode/issues/328878](https://github.com/microsoft/vscode/issues/328878)

## Summary

The unconfigured Explore agent still uses the reported static fallback list. Existing model overrides do not satisfy the request to periodically reevaluate the default; keep this open for a model-selection decision grounded in exploration quality, latency, cost, and availability.

## Change summary

Periodically reevaluate and refresh Explore's fallback model preferences for users who have not configured an override.

## Best solution

Establish evidence-based selection criteria and a refresh policy for Explore's lightweight default models, then update its fallback preferences accordingly. Preserve explicit user overrides and distinguish Explore research from unrelated auxiliary model requests.
