# Issue #336161 — Agent Host fails to start when XDG_RUNTIME_DIR is unavailable in WSL

[https://github.com/microsoft/vscode/issues/336161](https://github.com/microsoft/vscode/issues/336161)

## Summary

Confirmed on current main: createRandomIPCHandle/createStaticIPCHandle in ipc.net.ts use XDG_RUNTIME_DIR whenever it's set, without checking the directory actually exists, matching the reported EACCES failure. An open PR already targets this fix, so it should be reviewed/landed rather than closed or auto-fixed here.

## Change summary

Agent Host / IPC socket creation fails when XDG_RUNTIME_DIR points to a directory that no longer exists (e.g. after a WSL reboot before systemd recreates /run/user/1000).

## Best solution

Land or iterate on https://github.com/microsoft/vscode/pull/336162, which adds an existence/usability check for XDG_RUNTIME_DIR in src/vs/base/parts/ipc/node/ipc.net.ts and falls back to tmpdir() when the directory is unavailable, mirroring the existing fallback used when the variable is unset.
