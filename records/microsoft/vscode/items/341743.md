# Issue #341743 — Ask is missing from the agent picker after updating to VS Code 1.142.0.

[https://github.com/microsoft/vscode/issues/341743](https://github.com/microsoft/vscode/issues/341743)

## Summary

Thanks for the report. Several users see the same symptom on 1.142.0 (Local harness and Ask missing, Insiders fine). The reporter's follow-up points to workspace-level `github.copilot.enable` / `chat.disableAIFeatures` settings and a 'preview features disabled by organizational policy' log line. That makes this likely a policy or setting gating path, but I did not trace the source to confirm it. The report is complete, so it stays open.

## Change summary

After updating to 1.142.0, the Local harness and the Ask agent no longer appear in the chat pickers when running over Remote SSH, even with the local-agent settings enabled.

## Best solution

Find which policy or setting gate hides the Local harness and Ask mode (candidates are the org preview-features policy and the `github.copilot.enable` or `chat.disableAIFeatures` workspace overrides). Then make the pickers honour the explicit `chat.editor.localAgent.enabled` setting, or surface why Local is unavailable.
