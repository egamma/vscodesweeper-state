# Issue #191640 — Unexpected tab order in moved code

[https://github.com/microsoft/vscode/issues/191640](https://github.com/microsoft/vscode/issues/191640)

## Summary

Keep this accepted diff-editor accessibility polish open. Current source still exposes moved-code captions as keyboard focus targets, and the review found neither a verified fix nor an older canonical owning the reported invisible-first-focus and repeated-announcement behavior.

## Change summary

Make keyboard navigation through moved-code indicators visibly focused and understandable without an unexplained extra Tab stop or repeated caption announcement.

## Best solution

Ensure moved-code overlays have a logical, visibly indicated keyboard focus sequence while keeping their location information and Compare action accessible. First identify the element receiving the initial Tab focus on a current build; the caption action and overlay ordering are concrete investigation leads, not a proven explanation of both symptoms.
