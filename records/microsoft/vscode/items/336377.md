# Issue #336377 — `"workbench.experimental.modernUIEditorTabStyle": "connected"` ignores `tabActiveBorder` color

[https://github.com/microsoft/vscode/issues/336377](https://github.com/microsoft/vscode/issues/336377)

## Summary

Confirmed in source: the new Modern UI editor-tab CSS hardcodes `--modern-ui-editor-tab-active-border: transparent` for both the connected and pill styles and never wires it to a theme color, so `tab.activeBorder` (and related customization) has no effect. Already labeled `bug`, so this stays open pending a fix rather than any decline close; a second comment shows the same gap extends to `modernEditorTab.activeBackground`/`--modern-ui-connected-tab-surface`.

## Change summary

With `workbench.experimental.modernUIEditorTabStyle: "connected"`, a theme's `tab.activeBorder` color is not applied to the active tab, unlike the classic tab renderer.

## Best solution

Register a proper `modernEditorTab.activeBorder` color (mirroring how `modernEditorTab.activeBackground`/`activeForeground` already fall back to legacy `tab.*` colors) and wire it into `--modern-ui-editor-tab-active-border` via a theming participant in connectedEditorTabs.ts/tabs.css, instead of the current hardcoded `transparent`, deciding whether it should default to the borderless look or fall back to the legacy `tab.activeBorder` value.
