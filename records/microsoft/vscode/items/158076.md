# Issue #158076 — Support no-code language server integration

[https://github.com/microsoft/vscode/issues/158076](https://github.com/microsoft/vscode/issues/158076)

## Summary

Keep this accepted API request open: current contribution points do not provide manifest-only language-server integration, and no canonical duplicate was established. Its 24 upvotes and documented Backlog promotion support retaining it for design work.

## Change summary

Allow extensions to declare language-server integration in package.json without bundling client activation and teardown code.

## Best solution

Define a supported declarative language-server contribution contract and managed client lifecycle for straightforward integrations, while preserving programmatic clients for custom behavior. Settle the supported options and runtime coverage before implementation.
