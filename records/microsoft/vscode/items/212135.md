# Issue #212135 — {UI/UX} Show tab bar only if more than one tab

[https://github.com/microsoft/vscode/issues/212135](https://github.com/microsoft/vscode/issues/212135)

## Summary

Keep this accepted Backlog request open: ordinary editor groups still lack automatic tab-bar hiding when only one editor is open. Existing tab-display settings cover manual hiding, not the requested count-dependent behavior, and the request has 25 community upvotes.

## Change summary

Automatically hide the editor tab bar when only one file is open and restore it when additional files are opened.

## Best solution

Provide an opt-in, editor-count-dependent tab visibility mode for the ordinary workbench, preserving existing display modes and defaults. Settle whether the threshold applies to each editor group or the whole window before implementation.
