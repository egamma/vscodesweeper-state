# Issue #212135 — {UI/UX} Show tab bar only if more than one tab

[https://github.com/microsoft/vscode/issues/212135](https://github.com/microsoft/vscode/issues/212135)

## Summary

Keep open: this accepted Backlog feature request has 25 community upvotes, and current VS Code still lacks conditional tab-bar visibility.

## Change summary

Hide the editor tab bar when a group contains only one editor and show it when additional editors open.

## Best solution

If maintainers accept the additional UI configuration, extend the editor-tabs mode and title-control lifecycle under `src/vs/workbench/browser/parts/editor/` to switch visibility as each editor group's count crosses one.
