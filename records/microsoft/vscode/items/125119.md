# Issue #125119 — Bad resize behavior crowed status bar

[https://github.com/microsoft/vscode/issues/125119](https://github.com/microsoft/vscode/issues/125119)

## Summary

Still present on main: the notebook cell status bar uses flex-wrap with overflow:hidden on a fixed-height container, so items wrap out of view on resize rather than truncating gracefully. No fix has landed.

## Change summary

Notebook cell status bar items disappear or render awkwardly when the window is resized to be narrow.

## Best solution

Replace the flex-wrap + overflow:hidden pattern in notebookCellStatusBar.css with a proper truncation strategy (e.g. flex-shrink with text-overflow:ellipsis, or priority-based hiding) so that items degrade gracefully on narrow widths instead of wrapping into hidden overflow.
