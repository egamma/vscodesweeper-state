# Issue #280614 — Tools picker: MCP server entry checking state is not persisted if server is not started

[https://github.com/microsoft/vscode/issues/280614](https://github.com/microsoft/vscode/issues/280614)

## Summary

The selection-loss path remains in current source: an undiscovered MCP server appears in the picker without the toolset identity needed to save its checked state. Keep this team-authored issue open; the existing reproduction also identifies the affected custom-agent tools array.

## Change summary

Remember an MCP server's selection before its tools are discovered, including its wildcard reference in custom-agent files.

## Best solution

Represent server-level selection independently of discovered tools so accepting and reopening the picker preserves it, and selecting GitHub through the agent code lens records github/* without requiring server startup.

- **Exact selection-loss path:** src/vs/workbench/contrib/chat/browser/actions/chatToolPicker.ts:374–387 constructs an MCP bucket without a toolset.
