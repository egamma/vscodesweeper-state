# Issue #89414 — Rename refactoring context actions work on the entire input

[https://github.com/microsoft/vscode/issues/89414](https://github.com/microsoft/vscode/issues/89414)

## Summary

The UX concern is still valid on current main: the 'Apply Refactoring' context-menu action in the refactor preview still applies all checked changes rather than only the right-clicked item, and the label has not been updated to clarify this. Both contributors agreed a wording change would help but it was never implemented.

## Change summary

Right-clicking a refactor row and choosing 'Apply Refactoring' applies all checked changes rather than just the one right-clicked, and the label doesn't clarify this.

## Best solution

Either rename the context-menu command to 'Apply Checked Refactorings' (as joaomoreno suggested) to clarify it applies all checked items, or change the context action to apply only the right-clicked refactoring. The relevant registration is in `src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEdit.contribution.ts` around line 170.
