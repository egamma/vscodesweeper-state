# Issue #89414 — Rename refactoring context actions work on the entire input

[https://github.com/microsoft/vscode/issues/89414](https://github.com/microsoft/vscode/issues/89414)

## Summary

The wording gap remains: row context menus still offer “Apply Refactoring” and “Discard Refactoring”, although both operate on the preview session rather than the clicked row. The discussion supports clarifying their names while preserving their existing scope.

## Change summary

Make refactor-preview context-action labels explicitly describe their session-wide scope.

## Best solution

Clarify the apply and discard action labels in bulkEdit.contribution.ts: applying commits all checked changes, while discarding abandons the entire preview. Preserve the existing checked-state behavior and row-level Toggle Change action.
