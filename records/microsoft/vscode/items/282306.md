# Issue #282306 — [FR] Scoped Context for Copilot Chat in Monorepos and Large Codebases (@package, package index, and Per-Package copilot-instructions.md)

[https://github.com/microsoft/vscode/issues/282306](https://github.com/microsoft/vscode/issues/282306)

## Summary

Valid feature request for monorepo-scoped context in Copilot Chat. Per-package instructions are partially addressed by `chat.instructionsFilesLocations` (users can point at subfolder instruction files), but the core asks — a dedicated @package context scope with per-package smart indexing — remain unimplemented on main.

## Change summary

Add package/subfolder-scoped context for Copilot Chat in monorepos, including a @package command, per-package indexing, and per-package instruction files.

## Best solution

The per-package instructions aspect is partially served by existing `chat.instructionsFilesLocations` and the `.github/copilot-instructions.md` discovery mechanism. The larger ask — scoped workspace indexing per package with smart relevance filtering — would require significant new infrastructure in the Copilot context engine. This remains a valid enhancement for the AI-assisted development experience in large codebases; route to the chat/copilot area for prioritization.
