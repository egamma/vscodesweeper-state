# Issue #178577 — terminal.integrated.env.linux.PATH and terminal.integrated.env.osx.PATH settings break tasks

[https://github.com/microsoft/vscode/issues/178577](https://github.com/microsoft/vscode/issues/178577)

## Summary

The PATH replacement defect is addressed by a merged change that resolves terminal environment substitutions against the shell-enriched environment, including for remote tasks. Current source no longer follows the reported path that replaced the user's PATH with the basic process PATH.

## Change summary

Setting terminal.integrated.env.linux.PATH or terminal.integrated.env.osx.PATH to ${env:PATH} strips shell-derived PATH entries from tasks and can prevent commands from running.

## Best solution

Close the PATH report as completed by https://github.com/microsoft/vscode/commit/2a7cdf83e8f276c7b4446d4a0797808751a89a4b, retaining the shell-aware variable resolution now used by local terminals and remote tasks.
