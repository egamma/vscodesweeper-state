# Issue #178577 — terminal.integrated.env.linux.PATH and terminal.integrated.env.osx.PATH settings break tasks

[https://github.com/microsoft/vscode/issues/178577](https://github.com/microsoft/vscode/issues/178577)

## Summary

Thanks for the detailed steps. The report is complete (a minimal tasks.json plus a `terminal.integrated.env.linux.PATH` setting), and later commenters confirm similar behavior. I could not confirm or refute it from source, and the earlier fix claim was refuted, so this stays open. The given steps are enough to retest on a current build.

## Change summary

Setting `terminal.integrated.env.linux`/`osx` (e.g. PATH=${env:PATH}) makes tasks run with a basic system PATH or ignore the variable, while the integrated terminal works.

## Best solution

Trace how task terminals receive the `terminal.integrated.env.<platform>` values, in terminalTaskSystem.ts and the terminal environment resolution it uses. Make tasks apply and resolve those values the same way the integrated terminal does, including `${env:PATH}`.
