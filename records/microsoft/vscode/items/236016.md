# Issue #236016 — SCM - The version-control comment is not DevContainer-specific

[https://github.com/microsoft/vscode/issues/236016](https://github.com/microsoft/vscode/issues/236016)

## Summary

The reported cross-container draft collision is addressed by the landed SCM history storage rewrite: histories now use workspace-scoped storage and full repository URIs, including authority. Propose closing as completed.

## Change summary

Keep uncommitted SCM message drafts separate between development containers whose repository paths match but whose remote authorities differ.

## Best solution

Keep the workspace-scoped, full-URI history implementation introduced in https://github.com/microsoft/vscode/commit/f7c6e1a7a136084217a0180b980f56952ab65c23; it removes the path-only shared storage key responsible for this report.
