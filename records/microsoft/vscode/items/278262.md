# Issue #278262 — It's not obvious you can hide a model in Manage Models

[https://github.com/microsoft/vscode/issues/278262](https://github.com/microsoft/vscode/issues/278262)

## Summary

Keep open: current Manage Models still conceals the visibility action until row interaction, so the discoverability concern remains despite hiding being implemented. This team-authored, reopened issue needs a UX decision, not an as-designed close.

## Change summary

Make the ability to hide models discoverable in Manage Models without requiring users to first hover a row.

## Best solution

Provide an understandable at-rest cue for model visibility management while preserving the workbench's restrained interaction patterns. Agree on the affordance with the area owner; keep picker hiding separate from disabling models for Auto or subagents.
