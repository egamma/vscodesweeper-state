## Summary

The reported regression was fixed by merged PR https://github.com/microsoft/vscode/pull/312227. The fix validates the retained session type against the newly selected workspace before creating a session, preventing a cloud-agent type from reaching a local workspace.

## Change summary

Switching the Agents new-session composer from a cloud workspace to a local workspace retained the incompatible `copilot-cloud-agent` session type and threw an unsupported-session error.
