# Issue #185356 — Use `ThemeIcon.color` for `QuickInputButton`

[https://github.com/microsoft/vscode/issues/185356](https://github.com/microsoft/vscode/issues/185356)

## Summary

Keep open: current main still discards ThemeIcon.color when converting extension-provided quick input buttons. Maintainers explicitly accepted this behavior change, and the related merged PR did not implement it.

## Change summary

Honor ThemeIcon.color on QuickInputButton icons so extensions can visually distinguish button states.

## Best solution

Preserve and render the supplied theme color throughout the quick input button path, including updates to existing buttons, while retaining current behavior for icons without a color.
