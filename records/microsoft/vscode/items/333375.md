# Issue #333375 — Agent Host CLI output is garbled and shows the wrong management command on Windows

[https://github.com/microsoft/vscode/issues/333375](https://github.com/microsoft/vscode/issues/333375)

## Summary

Confirmed defect in the CLI source: the banner hardcodes the stable command name and doesn't detect the Windows console code page, matching the report exactly. There's already an open PR (#333376) fixing this, so the issue should stay open pending that PR's review/merge rather than being closed or auto-fixed now.

## Change summary

On Windows, `code-insiders agent host --tunnel` and `agent ps` emit mojibake for UTF-8 decorations and hardcode `code agent ps | code agent kill` instead of the actual product's CLI name.

## Best solution

Land the fix in https://github.com/microsoft/vscode/pull/333376, which should make the banner encoding-aware (detect the active console code page, fall back to ASCII decorations, keep redirected output UTF-8) and build the management hint from the product's `applicationName` instead of the hardcoded `code agent ps | code agent kill` string in cli/src/commands/agent_host.rs.
