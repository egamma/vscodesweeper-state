# Issue #333375 — Agent Host CLI output is garbled and shows the wrong management command on Windows

[https://github.com/microsoft/vscode/issues/333375](https://github.com/microsoft/vscode/issues/333375)

## Summary

Real, partially-fixed bug with an open PR actively addressing the remaining gap — keeping open per the open-PR rule rather than closing prematurely.

## Change summary

On Windows, non-UTF-8 console code pages garble the Agent Host CLI's decorative Unicode output, and the banner hardcodes 'code' instead of the actual product application name.

## Best solution

Land and verify https://github.com/microsoft/vscode/pull/335349, which makes the Node launcher inherit real Windows console handles instead of piping them, so the CLI's existing code-page detection actually sees the true console state end to end.
