# Issue #271012 — Copy and paste does not work between projects opened in dev containers

[https://github.com/microsoft/vscode/issues/271012](https://github.com/microsoft/vscode/issues/271012)

## Summary

Still reproduces on main. A fix was attempted in PR #320685 (merged June 11, 2026) but fully reverted (June 15 and June 29). The issue is assigned to lramos15 and chrmarti, indicating active team ownership — keep open.

## Change summary

File explorer copy/paste between two dev container windows fails because the clipboard stores container-local paths that don't exist in the other container's filesystem.

## Best solution

Re-land the cross-remote file copy/paste work from PR #320685 (or a successor) once the regression that caused the revert is resolved. The fix needs the explorer/clipboard service to resolve paths through the remote file system proxy so that container-local paths are translated correctly across windows. The team (lramos15, chrmarti) is already assigned and aware.
