# Issue #311326 — codex not reflected in terminal title

[https://github.com/microsoft/vscode/issues/311326](https://github.com/microsoft/vscode/issues/311326)

## Summary

Still reproduces on main: codex CLI detection is explicitly commented out in `agentCliTitlePatterns` because codex does not emit OSC title sequences, so the terminal shows 'node' instead of 'codex'. The fix requires either codex emitting an OSC title or an alternative detection mechanism (e.g. process-name matching).

## Change summary

Running `codex` in an integrated terminal shows 'node' as the tab title instead of 'codex' or the agent's own title.

## Best solution

Add a process-name-based fallback detection for codex (matching the process name or argv against a pattern like `/\bcodex\b/i`) in `terminalInstance.ts`, similar to how OSC-based detection works for claude/copilot/gemini but triggered from the pty's reported process name. Alternatively, file upstream against codex to emit an OSC 2 title sequence.
