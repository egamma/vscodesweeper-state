# Issue #336164 — Renaming MCP server in JSON appends it to MCP list

[https://github.com/microsoft/vscode/issues/336164](https://github.com/microsoft/vscode/issues/336164)

## Summary

Fresh, credible report from a team member with a screenshot showing the duplicate entry; the MCP server install/uninstall event pipeline is complex (multiple layers diff-and-sync server lists by name) and I could not pin the exact race from source alone, so this needs an engineer to trace it rather than an automated fix.

## Change summary

Renaming an MCP server's key in the JSON config leaves the old name as a stale entry in the MCP Servers - Installed list instead of updating it in place.

## Best solution

Route to the MCP area owners: trace why a rename (uninstall-old + install-new, as computed in src/vs/platform/mcp/common/mcpManagementService.ts's updateLocal diff) doesn't cleanly remove the old-name entry downstream in InstalledMcpServersDiscovery.sync() / McpWorkbenchService's onDidInstallMcpServers/onDidUninstallMcpServer handlers (areSameMcpServers matches by name+scope+mcpResource, so a race or missed uninstall event is the likely culprit).
