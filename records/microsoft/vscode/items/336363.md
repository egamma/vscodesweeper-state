# Issue #336363 — Git multi-file diff refresh steals keyboard focus from the terminal

[https://github.com/microsoft/vscode/issues/336363](https://github.com/microsoft/vscode/issues/336363)

## Summary

The reported refresh path still takes focus on current main: automatic change selection uses the original open options rather than current keyboard focus. Keep this team-authored issue open; the verified older focus reports describe different triggers and are not duplicate canonicals.

## Change summary

Refreshing an already-open staged or unstaged multi-file Git diff steals terminal focus when its change list repopulates or its active file disappears.

## Best solution

Background multi-diff updates should select and reveal appropriate content without taking focus from the terminal or another control. Preserve intentional focus on user-initiated opening and explicit change navigation, including restored-item and accessibility behavior.
