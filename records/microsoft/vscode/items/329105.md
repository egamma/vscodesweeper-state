# Issue #329105 — Support dictation in automation composer

[https://github.com/microsoft/vscode/issues/329105](https://github.com/microsoft/vscode/issues/329105)

## Summary

Genuine, unimplemented gap: dictation/mic actions (DictationActionViewItem, etc.) are wired into MenuId.ChatExecute for the main chat input but the automation composer's dialog only exposes MenuId.AutomationsDialogInput, which has no dictation entries — so voice input isn't available there yet. Team-authored (roblourens, MEMBER), already correctly labeled, and only 2 days old — no basis to close.

## Change summary

Requests dictation/voice-to-text support in the automation composer's prompt text box (and more broadly in arbitrary text fields).

## Best solution

Wire the existing dictation action view items (DictationActionViewItem / DictationDownloadActionViewItem in src/vs/workbench/contrib/chat/browser/speechToText/) into the AutomationsDialogInput menu the same way they're contributed to ChatExecute, reusing the same ChatInputPart-based composer used in src/vs/sessions/contrib/automations/browser/automationDialog.ts.
