# Issue #326510 — Allow access to Codex & Claude via BYOK

[https://github.com/microsoft/vscode/issues/326510](https://github.com/microsoft/vscode/issues/326510)

## Summary

The requested non-Copilot access is implemented: Codex can use a ChatGPT/OpenAI account, while Claude can use native Anthropic credentials. The signed-out path is currently enabled through the experimental `chat.agentHost.allowSignedOutWhenUsable` setting.

## Change summary

Allow Claude and Codex agent sessions in VS Code's unified Agents UI using the user's provider credentials instead of requiring a paid GitHub Copilot subscription.

## Best solution

Keep the provider-specific authentication paths now present on main and direct users to `chat.agentHost.allowSignedOutWhenUsable`; continue improving discoverability under https://github.com/microsoft/vscode/issues/323049.
