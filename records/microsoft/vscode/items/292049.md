# Issue #292049 — There is no android or ios application to install VS Code - Tauri

[https://github.com/microsoft/vscode/issues/292049](https://github.com/microsoft/vscode/issues/292049)

## Summary

Requesting a full rewrite of VS Code's runtime from Electron to Tauri for mobile platform support is out of scope for the project — Electron is a foundational architectural choice, and VS Code already provides vscode.dev for lightweight browser-based editing on any device including tablets.

## Change summary

Port VS Code from Electron to the Tauri framework to enable native Android and iOS installations.

## Best solution

Close as *out-of-scope. Migrating from Electron to Tauri would be a ground-up rewrite of VS Code's platform layer and is not something the project will undertake. Users wanting VS Code on mobile devices can use https://vscode.dev in a browser today.
