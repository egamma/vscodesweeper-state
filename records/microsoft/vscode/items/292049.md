# Issue #292049 — There is no android or ios application to install VS Code - Tauri

[https://github.com/microsoft/vscode/issues/292049](https://github.com/microsoft/vscode/issues/292049)

## Summary

Requesting a migration from Electron to Tauri and native Android/iOS apps is well outside VS Code's scope — Electron is a foundational architectural choice, and mobile/tablet access is served by vscode.dev.

## Change summary

Migrate VS Code from Electron to Tauri to enable native Android and iOS applications.

## Best solution

Close as out-of-scope. Electron is a deliberate, foundational choice for VS Code's desktop runtime; a framework migration to Tauri is not on the roadmap. Users needing VS Code on tablets can use https://vscode.dev, which runs in mobile browsers including Android and iPadOS.

## Vision fit

- **Fit:** rejected
- **Reason:** VS Code's values explicitly define it as an Electron-based application where 'the power lives in extensions'; a wholesale framework migration to Tauri contradicts the project's architectural foundation and the 'lightweight and fast' value (a rewrite of this magnitude would be an enormous destabilizing effort).
- **Evidence:** Value: 'Out of the box, VS Code is a text editor: lightweight and fast.' Guardrail: capabilities that can be served another way (here, vscode.dev for mobile) belong outside core. Durable theme: performance — a framework migration would risk regressions across every platform.
