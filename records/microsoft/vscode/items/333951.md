# Issue #333951 — Chat: allow an inline file reference to display a readable label instead of the raw basename

[https://github.com/microsoft/vscode/issues/333951](https://github.com/microsoft/vscode/issues/333951)

## Summary

Well-reasoned, code-grounded feature request: inline file references currently always render the raw basename with no alias mechanism, confirmed in chatInputCompletions.ts on main. No existing setting or duplicate covers this, so it should be routed to the chat area for product consideration.

## Change summary

Allow inline chat file references (#file:<name>) to display a custom/readable label instead of always showing the raw file basename.

## Best solution

A chat maintainer should weigh the proposed options (frontmatter/H1 title, editable label, or a chat.* setting for a shorter display form) against the added complexity of decoupling display text from the inserted variable text in chatInputCompletions.ts and chatInlineAnchorWidget.ts; this is a product/design decision, not a mechanical fix.
