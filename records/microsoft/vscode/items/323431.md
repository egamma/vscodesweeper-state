## Summary

Current main appears to cover this request by hiding completed ask-user tool details and rendering a stopped question as a conversational “Skipped question” summary. Because this is team-authored and neither likely-covering PR explicitly references the issue, the protected-item rule requires leaving it open for maintainer verification rather than proposing a completed close.

## Change summary

When a user stops an Agent Host turn at a multiple-choice question, show a purpose-built question summary instead of raw tool input/output JSON.

## Best solution

Verify the stop-at-question flow against current main: the pending question should become a conversational “Skipped question” summary while the completed ask-user tool remains hidden. If that matches the intended design, a maintainer can close the issue as covered by the response-part input-request and ask-question UX work.
