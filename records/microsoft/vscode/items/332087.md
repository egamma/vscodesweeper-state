# Issue #332087 — Agent host: responses render only at turn end because the optimistic turn start is never retired

[https://github.com/microsoft/vscode/issues/332087](https://github.com/microsoft/vscode/issues/332087)

## Summary

Real bug with a confirmed root cause and an open fixing PR already in flight — keep open until that PR merges rather than closing now.

## Change summary

Chat responses only render at the end of a turn instead of streaming, because the optimistic `turnStarted` action is never retired when the backend's echo doesn't carry a matching clientSeq, so replaying it on every recompute keeps resetting the visible turn to empty.

## Best solution

Land and verify https://github.com/microsoft/vscode/pull/332122, which retires the optimistic turn start on the first backend action for the turn; close this issue once that PR merges and streaming is confirmed restored.
