# Issue #332429 — Unable to differentiate between similarly named custom agents in multi root workspace

[https://github.com/microsoft/vscode/issues/332429](https://github.com/microsoft/vscode/issues/332429)

## Summary

Team-authored, freshly-filed UX gap: in a multi-root workspace, two custom agents with the same name under `.github/agents` in different roots are indistinguishable in the agent picker. No fix has landed yet, so this stays open and should be routed to the chat customizations/agent-picker owners.

## Change summary

The chat agent picker dropdown doesn't disambiguate same-named custom agents defined in different workspace root folders.

## Best solution

Add a folder/root indicator (label suffix or description, similar to how the model picker groups by provider) to the agent dropdown item renderer so same-named custom agents from different roots are distinguishable; likely touches the mode/agent picker item rendering (e.g. src/vs/workbench/contrib/chat/browser/widget/input/modePickerActionItem.ts or modePickerActionItem's underlying data source) and/or the custom agent discovery/aggregation code that builds the picker list from `.github/agents` across workspace folders.
