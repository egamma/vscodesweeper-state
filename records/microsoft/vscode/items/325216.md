# Issue #325216 — "No provider registered" log spam

[https://github.com/microsoft/vscode/issues/325216](https://github.com/microsoft/vscode/issues/325216)

## Summary

The warning-spam path remains in current main: silent model selection logs a warning for every contributed vendor without a registered provider, on every query. The linked fixing PR was closed without merging, so it does not establish completion.

## Change summary

Prevent repeated silent startup queries from flooding renderer logs with missing-provider warnings for optional language model vendors.

## Best solution

Keep expected provider absence quiet during silent background resolution while preserving actionable diagnostics for explicit provider management. Cover repeated selection queries and explicit management with logging regression tests in the LanguageModels suite.
