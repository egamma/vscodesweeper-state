# Issue #325216 — "No provider registered" log spam

[https://github.com/microsoft/vscode/issues/325216](https://github.com/microsoft/vscode/issues/325216)

## Summary

Still reproduces on main: `_resolveAllLanguageModels` logs a warning for every unregistered vendor regardless of the `silent` flag, and `selectLanguageModels` without a vendor selector triggers it for all contributed vendors. Filed by a team member — keeping open.

## Change summary

VS Code startup floods the renderer log with 72 'No provider registered for vendor' warnings from silent language-model resolution of optional providers.

## Best solution

Guard the warning at `languageModels.ts:1059` on `!silent` so that silent resolution (the startup and `selectLanguageModels` code paths) does not log for vendors whose providers haven't registered yet. Alternatively, deduplicate with a seen-set so each vendor warns at most once.
