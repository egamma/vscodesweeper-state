# Issue #328567 — Outline View - VS Code Hybrid Markdown Editor

[https://github.com/microsoft/vscode/issues/328567](https://github.com/microsoft/vscode/issues/328567)

## Summary

Valid, freshly-filed feature request: the outline view doesn't populate for the new experimental hybrid (WYSIWYG) Markdown custom editor, and no equivalent capability exists on main — keeping open for the community upvote process rather than closing a 5-day-old, 0-upvote request.

## Change summary

Make the Outline view populate document symbols while the experimental hybrid/WYSIWYG Markdown editor (vscode.markdown.editor) is active.

## Best solution

Belongs with the markdown-editor custom editor work in extensions/markdown-language-features/src/preview/markdownEditorProvider.ts — the outline view relies on DocumentSymbolProvider against the active text editor, which the custom webview-based hybrid editor doesn't expose; wiring symbol/outline support (or reusing the markdown language service's existing TOC provider) for this custom editor would close the gap. No canonical open issue currently owns this for the hybrid editor specifically.
