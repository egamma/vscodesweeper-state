# Issue #328567 — Outline View - VS Code Hybrid Markdown Editor

[https://github.com/microsoft/vscode/issues/328567](https://github.com/microsoft/vscode/issues/328567)

## Summary

Real, currently-unaddressed gap: the Outline view only has registered creators for the standard code editor, notebook editor, and chat panes (src/vs/workbench/services/outline/browser/outlineService.ts registrants), none for the new experimental hybrid Markdown custom editor, so headings from that editor never populate the Outline/breadcrumbs. Routing to the markdown area as a feature request rather than closing.

## Change summary

Wire the Outline view (and breadcrumbs) up to the new experimental Hybrid (WYSIWYG) Markdown editor so heading structure is shown and navigable, matching the existing plain-text Markdown editor behavior.

## Best solution

Add an IOutlineCreator for the `vscode.markdown.editor` custom text editor (extensions/markdown-language-features/src/preview/markdownEditorProvider.ts), similar to NotebookOutlineCreator in src/vs/workbench/contrib/notebook/browser/contrib/outline/notebookOutline.ts, that derives headings from the underlying TextDocument/markdown AST and reveals the corresponding location in the webview on selection.
