# Issue #199352 — Icon to hide equal lines only shows when all lines are visible

[https://github.com/microsoft/vscode/issues/199352](https://github.com/microsoft/vscode/issues/199352)

## Summary

Keep open: current source still withholds the standard diff editor's per-region fold icon until the entire unchanged region is revealed. This team-authored, accepted request has no verified older canonical covering the same symptom.

## Change summary

Make a per-region hide action available after partially revealing unchanged lines, without requiring full expansion or extra scrolling.

## Best solution

Provide a discoverable local collapse action for partially revealed unchanged regions in the standard diff and multi-diff editors. Settle its placement while preserving incremental reveal, drag interactions, and unrelated regions' expansion state.

## Vision fit

- **Fit:** aligned
- **Reason:** Making partial expansion readily reversible improves the built-in code-review workflow and keeps diff interactions understandable.
- **Evidence:** Public values: "Simple, uniform UI and UI interactions." Durable themes: Workbench & core UX and Developer inner loop.

Acceptance includes partial reveals from either edge, independently expanded neighboring regions, and keyboard access to the chosen affordance.
- **Trace:**
