# Issue #162018 — Cell context menu should use NotebookCell as context like the cell toolbar

[https://github.com/microsoft/vscode/issues/162018](https://github.com/microsoft/vscode/issues/162018)

## Summary

Still present on main: the cell container context menu (`showListContextMenu` in notebookEditorWidget.ts) passes `{ from: 'cellContainer' }` as context instead of the `INotebookCellActionContext` with the cell reference that the cell toolbar uses, so commands contributed to both surfaces get inconsistent context.

## Change summary

Cell context menu should pass a NotebookCell-based context (like the cell toolbar does) so commands work consistently from both surfaces.

## Best solution

Update `showListContextMenu` in `notebookEditorWidget.ts` to construct an `INotebookCellActionContext` (with cell, notebookEditor, and `$mid: MarshalledId.NotebookCellActionContext`) from the `IListContextMenuEvent<CellViewModel>` element, matching what `codeCellRunToolbar.ts` does for the toolbar context.
