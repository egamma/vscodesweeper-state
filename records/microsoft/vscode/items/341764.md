# Issue #341764 — Opening file from session changes in copilot harness always leads to broken file

[https://github.com/microsoft/vscode/issues/341764](https://github.com/microsoft/vscode/issues/341764)

## Summary

Thanks for the report. It has concrete steps and reproduces for the reporter every time in a dev container. I could not confirm it from source: the Open File action in the Agents window Changes editor maps the diff URI to a workspace URI, and that mapping may produce a wrong remote or dev-container path.

## Change summary

The per-file Open File button in the Agents window session Changes editor reports 'file not found' for files that exist, when working in a dev container.

## Best solution

Check the URI that `OpenChangedFileAction` resolves through `getWorkspaceResource` and `getChangesFileUri` for dev-container and remote sessions. It should point at the remote workspace file, not a local or agent-host path. Add a test for that case.
