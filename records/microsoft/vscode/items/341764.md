Current main has explicit host-resource mapping and separate snapshot/file targets, but inspection does not establish that this environment-specific failure is fixed; newer remote reports describe similar failures.

## Change summary

Opening an existing container file from the Copilot harness Session Changes header reports that the file cannot be found, although its diff is readable.

## Best solution

Make Session Changes open the live file through its owning remote connection, preserving its filesystem identity rather than resolving a container path locally. First reproduce the supplied dev-container scenario and compare the target URI with the same file opened through Explorer.
