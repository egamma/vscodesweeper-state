# Issue #200531 — Click scroll bar by page not smooth(Editor,Workbench list )

[https://github.com/microsoft/vscode/issues/200531](https://github.com/microsoft/vscode/issues/200531)

## Summary

Still reproduces on main: when `scrollByPage` is enabled and smooth scrolling is on, clicking the scrollbar track calls `setScrollPositionNow` (instant jump) instead of `setScrollPositionSmooth`, so the page-scroll is never animated.

## Change summary

Clicking the scrollbar track with `scrollByPage` enabled ignores smooth scrolling settings — the scroll jumps instantly instead of animating.

## Best solution

In `AbstractScrollbar._setDesiredScrollPositionNow` (or the call site at line 226 of `abstractScrollbar.ts`), check whether smooth scrolling is enabled and call `setScrollPositionSmooth` instead of `setScrollPositionNow` when it is. The `Scrollable` class already supports both paths.
