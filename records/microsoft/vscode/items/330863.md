# Issue #330863 — Weird tab titles on macOS since 1.132

[https://github.com/microsoft/vscode/issues/330863](https://github.com/microsoft/vscode/issues/330863)

## Summary

This is a symptom (heavier tab/panel-title font) of the same root cause tracked by the earlier, actively-assigned issue https://github.com/microsoft/vscode/issues/328764: the `workbench.experimental.modernUI` setting carries `experiment: { mode: 'auto' }` in workbench.contribution.ts, so an A/B rollout silently flips its effective default to `true` for enrolled users across platforms, independent of any prior opt-in.

## Change summary

Editor tab and panel title fonts became noticeably heavier/bolder on macOS starting in 1.132, with no visible setting to restore the old look.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/328764 (already assigned to mrleemurray/hawkticehurst) which tracks the same root cause — the `modernUI` auto-experiment silently overriding the setting default; users can work around it today by explicitly setting `"workbench.experimental.modernUI": false` in settings.json, since an explicit user value overrides the experiment-provided default (see `ConfigurationDefaultOverridesContribution.shouldOverride` in src/vs/workbench/services/configuration/browser/configurationService.ts).

## Evidence

- **experiment annotation:** src/vs/workbench/browser/workbench.contribution.ts defines `[LayoutSettings.MODERN_UI]: { type: 'boolean', default: false, ..., experiment: { mode: 'auto' } }`, meaning the effective default can be silently switched to true by an A/B assignment.
- **override mechanism:** src/vs/workbench/services/configuration/browser/configurationService.ts `ConfigurationDefaultOverridesContribution.processExperimentalSettings` calls `workbenchAssignmentService.getTreatment(...)` and registers a default-configuration override whenever the treatment differs from the schema default — this happens automatically on 'auto' mode refetches, matching the reporters' 'it silently turned on after a restart/update' experience.
- **canonical duplicate:** https://github.com/microsoft/vscode/issues/328764 ('Experimental `modernUI` switched on by itself') is open, assigned to mrleemurray and hawkticehurst, and its own comment thread already concludes 'I think an A/B experiment is being conducted on this setting' — same root cause, filed earlier, already being worked on by the team.
- **migration path (secondary):** workbench.contribution.ts also migrates the older `workbench.experimental.floatingPanels` / `workbench.experimental.styleOverrides` settings onto `LayoutSettings.MODERN_UI` when unset, which is a second, narrower path to the same effective symptom but the A/B experiment is the dominant explanation given the reports span macOS and Linux with no prior experimental opt-in mentioned.
