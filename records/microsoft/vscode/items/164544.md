# Issue #164544 — Navigating back from debug quick pick is not going to CC

[https://github.com/microsoft/vscode/issues/164544](https://github.com/microsoft/vscode/issues/164544)

## Summary

The reported navigation defect remains in current source: selecting Debug through More loses the Command Center options, so clearing the prefix returns to ordinary Quick Open. Keep this accepted, team-authored bug open in command-center.

## Change summary

Clearing the debug picker input after entering through Command Center → More should restore the Command Center modes rather than ordinary file picking.

## Best solution

Preserve the originating Command Center experience across the Help quick-access provider's transitions, including More → Debug → empty input. Ordinary Quick Open and directly invoked debug pickers should retain their existing behavior.
