# Issue #165009 — Feature: identify Inlay Hints text (e.g. info in tooltip)

[https://github.com/microsoft/vscode/issues/165009](https://github.com/microsoft/vscode/issues/165009)

## Summary

The request for self-identifying inlay hints (a tooltip or icon explaining what they are and how to disable them) remains unimplemented on current main. The hover participant shows extension-provided tooltips and navigation links but no 'this is an inlay hint' discoverability message. Keeping open as an under-discussion UX improvement.

## Change summary

Add a discoverability mechanism (e.g. tooltip text or icon) that identifies inlay hint text as non-code and links to the setting to disable it.

## Best solution

Add a footer line to the inlay-hint hover (in `inlayHintsHover.ts`) that identifies the text as an inlay hint and links to `editor.inlayHints.enabled` settings — a small, localized UX polish that helps newcomers without cluttering experienced users' workflows.
