# Issue #337743 — Are “fun working messages” intended to occur ~1 in 50 message picks, rather than ~1 in 50 chat interactions?

[https://github.com/microsoft/vscode/issues/337743](https://github.com/microsoft/vscode/issues/337743)

## Summary

The maintainer confirmed that the per-selection 1-in-50 behavior is intentional, directly answering the report's central question. The existing thinking-phrases setting also provides a way to avoid the built-in Easter-egg messages.

## Change summary

Clarify whether fun chat working messages should be sampled once per message selection or once per chat interaction.

## Best solution

Keep the intentional per-selection sampling behavior and direct users who prefer predictable messages to `chat.agent.thinking.phrases` with `mode: "replace"`; any future frequency control can be considered as a separate feature request.
