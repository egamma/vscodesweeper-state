# Issue #325261 — macOs Command + Right to accept a word

[https://github.com/microsoft/vscode/issues/325261](https://github.com/microsoft/vscode/issues/325261)

## Summary

VS Code already supports rebinding any keyboard shortcut including Cmd+Right for inline suggestions — the user can remap `editor.action.inlineSuggest.acceptNextWord` in Keyboard Shortcuts (⌘K ⌘S) to any preferred key combination. This is as-designed.

## Change summary

Request to configure the keyboard shortcut for accepting a word of an inline suggestion (Cmd+Right on macOS).

## Best solution

Close as already possible: the command `editor.action.inlineSuggest.acceptNextWord` is rebindable via File > Preferences > Keyboard Shortcuts or keybindings.json. Point the reporter to the keybinding customization docs.

  > Thanks for the report! VS Code already supports rebinding any keyboard shortcut. You can change the key for accepting the next word of an inline suggestion:
  > 
  > 1. Open **Keyboard Shortcuts** (⌘K ⌘S)
  > 2. Search for `editor.action.inlineSuggest.acceptNextWord`
  > 3. Click the pencil icon and assign your preferred keybinding
  > 
  > You can also remove the existing Cmd+Right binding there so it doesn't conflict with your virtual-screen switching. Closing as this is already configurable — hope that helps!
