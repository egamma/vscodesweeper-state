# Issue #336717 — Closing a window with an attention notification throws "Object has been destroyed"

[https://github.com/microsoft/vscode/issues/336717](https://github.com/microsoft/vscode/issues/336717)

## Summary

Confirmed on main: `showNotifyFocus()` in windowImpl.ts registers a disposable that calls `this.win?.flashFrame(false)` without checking whether the native window was already destroyed, matching the reported stack. An open PR (#336719) already targets this exact cleanup path, so it should be reviewed/landed rather than closed here.

## Change summary

Closing a window while its taskbar icon is flashing for attention throws 'Object has been destroyed' during window cleanup, because flashFrame(false) is called on an already-destroyed native window.

## Best solution

Land the linked PR (or an equivalent), guarding `flashFrame(false)` with a liveness check (e.g. `!this.win.isDestroyed()`) before calling it in the notifyFocus disposal, similar to the pattern already used at windowImpl.ts:1650.
