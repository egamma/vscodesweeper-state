## Summary

The reported endpoint is not deprecated for Azure OpenAI inference; current Microsoft documentation still specifies `*.openai.azure.com`, so the existing behavior is intentional.

## Change summary

Replace Azure OpenAI endpoint handling for `*.openai.azure.com` with `*.cognitiveservices.azure.com`.

Keep `*.openai.azure.com` as the recognized Azure OpenAI base endpoint while continuing to preserve fully resolved custom endpoints.
