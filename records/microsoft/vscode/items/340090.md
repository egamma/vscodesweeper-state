Keep open: independent reports confirm stale background-command counts, including after successful kill_terminal calls on Windows without Remote-SSH. Current source exposes a matching lifecycle gap; no verified fixing commit or canonical duplicate establishes that this report is resolved.

## Change summary

Make Copilot Chat's background-command count stop including commands that have completed or whose terminals have been stopped.

## Best solution

Keep the chat activity indicator synchronized with terminal execution lifecycle, including completion, explicit termination, and restored conversations, while continuing to count genuinely running servers.
