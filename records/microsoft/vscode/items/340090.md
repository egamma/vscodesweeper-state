# Issue #340090 — Copilot Chat: background commands running counter only increases after commands finish

[https://github.com/microsoft/vscode/issues/340090](https://github.com/microsoft/vscode/issues/340090)

## Summary

Keep open: independent reports confirm that stopped commands remain counted, including after restarting VS Code. Current source exposes a plausible terminal-disposal accounting gap, but the affected session's counting path still needs confirmation.

## Change summary

Make the background-command count decrease when commands finish or are stopped, without excluding legitimately running servers.

## Best solution

Ensure background activity reflects command lifecycle independently of rendered terminal widgets and steering notifications. Diagnose the confirmed local run_in_terminal/kill_terminal case first, then verify completion, cancellation, and restored-session behavior.
