[https://github.com/microsoft/vscode/issues/168406](https://github.com/microsoft/vscode/issues/168406)

## Summary

Keep this open under discussion: the active-tab foreground regression was fixed, but that does not resolve the remaining default-theme readability feedback. Current connected-tab styling partially covers the original geometry request; neither that capability nor the newer theme discussions establishes completion of the whole issue.

## Change summary

Improve default dark-theme sidebar readability and active-tab distinction, originally including rounded borders connecting tabs to the editor.

## Best solution

Have the theme owner evaluate the remaining sidebar and active-tab readability concerns against current themes, separating them from the already-fixed foreground regression and existing connected-tab treatment. Agree on any default palette changes without requiring users to override colors or reviving the previously rejected border treatment by assumption.
