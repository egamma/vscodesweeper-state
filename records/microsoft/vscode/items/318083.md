# Issue #318083 — Markdown wrong parsing for link in codeblock

[https://github.com/microsoft/vscode/issues/318083](https://github.com/microsoft/vscode/issues/318083)

## Summary

Keep open: the experimental Markdown preview diff still inserts HTML markers into Markdown source before parsing, which exposes those markers inside fenced code blocks. The thread establishes the affected editor and a working text-diff workaround; the linked PR closed without merging.

## Change summary

Prevent rendered Markdown diffs from displaying internal diff-marker markup or corrupting fenced code block contents.

## Best solution

Preserve code block content and Markdown parsing while showing changes in the rendered diff. Address the Markdown preview rendering pipeline rather than disabling ordinary editor URL detection, and retain the default text diff as the documented workaround.
