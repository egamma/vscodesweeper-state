# Issue #284506 — Agent could suggest to preview the site I am creating using simple browser

[https://github.com/microsoft/vscode/issues/284506](https://github.com/microsoft/vscode/issues/284506)

## Summary

Keep open to settle the website-preview recommendation behavior. Current agents can open the integrated browser and receive conditional browser-use instructions, but this does not establish consistent preview suggestions after project creation; no issue-referencing fix or qualifying canonical was verified.

## Change summary

Have the agent recommend previewing a newly created website inside VS Code, optionally offering a more integrated developer-tools experience.

## Best solution

Use the existing integrated-browser capability for an appropriate preview offer after website creation, without requiring an additional extension. Decide whether that offer should also appear when browser automation is disabled and whether optional developer-tools recommendations belong in this flow.
