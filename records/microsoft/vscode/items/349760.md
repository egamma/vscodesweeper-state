# Issue #349760 — Search keeps results from the previous worktree after switching Folder Location

[https://github.com/microsoft/vscode/issues/349760](https://github.com/microsoft/vscode/issues/349760)

## Summary

Keep open: switching Folder Location changes the workspace folder without invalidating Search's existing results. The current source supports the reported stale match, and the linked test plan explicitly expects Search to follow the selected location.

## Change summary

Invalidate results from the previous folder location when switching between a worktree and the original folder.

## Best solution

Search should stop presenting the previous location's matches after a successful location switch, while preserving the query and search options. Scope the behavior to location changes without altering ordinary multi-root folder-editing semantics.
