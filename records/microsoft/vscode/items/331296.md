# Issue #331296 — `code --status` multiplies process memory twice on macOS and Linux

[https://github.com/microsoft/vscode/issues/331296](https://github.com/microsoft/vscode/issues/331296)

## Summary

Confirmed in source: `DiagnosticsService.formatProcessItem` in src/vs/platform/diagnostics/node/diagnosticsService.ts re-applies the percent-to-bytes conversion to a value `listProcesses` (src/vs/base/node/ps.ts) already converted to bytes on non-Windows platforms, producing absurd Mem MB values in `code --status`. An open PR (#331297) already carries a fix with `Fixes #331296`, so this stays open for that PR to land rather than being auto-fixed or closed.

## Change summary

`code --status` reports impossible process memory values on macOS/Linux because the text formatter double-converts an already-byte value as if it were still a percentage.

## Best solution

Land the fix in https://github.com/microsoft/vscode/pull/331297, which corrects `formatProcessItem` to treat `item.mem` as bytes consistently with `listProcesses` and the Process Explorer view.
