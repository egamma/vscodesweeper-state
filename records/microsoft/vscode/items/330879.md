# Issue #330879 — fix: guard identity lookup for root element in getDataNode (fixes #330873)

[https://github.com/microsoft/vscode/issues/330879](https://github.com/microsoft/vscode/issues/330879)

This is a bot-authored, well-diagnosed bug report (an auto-fix proposal whose PR creation failed due to a fork permission error) — the defect is confirmed on current main and the proposed fix is small and localized, so it should stay open and be applied.

## Change summary

getDataNode's error-enrichment branch in asyncDataTree.ts unconditionally casts the root TInput element to T before calling identityProvider.getId, throwing 'getId is not a function' instead of the intended TreeError when the root array reaches that path.

## Best solution

Apply the one-line guard in getDataNode (src/vs/base/browser/ui/tree/asyncDataTree.ts) to only call identityProvider.getId when element !== this.root.element, matching the same root check already used a few lines above for the node-map lookup; land it via a manually opened PR since the bot's automated PR creation failed (fork_collab permission error).
