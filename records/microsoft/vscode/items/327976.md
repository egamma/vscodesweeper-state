# Issue #327976 — Add max_tokens as allowed modelOption

[https://github.com/microsoft/vscode/issues/327976](https://github.com/microsoft/vscode/issues/327976)

## Summary

A real Custom Endpoint configuration gap remains: current main intentionally omits `max_tokens` for Chat Completions and permits only sampling parameters in `modelOptions`. Route this feature request to BYOK model ownership.

## Change summary

Allow Custom Endpoint configurations to set an explicit output-token limit instead of relying on the server default.

## Best solution

Extend Custom Endpoint model options with an explicit output-token limit and map it to the API-appropriate field (`max_tokens`, `max_completion_tokens`, or `max_output_tokens`), while preserving the current omission behavior when it is unset.
