# Issue #327976 — Add max_tokens as allowed modelOption

[https://github.com/microsoft/vscode/issues/327976](https://github.com/microsoft/vscode/issues/327976)

## Summary

Keep open: current custom-endpoint configuration cannot explicitly send max_tokens for non-thinking Chat Completions models, so the requested control remains missing. The related BYOK requests do not establish an older canonical reporting the same response-truncation symptom.

## Change summary

Allow configuring an explicit output-token limit through modelOptions in chatLanguageModels.json instead of relying on a custom server's default.

## Best solution

Provide an explicit per-model output-token override in the custom-endpoint request path while preserving server-default behavior when unset. Coordinate with the broader extra-body proposal, ensuring the final request retains the configured limit rather than deleting it during interception.
