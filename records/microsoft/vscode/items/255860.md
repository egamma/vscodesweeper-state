Make the VSCode chat participant recognize relevant commands contributed by installed extensions instead of overlooking capabilities available in the current instance.

Its implementation invokes _getAllCommands; src/vs/workbench/contrib/preferences/browser/preferencesActions.ts:235–272 enumerates CommandPalette menu contributions without a core-only ownership restriction. The current implementation therefore already discovers extension command metadata, contrary to a blanket assertion that it only indexes core commands.
- **Current retrieval coverage gap:** extensions/copilot/src/platform/embeddings/common/embeddingsIndex.ts: RemoteEmbeddingsExtensionCache.fetchRemoteExtensionCache returns an empty cache on HTTP 404. BaseEmbeddingsIndex._calculateEmbeddings attaches only existing or cached embeddings, and nClosestValues filters out items without embeddings. Consequently, an installed command lacking a cached embedding is excluded from semantic results. Whether the reported SDK commands encounter this condition has not been established.
