# Issue #255860 — VSCode chat participant is not aware of commands from extensions

[https://github.com/microsoft/vscode/issues/255860](https://github.com/microsoft/vscode/issues/255860)

## Summary

Valid feature request: the chat participant that handles @vscode-style queries lacks awareness of extension-contributed commands and contributions. While runCommand/vscodeAPI tools exist, the participant doesn't proactively surface extension capabilities when answering user questions about what's possible in their VS Code instance.

## Change summary

The VSCode chat participant should be aware of commands and contributions from installed extensions so it can guide users to capabilities already available in their instance.

## Best solution

Enrich the chat participant's context with installed extension contributions (commands, settings, views) so that when a user asks 'how do I install .NET SDK', it can discover and suggest the relevant extension command rather than saying it doesn't know. This likely lives in the prompt/context assembly for the panel chat flow in `extensions/copilot/src/extension/prompts/node/panel/`.
