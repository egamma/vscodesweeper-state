# Issue #183340 — Better codicons for Open on GitHub and Open on vscode.dev in branch picker

[https://github.com/microsoft/vscode/issues/183340](https://github.com/microsoft/vscode/issues/183340)

## Summary

The branch picker still uses the generic GitHub and globe icons, so the requested action-oriented distinction remains unresolved. Keep this accepted Backlog item open for a design decision; the discussion offers alternatives but does not settle the icon pair.

## Change summary

Give the branch picker's Open on GitHub and Checkout on vscode.dev actions distinct icons that better communicate their purpose.

## Best solution

Choose a recognizable, visually distinct icon pair for the two existing branch-picker actions, following shared codicon conventions. Preserve their labels, tooltips, destinations, and checkout behavior.
