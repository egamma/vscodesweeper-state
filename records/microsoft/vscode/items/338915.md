# Issue #338915 — "This is taking a little longer than usual" shows while a foreground terminal command is running

[https://github.com/microsoft/vscode/issues/338915](https://github.com/microsoft/vscode/issues/338915)

## Summary

The misleading delayed-progress message is reproducible from current source: an active foreground terminal invocation does not count as known activity, so the 90-second inactivity message remains enabled. Route this to the chat terminal area for a bounded correction.

## Change summary

Do not show the chat inactivity warning while a foreground terminal command or other recognized tool invocation is actively executing.

## Best solution

Keep the persistent working footer in an active-tool state for the duration of a foreground terminal invocation, suppressing the delayed inactivity warning without changing its behavior during genuine model inactivity.
