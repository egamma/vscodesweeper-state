# Issue #336898 — Agents Window: Editor action buttons overlap when tab wrapping is enabled

[https://github.com/microsoft/vscode/issues/336898](https://github.com/microsoft/vscode/issues/336898)

## Summary

Confirmed on current main: both `.editor-actions` and `.editor-layout-actions` are absolutely positioned at the same bottom-right spot when tabs wrap, and the last-tab margin reservation only targets `:last-child`, missing the Add Tab button — exactly as the reporter traced. Genuine, bounded CSS layering bug in the actively-developed Agents Window modern UI tab wrapping.

## Change summary

In the Agents Window, when tab wrapping is enabled, the editor action buttons and layout action buttons overlap each other and can overlap the Add Tab button.

## Best solution

Reserve space for both action toolbars together (not two independently-positioned absolute elements) and extend the last-row margin reservation to also apply when the Add Tab button (not a `.tab`) is the trailing element in the wrapped row, likely reusing the existing `.last-in-row` class pattern already used elsewhere in multieditortabscontrol.css.
