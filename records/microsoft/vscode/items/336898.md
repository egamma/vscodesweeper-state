# Issue #336898 — Agents Window: Editor action buttons overlap when tab wrapping is enabled

[https://github.com/microsoft/vscode/issues/336898](https://github.com/microsoft/vscode/issues/336898)

## Summary

Reopened on 2026-10-09 by a contributor who confirmed the wrapped-tabs overlap in the Agents Window still reproduces. An open PR already references it, so this stays open pending that fix. I did not inspect the checkout or the linked PRs.

## Change summary

With workbench.editor.wrapTabs enabled in the Agents Window, the editor actions, the layout actions and the Add Tab button overlap at the bottom-right of the tab area.

## Best solution

Land https://github.com/microsoft/vscode/pull/340834, which keeps the wrapped Agents tab controls separate. Check that it covers the Add Tab button spacing and the connected-tab pill shape when only the Add Tab button wraps.
