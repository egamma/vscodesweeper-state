# Issue #336898 — Agents Window: Editor action buttons overlap when tab wrapping is enabled

[https://github.com/microsoft/vscode/issues/336898](https://github.com/microsoft/vscode/issues/336898)

## Summary

Confirmed in source: two absolutely-positioned action containers overlap in wrapped-tab mode, and a margin fix aimed at the last tab doesn't cover the Add Tab button — a real, bounded CSS layout bug in the still-experimental Agents Window UI.

## Change summary

In the Agents Window (modern UI), enabling tab wrapping causes the editor action buttons and the layout-action buttons (and sometimes the Add Tab button) to visually overlap at the bottom-right corner.

## Best solution

Reserve distinct space for both `.editor-actions` and `.editor-layout-actions` when wrapping is active (e.g. stack or offset one from the other) and extend the last-tab margin rule to also match the Add Tab button so it isn't covered.
