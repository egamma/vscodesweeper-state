# Issue #155196 — Git - Missing context menu command to stage deleted hunk in Git

[https://github.com/microsoft/vscode/issues/155196](https://github.com/microsoft/vscode/issues/155196)

## Summary

The deleted-code action menu still lacks a staging command in current source. Keep this accepted bug open: the older partial-deletion staging request is related, but does not clearly own the narrower problem of staging an entire deleted hunk from its context menu.

## Change summary

Expose staging from the deleted-hunk context menu, consistently with staging actions available for added lines.

## Best solution

Make an unstaged deleted hunk stageable directly from its deleted-code menu without requiring selection of surrounding unchanged lines. Preserve the distinction between staging an entire hunk and the separate capability to stage individual deleted lines.
