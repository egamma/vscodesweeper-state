- **Proposed comment:**

  > Thanks for the report. Your logs show Copilot's inline code suggestions. To stop these automatic suggestions while keeping chat available, set `"github.copilot.enable": { "*": false }` in your User Settings JSON, removing any language-specific `true` entries. You can still request suggestions manually.
  > 
  > Alternatively, turn off **Editor: Inline Suggest: Enabled** (`editor.inlineSuggest.enabled`) to stop automatic inline suggestions from all providers.
