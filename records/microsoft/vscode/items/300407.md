# Issue #300407 — Automated Screenshot Tool Failure - Error 400 (Image dimensions exceed 2000px)

[https://github.com/microsoft/vscode/issues/300407](https://github.com/microsoft/vscode/issues/300407)

## Summary

The reported failure was confirmed in image-heavy Anthropic conversations and is now fixed on main. Requests are capped at 20 images by omitting the oldest historical images, preventing the server's many-image dimension rejection.

## Change summary

Copilot screenshot requests failed with HTTP 400 when an image-rich conversation crossed the server threshold that limits every image dimension to 2000 pixels.

## Best solution

Keep the request-level image filtering implemented by https://github.com/microsoft/vscode/commit/c47cdd79dd2ff8bd0ad61b169330c03e2ae53db0; it preserves current-turn screenshots while replacing excess historical images before submission.
