# Issue #300407 — Automated Screenshot Tool Failure - Error 400 (Image dimensions exceed 2000px)

[https://github.com/microsoft/vscode/issues/300407](https://github.com/microsoft/vscode/issues/300407)

## Summary

The reported many-image failure has been addressed: tool-call images are resized before serialization, and historical screenshots are now replaced with references so they cannot accumulate past the provider's image limits.

## Change summary

Repeated high-resolution screenshots accumulated in Copilot chat requests until the provider rejected every subsequent request with the 2000-pixel many-image limit.

## Best solution

Keep the prompt-history compaction and shared image-budget behavior introduced by commit 4fa2ff42e96aed774d211ec4e0f605fea6a6eeb0; together with tool-image resizing, it prevents screenshot-heavy sessions from entering the unrecoverable request loop.
