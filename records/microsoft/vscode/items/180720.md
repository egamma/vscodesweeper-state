# Issue #180720 — Git - git stash view

[https://github.com/microsoft/vscode/issues/180720](https://github.com/microsoft/vscode/issues/180720)

## Summary

The native Stashes list now exists, but the requested workflow is only partially covered: it requires an experimental single-repository mode, Drop is context-menu-only, and the list lacks a Drop All control and stash-branch action. Keep this accepted Backlog request open to settle the remaining scope rather than treating the initial implementation as complete.

## Change summary

Provide a built-in SCM stash list with direct management actions, staged-change stashing, and confirmed deletion of all stashes.

## Best solution

Finish the stash-management workflow within the existing Repositories explorer rather than introduce a second stash view. Agree which remaining controls and availability requirements belong to this request, while leaving changed-file expansion to its separate follow-up.
