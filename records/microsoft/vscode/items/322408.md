# Issue #322408 — setModelConfiguration write per-model settings to the wrong provider group when multiple groups share the same vendor

[https://github.com/microsoft/vscode/issues/322408](https://github.com/microsoft/vscode/issues/322408)

## Summary

Already fixed on main: commit fa3b663f723 added a model→group lookup that resolves the correct provider group instead of blindly picking the first vendor match. The fix references #322872, which is the same bug.

## Change summary

setModelConfiguration writes per-model settings to the wrong provider group when multiple groups share the same vendor, because the fallback logic matches by vendor name alone.

## Best solution

Keep the shipped fix (fa3b663f723); no further change needed. The new lookup via _modelsGroups resolves the containing group before falling back to vendor-only matching.
