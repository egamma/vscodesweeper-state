# Issue #145712 — For language-specific settings, modified settings should be shown first

[https://github.com/microsoft/vscode/issues/145712](https://github.com/microsoft/vscode/issues/145712)

## Summary

Still valid: when searching `@lang:markdown` without additional text, the settings editor sorts by ToC order but does not prioritize modified (configured) settings. The `sortResults` method in settingsTreeModels.ts has no logic to bubble up `isConfigured` settings.

## Change summary

When filtering settings by language (`@lang:X`), modified settings should appear first in the results.

## Best solution

In `settingsTreeModels.ts`'s `sortResults`, when a language filter is active and the query is filter-only (no free text), sort configured settings before unconfigured ones as a primary key, then by ToC order as a secondary key. The `isConfigured` status is already computed per-setting via `inspectSetting`.
