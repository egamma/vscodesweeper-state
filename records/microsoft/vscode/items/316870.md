# Issue #316870 — VS Code Installer Option Add "Open with Code" action to Windows Explorer directory context menu failed

[https://github.com/microsoft/vscode/issues/316870](https://github.com/microsoft/vscode/issues/316870)

## Summary

Valid bug confirmed in installer source: on Windows 11, the 'addcontextmenufolders' task is effectively inoperative because the legacy folder registry keys are skipped (ShouldUseWindows11ContextMenu is true) and the Windows 11 context menu title registration at Software\Classes\{RegValueName}ContextMenu is only created when 'addcontextmenufiles' is also selected.

## Change summary

On Windows 11, checking only 'Add Open with Code action to directory context menu' (without the file context menu option) does not produce any directory context menu entry.

## Best solution

The installer should either register a separate Windows 11 context menu entry gated on 'addcontextmenufolders', or the appx package registration logic should consider both tasks independently. The fix belongs in build/win32/code.iss — likely adding a Tasks condition or a separate registry entry for the folder case on Windows 11.
