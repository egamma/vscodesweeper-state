# Issue #162030 — [css] CSS custom property completions

[https://github.com/microsoft/vscode/issues/162030](https://github.com/microsoft/vscode/issues/162030)

## Summary

The requested typed custom-property support remains absent from the current CSS language service, and this team-authored Backlog item is the canonical request identified by the CSS maintainer. Keep it open for implementation in the language-service dependency.

## Change summary

Use CSS @property registrations to complete custom-property names and validate assigned values against their declared syntax.

## Best solution

Enhance microsoft/vscode-css-languageservice so @property registrations participate in custom-property symbols, completions, and syntax-aware validation, then consume that service update in VS Code.
