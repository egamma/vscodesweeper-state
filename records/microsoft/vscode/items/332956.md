# Issue #332956 — GIT Count BAdge

[https://github.com/microsoft/vscode/issues/332956](https://github.com/microsoft/vscode/issues/332956)

## Summary

Same reporter filed this exact defect four months ago as an open, still-unresolved issue; this is a duplicate of that report, and the code confirms the underlying defect is real.

## Change summary

With `scm.countBadge` set to `all`, the Source Control activity-bar badge only shows the count of the currently focused repository instead of the sum across all repositories.

## Best solution

Consolidate onto https://github.com/microsoft/vscode/issues/313682 (already assigned to the SCM area owner) — fix `SCMActiveRepositoryController`/`SCMViewService` so the `all` count-badge mode sums `this.repositories` rather than `visibleRepositories`, which collapses to the focused repo under single-selection mode.
