# Issue #335691 — Add a command to focus and expand the Chat “Files changed” list

[https://github.com/microsoft/vscode/issues/335691](https://github.com/microsoft/vscode/issues/335691)

## Summary

Real, well-scoped accessibility gap: VS Code already ships an analogous command for the agent TODO list (`workbench.action.chat.focusTodosView` in chatActions.ts) but nothing equivalent exists for the chat editing session's 'Files changed' (working set) list — confirmed by tracing chatWidget.ts and chatInputPart.ts, where no focus/toggle method exists for the working-set list.

## Change summary

Add a command that expands the Chat 'Files changed' list if collapsed and moves keyboard focus into it (and back), mirroring the existing TODO-list focus command.

## Best solution

Add a `focusWorkingSet`/`toggleWorkingSetFocus` pair on ChatWidget (analogous to `focusTodosView`/`toggleTodosViewFocus` in chatWidget.ts) plus a matching `workbench.action.chat.focusFilesChanged`-style Action2 in chatActions.ts, reusing `setWorkingSetCollapsed`/list APIs already in chatInputPart.ts.
