# Issue #335691 — Add a command to focus and expand the Chat “Files changed” list

[https://github.com/microsoft/vscode/issues/335691](https://github.com/microsoft/vscode/issues/335691)

## Summary

Fresh, well-articulated accessibility/keyboard-navigation gap: the Chat 'Files changed' list has no dedicated command to expand and focus it, confirmed by reading the source — routing to the chat area for triage rather than closing.

## Change summary

Add a command that expands the Chat 'Files changed' list (if collapsed) and moves keyboard focus into it, so the whole review flow can be done via keybindings without the mouse.

## Best solution

Add a registered command/action (e.g. in src/vs/workbench/contrib/chat/browser/actions or chatMultiDiffContentPart.ts) that expands the multi-diff 'Files changed' section and calls .focus()/domFocus() on its WorkbenchList, restoring the last-focused item when available, so it can be bound in keybindings.json alongside the existing workbench.action.chat.focusInput.
