# Issue #344205 — Copilot Chat: agent session web_fetch asks to confirm every URL, chat.tools.urls.autoApprove has no effect

[https://github.com/microsoft/vscode/issues/344205](https://github.com/microsoft/vscode/issues/344205)

## Summary

The Agent Host approval path has no URL-rule handling, so the reported settings-parity gap remains on main. The reproduction example also uses an array where the setting requires an object, but correcting that syntax does not address the missing integration.

## Change summary

Honor persistent URL approval preferences for Copilot Agent Host web_fetch calls without requiring blanket or session-only tool approval.

## Best solution

Make Agent Host fetch approvals honor the existing URL-pattern approval contract across sessions while preserving runtime-enforced restrictions and managed confirmations. Coordinate with the network-filter work without treating network authorization and user confirmation preferences as interchangeable.
