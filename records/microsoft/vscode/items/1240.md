# Issue #1240 — Support contributing different keybindings based on keyboard layout

[https://github.com/microsoft/vscode/issues/1240](https://github.com/microsoft/vscode/issues/1240)

## Summary

This remains the canonical, strongly supported request for layout-specific default keybindings. Current main detects keyboard layouts but still defines defaults only by operating system, leaving the central gap unresolved.

## Change summary

Ship and dynamically select default keybinding variants appropriate to the active keyboard layout.

## Best solution

Extend default-keybinding registration and resolution to support layout-specific variants while preserving user overrides and updating them when the active layout changes. The design belongs in the keybinding registry and workbench keyboard-layout service, with curated variants introduced incrementally for affected layouts.
