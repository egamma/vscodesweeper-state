## Summary

Team-authored (COLLABORATOR) feature request with a real version milestone (1.140.0) assigned, so it stays open under the milestone keep-open rule regardless of scope or complexity; it's also a large, unimplemented multi-session comparison workflow with no code on main yet.

## Change summary

Add a 'Compare Attempts' workflow to the Agents window that fans a prompt out to multiple harness-specific sessions in isolated worktrees and presents a code-oriented comparison (diffs, tests, diagnostics, usage) so the user can pick or synthesize a winner.

## Best solution

Design and land incrementally per the issue's own 'Suggested initial scope': comparison toggle in the new-session input, multi-select harness picker, fan-out to worktree-isolated sessions grouped for comparison, then a basic comparison view; defer auto-synthesis and cleanup to follow-up work. Related: https://github.com/microsoft/vscode/issues/329648 for provider-aware session creation feeding the multi-harness fan-out.
