# Issue #304405 — Copilot Chat sending messages I did not type / auto-submitting prompts

[https://github.com/microsoft/vscode/issues/304405](https://github.com/microsoft/vscode/issues/304405)

## Summary

Keep open: two reporters observed Autopilot starting additional turns without user input, and a maintainer confirmed that completing a task should not send another request. Current main still contains multiple automatic-continuation paths, so the exact trigger needs diagnosis rather than a close.

## Change summary

Autopilot can submit generated prompts repeatedly after completing a task or when the user changes the selected model or agent.

## Best solution

Determine whether the reported turns originate from the in-turn Autopilot continuation loop or the cross-turn auto-send handoff path, then ensure completion and model/agent changes cannot start an unintended continuation. Machine-generated continuation context must not appear as user-authored input, and cyclic continuations need a deterministic stop.
