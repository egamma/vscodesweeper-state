# Issue #169899 — Investigate performance of `menubar.updateOverflowAction`

[https://github.com/microsoft/vscode/issues/169899](https://github.com/microsoft/vscode/issues/169899)

## Summary

The reported performance hazard remains on current main: each title-bar layout schedules `updateOverflowAction`, which mutates layout-affecting state before synchronous width reads and then interleaves further DOM reads and writes. The issue should stay open for a focused menubar layout optimization.

## Change summary

Reduce forced synchronous layout and layout thrashing in `menubar.updateOverflowAction` while resizing a window with the custom title bar.

## Best solution

Separate the menubar's width measurements from its visibility and overflow mutations, preserving the existing responsive overflow behavior while avoiding repeated forced layouts during resize.
