# Issue #321473 — Drag-and-drop from remote -> desktop creates a file with remote file URI

[https://github.com/microsoft/vscode/issues/321473](https://github.com/microsoft/vscode/issues/321473)

## Summary

Verified duplicate: the older open canonical issue owns remote drag-and-drop to local destinations, and a maintainer previously consolidated the exact macOS `.inetloc` symptom into it.

## Change summary

Dragging an unsupported remote file to the macOS desktop creates an internet-location file containing the remote URI instead of rejecting the drop.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/93599 and ensure remote-resource drag data either supports a real local transfer or avoids exposing a standard URI that native macOS targets turn into an `.inetloc` file.
