# Issue #329750 — API-provided terminal editor icon is not preserved across window reload or restart

[https://github.com/microsoft/vscode/issues/329750](https://github.com/microsoft/vscode/issues/329750)

## Summary

Fresh, well-documented bug with clear repro steps; a plausible root cause is traceable in terminalInstance.ts, and a contributor has already offered to investigate and submit a fix, with the author's blessing.

## Change summary

A terminal editor tab's API-supplied ThemeIcon (via TerminalOptions.iconPath) reverts to the default shell icon after a window reload or full restart once the terminal is reattached/revived.

## Best solution

Ensure the persisted/attached process state (attachPersistentProcess) carries forward the original API-provided icon so terminalInstance.ts's `this._icon = this._shellLaunchConfig.attachPersistentProcess?.icon || this._shellLaunchConfig.icon` (lines ~534, ~1553, ~1639) doesn't silently drop it during reattach/revive; let the volunteering contributor (kKrishGupta) drive the fix and regression test.
