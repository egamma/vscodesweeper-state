# Issue #335883 — Error when invalid automation is imported could point to docs

[https://github.com/microsoft/vscode/issues/335883](https://github.com/microsoft/vscode/issues/335883)

## Summary

The documentation-discovery gap remains on current main: importing an unsupported schedule kind still produces only the generic property error. Keep this team-authored improvement open; the related import issues do not cover the same symptom.

## Change summary

Make invalid automation import errors point users to documentation explaining the supported blueprint properties and schedule examples.

## Best solution

Provide discoverable help from the automation import error to authoritative blueprint documentation, including how daily schedules are represented with cron expressions. Preserve the existing rejection of unsupported schedule kinds rather than changing the blueprint format.
