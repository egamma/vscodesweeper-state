# Issue #332618 — Markdown preview emits duplicate heading ids when a heading matches a generated suffix

[https://github.com/microsoft/vscode/issues/332618](https://github.com/microsoft/vscode/issues/332618)

## Summary

Confirmed source-level bug in the markdown heading slug builder, and there's already an open PR fixing it — best action is to review/land that PR rather than close or auto-fix here.

## Change summary

Markdown preview's heading-id deduper can reissue an id that was already generated as a `-N` suffix for an earlier heading, producing duplicate DOM anchor ids.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332628, which already fixes this collision-free-dedupe issue in `extensions/markdown-language-features/src/slugify.ts`; no further triage decision is needed beyond merging that PR.
