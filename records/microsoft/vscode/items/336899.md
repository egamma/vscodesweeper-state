# Issue #336899 — Markdown editor submits plan feedback comment when Enter confirms Japanese IME composition

[https://github.com/microsoft/vscode/issues/336899](https://github.com/microsoft/vscode/issues/336899)

## Summary

Well-documented, reporter-verified bug, but the actual defect lives in the bundled `@vscode/markdown-editor` npm package's CommentInputWidget key handler (compiled into extensions/markdown-language-features/markdown-editor-out/editor.js), not in this repo's own markdown-editor-src — the fix has to land upstream in that package before it can ship here.

## Change summary

Pressing Enter to confirm an active Japanese IME composition in the Markdown plan-feedback comment box also submits the comment, because the key handler doesn't check event.isComposing.

## Best solution

File/land the fix in the `@vscode/markdown-editor` package's CommentInputWidget key handler (add an `event.isComposing` guard before treating Enter as submit), then bump the `@vscode/markdown-editor` dependency version in extensions/markdown-language-features/package.json.
