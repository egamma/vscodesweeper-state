# Issue #293535 — Make message queueing screen reader friendly

[https://github.com/microsoft/vscode/issues/293535](https://github.com/microsoft/vscode/issues/293535)

## Summary

Keep open: current queue actions provide some functionality, but do not fully cover discoverable keyboard cancellation or the requested accessibility-help guidance. The maintainer's follow-up identifies cancellation as the remaining priority; no verified fix or same-symptom canonical was found.

## Change summary

Make queued chat messages discoverable and manageable with a screen reader, particularly cancelling queued requests without difficult keyboard navigation.

## Best solution

Provide a discoverable keyboard workflow for removing individual queued messages, documented in Chat Accessibility Help. Preserve existing queue and steering semantics, and assess the original announcement and send-immediately requests alongside the cancellation workflow.
