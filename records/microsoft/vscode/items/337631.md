# Issue #337631 — Claude agent host: native (Anthropic-auth) models hardcode supportsVision:false, so image paste is rejected

[https://github.com/microsoft/vscode/issues/337631](https://github.com/microsoft/vscode/issues/337631)

## Summary

Confirmed on current main: `fromSdkModelInfo` in claudeAgent.ts hardcodes `supportsVision: false` for native (non-Copilot) Claude models, so image paste is rejected for every Anthropic-auth model even though the models support vision — this is a real, narrow, source-confirmed bug worth fixing.

## Change summary

Native (Anthropic OAuth/API-key) Claude models always report supportsVision:false in the agent host, so pasting an image into a native Claude chat is rejected with '<model> does not support images.'

## Best solution

Have `fromSdkModelInfo` (src/vs/platform/agentHost/node/claude/claudeAgent.ts) report vision support for native models instead of hardcoding false — either statically true (all current Claude model families support vision) or derived from the model id/family — bringing native-transport parity with the Copilot-routed projection in `toAgentModelInfo`, which already reads a real vision flag.
