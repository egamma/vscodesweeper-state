# Issue #335679 — Partly scrolled away messages feel unnatural with chat image background in Agents

[https://github.com/microsoft/vscode/issues/335679](https://github.com/microsoft/vscode/issues/335679)

## Summary

Keep open for Agents-window scroll-edge polish: current source deliberately suppresses scroll shadows over custom backgrounds, leaving the reported abrupt clipping without an elevation cue. No qualifying fix or older canonical covering the complete reported symptom was established.

## Change summary

Make partially scrolled chat bubbles look naturally occluded rather than abruptly cut off or visually merged with adjacent messages over an Agents background image.

## Best solution

Give the custom-background transcript a coherent scroll-edge treatment that distinguishes pinned requests from scrolling responses while preserving stationary wallpaper. Coordinate the design with the related sticky-message separation work without folding this older report into a newer issue.
