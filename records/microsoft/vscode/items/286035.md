# Issue #286035 — Ensure context (screenshots, divs, highlighted lines) from VSCode Cloud Agent is attached to PR comments

[https://github.com/microsoft/vscode/issues/286035](https://github.com/microsoft/vscode/issues/286035)

## Summary

Keep open: supplied context still has no established path to reviewer-visible PR attachments or references, and current cloud-session follow-ups forward only the prompt text. This team-authored request has customer evidence and needs an end-to-end design rather than a cleanup close.

## Change summary

Preserve screenshots, selected code, and browser-element context in cloud-agent interactions and make that context visible or clearly referenced in resulting PR comments.

## Best solution

Provide an end-to-end context contract between VS Code cloud-session requests and PR comment publication, preserving supplied context through readable attachments or references and explicitly identifying unsupported context. Diagnose transport and publication separately so displaying context in VS Code is not mistaken for making it available to PR reviewers.
