## Summary

The simplified proposal is now implemented on main: `chat.defaultModel` is user-configurable and experiment-controlled, and new empty conversations consistently apply it instead of inheriting a model from the previous session.

## Change summary

Make the configured default chat model stronger than remembered model selection whenever a new conversation starts.

## Best solution

Keep the current `chat.defaultModel` behavior established by commit de7b8e2811af44a1f2683c21de870a5059536d5f: configured defaults seed every new conversation while explicit choices remain scoped to the active conversation.
