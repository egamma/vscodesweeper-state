# Issue #270170 — Default model in chat behaviour

[https://github.com/microsoft/vscode/issues/270170](https://github.com/microsoft/vscode/issues/270170)

## Summary

The simplified proposal is implemented on current main: `chat.defaultModel` is a user-configurable and experiment-controlled setting that seeds every new conversation while preserving explicit choices within existing conversations.

## Change summary

Make the chat default model less dependent on globally remembered selections by exposing a configurable default and applying it whenever a new conversation starts.

## Best solution

Keep the implemented `chat.defaultModel` precedence: configuration or experiment defaults seed new conversations, explicit selections remain conversation-local, and unavailable configured models fall back to the provider-declared default.
