# Issue #339906 — Comparison fails to start due to workspace isolation

[https://github.com/microsoft/vscode/issues/339906](https://github.com/microsoft/vscode/issues/339906)

## Summary

The source still explains the reported failure: comparisons require worktrees, while repositories without an initial commit advertise folder-only isolation. Keep this team-authored report open to resolve the unsupported-repository experience rather than treating the generic host error as a completed outcome.

## Change summary

Starting a model comparison in a newly initialized, empty Git repository fails every attempt with a misleading workspace-isolation error.

## Best solution

Detect the repository prerequisite before launching comparison attempts and give actionable guidance, while preserving independent worktree isolation. A maintainer should decide whether empty repositories remain explicitly unsupported or gain a supported initialization workflow.
