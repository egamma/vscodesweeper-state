# Issue #349303 — Assisted permissions: skipping one out-of-scope edit causes all edited files to be missing from the agent’s changes list

[https://github.com/microsoft/vscode/issues/349303](https://github.com/microsoft/vscode/issues/349303)

## Summary

Keep open: the supplied steps and partial-patch logs are sufficient to retest. Current main accepts file-edit records from failed tools, but its snapshot lifecycle may discard changes when a failed patch lacks a post-tool snapshot; the exact runtime sequence remains unconfirmed.

## Change summary

Skipping a later edit in a multi-file patch leaves earlier applied changes on disk but absent from the agent's changes list.

## Best solution

Ensure the Copilot edit-tracking lifecycle records every actually applied change even when the enclosing patch fails after a declined permission. Preserve the declined edit and failed-tool status rather than treating the entire patch as successful.
