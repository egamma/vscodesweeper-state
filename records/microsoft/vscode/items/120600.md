# Issue #120600 — Allow notebook-output to be marked as transient per instance

[https://github.com/microsoft/vscode/issues/120600](https://github.com/microsoft/vscode/issues/120600)

## Summary

A real notebook API gap remains on current main: output transience is fixed when the serializer is registered and cannot vary by notebook or output instance. This issue is already the open canonical request and correctly classified as under discussion.

## Change summary

Allow notebook extensions to decide per document or output instance whether outputs affect dirty state and persistence.

## Best solution

Add a supported per-instance transience mechanism, likely on `NotebookCellOutput`, and make notebook dirty tracking, snapshots, serialization, and diffs honor it while retaining registration-wide defaults.
