# Issue #320250 — Side Scroll speed control / recent increase if side scroll speed.

[https://github.com/microsoft/vscode/issues/320250](https://github.com/microsoft/vscode/issues/320250)

## Summary

Independent horizontal scrolling sensitivity remains missing from the editor. Keep this request open for discussion; the related system-scroll-speed issue does not cover the separate horizontal control requested here.

## Change summary

Allow users to adjust horizontal mouse-wheel scrolling speed without changing vertical scrolling speed, optionally respecting Windows scroll settings.

## Best solution

Provide independent horizontal sensitivity while preserving existing scrolling defaults and the shared sensitivity setting's compatibility. Coordinate Windows baseline behavior with https://github.com/microsoft/vscode/issues/112134 rather than making that a prerequisite for horizontal control.

The editor's scrollbar options expose horizontal visibility and sizing, not an independent horizontal speed multiplier.
- **current scrolling path:** src/vs/editor/browser/viewParts/editorScrollbar/editorScrollbar.ts passes the shared sensitivity to SmoothScrollableElement. In src/vs/base/browser/ui/scrollbar/scrollableElement.ts:476–477, _onMouseWheel multiplies both axes by that same value; horizontal displacement then uses SCROLL_WHEEL_SENSITIVITY at lines 520–524. Lowering the existing setting therefore also slows vertical scrolling.
