# Issue #176811 — Allow opening startup CPU profiles in VS Code or explorer 

[https://github.com/microsoft/vscode/issues/176811](https://github.com/microsoft/vscode/issues/176811)

## Summary

The startup profiler still lacks independent actions to open or reveal the generated profiles. Revealing a file currently requires choosing Create Issue and Restart, which does not cover inspecting profiles without filing an issue.

## Change summary

Provide direct actions to open startup CPU profiles in VS Code or reveal them in the file explorer.

## Best solution

Allow users to inspect generated profiles directly from the startup-profile completion dialog, independently of issue creation, while preserving the required restart flow.
