# Issue #176811 — Allow opening startup CPU profiles in VS Code or explorer 

[https://github.com/microsoft/vscode/issues/176811](https://github.com/microsoft/vscode/issues/176811)

## Summary

A usability gap remains: startup profiles can only be revealed as a side effect of creating an issue and cannot be opened directly. Keep this request open for a UX decision.

## Change summary

Add actions to open generated startup CPU profiles in VS Code or reveal them in the system file explorer.

## Best solution

Update `StartupProfiler` to offer explicit Open Profile and Reveal in File Explorer actions, reusing the built-in CPU profile viewer integration.
