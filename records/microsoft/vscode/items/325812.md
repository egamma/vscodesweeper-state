# Issue #325812 — Cannot set value in Watch by double click

[https://github.com/microsoft/vscode/issues/325812](https://github.com/microsoft/vscode/issues/325812)

## Summary

Confirmed on current main: the Watch view's double-click handler excludes nested `Variable` nodes, despite its comment saying primitive values should open an input box. The context-menu workaround remains available, but the inconsistent gesture is a real core debug-view bug.

## Change summary

Double-clicking a nested variable value in the Watch view no longer opens the value editor, while Set Value from the context menu still works.

## Best solution

Restore double-click value editing for eligible nested variables in the Watch view, matching the Variables view's capability and read-only checks while preserving top-level watch-expression renaming.
