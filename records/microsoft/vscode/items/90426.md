# Issue #90426 — Add ability for before decorations to indent (stretch across) word wrapped lines

[https://github.com/microsoft/vscode/issues/90426](https://github.com/microsoft/vscode/issues/90426)

## Summary

This is the canonical feature request for before-decorations to respect word-wrap indentation. Issue #170023 was closed as a duplicate of this one by alexdima, confirming it as the tracker. No implementation exists on main — the existing `wrappingIndent` setting applies to text lines, not to decoration content. Stays open as a valid, unimplemented request.

## Change summary

Before-decorations (e.g. GitLens gutter blame) break visual indentation on word-wrapped lines because wrapped view-lines don't carry the same before-decoration padding.

## Best solution

Extend the editor decoration rendering so that before-decorations can optionally stretch across or indent word-wrapped continuation lines, likely requiring changes in the view-line rendering pipeline (`src/vs/editor/browser/view/viewLayer.ts` and related decoration layout code). This is an editor-core change, not an extension API gap alone — alexdima noted new editor API may be needed.
