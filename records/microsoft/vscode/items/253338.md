# Issue #253338 — Unintuitive how to use ai search in settings view

[https://github.com/microsoft/vscode/issues/253338](https://github.com/microsoft/vscode/issues/253338)

## Summary

Team-authored UX polish request for the settings AI search discoverability. Subsequent commits (98b8d4a708b, 7721b268d7b) improved aspects of the AI search pill but did not address the core ask — making the pill itself the clickable entry point or adding visual cues (halo/glare) to invite interaction. Stays open.

## Change summary

The 'AI results available' pill in the settings search bar is unintuitive — users don't realize they should click the sparkle icon to see results.

## Best solution

Unify the notification and action: make the 'AI results available' pill itself clickable (or add a visual affordance like a glow/halo on the sparkle button) so the indication and the invitation to act are one gesture, not two disconnected elements.
