# Issue #253338 — Unintuitive how to use ai search in settings view

[https://github.com/microsoft/vscode/issues/253338](https://github.com/microsoft/vscode/issues/253338)

## Summary

The discoverability gap remains: current source announces AI results in a passive count pill while exposing them through a separate icon-only toggle. Keep this team-authored request open for an affordance decision; existing settings and keyboard access do not resolve the reported disconnect.

## Change summary

Make the Settings editor's AI-results availability indication clearly communicate how to reveal those results.

## Best solution

Give the AI-results availability state an explicit, discoverable activation affordance in the Settings search header. Settle whether the indication itself is actionable or clearly identifies the separate toggle, while preserving ordinary search and keyboard access.
