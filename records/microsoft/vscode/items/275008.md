Valid polish request: emoji completions show the emoji character as the primary label, which prevents match highlighting. ## Change summary

## Best solution

The emoji completion provider should swap its label and detail fields so the text code (`:apple:`) is the label (supporting fuzzy-match highlights) and the emoji character is the detail/description. The fix depends on which component provides the emoji completions — likely an extension or a built-in completion provider — and would be a small change to the CompletionItem construction.
