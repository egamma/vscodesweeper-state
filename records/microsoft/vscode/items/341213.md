# Issue #341213 — Copilot pipelines should follow the pinned Node.js version

[https://github.com/microsoft/vscode/issues/341213](https://github.com/microsoft/vscode/issues/341213)

## Summary

Thanks for the report. The gap is real on current main: .nvmrc pins 24.18.0, but two Azure Copilot pipeline files still hardcode 22.21.x, and the Copilot node_modules cache key does not include the Node version.

## Change summary

Make the Copilot Azure pipelines use the Node.js version pinned in .nvmrc and include that version in the dependency-cache key.

## Best solution

Switch build/azure-pipelines/copilot/setup-steps.yml to NodeTool with versionFilePath: .nvmrc, as the other pipelines do. Fix the recovery pipeline's nodeVersion, and add the Node version to the Cache@2 key.
