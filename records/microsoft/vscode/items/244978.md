# Issue #244978 — Unified MCP Server Management UI

[https://github.com/microsoft/vscode/issues/244978](https://github.com/microsoft/vscode/issues/244978)

## Summary

Current main provides a dedicated MCP management surface with status, lifecycle controls, output access, and some form-based configuration, but it does not establish full coverage of this request. Keep it under discussion for the remaining configuration and monitoring scope rather than closing it as completed or duplicating it into a broader cross-harness initiative.

## Change summary

Provide unified visual MCP server management with runtime status, controls, monitoring, connection details, and configuration editing without JSON.

## Best solution

Use the existing MCP Servers management surface rather than introduce a separate dashboard. Have the MCP owner decide whether to extend form editing to the remaining configuration sources and add defined performance or environment diagnostics, distinguishing those gaps from capabilities already available.
