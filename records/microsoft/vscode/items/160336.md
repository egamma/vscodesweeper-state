# Issue #160336 — Connecting via code-server shows the cwd in the terminal tab incorrectly

[https://github.com/microsoft/vscode/issues/160336](https://github.com/microsoft/vscode/issues/160336)

## Summary

The terminal label code still uses client-platform path handling when comparing a remote Windows cwd with the workspace root, allowing the root to appear unnecessarily on a macOS client. Keep this open; the related open reports are newer and cannot replace this previously reviewed issue.

## Change summary

Suppress the terminal tab's cwd-folder label when a remote Windows terminal is at its single workspace root, including when connected from macOS.

## Best solution

Make terminal cwd-folder labels respect the remote filesystem's path semantics while preserving the existing single-root suppression and multi-root disambiguation behavior.
