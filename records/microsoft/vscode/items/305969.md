# Issue #305969 — Go to Repeating Prompt with Each Character Typed When Using a Screen Reader

[https://github.com/microsoft/vscode/issues/305969](https://github.com/microsoft/vscode/issues/305969)

## Summary

Keep open: another user confirms the repeated Go to Line announcements, and current source still changes the input's ARIA popup state around typing and result focus. Linux Orca's non-reproduction of Ctrl+G does not resolve the Windows report; its separate Ctrl+P observation warrants checking the shared Quick Input path.

## Change summary

Prevent duplicate screen-reader announcements of the Go to Line navigation prompt while entering a line number.

## Best solution

Make Quick Input announce the updated destination without duplicate speech, while preserving character echo, input editing and result navigation. First reproduce the Windows Ctrl+G case and compare the Linux Orca Ctrl+P case to establish whether they share the same announcement trigger.
