# Issue #337981 — Agents window: picker changes made right after sending the first message are lost

[https://github.com/microsoft/vscode/issues/337981](https://github.com/microsoft/vscode/issues/337981)

## Summary

Clearly reported bug with a fix already in progress: an open PR by the same author (#337982, 'Fixes #337981') addresses it directly, so this should stay open until that PR lands rather than being closed now.

## Change summary

In the Agents window, picker changes (permission level, mode, sandbox, model, agent) made while the first message's session is still starting get silently reverted and never reach the agent host once the session finishes starting.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/337982, which adds a shared `_dispatchRunningSessionConfig` helper to send the draft's latest picks to the agent host once the session is ready, with four new tests in localAgentHostSessionsProvider.test.ts covering permission level, model/settings, custom agent, and default-agent switch-back.
