# Issue #282923 — Code Tab doesn't scroll up or down.

[https://github.com/microsoft/vscode/issues/282923](https://github.com/microsoft/vscode/issues/282923)

## Summary

The issue should remain open: after the initial non-reproduction close, a VS Code maintainer confirmed the same code-block selection scrolling defect and the issue was reopened because it persisted.

## Change summary

Selecting part of a generated chat code block with the keyboard does not automatically scroll when the selection endpoint moves outside the visible viewport.

## Best solution

Make keyboard-driven selection in partially visible chat code blocks scroll the containing chat response so the selection endpoint remains visible, while preserving normal code-block and whole-response scrolling behavior.
