# Issue #188781 — Too many icons in the Search title area

[https://github.com/microsoft/vscode/issues/188781](https://github.com/microsoft/vscode/issues/188781)

## Summary

The default Search toolbar still exposes the tree/list toggle inline, so the requested simplification remains outstanding. Maintainers supported the direction, and the later matching request was explicitly closed in favor of this issue.

## Change summary

Reduce Search title-area clutter by moving less-used actions, particularly the tree/list toggle, into a trailing overflow menu.

## Best solution

Provide a quieter default Search toolbar with the tree/list toggle available through the trailing overflow menu, preserving command access and existing toolbar customization. Confirm whether Refresh and Open New Search Editor should also be hidden by default.
