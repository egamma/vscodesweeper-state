# Issue #296269 — File remains changed when restoring a checkpoint

[https://github.com/microsoft/vscode/issues/296269](https://github.com/microsoft/vscode/issues/296269)

## Summary

Keep open: the current local-chat checkpoint path can restore an existing file's original contents while retaining its Modified state, leaving a zero-change row in the changed-files list. The related reports inspected do not establish an open canonical for this specific restoration defect.

## Change summary

Restoring a checkpoint should remove fully reverted files from the pending changed-files list rather than leave zero-change entries.

## Best solution

Make the local chat editing session's pending-file presentation accurately reflect the restored checkpoint: fully reverted existing text files should no longer appear as pending changes, while files with remaining edits stay visible. Preserve checkpoint redo and file creation/deletion semantics.
