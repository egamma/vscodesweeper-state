# Issue #323187 — Claude agent host undercounts on canceled credits

[https://github.com/microsoft/vscode/issues/323187](https://github.com/microsoft/vscode/issues/323187)

## Summary

Still open on main — the Claude agent session resets the per-turn credit accumulator at the start of each `send()` and enriches signals as they arrive, but on cancellation the client aborts eagerly before the proxy has flushed all pending credit reports, so the displayed total undercounts. No fix commit references this issue.

## Change summary

When a Claude agent turn is canceled, the client shows credits accumulated so far but misses unflushed credit reports still in transit from the proxy.

## Best solution

On cancellation, either wait for the proxy to flush its final credit report before surfacing the total (e.g. a short drain window or a final-credits callback), or retroactively update the displayed credits when late reports arrive. The fix likely touches `src/vs/platform/agentHost/node/claude/claudeAgentSession.ts` (the `_currentTurnNanoAiu` accumulator and `_enrichSignalWithCredits` path) and possibly the proxy service's cancellation flow in `claudeProxyService.ts`.
