# Issue #338055 — Copilot Chat: Repeated "Sign in to use GitHub Copilot" prompt on GHE.com; CopilotCLIModels returns 401 Bad credentials

[https://github.com/microsoft/vscode/issues/338055](https://github.com/microsoft/vscode/issues/338055)

## Summary

Verified duplicate: this is the same GHE.com Copilot auth defect (repeated sign-in prompt + 401 Bad credentials from CopilotCLIModels) already tracked by the earlier, open, maintainer-assigned https://github.com/microsoft/vscode/issues/337996, which covers the same and a broader agent-host symptom set — proposing consolidation there.

## Change summary

On GHE.com with the github-enterprise auth provider, CopilotCLIModels/agent host fails with 401 Bad credentials fetching Copilot user info, causing a repeated 'Sign in to use GitHub Copilot' prompt even after successful enterprise sign-in.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/337996 (already assigned) — the fix is to stop hardcoding the Copilot auth/user-info host to github.com when the github-enterprise auth provider is configured, in extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCli.ts (getAuthInfo() falls back to host: 'https://github.com') and the corresponding agent-host auth path.
