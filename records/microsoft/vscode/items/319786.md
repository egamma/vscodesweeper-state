# Issue #319786 — Hard to discover no-code themes in Marketplace search

[https://github.com/microsoft/vscode/issues/319786](https://github.com/microsoft/vscode/issues/319786)

## Summary

This remains a valid Backlog Candidates feature request whose community voting window is still active. Current main tracks whether extensions execute code but offers no corresponding Marketplace search filter.

## Change summary

Allow users to filter Marketplace theme searches to extensions that contain no executable code.

## Best solution

Add an executable-code filtering capability to the Marketplace API, then expose it through the Extensions view's query syntax and theme-search UI.
