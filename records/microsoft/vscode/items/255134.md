# Issue #255134 — Git - Add Git Tools for VS Code Copilot (git_status, git_diff, git_branch, git_log)

[https://github.com/microsoft/vscode/issues/255134](https://github.com/microsoft/vscode/issues/255134)

## Summary

Keep open: terminal auto-approval and the existing changes tool address part of the request, but do not provide the full native, structured status, diff, branch, and history interface. Related open issues cover narrower capabilities, not a verified canonical for this report.

## Change summary

Expose native Copilot tools for structured Git status, filtered diffs, branch information, and commit history without per-command terminal interaction.

## Best solution

Define a read-only Git tool contract using the existing Git integration, complementing rather than duplicating get_changed_files. Settle the tool surface and supported filters before implementation, while retaining applicable permission controls and bounded output.

- **Behavior:**

  > Copilot should obtain local repository status, selected-file differences, branch information, and filtered commit history through native tools with predictable machine-consumable results. Supported read-only requests should not require launching a terminal or approving each shell command, while still honoring applicable permission controls. Acceptance should cover repositories with staged, unstaged, and untracked files, multiple branches and commits, and explicit repository selection in a multi-repository workspace. The exact tool surface, filters, and result contract must be agreed before implementation.
- **Trace:**

  > GetScmChangesTool in extensions/copilot/src/extension/tools/node/scmChangesTool.ts resolves an explicit or active repository through IGitService, selects change groups, retrieves diffs through IGitDiffService, and emits prompt/text parts with file-count and timeout limits. Its manifest registration in extensions/copilot/package.json exposes repositoryPath and sourceControlState, not file filtering, branch listing, or history. extensions/copilot/src/platform/git/common/gitService.ts already provides repository and branch metadata plus access to the underlying Repository; extensions/git/src/api/git.d.ts defines status, branch, log, and diff capabilities.
