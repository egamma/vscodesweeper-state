## Change summary

Show a list of all functions/symbols on the editor scrollbar when hovering, positioned proportionally to their file location, as an alternative to the minimap.

## Best solution

This would be a significant new UI surface on the editor scrollbar, blending outline/symbol data with scrollbar interaction. The closest existing features are the minimap (visual code overview) and the Outline view (symbol list in the sidebar), but neither provides an interactive symbol overlay on the scrollbar itself. If pursued, it would likely live in the editor scrollbar contribution area. Given the niche appeal and UI complexity, this could also be an extension-candidate if the scrollbar extensibility API were available — but no such API exists today.
