# Issue #324365 — Function List on Scrollbar Hover

[https://github.com/microsoft/vscode/issues/324365](https://github.com/microsoft/vscode/issues/324365)

## Summary

A real navigation gap remains: VS Code can list document symbols and show explicit section headers in the minimap, but it does not expose language-service functions as a position-aligned list on scrollbar hover. Keep this open for interaction and accessibility design discussion.

## Change summary

Show an interactive, position-aligned list of functions when hovering over the editor scrollbar, potentially as an alternative to the minimap.

## Best solution

If pursued, provide a keyboard-accessible document-symbol navigation surface aligned with positions in the file, while preserving existing minimap behavior unless the user explicitly selects an alternative mode. The design should resolve whether this belongs in the minimap, scrollbar, or existing Outline experience before implementation.
