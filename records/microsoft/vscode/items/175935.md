# Issue #175935 — Quick open renders icons from file names

[https://github.com/microsoft/vscode/issues/175935](https://github.com/microsoft/vscode/issues/175935)

## Summary

Quick Open still interprets filename text as theme-icon markup when highlighting does not split the icon token. Keep this accepted bug open; the related broader report is newer and cannot replace this re-reviewed item.

## Change summary

Display filenames containing theme-icon syntax, such as $(zap).ts, literally in Quick Open.

## Best solution

Quick Open file results should preserve literal filenames and directory descriptions, including their search highlights, while retaining intentional icons in other quick-pick providers and the normal file-type icon.
