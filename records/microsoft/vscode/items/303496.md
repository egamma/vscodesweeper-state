## Summary

## Change summary

Ensure Copilot generates commands compatible with its terminal shell or lets users select a separate agent shell without changing their interactive default.

## Best solution

Consolidate the remaining fish command-generation failures under https://github.com/microsoft/vscode/issues/286146, preserving this report's Remote-SSH environment and repeated steering failures. The existing chat.tools.terminal.terminalProfile.linux and chat.tools.terminal.terminalProfile.osx settings already provide the requested independent agent-shell selection.
