## Change summary

In voice mode, the mic mute/unmute toggle icon shows the action that will happen rather than the current microphone state, which feels reversed.

## Best solution

Swap the ternary at voiceInputModeActionViewItem.ts:681 so the glyph reflects current state (crossed/muted icon while muted, plain mic while live) instead of the available action; this directly matches the reporter's and commenter's expectation.
