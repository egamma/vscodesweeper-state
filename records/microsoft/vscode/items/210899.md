# Issue #210899 — File Explorer Collapsed Items Focus Issue

[https://github.com/microsoft/vscode/issues/210899](https://github.com/microsoft/vscode/issues/210899)

## Summary

The bug remains source-reproducible on current main: rerendering a compressed Explorer row recreates its navigation controller and resets the active segment to the deepest item. This team-authored Backlog bug should remain open for a bounded fix.

## Change summary

Preserve the explicitly focused segment of a compressed File Explorer path when the row rerenders after VS Code loses focus.

## Best solution

Preserve a compressed row's active segment across rerenders while retaining the deepest segment as the initial default and leaving explicit mouse and keyboard navigation unchanged.
