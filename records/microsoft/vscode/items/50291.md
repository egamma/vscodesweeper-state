[https://github.com/microsoft/vscode/issues/50291](https://github.com/microsoft/vscode/issues/50291)

## Summary

Keep this canonical Backlog request open. Static suggestion-type settings provide only a partial workaround; the requested in-widget, temporary category filtering remains absent and has strong community support.

## Change summary

Add mouse- and keyboard-accessible type/category filters to the active IntelliSense suggestion widget.

## Best solution

Add temporary completion-kind toggles to the suggest widget status bar, with commands scoped to the active widget, while retaining `editor.suggest.show*` settings as persistent defaults. The implementation belongs in the editor suggest controller, widget, and model.
