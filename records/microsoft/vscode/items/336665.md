# Issue #336665 — Allow agents to create research sessions without a new worktree

[https://github.com/microsoft/vscode/issues/336665](https://github.com/microsoft/vscode/issues/336665)

## Summary

The exact capability and clarity requested already exist in the `create_session` tool schema on main: `relationship: 'currentSession'` never allocates a worktree (it shares the current workspace), and for `independent` work the schema explicitly documents that omitting `worktree` inherits the creating session's isolation and that `worktree: false` opts out — so there's already a clear, documented way to avoid worktree creation for research-only work.

## Change summary

Requests an explicit, unambiguous way for an orchestrating agent to create a delegated session without allocating a new Git worktree, since omitting the `worktree` option still created one.

## Best solution

Keep the current design: guide agents to use `relationship: 'currentSession'` for research/delegated work that doesn't need isolation (no worktree ever created), and use `worktree: false` explicitly with `relationship: 'independent'` when isolation truly isn't wanted — both paths and their semantics are already spelled out in the tool's `inputSchema` descriptions.
