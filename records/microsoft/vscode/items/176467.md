# Issue #176467 — Allow VS-code to respect native titlebar decorations configuration on GNOME/Linux

[https://github.com/microsoft/vscode/issues/176467](https://github.com/microsoft/vscode/issues/176467)

## Summary

The central request—respecting Linux system preferences for window-control visibility and placement within the custom title bar—is implemented upstream and adopted on current main. Exact desktop-themed button appearance remains separate work tracked by an open follow-up.

## Change summary

Respect GNOME/Linux preferences for which title-bar buttons appear and where they are placed while retaining VS Code's integrated custom title bar.

## Best solution

Close the implemented visibility/layout request as completed, retaining window.titleBarStyle="custom" and window.controlsStyle="native". Track the remaining system-themed icon and styling improvements in https://github.com/microsoft/vscode/issues/337058 rather than treating them as an unresolved button-layout requirement.
