# Issue #176467 — Allow VS-code to respect native titlebar decorations configuration on GNOME/Linux

[https://github.com/microsoft/vscode/issues/176467](https://github.com/microsoft/vscode/issues/176467)

## Summary

Keep open as an upstream-tracked Linux integration request. VS Code already enables Electron's window-controls overlay, but recent confirmations show that respecting GNOME's configured button visibility and placement remains incomplete; Electron 43 may supply the remaining behavior and needs validation during the current integration.

## Change summary

Make custom title bars on GNOME/Linux honor the native window-control visibility, ordering, placement, and appearance configured by the desktop environment.

## Best solution

Validate Electron 43's Linux window-control-layout support in VS Code with `window.titleBarStyle: custom`, then retain this issue until native button visibility and left/right placement match GNOME settings; remaining defects should be fixed upstream in Electron.
