# Issue #333978 — Chat / Agents: Git ignored files cannot be referenced in the chat or agents

[https://github.com/microsoft/vscode/issues/333978](https://github.com/microsoft/vscode/issues/333978)

## Summary

The chat/agents `@`/`#` file picker reuses VS Code's standard `AnythingQuickAccessProvider` (the same 'Go to File' quick-open used app-wide), which honors `search.useIgnoreFiles` (default `true`) and excludes `.gitignore`'d files by design — this matches editor-wide file search behavior, not a chat-specific defect.

## Change summary

Git-ignored files in the workspace cannot be attached/referenced via @ or # in chat/agent context.

## Best solution

Keep the existing behavior: it is consistent with Quick Open and workspace file search elsewhere in the product. The reporter can set `search.useIgnoreFiles: false` (and related `search.useGlobalIgnoreFiles`/`search.useParentIgnoreFiles`) to include gitignored files, the same as they would for Quick Open.
