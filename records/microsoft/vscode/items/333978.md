# Issue #333978 — Chat / Agents: Git ignored files cannot be referenced in the chat or agents

[https://github.com/microsoft/vscode/issues/333978](https://github.com/microsoft/vscode/issues/333978)

## Summary

Current main confirms the bug: chat and Agents `@`/`#` file completions pass `explorer.excludeGitIgnore` directly as `disregardIgnoreFiles`, reversing the setting's meaning. The shared completion path should remain open for a bounded correction and regression test.

## Change summary

Git-ignored workspace files do not appear in Chat or Agents file-reference completions when the Explorer is configured to show them.

## Best solution

Make the shared chat file search follow `explorer.excludeGitIgnore` consistently with the Explorer: include Git-ignored files when the setting is false and exclude them when it is true.
