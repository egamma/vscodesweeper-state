# Issue #285515 — GitHub Copilot Chat does not recognize multi-folder workspace structure in @ mentions

[https://github.com/microsoft/vscode/issues/285515](https://github.com/microsoft/vscode/issues/285515)

## Summary

The reported multi-folder context gap is resolved by the merged context-reference completion work: `@` now invokes the same file and folder provider as `#`, and that provider searches every workspace folder.

## Change summary

Make files and directories from every folder in a multi-root workspace available through Copilot Chat context mentions.

## Best solution

Keep the unified `@` and `#` context-reference behavior from commit 98c60a142fb20a59cdf4602f056418e46a9880de, with file and folder searches spanning every entry returned by the workspace context service.
