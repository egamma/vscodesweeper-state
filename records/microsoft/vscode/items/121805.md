# Issue #121805 — "Reopen folder using..." should use a more dedicated ux solution, not notifications

[https://github.com/microsoft/vscode/issues/121805](https://github.com/microsoft/vscode/issues/121805)

## Summary

The core request — replace startup notifications for workspace files with a more integrated UX — remains unaddressed on current main. The `WorkspacesFinderContribution` still uses `notificationService.prompt` for `.code-workspace` discovery. Keeping open as a valid under-discussion UX improvement.

## Change summary

Replace notification-based prompts for reopening folders (dev containers, .code-workspace files) with a dedicated UX surface like explorer badges or welcome-view buttons.

## Best solution

Implement a non-notification discovery surface (e.g. explorer badge, editor area hint, or welcome view button) for workspace-reopen suggestions. The workspace-file notification lives in `src/vs/workbench/contrib/workspaces/browser/workspaces.contribution.ts`; the dev container notification is owned by the Remote Containers extension. A unified approach would benefit both.
