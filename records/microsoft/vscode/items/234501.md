# Issue #234501 — The font of global search bar and search bar should be a monospace font.

[https://github.com/microsoft/vscode/issues/234501](https://github.com/microsoft/vscode/issues/234501)

## Summary

Keep open as a typography feature request: the inspected search settings do not provide editor-font inheritance for search inputs and results. Older requests overlap, but none verified here covers the full scope closely enough for this re-reviewed item's duplicate bar.

## Change summary

Allow editor find, workspace search inputs, and search results to use the same monospace font as the editor.

## Best solution
