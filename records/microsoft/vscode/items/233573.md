# Issue #233573 — When searching rtl letters in Arabic using `Ctrl+F` the word gets reversed and disconnected

[https://github.com/microsoft/vscode/issues/233573](https://github.com/microsoft/vscode/issues/233573)

## Summary

Still reproduces on main: find decorations use inline text styling that breaks bidi runs in RTL text, causing visually reversed/disconnected highlights. An open PR (#314872) addresses this but has not merged yet.

## Change summary

Ctrl+F find highlights in Arabic/RTL text cause the matched word to appear reversed and disconnected due to inline decoration styling splitting bidi runs.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/314872, which makes find match decorations RTL-aware by avoiding inline text styling for lines containing RTL content. The fix is localized to `findDecorations.ts`.
