# Issue #291518 — Sign-in can get stuck from Chat

[https://github.com/microsoft/vscode/issues/291518](https://github.com/microsoft/vscode/issues/291518)

## Summary

Keep open: the Chat setup agent still drops the request cancellation token, so stopping an unfinished sign-in leaves subsequent requests waiting on the same setup promise. The linked fix attempt was closed without merging.

## Change summary

Allow sign-in to be retried after abandoning browser authentication and stopping the initiating Chat request.

## Best solution

Chat Stop should release the canceled setup operation so another request can start sign-in without reloading VS Code. Preserve ordinary concurrent-request deduplication and distinguish canceling Chat setup from canceling the underlying authentication provider.
