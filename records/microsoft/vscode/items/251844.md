# Issue #251844 — Add "Admin Contact Info" policy

[https://github.com/microsoft/vscode/issues/251844](https://github.com/microsoft/vscode/issues/251844)

## Summary

Keep open: current policy indicators identify managed settings but do not provide administrator-configured contact information. The proposed implementation was closed without merging, and a maintainer explicitly consolidated another organization's request into this issue.

## Change summary

Allow administrators to configure a support email or URL that VS Code can display when device policy restricts a setting or feature.

## Best solution

Provide administrator-managed contact metadata and actionable contact information on relevant policy-restriction surfaces, preserving the distinction between device and account policy. Agree on the initial presentation scope and whether the requested extension API belongs in this work before implementation.
