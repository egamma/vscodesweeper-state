# Issue #46331 — Spacing or Horizontal lines in custom VS Code grammar

[https://github.com/microsoft/vscode/issues/46331](https://github.com/microsoft/vscode/issues/46331)

## Summary

Implemented and shipped: TextMate scopes can now apply custom line-height multipliers, enabling the requested visual spacing between grammar-defined blocks.

## Change summary

Allow custom grammar scopes to visually separate logical blocks with additional vertical spacing or divider-like styling.

## Best solution

Use a custom TextMate scope with `editor.tokenColorCustomizations.textMateRules[].settings.lineHeight`; variable line heights landed in commit 91eec7195551d6978f7c4abda653d5bf839a9c5a and shipped in VS Code 1.100.0.
