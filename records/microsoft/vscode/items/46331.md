# Issue #46331 — Spacing or Horizontal lines in custom VS Code grammar

[https://github.com/microsoft/vscode/issues/46331](https://github.com/microsoft/vscode/issues/46331)

## Summary

The requested larger spacing for grammar-defined blocks is now supported through scope-specific line heights. The implementation supersedes the thread's equal-line-height limitation and satisfies the spacing alternative without inserting characters into the document.

## Change summary

Allow a custom grammar's logical blocks to be visually separated by larger spacing or horizontal rules without changing the file contents.

## Best solution

Use editor.tokenColorCustomizations.textMateRules to assign a larger lineHeight to the custom grammar's block-boundary scope, with editor.allowVariableLineHeights enabled. Close as completed for the spacing alternative; horizontal rules remain a separate decoration-based option, not a TextMate theme property.
