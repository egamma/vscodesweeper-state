# Issue #317033 — Markdown keeps scrolling to a specific position when switching tabs

[https://github.com/microsoft/vscode/issues/317033](https://github.com/microsoft/vscode/issues/317033)

## Summary

Confirmed bug: the markdown preview's scroll position is stored permanently in `#previousStaticEditorInfo` and forcibly re-applied to the text editor on every tab switch via the `onDidChangeActiveTextEditor` handler in `previewManager.ts`, because unlike `getPreviousTextEditorLineByUri`, the static variant never clears the stored entry.

## Change summary

After exiting markdown preview mode, the text editor's scroll position snaps back to the preview's last scroll position every time the user switches tabs.

## Best solution

Fix the scroll-lock by clearing the `#previousStaticEditorInfo` entry after it is consumed in the `onDidChangeActiveTextEditor` handler (mirroring how `getPreviousTextEditorLineByUri` already deletes its entry on read), or by clearing it when the preview is disposed / the user exits preview mode. The fix is in `extensions/markdown-language-features/src/preview/topmostLineMonitor.ts` and/or `extensions/markdown-language-features/src/preview/previewManager.ts`.
