# Issue #332117 — Markdown editor lets you edit a staged file, and then shows text that is not actually staged

[https://github.com/microsoft/vscode/issues/332117](https://github.com/microsoft/vscode/issues/332117)

## Summary

The staged-revision edit path remains unguarded on current main: Markdown's user-selectable reading mode does not enforce the resource's read-only status. Keep this open as a bounded correctness bug; no verified canonical or completed fix covers it.

## Change summary

Prevent the Markdown editor from accepting edits to staged, read-only revisions and displaying content that differs from the Git index.

## Best solution

The Markdown editor should respect resource writability independently of its remembered Locked/Editing preference, preserving staged content in both the webview and shared document model. Normal writable Markdown documents should retain their existing editing and mode-preference behavior.
