# Issue #71712 — [folding] Distinctly highlight corresponding `#endregion` for `#region X` comments

[https://github.com/microsoft/vscode/issues/71712](https://github.com/microsoft/vscode/issues/71712)

## Summary

A real editor-folding gap remains: current main knows each region's start and end lines but does not visually pair them when the cursor is on a marker. No older issue with the same observable request was found, so this stale Backlog request should remain open under discussion rather than be closed.

## Change summary

Visually distinguish the matching `#endregion` when the cursor is on a `#region` marker, across languages that support region folding.

## Best solution

If accepted by the editor area, provide a cursor-sensitive, themeable paired-marker treatment for `FoldingRangeKind.Region`, consistent with existing bracket-pair feedback and without making the behavior language-specific.

## Evidence

- **current source gap:** `src/vs/editor/contrib/folding/browser/foldingRanges.ts` retains start and end line numbers plus the folding-range type, so region pairing is available, but there is no state or decoration for an active corresponding marker.
- **decoration behavior:** `src/vs/editor/contrib/folding/browser/foldingDecorations.ts` decorates collapsed or expanded folding ranges and optionally highlights collapsed content; it does not distinguish the matching end marker of the region under the cursor.
- **cursor behavior:** `src/vs/editor/contrib/folding/browser/folding.ts` listens for cursor movement only to reveal a cursor that enters hidden folded content; it does not update paired region-marker decorations.
- **existing capability check:** The `editor.foldingHighlight` option in `src/vs/editor/common/config/editorOptions.ts` is documented as highlighting folded ranges and is applied only to collapsed-range decorations, so it does not satisfy the requested expanded-region correspondence.
- **canonical search:** Searches for region-boundary, matching-region, and `#endregion` highlighting issues found no open issue owning this request. https://github.com/microsoft/vscode/issues/38149 is older and related, but requests showing the region description on hover rather than visually pairing the markers.
