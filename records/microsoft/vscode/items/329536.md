# Issue #329536 — Cannot open Themes menu. Opens for a split second and then closes

[https://github.com/microsoft/vscode/issues/329536](https://github.com/microsoft/vscode/issues/329536)

## Summary

Already fixed on main: this is the same 'Modern UI' toolbar-menu-closes-quick-pick-immediately regression tracked and fixed via PR #329327 (merged as commit b966285933b27aaa9be0904c1c6f2bbe666aefa9), which explicitly fixes the closely related issue https://github.com/microsoft/vscode/issues/328190 ('Cannot open Color Theme menu when Modern UI is enabled') and several duplicates with the identical symptom (menu flashes and closes, keyboard shortcut works as a workaround).

## Change summary

Clicking Manage → Themes opens the theme picker for a fraction of a second before it closes, making selection impossible; Ctrl+K Ctrl+T works fine as a workaround.

## Best solution

Keep the shipped fix in commit b966285933b27aaa9be0904c1c6f2bbe666aefa9 (PR #329327, targeting 1.132.1/1.133.0) — animated context views no longer let toolbar menu mouse-out handling reclaim focus and close a freshly opened quick pick. No further change needed; ask the reporter to confirm on the next stable release.
