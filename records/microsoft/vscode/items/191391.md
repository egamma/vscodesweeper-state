# Issue #191391 — Extension Contributed Menu Item: resourceFilename does not work as expected

[https://github.com/microsoft/vscode/issues/191391](https://github.com/microsoft/vscode/issues/191391)

## Summary

The bug remains source-reproducible on main: compact-folder context menus can evaluate `resourceFilename` for a different explorer item than the resource passed to the contributed command. This team-authored, accepted bug should remain open.

## Change summary

Extension-contributed Explorer menu items guarded by `resourceFilename` appear inconsistently for compact folders.

## Best solution

Make the Explorer's resource context keys and command target consistently refer to the active segment of a compact folder, with regression coverage in the existing Explorer context-menu tests.

Those values can differ for a compact-folder row.
