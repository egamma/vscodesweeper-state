# Issue #345617 — Disabling a failing timeline provider also disables other timeline providers

[https://github.com/microsoft/vscode/issues/345617](https://github.com/microsoft/vscode/issues/345617)

## Summary

The cosmetic filter-state defect remains in current source: excluding timelineDemo.failure also unchecks timelineDemo because the menu matches word boundaries rather than complete provider IDs. Actual timeline filtering uses exact membership and remains independent.

## Change summary

Disabling one timeline provider incorrectly unchecks another provider with a related ID in the filter menu.

## Best solution

Make each timeline filter checkmark reflect exact provider exclusion membership, while preserving the existing independent filtering of timeline items.
