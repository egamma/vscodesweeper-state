# Issue #118751 — Need to be able to specify view type for vscode.notebook.openNotebookDocument

[https://github.com/microsoft/vscode/issues/118751](https://github.com/microsoft/vscode/issues/118751)

## Summary

A real notebook API gap remains on current main: extensions cannot open an existing URI with a specified notebook view type. The issue is already correctly routed and under discussion, and no canonical replacement was found.

## Change summary

Allow `vscode.workspace.openNotebookDocument` to open an existing notebook URI using an explicitly selected view type.

## Best solution

Design an API overload or options object combining a URI with a notebook view type, backed by notebook model identity that safely supports explicit or concurrent view types without preventing users from choosing Open With.
