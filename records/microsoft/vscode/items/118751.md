# Issue #118751 — Need to be able to specify view type for vscode.notebook.openNotebookDocument

[https://github.com/microsoft/vscode/issues/118751](https://github.com/microsoft/vscode/issues/118751)

## Summary

Keep open under the existing notebook API discussion: opening an existing notebook URI without showing an editor still cannot specify its notebook type. The reporter accepted default-provider selection for the original Live Share scenario, but that does not cover explicit provider selection, and no qualifying canonical or completed fix was found.

## Change summary

Allow extensions to specify the notebook type when opening an existing notebook document programmatically without displaying an editor.

## Best solution

Resolve the notebook API contract for explicit provider selection while preserving users' ability to switch providers through Open With. Any eventual API should define what happens when the URI is already loaded with a different notebook type; simultaneous multi-provider documents are a separate, larger scope.
