# Issue #343753 — dont remove keep/undo, stop trying to switch to copilot from local session

[https://github.com/microsoft/vscode/issues/343753](https://github.com/microsoft/vscode/issues/343753)

## Summary

Keep open as feedback about preserving an explicit Local choice and granular edit review. Current source supports per-change Keep/Undo for Agent Host sessions, but also deliberately allows Copilot preference to override remembered Local selections; that partial coverage does not establish that the full request is resolved.

## Change summary

Preserve the user's selected Local chat harness across updates and retain in-editor, per-change Keep/Undo without requiring a separate diff tab.

## Best solution

Retain accessible, in-editor granular review across harnesses and establish a durable user-choice contract for Local versus automatic Copilot promotion. Distinguish the existing review controls from the separate session-selection concern before deciding whether any remaining work belongs in the granular-control discussion.
