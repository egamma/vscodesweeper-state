# Issue #289685 — Allow extensions to declare their runtime affinity towards other extensions

[https://github.com/microsoft/vscode/issues/289685](https://github.com/microsoft/vscode/issues/289685)

## Summary

Keep open as an API-proposal tracking issue. The runtime-affinity capability is implemented on main behind the `extensionAffinity` proposal, but proposal tracking must remain open until the API owners finalize or explicitly abandon it.

## Change summary

Allow an extension to request colocation with another extension in the same extension-host process without declaring a hard dependency.

## Best solution

Retain this issue as the design and finalization tracker for `extensionAffinity`; the API owners should close it only after deciding whether to graduate the manifest property from proposed status or abandon it.
