# Issue #325256 — Fitt's Law violated in v1.129

[https://github.com/microsoft/vscode/issues/325256](https://github.com/microsoft/vscode/issues/325256)

## Summary

Keep open: the report now has video evidence and current Modern UI styling still creates non-clickable edge gutters around tab and activity-bar targets, so the existing info-needed state looks outdated rather than a reason to close.

## Change summary

Modern UI floating tab and activity-bar styling prevents edge/corner clicks from selecting tabs or side-bar icons, reducing click-target usability.

## Best solution

Modernization owners should decide the intended hit-target behavior and, if preserving the floating visual treatment, extend the interactive area to the window edges without changing the visible pill/card styling.

## Evidence

- **confirmed report detail:** The issue body reports that in VS Code 1.129 Insiders on Ubuntu/X11, tabs in Modern UI do not respond when the pointer is slammed to the top edge; comment https://github.com/microsoft/vscode/issues/325256#issuecomment-3065920990 adds an inline recording, and https://github.com/microsoft/vscode/issues/325256#issuecomment-3155713597 shows the same problem for left-side icons.
- **current source - editor tabs:** src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css still gives Modern UI editor tabs a pill treatment and sets `.tabs-and-actions-container` padding to `4px 0 4px 4px`, leaving space around the `.tab` elements rather than making the top edge part of the tab hit target.
- **current source - floating edges:** src/vs/workbench/browser/media/floatingPanels.css still applies Modern UI floating margins, including `.part.activitybar { margin-left: var(--vscode-spacing-size40); margin-bottom: var(--vscode-spacing-size40); }`, which matches the reported left-edge click gap for activity-bar icons.
- **related item:** https://github.com/microsoft/vscode/issues/328365 is a later closed issue about the Modern UI left-edge click target; it is related evidence for the same interaction class, but it does not by itself close this tab-strip report.
