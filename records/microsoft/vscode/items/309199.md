# Issue #309199 — Add Option to Copilot Chat to "Keep and Commit"

[https://github.com/microsoft/vscode/issues/309199](https://github.com/microsoft/vscode/issues/309199)

## Summary

Keep open as a feature request: accepting chat edits does not create the requested Git commit. This team-authored item needs a product decision about acceptance-time commits; the newer granular-control discussion is related, not a valid duplicate target.

## Change summary

Provide an optional acceptance action that creates a Git commit after reviewing and optionally tweaking Copilot edits.

## Best solution

Design an explicit, opt-in commit-at-acceptance workflow within the current chat change-review experience, preserving ordinary acceptance without committing. Define its treatment of unrelated edits and staged changes before implementation.
