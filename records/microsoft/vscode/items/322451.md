## Change summary

Copilot's deleted-line preview should use the same effective tab display width as the current file when project indentation differs from the editor default.

## Best solution

Ensure Copilot's inline deleted-line rendering consistently matches the document's effective tab width, including changes to indentation options while a diff is visible. First reproduce the reported two-column project versus four-column default configuration and distinguish incorrect initial rendering from stale rendering.
