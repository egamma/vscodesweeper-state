# Issue #299840 — Plan mode → Cloud implementation handoff sends generated summary, not the actual plan

[https://github.com/microsoft/vscode/issues/299840](https://github.com/microsoft/vscode/issues/299840)

## Summary

A team member confirmed this is expected behavior: the cloud agent has a small input limit (~30K chars) unrelated to the model's context window, so the conversation is summarized before handoff. The request for higher-fidelity handoff is valid but the current behavior is intentional — closing as designed per the maintainer's signal.

## Change summary

Plan mode → Cloud implementation handoff summarizes the conversation instead of sending the actual plan, losing fidelity.

## Best solution

The current summarization is intentional due to the Copilot Coding Agent's `problem_statement` input limit (30K chars, enforced in `copilotCodingAgentUtils.ts`). Improvements to handoff fidelity would require either raising the API-side limit or implementing a smarter plan-aware summarization strategy — both are product decisions that belong with the cloud agent team, not a bug fix in the extension.
