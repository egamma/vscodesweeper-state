# Issue #299840 — Plan mode → Cloud implementation handoff sends generated summary, not the actual plan

[https://github.com/microsoft/vscode/issues/299840](https://github.com/microsoft/vscode/issues/299840)

## Summary

Keep open: current cloud delegation still summarizes the conversation rather than transferring the approved plan as authoritative input. The discussion acknowledges the fidelity loss, and no verified canonical or completed fix covers this request.

## Change summary

Preserve the approved implementation plan when handing a Plan-mode session to the cloud agent instead of substituting a lossy conversation summary.

## Best solution

Make the approved plan the authoritative input for cloud implementation, with an explicit user-facing contract when it exceeds the cloud input limit. Preserve ordinary conversation delegation and distinguish cloud handoff from background/CLI continuation.
