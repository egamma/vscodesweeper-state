[https://github.com/microsoft/vscode/issues/343214](https://github.com/microsoft/vscode/issues/343214)

## Summary

Notebook editing still fails without a chat response stream in the current source. An open maintainer PR explicitly fixes this issue, so keep it open pending that implementation.

## Change summary

Allow Copilot SDK and Agent Host sessions to edit notebooks without failing with “Invalid input, no stream.”
