# Issue #343214 — Copilot SDK/Agent Host notebook editing fails with Invalid input

[https://github.com/microsoft/vscode/issues/343214](https://github.com/microsoft/vscode/issues/343214)

## Summary

The failure remains traceable in current main: public tool invocation reaches the notebook editor without initializing the private prompt context that supplies its required response stream. A second user confirms the same error on Linux with VS Code 1.143.0, so upgrading alone does not resolve this report.

## Change summary

Notebook edits invoked through Copilot SDK/Agent Host fail with "Invalid input, no stream" while notebook reads succeed.

## Best solution

Make notebook editing work through the Agent Host tool-invocation path, with request-scoped edit delivery and an explicitly agreed review/undo experience. Preserve existing native Copilot notebook editing and avoid reusing another request's stream.
