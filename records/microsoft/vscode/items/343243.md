# Issue #343243 — MCP Apps: Agent Host drops _meta from the rebuilt tool-result, so restored app cards render empty

[https://github.com/microsoft/vscode/issues/343243](https://github.com/microsoft/vscode/issues/343243)

## Summary

Keep open: current main still reconstructs MCP App results without the server's result _meta, and both Copilot completion mappings omit it. The related structuredContent fix does not cover this distinct payload.

## Change summary

Preserve MCP tool-result _meta when Agent Host rebuilds app notifications from live or restored tool state.

## Best solution

MCP Apps should receive their original app-only result metadata after state reconstruction, without moving that data into model-visible content or confusing it with Agent Host presentation metadata. Establish the SDK and protocol transport contract, then cover completion, history replay, and app delivery end to end.
