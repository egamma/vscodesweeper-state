# Issue #271261 — Chat: Current file selection is debounced to the point of feeling sluggish

[https://github.com/microsoft/vscode/issues/271261](https://github.com/microsoft/vscode/issues/271261)

## Summary

The sluggishness remains directly visible in current source: editor selection changes are handled by a trailing 500 ms debounce before Chat refreshes implicit context. This is a bounded responsiveness bug in the existing Chat context flow and should stay open for a targeted fix.

## Change summary

Make Chat's current-file selection context update promptly when the editor selection changes.

## Best solution

Preserve coalescing for noisy editor events while ensuring that a meaningful selection change is reflected promptly in the Chat implicit-context attachment, with a timer-controlled regression test covering the latency.
