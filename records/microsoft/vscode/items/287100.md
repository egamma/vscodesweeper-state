# Issue #287100 — Remote CLI server env settings conflict with user and custom env

[https://github.com/microsoft/vscode/issues/287100](https://github.com/microsoft/vscode/issues/287100)

## Summary

The reporter's PATH is missing user-profile entries in the remote terminal because the VS Code server process starts before the login shell profile is read. A team member (chrmarti) is actively investigating and asked for more details; the conversation is mid-triage.

## Change summary

Remote SSH terminal PATH does not include entries from the user's login shell profile (~/.bash_profile), losing custom PATH directories like ~/bin.

## Best solution

The server's shell environment resolution (src/vs/platform/shell/node/shellEnv.ts) spawns a login shell (`-l`) to capture environment — investigation should confirm whether the `VSCODE_CLI` flag is set when the remote server starts (which would skip resolution). The team member is already on it; let the triage continue. This may ultimately belong in the remote-ssh extension tracker if the issue is in how the server is launched.
