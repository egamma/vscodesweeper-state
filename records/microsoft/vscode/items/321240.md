# Issue #321240 — Support `file://` URLs in the integrated browser in remote workspaces

[https://github.com/microsoft/vscode/issues/321240](https://github.com/microsoft/vscode/issues/321240)

## Summary

Valid feature request from a team member. The integrated browser currently warns that file:// URLs are served locally and not over the remote connection; no work has landed to change this. Stays open in the Backlog.

## Change summary

Allow the integrated browser to serve file:// URLs via the remote connection in remote workspaces, matching local-workspace behavior.

## Best solution

Extend the remote proxy infrastructure in `src/vs/workbench/contrib/browserView/electron-browser/features/browserRemoteFeatures.ts` to intercept file:// requests and serve them through the remote connection, so users can open HTML files on the remote host in the integrated browser just as they can locally.
