# Issue #265466 — Dragging to expand unchanged regions in diff editor should auto-scroll the viewport

[https://github.com/microsoft/vscode/issues/265466](https://github.com/microsoft/vscode/issues/265466)

## Summary

Keep open: unchanged-region expansion still lacks viewport-edge auto-scrolling in the current source. Existing reveal controls provide alternatives but do not cover the requested continuous drag interaction, and no verified canonical owns the same symptom.

## Change summary

Automatically scroll the diff editor when dragging an unchanged-region reveal handle beyond the viewport.

## Best solution

Extend the unchanged-region drag interaction in CollapsedCodeOverlayWidget so revealing context can continue across viewport boundaries, while preserving click-to-reveal behavior and scroll anchoring.
