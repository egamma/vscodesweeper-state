# Issue #259987 — Cannot read properties of undefined (reading 'toString')

[https://github.com/microsoft/vscode/issues/259987](https://github.com/microsoft/vscode/issues/259987)

## Summary

Fixed on main and shipped in 1.122.0. The crash occurred because `_tabAction` could be undefined, causing the switch in `_gutterIndicatorStyles` to fall through and return undefined, which then had `.toString()` called on it. The refactoring in 8c5cd5c1a8a moved `_tabAction` to a constructor parameter where the caller defaults to `InlineEditTabAction.Inactive` via nullish coalescing, eliminating the crash path.

## Change summary

TypeError crash in the inline completions gutter indicator when `tabAction` was undefined and `getEditorBlendedColor(...).read(reader).toString()` was called on the undefined result of a switch with no default case.

## Best solution

Keep the shipped fix — no further change is needed. The refactored code properly handles the undefined case at the call site with `s?.tabAction?.read(reader) ?? InlineEditTabAction.Inactive`.
