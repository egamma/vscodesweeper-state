# Issue #208378 — Align review comments UX and diff buttons UX

[https://github.com/microsoft/vscode/issues/208378](https://github.com/microsoft/vscode/issues/208378)

## Summary

Keep open: current source still gives comment and diff gutter controls different stroke widths and reveal behavior. The maintainer accepted animation alignment and explicitly decided against adding comment-button borders; the related border cleanup does not complete this work.

## Change summary

Align review-comment and diff gutter vertical strokes and hover feedback.

## Best solution

Make equivalent gutter affordances visually consistent while preserving their distinct actions, whole-line comment activation, and the accepted borderless default. First establish how comment decorations can support a complete reveal-and-dismiss transition without changing editor interaction semantics.
