# Issue #275254 — Handoffs are not screen reader discoverable

[https://github.com/microsoft/vscode/issues/275254](https://github.com/microsoft/vscode/issues/275254)

## Summary

The accessibility defect remains on current main: handoff actions become visible after a completed response without a screen-reader announcement, and Chat Accessibility Help does not explain how to reach them. This team-authored Backlog bug should remain open for the assigned chat UX work.

## Change summary

Announce newly available chat handoff actions to screen readers and document that they are reachable with Shift+Tab.

## Best solution

When a completed response first exposes handoff actions, provide a concise polite status announcement and document their Shift+Tab navigation in Chat Accessibility Help, without changing handoff execution or visual behavior.
