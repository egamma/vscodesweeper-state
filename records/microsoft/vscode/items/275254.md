# Issue #275254 — Handoffs are not screen reader discoverable

[https://github.com/microsoft/vscode/issues/275254](https://github.com/microsoft/vscode/issues/275254)

## Summary

Still reproduces on main: the chatSuggestNextWidget has aria-labels on individual handoff buttons but no aria-status announcement when handoffs appear, and the chat accessibility help dialog does not mention handoffs or how to reach them via shift+tab. Both gaps identified in the issue remain.

## Change summary

Screen readers receive no notification when chat handoff actions appear, and the accessibility help dialog does not document how to navigate to them.

## Best solution

Add an aria-status announcement in `chatSuggestNextWidget.ts` when handoff actions render (e.g. 'N next actions available'), and update the chat accessibility help content in `chatAccessibilityHelp.ts` to mention that handoffs can be reached via shift+tab.
