# Issue #149191 — Increase max height for the hover widget?

[https://github.com/microsoft/vscode/issues/149191](https://github.com/microsoft/vscode/issues/149191)

## Summary

Implemented and shipped in VS Code 1.80.0: editor content hovers can now be resized, allowing users to expand image previews beyond the default maximum height.

## Change summary

Allow editor hover widgets to grow beyond their default height so large extension-provided images are not cropped behind scrollbars.

## Best solution

Keep the shipped resizable-hover behavior from commit cf23221e0f6355fdd628b21c6ba0181ce707a64b; users can drag the hover sash to expose the complete preview without adding another size setting.
