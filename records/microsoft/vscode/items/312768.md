## Summary

Still unfixed on main: the SCM viewlet's getting-started welcome content (Clone Repository, Open Folder buttons) no longer renders when opening an empty VS Code window. The welcome content registrations in `extensions/git/package.json` and `src/vs/workbench/contrib/scm/browser/scm.contribution.ts` are intact, but something in the rendering or context-evaluation pipeline prevents them from appearing. No related fix commit found.

## Change summary

SCM viewlet no longer shows getting-started buttons (Clone Repository, Open Folder) when no repository is open.

## Best solution

Debug the `ViewWelcomeController` flow for the SCM view to determine why the welcome content items registered by the git extension (the `view.workbench.scm.empty` entry with `when: workbenchState == empty && ...`) are not rendering. The `shouldShowWelcome()` override in `SCMViewPane` returns `true` when `repositoryCount === 0`, so the issue likely lies in the `when`-clause context evaluation or a timing issue between the git extension's `git.state == initialized` context key and the welcome-content rendering.
