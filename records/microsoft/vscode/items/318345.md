## Change summary

Opening the editor context menu at reduced window zoom can place an action under the pointer and execute it when the opening right-click is released.

## Best solution

Establish whether the recurrence uses custom or Electron-rendered menus, then ensure opening the editor context menu does not accidentally execute an action at nonzero zoom. Preserve the Linux/X11, zoom -2, and extension-expanded menu conditions when isolating the responsible component.
