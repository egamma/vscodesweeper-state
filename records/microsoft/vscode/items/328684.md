# Issue #328684 — [Bug]"Add File to Chat" silently does nothing in the Agents Window

[https://github.com/microsoft/vscode/issues/328684](https://github.com/microsoft/vscode/issues/328684)

## Summary

Confirmed on current main from source and by two independent reports: shared attachment actions discard the active Agents Window chat widget after trying to reveal it through workbench-only hosts. The issue remains necessary and should stay open for a bounded fix covering all actions that use `withChatView`.

## Change summary

Chat attachment commands silently fail to add files, folders, selections, pinned editors, or search results to the active session in the Agents Window.

## Best solution

Make the shared attachment actions retain and target the visible active Agents Window chat widget while preserving the existing reveal behavior for regular chat views, editors, quick chat, terminal chat, and notebook chat. Cover every action routed through `withChatView` with a focused regression test.
