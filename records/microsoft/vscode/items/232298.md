## Summary

The core request — suppress the long-line tokenization warning hover — is a duplicate of the closed and verified issue #172713, which shipped in 1.111.0 via the `editor.hover.showLongLineWarning` setting. The UX issues noted during verification (button not dismissing the popup, tooltip overflow) are separate concerns that should be filed as new issues if they persist.
