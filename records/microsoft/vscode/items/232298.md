# Issue #232298 — Large tooltip when not tokenized on long lines makes code hard to read

[https://github.com/microsoft/vscode/issues/232298](https://github.com/microsoft/vscode/issues/232298)

## Summary

The initial fix (commit c3e06383df1, adding a 'Don't Show Again' action) landed but verification found remaining UX issues: clicking the dismiss link doesn't visually dismiss the hover, and the tooltip overflows the editor pane. These remain unfixed on main.

## Change summary

The long-line tokenization warning hover is too large, appears too quickly, and the new 'Don't Show Again' action doesn't properly dismiss the hover widget when clicked.

## Best solution

Fix the hover dismiss behavior in `src/vs/editor/contrib/hover/browser/hoverContribution.ts` — the `HIDE_LONG_LINE_WARNING_HOVER_ACTION_ID` command should also close the active hover widget after updating the setting. The tooltip overflow issue may need a max-width constraint or content shortening in `markdownHoverParticipant.ts`.
