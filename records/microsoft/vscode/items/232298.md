# Issue #232298 — Large tooltip when not tokenized on long lines makes code hard to read

[https://github.com/microsoft/vscode/issues/232298](https://github.com/microsoft/vscode/issues/232298)

## Summary

The original suppression request was implemented in 1.111.0, but verification found that the new action does not dismiss the hover and that the warning can extend far outside the editor pane. Because the issue was reopened after that verification, the pre-reopen fix cannot support closing it.

## Change summary

Make the long-line tokenization warning less obstructive and ensure its Don't Show Again action visibly takes effect and dismisses the hover.

## Best solution

Keep the suppression setting, but make the action immediately close the hover and constrain or shorten the warning so it remains readable within the editor pane.
