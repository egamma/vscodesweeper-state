# Issue #280918 — Detect and handle when a Copilot terminal has been interacted with by the user in such a way that breaks command execution

[https://github.com/microsoft/vscode/issues/280918](https://github.com/microsoft/vscode/issues/280918)

## Summary

The reported ncdu/interactive-terminal case is handled on current main by detecting alternate-buffer entry and returning a controlled tool result instead of continuing command execution.

## Change summary

Detect when user interaction leaves a Copilot terminal unable to accept the agent's next command and avoid crashing VS Code.

## Best solution

Keep the alternate-buffer handling shipped in commit cbf7676898ca6a8f7ef1f06d5b38f9cf0b2ecfc8; it covers ncdu and similar full-screen interactive programs without broadly rejecting terminals that have child processes.
