## Change summary

Detect when the user has left an agent-owned terminal in an interactive state (for example running ncdu) and handle it so the agent's next command does not break execution.

## Best solution

In the chat terminal tool, detect that the terminal is busy or in an alternate-screen or interactive program before sending the next command. Then either create a fresh terminal or report the state back to the agent, instead of writing into it.
