# Issue #282890 — ❌ Error: {"message":"The requested model is not supported.","code":"model_not_supported","param":"model","type":"invalid_request_error"}

[https://github.com/microsoft/vscode/issues/282890](https://github.com/microsoft/vscode/issues/282890)

## Summary

Keep open as the Auto-specific canonical report: multiple users confirmed that Auto can select a model the account cannot use, and a maintainer identified the missing authorization handling when selection changes during a turn. Later comments include distinct plan-availability and GHE CLI failures, which should be separated during diagnosis rather than used to close the original bug.

## Change summary

Auto model selection can send a request to an unavailable or unauthorized model, producing a 400 model_not_supported error instead of completing the request or handling authorization first.

## Best solution

Ensure every model selected by Auto is usable for the active account and request before dispatch; if authorization is required, handle it before the first request rather than failing and only prompting on retry. Keep GHE Copilot CLI routing and model-plan availability failures in their narrower issue lanes.
