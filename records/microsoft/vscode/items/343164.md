# Issue #343164 — Extension details editor keeps targeting the previous local or remote installation

[https://github.com/microsoft/vscode/issues/343164](https://github.com/microsoft/vscode/issues/343164)

## Summary

The current source still discards the newly requested installation when an extension details tab already exists. Keep this open: the related reports concern distinct selection and state problems, and a later maintainer statement supports respecting the installation the user selected.

## Change summary

An already-open extension details tab should switch to the explicitly selected local or remote installation instead of retaining its previous target.

## Best solution

Keep one details tab per extension while ensuring that explicitly opening another installation updates the tab's installation and management actions. Address this independently of uninstall-state calculation and uninstall-label clarity.
