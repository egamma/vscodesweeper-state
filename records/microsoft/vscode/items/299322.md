# Issue #299322 — Copilot 0.38.0 Extension - "Chat failed to load..." error after 1.110 Update

[https://github.com/microsoft/vscode/issues/299322](https://github.com/microsoft/vscode/issues/299322)

## Summary

Keep this open as the canonical WSL compatibility bug and route it to Chat. Multiple users reproduced the failure across consecutive VS Code and Copilot Chat versions, while reinstalling the WSL-side extension only provides a workaround.

## Change summary

After upgrading VS Code and Copilot Chat, the WSL-installed extension can remain marked incompatible and prevent Chat from loading until it is reinstalled.

## Best solution

A VS Code upgrade should reconcile and activate the compatible Copilot Chat installation in the WSL extension host without requiring uninstall/reinstall; the compatibility message should remain only for genuinely incompatible versions.
