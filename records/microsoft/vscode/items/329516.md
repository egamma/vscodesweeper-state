# Issue #329516 — Agent plugins: auto-update permanently fails with "Cannot fast-forward to multiple branches" due to concurrent git fetch/pull in the same plugin clone

[https://github.com/microsoft/vscode/issues/329516](https://github.com/microsoft/vscode/issues/329516)

## Summary

Keep open: current source still permits overlapping marketplace fetch/pull operations and immediately rejects the reported multiple-branches error without recovery. Some independent plugin updates now have in-process serialization, but that does not cover marketplace operations or establish coordination across processes.

## Change summary

Prevent concurrent Git operations from repeatedly breaking agent-plugin updates and make update failures diagnosable from their notification.

## Best solution

Make updates of a shared plugin checkout reliable across windows and application processes, while preserving pinned refs and existing safeguards against destructive recovery. Failed updates should expose useful error details and open the log that actually records the failure.
