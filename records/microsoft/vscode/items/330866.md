The missing legacy slash commands reflect an intentional Inline Chat redesign, not an incomplete completion registration. A maintainer explicitly confirmed their removal, and current source preserves that distinction between editor Inline Chat and panel Chat.

  > Thanks for the report. The legacy built-in slash commands were intentionally removed from editor Inline Chat during its redesign; the maintainer explains that decision in https://github.com/microsoft/vscode/issues/283199#issuecomment-4097015099. Inline Chat accepts natural-language requests, while panel Chat has a separate command list. Getting a useful response after typing `/doc` does not mean it remains a registered Inline Chat command, so the missing suggestions are expected.
