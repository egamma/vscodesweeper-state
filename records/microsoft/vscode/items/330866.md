# Issue #330866 — Built-in Copilot Inline Chat slash commands are missing from autocomplete

[https://github.com/microsoft/vscode/issues/330866](https://github.com/microsoft/vscode/issues/330866)

## Summary

Confirmed in the current checkout: the bundled Copilot Chat 'editingSessionEditor' participant (the editor Inline Chat agent) is registered in extensions/copilot/package.json with an empty `commands: []` array, while extensions/copilot/src/extension/common/constants.ts hardcodes a real command→intent mapping for `Intent.Editor` (doc, fix, explain, review, tests, edit, generate) with a maintainer TODO noting the manifest and code are out of sync ('THIS IS WEIRD. We should read this from package.json'). That explains exactly why manual `/doc` still executes but nothing is proposed in autocomplete.

## Change summary

Built-in Inline Chat (editor participant) slash commands like /doc, /explain, /fix, /tests, /help are not surfaced in the Inline Chat autocomplete list, even though they execute correctly when typed manually.

## Best solution

Populate the `commands` array for the `github.copilot.editingSessionEditor` chat participant in extensions/copilot/package.json to match the runtime mapping already hardcoded in extensions/copilot/src/extension/common/constants.ts (`agentsToCommands[Intent.Editor]`), adding the missing localized descriptions in package.nls.json; this is core Copilot Chat code (ships in this repo), not an extension issue.
