# Issue #316984 — Sessions sections are missing expansion state indication

[https://github.com/microsoft/vscode/issues/316984](https://github.com/microsoft/vscode/issues/316984)

## Summary

Still reproduces on main: the sessions list in the Agents window explicitly suppresses twistie icons via `force-no-twistie` CSS class, so users cannot see whether sections are expanded or collapsed. Team-authored issue, keeping open.

## Change summary

Sessions sections in the Agents window lack visual expansion/collapse indicators (twistie icons are hidden).

## Best solution

Remove or conditionally apply the `force-no-twistie` class for collapsible section headers in `sessionsList.ts` (lines ~1751 and ~3338), so that sections show the standard twistie chevron indicating expanded/collapsed state. The changes view (`changesView.ts` line ~1364) conditionally applies it only in list mode, which may be a better pattern to follow.
