# Issue #249257 — Inline completion that just inserts tab is indistinguishable from a tab that is in the text buffer

[https://github.com/microsoft/vscode/issues/249257](https://github.com/microsoft/vscode/issues/249257)

## Summary

Current main gives single-tab inline completions a dotted underline, addressing the reported indistinguishability from indentation already in the buffer. A concrete rendering commit supports closing this as completed.

## Change summary

Make a suggested tab visually distinguishable from a tab already present in the text buffer.

## Best solution

Keep the short-suggestion highlighting introduced by d346fdcdfeecf76e56433dedfaf8df32126ad9ad. Suppression of suggestions after deletion is separate provider behavior tracked by https://github.com/microsoft/vscode/issues/229312.
