[https://github.com/microsoft/vscode/issues/302030](https://github.com/microsoft/vscode/issues/302030)

## Summary

Keep open: plugin installation commands exist, but the inspected built-in skills do not teach the agent to discover and help install agent plugins. The maintainer-requested capability remains distinct from UI installation support, and no qualifying older canonical or referencing fix was identified.

## Change summary

Make agents aware of agent plugins and able to help users install them through supported VS Code capabilities.

## Best solution

Provide discoverable agent guidance for finding and installing agent plugins, building on the existing installation flow and preserving its user confirmations.
