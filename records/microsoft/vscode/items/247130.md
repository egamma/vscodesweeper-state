# Issue #247130 — The bold text inside a walkthrough description is not being read out or shown in the accessible view exactly as is

[https://github.com/microsoft/vscode/issues/247130](https://github.com/microsoft/vscode/issues/247130)

## Summary

Confirmed on current main: the walkthrough accessible view renders raw markdown bold markers (`**`) as literal text because `_getContent` joins string nodes from `parseLinkedText` without stripping inline markdown formatting.

## Change summary

Screen readers read `**` markers literally in the walkthrough accessible view instead of presenting text as bold or stripping the markers.

## Best solution

In `gettingStartedAccessibleView.ts`, strip inline markdown formatting (at minimum `**` and `__` for bold, `*` and `_` for italic) from the string nodes before presenting them in the accessible view. A simple regex replace on the joined description string would suffice.
