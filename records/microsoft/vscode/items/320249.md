# Issue #320249 — Files changed via the copilot cli in terminal in another session pop up when a different session is selected

[https://github.com/microsoft/vscode/issues/320249](https://github.com/microsoft/vscode/issues/320249)

## Summary

Verified duplicate of the older open issue https://github.com/microsoft/vscode/issues/296087, which reports the same observable behavior: a background Copilot CLI session opens and focuses its diff while the user is working in another session.

## Change summary

Prevent a background Copilot CLI session from surfacing its changed-file diff over the currently selected Agents Window session.

## Best solution

Consolidate the behavior decision in https://github.com/microsoft/vscode/issues/296087, including whether externally initiated editor opens can be attributed to a session without blocking legitimate desktop file opens.
