# Issue #320249 — Files changed via the copilot cli in terminal in another session pop up when a different session is selected

[https://github.com/microsoft/vscode/issues/320249](https://github.com/microsoft/vscode/issues/320249)

## Summary

Team-authored issue describing a real cross-session isolation bug in the Agents window — file diffs from a background session's terminal activity surface in the focused session. Keeping open for maintainer judgment; the discussion is active with architectural questions about scoping editor opens to sessions.

## Change summary

Files changed by a Copilot CLI agent running in a background terminal session incorrectly pop up as diffs in a different, currently-focused session.

## Best solution

The Agents window needs a mechanism to associate terminal-driven file-change events with the session that owns the terminal, so that editor opens (diffs) are routed to the correct session rather than whichever session is focused. The comment from benibenj raises the broader design question of how to handle externally-opened files in the Agents window — this likely needs an under-discussion resolution before implementation.
