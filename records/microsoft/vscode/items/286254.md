# Issue #286254 — Chat suggest isn't positioned correctly when editing an old prompt in a chat editor

[https://github.com/microsoft/vscode/issues/286254](https://github.com/microsoft/vscode/issues/286254)

## Summary

This is a confirmed chat UI bug with no evidence of a fix or canonical duplicate. Route it to the chat area and investigate how the inline request editor's fixed overflow widgets are positioned while its virtualized tree row moves.

## Change summary

The suggestion widget appears at the bottom-right of the window instead of beside the cursor when editing an older prompt in a chat editor.

## Best solution

Keep completion and hover widgets anchored to the cursor while an old request is edited inside the chat transcript, including after the virtualized list reveals or repositions that request.
