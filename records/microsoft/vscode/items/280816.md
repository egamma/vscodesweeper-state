# Issue #280816 — Agents are limited over SSH

[https://github.com/microsoft/vscode/issues/280816](https://github.com/microsoft/vscode/issues/280816)

## Summary

The reporter confirmed that removing Copilot's forced UI-host placement restored all file tools. The underlying limitation—Copilot Agent file operations failing over SSH when forced to run locally—is already covered by an older, verified open issue.

## Change summary

Copilot Agent rejects remote Linux workspace paths when remote.extensionKind forces it onto the Windows UI host.

## Best solution

Consolidate the UI-host remote-file limitation under https://github.com/microsoft/vscode/issues/269919, preserving this report's Windows-to-Linux path diagnostics and confirmed configuration workaround.
