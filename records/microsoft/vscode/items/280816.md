# Issue #280816 — Agents are limited over SSH

[https://github.com/microsoft/vscode/issues/280816](https://github.com/microsoft/vscode/issues/280816)

## Summary

Reporter identified the root cause as their own misconfiguration — a workspace-level `remote.extensionKind` override forcing Copilot extensions to run on the UI side, causing path conversion issues. Not a VS Code bug; resolved by removing the user's own setting.

## Change summary

Copilot agent file tools (list_dir, read_file) returned 'outside of the workspace' errors when connected over SSH to a Linux remote.

## Best solution
