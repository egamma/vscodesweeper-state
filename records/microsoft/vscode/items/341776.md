# Issue #341776 — Search results keep refreshing entire list *while I'm trying to read it*

[https://github.com/microsoft/vscode/issues/341776](https://github.com/microsoft/vscode/issues/341776)

## Summary

Keep open as a request to preserve the reader's position while search results arrive. Current source still refreshes and sorts the result tree during an active search; existing search settings do not directly address that reading-position requirement.

## Change summary

Keep already-visible search results stable enough to read and scroll while a long-running search continues adding matches.

## Best solution

Preserve the visible result and its relative viewport position during incremental Search view updates without sacrificing progressive results or the configured final sort order. First verify the reported jumping with a long-running search and distinguish viewport movement from incoming results being inserted before the visible rows.
