## Summary

Thanks for the report. It was filed as a feature request, but it describes a usability defect: the Search view keeps refreshing while results stream in and moves the scroll position back to the top. The report is complete enough to retest, but I did not trace or run it against current main, so it stays open.

## Change summary

While a large search is running, streaming result updates reset the user's scroll position in the results list.

## Best solution

Preserve scroll position and focus while search results stream in, in the Search view tree refresh path. The result order could also be made more stable, with updates batched or incremental instead of a full re-render.
