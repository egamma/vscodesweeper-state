- **Behavior:**

  > The reporter observes disappearance of terminal output without a trailing newline after locking and unlocking Ubuntu. Reproduce with a deterministic command that keeps the process running so a subsequent shell prompt does not obscure the condition. - **Trace:**

  > TerminalNativeContribution subscribes to onDidResumeOS and invokes XtermTerminal.forceRedraw(), which clears the texture atlas. This establishes a relevant lifecycle boundary, not the cause of the Ubuntu defect; diagnosis must first distinguish rendering failure from buffer mutation. The open macOS report https://github.com/microsoft/vscode/issues/311614 contains related repaint symptoms but does not establish the same newline-sensitive failure or Linux fix. Keep shell output, newline handling, and unrelated terminal lifecycle behavior unchanged.
