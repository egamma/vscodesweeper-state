# Issue #146896 — Setting checkboxes for object boolean values has no focus or active style

[https://github.com/microsoft/vscode/issues/146896](https://github.com/microsoft/vscode/issues/146896)

## Summary

Keep open: current source still replaces boolean-object checkboxes during mousedown, matching the maintainer's confirmed explanation for missing pressed feedback. The existing settings-editor and accessibility labels already route this correctly.

## Change summary

Boolean-object settings checkboxes need visible focus and pointer-interaction feedback that survives changing their values.

## Best solution

Make boolean-object checkboxes in the Settings editor retain usable focus and visible interaction feedback throughout activation, while preserving their existing configuration semantics. Keep the change bounded to this widget and its renderer rather than altering all list-setting controls.
