# Issue #146896 — Setting checkboxes for object boolean values has no focus or active style

[https://github.com/microsoft/vscode/issues/146896](https://github.com/microsoft/vscode/issues/146896)

## Summary

Still present on main: the Toggle base CSS (`src/vs/base/browser/ui/toggle/toggle.css`) has no `:focus` or `:active` pseudo-class styles, and the settings editor checkbox CSS adds none either. The re-render on click also drops active state. A team member confirmed this in May 2025.

## Change summary

Object boolean setting checkboxes in the settings editor lack visible focus ring and active/mousedown styling.

## Best solution

Add `:focus-visible` (outline or border via `--vscode-focusBorder`) and `:active` (background shift) styles to `.monaco-custom-toggle` in `src/vs/base/browser/ui/toggle/toggle.css`, and fix the settings widget re-render in `settingsWidgets.ts` so active state isn't immediately lost on click.
