# Issue #264452 — please announce  suggestion number along with the text in editor.

[https://github.com/microsoft/vscode/issues/264452](https://github.com/microsoft/vscode/issues/264452)

## Summary

Still reproduces on main: the screen reader announcement for inline completions does not include the suggestion index or total count. The model exposes `selectedInlineCompletionIndex` and `inlineCompletionsCount` but `_provideScreenReaderUpdate` in the controller only announces the ghost text content, not the position within the list.

## Change summary

Screen reader users cannot tell which suggestion they are viewing or how many suggestions are available when cycling through inline completions.

## Best solution

Augment `_provideScreenReaderUpdate` in `inlineCompletionsController.ts` to include the 1-based index and total count (e.g., 'suggestion 2 of 5') when `inlineCompletionsCount` is available. Also consider including count info in the accessible view provider (`inlineCompletionsAccessibleView.ts`) for the Alt+F2 flow. Note that `inlineCompletionsCount` currently only returns a value for explicit triggers — this limitation should be evaluated.
