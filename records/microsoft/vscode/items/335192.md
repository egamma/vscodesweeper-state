# Issue #335192 — Integrated Browser: Very difficult to use Add Element to Chat in Mobile view

[https://github.com/microsoft/vscode/issues/335192](https://github.com/microsoft/vscode/issues/335192)

## Summary

Real, well-diagnosed UX gap in the Integrated Browser's element picker: mobile/device-emulation view doesn't reliably highlight or capture element clicks for 'Add Element to Chat', and the reporter's follow-up traces this to two separate, unintegrated mechanisms (dev-tools device toolbar vs. the emulation feature's own mobile mode). Worth routing to the browser-view owners rather than closing.

## Change summary

In the Integrated Browser's mobile/device-emulation view, 'Add Element to Chat' element highlighting doesn't work reliably, and links get clicked instead of being selected for the chat.

## Best solution

Have the integrated-browser feature owners evaluate unifying the two device/mobile presentation paths — src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorEmulationFeatures.ts (device emulation / mobile presets) and browserEditorChatFeatures.ts (element-selection/highlight overlay) — so element picking works consistently under emulation, per the reporter's own diagnosis in the comments.
