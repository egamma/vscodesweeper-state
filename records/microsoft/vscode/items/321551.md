# Issue #321551 — Bug: Prompt cache expires during active agent sessions, causing 10x cost spikes on gaps > 5 min

[https://github.com/microsoft/vscode/issues/321551](https://github.com/microsoft/vscode/issues/321551)

## Summary

The primary ask — keepalive pings during long tool calls to preserve the prompt cache — is already implemented (behind experiment rollout) and landed before this issue was filed. The cache TTL behavior itself is expected (confirmed by a team member). The secondary UI indicator requests are separate feature requests not covered by the existing implementation.

## Change summary

Request for cache keepalive pings during active agent sessions to prevent prompt cache expiration and resulting cost spikes when inter-call gaps exceed ~5 minutes.

## Best solution

The core mechanism is already shipped: `LongToolCallCachePreservation` sends periodic probes during long tool calls (commit 2787a511668, 2026-05-30), and `AnthropicExtendedCacheTtl` extends cache TTL to 1 hour for Anthropic models. Both are experiment-gated and rolling out. The remaining gap is the proposed cache-status UI indicator (traffic light / token counter), which could be filed as a separate, narrower feature request.
