# Issue #321551 — Bug: Prompt cache expires during active agent sessions, causing 10x cost spikes on gaps > 5 min

[https://github.com/microsoft/vscode/issues/321551](https://github.com/microsoft/vscode/issues/321551)

## Summary

Keep open as a cache-preservation feature request: existing keepalive and extended-TTL settings cover only part of the requested workflow, and recent measurements document remaining costs during interactive pauses. Linked implementation work is still open, so neither a completed close nor a competing agent implementation is appropriate.

## Change summary

Preserve prompt-cache reuse across long tool waits and user-response pauses, with clearer control over cache lifetime and its cost implications.

## Best solution

Review the existing cache-related PRs, then decide a model-aware preservation policy for long tool waits and interactive pauses. Make the cost/lifetime tradeoff understandable without promising that a client can guarantee provider-side cache retention.
