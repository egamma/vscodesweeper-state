# Issue #321551 — Bug: Prompt cache expires during active agent sessions, causing 10x cost spikes on gaps > 5 min

[https://github.com/microsoft/vscode/issues/321551](https://github.com/microsoft/vscode/issues/321551)

## Summary

The original request is partially implemented, but a real gap remains for waits such as `vscode_askQuestions`; the Backlog Candidates milestone and an open linked fix attempt also require keeping this open. The remaining work should be discussed as a cache-preservation feature rather than treated as a VS Code correctness bug, since a maintainer confirmed that some expiration is expected and model-dependent.

## Change summary

Preserve or clearly communicate prompt-cache state across long pauses during active agent sessions to avoid unexpectedly expensive cache misses.

## Best solution

Retain the existing bounded keep-alive behavior for eligible long-running tool calls, then decide whether cache preservation should also cover user-blocking tools such as `vscode_askQuestions` and whether the UI should expose cache-expiry or cost state. Review https://github.com/microsoft/vscode/pull/330232 separately because its custom-endpoint prefix-stability work does not cover the remaining hosted Anthropic wait scenario.
