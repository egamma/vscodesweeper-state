# Issue #299904 — Random codespans get linkified

[https://github.com/microsoft/vscode/issues/299904](https://github.com/microsoft/vscode/issues/299904)

## Summary

Still reproduces on main: the InlineCodeSymbolLinkifier aggressively resolves partial words within multi-word inline code spans (e.g. `cancels mid-stream` links to a symbol named 'stream'). An open PR (#322473) attempts a fix but hasn't merged.

## Change summary

Inline code spans in chat responses get incorrectly linkified to unrelated symbols when a substring happens to match a workspace symbol.

## Best solution

The InlineCodeSymbolLinkifier needs smarter matching — it should not linkify multi-word code spans to a symbol matching only one word within them. The open PR https://github.com/microsoft/vscode/pull/322473 is an implementation candidate; review and land it (or a refined version) to fix overly aggressive linkification.
