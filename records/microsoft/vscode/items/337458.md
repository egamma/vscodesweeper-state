# Issue #337458 — openDebug setting Does not work when debug view in secondary side bar

[https://github.com/microsoft/vscode/issues/337458](https://github.com/microsoft/vscode/issues/337458)

## Summary

Confirmed from source: when a debug session starts, debugService.ts hardcodes `ViewContainerLocation.Sidebar` when revealing the Run and Debug view, so if the user has moved that view to the secondary side bar (auxiliary bar), it never opens/reveals it there.

## Change summary

`debug.openDebug` (e.g. `openOnSessionStart`) fails to reveal the collapsed secondary side bar when the Run and Debug view has been moved there instead of the primary side bar.

## Best solution

In debugService.ts, resolve the actual container location for VIEWLET_ID via `viewDescriptorService.getViewContainerLocation()` (as already used elsewhere in this file, e.g. for REPL_VIEW_ID) instead of hardcoding `ViewContainerLocation.Sidebar`, then pass that resolved location to `paneCompositeService.openPaneComposite`.
