# Issue #337458 — openDebug setting Does not work when debug view in secondary side bar

[https://github.com/microsoft/vscode/issues/337458](https://github.com/microsoft/vscode/issues/337458)

## Summary

The reported failure remains source-reproducible: starting a debug session explicitly opens the primary sidebar rather than the debug container's current location. Keep this open; the existing debug label routes it correctly.

## Change summary

debug.openDebug should reveal the Run and Debug container when it has been moved to a collapsed secondary sidebar.

## Best solution

Make automatic debug-container opening honor its current workbench location while preserving the existing setting, session-suppression, and focus semantics. Cover session-start opening and the equivalent hard-coded location in breakpoint-triggered opening.
