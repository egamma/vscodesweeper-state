# Issue #337458 — openDebug setting Does not work when debug view in secondary side bar

[https://github.com/microsoft/vscode/issues/337458](https://github.com/microsoft/vscode/issues/337458)

## Summary

Real, source-confirmed bug: the debug view is auto-revealed via a hardcoded `ViewContainerLocation.Sidebar` instead of the view container's actual current location, so `debug.openDebug` silently no-ops once the Debug view is dragged to the secondary side bar (Auxiliary Bar).

## Change summary

`debug.openDebug: openOnSessionStart` fails to reveal the Debug view when its view container has been moved to the secondary side bar.

## Best solution

In `doCreateSession` (and the analogous calls in `debugCommands.ts` and `debugSession.ts`), resolve the debug view container's actual `ViewContainerLocation` via `IViewDescriptorService.getViewContainerLocation(viewContainer)` before calling `openPaneComposite`, instead of assuming `Sidebar`.
