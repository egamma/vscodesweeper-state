# Issue #206329 — Warning tooltips hidden behind bottom panel

[https://github.com/microsoft/vscode/issues/206329](https://github.com/microsoft/vscode/issues/206329)

## Summary

Still reproduces on main: settings validation messages use position:absolute with z-index:1, which is insufficient to overlay the bottom panel when the setting is near the viewport bottom.

## Change summary

Settings editor validation/warning tooltips are hidden behind the bottom panel when the setting is near the bottom of the visible area.

## Best solution

Either increase the z-index of `.setting-item-validation-message` to be above the panel's z-index, or switch validation messages to use the IHoverService (which renders in a top-level overlay). The fix lives in `src/vs/workbench/contrib/preferences/browser/media/settingsEditor2.css` (line ~531) and potentially the rendering logic in `settingsTree.ts`.
