## Change summary

GitHub Copilot Chat reports 'Language model unavailable' in WSL2 because Node.js network-family autoselection (Happy Eyeballs) causes ETIMEDOUT when connecting to Copilot API endpoints.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/253137, the team-maintained meta issue for 'Language model unavailable' errors. The fix likely involves either disabling autoSelectFamily for outbound Copilot requests in WSL/remote contexts, or ensuring the Copilot networking layer handles IPv6 fallback more gracefully.
