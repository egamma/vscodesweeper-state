# Issue #124954 — Allow going inside graphemes (with an explicit gesture)

[https://github.com/microsoft/vscode/issues/124954](https://github.com/microsoft/vscode/issues/124954)

## Summary

Still a valid, unimplemented feature request. The editor enforces Unicode grapheme cluster boundaries for cursor movement with no opt-out or explicit gesture to navigate inside a grapheme. The issue reached 20+ upvotes and was promoted to Backlog — it should stay open.

## Change summary

Allow an explicit gesture (command or setting) to move the cursor inside grapheme clusters, enabling editing of individual code points within combined characters.

## Best solution

Add an opt-in editor command (e.g. 'Cursor Move Inside Grapheme') or a setting that relaxes grapheme-cluster-boundary enforcement for cursor movement. The implementation would live in `src/vs/editor/common/core/cursorColumns.ts` and the cursor movement logic, providing a code-point-level navigation mode alongside the default grapheme-level one.
