# Issue #343176 — Multi-diff file tree skips files while scrolling when a later active diff remains visible

[https://github.com/microsoft/vscode/issues/343176](https://github.com/microsoft/vscode/issues/343176)

## Summary

Keep open: current source confirms that a previously active diff overrides scroll-follow selection whenever it remains visible, allowing an intervening file to be skipped. This team-authored bug remains necessary; no qualifying fix or verified duplicate was established.

## Change summary

Make the Changed Files tree follow scrolling without skipping a preceding diff because a later, previously active diff remains visible.

## Best solution

The multi-diff file list should distinguish explicit navigation from subsequent scrolling so stale active state does not suppress scroll-follow selection. Preserve clicked or revealed-file selection near the document end, where that file cannot reach the top of the viewport.
