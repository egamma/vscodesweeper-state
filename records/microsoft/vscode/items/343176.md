# Issue #343176 — Multi-diff file tree skips files while scrolling when a later active diff remains visible

[https://github.com/microsoft/vscode/issues/343176](https://github.com/microsoft/vscode/issues/343176)

## Summary

Keep open: current source still lets a previously active, partially visible diff override the topmost visible file, producing the reported selection skip. The later tree-order fix does not address this behavior.

## Change summary

Make Changed Files selection follow scrolling without skipping a preceding diff when a later active diff remains visible.

## Best solution

Make scroll-follow selection distinguish subsequent scrolling from explicit file navigation in the multi-diff file-list integration. Preserve clicked/revealed-file selection at the document end and cover the tall-viewport, stale-active-item scenario in the existing widget tests.
