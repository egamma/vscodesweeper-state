# Issue #53992 — Outline view + Markdown: Do not display the "#"s

[https://github.com/microsoft/vscode/issues/53992](https://github.com/microsoft/vscode/issues/53992)

## Summary

Long-standing, heavily upvoted (109 👍) request that is still unimplemented on main — the symbol label is still built with the leading '#'s upstream in vscode-markdown-languageservice — and there is now an open community PR (https://github.com/microsoft/vscode/pull/298857, "Resolves #53992") plus its upstream companions; keep it open so that PR can be reviewed and landed or declined.

## Change summary

Markdown outline entries are prefixed with the raw '#' heading markers, which duplicate the information the tree indentation already conveys.

## Best solution

Review and land (or explicitly decline) https://github.com/microsoft/vscode/pull/298857 together with its upstream dependency https://github.com/microsoft/vscode-markdown-languageservice/pull/228 — drop the '#' prefix from the TOC symbol name upstream and convey heading level via symbol icons in the outline tree, rather than adding yet another setting.
