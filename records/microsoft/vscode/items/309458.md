# Issue #309458 — Worktrees not showing in Source Control

[https://github.com/microsoft/vscode/issues/309458](https://github.com/microsoft/vscode/issues/309458)

## Summary

The original disappearance is explained by the intentional git.detectWorktrees default change, and enabling it resolved the reporter's case. Keep this open for the subsequently confirmed mismatch between documented UI-created worktree visibility and current behavior, and route it to Git.

## Change summary

Worktrees disappear from Source Control unless detection is enabled, including worktrees created through VS Code's own UI.

## Best solution

Reconcile UI-created worktree visibility with the documented promise that these worktrees appear without automatic detection enabled. Preserve the deliberate opt-in for discovering existing worktrees unless the Git owner explicitly revisits that default; track prefix-based hiding separately.
