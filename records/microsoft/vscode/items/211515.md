# Issue #211515 — Ctrl+Backspace takes effect in editor when Command Palette is focused

[https://github.com/microsoft/vscode/issues/211515](https://github.com/microsoft/vscode/issues/211515)

## Summary

Still appears reproducible on main: the `deleteWordLeft` keybinding is gated on `EditorContextKeys.textInputFocus` but when the Command Palette input has focus, keybinding dispatch may still route Ctrl+Backspace to the editor command instead of the quick input's native input handling. No fix commit found.

## Change summary

Ctrl+Backspace deletes a word in the underlying editor instead of in the Command Palette input when the palette is focused.

## Best solution

The keybinding for `deleteWordLeft` (and similar word-deletion commands) should not fire when focus is inside the quick input widget. Either the quick input's input box should suppress editor keybinding dispatch for these keys, or the keybinding expression should add a `!inQuickOpen` (or equivalent) guard. The fix likely touches `src/vs/editor/contrib/wordOperations/browser/wordOperations.ts` (keybinding registration) or the quick input controller's focus/keybinding management.
