# Issue #344201 — Agent Host: one failed Copilot proxy model fetch empties the Claude model catalog (known-good catalog not kept)

[https://github.com/microsoft/vscode/issues/344201](https://github.com/microsoft/vscode/issues/344201)

## Summary

The catalog-loss defect remains directly traceable on current main, and an existing test explicitly expects the reported empty catalog. Keep open to preserve successful per-source catalogs across transient failures without retaining models after account changes.

## Change summary

A failed Copilot model refresh removes previously available Claude models when native enumeration succeeds with an empty catalog.

## Best solution

Preserve each source's last successful catalog when that source temporarily fails, while honoring successful empty responses and explicit credential invalidation. Retaining the catalog prevents the reported empty-picker dead end; the additional wake-recovery observation should also be checked.
