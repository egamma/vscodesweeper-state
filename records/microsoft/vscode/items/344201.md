# Issue #344201 — Agent Host: one failed Copilot proxy model fetch empties the Claude model catalog (known-good catalog not kept)

[https://github.com/microsoft/vscode/issues/344201](https://github.com/microsoft/vscode/issues/344201)

## Summary

The reported catalog loss is confirmed in current main: a rejected proxy fetch is replaced with an empty list when native enumeration successfully reports no account. Keep this open; an existing unit test explicitly demonstrates the failure, and the earlier periodic-refresh issue does not resolve this partial-failure case.

## Change summary

Preserve each model source's last known-good catalog across transient refresh failures without retaining models after intentional source invalidation.

## Best solution

Claude model refresh should retain the failed source's previously valid models while accepting successful updates from the other source, including authoritative empty results. Preserve existing account-change invalidation and stale-result protections.
