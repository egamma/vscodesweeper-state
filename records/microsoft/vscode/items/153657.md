# Issue #153657 — Treat numpad-enter and enter keys as different

[https://github.com/microsoft/vscode/issues/153657](https://github.com/microsoft/vscode/issues/153657)

## Summary

A real capability gap remains on current main: VS Code deliberately normalizes Numpad Enter to Enter, preventing separate bindings. The request is already correctly routed and should remain open for product and implementation discussion.

## Change summary

Allow Numpad Enter and the main Enter key to invoke different keybindings.

## Best solution

Support NumpadEnter as a distinct scan-code binding while preserving existing Enter defaults and avoiding duplicate generated keybindings, likely in the keyboard mapper and key-code registry.
