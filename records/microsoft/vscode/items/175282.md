# Issue #175282 — [Accessibility] Do not use title attribute when labeling buttons

[https://github.com/microsoft/vscode/issues/175282](https://github.com/microsoft/vscode/issues/175282)

## Summary

The specific defect reported — the 'Toggle Search Details' button missing an aria-label — was fixed in commit 542b272f06c and shipped in 1.100.0. The ActionBar base class also already sets aria-label on action items. The concrete problem is resolved.

## Change summary

JAWS screen reader could not announce the 'Toggle Search Details' button because it relied on the title attribute alone, which JAWS does not read.

## Best solution

Keep the shipped fix (commit 542b272f06c, 1.100.0). Both the search view and search editor toggle buttons now carry explicit aria-label attributes. No further change needed.
