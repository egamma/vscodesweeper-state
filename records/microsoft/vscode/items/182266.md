# Issue #182266 — The Toggle Command of Webview can only open, but not close panel

[https://github.com/microsoft/vscode/issues/182266](https://github.com/microsoft/vscode/issues/182266)

## Summary

Still reproducible on main: the toggle logic for panel view containers checks `layoutService.hasFocus(Parts.PANEL_PART)` via `isAncestorUsingFlowTo`, which fails when focus is inside a webview iframe because the active element isn't a DOM descendant of the panel container. The linked PR #182279 is open but unreviewed. The issue is on the 'On Deck' milestone and remains valid.

## Change summary

Toggle commands for webview-based panel views can only open the panel, not close it, because the focus check does not detect focus inside webview iframes.

## Best solution

Fix the `hasFocus(Parts.PANEL_PART)` check in `src/vs/workbench/browser/layout.ts` to account for webview iframes that don't participate in the normal DOM ancestor chain. Review or close the stale PR https://github.com/microsoft/vscode/pull/182279 and land a proper fix. The toggle logic in `src/vs/workbench/services/views/browser/viewsService.ts` (lines 444–450) relies on this check to decide whether to close vs. open the panel.
