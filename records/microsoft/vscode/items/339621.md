# Issue #339621 — Dev extension host broken in serve-web

[https://github.com/microsoft/vscode/issues/339621](https://github.com/microsoft/vscode/issues/339621)

## Summary

Keep open: current main still passes extension-development arguments through a payload that production builds deliberately ignore, breaking the serve-web development-host workflow. Restoring that workflow needs human review of the security boundary, not removal of the production guard.

## Change summary

F5 in a published code serve-web instance opens a development window without loading the extension under development.

## Best solution

Provide a security-reviewed way for an explicitly initiated extension-debug session to supply development-host configuration in published serve-web builds, while continuing to reject untrusted URL payloads.
