# Issue #344823 — Skip unnecessary Component Fixtures jobs for documentation-only PRs

[https://github.com/microsoft/vscode/issues/344823](https://github.com/microsoft/vscode/issues/344823)

## Summary

The CI optimization remains unimplemented: Component Fixtures still runs both expensive jobs unconditionally on documentation-only PRs. Keep this follow-up open; the earlier implementation proposal was closed without merging.

## Change summary

Skip Component Fixtures Playwright and screenshot work for documentation-only PRs while preserving required-check completion and merge safety.

## Best solution

Conservatively identify PR changes that cannot affect component fixtures, while retaining branch-push baseline generation and an always-reporting Screenshots & Tests gate. Intentional skips should pass that gate, but relevant changes, uncertain detection, failures, cancellations, and unexpected skips must not bypass coverage.
