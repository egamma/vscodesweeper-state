## Change summary

Right-clicking an inactive VS Code window after switching applications unexpectedly activates the most recently opened VS Code window.

## Best solution

Context-menu interaction should remain associated with the clicked window rather than activate an unrelated window. Establish whether this occurs between independent workspace windows or auxiliary windows, and with native or custom menus, before diagnosing the context-menu and native activation paths.
