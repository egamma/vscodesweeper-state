# Issue #334651 — Questions Carousel: Only "dark 2026" theme seems to have a different color on hover

[https://github.com/microsoft/vscode/issues/334651](https://github.com/microsoft/vscode/issues/334651)

## Summary

Confirmed in source: the base `textLink.foreground`/`textLink.activeForeground` color pair is identical across nearly every built-in theme (the shared defaults in baseColors.ts, plus dark_modern/light_modern/2026-light explicitly set them equal), so links show no hover color change except in the 2026 Dark theme, which alone sets a distinct `activeForeground`. This is a real, longstanding design choice rather than a broken behavior, but the reporter's ask (should more themes have a subtle hover shift, especially for high-contrast readability) is a legitimate polish/design question for the theming team to weigh in on.

## Change summary

Reporter observes that in the Questions Carousel/chat link hover, only the 'Dark 2026' theme visibly changes link color on hover; other built-in themes (and even 2026 Light) don't.

## Best solution

A theming/design decision on whether `textLink.activeForeground` should diverge from `textLink.foreground` more broadly (or specifically within the new 2026 theme family, since 2026-light currently sets them equal too) — likely belongs with the design-tokens/theme owners rather than the carousel feature itself; see src/vs/platform/theme/common/colors/baseColors.ts and extensions/theme-defaults/themes/*.json.
