# Issue #334651 — Questions Carousel: Only "dark 2026" theme seems to have a different color on hover

[https://github.com/microsoft/vscode/issues/334651](https://github.com/microsoft/vscode/issues/334651)

## Summary

Confirmed in source: only the `2026-dark` theme gives `textLink.activeForeground` a value distinct from `textLink.foreground` — every other built-in theme (2026-light, dark_modern, light_modern, and the base default colors) sets both to the same value, so hover produces no visible change there. This is a design-consistency gap for the theme maintainers to decide on, not a functional bug.

## Change summary

Links in the chat questions carousel (and chat output generally) only show a subtle hover-color change in the 2026-dark theme; other built-in themes' link color stays identical on hover.

## Best solution

Have the 2026-themes owners decide consistent hover treatment for `textLink.activeForeground` across 2026-light/dark, dark_modern, and light_modern (and consider an underline affordance for HC themes), then update the theme JSON files under extensions/theme-defaults/themes/ accordingly.
