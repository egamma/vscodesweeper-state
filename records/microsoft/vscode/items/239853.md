## Summary

Still reproduces as of 1.125.0 per the reporter's June 2026 confirmation. The pipe-starting ligature rendering bug likely lives in the `@xterm/addon-ligatures` package (upstream xterm.js), not in VS Code's own terminal code. The related merged PR #318992 fixes a different issue (#318993 — config change detection) and does not address this rendering defect.

## Change summary

Terminal ligatures starting with a pipe character (e.g. `|==`, `|->`) fail to render correctly unless the text is selected.

## Best solution

Investigate and fix in the upstream `@xterm/addon-ligatures` addon (the ligature glyph substitution path for sequences beginning with `|`). The VS Code terminal code delegates ligature resolution entirely to `@xterm/addon-ligatures`; the fix likely belongs in that package's OpenType GSUB lookup handling, then flows to VS Code via a dependency bump.
