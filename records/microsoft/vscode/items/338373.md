# Issue #338373 — "workspace folder" is confusing in "MCP: Open Workspace Folder MCP Configuration" command name

[https://github.com/microsoft/vscode/issues/338373](https://github.com/microsoft/vscode/issues/338373)

## Summary

The two confusing command names remain on current main, and a maintainer has proposed distinguishing the folder configuration from the .code-workspace configuration. Keep this team-authored naming issue open; the related remote-configuration issue does not report the same observable problem.

## Change summary

Make the MCP configuration command names clearly distinguish folder-level files from the .code-workspace file.

## Best solution

Use a clearly distinguishable pair of command labels in mcpCommands.ts while preserving command IDs, visibility conditions, folder selection, and configuration destinations. The maintainer's proposed Workspace versus code-workspace wording is a concrete starting point for agreeing the final labels.
