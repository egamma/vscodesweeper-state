# Issue #338373 — "workspace folder" is confusing in "MCP: Open Workspace Folder MCP Configuration" command name

[https://github.com/microsoft/vscode/issues/338373](https://github.com/microsoft/vscode/issues/338373)

## Summary

Real naming confusion, confirmed in source: two similarly-named MCP commands open different files, and a maintainer already replied same-day with a concrete rename proposal — this stays open for that direction to be finalized, not closed.

## Change summary

The command title "MCP: Open Workspace Folder MCP Configuration" is easily confused with "MCP: Open Workspace MCP Configuration", which opens a different file (.mcp.json in a folder vs. the .code-workspace file).

## Best solution

Rename the two commands per the maintainer's proposal in the thread: "MCP: Open Workspace MCP Configuration" for the per-folder .mcp.json, and "MCP: Open code-workspace MCP Configuration" for the .code-workspace file, updating the `localize2` title strings in mcpCommands.ts.
