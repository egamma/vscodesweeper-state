# Issue #242040 — Hover commands are off

[https://github.com/microsoft/vscode/issues/242040](https://github.com/microsoft/vscode/issues/242040)

## Summary

The defect remains source-reproducible on current main: right-edge hovers still apply a legacy margin that can push command actions outside the visible hover. The existing `workbench-hover` routing is appropriate, and no canonical issue or fixing PR was found.

## Change summary

Command actions in a hover near the right window edge can render partially offscreen.

## Best solution

Keep hover commands within the visible hover boundary when right-edge overflow triggers right alignment, while preserving normal action spacing and hover positioning elsewhere.
