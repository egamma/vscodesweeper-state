# Issue #325176 — cannot report a bug for an extension

[https://github.com/microsoft/vscode/issues/325176](https://github.com/microsoft/vscode/issues/325176)

## Summary

The reporter could not see extensions in the issue reporter because extension loading failed in that window (the system info shows "Extensions not loaded | extensions-load-error"). They resolved it themselves by opening a new window and successfully filed the Remote SSH bug. This is a transient state, not a reproducible defect in the issue reporter.

## Change summary

The issue reporter did not list installed extensions, preventing the user from filing a bug against an extension.

## Best solution

No code change needed — the issue reporter already handles extension-load failures by surfacing the error in the report body (`extensions-load-error` sentinel in `src/vs/workbench/contrib/issue/electron-browser/issueService.ts`). The reporter's window had a broken SSH connection that caused extension loading to fail; opening a new window resolved it. The underlying Remote SSH error (`UnsupportedPlatform("LinuxARM32")`) was filed separately at https://github.com/microsoft/vscode-remote-release/issues/11742.
