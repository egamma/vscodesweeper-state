# Issue #313790 — Pipe terminal-profile `args` (and decide on `env`) to the agent host

[https://github.com/microsoft/vscode/issues/313790](https://github.com/microsoft/vscode/issues/313790)

## Summary

Keep open: current main still forwards only the profile executable, not its arguments or environment. This is accepted, team-authored follow-up work; environment precedence and handling of arguments incompatible with shell integration need a maintainer decision.

## Change summary

Honor terminal-profile arguments in host-managed shells and define whether profile environment variables participate in their environment.

## Best solution

Provide backward-compatible argument forwarding for host-managed terminals, with shell-family-specific behavior that preserves the intended startup semantics and command detection. Explicitly settle and document profile environment handling; keep remote shell configuration and the SDK-owned non-PTY shell tool as separate work.

Selecting an existing profile therefore does not satisfy the central ask.
