# Issue #313790 — Pipe terminal-profile `args` (and decide on `env`) to the agent host

[https://github.com/microsoft/vscode/issues/313790](https://github.com/microsoft/vscode/issues/313790)

## Summary

Team-authored follow-up tracking concrete remaining work (args/env piping) after the merged PR #313679. None of the checklist items are implemented on current main — `AgentHostConfigKey.DefaultShellArgs` does not exist, and the terminal contribution still only pushes `DefaultShell`. Keeping open.

## Change summary

Terminal profile `args` (and potentially `env`) from the user's configured shell profile are silently dropped when forwarded to the agent host, so login shells and custom rc-file flags don't apply.

## Best solution

Implement the remaining checklist: add `DefaultShellArgs` to the config schema, update the workbench bridge to push args alongside the shell path, and splice them correctly relative to shell-integration injection in `AgentHostTerminalManager.createTerminal`. The env policy decision (ignore, whitelist, or merge) should be settled by the terminal and agent-host area owners.
