# Issue #342150 — HydraFusion: first approval prompt in a new agent host session is never shown, so the first turn hangs

[https://github.com/microsoft/vscode/issues/342150](https://github.com/microsoft/vscode/issues/342150)

## Summary

Keep open: the follow-up establishes that missing approvals correlate with phase child chats, not first-turn timing alone. Current main removes that routing for primary/draft phases, but neither the remaining child-chat approval path nor the reported post-cancellation behavior has been verified end to end.

## Change summary

HydraFusion manual approvals disappear while a phase child chat is active, leaving the turn waiting until cancellation.

## Best solution

Ensure every HydraFusion phase exposes actionable manual approvals and returns the user's decision to the runtime, including before any assistant output. Verify the inline-phase change against the reported scenario and investigate post-cancellation phase ownership separately without weakening stale-event protection.
