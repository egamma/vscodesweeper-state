# Issue #251975 — Accept all ... button text is wrong in merge editor.

[https://github.com/microsoft/vscode/issues/251975](https://github.com/microsoft/vscode/issues/251975)

## Summary

The toolbar labels still contradict the input titles when Git reverses the inputs for a rebase. Keep this open while the linked, still-open fix PR is reviewed; a global label swap would make ordinary merges incorrect instead.

## Change summary

Make the merge editor’s Accept All labels accurately describe the input whose changes the action accepts.

## Best solution

Review https://github.com/microsoft/vscode/pull/278396 against ordinary merges, rebases, and custom input titles, coordinating with the older matching report at https://github.com/microsoft/vscode/issues/247687. The finished behavior should identify the accepted side accurately without assuming Current and Incoming always occupy fixed positions.
