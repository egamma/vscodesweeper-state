# Issue #315768 — Agents: Unable to run Jupyter notebooks

[https://github.com/microsoft/vscode/issues/315768](https://github.com/microsoft/vscode/issues/315768)

## Summary

The team-authored test report demonstrates a real notebook-execution failure in the Agents Window. Execution depends on an extension-provided kernel, and Jupyter does not currently declare Agents Window support, so this should remain open and move to the VS Code-owned Jupyter tracker.

## Change summary

Running all cells in a Jupyter notebook from the Agents Window produces no execution or visible response.

## Best solution

Move the issue to https://github.com/microsoft/vscode-jupyter and make Jupyter notebook controllers and kernels work reliably when the extension runs in the Agents Window, including a visible error when no runnable kernel is available.

- **extension support:** The current microsoft/vscode-jupyter package.json has executable entry points and activates for jupyter-notebook documents, but version 2026.6.1 does not enable the agentsWindowActivation proposal or declare capabilities.agentsWindow support: https://github.com/microsoft/vscode-jupyter/blob/main/package.json.
- **core policy:** src/vs/workbench/services/extensions/common/extensionManifestPropertiesService.ts disables executable extensions in the Agents Window unless explicitly overridden or opted in through the Agents Window capability.
