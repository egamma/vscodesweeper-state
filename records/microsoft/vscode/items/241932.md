# Issue #241932 — macOS Configuration Profiles: Only watch for configuration if profile detected on startup

[https://github.com/microsoft/vscode/issues/241932](https://github.com/microsoft/vscode/issues/241932)

## Summary

The optimization has not been implemented — on macOS, NativePolicyService and its file watcher are unconditionally created for all users regardless of whether any managed profile/policy exists. The request to gate the watcher on detected policy at startup remains valid.

## Change summary

Skip creating the macOS policy file watcher when no managed configuration profile is detected at startup, saving resources for the majority of users.

## Best solution

In `src/vs/code/electron-main/main.ts` (line 225–226), gate the NativePolicyService instantiation on a lightweight probe (e.g. check whether the expected plist exists) before committing to the file watcher. Alternatively, push the check into @vscode/policy-watcher itself so it no-ops when no profile is present.
