# Issue #307184 — Tree item actions are transparent in 2026 theme

[https://github.com/microsoft/vscode/issues/307184](https://github.com/microsoft/vscode/issues/307184)

## Summary

Keep open: current source still gives viewport-aligned tree actions translucent backgrounds, allowing script text to show through in the 2026 themes. The related discussion independently confirms the symptom, and the maintainer explicitly identifies this issue as the remaining bug.

## Change summary

Prevent script labels from showing through tree item actions when horizontal scrolling is enabled in a narrow NPM Scripts view using a 2026 theme.

## Best solution

Make viewport-aligned action backgrounds visually match the row over its containing surface without exposing underlying label text. Preserve right-edge alignment, horizontal scrolling, and existing hover, selection, and keyboard-focus behavior.
