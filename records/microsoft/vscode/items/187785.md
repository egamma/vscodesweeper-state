## Summary

Still valid: double-click in the keybindings editor always opens the keybinding edit dialog regardless of column. The when-expression column-aware edit UX has not been implemented on main.

## Change summary

Double-clicking the 'when' column cell in Keyboard Shortcuts editor should open the when-expression editor instead of the keybinding editor.

## Best solution

Modify the `onDidOpen` handler in `keybindingsEditor.ts` (line ~548) to detect which column was clicked and dispatch to `defineKeybinding` or the when-expression input widget accordingly. The when-expression editing infrastructure already exists (WhenInputWidget at line 1211).
