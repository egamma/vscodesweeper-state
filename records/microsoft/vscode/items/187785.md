# Issue #187785 — Keyboard Shortcuts: Allow us to edit "when expression" when double clicked on the cell in "when" column

[https://github.com/microsoft/vscode/issues/187785](https://github.com/microsoft/vscode/issues/187785)

## Summary

The requested interaction is still missing: opening a shortcut row edits its keybinding regardless of the clicked column. Keep this accepted Backlog request open; existing when-expression editing does not address its discoverability goal.

## Change summary

Allow double-clicking the When column to edit the expression, with column-local edit affordances to make both editing actions discoverable.

## Best solution

Make double-clicking a When cell enter expression editing while retaining keybinding editing elsewhere in the row. Consider the suggested column-local pencil affordances alongside the keyboard shortcuts editor's existing action layout.
