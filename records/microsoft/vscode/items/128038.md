# Issue #128038 — Add support for implicit tag names

[https://github.com/microsoft/vscode/issues/128038](https://github.com/microsoft/vscode/issues/128038)

## Summary

Keep open: surrounding-element-aware implicit tag names remain a meaningful gap in the Emmet integration. The related report was explicitly consolidated into this issue, and no verified older open canonical or implementing fix was found.

## Change summary

Infer omitted Emmet tag names from the surrounding HTML element, such as span inside inline elements and li inside lists.

## Best solution

Support Emmet's documented parent-context inference consistently in abbreviation expansion and completion suggestions, preserving explicit tag names and context-free expansion. This issue should remain the focused tracker for that capability.

- **Current expansion path:** In extensions/emmet/src/abbreviationActions.ts, expandEmmetAbbreviation finds currentNode for location validation but passes only syntax, abbreviation, rangeToReplace, and filter into the expansion list. expandAbbr obtains options from syntax and configuration, then calls helper.expandAbbreviation without supplying the surrounding element. Identical abbreviations at multiple cursors also share one expansion regardless of their parent elements.
