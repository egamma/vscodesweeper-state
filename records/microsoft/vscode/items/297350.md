# Issue #297350 — Metered connection UI interactions for VS Code Update

[https://github.com/microsoft/vscode/issues/297350](https://github.com/microsoft/vscode/issues/297350)

## Summary

Team-authored bug report about the metered-connection update tooltip incorrectly showing 'Up to Date' when an update is actually available (auto-check was skipped). No commit references this issue directly, so it stays open despite possibly-related refactoring in the update service.

## Change summary

On a metered connection, the update status bar tooltip incorrectly shows 'Up to Date' even when the user is behind on Insiders, because the auto-check was suppressed.

## Best solution

The `renderUpToDate()` path in `src/vs/workbench/contrib/update/browser/updateTooltip.ts` should distinguish between 'confirmed up to date' and 'haven't checked yet due to metered connection' — the metered message should not imply the user is current when no check has run. The recent streamline commit (0e294574fb9) may partially address this but doesn't reference this issue.
