# Issue #268369 — Resolving to the current workspace root in the workspace config file.

[https://github.com/microsoft/vscode/issues/268369](https://github.com/microsoft/vscode/issues/268369)

## Summary

The existing `${fileWorkspaceFolder}` variable covers the active-file form of this request, but not Explorer-selected-root resolution. Keep this accepted Backlog item open for the debug owner to establish whether that remaining behavior is needed; no qualifying fix commit or canonical duplicate was established.

## Change summary

Allow one workspace-level debug configuration to resolve paths against the current project without hardcoding a workspace-folder name.

## Best solution

Use `${fileWorkspaceFolder}/src` and `${fileWorkspaceFolder}/tests` for the active-editor workflow rather than introducing another equivalent variable. Establish whether resolving from the selected Explorer root without an active editor is an additional requirement before expanding core variable semantics.
