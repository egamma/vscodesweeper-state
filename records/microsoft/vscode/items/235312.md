# Issue #235312 — VS Code re-installing extensions immediately after uninstalling

[https://github.com/microsoft/vscode/issues/235312](https://github.com/microsoft/vscode/issues/235312)

## Summary

The reporter's trace logs confirm that Settings Sync reinstalled the extension seconds after a successful local uninstall. The issue is accepted as a settings-sync bug, and no fixing commit or open canonical issue was found, so it should remain open while current-main behavior is verified.

## Change summary

Uninstalling a profile-synced extension on a second machine causes Settings Sync to reinstall it instead of propagating the removal.

## Best solution

Ensure a completed initial profile sync persists the extensions resource's last-sync state so a subsequent local uninstall is merged as a removal rather than treated as a remotely added extension. Cover the two-machine profile-sync sequence with a regression test.
