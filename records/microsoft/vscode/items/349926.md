# Issue #349926 — Manage remote environments: allow deleting a remote ssh connection

[https://github.com/microsoft/vscode/issues/349926](https://github.com/microsoft/vscode/issues/349926)

## Summary

Keep open: SSH hosts still present in SSH configuration cannot be removed through Remote Environments. The maintainer explicitly identified a remaining product decision between editing that configuration and providing reversible UI hiding; existing controls do not fully cover the request.

## Change summary

Allow users to remove SSH connections listed in Manage Remote Environments, including hosts discovered from SSH configuration.

## Best solution

Provide a clear way to remove unwanted configured SSH hosts from the management list, with explicit persistence and restoration semantics. Decide whether this edits SSH configuration or hides entries locally before implementing the behavior.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/sessions/providers/remoteAgentHost/browser/remotesModel.ts`, `src/vs/workbench/contrib/sessions/providers/remoteAgentHost/browser/remotesTable.ts`, `src/vs/workbench/contrib/sessions/providers/remoteAgentHost/browser/remotesWidget.ts`, `src/vs/workbench/contrib/sessions/providers/remoteAgentHost/test/browser/remotesModel.test.ts`
- **Validation:** Extend the remotesModel.test.ts suite for the chosen configured-host removal contract, including confirmation cancellation, refresh/reopen persistence, and restoration or re-addition. Manually verify that removing a configured SSH row has the agreed effect while leaving the remote computer and files untouched.
- **Behavior:**

  > Users cannot remove SSH hosts discovered from SSH configuration through Manage Remote Environments. Forget SSH Connection currently handles only orphaned saved connections, while Hide from Environment Picker leaves the management row visible. The completed feature must make configured-host removal understandable and specify whether it changes SSH configuration or only local visibility. Acceptance includes cancellation preserving the entry, the agreed result surviving refresh and reopening, and a documented way to restore or re-add the host.
- **Trace:**

  > RemotesModel builds SSH rows with canDelete restricted to registered hosts absent from successfully discovered SSH configuration. Its checkSSHHostDeletion independently rejects configured hosts; current remotesModel.test.ts cases explicitly encode this restriction. RemotesTable exposes Open SSH Configuration and picker-only hiding, whose tooltip states that the row stays in Remote Environments. The maintainer identifies configuration deletion and local hiding as alternatives at https://github.com/microsoft/vscode/issues/349926#issuecomment-7125594883. The trace establishes the capability gap, but not which persistence contract should replace it. Preserve unrelated connection, session, tunnel, and remote-file behavior.
- **Open decisions:**
  - Should removing a configured SSH host edit its SSH configuration or hide it locally while leaving that configuration unchanged?
  - If removal is local hiding, how does the user discover and restore a hidden host?
