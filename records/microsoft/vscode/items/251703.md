# Issue #251703 — Issue Reporter - Add more information to the submission form (i.e. submitting Username and target repository)

[https://github.com/microsoft/vscode/issues/251703](https://github.com/microsoft/vscode/issues/251703)

## Summary

Keep open: the current reporter wizard displays the destination repository, but that only partially covers the request; identifying the account that will actually publish the issue remains unresolved. The existing issue-reporter routing is appropriate.

## Change summary

Show the destination repository and submitting GitHub identity in the issue reporter, with account switching suggested as optional.

## Best solution

Retain the wizard's repository disclosure and clarify the actual publishing identity before submission. Account disclosure must reflect the browser session used to publish, rather than imply that VS Code's authentication account necessarily determines authorship; optional account switching needs a product decision.
