## Summary

This is a specific instance of the known Node.js system certificate loading issue tracked by #287739. The reporter confirmed that disabling `http.systemCertificatesNode` resolved the problem. The setting now defaults to `false`, and the tracking issue (#287739) owns the remaining work to evaluate and fix certificate loading before re-enabling it.
