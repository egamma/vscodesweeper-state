[https://github.com/microsoft/vscode/issues/43154](https://github.com/microsoft/vscode/issues/43154)

## Summary

The requested single-row or titlebar-less layout remains unavailable on main, and an open PR explicitly targets this issue. With 217 upvotes and a Backlog milestone, this should remain open while that implementation is reviewed or superseded.

## Change summary

Allow Linux users to eliminate the separate title-bar row by integrating its controls into the editor-tabs row.
