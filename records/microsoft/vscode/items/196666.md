# Issue #196666 — Cannot read properties of undefined (reading 'tooltip')

[https://github.com/microsoft/vscode/issues/196666](https://github.com/microsoft/vscode/issues/196666)

## Summary

Team-authored error-telemetry issue. The unguarded access to `part.item.hint.tooltip` in `inlayHintsHover.ts` is still present on current main — no fix commit references this issue, and no null guard has been added. Keeping open.

## Change summary

TypeError thrown when hovering over an inlay hint whose `hint` property is undefined, because `part.item.hint.tooltip` is accessed without a null guard.

## Best solution

Add a null guard for `part.item.hint` in `src/vs/editor/contrib/inlayHints/browser/inlayHintsHover.ts` around line 94, before accessing `.tooltip` and `.textEdits`. The `resolve()` call at line 86 is async and the hint item could be invalidated; an early return when `hint` is falsy would prevent the crash.
