# Issue #134336 — Restore all windows when closing them all at once

[https://github.com/microsoft/vscode/issues/134336](https://github.com/microsoft/vscode/issues/134336)

## Summary

Valid feature request still unresolved on main. The gap is confirmed by a maintainer: on Linux/Windows the OS taskbar 'Quit N Windows' action closes windows one by one without triggering the quit flow, so VS Code discards window state. A fix likely requires Electron-level support or a heuristic to detect rapid sequential closes.

## Change summary

When using the OS taskbar 'Quit N Windows' action on Linux/Windows, VS Code should restore all windows on next launch (respecting `window.restoreWindows`), not just the last active one.

## Best solution

Implement a heuristic in `lifecycleMainService.ts` to detect rapid sequential window closes (all windows closing within a short time window without an explicit quit) and treat them as a quit for state-preservation purposes, or upstream an Electron event for the OS-initiated close-all action. The `window-all-closed` event firing before `will-quit` (noted in comment 6) could serve as the signal.
