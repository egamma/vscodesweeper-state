# Issue #349102 — BUG: ZoneWidget.getHorizontalSashTop() compares style.height to null, returns NaN before height is set

[https://github.com/microsoft/vscode/issues/349102](https://github.com/microsoft/vscode/issues/349102)

## Summary

Confirmed in current source: creating a ZoneWidget constructs and lays out its sash before an inline height exists, producing NaN. Keep open for a bounded initialization fix; no persistent user-visible symptom has been established.

## Change summary

ZoneWidget.getHorizontalSashTop() returns NaN instead of a finite offset when its inline height is unset.

## Best solution

Ensure the zone widget supplies a finite initial sash position while preserving its existing positioning after a height is assigned, with browser regression coverage.
