# Issue #86948 — "editor.suggestSelection": "first" does not work as described

[https://github.com/microsoft/vscode/issues/86948](https://github.com/microsoft/vscode/issues/86948)

## Summary

Keep open: the setting still promises to always select the first suggestion, but its implementation deliberately honors provider preselection. The maintainer acknowledged the snippet-selection concern without settling the desired behavior, and no verified canonical owns this exact report.

## Change summary

Make the documented first-suggestion selection behavior consistent with how top-ranked snippets are selected and accepted.

## Best solution

Resolve whether editor.suggestSelection="first" guarantees the first visible item or permits provider preselection, then align the setting description and selection behavior with that decision. Preserve snippet ordering and the other selection strategies unless the agreed contract requires otherwise.
