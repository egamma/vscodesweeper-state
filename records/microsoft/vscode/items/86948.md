# Issue #86948 — "editor.suggestSelection": "first" does not work as described

[https://github.com/microsoft/vscode/issues/86948](https://github.com/microsoft/vscode/issues/86948)

## Summary

A real semantic gap remains on main: `editor.suggestSelection: "first"` can select a provider-preselected item below the visually first snippet. The issue is already correctly routed and needs a maintainer decision about precedence.

## Change summary

Make `editor.suggestSelection: "first"` select the first displayed suggestion when snippets are sorted to the top.

## Best solution

Define and test the precedence between displayed order, completion-provider `preselect`, and suggestion memory. Either make `first` strictly select index 0 as documented or clarify the documented exception while providing a setting that guarantees displayed-first selection.
