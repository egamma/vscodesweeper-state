# Issue #336892 — editor.formatOnPaste is not respected when a DocumentPasteEditProvider provides edits to the paste

[https://github.com/microsoft/vscode/issues/336892](https://github.com/microsoft/vscode/issues/336892)

## Summary

Keep open as a core editor bug: provider-handled paste bypasses the event that triggers format-on-paste. The current source confirms the reported distinction between ordinary paste and paste-provider edits.

## Change summary

Honor editor.formatOnPaste after a DocumentPasteEditProvider inserts text, allowing range formatting to clean up the resulting document context.

## Best solution

Provider-handled text paste should participate in the existing format-on-paste behavior when enabled and a range formatter is available, without changing ordinary paste, drop behavior, or paste-alternative undo semantics.
