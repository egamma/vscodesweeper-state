# Issue #297469 — What is a "session" for "allow in session"

[https://github.com/microsoft/vscode/issues/297469](https://github.com/microsoft/vscode/issues/297469)

## Summary

The ambiguity remains on current main: confirmation actions and their tooltips say only “this Session,” without clarifying that the scope is the current chat session. This should stay open as bounded confirmation-UI polish.

## Change summary

Clarify that “Allow in this Session” grants approval for the current chat session, rather than the current turn or VS Code process.

## Best solution

Use consistent wording across pre-execution, post-execution, combination, and MCP-server confirmation actions that explicitly identifies the scope as the current chat session.
