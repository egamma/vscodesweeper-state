# Issue #170442 — Trusted domain dialog in web doesn't return focus to previously clicked element when canceled.

[https://github.com/microsoft/vscode/issues/170442](https://github.com/microsoft/vscode/issues/170442)

## Summary

Still open on main — the dialog code restores focus to the iframe outer element, but the webview-internal focus restoration (the last focused element inside the iframe) has no general solution yet. Team discussion reduced severity to sev3 but no fix landed.

## Change summary

When a custom dialog (e.g. trusted domain prompt) is canceled in vscode.dev, focus returns to the webview iframe but not to the previously focused element inside it.

## Best solution

Implement a general webview focus-restoration mechanism: when the outer iframe regains focus after a dialog dismiss, the webview framework should signal the inner content to restore its last-focused element. This likely lives in `src/vs/workbench/contrib/webview/browser/` and the webview preload scripts.
