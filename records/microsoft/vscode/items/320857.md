# Issue #320857 — Adopt native sanitizer API instead of dompurify

[https://github.com/microsoft/vscode/issues/320857](https://github.com/microsoft/vscode/issues/320857)

## Summary

Keep this migration investigation open: current main still uses DOMPurify, and no verified canonical owns its replacement. Browser compatibility and preservation of the existing sanitization contract remain prerequisites, not established outcomes.

## Change summary

Explore replacing DOMPurify with the native Sanitizer API once supported browsers permit it.

## Best solution

Evaluate native sanitization against supported browsers and VS Code's existing protocol filtering, attribute predicates, plaintext replacement, and Trusted Types requirements. Retire DOMPurify only where native behavior preserves those contracts and demonstrates the expected maintenance or performance benefit.
