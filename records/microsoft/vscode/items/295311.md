# Issue #295311 — Copilot Chat: Diff summary number overflows

[https://github.com/microsoft/vscode/issues/295311](https://github.com/microsoft/vscode/issues/295311)

## Summary

The defect remains source-reproducible on current main: the aggregate is calculated correctly, but narrowing the chat view can clip trailing digits from the deletion count and make the total appear incorrect.

## Change summary

Keep multi-digit added and removed line totals fully visible when the Copilot Chat changed-files summary is narrow.

## Best solution

Preserve the complete aggregate counts at narrow widths while allowing the file-count label to shrink or ellipsize first; wide layouts, per-file counts, and the surrounding action toolbar should remain unchanged.
