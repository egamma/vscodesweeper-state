# Issue #333507 — Notifications icon top-right misses do-not-disturb decoration

[https://github.com/microsoft/vscode/issues/333507](https://github.com/microsoft/vscode/issues/333507)

## Summary

Current main conclusively reproduces this member-authored consistency bug: Do Not Disturb changes the status-bar bell to a slashed icon, but the top-right title-bar contribution always uses the plain bell. The issue should remain open for a bounded fix.

## Change summary

Show the Do Not Disturb decoration on the notifications icon when notifications are positioned in the top-right title bar.

## Best solution

Make the top-right title-bar notifications icon reflect the global notification filter just like the status-bar icon, including updating immediately when Do Not Disturb is toggled.
