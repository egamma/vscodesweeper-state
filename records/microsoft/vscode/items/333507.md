# Issue #333507 — Notifications icon top-right misses do-not-disturb decoration

[https://github.com/microsoft/vscode/issues/333507](https://github.com/microsoft/vscode/issues/333507)

## Summary

Traced and confirmed on main: the title-bar bell icon shown when notifications are positioned top-right is registered with a single static `icon: Codicon.bell` and never reflects unread or do-not-disturb state, unlike the status-bar entry which dynamically switches between bell/bell-dot/bell-slash/bell-slash-dot.

## Change summary

When notifications are set to top-right position, the title bar bell icon never shows the do-not-disturb (or unread) decoration that the status bar bell shows in other positions.

## Best solution

Mirror the status-bar logic (src/vs/workbench/browser/parts/notifications/notificationsStatus.ts, `updateNotificationsCenterStatusItem`) for the title-bar menu item in notificationsCommands.ts: introduce context keys for do-not-disturb / unread state and register icon-variant menu items (bell / bell-dot / bell-slash / bell-slash-dot) gated by `when`, the same pattern already used for the position-toggle actions with `toggled`.
