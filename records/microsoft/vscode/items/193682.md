# Issue #193682 — Profile icon should have a focus border when focus is not in text area

[https://github.com/microsoft/vscode/issues/193682](https://github.com/microsoft/vscode/issues/193682)

## Summary

Still reproduces on main: the shared IconSelectBox's `.icon-container.focused` CSS rule only sets a background color, no outline, so there's no visible focus border when the grid (not the search input) has DOM focus — exactly what the report and the maintainer discussion describe. The prior review's cited fix commit was refuted, and this review independently confirms the gap in current source rather than relying on it.

## Change summary

The icon picker's icon grid (used by the profile icon picker and other icon-select UIs) shows no focus border/outline on the active item, unlike standard VS Code lists.

## Best solution

Add an explicit outline for `.icon-container.focused` in src/vs/base/browser/ui/icons/iconSelectBox.css (ideally reusing a focus-outline color token, consistent with how standard lists style `.focused` rows) — but first settle, with the maintainers who already debated it in the thread, whether the grid should adopt list-like persistent-focus styling or stay closer to the quick-pick active/selected pattern.
