# Issue #190901 — Notebook cut fails to paste

[https://github.com/microsoft/vscode/issues/190901](https://github.com/microsoft/vscode/issues/190901)

## Summary

A real notebook clipboard gap remains on current main: cutting a cell overwrites previously cut editor text. The issue is already correctly routed and accepted into the Backlog, so it should remain open for product discussion.

## Change summary

Keep notebook cell cut/copy operations from replacing text previously stored in the system clipboard.

## Best solution

Separate notebook cell-operation state from the system text clipboard while preserving cell paste across notebooks and ordinary text paste behavior.
