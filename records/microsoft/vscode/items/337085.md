# Issue #337085 — MCP tool output cannot render an HTTPS deep link as a clickable link alongside structured answer and resources

[https://github.com/microsoft/vscode/issues/337085](https://github.com/microsoft/vscode/issues/337085)

## Summary

Current main has no deterministic path for an MCP tool result to place an HTTPS hyperlink in the final response alongside structured content and resources. This team-authored request should remain open for a supported presentation-contract decision.

## Change summary

Provide a supported MCP tool-result shape that renders a safe HTTPS deep link as clickable chat content while retaining structured output and generated resources.

## Best solution

Define and document a deterministic MCP presentation contract for safe HTTPS links, preserving structured content as model input and resource links as attachments while giving servers a supported way to request a user-visible hyperlink.

- **Trace:**

  > McpLanguageModelToolImpl.invoke in src/vs/workbench/contrib/mcp/common/mcpLanguageModelToolContribution.ts maps `resource_link` entries to resource-reference data and serializes `structuredContent` for the assistant. - **Open decisions:**

## Evidence
