# Issue #337085 — MCP tool output cannot render an HTTPS deep link as a clickable link alongside structured answer and resources

[https://github.com/microsoft/vscode/issues/337085](https://github.com/microsoft/vscode/issues/337085)

## Summary

Fresh, well-documented feature request confirmed against current source: resource_link items and structuredContent are never surfaced as an inline clickable link in the final chat response, only as attachments or raw JSON fed to the model. No maintainer triage yet beyond the automated version bot, no community traction, and no duplicate found, so this should stay open as a feature request pending maintainer interest.

## Change summary

MCP tool results that include an HTTPS deep link (via resource_link or structuredContent) alongside text and other resources have no supported way to render that link as clickable inline text in the final chat response.

## Best solution

A maintainer should decide the supported shape: either render resource_link with a plain http(s) URI as an inline clickable link instead of an MCP attachment, or define a structured-output convention (e.g. a designated field) that the chat renderer treats as trusted markdown for inline links — this is a product/UX decision, not a bug fix.
