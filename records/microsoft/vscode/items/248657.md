# Issue #248657 — Improve Top Activity Bar Usability with Better Spacing and Overflow Options

[https://github.com/microsoft/vscode/issues/248657](https://github.com/microsoft/vscode/issues/248657)

## Summary

The automatic overflow menu already exists on current main, but the requested configurable icon limit and additional spacing remain unresolved. The older spacing request was declined on consistency and capacity grounds, but that decision does not cover this issue's full scope, so the request should remain open for product discussion.

## Change summary

Improve the top-positioned Activity Bar with wider icon spacing and an optional limit on visible icons backed by an overflow menu.

## Best solution

Have the workbench UX owners decide whether top and bottom Activity Bars should use a roomier standard density and whether users should control the visible-item limit. Preserve the existing width-responsive overflow behavior and avoid an arbitrary configuration setting unless it provides a clear benefit beyond that behavior.
