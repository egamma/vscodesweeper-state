[https://github.com/microsoft/vscode/issues/316588](https://github.com/microsoft/vscode/issues/316588)

## Summary

Keep open: the reporter confirmed that out-of-workspace edits stall without a visible approval prompt in both Copilot CLI chat surfaces. No issue-referencing fix or eligible older canonical was verified, so this team-authored, previously reviewed report remains necessary.

## Change summary

Copilot CLI file edits outside the workspace wait indefinitely for permission without showing an actionable confirmation.

## Best solution

Ensure each required external-file write confirmation is visible and answerable in both regular chat and the Agents window, and that approval, denial, or cancellation resolves the waiting operation without weakening permission checks. Diagnose the shared Copilot CLI permission-to-chat integration rather than treating this as an Agents-window-only defect.
