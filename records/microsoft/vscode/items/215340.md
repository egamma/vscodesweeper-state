# Issue #215340 — Skip re-requesting implicit code actions if diagnostics around the cursor have not changed

[https://github.com/microsoft/vscode/issues/215340](https://github.com/microsoft/vscode/issues/215340)

## Summary

The optimization remains unimplemented on current main, but the discussion has not settled whether diagnostics elsewhere in the document may legitimately affect code actions at the cursor. Keep this open under discussion until the invalidation contract is decided.

## Change summary

Avoid recomputing implicit code actions when marker updates do not change diagnostics around the current cursor position.

## Best solution

Define when document-wide diagnostic changes are allowed to invalidate code actions at the cursor, then cache and compare the relevant marker state before auto-triggering. Preserve correctness for providers whose actions can depend on broader document state, potentially through an explicit provider change event if that use case is retained.
