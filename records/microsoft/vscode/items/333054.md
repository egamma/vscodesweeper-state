# Issue #333054 — Diff Editor: Setting to Change Overview Ruler Size

[https://github.com/microsoft/vscode/issues/333054](https://github.com/microsoft/vscode/issues/333054)

## Summary

The requested width control is still missing: the diff-specific overview ruler has a fixed width independent of the ordinary scrollbar setting. Keep this open as a feature request; the inspected related issues cover different behaviors.

## Change summary

Allow users to decrease or increase the width of the diff editor's dedicated overview ruler without resizing the ordinary editor scrollbar.

## Best solution

Have the diff editor owner assess whether adjustable overview width warrants a supported option, balancing quieter secondary chrome with consistent navigation targets. Existing visibility and scrollbar options do not satisfy retaining the diff overview at a chosen width.

## Evidence

- **Current width is fixed:** src/vs/editor/browser/widget/diffEditor/features/overviewRulerFeature.ts defines ONE_OVERVIEW_WIDTH = 15 and ENTIRE_DIFF_OVERVIEW_WIDTH = ONE_OVERVIEW_WIDTH * 2. The overview container, both decoration lanes, and viewport indicator use these constants, rather than a configurable width.
- **Existing options do not cover the request:** src/vs/editor/common/config/editorOptions.ts exposes editor.scrollbar.verticalScrollbarSize for the ordinary scrollbar and a boolean renderOverviewRuler diff-editor option. In overviewRulerFeature.ts, verticalScrollbarSize is passed to ScrollbarState, but the diff overview's horizontal geometry remains constant. Hiding the overview or changing ordinary overview lanes does not provide the requested adjustable diff-specific width.
