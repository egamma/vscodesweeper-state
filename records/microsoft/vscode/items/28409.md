# Issue #28409 — Add "line_padding_bottom", "line_padding_top" like sublime text

[https://github.com/microsoft/vscode/issues/28409](https://github.com/microsoft/vscode/issues/28409)

## Summary

The central request is implemented: line spacing can now be increased without forcing the line cursor to fill the entire line height, using `editor.cursorHeight`.

## Change summary

Allow vertical line spacing without making the editor cursor as tall as the configured line height.

## Best solution

Use the shipped `editor.lineHeight` and `editor.cursorHeight` settings together; commit 648281e68857dc1494e624e2081b8186f30f4244 decouples line-cursor height from line height.

## Vision fit

- **Fit:** rejected
- **Reason:** Separate top and bottom padding settings would add narrowly scoped visual configuration, while the shipped cursor-height control addresses the motivating problem with less configuration.
- **Evidence:** Values and guardrails favor a simple, uniform UI and caution against per-component visual toggles and configuration sprawl.
