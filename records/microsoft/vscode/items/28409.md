# Issue #28409 — Add "line_padding_bottom", "line_padding_top" like sublime text

[https://github.com/microsoft/vscode/issues/28409](https://github.com/microsoft/vscode/issues/28409)

## Summary

The central request—more space between lines without making the cursor taller—is now supported by combining editor.lineHeight with editor.cursorHeight. A concrete merged implementation supports closing this accepted backlog request as completed.

## Change summary

Allow increased editor line spacing while keeping the caret independently sized.

## Best solution

Use editor.lineHeight for line spacing and editor.cursorHeight for the line cursor's height, preserving the implementation in commit 648281e68857dc1494e624e2081b8186f30f4244. Separate asymmetric per-line padding is not implemented, but the issue and discussion identify independent cursor height as the desired outcome.
