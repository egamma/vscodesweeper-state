# Issue #316603 — committerDate as variable for Git blame decorations

[https://github.com/microsoft/vscode/issues/316603](https://github.com/microsoft/vscode/issues/316603)

## Summary

The built-in blame templates still expose only author metadata, so the requested committer-date capability remains missing. Keep this accepted Backlog request open; the related date-formatting requests do not own the same work.

## Change summary

Expose committer information, particularly the committer date, in Git blame editor-decoration and status-bar templates.

## Best solution

Extend the built-in Git blame template capability to expose the blamed commit's committer date independently of its author date on both surfaces, preserving existing author tokens and defaults.
