# Issue #97190 — Provide some richer (optional) UI for custom tree views

[https://github.com/microsoft/vscode/issues/97190](https://github.com/microsoft/vscode/issues/97190)

## Summary

Well-supported feature request (127 upvotes) with partial progress — search/filter and richer hovers are done, but the most-requested remaining items (inline input/rename box, details pane) have no API or implementation on current main. Stays open in Backlog.

## Change summary

Provide richer optional UI components for extension-authored tree views, including inline input/rename boxes and a details footer pane.

## Best solution

Implement an extension API for inline editing/rename in TreeView nodes (the capability already exists internally for the Explorer and Debug Variables views but is not exposed via `vscode.TreeView`). A details/footer pane is a secondary ask. The `tree-views` area label is correct; no re-routing needed.
