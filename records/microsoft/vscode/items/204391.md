# Issue #204391 — Debug Console filter with Go is difficult to use and inaccurate

[https://github.com/microsoft/vscode/issues/204391](https://github.com/microsoft/vscode/issues/204391)

## Summary

The central filtering defect is fixed on current main: multiline debug-adapter output is now split into individual text-line elements before filtering, so unrelated lines are no longer retained as one block and the displayed count reflects those line elements. The reported Home/End behavior was also fixed separately, while Copy All remains available for output extraction.

## Change summary

Make Debug Console filtering and copying usable when the Go debugger emits substantial or multiline output.

## Best solution

Keep the line-based Debug Console model introduced by commit 27fe9fc76c2fb9e1c957c0249b89ae85880fe05c; any remaining request for selecting across virtualized output should be tracked separately from the resolved filtering defect.
