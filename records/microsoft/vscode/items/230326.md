# Issue #230326 — Only expose chat code blocks to languages once they are complete

[https://github.com/microsoft/vscode/issues/230326](https://github.com/microsoft/vscode/issues/230326)

## Summary

Keep open: current source still exposes ordinary chat code-block models to extensions while their content streams. The original implementation was explicitly reverted, and the related synchronization-control issue is newer, so neither provides grounds to close this reopened report.

## Change summary

Delay exposing streamed chat code-block documents to language extensions until the blocks are complete.

## Best solution

Keep streaming code visible in chat while deferring extension document synchronization until completion, without losing completed-block language features. Coordinate the lifecycle work with https://github.com/microsoft/vscode/issues/232538 and establish why the previous implementation needed reverting before choosing a replacement.
