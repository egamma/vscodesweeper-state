# Issue #230326 — Only expose chat code blocks to languages once they are complete

[https://github.com/microsoft/vscode/issues/230326](https://github.com/microsoft/vscode/issues/230326)

## Summary

Still open: the original fix (PR #232536) was reverted, and the recent codeblock simplification (11f363eab70) did not reintroduce the completeness gate. Chat code block text models are still updated live during streaming and visible to language extensions via ITextModelService.

## Change summary

Defer exposing chat code block text models to language extensions until the code block is fully streamed.

## Best solution

Implement a mechanism in the code block rendering pipeline (codeBlockPart.ts / chatMarkdownContentPart.ts) to either delay model registration with ITextModelService until streaming completes, or use a transient scheme/language during streaming. The related issue https://github.com/microsoft/vscode/issues/232538 tracks the broader API for controlling document sync frequency and may provide the foundation for this fix.
