# Issue #247046 — Accessible diff view become blank after accepting the change that agent made

[https://github.com/microsoft/vscode/issues/247046](https://github.com/microsoft/vscode/issues/247046)

## Summary

Keep open for an accessible review-completion experience. A maintainer confirmed that the blank view is currently intentional but suggested improving it; current source still lacks an explicit empty state, and the choice between announcing completion and automatically returning to the editor remains unsettled.

## Change summary

Provide a meaningful completion state or navigation destination when accepting an agent edit leaves the accessible diff viewer empty.

## Best solution

Make completion understandable and keyboard-accessible rather than leaving an unexplained blank review surface. Settle whether the viewer should retain focus with an accessible completion message or close and return focus to the editor, while preserving navigation when changes remain.
