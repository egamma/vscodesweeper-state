# Issue #247046 — Accessible diff view become blank after accepting the change that agent made

[https://github.com/microsoft/vscode/issues/247046](https://github.com/microsoft/vscode/issues/247046)

## Summary

Still reproduces on main: the accessible diff viewer goes blank after accepting the last change because no empty-state handling exists. A team member confirmed the behavior and suggested improvements (show a message or auto-close) but no fix has landed.

## Change summary

Accessible diff viewer shows a blank screen after accepting the last change instead of showing a message or closing.

## Best solution

Add empty-state handling in `accessibleDiffViewer.ts` — when `_groups` becomes empty after an accept action, either auto-close the viewer or display a 'no changes left to review' message. The fix lives in the ViewModel's autorun that watches `_diffs`.
