# Issue #314142 — agents app, package-lock generation causes large line change count that doesn't show in changes

[https://github.com/microsoft/vscode/issues/314142](https://github.com/microsoft/vscode/issues/314142)

## Summary

Still open on main: the changes summary pill counts insertions/deletions from all files (including generated ones like package-lock.json), but some of those files don't appear in the changes view, creating a confusing mismatch. No fix commit references this issue.

## Change summary

In the Agents window, when an agent runs `npm install` and generates a package-lock.json, the changes pill shows a large line count but the changes view shows nothing, making it unclear what was modified.

## Best solution

The changes summary widget in `src/vs/sessions/contrib/changes/browser/changesSummaryWidget.ts` and the changes pill in `changesActions.ts` should compute their totals from the same set of files that actually appear in the changes view. Either the summary should exclude files not shown in the changes view, or the changes view should include all files that contribute to the summary count. The mismatch likely originates from the agent host reporting file changes that the changeset doesn't expose via its `changes` observable.
