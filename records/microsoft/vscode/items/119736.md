# Issue #119736 — Emmet JSX HTML abbreviations suggested inside `style` tag

[https://github.com/microsoft/vscode/issues/119736](https://github.com/microsoft/vscode/issues/119736)

## Summary

Still reproduces on main: the Emmet completion provider's style-tag detection (which switches syntax to CSS) only fires when `syntax === 'html'`, so JSX files (`syntax === 'jsx'`) never get that switch — HTML/JSX abbreviations are suggested inside CSS regions (styled-components, inline style blocks).

## Change summary

Emmet suggests JSX HTML abbreviations instead of CSS abbreviations when typing inside CSS regions (e.g. styled-components template literals) in JSX/TSX files.

## Best solution

Extend the style-node detection logic in `extensions/emmet/src/defaultCompletionProvider.ts` (currently gated on `syntax === 'html'` at line 76) to also handle the `'jsx'` case, or implement the embedded-language API the author described so Emmet can determine the local language in mixed-content regions of JSX files.
