# Issue #173842 — Task with empty command does not terminate

[https://github.com/microsoft/vscode/issues/173842](https://github.com/microsoft/vscode/issues/173842)

## Summary

Still reproduces on main: `_isTaskEmpty()` treats an empty-string command as non-empty because `"" !== undefined` is true, so the task enters terminal execution and never terminates. An open PR (#251115) proposes a fix; keeping open until it lands.

## Change summary

A task with an empty command string (`"command": ""`) never terminates — it should complete immediately with exit code 0.

## Best solution

Land or refine the open PR https://github.com/microsoft/vscode/pull/251115, which adds a trimmed-empty-string check to `_isTaskEmpty()` in `terminalTaskSystem.ts`. The fix is small and localized; the PR already targets the right code path.

## Evidence

- **bug in source:** src/vs/workbench/contrib/tasks/browser/terminalTaskSystem.ts line 839: `_isTaskEmpty` returns false for empty-string commands because the guard is `task.command.name !== undefined` — an empty string passes this check, so the task proceeds to `_executeInTerminal` and hangs.
- **confirmed by team:** Comment by @anthonykim1 (MEMBER) on 2025-05-27 confirms reproduction: the empty task shows a progress icon and never completes.
- **open fix PR:** https://github.com/microsoft/vscode/pull/251115 is open (not merged) and targets this issue with `Fixes #173842`. It adds a `CommandString.value(task.command.name).trim() !== ''` check to `_isTaskEmpty()`.
