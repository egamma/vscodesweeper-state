# Issue #329619 — AHP listSessions ignores limit and cursor pagination parameters

[https://github.com/microsoft/vscode/issues/329619](https://github.com/microsoft/vscode/issues/329619)

## Summary

Keep open: current main still ignores listSessions pagination inputs, and a maintainer expressed interest in incremental loading. Classify this as a feature request rather than a protocol violation because the current shared contract explicitly permits non-paginating servers to ignore those inputs.

## Change summary

Support bounded, most-recently-modified-first AHP session pages with opaque continuation cursors and invalid-cursor rejection.

## Best solution

Provide pagination over the requesting client's visible session catalogue while preserving existing unpaged behavior, visibility filtering, and listener-specific adaptations. Treat reducing underlying catalogue enumeration and enrichment costs as a separate optimization rather than a prerequisite for bounded wire responses.
