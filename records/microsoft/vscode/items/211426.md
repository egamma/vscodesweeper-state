The older, open canonical issue reports the same tab-switching symptom and includes maintainer-confirmed reproductions. Consolidate this report there, preserving the Linux and Windows observations.

## Change summary

Switching away from an editor and back replaces the current find-result index with '?', although navigating still advances from the correct match.

## Best solution
