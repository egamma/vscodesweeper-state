# Issue #211426 — Search-Indicator - Number of found items not updated when switching tabs

[https://github.com/microsoft/vscode/issues/211426](https://github.com/microsoft/vscode/issues/211426)

## Summary

The current source still permits the match position to become unknown when an editor model is restored after its find model has already recalculated. The issue is correctly routed to editor find and should remain open.

## Change summary

Preserve and display the current find-match index when switching away from and back to an editor tab.

## Best solution

Recalculate the current match position after the restored editor selection is applied, while preserving the intentional “? of N” state when the user explicitly moves away from a match.
