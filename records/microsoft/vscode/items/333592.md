# Issue #333592 — Focus border corners are cut

[https://github.com/microsoft/vscode/issues/333592](https://github.com/microsoft/vscode/issues/333592)

## Summary

Real, source-traceable visual bug in the new chat agent-merge widget: the collapsible header is a focusable Button whose default focus style pushes the outline outward (`outline-offset: 2px !important` in button.css), while its ancestor `.chat-agent-merge` clips with `overflow: hidden` and a rounded `border-radius`, so the outline gets clipped exactly at the rounded corners.

## Change summary

Clicking the agent merge widget in chat shows a focus outline whose corners are visibly cut off by the widget's rounded, clipped container.

## Best solution

Add a CSS override for the merge widget's header focus style (e.g. `.chat-agent-merge-header.monaco-text-button:focus { outline-offset: -1px !important; }`) in chatAgentMergeContent.css, matching the existing negative-outline-offset pattern already used elsewhere in the codebase (e.g. src/vs/sessions/.../sessionsTitleBarWidget.css:64) to keep the outline inside the rounded, overflow-hidden container.
