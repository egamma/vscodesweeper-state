## Change summary

Starting new coding-agent work after merging a checked-out PR and deleting its branch incorrectly targets a nonexistent PR, and switching to main does not recover until VS Code restarts.

## Best solution

New cloud-agent work should use valid, current repository context rather than stale PR identity, and switching to main should recover without restarting. Reproduce the reported lifecycle against the current cloud-session implementation before deciding whether a code change remains necessary.
