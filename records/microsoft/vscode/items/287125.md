# Issue #287125 — No heading is defined on every copilot response: A11y_Visual Studio Code_Github Copilot_Screenreader

[https://github.com/microsoft/vscode/issues/287125](https://github.com/microsoft/vscode/issues/287125)

## Summary

The accessibility defect remains on current main: Copilot responses hide their only heading from the accessibility tree, so NVDA heading navigation cannot reach each response. The issue is correctly routed to accessibility and should remain open.

## Change summary

Expose every generated Copilot response as a screen-reader heading so users can navigate between responses with heading commands.

## Best solution

Preserve the streamlined visual presentation while exposing a stable heading at the beginning of every Copilot response, including local and Agent Host Copilot sessions, and cover that semantic contract in the chat renderer tests.
