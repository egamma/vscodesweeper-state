# Issue #338417 — Show same information for sub chats as for main chat in a session

[https://github.com/microsoft/vscode/issues/338417](https://github.com/microsoft/vscode/issues/338417)

## Summary

Fresh, reasonable UX-consistency request (0 days old, no discussion yet) about the just-shipped agent-sessions sub-chat feature; the third bullet (no per-repo lines-added/removed breakdown in the summary hover) is confirmed in current source, so this stays open for the sessions team to triage and design.

## Change summary

Sub-chats in an agent session don't surface the same info as the main chat (lines added/removed, 'updated N ago'), and the session summary hover only shows a combined total of lines changed instead of a per-repo/workspace breakdown.

## Best solution

Have the sessions/agentSessions area own this: decide which per-session metadata (change stats, last-updated timestamp) sub-chats should surface in the list UI, and extend sessionSummaryHover.ts to render changes per location instead of a single aggregate row.
