# Issue #343156 — Variables for current theme colors.

[https://github.com/microsoft/vscode/issues/343156](https://github.com/microsoft/vscode/issues/343156)

## Summary

Existing task icon colors already resolve against the active theme, but general theme-color substitution across extension settings is not established by that support. Keep this request open to distinguish the proposed broader capability from the existing ANSI color references; neither inspected related issue clearly owns that full scope.

## Change summary

Provide theme-aware color variables usable in task icon configuration and extension UI color settings.

## Best solution

Establish which theme colors and extension configuration surfaces need references beyond the existing theme-color IDs. Preserve the current task icon behavior, where terminal.ansiBlue already selects the active theme's terminal blue, rather than introducing equivalent aliases without an additional capability.
