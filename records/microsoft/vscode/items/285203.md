# Issue #285203 — Quick Pick cannot be dismissed with mouse only (accessibility issue)

[https://github.com/microsoft/vscode/issues/285203](https://github.com/microsoft/vscode/issues/285203)

## Summary

The generic mouse-only dismissal request is already covered by the older, open issue https://github.com/microsoft/vscode/issues/99081. Its discussion explicitly covers adding a close button to all focus-persistent Quick Picks, including those without a title bar, so consolidation preserves the full requested scope.

## Change summary

Provide a visible mouse-operable cancellation control for Quick Picks that remain open when focus is lost.

## Best solution

Consolidate the generic close-control work in https://github.com/microsoft/vscode/issues/99081, preserving this report's adaptive-input scenario and iPad keyboard motivation. The resulting control should cancel without accepting a selection while retaining intentional ignoreFocusOut behavior.
