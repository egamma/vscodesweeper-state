# Issue #267359 — Surface terminal progress sequence results in first class UI

[https://github.com/microsoft/vscode/issues/267359](https://github.com/microsoft/vscode/issues/267359)

## Summary

Keep open: current main exposes terminal progress through label text and icons, but does not provide the requested first-class progress bar. The existing terminal label is appropriate, and no verified canonical issue owns this remaining capability.

## Change summary

Display progress reported through terminal escape sequences using VS Code's progress-bar UI above the terminal or on its tab.

## Best solution

Use the existing OSC 9;4 progress state to drive a standard, accessible progress indicator in the terminal surface. The terminal owner should settle its placement and presentation before implementation; label-template support is useful but does not fulfill the graphical progress-bar request.
