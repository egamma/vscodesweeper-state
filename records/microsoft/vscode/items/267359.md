# Issue #267359 — Surface terminal progress sequence results in first class UI

[https://github.com/microsoft/vscode/issues/267359](https://github.com/microsoft/vscode/issues/267359)

## Summary

Valid feature request from the terminal area owner. VS Code already parses OSC 9;4 progress sequences and exposes a `${progress}` tab title variable, but lacks a first-class visual progress bar UI element (e.g., at the top of the terminal or on the tab). The requested UI enhancement remains unimplemented on main.

## Change summary

Show terminal progress sequences (OSC 9;4) as a visual progress bar in the terminal UI rather than only as a tab title variable.

## Best solution

Add a progress bar widget (similar to the editor's scoped progress indicator) at the top of the terminal pane or as a visual decoration on the terminal tab, driven by the existing `IProgressState` from the `@xterm/addon-progress` addon. The plumbing is already in place — `xtermTerminal.ts` fires `onDidChangeProgress` and `terminalInstance.ts` exposes `progressState`; the remaining work is purely UI rendering.
