# Issue #325924 — Fixtures do not render file icons with resource labels

[https://github.com/microsoft/vscode/issues/325924](https://github.com/microsoft/vscode/issues/325924)

## Summary

The fixture infrastructure currently installs color-theme styles but not an enabled file-icon theme, explaining the missing resource-label icons. Keep this team-authored bug open and route it to engineering.

## Change summary

Component fixtures using resource labels omit the corresponding file icons.

## Best solution

Extend the component-fixture theme setup in `fixtureUtils.ts` to load and apply a deterministic built-in file-icon theme, including its stylesheet and enabled-state class within the fixture container.

- **production behavior:** `src/vs/workbench/services/themes/browser/workbenchThemeService.ts:718-726` applies file-icon stylesheet content and adds `file-icons-enabled`, behavior absent from fixture setup.
- **resource-label path:** `src/vs/workbench/browser/labels.ts:671-680` computes file icon classes for resource labels, so the label path is present but lacks the fixture-level icon-theme styling needed to render those classes.
