# Issue #343218 — Remove the fake copilot command from the RPM package

[https://github.com/microsoft/vscode/issues/343218](https://github.com/microsoft/vscode/issues/343218)

## Summary

Keep open for a packaging decision: current RPM installation still adds the Copilot launcher by default. Linux policy support addresses the reported lack of an administrative opt-out, but does not satisfy the central request to separate the launcher from the editor package.

## Change summary

Stop installing the Copilot launcher through the primary VS Code RPM and consider distributing it as an optional package.

## Best solution

Have the Linux packaging owner decide whether the system-wide Copilot launcher should require a separate installation choice, so command discovery does not imply that the standalone CLI is installed. Preserve independently installed Copilot commands and existing enterprise policy behavior.

- **Fit:** aligned
- **Reason:** Making an additional system-wide command optional supports a lightweight default editor experience and deliberate CLI integration.
