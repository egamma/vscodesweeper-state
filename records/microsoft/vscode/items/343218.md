# Issue #343218 — Remove the fake copilot command from the RPM package

[https://github.com/microsoft/vscode/issues/343218](https://github.com/microsoft/vscode/issues/343218)

## Summary

Keep open: Linux already supports disabling the launcher through policy, but that does not satisfy the request to stop publishing it by default from the editor RPM. Separating the launcher into an optional package remains a packaging decision.

## Change summary

Stop the VS Code RPM from exposing a copilot launcher when the actual CLI is absent, potentially distributing the launcher separately.

## Best solution

Have the Linux packaging owner evaluate making the system-wide launcher independently installable rather than advertising CLI availability with the editor package. Document the existing Linux policy workaround without treating it as resolution of the default-packaging request.

  > Thanks for the request.
