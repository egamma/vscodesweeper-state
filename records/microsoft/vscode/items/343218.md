# Issue #343218 — Remove the fake copilot command from the RPM package

[https://github.com/microsoft/vscode/issues/343218](https://github.com/microsoft/vscode/issues/343218)

## Summary

Keep open: RPM installation still exposes the Copilot bootstrap command by default. Linux now has a policy-controlled opt-out, but that does not satisfy the requested separation into an optional package.

## Change summary

Stop exposing the Copilot bootstrap command through the main VS Code RPM and make it separately installable.

## Best solution

Have the Linux packaging owners decide whether system-wide Copilot command exposure should require an optional RPM. Preserve independently installed CLI commands and existing package upgrade/removal behavior.
