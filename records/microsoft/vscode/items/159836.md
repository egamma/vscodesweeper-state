# Issue #159836 — Startup profiler should use issue reporter instead

[https://github.com/microsoft/vscode/issues/159836](https://github.com/microsoft/vscode/issues/159836)

## Summary

The startup profiler still opens GitHub directly and relies on manually pasted clipboard data, so the requested integration remains missing. Keep this team-authored, accepted backlog item open; no verified canonical or fixing commit was identified.

## Change summary

Route startup-profile reports through the built-in issue reporter instead of opening a GitHub template that requires pasting diagnostic data.

## Best solution

Have the startup profiling flow present its collected diagnostics in the built-in issue reporter while retaining profile-file attachment instructions and a usable restart workflow.
