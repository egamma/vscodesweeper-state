# Issue #47192 — [html] propose html 4 properties (cellPadding ...)

[https://github.com/microsoft/vscode/issues/47192](https://github.com/microsoft/vscode/issues/47192)

## Summary

A real built-in completion gap remains for legacy HTML used in email templates: current data includes deprecated `align`, but still omits `cellpadding`, `cellspacing`, and `valign`. The `html.customData` setting is a workable customization path, not full coverage of the central request, so this should remain open for a product decision.

## Change summary

Offer completion for selected HTML 4 table attributes, accounting for their obsolete or doctype-dependent status.

## Best solution

Decide whether the HTML language service should include commonly used legacy attributes with deprecation metadata, potentially conditioned on document type; preserve `html.customData` as the workaround for specialized attribute sets.
