# Issue #73748 — Be able disable task detection from tasks.json or override tasks execution

[https://github.com/microsoft/vscode/issues/73748](https://github.com/microsoft/vscode/issues/73748)

## Summary

Valid feature request from a team member. The task system still reads tasks.json from all workspace folder schemes without an API to disable detection or override execution per scheme. No evidence of implementation on main.

## Change summary

Allow extensions to disable task detection from tasks.json or override task execution based on workspace folder URI scheme.

## Best solution

Add an extension API in the task system (around `registerTaskSystem` / `ITaskSystemInfo` in `src/vs/workbench/contrib/tasks/browser/abstractTaskService.ts`) that lets extensions either opt out of tasks.json detection for non-file schemes, or override task execution when the tasks.json originates from a virtual/remote file system. This aligns with the existing scheme-keyed `_taskSystemInfos` map but needs a filtering/override surface exposed to extensions.
