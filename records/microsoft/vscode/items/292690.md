# Issue #292690 — Notebook Outline view does not auto-update code cell symbols without manual refresh

[https://github.com/microsoft/vscode/issues/292690](https://github.com/microsoft/vscode/issues/292690)

## Summary

Confirmed on current main: when notebook cell content changes, the outline only calls `recomputeState()` (which reads from a stale symbol cache) instead of also calling `computeSymbols()` to refresh the cache. The bug is real and localized.

## Change summary

Notebook Outline view does not auto-update code cell symbols when new functions/classes are defined in a cell; requires manual toggle of the Code Cell Symbols filter.

## Best solution

In `setModelListeners()` in `notebookOutline.ts`, the `onDidChangeContent` handler for `ChangeCellContent` should also trigger `delayedComputeSymbols()` (not just `delayedRecomputeState()`), so that the symbol cache is refreshed when cell content changes. `computeFullSymbols` in the data source already re-calls `recomputeState()` after caching, so no double-fire risk.
