[https://github.com/microsoft/vscode/issues/186312](https://github.com/microsoft/vscode/issues/186312)

## Summary

The reported inconsistency remains in current source: command-center sharing displays the generated link in a dialog, while gutter copying writes directly to the clipboard. Keep this team-authored item open for an owner decision on consistent completion feedback; neither a qualifying fix nor an older canonical covering the same symptom was established.

## Change summary

Make link-sharing completion feedback consistent between the command-center Share action and the editor gutter.

## Best solution

Establish a consistent feedback policy for equivalent link-copy operations across the workbench Share action and built-in GitHub commands, preserving their resource and line-selection context. The owner should settle whether consistency means showing a dialog in both entry points or avoiding it for explicit copy operations.
