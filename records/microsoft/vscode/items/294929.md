# Issue #294929 — Overview ruler rendering in terminal can be expensive

[https://github.com/microsoft/vscode/issues/294929](https://github.com/microsoft/vscode/issues/294929)

## Summary

Team-filed upstream perf issue — the xterm.js fix (PR xtermjs/xterm.js#5697) merged same day, and the issue carries `upstream-issue-fixed`, but VS Code's bundled @xterm/xterm (5.6.0-beta.99) still contains the forced-layout `clientHeight` reads. Remains open until the dependency is bumped to pick up the fix.

## Change summary

The terminal overview ruler forces expensive layout reflows on every render by reading `_screenElement.clientHeight` synchronously.

## Best solution

Bump `@xterm/xterm` to a version that includes commit 2f66b5fdb697 ("Avoid forced layout in overview ruler impl") — the fix avoids the synchronous `clientHeight` read. Once the dependency update lands, verify the input-latency regression is resolved and close this issue.
