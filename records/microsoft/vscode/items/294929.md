# Issue #294929 — Overview ruler rendering in terminal can be expensive

[https://github.com/microsoft/vscode/issues/294929](https://github.com/microsoft/vscode/issues/294929)

## Summary

The upstream xterm.js issue is closed (fixed upstream), but VS Code's bundled @xterm/xterm (beta.99) still reads `_screenElement.clientHeight` on every render callback, forcing layout. The fix hasn't been consumed yet — keeping open until an xterm bump picks it up.

## Change summary

Terminal overview ruler forces expensive layout reflows by reading `clientHeight` on every render cycle.

## Best solution

Bump the @xterm/* dependency to a version that includes the upstream fix for xtermjs/xterm.js#5696 (likely caching or avoiding the clientHeight read in OverviewRulerRenderer). The label `upstream-issue-fixed` is correct — this just needs consumption.
