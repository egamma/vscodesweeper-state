[https://github.com/microsoft/vscode/issues/330811](https://github.com/microsoft/vscode/issues/330811)

## Summary

Well-specified feature request for a richer per-chat scroll experience (reading mode with configurable preview lines, smooth batched animation). Current main already has a scroll-lock/jump-to-latest mechanism but not the reading-mode preview or animation batching this asks for, so a real gap remains; routing to the chat area for product/design triage.

## Change summary

Add a per-chat auto-scroll toggle with a 'reading mode' that reveals only a configurable number of lines of a new streaming response and animates/batches scroll movement in 'follow latest' mode.
