# Issue #255363 — Explorer context menu: Test actions should not show if file does not have any tests

[https://github.com/microsoft/vscode/issues/255363](https://github.com/microsoft/vscode/issues/255363)

## Summary

The Explorer still shows test actions based on globally available test profiles rather than the selected file's tests. Keep this maintainer-authored polish issue open: the linked implementation was closed without merging, and its review identified unresolved discovery and performance constraints.

## Change summary

Hide Run Tests, Debug Tests, and Run Tests with Coverage from the Explorer context menu for files without tests.

## Best solution

Make Explorer test-action visibility reflect the selected file without hiding actions for unopened test files or slowing Explorer focus and context-menu handling. Preserve the maintainer-approved fallback of showing actions for folders rather than recursively discovering their tests.
