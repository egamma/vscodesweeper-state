# Issue #255363 — Explorer context menu: Test actions should not show if file does not have any tests

[https://github.com/microsoft/vscode/issues/255363](https://github.com/microsoft/vscode/issues/255363)

## Summary

Still reproduces on main: test actions (Run Tests, Debug Tests, Run Tests with Coverage) show in the explorer context menu for all files regardless of whether they contain tests. The related PR #255364 was closed without merging, so the fix has not landed.

## Change summary

Explorer context menu shows Run/Debug/Coverage test actions on files that have no tests, adding useless clutter.

## Best solution

Add a context key (e.g. `explorerResourceHasTests`) that tracks whether the selected explorer resource contains tests, and gate the test action menu items on it — similar to the existing `activeEditorHasTests` pattern. The fix touches `testingContextKeys.ts`, `testExplorerActions.ts`, and `explorerView.ts`.
