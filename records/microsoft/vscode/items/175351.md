# Issue #175351 — Make the peek submodule contributable

[https://github.com/microsoft/vscode/issues/175351](https://github.com/microsoft/vscode/issues/175351)

## Summary

The extension API gap remains on current main: extensions cannot contribute commands to the built-in Peek submenu. The issue is already correctly classified and routed.

## Change summary

Expose the editor's built-in Peek context submenu as an extension menu contribution point.

## Best solution

Add an `editor/context/peek` entry mapped to `MenuId.EditorContextPeek` in `src/vs/workbench/services/actions/common/menusExtensionPoint.ts`, allowing extensions such as rust-analyzer to integrate with the existing submenu.
