# Issue #145696 — Expose checkbox in extension dialog API

[https://github.com/microsoft/vscode/issues/145696](https://github.com/microsoft/vscode/issues/145696)

## Summary

The internal dialog service already supports checkboxes (ICheckbox/ICheckboxResult in src/vs/platform/dialogs/common/dialogs.ts), but this is not exposed in the extension API's MessageOptions. The feature request remains valid and unimplemented.

## Change summary

Expose checkbox support in the extension dialog/message API (vscode.window.showInformationMessage etc.) so extensions can offer 'Don't show again' as a checkbox rather than a button.

## Best solution

Extend MessageOptions (or introduce a ModalOptions bag as suggested in comment 6) to include checkbox configuration, piping through to the existing internal ICheckbox/ICheckboxResult infrastructure in the dialog service. The return type would need to include the checkbox state.
