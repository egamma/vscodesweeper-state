# Issue #338344 — `executeTask()` resolves for a fetched task that never runs when the task lookup fails

[https://github.com/microsoft/vscode/issues/338344](https://github.com/microsoft/vscode/issues/338344)

## Summary

The failure remains in current main: a fetched task's second lookup can reject while executeTask() returns an execution and suppresses the error. The linked fix PR was closed without merging, so the issue still needs a fix.

## Change summary

Reject executeTask() when a fetched task cannot be resolved for execution instead of returning an execution that never starts or ends.

## Best solution

Make the fetched-task execution promise report lookup failures to the caller while preserving successful execution timing and shared execution bookkeeping. Cover overlapping requests so one failed call cannot invalidate an execution started by another call or the UI.
