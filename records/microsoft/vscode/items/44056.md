# Issue #44056 — When A grammar injects to B, grammars embedding B should get A's injection

[https://github.com/microsoft/vscode/issues/44056](https://github.com/microsoft/vscode/issues/44056)

## Summary

Maintainer analysis of the same embedded-grammar injection behavior concluded that injections are intentionally collected only for the root grammar. Recursively inheriting injections would effectively make many existing injections global, break grammars, and diverge from TextMate behavior, so this can close as designed.

## Change summary

Make a grammar embedded by another grammar automatically inherit all injections contributed to the embedded grammar.

## Best solution

Keep root-only injection collection for compatibility. Extension authors needing this composition should explicitly contribute the injection to each host grammar and constrain its injection selector to the relevant embedded scopes.

## Evidence

- **maintainer decision:** https://github.com/microsoft/vscode-textmate/issues/152 documents the same observable behavior. Maintainer investigation found that recursively collecting injections effectively makes them global, broke an existing Razor colorization test, and was declined because TextMate itself does not honor injections from included grammars.
- **current VS Code source:** src/vs/workbench/services/textMate/common/TMGrammarFactory.ts registers `getInjections(scopeName)` by looking up injections associated with the requested grammar scope; it does not expand injections from scopes included by that grammar.
- **current upstream source:** microsoft/vscode-textmate's `Grammar._collectInjections` collects injections for `_rootScopeName` only, while `Registry._doLoadSingleGrammar` associates contributed injections with the individually loaded scope. This preserves the behavior described in the issue.
- **matching precedent:** https://github.com/microsoft/vscode/issues/87496 reports injections working for a standalone language but not when that language is embedded. The documented workaround is to add the host grammar to `injectTo`, matching the intended root-only model.
- **canonical search:** The older open https://github.com/microsoft/vscode/issues/20488 concerns embedded grammars corrupting and forcing re-tokenization of the containing document, not inheritance of injection grammars, so it does not own this request.
