# Issue #130053 — Find widget: renders "? of 5" 

[https://github.com/microsoft/vscode/issues/130053](https://github.com/microsoft/vscode/issues/130053)

## Summary

The defect remains traceable on current main: switching models restarts find before the editor restores its selection, leaving the displayed match position unknown. It should remain open in editor-find.

## Change summary

Switching away from and back to an editor can make the Find widget display an unknown current match such as “? of 5.”

## Best solution

Recompute or restore the current find match after the editor view state and selection have been restored, coordinating the find controller lifecycle with text editor model restoration without changing the intentional unknown-position state for ordinary searches.
