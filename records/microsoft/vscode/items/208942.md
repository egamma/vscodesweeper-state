## Summary

Verified duplicate: the older open canonical issue owns cross-application native file transfer, including the upstream limitation that permits only one selected file to be dragged out of VS Code.

## Change summary

Dragging multiple selected Explorer files to Windows File Explorer or the desktop copies only one file.

## Best solution
