# Issue #345481 — Agents window hangs restoring large cached cloud-sandbox inventory on the renderer thread

[https://github.com/microsoft/vscode/issues/345481](https://github.com/microsoft/vscode/issues/345481)

## Summary

Keep open: current source still restores cached inventories synchronously and repeatedly rebuilds provider-dependent state. The captured startup hangs identify a local renderer bottleneck distinct from excessive network discovery.

## Change summary

Large cached cloud-sandbox inventories block the Agents window during account restoration.

## Best solution

Make cached-inventory restoration perform bounded renderer work while preserving complete offline history and account isolation. Establish a large-inventory responsiveness regression covering provider notifications and session-list consumers, not only restoration throughput.
