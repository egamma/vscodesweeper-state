# Issue #318407 — Device preset should be dropdown?

[https://github.com/microsoft/vscode/issues/318407](https://github.com/microsoft/vscode/issues/318407)

## Summary

Valid polish request from a team member — the device preset selector in the browser emulation toolbar currently uses a QuickPick action button rather than an inline dropdown, so the toolbar doesn't reflect the current selection. Not yet addressed on main.

## Change summary

Change the browser emulation device-preset picker from a QuickPick-based action to an inline dropdown (SelectBox) in the toolbar that reflects the current selection.

## Best solution

Replace the `PickBrowserDevicePresetAction` QuickPick flow with an inline `SelectBox` in the emulation toolbar (in `browserEditorEmulationFeatures.ts`) that shows the current preset and reverts to a placeholder like "Select a preset..." when the user manually adjusts dimensions. The `SelectBox` import and `defaultSelectBoxStyles` are already present in the file (used for the zoom selector), so the pattern is established.
