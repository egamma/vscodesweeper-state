# Issue #335347 — Generate Commit Message shows "Sign in to use GitHub Copilot" dialog with BYOK models and utility models configured

[https://github.com/microsoft/vscode/issues/335347](https://github.com/microsoft/vscode/issues/335347)

## Summary

Traced this in the current source: the SCM sparkle button only offers the real 'Generate Commit Message' command once `ChatContextKeys.Setup.completed` is true, and that flag is only flipped by the GitHub-Copilot chat setup runner (chatSetupRunner.ts) — it never accounts for a user who has fully configured BYOK utility models and intentionally never signs in. So the button always routes through `CHAT_SETUP_SUPPORT_ANONYMOUS_ACTION_ID`, which shows the 'Sign in to use GitHub Copilot' dialog regardless of BYOK configuration.

## Change summary

Clicking the commit-message sparkle shows a GitHub sign-in dialog even when the user has fully configured BYOK models for the main agent and utility models and never intends to sign in.

## Best solution

The SCM sparkle's setup gating in src/vs/workbench/contrib/scm/browser/scmInput.ts (SetupAction, `ChatContextKeys.Setup.completed`) and the completion logic in chatSetupRunner.ts/chatSetupProviders.ts need to recognize a fully-configured BYOK setup as 'completed' so the real generateCommitMessageCommand runs directly instead of forcing the sign-in dialog.
