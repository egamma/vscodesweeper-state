# Issue #287012 — Selection decoration incorrectly drawn below custom decorations, hindering usability

[https://github.com/microsoft/vscode/issues/287012](https://github.com/microsoft/vscode/issues/287012)

## Summary

Thanks for the report. The selection appears to be drawn in a view-overlay layer beneath the view lines, so an opaque inline-decoration background covers it. This looks like long-standing layering behavior rather than a regression. No maintainer has weighed in, so this stays open as a layering/polish discussion rather than closing as designed.

## Change summary

Opaque custom text-decoration backgrounds hide the editor selection; the reporter wants the selection drawn on top.

## Best solution

A maintainer should decide whether selection should render above opaque decoration backgrounds, or whether the supported answer is for extensions to use semi-transparent colors. If layering changes, it would be in the editor view's selection overlay and decoration rendering. Otherwise document the transparency guidance for extension authors.
