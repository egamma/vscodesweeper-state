# Issue #227130 — Notebook scrolls to reveal partially hidden cell when uncommenting cells

[https://github.com/microsoft/vscode/issues/227130](https://github.com/microsoft/vscode/issues/227130)

## Summary

Still reproduces on main: when a partially-visible cell's height changes (uncomment shrinks content), the scroll anchor logic doesn't handle the partially-above-viewport case, causing an unwanted scroll-to-top.

## Change summary

Notebook scrolls to top unexpectedly when uncommenting multiple cells where the first cell is partially scrolled out of view.

## Best solution

In `notebookCellList.ts` `updateElementHeight2`, add handling for partially-visible cells above the viewport (elementTop < scrollTop but elementBottom >= scrollTop) so height changes preserve scroll position rather than falling through to the focus-anchor path.
