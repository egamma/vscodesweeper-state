# Issue #348570 — Screenshot editing: Provide blur

[https://github.com/microsoft/vscode/issues/348570](https://github.com/microsoft/vscode/issues/348570)

## Summary

The screenshot editor still lacks a blur tool; its eraser removes annotations, not captured image content. Keep this request open for a screenshot-editing product decision.

## Change summary

Add a blur tool for obscuring selected screenshot content before sharing.

## Best solution

Provide a region-based blur operation in ScreenshotAnnotationEditor that is reflected in the exported image and participates in undo/redo. Existing opaque shapes offer a workaround, but do not deliver the requested blur effect.
