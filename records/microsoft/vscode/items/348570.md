# Issue #348570 — Screenshot editing: Provide blur

[https://github.com/microsoft/vscode/issues/348570](https://github.com/microsoft/vscode/issues/348570)

## Summary

Keep open as a feature request: the built-in screenshot editor has no blur tool, and its eraser intentionally removes annotations rather than screenshot pixels.

## Change summary

Add a screenshot editing tool that blurs selected image content before sharing.

## Best solution

Consider a region-blur tool within ScreenshotAnnotationEditor, with consistent preview, undo/redo, and exported-image behavior. Existing opaque rectangles provide a masking workaround but do not deliver the requested blur effect.
