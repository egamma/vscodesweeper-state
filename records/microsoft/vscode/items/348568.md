# Issue #348568 — Screenshot editing: Provide Cancel

[https://github.com/microsoft/vscode/issues/348568](https://github.com/microsoft/vscode/issues/348568)

## Summary

Keep open: screenshot markup currently applies edits when dismissed, and its existing Cancel button only cancels cropping. Explicitly discarding an editing session with confirmation remains a genuine missing capability.

## Change summary

Provide Done and Cancel for screenshot editing, with the window close button cancelling and confirmation before discarding changes.

## Best solution

Allow users to explicitly apply or discard screenshot edits, with Cancel and window close preserving the image as it was before editing and warning before discarding changes.
