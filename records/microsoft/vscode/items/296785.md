- **Confirmed symptoms:** The discussion at https://github.com/microsoft/vscode/issues/296785 includes independent confirmations from luboi75 and EvidentlyCube: Ctrl+Tab or Enter-based file opening produces continuous spaces or newlines on Fedora 43 Wayland, across multiple keyboards. The reporter also observed it with extensions disabled and after reinstalling the OS.
- **Reporter-provided workaround:** The reporter's March 21 comment links https://discussion.fedoraproject.org/t/vscode-keeps-typing-like-the-key-has-not-been-released/183285/6, which suggests setting KDE Settings > Keyboard > Virtual Keyboard to None. The preceding forum comment reports similar repetition in Firefox and Meld, so the symptom is not confined to VS Code.
