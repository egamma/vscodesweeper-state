# Issue #330878 — How can we indicate visually that a user can type text input while in voice mode

[https://github.com/microsoft/vscode/issues/330878](https://github.com/microsoft/vscode/issues/330878)

## Summary

Keep open for a small UX decision: current voice hints explain speaking and interruption, but do not advertise that typing remains available. This team-authored Backlog item has no verified fixing commit or qualifying duplicate.

## Change summary

Make the ability to type into the chat input during voice mode visually discoverable.

## Best solution

Provide a quiet, understandable typing affordance in the voice-enabled chat composer without competing with typed text or transcripts. Agree whether this belongs in the empty-input placeholder or a separate hint before implementing it.

The affordance should explain the existing capability without suggesting that voice mode must be stopped first. Acceptance includes entering and clearing text with transcripts enabled and disabled.
