# Issue #186333 — Diff Editor - Show All/Fold Unchanged Region actions

[https://github.com/microsoft/vscode/issues/186333](https://github.com/microsoft/vscode/issues/186333)

## Summary

Keep this accepted, team-authored polish issue open: the standard diff editor still positions the reveal and refold controls differently. The compact presentation improves toggling, but does not establish completion of the requested standard-editor alignment.

## Change summary

Align the unchanged-region reveal control with the left-side refold control so users can expand and collapse without moving horizontally.

## Best solution

Give the standard diff editor's reveal and refold actions a consistent gutter position while preserving partial-reveal dragging, inline and side-by-side behavior, and the compact presentation. Keep this issue as the canonical record for that alignment work.
