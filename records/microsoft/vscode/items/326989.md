- **Behavior:**

  > A remote window whose server has no configured upstream Agent Host endpoint must not emit an unhandled error for that expected condition. The connection must settle into the maintainer-selected unavailable or retry state without a floating rejection. Genuine connection loss after a successful handshake must continue to use the existing reconnect behavior. Acceptance requires a regression test covering the unavailable channel and preserving reconnect coverage.
- **Trace:**

  > UnavailableAgentHostChannel.call('connect') in src/vs/server/node/agentHostChannel.ts creates the exact rejection, which AgentHostIpcChannelTransport.connect() in src/vs/platform/agentHost/browser/agentHostIpcChannelTransport.ts awaits. Instrument the unavailable-channel scenario before choosing the handling point. Do not blanket-swallow transport errors or weaken recovery for a previously connected remote.
