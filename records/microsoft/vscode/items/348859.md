# Issue #348859 — An empty New Session tab blocks closing its chat window with a save-or-revert error

[https://github.com/microsoft/vscode/issues/348859](https://github.com/microsoft/vscode/issues/348859)

## Summary

The reported window-close failure remains traceable on current main: native window closing checks the empty composer's move restriction and incorrectly treats it as a shutdown veto. Keep this open; closing the draft tab first remains a workaround.

## Change summary

Allow an auxiliary chat window containing an empty New Session tab to close without a move-restriction error or irrelevant save-or-revert guidance.

## Best solution

Distinguish closing a chat window from explicitly moving its unsent composers, while retaining protection for ordinary editors that cannot leave the window. Coordinate with the owner of the related open shared-host PR before starting competing work.
