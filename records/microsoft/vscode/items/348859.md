# Issue #348859 — An empty New Session tab blocks closing its chat window with a save-or-revert error

[https://github.com/microsoft/vscode/issues/348859](https://github.com/microsoft/vscode/issues/348859)

## Summary

Current source confirms that native window closing treats the empty composer as an editor transfer and vetoes it. Keep this open: closing the window should not require sending or separately closing an empty New Session tab.

## Change summary

An empty New Session tab prevents its auxiliary chat window from closing and produces irrelevant save-or-revert guidance.

## Best solution

Make native chat-window closure honor chat-owned editor disposal rather than treating those editors as transfers to the main window. Preserve transfer restrictions for unsent composers and close vetoes for ordinary editors that genuinely cannot leave.
