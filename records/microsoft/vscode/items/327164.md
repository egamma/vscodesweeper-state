# Issue #327164 — Agents session disappears after switching away from a failed session with an active fork

[https://github.com/microsoft/vscode/issues/327164](https://github.com/microsoft/vscode/issues/327164)

## Summary

Confirmed on current main: session aggregation incorrectly gives Error precedence over an actively running peer chat. Keep open and route to the agent-host multi-chat owners.

## Change summary

A failed default chat keeps the aggregate session status at Error while a fork is running, causing the filtered session to disappear after navigation.

## Best solution

Change `AgentHostStateManager._aggregateChatSummaries` to use `InputNeeded > InProgress > Error` precedence and add regression coverage for Error → InProgress → Error as a peer chat starts and completes.
