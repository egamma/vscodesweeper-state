# Issue #67711 — Reveal in sidebar by double-click breadcrumb

[https://github.com/microsoft/vscode/issues/67711](https://github.com/microsoft/vscode/issues/67711)

## Summary

Keep open as the canonical backlog request. The native breadcrumbs still lack a direct Reveal in Explorer interaction, and the request has 21 community upvotes.

## Change summary

Allow a breadcrumb file or folder to be explicitly revealed in the Explorer without enabling automatic reveal.

## Best solution

Add a deliberate breadcrumbs interaction that invokes the existing `revealInExplorer` command with the selected `FileElement` URI, while preserving normal breadcrumb navigation. Consolidate the overlapping https://github.com/microsoft/vscode/issues/224898 discussion here unless its secondary-sidebar behavior requires separate work.
