# Issue #78243 — String Settings UI: Multiple edits loses data on Save

[https://github.com/microsoft/vscode/issues/78243](https://github.com/microsoft/vscode/issues/78243)

## Summary

The reported cross-setting draft loss is addressed by the change to rerender only the setting being saved. Current source preserves the other settings' controls on this path, so this can be closed as completed.

## Change summary

Committing one string-array setting discards uncommitted entries in other settings being edited.

## Best solution

Keep the targeted setting refresh implemented in commit 316c67d8a25f2f892227bc21df0b2b7c5a98aaa0: saving one setting should leave drafts in other settings untouched, without requiring a single-setting editing restriction.
