# Issue #321412 — Agent Window session list should show icon for sessions

[https://github.com/microsoft/vscode/issues/321412](https://github.com/microsoft/vscode/issues/321412)

## Summary

The bug remains on current main: session models provide an identity icon, but the Agents Window list renderer never renders it, leaving multi-agent sessions visually indistinguishable. This team-authored Backlog bug should remain open.

## Change summary

Show each session's agent identity icon in the Agents Window session list, including sessions from non-Copilot agent hosts.

## Best solution

Render the provider-neutral session identity icon in each session row while preserving the existing status indicator, virtualization behavior, compact layouts, and selected/hover states.
