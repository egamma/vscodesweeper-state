# Issue #239255 — Visual Studio Code doesn't show translated walkthrough strings until restarting app or reloading window

[https://github.com/microsoft/vscode/issues/239255](https://github.com/microsoft/vscode/issues/239255)

## Summary

The install-time and startup localization paths still differ on current main: newly installed extension contributions can use default-language strings until reload. Keep this accepted localization bug open; no verified fixing commit or canonical duplicate was found.

## Change summary

Show newly installed extensions' translated walkthrough titles and descriptions immediately in the configured display language, without requiring a window reload.

## Best solution

Make install-time extension contribution localization consistent with the locale-aware startup scan, so walkthrough steps appear translated on first opening. Preserve default-language fallback when translations are unavailable.
