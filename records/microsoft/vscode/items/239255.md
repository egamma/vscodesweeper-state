# Issue #239255 — Visual Studio Code doesn't show translated walkthrough strings until restarting app or reloading window

[https://github.com/microsoft/vscode/issues/239255](https://github.com/microsoft/vscode/issues/239255)

## Summary

Still reproduces on main: when an extension is freshly installed, walkthrough titles/descriptions use unlocalized strings because the extension manifest's NLS translations are resolved at scan time (startup/reload) — not at dynamic registration time during install.

## Change summary

Extension walkthrough step titles and descriptions show in English until the window is reloaded, even when a language pack is active.

## Best solution

The getting started service at `src/vs/workbench/contrib/welcomeGettingStarted/browser/gettingStartedService.ts` reads `walkthrough.title` and `step.title` directly from the extension contribution without re-resolving NLS translations. The fix should ensure that when walkthroughs are dynamically registered post-install, the localized manifest (via `localizeManifest` from `src/vs/platform/extensionManagement/common/extensionNls.ts`) is used rather than the raw English strings from the unlocalized contribution point data.
