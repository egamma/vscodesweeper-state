# Issue #315712 — Hovering model picker search shows auto tool tip

[https://github.com/microsoft/vscode/issues/315712](https://github.com/microsoft/vscode/issues/315712)

## Summary

Still present on main: when the model picker opens, the Auto item is focused and its hover/tooltip is shown; hovering the search input doesn't clear that focus, so the Auto tooltip persists over the search area. No fixing commit references this issue.

## Change summary

Hovering the model picker search input incorrectly shows the Auto item's tooltip because focus remains on the Auto element.

## Best solution

In `src/vs/platform/actionWidget/browser/actionList.ts`, suppress or hide the hover panel when the filter input receives focus or mouse-enter, so that moving the mouse to the search field clears the Auto item's hover. The fix is localized to the action list widget's hover-on-focus logic.
