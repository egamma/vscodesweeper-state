# Issue #276982 — Give context into what helper is being installed or updated

[https://github.com/microsoft/vscode/issues/276982](https://github.com/microsoft/vscode/issues/276982)

## Summary

Valid and confirmed: the macOS authorization dialog shown during VS Code updates provides no context about which helper tool is being installed. Team members have acknowledged the issue and are investigating. Multiple users continue to report it.

## Change summary

On macOS, the system authorization prompt triggered by VS Code's updater says 'Code is trying to add a new helper tool' without identifying what the helper is, causing user confusion and security concerns.

## Best solution

Improve the helper tool metadata (Info.plist or SMJobBless configuration in the Electron/Squirrel updater integration) so the macOS authorization dialog provides a meaningful description of what is being installed. This likely requires changes in the build/signing pipeline (build/darwin/) or coordination with Electron's auto-updater. The team (joshspicer, deepak1556, dmitrivMS) has already started investigating.
