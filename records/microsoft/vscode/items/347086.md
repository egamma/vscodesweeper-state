# Issue #347086 — "ask in side chat", /btw, /fork all create conversations in a different window

[https://github.com/microsoft/vscode/issues/347086](https://github.com/microsoft/vscode/issues/347086)

## Summary

Keep open: new side chats and forks still enter the main-window grid instead of the originating chat window. The source confirms the routing gap, and this collaborator-authored report has no verified fix or duplicate.

## Change summary

Keep conversations created through Ask in Side Chat, /btw, and /fork in the originating chat window.

## Best solution

Make newly created side chats and forks appear in their source chat window, preserving background-send behavior when the user navigates away. Cover window ownership as well as successful conversation creation.
