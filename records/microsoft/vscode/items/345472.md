# Issue #345472 — Agents: SSH host whose first connection fails is saved anyway, and its draft ignores Enter

[https://github.com/microsoft/vscode/issues/345472](https://github.com/microsoft/vscode/issues/345472)

## Summary

Current source still persists a new SSH host before connection succeeds and silently rejects submission when its environment remains disconnected. Keep this team-authored bug open; the persistence/recovery behavior needs a maintainer decision.

## Change summary

Make failed first-time SSH connections recoverable and explain why an unreachable environment cannot send a draft.

## Best solution

Provide a readable connection failure and an actionable recovery path in the Agents environment flow, preserving unsent text. Decide whether never-connected hosts should be forgotten or retained with explicit retry, edit, and removal affordances.
