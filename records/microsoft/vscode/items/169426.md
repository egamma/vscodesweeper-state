# Issue #169426 — Inside of Jupyter Notebook cannot replace text with a multi-line text

[https://github.com/microsoft/vscode/issues/169426](https://github.com/microsoft/vscode/issues/169426)

## Summary

Still a valid open feature request — the notebook find/replace widget uses a single-line ReplaceInput that strips newlines from pasted text; no multi-line replace support has been added on main.

## Change summary

Pasting multi-line text into the notebook Find and Replace widget's replace field collapses it to a single line, losing newlines.

## Best solution

Extend the notebook find widget's replace input to support multi-line replacement text (either by switching to a multi-line input or by interpreting literal newlines from paste), similar to how the editor find widget handles `\n` in regex mode but for non-regex pastes.
