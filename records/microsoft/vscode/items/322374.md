# Issue #322374 — Allow a custom/arbitrary sort order for files in the Source Control 'Changes' list

[https://github.com/microsoft/vscode/issues/322374](https://github.com/microsoft/vscode/issues/322374)

## Summary

Custom per-file ordering remains unsupported on current main, and the related sorting requests do not own this capability. Keep this open under discussion; the lack of community traction is not grounds for an independent decline.

## Change summary

Allow user-defined or tool-defined ordering of files within Source Control resource groups.

## Best solution

Consider an opt-in ordering contract that lets extensions supply rankings while preserving existing default sorting. The SCM owner should first decide whether this belongs in the extension API, a user-controlled mode, or Git-specific order-file support.
