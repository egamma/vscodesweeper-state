# Issue #232813 — word wrap is different for left and right sides

[https://github.com/microsoft/vscode/issues/232813](https://github.com/microsoft/vscode/issues/232813)

## Summary

Still present on current main: wrapped deleted lines in the inline diff renderer lose their continuation indentation, while modified lines retain it. This is a distinct, bounded diff-editor rendering bug.

## Change summary

Inline diffs render continuation lines with different indentation on the deleted and inserted sides when word wrap is enabled.

## Best solution

Make inline deleted-line rendering honor the wrapping indentation calculated by the modified editor's line-break computer, while preserving existing diff decorations, selection mapping, and side-by-side behavior.
