# Issue #36809 — Have Shift+Tab remove whitespace within a line

[https://github.com/microsoft/vscode/issues/36809](https://github.com/microsoft/vscode/issues/36809)

## Summary

The requested inline Shift+Tab behavior remains absent on current main. This team-authored feature request has no verified duplicate or referenced implementation, so it should remain open.

## Change summary

Make Shift+Tab remove preceding inline whitespace back to the previous tab stop instead of only outdenting the line prefix.

## Best solution

Extend the editor's Shift+Tab handling for an empty selection inside a line with an inverse of `TabOperation`, while preserving leading-indent and multi-line selection behavior.
