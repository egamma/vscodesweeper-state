# Issue #257335 — The `"smart"` value for `editor.AcceptSuggestionOnEnter` should invoke auto-import actions always

[https://github.com/microsoft/vscode/issues/257335](https://github.com/microsoft/vscode/issues/257335)

## Summary

Legitimate design discussion about whether the `smart` mode of `AcceptSuggestionOnEnter` should treat lazily-resolved additionalTextEdits (auto-imports) as "making a text edit." A maintainer has engaged and identified the core question (sync vs async additional edits vs commands). Correctly labeled under-discussion.

## Change summary

When `editor.AcceptSuggestionOnEnter` is `smart`, accepting a suggestion whose text matches what's already typed (e.g. `os`) should still accept if the completion would trigger an auto-import.

## Best solution

The `makesTextEdit` check in `suggestController.ts` (lines 184–205 and 622–641) needs a design decision: either eagerly resolve completions to detect `additionalTextEdits` before judging, or treat completions with a `command` as always making a text edit. jrieken's investigation into whether Python provides imports via `additionalTextEdits` vs `command` is the key input needed.
