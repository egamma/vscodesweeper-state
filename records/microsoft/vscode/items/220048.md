# Issue #220048 — debugDescriptionSymbol should not be used for snapshots

[https://github.com/microsoft/vscode/issues/220048](https://github.com/microsoft/vscode/issues/220048)

## Summary

Snapshot serialization still directly consumes debug.description on current main, so the reported coupling remains. Keep this team-authored debt item open to resolve the maintainers' differing expectations about snapshot formatting.

## Change summary

Decouple snapshot assertions from human-facing debug.description output while retaining readable representations of values.

## Best solution

Establish a snapshot-formatting contract independent of debugger descriptions in the shared snapshot utility, preserving readable representations of URIs, ranges, and positions. Settle the compatibility expectations for existing snapshots before implementation.
