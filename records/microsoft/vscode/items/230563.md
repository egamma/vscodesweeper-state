# Issue #230563 — VSCode should support an install switch to enable/disable updates

[https://github.com/microsoft/vscode/issues/230563](https://github.com/microsoft/vscode/issues/230563)

## Summary

Valid enterprise feature request — no install-time switch for update mode exists on current main. The policy mechanism (GPO/ADMX) exists but is inaccessible in MDM-managed environments due to protected registry locations. Stays open as under-discussion.

## Change summary

Add an installer command-line switch to set the update mode at install time, enabling MDM tools like Intune to control VS Code updates without relying on GPO or protected registry keys.

## Best solution

Add an Inno Setup parameter (e.g. `/UpdateMode=none`) to `build/win32/code.iss` that writes the `update.mode` setting into the product's configuration at install time, so MDM silent-install commands can disable or control auto-updates without post-install config file manipulation or protected-registry GPO.
