# Issue #333147 — Cannot start a session from a PR from a fork

[https://github.com/microsoft/vscode/issues/333147](https://github.com/microsoft/vscode/issues/333147)

## Summary

Keep open: starting a session from a fork-origin pull request remains unsupported in current source, and a maintainer explicitly committed to adding support. The picker now excludes these pull requests and the backend rejects them, so the original spinner symptom may have changed without delivering the requested capability.

## Change summary

Support starting an agent session from a pull request whose source branch belongs to a fork, without leaving the picker waiting indefinitely.

## Best solution

Deliver fork-origin pull request session creation across the Agents Window picker and Agent Host checkout path, preserving the correct source repository, branch, and pull request association. Establish the checkout and subsequent editing behavior before treating this as a picker-only change.
