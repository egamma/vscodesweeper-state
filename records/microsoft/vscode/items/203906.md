# Issue #203906 — Webview View won't get focussed properly

[https://github.com/microsoft/vscode/issues/203906](https://github.com/microsoft/vscode/issues/203906)

## Summary

Verified duplicate of #180321 — both report that webview views don't receive proper focus when the focus command is executed, due to the webview overlay living outside the ViewPane DOM tree. #180321 is older and describes the same root cause.

## Change summary

Executing the 'Focus on [Webview View]' command does not produce a focus indication or deliver focus events to the webview.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/180321 which tracks the same root cause: WebviewViewPane.focus() transfers focus to the overlay iframe, but the ViewPane's focusTracker (trackFocus on this.element) sees a blur because the iframe lives outside the element tree. The fix likely involves wiring the webview's onDidFocus/onDidBlur events into the ViewPane's focus state.
