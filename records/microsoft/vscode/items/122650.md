# Issue #122650 — When touching the button on touch screan, The terminal pannel show new terminal with flashing drop-down menu .

[https://github.com/microsoft/vscode/issues/122650](https://github.com/microsoft/vscode/issues/122650)

## Summary

Keep open: current source allows a touch on the terminal dropdown to also execute Create New Terminal, explaining the unwanted terminal creation and menu dismissal. The existing terminal-tabs and touch/pointer labels already route this correctly.

## Change summary

Touching the terminal creation dropdown should open its menu without creating a terminal or immediately dismissing the menu.

## Best solution

Make the terminal split action's touch behavior match its mouse behavior: the dropdown opens the profile menu, while the primary button creates exactly one terminal. Preserve normal menu dismissal and keyboard navigation.
