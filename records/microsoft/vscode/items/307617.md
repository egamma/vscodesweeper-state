# Issue #307617 — Agent memory files are not reverted when restoring checkpoints or editing previous messages

[https://github.com/microsoft/vscode/issues/307617](https://github.com/microsoft/vscode/issues/307617)

## Summary

Valid request: agent memory files (stored outside the workspace editing session's checkpoint-tracked operations) are not reverted when restoring checkpoints. A team member has engaged, asking about leveraging the artifact tool — this is actively being considered.

## Change summary

Agent memory files persist through checkpoint restores, causing stale/incorrect context to poison subsequent agent interactions.

## Best solution

Integrate memory-tool writes into the checkpoint timeline (in `chatEditingCheckpointTimelineImpl.ts`) so that navigating to an earlier epoch also reverts memory file state — or expose a dedicated memory-reset mechanism tied to the checkpoint restore flow. The team member comment suggests exploring the artifact tool as a vehicle for this.
