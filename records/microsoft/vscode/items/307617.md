# Issue #307617 — Agent memory files are not reverted when restoring checkpoints or editing previous messages

[https://github.com/microsoft/vscode/issues/307617](https://github.com/microsoft/vscode/issues/307617)

## Summary

The memory/checkpoint disconnect remains in current source: memory mutations bypass the editing timeline, so restoring a checkpoint leaves those files available to subsequent prompts. Keep this open; a maintainer should settle rollback semantics for shared memory before implementation.

## Change summary

Restoring a checkpoint or rolling back an earlier message leaves agent memory created or modified during the discarded conversation active.

## Best solution

Make conversation-local memory consistent with the restored conversation boundary, including removing subsequently created files and restoring prior content. Define how rollback interacts with user- and repository-scoped memory shared across conversations, without erasing unrelated updates.
