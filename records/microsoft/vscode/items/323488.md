# Issue #323488 — Explorer context menu command target depends on selection size

[https://github.com/microsoft/vscode/issues/323488](https://github.com/microsoft/vscode/issues/323488)

## Summary

The inconsistent Explorer targeting was fixed by merged PR https://github.com/microsoft/vscode/pull/335882. Current main consistently replaces an existing selection when the context menu is opened on an unselected item, so this can be closed as completed.

## Change summary

Make Explorer context-menu commands target the clicked item whenever it is outside the existing selection, regardless of selection size or visibility.

## Best solution

Keep the behavior implemented in https://github.com/microsoft/vscode/commit/49247edb6ab458e52a9e787945f0aa4985f129d0: right-clicking an unselected Explorer item selects and targets that item, while right-clicking within the selection preserves multi-selection.
