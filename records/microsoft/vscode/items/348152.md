# Issue #348152 — Copilot SDK chat becomes read-only after changing its workspace

[https://github.com/microsoft/vscode/issues/348152](https://github.com/microsoft/vscode/issues/348152)

## Summary

Keep open: current source confirms that moving an Editor-window session into a sibling worktree can remove its list entry, dispose its active chat, and make it read-only despite a successful backend resume.

## Change summary

An active Copilot SDK chat loses messaging and approval controls after its working directory changes to a sibling worktree.

## Best solution

Preserve active chat interactivity across workspace-filter changes without requiring experimental worktree support. Keep genuine session deletion, unrelated-workspace filtering, and existing folder-switching behavior intact.
