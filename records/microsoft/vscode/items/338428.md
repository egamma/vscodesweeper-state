# Issue #338428 — Customizations: Sources button misses drop-down indicator

[https://github.com/microsoft/vscode/issues/338428](https://github.com/microsoft/vscode/issues/338428)

## Summary

Real, team-reported UI bug found while testing PR #338174: the Sources button in the Customizations discovery page is a plain secondary Button with no dropdown chevron, so it doesn't visually signal that clicking it opens a menu.

## Change summary

The 'Sources' filter button in the AI Customizations discovery page opens a dropdown menu but looks like a plain action button because it lacks a drop-down (chevron) indicator.

## Best solution

Add a dropdown chevron indicator to the source button in aiCustomizationDiscoveryPage.ts, consistent with other dropdown-triggering controls in the chat UI (e.g. the chevron-down affordance used by ActionWidgetDropdown/ChevronActionWidgetDropdown elsewhere in src/vs/workbench/contrib/chat/browser/widget/input/chatQueuePickerActionItem.ts).
