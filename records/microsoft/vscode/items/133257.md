# Issue #133257 — Adopt onDidCloseEditor context in terminal

[https://github.com/microsoft/vscode/issues/133257](https://github.com/microsoft/vscode/issues/133257)

## Summary

The terminal close handler still ignores the editor-close context on current main. An open PR implements the requested distinction, so keep this issue open pending review and merge rather than starting competing work.

## Change summary

Distinguish terminal editor moves from actual closes using the onDidCloseEditor context.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/339488, which preserves terminal tracking during editor-group moves while retaining normal close behavior; then assess this debt issue for completion.

## Evidence

- **Current source:** At main commit 7e092ca6c3cdaccb5e6bcabd0def62a8a84b6b37, src/vs/workbench/contrib/terminal/browser/terminalEditorService.ts handles onDidCloseEditor without checking e.context. It calls _removeInstance and clears the active instance even when the editor is moving.
- **Move contract:** src/vs/workbench/common/editor.ts defines EditorCloseContext.MOVE as closing caused by moving to another group. In src/vs/workbench/browser/parts/editor/editorGroupView.ts, doMoveOrCopyEditorAcrossGroups opens the editor in the target group and then closes the source with context: EditorCloseContext.MOVE.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/339488 is open and unmerged. Its inspected diff adopts EditorCloseContext.MOVE in TerminalEditorService's close handler and adds tests for preserving a moved terminal and removing a normally closed terminal. It explicitly fixes https://github.com/microsoft/vscode/issues/183268 and directly addresses this issue's requested adoption.
- **Related issue, not a canonical:** https://github.com/microsoft/vscode/issues/183268 is open, created in 2023, and reports terminal keybindings failing after editor-group moves. https://github.com/microsoft/vscode/issues/183268#issuecomment-5971059792 identifies the same context-blind handler. It is younger than this re-reviewed 2021 debt issue and reports a specific symptom rather than the same adoption request, so it does not satisfy the stronger duplicate bar.
- **Historical context:** The inspected diff of https://github.com/microsoft/vscode/commit/0f0db5773a96fa9a2fcbb832f49efa00c322291d added terminal instance removal on editor close but did not distinguish move context. https://github.com/microsoft/vscode/issues/133870 subsequently requested use of that event and was closed as a duplicate; it is not an open canonical or evidence that context adoption landed.
