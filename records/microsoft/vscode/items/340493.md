# Issue #340493 — Copilot Agent Host does not appear to respect the selected GitHub account when multiple accounts are signed in

[https://github.com/microsoft/vscode/issues/340493](https://github.com/microsoft/vscode/issues/340493)

## Summary

Keep open: current source still permits Agent Host authentication to select a different GitHub account from the configured Copilot account. The thread provides cross-platform corroboration; signing out and back in corrected one commenter's state but does not resolve the account-selection defect.

## Change summary

Make Copilot Agent Host authentication and model discovery honor the selected Copilot account when multiple GitHub accounts are signed in.

## Best solution

Copilot Agent Host should consistently use the configured Copilot account for authentication and catalog discovery, including after account-preference changes and reloads. Preserve organization policy and hidden-model filtering rather than requiring the two model-management surfaces to have identical catalogs.
