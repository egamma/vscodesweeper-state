# Issue #282806 — Support .code-workspace.local files for untracked local setting overrides

[https://github.com/microsoft/vscode/issues/282806](https://github.com/microsoft/vscode/issues/282806)

## Summary

Keep this accepted feature request open: current workspace loading does not support sibling local overrides, and an open PR explicitly targets it. The older related requests do not establish the same tracked-workspace scenario required for a duplicate close on this re-reviewed item.

## Change summary

Automatically merge an untracked .code-workspace.local file over a shared multi-root workspace configuration for per-checkout personal overrides.

## Best solution

Review https://github.com/microsoft/vscode/pull/282854 as the existing implementation candidate, settling configuration precedence, editing behavior, and the supported non-settings sections before landing. Preserve shared workspace structure while allowing personal overrides without modifying the tracked file.
