# Issue #350378 — Reconsider support for commenting on deleted lines in inline diff view

[https://github.com/microsoft/vscode/issues/350378](https://github.com/microsoft/vscode/issues/350378)

## Summary

Keep open as a renewed feature request: current source still excludes original-side comment threads in inline diffs. The earlier request closed through the community-upvote process, not because support shipped or maintainers ruled it out.

## Change summary

Support review comments on deleted lines without switching from inline to side-by-side diff view.

## Best solution

Have the comments and diff-editor owners reconsider original-side comment support within inline diffs, preserving deleted-line identity and existing side-by-side behavior. The side-by-side workaround does not satisfy the limited-screen-space use case.
