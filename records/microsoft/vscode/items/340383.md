# Issue #340383 — Allow editor font settings to be scoped by file encoding

[https://github.com/microsoft/vscode/issues/340383](https://github.com/microsoft/vscode/issues/340383)

## Summary

Fresh feature request (filed today, 0 upvotes) asking for a new configuration scoping dimension — by detected/selected file encoding — which doesn't exist anywhere in VS Code's settings model today; too new to judge traction, so keep open as a feature request.

## Change summary

Let editor.fontFamily (and presumably other editor settings) be scoped by a file's encoding (e.g. Shift-JIS) independent of its language mode.

## Best solution

If pursued, this would need a new configuration override dimension alongside language/resource overrides (src/vs/platform/configuration/common/configuration.ts's IConfigurationOverrides only supports overrideIdentifier for language and resource), which is a substantial design change — worth a maintainer design discussion before any implementation given the precedent it sets for settings scoping.
