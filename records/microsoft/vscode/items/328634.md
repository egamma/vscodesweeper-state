# Issue #328634 — Custom foreground colors for the editor affects the Debug Console

[https://github.com/microsoft/vscode/issues/328634](https://github.com/microsoft/vscode/issues/328634)

## Summary

Keep open for a themes-owner decision: Debug Console info and warning colors explicitly inherit editor diagnostic colors, so the reported coupling is present by construction rather than an accidental rendering defect. Independent console overrides work, but require the theme-specific maintenance the reporter wants to avoid.

## Change summary

Allow editor diagnostic foreground customization without changing Debug Console message colors or requiring theme-specific console overrides.

## Best solution

Have the themes owner decide whether Debug Console severity defaults should remain linked to editor diagnostic colors or become independent while retaining coherent theme defaults. Treat the reported settings-schema warning as a separate, unconfirmed symptom rather than assuming a change to color inheritance would resolve it.
