# Issue #336887 — SCM: option to hide the branch name in the Repositories view

[https://github.com/microsoft/vscode/issues/336887](https://github.com/microsoft/vscode/issues/336887)

## Summary

Reasonable, unaddressed request: current source still renders the checkout action's branch label with CSS ellipsis truncation (min-width:0, overflow hidden, text-overflow ellipsis), not the icon-only shrink @lszomoru described when declining the earlier ask, so the precedent's stated rationale doesn't fully cover this narrower 'never show the label' request.

## Change summary

Add a setting to always render the Repositories view checkout action icon-only, hiding the branch-name label instead of letting it truncate to a fragment at narrow widths.

## Best solution

A maintainer should weigh in on whether a setting (e.g. `scm.repositories.showBranchName`) is warranted given the label still truncates to an unhelpful fragment/stub in narrow sidebars, per src/vs/workbench/contrib/scm/browser/media/scm.css lines ~101-106; the author has already offered to send a PR.
