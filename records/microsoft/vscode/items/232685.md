[https://github.com/microsoft/vscode/issues/232685](https://github.com/microsoft/vscode/issues/232685)

## Summary

Keep this test-and-iteration tracking issue open: basic expandable hovers have shipped, but that does not complete the broader UI/API feedback collected here. As a process umbrella, its completion should remain with the maintainers rather than follow automatically from feature availability.

## Change summary

Evaluate TypeScript expandable hovers and iterate on their controls, expansion granularity, presentation, and API requirements.

## Best solution

Have the hover and TypeScript maintainers disposition the remaining feedback into bounded follow-ups, particularly expansion-control usability, selective expansion, and default verbosity. Keep TypeScript-generated type presentation and the separately diagnosed Next.js plugin conflict distinct from editor UI/API work.

- **Tracking scope and protection:** https://github.com/microsoft/vscode/issues/232685 explicitly asks to test the implementation and determine whether UI findings require API changes. Its on-testplan label, accumulating feedback, and linked test pass establish a process umbrella rather than a single feature-delivery task; the hard keep-open rule for process artifacts applies.
- **Existing capability checked:** extensions/typescript-language-features/src/languageFeatures/hover.ts enables verbosity requests for TypeScript API v590 and newer, constructs vscode.VerboseHover from quickinfo metadata, and initializes a fresh hover at verbosity zero. src/vs/editor/contrib/hover/browser/hoverActionIds.ts exposes editor.action.increaseHoverVerbosityLevel and editor.action.decreaseHoverVerbosityLevel. These provide whole-hover expansion, not selective token expansion or a configurable initial verbosity in this provider.
- **Shipping is not completion:** A TypeScript maintainer confirmed availability with TypeScript 5.9 at https://github.com/microsoft/vscode/issues/232685#issuecomment-3160697641. The closed test pass https://github.com/microsoft/vscode/issues/234989 requested feedback on both UI and results; completing that pass does not resolve all work collected in this umbrella.
