# Issue #319122 — Error with model azure foundry gtp. nano etc, this models send temperature to 01. 

[https://github.com/microsoft/vscode/issues/319122](https://github.com/microsoft/vscode/issues/319122)

## Summary

Verified duplicate of #323110, which is the canonical open issue tracking the hardcoded temperature=0.1 problem for BYOK Azure OpenAI models (GPT-5 family). Both report the identical 400 error from models that reject non-default temperature values.

## Change summary

BYOK Azure OpenAI requests fail with a 400 error because VS Code hardcodes temperature=0.1, which GPT-5 reasoning models reject.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/323110 — it is the better-diagnosed canonical issue tracking this exact problem. PR https://github.com/microsoft/vscode/pull/323532 (merged 2026-06-29) added `modelOptions` support as a workaround, but #323110 remains open for a complete solution (auto-detecting models that don't support custom temperature).
