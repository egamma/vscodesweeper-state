# Issue #30140 — Show suggestion details always at the bottom

[https://github.com/microsoft/vscode/issues/30140](https://github.com/microsoft/vscode/issues/30140)

## Summary

A real configuration gap remains: current main can place suggestion details below automatically, but users cannot request that placement consistently. With 26 community upvotes and a Backlog milestone, this should remain open for maintainer consideration.

## Change summary

Add an option that always places IntelliSense suggestion details below the suggestion list.

## Best solution

Decide whether to expose an `editor.suggest` placement preference in the editor suggest options, implemented by `SuggestDetailsOverlay`, while preserving adaptive placement as the default. The alternative is to improve adaptive placement under https://github.com/microsoft/vscode/issues/110069 without adding another setting.
