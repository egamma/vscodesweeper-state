# Issue #30140 — Show suggestion details always at the bottom

[https://github.com/microsoft/vscode/issues/30140](https://github.com/microsoft/vscode/issues/30140)

## Summary

Keep this accepted Backlog request open: current placement still prefers the sides, with no option to keep suggestion details below the list. Its 26 upvotes and related maintainer discussion support a placement design decision rather than a staleness close.

## Change summary

Provide an option to display suggestion documentation below the completion list instead of beside it.

## Best solution

Offer an opt-in below-list placement preference in the editor suggest widget while preserving automatic placement by default. Agree on the behavior when insufficient space exists below before implementing the preference.

  > Users want completion documentation below the suggestion list instead of beside it. The selected placement should remain consistent as users navigate suggestions and documentation changes size. Acceptance should cover ample side space, constrained vertical space, and a completion list positioned above the cursor. Existing automatic placement and keyboard access should remain unchanged unless the user opts into the new behavior.
- **Trace:**

SuggestDetailsOverlay._placeAtAnchor in suggestWidgetDetails.ts tries east, west, then a vertical fallback; content changes repeat this placement using the stored anchor and user size. editorOptions.ts exposes inline-detail visibility but no documentation-panel placement preference, and suggestController.ts provides visibility/focus commands rather than positioning controls. The unresolved boundary is whether bottom placement is mandatory or may fall back when the viewport cannot accommodate it.
- **Open decisions:**
