# Issue #186637 — Simple file dialog: support multi-select

[https://github.com/microsoft/vscode/issues/186637](https://github.com/microsoft/vscode/issues/186637)

## Summary

The core ask — multi-select support within the simple file dialog's quick pick UI — remains unimplemented. PR #300408 only fixed the 'Show Local' native-dialog fallback to return multiple URIs; the simple dialog itself still ignores `canSelectMany` and all `pickResource` call sites hardcode it to `false`.

## Change summary

The simple file dialog (remote/web quick-pick-based file browser) should support multi-selection of files and folders.

## Best solution

Implement `canSelectMany` support in `SimpleFileDialog.pickResource` (src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts) by enabling `QuickPick.canSelectMany` when the option is set, and update `abstractFileDialogService.ts` call sites to pass through the caller's `canSelectMany` instead of hardcoding `false`. The closed PR https://github.com/microsoft/vscode/pull/300163 attempted this and could inform the implementation.
