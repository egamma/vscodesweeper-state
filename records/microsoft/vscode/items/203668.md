# Issue #203668 — command actions (copy, paste, etc.) do no work on macOS

[https://github.com/microsoft/vscode/issues/203668](https://github.com/microsoft/vscode/issues/203668)

## Summary

Verified duplicate of #129178 — the same root cause (Cmd+C/V/A not working inside iframe-based webview content on macOS/Electron due to key-event forwarding and `execCommand` round-trip) is already tracked there with a repro extension, `help wanted`, and a `Backlog` milestone.

## Change summary

Cmd+C, Cmd+V, Cmd+A (copy, paste, select-all) keyboard shortcuts do not work inside contenteditable areas within webview iframes on macOS.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/129178, which already owns this work with a clean repro and the `help wanted` label. The fix likely lives in the webview keyboard-event round-trip (pre/index.html ↔ webviewElement.ts) where on Electron+macOS, `preventDefault()` blocks the native clipboard action but the re-dispatched `execCommand` doesn't reach the inner iframe's contenteditable context.
