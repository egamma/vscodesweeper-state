## Summary

This is the plugin-import manifestation of the same-name MCP source-collision problem already tracked by the older open canonical issue. That issue explicitly owns hierarchical collision priority and preserving every distinct server source.

## Change summary

Importing a plugin alongside workspace MCP configuration causes colliding MCP servers to resolve to the nearest source instead of retaining all configured sources with hierarchical enablement.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/327167 and implement its source-aware collision model: preserve each raw MCP server identity, expose its provenance, and disable lower-priority same-name copies rather than dropping them.
