# Issue #336423 — `"window.density.layout": "compact"` does not make horizontal window spacing compact in modern UI

[https://github.com/microsoft/vscode/issues/336423](https://github.com/microsoft/vscode/issues/336423)

## Summary

Traced in source: the Modern UI's floating-panel perimeter gutter (4px) is intentionally kept identical between default and compact density — compact only removes the gap *between* cards, not the outer gutter against window chrome. This is documented, deliberate current behavior, but the ask (let compact also shrink the outer perimeter, or make it configurable) is a reasonable design request for a still-experimental, actively-iterated feature, filed same-day with no maintainer verdict yet.

## Change summary

`window.density.layout: compact` removes gaps between Modern UI floating panels but not the fixed outer perimeter margin against the window edge, so users lose horizontal editor space versus the classic UI.

## Best solution

A maintainer decision is needed: either confirm the perimeter gutter is by design (in which case this closes as *as-designed once stated), or extend `window.density.layout: compact` to also collapse `COMPACT_FLOATING_PANEL_OUTER_MARGIN` (currently hardcoded to 4px in src/vs/workbench/services/layout/browser/layoutService.ts) so power users on tight/high-DPI layouts don't lose a character column. Given Modern UI is still experimental (`workbench.experimental.modernUI`), this belongs with the broader interface-evolution feedback thread.
