# Issue #336423 — `"window.density.layout": "compact"` does not make horizontal window spacing compact in modern UI

[https://github.com/microsoft/vscode/issues/336423](https://github.com/microsoft/vscode/issues/336423)

## Summary

Confirmed in source that the modern UI's compact density intentionally leaves the window-edge gutter unchanged and only tightens the gap between floating cards — a deliberate design choice, not a bug — but it's an open design question (raised as feedback on the still-experimental modern UI) rather than a settled maintainer decision, so it should stay open for design input.

## Change summary

With `workbench.experimental.modernUI` enabled, `window.density.layout: compact` doesn't shrink the outer window-edge margins, only the gaps between floating panels, costing usable horizontal editor width versus the classic UI.

## Best solution

A maintainer on the modern UI workstream should decide whether compact density should also reduce `--modern-ui-floating-card-outer-margin` (the window-chrome gutter), or whether the current perimeter-is-constant behavior is intentional and final; either way this belongs in the ongoing modernUI/floatingPanels design work, not as an isolated fix.
