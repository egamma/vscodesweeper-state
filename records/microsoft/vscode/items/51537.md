# Issue #51537 — Emmet too active in files such as JSX, TSX, and PHP 

[https://github.com/microsoft/vscode/issues/51537](https://github.com/microsoft/vscode/issues/51537)

## Summary

Still reproduces on main: the `isValidLocationForEmmetAbbreviation` function uses character-level heuristics (backtracking for `<`/`>`) rather than AST-based parsing, so it cannot distinguish JS expression contexts from markup positions in JSX/TSX/PHP. The `emmet-parse` label correctly tracks this known limitation.

## Change summary

Emmet completions appear incorrectly inside JavaScript expression contexts (e.g. array indexing) in JSX/TSX/PHP files because the extension lacks proper file parsing.

## Best solution

Implement proper AST-aware context detection in `extensions/emmet/src/abbreviationActions.ts` — likely by consuming the TypeScript/JSX syntax tree (via a language service or embedded parser) to determine whether the cursor is in a markup region vs. a JS expression, so Emmet only activates in markup positions.
