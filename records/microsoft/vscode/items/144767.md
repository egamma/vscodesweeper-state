# Issue #144767 — [scss] variables in @media parsing

[https://github.com/microsoft/vscode/issues/144767](https://github.com/microsoft/vscode/issues/144767)

## Summary

The SCSS parser on current main still rejects interpolation in a media-query condition after `and`; this is a real parser gap, not a TextMate grammar or Atom dependency issue.

## Change summary

Allow SCSS interpolation such as `#{breakpoint(medium)}` as a media-query condition without reporting `css-lparentexpected`.

## Best solution

Update the SCSS parser's media-query condition handling in the bundled CSS language service so interpolation is accepted wherever SCSS permits it, with parser tests covering the reported chained `and` form.
