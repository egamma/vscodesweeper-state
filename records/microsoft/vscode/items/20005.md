# Issue #20005 — Suggestion - Add a line-spacing or line-margin option

[https://github.com/microsoft/vscode/issues/20005](https://github.com/microsoft/vscode/issues/20005)

## Summary

This remains a valid Backlog feature request with 34 community upvotes. Current settings cannot add inter-line spacing independently from cursor, highlight, and line-box height.

## Change summary

Add configurable spacing between editor lines without enlarging the cursor and current-line highlight.

## Best solution

Add an editor spacing option independent of `editor.lineHeight`, or separately size and center the cursor and line highlight within taller line boxes while preserving current defaults.
