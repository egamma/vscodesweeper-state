# Issue #41320 — [xml] add on enter rules

[https://github.com/microsoft/vscode/issues/41320](https://github.com/microsoft/vscode/issues/41320)

## Summary

The requested capability remains absent on current main: built-in HTML support defines on-enter and indentation rules, while built-in XML support does not. No older open issue was found that reports the same observable XML indentation request, so this re-reviewed Backlog item should remain open and be classified as under discussion.

## Change summary

Add XML-aware on-enter rules so pressing Enter within or after an XML element applies structural indentation comparable to HTML editing.

## Best solution

Add XML-specific `onEnterRules` and `indentationRules` to the built-in XML language configuration, using XML semantics rather than copying HTML's void-element exclusions. Keep automatic tag completion and matching-tag highlighting outside this narrowly titled request unless maintainers deliberately expand its scope.

## Plan brief

- **Likely files:** `extensions/xml/xml.language-configuration.json`, `src/vs/editor/test/common/modes/supports/onEnter.test.ts`
- **Validation:** Add a focused XML on-enter test using the editor's OnEnterSupport harness, covering paired elements, an unmatched opening element, self-closing elements, comments, and XML element names that overlap HTML void-element names; run it with `scripts/test.sh --grep "XML on-enter rules"`.
- **Behavior:**

  > In an XML document, pressing Enter between matching opening and closing elements indents the new line and keeps the closing element outdented. Pressing Enter after a non-self-closing opening element increases indentation, while self-closing elements do not. XML element names remain governed by XML syntax rather than HTML's predefined void-element list. Existing quote, bracket, comment, folding, and word-boundary behavior remains unchanged.
- **Trace:**

  > `extensions/xml/xml.language-configuration.json` is registered for the built-in `xml` language by `extensions/xml/package.json`, but currently has no `onEnterRules` or `indentationRules`. The analogous definitions are present in `extensions/html/language-configuration.json`; however, those expressions exclude HTML void-element names, which are not intrinsically void in XML. Commit ce7f99fa960286b42dc6823045f10c044edbb16f and https://github.com/microsoft/vscode/pull/77751 previously aligned other XML and HTML configuration features but did not cover enter behavior. Keep the change within basic XML indentation support; do not add tag completion, tag renaming, matching-tag highlighting, formatter behavior, or language-server functionality.
- **Open decisions:**
  - Should XML on-enter behavior treat every syntactically non-self-closing element uniformly, including names such as `<br>` and `<input>`, rather than preserving HTML's void-element exclusions?
