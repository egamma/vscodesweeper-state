## Summary

The report describes a concrete CRLF-specific rendering discrepancy, but current-source inspection does not establish whether the extra arrows persist. Request confirmation on the latest build rather than proposing a completed or duplicate close.

## Change summary

The rich Markdown editor displays excess line-ending arrows between headings in CRLF files compared with equivalent LF files.

## Best solution

Equivalent CRLF and LF Markdown should display the same number of logical line-ending markers while preserving the document's original line endings. Confirm the current behavior first, then isolate marker generation in the rich Markdown renderer rather than treating conversion to LF as the fix.
