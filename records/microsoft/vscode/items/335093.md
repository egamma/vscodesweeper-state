# Issue #335093 — Markdown editor renders three line-ending arrows for CRLF files

[https://github.com/microsoft/vscode/issues/335093](https://github.com/microsoft/vscode/issues/335093)

## Summary

The adopted Markdown editor dependency still counts CR and LF separately when rendering inter-block line-ending arrows, explaining the reported three-arrow result. Keep this open for an upstream rendering correction; the supplied heading sample and CRLF/LF comparison suffice to retest.

## Change summary

Render the same number of logical line-ending arrows between Markdown headings for CRLF and LF documents.

## Best solution

Correct whitespace segmentation in @vscode/markdown-editor so a CRLF pair represents one logical line ending while preserving source offsets and existing structural-break behavior. Adopt the correction in VS Code and verify the reporter's three-heading sample with both line-ending formats.
