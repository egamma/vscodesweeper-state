# Issue #277928 — Adopt chatSessions/newSession for copilot-cloud-agent

[https://github.com/microsoft/vscode/issues/277928](https://github.com/microsoft/vscode/issues/277928)

## Summary

Keep open: the menu contribution point still exists, but Copilot Cloud does not contribute a session-creation command to it. Subsequent session-lifecycle design work warrants checking the migration against the current creation flow before implementation.

## Change summary

Move Copilot Cloud session creation from automatically generated workbench behavior to provider-contributed commands through chatSessions/newSession.

## Best solution

Give Copilot Cloud ownership of session creation while preserving the existing new-session entry points, ordering, delegation, and initial-prompt behavior. Reconcile this migration with the newer controller-based creation design rather than adding a parallel or duplicate creation path.
