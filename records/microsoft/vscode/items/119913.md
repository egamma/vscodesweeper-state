# Issue #119913 — Custom file save dialog keyboard shortcuts inconsistent with macOS

[https://github.com/microsoft/vscode/issues/119913](https://github.com/microsoft/vscode/issues/119913)

## Summary

The custom dialog still does not implement the macOS keyboard-navigation distinction discussed by maintainers: it initially focuses Save, so both Enter and Space activate Save. The issue should remain open while the team decides whether custom dialogs should mirror macOS Keyboard Navigation unconditionally or only when the OS option is enabled.

## Change summary

Make custom save dialogs on macOS distinguish the default Save action from the keyboard-focused secondary action, so Enter and Space need not activate the same button.

## Best solution

Define the intended macOS contract for custom dialogs—particularly whether it depends on the system Keyboard Navigation preference—then make initial focus and Enter/Space activation follow that contract without changing other platforms.

Escape and Cmd+D behavior, input-field submission, and non-macOS dialogs must remain unchanged.
