# Issue #119913 — Custom file save dialog keyboard shortcuts inconsistent with macOS

[https://github.com/microsoft/vscode/issues/119913](https://github.com/microsoft/vscode/issues/119913)

## Summary

Still relevant on main: the custom dialog focuses the default button (index 0) on all platforms, so Space and Enter both trigger Save. The macOS-native behavior (Space triggers focused non-default button, Enter triggers default) is not replicated. The Cmd+D shortcut was added as a partial workaround for 'Don't Save' but the original keyboard navigation inconsistency remains.

## Change summary

VS Code's custom save dialog on macOS doesn't match native macOS keyboard behavior where Space triggers the focused button and Enter triggers the default button.

## Best solution

On macOS, when the system 'keyboard navigation' accessibility setting is enabled, the custom dialog should focus the secondary action button (like 'Don't Save') and differentiate Enter (always triggers default/primary) from Space (triggers currently focused button). The fix belongs in `src/vs/base/browser/ui/dialog/dialog.ts` in the initial focus logic and key handling. The Cmd+D addition (commit 20899216df0) partially addresses the UX but doesn't match native macOS semantics.
