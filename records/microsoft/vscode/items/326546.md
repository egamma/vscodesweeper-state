Keep open for Windows accessibility investigation: the report supplies sufficient steps and IA2 diagnostics to retest without requesting more information. Current source still uses Electron's native dialog path, but source inspection cannot establish whether the reported accessibility failure persists on today's runtime.

## Change summary

NVDA loses usable accessibility information after a native Open File or Open Folder dialog is accepted or canceled.

## Best solution

Restore reliable NVDA reading after native file dialogs, first reproducing on Windows and determining whether accessibility objects become invalid in VS Code's integration, Electron/Chromium, or NVDA. Preserve the reported UIA workaround as diagnostic evidence, not as a substitute for resolving the default IA2 failure.
