# Issue #230297 — Editor: cannot Ctrl+click to goto definition in a link with a method name included

[https://github.com/microsoft/vscode/issues/230297](https://github.com/microsoft/vscode/issues/230297)

## Summary

The supplied JavaScript reproduction exhibits the same observable editor bug already tracked by the older, open canonical issue: one Ctrl+click both opens a link and navigates to a definition. Consolidate there while preserving this minimal template-interpolation example.

## Change summary

Ctrl+clicking a method call inside a URL template literal opens the URL instead of exclusively navigating to the method definition.

## Best solution

Resolve competing link and definition navigation under https://github.com/microsoft/vscode/issues/81520, retaining this report's JavaScript example as an acceptance case: clicking foobar inside the interpolation should navigate to its definition without opening a browser.
