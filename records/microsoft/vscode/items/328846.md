# Issue #328846 — Special characters improperly escaped in question titles

[https://github.com/microsoft/vscode/issues/328846](https://github.com/microsoft/vscode/issues/328846)

## Summary

The defect remains source-reproducible on current main: plain question titles are passed through the Markdown renderer, so Markdown-special characters and their escapes are interpreted instead of displayed literally.

## Change summary

Question-card titles containing Markdown-special characters render with incorrect escaping while the full question text renders correctly.

## Best solution

Preserve plain-string question titles as literal text while retaining Markdown rendering for values explicitly supplied as Markdown, with regression coverage for escaped and unescaped special characters.
