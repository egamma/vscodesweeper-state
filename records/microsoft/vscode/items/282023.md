# Issue #282023 — Use context keys to hide 'Cloud agent' if workspace doesn't have GH remote

[https://github.com/microsoft/vscode/issues/282023](https://github.com/microsoft/vscode/issues/282023)

## Summary

Keep open for a visibility decision: the existing setting hides Cloud Agent manually, but does not implement workspace-dependent hiding. Current repository-selection support also means that lacking a local GitHub remote does not always make Cloud Agent unusable.

## Change summary

Make Cloud Agent visibility reflect whether the workspace has a usable GitHub remote rather than exposing an action that can fail when invoked.

## Best solution

Define visibility separately for workspace-bound delegation and cloud sessions that can select another repository. Resolve the thread's hide-versus-discoverability decision without removing valid repository-picker workflows or the existing manual disable setting.
