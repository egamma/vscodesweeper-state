# Issue #90005 — Allow to reveal an empty TreeView programmatically

[https://github.com/microsoft/vscode/issues/90005](https://github.com/microsoft/vscode/issues/90005)

## Summary

Valid backlog feature request with 40 upvotes. The proposed API change (allowing `element: T | undefined` in `TreeView.reveal`) exists in `vscode.proposed.treeViewReveal.d.ts` but has not been finalized into the stable API — the gap remains real.

## Change summary

Allow programmatically revealing/showing a TreeView even when there is no element to select, e.g. to make an empty tree visible.

## Best solution

Finalize the proposed `treeViewReveal` API (currently in `src/vscode-dts/vscode.proposed.treeViewReveal.d.ts`) that allows `element: T | undefined` in `TreeView.reveal`. The discussion also suggests adding a dedicated `show(preserveFocus?)` method for parity with `WebviewView`, which may be the cleaner long-term API — a maintainer decision is needed on which shape to finalize.
