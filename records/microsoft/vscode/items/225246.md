# Issue #225246 — CSHTML Razor syntax highlighting suboptimal

[https://github.com/microsoft/vscode/issues/225246](https://github.com/microsoft/vscode/issues/225246)

## Summary

The Razor/CSHTML TextMate grammar doesn't tokenize Razor expressions inside embedded JavaScript strings, leading to visually flat highlighting compared to Visual Studio. The grammar is sourced upstream from dotnet/roslyn; improvements likely need to happen there or via injection patches in VS Code's built-in razor extension. Still a valid gap — keeping open.

## Change summary

Razor `@` expressions inside JavaScript string contexts in `.cshtml` files are not syntax-highlighted, making Razor code harder to read compared to Visual Studio.

## Best solution

Improve the Razor TextMate grammar (sourced from `dotnet/roslyn`) to handle Razor expressions inside embedded JS string literals — either upstream or via a local injection patch in `extensions/razor/`. RedCMD's comment identifies the needed injection scope. A maintainer should coordinate with the dotnet/razor team or add a grammar injection in `extensions/razor/syntaxes/`.
