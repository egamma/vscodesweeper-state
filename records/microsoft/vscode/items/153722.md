# Issue #153722 — Provide speech feedback when commenting or uncommenting a line.

[https://github.com/microsoft/vscode/issues/153722](https://github.com/microsoft/vscode/issues/153722)

## Summary

Keep open: the comment actions still have no explicit speech feedback, and the discussion supports reading the resulting line content. Existing accessibility settings do not cover that action-specific feedback; no verified older canonical issue was found.

## Change summary

Automatically read the resulting line after the user comments or uncomments it, without requiring a separate screen-reader read-line command.

## Best solution

Provide concise screen-reader feedback for successful single-line comment changes in the editor comment actions, following the thread's preference for the resulting line content. Treat passive audio cues for navigating multiline comments as a separate accessibility design question.
