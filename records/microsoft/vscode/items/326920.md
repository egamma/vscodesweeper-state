# Issue #326920 — Terminal suggest spawns runaway bash processes when npm/yarn package.json lookup reaches /

[https://github.com/microsoft/vscode/issues/326920](https://github.com/microsoft/vscode/issues/326920)

## Summary

Confirmed on current main: the npm/yarn package.json root-check has a broken string literal (`' / '` instead of `'/'`), so the until-loop never terminates once $PWD reaches `/`, spawning runaway bash processes. Small, clearly localized, and independently reproduced by a second reporter — this belongs in route-to-area/terminal for a quick fix rather than staying purely info-gathering.

## Change summary

Terminal suggest's npm/yarn 'no package.json found' bash lookup loops forever at the filesystem root instead of stopping, spawning runaway CPU-consuming bash processes.

## Best solution

Fix the two broken string literals in extensions/terminal-suggest/src/completions/npm.ts:214 and yarn.ts:144, changing `[[ $PWD = ' / ' ]]` back to `[[ $PWD = '/' ]]` (matching the already-correct pattern at yarn.ts:395 and npx.ts:16); separately consider killing the child process on the existing execution timeout so future bugs of this class don't accumulate zombie processes.
