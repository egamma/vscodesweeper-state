# Issue #326920 — Terminal suggest spawns runaway bash processes when npm/yarn package.json lookup reaches /

[https://github.com/microsoft/vscode/issues/326920](https://github.com/microsoft/vscode/issues/326920)

## Summary

Confirmed on current main: both npm and yarn completion generators contain a malformed root comparison that loops forever at `/`. This is a small, localized terminal-suggest regression that should remain open for a fix.

## Change summary

Correct npm and yarn package.json discovery so it terminates at the filesystem root instead of spawning runaway bash processes.

## Best solution

Restore the root check to `[[ $PWD = '/' ]]` in both completion generators and add a regression test covering their generated commands.
