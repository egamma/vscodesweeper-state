# Issue #254879 — Multiple edits to the same file should just be rendered as one

[https://github.com/microsoft/vscode/issues/254879](https://github.com/microsoft/vscode/issues/254879)

## Summary

Current chat rendering partially addresses this with collapsed tool groups and file-aware summaries, but still retains separate edit entries when expanded. Keep this accepted Backlog request open to resolve whether same-file edits should become one combined diff while preserving access to individual operations.

## Change summary

Render multiple chat edits to the same file as one consolidated file-edit presentation.

## Best solution

Agree on a same-file aggregation boundary in the chat transcript, retaining access to individual diffs as requested by the maintainer. Extend the existing grouping presentation only where its summaries do not already meet that agreed behavior.
