# Issue #17963 — Expose -webkit-text-stroke (Fonts are too thin on Ubuntu 16.10)

[https://github.com/microsoft/vscode/issues/17963](https://github.com/microsoft/vscode/issues/17963)

## Summary

VS Code already exposes the standard `editor.fontWeight` setting for making editor text heavier, including numeric weights; a Chromium-specific text-stroke setting is unnecessary.

## Change summary

Expose CSS text stroke or another emboldening control for thin editor fonts on Linux.

## Best solution

Use `editor.fontWeight` with an installed heavier or variable font weight, rather than adding a nonstandard `-webkit-text-stroke` rendering option.

## Vision fit

- **Fit:** rejected
- **Reason:** A browser-specific visual toggle duplicates the existing standard font-weight control and adds configuration complexity.
- **Evidence:** Values and guardrails favor a simple, uniform UI over per-feature visual customization.

- **Proposed comment:**

  > Thanks for the request. Editor text weight is supported through `editor.fontWeight`, which accepts `normal`, `bold`, or numeric values from 1 through 1000—for example, `"editor.fontWeight": 500` when the selected font provides that weight. VS Code uses this standard font mechanism rather than exposing Chromium-specific `-webkit-text-stroke`, so this can be closed as designed.
