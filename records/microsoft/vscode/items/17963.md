# Issue #17963 — Expose -webkit-text-stroke (Fonts are too thin on Ubuntu 16.10)

[https://github.com/microsoft/vscode/issues/17963](https://github.com/microsoft/vscode/issues/17963)

## Summary

Keep open: existing font-weight controls provide a partial workaround, but do not expose the requested stroke/shadow emboldening or its workbench-wide scope on Linux. No fixing commit or verified canonical duplicate was found, and the Backlog assignment rules out declining the accepted request on design preference alone.

## Change summary

Provide supported text emboldening controls to improve the readability of thin Linux fonts, including stroke or shadow rendering.

## Best solution

Have the font-rendering owners determine whether a supported emboldening control offers a meaningful benefit beyond editor.fontWeight on current Linux systems, with editor versus workbench scope explicitly settled. Preserve existing defaults and consistent typography rather than introducing unrestricted user CSS.
