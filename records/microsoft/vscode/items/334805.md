# Issue #334805 — Tool call's `explanation` is misleading due to truncated arguments

[https://github.com/microsoft/vscode/issues/334805](https://github.com/microsoft/vscode/issues/334805)

## Summary

Confirmed on current main: long tool arguments are serialized and then cut at a fixed character boundary, so destination fields appearing after a long comment body can be omitted and produce a misleading permission explanation.

## Change summary

Keep destination and other action-defining tool arguments available to the risk assessor when individual argument values are long.

## Best solution

Preserve a bounded prompt while ensuring every argument key and action-defining value, such as the repository and issue number, reaches the risk model; long payload values should consume only their own bounded allocation.
