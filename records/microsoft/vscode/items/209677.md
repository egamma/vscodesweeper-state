# Issue #209677 — Inline editing of debug variables

[https://github.com/microsoft/vscode/issues/209677](https://github.com/microsoft/vscode/issues/209677)

## Summary

The requested in-editor variable editing remains missing: inline values display results, while existing Set Value actions live in the Variables and Watch views. Keep this team-authored Backlog request open for an editor-debugging UX decision; no verified canonical or fixing commit was found.

## Change summary

Allow editing a paused debug variable from the editor through a value-prefilled overlay opened from a debug hover or inline value.

## Best solution

Provide an editor-local editing experience that respects debug-adapter capabilities and read-only variables, without requiring a trip to the REPL or sidebar. First settle whether the initial experience includes both hover actions and clickable inline values, or starts with one.
