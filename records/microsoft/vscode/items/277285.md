# Issue #277285 — Bad syntax highlighting for md file with single $ 

[https://github.com/microsoft/vscode/issues/277285](https://github.com/microsoft/vscode/issues/277285)

## Summary

Still reproduces on main — the single-dollar math block grammar in the markdown-math extension incorrectly starts a math block for `$ b` (dollar-space-text). An open PR (#308694) is in progress to fix it; keeping open until it lands.

## Change summary

A lone `$` followed by a space on its own line in a markdown file incorrectly triggers math-block syntax highlighting for all subsequent content until a closing `$` is found.

## Best solution

Land the open fix PR (https://github.com/microsoft/vscode/pull/308694) which tightens the `single_dollar_math_block` begin regex in `extensions/markdown-math/syntaxes/md-math-block.tmLanguage.json` to prevent `$ ` (dollar-space) from starting a math block.

## Evidence

- **source trace:** In `extensions/markdown-math/syntaxes/md-math-block.tmLanguage.json`, the `single_dollar_math_block` begin pattern `(?<=^\s*)(\$)(?![^$]*\$|\d)` matches `$ b` because after the `$` there is no closing `$` on the same line and the next character is a space (not a digit), so the block opens and consumes everything until a closing `$` is found.
- **no fix on main:** git log shows no commit referencing #277285 or modifying the single-dollar block regex on current main; the bug persists.
- **open fix PR:** https://github.com/microsoft/vscode/pull/308694 is open and targets this issue by preventing a single `$` with trailing space from starting a math block.
