# Issue #277285 — Bad syntax highlighting for md file with single $ 

[https://github.com/microsoft/vscode/issues/277285](https://github.com/microsoft/vscode/issues/277285)

## Summary

The reported highlighting leak remains in current main. The linked fix attempt was closed without merging because it would remove supported multiline math behavior, so this needs a compatibility-aware solution rather than closure.

## Change summary

A line containing `$ b` incorrectly starts math highlighting that consumes the following Markdown heading.

## Best solution

Prevent unmatched dollar-prefixed prose from consuming subsequent Markdown while preserving supported single-dollar multiline math. Settle the delimiter compatibility contract before revisiting the built-in Markdown math grammar.

- **Trace:**
