# Issue #70136 — Git - Pull and Sync  fails when name of tracking branch differs from name of tracked branch on remote

[https://github.com/microsoft/vscode/issues/70136](https://github.com/microsoft/vscode/issues/70136)

## Summary

The reported Pull and Sync failure is addressed by a landed change that reads the actual remote branch reference instead of deriving it from the local tracking name. Current source passes path/to/foo, rather than foo, for the reporter's configuration.

## Change summary

Git Pull and Sync fail when a custom fetch refspec maps remote path/to/foo to local tracking ref upstream/foo.

## Best solution

Close as completed by commit cb1851d2dc7bae1c7ea017c57453bf65060ce39d, retaining the current remote-reference decoding for Pull and Sync. Separate history-display problems with unusual ref mappings should not be conflated with this resolved remote-ref error.
