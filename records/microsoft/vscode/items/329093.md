# Issue #329093 — submit feedback not works when open multiple chats in the session

[https://github.com/microsoft/vscode/issues/329093](https://github.com/microsoft/vscode/issues/329093)

## Summary

Keep open: current source contains a session-versus-chat identity mismatch that can prevent editor feedback submission when a secondary chat is displayed. No verified canonical or fixing commit establishes that this team-authored report is resolved.

## Change summary

Editor feedback cannot be submitted reliably in an Agents Window session containing multiple chats.

## Best solution

Make editor feedback submission resolve an appropriate conversation independently of its session-scoped storage identity. Establish which conversation receives feedback when multiple chats are available, then cover secondary-chat submission without changing feedback ownership or queued-request semantics.

  > In an Agents Window session with multiple chats, adding editor feedback and invoking Submit must not fail solely because the displayed chat has a different resource from the owning session. Verify a secondary chat with no main-chat widget loaded, multiple visible conversations, and unchanged single-chat and queued-submission behavior.
- **Trace:**

  > SubmitFeedbackAction.runWithSession in src/vs/sessions/contrib/agentFeedback/browser/agentFeedbackEditorActions.ts passes only the feedback session resource. AgentFeedbackService.submitFeedback defaults its widget lookup to that resource, while ChatView.setChat in src/vs/sessions/contrib/chat/browser/chatView.ts loads the individual chat resource and ChatWidgetService uses exact model-resource equality. This conclusively exposes a timeout/false path when only a secondary chat is loaded. The service already supports an explicit targetChat, and its tests establish that destination and feedback storage can differ. Preserve session-scoped feedback ownership, explicit targetChat behavior, plan-review submission, and request-acceptance/queue semantics. The unresolved boundary is which conversation editor-originated feedback should target when several chats share a session; the report does not settle that public behavior.
- **Open decisions:**
