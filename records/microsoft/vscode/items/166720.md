# Issue #166720 — Continue Working On should surface working changes with slight differences in edit session state

[https://github.com/microsoft/vscode/issues/166720](https://github.com/microsoft/vscode/issues/166720)

## Summary

A real gap remains: partial matches trigger the requested recovery prompt only behind an experimental setting that is disabled by default. The issue should remain open to track safely graduating that behavior.

## Change summary

Surface stored working changes when the destination workspace has a slightly different branch state.

## Best solution

Validate the partial-match safety model, then enable the existing prompt by default and graduate `workbench.experimental.cloudChanges.partialMatches.enabled` in the Continue Working On implementation.
