# Issue #289362 — Don't delete files when copying/moving into an existing folder

[https://github.com/microsoft/vscode/issues/289362](https://github.com/microsoft/vscode/issues/289362)

## Summary

Verified duplicate: the older open canonical issue tracks the same Explorer behavior where moving or copying into an existing folder replaces it and deletes destination-only files instead of merging the contents.

## Change summary

Preserve destination-only files when copying or moving a folder onto an existing folder, with conflict handling for files present in both.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/165706 and implement consistent merge-versus-replace behavior there across drag-and-drop and keyboard copy/paste, including when `explorer.incrementalNaming` is disabled.
