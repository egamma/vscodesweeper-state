# Issue #310037 — Agents: The run button's behavior is a little unpredictable

[https://github.com/microsoft/vscode/issues/310037](https://github.com/microsoft/vscode/issues/310037)

## Summary

The requested predictability improvement remains necessary on current main: the primary Run button chooses the pinned task or the first configured task without excluding worktree-creation tasks or considering the most recently run task. This team-authored Backlog item should remain open.

## Change summary

Make the Agents Window primary Run button prefer an ordinary run task over a worktree-initialization task and otherwise repeat the most recently run ordinary task.

## Best solution

Choose the primary task deterministically: when ordinary and worktree-creation tasks are mixed, do not rerun the initialization task; among multiple ordinary tasks, use the most recently run task, retaining the current deterministic fallback when no run history exists.
