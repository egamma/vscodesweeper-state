# Issue #327954 — UI Suggestions for sticky prompt

[https://github.com/microsoft/vscode/issues/327954](https://github.com/microsoft/vscode/issues/327954)

## Summary

Keep open as active chat UX polish. The team-authored proposal still contains meaningful gaps on current main, and the maintainer discussion has not settled the behavior for long prompts or the preferred sticky-scroll experiment.

## Change summary

Refine the sticky chat prompt's width, attachment styling, activation threshold, content transition, and navigation controls.

## Best solution

Use the sticky-scroll experiment to settle one coherent interaction: retain the current one-line prompt preview, visually connect it to its source bubble, delay pinning until the source prompt has passed, and consolidate prompt navigation without duplicating persistent chrome. Apply the resulting design consistently to the custom prompt timeline and tree-based sticky-scroll paths.
