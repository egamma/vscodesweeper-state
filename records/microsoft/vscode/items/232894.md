# Issue #232894 — VS Code Insiders (zipped) ignoring Portable Mode

[https://github.com/microsoft/vscode/issues/232894](https://github.com/microsoft/vscode/issues/232894)

## Summary

This is a duplicate of #279329 — portable mode broken on Windows Insiders due to the versioned folder layout. Fixed by commit aeeddb2b259 (PR #279510) and verified/released.

## Change summary

VS Code Insiders zip on Windows ignored the `data` folder for portable mode because the versioned folder layout added an extra directory level that the portable path resolution didn't account for.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/279329 which tracked and resolved this exact bug. The fix shipped in Insiders and is verified.
