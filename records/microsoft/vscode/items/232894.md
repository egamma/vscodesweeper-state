# Issue #232894 — VS Code Insiders (zipped) ignoring Portable Mode

[https://github.com/microsoft/vscode/issues/232894](https://github.com/microsoft/vscode/issues/232894)

## Summary

Keep open: the reporter followed the documented Windows ZIP portable setup and supplied steps sufficient to retest. Startup layout handling has changed since the affected 1.96 Insiders build, but source inspection does not establish whether the reported writes outside the portable directory have stopped.

## Change summary

Launching Windows ZIP Insiders with data and data/tmp folders reportedly creates extension-related files in the user profile instead of keeping them within the portable installation.

## Best solution

Reproduce the documented ZIP setup on Windows and identify which process creates the non-portable extension files. Preserve portable storage for VS Code-owned state; distinguish a core detection failure from any Remote-WSL-owned writes before choosing the fix boundary.
