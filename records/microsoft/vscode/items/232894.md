# Issue #232894 — VS Code Insiders (zipped) ignoring Portable Mode

[https://github.com/microsoft/vscode/issues/232894](https://github.com/microsoft/vscode/issues/232894)

## Summary

Fixed on main: commit aeeddb2b259 corrected the portable-mode path computation for the versioned Windows layout, so the zip Insiders build now correctly discovers the `data` folder. Shipped in 1.107.0.

## Change summary

VS Code Insiders zip on Windows ignored the `data` folder for portable mode because `getApplicationPath()` did not account for the versioned directory layout.

## Best solution

Keep the shipped fix — no further change needed. The portable path logic in `src/bootstrap-node.ts` now navigates up 3 levels from `appRoot` when `win32VersionedUpdate` is set, correctly reaching the folder where the user places `data`.
