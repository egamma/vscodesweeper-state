# Issue #340038 — `includeCoAuthoredBy: false` is ignored in VS Code Agent Host — `Co-authored-by: Copilot` is still injected into commits

[https://github.com/microsoft/vscode/issues/340038](https://github.com/microsoft/vscode/issues/340038)

## Summary

Traced in the checkout: nowhere in src/vs/platform/agentHost (copilotSessionLauncher.ts, copilotAgentSession.ts, copilotCliConfig.ts) is there any mapping from a coauthor preference to the SDK's `coauthorEnabled` SessionConfig field or to the `<git_commit_trailer>` system-prompt section — the reported integration gap is real, but the right fix (read the CLI's own settings.json vs. add a distinct VS Code setting, and how it should relate to `git.addAICoAuthor`) needs a design call.

## Change summary

Agent Host sessions always inject the Copilot co-author git trailer instruction, ignoring the Copilot CLI's `includeCoAuthoredBy`/`include_coauthor` settings.json preference that the standalone CLI honors.

## Best solution

Decide how VS Code's Agent Host integration should source this preference (reading the CLI's settings.json directly, or introducing a dedicated VS Code setting) and thread it into the SDK's `coauthorEnabled` session option in copilotSessionLauncher.ts, so the `<git_commit_trailer>` section is suppressed when the user has opted out.
