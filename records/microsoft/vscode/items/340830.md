# Issue #340830 — Extended cache TTL settings have no effect for Claude 5.x models

[https://github.com/microsoft/vscode/issues/340830](https://github.com/microsoft/vscode/issues/340830)

## Summary

Thanks for the detailed report. The defect is still present on main: modelSupportsExtendedCacheTtl has no Claude 5.x Opus/Sonnet/Haiku entries, so the extended TTL settings are silently ignored for those models. An open PR already proposes the fix, so this stays open for that PR to land.

## Change summary

Extended 1h prompt cache TTL settings are ignored for Claude Opus 5/5.5, Sonnet 5/5.5 and Haiku 5.5 because the model allowlist omits them.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/340831 to add the Claude 5.x families to the allowlist in extensions/copilot/src/platform/networking/common/anthropic.ts, and update the doc comment and the modelSupportsExtendedCacheTtl suite in messagesApi.spec.ts.
