# Issue #327974 — Markdown Editor (Experimental) Breaks When Markdown Metadata Is Present

[https://github.com/microsoft/vscode/issues/327974](https://github.com/microsoft/vscode/issues/327974)

## Summary

The experimental editor's pinned Markdown component does not recognize YAML front matter, so it parses the contents as ordinary Markdown. Keep this open and route it to the Markdown area while the component fix is published and adopted.

## Change summary

Render nested YAML front matter coherently in the experimental Markdown editor instead of interpreting it as paragraphs and lists.

## Best solution

Publish the front-matter-aware parser currently present in microsoft/vscode-packages, update VS Code from `@vscode/markdown-editor` 0.0.2-13, and cover nested YAML with a component regression test.
