# Issue #92868 — Terminal doesn't flush all line data before firing onExit

[https://github.com/microsoft/vscode/issues/92868](https://github.com/microsoft/vscode/issues/92868)

## Summary

Fixed and shipped in 1.48.0 — the fix commit explicitly references this issue, and both the team member and the reporter confirmed it was resolved. The later regression was tracked separately as #105159.

## Change summary

Terminal doesn't flush buffered xterm data before firing onExit, causing ProblemMatchers to miss output from CustomExecution tasks.

## Best solution

Keep the shipped fix from commit c2e9b6a63c0 (1.48.0). The remaining setTimeout hack in terminalTaskSystem.ts is tracked by https://github.com/microsoft/vscode/issues/105159, not this issue.
