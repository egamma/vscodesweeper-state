# Issue #346240 — Streaming reasoning tokens split into individual "Thought for 1s" UI blocks per word

[https://github.com/microsoft/vscode/issues/346240](https://github.com/microsoft/vscode/issues/346240)

## Summary

Keep open: multiple users confirm reasoning fragmentation across BYOK providers, and the reporter still sees fragmented live reasoning in 1.145.2 despite completed blocks now merging. The existing reproduction details suffice to retest the remaining streaming defect.

## Change summary

Consecutive streamed reasoning fragments create separate thought blocks and excessive chat rendering work.

## Best solution

Ensure one continuous reasoning run updates one collapsible block throughout streaming, not only after completion, while preserving genuine reasoning boundaries. Diagnose the remaining live-rendering behavior before treating the related fix as sufficient.
