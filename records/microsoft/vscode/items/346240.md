[https://github.com/microsoft/vscode/issues/346240](https://github.com/microsoft/vscode/issues/346240)

## Summary

The per-token reasoning fragmentation is fixed on main by a concrete aggregation change. The later complaint about reasoning appearing only after completion is a separate agent-host buffering problem already tracked elsewhere.

## Change summary

Keep consecutive streamed reasoning tokens in one continuously updated collapsible block instead of creating a block per chunk.
