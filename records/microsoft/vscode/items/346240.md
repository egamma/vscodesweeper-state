# Issue #346240 — Streaming reasoning tokens split into individual "Thought for 1s" UI blocks per word

[https://github.com/microsoft/vscode/issues/346240](https://github.com/microsoft/vscode/issues/346240)

## Summary

The reported per-chunk reasoning fragmentation is fixed on current main by a concrete change to live reasoning aggregation. Later reports against 1.145.2–1.145.3 are acknowledged, but the corresponding streaming path and regression coverage on main now preserve one block throughout streaming.

## Change summary

Consecutive BYOK reasoning deltas create individual thought blocks and excessive chat-rendering work instead of one continuously updated block.

## Best solution

Treat the aggregation defect as completed by commit 6c1e4a0f86e93bab92796645a9a3463511275b66, preserving genuine provider-owned reasoning boundaries while merging untimed BYOK chunks.
