# Issue #285872 — Custom Agent references multiple tools using 'search'

[https://github.com/microsoft/vscode/issues/285872](https://github.com/microsoft/vscode/issues/285872)

## Summary

The custom-agent tool reference is still necessary: the report describes an ambiguous short tool name resolving to multiple installed tools, and current source retains short-name lookup paths alongside qualified tool IDs. As a team-authored, re-reviewed issue with no verified older canonical or referenced fix, it should remain open.

## Change summary

Using `tools: [search]` in a custom agent can reference multiple tools when an installed MCP extension contributes another tool named `search`.

## Best solution

Make custom-agent tool resolution deterministic when short names collide, while preserving qualified tool identifiers and compatibility for uniquely named tools. The chat tools/custom-agent parsing path should surface an actionable ambiguity rather than silently binding one short name to multiple tools.
