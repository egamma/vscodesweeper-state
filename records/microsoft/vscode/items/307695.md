# Issue #307695 — Source Control Graph shows repository not visible in Source Control view

[https://github.com/microsoft/vscode/issues/307695](https://github.com/microsoft/vscode/issues/307695)

## Summary

The Graph still has an unfiltered path to repositories intentionally hidden from Source Control. Keep this team-authored report open; the related Copilot startup issue concerns a separate defect, not a canonical duplicate.

## Change summary

Prevent the Source Control Graph from displaying a hidden repository registered in an empty window.

## Best solution

Make Graph repository selection and history loading respect the SCM provider's hidden state, including automatic selection and fallback paths. Preserve the intentional independence of explicit Graph repository selection from the Changes view's selection.

- **Graph bypasses hidden-provider filtering:** src/vs/workbench/contrib/scm/browser/scmHistoryViewPane.ts:1152-1167 selects from raw ISCMService repositories or ISCMViewService.activeRepository without checking provider.isHidden. RepositoryPicker in scmHistoryViewPane.ts:1473-1485 uses this filtered repositories list, explaining why a hidden repository can supply Graph history while being absent from its picker.
