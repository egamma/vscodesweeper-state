# Issue #332693 — SSH connection establishing issue, only on windows.

[https://github.com/microsoft/vscode/issues/332693](https://github.com/microsoft/vscode/issues/332693)

## Summary

The failure is a proposed-API declaration mismatch inside the Remote-SSH extension itself (its package.json#enabledApiProposals doesn't list terminalRemoteResolver), not a defect in VS Code core — this belongs on the Remote Development tracker, so it should be moved rather than closed-and-refiled.

## Change summary

SSH connections fail on Windows with 'CANNOT use API proposal: terminalRemoteResolver' because ms-vscode-remote.remote-ssh's package.json doesn't declare that proposal.

## Best solution

Move this issue to microsoft/vscode-remote-release (the Remote Development / Remote-SSH tracker), where the extension's package.json#enabledApiProposals needs terminalRemoteResolver added, or the extension needs to be updated/rolled back to a version compatible with the currently shipped VS Code build.
