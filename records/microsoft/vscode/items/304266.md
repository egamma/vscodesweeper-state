# Issue #304266 — Renamed Keep button

[https://github.com/microsoft/vscode/issues/304266](https://github.com/microsoft/vscode/issues/304266)

## Summary

Keep open for the naming discussion: current source still labels acceptance of deletions as “Keep,” and a maintainer explicitly acknowledged the confusion. “Apply” was rejected because the edits have already happened; choosing clearer wording remains unresolved.

## Change summary

Make the chat edit acceptance label understandable when the accepted change deletes code.

## Best solution

Agree on concise acceptance wording that makes sense for additions and deletions without implying edits are awaiting application, then use it consistently across chat edit review actions. Preserve existing acceptance, undo, and save behavior.
