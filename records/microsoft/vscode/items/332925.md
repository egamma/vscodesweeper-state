# Issue #332925 — First character not included in search when using Unified Command Palette

[https://github.com/microsoft/vscode/issues/332925](https://github.com/microsoft/vscode/issues/332925)

## Summary

The first-character filtering defect remains in current source: clicking Commands leaves the input prefix-free, but the command provider unconditionally removes its first character. Keep this open and classify it as a bug.

## Change summary

Searching in the Unified Command Palette's Commands tab must include the first typed character, including single-character queries.

## Best solution

Make the unified Commands tab deliver the complete user query to the command provider while preserving explicit shortcut-prefix behavior and the conventional Command Palette.
