# Issue #327468 — ADO code-search endpoint override is workspace-scoped while authenticated requests use it

[https://github.com/microsoft/vscode/issues/327468](https://github.com/microsoft/vscode/issues/327468)

## Summary

Security-sensitive hardening report with an active, unmerged fix PR that explicitly says 'Fixes #327468' — both facts independently require keep-open; verified on current main that the setting still lacks a restricted/application scope.

## Change summary

The ADO code-search endpoint override setting is workspace-scoped and unrestricted, so a workspace can redirect a credential-bearing request to an attacker-controlled origin.

## Best solution

Land and merge open PR https://github.com/microsoft/vscode/pull/327500, which registers the setting as application-scoped/restricted via the existing `userScopeOnly` mechanism and adds regression coverage; close this issue only once that PR merges.
