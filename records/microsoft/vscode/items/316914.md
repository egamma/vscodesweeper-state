# Issue #316914 — Agents App: Allow me to submit a bug report from within the Agents App

[https://github.com/microsoft/vscode/issues/316914](https://github.com/microsoft/vscode/issues/316914)

## Summary

The central request is already supported: the Agents window includes Help: Report Issue... in its Command Palette and Report Issue in its Help menu. The reporting flow does not require opening the normal VS Code window.

## Change summary

Allow users to submit bug reports directly from the Agents App without switching to normal VS Code.

## Best solution

Use the existing workbench.action.openIssueReporter command from the Agents window; no additional reporting capability is needed for the requested workflow.
