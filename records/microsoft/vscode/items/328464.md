# Issue #328464 — Synchronized /act-on-feedback skill can be advertised while its backing file is missing

[https://github.com/microsoft/vscode/issues/328464](https://github.com/microsoft/vscode/issues/328464)

## Summary

The defect is visible on current main: syncing a new nonce immediately deletes the previous directory without tracking whether an active session still references it. Route this confirmed bug to agent plugin ownership.

## Change summary

Keep synchronized skill files available while active Agent Host sessions still reference their plugin-cache revision.

## Best solution

Give synchronized cache revisions explicit session-scoped leases and evict only unreferenced revisions, releasing leases when sessions dispose. Skill loading should also re-resolve or surface a recoverable synchronization error when a cached file disappears.
