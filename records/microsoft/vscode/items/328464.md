# Issue #328464 — Synchronized /act-on-feedback skill can be advertised while its backing file is missing

[https://github.com/microsoft/vscode/issues/328464](https://github.com/microsoft/vscode/issues/328464)

## Summary

Keep open: current source retains eight plugin revisions but still deletes older paths without checking whether active sessions reference them. The linked fix PR was closed without merging, and the independent reproductions support retaining this issue as the canonical report.

## Change summary

Prevent synchronized plugin-cache eviction from making advertised skills unreadable during an active Agent Host session.

## Best solution

Guarantee that synchronized paths remain readable while provider sessions can invoke them, while retaining bounded cleanup of unused revisions across hosts. Preserve the distinction between submitted feedback retrieved through listComments and comments awaiting reveal through viewUnreviewedComments.
