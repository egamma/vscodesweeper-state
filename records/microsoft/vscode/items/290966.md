# Issue #290966 — Spinner moves down while thinking text loads

[https://github.com/microsoft/vscode/issues/290966](https://github.com/microsoft/vscode/issues/290966)

## Summary

The progress row still follows streamed thinking markdown on current main, so it visibly moves downward as the text grows. This team-authored polish issue should remain open because the thread leaves the intended spinner behavior as an explicit design decision.

## Change summary

Make progress feedback inside the thinking container stable and consistent while reasoning text streams.

## Best solution

Choose one consistent progress rule for thinking containers: either hide the working row once reasoning text is visibly streaming, matching classic markdown behavior, or retain it without allowing the indicator to drift with the growing content. Apply that rule across the supported thinking display modes.
