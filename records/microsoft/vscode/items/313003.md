[https://github.com/microsoft/vscode/issues/313003](https://github.com/microsoft/vscode/issues/313003)

## Summary

Keep open: existing controls do not suppress Copilot completions specifically inside comments while retaining automatic code suggestions. A maintainer acknowledges the gap, and this is the older, better-discussed report of the comment-specific request.

## Change summary

Provide an option to disable automatic Copilot ghost-text completions inside comments and documentation comments without disabling code completions.

## Best solution

Provide an opt-in comment-specific suppression control while preserving automatic suggestions in code and existing defaults. Decide whether this is a Copilot-specific preference or an editor-wide inline-completion control before implementation.
