# Issue #176523 — drag selection going outside of search box moves caret to document

[https://github.com/microsoft/vscode/issues/176523](https://github.com/microsoft/vscode/issues/176523)

## Summary

The bug remains open with a confirmed reproduction and an active fixing PR. It should stay open until that PR is reviewed and merged or otherwise resolved.

## Change summary

Dragging a selection outside the editor find input can transfer focus and the caret to the document, causing subsequent typing to edit the document.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/327276, which disables native dragging from `FindInput` and adds a focused regression test.
