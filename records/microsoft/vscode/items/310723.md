# Issue #310723 — copilot: delegation mode (only final response in context)

[https://github.com/microsoft/vscode/issues/310723](https://github.com/microsoft/vscode/issues/310723)

## Summary

A real gap remains: current main can isolate work in a subagent and return its final result, but that path is still selected and mediated by the parent agent rather than exposed as the reporter's direct execution mode. The request should remain open for a product decision and be classified as under discussion.

## Change summary

Add a delegation mode that runs the selected agent in an isolated context and retains only its final response in the current conversation.

## Best solution

Provide an explicit user-selectable execution mode that starts the chosen agent with a fresh task context and imports only its final response into the conversation, avoiding a parent-model delegation round trip while retaining visible progress and cancellation.
