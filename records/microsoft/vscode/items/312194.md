# Issue #312194 — Source control menu stack closing on repository visibility toggling

[https://github.com/microsoft/vscode/issues/312194](https://github.com/microsoft/vscode/issues/312194)

## Summary

Keep open as a feature request: repository visibility toggles use the standard dismiss-on-action menu behavior, and the requested persistent submenu is not currently provided. The existing Repositories view offers a workaround, but does not satisfy the menu interaction request.

## Change summary

Allow toggling several repositories' visibility without reopening the Source Control menu stack after each selection.

## Best solution

Consider a repository-selection interaction that supports consecutive visibility changes while preserving ordinary menu dismissal elsewhere. The SCM owner should decide whether this belongs in the existing submenu or a dedicated multi-selection surface.
