# Issue #237353 — Ability to close and folders to reduce resource consumption in multi-root workspaces

[https://github.com/microsoft/vscode/issues/237353](https://github.com/microsoft/vscode/issues/237353)

## Summary

Keep open in the Backlog: this passed the community threshold with 34 upvotes, and current main still lacks a persistent disabled state for workspace folders. Existing exclusion settings cover only parts of the requested behavior.

## Change summary

Allow multi-root workspace folders to be temporarily disabled and later re-enabled without removing their saved workspace membership.

## Best solution

Add a persistent enabled/disabled state to stored workspace folders and make core workspace consumers omit disabled roots from search, quick open, SCM, and extension activation while retaining them in the workspace UI. Keep the scope at workspace-folder roots rather than making arbitrary files disappear from external programs.
