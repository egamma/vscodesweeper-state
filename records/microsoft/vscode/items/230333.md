# Issue #230333 — When doing suggestions for symbols, it would be useful to show the path relative to the workspace

[https://github.com/microsoft/vscode/issues/230333](https://github.com/microsoft/vscode/issues/230333)

## Summary

Keep open: the existing completion presentation does not establish workspace-relative provenance independently of the import specifier. The discussion already identifies the desired direction, and this reopened, team-authored request has no verified subsequent fix or canonical duplicate.

## Change summary

Show workspace-relative source paths in TypeScript symbol completion details so users can distinguish auto-import candidates without knowing the current file's directory.

## Best solution

Preserve the actual import specifier in the suggestion list while showing the source file's workspace-relative path in completion details, following the direction agreed in the thread. Confirm how current TS Server completion metadata exposes the source file before implementing the presentation.
