# Issue #230333 — When doing suggestions for symbols, it would be useful to show the path relative to the workspace

[https://github.com/microsoft/vscode/issues/230333](https://github.com/microsoft/vscode/issues/230333)

## Summary

Still an open feature request. The TS extension does compute workspace-relative paths at line 77 of completions.ts, but `sourceDisplay` from the TS server overwrites it at line 86. The details panel (`getDetails`) doesn't use `fileName` to show workspace-relative paths either. No commits reference this issue; the requested behavior remains unimplemented.

## Change summary

Show workspace-relative paths instead of file-relative paths in auto-import completion suggestions.

## Best solution

In `extensions/typescript-language-features/src/languageFeatures/completions.ts`, use the `fileName` field already returned by TS Server (confirmed by RyanCavanaugh) to compute workspace-relative paths via `vscode.workspace.asRelativePath()` and display them in the completion details. The label description logic at lines 75-86 also needs reconciliation so `sourceDisplay` doesn't always overwrite the workspace-relative path.
