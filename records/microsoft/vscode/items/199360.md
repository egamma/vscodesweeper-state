# Issue #199360 — Diff editor title actions menu

[https://github.com/microsoft/vscode/issues/199360](https://github.com/microsoft/vscode/issues/199360)

## Summary

The requested toolbar prioritization remains unresolved: whitespace and collapse controls are still primary actions, and the inspected registrations do not provide the proposed multi-file diff entry point. Keep this accepted Backlog item open for a focused design decision.

## Change summary

Rebalance the diff editor title toolbar between primary and secondary actions and provide an entry point to the relevant multi-file diff.

## Best solution

Give frequent diff navigation actions clear priority while retaining discoverable access to less-used controls. Decide the placement and resource scope of a multi-file diff entry point, supplied by a component that knows the relevant repository and change group.
