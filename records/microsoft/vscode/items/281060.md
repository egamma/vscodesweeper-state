Team-authored bug about stopping a cloud agent from the editor window chat not syncing state to the agent view. No fix commit references this issue, so it stays open.

## Change summary

Clicking stop on a cloud agent in the editor window does not actually stop the agent — it keeps spinning in the agent view and persists as running after reload.

## Best solution

The stop action in the editor-window chat needs to properly propagate cancellation to the cloud agent session provider so the agent view reflects the stopped state and reload doesn't resurrect it.
