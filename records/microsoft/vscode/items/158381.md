# Issue #158381 — editor.unicodeHighlight.ambiguousCharacters not accessible

[https://github.com/microsoft/vscode/issues/158381](https://github.com/microsoft/vscode/issues/158381)

## Summary

Keep open: Unicode warnings have accessible hover text, but ordinary caret navigation still lacks the requested automatic announcement. The existing accessibility and unicode-highlight labels already route this accepted Backlog work appropriately.

## Change summary

Expose highlighted ambiguous Unicode characters during screen-reader navigation, including their code point and warning classification.

## Best solution

Provide an exact-position announcement identifying the highlighted character and its ambiguity, consistent with the feedback recorded in the thread. Decide whether equivalent full-line and Braille exposure is part of this work, while preserving editing and caret mapping.
