# Issue #207361 — Add extensibility point for notebook outline pane entry toolbar

[https://github.com/microsoft/vscode/issues/207361](https://github.com/microsoft/vscode/issues/207361)

## Summary

The internal MenuId.NotebookOutlineActionMenu exists and is consumed by built-in actions (added in 88d1e2cbfdf), but it has not yet been exposed in menusExtensionPoint.ts as an extension contribution point, nor is there a proposed API for it. The tracking issue's core ask remains unimplemented.

## Change summary

Expose the notebook outline entry toolbar MenuId as an extension contribution point so third-party extensions can add actions to it.

## Best solution

Add a `notebook/outline/toolbar` (or similar) key in menusExtensionPoint.ts mapping to MenuId.NotebookOutlineActionMenu, and create a proposed API surface so extensions can contribute toolbar items to notebook outline entries.
