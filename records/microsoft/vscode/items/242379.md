# Issue #242379 — Method signature hint can get covered by autocomplete option list

[https://github.com/microsoft/vscode/issues/242379](https://github.com/microsoft/vscode/issues/242379)

## Summary

Keep open for a popup-layout design decision: current source positions suggestions and signature help independently, leaving the reported overlap possible. The maintainer explicitly invited discussion of stacking, and the older related requests do not establish a same-symptom canonical.

## Change summary

Keep signature help readable when a resized completion list moves above the cursor near the bottom of the window.

## Best solution

Coordinate completion-list and parameter-help placement so both remain readable when space permits, with an agreed fallback when they cannot both fit. Resolve the stacking-versus-repositioning behavior in the editor widget layout before implementation.
