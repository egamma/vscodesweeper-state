# Issue #242379 — Method signature hint can get covered by autocomplete option list

[https://github.com/microsoft/vscode/issues/242379](https://github.com/microsoft/vscode/issues/242379)

## Summary

The overlap remains possible on current main because parameter hints and suggestions choose their placement independently. This is correctly routed and under discussion; it needs a coordinated UX decision rather than closure.

## Change summary

Prevent the suggestion widget from covering parameter hints when limited space forces both above the cursor.

## Best solution

Coordinate suggest and parameter-hint placement when both widgets are visible, stacking them where space permits and using the opposite side or a capped layout otherwise. This likely belongs in the editor content-widget positioning logic and the two widget implementations.
