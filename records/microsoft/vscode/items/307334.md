# Issue #307334 — Please make sure you can configure user.name and user.email options from Code's Source Control menu

[https://github.com/microsoft/vscode/issues/307334](https://github.com/microsoft/vscode/issues/307334)

## Summary

Keep open for discussion: configuring Git identity inside VS Code overlaps an existing request, but warning when it differs from the signed-in GitHub account is additional scope not covered by the verified candidate.

## Change summary

Allow configuring Git user.name and user.email from Source Control and warn when global identity differs from the signed-in GitHub account.

## Best solution

Coordinate the identity-configuration UI with the existing Git request, while separately deciding whether account-mismatch warnings are useful. Any warning should accommodate intentional differences between Git author identity and GitHub login, including alternate and private email addresses.
