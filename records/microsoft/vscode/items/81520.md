# Issue #81520 — ctrl + click "go to definition" clashes with ctrl + click "follow link"

[https://github.com/microsoft/vscode/issues/81520](https://github.com/microsoft/vscode/issues/81520)

## Summary

Still reproduces on main: both `goToDefinitionAtPosition.ts` and `links.ts` independently create `ClickLinkGesture` instances and handle the same ctrl+click event, so both fire when a definition and a link overlap. An earlier fix attempt (LinkOpener) was reverted. The architectural solution proposed by a team member (a unified `FollowLinkController`) was never implemented.

## Change summary

Ctrl+click on text that is both a link and has a go-to-definition target triggers both actions simultaneously instead of picking one.

## Best solution

Implement the unified `FollowLinkController` architecture proposed in https://github.com/microsoft/vscode/issues/81520#issuecomment-943561655 — a single controller owns the click gesture, collects handlers from both `goToDefinitionAtPosition.ts` and `links.ts`, resolves them in parallel, and disambiguates (pick one or show an inline picker). The related issue https://github.com/microsoft/vscode/issues/131410 could be closed as a duplicate once this is resolved.
