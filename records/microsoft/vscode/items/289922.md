# Issue #289922 — Terminal being opened in wrong directory in multi-root workspace

[https://github.com/microsoft/vscode/issues/289922](https://github.com/microsoft/vscode/issues/289922)

## Summary

Keep open: the supplied Windows/Git Bash steps suffice to retest restoration into the wrong workspace root. Current source explicitly restores workspace-scoped terminal state, but inspection cannot establish why this report restores /c/foo instead of /c/bar, and no verified fix or canonical duplicate was found.

## Change summary

Restore a multi-root workspace's terminal in its previously used directory rather than another root shared with a separate workspace.

## Best solution

Preserve the terminal's directory independently for each saved workspace through close and reopen. Diagnose the terminal-persistence path on Windows with the reported overlapping workspaces; do not replace restoration semantics with an unconditional first-root default.
