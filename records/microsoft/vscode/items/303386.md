# Issue #303386 — Search Tab `Match whole word` mismatches in notebook

[https://github.com/microsoft/vscode/issues/303386](https://github.com/microsoft/vscode/issues/303386)

## Summary

The initial Search-view query for an open notebook still drops the word separators required to enforce whole-word matching. Keep this open: older related reports cover keyboard toggles or closed notebooks, not conclusively the same reported flow.

## Change summary

Make Match Whole Word exclude substring matches when searching an open notebook from the Search view.

## Best solution

Ensure initial searches of open notebook cell inputs honor the query's configured word boundaries, consistently with subsequent notebook-result refreshes and ordinary text-file searches.
