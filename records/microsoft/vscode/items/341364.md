# Issue #341364 — Cursor Left/Right splits Indic conjuncts (क्ष, स्त्री, ক্ষ): grapheme breaking is missing Unicode 15.1's GB9c

[https://github.com/microsoft/vscode/issues/341364](https://github.com/microsoft/vscode/issues/341364)

## Summary

Thanks for the detailed report. The grapheme rules in strings.ts still follow Unicode 13 with no GB9c handling, so Indic conjuncts split under cursor movement. An open PR already references the issue, so it stays open for that PR.

## Change summary

Cursor Left/Right (and Delete) stop inside Indic virama conjuncts such as क्ष because grapheme breaking lacks Unicode 15.1 rule GB9c.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/341365, which adds a stateless GB9c (no break between a Linker and a Consonant) in src/vs/base/common/strings.ts. A maintainer should confirm that Delete removing the whole conjunct is intended.
