# Issue #326344 — agent 窗口缺少自定义模型

[https://github.com/microsoft/vscode/issues/326344](https://github.com/microsoft/vscode/issues/326344)

## Summary

Multiple independent reporters (across VS Code versions 1.129 through 1.134, macOS/Windows/WSL) confirm that BYOK custom models registered via chatLanguageModels.json never appear in the Agent Host / Agents window model picker even with `chat.agentHost.byokModels.enabled` set and a full restart performed — this is a real, reproducible gap, though I could not conclusively pin the exact defect in the wiring from source alone.

## Change summary

Extension-provided BYOK (bring-your-own-key) language models are visible and usable in the normal Chat view but never surface in the Agent Host / Agents window model picker, which only shows 'Auto'.

## Best solution

Have the agentHost/BYOK bridge owners trace why `AgentHostByokLmHandler.listModels`/`_refreshByokModels` never returns renderer models in practice for affected users — the plumbing (`chat.agentHost.byokModels.enabled` → `AgentHostByokModelsEnabledConfigKey` → `resolveByokLmEnablement` in copilotAgent.ts/copilotSessionLauncher.ts, plus the separate `clientByokEnabled` context-key gate in agentHostByokLmHandler.ts) looks structurally complete on current main, so the remaining defect is likely a timing/registration-order issue, a stuck `clientByokEnabled` context key, or a sync failure between the renderer setting and the node config key rather than a fully unwired feature.
