# Issue #308944 — Unable to use Copilot/Local in multiple Chat Editors

[https://github.com/microsoft/vscode/issues/308944](https://github.com/microsoft/vscode/issues/308944)

## Summary

Keep open: the discussion contains a concrete diagnosis of session switching targeting the active editor rather than the clicked chat editor, and current source still derives its target from the active group. Newer replacement logic protects against activation changes during asynchronous work, but does not establish that the correct editor was selected initially; no qualifying fix or canonical duplicate was found.

## Change summary

Switching between Copilot and Local in one of several chat editors should affect that editor, not whichever editor was previously active.

## Best solution

Ensure session-type selection consistently targets the chat editor containing the invoked picker, including when another editor group was active. Verify the inactive-editor interaction before choosing a bounded fix in the picker-to-session-opening path.
