# Issue #308944 — Unable to use Copilot/Local in multiple Chat Editors

[https://github.com/microsoft/vscode/issues/308944](https://github.com/microsoft/vscode/issues/308944)

## Summary

Still reproduces on main: the `NewChatSessionInPlaceAction` targets the active editor group's active editor instead of the specific chat editor the user clicked on, so switching sessions in a non-focused chat editor tab fails. The TODO on line 1549 acknowledges the problem.

## Change summary

Cannot use the new-session picker in a chat editor tab that is not the currently active editor.

## Best solution

When `replaceEditor` is true, pass the target editor (or its group) from the invoking widget context rather than reading `editorGroupService.activeGroup.activeEditor`. The fix suggested in the comments — focusing the chat editor on widget click — is the simplest path. The fix is localized to `openChatSession` in `src/vs/workbench/contrib/chat/browser/chatSessions/chatSessions.contribution.ts`.
