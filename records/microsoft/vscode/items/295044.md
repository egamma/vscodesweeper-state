# Issue #295044 — Add an enterprise policy to accept JSON settings

[https://github.com/microsoft/vscode/issues/295044](https://github.com/microsoft/vscode/issues/295044)

## Summary

Legitimate enterprise request for a generic JSON-based policy that can override arbitrary extension settings without requiring each extension to declare individual policies. The existing managed-settings infrastructure is scoped to Copilot; no general mechanism exists yet.

## Change summary

Add an enterprise policy that accepts a JSON blob of arbitrary settings overrides, enabling IT admins to manage extension settings via GPO/MDM without per-extension policy declarations.

## Best solution

Implement a general-purpose managed-settings policy (analogous to the Copilot-specific `managedSettings` infrastructure in `src/vs/platform/policy/`) that accepts a JSON object of setting keys and values, applying them as overrides at the policy configuration level. This would extend the existing `PolicyConfiguration` and native policy watcher to support a single GPO/MDM key containing arbitrary settings JSON. The feature belongs in `src/vs/platform/policy/` and `src/vs/platform/configuration/`.
