# Issue #12588 — Extension proxy support

[https://github.com/microsoft/vscode/issues/12588](https://github.com/microsoft/vscode/issues/12588)

## Summary

The core request — extension proxy support — has been implemented since VS Code 1.29 via @vscode/proxy-agent, which transparently patches Node's http, https, net, tls, and undici modules in the extension host. Extensions using standard Node networking automatically get proxy support without any API call or code duplication. This can be closed as completed.

## Change summary

Provide a way for extensions to make HTTP requests through the user's configured proxy without duplicating VS Code's internal proxy logic.

## Best solution

Keep the shipped transparent proxy-patching approach (via @vscode/proxy-agent in src/vs/workbench/api/node/proxyResolver.ts). Extensions using Node's http/https/net/tls/undici modules automatically get proxy support. No further API surface is needed — the original request is satisfied.
