# Issue #12588 — Extension proxy support

[https://github.com/microsoft/vscode/issues/12588](https://github.com/microsoft/vscode/issues/12588)

## Summary

The central request is largely present on current main, but this re-reviewed Backlog item cannot be closed as implemented without a different, complete fixing commit. A maintainer should confirm whether the automatic support for `fetch`, `http`, and `https` exhausts the accepted scope before closing it.

## Change summary

Provide extensions with automatic access to VS Code's proxy configuration instead of requiring each extension to implement proxy handling.

## Best solution

Keep automatic proxy and system-certificate support active for extension-host `fetch`, `http`, and `https`, and track concrete failures as separate bugs. The proxy owner should decide whether those supported networking paths complete this broad Backlog request or whether another extension networking path remains in scope.
