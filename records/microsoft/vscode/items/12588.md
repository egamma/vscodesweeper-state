# Issue #12588 — Extension proxy support

[https://github.com/microsoft/vscode/issues/12588](https://github.com/microsoft/vscode/issues/12588)

## Summary

The extension-host networking support requested here is implemented on current main: VS Code automatically applies its proxy configuration to extension use of `fetch`, `http`, and `https`. Later CLI installation and individual connection failures in the thread are separate issues rather than remaining API work.

## Change summary

Make VS Code's proxy configuration available to extensions without requiring each extension to implement proxy resolution and authentication itself.

## Best solution

Keep the shipped automatic extension-host integration for Node.js `fetch`, `http`, and `https`; track specific failures in those paths, CLI extension installation, or unrelated schema requests as focused bugs.
