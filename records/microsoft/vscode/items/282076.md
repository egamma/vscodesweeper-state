# Issue #282076 — NES rendering for minor changes (i.e. missing letter or parenthesis)

[https://github.com/microsoft/vscode/issues/282076](https://github.com/microsoft/vscode/issues/282076)

## Summary

Keep open for a focused NES design review: existing highlighting and display settings offer partial mitigations, but do not establish that tiny suggested corrections are sufficiently distinguishable from saved text. No verified canonical owns this exact feedback, and the team-authored Backlog request should not be declined on a design judgment.

## Change summary

Make single-character NES corrections, such as missing identifier letters or closing delimiters, more visibly distinguishable from actual file contents.

## Best solution

Agree on a theme-aware presentation for tiny NES corrections that clearly communicates their unaccepted state without making routine editing more intrusive. Evaluate the existing inline borders and separate-preview mode against the reported grey background before deciding whether additional visual treatment is needed.

The finished presentation should make that unaccepted state recognizable at a glance, including on the reported #d0d0c0 background. Acceptance must apply the correction, while dismissal must leave the original buffer unchanged. Larger suggestions, keyboard acceptance, and existing accessibility behavior must remain intact; the exact visual treatment requires agreement with the maintainer.
