# Issue #320284 — "Open File" dialog does not open to current file directory

[https://github.com/microsoft/vscode/issues/320284](https://github.com/microsoft/vscode/issues/320284)

## Summary

Keep open as a confirmed Linux file-dialog regression: another user reports that downgrading to 1.122.1 restores the expected behavior. Current source still requests the active file's directory, but neither a fix for this recurrence nor an open canonical was established.

## Change summary

Opening the native file picker from a standalone file selects Recent instead of the currently edited file's directory.

## Best solution

Restore the native Linux picker's use of the active file's directory. Investigate the Electron/desktop-dialog boundary with the reported Cinnamon/X11 configuration before deciding whether the correction belongs in VS Code or upstream.

- **Current default-directory path:** src/vs/workbench/services/dialogs/browser/abstractFileDialogService.ts: defaultFilePath selects the last active file and returns its parent directory. src/vs/workbench/services/dialogs/electron-browser/fileDialogService.ts: pickFileAndOpen supplies that URI and toNativeOpenDialogOptions converts it to defaultPath.
- **Native-dialog boundary:** src/vs/platform/native/electron-main/nativeHostMainService.ts: pickFileAndOpen forwards the options to dialogMainService.pickFile. src/vs/platform/dialogs/electron-main/dialogMainService.ts: doPick preserves defaultPath; showOpenDialog clears it only when the path does not exist, then passes the options to electron.dialog.showOpenDialog. Source inspection does not establish why the Linux picker ignores an existing directory.

The former was consolidated into the also-closed https://github.com/microsoft/vscode/issues/213780, whose maintainer discussion attributes the 2024 failure to Electron portal handling. That history is an investigation lead, not proof that the 2026 recurrence has the same cause or is fixed.
- **Canonical search:** Open-issue searches for dialog/recent, dialog/default path, and file-dialog directory/path found no verified older issue owning this symptom. https://github.com/microsoft/vscode/issues/210991 concerns the simplified Open Folder picker selecting a parent directory, not the native Open File picker selecting Recent, so it is not a duplicate canonical.
