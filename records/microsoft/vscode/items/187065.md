# Issue #187065 — Streaming Diff Algorithm

[https://github.com/microsoft/vscode/issues/187065](https://github.com/microsoft/vscode/issues/187065)

## Summary

Keep open: the current diff pipeline still computes word-level refinements before publishing its result. This team-authored backlog request remains relevant, with the effect of deferred refinement on intra-hunk alignment still needing a product decision.

## Change summary

Compute word-level diffs lazily rather than making them a prerequisite for the initial line-level diff.

## Best solution

Develop deferred word-level refinement in the editor diff pipeline while preserving accurate final mappings and usable navigation and revert actions. Establish whether initial line alignment must remain stable or may change as refinements arrive.
