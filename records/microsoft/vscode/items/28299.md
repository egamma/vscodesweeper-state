# Issue #28299 — [theme] Request the feature: "editor.lineHighlightForeground".

[https://github.com/microsoft/vscode/issues/28299](https://github.com/microsoft/vscode/issues/28299)

## Summary

The requested foreground token remains absent on current main, while the existing background and border tokens only partially address the contrast problem. The request has limited demand and an unresolved design tradeoff around preserving syntax colors, so it should remain open under discussion rather than be closed.

## Change summary

Allow themes to specify a foreground color for all text on the currently highlighted editor line.

## Best solution

Preserve syntax-color distinctions while providing an accessible way for themes to maintain current-line contrast. Maintainers should first decide whether that requires a line-wide foreground token or a different contrast mechanism; today, themes can use a transparent `editor.lineHighlightBackground` or `editor.lineHighlightBorder` as a partial workaround.
