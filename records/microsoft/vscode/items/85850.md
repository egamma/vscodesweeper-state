# Issue #85850 — Allow for setting `enter` as a keyboard shortcut through the UI 

[https://github.com/microsoft/vscode/issues/85850](https://github.com/microsoft/vscode/issues/85850)

## Summary

Valid feature request: the DefineKeybindingWidget uses Enter as accept/submit rather than recording it as a chord, so bare `enter` cannot be set via the UI. Still open — the linked PR #91315 has not merged and the code is unchanged on main.

## Change summary

Allow setting bare `enter` (or chords ending in `enter`) as a keyboard shortcut through the Keybindings UI rather than requiring manual edits to keybindings.json.

## Best solution

Modify the DefineKeybindingWidget and DefineKeybindingOverlayWidget in src/vs/workbench/contrib/preferences/browser/keybindingWidgets.ts to use an explicit accept button (or a timeout/double-press) instead of Enter-to-submit, so Enter can be recorded as part of a keybinding. The open PR #91315 attempts this but has stalled.
