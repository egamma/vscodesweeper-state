# Issue #85850 — Allow for setting `enter` as a keyboard shortcut through the UI 

[https://github.com/microsoft/vscode/issues/85850](https://github.com/microsoft/vscode/issues/85850)

## Summary

The Keyboard Shortcuts editor still reserves bare Enter for accepting the binding rather than recording it. Keep this accepted request open while the existing implementation candidate is reviewed; PR https://github.com/microsoft/vscode/pull/91315 remains open and explicitly targets this issue.

## Change summary

Allow the Keyboard Shortcuts UI to configure bare Enter and chord sequences ending in bare Enter without editing keybindings.json.

## Best solution

Provide an accessible way to distinguish recording Enter from accepting a shortcut in the definition widget. Review https://github.com/microsoft/vscode/pull/91315 against current UI and keyboard-accessibility expectations before pursuing another implementation.
