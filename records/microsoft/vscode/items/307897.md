## Summary

Keep open: an independent reporter confirmed repeated extension-host crashes in the same large Windows multi-root scenario, while both reporters found that the `promptCacheKey` error is not consistently present and is likely incidental. The open Claude-session crash issue has a narrower diagnosed trigger and does not yet absorb this report's concurrent file-search path.

## Change summary

Copilot agent activity in a very large multi-root workspace saturates the extension host during concurrent file searches and eventually terminates it with a native crash.

## Best solution

Reproduce the concurrent `copilot_findFiles` workload on the current build while collecting ETW and crash dumps, then isolate whether the native abort comes from search concurrency, result materialization, or another extension-host component. Preserve bounded and cancellable file discovery in large multi-root workspaces without changing normal tool results.
