# Issue #259088 — Run in terminal: Confirmation edited command disappears when you scroll it out of view and back in

[https://github.com/microsoft/vscode/issues/259088](https://github.com/microsoft/vscode/issues/259088)

## Summary

The canonical bug remains source-reproducible: terminal confirmation edits are stored, but a virtualized re-render initializes the editor from stale confirmation data instead.

## Change summary

Preserve a user-edited terminal confirmation command when its chat row scrolls out of view and is rendered again.

## Best solution

Restore `commandLine.userEdited` when recreating `ChatTerminalToolConfirmationSubPart`, accounting for an extracted `cdPrefix`, while preserving read-only presentation overrides.
