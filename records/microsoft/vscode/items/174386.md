# Issue #174386 — Visual feedback when horizontal scroll "hides" columns

[https://github.com/microsoft/vscode/issues/174386](https://github.com/microsoft/vscode/issues/174386)

## Summary

Keep open: the editor still lacks the requested full-height, conditional left-edge shadow when horizontal scrolling hides columns. Existing shadow options and gutter colors do not cover this behavior, and no verified open canonical was found.

## Change summary

Show a full-height shadow at the left edge of editor text only while horizontal scrolling hides preceding columns.

## Best solution

Have the editor owner consider a restrained, theme-consistent scroll cue at the text/gutter boundary that disappears when the horizontal offset returns to zero. Preserve the existing vertical scroll cue and avoid treating permanent gutter coloring as equivalent coverage.

## Vision fit

- **Fit:** aligned
- **Reason:** A conditional cue that helps users distinguish clipped text from the start of a line supports consistent, self-explanatory editor interactions without adding permanent chrome.
