[https://github.com/microsoft/vscode/issues/161874](https://github.com/microsoft/vscode/issues/161874)

## Summary

Keep open: the requested offline handoff from a Codespace to a local container is not established as implemented, and the existing local-clone option does not itself deliver that transition. The related test plan explicitly identifies this issue as a missing transition; no verified canonical or fixing commit was found.

## Change summary

Support continuing a Codespace's work, including uncommitted changes, in a local development container before going offline.

## Best solution

Provide a Codespace-to-local-container destination through the existing Continue Working On integration, preserving working changes and making the destination usable offline. Coordinate the container-specific behavior with Dev Containers rather than treating a local clone alone as completion.
