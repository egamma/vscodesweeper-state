# Issue #337222 — Allow model- and agent-specific color indicators in Copilot Chat

[https://github.com/microsoft/vscode/issues/337222](https://github.com/microsoft/vscode/issues/337222)

## Summary

A real customization gap remains, but this nine-day-old Backlog Candidates request is still inside its 60-day community review period and has no verified canonical duplicate. Keep it open as under discussion while demand and the visual-design tradeoffs are evaluated.

## Change summary

Allow users to assign stable, model- and agent-specific color indicators to the selected Chat controls and their picker entries.

## Best solution

If community demand and design review support the feature, provide an optional accessible indicator keyed by stable model and agent IDs, while retaining text and icons so color is never the only distinguishing signal. The design should avoid turning the chat controls into unrestricted per-item styling.
