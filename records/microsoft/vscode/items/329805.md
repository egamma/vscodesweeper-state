# Issue #329805 — Markdown preview: code block copy button scrolls with content on horizontal overflow

[https://github.com/microsoft/vscode/issues/329805](https://github.com/microsoft/vscode/issues/329805)

## Summary

Confirmed on current main: the copy button is appended inside `pre` (the horizontal scroll container) with `position: absolute; right: 8px`, so it drifts with horizontal scroll instead of staying pinned to the viewport corner. Two open PRs already target this exact fix, so this stays open pending one of them landing rather than being auto-fixed or closed.

## Change summary

In the Markdown preview, the code-block copy button scrolls along with horizontally-overflowing code instead of staying pinned to the top-right corner of the visible viewport.

## Best solution

Land one of the two open PRs (#329808 or #330494), both of which restructure the button to sit outside `pre`'s own scroll container (or otherwise anchor it to the visible viewport) — a maintainer should pick/merge one and close this issue via that PR.
