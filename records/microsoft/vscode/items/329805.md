# Issue #329805 — Markdown preview: code block copy button scrolls with content on horizontal overflow

[https://github.com/microsoft/vscode/issues/329805](https://github.com/microsoft/vscode/issues/329805)

## Summary

Verified on current main: the copy button is appended inside `pre` (a scroll container with `overflow: auto`), so its `position: absolute; right: 8px` is anchored to the layout box and drifts left as the block scrolls right — matching the report. An open PR from the same author already fixes it, so this should stay open pending review/merge rather than being closed.

## Change summary

In the Markdown preview, the code-block copy button scrolls with the content instead of staying pinned to the top-right corner when a code block overflows horizontally.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/329808, which moves the button out of `pre`'s scroll container into a `.code-block-wrapper` sibling so `position: absolute; right: 8px` resolves against the wrapper's visible bounds instead of the scrollable content box.
