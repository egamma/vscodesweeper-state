# Issue #121225 — QuickPick.onDidChangeActive fires before QuickPick.onDidChangeValue on a value change

[https://github.com/microsoft/vscode/issues/121225](https://github.com/microsoft/vscode/issues/121225)

## Summary

The reported event ordering remains source-reproducible: changing the input filters and focuses the list before emitting onDidChangeValue. Keep this open; the related reports do not own the same observable defect.

## Change summary

Emit QuickPick.onDidChangeValue before active-item change notifications caused by that input change.

## Best solution

Make value-change notification precede the resulting active-item notifications in the quick-input implementation, while preserving filtering, final active-item state, and extension event forwarding.
