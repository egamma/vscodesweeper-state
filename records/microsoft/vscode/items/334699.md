# Issue #334699 — [Bug] Markdown table headers are not rendering correctly in extension details

[https://github.com/microsoft/vscode/issues/334699](https://github.com/microsoft/vscode/issues/334699)

## Summary

Confirmed in source: the extension README/details markdown renderer's stylesheet unconditionally sets `th { text-align: left; }`, which overrides the `align="center"`/`align="right"` HTML attribute marked.js emits for aligned table headers — CSS author rules beat presentational HTML attributes, so header cells never center or right-align even though body `td` cells (with no competing rule) do.

## Change summary

Markdown table headers in the Extensions view's README/details rendering ignore column alignment (e.g. `:-:`) and always render left-aligned, even though the same content aligns correctly in the editor's Markdown preview.

## Best solution

In src/vs/workbench/contrib/markdown/browser/markdownDocumentRenderer.ts's DEFAULT_MARKDOWN_STYLES, drop the blanket `text-align: left` from the `th` rule (or scope it to `th:not([align])`) so the `align` attribute marked.js renders per-column can take effect for header cells, matching `td` behavior.
