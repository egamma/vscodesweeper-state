# Issue #334699 — [Bug] Markdown table headers are not rendering correctly in extension details

[https://github.com/microsoft/vscode/issues/334699](https://github.com/microsoft/vscode/issues/334699)

## Summary

Confirmed on main by tracing the code: the Extensions view's README renderer correctly emits the markdown table's `align` attribute (via marked.js), but extensionEditor.css unconditionally forces `text-align: left` on all `<th>` elements, which overrides the deprecated `align` attribute (author CSS always wins over presentational HTML attributes). This is why centered/right-aligned table headers always render left-aligned.

## Change summary

Markdown table header alignment (e.g. `:-:` centered columns) is ignored and always rendered left-aligned in the Extensions view's README/details panel.

## Best solution

In src/vs/workbench/contrib/extensions/browser/media/extensionEditor.css, split the `.extension-editor ... table th { text-align: left; word-break: keep-all; }` rule so `text-align: left` only applies when no `align` attribute is present (e.g. `table th:not([align])`), letting marked.js's per-column `align="center"/"right"` attribute take effect as intended.
