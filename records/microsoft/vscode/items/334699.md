# Issue #334699 — [Bug] Markdown table headers are not rendering correctly in extension details

[https://github.com/microsoft/vscode/issues/334699](https://github.com/microsoft/vscode/issues/334699)

## Summary

Confirmed in source: the shared markdown document CSS unconditionally sets `th { text-align: left; }`, which overrides the per-column `align` attribute (`align="center"`/`"right"`) that `marked` correctly emits for table header alignment syntax (`:-:`, `--:`). This is a genuine, reproducible bug in shared rendering CSS, not extension-specific.

## Change summary

Markdown table header cell alignment (`:-:`, `--:`) set via GFM table syntax is not respected when a README is rendered in the Extensions view.

## Best solution

Scope the default header alignment rule in DEFAULT_MARKDOWN_STYLES so it doesn't clobber an explicit `align` attribute, e.g. change `th { text-align: left; }` to `th:not([align]) { text-align: left; }` in src/vs/workbench/contrib/markdown/browser/markdownDocumentRenderer.ts — this also fixes the same defect in MCP server details, release notes, getting-started, and agent plugin editors, which all share DEFAULT_MARKDOWN_STYLES.
