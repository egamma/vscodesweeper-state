# Issue #236258 — FR: During open of search bar leave cursor in editor if before search opening some text was selected (put that text into search field)

[https://github.com/microsoft/vscode/issues/236258](https://github.com/microsoft/vscode/issues/236258)

## Summary

The requested workflow already exists as the separate “Find with Selection” command, while regular Find intentionally focuses its input.

## Change summary

Keep editor focus when opening Find with selected text used as the query.

## Best solution

Use or assign a keybinding to `actions.findWithSelection`; retain the distinct focus behavior of regular Find.

- **Proposed comment:**

  > Thanks for the request. This workflow is available through the **Find with Selection** command (`actions.findWithSelection`): it puts the selection into Find while preserving editor focus. On macOS it is bound to Cmd+E; on other platforms it can be assigned a keybinding. Regular Find intentionally focuses its input, so keeping these as separate commands avoids conditional focus behavior.

## Evidence

- **existing command:** `StartFindWithSelectionAction` in src/vs/editor/contrib/find/browser/findController.ts registers `actions.findWithSelection`, seeds the selected text, and uses `FindStartFocusAction.NoFocusChange`.
- **intentional behavior:** In https://github.com/microsoft/vscode/issues/44093#issuecomment-546157573, the maintainer explicitly distinguished Find with Selection, which preserves editor focus, from regular Find, which focuses the widget.
- **existing implementation:** Commit https://github.com/microsoft/vscode/commit/6acc9ff1eeb155b66d0a1548c2eba395846b0802 added and tested selection-based Find without changing focus.
