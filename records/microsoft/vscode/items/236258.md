# Issue #236258 — FR: During open of search bar leave cursor in editor if before search opening some text was selected (put that text into search field)

[https://github.com/microsoft/vscode/issues/236258](https://github.com/microsoft/vscode/issues/236258)

## Summary

Keep open as a request to change ordinary Find's focus behavior when text is selected. The existing Find with Selection command supports searching without moving focus, but ordinary Find still focuses its input; the current bug label also bars an as-designed close without a later maintainer decision.

## Change summary

When opening the editor Find widget with selected text, populate the search field while retaining editor focus.

## Best solution

Have the editor-find owner decide whether ordinary Find should retain editor focus when seeded from a selection, while preserving input focus when no text is selected. Document actions.findWithSelection as the existing alternative rather than treating it as proof that the requested conditional behavior has landed.
