Keep open for graphics-stack investigation. Two independent confirmations, hardware-acceleration workarounds, and matching symptoms in Chrome and Edge point toward Chromium or the Windows graphics driver rather than an extension.

## Change summary

The mouse pointer stops visibly updating in full-screen mode on a Windows 4K display while mouse input continues working.
