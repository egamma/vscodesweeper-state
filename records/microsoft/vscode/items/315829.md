# Issue #315829 — Agents Local: current branch is hard to find out due to being hidden in collapsed menu

[https://github.com/microsoft/vscode/issues/315829](https://github.com/microsoft/vscode/issues/315829)

## Summary

Valid polish request from a team member: the current git branch in the Agents window local harness is only visible in hover content or a collapsed menu, not directly on the UI surface. The issue remains unaddressed on main.

## Change summary

Promote the current git branch name to a visible UI element in the Agents window session header instead of hiding it in a collapsed menu.

## Best solution

Surface the branch name directly in the session header meta row (e.g. as a visible pill or inline label alongside the workspace folder pill in `src/vs/sessions/contrib/files/browser/workspaceFolderActions.ts` or `src/vs/sessions/browser/parts/sessionHeader.ts`), so users can see the active branch at a glance without hovering or expanding a menu.
