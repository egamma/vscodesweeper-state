# Issue #345553 — Worktree cleanup: No new entries shown

[https://github.com/microsoft/vscode/issues/345553](https://github.com/microsoft/vscode/issues/345553)

## Summary

Confirmed in current source: agent branches created with git.branchPrefix are excluded by cleanup's literal agents/ checks. Both the Sessions filtering and host inventory/removal validation need to recognize supported prefixed branches.

## Change summary

Worktree Cleanup omits agent worktrees whose branch names include the configured Git branch prefix.

## Best solution

Make cleanup recognize the branch names agent worktree creation supports, consistently across the Sessions UI and host inventory/removal checks, while retaining existing managed-path, registration, branch-identity, and usage protections.
