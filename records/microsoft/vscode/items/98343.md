# Issue #98343 — Resize Pane actions for all panes

[https://github.com/microsoft/vscode/issues/98343](https://github.com/microsoft/vscode/issues/98343)

## Summary

The accessibility gap remains on current main: keyboard commands resize entire workbench parts rather than the focused pane. This team-authored Backlog request is also the established canonical issue, so it should remain open.

## Change summary

Allow keyboard resize actions to resize the focused individual view pane, not only terminal panes or whole workbench parts.

## Best solution

Update the workbench resize actions to target the focused pane in a multi-view container, using the existing ViewPaneContainer pane-resizing API while preserving sensible part-level behavior when no individual pane can be resized.
