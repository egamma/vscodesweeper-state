# Issue #332106 — Accessibility ModernUI: Editor Active file tab design has undesired effect

[https://github.com/microsoft/vscode/issues/332106](https://github.com/microsoft/vscode/issues/332106)

## Summary

The central request is implemented: Modern UI now defaults to Connected tabs, making the selected tab and editor read as one document surface rather than separate pills. The concrete implementation and subsequent geometry refinements support closing this as completed.

## Change summary

Make the active editor tab visually identifiable and connected to its document in Modern UI, including dark themes.

## Best solution

Retain the Connected default implemented in commit 301c31b679b3313439f01cdf9cd1d6c63d70d34b and its subsequent refinements. Any remaining theme-specific contrast problem should be evaluated against that treatment rather than the original separated-pill design.
