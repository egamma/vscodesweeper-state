# Issue #332106 — Accessibility ModernUI: Editor Active file tab design has undesired effect

[https://github.com/microsoft/vscode/issues/332106](https://github.com/microsoft/vscode/issues/332106)

## Summary

Design feedback on the actively-developed experimental Modern UI: the reporter finds the new active-tab styling less visually distinct than Classic UI, especially with Dark themes. This is subjective UX feedback on in-progress, opt-in experimental work, not a defined defect — best left for the modernUI team to weigh as design input.

## Change summary

With `workbench.experimental.modernUI` enabled, the active editor tab is harder to visually distinguish from inactive tabs than with Classic UI, particularly in Dark Modern/Dark+ themes.

## Best solution
