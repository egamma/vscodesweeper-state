# Issue #332106 — Accessibility ModernUI: Editor Active file tab design has undesired effect

[https://github.com/microsoft/vscode/issues/332106](https://github.com/microsoft/vscode/issues/332106)

## Summary

Valid design feedback on the experimental Modern UI: the 'connected' active editor tab intentionally uses `editor.background` to blend with the document, but two independent reporters say this reduces contrast against inactive tabs across several themes, hurting at-a-glance focus tracking. Worth routing to the modernUI team for design iteration rather than closing.

## Change summary

With `workbench.experimental.modernUI` enabled, the active editor tab is harder to visually distinguish from inactive tabs than in Classic UI, especially with certain themes.

## Best solution

modernUI team should evaluate stronger active/inactive contrast for the 'connected' tab style (src/vs/workbench/contrib/modernUI/browser/media/tabs.css, README.md 'Editor tab style' section) — e.g. an additional visual cue beyond background-blend for the active tab, especially with third-party themes like Tokyo Night/Catppuccin.
