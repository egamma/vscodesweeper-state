# Issue #333005 — In the agents window, the inline comments have a bad hover background for rendered markdown

[https://github.com/microsoft/vscode/issues/333005](https://github.com/microsoft/vscode/issues/333005)

## Summary

Real, already-confirmed visual bug (hediet reproduced it and flagged the underlying theme-token issue), team-authored with an assigned real milestone (1.136.0) and already being actively triaged (bot reassigned a backup owner today) — keep open for the fix, not a triage close.

## Change summary

In the Agents window, hovering an inline plan comment renders with an inconsistent/transparent-looking background depending on the active color theme.

## Best solution

In src/vs/sessions/contrib/agentFeedback/browser/media/agentFeedbackEditorWidget.css, the `.agent-feedback-widget-item:hover` rule uses `var(--vscode-list-hoverBackground)`, a token many themes define as a semi-transparent overlay meant for list rows sitting on the list's own background — applied here over the agent-feedback editor widget's background it can look inconsistent or transparent. Switch to a hover token intended for widget/editor surfaces (or an opaque widget-scoped hover color) so it renders consistently across themes, per hediet's comment.
