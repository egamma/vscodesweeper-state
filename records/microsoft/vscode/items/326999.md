# Issue #326999 — Single Detail Panel: List toggle not visible when opening a markdown file from chat

[https://github.com/microsoft/vscode/issues/326999](https://github.com/microsoft/vscode/issues/326999)

## Summary

Keep open: the screenshot documents an incorrect detail-panel state, and the open team-authored feedback tracker explicitly classifies this report as a bug. Current source still has paths where an editor opened from chat preserves the Changes panel rather than selecting Files.

## Change summary

Opening a Markdown file from chat can leave the Changes list in the detail panel and omit the control for toggling the expected Files list.

## Best solution

Ensure Markdown editors opened from chat map to the Files detail target and keep the Toggle Details action visible. The likely investigation points are the editor-type mapping in `singlePaneDetailPanelStrategy.ts` and the menu conditions in `singlePaneResponsiveSidebarStrategy.ts`.
