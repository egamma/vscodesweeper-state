Keep open: this is the canonical exploration issue for a terminal buffer extension API, and exploration items are deliberately long-lived. Current APIs and Copilot's limited buffer reconstruction do not provide the proposed structured buffer access.

## Change summary

Explore an extension API for reading terminal buffers, selections, buffer modes, and completed command output.
