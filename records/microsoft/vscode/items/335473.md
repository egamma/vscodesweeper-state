# Issue #335473 — Agent Host Claude session still subscribes to obsolete untitled URI after #330761 and hangs forever

[https://github.com/microsoft/vscode/issues/335473](https://github.com/microsoft/vscode/issues/335473)

## Summary

Well-diagnosed race in the Agent Host new-session eager-create path where a subscribe can target the obsolete `untitled-*` URI right before materialization rebinds to the real backend URI, causing a permanent hang; an open PR already targets this exact issue, so it should stay open pending that fix landing.

## Change summary

A new Claude Agent Host session can subscribe to a provisional `claude:/untitled-*` URI just before the real backend URI is bound, receiving AHP_SESSION_NOT_FOUND and hanging forever since the correct URI is never subscribed to.

## Best solution

Land https://github.com/microsoft/vscode/pull/335472 ("Avoid subscribing to untitled Agent Host sessions"), which appears to target exactly this identity-remapping race in `baseAgentHostSessionsProvider.ts`'s `eagerCreate`/subscription flow; keep the issue open until that PR merges and is verified against this repro.
