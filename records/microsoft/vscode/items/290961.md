# Issue #290961 — Skeleton view doesnt show on new welcome

[https://github.com/microsoft/vscode/issues/290961](https://github.com/microsoft/vscode/issues/290961)

## Summary

The walkthrough-to-sessions swap remains possible on current main when the session cache is empty and providers resolve later. The linked merged PR removes the grid's loading skeleton but leaves the initial walkthrough-selection branch unchanged, so it does not establish a complete fix for this team-authored report.

## Change summary

Prevent the welcome page from briefly showing walkthrough widgets while existing sessions are still loading.

## Best solution

Distinguish unresolved session discovery from a genuinely empty session list in the Agent Sessions welcome page. Preserve immediate display of cached sessions and show walkthroughs only once the empty state is established.
