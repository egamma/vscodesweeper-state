## Summary

The stale Windows PATH behavior is already covered by the verified open canonical issue. Consolidate this report there, preserving its PowerShell 7, Node.js, and persistent-session observations.

## Change summary

Have newly created Windows integrated terminals pick up current system/user PATH changes so installed commands such as npm resolve without restarting VS Code.

## Best solution

Implement fresh Windows terminal environment resolution under https://github.com/microsoft/vscode/issues/47816, covering newly launched shells and environment resolution during session revival while preserving explicit environment overrides.
