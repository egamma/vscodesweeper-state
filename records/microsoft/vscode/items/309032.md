[https://github.com/microsoft/vscode/issues/309032](https://github.com/microsoft/vscode/issues/309032)

## Summary

The reporter describes a known trade-off of terminal persistent sessions (a reconnected shell keeps its original environment), but hasn't responded to a team member's clarifying question from April 14. Requesting more info before routing.

## Change summary

Persistent terminal sessions on Windows can retain a stale PATH after software installation, preventing npm resolution until the session is manually refreshed.

## Best solution

If confirmed as a persistent-session reconnection issue, this is a known trade-off of the feature — the fix would be to refresh the environment when reconnecting to a persisted terminal process, likely in the pty host reconnection path. Route to terminal-persistence area. Alternatively, may be closed as *as-designed since disabling persistent sessions is the documented workaround.
