# Issue #309032 — Integrated terminal on Windows can start with stale PATH and fail to resolve npm while standalone PowerShell works

[https://github.com/microsoft/vscode/issues/309032](https://github.com/microsoft/vscode/issues/309032)

## Summary

This is a duplicate of the long-standing canonical issue #47816 — VS Code terminals on Windows inherit the process's environment snapshot rather than fetching fresh environment variables. The persistent-session revival aspect is a subset of the same root cause (the revived session inherits whatever stale environment was captured).

## Change summary

Integrated terminal on Windows starts with stale PATH when persistent sessions revive, failing to resolve commands like npm that were installed after VS Code launched.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/47816 which tracks fresh environment blocks for new terminals on Windows — implementing that would cover both newly created terminals and revived persistent sessions.
