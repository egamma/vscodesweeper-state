# Issue #335054 — [Feature Request] Terminal: add inline Clear action to the tab hover actions (next to Split/Kill)

[https://github.com/microsoft/vscode/issues/335054](https://github.com/microsoft/vscode/issues/335054)

## Summary

The requested per-terminal inline Clear action is still absent; the existing Clear command and toolbar action do not cover clearing an inactive terminal directly from its tab row. Keep this open for a terminal UX decision: the cited discussions address panel-toolbar clearing, not the full scope of this request.

## Change summary

Add a Clear action alongside Split and Kill on terminal tab rows, allowing an inactive terminal's buffer to be cleared without activating or terminating it.

## Best solution

Decide whether terminal tab rows should expose an optional Clear action, balancing direct access against action-bar clutter. If accepted, it should target the represented terminal without changing focus or terminating its session.
