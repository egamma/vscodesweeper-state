# Issue #335054 — [Feature Request] Terminal: add inline Clear action to the tab hover actions (next to Split/Kill)

[https://github.com/microsoft/vscode/issues/335054](https://github.com/microsoft/vscode/issues/335054)

## Summary

The existing Clear Terminal command and optional title-toolbar button do not provide the requested per-row action for an inactive terminal. Keep this request open and route it to the terminal area for a decision on the additional affordance.

## Change summary

Expose Clear alongside Split and Kill on terminal tab rows so an inactive terminal can be cleared without activating it.

## Best solution

Have the terminal owner decide whether a row-scoped Clear action merits inclusion, and whether it should be opt-in to preserve uncluttered tabs. If accepted, it should clear the targeted terminal without changing the active terminal or terminating its process.
