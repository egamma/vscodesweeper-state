Keep open: current source still explains the displaced Timeline hover when horizontal list scrolling is enabled. The report is team-authored and already accepted as a bug, and no fixing commit or older canonical issue with the same observable symptom was found.

## Change summary

Timeline item hovers are positioned outside the visible sidebar when `workbench.list.horizontalScrolling` is enabled.

## Best solution
