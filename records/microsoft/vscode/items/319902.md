# Issue #319902 — VS Code Automatic updates don't work on any systems with default update setting.  

[https://github.com/microsoft/vscode/issues/319902](https://github.com/microsoft/vscode/issues/319902)

## Summary

Active investigation by the update team — reporter clarified this is a system install on multi-user AVD hosts where background updates fail when other users have VS Code open. The team member asked follow-up questions and the reporter responded; the conversation is mid-triage and should stay open.

## Change summary

Automatic background updates fail on Windows system installs in multi-user Azure Virtual Desktop environments when other users have VS Code open.

## Best solution

The update team (install-update area) needs to investigate whether the Windows background update mechanism (`update.enableWindowsBackgroundUpdates`) handles file-locking conflicts in multi-user system installs on AVD. May need coordination with Inno Setup's locking behavior or scheduled-task-based updates when no sessions hold locks.
