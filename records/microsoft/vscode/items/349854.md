# Issue #349854 — default ai model problem

[https://github.com/microsoft/vscode/issues/349854](https://github.com/microsoft/vscode/issues/349854)

## Summary

The requested default-model preference already exists as chat.defaultModel. Current source applies it to new conversations ahead of remembered or automatic selections, subject to organization-managed defaults.

## Change summary

Allow choosing a persistent default chat model instead of automatically starting with Fusion.

## Best solution

Use chat.defaultModel with an available model ID or family name. More discoverable preference controls in the model picker are separately tracked at https://github.com/microsoft/vscode/issues/349192.
