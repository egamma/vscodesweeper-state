# Issue #333726 — VSCode supports the peek function definition capability in secondary windows.

[https://github.com/microsoft/vscode/issues/333726](https://github.com/microsoft/vscode/issues/333726)

## Summary

This remains a genuine feature gap and is only 24 days into the established Backlog Candidates upvote period. Existing navigation and auxiliary-window commands provide pieces of the workflow but do not automatically track hovered definitions in a dedicated secondary window.

## Change summary

Add an optional secondary editor window that follows delayed symbol hovers from the main editor and opens each symbol's definition for browsing or editing.

## Best solution

Provide an opt-in definition-preview mode targeting a dedicated auxiliary editor window, preserving focus and navigation state in the main editor while updating the secondary editor after a deliberate hover delay.
