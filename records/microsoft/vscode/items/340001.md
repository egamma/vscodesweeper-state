# Issue #340001 — Remove the AI Usage Statistics widget

[https://github.com/microsoft/vscode/issues/340001](https://github.com/microsoft/vscode/issues/340001)

## Summary

Keep open: current main still implements the AI Usage Statistics widget and hover. Disabling it through a setting does not satisfy the maintainer-authored request to retire the feature.

## Change summary

Remove the AI Usage Statistics status bar widget and its associated hover because its attribution-based metrics are no longer meaningful.

## Best solution

Retire the statistics widget and hover in the editTelemetry contribution while preserving independent edit telemetry and AI co-author functionality. Establish the compatibility behavior for the existing experimental setting before completing the cleanup.
