# Issue #275200 — switch modes with multiple chat windows

[https://github.com/microsoft/vscode/issues/275200](https://github.com/microsoft/vscode/issues/275200)

## Summary

Keep open while the directly linked fixing PR is reviewed: when a panel and editor chat share a session, mode selection can target the wrong widget. The open PR identifies the ambiguous session-based lookup and adds focused regression coverage.

## Change summary

Changing chat mode from one of multiple chat widgets displaying the same session changes the mode in the wrong widget.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/310970 so mode changes resolve the originating widget by its unique input URI while retaining the session-resource fallback for existing callers.
