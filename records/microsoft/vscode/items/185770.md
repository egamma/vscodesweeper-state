# Issue #185770 — Cursor should snap to nearest sash for easy resize

[https://github.com/microsoft/vscode/issues/185770](https://github.com/microsoft/vscode/issues/185770)

## Summary

The existing `workbench.sash.size` setting improves hit targeting but does not provide the requested pointer-to-nearest-sash interaction, and larger values can interfere with adjacent scrollbars. The request remains a real, narrowly scoped workbench accessibility/interaction gap.

## Change summary

Add a modified pointer action that moves the cursor to the nearest workbench sash so resizing does not require precisely targeting a narrow border.

## Best solution

Define a consistent workbench interaction for locating and engaging the nearest eligible sash without enlarging sash hit targets over neighboring controls; the sash/grid widget owners should decide the modifier and behavior across platforms.
