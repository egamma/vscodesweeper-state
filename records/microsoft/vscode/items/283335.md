## Evidence

- **Detailed reproduction:** https://github.com/microsoft/vscode/issues/283335#issuecomment-3670047150 describes git log reporting lines 1–13 in a 14-row terminal while sticky scroll obscures two rows; pager page-up cannot reveal them and page-down skips additional obscured lines.
- **Independent confirmations:** https://github.com/microsoft/vscode/issues/283335#issuecomment-3679171267 reports git commit output obscured until resizing. https://github.com/microsoft/vscode/issues/283335#issuecomment-4509508949 reports entr -c hiding initial output on macOS with VS Code 1.121.0 and explicitly confirms disabling sticky scroll resolves it.
- **Current overlay behavior:** src/vs/workbench/contrib/terminalContrib/stickyScroll/browser/terminalStickyScrollOverlay.ts, TerminalStickyScrollOverlay._updateContent, suppresses a live partial-command pager only for bottom-row ':' with cursorX === 1 or '(END)' with cursorX === 5. The reporter's 'lines 1-13' footer is not covered by those checks. browser/media/stickyScroll.css places the header absolutely over terminal content rather than reserving rows.
- **Page-navigation path:** src/vs/workbench/contrib/terminal/browser/terminalActions.ts routes Shift+PageUp to scrollUpPage. src/vs/workbench/contrib/terminal/browser/xterm/xtermTerminal.ts implements scrollUpPage and scrollDownPage through raw.scrollPages(-1/1), without passing the sticky header's occupied row count.
- **Existing workarounds:** src/vs/workbench/contrib/terminalContrib/stickyScroll/common/terminalStickyScrollConfiguration.ts exposes terminal.integrated.stickyScroll.enabled and terminal.integrated.stickyScroll.ignoredCommands.
