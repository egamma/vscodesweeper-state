No commenter independently confirms the defect.
- **Current welcome layout path:** src/vs/workbench/contrib/welcomeAgentSessions/browser/agentSessionsWelcome.ts:812-834 stores editor dimensions in AgentSessionsWelcomePage.layout(), calls layoutChatWidget(), computes chat width as Math.min(800, editorWidth - 80), and sets an input-height override before ChatWidget.layout(). This identifies the resize path but does not establish that the reported visual corruption still occurs.
- **Related fix does not establish resolution:** https://github.com/microsoft/vscode/pull/306454 merged as 4ebc211cda9e32010ab4770859156e9a95583559 and introduced the height override still present in the welcome editor. - **Shared input sizing has changed:** src/vs/workbench/contrib/chat/browser/widget/chatWidget.ts:3915-3934 derives the input height budget and passes width to ChatInputPart.layout(). src/vs/workbench/contrib/chat/browser/widget/input/chatInputPart.ts:5158-5171 now floors the effective editor budget at a usable line height. These protections may affect the symptom, but source inspection alone cannot verify the Windows rendering outcome.
