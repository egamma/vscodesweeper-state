# Issue #322796 — Changing from dark -> light with TUI CLI makes text difficult to see

[https://github.com/microsoft/vscode/issues/322796](https://github.com/microsoft/vscode/issues/322796)

## Summary

Team-authored terminal rendering bug still open on main — the terminal does update its theme colors on theme change (via `_updateTheme` in xtermTerminal.ts), but TUI applications that have already painted ANSI-colored text retain stale foreground/background colors that clash with the new theme. No fix commit references this issue.

## Change summary

Switching from a dark to light VS Code theme while a TUI CLI (Copilot CLI) is running leaves previously rendered text with dark-theme ANSI colors, making it hard to read against the new light background.

## Best solution

The terminal needs to either re-render existing TUI content with updated ANSI palette mappings on theme change, or signal the running TUI application to repaint. The relevant code path is in `src/vs/workbench/contrib/terminal/browser/xterm/xtermTerminal.ts` (`_updateTheme`), which updates xterm's theme but does not force a repaint of already-rendered cells using palette ANSI colors. This likely requires xterm.js-level support for retroactively remapping ANSI palette colors in the buffer.
