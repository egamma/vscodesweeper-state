# Issue #348176 — Feature Request / Bug: Persistent MCP Tool Approvals in the New Copilot Harness

[https://github.com/microsoft/vscode/issues/348176](https://github.com/microsoft/vscode/issues/348176)

## Summary

Keep open as a permissions-management feature request. Current main already supports persistent host-wide MCP server/tool approvals, but the management UI does not expose the requested complete allow/ask/deny hierarchy, and the reported cross-interface inconsistency remains unconfirmed.

## Change summary

Provide consistent, persistent per-server and per-tool MCP execution permissions across Editor Chat and the Agents window, independently of terminal permissions.

## Best solution

Build on the existing host-wide permission rules rather than introduce another approval store. Establish consistent management across both interfaces and define the requested server/tool override semantics while preserving runtime-enforced restrictions.

- **Remaining management gap:** manageAgentHostToolApprovals exposes boolean isServerApproved/setServerApproved and isToolApproved/setToolApproved operations.
