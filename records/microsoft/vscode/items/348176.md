[https://github.com/microsoft/vscode/issues/348176](https://github.com/microsoft/vscode/issues/348176)

## Summary

Current main already has host-wide MCP server/tool approval management and persistent permission storage, but that does not establish that the reported cross-interface inconsistencies or requested safeguards are resolved. Keep this security-sensitive approval request open for human review.

## Change summary

Provide persistent, granular MCP execution permissions consistently across Editor Chat and the Agents window, independently of terminal permissions.

## Best solution

Verify the existing host-wide approval path against the supplied new-conversation and restart steps in both interfaces, then address remaining permission-management gaps without broadening terminal access. Explicitly resolve the requested ask/deny overrides and approval invalidation when server identity or advertised tool definitions change.
