Keep open for the remaining permission-override semantics and definition-change safeguards; these security-sensitive authorization decisions need human review.

## Change summary

Provide persistent, granular MCP execution permissions shared across Editor Chat and the Agents window without approving unrelated terminal operations.

## Best solution

Build on the existing host-wide approval management rather than introducing another approval store. Establish consistent cross-window behavior, explicit server/tool override semantics, and a reviewed policy for invalidating approvals when advertised tool definitions change.
