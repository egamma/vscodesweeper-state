## Summary

Still reproduces on main: the `branchSupport.enabled` setting is only checked when building option groups for new sessions — no `onDidChangeConfiguration` listener fires `_onDidChangeChatSessionProviderOptions` when it changes, so toggling the flag has no immediate effect.

## Change summary
