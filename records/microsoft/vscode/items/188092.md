# Issue #188092 — Command-W should not have different behavior based on editor context

[https://github.com/microsoft/vscode/issues/188092](https://github.com/microsoft/vscode/issues/188092)

## Summary

Keep this accepted default-keybinding request open: current macOS defaults still close an empty window with Command-W. The reporter confirmed the customization workaround but explicitly requested a default change, and the issue earned promotion to Backlog with sufficient community support.

## Change summary

Make the default macOS Command-W shortcut stop closing the application window when no editors remain.

## Best solution

Have the workbench owners decide whether Command-W should become editor-only by default on macOS, reconciling this request with the earlier intentional native-window behavior. Preserve explicit Close Window and Quit commands and user keybinding overrides.
