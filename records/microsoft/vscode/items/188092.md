# Issue #188092 — Command-W should not have different behavior based on editor context

[https://github.com/microsoft/vscode/issues/188092](https://github.com/microsoft/vscode/issues/188092)

## Summary

Keep this accepted Backlog request open and route it to window/keybinding owners. It has 23 community upvotes, and the configurable override does not satisfy the clarified request to change the macOS default.

## Change summary

Change the macOS default so Command-W does nothing, rather than closing the VS Code window, when no editors remain.

## Best solution

Decide whether to reverse the intentional macOS fallback in `src/vs/workbench/electron-browser/desktop.contribution.ts` while preserving `workbench.action.closeActiveEditor` and user keybinding customization. This needs a UX decision reconciling the accepted request with the behavior deliberately restored by https://github.com/microsoft/vscode/issues/126042.
