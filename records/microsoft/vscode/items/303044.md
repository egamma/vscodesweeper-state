# Issue #303044 — Support shipping TS-Go as a bundled extension with pre-release support

[https://github.com/microsoft/vscode/issues/303044](https://github.com/microsoft/vscode/issues/303044)

## Summary

Active team coordination issue for shipping TS-Go as a bundled extension. The auto-update infrastructure for built-in extensions has landed (commit 143b631d0c4), but the pre-release support for built-in extensions and the semver version-space problem with the VS Marketplace remain open questions — keeping open.

## Change summary

Bundle the new LSP-based TypeScript extension (TS-Go) into VS Code with support for pre-release builds via the marketplace.

## Best solution

Resolve the two open sub-problems: (1) enable pre-release version support for built-in extensions with auto-update (sandy081's proposal of locking release for stable / pre-release for Insiders), and (2) address the semver pre-release version-space limitation in the VS Marketplace so the TypeScript team can publish matching npm and extension versions without skipping numbers.
