# Issue #261512 — copilot chat session unresponsive

[https://github.com/microsoft/vscode/issues/261512](https://github.com/microsoft/vscode/issues/261512)

## Summary

Two reporters confirmed a workspace-specific failure that leaves Chat unable to create sessions, switch modes or models, or apply edits; deleting that workspace's persisted state restored operation. No verified canonical or issue-referencing fix owns this behavior, so the On Deck issue should remain open for current-version diagnosis.

## Change summary

A damaged or inconsistent workspace chat session can leave the entire Chat pane operationally stuck, including New Chat, mode/model selection, responses, and file edits.

## Best solution

Make loading and recovery of workspace-scoped chat state resilient so one invalid session cannot disable unrelated Chat controls or prevent creating a fresh session. Preserve recoverable history, isolate the invalid state, and expose a supported recovery path rather than requiring deletion of the whole workspace storage directory.
