[https://github.com/microsoft/vscode/issues/266114](https://github.com/microsoft/vscode/issues/266114)

## Summary

Keep this accepted Backlog request open: existing extension policies and bootstrap installation do not cover centralized, policy-driven deployment of both extensions and MCP servers. No verified older canonical issue or complete implementation was identified.

## Change summary

Allow enterprise administrators to centrally provision extensions and MCP servers without relying on individual recommendations, while avoiding unnecessary startup overhead.

## Best solution

Define the enterprise provisioning contract, distinguishing VS Code extension deployment from runtime-managed MCP availability and installation from execution. Reuse existing management channels where possible, and settle whether centrally configured remote servers satisfy the MCP requirement before adding a separate orchestration capability.
