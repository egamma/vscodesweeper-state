# Issue #195555 — Completion widget assigns too much space to details and not enough to the completion item label

[https://github.com/microsoft/vscode/issues/195555](https://github.com/microsoft/vscode/issues/195555)

## Summary

The layout concern remains on current main: completion details may consume up to 70% of a row, while the existing setting only hides inline details entirely. Keep this Backlog item open for UX discussion.

## Change summary

Reserve more completion-widget row space for the completion label and truncate detail text more aggressively.

## Best solution

Adjust the flex allocation in `src/vs/editor/contrib/suggest/browser/media/suggest.css` so the primary label retains a useful minimum share while long details truncate; UX should determine the appropriate ratio.
