# Issue #315762 — Agents: "Open in Agents Window" button is difficult to discover in VS Code

[https://github.com/microsoft/vscode/issues/315762](https://github.com/microsoft/vscode/issues/315762)

## Summary

Keep open for a discoverability design decision: current main offers Command Palette and chat title-menu entries, but these do not establish that the repeated usability-study finding is resolved. The team-authored issue has no verified duplicate or issue-referencing fix that meets the closure bar.

## Change summary

Make opening the Agents Window discoverable from expected chat or application-menu locations without disruptive title-bar expansion.

## Best solution

Provide an understandable, stable Agents Window entry point where users look for it, using the existing opening commands. Agree the chat/application-menu placement and title-bar presentation with the UX owner, then reassess discoverability against the reported usability tasks.
