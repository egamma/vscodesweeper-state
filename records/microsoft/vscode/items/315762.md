# Issue #315762 — Agents: "Open in Agents Window" button is difficult to discover in VS Code

[https://github.com/microsoft/vscode/issues/315762](https://github.com/microsoft/vscode/issues/315762)

## Summary

Still valid: the "Open in Agents Window" action lives primarily in the title bar (with a keybinding and chat title-bar menu entry), but the core request — placing it in the View menu or prominently in the chat panel for discoverability — has not been fully addressed. Repeated UX study findings (most recently June 2026) confirm the problem persists.

## Change summary

Users cannot find the "Open in Agents Window" button because it is placed only in the title bar icons, which is not an intuitive location.

## Best solution

Add the "Open in Agents Window" / "Open in Agents" action to the View menu and/or a prominent spot inside the chat panel so users can discover it without hunting through title bar icons. The relevant registration is in `src/vs/workbench/contrib/chat/electron-browser/agentSessions/agentSessionsActions.ts` — add a `MenuId.MenubarViewMenu` entry and/or surface it in the chat panel UI. The animation expansion behavior (comment #1, #3) should also be addressed as a separate polish item.
