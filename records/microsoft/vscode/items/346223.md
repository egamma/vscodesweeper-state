# Issue #346223 — "Set agent" dropdown disappears from chat when in agent mode

[https://github.com/microsoft/vscode/issues/346223](https://github.com/microsoft/vscode/issues/346223)

## Summary

The picker relocation is intentional, and the existing sessions.chat.experimental.agentsPickerInAttachContextMenu setting provides the reporter's explicitly requested alternative: disabling it keeps the picker in the toolbar when switching to Agent.

## Change summary

Keep the agent selector visible when switching between Ask and Agent, or provide a setting that preserves its toolbar placement.

## Best solution

Use the existing placement setting set to false to retain the visible toolbar selector. No new setting is needed; removing automatic experimentation would be a separate product decision.

  > Thanks for the report. Selecting the default Agent intentionally moves the selector into Add Context when `sessions.chat.experimental.agentsPickerInAttachContextMenu` is enabled. Set `"sessions.chat.experimental.agentsPickerInAttachContextMenu": false` in settings.json to keep the selector in the toolbar when switching between Ask and Agent; this provides the always-visible placement option you requested.
