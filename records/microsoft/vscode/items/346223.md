# Issue #346223 — "Set agent" dropdown disappears from chat when in agent mode

[https://github.com/microsoft/vscode/issues/346223](https://github.com/microsoft/vscode/issues/346223)

## Summary

The selector intentionally moves into Add Context when the default Agent is selected and the placement setting is enabled. An existing setting provides the requested always-visible toolbar behavior.

## Change summary

Keep the agent selector visible when switching from Ask to Agent, or provide a setting that does so.

## Best solution

Use "sessions.chat.experimental.agentsPickerInAttachContextMenu": false to retain the selector in the toolbar when switching modes.

- **Reason:** The requested mode visibility supports understandable, consistent chat interactions and is already configurable.
