# Issue #346223 — "Set agent" dropdown disappears from chat when in agent mode

[https://github.com/microsoft/vscode/issues/346223](https://github.com/microsoft/vscode/issues/346223)

## Summary

The picker relocation is intentional, and the existing setting already provides the reporter's requested alternative: keeping the dropdown visible. The discussion identifies that setting, and current source confirms its behavior.

## Change summary

Keep the Agent dropdown visible when switching from Ask to Agent, or provide a setting that preserves its toolbar position.

## Best solution

Use "sessions.chat.experimental.agentsPickerInAttachContextMenu": false to retain the toolbar dropdown. With relocation enabled, agent selection remains available through Add Context → Agent... and the existing keyboard shortcut.

  > Thanks for the report. When `sessions.chat.experimental.agentsPickerInAttachContextMenu` is enabled, selecting the default Agent intentionally moves the dropdown into **Add Context (+) → Agent...**. Set `"sessions.chat.experimental.agentsPickerInAttachContextMenu": false` in your settings to keep the dropdown in the toolbar when switching between Ask and Agent; this provides the always-visible option you requested.
