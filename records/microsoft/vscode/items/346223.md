# Issue #346223 — "Set agent" dropdown disappears from chat when in agent mode

[https://github.com/microsoft/vscode/issues/346223](https://github.com/microsoft/vscode/issues/346223)

## Summary

The default Agent picker intentionally moves into Add Context when an experimental setting is enabled. An existing setting provides the reporter's requested option to keep it visible.

## Change summary

Keep the agent selector visible when switching from Ask to the default Agent mode.

## Best solution

Set sessions.chat.experimental.agentsPickerInAttachContextMenu to false to retain the toolbar selector; no new setting or code change is needed for the requested behavior.
