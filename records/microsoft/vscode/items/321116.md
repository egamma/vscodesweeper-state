# Issue #321116 — Git: "Fetch (Prune)" should also prune local tags deleted from remote (--prune-tags)

[https://github.com/microsoft/vscode/issues/321116](https://github.com/microsoft/vscode/issues/321116)

## Summary

Keep open for discussion of an explicit tag-pruning UI option, rather than changing Fetch (Prune) unconditionally. Git already supports opt-in tag pruning through its configuration, but VS Code does not expose the requested dedicated command or setting.

## Change summary

Expose tag pruning during fetch so tags absent from the selected remote can be removed without manually running a fetch command.

## Best solution

Preserve the current safe default and consider a discoverable, explicit opt-in that respects Git's existing tag-pruning configuration. Any UI must explain that pruning can also delete locally created tags and tags belonging to other remotes.
