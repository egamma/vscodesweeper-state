# Issue #213911 — Can arrow symbol formatting be brought to non-mac devices?

[https://github.com/microsoft/vscode/issues/213911](https://github.com/microsoft/vscode/issues/213911)

## Summary

The requested cross-platform arrow-key symbols remain absent: current source still restricts symbolic labels to macOS. No existing setting or verified older canonical was found that covers this request, so it should remain open for a UI consistency decision.
