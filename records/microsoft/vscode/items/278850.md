# Issue #278850 — Prompts and instructions aren't syncing if non-default profile is used

[https://github.com/microsoft/vscode/issues/278850](https://github.com/microsoft/vscode/issues/278850)

## Summary

A real gap remains on current main: profiles can internally share the default profile's prompts directory, but the Profiles editor does not expose Prompts and Instructions as a selectable resource. The issue is already correctly routed and should remain open.

## Change summary

Allow non-default profiles to use and sync the default profile's prompt and instruction files.

## Best solution

Expose Prompts and Instructions in the Profiles editor's resource list and wire its checkbox to the existing `ProfileResourceType.Prompts` default-profile flag.

- **Reason:** Portable prompt and instruction configuration supports the AI-native editor and unified configuration experience.
