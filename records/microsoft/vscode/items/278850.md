# Issue #278850 — Prompts and instructions aren't syncing if non-default profile is used

[https://github.com/microsoft/vscode/issues/278850](https://github.com/microsoft/vscode/issues/278850)

## Summary

A real capability gap remains: prompts and instructions are profile-scoped resources and are not inherited or synchronized when a non-default profile uses data from the default profile. The request is parked in Backlog with limited demand, so it should remain open for product discussion rather than be treated as a broken existing guarantee.

## Change summary

Allow non-default profiles to inherit and synchronize prompts and instructions from the default profile.

## Best solution

Define prompts and instructions as shareable profile resources, then integrate them with profile inheritance and Settings Sync without changing the isolation semantics of unrelated profile resources.
