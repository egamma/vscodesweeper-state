# Issue #324296 — Github flavored markdown

[https://github.com/microsoft/vscode/issues/324296](https://github.com/microsoft/vscode/issues/324296)

## Summary

The Markdown team has established that GitHub-specific preview syntax should remain opt-in through extensions, and VS Code already exposes the markdown-it plugin mechanism needed to implement a complete GFM preview.

## Change summary

Add an optional GitHub-flavored Markdown preview mode, potentially enabled or suggested for repositories hosted on GitHub.

## Best solution

Provide GFM rendering through a Markdown extension that contributes markdown-it plugins and preview styles; core should retain its renderer-neutral default without GitHub-host detection or prompts.

## Vision fit

- **Fit:** rejected
- **Reason:** A provider-specific rendering mode that can be implemented through the existing extension API belongs in an extension rather than adding configuration and prompting to the default editor.
- **Evidence:** Values and guardrails: “The power lives in extensions” and capabilities that work through existing extension APIs should generally remain outside core.
