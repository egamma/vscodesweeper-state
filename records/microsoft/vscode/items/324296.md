# Issue #324296 — Github flavored markdown

[https://github.com/microsoft/vscode/issues/324296](https://github.com/microsoft/vscode/issues/324296)

## Summary

The built-in Markdown preview still has no configurable GitHub-flavor mode. Keep this broader request under discussion: existing alert support and extension workarounds do not cover the requested setting and repository-aware enablement.

## Change summary

Provide an optional GitHub-compatible Markdown preview mode, with automatic enablement or a prompt for GitHub-hosted repositories.

## Best solution

Have the Markdown owner decide whether GitHub-specific preview syntax should remain extension-provided or become an explicit built-in opt-in, and define which syntax that mode covers. Preserve existing defaults and consider repository detection separately from the rendering capability.
