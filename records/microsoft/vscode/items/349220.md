# Issue #349220 — In agents window default keybinding on Windows for Mark as Done is `del`. I expect `del` to be Delete

[https://github.com/microsoft/vscode/issues/349220](https://github.com/microsoft/vscode/issues/349220)

## Summary

The current source explicitly binds Delete to Archive/Mark as Done in the Agents Window session list, while permanent deletion has no default shortcut. Keep this team-authored request open as a keyboard-consistency improvement, not a broken command implementation.

## Change summary

Make the Windows Delete key delete a session rather than mark it as done.

## Best solution

Align the session-list Delete shortcut with the existing confirmed deletion action, preserving capability checks, multi-selection, and input-focus protection. Keep Archive/Mark as Done separately accessible.
