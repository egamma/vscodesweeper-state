# Issue #335005 — Agents window: allow rebinding submit key in new-session composer (Ctrl+Enter)

[https://github.com/microsoft/vscode/issues/335005](https://github.com/microsoft/vscode/issues/335005)

## Summary

Well-diagnosed request for the new Agents window (Sessions) composer: the submit/background-submit handling is confirmed on main to still live in a raw `onKeyDown` listener with hardcoded `!e.ctrlKey` guards rather than going through the keybinding system, so it can't be rebound the way `workbench.action.chat.submit` can once a session exists.

## Change summary

Let users rebind the Agents window's new-session composer submit action (e.g. to Ctrl+Enter) via the keybinding system instead of a hardcoded Enter/Alt+Enter-only handler.

## Best solution

Register the composer's send/send-in-background actions as commands with default keybindings scoped to the existing `inChatComposer` context key (already bound at newChatInput.ts:628), mirroring how `workbench.action.chat.submit` works for the in-session chat input; this belongs in src/vs/sessions/contrib/chat/browser/newChatInput.ts.
