# Issue #184679 — Fuzzy search not working well in Recent Folders quickpick in 1.79.0

[https://github.com/microsoft/vscode/issues/184679](https://github.com/microsoft/vscode/issues/184679)

## Summary

The regression was confirmed and diagnosed by a quick-pick maintainer: Recent Folders split the folder and remote host across label and description, while filtering no longer combines those fields. No fixing commit or verified older canonical is identified, so the Backlog issue should remain open.

## Change summary

Restore fuzzy matching in Recent Folders so a query containing both a folder name and remote host can find the corresponding remote folder.

## Best solution

Define and test consistent multi-field matching for quick-pick items so Recent Folders can match a query across its label and description without regressing ranking in other pickers.
