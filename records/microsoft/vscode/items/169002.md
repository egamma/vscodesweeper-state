# Issue #169002 — Editor triggers keyboard open on scroll on mobile

[https://github.com/microsoft/vscode/issues/169002](https://github.com/microsoft/vscode/issues/169002)

## Summary

Still present on main: the PointerEventHandler's onTap calls focusTextArea() which opens the virtual keyboard on mobile; if the Gesture system's 30px movement threshold is too generous for fast flick-scrolls, a scroll gesture can be misclassified as a tap, triggering the keyboard. Team member hediet confirmed this on vscode.dev with Android and Surface. No fix commit references this issue.

## Change summary

On mobile (Android/Surface), touch-scrolling through a file can trigger the virtual keyboard to open because the gesture system misclassifies a scroll as a tap.

## Best solution

Tighten the tap detection in the Gesture class (src/vs/base/browser/touch.ts) — either reduce the 30px movement threshold or add velocity-based discrimination — so that flick-scroll gestures are not classified as taps, preventing the unwanted focusTextArea() call that opens the virtual keyboard.
