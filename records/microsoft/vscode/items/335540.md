# Issue #335540 — Inter-session communication should use steering messages

[https://github.com/microsoft/vscode/issues/335540](https://github.com/microsoft/vscode/issues/335540)

## Summary

Current main still queues inter-session messages behind a busy target, so a long-running turn can prevent agent-to-agent guidance from being observed. The behavior is directly traceable and should remain open under the Agents Window area.

## Change summary

Deliver inter-session messages as steering while the destination agent is actively working instead of waiting for its turn to finish.

## Best solution

A busy destination should receive the first inter-session message through its existing steering path, while preserving pending-message ordering and avoiding replacement of an already outstanding steering message.
