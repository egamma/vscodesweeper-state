# Issue #102650 — Allow tooltips/hovering on symbols in outline view and breadcrumbs

[https://github.com/microsoft/vscode/issues/102650](https://github.com/microsoft/vscode/issues/102650)

## Summary

Still unimplemented: DocumentSymbol has no tooltip property, and the outline/breadcrumbs views do not surface hover information from the document's HoverProvider. The request remains valid.

## Change summary

Allow symbols in the outline view and breadcrumbs to display tooltips — either via a new DocumentSymbol.tooltip property or by triggering the document's HoverProvider on hover.

## Best solution

Add a `tooltip` property to the DocumentSymbol API (similar to TreeItem.tooltip) and surface it in the outline tree and breadcrumb renderers. A second, more ambitious phase could optionally invoke HoverProviders for richer hover content. This likely touches the extension API (vscode.d.ts), extHostTypes, the outline tree renderer, and the breadcrumb widget.
