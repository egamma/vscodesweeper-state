# Issue #200511 — Expose API/configuration to add supported language IDs for `typescript-language-features`

[https://github.com/microsoft/vscode/issues/200511](https://github.com/microsoft/vscode/issues/200511)

## Summary

Valid feature request for a dynamic API to register supported language IDs in typescript-language-features. The existing static `contributes.typescriptServerPlugins` mechanism partially covers this but lacks the runtime flexibility needed by Vue/Astro/MDX/Svelte extensions migrating to TS plugins. Not yet implemented on main.

## Change summary

Expose an API or configuration to dynamically add supported language IDs to the TypeScript language features extension at runtime.

## Best solution

Extend `getAPI()` in `extensions/typescript-language-features/src/api.ts` to expose an `addSupportedLanguageMode()` method (or similar) that dynamically registers language providers via `registerExtensionLanguageProvider()` in the client host, so TS-plugin-based extensions (Vue, Astro, MDX, Svelte) can register their languages without hacky workarounds. Alternatively, improve the existing `contributes.typescriptServerPlugins` contribution point to better serve these use cases.
