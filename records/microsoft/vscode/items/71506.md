- **Discussion identifies the same work:** The final supplied comment asks whether this duplicates https://github.com/microsoft/vscode/issues/42785. The older issue's https://github.com/microsoft/vscode/issues/42785#issuecomment-494915420 also explicitly says implementing this request would solve that report.
- **Existing capability does not satisfy the request:** In src/vs/editor/common/cursor/cursorDeleteOperations.ts, DeleteOperations.getDeleteLeftRange deletes back to the preceding indentation tab stop when editor.useTabStops is enabled; getPositionAfterDeleteLeft crosses to the previous line only from column 1. Disabling useTabStops instead deletes individual characters. In src/vs/editor/contrib/linesOperations/browser/linesOperations.ts, deleteAllLeft deletes to column 1 and crosses the newline only when already at column 1, so it does not provide the requested single-Backspace behavior.
