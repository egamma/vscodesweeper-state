# Issue #246158 — `ctrl+space` keybinding shouldn't toggle checkbox in quick pick

[https://github.com/microsoft/vscode/issues/246158](https://github.com/microsoft/vscode/issues/246158)

## Summary

Keep this accepted keyboard-interaction bug open. The maintainer confirmed the checkbox conflict, and current source still contains modified-Space interception paths; no verified fixing commit or older same-symptom canonical was found.

## Change summary

Ctrl+Space in a multi-select Quick Pick should toggle an available item hover without changing checkbox selection.

## Best solution

Make the Quick Pick hover shortcut leave checked items unchanged across relevant focus targets, while preserving ordinary Space selection. First establish the current DOM focus and keyboard-event path so the correction does not alter unrelated tree or toggle behavior.

- **Behavior:**
