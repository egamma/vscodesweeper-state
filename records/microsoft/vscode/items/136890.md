## Change summary

Allow users to open Bitbucket.org repositories directly in vscode.dev through Open Remote Repository.

## Best solution

Deliver a browser-compatible Bitbucket repository provider integrated with the Remote Repositories experience, preserving consistent repository browsing and editing across providers. Determine the provider integration contract with the Remote Repositories owners rather than treating local cloning or remote compute as equivalent support.
