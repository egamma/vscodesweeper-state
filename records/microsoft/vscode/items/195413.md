# Issue #195413 — indicate the number of available completions in inline completions accessible view aria label

[https://github.com/microsoft/vscode/issues/195413](https://github.com/microsoft/vscode/issues/195413)

## Summary

The accessible view still does not expose the inline completion count or current index, although navigation queries the alternatives. Keep this team-authored request open for a decision on announcement placement and when to incur the additional query.

## Change summary

Expose the number of available inline completions and the current suggestion index to screen reader users in Accessible View.

## Best solution

Provide accurate completion-position information in the inline completions accessible view without obscuring suggestion content or adding unnecessary provider requests. Settle whether enumeration happens on opening the view or only through explicit navigation, and whether the information belongs in the ARIA label or after the content.
