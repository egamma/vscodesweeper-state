# Issue #299744 — Repository picker buggy after adding keyboard shortcut

[https://github.com/microsoft/vscode/issues/299744](https://github.com/microsoft/vscode/issues/299744)

## Summary

The screenshot identifies a built-in SCM Graph toolbar layout defect, and the triggering path remains in current source: assigning a shortcut adds a second row beneath the repository label. Keep this open for the SCM owner; no verified fix or matching canonical was found.

## Change summary

Assigning a keyboard shortcut to the SCM Graph repository picker causes its header control to overflow and overlap the graph.

## Best solution

Keep the repository picker within the Graph header’s normal toolbar layout when a shortcut is assigned, preserving repository selection, shortcut execution, and discoverability without changing shared action-bar behavior unnecessarily.
