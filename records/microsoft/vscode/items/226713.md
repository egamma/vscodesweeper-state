# Issue #226713 — Not fully clear why `export type TextSearchResultNew = TextSearchMatchNew | TextSearchContextNew;`

[https://github.com/microsoft/vscode/issues/226713](https://github.com/microsoft/vscode/issues/226713)

## Summary

Keep open: the proposed search API still streams matches and context separately, and the discussion has not settled the consumer-facing association and ordering contract. The maintainer's explanation establishes the provider-side rationale, but does not resolve the API usability concern.

## Change summary

Clarify whether text-search context should be associated directly with matches and what ordering consumers can rely on.

## Best solution

Have the search API owners settle the result-shape and ordering contract before stabilization, then document how consumers associate shared context with matches. Coordinate with the existing stabilization trackers without treating those broader work items as duplicates of this unresolved design question.
