# Issue #297509 — Selection is invisible in solarized light theme

[https://github.com/microsoft/vscode/issues/297509](https://github.com/microsoft/vscode/issues/297509)

## Summary

Still reproduces on main: `editor.selectionBackground` in Solarized Light is #EEE8D5, nearly identical to the theme background #FDF6E3, making text selection invisible. An open PR exists but has not merged.

## Change summary

Text selection is invisible in the built-in Solarized Light theme because the selection background color has almost no contrast against the editor background.

## Best solution

Land a fix that changes `editor.selectionBackground` in `extensions/theme-solarized-light/themes/solarized-light-color-theme.json` to a color with adequate contrast. PR https://github.com/microsoft/vscode/pull/301572 is an existing attempt — review and merge it, or apply a similar fix.
