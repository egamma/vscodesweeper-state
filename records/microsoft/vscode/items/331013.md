# Issue #331013 — New UI: Uneven padding around panel title tabs

[https://github.com/microsoft/vscode/issues/331013](https://github.com/microsoft/vscode/issues/331013)

## Summary

Real, well-diagnosed Modern UI visual bug — the panel title bar's border-top-width consumes an extra layout pixel, offsetting the 32px pill from the 4px gutter used by editor tabs. An open PR already fixes it with `Fixes #331013`, so this should stay open until that PR lands rather than being closed now.

## Change summary

Panel title tabs (Problems, Terminal, etc.) in the Modern UI have uneven outer padding and a hover bounding box that doesn't match editor tabs, due to inconsistent border/gutter sizing.

## Best solution

Land and merge https://github.com/microsoft/vscode/pull/331612, which sets `border-top-width: 0` on `.part.panel.bottom .composite.title` under Modern UI to restore the same 4px gutter used by editor tabs; close this issue once that PR merges.
