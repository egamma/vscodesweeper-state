# Issue #309661 — YAML support for VSCode tasks

[https://github.com/microsoft/vscode/issues/309661](https://github.com/microsoft/vscode/issues/309661)

## Summary

The requested YAML fallback remains unsupported, but it is covered by an explicit maintainer decision against maintaining parallel JSON/YAML configuration formats, reaffirmed in 2022. Propose closing on that scope precedent, not because of age or insufficient upvotes.

## Change summary

Support tasks.yml when tasks.json is absent, allowing YAML anchors to reduce repeated task configuration.

## Best solution

Retain JSON/JSONC as the built-in task configuration format under the established configuration-format decision; adding YAML fallback would require maintainers to explicitly revisit that decision.

## Vision fit

- **Fit:** rejected
- **Reason:** Maintaining a second built-in configuration format cuts against the lean, uniform experience and maintenance rationale established for configuration files.
- **Evidence:** Public values: "Out of the box, VS Code is a text editor: lightweight and fast" and "Simple, uniform UI and UI interactions."
