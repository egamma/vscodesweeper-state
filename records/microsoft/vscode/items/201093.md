# Issue #201093 — Join Lines should not include the line after the last fully selected line

[https://github.com/microsoft/vscode/issues/201093](https://github.com/microsoft/vscode/issues/201093)

## Summary

Still reproduces on main: JoinLinesAction uses `selection.endLineNumber` without checking whether the cursor sits at column 1 of that line (a full-line select via Shift+Down), so it joins one extra line. An open PR exists to fix it.

## Change summary

Join Lines includes the line after the last fully selected line when the selection ends at column 1.

## Best solution

Land https://github.com/microsoft/vscode/pull/318075, which adjusts the end-line calculation to exclude the trailing line when `selection.endColumn === 1`. The fix is small and localized in `JoinLinesAction.run`.
