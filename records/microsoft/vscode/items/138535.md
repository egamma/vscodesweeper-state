# Issue #138535 — Allow better progress notifications (eg. percentage/text status) for progress notifications VS code shows during events like willRenameFiles etc.

[https://github.com/microsoft/vscode/issues/138535](https://github.com/microsoft/vscode/issues/138535)

## Summary

A real API and UX gap remains on current main, and this accepted Backlog request has exceeded the 20-upvote threshold. The existing notification cannot receive participant progress, so extensions must create a second notification.

## Change summary

Allow file-operation participants to report percentage and status through VS Code's existing progress notification, or suppress that notification when participants provide their own.

## Best solution

Extend the file-operation participant bridge so `onWillRenameFiles` and sibling events can report progress into the existing `IProgressService` notification, while preserving its cancellation and timeout behavior. It should also expose which extension is currently running where practical.
