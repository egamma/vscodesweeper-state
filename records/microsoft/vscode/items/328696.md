# Issue #328696 — Terminal sends `\x1b[<0;NaN;NaNm` to the pty when a file link is activated by ctrl+click

[https://github.com/microsoft/vscode/issues/328696](https://github.com/microsoft/vscode/issues/328696)

## Summary

Well-diagnosed bug with an open fixing PR already linked (`Fixes #328696`); the fix hasn't merged yet, so this stays open pending review/landing of that PR rather than being closed now.

## Change summary

Ctrl+click-activating a terminal link while mouse reporting is enabled sends a malformed `NaN` SGR mouse report to the pty, injecting garbage bytes into the shell's input buffer.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/328707, which adds `stopImmediatePropagation()` in TerminalLinkManager's link activation handlers (src/vs/workbench/contrib/terminalContrib/links/browser/terminalLinkManager.ts) to stop xterm.js's mouse tracking from processing the same event after a link is activated.
