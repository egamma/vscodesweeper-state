# Issue #328696 — Terminal sends `\x1b[<0;NaN;NaNm` to the pty when a file link is activated by ctrl+click

[https://github.com/microsoft/vscode/issues/328696](https://github.com/microsoft/vscode/issues/328696)

## Summary

Keep open while the linked fixes are reviewed. The malformed mouse-report encoding is owned by xterm.js, with an open upstream coordinate-validation fix and an open VS Code link-activation fix explicitly referencing this report.

## Change summary

Prevent modifier-clicking a file link in an editor-area terminal from sending malformed SGR mouse reports into the shell input buffer.

## Best solution

Ensure xterm.js never encodes non-finite mouse coordinates, and review whether VS Code link activation also needs event suppression without disrupting ordinary TUI mouse input. Review https://github.com/microsoft/vscode/pull/328707 alongside https://github.com/xtermjs/xterm.js/pull/6204 before treating this report as resolved.
