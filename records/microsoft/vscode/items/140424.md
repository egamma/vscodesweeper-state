# Issue #140424 — Webview find doesn't play nicely with keyboard

[https://github.com/microsoft/vscode/issues/140424](https://github.com/microsoft/vscode/issues/140424)

## Summary

Still reproduces on main: the webview find widget's `hasFindResult` callback unconditionally calls `this.focusFindBox()`, which steals focus from the next/previous buttons after each find operation. The issue remains valid and correctly labeled as `help wanted`.

## Change summary

Webview find next/previous via keyboard skips results and clicking the buttons steals focus back to the input box.

## Best solution

Guard the `focusFindBox()` call in `WebviewFindWidget`'s `hasFindResult` handler so it only moves focus when the find input already has focus (not when triggered via button clicks). The fix belongs in `src/vs/workbench/contrib/webview/browser/webviewFindWidget.ts`.
