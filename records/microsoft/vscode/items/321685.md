# Issue #321685 — Agents window: Allow customization of branch name prefix for worktree branches

[https://github.com/microsoft/vscode/issues/321685](https://github.com/microsoft/vscode/issues/321685)

## Summary

Keep open: git.branchPrefix now supports a user prefix, but generated branches still include the mandatory agents/ segment and branch naming does not consult AGENTS.md. This partially addresses the request without delivering the reported <username>/<topic> convention; neither verified related issue owns that remaining work.

## Change summary

Allow Agents-window worktree branches to follow a configurable naming convention instead of always including agents/.

## Best solution

Provide a supported way to produce worktree branch names such as <username>/<topic>, while retaining existing naming by default. A maintainer should decide whether the naming contract is explicit configuration or instruction-driven before implementation.
