# Issue #321685 — Agents window: Allow customization of branch name prefix for worktree branches

[https://github.com/microsoft/vscode/issues/321685](https://github.com/microsoft/vscode/issues/321685)

## Summary

Valid feature request: the worktree branch prefix `agents/` is hardcoded in `CopilotBranchNameGenerator` with no user-facing configuration. The reporter wants to honor custom branch-naming conventions (e.g. `<username>/<topic>`) via AGENTS.md or a setting.

## Change summary

Allow users to customize the branch name prefix used when creating worktree branches in the Agents window, instead of the hardcoded `agents/` prefix.

## Best solution

Add a configurable branch-name prefix (or template) — either as a VS Code setting or honored from AGENTS.md instructions — in `CopilotBranchNameGenerator`. The constant `COPILOT_BRANCH_PREFIX` in `src/vs/platform/agentHost/node/copilot/copilotBranchNameGenerator.ts` and its consumers in `_buildBranchName` would need to read from configuration rather than being a compile-time constant. The worktree-name helper `getCopilotWorktreeName` in `copilotAgent.ts` should also handle arbitrary prefixes.
