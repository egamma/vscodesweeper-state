# Issue #264748 — Terminal suggest descriptions are only visible in the flyout

[https://github.com/microsoft/vscode/issues/264748](https://github.com/microsoft/vscode/issues/264748)

## Summary

Still open on main: flag doc strings in terminal suggest are passed as `documentation` (flyout-only) rather than `detail` (visible in the row). The team-authored issue with a clear suggestion from meganrogge to set it as detail instead of description remains unaddressed.

## Change summary

Terminal suggest flag descriptions (from man pages) are only visible in the flyout panel, not in the completion row itself.

## Best solution

In the terminal suggest completion pipeline, move the flag doc strings from the `documentation` field to the `detail` field (which renders on the right side of the completion row) so they are visible without opening the flyout. The fix likely involves `extensions/terminal-suggest/src/helpers/completionItem.ts` and possibly the fig integration in `extensions/terminal-suggest/src/fig/figInterface.ts`. roblourens also requested showing the long flag equivalent (e.g. `--text`) alongside short flags.
