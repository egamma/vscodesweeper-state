# Issue #264748 — Terminal suggest descriptions are only visible in the flyout

[https://github.com/microsoft/vscode/issues/264748](https://github.com/microsoft/vscode/issues/264748)

## Summary

Keep open: current source still puts flag descriptions exclusively in flyout documentation, while a maintainer explicitly endorsed making them visible as row details. This is a bounded discoverability improvement, not a failure of the existing documentation renderer.

## Change summary

Expose terminal flag descriptions in collapsed suggestion rows and make corresponding long-form flags discoverable.

## Best solution

Make flag help available as secondary information in terminal suggestion rows, preserving argument signatures, completion insertion behavior, and access to full documentation. Surface long-form equivalents when the completion specification supplies them.
