# Issue #158546 — need region support in code-search formate file

[https://github.com/microsoft/vscode/issues/158546](https://github.com/microsoft/vscode/issues/158546)

## Summary

Keep this accepted, community-supported request open: Search Result files still lack explicit region-folding support. Existing selection-based folding is a partial workaround, and the canonical search found no verified older issue covering the same request.

## Change summary

Support collapsible regions in .code-search files to organize call-graph and stack analysis.

## Best solution

Support explicit regions through the bundled Search Result language features, using standard editor folding rather than a separate UI. Agree on the region syntax and its interaction with search-result content before implementation.
