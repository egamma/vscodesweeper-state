## Summary

The "Detecting Kernels" spinner is VS Code core UI reflecting that the Jupyter extension's kernel detection task never completes. The root cause — why detection hangs — lives in the Jupyter extension (microsoft/vscode-jupyter), not in VS Code core. The reporter's environment (Anaconda on ARM Windows with frozen envs) points to an extension-side detection issue.
