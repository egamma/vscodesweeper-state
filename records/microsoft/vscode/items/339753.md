# Issue #339753 — Copilot keep prompting for sign in when using GHE (github enterprise)

[https://github.com/microsoft/vscode/issues/339753](https://github.com/microsoft/vscode/issues/339753)

## Summary

Keep open: multiple reporters confirm that opening another window prompts already-authenticated windows to sign in. The October 11 fix helped some users, but the October 21 report reproduces the same behavior on 1.143.0 and confirms that the suggested account-reset workarounds did not help.

## Change summary

Opening a new VS Code window unnecessarily displays Copilot sign-in dialogs in existing windows despite valid GitHub Enterprise authentication.

## Best solution

Ensure cross-window account initialization and session replacement preserve working Copilot authentication without interactive prompts. Diagnose the remaining 1.143.0 case before treating the earlier enterprise-endpoint fix as complete.
