# Issue #339753 — Copilot keep prompting for sign in when using GHE (github enterprise)

[https://github.com/microsoft/vscode/issues/339753](https://github.com/microsoft/vscode/issues/339753)

## Summary

Real, reproducible regression: Copilot's spurious 'sign in' prompt — previously addressed for 1.139.0/1.140.0 (now-closed #336407 and #337562) — recurs under a specific multi-window trigger (a second VS Code window finishing extension activation while a first window is focused), and multiple independent reporters confirm it with clear repro steps; GHE-specific accounts seem especially affected.

## Change summary

Copilot repeatedly shows a 'sign in to use GitHub Copilot' prompt even though the user is already signed in via GHE, especially when multiple VS Code windows are open.

## Best solution

Trace why the chat entitlement/sign-in state recheck re-triggers a 'not signed in' prompt in an already-signed-in window once a second window finishes extension activation — likely a cross-window entitlement/account-state resync race in chatEntitlementService.ts or chatSetupContributions.ts — and fix the race instead of just the prompt gating.
