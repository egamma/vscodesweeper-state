# Issue #339753 — Copilot keep prompting for sign in when using GHE (github enterprise)

[https://github.com/microsoft/vscode/issues/339753](https://github.com/microsoft/vscode/issues/339753)

## Summary

Thanks for the report. This looks like a regression that persists after the 1.139.0 and 1.140.0 fixes: several independent users on GHE and GHEC-DR still get a repeated Copilot sign-in prompt, and one gives a concrete multi-window repro. It stays open and is routed to the authentication area.

## Change summary

Copilot repeatedly prompts for sign-in with a GitHub Enterprise account even though the user is already signed in, notably when additional VS Code windows are opened.

## Best solution

Find why the first window loses or does not see the GHE session when another window's extensions activate. Likely suspects are the auth session change or sync events across windows and the Copilot sign-in prompt logic. Then make the prompt appear only when no valid GHE session exists. A maintainer should decide whether to reopen the earlier closed issues or track the remaining case here.
