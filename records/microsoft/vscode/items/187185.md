# Issue #187185 — Shell integration breaks prompt when using Fish shell with Tide prompt

[https://github.com/microsoft/vscode/issues/187185](https://github.com/microsoft/vscode/issues/187185)

## Summary

Still reproduces on main: the `functions --copy fish_prompt __vsc_fish_prompt` call in shellIntegration.fish (line 157) copies only the function body, losing file-scope variables that prompts like Tide and Hydro depend on. No fix has landed.

## Change summary

VS Code's Fish shell integration breaks third-party prompts (Tide, Hydro, Pure, custom) that rely on file-scoped variables, because `functions --copy` duplicates only the function body, not its lexical scope.

## Best solution

Replace the `functions --copy` approach in `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.fish` with a wrapper that calls the original `fish_prompt` by reference rather than copying it — e.g., using `functions --wrap` (Fish 3.x+) or aliasing via `emit` — so file-scope variables and event bindings survive. The `help wanted` label is appropriate; this is a good community contribution target.
