# Issue #172165 — Completion toolbar not accessible

[https://github.com/microsoft/vscode/issues/172165](https://github.com/microsoft/vscode/issues/172165)

## Summary

Keep open: the always-visible inline completion toolbar still lacks a dedicated keyboard focus entry point. The existing hover command covers the on-hover mode, not the remaining capability acknowledged by the maintainer.

## Change summary

Provide keyboard access to the inline completion toolbar, followed by standard arrow-key navigation and action activation.

## Best solution

Make the always-visible inline completion toolbar directly reachable from the editor by a discoverable keyboard command, preserving the suggestion while its actions are used. Retain the existing on-hover behavior and standard toolbar navigation.

- **Trace:**
