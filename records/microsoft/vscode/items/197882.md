# Issue #197882 — The focused setting should remain in view after clicking "Clear Settings Search Input" 

[https://github.com/microsoft/vscode/issues/197882](https://github.com/microsoft/vscode/issues/197882)

## Summary

Keep open: clearing Settings search still has no explicit preservation of the selected setting's browsing context. The request is already correctly routed and accepted into Backlog; no verified canonical or fixing commit was found.

## Change summary

Preserve the focused setting and its surrounding category when clearing Settings search so users can browse neighboring settings.

## Best solution

Preserve a meaningful setting anchor when transitioning from filtered results to unfiltered settings in SettingsEditor2, allowing users to browse neighboring settings without finding the category again. Define keyboard-focus behavior separately from keeping that setting visible.
