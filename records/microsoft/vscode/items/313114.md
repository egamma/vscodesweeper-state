# Issue #313114 — Agents: Provide option to pin entire workspaces

[https://github.com/microsoft/vscode/issues/313114](https://github.com/microsoft/vscode/issues/313114)

## Summary

Keep open: current workspace reordering provides persistent placement and visibility, but does not expose an explicit workspace pin/unpin option. This team-authored Backlog request has neither a verified canonical duplicate nor an issue-referencing fix that would justify closing it.

## Change summary

Allow users to pin an entire workspace in the Agents Window session list rather than pinning individual sessions.

## Best solution

Define explicit workspace pinning semantics in the Sessions list, accounting for the existing persisted workspace ordering and promotion behavior. Preserve individual session pins as a separate capability.
