# Issue #313114 — Agents: Provide option to pin entire workspaces

[https://github.com/microsoft/vscode/issues/313114](https://github.com/microsoft/vscode/issues/313114)

## Summary

Valid feature request from a team member. The Agents window currently supports pinning individual sessions (via `pinSession`/`unpinSession` in `sessionsListModelService`) but has no workspace-level pinning. The capability gap is confirmed on current main — no workspace pinning code exists.

## Change summary

Allow users to pin an entire workspace group (not just individual sessions) in the Agents window session list.

## Best solution

Extend the session list model (`sessionsListModelService`) and the workspace section UI to support pinning a workspace group, which would pin all its sessions collectively and keep the workspace section persistently visible/promoted. The likely implementation area is `src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts` (workspace section rendering and pinning logic) and `src/vs/sessions/services/sessions/browser/sessionsListModelService.ts` (pin state persistence).
