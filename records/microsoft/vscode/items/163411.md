# Issue #163411 — Quick input list dom nodes hang around after quick input dismissed

[https://github.com/microsoft/vscode/issues/163411](https://github.com/microsoft/vscode/issues/163411)

## Summary

The cleanup remains necessary: current main hides quick input without clearing its rendered list, and the previous fix was reverted. Keep this open for bounded lifecycle cleanup that preserves picker events, focus, and close animations.

## Change summary

Release obsolete quick-input list content after dismissal rather than retaining it until another quick input opens.

## Best solution

Clear the dismissed picker's rendered list after its visible lifecycle ends, without changing acceptance, selection, focus restoration, or picker reuse. Preserve closing animations and ensure cleanup cannot affect a replacement picker opened by a hide callback.
