# Issue #203288 — Allow the user to choose the default view for sidebars and panels

[https://github.com/microsoft/vscode/issues/203288](https://github.com/microsoft/vscode/issues/203288)

## Summary

User-selectable startup views remain missing: current source still overrides a remembered SCM selection on normal primary-sidebar startup. Keep this accepted Backlog request open for a layout design decision; related reports have already been consolidated here.

## Change summary

Let users choose which view container opens by default in each sidebar and the panel, including an option to restore the last active container.

## Best solution

Provide a consistent startup-view preference for the primary sidebar, secondary sidebar, and panel, supporting an explicit container or the last active selection. Settle the default and persistence semantics with the layout maintainer while preserving existing behavior for users who do not opt in.
