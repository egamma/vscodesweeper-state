# Issue #203288 — Allow the user to choose the default view for sidebars and panels

[https://github.com/microsoft/vscode/issues/203288](https://github.com/microsoft/vscode/issues/203288)

## Summary

The requested configurability remains absent on current main, and this is the canonical Backlog issue for choosing or restoring the initial view container. Maintainers have supported remembering the selection per workspace, so it should remain open.

## Change summary

Let users choose a default view container, or restore the last active one, when opening a workspace.

## Best solution

Add a window-scoped workbench setting for each part's initial view container, supporting a fixed container ID and last-active behavior, then consume it during startup restoration in `src/vs/workbench/browser/layout.ts`.
