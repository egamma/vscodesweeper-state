# Issue #186866 — SIngle terminal tabs is re-rendered several times on start up

[https://github.com/microsoft/vscode/issues/186866](https://github.com/microsoft/vscode/issues/186866)

## Summary

This is the single-tab variant of the same report Tyriar filed 38 minutes earlier as the general multi-tab case; the older issue owns the broader scope (2 and 3 tabs) and this narrower single-tab observation is a subset of it, so a duplicate close consolidates the discussion.

## Change summary

On startup, TerminalViewPane.createActionViewItem (via the Focus/single-tab action) is invoked repeatedly, re-creating the single terminal tab's action view item multiple times and triggering dispose warnings.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/186862, which documents the same TerminalViewPane re-render behavior for 2 and 3 tabs and already carries the assignment (meganrogge) and milestone; fixing the toolbar-refresh logic there (avoid recreating the SingleTerminalTabActionViewItem/menu action view items on every refresh) covers the 1-tab case too.
