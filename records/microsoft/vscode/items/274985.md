# Issue #274985 — Chat: Opening todos should scroll to current in-progress item

[https://github.com/microsoft/vscode/issues/274985](https://github.com/microsoft/vscode/issues/274985)

## Summary

Keep open: the current todo drawer still opens without revealing the in-progress item, so completed tasks can occupy the entire initial viewport. The existing collapsed-title preview does not satisfy the request to see current and upcoming work together.

## Change summary

Opening a long chat todo drawer should reveal the in-progress task and nearby upcoming tasks instead of only completed tasks.

## Best solution

Make opening the chat todo drawer orient its viewport around the current in-progress item, with upcoming work visible where space permits. Preserve task ordering, access to completed tasks, and existing keyboard-focus behavior.
