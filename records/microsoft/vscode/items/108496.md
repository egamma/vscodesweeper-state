# Issue #108496 — Badges for extension activity bar icons

[https://github.com/microsoft/vscode/issues/108496](https://github.com/microsoft/vscode/issues/108496)

## Summary

The requested extension activity-bar count badges are available through the stable TreeView.badge and WebviewView.badge APIs. Propose closing as completed; the API was finalized and documented in VS Code 1.72.

## Change summary

Allow extensions to display a numeric badge on their activity-bar icon to indicate actionable items without opening the view.

## Best solution

Use TreeView.badge or WebviewView.badge with a ViewBadge containing value and tooltip; the existing implementation forwards this badge to the view container's activity-bar icon.

- **Reason:** Exposing the existing badge mechanism to extensions supports the extension ecosystem while preserving uniform workbench interactions.
