# Issue #332794 — Chat marked as "Done" disappears from Sessions view with no filter to restore it

[https://github.com/microsoft/vscode/issues/332794](https://github.com/microsoft/vscode/issues/332794)

## Summary

Traced the exact flow in current main and the described gap doesn't hold: marking a session done just sets `isArchived`, which is hidden only because the 'exclude archived' filter defaults on — there is a dedicated toggle in the same filter-funnel menu (labeled to match the archive wording, i.e. 'Done' when the Mark-as-Done wording is active) that reveals it, plus a Restore/Unarchive action once visible.

## Change summary

A session marked 'Done' vanishes from the Sessions view with no apparent way to filter it back in or un-mark it.

## Best solution

Point the reporter at the archived/'Done' toggle in the filter funnel menu (registered in src/vs/sessions/contrib/sessions/browser/views/sessionsView.ts `registerStatusFilters`/`registerArchivedFilter`) and the Restore command (`RestoreArchivedSessionAction`/`RestoreActiveSessionAction` in sessionsViewActions.ts) — both already exist on current main and are wired through the same `chat.experimental.sessionArchiveActionWording` setting the reporter's build was flighted into.
