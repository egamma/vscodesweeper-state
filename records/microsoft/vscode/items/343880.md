## Change summary

Switching from Manual permissions to Allow all while an approval is pending prevents approving that prompt by voice.

## Best solution

Ensure changing permission modes cannot strand an outstanding approval: if it remains pending, an explicit spoken approval must still resolve that occurrence. First reproduce the transition and determine whether pending-state publication, occurrence identity, or response dispatch loses synchronization.
