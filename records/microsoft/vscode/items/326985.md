# Issue #326985 — Context Annotations and Context Groups for Copilot Chat Attachments

[https://github.com/microsoft/vscode/issues/326985](https://github.com/microsoft/vscode/issues/326985)

## Summary

This is a distinct, actionable feature request for structured attachment metadata and grouping. Current source supports individual attachment descriptions but no user-editable annotations or groups, and no open canonical issue was found.

## Change summary

Allow Copilot Chat users to annotate individual context attachments and organize related attachments into named groups.

## Best solution

Design attachment-level notes and groups as first-class chat request metadata, including editing, rendering, persistence, and model serialization across file, folder, symbol, and selection attachments.
