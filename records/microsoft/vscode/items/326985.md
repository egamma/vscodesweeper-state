# Issue #326985 — Context Annotations and Context Groups for Copilot Chat Attachments

[https://github.com/microsoft/vscode/issues/326985](https://github.com/microsoft/vscode/issues/326985)

## Summary

A real capability gap remains: current chat attachments are flat context entries without user-authored annotations or groups. The request has no community traction or settled UX yet, so it should remain open as under discussion rather than be closed or treated as agent-ready implementation work.

## Change summary

Allow users to add per-attachment notes and organize Copilot Chat attachments into named groups with shared guidance.

## Best solution

If adopted, define a coherent attachment-metadata model that carries user-authored guidance from the chat input UI through request serialization, with named groups and per-item annotations presented without cluttering simple attachment workflows.
