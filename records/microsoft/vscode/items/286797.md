# Issue #286797 — Different cloud session titles in Agent Sessions vs chat tab

[https://github.com/microsoft/vscode/issues/286797](https://github.com/microsoft/vscode/issues/286797)

## Summary

Still reproduces on main: the panel path in ChatWidgetService.openSession does not apply the preferred title after loadSession, while the editor path does. PR #296937 attempted a fix but was closed without merging.

## Change summary

Cloud sessions opened from the Agent Sessions list in the chat panel show the wrong title (e.g. 'Initial Implementation') instead of the descriptive session label.

## Best solution

Mirror the editor path's `setChatSessionTitle` call in the panel path of `ChatWidgetService.openSession` (src/vs/workbench/contrib/chat/browser/widget/chatWidgetService.ts, lines ~125-134) — after `chatView.loadSession(sessionResource)`, apply `options.title.preferred` via `chatService.setChatSessionTitle` for non-local sessions, as the closed PR #296937 attempted.
