# Issue #180056 — Would it be possible to create some way to identify that the zen mode is active?

[https://github.com/microsoft/vscode/issues/180056](https://github.com/microsoft/vscode/issues/180056)

## Summary

Valid accessibility feature request — screen reader users cannot identify when zen mode is active. An open PR (#305701) proposes adding a `${zenMode}` window title variable. The issue has a `help wanted` label, an `On Deck` milestone, and an open linked PR, so it should stay open.

## Change summary

Screen reader users have no way to tell if zen mode is active because the status bar (a natural location for such info) is hidden by default in zen mode.

## Best solution

Land the approach in https://github.com/microsoft/vscode/pull/305701 (adding a `${zenMode}` template variable to the window title, auto-appended when screen reader optimization is enabled) after team review. The related API request https://github.com/microsoft/vscode/issues/114741 is a separate concern (extension API) and not a duplicate.
