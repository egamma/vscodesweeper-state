# Issue #241290 — [Feature Request] Enable Pinpoint Changes in GitHub Copilot Edits and Agent Mode

[https://github.com/microsoft/vscode/issues/241290](https://github.com/microsoft/vscode/issues/241290)

## Summary

Targeted replacement and patch tools now address much of this request, but full-file rewriting remains available in the edit-mapping pipeline. Keep open to assess the remaining small-edit latency and streaming behavior rather than treating partial coverage as completion.

## Change summary

Apply and display small Copilot changes as localized edits instead of streaming a rewritten file.

## Best solution

Use the existing targeted-edit capabilities to deliver efficient small changes consistently across Edit and Agent workflows, retaining full-file rewriting where necessary. First establish which current model and editing paths still exhibit the reported whole-file streaming before deciding whether further changes are needed.
