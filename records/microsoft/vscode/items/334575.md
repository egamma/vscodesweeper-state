# Issue #334575 — Agent host: a local slash command's output is never shown, leaving an empty turn

[https://github.com/microsoft/vscode/issues/334575](https://github.com/microsoft/vscode/issues/334575)

## Summary

Traced and confirmed in source: local slash-command stdout/stderr is dropped in both the replay path and the live path, leaving turns that ran a local command appear empty even though the command produced real output.

## Change summary

A local slash command's stdout/stderr is discarded instead of shown, so the turn renders as empty.

## Best solution

In claudeReplayMapper.ts, split local-command-stdout/stderr out of CLI_ECHO_MARKER_PATTERN so it's surfaced as a response part on the active turn instead of being swept up with the echo markers and caveat; make the equivalent live-path change so 'local_command' system messages aren't silently ignored.
