# Issue #342382 — Agent Host: an unresponsive window blocks every send in a chat indefinitely (retryFailedClientSyncIfNeeded has no timeout)

[https://github.com/microsoft/vscode/issues/342382](https://github.com/microsoft/vscode/issues/342382)

## Summary

The indefinite shared-plugin wait remains in current source: an attached client that never answers a resource request can block another window's send. Existing cancellation support does not provide an automatic deadline, and no verified fix or canonical duplicate was found.

## Change summary

Prevent an unresponsive attached window's plugin synchronization from indefinitely blocking chat sends from responsive windows.

## Best solution

Make client-plugin preparation settle within a bounded interval, with explicit failure or degraded-state reporting and recoverable subsequent sends. Decide whether unavailable client contributions should prevent the turn or permit it with a visible warning, without weakening resource permissions.
