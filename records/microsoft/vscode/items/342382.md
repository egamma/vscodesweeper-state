# Issue #342382 — Agent Host: an unresponsive window blocks every send in a chat indefinitely (retryFailedClientSyncIfNeeded has no timeout)

[https://github.com/microsoft/vscode/issues/342382](https://github.com/microsoft/vscode/issues/342382)

## Summary

Keep open: current source confirms that an unanswered client plugin sync can indefinitely block another client's send in the same session. Explicit cancellation now releases the caller, but neither the shared sync wait nor its reverse resource requests have an automatic deadline.

## Change summary

Prevent a connected but unresponsive window's plugin synchronization from indefinitely blocking chat sends from another window.

## Best solution

Give client-plugin preparation a bounded, observable failure outcome without weakening resource authorization or silently changing the plugins used by a turn. Settle whether an affected send should fail retryably or proceed with explicitly reported unavailable customizations before implementing the recovery behavior.
