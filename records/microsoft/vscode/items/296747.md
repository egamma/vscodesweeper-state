# Issue #296747 — Git: Create a fixup commit from the graph view

[https://github.com/microsoft/vscode/issues/296747](https://github.com/microsoft/vscode/issues/296747)

## Summary

The built-in Git graph still lacks the requested fixup action, and no verified canonical owns this exact workflow. Keep the accepted Backlog request open; the extension alternative remains blocked on a proposed menu contribution point.

## Change summary

Create a fixup commit from staged changes by selecting the target commit in the Git graph context menu, without copying its hash into a terminal command.

## Best solution

Provide a graph action equivalent to git commit --fixup=<selected commit>, preserving ordinary commit signing and hooks without automatically rebasing history. The Git owner should decide whether to deliver it in the built-in extension or enable the existing extension approach through the stable history-item menu contribution point.
