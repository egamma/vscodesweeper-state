# Issue #306017 — Copilot does not realize it's in ask mode

[https://github.com/microsoft/vscode/issues/306017](https://github.com/microsoft/vscode/issues/306017)

## Summary

The reported Ask-mode retry loop remains relevant and has an independent current-version confirmation. This older report should stay open as the likely canonical while the runtime path is diagnosed.

## Change summary

In Ask mode, Copilot attempts unavailable editing tools and repeatedly diagnoses tool-call failures instead of recognizing the read-only mode and answering without edits.

## Best solution

Ensure every Ask-mode implementation advertises only read-only tools and explicitly handles edit intent without retrying unavailable tools, with a regression scenario covering an Agent-to-Ask mode switch.

If the user requests a change, Copilot must not invoke or retry editing tools; it should provide a useful read-only response that clearly reflects the mode limitation. - **Trace:**
