# Issue #133566 — Git - Source Control Tab "Discard Changes" on a file called '*' discards all untracked changes

[https://github.com/microsoft/vscode/issues/133566](https://github.com/microsoft/vscode/issues/133566)

## Summary

Keep open: the permanent-delete path still interprets filenames as Git pathspec patterns, allowing a single-file discard to delete unrelated untracked work. An open PR explicitly addresses this issue and should be reviewed before closure.

## Change summary

Discarding an untracked file named '*' must delete only that file, not other untracked files matched by its name.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/324378 so targeted permanent deletion treats filenames literally, while preserving paths containing spaces and existing trash behavior.
