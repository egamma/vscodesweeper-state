# Issue #133566 — Git - Source Control Tab "Discard Changes" on a file called '*' discards all untracked changes

[https://github.com/microsoft/vscode/issues/133566](https://github.com/microsoft/vscode/issues/133566)

## Summary

Still reproduces on main: `git clean -f -q -- *` treats the filename as a glob, deleting all untracked files. An open PR (#324378) adds `--literal-pathspecs` to fix this. Keeping open since the fix has not merged.

## Change summary

Discarding changes on a file named `*` (or other pathspec metacharacters) via Source Control deletes all untracked files instead of just the target file.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/324378, which passes `--literal-pathspecs` to targeted `git clean` operations so metacharacters in filenames are treated literally. This supersedes the earlier reverted shell-escaping approach from PR #236849.
