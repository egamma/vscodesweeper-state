# Issue #20112 — Code snippet control indentation

[https://github.com/microsoft/vscode/issues/20112](https://github.com/microsoft/vscode/issues/20112)

## Summary

This remains the canonical request for explicit snippet unindent/start-of-line control. Current source still applies insertion-line indentation to continuation lines, while the open related PR addresses only blank-line whitespace.

## Change summary

Allow snippet authors to reset a line to column zero or remove indentation levels independently of the insertion context.

## Best solution

Define explicit start-of-line and possibly single-level unindent syntax for snippets, implement it in the snippet parser/whitespace adjustment path, and cover heredoc and fixed-column language cases. Review https://github.com/microsoft/vscode/pull/315157 separately as a partial fix for internal blank lines.
