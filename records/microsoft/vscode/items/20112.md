# Issue #20112 — Code snippet control indentation

[https://github.com/microsoft/vscode/issues/20112](https://github.com/microsoft/vscode/issues/20112)

## Summary

Keep open: user snippets still lack per-line control to reset indentation to the start of the line or unindent relative to the insertion context. The related open PR addresses blank-line whitespace, not this capability, and a maintainer explicitly consolidated a newer request here.

## Change summary

Allow snippets to place selected lines at column one or reduce their indentation independently of the insertion context.

## Best solution

Provide an explicit, backward-compatible indentation-control mechanism for user snippets while preserving automatic indentation for ordinary snippets. Settle its syntax and absolute-versus-relative semantics before implementation; retain this issue as the canonical request.

## Evidence

- **Current insertion behavior:** src/vs/editor/contrib/snippet/browser/snippetSession.ts:427–477, SnippetSession.adjustWhitespace, splits text on CRLF, CR, or LF and prepends insertion-line whitespace to continuation lines when adjustment is enabled. Thus the reporter's '\rSQL' becomes a new indented line rather than a column-one SQL terminator.
- **Existing-capability boundary:** src/vs/workbench/contrib/snippets/browser/snippets.contribution.ts:54–89 exposes no indentation-control property in the user-snippet schema. editor.action.insertSnippet in browser/commands/insertSnippet.ts accepts snippet, name, and langId and inserts with default adjustment. KnownSnippetVariableNames in src/vs/editor/contrib/snippet/browser/snippetVariables.ts contains no TM_CURRENT_INDENT variable.
- **Partial API capability is not coverage:** https://github.com/microsoft/vscode/issues/57093 introduced completion whitespace control; src/vs/editor/contrib/suggest/browser/suggestController.ts:449 maps CompletionItemInsertTextRule.KeepWhitespace to disabling adjustment. This is completion-provider control, not a per-line mechanism in user snippets, and the discussion supplied for https://github.com/microsoft/vscode/issues/20112 explicitly distinguishes it from unindentation.
- **Maintainer-confirmed canonical direction:** https://github.com/microsoft/vscode/issues/205668 requests absolute or backward indentation control for snippets.
