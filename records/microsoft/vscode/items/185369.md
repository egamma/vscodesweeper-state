# Issue #185369 — Delayed pty host startup can cause terminal service connection state to stay connecting

[https://github.com/microsoft/vscode/issues/185369](https://github.com/microsoft/vscode/issues/185369)

## Summary

The race condition is still present on current main: creating a terminal before the pty host finishes connecting can leave the connection state stuck at Connecting, preventing proper focus on Ctrl+`. No commit references this issue, and the underlying code path is unchanged. Keeping open as a valid team-filed bug.

## Change summary

Creating a terminal before the pty host connects causes the terminal panel to open but not focus when toggling with Ctrl+`.

## Best solution

Guard the toggle/focus flow in `terminalService.ts` to handle the case where a terminal is created while `_connectionState` is still `Connecting` — either defer focus until connected or ensure `_setConnected()` re-evaluates pending focus requests. The fix is localized to the terminal service connection lifecycle.
