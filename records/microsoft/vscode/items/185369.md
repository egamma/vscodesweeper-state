## Summary

The delayed-startup focus failure is documented, but its persistence on current main is unconfirmed. Request a current reproduction: a related startup-delay fix has landed, while source inspection alone does not establish whether this connection-state failure remains.

## Change summary

Creating a terminal during delayed pty-host startup can leave the terminal service connecting and prevent Ctrl+` from focusing the terminal.

## Best solution

Terminal initialization should reach Connected after successful backend reconnection, and subsequent terminal toggles should focus the terminal. Confirm the original delayed-startup sequence on a current build before deciding whether further connection-state or focus recovery work is necessary.
