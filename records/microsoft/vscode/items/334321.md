# Issue #334321 — Support Gemini 3.8 and future unlisted models via fallback capabilities and custom model settings

[https://github.com/microsoft/vscode/issues/334321](https://github.com/microsoft/vscode/issues/334321)

## Summary

The native Gemini provider still deliberately lists only known models, and its configuration offers no custom model registration. Keep this open as a feature request: supporting future models requires capability and configuration decisions, not another one-model manifest update.

## Change summary

Allow native Gemini BYOK users to discover and configure supported models without waiting for the curated model manifest.

## Best solution

Extend native Gemini model availability with reliable capability handling and a supported manual-registration path, preserving curated metadata for known models. Decide the eligibility and override contracts before implementation, coordinating with the existing BYOK discovery work.

- **Trace:**
