# Issue #188015 — touch keyboard come up behavior

[https://github.com/microsoft/vscode/issues/188015](https://github.com/microsoft/vscode/issues/188015)

## Summary

Keep open: a maintainer reproduced the unwanted touch-keyboard activation, and another user confirmed that scrolling with editor focus interrupts navigation and resizes the viewport. No verified fix or older open issue owning this exact symptom was found.

## Change summary

Prevent touch scrolling from reopening the on-screen keyboard while preserving keyboard activation for deliberate editing touches.

## Best solution

Make touch navigation preserve the dismissed keyboard state until an editing touch requests text input. First reproduce on a current Windows touch device and isolate whether editor focus handling or browser/OS keyboard activation causes the unwanted reopening.
