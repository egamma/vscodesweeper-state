# Issue #188015 — touch keyboard come up behavior

[https://github.com/microsoft/vscode/issues/188015](https://github.com/microsoft/vscode/issues/188015)

## Summary

Still reproduces on main: the touch gesture handler in `src/vs/base/browser/touch.ts` dispatches Tap events even during scroll gestures (when total movement is small), causing the virtual keyboard to appear. No fix has landed on main. The confirmed bug on touch/tablet devices remains valid.

## Change summary

Virtual keyboard appears when scrolling on touchscreen devices because small-movement scroll gestures are misidentified as taps.

## Best solution

Guard Tap dispatch in `src/vs/base/browser/touch.ts` to suppress it when Change (scroll) events have already been dispatched during the same gesture. The fix should be localized to the `onTouchEnd` handler's Tap/Contextmenu dispatch logic.
