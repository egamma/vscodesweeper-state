# Issue #335608 — entering "Trusted" mode for a folder disables the "File->Save" option until a new file is opened

[https://github.com/microsoft/vscode/issues/335608](https://github.com/microsoft/vscode/issues/335608)

## Summary

Confirmed bug: after granting workspace trust, the active editor's context isn't re-asserted, so Save stays disabled until the file is reopened. A contributor has already reproduced it and opened a fixing PR, so this should stay open pending review/merge rather than be triaged as a fresh defect.

## Change summary

After trusting a previously-untrusted folder, File > Save (and its keybinding) remains greyed out/non-functional for the already-open file until it is closed and reopened; Save All still works.

## Best solution

Land https://github.com/microsoft/vscode/pull/335615, which re-asserts the active editor context on workspace trust change, to restore Save availability without requiring the file to be reopened.
