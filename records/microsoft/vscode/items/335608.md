# Issue #335608 — entering "Trusted" mode for a folder disables the "File->Save" option until a new file is opened

[https://github.com/microsoft/vscode/issues/335608](https://github.com/microsoft/vscode/issues/335608)

## Summary

Reproduced bug: after granting workspace trust, the File > Save command's enablement context key isn't re-asserted for the active editor, so Save stays greyed out until the file is reopened. A contributor already reproduced it and opened a fix PR, so this stays open pending review/merge.

## Change summary

Entering Trusted mode for a folder leaves the File > Save menu item disabled for the currently open dirty file until it is closed and reopened.

## Best solution

Land or continue reviewing https://github.com/microsoft/vscode/pull/335615, which re-asserts the active editor context on workspace trust change — that directly targets the stale-context-key root cause described here.
