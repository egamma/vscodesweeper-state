## Summary

Team-authored design-guidance tracking issue. PR #164835 addressed specific list/tree icon cases but did not reference this issue or deliver the broader reusable guidance the issue requests. The discussion shows consensus (icons should reflect current state, tooltips indicate target action) but no formal codified guidance exists yet.

Define and consistently apply reusable UX guidance for icon toggle states (show current state vs. target state) across the VS Code workbench.
