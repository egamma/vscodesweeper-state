# Issue #284299 — ADO Repository Throttling from `refreshRepoDiffs`

[https://github.com/microsoft/vscode/issues/284299](https://github.com/microsoft/vscode/issues/284299)

## Summary

Still active on main: the refreshRepoDiffs code path in the Copilot extension triggers excessive git blob downloads on blobless partial clones (ADO), causing rate limiting. The open PR #292453 to expose noRenames in the git diff API has not merged, and multiple team members confirm the workaround is insufficient.

## Change summary

Copilot Chat's workspace diff tracking triggers rename detection in git diff on blobless partial clones, causing excessive blob downloads and ADO rate limiting.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/292453 to expose noRenames in the git diff API, then wire it through the workspace diff tracker (extensions/copilot/src/platform/workspaceChunkSearch/node/codeSearch/workspaceDiff.ts → diffWithIndexedCommit path) so rename detection is disabled for partial clones. The agent host service already uses --no-renames; the copilot extension's workspace diff path needs parity.
