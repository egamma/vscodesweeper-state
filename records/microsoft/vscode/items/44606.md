# Issue #44606 — Allow extensions to add coloured markers in the gutter similar to source control

[https://github.com/microsoft/vscode/issues/44606](https://github.com/microsoft/vscode/issues/44606)

## Summary

A real extension API gap remains: extensions can render gutter icons, but cannot create the narrow, contiguous line decorations used by source control. Keep this Backlog request open for API design discussion.

## Change summary

Expose source-control-style colored gutter markers, with tooltip support, through the text editor decoration API.

## Best solution

Extend `DecorationRenderOptions` with a constrained, theme-aware line-decoration option backed by the editor's existing lines-decoration rendering, while defining overlap behavior between competing decorations.

- **Reason:** This API would let extensions implement specialized visualization while keeping that functionality outside the core product.

## Evidence

- **remaining API gap:** `src/vscode-dts/vscode.d.ts` exposes `gutterIconPath` and `gutterIconSize`, but no source-control-style line-decoration color or equivalent.
- **internal capability:** `src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts` renders SCM markers using internal `linesDecorationsClassName` and `linesDecorationsTooltip` options.
- **not extension-accessible:** `src/vs/editor/common/model.ts` defines `linesDecorationsClassName` and `linesDecorationsTooltip`, while `src/vs/editor/browser/services/abstractCodeEditorService.ts` does not map them from public extension decoration options.
- **maintainer direction:** A maintainer explicitly identified adding a property to `ThemableDecorationRenderOptions` as the appropriate implementation direction.
- **no canonical replacement:** https://github.com/microsoft/vscode/issues/47559 concerns clickable glyph-margin decorations, a different rendering surface and interaction requirement.
