# Issue #105625 — API for horizontal scroll position in TextEditor

[https://github.com/microsoft/vscode/issues/105625](https://github.com/microsoft/vscode/issues/105625)

## Summary

The API gap remains on current main, and this accepted Backlog request has 30 community upvotes. Existing APIs expose vertical ranges only, while horizontal scroll state remains internal.

## Change summary

Expose readable, writable, and observable horizontal scroll state for extension-host text editors.

## Best solution

Design a proposed TextEditor scroll API and bridge the existing ICodeEditor scroll-left methods and scroll event through the main-thread/extension-host protocol, with cycle-safe synchronization semantics.

- **Reason:** Exposing a missing low-level API enables extensions to provide specialized synchronized-scrolling experiences without adding niche UI to core.

## Evidence

- **current public API:** src/vscode-dts/vscode.d.ts explicitly documents TextEditor.visibleRanges as vertical-only and exposes revealRange but no horizontal scroll property, setter, or event.
- **extension-host bridge:** src/vs/workbench/api/browser/mainThreadEditor.ts and src/vs/workbench/api/common/extHostTextEditor.ts transmit visible ranges but no horizontal scroll state.
