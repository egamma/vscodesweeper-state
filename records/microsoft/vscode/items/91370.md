# Issue #91370 — Undo/Redo: consider to show global undo/redo as label in menu

[https://github.com/microsoft/vscode/issues/91370](https://github.com/microsoft/vscode/issues/91370)

## Summary

The requested operation-aware Edit menu labels remain missing: current registrations still show plain Undo and Redo. Keep this accepted Backlog request open; the related history request does not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Show the upcoming global undo or redo operation in the Edit menu, such as Undo (Rename), while leaving ordinary typing labels unchanged.

## Best solution

Make Edit menu labels describe the upcoming global operation consistently across custom and native menus, without changing undo/redo execution or labeling ordinary typing. First establish how the displayed operation follows the active command target and effective undo/redo stack.
