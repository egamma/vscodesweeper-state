# Issue #91370 — Undo/Redo: consider to show global undo/redo as label in menu

[https://github.com/microsoft/vscode/issues/91370](https://github.com/microsoft/vscode/issues/91370)

## Summary

A real UI gap remains: current main always displays static Undo and Redo menu labels, even when the next operation spans multiple resources. Keep this Backlog request open under discussion rather than closing it for age or low engagement.

## Change summary

Show the pending workspace-wide operation in the Edit menu, such as “Undo (Rename),” while retaining plain labels for typing edits.

## Best solution

Update the Edit menu labels from the active resource's undo/redo stack when the next element is a workspace operation, using its localized operation label; retain the existing static labels for ordinary resource edits.
