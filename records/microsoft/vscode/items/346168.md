# Issue #346168 — SCM: Group repositories by workspace folder in Repositories and Changes views

[https://github.com/microsoft/vscode/issues/346168](https://github.com/microsoft/vscode/issues/346168)

## Summary

Keep open as a feature request: current SCM sorting and file-tree modes do not provide collapsible workspace-folder groups above repositories. The related repository-tree request is closed, and the open flat-view request asks for materially different behavior.

## Change summary

Optionally group repositories under persistent, collapsible workspace-folder headings in both SCM views while preserving independent repository workflows.

## Best solution

Evaluate workspace-folder grouping within the SCM views, retaining the existing flat presentation and per-repository operations. Existing path sorting is a partial workaround, not a substitute for folder-level collapse.
