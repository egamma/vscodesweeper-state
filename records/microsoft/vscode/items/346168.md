# Issue #346168 — SCM: Group repositories by workspace folder in Repositories and Changes views

[https://github.com/microsoft/vscode/issues/346168](https://github.com/microsoft/vscode/issues/346168)

## Summary

Workspace-folder grouping remains missing in both SCM views. Existing sorting and tree modes do not satisfy the request, and the related issues examined do not provide an open duplicate canonical.

## Change summary

Add optional, persistent workspace-folder grouping above repositories in the Repositories and Changes views without combining repository workflows.

## Best solution

Consider an optional presentation mode in the SCM contribution that uses Explorer workspace-folder names and order, preserves independent repository controls, and remembers folder expansion while retaining the existing ungrouped mode.

- **Reason:** Matching Explorer's workspace organization would make navigation across the built-in workbench more consistent.
