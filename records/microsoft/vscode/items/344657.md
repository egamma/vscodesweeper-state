# Issue #344657 — Parallel subagents' foreground `run_in_terminal` calls still share one terminal (regression of #292222)

[https://github.com/microsoft/vscode/issues/344657](https://github.com/microsoft/vscode/issues/344657)

## Summary

Keep open and route to the terminal area: current source still reuses foreground terminals by chat session without distinguishing parallel subagents. The detailed output crossover and independent Linux confirmation support treating this as an active regression.

## Change summary

Prevent parallel subagents' foreground terminal commands from interrupting each other or returning another invocation's output.

## Best solution

Ensure concurrent subagents cannot execute foreground commands in the same shell without isolation, while preserving ordinary sequential terminal reuse and parent-session cleanup. Investigate the default Copilot shell harness separately, as requested by the maintainer; its behavior is not established by this report.
