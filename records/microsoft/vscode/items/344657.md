# Issue #344657 — Parallel subagents' foreground `run_in_terminal` calls still share one terminal (regression of #292222)

[https://github.com/microsoft/vscode/issues/344657](https://github.com/microsoft/vscode/issues/344657)

## Summary

The foreground-terminal sharing defect remains traceable in current source: sibling subagents retain the parent session resource, and foreground terminal reuse ignores subagent identity. Route to the terminal area; the closed predecessor does not resolve this regression.

## Change summary

Prevent concurrent subagents' foreground terminal commands from interrupting one another or receiving one another's output.

## Best solution

Ensure foreground executions from separate subagents cannot share an actively used shell or misattribute command results, while preserving sequential shell state and existing background behavior. Investigate the Local harness path first; the maintainer's requested comparison with the default Copilot harness is a separate verification step.
