# Issue #344657 — Parallel subagents' foreground `run_in_terminal` calls still share one terminal (regression of #292222)

[https://github.com/microsoft/vscode/issues/344657](https://github.com/microsoft/vscode/issues/344657)

## Summary

Keep open: parallel foreground calls in the Local harness have documented output cross-contamination and an independent Linux confirmation. The reporter verified that the Copilot harness avoids the problem, but that does not establish a fix for the reported Local-harness path.

## Change summary

Prevent concurrent subagents' foreground terminal commands from interrupting one another or receiving another command's output.

## Best solution

Guarantee command and output isolation wherever parallel subagents use the integrated-terminal tool, while preserving session cleanup and intentional terminal reuse. Resolve the remaining Local-harness behavior rather than treating success with a different harness as proof of repair.
