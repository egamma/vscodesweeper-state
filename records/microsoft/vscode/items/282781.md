# Issue #282781 — NES: Word Replacement doesn't render CJK nicely

[https://github.com/microsoft/vscode/issues/282781](https://github.com/microsoft/vscode/issues/282781)

## Summary

The CJK word-replacement rendering defect remains on current main: the replacement text is rendered at its measured width, but its enclosing geometry assumes every character has halfwidth. This is a bounded visual bug with no verified duplicate or fixing PR.

## Change summary

Size the NES word-replacement widget correctly when replacement text contains CJK or other non-halfwidth characters.

## Best solution

Base the replacement box and surrounding widget geometry on the rendered text width rather than UTF-16 string length multiplied by the editor's typical halfwidth character width, with a CJK screenshot fixture preventing regressions.
