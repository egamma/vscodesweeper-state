# Issue #323458 — Multi-root: Pick workspace folder of the selected file/text when starting a new chat

[https://github.com/microsoft/vscode/issues/323458](https://github.com/microsoft/vscode/issues/323458)

## Summary

Valid feature request from a team member: auto-select workspace folder from the active file/selection context when starting a new chat in a multi-root workspace. Stays open for routing.

## Change summary

In multi-root workspaces, automatically pick the workspace folder based on the currently selected file or text when starting a new chat session.

## Best solution

When a new chat is initiated, infer the workspace folder from the active editor's file URI (or the file containing the selected text) and pre-select it in the workspace folder picker, so users don't need to manually choose it when context makes it unambiguous.
