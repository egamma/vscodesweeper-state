# Issue #341152 — Dictation regression in 1.141.0: on-device model ignores Spanish and leaks the <en-US> token (works in 1.140.0)

[https://github.com/microsoft/vscode/issues/341152](https://github.com/microsoft/vscode/issues/341152)

## Summary

Thanks for the detailed report. It is a plausible regression from the dictation runtime bump (1.2.3 to 2.0.1): the workbench passes `es-US` to the native runtime, which reportedly only accepts lowercase codes. I could not confirm this from source because the native runtime is not in the repo, and I could not execute it. The report has clear steps and a version bisect, so it is worth retesting rather than asking for more information.

## Change summary

On-device dictation with agents.voice.language=es transcribes as English and leaks an <en-US> token after the runtime update in 1.141.0.

## Best solution

Confirm the language tag format the 2.0.1 runtime expects, then normalize the casing (or locale form) in localTranscriptionService.ts where session.settings.language is set. Alternatively, fix it in the runtime.
