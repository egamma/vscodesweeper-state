# Issue #341152 — Dictation regression in 1.141.0: on-device model ignores Spanish and leaks the <en-US> token (works in 1.140.0)

[https://github.com/microsoft/vscode/issues/341152](https://github.com/microsoft/vscode/issues/341152)

## Summary

Thanks for the detailed report. It is a plausible regression from the dictation runtime bump (1.2.3 to 2.0.1). It has a real milestone (1.143.0) and an open linked PR (Foundry Local SDK 2.1.0) that may fix it, so it stays open until that PR lands and the fix is confirmed.

## Change summary

On-device dictation with agents.voice.language set to "es" sends "es-US" to the 2.0.1 Foundry runtime, which falls back to English and leaks the <en-US> token.

## Best solution

Land and review the open Foundry Local SDK 2.1.0 PR (https://github.com/microsoft/vscode/pull/341640), then confirm that Spanish dictation works and the language tag no longer leaks. If it does not, make the language code passed to the runtime match the casing it accepts.
