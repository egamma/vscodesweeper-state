# Issue #25356 — Problem saving keybindings

[https://github.com/microsoft/vscode/issues/25356](https://github.com/microsoft/vscode/issues/25356)

## Summary

Keep open: the keybinding recorder still permits sequences that turn ordinary typing or an existing shortcut into a chord prefix. Previewing, re-recording, and cancelling help correct mistakes, but do not provide the requested protection before saving; no verified older duplicate owns this behavior.

## Change summary

Provide safeguards when recording chord shortcuts that would intercept ordinary typing or an existing single-key shortcut.

## Best solution

Consider contextual warnings in the Keyboard Shortcuts editor when a recorded chord prefix would interfere with typing or an existing shortcut, while preserving intentionally configured chords. The maintainer should decide the protection policy before introducing restrictions or automatic reordering.
