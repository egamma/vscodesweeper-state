# Issue #331230 — External session banner issues

[https://github.com/microsoft/vscode/issues/331230](https://github.com/microsoft/vscode/issues/331230)

## Summary

Fresh, team-authored testing feedback on the new external-session banner (from PR #331122) — three concrete, traceable UI copy/layout rough edges, not a closeable item; routing to the sessions/chat area for follow-up.

## Change summary

Testing feedback: the banner description text is misleading about what the dropdown controls, the dropdown shows a stray 'Pick an option' placeholder, and the option descriptions look cramped.

## Best solution

Reword `externalSessionBanner.description` in src/vs/sessions/contrib/chat/browser/externalSessionBanner.ts to clarify the dropdown controls session recency/visibility (not which apps show up), remove or hide the disabled 'Pick an option' placeholder item once a mode is always pre-selected, and adjust spacing/line-height in externalSessionBanner.css for the per-option description text.
