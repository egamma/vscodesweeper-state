# Issue #331666 — create_file tool reports success on /memories/ virtual paths but writes nothing (silent no-op)

[https://github.com/microsoft/vscode/issues/331666](https://github.com/microsoft/vscode/issues/331666)

## Summary

Current main still treats the virtual `/memories/...` namespace as an ordinary filesystem path and then returns a successful create-file result without routing the write to memory storage. This is a distinct, source-confirmed false-success bug and should remain open for a bounded fix.

## Change summary

Prevent `create_file` from reporting success when asked to create a file through the virtual `/memories/...` namespace.

## Best solution

Reject `/memories` and `/memories/...` inputs in the workspace create-file tool with an actionable error directing the agent to the dedicated memory tool, while leaving normal absolute workspace paths unchanged.
