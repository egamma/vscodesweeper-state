# Issue #268456 — Copy selection from Debug console

[https://github.com/microsoft/vscode/issues/268456](https://github.com/microsoft/vscode/issues/268456)

## Summary

Real bug confirmed by two users on Linux: the Debug Console context menu "Copy" action fails to copy the selected text, likely because the tree's context menu handler disrupts the native DOM selection before the copy action reads it. The reporter provided a video and a second user independently confirmed the same behavior. No fix found on main.

## Change summary

Context menu "Copy" in the Debug Console copies only the visible/scrolled portion or nothing, rather than the user's actual text selection, on Linux.

## Best solution

The `debug.replCopy` action (src/vs/workbench/contrib/debug/browser/repl.ts:1190) reads the native selection via `getActiveWindow().getSelection()`, but the tree list's `onContextMenu` handler (src/vs/base/browser/ui/list/listWidget.ts:756) calls `setFocus()` on right-click which may cause DOM re-rendering that clears the native text selection before the copy action runs. The fix should preserve the native selection through the context menu flow — e.g., snapshot the selection text before the tree's focus update, or avoid the focus-set on right-click when a text selection is active.
