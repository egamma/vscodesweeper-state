## Summary

This is a support question, not a bug. The "Preview on GitHub" button appears by design when the user is not signed in with a GitHub access token — signing in switches it to "Create on GitHub". The template chooser page the reporter lands on is the vscode-python repo's GitHub issue template configuration, not a VS Code defect.

## Change summary

Reporter sees "Preview on GitHub" instead of "Create on GitHub" in the Issue Reporter, and the resulting GitHub page shows a template chooser instead of a direct bug form.

## Best solution

Close as a support question. The reporter needs to sign into GitHub within VS Code to get the "Create on GitHub" button. The template chooser page is standard GitHub behavior for repos with issue templates — selecting the Bug Report template there is the intended path.
