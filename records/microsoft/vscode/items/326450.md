# Issue #326450 — Restore Checkpoint not working with AH session

[https://github.com/microsoft/vscode/issues/326450](https://github.com/microsoft/vscode/issues/326450)

## Summary

Team-authored bug with a maintainer-confirmed root cause: checkpoint state for the current (unsent) turn isn't persisted in the agent-host runtime/protocol, so switching sessions and back loses the restore. A fix is blocked on a protocol change tracked externally, so this stays open.

## Change summary

Restoring a checkpoint and then switching away from and back to the agent-host session reverts the restore, because the pre-send-message state isn't persisted.

## Best solution

Wait on the agent-host-protocol change (a way to represent a non-latest 'current turn' pointer, or a non-destructive persistence mechanism) referenced in the linked upstream issue; this VS Code issue should stay open and tracked against that dependency until the protocol supports it.
