# Issue #274154 — copy text, delete text, pastes different text that is now in the location where old text was

[https://github.com/microsoft/vscode/issues/274154](https://github.com/microsoft/vscode/issues/274154)

## Summary

Keep open: a second user confirmed a reliable copy-delete-paste failure with KDE clipboard synchronization enabled, independently of extensions. The supplied recordings and configuration are sufficient to investigate; neither a concrete fix nor an older canonical reporting the same symptom was established.

## Change summary

On KDE, copying selected text and then deleting it can make Ctrl+V paste replacement text from the original location instead of the copied text.

## Best solution

Preserve the explicitly copied text through deletion and cursor movement while retaining normal Linux primary-selection behavior. Diagnose the interaction between editor selection updates, native copy handling, and KDE clipboard synchronization before choosing the fix boundary.
