# Issue #349566 — Agent Host: let a send_remote_message recipient reply to the exact sending chat

[https://github.com/microsoft/vscode/issues/349566](https://github.com/microsoft/vscode/issues/349566)

## Summary

Keep open: current source preserves exact sender metadata but does not expose a message-bound return reference to the recipient. The creator-bound origin alias does not cover communication between independently existing chats.

## Change summary

Let recipients of remote messages reply to the exact sending chat using native, message-bound provenance.

## Best solution

Provide a documented recipient-facing return reference or opaque reply operation bound to each incoming turn, preserving exact nested-chat identity, host qualification, and existing approvals. Choose the public contract before implementation.
