# Issue #101064 — Allow us to change the font type and size of find-replace widget

[https://github.com/microsoft/vscode/issues/101064](https://github.com/microsoft/vscode/issues/101064)

## Summary

Keep open: current main still hard-codes the editor find input at 13px, while this Backlog request has 199 community upvotes and addresses a documented accessibility gap.

## Change summary

Allow users to configure the editor find/replace widget's font family and font size.

## Best solution

Add find-widget font family and size settings with semantics consistent with `scm.inputFontFamily` and `scm.inputFontSize`, then apply them to both find and replace inputs while preserving responsive widget layout.
