# Issue #272346 — Have feedback on `show/hide leading/trailing whitespaces` button when there are whitespace only diffs

[https://github.com/microsoft/vscode/issues/272346](https://github.com/microsoft/vscode/issues/272346)

## Summary

Keep open: the whitespace toggle indicates whether filtering is enabled, not whether the current diff contains hidden whitespace changes. Existing feedback covers entirely whitespace-only diffs, but not whitespace changes hidden alongside visible edits.

## Change summary

Provide feedback on the diff editor's whitespace toggle when leading or trailing whitespace changes are hidden.

## Best solution

Provide a discoverable indication of hidden whitespace changes in the diff editor, including files that also contain visible edits, while preserving the user's whitespace-filter preference. The diff-editor owner should decide the presentation before implementation.
