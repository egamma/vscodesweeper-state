# Issue #237582 — Find widget looks different at different places

[https://github.com/microsoft/vscode/issues/237582](https://github.com/microsoft/vscode/issues/237582)

## Summary

The find widget intentionally differs across surfaces because each uses a different implementation matched to its capabilities. The Editor uses the full FindWidget (with replace/regex), while the Terminal uses SimpleFindWidget (no replace). The Output panel embeds a CodeEditor and therefore gets the editor's FindWidget. A team member already commented 'looks by design.'

## Change summary

The find widget has different visual appearances in the Editor, Output panel, and Terminal.

## Best solution

Close as designed. The Editor find widget supports replace and regex (hence the expand arrow); the Terminal's SimpleFindWidget intentionally omits replace since terminal content is read-only output. The Output panel hosts a full CodeEditor so it inherits the editor's find widget. The visual differences reflect genuine functional differences. If visual unification is desired in the future, it would be a polish/feature-request tracked separately.
