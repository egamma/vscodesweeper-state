# Issue #188747 — ptyHost starts when there is only a terminal renderer

[https://github.com/microsoft/vscode/issues/188747](https://github.com/microsoft/vscode/issues/188747)

## Summary

Keep open: current source still allows a renderer-only terminal to launch the pty host through terminal-layout persistence. The issue is already correctly routed, and no verified fix or qualifying canonical duplicate was found.

## Change summary

Opening a renderer-only terminal unnecessarily starts the pty host despite having no shell process to manage.

## Best solution

Renderer-only terminals should display and update without starting the pty host, including when persistent sessions are enabled. Preserve normal shell startup, process revival, and layout updates for an already-running host.
