# Issue #280689 — Cloud session should have more prominent link to the PR

[https://github.com/microsoft/vscode/issues/280689](https://github.com/microsoft/vscode/issues/280689)

## Summary

Keep open: current code provides a browser-opening PR action inside an opened cloud session, but that does not establish the requested discoverability from the Agents sidebar. This team-authored request has neither a verified older canonical nor an explicitly linked fixing commit that would justify closing it.

## Change summary

Make a cloud session's associated pull request easier to discover and open on GitHub from the Agents sidebar, without relying on hover content.

## Best solution

Provide a recognizable, keyboard-accessible way to open the associated PR from the cloud-session list, reusing existing PR metadata and browser-opening behavior. The area owner should assess whether current sidebar affordances satisfy that goal rather than treating the chat-input toolbar as equivalent coverage.
