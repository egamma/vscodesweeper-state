# Issue #134592 — markdownDescriptions/markdownEnumDescriptions don't remove ## in settings.json hover

[https://github.com/microsoft/vscode/issues/134592](https://github.com/microsoft/vscode/issues/134592)

## Summary

Still reproduces on main: `fixSettingLinks` is only applied to `deprecationMessage` and the default-settings content builder, but NOT to `markdownDescription`/`markdownEnumDescriptions` passed to the JSON schema that powers settings.json hovers.

## Change summary

Hovering over settings in settings.json shows raw `##` link syntax from markdownDescription/markdownEnumDescriptions because the JSON language server doesn't understand VS Code's custom `#settingId#` link format.

## Best solution

In `RegisterConfigurationSchemasContribution.registerConfigurationSchemas()` (src/vs/workbench/services/configuration/browser/configurationService.ts), apply `fixSettingLinks` to `markdownDescription` and `markdownEnumDescriptions` before passing them into the JSON schema — similar to how `deprecationMessage` is already stripped. Alternatively, convert `#settingId#` into standard markdown links (e.g. `[settingId](command:...)`) so they render clickably in the hover.
