# Issue #227122 — Editor GPU: Support editor.fontWeight

[https://github.com/microsoft/vscode/issues/227122](https://github.com/microsoft/vscode/issues/227122)

## Summary

Keep this protected plan-item open: GPU rendering still lacks support for the configured editor font weight, including Cascadia Code at weight 350. Related user reports were consolidated into this issue, which remains the specific owner of the work.

## Change summary

Honor editor.fontWeight when rendering editor text with experimental GPU acceleration.

## Best solution

Bring GPU-rendered text into parity with the configured editor.fontWeight, including numeric weights and changes made while the editor is open, while preserving token and decoration bold styling.

## Evidence

- **Protected planning item:** https://github.com/microsoft/vscode/issues/227122 carries plan-item. The hard keep-open rule protects planning artifacts regardless of possible fixes or duplicate relationships.
- **Concrete requested behavior:** https://github.com/microsoft/vscode/issues/221145#issuecomment-2587698553 reports that Cascadia Code with editor.fontWeight set to 350 renders noticeably heavier on GPU-rendered lines than on DOM fallback lines when editor.experimentalGpuAcceleration is on.
- **Existing capability does not cover GPU rendering:** src/vs/editor/common/config/editorOptions.ts:2167-2202 registers fontWeight with numeric values from 1 through 1000. src/vs/editor/browser/config/domFontInfo.ts applies fontInfo.fontWeight to DOM text, but src/vs/editor/browser/viewParts/viewLinesGpu/viewLinesGpu.ts:203-205 constructs GlyphRasterizer with only font size, family, pixel ratio and decoration cache; its refresh checks at lines 464-470 likewise omit weight.
- **Current rasterization gap:** src/vs/editor/browser/gpu/raster/glyphRasterizer.ts has no configured font-weight parameter. Its canvas font strings contain size and family, with optional bold from token metadata or decorations; its cacheKey includes only family and size. The configured numeric weight 350 therefore never reaches glyph rasterization.
- **This issue owns consolidated reports:** https://github.com/microsoft/vscode/issues/244422 describes ignored font-weight changes on macOS with GPU acceleration and was closed toward this issue at https://github.com/microsoft/vscode/issues/244422#issuecomment-3629010774. https://github.com/microsoft/vscode/issues/271241 describes lost bold styling on Windows and was likewise consolidated at https://github.com/microsoft/vscode/issues/271241#issuecomment-3638397914.
