# Issue #325250 — Modern UI: `tab.activeBorder` color customization not respected

[https://github.com/microsoft/vscode/issues/325250](https://github.com/microsoft/vscode/issues/325250)

## Summary

Confirmed in source: Modern UI's tab CSS only reads `tab.activeBorderTop` (and only for the multi-selected state), never `tab.activeBorder`, so a plain active tab's border customization is silently dropped. A prior fix attempt (PR #325370) was closed unmerged, and the later merged tabs redesign (#328111) didn't address this issue, so the gap remains open on current main.

## Change summary

Under Modern UI, the `tab.activeBorder` color customization (and related colorCustomizations like titleBar/activityBar colors mentioned by commenters) is not applied to the active editor tab.

## Best solution

Extend `src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css` so the plain `.tab.active` (not just `.active.multi-selected.tab-border-top`) state maps `--tab-border-top-color` from `--vscode-tab-activeBorder`/`--vscode-tab-activeBorderTop` when the user has customized it, picking up where the abandoned WIP PR #325370 left off; the broader titleBar/activityBar reports in the comments likely need separate follow-up issues under the same modernization effort.
