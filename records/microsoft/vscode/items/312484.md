# Issue #312484 — Allow opening the integrated browser to a specified URL from 'tasks' and the 'code' cli.

[https://github.com/microsoft/vscode/issues/312484](https://github.com/microsoft/vscode/issues/312484)

## Summary

Valid feature request. The integrated browser's `workbench.action.browser.open` command already accepts a URL argument programmatically, but there is no task-schema property or CLI flag to invoke it declaratively from `tasks.json` or the `code` CLI. The gap is real.

## Change summary

Allow opening the VS Code integrated browser to a specified URL from task configuration and the `code` CLI.

## Best solution

Two enhancements: (1) add a `code --open-browser <url>` CLI flag (or extend `--open-url` semantics) that opens the integrated browser rather than the system browser, and (2) add a task presentation option or post-task action that invokes `workbench.action.browser.open` with a configurable URL. The command infrastructure exists in `src/vs/workbench/contrib/browserView/electron-browser/features/browserTabManagementFeatures.ts` (`OpenIntegratedBrowserAction`); the work is wiring it into the task runner and CLI argument parser.
