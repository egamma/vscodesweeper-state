# Issue #328446 — Add a CLI "open" command

[https://github.com/microsoft/vscode/issues/328446](https://github.com/microsoft/vscode/issues/328446)

## Summary

Current main mishandles the standard `--` end-of-options marker when a following path matches a CLI subcommand. This is a source-confirmed CLI parsing bug that should remain open and route to the CLI area.

## Change summary

Allow folders named after CLI subcommands, such as `agent`, to be opened from the command line.

## Best solution

Make subcommand detection in `parseArgs` stop at `--`, preserving subsequent values as positional paths, and add parser coverage for conflicting folder names.
