# Issue #326392 — create_chat-created chats: multi-chat pill is non-responsive

[https://github.com/microsoft/vscode/issues/326392](https://github.com/microsoft/vscode/issues/326392)

## Summary

Real, well-described bug from a team member with a screenshot; no fix commit or open PR found on main, so this stays open — already correctly labeled `bug`/`agents-window`.

## Change summary

Chats created via the `create_chat` MCP/agent-host server tool live outside a Session, so the multi-chat pill shown for them has nothing to open and is non-responsive when clicked.

## Best solution

Either have `create_chat` create/attach to a Session (so the pill has a real multi-chat target), or suppress/disable the multi-chat pill for chats whose underlying entity reports no multi-chat capability, consistent with the `supportsMultipleChats` capability gating already used elsewhere (e.g. src/vs/sessions/browser/parts/chatCompositeBar.ts, src/vs/sessions/contrib/providers/agentHost/browser/baseAgentHostSessionsProvider.ts).
