# Issue #229917 — SCM Graph - allow to multi select for e.g. cherry-pick

[https://github.com/microsoft/vscode/issues/229917](https://github.com/microsoft/vscode/issues/229917)

## Summary

Keep open: the Source Control Graph still explicitly disables multi-selection, and its cherry-pick action accepts only one commit. The older graph requests examined do not establish the same bulk-operation requirement, so they do not meet the stronger duplicate bar for this re-review.

## Change summary

Allow selecting multiple commits in the Source Control Graph and performing bulk operations such as cherry-picking.

## Best solution

Support multi-commit selection and selection-aware bulk actions across the SCM graph and built-in Git extension, with defined commit ordering and conflict handling. Preserve existing single-commit actions and distinguish commit selections from file-change and incoming/outgoing summary nodes.
