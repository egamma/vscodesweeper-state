# Issue #337448 — Markdown editor: let extensions add syntax, like markdown.markdownItPlugins does for the preview

[https://github.com/microsoft/vscode/issues/337448](https://github.com/microsoft/vscode/issues/337448)

## Summary

Well-diagnosed, brand-new request: the WYSIWYG Markdown editor genuinely has no syntax-extension hook today, only `markdown.codeBlockEditorProviders`. Worth tracking as a feature request, but it's 0 days old with no upvotes yet, so it should sit and gather maintainer/community signal rather than being fast-tracked.

## Change summary

Add a contribution point letting extensions add custom Markdown syntax (inline or block, not just code-block views) to the new WYSIWYG Markdown editor, mirroring what `markdown.markdownItPlugins` does for the preview.

## Best solution

Route to the markdown-language-features area owners to decide the extension-point shape (micromark-syntax-extension hook vs. narrower node/pattern-claim API); either design needs to guarantee lossless round-tripping of unrecognized/extended syntax.
