# Issue #337448 — Markdown editor: let extensions add syntax, like markdown.markdownItPlugins does for the preview

[https://github.com/microsoft/vscode/issues/337448](https://github.com/microsoft/vscode/issues/337448)

## Summary

Legitimate, well-diagnosed gap: the new Markdown editor (`vscode.markdown.editor`) has no equivalent to `markdown.markdownItPlugins` for extending syntax, confirmed by inspecting the source — the only extension point is `markdown.codeBlockEditorProviders`, which only covers fenced code blocks, not inline/block syntax. No maintainer has weighed in on design yet, so this stays open rather than closing on the `stale` label.

## Change summary

Add a contribution point letting extensions add custom Markdown syntax (inline or block, not just code-fence content) to the new WYSIWYG-style Markdown editor, mirroring what `markdown.markdownItPlugins` already does for the preview.

## Best solution

A maintainer should decide the extension mechanism — full micromark syntax extensions with render/serialize hooks, versus a narrower read-only node/pattern registration — then implement it in extensions/markdown-language-features (markdownExtensions.ts contribution parsing plus the markdown-editor-src bundle); until that design choice is made, this stays a planning item.
