## Summary

Well-documented, actively-acknowledged bug: a VS Code team member confirmed Windows AppContainer sandboxing is experimental and being worked on, with an interim workaround (grant read access to C:\). No fix has landed yet, so this stays open.

## Change summary

On Windows, enabling the Copilot Agent Host SDK sandbox causes every sandboxed command to fail immediately with STATUS_ACCESS_DENIED (0xC0000022), even though the AppContainer itself is created successfully.

## Best solution
