# Issue #316791 — Agents App: git commit hangs when commit signing (gpg.format=ssh) is enabled due to missing GIT_ASKPASS environment variable

[https://github.com/microsoft/vscode/issues/316791](https://github.com/microsoft/vscode/issues/316791)

## Summary

Confirmed in current source: the agent host git service and terminal manager do not inject `GIT_ASKPASS` into the environment, so `git commit` with SSH signing hangs indefinitely on a TTY prompt that can never be answered. The recent removal of `--no-gpg-sign` (commit 8c7f8a1409f) made GPG signing reachable but the environment still lacks the askpass plumbing.

## Change summary

Git commits in the Agents App hang indefinitely when the user has SSH commit signing enabled because the non-interactive environment is missing `GIT_ASKPASS`.

## Best solution

Inject `GIT_ASKPASS` (and the supporting `VSCODE_GIT_ASKPASS_*` variables) into the agent host git environment — both in `AgentHostGitService._runGit` and in `AgentHostTerminalManager`'s non-interactive env setup — mirroring what the built-in Git extension already does via `extensions/git/src/askpass.ts`. This ensures SSH signing can prompt through VS Code's askpass helper instead of falling back to `/dev/tty`.

## Evidence

- **missing env vars:** No occurrence of `GIT_ASKPASS`, `SSH_ASKPASS`, or `VSCODE_GIT_ASKPASS` anywhere under `src/vs/platform/agentHost/` — confirmed via `rg`.
- **terminal manager env:** `src/vs/platform/agentHost/node/agentHostTerminalManager.ts` line 291 sets `GIT_TERMINAL_PROMPT=0` for non-interactive terminals but does not set `GIT_ASKPASS`, leaving git with no way to prompt for passphrases.
- **_runGit method:** `src/vs/platform/agentHost/node/agentHostGitService.ts` line 550-564: `_runGit` spawns `git` via `cp.execFile` with no `GIT_ASKPASS` in the environment.
- **no-gpg-sign removal:** Commit https://github.com/microsoft/vscode/commit/8c7f8a1409f (2026-07-08) removed `--no-gpg-sign` from `commitAll`, enabling GPG signing but without the askpass plumbing to support it.
- **built-in git has it:** The built-in Git extension already implements askpass correctly via `extensions/git/src/askpass.ts` and the `askpass.sh` helper — the agent host needs equivalent plumbing.
