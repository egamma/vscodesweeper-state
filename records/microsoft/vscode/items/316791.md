# Issue #316791 — Agents App: git commit hangs when commit signing (gpg.format=ssh) is enabled due to missing GIT_ASKPASS environment variable

[https://github.com/microsoft/vscode/issues/316791](https://github.com/microsoft/vscode/issues/316791)

## Summary

Valid bug: the Agents App bash tool environment lacks GIT_ASKPASS, causing git commit to hang indefinitely when SSH commit signing is configured. No fix found on current main.

## Change summary

Git commit hangs in Agents App sessions when gpg.format=ssh commit signing is enabled because GIT_ASKPASS is not set in the bash tool environment.

## Best solution

The agent host's terminal/bash tool environment should inject GIT_ASKPASS (and related VSCODE_GIT_ASKPASS_* variables) the same way VS Code's built-in git extension does for its spawned processes. The fix likely belongs in the agent host environment setup under src/vs/platform/agentHost/ or wherever the sessions bash tool spawns processes.
