# Issue #343968 — Copilot Connectors: detail page has no Cancel action while connecting

[https://github.com/microsoft/vscode/issues/343968](https://github.com/microsoft/vscode/issues/343968)

## Summary

Keep open: current source confirms that the connector detail page disables its only action while connecting, whereas Browse exposes cancellation. The report identifies a concrete inconsistency with the maintainer-authored test expectations, not a missing reproduction.

## Change summary

Expose an enabled Cancel action on connector detail pages while authorization is pending, and restore Connect after cancellation.

## Best solution

Make pending connector connections cancellable directly from EmbeddedMarketplaceDetail while retaining the connecting status and the existing Browse behavior. Cancellation should stop the local attempt without reporting successful connection or an ordinary connection failure.
