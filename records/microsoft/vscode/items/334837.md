# Issue #334837 — Main process leaks every terminal's pty output: `ProxyChannel.fromService(PtyHostService)` buffers `onProcessData` via `Event.buffer` for a `localPty` listener that never attaches

[https://github.com/microsoft/vscode/issues/334837](https://github.com/microsoft/vscode/issues/334837)

## Summary

Verified duplicate: this is the same main-process pty-buffer leak already tracked (and much earlier reported, team-assigned) as issue #234393, with an open fix PR against that canonical — the reporter themselves confirmed the duplicate in a later comment.

## Change summary

Main process leaks unbounded pty output because ProxyChannel.fromService buffers every PtyHostService event (including onProcessData) on the localPty channel that no renderer ever listens() on, causing linear heap growth and eventual OOM crash.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/234393 and land https://github.com/microsoft/vscode/pull/323980 (adds unbufferedEvents for the pty stream events in src/vs/code/electron-main/app.ts), which fixes exactly this defect; no separate work needed here.
