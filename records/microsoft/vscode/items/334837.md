# Issue #334837 — Main process leaks every terminal's pty output: `ProxyChannel.fromService(PtyHostService)` buffers `onProcessData` via `Event.buffer` for a `localPty` listener that never attaches

[https://github.com/microsoft/vscode/issues/334837](https://github.com/microsoft/vscode/issues/334837)

## Summary

Verified duplicate of the open, assigned, higher-severity canonical issue #234393 — the author of this report independently traced and confirmed the same root cause and asked for consolidation themselves.

## Change summary

Main process leaks unbounded pty output because ProxyChannel.fromService eagerly buffers the localPty channel's onProcessData event that no renderer ever listens to, causing a V8 heap OOM crash of the browser process.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/234393 (open, labeled bug/important/freeze-slow-crash-leak, assigned to dmitrivMS and anthonykim1) and land https://github.com/microsoft/vscode/pull/323980, which adds a `disableEventBuffering` option to `ProxyChannel` and applies it to the LocalPty channel — that PR explicitly says `Fixes #234393` and matches this report's root cause exactly.
