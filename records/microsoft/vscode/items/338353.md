# Issue #338353 — Terminal output preview misses vertical scrollbar

[https://github.com/microsoft/vscode/issues/338353](https://github.com/microsoft/vscode/issues/338353)

## Summary

Confirmed from source: the chat terminal output preview's scrollable container hardcodes the vertical scrollbar to Hidden and only toggles the horizontal one to Auto on hover/focus, so a vertically-overflowing preview never shows a scrollbar even though it is still scrollable — matches the reported screenshot.

## Change summary

The terminal command output preview in chat never shows a vertical scrollbar even when content overflows the capped preview height.

## Best solution

Mirror the existing horizontal hover/focus toggle for the vertical scrollbar in `_createScrollableContainer` in chatTerminalToolProgressPart.ts so it also becomes `Auto` on hover/focus (or whenever content overflows vertically), consistent with the horizontal behavior added in the same method.
