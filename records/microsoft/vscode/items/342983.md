# Issue #342983 — agentHost: batch AgentHostDatabase schema migrations into fewer durable commits

[https://github.com/microsoft/vscode/issues/342983](https://github.com/microsoft/vscode/issues/342983)

## Summary

Keep open: current main still commits each pending schema migration separately. The merged timeout adjustment explicitly leaves this optimization outstanding, and no qualifying fix or canonical duplicate was identified.

## Change summary

Reduce durable commits during AgentHostDatabase initialization while preserving migration correctness, recovery, and compatibility.

## Best solution

Batch compatible schema migrations in AgentHostDatabase initialization without weakening SQLite durability or changing the resulting schema and stored data. Establish which normalization and repair operations require independent transaction boundaries, then verify reduced commit counts and failure recovery.
