# Issue #70589 — Settings UI is overwhelming for extensions with lots of settings

[https://github.com/microsoft/vscode/issues/70589](https://github.com/microsoft/vscode/issues/70589)

## Summary

This is a long-standing, well-discussed feature request (25 upvotes) for richer extension settings presentation — ordering was partially addressed, but grouping, collapsible sections, custom labels/casing, images, and simple/advanced modes remain unimplemented. Stays open in Backlog as a valid tracking issue.

## Change summary

Extensions with many settings need better control over ordering, grouping, labeling, and progressive disclosure in the Settings UI.

## Best solution

Incrementally address the highest-value sub-items: sub-extension grouping with collapsible sections in the ToC and main view (settings-editor area), and custom label/casing control for setting titles. Each could land independently. The related open issue https://github.com/microsoft/vscode/issues/115409 (.enabled convention) covers one slice of progressive disclosure.
