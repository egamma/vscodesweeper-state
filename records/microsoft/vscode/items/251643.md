# Issue #251643 — Option to accept/discard hunk does not show when opening diffs from SCM view

[https://github.com/microsoft/vscode/issues/251643](https://github.com/microsoft/vscode/issues/251643)

## Summary

Still open by design: the code at line 130 of chatEditingCodeEditorIntegration.ts intentionally disables Keep/Undo buttons for non-entry diff editors (including SCM diffs), and comment discussion explicitly deferred this pending a UX resolution for the mixed LLM-and-manual-change confusion problem.

## Change summary

Accept/discard hunk buttons do not appear when opening diffs from the SCM changes view, only from the inline editor diff icon.

## Best solution

Revisit the UX design so that Keep/Undo buttons appear only on LLM-originated hunks in SCM diffs without confusing users about manual changes. The guard is in `src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingCodeEditorIntegration.ts` (line ~130, `isTextDiffEditorForEntry` check). Needs a team UX decision before implementation.
