# Issue #205369 — Git - Unable to see buttons when list of conflicting tag(s) is too long.

[https://github.com/microsoft/vscode/issues/205369](https://github.com/microsoft/vscode/issues/205369)

## Summary

Keep open: current Git code still puts the entire conflicting-tag list into a native modal message. The native runtime has changed since the report, so the macOS overflow and window displacement remain unverified, but the supplied steps suffice to retest both.

## Change summary

A pull with many conflicting tags produces an oversized dialog with inaccessible buttons and leaves the macOS workbench window displaced after dismissal.

## Best solution
