# Issue #333509 — Test Explorer: show test counts on tree nodes (project / namespace / class)

[https://github.com/microsoft/vscode/issues/333509](https://github.com/microsoft/vscode/issues/333509)

## Summary

Per-node discovery counts remain absent from the current Test Explorer. Keep this request open: the testing maintainer welcomed a contribution for fully materialized subtrees, while explicitly ruling out reliable totals for undiscovered lazy subtrees.

## Change summary

Optionally display aggregate descendant test-case counts beside Test Explorer project, namespace, class, and folder nodes.

## Best solution

Provide opt-in per-node counts for fully materialized subtrees without triggering discovery or presenting incomplete totals as exact. Settle the counting semantics for provider-defined test hierarchies before implementation.
