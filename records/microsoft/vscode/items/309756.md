## Summary

Keep this accepted Backlog request open: it has 23 upvotes, and the inspected source does not provide a Finder Quick Look extension synchronized with VS Code's theme. Earlier Quick Look requests were closed, but those decisions do not establish completion or override this item's later Backlog acceptance.

## Change summary

Bundle an optional macOS Quick Look preview extension that uses VS Code's language grammars and follows the user's active theme.

## Best solution

Have the macOS integration owner evaluate a separately hosted, optional preview component that reuses VS Code's tokenization and theme data without starting the full editor. Resolve the distribution and theme-selection contract before committing to implementation, taking the earlier unsuccessful integration into account.
