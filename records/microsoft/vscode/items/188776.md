# Issue #188776 — Settings UI: Right click on setting should behave the same as click on ⚙️ 

[https://github.com/microsoft/vscode/issues/188776](https://github.com/microsoft/vscode/issues/188776)

## Summary

Still unimplemented on main: there is no DOM `contextmenu` event listener on setting rows — `showContextMenu` is only invoked via the keyboard command or the ⚙️ toolbar click. Valid polish/UX request that belongs in the settings editor area.

## Change summary

Right-clicking a setting row in the Settings UI should open the same context menu as clicking the ⚙️ gear icon.

## Best solution

Add a `contextmenu` DOM event listener on each setting row element (in `settingsTree.ts` renderers) that calls the existing `showContextMenu` with the appropriate element and DOM anchor, so right-click behaves the same as the gear icon.
