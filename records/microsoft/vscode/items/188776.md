## Summary

The requested right-click shortcut remains absent from the Settings UI wiring on current main. Keep this accepted Backlog request open: the existing toolbar and keyboard command provide the actions, but neither covers opening them by right-clicking a setting row.

## Change summary

Allow right-clicking a setting row to open the same actions menu as its gear button.

## Best solution

Provide a consistent row context menu in the Settings editor with the same setting-specific actions as the toolbar, while preserving appropriate text-editing context menus inside editable controls.
