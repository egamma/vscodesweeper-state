# Issue #233170 — Support comment toggling for languages that do not support content on the first column

[https://github.com/microsoft/vscode/issues/233170](https://github.com/microsoft/vscode/issues/233170)

## Summary

The requested second-column comment toggling is now supported through language configuration. The merged implementation preserves leading whitespace in the configured token and recognizes it when toggling comments off, so this can be closed as completed.

## Change summary

Allow language extensions to configure comment toggling so the first column remains blank and the comment indicator appears in the second column.

## Best solution

Use comments.lineComment: { "comment": " !", "noIndent": true } in the language extension's language-configuration.json. The implementation in d9145a291dcef0bad3ace81a3d55727ca294c122 supplies the requested capability without changing tab size.
