# Issue #247218 — Index in model selector is skipping the first item of the 11 options

[https://github.com/microsoft/vscode/issues/247218](https://github.com/microsoft/vscode/issues/247218)

## Summary

Fixed on current main: ActionList now excludes headers and separators from its accessible item count and position, so the first model is announced as item 1 rather than item 2.

## Change summary

The model picker counted its non-actionable header as the first listbox item, causing screen readers to announce the first model as item 2 of 11.

## Best solution

Keep the ActionList-level fix from https://github.com/microsoft/vscode/commit/e08af174ec1882d58850385a1b5fe7931b033437, which corrects every consumer including the model picker and code-action widget.
