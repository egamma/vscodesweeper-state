# Issue #283453 — MCP Auth integration with Entra Id

[https://github.com/microsoft/vscode/issues/283453](https://github.com/microsoft/vscode/issues/283453)

## Summary

Keep open for the authentication owners to resolve the tenant-selection question. The thread contains maintainer support for user control as well as concerns about an OAuth-generic solution; neither a verified fix nor an eligible duplicate settles that discussion.

## Change summary

Clarify and potentially extend MCP authentication so personal accounts and B2B guests can authenticate against the intended Entra tenant.

## Best solution

Establish whether MCP users should be able to select a resource tenant independently of the server-advertised authorization server, and define how that interacts with OAuth metadata. Preserve the working tenant-specific authority path and distinguish server app-registration or issuer-validation requirements from client authentication defects.
