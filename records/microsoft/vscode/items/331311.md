## Change summary

Play a configurable audible notification when the embedded Claude harness requests permission, matching the Local harness.

## Best solution

Claude permission prompts should participate in the shared Chat User Action Required accessibility signal and respect accessibility.signals.chatUserActionRequired, rather than require platform-specific shell hooks or a separate sound setting.
