# Issue #331311 — Add an sound notification for Claude harness permission prompts

[https://github.com/microsoft/vscode/issues/331311](https://github.com/microsoft/vscode/issues/331311)

## Summary

Fresh, well-scoped feature request just entered the standard 60-day Backlog Candidates window (0 upvotes so far) — keeping it open per the community process rather than closing for being new/quiet.

## Change summary

The Claude agent harness doesn't play the chatUserActionRequired sound/announcement when it needs a permission decision, unlike the local harness.

## Best solution

Wire the agent host's Claude permission-request path (ClaudeAgentSession.requestPermission → the `pending_confirmation` protocol state consumed by stateToProgressAdapter.ts) to fire AccessibilitySignal.chatUserActionRequired the same way languageModelToolsService.ts's playAccessibilitySignal does for local tool invocations, gated by the existing chatUserActionRequired sound/announcement setting.
