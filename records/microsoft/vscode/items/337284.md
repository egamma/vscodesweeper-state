# Issue #337284 — Staging a file with * adds unrelated files

[https://github.com/microsoft/vscode/issues/337284](https://github.com/microsoft/vscode/issues/337284)

## Summary

The built-in Git extension still passes the selected filename as a wildcard pathspec, allowing staging '*.md' to stage another.md too. Keep this open and route it to Git; no verified canonical or fixing implementation was found.

## Change summary

Staging a file whose literal name contains an asterisk also stages unrelated matching files.

## Best solution

Single-file staging should honor the literal selected filename, including valid Linux filenames containing wildcard characters, while preserving intentional bulk-staging behavior.
