# Issue #316204 — Commit message generation fails with promptFiltered (422) on innocuous diff

[https://github.com/microsoft/vscode/issues/316204](https://github.com/microsoft/vscode/issues/316204)

## Summary

Keep this as the canonical report for commit-message filtering failures with benign custom instructions. Multiple confirmed reproductions establish an actionable defect, and neither the available workarounds nor the inspected source establishes a completed fix.

## Change summary

Commit-message generation rejects harmless diffs and custom instructions with promptFiltered (422), leaving the SCM input unchanged without an actionable explanation.

## Best solution

Diagnose the rendered commit prompt and default utility-model filtering together so benign custom instructions work without requiring users to remove them or switch models. Surface an actionable filtering explanation in SCM when generation is rejected, without weakening legitimate content protections.
