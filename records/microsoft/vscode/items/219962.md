# Issue #219962 — Stage block does not work at end of file

## Summary

The EOF staging failure in the reported 1.88.1 build is addressed by commit 9858988cd52ed049e0e299b012e0c8f176162a22. Tracing the current Stage Block path confirms that it no longer constructs the out-of-bounds edit endpoint that prevented staging.

## Change summary

Stage Block does nothing for a changed block reaching EOF without a trailing newline, while manually staging the selected range works.
