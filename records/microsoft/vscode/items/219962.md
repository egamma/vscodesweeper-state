## Change summary

The diff editor's Stage Block button does nothing for a change ending at EOF without a trailing newline, although staging the selected range works.

## Best solution

Stage Block should stage the entire EOF hunk without changing newline termination or including unrelated changes. Obtain a current reproduction, then investigate the diff gutter's staged-content construction and the built-in Git staging command.
