# Issue #306235 — Feature Request: Add `.cws` (or `.vsws`, `.vscw`) as an official short alias for `.code-workspace`

[https://github.com/microsoft/vscode/issues/306235](https://github.com/microsoft/vscode/issues/306235)

## Summary

Adding an alternate file extension alias for .code-workspace introduces OS file-association fragmentation, ecosystem confusion (extensions, CLI tools, documentation), and maintenance burden for a marginal typing convenience — this is out of scope for VS Code core.

## Change summary

Add a shorter file extension alias (e.g. .cws) that VS Code recognizes interchangeably with .code-workspace.

## Best solution

Keep .code-workspace as the single canonical extension. The verbosity is intentional — it makes workspace files self-documenting and avoids namespace collisions. Users who want shorter names can use shell aliases or symlinks locally.

## Vision fit
