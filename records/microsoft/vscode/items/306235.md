## Summary

The requested short workspace-file alias is not supported by current source. An earlier equivalent request closed through the community upvote process, not a technical or scope decision; keep this request open for discussion rather than treating that closure or inactivity as grounds to decline it.

## Change summary

Recognize a short extension such as .cws, .vsws, or .vscw as an official alias for .code-workspace while preserving existing workspace behavior.

## Best solution

Decide whether an additional official workspace extension warrants its compatibility and file-association commitments. If accepted, make recognition consistent across workspace opening, discovery, file dialogs, and platform associations while retaining .code-workspace support.
