# Issue #90181 — [Feature-request] Remove cursor

[https://github.com/microsoft/vscode/issues/90181](https://github.com/microsoft/vscode/issues/90181)

## Summary

The requested reversal behavior remains missing: opposite-direction cursor commands add cursors rather than retracting the last addition. Keep this accepted Backlog request open; its 24 upvotes support a maintainer-led design session.

## Change summary

Allow reversing multi-cursor creation direction to remove the most recently added cursor, including occurrence-selection workflows.

## Best solution

Provide a deliberate, consistent way to retract cursor additions through the opposite-direction operation, while preserving existing additive workflows unless a maintainer explicitly chooses to change them. Settle the compatibility and occurrence-selection semantics before implementation.

- **Behavior:**

  > The requested interaction lets users retract multi-cursor additions by reversing creation direction. In the supplied three-line example, adding downward twice and then reversing upward twice leaves cursors on lines 1 and 2, then only line 1, without changing text. The request also includes occurrence selection through Ctrl+D. Acceptance must cover the exact cursor positions and counts, the agreed occurrence-selection behavior, and compatibility with existing additive commands.
- **Trace:**

  > InsertCursorAbove and InsertCursorBelow in src/vs/editor/contrib/multicursor/browser/multicursor.ts delegate to CursorMoveCommands.addCursorUp/addCursorDown in src/vs/editor/common/cursor/cursorMoveCommands.ts. Those methods retain all original cursors and add translated copies; overlap normalization merges duplicates rather than retracting the latest addition. MultiCursorSession's next/previous occurrence methods likewise append selections. cursorUndo in src/vs/editor/contrib/cursorUndo/browser/cursorUndo.ts provides separate selection-history undo, not directional reversal, and clears history on content changes. The unresolved boundary is the user-visible activation and reversal contract, not helper placement.
- **Open decisions:**
