# Issue #90181 — [Feature-request] Remove cursor

[https://github.com/microsoft/vscode/issues/90181](https://github.com/microsoft/vscode/issues/90181)

## Summary

Keep open in the Backlog: the request earned 24 community upvotes, and current main still adds cursors unconditionally when reversing direction. Cursor Undo is a workaround but does not provide the requested interaction.

## Change summary

Make adding a cursor in the opposite direction remove the most recently added cursor, including cursors created through Ctrl/Cmd+D.

## Best solution

Define consistent reversal semantics for Add Cursor Above/Below and occurrence-based multicursor commands, then implement them in the editor multicursor contribution without changing ordinary Cursor Undo behavior.
