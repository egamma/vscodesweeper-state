Keep open for resolution of the obsolete installer entry point: another reporter confirmed the same download failure. The supported replacement is the standalone code CLI, but that does not establish that the reported URL was repaired.

## Change summary

The installation command in the July 2022 VS Code Server blog redirects to a hostname that reporters cannot resolve.

## Best solution

Restoring the retired code-server launcher is not necessary to deliver server access.
