# Issue #178078 — ViewPane saveState is not called before view is disposed

[https://github.com/microsoft/vscode/issues/178078](https://github.com/microsoft/vscode/issues/178078)

## Summary

Still present on main: when a ViewPane is removed (e.g. dragged to the panel), `removePane` disposes it without calling `saveState()` first. The `saveState()` call only happens during the workbench shutdown lifecycle, not on individual pane removal. Team-authored issue, keeping open.

## Change summary

ViewPane.saveState() is never called before the view is disposed when a view container is moved (e.g. dragged to the panel).

## Best solution

Call `pane.saveState()` in `ViewPaneContainer.removePane()` before `paneItem.disposable.dispose()`, so individual view state is persisted when views are removed outside of the shutdown path. Needs careful evaluation of whether all removePane callers expect this.
