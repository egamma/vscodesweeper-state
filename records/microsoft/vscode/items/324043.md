# Issue #324043 — "explorer.sortOrder": "filesFirst" doesn't apply in "Source control" view with "View as Tree"

[https://github.com/microsoft/vscode/issues/324043](https://github.com/microsoft/vscode/issues/324043)

## Summary

Keep open for an SCM tree-sorting product decision. Current source confirms the missing capability, but explorer.sortOrder is explicitly Explorer-only, making this a feature request rather than a broken existing SCM setting.

## Change summary

Allow Source Control tree mode to display files before folders or interleave files and folders alphabetically.

## Best solution

Provide configurable file/folder ordering in the SCM tree while retaining existing list-sort behavior. The area owner should decide whether SCM inherits Explorer ordering or exposes an independent preference.
