# Issue #167863 — Column number is incorrect when using tabs.

[https://github.com/microsoft/vscode/issues/167863](https://github.com/microsoft/vscode/issues/167863)

## Summary

Valid feature request: the status bar column display intentionally shows the visual column (tabs expanded), and no setting exists to show character offset instead. Already promoted to Backlog with sufficient upvotes — keeping open.

## Change summary

Request an option to show character position (1-based offset) instead of visual column in the status bar, so tab characters count as one column each.

## Best solution

Add a setting (e.g. `editor.statusBarColumnMode` with values `visualColumn` / `characterOffset`) that controls how the status bar computes the column number. The change would be localized to `CursorColumns.toStatusbarColumn` in `src/vs/editor/common/core/cursorColumns.ts` and the status bar update path in `src/vs/workbench/browser/parts/editor/editorStatus.ts`.
