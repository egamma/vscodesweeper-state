# Issue #341970 — Model cost no longer visible in tooltip from 1.142.0+

[https://github.com/microsoft/vscode/issues/341970](https://github.com/microsoft/vscode/issues/341970)

## Summary

Keep open as model-picker usability feedback: current source puts pricing behind a details page rather than providing the requested hover comparison. This appears consistent with the new picker's design, but that does not resolve the extra-navigation concern or establish grounds to decline it.

## Change summary

Make model costs available while browsing the model selector without opening and leaving each model's details page.

## Best solution

Provide a lightweight way to compare available model pricing without leaving the picker list, while preserving the existing details and configuration workflow. The model-picker owner should decide whether pricing belongs in a hover preview or directly in the list.
