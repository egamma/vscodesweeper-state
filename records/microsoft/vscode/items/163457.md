# Issue #163457 — Add workspace folder path to context keys.

[https://github.com/microsoft/vscode/issues/163457](https://github.com/microsoft/vscode/issues/163457)

## Summary

A real context-key gap remains on current main, and this accepted Backlog request has 34 community upvotes. The existing `resourcePath` identifies the selected resource but not its containing workspace root.

## Change summary

Expose the containing workspace-folder path as a resource context key so extensions can conditionally show commands for selected folders and descendants.

## Best solution

Add a resource-scoped workspace-folder path or URI key alongside `resourcePath` in `AbstractResourceContextKey`, populated for the active or context-menu resource, so extensions can compare it against workspace roots supplied through `setContext`.
