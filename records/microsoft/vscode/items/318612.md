# Issue #318612 — BG Todo tool disablement

[https://github.com/microsoft/vscode/issues/318612](https://github.com/microsoft/vscode/issues/318612)

## Summary

Keep open: current source excludes free users and declares the background agent off by default, but its enablement gate still lacks a Plan-mode exclusion and experiments can enable it. This reopened, team-authored request has no verified complete fix or canonical covering its full scope.

## Change summary

Disable background todo processing in Plan mode and make todo behavior disabled by default.

## Best solution

Ensure Plan sessions do not run background todo processing, including the final review pass. Settle whether default disablement covers the background agent alone or also the ordinary manage_todo_list tool, and whether experiment enrollment may override that default.
