# Issue #58315 — [html] Automatically delete HTML closing tag when converting to self-closing tag

[https://github.com/microsoft/vscode/issues/58315](https://github.com/microsoft/vscode/issues/58315)

## Summary

This remains a valid, well-supported backlog request: converting an existing paired HTML or JSX element into a self-closing element still needs coordinated removal of the closing tag. It exceeded the community threshold with 36 upvotes, and no verified canonical issue or shipped capability was identified.

## Change summary

Automatically remove the matching closing tag when a user converts an HTML or JSX opening tag to self-closing syntax.

## Best solution

Add linked-editing behavior that recognizes insertion of the self-closing slash in an opening HTML or JSX tag and removes its syntactically matched closing tag, while leaving unrelated or malformed markup unchanged.

Existing Emmet expansion behavior, including direct self-closing abbreviations such as `App/`, must continue to work.
