# Issue #185098 — Add proxy support to `http2` requests in the extension host

[https://github.com/microsoft/vscode/issues/185098](https://github.com/microsoft/vscode/issues/185098)

## Summary

The raw Node.js `http2` module remains outside the extension host's proxy patching, while proxy-aware `fetch` now provides an HTTP/2-capable alternative. This team-authored Backlog request cannot receive a judgment close, and the latest maintainer comment says the specific `http2` work is not currently planned.

## Change summary

Make extension-host requests created through Node.js `http2` honor VS Code's proxy configuration automatically.

## Best solution

Keep the existing proxy-aware `fetch`/Undici path as the supported HTTP/2 option for extensions, while retaining this issue for a future decision on whether transparent proxy handling for raw `http2.connect()` is worth the compatibility and maintenance cost.
