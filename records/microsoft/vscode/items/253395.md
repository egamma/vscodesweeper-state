# Issue #253395 — feature: update PR once created with agent

[https://github.com/microsoft/vscode/issues/253395](https://github.com/microsoft/vscode/issues/253395)

## Summary

Current cloud sessions support follow-up messages, but that does not establish that another delegation from the original local chat updates the existing PR. Keep this team-authored item open: no issue-referencing fix or qualifying older duplicate was established.

## Change summary

Allow follow-up instructions from the chat that initiated a cloud coding task to update its existing PR rather than create another PR.

## Best solution

Preserve continuity between the initiating chat and its cloud task so an explicit follow-up targets the existing task and PR, while intentionally starting separate work remains possible. Retest the original-chat delegation flow rather than treating follow-ups inside a dedicated cloud session as equivalent coverage.
