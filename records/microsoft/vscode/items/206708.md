# Issue #206708 — javascript and typescript: "conditions" configuration setting for conditional export resolution in package.json

[https://github.com/microsoft/vscode/issues/206708](https://github.com/microsoft/vscode/issues/206708)

## Summary

Keep this accepted Backlog request open and route it to the JavaScript/TypeScript owners. TypeScript's `customConditions` covers project configuration, but VS Code still lacks the requested editor-level setting that merges conditions into language-service configuration.

## Change summary

Allow users to configure conditional package export/import conditions used by VS Code's JavaScript and TypeScript language service.

## Best solution

Add a JavaScript/TypeScript setting whose values are forwarded as `customConditions` for language-service projects, while preserving explicit `tsconfig.json` and `jsconfig.json` behavior.
