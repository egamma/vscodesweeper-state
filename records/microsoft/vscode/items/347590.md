# Issue #347590 — Agents window: Close Canvas fails on remote agent hosts - Closing canvases is unavailable for this session

[https://github.com/microsoft/vscode/issues/347590](https://github.com/microsoft/vscode/issues/347590)

## Summary

Current source confirms that the Agents window offers Close Canvas on remote connections that cannot perform it. Keep this scheduled, team-authored bug open for its 1.147.0 milestone.

## Change summary

Make remote canvas closing work, or stop offering Close Canvas when the owning connection cannot close it.

## Best solution

Support provider-notifying canvas closure on capable remote hosts, with consistent capability gating across canvas pills and pinned-canvas actions so unsupported hosts never offer a failing operation.
