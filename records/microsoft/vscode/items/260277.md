[https://github.com/microsoft/vscode/issues/260277](https://github.com/microsoft/vscode/issues/260277)

## Summary

This is as-designed: on Windows with accessibility mode enabled, Ctrl+Shift+Left/Right word-selection shortcuts are intentionally suppressed so screen readers can use those keys. The reporter confirmed the fix (disabling accessibility support) in their own follow-up comment.

## Change summary

Ctrl+Shift+Left/Right word selection does nothing when Windows accessibility mode is active.

## Best solution

Close as designed — the keybinding's `when` clause deliberately excludes accessibility mode on Windows (see `wordOperations.ts` line 170). The reporter already found the workaround (`editor.accessibilitySupport: "off"`).
