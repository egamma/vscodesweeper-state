# Issue #160573 — WebSocket is not open: readyState 3 (CLOSED)

[https://github.com/microsoft/vscode/issues/160573](https://github.com/microsoft/vscode/issues/160573)

## Summary

Team-authored error-telemetry item. The original v8-inspect-profiler code path was replaced in April 2026 (commit 7c6d456ec30), but the new implementation still lacks a guard against a closed WebSocket when stopping profiling — the same class of race could recur. No commit explicitly references this issue, so it stays open.

## Change summary

WebSocket 'readyState 3 (CLOSED)' error thrown when stopping a V8 profiling session because the debug target disconnected before the stop command was sent.

## Best solution

Add a try/catch or readyState guard around the `Profiler.stop()` call in `src/vs/base/node/profiling.ts` so that a closed connection yields a graceful 'profiling session lost' error rather than an unhandled WebSocket exception. Alternatively, verify via error telemetry whether this error class still fires after the v8-inspect-profiler removal — if it's gone, close as completed.
