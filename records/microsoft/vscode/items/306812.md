# Issue #306812 — White flash when reloading window & using Dark theme

[https://github.com/microsoft/vscode/issues/306812](https://github.com/microsoft/vscode/issues/306812)

## Summary

Keep open as an Electron/macOS window-background limitation. The reporter repeatedly confirmed the behavior, and the current source already attempts to update the native window background after a theme change, but the maintainer reports that the initial background remains fixed for reload.

## Change summary

Avoid flashing the original light native-window background when reloading after switching macOS and VS Code to a dark theme.

## Best solution

Reduce this to an Electron BrowserWindow reproduction on macOS and link or open the corresponding upstream issue. Once Electron can reliably update the native background after window creation, VS Code's existing splash-update path should keep reloads aligned with the active theme.
