  > Thanks for the report. The list you pasted is VS Code's 'Terminal Environment Changes' view, which shows the environment variables that your installed extensions add to integrated terminals through the extension API. This is expected behavior, and the entries are not an attack.
  > 
  > - GitHub Copilot Chat adds `copilot-debug` and `copilot` to your `PATH`.
  > - Claude Code sets a local port for its IDE integration.
  > - The built-in Git extension sets variables for git authentication prompts.
  > - The Python extension sets `PYTHONSTARTUP` for terminal shell integration.
  > 
  > To stop a given change, disable or uninstall the extension that contributes it. You can also turn off the specific feature, for example `python.terminal.shellIntegration.enabled` for the Python entry. The variables only affect terminals launched from VS Code, not the rest of your system. Closing this as a support question. Please open a new issue if you find a concrete bug.
