# Issue #170664 — Workspace Trust - icon on the status bar cannot be pinned and always resets the state after a restart

[https://github.com/microsoft/vscode/issues/170664](https://github.com/microsoft/vscode/issues/170664)

## Summary

The workspace trust status bar icon is intentionally shown only in restricted (untrusted) workspaces as a warning indicator — the code actively removes it when the workspace is trusted, so pinning via the context menu cannot persist across restarts for a trusted workspace.

## Change summary

User wants the workspace trust status bar icon to remain visible (pinned) in trusted workspaces across restarts.

## Best solution

Close as designed: the workspace trust status bar entry is a warning indicator for restricted mode, not a persistent status item. In `WorkspaceTrustUXHandler.updateStatusbarEntry()`, the entry is explicitly cleared when the workspace is trusted. Showing it permanently for trusted workspaces would contradict its role as an untrusted-mode warning.
