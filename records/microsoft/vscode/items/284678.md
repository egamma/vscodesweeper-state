# Issue #284678 — GitHub Copilot race condition prevents stopping processing of a submitted prompt.

[https://github.com/microsoft/vscode/issues/284678](https://github.com/microsoft/vscode/issues/284678)

## Summary

Keep open for maintainer investigation of the edit/resubmit cancellation race. The discussion confirms continued agent activity after Stop, but neither the related cancellation fix nor an open canonical issue conclusively accounts for this trigger.

## Change summary

Repeatedly editing and resubmitting a previous Copilot prompt can leave processing active despite pressing Stop.

## Best solution

Ensure Stop cancels the active response after editing or resubmitting a prompt, without leaving an earlier response performing further work. Investigate the request replacement and cancellation lifecycle in ChatWidget and ChatService, distinguishing it from the language-model RPC cancellation defect already fixed.

Its response-completion cleanup at lines 2075-2083 checks request identity before removing the registration. These mechanisms do not by themselves prove the reported race resolved.
