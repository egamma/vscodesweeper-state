# Issue #284678 — GitHub Copilot race condition prevents stopping processing of a submitted prompt.

[https://github.com/microsoft/vscode/issues/284678](https://github.com/microsoft/vscode/issues/284678)

## Summary

The cancellation race was fixed by merged PR https://github.com/microsoft/vscode/pull/319098. Current main preserves cancellation both when Stop is pressed before the provider request starts and after the start RPC has returned, covering the reported edit/resubmit timing.

## Change summary

Rapidly editing, resubmitting, and stopping a Copilot request could leave the provider running while the Stop button had no effect.

## Best solution

Keep the explicit cross-process cancellation channel introduced by commit 3d87c046caabc5c8428c8af3a893149080deeec5 and its regression coverage; no additional change is indicated unless the problem returns on a current build.
