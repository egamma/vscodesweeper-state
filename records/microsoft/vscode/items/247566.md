# Issue #247566 — Tools icon doesn't have visual indication if all/some/none tools are added

[https://github.com/microsoft/vscode/issues/247566](https://github.com/microsoft/vscode/issues/247566)

## Summary

Keep this team-authored design discussion open: current source still exposes a static Configure Tools icon, while the thread explicitly says the previous indication was removed intentionally. The related redesign and custom-agent requests inform the decision but are newer and do not qualify as duplicate targets for this re-reviewed item.

## Change summary

Make the chat tools control communicate whether all, some, or none of the available tools are enabled.

## Best solution

Resolve the tool-selection visibility requirement alongside the prompt-area redesign, explicitly deciding whether users need an at-rest selection indicator or whether hover and picker details suffice. Preserve the intentional reduction in toolbar clutter rather than restoring tick badges without design agreement.
