# Issue #338963 — notebook.codeActionsOnSave does nothing when the notebook's first cell is markdown

[https://github.com/microsoft/vscode/issues/338963](https://github.com/microsoft/vscode/issues/338963)

## Summary

Traced to source: both the notebook-kind code-actions-on-save path and the notebook format-on-save path anchor on `notebookModel.cells[0]` unconditionally, so when the first cell is markdown the 'notebook.*' code action (and notebook format) is requested against a markdown text model, which yields no actions and silently no-ops — matching the reporter's 'nothing happens, no error' symptom exactly.

## Change summary

`notebook.codeActionsOnSave` (and likely notebook-level format-on-save) silently does nothing when the notebook's first cell is markdown instead of code.

## Best solution

In saveParticipants.ts, anchor notebook-kind code actions (and the notebook format-on-save check) on the first *code* cell rather than literally `cells[0]`, mirroring the existing `viewCells.find(cell => cell.cellKind === CellKind.Code)` pattern already used elsewhere in the notebook contrib (e.g. cellOperations.ts).
