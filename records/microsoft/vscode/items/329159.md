# Issue #329159 — new switch editor type dropdown in breadcrumbs only appears in agents window not editor

[https://github.com/microsoft/vscode/issues/329159](https://github.com/microsoft/vscode/issues/329159)

## Summary

Confirmed as a real, still-present gap on current main: the `showEditorTypePicker` option is only passed to `BreadcrumbsControlFactory` in the sessions (Agents) window's `EditorHeaderControl`, not in `SingleEditorTabsControl` used by the normal editor part, so the editor-type dropdown never renders there even with `breadcrumbs.showEditorType` enabled. This carries a real milestone (1.137.0), which per policy blocks any close regardless of the clear fix.

## Change summary

The breadcrumbs editor-type switcher dropdown (enabled via `breadcrumbs.showEditorType`) appears for markdown files in the Agents window but not in the regular editor window.

## Best solution

Add `showEditorTypePicker: true` to the options object passed to `BreadcrumbsControlFactory` in `src/vs/workbench/browser/parts/editor/singleEditorTabsControl.ts` (mirroring `editorHeaderControl.ts:70`) so the dropdown is available in the standard single-tab editor breadcrumbs, not just the sessions window header.
