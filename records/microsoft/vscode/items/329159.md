## Change summary

The new breadcrumbs.showEditorType dropdown appears when a markdown file is opened in the agents window but not when the same file is opened in a normal editor group.

## Best solution

Needs further root-cause tracing in src/vs/workbench/browser/parts/editor/editorTypePicker.ts (getAvailableEditorTypes) and editorResolverService.ts's excludeUnconfiguredUniversalOptionalEditors filtering — both surfaces share the same BreadcrumbsControl code, so the discrepancy likely comes from markdown extension activation timing, editor-id/resource differences, or how the markdown custom editor's glob/priority is evaluated when the extension host hasn't yet registered it for the current editor group.
