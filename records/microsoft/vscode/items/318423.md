# Issue #318423 — "with" button in agents view broken

[https://github.com/microsoft/vscode/issues/318423](https://github.com/microsoft/vscode/issues/318423)

## Summary

Keep open for the requested UX decision: maintainers reproduced the apparently broken “with” control and agreed it needs a clearer treatment. This team-authored issue has an accepted improvement direction, no verified fix commit, and no older issue with the same observable symptom.

## Change summary

Make the Agents Window “with” execution control communicate its non-actionable state when a remote GitHub repository permits only Cloud execution.

## Best solution

Choose and implement a consistent constrained-picker treatment: hide or clearly disable the control when Cloud is the only valid option, or keep it actionable with an explanatory single-option popup. Preserve equivalent pointer and keyboard behavior and cover the selected treatment with a focused picker test.
