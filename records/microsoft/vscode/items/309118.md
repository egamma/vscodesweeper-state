# Issue #309118 — Agents App: Fetched web content empty

[https://github.com/microsoft/vscode/issues/309118](https://github.com/microsoft/vscode/issues/309118)

## Summary

Keep open: maintainers confirmed that fetched content is absent during the active turn but appears afterward. Current code publishes tool results at tool completion, but source inspection does not establish that the live expanded widget displays them correctly; no qualifying fix or duplicate was verified.

## Change summary

Fetched web content should be visible when expanding a completed fetch call while the enclosing agent turn is still active.

## Best solution

Make completed web-fetch results inspectable during an ongoing turn in both VS Code Chat and the Agents app, without requiring session restoration. First isolate whether the remaining discrepancy is in SDK result delivery, live tool-part updates, or rendering.
