# Issue #203539 — Workspace Trust - Workspace trust should not default to true when hitting enter?

[https://github.com/microsoft/vscode/issues/203539](https://github.com/microsoft/vscode/issues/203539)

## Summary

Keep open for the Workspace Trust owner's decision: the startup trust dialog still initially focuses the affirmative action. This is an accepted Backlog discussion about a security-sensitive default, not grounds for a cleanup close.

## Change summary

Make pressing Enter immediately after the Workspace Trust dialog appears leave the folder untrusted rather than grant trust.

## Best solution

Have the Workspace Trust owner settle the startup dialog's keyboard default so granting trust requires deliberate selection. Keep the explicit trust action available and distinguish this decision from whether the startup prompt is shown.
