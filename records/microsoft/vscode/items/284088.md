# Issue #284088 — Automatically clean up (close or delete) worktree after background agent changes are applied

[https://github.com/microsoft/vscode/issues/284088](https://github.com/microsoft/vscode/issues/284088)

## Summary

Worktree cleanup on archive already exists, but applying background-agent changes still retains the session and worktree. Keep this team-authored request open to resolve that remaining lifecycle choice; the related merged PR does not explicitly close this issue, and the newer tracking issue is not an eligible duplicate target.

## Change summary

Clean up background-agent worktrees after changes are applied or the associated session is archived, without disrupting continued sessions or unrelated worktrees.

## Best solution

Retain the existing safe archive-and-restore lifecycle and have the owner decide whether Apply should offer an explicit completion/cleanup action or leave cleanup exclusively to Mark as Done. Reconcile this original background-agent workflow with the newer merged-PR automation rather than assuming they are equivalent.
