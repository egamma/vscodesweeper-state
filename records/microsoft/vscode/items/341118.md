# Issue #341118 — delay between chat request submit and visual feedback

[https://github.com/microsoft/vscode/issues/341118](https://github.com/microsoft/vscode/issues/341118)

## Summary

Thanks for the report. The ~1s delay between Enter and the first UI feedback is plausible. The report has no reproduction details, such as whether there are dirty files, which chat mode is used, or whether the delay occurs in new versus existing chats. A commenter pointed to the pre-submit Save All path as a candidate cause but nothing has been confirmed.

## Change summary

Chat submit shows no visual feedback for about 1 second after pressing Enter, starting in 1.141.0 or the release before it.

## Best solution

Isolate whether the delay comes from the pre-send Save All step or another awaited pre-submit step in chatWidget.ts. Then make the input clear and the user message appear before slow awaits, or run those awaits in a way that doesn't block UI feedback.
