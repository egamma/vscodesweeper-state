# Issue #330368 — JSX multi-line attribute alignment is not preserved after formatting

[https://github.com/microsoft/vscode/issues/330368](https://github.com/microsoft/vscode/issues/330368)

## Summary

Real, reproducible report, but the default TS/JSX formatter delegates entirely to tsserver's own `format` request (extensions/typescript-language-features/src/languageFeatures/formatting.ts), so the indentation logic that discards manual JSX attribute alignment lives in TypeScript's language service, not in VS Code's own formatting code.

## Change summary

Formatting a .tsx file with manually column-aligned multi-line JSX attributes collapses them to standard indent-size indentation instead of preserving alignment with the first attribute.

## Best solution

Route to the typescript area for awareness, but the actual fix (alignment-aware indentation for JSX attributes) would need to land in TypeScript's tsserver formatting engine upstream; VS Code only forwards the formatting request and edits it receives.
