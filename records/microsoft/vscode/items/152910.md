## Summary

The conflict remains source-reproducible on current main: overlapping child patterns can produce duplicate self-ancestors, bypassing the trie’s single-self guard and suppressing otherwise valid nesting. No canonical issue or existing fix owns this specific behavior.

## Change summary

Combining two individually working file-nesting child patterns causes all matching files to remain unnested.

## Best solution

Make file-nesting ancestry resolution tolerate duplicate self-matches from overlapping child patterns while preserving valid nesting, cycle handling, and the behavior of each pattern when used alone.
