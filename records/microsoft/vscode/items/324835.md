# Issue #324835 — Please add native support for Color Identifiers

[https://github.com/microsoft/vscode/issues/324835](https://github.com/microsoft/vscode/issues/324835)

## Summary

Keep this accepted Backlog request open: existing semantic highlighting styles token categories, not individual identifiers. It reached 20 community upvotes, and neither a covering implementation nor a verified duplicate was found.

## Change summary

Provide native, configurable per-identifier coloring, potentially distinguishing separate symbols that share the same spelling.

## Best solution

Preserve this request for an editor-owner decision on native support versus the existing extension. Before implementation, settle whether colors follow identifier spelling or resolved symbol identity; current semantic-token theming does not provide either automatically.
