# Issue #211443 — OSC 8 terminal hyperlinks don't work properly in Remote - WSL

[https://github.com/microsoft/vscode/issues/211443](https://github.com/microsoft/vscode/issues/211443)

## Summary

Keep open: OSC 8 file hyperlinks still bypass remote URI resolution in current main. This issue already owns the reported WSL failure and related SSH reports, with the correct area labels.

## Change summary

Opening an OSC 8 file hyperlink in a remote terminal fails instead of opening the existing remote file in VS Code.

## Best solution

Make OSC 8 file hyperlinks resolve against the originating terminal's remote authority and open the resulting resource in VS Code. Preserve local file behavior, non-file URL handling, and existing scheme approval safeguards.
