# Issue #31141 — [html] provide rename for embedded JavaScript

[https://github.com/microsoft/vscode/issues/31141](https://github.com/microsoft/vscode/issues/31141)

## Summary

Single-file embedded JavaScript rename is implemented, but cross-file rename remains unsupported and an open PR explicitly targets this issue. Keep it open while that implementation candidate is reviewed; the later report that single-file rename still failed should also be checked before declaring the request complete.

## Change summary

Provide semantic Rename Symbol support for JavaScript embedded in HTML, including references across files.

## Best solution

Review https://github.com/microsoft/vscode/pull/171547 against the remaining cross-file rename requirement and the reported single-file failure. Retain the existing single-file capability and close this issue only once the remaining behavior is demonstrably covered.

## Evidence

This establishes partial implementation, not completion of the continuing discussion.
- **Existing capability checked:** extensions/html-language-features/server/src/htmlServer.ts:215 advertises renameProvider, and lines 530–543 dispatch rename requests to the embedded language mode. extensions/html-language-features/server/src/modes/javascriptMode.ts:254–275 implements doRename using TypeScript getRenameInfo and findRenameLocations. The existing HTML Javascript Rename suite in server/src/test/rename.test.ts covers variables, functions, parameters, and classes within one HTML document; these tests were inspected, not executed.
- **Cross-file boundary remains:** extensions/html-language-features/server/src/modes/javascriptMode.ts:getLanguageServiceHost exposes only the current document and jquery through getScriptFileNames; other reads resolve bundled libraries rather than workspace source files. doRename returns edits under only document.uri. The current implementation therefore does not provide workspace-wide embedded JavaScript rename.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/171547 was verified OPEN. Its body explicitly lists 'Fixes #31141 (Cross file renaming)'. This is an existing implementation candidate, not a merged fix, and excludes a competing agent implementation.
