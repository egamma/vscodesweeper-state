## Evidence

- **Verified open canonical:** https://github.com/microsoft/vscode/issues/270925 is open and explicitly requests paragraph spacing for double newlines but ordinary line breaks for single newlines in SCM commit tooltips. Its examples include a subject, blank separator, and hard-wrapped body, covering this report's central requirement.
- **Current source explains both symptoms:** extensions/git/src/historyProvider.ts:301-314 passes the commit message to getHistoryItemHover. In extensions/git/src/hover.ts, appendContent replaces every newline with two newlines. Consequently, both original single and double newlines become Markdown paragraph separators; extra blank lines do not create an additional visible paragraph gap.
- **Graph rendering:** src/vs/workbench/contrib/scm/browser/scmHistory.ts:594-603 renders these sections as Markdown. src/vs/workbench/contrib/scm/browser/media/scm.css:652-654 applies the same paragraph margins throughout, so original paragraph boundaries receive no distinct spacing.
- **Existing implementation candidate:** The canonical issue links the open https://github.com/microsoft/vscode/pull/301633, titled 'Fix SCM commit tooltip newline handling (#270925)'. This is pending work, not evidence that the defect is fixed.
