# Issue #174327 — STOP auto adding space after colon on css properties

[https://github.com/microsoft/vscode/issues/174327](https://github.com/microsoft/vscode/issues/174327)

## Summary

The emmet.preferences css.valueSeparator setting works for Emmet expansions that resolve to a known value (e.g. `fl` → `float:left;`), but property-only expansions are filtered as noise by design. The space the reporter sees likely comes from the built-in CSS language service completions (which don't respect Emmet preferences). The report is from VS Code 1.75 and it's unclear whether the reporter is seeing Emmet completions or CSS language service completions — needs confirmation on latest build.

## Change summary

Setting `emmet.preferences.css.valueSeparator` to `":"` does not remove the space after the colon for property-only CSS completions in HTML style attributes.

## Best solution

Ask the reporter to confirm on the latest VS Code version whether the issue persists, and clarify whether the completions they accept are from Emmet or the CSS language service. If it's the CSS language service, this would need to be filed/tracked as a feature request for the CSS language service to respect a custom separator setting.
