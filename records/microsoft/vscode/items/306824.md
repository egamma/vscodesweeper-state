# Issue #306824 — Automatically starting plan implementation without approval

[https://github.com/microsoft/vscode/issues/306824](https://github.com/microsoft/vscode/issues/306824)

## Summary

Keep open: current source can submit a Start Implementation handoff when a completed Plan conversation is reopened under Autopilot. Separate that navigation-triggered behavior from the intentional, but disputed, automatic handoff when planning finishes.

## Change summary

Returning to a Plan conversation starts implementation without the reporter clicking Start Implementation or approving the plan.

## Best solution

Make reopening a completed Plan conversation a presentation-only operation rather than an implementation trigger. Resolve separately whether Autopilot should require explicit plan approval before the initial implementation handoff, preserving deliberate handoff actions.
