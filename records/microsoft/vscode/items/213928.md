# Issue #213928 — Terminal fails to launch on Task Rerun with "A native exception occurred during launch (args as a string is not supported on unix.)."

[https://github.com/microsoft/vscode/issues/213928](https://github.com/microsoft/vscode/issues/213928)

## Summary

The reported repeated-rerun failure is covered by a landed fix that preserves the remote task's platform information. The attached logs confirm the precise failure mechanism: a Windows cmd.exe launch configuration was incorrectly sent to the Linux remote terminal.

## Change summary

Repeatedly rerunning a shell task with reevaluateOnRerun disabled causes reused remote terminals to receive Windows-style string arguments and fail to launch.

## Best solution

Treat this as completed by commit 4fe05641998b6ca74777f43fde3e68171067ebb2, which preserves remote system information across successive task reruns and keeps Linux shell arguments in array form.
