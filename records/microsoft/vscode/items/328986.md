# Issue #328986 — [Error] unhandlederror-Already in transaction

[https://github.com/microsoft/vscode/issues/328986](https://github.com/microsoft/vscode/issues/328986)

## Summary

Confirmed real regression traced in current source, and an open PR (#329000) already implements and targets the fix — best action is to review/land that PR rather than close or auto-fix here.

## Change summary

Notebook code cell disposal can re-enter ListView.render while an outer render transaction is active, throwing 'Already in transaction' in RowCache.transact.

## Best solution

Land https://github.com/microsoft/vscode/pull/329000, which adds an early `_isDisposed` guard at the top of the `onDidChangeCursorSelection` listener in codeCell.ts so it can't trigger a reveal during cell disposal.
