# Issue #295599 — Cloud agent does not work with GHE account

[https://github.com/microsoft/vscode/issues/295599](https://github.com/microsoft/vscode/issues/295599)

## Summary

Real bug report: the Copilot cloud/coding agent sends auth requests to api.github.com instead of the configured GHE instance, confirmed by a second reporter and acknowledged by a team member. Already assigned to joshspicer. Related but distinct from https://github.com/microsoft/vscode/issues/304075 (CLI Session GHE auth), which targets a different code path. Keeping open — it needs area labeling and the fix is still pending.

## Change summary

The Copilot cloud agent (coding agent) fails with GHE accounts because authentication requests are sent to api.github.com instead of the configured GitHub Enterprise URI.

## Best solution

Fix the cloud/coding agent code path to respect the `github-enterprise.uri` setting and `authProvider: "github-enterprise"` configuration when initiating cloud agent sessions, similar to how local mode already handles GHE auth correctly. Consider whether https://github.com/microsoft/vscode/issues/304075 (CLI Session GHE auth, also assigned) shares the same underlying hardcoded-host root cause and can be addressed together.
