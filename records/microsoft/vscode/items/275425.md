# Issue #275425 — Alerts don't render properly in hovers / suggestion details

[https://github.com/microsoft/vscode/issues/275425](https://github.com/microsoft/vscode/issues/275425)

## Summary

Still present on main: the alert/blockquote CSS styling lives only in the markdown contribution's CSS and is not applied in hovers or suggestion details. The base markdown renderer generates the correct `blockquote[data-severity]` HTML, but the styling rules never reach those contexts.

## Change summary

Markdown alerts (e.g. `> [!NOTE]`) and blockquotes render without proper styling in hovers and suggestion detail widgets.

## Best solution

Move the alert/blockquote CSS from `src/vs/workbench/contrib/markdown/browser/media/markdown.css` into the base markdown rendering layer (or duplicate it into the hover and suggest-detail CSS) so that `blockquote[data-severity]` elements are styled consistently wherever markdown is rendered — hovers, suggestion details, and chat alike.
