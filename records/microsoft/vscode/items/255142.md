# Issue #255142 — Allow to disable project context in ask mode

[https://github.com/microsoft/vscode/issues/255142](https://github.com/microsoft/vscode/issues/255142)

## Summary

Team-authored feature request to allow disabling project context injection in ask mode via chat mode files. No implementation found on main; the IChatModeData interface has no field for controlling project context, and no commits reference this issue. Keeping open.

## Change summary

Allow chat mode files to disable automatic project context injection in ask mode so generic questions don't receive project-scoped answers.

## Best solution

Add a metadata flag (e.g. `context: false` or `noProjectContext: true`) to the chat mode file header schema and wire it through IChatModeData into the implicit-context contribution (src/vs/workbench/contrib/chat/browser/attachments/chatImplicitContext.ts) so that when a mode opts out, project context is not attached to the request. Related: https://github.com/microsoft/vscode/issues/273815 (instruction files variant).
