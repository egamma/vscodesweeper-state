# Issue #181369 — Expose ability to replace an existing Output along with the metadata

[https://github.com/microsoft/vscode/issues/181369](https://github.com/microsoft/vscode/issues/181369)

## Summary

The requested API overload to replace a single existing output (including metadata) has not been implemented on main — the current `replaceOutput` still only replaces all outputs of a cell. This is a valid team-authored API gap tracked as debt.

## Change summary

Expose an overload of `NotebookCellExecution.replaceOutput` that replaces a single existing output (with its metadata) rather than all outputs of a cell.

## Best solution

Add an overload to `replaceOutput` (or a new method) on `NotebookCellExecution` that accepts a target `NotebookCellOutput` to replace, allowing extensions to update both items and metadata of a specific output without managing the full output array themselves.
