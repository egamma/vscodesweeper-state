# Issue #300583 — SubagentStart, UserPromptSubmit, and SubagentStop hooks don't have `transcript_path` in their input

[https://github.com/microsoft/vscode/issues/300583](https://github.com/microsoft/vscode/issues/300583)

## Summary

Confirmed on current main: subagent sessions never call `startSession` on the transcript service, so `getTranscriptPath` returns undefined and the `transcript_path` field is omitted from SubagentStart, SubagentStop, and subagent-context UserPromptSubmit hook inputs. The bug is in `toolCallingLoop.ts` — the `startSession` call is inside the non-subagent branch only.

## Change summary

SubagentStart, UserPromptSubmit (subagent context), and SubagentStop hooks are missing the `transcript_path` field in their input because the transcript service session is never started for subagent sessions.

## Best solution

Call `this._sessionTranscriptService.startSession(sessionId)` for subagent sessions in `runStartHooks()` before the SubagentStart hook executes, mirroring the existing `startSession` call for top-level sessions. The subagent session may also need its own transcript file, or optionally it could receive the parent session's transcript path — that's a design choice the hooks area owner should make.
