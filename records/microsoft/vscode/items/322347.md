# Issue #322347 — Feature Request: double clicking on chat bar should create a new chat

[https://github.com/microsoft/vscode/issues/322347](https://github.com/microsoft/vscode/issues/322347)

## Summary

The request is now clearly scoped to double-clicking empty space in the chat tab bar, and current main does not provide that gesture. This team-authored feature request should remain open and be classified as a feature request rather than left in the info-needed lane.

## Change summary

Double-clicking empty space next to the chat tabs should start a new chat, matching the editor tab-bar interaction.

## Best solution

Give the empty chat-tab-strip area the same double-click and double-tap behavior as the editor tab strip, routing through the existing New Chat in This Session action while preserving double-click-on-tab rename and the existing Ctrl/Cmd+T keyboard path.
