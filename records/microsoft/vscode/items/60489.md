# Issue #60489 — [html] proper support of XHTML

[https://github.com/microsoft/vscode/issues/60489](https://github.com/microsoft/vscode/issues/60489)

## Summary

A real XHTML support gap remains: `.xhtml` files are still routed through the HTML parser, which does not provide XML parsing semantics. The issue is accepted in the Backlog milestone, so the conflicting extension-candidate precedent does not justify a decline close here without a later maintainer decision in this thread.

## Change summary

Provide proper XHTML parsing and language support instead of treating XHTML documents as ordinary HTML.

## Best solution

Decide whether XHTML remains an accepted core web-language mode or should move to an extension. If retained in core, use XML well-formed parsing while preserving HTML element metadata and embedded CSS/JavaScript support, rather than routing `.xhtml` through the ordinary HTML parser.
