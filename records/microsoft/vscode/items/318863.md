# Issue #318863 — getCwd() on macOS invokes lsof on every terminal command, generating many syscalls per invocation

[https://github.com/microsoft/vscode/issues/318863](https://github.com/microsoft/vscode/issues/318863)

## Summary

The expensive macOS lsof implementation remains, but current source already disables Enter-triggered cwd refreshes when shell integration provides cwd detection. Request a current reproduction to identify which caller still invokes it after each command.

## Change summary

Avoid repeated expensive macOS cwd queries when shell integration has already reported the working directory.

## Best solution

Identify the caller responsible for redundant queries and avoid them when a sufficiently current shell-integration cwd is available, while preserving accurate fallback detection and terminal restoration. Returning the process's cached cwd unconditionally would risk stale directories.
