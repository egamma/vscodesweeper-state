# Issue #318863 — getCwd() on macOS invokes lsof on every terminal command, generating many syscalls per invocation

[https://github.com/microsoft/vscode/issues/318863](https://github.com/microsoft/vscode/issues/318863)

## Summary

Keep open: current source still spawns lsof for macOS process-CWD queries, but the per-command invocation despite active shell integration is not confirmed. The terminal frontend already bypasses some process queries when CWD detection is available; the supplied monitoring steps suffice to retest the remaining path without requesting more information.

## Change summary

Avoid expensive macOS lsof invocations on terminal commands when shell integration already provides the current working directory.

## Best solution

Identify which caller still requests process CWD during shell-integrated commands and eliminate redundant queries while preserving accurate fallback detection and terminal restoration. Do not substitute the backend's cached CWD without establishing that it receives fresh shell-integration updates.
