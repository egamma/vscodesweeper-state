[https://github.com/microsoft/vscode/issues/256414](https://github.com/microsoft/vscode/issues/256414)

## Summary

Still valid on current main: the legacy issue reporter auxiliary window opens without passing a `backgroundColor`, so it flashes white before styles load. The issue is already assigned to the issue-reporter maintainer, and the new wizard editor-pane path (behind `issueReporter.wizard.enabled`) avoids the problem by rendering in-editor. Keeping open for the assignee to address.

## Change summary

The Issue Reporter auxiliary window briefly flashes a white background before its content and themed styles load.

## Best solution

Pass the current theme's background color (e.g. `SIDE_BAR_BACKGROUND`) as the `backgroundColor` option when opening the auxiliary window in `openAuxIssueReporter` (src/vs/workbench/contrib/issue/browser/issueFormService.ts, line ~447), or — since the wizard editor-pane path eliminates the aux window entirely — finish rolling out the wizard as the default, which sidesteps the flash.
