# Issue #319825 — Terminal detail popup missing vertical scrollbar, bottom content & hidden buttons cannot be clicked

[https://github.com/microsoft/vscode/issues/319825](https://github.com/microsoft/vscode/issues/319825)

## Summary

Still reproduces on main: the hover widget sets `maxHeight` on `containerDomNode` but not on `contentsDomNode`, so the `DomScrollableElement` wrapping content never detects overflow and the vertical scrollbar never appears. Bottom content and action buttons are clipped.

## Change summary

Hover popups (terminal detail, SCM graph, etc.) clip overflowing content without showing a scrollbar because the inner content node lacks a maxHeight constraint.

## Best solution

Set `maxHeight` on `contentsDomNode` alongside `containerDomNode` in `src/vs/platform/hover/browser/hoverWidget.ts` so the `DomScrollableElement` scrollbar activates on overflow. The commenter's one-line diff is on the right track; also clear `contentsDomNode.style.maxHeight` in the reset path at line 361.
