# Issue #171187 — Reset Menu doesn't show up when all items are visible, even if some are hidden by default

[https://github.com/microsoft/vscode/issues/171187](https://github.com/microsoft/vscode/issues/171187)

## Summary

Still reproduces on main: the Reset Menu only appears when `someAreHidden` is true, but when items hidden-by-default have been explicitly revealed by the user, nothing is currently hidden so the reset option never shows — leaving no way to restore the default toolbar state. An open PR exists but hasn't merged.

## Change summary

The "Reset Menu" context-menu item does not appear when all toolbar items are visible but some differ from their hidden-by-default state.

## Best solution

Land or supersede https://github.com/microsoft/vscode/pull/171361 — the fix should check whether the current visibility state differs from the default state (comparing against `_hiddenByDefaultCache`), not just whether `someAreHidden` is true. The change lives in `src/vs/platform/actions/browser/toolbar.ts` around the `someAreHidden` condition at line 266.
