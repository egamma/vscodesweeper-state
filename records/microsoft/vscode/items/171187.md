# Issue #171187 — Reset Menu doesn't show up when all items are visible, even if some are hidden by default

[https://github.com/microsoft/vscode/issues/171187](https://github.com/microsoft/vscode/issues/171187)

## Summary

The bug remains source-reproducible on current main: Reset Menu is offered only when an action is currently hidden, so it disappears when a user makes every item visible even though that differs from the menu defaults. Keep the issue open while the linked fixing PR remains open.

## Change summary

Show Reset Menu when toolbar visibility differs from its defaults, including when a default-hidden item has been made visible.

## Best solution

Make reset availability reflect whether the menu has persisted visibility customizations rather than whether an item is currently hidden, then review and land or supersede https://github.com/microsoft/vscode/pull/171361 with coverage for default-hidden items made visible.

## Evidence
