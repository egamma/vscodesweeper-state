# Issue #186043 — Support opening links in a new window from within webviews

[https://github.com/microsoft/vscode/issues/186043](https://github.com/microsoft/vscode/issues/186043)

## Summary

Valid, community-backed feature request (39 upvotes, Backlog milestone, `help wanted` + `keep` labels). The sandbox on the webview iframe still does not include `allow-popups` on current main, so the gap remains. A maintainer declined the feature in Oct 2023 citing phishing/consistency concerns, but the reporter's counter-argument (still routing through `vscode.openExternal` confirmation dialog) was never addressed — the discussion is unresolved.

## Change summary

Allow links using `<a target="_blank">` or `window.open` inside webview iframes to trigger VS Code's external-URL confirmation dialog instead of being silently blocked by the sandbox.

## Best solution

The `help wanted` label invites a community contribution. The implementation would likely add `allow-popups` to the webview iframe sandbox in `src/vs/workbench/contrib/webview/browser/webviewElement.ts` and intercept the resulting popup to route it through the existing `vscode.openExternal` confirmation flow, addressing the maintainer's phishing/consistency concerns. Related issue https://github.com/microsoft/vscode/issues/185204 (modals in webviews) overlaps but is distinct enough to keep separate.
