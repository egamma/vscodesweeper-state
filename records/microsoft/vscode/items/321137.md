# Issue #321137 — The setting "task.allowAutomaticTasks" is not supported in non default profiles, while the settings file it is defined in does get synced across profiles

[https://github.com/microsoft/vscode/issues/321137](https://github.com/microsoft/vscode/issues/321137)

## Summary

The `task.allowAutomaticTasks` setting was intentionally scoped to `ConfigurationScope.APPLICATION` (default profile only) in commit 7decfe6a6b3 to prevent workspace-level overrides for security reasons. APPLICATION-scoped settings are shared across all profiles and can only be set in the default profile — this is by design.

## Change summary

The `task.allowAutomaticTasks` setting does not take effect when set in a non-default profile's settings.json.

## Best solution

Keep the current APPLICATION scope — the setting value from the default profile applies globally across all profiles. If the user sets it to `on` in their default profile, it will take effect in all profile windows. The reporter should set it in their default profile's user settings instead.
