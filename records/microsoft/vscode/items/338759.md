# Issue #338759 — Opening file with Cmd+O on macOS sometimes destroys existing workspace

[https://github.com/microsoft/vscode/issues/338759](https://github.com/microsoft/vscode/issues/338759)

## Summary

Keep open: the reporter confirmed that native file selection still resets on 1.139.1. The file-only keybinding prevents accidental folder opening but does not resolve the selection regression.

## Change summary

Selecting a file in the macOS Cmd+O dialog sometimes clears the selection, allowing Open to replace the current window's workspace with the containing folder.

## Best solution

Restore reliable file selection in the native macOS dialog while preserving intentional folder opening. First isolate whether the selection reset originates in Electron/macOS or VS Code's dialog integration; the existing keybinding workaround is mitigation, not a fix.
