# Issue #255143 — NES should not jump when trying to align brackets

[https://github.com/microsoft/vscode/issues/255143](https://github.com/microsoft/vscode/issues/255143)

## Summary

Keep open: current source still allows NES to intercept Tab before a closing bracket when the user is trying to indent. The maintainer explicitly supports fixing this conflict, and no verified older canonical or fixing commit was found.

## Change summary

Tab intended to align a closing bracket jumps to or accepts a next edit suggestion instead.

## Best solution

Preserve ordinary Tab indentation in the reported bracket-alignment scenario while retaining intentional NES jump and acceptance elsewhere. Address the inline-completion Tab eligibility path without changing suggestion generation or the editor's indentation rules.
