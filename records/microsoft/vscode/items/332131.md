# Issue #332131 — Custom title bar overlaps left-side window controls with Electron 43

[https://github.com/microsoft/vscode/issues/332131](https://github.com/microsoft/vscode/issues/332131)

## Summary

Confirmed in source: the custom title bar hardcodes window controls to the right side on Linux/Windows and only reserves left-side space for WCO on web, so Electron 43's now-accurate left-side control reporting overlaps the app icon/menu. An open PR already targets this exact issue, so it should stay open for that PR to land rather than be auto-fixed or closed.

## Change summary

With Electron 43 on Linux desktops configured to show window controls on the left, the custom title bar's app icon/menu overlap the native controls instead of reserving space for them.

## Best solution

Land the fix in the open PR https://github.com/microsoft/vscode/pull/332935 (Electron 43 update, which states "Fixes #332131"); the author's own earlier attempt at https://github.com/microsoft/vscode/pull/310602 was closed unmerged, likely superseded by work folded into #332935. No separate core change is needed once that PR merges.

## Evidence

- **hardcoded side:** src/vs/workbench/browser/parts/titlebar/titlebarPart.ts line 548: `let primaryWindowControlsLocation = isMacintosh ? 'left' : 'right';` — on Linux this is always 'right', so `windowControlsContainer` (line 569) is appended to `rightContent` regardless of the actual OS-configured control position.
- **left reservation is web-only:** src/vs/workbench/browser/parts/titlebar/titlebarPart.ts line 570-574: the left-side spacer container is only created `if (isWeb)`. On native/desktop Linux (isWeb=false), no left spacer exists, so nothing reserves the `env(titlebar-area-x)` space when native controls are actually on the left.
- **CSS only handles right-side WCO on desktop Linux:** src/vs/workbench/browser/parts/titlebar/media/titlebarpart.css line 352-354: `.monaco-workbench.linux:not(.web) .part.titlebar .window-controls-container.wco-enabled { width: calc(100vw - env(titlebar-area-width, 100vw) - env(titlebar-area-x, 0px)); }` — this formula only makes sense for a right-side overlay; there is no equivalent Linux-desktop rule using `env(titlebar-area-x)` directly for a left-side container.
- **author's own fix PR, closed unmerged:** https://github.com/microsoft/vscode/pull/310602 ("fix: consider wco on the left side", by the issue author tarik02) says "Fixes #332131" and describes adding left/right spacers sized from `titlebar-area-*` env vars, but is closed with merged=false.
- **open PR still claims the fix:** https://github.com/microsoft/vscode/pull/332935 ("chore: update to Electron 43") is open and its description lists "Fixes https://github.com/microsoft/vscode/issues/332131" alongside two other issues — this is the active in-flight fix.
