# Issue #332131 — Custom title bar overlaps left-side window controls with Electron 43

[https://github.com/microsoft/vscode/issues/332131](https://github.com/microsoft/vscode/issues/332131)

## Summary

Confirmed root cause and an open fixing PR already exist — Electron 43 now honors the Linux compositor's window-control side, but VS Code's titlebar only reserved WCO space based on a fixed primary side, so a left-side native layout overlaps the app icon/menu; keep open for the linked PR to land rather than closing it now.

## Change summary

With Electron 43 and KDE window controls set to the left, the custom title bar's app icon/menu overlaps the native window controls instead of reserving space for them.

## Best solution

Land (or continue reviewing) https://github.com/microsoft/vscode/pull/310602, which reworks BrowserTitlebarPart/titlebarPart WCO handling to add a `wco-enabled` window-controls-container on whichever side the OS actually places the controls (not just the configured primary side) and updates the CSS titlebar-area-x/width rules accordingly for desktop Linux.
