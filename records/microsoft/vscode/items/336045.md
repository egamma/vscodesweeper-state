# Issue #336045 — Second click after selecting from command center interpreted as double click on underlying UI

## Summary

Fresh, reporter-confirmed bug on both 1.137.0 stable and 1.138.0 Insiders: a second click used to activate a command-center/palette entry appears to bleed through as a double-click event to the underlying UI (e.g. creating an untitled file when the editor area is empty behind it).
