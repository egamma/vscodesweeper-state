# Issue #326359 — [Error] [GitHub.copilot-chat] unhandlederror-An unexpected bug occurred.

[https://github.com/microsoft/vscode/issues/326359](https://github.com/microsoft/vscode/issues/326359)

## Summary

Ongoing, high-volume regression in Copilot Chat's Next Edit Suggestion (NES) provider, confirmed by continuous automated regression scans across 0.54.0 → 0.60.0, and traced in current source to a real assertion failure — not yet fixed on main.

## Change summary

The Next Edit Suggestion (NES) streaming-edit rebase path throws an unhandled 'An unexpected bug occurred.' error affecting thousands of users per release.

## Best solution

In extensions/copilot/src/extension/inlineEdits/node/nextEditProvider.ts, `_rebaseAndCacheStreamedEdit` (around line 788) calls `statePerDoc.get(streamedEdit.targetDocument)`, whose lookup function (`createDocStateLookupMap`, line ~132-149) throws `BugIndicatingError()` when the target document isn't found in either `projectedDocuments` or `xtabEditHistory`. The NES/inline-edits owners should determine why a streamed edit can reference an untracked document (likely a race between document lifecycle and the edit stream) and either resolve it gracefully or narrow the invariant; the closely related open issue https://github.com/microsoft/vscode/issues/324541 traces the same throw site and should be reconciled with this one once a fix is scoped.
