# Issue #331542 — `code --status` reports impossible process memory on macOS

## Summary

Confirmed real bug — `DiagnosticsService.formatProcessItem` double-converts `ProcessItem.mem` on non-Windows platforms — but an open PR (#331543) already targets this exact issue with `Fixes #331542`, so this should stay open pending review/merge rather than be auto-fixed or closed.
