# Issue #303739 — Copilot crashes on CNB.cool docker workspaces

[https://github.com/microsoft/vscode/issues/303739](https://github.com/microsoft/vscode/issues/303739)

## Summary

The missing Linux `pty.node` path was fixed after this report by restoring the runtime node-pty shim for separately installed Copilot Chat extensions. Current main copies VS Code's matching native binary before importing the Copilot SDK, so this can close as completed.

## Change summary

Copilot Chat fails to load in a CNB.cool Linux workspace because its SDK cannot find the Linux node-pty native module.

## Best solution

Keep the runtime node-pty shim introduced by commit 17c5c32122f71707abd6ea0f8f3265fd5f161680, which supplies the SDK's expected platform-specific native binary before SDK import.
