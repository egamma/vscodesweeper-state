# Issue #244449 — Pressing up on quick pick with headers will select but not reveal the final item

[https://github.com/microsoft/vscode/issues/244449](https://github.com/microsoft/vscode/issues/244449)

## Summary

The current source still permits Up-arrow navigation to focus the final item without revealing it when that item is the first child of a section header. Keep this open; the reveal defect is distinct from the older checkbox-navigation report.

## Change summary

Ensure Up-arrow navigation in a sectioned quick pick reveals the focused final item, not only its header.

## Best solution

Make backward navigation in QuickInputList keep the focused item visible while preserving section-header context and existing wraparound behavior. Cover the final section containing a single item with a viewport regression test.
