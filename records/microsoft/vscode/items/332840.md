# Issue #332840 — Builtin GitHub MCP server: no way to select tools

[https://github.com/microsoft/vscode/issues/332840](https://github.com/microsoft/vscode/issues/332840)

## Summary

Legitimate, fresh gap: the builtin GitHub MCP server is registered via the extension API (lm.registerMcpServerDefinitionProvider) with its tool list computed server-side (X-MCP-Tools header in githubMcpServer.ts), so it doesn't go through the same tool-selection UI as user-configured MCP servers — a collaborator comment confirms tool management exists for 'other' MCP servers today, implying this one is the exception.

## Change summary

Users can't pick which tools from the builtin GitHub MCP server are enabled, unlike user-configured MCP servers.

## Best solution

Extend the MCP tool-management UI (chatToolPicker.ts / aiCustomization mcpListWidget.ts) to cover collections contributed via extension-registered MCP definition providers, or expose a client-side override for the GitHub MCP server's X-MCP-Tools header (src/vs/platform/agentHost/node/shared/githubMcpServer.ts, extensions/copilot/src/extension/githubMcp/vscode-node/githubMcp.contribution.ts) so its tool set is user-selectable like other servers.
