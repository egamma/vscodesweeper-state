# Issue #332840 — Builtin GitHub MCP server: no way to select tools

[https://github.com/microsoft/vscode/issues/332840](https://github.com/microsoft/vscode/issues/332840)

## Summary

Real gap, thinly reported: the builtin GitHub MCP server only exposes a coarse `toolsets` setting and, in the Copilot CLI/agent-session config path, is wired up with a hardcoded `tools: ['*']`, so there's no per-tool checkbox selection like user-configured MCP servers get. The report itself is a bare forward from Slack with no screenshots or version info attached, so routing to the MCP/chat area for a maintainer to confirm the exact surface (core chat tool picker vs. agent sessions) makes more sense than closing.

## Change summary

The builtin GitHub MCP server lacks the per-tool selection UI/config that user-configured MCP servers have.

## Best solution

Give the builtin GitHub MCP server the same per-tool enablement path as other MCP servers: either surface it properly in the standard tool picker (src/vs/workbench/contrib/chat/browser/actions/chatToolPicker.ts) if it's currently excluded there, and/or stop hardcoding `tools: ['*']` for it in extensions/copilot/src/extension/chatSessions/copilotcli/node/mcpHandler.ts (addBuiltInGitHubServer) so its tool list can be filtered like any other configured server.
