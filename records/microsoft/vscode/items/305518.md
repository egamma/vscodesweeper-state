## Evidence

- **Discussion and theme identity:** The comments on https://github.com/microsoft/vscode/issues/305518 attribute the change to the new default themes and link https://github.com/microsoft/vscode/issues/305624. That issue is open and specifically describes Python contrast in the new VS Code Dark theme, with switching to Dark Modern as a workaround; it does not cover Delphi or generated-agent diagnostics.
- **Current theme surface:** extensions/theme-defaults/package.json registers Dark 2026, Dark Modern, and Dark+ as separate built-in themes. themes/dark_modern.json includes dark_plus.json; themes/2026-dark.json includes dark_modern.json but supplies additional token colors and enables semantic highlighting. The report's theme naming therefore does not conclusively identify which palette caused the observed change.
- **Generated references explained:** extensions/copilot/src/extension/agents/vscode-node/agentTypes.ts still lists all three reported GitHub identifiers in DEFAULT_READ_TOOLS. AskAgentProvider builds its generated configuration from that list, and CachedAgentFileWriter writes it into globalStorage with an in-memory cache, explaining why manual deletions do not survive a new session. These are tool identifiers, not keybinding context keys.
- **Confirmed historical diagnostics and later resolution:** https://github.com/microsoft/vscode/issues/302880#issuecomment-4129942576 confirms the same three warnings and regeneration on Windows 1.113. A maintainer subsequently recommends Copilot Chat 0.41.2 and a restart at https://github.com/microsoft/vscode/issues/302880#issuecomment-4141396018. The closely matching https://github.com/microsoft/vscode/issues/308364 is closed, with a maintainer reporting resolution for 1.114 at https://github.com/microsoft/vscode/issues/308364#issuecomment-4214452991.
- **Current diagnostics differ:** src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptValidator.ts now emits MarkerSeverity.Hint for unknown tool and extension-tool references. Historical warning reports therefore do not establish that the same Problems-panel regression persists on current main.

Neither it nor the Python-only https://github.com/microsoft/vscode/issues/305624 is a verified full-scope duplicate target.
