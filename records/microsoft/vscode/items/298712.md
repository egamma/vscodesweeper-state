# Issue #298712 — Cannot edit messages in Claude Agent or Copilot CLI chat sessions

[https://github.com/microsoft/vscode/issues/298712](https://github.com/microsoft/vscode/issues/298712)

## Summary

Implemented on current main: editing an earlier message now truncates the Agent Host conversation before resubmitting, with provider-specific truncation implemented for both Copilot CLI and Claude Agent.

## Change summary

Allow users to edit and resubmit earlier messages in Claude Agent and Copilot CLI chat sessions.

## Best solution

Keep the shipped Agent Host checkpoint/edit flow: the chat widget removes the stale request tail, the Agent Host dispatches chat truncation, and each provider truncates its native conversation before processing the edited message.
