# Issue #9209 — Offer code mark styles and gutter marks

[https://github.com/microsoft/vscode/issues/9209](https://github.com/microsoft/vscode/issues/9209)

## Summary

Long-standing, heavily upvoted (123) team-authored request already sits in the Backlog milestone, which is exactly the right home for it; part of the original ask (customizable squiggly/border colors per severity) shipped years ago, but the core ask — built-in alternate mark styles (outline/solid/fill) and native gutter marks for diagnostics — is still not in core, so this stays open.

## Change summary

Offer alternate diagnostic mark rendering styles (outline, solid underline, fill, etc.) and built-in gutter icons for errors/warnings, instead of only squiggly underlines.

## Best solution

Keep tracking as a Backlog feature request; the color-customization slice (editorError.foreground/border, editorWarning.foreground/border, editorInfo.foreground/border) is already shipped, so the remaining scope is a built-in setting for alternate squiggly styles and/or gutter glyphs for diagnostic severities — note that the `vscode.window.createTextEditorDecorationType` gutterIconPath/gutterIconSize API already lets any extension (e.g. Error Lens, error-gutters) build this today, so a maintainer could also consider whether this should stay an extension-space capability rather than a core default.
