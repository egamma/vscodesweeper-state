# Issue #9209 — Offer code mark styles and gutter marks

[https://github.com/microsoft/vscode/issues/9209](https://github.com/microsoft/vscode/issues/9209)

## Summary

Color customization is available, but built-in diagnostic gutter marks and selectable outline/fill styles remain missing. The older gutter issue covers only part of this team-authored, strongly supported request, so it should remain open.

## Change summary

Offer alternative visual styles for diagnostic ranges and built-in gutter indicators for errors and warnings.

## Best solution

Define a consistent, opt-in diagnostic presentation covering range styles and gutter indicators while preserving the current default rendering. Coordinate the gutter portion with https://github.com/microsoft/vscode/issues/3915 without treating that narrower request as a duplicate target for the whole issue.
