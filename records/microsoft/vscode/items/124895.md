# Issue #124895 — Can't drag scroll bars anymore

[https://github.com/microsoft/vscode/issues/124895](https://github.com/microsoft/vscode/issues/124895)

## Summary

Keep open as an upstream Chromium/Electron input-handling issue. Reports continued after the purported upstream fix reached Insiders, so affected users still need to confirm current behavior and the remaining upstream cause.

## Change summary

Scrollbar clicks and drags intermittently pass through to the editor instead of scrolling on certain Linux window systems.

## Best solution

Confirm the failure on the current Electron runtime across the affected Linux environments, then track any remaining pointer-event defect upstream in Chromium/Electron rather than changing VS Code's scrollbar implementation.
