## Summary

Fresh, same-day feedback from testing the new connected-tab geometry work (tabActionLocation=left): the CSS does set asymmetric spacing for this layout (row-reverse with padding-left:0/padding-right:10px), which is consistent with the reported imbalance, but the exact 'right amount' of padding is a visual-design call a maintainer should make, not something to close or auto-fix blind.
