# Issue #295334 — VS Code Insiders Renderer Crash (EXC_BREAKPOINT) When Processing Large Image Attachment in Copilot Chat Agent Mode

[https://github.com/microsoft/vscode/issues/295334](https://github.com/microsoft/vscode/issues/295334)

## Summary

Keep open: the reporter captured a renderer crash after large image-backed chat history, and current main still persists image bytes inline in session JSONL. The issue is team-authored and no commit or older same-symptom canonical meets the factual-close bar.

## Change summary

Prevent large image attachments and accumulated chat-session state from crashing the renderer or making the session unrecoverable.

## Best solution

Move persisted image and binary content out of the JSONL/model heap into session-scoped resources that can be loaded lazily, while preserving attachment restoration and providing graceful recovery for oversized or legacy sessions. Coordinate that broader persistence work with https://github.com/microsoft/vscode/issues/314556 while retaining this older report as crash evidence.
