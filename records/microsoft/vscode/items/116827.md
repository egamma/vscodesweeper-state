# Issue #116827 — [FR] Settings to make find-and-replace work like Notepad++

[https://github.com/microsoft/vscode/issues/116827](https://github.com/microsoft/vscode/issues/116827)

## Summary

Keep this accepted Backlog request open: current settings cover opening Find in Selection and selection seeding, but the active search scope still does not follow a changed editor selection. This is the established canonical issue for that remaining workflow.

## Change summary

Provide settings that preserve and continuously reuse the user's exact selection as the Find and Replace scope.

## Best solution

Extend the editor find configuration and controller so an enabled mode updates `searchScope` when the user changes selection, without replacing that selection with the active match. Preserve the existing behavior as the default and consolidate overlapping scope-update reports here.
