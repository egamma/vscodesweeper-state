# Issue #211711 — Keybindings service spends a long time in `updateKeybindingsJsonSchema`

[https://github.com/microsoft/vscode/issues/211711](https://github.com/microsoft/vscode/issues/211711)

## Summary

Keep open: schema construction has moved into KeybindingsJsonSchema, but current main still rebuilds it synchronously twice during eager keybinding-service construction. The attached startup trace and named hot path are sufficient to retest; the current performance cost remains unmeasured.

## Change summary

Reduce startup time spent rebuilding the keybindings JSON schema before it is needed.

## Best solution

Establish which schema work must complete during startup, then eliminate unnecessary startup rebuilding while preserving keybindings.json validation, completion, and contribution updates.
