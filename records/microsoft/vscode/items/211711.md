# Issue #211711 — Keybindings service spends a long time in `updateKeybindingsJsonSchema`

[https://github.com/microsoft/vscode/issues/211711](https://github.com/microsoft/vscode/issues/211711)

## Summary

Still reproduces on main: `updateKeybindingsJsonSchema` is called eagerly in the WorkbenchKeybindingService constructor (line 206) and again after extensions register (line 240), rebuilding the entire commands schema each time. The TODO on line 946 acknowledges this could be incremental. No optimization has landed since the issue was filed.

## Change summary

The keybinding service eagerly rebuilds the full JSON schema for keybindings.json during startup, consuming significant time that could be deferred.

## Best solution

Defer `updateKeybindingsJsonSchema` out of the startup critical path — lazily build the schema only when the keybindings editor is first opened, or make the rebuild incremental as the existing TODO suggests. The schema is only needed for keybindings.json validation/completion, not for keybinding resolution itself.
