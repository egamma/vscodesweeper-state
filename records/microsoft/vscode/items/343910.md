# Issue #343910 — Why can't I nest a Claude/Codex session under a Copilot session?

[https://github.com/microsoft/vscode/issues/343910](https://github.com/microsoft/vscode/issues/343910)

## Summary

Keep open as a feature request: current nesting explicitly requires the same harness, so the requested cross-harness organization remains unsupported. This team-authored request needs a product decision about whether nesting represents visual organization or shared session ownership.

## Change summary

Allow Claude, Codex, and Copilot sessions to be nested together in the Agents Window.

## Best solution

Provide a harness-neutral way to organize related sessions beneath another session while preserving each conversation's harness and history. First settle whether this is presentation-only hierarchy or actual mixed-harness session membership, since existing nesting performs an ownership transfer.
