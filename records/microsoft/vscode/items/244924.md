# Issue #244924 — Some cursor movement events are ignored in webview

[https://github.com/microsoft/vscode/issues/244924](https://github.com/microsoft/vscode/issues/244924)

## Summary

Still reproduces on main: the webview key event filtering uses `e.ctrlKey || e.metaKey` for find/print detection, incorrectly intercepting macOS ctrl+key cursor movement shortcuts. An open PR (#310057) exists to fix this but has not merged.

## Change summary

On macOS, ctrl+f and ctrl+p in webview text inputs are intercepted as find/print shortcuts instead of being handled as cursor movement.

## Best solution

Land https://github.com/microsoft/vscode/pull/310057 (or an equivalent fix) that distinguishes ctrl from meta on macOS in `isPrint` and `isFindEvent` within `src/vs/workbench/contrib/webview/browser/pre/index.html`.
