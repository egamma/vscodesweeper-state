# Issue #291401 — Implementation handoff uses summary instead of actual plan file

[https://github.com/microsoft/vscode/issues/291401](https://github.com/microsoft/vscode/issues/291401)

## Summary

Keep open: newer agent-host handoffs import conversation turns, but that does not establish that the persistent implementation plan reaches the background session. The supplied steps suffice to retest, and this issue already owns a maintainer-consolidated report of plan loss.

## Change summary

Local Plan-to-background implementation handoff substitutes a lossy conversation summary for the completed implementation plan file.

## Best solution

Ensure the background implementation session receives and can read the authoritative completed plan, preserving its implementation details rather than substituting a conversation summary. First verify the current agent-host handoff against the legacy delegation path and the cross-provider plan-transfer direction raised in the thread.
