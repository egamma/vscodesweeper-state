# Issue #250399 — Cmd+Backspace should also work if focus is on elements of the chat output.

[https://github.com/microsoft/vscode/issues/250399](https://github.com/microsoft/vscode/issues/250399)

## Summary

Keep open: current main still binds Undo Requests to Delete on Windows and Cmd+Backspace only on macOS, matching the Windows reporter's observation that only Delete works. This is team-authored and no issue-referencing fix exists; the later macOS confirmation does not verify the reported Windows path.

## Change summary

Make the chat request undo shortcut work from focusable elements within chat output on Windows, rather than accepting only Delete.

## Best solution

Confirm the intended Windows equivalent of the macOS Cmd+Backspace binding, then ensure that shortcut invokes Undo Requests while focus is on non-text-input elements within the chat transcript, without removing the existing Delete binding.
