# Issue #334437 — Copilot Chat cannot resolve installed custom skills

[https://github.com/microsoft/vscode/issues/334437](https://github.com/microsoft/vscode/issues/334437)

## Summary

Traced on current main: skills beyond a ~15000-character serialization budget are listed only by name in the system-prompt index, without a `<file>` URI, so the skill tool's resolver can never find them — matching the reporter's observed ~15-skill cutoff exactly.

## Change summary

The `skill` tool fails with "not found" for any custom skill beyond roughly the first 15 registered, once many skills are configured.

## Best solution

In automaticInstructionsCollector.ts, either raise/adapt the `SKILL_DESCRIPTION_CHAR_BUDGET` truncation so skill `<file>` entries (not just names) survive for all skills, or make `resolveSkillUri`/skillTool.ts fall back to the full skills list from `IPromptsService.getSkills()` instead of only the truncated serialized index text, so truncation only affects prompt verbosity, not resolvability.
