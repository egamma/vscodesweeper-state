# Issue #334437 — Copilot Chat cannot resolve installed custom skills

[https://github.com/microsoft/vscode/issues/334437](https://github.com/microsoft/vscode/issues/334437)

## Summary

This is the same skill-resolution bug already tracked (and assigned) at https://github.com/microsoft/vscode/issues/314772 — the skill tool's resolver reads a narrower index than the one used to build the system prompt's `<skills>` list, so skills outside the default `~/.copilot/skills/` location get listed but fail with 'not found' when invoked.

## Change summary

The `skill` tool fails with "Skill ... not found" for skills installed via a configured custom skills directory, even though the skill exists on disk.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/314772 (already assigned) — the fix is to make `SkillTool.resolveSkillUri` in extensions/copilot/src/extension/tools/node/skillTool.ts resolve against the same full skill catalog (`IPromptsService.getSkills`) used by extensions/copilot/src/platform/promptFiles/node/automaticInstructionsCollector.ts to build the `<skills>` prompt section, instead of a separately-built `customizationsIndex` chat variable.
