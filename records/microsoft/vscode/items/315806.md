# Issue #315806 — Useful session info is hidden while the session is in progress

[https://github.com/microsoft/vscode/issues/315806](https://github.com/microsoft/vscode/issues/315806)

## Summary

Keep open: current source deliberately hides worktree badges and change summaries during session progress, so the requested persistent context remains missing. No verified older canonical owns this same disappearance.

## Change summary

Keep a session's worktree identity and available change summary visible while the session is running.

## Best solution

Let session rows retain glanceable worktree identity and available change counts alongside progress information. The agent-session renderer owns this presentation; a maintainer should settle the information hierarchy before implementation.
