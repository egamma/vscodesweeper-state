# Issue #346414 — Agent host: send_message to a session evicted as idle fails with "Unknown chat owner" instead of restoring it

[https://github.com/microsoft/vscode/issues/346414](https://github.com/microsoft/vscode/issues/346414)

## Summary

The reported failure is supported by current source: send_message starts a turn without restoring the evicted target, then requires ownership that eviction removed. Keep this open as a host orchestration bug.

## Change summary

Restore an idle-evicted send_message target before starting its turn, and surface restoration failures without an internal ownership error.

## Best solution

The session server-tool execution path should restore the recorded target session and addressed chat before admitting a message, preserving conversation identity and existing queue semantics. Failed restoration should produce an actionable tool error without claiming that a turn started.
