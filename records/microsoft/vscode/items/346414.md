# Issue #346414 — Agent host: send_message to a session evicted as idle fails with "Unknown chat owner" instead of restoring it

[https://github.com/microsoft/vscode/issues/346414](https://github.com/microsoft/vscode/issues/346414)

## Summary

The idle-eviction failure remains source-reproducible on current main: send_message starts a turn against an unregistered chat without restoring its owning session. Keep this open; automatic restoration, not merely a clearer error, is the required outcome.

## Change summary

Restore an idle-evicted target session before delivering an inter-session message, and report restoration failures explicitly.

## Best solution

The agent-host server-tool delivery path should reactivate a persisted target and deliver the message without requiring anyone to reopen its chat. If restoration fails, return an actionable failure without claiming delivery or exposing an internal ownership error.
