# Issue #338734 — Sessions: Hide other controls while editing a session name

[https://github.com/microsoft/vscode/issues/338734](https://github.com/microsoft/vscode/issues/338734)

## Summary

Confirmed in the SessionHeaderBar source: the title-actions toolbar (which hosts Mark as Done and other session actions) is a sibling of the title element and is never hidden when inline rename starts, so it stays visible and clickable next to the rename input — matching the report exactly.

## Change summary

While editing a session's name in the session header bar, the adjacent toolbar (including Mark as Done) stays visible and can be misclicked for the save action.

## Best solution

Hide `.chat-composite-bar-title-actions` while `.chat-composite-bar-session-title` has `.editing`, mirroring the existing pattern already used for the sessions list rows (`.renaming` hides `.session-title-toolbar` in sessionsList.css) and for chat tabs (`.chat-composite-bar-tab.editing` hides `.chat-composite-bar-tab-actions`).
