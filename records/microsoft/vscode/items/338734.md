# Issue #338734 — Sessions: Hide other controls while editing a session name

[https://github.com/microsoft/vscode/issues/338734](https://github.com/microsoft/vscode/issues/338734)

## Summary

Keep open as session-header polish: current source leaves the unrelated toolbar visible during inline renaming. The requested separation of rename controls from session actions remains missing, and no matching canonical or open implementation PR was found.

## Change summary

Hide unrelated session actions while editing the session name so Mark as Done cannot be mistaken for rename confirmation.

## Best solution

Make the header's rename state expose only rename-related interactions, with unrelated actions unavailable visually and through keyboard navigation until editing ends. Preserve the existing rename commit and cancellation semantics and restore normal session controls afterward.
