## Summary

The report contains a concrete reproduction showing that CSS range formatting can collapse a selected declaration and surrounding whitespace onto one line. The expected invariant is clear from the discussion, but the exact current source path and a deterministic validation have not yet been established, so the issue should remain open for diagnosis.

## Change summary

Make CSS range formatting operate on an appropriate syntax-tree range so formatting an arbitrary selection does not produce a result that full-document formatting would immediately undo.

## Best solution

Define and enforce a stable range-formatting contract in the built-in CSS language service: expand or interpret partial selections using syntax boundaries so the result remains valid and consistent with document formatting.
