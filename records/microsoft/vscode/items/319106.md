# Issue #319106 — Dates on chat sessions

[https://github.com/microsoft/vscode/issues/319106](https://github.com/microsoft/vscode/issues/319106)

## Summary

The existing Sort by Updated option covers the central request: session dates, ordering, and date groups can reflect the latest conversation activity instead of creation. The Chronicle concern is also addressed separately by its activity timestamps, rather than the displayed creation date.

## Change summary

Show a chat session's latest conversation date instead of its creation date when the conversation is continued.

## Best solution

Use Filter Agent Sessions → Sort by Updated, retaining Sort by Created for users who prefer creation-based history. Chronicle should continue using its independently recorded updated_at timestamps for recent-activity queries.
