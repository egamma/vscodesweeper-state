# Issue #319106 — Dates on chat sessions

[https://github.com/microsoft/vscode/issues/319106](https://github.com/microsoft/vscode/issues/319106)

## Summary

The chat sessions view already supports sorting and grouping by last-updated date — users can toggle from the default 'Created' sort to 'Updated' sort, which shows and groups sessions by when they were last used. The requested behavior is available today.

## Change summary

Request to show the last-used date on chat sessions instead of the creation date.

## Best solution

The existing 'Sort by Updated' option in the agent sessions view (via `AgentSessionsSorting.Updated`) already delivers this — when enabled, sessions display and group by `timing.lastRequestEnded` instead of `timing.created`. Close as as-designed and point the reporter to the sort toggle.
