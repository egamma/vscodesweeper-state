# Issue #324498 — Add option for manual handling of collapsibleState similar to manageCheckboxStateManually

[https://github.com/microsoft/vscode/issues/324498](https://github.com/microsoft/vscode/issues/324498)

## Summary

A real extension API gap remains, and the request is still within the Backlog Candidates community-review period. The older collapse API proposal overlaps but does not fully cover manual expansion-state ownership and event semantics.

## Change summary

Allow extensions to manage custom tree-item expansion state manually without revealing or scrolling to an item.

## Best solution

The tree-view API owners should evaluate a unified expansion-state API that supports targeted collapse or controlled state changes without forced reveal/scrolling, while preserving user expansion and collapse notifications.
