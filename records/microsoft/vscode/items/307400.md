# Issue #307400 — "Terminal process failed to launch" error message is inaccurate

[https://github.com/microsoft/vscode/issues/307400](https://github.com/microsoft/vscode/issues/307400)

## Summary

The issue is still reproducible on main — the 500ms `ErrorLaunchThresholdDuration` threshold causes a misleading 'failed to launch' message for processes that exit quickly after a successful launch. An open PR (#309177) targets this but has not merged.

## Change summary

Terminal shows misleading 'failed to launch' error for processes that launched successfully but exited within 500ms.

## Best solution

The fix should transition from `Launching` to `Running` when `onProcessReady` fires (i.e. when a PID is received), not after an arbitrary timeout. The open PR https://github.com/microsoft/vscode/pull/309177 addresses this — review and land it, or implement an equivalent approach in `terminalProcessManager.ts`.
