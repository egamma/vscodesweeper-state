# Issue #233078 — Emmet wrap with abbreviation reindents content when used with `pre`

[https://github.com/microsoft/vscode/issues/233078](https://github.com/microsoft/vscode/issues/233078)

## Summary

Still reproduces on main: the Emmet wrap-with-abbreviation logic unconditionally reindents wrapped content regardless of the target element, with no special handling for preformatted elements like `pre`.

## Change summary

Emmet 'Wrap with Abbreviation' using `pre` reindents content that should preserve its original indentation.

## Best solution

Add logic in `extensions/emmet/src/abbreviationActions.ts` to detect when the wrapping abbreviation resolves to a preformatted element (`pre`, `code`, `textarea`, etc.) and skip reindentation of the wrapped content in that case, or pass an Emmet option that suppresses indentation for preformatted output.
