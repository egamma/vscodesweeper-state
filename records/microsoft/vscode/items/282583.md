# Issue #282583 — PRs are auto attached as context

[https://github.com/microsoft/vscode/issues/282583](https://github.com/microsoft/vscode/issues/282583)

## Summary

Team-authored bug report about PRs being auto-attached as context in agent sessions even when the user did not explicitly add them. The issue is actively under discussion among team members (alexr00 asked justschen for input), so it should remain open pending that design decision.

## Change summary

Opening a PR webview causes the PR to be silently attached as context to a new agent session message, even when the user only saw it as a suggestion and did not add it.

## Best solution

The team needs to resolve the design question raised by alexr00: whether suggested-but-not-added context items (like PRs) should be implicitly included when sending a message. The implicit context logic in `src/vs/workbench/contrib/chat/browser/attachments/chatImplicitContext.ts` and the webview/context-provider integration are the likely areas to adjust once the design decision is made.
