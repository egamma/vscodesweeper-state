# Issue #292946 — [bug]: Flag emojis do not render, regardless of font

[https://github.com/microsoft/vscode/issues/292946](https://github.com/microsoft/vscode/issues/292946)

## Summary

Flag emoji rendering in the integrated terminal is an upstream xterm.js limitation — its canvas/WebGL renderer doesn't support multi-codepoint regional indicator sequences the way native text renderers do. No fix has landed on VS Code main.

## Change summary

Flag emojis (regional indicator sequences) render as individual codepoints in the integrated terminal instead of as combined flag glyphs.

## Best solution

This needs a fix in xterm.js's text rendering layer to handle regional indicator sequences. Track upstream at https://github.com/xtermjs/xterm.js — VS Code would pick it up via a dependency bump once supported there.
