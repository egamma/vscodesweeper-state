# Issue #342929 — Agent Host: file links in Copilot (Agent Host) chat open as vscode-agent-host:// in Remote-SSH windows and cannot be revealed in Explorer (Local harness works)

[https://github.com/microsoft/vscode/issues/342929](https://github.com/microsoft/vscode/issues/342929)

## Summary

Keep open: current source still routes Remote-SSH Agent Host file links through a separate vscode-agent-host resource identity, and relative links receive no working-directory base. The report provides sufficient reproduction details; this belongs to core Agent Host integration, not an external extension tracker.

## Change summary

Make Agent Host chat file links resolve to the matching Remote-SSH workspace resource so Explorer reveal and editor identity work consistently.

## Best solution

Remote-SSH chat links to workspace files should open the same resources as Explorer, including workspace-relative links. Preserve proxy routing for genuinely separate Agent Hosts and opaque host-owned content.
