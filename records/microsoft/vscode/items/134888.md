## Summary

Valid, team-authored feature request with 15 upvotes and steady community interest. No implementation exists on current main — bracket pair guides have no hover or mouse interaction support. Keeping open in Backlog.

## Change summary

Add hover/mouse interaction to bracket pair and indentation guides so users can see the opening/closing bracket line and navigate to it.

## Best solution

Implement hover support in the indent guides view part (`src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts`) so that hovering a guide (optionally with Ctrl) shows a tooltip with the opening/closing bracket context line, with click-to-navigate. Related issue https://github.com/microsoft/vscode/issues/55075 (show opening tag when closing tag selected) overlaps but is narrower — this issue is the better canonical home for the general bracket-guide interaction feature.
