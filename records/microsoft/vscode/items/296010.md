# Issue #296010 — Git - detecting filepath+line link in console diff not working for all formats

[https://github.com/microsoft/vscode/issues/296010](https://github.com/microsoft/vscode/issues/296010)

## Summary

The terminal’s existing Git diff link detector still rejects valid hunk headers with an omitted destination count. Its anchored, single-match parsing also explains the reporter’s compressed-output limitation; this remains actionable terminal link work.

## Change summary

Recognize Git diff hunk links when the destination count is omitted and when an external formatter places multiple hunk headers on one line.

## Best solution

Make terminal Git diff navigation handle valid single-line ranges and the reported space-separated hunk headers, resolving each link to its destination file and position. Treat the scrolling observation separately unless it can be reproduced with the file header still retained in the terminal buffer.
