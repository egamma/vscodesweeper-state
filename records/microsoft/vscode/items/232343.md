# Issue #232343 — Comments broken in markdown codeblock

[https://github.com/microsoft/vscode/issues/232343](https://github.com/microsoft/vscode/issues/232343)

## Summary

Keep open: the current comment command still selects comment syntax at column 1, which does not cover embedded code whose leading indentation belongs to Markdown. No verified canonical owns this specific behavior; the existing editor-comments classification is appropriate.

## Change summary

Make Toggle Line Comment use TypeScript comment syntax on indented code inside Markdown fences, including fences nested in lists.

## Best solution

Make embedded-language comment selection consistent with the code being commented, while preserving Markdown indentation and existing mixed-language selection behavior. This belongs in the editor comment command rather than requiring a separate Markdown extension.
