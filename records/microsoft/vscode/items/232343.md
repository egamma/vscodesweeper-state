# Issue #232343 — Comments broken in markdown codeblock

[https://github.com/microsoft/vscode/issues/232343](https://github.com/microsoft/vscode/issues/232343)

## Summary

Still reproduces on main: the line comment command determines the embedded language at column 1, which falls in markdown territory when the fenced code block is indented (e.g., inside a list item). The fix needs the language check to use the first non-whitespace column instead.

## Change summary

Toggle Line Comment (Ctrl+/) inside an indented fenced code block in markdown inserts HTML comments instead of the embedded language's line comment.

## Best solution

In `lineCommentCommand.ts`, change the three `getLanguageIdAtPosition(lineNumber, 1)` calls to use the column of the first non-whitespace character on the line instead of column 1, so that the embedded language (e.g., TypeScript) is correctly detected for indented code blocks. Prior fixes (#142960, #150346) addressed missing embedded grammars but not the column-detection logic.
