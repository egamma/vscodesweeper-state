# Issue #173181 — [Feature Request] Mouse Gestures Support

[https://github.com/microsoft/vscode/issues/173181](https://github.com/microsoft/vscode/issues/173181)

## Summary

Keep open: the request earned 28 upvotes and was explicitly promoted to the Backlog. The related mouse-shortcut issue does not fully cover drawn gesture recognition, and the available extension is only a constrained workaround.

## Change summary

Allow users to bind commands to patterns drawn with the mouse.

## Best solution

Prefer an extension-based implementation, supported by a carefully scoped input API if extensions cannot capture gestures safely outside webviews; the keybindings and extension-API owners should decide that boundary.
