# Issue #328710 — Join us on youtube button does nothing as expected

[https://github.com/microsoft/vscode/issues/328710](https://github.com/microsoft/vscode/issues/328710)

## Summary

Milestone 1.134.0 is assigned, so this stays open regardless of the ambiguous repro status; a contributor's investigation is convincing that the code path is fine and the actual defect is a stale internal branding value for `youTubeUrl`, not something fixable in this public repo.

## Change summary

Clicking Help > Join Us on YouTube opens a Bing search/home page instead of the YouTube channel.

## Best solution

No code change needed in this repo — `OpenYouTubeUrlAction.run()` in src/vs/workbench/browser/actions/helpActions.ts just calls `openerService.open(URI.parse(productService.youTubeUrl))`, and `youTubeUrl` (src/vs/base/common/product.ts:214) is never populated in the public product.json; it's set at build time from Microsoft's internal branding config. Someone with access to that internal config needs to re-point the (likely expired aka.ms) short link.
