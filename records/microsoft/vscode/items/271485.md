# Issue #271485 — Reconsider adding settings for preferred icon theme for light and dark modes

[https://github.com/microsoft/vscode/issues/271485](https://github.com/microsoft/vscode/issues/271485)

## Summary

A maintainer explicitly confirmed that there are no plans to add separate preferred light/dark icon-theme settings to VS Code core and directed users to an existing extension, so this is a high-confidence extension-candidate close.

## Change summary

Add separate preferred file icon theme settings for light and dark system color modes and switch them automatically with the system theme.

## Best solution

Keep this capability in the existing Preferred Icon Theme extension, where it can evolve without adding more core settings or maintenance burden.

## Vision fit

- **Fit:** rejected
- **Reason:** The capability is already implementable as an extension, while adding two specialized core settings conflicts with the lean-default and extension-first guardrails.
- **Evidence:** Values and guardrails: “The power lives in extensions” and “Out of the box, VS Code is a text editor: lightweight and fast.”
