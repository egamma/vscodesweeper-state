# Issue #127614 — Trusted uris: added uri should be focused

[https://github.com/microsoft/vscode/issues/127614](https://github.com/microsoft/vscode/issues/127614)

## Summary

Still reproduces on main: after adding a trusted folder, updateTable() is called but the newly added entry is never focused — the selectTrustedUriEntry helper exists but isn't wired into the add flow.

## Change summary

After adding a trusted URI via the workspace trust editor, the list refreshes but doesn't focus the newly added entry.

## Best solution

In the add-button click handler (workspaceTrustEditor.ts ~line 188), capture the added URI before calling setUrisTrust, then after updateTable completes, call selectTrustedUriEntry on the matching entry to focus it in the table.
