Keep open: the supplied Custom Endpoint configuration steps and Local-versus-Copilot comparison suffice to retest the attribution discrepancy. Current main still converts generic numeric cost metadata into Copilot credits, but the Custom Endpoint runtime payload has not been confirmed.

## Change summary

Omit misleading Copilot credit attribution for Custom Endpoint responses when applicable billing information is unavailable.

## Best solution

Make Custom Endpoint attribution distinguish unavailable provider cost from reported Copilot credits, while preserving genuine Copilot charges, including zero-valued charges. Treat the optional provider-native cost API as a separate design consideration rather than a prerequisite for correcting the footer.
