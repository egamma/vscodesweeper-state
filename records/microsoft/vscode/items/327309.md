# Issue #327309 — 1.130 version extension host crash in Arch Linux 

[https://github.com/microsoft/vscode/issues/327309](https://github.com/microsoft/vscode/issues/327309)

## Summary

A VS Code collaborator investigated the crash dumps in detail and traced the segfault to the dynamic linker crashing during lazy relocation of the user's system libwebkit2gtk-4.1.so.0 on Arch/CachyOS — confirmed by directly dlopen'ing that library outside VS Code entirely and reproducing the same crash. The maintainer could not reproduce on tar/deb packages and identified the root cause as outside VS Code binaries.

## Change summary

Extension host / login flow crashes on Arch Linux after updating to 1.130, apparently tied to msal-node-runtime.node loading.

## Best solution

Close as not reproducible in VS Code itself; the crash is in the user's system dynamic linker/webkit2gtk stack. Recommend the workaround `LD_BIND_NOW=1` and following up with the distro (CachyOS/Arch) for a glibc/webkit2gtk fix.
