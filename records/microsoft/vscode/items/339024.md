# Issue #339024 — Crash reports on Windows include the full process environment (incl. user env-var secrets); please document this and revisit the default

[https://github.com/microsoft/vscode/issues/339024](https://github.com/microsoft/vscode/issues/339024)

## Summary

Security-sensitive report (crash dumps can leak user env-var secrets via Crashpad on Windows, plus a confirmed doc/UX gap in disabling crash reporting) — never propose closing this per the hard keep-open rule for security concerns; the code claims check out on main.

## Change summary

On Windows, uploaded Crashpad minidumps include the full process environment (so User env-var secrets can be exfiltrated), the docs don't disclose this, and the documented way to disable crash reporting via argv.json is silently overwritten by the telemetry level.

## Best solution

Treat as a security/privacy issue needing a human decision: (1) update telemetry docs and the FAQ/1.49 release notes to state Windows minidumps include the process environment, the App Center destination, and retention; (2) fix the misleading argv.json comment and the telemetry-level override described in app.ts; (3) have the team evaluate upstream options with Crashpad (exclude/allowlist the environment block) or change the default to opt-in minidump upload.
