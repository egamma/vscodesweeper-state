# Issue #299907 — Limited context size (33k) for Ollama Models

[https://github.com/microsoft/vscode/issues/299907](https://github.com/microsoft/vscode/issues/299907)

## Summary

Still reproduces on main: the Ollama provider falls back to a hardcoded 32768 context window when the architecture-specific `context_length` key is missing from the `/api/show` response, which happens for cloud models and some model families. Additionally, user-configured Ollama context sizes (`num_ctx` / `OLLAMA_CONTEXT_LENGTH`) are never consulted.

## Change summary

Ollama models in VS Code Copilot Chat show a capped ~33k context window instead of the model's actual context length, because the fallback in `ollamaProvider.ts` defaults to 32768 when the architecture-keyed `context_length` field is absent.

## Best solution

Fix the context-length extraction in `_getOllamaModelInfo` to also check top-level `context_length` from the `/api/show` response (newer Ollama versions expose it there, as seen in comment 10's `/api/tags` output), and consider respecting the Ollama-configured `num_ctx` as a cap. The fallback of 32768 should be the last resort, not the common path for cloud or non-standard models.
