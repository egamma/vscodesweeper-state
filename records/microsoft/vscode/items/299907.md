# Issue #299907 — Limited context size (33k) for Ollama Models

[https://github.com/microsoft/vscode/issues/299907](https://github.com/microsoft/vscode/issues/299907)

## Summary

Keep open: the built-in Ollama provider still falls back to 32,768 tokens when architecture-specific metadata is absent and ignores configured runtime context limits. The provider is now deprecated, so a maintainer should decide the support boundary before pursuing the remaining fixes.

## Change summary

Make Ollama model context reporting and prompt budgeting reflect valid model metadata and the effective configured context limit.

## Best solution

Ensure Ollama users receive accurate context budgets without premature compaction or requests exceeding the server's capacity. Decide whether to correct the still-registered deprecated provider or address the remaining behavior through the supported integration; deprecation alone does not establish that this report is fixed.
