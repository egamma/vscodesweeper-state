# Issue #326943 — Chat: add an explicit agent-host model readiness signal (distinguish "still loading" from "authoritatively empty")

[https://github.com/microsoft/vscode/issues/326943](https://github.com/microsoft/vscode/issues/326943)

## Summary

Team-authored architectural debt issue requesting a first-class agent-host model readiness signal to replace ad-hoc heuristics. The proposed signal has not been implemented on main; the issue tracks real remaining work after the stop-gap fix in #326938.

## Change summary

Introduce an explicit per-agent-host 'models published / ready' signal so consumers can distinguish a transient empty model list from an authoritatively empty one.

## Best solution

Plumb a per-agent-host readiness state through ILanguageModelsService (e.g. `isVendorReady` / `onDidChangeVendorReadiness`), feed it into resolve, cache-retention, and send-blocked paths, then remove the special-case agent-host heuristics from #326938. The work spans `languageModels.ts`, `modelSelection.ts`, `chatInputModelUtils.ts`, `chatInputModelSelectionController.ts`, and the agent-host connection layer.
