# Issue #298339 — Enable CSS customization for all themes

[https://github.com/microsoft/vscode/issues/298339](https://github.com/microsoft/vscode/issues/298339)

## Summary

The maintainer reports that the 2026 theme styles were upstreamed, but current main still gates extension-contributed CSS behind proposed API. Keep this team-authored issue open to settle the supported theme-author contract; neither a qualifying referenced fix nor an older canonical covering the same request was established.

## Change summary

Determine whether extension-contributed themes can customize non-color workbench styling and define the supported developer experience.

## Best solution

Define a supported, documented styling contract for theme authors, distinguishing shared product styling from theme-specific overrides. Explicitly settle whether the proposed contributes.css mechanism should become generally available or whether supported theme tokens should provide the customization boundary.
