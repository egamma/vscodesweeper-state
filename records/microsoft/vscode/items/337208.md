# Issue #337208 — Terminal: support crisp font rendering on HiDPI displays

[https://github.com/microsoft/vscode/issues/337208](https://github.com/microsoft/vscode/issues/337208)

## Summary

The experimental macOS setting has landed, but GPU rendering remains inconsistent and Windows/Linux support is still unevaluated. Keep this team-authored request open; the merged PR explicitly implements only part of it, and a related image-transparency fix is still under review.

## Change summary

Provide opt-in sharper terminal antialiasing on HiDPI displays without changing other text surfaces, terminal styling, or image transparency.

## Best solution

Retain the unchanged inherit default and make the opt-in policy consistent across terminal creation, restoration, and live switching through an adopted xterm.js rendering capability. Review the existing image-transparency PR rather than competing with it, and evaluate Windows/Linux separately before extending support.
