# Issue #203215 — Diff Editor scroll viewport inaccurate (regression)

[https://github.com/microsoft/vscode/issues/203215](https://github.com/microsoft/vscode/issues/203215)

## Summary

The current diff overview still uses an artificially enlarged scrollbar thumb to represent the visible document range, which explains the inaccurate indication on large files in small windows. Keep this accepted bug open; no fixing commit or eligible older open duplicate was established.

## Change summary

Make the diff overview's viewport indicator accurately represent the visible document range when comparing large files, including in small windows.

## Best solution

Restore accurate viewport geometry in the diff overview without reducing the usability of scrollbar dragging or changing shared scrollbar behavior. Pin the large-file, short-viewport case with a focused diff-editor regression test.
