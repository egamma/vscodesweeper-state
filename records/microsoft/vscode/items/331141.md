# Issue #331141 — Pet shifting chat content based on window focus

[https://github.com/microsoft/vscode/issues/331141](https://github.com/microsoft/vscode/issues/331141)

## Summary

Team-authored, milestone-scheduled report; the merged fix (PR #331278) addressed the multi-window duplicate-pet issue but the reporter (roblourens, MEMBER) confirmed on 2026-08-20 that the distracting show/hide animation on window blur/focus still persists, and the follow-up design (only hide when swapping editor/agents windows) was also called insufficient — this stays open pending further work.

## Change summary

The chat pet plays a visible disappear/reappear animation whenever the VS Code window loses or regains OS focus, which the reporter finds distracting.

## Best solution

Continue iterating in chatPetWidget.ts's enablement autorun (around isChatPetVisible/isChatPetWindowActive, lines ~1336-1411): decouple window-focus changes from the enable/disable animation path so the pet's visibility doesn't blink on ordinary window/app focus swaps, per the design discussion between roblourens and justschen still in progress on the issue.
