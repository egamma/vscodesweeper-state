# Issue #331141 — Pet shifting chat content based on window focus

[https://github.com/microsoft/vscode/issues/331141](https://github.com/microsoft/vscode/issues/331141)

## Summary

The original content jump was addressed, but current main still deliberately transfers pet ownership between VS Code windows using animated disable/enable transitions, matching the distracting motion reported after the issue was reopened. This team-authored On Deck item should remain open for the remaining focus-handoff polish.

## Change summary

Avoid distracting pet disappearance and re-entry motion when application or VS Code window focus changes.

## Best solution

Preserve the single-pet ownership model while making focus-driven ownership handoffs visually stationary: leaving VS Code should not remove the pet, and switching VS Code windows should not replay the ordinary pet entry and exit animations.
