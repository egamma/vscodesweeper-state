# Issue #96104 — Git - "Stage selected ranges" clobbers line endings for the entire file without any warning (Windows)

[https://github.com/microsoft/vscode/issues/96104](https://github.com/microsoft/vscode/issues/96104)

## Summary

Keep open: the current partial-staging path still applies Git's line-ending conversion to the reconstructed file. An open PR explicitly targets this issue and should be reviewed before considering it resolved.

## Change summary

Stage Selected Ranges silently converts committed CRLF line endings to LF across the file, including unselected lines.

## Best solution

Partial staging should preserve the indexed line endings outside the selected changes while retaining intended encoding and clean-filter behavior. Review https://github.com/microsoft/vscode/pull/328187 as the existing implementation candidate; keep this issue open until the fix lands.
