# Issue #345987 — MCP trust dialog closes Configure Tools, so each `mcp-config.json` server needs a reopen

[https://github.com/microsoft/vscode/issues/345987](https://github.com/microsoft/vscode/issues/345987)

## Summary

The current picker still closes when its MCP trust dialog takes focus, then disposes itself instead of remaining available for the next server. This is distinct from the closed scrolling-related report and remains actionable.

## Change summary

Preserve the Configure Tools workflow when Update Tools opens an MCP server trust dialog.

## Best solution

Keep Configure Tools available, with its selections preserved, after trusting and successfully starting a server. Preserve explicit trust decisions and normal picker dismissal; batch trust is an optional enhancement, not required to resolve this bug.
