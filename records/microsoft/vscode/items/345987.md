# Issue #345987 — MCP trust dialog closes Configure Tools, so each `mcp-config.json` server needs a reopen

[https://github.com/microsoft/vscode/issues/345987](https://github.com/microsoft/vscode/issues/345987)

## Summary

Keep open: the current source confirms that opening the MCP trust dialog dismisses and disposes Configure Tools, despite Update Tools explicitly intending to keep it open.

## Change summary

Preserve the Configure Tools session while users approve untrusted MCP servers, avoiding a picker reopen for each server.

## Best solution

Keep the tool-selection session available after the trust interaction, retaining selections and refreshing the server's tools. Preserve explicit trust requirements and normal dismissal behavior; a combined multi-server prompt is an optional enhancement, not necessary to resolve this defect.
