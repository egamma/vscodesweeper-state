# Issue #290956 — new agent requires reload

[https://github.com/microsoft/vscode/issues/290956](https://github.com/microsoft/vscode/issues/290956)

## Summary

Keep open: current source still lacks an automatic cloud custom-agent picker refresh after pushing a new agent. Dynamic option updates are now supported, but ordinary background refreshes update session items rather than the agent options.

## Change summary

New custom agents pushed to the repository's main branch should appear in the cloud-agent dropdown without reloading VS Code.

## Best solution

Make the cloud provider's custom-agent options reflect newly available remote agents without a window reload, while preserving the distinction between selectable remote agents and disabled local-only agents.
