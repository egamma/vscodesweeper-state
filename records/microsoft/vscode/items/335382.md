# Issue #335382 — Markdown smart select: a single-asterisk italic span on the line discards all Markdown selection ranges

[https://github.com/microsoft/vscode/issues/335382](https://github.com/microsoft/vscode/issues/335382)

## Summary

Well-diagnosed bug with a precise suggested fix; the defective code lives in the microsoft/vscode-markdown-languageservice package (bundled dependency of the built-in markdown-language-features extension), and I confirmed the described defect is still present on that package's current main.

## Change summary

In Markdown, Expand Selection loses all Markdown ranges (paragraph/section/document) whenever a line contains a single-asterisk italic span, because the italic smart-select regex tests the cursor against the whole match instead of the inner group, so it wrongly claims to contain a cursor position outside the actual span, then the extension host's containment check discards the entire chain.

## Best solution

Fix `createOtherInlineRange` in vscode-markdown-languageservice's src/languageFeatures/smartSelect.ts to test/position using the inner capture group's own offsets (e.g. via the regex `d` flag and match.indices[1]) rather than match[0], as the reporter suggests, then bump the `vscode-markdown-languageservice` dependency version in extensions/markdown-language-features/package.json once that fix ships.
