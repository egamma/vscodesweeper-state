# Issue #335382 — Markdown smart select: a single-asterisk italic span on the line discards all Markdown selection ranges

[https://github.com/microsoft/vscode/issues/335382](https://github.com/microsoft/vscode/issues/335382)

## Summary

Confirmed real bug in the bundled `vscode-markdown-languageservice` dependency (pinned at 0.5.0 in `extensions/markdown-language-features/package.json`): the italic selection-range filter tests the cursor against the whole regex match instead of the inner capture group, so any single-asterisk italic span on a line silently discards the entire smart-select chain for that line. This needs a fix upstream in the `microsoft/vscode-markdown-languageservice` repo, then a version bump in this repo, so routing rather than a direct core close.

## Change summary

Markdown 'Expand Selection' loses all paragraph/section/document ranges on any line containing a single-asterisk italic span, unless the cursor happens to sit inside that span.

## Best solution

Fix `createOtherInlineRange` in `microsoft/vscode-markdown-languageservice`'s `src/languageFeatures/smartSelect.ts` to filter/position on capture group 1 (e.g. using the `d` regex flag and `match.indices[1]`) instead of `match[0]`, release a patched version, then bump the `vscode-markdown-languageservice` dependency in `extensions/markdown-language-features/package.json`.
