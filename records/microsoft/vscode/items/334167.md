# Issue #334167 — Primary Side Bar width resets after toggling visibility (Ctrl+B)

[https://github.com/microsoft/vscode/issues/334167](https://github.com/microsoft/vscode/issues/334167)

## Summary

Well-documented regression in 1.136.x: at least five independent reporters confirm the Primary Side Bar resets to minimum width after Ctrl+B toggle, with several narrowing it to sidebar-on-the-right configurations and identifying two independent workarounds (`window.density.layout: compact`, `workbench.experimental.modernUI: false`) that point at the new Modern UI / floating-panels feature interacting badly with the grid's cached-visible-size restore path.

## Change summary

Toggling the Primary Side Bar off and back on with Ctrl+B resets its width to the default/minimum instead of restoring the previously resized width.

## Best solution

Investigate the interaction between the new Modern UI (`src/vs/workbench/contrib/modernUI/browser/modernUI.contribution.ts`) / `window.density.layout` setting and the sidebar's cached-visible-size restore in `setSideBarHidden`/`workbenchGrid.setViewVisible` (src/vs/workbench/browser/layout.ts, src/vs/base/browser/ui/grid/gridview.ts) — the workarounds (disabling Modern UI, switching to compact density) strongly suggest the regression is in how Modern UI's floating-panel layout caches or restores the sidebar's grid size, especially when the sidebar is positioned on the right.
