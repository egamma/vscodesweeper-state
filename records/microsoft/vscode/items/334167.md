# Issue #334167 — Primary Side Bar width resets after toggling visibility (Ctrl+B)

[https://github.com/microsoft/vscode/issues/334167](https://github.com/microsoft/vscode/issues/334167)

## Summary

Multiple independent users confirm the Primary Side Bar resets to its minimum/default width after a Ctrl+B hide/show toggle in 1.136.x; this reads as a real regression, but the exact root cause is disputed in the thread (setting `window.density.layout` to compact works around it for some, not others; one commenter reports it's specific to the side bar being on the right) so I can't cite a fix commit or pin the defect to one code path from static reading alone.

## Change summary

After manually widening the Primary Side Bar, hiding it and showing it again via Ctrl+B resets it to the minimum/default width instead of preserving the custom width.
