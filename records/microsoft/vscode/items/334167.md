# Issue #334167 — Primary Side Bar width resets after toggling visibility (Ctrl+B)

[https://github.com/microsoft/vscode/issues/334167](https://github.com/microsoft/vscode/issues/334167)

## Summary

Well-confirmed regression: dragging the Primary Side Bar wider then toggling it with Ctrl+B resets its width, most consistently reproduced when the side bar is positioned on the right. A VS Code contributor is already actively investigating and has said a fix is coming, so this should stay open pending that work rather than being closed.

## Change summary

Toggling the Primary Side Bar's visibility (Ctrl+B) discards its custom width and resets it to the minimum/default, particularly when the bar is docked on the right.

## Best solution

Fix the width-restoration path invoked from `setSideBarHidden`/`workbenchGrid.setViewVisible` in src/vs/workbench/browser/layout.ts (and the underlying cached-visible-size handling in src/vs/base/browser/ui/grid/gridview.ts / splitview.ts) so the cached width is honored symmetrically for both left- and right-positioned side bars; a VS Code contributor (mrleemurray) is already tracking this and says a fix is forthcoming.
