# Issue #169779 — GitHub - Handle GitHub's branch protection push errors

[https://github.com/microsoft/vscode/issues/169779](https://github.com/microsoft/vscode/issues/169779)

## Summary

Keep open: current code offers preventive branch-protection prompts but still lacks dedicated handling when GitHub rejects a push for branch protection. This team-authored Backlog request remains distinct from the completed secret-scanning work.

## Change summary

Explain GitHub branch-protection push rejections directly and offer an appropriate recovery path without requiring users to inspect Git output.

## Best solution

The built-in GitHub integration should distinguish branch-protection rejections from ordinary push failures and present useful recovery actions. Agree whether recovery only explains the restriction or also offers a new-branch and pull-request workflow.
