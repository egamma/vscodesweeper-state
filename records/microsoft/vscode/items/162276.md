# Issue #162276 — Continue on does not provide a way to move to a different machine.

[https://github.com/microsoft/vscode/issues/162276](https://github.com/microsoft/vscode/issues/162276)

## Summary

Keep open: standalone Cloud Changes commands support a manual cross-machine handoff, but Continue Working On still lacks a built-in save-for-another-machine destination. The discussion also identifies identity-matching failures; the linked tracking issue is closed, and no verified older canonical or issue-referencing fix establishes completion of this team-authored request.

## Change summary

Provide a discoverable way to save working changes through Continue Working On and resume them on a different machine.

## Best solution

Make the existing Cloud Changes store/resume capability discoverable as a cross-machine handoff within Continue Working On, without requiring an immediate destination launch. Treat the reported SSH/HTTPS and differing-HEAD restoration failure separately from that missing entry point.

## Evidence

- **Existing capability and remaining gap:** src/vs/workbench/contrib/editSessions/browser/editSessions.contribution.ts registers workbench.editSessions.actions.storeCurrent ('Store Working Changes in Cloud') and workbench.editSessions.actions.resumeLatest ('Resume Latest Changes from Cloud'). These provide a manual handoff, but createPickItems() only adds contributed destinations, a conditional local-folder destination, and additional-options installation; it does not add a built-in store-only handoff.
- **Continue On control flow:** In registerContinueEditSessionAction(), destination selection precedes storing changes, and cancelling selection returns before storage. This differs from saving now to resume later on another machine.
- **Discussion diagnosis:** https://github.com/microsoft/vscode/issues/162276#issuecomment-1261554214 shows successful storage on vscode.dev followed by skipped restoration and deletion on Linux, with SSH versus HTTPS remotes and different HEAD SHAs. https://github.com/microsoft/vscode/issues/162276#issuecomment-1262303183 identifies both identity differences and explicitly points to https://github.com/microsoft/vscode/issues/162120.
