# Issue #123879 — Debugger: Smart Step Into

[https://github.com/microsoft/vscode/issues/123879](https://github.com/microsoft/vscode/issues/123879)

## Summary

The basic Step Into Target feature exists (context menu + cursor-position matching via DAP StepInTargets), but the core request — inline visual highlighting of step-into targets in the editor (solutions 2 and 3 from the issue) — remains unimplemented. Author is a MEMBER; keeping open.

## Change summary

Provide an inline visual UI for selecting step-into targets during debugging, showing highlighted ranges directly in the editor rather than requiring a context menu.

## Best solution

Implement inline editor decorations that highlight step-into target ranges on the active debug line, allowing click or keyboard selection — the 'Source Code Range Highlight + Selection' approach described in the issue. The existing StepIntoTargetsAction in src/vs/workbench/contrib/debug/browser/debugEditorActions.ts and the DAP StepInTarget range support (added in commit 6b4b3613197) provide the foundation; the remaining work is the inline decoration UI layer.
