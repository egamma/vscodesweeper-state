# Issue #180496 — Allow display prop on markdown span style

[https://github.com/microsoft/vscode/issues/180496](https://github.com/microsoft/vscode/issues/180496)

## Summary

Still unimplemented on main: the span style sanitizer in markdownRenderer.ts only allows color, background-color, and border-radius — no display property. The linked PR #180498 remains open. With 605 upvotes and Backlog milestone, this should stay open for a maintainer to review the PR.

## Change summary

Allow the `display` CSS property on `<span>` style attributes in VS Code's markdown renderer so extensions like pretty-ts-errors can properly style inline elements.

## Best solution

Review and land (or update) the open PR https://github.com/microsoft/vscode/pull/180498, which adds `display:inline-block` to the allowed style regex in `src/vs/base/browser/markdownRenderer.ts`. The change is a one-line regex extension with minimal risk — a maintainer should evaluate which display values to allow (e.g. only `inline-block` or a broader safe subset).
