# Issue #335250 — Title bar "Layout Control" / action-toolbar-container icons don't use titleBar.activeForeground/inactiveForeground

[https://github.com/microsoft/vscode/issues/335250](https://github.com/microsoft/vscode/issues/335250)

## Summary

Traced this directly in the CSS on current main: the action-toolbar-container (Layout Control, Accounts, relocated editor actions) only sets `color: inherit` on its codicons, with no rule binding to `--vscode-titleBar-activeForeground`/`-inactiveForeground` the way the Command Center and menubar rules do — a real, well-diagnosed gap that just needs area routing.

## Change summary

The Layout Control/Accounts icon group in the custom title bar's action-toolbar-container doesn't bind to titleBar.activeForeground/inactiveForeground like the Command Center and menubar icons do.

## Best solution

Add color rules for `.action-toolbar-container` (and its `.inactive` variant) in titlebarpart.css mirroring the existing Command Center/menubar pattern (lines ~154-161), binding to `--vscode-titleBar-activeForeground`/`--vscode-titleBar-inactiveForeground` instead of leaving `.codicon { color: inherit; }` as the only rule.
