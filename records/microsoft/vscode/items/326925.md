# Issue #326925 — Agent sessions: PR link never shows because the tracked branch goes stale (and gets cross-contaminated between sessions)

[https://github.com/microsoft/vscode/issues/326925](https://github.com/microsoft/vscode/issues/326925)

## Summary

Current main retains the session's creation-time branch after its worktree HEAD changes, so PR detection queries the stale branch. Route this confirmed bug to the Agents window and Copilot CLI integration owners.

## Change summary

Keep each agent session's branch and PR association synchronized with its own worktree after branch changes.

## Best solution

Update each session's worktree metadata from that worktree repository's HEAD, then rerun PR detection when the branch changes. Audit Chronicle branch attribution separately to ensure spans cannot write another session's repository context.
