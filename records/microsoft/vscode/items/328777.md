# Issue #328777 — Switching between tool confirmations shifts UI.

[https://github.com/microsoft/vscode/issues/328777](https://github.com/microsoft/vscode/issues/328777)

## Summary

The layout shift remains explainable on current main: navigating between confirmations replaces variably sized content inside an intrinsically sized input area. This team-authored visual bug should remain open.

## Change summary

Keep the surrounding chat UI stationary when navigating between tool confirmations with different content dimensions.

## Best solution

Stabilize the confirmation carousel's visible footprint while moving between pending tools, while retaining its existing viewport cap, explicit expansion behavior, keyboard navigation, and focus handling.
