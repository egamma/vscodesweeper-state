# Issue #336742 — UX Issue: Unable to reopen AI chat in Editor Mode after closing, forced into Agents Mode (Antigravity UI)

[https://github.com/microsoft/vscode/issues/336742](https://github.com/microsoft/vscode/issues/336742)

## Summary

The reported Editor Mode / Agents Mode interface and Antigravity agent behavior belong to the third-party Antigravity integration, not VS Code core. The docking request and the reported edit/keybinding failures should therefore be handled by that integration's owner.

## Change summary

Restore the Antigravity chat inside the editor window and prevent its standalone agent surface from blocking debugging shortcuts or failing workspace edits.

## Best solution

The Antigravity integration should provide a supported way to reveal or relocate its contributed view and ensure its agent surface does not intercept VS Code keybindings or fail edits. Any core API gap identified by its maintainers can then be filed separately with a minimal VS Code reproduction.
