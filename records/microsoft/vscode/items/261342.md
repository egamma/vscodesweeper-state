# Issue #261342 — QuickPick — Add `noFiltering` option to `QuickPick`

[https://github.com/microsoft/vscode/issues/261342](https://github.com/microsoft/vscode/issues/261342)

## Summary

Keep open: hiding the QuickPick input is supported internally but remains unavailable through the stable extension API. This is an api-proposal tracking issue, so any finalization or closure belongs to the API owners.

## Change summary

Expose an option to hide the filter input in both createQuickPick() and showQuickPick() for short, keyboard-navigable lists.

## Best solution

Have the API owners evaluate exposing the existing hideInput behavior consistently through QuickPick and QuickPickOptions, preserving the default searchable picker. The maintainer's suggested name distinguishes hiding the input from merely disabling filtering.
