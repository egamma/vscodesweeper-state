# Issue #232604 — After update, app is completely unusable

[https://github.com/microsoft/vscode/issues/232604](https://github.com/microsoft/vscode/issues/232604)

## Summary

The supplied crash dump identifies an NVIDIA driver crash rather than a VS Code workbench defect. Dependency-owned failures remain open as upstream issues, although one affected user reported the problem gone in VS Code 1.96.0.

## Change summary

VS Code 1.95 displayed an unresponsive gray window on Linux when its GPU process crashed.

## Best solution

The NVIDIA driver must avoid crashing during GPU-process teardown; VS Code should retain `--disable-gpu` as the workaround and track whether current Electron or driver releases still trigger the failure.
