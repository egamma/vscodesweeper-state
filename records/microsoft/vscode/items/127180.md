# Issue #127180 — Git - Inconsistent use of git.path variable if containing ${execPath}

[https://github.com/microsoft/vscode/issues/127180](https://github.com/microsoft/vscode/issues/127180)

## Summary

Keep open: current Git discovery and execution still use different working directories without resolving configured path variables, but the reported Windows discovery-success/execution-failure sequence remains unverified. The implementation has evolved since 1.57.1; the supplied portable layout, setting, and observed behavior suffice to retest it.

## Change summary

A variable-containing git.path can find Git during discovery but fail when executing commands from a workspace in a portable Windows installation.

## Best solution

Ensure Git discovery and repository commands consistently identify the same executable, independent of the workspace directory or drive. First reproduce the Windows path behavior and distinguish inconsistent executable resolution from the separately tracked request for setting-variable support.
