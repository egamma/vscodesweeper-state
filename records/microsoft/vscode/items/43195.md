# Issue #43195 — [json] launch.json completion for "type" does not include expected values

[https://github.com/microsoft/vscode/issues/43195](https://github.com/microsoft/vscode/issues/43195)

## Summary

Keep open: the missing completion alternatives are a confirmed limitation in the bundled JSON language service, and an open upstream PR explicitly targets this issue. The issue should remain available until that fix is reviewed, merged, and consumed by VS Code.

## Change summary

JSON completion omits valid discriminator values when `anyOf` or `oneOf` alternatives have differing required properties.

## Best solution

Review and land https://github.com/microsoft/vscode-json-languageservice/pull/237, then update the bundled `vscode-json-languageservice` dependency in VS Code and verify launch configuration plus general `anyOf`/`oneOf` completion scenarios.
