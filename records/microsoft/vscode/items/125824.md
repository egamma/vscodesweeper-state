# Issue #125824 — The exitCode in onDidEndTaskProcess event callback is 0 when user hits Ctrl-C on the task.

[https://github.com/microsoft/vscode/issues/125824](https://github.com/microsoft/vscode/issues/125824)

## Summary

Confirmed bug still present on main. When Ctrl-C terminates a task's child process, the exit code reported via `onDidEndTaskProcess` is 0 instead of the expected 130 (128 + SIGINT). Team members confirmed the issue in 2023 and it remains unfixed.

## Change summary

The `onDidEndTaskProcess` event reports exit code 0 when a user presses Ctrl-C to stop a running task, instead of the correct non-zero signal-based exit code (e.g. 130).

## Best solution

The root cause likely involves how the shell in a ShellExecution reports its exit status after the child process is killed by SIGINT. The fix should ensure that the exit code from the terminated child process (130 for SIGINT) propagates correctly through node-pty → `TerminalProcess._exitCode` → `terminalTaskSystem`'s `onExit` handler. The relevant files are `src/vs/platform/terminal/node/terminalProcess.ts` (line 407: `this._exitCode || 0` also masks a 0 exit code from a non-zero one if `_exitCode` is undefined) and `src/vs/workbench/contrib/tasks/browser/terminalTaskSystem.ts`.
