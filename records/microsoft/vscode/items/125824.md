# Issue #125824 — The exitCode in onDidEndTaskProcess event callback is 0 when user hits Ctrl-C on the task.

[https://github.com/microsoft/vscode/issues/125824](https://github.com/microsoft/vscode/issues/125824)

## Summary

Keep open: maintainers confirmed that interrupting a Linux task reports success instead of exit code 130, and current terminal process handling still discards the termination signal. No verified canonical or fixing commit was found.

## Change summary

Report an interrupted Linux task as unsuccessful rather than emitting exitCode 0 through onDidEndTaskProcess.

## Best solution

Preserve signal-termination semantics through the terminal process exit pipeline so the task API reports 130 for the confirmed SIGINT case. Preserve ordinary exit codes and Windows behavior.
