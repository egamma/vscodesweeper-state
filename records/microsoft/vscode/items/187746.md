# Issue #187746 — tasks.json: Operating system specific properties can't be combined with the dependsOn property

[https://github.com/microsoft/vscode/issues/187746](https://github.com/microsoft/vscode/issues/187746)

## Summary

The reported dependency is still ignored on current main: platform-specific commands are selected, but dependsOn is read only from the task's top level. Keep this confirmed tasks bug open; the source identifies a bounded parsing defect.

## Change summary

Honor dependsOn inside the active operating-system-specific task configuration so prerequisite tasks run before its command.

## Best solution

Make platform-specific task dependencies effective while preserving top-level dependency behavior and existing command overrides, with matching configuration typing/schema and focused parser regression coverage.
