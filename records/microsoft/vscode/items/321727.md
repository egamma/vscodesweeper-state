# Issue #321727 — Agents window ("Open in Agents"): preserve source subfolder as working directory when a session uses worktree isolation (monorepo)

[https://github.com/microsoft/vscode/issues/321727](https://github.com/microsoft/vscode/issues/321727)

## Summary

Valid feature request — the worktree isolation path in `_resolveSessionWorkingDirectory` returns the bare worktree root without preserving the relative subfolder offset. No fix or related change has landed on main. Routing to agent-host area.

## Change summary

When worktree isolation is used from a monorepo subfolder, the session's working directory resets to the worktree root instead of preserving the original relative subpath.

## Best solution

In `_resolveSessionWorkingDirectory` (copilotAgent.ts ~line 3055), compute the relative path from `repositoryRoot` to the original `config.workingDirectory`, then append it to the new worktree URI before returning. Propagate consistently to instructions discovery and `worktreeCreated` task discovery.
