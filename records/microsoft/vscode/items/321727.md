# Issue #321727 — Agents window ("Open in Agents"): preserve source subfolder as working directory when a session uses worktree isolation (monorepo)

[https://github.com/microsoft/vscode/issues/321727](https://github.com/microsoft/vscode/issues/321727)

## Summary

Keep open: current source still replaces the selected monorepo subfolder with the isolated worktree root, and no verified canonical owns preserving that subfolder. Existing directory propagation and task discovery do not supply the requested behavior.

## Change summary

Preserve the selected subproject's relative path inside an isolated worktree so the session, customization discovery, Files panel, and tasks remain scoped to that subproject.

## Best solution

Distinguish the repository-level worktree root from the session's effective working directory in Agent Host, preserving the selected subfolder across creation and restoration. Decide whether preservation is the default or opt-in, while keeping Git worktree lifecycle operations repository-scoped.
