# Issue #85781 — JavaScript: Improve indentation on insert with trailing newline

[https://github.com/microsoft/vscode/issues/85781](https://github.com/microsoft/vscode/issues/85781)

## Summary

Keep open: the paste-indentation path still adjusts the pre-existing line when the pasted range ends at column 1. An open PR explicitly targets this issue, so the next step is reviewing that contribution rather than closing the report or starting competing work.

## Change summary

Pasting whole lines with a trailing newline incorrectly changes the indentation of the existing line immediately after the pasted text.

## Best solution

Review and update https://github.com/microsoft/vscode/pull/182934 so auto-indentation preserves existing code outside the pasted range while continuing to indent the inserted lines correctly.

## Evidence

- **Current source confirms the boundary defect:** In src/vs/editor/contrib/indentation/browser/indentation.ts, AutoIndentOnPaste.trigger computes an indentation offset and applies it through i <= range.endLineNumber at line 509 without excluding an end position at column 1. For the reported whole-line paste, this includes the existing line containing b even though none of that line belongs to the pasted text.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/182934 is currently OPEN and explicitly contains Fixes #85781. Its diff excludes the terminal line when range.endColumn === 1 and adds a regression test asserting that pre-existing following code retains its indentation. This is an unmerged proposal, not evidence of a completed fix.
- **Discussion establishes expected behavior:** The discussion supplied for https://github.com/microsoft/vscode/issues/85781 identifies the column-1 end boundary, and the reporter confirms that indentation should apply only to the pasted text, leaving the following existing line unchanged.
- **Related closed report is not a duplicate target:** https://github.com/microsoft/vscode/issues/147223 reports the same existing-code indentation problem and was closed as a regex-indentation limitation, not as fixed. Its discussion includes examples in JavaScript, HTML, CSS, and JSON. It is newer and closed, so it cannot serve as a canonical for this re-reviewed issue.
- **Canonical search:** An open-issue search for paste and trailing newline returned this issue and newer reports, including https://github.com/microsoft/vscode/issues/86301 and https://github.com/microsoft/vscode/issues/324290; it did not establish an older canonical owning the same observable symptom.
- **Current behavior is gated:** AutoIndentOnPaste.update requires editor.autoIndentOnPaste and full auto-indentation. src/vs/editor/common/config/editorOptions.ts currently defaults editor.autoIndentOnPaste to false. Disabling this behavior avoids the affected path but does not satisfy the request to preserve following code while retaining paste auto-indentation.
