# Issue #92964 — [rename on type] option-delete and pasting creates 2 undo stops

[https://github.com/microsoft/vscode/issues/92964](https://github.com/microsoft/vscode/issues/92964)

## Summary

The defect remains encoded in current main: linked editing still requires two undo operations after word deletion, and the original implementation PR identifies the same failure for paste. The issue should remain open for a bounded undo-grouping fix.

## Change summary

Option-delete or paste within an HTML linked-editing region creates separate undo elements for the initiating edit and its mirrored edit.

## Best solution

Group the initiating paste or word-deletion edit with the linked-region mirror update so one undo restores both tag names, while preserving existing typing, breakout, and redo behavior.
