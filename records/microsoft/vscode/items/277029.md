# Issue #277029 — Chat Agent: Pressing "keep" restores deleted files that previously had modifications

[https://github.com/microsoft/vscode/issues/277029](https://github.com/microsoft/vscode/issues/277029)

## Summary

Keep open: current source retains pending edits for externally deleted existing files, and Keep can force-save their retained contents back to disk. No verified older canonical or concrete fixing commit was found.

## Change summary

Keeping chat edits should not recreate a previously modified file that the agent subsequently deleted through the terminal.

## Best solution

Make chat edit acceptance preserve subsequent filesystem deletions without changing ordinary editor save behavior or acceptance of files that still exist.
