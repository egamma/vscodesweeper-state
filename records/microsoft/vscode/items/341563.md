# Issue #341563 — Selection not rendered on RTL line when it ends at two empty end-of-line decoration spans

[https://github.com/microsoft/vscode/issues/341563](https://github.com/microsoft/vscode/issues/341563)

## Summary

Thanks for the detailed report. The defect is still present in `RangeUtil.readHorizontalRanges` on main: when the end is moved back to an empty span, the empty-span fallback is skipped and `null` is returned. An open PR already references this issue, so it stays open.

## Change summary

Selection is not rendered on an RTL line that ends with two empty decoration spans, such as GitLens blame.

## Best solution

Review and land the open fix PR https://github.com/microsoft/vscode/pull/341587. It makes the fallback search back to the nearest span that has text, and it should add unit tests for two trailing empty spans.
