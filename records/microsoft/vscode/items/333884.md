Keep open: the Windows reproduction steps suffice to retest, but source inspection does not establish why the new window retains a hidden menu. Recent window changes do not demonstrate a fix; inherited fullscreen behavior must be distinguished from a menu visibility defect.

## Change summary

Opening a new window from Zen Mode leaves its menu bar hidden, reportedly even after exiting Zen Mode in that window.

## Best solution

Ensure a new window's menu visibility follows its own fullscreen state and configured menu policy, without carrying an inconsistent state from the originating Zen Mode window. First reproduce the supplied Windows flow and determine whether the new window is actually fullscreen or only renders as though it is.
