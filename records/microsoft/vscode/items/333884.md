## Change summary

Opening another window while the active window is in Zen Mode can leave the new window without a persistent menu bar, even after exiting Zen Mode.

## Best solution

Reproduce on Windows with the reporter's effective Zen Mode, menu-bar, title-bar, and new-window dimension settings, then determine whether the native BrowserWindow menu state or the workbench custom title bar is stale. The menu bar should reflect the new window's own fullscreen and configuration state rather than the originating window's Zen Mode state.
