## Change summary

On Windows, opening a new/recent window after using Zen Mode in the previous window leaves the new window without a menu bar, even outside Zen Mode.

## Evidence

- **fullscreen inheritance:** src/vs/platform/windows/electron-main/windowsStateHandler.ts (doGetNewWindowState, ~line 389-392) only copies WindowMode.Fullscreen from the last active window into a new window's state when window.newWindowDimensions is 'inherit' or 'offset' — VS Code's default is 'default', which does not carry fullscreen over, so the report's exact repro path (default settings, no mention of this setting) is not confirmed against the code.
- **menu bar / fullscreen coupling:** src/vs/platform/windows/electron-main/windowImpl.ts setFullScreen() re-applies setMenuBarVisibility() when fullscreen changes, and doSetMenuBarVisibility('classic') sets autoHideMenuBar = isFullscreen; if a new window is created already in fullscreen mode (inherited or otherwise) there's a known historical timing issue noted in the code (comment referencing https://github.com/microsoft/vscode/issues/19777) where the menu bar fails to show/hide correctly on window creation.
