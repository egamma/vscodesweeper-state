# Issue #177747 — Notebook Search: regex enabled on default toggle state

[https://github.com/microsoft/vscode/issues/177747](https://github.com/microsoft/vscode/issues/177747)

## Summary

The mismatch remains in current source: notebook outputs are included by default, but their search ignores the enabled regex option without explaining the limitation. Keep this accepted, team-authored issue open; the older related report concerns a different toggle failure, not a verified duplicate.

## Change summary

Notebook search permits regex with outputs included, although rendered output searches interpret the query literally.

## Best solution

Make the mixed search semantics explicit in the global Search UI while preserving regex for source text and avoiding blanket disabling when a notebook opens. The related discussion favors a warning; settle its presentation before implementation.
