# Issue #347325 — Claude agent host: steering a running turn shows `error_during_execution` (`[ede_diagnostic] result_type=user …`) while the agent keeps working

[https://github.com/microsoft/vscode/issues/347325](https://github.com/microsoft/vscode/issues/347325)

## Summary

Keep open: the SDK reports an expected interruption as an execution error, and current VS Code forwards that error even while steering keeps the protocol turn active. The related reports do not establish a canonical duplicate for this false-failure symptom.

## Change summary

Steering a running Claude turn displays an execution failure although the agent continues processing the task.

## Best solution

Resolve the SDK's interruption-result classification and ensure the Claude host distinguishes expected steering preemption from genuine execution failures. Preserve continued response delivery and normal error reporting rather than suppressing execution errors indiscriminately.
