# Issue #330403 — Agents Window: Filter or collapse test files in the Changes multi-diff editor

[https://github.com/microsoft/vscode/issues/330403](https://github.com/microsoft/vscode/issues/330403)

## Summary

Keep open: current Changes editor supports manual collapse and restored view state, but not configurable pattern-based de-emphasis. This team-authored request remains a distinct capability gap; no qualifying canonical or open implementation PR was found.

## Change summary

Allow configurable filename/path patterns to hide or initially collapse low-priority files in the Agents Window Changes multi-diff editor, with counts and quick access to affected files.

## Best solution

Provide a reversible, presentation-only de-emphasis mechanism in the Sessions Changes editor, preserving all underlying changes and explicit user choices. Settle whether matching files remain visible as collapsed headers or are hidden behind a reveal control before implementation.
