# Issue #196491 — [wrapped lines] inline chat zone shows on the wrong line

[https://github.com/microsoft/vscode/issues/196491](https://github.com/microsoft/vscode/issues/196491)

## Summary

The current inline-chat opening path still anchors the widget at column 1 of the preceding model line, placing it inside that line when it wraps. Keep this open under its existing editor-api and inline-chat labels; the source confirms a remaining placement defect.

## Change summary

Opening inline chat on an empty line below a wrapped paragraph inserts the widget inside the preceding paragraph instead of immediately above the selected line.

## Best solution

Make inline chat respect the intended model-line boundary when opening below wrapped text, while preserving the editor view-zone API's ability to position zones at explicit columns.
