# Issue #196491 — [wrapped lines] inline chat zone shows on the wrong line

[https://github.com/microsoft/vscode/issues/196491](https://github.com/microsoft/vscode/issues/196491)

## Summary

The discussion confirms that inline chat's view zone can be inserted between wrapped visual segments instead of below the requested model line. The issue should remain open because it identifies a broader editor view-zone positioning defect and no fixing change is cited.

## Change summary

Opening inline chat on an empty line after a word-wrapped Markdown paragraph displays the chat zone one visual line too high.

## Best solution

Define and enforce view-zone placement at the boundary after all wrapped view lines belonging to `afterLineNumber`, then validate inline chat and other editor API consumers with word wrap enabled.
