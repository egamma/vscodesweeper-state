# Issue #196491 — [wrapped lines] inline chat zone shows on the wrong line

[https://github.com/microsoft/vscode/issues/196491](https://github.com/microsoft/vscode/issues/196491)

## Summary

The defect remains traceable on current main: inline chat anchors at column 1 of the preceding model line, which places its view zone between visual segments when that line wraps.

## Change summary

Inline chat opened on an empty line appears inside the preceding wrapped line instead of below it.

## Best solution

Make inline chat anchor after the preceding model line's final column while preserving intentional column-sensitive behavior for other view-zone consumers, likely in the inline chat session positioning logic.

- **rendering path:** src/vs/editor/contrib/zoneWidget/browser/zoneWidget.ts:428-438 passes that line and column to ViewZoneDelegate, while src/vs/editor/browser/viewParts/viewZones/viewZones.ts:158-194 converts an explicit `afterColumn` to its corresponding wrapped view line.
