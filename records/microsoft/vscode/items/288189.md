# Issue #288189 — Unclear what mode I'm in from command center chat

[https://github.com/microsoft/vscode/issues/288189](https://github.com/microsoft/vscode/issues/288189)

## Summary

Keep open: current source provides an unread-count tooltip and a New Chat menu entry, but the command-center message entry point still does not identify the effective chat mode. This team-authored request needs a design decision for the evolved entry point, not a partial-completion close.

## Change summary

Make command-center chat explain its effective mode, expose new-chat creation, and provide appropriate workspace or repository context for background and cloud sessions.

## Best solution

Make the command-center message flow communicate the mode and destination before submission, consistent with the main chat input. Retain the existing New Chat action and unread tooltip, and assess the empty-workspace repository-selection concern alongside the related cloud report.
