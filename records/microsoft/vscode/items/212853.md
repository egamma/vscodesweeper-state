# Issue #212853 — Can't click on links in streaming chat response

[https://github.com/microsoft/vscode/issues/212853](https://github.com/microsoft/vscode/issues/212853)

## Summary

Keep open: maintainers confirmed that streaming DOM replacement can swallow link clicks, and current rendering paths still replace interactive content. The newer incremental-rendering experiment does not establish a complete fix for this reopened report.

## Change summary

Keep file and method links clickable while a chat response continues streaming.

## Best solution

Make streaming updates preserve reliable activation of already-visible links in the chat markdown renderer, including updates that change inline-reference metadata. Preserve existing code-block reuse, navigation targets, and completed-response behavior.
