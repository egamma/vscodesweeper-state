# Issue #237421 — Type filters for outline according to VSCode settings.

[https://github.com/microsoft/vscode/issues/237421](https://github.com/microsoft/vscode/issues/237421)

## Summary

Valid feature request: the notebook outline has its own coarse filters (show code cells, show code cell symbols, show markdown headers only) but does not respect the per-symbol-kind type filters (`outline.showVariables`, `outline.showFunctions`, etc.) that the regular editor outline uses via `DocumentSymbolFilter`. No work has been done toward this on main.

## Change summary

Notebook outline should respect the standard `outline.show*` type filter settings (e.g. `outline.showVariables`, `outline.showFunctions`) so users can customize which symbol kinds appear.

## Best solution

Extend the notebook outline's `filterEntry` function (or add a tree filter) in `src/vs/workbench/contrib/notebook/browser/contrib/outline/notebookOutline.ts` to consult the `outline.show*` configuration keys for code cell symbol entries, similar to how `DocumentSymbolFilter` in `src/vs/workbench/contrib/codeEditor/browser/outline/documentSymbolsTree.ts` maps `SymbolKind` to config names. This is a targeted enhancement to an existing filtering pipeline.
