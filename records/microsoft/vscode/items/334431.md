# Issue #334431 — Flacky Test: Agent Host E2E — Copilot, cancelling a turn paused for input allows a replacement turn

[https://github.com/microsoft/vscode/issues/334431](https://github.com/microsoft/vscode/issues/334431)

## Summary

Keep open while the directly linked fix PR is reviewed and landed. Repeated CI failures and the current source confirm an abort-ordering race that lets a late terminal event from the cancelled turn interfere with its replacement.

## Change summary

Stabilize the Agent Host Copilot cancellation flow so a replacement turn completes after cancelling a turn paused for input.

## Best solution

Rebase as needed, review, and land https://github.com/microsoft/vscode/pull/335981, which preserves turn ownership across late abort notifications and strengthens deterministic regression coverage for both input and file-approval cancellation.
