# Issue #244343 — SCM - Don't include the commit message input and commit button in the scroll

[https://github.com/microsoft/vscode/issues/244343](https://github.com/microsoft/vscode/issues/244343)

## Summary

The requested sticky commit controls remain absent from current main, and a maintainer explicitly endorsed the improvement. A newer issue and open implementation PR cover the same work, but the stronger re-review duplicate rule prevents closing this older report against that younger issue.

## Change summary

Keep the SCM commit-message input and commit action visible while scrolling through changed files.

## Best solution

Complete the generalized tree support for sticky non-parent nodes being developed in https://github.com/microsoft/vscode/pull/274639, then use it to keep both the SCM input and action button visible without changing resource-tree scrolling.

## Evidence

- **maintainer intent:** A VS Code maintainer said this is something the team would like to do and identified missing tree-widget support for pinning nodes: https://github.com/microsoft/vscode/issues/244343#issuecomment-2747633204.
- **current source:** On current main, src/vs/workbench/contrib/scm/browser/scmViewPane.ts renders ISCMInput and ISCMActionButton as ordinary children of the WorkbenchCompressibleAsyncDataTree and supplies no sticky-scroll delegate that can keep those leaf nodes visible.
- **infrastructure gap:** src/vs/base/browser/ui/tree/abstractTree.ts currently limits IStickyScrollDelegate to constraining already-selected sticky nodes; it has no shouldStick-style API for nominating SCM input or action-button leaf nodes.
- **younger related issue:** https://github.com/microsoft/vscode/issues/274524 is open and requests the same observable behavior, but it was created on 2025-11-01, after this 2025-03-22 issue, so it cannot be the duplicate canonical for this re-reviewed item.
- **open implementation:** https://github.com/microsoft/vscode/pull/274639 is an open, unmerged attempt to add sticky non-parent tree nodes for SCM; its commits are not ancestors of main. The separate open prototype https://github.com/microsoft/vscode/pull/285943 also documents unresolved handling for the SCM input and action button.
