# Issue #342744 — Not clear what "Done" vs. "Next" do. Cognitive load

[https://github.com/microsoft/vscode/issues/342744](https://github.com/microsoft/vscode/issues/342744)

## Summary

Keep open as actionable comparison-setup polish: current main still presents generic Done and Next buttons without identifying the optional Judge step. The actions work as documented, but their consequences are not clear before activation.

## Change summary

Make finishing comparison setup distinguishable from continuing to optional Judge and Synthesizer configuration.

## Best solution

Make the completion action and optional review steps understandable before activation, while preserving the ability to compare attempts without a Judge. Settle whether destination-specific wording is sufficient or optional roles should be exposed on the initial setup screen.

- **Behavior:**

  > Before leaving the Attempts screen, users should understand which action saves their current comparison and which exposes optional evaluation configuration. They should not need to open another screen to discover what they would skip by finishing. Comparing without a Judge must remain supported, and finishing setup must not launch attempts.
- **Trace:**

  > The shared ModelPickerTabbedWidget._renderComparisonFooter renders fixed Done and Next labels from comparison state that exposes navigation booleans but no destination label. SessionComparisonModelSelection supplies the role-specific state and transitions: Attempts to Judge to Synthesizer, with finish() committing the draft at any valid stage. SESSION_COMPARISONS.md documents that behavior, and sessionsChatAccessibilityHelp.ts explains commitment separately. The uncertainty is the presentation of optional roles, not the functioning of the state transitions. Preserve draft cancellation, committed selections, optional judging, and the separate run action.
- **Open decisions:**
  - Should optional Judge and Synthesizer configuration remain a staged flow with explicit destination wording, or become discoverable and selectable on the initial setup screen?
