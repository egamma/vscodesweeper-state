# Issue #257923 — Managed hovers leak `hoverwidget` disposables

[https://github.com/microsoft/vscode/issues/257923](https://github.com/microsoft/vscode/issues/257923)

## Summary

The lifecycle gap remains on current main: managed HTML hover content has no disposal contract, and the wrapper can be abandoned when its displayed widget hides without releasing content-owned disposables. This team-authored debt should remain open.

## Change summary

Release resources owned by managed HTML hover content when that content is hidden, replaced, cancelled, or disposed.

## Best solution

Give managed HTML hover content an explicit, exactly-once disposal lifecycle tied to the displayed content, including replacement and asynchronous cancellation, while preserving existing string, Markdown, and native-hover behavior.
