[https://github.com/microsoft/vscode/issues/288635](https://github.com/microsoft/vscode/issues/288635)

## Summary

The alternate-delimiter gap remains in the current default sed approval rules. Keep this open for human security-sensitive review; the merged PR did not address the referenced concern.

## Change summary

Ensure sed substitutions using alternative delimiters cannot bypass approval checks for execution and file-writing flags.

## Best solution
