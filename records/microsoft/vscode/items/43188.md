# Issue #43188 — Allow to open multiple workspaces in the same window

[https://github.com/microsoft/vscode/issues/43188](https://github.com/microsoft/vscode/issues/43188)

## Summary

Keep open as the canonical request for multiple isolated workspaces in one VS Code window. Current main still supports one active workspace per workbench context, and the Backlog item has overwhelming community support.

## Change summary

Allow several independently configured workspaces to remain open and switchable within one VS Code window.

## Best solution

Introduce a workbench-level project/session container that can switch among independently configured workspaces while preserving each workspace's editors, terminals, debugging state, settings, and extension context. Consolidate newer UX proposals such as https://github.com/microsoft/vscode/issues/324309 into this canonical request.
