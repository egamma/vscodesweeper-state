# Issue #332515 — Need a command to copy all errors/warnings in the Problems panel

[https://github.com/microsoft/vscode/issues/332515](https://github.com/microsoft/vscode/issues/332515)

## Summary

Reasonable, small feature request: there's no single command to copy all Problems panel entries, only a per-selection `problems.action.copy` command bound to Ctrl+C — the reporter's workaround (select-all via triple Ctrl+A, then copy) reflects a real gap analogous to the Debug Console's `workbench.debug.action.copyAll`.

## Change summary

Add a command to copy all errors/warnings in the Problems panel at once, similar to the Debug Console's copyAll action.

## Best solution

Add a `problems.action.copyAll` (or similar) command in src/vs/workbench/contrib/markers/browser/markers.contribution.ts, analogous to workbench.debug.action.copyAll, that copies all markers in the current view regardless of selection.
