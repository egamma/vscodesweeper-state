# Issue #332515 — Need a command to copy all errors/warnings in the Problems panel

[https://github.com/microsoft/vscode/issues/332515](https://github.com/microsoft/vscode/issues/332515)

## Summary

The built-in copy commands remain selection-dependent and do not provide the requested single-action Copy All command. Keep this request in its existing community-review process; no verified open canonical owns the same work.

## Change summary

Provide a command that copies all Problems-panel errors and warnings without manually focusing the panel and selecting its entries.

## Best solution

A selection-independent Problems Copy All command would remove the repeated focus and selection steps while preserving existing selection-based copying. Leave acceptance to the Backlog Candidates process before starting implementation.

- **focus and selection dependency:** src/vs/workbench/contrib/markers/browser/markersView.ts:859–880 returns the focused selection or the focused element from getFocusedSelectedElements(). src/vs/workbench/browser/parts/views/viewPane.ts:865–880 runs ViewAction only against an active view.
