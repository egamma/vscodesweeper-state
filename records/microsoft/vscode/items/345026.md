- **Behavior:**

  > The report describes VoiceOver announcing 'selection replaced' when the first character is inserted without a selection. Ordinary insertion should provide accurate typing feedback without implying that existing text was replaced. Acceptance covers blank and populated documents, while preserving feedback for genuine replacements and subsequent navigation.
- **Trace:**

  > NativeEditContext receives textupdate events and synchronizes its text and selection through _updateEditContext. ScreenReaderSupport delegates the default accessibility representation to SimpleScreenReaderContent, which updates DOM text and selection while focused. Source inspection identifies these paths but cannot establish which native accessibility event produces the reported speech. Compare native EditContext with the textarea path before attributing the defect to VS Code or upstream. Preserve editing, selection, and screen-reader navigation semantics; do not assume the silent-echo investigation at https://github.com/microsoft/vscode/issues/338956 also resolves this distinct announcement.
