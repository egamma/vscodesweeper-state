# Issue #345026 — VoiceOver says "selection replaced" when the first character is typed in the editor

[https://github.com/microsoft/vscode/issues/345026](https://github.com/microsoft/vscode/issues/345026)

## Summary

Keep open for the editor accessibility investigation already requested by the maintainer. The first-character steps suffice to retest, but current VoiceOver behavior remains unverified; the related reports describe different symptoms, not a proven duplicate.

## Change summary

VoiceOver incorrectly announces a replaced selection when typing the first character with no editor selection.

## Best solution

Determine whether the incorrect announcement originates in editor screen-reader synchronization or the browser/VoiceOver bridge, then correct insertion feedback without suppressing genuine selection-replacement announcements.
