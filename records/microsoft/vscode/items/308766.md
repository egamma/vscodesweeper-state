[https://github.com/microsoft/vscode/issues/308766](https://github.com/microsoft/vscode/issues/308766)

## Summary

Keep open: current main still omits the MCP-Protocol-Version header on normal Streamable HTTP requests, matching the reporter's failure after successful initialization. The maintainer acknowledged this defect; the newer protocol-negotiation request does not supersede it.

## Change summary

Preserve the negotiated MCP protocol version in subsequent HTTP requests so servers requiring 2025-11-25 can complete tool discovery.

## Best solution

Make the Streamable HTTP transport consistently send the negotiated protocol version on subsequent requests, including notifications and tool discovery, while preserving existing authentication and legacy SSE behavior.
