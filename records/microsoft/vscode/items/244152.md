# Issue #244152 — Allow to use a custom Azure SDK speech model in voice support

[https://github.com/microsoft/vscode/issues/244152](https://github.com/microsoft/vscode/issues/244152)

## Summary

This remains an accepted, well-supported request: selecting a language does not enable a developer-trained Azure Custom Speech model. Preserve the backlog item and transfer it to the VS Code-team-owned Speech extension tracker rather than closing it.

## Change summary

Allow VS Code Speech to recognize speech using a developer-trained Azure Custom Speech model, particularly to improve Traditional Chinese recognition.

## Best solution

Support custom Azure recognition models in the Speech provider while preserving the existing default recognition experience. The Speech owners should establish how Azure-hosted custom models fit the current local-model implementation before committing to a configuration contract.
