# Issue #339761 — Agent Host session missing token usage

[https://github.com/microsoft/vscode/issues/339761](https://github.com/microsoft/vscode/issues/339761)

## Summary

The reporter accurately describes the new Agent Host session storage layout (session-state/<id>/events.jsonl, workspace.yaml), and tracing the code confirms the token-usage summary the Agent Host collects (ObservedTokenUsage / getTurnTokenUsage in agentHostTurnTracker.ts) is only fed into the internal telemetry reporter, not surfaced anywhere in the Sessions/Agents Window or chat UI for historical sessions — so this looks like a real UI gap rather than a misunderstanding, but it needs area-owner triage, not a close.

## Change summary

Token usage is no longer shown for chat/agent sessions that use the new Agent Host session-state storage (events.jsonl) instead of the legacy workspaceStorage chatSessions format.

## Best solution

Route to the Agent Host / chat team to decide where historical token usage should be surfaced for Agent Host sessions (e.g. in the Agents Window session list, or a per-session summary view) and wire the existing ObservedTokenUsage/getTurnTokenUsage data (currently telemetry-only in src/vs/platform/agentHost/node/agentHostTurnTracker.ts) into that UI, including a path to recompute/replay usage from events.jsonl for already-completed sessions.
