# Issue #326059 — "Render whitespace" doesn't show NBSP

[https://github.com/microsoft/vscode/issues/326059](https://github.com/microsoft/vscode/issues/326059)

## Summary

Verified duplicate of #13239, which requested the same NBSP rendering under `renderWhitespace` and was closed by a maintainer pointing to the Unicode highlighting feature (shipped in 1.63) as the established solution.

## Change summary

Request to render non-breaking spaces (and other Unicode whitespace) with visible glyphs when `editor.renderWhitespace` is enabled, similar to how regular spaces and tabs are rendered.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/13239 — the maintainer position (from @alexdima) is that the Unicode highlighting feature (`editor.unicodeHighlight.nonBasicASCII`) covers this use case. The `renderWhitespace` code path in `viewLineRenderer.ts` intentionally handles only `CharCode.Space` and `CharCode.Tab`; extending it to NBSP and other Unicode whitespace was declined in favor of the broader Unicode highlighting approach.
