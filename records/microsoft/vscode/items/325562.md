# Issue #325562 — Log Panel: Allow clicking `error` in AHP log to filter to errors

[https://github.com/microsoft/vscode/issues/325562](https://github.com/microsoft/vscode/issues/325562)

## Summary

Valid feature request from a team member: the AHP (Agent Host Process) debug log overview shows metric pills (e.g. "Errors") that are not clickable — the request is to make them interactive so clicking filters the logs view to that category. Not yet implemented on main.

## Change summary

Allow clicking metric pills (like 'Errors') in the AHP debug log overview to navigate to the logs view filtered to that category.

## Best solution

Make the metric cards in `ChatDebugOverviewView.renderMetricsContent()` clickable, so that clicking e.g. the 'Errors' card navigates to the Logs view with the filter state pre-set to show only errors. The overview view already has an `_onNavigate` emitter and knows how to compute error counts; the logs view already has `ChatDebugFilterState` with kind toggles and text filtering. Wire the card click to navigate to logs with an appropriate filter preset.
