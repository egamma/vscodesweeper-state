## Summary

This request for first-class Jupyter Notebook support has been comprehensively implemented. VS Code now has a full native notebook editor (src/vs/workbench/contrib/notebook/), an interactive window (src/vs/workbench/contrib/interactive/), and a finalized Notebook API supporting multiple language kernels — exactly what was asked for.

## Change summary

Request to make Jupyter Notebook interactive computing a first-class citizen in VS Code rather than relying on a volunteer-maintained extension.
