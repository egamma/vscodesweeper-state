# Issue #339047 — Won't Reconnect

[https://github.com/microsoft/vscode/issues/339047](https://github.com/microsoft/vscode/issues/339047)

## Summary

Reported as a generic Remote-SSH reconnect failure, but the one diagnostic trace provided points at an interaction between Remote-SSH and the Dev Containers extension (ENOPRO error trying to stat a vscode-remote:// resource via the Dev Containers extension before the SSH filesystem provider is ready). Both extensions belong to the Remote Development family, which is moved rather than closed per VS Code team practice.

## Change summary

After reconnecting over Remote-SSH, VS Code fails to recreate/access its remote working directories; a commenter traced it to the Dev Containers extension querying a vscode-remote:// resource before the SSH file system provider is registered.

## Best solution

This should be moved to microsoft/vscode-remote-release, where Remote-SSH and Dev Containers issues are tracked together; the maintainers there can investigate the race between SSH reconnect and Dev Containers' devcontainer.json lookup.
