# Issue #233618 — VSCode trying to update WSL on launch for literally no reason

[https://github.com/microsoft/vscode/issues/233618](https://github.com/microsoft/vscode/issues/233618)

## Summary

Keep this as the canonical report for unwanted WSL installation/update prompts during automatic discovery. The reporter confirmed that the earlier fix was insufficient, and a maintainer has since consolidated a detailed, extension-independent reproduction here.

## Change summary

Automatic WSL discovery opens an unsolicited installation or update console on Windows systems without a usable WSL installation.

## Best solution

Background discovery should not present interactive WSL installation/update prompts, while preserving discovery of installed distributions. Diagnose the terminal-profile path and the reported Agents Window variant before considering this resolved.
