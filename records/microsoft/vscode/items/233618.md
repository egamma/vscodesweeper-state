# Issue #233618 — VSCode trying to update WSL on launch for literally no reason

[https://github.com/microsoft/vscode/issues/233618](https://github.com/microsoft/vscode/issues/233618)

## Summary

Keep open as the existing canonical report for unwanted WSL installation/update prompts. The reporter confirmed the attempted fix was insufficient, current source retains the implicated discovery command, and later reports identify additional triggers outside terminal-profile discovery.

## Change summary

Prevent automatic WSL discovery from opening installation or update prompts when WSL is absent or has been uninstalled.

## Best solution

Make background WSL detection noninteractive across terminal discovery and Agents Window startup while preserving discovery of installed distributions. Correlate the remaining process-launch paths on an affected Windows machine before treating a terminal-only change as a complete fix.
