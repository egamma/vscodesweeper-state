# Issue #174295 — Multiple Import Organizers results in corrupted code

[https://github.com/microsoft/vscode/issues/174295](https://github.com/microsoft/vscode/issues/174295)

## Summary

Still reproduces on main: when multiple code action providers register for the same kind (e.g. source.organizeImports), all providers receive the same document version and their edits are applied against stale state, corrupting the file. No fix has landed — PR #306045 was closed without merging.

## Change summary

Multiple code action providers for the same kind (e.g. organizeImports) on save all receive the same document state, causing edits to conflict and corrupt code.

## Best solution

In `applyOnSaveActions` in `src/vs/workbench/contrib/codeEditor/browser/saveParticipants.ts`, after applying each action from `actionsToRun.validActions`, re-query remaining providers against the updated document state rather than applying all pre-fetched edits. Alternatively, provide UI to select which provider to use for a given code action kind (like the formatter picker). The `help wanted` label is appropriate — this is a well-understood, impactful bug with a clear repro.
