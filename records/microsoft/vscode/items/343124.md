# Issue #343124 — all ai powershell interactions report an error in constrained language mode

[https://github.com/microsoft/vscode/issues/343124](https://github.com/microsoft/vscode/issues/343124)

## Summary

Keep open: the report supplies concrete commands and a Windows constrained-language trigger for successful commands being reported as failures. Current main still delegates Windows shell execution to the Copilot runtime; the supplied steps suffice to retest, but source inspection alone cannot confirm this environment-dependent failure or establish a fix.

## Change summary

Copilot PowerShell execution reports exit code 1 after successful commands because its completion wrapper invokes SetShouldExit in constrained language mode.

## Best solution

Ensure Copilot's Windows shell completion handling preserves successful command results under enforced constrained language mode without weakening the language restrictions. First reproduce through the bundled runtime and establish whether the correction belongs in its shell wrapper or VS Code's integration.
