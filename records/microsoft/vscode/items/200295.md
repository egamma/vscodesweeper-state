## Summary

Still reproduces on main: the notebook find widget has no registered toggle actions for case sensitivity, whole word, or regex — keyboard shortcuts (Alt+C, Alt+W, Alt+R) do nothing because no notebook-specific implementations exist. An open PR (#307242) is attempting to fix this.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/307242 (or an equivalent) that adds notebook-specific toggle actions for case sensitivity, whole word, and regex in the find widget, wired to the notebook's FindReplaceState.
