# Issue #346160 — Agent Merge: Authorized tools cannot edit PR metadata

[https://github.com/microsoft/vscode/issues/346160](https://github.com/microsoft/vscode/issues/346160)

## Summary

Agent Merge currently lacks an authorized operation for editing PR titles and descriptions, so metadata-based CI failures remain actionable work. Keep this open as a capability request; the reported stop follows the existing tool restrictions.

## Change summary

Allow Agent Merge to repair PR titles and descriptions when their formatting causes CI checks to fail.

## Best solution

Decide whether CI-repair authorization should include PR title and description changes, then provide a narrowly scoped metadata-editing capability if approved. Preserve the existing restrictions against alternate GitHub tools and CLI access.
