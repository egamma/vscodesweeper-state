# Issue #138664 — Setting `files.associations` is not observed/respected

[https://github.com/microsoft/vscode/issues/138664](https://github.com/microsoft/vscode/issues/138664)

## Summary

Keep open: an extensionless file explicitly associated with plaintext can still enter automatic language detection on current main. This issue already owns the matching report; the other linked closures do not establish a fix.

## Change summary

Respect an explicit plaintext file association instead of replacing it with an automatically detected language.

## Best solution

Preserve configured plaintext associations for extensionless files while retaining automatic detection for files that only fall back to plaintext. Keep this issue as the canonical report for that precedence gap.
