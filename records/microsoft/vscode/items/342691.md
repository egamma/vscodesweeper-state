# Issue #342691 — Shell init scripts for Copilot harness sessions don't work in remote windows

[https://github.com/microsoft/vscode/issues/342691](https://github.com/microsoft/vscode/issues/342691)

## Summary

Keep open as a request to extend shell initialization to remote Copilot harness sessions. Current source, configuration text, and tests explicitly restrict this feature to local windows; that explains the behavior but does not satisfy the requested remote capability.

## Change summary

Allow Copilot harness shell commands on remote hosts to load the remote user's shell initialization when the setting is enabled.

## Best solution

Provide opt-in shell initialization using the executing host's platform and environment, preserving existing local behavior and disabled-setting semantics. The Agent Host/Copilot area should decide the supported remote initialization contract before implementation.
