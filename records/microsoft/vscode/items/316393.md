# Issue #316393 — Chat renaming not persisting

[https://github.com/microsoft/vscode/issues/316393](https://github.com/microsoft/vscode/issues/316393)

## Summary

Still reproduces on main: renaming a chat session from the session list does not persist or update the UI because ChatSessionStore.setSessionTitle() never flushes the index to disk and LocalAgentsSessionsController has no listener for title changes on sessions not currently loaded as models.

## Change summary

Renaming a chat session via the session list context menu does not persist the new title and the UI does not update until manual refresh; the title may also revert when the session is opened.

## Best solution

Fix two gaps: (1) ChatSessionStore.setSessionTitle() should call flushIndex() after updating the in-memory entry so the title persists to disk; (2) fire an event from ChatService.setChatSessionTitle() that LocalAgentsSessionsController listens to, so the session list UI updates immediately for sessions whose model is not loaded. An attempted fix existed (commit e2f1c08d034) but was never merged. Issue https://github.com/microsoft/vscode/issues/316994 is a duplicate of this one.
