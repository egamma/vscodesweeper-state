# Issue #13441 — Multiple extensions registering the 'type' command

[https://github.com/microsoft/vscode/issues/13441](https://github.com/microsoft/vscode/issues/13441)

## Summary

The extension API still cannot support multiple cooperating `type` handlers, and the request remains necessary. It is an established Backlog feature request with 55 community upvotes and should stay open.

## Change summary

Allow extensions to temporarily intercept typing and then delegate it to another extension's handler.

## Best solution

Design a backward-compatible, composable typing-interception API with explicit ordering, continuation, and disposal semantics, while retaining `default:type` for existing extensions.
