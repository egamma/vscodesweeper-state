# Issue #335834 — Inconsistent inheritance

[https://github.com/microsoft/vscode/issues/335834](https://github.com/microsoft/vscode/issues/335834)

## Summary

Keep open for a decision on the Agents diff-editor inheritance contract. Current source deliberately inherits from editor.wordWrap, matching the original specification, but this team-authored follow-up questions whether it should instead respect diffEditor.wordWrap.

## Change summary

Make sessions.diffEditor.wordWrap inheritance respect the corresponding diffEditor.wordWrap preference rather than bypassing it.

## Best solution

Resolve whether Agents diff editors should inherit through diffEditor.wordWrap, with editor.wordWrap as its fallback, and keep the setting description, effective wrapping, and Word Wrap menu state consistent with that decision.

## Evidence

- **Original specification:** https://github.com/microsoft/vscode/issues/335228 is closed and explicitly specifies that both sessions.editor.wordWrap and sessions.diffEditor.wordWrap default to inherit, following editor.wordWrap. The current behavior therefore follows the recorded specification rather than clearly violating it.
- **Current inheritance path:** src/vs/sessions/contrib/editor/browser/diffEditorOptionsService.ts observes the raw sessions.diffEditor.wordWrap value. SessionsDiffEditorLayoutContribution.applyDiffEditorLayout in src/vs/sessions/contrib/editor/browser/diffEditor.sessions.contribution.ts passes that value directly as diffWordWrap, including inherit; its registered enum description explicitly names editor.wordWrap.
- **Underlying diff-editor behavior:** src/vs/editor/browser/widget/diffEditor/components/diffEditorEditors.ts:141–174 assigns diffWordWrap to the subeditors' wordWrapOverride1. src/vs/editor/common/config/editorConfigurationSchema.ts:257–265 separately defines diffEditor.wordWrap and documents its own inherit value as following editor.wordWrap. Passing the Agents inherit value directly bypasses the separately configured diffEditor.wordWrap preference.
- **Menu semantics:** src/vs/sessions/contrib/changes/browser/changesViewActions.ts:247–254 and 313–327 calculate the checked state and toggle direction using editor.wordWrap for inherited Agents settings. Any inheritance-contract change needs to account for these user-visible surfaces as well.
