# Issue #336866 — Allow configuring the default Changes view changeset

[https://github.com/microsoft/vscode/issues/336866](https://github.com/microsoft/vscode/issues/336866)

## Summary

Keep open: current main remembers changeset selections independently per chat, but still lacks a configurable default for newly visited sessions or chats. The team-authored request remains distinct from related branch-diff and session-count issues.

## Change summary

Allow users to configure the initial Changes view changeset across agent sessions, falling back to the provider default when unavailable.

## Best solution

Provide a syncable Changes view default preference in the Sessions-owned configuration and selection layer, with provider-default fallback. Preserve deliberate manual selections and treat large-diff performance protection as separate work rather than assuming a preference setting fixes it.
