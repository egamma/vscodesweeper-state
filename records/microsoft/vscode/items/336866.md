# Issue #336866 — Allow configuring the default Changes view changeset

[https://github.com/microsoft/vscode/issues/336866](https://github.com/microsoft/vscode/issues/336866)

## Summary

Team-authored (protected from judgment closes) and freshly filed, well-scoped feature request; checked the source and confirmed no default-changeset setting or persistence exists today, so this is a genuine gap worth keeping open.

## Change summary

Add a setting to control which changeset (branch/uncommitted/session/last-turn) the Agents Changes view defaults to, since the selection currently resets on session switch.

## Best solution

Add an `agents.changes.defaultChangeset` (or similar) setting honored by ChangesViewPane/changesViewService when initializing or switching sessions, with graceful fallback to the provider default when the chosen changeset is unavailable — a maintainer should decide setting name/values and whether to also support 'remember last selection' as an alternative.
