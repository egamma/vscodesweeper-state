# Issue #336866 — Allow configuring the default Changes view changeset

[https://github.com/microsoft/vscode/issues/336866](https://github.com/microsoft/vscode/issues/336866)

## Summary

Team-authored feature request for a configurable default changeset in the Agents Changes view; no such setting exists on main and no maintainer has committed to it yet (the reporter is still asking @osortega), so this stays open per the team-authored protection rules.

## Change summary

Add a user setting to control which changeset (branch/uncommitted/session/lastTurn) the Agents Changes view shows by default, since the current selection resets whenever the active session changes.

## Best solution

Add a `agents.changes.*` (or similarly named) setting consulted by `findDefaultChangeset` in src/vs/sessions/contrib/changes/common/changesViewService.ts, falling back to the provider's current default when the configured changeset is unavailable — pending a maintainer's confirmation this is the direction they want.
