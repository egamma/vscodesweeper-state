# Issue #337762 — Copilot Chat repeatedly fails with attachment 404 after browser screenshot tool completes

[https://github.com/microsoft/vscode/issues/337762](https://github.com/microsoft/vscode/issues/337762)

## Summary

Multiple independent reporters (including a contributor) confirmed the failure and traced it to `github.copilot.chat.responsesApi.promptCacheBreakpoint.enabled` defaulting to true in 1.139.0; that default was already reverted to false in this repo (confirmed in source), and a maintainer/CAPI-side contact just reported a server-side fix with clean telemetry — but they explicitly deferred the close decision, so this stays open pending that confirmation.

## Change summary

Copilot Chat fails with an image-attachment 404/400 right after a browser screenshot or view_image tool call succeeds.

## Best solution

Once the CAPI-side fix (github/copilot-api#38931) is confirmed stable and the responsesApi.promptCacheBreakpoint.enabled default stays false (or is safely re-enabled), close as completed citing both the settings mitigation and the upstream tracking issue.
