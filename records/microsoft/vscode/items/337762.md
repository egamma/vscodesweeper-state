# Issue #337762 — Copilot Chat repeatedly fails with attachment 404 after browser screenshot tool completes

[https://github.com/microsoft/vscode/issues/337762](https://github.com/microsoft/vscode/issues/337762)

## Summary

Multiple independent reproductions (reporter, another user on macOS, and a Copilot Chat contributor with a local harness) confirm a real defect in image/attachment handoff after browser screenshot or view_image tool calls; the underlying cause looks tied to CAPI-side attachment expiry rather than anything fixable with a bounded local trace, so this should stay open pending further backend-side diagnosis.

## Change summary

Copilot Chat fails with an attachment/resource 404 immediately after the screenshot_page (and view_image) tool successfully returns an image result.

## Best solution

Keep open for the Copilot Chat team to trace the image-attachment lifecycle between tool result and the next model request (CAPI 400/upstream 404 per comment evidence); the fix likely lives in how image tool-results are referenced/persisted across turns, not in the browser tool itself (label already correctly narrowed by a contributor removing `browser-integration`).
