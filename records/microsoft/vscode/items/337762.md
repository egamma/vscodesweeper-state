# Issue #337762 — Copilot Chat repeatedly fails with attachment 404 after browser screenshot tool completes

[https://github.com/microsoft/vscode/issues/337762](https://github.com/microsoft/vscode/issues/337762)

## Summary

Actively being investigated by a contributor (jruales), who just narrowed the trigger to the `github.copilot.chat.responsesApi.promptCacheBreakpoint.enabled` setting combined with certain models. No fix exists yet; this should stay open for continued investigation.

## Change summary

After the browser screenshot (or view_image) tool successfully returns an image, the next Copilot Chat request fails with an attachment/resource 404 instead of continuing.

## Best solution

Root-cause the image-attachment handoff in the Responses API path (extensions/copilot/src/platform/endpoint/node/responsesApi.ts and networking.ts) specifically when prompt cache breakpoints are enabled, since a contributor has already isolated the trigger to that setting plus model combination.
