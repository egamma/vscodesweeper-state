# Issue #210371 — minimap markers include `-->` in the end of the display

[https://github.com/microsoft/vscode/issues/210371](https://github.com/microsoft/vscode/issues/210371)

## Summary

Still reproduces on main: the default `markSectionHeaderRegex` captures trailing comment delimiters (`-->`, `*/`) into the `label` group, and `collectMarkHeaders` uses the label without stripping them. An open PR (#308930) proposes a fix.

## Change summary

Minimap MARK section headers display trailing comment closing delimiters (e.g. `-->`, `*/`) as part of the label text.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/308930, which strips trailing `-->` and `*/` from the captured label. Alternatively, as aeschli suggested, the `blockComment` language configuration could be used to determine what to strip, which would be more robust for arbitrary comment syntaxes.
