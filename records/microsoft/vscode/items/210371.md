[https://github.com/microsoft/vscode/issues/210371](https://github.com/microsoft/vscode/issues/210371)

## Summary

The minimap section-header parser includes trailing block-comment delimiters in marker labels across Markdown, C++, and CFML. Keep this open because an open PR already provides the human-owned fix attempt and must be reviewed rather than competing with an agent implementation.

## Change summary

Minimap MARK section headers should display only their label text, excluding closing block-comment delimiters such as `-->`, `*/`, and `--->`.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/308930 if its language-aware stripping handles the confirmed Markdown, C++, and CFML cases without changing ordinary folding-marker labels.
