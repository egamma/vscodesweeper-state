# Issue #329709 — Drag Files from VS Code File Explorer to External Applications

[https://github.com/microsoft/vscode/issues/329709](https://github.com/microsoft/vscode/issues/329709)

## Summary

The core ask — dragging a file from the Explorer out to another application to create a copy on disk — is already implemented on main via Chromium's DownloadURL drag data type, shared between editor tabs and the Explorer tree, so this is best closed as already-covered rather than a new feature.

## Change summary

Allow dragging a file from VS Code's Explorer tree out to external applications (browser, OS file manager, desktop, chat/email clients) so the OS receives the actual file, copying rather than moving it.

## Best solution

Keep the existing DownloadURL-based drag-out support (src/vs/workbench/browser/dnd.ts, fillEditorsDragData) as the answer to the central ask; if a real gap remains it's multi-file drag-out (today limited to the first single file) or a Linux/GTK-specific limitation — a narrower follow-up scoped to that would be reasonable, but the base capability described in the report already exists.
