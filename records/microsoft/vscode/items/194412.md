# Issue #194412 — Settings editor width overflows space in 2x2 grid

[https://github.com/microsoft/vscode/issues/194412](https://github.com/microsoft/vscode/issues/194412)

## Summary

The overflow remains traceable on current main, and open PR https://github.com/microsoft/vscode/pull/307246 directly addresses the two minimum-width constraints causing it. Keep the issue open while that human-owned fix is reviewed.

## Change summary

Prevent the Settings editor's inner split view from overflowing its editor-grid cell in a small 2x2 layout.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/307246 after verifying that the Settings tree can shrink within a narrow grid cell without changing the existing threshold for hiding the table of contents.
