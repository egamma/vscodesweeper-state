# Issue #335782 — New chat starts an independent session with unrelated work

[https://github.com/microsoft/vscode/issues/335782](https://github.com/microsoft/vscode/issues/335782)

## Summary

Team-authored report of session-isolation leakage in the agent host's independent-session tool, and the discussion is still actively working out the expected behavior (amunger's clarifying question, vritant24's follow-up about adversarial-review isolation) — this stays open regardless per the team-authored protection, and the thread itself shows it isn't settled yet.

## Change summary

Creating a new 'independent' chat session sometimes pulls in unrelated context/title from another, unrelated session instead of staying scoped to the current chat's request.

## Best solution

A maintainer needs to decide the intended isolation contract for `relationship: independent` sessions in sessionServerTools.ts (e.g., src/vs/platform/agentHost/node/shared/sessionServerTools.ts) — whether the model should be prevented from referencing/exploring other sessions when creating an independent one, or whether it should just ask for clarification when the request is underspecified — before any code change is scoped.
