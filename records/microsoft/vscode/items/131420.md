# Issue #131420 — Add context key for when comments are visible

[https://github.com/microsoft/vscode/issues/131420](https://github.com/microsoft/vscode/issues/131420)

## Summary

The requested viewport-aware context key has not been implemented. The existing `commentWidgetVisible` key tracks whether any comment widget is expanded in the editor (globally), but not whether expanded comments are visible in the current viewport — the gap remains.

## Change summary

Add a context key that is true only when expanded comment threads are visible in the editor viewport, enabling keybindings like Escape to collapse only visible comments.

## Best solution

Add a new context key (e.g. `commentWidgetVisibleInViewport`) in `src/vs/workbench/contrib/comments/browser/commentsController.ts` that updates on scroll and widget expand/collapse, checking intersection of expanded comment thread ranges against `editor.getVisibleRanges()`. The existing `collapseVisibleComments` method already performs this viewport intersection check — the new key would mirror that logic reactively.
