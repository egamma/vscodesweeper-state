# Issue #315288 — Editor Scroll Lock Button

[https://github.com/microsoft/vscode/issues/315288](https://github.com/microsoft/vscode/issues/315288)

## Summary

A real discoverability gap remains: current main provides the command and a clickable status-bar entry only after locked scrolling is enabled, so there is no GUI control for activating it. Keep this open under discussion because a persistent affordance would require a UI-placement decision and the request currently has no community demand.

## Change summary

Provide a GUI control that can both enable and disable locked scrolling across editors without using the Command Palette or a keybinding.

## Best solution

Decide whether synchronized scrolling merits a persistent but unobtrusive affordance, such as an editor-layout or status-bar control, while retaining the existing command and active-state indication.
