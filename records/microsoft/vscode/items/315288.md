# Issue #315288 — Editor Scroll Lock Button

[https://github.com/microsoft/vscode/issues/315288](https://github.com/microsoft/vscode/issues/315288)

## Summary

Valid feature request: the locked scrolling toggle is currently only accessible via Command Palette or a user-assigned keybinding (plus a status bar item that only appears when active). The user wants a persistent, always-visible GUI button to toggle it. No existing setting, toolbar contribution, or menu entry covers this.

## Change summary

Add a persistent GUI button (e.g. in the editor title toolbar or a view action) to toggle locked scrolling across editors, instead of requiring the Command Palette.

## Best solution

Add the `workbench.action.toggleLockedScrolling` command to an appropriate menu contribution (e.g. the editor title area or the View menu) so it's accessible as a clickable button without the Command Palette. The implementation lives in `src/vs/workbench/contrib/scrollLocking/browser/scrollLocking.ts` — a menu registration with a toggled-state icon would be the natural approach. Alternatively, an always-visible status bar entry (not just when active) could serve the same purpose.
