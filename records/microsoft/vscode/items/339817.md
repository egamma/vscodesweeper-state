# Issue #339817 — Bundled /create-* customization slash commands are not registered in Copilot SDK harness sessions

[https://github.com/microsoft/vscode/issues/339817](https://github.com/microsoft/vscode/issues/339817)

## Summary

Well-diagnosed, real gap: current main's extensions/copilot/package.json explicitly restricts the bundled create-prompt/instructions/skill/agent/hook and init skills to `sessionTypes: ["local"]`, which — per matchesSessionType — excludes Copilot SDK harness (Agent Host) sessions, exactly matching the reported absence; keeping open as a bug worth fixing, not closing.

## Change summary

The built-in /create-prompt, /create-instructions, /create-skill, /create-agent, /create-hook, and /init slash commands don't show up as skills in Copilot SDK harness (Agent Host) sessions, only in regular Copilot Chat.

## Best solution

Extend the `sessionTypes` contribution for these skills (and/or wire the already-defined but unused `SessionType.AgentHostCopilot` constant into the harness's session-type resolution) so the bundled create-* and init skills are offered in Agent Host sessions the same way they are in regular Copilot Chat; also revisit whether `agent-customization`'s self-hiding rationale still holds for harness sessions.
