# Issue #327592 — How do you show LLM thinking when using VS Code + Ollama?

[https://github.com/microsoft/vscode/issues/327592](https://github.com/microsoft/vscode/issues/327592)

## Summary

Legitimate, unaddressed feature request: Ollama's BYOK provider doesn't surface `<think>` reasoning as VS Code's thinking UI does for hosted models. It's only 11 days old and still inside the 60-day community-upvote window (0 upvotes so far), so this stays open rather than closing for being quiet.

## Change summary

Ollama (and local llama.cpp-style) BYOK models don't get their `<think>` reasoning content rendered as a distinct thinking block the way Anthropic/OpenAI hosted models do.

## Best solution

In extensions/copilot/src/extension/byok/vscode-node/ollamaProvider.ts, derive a per-model `thinking` capability (from `/api/tags` metadata or a template-derived reasoning tag) instead of relying solely on the static `knownModels` table in resolveModelInfo, and stream parsed `<think>...</think>` content as `LanguageModelThinkingPart` (already unioned into `LMResponsePart` in byokProvider.ts) rather than dropping it into the final text.
