# Issue #327592 — How do you show LLM thinking when using VS Code + Ollama?

[https://github.com/microsoft/vscode/issues/327592](https://github.com/microsoft/vscode/issues/327592)

## Summary

This is a support question about how to display thinking content from Ollama in VS Code's chat. VS Code already has full thinking/reasoning infrastructure (IChatThinkingPart, ChatThinkingContentPart, LanguageModelThinkingPart); whether thinking tokens appear depends on the third-party Ollama extension surfacing them via the Language Model API.

## Change summary

User wants VS Code to display thinking/reasoning blocks from Ollama models in the chat panel.

## Best solution

VS Code's chat infrastructure already supports displaying thinking content via LanguageModelThinkingPart. The Ollama extension (third-party, by `ollama`) is responsible for emitting thinking parts through the Language Model API. The user should file a feature request on the Ollama extension's repository to support the LanguageModelThinkingPart API for models that produce <think> blocks.
