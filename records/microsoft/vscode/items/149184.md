# Issue #149184 — Allow drag-and-dropping text across panels of split editor (and possibly even to other applications)

[https://github.com/microsoft/vscode/issues/149184](https://github.com/microsoft/vscode/issues/149184)

## Summary

A real capability gap remains on current main: selected-text dragging is scoped to one editor instance, so cross-pane and outbound drops are unsupported. Keep this open for design discussion in the existing editor drag-and-drop area.

## Change summary

Allow selected text to be dragged between split editor panes and, optionally, into other applications.

## Best solution

Coordinate drag data and move semantics across editor instances, ideally using a native plain-text drag source that also supports other applications, while preserving current same-editor behavior.

## Evidence

- **native drop support:** src/vs/editor/browser/widget/codeEditor/codeEditorWidget.ts registers a native DragAndDropObserver for incoming data, and src/vs/editor/contrib/dropOrPasteInto/browser/defaultProviders.ts accepts text/plain, but the selection-drag path does not create a native dataTransfer source for cross-editor or outbound dragging.
