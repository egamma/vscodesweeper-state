Real bug in the Agent Host's pinned Claude Agent SDK version, but current main already pins a newer SDK (0.3.281) than what the reporter hit (0.3.258) — this looks like a routine release-lag issue that's likely already resolved upstream, not something to close yet without a confirmed diff.

- **call site:** src/vs/platform/agentHost/node/claude/claudeAgent.ts calls `query.supportedModels()` on the live SDK query object to populate the model picker — so the picker can list a model the pinned SDK/CLI build doesn't actually support at runtime, matching the reporter's 'unrecognized_model' + 'version 2.1.280 or newer is required' error.
