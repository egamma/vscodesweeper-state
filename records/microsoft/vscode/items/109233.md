# Issue #109233 — Markdown hovers in `IconLabel` shouldn't preclude decoration hovers

[https://github.com/microsoft/vscode/issues/109233](https://github.com/microsoft/vscode/issues/109233)

## Summary

This is the canonical issue for improving how markdown hovers in IconLabel interact with decoration hovers. Issue #257414 was closed as a duplicate of this one by the same author. The debt remains: decoration tooltips are concatenated as plain text into markdown strings rather than being composable hover sections.

## Change summary

When an IconLabel has a markdown tooltip, file decoration tooltips are string-concatenated into it rather than rendered as separate composable hover sections.

## Best solution

Refactor the hover composition in `src/vs/workbench/browser/labels.ts` (lines ~694–700) and `src/vs/base/browser/ui/iconLabel/iconLabel.ts` so that decoration hovers can coexist with markdown label hovers — likely by supporting composite/multi-part hover content rather than plain string concatenation. The related API request for markdown decoration tooltips (https://github.com/microsoft/vscode/issues/257414) was closed as a duplicate of this issue, so any solution here should also unblock that scenario.
