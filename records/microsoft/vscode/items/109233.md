# Issue #109233 — Markdown hovers in `IconLabel` shouldn't preclude decoration hovers

[https://github.com/microsoft/vscode/issues/109233](https://github.com/microsoft/vscode/issues/109233)

## Summary

Keep this maintainer-authored cleanup open: current source still drops decoration tooltip content when the label hover contains an IMarkdownString or an asynchronous markdown provider. An intervening change covers string-valued tooltips only, and the newer related issue was explicitly closed into this one.

## Change summary

Allow rich label hovers and file-decoration tooltip content to appear together instead of suppressing the decoration information.

## Best solution

Complete tooltip composition in ResourceLabelWidget so supported rich and asynchronous label hovers retain decoration information without losing markdown rendering options. Preserve existing plain-text behavior; expanding the public FileDecoration tooltip API is a separate scope decision.
