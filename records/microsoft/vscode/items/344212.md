# Issue #344212 — Agents window becomes unresponsive when selecting a zero-change session with a large branch diff

[https://github.com/microsoft/vscode/issues/344212](https://github.com/microsoft/vscode/issues/344212)

## Summary

This is another report of the Agents-window freeze already tracked by the open issue https://github.com/microsoft/vscode/issues/337420: zero session changes, a stale branch baseline, and excessive diff-resource loading. Consolidate there while preserving the Windows session-selection trigger; the requested default-changeset control is separately tracked.

## Change summary

Selecting a zero-change conversation can make the Agents window unresponsive while a roughly 20,000-file branch comparison loads.

## Best solution

Resolve the large-comparison responsiveness problem under https://github.com/microsoft/vscode/issues/337420, retaining this report's Windows evidence and session-selection trigger. Coordinate lazy model loading with https://github.com/microsoft/vscode/issues/240181 and configurable changeset defaults with https://github.com/microsoft/vscode/issues/336866.
