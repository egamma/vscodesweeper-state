# Issue #337896 — CLI spawns itself in an unbounded chain when more than one copy is on PATH

[https://github.com/microsoft/vscode/issues/337896](https://github.com/microsoft/vscode/issues/337896)

## Summary

The reported recursive launch remains source-reproducible on current main: discovery accepts another CLI copy, then the persisted entrypoint bypasses the self-executable check on every child launch. Keep this open for a bounded CLI fix that prevents process and thread exhaustion.

## Change summary

Prevent legacy editor commands from recursively launching standalone CLI copies discovered through PATH or cached entrypoints.

## Best solution

CLI-to-editor delegation should terminate promptly with an explicit nonzero error when resolution leads back into the CLI, including through cached paths or wrappers. Preserve legitimate desktop launcher delegation and the existing missing-installation behavior.
