# Issue #308847 — Windows-style path separators/backslashes used in chat pane when connected to Linux server

[https://github.com/microsoft/vscode/issues/308847](https://github.com/microsoft/vscode/issues/308847)

## Summary

Real bug, still present on main: when a Windows client displays chat file-path buttons for remote Linux URIs, the tooltip and possibly the navigation use local (Windows) path separators instead of the remote's. No fix has landed.

## Change summary

Chat file-path buttons render Windows-style backslashes in tooltips and fail to navigate when connected to a Linux remote.

## Best solution

The inline anchor widget in `chatInlineAnchorWidget.ts` calls `labelService.getUriLabel(location.uri, { relative: true })` without specifying `separator: '/'`. For remote URIs (vscode-remote scheme), the label service may fall back to the local platform separator. The fix should either pass `separator: '/'` for remote URIs, or ensure the remote formatter is always registered with the posix separator for remote resources. Additionally, the click handler should use the URI as-is rather than reconstructing from a potentially-corrupted fsPath.
