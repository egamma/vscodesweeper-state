## Summary

Team-authored perf bug about GitHub.copilot-chat's ~8.8s activation blocking dependent extensions via extensionDependencies. No fix commit found on main; the activation dependency chain in extensionDescriptionRegistry.ts still resolves dependencies synchronously before activating dependents. Keeping open.

## Change summary

GitHub.copilot-chat's slow activation (~8.8s) blocks extensions that declare it as an extensionDependency, causing ~11s delays.

## Best solution

Reduce Copilot Chat's activation time or explore whether the extension host can activate dependents sooner (e.g. after the dependency's `activate()` call returns but before `Finish Activate` completes). The blocking path runs through `extensionDescriptionRegistry.ts` (dependency graph) and the extension host manager's activation sequencing.
