# Issue #319159 — Incorrect padding on attached folder in chat input (VS Code Agents app)

[https://github.com/microsoft/vscode/issues/319159](https://github.com/microsoft/vscode/issues/319159)

## Summary

The attachment pill CSS in the Agents window chat input has not been specifically fixed for folder items — the padding rules are unchanged between the reporter's version and current main. The broad 'rehaul chat input padding and spacing' commit (0cd1884c6a8) adjusted toolbar-level padding but did not touch the attachment pill rules. Keeping open as a valid visual polish item.

## Change summary

Attached folder items in the Agents window chat input render with inconsistent padding compared to other attached items.

## Best solution

Adjust the `.sessions-chat-attachment-pill` and its `.monaco-icon-label` padding/gap rules in `src/vs/sessions/contrib/chat/browser/media/chatInput.css` so folder attachments (which use `monaco-icon-label` with `FileKind.FOLDER`) have visually consistent spacing with file and image attachment pills.
