Implemented after the issue was reopened: the stable `InputBox.valueSelection` API now provides the requested selection control, so this can be closed as completed.

## Change summary

Expose `valueSelection` on the flexible `window.createInputBox()` API as well as on `window.showInputBox()` options.

## Best solution
