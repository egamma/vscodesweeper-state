# Issue #331814 — Large pet cannot be grabbed without instant death

[https://github.com/microsoft/vscode/issues/331814](https://github.com/microsoft/vscode/issues/331814)

## Summary

Current source confirms that an extremely enlarged pet can be classified as missing the input platform as soon as a drag ends, sending it directly through the death-and-respawn path. This team-authored bug should remain open for a bounded drag/landing geometry fix.

## Change summary

Dragging a pet after repeatedly increasing its size can immediately make it fall off and die.

## Best solution

Keep oversized pets draggable and determine their landing from meaningful overlap with the input platform, while preserving intentional falls when the pet is actually released outside it.
