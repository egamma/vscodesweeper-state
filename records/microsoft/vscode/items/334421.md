# Issue #334421 — Copilot Agent repeatedly invokes disabled task_complete, causing tool loop and Extension Host CPU/RAM growth

[https://github.com/microsoft/vscode/issues/334421](https://github.com/microsoft/vscode/issues/334421)

## Summary

Traced conclusively in current source: `ensureAutopilotTools` in toolCallingLoop.ts force-adds `task_complete` to the model's tool list in autopilot mode without checking whether the user explicitly disabled it via the tool picker, so every invocation is rejected as disabled and the cycle repeats, matching the reporter's exact log sequence and resource-growth symptoms.

## Change summary

In Agent autopilot mode, when the `task_complete` tool is disabled by the user, the loop keeps re-adding and re-invoking it, causing repeated failures and Extension Host CPU/RAM growth.

## Best solution

In `ensureAutopilotTools` (extensions/copilot/src/extension/intents/node/toolCallingLoop.ts, ~line 962), check `this.options.request.tools` for an explicit `false` entry for `task_complete` before appending it, and skip forcing it back in when the user disabled it — falling back to the existing text-only-response completion heuristic in `shouldAutopilotContinue` instead.
