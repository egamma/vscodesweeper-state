# Issue #180193 — Reverting notebook does not restore cells as they were

[https://github.com/microsoft/vscode/issues/180193](https://github.com/microsoft/vscode/issues/180193)

## Summary

The defect remains on current main: notebook revert is incorrectly skipped when the working copy's dirty state has already been cleared during a soft revert.

## Change summary

File > Revert can leave modified notebook cells unchanged instead of restoring their saved contents.

## Best solution

Remove the `isDirty()` gate from `NotebookEditorInput.revert` and add a regression test proving that revert is forwarded even when the resolved model currently reports clean.
