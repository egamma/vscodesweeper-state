# Issue #54587 — Allow disabling of breadcrumbs on a per language basis

[https://github.com/microsoft/vscode/issues/54587](https://github.com/microsoft/vscode/issues/54587)

## Summary

A real gap remains on current main: breadcrumb enablement is global rather than resource- or language-aware. Given the limited demand and configuration tradeoff, this should remain open for a product decision under `under-discussion`.

## Change summary

Allow `breadcrumbs.enabled` to be overridden for individual languages such as Markdown.

## Best solution

If accepted, make `breadcrumbs.enabled` language-overridable and have `BreadcrumbsControlFactory` reevaluate enablement against the active editor resource when editors change within a group.

## Vision fit

- **Fit:** rejected
- **Reason:** A language-specific visibility toggle adds configuration and per-feature UI variability to the default workbench.
- **Evidence:** Values and guardrails: "Simple, uniform UI and UI interactions" and "UI consistency beats per-feature customization."
