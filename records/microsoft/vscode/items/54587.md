# Issue #54587 — Allow disabling of breadcrumbs on a per language basis

[https://github.com/microsoft/vscode/issues/54587](https://github.com/microsoft/vscode/issues/54587)

## Summary

Language-specific breadcrumb enablement remains unsupported: the setting is not language-overridable, and the control factory reads it without language context. Keep this accepted Backlog request open; no verified canonical owns the same work.

## Change summary

Allow language-specific settings such as `[markdown]` to disable breadcrumbs without disabling them for other languages.

## Best solution

Honor language-specific `breadcrumbs.enabled` values for each editor group, including when switching editors or changing a document's language, while preserving the existing global setting and toggle behavior.

- **Fit:** aligned
- **Reason:** Using the existing language-specific settings mechanism makes editor configuration more consistent without introducing another setting or UI surface.
