# Issue #204484 — API to find the active comment thread

[https://github.com/microsoft/vscode/issues/204484](https://github.com/microsoft/vscode/issues/204484)

## Summary

The active-thread API exists on main but remains proposal-gated and absent from the stable API. Keep this api-proposal tracking issue open for the API owners to decide finalization; the merged implementation PRs do not complete that lifecycle.

## Change summary

Expose the active comment thread to extensions so they can provide thread-specific keybindings.
