# Issue #219807 — File menu save commands get unexpectedly disabled when using a custom editor

[https://github.com/microsoft/vscode/issues/219807](https://github.com/microsoft/vscode/issues/219807)

## Summary

The bug appears to still be present on main — the File menu save commands' precondition relies on `ActiveEditorContext`, and the webview-based custom editor focus lifecycle may cause this context key to not be properly restored after a focus round-trip. The issue already has `help wanted` and correct area labels; it should stay open.

## Change summary

File menu Save/Save As commands become disabled after switching focus away from a custom editor and back.

## Best solution

Investigate why `ActiveEditorContext` is not properly set when a webview-based custom editor regains focus after defocusing. The save commands' precondition in `src/vs/workbench/contrib/files/browser/fileActions.contribution.ts` (lines 690–702) depends on `ActiveEditorContext`, which is set in `src/vs/workbench/browser/parts/editor/editorGroupView.ts` via `observeActiveEditor` on `onDidActiveEditorChange`. The webview focus tracking in `src/vs/workbench/contrib/webviewPanel/browser/webviewEditor.ts` may have a timing issue that prevents the editor pane from being fully recognized. A closely related issue https://github.com/microsoft/vscode/issues/96503 tracks similar save-menu misbehavior in custom editors and may share the same root cause.
