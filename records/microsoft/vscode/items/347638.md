# Issue #347638 — Can't use `/rename` during chat working

[https://github.com/microsoft/vscode/issues/347638](https://github.com/microsoft/vscode/issues/347638)

## Summary

The local-chat command registration still excludes `/rename` from execution during an active request, allowing it into the ordinary queue/steering path. Keep this open; the persistence reports examined concern a different failure.

## Change summary

Make `/rename <title>` rename the current chat while the agent is working instead of becoming a steering message.

## Best solution

Honor the existing local rename command during active turns without forwarding it to the agent, interrupting the turn, or changing ordinary message queuing.
