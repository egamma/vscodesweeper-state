# Issue #146421 — Only focused panel/editor should have solid border line for active item

[https://github.com/microsoft/vscode/issues/146421](https://github.com/microsoft/vscode/issues/146421)

## Summary

Editor tabs now use dotted/solid/dashed borders in high contrast to distinguish active from inactive groups, but the request for consistent treatment across panel tabs, sidebar views, and other parts remains unimplemented.

## Change summary

In high contrast themes, only the focused panel/editor area should show a solid border on its active item; unfocused areas should use dotted borders.

## Best solution

Extend the dotted-vs-solid border pattern already present in editor tabs (multiEditorTabsControl.ts) to panel tabs, sidebar views, and activity bar items, so that focus state is visually distinguishable across all workbench parts in high contrast themes.
