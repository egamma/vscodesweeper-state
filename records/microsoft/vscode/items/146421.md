# Issue #146421 — Only focused panel/editor should have solid border line for active item

[https://github.com/microsoft/vscode/issues/146421](https://github.com/microsoft/vscode/issues/146421)

## Summary

Keep open: current high-contrast styling still distinguishes active selections by editor-group or panel selection state rather than consistently following keyboard focus across areas. The maintainer-endorsed solid-versus-dotted distinction remains meaningful work; neither the earlier editor-only issue nor the newer activity-bar report owns its full scope.

## Change summary

Distinguish keyboard-focused selections from retained active selections across editor tabs, panel tabs, and sidebar lists in high-contrast themes.

## Best solution

Make high-contrast selection indicators consistently distinguish the area receiving keyboard input from other areas retaining a selection, following the solid-for-focused and dotted-for-unfocused behavior agreed in the discussion. Preserve separate hover and direct tab-focus affordances rather than highlighting whole workbench containers.
