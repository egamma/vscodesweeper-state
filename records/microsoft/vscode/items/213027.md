# Issue #213027 — Using #pragma region too close to each other creates overlap in minmap

[https://github.com/microsoft/vscode/issues/213027](https://github.com/microsoft/vscode/issues/213027)

## Summary

Still reproduces on main: minimap section headers for nested or adjacent `#pragma region` / `#region` markers render at their raw line positions with no overlap prevention, causing visual overlap when regions are close together.

## Change summary

Nested or adjacent `#pragma region` / `#region` directives produce overlapping section header labels in the minimap.

## Best solution

Add overlap detection in `InnerMinimap._renderSectionHeaders` (src/vs/editor/browser/viewParts/minimap/minimap.ts, around line 1836): track the bottom Y of the last rendered header and skip or offset subsequent headers that would overlap it.
