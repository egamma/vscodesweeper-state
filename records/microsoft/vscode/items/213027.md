# Issue #213027 — Using #pragma region too close to each other creates overlap in minmap

[https://github.com/microsoft/vscode/issues/213027](https://github.com/microsoft/vscode/issues/213027)

## Summary

The overlap remains source-reproducible on current main: adjacent section headers are positioned by the much smaller minimap line height while each label paints a substantially taller background. The existing `editor-minimap` routing is appropriate.

## Change summary

Closely spaced region declarations cause their section-header labels and backgrounds to overlap in the minimap.

## Best solution

Make minimap section-header placement collision-aware so every rendered label remains legible when regions occur closer together than the label height, without changing ordinary minimap line placement or sufficiently separated headers.
