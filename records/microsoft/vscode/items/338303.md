# Issue #338303 — Add optional right-click drag to pan the editor viewport

[https://github.com/microsoft/vscode/issues/338303](https://github.com/microsoft/vscode/issues/338303)

## Summary

Keep open as a feature request: existing middle-button scrolling does not provide canvas-style panning while preserving middle-button column selection. No verified canonical covers the same requested gesture.

## Change summary

Provide an optional mouse-only editor viewport panning gesture that preserves ordinary context-menu clicks and existing column selection.

## Best solution

Have the editor input owners assess a consistent, opt-in panning gesture that coexists with selection and context menus. Coordinate with the existing mouse-binding configurability discussion without treating it as an implementation of this request.
