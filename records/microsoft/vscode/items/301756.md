# Issue #301756 — Touchscreen issue with model selection.

[https://github.com/microsoft/vscode/issues/301756](https://github.com/microsoft/vscode/issues/301756)

## Summary

The touchscreen defect remains on current main: the model picker’s custom buttons handle mouse-down and keyboard activation but never register or handle VS Code’s touch Tap gesture. The accepted Backlog bug should remain open for a bounded interaction fix.

## Change summary

Tapping the Copilot Chat model selector on a touchscreen does not open the model picker, although mouse and keyboard activation work.

## Best solution

Make both model-picker controls respond once to touchscreen taps while preserving their existing mouse, keyboard, focus-restoration, and disabled-state behavior.
