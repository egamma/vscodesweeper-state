# Issue #330912 — Invalid model in .prompt.md file blocks sending and subsequent messages

[https://github.com/microsoft/vscode/issues/330912](https://github.com/microsoft/vscode/issues/330912)

## Summary

The defect remains source-reproducible on current main: an unknown model from prompt metadata creates a pending selection that never resolves, blocking both the prompt submission and subsequent sends.

## Change summary

An invalid `model` value in `.prompt.md` frontmatter permanently blocks sending messages in that chat.

## Best solution

Reject an unavailable prompt-specified model without leaving pending model-selection state behind, preserving the current behavior that waits for valid models still being published asynchronously.

- **Behavior:**

  > Invoking a `.prompt.md` slash command whose `model` metadata cannot be resolved must not leave the chat unable to send. The invalid prompt submission may be rejected, but the selected valid model and subsequent ordinary messages must remain usable. Valid prompt models that become available during normal asynchronous model publication must continue to work.
- **Trace:**

  > `ChatWidget._applyPromptFileIfSet` resolves the slash prompt and awaits `_applyPromptMetadata`, which delegates model metadata to `ChatInputPart.requestModelByQualifiedName`. That method creates a request through `ChatInputModelSelectionController.requestProgrammaticSelection`; when the model name never matches, `_reconcilePendingProgrammaticSelection` deliberately retains the pending request for asynchronously published models. The unresolved promise stalls the initial submission, while `ChatWidget.acceptInput` and `ChatInputPart._updateInputContentContextKeys` independently block later sends whenever that pending flag remains set. Preserve delayed resolution for valid but not-yet-published models and do not alter user-selected model persistence or unrelated prompt metadata behavior. The generic failure tracker https://github.com/microsoft/vscode/issues/253136 does not cover this specific state-management defect.
