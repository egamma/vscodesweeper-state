# Issue #135552 — [json editing] don't remove the comments of the next property node when removing first property

[https://github.com/microsoft/vscode/issues/135552](https://github.com/microsoft/vscode/issues/135552)

## Summary

Keep open: current main still removes all trivia before the second property when deleting the first property, including comments intended for that second property. This is a team-authored heuristic-improvement request, and no factual fix or valid duplicate supports closing it.

## Change summary

Improve JSON property-removal heuristics so deleting the first property does not also remove comments associated with the following property.

## Best solution

Define and test a comment-ownership heuristic that preserves comments immediately leading into the next property while removing comments clearly associated with the deleted property, then apply it to object-property removal in the shared JSON edit utility.

- **Behavior:**

  > Removing the first property from a JSON object must preserve comments determined to describe the following property. Comments determined to describe only the removed property should be removed with it, and removal of middle or final properties must retain its existing behavior. Acceptance requires explicit tests for line and block comments, including ambiguous layouts separated by blank lines.
- **Trace:**

  > Object-property deletion is implemented in `setProperty` in src/vs/base/common/jsonEdit.ts. For the first property, the removal range currently starts after the opening brace and ends at the next property's offset, so all intervening comment trivia disappears; the parser's property-node tree does not encode comment ownership. Existing removal coverage is in src/vs/base/test/common/jsonEdit.test.ts, but it omits comments between the first and second properties. Keep the change within the shared JSON edit behavior and its tests; do not alter configuration-service default-value removal or JSON parsing semantics. The originating confirmed scenario is documented at https://github.com/microsoft/vscode/issues/134624#issuecomment-944119616.
