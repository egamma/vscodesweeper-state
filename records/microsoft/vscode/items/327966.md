# Issue #327966 — Django test discovery passes incompatible default arguments to `manage.py test`

[https://github.com/microsoft/vscode/issues/327966](https://github.com/microsoft/vscode/issues/327966)

## Summary

This is a Python (Microsoft Python extension) bug in Django test discovery argument construction — the code lives in microsoft/vscode-python, which has its own active tracker, and a fix PR is already open there, so this should be moved rather than tracked in microsoft/vscode core.

## Change summary

The Python extension's Django test discovery passes unittest-discover-style default args (`-v -s . -p '*test*.py'`) to `manage.py test`, which Django's CLI rejects.

## Best solution

Move this report to microsoft/vscode-python, where the reporter has already opened https://github.com/microsoft/vscode-python/pull/26121 to clear the default `unittestArgs` for Django discovery; land that fix there rather than tracking it in vscode core.
