## Summary

The migration still preserves server names containing spaces without checking Copilot Global naming restrictions. Keep this open while the explicitly linked fix PR is reviewed and completed.

## Change summary

Migrating a user MCP server with a space-separated name creates a Copilot configuration that is rejected at startup.

## Best solution

Review https://github.com/microsoft/vscode/pull/350063 to ensure incompatible names are flagged before migration and rejected before any configuration writes, while preserving the original configuration.
