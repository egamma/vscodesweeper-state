# Issue #349898 — Migration of mcp config to ~/.copilot/ lleft name invalid

[https://github.com/microsoft/vscode/issues/349898](https://github.com/microsoft/vscode/issues/349898)

## Summary

The migration still copies space-containing server names into Copilot Global configuration without checking destination naming restrictions. Keep open: migration should flag incompatible names before changing either configuration.

## Change summary

Migrating an MCP server named 'Azure MCP Server' produces a destination configuration rejected by Copilot and prevents agent startup.

## Best solution

Make MCP migration identify incompatible server names before committing the move, clearly explain the restriction, and preserve the original entry until it can migrate safely. Valid server names should continue migrating unchanged.
