# Issue #310135 — VS Code Update error due to background VS Code tasks

[https://github.com/microsoft/vscode/issues/310135](https://github.com/microsoft/vscode/issues/310135)

## Summary

Duplicate of #308524 — both report the same root cause: VS Code child processes (terminals, extension hosts, etc.) keep file handles open during the update, causing the Inno Setup installer to fail with a file-in-use error on Windows.

## Change summary

VS Code update on Windows fails because background child processes are not terminated before the installer attempts to replace files.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/308524 which has better diagnostics (OS error 32, specific Code.exe lock scenario) and already has team engagement from @dmitrivMS investigating the child-process lifecycle during updates.
