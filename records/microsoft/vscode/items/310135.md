# Issue #310135 — VS Code Update error due to background VS Code tasks

[https://github.com/microsoft/vscode/issues/310135](https://github.com/microsoft/vscode/issues/310135)

## Summary

Keep open: restarting to update fails until background processes are manually terminated, with repeat occurrences reported on two versions. The Windows update implementation has evolved since those reports; the supplied restart-and-retry steps suffice for retesting, but source inspection cannot confirm which process blocks this installation.

## Change summary

Prevent surviving background VS Code processes from blocking an update that the user requested through Restart to Update.

## Best solution

Identify the surviving process and locked resource, then ensure the relevant shutdown/update path completes without requiring Task Manager intervention. Consolidate with an existing update-lock issue only after matching its actual failure mechanism.
