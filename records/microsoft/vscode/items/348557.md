# Issue #348557 — Show or Focus Hover is not available from the Command Palette in the Chat input

[https://github.com/microsoft/vscode/issues/348557](https://github.com/microsoft/vscode/issues/348557)

## Summary

The Chat hover supports keyboard invocation, but its command is not exposed through the Command Palette for the composer. Keep this team-authored accessibility report open; current source confirms the discoverability gap.

## Change summary

Make Show or Focus Hover discoverable and executable from the Command Palette when editing a Chat draft.

## Best solution

Expose the existing hover action in the Chat input's Command Palette context, preserving its current preview, focus, Accessible View, and draft-restoration behavior.
