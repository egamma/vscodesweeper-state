# Issue #348557 — Show or Focus Hover is not available from the Command Palette in the Chat input

[https://github.com/microsoft/vscode/issues/348557](https://github.com/microsoft/vscode/issues/348557)

## Summary

The Command Palette still discovers editor actions through the active editor pane rather than the Chat input, leaving the documented hover command unavailable when no text editor is open. Keep this team-authored report open; the keybinding workaround does not restore command discoverability.

## Change summary

Make Show or Focus Hover discoverable and runnable from the Command Palette for inline references in the Chat input.

## Best solution

Expose the existing hover action in the Chat-input context and preserve its target through Command Palette invocation, so users can show and focus the reference preview without memorizing a shortcut.
