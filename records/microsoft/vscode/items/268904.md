# Issue #268904 — No `headers` completion item in mcp.json

[https://github.com/microsoft/vscode/issues/268904](https://github.com/microsoft/vscode/issues/268904)

## Summary

The `headers` property is present in the MCP JSON schema on current main. The commenter explained that the missing completion was caused by the reporter having a `"version"` property (not in the schema), which suppresses completions due to `additionalProperties: false`. The underlying behavior appears correct, but this is a team-authored issue so deferring to the author/team to close.

## Change summary

No `headers` completion offered in mcp.json when the server object contains an unknown property like `version`.

## Best solution

The schema already includes `headers` for HTTP-type servers. The real issue is that `additionalProperties: false` combined with an unknown property (`version`) suppresses completions — this is standard JSON schema validation behavior. The team should decide whether to add `version` to the schema (even as a no-op), relax `additionalProperties`, or close as working-as-intended given dmitrivMS's explanation.
