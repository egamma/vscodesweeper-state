# Issue #183403 — Have a way to show only workspace relative path

[https://github.com/microsoft/vscode/issues/183403](https://github.com/microsoft/vscode/issues/183403)

## Summary

The simple file dialog still displays full filesystem paths and has no workspace-relative display toggle. Keep this team-authored Backlog request open; the related report was explicitly consolidated into this issue, not the reverse.

## Change summary

Allow long paths in the simple file dialog to hide the workspace prefix, with a button and keyboard action to reveal the full path.

## Best solution

Provide a compact workspace-relative presentation in SimpleFileDialog while preserving unambiguous file selection and access to the full path. Settle when compaction activates and how workspace identity is represented before implementation.
