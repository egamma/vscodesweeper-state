# Issue #345527 — Chat session saved after its model is disposed is written out empty and hidden from the list

[https://github.com/microsoft/vscode/issues/345527](https://github.com/microsoft/vscode/issues/345527)

## Summary

The disposal/save race is supported by current source and explains the empty-session persistence failure already tracked in the verified open canonical issue. Consolidate this report there while preserving its diagnosis and ordering reproducer.

## Change summary

A queued save can serialize a disposed chat model, overwrite its saved requests with an empty snapshot, and hide the session from history.

## Best solution

Track the persistence fix in https://github.com/microsoft/vscode/issues/321290, carrying over this report's disposal ordering and reproducer. Preserve saved conversation history when an already-queued save outlives its model.
