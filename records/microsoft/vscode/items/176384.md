# Issue #176384 — Lock the Activity Bar Buttons

[https://github.com/microsoft/vscode/issues/176384](https://github.com/microsoft/vscode/issues/176384)

## Summary

Keep this accepted, community-supported request open: resetting view locations repairs accidental moves but does not prevent them. An open PR explicitly targets this issue, so the next step is to review that implementation rather than start competing work.

## Change summary

Provide a way to lock Activity Bar buttons against accidental drag-and-drop rearrangement or merging.

## Best solution

Provide an opt-out from Activity Bar layout dragging while preserving normal navigation and default customization behavior. Review the implementation candidate at https://github.com/microsoft/vscode/pull/213506 against that goal and keep this issue open until the work lands.
