# Issue #231615 — Have a setting to always delete untitled workspaces on close

[https://github.com/microsoft/vscode/issues/231615](https://github.com/microsoft/vscode/issues/231615)

## Summary

The requested workspace hot-exit control remains absent on current main. The issue is already accepted into the Backlog and correctly routed to multi-root workspace ownership.

## Change summary

Allow users to discard untitled workspaces when closing the last window instead of restoring them at the next launch.

## Best solution

Extend the untitled-workspace configuration with an explicit discard-on-quit option while preserving the current restoration default and guarding clearly against unintended workspace loss.
