# Issue #231615 — Have a setting to always delete untitled workspaces on close

[https://github.com/microsoft/vscode/issues/231615](https://github.com/microsoft/vscode/issues/231615)

## Summary

Keep open: current main still lacks an option to discard untitled workspaces when closing the last window or quitting. The discussion establishes that restoration is intentional, but existing settings do not cover the requested opt-out.

## Change summary

Provide an option to discard untitled workspaces on every window close, including when closing the last window quits the application.

## Best solution

Provide an opt-in untitled-workspace discard policy in the workspace lifecycle, preserving restoration by default and leaving saved workspaces and unsaved-file protection unchanged. The workspace owner should decide whether this warrants a separate setting or an expanded existing contract.
