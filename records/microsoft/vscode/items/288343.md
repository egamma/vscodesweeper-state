# Issue #288343 — Pressing no on periodically run git fetch doesn't do anything

[https://github.com/microsoft/vscode/issues/288343](https://github.com/microsoft/vscode/issues/288343)

## Summary

The declined auto-fetch prompt is remembered locally, but the checkout does not register that preference for synchronization. Keep this open: the earlier identical report was closed optimistically without a fixing commit, and the cross-machine persistence gap remains in the source.

## Change summary

Remember a declined Git auto-fetch prompt across machines using Settings Sync.

## Best solution

Synchronize the remembered auto-fetch prompt response so a new machine does not ask again after the user has declined. Preserve the existing auto-fetch setting and Ask Me Later behavior; writing false into user settings alone does not satisfy the current prompt-suppression condition.
