[https://github.com/microsoft/vscode/issues/313993](https://github.com/microsoft/vscode/issues/313993)

## Change summary

Opening a modified PNG from Source Control fails to display its previous revision in the left-hand image preview.

## Best solution

Retain the resource-root normalization implemented in commit b6a00bc1d179b7d78d92d36d58fd718ca92deaab, which allows ordinary Git-backed image revisions to load. Treat Git LFS pointers and configured text conversion as separate cases rather than assuming this fix covers them.
