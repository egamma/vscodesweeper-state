# Issue #313993 — Source control doesn't show changes for png images

[https://github.com/microsoft/vscode/issues/313993](https://github.com/microsoft/vscode/issues/313993)

## Summary

Already fixed and shipped in 1.120.0. The image preview for `git:` scheme files broke in 1.110 because the webview's `localResourceRoots` included query/fragment parts from the git URI, preventing the webview from loading the resource. Commit b6a00bc1d17 strips those parts, resolving the error.

## Change summary

Source control diff for PNG images shows "An error occurred while loading the image" instead of the original image, starting from VS Code 1.110.

## Best solution

Keep the shipped fix in commit b6a00bc1d17 (1.120.0). No further change needed — upgrading to 1.120+ resolves the issue.
