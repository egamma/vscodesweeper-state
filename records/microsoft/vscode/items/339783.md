## Summary

The described 'run button' and 'ctrl+r run shortcut' are features of the third-party Code Runner extension (formulahendry.code-runner, listed in the reporter's extension list), not VS Code core — this isn't a VS Code bug to track here.

## Change summary

Reporter says a run button disappeared, their ctrl+r run shortcut stopped working, editor focus/cursor behaves oddly after running, and ctrl+r now triggers terminal reverse-i-search instead of re-running code.

## Best solution

Reporter should file this with the Code Runner extension (formulahendry/vscode-code-runner on GitHub) — the run button and the ctrl+r command are that extension's contributions, and the 'bck-i-search' behavior they're seeing is the terminal's native Ctrl+R binding taking over when the extension's keybinding doesn't win focus, which is also something the extension author needs to account for.
