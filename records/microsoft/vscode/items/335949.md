# Issue #335949 — Markdown Editor - Mermaid Diagrams not rendering with Metadata

[https://github.com/microsoft/vscode/issues/335949](https://github.com/microsoft/vscode/issues/335949)

## Summary

Well-specified, fresh bug report against the new WYSIWYG 'Markdown Editor' mode: Mermaid diagrams with YAML frontmatter (title/config) fail to render there while the classic Markdown Preview renders them fine. The actual code-block rendering path in this feature lives in the external `@vscode/markdown-editor` npm package, which isn't vendored in this checkout, so I can't trace the exact parsing defect from source alone.

## Change summary

In the new Markdown Editor (WYSIWYG) mode, a mermaid code block that includes YAML frontmatter (e.g. `---\ntitle: Test\n---`) fails to render, whereas the same content renders correctly in Markdown Preview and renders fine once the frontmatter is stripped.

## Best solution

Reproduce with the exact repro snippet in the issue and trace `renderCustomCodeBlock` in extensions/markdown-language-features/markdown-editor-src/editor.ts (which hands the raw code-block content straight to `mermaid.render`) together with how `@vscode/markdown-editor`'s AST parser extracts fenced code-block content — the frontmatter's `---` delimiters are a likely place for the AST parser to mis-detect the code fence boundaries or strip/mangle the leading `---` before mermaid ever sees it.
