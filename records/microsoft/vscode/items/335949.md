# Issue #335949 — Markdown Editor - Mermaid Diagrams not rendering with Metadata

[https://github.com/microsoft/vscode/issues/335949](https://github.com/microsoft/vscode/issues/335949)

## Summary

Plausible, well-documented bug specific to the new WYSIWYG Markdown Editor: it renders Mermaid diagrams via a different code path than Markdown Preview, and the reporter gives a precise, deterministic repro (frontmatter breaks rendering only in Editor mode). Routing to the markdown area rather than closing.

## Change summary

Mermaid diagrams with YAML frontmatter/config metadata fail to render in the new Markdown Editor mode, while they render fine in Markdown Preview.

## Best solution

Investigate why `renderCustomCodeBlock` in extensions/markdown-language-features/markdown-editor-src/editor.ts (which calls `mermaid.render(id, content)` directly on the fenced code block's extracted content) receives content that mermaid can't parse when it starts with a `---` frontmatter block — likely an extraction bug in the `@vscode/markdown-editor` AST/parser package that the Editor's code-block content offset relies on.
