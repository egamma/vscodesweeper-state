# Issue #258716 — Needed python file open to trigger activation of extension to make completions show up in the terminal

[https://github.com/microsoft/vscode/issues/258716](https://github.com/microsoft/vscode/issues/258716)

## Summary

Team-authored bug about the Python extension (microsoft/vscode-python) not activating until a Python file is opened, which blocks terminal suggest completions in the Python REPL. No fix commit found on main; the root cause likely spans both vscode-python (activation events) and possibly VS Code core (terminal suggest integration). Keeping open.

## Change summary

Python terminal completions require a Python file to be open because the Python extension lacks an activation event for Python REPL startup.

## Best solution

The Python extension (microsoft/vscode-python) needs an activation event that triggers when a Python REPL is detected in the terminal, so that shell integration and terminal suggest completions work without requiring a .py file to be open first. This may also need a VS Code core contribution if no suitable activation event exists for terminal shell type detection.
