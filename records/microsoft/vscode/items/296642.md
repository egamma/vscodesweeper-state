# Issue #296642 — Different cloud and background options when delegating from local vs new empty chat

[https://github.com/microsoft/vscode/issues/296642](https://github.com/microsoft/vscode/issues/296642)

## Summary

Team-authored UX consistency request about chat delegation options. Some related work has landed (e.g. hiding delegation picker for local agent host, Copilot CLI label fixes), but the core ask — parity of options between 'new empty chat' and 'delegate from local chat' flows — remains an open discussion with no commit referencing this issue.

## Change summary

When delegating from a local chat session, the available options (cloud/background model picker, Configure Tools button) differ from those shown in a new empty chat, causing confusion.

## Best solution

Unify the session-target option rendering so delegation flows expose the same model picker and Configure Tools button as new-chat flows. The chat input box contribution and delegation picker code (likely in the chat/sessions contrib area) need alignment. The `under-discussion` label is appropriate while the team decides scope across Copilot CLI, Claude Agent, and local agent host targets.
