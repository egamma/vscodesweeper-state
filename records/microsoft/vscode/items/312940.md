# Issue #312940 — Custom OpenAI-compatible BYOK providers proxying Anthropic models cannot use prompt caching (no way to declare backend type)

[https://github.com/microsoft/vscode/issues/312940](https://github.com/microsoft/vscode/issues/312940)

## Summary

Keep open: custom endpoints now support selecting the Anthropic Messages API, but that does not cover gateways that require OpenAI Chat Completions with an Anthropic-compatible caching extension. The comments establish demand for that remaining capability, and no verified canonical issue absorbs it.

## Change summary

Allow custom OpenAI-compatible BYOK gateways to receive supported Anthropic prompt-caching fields without switching their request protocol.

## Best solution

Provide an explicit, capability-aware caching contract for custom Chat Completions gateways while preserving existing behavior for ordinary OpenAI-compatible servers. Distinguish caching support from API format and underlying model family; the existing Custom Endpoint Messages option already covers gateways exposing that protocol.
