# Issue #324652 — Agents window: make model provider & billing clear for 3rd-party agents (Claude / Codex)

[https://github.com/microsoft/vscode/issues/324652](https://github.com/microsoft/vscode/issues/324652)

## Summary

Legitimate, well-diagnosed UX/trust clarity gap for the Agents window that needs design work, not a code defect — already correctly labeled and routed (agent-host, claude-agent, codex-agent), so it should stay open for product decision rather than being closed.

## Change summary

The Agents window's agent picker doesn't clarify that selecting Claude/Codex routes through the Copilot proxy and consumes Copilot tokens rather than the user's own subscription, causing trust/confusion issues.

## Best solution

Design work belongs with the Agents window / agent-host owners: extend the existing editor-window Claude tooltip pattern into the Agents window picker, and/or add an explicit provider/billing disclosure (one-time explainer or persistent tooltip) before or when a 3rd-party agent is selected — tracked alongside the related BYOK discoverability issue (https://github.com/microsoft/vscode/issues/323049).
