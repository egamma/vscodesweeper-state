# Issue #324652 — Agents window: make model provider & billing clear for 3rd-party agents (Claude / Codex)

[https://github.com/microsoft/vscode/issues/324652](https://github.com/microsoft/vscode/issues/324652)

## Summary

Keep open for a provider/subscription clarity design pass. Current model selection and account UI offer partial improvements, but available harness entries still lack explanatory details, and no verified older canonical covers the full request.

## Change summary

Make Claude and Codex harness selection clearly distinguish the agent product, model provider, and subscription charged.

## Best solution

Users should understand which harness runs their task and which provider/account funds the selected model before sending it. Build on existing provider-aware model selection and account UI, while deciding how much explanation belongs in the harness picker versus first-use guidance.
