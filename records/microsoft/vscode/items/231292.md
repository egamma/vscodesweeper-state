# Issue #231292 — Behavior changed for middle click window title in gnome

[https://github.com/microsoft/vscode/issues/231292](https://github.com/microsoft/vscode/issues/231292)

## Summary

Confirmed upstream Mutter defect: server-side title-bar clicks never reach Electron applications, so VS Code cannot restore this behavior itself. Keep the issue open as an upstream-tracking report.

## Change summary

Middle-clicking the VS Code title bar no longer performs GNOME's configured lower-window action on Ubuntu 24.04 with GNOME 46.

## Best solution
