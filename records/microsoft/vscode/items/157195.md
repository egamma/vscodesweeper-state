# Issue #157195 — Poor sort order for 'go to symbol'

[https://github.com/microsoft/vscode/issues/157195](https://github.com/microsoft/vscode/issues/157195)

## Summary

Keep open: the current symbol picker still does not guarantee that a full-name match outranks partial matches. Maintainers supported improving this ranking, and the verified related issues do not provide a canonical for this specific remaining request.

## Change summary

Prioritize the complete symbol name Tab over partial matches when searching for tab in Go to Symbol in Editor.

## Best solution

Make full-name matches reliably surface above partial matches in the document-symbol picker, while retaining document order for otherwise equivalent results. Keep the improvement scoped to symbol navigation rather than changing unrelated quick-open ranking.
