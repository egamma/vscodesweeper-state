# Issue #147251 — Allow comment UI to be triggered via a clickable icon in the gutter

[https://github.com/microsoft/vscode/issues/147251](https://github.com/microsoft/vscode/issues/147251)

## Summary

The remaining request is unobtrusive, whole-document commenting, not merely a clickable add-comment icon. Current source still decorates the provided commenting ranges with a gutter bar, and the related gutter-click requests do not establish a valid duplicate target.

## Change summary

Allow extensions to offer native inline commenting anywhere in a document through an on-demand gutter icon without a persistent whole-document commenting bar.

## Best solution

Agree on a whole-document commenting presentation that reveals the native add-comment affordance on user intent without displaying a continuous gutter bar. Preserve existing range-based review behavior; extension-owned clickable decorations are a related, broader API alternative.
