# Issue #147251 — Allow comment UI to be triggered via a clickable icon in the gutter

[https://github.com/microsoft/vscode/issues/147251](https://github.com/microsoft/vscode/issues/147251)

## Summary

Still a valid open request. The comment gutter decorations exist (CommentingRangeDecorator with `comment-range-glyph` CSS classes) but they are purely visual — there is no click handler on them. No implementation of a clickable gutter icon to trigger comment creation has landed on main.

## Change summary

Allow extensions to trigger comment creation via a clickable icon in the editor gutter, rather than only through commands or the commenting range bar.

## Best solution

Add a clickable gutter icon mode for the commenting range API, so extensions like CodeStream can display an add-comment icon on hover/selection that opens the comment widget on click. The work would likely touch `CommentingRangeDecorator` in `commentsController.ts` and the glyph/decoration click infrastructure in the editor. The related upstream issue for decoration click events (https://github.com/microsoft/vscode/issues/5455) was closed as duplicate, so this capability would need to be built into the comments contribution specifically.
