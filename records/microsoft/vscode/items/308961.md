## Change summary

MCP tool calls that return Tasks block the entire chat conversation until the task reaches a terminal state, making async MCP workflows unusable.

## Best solution

Land the in-progress work on the `connor4312/tasks-backgrounding` branch, which should decouple the tool-call Promise from the conversation turn so the LLM can continue while MCP tasks poll in the background — surfacing task status, cancellation, and result notification in the chat UI.
