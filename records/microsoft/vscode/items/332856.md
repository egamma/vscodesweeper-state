# Issue #332856 — Remote SSH status bar indicator has incorrect rounded corners on macOS

[https://github.com/microsoft/vscode/issues/332856](https://github.com/microsoft/vscode/issues/332856)

## Summary

Traced in source: the pill-shaped, heavily-rounded status bar item styling is the intentional 'Modern UI' experimental design, not a Remote-SSH-specific defect — it applies `border-radius: var(--vscode-cornerRadius-small)` to every status bar item, so the remote indicator is simply following the same rule as all other status bar entries.

## Change summary

The Remote SSH status bar indicator on macOS shows large, pill-like rounded corners instead of the standard flat status bar styling.

## Best solution

No change needed for the remote indicator specifically — if the reporter finds the rounded-pill status bar style undesirable, that's feedback on the `workbench.experimental.modernUI` setting/design as a whole (src/vs/workbench/contrib/modernUI/browser/media/statusBar.css), not a per-extension styling bug; they can disable that experimental setting to restore the classic square status bar look.

  > Thanks for the report and screenshot. This isn't a Remote-SSH-specific issue — the pill-shaped rounding applies to every status bar item under the new experimental 'Modern UI' styling (`workbench.experimental.modernUI`), which intentionally applies `border-radius` to status bar items to give them a rounded, control-like look (see `src/vs/workbench/contrib/modernUI/browser/media/statusBar.css`). If you'd prefer the classic flat status bar, you can turn off that experimental setting. Closing as as-designed for the current Modern UI styling.

## Evidence

- **feature gate:** src/vs/workbench/contrib/modernUI/browser/modernUI.contribution.ts: ModernUIContribution toggles a `statusBar`/`roundedCorners` CSS module based on the `workbench.experimental.modernUI` setting; the comment in statusBar.css explicitly documents 'Round the status bar item backgrounds to a control-sized pill.'
