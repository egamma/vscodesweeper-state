# Issue #332856 — Remote SSH status bar indicator has incorrect rounded corners on macOS

[https://github.com/microsoft/vscode/issues/332856](https://github.com/microsoft/vscode/issues/332856)

## Summary

Unrouted visual bug with no labels yet — traced a plausible root cause in the status bar CSS (the macOS Tahoe corner-radius rule) rather than confirming by running the app, so this goes to the status bar area rather than a confident close.

## Change summary

On macOS 26 (Tahoe), the Remote SSH status bar indicator in the bottom-left corner shows an oversized, pill-like rounded corner that looks visually inconsistent with the rest of the status bar.

## Best solution

In src/vs/workbench/browser/parts/statusbar/media/statusbarpart.css, the `.monaco-workbench.mac.macos-tahoe:not(.fullscreen) .part.statusbar:focus` rule bumps the bottom-corner radius from 10px to 16px to match Tahoe's window chrome; the first status bar item (here the remote indicator, which has its own background color via `.has-background-color`) likely doesn't get a matching inner radius, producing the visible mismatch/gap the reporter describes. A maintainer familiar with the recent Tahoe styling work should confirm visually and either round the first/last item's background to match or clip it against the container.
