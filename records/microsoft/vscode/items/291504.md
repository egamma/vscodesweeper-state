# Issue #291504 — GitHub Copilot Chat: Account is not changed in the chat sidebar, when changed using the Account Preferences menu

[https://github.com/microsoft/vscode/issues/291504](https://github.com/microsoft/vscode/issues/291504)

## Summary

Keep open: multiple reporters supplied reproducible account/token mismatches, including after reloading, and have answered the original information request. The remaining work is to diagnose why Chat authenticates with a different account from the selected extension preference.

## Change summary

Copilot Chat continues using another signed-in GitHub account after the user changes its extension account preference.

## Best solution

Make Chat token acquisition and model discovery consistently honor the selected Copilot account without requiring sign-out or reload. Diagnose the session-selection and token-refresh boundary first; keep the separate account-indicator request independent.
