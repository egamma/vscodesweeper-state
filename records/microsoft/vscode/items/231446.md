# Issue #231446 — Allow terminal links to be opened in a web browser

[https://github.com/microsoft/vscode/issues/231446](https://github.com/microsoft/vscode/issues/231446)

## Summary

Valid feature request — `file://` URIs in the terminal are currently always opened in the editor via the local file opener. No 'open in browser' option exists. The maintainer (Tyriar) already linked this to #216853, suggesting a link-specific context menu is the preferred path. Both issues remain unimplemented on current main.

## Change summary

Allow terminal file links (especially `file://` URIs) to be opened in a web browser instead of the editor.

## Best solution

Implement as part of https://github.com/microsoft/vscode/issues/216853 — a link-specific context menu in the terminal that offers 'Open in Editor' and 'Open in Browser' actions, avoiding the need for a regex-based settings mapping. The opener logic in `terminalLinkOpeners.ts` (`TerminalUrlLinkOpener._openFileSchemeLink`) would need an alternative path that delegates to `IOpenerService.open` with `openExternal: true`.
