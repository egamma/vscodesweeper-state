[https://github.com/microsoft/vscode/issues/348613](https://github.com/microsoft/vscode/issues/348613)

## Summary

The manual automation dialog still invites users to describe an automation even though the field supplies its execution prompt directly. Keep this open for a bounded copy correction; the team-authored report is not grounds for a judgment close.

## Change summary
