# Issue #235009 — Git - git blame info is not provided to screen reader users

[https://github.com/microsoft/vscode/issues/235009](https://github.com/microsoft/vscode/issues/235009)

## Summary

Keep open: current source still presents inline Git blame as a visual decoration without announcing it during line navigation. The thread raises a meaningful choice between automatic announcements and on-demand access that should be settled with the accessibility owner.

## Change summary

Make built-in current-line Git blame information available to screen reader users while editing.

## Best solution

Provide discoverable, keyboard-accessible current-line blame information in the built-in Git experience, with announcement behavior agreed with the accessibility owner. Preserve ordinary editor reading and avoid unsolicited repeated speech.
