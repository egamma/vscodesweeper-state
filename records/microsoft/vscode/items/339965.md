# Issue #339965 — Agents window: Create PR uses wrong GitHub account when Copilot and repository accounts differ

[https://github.com/microsoft/vscode/issues/339965](https://github.com/microsoft/vscode/issues/339965)

## Summary

Keep open: current source supports the reported failure path, with repository authentication selected independently of SSH credentials but no repository-account recovery for the resulting 404. Related reports do not own this specific Create PR workflow.

## Change summary

Create PR fails after a successful SSH push when the GitHub API credential lacks repository access, without offering an independent repository-account selection.

## Best solution

Let Create PR select or sign into a repository-authorized GitHub account without changing the Copilot account, and remember the selection at an agreed repository or workspace scope. Offer actionable recovery for inaccessible repositories without assuming every 404 means the account is wrong.
