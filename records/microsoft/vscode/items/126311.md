# Issue #126311 — Workspace Trust - Declared Untrusted Folders

[https://github.com/microsoft/vscode/issues/126311](https://github.com/microsoft/vscode/issues/126311)

## Summary

Valid feature request with strong community support (48 upvotes). The workspace trust system on current main only supports a trusted-folders list — there is no mechanism to declare folders as always-untrusted. The feature remains unimplemented.

## Change summary

Allow users to configure folders that should always open in Restricted Mode (an 'untrusted folders' list), inverting the current trust-list-only model.

## Best solution

Implement an 'untrustedFolders' configuration in the workspace trust service (src/vs/workbench/services/workspaces/common/workspaceTrust.ts) that overrides per-session trust grants, so declared-untrusted paths always load in Restricted Mode. The trust editor UI would need a corresponding section.
