The current source still drops colored bracket guides when the viewport ends inside a long wrapped model line, allowing ordinary gray indentation guides to appear instead. Keep this open for a bounded guide-range correction; no verified canonical or fixing commit was found.

## Change summary

## Evidence

- **Current-source range defect:** In src/vs/editor/common/model/guidesTextModelPart.ts, GuidesTextModelPart.getLinesBracketGuides computes visibleGuideEndLineNumber = Math.min(end.lineNumber, endLineNumber), then emits vertical guides only while l < visibleGuideEndLineNumber + offset.
