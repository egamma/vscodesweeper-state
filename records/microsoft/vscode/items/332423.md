# Issue #332423 — Agent Host: failed transcript-less subagent blocks subsequent user turns

[https://github.com/microsoft/vscode/issues/332423](https://github.com/microsoft/vscode/issues/332423)

## Summary

Fixed on main: `_resolvePeerChatsForTurnValidation` in agentService.ts now catches `SubagentTranscriptUnavailableError` per-peer, logs a warning, and continues resolving the remaining peers instead of rejecting the whole new turn — exactly the tolerate-unavailable-transcript direction the reporter proposed, and a maintainer has confirmed the fix landed via PR #334312.

## Change summary

Sending a new parent-chat message after restoring a session with a failed, transcript-less subagent left the turn stuck forever with no provider call, because turn-id validation rejected the whole action when it couldn't hydrate the failed subagent's transcript.

## Best solution

Keep the shipped fix: unresolved peer chats that fail with `SubagentTranscriptUnavailableError` are now tracked in a skip-set and excluded from further resolution attempts, so turn validation proceeds against the remaining resolvable peers.
