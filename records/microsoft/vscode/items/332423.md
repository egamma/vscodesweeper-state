## Summary

Fixed on current main by the merged superseding implementation in https://github.com/microsoft/vscode/pull/334312. The fix specifically prevents a transcript-less restored subagent from rejecting a subsequent parent turn while keeping other resolution failures fail-closed.

## Change summary

Allow a restored Agent Host session to accept new parent-chat turns when a failed historical subagent has no transcript.

## Best solution

Keep the targeted behavior from commit 7949faffc31e1f0cf85f5d78b9ef035c1ed2880f: skip only restored subagents with the typed transcript-unavailable result during duplicate turn-ID validation, while leaving their transcripts unresolved and retryable.
