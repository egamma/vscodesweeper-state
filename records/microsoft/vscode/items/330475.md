# Issue #330475 — Agent Host (Claude): first message fails with `No conversation found with session ID` when the Claude SDK downloads lazily during the first turn

[https://github.com/microsoft/vscode/issues/330475](https://github.com/microsoft/vscode/issues/330475)

## Summary

Keep open: current source still allows a first-turn state refresh to resume a Claude conversation before it has been created. The related SDK-download fix addresses download discoverability, not this create-versus-resume failure.

## Change summary

A new Claude chat's first message fails after lazy SDK provisioning because a pre-send rebuild resumes a conversation that does not yet exist.

## Best solution

Preserve new-conversation semantics when startup-time tool or customization changes require rebuilding an unused Claude chat, while retaining resume behavior for existing conversations. Cover the first-materialization race with a deterministic regression test.
