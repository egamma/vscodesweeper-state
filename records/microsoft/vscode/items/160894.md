# Issue #160894 — `Auto Save` menu state not updated properly (vscode-web)

[https://github.com/microsoft/vscode/issues/160894](https://github.com/microsoft/vscode/issues/160894)

## Summary

Keep open: a maintainer confirmed the web-only delayed menu update, and no concrete fixing commit or verified current-main resolution was found. The older custom-editor report has the same visible stale checkmark but does not own this Settings UI and remote-configuration scenario.

## Change summary

Changing files.autoSave in vscode.dev leaves the File menu's Auto Save checkmark stale until the menu is closed and reopened.

## Best solution

Reproduce the event ordering on current vscode.dev, then ensure the File menu reflects the effective files.autoSave value on its first opening after local or remote configuration changes, without weakening the menubar's focus-update safeguards.
