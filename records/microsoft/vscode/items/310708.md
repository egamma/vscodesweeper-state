## Summary

A reasonable feature request to improve the AI Customization panel's skill scope UX — renaming labels and adding a unified checkbox UI. The current code uses "Workspace" and "User" terminology throughout; no existing issue covers this specific proposal. Keeping open for the team to evaluate.

## Change summary

Rename skill scope labels from Workspace/User to Repo/Local and add a unified checkbox UI to manage skill placement across both scopes without manual file duplication.

## Best solution

The rename portion (Workspace→Repo, User→Local) is a straightforward terminology change in `aiCustomizationListWidget.ts` and `aiCustomizationManagementEditor.ts`. The unified checkbox UI with cross-scope toggling is a more substantial UX redesign that would need design review from the AI Customization area owners. The color-coding proposal (orange/green/blue) conflicts with VS Code's value of uniform, theme-level UI — scope indicators via icons or badges would be more consistent.
