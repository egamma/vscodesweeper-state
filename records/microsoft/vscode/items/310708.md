[https://github.com/microsoft/vscode/issues/310708](https://github.com/microsoft/vscode/issues/310708)

## Summary

The requested cross-scope placement UI remains missing: current main still groups skills by storage rather than presenting one skill with Repo/Local placement controls. Keep this open under discussion; the verified related requests do not cover its full scope, and inactivity alone does not justify closing it.

## Change summary

Provide clearer skill scope names and a unified list with controls for maintaining skills in both repository and user locations.

## Best solution

Evaluate cross-scope skill management in the shared Chat Customizations editor, defining how independently edited same-name skills are distinguished and how placement, updates, and removal behave. Preserve consistent terminology across multi-root and remote environments, and use accessible, theme-aware scope indicators rather than fixed name colors.
