# Issue #34715 — Display line number as hybrid styles

[https://github.com/microsoft/vscode/issues/34715](https://github.com/microsoft/vscode/issues/34715)

## Summary

Keep this supported Backlog request open: current editor settings still cannot display absolute and relative numbers simultaneously on every line. The discussion supplies extension workarounds, but neither those nor the existing relative mode fulfills the native-feature request.

## Change summary

Provide simultaneous absolute and relative line-number columns, with optional distinct colors and configurable column order.

## Best solution

Decide whether to offer an opt-in native dual-number display in the editor gutter, preserving existing modes and the default gutter footprint. Settle whether independently themed columns and configurable ordering belong in the initial scope; the extension workaround alone is not grounds to decline accepted Backlog work.
