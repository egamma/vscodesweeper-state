# Issue #34715 — Display line number as hybrid styles

[https://github.com/microsoft/vscode/issues/34715](https://github.com/microsoft/vscode/issues/34715)

## Summary

A real gap remains: current main supports absolute or relative line numbers, but not both simultaneously. This canonical Backlog request has 103 community upvotes, well above the promotion threshold, so it should remain open.

## Change summary

Add a hybrid editor line-number style showing absolute and relative numbers together, optionally with distinct positioning and colors.

## Best solution

Add an optional hybrid value to `editor.lineNumbers` and render both values in the editor gutter, primarily in `src/vs/editor/common/config/editorOptions.ts` and `src/vs/editor/browser/viewParts/lineNumbers/lineNumbers.ts`; consider the extra color and positioning controls separately to avoid unnecessary configuration complexity.
