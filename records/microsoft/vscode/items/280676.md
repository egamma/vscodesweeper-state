# Issue #280676 — Option to keep history when delegating to background agent

[https://github.com/microsoft/vscode/issues/280676](https://github.com/microsoft/vscode/issues/280676)

## Summary

The existing chat.exitAfterDelegation setting addresses the original auto-clear behavior and now defaults to false. Keep this team-authored issue open because the identified implementation does not explicitly reference this issue, as required for a completed-close proposal.

## Change summary

Allow users to retain the original chat history instead of automatically starting an empty chat after delegating to a background agent.

## Best solution

Use chat.exitAfterDelegation=false for the original delegation flow; the setting prevents automatic archiving and clearing of the source conversation. The owner should confirm whether that satisfies the request or whether newer Continue In flows need separate history-retention behavior.
