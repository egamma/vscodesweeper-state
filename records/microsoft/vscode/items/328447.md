# Issue #328447 — Warn when replacement string already exists in target files during global Search & Replace

[https://github.com/microsoft/vscode/issues/328447](https://github.com/microsoft/vscode/issues/328447)

## Summary

The requested replacement-target warning is not covered by the existing Replace All confirmation or replacement preview. Keep this open for feature evaluation; no verified canonical or maintainer decision supports closing it.

## Change summary

Warn before global replacement when the replacement text already occurs within the selected search scope.

## Best solution

Evaluate a non-blocking collision indicator in the Search view, with explicit matching semantics and bounded search cost. Existing replacement previews should remain available without treating every repeated replacement string as an error.
