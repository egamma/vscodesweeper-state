# Issue #328447 — Warn when replacement string already exists in target files during global Search & Replace

[https://github.com/microsoft/vscode/issues/328447](https://github.com/microsoft/vscode/issues/328447)

## Summary

This is a valid, currently unmet Search & Replace safety enhancement. Route it to the search-replace area for product and performance evaluation.

## Change summary

Warn before multi-file Replace All when the replacement text already occurs within the active search scope.

## Best solution

Have the Search & Replace confirmation surface a non-blocking collision count when it can be computed without materially delaying replacement, likely in the Search view's Replace All flow.
