# Issue #237883 — extension get wrong resource in context key when right click a folder with subfolder

[https://github.com/microsoft/vscode/issues/237883](https://github.com/microsoft/vscode/issues/237883)

## Summary

Still present on current main: right-clicking an earlier segment of a compact folder updates the menu argument to that segment but leaves the `resource` context key on the compressed row's final folder. This team-authored, accepted bug should remain open.

## Change summary

Explorer context keys expose the final folder in a compact path instead of the specific folder segment that was right-clicked.

## Best solution

Make the Explorer's dynamic resource context keys consistently describe the clicked compact-folder segment, matching the resource already supplied to context-menu commands, while preserving ordinary rows and multi-selection behavior.
