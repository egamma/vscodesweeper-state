[https://github.com/microsoft/vscode/issues/331309](https://github.com/microsoft/vscode/issues/331309)

## Summary

Genuine gap: there's a built-in chat tool pattern for terminal output (getTerminalOutputTool.ts) but nothing equivalent exposing the Debug Console/REPL content to chat/agent tools, so this is a valid, currently-unimplemented request; too fresh (0 days old, no discussion) to route with certainty.

## Change summary

Request a built-in VS Code chat/MCP tool that lets AI agents read and search (grep-style) the contents of the Debug Console.

## Best solution

Add a chat tool analogous to the terminal's getTerminalOutputTool/getTerminalLastCommandTool (src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/) that surfaces debug REPL/session output (backed by src/vs/workbench/contrib/debug/common/replModel.ts) to agent tools, likely living under contrib/debug or a new chatAgentTools folder for debug.
