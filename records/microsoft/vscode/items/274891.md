# Issue #274891 — Multiple `#selection` attachments only include the last selection

[https://github.com/microsoft/vscode/issues/274891](https://github.com/microsoft/vscode/issues/274891)

## Summary

The defect remains present on current main: repeated inline selection references share an ID and are collapsed by ID-keyed attachment maps, leaving only the final selection. A second user also confirmed the same behavior in VS Code 1.121.0.

## Change summary

Multiple typed `#selection` references in one chat prompt should preserve and send every selected range instead of only the last one.

## Best solution

Preserve each inline occurrence as a distinct ranged attachment through chat input parsing and request submission, while retaining deduplication for genuinely identical standalone attachments.
