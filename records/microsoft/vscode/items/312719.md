# Issue #312719 — A word wrap indent ("editor.wrappingIndent") option for a FIXED amount of spaces from the margin

[https://github.com/microsoft/vscode/issues/312719](https://github.com/microsoft/vscode/issues/312719)

## Summary

The requested fixed, margin-relative wrap indentation is still missing. Keep this feature request open for discussion: existing options do not cover it, and the related language-aware wrapping request addresses a different behavior.

## Change summary

Allow wrapped continuation lines to start a configurable number of spaces from the editor's text margin, independently of source indentation and tab size.

## Best solution

Have the editor owner assess an optional fixed-offset wrapping mode while preserving existing wrapping defaults and accessibility behavior. Language-specific defaults can help individual workflows but do not satisfy the requested independent offset.
