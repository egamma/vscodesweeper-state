# Issue #340755 — Linux: archive builds use the com.microsoft.VSCode app_id when the system package is installed

[https://github.com/microsoft/vscode/issues/340755](https://github.com/microsoft/vscode/issues/340755)

## Summary

Keep open: current source still overrides an archive build's desktop identity based solely on the presence of the system package's launcher. The downstream installer workaround does not resolve this VS Code startup behavior.

## Change summary

Prevent Linux archive and portable builds from adopting an installed system package's desktop identity instead of their configured desktopName.

## Best solution

Ensure Linux startup preserves a separately distributed build's configured desktop identity while retaining the correct identities for system packages and Snap installations.
