# Issue #340755 — Linux: archive builds use the com.microsoft.VSCode app_id when the system package is installed

[https://github.com/microsoft/vscode/issues/340755](https://github.com/microsoft/vscode/issues/340755)

## Summary

The reported identity override remains in current main: an installed system launcher causes archive builds to adopt the package's desktop name without checking which executable is running. Keep this open; the downstream installer workaround does not resolve the core behavior.

## Change summary

Preserve an archive build's configured Linux desktop identity when a separately installed system package is present.

## Best solution

Linux startup should preserve a separately launched archive's desktop identity while retaining correct identities for packaged and Snap installations. Review the linked installer PR as downstream mitigation, not as completion of the VS Code fix.
