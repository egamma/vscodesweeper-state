# Issue #238603 — Dragging and dropping cells in Python REPL does not work.

[https://github.com/microsoft/vscode/issues/238603](https://github.com/microsoft/vscode/issues/238603)

## Summary

Still present on main: the REPL/IW sets `dragAndDropEnabled: false` so drag operations are no-ops, but the drag handle visual affordance (the grab-cursor icon on hover) is never hidden — the handles still get `draggable='true'` and the focus indicator dom nodes still render as drag targets. The reporter's ask (hide the grab icon) remains unaddressed.

## Change summary

The hand/drag icon appears on hover next to cells in the Python REPL even though cell drag-and-drop is disabled, confusing users.

## Best solution

Guard `registerDragHandle` (or its callers in `cellRenderer.ts`) so that when `dragAndDropEnabled` is false, the drag handles don't get `draggable='true'` and the grab-cursor CSS is suppressed. The fix lives in `src/vs/workbench/contrib/notebook/browser/view/cellParts/cellDnd.ts` and possibly the cell renderer CSS.
