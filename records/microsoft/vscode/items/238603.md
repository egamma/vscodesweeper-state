# Issue #238603 — Dragging and dropping cells in Python REPL does not work.

[https://github.com/microsoft/vscode/issues/238603](https://github.com/microsoft/vscode/issues/238603)

## Summary

The misleading drag affordance remains in current source: REPL history disables drag-and-drop, but notebook cell margins still advertise dragging. Keep this team-authored issue open; the maintainer discussion supports removing the affordance rather than enabling history reordering.

## Change summary

Python REPL history cells show a grab cursor and draggable handles even though dragging cannot reorder them.

## Best solution

Make REPL history cell affordances reflect their disabled drag-and-drop behavior while preserving cell focus, output controls, and normal notebook dragging. Treat copying cells into another notebook as a separate capability, not an implied requirement to enable REPL history reordering.
