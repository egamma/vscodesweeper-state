# Issue #86734 — Disambiguate quickSuggestion from editor.action.triggerSuggest

[https://github.com/microsoft/vscode/issues/86734](https://github.com/microsoft/vscode/issues/86734)

## Summary

Legitimate API feature request to distinguish automatic (quickSuggestions) from explicit (Ctrl+Space) completion triggers. The pattern already exists for InlineCompletionTriggerKind (Invoke vs Automatic) but was never extended to CompletionTriggerKind. Very low traction (1 upvote over 5+ years); already labeled under-discussion — keeping open for the community process.

## Change summary

Add a way for CompletionItemProviders to distinguish between completions triggered by quickSuggestions (automatic typing) and explicit invocation (Ctrl+Space).

## Best solution

Add an `Automatic` value to `CompletionTriggerKind` (mirroring `InlineCompletionTriggerKind`) so providers can differentiate quickSuggestions from explicit invocation. This is an API surface change that needs a product decision from the suggest area owner, particularly around the UX concern jrieken raised about users being confused by subtly different completion behavior.
