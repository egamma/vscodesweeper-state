# Issue #167401 — Alt+Space behavior disruptive and inconsistent

[https://github.com/microsoft/vscode/issues/167401](https://github.com/microsoft/vscode/issues/167401)

## Summary

The reported Alt+Space behavior on Windows was effectively fixed by commit af87ab952e9, which stopped intercepting the system-context-menu event on Windows entirely — Alt+Space now always shows the native OS system menu regardless of mouse position. Shipped in 1.101.0.

## Change summary

Alt+Space on Windows with the custom titlebar would show a VS Code layout-controls menu instead of the native system menu depending on the mouse cursor position, breaking standard OS keyboard shortcuts like Alt+Space, N to minimize.

## Best solution

Keep the shipped workaround in commit af87ab952e9 — on Windows, the native system menu now always shows on Alt+Space. No further change is needed. The underlying issue with the custom menu on Windows is tracked separately in https://github.com/microsoft/vscode/issues/250626.
