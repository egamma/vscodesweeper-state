# Issue #141761 — Some default shortcuts don't work with non-english layout: `cmd + .`, etc

[https://github.com/microsoft/vscode/issues/141761](https://github.com/microsoft/vscode/issues/141761)

## Summary

A real keyboard-layout gap remains on main, and this issue is the established tracker for adding physical-key fallbacks when a layout cannot produce punctuation used by default shortcuts. It is already correctly routed and under discussion.

## Change summary

Make punctuation-based default shortcuts usable on layouts that cannot produce the corresponding characters, while preserving layout-native shortcuts.

## Best solution

Extend the missing-character fallback in `MacLinuxKeyboardMapper` beyond Latin letters to carefully selected punctuation such as period and backquote, without globally changing defaults to physical scan codes. Coordinate the broader layout-specific-keybinding alternative with https://github.com/microsoft/vscode/issues/1240.
