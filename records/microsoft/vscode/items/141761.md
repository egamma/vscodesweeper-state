# Issue #141761 — Some default shortcuts don't work with non-english layout: `cmd + .`, etc

[https://github.com/microsoft/vscode/issues/141761](https://github.com/microsoft/vscode/issues/141761)

## Summary

Verified duplicate: the broader open keyboard-layout issue already owns layout-specific default bindings, which would cover the punctuation and physical-key fallback requested here.

## Change summary

Make default shortcuts continue working when users switch to non-English keyboard layouts whose punctuation keys produce different characters.

## Best solution

Consolidate the design work on https://github.com/microsoft/vscode/issues/1240, where keyboard-layout-specific defaults can address punctuation bindings without imposing US physical-key semantics on German, French, Dvorak, and other layouts.
