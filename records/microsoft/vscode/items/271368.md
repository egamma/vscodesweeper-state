# Issue #271368 — Mermaid diagram fails to render with syntax error

[https://github.com/microsoft/vscode/issues/271368](https://github.com/microsoft/vscode/issues/271368)

## Summary

Still reproduces on main: the Mermaid rendering pipeline has no preprocessing to handle special characters (parentheses, Unicode symbols like 𝕏) in node labels that cause Mermaid parser syntax errors. No fix commit references this issue.

## Change summary

Mermaid diagrams generated by the LLM fail to render when node labels contain special characters (parentheses, Unicode) that are invalid in Mermaid syntax.

## Best solution

Either add a preprocessing step in the mermaid-markdown-features extension that quotes/escapes problematic node labels before passing to the Mermaid parser, or improve the system prompt instructions for the LLM to produce valid Mermaid syntax (properly quoting node labels with special characters).
