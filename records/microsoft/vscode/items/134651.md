# Issue #134651 — Add "new folder" option -- to make starting a new project easier.

[https://github.com/microsoft/vscode/issues/134651](https://github.com/microsoft/vscode/issues/134651)

## Summary

Valid feature request for a dedicated 'New Folder/Project' action on the Welcome page; not yet implemented on main. The current UX relies on 'Open Folder' (which can create a folder via the OS dialog), but there's no explicit 'create new project folder' flow. Low upvote count and Backlog milestone — stays open for the community process.

## Change summary

Add a 'New Folder' or 'New Project' option to the Welcome page and File menu to streamline starting a new project from within VS Code.

## Best solution

Consider whether extensions (via project scaffolding APIs) or a lightweight 'Create Folder and Open' command in the getting-started content would best serve this. The core ask — reducing friction for new-project creation — could be addressed with a command that creates a folder via OS dialog and immediately opens it, or by making the existing 'Open Folder' flow more discoverable for folder creation. An extension-contributed 'New Project' walkthrough (as comment #8 suggests) may be the cleanest path.
