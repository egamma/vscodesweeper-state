# Issue #144513 — Remote extension fails to activate in web worker extension host 

[https://github.com/microsoft/vscode/issues/144513](https://github.com/microsoft/vscode/issues/144513)

## Summary

Still reproducible on main: the web worker extension host fetches remote extension code via `fetch()` which fails with CORS on cross-origin embedders (Codespaces, Gitpod). The proposed fix PR was closed without merging, and no alternative fix has landed.

## Change summary

Remote extensions fail to activate in the web worker extension host due to CORS errors when the worker runs on a different origin than the remote server.

## Best solution

Implement alexdima's suggested approach from comment 6: proxy the fetch through the main thread (which shares the remote server's origin) for cross-origin embedder scenarios. The fix would be in `src/vs/workbench/api/worker/extHostExtensionService.ts` around the `_loadCommonJSModule` method. The closed PR #144515 had the right idea but was never merged.
