# Issue #340265 — Language Models editor: groups from different providers all show the header "Copilot"

[https://github.com/microsoft/vscode/issues/340265](https://github.com/microsoft/vscode/issues/340265)

## Summary

Already fixed: the reporter's own follow-up comment identifies this as the same problem as issue #326538, which was fixed by PR #339840 (merged, scoping the Manage Models editor's Copilot lists to the selected harness). Current main already contains that fix.

## Change summary

Manage Models editor shows multiple groups all labelled "Copilot" (regular Copilot vendor, Copilot CLI agent host, Claude agent host) with no way to tell them apart.

## Best solution

Keep the shipped fix (commit 729f257fa411ea4b1cbdb7f404aa79941182209b, milestone 1.142.0): the Manage Models editor now scopes 'Copilot' lists to the harness it was opened for, so the duplicate same-labelled groups no longer appear together. No further change needed beyond confirming on a build that includes the fix.
