# Issue #286275 — Deleting a worktree in the active worktree window causes error

[https://github.com/microsoft/vscode/issues/286275](https://github.com/microsoft/vscode/issues/286275)

## Summary

Team-authored bug, still present on main. The `git.deleteWorktree2` command in the worktree window either shows a blocking error ('switch to main repository first') when the main repo isn't found, or deletes the worktree directory out from under the active window, triggering git errors from subsequent operations on the now-missing working directory. No fix has landed.

## Change summary

Deleting a git worktree from the window that has that worktree open causes a git error instead of gracefully closing or redirecting the window.

## Best solution

After `mainRepository.deleteWorktree()` succeeds in `git.deleteWorktree2` (extensions/git/src/commands.ts ~line 3784), the command should either close the current window or offer to reopen the main repository folder (via `vscode.openFolder` with `forceReuseWindow`). The error path at line 3780 could also be improved to offer opening the main repo instead of just blocking.
