# Issue #286275 — Deleting a worktree in the active worktree window causes error

[https://github.com/microsoft/vscode/issues/286275](https://github.com/microsoft/vscode/issues/286275)

## Summary

The active-worktree deletion path still lacks a graceful workspace transition and can refresh Git state from the directory it has just removed. Keep this accepted, team-authored bug open; no issue-referencing fix or qualifying older duplicate was found.

## Change summary

Deleting the worktree opened in the current window produces a Git error instead of gracefully handling the now-removed workspace.

## Best solution

Make active-worktree deletion finish without Git errors or leave the window pointing at a deleted workspace. The Git owner should settle whether this action closes the window or offers to reopen the main checkout, while preserving cancellation and uncommitted-change safeguards.

- **Trace:**
