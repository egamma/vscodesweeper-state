# Issue #258425 — A better way to manage prompts/instructions/agents with the same name.

[https://github.com/microsoft/vscode/issues/258425](https://github.com/microsoft/vscode/issues/258425)

## Summary

A real gap remains: current main displays user and workspace customizations separately but provides no unified same-name relationship or override model across agents, prompts, instructions, and skills. Keep this Backlog request open as under discussion because the desired precedence and synchronization semantics need product design.

## Change summary

Provide a management model for same-named user- and workspace-level AI customizations without requiring duplicate definitions or duplicate UI entries.

## Best solution

Define consistent cross-scope semantics for same-named customizations, including which definition is effective and whether workspace files override, inherit from, or synchronize with user files. Surface that relationship in the Chat Customizations editor while preserving clear source and version-control ownership.
