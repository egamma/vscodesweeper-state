# Issue #243826 — theme-seti overrides langauge extension icons by file extension, not by language

[https://github.com/microsoft/vscode/issues/243826](https://github.com/microsoft/vscode/issues/243826)

## Summary

The stale `.sss` association remains in the generated Seti theme, but the maintainer's attempted core fix was explicitly closed with “no plans to implement.” The general precedence of theme file-extension associations over language icons is intentional, so the remaining Seti-specific correction is declined for core.

## Change summary

Prevent the generated Seti icon theme's `.sss` association from overriding the icon contributed by an installed language extension.

## Best solution

Keep VS Code's established icon-association precedence unchanged. Any remaining correction should remove the obsolete `.sss` mapping from the upstream Seti theme data rather than add a VS Code-specific exception.
