# Issue #243826 — theme-seti overrides langauge extension icons by file extension, not by language

[https://github.com/microsoft/vscode/issues/243826](https://github.com/microsoft/vscode/issues/243826)

## Summary

The accepted Seti-specific bug remains on current main: `.sss` is still assigned the CSS icon ahead of the contributed language icon. The attempted fix was closed without merging, so there is no factual basis for a completed or duplicate close.

## Change summary

Stop the generated Seti theme from treating `.sss` as CSS when a language extension contributes its own icon.

## Best solution

Preserve the established icon-theme precedence while removing the unintended `.sss` association from the generated Seti theme, ideally through a durable exclusion in its update script or an upstream Seti mapping change.
