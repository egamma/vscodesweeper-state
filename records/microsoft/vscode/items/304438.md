# Issue #304438 — Copilot CLI "Apply" button appears after all changes are already committed

[https://github.com/microsoft/vscode/issues/304438](https://github.com/microsoft/vscode/issues/304438)

## Summary

The Apply action is intentional for isolated worktree sessions: committing or pushing the session branch does not transfer its changes into the primary workspace.

## Change summary

Hide the Copilot CLI Apply action after worktree changes have been committed and pushed.

## Best solution

Keep Apply available while the isolated branch differs from the session base; it should disappear only after those changes are applied to the primary workspace.

  > Thanks for the report. In a worktree session, committing or pushing records the changes on the isolated session branch but does not transfer them into the primary workspace. The Apply action intentionally remains available to perform that transfer, and the changes are cleared after Apply advances the session base. This is therefore working as designed.
