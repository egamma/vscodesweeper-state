The CLI session implementation has evolved since the reported build, including migration toward Agent Host, but the supplied worktree, commit, and push steps suffice to retest; no verified fix or canonical duplicate covers this exact case.

## Change summary

The Copilot CLI worktree session continues showing changed files and an Apply button after the reporter has committed and pushed the changes.

## Best solution

Ensure Apply accurately represents changes still needing transfer into the destination workspace, without treating a clean or committed source worktree as proof that transfer is unnecessary. First establish whether the reported changes were already present in the destination or remained only on the worktree branch.
