# Issue #304438 — Copilot CLI "Apply" button appears after all changes are already committed

[https://github.com/microsoft/vscode/issues/304438](https://github.com/microsoft/vscode/issues/304438)

## Summary

Clarify whether the changes were committed only in the CLI worktree or also incorporated into the destination workspace. Current source intentionally offers committed worktree changes for application elsewhere, so committing and pushing alone does not establish a redundant Apply action.

## Change summary

The CLI session continues showing an Apply panel after the reporter commits and pushes its changes.

## Best solution

Preserve application of committed worktree changes that are absent from the destination workspace. If the destination already contains those changes, establish a current reproduction and make the session's apply availability reflect that state.
