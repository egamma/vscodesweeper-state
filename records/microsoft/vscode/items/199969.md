# Issue #199969 — Add functionality to control ordinal type for headers within nb outline view

[https://github.com/microsoft/vscode/issues/199969](https://github.com/microsoft/vscode/issues/199969)

## Summary

Headers-only filtering is available, but configurable hierarchical heading numbering remains missing. Keep this issue as the maintainer-selected consolidation point; the closed enhancement tracker and newer icon-only reports do not absorb its remaining scope.

## Change summary

Support configurable hierarchical numbering of notebook outline headings, with headers-only filtering and optional removal of outline icons.

## Best solution

Define an opt-in hierarchical numbering experience for notebook outline headings, including ordinal formats and update behavior when headings change. Preserve the existing headers-only filter and coordinate icon visibility with the separate outline.icons reports.
