# Issue #199969 — Add functionality to control ordinal type for headers within nb outline view

[https://github.com/microsoft/vscode/issues/199969](https://github.com/microsoft/vscode/issues/199969)

## Summary

Part 1 (show only headers in outline) is fully implemented via `notebook.outline.showMarkdownHeadersOnly` (PR #207771, March 2024). Part 2 (ordinal numbering) is a niche formatting request already tracked within the now-closed umbrella #206308. The core ask is resolved by the existing setting; the numbering aspect is extension territory (like the Obsidian plugin the reporter references). Proposing duplicate against #200060 which owns the central delivered work.

## Change summary

Request to show only markdown headers in notebook outline and add automatic ordinal numbering to those headers.

## Best solution

The central ask is shipped: `notebook.outline.showMarkdownHeadersOnly` filters the outline to headers only. The ordinal numbering feature (auto-numbering like 1.1, 1.2.1) is a specialized formatting concern best delivered by an extension, similar to Obsidian's Number Headings plugin.
