# Issue #285684 — Suggestion: Wording / naming could be clearer for background agent worktrees and merging those change back in current branch.

[https://github.com/microsoft/vscode/issues/285684](https://github.com/microsoft/vscode/issues/285684)

## Summary

Keep open: current source still contains the ambiguous Copy/Move/Skip prompt and the workbench's short Apply label, although newer integration actions provide partial coverage. This team-authored report spans several distinct UX concerns; none of the verified older issues owns its full scope.

## Change summary

Clarify background-agent working locations, change-transfer destinations, integration actions, and worktree cleanup without requiring users to infer Git mechanics.

## Best solution

Make background-agent actions explain their source, destination, and retained state consistently across chat and SCM. Agree separately whether completing integration should retain a resumable session or offer explicit cleanup; existing merge and branch-naming capabilities do not settle that lifecycle choice.
