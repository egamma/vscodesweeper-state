## Summary

Team-authored UX polish suggestion about confusing worktree terminology and merge workflow in background agents. Valid feedback on an active area of development — keep open for the agents/git teams to consider.

## Change summary

Background agent worktree dialogs use unclear terminology (workspace vs worktree, Copy/Move/Skip vs Include/Exclude) and the apply/merge workflow is confusing.

## Best solution

Clarify the worktree reuse dialog options (replace Copy/Move/Skip with language matching the question), make the Apply button's target explicit, and consider a more branch/PR-like metaphor for bringing background agent changes back to the working branch. Likely spans the agents window UX and git worktree integration.
