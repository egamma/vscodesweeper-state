# Issue #285684 — Suggestion: Wording / naming could be clearer for background agent worktrees and merging those change back in current branch.

[https://github.com/microsoft/vscode/issues/285684](https://github.com/microsoft/vscode/issues/285684)

## Summary

Keep open for a focused background-agent workflow design review: current commands partially address applying and merging changes, but do not fully resolve the terminology and worktree-lifecycle confusion. No verified older canonical covers the full report, and this team-authored item has no issue-linked fixing commit.

## Change summary

Clarify background-agent worktree terminology, change-transfer destinations, and the workflow for integrating changes and retiring the worktree.

## Best solution

Make the source, destination, and consequences of Copy, Move, Apply, and Merge understandable before invocation, with a clear distinction between a branch and its worktree. Decide separately whether integration should offer an explicit finish-and-clean-up operation or retain the session for continued work.
