# Issue #318548 — Link provider runs for test results diff view, but not test results output view

[https://github.com/microsoft/vscode/issues/318548](https://github.com/microsoft/vscode/issues/318548)

## Summary

Extension-provided links remain unsupported in the detached terminal used for test output. This is an established API limitation rather than a broken terminal-provider contract; keep the request open for testing and terminal API design.

## Change summary

Allow extensions to detect and activate custom-scheme links in raw test-results output, as they can in test-result editor content.

## Best solution

Provide a supported extension link-detection contract for test-output text, including precise ranges and extension-controlled activation. Resolve the context/API boundary rather than treating arbitrary Ctrl+Click fallback or structured stack frames as equivalent coverage.
