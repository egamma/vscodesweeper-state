# Issue #160765 — SCM - Shell integration ignores env overrides when opening from SCM panel?

[https://github.com/microsoft/vscode/issues/160765](https://github.com/microsoft/vscode/issues/160765)

## Summary

Still reproducible on main: the `openInIntegratedTerminal` command creates terminals with `{ config: { cwd } }`, which is truthy and bypasses the default profile resolution in `createTerminal` — so env overrides from the user's default terminal profile are not applied. The `help wanted` label and `On Deck` milestone are appropriate; keeping open.

## Change summary

Opening a terminal from the SCM panel context menu ignores env overrides defined in the user's default terminal profile.

## Best solution

Fix the `openInIntegratedTerminal` handler in `src/vs/workbench/contrib/externalTerminal/browser/externalTerminal.contribution.ts` (line 77) to pass `cwd` separately rather than as part of `config`, so `createTerminal` falls through to `getDefaultProfile()` and picks up env overrides. Alternatively, resolve the default profile explicitly and merge `cwd` into it before calling `createTerminal`.
