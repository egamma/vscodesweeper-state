# Issue #336314 — Agents window: Sync Changes shows up for a branch tracking a local branch, and fails when clicked

[https://github.com/microsoft/vscode/issues/336314](https://github.com/microsoft/vscode/issues/336314)

## Summary

Confirmed in source: `AgentHostSyncOperationContribution.getOperations` (src/vs/platform/agentHost/node/agentHostSyncOperationProvider.ts) only checks `gitState?.upstreamBranchName`, not whether that upstream is actually a remote-tracking branch, so it offers Sync Changes for a branch tracking a local branch and the sync then fails. An open PR already fixes exactly this, so the issue should stay open pending that PR landing rather than being closed or auto-fixed here.

## Change summary

Agents window offers a 'Sync Changes' action for a branch whose upstream is another local branch (not a remote), and clicking it always fails with a remote-resolution error.

## Best solution

Land https://github.com/microsoft/vscode/pull/336309 ('agentHost: only offer Sync Changes for a remote-tracking upstream'), which appears to directly address this by restricting the Sync Changes operation to remote-tracking upstreams.
