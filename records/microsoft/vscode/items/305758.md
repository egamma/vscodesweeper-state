# Issue #305758 — Model picker does nothing when opened from the ellipsis menu

[https://github.com/microsoft/vscode/issues/305758](https://github.com/microsoft/vscode/issues/305758)

## Summary

The reported overflow-selection defect is resolved by a landed change that creates a live model picker for the ellipsis menu instead of reopening the disposed toolbar item. Tracing the supplied steps through current main shows selection reaching the chat input's model state.

## Change summary

Choosing a model through the narrow Chat pane's ellipsis menu leaves subsequent requests using the previously selected model.

## Best solution

Treat this as completed by https://github.com/microsoft/vscode/commit/d77fa1711fcb0501c1049795fd8fbaddfb3a57ea, preserving the dedicated overflow picker and its live selection delegate.
