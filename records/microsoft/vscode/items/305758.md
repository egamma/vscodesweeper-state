# Issue #305758 — Model picker does nothing when opened from the ellipsis menu

[https://github.com/microsoft/vscode/issues/305758](https://github.com/microsoft/vscode/issues/305758)

## Summary

Hard keep-open: issue carries the `important` label. The bug is real and appears unfixed on main — the model picker opened from the overflow/ellipsis menu fires the `OpenModelPickerAction` which calls `this.modelWidget?.show()`, but when the toolbar's responsive behavior hides the model picker, the delegate's `setModel` callback may not propagate the selection correctly because the widget was created inline and then hidden by the responsive toolbar.

## Change summary

Selecting a model via the model picker opened from the chat pane's overflow/ellipsis menu does not actually change the active model.

## Best solution

Trace the interaction between `ModelPickerActionItem`, its delegate's `setModel`, and the toolbar's responsive overflow in `src/vs/workbench/contrib/chat/browser/widget/input/chatInputPart.ts`. The likely fix is ensuring that when the model picker is opened from the overflow menu (via `openModelPicker()` → `this.modelWidget?.show()`), the picker's `onDidChangeSelection` → `delegate.setModel` path correctly calls `setCurrentLanguageModel` and the model actually updates. One community confirmation in the comments.
