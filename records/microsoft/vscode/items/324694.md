# Issue #324694 — Failed task terminal title is not red when active/focus

[https://github.com/microsoft/vscode/issues/324694](https://github.com/microsoft/vscode/issues/324694)

## Summary

Confirmed visual bug: the generic `.monaco-list:focus .selected .monaco-icon-label { color: inherit !important }` rule in iconlabel.css overrides the error-status foreground color on the terminal tab when it is focused+selected. An open PR (#324698) addresses this but has not merged.

## Change summary

A failed task's terminal tab title loses its red error color when the tab is focused/selected, reverting to the default text color.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/324698, which adds CSS specificity overrides in terminal.css and status classes in terminalTabsList.ts to preserve error/warning foreground colors when the tabs list is focused.
