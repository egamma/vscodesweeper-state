# Issue #281988 — Git - Commit Message Doesn't Overwrite User Message

[https://github.com/microsoft/vscode/issues/281988](https://github.com/microsoft/vscode/issues/281988)

## Summary

Keep open: commit-message generation still replaces the entire input, and custom style instructions do not preserve a prefix typed for an individual commit. Maintainers have explicitly consolidated matching requests into this issue, so it remains the canonical request.

## Change summary

Let Copilot complete a partially written commit message without overwriting unselected text, including a user-chosen conventional-commit prefix.

## Best solution

Support draft-preserving completion in the SCM commit-message action, with replacement limited to explicitly selected text. Plan the selection-aware SCM integration before implementation; passing the draft as model context alone would not guarantee preservation.
