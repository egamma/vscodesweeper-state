# Issue #336590 — [NES] Next Edit Suggestion data privacy and allow to change model provider

[https://github.com/microsoft/vscode/issues/336590](https://github.com/microsoft/vscode/issues/336590)

## Summary

A data-privacy/consent concern about NES being on by default, plus a request to choose a different model provider, is a policy question a maintainer should weigh in on — existing settings partially address it but don't fully cover 'change provider'.

## Change summary

Reporter wants Next Edit Suggestions (NES) to be opt-in (or clearly disclosed) rather than on by default, and wants the ability to change the model provider it uses, not just the model.

## Best solution

Point to the existing opt-out (`github.copilot.nextEditSuggestions.enabled`) and model-selection (`github.copilot.nextEditSuggestions.preferredModel`) settings; the remaining ask — using a non-Copilot provider/backend for NES — is a product/architecture decision for the Copilot Chat team, not a quick code change.
