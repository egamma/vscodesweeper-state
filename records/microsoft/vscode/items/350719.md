# Issue #350719 — Testing API: allow an extension to select an existing run's coverage, or to publish coverage without a Test Results entry

[https://github.com/microsoft/vscode/issues/350719](https://github.com/microsoft/vscode/issues/350719)

## Summary

Current source confirms a missing extension API: existing coverage can be selected internally, but extensions cannot reselect a completed run without creating additional results. Keep open for Testing API owner consideration; the related reports do not own this capability.

## Change summary

Allow extensions to switch between stored coverage reports in the native coverage UI without adding a Test Results entry on every switch.

## Best solution

Provide an owner-approved API for selecting coverage already associated with a retained run, preserving normal result history and disposal semantics. Consider hidden coverage-only runs only if selecting existing coverage cannot meet the intended workflow.
