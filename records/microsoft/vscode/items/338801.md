# Issue #338801 — Copilot Chat OTel: set service.instance.id on the resource

[https://github.com/microsoft/vscode/issues/338801](https://github.com/microsoft/vscode/issues/338801)

## Summary

Still valid on current main: the Copilot Chat OTel resource is built without `service.instance.id`, so Prometheus-style backends collapse every window's cumulative metrics into one series. Small, well-scoped gap in the OTel resource construction — keep open and fix in `otelServiceImpl.ts`.

## Change summary

Add a per-window `service.instance.id` resource attribute to the Copilot Chat OTel resource so cumulative metrics from different windows/users form distinct series.

## Best solution

Set `service.instance.id` on the resource built in `extensions/copilot/src/platform/otel/node/otelServiceImpl.ts` (reusing the already-exported per-window `session.id` value is the simplest conforming choice), so Prometheus-compatible backends get a distinct `instance` per window and `sum()` aggregates correctly.
