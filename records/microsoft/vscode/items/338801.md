# Issue #338801 — Copilot Chat OTel: set service.instance.id on the resource

[https://github.com/microsoft/vscode/issues/338801](https://github.com/microsoft/vscode/issues/338801)

## Summary

Confirmed on main: the Copilot Chat OTel resource sets service.name, service.version, and session.id but never service.instance.id, so this is a real, unaddressed gap worth fixing — a small, well-specified addition rather than a design question.

## Change summary

Add service.instance.id to the OTel resource attributes emitted by Copilot Chat so Prometheus-style backends can distinguish per-window/per-instance series.

## Best solution

Set service.instance.id in the resourceFromAttributes call in otelServiceImpl.ts, reusing the existing session.id (or a generated UUID) as its value, matching OTel semantic conventions.
