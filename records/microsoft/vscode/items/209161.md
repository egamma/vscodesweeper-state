# Issue #209161 — Selecting symbol from notebook outline doesn't highlight in editor properly

[https://github.com/microsoft/vscode/issues/209161](https://github.com/microsoft/vscode/issues/209161)

## Summary

Still reproduces on main: the `reveal` method in `notebookOutline.ts` passes `entry.position` (a cursor position) as the `selection` in editor options, which only places the cursor — it does not highlight or select the symbol range. Two community PRs are open to fix this.

## Change summary

Selecting a symbol from the notebook outline navigates to the cell but does not highlight or select the symbol line/range in the editor.

## Best solution

Review and land one of the two open PRs (https://github.com/microsoft/vscode/pull/251149 or https://github.com/microsoft/vscode/pull/318072) that change the `reveal` method to use the symbol's range instead of just its position, so the symbol is highlighted in the editor on reveal — similar to how the text editor outline behaves.
