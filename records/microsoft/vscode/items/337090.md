# Issue #337090 — Open in VS Code seems to kill the tunnel connection

[https://github.com/microsoft/vscode/issues/337090](https://github.com/microsoft/vscode/issues/337090)

## Summary

Keep open: a team member reproduced the tunnel-backed Dev Container handoff failure while executing the current test plan, and current source does not establish a fix. The issue already has appropriate ownership labels and is parked in the On Deck holding milestone.

## Change summary

Opening a tunnel-backed Dev Container session in a VS Code editor window fails to finish loading and appears to terminate the tunnel connection used by the Agents window.

## Best solution

Diagnose the ownership and lifetime of the nested Tunnel → Dev Container connection during editor handoff, then ensure opening the editor can establish its Dev Container remote authority without disposing the Agents window's active Agent Host transport.
