# Issue #156830 — Emmet wrapWithAbbreviation expands the selection when used within JSX attributes

[https://github.com/microsoft/vscode/issues/156830](https://github.com/microsoft/vscode/issues/156830)

## Summary

Still reproduces on main: the wrapWithAbbreviation logic at lines 52-75 of abbreviationActions.ts unconditionally expands any selection inside an open/close tag to encompass the entire node, which is incorrect for selections within attribute values (especially multi-line JSX attributes).

## Change summary

Emmet wrapWithAbbreviation expands the user's selection to the full element when the selection is within JSX/HTML attribute values inside an open tag.

## Best solution

The expand-to-node logic in `extensions/emmet/src/abbreviationActions.ts` (lines 52-75) should be refined to not expand the selection when the user has explicitly selected text within attribute values. The heuristic should only expand when the selection is on the tag name or bracket characters, not when it's clearly within attribute content.
