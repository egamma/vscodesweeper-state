# Issue #169900 — [scss] Display a wrong selector preview when using sibling combinators in SCSS, Less

[https://github.com/microsoft/vscode/issues/169900](https://github.com/microsoft/vscode/issues/169900)

## Summary

The defect remains visible in the current CSS language-service source and belongs upstream in that dependency. The issue should stay open until the selector printer correctly composes nested parent selectors with sibling combinators and VS Code consumes the fix.

## Change summary

SCSS and Less selector hovers place a nested parent selector incorrectly when the parent rule uses an adjacent or general sibling combinator.

## Best solution

Fix nested `&` composition in `SelectorElementBuilder` within microsoft/vscode-css-languageservice, add SCSS and Less regression tests for both `+` and `~`, then update the language-service version consumed by VS Code.
