# Issue #303033 — Multiple active browser tools in GitHub Copilot Chat create ambiguous command routing and break autonomous/programmatic usage

[https://github.com/microsoft/vscode/issues/303033](https://github.com/microsoft/vscode/issues/303033)

## Summary

Keep open as a request for explicit browser-provider coordination. Current tool dispatch uses a specific tool ID rather than arbitrarily choosing an implementation, but existing manual tool selection does not provide the requested overlap detection or browser-owner guidance.

## Change summary

Make overlapping integrated-browser and MCP browser capabilities visible and provide an explicit way to keep an agent's browser interactions on the intended provider.

## Best solution

Evaluate provider-selection guidance in the browser/chat tool experience, distinguishing model selection of different tools from incorrect dispatch of one tool ID. Preserve intentional use of multiple providers; automatic disabling or exclusive ownership needs a maintainer decision supported by an actual mixed-provider invocation trace.
