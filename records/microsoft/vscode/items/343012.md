# Issue #343012 — Chat editor: show the tool name for MCP tool calls

[https://github.com/microsoft/vscode/issues/343012](https://github.com/microsoft/vscode/issues/343012)

## Summary

The current UI already shows an MCP tool's human-readable title and server, as the commenter points out, but that title can replace the actual tool name. Keep this open as a request to expose the exact called tool name rather than a defect where all tool identification is missing.

## Change summary

Expose the exact MCP tool name alongside its human-readable title and server in chat tool-call details.

## Best solution

Make the exact MCP tool name discoverable in the expanded invocation while retaining the readable title and existing server attribution. Apply the behavior consistently to the shared chat renderer rather than introducing an editor-tab-only variant.
