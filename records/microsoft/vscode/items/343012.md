# Issue #343012 — Chat editor: show the tool name for MCP tool calls

[https://github.com/microsoft/vscode/issues/343012](https://github.com/microsoft/vscode/issues/343012)

## Summary

Keep open as a request for reliable MCP tool identification. Current code displays the server and a tool title, but that title can replace the actual tool name; expanded input/output does not independently expose the name.

## Change summary

Show the actual MCP tool name alongside its server when reviewing a tool invocation in the Chat editor.

## Best solution

Make the exact MCP tool identity discoverable in the expanded invocation while retaining readable titles and server attribution. This belongs in the shared chat tool-invocation presentation rather than an editor-tab-only implementation.
