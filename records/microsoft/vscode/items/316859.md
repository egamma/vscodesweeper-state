# Issue #316859 — MCP workspace configuration processed in Restricted Mode — Workspace Trust boundary violation

[https://github.com/microsoft/vscode/issues/316859](https://github.com/microsoft/vscode/issues/316859)

## Summary

The MCP subsystem discovers workspace server definitions in Restricted Mode (to display them in the UI), but blocks actual server process execution via a workspace trust gate in `_checkTrust`. The autostart path uses `errorOnUserInteraction: true`, which throws `UserInteractionRequiredError('workspaceTrust')` and prevents launch. MSRC closure confirms no exploitable boundary violation.

## Change summary

Reporter claims workspace-defined MCP servers execute in Restricted Mode, bypassing Workspace Trust.

## Best solution

Close as designed. Discovery (reading `.vscode/mcp.json`) is intentional for UI display; execution is gated by workspace trust. If the reporter can demonstrate actual command execution (calc.exe launching) without granting trust on the current build, that would warrant reopening — but the code path and MSRC closure indicate the gate is effective.
