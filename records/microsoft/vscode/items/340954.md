# Issue #340954 — Copilot Chat: Session Target Harness silently reverts back to Copilot/Agent Host instead of persisting 'Local'

[https://github.com/microsoft/vscode/issues/340954](https://github.com/microsoft/vscode/issues/340954)

## Summary

Thanks for the report. The steps are clear, but I couldn't confirm them without running the code. The harness default is driven by the `chat.defaultToCopilotHarness` and `chat.editor.preferCopilotHarness` settings, and a maintainer comment points to workaround settings. Whether the picker should remember an explicit 'Local' choice is a product decision, so this stays open.

## Change summary

A new chat session resets the Session Target harness to Copilot instead of remembering the user's last 'Local' choice.

## Best solution

Decide whether an explicit 'Local' harness choice should persist across new chats. If yes, store it in the session target picker (sessionTargetPickerActionItem.ts) and let it override the Copilot-harness defaults. If not, document the settings that control the default.
