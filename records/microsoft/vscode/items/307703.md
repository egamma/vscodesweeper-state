# Issue #307703 — Settings view Shift+Tab jumps focus back to editor unexpectedly

[https://github.com/microsoft/vscode/issues/307703](https://github.com/microsoft/vscode/issues/307703)

## Summary

Keep open: a maintainer confirmed that Shift+Tab unexpectedly leaves Settings in both overlaid and docked layouts. Source inspection does not establish a fix, and the older related reports do not demonstrably own this exact editor-focus escape.

## Change summary

Shift+Tab unexpectedly moves focus from the Settings UI back to the text editor instead of the preceding Settings control.

## Best solution

Restore logical reverse keyboard navigation in the Settings editor without trapping focus or changing normal arrow-key navigation. First identify the exact focus transition in both docked and overlaid layouts, then capture it in a regression check.
