# Issue #298034 — Browser needs repeated allow while I had already allowed the domain

[https://github.com/microsoft/vscode/issues/298034](https://github.com/microsoft/vscode/issues/298034)

## Summary

Keep open: session approval remains tool-specific, so opening a site does not approve subsequent navigation by the separate browser navigation tool. A maintainer-owned draft PR explicitly targets this issue and is still open; its approval semantics need review before this can be considered fixed.

## Change summary

Honor an approved website across browser opening and same-site navigation without repeatedly prompting during the session.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/298120 against the requested session-scoped, same-site approval behavior. Its proposed persistent URL approvals shared with fetch should be evaluated explicitly rather than assumed equivalent to the reported session approval.
