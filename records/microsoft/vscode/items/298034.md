# Issue #298034 — Browser needs repeated allow while I had already allowed the domain

[https://github.com/microsoft/vscode/issues/298034](https://github.com/microsoft/vscode/issues/298034)

## Summary

Still reproduces on main: each browser tool (openBrowserTool, navigateBrowserTool) independently checks `isUriAllowed` per full URL, so allowing `localhost:3000` does not carry over to `localhost:3000/prototypes/counter-demo`. An open PR (#298120) is already working on shared domain-level approval.

## Change summary

Browser tool URL approval is per-exact-URL instead of per-domain, causing repeated permission prompts for the same site.

## Best solution

Land the open PR (https://github.com/microsoft/vscode/pull/298120) that shares approval state across `openBrowserPage`, `navigatePage`, and `fetch` tools at the domain level rather than the full URL level.
