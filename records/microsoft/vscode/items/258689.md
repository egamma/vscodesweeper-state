# Issue #258689 — canceled chats have checkmarks

[https://github.com/microsoft/vscode/issues/258689](https://github.com/microsoft/vscode/issues/258689)

## Summary

The misleading success state remains on current main: canceled local-chat responses are explicitly converted to the same Completed session status used for successful responses. The session history therefore cannot render or announce cancellation distinctly.

## Change summary

Show canceled chats as canceled in session history instead of presenting them with the successful-completion status.

## Best solution

Represent cancellation as a distinct chat-session status and give it a localized “Canceled” label and non-success icon throughout the session list, hover, filtering, and accessibility paths, while preserving the existing states for successful, failed, active, and input-needed sessions.
