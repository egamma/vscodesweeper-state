NotebookCellOutputVariable in panel/notebookVariables.tsx renders labeled output and cleans error stacks, while the separate NotebookVariables component retrieves runtime variables through INotebookService.getVariables. Source inspection establishes partial existing capability, not completion of the requested heuristic.
