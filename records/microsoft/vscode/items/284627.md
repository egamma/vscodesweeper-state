# Issue #284627 — Allow agent skill scripts to retrieve the workspace root/workspace file

[https://github.com/microsoft/vscode/issues/284627](https://github.com/microsoft/vscode/issues/284627)

## Summary

Valid feature request to pass workspace root reliably to agent skill scripts. A team member (aeschli) acknowledged the issue and agreed the workspace_info section needs improvement. No fix or implementation found on current main. On Deck milestone; keeping open.

## Change summary

Agent skill scripts have no reliable way to determine the workspace root — the CWD is non-deterministic and environment-variable or argument-based workarounds depend on the LLM.

## Best solution

Expose a deterministic environment variable (e.g. `VSCODE_WORKSPACE_ROOT`) to processes spawned by skill scripts, or ensure the agent harness always sets a stable CWD. The team member's suggestion to clean up the `workspace_info` system prompt section (pointing to tasks.json instead of inlining tasks) is a related improvement. Implementation likely touches the skill script execution paths in `extensions/copilot/src/extension/chatSessions/` and possibly the agent host layer.
