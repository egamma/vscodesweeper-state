# Issue #296579 — Recommended models are all disabled

[https://github.com/microsoft/vscode/issues/296579](https://github.com/microsoft/vscode/issues/296579)

## Summary

Keep open: the default model picker can still put every selectable model behind Other Models when all promoted recommendations are unavailable. This is also a team-authored, On Deck item that a maintainer explicitly asked to keep open and revisit after further user feedback, which the thread subsequently received.

## Change summary

Ensure a managed account sees at least one selectable model in the model picker's promoted section when all curated recommendations are disabled.

## Best solution

Preserve unavailable recommendations so users can discover models to request, but promote at least one suitable enabled model above the collapsed section. The model-picker owners should settle the fallback ranking and how many unavailable recommendations remain visible.
