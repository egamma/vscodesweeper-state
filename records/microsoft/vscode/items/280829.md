# Issue #280829 — Copilot Code Review does not use `/instruction/**/NAME.instructions.md` files

[https://github.com/microsoft/vscode/issues/280829](https://github.com/microsoft/vscode/issues/280829)

## Summary

Keep open: current local code review still lacks automatic discovery of path-specific instruction files. A maintainer explicitly reopened this as valid work; review latency is tracked separately, and the newer SCM report is not a canonical for this older issue.

## Change summary

Automatically include applicable .github/instructions/**/*.instructions.md files when reviewing selected code or local changes.

## Best solution

Make local code review consume applicable repository instructions with correct file scoping, while preserving existing global instructions and explicit settings. Keep this issue focused on instruction support, not review latency or GitHub-hosted PR review.

- **Trace:**

  > ReviewSession.performReview in extensions/copilot/src/extension/review/node/doReview.ts selects the GitHub review path for enabled accounts. githubReviewAgent.ts constructs coding-guideline references through loadCustomInstructions, whose file discovery is limited by CustomInstructionsService.getAgentInstructions to global instruction files. AutomaticInstructionsCollector separately discovers path-specific instructions through IPromptsService and performs applyTo matching, but its chat-oriented context and outputs are not connected to local review. Existing tests in githubReviewAgent.spec.ts cover global files, settings, and language filters, not path-specific discovery. Preserve existing review settings and global behavior; do not assume instruction loading guarantees model compliance. Related SCM report: https://github.com/microsoft/vscode/issues/299447.
- **Open decisions:**
  - Should local review automatically include only instruction files whose applyTo patterns match reviewed files, or also include review-specific files without applyTo, which chat currently exposes through mechanisms other than automatic attachment?
