# Issue #332747 — Unintentionally closing 'Other' tabs

[https://github.com/microsoft/vscode/issues/332747](https://github.com/microsoft/vscode/issues/332747)

## Summary

Verified duplicate of the open canonical issue #331979, which fully describes and diagnoses the same defect (Alt-key hover state getting stuck after an OS-level Alt-Tab, turning a tab's close button into 'Close Others' without warning); a maintainer already posted the /duplicate slash command.

## Change summary

Alt-Tabbing away from and back to VS Code can leave a tab's close button stuck in the 'Close Other Editors' swapped state, so clicking it closes all other tabs unexpectedly.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/331979, which already traces the root cause (ModifierKeyEmitter clearing altKey on window blur while MultiEditorTabsControl's hoveredTabIndex is not cleared on blur) and suggests a fix; that issue is mid-verification (verification-found) so it should not itself be closed yet, but it fully absorbs this report.
