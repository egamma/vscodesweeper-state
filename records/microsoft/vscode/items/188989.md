# Issue #188989 — [themes] mark favorites themes

[https://github.com/microsoft/vscode/issues/188989](https://github.com/microsoft/vscode/issues/188989)

## Summary

Keep this accepted Backlog feature request open: it exceeded the 20-upvote threshold, and a theme-area maintainer agreed that favorites make sense while narrowing the unresolved design away from arbitrary custom categories.

## Change summary

Allow users to mark color themes as favorites so preferred themes are easier to find and switch between.

## Best solution

Design a lightweight favorites model in the color-theme picker and theme service, with persistence and ordering semantics settled before implementation; avoid expanding the first version into arbitrary custom categories or automated theme playlists.

## Plan brief

- **Likely files:** `src/vs/workbench/services/themes/common/workbenchThemeService.ts`, `src/vs/workbench/contrib/themes/browser/themes.contribution.ts`
- **Validation:** Add focused theme-service and theme-picker tests showing that favorited color themes persist, appear in the agreed location and order, and that non-favorite dark, light, and high-contrast grouping remains unchanged.
- **Behavior:**

  > Users can mark and unmark installed color themes as favorites and quickly find those themes in the color-theme selection experience. Favorite state persists according to the chosen scope and has deterministic ordering. Existing dark, light, and high-contrast categorization remains available, and the initial feature does not add arbitrary named categories or automatic theme rotation unless separately approved.
- **Trace:**

  > The issue was explicitly narrowed by the theme-area maintainer from custom categories to favorites, and it passed the community threshold into Backlog. The supplied candidate issues cover unrelated product-icon and Marketplace concepts, so no canonical duplicate was identified.
