# Issue #308400 — Invoking a .prompt.md file via /command permanently locks the chat session to Ask mode

[https://github.com/microsoft/vscode/issues/308400](https://github.com/microsoft/vscode/issues/308400)

## Summary

Keep open: the supplied steps suffice to retest the persistent loss of tools after invoking a prompt file. Current main explicitly handles prompt agent metadata and scopes tool selections by session and mode, but source inspection did not establish the reported failure or a concrete fixing commit.

## Change summary

Invoking a prompt slash command reportedly disables tools for the entire session despite agent frontmatter and subsequent selection of Agent mode.

## Best solution

Ensure prompt invocation honors the selected agent and that later Agent-mode requests use the enabled tools shown by the UI. First reproduce the initial invocation and subsequent-message failure, distinguishing actual tool disablement from a model incorrectly claiming it is in Ask mode.
