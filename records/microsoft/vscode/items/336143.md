# Issue #336143 — Agents window Markdown preview renders link reference definitions instead of hiding them

[https://github.com/microsoft/vscode/issues/336143](https://github.com/microsoft/vscode/issues/336143)

## Summary

Keep open: the bundled Markdown editor explicitly preserves reference definitions as unhandled blocks and renders their source visibly. The remaining work belongs in the @vscode/markdown-editor dependency, with adoption verified in the Agents window.

## Change summary

Hide link reference definitions in the Agents window's rendered Markdown while preserving reference links and the underlying document.

## Best solution

Make reference definitions non-rendering metadata in the Markdown editor's reading presentation, without losing source text or reference resolution. Address this in microsoft/vscode-packages and consume the corrected behavior through the built-in Markdown editor integration.
