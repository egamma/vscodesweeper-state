## Summary

Keep open: the block cursor redraws injected hint text using the editor font rather than the smaller inlay-hint font. Related cursor-position fixes are under review, but neither a completed fix nor a policy-valid duplicate was established.

## Change summary

A blinking block cursor over an inlay hint makes the covered character alternate between the hint font size and the larger editor font size.
