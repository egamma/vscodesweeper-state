# Issue #332241 — Agents Window does not forward Copilot CLI experiment settings (chat.agentHost.copilot.*, chat.copilot.*) into the local agent host root config

[https://github.com/microsoft/vscode/issues/332241](https://github.com/microsoft/vscode/issues/332241)

## Summary

Confirmed on main by reading the source: `AgentHostCopilotCliSettingsContribution` is registered in the workbench's `agentHost.contribution.ts` but not in `src/vs/sessions`'s `localAgentHost.contribution.ts`, so Copilot CLI experiment settings never reach the local agent host root config in the standalone Agents Window.

## Change summary

The Agents Window's local-agent-host contribution module omits the settings contribution that forwards `chat.agentHost.copilot.*`/`chat.copilot.*` settings into the agent host's root config, so those settings have no effect there.

## Best solution

Import and register `AgentHostCopilotCliSettingsContribution` in `src/vs/sessions/contrib/providers/agentHost/browser/localAgentHost.contribution.ts` alongside the other `registerWorkbenchContribution2` calls, mirroring `src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHost.contribution.ts:38`.
