# Issue #329722 — agentHost: adding a Claude credential while gated at "Sign in to use Agents" needs a restart

[https://github.com/microsoft/vscode/issues/329722](https://github.com/microsoft/vscode/issues/329722)

## Summary

Verified against current main: neither the protected-resources gate nor the model refresh scheduler has any reactive path when a Claude credential appears while the agent host is gated with zero sessions — the reporter's diagnosis matches the code exactly, and this remains unfixed as of the latest commit touching these files.

## Change summary

After hitting the signed-out 'Sign in to use Agents' gate and then adding a valid Claude credential (env var or ~/.claude/settings.json), the gate never lifts until the app restarts.

## Best solution

Implement the sketched fix: add an optional `onDidChangeProtectedResources` event to `IAgent` (alongside the existing optional `onDidChangeSessionList` at src/vs/platform/agentHost/common/agentService.ts:1589), wire it in `AgentSideEffects._registerAgentListeners` (src/vs/platform/agentHost/node/agentSideEffects.ts) next to the `onDidCustomizationsChange` handling around line 629-631, and give `ClaudeAgent` an agent-lifetime credential watcher (src/vs/platform/agentHost/node/claude/claudeAgent.ts) that fires it and calls `_startModelRefresh()` together so both gate inputs update in lockstep.
