# Issue #183994 — Add jump to previous/next bracket commands

[https://github.com/microsoft/vscode/issues/183994](https://github.com/microsoft/vscode/issues/183994)

## Summary

Keep this accepted Backlog request open: current bracket navigation does not provide separate previous/next commands. The related requests inspected do not cover the same observable behavior.

## Change summary

Add independently bindable commands for navigating backward and forward between brackets rather than toggling between enclosing or matching brackets.

## Best solution

Provide directional bracket-navigation commands in the editor bracket-matching contribution while preserving editor.action.jumpToBracket. Before implementation, establish whether navigation visits every bracket or selected block boundaries; Ctrl+Up/Down should remain a user binding preference rather than an assumed default.
