# Issue #249154 — Cannot read properties of undefined (reading 'id')

[https://github.com/microsoft/vscode/issues/249154](https://github.com/microsoft/vscode/issues/249154)

## Summary

The reported undefined-icon error is a secondary failure of the gutter indicator initialization defect fixed by commit 664424927b9ae6337be674d26bd985bb6161b9bd. Current source initializes the hover observables before activating indicator rendering, so a completed close is supported.

## Change summary

Rendering the inline-edit gutter indicator can pass an undefined icon to ThemeIcon.asClassNameArray and throw while reading its id.

## Best solution

Treat this as completed by https://github.com/microsoft/vscode/commit/664424927b9ae6337be674d26bd985bb6161b9bd, which initializes the hover observables before the gutter indicator reads them.
