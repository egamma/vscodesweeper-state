# Issue #338768 — Clicking on the "Discover" tab doesn't highlight the tab

[https://github.com/microsoft/vscode/issues/338768](https://github.com/microsoft/vscode/issues/338768)

## Summary

Confirmed on main: the sidebar 'Discover'/'Overview' home button in the AI Customization management editor never gets a selected/active visual state, unlike the sections list which highlights via `sectionsList.setSelection`/`setFocus`. A team-authored, freshly filed, clearly reproducible UI gap.

## Change summary

Clicking the sidebar 'Discover' (home/overview) tab does not visually highlight it as the active tab, unlike clicking other section tabs.

## Best solution

Toggle an active/selected class on `this.homeButton` in `ensureSectionsListReflectsActiveSection` (aiCustomizationManagementEditor.ts) whenever `section === undefined`, and add a matching CSS rule in aiCustomizationManagement.css so it renders with the same selected-state background used elsewhere in the sidebar.
