# Issue #344084 — New remote (Codespace) installs synced extensions even when Extensions is unchecked in Settings Sync

[https://github.com/microsoft/vscode/issues/344084](https://github.com/microsoft/vscode/issues/344084)

## Summary

The reported enablement bypass remains in current source: new desktop remote connections can install stored extensions even when Extensions sync is unchecked. Keep open for the existing area owners; the publisher-trust concern also requires human review.

## Change summary

Prevent new remote environments from importing stored synced extensions when Extensions sync is disabled.

## Best solution

Remote extension initialization should respect the Extensions resource's enablement while preserving explicitly requested remote installs and existing enabled-sync behavior. Have a maintainer assess the reported publisher-trust implications separately.
