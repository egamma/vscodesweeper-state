# Issue #197287 — Investigate debug visualization extension points

[https://github.com/microsoft/vscode/issues/197287](https://github.com/microsoft/vscode/issues/197287)

## Summary

Team-authored API proposal (hard keep-open). The debug visualization API has been partially implemented as a proposed API (`vscode.proposed.debugVisualization.d.ts`) with command-based and tree-based visualizers, but it has not been finalized — it remains behind the `api-proposal` gate. Active community interest (21 upvotes, multiple extension authors waiting) and ongoing discussion about scope (built-in text/JSON formatters, watch/hover support, menu contribution points).

## Change summary

Provide extension points for custom debug variable visualizations (tree replacements, commands, editors) so extensions can offer richer views than the generic variable tree.

## Best solution

Finalize the proposed `debugVisualization` API: resolve outstanding design questions (watch/hover support per hediet's comment, built-in text/JSON formatters per gregg-miskelly and mitchdenny, menu contribution points per thegecko/adrianstephens), migrate the hard-coded hex editor to use it, and promote the API from proposed to stable. The implementation lives in `src/vs/workbench/contrib/debug/` and the API surface in `src/vscode-dts/vscode.proposed.debugVisualization.d.ts`.
