# Issue #44755 — Support environment variables for paths in .code-workspace files

[https://github.com/microsoft/vscode/issues/44755](https://github.com/microsoft/vscode/issues/44755)

## Summary

A substantial portability gap remains on current main, and this Backlog request has 191 community upvotes. It is the established canonical issue for environment-variable expansion in workspace folder paths.

## Change summary

Allow environment-variable references such as `${env:HOME}` in `.code-workspace` folder paths.

## Best solution

Add environment-variable expansion to workspace-folder resolution while defining whether local or remote environment values apply. Preserve relative paths and URI-backed folders, and cover Windows, Unix, and remote workspace cases in the workspace tests.
