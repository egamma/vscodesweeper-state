## Summary

This is already fixed on main: PR #336798 (commit ff61d319) forwards maxInputTokens/maxOutputTokens as maxPromptTokens/maxOutputTokens through the exact renderer, agent host, and copilotSessionLauncher/copilotAgent code paths the report identifies, landing three days before this issue was filed.

## Change summary

BYOK language models in agent host sessions are capped at 128K prompt tokens because maxInputTokens/maxOutputTokens are not forwarded to the Copilot SDK, unlike in regular Copilot Chat.

## Best solution
