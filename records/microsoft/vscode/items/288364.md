# Issue #288364 — Created files should show +x -y diff annotations

[https://github.com/microsoft/vscode/issues/288364](https://github.com/microsoft/vscode/issues/288364)

## Summary

This remains a valid, accepted UX polish gap: Agent Sessions can recognize that created files changed while omitting the corresponding +X/-Y annotation. No older canonical or issue-linked fixing commit was found.

## Change summary

Show insertion and deletion counts for newly created files in Agent Sessions change summaries.

## Best solution

Ensure created-file change records carry meaningful insertion/deletion totals and render them consistently with modified files in the Agent Sessions list, without changing the treatment of sessions that genuinely have no changes.

- **Validation:** Add provider/model and renderer coverage for a session containing a newly created multi-line file, asserting that its summary renders the expected +X and -0 counts; retain coverage that a session with no changes renders no diff annotation.
- **Behavior:**

  > Agent Sessions entries should display +X/-Y annotations for created files just as they do for modified files. For a newly created file, X reflects its added lines and Y is zero. Sessions with no file changes must remain free of diff annotations, and existing modified/deleted-file summaries must remain unchanged.
- **Trace:**

  > The session list renders totals through AgentSessionRenderer.renderDiff in src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsViewer.ts. It calls getAgentChangesSummary from agentSessionsModel.ts, then suppresses the annotation when both totals are zero; meanwhile hasValidDiff accepts any non-empty change array. This explains how a provider-supplied created-file entry can be recognized as a change but still have no visible counts when its insertion/deletion metadata is absent or zero. Trace each built-in session provider's created-file representation before choosing the implementation boundary; preserve the no-change suppression and existing modified/deleted-file behavior. The related https://github.com/microsoft/vscode/issues/321472 concerns files missing from a Changes view and is not the same symptom.
