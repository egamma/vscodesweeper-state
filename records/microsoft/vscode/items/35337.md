# Issue #35337 — Add control to open file shown in "replace preview" editor when performing project-wide find/replace

[https://github.com/microsoft/vscode/issues/35337](https://github.com/microsoft/vscode/issues/35337)

## Summary

Keep open while the linked implementation candidate is reviewed: the requested Open File control remains relevant, and PR 307554 explicitly targets it but is still open. Existing workarounds bypass the replace preview rather than provide the requested control.

## Change summary

Provide an Open File control in the replace-preview editor so users can edit the underlying file without finding it again.

## Best solution

Review and land, or resolve, https://github.com/microsoft/vscode/pull/307554 to provide direct access to the original file from the replace-preview toolbar. Preserve the preview's existing replacement semantics; making either diff pane editable is a separate design question.

- **Existing capability check:** src/vs/workbench/contrib/search/browser/search.contribution.ts:155-158 registers search.useReplacePreview, default true.
