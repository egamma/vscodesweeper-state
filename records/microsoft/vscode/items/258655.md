# Issue #258655 — can't lazy load children within a quicktree

[https://github.com/microsoft/vscode/issues/258655](https://github.com/microsoft/vscode/issues/258655)

## Summary

Keep open: QuickTree still lacks expansion-triggered asynchronous child loading. This is accepted, team-authored backlog work; the older extension-API request does not track the same observable limitation.

## Change summary

Allow QuickTree consumers to fetch and populate a parent's children asynchronously when it is expanded.

## Best solution

Provide an optional lazy-child-loading contract in the core QuickTree API when a concrete consumer needs it, preserving existing eager trees. Establish loading, failure, and checkbox behavior for unresolved children before committing to the contract.
