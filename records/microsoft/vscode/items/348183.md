# Issue #348183 — terminal-suggest watches every PATH directory and holds directory handles, blocking third-party app updates on Windows

[https://github.com/microsoft/vscode/issues/348183](https://github.com/microsoft/vscode/issues/348183)

## Summary

Current main still creates lifetime PATH watchers independently of the terminal suggestions setting. The supplied steps and handle evidence suffice to retest the Windows update failure; the disabled-feature watcher lifecycle remains distinct work from the related reports.

## Change summary

Terminal suggestions retain PATH-directory watchers even when disabled, reportedly preventing Windows applications from renaming their installation directories during updates.

## Best solution

Ensure disabling terminal suggestions prevents and releases its PATH watches without requiring an extension disable or window shutdown. Coordinate enabled-feature watcher behavior with the existing directory-replacement and Windows watcher issues.
