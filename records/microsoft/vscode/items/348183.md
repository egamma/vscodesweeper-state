# Issue #348183 — terminal-suggest watches every PATH directory and holds directory handles, blocking third-party app updates on Windows

[https://github.com/microsoft/vscode/issues/348183](https://github.com/microsoft/vscode/issues/348183)

## Summary

Current main still creates lifetime PATH watchers regardless of whether terminal suggestions are enabled. Keep this open: the disabled-feature resource-lifecycle defect is confirmed from source, while the reported Windows rename failure was not independently executed.

## Change summary

Terminal suggestions retain PATH-directory watchers even when disabled, reportedly preventing Windows application updates.

## Best solution

Ensure disabling terminal suggestions prevents and releases its PATH watchers without requiring a window restart. Preserve executable-cache freshness when suggestions are enabled; broader idle-watching policy and generic Windows watcher behavior can be addressed separately.
