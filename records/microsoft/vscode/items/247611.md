# Issue #247611 — Image hover isn't buttery smooth

[https://github.com/microsoft/vscode/issues/247611](https://github.com/microsoft/vscode/issues/247611)

## Summary

The current source still permits the attachment hover shell and pointer to appear before asynchronous image thumbnail decoding completes. This accepted Backlog bug remains actionable in the chat image-hover path.

## Change summary

Image attachment hovers briefly show their pointer and shell before the preview contents finish rendering.

## Best solution

Make the initial attachment-hover presentation atomic: the pointer, shell, image preview, and URL should become visible together, while preserving subsequent relayout when image dimensions become available.
