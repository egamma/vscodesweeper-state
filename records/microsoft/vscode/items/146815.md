# Issue #146815 — Can't type in Cmd+` in Keyboard Shortcut UI

[https://github.com/microsoft/vscode/issues/146815](https://github.com/microsoft/vscode/issues/146815)

## Summary

Valid upstream issue: macOS intercepts keybindings displayed in native menus before Electron delivers them to VS Code, so the Keyboard Shortcuts UI cannot capture them. Already correctly labeled `upstream`. The limitation persists on current main — no fix has landed.

## Change summary

On macOS, Cmd+` cannot be typed into the Keyboard Shortcuts recording widget because the OS intercepts it via native menu dispatch.

## Best solution

This requires an Electron/Chromium-level change to allow apps to intercept keybindings that are also bound to native menu items during recording mode. The issue is correctly parked as `upstream`; no VS Code-side fix is feasible without upstream support. A workaround exists (editing keybindings.json directly).
