# Issue #325952 — CopilotAH: support more custom agent properties

[https://github.com/microsoft/vscode/issues/325952](https://github.com/microsoft/vscode/issues/325952)

## Summary

This team-authored request remains a broader architectural task: two referenced PRs added individual custom-agent properties, but neither establishes that Copilot now owns discovery and parsing or that all runtime-supported properties pass through.

## Change summary

Support additional Copilot custom-agent frontmatter properties and ideally delegate custom-agent file discovery and parsing to the Copilot runtime.

## Best solution

Define the ownership boundary between VS Code and the Copilot runtime, then make supported custom-agent metadata flow through without requiring a new VS Code parser change for each runtime property while preserving VS Code-local model migration.
