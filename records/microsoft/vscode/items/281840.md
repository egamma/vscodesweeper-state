# Issue #281840 — vscode.admx does not work with InTune

[https://github.com/microsoft/vscode/issues/281840](https://github.com/microsoft/vscode/issues/281840)

## Summary

Actively tracked upstream issue: the root cause is in Windows's Intune ADMX ingestion policy, which blocks writes to `Software\Policies\Microsoft\VSCode`. A VS Code team member is coordinating with the Windows team, and the issue carries milestone 1.125.0 — must stay open.

## Change summary

VS Code's ADMX policy file cannot be deployed via Microsoft Intune because Windows blocks registry writes to the VSCode policy path.

## Best solution

Continue coordinating with the Windows team to ensure the allowlist fix ships broadly (not just in 5D updates) and provide clear guidance to enterprise customers on the minimum required Windows build. Once the Windows fix is confirmed broadly available, update the VS Code enterprise documentation with prerequisites.
