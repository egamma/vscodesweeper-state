# Issue #148160 — extension.extensionKind is wrong for extensions not running on the host

[https://github.com/microsoft/vscode/issues/148160](https://github.com/microsoft/vscode/issues/148160)

## Summary

Still reproduces on main: `extensionKind` is determined solely by whether the current extension host is remote and applied uniformly to all extensions, including those from a different host. The code even has `TODO@alexdima THIS IS WRONG` comments acknowledging the bug at lines 611 and 629 of `extHost.api.impl.ts`.

## Change summary

`extension.extensionKind` returns `Workspace` for all extensions when queried via `allAcrossExtensionHosts` in a remote window, even for UI extensions running on the local host.

## Best solution

Fix the `extensionKind` computation in `extHost.api.impl.ts` to derive the kind from each extension's actual host location (e.g., by checking `isFromDifferentExtensionHost` and flipping the kind accordingly), rather than using the single `initData.remote.isRemote` value for all extensions.
