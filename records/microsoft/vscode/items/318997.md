# Issue #318997 — Remote agent sessions started via UI running in the background (detach VSCode)

[https://github.com/microsoft/vscode/issues/318997](https://github.com/microsoft/vscode/issues/318997)

## Summary

Valid feature request that just earned its way into the backlog with 20 community upvotes. Asks for agent sessions started via the VS Code UI over SSH remote to persist on the remote machine when the local window is closed — a focused, well-scoped request that complements the existing remote agent session work.

## Change summary

Allow agent sessions started via the VS Code UI on a remote SSH connection to continue running on the remote machine after the local VS Code window is closed, and reattach to them later.

## Best solution

Implement persistence for agent sessions spawned by the remote server process so they survive client disconnects, with a reattach mechanism in the agents window. This is a natural extension of the existing agent host and remote session architecture in `src/vs/sessions/` and the agent host infrastructure. The related https://github.com/microsoft/vscode/issues/320044 is broader (all remote state persistence); this issue is specifically scoped to agent sessions and should remain its own tracking item.
