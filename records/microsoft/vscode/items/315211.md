# Issue #315211 — Azure Foundry and Gemini models are missing from the VS Code Agents app

[https://github.com/microsoft/vscode/issues/315211](https://github.com/microsoft/vscode/issues/315211)

## Summary

Implemented after the report: current VS Code can bridge configured BYOK models, including Azure/OpenAI-compatible and Gemini providers, into local Agent Host sessions and expose them in the Agents Window model picker. The capability is intentionally opt-in through `chat.agentHost.byokModels.enabled`.

## Change summary

Make configured Azure AI Foundry and Gemini BYOK models selectable in the VS Code Agents Window.

## Best solution

Keep the Agent Host BYOK bridge introduced by https://github.com/microsoft/vscode/pull/322977 and direct users to enable `chat.agentHost.byokModels.enabled` when they want extension-provided models in local agent-host sessions.
