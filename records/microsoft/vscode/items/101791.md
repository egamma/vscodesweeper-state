# Issue #101791 — Allow DAP progress notifications to be shown more prominently than the status bar

[https://github.com/microsoft/vscode/issues/101791](https://github.com/microsoft/vscode/issues/101791)

## Summary

The central request is implemented on current main: DAP progress now uses normal-priority notification toasts rather than being forced into the silent status-bar presentation.

## Change summary

Allow user-initiated DAP progress such as launching, building, and hot reload to appear more prominently than status-bar-only progress.

## Best solution

Keep the current default-priority notification presentation introduced by commit f1f5d07d14472f954553049209e8fdb0afe0683e; it provides the prominent DAP progress feedback requested here while still honoring user notification filters.
