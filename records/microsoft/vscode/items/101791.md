# Issue #101791 — Allow DAP progress notifications to be shown more prominently than the status bar

[https://github.com/microsoft/vscode/issues/101791](https://github.com/microsoft/vscode/issues/101791)

## Summary

Current main already presents DAP progress as notifications after a 500 ms delay, but exposes no debug-specific control distinguishing background activity from user-initiated work. Keep this supported Backlog request open to settle that remaining behavior; no independently established fixing commit or verified duplicate supports closing it.

## Change summary

Allow more prominent DAP progress feedback for user-initiated operations such as launching, building, and hot reload.

## Best solution

Establish whether the existing delayed notification behavior satisfies the requested experience, and define any remaining user- or adapter-controlled distinction between foreground and background progress in the debug contribution. Preserve general notification filtering and avoid treating the separate short-operation timing request as the same issue.
