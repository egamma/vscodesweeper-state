# Issue #180579 — Quick pick label tooltips

## Summary

The missing label tooltip remains reproducible from current source: quick-pick labels receive no fallback hover content. Keep this accepted bug open; description tooltips and optional command-description tooltips do not expose the full truncated label.

## Change summary
