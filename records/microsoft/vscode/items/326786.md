# Issue #326786 — vscode should be in the list already to toggle on screen recording

[https://github.com/microsoft/vscode/issues/326786](https://github.com/microsoft/vscode/issues/326786)

## Summary

Traced a plausible root cause on main: VS Code's display-media handler primes desktopCapturer.getSources with thumbnailSize {0,0}, which (per Electron/macOS behavior) doesn't count as a real capture attempt and so doesn't register the app in macOS's Screen Recording privacy list — a real, narrow gap worth routing to the issue-reporter area, though I can't execute/verify the macOS TCC behavior in this environment.

## Change summary

On macOS, VS Code never appears in System Settings > Privacy & Security > Screen Recording, so users must add it manually to grant permission for the in-app issue-reporter recording feature.

## Best solution

In src/vs/code/electron-main/app.ts's setDisplayMediaRequestHandler, consider using a non-zero thumbnailSize (or otherwise performing a genuine capture-triggering call) for the initial desktopCapturer.getSources probe so macOS registers VS Code in the Screen Recording privacy list on first use, rather than relying on the user to add it manually.
