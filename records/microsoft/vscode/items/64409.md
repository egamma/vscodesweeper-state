# Issue #64409 — Git - Gracefully handle git hooks

[https://github.com/microsoft/vscode/issues/64409](https://github.com/microsoft/vscode/issues/64409)

## Summary

Keep open for a focused design decision on feedback during long-running commit hooks. Current Git integration provides generic commit progress, but not hook-specific status or live hook output; maintainers have also consolidated related reports here.

## Change summary

Make hook execution visible when committing through the Source Control panel.

## Best solution

Provide useful feedback throughout long-running commit hooks in the built-in Git integration, preserving existing verification safeguards. Decide whether generic commit activity is sufficient or whether live hook output is needed, without claiming hook progress that Git cannot reliably expose.
