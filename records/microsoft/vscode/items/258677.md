# Issue #258677 — Code in repl suggestion doesn't use monospace font

[https://github.com/microsoft/vscode/issues/258677](https://github.com/microsoft/vscode/issues/258677)

## Summary

Still reproduces on main: the CSS rule at `src/vs/workbench/services/suggest/browser/media/suggest.css:443` only sets `font-family: var(--monaco-monospace-font)` for `.suggest-details p code` (inline code in paragraphs), but code blocks rendered as `<pre><code>` or `<code>` outside `<p>` tags are not covered. The issue is correctly labeled as `debt` and `terminal-suggest`.

## Change summary

Code sections in terminal REPL suggestion details render with the system font instead of the editor monospace font.

## Best solution

Broaden the CSS selector in `src/vs/workbench/services/suggest/browser/media/suggest.css` to apply `font-family: var(--monaco-monospace-font)` to all `code` elements within `.suggest-details` (not just `p code`), matching how the editor suggest widget handles it in `src/vs/editor/contrib/suggest/browser/media/suggest.css`.
