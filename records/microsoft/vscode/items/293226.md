# Issue #293226 — Show premium agent features locked for free sku

[https://github.com/microsoft/vscode/issues/293226](https://github.com/microsoft/vscode/issues/293226)

## Summary

Keep open: this team-authored Backlog request identifies a distinct entitlement UX gap—premium session targets appear available to Copilot Free users and fail only after delegation. The related closed issue concerns making a later 401 response actionable, not communicating availability before invocation.

## Change summary

Show premium session targets to Copilot Free users as locked or otherwise unavailable, with clear upgrade messaging before delegation.

## Best solution

Represent each session target's entitlement in the target picker, retain discoverability for Free users, and prevent unsupported delegation while explaining the required plan through accessible disabled-state or lock affordances.
