# Issue #315910 — Integrated terminal restores incorrect height when VS Code is launched via code command in fullscreen

[https://github.com/microsoft/vscode/issues/315910](https://github.com/microsoft/vscode/issues/315910)

## Summary

The panel maximized state (`PANEL_WAS_LAST_MAXIMIZED`) is stored at `StorageScope.WORKSPACE`, so when a new window is opened via the `code` command with a different workspace context, the maximized flag doesn't carry over and the panel reverts to a default or non-maximized height. This is a real layout state restoration gap, still present on main.

## Change summary

The integrated terminal panel does not restore its maximized/near-full height when VS Code is launched in a new window via the `code` command.

## Best solution

Investigate the interaction between `PANEL_WAS_LAST_MAXIMIZED` (workspace-scoped) and `PANEL_SIZE` / `PANEL_LAST_NON_MAXIMIZED_HEIGHT` (profile-scoped) in `src/vs/workbench/browser/layout.ts`. When a new workspace is opened, the maximized flag defaults to `false` and the panel opens at the default 300px. Consider whether the maximized state should be profile-scoped or whether the persisted panel size should better reflect the actual last-used size regardless of maximization state.
