# Issue #187737 — "Additional Views" in Activity Bar should show up only when there's more than one item

[https://github.com/microsoft/vscode/issues/187737](https://github.com/microsoft/vscode/issues/187737)

## Summary

Still present on main: the composite bar overflow logic shows the overflow button whenever totalComposites > compositesToShow.length, even when only one item overflows. No fix has been committed referencing this issue.

## Change summary

The Activity Bar shows the "Additional Views" overflow menu when only a single item doesn't fit, making the menu pointless.

## Best solution

In `src/vs/workbench/browser/parts/compositeBar.ts`, when only one item overflows, either show it directly in the bar (since the overflow button takes roughly the same space) or skip the overflow button entirely. This is a minor polish item in the workbench layout area.
