# Issue #187737 — "Additional Views" in Activity Bar should show up only when there's more than one item

[https://github.com/microsoft/vscode/issues/187737](https://github.com/microsoft/vscode/issues/187737)

## Summary

The overflow behavior remains present on current main: CompositeBar creates the Additional Views action whenever any composite is hidden, including when its menu contains only one item. The accepted bug should remain open for a bounded Activity Bar overflow fix.

## Change summary

When vertical space leaves only one Activity Bar view hidden, show that view directly instead of replacing it with a one-item Additional Views menu.

## Best solution

Make the Activity Bar prefer the final view icon over the overflow action when exactly one view would be hidden and the icon can occupy that slot, while preserving the overflow menu for two or more hidden views and preserving active-view visibility.
