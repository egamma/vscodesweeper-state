# Issue #241814 — Settings search "moving selection" vs. "move selection"

[https://github.com/microsoft/vscode/issues/241814](https://github.com/microsoft/vscode/issues/241814)

## Summary

Still reproduces on main: settings search lacks stemming, so 'move selection' doesn't match the dragAndDrop setting whose description says 'moving selections'. No fix or workaround (like keywords) has been added for this setting. Team-authored issue, keeping open.

## Change summary

Searching 'move selection' in settings fails to find the 'Editor: Drag and Drop' setting because the description uses 'moving selections' and no stemming is applied.

## Best solution

Either add stemming/normalization to the settings search algorithm (broader fix), or add keywords to the dragAndDrop setting registration so common word forms match. The keywords infrastructure was added in commit 8efd494dc82 — it could be leveraged for built-in settings too.
