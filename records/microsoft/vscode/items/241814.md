# Issue #241814 — Settings search "moving selection" vs. "move selection"

[https://github.com/microsoft/vscode/issues/241814](https://github.com/microsoft/vscode/issues/241814)

## Summary

Keep open: local Settings search still does not recognize “move” as a word-form equivalent of “moving.” This is a search-capability improvement rather than a regression in the existing substring matcher; the team-authored, accepted request should remain available for design.

## Change summary

Make Settings search find Editor: Drag and Drop for “move selection,” as it does for “moving selection.”

## Best solution

Define word-form matching for local Settings search so common grammatical variations find relevant settings without depending on AI search. Preserve exact setting-ID matching and existing relevance safeguards.
