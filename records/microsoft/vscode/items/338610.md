# Issue #338610 — CustomExecution task terminals bypass the shell executeCommand guard

[https://github.com/microsoft/vscode/issues/338610](https://github.com/microsoft/vscode/issues/338610)

## Summary

The CustomExecution launch path still omits the task terminal type, so shell integration advertises executeCommand support and bypasses the intended rejection. Keep this open while the two directly linked fixing PRs are reviewed; neither has merged.

## Change summary

CustomExecution task terminals exposing shell integration accept executeCommand instead of synchronously rejecting it before sending task input.

## Best solution

Ensure CustomExecution task terminals obey the same executeCommand restriction as ProcessExecution and ShellExecution tasks, while preserving ordinary pseudoterminal behavior. Review the overlapping fixes at https://github.com/microsoft/vscode/pull/339296 and https://github.com/microsoft/vscode/pull/339539 and land one implementation.
