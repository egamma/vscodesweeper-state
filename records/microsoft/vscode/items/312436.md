# Issue #312436 — Codex login fails with ERR_CONNECTION_REFUSED on localhost:1455 after VS Code update (arm64 1.117.0)

[https://github.com/microsoft/vscode/issues/312436](https://github.com/microsoft/vscode/issues/312436)

## Summary

The failed OAuth callback is owned by the installed OpenAI ChatGPT/Codex extension, which is not maintained by the VS Code team. The forwarding workaround further indicates that the extension starts its callback listener on the remote extension host while directing the local browser to localhost.

## Change summary

Make Codex authentication complete successfully when the OpenAI extension runs in a Remote-SSH window on Windows ARM64.

## Best solution

The OpenAI extension should ensure its OAuth callback server and browser redirect run on the same side of a remote session, or establish the required forwarding itself. This should be tracked with the extension maintainers at https://github.com/openai/codex/issues.
