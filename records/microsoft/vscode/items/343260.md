# Issue #343260 — Agent Host (Copilot): Chat doesn't know its own model name

[https://github.com/microsoft/vscode/issues/343260](https://github.com/microsoft/vscode/issues/343260)

## Summary

Keep open: current main still replaces the SDK identity section with model-independent text, consistent with the reported missing model information. Prompt composition now runs through a registry, but the supplied steps and session evidence suffice to retest; the rendered runtime prompt was not independently verified.

## Change summary

Copilot Agent Host sessions lack authoritative model identity in their prompt and consequently deny knowing, or incorrectly name, the model serving the request.

## Best solution

Ensure ordinary Copilot Agent Host prompts retain authoritative runtime model identity, including after model changes, without losing the VS Code-specific assistant identity or other SDK instructions. Verify the actual model-facing request rather than only the host's system-message configuration.
