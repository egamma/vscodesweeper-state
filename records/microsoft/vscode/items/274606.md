# Issue #274606 — HTTP MCP Server URL Configuration Fails to Preserve Percent-Encoded Slashes (%2F) in Path

[https://github.com/microsoft/vscode/issues/274606](https://github.com/microsoft/vscode/issues/274606)

## Summary

Keep open: current source still loses the distinction between an encoded slash and a path separator before sending MCP HTTP requests. The report supplies a concrete configuration and observed request paths, and another user confirmed persistence in 1.106.2.

## Change summary

Preserve percent-encoded path separators in configured MCP HTTP endpoints so ARN-based routes do not fail with 404 responses.

## Best solution

Preserve the configured endpoint's encoded path through MCP configuration, variable resolution, launch serialization, and HTTP transport. Keep the repair scoped to MCP rather than changing the shared URI class's decoding contract.
