# Issue #347092 — Mark as Done under Done section? I'm so confused

[https://github.com/microsoft/vscode/issues/347092](https://github.com/microsoft/vscode/issues/347092)

## Summary

Keep open: current source explicitly offers Mark Session as Done for unarchived sessions already in Inbox's Done section. This is a genuine terminology collision between attention acknowledgement and session archival, raised by a team member.

## Change summary

Make Inbox's Done category distinguishable from the session-level Mark as Done archival action.

## Best solution

Make the distinction between dismissing an item from Inbox and archiving its session understandable in the Sessions list. Agree on category/action terminology before changing presentation, preserving the existing separation between acknowledgement and archival.
