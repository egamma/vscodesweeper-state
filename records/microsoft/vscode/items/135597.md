# Issue #135597 — Add pagination support to `QuickPick` API

[https://github.com/microsoft/vscode/issues/135597](https://github.com/microsoft/vscode/issues/135597)

## Summary

Keep open: QuickPick supports updating items and preserving scroll position, but still exposes no scroll-to-end notification for incremental loading. The existing api and quick-pick labels correctly route this accepted Backlog request; no verified canonical duplicate was found.

## Change summary

Expose a QuickPick pagination trigger so extensions can fetch additional repository, branch, or tag results when users scroll to the end.

## Best solution

Have the QuickPick API owners assess a viewport-driven loading notification that lets extensions manage fetching and append results without disrupting navigation. Existing item updates and keepScrollPosition cover presentation after fetching, but not the requested automatic trigger.
