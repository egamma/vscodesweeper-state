[https://github.com/microsoft/vscode/issues/329842](https://github.com/microsoft/vscode/issues/329842)

## Summary

The requested shortcut customization already exists in Keyboard Shortcuts. Tab is the default for accepting inline suggestions, but it can be replaced with Shift+Tab without adding a new option.

## Change summary

Allow changing the inline-suggestion acceptance shortcut from Tab to another key, such as Shift+Tab.

## Best solution

Keep the existing customizable command, editor.action.inlineSuggest.commit, and direct the reporter to change its binding in Keyboard Shortcuts rather than introducing a separate setting.

  > Thanks for the request.
