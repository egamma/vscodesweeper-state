The keybinding for accepting an inline suggestion is already fully customizable in core — no new feature is needed here.

## Change summary

Reporter wants to rebind the key that accepts an inline suggestion from Tab to something like Shift+Tab.

## Best solution

Point the reporter at rebinding the existing command `editor.action.inlineSuggest.commit` via `Preferences: Open Keyboard Shortcuts` (or editing `keybindings.json`) — no code change needed.
