# Issue #326797 — Agent/Ask/Plan not switching properly with customendpoint BYOK model

[https://github.com/microsoft/vscode/issues/326797](https://github.com/microsoft/vscode/issues/326797)

## Summary

Keep open: the custom-endpoint path drops the mode-change signal before Responses API serialization, allowing a Plan response chain to survive the switch to Agent. The supplied configuration and corroborating discussion describe an actionable failure, not a third-party extension ownership issue.

## Change summary

Starting implementation after planning with a custom-endpoint BYOK model changes the UI to Agent but leaves the model responding under planning restrictions.

## Best solution

Make mode transitions invalidate the previous Responses chain on the built-in BYOK path, so the first Agent request receives its current instructions. Preserve normal response chaining for subsequent requests in the same mode.
