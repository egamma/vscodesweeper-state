# Issue #326797 — Agent/Ask/Plan not switching properly with customendpoint BYOK model

[https://github.com/microsoft/vscode/issues/326797](https://github.com/microsoft/vscode/issues/326797)

## Summary

A real, still-open bug: switching Plan → Agent via the 'Start Implementation' handoff fails specifically when the active model is a BYOK `customendpoint` model, while native Copilot models and even a third-party BYOK extension (LiteLLM) work fine — pointing at a defect in how the agent host resolves/continues the session for custom-endpoint models during a handoff, not a generic Plan/Agent regression.

## Change summary

After approving a plan and clicking 'Start Implementation' with a `customendpoint` BYOK model configured, the mode visually switches to Agent but the model still reports being stuck in Plan mode and implementation cannot proceed.

## Best solution

Investigate the handoff/session continuity path for `customendpoint` BYOK models (extensions/copilot/src/extension/byok/vscode-node/customEndpointProvider.ts and extensions/copilot/src/extension/agents/vscode-node/planAgentProvider.ts) to see why the target agent identity/model context isn't correctly carried over on handoff for this vendor, given that the general Plan→Agent handoff bug (https://github.com/microsoft/vscode/issues/312554) was already fixed for built-in models.
