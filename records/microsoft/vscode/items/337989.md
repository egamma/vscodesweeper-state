# Issue #337989 — Renderer freezes during bulk text model cleanup

[https://github.com/microsoft/vscode/issues/337989](https://github.com/microsoft/vscode/issues/337989)

## Summary

Real, well-diagnosed perf/freeze bug (renderer trace shows a 6.89s stall, local repro at 6.84s with 18,000 full-model scans across 6,000 models) with an open fixing PR (#337990) already attached — keep open and let that PR land rather than closing or auto-fixing.

## Change summary

Disposing many text models in bulk (e.g. switching sessions) triggers O(n²) rescanning across edit tracking, extension document state, and the editor worker, freezing the renderer for several seconds.

## Best solution
