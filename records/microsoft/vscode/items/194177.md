# Issue #194177 — F7 does not work consistently in diff view when there are comments

[https://github.com/microsoft/vscode/issues/194177](https://github.com/microsoft/vscode/issues/194177)

## Summary

The current default keybindings still explain the inconsistent F7 behavior: symbol-highlight navigation wins whenever word highlights are active, including in a screen-reader-enabled diff editor. Keep this team-authored issue open; no verified fix or eligible canonical duplicate was found.

## Change summary

F7 and Shift+F7 intermittently navigate symbol highlights instead of differences in the diff editor.

## Best solution

Establish consistent precedence for accessible difference navigation in screen-reader-enabled diff editors, preserving symbol-highlight navigation outside the intended context. The diff-editor owner should settle the scope of that precedence and the accompanying accessibility-help wording.
