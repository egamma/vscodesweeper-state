## Summary

Team-authored lifecycle clarification request with detailed first-party event-log evidence showing sessionEnd firing per-turn rather than per-conversation in the Agents window; genuinely unclear whether this is an Agent Host defect or intended Copilot SDK execution-instance semantics, so it needs an Agent Host owner's answer rather than any close.

## Change summary

sessionEnd(reason: "complete") fires after every completed Copilot agent turn in the Agents window, even though the conversation and session ID continue, causing workspace sessionEnd hooks to run far more often than intended for actual session termination.
