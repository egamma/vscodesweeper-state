# Issue #330034 — Managed settings confirmations should say why confirmation is triggered

[https://github.com/microsoft/vscode/issues/330034](https://github.com/microsoft/vscode/issues/330034)

## Summary

Keep open: current confirmation text avoids incorrectly calling an in-workspace read external, but still does not explain when enterprise policy requires approval. This team-authored request remains distinct from the closed report about excessive confirmations.

## Change summary

Explain enterprise-policy requirements in tool approval prompts triggered by managed settings.

## Best solution

Show an accurate enterprise-policy explanation on policy-required confirmations while preserving ordinary confirmation wording and runtime enforcement. Establish whether the explanation should identify a specific policy rule or provide a general managed-policy notice.
