# Issue #250787 — Avoid individual indent guides in trees

[https://github.com/microsoft/vscode/issues/250787](https://github.com/microsoft/vscode/issues/250787)

## Summary

Keep open: current tree rendering still creates an individual guide element for every ancestor of every rendered row. The earlier opacity-transition improvement did not eliminate that cost, and the related nesting-performance reports do not establish a canonical duplicate for this specific follow-up.

## Change summary

Reduce deep-tree rendering and transition overhead by avoiding separate indent-guide elements for every ancestor in each row.

## Best solution

Optimize guide rendering in the shared base tree while preserving guide appearance, active-ancestor highlighting, configuration, and reduced-motion behavior. Establish a repeatable deep-tree performance baseline before selecting and validating a replacement.
