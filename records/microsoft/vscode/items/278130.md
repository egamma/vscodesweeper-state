# Issue #278130 — Pressing `F5` doesn't capture the active file for `${file}` immediately sometimes resulting in launching the wrong file

[https://github.com/microsoft/vscode/issues/278130](https://github.com/microsoft/vscode/issues/278130)

## Summary

The current source still resolves `${file}` from the editor active after asynchronous debug startup, allowing a quick tab switch after F5 to change the launch target. Keep this open while the existing fix candidate is reviewed.

## Change summary

Preserve the file active when F5 is pressed so switching editors during debug startup cannot launch a different file.

Review https://github.com/microsoft/vscode/pull/310790 and land an appropriately scoped fix that preserves the initiating file throughout asynchronous debug configuration resolution without affecting unrelated variable resolution.
