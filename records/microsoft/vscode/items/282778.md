- **Behavior:**

  > Users of standalone VS Code for Web should be able to sign in and receive conversational Copilot assistance without launching the desktop application or connecting a remote compute host. Acceptance must distinguish browser-only use from chat running through a server-side extension host. Existing desktop and remote-backed Copilot behavior must remain supported.
- **Trace:**

  > The request originated at https://github.com/microsoft/vscode-copilot-release/issues/3904 and was explicitly continued here after receiving sufficient community support.
