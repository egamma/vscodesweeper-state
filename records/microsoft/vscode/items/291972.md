# Issue #291972 — add a command to copy the most recent chat response text

[https://github.com/microsoft/vscode/issues/291972](https://github.com/microsoft/vscode/issues/291972)

## Summary

Keep open: existing copy actions target a context-menu item or the focused response, not automatically the most recent response. This maintainer-authored accessibility request remains distinct from the shipped copy button and merits a short design session.

## Change summary

Provide a directly invocable command that copies the most recent chat response without first opening Accessible View or focusing the response.

## Best solution

Expose a keyboard-bindable latest-response copy command in the chat actions and document it in chat accessibility help. Settle whether its clipboard content matches the existing full-response Copy action or Copy Final Response before implementation.

- **Behavior:**

  > A user can copy the most recent response in the relevant chat through one assigned keyboard shortcut without navigating into the transcript or opening Accessible View. Focusing an older response must not cause that older response to be copied by this command. The operation preserves focus and copies only the response content specified by the agreed clipboard contract. Existing item-specific copy actions retain their behavior.
