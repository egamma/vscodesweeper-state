# Issue #334610 — hard to see what is focused when tabbing beyond the chat tabs

[https://github.com/microsoft/vscode/issues/334610](https://github.com/microsoft/vscode/issues/334610)

## Summary

Fresh, team-authored accessibility bug filed hours ago describing missing/invisible focus indicators when tabbing through the chat view; a quick check of the chat browser CSS finds no focus-visible styling for chat rows/timestamps, consistent with the report, and there's no fix on main yet.

## Change summary

Tabbing past the chat tabs into the chat view loses a visible focus indicator in several states (selected view, re-focused input, and the message timestamp), making keyboard navigation hard to follow visually.

## Best solution

Add/verify :focus-visible styling for the chat list rows, chat input, and timestamp elements in the chat browser media CSS/contrib so keyboard focus is always visually indicated; likely touches src/vs/workbench/contrib/chat/browser and its media/*.css, in coordination with the follow-up work already noted from #334481.
