# Issue #204719 — Insider release: 'Experimental editor' shows two different color when select the text

[https://github.com/microsoft/vscode/issues/204719](https://github.com/microsoft/vscode/issues/204719)

## Summary

The visual defect remains source-reproducible on current main: the Interactive Editor Playground applies its custom background to only some Monaco editor layers, so translucent selection highlighting can produce inconsistent colors.

## Change summary

Selecting text in an embedded Interactive Editor Playground editor shows different selection colors across editor regions.

## Best solution

Make the playground background consistent across the embedded editor canvas and margin while preserving normal editor theming, then validate text selections under a contrasting theme.
