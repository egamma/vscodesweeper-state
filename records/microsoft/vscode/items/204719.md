# Issue #204719 — Insider release: 'Experimental editor' shows two different color when select the text

[https://github.com/microsoft/vscode/issues/204719](https://github.com/microsoft/vscode/issues/204719)

## Summary

Still reproduces on main: the walkthrough embedded editor CSS applies the custom background color to `.monaco-editor-background` and `.margin-view-overlays` but not to `.monaco-editor` itself, causing a two-tone selection highlight when text is selected.

## Change summary

The Interactive Playground's embedded editor shows two different background colors when selecting text, because the background override CSS is incomplete.

## Best solution

Add `.monaco-editor` to the background-color rule at line 165-168 of `src/vs/workbench/contrib/welcomeWalkthrough/browser/media/walkThroughPart.css`, as alexdima diagnosed.
