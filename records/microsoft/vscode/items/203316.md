# Issue #203316 — SCM Graph - Incoming commit should have `Pull Until` action

[https://github.com/microsoft/vscode/issues/203316](https://github.com/microsoft/vscode/issues/203316)

## Summary

Keep open: the current graph supports pulling a remote branch and cherry-picking a selected commit, but neither delivers the requested merge-through-selected-commit behavior. The related graph enhancement issue is newer and does not qualify as a canonical for this re-reviewed item.

## Change summary

Add a Pull Until action on an incoming commit that merges its history through that commit, inclusive, while leaving subsequent commits incoming.

## Best solution

Provide a commit-targeted integration action in the built-in Git graph that preserves ancestry through the selected incoming commit without integrating later upstream commits. Keep this accepted Backlog request distinct from general graph enhancements until the SCM owner chooses to prioritize it.
