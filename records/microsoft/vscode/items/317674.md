# Issue #317674 — MCP tools: Allow dynamic display title via tool result `_meta`

[https://github.com/microsoft/vscode/issues/317674](https://github.com/microsoft/vscode/issues/317674)

## Summary

Valid feature request for dynamic display titles in MCP tool results. The capability does not exist on current main — no `displayTitle` or `inputDisplayPath` handling in the MCP tool result path. The pattern is consistent with existing `_meta.ui.resourceUri` usage for MCP Apps.

## Change summary

Allow MCP tool results to specify a dynamic display title via `_meta.displayTitle` (and optionally an `inputDisplayPath` annotation) so the Chat view shows a meaningful header for gateway/router-pattern tools.

## Best solution

Implement `_meta.displayTitle` support in the tool invocation rendering path (around `stateToProgressAdapter.ts` and `chatToolInvocationPart.ts`), mapping it to the existing `pastTenseMessage` / collapsible-list title mechanism. The `inputDisplayPath` annotation is a nice-to-have secondary. This aligns with the existing `_meta.ui` pattern for MCP Apps and would benefit the gateway-pattern MCP ecosystem.
