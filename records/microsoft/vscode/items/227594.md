# Issue #227594 — Extra Space Added When Inserting New Line in HTML Document with Ctrl+Enter

[https://github.com/microsoft/vscode/issues/227594](https://github.com/microsoft/vscode/issues/227594)

## Summary

The current source still allows whitespace inside an HTML comment to become the next line's indentation. Keep this open in editor-autoindent; the report and follow-up discussion match the traced path, and no verified canonical or fixing commit was found.

## Change summary

Inserting a line after a completed HTML comment incorrectly inherits whitespace between the comment opener and its text.

## Best solution

Ensure new lines after completed HTML comments inherit the actual line indentation, not whitespace exposed by comment-token processing, while preserving existing HTML nesting and comment-editing behavior.
