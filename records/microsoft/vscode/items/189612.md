# Issue #189612 — What's new page does not respect smooth scrolling setting

[https://github.com/microsoft/vscode/issues/189612](https://github.com/microsoft/vscode/issues/189612)

## Summary

The release notes page renders inside a webview that uses the browser's native scrolling. There is no code that reads VS Code's smooth scrolling settings and applies them to the webview's scroll behavior — the gap still exists on current main.

## Change summary

The What's New / Release Notes page does not respect the user's smooth scrolling settings (e.g. `workbench.list.smoothScrolling`).

## Best solution

The release notes webview CSS (in `releaseNotesEditor.ts`) should conditionally set `scroll-behavior: smooth` on the `html` or `body` element based on the relevant workbench smooth scrolling setting, or alternatively disable any inherited smooth scrolling when the setting is off. The fix is localized to the release notes renderer's HTML template.
