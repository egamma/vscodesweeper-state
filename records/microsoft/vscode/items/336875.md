# Issue #336875 — Cursor Get Moved Immediately Somewhere After Typing While Opening The Git Diffs Inline Viewer

[https://github.com/microsoft/vscode/issues/336875](https://github.com/microsoft/vscode/issues/336875)

## Summary

Keep open: current source contains a delayed quick-diff update path that navigates to another change and resets the main editor's cursor while the user is editing. The older reports inspected cover different triggers and do not establish a duplicate.

## Change summary

Prevent typing with the Git gutter diff viewer open from unexpectedly moving the cursor after a diff refresh.

## Best solution

Passive quick-diff recomputation should preserve the user's editing position and focus while keeping the displayed change current. Explicit next/previous-change commands should retain their existing navigation behavior.
