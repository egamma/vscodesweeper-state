# Issue #80607 — removeSecondaryCursors should leave the cursor added last

[https://github.com/microsoft/vscode/issues/80607](https://github.com/microsoft/vscode/issues/80607)

## Summary

The requested behavior remains absent on current main: Escape retains the primary cursor, not the cursor added last. Keep this Backlog request open for a UX decision and classify it as under discussion.

## Change summary

Make `removeSecondaryCursors` retain the most recently added cursor instead of the primary cursor.

## Best solution

Decide whether to change Escape semantics or introduce a separate command for retaining the last-added cursor, then update the core editor command and multicursor tests. This older, focused issue should remain the canonical report for that behavior.
