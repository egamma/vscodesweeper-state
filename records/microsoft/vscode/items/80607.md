# Issue #80607 — removeSecondaryCursors should leave the cursor added last

[https://github.com/microsoft/vscode/issues/80607](https://github.com/microsoft/vscode/issues/80607)

## Summary

Keep open: Escape still retains the primary cursor, not the last-added selection. The maintainer's navigation workarounds do not provide the requested collapse behavior, and no qualifying older canonical was found; the Backlog milestone also bars a decline close.

## Change summary

Make removeSecondaryCursors retain the cursor added last so Ctrl+D navigation can end at the most recently selected occurrence.

## Best solution

Have the editor owner decide whether last-added-selection retention should be an alternate command or a change to Escape behavior, preserving existing primary-cursor semantics unless that compatibility change is explicitly accepted.
