# Issue #305591 — Android Virtual Keyboards overlap with the UI instead of resizing it.

[https://github.com/microsoft/vscode/issues/305591](https://github.com/microsoft/vscode/issues/305591)

## Summary

Real bug on Android: the viewport meta tag in the web workbench lacks `interactive-widget=resizes-content`, so virtual keyboards overlay the UI instead of resizing the layout. An open community PR (#305596) proposes the fix but hasn't merged yet.

## Change summary

On Android, opening the virtual keyboard overlaps the VS Code web UI instead of resizing the viewport to accommodate it.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/305596 which adds `interactive-widget=resizes-content` to the viewport meta in the web workbench HTML files, or apply an equivalent fix. Verify on other mobile platforms (iOS) that the change doesn't regress behavior.
