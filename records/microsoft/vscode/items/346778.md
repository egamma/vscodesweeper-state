# Issue #346778 — Copilot Chat terminal approval prompt disappears while approval is still pending

[https://github.com/microsoft/vscode/issues/346778](https://github.com/microsoft/vscode/issues/346778)

## Summary

Keep open: an independent commenter confirms that pending approvals become inaccessible in Agent View, blocking individual sessions while others work normally. The disappearance trigger remains undiagnosed; neither a fixing commit nor a sufficiently established duplicate was found.

## Change summary

Keep terminal approval controls visible or recoverable until the pending approval is resolved.

## Best solution

Diagnose the mismatch between pending confirmation state and rendered approval controls in the chat renderer/input lifecycle. Preserve explicit approval requirements and make Focus Chat Confirmation reliably reach the pending prompt.
