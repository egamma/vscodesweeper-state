# Issue #325091 — frontier_llm refusal for Claude Fable 5 results in an error

[https://github.com/microsoft/vscode/issues/325091](https://github.com/microsoft/vscode/issues/325091)

## Summary

Valid bug: when Anthropic returns a `frontier_llm` refusal, the refusal is logged and telemetered but the user sees only a generic "no response" error — no explanation of why the model refused or guidance on what to do next.

## Change summary

Anthropic model refusals (e.g. `frontier_llm` category) result in a generic error instead of an informative user-facing message explaining the refusal reason.

## Best solution

Surface the refusal category as a user-facing error message in the chat response (e.g. "The model declined this request due to policy restrictions") instead of the generic empty-response error. Whether to also implement automatic fallback to another model is a product decision that needs team input. The fix belongs in `extensions/copilot/src/platform/endpoint/node/messagesApi.ts` around the refusal handling paths (lines ~1273–1293 and ~929–946).
