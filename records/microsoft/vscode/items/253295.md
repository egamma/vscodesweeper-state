# Issue #253295 — Context menu on chat message should have an Edit entry

[https://github.com/microsoft/vscode/issues/253295](https://github.com/microsoft/vscode/issues/253295)

## Summary

The request remains necessary on current main: editing and undoing requests are available through the message toolbar and keyboard, but those actions are not contributed to the chat message context menu. The accepted Backlog feature request should stay open for its current chat/UX owners.

## Change summary

Expose Edit Request and the other applicable request-toolbar actions in a chat request's context menu.

## Best solution

The request context menu should offer the same applicable edit/undo or checkpoint actions as the request toolbar, while preserving their existing read-only, configuration, and request-type eligibility.

Invoking Edit Request starts the same editing experience as the existing toolbar and Enter-key paths.
