# Issue #267086 — Support cursor rules

[https://github.com/microsoft/vscode/issues/267086](https://github.com/microsoft/vscode/issues/267086)

## Summary

Current main supports Cursor-style `.cursor/rules/*.mdc` files through the agent plugin system, including workspace-relative configuration, so the central cross-tool rules request is implemented.

## Change summary

Allow VS Code Chat to consume Cursor-compatible rule files from `.cursor/rules` so repositories can share agent instructions across tools.

## Best solution

Use `"chat.pluginLocations": { ".cursor": true }`; VS Code treats `.cursor` as a manifestless plugin root, discovers its `rules/` directory, and loads `.mdc`, `.md`, and `.instructions.md` files.
