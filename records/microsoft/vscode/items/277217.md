# Issue #277217 — Add inline "Run to Cursor" icons during debugging sessions

[https://github.com/microsoft/vscode/issues/277217](https://github.com/microsoft/vscode/issues/277217)

## Summary

The hover-only Run to Cursor affordance remains distinct from the existing command and gutter context menu. Keep this accepted Backlog request open; the inspected source does not provide the requested interaction, and no matching canonical was verified.

## Change summary

Expose a clickable Run to Cursor icon beside the hovered line during debugging without interfering with breakpoint controls.

## Best solution

Have the debug area owner assess a discoverable, hover-only Run to Cursor affordance alongside the existing gutter interactions, preserving breakpoint targets and keyboard access. The remaining question is whether this additional interaction belongs in the standard debugging UI.
