# Issue #340985 — Agent host: recursive <workspace>/.claude watch with excludes: [] exhausts the Linux inotify limit when .claude/worktrees/ holds git worktrees

[https://github.com/microsoft/vscode/issues/340985](https://github.com/microsoft/vscode/issues/340985)

## Summary

Thanks for the thorough report. The cited code is still on main: both agent-host watchers use `excludes: []`, and the `.claude` hook source is recursive. On Linux this can exhaust inotify when `.claude/worktrees` holds many worktrees.

## Change summary

The agent host's recursive watches on `<workspace>/.claude` use no excludes, so on Linux they exhaust the inotify limit when `.claude/worktrees` contains worktrees with `node_modules`.

## Best solution

Watch `.claude` non-recursively (or only its two settings files) for the hook source, and watch only the customization subfolders recursively for Claude sessions. At minimum, exclude `**/node_modules/**` and `**/.claude/worktrees/**` from these watches.
