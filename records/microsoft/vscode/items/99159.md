# Issue #99159 — Partial cross-file undo if a file is changed in the meantime

[https://github.com/microsoft/vscode/issues/99159](https://github.com/microsoft/vscode/issues/99159)

## Summary

Team-authored feature request for partial cross-file undo remains valid — no implementation referencing this issue has landed, and the discussed improvement (undoing in files whose ranges weren't touched while skipping conflicted ones) is still absent from the undo/redo service.

## Change summary

When a cross-file operation (e.g. rename) is undone but one file was edited in the meantime, undo should still succeed in the unaffected files rather than failing entirely.

## Best solution

Enhance the cross-file undo logic in `src/vs/platform/undoRedo/common/undoRedoService.ts` to allow partial undo of multi-resource elements when only some resources have conflicting edits, with clear user notification about which files were skipped. Related to https://github.com/microsoft/vscode/issues/99295 (random-access undos) but distinct — this is about graceful degradation, not arbitrary undo selection.
