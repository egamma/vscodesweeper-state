# Issue #295508 — Agent sessions list still has pending changes after everything is applied

[https://github.com/microsoft/vscode/issues/295508](https://github.com/microsoft/vscode/issues/295508)

## Summary

Team-authored bug about stale pending-changes indicators in the sessions list after applying all changes. The Agents window has been heavily reworked since February 2026 — this may be incidentally fixed, but no commit explicitly references #295508, so it stays open for confirmation.

## Change summary

The sessions sidebar list still shows pending changes (diff stats) for a session after the user has applied all changes; the indicator only clears when switching to another session.

## Best solution

Verify on current Insiders whether the changes indicator in the sessions list clears immediately after all changes are applied. If still present, the fix likely belongs in the reactive update path where `session.changes` or `session.changesSummary` is observed — ensuring the observable emits an empty array after a successful apply so the list row re-renders without diff stats.
