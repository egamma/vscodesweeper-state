# Issue #317321 — Github Issue template mentions non-existing "Report Issue" help menu entry

[https://github.com/microsoft/vscode/issues/317321](https://github.com/microsoft/vscode/issues/317321)

## Summary

The template still unconditionally recommends a Help menu entry that current main deliberately hides when feedback is disabled. The supplied steps suffice to retest; source inspection establishes that configuration-dependent gap but does not confirm why the entry was absent in the reporter's installation.

## Change summary

The GitHub bug-report template directs users to Report Issue without accounting for configurations where that menu entry is unavailable.

## Best solution

Keep reporting guidance accurate when the built-in reporter is unavailable, while preserving intentional feedback-disable behavior. First distinguish a documentation gap from a menu-registration defect with feedback enabled.
