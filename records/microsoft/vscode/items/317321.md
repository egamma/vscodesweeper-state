# Issue #317321 — Github Issue template mentions non-existing "Report Issue" help menu entry

[https://github.com/microsoft/vscode/issues/317321](https://github.com/microsoft/vscode/issues/317321)

## Summary

The 'Report Issue' entry exists in the Help menu in standard VS Code builds (registered via `MenubarHelpMenu` in `src/vs/workbench/contrib/issue/common/issue.contribution.ts`). It is hidden when `telemetry.feedback.enabled` is set to `false` (e.g. by enterprise policy). More info is needed from the reporter to understand why they cannot see it.

## Change summary

Reporter cannot find the 'Report Issue' entry mentioned in the GitHub issue template's advisory text.

## Best solution

Ask the reporter to check their `telemetry.feedback.enabled` setting. If it's disabled by policy and the template text is misleading for those users, the template could be softened (e.g. 'if available, use Report Issue from the Help menu'), but this is a minor documentation polish, not a bug in VS Code itself.
