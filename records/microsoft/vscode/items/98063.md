# Issue #98063 — Add an option to save files atomically

[https://github.com/microsoft/vscode/issues/98063](https://github.com/microsoft/vscode/issues/98063)

## Summary

The underlying atomic-write infrastructure now exists, but normal editor saves still provide no setting or option to use it. This remains the canonical, explicitly retained feature request for that gap.

## Change summary

Allow users to save files through an atomic temporary-file-and-rename operation to reduce truncation and partial-write risks.

## Best solution

Add a file-save setting that makes StoredFileWorkingCopy request atomic writes from capable providers, with documented behavior for symlinks, remote providers, and file watchers.

- **Reason:** Protecting source files during the core edit-save loop advances VS Code's durable investment in editor reliability.
