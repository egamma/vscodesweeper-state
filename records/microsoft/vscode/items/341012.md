# Issue #341012 — Agent Host/Window: Devcontainer settings in `.devcontainer/<subfolder>/devcontainer.json` are not recognised.

[https://github.com/microsoft/vscode/issues/341012](https://github.com/microsoft/vscode/issues/341012)

## Summary

Thanks for the report. Dev container detection in the Agents window only checks `.devcontainer/devcontainer.json` and `.devcontainer.json`. A config in `.devcontainer/<subfolder>/devcontainer.json`, which the spec allows, is never detected, so the Dev Container option does not appear.

## Change summary

The Agents window does not detect devcontainer configs located in `.devcontainer/<subfolder>/devcontainer.json`.

## Best solution

Extend detection to also find `.devcontainer/*/devcontainer.json` (one level deep, per the spec). Update the file-change watcher so adding such a file refreshes availability. Check whether the launch path (`--config`) can use a subfolder config or needs config selection when there are several.
