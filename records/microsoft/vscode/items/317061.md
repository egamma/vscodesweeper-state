# Issue #317061 — Copilot Chat Conversation Title Will Not Persist

[https://github.com/microsoft/vscode/issues/317061](https://github.com/microsoft/vscode/issues/317061)

## Summary

Verified duplicate: the root cause is that `ChatSessionStore.setSessionTitle()` updates only the in-memory index without calling `flushIndex()`, so renamed titles don't persist to disk. This is already tracked by the canonical issue with an open fix PR.

## Change summary

Renaming a Copilot Chat conversation title does not persist across reloads — the title reverts to the auto-generated name.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/283514, which tracks chat session rename persistence and already has an open fix PR (https://github.com/microsoft/vscode/pull/323323) that adds the missing `flushIndex()` call and session-file update to `setSessionTitle()`.
