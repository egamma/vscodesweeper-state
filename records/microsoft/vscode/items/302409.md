# Issue #302409 — Confusing handling of slash prompts in Copilot Chat when working in workspace with multiple repos. Out-of-the-box.

[https://github.com/microsoft/vscode/issues/302409](https://github.com/microsoft/vscode/issues/302409)

## Summary

The request remains relevant: current prompt discovery retains same-named prompt files, and slash completions do not distinguish their repository origins. Existing location settings do not provide automatic deduplication or active-repository scoping.

## Change summary

Make same-named slash prompts from multiple workspace repositories less confusing through deduplication or repository-aware selection.

## Best solution

Define consistent multi-root prompt collision behavior in Chat customizations, preserving access to genuinely different same-named prompts while avoiding indistinguishable entries. Decide whether identical copies should collapse or suggestions should follow an explicit repository context.
