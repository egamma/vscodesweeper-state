# Issue #302409 — Confusing handling of slash prompts in Copilot Chat when working in workspace with multiple repos. Out-of-the-box.

[https://github.com/microsoft/vscode/issues/302409](https://github.com/microsoft/vscode/issues/302409)

## Summary

Valid feature request: slash prompts with the same name from multiple workspace roots all appear without deduplication or scoping, creating a confusing UX. The current behavior is intentional per test code, so this is a request to improve multi-root prompt handling.

## Change summary

When a multi-root workspace has identically-named prompt files in each root, the slash command picker shows duplicates with no way to distinguish or scope them.

## Best solution

Deduplicate same-named prompts across workspace roots (with a precedence rule, e.g. active-root wins), or disambiguate them in the picker UI by showing the workspace folder name. The relevant logic lives in `src/vs/workbench/contrib/chat/common/promptSyntax/service/promptsServiceImpl.ts` around `computeSlashCommandDiscoveryInfo`.
