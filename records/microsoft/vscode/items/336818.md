## Summary

A request for native Android/iOS VS Code apps with a bundled terminal (Termux or custom) is a fundamentally different product from the desktop/web editor VS Code ships today; this is a recurring, well-understood ask that the project has never taken on, so it's best declined as out-of-scope rather than left to accumulate.

## Change summary

Ship native mobile (Android/iOS) versions of VS Code, including a bundled or Termux-based terminal.

## Best solution

Point users toward vscode.dev / github.dev for browser-based mobile access; a full native mobile port with an integrated terminal is out of scope for VS Code core and would require a separate product effort, not a code change here.
