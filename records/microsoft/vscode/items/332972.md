# Issue #332972 — Files opened read-only by "ReadOnly Include" cannot be made writable via "Reset Active Editor Read-Only In Session"

[https://github.com/microsoft/vscode/issues/332972](https://github.com/microsoft/vscode/issues/332972)

## Summary

Traced the code: 'Reset Active Editor Read-only in Session' intentionally clears the session override and falls back to the configured `files.readonlyInclude` state, so it correctly stays read-only — the interactive override the reporter wants already exists via 'Set Active Editor Writeable in Session' (or Toggle), which explicitly force-sets the session override to writable and wins over the config matcher.

## Change summary

Reset Active Editor Read-only in Session does not unlock a file that was marked read-only by the files.readonlyInclude glob setting.

## Best solution

No code change needed: point the reporter at workbench.action.files.setActiveEditorWriteableInSession (or the Toggle command), both of which set an explicit session override that wins over files.readonlyInclude per FilesConfigurationService.isReadonly's precedence ('session override always wins over the others').
