# Issue #332972 — Files opened read-only by "ReadOnly Include" cannot be made writable via "Reset Active Editor Read-Only In Session"

[https://github.com/microsoft/vscode/issues/332972](https://github.com/microsoft/vscode/issues/332972)

## Summary

The reported result is intentional: Reset removes the per-session override and restores the configured `files.readonlyInclude` state. The existing Toggle or Set Writeable command already provides the requested case-by-case writable override.

## Change summary

Change the Reset Active Editor Read-Only In Session command so a file matched by `files.readonlyInclude` becomes writable for the current session.

## Best solution

Keep Reset as the operation that returns a file to its configured baseline, and use `workbench.action.files.toggleActiveEditorReadonlyInSession` or `workbench.action.files.setActiveEditorWriteableInSession` when the user wants a configured read-only file to become writable temporarily.

  > Thanks for the report. This is the intended distinction between the commands: **Reset Active Editor Read-Only in Session** removes the session override and returns the file to its configured `files.readonlyInclude` state. To make that file writable for the current session, use **Toggle Active Editor Read-Only in Session** or **Set Active Editor Writeable in Session**; the read-only notification also provides the toggle action.

## Evidence

- **current source:** In src/vs/workbench/services/filesConfiguration/common/filesConfigurationService.ts, `applyReadonly(..., 'reset')` deletes the entry from `sessionReadonlyOverrides`; `isReadonly` then evaluates `files.readonlyInclude`. A `false` session override takes precedence and makes the resource writable.
- **available commands:** src/vs/workbench/contrib/files/browser/fileActions.ts registers distinct Reset, Toggle, and Set Active Editor Writeable in Session commands. Toggle computes the inverse of the effective read-only state, so it creates the required writable override for a configured read-only file.
- **verified capability:** https://github.com/microsoft/vscode/issues/216491 specifically verified the one-click path for making a file matched by read-only configuration writable; it was implemented by https://github.com/microsoft/vscode/commit/69d85960f7ded9589a541795000347f9bc4f5c79.
- **command design history:** https://github.com/microsoft/vscode/commit/97be614d5b98d497aff5716d2cd938ea0cfeaab5 introduced Reset specifically to delete a session override, while https://github.com/microsoft/vscode/commit/05632b6afe4c43f8e058a7582ba91fc50f04b0e5 documents that explicit session overrides take precedence over configured glob patterns.
