# Issue #325177 — Agent Mode md file is not visible similar to Ask and Plan modes

[https://github.com/microsoft/vscode/issues/325177](https://github.com/microsoft/vscode/issues/325177)

## Summary

Current source confirms the reported difference, but it reflects two distinct mode implementations rather than a broken file action. Route this as a feature request for the chat agent owners to decide whether the built-in Agent mode should expose an editable or viewable definition.

## Change summary

Expose a file action for the built-in Agent mode comparable to the actions shown for Ask and Plan agent files.

## Best solution

Decide whether the built-in Agent mode should gain a stable, viewable configuration resource; if so, supply that resource through its mode model and let the existing mode-picker toolbar action open it.
