The parallel server download race condition is owned by the Remote SSH extension (microsoft/vscode-remote-release), which handles server installation coordination — this issue should be moved to that tracker.

## Change summary

Multiple VS Code windows connected to the same remote host all download the VS Code Server in parallel after an update, causing conflicts and connection failures.
