# Issue #294336 — VSCode Server is being downloaded in all remote sessions after upgrading VS Code to a new version

[https://github.com/microsoft/vscode/issues/294336](https://github.com/microsoft/vscode/issues/294336)

## Summary

This is a detailed Remote-SSH concurrency report and should remain open, but it belongs in the VS Code team's Remote Development tracker rather than the core repository.

## Change summary

After a VS Code upgrade, multiple Remote-SSH windows concurrently install the updated VS Code Server, sometimes using different transfer paths and leaving some sessions unable to reconnect.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release so the Remote-SSH maintainers can coordinate server installation across concurrent sessions and ensure all windows reconnect to the same completed installation.
