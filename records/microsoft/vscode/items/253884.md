# Issue #253884 — Investigate tool re-routing and using the terminal tool a an entry point to sub-tools

[https://github.com/microsoft/vscode/issues/253884](https://github.com/microsoft/vscode/issues/253884)

## Summary

Keep this investigation open: current source still provides narrow Python/Jupyter recommendations, not general terminal-to-native-tool routing. Both implementation attempts were closed without merging, and the discussion leaves the choice between transparent routing and ordinary terminal execution with tracked edits unresolved.

## Change summary

Investigate using the terminal tool as a shared entry point for native operations while preserving command semantics and integrating file changes with chat.

## Best solution

Establish whether semantics-preserving native dispatch or terminal execution with chat edit tracking best delivers the intended simpler tool surface. Retain terminal fallback for unsupported command forms and account explicitly for notebook-specific representations before reducing exposed tools.
