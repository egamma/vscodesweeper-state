# Issue #253884 — Investigate tool re-routing and using the terminal tool a an entry point to sub-tools

[https://github.com/microsoft/vscode/issues/253884](https://github.com/microsoft/vscode/issues/253884)

## Summary

A real design gap remains on main, and maintainers are still weighing transparent terminal execution against robust delegation to native tools. Keep this canonical investigation open and classify it as under discussion.

## Change summary

Create a general mechanism that lets the terminal tool delegate suitable commands to native tools while preserving command semantics and safe fallback execution.

## Best solution

Prototype delegation from `runInTerminalTool.ts` that reroutes only commands whose complete semantics can be represented by a native tool, otherwise executing them normally. Consolidate narrower task-tool work under this design while retaining specialized notebook tools and adding comprehensive routing and fallback tests.
