## Summary

Still open — the default title path in `ChatModel.getDefaultTitle` uses the raw first request message text (first line, up to 200 chars), and if internal prompt context is present in that message, it leaks into the displayed session title. No fix commit references this issue, and the relevant title generation code is unchanged since the report.

The fix likely involves either sanitizing the message in `ChatModel.getDefaultTitle` (src/vs/workbench/contrib/chat/common/model/chatModel.ts) to exclude non-user-visible content, or ensuring the Copilot extension's custom title generation (extensions/copilot/src/extension/chatSessions/copilotcli/vscode-node/customSessionTitleServiceImpl.ts) does not pass system prompt content to the title.
