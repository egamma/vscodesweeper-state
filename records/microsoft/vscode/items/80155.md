# Issue #80155 — Convert inline comment to block comment, and vice-versa

[https://github.com/microsoft/vscode/issues/80155](https://github.com/microsoft/vscode/issues/80155)

## Summary

A real capability gap remains on current main: VS Code can toggle line or block comments independently, but cannot convert between their representations. The accepted Backlog request should remain open.

## Change summary

Add commands to convert selected line comments into a formatted block comment and convert a block comment back into line comments.

## Best solution

Define language-aware conversion semantics, then implement conversion commands in the editor comment contribution while preserving indentation and using each language's configured comment tokens.
