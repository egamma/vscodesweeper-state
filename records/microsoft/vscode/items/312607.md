# Issue #312607 — Can't "buffer" terminal commands anymore

[https://github.com/microsoft/vscode/issues/312607](https://github.com/microsoft/vscode/issues/312607)

## Summary

Confirmed conpty DLL bug: terminal input buffering (queuing commands while one executes) is broken when using the conpty DLL on Windows with PowerShell. Reporter verified disabling `terminal.integrated.windowsUseConptyDll` resolves it. No fix on main yet; routing to terminal-conpty area.

## Change summary

Typing commands while a previous command is still executing results in `^M` instead of executing the buffered command, when the conpty DLL is enabled on Windows.

## Best solution

Investigate and fix the input handling in the conpty DLL path so that buffered Enter keystrokes are processed correctly rather than appearing as literal `^M`. Likely in the conpty native layer or its integration in `src/vs/platform/terminal/node/terminalProcess.ts`. The black background symptom may be a separate PSReadLine version issue (see #311821).
