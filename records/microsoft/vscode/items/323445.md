# Issue #323445 — Credit annotations are confusing

[https://github.com/microsoft/vscode/issues/323445](https://github.com/microsoft/vscode/issues/323445)

## Summary

Team-authored UX feedback on credit annotations: the current labeling is ambiguous (per-turn vs per-model cost, 'credits' vs 'credits used'), and expensive subagent calls lack a prominent visual warning. The issues raised remain unaddressed on main.

## Change summary

Credit annotations in chat are confusing — unclear whether costs are per-turn or per-model, missing 'used/spent' qualifier, and no prominent warning for expensive subagent model usage.

## Best solution

Improve the credit annotation UI in the chat context usage widget: clarify labels (e.g. 'Turn cost: X'), make per-model costs for subagents more prominent, consider moving detailed breakdowns into hovers, and add a visual warning (e.g. '$$$') for expensive subagent calls. Work likely lives in `src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatContextUsageWidget.ts` and `chatContextUsageDetails.ts`.
