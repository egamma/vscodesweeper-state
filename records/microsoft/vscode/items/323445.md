# Issue #323445 — Credit annotations are confusing

[https://github.com/microsoft/vscode/issues/323445](https://github.com/microsoft/vscode/issues/323445)

## Summary

Keep open for credit-display design clarification: current code provides optional subagent credit labels and a session total, but those capabilities do not fully explain parent-model versus whole-turn costs. This team-authored report has no verified duplicate or issue-referencing fix that would justify closing it.

## Change summary

Make chat credit annotations distinguish session, turn, and subagent consumption without overwhelming the conversation.

## Best solution

Agree on a consistent cost hierarchy across response footers, subagent details, and the session hover, with explicit wording about each total's scope. Decide which information should remain visible at rest and how users should recognize expensive subagent model choices.
