  > getHistoryItems() in src/vs/workbench/contrib/scm/browser/scmHistoryViewPane.ts requests history using scm.graph.pageSize, then awaits merge-base resolution and builds graph view models. provideHistoryItems() in extensions/git/src/historyProvider.ts awaits Git log with short statistics and additional metadata enrichment before returning commits.
