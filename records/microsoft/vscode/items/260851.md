# Issue #260851 — Support for MSYS2 Git breaks in version 1.103 (The folder currently open doesn't have a git repository)

[https://github.com/microsoft/vscode/issues/260851](https://github.com/microsoft/vscode/issues/260851)

## Summary

Confirmed regression from commit 6c8a25ae adding `--show-superproject-working-tree` to `rev-parse`, which fails with MSYS2 git. An open PR (https://github.com/microsoft/vscode/pull/317226) already targets this fix — keeping open for that PR to land.

## Change summary

MSYS2 Git users get 'folder has no git repository' since 1.103 because `git rev-parse --show-superproject-working-tree` fails or returns unexpected output under MSYS2.

## Best solution

Land https://github.com/microsoft/vscode/pull/317226 which adds a fallback when `--show-superproject-working-tree` fails, restoring MSYS2 Git compatibility without removing submodule detection for standard Git.
