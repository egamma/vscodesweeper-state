# Issue #338626 — Placeholder text used as the only visible label for Search input field: A11y_VisualStudioCode_Labels or Instructions

[https://github.com/microsoft/vscode/issues/338626](https://github.com/microsoft/vscode/issues/338626)

## Summary

Fresh accessibility test-case report (part of the same recurring internal a11y sweep as the just-closed https://github.com/microsoft/vscode/issues/336374, which the reporter closed pointing here). Confirmed in the QuickInput widget source that the search field's accessible label falls back to the placeholder text with no persistent visible label, matching the report; routing to accessibility for a maintainer to weigh severity/scope rather than closing a brand-new, unreviewed item.

## Change summary

The Quick Open/search input field uses placeholder text as its only visible label, which disappears once text is entered, leaving low-vision/cognitive-disability users without a persistent label.

## Best solution

Track under the existing accessibility placeholder-as-label workstream (see https://github.com/microsoft/vscode/issues/321135 for the team's severity discussion on this same issue class); a maintainer should decide whether a visually-hidden persistent label is added around QuickInput's input box in src/vs/platform/quickinput/browser/quickInput.ts or whether this is accepted as low severity like prior instances.
