# Issue #347000 — Cannot keep or undo chat edits: “another chat in this session also changed it”

[https://github.com/microsoft/vscode/issues/347000](https://github.com/microsoft/vscode/issues/347000)

## Summary

Keep open: a second reporter independently confirms that both review actions become blocked in an apparently single-chat workflow. The exact rejection remains in current source, but neither a fixing commit nor a sufficiently established duplicate was found.

## Change summary

Keep and Undo can both reject pending Copilot edits as belonging to another chat, leaving the original conversation's review stuck across restarts.

## Best solution

Diagnose which persisted chat edit records cause the conflict and restore a safe way to finish review without overwriting genuinely independent edits. Compare the single-chat reports with the fork-related failure in https://github.com/microsoft/vscode/issues/345857 before consolidating them.
