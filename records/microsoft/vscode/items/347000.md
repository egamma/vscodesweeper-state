# Issue #347000 — Cannot keep or undo chat edits: “another chat in this session also changed it”

[https://github.com/microsoft/vscode/issues/347000](https://github.com/microsoft/vscode/issues/347000)

## Summary

Keep open: independent Windows and Linux reports confirm that edit review can remain blocked with only one chat. Current acceptance logic differs from the reported error, but neither a fixing commit nor a qualifying duplicate is established.

## Change summary

Keep and Undo reject pending chat edits as belonging to another chat, leaving the original conversation's review stuck across restarts.

## Best solution

Diagnose the persisted edit ownership behind the blocked review and restore safe acceptance and undo for legitimately owned changes. Preserve protection against reverting actual changes from another chat.
