# Issue #304063 — Sessions: Can't create a PR

[https://github.com/microsoft/vscode/issues/304063](https://github.com/microsoft/vscode/issues/304063)

## Summary

Keep open pending a focused check of the already-committed worktree scenario. The reporter documented an initial false refusal followed by recovery; newer PR creation infrastructure is promising, but no verified fix establishes that the reported path is resolved.

## Change summary

Create Pull Request initially treats an already-committed session worktree as having no changes available for a PR.

## Best solution

PR creation should recognize session commits relative to the base branch even when the working tree is clean. First establish which current provider and creation path handles this scenario, then either identify its landed fix or address the remaining false refusal without changing automatic committing.
