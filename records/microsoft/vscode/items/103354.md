# Issue #103354 — Extension API: QuickPick fuzzy search not finding results

[https://github.com/microsoft/vscode/issues/103354](https://github.com/microsoft/vscode/issues/103354)

## Summary

The extension QuickPick still uses restricted fuzzy matching, and preserving extension-supplied ordering remains a proposed API. Keep this accepted request open: the verified related issues separately cover matching and ordering, but no single specific canonical establishes coverage of the complete report.

## Change summary

Support noncontiguous matching in extension QuickPicks, including signed date labels, while allowing extensions to preserve their supplied result order.

## Best solution

Provide predictable noncontiguous matching for extension QuickPicks and a supported way to retain extension-supplied ordering. Coordinate matching with https://github.com/microsoft/vscode/issues/34088 and ordering with https://github.com/microsoft/vscode/issues/73904, resolving compatibility expectations before changing defaults.
