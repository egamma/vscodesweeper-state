# Issue #341828 — Remote agent host sessions often fail to open in Insiders 1.143 ("Couldn't load this conversation", and re-opening doesn't retry)

[https://github.com/microsoft/vscode/issues/341828](https://github.com/microsoft/vscode/issues/341828)

## Summary

Team-authored, milestoned (1.143.0) regression with telemetry evidence, and an open PR already references it. I did not verify the cause in the checkout. The issue stays open until the linked PR merges.

## Change summary

Remote agent host sessions in the Agents window fail to load. The failed load is never retried, because the error path keeps the current chat resource, and replacing a provider cancels in-flight loads.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/341871. It should retry on setChat after a failed load and treat provider-replacement cancellations as retryable rather than as failures.
