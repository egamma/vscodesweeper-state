# Issue #249337 — drag and move file twice will cause file disappear

[https://github.com/microsoft/vscode/issues/249337](https://github.com/microsoft/vscode/issues/249337)

## Summary

The data-loss race remains present on current main: repeating a slow Explorer move leaves a stale source operation, and confirming overwrite can delete the successfully moved destination before the missing source is detected.

## Change summary

Dragging the same file to a destination twice while the first move is pending can make the file disappear after confirming replacement.

## Best solution

Make overwrite moves fail safely when the source no longer exists, preserving the existing destination, and cover this ordering with a file-service regression test.
