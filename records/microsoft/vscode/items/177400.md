# Issue #177400 — selecting text highlights match only if the length is less than or equal to 200

[https://github.com/microsoft/vscode/issues/177400](https://github.com/microsoft/vscode/issues/177400)

## Summary

Implemented and shipped: selection-highlight length is now configurable, including unlimited and multiline highlighting.

## Change summary

Make the 200-character selection-highlight limit configurable and support multiline matches.

## Best solution

Use `editor.selectionHighlightMaxLength` to raise or remove the limit and `editor.selectionHighlightMultiline` for multiline selections; commit 034724ad11429e59f66584f1a6cd6e87c8d7aafd provides the requested behavior.
