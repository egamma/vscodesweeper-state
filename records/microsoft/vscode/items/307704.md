# Issue #307704 — Cannot navigate to full list of deprecated extensions via Tab key

[https://github.com/microsoft/vscode/issues/307704](https://github.com/microsoft/vscode/issues/307704)

## Summary

Team-authored accessibility bug about Tab navigation in the deprecated extensions list. A MEMBER comment suggests arrow keys are the correct navigation pattern for lists, but no resolution has been reached — keeping open for the accessibility team to decide.

## Change summary

Tab key only focuses the first deprecated extension in the list; subsequent Tab presses do not move to other items.

## Best solution

The accessibility team should determine whether this is a real gap (Tab should cycle through list items for screen reader users) or whether arrow-key navigation is sufficient and the issue can be closed as as-designed. The extensions list uses WorkbenchPagedList in src/vs/workbench/contrib/extensions/browser/extensionsViewer.ts, where arrow keys are the standard navigation pattern.
