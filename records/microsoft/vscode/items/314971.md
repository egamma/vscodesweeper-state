[https://github.com/microsoft/vscode/issues/314971](https://github.com/microsoft/vscode/issues/314971)

## Summary

This request for a provider-side hidden flag on LanguageModelChatInformation is subsumed by the broader model visibility API tracked in #325455, which exposes setModelHidden/setGroupHidden — enabling providers to hide their own models immediately after registration. Proposing duplicate close.

## Change summary

Allow language model providers to mark models as hidden by default in the Model Picker via a `hidden` property on LanguageModelChatInformation.
