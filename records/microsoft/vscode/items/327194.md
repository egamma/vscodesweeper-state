# Issue #327194 — Settings.json incorrectly marks permitted extension versions as not accepted

[https://github.com/microsoft/vscode/issues/327194](https://github.com/microsoft/vscode/issues/327194)

## Summary

Real regression with a milestone (1.133.0) already assigned and a maintainer-confirmed root cause, so this stays open for the scheduled fix rather than being closed now.

## Change summary

Settings.json flags valid `extensions.allowed` version-array entries (e.g. `"ms-vscode.cpptools": ["1.31.4"]`) as invalid, even though the setting still functions correctly at runtime.

## Best solution

Anchor the `patternProperties` regexes in the `extensions.allowed` schema in src/vs/platform/extensionManagement/common/extensionManagement.ts (add `^`/full-match anchors) so the bare-publisher pattern (`([a-z0-9A-Z][a-z0-9-A-Z]*)$`) no longer also matches dotted extension IDs like `ms-vscode.cpptools`, which currently forces the value to satisfy both the extension-ID and publisher sub-schemas.
