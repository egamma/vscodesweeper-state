# Issue #327194 — Settings.json incorrectly marks permitted extension versions as not accepted

[https://github.com/microsoft/vscode/issues/327194](https://github.com/microsoft/vscode/issues/327194)

## Summary

Confirmed regression from the vscode-json-languageservice upgrade in PR #325505: patternProperties in the extensions.allowed schema aren't anchored, so a property name can match both the extension-ID and publisher patterns, causing valid version arrays to be flagged invalid even though runtime behavior still accepts them. A fix is already open in PR #329744, so this should stay open until it merges.

## Change summary

settings.json shows a false 'Value is not accepted' warning on extensions.allowed version arrays/strings, even though the setting still works correctly at runtime.

## Best solution

Land and merge https://github.com/microsoft/vscode/pull/329744, which anchors the extensions.allowed patternProperties regexes so extension IDs no longer also match the publisher-only pattern.
