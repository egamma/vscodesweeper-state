# Issue #338581 — Plugin marketplace: SHA-pinned source is discoverable but installation uses git clone --branch

[https://github.com/microsoft/vscode/issues/338581](https://github.com/microsoft/vscode/issues/338581)

## Summary

Confirmed real, current defect: the reporter's exact failing `git clone --branch <sha>` command matches source on main, where the marketplace clone path passes a full commit SHA straight through as a Git branch name.

## Change summary

Installing a plugin from a commit-SHA-pinned plugin marketplace fails because the desktop clone path passes the SHA as `git clone --branch <sha>`, which Git rejects since a SHA is not a branch name.

## Best solution

In `AgentPluginRepositoryService._cloneRepository`/`ensureRepository` (agentPluginRepositoryService.ts), don't forward a full-SHA `marketplace.ref` as `--branch`; clone without `--branch` and follow up with `IPluginGitService.checkoutCommit(repoDir, sha)`, mirroring the ref/sha split already implemented for individual plugin sources in `pluginSources.ts`'s `_checkoutRevision`.
