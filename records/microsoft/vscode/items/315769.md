# Issue #315769 — Agents: Agents window does not respect the current branch/repo context from VS Code

[https://github.com/microsoft/vscode/issues/315769](https://github.com/microsoft/vscode/issues/315769)

## Summary

Repository handoff is present, but inheriting the editor's checked-out branch is not guaranteed across isolation modes. Keep this team-authored request open for a contextual-default design that preserves existing sessions and user choices.

## Change summary

Preselect the invoking VS Code workspace and checked-out branch when opening a fresh Agents Window composer, while allowing users to change both.

## Best solution

A fresh composer opened explicitly from VS Code should start with that editor's repository and checked-out branch, without changing the checkout or replacing an occupied draft. Establish how this contextual default interacts with worktree isolation and existing Agents Window state before implementation.
