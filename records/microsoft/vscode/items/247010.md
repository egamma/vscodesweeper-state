# Issue #247010 — Clipboard copy notebook cell output doesn't doesn't work properly with multiple display() calls

[https://github.com/microsoft/vscode/issues/247010](https://github.com/microsoft/vscode/issues/247010)

## Summary

The defect remains on current main: copying targets one output model, while separate display outputs are rendered as independently positioned DOM containers without clipboard normalization.

## Change summary

Copying multiple notebook display outputs either captures only the clicked output or concatenates selected outputs without line breaks.

## Best solution

Make notebook output copying consistent: preserve selected text when present, otherwise copy the complete cell output, and normalize separators between independently rendered outputs in the notebook webview.
