## Summary

This is a specific symptom of the broader, actively-tracked issue https://github.com/microsoft/vscode/issues/321765 — custom agent frontmatter (model, tools, and `user-invocable`) is not fully applied on VS Code startup until the agent file is opened/edited or saved, after which it works correctly. That open issue explicitly describes 'Agents with `user-invocable: false` are still shown in the UI' as one of its symptoms and has maintainer engagement, so this should be consolidated there rather than tracked separately.

## Change summary
