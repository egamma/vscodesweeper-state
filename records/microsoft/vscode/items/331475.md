# Issue #331475 — Custom agents with `user-invocable: false` are shown in the agent dropdown after VS Code startup

[https://github.com/microsoft/vscode/issues/331475](https://github.com/microsoft/vscode/issues/331475)

## Summary

Verified duplicate: this is a narrower instance of the broader, already-open bug at https://github.com/microsoft/vscode/issues/321765, which explicitly describes custom agent frontmatter (model, tools, and `user-invocable`) not being applied until the agent file is opened and saved, with `user-invocable: false` agents remaining visible in the meantime.

## Change summary

Custom agents with `user-invocable: false` still show in the agent dropdown right after VS Code startup, until the agent file is opened and its frontmatter is touched.

## Best solution
