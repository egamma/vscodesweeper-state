# Issue #327604 — Agents - subagent UX read-only indicator

[https://github.com/microsoft/vscode/issues/327604](https://github.com/microsoft/vscode/issues/327604)

## Summary

The redundant read-only treatment remains on current main: read-only subagent chats receive both a lock in the tab and a separate generic banner. This team-authored UX polish should remain open and is bounded enough for implementation.

## Change summary

Remove or visually integrate the redundant read-only banner shown for subagent chats that already have a lock indicator in their tab.

## Best solution

Use the tab lock as the quiet visual indicator for an ordinary read-only subagent chat, while retaining banners that communicate actionable or specific states such as archived sessions and unavailable remote hosts. Ensure the tab's accessible name or equivalent announcement still communicates that the chat is read-only.
