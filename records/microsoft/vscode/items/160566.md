# Issue #160566 — Adjust settings dialog suggests language, not a script

[https://github.com/microsoft/vscode/issues/160566](https://github.com/microsoft/vscode/issues/160566)

## Summary

Keep open: the Unicode highlighting quick pick still offers language-based exclusions rather than the requested script-aware wording. The closest matching open report is newer and cannot serve as the canonical for this re-reviewed item.

## Change summary

Describe shared Cyrillic characters by their writing script rather than presenting them solely through the Russian language.

## Best solution

Make Unicode highlighting exclusion choices accurately describe characters shared across languages, while keeping their wording consistent with the actual exemption scope. A Cyrillic-script label must not imply whole-script coverage if selecting it still enables only a locale-specific character set.
