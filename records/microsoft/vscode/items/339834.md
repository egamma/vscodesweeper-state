# Issue #339834 — On restart, the individual last updated times for a chat and its peers changed to all be the same

[https://github.com/microsoft/vscode/issues/339834](https://github.com/microsoft/vscode/issues/339834)

## Summary

Keep open: the reporter completed the requested Insiders retest and confirmed that restarting still resets distinct chat timestamps. Current source preserves individual timestamps in the frontend cache, but that does not establish that live restoration leaves them unchanged.

## Change summary

Preserve each main and peer chat's individual last-activity timestamp across restart instead of showing all chats as recently updated.

## Best solution

Ensure cached timestamps survive subsequent host discovery and session restoration without treating passive reads as chat activity. Diagnose the transition from restored cache to authoritative host state before choosing the fix.
