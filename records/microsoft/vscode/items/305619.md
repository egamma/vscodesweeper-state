# Issue #305619 — Copilot doesn't see python test discovery errors (pytest)

[https://github.com/microsoft/vscode/issues/305619](https://github.com/microsoft/vscode/issues/305619)

## Summary

Keep open: the current testing tool still has a path that omits diagnostic output when no tests fail, consistent with the reported discovery failure. The supplied import-error example is sufficient to retest; the exact pytest-provider result reaching today's tool remains unverified.

## Change summary

Expose pytest discovery errors to the agent instead of returning an unexplained zero-test result.

## Best solution

Make the integrated testing tool distinguish discovery failure from a successful run with no failing tests and provide the available discovery diagnostic to the model. First establish how the Python test provider represents the supplied import failure, then cover that representation in the testing tool's regression tests.
