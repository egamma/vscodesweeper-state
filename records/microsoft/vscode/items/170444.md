# Issue #170444 — Allow `--wait` flag to work with split editors

[https://github.com/microsoft/vscode/issues/170444](https://github.com/microsoft/vscode/issues/170444)

## Summary

A real gap remains on current main: `--wait` completes when any matching split editor closes. Prior maintainer discussion classified changing this established behavior as a feature request, and the issue's `keep` label supports retaining it for design discussion.

## Change summary

Make CLI `--wait` remain blocked until every editor instance for the supplied files has closed.

## Best solution

Update `whenEditorClosed` in `src/vs/workbench/browser/editor.ts` to account for other open editor instances of each resource before releasing the wait marker, potentially behind a compatibility setting as previously suggested by a maintainer.
