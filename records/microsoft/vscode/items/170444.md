# Issue #170444 — Allow `--wait` flag to work with split editors

[https://github.com/microsoft/vscode/issues/170444](https://github.com/microsoft/vscode/issues/170444)

## Summary

The requested split-editor behavior remains missing: current --wait tracking releases a saved file on its first matching editor closure, without checking other groups. Keep this accepted Backlog request open; earlier maintainer discussion treats it as a feature and leaves compatibility with existing behavior unresolved.

## Change summary

Allow --wait to remain blocked until all editor instances of each requested file are closed.

## Best solution

Provide file-level completion semantics for --wait across split editor groups, with consistent handling of saved and unsaved files. Settle whether this becomes the default or an opt-in behavior before implementation, and make the CLI help describe the chosen contract.
