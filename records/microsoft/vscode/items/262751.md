- **Current built-in capability boundary:** extensions/git/src/quickDiffProvider.ts supplies a fixed empty-ref original resource in GitQuickDiffProvider.provideOriginalResource and a fixed HEAD resource in StagedResourceQuickDiffProvider.provideOriginalResource. src/vs/workbench/contrib/scm/browser/quickDiff.contribution.ts registers decoration appearance and interaction settings, not an arbitrary Git commit baseline. Existing staged/working-tree provider selection does not cover this request.
- **Comparison commands are not decoration baselines:** extensions/git/src/commands.ts implements git.graph.compareWithRemote and git.graph.compareWithMergeBase by opening changes between refs; git.timeline.compareWithSelected invokes vscode.diff. These comparison surfaces do not change the baseline of decorations in ordinary working-file editors.
