# Issue #313107 — Agents: Consider surfacing pinned sessions at the top

[https://github.com/microsoft/vscode/issues/313107](https://github.com/microsoft/vscode/issues/313107)

## Summary

Keep open: pinned sessions have a dedicated sidebar section, but the top-of-window session picker does not distinguish them. This team-authored Backlog request still needs a presentation decision; no verified fix or older canonical covers the same ask.

## Change summary

Make pinned sessions directly discoverable from the top of the Agents Window, through tabs or a pinned-session entry point.

## Best solution

Provide pin-aware access in the Agents Window's existing top navigation while preserving the sidebar's pin state as the source of truth. Decide whether pins should appear directly as tabs or through a compact picker entry before implementation.
