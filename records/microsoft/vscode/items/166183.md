# Issue #166183 — Wrong session restored after main window closed while another instance was running in debugger

[https://github.com/microsoft/vscode/issues/166183](https://github.com/microsoft/vscode/issues/166183)

## Summary

The defect remains source-reproducible on current main: when an Extension Development Host is the final window to close, its state replaces the ordinary window used for next-start restoration. The issue already has the appropriate bug/debug routing and should remain open.

## Change summary

Closing the main VS Code window before its Extension Development Host causes the development session, rather than the main session, to be restored on the next launch.

## Best solution

Preserve the last ordinary VS Code window as `lastActiveWindow` when only Extension Development Host windows remain, while continuing to track development-host state separately in `lastPluginDevelopmentHostWindow`.
