# Issue #265995 — Markdown Preview: Preview links on hover

[https://github.com/microsoft/vscode/issues/265995](https://github.com/microsoft/vscode/issues/265995)

## Summary

Valid feature request: the markdown preview does not show link URLs on hover, unlike browsers. A maintainer (mjbvz) explicitly kept this open. The feature is not yet implemented on main.

## Change summary

Show the actual URL when hovering over a link in the Markdown Preview, matching standard browser behavior.

## Best solution

Add a `title` attribute (set to the resolved href) on rendered `<a>` elements in the markdown preview's webview, or implement a lightweight tooltip in the preview client script (`extensions/markdown-language-features/preview-src/index.ts`). This is a small, self-contained change within the built-in markdown extension.
