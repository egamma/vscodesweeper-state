# Issue #323191 — Optimized tool selection breaks Deepseek cache

[https://github.com/microsoft/vscode/issues/323191](https://github.com/microsoft/vscode/issues/323191)

## Summary

Valid feature request: the client-side tool-grouping optimization dynamically varies the tool list per request, which invalidates prompt caching on providers like DeepSeek. Reporter requests a per-model or global toggle to disable it for BYOK models with large contexts and aggressive caching.

## Change summary

Request an option to disable VS Code's client-side tool selection optimization for BYOK/extension-provided models that benefit from stable prompt prefixes (e.g., DeepSeek's prompt caching).

## Best solution

Add a BYOK/model-level setting (or expose `supportsToolSearch`-like flag for extension-provided models) that skips the `toolGrouping.compute()` path in `defaultIntentRequestHandler.ts`, returning all tools unfiltered. This preserves prompt prefix stability for models with aggressive caching like DeepSeek.
