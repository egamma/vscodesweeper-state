# Issue #323191 — Optimized tool selection breaks Deepseek cache

[https://github.com/microsoft/vscode/issues/323191](https://github.com/microsoft/vscode/issues/323191)

## Summary

Keep open: the requested reliable opt-out from dynamic tool selection is not covered by the documented settings on the traced request path. The second reporter supplies a constrained workaround, but preserving cache-friendly tool definitions without reducing the selected tool set still needs a product decision.

## Change summary

Allow BYOK and extension-provided models to disable dynamic tool grouping so changing tool definitions does not invalidate their prompt cache.

## Best solution

Provide a supported cache-friendly tool-selection mode in the Copilot Chat request path, with explicit handling of model tool limits. Decide whether the existing global disable setting should satisfy this request or whether model-specific control is needed to preserve optimization for other models.
