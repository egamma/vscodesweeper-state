# Issue #208603 — Mutli-file diff: Support undo operation after revert

[https://github.com/microsoft/vscode/issues/208603](https://github.com/microsoft/vscode/issues/208603)

## Summary

Immediate undo still has a source-confirmed targeting gap: clicking Revert Block in another file can leave keyboard focus and the active undo target on the previously focused file. The later undo-stop fix addresses edit grouping, not this multi-file targeting problem.

## Change summary

Ctrl+Z immediately after Revert Block should restore the reverted block in the affected file without requiring another editor click.

## Best solution

Make immediate Undo target the document whose block was reverted, including when its gutter action was clicked while another file had focus. Preserve the existing per-operation undo boundaries and unrelated files' undo histories.
