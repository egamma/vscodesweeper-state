# Issue #295377 — Thinking titles are sometimes not saved

[https://github.com/microsoft/vscode/issues/295377](https://github.com/microsoft/vscode/issues/295377)

## Summary

Still unfixed on main. The PR #295378 was closed without merging, and the root cause identified by @connor4312 (thinking parts lack toJSON, causing the mutation log differ to miss late-arriving title updates) has not been addressed.

## Change summary

Thinking titles that arrive after the chat response completes are not saved because the mutation log's differ holds a mutable reference and misses the change.

## Best solution

Implement `toJSON` on thinking parts and use an `IObservable` for the `generatedTitle` field, as outlined by @connor4312 in the discussion. The fix is in `src/vs/workbench/contrib/chat/common/model/chatModel.ts` and the thinking part types in `src/vs/workbench/contrib/chat/common/chatService/chatService.ts`. This ensures the mutation log captures an immutable snapshot and detects the title update.
