# Issue #295377 — Thinking titles are sometimes not saved

[https://github.com/microsoft/vscode/issues/295377](https://github.com/microsoft/vscode/issues/295377)

## Summary

The persistence defect remains source-reproducible on current main: generated thinking titles mutate response-part objects after completed requests have been sealed, so the operation log can retain the same mutated reference without recording a durable update. This team-authored bug is accepted in the On Deck milestone and has no merged fix, so it should remain open.

## Change summary

Persist thinking titles that are generated after a chat response completes so they survive session reloads.

## Best solution

Make late thinking-title state observable to the chat model and serialize an immutable snapshot for operation-log comparison, ensuring the title triggers persistence while allowing the request to become sealed afterward.
