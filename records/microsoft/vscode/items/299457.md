# Issue #299457 — Copilot can not edit plain json for `.jpynb` notebooks

[https://github.com/microsoft/vscode/issues/299457](https://github.com/microsoft/vscode/issues/299457)

## Summary

Keep open: current notebook editing surfaces still lack arbitrary metadata editing, consistent with the maintainer's explanation. The notebook tools have evolved since the report; the supplied steps suffice to retest the misleading success behavior, which was not confirmed by execution.

## Change summary

Copilot reports successful notebook metadata or tag edits even though the requested JSON changes are not applied.

## Best solution

Notebook editing should either apply explicitly requested metadata changes or clearly report that they are unsupported, without claiming success or repeatedly attempting ineffective edits. Decide whether metadata editing belongs in the supported contract before expanding the notebook tooling.
