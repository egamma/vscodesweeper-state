# Issue #250159 — Settings search not matching across title + description

[https://github.com/microsoft/vscode/issues/250159](https://github.com/microsoft/vscode/issues/250159)

## Summary

Still reproduces on main: the settings search requires all query words to match within the same field (key OR description), never combining a key match with a description match across fields.

## Change summary

Settings search does not match when one query word appears in the setting key/title and another appears in its description.

## Best solution

Extend `SettingMatches._doFindMatchesInSetting` to allow cross-field matching — after the per-field passes, check if the union of key-matching words and description-matching words covers all query words, and if so, treat it as a match (with a lower-priority match type than same-field matches).
