[https://github.com/microsoft/vscode/issues/129980](https://github.com/microsoft/vscode/issues/129980)

## Summary

Still an open discussion about whether `editor.autoClosingDelete` should default to `always` instead of `auto`. The default remains `auto` on current main; no change has been made. A team member explicitly requested waiting for more feedback, and the issue has received no community upvotes — leaving open as under-discussion.

## Change summary

Change the default value of `editor.autoClosingDelete` from `auto` to `always` so that backspace always removes adjacent closing brackets/quotes.

## Best solution

The editor team should decide whether the `auto` default provides enough value over `always` given the limitations the reporter describes (state lost on cursor move, tab switch, file reopen, snippets, auto-surround). If the team agrees, the change is a one-line default swap in `src/vs/editor/common/config/editorOptions.ts` line 6041. Otherwise close as `*as-designed`.
