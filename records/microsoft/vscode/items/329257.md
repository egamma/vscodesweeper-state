# Issue #329257 — Right click causes Quick Open menu to disappear

[https://github.com/microsoft/vscode/issues/329257](https://github.com/microsoft/vscode/issues/329257)

## Summary

This matches the right-click dismissal of Quick Pick inputs already tracked by an older, open issue with maintainer diagnosis and independent confirmations. Consolidate there while retaining this report's Quick Open reproduction and recording.

## Change summary

Right-clicking the Quick Open input to paste dismisses the picker before the paste can be used.

## Best solution

Resolve context-menu focus handling for Quick Pick inputs under https://github.com/microsoft/vscode/issues/153267 so opening an input's context menu preserves the picker and allows pasting into its active input.
