## Change summary

Right-clicking inside the Quick Open (Ctrl+P) input box closes the picker instead of showing a paste context menu, so pasted text goes nowhere.

## Best solution

If confirmed on a specific OS/version, the fix likely belongs in src/vs/platform/quickinput/browser/quickInputController.ts, where focusTracker.onDidBlur() calls hide(QuickInputHideReason.Blur) — the native context menu opened by right-clicking a text input can steal window/element focus and trigger this blur-hide path before the user can interact with the menu; that path may need to ignore blur events caused by a native context menu.
