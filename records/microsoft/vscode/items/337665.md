# Issue #337665 — VSCode 1.139 forces rounded corners of Window Frame on Linux

[https://github.com/microsoft/vscode/issues/337665](https://github.com/microsoft/vscode/issues/337665)

## Summary

Genuine gap: on current main, `defaultBrowserWindowOptions` (src/vs/platform/windows/electron-main/windows.ts) never sets `roundedCorners`, so there is no way to opt out of Electron's default rounded window corners on Linux — but this was filed hours ago with no maintainer or community traction yet, so it should stay open for discussion rather than be acted on immediately.

## Change summary

Add a setting to disable the rounded window-frame corners that a recent Electron update introduced on Linux, since `window.titleBarStyle: native` doesn't help and there's no `roundedCorners: false` override exposed.

## Best solution

If accepted, expose a Linux-scoped window setting (e.g. under the `window` section) that maps to Electron's `roundedCorners: false` BrowserWindowConstructorOptions flag in defaultBrowserWindowOptions; needs a maintainer decision on setting name/scope before implementation.
