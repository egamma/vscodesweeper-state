[https://github.com/microsoft/vscode/issues/337665](https://github.com/microsoft/vscode/issues/337665)

## Summary

Keep open as a request to control Linux window-frame rounding independently of workbench styling. The inspected settings do not cover this capability, and neither related issue establishes a canonical for the same reported symptom.

## Change summary

Allow Linux users to retain square outer window corners without giving up the custom title bar.
