# Issue #272967 — Make behavior of "Show integrated terminal" more closely match "Create new terminal" in multi-root workspace

[https://github.com/microsoft/vscode/issues/272967](https://github.com/microsoft/vscode/issues/272967)

## Summary

The core terminal selects the expected workspace-folder working directory, while the incorrect virtual-environment activation is owned by the VS Code Python environment tooling. This should remain open and be moved to the Python Environments tracker for confirmation and investigation.

## Change summary

Opening the integrated terminal from a file in a multi-root workspace activates the first workspace folder's Python environment instead of the environment associated with the terminal's working directory.

## Best solution

In the Python Environments extension, resolve terminal auto-activation against the terminal working directory or corresponding workspace folder so each multi-root terminal receives the correct selected environment. Preserve the core terminal behavior that derives the working directory from the active editor.
