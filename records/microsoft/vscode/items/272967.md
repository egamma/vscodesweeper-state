## Summary

The reported behavior — wrong Python virtual environment activated in a multi-root workspace terminal — is owned by the Microsoft Python extension (ms-python.python), which lives outside this repo. VS Code core correctly sets the terminal's working directory to the workspace folder matching the focused editor; the venv activation logic is entirely in the Python extension. A team member already pointed toward the Python Environments extension as the solution path.

## Change summary
