# Issue #162157 — Search tree - selected item should be kept in the viewport

[https://github.com/microsoft/vscode/issues/162157](https://github.com/microsoft/vscode/issues/162157)

## Summary

Keep open: switching search results from list to tree still refreshes the hierarchy without revealing the selected result. The maintainer discussion already settles the multiselection behavior: reveal the first selected item.

## Change summary

Keep the first selected search result visible when switching results from list layout to tree layout.

## Best solution

Make the search layout transition preserve the user's location by leaving the first selected result visible after the hierarchy refresh completes, without changing selection or moving keyboard focus.
