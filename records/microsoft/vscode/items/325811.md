# Issue #325811 — VSCode Chat add support for dynamic and changing APIKeys for some endpoints

[https://github.com/microsoft/vscode/issues/325811](https://github.com/microsoft/vscode/issues/325811)

## Summary

Valid feature request for OAuth client-credentials token refresh on custom BYOK endpoints. The existing BYOK infrastructure supports static API keys and Azure Entra ID auth, but not generic OAuth token refresh flows for arbitrary endpoints. Low community signal so far (0 upvotes).

## Change summary

Add support for dynamic OAuth token refresh (client_id/client_secret → access_token) when calling custom LLM endpoints via BYOK.

## Best solution

Extend the custom endpoint BYOK provider (`extensions/copilot/src/extension/byok/vscode-node/customEndpointProvider.ts`) to support an OAuth client-credentials auth mode that fetches and caches a short-lived access token before each request, similar to how the Azure provider already handles Entra ID tokens. This could be modeled as a new `authType` in `chatLanguageModels.json` configuration.
