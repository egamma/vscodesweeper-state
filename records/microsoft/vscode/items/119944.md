# Issue #119944 — Color picker glitch in CSS when use Emmet cheats

[https://github.com/microsoft/vscode/issues/119944](https://github.com/microsoft/vscode/issues/119944)

## Summary

Still present on main: color decorations are not removed on text change, so they visually jump to wrong positions during edits (e.g. Emmet completions) until the debounce timer fires and recomputes. alexdima's suggested fix (remove stale decorations immediately on content change) was never implemented.

## Change summary

Color box decorations briefly appear at wrong positions after text replacements because they stick to a relative offset and only recompute after a debounce delay.

## Best solution

In `colorDetector.ts`, immediately clear (or hide) existing color decorations in the `onDidChangeModelContent` handler before starting the debounce timer, so stale decorations don't render in incorrect positions during the recompute wait. This was alexdima's suggestion from 2021.
