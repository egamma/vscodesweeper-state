# Issue #295012 — askQuestions - when only question is freeform text, confused on where to answer

[https://github.com/microsoft/vscode/issues/295012](https://github.com/microsoft/vscode/issues/295012)

## Summary

Team-authored UX polish issue about freeform-only askQuestions being confusing — substantial carousel polish landed after this was filed (commits 2f76a2d9722, 6495844b86c) but none reference this issue, so it's unclear whether the specific single-freeform-question confusion was addressed. Keeping open.

## Change summary

When askQuestions presents only a freeform text input, users don't realize they should answer in the carousel widget and try to type in the main chat input instead.

## Best solution

Ensure the freeform-only askQuestions state visually draws attention to the answer area (e.g. auto-focus the textarea, add a clearer prompt label) so users don't mistake the native chat input as the reply target. The carousel polish in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatQuestionCarouselPart.ts` may have partially addressed this — a maintainer should verify on current main.
