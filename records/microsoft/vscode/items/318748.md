# Issue #318748 — Custom endpoint language models display id instead of name in model picker

[https://github.com/microsoft/vscode/issues/318748](https://github.com/microsoft/vscode/issues/318748)

## Summary

Known bug acknowledged by a team member: custom endpoint models with the same `id` but different `name` values collide in the picker and in model override resolution. The team is actively looking into it.

## Change summary

Custom endpoint language models display the `id` field instead of the user-configured `name` in the model picker and Manage Language Models UI, causing indistinguishable entries when the same model is configured twice with different parameters.

## Best solution

The model identifier and display name for BYOK/custom endpoint models should incorporate the user-configured `name` (or the parent group name) so that models sharing the same underlying `id` but with different configurations are distinguishable in the picker and uniquely referenceable in model override settings like `chat.utilityModel`. The team member (vritant24) confirmed this is a known issue under active investigation.
