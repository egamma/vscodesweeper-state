# Issue #344711 — Cloud automations overwhelm the automations UI

[https://github.com/microsoft/vscode/issues/344711](https://github.com/microsoft/vscode/issues/344711)

## Summary

Keep open as a request for automation-list filtering. Current ownership grouping and the global cloud-automation setting do not provide selective cloud or repository filters across definitions and run history.

## Change summary

Provide controls to hide cloud automation runs and filter automation definitions and runs by repository.

## Best solution

Provide discoverable presentation filters in the Agents Window Automations view so users can focus on relevant providers and repositories without disabling cloud automation management or changing scheduled execution.
