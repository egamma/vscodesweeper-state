# Issue #268111 — Add API / command for showing a specific local chat session

[https://github.com/microsoft/vscode/issues/268111](https://github.com/microsoft/vscode/issues/268111)

## Summary

The requested capability — creating a chat session with a unique ID and later restoring it via command — remains unimplemented on current main. The `IChatViewOpenOptions` interface has no session-ID parameter, and the proposed chat sessions API covers customization providers, not session restore. A maintainer (roblourens) asked 'Still relevant?' but received no reply; the feature gap persists.

## Change summary

Allow extensions to create a chat session with a unique ID and later reopen that same session via a command argument.

## Best solution

Add a `sessionId` parameter to `IChatViewOpenOptions` (or a dedicated command) so extensions can both tag a new session and later reveal it by ID. This belongs in the chat API area (`src/vs/workbench/contrib/chat/browser/actions/chatActions.ts` and the proposed extension API surface).
