# Issue #268111 — Add API / command for showing a specific local chat session

[https://github.com/microsoft/vscode/issues/268111](https://github.com/microsoft/vscode/issues/268111)

## Summary

Keep open: current commands and provider APIs do not cover the complete extension workflow of creating an identifiable local chat and restoring it later. Internal session-opening support exists, but the extension-facing identity contract remains missing.

## Change summary

Let extensions create a local chat session and later reopen that same conversation using a persistent identifier.

## Best solution

Provide a supported extension-facing create-and-reopen contract over existing local chat persistence, with a session identifier that an extension can retain. Reuse existing session-opening behavior rather than requiring extensions to implement a session provider.
