# Issue #235684 — Reconsider auto vacuuming sqlite state.vscdb files? It saved 776MB on my install.

[https://github.com/microsoft/vscode/issues/235684](https://github.com/microsoft/vscode/issues/235684)

## Summary

Automatic reclamation of unused workspace-storage space remains missing; the existing cleanup command requires deleting stored entries and does not cover this request. Keep the accepted Backlog item open: the earlier vacuum-related test failures explain the caution but do not establish that safe automatic compaction is impossible.

## Change summary

Automatically compact state.vscdb databases periodically to reclaim unused space without deleting live workspace state.

## Best solution

Establish whether bounded, non-destructive automatic compaction can reclaim substantial unused space without impairing storage reliability or responsiveness. Any renewed design should address the previous SQLite contention/test failures and include databases belonging to inactive workspaces.
