[https://github.com/microsoft/vscode/issues/340700](https://github.com/microsoft/vscode/issues/340700)

## Summary

Thanks for the report. The accessibility concern is plausible but unverified: the search option toggles (match case, whole word, regex) are shown as selected only through a background and border colour change, and the report's version string (1.41.0) looks wrong. It stays open and needs a maintainer decision, because the fix is a shared design choice for all toggle controls and not specific to Search.

## Change summary

Search option toggles (match case, whole word, regex) show their selected state through colour alone, with no non-colour indicator (WCAG 1.4.1).

## Best solution

Decide on a non-colour selected-state treatment in the shared Toggle widget (src/vs/base/browser/ui/toggle/toggle.ts and its CSS). That change would then apply consistently to the Search, Find and filter toggles. Check how high-contrast themes already render it.
