# Issue #318939 — VS Code does not terminate active MCP sessions on exit

[https://github.com/microsoft/vscode/issues/318939](https://github.com/microsoft/vscode/issues/318939)

## Summary

Keep open: the reporter confirmed the failure on 1.122.1, and current source distinguishes explicit HTTP session closure from transport disposal without an awaited MCP shutdown step. Investigate graceful exit separately from force quit, where client-side cleanup cannot be guaranteed.

## Change summary

Closing VS Code leaves active server-side MCP sessions behind instead of explicitly terminating them.

## Best solution

Graceful shutdown should attempt authenticated termination of active streamable-HTTP sessions within a bounded shutdown budget. Forced termination needs server-side expiry or disconnect handling rather than a guarantee that the terminated client sends cleanup requests.
