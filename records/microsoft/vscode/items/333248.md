[https://github.com/microsoft/vscode/issues/333248](https://github.com/microsoft/vscode/issues/333248)

## Summary

Fresh, team-authored bug report with a clear repro: restoring a checkpoint while a pending agent question is on screen leaves the question widget orphaned/stuck in the transcript. No fix or discussion yet; routing to the chat area since the exact code path (elicitation/question-tool cleanup on checkpoint restore) needs a maintainer to trace.

## Change summary

After restoring a chat checkpoint while an agent question widget is pending, the question widget remains visible instead of being dismissed.

## Best solution

Ensure checkpoint restore (workbench.action.chat.restoreCheckpoint / restoreSnapshot path in chatEditingActions.ts) also hides/rejects any pending elicitation or question-carousel part (see ChatElicitationRequestPart.hide() and chatQuestionCarouselPart.ts) tied to the removed requests, so no orphaned widget remains in the transcript.
