# Issue #143991 — DAP - Terminate Request is not sent for "Attach" Configurations

[https://github.com/microsoft/vscode/issues/143991](https://github.com/microsoft/vscode/issues/143991)

## Summary

Still present on current main: invoking Stop for an attach session bypasses the supported DAP `terminate` request and immediately sends `disconnect` with `terminateDebuggee: true`. The debug maintainer explicitly confirmed that Stop should call `terminate` in this case.

## Change summary

Make graceful DAP termination work when the user explicitly chooses Stop for an attach debug session.

## Best solution

Have `DebugSession.terminate()` honor `supportsTerminateRequest` for both launch and attach sessions, while preserving the distinct Disconnect command and the forceful second-stop fallback.

The defect is the conjunction at lines 438-441: `supportsTerminateRequest` is honored only when the resolved request is `launch`, so attach sessions immediately call `raw.disconnect({ terminateDebuggee: true })`. `RawDebugSession.terminate()` already implements the intended two-stage behavior by sending `terminate` once and falling back to disconnect on a subsequent invocation.
