# Issue #329469 — Support variable interpolation in `chatLanguageModels.json` requestHeaders

[https://github.com/microsoft/vscode/issues/329469](https://github.com/microsoft/vscode/issues/329469)

## Summary

Well-traced, narrow feature request: `requestHeaders` values in `chatLanguageModels.json` are sent verbatim except for the special-cased `${apiKey}` token, so workspace/env variable interpolation is genuinely missing — routing to the BYOK/custom-endpoint area rather than closing.

## Change summary

Allow `requestHeaders` values in the custom-endpoint BYOK schema to interpolate variables like `${workspaceFolderBasename}`, `${env:VAR}`, or `${userHome}`, not just the literal `${apiKey}` token.

## Best solution

Extend `CustomEndpointOAIEndpoint._interpolateApiKey` (extensions/copilot/src/extension/byok/vscode-node/customEndpointProvider.ts) into a small general interpolation step for `requestHeaders` values, likely reusing the existing `${input:...}` resolution pattern from `languageModels.ts`/`languageModelsConfigurationService.ts` rather than pulling in the full `IConfigurationResolverService`.
