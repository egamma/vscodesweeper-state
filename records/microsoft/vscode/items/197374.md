# Issue #197374 — Markdown preview is not automatically opened when md file is opened via command-line and no VS code instance was already running

[https://github.com/microsoft/vscode/issues/197374](https://github.com/microsoft/vscode/issues/197374)

## Summary

The issue is labeled `help wanted` with milestone `Backlog` and describes a real timing/race condition where `workbench.editorAssociations` is not reliably applied during cold start from CLI. No fix commit found on main. Keeping open as it's already triaged and awaiting contribution.

## Change summary

The `workbench.editorAssociations` setting is not respected when VS Code is cold-started from the command line, causing custom editor associations (like markdown preview) to be ignored non-deterministically.

## Best solution

The editor resolver service needs to ensure `editorAssociations` configuration is fully loaded before processing initial file opens during cold startup — likely a sequencing fix in the startup/restore path in `src/vs/workbench/services/editor/browser/editorResolverService.ts` or the window open handler.
