- **Behavior:**

Acceptance must distinguish delayed index modification from delayed UI refresh and demonstrate improvement on an environment that reproduces the report.
- **Trace:**

  > CommandCenter.stageSelectedChanges in extensions/git/src/commands.ts obtains working-tree diff information and delegates to _stageChanges, which loads the index-backed original document before constructing the staged contents. Repository.stage delegates to the Git implementation in extensions/git/src/git.ts, where hash-object, HEAD/object-detail queries, and update-index execute sequentially. Repository.run in extensions/git/src/repository.ts awaits repository-state refresh after mutation, and retryRun can delay completion following lock errors.
