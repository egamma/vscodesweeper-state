# Issue #296133 — Integrated Browser: GitHub login page shows "This browser or device is reporting partial passkey support."

[https://github.com/microsoft/vscode/issues/296133](https://github.com/microsoft/vscode/issues/296133)

## Summary

Still open on main: the integrated browser's embedded Chromium BrowserView does not expose full WebAuthn/passkey APIs, so GitHub's login page reports partial passkey support. No fix or WebAuthn integration has landed. Team-authored issue — keeping open.

## Change summary

GitHub login page in the integrated browser warns about partial passkey support because the embedded BrowserView lacks full WebAuthn API exposure.

## Best solution

The integrated browser's Electron BrowserView needs to either fully support the WebAuthn/passkey APIs (so sites like GitHub detect full support) or suppress/intercept the capability query so it doesn't report partial support. This likely involves Electron-level configuration or API forwarding in `src/vs/platform/browserView/electron-main/browserView.ts`. May also be partly upstream (Electron's BrowserView passkey support).
