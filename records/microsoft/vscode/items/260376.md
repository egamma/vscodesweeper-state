# Issue #260376 — New line is not being detected in prompt input model for Python shell integration

[https://github.com/microsoft/vscode/issues/260376](https://github.com/microsoft/vscode/issues/260376)

## Summary

Still reproduces on main: the prompt input model's newline detection depends on continuation prompt information sent via OSC 633 shell integration, which Python's shell integration does not provide — so multiline Python input shows no newline symbols in the terminal tab description. Team-authored item by the terminal maintainer; keeping open.

## Change summary

Python shell integration does not report its continuation prompt, so multiline input in the terminal tab description lacks newline (⏎) symbols.

## Best solution

Python's VS Code shell integration script needs to emit `OSC 633 ; P ; ContinuationPrompt=... ST` (the `... ` continuation prompt) so the prompt input model can detect newlines, similar to how pwsh shell integration already does. The fix belongs in the Python shell integration scripts and possibly in `src/vs/platform/terminal/common/capabilities/commandDetection/promptInputModel.ts` if Python's continuation prompt format needs special handling.
