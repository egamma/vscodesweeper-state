# Issue #324297 — Search-based file-path autocomplete for the terminal

[https://github.com/microsoft/vscode/issues/324297](https://github.com/microsoft/vscode/issues/324297)

## Summary

Valid feature request for workspace-wide fuzzy file-path search in the terminal suggest widget. The existing terminal suggest (`terminal.integrated.suggest.enabled`) provides directory-relative path completions but not a cross-workspace search-based file finder like the Copilot agent harness screenshot shows. Keeping open for the community process.

## Change summary

Add a workspace-wide fuzzy file-path search to the terminal's autocomplete/suggest widget, similar to what Copilot's agent terminal shows.

## Best solution

Extend the terminal suggest infrastructure in `src/vs/workbench/contrib/terminalContrib/suggest/` with an optional workspace-wide fuzzy file search provider that can surface files from anywhere in the workspace (not just the current directory). This would complement the existing directory-relative path completion. The reporter should also be made aware that `terminal.integrated.suggest.enabled` already provides basic path completions today.
