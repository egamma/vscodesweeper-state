# Issue #286805 — `Proceed from Plan` options persist when cloud agent is working

[https://github.com/microsoft/vscode/issues/286805](https://github.com/microsoft/vscode/issues/286805)

## Summary

The 'Proceed from Plan' handoff widget persists because `renderChatSuggestNextWidget` only checks whether the last local response is complete — it doesn't account for an active cloud delegation started via the agent dropdown. No commit references this issue, and the code path is still present on main.

## Change summary

When delegating a plan-mode message directly to the cloud agent via the dropdown, the 'Proceed from Plan' options remain visible because the local plan response is already marked complete.

## Best solution

Hide the suggest-next widget when a delegation to a cloud/background session is in progress — either by tracking delegation state in the widget's render logic, or by immediately hiding it when `handleDelegationExitIfNeeded` is triggered (before `clear()` completes).
