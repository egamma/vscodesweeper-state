# Issue #237276 — Ctrl+F2 to "Select all occurrences of current word" does not work on Linux

[https://github.com/microsoft/vscode/issues/237276](https://github.com/microsoft/vscode/issues/237276)

## Summary

Keep open: another user confirms the shortcut failure, and current source still registers Ctrl+F2 on Linux. A documented KDE global-shortcut conflict is a plausible explanation, but it has not been established for this report and does not justify closing it.

## Change summary

Ctrl+F2 fails to select all occurrences in an editable file on Arch Linux and Kubuntu, including with extensions disabled.

## Best solution

Determine whether Ctrl+F2 reaches VS Code and invokes editor.action.changeAll on the affected desktop. If KDE intercepts it, document the conflicting desktop shortcut and available alternative; if VS Code receives it but fails to dispatch or select, address that specific keybinding or editor defect.
