# Issue #342921 — Paste large amount of text into Copilot

[https://github.com/microsoft/vscode/issues/342921](https://github.com/microsoft/vscode/issues/342921)

## Summary

The request to keep large pastes inline has an existing configuration, but the intermittent failure to read pasted attachments remains unexplained. Ask for a reproducible example and the affected model and chat mode before deciding whether an attachment-handling defect remains.

## Change summary

Large pasted text becomes an attachment that Copilot sometimes reports it cannot read; the reporter wants the text kept inline instead.

## Best solution

Use chat.pasteAsAttachmentThreshold to accommodate the inline-paste preference, and establish a reproducible case for the separate attachment-readability failure before changing chat attachment handling.
