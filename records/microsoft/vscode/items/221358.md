# Issue #221358 — undo not working in settings search input when i paste some text

[https://github.com/microsoft/vscode/issues/221358](https://github.com/microsoft/vscode/issues/221358)

## Summary

Still reproduces on main: the settings search input uses a native HTML input whose undo stack is broken by the `inputBox.value = newValue` setter pattern — the browser loses its undo history when `.value` is assigned programmatically.

## Change summary

Undo (Ctrl+Z) fails on the first attempt in the settings search input after pasting text.

## Best solution

Replace the direct `.value =` assignment in `InputBox.set value()` (src/vs/base/browser/ui/inputbox/inputBox.ts) with `document.execCommand('insertText')` or the newer `InputEvent`-based approach that preserves the native undo stack, or implement a custom undo stack for the input box. This is a known browser limitation with programmatic value changes.
