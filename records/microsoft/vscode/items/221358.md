# Issue #221358 — undo not working in settings search input when i paste some text

[https://github.com/microsoft/vscode/issues/221358](https://github.com/microsoft/vscode/issues/221358)

## Summary

The reported extra undo step is still explained by current source: the Settings search widget performs a full-value replacement after the paste has already created its own undo boundary. Keep this accepted bug open; the existing settings-editor routing is correct.

## Change summary

Undoing pasted text in Settings search requires two invocations because the first reverses an invisible post-paste replacement.

## Best solution

Make an ordinary Settings search paste reversible with one Undo while preserving single-line whitespace normalization, redo, and existing programmatic search updates. Keep the change bounded to the shared suggest-enabled input behavior rather than changing editor-wide paste undo semantics.
