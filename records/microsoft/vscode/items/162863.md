# Issue #162863 — Exposing the lookup of (x,y) pixel coordinates to corresponding activeTextEditor (line,col)

[https://github.com/microsoft/vscode/issues/162863](https://github.com/microsoft/vscode/issues/162863)

## Summary

The requested coordinate-mapping API remains absent, but maintainers explicitly declined exposing pixel-oriented editor APIs and previously closed the equivalent request as out of scope.

## Change summary

Expose an extension API that maps viewport pixel coordinates to a text editor line and column.

## Best solution

Preserve the public API's UI-abstraction boundary. Eye-tracking integrations requiring viewport coordinates should use a specialized VS Code fork unless a future API design can avoid exposing pixel-level UI geometry.

- **Evidence:** The vision says “The power lives in extensions,” while also favoring a simple, uniform UI and treating missing extension-API gaps as valid core discussions.
