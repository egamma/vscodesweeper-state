# Issue #162863 — Exposing the lookup of (x,y) pixel coordinates to corresponding activeTextEditor (line,col)

[https://github.com/microsoft/vscode/issues/162863](https://github.com/microsoft/vscode/issues/162863)

## Summary

The requested extension API remains missing: editor hit-testing exists internally, but extensions cannot use it to convert screen coordinates into document positions. Keep this accepted, 31-upvote request open; the maintainer's statement that there were no plans 'for now' does not establish a permanent decline.

## Change summary

Expose read-only mapping from eye-tracker screen coordinates to the active text editor's document line and column.

## Best solution

Have the editor API owners explicitly revisit whether a read-only hit-testing contract is acceptable for extensions. If accepted, define its coordinate system and behavior outside text content without exposing editor DOM or requiring extensions to estimate positions from visible ranges.
