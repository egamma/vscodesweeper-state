# Issue #287746 — Opening a codebase in Devcontainers on Windows leads to changes in line endings causing git diff to show changes across all source code files

[https://github.com/microsoft/vscode/issues/287746](https://github.com/microsoft/vscode/issues/287746)

## Summary

This is a Dev Containers cross-platform Git configuration request and should be moved to the VS Code team's Remote Development tracker rather than closed. The report asks Dev Containers to detect or warn about host/container line-ending mismatches that produce repository-wide diffs.

## Change summary

Detect mismatched Git line-ending behavior when opening a Windows checkout in a Dev Container and warn users before it creates spurious diffs.

## Best solution

In the Dev Containers implementation, detect when the mounted Windows checkout and the container's Git configuration interpret line endings differently, then provide a non-destructive warning with repository configuration guidance rather than automatically modifying `.gitattributes` or global Git settings.
