# Issue #309414 — File write detected `/dev/null`

[https://github.com/microsoft/vscode/issues/309414](https://github.com/microsoft/vscode/issues/309414)

## Summary

Still valid on main: while `/dev/null` writes are correctly auto-approved (since commit f310c111876, shipped in 1.107.0), the disclaimer message 'File write operations detected: `/dev/null`' is still shown to users. The request is to suppress that notification entirely for null-device writes, which hasn't been addressed.

## Change summary

Suppress the 'File write detected' disclaimer message when the only file write target is `/dev/null` (or `$null` on PowerShell).

## Best solution

Filter out `nullDevice` entries from the `fileWrites` array before building the disclaimer in `_getResult()` in `commandLineFileWriteAnalyzer.ts`. If only null-device writes remain after filtering, skip the disclaimer entirely. This is a small, localized change.
