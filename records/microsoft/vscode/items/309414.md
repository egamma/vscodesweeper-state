# Issue #309414 — File write detected `/dev/null`

[https://github.com/microsoft/vscode/issues/309414](https://github.com/microsoft/vscode/issues/309414)

## Summary

Keep open: current source exempts recognized /dev/null redirections from outside-workspace blocking, but still produces a file-write notice for them. The earlier approval fix does not fully cover the requested exception, and commenters report continued approval interruptions.

## Change summary

Exclude writes to /dev/null from unnecessary terminal file-write notices and approval interruptions.

## Best solution

Treat recognized null-device redirections as output disposal rather than ordinary file writes in terminal confirmation messaging, without relaxing checks for real destinations or unrelated command risks. Establish whether the explicit block-all setting should retain its existing null-device behavior.
