# Issue #282936 — Make the context selection easier in chatbox

[https://github.com/microsoft/vscode/issues/282936](https://github.com/microsoft/vscode/issues/282936)

## Summary

Partially addressed on current main: Add Context is now anchored above the chat button, but ordinary file or folder acceptance still dismisses the picker. The remaining multi-selection UX request is valid and has no verified canonical issue.

## Change summary

Keep the chat context picker near its invoking button and allow users to attach several files or folders without reopening it after every selection.

## Best solution

Retain the newly anchored picker and define a discoverable pointer-and-keyboard workflow for attaching multiple resources in one invocation, while preserving Escape and explicit completion behavior.
