# Issue #336638 — Remote session reopen can show a stale, incomplete conversation

[https://github.com/microsoft/vscode/issues/336638](https://github.com/microsoft/vscode/issues/336638)

## Summary

Confirmed on current main: reopening a retained remote chat model bypasses the reconnected provider, leaving the conversation permanently attached to stale pre-disconnect state. This should remain open for a focused lifecycle fix and regression test.

## Change summary

Reopening a remote session after disconnection can display an incomplete conversation that remains falsely in progress.

## Best solution

When the remote provider is available again, reopening must refresh or replace the retained chat model from the provider's authoritative session snapshot while preserving the existing offline cached-model fallback.
