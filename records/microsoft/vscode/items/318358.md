# Issue #318358 — Enable use of local agent in Agents Window

[https://github.com/microsoft/vscode/issues/318358](https://github.com/microsoft/vscode/issues/318358)

## Summary

Local agent support in the Agents Window exists and is enabled by default (`sessions.chat.localAgent.enabled`), but team members have acknowledged remaining gaps — notably the inability to combine custom agents with local LLMs in the same session, and Copilot CLI not yet supporting local LLMs. The team is actively iterating; this should stay open to track the remaining parity work.

## Change summary

Enable full local agent usage in the Agents Window with feature parity to Copilot Chat, including mixing custom agents and local LLMs.

## Best solution

Continue iterating on local harness parity in the Agents Window — the main remaining gaps are (1) using custom agents with local LLMs simultaneously and (2) Copilot CLI harness support for local LLMs. The `LocalChatSessionsProvider` and Agent Host Protocol work are the right vehicles. Once parity with Copilot Chat is reached, this can be closed as completed.
