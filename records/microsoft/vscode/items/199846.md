# Issue #199846 — Auto indent for Ruby language's block is not performed If a string include "#" is used as the method argument.

## Change summary

Pressing Enter after a Ruby do-block opener fails to increase indentation when a preceding string argument contains a hash character.

## Best solution

Make Ruby block indentation distinguish hash characters inside string arguments from actual comments, while preserving existing comment and block-closing behavior. The existing regression test for this issue provides a concrete acceptance check.
