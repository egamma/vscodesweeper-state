# Issue #327474 — New chat page with and without workspace

[https://github.com/microsoft/vscode/issues/327474](https://github.com/microsoft/vscode/issues/327474)

## Summary

Keep open: current main provides separate commands for workspace sessions and workspace-less quick chats, but the composer itself cannot switch between them. This team-authored UX request identifies a real discoverability gap.

## Change summary

Expose choices on the new-chat page for starting either a workspace session or a workspace-less quick chat.

## Best solution

Add an accessible, keyboard-operable mode choice to `NewChatWidget` that switches between workspace-backed and quick-chat composition while preserving the existing `openNewSession` and `openQuickChat` flows.
