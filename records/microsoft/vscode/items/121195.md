# Issue #121195 — iPad editor renders double cursor

[https://github.com/microsoft/vscode/issues/121195](https://github.com/microsoft/vscode/issues/121195)

## Summary

Still reproduces on main: `canUseZeroSizeTextarea` at line 111 of `textAreaEditContext.ts` only includes Firefox, not Safari, so the hidden textarea keeps a 1px width on iPad/Safari, rendering a visible second cursor. A Feb 2025 fix attempt in the NativeEditContext path was reverted.

## Change summary

On iPad Safari, the editor's hidden textarea renders a visible second (ghost) cursor because the textarea is sized at 1px instead of 0px.

## Best solution

Either extend `canUseZeroSizeTextarea` to include Safari (`browser.isFirefox || browser.isSafari`) — with IME/composition regression testing — or apply a CSS fix (`-webkit-user-select: none` or `caret-color: transparent`) to the hidden textarea on Safari. The reverted NativeEditContext fix (commit 978e8605ebf, reverted in 55d4dffb18a) suggests focus management complexity; the CSS route may be safer.
