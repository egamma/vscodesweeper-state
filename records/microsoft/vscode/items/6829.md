# Issue #6829 — [css] show all variable definitions for Go To definition

[https://github.com/microsoft/vscode/issues/6829](https://github.com/microsoft/vscode/issues/6829)

## Summary

The capability remains missing: VS Code's CSS server delegates definition lookup to a language-service API that can return only one location. Keep the issue open and classify it as upstream work in the CSS language service.

## Change summary

Show every matching CSS variable declaration when Go to Definition is invoked instead of navigating to an arbitrary single declaration.

## Best solution

Extend microsoft/vscode-css-languageservice to return all matching variable declarations, then let the built-in CSS language server pass those locations through the existing LSP definition response.

- **upstream API limitation:** The current language-service contract returns `Location | null`, not multiple locations: https://github.com/microsoft/vscode-css-languageservice/blob/1c00d690ee38c7dfb137df8de1a6ddf571ea9b36/src/cssLanguageService.ts
- **upstream implementation:** CSSNavigation.findDefinition resolves one symbol and immediately returns one location, so the requested multi-definition result is still absent: https://github.com/microsoft/vscode-css-languageservice/blob/1c00d690ee38c7dfb137df8de1a6ddf571ea9b36/src/services/cssNavigation.ts
