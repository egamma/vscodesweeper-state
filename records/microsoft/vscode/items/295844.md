# Issue #295844 — Error during update

[https://github.com/microsoft/vscode/issues/295844](https://github.com/microsoft/vscode/issues/295844)

## Summary

Still active: the original fix (PR #313791) that terminated dllhost.exe before update was partially reverted (PR #316264) due to security software conflicts. The team is working on an alternative solution and explicitly kept this open to track it.

## Change summary

VS Code update fails with 'Access is denied' on Windows because dllhost.exe (COM surrogate hosting the context menu shell extension) holds locks on VS Code directories during the update process.

## Best solution

Implement a non-PowerShell-based mechanism to release locks held by dllhost.exe on VS Code directories before the installer attempts to delete/replace them — likely via the Inno Setup installer script itself or a native helper that doesn't trigger security software alerts.
