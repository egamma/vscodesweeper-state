# Issue #325956 — Linux/X11: restored window height is clamped to 1080 on a 4K display in a mixed-resolution layout

[https://github.com/microsoft/vscode/issues/325956](https://github.com/microsoft/vscode/issues/325956)

## Summary

Keep open: two independent Linux/X11 reports demonstrate saved normal-window dimensions being clamped to another display's size and subsequently persisted. Current source still excludes Linux from the post-construction bounds workaround, but the native cause and effective correction timing need investigation.

## Change summary

Restore saved normal-window geometry on mixed-resolution Linux/X11 displays without clamping a dimension to a smaller monitor.

## Best solution
