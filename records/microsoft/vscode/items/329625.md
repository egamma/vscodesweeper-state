# Issue #329625 — Markdown editor loses scroll position when switching tabs

[https://github.com/microsoft/vscode/issues/329625](https://github.com/microsoft/vscode/issues/329625)

## Summary

This is the same defect already tracked and well-diagnosed in the open canonical issue #317033: Markdown editor view state absorbs the preview's last synced scroll position and re-applies it on tab switch. Proposing a duplicate close to consolidate the reports.

## Change summary

Markdown editor scrolls to an unrelated position (rather than preserving the user's own scroll position) when switching tabs away from and back to a Markdown file.

## Best solution

Fix the markdown preview scroll-sync leak into the editor's view state in extensions/markdown-language-features/src/preview/preview.ts and preview/documentRenderer.ts (the `#scrollToFirstDiffChange` / diff-scroll-sync mechanism), tracked under https://github.com/microsoft/vscode/issues/317033 which already has a detailed root-cause analysis from a commenter.
