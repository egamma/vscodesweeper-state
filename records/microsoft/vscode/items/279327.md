# Issue #279327 — [Copilot] Agent always uses pwsh but grabs args list from default terminal profile.

[https://github.com/microsoft/vscode/issues/279327](https://github.com/microsoft/vscode/issues/279327)

## Summary

The defect remains in current main: when the default Windows profile is Command Prompt, the chat terminal replaces its executable with Windows PowerShell but retains the Command Prompt arguments. This older report should remain the canonical issue for the same observable failure later reported in https://github.com/microsoft/vscode/issues/309502.

## Change summary

Copilot agent terminals launch Windows PowerShell with arguments inherited from the configured Command Prompt profile, causing the terminal to exit immediately.

## Best solution

Ensure the fallback from Command Prompt to Windows PowerShell produces a coherent PowerShell profile without cmd-specific arguments, while preserving explicit `chat.tools.terminal.terminalProfile.windows` profiles and other shell-selection behavior.
