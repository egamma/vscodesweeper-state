# Issue #339786 — API: expose selected SCM resources to extension commands invoked by keybindings

[https://github.com/microsoft/vscode/issues/339786](https://github.com/microsoft/vscode/issues/339786)

## Summary

A supported extension-access gap remains: SCM menus forward multi-selection, but ordinary keybinding commands do not. Keep this API request open for maintainer consideration; the verified related issues do not own the same extension-facing capability.

## Change summary

Expose the built-in SCM resource selection to extension commands invoked through keyboard shortcuts, without changing existing command arguments by default.

## Best solution

Define a supported SCM selection contract usable by extensions, preserving ordinary keybinding dispatch and leaving assistant-specific copying in the extension. API owners should decide between a selection query and opt-in context forwarding, including resource identity, folder expansion, and empty-selection semantics.
