# Issue #336442 — Don't write files explicitly being asked for into session storage

Team-authored issue (author is a VS Code MEMBER), which is protected from judgment closes; a contributor's comment explains the plan-mode behavior is intentional per the copilot-agent-runtime system prompt but explicitly suggests making file-write location configurable for other modes and looped in maintainers, so this stays open pending that design decision.

## Change summary

When the agent session is asked to write a file and is associated with a workspace folder, the file is written into obscure internal session storage instead of the folder, for at least non-plan-mode interactions.

## Best solution
