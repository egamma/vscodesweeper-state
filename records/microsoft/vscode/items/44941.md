## Summary

The reported proxy-bypass gap has been implemented and shipped: current VS Code exposes `http.noProxy` and applies it to both Electron/Chromium and extension-host HTTP traffic. The command-line proxy switches were separately confirmed working by a maintainer, so this can close as completed.

## Change summary

Ensure networking honors proxy command-line parameters and provide a user setting for hosts that should bypass the proxy.

## Best solution

Keep the shipped `http.noProxy` support from commit e3e15e15e82df2390b0c9e1ad4bc8add01752610; users can configure bypass hosts there while `http.proxy` and `http.proxyStrictSSL` control the proxy and its certificate verification.
