# Issue #328821 — Multi Agent Support

[https://github.com/microsoft/vscode/issues/328821](https://github.com/microsoft/vscode/issues/328821)

## Summary

Current main already provides substantial multi-provider session infrastructure, but that does not satisfy the full request for an extensible CLI-agent experience and replacement of existing Copilot surfaces. Keep this open for product discussion; neither the older extension-API request nor the newer provider-neutral Agents request qualifies as a canonical covering this entire report.

## Change summary

Replace the Copilot-centered experience with workspace-scoped, multi-provider CLI-agent sessions, provider-specific model selection, and integrated editor actions.

## Best solution

Build on the existing provider-neutral Sessions infrastructure and distinguish the remaining third-party harness integration work from decisions about layout defaults, autocomplete, and agent-backed editor actions. Consider those product choices explicitly rather than treating support for several built-in providers as completion of the whole request.
