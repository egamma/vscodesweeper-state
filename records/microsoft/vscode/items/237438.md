# Issue #237438 — Visual Studio Toggle Line Comment Short key not working - Windows 11

[https://github.com/microsoft/vscode/issues/237438](https://github.com/microsoft/vscode/issues/237438)

## Summary

The keyboard troubleshooting log shows the `/` keypress never reaches VS Code (only the Ctrl modifier arrives), confirming external software intercepts it. Two commenters independently identified 1Password as the culprit — disabling or reconfiguring its shortcut resolved the issue. This is not a VS Code defect.

## Change summary

Ctrl+/ (Toggle Line Comment) stops working on Windows 11 because an external application (1Password) intercepts the keystroke before it reaches VS Code.

## Best solution

Close as not reproducible — the root cause is external software (1Password) capturing Ctrl+/ at the OS level. The separate async-tokenization issue with toggle comment is tracked at https://github.com/microsoft/vscode/issues/235344 and is a different problem.
