# Issue #314389 — Open Worktree opens repo root, ignoring current subfolder

[https://github.com/microsoft/vscode/issues/314389](https://github.com/microsoft/vscode/issues/314389)

## Summary

The requested subfolder-preserving behavior is still missing from the built-in Git worktree commands. Route this to Git for a product decision; the related Agents-window request is newer and covers a different surface, not a duplicate canonical.

## Change summary

Preserve the currently opened repository-relative subfolder when opening another worktree, falling back to its root when that directory is absent.

## Best solution

Provide consistent subfolder-preserving navigation through the built-in Git worktree opening commands, with the requested root fallback. The Git owner should decide whether this becomes the default or an opt-in behavior before implementation.
