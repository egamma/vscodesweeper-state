# Issue #331652 — [Error] [GitHub.copilot-chat] unhandlederror-Illegal value for `line`

[https://github.com/microsoft/vscode/issues/331652](https://github.com/microsoft/vscode/issues/331652)

## Summary

Confirmed in source: `toInlineSuggestion`'s `tryRebaseAsCursorEdit` calls `doc.lineAt(cursorPos.line)` without validating the cursor line is still in range, which throws when an async next-edit-suggestion is processed after the document has shrunk. An open PR (#331657) already implements a traced fix, so this should stay open pending that PR's review/merge rather than being auto-fixed or closed.

## Change summary

Copilot Chat's inline-suggestion rebasing throws `Illegal value for line` when an async NES result is processed after the document shrinks, leaving the request cursor's line out of range.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/331657, which adds a guard at the top of `toInlineSuggestion` (extensions/copilot/src/extension/inlineEdits/vscode-node/isInlineSuggestion.ts) rejecting a `cursorPos.line` outside `[0, doc.lineCount)` before dispatching to any rebasing helper.
