## Change summary

Show a yellow warning indicator on the Customizations side-panel entry while the user has pending customization migrations, clearing once resolved.

## Best solution

Wire the existing ICustomizationMigrationService.getMigrationHints()/onDidChangeMigrationHints signal into the Customizations header widget (AICustomizationShortcutsWidget) so its header shows a warning dot alongside the existing count badge; the migration detection logic already exists, only the panel-entry indicator is missing.
