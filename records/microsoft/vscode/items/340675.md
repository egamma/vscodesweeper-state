# Issue #340675 — Chat Participant - Auto mode needs a prompt or a command to route a request

[https://github.com/microsoft/vscode/issues/340675](https://github.com/microsoft/vscode/issues/340675)

## Summary

Thanks for the detailed report. Source confirms it: in a vscode.lm tool-calling loop the last user message holds only tool results, so Auto routing gets no context and throws.

## Change summary

vscode.lm sendRequest with the Auto model throws 'Auto mode needs a prompt or a command' on the follow-up request after a tool call.

## Best solution

Make buildAutoRoutingContext return a sessionId (and prompt, when one exists) even when the last user message has no text, for example by falling back to the latest earlier user text. That lets the cached Auto endpoint be reused for tool-result follow-ups.
