## Change summary

The Markdown source/preview toggle action changes relative position around Git's Open Changes action when the file has working tree changes.

## Best solution

Merge PR https://github.com/microsoft/vscode/pull/330806, which moves markdown.reopenAsPreview/reopenAsSource from navigation@2 to navigation@1.5 in extensions/markdown-language-features/package.json so they consistently sort before git.openChange (navigation@2 in extensions/git/package.json).
