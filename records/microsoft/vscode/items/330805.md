# Issue #330805 — Markdown source/preview toolbar toggle changes position when file has Git changes

[https://github.com/microsoft/vscode/issues/330805](https://github.com/microsoft/vscode/issues/330805)

## Summary

Confirmed on main: `markdown.reopenAsPreview` and `markdown.reopenAsSource` both use `group: navigation@2` in extensions/markdown-language-features/package.json, same group as `git.openChange`, so VS Code's menu tie-break sorts by title and the toggle swaps position when Git changes are present. An open PR (https://github.com/microsoft/vscode/pull/330806) already fixes this by moving both markdown commands to `navigation@1.5`, so this should stay open pending that PR merging rather than being closed or auto-fixed.

## Change summary

The Markdown source/preview toggle action changes its relative position next to the Git 'Open Changes' action depending on which editor mode is active, instead of staying in a stable spot.

## Best solution

Land https://github.com/microsoft/vscode/pull/330806, which reassigns `markdown.reopenAsPreview` and `markdown.reopenAsSource` to `navigation@1.5` in extensions/markdown-language-features/package.json so both always sort before `git.openChange`.
