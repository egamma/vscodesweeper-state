# Issue #314622 — Introduce multi-tier difficulty labels to improve newcomer onboarding

[https://github.com/microsoft/vscode/issues/314622](https://github.com/microsoft/vscode/issues/314622)

## Summary

The existing newcomer label and code-pointer guidance already cover part of this proposal, but intermediate/advanced tiers and their documented prerequisites remain a distinct process request. Keep it under discussion rather than closing for inactivity or treating partial coverage as completion.

## Change summary

Introduce documented difficulty tiers so external contributors can select issues matching their experience.

## Best solution

Preserve the existing `good first issue` and `help wanted` labels, and have maintainers decide whether additional difficulty tiers provide enough onboarding value to justify ongoing classification work. If adopted, document prerequisites and expected assistance in the contribution and triage wiki pages.
