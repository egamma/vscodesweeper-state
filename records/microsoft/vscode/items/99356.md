# Issue #99356 — `getTokenInformationAtPosition` API causes too much traffic and blocks the renderer process

[https://github.com/microsoft/vscode/issues/99356](https://github.com/microsoft/vscode/issues/99356)

## Summary

The `getTokenInformationAtPosition` proposed API still exists in the codebase (marked deprecated) and is still wired up in `extHost.api.impl.ts`. The underlying performance concern — synchronous per-token renderer roundtrips blocking the UI — remains structurally valid. The issue doubles as a tracking item for either removing or replacing this API, which is an open design discussion among team members.

## Change summary

The proposed `getTokenInformationAtPosition` API causes excessive renderer-process roundtrips when called per-token (e.g. for issue-link detection), blocking the UI.

## Best solution

Resolve the long-standing design discussion: either remove the deprecated proposed API entirely (extensions like GHPRI should use vscode-textmate or language-configuration-based comment detection instead), or replace it with a batched/async alternative that avoids per-token roundtrips. The API surface is in `src/vscode-dts/vscode.proposed.tokenInformation.d.ts` and wired through `src/vs/workbench/api/common/extHost.api.impl.ts`.
