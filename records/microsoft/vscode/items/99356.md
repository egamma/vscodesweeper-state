# Issue #99356 — `getTokenInformationAtPosition` API causes too much traffic and blocks the renderer process

[https://github.com/microsoft/vscode/issues/99356](https://github.com/microsoft/vscode/issues/99356)

## Summary

Keep open: the deprecated API still exists on current main and still performs one renderer roundtrip per position request. The discussion confirms excessive traffic, though not an unconditional freeze; neither a verified fix nor an eligible duplicate establishes that this team-authored issue is complete.

## Change summary

Prevent repeated token-information queries from generating excessive extension-host-to-renderer traffic and degrading editor responsiveness.

## Best solution

Resolve the deprecated token API's lifecycle with the API owners: either retain efficient token queries or retire the API with an agreed migration for comment-sensitive consumers. Preserve document-version correctness and avoid eagerly loading every language configuration.
