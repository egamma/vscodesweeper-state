# Issue #306813 — Clicking tips removed all prompt

[https://github.com/microsoft/vscode/issues/306813](https://github.com/microsoft/vscode/issues/306813)

## Summary

Valid bug: clicking a tip command link (like `/create-skill`) in the chat input area executes `workbench.action.chat.open` with a `query` parameter that replaces whatever the user had typed, with no undo support. The code path is still present on current main.

## Change summary

Clicking a chat tip link (e.g. `/create-skill`) replaces the user's existing chat input with the slash command text, losing their typed prompt with no way to undo.

## Best solution

The `GenerateSkillAction` (and similar tip-linked actions like `GeneratePromptAction`) should either append to / prefix the existing input, or open a new chat session instead of overwriting the current input. The fix likely lives in `src/vs/workbench/contrib/chat/browser/actions/chatActions.ts` around the `workbench.action.chat.open` calls with `query`. Alternatively, the tip link could be made non-destructive by opening a new chat tab rather than mutating the current one.
