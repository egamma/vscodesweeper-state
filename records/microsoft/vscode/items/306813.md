# Issue #306813 — Clicking tips removed all prompt

[https://github.com/microsoft/vscode/issues/306813](https://github.com/microsoft/vscode/issues/306813)

## Summary

Keep open: the current source still routes the /create-skill tip through an input replacement that clears the editor's undo history. The report provides sufficient steps, and the destructive path remains identifiable without executing VS Code.

## Change summary

Clicking the /create-skill chat tip replaces an unsent prompt and prevents restoring it with Ctrl+Z.

## Best solution

Make activating the skill-creation tip non-destructive: the existing draft must remain intact or recoverable through ordinary Undo, while the skill command remains available. Cover the tip-to-command path with a regression test.
