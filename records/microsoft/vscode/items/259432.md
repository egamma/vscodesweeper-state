# Issue #259432 — Issue reporter breaks after closing vscode window

[https://github.com/microsoft/vscode/issues/259432](https://github.com/microsoft/vscode/issues/259432)

## Summary

The issue reporter has been completely rewritten since this report — it is now an editor pane inside the workbench (not a separate window), so the original scenario of the issue reporter surviving after the main window closes no longer applies. The reported bug is no longer reproducible on current main.

## Change summary

The 'Preview on GitHub' button in the Issue Reporter stops working after the main VS Code window is closed, because the issue reporter (as a separate window) loses its connection to the workbench.

## Best solution

No further change needed. The issue reporter was rewritten as an in-workbench editor pane (IssueReporterEditorPane / IssueReporterOverlay), eliminating the separate-window lifecycle issue entirely. Closing the main window now closes the issue reporter with it.
