# Issue #125098 — Trust editor: should allow multi-select of folders from the dialog

[https://github.com/microsoft/vscode/issues/125098](https://github.com/microsoft/vscode/issues/125098)

## Summary

Still unimplemented on main: both folder-picker dialogs in the workspace trust editor explicitly set `canSelectMany: false`. The request remains valid.

## Change summary

Allow multi-selecting folders in the workspace trust editor's folder-picker dialog so users can trust several folders at once.

## Best solution

Change `canSelectMany: false` to `true` in both `showOpenDialog` calls in `src/vs/workbench/contrib/workspace/browser/workspaceTrustEditor.ts` (lines ~182 and ~365), and handle the resulting URI array by trusting all selected folders. Small, localized change.
