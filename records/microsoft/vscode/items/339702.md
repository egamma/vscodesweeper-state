# Issue #339702 — allowedDomains has no effect if allowNetwork is off

[https://github.com/microsoft/vscode/issues/339702](https://github.com/microsoft/vscode/issues/339702)

## Summary

Confirmed from source: `allowNetwork` is a master network switch, and `allowedDomains` only narrows access when network is already allowed — this is intentional layering, not a bug, and matches the reporter's own suspicion ('probably as expected, just to make sure').

## Change summary

Setting `chat.agent.sandbox.network.allowedDomains` to a specific domain has no effect when `chat.agent.sandbox.network.allowNetwork` is false — the domain is still blocked.

## Best solution

Keep the current design: `allowNetwork` gates all network access first, `allowedDomains`/`deniedDomains` only apply when network is permitted. If the settings' relationship is confusing, consider clarifying it in the setting descriptions (a polish follow-up, not a behavior change).
