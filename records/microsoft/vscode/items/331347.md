# Issue #331347 — Pasted images are labelled unsupported in Claude sessions even though the model receives them

[https://github.com/microsoft/vscode/issues/331347](https://github.com/microsoft/vscode/issues/331347)

## Summary

Confirmed on main: `fromSdkModelInfo` in claudeAgent.ts still hardcodes `supportsVision: false` for the native Claude SDK transport, causing the attachment widget to mislabel image attachments as unsupported even though the model receives and uses them. A fixing PR is already open and references this issue, so it should stay open for review/merge rather than being closed now.

## Change summary

Pasted images in native-transport Claude sessions are marked "does not support images" in the UI even though the model correctly receives and describes them, because the vision capability is hardcoded to false instead of reflecting reality.

## Best solution

Land https://github.com/microsoft/vscode/pull/331396 (or an agreed variant), which changes `fromSdkModelInfo` in src/vs/platform/agentHost/node/claude/claudeAgent.ts to report `supportsVision: true` for this transport since the SDK's `ModelInfo` has no vision field and `undefined` collapses to `false` downstream anyway.
