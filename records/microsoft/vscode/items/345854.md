# Issue #345854 — Remote extensions never load for a profile whose Extensions use the Default profile

## Summary

Keep open: current source confirms that an existing remote profile retains missing extension-inheritance flags. The linked open PR is an implementation candidate, not a completed fix.

## Change summary

Remote profiles should honor the local profile's Default extension source so installed remote extensions load correctly.
