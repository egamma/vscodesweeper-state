# Issue #345854 — Remote extensions never load for a profile whose Extensions use the Default profile

[https://github.com/microsoft/vscode/issues/345854](https://github.com/microsoft/vscode/issues/345854)

## Summary

The reported profile-inheritance mismatch remains in current source. Keep this open while the existing fixing PR is reviewed; it is a core profile-service defect, not a Remote-SSH extension issue.

## Change summary

Remote extensions fail to load when a non-default profile inherits its Extensions from the Default profile.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/345865 so existing remote profiles honor local useDefaultFlags, including Extensions inheritance.
