# Issue #216701 — Debug console doesn't appear on Restart (Ctrl+Shift+F5)

[https://github.com/microsoft/vscode/issues/216701](https://github.com/microsoft/vscode/issues/216701)

## Summary

The requested restart behavior remains absent on current main, and the debug maintainer accepted the use case before placing it in Backlog. Keep it open for a product decision about extending the existing setting or adding a distinct restart option.

## Change summary

Allow the Debug Console to reopen after a manual debug restart when build tasks have switched the panel to Terminal.

## Best solution

Provide an explicit configuration contract for reopening the Debug Console after manual restart, covering both adapter-supported restart and terminate/relaunch flows without changing the current default behavior.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/debug/browser/debugService.ts`, `src/vs/workbench/contrib/debug/common/debug.ts`
- **Validation:** Use a launch configuration with internalConsoleOptions=openOnSessionStart and a preLaunchTask that reveals Terminal; start with F5, switch to Debug Console, then restart with Ctrl/Cmd+Shift+F5 and verify the selected panel follows the chosen setting contract in both supportsRestartRequest and terminate/relaunch paths.
- **Behavior:**

  > A manual debug restart can be configured to return focus to the Debug Console after restart tasks have switched the panel to Terminal. The behavior must work for adapters that implement the DAP restart request and for sessions that restart through terminate/relaunch. Initial F5 behavior, automatic restarts, neverOpen, openOnFirstSessionStart, and the default configuration must retain their documented behavior unless the maintainer explicitly chooses otherwise.
- **Trace:**

  > DebugService.doCreateSession in src/vs/workbench/contrib/debug/browser/debugService.ts evaluates internalConsoleOptions and opens REPL_VIEW_ID after launchOrAttachToSession. DebugService.restartSession has two principal paths: adapters with supportsRestartRequest call session.restart(), while other adapters terminate and call launchOrAttachToSession directly; neither path reevaluates internalConsoleOptions after restart tasks finish. INTERNAL_CONSOLE_OPTIONS_SCHEMA and the corresponding configuration types in src/vs/workbench/contrib/debug/common/debug.ts expose no restart-specific state. The boundary is manual debug restart and Debug Console visibility; do not alter task focus behavior, automatic restart semantics, or terminal-backed console configurations. The same capability was previously requested in https://github.com/microsoft/vscode/issues/97477, but this newer issue received affirmative maintainer feedback and Backlog placement.
- **Open decisions:**
  - Should openOnSessionStart be redefined to include manual restarts, or should a new enum value opt into reopening on restart while preserving the existing value's semantics?

## Evidence
