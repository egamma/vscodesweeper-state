# Issue #268745 — Wrapped chat symbol links don't look great

[https://github.com/microsoft/vscode/issues/268745](https://github.com/microsoft/vscode/issues/268745)

## Summary

Still present on main: the `.chat-resource-widget` inline element has padding and a background but no increased line-height to prevent overlap when it wraps to a second line. No fix commit found.

## Change summary

Chat symbol links (inline resource widgets) visually overlap when they wrap to a second line in a narrow chat panel.

## Best solution

Increase the `line-height` on `.chat-resource-widget` (or its containing paragraph) in `src/vs/workbench/contrib/chat/browser/widget/media/chat.css` to accommodate the padding and background, similar to how `line-height: 18px` was applied to other chat elements. Alternatively, add `display: inline-block` or `box-decoration-break: clone` to handle the wrapped state cleanly.
