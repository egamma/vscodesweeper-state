# Issue #333830 — Extension host unresponsive ~40s at startup: synchronous macOS system CA load evaluates every keychain cert via trustd XPC

[https://github.com/microsoft/vscode/issues/333830](https://github.com/microsoft/vscode/issues/333830)

## Summary

Well-diagnosed, maintainer-confirmed freeze with a standalone repro and a linked upstream Node.js issue; two PRs are already in flight to fix it, so this should stay open and be tracked to landing, not closed or auto-fixed here.

## Change summary

On macOS with many keychain certificates, the extension host's synchronous system CA load (via node's tls.getCACertificates('system') / @vscode/proxy-agent) blocks the main thread for tens of seconds on every extension host start.

## Best solution

Land the fixes already proposed: move the system cert load to a worker thread and gate the main-thread TLS request on its completion (per deepak1556's comment), tracked via https://github.com/microsoft/vscode-proxy-agent/pull/116 and https://github.com/microsoft/vscode/pull/333953; also watch the upstream Node.js report chrmarti linked (https://github.com/nodejs/node/issues/63313) since the root slowness may need an upstream fix too.
