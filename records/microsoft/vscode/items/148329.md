# Issue #148329 — "Bracket" colorization for indent

[https://github.com/microsoft/vscode/issues/148329](https://github.com/microsoft/vscode/issues/148329)

## Summary

Indent-based guide colorization is implemented and shipped, including customizable colors for six indentation levels.

## Change summary

Color indentation guides by nesting level for languages whose blocks are defined by indentation rather than brackets.

## Best solution

Use the shipped per-level theme colors `editorIndentGuide.background1` through `background6` and their `activeBackground` variants, implemented by https://github.com/microsoft/vscode/pull/178112.
