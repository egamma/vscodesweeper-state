# Issue #148329 — "Bracket" colorization for indent

[https://github.com/microsoft/vscode/issues/148329](https://github.com/microsoft/vscode/issues/148329)

## Summary

Keep open: configurable vertical indentation colors now exist, but the illustrated active scope includes a horizontal connector that still requires actual bracket pairs. The related open requests do not fully cover that remaining behavior.

## Change summary

Provide bracket-style colored scope guides for indentation-based languages without requiring physical brackets.

## Best solution

Extend the indentation-guide experience to represent active indentation scopes as illustrated, including the horizontal header connector, while reusing existing guide colors. Native indentation detection is the reporter's preferred approach; a language-server contract is an alternative, not an established requirement.

## Evidence

- **Requested behavior:** https://github.com/microsoft/vscode/issues/148329 requests scope highlighting for a custom indentation-based language. The first attached illustration shows a vertical guide; the second shows an active yellow guide with a horizontal connector beneath the function header. The reporter simulated these by making actual braces transparent.
- **Existing partial implementation:** https://github.com/microsoft/vscode/commit/6bbb1283048f40e30dac74d279582124455fc288, merged through https://github.com/microsoft/vscode/pull/178112, added indentation-level CSS classes and cycling theme colors. Current src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts:224-235 assigns these classes but constructs indentation guides with horizontalLine set to null; lines 333-341 apply per-level colors.
- **Available configuration:** src/vs/editor/common/config/editorOptions.ts registers editor.guides.indentation and editor.guides.highlightActiveIndentation. src/vs/editor/common/core/editorColorRegistry.ts registers editorIndentGuide.background1 through background6 and their activeBackground counterparts. Both inactive and active colors must be nontransparent for a color pair to participate in the cycle; ordinary defaults therefore do not automatically provide rainbow indentation.
- **Remaining scope-guide boundary:** IndentGuidesOverlay.getGuidesByLine routes editor.guides.bracketPairsHorizontal through bracket-guide generation, not indentation-guide generation. src/vs/editor/common/model/guidesTextModelPart.ts:289-305 obtains actual bracket pairs, and its horizontal-guide branches at lines 367-425 depend on those pairs. Changing indentation colors alone does not deliver the horizontal active-scope connector shown in the report.
- **Canonical search:** https://github.com/microsoft/vscode/issues/203857 is open but requests colored vertical indentation guides, a narrower scope; its latest maintainer comment also disputes the earlier completion claim: https://github.com/microsoft/vscode/issues/203857#issuecomment-5169291662. https://github.com/microsoft/vscode/issues/188782 concerns default theme palettes rather than bracket-free scope geometry. Additional searches for indentation colorization and horizontal indentation guides did not establish a full-scope open canonical.

Its Python indentation suggestion at https://github.com/microsoft/vscode/issues/136506#issuecomment-962506045 is related evidence, but the closed issue cannot serve as a duplicate target.
