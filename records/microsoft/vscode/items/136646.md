# Issue #136646 — Feature request: Option to colorize only active bracket pairs

[https://github.com/microsoft/vscode/issues/136646](https://github.com/microsoft/vscode/issues/136646)

## Summary

The explicitly requested alternative, editorBracketMatch.foreground, is now implemented on main and allows matching brackets to use a single foreground color without enabling all-bracket colorization. Propose closing as completed; this does not claim that a guide-driven active-only colorization mode was added.

## Change summary

Allow coloring only the current bracket pair, preferably alongside active guides, or alternatively through a matching-bracket foreground override.

## Best solution

Use editorBracketMatch.foreground through workbench.colorCustomizations, with editor.matchBrackets set to always and editor.bracketPairColorization.enabled set to false. This delivers the reporter's accepted alternative while preserving the existing distinction between bracket matching and active guides.
