# Issue #263027 — feature request for editor cursor

[https://github.com/microsoft/vscode/issues/263027](https://github.com/microsoft/vscode/issues/263027)

## Summary

Legitimate feature request for two cursor customizations (overtype cursor color and inactive editor cursor style) that do not exist on current main. Promoted to Backlog with 20 upvotes — should stay open.

## Change summary

Allow separate color theming for the overtype-mode cursor and a distinct cursor style when an editor is unfocused/inactive.

## Best solution

Implement `editorCursorOvertype.foreground` as a new theme color in `src/vs/editor/common/core/editorColorRegistry.ts` (alongside the existing `editorCursor.foreground`), and add an `editor.cursorStyleInactive` setting in `src/vs/editor/common/config/editorOptions.ts` (similar to the existing `editor.overtypeCursorStyle` pattern). The cursor rendering in `src/vs/editor/browser/viewParts/viewCursors/viewCursors.ts` would need to consume both new options.
