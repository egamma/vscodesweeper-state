# Issue #318516 — Add Bootstrap Support for Git Worktrees

[https://github.com/microsoft/vscode/issues/318516](https://github.com/microsoft/vscode/issues/318516)

## Summary

The requested optional bootstrap capability is implemented on current main: newly created worktrees can copy ignored files, share dependency folders through symlinks, and automatically launch setup tasks.

## Change summary

Provide optional worktree bootstrap automation for dependency installation or reuse, local configuration files, and initialization commands.

## Best solution

Use the existing git.worktreeIncludeFiles and git.worktreeSymlinkFolders settings together with tasks tagged runOptions.runOn = "worktreeCreated"; close this request as completed by the combined bootstrap surface.
