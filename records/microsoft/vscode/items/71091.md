# Issue #71091 — [html] bracket matching in strings

[https://github.com/microsoft/vscode/issues/71091](https://github.com/microsoft/vscode/issues/71091)

## Summary

The reported false angle-bracket match is fixed on current main: HTML no longer registers `<` and `>` as a bracket pair. The concrete change landed in commit ff757ef8f467015a91b0f8052e7ef3b611bc538e, so this can be closed as completed.

## Change summary

Comparison operators inside quoted HTML attribute values were interpreted as tag brackets, corrupting bracket matching and smart selection.

## Best solution

Keep the shipped HTML language configuration that excludes `<` and `>` from editor bracket matching; HTML-aware tag features remain responsible for tag structure.
