# Issue #295159 — Splitting a terminal window will open the terminal in the main workbench window, not the terminal window

[https://github.com/microsoft/vscode/issues/295159](https://github.com/microsoft/vscode/issues/295159)

## Summary

Keep open: the current source still sends a terminal split from a compact auxiliary window into the main workbench. The issue is already correctly routed, and no verified open canonical owns this same symptom.

## Change summary

Splitting a terminal in a standalone terminal window should create the split in that window rather than the main workbench.

## Best solution

Make the terminal split remain beside its source terminal in the same auxiliary window, preserving ordinary main-window splits and unrelated compact-window behavior.

- **Trace:**
