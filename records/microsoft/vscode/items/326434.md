# Issue #326434 — Add a supported non interactive CLI for provisioning BYOK model secrets into VS Code SecretStorage

[https://github.com/microsoft/vscode/issues/326434](https://github.com/microsoft/vscode/issues/326434)

## Summary

Genuine feature request for a non-interactive CLI to provision BYOK language-model secrets into VS Code's SecretStorage — no such mechanism exists today. The request is well-scoped and distinct from the env-variable approach in #322545. Keeping open for the BYOK area owners to evaluate.

## Change summary

Add a CLI command (e.g. `code --set-language-model-secret <id> --stdin`) to non-interactively create, update, or remove BYOK model API-key secrets in VS Code's SecretStorage backend.

## Best solution

Route to the BYOK/language-model-management area for design evaluation. The implementation would need a new CLI argument handled in `src/vs/code/` that writes into the same `ISecretStorageService` backend used by `LanguageModelsService` (which already stores BYOK secrets via `SecretStorage` in `src/vs/workbench/contrib/chat/common/languageModels.ts`). Key design questions: secret-key naming convention (stable IDs vs. generated UUIDs), stdin-only ingestion for security, cross-platform storage guarantees, and how the CLI process accesses the Electron SecretStorage without a running window.
