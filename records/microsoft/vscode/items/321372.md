## Summary

Valid feature request for passing additional request parameters (extra_body, extra_query, extra_headers) to custom BYOK model endpoints. Related to but broader than https://github.com/microsoft/vscode/issues/316794 — the extra_body ask (e.g. thinking mode configuration) is a distinct requirement. Routing to the BYOK area.

## Change summary

Allow users to specify extra_query, extra_body, and extra_headers parameters when configuring custom AI model endpoints, enabling model-specific features like thinking mode control.

## Best solution

Consider consolidating the custom-headers ask with https://github.com/microsoft/vscode/issues/316794 and extending the BYOK model configuration schema to also support extra_body and extra_query, following the OpenAI SDK pattern. The extra_body capability is the most impactful piece — it enables provider-specific parameters like thinking mode intensity without requiring first-class support for each.
