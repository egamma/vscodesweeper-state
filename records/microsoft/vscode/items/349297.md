# Issue #349297 — Markdown files show error `link.no-such-file` for a link to an existing folder after a file inside that folder is deleted

[https://github.com/microsoft/vscode/issues/349297](https://github.com/microsoft/vscode/issues/349297)

## Summary

Keep open: current source forwards deletion of a linked folder's direct child as deletion of the folder itself. The report provides a complete reproduction, and the defect is bounded to the built-in Markdown watcher bridge.

## Change summary

Prevent false Markdown link.no-such-file diagnostics when a file inside an existing linked folder is deleted.

## Best solution

Markdown link validation should track the existence of the linked resource, not mistake its children's changes for its deletion, while retaining detection of actual target and ancestor deletion.
