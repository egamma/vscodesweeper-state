# Issue #318414 — Chat session with no workspace shows semantic index out of date

[https://github.com/microsoft/vscode/issues/318414](https://github.com/microsoft/vscode/issues/318414)

## Summary

Still reproduces on main: the semantic index chat status item shows 'Out of date' even without a workspace because the status rendering logic doesn't guard against empty-workspace scenarios when externalIngestState is defined but not ready.

## Change summary

The semantic index status bar shows 'Out of date' and offers an 'Update' action in chat sessions with no open workspace, which then fails with 'No workspace found'.

## Best solution

Guard the ChatStatusWorkspaceIndexingStatus rendering so it hides or shows 'Not available' when no workspace folders are open, preventing the misleading 'Out of date' state and the failing 'Update' action. The fix belongs in extensions/copilot/src/extension/workspaceChunkSearch/vscode-node/workspaceIndexingStatus.ts.
