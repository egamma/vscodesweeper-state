# Issue #316717 — "Enable AI Features (Workspace)" does not persist across sessions

[https://github.com/microsoft/vscode/issues/316717](https://github.com/microsoft/vscode/issues/316717)

## Summary

This persistence defect was fixed immediately after the reported VS Code build: current code stores an explicit workspace-level AI enablement override, so reopening the workspace preserves the opt-in.

## Change summary

Enabling AI features for one workspace did not survive closing and reopening that workspace when AI was disabled globally.

## Best solution

Keep the fix from https://github.com/microsoft/vscode/commit/199bf7e55222baca85bc6f56d0bba8320b247841, which persists `chat.disableAIFeatures: false` at workspace scope when the user selects Enable AI Features (Workspace).
