## Change summary

Uninstalling a disabled marketplace plugin from MCP Servers briefly re-enables the still-discovered plugin instead of removing it without an enabled transition.

## Best solution

Make marketplace plugin removal preserve disabled intent until the plugin disappears from discovery and publication, with the MCP Servers row disappearing after the first successful uninstall. Cover both the discovered-plugin removal callback and the configured-plugin fallback, without changing child MCP enablement or unrelated installation ownership.
