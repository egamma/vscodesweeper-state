# Issue #336965 — Uninstalling a disabled plugin from MCP Servers briefly enables it

[https://github.com/microsoft/vscode/issues/336965](https://github.com/microsoft/vscode/issues/336965)

## Summary

Confirmed in source: the marketplace plugin uninstall path clears the enablement entry before the plugin is removed from the installed-plugins store, which transiently restores the default-enabled state for a plugin that is still observable until async discovery catches up.

## Change summary

Uninstalling a disabled marketplace-installed plugin from MCP Servers briefly flips it back to enabled before the row disappears.

## Best solution

Reorder or transaction the removal in the marketplace discovery's `remove` callback so the plugin is dropped from the installed-plugins store (or discovery is otherwise suppressed) before its enablement entry is cleared, avoiding the transient default-enabled window.
