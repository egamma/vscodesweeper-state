# Issue #263841 — Check for extension update when opening the extension

[https://github.com/microsoft/vscode/issues/263841](https://github.com/microsoft/vscode/issues/263841)

## Summary

The requested extension-details refresh remains absent on current main. This team-authored, accepted Backlog feature request must remain open, and no older canonical with the same observable behavior or referenced fixing commit was found.

## Change summary

Check the Marketplace for an installed extension's latest version when its extension details editor is opened.

## Best solution

Opening an installed extension's details should refresh its Marketplace metadata so the editor immediately reflects whether an update is available, while respecting the existing automatic-update-check setting and avoiding an unnecessary check of every installed extension.
