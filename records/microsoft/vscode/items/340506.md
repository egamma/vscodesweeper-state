# Issue #340506 — “Open Session” notification overlaps the chat input

[https://github.com/microsoft/vscode/issues/340506](https://github.com/microsoft/vscode/issues/340506)

## Summary

The requested option to disable “Open Session” notifications already exists. Both session-completion and question notifications have explicit opt-out settings, so this request can be closed with instructions for those controls.

## Change summary

Prevent “Open Session” notifications from obstructing chat input by repositioning them or allowing dismissal or disabling.

## Best solution

Use the existing chat notification settings rather than adding another option: set chat.notifyWindowOnResponseReceived and chat.notifyWindowOnConfirmation to off to suppress these notifications, or windowNotFocused to prevent new notifications while using the VS Code window.
