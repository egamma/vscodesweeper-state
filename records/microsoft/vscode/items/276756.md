# Issue #276756 — Explore removing most default false rules from terminal auto approve

[https://github.com/microsoft/vscode/issues/276756](https://github.com/microsoft/vscode/issues/276756)

## Summary

Valid, active feature request from the terminal area owner — the default `false` auto-approve rules and the `ignoreDefaultAutoApproveRules` setting are still present on current `main`, so this work remains unimplemented. Keeping open.

## Change summary

Remove most default `false` rules from the terminal auto-approve configuration now that tree-sitter parsing and file write detection provide better safety, and potentially remove the ignore-defaults setting.

## Best solution

As tree-sitter command parsing and file-write detection mature, audit the ~40+ default `false` deny rules in `terminalChatAgentToolsConfiguration.ts` and remove those that tree-sitter can now safely gate at runtime, simplifying the configuration surface. If most are removable, the `chat.tools.terminal.ignoreDefaultAutoApproveRules` setting can also be retired.
