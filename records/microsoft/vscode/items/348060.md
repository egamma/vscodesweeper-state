# Issue #348060 — Add Allow Automatic Tasks configuration option for Windows, macOS , and Lunix device management

[https://github.com/microsoft/vscode/issues/348060](https://github.com/microsoft/vscode/issues/348060)

## Summary

The enterprise-enforcement gap remains: task.allowAutomaticTasks exists, but has no managed-policy declaration. Keep this security-sensitive request open for human review; workspace trust does not provide the requested independent administrative control.

## Change summary

Allow administrators to enforce automatic-task permissions through Windows Group Policy, macOS MDM, and Linux policy files.

## Best solution

Provide an administrator-enforced automatic-task restriction that remains effective in trusted workspaces and cannot be overridden through user settings or task-permission prompts. Have the task and enterprise-policy owners review the security boundary and the earlier workspace-trust decision.
