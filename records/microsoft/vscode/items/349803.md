# Issue #349803 — A failed worktree cleanup disappears from Worktree Cleanup and can't be retried

[https://github.com/microsoft/vscode/issues/349803](https://github.com/microsoft/vscode/issues/349803)

## Summary

The failure-and-disappearance path remains in current source: failed host removals are explicitly excluded from the inventory and selection. Keep this open to restore the retry behavior required by the linked test plan.

## Change summary

Keep failed worktree removals visible with their failure reason and allow normal cleanup to be retried after the obstruction is resolved.

## Best solution

Worktree Cleanup should retain failed removals across refresh and reopening, explain the failure, and offer normal retry without weakening host safety checks. Align the editor tests and Accessibility Help with that behavior.
