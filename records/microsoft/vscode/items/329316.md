# Issue #329316 — Agent Window retains a zsh process for every archived session terminal

[https://github.com/microsoft/vscode/issues/329316](https://github.com/microsoft/vscode/issues/329316)

## Summary

Team-authored, reopened bug that carries `verification-found` (mid release verification) — never propose a close here. The reporter (a maintainer) confirmed on 2026-08-24 that the leak still reproduces, and a second angle (eager terminal creation for unopened sessions) was raised in a follow-up comment.

## Change summary

Archiving an Agents Window session moves its terminal to the background instead of disposing it, so the PTY and interactive shell for every archived session accumulate indefinitely, sometimes rooted in already-deleted worktrees.

## Best solution

In src/vs/sessions/contrib/terminal/browser/sessionsTerminalContribution.ts, the archive path (`_onActiveSessionChanged` / `_hideTerminalsForSession`, calling `moveToBackground` around line 212/637) should dispose the terminal when the owning worktree is removed rather than just hiding it, and/or terminals should be created lazily on first use instead of eagerly per active session — both concerns are confirmed live by roblourens in comments.
