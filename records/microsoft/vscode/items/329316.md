# Issue #329316 — Agent Window retains a zsh process for every archived session terminal

[https://github.com/microsoft/vscode/issues/329316](https://github.com/microsoft/vscode/issues/329316)

## Summary

Team-authored bug (roblourens) with a clear source-level trace of the leak on current main; a real gap remains — archived-session terminals are hidden, not disposed, with no coordination against worktree removal — and no fix has landed yet, so this stays open.

## Change summary

Archiving an Agents window session hides its terminal via moveToBackground instead of disposing it, so the zsh process and PTY (and its now-deleted worktree cwd) live on indefinitely, accumulating across sessions.

## Best solution

Coordinate `_hideTerminalsForSession` (or the worktree-removal path) so that when archive cleanup actually deletes the session's worktree, the terminal is disposed rather than merely backgrounded — or make session terminal creation lazy so idle archived sessions don't retain a live shell at all.
