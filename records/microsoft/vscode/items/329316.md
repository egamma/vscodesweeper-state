# Issue #329316 — Agent Window retains a zsh process for every archived session terminal

[https://github.com/microsoft/vscode/issues/329316](https://github.com/microsoft/vscode/issues/329316)

## Summary

Mid-verification (verification-found) and reopened after the problem persisted post-fix, so this cannot be proposed for closure regardless of other evidence; the underlying leak path is still visible on main.

## Change summary

Archiving an Agent Window session moves its terminal to the background instead of disposing it, so PTYs and idle zsh shells accumulate indefinitely (and terminals are also created eagerly before the terminal surface is ever opened).

## Best solution

In src/vs/sessions/contrib/terminal/browser/sessionsTerminalContribution.ts, dispose (not just moveToBackground) terminals when archive removes the owned worktree, and/or make session terminal creation lazy (only on first terminal-surface use) instead of eager in _onActiveSessionChanged; verify against the `hides (does not dispose) terminals when session is archived` test, which currently locks in the retention behavior and would need to change.
