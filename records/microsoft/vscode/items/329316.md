# Issue #329316 — Agent Window retains a zsh process for every archived session terminal

[https://github.com/microsoft/vscode/issues/329316](https://github.com/microsoft/vscode/issues/329316)

## Summary

Team-authored bug report (falls outside hard keep-open protections since this is a factual, code-confirmed defect, not a judgment call) describing a real resource leak in the Agents window terminal lifecycle; the fix requires a design decision (dispose-on-worktree-removal vs. lazy terminal creation), so this stays open for a maintainer/PR rather than an automatic fix.

## Change summary

Archiving an agent session hides (backgrounds) its terminal instead of disposing it, so the PTY and interactive zsh shell survive indefinitely even after the session's worktree is deleted, leaking one shell per archived session.

## Best solution

Decide and implement the retention policy conflict in src/vs/sessions/contrib/terminal/browser/sessionsTerminalContribution.ts: either dispose the terminal when the owning worktree is actually removed (distinguishing that from a reversible archive), or create session terminals lazily so archived sessions with deleted worktrees don't hold a live shell. This is a design tradeoff (see history of #297330/#318985/#321506 cited in the issue) best owned by whoever authored #318985.
