# Issue #240241 — Terminal suggest: Support lazy loading of fig specs via an index

[https://github.com/microsoft/vscode/issues/240241](https://github.com/microsoft/vscode/issues/240241)

## Summary

Still valid: all 100+ upstream specs and 14 custom specs are eagerly imported at module load time into `availableSpecs`. No lazy loading index has been implemented on current main.

## Change summary

Lazy-load fig completion specs via an index file instead of eagerly importing all ~115 specs at startup, to reduce activation time and memory.

## Best solution

Generate an index file with only command names and descriptions for the initial completion list; load full specs on demand via dynamic `import()` when argument completions are needed. The work lives in `extensions/terminal-suggest/src/terminalSuggestMain.ts` (the `availableSpecs` array and its imports) and `extensions/terminal-suggest/src/upstreamSpecs.ts` (the generated barrel file), plus a new or updated `scripts/update-specs.js` to produce the index.
