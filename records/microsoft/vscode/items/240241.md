# Issue #240241 — Terminal suggest: Support lazy loading of fig specs via an index

[https://github.com/microsoft/vscode/issues/240241](https://github.com/microsoft/vscode/issues/240241)

## Summary

Keep open: current main still eagerly imports the completion specs, so the requested loading optimization remains missing. The related first-completion performance issue addressed caching and telemetry, not deferred spec loading.

## Change summary

Provide command names and descriptions from a lightweight index and load full Fig specs only when argument completions need them.

## Best solution

Preserve existing terminal completion behavior while avoiding evaluation of full specs for activation and command-name suggestions. Plan the metadata generation and packaged loading boundary together so deferred imports also work in the distributed extension.
