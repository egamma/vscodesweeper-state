# Issue #145092 — Improved CSV/TSV editing

[https://github.com/microsoft/vscode/issues/145092](https://github.com/microsoft/vscode/issues/145092)

## Summary

CSV-aware editing is a valid capability, but established maintainer decisions consistently place CSV-specific viewing and editing in extensions rather than VS Code core.

## Change summary

Add a built-in CSV/TSV editing mode with delimiter detection, aligned columns, quote handling, structured navigation, and diff-editor integration.

## Best solution

Provide the CSV/TSV experience through an extension or custom editor, preserving the lightweight general-purpose editor. Any concrete extension API limitation that prevents a high-quality implementation should be isolated as a separate core API request.

## Vision fit

- **Fit:** rejected
- **Reason:** Specialized structured-data editing can be delivered by extensions and would add substantial language-specific behavior to the default text editor.
- **Evidence:** Public values and guardrails: “The power lives in extensions” and “Out of the box, VS Code is a text editor: lightweight and fast.”
