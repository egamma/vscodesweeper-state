# Issue #185575 — `⌘ Command` + `Backtick` hotkey on MacOS doesn't switch between  VSCode windows (AZERTY layout)

[https://github.com/microsoft/vscode/issues/185575](https://github.com/microsoft/vscode/issues/185575)

## Summary

Keep open: multiple reporters confirm that macOS window cycling fails while a text input has focus, with reports extending through VS Code 1.121.0. The latest comment provides a repeatable keybinding interaction worth investigating; neither a fixing commit nor an older canonical covering the same observable failure was established.

## Change summary

Command+Backtick fails to cycle macOS windows when the editor is focused, sometimes inserting text or invoking another action instead.

## Best solution

Restore native macOS window cycling consistently across editor and terminal focus without changing unrelated layout-specific shortcuts. Start by reproducing the reported navigateBack binding interaction and locating whether interception occurs in native menu accelerators or renderer keybinding dispatch.
