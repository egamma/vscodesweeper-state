# Issue #185575 — `⌘ Command` + `Backtick` hotkey on MacOS doesn't switch between  VSCode windows (AZERTY layout)

[https://github.com/microsoft/vscode/issues/185575](https://github.com/microsoft/vscode/issues/185575)

## Summary

Still reproducible: Cmd+` on macOS fails to switch VS Code windows when the editor has focus, particularly on AZERTY but also intermittently on QWERTY. No fix found on main. Related to upstream keyboard event handling but also VS Code's own keybinding dispatch.

## Change summary

Cmd+` (macOS native window-switch shortcut) is intercepted by VS Code's editor instead of being passed through to the system, especially with non-US keyboard layouts.

## Best solution

Investigate whether VS Code's keybinding dispatch can detect and defer Cmd+` to the system-level window switcher on macOS, particularly when Electron delivers it as a text-input event on non-US layouts. The fix likely involves the keyboard dispatch layer in src/vs/platform/keyboardLayout/ or Electron-level event handling. May partially overlap with https://github.com/microsoft/vscode/issues/141761 but this is specifically about the system-level Cmd+` shortcut being swallowed.
