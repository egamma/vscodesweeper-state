# Issue #334704 — Bug: "git.blame" settings not work

[https://github.com/microsoft/vscode/issues/334704](https://github.com/microsoft/vscode/issues/334704)

## Summary

The screenshot shows GitLens blame annotations and its changes hover, which are controlled independently of VS Code's built-in git.blame settings. Propose closing as extension-owned and explain the GitLens settings that disable both surfaces.

## Change summary

Disable inline Git blame annotations and blame hovers that remain visible after turning off the built-in Git blame settings.

## Best solution

Use gitlens.currentLine.enabled=false and gitlens.hovers.enabled=false to disable GitLens inline blame and hovers while retaining the reporter's built-in Git settings. Any remaining GitLens settings malfunction belongs in its own tracker.
