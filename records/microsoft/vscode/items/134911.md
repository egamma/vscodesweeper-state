## Summary

This remains a valid, community-promoted Backlog request: current VS Code exposes numbered fold-level commands but no corresponding numbered unfold-level commands. No verified older canonical with the same observable request was found, so the issue should remain open.

## Change summary

Add numbered unfold-level commands analogous to the existing fold-level commands, allowing a fully folded file to be expanded to a selected nesting depth.

## Best solution
