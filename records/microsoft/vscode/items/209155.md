# Issue #209155 — Issue reporter doesn't allow the issue body to be the template body

[https://github.com/microsoft/vscode/issues/209155](https://github.com/microsoft/vscode/issues/209155)

## Summary

The old web issue reporter fallback path (used when `issueReporter.experimental.webReporter` is false, i.e. on stable) still pre-fills 'ADD ISSUE DESCRIPTION HERE' as the body template and does not validate against submitting it unchanged. The new wizard overlay reporter sidesteps this by using form fields, but the legacy code path remains reachable. No commit references this issue, so it stays open.

## Change summary

The web issue reporter allows filing issues whose body is just the unchanged pre-filled template text ('ADD ISSUE DESCRIPTION HERE').

## Best solution

Either remove the old `getIssueUriFromStaticContent` fallback now that the wizard overlay reporter exists, or add client-side validation to detect unchanged template text before opening the GitHub URL. The code lives in `src/vs/workbench/contrib/issue/browser/issueService.ts` around line 169.
