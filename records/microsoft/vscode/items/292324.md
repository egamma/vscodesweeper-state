# Issue #292324 — Ability to create a PR for changes from background session

[https://github.com/microsoft/vscode/issues/292324](https://github.com/microsoft/vscode/issues/292324)

## Summary

Current main provides a Create PR action for eligible background worktree sessions in the Agents Window, but the regular chat session toolbar does not expose that action. Keep this team-authored request open: full coverage is not established, and no fixing commit explicitly referencing this issue was found.

## Change summary

Provide a button to create a pull request directly from a background session's changes.

## Best solution

Make PR creation directly discoverable from the background session's changes surface, using the existing session-worktree PR creation capability. The maintainer should establish whether the Agents Window action satisfies the original request or whether the regular chat session toolbar remains in scope.
