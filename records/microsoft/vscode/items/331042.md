# Issue #331042 — Support negation syntax in Settings filter

[https://github.com/microsoft/vscode/issues/331042](https://github.com/microsoft/vscode/issues/331042)

## Summary

Settings search still lacks general negation for feature filters. Keep this request open: existing inclusion filters do not cover the requested exclusion, and the related file-search issues are not duplicates.

## Change summary

Allow Settings search to exclude terms or feature groups, including AI-related settings.

## Best solution

Support exclusion within the existing Settings search grammar, with consistent behavior when combined with positive filters and ordinary search text. Keep this separate from disabling AI functionality globally.
