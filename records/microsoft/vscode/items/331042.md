# Issue #331042 — Support negation syntax in Settings filter

[https://github.com/microsoft/vscode/issues/331042](https://github.com/microsoft/vscode/issues/331042)

## Summary

Genuine, unmet feature request: the Settings editor's `@tag:`/`@feature:`/`@ext:`/`@id:`/`@lang:` query parser (settingsTreeModels.ts) has no negation/exclusion syntax today, so there's no way to filter out an `@feature` group; routing to the settings/preferences area for a product decision.

## Change summary

Add support for negating filter terms (e.g. excluding an `@feature:` group) in the Settings editor's search box.

## Best solution

If pursued, extend `parseQuery`/`tagRegex` family in src/vs/workbench/contrib/preferences/browser/settingsTreeModels.ts to recognize a `-` prefix (e.g. `-@feature:chat`) and thread an exclusion set through TOCTreeModel/filtering in settingsTree.ts; this is a scoped, additive parser change, not present today.
