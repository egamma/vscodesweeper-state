# Issue #94148 — Investigate setting Electron's proxy from user setting

[https://github.com/microsoft/vscode/issues/94148](https://github.com/microsoft/vscode/issues/94148)

## Summary

Fixed on main since April 2020: VS Code now calls Electron's session.setProxy when http.proxy is set. The fix commit explicitly references this issue, and current main still has the implementation in windowImpl.ts.

## Change summary

The http.proxy user setting was not propagated to Electron's network session, so extension marketplace and update requests ignored the configured proxy.

## Best solution

Keep the shipped fix; the proxy-from-settings functionality is live and verified. The documentation gap noted in comment 13 is tracked separately by https://github.com/microsoft/vscode/issues/121224.
