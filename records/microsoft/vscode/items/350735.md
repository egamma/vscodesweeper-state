# Issue #350735 — P2 HTML language server returns an uncapped ~25 MB document symbol tree for a 30k-line HTML file on every edit pause (~1 s extension host + ~2 s renderer CPU, 0.7 s UI freezes)

[https://github.com/microsoft/vscode/issues/350735](https://github.com/microsoft/vscode/issues/350735)

## Summary

Keep open: current HTML and CSS servers still return uncapped document symbols. Request sharing changed after the measured build, but does not bound individual replies; the supplied generator and steps suffice to retest the remaining performance problem.

## Change summary

Bound document-symbol results for large HTML and CSS documents to avoid excessive serialization and renderer work.

## Best solution

Provide bounded server-side symbol results with an explicit indication of truncation, preserving ordinary-file behavior and valid symbol structure. Establish the limit contract and measure the remaining cost after the merged editor request-sharing change.

- **Behavior:**

  > Large HTML and CSS files should not repeatedly deliver unbounded symbol results that stall the editor after typing pauses. Results must respect an agreed total-symbol budget, and users must be informed when results are incomplete. Ordinary files should retain complete Outline, breadcrumbs and Go to Symbol behavior. Acceptance includes bounded serialized responses and measured improvement on the supplied HTML fixture.
- **Trace:**

  > HTML's onDocumentSymbol in extensions/html-language-features/server/src/htmlServer.ts concatenates unrestricted results from all document modes; htmlMode.findDocumentSymbols delegates without a limit. CSS's onDocumentSymbol in extensions/css-language-features/server/src/cssServer.ts returns the complete hierarchical language-service result. JSON provides a client/server limit and status-item precedent in extensions/json-language-features/client/src/jsonClient.ts and server/src/jsonServer.ts. https://github.com/microsoft/vscode/pull/350711 addresses redundant and outdated editor requests, not response size. Source inspection establishes the uncapped paths, but current-build latency and generation-versus-transfer costs remain unmeasured. Preserve request sharing, cancellation, small-file completeness and unrelated link, folding and color behavior.
- **Open decisions:**
  - Should the symbol budget be configurable, as in JSON, or a fixed protective limit, and what default should apply?
  - When the budget is exceeded, what partial-symbol selection and user-visible truncation indication should Outline, breadcrumbs and Go to Symbol expose?
