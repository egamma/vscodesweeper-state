# Issue #139840 — Use modern (CSS color level 4) syntax for colors in the color picker

[https://github.com/microsoft/vscode/issues/139840](https://github.com/microsoft/vscode/issues/139840)

## Summary

Keep open: modern color-function support does not yet satisfy the request for modern RGB/HSL output, percentage alpha, and explicit degree units. The linked open PR addresses only part of the broader discussion, not the original formatting request.

## Change summary

Have the color picker offer CSS Color 4 notation with space-separated components, percentage alpha, and explicit deg suffixes.

## Best solution

Provide the requested modern presentations in the CSS language service and assess consistency with the editor's generic color provider. Review https://github.com/microsoft/vscode/pull/310768 as a partial implementation candidate without treating its OKLab/OKLCH additions as completion of the RGB/HSL formatting request.
