# Issue #244866 — SCM Graph - Allow user to change the default history item reference

[https://github.com/microsoft/vscode/issues/244866](https://github.com/microsoft/vscode/issues/244866)

## Summary

The graph remembers filters per repository within a workspace, but still lacks a configurable default for other repositories and machines. Keep this request open while the existing implementation candidate is reviewed.

## Change summary

Allow users to make All the default SCM Graph reference filter across repositories and machines.

## Best solution

Provide a user-configurable default reference filter while preserving explicit per-repository selections. Review https://github.com/microsoft/vscode/pull/244988 as the existing implementation candidate rather than starting competing work.
