# Issue #140950 — Spacing out the buttons in action bar [Accessibility]

[https://github.com/microsoft/vscode/issues/140950](https://github.com/microsoft/vscode/issues/140950)

## Summary

Modern UI now adds separation between Source Control row actions, partially addressing the original complaint, but the broader action-bar accessibility request remains unsettled. Keep this accepted Backlog item open for a design review of the remaining scope; no older same-symptom canonical was verified.

## Change summary

Improve spacing between inline action buttons so users can reliably select Stage without accidentally selecting Discard Changes.

## Best solution

Establish consistent, accessible spacing for inline view actions, using the existing Modern UI SCM separation as a starting point. Assess whether that treatment adequately addresses accidental activation and whether equivalent spacing should apply to other views and the classic layout.

- **Behavior:**

  > The reporter repeatedly selects Discard Changes while aiming for Stage during bulk staging in Source Control. The intended outcome is reliably distinguishable and targetable neighboring actions without sacrificing usable compact rows. Modern UI already introduces an SCM action gap, so assess that behavior before deciding what remains necessary. Acceptance should cover the agreed spacing across affected layouts and views, with no clipping or keyboard-navigation regression.
- **Trace:**

  > The shared ActionBar stylesheet in src/vs/base/browser/ui/actionbar/actionbar.css defines horizontal flex action containers without a gap and gives labels 3px padding. These source paths establish differing spacing treatments, not whether the newer treatment resolves the reporter's targeting difficulty. - **Open decisions:**
