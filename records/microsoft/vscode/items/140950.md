# Issue #140950 — Spacing out the buttons in action bar [Accessibility]

[https://github.com/microsoft/vscode/issues/140950](https://github.com/microsoft/vscode/issues/140950)

## Summary

The request for better spacing between inline action buttons in view list items remains valid — the padding was bumped from 2px to 3px at some point, but no dedicated fix has addressed the accidental-click problem for tightly grouped inline actions in views like SCM. Keeping open in the Backlog as an accessibility improvement.

## Change summary

Inline action buttons in view list rows (e.g. SCM file actions) are too close together, causing accidental clicks on the wrong button.

## Best solution

Increase the hit-target spacing between inline action items in list rows (the row-level action bar), potentially via padding or gap adjustments in the view-level action bar CSS, while respecting the 22px row height constraint. The fix area spans the workbench views action bar styling.
