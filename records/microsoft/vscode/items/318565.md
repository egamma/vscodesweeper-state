# Issue #318565 — "Publish to GitHub" defaults to broken HTTPS remote instead of SSH

[https://github.com/microsoft/vscode/issues/318565](https://github.com/microsoft/vscode/issues/318565)

## Summary

Publishing already supports SSH through github.gitProtocol, and HTTPS is an intentional, authenticated default. The subsequent terminal authentication failure needs clarification before it can be diagnosed or closed.

## Change summary

Publishing a repository to GitHub leaves an HTTPS remote that the reporter cannot subsequently push to from a terminal.

## Best solution

Retain the existing protocol preference and establish whether pushes fail in VS Code's integrated terminal or an external terminal. If the enabled built-in authentication path fails in the integrated terminal, address that defect in the Git/GitHub authentication integration rather than changing the default protocol.
