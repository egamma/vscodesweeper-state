- **Shared current-source path:** extensions/git/src/commands.ts:3210-3226 passes the remote revision first and selected local commit second to _openChangesBetweenRefs. The generic Compare With command uses the same helper. At lines 3291-3304, that helper calls repository.diffBetweenWithStats and displays the reported no-changes message for an empty result.
- **Trigger explained:** extensions/git/src/repository.ts:1151-1162 constructs ref1...ref2, and extensions/git/src/git.ts:1949-1966 passes it to git diff. When the fetched remote is ahead of the selected local commit, remote...local compares their merge base with local, yielding no changes for an ancestor local commit. This is the same older-versus-newer comparison symptom owned by the canonical, not evidence that fetching failed.
