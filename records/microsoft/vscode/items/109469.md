# Issue #109469 — Suggest widget: do not grow horizontally to the left if I am dragging to the right

[https://github.com/microsoft/vscode/issues/109469](https://github.com/microsoft/vscode/issues/109469)

## Summary

Still present on main: the suggest widget's east-sash resize has no viewport-boundary clamping, so dragging right past the VS Code window edge causes the content widget to reposition leftward. Both commenters are team members and the author recommended prohibiting the behavior; keeping open as a polish item.

## Change summary

Dragging the suggest widget's right sash beyond the VS Code window boundary causes the widget to grow to the left instead of being clamped.

## Best solution

Clamp the east-sash resize of the suggest widget so it cannot exceed the available space to the right of the widget's current position — either cap `maxWidth` in `_layout` based on the editor's visible width minus the widget's left offset, or prevent `ResizableHTMLElement` from reporting a width that would push the content widget leftward. The fix likely lives in `src/vs/editor/contrib/suggest/browser/suggestWidget.ts` around the `_layout` / `_resize` path.
