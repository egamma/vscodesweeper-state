# Issue #211424 — Right click on a file on the file explorer shifts into an already opened image instead of the one that is being clicked

[https://github.com/microsoft/vscode/issues/211424](https://github.com/microsoft/vscode/issues/211424)

## Summary

Current main fixes the reported stale-selection behavior: right-clicking an unselected Explorer item now selects that item rather than retaining an already-open file or image as the selection.

## Change summary

Right-clicking a file in the Explorer could retain and act on an already-open image instead of selecting the clicked file.

## Best solution

Keep the context-menu targeting behavior implemented by commit 49247edb6ab458e52a9e787945f0aa4985f129d0, which makes the clicked Explorer item the selection before opening its context menu.
