# Issue #237320 — Explorer: Sticky folder cannot be dragged

[https://github.com/microsoft/vscode/issues/237320](https://github.com/microsoft/vscode/issues/237320)

## Summary

Valid feature request from a team member: sticky scroll folders in the Explorer support context menus but not drag-and-drop. No implementation exists on current main — the StickyScrollWidget has no DnD handling. Keeping open.

## Change summary

Enable drag-and-drop operations on sticky-scrolled folder elements in the Explorer tree.

## Best solution

Add drag-and-drop support to the StickyScrollWidget in `src/vs/base/browser/ui/tree/abstractTree.ts`, wiring up the same DnD controller used by the regular tree rows so sticky folder elements can be dragged or used as drop targets.
