# Issue #315779 — Why is `cloud` disabled for my workspace in the agents window

[https://github.com/microsoft/vscode/issues/315779](https://github.com/microsoft/vscode/issues/315779)

## Summary

Valid polish request: the Cloud option in the Agents window session picker is disabled without any hover or tooltip explaining why. A team member confirmed the confusion. No fix found on current main.

## Change summary

When Cloud is disabled in the Agents window picker (because no GitHub repository is selected), there is no hover or tooltip explaining why it is unavailable.

## Best solution

Add a hover/tooltip to the disabled Cloud option explaining that a GitHub repository must be selected first. The existing pattern in `src/vs/workbench/contrib/chat/browser/agentSessions/sessionTypeAvailability.ts` already provides hover explanations for other disabled states (sign-in required, upgrade required, no models) — extend this pattern to cover the 'no repository selected' case. The workspace picker in `src/vs/sessions/contrib/chat/browser/sessionWorkspacePicker.ts` and the session type picker in `src/vs/sessions/contrib/chat/browser/sessionTypePicker.ts` are the likely integration points.
