# Issue #291288 — Read folder uses search icon, read file uses book icon?

[https://github.com/microsoft/vscode/issues/291288](https://github.com/microsoft/vscode/issues/291288)

## Summary

The icon inconsistency remains on current main and is explicitly listed as unfinished in the UI refresh tracker. The rendering path is bounded, but the shared icon or icon family should be chosen before implementation.

## Change summary

Make the chat tool-call icons for reading files and folders semantically clear and visually consistent.
