# Issue #291288 — Read folder uses search icon, read file uses book icon?

[https://github.com/microsoft/vscode/issues/291288](https://github.com/microsoft/vscode/issues/291288)

## Summary

The icon mismatch remains in current source: directory listing is categorized as search, while file reading receives a book icon. Keep this open for a focused design decision; the related refresh tracker explicitly lists it as unfinished.

## Change summary

Make folder-reading and file-reading tool icons convey consistent, understandable semantics in chat.

## Best solution

Agree on a coherent icon vocabulary for reading files and listing directories, then apply it consistently across grouped and standalone tool rows. Preserve the distinct treatment of genuine searches, explicit provider icons, and MCP tools.
