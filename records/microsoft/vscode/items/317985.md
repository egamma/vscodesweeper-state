[https://github.com/microsoft/vscode/issues/317985](https://github.com/microsoft/vscode/issues/317985)

## Summary

The unexplained permission prompt was an unintended Linux Wayland regression, not a permission VS Code needed at startup. The startup capture warmup was removed and the fix was verified in 1.122.1.

## Change summary

Avoid or explain the display-capture permission prompt shown when VS Code first starts on KDE Wayland.
