# Issue #324604 — Agents Window - Placeholder text should be gray

[https://github.com/microsoft/vscode/issues/324604](https://github.com/microsoft/vscode/issues/324604)

## Summary

Traced on main: the agent-sessions chat input CSS colors `.ghost-text-decoration` (an unrelated inline-suggestions ghost-text class) instead of `.editorPlaceholder` (the class actually used by the editor's PlaceholderTextContribution for the 'What are you building?' text), so the dedicated `agentsChatInput.placeholderForeground` token is dead code and the placeholder falls back to whatever `--vscode-editor-placeholder-foreground` resolves to, which can end up matching normal text depending on theme.

## Change summary

The 'What are you building?' placeholder text in the new Agents window chat input renders in the same (non-gray) color as regular input text instead of a muted placeholder color.

## Best solution

Fix the selector in src/vs/sessions/contrib/chat/browser/media/chatInput.css to target `.editorPlaceholder` (the actual overlay element created by PlaceholderTextContribution in src/vs/editor/contrib/placeholderText/browser/placeholderTextContribution.ts) instead of `.ghost-text-decoration`, so the existing `agentsChatInput.placeholderForeground` color token is actually applied.
