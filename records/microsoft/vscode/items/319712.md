# Issue #319712 — Agents window: after session starts and is in progress, it's being replaced by a new session view

[https://github.com/microsoft/vscode/issues/319712](https://github.com/microsoft/vscode/issues/319712)

## Summary

Verified duplicate of the older open issue https://github.com/microsoft/vscode/issues/317183: both reports show the active temporary Copilot CLI session being removed and the Agents Window returning to the new-session view after timing out while waiting for session commit.

## Change summary

An in-progress Copilot CLI session disappears and is replaced by the new-session view when its temporary session times out waiting for the committed session.

## Best solution

Consolidate the defect and its additional logs on https://github.com/microsoft/vscode/issues/317183, then resolve the commit-handoff timeout without removing the active temporary session; the existing implementation candidate is https://github.com/microsoft/vscode/pull/319202.
