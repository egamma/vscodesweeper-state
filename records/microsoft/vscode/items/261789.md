# Issue #261789 — keyword suggestion message overrides search results count

[https://github.com/microsoft/vscode/issues/261789](https://github.com/microsoft/vscode/issues/261789)

## Summary

The current source still replaces the search result count with keyword suggestions and prevents subsequent count updates while suggestions exist. Keep this open while the explicitly linked fixing PR is reviewed; it has not merged.

## Change summary

Show the search result count and keyword suggestions simultaneously in the Search view.
