# Issue #201703 — Redo action does not reveal content that was added by accepting inlay hint

[https://github.com/microsoft/vscode/issues/201703](https://github.com/microsoft/vscode/issues/201703)

## Summary

The reported redo failure remains traceable in current source: accepting an inlay hint records no resulting cursor selection, so redo restores the text without requesting a reveal. Keep this open in the already-correct inlay-hints area.

## Change summary

Redoing an accepted inlay hint should reveal the reapplied content after its line has been scrolled out of view.

## Best solution

Make accepted inlay-hint edits participate in cursor restoration and reveal on redo, with regression coverage for an off-screen edited line. Preserve the generic executeEdits API's existing behavior for unrelated callers.
