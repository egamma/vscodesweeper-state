# Issue #260641 — Add terminal/shell mode to chat input

[https://github.com/microsoft/vscode/issues/260641](https://github.com/microsoft/vscode/issues/260641)

## Summary

A real gap remains: current main has terminal-command attachments but no shell mode in the chat input. This team-authored Backlog request must remain open because its prototype closed unmerged and no verified duplicate or referenced implementation exists.

## Change summary

Add a chat-input shortcut that executes a shell command and automatically supplies its result to Copilot for analysis.

## Best solution

Define a secure shell-input mode that treats the explicitly entered command as execution intent, runs it in the appropriate terminal, and attaches the command, output, and exit status to the ensuing chat request. The implementation likely belongs across chat request parsing/input handling and terminal-chat integration.
