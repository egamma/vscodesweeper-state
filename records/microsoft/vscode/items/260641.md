# Issue #260641 — Add terminal/shell mode to chat input

[https://github.com/microsoft/vscode/issues/260641](https://github.com/microsoft/vscode/issues/260641)

## Summary

The direct-command chat workflow remains distinct from existing terminal context and auto-approval features. The linked shell-mode prototype was closed without merging, and no verified older canonical owns this request; keep this team-authored Backlog item open for product design.

## Change summary

Allow users to submit a literal shell command from chat input and get Copilot help with its output without separately running and attaching it or approving a model-selected command.

## Best solution

Provide an explicit user-command entry path in chat that executes the supplied command and makes its result available for Copilot analysis. Settle the interaction and follow-up behavior first, without changing approval rules for ordinary agent-generated commands.
