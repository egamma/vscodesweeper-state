# Issue #264977 — Low maxInputTokens gives no lowest priority node found error

[https://github.com/microsoft/vscode/issues/264977](https://github.com/microsoft/vscode/issues/264977)

## Summary

The accepted Backlog bug remains on current main: an undersized custom-model budget can still surface an internal prompt-rendering error instead of an actionable message. Newer reports confirm the symptom but cannot become canonicals for this re-reviewed older issue.

## Change summary

Show an actionable chat error when a custom language model's input-token budget is too small to construct the prompt.

## Best solution

Keep the custom provider selected but report that its configured context budget cannot fit the required prompt, including enough guidance to increase `maxInputTokens`; do not alter Auto model-selection behavior as part of this narrowly scoped report.
