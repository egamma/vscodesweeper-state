# Issue #272272 — Publish log files fails

[https://github.com/microsoft/vscode/issues/272272](https://github.com/microsoft/vscode/issues/272272)

## Summary

Still-active CI infrastructure issue — the March 2026 comment from chrmarti links another failing build with the same file-locking error, confirming it remains unresolved. No fix has landed on main. Keeping open for the engineering team.

## Change summary

Azure DevOps pipeline fails to publish integration-test log files on Windows because the git extension's log file is locked by another process.

## Best solution

The publish-logs step in `build/azure-pipelines/win32/product-build-win32.yml` (line ~44) runs while VS Code processes may still hold log files open. Either ensure all VS Code processes are fully terminated before the publish step, or configure the artifact upload to use `FileShare.Read` / retry with backoff, or copy the logs to a staging directory before the artifact publish.
