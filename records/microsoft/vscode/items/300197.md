# Issue #300197 — [Feature Request]Allow extension authors to include plugin installation from any desired location

[https://github.com/microsoft/vscode/issues/300197](https://github.com/microsoft/vscode/issues/300197)

## Summary

Keep open: current source supports user-driven installation from arbitrary repositories and extension-bundled plugins, but neither establishes the requested extension-facing installation contract. This team-authored Backlog request has no verified issue-referencing fix or qualifying canonical duplicate.

## Change summary

Allow extensions to initiate agent-plugin installation from a chosen repository or other source, optionally letting the user select that source.

## Best solution

Decide whether to expose a supported, user-confirmed plugin installation contract to extensions, reusing the existing installation flow and preserving trust and managed-policy enforcement. Bundled plugin contributions and manual source installation should be documented as partial alternatives, not treated as equivalent coverage.
