# Issue #187756 — vscode.FileDecoration color overides gitDecoration color on folders, even when set to null

[https://github.com/microsoft/vscode/issues/187756](https://github.com/microsoft/vscode/issues/187756)

## Summary

The agreed “falsy yields the floor” behavior was implemented: decorations without a color no longer suppress another provider’s defined color. Current main retains that behavior for files and collapsed folders, so this can be closed as completed.

## Change summary

Allow colorless file decorations to contribute badges and tooltips without overriding Git decoration colors.

## Best solution

Keep the color-selection behavior implemented in commit 0f5be7c29fc276f70cfd4cf4140079aaef649823. The accepted solution preserves defined decoration colors without introducing extension priority settings.
