# Issue #325324 — Copy Branch Name UI

[https://github.com/microsoft/vscode/issues/325324](https://github.com/microsoft/vscode/issues/325324)

## Summary

The request for an accessible UI action to copy a branch name is already covered by an open, maintainer-accepted issue. Consolidate there, preserving this report's discoverability feedback from VS Code 1.128.0 on Windows.

## Change summary

Provide a discoverable UI action to copy a Git branch name without using the terminal.

## Best solution

Follow https://github.com/microsoft/vscode/issues/148069 for a discoverable branch-copy action in the standard Git UI. The experimental repository explorer already supports copying branch names, but does not settle the default-UI discoverability request.
