# Issue #341050 — "npm" MCP Servers No Longer Found in Search Since Version 1.138

[https://github.com/microsoft/vscode/issues/341050](https://github.com/microsoft/vscode/issues/341050)

## Summary

Thanks for the detailed report. In current source, `toSupportedPackageRegistryType` only accepts npm, docker, docker-hub, oci, pypi and nuget, so packages with `registryType: "npx"` are silently dropped and the server disappears from the list. Whether `npx` should be tolerated as an alias for npm is a product call.

## Change summary

MCP registry servers whose package has registryType "npx" are filtered out of gallery search since 1.138, while "npm" ones appear.

## Best solution

Decide whether to map 'npx' to RegistryType.NODE in toSupportedPackageRegistryType (lenient), or keep strict spec behavior and surface an unsupported-type message.
