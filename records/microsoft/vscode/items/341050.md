# Issue #341050 — "npm" MCP Servers No Longer Found in Search Since Version 1.138

[https://github.com/microsoft/vscode/issues/341050](https://github.com/microsoft/vscode/issues/341050)

## Summary

Thanks for the detailed report. Current main only accepts `npm`, `docker`, `docker-hub`, `oci`, `pypi` and `nuget` as package registry types. Any package with `registryType: "npx"` is dropped, which matches what you saw. Whether to accept `npx` as an alias for `npm` is a maintainer call, because it is not a value in the official registry spec.

## Change summary

MCP gallery or registry entries with `registryType: "npx"` are filtered out of search results, while `npm` entries still appear.

## Best solution

Decide whether `toSupportedPackageRegistryType` in `src/vs/platform/mcp/common/mcpGalleryService.ts` should map `npx` to `RegistryType.NODE`. If it should not, the unsupported entries need a clearer signal than silently disappearing.
