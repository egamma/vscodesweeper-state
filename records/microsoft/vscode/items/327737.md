# Issue #327737 — `editor.occurrencesHighlight` incorrectly highlights identifier occurrences in Python

[https://github.com/microsoft/vscode/issues/327737](https://github.com/microsoft/vscode/issues/327737)

## Summary

Confirmed regression on current main: the generic textual highlight provider treats words inside non-code tokens as identifiers. Keep this open while the linked fix attempt is reviewed and expanded to cover the full report.

## Change summary

Occurrence highlighting in Python incorrectly treats string contents and keywords as identifier references.

## Best solution

Land an upstream fix in the editor word-highlighter that prevents textual fallback for non-identifier tokens, with tests for strings, comments, regex tokens, and Python keywords in both single- and multi-file modes. The linked fix handles standard non-code token types but does not appear to distinguish keywords from identifiers.
