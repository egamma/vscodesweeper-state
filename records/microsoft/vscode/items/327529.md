# Issue #327529 — Agents window Markdown editor: macOS word and line navigation use the wrong modifiers

[https://github.com/microsoft/vscode/issues/327529](https://github.com/microsoft/vscode/issues/327529)

## Summary

Confirmed in source: the shipped Markdown editor conflates Ctrl and Cmd and ignores Option. An upstream fix exists but is not yet consumed by VS Code main, so this team-authored issue should remain open.

## Change summary

Make word, visual-line, and document navigation in the experimental Markdown editor use standard macOS modifiers.

## Best solution

Publish and consume the markdown-editor changes from https://github.com/microsoft/vscode-packages/commit/00201d98067ac90019d4da13a37f1138e7806ddb, including its platform-specific keybinding tests, then verify the reported macOS commands in VS Code.
