# Issue #167108 — Enable debugging Code OSS with "break on caught exceptions" enabled

[https://github.com/microsoft/vscode/issues/167108](https://github.com/microsoft/vscode/issues/167108)

## Summary

Keep open: conditional exception breakpoints already exist, but the expected-error classification needed to make them practical for debugging Code OSS remains incomplete. This team-authored Backlog item has no verified fixing commit or open canonical that supersedes it.

## Change summary

Make caught-exception debugging distinguish expected operational failures from unexpected programming errors in Code OSS.

## Best solution

Establish a consistent developer-facing exception classification and filtering convention, then adopt it across the expected-error paths that interrupt Code OSS debugging. Preserve visibility of unexpected TypeErrors, ReferenceErrors, and bug-indicating failures rather than indiscriminately suppressing exception pauses.
