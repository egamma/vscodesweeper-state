# Issue #171032 — Command Center does not work well with default window title

[https://github.com/microsoft/vscode/issues/171032](https://github.com/microsoft/vscode/issues/171032)

## Summary

The Command Center intentionally shows only the workspace name when using the default title format — this is a deliberate space-saving design. A related request for a separate CC label setting (#256643) was closed as not-planned, reinforcing the current behavior as intentional.

## Change summary

When the Command Center is enabled and the default window title format is used, only the workspace name is shown instead of the full title string.

## Best solution

Keep the current behavior: the Command Center shows the workspace name by default and respects the full title only when the user has explicitly customized `window.title`. The related feature request for a separate CC label setting was already declined.
