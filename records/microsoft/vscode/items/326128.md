# Issue #326128 — Agents window: consolidate redundant progress spinners

[https://github.com/microsoft/vscode/issues/326128](https://github.com/microsoft/vscode/issues/326128)

## Summary

Keep open: current main still implements three overlapping spinner affordances, and this team-authored Modern UI cleanup has specific acceptance criteria.

## Change summary

Consolidate concurrent Agents window progress indicators by using shimmer for inline work and suppressing redundant chat spinners.

## Best solution

Audit the progress states across the chat input, chat tabs, and subagent pills, then establish one session-level spinner while using lightweight text shimmer for subordinate activity. Suppress tab progress for the active or sole chat.
