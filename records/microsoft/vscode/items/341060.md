# Issue #341060 — Discover: Installing 'Argus testing' fails

[https://github.com/microsoft/vscode/issues/341060](https://github.com/microsoft/vscode/issues/341060)

## Summary

Thanks for testing. The error is thrown by design when the MCP server only offers install choices that need secrets or inputs. Discover still lists those servers as installable, so the install fails after the user clicks it. The open question is whether to hide them, disable the button, or add input collection.

## Change summary

Discover offers an Install action for MCP servers that it can't install because they need secrets or other inputs, and then fails with an error.

## Best solution

Mark MCP candidates that have no remote, secret-free transport choice as not installable in Discover, or disable their Install button with an explanation. This avoids the dead-end error. Longer term, Discover could collect the required inputs.
