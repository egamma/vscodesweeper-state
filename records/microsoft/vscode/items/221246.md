# Issue #221246 — Vertical font hinting bug solution

[https://github.com/microsoft/vscode/issues/221246](https://github.com/microsoft/vscode/issues/221246)

## Summary

Confirmed Linux font rendering issue where subpixel positioning causes blurry text; the workaround (`--disable-font-subpixel-positioning`) works but isn't exposed as a VS Code flag. Still reproducible on current builds (Debian 13, June 2025). Keeping open as a confirmed bug in the Backlog.

## Change summary

On certain Linux configurations, VS Code renders blurry/unsharp text due to Chromium's font subpixel positioning; adding `--disable-font-subpixel-positioning` as a supported flag (like the existing `--disable-lcd-text`) would fix it.

## Best solution

Expose `--disable-font-subpixel-positioning` as a recognized CLI flag in `src/vs/platform/environment/node/argv.ts` and pass it through to Electron, mirroring how `--disable-lcd-text` is already handled. Alternatively, investigate whether this should be the default on Linux with grayscale antialiasing.
