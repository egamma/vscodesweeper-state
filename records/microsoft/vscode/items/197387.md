# Issue #197387 — terminal confirm on exit dialog appears when no child process running after reload

[https://github.com/microsoft/vscode/issues/197387](https://github.com/microsoft/vscode/issues/197387)

## Summary

Still reproduces on main: the `hasChildProcesses` getter in `terminalInstance.ts` short-circuits on a stale snapshot from persistence time, causing a false positive confirmation dialog. An open PR (#311860) addresses this but has not merged.

## Change summary

After a window reload, the 'confirm on exit' dialog fires even after the child process has exited, because the persisted `hasChildProcesses` snapshot is never updated.

## Best solution

Land the fix from https://github.com/microsoft/vscode/pull/311860 (or an equivalent one-line update in the `onDidChangeProperty` handler in `terminalInstance.ts` to sync the stale snapshot with live `HasChildProcesses` events).
