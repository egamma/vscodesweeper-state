The restored terminal's stale child-process snapshot still causes an unnecessary exit confirmation on current main. Keep this open while the directly linked fix proposal is reviewed.

## Change summary

After reloading with a running terminal child process, exiting that process should stop the hasChildProcesses-based window-close confirmation.
