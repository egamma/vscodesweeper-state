# Issue #201732 — Indent instead of de-indent when soft wrapping long lines in signatures

[https://github.com/microsoft/vscode/issues/201732](https://github.com/microsoft/vscode/issues/201732)

## Summary

The requested continuation indentation remains missing from the hover rendering path; editor wrapping settings do not cover it. Keep this correctly routed request open: the maintainer welcomed an implementation, and no verified older canonical issue or fixing commit was found.

## Change summary

Indent soft-wrapped signature and parameter-documentation continuations beyond their parent line so parameter boundaries remain readable.

## Best solution

Provide consistent continuation indentation in hover signatures and parameter documentation without altering the underlying text or unrelated Markdown layout. Establish which rendered content can reliably retain parameter grouping before implementing across the shared rendering path.
