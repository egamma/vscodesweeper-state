# Issue #250300 — Detect missing marketplace extensions upon search

[https://github.com/microsoft/vscode/issues/250300](https://github.com/microsoft/vscode/issues/250300)

## Summary

The search-specific follow-up remains necessary: current search refreshes gallery metadata but does not invoke missing-extension detection. The existing warning covers update checks, not this search path, and no verified open canonical was found.

## Change summary

Detect installed extensions missing from the Marketplace when synchronizing matching local extensions during search.

## Best solution

Matching installed Marketplace extensions should acquire the existing unavailable-extension warning when search checks their gallery metadata, without requiring a separate update check. Keep this bounded to preferred local search results and preserve existing search ordering and filtering.
