# Issue #134410 — Possible to disable automatic insertion of periods when using Codespaces on macOS?

[https://github.com/microsoft/vscode/issues/134410](https://github.com/microsoft/vscode/issues/134410)

## Summary

Still a real gap on current main: VS Code does not suppress macOS's automatic period-on-double-space in the code editor, and the issue has grown more acute since EditContext became the default input path on desktop. The workaround (`editor.editContext: false`) exists but disables a broader feature. Keeping open — 20 upvotes, active community interest, and no fix landed.

## Change summary

macOS's 'Add period with double-space' text substitution fires inside the VS Code code editor, inserting unwanted periods; other code editors suppress this.

## Best solution

Suppress macOS automatic text replacement (specifically period-on-double-space) in the code editor's EditContext/textarea input path, either via the Electron `toggleTextReplacement` role menu item or by programmatically disabling `isAutomaticTextReplacementEnabled` on the underlying text view. On web, a similar suppression should be applied to the hidden textarea. This keeps the OS-level setting intact for other apps while preventing unwanted periods in code.
