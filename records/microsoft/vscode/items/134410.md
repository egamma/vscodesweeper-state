# Issue #134410 — Possible to disable automatic insertion of periods when using Codespaces on macOS?

[https://github.com/microsoft/vscode/issues/134410](https://github.com/microsoft/vscode/issues/134410)

## Summary

Still valid and unfixed on main. The macOS double-space-to-period substitution now affects desktop VS Code too since EditContext became the default input method. The workaround (`editor.editContext: false`) is available but trades away EditContext benefits. No commit addresses the underlying request to suppress OS text replacements in the editor.

## Change summary

Suppress macOS's automatic period insertion (double-space → period) in the VS Code editor, which now affects both web and desktop since EditContext became the default.

## Best solution

Implement suppression of macOS text substitutions (double-space → period) in the editor input layer. On desktop/Electron, the `isAutomaticTextReplacementEnabled` property on NSTextView (or the Electron Substitutions menu support via https://github.com/electron/electron/pull/32024) could be leveraged. For the EditContext path, the `textupdate` handler in `nativeEditContext.ts` could detect and revert OS-level substitutions. For the web textarea path, similar interception logic would be needed in `textAreaEditContext.ts`. A dedicated editor option (e.g. `editor.suppressOSTextSubstitutions`) would give users control.
