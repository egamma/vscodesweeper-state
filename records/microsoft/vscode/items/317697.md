# Issue #317697 — Support headersHelper in MCP config

[https://github.com/microsoft/vscode/issues/317697](https://github.com/microsoft/vscode/issues/317697)

## Summary

Keep open: current MCP configuration supports headers and variable substitution, but not the requested script-based headersHelper. No verified older canonical issue was found, and the accepted Backlog request should not be declined for inactivity.

## Change summary

Support generating MCP authentication headers by running a configured credential-helper script.

## Best solution

Have the MCP owners evaluate a supported dynamic-header mechanism for custom authentication, including its execution approval and credential-refresh semantics. Existing header variables are a partial alternative, not equivalent to invoking a script that returns the header map.
