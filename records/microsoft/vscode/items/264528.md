# Issue #264528 — Accepting an ML completion while in references view switches focus to main editor

[https://github.com/microsoft/vscode/issues/264528](https://github.com/microsoft/vscode/issues/264528)

## Summary

The reported focus switch remains reproducible from current source: accepting a completion in the references preview selects and focuses the parent editor's completion controller. Keep this open in NES; the editor-selection defect is bounded and ready for implementation.

## Change summary

Accepting an inline completion with Tab in the references peek editor should apply it there without moving focus or modifying the main editor.

## Best solution

Make inline-completion commands respect the focused editable references preview while preserving parent-editor handling for dedicated inline-edit preview widgets. Cover completion ownership, document changes, and focus with an embedded-editor regression test.
