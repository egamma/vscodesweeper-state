# Issue #342606 — Incorrect Default for Copilot's Permission

[https://github.com/microsoft/vscode/issues/342606](https://github.com/microsoft/vscode/issues/342606)

## Summary

Keep open for a permission-default decision: current source explicitly makes session-wide approval the primary action for ordinary Agent Host confirmations. This security-sensitive concern should not be closed merely because the current ordering is intentional.

## Change summary

Restore Allow Once as the default permission action in the Copilot harness, rather than session-wide approval.

## Best solution

Make one-time approval the primary action for ordinary Copilot confirmations, with session-wide approval remaining an explicit alternative, subject to the permission owners' review. Preserve the separate one-time-only rules for managed and sandbox confirmations.
