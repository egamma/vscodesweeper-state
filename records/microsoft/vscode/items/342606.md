# Issue #342606 — Incorrect Default for Copilot's Permission

[https://github.com/microsoft/vscode/issues/342606](https://github.com/microsoft/vscode/issues/342606)

## Summary

Keep open for human review of permission defaults and approval scope. Another user confirms the regression; current source improves shell and URL confirmations but still places session-wide approval first for other tools, so it does not establish complete resolution.

## Change summary

Copilot permission prompts default to session-wide approval rather than one-time approval, with reports of unexpectedly broad authorization.

## Best solution

Resolve the approval-default and scope concerns together in Copilot's permission flow, ensuring broader grants require an informed choice. Evaluate the suggested remembered selection with the area owner rather than treating it as an agreed design.
