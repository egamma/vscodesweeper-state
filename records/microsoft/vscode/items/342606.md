# Issue #342606 — Incorrect Default for Copilot's Permission

[https://github.com/microsoft/vscode/issues/342606](https://github.com/microsoft/vscode/issues/342606)

## Summary

Keep open for human review because the report concerns permission scope and unintended blanket authorization. Current source addresses the reported shell and URL defaults, and a commenter reports improvement, but neither establishes resolution across all affected confirmation types.

## Change summary

Restore one-click, one-time approval instead of making session-wide permission the default in the Copilot harness.

## Best solution

Confirm that Copilot permission prompts default to one-time approval throughout the affected tool categories, with broader grants requiring explicit selection. Reconcile the remaining generic session-first fallback with that expectation before a maintainer determines whether this security-sensitive report is resolved.
