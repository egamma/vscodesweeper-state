# Issue #330787 — Transparency or Vibrancy is not working now

[https://github.com/microsoft/vscode/issues/330787](https://github.com/microsoft/vscode/issues/330787)

## Summary

The transparency behavior is provided by the third-party Vibrancy Continued extension, and the reported failure is its compatibility problem with VS Code's experimental Modern UI layout rather than a defect in a core VS Code feature.

## Change summary

Make the Vibrancy Continued transparency effect work while `workbench.experimental.modernUI` is enabled.

## Best solution

Vibrancy Continued should update its HTML/CSS patching to support the Modern UI workbench structure; VS Code core should not incorporate or maintain the extension's installation-modifying vibrancy implementation.
