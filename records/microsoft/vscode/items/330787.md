# Issue #330787 — Transparency or Vibrancy is not working now

[https://github.com/microsoft/vscode/issues/330787](https://github.com/microsoft/vscode/issues/330787)

## Summary

The reporter identifies the third-party extension `illixion.vscode-vibrancy-continued`, which works by patching VS Code's own window/CSS internals to fake transparency — not a supported extension API. The new `workbench.experimental.modernUI` setting changes those same internals (inline background styling in the Electron workbench bootstrap), so the two are incompatible; this is the extension's patching breaking against a core UI change, not a VS Code defect.

## Change summary

Vibrancy/transparency from the vscode-vibrancy-continued extension stops working once the new Modern UI Update experimental setting is enabled.

## Best solution

Point the reporter to the vscode-vibrancy-continued extension's own repository to update its patches for Modern UI's new DOM/CSS structure; VS Code core has no supported vibrancy/transparency API for this extension to hook into, so there's no core fix here.
