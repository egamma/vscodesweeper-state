# Issue #306748 — Feature Request: Prompt inputs for all dependent tasks at launch

[https://github.com/microsoft/vscode/issues/306748](https://github.com/microsoft/vscode/issues/306748)

## Summary

The requested upfront collection of dependency inputs remains missing: current task execution resolves inputs separately as each dependency reaches execution. Keep this open for discussion; the existing sequencing option and the related parallel-input report do not cover the full request.

## Change summary

Offer an opt-in mode that collects all dependent-task inputs before any task in the dependency graph starts executing.

## Best solution

Consider an opt-in input-preflight mode in the task execution system that preserves existing lazy behavior by default. Establish its treatment of command inputs and workspace-scoped input identities before committing to a public configuration property.
