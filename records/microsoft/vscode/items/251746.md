# Issue #251746 — Improve Slash-Command UI for MCP Prompts

[https://github.com/microsoft/vscode/issues/251746](https://github.com/microsoft/vscode/issues/251746)

## Summary

The MCP prompt completion provider still displays a qualified identifier, puts the prompt description in the secondary label, and supplies no documentation tooltip. Keep this open: a maintainer proposed a concrete presentation improvement, and the current source does not deliver it.

## Change summary

Make MCP prompt slash-command suggestions easier to scan through shorter names, server attribution, and description tooltips.

## Best solution

Follow the maintainer's proposed hierarchy: prompt name as the primary label, server name as secondary text, and prompt description in the details tooltip. Resolve the remaining questions about MCP identification and argument indicators before treating the broader design as settled.
