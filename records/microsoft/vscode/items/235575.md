# Issue #235575 — "Do you want to terminate the active terminal session?" on close for background terminals

[https://github.com/microsoft/vscode/issues/235575](https://github.com/microsoft/vscode/issues/235575)

## Summary

Still reproduces on current main: background terminals created by extensions (e.g. Python/Jedi) trigger the confirmOnExit dialog despite two prior fix attempts (PRs #236588 and #240074). A MEMBER confirmed the issue persists as of Feb 2025, and no subsequent fix has landed. The `help wanted` label is appropriate.

## Change summary

Background terminals spawned by extensions (like the Python extension for Jedi) incorrectly trigger the 'Do you want to terminate the active terminal session?' confirmation dialog on window close.

## Best solution

The root cause is likely that the Python extension's terminal is not using `hideFromUser: true` in its `ShellLaunchConfig`, so it ends up in `_terminalGroupService.instances` rather than `_backgroundedTerminalInstances`. The fix should either ensure extension-created background terminals consistently use `hideFromUser`, or the `foregroundInstances` getter / confirmOnExit check should have an additional filter (e.g. checking if the terminal has no visible UI presence). The fix belongs in `src/vs/workbench/contrib/terminal/browser/terminalService.ts`.
