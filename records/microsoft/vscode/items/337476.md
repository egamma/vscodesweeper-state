# Issue #337476 — Modern UI abbreviates editor tabs instead of shrinking or line wrapping for `tabSizing: "shrink"` and `wrapTabs: true`

[https://github.com/microsoft/vscode/issues/337476](https://github.com/microsoft/vscode/issues/337476)

## Summary

Real, freshly-introduced regression: the default Modern UI Update's 'connected' editor-tab style adds per-tab minimum-width/ellipsis handling (`layoutConnectedTabLabels` in multiEditorTabsControl.ts) that appears to let tabs squeeze onto one row with heavier label abbreviation before `tabSizing: shrink` / `wrapTabs: true` kick in, matching the reporter's screenshots; worth tracking as the modern UI tabs work continues.

## Change summary

With `workbench.editor.tabSizing: shrink` and `workbench.editor.wrapTabs: true`, the new default Modern UI tab style abbreviates tab labels (heavy ellipsis, indistinguishable Untitled-X names) instead of shrinking tab width or wrapping to a second row like the old UI did.

## Best solution

Have the Modern UI editor-tabs work (multiEditorTabsControl.ts / editorTabsControl.ts, `connected-tab-narrow`/`layoutConnectedTabLabels` logic) honor `tabSizing`/`wrapTabs` the same way the classic UI did, so shrink/wrap still take effect before labels get abbreviated to indistinguishable names.

## Evidence

- **modern UI default:** `LayoutSettings.MODERN_UI` defaults to `true` and `MODERN_UI_EDITOR_TAB_STYLE` defaults to `Connected` in src/vs/workbench/browser/workbench.contribution.ts (lines ~833-855), matching the reporter's '1.139.0, modern UI became default' claim.
- **connected-tab narrowing logic:** src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts `layoutConnectedTabLabels()` (~line 2100) computes a minimum per-tab width sized to fit only the first grapheme of the name plus an ellipsis when the connected tab style is active, then marks tabs `connected-tab-narrow`; this only runs for the connected style (`hasModernUITabs`/`CONNECTED_EDITOR_TABS_CLASS` checks at editor.ts:32 and multiEditorTabsControl.ts:2502), so it's plausible this narrower per-tab sizing changes when `doLayoutTabsWrapping`'s shrink/wrap thresholds trigger versus the classic UI.
- **tabSizing default:** Default `tabSizing` is `'fit'` (src/vs/workbench/browser/parts/editor/editor.ts:44); the reporter's config (`shrink` + `wrapTabs: true`) is a non-default combination, so the impact is real but narrow to users of that specific setting pair.
