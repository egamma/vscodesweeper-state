# Issue #308015 — Add an "Ignored" tree in Source Control to review .gitignored affected files

[https://github.com/microsoft/vscode/issues/308015](https://github.com/microsoft/vscode/issues/308015)

## Summary

Keep open as a feature request: current Source Control does not provide an ignored-files section or an un-ignore action. Existing untracked-file settings do not cover the request, and no verified canonical issue was found.

## Change summary

Provide a Source Control section for reviewing existing Git-ignored files, with a context-menu action to un-ignore individual paths.

## Best solution

Consider an opt-in, on-demand ignored-files review surface in the built-in Git extension, keeping potentially large ignored directories out of routine status processing. Define un-ignore behavior for excluded parent directories and nested ignore rules before accepting the feature.
