# Issue #199141 — Double-click on scrollbar creates a new file, and it should not ...

[https://github.com/microsoft/vscode/issues/199141](https://github.com/microsoft/vscode/issues/199141)

## Summary

The bug remains present on current main and the reporter reconfirmed it on version 1.113.0. Keep it open while the existing human-authored fix in https://github.com/microsoft/vscode/pull/199334 is reviewed or revised.

## Change summary

Double-clicking or dragging the Explorer scrollbar can incorrectly invoke the New File action.

## Best solution

Review and land the targeted event-propagation fix in https://github.com/microsoft/vscode/pull/199334, ensuring both direct scrollbar double-clicks and the reported click-drag-release sequence cannot reach the Explorer's empty-space double-click handler.
