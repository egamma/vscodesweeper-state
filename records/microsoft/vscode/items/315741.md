# Issue #315741 — Add ability to specify reasoning effort for Gemini BYOK models

[https://github.com/microsoft/vscode/issues/315741](https://github.com/microsoft/vscode/issues/315741)

## Summary

Valid remaining work: reasoning effort support was implemented for other BYOK providers (#262187, closed as completed), but the Gemini native BYOK provider still hardcodes `thinkingConfig: { includeThoughts: true }` without a `thinkingBudget` parameter. The gap is real and this is the canonical issue for it.

## Change summary

Allow users to specify reasoning effort (thinking budget) for Gemini BYOK models, similar to what other BYOK providers already support.

## Best solution

Wire the reasoning effort picker value into the Gemini native provider's `thinkingConfig` as a `thinkingBudget` parameter in `extensions/copilot/src/extension/byok/vscode-node/geminiNativeProvider.ts`, and register the reasoning effort schema property for Gemini BYOK models in `byokContribution.ts` using `buildReasoningEffortSchemaProperty`. Issue #317642 is a duplicate of this one.
