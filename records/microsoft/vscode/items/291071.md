# Issue #291071 — Delete should be accessible on an individidual model level for Azure + Custom OAI

[https://github.com/microsoft/vscode/issues/291071](https://github.com/microsoft/vscode/issues/291071)

## Summary

The requested per-model deletion remains absent on current main. This team-authored feature request is accepted in the On Deck milestone, so it should remain open for language-model management work.

## Change summary

Allow users to delete one configured Azure or OpenAI-compatible model without deleting its entire provider group.

## Best solution

Expose a confirmed Delete action for individually configured model rows, removing only that model from its provider group's `models` array while preserving the group credentials, settings, and other models.
