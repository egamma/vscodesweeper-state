# Issue #102438 — No way for an extension to tell have vscode suggest .JSON when user saves file if it is not the main extension for json files

[https://github.com/microsoft/vscode/issues/102438](https://github.com/microsoft/vscode/issues/102438)

## Summary

The capability gap remains: language contributions cannot specify a suggested save extension independently of filename-to-language associations. Keep this accepted Backlog request open; the maintainer already suggested adding a separate contribution property.

## Change summary

Allow an extension-defined language to suggest .json when saving an untitled document without claiming ordinary .json files for that language.

## Best solution

Provide language-level save-name metadata that does not affect language detection, so the ordinary Save command can suggest .json for ARM templates while generic JSON files retain their existing language association.
