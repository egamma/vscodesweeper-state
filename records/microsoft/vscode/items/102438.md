# Issue #102438 — No way for an extension to tell have vscode suggest .JSON when user saves file if it is not the main extension for json files

[https://github.com/microsoft/vscode/issues/102438](https://github.com/microsoft/vscode/issues/102438)

## Summary

The extension API gap remains on current main: save-name suggestions still come exclusively from language file associations, so an extension cannot suggest `.json` without also claiming JSON files. This accepted Backlog request should remain open.

## Change summary

Allow a language contribution to specify its preferred save extension independently of extensions used for language detection.

## Best solution

Add an optional preferred filename or extension property to language contributions, retain it in the language registry, and use it before association extensions when suggesting names for untitled files. The property must not register a reverse filename-to-language association.
