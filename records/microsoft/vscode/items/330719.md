# Issue #330719 — Custom Title Bar does not render in fullscreen on macOS (1.133.0)

[https://github.com/microsoft/vscode/issues/330719](https://github.com/microsoft/vscode/issues/330719)

## Summary

A contributor already asked whether behavior actually changed and the reporter said yes but gave no configuration details; tracing `shouldShowCustomTitleBar`/`isTitleBarEmpty` on main shows macOS hides the custom title bar in fullscreen only when the title bar has no functional content (command center off, activity bar not top/bottom, editor actions not in the title bar, layout actions off) — and command center defaults to on, so this shouldn't reproduce with default settings. Needs the reporter's exact window/titlebar settings to verify.

## Change summary

Custom title bar (with folder/file name) stops rendering in fullscreen on macOS with customTitleBarVisibility: auto, and the View → Appearance → Custom Title Bar toggle appears to have no effect while fullscreen.

## Best solution

Get the reporter's `window.commandCenter`, `workbench.activityBar.location`, `workbench.editor.editorActionsLocation`/`editorTabsMode`, and `workbench.layoutControl.enabled` values; if command center (or another 'non-empty title bar' condition) is disabled, the reported behavior matches the intended macOS fullscreen rule in src/vs/workbench/services/layout/browser/layoutService.ts (isTitleBarEmpty + 'macOS desktop does not need a title bar when full screen'), and the toggle 'doing nothing' is explained because AUTO and NEVER compute to the same hidden result there — in which case this is as-designed. If those settings are non-empty and it still doesn't show, that would be a genuine regression worth deeper investigation.
