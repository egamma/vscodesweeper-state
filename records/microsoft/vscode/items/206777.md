# Issue #206777 — File nesting for enumeration of files with same basename

[https://github.com/microsoft/vscode/issues/206777](https://github.com/microsoft/vscode/issues/206777)

## Summary

A real capability gap remains: file nesting can group children only beneath an existing file, while this request needs a synthetic grouping node for numbered files sharing a prefix. The related shared-prefix request is younger than this re-reviewed issue, so it cannot serve as its duplicate canonical.

## Change summary

Allow Explorer file nesting to collect numbered files with a shared basename under a configurable virtual group.

## Best solution

Extend Explorer file nesting with an explicit virtual-group concept derived from a shared prefix or basename, without changing the filesystem or the behavior of existing real-file parent patterns. Product design should first settle how virtual nodes are named and configured.

## Evidence

- **current configuration limit:** src/vs/workbench/contrib/files/browser/files.contribution.ts documents explorer.fileNesting.patterns as parent-file patterns with a single wildcard; it exposes no syntax for declaring a synthetic group.
- **current implementation limit:** ExplorerFileNestingTrie.nest in src/vs/workbench/contrib/files/common/explorerFileNestingTrie.ts considers each real file as a potential parent and returns those files as root ancestors, so it cannot create the `solution_00000000.pvu` grouping node shown in the request when that file does not exist.
- **related younger issue:** https://github.com/microsoft/vscode/issues/207717 requests virtual shared-prefix groups for migration files and confirms existing file nesting cannot reduce the list sufficiently, but it was created on 2024-03-14, after this issue's 2024-03-04 creation date, and therefore cannot be the canonical duplicate for this re-reviewed item.
- **existing partial capability:** If an actual unnumbered `.pvu` parent exists, a pattern such as `*.pvu` with `${capture}_*.pvu` can nest the numbered files; it does not satisfy the example's central request to introduce an intermediate group absent from the original directory listing.
