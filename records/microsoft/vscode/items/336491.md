# Issue #336491 — Multi-diff editor word wrap action appears in different menu than the other options

[https://github.com/microsoft/vscode/issues/336491](https://github.com/microsoft/vscode/issues/336491)

## Summary

Team-authored bug filed today with no fix yet, so it stays open — traced in source to a real menu-registration inconsistency in the Agents window's multi-diff editor toolbar.

## Change summary

In the Agents window, the multi-diff editor's Word Wrap toggle is registered in a different menu than the Diff View (Inline/Side by Side/Automatic) options, so it visually appears in a separate place from the related layout controls.

## Best solution

Align the menu placement of ToggleSessionsDiffEditorWordWrapAction with the Diff View submenu registration in src/vs/sessions/contrib/changes/browser/changesViewActions.ts so both live in the same menu/group for the single-pane and multi-pane layouts; needs a UX call from the author on which menu (main toolbar vs. layout dropdown) is correct before implementing.
