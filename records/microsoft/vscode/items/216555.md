# Issue #216555 — Normalize let/const exports in vscode.d.ts

[https://github.com/microsoft/vscode/issues/216555](https://github.com/microsoft/vscode/issues/216555)

## Summary

The declaration inconsistency remains on current main, and the linked const-normalization PR was closed without merging. Keep this open for API-owner agreement on the public declaration shape, including the interface-based alternative raised in the discussion.

## Change summary

Make extension API declarations consistently express that VS Code-controlled namespace values cannot be assigned by extensions.

## Best solution

Ensure the public declarations reject assignments to VS Code-controlled values while preserving their changing runtime values and proposed-API augmentation. Settle whether this remains a namespace declaration cleanup or adopts the readonly-interface design discussed by the maintainer.
