# Issue #252832 — Diff:Switch sides does not announce which side is active to screen reader (JAWS)

[https://github.com/microsoft/vscode/issues/252832](https://github.com/microsoft/vscode/issues/252832)

## Summary

The current source still exposes the same accessible label on both sides of a standard file comparison, and Switch Side provides no additional side identification. Keep this open for a bounded accessibility fix; no verified canonical or landed fix was found.

## Change summary

Switching sides in a file comparison should identify the newly focused side to screen reader users.

## Best solution

Make the focused original or modified editor distinguishable to screen readers when Switch Side moves focus, while preserving file context and existing selection mapping. Window-title reordering is not necessary if the focused editor communicates the destination reliably.
