# Issue #308976 — Agents app - context convenience features from VS Code

[https://github.com/microsoft/vscode/issues/308976](https://github.com/microsoft/vscode/issues/308976)

## Summary

Keep open: symbol-reference paste remains unavailable in the Agents composer on current main. The paste architecture has changed since the report, but the current provider registration and composer adapter still leave this capability unwired.

## Change summary

Copying a code symbol and pasting it into the Agents chat input should add symbol context, as it does in the regular VS Code chat input.

## Best solution

Support symbol-reference paste through the Agents composer's existing attachment and reference lifecycle, including outgoing context and undo/redo. Preserve regular chat behavior and account for source editors being disposed before paste.
