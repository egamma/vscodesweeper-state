# Issue #345834 — Linux Wayland: Neo2 Mod4 key (ISO_Level5_Shift on Right Alt) opens menu bar

[https://github.com/microsoft/vscode/issues/345834](https://github.com/microsoft/vscode/issues/345834)

## Summary

Keep open for the Chromium Wayland modifier fix. The maintainer confirms the upstream cause; disabling Alt menu focus is a workaround, not correct recognition of Neo2's Level5 modifier.

## Change summary

Neo2's Right Alt Level5 modifier incorrectly focuses the menu bar when pressed and released under native Wayland.

## Best solution

Chromium should preserve ISO_Level5_Shift rather than report it as Alt, and VS Code should adopt the corrected behavior through Electron. Preserve ordinary Alt menu navigation and track this separately from layout-dependent shortcut translation.
