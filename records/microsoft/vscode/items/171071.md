# Issue #171071 — Move the vertical ruler (the column limit) correctly when the inlay hints are used.

[https://github.com/microsoft/vscode/issues/171071](https://github.com/microsoft/vscode/issues/171071)

## Summary

The requested source-column-aware ruler remains missing on current main. Keep this accepted editor feature request open for a presentation decision; existing settings do not let users retain both hints and an accurate source-column ruler.

## Change summary

Make column-limit rulers account for the visual width of inlay hints without counting hints as source text.

## Best solution

Provide a ruler presentation that accurately marks source-column limits while inlay hints remain visible. The editor owner should settle the presentation and compatibility behavior before implementation across DOM and GPU rendering.
