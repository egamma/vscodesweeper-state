# Issue #335663 — Markdown: escaped `\$` opens an inline math span and hides highlighting until the next `$`

[https://github.com/microsoft/vscode/issues/335663](https://github.com/microsoft/vscode/issues/335663)

## Summary

Confirmed on current main: the math_inline_single/double regexes in the markdown-math grammar only reject a preceding literal `$`, not an escaped `\$`, so an escaped dollar sign wrongly opens an inline math span and breaks subsequent highlighting. An open PR (#335664) already targets this exact fix, so the issue should stay open pending review/merge rather than being closed or auto-fixed now.

## Change summary

An escaped `\$` in a Markdown file is misinterpreted as opening an inline math span, causing surrounding syntax (e.g. code spans) to lose highlighting until the next `$`.

## Best solution

Land the fix in the linked PR https://github.com/microsoft/vscode/pull/335664, which adjusts the `math_inline_single`/`math_inline_double` lookbehind in extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json to also exclude an escaped `\$` as an opener.
