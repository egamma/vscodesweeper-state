# Issue #335663 — Markdown: escaped `\$` opens an inline math span and hides highlighting until the next `$`

[https://github.com/microsoft/vscode/issues/335663](https://github.com/microsoft/vscode/issues/335663)

## Summary

Confirmed source bug: the math_inline_single/double regex lookbehind `(?<!\$)` only rejects a preceding `$`, not a preceding backslash, so an escaped `\$` is wrongly treated as a math opener and suppresses highlighting until the next `$`. An open PR (#335664) already proposes the fix, so this should stay open pending that merge rather than be closed now.

## Change summary

In plain Markdown files, an escaped `\$` is mis-tokenized as opening an inline math span, causing subsequent code spans to lose syntax highlighting until the next `$`.

## Best solution

Land the fix in https://github.com/microsoft/vscode/pull/335664 (or an equivalent regex fix to reject a preceding backslash) in extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json, covering both the single- and double-dollar rules.
