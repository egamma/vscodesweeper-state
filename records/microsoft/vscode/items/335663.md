The escaped-dollar highlighting defect remains in the current grammar. Keep this open while the directly linked fixing PR is reviewed; it has not merged.

## Change summary

Escaped dollar signs incorrectly delimit inline Markdown math, suppressing highlighting of enclosed code spans.

## Evidence

- **Current source confirms the trigger:** In extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json, math_inline_single and math_inline_double still use the opener lookbehinds (?<=\s|\W|^)(?<!\$). A preceding backslash satisfies \W and is not excluded, so the reported paragraph matches from its first escaped dollar sign to the second and assigns markup.math.inline.markdown over both `admin` spans.
- **Built-in editor highlighting path:** extensions/markdown-math/package.json injects markdown.math.inline into text.html.markdown. The injection targets meta.paragraph.markdown; the base grammar's escape rule in extensions/markdown-basics/syntaxes/markdown.tmLanguage.json does not consume \$. This is a built-in TextMate highlighting defect, not an external extension or preview-renderer problem. Verification was source-only; no code or tests were executed.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/335664 is verified OPEN and explicitly says Fixes #335663. It changes both affected opener patterns and includes colorization fixtures/results. Its description reports 109 passing colorization tests, but also acknowledges rejecting \\$ as an opener; that limitation deserves review before landing.
- **Related reports do not own the same symptom:** The commenter linked https://github.com/microsoft/vscode/issues/223545 and https://github.com/microsoft/vscode/pull/304800; both concern multiline single-dollar math highlighting, not escaped-dollar openers. https://github.com/microsoft/vscode/issues/334935 concerns dollar signs disappearing or rendering as math in the WYSIWYG Markdown Editor, whose rendering path is distinct. An open-issue search for escaped math found no verified older canonical covering this exact source-editor symptom.
