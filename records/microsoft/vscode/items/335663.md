# Issue #335663 — Markdown: escaped `\$` opens an inline math span and hides highlighting until the next `$`

[https://github.com/microsoft/vscode/issues/335663](https://github.com/microsoft/vscode/issues/335663)

## Summary

Confirmed defect in the markdown-math grammar: the lookbehind `(?<!\$)` only excludes a preceding `$`, not an escaping backslash, so `\$` is treated as an unescaped math opener and everything up to the next `$` (including code spans like `` `admin` ``) loses its normal tokenization. An open PR already targets this fix, so the issue should stay open for that PR to land rather than being closed now.

## Change summary

Escaped `\$` in a Markdown file is incorrectly treated as an inline-math delimiter, suppressing syntax highlighting (e.g. of code spans) until the next `$`.

## Best solution

Land https://github.com/microsoft/vscode/pull/335664, which reportedly fixes the `math_inline_single`/`math_inline_double` regexes in extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json to treat a backslash-escaped `\$` as non-opening; verify it covers both the single and double-dollar variants noted in the report.
