# Issue #297149 — Signed out user model picker drop down

[https://github.com/microsoft/vscode/issues/297149](https://github.com/microsoft/vscode/issues/297149)

## Summary

Team-authored feature request (hard keep-open). The model picker now has a Sign In prompt for signed-out users, but the latest discussion (comment 6) asks for showing Free-tier models alongside the Sign In action — that richer dropdown experience has not been implemented yet.

## Change summary

Improve the model picker dropdown for signed-out users to show Free-tier models with a Sign In link instead of an abbreviated dropdown.

## Best solution

Extend `buildModelPickerItems` in `chatModelPicker.ts` so the `setupRequired` branch also renders the featured/Free-tier models (disabled, with a Sign In link invoking `workbench.actions.accounts.signIn`) rather than only showing a bare Sign In action. This matches the discussion consensus in comment 6 and aligns with the existing upgrade-link pattern for Free/EDU users.
