# Issue #335928 — permissions.disableBypassPermissionsMode "allow-auto-only" incorrectly enables "Allow all" in Local and Copilot harnesses in VSCode

[https://github.com/microsoft/vscode/issues/335928](https://github.com/microsoft/vscode/issues/335928)

## Summary

Maintainer (rwoll) has confirmed the defect, proposed a concrete design (new `disableAssistedPermissionsMode`/`defaultMode` keys), and reports the underlying implementation is now underway upstream — this stays open and tracks that work.

## Change summary

Setting `permissions.disableBypassPermissionsMode` to `allow-auto-only` incorrectly still allows selecting 'Allow All' in the Local and Copilot harnesses instead of restricting to Assisted Permissions only.

## Best solution

Land the proposed `permissions.disableAssistedPermissionsMode` and `permissions.defaultMode` managed-settings keys (per rwoll's comment) once the required capability ships in the Copilot SDK VS Code depends on, then verify consistent behavior across Local/Copilot harnesses and with `permissions.ask/deny/allow` rules.
