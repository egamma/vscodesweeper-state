# Issue #335928 — permissions.disableBypassPermissionsMode "allow-auto-only" incorrectly enables "Allow all" in Local and Copilot harnesses in VSCode

[https://github.com/microsoft/vscode/issues/335928](https://github.com/microsoft/vscode/issues/335928)

## Summary

A maintainer (rwoll) has already engaged, confirmed the gap, and proposed a concrete redesign (new disableAssistedPermissionsMode and defaultMode keys) which the reporter accepted; the project has chosen a direction and is actively implementing it, so this stays open rather than closed on any judgment basis.

## Change summary

Setting permissions.disableBypassPermissionsMode to the documented allow-auto-only value doesn't correctly restrict to assisted-permissions mode — VS Code's local harness still lets users pick Allow All, and the Copilot harness visually allows it but errors at runtime.

## Best solution

Land the new permissions.disableAssistedPermissionsMode and permissions.defaultMode managed-settings keys (per rwoll's 2026-09-24 proposal) across all Copilot harnesses in src/vs/platform/agentHost/common/agentHostManagedSettings.ts, which only supports disableBypassPermissionsMode: 'disable' today with no allow-auto-only or assisted-mode distinction.
