# Issue #84072 — Allow viewing and editing commands with 'args' in the keybindings editor

[https://github.com/microsoft/vscode/issues/84072](https://github.com/microsoft/vscode/issues/84072)

## Summary

Still valid: the keybindings editor on current main has no support for displaying or editing command `args`. The feature remains unimplemented and has meaningful community support (11 upvotes, multiple corroborating comments from members and contributors).

## Change summary

Allow viewing, editing, and creating keybindings with command `args` in the GUI keybindings editor.

## Best solution

Extend the keybindings editor (src/vs/workbench/contrib/preferences/browser/keybindingsEditor.ts and its model) to surface command arguments — display them in a column or expandable detail, and provide inline editing UX (similar to the settings editor's object/array editing). This would help discoverability of parameterized commands like `editor.action.codeAction` with specific `kind` args.
