# Issue #339780 — Automation changes in Chat shouldn't include an icon if already has one?

[https://github.com/microsoft/vscode/issues/339780](https://github.com/microsoft/vscode/issues/339780)

## Summary

Confirmed in source: the tool-invocation row always renders a leading generic activity icon, and ChatAutomationConfiguredResultSubPart additionally draws its own calendar icon on the button, producing the two icons shown in the screenshot.

## Change summary

When an automation is created/edited via chat, the result row shows both the generic tool-row icon and the automation button's own calendar icon.

## Best solution

Suppress the row-level `.chat-tool-call-icon` (or skip setting `button.icon`) when the subpart is ChatAutomationConfiguredResultSubPart (and likely ChatSessionCreatedResultSubPart, which shares `.chat-open-session-result`), so only one icon is shown per row.
