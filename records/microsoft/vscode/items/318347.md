# Issue #318347 — chat.tools.terminal.autoApprove (and related terminal tool auto-approval) does not match inner commands when the command line uses common wrappers (timeout, bash -c, env, sudo time, etc.)

[https://github.com/microsoft/vscode/issues/318347](https://github.com/microsoft/vscode/issues/318347)

## Summary

Keep open for security-sensitive maintainer review: the independently confirmed wrapper-parsing gap can bypass explicit inner-command deny rules, not merely require extra confirmations. Current source remains consistent with that report, and the existing terminal-auto-approve routing is appropriate.

## Change summary

Terminal auto-approval fails to evaluate effective commands inside common wrappers, missing both granular allow rules and explicit denials.

## Best solution

Establish security-reviewed wrapper-aware approval semantics that preserve argument boundaries, honor inner-command denials, and require confirmation when interpretation is ambiguous. Preserve exact-command-line behavior and distinguish approval-suggestion filtering from enforcement.
