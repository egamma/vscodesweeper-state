# Issue #324335 — GitHub Copilot "Response Contained No Choices" Using BYOK - Ollama, OpenRouter.ai

[https://github.com/microsoft/vscode/issues/324335](https://github.com/microsoft/vscode/issues/324335)

## Summary

Keep open: the supplied Ollama capture follows a current-source path that reports “Response contained no choices” despite receiving assistant text. The OpenRouter capture exposes a separate provider-error handling gap, and the merged Agent Host diagnostics PR does not resolve these extension-side failures.

## Change summary

Handle interrupted and failed BYOK streams without misreporting received assistant content as a response containing no choices.

## Best solution

Distinguish incomplete streams, explicit provider errors, and genuinely empty replies in the Copilot BYOK response pipeline. Establish how partial responses should be presented, then validate the captured Ollama and OpenRouter failure shapes without changing successful usage-only chunk handling.

- **Trace:**

  > The Ollama attachment ends after content deltas without a finish_reason or [DONE]. The remaining uncertainty is the intended presentation and recovery contract for already-streamed text when the endpoint never completes the response.
- **Open decisions:**
