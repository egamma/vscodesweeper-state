# Issue #331580 — `cancelSelection` interferes with extension API `registerCommand("type")`

[https://github.com/microsoft/vscode/issues/331580](https://github.com/microsoft/vscode/issues/331580)

## Summary

The source exposes a plausible editor input-state synchronization problem, not evidence that Vimspired is responsible. Ask for confirmation on the latest build and an EditContext comparison before deciding whether the defect remains.

## Change summary

Canceling a forward single-line selection through an overridden type command causes subsequent intercepted keystrokes to modify text instead of executing navigation commands.

## Best solution

Preserve ordinary type-command interception after selection cancellation, with the native input buffer synchronized to the unchanged editor text. First confirm whether the reported sequence still fails and whether disabling editor.editContext isolates the native input path.
