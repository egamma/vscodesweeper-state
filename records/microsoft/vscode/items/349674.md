- **Behavior:**

  > After Gemini CLI displays a response, narrowing the Explorer sidebar must leave previously scrollable terminal output accessible. Wheel scrolling and scrollbar dragging should continue working after the layout settles. Verify ordinary shell scrollback remains unchanged and distinguish inaccessible history from a terminal or window hang.
- **Trace:**

  > TerminalInstance.layout evaluates dimensions and invokes _resize, which calls TerminalResizeDebouncer.resize. The debouncer applies immediate resizing for small normal buffers and otherwise delays column changes by 100 ms; TerminalInstance callbacks resize xterm and synchronize PTY dimensions. XtermTerminal.resize delegates directly to raw.resize. Source inspection establishes the relevant path but not whether Gemini redraws, terminal mouse modes, xterm reflow, or rendering cause the failure. https://github.com/microsoft/vscode/issues/340786 is a vertical-resize investigation, not a verified duplicate. Start with the supplied reproduction and preserve existing buffer, mouse-input, and normal scrolling semantics.
