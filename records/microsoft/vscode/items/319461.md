## Change summary

Error notification popups appear repeatedly while searching for plugins in the Agents Customizations marketplace view when enterprise-managed settings are enabled.

## Best solution

The marketplace fetch path in `pluginSources.ts` shows error notifications via `INotificationService` on clone/update failures, and these can fire on every debounced search keystroke via `queryMarketplace()` → `fetchMarketplacePlugins()` → `_fetchFromClonedRepo()` → `ensureRepository()`. The fix should either suppress repeated error notifications during marketplace browsing, or the `queryMarketplace` catch block in `pluginListWidget.ts` should prevent the underlying source operations from surfacing notifications during passive browsing. The area owners should confirm the exact managed-settings configuration that triggers this.
