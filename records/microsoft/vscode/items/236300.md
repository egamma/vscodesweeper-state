# Issue #236300 — CTRL+A randomly breaks in Jupyter notebooks

[https://github.com/microsoft/vscode/issues/236300](https://github.com/microsoft/vscode/issues/236300)

## Summary

Still reproduces on main: the `NOTEBOOK_OUTPUT_FOCUSED` context key gets stuck after right-clicking on a notebook output cell, causing Ctrl+A to dispatch `notebook.cell.output.selectAll` instead of the editor's select-all. No fix has been committed. The issue has 99 upvotes and clear reproduction steps.

## Change summary

Ctrl+A stops working in Jupyter notebook cells after right-clicking on an output cell, because the output-focused context key is not properly cleared.

## Best solution

Fix the `NOTEBOOK_OUTPUT_FOCUSED` context key lifecycle in `notebookEditorWidget.ts` so it is properly cleared when focus returns to a cell editor after a context menu interaction on the output webview. The webview blur handler (line ~1407) or `updateCellFocusMode` should ensure the context key is reset when focus transitions away from the output. @Yoyokrazy acknowledged this in comment 21 and identified the root cause.
