# Issue #300208 — Missing raw chat response stream from websocket

[https://github.com/microsoft/vscode/issues/300208](https://github.com/microsoft/vscode/issues/300208)

## Summary

Team-authored issue; the gap is confirmed in current source — the WebSocket response path in chatWebSocketManager.ts does not log raw stream chunks to the Copilot Chat output channel, unlike the HTTP SSE path (stream.ts, where even the SSE logging is commented out at line 328). Still needs a fix.

## Change summary

Raw chat response stream chunks are not logged to the Copilot Chat output channel when using WebSocket-based models (e.g. gpt-5.3-codex), making troubleshooting harder.

## Best solution

Add raw response stream logging in the WebSocket message handler in `extensions/copilot/src/platform/networking/node/chatWebSocketManager.ts` to match what the SSE/HTTP path was expected to provide, writing chunks to the Copilot Chat output channel at a debug/trace level.
