# Issue #300208 — Missing raw chat response stream from websocket

[https://github.com/microsoft/vscode/issues/300208](https://github.com/microsoft/vscode/issues/300208)

## Summary

The diagnostic gap remains on current main: WebSocket response frames are parsed and dispatched without being written to the Copilot Chat log. This team-authored issue should stay open as a bounded logging-parity bug.

## Change summary

Raw response frames received through the Copilot Chat WebSocket transport are missing from the GitHub Copilot Chat output channel.
