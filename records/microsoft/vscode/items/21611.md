# Issue #21611 — Add option to always show word based suggestions

[https://github.com/microsoft/vscode/issues/21611](https://github.com/microsoft/vscode/issues/21611)

## Summary

A real capability gap remains on current main: word-based completions are still skipped whenever a higher-scored provider returns items. This Backlog request has 80 community upvotes and should remain open.

## Change summary

Add an option to mix word-based completions with suggestions from language-specific completion providers.

## Best solution

Add an editor setting that optionally queries and merges the wildcard word-based provider with higher-scored providers, with suitable deduplication and ordering. The implementation belongs in the editor suggestion pipeline and should preserve the current behavior by default.
