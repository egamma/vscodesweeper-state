# Issue #21611 — Add option to always show word based suggestions

[https://github.com/microsoft/vscode/issues/21611](https://github.com/microsoft/vscode/issues/21611)

## Summary

The requested option remains missing: current suggestion collection still stops when a higher-scoring provider returns items, excluding word-based suggestions. Keep this accepted Backlog request open; its 80 upvotes and cross-language examples support a maintainer-led design session.

## Change summary

Allow users to show word-based suggestions alongside language-provider completions, rather than only as a fallback.

## Best solution

Provide an opt-in way to combine word-based and semantic suggestions while preserving the existing default behavior. Settle how duplicate entries and ranking should behave before implementation.
