# Issue #291418 — Mermaid file URIs are not unique on reload

[https://github.com/microsoft/vscode/issues/291418](https://github.com/microsoft/vscode/issues/291418)

## Summary

Keep open: current source persists template-added whitespace as Mermaid source, so restoring a preview computes a different identity from reopening the original diagram. This explains the reported duplicate tab after reload; the existing mermaid routing is appropriate.

## Change summary

Reopening the same chat Mermaid diagram after a window reload creates another editor tab instead of revealing the restored preview.

## Best solution

Preserve the diagram's identity across preview serialization and restoration so opening it from chat reveals the existing tab. Keep diagram content and unrelated pan/zoom behavior unchanged.
