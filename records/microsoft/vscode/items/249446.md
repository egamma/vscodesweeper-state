# Issue #249446 — Multiple remote connections fail after VSCode update

[https://github.com/microsoft/vscode/issues/249446](https://github.com/microsoft/vscode/issues/249446)

## Summary

The logs confirm a Remote - SSH race during concurrent server installation on Windows. Remote - SSH is maintained in microsoft/vscode-remote-release, so this should remain open and be transferred there.

## Change summary

Opening multiple Remote - SSH windows after an update can make concurrent server downloads collide on the same temporary directory and prevent connections.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release and make Remote - SSH coordinate concurrent downloads and installations, ideally by sharing completed work or locking the complete operation rather than allowing windows to race on a timestamp-derived directory.
