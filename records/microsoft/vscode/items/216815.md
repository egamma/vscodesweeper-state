## Summary

Valid feature request — the Git extension already tracks slow git status via telemetry (`statusSlow` event in repository.ts) but does not surface a recommendation to the user to run `git gc`. No implementation exists on current main.

## Change summary

Detect when git operations are slow and recommend that users run `git gc` to improve performance.

## Best solution

Extend the existing slow-status detection in `extensions/git/src/repository.ts` (around the `statusSlow` telemetry path) to show a notification suggesting `git gc` when git operations consistently exceed a threshold. The notification could include a button to run `git gc` directly. This is a self-contained enhancement within the built-in git extension.
