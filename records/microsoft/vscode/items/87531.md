## Summary

Current source supports HTML disclosure elements through MarkdownString.supportHtml, so the original limitation may already be addressed. However, working expansion inside extension tooltips and a qualifying implementation commit have not been established; no verified older duplicate owns this request.

## Change summary

Allow extension-authored tooltips to contain independently collapsible sections with formatted content.
