# Issue #87531 — [Feature Request] Create collapsed and expanded elements in tooltips

[https://github.com/microsoft/vscode/issues/87531](https://github.com/microsoft/vscode/issues/87531)

## Summary

The central request is implemented: extension-provided MarkdownString tooltips can contain expandable <details>/<summary> sections when supportHtml is enabled. Arbitrary JavaScript and unrestricted CSS remain outside that supported capability.

## Change summary

Allow extension authors to include expandable and collapsible formatted sections in tooltips.

## Best solution

Use MarkdownString.supportHtml with <details>/<summary> for optional tooltip content and close this request as completed by commit 2a4fb40a6e92b5ff024a3b32ba91d3ced2677a34; retain the existing sanitization restrictions.
