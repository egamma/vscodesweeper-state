# Issue #87531 — [Feature Request] Create collapsed and expanded elements in tooltips

[https://github.com/microsoft/vscode/issues/87531](https://github.com/microsoft/vscode/issues/87531)

## Summary

The requested capability — collapsible/expandable elements in extension-authored tooltips — is now supported. Extensions can use `MarkdownString` with `supportHtml: true` and `<details>`/`<summary>` HTML tags to create collapsible content in hovers and tooltips.

## Change summary

Request for collapsible/expandable elements in extension API tooltips.

## Best solution

No further change needed. The capability ships today: extensions set `supportHtml: true` on their `MarkdownString` and use `<details><summary>Title</summary>Content</details>` HTML. The allowed-tags list includes both `details` and `summary`.

- **Proposed comment:**

  > Thanks for the suggestion! This is now supported in VS Code. Extensions can create collapsible/expandable content in tooltips by setting `supportHtml: true` on a `MarkdownString` and using the HTML `<details>` and `<summary>` tags:
  > 
  > ```ts
  > const md = new vscode.MarkdownString('', true);
  > md.supportHtml = true;
  > md.appendMarkdown('<details><summary>Click to expand</summary>\n\nHidden content here\n\n</details>');
  > ```
  > 
  > This has been available since VS Code 1.73+ (the `supportHtml` property was finalized in 1.62, and `<details>`/`<summary>` tags were added to the allowed HTML subset shortly after). Closing as the capability now exists — please open a new issue if something specific isn't working as expected.
