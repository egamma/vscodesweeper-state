# Issue #208289 — MultiProvider is not supported for registerDebugConfigurationProvider Dynamic

[https://github.com/microsoft/vscode/issues/208289](https://github.com/microsoft/vscode/issues/208289)

## Summary

The defect remains on current main: dynamic configuration lookup selects only the first provider for a debug type, contrary to the extension API contract allowing multiple providers for the same type.

## Change summary

Allow every dynamically triggered DebugConfigurationProvider registered for one debug type to contribute configurations.

## Best solution

Aggregate configurations from all matching dynamic providers in ConfigurationManager, including the picker and restoration path, while preserving existing behavior for initial providers and configuration resolvers.
