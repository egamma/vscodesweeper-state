# Issue #112730 — Offer to open a workspace from empty explorer

[https://github.com/microsoft/vscode/issues/112730](https://github.com/microsoft/vscode/issues/112730)

## Summary

Still a valid, unimplemented feature request. The empty explorer welcome view still renders individual buttons with no dropdown/split-button support. The welcome view markdown infrastructure does not support multi-command buttons. On Deck milestone with low upvotes but active design discussion from team members — keeping open.

## Change summary

Add a split/dropdown button to the empty explorer view so users can access 'Open Workspace' alongside 'Open Folder' without cluttering the UI with additional buttons.

## Best solution

Extend the welcome view markdown rendering infrastructure to support split/dropdown buttons (e.g. via a `commands:ID1,ID2` syntax or submenu reference as discussed in the thread), then update the empty explorer welcome content in `src/vs/workbench/contrib/files/browser/explorerViewlet.ts` to use it. This would also benefit extensions contributing to welcome views. The implementation requires changes in the view welcome content renderer and the explorer viewlet registration.
