# Issue #114614 — Can't update the collapse state in the references-viewlet

[https://github.com/microsoft/vscode/issues/114614](https://github.com/microsoft/vscode/issues/114614)

## Summary

A concrete references-view API gap remains on current main: consumers cannot reset preserved expansion state. This team-authored API request should remain open under discussion.

## Change summary

Allow references-view API consumers to reset a tree and apply fresh item collapse states when replacing its input.

## Best solution

Add an explicit reset mechanism to the references-view API, or the underlying TreeView API, while preserving expansion state by default. The API should avoid requiring a temporary empty provider or disposal of the shared view.
