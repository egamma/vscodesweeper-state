# Issue #257430 — Text selection highlighting in jupyter notebook with the Solarized Light theme is hardly visible

[https://github.com/microsoft/vscode/issues/257430](https://github.com/microsoft/vscode/issues/257430)

## Summary

Still reproduces on main: the Solarized Light theme's `editor.selectionBackground` (#EEE8D5) is too close to `notebook.cellEditorBackground` (#F7F0E0), making text selection nearly invisible in notebook cells. A team member acknowledged the issue and the prior fix (#137085) only addressed the cell background, not the selection contrast itself.

## Change summary

Text selection highlighting in Jupyter notebooks with the Solarized Light theme has insufficient contrast against the notebook cell editor background.

## Best solution

Adjust `editor.selectionBackground` in `extensions/theme-solarized-light/themes/solarized-light-color-theme.json` to a color with stronger contrast against the notebook cell editor background (#F7F0E0), or add a dedicated `notebook`-scoped selection override. A designer review of the Solarized palette would ensure the new value stays on-brand.
