## Summary

This is the same Chromium/Electron os_crypt keyring-detection problem already tracked by the open, well-diagnosed canonical issue, which even has a KDE/kwallet-specific comment thread — consolidating there rather than tracking a fresh KDE-only report.

## Change summary

On Kubuntu 26.04 (KDE), VS Code shows the 'kwallet running' keyring warning and falls back to unencrypted secret storage even though kwalletd is confirmed open, for every --password-store value tried.
