Keep this team-authored tracking issue open: the folded-section control supports Run and a spinning execution indicator, but still lacks the requested Stop action. Tracking artifacts are protected from closure, and the current source confirms meaningful work remains.

Extend the notebook folded-section execution control to support stopping execution alongside Run and its running indicator.
