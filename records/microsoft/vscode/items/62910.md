# Issue #62910 — emmet.includeLanguages for one to many mapping

[https://github.com/microsoft/vscode/issues/62910](https://github.com/microsoft/vscode/issues/62910)

## Summary

Still unimplemented on main: `emmet.includeLanguages` only accepts string values (one-to-one mapping). The feature has community interest (15 upvotes) and is labeled `help wanted` on the On Deck milestone — keep open for a community PR.

## Change summary

Allow `emmet.includeLanguages` to map a single language to multiple Emmet syntaxes (e.g. HTML + CSS in the same file type).

## Best solution

Accept an array value in `emmet.includeLanguages` and update `getMappingForIncludedLanguages` in `extensions/emmet/src/util.ts` plus the completion provider and expand command to resolve the correct syntax at the cursor position (leveraging embedded-region detection for HTML-family languages). The hard part is cursor-position scoping for arbitrary grammars — the tractable first step is HTML-family region detection as noted in the latest comment.
