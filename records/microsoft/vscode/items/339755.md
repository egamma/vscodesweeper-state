# Issue #339755 — Git: staging a file with unsaved edits silently stages stale on-disk content (commit/stash already prompt to save)

[https://github.com/microsoft/vscode/issues/339755](https://github.com/microsoft/vscode/issues/339755)

## Summary

Confirmed on current main: the stage command path (git.stage/stageAll/stageAllTracked/stageAllUntracked/stageFile, all funneling into repository.add) has no dirty-document save prompt, unlike commit (git.promptToSaveFilesBeforeCommit) and stash (git.promptToSaveFilesBeforeStash). This is a real, well-diagnosed inconsistency worth fixing.

## Change summary

Staging a file with unsaved editor changes silently runs `git add` against the stale on-disk content, with no save prompt (unlike commit/stash).

## Best solution

Factor the existing dirty-document save prompt (used by smartCommit and the stash command) into a shared helper, add a `git.promptToSaveFilesBeforeStage` setting (always|staged|never, default always) mirroring promptToSaveFilesBeforeCommit, and call it from the stage entry points in extensions/git/src/commands.ts.
