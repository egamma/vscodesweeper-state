## Change summary

Explore using the multi-diff editor to preview a logical workspace edit spanning multiple files.

## Best solution

Define and prototype a workspace-edit preview backed by the multi-diff editor, preserving per-file review and accept/reject behavior while removing the intermediate list-to-individual-diff workflow. A maintainer should first settle whether this replaces the existing preview universally or is introduced for selected workspace-edit producers.
