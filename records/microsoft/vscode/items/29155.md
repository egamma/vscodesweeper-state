# Issue #29155 — [folding] Allow to show amount of lines folded

[https://github.com/microsoft/vscode/issues/29155](https://github.com/microsoft/vscode/issues/29155)

## Summary

Keep this older Backlog request open: current main still renders only a static ellipsis for collapsed ranges, while the later, strongly supported https://github.com/microsoft/vscode/issues/130250 requests the same observable behavior and is younger, so it cannot serve as this re-reviewed item's canonical.

## Change summary

Show how many lines are hidden by each folded editor range.

## Best solution

Design a compact, accessible folded-range placeholder in editor core that communicates the hidden range size while remaining visually secondary to the source text. A maintainer should first settle whether it reports physical lines or language-aware items and whether the richer placeholder is always enabled or configurable.
