# Issue #188636 — Support 'smart' automatic markdown link pasting for external image links

[https://github.com/microsoft/vscode/issues/188636](https://github.com/microsoft/vscode/issues/188636)

## Summary

Smart paste handling now includes external image resources, rather than applying only to pasted URL text. The implementation and the later comment reporting that it works support closing this request as completed.

## Change summary

Apply context-sensitive Markdown link pasting to image links and resources outside the workspace.

## Best solution

Keep the shared smart-paste handling introduced in commit e5f5e91423b52dd9501f7244ea2f5e555c5cc8b2, which evaluates the insertion context for both image resources and URI lists.
