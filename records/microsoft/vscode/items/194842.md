## Summary

Still valid: the Execute Cell button is hidden via `executeCondition` (requires kernel count > 0) during notebook load/kernel detection. No commit references this issue and the condition logic is unchanged on main.

## Change summary

Show the Execute Cell button (possibly disabled) during notebook kernel detection instead of hiding it entirely.

## Best solution

Decouple the Execute Cell button visibility from kernel availability — show the button always (or after a short delay) and either disable it or trigger the kernel selector on click when no kernel is ready yet. The fix lives in `src/vs/workbench/contrib/notebook/browser/controller/executeActions.ts` around the `executeCondition` and potentially the cell toolbar rendering logic.
