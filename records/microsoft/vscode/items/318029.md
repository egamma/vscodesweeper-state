# Issue #318029 — Setup gets stuck due to dllhost.exe blocking inno_updater.exe from finishing cleanup

[https://github.com/microsoft/vscode/issues/318029](https://github.com/microsoft/vscode/issues/318029)

## Summary

Keep open: current installer source retains the PowerShell command construction that produced the reported parser failure, then waits for cleanup despite unsuccessful surrogate termination. The report supplies an exact deployment command, diagnostic logs, and confirmation beyond the original deployment.

## Change summary

Windows setup fails to release the context-menu DLL before removing an older installation directory, blocking installer completion.

## Best solution

Make the installer's targeted context-menu surrogate cleanup work through the actual Windows process-launch boundary so versioned-directory cleanup completes. Preserve unrelated COM surrogate processes and avoid reintroducing cleanup during routine update checks.
