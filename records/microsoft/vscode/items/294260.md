The requested cleanup is still necessary: UnifiedQuickAccess continues to inject its tab bar directly into QuickPick-owned DOM, and the core picker contract has no tab data or selection event. Keep this maintainer-authored debt issue open; no verified fix or canonical duplicate was found.

## Change summary

Replace command-center tab DOM injection with component-owned rendering driven by a core QuickPick data and event contract.

## Best solution
