# Issue #347582 — Agent customizations synchronization through Settings Sync

[https://github.com/microsoft/vscode/issues/347582](https://github.com/microsoft/vscode/issues/347582)

## Summary

Settings Sync already supports some agent customization files, but its coverage is narrower than this request and profile export omits them. Keep open to define the remaining synchronization and profile-portability scope.

## Change summary

Synchronize agent customizations across devices and include them in portable VS Code profiles.

## Best solution

Build on the existing Prompts sync resource rather than introduce a redundant one, defining which additional user-level customizations and profile resources should travel between devices. Preserve the distinction between personal customizations and workspace-owned files.

  > Thanks for the request. Settings Sync already offers “Prompts and Instructions” under “Settings Sync: Configure” (`workbench.userDataSync.actions.configure`), including custom agent files stored in the profile's prompts folder. That does not cover all personal customization locations, skill directories, or profile export, so the broader portability request remains useful. The skills-specific request is also tracked in https://github.com/microsoft/vscode/issues/296414.

## Evidence

- **Existing capability:** src/vs/platform/userDataSync/common/userDataSync.ts already defines SyncResource.Prompts. src/vs/workbench/contrib/userDataSync/browser/userDataSync.ts exposes it through workbench.userDataSync.actions.configure, labeled 'Prompts and Instructions' in src/vs/workbench/services/userDataSync/common/userDataSync.ts. UserDataSyncEnablementService defaults this resource to disabled.
- **Incomplete synchronization coverage:** PromptsSynchronizer.getPromptsFileContents in src/vs/platform/userDataSync/common/promptsSync/promptsSync.ts:504-527 reads only immediate children of profile.promptsHome ending in .prompt.md, .instructions.md, .chatmode.md, or .agent.md. It does not collect skill directories or the additional personal customization locations recognized by src/vs/workbench/contrib/chat/common/promptSyntax/config/promptFileLocations.ts.
- **Profile portability gap:** Profiles already have promptsHome, but applyProfileTemplate in src/vs/workbench/services/userDataProfile/browser/userDataProfileImportExportService.ts handles settings, keybindings, tasks, snippets, global state, and extensions without a prompts/customizations resource. Profile-scoped storage therefore does not establish profile import/export coverage.
- **Related request is narrower:** https://github.com/microsoft/vscode/issues/296414 was verified open and specifically requests syncing ~/.copilot/skills across machines. It overlaps the skills portion but does not own this report's broader customization and profile-portability scope, so it is not a sufficient duplicate canonical.
