[https://github.com/microsoft/vscode/issues/213440](https://github.com/microsoft/vscode/issues/213440)

## Summary

Keep open: current vertical cursor movement still estimates character widths independently of the font, consistent with the reported mismatch. Rendering now has a full-width character setting, but it does not resolve that navigation path; the supplied example and steps suffice to retest.

## Change summary

Up/down cursor movement should preserve horizontal alignment when a font renders emoji or full-width characters at widths different from the editor's column estimates.
