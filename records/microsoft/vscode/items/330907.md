# Issue #330907 — Agent Sessions sidebar visibility is global across all windows instead of per-window

[https://github.com/microsoft/vscode/issues/330907](https://github.com/microsoft/vscode/issues/330907)

## Summary

The cross-window behavior remains traceable in current main: Show Sessions updates shared User configuration when no workspace override exists. Keep this open; the workspace-setting workaround does not make the normal toggle window-local.

## Change summary

Showing or hiding Agent Sessions in one window also changes other windows using the same User settings.

## Best solution

Make Agent Sessions visibility controls local to the invoking window, consistent with other workbench visibility controls. Settle how local visibility interacts with the existing configuration defaults and workspace overrides before implementation.

- **Trace:**
