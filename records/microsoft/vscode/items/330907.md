# Issue #330907 — Agent Sessions sidebar visibility is global across all windows instead of per-window

[https://github.com/microsoft/vscode/issues/330907](https://github.com/microsoft/vscode/issues/330907)

## Summary

Confirmed in source: the 'Show Sessions' toggle writes chat.viewSessions.enabled via configurationService.updateValue with no target, which resolves to a global User-settings write (ConfigurationTarget.USER) whenever no workspace/folder override already exists — so the toggle really does apply globally across all windows, unlike normal per-window view/panel visibility.

## Change summary

Toggling the Agent Sessions sidebar in one VS Code window also toggles it in every other open window, because visibility is persisted as a global setting instead of per-window UI state.

## Best solution

Rework agent-sessions visibility to behave like other view/panel visibility (per-window layout/storage state) rather than a global configuration write in ToggleShowAgentSessionsAction (src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsActions.ts); this likely also touches the several other call sites and preconditions keyed on config.chat.viewSessions.enabled (chatViewPane.ts, agentTitleBarStatusWidget.ts), so it's a moderate cross-cutting change, not a one-line fix.
