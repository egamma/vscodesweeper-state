# Issue #239851 — Force Update Git internals when Refreshing Explorer

[https://github.com/microsoft/vscode/issues/239851](https://github.com/microsoft/vscode/issues/239851)

## Summary

Confirmed bug: GitIgnoreDecorationProvider does not listen to onDidRunGitStatus or any refresh event, so ignored-file decorations only update on .gitignore save or repository open/close — not on "Git: Refresh" or Explorer refresh. Already labeled help-wanted and acknowledged by a team member; still unfixed on main.

## Change summary

Explorer git-ignore decorations (grayed-out files) do not refresh when the user runs "Git: Refresh" or clicks the Explorer refresh button; only closing and reopening the project updates them.

## Best solution

In `extensions/git/src/decorationProvider.ts`, wire `GitIgnoreDecorationProvider` to also fire `_onDidChangeDecorations` on repository status changes (e.g. subscribe to `model.onDidChangeRepository` or the individual repository's `onDidRunGitStatus` event), so that a manual refresh or any git status update causes the ignore decorations to be re-queried. The fix is small and localized to this one file.
