# Issue #107989 — Add when clause context for language at active cursor

[https://github.com/microsoft/vscode/issues/107989](https://github.com/microsoft/vscode/issues/107989)

## Summary

A real gap remains: current main exposes only the document-level `editorLangId`, while embedded-language-aware keybindings remain unsupported. This Backlog request has 46 upvotes and should stay open.

## Change summary

Expose the embedded language at the active cursor as a when-clause context key.

## Best solution

Add a separate cursor-scoped language context key in the editor, updating it when the cursor position or tokenization changes while preserving `editorLangId` for the document language.

- **Fit:** aligned
- **Reason:** A cursor-language context key strengthens the extension and keybinding ecosystem without adding permanent UI or bundled functionality.

## Evidence

- **current source:** src/vs/editor/common/editorContextKeys.ts defines only `editorLangId`, described as the language identifier of the editor.
- **current behavior:** src/vs/editor/browser/widget/codeEditor/codeEditorWidget.ts sets that context from `model.getLanguageId()` in `EditorModeContext._update`; it does not use the cursor or `getLanguageIdAtPosition()`.
