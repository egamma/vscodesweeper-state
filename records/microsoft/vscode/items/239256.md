# Issue #239256 — Long descriptions in merge editor can push the action items off the screen.

[https://github.com/microsoft/vscode/issues/239256](https://github.com/microsoft/vscode/issues/239256)

## Summary

The input-header layout still permits long descriptions to push toolbar actions outside the visible pane. Keep this accepted merge-editor bug open; the source identifies a bounded layout defect with a concrete browser regression check.

## Change summary

Keep merge-editor input-header actions visible when long descriptions exceed the available pane width.

## Best solution

The merge-editor header should prioritize visible, usable toolbar actions over descriptive text at supported narrow pane widths. Long text should truncate without changing merge behavior or regressing the result header.
