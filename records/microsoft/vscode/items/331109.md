# Issue #331109 — Repeated co-author on blame hover

[https://github.com/microsoft/vscode/issues/331109](https://github.com/microsoft/vscode/issues/331109)

## Summary

Traced on main: parseCoAuthors in extensions/git/src/git.ts extracts every Co-authored-by trailer line without deduplication, so a squash-merged commit message containing the same trailer multiple times (one per underlying commit) shows the same co-author repeated in the blame/commit hover.

## Change summary

The git blame/commit hover shows the same co-author (e.g. Copilot) listed multiple times for a single commit.

## Best solution

Deduplicate co-authors by email (case-insensitive) in parseCoAuthors (extensions/git/src/git.ts), so a commit message with the same Co-authored-by trailer repeated multiple times (typical after a squash merge combining several AI-assisted commits) yields one entry in the hover.
