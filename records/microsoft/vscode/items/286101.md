## Summary

Team-authored issue (MEMBER) reporting a behavior problem with 'Close Other Repositories' on git worktree nodes — closing the worktree's parent tree unexpectedly. Must remain open for maintainer judgment.

## Change summary

'Close Other Repositories' on a top-level worktree node closes the worktree's original repository, causing all related worktrees to close.

## Best solution

The 'Close Other Repositories' action on a worktree node should exclude the worktree's parent/original repository from the set of repositories being closed. The fix likely lives in the SCM/git repository management layer. Related issue https://github.com/microsoft/vscode/issues/313526 reports that worktrees reappear immediately after being closed via this action, which may share the same root cause around worktree-parent relationship handling.
