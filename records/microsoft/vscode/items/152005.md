# Issue #152005 — Feature Request: Vertical Display of Editor Area Texts (Vertical Texts)

[https://github.com/microsoft/vscode/issues/152005](https://github.com/microsoft/vscode/issues/152005)

## Summary

Keep this backlog request open: it earned 32 community upvotes, and current VS Code still lacks editable vertical text layout. The referenced extension provides only a preview, not the requested editor behavior.

## Change summary

Support top-to-bottom, right-to-left vertical text editing in the editor.

## Best solution

The editor-core team should assess native vertical layout support or an editor API that lets extensions provide it without relying on unsupported CSS injection. Cursor movement, selections, hit testing, and accessibility must follow the vertical flow, not merely rotate rendered text.
