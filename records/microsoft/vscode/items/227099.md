# Issue #227099 — Editor GPU: Reduce memory use in the atlas glyph storage buffers

[https://github.com/microsoft/vscode/issues/227099](https://github.com/microsoft/vscode/issues/227099)

## Summary

Keep this protected plan-item open. Current source still allocates glyph metadata at fixed maximum capacity, so the requested memory optimization remains relevant.

## Change summary

Size texture-atlas glyph metadata storage dynamically rather than reserving the maximum glyph capacity.

## Best solution

Make glyph metadata storage track actual atlas demand while preserving glyph indexing, multi-page rendering, and rendering performance. Coordinate this optimization with the existing GPU-renderer work rather than treating the broad renderer tracker as a duplicate.
