# Issue #329669 — Kimi K2.7 consistently fails with Server Error 500 in VS Code Copilot local session side chat

[https://github.com/microsoft/vscode/issues/329669](https://github.com/microsoft/vscode/issues/329669)

## Summary

Multiple independent users confirm the Kimi K2.7 model consistently returns a server 500 when routed through the 'Local' session delegation mode in the Copilot Chat side panel, while the same model works fine via Copilot session delegation, the Agents window, and the CLI — pointing at a backend/session-routing issue specific to local delegation rather than something visible in the client checkout.

## Change summary

Kimi K2.7 fails with a persistent Server error 500 only when 'Local' session delegation is selected in the Copilot Chat side panel.

## Best solution

Needs backend/service-side investigation into how 'Local' session delegation routes requests to the Kimi K2.7 model (likely a session-router / model-proxy issue), since the same account and model work through every other delegation path; route to the chat/session-router owners rather than treating as a client-code defect.
