# Issue #329669 — Kimi K2.7 consistently fails with Server Error 500 in VS Code Copilot local session side chat

[https://github.com/microsoft/vscode/issues/329669](https://github.com/microsoft/vscode/issues/329669)

## Summary

Multiple independent users confirm Kimi K2.7 consistently fails with a 500 (and later a Responsible-AI-filter error) specifically in the Local session mode of Copilot Chat, while the same model/account works in Copilot session mode, the Agents window, and the CLI — this looks like a real, narrowly-scoped bug in how Local session requests are built or routed, but the exact fault (context size with MCP tools enabled, per one commenter) hasn't been isolated in code.

## Change summary

Kimi K2.7 fails on every request when used via Copilot Chat's 'Local' session delegation in VS Code, while working fine in other Copilot surfaces (CLI, Agents window, Copilot session mode).

## Best solution

Needs Copilot Chat/agent-host team investigation into what differs in the Local session request path for this model (context/tool payload construction, MCP server context injection) versus the working Copilot-session path; comment from gugaiz suggests disabling all MCP servers avoids the failure, pointing at oversized or malformed context being sent for local sessions specifically.
