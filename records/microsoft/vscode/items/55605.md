# Issue #55605 — Slow when editing a file with very long lines

[https://github.com/microsoft/vscode/issues/55605](https://github.com/microsoft/vscode/issues/55605)

## Summary

This issue carries the `verification-found` label, placing it mid-verification — it must remain open regardless of other evidence. The original auto-indent tokenization cause was fixed in 5db58b3867b, but comment 9 confirmed a remaining retokenization freeze (~300ms) on long lines in HTML mode, which was never fully resolved.

## Change summary

Editing very long lines (10k+ chars) in embedded language modes like HTML causes choppy/frozen typing due to expensive retokenization on each keystroke.

## Best solution

The remaining issue (comment 10) is that typing at the end of a long line triggers full-line retokenization taking ~300ms. The tokenization backend should skip or batch retokenization for lines exceeding the length threshold. Likely areas: `src/vs/editor/common/model/tokens/tokenizerSyntaxTokenBackend.ts`, `src/vs/editor/common/model/textModelTokens.ts`, and the `isCheapToTokenize` guard paths.
