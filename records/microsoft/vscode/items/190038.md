# Issue #190038 — layout or display issue

[https://github.com/microsoft/vscode/issues/190038](https://github.com/microsoft/vscode/issues/190038)

## Summary

Still relevant on main: the quick pick layout uses `dimension.width * 0.62` with no minimum side margin, so on very narrow windows the OK button can overflow. @sbatten acknowledged this and suggested reserving more space on Windows, but no fix has landed.

## Change summary

Quick pick OK button is clipped/unreachable when the VS Code window is very narrow on Windows.

## Best solution

In `src/vs/platform/quickinput/browser/quickInputController.ts`, the `updateLayout()` method should ensure a minimum side margin (or clamp the quick pick width more aggressively) so that action buttons remain accessible at small window sizes, particularly on Windows where title bar controls are wider.
