# Issue #190038 — layout or display issue

[https://github.com/microsoft/vscode/issues/190038](https://github.com/microsoft/vscode/issues/190038)

## Summary

The accepted quick-pick layout bug remains on current main: default centered quick picks do not reserve space for custom window controls in a narrow window, so the multi-select OK action can overlap the controls. A later overlap fix only constrains dragged quick inputs and does not cover this default path.

## Change summary

Keep the GitHub publishing quick pick's OK button usable when the VS Code window is narrowed or minimized on Windows.

## Best solution

Make default quick-input positioning honor the platform's custom window-control exclusion area, while preserving the existing centered layout whenever sufficient space is available.
