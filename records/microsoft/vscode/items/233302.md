## Change summary

Allow Node.js debugging to exclude child scripts launched through execSync without manually removing NODE_OPTIONS.

## Best solution

Use "autoAttachChildProcesses": false in the parent Node.js launch configuration to retain parent debugging without automatically attaching to children. The debugger owner should determine whether any additional global control remains intended by this accepted request before scheduling new functionality.
