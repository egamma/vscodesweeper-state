# Issue #233302 — node debugger also connects to externally executed node scripts

[https://github.com/microsoft/vscode/issues/233302](https://github.com/microsoft/vscode/issues/233302)

## Summary

Keep open as a scoped debug feature request: the Node debugger intentionally injects auto-attach state through environment variables, and this asks for a way to suppress that inheritance for child/external scripts. The issue is already routed to `debug` and parked in `On Deck`, which does not block normal backlog review.

## Change summary

Add a switch to prevent VS Code's Node debugging environment from auto-attaching to Node scripts launched via `execSync` or similar child-process calls.

## Best solution

Debug ownership should decide whether a user-facing launch/configuration option is warranted, or whether the existing workaround of unsetting inherited debug environment such as `NODE_OPTIONS` is the intended boundary.
