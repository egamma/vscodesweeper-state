# Issue #343168 — Uninstall All can remove a remote dependent but fail to uninstall its local dependency

[https://github.com/microsoft/vscode/issues/343168](https://github.com/microsoft/vscode/issues/343168)

## Summary

Keep open: current main still starts server-specific uninstalls concurrently, while the local dependency check cannot see the remote removals included in the same request. The reported timing-dependent partial failure follows directly from that code path.

## Change summary

Make Uninstall All handle a local dependency and its remote dependent consistently, without removing the dependency if a dependent remains installed.

## Best solution

Make the workbench extension-management service coordinate cross-server batch removal so successful dependent removal permits dependency removal, while failed or unrequested dependent removals continue to block it. Cover both outcomes with deterministic service-level regression tests.
