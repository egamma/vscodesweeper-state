# Issue #343168 — Uninstall All can remove a remote dependent but fail to uninstall its local dependency

[https://github.com/microsoft/vscode/issues/343168](https://github.com/microsoft/vscode/issues/343168)

## Summary

Keep open: current source still allows the remote dependent to be removed while the local dependency fails against an earlier inventory snapshot. The related inventory-performance issue does not cover this mixed-server removal failure.

## Change summary

Make Uninstall All reliably remove a local dependency and its requested remote dependent without bypassing protection for dependents that remain installed.

## Best solution

Make cross-server batch uninstall respect dependency removal outcomes in the workbench extension-management service. Preserve the local dependency when a remote dependent remains installed, including after a failed removal.
