# Issue #343168 — Uninstall All can remove a remote dependent but fail to uninstall its local dependency

[https://github.com/microsoft/vscode/issues/343168](https://github.com/microsoft/vscode/issues/343168)

## Summary

The cross-server uninstall race remains in current main: a local dependency check can reject a dependent that the same request is concurrently removing remotely. Keep this open as a backend extension-management bug; the report provides sufficient detail for a deterministic regression test.

## Change summary

Make Uninstall All successfully remove a local dependency and its requested remote dependents without weakening protection for dependents that remain installed.

## Best solution

Make the workbench extension-management service coordinate cross-server batch removal so successfully removed dependents no longer block their requested dependencies. Preserve dependency checks when a dependent is outside the request or its removal fails.
