## Summary

Confirmed gap on current main: git.mergeAbort is only surfaced in the command palette, not in the git.branch submenu. An open PR (#307990) is actively addressing this — keeping the issue open as the tracking target for that PR.

## Change summary

The 'Abort Merge' action is available only via the command palette, not in the Branch submenu UI where users initiate the merge.

## Best solution

Land https://github.com/microsoft/vscode/pull/307990, which adds abort merge/rebase actions to the Branch submenu. The fix is a menu registration change in `extensions/git/package.json` — adding `git.mergeAbort` (and likely `git.rebaseAbort`) entries to the `git.branch` menu with appropriate `when` clauses.
