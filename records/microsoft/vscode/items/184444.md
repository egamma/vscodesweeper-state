# Issue #184444 — Test Explorer: Sort tests by name

[https://github.com/microsoft/vscode/issues/184444](https://github.com/microsoft/vscode/issues/184444)

## Summary

Valid feature request: the Test Explorer currently offers Sort by Location, Status, and Duration, but no Sort by Name. The request for a name-based sort option remains unimplemented on main. On Deck milestone and low upvote count — keeping open.

## Change summary

Add a 'Sort by Name' option to the Test Explorer view so tests can be alphabetically ordered within a file.

## Best solution

Add a `ByName` entry to `TestExplorerViewSorting` in `src/vs/workbench/contrib/testing/common/constants.ts`, a corresponding `TestingSortByNameAction` in `testExplorerActions.ts`, and a name-primary branch in the `TreeSorter.compare` method in `testingExplorerView.ts` (lines ~1316–1348) that sorts by `sortText || label` without the location-first tiebreaker. The coverage view already has a Name sort that could serve as a pattern.
