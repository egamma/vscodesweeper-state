# Issue #172182 — Emmet extension is getting activate even when no editor is opened

[https://github.com/microsoft/vscode/issues/172182](https://github.com/microsoft/vscode/issues/172182)

## Summary

Keep open: the discussion confirms that the original startup case was fixed, but opening or restoring the Extensions view still activates Emmet without a document editor. Current source retains that activation path, and no verified canonical issue owns the remaining work.

## Change summary

Avoid activating built-in Emmet solely because an embedded workbench input requests language features when no document editor is open.

## Best solution

Make Emmet activation reflect document-editor use while preserving support for user-configured languages such as JSX and SCSS. Settle whether that distinction belongs in an Emmet-specific activation mechanism or a reusable editor-scoped activation contract without silently narrowing existing onLanguage behavior for other extensions.
