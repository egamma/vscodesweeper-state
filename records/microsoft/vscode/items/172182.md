# Issue #172182 — Emmet extension is getting activate even when no editor is opened

[https://github.com/microsoft/vscode/issues/172182](https://github.com/microsoft/vscode/issues/172182)

## Summary

The original startup scenario was fixed by PR #175331, but a remaining issue persists: opening the extensions view creates a text model that fires `onLanguage`, activating Emmet unnecessarily. The underlying mechanism in `languageService.ts` fires `onLanguage` for any `requestRichLanguageFeatures` call from any text model, including non-editor UI surfaces.

## Change summary

Emmet extension activates when the extensions view is opened even though no actual editor file is open.

## Best solution

Distinguish between editor text models (user-facing files) and UI/internal text models when deciding whether to fire `onLanguage` activation events, or introduce an `onEditorLanguage` activation event (as suggested in comment 7) that only fires for actual editor documents. The fix belongs in `src/vs/workbench/services/language/common/languageService.ts` or in how text models from UI inputs trigger `requestRichLanguageFeatures`.
