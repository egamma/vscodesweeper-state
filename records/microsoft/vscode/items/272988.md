# Issue #272988 — Agent handoffs: prompt should not overriden existing chat input text

[https://github.com/microsoft/vscode/issues/272988](https://github.com/microsoft/vscode/issues/272988)

## Summary

The defect remains on current main: executing a regular agent handoff unconditionally replaces the chat input with the handoff prompt, discarding any answer the user typed. The behavior is source-confirmed and bounded, so this team-authored issue should remain open for a fix.

## Change summary

Preserve text already entered in the chat input when adding an agent handoff prompt.

## Best solution

Keep the existing draft in the chat input and place the handoff prompt after it, while retaining the current mode switch, model selection, focus, and auto-send behavior.
