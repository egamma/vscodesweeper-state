# Issue #162810 — API for using  file quick open

[https://github.com/microsoft/vscode/issues/162810](https://github.com/microsoft/vscode/issues/162810)

## Summary

The extension API still lacks a way to return a file selected through built-in Quick Open. Keep this accepted Backlog request open for API design; existing commands and file dialogs do not cover it, and no verified open canonical or fixing PR was found.

## Change summary

Let extensions invoke built-in file Quick Open and receive the selected URI instead of opening the file.

## Best solution

Provide a supported extension-facing file-selection contract that reuses Quick Open's search and presentation without opening the selected file. API owners should settle whether this is a distinct API or an explicit mode of the existing file-dialog API.

Existing showOpenDialog and extension-populated quick picks do not provide the same workspace search and recent-file experience. - **Trace:**

  > workbench.action.quickOpen in src/vs/workbench/browser/actions/quickAccessActions.ts calls quickAccess.show() and returns void, so invoking it cannot deliver the requested selection. MainThreadDialogs.$showOpenDialog currently routes through the native/simplified file-dialog service, and OpenDialogOptions exposes no Quick Open mode. - **Open decisions:**
