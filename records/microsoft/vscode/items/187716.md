# Issue #187716 — "unable to get local issuer certificate" attempting to install extensions into dev container by code-server on dev container build

[https://github.com/microsoft/vscode/issues/187716](https://github.com/microsoft/vscode/issues/187716)

## Summary

Real gap in code-server's certificate handling when installing extensions behind a corporate proxy with custom root CA. Workaround exists (NODE_EXTRA_CA_CERTS) but the underlying issue — code-server not automatically picking up system/host certificates during extension installation — remains unfixed on main. 10 community upvotes and team engagement justify keeping open.

## Change summary

code-server fails to install extensions in dev containers when behind a corporate proxy with a custom root CA, producing 'unable to get local issuer certificate' errors.

## Best solution

The remote server's extension download path should automatically respect the host's certificate chain or honor system CA stores without requiring manual NODE_EXTRA_CA_CERTS configuration. This likely involves improving how the server-side request infrastructure (src/vs/server/ and the proxy resolver) handles custom CAs during the build-time extension installation phase. Related broader proxy work is tracked in https://github.com/microsoft/vscode/issues/12588 and https://github.com/microsoft/vscode/issues/29910.
