# Issue #277144 — AI changes hard to read without side by side view

[https://github.com/microsoft/vscode/issues/277144](https://github.com/microsoft/vscode/issues/277144)

## Summary

Keep open: a full-file diff command already exists, but inline chat still forces inline review rather than offering the requested new-code-first, region-focused comparison. The team-authored request and discussion establish an accepted improvement; no verified fix or eligible canonical was found.

## Change summary

Make fragmented inline-chat edits easier to review through a discoverable, region-focused side-by-side comparison.

## Best solution

Provide an inline-chat review experience that avoids interleaving numerous old-code hunks and makes before/after comparison readily accessible. Settle whether this should follow the existing diff layout preference automatically or use the proposed new-code-first presentation with an explicit region-focused comparison action.
