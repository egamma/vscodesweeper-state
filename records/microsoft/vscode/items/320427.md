# Issue #320427 — AI Customizations impacting harnesses they should not

[https://github.com/microsoft/vscode/issues/320427](https://github.com/microsoft/vscode/issues/320427)

## Summary

Valid team-authored bug: hooks configured for one harness (e.g. regular Copilot CLI) incorrectly affect other harnesses (e.g. AHP variant, Local agent). No fix found on current main — the hook resolution path does not filter by harness/session-type. Keeping open.

## Change summary

PreToolUse hooks set for one agent harness leak into other harnesses, causing tool calls to fail in unrelated sessions.

## Best solution

The hook resolution and sync paths need to scope hooks to the harness they were configured for. The customization enumeration in `agentHostLocalCustomizations.ts` already filters prompts by `sessionType` via `matchesSessionType`, but hooks are excluded from `SYNCABLE_PROMPT_TYPES` and follow a separate bundling path that likely lacks this per-harness scoping. The fix should ensure hooks are only applied to the harness/session-type they were created under.
