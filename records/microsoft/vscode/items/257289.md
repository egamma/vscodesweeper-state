# Issue #257289 — scoping of CCA (copilot coding agent) tasks

[https://github.com/microsoft/vscode/issues/257289](https://github.com/microsoft/vscode/issues/257289)

## Summary

Keep open: Plan mode now provides iterative clarification and explicit scope boundaries, but that does not establish that a delegated cloud task has the external access or manageable scope needed to succeed. This team-authored request still warrants a product decision about destination-aware readiness checks.

## Change summary

Help users refine cloud coding-agent tasks into achievable scopes and identify missing external access before execution.

## Best solution

Build on the existing Plan-to-cloud workflow so users can distinguish a reviewed plan from a task whose execution prerequisites have actually been checked. Define how unavailable dependencies and excessive scope should be surfaced before delegation, without promising that planning alone guarantees completion.
