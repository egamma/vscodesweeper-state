# Issue #65388 — Microsoft Surface Precision Mouse - "Accelerated Vertical Scrolling" breaks smooth scroll

[https://github.com/microsoft/vscode/issues/65388](https://github.com/microsoft/vscode/issues/65388)

## Summary

Keep this accepted Backlog request open: existing smooth-scrolling settings do not establish compatibility with Microsoft's accelerated wheel input, and no qualifying fix or duplicate was identified. The next useful step is to capture wheel events on current Windows builds with acceleration enabled and disabled.

## Change summary

Preserve smooth scrolling when Microsoft Mouse and Keyboard Center's Accelerated Vertical Scrolling is enabled.

## Best solution

Support accelerated Microsoft mouse input in the shared wheel-scrolling path without degrading touchpad scrolling or requiring users to disable acceleration system-wide. Confirm the current device event stream before deciding whether wheel classification or animation handling needs adjustment.

Its _onMouseWheel path at lines 545-556 uses smooth animation only when isPhysicalMouseWheel() is true; otherwise it updates the position immediately. This is a plausible investigation target, not proof that these devices currently take the failing branch: the report contains no recorded wheel-event sequence.
