# Issue #65388 — Microsoft Surface Precision Mouse - "Accelerated Vertical Scrolling" breaks smooth scroll

[https://github.com/microsoft/vscode/issues/65388](https://github.com/microsoft/vscode/issues/65388)

## Summary

Keep this accepted Backlog request open: current scrolling remains gated by mouse-versus-touchpad classification, and the existing settings do not guarantee smooth scrolling with Microsoft's accelerated wheel mode. No concrete fix or eligible older, open canonical was established.

## Change summary

Preserve smooth scrolling when Accelerated Vertical Scrolling is enabled for Microsoft Surface Precision and Sculpt Ergonomic mice.

## Best solution

Establish how these devices' accelerated wheel events interact with the shared scroll classifier, then provide smooth editor scrolling without requiring users to disable driver acceleration. Preserve native touchpad scrolling rather than indiscriminately animating every wheel event.
