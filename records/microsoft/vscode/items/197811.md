# Issue #197811 — Allow to recover backups from extension provided file systems if extension uninstalled

[https://github.com/microsoft/vscode/issues/197811](https://github.com/microsoft/vscode/issues/197811)

## Summary

A real recovery gap remains on current main: backups for extension-provided resources cannot be opened when their file-system provider is unavailable. Keep this accepted Backlog request open for design discussion.

## Change summary

Allow users to recover raw hot-exit backup contents after the extension providing the resource scheme is uninstalled or unavailable.

## Best solution

Add a generic fallback editor for unrestored backups whose normal editor handler is unavailable, exposing the preserved contents with Save As or export while retaining the original resource metadata.
