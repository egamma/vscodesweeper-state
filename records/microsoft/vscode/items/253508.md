[https://github.com/microsoft/vscode/issues/253508](https://github.com/microsoft/vscode/issues/253508)

## Change summary

MCP model selections made through Configure Model Access do not appear on a second machine after Settings Sync.

## Best solution

Make user-scoped MCP sampling model selections round-trip through Settings Sync and appear for the corresponding server on another machine. First distinguish a settings-transfer failure from a server-key or model-ID mismatch; preserve the existing separation between user and workspace configuration.
