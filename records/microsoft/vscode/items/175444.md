# Issue #175444 — Keybindings don't respect `editorTextFocus` in the find widget

[https://github.com/microsoft/vscode/issues/175444](https://github.com/microsoft/vscode/issues/175444)

## Summary

Keep open: current source still moves focus from the find input to the editor on Ctrl+Down independently of keybinding resolution. An open PR explicitly targets this issue and should be reviewed before considering completion.

## Change summary

Find-widget input handlers move editor focus on Ctrl+Down even when the shortcut is unbound or overridden, interfering with context-scoped keybindings.

## Best solution

Review https://github.com/microsoft/vscode/pull/327275 against the maintainer's requested command-based behavior, preserving the default focus shortcut while allowing normal rebinding and suppression. Keep this issue open until the fix lands and its scope is confirmed.
