# Issue #340743 — Misleading UX: Session target

[https://github.com/microsoft/vscode/issues/340743](https://github.com/microsoft/vscode/issues/340743)

## Summary

Keep open as a session-picker clarity improvement: current source explains Copilot usage in a Claude hover, but does not make the subscription visible in the normal picker description. This is product feedback about informed selection, not an account or billing-support request.

## Change summary

Make the Claude session target's execution harness and subscription implications clear before users start consuming Copilot credits.

## Best solution

Make the active provider/subscription understandable when choosing a Claude session, distinguishing the agent harness from the selected model. Coordinate the presentation with the related Agents-window and native-auth discoverability work without requiring removal of the Claude integration.
