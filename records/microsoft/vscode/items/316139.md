# Issue #316139 — Turn off integrated browser for default

[https://github.com/microsoft/vscode/issues/316139](https://github.com/microsoft/vscode/issues/316139)

## Summary

Legitimate, well-supported feature request (64 upvotes, already in Backlog) asking that the integrated browser not be the default for opening localhost links. The code default is already `false`, but the experimentation framework (`experiment: { mode: 'startup' }`) overrides it for enrolled users — so the complaint is about the ExP rollout strategy, not the hardcoded default. A team member has engaged; this should stay open for the team to decide on the rollout approach.

## Change summary

Users want `workbench.browser.openLocalhostLinks` to default to `false` (use external browser) rather than being silently flipped to `true` via experimentation, or at minimum to be prompted before the behavior changes.

## Best solution

Either remove the experimentation override so the `false` default takes effect universally, or add a first-run prompt when the integrated browser intercepts a localhost link for the first time (as several commenters suggest), letting users opt in rather than opt out. The relevant code is in `src/vs/workbench/contrib/browserView/electron-browser/features/browserTabManagementFeatures.ts` around lines 923–932.
