# Issue #316139 — Turn off integrated browser for default

[https://github.com/microsoft/vscode/issues/316139](https://github.com/microsoft/vscode/issues/316139)

## Summary

Keep this accepted, well-supported request open for a browser-default decision. The source default is already false, but startup experiments can override it; neither the existing opt-out nor the newer action-targeting request settles the requested default experience.

## Change summary

Make opening localhost links in the integrated browser an explicit user choice rather than an automatic default.

## Best solution

Resolve the effective default for ordinary VS Code windows, including experiment assignments, so users retain their system-browser workflow unless they choose otherwise. The reporter also accepts an explicit first-use choice; a maintainer should decide between that experience and an external-browser default while treating Agents-window behavior separately.
