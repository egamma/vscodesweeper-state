# Issue #330519 — Remote-WSL keeps old VS Code Server versions indefinitely, accumulating 6.55 GB

[https://github.com/microsoft/vscode/issues/330519](https://github.com/microsoft/vscode/issues/330519)

## Summary

This is a confirmed Remote-WSL cache-cleanup regression owned by the VS Code Remote Development team. The issue should remain open and be moved to microsoft/vscode-remote-release with its filesystem evidence and confirmations intact.

## Change summary

Remote-WSL retains every downloaded Windows-side VS Code Server version, allowing the cache to grow indefinitely across updates.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release and restore bounded cleanup of `%USERPROFILE%\vscode-remote-wsl\stable` after successful server installation, while preserving any versions still needed by active clients.
