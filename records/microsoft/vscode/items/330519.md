# Issue #330519 — Remote-WSL keeps old VS Code Server versions indefinitely, accumulating 6.55 GB

[https://github.com/microsoft/vscode/issues/330519](https://github.com/microsoft/vscode/issues/330519)

## Summary

The `vscode-remote-wsl` server cache is created and managed by the Microsoft-owned Remote - WSL extension, whose code and tracker live outside this repo (microsoft/vscode-remote-release) — this belongs there, not in microsoft/vscode core.

## Change summary

Old VS Code Server version directories under `%USERPROFILE%\vscode-remote-wsl\stable` are never cleaned up after upgrades, accumulating gigabytes of stale server installs over time.

## Best solution

Move this issue to microsoft/vscode-remote-release, the tracker for the Remote - WSL extension, whose install/update logic is responsible for pruning stale `vscode-remote-wsl` server directories; the reporter's own linked prior reports (vscode-remote-release#2852, #3746) confirm this is the established home for the problem.
