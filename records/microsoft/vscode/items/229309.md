# Issue #229309 — Ghost text flickers before suggestions show

[https://github.com/microsoft/vscode/issues/229309](https://github.com/microsoft/vscode/issues/229309)

## Summary

Keep open: current source still permits inline ghost text to appear while suggestion providers are resolving, then disappear when a conflicting suggestion becomes focused. Existing delay and suppression settings do not deliver the requested coordination.

## Change summary

Avoid briefly displaying inline ghost text that pending IntelliSense suggestions will immediately invalidate.

## Best solution

Coordinate automatic ghost-text presentation with pending suggestion requests in the inline-completions model and suggest-widget adapter, preserving existing suggestion priority and releasing the wait when requests finish or are cancelled.
