# Issue #343999 — "Work in Repository…" errors with "Choose a Workspace Available in This Computer"

[https://github.com/microsoft/vscode/issues/343999](https://github.com/microsoft/vscode/issues/343999)

## Summary

The failure remains explainable in current source: choosing a GitHub repository without a matching known local checkout returns a virtual workspace that This Computer rejects, without attempting a clone. Keep this team-authored bug open; the existing coverage exercises checkout reuse, not the reported missing-checkout case.

## Change summary

Selecting Work in Repository under This Computer should offer to clone a repository that has no available local checkout instead of rejecting its virtual workspace.

## Best solution

Complete the repository-to-local-workspace handoff for This Computer, retaining reuse of known local checkouts and normal clone destination and cancellation behavior. Preserve cloud repository selection and do not weaken environment compatibility checks to accept virtual repositories as local folders.
