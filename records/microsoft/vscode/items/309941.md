# Issue #309941 — Bad chat loading rendering

[https://github.com/microsoft/vscode/issues/309941](https://github.com/microsoft/vscode/issues/309941)

## Summary

Still reproduces on main: the loading overlay created in chatEditor.ts uses class `chat-loading-overlay` but no corresponding CSS rules exist in the workbench/contrib/chat stylesheets, so the overlay renders as an unstyled inline element, causing the described layout shift (tabs pushed up, spinner below input). No fix commit references this issue.

## Change summary

Restoring a window with a contributed chat session (Copilot CLI, Claude) shows a broken loading state — editor tabs are pushed up and a loading spinner appears below the input box instead of as a proper overlay.

## Best solution

Add proper CSS for `.chat-loading-overlay` and `.chat-loading-content` in the chat editor stylesheet — at minimum `position: absolute; inset: 0;` with centering and a background, so the spinner overlays the editor area without displacing layout. The loading code lives in `src/vs/workbench/contrib/chat/browser/widgetHosts/editor/chatEditor.ts` (lines 179–210) and was introduced in commit 98997404e6e9.
