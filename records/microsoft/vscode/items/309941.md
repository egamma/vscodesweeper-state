# Issue #309941 — Bad chat loading rendering

[https://github.com/microsoft/vscode/issues/309941](https://github.com/microsoft/vscode/issues/309941)

## Summary

The visual defect remains source-reproducible on current main: contributed-session restore appends a loading element after the chat widget, but the supposed overlay classes have no CSS definitions, leaving the spinner in normal document flow below the input.

## Change summary

Restoring a contributed chat editor displaces its content and renders the loading spinner below the input box.

## Best solution

Keep the accessible loading status but render it as a centered overlay within the chat editor host so it cannot displace the transcript, input, or surrounding editor layout.
