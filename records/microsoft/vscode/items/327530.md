# Issue #327530 — Agents window Markdown editor: Rendered task checkboxes do not toggle

[https://github.com/microsoft/vscode/issues/327530](https://github.com/microsoft/vscode/issues/327530)

## Summary

Confirmed event-ordering defect in the upstream Markdown editor package: its root handles `pointerdown` before the checkbox's later `mousedown` handler, activating raw editing before the toggle can complete.

## Change summary

Rendered task-list checkboxes should update their Markdown marker instead of activating raw editing.

## Best solution

Handle the checkbox gesture at `pointerdown` in `microsoft/vscode-packages`, add a regression fixture, then update VS Code's `@vscode/markdown-editor` dependency.
