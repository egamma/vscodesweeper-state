# Issue #322463 — Completions not sent after every character in debug console

[https://github.com/microsoft/vscode/issues/322463](https://github.com/microsoft/vscode/issues/322463)

## Summary

The current source still permits the reported failure: Debug Console completions are treated as complete, so matching history suggestions can keep the widget open without refreshing adapter results as typing continues. Keep this report open; the related older report describes disappearing suggestions rather than the same missing-request symptom.

## Change summary

Refresh debug-adapter completions while typing even when history or other existing suggestions remain visible.

## Best solution

Ensure the Debug Console completion provider participates in incremental refresh so adapter suggestions stay current while the widget remains open, without disabling history suggestions or changing completion caching for ordinary editors.
