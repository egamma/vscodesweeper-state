# Issue #322015 — Agent host does not seem to pick up account changes without process restart

[https://github.com/microsoft/vscode/issues/322015](https://github.com/microsoft/vscode/issues/322015)

## Summary

Keep open: account-switch failures have independent confirmations, including reports that restarting does not help. Current source supports credential updates but leaves a plausible account-selection gap; no issue-referencing fix was established for this team-authored Backlog item.

## Change summary

Agent Host should honor account changes without continuing to use the previous account's credentials or quota.

## Best solution

Ensure the account selected for Copilot is consistently used for Agent Host authentication, model discovery, and subsequent requests without requiring a manual process restart. Diagnose account selection separately from delivery of updated credentials, using the related reports to distinguish these failure modes.
