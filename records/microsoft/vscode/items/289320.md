# Issue #289320 — Improve Performance of Session History Tooltip in GitHub Copilot Session List

[https://github.com/microsoft/vscode/issues/289320](https://github.com/microsoft/vscode/issues/289320)

## Summary

Keep open: the hover already limits the transcript to the latest request/response pair, but that does not bound the cost of loading the session or rendering one long response. The maintainer identified response-part rendering as a prerequisite; that related issue does not report the same hover-specific symptom required for a duplicate close on this re-reviewed item.

## Change summary

Make long-session hover previews appear quickly, potentially by displaying only a recent subsection of the response.

## Best solution

Provide a responsive, bounded-cost session preview while preserving access to the complete conversation when the session is opened. Establish whether session loading or response rendering dominates hover latency, and coordinate any response-part rendering work with https://github.com/microsoft/vscode/issues/263499.
