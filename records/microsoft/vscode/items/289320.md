# Issue #289320 — Improve Performance of Session History Tooltip in GitHub Copilot Session List

[https://github.com/microsoft/vscode/issues/289320](https://github.com/microsoft/vscode/issues/289320)

## Summary

Verified duplicate: the tooltip already limits history to the latest request/response pair, but a single long response remains expensive because response parts are rendered together. The open canonical issue owns that underlying rendering work.

## Change summary

Long Copilot sessions make the session-list history tooltip slow to load.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/263499 and split response parts into incrementally rendered list rows; this would make long-response previews responsive without discarding useful content.
