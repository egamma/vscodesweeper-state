# Issue #289320 — Improve Performance of Session History Tooltip in GitHub Copilot Session List

[https://github.com/microsoft/vscode/issues/289320](https://github.com/microsoft/vscode/issues/289320)

## Summary

Keep open for improving long-response hover previews. Current source already limits the preview to the last request/response pair, but does not limit the content within that response; the maintainer explicitly identified this remaining rendering limitation.

## Change summary

Make session-list hover previews faster for long conversations, potentially by showing only a recent subsection of the response.

## Best solution

Provide a lightweight session hover whose rendering cost does not grow with the entire last response, while retaining access to the complete conversation when opened. Coordinate with the response-part rendering work at https://github.com/microsoft/vscode/issues/263499, without treating its editor-opening symptom as a verified duplicate of this hover-specific request.
