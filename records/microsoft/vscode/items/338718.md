# Issue #338718 — Agent cannot find remote sub-sessions

[https://github.com/microsoft/vscode/issues/338718](https://github.com/microsoft/vscode/issues/338718)

## Summary

Keep open: current tools can inspect a known remote session or chat, but do not provide dynamic discovery of its sub-sessions. The older peer-chat discovery request is related, but its explicitly same-session scope does not establish a duplicate of this remote-discovery request.

## Change summary

Allow an agent to discover sub-sessions created by remote sessions without already knowing their references.

## Best solution

Provide agent-visible discovery of remote sub-sessions with stable, host-qualified references in the session-management tools. Establish whether discovery covers descendants of delegated sessions or all peer chats in a specified remote session before implementation.
