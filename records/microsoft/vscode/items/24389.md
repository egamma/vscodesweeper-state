# Issue #24389 — SCM - Support workspace diff navigation

[https://github.com/microsoft/vscode/issues/24389](https://github.com/microsoft/vscode/issues/24389)

## Summary

Long-lived, heavily upvoted (114 👍) SCM umbrella request that a maintainer explicitly merged other requests into; parts have shipped (multi-diff editor cross-file change navigation, SCM tree mode, multi-select) but the central asks — a filter/search box in the Source Control view and a keybinding that walks from the last change of one file into the next changed file — are still missing on main, so it stays open.

## Change summary

Make the Source Control view searchable with bulk selection and add keyboard navigation that cycles through all changes across all changed files.

## Best solution

Deliver the two remaining pieces in the SCM contrib: a find/filter widget in the Source Control view (src/vs/workbench/contrib/scm/browser/scmViewPane.ts, which has no find widget today) and a navigation command that continues past the last change of a file into the next changed file — the multi-diff editor's `multiDiffEditor.goToNextChange` already does this inside the all-changes editor, so the gap is the regular diff/editor flow tracked by https://github.com/microsoft/vscode/issues/145009.
