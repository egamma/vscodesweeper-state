## Summary

Keep open while the SCM owner reconciles this request with existing multi-file diff navigation. Current source supports cross-file change cycling in the multi-diff editor, but ordinary diff navigation remains file-local; neither a qualifying older canonical nor a concrete fixing commit was established.

## Change summary

Provide keyboard-driven SCM review that moves through changes across files, alongside filtering, folder grouping, and bulk staging.

Current multi-diff review already supports this, while ordinary diff navigation stays within one file. Decide whether the ordinary SCM diff workflow must also provide cross-file progression. Acceptance should cover forward and backward navigation, file boundaries, and the selected wrap-or-stop behavior without regressing existing multi-diff review.
