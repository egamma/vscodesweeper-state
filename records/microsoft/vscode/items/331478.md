# Issue #331478 — Modern UI glitch

[https://github.com/microsoft/vscode/issues/331478](https://github.com/microsoft/vscode/issues/331478)

## Summary

Keep open as Modern UI usability polish: the reporter clarified that the selected activity-bar icon needs more visible surrounding highlight, rather than a different color. Existing customization offers mitigations, but neither a completed fix nor an older canonical reporting the same symptom was established.

## Change summary

Improve the visual separation between an activity-bar icon and its selected-state highlight in Modern UI.

## Best solution

Have the Modern UI owner evaluate the default icon-to-highlight spacing in src/vs/workbench/contrib/modernUI/browser/media/activityBar.css and choose a consistently legible selection treatment across themes. Preserve distinct hover, selection, and keyboard-focus states rather than adding a one-off appearance setting.
