# Issue #297842 — `/yolo <prompt>` does not disable auto approve

[https://github.com/microsoft/vscode/issues/297842](https://github.com/microsoft/vscode/issues/297842)

## Summary

The mismatch remains visible in current source: `/yolo` unconditionally enables auto-approval, while the referenced test plan says invoking it when enabled should disable it. This team-authored report has no explicitly linked fix or verified duplicate, so it should remain open while the intended command contract is reconciled with the newer explicit `/disableYolo` command.

## Change summary

Using `/yolo <prompt>` while auto-approval is enabled does not turn auto-approval off as expected.

## Best solution

Choose and document one command contract: either preserve `/yolo` as a state-aware toggle, including when followed by a prompt, or formally make it enable-only and use `/disableYolo` for disabling. Cover the selected behavior with command-level tests, including preservation or submission of the trailing prompt.
