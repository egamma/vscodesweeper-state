# Issue #338554 — `create_session` shows hierarchy and so should `create_remote_session`

[https://github.com/microsoft/vscode/issues/338554](https://github.com/microsoft/vscode/issues/338554)

## Summary

Confirmed on main: `create_session`/`create_chat`/`send_message` completions render the clickable session hierarchy link via `IChatSessionCreatedData` and are exempted from being folded into the collapsed "thinking" group, but `create_remote_session` does neither — its `invoke()` only sets a plain markdown `toolResultMessage`, and its tool id isn't in the pin-exemption list.

## Change summary

`create_remote_session` results should show the same session-hierarchy "Open Session" treatment that `create_session` already gets.

## Best solution

Have `CreateRemoteSessionTool.invoke()` (src/vs/sessions/contrib/remoteSessions/browser/remoteSessionTools.ts) return `toolSpecificData: { kind: 'sessionCreated', openLink, label, fullTitle }` from the already-built `created.openLink`/title, and add its tool id to the pin-exemption check in chatListRenderer.ts alongside `isCreateSessionTool`/`isCreateChatTool`/`isSendMessageTool` so its result stays visible and renders with `ChatSessionCreatedResultSubPart`.
