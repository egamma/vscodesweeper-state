# Issue #330309 — TreeView: allow disabling expand/collapse on double-click

[https://github.com/microsoft/vscode/issues/330309](https://github.com/microsoft/vscode/issues/330309)

## Summary

Reporter thoroughly answered the maintainer's `workbench.tree.expandMode` question with code references showing it's a global setting that's also short-circuited by `!!e.command` for TreeView items — this is a real API gap, not something answerable with existing settings, so it shouldn't sit on `info-needed` awaiting a reply that already happened.

## Change summary

Extension TreeViews have no way to disable the built-in double-click expand/collapse toggle when a per-item `command` is used for double-click navigation, causing an expanded node to flicker/collapse.

## Best solution

Consider a new `TreeViewOptions` field (e.g. `expandOnDoubleClick?: boolean`) or adjust `expandOnlyOnTwistieClick` in src/vs/workbench/browser/parts/views/treeView.ts so `TreeItem.command` presence also suppresses double-click toggling per-item rather than relying on the global `workbench.tree.expandMode` setting; this is an API design decision for the tree-views/API owners.
