# Issue #330309 — TreeView: allow disabling expand/collapse on double-click

[https://github.com/microsoft/vscode/issues/330309](https://github.com/microsoft/vscode/issues/330309)

## Summary

Genuine API gap confirmed in source: the internal tree widget already supports a per-tree `expandOnDoubleClick` option (src/vs/base/browser/ui/tree/abstractTree.ts), but the extension `TreeView` implementation never exposes it — `createTree()` in treeView.ts only sets `expandOnlyOnTwistieClick` (checking `e.command`/`e.checkbox`/a global setting) and leaves `expandOnDoubleClick` at its default `true`. There's no `TreeViewOptions` field to opt out, so extensions using double-click for navigation get an unwanted expand/collapse toggle.

## Change summary

Add a way for extension TreeViews to disable the built-in expand/collapse behavior on double-click so extensions can use double-click for other actions (e.g. navigation) without the toggle flicker.

## Best solution

Add an `expandOnDoubleClick?: boolean` (or similar) field to `TreeViewOptions` in vscode.d.ts, thread it through `ExtHostTreeViews`/`MainThreadTreeViews` down to the `expandOnDoubleClick` option already accepted by the tree widget in src/vs/workbench/browser/parts/views/treeView.ts's `createTree()`.
