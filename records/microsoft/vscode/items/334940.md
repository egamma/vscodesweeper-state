# Issue #334940 — Debugger UI does not display ErrorResponse from Variables Request

[https://github.com/microsoft/vscode/issues/334940](https://github.com/microsoft/vscode/issues/334940)

## Summary

The defect remains on current main: a failed Variables request while evaluating a lazy variable rejects before the debug view model emits its update event, leaving the Variables UI unchanged.

## Change summary

Display a debug adapter's failed Variables response inline when expanding a lazy variable, consistent with Watch evaluation errors.

## Best solution

Represent a failed lazy-variable request as an inline error state in the debug expression model and complete the lazy-evaluation update flow so the Variables view rerenders instead of showing no feedback.
