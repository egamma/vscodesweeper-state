# Issue #253435 — Should we link to extensions using our LM APIs in the Manage LM access menu?

[https://github.com/microsoft/vscode/issues/253435](https://github.com/microsoft/vscode/issues/253435)

## Summary

The Manage Language Model Access empty state still lacks discovery of extensions that consume model APIs. Keep this team-authored discussion open: existing provider and tool discovery cover different capabilities, and no verified canonical or qualifying fix was found.

## Change summary

Offer an extension-discovery action when no extensions have language model access.

## Best solution

Decide whether this access-management surface should offer discovery, and establish a reliable Marketplace classification for extensions that consume language models before adding an actionable empty-state entry. Do not substitute model-provider or tool-extension searches, which do not cover the requested audience.
