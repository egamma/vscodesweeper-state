# Issue #20742 — Allow to create multi-cursor with keyboard

[https://github.com/microsoft/vscode/issues/20742](https://github.com/microsoft/vscode/issues/20742)

## Summary

Keep this open as the canonical keyboard-driven multicursor request. It has 27 community upvotes, is assigned to Backlog, remains distinct from existing directional cursor commands, and a maintainer explicitly redirected a related issue here.

## Change summary

Allow users to preserve cursor positions while navigating by keyboard to add or remove arbitrary additional cursors.

## Best solution

Decide whether to add a keyboard-oriented multicursor mode in the editor, likely around `createCursor` and the multicursor contribution, while preserving the existing mouse and directional insertion behavior. The available extension demonstrates feasibility but does not provide the requested built-in, durable accessibility surface.
