# Issue #128355 — Support font family picker in settings

[https://github.com/microsoft/vscode/issues/128355](https://github.com/microsoft/vscode/issues/128355)

## Summary

Thanks for the context. The merged font-snippet work gives system-font suggestions only in the JSON settings editor on desktop. The Settings UI combobox this issue asks for (preview and freeform entry) is still missing, so it stays open.

## Change summary

Offer system-font suggestions for font family settings in the Settings editor as a combobox that also allows freeform entry.

## Best solution

Add a combobox renderer in the settings editor for string settings that carry suggestions (defaultSnippets or similar), so font settings show a font dropdown plus freeform entry. Optionally add monospace filtering and a shared font service.
