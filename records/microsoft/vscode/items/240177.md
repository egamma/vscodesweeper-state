# Issue #240177 — Settings UI: Insert settings in alphabetical order

[https://github.com/microsoft/vscode/issues/240177](https://github.com/microsoft/vscode/issues/240177)

## Summary

Keep open: Settings UI writes still append new settings, and the built-in JSON sorting command does not provide automatic alphabetical insertion. The Backlog milestone records accepted work, so older decisions against JSON-editor enhancements do not justify declining this request.

## Change summary

Insert settings added through the Settings UI alphabetically in settings.json rather than appending them.

## Best solution

Resolve the insertion-order policy in the configuration-editing area, preserving manually organized settings and comments. The existing json.sort command offers a manual workaround but does not fulfill the requested default behavior.
