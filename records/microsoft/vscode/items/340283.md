# Issue #340283 — Add a setting to prevent Copilot from saving files before starting or continuing a session

## Summary

The exact setting requested already exists on main: `chat.saveBeforeSend` (boolean, default true) controls whether dirty editors are saved before a chat message is sent, mirroring `debug.saveBeforeStart`. Setting it to `false` delivers exactly what's asked.
