# Issue #310718 — Code executable has improper permissions under Red Hat Linux.

[https://github.com/microsoft/vscode/issues/310718](https://github.com/microsoft/vscode/issues/310718)

## Summary

Keep open for the Linux packaging owner: the report provides sufficient steps to retest the installed launcher permissions, but current RPM output has not been verified. This security-hardening concern also requires human review rather than an automated close.

## Change summary

Ensure the RPM-installed /usr/share/code/bin/code launcher is mode 0755 rather than group-writable 0775, including after updates.

## Best solution

Make fresh RPM installations and upgrades consistently deliver a root-owned, non-group-writable executable launcher. Verify the generated package metadata and installed symlink target on RHEL before deciding whether a packaging change is necessary.
