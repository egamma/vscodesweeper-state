## Summary

Keep open: current code can open test output as editor text, but that is not equivalent to relocating the Test Results output surface into an editor group. The accepted Backlog request has neither a verified canonical duplicate nor a concrete fixing commit supporting closure.

## Change summary

Allow test output to occupy the editor area independently of the panel's docking position, so wide output can be inspected without excessive wrapping.

## Best solution
