# Issue #326604 — Unexpected space in rendered markdown

[https://github.com/microsoft/vscode/issues/326604](https://github.com/microsoft/vscode/issues/326604)

## Summary

Root cause traced to the `@vscode/markdown-editor` npm dependency, not this repo's own code, and an open PR already documents it with a regression test — keep open as upstream and let that PR/dependency update land the fix.

## Change summary

In the Agents window's experimental hybrid Markdown editor (locked/rendered view), reference-style links render as a blank space instead of their link text.

## Best solution

Track the fix in `@vscode/markdown-editor`'s own (private) source repo and bump the dependency in extensions/markdown-language-features/package.json once a fixed version ships; land https://github.com/microsoft/vscode/pull/328363 (adds a failing regression test in extensions/markdown-language-features/src/test/markdownEditorLinks.test.ts) now to lock in the expected behavior, then flip it green with the dependency bump.
