# Issue #326489 — GitHub Copilot context window size difference of over 300K when switching models.

[https://github.com/microsoft/vscode/issues/326489](https://github.com/microsoft/vscode/issues/326489)

## Summary

This is a support question based on treating token usage as model-independent. The indicator displays usage reported for the latest model-specific request, so switching models can legitimately change the count without summarizing the stored conversation.

## Change summary

Explain why a conversation reports substantially different context-token usage after switching between two models with equal advertised context windows.

## Best solution

Clarify that the context indicator reflects each model's server-reported prompt and completion tokens, including model-specific tokenization and prompt construction, rather than a persistent model-neutral conversation size.

  > Thanks for the detailed context. The number shown is not a model-independent size of the stored conversation. It comes from the prompt and completion token usage reported for the latest request, so model-specific tokenization and prompt construction can produce substantially different counts even when both models advertise a 1M window. Disabling conversation summarization does not make those model-specific counts identical, and the count returning when switching back is consistent with this behavior. If you observe particular messages or tool results actually missing from the model's context, please open a focused bug with Chat Debug logs showing the omitted content.
