# Issue #205112 — Diff Editor: Hide Renames

[https://github.com/microsoft/vscode/issues/205112](https://github.com/microsoft/vscode/issues/205112)

## Summary

Keep open: existing diff settings do not suppress consistent word renames, and no verified canonical owns this request. This team-authored feature needs a product decision about what can safely be hidden during review.

## Change summary

Detect consistent word renames and suppress their repetitive differences so substantive changes remain easier to review.

## Best solution

Provide a reversible review mode that reduces consistent-rename noise without concealing unrelated edits or changing file contents. First establish the detection scope and how reviewers inspect suppressed changes.
