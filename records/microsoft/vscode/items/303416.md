# Issue #303416 — Modal settings editor and quick outline is weird

[https://github.com/microsoft/vscode/issues/303416](https://github.com/microsoft/vscode/issues/303416)

## Summary

Keep open as modal-editor positioning polish: quick outline still uses window-level placement rather than placement associated with the modal. The discussion acknowledges that this is existing quick-open behavior and suggests improving the modal case; no verified canonical or fixing commit was found.
