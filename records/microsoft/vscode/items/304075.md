# Issue #304075 — Copilot CLI Session (Agent Mode) fails with GHE

[https://github.com/microsoft/vscode/issues/304075](https://github.com/microsoft/vscode/issues/304075)

## Summary

Keep open: multiple users confirmed the GHE-specific CLI failure and endpoint workaround, but the proposed fix was closed without merging. Authentication now delegates to an SDK resolver, so the original steps suffice to retest; the inspected source and related fixes do not establish that this report is fully resolved.

## Change summary

Copilot CLI sessions should authenticate and discover models using the configured GitHub Enterprise account and endpoints, as ordinary Copilot Chat already does.

## Best solution

Ensure model discovery and CLI session creation consistently honor the configured enterprise host without requiring COPILOT_API_URL or GH_HOST workarounds. First distinguish the extension's in-process SDK path from the newer agent-host path and verify the remaining failure against the bundled SDK.
