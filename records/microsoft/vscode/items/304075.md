# Issue #304075 — Copilot CLI Session (Agent Mode) fails with GHE

[https://github.com/microsoft/vscode/issues/304075](https://github.com/microsoft/vscode/issues/304075)

## Summary

Confirmed still broken on main: `getAuthInfo()` in `copilotCli.ts` hardcodes `host: 'https://github.com'` in three places (lines 679, 681, 691), causing Copilot CLI sessions to fail for GitHub Enterprise users. PR #314724 was closed without merging; no other fix has landed.

## Change summary

Copilot CLI Session (Agent Mode) fails with GHE because the auth info passed to the SDK always uses a hardcoded `host: 'https://github.com'` instead of the configured `github-enterprise.uri`.

## Best solution

Update `CopilotCLISDK.getAuthInfo()` in `extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCli.ts` to read the host from the `github-enterprise.uri` setting when `authProvider === 'github-enterprise'`, and supply the correct `copilotUser.endpoints.api` URL (e.g. `copilot-api.<tenant>.ghe.com`) so the SDK can resolve models. The extension already has helpers for this (`kq()` for auth provider detection, `getNonExtensionConfig('github-enterprise.uri')` for the URI) — they just need to be wired into the CLI auth path.
