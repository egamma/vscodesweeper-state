# Issue #342470 — Copilot Agent session fails to start on macOS ARM64: runtime.node cannot load libruntime.dylib

[https://github.com/microsoft/vscode/issues/342470](https://github.com/microsoft/vscode/issues/342470)

## Summary

Keep open: the reporter and an independent commenter identify an unresolved native-runtime loading failure on Apple Silicon, including confirmation on 1.143.1. The evidence points to Copilot runtime dependency packaging; the related runtime-deduplication issue does not own this startup failure.

## Change summary

Ensure the bundled Copilot native runtimes load their required libraries on macOS ARM64 so Agent sessions can start.

## Best solution

Resolve the native runtime's nonportable dylib dependency in its producing build and ensure VS Code distributes the required assets for both bundled runtime paths. Verify the resulting signed macOS application starts Agent sessions without access to the runtime build machine's filesystem.
