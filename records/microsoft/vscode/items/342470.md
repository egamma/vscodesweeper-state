- **Independent confirmations:** The supplied discussion confirms the same absolute dependency in both bundled runtime locations on VS Code 1.143.1. - **Current consumption path:** src/vs/platform/agentHost/node/copilot/copilotRuntimePaths.ts:88-120 checks that the packaged executable, runtime.node and SDK exist, not whether Mach-O dependencies resolve. copilotAgent.ts:4922-4941 and 5005 use that bundled executable through RuntimeConnection.forStdio.
- **Packaging boundary:** build/lib/copilot.ts:215-250 includes the selected SDK platform package and checks required-file presence; materializeBuiltInCopilotSdkPlatformFiles copies version-matched native prebuilds into the built-in extension. These paths consume dependency-provided binaries and do not establish that their embedded dylib references are valid.
