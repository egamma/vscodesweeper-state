# Issue #345163 — "Reply immediately" after the agent has finished its reply cancels its running background subagents

[https://github.com/microsoft/vscode/issues/345163](https://github.com/microsoft/vscode/issues/345163)

## Summary

Keep open: the report and independent confirmation show background agents actually being aborted when a follow-up is sent immediately. Current source retains the session-wide cancellation path; the related steering issue describes a different observable failure.

## Change summary

Sending a message with Reply Immediately after the parent has answered cancels its still-running background agents.

## Best solution

Allow immediate follow-up messages after the parent finishes without terminating background subagents, while keeping runtime execution and displayed child status consistent. Establish the interruption boundary across the chat client, Agent Host, and Copilot SDK before implementing.
