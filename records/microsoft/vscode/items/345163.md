# Issue #345163 — "Reply immediately" after the agent has finished its reply cancels its running background subagents

[https://github.com/microsoft/vscode/issues/345163](https://github.com/microsoft/vscode/issues/345163)

## Summary

Keep open: the cancellation path still aborts the SDK session and completes active subagents, matching the reported permanent cancellation. The related steering issue explicitly concerns lost presentation state without runtime cancellation and does not absorb this report.

## Change summary

Sending an immediate follow-up after the foreground reply finishes permanently cancels still-running background subagents.

## Best solution

Allow a follow-up after foreground completion without aborting independent background subagents, while preserving cancellation of genuinely active foreground work. Establish the foreground-versus-session activity boundary across the chat client and Copilot provider before implementation.
