# Issue #282658 — managed model - Azure model is normal before upgrade using API key, but cannnot use after upgrade because of Microsoft Login is required

[https://github.com/microsoft/vscode/issues/282658](https://github.com/microsoft/vscode/issues/282658)

## Summary

The pre-release regression was confirmed, but current main now routes Azure models with configured API keys through API-key authentication rather than Microsoft sign-in. The concrete fix is commit b69754ceca51e327be67b5aeec09247b52edbf5d.

## Change summary

Azure BYOK models configured with an API key incorrectly requested Microsoft account authentication after upgrading Copilot Chat.

## Best solution

Keep the current per-model Azure BYOK authentication behavior from commit b69754ceca51e327be67b5aeec09247b52edbf5d, which selects API-key authentication whenever the model configuration contains an API key.
