# Issue #266015 — Pre-commit Problems detection comes up with false positives

[https://github.com/microsoft/vscode/issues/266015](https://github.com/microsoft/vscode/issues/266015)

## Summary

Keep open: the reporter confirmed recurring false positives, and the linked fix attempt was closed without merging. The discrepancy between an empty Problems view and diagnostics returned to the Git commit hook still needs diagnosis; no verified fix or canonical duplicate was found.

## Change summary

The pre-commit diagnostics check continues warning about problems after the reported errors have been fixed and the changes staged.

## Best solution

Make the built-in Git diagnostics commit hook reflect current diagnostics without suppressing genuine errors. Investigate the disagreement between the Problems view and languages.getDiagnostics for the affected file, including the maintainer's suggested TypeScript-server restart experiment, rather than assuming a fixed delay resolves it.
