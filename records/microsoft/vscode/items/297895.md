# Issue #297895 — Show progress indication for downloading update if it's taking a long time?

[https://github.com/microsoft/vscode/issues/297895](https://github.com/microsoft/vscode/issues/297895)

## Summary

Keep open: current update UI supports percentages and estimated time remaining, but the macOS updater does not supply the download measurements those displays require. The central request remains unmet on the reported platform, consistent with the maintainer's Electron dependency assessment.

## Change summary

Show meaningful progress during slow macOS update downloads, ideally including an approximate time remaining.

## Best solution

Expose real macOS update-download measurements through the Electron-backed update service and use the existing progress and time-remaining UI. Retain indeterminate feedback when measurements are unavailable rather than presenting an unsupported estimate.
