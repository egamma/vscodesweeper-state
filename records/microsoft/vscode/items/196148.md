# Issue #196148 — Aux window: allow to configure location and size of new windows opening

[https://github.com/microsoft/vscode/issues/196148](https://github.com/microsoft/vscode/issues/196148)

## Summary

Keep open: newly created auxiliary windows still use fixed default dimensions rather than a configurable sizing and placement policy. This issue already owns the work, including a later report closed as its duplicate; the default behavior needs a maintainer decision.

## Change summary

Allow users to configure the size and placement of newly opened auxiliary windows, including inheriting the active window's dimensions with an offset.

## Best solution

Provide a configurable auxiliary-window opening policy in the auxiliary window service, with explicit decisions about its relationship to main-window settings and its default. Preserve supplied bounds for restored windows and specialized callers.
