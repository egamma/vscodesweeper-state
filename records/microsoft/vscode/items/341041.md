# Issue #341041 — Deny All option for codex agents

[https://github.com/microsoft/vscode/issues/341041](https://github.com/microsoft/vscode/issues/341041)

## Summary

Thanks for the report. The Agents window already has a per-session Codex "Approvals" setting with a "No Escalations" option that maps to approvalPolicy 'never'. The reporter's actual complaint is that a config.toml `approval_policy = "never"` isn't honored and prompts still appear. That may be a real gap in how the host resolves session permissions, so I'm keeping this open rather than closing it.

## Change summary

Let Codex agents in the Agents window auto-deny approval requests (honoring approval_policy = "never") so long-running agents don't block on prompts.

## Best solution

Confirm whether the session's default approval policy, or the user's Codex config.toml, takes effect for new Agents-window sessions. If config.toml is ignored, honor it or make 'No Escalations' the documented path. If prompts still appear under 'never', clarify with the reporter which requests they are.
