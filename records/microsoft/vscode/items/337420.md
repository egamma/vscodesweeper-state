# Issue #337420 — Agents window hangs with thousands of binary text models and a stale origin/HEAD base branch

[https://github.com/microsoft/vscode/issues/337420](https://github.com/microsoft/vscode/issues/337420)

## Summary

Detailed, maintainer-observed freeze report (renderer ~200% CPU/8-9GB, extension host ~110% CPU) tied to a stale local origin/HEAD causing a huge (9,883-file) branch comparison and mass binary text-model creation in the Agents window, but the reporter explicitly has not isolated the causal code path or a CPU profile — keep open pending diagnosis; no canonical issue owns this exact combination of symptoms.

## Change summary

Agents window becomes unresponsive processing thousands of binary (PNG/GIF/MP4) resources as text models when a session's base-branch comparison is inflated by a stale origin/HEAD pointing at an old default branch.

## Best solution

Investigate two related but separable fixes: (1) make base-branch selection for a session resilient to a stale local origin/HEAD (prefer the hosted repo's actual default branch), and (2) bound/lazily load branch-changes diffs so eagerly materializing thousands of binary files as text models cannot freeze the renderer/extension host. A CPU profile of the hang is needed to pin the exact hot path before implementing.
