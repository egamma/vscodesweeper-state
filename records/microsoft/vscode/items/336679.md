## Summary

Legitimate, well-scoped follow-up filed by a VS Code collaborator: confirmed via the checkout that Agent Host telemetry, CLI telemetry, and the browser 1DS appender/health probe genuinely lack metered-connection wiring while the desktop path already has it — this stays open as real, unfinished work.

## Change summary

Extend metered-connection awareness (pausing telemetry sends/health probes, resuming when unmetered) to Agent Host, CLI, and browser-local telemetry collectors that were explicitly deferred from the prior desktop consolidation.
