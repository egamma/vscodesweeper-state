# Issue #336679 — Respect metered connections in Agent Host, CLI, and browser telemetry

[https://github.com/microsoft/vscode/issues/336679](https://github.com/microsoft/vscode/issues/336679)

## Summary

Keep open: current source confirms that the Agent Host, CLI, and browser-local telemetry collectors bypass metered-connection state. The open PRs provide prerequisite and adjacent infrastructure but explicitly defer these remaining collectors.

## Change summary

Prevent VS Code-owned Agent Host, CLI, and browser-local telemetry transports from probing or sending while the active connection is metered.

## Best solution

After the native metered-connection and core telemetry PR stack lands, propagate initialized metered state into each remaining collector, pause probes, queued retries, and shutdown flushes while metered, and verify pause/resume behavior with intercepted transport tests.
