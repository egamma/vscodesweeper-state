# Issue #331535 — MCP: Configure Model Access > Enable ALL models (vs. individually)

[https://github.com/microsoft/vscode/issues/331535](https://github.com/microsoft/vscode/issues/331535)

## Summary

Reasonable request: MCP sampling model access currently only supports an explicit list of model IDs, with no wildcard or 'allow all' shortcut, so users with many models (or synced settings across machines) end up with large, brittle allowedModels arrays. Routing to the MCP area for a product decision on wildcard/deny-list support.

## Change summary

Add a way to allow all (or wildcard-match) models for MCP sampling access instead of listing every model ID individually.

## Best solution

Extend IMcpServerSamplingConfig (src/vs/workbench/contrib/mcp/common/mcpConfiguration.ts) and the matching logic in McpSamplingService._getMatchingModelInner (src/vs/workbench/contrib/mcp/common/mcpSamplingService.ts) to support a wildcard/allow-all marker (e.g. an explicit 'allow all' toggle or `*/*`-style pattern) plus an optional deniedModels list, and add a corresponding 'Enable All' quick pick option in McpConfigureSamplingModels (src/vs/workbench/contrib/mcp/browser/mcpCommands.ts) so users aren't forced to enumerate every model ID.
