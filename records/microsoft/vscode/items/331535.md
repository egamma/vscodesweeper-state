# Issue #331535 — MCP: Configure Model Access > Enable ALL models (vs. individually)

[https://github.com/microsoft/vscode/issues/331535](https://github.com/microsoft/vscode/issues/331535)

## Summary

The requested persistent access to all current and future models remains missing: selecting all models saves individual IDs, and sampling does not interpret wildcards. Keep this request open; the verified related issues do not own the same capability.

## Change summary

Allow per-server MCP sampling access to all current and future models without maintaining an explicit model list, optionally supporting provider wildcards and exclusions.

## Best solution

Provide an explicit, opt-in per-server model-access mode that includes future models while preserving existing explicit allowlists and sampling-consent controls. Decide whether provider-scoped patterns and exclusions belong in that contract before expanding the configuration.
