# Issue #331535 — MCP: Configure Model Access > Enable ALL models (vs. individually)

[https://github.com/microsoft/vscode/issues/331535](https://github.com/microsoft/vscode/issues/331535)

## Summary

Legitimate, fresh feature request: MCP's `allowedModels` config only supports exact model-ID matches today, with no wildcard or 'allow all' option, confirmed by reading the matching logic — routing to the MCP area for product consideration.

## Change summary

Add a way to allow all (current and future) models for an MCP server, e.g. via a wildcard (`*/*`) or an 'enable all' toggle, instead of listing every model ID individually in `allowedModels`.

## Best solution

Extend the MCP model-access config (src/vs/workbench/contrib/mcp/common/mcpSamplingService.ts, mcpConfiguration.ts) to support wildcard patterns or an explicit allow-all flag in `allowedModels`, and correspondingly simplify the 'Configure Model Access' quick pick UI in mcpCommands.ts to offer an 'Allow all models' choice instead of forcing per-model checkboxes.
