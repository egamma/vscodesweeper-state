# Issue #325990 — vs.commands.executeCommand("vscode.executeCodeActionProvider") loses keepWhitespace field from SnippetTextEdits

[https://github.com/microsoft/vscode/issues/325990](https://github.com/microsoft/vscode/issues/325990)

## Summary

Confirmed bug on current main: the `WorkspaceEdit.to` converter does not carry over `keepWhitespace` from the DTO when reconstructing a `SnippetTextEdit`, so the field is always lost when round-tripping through `executeCodeActionProvider`.

## Change summary

The `keepWhitespace` field on `SnippetTextEdit` is dropped when a `WorkspaceEdit` is deserialized back to extension types via `WorkspaceEdit.to`.

## Best solution

In `WorkspaceEdit.to` (extHostTypeConverters.ts ~line 725), after creating the `SnippetTextEdit`, set `editOrSnippetTest.keepWhitespace = item.textEdit.keepWhitespace` when `insertAsSnippet` is true.
