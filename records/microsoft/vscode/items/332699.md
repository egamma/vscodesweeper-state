# Issue #332699 — Agents window: Windows custom close button has gap

[https://github.com/microsoft/vscode/issues/332699](https://github.com/microsoft/vscode/issues/332699)

## Summary

The gap remains on current main: the Agents workbench deliberately insets its shared grid from the right edge, and that grid contains the title bar, leaving the custom Windows close control short of the screen corner.

## Change summary

Make the Agents window's custom Windows close button reach the top-right corner so it is easy to target by moving the pointer to the screen edge.

## Best solution

Keep the floating-panel gutter for content surfaces while allowing the title bar's custom Windows controls—and specifically the close hit target—to reach the native window edge.
