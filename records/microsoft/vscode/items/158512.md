# Issue #158512 — Merge editor button missing hover state

[https://github.com/microsoft/vscode/issues/158512](https://github.com/microsoft/vscode/issues/158512)

## Summary

The visual gap remains on current main: the merge editor uses the shared Toggle widget, but merge-specific background styling masks its standard hover background. This is bounded interaction polish and should remain open in the editor-contrib backlog.

## Change summary

Give the merge editor's accept-conflict gutter toggle a visible hover state consistent with other interactive controls.

## Best solution
