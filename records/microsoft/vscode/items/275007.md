# Issue #275007 — "files to include" doesn't work with folder names containing glob characters

[https://github.com/microsoft/vscode/issues/275007](https://github.com/microsoft/vscode/issues/275007)

## Summary

Keep open: current source supports bracket escaping, but that does not establish that the reported include-field failure is resolved. The supplied patterns and failed character-class escape attempt provide enough context for a focused retest; neither a fixing commit nor an eligible duplicate canonical was established.

## Change summary

Searching within directories containing literal glob characters fails through the Search view's files-to-include field, reportedly even with bracket escaping.

## Best solution

Establish whether correctly escaped complete directory paths reach the text-search backend and return the expected contents. Preserve existing glob syntax, distinguish exact-directory matching from prefix matching, and address any demonstrated failure in the search query or backend translation path.
