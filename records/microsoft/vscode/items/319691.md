# Issue #319691 — Copilot Chat: Editing model on historical message is ignored when regenerating — always falls back to bottom selector model

[https://github.com/microsoft/vscode/issues/319691](https://github.com/microsoft/vscode/issues/319691)

## Summary

This exact model-selection regression was fixed after the report. Current main captures the historical message editor's selected model before tearing down that editor and gives it precedence over the bottom composer model.

## Change summary

Regenerating an edited historical chat message ignored that message's selected model and used the bottom composer model instead.

## Best solution

Keep the implemented behavior from commit 2811a79f93d12ecff6f05bc8c6302368d7fc3beb: regeneration uses the historical message editor's model selection, independently of the bottom selector.
