# Issue #329639 — Bring back all caps separators for views and root folder

[https://github.com/microsoft/vscode/issues/329639](https://github.com/microsoft/vscode/issues/329639)

## Summary

Reasonable design feedback tied to the experimental Modern UI redesign; no maintainer has weighed in on whether to restore stronger visual differentiation for stacked view/section headers, so this stays open for design/UX judgment.

## Change summary

Restore all-caps (or another strongly differentiated) styling for individual view/section headers (e.g. Outline, Timeline) inside the sidebar, which now render in normal case under the new design and are harder to visually scan against files/folders.

## Best solution

UX/design owners should decide whether stacked pane section headers (src/vs/workbench/browser/parts/views/media/paneviewlet.css, `h3.title`) need a differentiator — could be uppercase, but also font-weight, letter-spacing, or color, especially given the Feb 2026 a11y contrast fix (commit 5bb327de4bf) that already touched description text in this same file; any change must not regress that contrast fix or the 2022 decision (commit e0e194d4050) that intentionally scoped uppercase away from per-view titles.
