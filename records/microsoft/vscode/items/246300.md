# Issue #246300 — No remote SSH for Synology NAS servers: The remote host may not meet VS Code Server's prerequisites for glibc and libstdc+

## Summary

Keep open: multiple reporters confirm that prerequisite detection blocks otherwise working Synology connections. The current CLI contains a detection path consistent with the reported misleading musl error, but neither a fixing commit nor an open canonical was established.

## Change summary

Remote SSH rejects Synology hosts whose glibc and libstdc++ meet the server requirements.

## Best solution

Make server prerequisite detection accurately recognize qualifying GNU/Linux hosts without requiring the skip-check workaround, while preserving minimum-version enforcement. Diagnose the CLI detection path using complete connection logs and the affected host's library-discovery output before choosing a fix.
