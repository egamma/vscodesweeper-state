# Issue #330384 — Expose Max thinking effort for Luna 5.6 in the Copilot harness

[https://github.com/microsoft/vscode/issues/330384](https://github.com/microsoft/vscode/issues/330384)

## Summary

Already fixed on main: the Copilot harness's reasoning-effort picker filters against a shared `reasoningEffortLevels` list that already includes `'max'`, fixed by PR #329167 a week before this report was filed.

## Change summary

The Copilot harness doesn't offer the `Max` thinking-effort option for Luna 5.6 even though the Local harness does.

## Best solution

Keep the shipped fix from commit f4a4c4825bb5c0c7f46e67aacf245ca0515bb0cd (PR #329167, merged 2026-08-05) — `isCopilotReasoningEffort` now derives from the canonical `reasoningEffortLevels` list (which includes `'max'`) instead of a private copy that silently dropped it, so the Copilot harness picker surfaces `Max` whenever the model's `supportedReasoningEfforts` advertises it.
