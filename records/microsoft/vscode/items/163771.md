# Issue #163771 — accessibility: Can the high contrast theme be much more high contrast

[https://github.com/microsoft/vscode/issues/163771](https://github.com/microsoft/vscode/issues/163771)

## Summary

Valid accessibility feedback requesting stronger contrast in the built-in HC Dark theme — particularly for list selections, current line, bracket matching, and tooltips. A team member acknowledged it but no substantial contrast improvements have landed for these specific areas. Keeping open as actionable accessibility work.

## Change summary

The built-in Dark High Contrast theme uses subtle borders/outlines (e.g. orange lines) instead of solid high-contrast backgrounds for selections, focus indicators, and highlights, making them hard to distinguish for low-vision users.

## Best solution

Audit and revise the HC Dark theme defaults for list focus/selection backgrounds, editor current-line highlighting, bracket match backgrounds, and suggest-widget styling to use solid, high-contrast fills rather than subtle borders — aligning more closely with OS-level HC conventions. The theme file is `extensions/theme-defaults/themes/hc_black.json` and the workbench color defaults live in `src/vs/platform/theme/common/colorRegistry.ts` (HC branches).
