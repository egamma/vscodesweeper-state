# Issue #163771 — accessibility: Can the high contrast theme be much more high contrast

[https://github.com/microsoft/vscode/issues/163771](https://github.com/microsoft/vscode/issues/163771)

## Summary

Keep open for an accessibility-led review of the built-in high-contrast defaults. Current source still uses unfilled selection and current-line backgrounds in the reported dark-theme paths, and the maintainer welcomed improvements; customization options do not resolve the request for usable defaults.

## Change summary

Improve high-contrast defaults so focused items, the current line, matching brackets, diagnostics, and signature help are easier to distinguish.

## Best solution

Agree on a coherent high-contrast visual hierarchy with affected users, making focus clearly distinguishable from search matches and diagnostics while preserving text readability. Apply the agreed treatment consistently to the built-in themes and shared color defaults rather than requiring individual users to assemble overrides.

- **Trace:**
