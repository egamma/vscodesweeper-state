# Issue #284225 — Don't show NES when making a selection

[https://github.com/microsoft/vscode/issues/284225](https://github.com/microsoft/vscode/issues/284225)

## Summary

Team-authored bug about NES appearing during text selection. A related fix (54b254b0a0d) prevents completions from triggering on selection change in the joint provider, but NES itself may still trigger in that path. No commit references this issue directly, so it stays open.

## Change summary

NES (Next Edit Suggestions) should not appear when the user is making a text selection.

## Best solution

Ensure the joint inline completion provider also suppresses NES triggers (not just completions) when the selection is non-empty, complementing the existing guard in `inlineEditTriggerer.ts` line 135. The fix likely belongs in `extensions/copilot/src/extension/inlineEdits/vscode-node/jointInlineCompletionProvider.ts`.
