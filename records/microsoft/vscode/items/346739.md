# Issue #346739 — Go to Symbol in Editor: can it function in Markdown Preview?

[https://github.com/microsoft/vscode/issues/346739](https://github.com/microsoft/vscode/issues/346739)

## Summary

Keep open as a feature request: searchable heading navigation in Markdown Preview remains distinct from navigation in the source or Markdown Editor. Related outline/API requests do not establish a verified duplicate covering this preview workflow.

## Change summary

Make Go to Symbol in Editor list and navigate Markdown headings while Markdown Preview is active.

- **Existing-capability check:** extensions/markdown-language-features/package.json exposes markdown.showPreview, markdown.showSource and markdown.preview.scrollPreviewWithEditor, but no preview heading picker. Source navigation with synchronized preview scrolling is a workaround, not navigation while the preview itself remains active.
- **Preview/editor distinction:** extensions/markdown-language-features/src/preview/previewManager.ts registers the traditional preview separately from MarkdownEditorProvider in src/extension.shared.ts. src/test/markdownEditorNavigation.test.ts covers the latter's outline navigation, not the traditional Markdown Preview.
- **Workbench integration:** src/vs/workbench/contrib/codeEditor/browser/quickaccess/gotoSymbolQuickAccess.ts routes non-text-editor symbol picking through IOutlineService when the active editor can provide an outline. Its existence alone does not supply Markdown Preview with heading navigation.

It requests CustomTextEditor document-symbol support, mentioning Markdown preview and symbol navigation, but does not establish that the traditional preview's searchable heading workflow is owned or delivered there; it is related rather than a verified same-symptom canonical.
- **Related preview request:** https://github.com/microsoft/vscode/issues/342919 requests the Outline sidebar in Markdown Preview and distinguishes it from Markdown Editor navigation. That sidebar request does not explicitly cover this report's searchable Go to Symbol picker, so it does not clear the stronger duplicate bar for a re-reviewed item.
