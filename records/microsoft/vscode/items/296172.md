# Issue #296172 — Tool picker live-syncs to running agent session

[https://github.com/microsoft/vscode/issues/296172](https://github.com/microsoft/vscode/issues/296172)

## Summary

Keep open: the discussion confirms cross-session tool changes affecting running agents, and current source still combines global picker state with live request updates. Existing session-switch guards provide partial isolation, but do not establish the more conservative running-loop behavior requested here.

## Change summary

Prevent tool-picker changes in another session from changing the tools available to an already-running agent.

## Best solution

Isolate running requests from unrelated sessions' tool-selection changes while retaining deliberate support for tools discovered during execution. Settle which live changes are allowed before changing the request-tool synchronization contract.
