# Issue #116540 — [json] support link on $ref for external references

[https://github.com/microsoft/vscode/issues/116540](https://github.com/microsoft/vscode/issues/116540)

## Summary

The requested external `$ref` links remain unsupported on current main. The missing capability is owned primarily by the JSON language service, so this should stay open and be classified as upstream rather than closed.

## Change summary

Make syntactically valid external JSON Schema `$ref` values clickable and resolve them to the referenced file and fragment.

## Best solution

Add external-reference document-link support to https://github.com/microsoft/vscode-json-languageservice, including deferred target resolution, then wire document-link resolution into VS Code's JSON language server and update the bundled dependency.

## Evidence

- **current VS Code path:** extensions/json-language-features/server/src/jsonServer.ts registers document links but only delegates to `languageService.findLinks`; its capability declaration explicitly sets `resolveProvider: false`, and there is no `onDocumentLinkResolve` handler.
- **upstream source gap:** The current https://github.com/microsoft/vscode-json-languageservice implementation in `src/services/jsonLinks.ts` resolves same-document JSON pointers, anchors, and embedded `$id` schemas, but does not load or target an external document.
- **maintainer direction:** Maintainer comments on https://github.com/microsoft/vscode/issues/116540 identify https://github.com/microsoft/vscode-json-languageservice as the owning implementation and outline deferred resolution through LSP `documentLink/resolve`; that design remains unwired on main.
- **canonical search:** https://github.com/microsoft/vscode/issues/138546 is newer and requests navigation from a JSON instance into its associated schema, not external `$ref` links within a schema, so it does not satisfy the stronger same-symptom duplicate bar for this re-reviewed issue.
- **related item:** https://github.com/asyncapi/studio/issues/528 concerns file-reference support in AsyncAPI Studio and neither owns nor replaces VS Code's JSON document-link work.
