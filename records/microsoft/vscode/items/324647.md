# Issue #324647 — cmd+shift+A should toggle agents/editor windows

[https://github.com/microsoft/vscode/issues/324647](https://github.com/microsoft/vscode/issues/324647)

## Summary

Current main still chooses an arbitrary editor window rather than the most recently focused one, so the requested toggle behavior remains necessary. This team-authored Agents Window polish should stay open for a bounded focus-selection change.

## Change summary

Make Cmd+Shift+A toggle from the Agents Window back to the editor window the user most recently used.

## Best solution

Have the return action focus the most recently active non-Agents main window, opening a new editor window only when none exists, while preserving the current shortcut and Linux conflict handling.
