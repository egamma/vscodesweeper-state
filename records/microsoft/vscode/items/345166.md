# Issue #345166 — Remember last used mode in new chat sessions

[https://github.com/microsoft/vscode/issues/345166](https://github.com/microsoft/vscode/issues/345166)

## Summary

The harness switch is an intentional, configurable preference. The reporter confirmed that disabling it delivers their desired New Chat behavior and explicitly accepted closure; the later commenter also confirmed the setting works.

## Change summary

Preserve the user's preferred harness and mode when starting a new chat instead of switching to Copilot and Ask.

## Best solution

Use chat.editor.preferCopilotHarness=false to retain the remembered Local harness. Close this resolved configuration report without treating it as evidence of a separate, confirmed Ask-mode persistence defect.
