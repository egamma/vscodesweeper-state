# Issue #323501 — Thinking effort not remembered for Copilot CLI

[https://github.com/microsoft/vscode/issues/323501](https://github.com/microsoft/vscode/issues/323501)

## Summary

Team-authored bug report about thinking effort not persisting per-session when switching between Copilot CLI chats in the Agents window. No fix found on main; stays open.

## Change summary

Switching back to a previous Copilot CLI chat session loses its originally-chosen thinking effort level, adopting the most-recently-set value instead.

## Best solution

The ChatModelConfigurationStore (or its session-level equivalent in the Agents window) needs to persist thinking effort per session rather than sharing a single mutable value across sessions. The fix likely lives in the session/widget lifecycle in `src/vs/workbench/contrib/chat/browser/widget/input/chatModelConfigurationStore.ts` or how sessions restore their model configuration.
