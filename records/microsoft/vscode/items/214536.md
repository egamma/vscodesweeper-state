# Issue #214536 — Anchor Selection with Search and Replace not working correctly

[https://github.com/microsoft/vscode/issues/214536](https://github.com/microsoft/vscode/issues/214536)

## Summary

Verified duplicate: the open, older issue https://github.com/microsoft/vscode/issues/192388 tracks the same loss of the intended selection when users enter a query before enabling Find in Selection.

## Change summary

Find and Replace uses a search-result selection instead of the range created with Selection Anchor, producing incorrect replacements and announcements.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/192388 and preserve the user's original selection as the scope when Find in Selection is enabled after entering a query.
