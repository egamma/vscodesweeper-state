# Issue #209653 — Command to "Run cells in section" for current cell's section in notebook.

[https://github.com/microsoft/vscode/issues/209653](https://github.com/microsoft/vscode/issues/209653)

## Summary

The core request — invoking 'Run Cells in Section' from the command palette or a keyboard shortcut for the currently focused cell — is still unimplemented on main. The command exists but only works when invoked with outline-entry or cell-toolbar context; it silently no-ops from the palette.

## Change summary

Add command-palette and keyboard-shortcut support for running all cells in the focused cell's notebook section.

## Best solution

Extend `NotebookRunCellsInSection.run()` in `src/vs/workbench/contrib/notebook/browser/controller/sectionActions.ts` with a fallback path: when no outline/cell context is provided, resolve the active notebook editor and its focused cell, look up the enclosing section via `getFoldingStartIndex`, and execute. This would make the command work from the command palette and allow keyboard-shortcut binding.
