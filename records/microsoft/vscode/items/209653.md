# Issue #209653 — Command to "Run cells in section" for current cell's section in notebook.

[https://github.com/microsoft/vscode/issues/209653](https://github.com/microsoft/vscode/issues/209653)

## Summary

Keep open: markdown-cell toolbar support now covers part of the request, but the existing section command still requires menu-provided context and does not resolve the active cell when invoked through a keyboard shortcut. The matching open report is newer, so it cannot replace this older, re-reviewed request.

## Change summary

Expose section execution through the command palette and keyboard shortcuts, deriving the sections from the active or selected notebook cells.

## Best solution

Make section execution available without outline or toolbar arguments, using the active or selected cells to identify the sections while preserving existing menu behavior. Retain this issue as the older request and cross-reference the matching keyboard-invocation report.
