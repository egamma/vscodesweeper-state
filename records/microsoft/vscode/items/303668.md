# Issue #303668 — Terminal: Run Active File In Active Terminal fails when folder name contains a "~"

[https://github.com/microsoft/vscode/issues/303668](https://github.com/microsoft/vscode/issues/303668)

## Summary

Confirmed on current main: `escapeNonWindowsPath` strips `~` from paths as a 'banned character', breaking any path containing a literal tilde (e.g. macOS iCloud's `com~apple~CloudDocs`).

## Change summary

Terminal: Run Active File In Active Terminal fails when the file path contains a literal `~` because it is stripped by the path-escaping function.

## Best solution

Remove `~` from the `bannedChars` regex in `src/vs/platform/terminal/common/terminalEnvironment.ts` (line 69). Within single quotes, `~` is already literal and harmless — it only expands unquoted at the start of a word, but this function always wraps the path in quotes. The fix is a one-character regex change plus a test asserting paths with interior tildes are preserved.
