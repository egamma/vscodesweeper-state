# Issue #241636 — Lifecycle Management VSCode snap to core24 ::  Java 21 applications crashing when run from inside VSCode

[https://github.com/microsoft/vscode/issues/241636](https://github.com/microsoft/vscode/issues/241636)

## Summary

Still reproduces on main: the snap's `snapcraft.yaml` still declares `base: core20`, which bundles ancient glibc libraries that conflict with system-installed Java 21 on Ubuntu 24.04. An open PR (#298237) appears to address this, and a team member is engaged.

## Change summary

Java 21 applications crash with a glibc symbol lookup error when run from VS Code's integrated terminal in the snap package because the snap uses the outdated core20 base.

## Best solution

Migrate the snap base from core20 to at least core22 (or core24) in `resources/linux/snap/snapcraft.yaml` — PR https://github.com/microsoft/vscode/pull/298237 is already open for this. Landing that PR resolves the library mismatch.
