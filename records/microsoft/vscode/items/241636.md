# Issue #241636 — Lifecycle Management VSCode snap to core24 ::  Java 21 applications crashing when run from inside VSCode

[https://github.com/microsoft/vscode/issues/241636](https://github.com/microsoft/vscode/issues/241636)

## Summary

Keep open while the linked Snap packaging PRs are reviewed: independent reports confirm host applications failing with core20 library conflicts, and current main still uses core20. No verified landed fix resolves this runtime failure.

## Change summary

Prevent applications launched from the Snap installation's integrated terminal from loading incompatible Snap libraries and failing with GLIBC_PRIVATE symbol errors.

## Best solution

Review and coordinate the existing Snap packaging proposals, then verify that Java 21 and other host applications launch without mixed-library failures on Ubuntu 24.04. Updating the base alone should not be treated as proof that terminal environment contamination is resolved.
