# Issue #187627 — Realtime Performance icons always show up when the view is visible

[https://github.com/microsoft/vscode/issues/187627](https://github.com/microsoft/vscode/issues/187627)

## Summary

The always-visible actions on webview views (when expanded) were an intentional trade-off for discoverability (PR #185864, refined by commit e98bfca164b). The team agreed the ideal fix is detecting hover inside the webview and exposing it to the main frame, but that work hasn't landed. Still a valid polish item.

## Change summary

Debug sidebar's realtime performance icons (webview view actions) are always visible when the view is expanded, rather than appearing only on hover.

## Best solution

Implement hover-state communication from webview to the main frame so webview view actions can follow the same show-on-hover pattern as tree views. The change would likely live in `src/vs/workbench/contrib/webviewView/browser/webviewViewPane.ts` and the webview's iframe messaging layer.
