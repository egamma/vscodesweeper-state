# Issue #100856 — Extension doesn't activate after install

[https://github.com/microsoft/vscode/issues/100856](https://github.com/microsoft/vscode/issues/100856)

## Summary

The requested improvements — a user-visible notification on extension activation failure and showing failed extensions in the Running Extensions view — are not yet implemented on main. The activation error handler still only logs telemetry, and the Running Extensions view still filters to `activationStarted === true`. Keeping open as a valid, unaddressed feature request from a team member.

## Change summary

Improve the UX when an extension fails to activate: show a notification to the user and indicate failure in the Running Extensions view.

## Best solution

Add a user-facing notification in `_onDidActivateExtensionError` (abstractExtensionService.ts) and extend `IExtensionsStatus` with an activation error field so the Running Extensions editor (abstractRuntimeExtensionsEditor.ts) can display failed extensions with an error indicator instead of hiding them.
