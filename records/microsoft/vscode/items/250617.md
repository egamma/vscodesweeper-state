# Issue #250617 — Find in selection finds no results with multipline lines selected

[https://github.com/microsoft/vscode/issues/250617](https://github.com/microsoft/vscode/issues/250617)

## Summary

The stale-selection behavior is already tracked by an older, verified open issue with the same observable symptoms. Consolidate there; its linked fix candidate remains open, so this is not a completed-fix proposal.

## Change summary

Find in Selection retains an earlier selection instead of searching and replacing within the newly selected lines.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/237774 and review its implementation candidate, https://github.com/microsoft/vscode/pull/331038, against both selection changes and entering search text before enabling the selection scope.
