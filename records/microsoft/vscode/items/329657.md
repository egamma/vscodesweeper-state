# Issue #329657 — Include cache creation (write) tokens in Copilot Chat debug-log main.jsonl llm_request events

[https://github.com/microsoft/vscode/issues/329657](https://github.com/microsoft/vscode/issues/329657)

## Summary

The requested cache-write count is still missing from main.jsonl llm_request events, even though the underlying chat spans already carry it. Keep this request open; the verified related issues cover cache reads or exported metrics, not this remaining file-log capability.

## Change summary

Include provider-reported cache creation token counts separately from cache reads in Copilot Chat main.jsonl llm_request events.

## Best solution

Expose the available cache-creation count in the existing ChatDebugFileLoggerService llm_request attributes without changing inputTokens, outputTokens, or cachedTokens semantics. Preserve the distinction between unavailable usage and reported counts, and avoid treating token estimates as authoritative Copilot billing.
