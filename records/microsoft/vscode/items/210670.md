# Issue #210670 — Restarting extensions messes the script order in npm scripts pane in the folder side bar.

[https://github.com/microsoft/vscode/issues/210670](https://github.com/microsoft/vscode/issues/210670)

## Summary

Still reproduces on main: `sortTaskTree` only sorts the top-level tree array, not the child `packages` or `scripts` arrays returned by `getChildren`. An open PR (https://github.com/microsoft/vscode/pull/281932) already targets this fix but has not merged.

## Change summary

Restarting extensions scrambles the npm script order in the sidebar because child arrays (packages, scripts) are not sorted in `getChildren`.

## Best solution

Land or close https://github.com/microsoft/vscode/pull/281932, which adds sorting to the `packages` and `scripts` child arrays in `NpmScriptsTreeDataProvider.getChildren` in `extensions/npm/src/npmView.ts`.
