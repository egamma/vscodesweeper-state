# Issue #284959 — Copilot silently corrupts long attached files

[https://github.com/microsoft/vscode/issues/284959](https://github.com/microsoft/vscode/issues/284959)

## Summary

Keep open: multiple users confirm that explicit file attachments are silently summarized, and the discussion still has an unresolved product decision about whether attachments should be passed verbatim, visibly truncated, or represented only by paths for agentic discovery. The On Deck milestone does not block cleanup, but the latest June confirmation shows that the behavior and its prompt-cache side effects remain current.

## Change summary

Make handling of long, explicitly attached chat files reliable and transparent instead of silently replacing substantial content with omission markers.

## Best solution

Choose and validate a consistent attachment contract across chat modes: either preserve user-selected content within a documented budget, disclose every truncation before sending, or pass paths with a clear requirement that capable agents read them. The solution should also keep the cacheable prompt prefix stable and provide an intentional fallback for modes or models without file-reading tools.
