# Issue #327304 — Feature: Read MCP server config from ~/.copilot/mcp-config.json (Copilot CLI user config)

[https://github.com/microsoft/vscode/issues/327304](https://github.com/microsoft/vscode/issues/327304)

## Summary

A real interoperability gap remains: current main discovers several external user-level MCP configurations but not Copilot CLI's configuration. Route this to MCP ownership as a feature request.

## Change summary

Make MCP servers configured in `~/.copilot/mcp-config.json` available to VS Code without duplicating their configuration.

## Best solution

Add a Copilot CLI discovery source and native adapter for `~/.copilot/mcp-config.json`, following the existing opt-in `chat.mcp.discovery.enabled` pattern and reusing the existing `mcpServers` parser.
