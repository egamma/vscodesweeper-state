# Issue #231728 — Inlay hint flicker when adding/removing whitespace around it

[https://github.com/microsoft/vscode/issues/231728](https://github.com/microsoft/vscode/issues/231728)

## Summary

Confirmed and assigned: jrieken reproduced the inlay hint width flicker when adding/removing whitespace near a hint (Comment 8). The fixed-length mechanism from PR #227377 does not fully prevent the transient truncation ('numbe…' → 'number'). No fix has landed; stays open for the assignee.

## Change summary

Inlay hints briefly flicker (truncate to ellipsis and back) when adding or removing whitespace adjacent to them, despite the fixed-length stabilization mechanism.

## Best solution

Refine the fixed-length stabilization logic in `src/vs/editor/contrib/inlayHints/browser/inlayHintsController.ts` (`_updateHintsDecorators`) so that when a hint's new label matches the old label text, its width is preserved without a transient truncation pass — likely by comparing the incoming hint label against the cached decoration content before applying the fixed-length trim.
