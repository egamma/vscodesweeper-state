# Issue #64317 — Loaded scripts: session and folder should be a bit more distinguishable

[https://github.com/microsoft/vscode/issues/64317](https://github.com/microsoft/vscode/issues/64317)

## Summary

The Loaded Scripts hierarchy still needs a clearer visual distinction between debug-session roots and source-folder nodes, especially with icon themes that do not expose the existing icon difference. The Backlog milestone, `under-discussion` label, and lack of a settled presentation argue for keeping this open as debug UI polish.

## Change summary

Make debug sessions and folders easier to distinguish in the Loaded Scripts view when multiple sessions are active.

## Best solution

Keep the hierarchy structurally unchanged while giving session roots a consistent, theme-independent identity through their accessible label and visible presentation; the debug area should choose wording or decoration that does not make ordinary folder paths misleading.
