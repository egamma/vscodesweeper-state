# Issue #320566 — Roo Code on Win11 - Codebase Indexing "Error - Failed during initial scan: Could not find ripgrep binary"

[https://github.com/microsoft/vscode/issues/320566](https://github.com/microsoft/vscode/issues/320566)

## Summary

The failure is in the third-party Roo Code extension, which still looks for VS Code's former internal `@vscode/ripgrep` path after the package moved to `@vscode/ripgrep-universal`. This should be handled by the extension publisher rather than VS Code core.

## Change summary

Restore Roo Code codebase indexing after its bundled ripgrep lookup fails in local and remote environments.

## Best solution

Roo Code should stop relying on VS Code's private node_modules layout and resolve or bundle ripgrep through a stable extension-owned mechanism; users should not need to create compatibility symlinks inside VS Code installations.
