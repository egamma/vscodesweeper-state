# Issue #301248 — Bottom border under breadcrumbs is too distracting

[https://github.com/microsoft/vscode/issues/301248](https://github.com/microsoft/vscode/issues/301248)

## Summary

The distracting light-theme separator remains in current source, and a maintainer has explicitly endorsed removing it in a related report. Keep this older issue open: both matching reports are newer and cannot serve as duplicate targets under the re-review rules.

## Change summary

Remove the persistent bottom border beneath breadcrumbs so it does not compete with editor content in Light+.

## Best solution

Breadcrumbs should remain visually quiet at rest, without the light-theme-only bottom border, following the maintainer's approved direction. Preserve breadcrumb navigation, editor scroll shadows, and unrelated widget borders.
