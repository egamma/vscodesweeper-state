# Issue #307824 — Git: Clone wizard skips destination folder selection step in VS Code Insiders

[https://github.com/microsoft/vscode/issues/307824](https://github.com/microsoft/vscode/issues/307824)

## Summary

The single-cached-clone path still bypasses destination selection on current main, consistent with the maintainer's confirmation. Keep this issue open while the explicitly linked fixing PR is reviewed; the available evidence does not establish the report's broader claim for arbitrary repositories.

## Change summary

Git: Clone skips the destination picker and prevents creating another working copy when exactly one existing clone is cached.

## Best solution

Preserve the option to open an existing clone while allowing users to choose Clone again and select a new destination even when only one clone exists. Review and resolve https://github.com/microsoft/vscode/pull/309247 rather than starting a competing implementation.
