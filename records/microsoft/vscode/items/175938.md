# Issue #175938 — Explore using CSS highlighting API for HighlightedLabel

[https://github.com/microsoft/vscode/issues/175938](https://github.com/microsoft/vscode/issues/175938)

## Summary

Still a valid debt/perf improvement — the CSS Custom Highlight API has not been adopted in HighlightedLabel on current main, and the exploratory PR #175941 remains open. Keeping open for the area owner.

## Change summary

Replace per-range DOM span nodes in HighlightedLabel with the CSS Custom Highlight API to reduce DOM node count and avoid full re-renders on highlight changes.

## Best solution

Land or close the exploratory PR (https://github.com/microsoft/vscode/pull/175941) once the Chromium bugs cited in the comments are resolved; the CSS Custom Highlight API is now broadly supported in Chromium and has matured since 2023, so the exploration is worth revisiting.
