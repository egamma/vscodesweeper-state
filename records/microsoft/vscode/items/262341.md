# Issue #262341 — Update tool confirmation actions

[https://github.com/microsoft/vscode/issues/262341](https://github.com/microsoft/vscode/issues/262341)

## Summary

Current main partially addresses this request with Allow/Allow Once labels and promotion of session approval in generic confirmations, but does not fully address discoverability and collaborative redirection. Keep this team-authored Backlog request open for a focused design decision, informed by the terminal adoption evidence in the discussion.

## Change summary

Make tool confirmation actions clearer, expose remembered approvals more readily, and make suggesting an alternative approach discoverable.

## Best solution

Agree on a consistent, keyboard-accessible confirmation interaction across generic and terminal tools that clearly distinguishes one-time approval, remembered approval, and steering the agent. Resolve whether steering answers the pending confirmation or leaves it pending before implementing the remaining UX.
