# Issue #9936 — Allow to bring up a dialog with multiple inputs

[https://github.com/microsoft/vscode/issues/9936](https://github.com/microsoft/vscode/issues/9936)

## Summary

The API gap remains: extensions can implement sequential wizard steps, but cannot display multiple editable fields together. This Backlog request has 33 community upvotes and is the canonical issue for the capability.

## Change summary

Allow extensions to collect several text or selection values in one native dialog.

## Best solution

Design a compact multi-field Quick Input API, preserving native accessibility and validation while avoiding webview-based forms. The API and bridge would likely span `src/vscode-dts/vscode.d.ts`, `src/vs/workbench/api/common/extHostQuickOpen.ts`, and `src/vs/workbench/api/browser/mainThreadQuickOpen.ts`.

## Vision fit

- **Fit:** aligned
- **Reason:** A native form API would let extensions deliver specialized workflows without adding those workflows to VS Code core.
- **Evidence:** Public value: “The power lives in extensions.” Durable theme: extension API hygiene and ecosystem capability.
