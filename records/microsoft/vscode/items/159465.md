Keep open: script-runner selection now uses npm.scriptRunner rather than npm.packageManager, but automatic detection still contains a potentially incorrect Yarn-selection path. The supplied task and steps suffice to retest; the reporter's exact environment-dependent selection has not been confirmed.

## Change summary

An npm watch task configured to run on folder open incorrectly invokes an unavailable Yarn executable.
