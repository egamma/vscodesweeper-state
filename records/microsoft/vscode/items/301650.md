# Issue #301650 — Failed to sign in and sync with microsoft

[https://github.com/microsoft/vscode/issues/301650](https://github.com/microsoft/vscode/issues/301650)

## Summary

This is a proxy-configuration support question rather than an actionable VS Code defect. The authentication flow reaches the browser successfully but VS Code's token-exchange requests fail under the VPN with `network_error`, and a maintainer confirmed that VS Code needs the corresponding proxy configuration.

## Change summary

Microsoft account sign-in and Settings Sync fail because token requests cannot reach the Microsoft endpoint through the reporter's VPN setup.

## Best solution

Configure VS Code's `http.proxy` setting, or the inherited `http_proxy`/`https_proxy` environment variables, for the VPN's proxy and retry sign-in; no product change is indicated by the available evidence.
