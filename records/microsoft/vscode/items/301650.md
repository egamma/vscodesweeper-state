## Summary

This is a support question about proxy/network configuration for Microsoft authentication behind a VPN in China. A team member already answered: VS Code needs proxy configuration to reach Microsoft endpoints. The error (`ClientAuthError: network_error: Network request failed`) confirms a network connectivity issue, not a product defect.

## Change summary

User behind a VPN in China cannot sign in to their Microsoft account because VS Code cannot reach Microsoft authentication endpoints due to missing proxy configuration.

## Best solution

The user needs to configure VS Code's proxy settings (`http.proxy`, `http.proxyStrictSSL`) so that authentication requests to `login.microsoftonline.com` can route through their VPN. The team member's reply already covers this.
