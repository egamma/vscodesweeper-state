# Issue #219891 — I should be able to select multiple lines of python code and hit control F and it automatically imports it into the search box...

[https://github.com/microsoft/vscode/issues/219891](https://github.com/microsoft/vscode/issues/219891)

## Summary

A real editor-find gap remains: Ctrl+F and Ctrl+H intentionally seed only single-line selections, while the separate Find with Selection command supports multiline text. Keep this older, already-routed request open as the canonical discussion.

## Change summary

Allow Ctrl+F and Ctrl+H to populate the find input from a multiline editor selection, optionally through a setting.

## Best solution

Decide whether standard Find/Replace should accept multiline selections, then update the StartFindAction and StartFindReplaceAction paths in src/vs/editor/contrib/find/browser/findController.ts with focused controller tests. The newer matching report at https://github.com/microsoft/vscode/issues/307720 should be consolidated into this older issue.
