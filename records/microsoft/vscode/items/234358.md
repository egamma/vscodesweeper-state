# Issue #234358 — Task API for `ShellExecutionOptions.env` type does not support `undefined` values

[https://github.com/microsoft/vscode/issues/234358](https://github.com/microsoft/vscode/issues/234358)

## Summary

The reported typing mismatch remains on current main: ShellExecutionOptions.env excludes undefined, while TerminalOptions.env permits it. Keep this team-authored, already correctly routed issue open; no verified fix or qualifying canonical duplicate was found.

## Change summary

Allow environment dictionaries containing string or undefined values in ShellExecutionOptions.env, matching the terminal API's handling of undefined.

## Best solution

Make shell task environment options accept the reporter's shared environment dictionary without casts or filtering, with undefined entries leaving inherited values unchanged as they do for terminals. Cover both declaration compatibility and task environment processing so widening the type cannot introduce literal "undefined" values.
