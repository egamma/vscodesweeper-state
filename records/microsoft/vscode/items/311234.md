# Issue #311234 — checkout error on agent plugin/marketplace using gitlfs

[https://github.com/microsoft/vscode/issues/311234](https://github.com/microsoft/vscode/issues/311234)

## Summary

The reported difference between marketplace checkout and successful terminal recovery warrants investigation, not an as-designed close. Confirming the current behavior requires the marketplace configuration and Git LFS environment details.

## Change summary

Marketplace cloning fails to check out Git LFS resources that can subsequently be fetched manually; the report also requests sparse checkout of plugin directories.

## Best solution

Make marketplace checkout resolve Git LFS resources when LFS is available to VS Code's Git process, without silently substituting pointer files. First distinguish missing LFS installation from a desktop-process environment mismatch; evaluate sparse checkout separately from this failure.
