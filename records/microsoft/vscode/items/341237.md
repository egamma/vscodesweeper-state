# Issue #341237 — Agent Host fills .git/objects with tmp_obj_* files when a large untracked file is in the workspace (60 GB in 3 hours)

[https://github.com/microsoft/vscode/issues/341237](https://github.com/microsoft/vscode/issues/341237)

## Summary

Thanks for the detailed report. The temp-index staging in agentHostGitService.ts still has no GIT_OBJECT_DIRECTORY isolation on main. An open PR already proposes the fix, so this stays open while it is reviewed.

## Change summary

Agent Host's temp-index git add writes blobs (and killed partial tmp_obj_* files) into the user's .git/objects, growing without bound with large untracked files.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/341238, which isolates the object directory in the temp dir. Then decide separately how to handle the 5s timeout and retry backoff for large untracked files.
