# Issue #194746 — Show Notebook Execution Status in tabs 

[https://github.com/microsoft/vscode/issues/194746](https://github.com/microsoft/vscode/issues/194746)

## Summary

A real notebook/workbench UX gap remains: current main exposes execution progress inside the active notebook but not on inactive notebook tabs. The issue is already correctly routed and has positive maintainer feedback, so it should remain open.

## Change summary

Show running, completed, or failed notebook execution state on editor tabs, optionally with completion notifications.

## Best solution

Add a notebook tab decoration driven by `INotebookExecutionStateService`, with clear running and failure states. Treat broader completion notifications separately because accessibility signals already cover configurable audio and screen-reader feedback.
