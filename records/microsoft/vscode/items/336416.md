# Issue #336416 — Access WSL tunnels from Agents web UI

[https://github.com/microsoft/vscode/issues/336416](https://github.com/microsoft/vscode/issues/336416)

## Summary

Keep open: desktop WSL connections and browser tunnel support do not establish that the Agents web UI can select a WSL environment behind a Windows tunnel. This team-authored request has no verified fixing commit or qualifying duplicate.

## Change summary

Allow the Agents web UI to access a tunneled WSL environment and use its Linux filesystem for workspace selection and file context.

## Best solution

Support an explicitly selected WSL environment through the browser's remote Agent Host connection, with workspace browsing and context attachments consistently targeting that environment. First establish how the Windows tunnel exposes the WSL host; desktop WSL support alone does not deliver this capability.
