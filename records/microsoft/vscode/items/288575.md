# Issue #288575 — Icons in thinking blocks are blurry

[https://github.com/microsoft/vscode/issues/288575](https://github.com/microsoft/vscode/issues/288575)

## Summary

The visual defect remains on current main: thinking-block icons are explicitly converted to compact glyphs and rendered at the compact 12px size. The closed, unmerged implementation PR confirms a bounded solution and validation path, so the issue should remain open for implementation.

## Change summary

Render thinking-block status and tool icons crisply on standard-DPI displays instead of scaling them below their base size.

## Best solution

Use base-size codicon glyphs for thinking-block headers and rows, with connector and padding alignment adjusted so the 16px icons remain centered without changing row height or interaction behavior.
