## Summary

Keep open as a likely Electron/Linux font-loading sandbox defect, supported by independent Fedora and Arch reports. Removing the Adwaita product-icon setting avoids the crash, but neither a verified fix nor an eligible canonical duplicate was established.

## Change summary

Selecting the Adwaita product-icon theme causes the Linux window to terminate with code 159.

## Best solution

Identify the native font-loading failure triggered by adwaita-icons.ttf and resolve it in Electron/Chromium if the maintainer's diagnosis is confirmed. Preserve sandbox protection and supported product-icon themes; reverting to the default icon theme is a workaround, not completion.
