[https://github.com/microsoft/vscode/issues/331189](https://github.com/microsoft/vscode/issues/331189)

## Summary

The requested diff-statistic colors are still absent from the current picker. Keep this accepted, team-authored Backlog request open; the related Quick Pick description-color request does not cover the same observable behavior.

## Change summary
