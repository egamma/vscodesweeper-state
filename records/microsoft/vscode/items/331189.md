# Issue #331189 — Create session from pull request - picker polish

[https://github.com/microsoft/vscode/issues/331189](https://github.com/microsoft/vscode/issues/331189)

## Summary

Team-authored polish idea filed while testing the new "Create Session from Pull Request" feature (test plan #330674); the current quick-pick detail is a plain localized string with no per-substring styling, so adding red/green coloring to the +/- diff stats is a real, unimplemented enhancement rather than something already covered.

## Change summary

Add colored (red/green) styling to the addition/deletion diff counts shown in the pull-request session picker's detail line.

## Best solution

Decide on a rendering approach for colored diff stats in the PR quick pick (e.g. via IQuickPickItem.highlights, a custom renderer, or restructuring the detail into styled segments) in src/vs/sessions/contrib/github/browser/pullRequestPicker.ts, then apply theme-appropriate add/delete colors consistent with how the Git/SCM views color diff stats elsewhere.
