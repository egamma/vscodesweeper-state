# Issue #325539 — Extend `chat.tools.terminal.autoApprove` to deny tool calls

[https://github.com/microsoft/vscode/issues/325539](https://github.com/microsoft/vscode/issues/325539)

## Summary

Genuine feature request: the current `chat.tools.terminal.autoApprove` setting supports auto-approve (`true`) and require-explicit-approval (`false`), but there is no auto-deny mode that would automatically reject a tool call and optionally steer the agent with a message. No duplicate found.

## Change summary

Extend `chat.tools.terminal.autoApprove` to support an auto-deny mode that automatically rejects matching tool calls, with an optional steering message sent back to the agent.

## Best solution

Add a new value (e.g. `"deny"` or `{ approve: false, deny: true, message: "..." }`) to the `chat.tools.terminal.autoApprove` setting schema in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/common/terminalChatAgentToolsConfiguration.ts`, and wire the denial + optional message into the terminal tool confirmation flow in `chatTerminalToolConfirmationSubPart.ts` and `commandAutoApprover.ts`. This would let users block commands they never want the agent to run without repeated manual denial.
