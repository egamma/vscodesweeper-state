# Issue #244491 — Terminal QuickFix Provider and Command with arguments fail.

[https://github.com/microsoft/vscode/issues/244491](https://github.com/microsoft/vscode/issues/244491)

## Summary

Keep open: current main drops the arguments when invoking a terminal quick-fix command, which prevents argument-bearing extension commands from resolving their cached delegate. The reporter supplies a complete reproduction, and the failing path is confirmed in source.

## Change summary

Terminal quick fixes returning a VS Code Command with arguments fail instead of invoking the command with those arguments.

## Best solution

Terminal quick-fix actions should execute the converted command with its argument payload intact, including the cache identifier required by extension-command delegation. Preserve the existing behavior for commands without arguments, terminal-command fixes, and opener fixes.
