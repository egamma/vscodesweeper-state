# Issue #151715 — Extension variables are not expanded in integrated terminal profiles

[https://github.com/microsoft/vscode/issues/151715](https://github.com/microsoft/vscode/issues/151715)

## Summary

Still reproduces on main: terminal profile env values are never passed through variable resolution. The `_resolveProfile` method in `terminalProfileResolverService.ts` resolves variables in `profile.path` and `profile.args` but skips `profile.env` values entirely.

## Change summary

Variables like `${workspaceFolder}` in terminal profile `env` settings are not expanded — they pass through as literal strings.

## Best solution

In `terminalProfileResolverService.ts`, after resolving `profile.path` and `profile.args`, iterate over `profile.env` entries and call `_resolveVariables` on each value before returning the resolved profile.
