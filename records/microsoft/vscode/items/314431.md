# Issue #314431 — Warn before reload/close when extension webviews have active sessions or running work

[https://github.com/microsoft/vscode/issues/314431](https://github.com/microsoft/vscode/issues/314431)

## Summary

Legitimate feature request for an extension API to warn/block before window reload/close when webviews have active sessions. No existing API covers this — the proposed `onWillShutdown` is notification-only (no veto). Currently in the Backlog Candidates community voting window with 0 upvotes.

## Change summary

Extensions with active webview sessions cannot warn or prevent window reload/close, unlike the built-in terminal active-process warning.

## Best solution

Expose a new extension API (e.g. on `vscode.workspace` or `vscode.env`) that lets extensions register a beforeShutdown/beforeReload veto or confirmation dialog, similar to the internal lifecycle veto mechanism in `src/vs/workbench/services/lifecycle/`. This would let webview-based extensions (AI assistants, terminals, etc.) warn users before active sessions are interrupted. Let the community voting process determine demand.
