# Issue #144148 — Dialog asking to copy or add workspace folder could mention target

[https://github.com/microsoft/vscode/issues/144148](https://github.com/microsoft/vscode/issues/144148)

## Summary

The requested UX improvement remains absent on current main: dropping onto empty Explorer space resolves to the last workspace root, but the copy-or-add prompt does not identify that destination. The accepted Backlog request should remain open.

## Change summary

Clarify the external-folder drag-and-drop prompt by naming the workspace folder that will receive a copied folder.

## Best solution

Show the resolved copy destination in the confirmation prompt, particularly when an empty-area drop in a multi-root workspace implicitly targets the last root, while preserving the existing Add to Workspace choice.
