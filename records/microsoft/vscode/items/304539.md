# Issue #304539 — Copilot Chat "Keep/Discard" creates unsafe state for vibe-coding workflows

[https://github.com/microsoft/vscode/issues/304539](https://github.com/microsoft/vscode/issues/304539)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/262495 owns the same request to eliminate or disable Chat's Keep/Undo intermediate state and use normal file-saving behavior. This report adds useful evidence about interleaved sessions, which should be carried into the canonical discussion.

## Change summary

Provide a Chat editing mode without Keep/Undo state so agent edits behave like ordinary saved workspace changes and cannot interact unexpectedly across sessions.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/262495 and design direct agent editing there, preserving normal save behavior while addressing review and save-participant requirements. The canonical should retain this report's evidence about stale pending edits in interleaved sessions.
