# Issue #326146 — Preserve option to keep current UI: The so-called Modern UI is disgusting and objectively inferior

[https://github.com/microsoft/vscode/issues/326146](https://github.com/microsoft/vscode/issues/326146)

## Summary

This should stay open as active product feedback: the central ask is to preserve an opt-out for the experimental Modern UI, and the thread already includes substantial community signal and concrete usability concerns. Current comments indicate an opt-out setting exists today, but that does not settle whether it will be preserved if the UI graduates from experimental.

## Change summary

Preserve a supported way to keep the current/classic workbench UI instead of forcing the experimental Modern UI as the default.

## Best solution

Workbench modernization owners should explicitly decide and document whether `workbench.experimental.modernUI: false` or an equivalent stable setting will remain available if Modern UI becomes default, and consolidate feedback with any broader open Modern UI tracking issue if one exists.
