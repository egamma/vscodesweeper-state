# Issue #326146 — Preserve option to keep current UI: The so-called Modern UI is disgusting and objectively inferior

[https://github.com/microsoft/vscode/issues/326146](https://github.com/microsoft/vscode/issues/326146)

## Summary

Large, high-upvote design-feedback thread asking that the classic (pre-"Modern UI") layout remain selectable; the requested opt-out already exists today (`workbench.experimental.modernUI`, default `false`), but the underlying worry — that the setting could disappear once Modern UI becomes the default — is a forward-looking product decision no maintainer has settled, so this stays open for the design team.

## Change summary

Reporter and many commenters object to the new 'Modern UI' visual style and ask that VS Code permanently keep an option to use the classic UI, especially once/if Modern UI becomes default.

## Best solution

Track this as ongoing design feedback for the Modern UI rollout (owned by workbench/UX); the concrete ask (a persistent opt-out) is already met by `workbench.experimental.modernUI` in src/vs/workbench/browser/workbench.contribution.ts (line ~824-829, default false), so the remaining open question is a policy commitment about whether that toggle (or an equivalent) survives once Modern UI ships as default — that call belongs to the workbench/design team, not this review.
