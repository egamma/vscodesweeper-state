# Issue #326146 — Preserve option to keep current UI: The so-called Modern UI is disgusting and objectively inferior

[https://github.com/microsoft/vscode/issues/326146](https://github.com/microsoft/vscode/issues/326146)

## Summary

Keep open as a well-supported request for a lasting Classic UI option, not instructions for reverting today. Current main retains the toggle, but the team's published transition explicitly plans to remove it; compact density and connected tabs do not establish permanent Classic UI availability.

## Change summary

Preserve an enduring option to use the Classic UI if Modern UI becomes the default.

## Best solution

Make an explicit product decision on long-term Classic UI availability, addressing the thread's low-vision, high-contrast, and dense-workspace requirements. If the planned removal stands, establish which supported modern-layout behaviors satisfy those needs rather than treating the temporary toggle as completion of this request.
