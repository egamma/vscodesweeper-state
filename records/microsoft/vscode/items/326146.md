# Issue #326146 — Preserve option to keep current UI: The so-called Modern UI is disgusting and objectively inferior

[https://github.com/microsoft/vscode/issues/326146](https://github.com/microsoft/vscode/issues/326146)

## Summary

This is design-taste feedback on the experimental Modern UI, with 140 upvotes and heavy discussion — the literal ask (an option to keep the old UI) already exists via `workbench.experimental.modernUI: false`, but whether Modern UI should ever become the default remains an open product/design decision, so this stays open as a discussion item rather than a close.

## Change summary

Requests that VS Code never default to the new 'Modern UI' styling, or at minimum permanently preserve a setting to switch back to the classic UI.

## Best solution

Track this as design feedback for the workbench/UI-modernization team: the opt-out setting already exists (`workbench.experimental.modernUI`), so the remaining open question is a product decision about defaults and rollout communication (several commenters report the experiment silently enabling itself via A/B testing) rather than something engineering can resolve unilaterally.
