# Issue #322987 — Feature Request: Automated PR comment listener with Copilot triage and agentic resolution

[https://github.com/microsoft/vscode/issues/322987](https://github.com/microsoft/vscode/issues/322987)

## Summary

The request asks for an integrated PR-comment-to-Copilot workflow with notifications, triage actions, and agentic resolution. VS Code's Agents window already has significant PR review feedback infrastructure (agent feedback seeder, PR thread resolver, code review service, review commands), but the specific "background listener with toast notifications and three triage paths" UX described here is not yet shipped as described. The existing work partially overlaps but does not fully cover the central ask. Keeping open in the Backlog Candidates community process.

## Change summary

Add a background PR comment listener that surfaces toast notifications with triage actions (manual review, Copilot-assisted suggestion, or fully agentic resolution) and a Chat context-menu entry for PR comments.

## Best solution

Evaluate against the existing agent feedback and PR review infrastructure in `src/vs/sessions/contrib/agentFeedback/` and `src/vs/sessions/contrib/codeReview/` — much of the plumbing (PR comment mirroring, agent feedback seeding, review commands) already exists in the Agents window. The remaining gap is the notification-driven triage UX with the three resolution paths. This likely belongs in the Agents window's PR/changes review flows rather than a new standalone feature. Let the community process decide whether the specific notification-and-triage UX has enough demand.
