[https://github.com/microsoft/vscode/issues/272927](https://github.com/microsoft/vscode/issues/272927)

## Summary

Confirmed bug on Linux: middle-click paste fails when the cursor is over a linked/clickable word because xterm.js intercepts the mouse event. An open PR (#307884) is addressing this — keeping open until it lands.

## Change summary

Middle-mouse-button paste in the integrated terminal on Linux is unreliable when clicking over non-blank characters that trigger link detection.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/307884 which explicitly pastes the primary selection clipboard on Linux middle-click instead of relying on the browser's default behavior, which xterm.js's word-selection intercepts.
