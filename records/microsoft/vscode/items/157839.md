# Issue #157839 — Git - "Add to gitignore" should add to closest gitignore file, not root one.

[https://github.com/microsoft/vscode/issues/157839](https://github.com/microsoft/vscode/issues/157839)

## Summary

The requested capability is still missing: git.ignore writes exclusively to the repository-root .gitignore. Keep this canonical request open while the linked implementation PR is reviewed, including whether users should retain a choice of destination.

## Change summary

Allow Add to .gitignore to target an existing ancestor .gitignore closer to the selected file or folder instead of always using the repository-root file.

## Best solution

Review https://github.com/microsoft/vscode/pull/307639 against the request and discussion, settling automatic nearest-file selection versus a destination picker that preserves the root option. The finished behavior should write patterns relative to the chosen .gitignore and retain root-file creation when no ancestor .gitignore exists.
