[https://github.com/microsoft/vscode/issues/280753](https://github.com/microsoft/vscode/issues/280753)

## Summary

The rendering gap remains on current main: inline chat still copies error markdown into a plain icon-label surface, leaving links unrendered. The issue is already correctly routed and should remain open.
