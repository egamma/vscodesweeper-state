# Issue #316360 — [Copilot Chat] Add "Show Raw Response Body" button to Chat Debug View

[https://github.com/microsoft/vscode/issues/316360](https://github.com/microsoft/vscode/issues/316360)

## Summary

The raw-response inspection gap remains in the current Chat Debug View: existing JSON exports reconstruct parsed results rather than preserve the received body. Keep this request open; no verified canonical or completed implementation was found.

## Change summary

Expose the original model response body in Chat Debug View, including responses that fail parsing or produce no choices.

## Best solution

Provide an explicit raw-response inspection action alongside raw-request inspection in the built-in Copilot diagnostics. Define how streamed responses and capture limits are represented without presenting reconstructed results as the original payload.
