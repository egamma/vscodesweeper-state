# Issue #32267 — [GRIPE] "editor.mouseWheelScrollSensitivity" setting is not respected while making a text selection

[https://github.com/microsoft/vscode/issues/32267](https://github.com/microsoft/vscode/issues/32267)

## Summary

The underlying unusably fast selection scrolling was fixed and shipped in 1.72.0. Drag scrolling now uses dedicated, distance-sensitive behavior rather than the mouse-wheel sensitivity setting.

## Change summary

Make scrolling while extending a mouse selection controllable instead of excessively fast.

## Best solution

Keep the adaptive drag-scrolling implementation delivered by commit dfc8776b46579a578c120f4135217119d5560cc2; it resolves the central usability problem without coupling pointer dragging to mouse-wheel configuration.
