# Issue #171730 — "Resolve in Merge Editor" button initially missing

[https://github.com/microsoft/vscode/issues/171730](https://github.com/microsoft/vscode/issues/171730)

## Summary

Keep open: independent confirmations, including reports from June–September 2026, establish an intermittent missing merge-editor entry point. Source inspection identifies the visibility gates but does not establish a fixing commit or an older canonical covering the same symptom.

## Change summary

The Resolve in Merge Editor button can be missing when a conflicted file is first opened and appear only after switching tabs.

## Best solution

Make the existing merge-editor entry point reliably appear when an ordinary editor displays a conflict in a detected Git repository. Investigate the Git context updates and editor-content toolbar lifecycle, distinguishing delayed visibility from cases where the repository was never detected.
