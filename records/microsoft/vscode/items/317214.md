# Issue #317214 — Chat thinking output can render code blocks as blank-looking bordered blocks

[https://github.com/microsoft/vscode/issues/317214](https://github.com/microsoft/vscode/issues/317214)

## Summary

Thanks for the detailed report. The blank bordered shell remains source-reproducible on current main: thinking markdown creates and styles a code-block placeholder even when the fenced payload is empty, and no regression test covers that case.

## Change summary

Thinking/commentary output can display an empty bordered code-block shell instead of visible code or no block.

## Best solution

Thinking markdown should render non-empty fenced content visibly and omit the visual code-block shell when a streamed fence has no content, without changing normal answer code blocks.
