# Issue #307341 — remove the `copilot review` overtaking the command center

[https://github.com/microsoft/vscode/issues/307341](https://github.com/microsoft/vscode/issues/307341)

## Summary

Valid UX polish request: the agent session 'Review Changes' pill in the command center displaces the user's pinned debug toolbar with no obvious way to dismiss it. The `chat.agentsControl.enabled` setting (values: `hidden`, `badge`, `compact`) can mitigate this, but the user shouldn't need to discover a hidden setting — the competing command-center items should coexist or have a clear dismiss action.

## Change summary

When an agent session completes, the 'Review Changes' indicator in the command center hides the pinned debug toolbar, with no visible way to remove or dismiss it.

## Best solution

Improve the command center layout so that the agent status indicator and pinned debug toolbar coexist rather than one displacing the other. Consider the `badge` mode as a less intrusive default for users with pinned command-center items, or add a dismiss/close affordance on the review pill. The relevant code is in `src/vs/workbench/contrib/chat/browser/agentSessions/experiments/agentTitleBarStatusWidget.ts`.
