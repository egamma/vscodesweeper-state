# Issue #307341 — remove the `copilot review` overtaking the command center

[https://github.com/microsoft/vscode/issues/307341](https://github.com/microsoft/vscode/issues/307341)

## Summary

The current source still drops command-center debug controls when the agent widget enters its session-ready Review state. Keep this open: hiding the agent indicator is an available workaround, but the Review state should preserve the pinned debug toolbar.

## Change summary

Keep pinned command-center debug controls accessible when an agent session has changes ready for review.

## Best solution

Preserve command-center debug actions alongside the session title and Review control in AgentTitleBarStatusWidget's session-ready state, without requiring the user to enter review or disable the agent indicator.
