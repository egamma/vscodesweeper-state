# Issue #260057 — Cannot read properties of null (reading 'uri')

[https://github.com/microsoft/vscode/issues/260057](https://github.com/microsoft/vscode/issues/260057)

## Summary

Still reproduces on current main: the `get uri()` getter on codeblock info objects captures a pool reference by closure, and after the reference is disposed during re-render, any caller of `.uri` hits a null `ref.object`. The related PR #260162 was closed without merging and no fix has landed.

## Change summary

Accessing `ref.object.uri` in a `get uri()` closure on codeblock info throws a TypeError when the captured pool reference has been disposed.

## Best solution

Guard the `ref.object` access in the `get uri()` getter (and similar `focus()` closures) in `chatMarkdownContentPart.ts` to return `undefined` when the reference is stale or disposed, rather than crashing. Alternatively, ensure `_codeblocks` entries are invalidated before their captured refs are disposed.
