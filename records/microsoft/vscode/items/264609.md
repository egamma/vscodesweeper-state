# Issue #264609 — Offer to retry with another model or auto when model fails due to high demand

[https://github.com/microsoft/vscode/issues/264609](https://github.com/microsoft/vscode/issues/264609)

## Summary

Keep open: the team-authored request has explicit maintainer support and the Auto/Copilot platform team has committed to an SDK-and-client implementation direction. Current main still offers a same-model “Try Again” action for this failure path.

## Change summary

When a selected model is overloaded, offer an explicit retry using Auto instead of repeatedly retrying the same model.

## Best solution

Let the SDK determine whether a failed request is eligible for fallback and request explicit consent, while VS Code renders the retry-with-Auto offer, returns the user's decision, and records the associated telemetry.
