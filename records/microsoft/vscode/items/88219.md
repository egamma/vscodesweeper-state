# Issue #88219 — API to programatically expand/collapse tree view

[https://github.com/microsoft/vscode/issues/88219](https://github.com/microsoft/vscode/issues/88219)

## Summary

Still a valid, unimplemented API request with strong community support (56 upvotes, well past the 20-upvote backlog bar). The internal infrastructure exists (ViewPane.setExpanded/setCollapsed) but is not exposed through the extension API. Stays open on the On Deck milestone.

## Change summary

Request an extension API to programmatically expand or collapse a TreeView's view pane (the section header), not just tree items within it.

## Best solution

Expose a `collapsed`/`expanded` property or `setExpanded(boolean)` method on the `TreeView` interface, backed by the existing `ViewPane.setExpanded()` internal machinery. The plumbing exists in `src/vs/workbench/browser/parts/views/viewPane.ts` and `viewPaneContainer.ts`; the gap is purely the extension API surface and the ext-host proxy wiring in `extHostTreeViews.ts`.
