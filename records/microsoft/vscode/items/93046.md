# Issue #93046 — Snap: Register code as an editor in Debian with update-alternatives

[https://github.com/microsoft/vscode/issues/93046](https://github.com/microsoft/vscode/issues/93046)

## Summary

The snap package still lacks update-alternatives registration on current main; the deb package has it (resources/linux/debian/postinst.template line 13) but no equivalent hook exists in resources/linux/snap/snapcraft.yaml. An open PR (#298237) addresses snap improvements but hasn't merged.

## Change summary

Register VS Code with update-alternatives when installed via the snap package, matching the behavior of the deb package.

## Best solution

Add a snap hook (or post-install script) that runs `update-alternatives --install /usr/bin/editor editor /snap/bin/code 0`, mirroring what the deb postinst already does. The open PR https://github.com/microsoft/vscode/pull/298237 may cover this — review and land it, or extract the relevant piece.
