# Issue #324590 — Agents - cannot rename a new chat

[https://github.com/microsoft/vscode/issues/324590](https://github.com/microsoft/vscode/issues/324590)

## Summary

Current main still explicitly blocks renaming a newly added, untitled peer chat in every rename entry point. This should remain open and route to the Agents window area as a confirmed, bounded bug.

## Change summary

Allow a newly added chat in an Agents window session to be renamed before its first message is sent.

## Best solution

Permit rename for a rename-capable untitled peer chat, update its title immediately, and preserve that custom title when the first message materializes the chat and after reload. Keep the main-chat and capability restrictions intact.
