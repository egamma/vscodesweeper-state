## Summary

The reporter describes "Mark as Done" failing to close the Copilot CLI agent session tab, attributing it to a URI mismatch race. The Agents window code (sessionsService.ts lines 410–426) does react to `isArchived` transitions by navigating to a new session, but no team member has confirmed this specific failure path, and the AI-generated root-cause analysis may not be accurate. The area is under heavy active development with no fix commit referencing this issue. Keeping open for the agents-window team to investigate.

## Change summary

"Mark as Done" on a Copilot CLI agent session in Agents Insiders sets the archived flag but does not close or navigate away from the tab.

## Best solution

The agents-window team should investigate whether the `isArchived` observable transition fires correctly for Copilot CLI sessions. The archive→navigate-away autorun lives in `src/vs/sessions/services/sessions/browser/sessionsService.ts` (line 415). If the issue is a URI identity mismatch between the session the autorun watches and the session the provider archives, the fix would be in the copilotChatSessionsProvider or baseAgentHostSessionsProvider archive path. A reproduction on current Insiders would help clarify whether the rapid iteration in this area has already addressed it.
