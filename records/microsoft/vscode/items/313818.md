# Issue #313818 — Vscode Agents insider  — "Mark as Done" cannot close the tab

[https://github.com/microsoft/vscode/issues/313818](https://github.com/microsoft/vscode/issues/313818)

## Summary

The reported split identity is eliminated on current main: Agent Host sessions receive their final resource before backend creation, and the backend is required to use that same ID. This removes the stale `untitled-*` cache entry that caused Mark as Done to archive one identity while leaving another tab open.

## Change summary

Copilot CLI sessions could retain a placeholder editor URI after materialization, preventing Mark as Done from closing the corresponding tab and allowing session state to become stale.

## Best solution

Treat this as fixed by https://github.com/microsoft/vscode/commit/8dbb8606e2c27e9bf6eedd164f8168625609471d and preserve the tested invariant that the client-created session resource and backend session ID are identical.
