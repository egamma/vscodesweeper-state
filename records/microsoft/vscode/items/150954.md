# Issue #150954 — Double dialog when installing new language pack

[https://github.com/microsoft/vscode/issues/150954](https://github.com/microsoft/vscode/issues/150954)

## Summary

Keep open: the current desktop source still produces both the language-switch notification and the restart modal when Configure Display Language installs a new pack. This is an accepted, team-authored backlog bug, and the related report was closed as a duplicate of this issue—not as fixed.

## Change summary

Suppress the redundant language-switch notification when installing a language pack through the modal-driven Configure Display Language flow.

## Best solution

The explicit display-language selection flow should present only its restart modal, while ordinary language-pack installations retain their language-switch notification. Keep cancellation and subsequent independent installations working without leaving notification suppression active.
