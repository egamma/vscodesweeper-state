# Issue #328749 — Plan editing is not screen reader friendly

[https://github.com/microsoft/vscode/issues/328749](https://github.com/microsoft/vscode/issues/328749)

## Summary

Keep open: a maintainer reproduced a keyboard-accessibility gap in plan editing, and current main still delegates the relevant focus behavior to `@vscode/markdown-editor`. The related Tab issue covers focus leaving from inside a list item, not this re-reviewed issue's toolbar-to-first-heading symptom.

## Change summary

Tabbing from the plan editor toolbar skips the first editable heading, requiring a mouse click before a screen reader user can edit the plan.

## Best solution

The Markdown editor should expose a logical keyboard path from its editing toolbar into the document, focusing the first editable heading without requiring pointer input. Implement and validate that behavior in `microsoft/vscode-packages`' Markdown editor, then adopt the corrected package in the built-in Markdown extension.
