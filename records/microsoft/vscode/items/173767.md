# Issue #173767 — Sorting is not correct when looking for `Profiles: ` commands

[https://github.com/microsoft/vscode/issues/173767](https://github.com/microsoft/vscode/issues/173767)

## Summary

Keep open: current command-palette sorting still lacks query-relevance ranking for ordinary matching commands. The thread supports revisiting that intentional behavior, but the ranking policy and its interaction with command history need an owner decision.

## Change summary

Prefer directly relevant command titles and categories over incidental matches when searching the Command Palette.

## Best solution

Make command discovery prioritize strong textual matches, including the Profiles category, under an owner-approved ranking policy. Preserve predictable grouping and recently-used behavior unless the owner explicitly approves changing those contracts.
