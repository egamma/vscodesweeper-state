# Issue #232790 — Toggling views/panels has inconsistent focus behaviour

[https://github.com/microsoft/vscode/issues/232790](https://github.com/microsoft/vscode/issues/232790)

## Summary

The underlying bug — focus calls happening before the grid makes the container visible — is still present on current main. The attempted fix (PR #235622) was reverted (PR #236556) because it broke muscle memory for terminal/panel users. The issue remains valid and needs a nuanced solution that handles focus timing correctly while preserving expected behavior for common workflows.

## Change summary

Toggling view/panel visibility has inconsistent focus behavior because focus is set before the DOM nodes become visible in the grid.

## Best solution

Implement the two-part fix bpasero outlined: (1) ensure focus is applied after `setViewVisible` makes the container visible in the grid, and (2) make the `focus` parameter explicit in toggle actions so each can opt into focus-on-show or preserve-focus independently. The fix lives in `src/vs/workbench/browser/layout.ts` in `setSideBarHidden`, `setPanelHidden`, and `setAuxiliaryBarHidden`. The key insight from the revert is that toggle-panel (Cmd+J) users expect terminal focus, so the default for panel toggle should be focus=true while sidebar toggles may want focus=false.
