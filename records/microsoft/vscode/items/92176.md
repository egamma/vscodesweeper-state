# Issue #92176 — API to collapse custom tree items

[https://github.com/microsoft/vscode/issues/92176](https://github.com/microsoft/vscode/issues/92176)

## Summary

The request for a programmatic collapse API on TreeView remains unimplemented. The `reveal` method supports `expand` but has no `collapse` option. The related command-level request (#157410) was implemented and shipped, but this issue's core ask — an extension API to programmatically collapse tree items — is still a real gap. 14 upvotes and active community interest support keeping it open.

## Change summary

Add a programmatic API (e.g. a `collapse` option on `TreeView.reveal` or a dedicated method) so extensions can collapse custom tree items.

## Best solution

Add a `collapse` option to `TreeView.reveal()` (symmetrical with the existing `expand` option), or introduce a dedicated `collapse` method on `TreeView`. The implementation would flow through `src/vs/workbench/api/common/extHostTreeViews.ts` and the tree-view contribution layer. The related issue https://github.com/microsoft/vscode/issues/324498 (manual collapsibleState handling) is a broader variant but distinct — this one is simpler and more targeted.
