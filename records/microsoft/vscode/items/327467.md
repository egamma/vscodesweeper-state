# Issue #327467 — Workspace skill descriptions can alter customization-index structure and suppress external-file confirmation

[https://github.com/microsoft/vscode/issues/327467](https://github.com/microsoft/vscode/issues/327467)

## Summary

Valid security-hardening bug: workspace skill descriptions are interpolated unescaped into the XML-like customizations index, allowing crafted descriptions to inject synthetic instruction/file records that bypass the external-file ReadFile confirmation. An open fix PR exists — keeping open for that to land.

## Change summary

A workspace skill description containing XML delimiter characters can alter the customizations-index structure, causing an outside-workspace URI to be treated as an instruction file and skip the ReadFile external-file confirmation prompt.

## Best solution

Land https://github.com/microsoft/vscode/pull/327475, which XML-entity-encodes dynamic values in the index producers and adds a format marker so the parser fails closed on unmarked indexes for security-sensitive consumers. The longer-term suggestion in the issue — using a structured authorization object rather than reparsing prompt text — is sound but a larger refactor.
