# Issue #265397 — Pasting large JSON into existing JSON file makes VS Code editor unresponsive

[https://github.com/microsoft/vscode/issues/265397](https://github.com/microsoft/vscode/issues/265397)

## Summary

Legitimate freeze bug — pasting large JSON into an existing JSON file triggers auto-indent-on-paste processing that iterates over every pasted line synchronously, causing the editor to hang. Already properly triaged with correct labels and On Deck milestone; no fix found on main.

## Change summary

Pasting large (1MB+) JSON content into an existing JSON file makes the editor unresponsive, requiring a reload.

## Best solution

Add a line-count or size guard to `AutoIndentOnPaste.trigger()` in `src/vs/editor/contrib/indentation/browser/indentation.ts` so that pastes above a threshold skip auto-indentation (or run it asynchronously). Related issue https://github.com/microsoft/vscode/issues/230320 tracks a cursor-position bug in the same code path and should be considered together.
