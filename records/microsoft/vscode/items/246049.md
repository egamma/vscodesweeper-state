# Issue #246049 — MCP: Expose current git remote as root

[https://github.com/microsoft/vscode/issues/246049](https://github.com/microsoft/vscode/issues/246049)

## Summary

Keep open: current MCP roots still do not convey Git remote identity, but the bundled protocol explicitly restricts root URIs to file://. This team-authored request needs a protocol-compatible product decision, not a decline or a duplicate close.

## Change summary

Expose workspace Git remote identity to MCP servers without relying on model-supplied tool arguments.

## Best solution

Establish whether repository identity should be supplied by a Git-aware MCP server or through a supported client-context mechanism. Preserve filesystem-root semantics and settle multiple-remotes and multiple-host behavior before adding automatic remote exposure.
