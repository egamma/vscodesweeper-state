# Issue #198381 — Provide ability to ignore all line breaks in diff editor (feature request) 

[https://github.com/microsoft/vscode/issues/198381](https://github.com/microsoft/vscode/issues/198381)

## Summary

Thanks for the request. A diff option to ignore line-break-only changes isn't in the editor today, and the issue has 49 upvotes and sits in the Backlog, so it stays open. The related whitespace request (#43026) covers a different ask.

## Change summary

Add a diff editor option so changes that only add, remove or move line breaks are not highlighted as differences.

## Best solution

Add an opt-in diff computation option, alongside ignoreTrimWhitespace in the diff editor options, that normalizes line breaks before diffing. Decide how it relates to the whitespace request in https://github.com/microsoft/vscode/issues/43026.
