# Issue #198381 — Provide ability to ignore all line breaks in diff editor (feature request) 

[https://github.com/microsoft/vscode/issues/198381](https://github.com/microsoft/vscode/issues/198381)

## Summary

The older, open whitespace-diff request already explicitly includes ignoring inserted or removed line breaks, matching this report's observable behavior. Consolidate there while preserving this report's request for a separately selectable line-break option.

## Change summary

Allow the diff editor to ignore actual line-break changes so reflowed code does not obscure substantive edits.

## Best solution

Carry this report's preference for an independent line-break setting into that work rather than maintaining a second request for the same comparison capability.
