[https://github.com/microsoft/vscode/issues/286974](https://github.com/microsoft/vscode/issues/286974)

## Summary

The Windows-to-WSL path mismatch remains in current source: terminal labels resolve the remote cwd using the frontend's Windows path rules. The linked fix attempt was closed without merging, so this accepted terminal-tabs bug should stay open.

## Change summary

Hide ${cwdFolder} in terminal titles and descriptions when a WSL terminal is at its single workspace root, and show it after changing to another folder.

## Best solution
