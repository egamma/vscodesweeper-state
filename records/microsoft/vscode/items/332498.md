# Issue #332498 — macOS 15: Space in the save-changes dialog hits Cancel instead of Don't Save

[https://github.com/microsoft/vscode/issues/332498](https://github.com/microsoft/vscode/issues/332498)

## Summary

The changed focus behavior is intentional: the maintainer explicitly chose to stop initially focusing Don't Save, preventing accidental loss of unsaved work. Cmd+D remains the keyboard shortcut for Don't Save.

## Change summary

Restore Space-to-discard and the previous horizontal layout in macOS native save-changes dialogs.

## Best solution

Retain the intentional native button ordering and use Cmd+D to discard after Cmd+W. Do not restore destructive initial focus solely to recover the former Space shortcut.

- **Reason:** Efficient keyboard interaction fits accessibility and core UX goals, although that does not override the documented decision about destructive initial focus.
