# Issue #332498 — macOS 15: Space in the save-changes dialog hits Cancel instead of Don't Save

[https://github.com/microsoft/vscode/issues/332498](https://github.com/microsoft/vscode/issues/332498)

## Summary

Well-diagnosed regression confirmed in current source: on macOS 15+ (Darwin 24+), `massageMessageBoxOptions` skips the legacy button reordering, so three-button save dialogs stack vertically and the focus ring (and Space key) lands on Cancel instead of Don't Save. Routing to the area owner rather than closing, since this is a genuine gap needing a maintainer decision on the right fix approach.

## Change summary

On macOS 15+, pressing Space in the save-changes dialog now hits Cancel instead of Don't Save, because a Darwin-version gate added when native dialog reordering was removed only preserves the old (correct) button layout for macOS < 15.

## Best solution

In src/vs/platform/dialogs/electron-main/dialogMainUtils.ts, either drop (or extend) the `useLegacyMacOSButtonOrder` Darwin<24 gate so cancel-button repositioning still applies on macOS 15+, or give the middle 'Don't Save'-style button an explicit key equivalent (mirroring how message_box_mac.mm sets `\r`/`\e` for default/cancel) so the shortcut no longer depends on NSAlert's focus-ring/stacking behavior.
