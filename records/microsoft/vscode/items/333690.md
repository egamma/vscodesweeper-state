# Issue #333690 — Background layout preferences aren't specific to light or dark modes

[https://github.com/microsoft/vscode/issues/333690](https://github.com/microsoft/vscode/issues/333690)

Team-authored report (filed by a collaborator while testing the new agent-sessions background feature) that's already been confirmed reproduced by an automated verification comment, and the code confirms why: this stays open per the team-authored keep-open rule regardless, since there's no fix commit referencing it yet.

## Change summary

Setting a different background-image layout (left/right/etc.) for light vs. dark theme in agent sessions causes the layout to apply globally instead of per-theme, even though the background image itself is stored separately per theme.

## Best solution

Decide whether `chat.agentSessions.backgroundImageLayout` should be split into per-theme settings (mirroring `preferredDarkBackgroundImage`/`preferredLightBackgroundImage`) in src/vs/sessions/services/chatBackground/browser/chatBackgroundService.ts, or whether the single-layout model is intentional per the parent tracking issue — this is a product call, not a mechanical fix.
