# Issue #205125 — Git - "Discard Changes" and "Stage Changes" don't work for submodules

[https://github.com/microsoft/vscode/issues/205125](https://github.com/microsoft/vscode/issues/205125)

## Summary

Still reproduces on main: when a submodule repository is closed, `runByRepository` in `commands.ts` silently drops stage/discard operations because `getRepository()` only searches open repositories and returns `undefined` for a closed submodule. An earlier fix (PR #236098) was merged then reverted; an open PR #296975 is actively attempting to fix this.

## Change summary

Stage Changes and Discard Changes buttons silently do nothing for submodules when the submodule repository is closed in the Source Control view.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/296975 (or a similar approach) that enables `runByRepository` to resolve a closed submodule to its parent repository so the git add/checkout operation runs against the parent. The fix is localized to `extensions/git/src/commands.ts` and `extensions/git/src/model.ts`.
