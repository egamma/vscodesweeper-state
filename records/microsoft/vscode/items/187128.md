# Issue #187128 — Dancing keys and shortcuts

[https://github.com/microsoft/vscode/issues/187128](https://github.com/microsoft/vscode/issues/187128)

## Summary

This issue is the canonical tracker for keyboard dispatch mismatches on non-QWERTY layouts (a team member closed #169826 in its favor). No fix commit found on main; the underlying keyboard-layout dispatch logic hasn't been reworked since the report. Keeping open as the active bug.

## Change summary

Keyboard shortcuts interpret physical keys incorrectly on QWERTZ (and Dvorak-Qwerty) layouts when using `code` dispatch, swapping keys like `-`→`/` and `z`→`y`.

## Best solution

Investigate and fix the mismatch between the key shown during shortcut recording and the key matched during dispatch in the keyboard layout service (`src/vs/platform/keyboardLayout/`). A team member already consolidated duplicates here, so this is the place to land the fix.
