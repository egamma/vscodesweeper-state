# Issue #234194 — Focus movement with Attached file pill should be improved

[https://github.com/microsoft/vscode/issues/234194](https://github.com/microsoft/vscode/issues/234194)

## Summary

The general attachment-navigation work merged in 2025, but current main still recreates the implicit current-file pill after toggling it without restoring focus, and neither Escape-to-input nor keyboard removal is handled on that implicit-pill path.

## Change summary

Preserve focus when toggling the current-file attachment pill, let Escape return focus to the chat input, and provide the requested keyboard removal behavior.

## Best solution

Complete the keyboard contract for implicit-context attachment pills in the chat input: retain pill focus after toggles, return focus to the input on Escape, and support platform-appropriate removal while preserving the existing behavior of explicit attachments.

## Evidence
