# Issue #296942 — AI Customizations Editor: Can't expand/collapse sections uisng the keyboard

[https://github.com/microsoft/vscode/issues/296942](https://github.com/microsoft/vscode/issues/296942)

## Summary

Still reproduces on main: the AI Customizations list widget uses WorkbenchList with custom group-header collapsing, but only handles toggle via onDidOpen (click/Enter) — no Left/Right arrow key handling exists for collapse/expand.

## Change summary

Left/Right arrow keys do not collapse/expand group sections in the AI Customizations Editor.

## Best solution

Add a keydown listener on the list (or use the list's keyboard event) to handle LeftArrow (collapse focused group header or jump to parent group) and RightArrow (expand focused group header) in aiCustomizationListWidget.ts, similar to tree widget semantics.
