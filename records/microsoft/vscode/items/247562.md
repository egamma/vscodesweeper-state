# Issue #247562 — Refine alt text: Code action changes more than one image

[https://github.com/microsoft/vscode/issues/247562](https://github.com/microsoft/vscode/issues/247562)

## Summary

The accepted bug remains present on current main: the alt-text action does not establish the selected image as the inline-edit boundary, so another nearby image can be modified. As a team-authored issue carrying the accepted `bug` classification, it should remain open for a scoped fix.

## Change summary

Refining one Markdown image's alt text can also rewrite the alt text of another nearby image.

## Best solution

Constrain the operation to the invoked image's alt-text span while preserving the inline-chat review flow. The implementation must also ensure that `vscode.editorChat.start` applies its supplied target range before creating the editing session rather than treating that range only as reveal information.
