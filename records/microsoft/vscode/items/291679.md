# Issue #291679 — Cursor in the middle of terminal path

[https://github.com/microsoft/vscode/issues/291679](https://github.com/microsoft/vscode/issues/291679)

## Summary

A real terminal persistence bug where the cursor position is incorrectly restored after session revive (stuck at the column of the previous project's path). The reporter diagnosed it to `persistentSessionReviveProcess` on Linux/bash. A related fix landed for pty host restart on Windows (1d3e82fd38b) but doesn't cover this Linux session-revive path. Still valid on main.

## Change summary

Opening the integrated terminal after a persistent session revive places the cursor in the middle of the prompt path instead of at the end.

## Best solution

The terminal persistence revive path needs to reset cursor position after restoring the session, similar to how 1d3e82fd38b handles it for pty host restart. The fix likely belongs in the session revive logic in `src/vs/workbench/contrib/terminal/browser/terminalService.ts` or the pty service revive path.
