# Issue #41565 — Git - Detect git repositories under ignored paths

[https://github.com/microsoft/vscode/issues/41565](https://github.com/microsoft/vscode/issues/41565)

## Summary

Keep open: scan-depth configuration and parent-repository controls address parts of the discussion, but current source still skips an ignored nested repository when its workspace folder is added after the parent repository is registered. This preserves the ordering-dependent failure documented in the thread.

## Change summary

Detect and expose independent Git repositories inside parent-ignored directories without requiring workspace-folder reordering or closing the parent repository.

## Best solution

Make explicitly added nested workspace repositories register independently of an already-open ancestor, with their own SCM changes and diffs. Preserve the existing scan exclusions and parent-repository consent behavior; treat the related open-editors detection problem as related work rather than a replacement for this older report.
