# Issue #342949 — Terminal output on Windows is paced by the ~15.6 ms timer tick during flow control

[https://github.com/microsoft/vscode/issues/342949](https://github.com/microsoft/vscode/issues/342949)

## Summary

Keep open: current source still delays buffered output after the pty pauses, supporting the reported performance concern. The Windows timer-tick explanation needs measurement; neither related issue establishes that this specific work is completed or duplicated.

## Change summary

Avoid unnecessary batching delay after terminal flow control pauses bulk output on Windows.

## Best solution

Establish the Windows pause-to-delivery timing and remove avoidable waiting at that boundary while preserving output ordering, bounded buffering, and interrupt responsiveness. Keep this targeted investigation distinct from adaptive flow-control design.
