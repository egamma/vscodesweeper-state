# Issue #342949 — Terminal output on Windows is paced by the ~15.6 ms timer tick during flow control

[https://github.com/microsoft/vscode/issues/342949](https://github.com/microsoft/vscode/issues/342949)

## Summary

Keep open for the scheduled 1.144.0 milestone. Current source still delays buffered output after a flow-control pause; the Windows timer amplification is plausible but needs the before/after measurement explicitly outstanding in the report.

## Change summary

Avoid waiting for the output batching timer after flow control pauses a Windows terminal producing bulk output.

## Best solution

Deliver buffered output promptly when flow control pauses the pty, while preserving output ordering, acknowledgement accounting, and existing watermarks. Establish the Windows throughput benefit with the supplied trace scenario and coordinate with the broader batching work at https://github.com/microsoft/vscode/issues/338156.
