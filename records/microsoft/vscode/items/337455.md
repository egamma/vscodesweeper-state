# Issue #337455 — Allow to mark a (sub) chat as Done

[https://github.com/microsoft/vscode/issues/337455](https://github.com/microsoft/vscode/issues/337455)

## Summary

Team-authored feature request filed today with no discussion yet — hard keep-open rule applies regardless, and there is no existing 'mark as done' affordance in the sessions/chat UI to point to, so this is a genuine open ask.

## Change summary

Add a way to explicitly mark a chat/session (or sub-chat) as Done in the Agents/Sessions window, instead of the workaround of appending `[done]` to the title.

## Best solution

Add a first-class 'done' status to the sessions list model (src/vs/sessions/services/sessions/common/session.ts and sessionsListModelService.ts) with a UI affordance in the session list/header (sessionsList.ts, sessionHeaderBar.ts) — a maintainer should first decide how 'done' interacts with existing status/archival concepts before implementation.
