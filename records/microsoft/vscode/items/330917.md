# Issue #330917 — agent host: stop deleting enablement decisions against a mutable client base

[https://github.com/microsoft/vscode/issues/330917](https://github.com/microsoft/vscode/issues/330917)

## Summary

Keep open: current source still discards explicit persistent decisions when they match inherited values and prunes matching workspace decisions after global writes. The original stale-republish regression has coverage, but that does not implement this team-authored follow-up.

## Change summary

Persist explicit host customization-enablement decisions independently of the mutable client inheritance base, clearing them only through explicit reset operations.

## Best solution

Make durable host enablement represent explicit intent rather than differences from inherited state, retaining inheritance for absent decisions. Preserve explicit clearing, scope precedence, the storage bound, and the stale-client-republish regression.
