# Issue #326676 — can't cycle through feedback

[https://github.com/microsoft/vscode/issues/326676](https://github.com/microsoft/vscode/issues/326676)

## Summary

The navigation defect remains on main: feedback navigation opens the configured Markdown custom editor, but that editor has no mechanism to reveal the selected feedback range. This team-authored bug should remain open.

## Change summary

Cycling through agent feedback on a Markdown file opens the Markdown editor but does not reveal successive feedback locations.

## Best solution

Teach the Markdown custom editor to reveal a requested feedback range, or preserve the text editor when the navigation command requires range selection. The navigation contract should work consistently across both editor types.
