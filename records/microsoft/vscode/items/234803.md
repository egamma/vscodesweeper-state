# Issue #234803 — Invalid outline in search editor

[https://github.com/microsoft/vscode/issues/234803](https://github.com/microsoft/vscode/issues/234803)

## Summary

Still reproduces on main: clicking an outline item in a search editor triggers openCodeEditor with the search-editor URI, which cannot be resolved as a standalone resource, producing the error. No fix has landed.

## Change summary

Clicking outline items in a search editor opens an error tab instead of navigating within the search results.

## Best solution

The search editor should either provide a custom outline that maps file-header symbols to the actual file URIs, or the DocumentSymbolsOutline reveal should detect when the editor is a search editor and navigate within it (reveal the range in the existing editor) rather than calling openCodeEditor with the unresolvable search-editor URI. The fix likely lives in src/vs/workbench/contrib/searchEditor/browser/searchEditor.ts (provide a custom outline) or src/vs/workbench/contrib/codeEditor/browser/outline/documentSymbolsOutline.ts (guard the reveal path).
