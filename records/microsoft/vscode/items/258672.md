# Issue #258672 — Auto imports don't work in python repl

[https://github.com/microsoft/vscode/issues/258672](https://github.com/microsoft/vscode/issues/258672)

## Summary

The terminal REPL LSP completion pipeline does not carry `additionalTextEdits` from LSP completion items — the mechanism that auto-imports rely on — so accepting a completion like `path` in the Python REPL never inserts the corresponding `import path` statement. This is a genuine gap in the terminal suggest infrastructure.

## Change summary

Accepting an LSP completion in the Python REPL should apply `additionalTextEdits` (auto-import statements), but those edits are silently dropped.

## Best solution

Extend the terminal completion item model (`ITerminalCompletion`) to carry `additionalTextEdits`, propagate them from the LSP adapter in `lspCompletionProviderAddon.ts`, and apply them to the terminal input (or the virtual document) when a completion is accepted in `terminalSuggestAddon.ts`. This requires deciding how auto-import text (which in an editor inserts at the top of the file) maps to the REPL's line-by-line model — likely by prepending the import line before the current input.
