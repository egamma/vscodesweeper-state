# Issue #318089 — LM tool specific to Git changes

[https://github.com/microsoft/vscode/issues/318089](https://github.com/microsoft/vscode/issues/318089)

## Summary

The requested dedicated Git changes tool already exists and predates this report. Propose closing as covered by the existing experimental capability, while distinguishing tool availability from its remaining efficiency issues.

## Change summary

Provide a built-in language-model tool that reads staged and unstaged Git changes through the Git extension API instead of requiring agent-issued terminal commands.

## Best solution

Use the existing Git Changes tool through github.copilot.chat.getChangedFilesTool.enabled rather than add another tool. Improvements to large-change context efficiency remain tracked separately at https://github.com/microsoft/vscode/issues/276413.

## Evidence

- **Existing capability:** extensions/copilot/package.json registers copilot_getChangedFiles, displayed as Git Changes with tool reference changes. Its schema accepts repositoryPath and sourceControlState values staged, unstaged, and merge-conflicts; its model description explicitly offers Git diffs of current changes.
- **Git API implementation:** extensions/copilot/src/extension/tools/node/scmChangesTool.ts: GetScmChangesTool.invoke selects indexChanges for staged changes and workingTree plus untrackedChanges for unstaged changes, then calls IGitDiffService.getChangeDiffs. extensions/copilot/src/extension/prompt/vscode-node/gitDiffService.ts:90–136 retrieves patches through the Git repository API, including diffIndexWithHEAD and diffWithHEAD, and returns them to the model.
- **Availability and limitations:** github.copilot.chat.getChangedFilesTool.enabled is an experimental setting with default false. extensions/copilot/src/extension/intents/node/agentIntent.ts reads this setting and sets allowTools[ToolName.GetScmChanges]; the manifest also gates the tool on it. extensions/copilot/src/extension/tools/vscode-node/toolsService.ts applies additional model-specific experimental gates for GPT-5.5 and Gemini 3. Availability does not guarantee the model will prefer this tool over terminal commands.
- **Predates the request:** The historical file at https://github.com/microsoft/vscode/blob/333d9a4053e71ed5249450e112b6a9decd3997b4/extensions/copilot/src/extension/tools/node/scmChangesTool.ts already contains GetScmChangesTool, staged/unstaged filtering, and Git API diff retrieval. That commit dates to 2025-06-27, before this report was filed on 2026-05-23.
- **Related efficiency work, not a duplicate canonical:** https://github.com/microsoft/vscode/issues/276413 is open and concerns excessive context from the existing changes tool, not the absence of a dedicated tool. A maintainer's 2026-04-13 comment at https://github.com/microsoft/vscode/issues/276413#issuecomment-4240053348 reports that terminal-based inspection can still perform better. This supports acknowledging the efficiency limitation without claiming the existing tool is necessarily more efficient.
