# Issue #334438 — Agent plugin skill namespaces are dropped, causing same-named skills to shadow each other

[https://github.com/microsoft/vscode/issues/334438](https://github.com/microsoft/vscode/issues/334438)

## Summary

Confirmed on current main: plugin skills are initially assigned plugin-qualified names, but final model-context discovery replaces those names with the bare skill folder name and globally deduplicates them. Distinct same-named skills from different plugins therefore still shadow each other.

## Change summary

Preserve plugin namespaces when loading same-named agent skills into the model context.

## Best solution

Preserve each plugin skill's canonical qualified name through `PromptsService.computeSkillDiscoveryInfo`, while retaining existing bare-name precedence and deduplication for standalone workspace, user, and extension skills.
