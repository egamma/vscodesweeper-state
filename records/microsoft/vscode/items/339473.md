# Issue #339473 — Allow VS Code Profiles to Maintain Separate Authentication States

[https://github.com/microsoft/vscode/issues/339473](https://github.com/microsoft/vscode/issues/339473)

## Summary

This is the same underlying request as the older, open, actively-discussed issue https://github.com/microsoft/vscode/issues/240700 (profile-scoped authentication/account preferences), which fully covers the GitHub/Copilot account-isolation-per-profile ask — proposing a duplicate close to consolidate the discussion there.

## Change summary

Make authentication state (GitHub, Microsoft, Copilot sign-ins) profile-scoped instead of global, so switching profiles switches accounts too.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/240700, where a maintainer (TylerLeonhardt) already proposed storing the account preference with `StorageScope.PROFILE` instead of `StorageScope.APPLICATION` in authenticationExtensionsService.ts, and sandy081 agreed — that issue owns the fix for this exact problem, including the GitHub Copilot account-switching angle raised in its later comments.
