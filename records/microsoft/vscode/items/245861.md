# Issue #245861 — NPM notification endless loop

[https://github.com/microsoft/vscode/issues/245861](https://github.com/microsoft/vscode/issues/245861)

## Summary

Still reproduces on main: when opening a home folder (especially in WSL) with many nested package.json files that each have multiple lock files, `detectPackageManager` fires `window.showInformationMessage` per folder without any throttle or deduplication, flooding the notification area.

## Change summary

Opening a workspace with many package.json files triggers an endless stream of 'multiple lock files detected' notifications from the npm extension.

## Best solution

Add deduplication or throttling to the multiple-lock-file warning in `extensions/npm/src/tasks.ts` — e.g. show the notification at most once per session (or once per workspace), rather than per-folder per-`detectPackageManager` call. The `neverShowWarning` global-state guard only suppresses after the user clicks 'Do not show again', but by then dozens of notifications have already fired.
