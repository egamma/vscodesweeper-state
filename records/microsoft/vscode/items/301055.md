# Issue #301055 — The search keyword is blocked and cannot be seen.

[https://github.com/microsoft/vscode/issues/301055](https://github.com/microsoft/vscode/issues/301055)

## Summary

Verified duplicate: the open, triaged issue https://github.com/microsoft/vscode/issues/323072 tracks the same Chinese-locale status chip obscuring the Problems filter and covers the shared filter widget more broadly.

## Change summary

The Problems filter shrinks after losing focus, allowing its localized result-count badge to obscure the entered keyword; the Chinese count translation also uses the wrong unit.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/323072 and correct the shared FilterWidget layout so localized badges cannot cover filter text when the title control loses focus; carry over the reported Chinese translation correction from 页 to 项.
