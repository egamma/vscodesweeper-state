# Issue #330192 — Enable extensions for VS Code Agents Window to allow Terraform syntax highlighting 

[https://github.com/microsoft/vscode/issues/330192](https://github.com/microsoft/vscode/issues/330192)

## Summary

Real gap, but the framing is a bit off: the Agents Window already allows declarative, code-free extensions (themes, grammars, languages) to run — the practical blocker is that most Terraform extensions (e.g. HashiCorp's official one) ship a language server (`main`) and are therefore disabled there. This is a legitimate feature request to extend Agents Window extension support, not something already fixed.

## Change summary

Terraform files opened in the Agents Window get no syntax highlighting because the extension providing it is disabled there.

## Best solution

Route to the agents-window area owners: either broaden `canExecuteOnSessionsWindow` policy to better support grammar-heavy extensions that also happen to declare `main` (e.g. by running only the declarative contribution surface), or document/encourage a lighter grammar-only path; this sits with the same extension-support gap already tracked by adjacent issues like https://github.com/microsoft/vscode/issues/318103 and https://github.com/microsoft/vscode/issues/315776.
