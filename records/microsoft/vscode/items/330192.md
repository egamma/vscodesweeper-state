# Issue #330192 — Enable extensions for VS Code Agents Window to allow Terraform syntax highlighting 

[https://github.com/microsoft/vscode/issues/330192](https://github.com/microsoft/vscode/issues/330192)

## Summary

Genuine gap: the Agents Window doesn't yet support arbitrary third-party extensions, so language-only extensions like Terraform syntax highlighting can't be enabled there — routing to the Agents Window area since the extension story is still being actively worked out.

## Change summary

Request to allow installing/enabling extensions (e.g. Terraform syntax highlighting) inside the Agents Window, which currently only runs a curated set of built-ins.

## Best solution

Tracked as part of the broader Agents Window extension-support workstream (src/vs/sessions); no single fix — the team needs to decide how/which extensions (or a Terraform grammar specifically) get enabled there, per the maintainer note on https://github.com/microsoft/vscode/issues/315776.
