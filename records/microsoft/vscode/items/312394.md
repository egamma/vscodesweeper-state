# Issue #312394 — Extensions are not installed on Debian 12 (Myvestacp)

[https://github.com/microsoft/vscode/issues/312394](https://github.com/microsoft/vscode/issues/312394)

## Summary

This is an environment-specific support question — the "Error: aborted" during file writes to the CachedExtensionVSIXs directory on a Myvestacp-managed Debian 12 server points to the hosting panel's security or filesystem restrictions interfering with VS Code Server's file operations, not a VS Code bug. The reporter confirms it works on a plain Linux server without Myvestacp.

## Change summary

Extension VSIX downloads fail with 'Error: aborted' when writing to the CachedExtensionVSIXs directory on a Myvestacp-managed Debian 12 server.

## Best solution

This is an environment configuration issue. The Myvestacp control panel likely restricts file operations (e.g. inotify watches, open file limits, or security modules like AppArmor/SELinux profiles) that abort the download stream mid-write. The reporter should check Myvestacp's security settings, filesystem quotas, and any active security modules on the server.
