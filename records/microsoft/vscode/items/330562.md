# Issue #330562 — Add native "Swap Sides" button in Diff Editor and optimize "Compare with Clipboard" UX

[https://github.com/microsoft/vscode/issues/330562](https://github.com/microsoft/vscode/issues/330562)

## Summary

The core ask — a native 'Swap Sides' button in the Diff Editor title bar — already shipped and is present on current main, which directly resolves the reversed-comparison problem described (including for Compare with Clipboard); the remaining sub-asks (a clipboard-position setting, native folder diffing) are separate, narrower ideas better filed on their own.

## Change summary

Requests a native 'Swap Sides' toggle in the Diff Editor toolbar, a setting to control clipboard-compare default side, and a built-in folder/directory diff view.
