# Issue #333046 — GitHub Copilot inline suggestions fail when parent directory name contains a space on Windows

[https://github.com/microsoft/vscode/issues/333046](https://github.com/microsoft/vscode/issues/333046)

## Summary

Keep open for diagnosis of the Windows path-dependent inline-completion regression, independently confirmed across several languages. The related open report is newer, and neither a verified fixing commit nor an older canonical covering this symptom was established.

## Change summary

Copilot ghost-text completions fail for Windows file paths containing spaces or '+', with additional evidence that CLI workspace opening affects the failure.

## Best solution

Restore classic inline completions for valid Windows paths regardless of whether the workspace is opened through the CLI or File → Open Folder. Diagnose the completion pipeline separately from the correlated database initialization error before choosing a bounded fix.
