# Issue #333046 — GitHub Copilot inline suggestions fail when parent directory name contains a space on Windows

[https://github.com/microsoft/vscode/issues/333046](https://github.com/microsoft/vscode/issues/333046)

## Summary

Real, actively-investigated regression: Copilot ghost-text inline suggestions stop working whenever the active file's path contains a space (or, per a later comment, a '+') on Windows. Multiple independent reporters across two issues reproduce it consistently with clear before/after (rename-the-folder) tests, and the related issue #333320 (younger than this one) is already assigned to a VS Code maintainer — so this stays open as the primary tracking issue rather than being folded into the newer report.

## Change summary

Copilot inline/ghost-text completions silently fail ('No inline suggestion available') when the file's absolute path contains a space (or a '+') on Windows, while Chat and NES keep working.

## Best solution

Diagnose why a space/'+' in the file's path breaks the ghost-text pipeline in extensions/copilot's completions-core (vendored LSP client) — the reported 'Failed to create database... unable to open database file' log line and the percent-encoded file: URI are both leads worth checking — then fix the path/URI handling that mis-parses these characters. Coordinate with the maintainer already assigned on the related #333320.
