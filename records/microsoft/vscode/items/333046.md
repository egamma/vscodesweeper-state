# Issue #333046 — GitHub Copilot inline suggestions fail when parent directory name contains a space on Windows

[https://github.com/microsoft/vscode/issues/333046](https://github.com/microsoft/vscode/issues/333046)

## Summary

Well-documented, multi-user-confirmed regression: Copilot inline/ghost-text completions silently stop working whenever a workspace path contains a space on Windows (and the reporter narrowed it further to launching via `code .`). A near-duplicate report (#333320) already has a VS Code maintainer assigned, so this is being looked at, but I can't pin the exact root cause from static source reading alone (no Windows repro environment here), so I'm not proposing a close.

## Change summary

GitHub Copilot inline suggestions never appear when the active file's parent directory (or a workspace opened via `code .`) has a space in its path on Windows.
