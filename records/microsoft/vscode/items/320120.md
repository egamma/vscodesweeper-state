# Issue #320120 — Powershell doesn't open correctly for Next.js app router files

[https://github.com/microsoft/vscode/issues/320120](https://github.com/microsoft/vscode/issues/320120)

## Summary

This is the known Windows PowerShell 5 path-handling defect, not a Next.js-specific VS Code bug. It remains relevant for bracketed directories and should be classified upstream and routed to terminal maintainers.

## Change summary

Windows PowerShell 5 starts in its installation directory when the requested terminal cwd contains square brackets.

## Best solution

Use PowerShell 7, where the upstream defect is fixed. VS Code should continue passing the literal process cwd without adding fragile shell-specific startup commands.
