## Change summary

The browser sharing toggle appears inconsistent with agents' ability to read agent-opened pages and is not consistently enabled when pages open.

## Best solution

Ensure the sharing indicator accurately reflects agent access for both user-opened and agent-opened tabs, and that stopping sharing prevents subsequent browser-tool access. Retest the linked Local Agent Host scenario before deciding whether a behavioral fix or clearer UI remains necessary.
