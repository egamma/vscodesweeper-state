# Issue #314160 — unclear what "share with agent" actually does

[https://github.com/microsoft/vscode/issues/314160](https://github.com/microsoft/vscode/issues/314160)

## Summary

The two reported problems — (1) the share toggle not gating agent access to browser content, and (2) inconsistent initial toggle state — remain unaddressed on current main. No commits since the report have touched the sharing logic in browserEditorChatFeatures.ts or browserView.ts. The related internal tracking issue is still open.

## Change summary

The integrated browser's "Share with Agent" toggle does not reliably control whether the agent can access browser content, and its initial enabled state is inconsistent.

## Best solution

Fix the sharing gate so that when the toggle is off, agent tools (Playwright page tracking) are actually disconnected from the browser view; and ensure the toggle's initial state is deterministic on open. The relevant code is in `src/vs/workbench/contrib/browserView/common/browserView.ts` (the `_sharedWithAgent` field and `setSharedWithAgent` flow) and `src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorChatFeatures.ts` (the share button UI). The linked internal issue https://github.com/microsoft/vscode-internalbacklog/issues/7702 tracks broader browser-tools polish.
