# Issue #345188 — Code editor bug report form should be consistent with the bug reporting requirements

[https://github.com/microsoft/vscode/issues/345188](https://github.com/microsoft/vscode/issues/345188)

## Summary

Keep open as a feature request to keep the in-editor reporting form aligned with reporting requirements. Existing forms provide reproduction guidance, but that does not establish automatic synchronization with the guidelines or cover every requested detail.

## Change summary

Keep the in-editor bug report form synchronized with reporting guidelines so users know what information to supply before submitting.

## Best solution

Make applicable reporting requirements clear within the issue reporter and establish how its guidance stays consistent with the published guidelines. The area owner should decide whether shared content or maintenance checks best meets that goal without making every diagnostic attachment mandatory.
