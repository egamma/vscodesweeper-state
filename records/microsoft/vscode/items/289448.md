# Issue #289448 — Chat editor unexpectedly closes when switching git branches with SCM Working Sets enabled

[https://github.com/microsoft/vscode/issues/289448](https://github.com/microsoft/vscode/issues/289448)

## Summary

The reported silent-close path remains in current main when switching to a saved working set that omits the chat editor. Keep this team-authored bug open; neither a fixing commit nor an eligible canonical duplicate was established.

## Change summary

Prevent SCM working-set restoration from unexpectedly closing chat editors containing active conversations or pending edits.

## Best solution

Establish a chat-editor preservation policy for SCM working-set restoration without changing intentional manual-close or background-session behavior. The maintainer should settle whether these editors always remain visible or receive protection only while active or holding pending edits.
