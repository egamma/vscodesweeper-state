# Issue #309782 — Infinite marker re-registration loop in clearAllMarkers causes UnresponsiveSampleError

[https://github.com/microsoft/vscode/issues/309782](https://github.com/microsoft/vscode/issues/309782)

## Summary

Still reproduces on current main: the infinite loop between xterm's `clearAllMarkers` (live `.length` iteration) and VS Code's `setupRecreatingStartMarker` (marker-on-dispose recreation) remains unguarded. The fix could be applied on either side — xterm should snapshot the array length or suppress `onDispose` during clear, and/or VS Code's recreation helper should detect the clearing state.

## Change summary

Exiting alternate screen buffer triggers an infinite loop when `clearAllMarkers` disposes markers that VS Code's chat agent tool strategy helper immediately re-registers, freezing the renderer.

## Best solution

Guard `setupRecreatingStartMarker` in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/executeStrategy/strategyHelpers.ts` to not re-register during a bulk clear (e.g. defer recreation via `queueMicrotask` or check a flag). Independently, file or verify an upstream xterm.js issue requesting that `clearAllMarkers` snapshot the array length before iterating, or suppress `onDispose` during the clear.
