# Issue #301736 — Unified Agents Bar: switching to Commands or Files removes focus from search input

[https://github.com/microsoft/vscode/issues/301736](https://github.com/microsoft/vscode/issues/301736)

## Summary

The focus loss remains source-reproducible on current main: clicking a tab focuses the radio control, while the tab-selection path switches providers without restoring focus to the quick-input text field.

## Change summary

Switching the Unified Agents Bar from Sessions to Commands or Files prevents immediate typing because focus remains on the selected tab.

## Best solution

Keep the quick-input text field focused after a pointer-driven tab switch so users can continue typing immediately, while preserving keyboard accessibility for the tab controls.
