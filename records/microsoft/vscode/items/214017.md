# Issue #214017 — Support showing Pull Request comments on notebook cells

[https://github.com/microsoft/vscode/issues/214017](https://github.com/microsoft/vscode/issues/214017)

## Summary

Keep open: current notebook commenting still does not map backing-file PR comment ranges onto notebook cells. An open contributor PR explicitly addresses this issue and needs maintainer review rather than a competing implementation.

## Change summary

Show pull request comments attached to notebook backing-file ranges on the corresponding cells in the notebook editor.

Review https://github.com/microsoft/vscode/pull/246317 with the notebook and commenting owners, settle the serializer mapping contract, and land an agreed solution that preserves comment identity and existing text-editor behavior.
