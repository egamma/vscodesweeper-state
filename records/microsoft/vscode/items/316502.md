# Issue #316502 — Reintroduce find/grep/tree compression with smart summarization

[https://github.com/microsoft/vscode/issues/316502](https://github.com/microsoft/vscode/issues/316502)

## Summary

Team-authored feature request (MEMBER) to reintroduce find/grep/tree compression filters with smart summarization instead of naive line capping. The filters were removed in PR #316500 / commit 0ccbe887a1c to avoid model refetch behavior. This needs maintainer judgment on the new summarization design.

## Change summary

Reintroduce find, grep, and tree output compression filters with directory/file-grouped summarization instead of the removed naive 200-line cap.

## Best solution

Implement smart summarization in `toolResultCompressorService.ts` — directory-grouped counts for find, file-grouped match counts for grep (with passthrough for small outputs), and noise-directory stripping for tree — so the model gets a compact but lossless view of results without triggering refetch.
