# Issue #331815 — Pet should hide when going on run regardless of size

[https://github.com/microsoft/vscode/issues/331815](https://github.com/microsoft/vscode/issues/331815)

## Summary

Current source confirms that the run transition does not account for the pet's size, leaving sufficiently enlarged pets visible. This team-authored issue should remain open for a bounded CSS and test fix.

## Change summary

Make the pet move fully out of view when sent on the run at any supported size.

## Best solution

Make the on-the-run displacement follow the pet's current rendered height while preserving the existing return animation and run-layer stacking behavior.
