# Issue #331815 — Pet should hide when going on run regardless of size

[https://github.com/microsoft/vscode/issues/331815](https://github.com/microsoft/vscode/issues/331815)

## Summary

Real, source-confirmed bug: the 'go on the run' hide effect for the chat pet uses a fixed CSS translateY offset that doesn't scale with the pet's size, so a pet grown large barely moves and stays mostly visible instead of hiding.

## Change summary

When the chat pet is scaled up to a large size and put 'on the run', it should slide out of view but instead only shifts by a small, fixed amount and remains largely visible.

## Best solution

Make the on-the-run/searching hide offset scale with the pet's current display size (e.g. compute it from `_getDisplaySize()`/`_scale` in chatPetWidget.ts and apply it inline, or switch the CSS rule to a percentage of the element's own box) instead of the fixed `--vscode-spacing-size400`/`size240`/`size60` tokens in chatPet.css.
