# Issue #111669 — Extension bisect unable to find 2 bad extensions

[https://github.com/microsoft/vscode/issues/111669](https://github.com/microsoft/vscode/issues/111669)

## Summary

Valid feature request: extension bisect still uses a single-pass binary search that can only identify one bad extension. The algorithm and UI have not been updated to support finding multiple problematic extensions. Stays open as an enhancement request.

## Change summary

Extension Bisect should be able to identify multiple bad extensions in a single bisect session, rather than only finding one.

## Best solution

Enhance the bisect algorithm in `extensionBisect.ts` to iteratively find multiple bad extensions — either by re-running the binary search on the remaining set after each bad extension is found, or by implementing the recursive splitting approach sketched in comment 2. The related issue https://github.com/microsoft/vscode/issues/237092 (keeping already-eliminated extensions disabled) is a complementary improvement that would also help. Both should be considered together.
