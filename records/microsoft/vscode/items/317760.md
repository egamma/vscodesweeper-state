# Issue #317760 — Agents: Multiple Secessions Visible UX

[https://github.com/microsoft/vscode/issues/317760](https://github.com/microsoft/vscode/issues/317760)

## Summary

Keep this team-authored UX exploration open for an owner-led design review. Current source includes active-session styling, sticky list markers, and directional drop overlays, but those implementations do not establish that the discussion's full scope is complete.

## Change summary

Explore how multiple visible agent sessions communicate active state, visible/sticky state in the sidebar, and drag-and-drop destinations.

## Best solution

Have the owner assess the existing multi-session affordances together and record which design questions remain, with focused follow-up issues for any agreed changes. Distinguish active, visible, and sticky states without making secondary sessions compete visually with the active one.
