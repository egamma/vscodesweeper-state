# Issue #199410 — Settings Editor isn't updated until focused

[https://github.com/microsoft/vscode/issues/199410](https://github.com/microsoft/vscode/issues/199410)

## Summary

Still reproduces on main: the Settings Editor intentionally defers re-rendering when a setting control is focused (to avoid disrupting active input), but this also blocks updates from external changes to the same setting, leaving the UI stale until blur.

## Change summary

Settings Editor does not visually update a setting's value when that setting is changed externally while the same setting control is focused.

## Best solution

Refine the deferred-refresh logic in `renderTree()` so that externally-sourced configuration changes (those not initiated by the Settings Editor itself) bypass the focus-guard and render immediately, even when the changed setting is currently focused. The fix belongs in `src/vs/workbench/contrib/preferences/browser/settingsEditor2.ts` around the `scheduleRefresh`/`renderTree` interaction.
