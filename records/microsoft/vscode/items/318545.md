# Issue #318545 — Support BYOK/Custom Models for Inline Code Completions

[https://github.com/microsoft/vscode/issues/318545](https://github.com/microsoft/vscode/issues/318545)

## Summary

Legitimate, high-demand feature request (153 upvotes, promoted to Backlog) for BYOK/custom model support in inline completions. The limitation is confirmed in the current source — the model validation in model.ts still rejects user-selected models not in the API-provided list. No fix or implementation has landed on main.

## Change summary

Allow users to configure custom/OpenAI-compatible models for inline code completions, not just chat.

## Best solution

Extend the completions model selection in `extensions/copilot/src/extension/completions-core/vscode-node/lib/src/openai/model.ts` to accept BYOK-registered models (similar to how chat already supports them via `chatLanguageModels.json`), routing requests to the user-configured endpoint instead of falling back to the default cloud model. This requires a product decision on endpoint configuration UX and model capability validation.
