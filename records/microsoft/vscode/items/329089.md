# Issue #329089 — The "chatLanguageModels.json" file allows for the option to inherit from the default profile.

[https://github.com/microsoft/vscode/issues/329089](https://github.com/microsoft/vscode/issues/329089)

## Summary

Confirmed gap on main: `ProfileResourceType.LanguageModels` and `languageModelsResource` exist on the profile model, but the Profiles editor's resource-type list and the profile copy/import machinery never wire it in, so non-default profiles get an empty, non-inheriting `chatLanguageModels.json` with no UI toggle.

## Change summary

Custom `chatLanguageModels.json` entries defined in the default profile aren't inherited by (or toggleable as 'Use Default' for) non-default profiles.

## Best solution

Add `ProfileResourceType.LanguageModels` to the resource-type list and copy-flag wiring in src/vs/workbench/contrib/userDataProfile/browser/userDataProfilesEditorModel.ts (mirroring how Mcp/Tasks were added), and a corresponding resource handler (like mcpProfileResource.ts) so the Profiles UI can toggle 'Use Default' for chat language models, consistent with other resource types.
