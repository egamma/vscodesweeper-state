# Issue #329089 — The "chatLanguageModels.json" file allows for the option to inherit from the default profile.

[https://github.com/microsoft/vscode/issues/329089](https://github.com/microsoft/vscode/issues/329089)

## Summary

Keep open: current main supports default-profile language-model inheritance internally, but the Profiles editor still provides no way to select it. This is a missing profile-management capability rather than evidence that an empty profile configuration should automatically inherit.

## Change summary

Allow non-default profiles to reuse the Default profile's chatLanguageModels.json without manually copying its contents.

## Best solution

Expose language-model configuration as an inheritable resource in the Profiles editor, using the existing languageModels profile flag. Prefer explicit opt-in inheritance to preserve independent profile configurations; confirm that product choice before implementation.
