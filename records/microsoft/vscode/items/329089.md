# Issue #329089 — The "chatLanguageModels.json" file allows for the option to inherit from the default profile.

[https://github.com/microsoft/vscode/issues/329089](https://github.com/microsoft/vscode/issues/329089)

## Summary

Confirmed real gap on main: profiles fully support 'use default' inheritance for mcp.json and other resources, but chatLanguageModels.json has no such UI path, so non-default profiles silently start with an empty custom-models list.

## Change summary

Non-default profiles don't inherit chatLanguageModels.json from the default profile, and the Profiles editor UI doesn't expose it as a toggleable/inheritable resource like it does for mcp.json.

## Best solution

Add a LanguageModelsResourceTreeItem (mirroring src/vs/workbench/services/userDataProfile/browser/mcpProfileResource.ts) and wire ProfileResourceType.LanguageModels into the resource-type list and switch statements in userDataProfilesEditorModel.ts, so users can toggle 'use default' for chat language models the same way they can for MCP servers.
