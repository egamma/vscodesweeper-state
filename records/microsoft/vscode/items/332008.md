# Issue #332008 — "Export Chat as Zip" doesn't work from remote session

[https://github.com/microsoft/vscode/issues/332008](https://github.com/microsoft/vscode/issues/332008)

## Summary

The remote export failure is still present on current main. The save dialog can return a remote URI, but the archive is created by the local native host using that URI's local-platform filesystem path.

## Change summary

Export Chat as Zip fails when a remote-session user selects a destination in the remote workspace.

## Best solution

Allow chat ZIP exports to reach either local or remote destinations: create the archive where the native ZIP implementation can write it, then persist it through the file service when the selected destination is remote, with temporary resources cleaned up.
