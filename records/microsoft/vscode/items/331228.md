# Issue #331228 — Chat input min width hides send button

[https://github.com/microsoft/vscode/issues/331228](https://github.com/microsoft/vscode/issues/331228)

## Summary

The narrow-width failure remains explainable on current main: the chat input is a flex item with an automatic minimum width, so its right edge and send control can be clipped when the row becomes narrower than its contents. This team-authored bug should remain open; no older issue with the same observable symptom or issue-referencing fix was found.

## Change summary

Keep the chat send button visible and usable when the chat input is resized to a very narrow width.

## Best solution

Make the chat input row degrade responsively at narrow widths while preserving the execute toolbar and send control, with less essential input actions shrinking or overflowing first.
