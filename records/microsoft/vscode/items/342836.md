# Issue #342836 — Revoke Trust of Workspace Based on Time or Sensitive Changes

[https://github.com/microsoft/vscode/issues/342836](https://github.com/microsoft/vscode/issues/342836)

## Summary

Keep open for human security and Workspace Trust design review: existing controls do not provide time-bound or content-aware revalidation. The proposal concerns workspace-controlled execution and supply-chain compromise, so the security-sensitive keep-open rule applies.

## Change summary

Add optional time-based and sensitive-change-based Workspace Trust revalidation before affected execution, including during active sessions.

## Best solution

Have the Workspace Trust owners define the threat model and revalidation contract, including inherited trust, execution ordering, enterprise enforcement, and prompt fatigue. Treat protection against changes to repository content separately from the comment's question about malicious tools modifying local trust state.
