# Issue #342836 — Revoke Trust of Workspace Based on Time or Sensitive Changes

[https://github.com/microsoft/vscode/issues/342836](https://github.com/microsoft/vscode/issues/342836)

## Summary

Keep open for human security review: existing controls do not provide time-bound or content-sensitive trust revalidation. The supply-chain execution scenario and trust-store integrity question make this security-sensitive, so a cleanup close is inappropriate.

## Change summary

Add optional time-bound and change-aware workspace trust revalidation before affected execution, including changes during an active session.

## Best solution

Workspace Trust owners should establish the threat model and approval semantics for changed executable content, inherited trust, and enterprise enforcement. Any accepted design should block affected execution before approval while avoiding prompts for ordinary edits.
