# Issue #298730 — Inconsistent comment toggle in in `.ini` / `.properties` depending on which file is opened first

[https://github.com/microsoft/vscode/issues/298730](https://github.com/microsoft/vscode/issues/298730)

## Summary

Keep open: the reported opening-order dependence matches a concrete grammar-cache collision in the bundled vscode-textmate dependency. The older reports are closed, and the verified open commenting issue concerns a different symptom, so neither provides a duplicate target.

## Change summary

Toggle Line Comment should consistently use semicolons for INI files and hash characters for Properties files, regardless of which language was opened first.

## Best solution

Ensure vscode-textmate preserves each requested initial language when languages share a grammar scope, and verify that VS Code receives the correct token language IDs in both opening orders. Preserve the existing INI and Properties comment configurations and embedded-language commenting behavior.
