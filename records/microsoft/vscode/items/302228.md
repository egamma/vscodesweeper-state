# Issue #302228 — Chat agent debug log view: Embedded 'output' editors should offer find

[https://github.com/microsoft/vscode/issues/302228](https://github.com/microsoft/vscode/issues/302228)

## Summary

Keep open: the current tool-output detail renderer still has no in-place Find capability. Open in Editor provides a searchable workaround, but does not satisfy the request to search output without leaving the debug view.

## Change summary

Allow searching within large tool-call outputs directly in the Chat agent debug log detail view.

## Best solution

Provide keyboard-accessible Find within displayed tool-call output, including match navigation and revealing matches in long content. Retain Open in Editor as an alternative rather than requiring it for search.
