[https://github.com/microsoft/vscode/issues/332295](https://github.com/microsoft/vscode/issues/332295)

## Summary

Current main intentionally pins and packages compatible SDK versions rather than resolving an untested latest release, while already providing local SDK-root overrides for both Claude and Codex. The existing override path satisfies the request's stated alternative, so this can close as designed.

## Change summary

Automatically use the latest Claude/Codex SDK or let users select a locally installed SDK version.

## Best solution

Keep release SDKs reproducibly pinned and validated in lockstep, while using the existing local-root overrides when developing or testing another SDK version.

  > Thanks for the request. Agent Host intentionally uses exact SDK pins so the packaged runtime and lockfiles stay tested in lockstep, rather than automatically loading an unvalidated latest release. Local-version overrides already cover the development scenario: use `chat.agentHost.codexAgent.sdkRoot` (or `VSCODE_AGENT_HOST_CODEX_SDK_ROOT`) for Codex and `VSCODE_AGENT_HOST_CLAUDE_SDK_ROOT` for Claude.

## Evidence

- **local Claude override:** src/vs/platform/agentHost/common/agentService.ts defines `VSCODE_AGENT_HOST_CLAUDE_SDK_ROOT`, and src/vs/platform/agentHost/node/agentSdkDownloader.ts resolves each SDK's override before consulting product configuration or downloading.
- **local Codex override:** src/vs/platform/agentHost/common/agentHostStarter.config.contribution.ts registers `chat.agentHost.codexAgent.sdkRoot`, an experimental advanced setting that selects a local `node_modules/@openai/codex` tree instead of downloading the SDK; `VSCODE_AGENT_HOST_CODEX_SDK_ROOT` is the corresponding environment override.
- **intentional version pinning:** build/agent-sdk/test/versionSync.test.ts explicitly requires each SDK's build pin, root runtime dependency, and lockfile version to match, with the build pin designated as the source of truth.
- **release distribution design:** build/agent-sdk/README.md documents per-platform, exact-version SDK tarballs stamped into `product.agentSdks`; src/vs/platform/agentHost/node/agentSdkDownloader.ts caches them by package, configured version, and target.
