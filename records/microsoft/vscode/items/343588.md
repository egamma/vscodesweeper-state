# Issue #343588 — Agent Host (Copilot CLI) sessions don't substitute ${input:...} values in mcp.json env, so registry-installed stdio servers fail to start

[https://github.com/microsoft/vscode/issues/343588](https://github.com/microsoft/vscode/issues/343588)

## Summary

The user-level forwarding defect remains in current main: input references are recognized as unsupported but still copied unchanged into the Agent Host bundle. Keep this report open; explicit migration support and the related registry/install issues do not resolve this automatic-forwarding failure.

## Change summary

Prevent user-level MCP servers from receiving unresolved ${input:...} environment values when started in Agent Host sessions.

## Best solution

Ensure legacy user MCP configurations never launch with unresolved VS Code input references. The MCP owner should settle whether automatic forwarding supports input resolution or instead requires an explicit, actionable migration step, consistent with the established portable-configuration direction.
