# Issue #343588 — Agent Host (Copilot CLI) sessions don't substitute ${input:...} values in mcp.json env, so registry-installed stdio servers fail to start

[https://github.com/microsoft/vscode/issues/343588](https://github.com/microsoft/vscode/issues/343588)

## Summary

The user-level forwarding path still sends unresolved input references on current main, so the central failure remains actionable. Workspace-folder input handling and explicit migration do not resolve this automatic user-config sync defect.

## Change summary

Agent Host sessions forward user-level MCP environment variables containing unresolved ${input:...} references instead of supplying the values used by Local sessions.

## Best solution

Make automatic user-level MCP delivery honor resolved inputs consistently with Local sessions, including cached values and the input-prompt lifecycle, while preserving existing access controls and secret-storage behavior. Explicit migration should remain a separate operation rather than a prerequisite for registry-installed servers to work.
