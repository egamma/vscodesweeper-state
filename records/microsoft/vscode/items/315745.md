# Issue #315745 — Two scrollbars in plan widget

[https://github.com/microsoft/vscode/issues/315745](https://github.com/microsoft/vscode/issues/315745)

## Summary

The nested scrollbar defect remains relevant on current main, and a later independent report describes the same observable symptom. This team-authored Backlog bug must stay open because there is no cited fix or older canonical issue.

## Change summary

The plan review widget can display its own vertical scrollbar alongside the enclosing chat scrollbar.

## Best solution

Adjust the plan review widget's constrained-height layout so the plan body has one intentional scrolling region without producing a second adjacent scrollbar from the enclosing surface.
