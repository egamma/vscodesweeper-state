# Issue #290266 — Need a way to inspect every tool call to understand how the LLM operates / what bugs the tools have

[https://github.com/microsoft/vscode/issues/290266](https://github.com/microsoft/vscode/issues/290266)

## Summary

Team-authored feature request (MEMBER) — must keep open. The Agent Debug Panel now exists with tool call rendering, but the specific ask for a quick link from the main chat window to inspect individual tool calls remains an open design question, with active discussion among team members.

## Change summary

Add a way to quickly inspect tool call inputs/outputs from the main chat window, e.g. via a pill or link that opens the debug view for that specific call.

## Best solution

Add a lightweight affordance (pill, badge, or hover link) on tool invocations in the main chat widget that deep-links to the corresponding tool call detail in the Agent Debug Panel. The last comment from justschen suggests showing something on hover to avoid cluttering the chat. The relevant code lives in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/` (chat-side) and `src/vs/workbench/contrib/chat/browser/chatDebug/` (debug panel side).
