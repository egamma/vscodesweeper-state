# Issue #290266 — Need a way to inspect every tool call to understand how the LLM operates / what bugs the tools have

[https://github.com/microsoft/vscode/issues/290266](https://github.com/microsoft/vscode/issues/290266)

## Summary

The Agent Debug Panel partially addresses tool call inspection, but the specific ask — a lightweight pill or hover link in the main chat window that opens tool call input/output — remains unimplemented and is still under active team discussion (comments 5–6).

## Change summary

Add a quick way to inspect individual tool call inputs and outputs directly from the main chat window, without navigating to the separate debug log view.

## Best solution

Add a subtle tool-call indicator (pill or hover link) in the main chat response stream that opens the tool call's input/output in the Agent Debug Panel or a new editor tab. The rendering logic in `src/vs/workbench/contrib/chat/browser/chatDebug/chatDebugToolCallContentRenderer.ts` already tokenizes and formats tool call content — this is about surfacing an entry point from the chat widget itself.
