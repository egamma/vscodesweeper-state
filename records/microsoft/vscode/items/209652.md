# Issue #209652 — [Feature request] Native VS Code support for GitHub Alerts

[https://github.com/microsoft/vscode/issues/209652](https://github.com/microsoft/vscode/issues/209652)

## Summary

Partially implemented: the `supportAlertSyntax` property on `MarkdownString` landed via PR #272228 (commit 807d43abb4f) but remains a proposed API (`vscode.proposed.markdownAlertSyntax.d.ts`). The team explicitly stated they don't intend to enable alerts in the markdown file preview or notebooks by default, and @alexr00 moved it to the Backlog noting it's not ready to finalize. Ongoing work remains — keep open.

## Change summary

Add native VS Code support for rendering GitHub-style alert/admonition syntax (NOTE, TIP, IMPORTANT, WARNING, CAUTION) in markdown.

## Best solution

Finalize the `markdownAlertSyntax` proposed API so extensions can opt into alert rendering in MarkdownStrings. The community also wants opt-in support in the markdown file preview (via a setting or a built-in markdown-it plugin), which the team hasn't committed to yet — that decision should be made explicitly.
