# Issue #209652 — [Feature request] Native VS Code support for GitHub Alerts

[https://github.com/microsoft/vscode/issues/209652](https://github.com/microsoft/vscode/issues/209652)

## Summary

Keep open: MarkdownString alert rendering is implemented, but the API remains proposed and the maintainer explicitly deferred finalization. The api-proposal label protects this tracking issue from a completed close.

## Change summary

Provide native rendering of GitHub-style Markdown alerts, with the accepted implementation scoped to opt-in MarkdownString content.

## Best solution

Retain this issue for the API owners to finalize or explicitly abandon MarkdownString.supportAlertSyntax. Preserve the documented boundary that Markdown file previews and notebooks obtain alert rendering through markdown-it extensions rather than enabling it by default.
