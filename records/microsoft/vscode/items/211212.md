## Summary

Still unfixed on main: remote server process memory is reported as 0 in Process Explorer. The bug is confirmed and labeled, and no fix commit references this issue.

## Change summary

Process Explorer and `code --status` show all remote server (WSL) process memory as 0 MB instead of actual values.

## Best solution

Investigate why `listProcesses` in `src/vs/base/node/ps.ts` returns 0 for `mem` when invoked on the remote server. The `ps -ax -o pmem=` output or `ps.sh` fallback calculation may be failing silently for the remote server's process tree — the fix likely involves ensuring `totalmem()` and the `pmem` percentage are properly computed when running as a remote server process.
