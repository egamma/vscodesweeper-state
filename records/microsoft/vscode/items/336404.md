# Issue #336404 — Markdown edit button doesn't respect the "workbench.reduceMotion" setting

[https://github.com/microsoft/vscode/issues/336404](https://github.com/microsoft/vscode/issues/336404)

## Summary

Keep open: the Markdown editor's toggle animation respects the operating system's reduced-motion preference, but not VS Code's explicit workbench.reduceMotion setting. The current integration still leaves this accessibility gap.

## Change summary

Suppress the Markdown edit/read-only toggle animation when workbench.reduceMotion is enabled.

## Best solution

Make the built-in Markdown editor honor the reduced-motion state already supplied to its webview, including changes while the editor remains open, without altering the toggle's functionality or normal-motion behavior.
