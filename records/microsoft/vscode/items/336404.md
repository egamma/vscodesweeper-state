# Issue #336404 — Markdown edit button doesn't respect the "workbench.reduceMotion" setting

[https://github.com/microsoft/vscode/issues/336404](https://github.com/microsoft/vscode/issues/336404)

## Summary

Plausible, well-described bug: the generic webview host already applies a `.vscode-reduce-motion` class based on `workbench.reduceMotion` to every webview body, but the new Markdown editor's edit/read-only toggle button (built from the external `@vscode/markdown-editor` package) doesn't appear to react to it, so its entrance animation still plays.

## Change summary

The animated edit/read-only toggle button in the (new hybrid) Markdown editor ignores `workbench.reduceMotion: on`.

## Best solution

Gate the toggle button's CSS animation on the `vscode-reduce-motion` body class (or the equivalent reduced-motion signal) the webview host already sets; the fix likely lives in the `@vscode/markdown-editor` npm package (bundled via `extensions/markdown-language-features/markdown-editor-src/editor.ts` and built to `markdown-editor-out/editor.css`), not in this repo's own sources.
