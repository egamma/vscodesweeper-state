# Issue #336404 — Markdown edit button doesn't respect the "workbench.reduceMotion" setting

[https://github.com/microsoft/vscode/issues/336404](https://github.com/microsoft/vscode/issues/336404)

## Summary

Credible, well-described report (screenshot, exact setting), but the edit/read-only toggle button lives in the external `@vscode/markdown-editor` npm package, whose CSS isn't vendored in this checkout, so I can't confirm the current animation code directly — asking the reporter to confirm it still reproduces on the latest Insiders build, since that dependency iterates quickly (pinned at `^0.0.2-99`).

## Change summary

The edit/read-only toggle button in the new Markdown editor animates even when `workbench.reduceMotion` is set to `on`.

## Best solution

Guard the toggle button's attention animation with the reduce-motion signal in `@vscode/markdown-editor`'s own editor.css, mirroring the pattern already used in this repo's chatRichLink.css (`.monaco-reduce-motion` for main-window UI; the webview host already exposes a `vscode-reduce-motion` body class per src/vs/workbench/contrib/webview/browser/pre/index.html, so the same mechanism is available inside the markdown editor's webview).
