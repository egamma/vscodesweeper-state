# Issue #306261 — git integration can fork wrong repository when there is a period in the repository name

[https://github.com/microsoft/vscode/issues/306261](https://github.com/microsoft/vscode/issues/306261)

## Summary

The incorrect fork target is still reproducible from current source, but the same observable defect is already tracked by the older, open issue https://github.com/microsoft/vscode/issues/300647. Consolidate there, preserving this report's confirmation that an explicit .git suffix does not avoid the problem.

## Change summary

Preserve periods in GitHub repository names when offering and creating a fork after a permission-denied push.

## Best solution

Resolve the repository-name truncation under https://github.com/microsoft/vscode/issues/300647 so both the fork prompt and GitHub API request target the complete repository name, with or without a trailing .git suffix.
