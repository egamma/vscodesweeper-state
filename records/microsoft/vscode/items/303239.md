# Issue #303239 — Open file automatically adding to contexted files

[https://github.com/microsoft/vscode/issues/303239](https://github.com/microsoft/vscode/issues/303239)

## Summary

Current VS Code intentionally surfaces the active editor as implicit chat context, with different inclusion behavior by mode. The existing `chat.implicitContext.enabled` setting provides the requested opt-out, so no additional product change is needed.

## Change summary

Prevent an open editor from appearing automatically in Copilot Chat context, including when text is selected.

## Best solution

Keep the current mode-aware implicit-context behavior and use `chat.implicitContext.enabled` with the `panel` value set to `never` for users who want context added only explicitly.
