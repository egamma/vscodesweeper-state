# Issue #296543 — Smarter command line options UI (contextual options for tools like 'head' and 'python')

[https://github.com/microsoft/vscode/issues/296543](https://github.com/microsoft/vscode/issues/296543)

## Summary

Current terminal approval actions already recognize subcommands, but they group suggested rules together and deliberately omit interpreter-wide suggestions for Python. The requested independently contextual controls remain a meaningful UI gap; no verified canonical owns that same request, and this team-authored item should stay open for design.

## Change summary

Provide contextual controls for individual executables within complex terminal command lines instead of relying on whole-command approval.

## Best solution

Design a terminal confirmation experience that clearly distinguishes individual executable or subcommand choices from whole-command approval, building on the existing parsed-command information. Decide what useful, narrowly scoped Python options should mean without weakening existing approval safeguards.
