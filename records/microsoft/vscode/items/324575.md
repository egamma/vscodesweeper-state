# Issue #324575 — Inconsistent wording of org policy enforcement

[https://github.com/microsoft/vscode/issues/324575](https://github.com/microsoft/vscode/issues/324575)

## Summary

Confirmed on main: two different UI surfaces use inconsistent wording for the same policy-managed-setting condition. This is a small, legitimate wording cleanup that should just be routed to the settings-editor area rather than closed.

## Change summary

The tooltip in the Settings editor's scope-override indicator and the marker message in the settings JSON editor use different wording to describe the same 'setting is locked by org policy' state.

## Best solution

Unify the two strings (or at least align their phrasing) — one lives in settingsEditorSettingIndicators.ts ('policyDescription') and the other in preferencesRenderers.ts ('unsupportedPolicySetting') — so users see one consistent explanation regardless of which UI surface they hit.
