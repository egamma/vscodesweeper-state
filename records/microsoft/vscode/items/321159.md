# Issue #321159 — Terminal: glyphs overlap / are too close with Iosevka on Linux (WebGL renderer)

[https://github.com/microsoft/vscode/issues/321159](https://github.com/microsoft/vscode/issues/321159)

## Summary

Legitimate WebGL renderer bug with Iosevka on Linux — already labeled info-needed with a maintainer engaged, awaiting regression info from the reporter. The hard keep-open rule for info-needed bugs doesn't apply here because info-needed is already in place (the maintainer applied it); keeping open is correct while waiting for the 7-day auto-close cycle.

## Change summary

Terminal glyphs rendered with Iosevka font overlap or are too close together on Linux when the WebGL renderer is active; disabling GPU acceleration resolves it.

## Best solution

The root cause is likely in xterm.js's WebGL renderer font-metrics/cell-width measurement for Iosevka on Linux. Once the reporter confirms whether it's a regression, the terminal team can decide whether to fix the measurement in xterm.js upstream or add a workaround in VS Code's terminal integration. If confirmed as an xterm.js issue, file upstream at xtermjs/xterm.js with the reproduction details.
