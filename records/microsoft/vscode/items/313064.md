# Issue #313064 — Keep getting "Co-authored-by: Copilot" in commit messages for no reason

[https://github.com/microsoft/vscode/issues/313064](https://github.com/microsoft/vscode/issues/313064)

## Summary

The default-off and disable-AI safeguards have landed, but third-party inline completions can still receive a Copilot trailer when git.addAICoAuthor is explicitly set to all. Keep this report open: the remaining attribution defect is visible in current source, and the newer update issue does not qualify as a duplicate canonical for this re-reviewed item.

## Change summary

Prevent third-party AI completions from being credited to Copilot and avoid unexpected commit-message changes without consent.

## Best solution

Ensure attribution reflects the actual contribution source, while preserving the default-off and disable-AI safeguards. Complete the maintainer-supported consent and commit-message visibility behavior rather than treating the default change as a complete fix.
