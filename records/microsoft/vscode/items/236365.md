# Issue #236365 — "Undo" history lost after "Save as".

[https://github.com/microsoft/vscode/issues/236365](https://github.com/microsoft/vscode/issues/236365)

## Summary

Verified duplicate of #17977, which tracks preserving undo/redo history across Save As and untitled-file saves. The behavior is structural — Save As creates a new model for the target URI, and undo/redo state is not transplanted. The canonical issue has detailed team discussion on the approach.

## Change summary

Undo/redo history is lost when using Save As because the target file gets a new model without the source's undo stack.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/17977 — it tracks the exact same capability (transplanting undo/redo stack elements to a new URI on Save As) with a clear technical path discussed by the undo/redo and workbench owners.
