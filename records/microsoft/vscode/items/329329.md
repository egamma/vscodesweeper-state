# Issue #329329 — Regression: Modern UI rounded corners break edge scrollbar dragging behavior

[https://github.com/microsoft/vscode/issues/329329](https://github.com/microsoft/vscode/issues/329329)

## Summary

Traced a plausible source-level mechanism for this in the experimental Modern UI style overrides: enabling it wraps the editor part in a 1px border (box-sizing: border-box), which insets the editor content — including the vertical scrollbar — from the raw window edge. This is consistent with, but not a confirmed OS-level reproduction of, the reported edge-throw regression.

## Change summary

With the experimental Modern UI setting enabled, the editor's rounded-corner border insets the vertical scrollbar from the physical screen edge, breaking the OS 'throw to edge' scrollbar-drag gesture.

## Best solution

Route to the Modern UI / style-overrides owners: if the 1px editorBorder inset (src/vs/workbench/contrib/styleOverrides/browser/media/editorBorder.css) is confirmed as the cause, either keep the scrollbar's hit-test region flush with the window edge (independent of the visual border) or accept the suggested invisible edge-hit-area extension; a maintainer with a Windows box should confirm the OS-level edge-throw behavior before committing to a specific fix.

## Evidence

- **editor border module:** src/vs/workbench/contrib/styleOverrides/browser/media/editorBorder.css adds `border: var(--vscode-strokeThickness) solid ...` with `box-sizing: border-box` around `.monaco-grid-view .part.editor`, gated on `.style-override` (set by `workbench.experimental.modernUI`). This insets the editor content (including its vertical scrollbar) by 1px from the allocated editor-part edge without changing the part's outer size.
- **rounded corners module:** src/vs/workbench/contrib/styleOverrides/browser/media/roundedCorners.css also rounds the scrollbar slider itself (`.monaco-scrollable-element > .scrollbar > .slider`) under the same `.style-override` gate, part of the same visual redesign referenced in the report.
- **no OS-level test possible:** Could not execute a real mouse-drag test against the window edge in this read-only checkout; the causal chain from CSS inset to OS hit-testing is plausible but unverified.
