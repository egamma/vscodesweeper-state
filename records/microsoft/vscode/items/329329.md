# Issue #329329 — Regression: Modern UI rounded corners break edge scrollbar dragging behavior

[https://github.com/microsoft/vscode/issues/329329](https://github.com/microsoft/vscode/issues/329329)

## Summary

Legitimate regression: the Modern UI adds an outer margin around floating panels/editor (via --vscode-spacing-size40 in floatingPanels.css), so the physical screen edge no longer lands on the scrollbar hit area — a maintainer has already confirmed the exact gap in comments, so this stays open pending a design/implementation decision.

## Change summary

Rounded-corner/spacing changes in the Modern UI leave a gap between the window edge and scrollable panels, breaking the classic 'throw to screen edge' scrollbar-drag interaction.

## Best solution

Belongs with the workbench layout/modernization team: either extend the hit-testing region for scrollbars in edge-adjacent panels (editor, secondary sidebar, terminal) by a couple of DPI-aware pixels, or accept the tradeoff as-designed — a maintainer (hawkticehurst) is already engaging and should make that call; likely touches src/vs/workbench/browser/media/floatingPanels.css and the scrollbar mouse-down handling in src/vs/base/browser/ui/scrollbar/verticalScrollbar.ts.
