# Issue #219821 — Indent using spaces function does not convert tabs to spaces in mixed indentation text content

[https://github.com/microsoft/vscode/issues/219821](https://github.com/microsoft/vscode/issues/219821)

## Summary

Existing commands already provide the requested indentation conversion; the remaining concern is distinguishing configuration from conversion in the command names. Keep this open as a polish consideration: the existing bug classification bars an as-designed close without a later maintainer decision.

## Change summary

Clarify that “Indent Using Spaces” configures subsequent indentation, whereas “Convert Indentation to Spaces” rewrites existing leading whitespace.

## Best solution

Make the distinction between indentation configuration and content conversion clearer in the editor commands, preserving their separate behaviors. The reporter's mixed-indentation example is already handled by “Convert Indentation to Spaces”; whitespace alignment after non-whitespace characters is a separate concern.
