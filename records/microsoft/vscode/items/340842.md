Disabling `.claude/skills` and `.claude/commands` in `chat.agentSkillsLocations` still leaves `.claude/commands` entries listed as skills and available to models.

## Evidence

- **settings handling:** src/vs/workbench/contrib/chat/common/promptSyntax/utils/promptFilesLocator.ts (getLocalStorageFolders) honors disabled defaults for skills. The default skill folders in config/promptFileLocations.ts include `.claude/skills` but no `.claude/commands`.
- **commands as skills:** src/vs/platform/agentHost/node/claude/customizations/scan/claudeAgentSkillScan.ts folds `.claude/commands` into skills (`includeCommands` defaults to true) and never reads `chat.agentSkillsLocations`. A `.claude/commands: false` entry is not a recognised location, so it would have no effect here.
- **missing details:** The report doesn't say which session type was used or whether the commands appear in the Chat Customizations editor only or also reach the model.
