# Issue #317216 — the chat panel cannot delete the chat sessions from calude code

[https://github.com/microsoft/vscode/issues/317216](https://github.com/microsoft/vscode/issues/317216)

## Summary

Keep open: deleting imported Claude Code sessions remains a meaningful capability gap, and the report also describes entries surviving deletion outside VS Code. The related issues do not establish an older canonical that owns both behaviors.

## Change summary

Allow deleting imported Claude Code sessions from the Sessions panel and ensure externally deleted sessions no longer remain listed.

## Best solution

Provide provider-aware deletion for imported Claude Code sessions and reconcile the list with externally deleted history. Distinguish this imported-history path from native agent-host Claude sessions, which already expose deletion.
