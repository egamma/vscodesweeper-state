# Issue #326576 — VS Code launches `wsl.exe -l -q` in a visible console window on systems without WSL installed

[https://github.com/microsoft/vscode/issues/326576](https://github.com/microsoft/vscode/issues/326576)

## Summary

Confirmed on current main: `cp.exec('wsl.exe -l -q', ...)` in `terminalProfiles.ts` does not pass `windowsHide: true`, causing a visible console window on systems without WSL. The newer `wslRemoteAgentHostHelpers.ts` already uses `windowsHide: true` as the correct pattern.

## Change summary

VS Code's WSL profile detection spawns `wsl.exe -l -q` without `windowsHide: true`, causing a visible console window on systems without WSL installed.

## Best solution

Add `windowsHide: true` to the `cp.exec` options in `getWslProfiles()` at `src/vs/platform/terminal/node/terminalProfiles.ts:352`, matching the pattern already used in `wslRemoteAgentHostHelpers.ts`.
