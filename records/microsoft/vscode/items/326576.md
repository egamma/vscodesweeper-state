This matches the reporter's captured cmd.exe /d /s /c invocation; source inspection does not independently establish Windows console behavior.
- **Confirmed persistence and workaround limits:** https://github.com/microsoft/vscode/issues/233618#issuecomment-2954070195 reports that the unwanted prompt persisted in Insiders after an attempted fix. https://github.com/microsoft/vscode/issues/233618#issuecomment-2600376909 documents terminal.integrated.useWslProfiles=false as a workaround, while https://github.com/microsoft/vscode/issues/233618#issuecomment-4896374313 reports that it does not suppress the Agents Window case. Disabling discovery is not full coverage of this request for silent detection.
