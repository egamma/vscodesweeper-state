# Issue #300749 — Model picker should support fuzzy searching

[https://github.com/microsoft/vscode/issues/300749](https://github.com/microsoft/vscode/issues/300749)

## Summary

Still reproduces on main: the model picker's filter uses substring matching (`String.includes()`), not fuzzy matching, so typing 'cl op' for 'Claude Opus' yields no results. The defect is in the shared ActionListWidget filtering logic.

## Change summary

The model picker's search field does not support fuzzy matching — only exact substring matches work.

## Best solution

Replace the `matchesFilter` function in `ActionListWidget._applyFilter` (src/vs/platform/actionWidget/browser/actionList.ts, ~line 992) with a fuzzy-score-based filter using VS Code's existing `fuzzyScore` utility from `src/vs/base/common/filters.ts`, so that non-contiguous query terms like 'cl op' match 'Claude Opus'.
