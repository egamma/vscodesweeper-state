# Issue #187369 — Option-key navigation between words separated by a non-breaking space on a Mac

[https://github.com/microsoft/vscode/issues/187369](https://github.com/microsoft/vscode/issues/187369)

## Summary

Still reproduces on main: WordCharacterClassifier only classifies regular space and tab as Whitespace — non-breaking space (U+00A0) is left as Regular, so word navigation treats it as a word character and skips over it.

## Change summary

Option+Arrow word navigation on Mac skips over non-breaking spaces (U+00A0) instead of stopping at them, because they are classified as regular word characters rather than whitespace.

## Best solution

Add `this.set(CharCode.NoBreakSpace, WordCharacterClass.Whitespace)` alongside the existing Space/Tab entries in the `WordCharacterClassifier` constructor in `src/vs/editor/common/core/wordCharacterClassifier.ts`. This is a one-line fix with clear validation.
