# Issue #328807 — Terminal dictation, Chat dictation, editor dictation all have different microphone rendering experiences

[https://github.com/microsoft/vscode/issues/328807](https://github.com/microsoft/vscode/issues/328807)

## Summary

The microphone treatments remain different in current source: terminal and editor dictation animate icon colors, while Chat uses an audio-reactive glow. Keep this team-authored, accepted Backlog request open for a shared visual-design decision; no verified canonical covers all three surfaces.

## Change summary

Give terminal, editor, and Chat dictation a consistent microphone recording experience.

## Best solution

Agree on one recognizable recording-state treatment across the three dictation surfaces, preserving their placement and interaction needs. Decide whether consistency means adopting Chat's audio-reactive feedback everywhere or choosing another common treatment before implementation.
