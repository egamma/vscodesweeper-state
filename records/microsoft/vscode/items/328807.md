# Issue #328807 — Terminal dictation, Chat dictation, editor dictation all have different microphone rendering experiences

[https://github.com/microsoft/vscode/issues/328807](https://github.com/microsoft/vscode/issues/328807)

## Summary

Keep open: current source still gives chat an audio-reactive microphone glow while editor and terminal dictation use separate color-cycling animations. This accepted, team-authored consistency request has neither a verified full-scope duplicate nor an issue-referencing fix.

## Change summary

Make microphone listening feedback consistent across terminal, editor, and chat dictation.

## Best solution

Agree on a common listening-state visual language across all three dictation surfaces, preserving their contextual placement and respecting reduced motion and high-contrast themes. Coordinate the editor-only motion request without treating it as coverage of terminal and chat consistency.
