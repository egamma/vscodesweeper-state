# Issue #160711 — Given VS Code processes unique icons and titles on Windows

[https://github.com/microsoft/vscode/issues/160711](https://github.com/microsoft/vscode/issues/160711)

## Summary

Keep open: the built-in Process Explorer helps identify processes, but does not deliver distinct icons and titles in Windows Task Manager. No qualifying older canonical or concrete implementing commit was found.

## Change summary

Give VS Code processes distinguishable icons and descriptive titles in Windows Task Manager so users can identify their roles without inspecting long command lines.

## Best solution

Determine what Windows Task Manager process metadata the Electron runtime can expose, then use it to distinguish VS Code process roles. Preserve this Windows-specific request rather than replacing it with command-line identification or internal Process Explorer improvements.
