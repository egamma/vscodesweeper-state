# Issue #120521 — Enable Emmet abbreviations in `.js` files for CSS-in-JS (object syntax)

[https://github.com/microsoft/vscode/issues/120521](https://github.com/microsoft/vscode/issues/120521)

## Summary

Keep open: the Emmet integration still lacks the requested JavaScript-object output option. Existing language mappings and formatting preferences do not cover it, and no verified older duplicate owns the same request.

## Change summary

Expose Emmet's stylesheet.json option so CSS abbreviations can expand into JavaScript style-object properties in .js files.

## Best solution

Support an opt-in object-output mode through the built-in Emmet configuration and its helper, with camel-cased properties and appropriate JavaScript values. Preserve ordinary CSS and JSX expansion behavior rather than treating language mapping alone as a solution.
