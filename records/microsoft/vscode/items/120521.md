# Issue #120521 — Enable Emmet abbreviations in `.js` files for CSS-in-JS (object syntax)

[https://github.com/microsoft/vscode/issues/120521](https://github.com/microsoft/vscode/issues/120521)

## Summary

The request to expose Emmet's `stylesheet.json` option (for CSS-in-JS object syntax output) remains unimplemented — no such setting exists in the current Emmet extension configuration on main.

## Change summary

Expose Emmet's `stylesheet.json` config option in VS Code settings so CSS abbreviations can expand to JS object syntax in .js files.

## Best solution

Add a new `emmet.preferences` entry (or a dedicated setting) that passes the `stylesheet.json: true` option through to the Emmet library's config, enabling object-style CSS output for CSS-in-JS workflows. The change would live in `extensions/emmet/src/util.ts` (where Emmet config is assembled) and `extensions/emmet/package.json` (setting registration).
