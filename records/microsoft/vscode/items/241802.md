# Issue #241802 — Bug: Enter Press After ‘//’ Breaks Line and Converts Code to Comment in JavaScript

[https://github.com/microsoft/vscode/issues/241802](https://github.com/microsoft/vscode/issues/241802)

## Summary

Fixed on main: the onEnter comment-continuation regex was tightened in PR #321230 (commit 9b43a71f039) so that `//` inside strings or URLs no longer triggers unwanted comment insertion. The reported scenarios (string literals containing `//`, HTTP URLs) no longer match the rule.

## Change summary

Pressing Enter after `//` inside a string literal or URL in JavaScript incorrectly inserts `// ` on the next line, breaking code.

## Best solution

Keep the shipped fix in commit 9b43a71f039 — the new `beforeText` regex (`^\s*//|\s//\s`) requires `//` to be at the line start or surrounded by whitespace, which excludes `//` inside string literals and URLs. The open community PR #307798 can be closed as superseded.
