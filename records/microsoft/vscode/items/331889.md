# Issue #331889 — AgentHostPty is not disposed after terminal shutdown

[https://github.com/microsoft/vscode/issues/331889](https://github.com/microsoft/vscode/issues/331889)

## Summary

Confirmed on current main: AgentHostPty.shutdown() never calls dispose() on itself, and can hang indefinitely if _startBarrier never resolves — matching the reported leaked-disposable warning. An open PR (#331908) already targets this exact fix, so the issue should stay open for that PR to land rather than being auto-fixed or closed.

## Change summary

AgentHostPty's shutdown() clears its subscription and fires exit but doesn't dispose the pty object itself, and can block forever if initial hydration never completes.

## Best solution

Land https://github.com/microsoft/vscode/pull/331908 ("Dispose AgentHostPty after terminal shutdown"), which appears to directly address this report; verify it also unblocks shutdown when hydration is still pending before merging.
