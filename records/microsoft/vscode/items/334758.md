# Issue #334758 — Search in experimental model picker does not handle ArrowDown and Enter

[https://github.com/microsoft/vscode/issues/334758](https://github.com/microsoft/vscode/issues/334758)

## Summary

Traced a real defect in the tabbed model picker's keydown handler: when `chat.experimentalModelPicker` search is active, the filter input lives inside `.tabbed-action-list-tabbar` (via `filterInTabBar: true`), so the handler's `onTabBar` check matches the input too, which forces `listNavigation` false and skips both the ArrowDown and Enter branches — Enter never reaches `list.acceptSelected()`. The apparent ArrowDown highlight is actually the pre-focused first match from `focusFilterOnOpen`, not real navigation.

## Change summary

In the experimental (tabbed) model picker, pressing ArrowDown then Enter in the Search Models field doesn't select the highlighted model or close the picker.

## Best solution

In src/vs/platform/actionWidget/browser/tabbedActionListWidget.ts, refine the `onTabBar` check (around the keydown handler near line 415-445) so an event target inside the filter input (e.g. matching `.action-list-filter-input`) is not treated as being 'on the tab bar', letting ArrowUp/ArrowDown/Enter reach `list.focusNext/focusPrevious/acceptSelected` even when `filterInTabBar` places the filter inside the tab-strip container.

- **Fix prompt:**

  > In src/vs/platform/actionWidget/browser/tabbedActionListWidget.ts, the popup-level keydown handler (around lines 415-445) computes `onTabBar = !!target?.closest('.tabbed-action-list-tabbar')` and uses it to gate `listNavigation = !onTabBar && !onFooter && !onOwnControls`, which in turn guards the ArrowUp/ArrowDown/Enter branches that call `list.focusPrevious()`, `list.focusNext()`, and `list.acceptSelected()`. When a consumer sets `filterInTabBar: true` (as src/vs/workbench/contrib/chat/browser/widget/input/modelPicker/modelPickerTabbedWidget.ts does for the experimental model picker's Search Models field, `filterInTabBar: true` at line 177), the filter's `<input class="action-list-filter-input">` is appended into `filterSlot`, itself a child of `.tabbed-action-list-tabbar` (see tabbedActionListWidget.ts lines 244-251, 353).
