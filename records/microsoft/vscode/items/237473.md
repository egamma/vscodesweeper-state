# Issue #237473 — Flag invalid engine version in package.json schema of extensions

[https://github.com/microsoft/vscode/issues/237473](https://github.com/microsoft/vscode/issues/237473)

## Summary

The accepted Backlog request remains necessary: current main documents that `engines.vscode` cannot be `*`, but the extension manifest schema imposes no constraint and runtime validation explicitly accepts it. Keep it open for an authoring-time validation decision and implementation.

## Change summary

Flag an extension manifest whose `engines.vscode` value is `*` through package.json schema validation.

## Best solution

Make the extension manifest authoring schema report `engines.vscode: "*"` consistently with the published documentation while preserving any runtime compatibility behavior needed for existing extensions. Decide whether the schema should reject only the documented `*` case or validate the complete supported engine-version syntax.
