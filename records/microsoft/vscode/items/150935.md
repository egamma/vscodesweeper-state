# Issue #150935 — status and diagnostic information could not be printed for remote-ssh coinnection

[https://github.com/microsoft/vscode/issues/150935](https://github.com/microsoft/vscode/issues/150935)

## Summary

Keep open: a maintainer independently reproduced missing remote diagnostics on 1.95.3, and current source retains a buffer-limited process collector and a five-second diagnostic timeout. The existing steps suffice for retesting; no verified fix or older same-symptom canonical was found.

## Change summary

Restore remote process and hardware diagnostics in `code -s` and Process Explorer when the SSH workspace itself works normally.

## Best solution

Make core remote diagnostic collection reliable without treating collection failures as SSH connection failures. Diagnose whether the later generic error comes from process collection or the diagnostic deadline before choosing the bounded fix.
