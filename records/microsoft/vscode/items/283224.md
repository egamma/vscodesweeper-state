[https://github.com/microsoft/vscode/issues/283224](https://github.com/microsoft/vscode/issues/283224)

## Summary

Team-authored bug that still appears present on main — when a session is cancelled (Cmd+Esc) while an MCP tool has a pending confirmation, the tool renders the redundant message "Canceled: canceled". No fix commit found in the history.

## Change summary

Cancelling a chat session while an MCP tool awaits confirmation shows the ugly redundant message "Canceled: canceled" instead of a clean cancellation state.

## Best solution

When a tool invocation is cancelled via session cancellation (not user denial), either suppress the error details rendering entirely for the cancelled tool or provide a cleaner message like just "Canceled". The fix likely involves the interaction between `cancelToolCallsForRequest` in `languageModelToolsService.ts` and how the cancelled state/error details are rendered in `chatListRenderer.ts` and `chatToolProgressPart.ts`.
