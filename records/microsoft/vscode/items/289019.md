# Issue #289019 — "Allow for ..." should approve other calls that match in the parallel tool calls

[https://github.com/microsoft/vscode/issues/289019](https://github.com/microsoft/vscode/issues/289019)

## Summary

The gap remains in current source: scoped approval updates saved permissions and confirms the selected invocation, but matching parallel calls already awaiting confirmation do not re-evaluate those permissions. Keep this team-authored, correctly routed bug open; neither a qualifying fix nor an older same-symptom canonical was established.

## Change summary

Applying session or workspace approval to one tool call should also approve matching parallel calls already waiting, while Allow Once should affect only the selected call.

## Best solution

Pending matching tool calls should honor newly granted scoped approvals through the existing tool-confirmation machinery, without broadening the permission granted or bypassing policy restrictions, explicit confirmation requirements, or post-execution review.
