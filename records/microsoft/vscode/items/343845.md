# Issue #343845 — Team plugin enablement in VS Code disagrees with SDK/runtime state

[https://github.com/microsoft/vscode/issues/343845](https://github.com/microsoft/vscode/issues/343845)

## Summary

Keep open: current source still treats the persisted installation flag as effective plugin enablement. The linked fix attempt was closed without merging, and SDK-backed toggle actions alone do not resolve the displayed-state mismatch.

## Change summary

Make plugin presentation, forwarded enablement, and contribution availability reflect SDK-resolved state while preserving explicit user choices.

## Best solution

Align discovery and plugin listings with authoritative runtime enablement, including before the first chat and during prewarming. Preserve SDK-owned defaults and explicit choices without converting Team defaults into personal opt-ins.
