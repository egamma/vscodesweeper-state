# Issue #235166 — issue with nb occurrence highlighting

[https://github.com/microsoft/vscode/issues/235166](https://github.com/microsoft/vscode/issues/235166)

## Summary

Still reproduces on main: the occurrence highlighter and the select-all-occurrences command use different word-separator parameters in their `findMatches` calls, causing a mismatch between highlighted and selected matches.

## Change summary

Cmd+Shift+L in notebooks selects fewer occurrences than are visually highlighted by occurrence highlighting.

## Best solution

Align the `findMatches` calls: either pass `USUAL_WORD_SEPARATORS` in the highlighter (`notebookSelectionHighlight.ts` line 110) to match the select-all behavior, or pass `null` in `handleCellEditorSelectAllMatches` (`notebookMulticursor.ts` line 689) — the former is more correct since select-all should match what was highlighted. The `getWord` extraction in `handleCellEditorSelectAllMatches` also uses `getWordAtPosition` which returns whole-word boundaries, contributing to the mismatch when the selection text is a substring of a word.
