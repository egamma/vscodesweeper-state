# Issue #334875 — VS Code 1.136: Copilot Editor Preview Features policy incorrectly hides native Claude Agent Host harness

[https://github.com/microsoft/vscode/issues/334875](https://github.com/microsoft/vscode/issues/334875)

## Summary

The behavior is intentional: the `Claude3PIntegration` policy is explicitly designed to force `chat.agentHost.claudeAgent.enabled` off whenever the account disables chat preview features (or any managed settings are active), as a governance floor so a governed user can't route around enterprise controls via an independently authenticated Claude harness.

## Change summary

Since 1.136, disabling a Copilot org's 'Editor Preview Features' policy also hides the native Claude Agent Host harness, even when Claude is authenticated independently via Anthropic OAuth.

## Best solution

Keep current behavior — the coupling is an intentional governance floor, not an oversight. The reporter's secondary ask (surface *why* Claude was hidden, e.g. an 'hidden by organization policy' indicator in the harness picker) is the only part with any residual merit and could be filed separately as a UX polish request if not already covered.
