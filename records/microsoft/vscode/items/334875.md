## Summary

Current source explicitly intends preview-policy denial to hide Claude, so this is a request to change the policy boundary or improve its explanation rather than an accidental filtering bug. Keep it open: developer diagnostics help investigate, but do not fully satisfy the requested explanation at the harness picker.
