# Issue #278551 — I get GPT 4.1 as default model

[https://github.com/microsoft/vscode/issues/278551](https://github.com/microsoft/vscode/issues/278551)

## Summary

The late-model timing defect is fixed on current main: an initially available model is now provisional and is replaced when the provider's declared default, such as Auto, arrives after authentication.

## Change summary

Opening transient Insiders chat before signing in could leave GPT-4.1 selected instead of adopting the paid account's default model after login.

## Best solution

Keep the landed provisional-selection reconciliation from commit 28093f7b30a9cdcffc99aa1164f597d7fa5c2e49; it prevents an early model from becoming the lasting default when Auto or another declared default publishes later.
