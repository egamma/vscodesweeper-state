# Issue #198021 — In inline diff view of files with >= 1000 lines, the last digits of the left line numbers are sometimes truncated 

[https://github.com/microsoft/vscode/issues/198021](https://github.com/microsoft/vscode/issues/198021)

## Summary

Intermittent visual bug where left line numbers in inline diff view are truncated for files with ≥1000 lines — likely a race in layout width computation. No fix commit references this issue, and the bug is confirmed by two reporters but hard to reproduce reliably. Already correctly labeled and triaged in the Backlog.

## Change summary

In inline diff view, the left editor's line number column is sometimes too narrow, truncating the last digit(s) of line numbers for files with ≥1000 lines.

## Best solution

The line number width computation in the editor layout (src/vs/editor/common/config/editorOptions.ts around line 2913) uses `lineNumbersDigitCount` which is updated when the model line count changes. In the inline diff view, there may be a timing issue where the original editor's line count isn't fully reflected when the layout is first computed. A fix would ensure the diff editor updates its layout after both models are fully loaded, or that the original editor's line number width accounts for the original model's line count from the start.
