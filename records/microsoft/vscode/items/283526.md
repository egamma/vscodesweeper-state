# Issue #283526 — [Windows] VS Code shows blank white window and exits when launched via “Run as different user”/"Run as Administrator"; fixed by --disable-gpu-sandbox (1.107 / Electron 39)

[https://github.com/microsoft/vscode/issues/283526](https://github.com/microsoft/vscode/issues/283526)

## Summary

Keep open as an upstream Windows sandbox launch failure. Electron has added an optional de-elevation API, but that does not establish a fix for VS Code launching under alternate credentials, and automatic sandbox disabling needs human security review.

## Change summary

Restore successful Windows startup under alternate credentials or elevation without requiring users to disable the GPU sandbox.

## Best solution

Resolve the Electron/Chromium sandbox process-launch failure while preserving the requested account and required privileges. Evaluate upstream de-elevation separately for unnecessarily elevated launches; it is not equivalent to supporting the alternate-credentials workflow.
