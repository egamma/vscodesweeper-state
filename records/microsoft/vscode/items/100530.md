# Issue #100530 — Symbol occurrence highlighting overlaps occurrences of the selected text

[https://github.com/microsoft/vscode/issues/100530](https://github.com/microsoft/vscode/issues/100530)

## Summary

The core color-confusion problem (DocumentHighlightKind.Text using the same color as selection highlights) was fixed in Dec 2022 via a new `editor.wordHighlightTextBackground` color. However, the rendering-order issue — symbol occurrence highlights painting on top of the selection background, obscuring it — remains on current main and is still reported (comment from Nov 2024 with a CSS workaround).

## Change summary

Symbol occurrence highlighting renders on top of selection highlighting, obscuring the user's selection and making it impossible to distinguish between selection occurrences and symbol occurrences.

## Best solution

The remaining gap is the z-index ordering of decoration layers: the selection background (`cslr`) should render above word-highlight decorations (`cdr`) so the user's explicit selection is never obscured. This is a rendering-order fix in `src/vs/editor/browser/viewParts/decorations/decorations.ts` or the CSS stacking context, not a color problem. The separate color introduced via https://github.com/microsoft/vscode/issues/167766 mitigates the confusion but does not fully resolve the overlap when both are visible on the same range.
