# Issue #100530 — Symbol occurrence highlighting overlaps occurrences of the selected text

[https://github.com/microsoft/vscode/issues/100530](https://github.com/microsoft/vscode/issues/100530)

## Summary

Partially addressed: commit c97f4be67d0 introduced a separate `editor.wordHighlightTextBackground` color for `DocumentHighlightKind.Text` (fixing the same-color confusion), but the core rendering-order problem — symbol occurrence highlights rendering on top of and obscuring the selection — remains on current `main`. Both decoration types use default `zIndex: 0` and the selection layer (`.cslr`) can still be visually hidden by the decoration layer (`.cdr`).

## Change summary

Symbol occurrence highlighting (from document highlight providers) renders on top of the user's selection, making the selection invisible and making it impossible to distinguish selection occurrences from symbol occurrences.

## Best solution

Adjust the rendering order so that the selection layer renders above word/document highlight decorations, or give the selection highlight decorations a higher z-index than word highlight decorations in the view overlays. The fix likely involves `src/vs/editor/browser/viewParts/decorations/decorations.ts` (zIndex sorting) or the CSS for `.cslr` vs `.cdr` in the view-overlays DOM structure.
