# Issue #100530 — Symbol occurrence highlighting overlaps occurrences of the selected text

[https://github.com/microsoft/vscode/issues/100530](https://github.com/microsoft/vscode/issues/100530)

## Summary

The overlap remains source-reproducible on current main: active selections are emitted before editor decorations, so later semantic document highlights can cover them. A 2022 change separated textual and selection-occurrence colors, but it did not fix the active-selection layering.

## Change summary

Keep an active text selection visible and distinguishable when semantic symbol-occurrence highlights overlap it.

## Best solution

Preserve semantic occurrence highlighting while ensuring the active selection retains visual precedence over overlapping content decorations; selection-occurrence and semantic-occurrence colors should remain independently themeable.
