# Issue #287636 — enable adding running py scripts with "python3 script.py ..." to be allow listed

[https://github.com/microsoft/vscode/issues/287636](https://github.com/microsoft/vscode/issues/287636)

## Summary

Team-authored feature request for improving the terminal tool confirmation UX to support allow-listing command patterns with varying arguments (e.g. 'python3 script.py ...' regardless of specific args). The auto-approve infrastructure exists but the UI doesn't currently offer a convenient way to add pattern-based rules from the confirmation dialog.

## Change summary

Enable adding running Python scripts (or similar commands with varying arguments) to the auto-approve allow list from the terminal tool confirmation UI.

## Best solution

Extend the terminal tool confirmation sub-part (chatTerminalToolConfirmationSubPart.ts) to offer an 'Always allow this command' option that creates a regex-based allow-list rule matching the command prefix while ignoring arguments. The CommandLineAutoApprover already supports regex rules via TerminalChatAgentToolsSettingId.AutoApprove — the gap is surfacing a convenient UI action that generates the right pattern.
