# Issue #274211 — Signature help doesn't provide enough information for a screenreader user, at least in languages supporting overloads

[https://github.com/microsoft/vscode/issues/274211](https://github.com/microsoft/vscode/issues/274211)

## Summary

Keep open: current signature-help announcements omit the full overload signature and overload position, and parameterless overloads produce no announcement. The accessibility gap is confirmed in core source; deciding how to expose complete information without excessive speech needs accessibility-owner input.

## Change summary

Make signature help expose overload signatures and parameter types to screen reader users, including parameterless overloads.

## Best solution

Provide keyboard-accessible access to the selected overload's complete signature, types, documentation, and overload position within the core parameter-hints experience. Agree on automatic versus explicitly requested speech so overload navigation is informative without making ordinary typing excessively noisy.
