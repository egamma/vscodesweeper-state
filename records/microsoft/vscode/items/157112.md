# Issue #157112 — Add support for running custom tasks in VS Code Web

[https://github.com/microsoft/vscode/issues/157112](https://github.com/microsoft/vscode/issues/157112)

## Summary

Valid feature request to officially support custom task providers in VS Code Web. A team member acknowledged the gap and partial support exists (CustomExecutionSupportedContext gates task menus via TaskExecutionSupportedContext), but the reporter's 2024 update shows the task menu still does nothing on vscode.dev — indicating remaining work is needed. On Deck milestone is appropriate.

## Change summary

Officially support custom task providers in VS Code Web by ensuring task menu items appear and work when a web extension contributes custom execution tasks.

## Best solution

Complete the custom-task-in-web support: ensure that when a web extension registers a custom task provider, the task menu commands (Run Task, etc.) work on vscode.dev without a remote authority. The gating via `TaskExecutionSupportedContext` already includes `CustomExecutionSupportedContext`, but the end-to-end flow (task discovery, quick pick population, execution) needs verification and fixes in `src/vs/workbench/contrib/tasks/browser/abstractTaskService.ts`. The `_trust()` method at line 3098 short-circuits when `ServerlessWebContext` is true and `TaskExecutionSupportedContext` is false, which may block task discovery before any extension has registered.
