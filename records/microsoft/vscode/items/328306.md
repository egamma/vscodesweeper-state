# Issue #328306 — Creating a PR with changes on a protected branch fails silently

[https://github.com/microsoft/vscode/issues/328306](https://github.com/microsoft/vscode/issues/328306)

## Summary

The confirmed Agents window flow lacks protected-branch handling and can suppress rejected request feedback. Keep this team-authored issue open and route it to the Agents window and Copilot CLI areas.

## Change summary

Creating a pull request from a non-worktree agent session fails without feedback after changes are committed directly to a protected branch.

## Best solution

Before committing or pushing, the create-PR workflow should detect a protected active branch, create a topic branch carrying the changes, and create the PR from that branch. Any dispatch, push, or PR-creation failure must be surfaced in the session UI.
