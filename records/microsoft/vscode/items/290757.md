# Issue #290757 — Custom Agent: Model name should not require (Preview) syntax in the name

[https://github.com/microsoft/vscode/issues/290757](https://github.com/microsoft/vscode/issues/290757)

## Summary

The durability gap remains on current main: custom-agent model references still derive from display names, including the preview marker, although Copilot references may now omit the vendor suffix. This team-authored request cannot receive a judgment close, and the discussion has not settled whether stable IDs should replace names.

## Change summary

Allow custom agents to reference models without transient display suffixes such as `(Preview)`, and avoid suggesting an unnecessary `(copilot)` suffix.

## Best solution

Define a durable custom-agent model reference based on stable provider/model identity while continuing to resolve legacy display-name references. Keep presentation metadata such as preview status out of persisted references, and simplify Copilot completions where the vendor is optional.
