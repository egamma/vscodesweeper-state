# Issue #340463 — thinking display mode "collapsed" is not honoured

[https://github.com/microsoft/vscode/issues/340463](https://github.com/microsoft/vscode/issues/340463)

## Summary

Keep open: current main overrides the configured collapsed thinking style when persistent progress is enabled, allowing active reasoning to expand automatically. The later comment reports the opposite visibility problem and does not establish that the original regression was fixed.

## Change summary

Honor the collapsed thinking preference so active reasoning does not automatically expand.

## Best solution

In editable chats, preserve the user's collapsed thinking preference independently of the persistent progress indicator, while retaining manual expansion and existing read-only behavior. Treat the comment about missing reasoning as a separate symptom unless its rendering path is confirmed.
