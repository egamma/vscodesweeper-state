# Issue #340463 — thinking display mode "collapsed" is not honoured

[https://github.com/microsoft/vscode/issues/340463](https://github.com/microsoft/vscode/issues/340463)

## Summary

Keep open: the persistent-progress rendering path overrides the configured collapsed thinking style and automatically expands active reasoning. This matches the screenshots and contradicts the setting's documented behavior.

## Change summary

Honor the collapsed thinking preference while reasoning streams with persistent progress enabled.

## Best solution

Keep active reasoning collapsed when chat.agent.thinkingStyle is collapsed, including with persistent progress enabled, while preserving manual expansion and existing tool-chain behavior.

  > Thanks for the report. The persistent working indicator currently switches reasoning to an expanded preview, overriding `chat.agent.thinkingStyle: "collapsed"`. As a workaround, setting `chat.experimental.persistentProgress` to `"off"` restores the rendering path that honors this preference.
