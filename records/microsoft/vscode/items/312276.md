## Summary

Valid feature request from the Chronicle author — the `session_refs` tracking gap is confirmed on current main. The ref extraction still only covers MCP tools and Copilot terminal tool spans; no `onDidCommit` hook, no prompt-text extraction, and narrow terminal patterns. Keeping open for the author to implement the proposed improvements.

## Change summary

Chronicle session_refs table is always empty because ref tracking only fires for GitHub MCP tool calls and Copilot terminal tool spans, missing SCM UI commits, user terminal commits, and issue references in prompts.

## Best solution

Implement the three proposed improvements in priority order: (P0) hook `Repository.onDidCommit` from the Git extension API in `sessionStoreTracker.ts` to capture all commit SHAs — the pattern already exists in `gitCommitMessageServiceImpl.ts`; (P1) parse `#N` / GitHub URL refs from user prompt text in `_handleAgentSpan`; (P2) broaden terminal command regex patterns in `extractRefsFromTerminal`.
