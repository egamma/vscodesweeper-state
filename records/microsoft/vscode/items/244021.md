# Issue #244021 — Auto-indent of switch-case is idiotic

[https://github.com/microsoft/vscode/issues/244021](https://github.com/microsoft/vscode/issues/244021)

## Summary

The older, currently open PHP indentation report covers the same observable failure: indentation remains at the case-body level after `break;`, causing subsequent cases to drift right. Consolidate this report's complete typing example and Linux reproduction with that issue.

## Change summary

Typing a PHP switch statement progressively over-indents successive case labels and their bodies.

## Best solution

Resolve PHP switch-case indentation under https://github.com/microsoft/vscode/issues/174667, preserving this report's full multi-case example as an acceptance case: sibling case labels should align without manual indentation edits.

- **Current source:** extensions/php/language-configuration.json increases indentation after `case ...:` but has no corresponding decrease rule for subsequent case labels and no switch-specific Enter rule after `break;`. src/vs/editor/common/languages/autoIndent.ts:getIndentActionForType only performs the relevant automatic outdent when typing makes the line match decreaseIndentPattern. Consequently, typing another case label does not correct the inherited body indentation, and its colon increases the next line's indentation again.
