# Issue #245579 — [scss] "Follow link" on `@use`/`@import` statements with absolute paths not working with node_modules.

[https://github.com/microsoft/vscode/issues/245579](https://github.com/microsoft/vscode/issues/245579)

## Summary

The defect remains open in the bundled CSS language service, with an active replacement PR under maintainer review. Keep this issue open until that fix lands and VS Code consumes the updated language-service version.

## Change summary

SCSS document links for bare package imports such as `bootstrap/scss/variables` fail to resolve through `node_modules` on Windows.

## Best solution

Revise and land https://github.com/microsoft/vscode-css-languageservice/pull/459 without changing relative-import precedence, then update VS Code's `vscode-css-languageservice` dependency and verify bare SCSS package links on Windows.
