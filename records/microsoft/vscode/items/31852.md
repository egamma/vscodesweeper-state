# Issue #31852 — multiCursorModifier should be ctrlCmd by default for *nix users

[https://github.com/microsoft/vscode/issues/31852](https://github.com/microsoft/vscode/issues/31852)

## Summary

Verified duplicate: the open mouse-shortcut customization issue owns this Linux modifier conflict and the broader solution identified by maintainers.

## Change summary

Use Control rather than Alt as the default multi-cursor modifier on Linux because desktop environments reserve Alt-click for moving windows.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/3130 and implement configurable mouse shortcuts there. Until then, Linux users can set `editor.multiCursorModifier` to `ctrlCmd`.
