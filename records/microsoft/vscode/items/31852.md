# Issue #31852 — multiCursorModifier should be ctrlCmd by default for *nix users

[https://github.com/microsoft/vscode/issues/31852](https://github.com/microsoft/vscode/issues/31852)

## Summary

Verified duplicate: the open mouse-shortcut customization issue owns the proposed long-term fix, while the existing setting already provides the requested Ctrl+Click behavior on Linux.

## Change summary

Use Ctrl+Click rather than Alt+Click as the default multi-cursor modifier on Unix-like systems.

## Best solution

Consolidate modifier-default and Linux window-manager requirements in https://github.com/microsoft/vscode/issues/3130. Users can currently select Ctrl+Click with `editor.multiCursorModifier: "ctrlCmd"` or the Toggle Multi-Cursor Modifier command.

- **Reason:** This improves Linux usability, but changing a cross-platform interaction default is not clearly favored by the stated product direction.
- **Evidence:** The public value of “Simple, uniform UI and UI interactions” does not clearly resolve whether this modifier should vary by platform.
