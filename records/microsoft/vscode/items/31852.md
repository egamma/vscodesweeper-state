# Issue #31852 — multiCursorModifier should be ctrlCmd by default for *nix users

[https://github.com/microsoft/vscode/issues/31852](https://github.com/microsoft/vscode/issues/31852)

## Summary

The Linux default remains Alt+Click; the existing setting answers the configuration question but does not deliver the requested default change. Keep this accepted Backlog request open: the maintainer discussion favors mouse customization, and the related customization issue does not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Default multi-cursor mouse gestures to Ctrl+Click on Unix-like systems to avoid window-manager interception of Alt+Click.

## Best solution

Resolve the Linux window-manager conflict without moving it from multi-cursor selection to link activation. Evaluate the platform default alongside the maintainer-preferred mouse-customization direction, preserving existing users' explicit modifier settings.
