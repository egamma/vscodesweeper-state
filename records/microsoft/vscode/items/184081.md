# Issue #184081 — Disable global replace all if all files are readonly

[https://github.com/microsoft/vscode/issues/184081](https://github.com/microsoft/vscode/issues/184081)

## Summary

The global Replace All action still enables for output-only notebook matches, although those matches cannot be replaced, and its completion path reports success. Keep this accepted, team-authored issue open; the current source confirms the remaining gap.

## Change summary

Disable global Replace All when every search match is read-only, avoiding a misleading successful-replacement message.

## Best solution

Make global Replace All availability reflect whether the applicable search results contain replaceable matches. Preserve replacement for editable results and the existing exclusion of notebook-output matches from edits.
