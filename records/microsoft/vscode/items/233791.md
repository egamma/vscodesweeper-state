# Issue #233791 — Editor GPU: Lines aren't clipped to the viewport and show under line numbers

[https://github.com/microsoft/vscode/issues/233791](https://github.com/microsoft/vscode/issues/233791)

## Summary

Keep open: the original clipping fix preceded the reopen, and current source still permits horizontal scrolling to draw text beneath the gutter when the clipping offset remains zero. A later report of the same symptom was explicitly consolidated here.

## Change summary

GPU-rendered line content should remain clipped to the editor content viewport during horizontal scrolling.

## Best solution

Make GPU clipping consistently match the editor's actual content boundary from initial rendering through layout changes. Preserve this issue as the canonical horizontal-scroll gutter-overlap report and establish a rendering regression check before implementation.
