# Issue #190917 — Hot reload in extension development - automatically reload the Extension Development Host window

[https://github.com/microsoft/vscode/issues/190917](https://github.com/microsoft/vscode/issues/190917)

## Summary

Valid, well-supported feature request (80 upvotes, in Backlog) for automatic reload of the Extension Development Host on source changes. No implementation exists on current main — the existing hot-reload infrastructure is internal to VS Code's own dev loop, not exposed to extension developers.

## Change summary

Automatically reload the Extension Development Host window when extension source code changes, eliminating the manual Ctrl+Shift+F5 step.

## Best solution

Implement a file-watcher-driven auto-reload for the Extension Development Host, likely in `src/vs/workbench/services/extensions/electron-browser/nativeExtensionService.ts` or the debug adapter flow. This would watch the extension's output directory and trigger the equivalent of the 'Restart Extension Host' command automatically. The webview hot-reload aspect is a stretch goal that could build on the existing webview dev tools infrastructure.
