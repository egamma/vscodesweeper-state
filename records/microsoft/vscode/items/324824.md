# Issue #324824 — Provide way to stop running command in agent host copilot

[https://github.com/microsoft/vscode/issues/324824](https://github.com/microsoft/vscode/issues/324824)

## Summary

Valid feature request from a team member: the agent host needs a user-facing mechanism to send Ctrl+C (or equivalent interrupt) to a running command without killing the entire agent session. The backend plumbing partially exists but the UX affordance is missing.

## Change summary

Provide a way for users to interrupt (Ctrl+C) a running command in agent host Copilot sessions without stopping the entire session.

## Best solution

Surface a UI affordance (button or keybinding) in the agent host chat terminal view that sends a SIGINT/Ctrl+C to the currently running command. The backend has `command/exec/terminate` (Codex protocol) and shell-tool input support (`copilotShellTools.ts` already describes sending Ctrl+C), so the work is likely wiring a user-facing action through the chat/sessions UI to the appropriate agent-host command channel.
