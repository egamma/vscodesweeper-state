# Issue #324824 — Provide way to stop running command in agent host copilot

[https://github.com/microsoft/vscode/issues/324824](https://github.com/microsoft/vscode/issues/324824)

## Summary

Keep open: current main provides Stop Shell for attached background commands, but detached commands remain unsupported and an attached-shell cancellation recovery limitation has been reported. The landed implementation does not explicitly reference this team-authored issue, so it also falls short of the factual-close bar.

## Change summary

Allow users to stop an individual Copilot Agent Host command without stopping the entire session or asking the model to intervene.

## Best solution

Preserve the existing per-shell Stop action and review the detached-shell extension in https://github.com/microsoft/vscode/pull/340514. Confirm that stopping an attached command lets the user continue the chat without requiring a separate session-level cancellation before considering this request complete.
