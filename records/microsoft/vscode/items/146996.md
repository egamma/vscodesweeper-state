# Issue #146996 — Reuse tokens when a new line is inserted

[https://github.com/microsoft/vscode/issues/146996](https://github.com/microsoft/vscode/issues/146996)

## Summary

Keep this tokenization improvement open: current source still discards the moved suffix's tokens when inserting a newline. This team-authored Backlog item is also the canonical report explicitly identified in the related discussion.

## Change summary

Reuse existing syntax tokens for text moved onto a new line so pressing Enter does not briefly replace its highlighting with the default foreground.

## Best solution

Preserve provisional highlighting for the unchanged text moved by a newline insertion in ContiguousTokensStore, while allowing normal retokenization to correct context-dependent tokens. Keep this issue as the canonical record for that improvement.
