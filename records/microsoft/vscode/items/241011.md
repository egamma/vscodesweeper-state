# Issue #241011 — Moving a line down in Go code messes up indentation in VS Code

[https://github.com/microsoft/vscode/issues/241011](https://github.com/microsoft/vscode/issues/241011)

## Summary

Keep open: current Go indentation rules still mishandle closing-brace lines containing `else`, and moving a statement downward through those branches propagates the incorrect indentation. The supplied reproduction is complete, and another commenter confirmed it after repeating the move.

## Change summary

Repeated Alt+Down moves through Go conditional branches progressively distort indentation.

## Best solution

Make Go line movement recognize combined closing/opening branch boundaries without accumulating indentation, with regression coverage for the supplied snippet. Preserve intentional indentation adjustment when statements move into or out of blocks.
