# Issue #302033 — Unclear how to install npm plugin

[https://github.com/microsoft/vscode/issues/302033](https://github.com/microsoft/vscode/issues/302033)

## Summary

Keep open: npm-backed marketplace plugins are supported, but the direct source-install command still accepts only repositories and local folders. The maintainer-confirmed direct npm installation gap remains, and no matching canonical or explicitly linked fix was found.

## Change summary

Make installing an agent plugin directly from npm supported and discoverable.

Provide a discoverable npm package installation path in the agent-plugin source-install experience, retaining the existing explicit confirmation before running package-manager commands. Decide the supported package input and version semantics before implementation.
