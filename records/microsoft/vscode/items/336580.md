## Summary

Legitimate architectural transition proposal to move GitHub/Microsoft auth ownership from VS Code to the agent host per agent-host-protocol#404; currently unimplemented, milestone is Backlog (a holding bin), and no canonical or duplicate covers it — stays open as a design-stage tracking item.

## Change summary

Move ownership of GitHub/Microsoft authentication state and flows from VS Code into the agent host/runtime, with VS Code only brokering client-specific UI (e.g. browser opens) via the Agent Host Protocol.
