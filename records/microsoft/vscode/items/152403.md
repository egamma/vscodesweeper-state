# Issue #152403 — Open source translations of third-party vs code OSS extensions

[https://github.com/microsoft/vscode/issues/152403](https://github.com/microsoft/vscode/issues/152403)

## Summary

The localization tooling is now open source, but the translated bundles needed to reproduce Microsoft-published OSS extension builds remain unavailable. This accepted Backlog request therefore still tracks a real gap.

## Change summary

Publish the localization pipeline or translated resources required to build Microsoft-owned open-source extensions with translations enabled.

## Best solution

Publish generated translation bundles for Microsoft-owned OSS extensions in an openly licensed repository or build artifact, allowing downstream registries to produce translated builds without the internal Microsoft service.
