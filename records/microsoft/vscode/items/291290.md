# Issue #291290 — Roll the line numbers into the read file link, highlight range

[https://github.com/microsoft/vscode/issues/291290](https://github.com/microsoft/vscode/issues/291290)

## Summary

The requested polish remains necessary on current main: read-tool ranges are encoded in the file link, but the chat file-widget path discards that range and leaves the separately rendered “lines x to y” text outside the link.

## Change summary

Include read-tool line ranges in the clickable file label and select the complete range when the file opens.

## Best solution

Have the chat inline-anchor widget preserve the range encoded by `formatUriForFileWidget`, display it as the existing `:start-end` label suffix, and pass that range as the editor selection; remove the redundant prose suffix from read-tool titles.
