# Issue #317487 — Backgrounded VSCode window throttles integrated terminal and Remote-SSH processes on Windows

[https://github.com/microsoft/vscode/issues/317487](https://github.com/microsoft/vscode/issues/317487)

## Summary

The report describes Electron's background throttling slowing terminal output consumption when the window loses focus on Windows. The main VS Code window has backgroundThrottling enabled by default (only the agents window and active chat requests disable it). However, the report lacks a specific before/after version, and the claim that actual process execution slows (not just rendering) needs confirmation — Electron throttling affects the renderer, which may create output backpressure but should not directly slow pty process execution. More reproduction detail is needed.

## Change summary

Terminal processes and Remote-SSH sessions slow down dramatically when the VS Code window is minimized or unfocused on Windows, recovering immediately when refocused.

## Best solution

Investigate whether Electron's backgroundThrottling on the main window creates enough backpressure through xterm.js output consumption to slow pty processes. If confirmed, consider disabling backgroundThrottling for the main window when an active terminal exists (similar to the chat request pattern in `ChatSuspendThrottlingHandler` at `src/vs/workbench/contrib/chat/electron-browser/chat.contribution.ts`), or decouple the pty output pipeline from renderer frame scheduling. The Remote-SSH slowdown portion may belong to `microsoft/vscode-remote-release`.

## Evidence

- **Electron behavior:** Electron/Chromium throttles timers, requestAnimationFrame, and other scheduling in backgrounded windows by default. This affects xterm.js rendering in the terminal, which could create output backpressure on the pty process.
- **reporter hint:** The reporter notes programs with continuous terminal output (e.g. tqdm) are less affected, which is consistent with the renderer staying active when it has data to process, reducing throttling impact.
