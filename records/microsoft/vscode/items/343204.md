The reported case mismatch remains reproducible from current source: the formatter lowercases both POSIX paths and incorrectly renders an unrelated directory as ~/project. Route this to the terminal area; the related open PR addresses different matching errors and does not fix case sensitivity.

## Change summary

## Best solution
