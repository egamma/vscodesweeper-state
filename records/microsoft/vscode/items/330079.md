## Summary

Keep open: the reporter confirmed that restarting a transient session restores the Agents window behind blocking sign-in, and a maintainer accepted the problem. Current source offers an editor escape hatch and conditional signed-out access, but neither establishes an issue-referenced fix for this team-authored report.

## Change summary

Reopening a transient session after closing the editor and Agents windows leaves the user in an Agents window blocked by sign-in.

## Best solution

Ensure restoring a signed-out transient session never strands the user behind authentication, preserving a usable return to the editor and requesting provider authentication when needed. Verify the reported restart sequence against the existing escape hatch before deciding whether further restoration or onboarding changes are necessary.
