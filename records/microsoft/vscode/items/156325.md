# Issue #156325 — Terminal: recent command fuzzy search not very fuzzy

[https://github.com/microsoft/vscode/issues/156325](https://github.com/microsoft/vscode/issues/156325)

## Summary

The terminal's fuzzy-search toggle still uses the restricted quick-pick matcher. This is a verified specific case of the open request to enable genuine fuzzy matching in pickers, so consolidate it there.

## Change summary

Allow noncontiguous characters within a word, such as “gt” in “git”, to match commands in the terminal's recent-command picker.

## Best solution

Track the shared filtering improvement in https://github.com/microsoft/vscode/issues/34088, preserving this terminal example as an acceptance case while retaining the separate contiguous-search mode.
