# Issue #42203 — Support assigning numeric value to "editor.wrappingIndent"

[https://github.com/microsoft/vscode/issues/42203](https://github.com/microsoft/vscode/issues/42203)

## Summary

A real gap remains on current main: wrapping indentation is limited to four presets, so arbitrary numeric values are unsupported. This accepted Backlog request should remain open.

## Change summary

Allow `editor.wrappingIndent` to specify a custom numeric continuation-line indentation.

## Best solution

Extend the editor option and both line-break implementations to accept a bounded numeric indentation while preserving the existing string presets and accessibility behavior.
