# Issue #326891 — vscode_listCodeusages does not deliver requested references in order

[https://github.com/microsoft/vscode/issues/326891](https://github.com/microsoft/vscode/issues/326891)

## Summary

The ordering defect remains in current main: the usages tool emits references in provider-returned order without deterministic sorting. The existing reference command establishes URI-and-range ordering as the applicable convention, making this a bounded bug to keep open and fix.

## Change summary

Make vscode_listCodeUsages return references in a deterministic file-and-position order rather than provider completion order.

## Best solution

Normalize references into URI and source-range order before generating previews, tool text, and result details, following the ordering already used by VS Code's reference results.
