# Issue #340719 — Agent Host skill synchronization drops executable permissions from extension-contributed scripts

[https://github.com/microsoft/vscode/issues/340719](https://github.com/microsoft/vscode/issues/340719)

## Summary

Thanks for the detailed report. On current main, AgentPluginManager._syncPlugin copies plugins with IFileService.copy() across providers. Nothing in that path or in agentPluginManager.ts handles or restores file modes, so the report is consistent with the source. How a client-side provider reports and transfers modes is not yet traced, so the fix design is open.

## Change summary

Extension-contributed skill scripts lose their executable bit when synced into the Agent Host agentPlugins cache.

## Best solution

Preserve the executable mode when syncing plugin files into the agentPlugins cache. For example, carry the mode through the client file provider and chmod after the copy in agentPluginManager.ts.

## Plan brief

- **Likely files:** `src/vs/platform/agentHost/node/agentPluginManager.ts`, `src/vs/platform/agentHost/common/agentHostClientFileSystemProvider.ts`
- **Validation:** A test syncing a plugin containing a 0755 script asserts the synced copy is still executable.
- **Behavior:**

  > After syncing an extension-contributed skill, scripts that were executable in the source (0755) stay executable in the agentPlugins copy. Non-executable files are unchanged.
- **Trace:**

  > _syncPlugin in agentPluginManager.ts copies via IFileService.copy() across the vscode-agent-client: provider to a local file destination. That cross-provider path transfers content only. The uncertainty is whether the client file-system protocol exposes file mode at all. Do not change the nonce cache or LRU logic.
- **Open decisions:**
  - Should the protocol carry file modes, or should the sync treat known script files as executable?

## Evidence

- **provider:** src/vs/platform/agentHost/common/agentHostClientFileSystemProvider.ts is the cross-provider source. I did not verify whether it exposes file modes.
