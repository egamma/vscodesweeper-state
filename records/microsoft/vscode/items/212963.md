# Issue #212963 — Add support for running command when clicking on a progress status item

[https://github.com/microsoft/vscode/issues/212963](https://github.com/microsoft/vscode/issues/212963)

## Summary

The API gap remains on current main, and this accepted Backlog request has 63 community upvotes. It is already routed to the appropriate API and status-bar areas.

## Change summary

Allow extension progress shown in the status bar to execute a command when clicked.

## Best solution

Extend `ProgressOptions` for `ProgressLocation.Window` with a command and pass it through `ExtHostProgress` to the existing `IProgressWindowOptions.command` implementation.

- **Fit:** aligned
- **Reason:** This enables extensions to integrate richer workflows without adding specialized functionality to core.

## Evidence

- **public API gap:** `src/vscode-dts/vscode.d.ts` defines `ProgressOptions` with only `location`, `title`, and `cancellable`; no command is exposed.
- **existing core support:** `src/vs/platform/progress/common/progress.ts` already defines `IProgressWindowOptions.command`, and `src/vs/workbench/services/progress/browser/progressService.ts` assigns it to the status-bar entry.
- **missing API bridge:** `src/vs/workbench/api/common/extHostProgress.ts` forwards only `location`, `title`, `source`, and `cancellable`, so extensions cannot reach the existing command support.
