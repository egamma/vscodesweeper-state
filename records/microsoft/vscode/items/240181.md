# Issue #240181 — Multi-file diff editor - support lazy text model loading

[https://github.com/microsoft/vscode/issues/240181](https://github.com/microsoft/vscode/issues/240181)

## Summary

Keep open: current main still resolves every file's text models before publishing the multi-diff document list. This remains the established lazy-loading request; the newer performance reports and open scrolling PR do not replace it.

## Change summary

Load multi-diff text models on demand so opening a large commit does not wait for every file's contents.

## Best solution

Let the multi-diff editor present resource entries without resolving all their contents, then load text models as needed while preserving navigation, editing, and model lifetime semantics. Review the existing collapsed-scrolling PR separately; it addresses rendering costs rather than this loading barrier.
