# Issue #284302 — Allow MDM to prevent modifying list of allow/denied commands for chat auto-approval

[https://github.com/microsoft/vscode/issues/284302](https://github.com/microsoft/vscode/issues/284302)

## Summary

Still needed: the `chat.tools.terminal.autoApprove` (command list) and `chat.tools.terminal.ignoreDefaultAutoApproveRules` settings lack MDM policy support on current main. Two PRs (#285687, #285732) attempted to add them but were closed without merging. The boolean `enableAutoApprove` toggle already has a policy, but the granular command-list control the reporter asks for does not.

## Change summary

Allow MDM administrators to lock down the terminal auto-approval command list so users cannot override safe defaults.

## Best solution

Add `policy:` declarations to `chat.tools.terminal.autoApprove` and `chat.tools.terminal.ignoreDefaultAutoApproveRules` in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/common/terminalChatAgentToolsConfiguration.ts`, plus the corresponding entries in `build/lib/policies/policyData.jsonc` and test fixtures. The prior work in the closed PRs (#285687, #285732) and commit a407095c06e can serve as a reference for what's needed. The complex-object type of the `autoApprove` setting may need special handling for policy merging with defaults, as @Tyriar noted in the discussion.
