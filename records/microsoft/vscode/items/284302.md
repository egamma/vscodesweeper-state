# Issue #284302 — Allow MDM to prevent modifying list of allow/denied commands for chat auto-approval

[https://github.com/microsoft/vscode/issues/284302](https://github.com/microsoft/vscode/issues/284302)

## Summary

Valid feature request: MDM policy for the `chat.tools.terminal.autoApprove` command list setting is still missing on main. The boolean `enableAutoApprove` has a policy, but the object-typed command list does not, so admins cannot lock down which specific commands are allowed/denied. Two related PRs (#285687, #285732) were closed without merging.

## Change summary

Allow MDM administrators to lock down the `chat.tools.terminal.autoApprove` command list so users cannot override safe defaults.

## Best solution

Add a `policy` property to the `chat.tools.terminal.autoApprove` configuration registration in `terminalChatAgentToolsConfiguration.ts`, similar to the existing policy on `enableAutoApprove`. Consider also adding a policy for `ignoreDefaultAutoApproveRules` to prevent users from bypassing the built-in safety rules. The main challenge (noted in comments) is how merging with defaults works for object-typed policies.
