# Issue #284302 — Allow MDM to prevent modifying list of allow/denied commands for chat auto-approval

[https://github.com/microsoft/vscode/issues/284302](https://github.com/microsoft/vscode/issues/284302)

## Summary

Keep open: current terminal settings do not provide the requested MDM lock on command approval rules, and both linked implementation proposals were closed without merging. The existing chat-terminal routing is appropriate.

## Change summary

Allow administrators to enforce terminal chat auto-approval rules while preventing users from overriding the approved command list.

## Best solution

Provide an administrator-enforced command approval boundary that permits approved commands without allowing personal settings to broaden that permission. Preserve the distinction between retaining built-in defaults and supplying custom rules, with enforcement appropriate to each supported agent runtime.
