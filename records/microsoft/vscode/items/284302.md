# Issue #284302 — Allow MDM to prevent modifying list of allow/denied commands for chat auto-approval

[https://github.com/microsoft/vscode/issues/284302](https://github.com/microsoft/vscode/issues/284302)

## Summary

Keep open: current main exposes a policy to disable terminal auto-approval, but neither the command-rule object nor the ignore-defaults setting declares a policy. Both linked implementation attempts closed without merging; the security-sensitive request needs human review, not a cleanup close.

## Change summary

Allow administrators to enforce default or custom terminal auto-approval rules through MDM without allowing users to override them.

## Best solution

Provide an administrator-enforced command approval contract that preserves selective auto-approval and cannot be relaxed by user settings. Reconcile the existing terminal settings with runtime-managed permissions, explicitly settling default-rule merging and enforcement across supported chat execution paths.
