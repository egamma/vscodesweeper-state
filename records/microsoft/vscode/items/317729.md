# Issue #317729 — Support ~ in files.dialog.defaultPath

[https://github.com/microsoft/vscode/issues/317729](https://github.com/microsoft/vscode/issues/317729)

## Summary

Valid feature request: the `files.dialog.defaultPath` setting currently requires an absolute path (enforced by both its regex pattern and an `isAbsolute` check in `abstractFileDialogService.ts`), so `~` is silently rejected. An open PR already addresses this.

## Change summary

Allow `~` as a shorthand for the user's home directory in the `files.dialog.defaultPath` setting.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/317730, which adds tilde expansion. The fix touches the `preferredHome` method in `src/vs/workbench/services/dialogs/browser/abstractFileDialogService.ts` and the validation pattern in `src/vs/workbench/contrib/files/browser/files.contribution.ts`.
