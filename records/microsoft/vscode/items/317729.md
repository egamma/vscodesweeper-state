# Issue #317729 — Support ~ in files.dialog.defaultPath

[https://github.com/microsoft/vscode/issues/317729](https://github.com/microsoft/vscode/issues/317729)

## Summary

Tilde expansion remains unsupported in files.dialog.defaultPath, and an open PR already proposes implementing it. Keep this issue open while that contribution is reviewed.

## Change summary

Allow files.dialog.defaultPath to interpret ~ as the user's home directory.

## Best solution

Review https://github.com/microsoft/vscode/pull/317730 for home-directory expansion consistent with local and remote dialog paths, preserving existing context-specific path precedence. Keep this issue as the feature's tracking item until an accepted implementation lands.
