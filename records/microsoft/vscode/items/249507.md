# Issue #249507 — Unable to authenticate to Azure using msal using the Azure machine Learning - Remote extension

[https://github.com/microsoft/vscode/issues/249507](https://github.com/microsoft/vscode/issues/249507)

## Summary

Keep open as an upstream authentication-broker issue: the reported Okta/Kerberos account-selection loop has not been shown fixed. Current VS Code offers a supported external-browser authentication option, but that does not establish that the native broker defect is resolved.

## Change summary

Allow Azure authentication with a separate privileged account without getting trapped in the native broker's automatic Okta/Kerberos sign-in loop.

## Best solution

The Microsoft Identity broker should permit returning to manual sign-in and selecting the intended account. In the meantime, use microsoft-authentication.implementation = msal-no-broker for external-browser authentication and retain this report's distinct account-selection evidence.
