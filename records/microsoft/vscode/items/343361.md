# Issue #343361 — Chat file links with a line range (#L5-L7) don't select the last line

[https://github.com/microsoft/vscode/issues/343361](https://github.com/microsoft/vscode/issues/343361)

## Summary

The reported endpoint error remains in current main: a range anchor ends at the beginning of its last line, and that range reaches the editor selection unchanged. Keep open as a bounded Copilot linkification bug.

## Change summary

Chat file links with inclusive line ranges omit the contents of the final referenced line from the editor selection.

## Best solution

Make explicit line-range links select all referenced lines, including the final line and ranges ending at EOF, within Copilot's model file-path linkifier. Preserve existing single-line navigation and file-resolution behavior.
