# Issue #319074 — Chat: Unsent (draft) input should not surface when navigating back to the session list

[https://github.com/microsoft/vscode/issues/319074](https://github.com/microsoft/vscode/issues/319074)

## Summary

Keep open: existing session-state restoration and session-list layout controls do not establish that returning to the list hides the outgoing session's draft. The related Agents-window request addresses draft independence, but does not clearly own this Chat-panel navigation behavior.

## Change summary

Hide a session's unsent input when returning to the Chat session list, while restoring it unchanged when that session is reopened.

## Best solution

Make session-list navigation in the Chat panel preserve the outgoing session's draft without presenting it as list-level or new-session input. Identify the reporter's exact Back control and layout before deciding whether the existing ChatViewPane navigation needs a behavior change.
