# Issue #226261 — ERROR: unable to resolve text model content for notebook cell output

[https://github.com/microsoft/vscode/issues/226261](https://github.com/microsoft/vscode/issues/226261)

## Summary

The defect remains on current main: the large-output link creates a URI without an output ID, but the content provider requires a matching output ID and consequently returns no text model.

## Change summary

Opening the raw data for a notebook cell with more than 500 outputs fails with an unresolved text-model error.

## Best solution

Generate a cell-scoped raw-output URI and update the content provider to resolve all outputs for that specific cell. The configurable-limit work in https://github.com/microsoft/vscode/pull/325792 is useful separately but does not repair the link.
