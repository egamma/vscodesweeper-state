# Issue #156546 — Allow to resolve save conflicts using the merge editor

[https://github.com/microsoft/vscode/issues/156546](https://github.com/microsoft/vscode/issues/156546)

## Summary

Still unimplemented on main — the save conflict handler in textFileSaveErrorHandler.ts continues to use DiffEditorInput, not the merge editor. Low community traction (1 upvote in ~3 years) but a valid enhancement with a team member (hediet) expressing interest in implementing it behind a setting.

## Change summary

Use the merge editor (with no base) instead of the diff editor when resolving file save conflicts.

## Best solution

Implement behind a setting (disabled by default) as hediet suggested in comment 2. The entry point is ResolveSaveConflictAction in src/vs/workbench/contrib/files/browser/editors/textFileSaveErrorHandler.ts, which currently calls TextFileContentProvider.open to create a DiffEditorInput. A merge-editor path would need to create a merge editor input with the on-disk version and the in-editor version as the two sides, with no common base. Given the low traction, this can remain in Backlog until someone picks it up.
