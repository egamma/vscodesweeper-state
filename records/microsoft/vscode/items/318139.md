# Issue #318139 — Title: [Markdown Preview] gitGraph diagrams render empty (white box) on Windows when VS Code runs as Administrator — mermaid-markdown-features 10.0.0 / Mermaid 11.15.0

[https://github.com/microsoft/vscode/issues/318139](https://github.com/microsoft/vscode/issues/318139)

## Summary

Well-diagnosed upstream issue in Mermaid's gitGraph renderer: getBBox() returns zeros in the degraded Chromium sandbox when VS Code runs elevated on Windows. Already correctly labeled `upstream` and `mermaid`; the fix belongs in mermaid-js/mermaid or as a workaround in the built-in extension wrapper.

## Change summary

gitGraph Mermaid diagrams render as empty white boxes in Markdown Preview when VS Code runs as Administrator on Windows, because Mermaid's draw4() relies on getBBox() which returns zero dimensions in the elevated webview context.

## Best solution

File upstream at mermaid-js/mermaid for a getBBox fallback in the gitGraph renderer. Alternatively, the built-in mermaid-markdown-features extension could add a workaround (e.g. deferring render until document.fonts.ready or patching zero-dimension results). Related to the long-standing admin-mode Chromium sandbox degradation in https://github.com/microsoft/vscode/issues/122951.
