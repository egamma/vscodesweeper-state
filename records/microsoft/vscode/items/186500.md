# Issue #186500 — Listing processes failed: Error: cat: /proc/241496/stat: No such file or directory

[https://github.com/microsoft/vscode/issues/186500](https://github.com/microsoft/vscode/issues/186500)

## Summary

The Linux process-listing race remains on current main: a process can exit between checking `/proc/<pid>/stat` and reading it, causing diagnostics collection to fail.

## Change summary

Process Explorer intermittently logs an error and loses process diagnostics when a Linux process exits during CPU sampling.

## Best solution

Make `src/vs/base/node/cpuUsage.sh` tolerate failed `/proc/<pid>/stat` reads by treating a vanished process as having no additional CPU usage, while preserving one output value per requested PID.
