# Issue #332859 — Terminal: sustained braille/truecolor animation in one terminal corrupts glyph rendering in all other terminals (WebGL renderer)

[https://github.com/microsoft/vscode/issues/332859](https://github.com/microsoft/vscode/issues/332859)

## Summary

Detailed, well-diagnosed report of WebGL terminal glyph corruption spreading across terminals; the WebGL renderer and its texture atlas live in the @xterm/addon-webgl dependency (not this repo's source), and xterm.js is known to share/cache texture atlases across terminal instances with matching font/color config — a plausible root cause for cross-terminal atlas corruption under sustained glyph-diverse output.

## Change summary

Sustained full-screen truecolor braille animation in one WebGL-rendered integrated terminal corrupts glyph rendering in all sibling terminals until a window reload.

## Best solution

This needs investigation in xterm.js's addon-webgl texture atlas / atlas-cache code (the WebGL renderer and its shared-atlas logic ship from @xterm/addon-webgl, currently pinned at ^0.20.0-beta.298 in package.json, not from microsoft/vscode source) — likely best pursued as an upstream xterm.js issue, with VS Code picking up the fix on the next addon bump once resolved there.
