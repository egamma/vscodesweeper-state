# Issue #326533 — Improve visibility into long-running subagent activity

[https://github.com/microsoft/vscode/issues/326533](https://github.com/microsoft/vscode/issues/326533)

## Summary

Well-corroborated, actively discussed feature request for the Agents window: give users real signal (phase, current activity, elapsed time, heartbeat) into long-running subagents instead of an ambiguous spinner. A team member reproduced the confusion directly and another contributor added related UX bugs as recently as yesterday, so this is live, unresolved work, not a stale request.

## Change summary

Show a compact, evolving status (model, current activity/tool, elapsed time, and clearer states like waiting/blocked/stalled) for each running subagent in the Agents window, plus a parent-level overview and controls to open/steer/cancel/retry.

## Best solution

Design a subagent status model (phase, current activity, last-heartbeat) surfaced compactly in the Agents window session view, likely in src/vs/workbench/contrib/chat/browser/agentSessions or src/vs/sessions/contrib/providers/agentHost where subagent/session state is tracked; this is UX/product design work best driven by the Agents window team rather than an automated fix.
