# Issue #348022 — Webview resources reached through an npm link symlink now return 401

[https://github.com/microsoft/vscode/issues/348022](https://github.com/microsoft/vscode/issues/348022)

## Summary

The 401 follows an intentional resolved-path containment check, not an npm-link-specific failure. Keep this open for human review because disabling that check concerns a security boundary; the diagnostic improvement remains actionable.

## Change summary

## Best solution
