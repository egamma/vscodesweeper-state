# Issue #348022 — Webview resources reached through an npm link symlink now return 401

[https://github.com/microsoft/vscode/issues/348022](https://github.com/microsoft/vscode/issues/348022)

## Summary

The reported build deliberately checks resolved symlink targets against allowed webview roots, but its denial message prints only the unresolved paths. Keep this open for human review: the requested opt-out affects a security boundary, and the checkout predates the reported build.

Improve diagnostics for denied npm-linked webview resources and consider how extension development can authorize them without disabling resource containment.
