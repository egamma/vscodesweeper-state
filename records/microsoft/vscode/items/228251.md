# Issue #228251 — Find in the multi-diff editor is limited to the focused file

[https://github.com/microsoft/vscode/issues/228251](https://github.com/microsoft/vscode/issues/228251)

## Summary

Keep open: the current find action still searches one embedded editor, not all files in the multi-diff editor. This is the older report of that gap; the newer matching issue is related, not a valid duplicate target for this re-review.

## Change summary

Allow the multi-diff editor's find widget to search and navigate matches across all files in that editor.

## Best solution

Provide a multi-diff-wide find experience that includes files outside the rendered viewport and reveals matches across file boundaries. Settle search-side and collapsed-file behavior with the area owner before implementation, retaining this issue as the older tracking report.
