# Issue #334883 — Copilot Chat forked session posts tool-use events with the original sessionId

[https://github.com/microsoft/vscode/issues/334883](https://github.com/microsoft/vscode/issues/334883)

## Summary

The fork identity mismatch remains reproducible from current source: Copilot prioritizes the original session ID copied into history over the fork's current request ID. Keep this open as a bounded session-identity bug.

## Change summary

Tool-use hooks and transcript attribution should identify the forked chat session rather than its source session.

## Best solution

Make new requests in a fork consistently belong to the fork's session across conversation metadata, tool-use hooks, and transcript attribution, while preserving inherited conversation history and ordinary session continuity.
