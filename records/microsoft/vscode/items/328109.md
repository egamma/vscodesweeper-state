# Issue #328109 — Terminal auto-approve: exact-command-line rules are case-sensitive for PowerShell and dropped on parse failure

[https://github.com/microsoft/vscode/issues/328109](https://github.com/microsoft/vscode/issues/328109)

## Summary

Both defects remain visible in current main, and this team-authored issue should stay open until the workbench and Agent Host implementations consistently honor explicit exact-command-line rules.

## Change summary

PowerShell exact-command-line auto-approve rules match case-sensitively and are ignored when command parsing fails.

## Best solution

Evaluate full-command deny rules first, then parse, and permit an explicit full-command allow rule when parsing fails; PowerShell matching must be case-insensitive in both engines. Add regression coverage for changed command casing and unparsable commands, including deny precedence.
