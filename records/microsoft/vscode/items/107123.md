# Issue #107123 — Option to combine tabs and title bar

[https://github.com/microsoft/vscode/issues/107123](https://github.com/microsoft/vscode/issues/107123)

## Summary

This established Backlog request remains necessary: current title-bar settings can hide or customize the title bar but cannot place editor tabs in the window chrome. Its 118 upvotes and platform-specific requirements justify retaining it as the focused Windows request.

## Change summary

Add an option to combine editor tabs with the window title bar to reclaim vertical space.

## Best solution

Design an optional compact title-bar layout that places the primary editor group's tabs alongside window controls while preserving drag regions, editor actions, and sensible behavior with multiple editor groups. Coordinate it with the broader density exploration without losing this request's specific requirements and community signal.
