# Issue #202418 — Folder collapses after rename when changing letter case

[https://github.com/microsoft/vscode/issues/202418](https://github.com/microsoft/vscode/issues/202418)

## Summary

The case-only rename path can still discard the Explorer node's expansion state on current main. This is an accepted Backlog bug with a bounded source path and no open PR or canonical open issue owning the same observable symptom.

## Change summary

Keep an expanded folder expanded when it is renamed by changing only its letter casing on a case-insensitive macOS filesystem.

## Best solution

Preserve the renamed Explorer item's expansion state across a case-only folder rename, including its already-expanded descendants, without changing ordinary move, selection, or auto-reveal behavior.
