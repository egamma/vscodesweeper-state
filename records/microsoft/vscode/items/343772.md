# Issue #343772 — Feedback: Copilot/AHP removes essential capabilities from my Local workflow

[https://github.com/microsoft/vscode/issues/343772](https://github.com/microsoft/vscode/issues/343772)

## Summary

Keep open: existing per-command sandbox bypass support does not establish parity with the requested proactive execution choice, local credentials, signing, or transparent retry behavior. The sandbox-boundary and credential concerns require human review, and the suggested meta issue has not been verified as covering these specific symptoms.

## Change summary

Preserve sandboxed ordinary execution while allowing predictable, individually approved access to the local environment without silently replaying completed side effects.

## Best solution

Have the Copilot Agent Host owners establish the supported per-command escalation and local-authentication contract, including SSH signing and GitHub/Azure CLI access. Investigate replay separately so partial execution and repeated side effects are accurately communicated rather than hidden behind a successful retry.
