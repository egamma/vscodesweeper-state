## Change summary

Preserve Local-style, per-command access to authorized development tools and credentials in Copilot/AHP, without requiring a failed first execution or obscuring repeated side effects.

## Best solution

Assess signing, GitHub Projects credentials, Azure access, and retry reporting separately so partial escalation support is not mistaken for full workflow parity.
