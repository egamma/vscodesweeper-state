# Issue #337589 — VSCode won't launch from shortcut

[https://github.com/microsoft/vscode/issues/337589](https://github.com/microsoft/vscode/issues/337589)

## Summary

Keep open: the Linux package emits the renamed desktop entry without compatibility for existing launcher references, matching the reported upgrade failure. A maintainer has already proposed a fix in an open PR; the intentional rename and merged release-note documentation do not establish that existing shortcuts have been repaired.

## Change summary

Upgrading to 1.139.0 leaves existing KDE Favorites pointing to the removed code.desktop entry, so launching VS Code from those shortcuts fails.

## Best solution

Review https://github.com/microsoft/vscode/pull/337603 against the Debian/KDE upgrade scenario and settle the supported migration behavior for existing launcher references. Land the agreed mitigation and retain the proposed shortcut sanity checks; release notes alone do not restore broken Favorites.
