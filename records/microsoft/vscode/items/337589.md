- **Current packaging path:** build/gulpfile.vscode.linux.ts:45-59 generates the DEB application entry as ${linuxDesktopName}.desktop and the hidden handler as ${linuxDesktopName}.UrlHandler.desktop. The merged packaging streams at line 118 contain no legacy desktop entry or migration notice. The RPM path uses the same canonical naming at lines 156-167. This preserves the missing-file condition for saved references to the old name; no desktop-shell execution was performed.

This is an installer change, not merely an Electron dependency bump. Its merge commit is absent from the shallow checkout, so the diff was inspected through the read-only GitHub API.
- **Maintainer diagnosis and accepted follow-up:** https://github.com/microsoft/vscode/issues/337589#issuecomment-5807345256 identifies the intentional installer rename rather than Electron itself.
