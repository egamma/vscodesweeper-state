# Issue #337589 — VSCode won't launch from shortcut

[https://github.com/microsoft/vscode/issues/337589](https://github.com/microsoft/vscode/issues/337589)

## Summary

Confirmed regression acknowledged by a maintainer, with root cause identified (PR #332935's installer/.desktop rename) and an open fix PR (#337603) already in flight — this should stay open pending that PR landing, not be closed.

## Change summary

The 1.139 Linux installer renamed the .desktop launcher file (code.desktop -> com.microsoft.VSCode.desktop), breaking existing shortcuts/favorites that reference the old filename.

## Best solution

Land the fix/migration+sanity-check work in the open PR https://github.com/microsoft/vscode/pull/337603 (adding launcher migration notices and shortcut sanity checks), and consider documenting the rename more prominently in release notes.
