# Issue #337589 — VSCode won't launch from shortcut

[https://github.com/microsoft/vscode/issues/337589](https://github.com/microsoft/vscode/issues/337589)

## Summary

Confirmed regression: a collaborator identifies the root cause as an intentional installer/.desktop-file renaming change in the same PR as a recent Electron bump, and an open PR (#337603) is already in flight adding launcher migration notices and shortcut sanity checks — this should stay open and track that PR rather than close.

## Change summary

Upgrading on Linux (Debian/KDE, apt repo) silently renames the .desktop launcher file, breaking existing shortcuts (e.g. KDE Favorites) with a misleading 'not authorized to execute' error.

## Best solution

Land (or iterate on) the fix in https://github.com/microsoft/vscode/pull/337603, which adds launcher migration notices and shortcut sanity checks for this exact class of regression; release notes for 1.139 already document the launcher migration per the linked vscode-docs PR.
