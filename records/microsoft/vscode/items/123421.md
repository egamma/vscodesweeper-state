# Issue #123421 — Couldn't open two folders with almost equal names, except for capitalization on Windows via SSH

[https://github.com/microsoft/vscode/issues/123421](https://github.com/microsoft/vscode/issues/123421)

## Summary

The defect remains directly traceable on current main: window reuse compares every non-file URI case-insensitively, so distinct case-sensitive remote folders collapse to the same window. This issue should remain open as the canonical report.

## Change summary

Opening remote Linux folders whose paths differ only by capitalization incorrectly reuses the existing VS Code window.

## Best solution

Treat non-file remote URI paths as case-sensitive when identifying folders and windows while preserving platform-dependent casing behavior for local file URIs, with regression coverage for differently-cased remote folders.
