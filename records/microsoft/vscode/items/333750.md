# Issue #333750 — Too strong a push for VS Code to do the work of IDE

[https://github.com/microsoft/vscode/issues/333750](https://github.com/microsoft/vscode/issues/333750)

## Summary

VS Code intentionally offers file- and language-based extension recommendations, but already provides a global opt-out that directly covers the reported interruption. This can be closed as designed with guidance to enable that setting.

## Change summary

Stop showing extension recommendations when opening files or changing their language mode.

## Best solution

Keep recommendations enabled by default while preserving the existing `extensions.ignoreRecommendations` opt-out for users who do not want recommendation notifications.

## Vision fit

- **Fit:** unclear
- **Reason:** Suppressing recommendations supports a lean default experience, while recommendations themselves support the extension ecosystem, so the vision does not clearly favor changing the current opt-out balance.
- **Evidence:** Values and guardrails: “Out of the box, VS Code is a text editor: lightweight and fast” and “The power lives in extensions.”
