# Issue #333667 — `github.copilot.chat.summarizeAgentConversationHistory.enabled` not recognized in per-directory workspace settings

[https://github.com/microsoft/vscode/issues/333667](https://github.com/microsoft/vscode/issues/333667)

## Summary

Traced in source: `github.copilot.chat.summarizeAgentConversationHistory.enabled` has no `scope` in `extensions/copilot/package.json` (line 3989), so it defaults to `ConfigurationScope.WINDOW` — configurable only in user or `*.code-workspace` settings, never in a folder's `.vscode/settings.json`. That exactly matches the reported behavior (works in multi-root `*.code-workspace`, grayed out per-folder), so it's not a new regression but a scope choice that may be an inconsistency worth a maintainer look.

## Change summary

`github.copilot.chat.summarizeAgentConversationHistory.enabled` is grayed out / unrecognized in per-folder `.vscode/settings.json`, though it works in `*.code-workspace` settings.

## Best solution

A Copilot Chat maintainer should decide whether this setting is intentionally window/workspace-scoped or should be `"scope": "resource"` like sibling agent settings (e.g. `github.copilot.chat.languageContext.typescript.enabled` at line 3878) so it can be set per folder; if resource scope is the intent, add that one line in `extensions/copilot/package.json`.
