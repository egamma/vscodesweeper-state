# Issue #333667 — `github.copilot.chat.summarizeAgentConversationHistory.enabled` not recognized in per-directory workspace settings

[https://github.com/microsoft/vscode/issues/333667](https://github.com/microsoft/vscode/issues/333667)

## Summary

The setting has no explicit `scope` in extensions/copilot/package.json, so it defaults to `ConfigurationScope.WINDOW` (user/workspace only, not folder) — exactly matching the reported symptom of it being grayed out and unrecognized in a single-folder `.vscode/settings.json` while working in a multi-root `.code-workspace`.

## Change summary

`github.copilot.chat.summarizeAgentConversationHistory.enabled` isn't recognized/settable in a single-folder workspace's `.vscode/settings.json`, though it works in multi-root `*.code-workspace` settings.

## Best solution

Add `"scope": "resource"` to the `github.copilot.chat.summarizeAgentConversationHistory.enabled` entry in extensions/copilot/package.json, consistent with sibling agent-behavior settings (`github.copilot.chat.askAgent.model`, `github.copilot.chat.exploreAgent.model`, the `languageContext.*` settings) that already declare `resource` scope, so it can be set per single-folder workspace, not just user/workspace-file level.
