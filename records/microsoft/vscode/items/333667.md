# Issue #333667 — `github.copilot.chat.summarizeAgentConversationHistory.enabled` not recognized in per-directory workspace settings

[https://github.com/microsoft/vscode/issues/333667](https://github.com/microsoft/vscode/issues/333667)

## Summary

Traced the scope mechanics in the source: `github.copilot.chat.summarizeAgentConversationHistory.enabled` has no explicit `scope` in extensions/copilot/package.json, so it defaults to `ConfigurationScope.WINDOW` (src/vs/platform/configuration/common/configurationRegistry.ts:804). Per-folder `.vscode/settings.json` inside a multi-root `*.code-workspace` is validated against `FOLDER_SCOPES = [RESOURCE, LANGUAGE_OVERRIDABLE, MACHINE_OVERRIDABLE]` (src/vs/workbench/services/configuration/common/configuration.ts:34), which excludes WINDOW — so a WINDOW setting being greyed out there is expected/as-designed. But a true single-folder window's `.vscode/settings.json` resolves to `ConfigurationTarget.WORKSPACE` (preferencesService.ts:119-124, 185-188), which IS in `WORKSPACE_SCOPES` and should allow the setting. Which of these two the reporter actually hit isn't clear from the report, so I can't tell whether this is as-designed or a genuine regression.
