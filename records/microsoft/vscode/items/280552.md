# Issue #280552 — File path and line number linkification - clicking on a selection link should open the editor with a selection

[https://github.com/microsoft/vscode/issues/280552](https://github.com/microsoft/vscode/issues/280552)

## Summary

Still reproduces on main — the link click intentionally places cursor at range start without selecting. The team discussion (mjbvz, roblourens) is converging on a UX compromise (outline-view-style reveal-on-click / select-on-double-click) but no implementation has landed yet. Keeping open for the design decision.

## Change summary

Clicking a file path link with a selection range in chat opens the editor with cursor at range start but does not set the selection.

## Best solution

Implement outline-view-style behavior as roblourens suggested: single click reveals/highlights the range without selecting, double click selects. The fix would touch `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatInlineAnchorWidget.ts` — specifically the click handler around line 318–323 where `editorOptions.selection` is set, and the other open-editor paths at lines 451–454 and 512–520 that only pass `startColumn`/`startLineNumber`.
