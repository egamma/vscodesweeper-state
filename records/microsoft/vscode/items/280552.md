# Issue #280552 — File path and line number linkification - clicking on a selection link should open the editor with a selection

[https://github.com/microsoft/vscode/issues/280552](https://github.com/microsoft/vscode/issues/280552)

## Summary

Keep open for a decision on range-link navigation: the discussion identifies intentional cursor-only behavior and proposes distinguishing reveal from selection. Current source forwards full ranges on one opening path, but no issue-referencing fix was identified to justify closing this team-authored report.

## Change summary

Make chat links to source ranges clearly identify the referenced code when opening an editor, rather than only positioning the cursor at the range start.

## Best solution

Agree on consistent reveal-versus-select behavior for chat range links, taking the maintainer's Outline-style interaction suggestion into account. Then verify both explicit location references and Markdown file links against that contract without making ordinary navigation prone to accidental deletion.
