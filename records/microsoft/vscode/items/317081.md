# Issue #317081 — gh auth login - doesn't show Focus Terminal

[https://github.com/microsoft/vscode/issues/317081](https://github.com/microsoft/vscode/issues/317081)

## Summary

Team-authored issue — must keep open. The report describes a real UX gap: when `gh auth login` prompts a non-sensitive interactive question ('Where do you use GitHub?'), the output monitor fires `onDidDetectInputNeeded` (routing through the agent) instead of surfacing a 'Focus Terminal' action, leaving the user stuck in a limited chat-driven UI that can't easily drive arrow-key menu selection.

## Change summary

When a chat-agent terminal command prompts for non-sensitive interactive input (e.g. `gh auth login` asking 'Where do you use GitHub?'), the user does not see a 'Focus Terminal' button and is stuck with a limited agent-driven UI.

## Best solution

Improve the `runInTerminalTool` input-needed handling so that interactive prompts requiring direct terminal interaction (arrow-key menus, multi-choice selectors) surface a 'Focus Terminal' action similar to the sensitive-input path, rather than only routing through the agent's text-based response. The fix likely lives in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/runInTerminalTool.ts` around the `onDidDetectInputNeeded` handler, and possibly in `outputMonitor.ts` to better classify interactive prompts that need direct terminal focus.
