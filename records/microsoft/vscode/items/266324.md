# Issue #266324 — Consistent crashes with "The window terminated unexpectedly (reason: 'crashed', code: '5')"

[https://github.com/microsoft/vscode/issues/266324](https://github.com/microsoft/vscode/issues/266324)

## Summary

Keep open for the confirmed giant-line Debug Console crash: current source still passes oversized output into DOM text rendering, and no verified fixing commit or qualifying canonical was found. Later reports sharing code 5 do not establish the same defect.

## Change summary

Rendering a roughly 120 MB source-map diagnostic in the Debug Console makes the window unresponsive and crashes its renderer.

## Best solution

Make the Debug Console resilient to oversized output, including single lines and incrementally concatenated output, while preserving useful diagnostics. Establish whether undisplayed text remains available for copying before choosing the output-handling contract.
