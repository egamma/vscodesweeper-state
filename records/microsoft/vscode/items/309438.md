## Summary

Team-authored polish issue about confusing delete-skill UX in the Agents window — the confirmation dialog doesn't explain that deletion will be auto-committed. The maintainer (joshspicer) acknowledged the need for a custom delete modal. No fix commit references this issue; it remains open.

## Change summary

Deleting a skill in the Agents window shows a generic irreversibility warning without explaining that the deletion is auto-committed, confusing users who expect git to still track the change.

## Best solution

Add a custom delete confirmation dialog in the Agents window that explains auto-commit behavior — e.g. 'This file will be deleted and the change will be auto-committed.' The delete action lives in `src/vs/workbench/contrib/chat/browser/aiCustomization/aiCustomizationManagement.contribution.ts` around line 336; the dialog text needs to be context-aware for the sessions/agents window where auto-commit is on by default.
