# Issue #270810 — Terminal tool misuses double quotes in bash (eg. history expansion), especially when running python

[https://github.com/microsoft/vscode/issues/270810](https://github.com/microsoft/vscode/issues/270810)

## Summary

Keep this as the canonical report for Bash history-expansion errors leaving terminal-tool execution unresolved. Current source adds an idle-silence escape hatch, but the documented error-and-prompt sequence still does not resolve normal command completion.

## Change summary

Ensure a Bash history-expansion rejection returns control and its error to the agent instead of leaving the terminal step pending.

## Best solution

Terminal-tool completion should recognize a submitted command rejected before execution when Bash has returned to its prompt, report the error, and allow subsequent commands. Preserve normal Bash quoting semantics and do not treat genuinely running, silent commands as completed.
