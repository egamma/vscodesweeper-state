# Issue #321200 — Chat: foreground history compaction stores raw <analysis>/<summary> response instead of extracting the summary

[https://github.com/microsoft/vscode/issues/321200](https://github.com/microsoft/vscode/issues/321200)

## Summary

Confirmed on current main: the foreground summarization path in summarizeHistory() returns the raw model response without calling extractSummary(), so <analysis> and <summary> tags are stored and rendered verbatim. The background path in agentIntent.ts correctly extracts the summary.

## Change summary

Foreground history compaction stores the raw model response (including <analysis> tags) instead of extracting just the <summary> content.

## Best solution

Apply extractSummary() to summary.result.value at line 654 of summarizedConversationHistory.tsx before passing it to appendTranscriptHint(), mirroring the background path in agentIntent.ts. The closed PR #321201 had the right idea but was never merged.
