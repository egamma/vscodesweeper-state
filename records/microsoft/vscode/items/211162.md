# Issue #211162 — I misunderstood yieldTo

[https://github.com/microsoft/vscode/issues/211162](https://github.com/microsoft/vscode/issues/211162)

## Summary

The API documentation still does not explain how provider-returned array order interacts with yieldTo, and the current sorter retains the reported ordering. Keep this open for an API-owner decision: the discussion explicitly entertains changing the behavior rather than merely documenting it.

## Change summary

Clarify the ordering contract when a provider returns multiple paste edits and only some specify yieldTo.

## Best solution

Settle whether an unconstrained edit should precede an earlier edit that yields to plain text, then make the public API documentation and ordering tests express that contract consistently. Avoid changing paste selection behavior as an incidental documentation cleanup.
