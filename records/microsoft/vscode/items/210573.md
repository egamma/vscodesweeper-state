# Issue #210573 — Resizing Primary Side Bar opens terminal Panel

[https://github.com/microsoft/vscode/issues/210573](https://github.com/microsoft/vscode/issues/210573)

## Summary

The bug remains explainable on current main: when the hidden vertical Panel lies between the Primary Side Bar and editor in the grid, resizing that boundary can select the hidden Panel as a snap target and reveal it. The issue should remain open for a focused split-view fix.

## Change summary

Resizing the Primary Side Bar unexpectedly reveals the closed terminal Panel when both occupy the same side of the workbench.

## Best solution

Ensure resizing the visible Primary Side Bar does not treat the unrelated hidden Panel as the sash's snap-open target, while preserving intentional drag-to-open behavior for hidden parts.
