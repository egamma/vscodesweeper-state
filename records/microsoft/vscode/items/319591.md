# Issue #319591 — ${workspaceFolderBasename} variable not assign correctly when .code-workspace is active

[https://github.com/microsoft/vscode/issues/319591](https://github.com/microsoft/vscode/issues/319591)

## Summary

This is a valid, unrouted feature request rather than a defect in `${workspaceFolderBasename}`: the variable intentionally describes a folder, while multi-root workspaces currently have no interpolation variable for their logical workspace name.

## Change summary

Provide a workspace-level name variable or configurable name for use when a `.code-workspace` contains multiple folders.

## Best solution

Preserve the folder-based meaning and qualified form of `${workspaceFolderBasename}`, and consider a distinct workspace-scoped variable derived from the `.code-workspace` identity or an explicit workspace name. The configuration area should decide whether that additional contract is warranted.
