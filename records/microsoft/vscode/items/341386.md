# Issue #341386 — VS Code 1.141.1 breaks WSL extensions with PendingMigrationError

[https://github.com/microsoft/vscode/issues/341386](https://github.com/microsoft/vscode/issues/341386)

## Summary

Thanks for the report. The PendingMigrationError is a deliberate, long-standing guard in the extension host that fires when an extension reads the global `navigator`. It is only logged as an error, and the setting `extensions.supportNodeGlobalNavigator` turns it off. It is unclear whether this error is what stops the extensions from loading, or why it only appears after 1.141.1. I could not run anything to check, so this stays open until the setting has been tried.

## Change summary

Claude Code and OpenAI Codex fail in the WSL remote extension host after updating to 1.141.1, with a PendingMigrationError about `navigator`.

## Best solution

Confirm whether `extensions.supportNodeGlobalNavigator` fixes it. If it does, the extensions need to stop touching `navigator` in Node, or the remote Node runtime change that exposed it needs to be understood. If it doesn't, find the real load failure in the extension host log.
