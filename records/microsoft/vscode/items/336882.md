# Issue #336882 — Agent Plugins format: ${PLUGIN_ROOT} / ${PLUGIN_DATA} not expanded in plugin mcp.json and hooks.json (stdio MCP server cannot start)

[https://github.com/microsoft/vscode/issues/336882](https://github.com/microsoft/vscode/issues/336882)

## Summary

Same root cause as the older, open issue #335006: the Agent Plugins 1.0 format config has empty pluginRootTokens/pluginRootEnvVars and skips interpolation, so ${PLUGIN_ROOT}/${PLUGIN_DATA} are never expanded for that format's mcp.json (and this report additionally shows it breaks hooks.json too). Proposing a duplicate close, carrying forward the hooks.json and stdio-server detail into the canonical thread.

## Change summary

For Agent Plugins 1.0-format plugins, ${PLUGIN_ROOT}/${PLUGIN_DATA} placeholders in mcp.json (and hooks.json) are never expanded, so stdio MCP servers referencing bundled files fail to start.

## Best solution

Fix on https://github.com/microsoft/vscode/issues/335006: populate AGENT_PLUGIN_FORMAT's pluginRootTokens/pluginRootEnvVars and stop excluding PluginFormat.AgentPlugin from interpolateMcpPluginRoot / defaultCwd assignment in src/vs/platform/agentPlugins/common/pluginParsers.ts; while there, also check the hooks.json command-substitution path this report calls out.
