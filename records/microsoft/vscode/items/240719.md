# Issue #240719 — Git - stage selected ranges in an untracked file

[https://github.com/microsoft/vscode/issues/240719](https://github.com/microsoft/vscode/issues/240719)

## Summary

Valid feature request acknowledged by the area owner (lszomoru). The intentional 1.97 change to skip quick-diff for untracked files removed the ability to stage selected ranges; the maintainer said the scenario has merit and would get back. Still under discussion with 8 upvotes — keeping open.

## Change summary

Allow staging selected ranges in untracked (new) files, which became impossible after the 1.97 change that stopped showing untracked files in a diff editor.

## Best solution

Provide a quick-diff original for untracked files (e.g. an empty document) so the diff editor can open and 'Stage Selected Ranges' works. The change would be in `extensions/git/src/quickDiffProvider.ts` (lines 60-64 currently return `undefined` for untracked paths) and possibly in how the SCM resource click opens untracked files. The area owner already acknowledged merit — this needs a design decision on whether to always show a diff or add a setting.
