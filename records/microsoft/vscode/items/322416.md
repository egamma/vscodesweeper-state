# Issue #322416 — New chat issue title changes twice

[https://github.com/microsoft/vscode/issues/322416](https://github.com/microsoft/vscode/issues/322416)

## Summary

Keep open: current source still has two distinct first-message title transitions, and the team-authored issue is accepted in the On Deck milestone. The remaining product decision is whether to retain the prompt-derived title, wait for the host-generated title, or support later dynamic retitling.

## Change summary

Prevent a new Local Agent Host Copilot CLI session from replacing an accurate prompt-derived title with a less representative generated title, and clarify whether titles should evolve with later turns.

## Best solution

Define one predictable title lifecycle for new Agent Host sessions and encode it in the provider tests: avoid a visibly misleading provisional-to-generated replacement while preserving explicit user renames. Decide separately whether subsequent conversation turns may automatically retitle an unrenamed session.
