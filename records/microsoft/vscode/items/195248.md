# Issue #195248 — File Nesting setting is ignored

[https://github.com/microsoft/vscode/issues/195248](https://github.com/microsoft/vscode/issues/195248)

## Summary

The reporter's original bug was self-resolved (a folder-level settings.json was overriding the value), but the residual ask — showing 'Modified in Folder' indicators in the Settings UI — is a real gap confirmed by source inspection: the overriddenScopeList computation omits workspaceFolderValue. Keeping open as a polish item in the settings-editor area.

## Change summary

The Settings UI does not show an 'Also modified in' indicator when a setting is overridden at the workspace-folder level in a multi-root workspace.

## Best solution

Extend the overriddenScopeList computation in settingsTreeModels.ts to include workspaceFolderValue (similar to how workspace/remote/user are already handled), and add corresponding display text in settingsEditorSettingIndicators.ts. This is a small, localized change.
