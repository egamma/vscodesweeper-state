# Issue #342823 — Disconnecting / Detaching with multiple debug sessions

[https://github.com/microsoft/vscode/issues/342823](https://github.com/microsoft/vscode/issues/342823)

## Summary

The current source still loses the target session when Disconnect is invoked from a Call Stack row's dropdown: it falls back to the focused session instead. Keep this open; the older reported version does not invalidate the source-confirmed defect.

## Change summary

Disconnecting from one debug session's Call Stack dropdown can detach a different session when multiple independent sessions are running.

## Best solution

Make Call Stack dropdown actions honor the session belonging to their originating row, while preserving focused-session behavior for global debug controls and the existing arguments passed to extension-contributed actions.
