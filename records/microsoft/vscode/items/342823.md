# Issue #342823 — Disconnecting / Detaching with multiple debug sessions

[https://github.com/microsoft/vscode/issues/342823](https://github.com/microsoft/vscode/issues/342823)

## Summary

The Call Stack dropdown loses the target session through an argument-position mismatch on current main, causing Disconnect to use the focused session instead. Keep this open as a bounded debugger command-context bug.

## Change summary

Disconnect from a Call Stack session's dropdown should detach that session, not another running session.

## Best solution

Make the per-session dropdown honor its originating session while preserving focused-session behavior for global debug controls and the existing extension-contributed argument contract.
