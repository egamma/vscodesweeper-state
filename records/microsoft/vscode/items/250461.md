# Issue #250461 — Show MCP sampling using on registry page

[https://github.com/microsoft/vscode/issues/250461](https://github.com/microsoft/vscode/issues/250461)

## Summary

Keep open: the MCP server editor still lacks an integrated sampling-usage view, and the existing action opens a separate text report. A maintainer explicitly accepted the server-page direction; the current chat-mcp routing remains appropriate.

## Change summary
