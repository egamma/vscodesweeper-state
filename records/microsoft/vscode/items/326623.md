# Issue #326623 — Agents - no workspace layout

[https://github.com/microsoft/vscode/issues/326623](https://github.com/microsoft/vscode/issues/326623)

## Summary

Keep open: current single-pane layout logic mishandles a new session with no selected workspace, leaving workspace-dependent layout visible and compressing the composer.

## Change summary

Opening the Agents window from a transient profile without selecting a workspace produces an inappropriate empty workspace side-pane layout.

## Best solution

Define the zero-folder new-session state consistently across the single-pane strategies, hiding workspace-dependent editor/detail surfaces until a workspace is selected, with a focused layout regression test.
