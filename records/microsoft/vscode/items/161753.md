## Change summary

Expose an extension API callback so TreeView extensions can react to the built-in Ctrl+F tree filter text and customize filtering behavior (e.g. keeping children of matching parents visible).

## Best solution

Add a proposed API surface on `TreeView` (e.g. an `onDidChangeFilterText` event or a `filterProvider` option) that lets extensions receive the current filter string and control which nodes remain visible.
