These are contributor-provided measurements, not a locally executed reproduction.

Lines 597-609 already construct a WorkbenchObjectTree with dynamic-height support, so the report's assertion that chat simply lacks virtualization is not an established diagnosis.
- **Older same-symptom report:** https://github.com/microsoft/vscode/issues/297349 was verified OPEN and created on 2026-02-24, before this report. It describes progressive scrolling, resizing, typing, and interaction lag in long Copilot conversations. It is a strong consolidation lead under the re-review criteria, but the explicit keep-open rule for an open PR referencing this issue takes precedence here.
- **Remaining scope:** The linked PR identifies additional per-update costs in approval tracking, generated-image extraction, tool-confirmation observation, and ChatViewModel.computeItems.
