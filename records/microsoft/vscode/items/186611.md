# Issue #186611 — Grid: distribute split views evenly even when one view requires a larger width

[https://github.com/microsoft/vscode/issues/186611](https://github.com/microsoft/vscode/issues/186611)

## Summary

The distribution bug remains in current main: a view clamped to a larger minimum creates a size deficit that is absorbed from the last view first, producing the reported asymmetric layout.

## Change summary

Distribute the space required by a split view with a larger minimum width evenly across the other flexible views instead of taking it from the final view.

## Best solution

Make SplitView distribution constraint-aware so all views satisfy their minimum and maximum sizes while the remaining space is shared as evenly as possible, with unit coverage for unequal minimum sizes.
