# Issue #208665 — Notebook outline view: Symbols are often incomplete

[https://github.com/microsoft/vscode/issues/208665](https://github.com/microsoft/vscode/issues/208665)

## Summary

Still reproduces on main: editing a code cell's content triggers `delayedRecomputeState()` but never re-caches the document symbols, so the outline shows stale symbols after edits. The refactor work mentioned in comment #4 has not fully addressed the live-update path.

## Change summary

Notebook outline view does not update code cell symbols when cell content is edited (e.g. renaming a variable), nor when the cell language type changes.

## Best solution

When `ChangeCellContent` fires for a code cell, trigger `cacheSymbols()` for that cell (debounced) before calling `recomputeState()`, so the outline entry factory's `cellOutlineEntryCache` reflects the current document symbols. The fix belongs in `notebookOutline.ts` (the content-change listener at ~line 702) and possibly `notebookOutlineDataSource.ts`.
