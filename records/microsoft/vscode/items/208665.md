# Issue #208665 — Notebook outline view: Symbols are often incomplete

[https://github.com/microsoft/vscode/issues/208665](https://github.com/microsoft/vscode/issues/208665)

## Summary

The stale-symbol defect remains traceable on current main: editing a cell rebuilds the outline from cached symbols without refreshing them, and changing the cell language is not handled by the outline's content listener. Keep this team-authored report open; the related refactor's closure does not establish that these behaviors were fixed.

## Change summary

Notebook outline code symbols should update after symbol renames and cell-language changes without reopening the notebook.

## Best solution

Make notebook outline symbols reflect the current cell contents and language after asynchronous symbol discovery completes, while preserving nonblocking outline updates. Cover both reported triggers in the notebook outline tests and coordinate the newer related reports under this older issue.
