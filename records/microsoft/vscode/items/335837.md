# Issue #335837 — Incomplete enum settings for Agents Window word wrap settings

[https://github.com/microsoft/vscode/issues/335837](https://github.com/microsoft/vscode/issues/335837)

## Summary

A team member is raising a design question while reviewing the new Agents Window word-wrap settings: `sessions.editor.wordWrap` and `sessions.diffEditor.wordWrap` only expose `off | on | inherit`, unlike `editor.wordWrap`'s full `off | on | wordWrapColumn | bounded`. This is a self-filed, team-authored note that needs a maintainer decision, not a mechanical fix — stays open per the team-authored keep-open rule.

## Change summary

Question why the new Agents Window word-wrap settings (`sessions.editor.wordWrap`, `sessions.diffEditor.wordWrap`) omit the `wordWrapColumn` and `bounded` enum values that `editor.wordWrap` supports.

## Best solution

A maintainer should decide whether `wordWrapColumn`/`bounded` are worth supporting for the Agents Window editors (they'd also need a column-width setting to pair with them) — if intentionally simplified for this experimental surface, document that in the setting description; if not, extend the enum in `src/vs/sessions/contrib/editor/browser/diffEditor.sessions.contribution.ts` and the `SessionsWordWrap` type in `src/vs/sessions/contrib/editor/common/diffEditorOptionsService.ts`.
