# Issue #316164 — [Agents App] Changes view categories are confusing — "Branch Changes" vs "All Changes" vs "Uncommitted Changes"

[https://github.com/microsoft/vscode/issues/316164](https://github.com/microsoft/vscode/issues/316164)

## Summary

Keep open for a Changes-view design decision: current main offers a single changeset dropdown with descriptions, but still exposes the overlapping terminology and provider-defined defaults behind the reported confusion. Related requests cover default selection and cross-worktree review, but no verified older canonical owns this full usability problem.

## Change summary

Simplify the Agents Window change categories so users understand the review scope and can readily review the changes they care about.

## Best solution

Establish a plainly explained default review scope and consistent terminology across the Changes panel and chat entry points, retaining access to genuinely distinct comparisons. Decide whether reviewing all worktrees belongs in this surface or a separate aggregate view, and coordinate configurable defaults with https://github.com/microsoft/vscode/issues/336866.
