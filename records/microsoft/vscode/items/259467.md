# Issue #259467 — MCP code exchange request not going through due to proxy

[https://github.com/microsoft/vscode/issues/259467](https://github.com/microsoft/vscode/issues/259467)

## Summary

Keep open: the reporter supplied a credible MCP OAuth failure at the token-exchange step, and repeated maintainer reopenings indicate that the problem remains under investigation. Current source and history provide neither a post-reopen fixing commit nor a verified duplicate, which are the only applicable factual close paths for this team-authored issue.

## Change summary

MCP OAuth obtains an authorization code but the form-encoded POST to the token endpoint does not complete when the MCP service is behind a Traefik reverse proxy.

## Best solution

Reproduce the authorization-code exchange against a controlled reverse-proxy OAuth endpoint and determine why the POST stalls even though requests reach the endpoint. If transport behavior is responsible, make MCP authentication use the established proxy-compatible network path without changing OAuth request semantics.
