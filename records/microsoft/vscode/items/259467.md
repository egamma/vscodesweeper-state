## Change summary

MCP OAuth token exchange request fails when the MCP server is behind a reverse proxy (traefik), because the code uses Node.js native `fetch` instead of VS Code's proxy-aware fetch.

## Best solution

Align the `fetch` calls in `extHostAuthentication.ts` (lines 776 and 826) with the proxy-aware fetch pattern used in `github-authentication`, as chrmarti suggested. This ensures the token exchange respects VS Code's proxy configuration. The reporter should also be asked to re-test on the latest Insiders once a fix lands.
