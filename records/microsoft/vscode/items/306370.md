## Evidence

- **canonical issue:** https://github.com/microsoft/vscode/issues/301793 is older, open, and reports the same observable symptom in the Chat panel: after a workspace-identity-changing reload, the current conversation disappears and is absent from Show Chats.
- **confirmed root cause:** https://github.com/microsoft/vscode/pull/305109 diagnoses the shared defect: workspace storage switches before ChatSessionStore migrates metadata, so clearing `indexCache` and calling `flushIndex()` writes an empty index. Its description explicitly states that both workspace-to-workspace and empty-window-to-workspace transitions are affected.
- **current source:** On current main, `ChatSessionStore.migrateSessionsToNewWorkspace()` in src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts still sets `indexCache = undefined` before `flushIndex()`, matching the diagnosed path that leaves copied session files inaccessible through chat history.
- **open implementation:** https://github.com/microsoft/vscode/pull/305109 remains open and references the canonical issue, so implementation should be reviewed and consolidated there rather than tracked independently here.
