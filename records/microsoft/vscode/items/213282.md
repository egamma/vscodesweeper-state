# Issue #213282 — Bolded font is not detected for custom font family

[https://github.com/microsoft/vscode/issues/213282](https://github.com/microsoft/vscode/issues/213282)

## Summary

The font itself has incorrect metadata (weight settings and naming), preventing the OS font system from matching the bold variant — this is a font-file issue, not a VS Code rendering bug.

## Change summary

Bold weight of Comic Mono font not rendered in the editor despite being installed.

## Best solution

Close as not reproducible — the root cause is malformed font metadata in the Comic Mono font files, not a defect in VS Code's font handling. VS Code correctly delegates bold rendering to the platform's font matching system via CSS `font-weight: bold`.
