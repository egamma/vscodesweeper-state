# Issue #348287 — COPILOT_HOME is not respected by default customization locations and hook discovery

[https://github.com/microsoft/vscode/issues/348287](https://github.com/microsoft/vscode/issues/348287)

## Summary

The path mismatch remains directly traceable on current main: default personal customization locations and host-side hook watch roots still resolve beneath the user home rather than COPILOT_HOME. Keep this report open; the related portable-skills issue does not cover its full scope.

## Change summary

Make default personal Copilot customization locations and host-side hook discovery roots honor COPILOT_HOME while preserving explicitly configured locations.

## Best solution

Default personal discovery, creation destinations, and refresh tracking should agree with the runtime's resolved Copilot home. Preserve explicit location overrides, workspace discovery, other providers' paths, and SDK ownership of hook execution.
