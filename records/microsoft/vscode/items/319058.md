# Issue #319058 — Shell integration for fish breaks command status code return

[https://github.com/microsoft/vscode/issues/319058](https://github.com/microsoft/vscode/issues/319058)

## Summary

Confirmed bug traceable in source: when `fish_mode_prompt` is empty/erased (as starship and similar tools do), `__vsc_fish_prompt_start` emits an escape sequence via `builtin printf` which resets `$status` to 0 before the user's prompt function can read it. An open PR (#319065) addresses this — keeping open pending review of that PR.

## Change summary

Fish shell integration's prompt-start escape sequence clobbers `$status`, breaking command exit-code detection when `fish_mode_prompt` is empty.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/319065, which should save/restore `$status` around the `__vsc_fish_prompt_start` escape sequence emission in `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.fish`.
