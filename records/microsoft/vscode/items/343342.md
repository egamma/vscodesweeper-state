# Issue #343342 — Stop reading Copilot's plugin inventory from config.json on the client

[https://github.com/microsoft/vscode/issues/343342](https://github.com/microsoft/vscode/issues/343342)

## Summary

Keep open: the client still reads and watches Copilot's private installation configuration, and host publication still misses hooks-only and MCP-only plugins. The merged marketplace prerequisite does not complete this migration, and an open PR owns the forwarding portion.

## Change summary

Make the selected Copilot host authoritative for SDK-managed plugin inventory and content while preserving forwarding of genuinely client-provided plugins.

## Best solution

Review and land the forwarding change in https://github.com/microsoft/vscode/pull/343899, complete SDK-owned hook/MCP publication tracked by https://github.com/microsoft/vscode/issues/343572, and retire client configuration/cache discovery once its remaining consumers use provider-published inventory.
