# Issue #343342 — Stop reading Copilot's plugin inventory from config.json on the client

[https://github.com/microsoft/vscode/issues/343342](https://github.com/microsoft/vscode/issues/343342)

## Summary

Keep open: current main still discovers SDK-managed installations through the client's config.json reader and can forward them back as client plugins. Host-side projection exists, but explicitly misses hooks-only and MCP-only plugins, so it does not yet satisfy this request.

## Change summary

Make the selected Copilot agent host authoritative for SDK-managed plugin inventory and content while preserving genuinely client-provided plugin forwarding.

## Best solution

Publish complete SDK-managed plugin inventory and content from the owning host, with customization UI, enablement, navigation, and installation refresh consuming that authoritative state. Remove client config/cache discovery and SDK-plugin round-trip forwarding without absorbing the separate VS Code-managed installation migration.
