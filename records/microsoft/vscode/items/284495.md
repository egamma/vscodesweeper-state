# Issue #284495 — Remember Copilot Results expand state

[https://github.com/microsoft/vscode/issues/284495](https://github.com/microsoft/vscode/issues/284495)

## Summary

Keep open: current search code still changes the semantic-results heading's expansion state programmatically rather than consistently retaining the user's choice across searches. This team-authored request has neither a verified fixing commit nor an older open canonical covering the same behavior.

## Change summary

Start the Copilot Results heading collapsed, then preserve the user's expanded or collapsed choice across subsequent searches.

## Best solution

Have the Search view retain the user's chosen semantic-results heading state across successive queries, while preserving the initially collapsed presentation and explicit commands that reveal results.
