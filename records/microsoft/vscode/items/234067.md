# Issue #234067 — Regex replace matches without consuming and leaks groups between matches

[https://github.com/microsoft/vscode/issues/234067](https://github.com/microsoft/vscode/issues/234067)

## Summary

Two defects remain identifiable in current source: closed-file searches can turn a consuming character class into a zero-width assertion, and context-dependent replacements can reuse an earlier match's captures. Keep this issue open; the verified related reports do not individually cover its full scope.

## Change summary

Preserve regex match consumption and use each search result's own capture groups when computing replacements.

## Best solution

Make workspace search preserve the original regex's consuming semantics and compute replacement captures for the specific result range, including when lookarounds require surrounding text. Open and closed files should produce the same matches and replacement text for the supplied examples.
