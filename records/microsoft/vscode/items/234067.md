# Issue #234067 — Regex replace matches without consuming and leaks groups between matches

[https://github.com/microsoft/vscode/issues/234067](https://github.com/microsoft/vscode/issues/234067)

## Summary

Verified duplicate: the open, confirmed canonical issue tracks the same defect where every replacement on a line can reuse the first match's capture groups.

## Change summary

Regex replacement previews and edits can use capture groups from another match, especially with lookarounds or unopened files.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/153522 and change workspace-search replacement calculation to evaluate the exact reported match range rather than the first regex match in its preview context.
