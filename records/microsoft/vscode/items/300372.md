Manually retest custom menubar menus, a contrasting menu.border, and editorStickyScroll.shadow while scrolling a file with sticky headers on Windows and Linux; distinguish confirmed remaining failures from already-working cases.
- **Behavior:**

  > A custom theme's menu.selectionForeground and menu.selectionBackground should determine selected-item colors in VS Code's custom menus, independently of list hover colors. The report also expects menu.border to affect right-click context menus and editorStickyScroll.shadow to affect sticky headers. Acceptance requires independent checks for each token so restoring menu selection colors is not mistaken for resolving the entire report. Preserve keyboard selection, submenu behavior, and high-contrast visibility.
- **Trace:**

  > The selection regression is conclusive: defaultMenuStyles in src/vs/platform/theme/browser/defaultStyles.ts uses list hover variables even though src/vs/platform/theme/common/colors/menuColors.ts still registers the menu selection tokens. ContextMenuHandler passes these defaults to Menu, whose BaseMenuActionViewItem.applyStyle consumes them for focused items; MenubarControl uses the same defaults. The exact replacement appears in https://github.com/microsoft/vscode/commit/a6bcce17ede062097d21484fb8665e8e8a51125a. Current menu border CSS and sticky-scroll CSS still reference their reported tokens, so uncertainty starts with reproducing those two visual cases and identifying any overriding or clipping behavior. https://github.com/microsoft/vscode/issues/313843 was consolidated into this issue and adds a menubar selection observation, while https://github.com/microsoft/vscode/issues/300396 covers only borders. Keep ordinary list hover behavior, menu interaction semantics, and unrelated terminal styling outside the change boundary.

## Evidence

- **Exact rendering path:** src/vs/platform/contextview/browser/contextMenuHandler.ts:88–95 supplies defaultMenuStyles to Menu. src/vs/base/browser/ui/menu/menu.ts:712–725 applies those selection colors to focused menu items. src/vs/workbench/browser/parts/titlebar/menubarControl.ts:514 also supplies defaultMenuStyles to MenuBar. Customizing only the reported menu selection tokens therefore does not control these selected-item colors.
