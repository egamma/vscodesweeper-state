## Summary

This still looks actionable: current main continues to route menu selection styling through list hover colors, so documented `menu.selectionForeground` and `menu.selectionBackground` customizations are not honored. Some pieces of the original report have follow-up commits, but the menu-selection token regression remains and should be routed to theming/workbench owners.
