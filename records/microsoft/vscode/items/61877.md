# Issue #61877 — Git - VS Code no longer supports 'edit' in 'git rebase' flow

[https://github.com/microsoft/vscode/issues/61877](https://github.com/microsoft/vscode/issues/61877)

## Summary

Keep open: the current source still substitutes rebase continuation for ordinary commits during an interactive edit stop and warns against changing the message. The related interactive-rebase feature request does not establish a same-symptom duplicate, and this team-authored bug remains accepted work.

## Change summary

Allow Source Control to create or amend commits while an interactive rebase is paused for editing, without implicitly continuing the rebase.

## Best solution

Restore ordinary commit and amend operations during interactive edit stops, with rebase continuation available as a distinct action. Address the rebase-state detection, message validation, command dispatch, and action-button behavior together while preserving conflict-resolution workflows.
