## Summary

The answer-kind mismatch remains directly traceable on current main: a custom single-select response becomes Text despite selection question metadata being available. Keep this team-authored bug open for protocol-correct conversion and submission-recovery handling.

## Change summary

Custom-only answers to Agent Host selection questions must preserve the selection answer kind, and rejected submissions must remain visibly retryable.

## Best solution

Ensure the Agent Host carousel boundary preserves question-kind-compatible answers for custom input without changing genuine text, boolean, or listed-option behavior. Complete the fix with rejection feedback and a retryable question, validated against a conforming cloud host.
