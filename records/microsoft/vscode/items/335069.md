# Issue #335069 — First agent handoff blocked by process-wide message limit

[https://github.com/microsoft/vscode/issues/335069](https://github.com/microsoft/vscode/issues/335069)

## Summary

The process-wide counter can still reject a task session's first completion handoff after unrelated sessions exhaust the shared allowance. A later mitigation doubled the limit and added an opt-out, but it did not remove the starvation path; this team-authored issue should remain open.

## Change summary

Prevent unrelated process-wide `send_message` traffic from blocking a task session's first completion report to its coordinator, and make limit recovery actionable.

## Best solution

Retain protection against runaway messaging while guaranteeing that ordinary child-to-coordinator completion reports cannot be starved by unrelated sessions. When a limit is reached, report its accounting scope, usage, and recovery condition.
