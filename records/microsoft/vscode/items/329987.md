# Issue #329987 — [Claude] Adding API key in Claude Settings needs VS Code restart to use Anthropic models

[https://github.com/microsoft/vscode/issues/329987](https://github.com/microsoft/vscode/issues/329987)

## Summary

Verified duplicate: the underlying defect — no reactivity to `~/.claude/settings.json` credential changes, so the native model catalog never re-enumerates without a restart — is already tracked, more broadly, by the open issue https://github.com/microsoft/vscode/issues/329722, whose sketched fix (a credential-source watcher that kicks `_startModelRefresh()`) resolves this symptom too.

## Change summary

Adding an Anthropic API key to `~/.claude/settings.json` while VS Code is running doesn't surface native Anthropic models in the Claude harness until VS Code is restarted.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/329722 — implementing the credential-source file watcher there (firing `_startModelRefresh()`/`onDidChangeProtectedResources`) both lifts the sign-in gate reactively and refreshes the native model catalog, which is exactly what this report needs.
