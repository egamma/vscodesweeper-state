# Issue #329987 — [Claude] Adding API key in Claude Settings needs VS Code restart to use Anthropic models

[https://github.com/microsoft/vscode/issues/329987](https://github.com/microsoft/vscode/issues/329987)

## Summary

The automatic model-refresh gap remains: editing Claude settings does not invalidate the native model catalog while the harness is idle. Keep this team-authored report open; the older related issue concerns a different observable symptom, a blocked sign-in gate.

## Change summary

Adding an Anthropic API key to ~/.claude/settings.json should make native Anthropic models appear without restarting VS Code.

## Best solution

Refresh and republish Claude's native model catalog when the relevant settings change, including before any turn has started, while preserving Copilot-backed models. Coordinate with the related sign-in-gate issue without treating its narrower gated scenario as coverage for this already-usable harness.
