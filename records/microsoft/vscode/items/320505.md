# Issue #320505 — problem with zoom

[https://github.com/microsoft/vscode/issues/320505](https://github.com/microsoft/vscode/issues/320505)

## Summary

The requested editor-only zoom behavior already exists through the `editor.mouseWheelZoom` setting and dedicated editor font-size commands. This is a configuration/support question rather than missing functionality.

## Change summary

Zoom only the editor text without resizing the sidebar and other workbench UI.

## Best solution

Enable `editor.mouseWheelZoom` for Ctrl+mouse-wheel editor font zoom, or bind the existing Increase/Decrease Editor Font Size commands to preferred shortcuts; retain Ctrl+Plus/Minus for whole-window zoom.
