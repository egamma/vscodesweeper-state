# Issue #221362 — BUG: `Move line down` command doesnt preserve indentation

[https://github.com/microsoft/vscode/issues/221362](https://github.com/microsoft/vscode/issues/221362)

## Summary

The TypeScript import round trip still loses indentation in the current source: moving down removes the imported name's indentation, and moving back up reinserts it without recalculating that indentation. Keep this open in editor-autoindent; the older related report describes a different observable failure.

## Change summary

Moving an import's opening line down and back up loses the indentation of its imported name.

## Best solution

Make the reported line-move round trip restore the imported name's indentation while retaining context-aware indentation for ordinary line moves. Cover the command's displaced-line behavior with a focused regression test rather than disabling auto-indentation globally.
