# Issue #206597 — Outline view: Auto collapse previous method tree when 'Follow Cursor' is checked.

[https://github.com/microsoft/vscode/issues/206597](https://github.com/microsoft/vscode/issues/206597)

## Summary

Keep open: Follow Cursor reveals the active symbol but does not collapse previously expanded branches, and the existing collapse setting does not provide that behavior. This is accepted Backlog work; the historical community-review notices are not grounds for closing it.

## Change summary

Offer an Outline mode that expands the active method's branch and collapses previously active branches as the editor cursor moves.

## Best solution

Provide an opt-in active-branch mode in the Outline contribution while preserving existing Follow Cursor behavior by default. Settle how this mode interacts with manually expanded branches before implementation.

- **Behavior:**

  > With Follow Cursor enabled, an optional mode keeps the Outline focused on the current method rather than accumulating expanded method branches. Moving the cursor from one method to another reveals the new active branch and collapses the previously active branch. Existing Follow Cursor behavior remains unchanged when the mode is disabled. Acceptance must also specify what happens to branches the user expanded manually.
- **Trace:**

  > OutlinePane in src/vs/workbench/contrib/outline/browser/outlinePane.ts creates the tree and defines revealActiveElement, which reveals and selects the active symbol without collapsing prior branches. The existing outline.collapseItems setting is registered in outline.contribution.ts and feeds collapseByDefault in documentSymbolsOutline.ts; it does not implement active-only expansion. OutlineViewState owns the existing Follow Cursor state. Preserve default navigation, filtering, and saved expansion behavior outside the new mode. Source inspection establishes the missing capability; no runtime reproduction was attempted. The remaining uncertainty is the user-visible policy for manual expansion while active-branch following is enabled.
- **Open decisions:**
