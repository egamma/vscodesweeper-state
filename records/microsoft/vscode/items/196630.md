# Issue #196630 — Vscode cannot access extensions marketplace when http.proxy contains user credentials

[https://github.com/microsoft/vscode/issues/196630](https://github.com/microsoft/vscode/issues/196630)

## Summary

Fixed on main and shipped in 1.92.0 — the proxy credential handling was reworked to strip credentials from the URL before passing to Electron's setProxy, and supply them separately via the proxy auth handler.

## Change summary

VS Code cannot access the extensions marketplace when http.proxy contains user credentials (user:password@host).

## Best solution

Keep the shipped fix (commit c36c1716f8b, 1.92.0). The proxy URL is now stripped of credentials before being passed to Electron, and credentials are used via the ProxyAuthService when Electron challenges for authentication.
