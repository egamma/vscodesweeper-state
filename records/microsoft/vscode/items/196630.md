# Issue #196630 — Vscode cannot access extensions marketplace when http.proxy contains user credentials

[https://github.com/microsoft/vscode/issues/196630](https://github.com/microsoft/vscode/issues/196630)

## Summary

This is a duplicate of #220034 ("Basic auth support for proxies"), which was fixed in commit c36c1716f8b and shipped in 1.92.0. The fix strips credentials from the proxy URL before passing to Electron and uses them to respond to proxy auth challenges.

## Change summary

VS Code cannot access the extensions marketplace when http.proxy contains user credentials (user:password@host).

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/220034 which tracked and resolved this exact problem — proxy URLs with embedded credentials now work for marketplace access.
