# Issue #311732 — MCP tool returning MIME-mismatched image permanently poisons conversation (400 on all subsequent turns)

[https://github.com/microsoft/vscode/issues/311732](https://github.com/microsoft/vscode/issues/311732)

## Summary

The defect remains source-reproducible on current main: Anthropic request serialization trusts an MCP image's declared MIME type and reserializes the same invalid historical tool result on every subsequent turn. Route this canonical report to the Chat vision/MCP owners for a bounded fix.

## Change summary

Prevent a MIME-mismatched image returned by an MCP tool from causing the current and all subsequent conversation requests to fail with HTTP 400.

## Best solution

Normalize supported base64 image media types from their actual bytes before constructing Anthropic image blocks, including historical tool results, so the first request succeeds and already-poisoned conversations recover on their next turn.
