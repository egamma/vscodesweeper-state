# Issue #235754 — Incorrect Batch Regex Replacement

[https://github.com/microsoft/vscode/issues/235754](https://github.com/microsoft/vscode/issues/235754)

## Summary

Confirmed on current main: the notebook Replace All implementation uses a per-cell index into a flat cross-cell replacement array, causing incorrect replacements in all cells after the first — leading to data corruption.

## Change summary

Notebook regex Replace All applies wrong replacement strings to cells after the first, corrupting notebook content.

## Best solution

Fix the index mismatch in `notebookViewModelImpl.ts` `replaceAll()`: use a running counter across the outer loop instead of the per-cell `index` from the inner `forEach`. The flat `texts` array from the widget is correct; only the consumption side indexes it wrong.
