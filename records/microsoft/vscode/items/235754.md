# Issue #235754 — Incorrect Batch Regex Replacement

[https://github.com/microsoft/vscode/issues/235754](https://github.com/microsoft/vscode/issues/235754)

## Summary

Keep open: notebook Replace All can corrupt cell contents by applying another cell's captured text. An independent confirmation and the current implementation identify the same indexing defect; the existing notebook-find routing is correct.

## Change summary

Regex Replace All in notebooks incorrectly reuses replacement strings from earlier cells, overwriting later cells with unrelated captured content.

## Best solution

Make notebook bulk replacement preserve the correspondence between every match and its replacement across cell boundaries. Preserve single-replacement behavior and verify that identity replacements leave every cell unchanged.
