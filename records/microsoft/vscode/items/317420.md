# Issue #317420 — Add search/filter functionality to utility model settings

[https://github.com/microsoft/vscode/issues/317420](https://github.com/microsoft/vscode/issues/317420)

## Summary

Valid feature request from a team member for search/filter in the utility model settings dropdown. The current implementation uses a dynamic enum populated by UtilityModelContribution but has no built-in filtering — as models grow, scrolling becomes cumbersome. Stays open for the area owners.

## Change summary

Add search or filter capability to the utility model settings picker so users can quickly find models as the list grows.

## Best solution

Add a filter/search input to the model enum picker in the settings editor (likely in `src/vs/workbench/contrib/preferences/browser/`) or adopt a searchable dropdown pattern for dynamic enum settings with many entries. The settings-editor area team should decide whether this is a generic settings-editor improvement for large enums or specific to model pickers.
