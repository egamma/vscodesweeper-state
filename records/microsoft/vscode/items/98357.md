# Issue #98357 — Strange bug in PHP files with HTML and Emmet parser because conditionals are been mistaken as opening and/or closing tags

[https://github.com/microsoft/vscode/issues/98357](https://github.com/microsoft/vscode/issues/98357)

## Summary

Still reproduces on current main: the @emmetio/html-matcher (v0.3.3) used by VS Code's Emmet extension parses PHP comparison operators (<=, >=) as HTML tag delimiters. The upstream issue remains open with no fix.

## Change summary

Emmet and HTML features break in PHP files when comparison operators like <= or >= appear, because the parser mistakes them for HTML tags.

## Best solution

Wait for a fix in @emmetio/html-matcher (tracked at https://github.com/emmetio/html-matcher/issues/8), or implement a VS Code-side workaround in `extensions/emmet/src/parseDocument.ts` that strips or escapes PHP blocks before passing content to the html-matcher parser.
