# Issue #299600 — CLI session isolation: Confusing to have two identical folder icons

[https://github.com/microsoft/vscode/issues/299600](https://github.com/microsoft/vscode/issues/299600)

## Summary

Keep open: current source still allows the folder selector and Workspace isolation selector to display identical folder icons without visible labels in compact mode. No verified older canonical or issue-referencing fix was found, and this team-authored report should not receive a judgment close.

## Change summary

Make the folder-selection and isolation-mode controls distinguishable when creating a Copilot CLI session in an empty window.
