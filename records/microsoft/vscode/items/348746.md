# Issue #348746 — Agents: failed feedback send leaves the comment submitted and hides Submit

[https://github.com/microsoft/vscode/issues/348746](https://github.com/microsoft/vscode/issues/348746)

## Summary

The missing failure recovery remains in current main: local acceptance marks feedback submitted, but a subsequent send rejection never restores retryability. Keep this open as a bounded feedback-state bug, separate from transport reconnection.

## Change summary

Restore feedback retryability when its locally accepted request subsequently fails to send, without delaying acknowledgement of queued submissions.

## Best solution

Failed delivery should leave the affected comments available to submit again while preserving immediate acknowledgement for legitimately queued requests. Cover the failure ordering in the existing AgentFeedbackService agent-host submission suite.
