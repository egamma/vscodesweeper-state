# Issue #348973 — Enable native Automation creation from Agent Host sessions in the VS Code Chat view

[https://github.com/microsoft/vscode/issues/348973](https://github.com/microsoft/vscode/issues/348973)

## Summary

The requested editor Chat capability is still missing: Automation tools are currently contributed by the Agents Window. Keep this as a feature request; the documented window difference explains current behavior but does not decide whether support should expand.

## Change summary

Expose listAutomations and configureAutomation to Agent Host conversations in the editor Chat view using the existing approval flow.

## Best solution

Allow editor Chat Agent Host sessions to discover and configure native Automations through shared Workbench contracts, preserving provider availability checks and existing approval behavior without introducing a Workbench dependency on the Sessions layer.

## Evidence

- **Existing-capability check:** src/vs/workbench/contrib/chat/browser/tools/clientToolSetsContribution.ts registers the vscodeAutomations tool set, including listAutomations and configureAutomation, only inside the workspaceService.isSessionsWindow branch. It does not expose that tool set in editor windows.
- **Implementation boundary:** AutomationToolsContribution is implemented in src/vs/sessions/contrib/automations/browser/automationTools.ts and registered by automations.contribution.ts. src/vs/sessions/sessions.common.main.ts imports that contribution; the corresponding Workbench entry point does not. Shared Automation interfaces alone do not provide the requested editor-window tools.
- **Discussion and duplicate assessment:** https://github.com/microsoft/vscode/issues/343250#issuecomment-6323916530 explicitly identifies Agents-Window-only Automation tools as an expected difference. That issue concerns customization and enablement inconsistencies, not a commitment to expose Automation creation in editor Chat, so it is related rather than a verified duplicate.
- **Existing workaround is partial:** https://github.com/microsoft/vscode/issues/348973 reports successful creation in the Agents Window on Windows with VS Code 1.146.0. Switching windows does not satisfy the central request to schedule from the existing editor Chat conversation.
