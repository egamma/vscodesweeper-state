# Issue #253847 — Side loaded extensions should not sync metadata from MP

[https://github.com/microsoft/vscode/issues/253847](https://github.com/microsoft/vscode/issues/253847)

## Summary

Current main still associates side-loaded VSIX extensions with Marketplace entries and presents their updates generically. This security-hardening request remains necessary and is already accepted in the Backlog.

## Change summary

Keep side-loaded extension metadata distinct from Marketplace metadata and clearly identify updates that replace a side-loaded extension with the Marketplace version.

## Best solution

Preserve the side-loaded extension's local identity and presentation metadata until the user explicitly chooses to replace it with the Marketplace package, and label that transition as “Update to Marketplace Version.”

## Evidence

- **current gallery association:** On current main, src/vs/workbench/contrib/extensions/browser/extensionsWorkbenchService.ts maps every installed extension other than `source === 'resource'` to a Marketplace entry by UUID or extension ID in `mapInstalledExtensionWithGalleryExtension`; this includes extensions whose local source is `vsix`.
- **metadata synchronization:** In `syncInstalledExtensionsWithGallery` in src/vs/workbench/contrib/extensions/browser/extensionsWorkbenchService.ts, a matched local extension without a UUID receives the Marketplace UUID, publisher display name, and publisher ID, and its `gallery` property is populated.
- **Marketplace metadata presentation:** The `Extension` model in src/vs/workbench/contrib/extensions/browser/extensionsWorkbenchService.ts prefers gallery values for name, display name, publisher, description, icon, repository, ratings, and related fields whenever `gallery` is populated.
- **ambiguous update action:** UpdateAction in src/vs/workbench/contrib/extensions/browser/extensionsActions.ts still labels the action as `Update` or `Update to v{0}` even when `extension.local.source === 'vsix'`; that source distinction currently only clears the pinned state before installation.
