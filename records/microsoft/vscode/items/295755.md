## Change summary

Allow organizations or individual developers to source Copilot agent definitions from a non-default branch of the org agents repository, enabling progressive rollout and testing.

## Best solution

Add a setting (e.g. `github.copilot.chat.organizationAgents.branch`) that lets users or org policy override which branch agent definitions are synced from. Implementation likely lives in the Copilot extension's org-agent sync logic under `extensions/copilot/`. This needs a product decision on whether the override is per-machine, org-policy-level, or both.
