# Issue #346203 — Git: a worktree deleted from Source Control stays open until a git command fails with "spawn git.exe ENOENT"

## Summary

The deleted worktree still remains registered in the Git model on current main. Keep this actionable report open and route it to the built-in Git area.

## Change summary

Deleting a worktree should immediately remove its repository from command pickers and the Git API and emit the repository-close event.

## Best solution

Complete the deleted worktree's repository lifecycle so model registration, API consumers, and Source Control agree immediately after successful deletion, without requiring a subsequent failing Git command.
