# Issue #165816 — _sendLineData can freeze the renderer for seconds for very long lines

[https://github.com/microsoft/vscode/issues/165816](https://github.com/microsoft/vscode/issues/165816)

## Summary

Still reproduces on main: `_sendLineData` in `lineDataEventAddon.ts` concatenates all wrapped lines without any length threshold, so extremely long wrapped lines can freeze the renderer. The related issue #166031 only lazily initialized the addon — the core freeze path is unchanged.

## Change summary

Very long wrapped terminal lines cause `_sendLineData` to freeze the renderer for seconds while assembling the full line string via `translateToString`.

## Best solution

Add a line-length threshold (e.g. 1024 characters) in `_sendLineData` that either truncates or skips emitting the line data event for extremely long lines. The open question from the author — whether tasks can safely ignore lines over that threshold — needs a product decision before implementing.
