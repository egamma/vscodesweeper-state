# Issue #260391 — Fonts are fuzzy after update to v103 on linux 

[https://github.com/microsoft/vscode/issues/260391](https://github.com/microsoft/vscode/issues/260391)

## Summary

Genuine upstream regression — Chromium's switch from FreeType to Fontations broke horizontal hinting on Linux, especially for bitmap-style and many popular monospace fonts. The root fix lives in googlefonts/fontations; VS Code's earlier workaround (disabling FontationsLinuxSystemFonts) was dropped when Chromium removed the flag. Still reproducible on current main (Electron 42 / Chromium 146+). Milestone is On Deck; keeping open.

## Change summary

Font rendering on Linux became blurry/fuzzy after Chromium switched from FreeType to Fontations, which lacks horizontal hinting support.

## Best solution

Track the upstream fix in https://github.com/googlefonts/fontations/issues/1215 and https://github.com/googlefonts/fontations/pull/1496. Once horizontal hinting lands in Fontations and propagates through Chromium into Electron, this resolves automatically. In the meantime, keep this open as the canonical VS Code tracking issue for the regression.
