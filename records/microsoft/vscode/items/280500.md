# Issue #280500 — Unable to drag an editor into a split editor

[https://github.com/microsoft/vscode/issues/280500](https://github.com/microsoft/vscode/issues/280500)

## Summary

Keep this accepted Backlog request open: Shift-drop currently inserts a file path, and the inspected comparison commands do not provide the requested drop-to-populate behavior. The earlier identical report was closed for insufficient votes, not fixed, and cannot serve as a duplicate target.

## Change summary

Allow a file dragged from Windows Explorer to populate one side of an untitled comparison with its contents instead of inserting its path.

## Best solution

Define a diff-editor-specific way to populate the selected comparison side from a dropped file while preserving ordinary Shift-drop path insertion elsewhere. Existing file-comparison commands provide a workaround, but do not replace this interaction.
