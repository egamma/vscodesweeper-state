# Issue #327606 — Agents - multi-chat tab container does not have a scrollbar

[https://github.com/microsoft/vscode/issues/327606](https://github.com/microsoft/vscode/issues/327606)

## Summary

Still present on main: the chat tab strip's ScrollableElement is configured with both horizontal and vertical scrollbar visibility set to `Hidden`, so when tabs overflow there's no scroll affordance shown, matching the screenshot in the report.

## Change summary

The multi-chat tab container in the Agents window has no visible scrollbar when the tabs overflow horizontally.

## Best solution

In src/vs/sessions/browser/parts/chatCompositeBar.ts, change the horizontal ScrollbarVisibility passed to the ScrollableElement constructor (currently `Hidden`) to `Auto` (or another visible-on-overflow mode) so users get a scroll affordance when there are more tabs than fit.
