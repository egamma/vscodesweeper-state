# Issue #344698 — chat-plugin install/add-marketplace links always go through a Copilot session and drop the marketplace ref

[https://github.com/microsoft/vscode/issues/344698](https://github.com/microsoft/vscode/issues/344698)

## Summary

Keep open: the reported branch-selection failure remains unverified, but the report supplies sufficient steps to retest it. Current source confirms Copilot-only link routing, while the merged change deliberately introduced that behavior; resolving the cross-agent expectation needs an explicit product decision.

## Change summary

Plugin protocol links reportedly install from the default branch instead of the requested marketplace ref and cannot perform a VS Code-managed installation for Claude or Codex users.

## Best solution

Ensure protocol-link installations honor the requested marketplace revision, and establish the supported installation destination when the active agent is not Copilot. Coordinate that contract with the SDK migration work without treating migration of existing installations as a resolution of these link-specific failures.
