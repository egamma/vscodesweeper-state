# Issue #329080 — Agent Plugins: adopt com.github.copilot as the GitHub Copilot client extension namespace

[https://github.com/microsoft/vscode/issues/329080](https://github.com/microsoft/vscode/issues/329080)

## Summary

Team-authored architecture task defining the shared `com.github.copilot` namespace/plumbing for Agent Plugins; related work has already landed but only as a private, per-file constant that doesn't satisfy the 'one shared constant/API' outcome and doesn't reference this issue, so it stays open per the team-authored hard keep-open rule.

## Change summary

Formalize `com.github.copilot` as the single shared reverse-domain namespace/API for GitHub Copilot Agent Plugin client extensions (manifest data + top-level directory), distinct from any VS Code- or CLI-specific variant.

## Best solution

Extract the namespace into a shared, exported constant/API (currently `AGENT_PLUGIN_COPILOT_EXTENSION_NAMESPACE` is a private const scoped to src/vs/platform/agentPlugins/common/pluginParsers.ts) and add a generic accessor for the optional `com.github.copilot/` directory and full `extensions['com.github.copilot']` payload (today `getPluginManifestComponent` only reads a fixed set of hardcoded components), plus tests locking the spelling and ignoring unimplemented namespaces.
