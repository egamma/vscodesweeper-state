# Issue #274137 — UI to signal selected terminal

[https://github.com/microsoft/vscode/issues/274137](https://github.com/microsoft/vscode/issues/274137)

## Summary

Keep open for terminal-tabs UX review: current source still places the active-terminal marker alongside competing list focus and selection treatments. The team-authored report raises an unresolved design distinction, and no qualifying fix or canonical duplicate was established.

## Change summary

Keep the currently viewed terminal identifiable when terminal-tab focus outlines and selection highlights appear.

## Best solution

Make the active terminal and list interaction states legible without weakening keyboard-focus visibility. First settle whether the active marker must remain independently visible on a selected row or whether the selection highlight intentionally replaces it.
