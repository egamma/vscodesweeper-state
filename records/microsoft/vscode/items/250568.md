# Issue #250568 — [Violation] Permissions policy violation: microphone is not allowed in this document.

[https://github.com/microsoft/vscode/issues/250568](https://github.com/microsoft/vscode/issues/250568)

## Summary

Verified duplicate: this request for microphone access in extension webviews is fully absorbed by the open canonical issue #323602, which proposes a concrete opt-in, consent-gated API for camera/microphone access and has already been promoted to the backlog with 20+ upvotes.

## Change summary

Extensions cannot use navigator.mediaDevices.getUserMedia in webviews because the iframe lacks a microphone/camera allow attribute and the Electron permission handler denies media for vscode-webview:// origins.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/323602 — it proposes a proper proposed API (`webviewMediaDevices`) with per-extension consent, iframe allow-attribute injection, and revocable grants, and already has a working PoC and community backing. Implementing that API delivers exactly what this issue requests.
