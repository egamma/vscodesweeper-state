# Issue #283310 — Improve Inline Completion Tab Handling

[https://github.com/microsoft/vscode/issues/283310](https://github.com/microsoft/vscode/issues/283310)

## Summary

The Tab-specific timing problem remains on current main: an indentation Tab immediately retriggers automatic inline completions, with no command-specific cooldown. The existing global minimum-delay setting does not provide the requested default behavior.

## Change summary

Delay automatic inline completions for about one second after Tab performs indentation, preventing suggestions from immediately competing with continued indentation.

## Best solution

Keep normal Tab indentation responsive, but suppress presentation of newly requested automatic inline completions for one second afterward. Accepting an already-visible completion with Tab and other completion triggers should retain their existing timing.
