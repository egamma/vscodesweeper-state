# Issue #283310 — Improve Inline Completion Tab Handling

[https://github.com/microsoft/vscode/issues/283310](https://github.com/microsoft/vscode/issues/283310)

## Summary

Keep open: current source allows automatic inline completions to reappear shortly after Tab indentation, without the requested one-second pause. No verified fix or older same-symptom canonical was found; this team-authored issue also cannot receive a judgment close.

## Change summary

Delay automatic inline completions for one second after the user presses Tab to indent.

## Best solution

Make repeated Tab indentation predictable by withholding automatic inline completions for one second after an indenting Tab, within the editor inline-completions area. Preserve ordinary typing responsiveness and intentional suggestion acceptance rather than imposing a global delay.
