# Issue #325438 — Copilot global memory not syncing across devices for same user

[https://github.com/microsoft/vscode/issues/325438](https://github.com/microsoft/vscode/issues/325438)

## Summary

Keep open as a request for cross-device user-memory continuity: the current file-based memory tool uses local extension storage, rather than a broken account-sync mechanism. A maintainer acknowledged ongoing memory work, and the older related requests do not establish the same reporter-observable symptom required for a duplicate close on this re-reviewed item.

## Change summary

Make user-scoped Copilot memory files available across devices signed into the same account.

## Best solution

Define whether file-based user memories participate in account-level synchronization or remain a clearly distinguished local-memory capability alongside cloud Copilot Memory. Preserve the reporter's two-device file-and-token scenario as the acceptance check for any synchronization support.
