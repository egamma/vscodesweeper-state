# Issue #311427 — Agents app picker menus are inconsistent with vscode

[https://github.com/microsoft/vscode/issues/311427](https://github.com/microsoft/vscode/issues/311427)

## Summary

Team-authored issue reporting an accessibility/UX inconsistency in the agents window new-chat page: the agent picker, model picker, and related controls are each separate tab stops instead of being grouped in a single-tabstop toolbar with arrow-key navigation (the standard VS Code pattern). Keybindings for the pickers also don't apply on the initial chat page. Keeping open per team-member policy.

## Change summary

The new-chat page in the agents window renders picker controls as individual tab stops instead of grouping them in a single toolbar, and agent/model picker keybindings don't work until a chat session is active.

## Best solution

Consolidate the agent picker, model picker, and related action items on the new-chat page into a proper single-tabstop toolbar (matching the VS Code chat widget pattern in `src/vs/workbench/contrib/chat`), and ensure the keybindings for agent/model picker commands are active on the new-chat page — likely needs the right `when` clause adjustments in `src/vs/sessions/contrib/chat/browser/chat.contribution.ts` and toolbar grouping changes in `src/vs/sessions/contrib/chat/browser/newChatInput.ts`.
