Current main fixes the multiple-tab-stop portion by using shared workbench toolbars, but the standard Agent and Model picker keybindings still do not target the focused new-session composer. This team-authored On Deck issue must remain open because the only PR explicitly referencing it was closed without merging and no qualifying fixing commit references the issue.
