# Issue #306277 — Deleting a session doesn't seem to do anything

[https://github.com/microsoft/vscode/issues/306277](https://github.com/microsoft/vscode/issues/306277)

## Summary

Confirmed bug from a team member, still reproducible as of April 15 2026 on local chat sessions. No fix commit references this issue. The event chain from provider → management service → list widget looks wired up correctly in current source, but the UI fails to refresh immediately after deletion — likely a subtle timing or visibility-gate issue that needs runtime investigation.

## Change summary

Deleting a local chat session in the Agents window does not immediately update the sessions list; the deleted session only disappears when the user navigates away and back.

## Best solution

Investigate the refresh path in `sessionsList.ts` (line 1857–1860): the `onDidChangeSessions` handler guards on `this.visible`, and the provider's `deleteSession` fires the event only after several async `removeHistoryEntry` calls complete. A timing issue or a stale `visible` flag likely causes the list to skip the refresh. The fix should ensure the list re-renders synchronously after a delete, or queues a deferred refresh when hidden.
