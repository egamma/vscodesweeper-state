# Issue #336152 — `executeTask()` activates *all* extensions with a task provider when the task came from `fetchTasks()`

[https://github.com/microsoft/vscode/issues/336152](https://github.com/microsoft/vscode/issues/336152)

## Summary

The fetched-task execution path still drops the task type and activates unrelated task providers on current main. Keep this open while the explicitly linked fixing PR is reviewed and landed.

## Change summary

Executing a provider task returned by fetchTasks should activate only providers for its task type, matching execution of an equivalent directly constructed task.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/336159, ensuring the task type reaches both main-thread task lookups and unrelated providers remain inactive. Treat failed-lookup error propagation as the separate work tracked by https://github.com/microsoft/vscode/issues/338344.
