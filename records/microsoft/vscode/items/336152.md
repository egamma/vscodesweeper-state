# Issue #336152 — `executeTask()` activates *all* extensions with a task provider when the task came from `fetchTasks()`

[https://github.com/microsoft/vscode/issues/336152](https://github.com/microsoft/vscode/issues/336152)

## Summary

The fetched-task execution path still drops the task type and activates unrelated task providers on current main. Keep this open while the existing fixing PR is reviewed and landed.

## Change summary

Executing a provider-contributed task returned by fetchTasks() should activate only providers matching its task type.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/336159 so fetched-task handles preserve the task type through both main-thread lookups, without changing task re-resolution semantics.
