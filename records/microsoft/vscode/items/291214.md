# Issue #291214 — Chat Sessions: Clicking on the read/unread indicator should toggle state

[https://github.com/microsoft/vscode/issues/291214](https://github.com/microsoft/vscode/issues/291214)

## Summary

The interaction gap remains on current main: clicking the status indicator still opens the session and marks it read rather than independently toggling its state. This team-authored Backlog request should remain open.

## Change summary

Make the session read/unread indicator toggle state without opening the session.

## Best solution

Make the status indicator an accessible button that calls `markRead` or `markUnread`, while stopping mouse, keyboard, and touch activation from reaching the session row's open handler.
