# Issue #343466 — Inconsistent block padding in the Status (Bottom) Bar

[https://github.com/microsoft/vscode/issues/343466](https://github.com/microsoft/vscode/issues/343466)

## Summary

Keep open to investigate the independently confirmed Modern UI spacing regression. Current source deliberately centers items within the status bar itself, but that does not establish balanced spacing between the editor edge, status items, and window bottom.

## Change summary

Restore visually balanced vertical spacing around status bar content in the Modern UI floating-panel layout.

## Best solution

Reconcile status bar alignment with the adjacent floating-panel gutter, preserving the intentional centering within a distinctly colored status bar. Verify the complete editor-to-window-bottom composition rather than restoring the previous padding rules without checking their effects.

- **Behavior:**

The complete bottom-of-window composition should feel balanced without moving items off-center within a distinctly colored status bar. Acceptance should cover default and compact density, the adjacent editor gutter, and both neutral and distinct status bar backgrounds. Classic UI must remain unchanged.
- **Trace:**

  > The current floating-panel stylesheet supplies equal vertical status bar padding, and the Modern UI status bar stylesheet no longer overrides it. The independently confirmed report associates the new imbalance with those removed overrides, but the complete layout mechanism has not been established from source. https://github.com/microsoft/vscode/issues/339785 and merged https://github.com/microsoft/vscode/pull/342182 document why equal padding was introduced: preserve their centered colored-background behavior rather than treating restoration of the old rules as an established solution. Investigate https://github.com/microsoft/vscode/issues/338618 for overlap before implementation; its full scope was unavailable during review.

## Evidence

This supplements the Windows report despite its initial extensions-disabled answer.
- **Current source:** src/vs/workbench/browser/media/floatingPanels.css gives the floating status bar equal top and bottom padding using --vscode-spacing-size20, while defining a separate density-dependent --modern-ui-floating-card-statusbar-margin. src/vs/workbench/contrib/modernUI/browser/media/statusBar.css contains no corresponding vertical-padding overrides.

No tests or application execution were performed during this read-only review.
