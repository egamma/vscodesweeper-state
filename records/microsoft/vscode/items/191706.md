# Issue #191706 — Dismissing a message will shrink the quick question UI

[https://github.com/microsoft/vscode/issues/191706](https://github.com/microsoft/vscode/issues/191706)

## Summary

Keep open: current Quick Chat still recalculates its height from the last two transcript items, but the original per-message dismiss interaction was not confirmed in the evolved UI. The supplied steps suffice to retest; no concrete fixing commit or verified duplicate was found.

## Change summary

Dismissing a message should not collapse scroll-expanded Quick Chat history when enough remaining content fills the existing viewport.

## Best solution

Preserve the expanded viewport when removing a history entry leaves sufficient content, without changing intentional expansion on scroll or height reset on a new question. First establish the current equivalent of the reported dismiss interaction.
