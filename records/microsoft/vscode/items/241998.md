# Issue #241998 — Warning message on references is awkward

[https://github.com/microsoft/vscode/issues/241998](https://github.com/microsoft/vscode/issues/241998)

## Summary

The awkward warning path remains on current main: failed text-document reads expose the raw error message, including a potentially long file URI. This team-authored bug has no referenced fixing commit or verified duplicate, so it should remain open.

## Change summary

Make omitted-reference warnings concise and consistent instead of displaying a raw read error containing the full file URI.

## Best solution

Present a concise, localized omission reason without exposing the full URI, while retaining enough detail to distinguish unsupported or unreadable files from other attachment failures.
