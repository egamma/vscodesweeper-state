# Issue #57070 — Add a command that redos the last command that was executed

[https://github.com/microsoft/vscode/issues/57070](https://github.com/microsoft/vscode/issues/57070)

## Summary

An identical proposal was reconsidered and closed as out of scope in May 2026 after maintainers identified unresolved safety and context semantics for arbitrary command replay. This supports closing on scope rather than age, despite the request's substantial community interest.

## Change summary

Add a keybindable command that repeats the most recently executed VS Code command, ideally preserving its arguments.

## Best solution

Keep explicit command keybindings and feature-specific history commands rather than introducing blind global replay; safe repetition would require command-specific opt-in and context semantics that the project has declined to pursue.

  > Thanks for the request and the discussion. The same built-in repeat-last-command proposal was reconsidered in https://github.com/microsoft/vscode/issues/273349 and closed as out of scope. Arbitrary replay cannot reliably determine whether a command should use its previous context or the current one, preserve arguments, or be repeated at all—especially for destructive commands.
