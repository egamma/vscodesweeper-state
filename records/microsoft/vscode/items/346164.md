# Issue #346164 — Feature: Select individual agent customizations per chat session

[https://github.com/microsoft/vscode/issues/346164](https://github.com/microsoft/vscode/issues/346164)

## Summary

Keep open as a feature request: existing customization controls provide partial coverage, but do not establish independent, per-item selections across all requested customization types for each conversation.

## Change summary

Allow each chat session to independently select individual skills, agents, instructions, hooks, prompts, and tools without changing shared defaults.

## Best solution

Provide a consistent session-scoped customization selection contract across supported harnesses, preserving defaults and excluding deselected items from future context and capability discovery where supported. Reuse existing enablement infrastructure while distinguishing individual selections from whole-plugin toggles.
