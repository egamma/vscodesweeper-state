# Issue #328811 — Start dictation in editor or terminal causes Chat to show it's "dictation" bubble

[https://github.com/microsoft/vscode/issues/328811](https://github.com/microsoft/vscode/issues/328811)

## Summary

The described bug — Chat's mic glow lighting up when dictation is started in the editor or terminal — no longer reproduces against current main, but this is a team-authored issue (TylerLeonhardt, MEMBER) and no merged commit or PR text explicitly references #328811, so per policy it must stay open rather than be closed on plausible coverage alone.

## Change summary

Starting dictation in the editor or terminal incorrectly lights up Chat's mic bubble, because the mic-glow logic reacted to the shared speech service's state without knowing which surface (chat/editor/terminal) initiated it.

## Best solution

Current main (commit a6162282) already contains `isDictationActiveOnSurface(service, surface)` in src/vs/workbench/contrib/chat/browser/speechToText/chatSpeechToTextService.ts, gating the chat glow to only light when `currentSurface === 'chat' && isBusy` — this appears to fix the exact defect. A maintainer should confirm this was the intended fix for #328811 and close it with an explicit citation, since no merged PR currently references this issue number.
