# Issue #282933 — Agent confused by SSH key login prompt on command line

[https://github.com/microsoft/vscode/issues/282933](https://github.com/microsoft/vscode/issues/282933)

## Summary

Keep open: current terminal tooling offers a human-input flow for detected secrets, but that does not establish coverage for an SSH passphrase prompt raised during shell startup, before the agent sends its first command. The related regex-consolidation issue does not own this entire startup-and-resume behavior.

## Change summary

Recognize SSH passphrase prompts during terminal initialization, ask the user to authenticate directly, and resume the agent's pending command afterward.

## Best solution

Ensure the chat terminal startup path distinguishes a shell awaiting authentication from one ready for commands, using the existing direct-terminal sensitive-input experience where appropriate. Preserve the pending command until authentication completes rather than submitting it as passphrase input.

Cancelling authentication must not run the pending command, and ordinary terminal startup must remain unchanged.
