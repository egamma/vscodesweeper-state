# Issue #288407 — GitHub Copilot

[https://github.com/microsoft/vscode/issues/288407](https://github.com/microsoft/vscode/issues/288407)

## Summary

The standalone GitHub Copilot extension is intentionally kept disabled while extension unification is active because GitHub Copilot Chat provides its functionality. The ineffective workspace-enable attempt matches that explicit unification path rather than a failure to activate Copilot functionality.

## Change summary

Allow the standalone GitHub Copilot extension to be enabled for a workspace while Copilot extension unification is active.

## Best solution

Use the unified GitHub Copilot Chat extension for Copilot functionality. Users who specifically need the former split-extension behavior can temporarily disable `chat.extensionUnification.enabled`, while the legacy GitHub Copilot extension is being retired.

## Vision fit

- **Fit:** aligned
- **Reason:** Consolidating overlapping Copilot extensions supports a simpler, more uniform product surface without removing their combined functionality.
- **Evidence:** Values and guardrails: “Out of the box, VS Code is a text editor: lightweight and fast” and “Simple, uniform UI and UI interactions.”
