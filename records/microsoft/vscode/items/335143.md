# Issue #335143 — Claude models missing from Agents window model picker in 1.136 (regression from 1.135)

[https://github.com/microsoft/vscode/issues/335143](https://github.com/microsoft/vscode/issues/335143)

## Summary

Verified duplicate: the Anthropic provider disappearing from the Agents window/model access is the same `isClaudeAccountSetUp` gate defect already open (and older/better-diagnosed) at #333738 — the checkout confirms the gate has no branch for a claude.ai subscription login, and a comment there reproduces the exact symptom on 1.136/1.137.

## Change summary

Claude models and the Anthropic provider entry vanish from the Agents window / 'Manage Language Model Access' in 1.136, reappearing on downgrade to 1.135, for a user authenticated via `claude login` (Anthropic subscription OAuth, keychain-stored) rather than an API key.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/333738: fix `isClaudeAccountSetUp` in src/vs/platform/agentHost/node/claude/claudeTransportMode.ts to also treat a `claude.ai` subscription login (`apiProvider: 'firstParty'`, no `tokenSource`/`apiKeySource`, i.e. `loggedIn`/`authMethod` fields the current gate never inspects) as set up. That single fix restores both the native model catalog and the 'Manage Language Model Access' Anthropic entry.
