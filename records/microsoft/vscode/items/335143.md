# Issue #335143 — Claude models missing from Agents window model picker in 1.136 (regression from 1.135)

[https://github.com/microsoft/vscode/issues/335143](https://github.com/microsoft/vscode/issues/335143)

## Summary

The requested Claude subscription/OAuth authentication path is intentionally unsupported in the Agents window, as clarified by a maintainer on the directly linked report. Propose closing as designed, not as an extension problem or a duplicate of the separate SDK-download regression.

## Change summary

Restore Claude models in the Agents window using an existing Anthropic subscription/OAuth login, as reportedly available in 1.135.

## Best solution

Retain the supported native API-key/provider and Copilot authentication paths without enabling claude.ai subscription login. Explain the authentication boundary using the maintainer's decision on the linked report rather than recommending its token workaround.

- **Proposed comment:**

  > Thanks for the report. As clarified in https://github.com/microsoft/vscode/issues/333738#issuecomment-5737308066, the Agents window intentionally does not use a `claude.ai` subscription/OAuth login, even when that login works in the Claude Code extension. The supported authentication paths include an Anthropic API key, configured external providers, or GitHub Copilot; restoring subscription login is therefore not planned under the current integration policy.
