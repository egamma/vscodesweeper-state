# Issue #343991 — cmd+F should focus search bar in environments editor

[https://github.com/microsoft/vscode/issues/343991](https://github.com/microsoft/vscode/issues/343991)

## Summary

Keep open: the Remote Environments editor already has a searchable input, but its contributions do not bind Cmd+F to return focus there. This is a bounded keyboard-consistency improvement requested by a team member, with no verified fix or duplicate.

## Change summary

Make Cmd+F focus the existing search field in the Remote Environments editor.

## Best solution

The standard Find shortcut should focus the Remote Environments search field while that editor has focus, without changing Find behavior elsewhere or altering the current filter.
