# Issue #149270 — Allow parameter hints and completion documentation to appear in a docked panel instead of floating over the code

[https://github.com/microsoft/vscode/issues/149270](https://github.com/microsoft/vscode/issues/149270)

## Summary

This remains a valid Backlog feature request with 135 community upvotes. Current main still renders parameter hints and completion documentation as editor-attached floating widgets, while available extensions do not cover the complete live experience requested.

## Change summary

Allow live parameter hints and selected completion-item documentation to appear in a dockable view instead of obscuring code.

## Best solution

Add an optional dockable workbench view fed by the editor's live signature-help and selected-completion state, while preserving the existing floating widgets as the default. The implementation would span the parameter-hints and suggest contributions plus workbench view integration.
