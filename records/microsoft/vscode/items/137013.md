## Summary

Keep this accepted, well-supported request open: existing font controls do not provide the requested Windows text-contrast enhancement, and the discussion explicitly reports that upgrading to Electron 30 did not deliver it. A current Windows comparison is needed before declaring the request completed or identifying the remaining integration gap.

## Change summary

Provide Windows font-rendering contrast improvements comparable to Edge's edge-enhance-text-contrast behavior in desktop VS Code.

Establish whether desktop VS Code now delivers the requested ClearType-sensitive contrast improvement under matched browser and desktop conditions.
