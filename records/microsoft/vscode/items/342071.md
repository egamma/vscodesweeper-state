# Issue #342071 — Terminal active tab highlight disappears when clicking within the tabs area

[https://github.com/microsoft/vscode/issues/342071](https://github.com/microsoft/vscode/issues/342071)

## Summary

The source explains the disappearing background: clicking empty space clears list selection without changing the active terminal. Keep this open for terminal UX review; the existing active border remains, but does not provide the persistent background distinction requested.

## Change summary

Keep the active terminal readily identifiable after clicking empty space in the terminal tabs area.

## Best solution

Give the active terminal a clear, persistent visual identity while keeping active-terminal state, keyboard focus, and multi-selection distinguishable. The terminal owner should settle whether empty-space clicks retain selection or leave an independent active indication.
