## Summary

Confirmed upstream Chromium issue — native context menus on Windows/Linux lack sufficient focus-indicator contrast. A Chromium bug has been filed and the team is waiting on the upstream fix. Team-authored and correctly tracked; keep open.

## Change summary

Keyboard focus indicator on integrated browser context menus has insufficient colour contrast (<3:1) on Windows/Linux due to Chromium's native menu rendering.

## Best solution

Wait for the upstream Chromium fix (https://issues.chromium.org/issues/525612746) to land and propagate through Electron. No VS Code core code change can address this since the context menus are native Chromium UI. If the Chromium fix stalls, the team could explore an Electron-level workaround to add a focus border, as Edge does.
