[https://github.com/microsoft/vscode/issues/197865](https://github.com/microsoft/vscode/issues/197865)

## Summary

The central request is already tracked by an older open issue: pasting a known workspace-relative path should show the file without waiting for workspace-wide search. Consolidate there, preserving this report's request to display the exact match while other results load without disrupting navigation.

## Change summary

Show exact workspace-relative file matches immediately in Quick Open while slower search results continue loading.

Resolve the exact-path latency tracked by https://github.com/microsoft/vscode/issues/131084, carrying over this report's incremental-display and stable-navigation requirements. Current main checks relative paths but still waits for the full file search before publishing those results.
