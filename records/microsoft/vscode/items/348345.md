## Plan brief

- **Likely files:** `src/vs/platform/agentHost/node/copilot/copilotSessionLauncher.ts`, `src/vs/platform/agentHost/node/copilot/copilotSessionWrapper.ts`, `src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts`, `src/vs/platform/agentHost/node/copilot/byokLmProxyService.ts`, `src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostSessionHandler.ts`
- **Validation:** Using an affected reasoning-capable model, compare Local and Copilot Harness on a long reasoning turn with Remote connection off and on. Verify readable reasoning grows before block completion, Stop remains available during generation, and completed reasoning remains inspectable. Correlate SDK reasoning-delta arrival with host actions and UI updates to locate any delay.
- **Behavior:**

  > Copilot Harness should display provider-exposed reasoning incrementally while generation is in progress, allowing users to notice repetition and stop the turn before timeout. This must work with Remote connection enabled and disabled. Finalized reasoning remains available through the existing expandable presentation. Acceptance requires observing growing reasoning before the block completes, not merely a generic activity indicator.
- **Trace:**

  > CopilotSessionLauncher already enables streaming, and CopilotSessionWrapper exposes assistant.reasoning_delta. CopilotAgentSession forwards those events through _emitReasoningDelta into reasoning-part creation and append actions; AgentHostSessionHandler._setupReasoningPart observes appended content and forwards it to the UI sink. The BYOK proxy also has an incremental delta subscription, so the earlier buffering explanation in https://github.com/microsoft/vscode/issues/340983 cannot be assumed to apply unchanged. The unresolved boundary is whether the reporter's model/runtime supplies live reasoning, whether transport delays it, or whether presentation hides arriving content. Preserve completed-reasoning fallback, parent/subagent scoping, existing visibility controls, and Stop semantics; do not assume unavailable provider reasoning can be reconstructed.
