# Issue #155242 — The background of main interface became grey.

[https://github.com/microsoft/vscode/issues/155242](https://github.com/microsoft/vscode/issues/155242)

## Summary

Keep open as the canonical notebook-output performance issue. Multiple users reproduced renderer freezes and greyed-out outputs with large notebooks, and current main still lacks a rendered-output byte-size limit.

## Change summary

Large or numerous notebook outputs can overload the renderer, grey out all outputs, and leave the VS Code window unresponsive.

## Best solution

Bound or virtualize heavyweight notebook output rendering in the notebook webview while preserving kernel and notebook state, so recovering does not require reloading the window.
