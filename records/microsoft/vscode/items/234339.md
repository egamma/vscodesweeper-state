# Issue #234339 — Status bar tooltip - add support for specifying a list of commands

[https://github.com/microsoft/vscode/issues/234339](https://github.com/microsoft/vscode/issues/234339)

## Summary

Team-authored feature request (MEMBER). The core workbench side already supports rendering commands in status bar hover tooltips (statusbarItem.ts lines 124–132), and a proposed API exists (vscode.proposed.statusBarItemTooltip.d.ts referencing this issue), but the proposed API's `tooltip2` does not yet expose a commands/actions shape to extensions. The remaining work is wiring the command list through the extension API. Keeping open per hard keep-open rule.

## Change summary

Allow extensions to specify a list of commands on a status bar item tooltip, rendered as actions in the hover widget.

## Best solution

Extend the proposed `tooltip2` API in `vscode.proposed.statusBarItemTooltip.d.ts` to accept a structured shape with `commands: Command[]` (similar to bpasero's sketch), and wire it through the extension host status bar item proxy so it reaches the existing `isTooltipWithCommands` code path in `statusbarItem.ts`. The core rendering is already in place; the gap is purely in the extension API surface.
