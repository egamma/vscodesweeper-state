# Issue #316591 — Feature request: Work on current branch instead of creating new agent branches

[https://github.com/microsoft/vscode/issues/316591](https://github.com/microsoft/vscode/issues/316591)

## Summary

The requested opt-out now exists: Agents sessions can work directly in the existing checkout, and sessions.useWorktree controls the initial default. This covers the frontend feedback-loop requirement without merging an agent branch.

## Change summary

Allow agent sessions to edit the current checkout and branch instead of automatically creating an isolated branch and worktree.

## Best solution

Use folder isolation by clearing New Worktree before starting the session. Set sessions.useWorktree to false for workspaces without a remembered preference; existing workspaces retain their last started session's isolation choice.
