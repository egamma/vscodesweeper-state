# Issue #334807 — Backspace over a flag emoji deletes only one Regional Indicator, leaving a dangling half-flag

[https://github.com/microsoft/vscode/issues/334807](https://github.com/microsoft/vscode/issues/334807)

## Summary

Confirmed via source: getOffsetBeforeLastEmojiComponent in strings.ts treats a Regional Indicator as a base emoji but never checks for its pairing partner, so backspace only deletes one of the two code points in a flag emoji. A fix is already proposed in open PR #334808, so this should stay open pending review/merge rather than being closed now.

## Change summary

Backspace over a flag emoji (two Regional Indicator code points) deletes only one code point instead of the whole flag, leaving a dangling half-flag.

## Best solution

Land the fix already proposed in https://github.com/microsoft/vscode/pull/334808, which should extend getOffsetBeforeLastEmojiComponent in src/vs/base/common/strings.ts to detect and consume a preceding paired Regional Indicator (per Unicode UAX #29 GB12/GB13) in addition to the existing ZWJ-skip logic.
