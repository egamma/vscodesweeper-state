# Issue #334807 — Backspace over a flag emoji deletes only one Regional Indicator, leaving a dangling half-flag

[https://github.com/microsoft/vscode/issues/334807](https://github.com/microsoft/vscode/issues/334807)

## Summary

Confirmed via source: `isEmojiImprecise` in strings.ts includes the whole Regional Indicator range (U+1F1E6–U+1F1FF), so `getOffsetBeforeLastEmojiComponent` treats a single Regional Indicator as a complete 'base emoji' and never checks whether it's paired with the preceding one to form a flag — Backspace deletes only one of the two code points. An open PR already fixes this with a cited regression test, so the issue should stay open pending review/merge rather than be closed now.

## Change summary

Backspace over a flag emoji (two Regional Indicator code points) removes only one code point instead of the whole flag, leaving a dangling lone Regional Indicator.
