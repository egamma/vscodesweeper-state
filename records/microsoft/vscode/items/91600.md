# Issue #91600 — [folding] pressing Enter in collapsed region should add new line outside region

[https://github.com/microsoft/vscode/issues/91600](https://github.com/microsoft/vscode/issues/91600)

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/72422 covers how cursor and selection operations should treat a collapsed range, and its discussion reports this exact End-then-Enter symptom.

## Change summary

Treat the visual end of a collapsed region as a position after the folded range so Enter inserts a line below it without expanding the region.
