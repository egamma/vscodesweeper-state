# Issue #235816 — Highlighted line in terminal moving with resizing the window

[https://github.com/microsoft/vscode/issues/235816](https://github.com/microsoft/vscode/issues/235816)

## Summary

Confirmed, reproducible terminal selection bug during vertical resize — selection drifts because xterm.js reflow doesn't adjust or clear the selection anchors. No fix commit found on main; keeping open.

## Change summary

Terminal text selection shifts to a different line when the terminal panel is vertically resized.

## Best solution

Fix the selection anchor adjustment during reflow in xterm.js (or clear selection on resize in VS Code's terminal layer). This likely requires coordination with the xterm.js reflow logic — either the selection model needs to track reflowed row positions, or VS Code should clear the selection on resize as a pragmatic workaround.
