## Change summary

Closing or reloading VS Code with a running cloud session incorrectly triggers a confirm dialog warning the session will stop, even though cloud sessions continue running in the cloud.

## Best solution

A maintainer should close this as completed — the fix landed in commit b43a3a3df6c (PR #289880, shipped in 1.109.0). The current code in `chatLifecycle.ts` explicitly returns false for `AgentSessionProviders.Cloud`, so the confirm dialog no longer appears for cloud sessions.
