# Issue #279041 — Titlebar overlay buttons have the wrong size when increasing Text size

[https://github.com/microsoft/vscode/issues/279041](https://github.com/microsoft/vscode/issues/279041)

## Summary

The bug remains actionable on current main: a maintainer confirmed the Windows Text Size reproduction, and the title-bar layout still clamps the native window controls to a zoom-derived height that does not account for separate OS text scaling.

## Change summary

Increasing Windows Accessibility Text Size enlarges the custom title-bar content without sizing the native window-controls overlay to match.

## Best solution

Make the native window-controls overlay follow the title bar's effective rendered scale under Windows Text Size while preserving the existing minimum control size when application zoom is reduced.
