# Issue #350172 — Remote terminal layout is never persisted, so terminals are not restored after the remote server restarts

[https://github.com/microsoft/vscode/issues/350172](https://github.com/microsoft/vscode/issues/350172)

## Summary

The missing remote layout persistence is confirmed in current main: terminal buffers survive, but the layout needed to reconnect revived processes does not. Keep this open and route it to terminal persistence.

## Change summary

Restore remote terminal tabs and splits after a remote server restart when persistent session revival is enabled.

## Best solution

Remote terminal revival should recover the saved workspace layout alongside the serialized processes, preserving tabs, splits, and active selection without changing ordinary reconnection behavior.
