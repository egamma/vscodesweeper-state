# Issue #296122 — Copilot CLI upgrade version issue

[https://github.com/microsoft/vscode/issues/296122](https://github.com/microsoft/vscode/issues/296122)

## Summary

Keep open: the current terminal bootstrapper still treats a successful npm update as sufficient and launches the PATH-selected CLI without checking whether its version actually changed. The reported upgrade-to-the-same-version outcome remains possible, and no verified fix or same-symptom older canonical was found.

## Change summary

Accepting the Copilot CLI upgrade prompt leaves the integrated terminal running the same incompatible CLI version.

## Best solution

Make the terminal bootstrapper's upgrade outcome reflect the version of the executable it will actually launch: proceed only when that executable meets the minimum version, otherwise explain that the upgrade did not resolve compatibility. Account for installations outside npm without assuming that /opt/homebrew/bin/copilot establishes which package manager owns the executable.
