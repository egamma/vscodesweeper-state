# Issue #336076 — Theme icons in Quick Search results are mistakenly rendered

[https://github.com/microsoft/vscode/issues/336076](https://github.com/microsoft/vscode/issues/336076)

## Summary

Quick Search still passes literal file contents to an icon-aware renderer, so the reported substitution remains reproducible from current source. Keep the issue open while the linked fix PR is reviewed and completed.

## Change summary

Quick Search renders theme-icon syntax in matching file contents as icons instead of literal text.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/336078 so Quick Search preserves literal preview text and correctly positioned match highlights, without changing intentional icons elsewhere in Quick Pick.
