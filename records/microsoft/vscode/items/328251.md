# Issue #328251 — Hard to drag window

[https://github.com/microsoft/vscode/issues/328251](https://github.com/microsoft/vscode/issues/328251)

## Summary

Keep open: dragging from the Command Center remains unavailable on Windows, with prior maintainer analysis identifying an Electron/OS limitation. Existing visibility settings provide a workaround, not the requested interaction, and no verified open canonical owns this same symptom.

## Change summary

Allow dragging the titlebar's search/Command Center area to reposition the window without losing its click-to-search behavior.

## Best solution

Support both window dragging and search activation from the Command Center through an appropriate Electron/native interaction capability. Until that boundary is resolved, preserve usable titlebar drag space without disabling the search control.
