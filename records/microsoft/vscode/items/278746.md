# Issue #278746 — `cannot set privileged capabilities: Operation not permitted` error for Snap installed packages

[https://github.com/microsoft/vscode/issues/278746](https://github.com/microsoft/vscode/issues/278746)

## Summary

Keep open: another reporter confirms that multiple Snap applications fail from VS Code, while the original report establishes that ShellCheck works in an external terminal. No concrete fix or older canonical reporting the same observable symptom was verified.

## Change summary

Snap-installed commands fail with a privileged-capabilities error when launched from VS Code's integrated terminal or extensions.

## Best solution

Identify why VS Code-launched processes cannot acquire the capabilities required by Snap, then restore normal command execution without weakening sandbox protections. Compare process privilege state and launch environment with a working external terminal before choosing the owning component.
