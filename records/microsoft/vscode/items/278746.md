# Issue #278746 — `cannot set privileged capabilities: Operation not permitted` error for Snap installed packages

[https://github.com/microsoft/vscode/issues/278746](https://github.com/microsoft/vscode/issues/278746)

## Summary

This is a platform-level issue where Electron's Chromium sandbox (which sets `PR_SET_NO_NEW_PRIVS` on Linux) prevents snap-confined child processes from acquiring the capabilities they need. A team member has pinged the Electron/platform expert (@deepak1556) but no response yet — keeping open pending that investigation.

## Change summary

Running snap-installed packages from VS Code's integrated terminal fails with 'cannot set privileged capabilities: Operation not permitted' because Electron's sandbox blocks the required privilege escalation.

## Best solution

The root cause is Electron's Chromium sandbox setting `no_new_privs` on spawned processes, which conflicts with snap's need to set capabilities. Resolution likely requires changes in how the VS Code snap package configures its sandbox or how the PTY host spawns child processes. Awaiting platform-team input from @deepak1556 on whether this can be mitigated in VS Code's snap build or requires upstream Electron/snapd changes.

## Evidence

- **upstream root cause:** Chromium's Linux sandbox sets PR_SET_NO_NEW_PRIVS via prctl, which prevents any child process from gaining new privileges. Snap packages need to set capabilities on launch, which requires privileges blocked by this flag. This is an interaction between Electron's sandbox and snap confinement — not a VS Code application-level bug.
- **team engagement:** Team member @anthonykim1 pinged @deepak1556 (Electron/platform expert) on 2025-12-11 but no response yet.
- **multiple reporters:** Two commenters confirm the issue affects various snap packages (shellcheck, firefox, thunderbird, powershell, chromium, audacious) on Ubuntu 24.04 and 25.04.
- **related snap issues:** Several open snap-related issues exist (https://github.com/microsoft/vscode/issues/241636, https://github.com/microsoft/vscode/issues/262431) suggesting ongoing snap confinement challenges, though each has distinct symptoms.
