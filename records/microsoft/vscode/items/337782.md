# Issue #337782 — Show effort level on subagent pill hover, if configured in Task tool call.

[https://github.com/microsoft/vscode/issues/337782](https://github.com/microsoft/vscode/issues/337782)

## Summary

This team-authored UI-polish request remains necessary: current main preserves and displays subagent model information but drops the Task call's configured reasoning effort before constructing the pill hover and accessible label.

## Change summary

Include an explicitly configured Task-tool reasoning effort in the subagent pill's hover metadata.

## Best solution

When a Task call explicitly sets `reasoning_effort`, retain that requested value through live and restored tool-call metadata and expose it in both the subagent pill hover and its accessible label; omit it when the argument was not configured.
