# Issue #161431 — Square brackets break Emmet in TypeScript files

[https://github.com/microsoft/vscode/issues/161431](https://github.com/microsoft/vscode/issues/161431)

## Summary

Still reproduces on main: the noise-reduction regex in defaultCompletionProvider.ts (line 173) intentionally suppresses Emmet completions for abbreviations with brackets-without-equals in JS/TS/JSX/TSX, blocking legitimate Emmet abbreviations like `a[href]`. The workaround (`emmet.triggerExpandOnTab` + Tab) works but the autocomplete dropdown path remains broken.

## Change summary

Emmet abbreviations containing square brackets without `=` (e.g. `a[href]`) don't trigger completions in TypeScript/JavaScript files, because a noise-reduction heuristic treats them as array access patterns.

## Best solution

Refine the regex heuristic in `extensions/emmet/src/defaultCompletionProvider.ts` (line 173) to distinguish legitimate Emmet attribute abbreviations (like `a[href]`, `div[class]`) from actual array accesses (like `a[i]`, `arr[0]`). One approach: only suppress when the bracket content looks like a variable/index rather than an HTML attribute name.
