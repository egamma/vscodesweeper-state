# Issue #161431 — Square brackets break Emmet in TypeScript files

The missing completion remains explained by current source: the JavaScript/TypeScript noise filter rejects a[href] even when TypeScript is explicitly mapped to HTML. Keep this accepted bug open; the confirmed Tab-expansion workaround does not restore the autocomplete dropdown.

Restore Emmet attribute-abbreviation suggestions in TypeScript files explicitly configured to use HTML Emmet.
