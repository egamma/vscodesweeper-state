[https://github.com/microsoft/vscode/issues/252035](https://github.com/microsoft/vscode/issues/252035)

## Summary

Current main now wires F3/Shift+F3 to Find Next/Find Previous when the notebook find widget has focus — exactly the reporter's ask — so this can be closed as completed, citing the commit that added the dedicated widget-focused keybindings.

## Change summary

F3/Shift+F3 do nothing in the Jupyter Notebook find widget, unlike other editors.

## Best solution

Keep the shipped fix: `notebook.findNext.fromWidget` (F3) and `notebook.findPrevious.fromWidget` (Shift+F3), scoped to `NOTEBOOK_EDITOR_FOCUSED && CONTEXT_FIND_WIDGET_VISIBLE`, calling `controller.findNext()`/`findPrevious()`.
