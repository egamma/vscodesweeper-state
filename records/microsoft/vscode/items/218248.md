# Issue #218248 — Dragging text upwards triggers scrolling far too early

[https://github.com/microsoft/vscode/issues/218248](https://github.com/microsoft/vscode/issues/218248)

## Summary

Still open — native text DnD auto-scrolling triggers too early when dragging upward. VS Code has no custom auto-scroll for native DnD (it relies on the browser), so this may be a Chromium/Electron upstream issue or addressable by implementing custom scroll-on-drag logic. No fix or response has been posted.

## Change summary

When dragging selected text upward in the editor, auto-scrolling triggers at approximately the vertical midpoint instead of near the top edge, while downward dragging scrolls correctly near the bottom edge.

## Best solution

Investigate whether Chromium's native DnD auto-scroll is the root cause or if VS Code's DOM layout (tab bar, breadcrumbs, sticky scroll) causes asymmetric edge detection. If upstream, consider implementing custom scroll-on-drag logic in the `onDragOver` handler in `codeEditorWidget.ts` to replace the browser's native auto-scroll, similar to how `TopBottomDragScrolling` works for selection-extending drags. The `_onMouseDownThenMove` path in `mouseHandler.ts` (line 420) deliberately skips auto-scroll when `isDragAndDrop` is true.
