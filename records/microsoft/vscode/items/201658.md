## Evidence

- **Confirmed driver-dependent trigger:** In https://github.com/microsoft/vscode/issues/201658, the reporter confirmed the slowdown on Insiders and isolated it to NVIDIA's Background Application Max Framerate setting. A second user confirmed that disabling the setting specifically for the VS Code executable restored smooth rendering; setting it to 5 FPS visibly throttled VS Code. Extensions were disabled in the original report.
- **Related older report, different diagnosed work:** https://github.com/microsoft/vscode/issues/107016 is open and older. https://github.com/microsoft/vscode/issues/107016#issuecomment-1193143661 independently describes the same NVIDIA limiter trigger and an application-profile workaround. However, its maintainer-diagnosed work concerns Chromium accessibility-tree slowdown, documented in https://github.com/microsoft/vscode/issues/107016#issuecomment-772509185 and https://github.com/microsoft/vscode/issues/107016#issuecomment-799232137. The matching user comment is useful corroboration, but does not establish that the accessibility issue owns the separate driver-profile correction.
- **Other related items do not supply a canonical or fix:** https://github.com/microsoft/vscode/issues/201657 is closed; its author explicitly identifies it as a duplicate of the issue under review in https://github.com/microsoft/vscode/issues/201657#issuecomment-1873327379. https://github.com/microsoft/vscode/issues/74098 concerns macOS external-display flickering that persisted with --disable-gpu, not the Windows NVIDIA frame-limit trigger.
- **Current source provides mitigation, not proof of resolution:** src/mainImpl.ts:251-305 recognizes disable-hardware-acceleration and calls app.disableHardwareAcceleration(); this bypasses the accelerated rendering path rather than correcting driver classification. src/vs/platform/windows/electron-main/windows.ts:262-266 exposes an optional Electron backgroundThrottling override, and src/vs/platform/windows/electron-main/windowImpl.ts:778-787 disables it for Agents windows. Neither establishes that NVIDIA exempts a foreground editor window from its driver-level limiter.
