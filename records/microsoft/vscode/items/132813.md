[https://github.com/microsoft/vscode/issues/132813](https://github.com/microsoft/vscode/issues/132813)

## Summary

The Explorer state-loss race behind this reload scenario was fixed by commit 1bd2fc7937140bf342459ff895a87dff9b219eec. Current main serializes tree input restoration and synchronizes the cached expansion state, so this can be closed as completed.

## Change summary

Preserve expanded Explorer folders when a Remote SSH reconnect requires the window to reload or reopen.
