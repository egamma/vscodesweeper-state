# Issue #266048 — A large number of test output events cause hangs in the VS Code UI

[https://github.com/microsoft/vscode/issues/266048](https://github.com/microsoft/vscode/issues/266048)

## Summary

Still reproduces after the initial throttling fix (PR #266085). The reporter confirmed on Insiders 1.105 that the UI still hangs with high-volume test output (50k iterations). No subsequent fix has landed for the remaining performance gap.

## Change summary

A large number of test output events causes VS Code UI hangs — typing in the terminal freezes and the Test Results view stutters badly.

## Best solution

The decoration throttling in `testingDecorations.ts` (100ms Throttler) helped but is insufficient for very high output rates. The test results tree and output rendering pipeline likely need additional batching/debouncing — investigate the rendering path in `testResultsView/` and the `onTestChanged` event propagation to reduce per-message DOM and layout work.
