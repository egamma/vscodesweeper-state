# Issue #336408 — Testing: automatic result eviction leaves extension-host run trackers retained

[https://github.com/microsoft/vscode/issues/336408](https://github.com/microsoft/vscode/issues/336408)

## Summary

Confirmed defect on current main: the ordinary history-eviction path in testResultService.ts never fires the `removed` change event, so the extension host never releases the corresponding run tracker. An open PR (#336409) already implements the fix, so this should stay open for that PR to land rather than be treated as agent-ready or closed.

## Change summary

Automatic test-result history eviction disposes the renderer-side result but never notifies the extension host, leaking extension-host run trackers over time.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/336409, which adds the missing `changeResultEmitter.fire({ removed: [removed] })` call (and covering tests) to the ordinary eviction branch in push().
