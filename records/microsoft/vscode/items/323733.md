# Issue #323733 — Live Preview: "Open in External Browser" from embedded preview fails with "Failed to open (0x2)"

[https://github.com/microsoft/vscode/issues/323733](https://github.com/microsoft/vscode/issues/323733)

## Summary

Keep open: independent Windows reproductions identify an encoded drive-letter colon reaching the external-opening path, and current source still permits that failure. The matching local-file report is newer, so it cannot replace this re-reviewed issue as the canonical.

## Change summary

Opening a local HTML page externally from the Integrated Browser fails on Windows when its file URL contains a percent-encoded drive-letter colon.

## Best solution

Make the existing external-open action successfully open Windows local HTML files in the default browser while preserving correct URL escaping and existing HTTP(S) behavior. Retain this older, diagnosed report as the tracking issue for the local-file failure.
