# Issue #296829 — Per-agent auto-approve for terminal commands in custom agents (.agent.md)

[https://github.com/microsoft/vscode/issues/296829](https://github.com/microsoft/vscode/issues/296829)

## Summary

A real capability gap remains: current VS Code supports session-level approval modes but no custom-agent field or agent-scoped permission default. Route this to the custom-agent and permissions owners for a product and security decision.

## Change summary

Allow a custom `.agent.md` agent to request an agent-specific default that bypasses terminal-command approvals.

## Best solution

Provide an explicitly user-approved, locally persisted permission default associated with a custom agent. Repository-controlled `.agent.md` content must not silently grant itself elevated permissions; selecting such a default should retain the existing approval warning and workspace-trust boundaries.
