# Issue #335023 — Agent feedback sent to parent session instead of fork

[https://github.com/microsoft/vscode/issues/335023](https://github.com/microsoft/vscode/issues/335023)

Keep open: feedback routing warrants retesting after the subsequent chat-folder changes, and the supplied Windows fork steps are sufficient. No issue-referencing fix or verified same-symptom canonical was found; this team-authored report does not meet the factual-close bar.

## Change summary

Inline feedback submitted on changes made in a forked Agents Window session reaches the parent session instead.

## Best solution

Feedback on the fork's changes should remain associated with that fork and submit `/act-on-feedback` to its conversation without changing the parent. Retest the reported sequence and trace editor-resource ownership through feedback creation and widget selection, preserving intentional ownership of editors belonging to other sessions.
