# Issue #306315 — No display or easy way to see what Repo you are in

[https://github.com/microsoft/vscode/issues/306315](https://github.com/microsoft/vscode/issues/306315)

## Summary

Keep open as a feature request for readily visible remote repository identity. Existing Source Control labels identify the local folder, which the reporter explicitly distinguishes from the remote repository they needed to identify.

## Change summary

Make the remote repository name or URL discoverable in Source Control without running git remote -v.

## Best solution

Provide a discoverable, read-only way to inspect configured remote identities in the built-in Git Source Control experience, distinct from local folder and branch labels. Preserve support for repositories with multiple remotes rather than assuming every checkout has a single origin.
