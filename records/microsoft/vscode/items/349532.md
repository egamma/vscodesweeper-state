# Issue #349532 — Diff tab close button flickers on resize and can stay hidden

[https://github.com/microsoft/vscode/issues/349532](https://github.com/microsoft/vscode/issues/349532)

## Summary

Keep open: the supplied settings and resize steps suffice to retest, and current source retains the suspected wrapping-state feedback path. Recent Add Tab layout changes do not establish a fix; the persistent hidden close button remains unconfirmed without rendered reproduction.

## Change summary

Long diff tabs flicker during resizing and can retain a hidden close button with Modern UI, Connected tabs, wrapping, and fit sizing enabled.

## Best solution

Make the editor tab layout settle consistently at a fixed width, truncating long titles while keeping the active tab's close action reachable. Reproduce the reported configuration first and cover repeated layout at the same width in the existing tabs-control browser suite.
