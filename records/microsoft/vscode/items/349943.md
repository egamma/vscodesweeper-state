# Issue #349943 — Enable Composite Task Multiple Instance Launch

[https://github.com/microsoft/vscode/issues/349943](https://github.com/microsoft/vscode/issues/349943)

## Summary

The requested ability to launch fresh dependency instances remains absent in current source. Route to the tasks area for a decision on dependency reuse; the existing instance-limit issue covers related enforcement problems, not the full request.

## Change summary

Allow repeated composite-task launches to create additional child-task instances while respecting configured instance limits and policies.

## Best solution

Define a supported way for composite tasks to request fresh child instances without disrupting workflows that share running dependencies. Coordinate limit and policy enforcement with https://github.com/microsoft/vscode/issues/248733.
