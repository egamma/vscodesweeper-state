# Issue #306984 — Starting from version 1.108.2 and later, the focus outline no longer appears when clicking with the mouse or when the focus is placed on "Explore."

[https://github.com/microsoft/vscode/issues/306984](https://github.com/microsoft/vscode/issues/306984)

## Summary

The missing full-list focus outline is an intentional design change: standard themes now rely on focused-item styling, while the surrounding outline is retained only for high-contrast themes.

## Change summary

Restore the focus outline around the Explorer so keyboard users can identify which workbench area has focus.

## Best solution

Keep the intentionally reduced outline treatment in standard themes and the stronger container outline in high-contrast themes. Any additional standard-theme keyboard-focus affordance should be considered separately as accessibility polish without necessarily restoring the former full-pane border.

- **implementation:** Commit 718b93c010005cf1cbd22d6712ae919608adad26 changed src/vs/workbench/browser/media/style.css so the empty-list/container focus outline is emitted only under `.monaco-workbench.hc-black` and `.monaco-workbench.hc-light`.
