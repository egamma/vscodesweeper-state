# Issue #162286 — Feature Request: Allow hiding the "Open in Merge Editor" button

[https://github.com/microsoft/vscode/issues/162286](https://github.com/microsoft/vscode/issues/162286)

## Summary

This accepted Backlog request remains unimplemented: current main still contributes the Merge Editor action without a visibility preference. It is also team-authored and has 37 community upvotes, so it should remain open.

## Change summary

Allow users who prefer inline conflict resolution to hide the in-editor “Resolve in Merge Editor” action.

## Best solution

Decide whether the Git extension should expose a narrowly scoped preference controlling this editor-content action, then condition its `when` clause in `extensions/git/package.json` without disabling the Merge Editor itself.

## Vision fit

- **Fit:** rejected
- **Reason:** A dedicated visual toggle for one editor action conflicts with the preference for uniform UI and avoiding configuration sprawl.
- **Evidence:** Values and guardrails: “Simple, uniform UI and UI interactions”; one-off visual toggles generally cut against uniform, theme-level mechanisms.

## Evidence
