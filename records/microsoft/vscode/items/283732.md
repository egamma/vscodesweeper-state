## Plan brief

- **Likely files:** `extensions/copilot/src/platform/git/vscode/gitExtensionServiceImpl.ts`, `extensions/copilot/src/extension/extension/vscode/services.ts`, `extensions/git/src/main.ts`
- **Validation:** Reproduce in an Extension Development Host with Copilot Chat enabled and a multi-repository workspace, then verify SCM diffs load and files can be saved and deleted while Copilot and the built-in Git extension activate; capture extension-host logs and repeat with Copilot disabled as the control.
- **Behavior:**

  > With Copilot Chat enabled, opening a Git workspace must not block SCM diffs, file saves or deletes, or activation of other extensions. Git integration may initialize asynchronously, but unrelated editor and file-system operations must remain responsive. Acceptance requires reproducing the reported startup flow with Copilot enabled and confirming all affected operations complete, with the Copilot-disabled run retained as a control.
- **Trace:**

  > The report was isolated through Extension Bisect and independently confirmed by two users after VS Code 1.107. In current source, GitExtensionServiceImpl in extensions/copilot/src/platform/git/vscode/gitExtensionServiceImpl.ts starts initialization from its constructor and calls `gitExtension.activate()` before retrieving the Git API; the implementation is registered in extensions/copilot/src/extension/extension/vscode/services.ts. A maintainer identified that API interaction as the investigation lead, but source inspection alone does not establish whether the awaited activation stalls the extension host or how that would block file operations. The boundary is the Copilot/Git activation lifecycle: normal Git discovery, commit-message integration, and unrelated Copilot functionality must remain unchanged. The notification-specific freeze tracked by https://github.com/microsoft/vscode/issues/275010 is related only at the symptom level and should not be assumed to share this root cause.

## Evidence

- **confirmed impact:** The reporter isolated Copilot Chat with Extension Bisect, supplied a recording, and two independent commenters confirmed Git changes stopped loading after upgrading to VS Code 1.107.
- **maintainer lead:** A Git maintainer explicitly asked whether Copilot Chat calling the Git extension API could be responsible: https://github.com/microsoft/vscode/issues/283732#issuecomment-3673227167.
- **current source path:** extensions/copilot/src/platform/git/vscode/gitExtensionServiceImpl.ts initializes Git integration from the service constructor and asynchronously calls `gitExtension.activate()` before obtaining API version 1; extensions/copilot/src/extension/extension/vscode/services.ts registers this implementation.
