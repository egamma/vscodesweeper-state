# Issue #45617 — Zen Mode Settings

[https://github.com/microsoft/vscode/issues/45617](https://github.com/microsoft/vscode/issues/45617)

## Summary

A real gap remains: current Zen Mode supports only a fixed set of dedicated settings, not general mode-specific overrides. This accepted Backlog request has 56 upvotes, and an open PR addresses only the minimap subset, so it should remain open.

## Change summary

Allow editor and workbench settings such as font size, minimap visibility, rulers, and decorations to be overridden while Zen Mode is active.

## Best solution

Add a coherent Zen Mode configuration override mechanism, likely spanning the configuration registry/services and the workbench Zen transition, with clear precedence over language overrides and reliable restoration on exit. Review https://github.com/microsoft/vscode/pull/208778 as a narrow interim minimap change without treating it as completion of the general request.
