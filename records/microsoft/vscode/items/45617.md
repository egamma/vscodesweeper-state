# Issue #45617 — Zen Mode Settings

[https://github.com/microsoft/vscode/issues/45617](https://github.com/microsoft/vscode/issues/45617)

## Summary

Keep open: current Zen Mode settings cover selected layout behaviors, not the general conditional settings scope requested here. The accepted Backlog request has 57 upvotes and maintainer support; the open minimap PR addresses only one part of it.

## Change summary

Allow editor and other supported settings to take different values while Zen Mode is active, without changing their normal-mode values.

## Best solution

Provide a coherent Zen Mode override mechanism with defined precedence relative to language settings and clear eligibility rules for editor, workbench, and extension settings. Review the existing minimap PR as a partial implementation candidate, without treating it as completion of the broader request.
