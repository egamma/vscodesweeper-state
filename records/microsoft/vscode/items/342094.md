# Issue #342094 — Chat prompt error: session construction failed in VFS repos

[https://github.com/microsoft/vscode/issues/342094](https://github.com/microsoft/vscode/issues/342094)

## Summary

Keep open: the reporter confirmed a model-independent Copilot harness failure in two virtual repositories, with Local working in the same workspace. Current source includes host-addressability filtering, but provisional creation still warrants investigation; no verified fixing commit establishes that the reported flow is resolved.

## Change summary

Starting or moving a chat to the Copilot harness in a GitHub virtual repository fails because its workspace is treated as an inaccessible filesystem directory.

## Best solution

Make Copilot harness selection and session creation handle virtual workspaces consistently without passing virtual URI paths as native working directories. Establish the supported virtual-workspace behavior across fresh sessions and Move to Copilot, while investigating the network-drive report separately unless a shared cause is demonstrated.
