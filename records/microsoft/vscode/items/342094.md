# Issue #342094 — Chat prompt error: session construction failed in VFS repos

[https://github.com/microsoft/vscode/issues/342094](https://github.com/microsoft/vscode/issues/342094)

## Summary

Keep open: the reporter confirmed a VFS-specific Copilot harness failure across two repositories and multiple models, with Local working. Current source still converts workspace URIs into native SDK paths; defaulting virtual workspaces to Local does not resolve explicit Copilot selection or Move to Copilot.

## Change summary

Copilot harness session creation fails in GitHub virtual workspaces because the virtual repository is treated as an accessible native working directory.

## Best solution

Make harness selection and continuation respect virtual-workspace compatibility so users retain a working chat path instead of encountering a native-directory error. Establish whether Copilot should support these workspaces or explicitly prevent unsupported transitions while retaining Local.
