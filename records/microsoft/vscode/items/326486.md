# Issue #326486 — Difficult to review create session approvals

[https://github.com/microsoft/vscode/issues/326486](https://github.com/microsoft/vscode/issues/326486)

## Summary

Current main still presents create-session approval through the generic raw-input path rather than a purpose-built summary. This team-authored Agents Window polish remains necessary and should stay open.

## Change summary

Replace the one-line JSON shown for create-session approval with a clear, outcome-oriented review UI.

## Best solution

Present a concise create-session approval that makes the proposed relationship, title, task, workspace/isolation, and model choices understandable before approval, while preserving access to any security-relevant details.
