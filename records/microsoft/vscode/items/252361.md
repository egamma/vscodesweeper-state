## Summary

The Explorer regression has a landed mitigation that both the reporter and another user confirmed works. Keep this upstream tracking issue open under the review policy; the remaining maintainer check is runtime resolution and whether the mitigation can be retired.

## Change summary

Opening a Windows subst drive root stopped listing its files in Explorer after the Electron 35 / Node.js 22 update, while opening subfolders still worked.
