# Issue #41909 — Provide API to access and change editor tab labels

[https://github.com/microsoft/vscode/issues/41909](https://github.com/microsoft/vscode/issues/41909)

## Summary

The path-pattern setting addresses many naming cases, but the requested extension API remains absent and an open PR is already implementing it. Maintainers have explicitly kept the API direction open, so the issue should remain available for that work.

## Change summary

Expose an extension API for reading and changing editor tab labels, including labels for dynamically generated and custom editors.

## Best solution

Settle the API contract and update or land https://github.com/microsoft/vscode/pull/197205, ensuring extension-provided labels behave consistently in editor tabs, Open Editors, and relevant quick picks while retaining the path-pattern setting for declarative cases.

## Evidence

- **partial built-in capability:** src/vs/workbench/services/editor/common/customEditorLabelService.ts implements workbench.editor.customLabels.patterns by matching resource paths and expanding fixed filename, extension, and directory placeholders.
