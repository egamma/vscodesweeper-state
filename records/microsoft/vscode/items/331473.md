# Issue #331473 — Dark 2026: ordinary variables are visually indistinguishable from plain text - looks like syntax highlighting is not applied

[https://github.com/microsoft/vscode/issues/331473](https://github.com/microsoft/vscode/issues/331473)

## Summary

The palette concern remains present in current source, but an older open report already describes the same symptom: Dark 2026 variables look like unhighlighted plain text. Consolidate this report's precise JS/TS scope and color analysis there.

## Change summary

Give ordinary mutable variables in Dark 2026 a color that is visibly distinct from the editor foreground.

## Best solution

Resolve variable-versus-plain-text differentiation through https://github.com/microsoft/vscode/issues/318839, preserving this report's measured colors and mutable-versus-readonly distinction as design evidence. The palette decision should balance code readability against the excessive variable emphasis reported after the previous orange-color change.
