# Issue #280786 — Edited request is not availabe in chat editor history

[https://github.com/microsoft/vscode/issues/280786](https://github.com/microsoft/vscode/issues/280786)

## Summary

The inline-edit submission path still loses the edited request when recording input history: it tears down the inline editor before reading the history entry. Keep this team-authored bug open; the supplied steps are sufficient and the current source exposes the failure.

## Change summary

Re-sent edited chat requests should become available in shared chat input history.

## Best solution

Record the actual submitted edited request in chat input history, without substituting the bottom composer's draft. Preserve the existing history-navigation behavior and distinguish this defect from requests to change history sharing between sessions.
