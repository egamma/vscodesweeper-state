# Issue #341543 — Copilot takes several minutes to respond, any query

[https://github.com/microsoft/vscode/issues/341543](https://github.com/microsoft/vscode/issues/341543)

## Summary

Thanks for the report. Many users confirm this regression with the Copilot harness. A VS Code contributor says the runtime waits up to 3-5 minutes for MCP servers to start or authenticate, and a UI bug hides the Skip/Authenticate prompt. I did not trace this in the source, so I'm keeping it open until a fix lands.

## Change summary

With the Copilot harness, chat responses are delayed by several minutes, possibly while the agent host waits on MCP servers (reportedly the GitKraken MCP server and the GitLens extension) before sending the message.

## Best solution

Don't block the first message on slow or unauthenticated MCP servers. Add a timeout or lazy start, and show the Skip/Authenticate UI during the wait so users can proceed.
