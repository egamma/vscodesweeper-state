# Issue #341543 — Copilot takes several minutes to respond, any query

[https://github.com/microsoft/vscode/issues/341543](https://github.com/microsoft/vscode/issues/341543)

## Summary

Thanks for the report. A maintainer has diagnosed the root cause: the Copilot harness waits up to 4-5 minutes for an MCP server that starts but never announces its tools, and the UI does not show a skip prompt during that wait. Many users confirm it. The maintainer says this issue will track the fix on the VS Code side, so it stays open.

## Change summary

Copilot harness chats stay on "Evaluating" for minutes before responding because startup waits on an unresponsive MCP server.

## Best solution

Show which MCP server is blocking the message, let the user skip waiting for it, and cut the startup timeout to about 60s. The GitLens/GitKraken MCP server needs to pick up the upstream mcp-go fix (>=1.1.1).
