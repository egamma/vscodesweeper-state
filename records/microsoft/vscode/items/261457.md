## Change summary

Delay NES model requests according to `editor.inlineSuggest.minShowDelay` so additional context can accumulate and avoid requests whose results cannot yet be displayed.

## Best solution

Define how much of `minShowDelay` should be spent waiting before an NES request, then implement the debounce in the NES request path while preserving enough model-response time to meet `earliestShownDateTime`.
