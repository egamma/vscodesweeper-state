# Issue #326353 — ESC don't close Intellisense

[https://github.com/microsoft/vscode/issues/326353](https://github.com/microsoft/vscode/issues/326353)

## Summary

This is a specific instance (Visual Basic, retyping a character mid-word) of the same ESC-doesn't-permanently-close-suggest-widget regression already tracked, with multiple confirmations and a version bisection, at https://github.com/microsoft/vscode/issues/323796 — proposing a duplicate close to consolidate.

## Change summary

Pressing Escape while the IntelliSense/suggest widget is visible fails to keep it closed — it reappears immediately after retyping a character that retriggers suggestions.

## Best solution

Consolidate discussion on https://github.com/microsoft/vscode/issues/323796, which has several independent confirmations (including a workaround via Quick Suggestions Delay / Inline Suggest Min Show Delay settings) and a user-reported regression window between 1.120.0 and 1.130.0 — that's the better place to track a fix in the suggest/quick-suggestions retrigger logic.
