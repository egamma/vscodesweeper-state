# Issue #191597 — ghost text hover screen cheese

[https://github.com/microsoft/vscode/issues/191597](https://github.com/microsoft/vscode/issues/191597)

## Summary

Keep open: current source still leaves the inline-completion toolbar without the normal hover-row separator and clears its count while the total is unknown. The older empty-rendering issue covers only the count symptom, not this report's full scope.

## Change summary

Separate inline-completion controls from language hover content and present a meaningful state while the suggestion count is pending.

## Best solution

Make the combined keyboard-triggered hover read as distinct language-information and inline-completion sections, with a stable, understandable pending-count presentation. Agree on that presentation without implying that the provider has finished or delaying usable hover actions.
