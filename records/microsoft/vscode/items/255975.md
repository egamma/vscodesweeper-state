# Issue #255975 — long Scrolling with physical trackpad on Android does not work properly

[https://github.com/microsoft/vscode/issues/255975](https://github.com/microsoft/vscode/issues/255975)

## Summary

Keep open as a Chromium/Android input issue: the report provides a specific physical-trackpad reproduction, and current source consumes browser wheel deltas without controlling whether Chrome emits post-gesture momentum events. The existing Chromium, Android, web, and trackpad labels already route it appropriately.

## Change summary

Long physical-trackpad gestures on Android stop scrolling immediately when the fingers lift instead of continuing with momentum.

## Best solution

Chromium on Android should deliver consistent momentum wheel events after both short and long physical-trackpad gestures. If that cannot be corrected upstream, the editor area can evaluate an Android-scoped fallback using the existing inertial-scroll path without changing desktop wheel behavior.
