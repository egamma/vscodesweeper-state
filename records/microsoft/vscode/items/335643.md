# Issue #335643 — Mark as Done is bound to the del key

[https://github.com/microsoft/vscode/issues/335643](https://github.com/microsoft/vscode/issues/335643)

## Summary

Keep open for the existing Agents Window discussion. The binding is intentional, but using Delete for reversible Mark as Done while the same menu offers permanent deletion creates a genuine interaction ambiguity; as a team-authored polish issue, this should not receive a judgment close.

## Change summary

Clarify the Agents Window keyboard behavior where Delete marks a focused session as done even though its context menu also offers permanent deletion.

## Best solution

Choose and consistently communicate one user-facing model for Delete in the Sessions list: either retain it as the reversible Mark as Done shortcut with sufficiently clear presentation, or reserve deletion-oriented input for permanent deletion and provide Mark as Done through a distinct binding.
