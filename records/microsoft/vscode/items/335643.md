# Issue #335643 — Mark as Done is bound to the del key

[https://github.com/microsoft/vscode/issues/335643](https://github.com/microsoft/vscode/issues/335643)

## Summary

Team-authored UX feedback on a shipped keybinding choice — confirmed in source that the Mark as Done action is bound to the bare Delete key (and Cmd+Backspace on mac), alongside a separate Delete Entry command in the same context menu. This is a design discussion, not a defect, and the author already applied under-discussion; keep it open for a maintainer decision.

## Change summary

The Sessions list binds the Delete key to "Mark as Done" (archive), which is confusing given a separate "Delete Entry" command exists in the same context menu.

## Best solution

A maintainer should decide whether to rebind Mark as Done away from the bare Delete key (e.g. require a modifier, matching the mac Cmd+Backspace pattern) to reduce confusion with Delete Entry — this is a keybinding-design call for the Sessions/Agents Window UX owners, in src/vs/sessions/contrib/sessions/browser/views/sessionsViewActions.ts.
