# Issue #166891 — Explore a lightweight notification UI to display confirmation feedback for actions to users

[https://github.com/microsoft/vscode/issues/166891](https://github.com/microsoft/vscode/issues/166891)

## Summary

Keep this UX exploration open: existing notifications, status messages, and hovers provide building blocks but do not deliver the proposed lightweight confirmation treatment. Maintainer feedback favors contextual feedback, while keyboard-triggered actions and the global opt-out still need a product decision.

## Change summary

Provide brief, lightweight confirmation feedback for successful actions such as copying links, saving browser-backed changes, and enabling settings sync, with a global opt-out.

## Best solution

Establish a consistent, accessible success-feedback treatment that favors contextual placement and defines a fallback for actions without an anchor. Settle its lifetime, notification-center persistence, extension availability, and opt-out semantics before adopting it across the motivating workflows.
