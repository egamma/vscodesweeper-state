# Issue #166891 — Explore a lightweight notification UI to display confirmation feedback for actions to users

[https://github.com/microsoft/vscode/issues/166891](https://github.com/microsoft/vscode/issues/166891)

## Summary

A real UX gap remains on current main, but the team has not settled whether ephemeral confirmation belongs in context, the status bar, or another global surface. Keep this open as under discussion rather than closing it for age.

## Change summary

Provide lightweight, transient confirmation feedback for successful actions without creating persistent notification noise.

## Best solution

Settle on a consistent contextual-first design, then provide a shared workbench primitive for short-lived confirmation feedback with appropriate accessibility behavior and an opt-out. Reuse the hover or notification infrastructure rather than introducing an unrelated third notification location.

- **Reason:** A uniform confirmation-feedback pattern improves core workbench UX and notification hygiene, provided it avoids another inconsistent global surface.
