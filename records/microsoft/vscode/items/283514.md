[https://github.com/microsoft/vscode/issues/283514](https://github.com/microsoft/vscode/issues/283514)

## Summary

Keep open: renaming is available, but the current source still leaves unloaded local sessions with an index-only rename that is lost when their stored content is restored. An open PR explicitly targets this issue and should be reviewed before considering it resolved.

## Change summary

Make local chat session renames update the sessions list reliably and persist when reopening the session or reloading the window.

## Best solution

Review and complete https://github.com/microsoft/vscode/pull/323323 against both immediate list updates and persistence for loaded and unloaded local sessions. Keep this reopened issue as the existing tracking report until the remaining behavior is fixed.
