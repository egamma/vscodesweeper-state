# Issue #286987 — VSCode Update Code

[https://github.com/microsoft/vscode/issues/286987](https://github.com/microsoft/vscode/issues/286987)

## Summary

Thanks for the report. Several Windows users describe the same failed in-place update, with 'failed to update code.exe' and 'DeleteFile failed; code 5. Access is denied'. That points to files being locked, likely by antivirus or endpoint software, during the user-setup update. The report is complete but I did not read the code and could not retest it. A maintainer asked for more detail and the thread has had no further activity, so it stays open.

## Change summary

After an automatic or manual update on Windows, the User Installer build fails to restart and leaves VS Code broken until a full uninstall and reinstall.

## Best solution

Find what holds the file locks during the update, for example antivirus or endpoint software or a lingering VS Code process. Then make the Windows update path either fail safely and roll back, or retry. Ask reporters for the setup/update log (the installer's /LOG output) to diagnose.
