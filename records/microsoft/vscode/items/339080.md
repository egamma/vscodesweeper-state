# Issue #339080 — Recursive watcher deduplication lets narrow same-root request replace broad workspace watcher

[https://github.com/microsoft/vscode/issues/339080](https://github.com/microsoft/vscode/issues/339080)

## Summary

Confirmed on main: ParcelWatcher.removeDuplicateRequests unconditionally overwrites a same-path uncorrelated watch request with a later, narrower one, silently dropping broader coverage. An open PR from the same reporter already proposes a fix, so this stays open pending review/merge of that PR.

## Change summary

A later-registered narrow recursive watch request (with an `includes` filter) for the same path can silently replace an earlier broad workspace watcher during Parcel watcher request deduplication, causing file changes outside the narrow filter to go unreported.

## Best solution

Land the union/priority fix in the already-open PR https://github.com/microsoft/vscode/pull/339081 so a narrow same-root request can no longer silently replace a broader uncorrelated watch request.
