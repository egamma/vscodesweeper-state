# Issue #157041 — Programmatically running a task in VS Code Web ignores `dependsOn` tasks

[https://github.com/microsoft/vscode/issues/157041](https://github.com/microsoft/vscode/issues/157041)

## Summary

Keep open: current source still exposes a web-specific path that loses configured dependencies, and no verified fix or canonical duplicate covers the report. The supplied steps suffice to retest, but the distinction between fetched and newly constructed tasks, plus the later preLaunchTask symptom, needs confirmation on current main.

## Change summary

Programmatic execution of custom tasks in VS Code Web should honor tasks.json dependencies consistently with Tasks: Run Task.

## Best solution

Preserve configured dependencies when executing an existing custom task through the web extension host, without expanding the public Task API or enabling shell/process execution in browsers. Independently reproduce the reported debugging symptom before assuming it shares the same cause.
