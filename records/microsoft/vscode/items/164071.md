# Issue #164071 — Markdown preview does not scroll to top on new URI

[https://github.com/microsoft/vscode/issues/164071](https://github.com/microsoft/vscode/issues/164071)

## Summary

Still reproducible on main: the `updateContent` handler in the markdown preview webview replaces content on resource change but does not scroll to top. Two open PRs are attempting to fix this.

## Change summary

Clicking a relative link in markdown preview opens the target document at the previous scroll position instead of scrolling to the top.

## Best solution

Land a fix in `extensions/markdown-language-features/preview-src/index.ts` that calls `window.scrollTo(0, 0)` in the `updateContent` handler when `data.source !== documentResource`. PR https://github.com/microsoft/vscode/pull/290101 or https://github.com/microsoft/vscode/pull/271555 should be reviewed and merged.
