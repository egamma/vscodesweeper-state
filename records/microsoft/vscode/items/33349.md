# Issue #33349 — Search bar input field very narrow

[https://github.com/microsoft/vscode/issues/33349](https://github.com/microsoft/vscode/issues/33349)

## Summary

Keep this canonical UI-polish issue open: current responsive behavior can still let a long localized result label consume the find input's space, while manual resizing is only a workaround.

## Change summary

Ensure the editor find widget retains a readable minimum input width when localized result text is long.

## Best solution

Update the editor find widget layout to preserve a usable input width, truncating or hiding the match label when necessary. The responsive logic belongs in `src/vs/editor/contrib/find/browser/findWidget.ts` and `findWidget.css`.
