# Issue #314048 — Very long session description

[https://github.com/microsoft/vscode/issues/314048](https://github.com/microsoft/vscode/issues/314048)

## Summary

Still open on main — when Copilot CLI wraps the user prompt with attachments/context, the default session title (used before the LLM-generated title arrives) includes the full wrapped message, producing a very long and ugly title. No fix has been committed.

## Change summary

Chat session title displays the full CLI-wrapped user prompt (with attachments and context) instead of just the user's actual question.

## Best solution

In `ChatModel.getDefaultTitle()` (src/vs/workbench/contrib/chat/common/model/chatModel.ts), strip or ignore CLI wrapper context from the message before extracting the default title — or use the `<userRequest>` content specifically. Alternatively, ensure the title generation LLM result is applied before the session list renders the default title.
