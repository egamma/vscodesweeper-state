# Issue #125871 — Resolve file with same name as folder as index

[https://github.com/microsoft/vscode/issues/125871](https://github.com/microsoft/vscode/issues/125871)

## Summary

Custom editor labels now address much of the filename-context problem in tabs, Open Editors, and Quick Open, but text-search results still display the original basename. Keep this accepted request open to settle the remaining cross-surface behavior; neither linked issue covers its full scope.

## Change summary

Make generic filenames such as index.tsx and __init__.py contextually meaningful across filename displays and navigation.

## Best solution

Build on existing custom editor labels to provide meaningful filename context on the remaining VS Code surfaces, beginning with search results. Preserve module-resolution semantics and decide the debugger/console boundary separately rather than introducing a new TypeScript naming convention.
