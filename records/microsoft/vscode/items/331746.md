# Issue #331746 — Markdown previews do not support path drag-and-drop

[https://github.com/microsoft/vscode/issues/331746](https://github.com/microsoft/vscode/issues/331746)

## Summary

The requested capability remains missing: Markdown preview tabs do not expose their source document as a file-path drag payload. Keep this open as a feature request; dragging the source tab is a workaround, not equivalent support.

## Change summary

Allow dragging a Markdown preview tab into the integrated terminal to insert the underlying Markdown file's path.

## Best solution

Support source-document path insertion when dragging a Markdown preview tab into the terminal, while preserving preview-tab movement and existing terminal path quoting. The relevant boundary is between the Markdown preview's source URI and the workbench's editor drag payload.
