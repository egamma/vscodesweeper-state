## Change summary

Copilot cannot retrieve diagnostic output displayed by CustomExecution task pseudoterminals, despite recognizing task execution and completion.

Ensure Copilot's task-output retrieval exposes retained CustomExecution output without requiring shell integration, a separate subtask terminal, or an extension-specific LM tool. - **Behavior:**

  > A CustomExecution task can display useful diagnostics in its pseudoterminal while Copilot reports only whether execution succeeded. Copilot should be able to retrieve those retained diagnostics through its task-output tools during execution and after completion. Acceptance checks should use a unique diagnostic emitted by a minimal custom task and confirm that the tool result contains it, without creating another terminal or requiring shell integration. Existing shell-task output behavior should remain unchanged.
- **Trace:**

  > TerminalTaskSystem._createTerminal in src/vs/workbench/contrib/tasks/browser/terminalTaskSystem.ts uses TerminalProcessExtHostProxy for CustomExecution; getTerminalsForTasks does not exclude that runtime. GetTaskOutputTool.invoke resolves those terminal resources and delegates to collectTerminalResults in src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/taskHelpers.ts. Its execution.getOutput reads the xterm buffer through outputHelpers.ts, but non-background queries create a marker when retrieval begins, making completed-task output boundaries a concrete investigation lead rather than a confirmed root cause. GetTerminalOutputTool instead looks up RunInTerminalTool executions and is not an arbitrary task-terminal reader. The uncertainty is whether the supplied completed custom task is located successfully and whether its earlier diagnostic survives output collection into the model result. Preserve normal shell-task behavior and avoid the extra-terminal workaround documented at https://github.com/microsoft/vscode-containers/issues/40#issuecomment-3156326414; do not expand the work into restoring historical attachment UI without separate evidence.
