# Issue #308013 — Web search tool is never used

[https://github.com/microsoft/vscode/issues/308013](https://github.com/microsoft/vscode/issues/308013)

## Summary

Valid feature gap: web search tool works in Copilot CLI but is not available in the standard VS Code Copilot chat experience. Team member filed, still unresolved on main — Anthropic BYOK and Codex have web search support, but the main Copilot chat path does not.

## Change summary

The web search tool is available in Copilot CLI but never invoked in VS Code's Copilot chat, forcing users to use fetch as a workaround.

## Best solution

Implement a web search tool for the standard Copilot chat path in VS Code (non-BYOK, non-Codex), likely by wiring through the same CAPI-exposed or GH MCP web search capability that the CLI uses. The work likely touches `extensions/copilot/src/extension/chatSessions/` and the tool registration layer.
