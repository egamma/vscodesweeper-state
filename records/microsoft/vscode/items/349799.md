# Issue #349799 — Worktree Cleanup shows SSH hosts as an encoded hex-… string instead of the host name

[https://github.com/microsoft/vscode/issues/349799](https://github.com/microsoft/vscode/issues/349799)

## Summary

Confirmed in current source: Worktree Cleanup displays raw URI authorities in titles, confirmations, and screen-reader labels instead of friendly SSH host names. Keep open; the related test plan and broader worktree UX issue do not replace this concrete defect.

## Change summary

Display friendly remote host names consistently throughout Worktree Cleanup, including unlinked worktrees and accessible labels.

## Best solution

Worktree Cleanup should identify remote worktrees using their configured host names across rows, workspace labels, and cleanup confirmations, while preserving authority-based identity and cleanup targeting.
