# Issue #328188 — Local chat session missing from Sessions list after Windows restart

[https://github.com/microsoft/vscode/issues/328188](https://github.com/microsoft/vscode/issues/328188)

## Summary

Current main confirms the persistence gap: workspace-less local chats retain their transcript, but the Sessions provider refuses to persist their list metadata. Route this to the Agents window/chat owners for recovery and restart coverage.

## Change summary

A local chat created in an empty window disappears from the Sessions list after restart despite its transcript remaining on disk.

## Best solution

Allow local-session registry entries without a working directory and restore them with an undefined workspace in `localChatSessionsProvider.ts`. Also reconcile existing unregistered transcripts so affected users recover sessions already omitted from `sessions.localChat.sessions`.
