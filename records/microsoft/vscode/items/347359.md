# Issue #347359 — Chat terminal auto-approval: suggest tool/script-scoped pnpm rules, including with --dir

[https://github.com/microsoft/vscode/issues/347359](https://github.com/microsoft/vscode/issues/347359)

## Summary

The requested suggestion granularity is missing from current source. Keep this open as a feature request: existing custom rules provide a workaround, but neither they nor the related agent-host parity issue cover the requested dropdown behavior.

## Change summary

Offer tool/script-specific package-manager approval suggestions that retain an explicit package directory while allowing target filenames to vary.

## Best solution

Extend approval suggestions to recognize package-manager tools, scripts, and directory-valued options without broadening the selected grant. Preserve existing approval checks, and treat cross-directory grants as a separate follow-up.
