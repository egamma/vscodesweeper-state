# Issue #336739 — Electron Script Fails with ERR_UNKNOWN_FILE_EXTENSION on Node.js

[https://github.com/microsoft/vscode/issues/336739](https://github.com/microsoft/vscode/issues/336739)

## Summary

Confirmed from source: the `electron` npm script in package.json runs `node build/lib/electron.ts` without the `--experimental-strip-types` flag that sibling scripts (`precommit`, `gulp`, `mock-policy-server`) all use, so it fails on Node versions where TS stripping isn't unflagged. An open PR already fixes this, so keep it open for that PR to land rather than closing or auto-fixing here.

## Change summary

`npm run electron` / `scripts/test.bat` fail with ERR_UNKNOWN_FILE_EXTENSION because the `electron` script lacks the `--experimental-strip-types` flag other TS-invoking scripts use.

## Best solution

Land the linked fix PR https://github.com/microsoft/vscode/pull/336740, which adds `--experimental-strip-types` to the `electron` script in package.json, matching the pattern already used by `precommit`, `gulp`, and `mock-policy-server`.
