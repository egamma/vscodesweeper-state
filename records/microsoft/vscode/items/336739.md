# Issue #336739 — Electron Script Fails with ERR_UNKNOWN_FILE_EXTENSION on Node.js

[https://github.com/microsoft/vscode/issues/336739](https://github.com/microsoft/vscode/issues/336739)

## Summary

Reproducible: package.json's `electron` script (`node build/lib/electron.ts`) omits the `--experimental-strip-types` flag needed to run a raw `.ts` file on Node versions where type-stripping isn't yet unflagged, and an open PR already proposes the exact fix — so this stays open pending that PR landing, not a new investigation.

## Change summary

`npm run electron` (and scripts that shell out to it, e.g. scripts/test.bat) throws ERR_UNKNOWN_FILE_EXTENSION on Node.js 22.17.0 because the script invokes `node build/lib/electron.ts` directly without a flag enabling `.ts` execution.

## Best solution

Land the already-open fix PR (or an equivalent) that adds `--experimental-strip-types` to the `electron` script in package.json so it runs correctly on Node versions where type-stripping isn't unflagged by default; repo's `.nvmrc` already pins 24.18.0 where this isn't needed, but the flag makes the script robust for contributors on other supported Node majors.
