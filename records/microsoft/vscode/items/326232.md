# Issue #326232 — Restore Remote-SSH support for 32-bit ARM Linux (armv7l) targets

[https://github.com/microsoft/vscode/issues/326232](https://github.com/microsoft/vscode/issues/326232)

## Summary

This is a Remote-SSH regression (server build dropping ARM32/armv7l support), which is owned by the microsoft/vscode-remote-release tracker, not microsoft/vscode core — per repo topology conventions this should be moved to that tracker rather than closed here, and an open issue there (#11698) already covers the same root problem.

## Change summary

Since VS Code 1.86 removed the Linux ARM32 (armv7l) remote server build, Remote-SSH can no longer connect to 32-bit ARM devices like Raspberry Pi running armv7l OS images.

## Best solution

Move this issue to microsoft/vscode-remote-release (the Remote-SSH extension's own tracker), where an open issue (#11698) already tracks the ARM32/armv7l server-build regression; a maintainer decision on restoring or providing a legacy ARM32 server build belongs there.
