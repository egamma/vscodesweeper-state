# Issue #326232 — Restore Remote-SSH support for 32-bit ARM Linux (armv7l) targets

[https://github.com/microsoft/vscode/issues/326232](https://github.com/microsoft/vscode/issues/326232)

## Summary

The ARM32 (armv7l) server build was intentionally removed in commit be5fa40f88a because Node.js v24 dropped 32-bit Linux ARM support — the server literally cannot run on that platform. This is a deliberate, upstream-driven decision, not a regression to fix. Reinstating the build is not feasible without a Node.js runtime that supports it.

## Change summary

Request to restore the ARM32 (armv7l) VS Code Server build so Remote-SSH can connect to 32-bit ARM Linux devices.

## Best solution

This is out of scope for VS Code core: Node.js v24 dropped armv7l support, making it impossible to build a current server for that platform. Users on 32-bit ARM devices should consider migrating to a 64-bit OS image where possible, or use the frozen 1.122.1 workaround the reporter identified.

## Vision fit

- **Fit:** rejected
- **Reason:** Restoring a platform build that the upstream runtime no longer supports conflicts with the value of keeping VS Code lightweight and performant — maintaining a custom fork or backport of Node.js for a niche platform is not aligned with the project's direction.
- **Evidence:** Value: 'Performance trumps functionality.' Durable theme: Remote development investment focuses on supported platforms. Maintaining a dead upstream dependency for a niche architecture cuts against both.
