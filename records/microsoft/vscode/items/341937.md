# Issue #341937 — Copilot "Local" mode is missing in VS Code 1.142.0 

[https://github.com/microsoft/vscode/issues/341937](https://github.com/microsoft/vscode/issues/341937)

## Summary

Keep open as feedback on the enterprise harness transition: maintainers confirmed that Local is intentionally hidden under managed permission policies, but the discussion explicitly requests reconsidering that default. The administrator-only compatibility setting does not restore independent user choice.

## Change summary

Preserve access to the Local harness during the enterprise transition rather than removing it automatically when managed permission settings are present.

## Best solution

Have the agent-host owners settle the transition contract for existing enterprise users, including whether retaining Local requires administrator opt-in and how that restriction is communicated. Preserve runtime policy enforcement; do not treat ordinary user preference settings as an equivalent workaround.
