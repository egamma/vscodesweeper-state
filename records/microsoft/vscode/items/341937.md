# Issue #341937 — Copilot "Local" mode is missing in VS Code 1.142.0 

[https://github.com/microsoft/vscode/issues/341937](https://github.com/microsoft/vscode/issues/341937)

## Summary

Keep open as feedback on the enterprise harness transition: the missing Local option follows intentional policy routing, but the thread explicitly requests preserving that choice and maintainers have acknowledged the rollout concerns. The administrator-only temporary override does not resolve the request for continued user choice.

## Change summary

Preserve access to the Local harness, or provide a clearer and less disruptive transition when enterprise policies require Copilot Agent Host.

## Best solution

Have the Agent Host owners settle the supported Local transition and selection contract, then make policy-driven availability understandable in the harness picker. Preserve enterprise enforcement; the existing temporary administrator override is a transition mechanism, not a permanent answer to the requested choice.
