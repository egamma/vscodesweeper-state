# Issue #13953 — Feature Request: Show all errors and warnings in project for all JavaScript and TypeScript files, not just opened ones

[https://github.com/microsoft/vscode/issues/13953](https://github.com/microsoft/vscode/issues/13953)

## Summary

Highly upvoted (1500+) feature request for project-wide diagnostics in the Problems panel. An experimental setting exists (`js/ts.tsserver.experimental.enableProjectDiagnostics`) but remains off by default and has known issues — the core ask for a robust, non-experimental implementation is still unmet.

## Change summary

Show all TypeScript/JavaScript errors and warnings across the entire project in the Problems panel, not just for opened files.

## Best solution

Graduate `enableProjectDiagnostics` from experimental to stable, resolving the known performance and correctness issues (stale diagnostics on file deletion, node_modules noise). This likely requires coordination with TypeScript server team on scalable project-wide diagnostic delivery.
