## Summary

Feature request to load fonts by file path rather than OS-installed font name. No traction (0 upvotes in 966 days), very niche, and technically complex (would require custom @font-face injection from arbitrary paths). ## Change summary

Allow editor.fontFamily to accept font file paths or filenames for fonts not installed in the OS.

## Best solution

This is a niche request that conflicts with how CSS font-family resolution works in Electron/Chromium. The most practical path would be an extension using @font-face injection via the webview API or a custom CSS loader extension, rather than core support. If demand materializes, the community process will promote it.
