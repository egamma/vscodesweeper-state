# Issue #199858 — I want to set font file names or filepaths into `editor.fontFamily`

[https://github.com/microsoft/vscode/issues/199858](https://github.com/microsoft/vscode/issues/199858)

## Summary

A real capability gap remains: current main treats `editor.fontFamily` strictly as a CSS font-family name and cannot load a font from a file path. This issue was explicitly placed in the Backlog and marked under discussion after similar older reports were closed, so it should remain open for a product and security decision.

## Change summary

Allow the editor font to be selected by an absolute font filename or path, including fonts that are not installed in the operating system.

## Best solution

Decide whether VS Code should safely support file-backed editor fonts, likely through a dedicated mechanism that loads a local font while preserving existing `editor.fontFamily`, web, remote, and workspace-trust behavior.
