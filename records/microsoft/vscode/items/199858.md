# Issue #199858 — I want to set font file names or filepaths into `editor.fontFamily`

[https://github.com/microsoft/vscode/issues/199858](https://github.com/microsoft/vscode/issues/199858)

## Summary

Keep open under the existing font-area triage: current editor font configuration selects CSS font families, not individual font files, so the requested capability remains missing. No verified older open canonical was found; the similar earlier request was closed for insufficient votes, not implemented.

## Change summary

Allow selecting an editor font by filename or absolute path without requiring OS installation, including fonts sharing the same internal family name.

## Best solution

Retain this as the focused discussion of file-backed editor font selection in workbench-fonts. Any accepted design should support uninstalled local fonts and distinguish files with identical family metadata while preserving existing font-family lists and fallbacks.

This path provides family selection, not loading or identifying a font by file path.
