# Issue #297308 — Chat: It's easy to accidentally enable editing all sensitive files

[https://github.com/microsoft/vscode/issues/297308](https://github.com/microsoft/vscode/issues/297308)

## Summary

Keep open: current main still makes “Allow in this Session” a tool-wide grant rather than limiting it to the sensitive file named in the prompt. The issue is security-sensitive and maintainers have already accepted that the scope and presentation need correction.

## Change summary

Prevent users from accidentally granting session-wide edit permission for every sensitive file when approving one sensitive-file edit.

## Best solution

Keep distinct “Allow Once” and session approval actions, but make the safer one-time action lead and state the session action’s scope plainly. For sensitive-file edits, session approval should apply to the specific file or exact tool-and-arguments combination rather than silently authorizing the edit tool for every sensitive file.
