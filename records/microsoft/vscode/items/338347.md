# Issue #338347 — New Chats in an existing session don't persist unsubmitted prompts

[https://github.com/microsoft/vscode/issues/338347](https://github.com/microsoft/vscode/issues/338347)

## Summary

Team-authored bug report (found while testing in-flight PR #337849) filed the same day it's reported; no fix commit references this issue yet, so it must stay open regardless.

## Change summary

When a user opens a new chat within an existing Agents session, types an unsubmitted prompt, switches to another chat and back, the prompt text is lost instead of being preserved.

## Best solution

Likely belongs in the new-chat/session composer state handling (src/vs/sessions/contrib/chat/browser/newChatInput.ts or the session multi-chat controller) — persist per-chat draft input the same way the main chat widget already preserves unsent input across view switches.
