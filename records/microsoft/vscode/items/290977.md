# Issue #290977 — Easier way to clean up leftover terminals from chat sessions

[https://github.com/microsoft/vscode/issues/290977](https://github.com/microsoft/vscode/issues/290977)

## Summary

Keep open: the hidden-terminal picker still only reveals terminals; it offers no cleanup action. The existing kill-all button addresses bulk cleanup outside the picker, but the author explicitly acknowledged it and retained the picker request.

## Change summary

Allow users to clean up leftover chat terminals directly from the hidden-terminal picker without revealing each terminal first.

## Best solution

Provide cleanup within the hidden-terminal picker while preserving its existing reveal action and terminal-disposal safeguards. Settle whether the picker should offer individual deletion, bulk deletion, or both; keep terminal creation and visibility policy outside this issue.
