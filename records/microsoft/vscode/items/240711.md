# Issue #240711 — Missing border under window buttons when the application window is maximized

[https://github.com/microsoft/vscode/issues/240711](https://github.com/microsoft/vscode/issues/240711)

## Summary

The reporter confirmed a repeatable fractional-scaling defect on Windows 11 24H2 in both Stable and Insiders. It remains a valid, correctly routed visual bug; current source inspection does not establish a fix or justify closing it.

## Change summary

The title-bar bottom border disappears beneath the Windows caption buttons at certain non-100% Accessibility Text Size values while the window is maximized.

## Best solution

Preserve a device-pixel-aligned title-bar border across the full maximized window width, including beneath the native window-controls region, for fractional Windows accessibility text scaling.
