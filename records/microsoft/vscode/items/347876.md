# Issue #347876 — Integrated browser: support window.prompt()

[https://github.com/microsoft/vscode/issues/347876](https://github.com/microsoft/vscode/issues/347876)

## Summary

Keep open for the preload investigation explicitly supported by a maintainer. The integrated browser lacks a window.prompt() implementation; the related webview modal request concerns a different embedding boundary.

## Change summary

Support pages that call window.prompt() in the integrated browser.

## Best solution

Investigate whether the integrated browser can provide compatible synchronous prompt behavior despite Electron's limitation, preserving existing alert() and confirm() behavior and page isolation.
