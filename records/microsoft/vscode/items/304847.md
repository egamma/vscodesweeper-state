# Issue #304847 — Add ability to hide extension contributed agents / customizations from Customizations window

[https://github.com/microsoft/vscode/issues/304847](https://github.com/microsoft/vscode/issues/304847)

## Summary

Keep open: Configure Custom Agents now opens the Customizations editor, but that editor still lacks hide/restore controls for extension-contributed agents. A maintainer explicitly endorsed bringing the existing picker capability into this UI; no verified canonical covers the same remaining request.

## Change summary

Manage visibility of extension-contributed agents and customizations from the Customizations editor instead of a separate quick pick.

## Best solution

Provide reversible agent hide/restore controls in the Customizations editor, reflecting the existing prompt enablement state and agent dropdown behavior. Preserve the already-implemented Configure Custom Agents navigation, and settle the scope for other customization types before expanding it.

- **Behavior:**

Configure Custom Agents opens this management surface, which current main already does. Other contributed agents and unrelated extension functionality remain unchanged.
