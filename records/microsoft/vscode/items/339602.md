# Issue #339602 — The `select available tools for chat` button disappeared after 1.140.0

[https://github.com/microsoft/vscode/issues/339602](https://github.com/microsoft/vscode/issues/339602)

## Summary

The reporter is on the new, intentionally-simplified 'Copilot' agent harness being rolled out — the tool picker and Ask mode are hidden there by design, but the old experience is still available by switching the session picker to the 'Local' harness, as another commenter already confirmed. This is a support/how-to question, not a bug.

## Change summary

After 1.140.0 the 'select available tools' button and Ask mode are missing, leaving only Agent mode.

## Best solution

Point the reporter at switching the harness/session-type picker to 'Local' (as the existing comment does) to get the tool picker and Ask mode back; no code change needed since the old harness remains available by design.
