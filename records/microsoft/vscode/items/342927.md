# Issue #342927 — Agent host: "Full message received: 0 chars" info log is ~20% of host log volume and hides empty responses

[https://github.com/microsoft/vscode/issues/342927](https://github.com/microsoft/vscode/issues/342927)

## Summary

The reported logging debt remains on current main: every assistant message emits an info-level character count before tool requests, chunk boundaries, or synthetic messages are considered. Keep this open for a bounded logging cleanup that reduces routine noise and distinguishes genuinely empty model responses.

## Change summary

Reduce tool-only assistant-message logging to trace and retain useful response metadata and distinct empty-response diagnostics.

## Best solution

Make CopilotAgentSession response logs distinguish routine tool-only messages from text-bearing and genuinely empty model responses, with available agent, model, token, and request-correlation metadata. Preserve existing message processing and avoid false empty-response diagnostics for synthetic messages or partial chunk sequences.
