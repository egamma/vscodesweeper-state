## Summary

Team-authored issue tracking a known flaky integration test in the Agent Host Provider customizations suite. The related fix PR #327448 was closed without merging, so the flakiness remains unresolved on main.

## Change summary

The 'watch skill file changes [scan]' integration test flakily times out because recursive file watchers on macOS CI VMs sometimes miss content-only changes to deeply nested SKILL.md files.

## Best solution

Land a fix that adds non-recursive watchers on skill subdirectories (as PR #327448 attempted), or adjust the test's watcher setup to be more reliable on macOS CI. The fix likely lives in `src/vs/platform/agentHost/node/` (the scan-root watcher logic) and the test in `src/vs/platform/agentHost/test/node/protocol/copilotCustomizations.integrationTest.ts`.
