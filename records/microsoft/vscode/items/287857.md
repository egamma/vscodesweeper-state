# Issue #287857 — New background agent sessions defaulting to workspace

[https://github.com/microsoft/vscode/issues/287857](https://github.com/microsoft/vscode/issues/287857)

## Summary

Keep open to settle consistent isolation defaults for newly created background sessions. Current source explicitly falls back to Workspace and remembers a global picker preference; existing worktree sessions do not by themselves establish that preference.

## Change summary

Make new background agent sessions select Worktree consistently when working in a Git repository and already using worktree-isolated agents.

## Best solution

Define how new background chats should derive their isolation default, including whether recent worktree use should override an older explicit Workspace preference. Apply the agreed behavior consistently across background-session creation paths while preserving explicit choices and non-Git restrictions.
