## Summary

Still open on main — no commit references this issue and no related fix to the notebook cell scroll-anchor behavior when inline chat expands near the top of the viewport was found. The bug remains valid.

## Change summary

Opening inline chat near the top of a notebook editor pushes cell content above the scrollable viewport, making it unreachable.

## Best solution

When the inline chat zone widget expands within a cell near the top of the notebook, the notebook scroll position should be adjusted (scroll anchor) so that the content above the widget remains visible and scrollable. The fix likely lives in the cell height-change handling in `src/vs/workbench/contrib/notebook/browser/view/cellParts/codeCell.ts` or the notebook list's scroll-anchor logic in `src/vs/workbench/contrib/notebook/browser/notebookCellList.ts`.
