# Issue #329143 — "Scroll to explore" affordance is unclear and seems buggy

[https://github.com/microsoft/vscode/issues/329143](https://github.com/microsoft/vscode/issues/329143)

## Summary

Current main confirms the ambiguity: the affordance says “Scroll to explore,” but outside the Sessions window its callback reveals the parent response rather than the specific subagent content. This team-authored report should remain open while the intended destination is clarified and the action, label, and accessible name are made consistent.

## Change summary

The tool-confirmation carousel's “— explore” affordance has an unclear destination and can scroll to the parent response instead of clearly revealing the associated subagent.

## Best solution

Choose one consistent interaction for each host—revealing the exact inline subagent or opening its dedicated chat—and make the visible label, tooltip, accessible name, and resulting navigation accurately describe that interaction.
