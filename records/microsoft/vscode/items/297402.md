# Issue #297402 — Suggestion- all config editors in same modal

[https://github.com/microsoft/vscode/issues/297402](https://github.com/microsoft/vscode/issues/297402)

## Summary

Keep open: current main still lacks a unified Settings, Keyboard Shortcuts, and Chat Customizations modal that Cmd+, opens at the last selected tab. The existing modal and preferences infrastructure provides partial building blocks, not the requested experience; no verified canonical or explicitly linked fix was found.

## Change summary

Provide one configuration modal with Settings, Keyboard Shortcuts, and Chat Customizations tabs, accessible through Cmd+, with the last selected tab remembered.

## Best solution

Agree on a unified configuration entry point in the preferences/editor area that exposes all three surfaces and restores the selected tab. Preserve explicit settings and keybindings commands, JSON-editor preferences, and AI-disabled hiding of Chat Customizations.
