# Issue #344495 — SDK Feature request: Allow dend_message to send instantly

[https://github.com/microsoft/vscode/issues/344495](https://github.com/microsoft/vscode/issues/344495)

## Summary

Keep open as a feature request: send_message supports queueing and steering, but neither provides the UI's cancel-and-send-immediately behavior for an active target chat.

## Change summary

Expose immediate, high-priority cross-session message delivery equivalent to the pending-message UI's Send Immediately action.

## Best solution

Consider an explicit immediate-delivery capability in the Agent Host messaging tool, preserving ordinary queueing and steering. Its observable behavior should match the existing UI action rather than treating provider steering as equivalent.
