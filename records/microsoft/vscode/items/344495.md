# Issue #344495 — SDK Feature request: Allow dend_message to send instantly

[https://github.com/microsoft/vscode/issues/344495](https://github.com/microsoft/vscode/issues/344495)

## Summary

Keep open as a feature request: send_message supports queueing and steering, but neither provides the stop-and-send behavior of the UI's Send Immediately action. The existing steering capability does not fully cover this request.

## Change summary

Expose immediate, interrupting delivery for messages sent between agent sessions, equivalent to the UI's Send Immediately action.

## Best solution

Have the Agent Host area evaluate an explicit stop-and-send delivery capability for inter-session messaging, preserving existing queue and steer semantics. Reuse the current tool where appropriate rather than requiring a separate tool solely for discoverability.

  > Thanks for the request. The current `send_message` tool supports `delivery: "steer"` to update an active turn without waiting for it to finish. That differs from **Send Immediately**, which cancels the current request and sends the selected message as a new turn, so exposing that stop-and-send behavior remains a feature request.
