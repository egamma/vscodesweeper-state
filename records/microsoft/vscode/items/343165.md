Keep open: the reporter confirmed creation-order rebuilding on 1.143.0, and current source delegates merging to native macOS behavior without preserving existing tab order. The related restart-restoration issue does not own this interactive merge problem.

## Change summary

Preserve manually arranged native-tab groups when merging additional macOS windows, rather than rebuilding their tabs in window-creation order.

Any solution must cover both the Window menu and command invocation, including when a newly opened standalone window has focus.
