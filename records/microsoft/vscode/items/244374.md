# Issue #244374 — Cannot read properties of null (reading 'uri')

[https://github.com/microsoft/vscode/issues/244374](https://github.com/microsoft/vscode/issues/244374)

## Summary

Still present on main: in `_removeAllDecorations`, `editor.getModel()` can return null at line 463 after `editor.removeDecorations()` on line 462 triggers events that detach the model, despite the `hasModel()` guard at line 453. Similarly, `_removeSingleDecorations` at line 440 accesses `this.editor.getModel().uri` without re-checking after `removeDecorations` on line 439.

## Change summary

WordHighlighter crashes with 'Cannot read properties of null (reading uri)' when `editor.getModel()` returns null after decoration removal triggers model detachment.

## Best solution

Cache the model URI before calling `removeDecorations` in both `_removeAllDecorations` (lines 457–463) and `_removeSingleDecorations` (lines 434–440), so subsequent accesses don't depend on the model still being attached. The fix is a small, localized null-safety improvement in `wordHighlighter.ts`.
