# Issue #23957 — [Feature] Option to disable cmd+click trigger for goToDefinition

[https://github.com/microsoft/vscode/issues/23957](https://github.com/microsoft/vscode/issues/23957)

## Summary

Keep open: current source still lacks an independent way to disable modifier-click definition navigation without replacing it with multicursor behavior. This accepted Backlog request has 64 upvotes and an open implementation proposal that needs a maintainer's disposition.

## Change summary

Allow users to disable or independently rebind Cmd/Ctrl+click Go to Definition so it does not interfere with text selection and copying.

## Best solution

Provide an opt-out from modifier-click definition navigation while preserving keyboard navigation and existing defaults. Review the scope and disposition of https://github.com/microsoft/vscode/pull/130215, whose word-selection option addresses part of the requested workflow but remains unmerged.
