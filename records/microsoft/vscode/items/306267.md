# Issue #306267 — Stale task output captured switching configurations with terminals reuse

[https://github.com/microsoft/vscode/issues/306267](https://github.com/microsoft/vscode/issues/306267)

## Summary

Keep open: current source resolves previously captured task variables before running the newly selected preLaunchTask, preserving the old URL in the launch configuration. This team-authored verification follow-up has no verified fix or qualifying duplicate.

## Change summary

Switching debug configurations should use the selected background task's captured URL rather than a previous task's value.

## Best solution

Ensure task-dependent launch values reflect the selected preLaunchTask's output before the debug adapter receives the configuration, while preserving variable resolution needed to select and start that task. Also verify the restart example's latest-value expectation separately from the stale previous-task defect.
