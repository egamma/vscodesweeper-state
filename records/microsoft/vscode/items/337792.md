# Issue #337792 — Customizations view does not identify signed-out MCP server

[https://github.com/microsoft/vscode/issues/337792](https://github.com/microsoft/vscode/issues/337792)

## Summary

Confirmed on current main: the MCP authentication action visibly says only “Sign In”; the server name is available only through its tooltip/ARIA label and neighboring row content. Route this bounded UI bug to MCP management.

## Change summary

Make the signed-out MCP server’s visible authentication action identify the server it will authenticate.

## Best solution

The Customizations view should visibly name the affected server in its idle sign-in action, including after an authentication attempt resets, while preserving the contextual accessible label and existing pending-state behavior.
