# Issue #342331 — hooks cannot find scripts in WSL because PLUGIN_ROOT is expanded in the wrong format (mixed / and \)

[https://github.com/microsoft/vscode/issues/342331](https://github.com/microsoft/vscode/issues/342331)

## Summary

Keep open: current source still expands plugin roots using the parsing process's platform, which can disagree with the remote execution environment. The versioned plugin and reproduction steps suffice to retest; the Windows-to-WSL execution path has not been confirmed end to end.

## Change summary

Resolve plugin hook script paths in the execution environment's filesystem format when using the Local harness with WSL or SSH.

## Best solution

Ensure plugin hook commands and plugin-root environment variables identify the installed plugin correctly on the execution host, while preserving native Windows behavior and shell quoting. Investigate the plugin parsing and remote hook handoff together rather than treating slash replacement alone as sufficient.
