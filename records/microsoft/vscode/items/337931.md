# Issue #337931 — multi-repo chats changes change depending on focus

[https://github.com/microsoft/vscode/issues/337931](https://github.com/microsoft/vscode/issues/337931)

## Summary

Freshly filed, specific repro with an attached video from a contributor: a session's shown "changes" list appears to include a child/other worktree's changes until the session is focused, then narrows to just its own changes. Routing to the chat/Agents Sessions area for triage since it's brand new and unconfirmed by anyone else yet.

## Change summary

In multi-repo/worktree agent sessions, the changes shown for a session incorrectly include a different (child) chat's changes until that session gets focus, at which point it correctly shows only its own changes.

## Best solution
