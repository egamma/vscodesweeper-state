# Issue #337931 — multi-repo chats changes change depending on focus

[https://github.com/microsoft/vscode/issues/337931](https://github.com/microsoft/vscode/issues/337931)

## Summary

The focus-dependent count is directly reproducible in current source: a multi-repository session row switches from session-wide aggregate changes to the main chat's branch changes when that chat becomes active. This recent team-authored bug should remain open for a focused fix.

## Change summary

Keep a multi-repository session's displayed change statistics stable when focus moves into that session or between its chats.

## Best solution

The session row should retain session-level aggregate change statistics regardless of which chat has focus, while the Changes detail surface may continue showing the explicitly selected chat or changeset.
