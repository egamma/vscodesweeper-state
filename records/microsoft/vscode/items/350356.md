# Issue #350356 — Agent feedback: Submit to a chat that loaded the session late hangs or sends no comments (non-agent-host sessions)

[https://github.com/microsoft/vscode/issues/350356](https://github.com/microsoft/vscode/issues/350356)

## Summary

The late-loaded-widget failure remains in current source: Add and Submit can wait indefinitely, while ordinary Submit can resolve comments without attaching them. Keep this open for a bounded fix to non-agent-host feedback submission.

## Change summary

Reliably submit the intended pending feedback when a non-agent-host chat widget loads after feedback was added.

## Best solution

Non-agent-host feedback submission should deliver exactly the comments pending at submission, independently of reactive attachment timing, and leave undelivered comments retryable. Preserve agent-host submission and ordinary chat attachment behavior.
