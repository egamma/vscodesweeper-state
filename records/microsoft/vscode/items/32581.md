# Issue #32581 — Add Opacity & Variable Height to Minimap

[https://github.com/microsoft/vscode/issues/32581](https://github.com/microsoft/vscode/issues/32581)

## Summary

Opacity controls have shipped, but the variable-height container and hit-target request remains open and is confirmed by current source. With 49 upvotes and a Backlog milestone, this should remain the canonical feature request.

## Change summary

Allow a transparent minimap whose container and interactive area only extend as far as the rendered content in short files.

## Best solution

Retain the existing `minimap.background` and `minimap.foregroundOpacity` controls, then add a minimap mode that limits the overlay and pointer target to rendered content height for short files without changing long-file scrolling behavior.
