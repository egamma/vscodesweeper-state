# Issue #301533 — Impossible to download or install any extensions

[https://github.com/microsoft/vscode/issues/301533](https://github.com/microsoft/vscode/issues/301533)

## Summary

The March 2026 failure was a confirmed VS Marketplace service regression rather than an extension-extraction defect in VS Code: Marketplace maintainers reverted the responsible rate-limiting change and users confirmed recovery. Policy keeps upstream/service-owned incidents open, and there is no VS Code fixing commit or current reproduction attempt supporting a factual close.

## Change summary

Extension installation failed because downloaded responses were not valid VSIX ZIP archives and consequently failed during extraction.

## Best solution

Keep extension downloads reliable at the VS Marketplace/CDN layer and ensure service errors never arrive as apparent VSIX payloads. The separate client-hardening case for gzip-encoded VSIX responses remains tracked by https://github.com/microsoft/vscode/issues/314359, but that younger and narrower report cannot serve as the canonical duplicate for this re-reviewed item.
