# Issue #77138 — ability to get/set currently selected debug configuration

[https://github.com/microsoft/vscode/issues/77138](https://github.com/microsoft/vscode/issues/77138)

## Summary

Keep this accepted API request open: extensions still lack a supported way to read, change, and observe the selected launch configuration without starting debugging. An existing open implementation PR should receive maintainer review rather than spawning competing work.

## Change summary

Expose an extension API to get and set the selected debug configuration and receive selection-change notifications.

## Best solution

Review https://github.com/microsoft/vscode/pull/271799 and settle the public API contract so extensions can synchronize their own configuration selectors with Run and Debug, independently of an active debug session.

## Evidence

- **Existing capability does not cover the request:** src/vscode-dts/vscode.d.ts:17290–17405 exposes debug.activeDebugSession, session lifecycle events, and debug.startDebugging, but no selected-launch-configuration getter, setter, or change event. An active debug session is distinct from the configuration selected before starting a session.
- **Selection exists internally:** src/vs/workbench/contrib/debug/browser/debugConfigurationManager.ts:397–418 provides selectedConfiguration, onDidSelectConfiguration, and selectConfiguration internally. The requested state therefore exists in the workbench but is not exposed through the inspected public debug API.
- **Command workaround is incomplete:** src/vs/workbench/contrib/debug/browser/debugCommands.ts registers workbench.action.debug.selectandstart, whose handler selects a configuration and starts debugging. That does not provide independent programmatic selection, reading, or selection-change notification.
- **Open implementation candidate:** Verified https://github.com/microsoft/vscode/pull/271799 is OPEN, not a draft, and has no merge timestamp. Its body explicitly references this issue and proposes vscode.debug.configuration, setConfiguration, and onDidChangeConfiguration; it also identifies API naming as requiring an official decision. The contributor's February 2026 comment points to this existing implementation effort.
- **Established use cases and demand:** The discussion on https://github.com/microsoft/vscode/issues/77138 requests synchronization with an extension-owned selector, per-file launch selection, selection-change notifications, and preselection after Docker scaffolding. The issue has 34 upvotes and was promoted to Backlog in August 2022.
