## Summary

Keep this open as the tracker for recurring upstream failures in the live Copilot Chat sanity tests. The merged mitigation reduces build failures and improves diagnostics but explicitly does not fix the underlying flake, and maintainers consider the test too valuable to remove.

## Change summary

The Copilot Chat sanity suite intermittently receives no usable progress from the live model endpoint, causing agent-mode and slash-command integration tests to fail.

## Best solution

Retain the high-value production sanity coverage and use its retries and enriched diagnostics to distinguish transient model-service failures from VS Code regressions. Recurring signatures can then be hardened individually without treating the mitigation as a complete fix.
