# Issue #157633 — Extensions list is empty on a disconnected window bug report screen

[https://github.com/microsoft/vscode/issues/157633](https://github.com/microsoft/vscode/issues/157633)

## Summary

Keep open: a maintainer confirmed the disconnected-window reproduction, and current source still discards usable local extension results when remote enumeration fails. The reporter has since gained wizard and legacy paths, but neither preserves the actual extension choices on this failure.

## Change summary

Keep available local extensions selectable in the Issue Reporter after a remote connection disconnects.

## Best solution

The Issue Reporter should retain successfully enumerated local extensions when the remote server is unavailable, without changing error semantics for unrelated extension-management callers. Both wizard and legacy reporters should support this degraded state.
