# Issue #331633 — MCP app webview CSP missing worker-src - blocks blob-based Web Workers (e.g. MapLibre)

[https://github.com/microsoft/vscode/issues/331633](https://github.com/microsoft/vscode/issues/331633)

## Summary

Confirmed in source: the MCP app webview CSP built in `_injectPreamble` (chatMcpAppModel.ts) lists default-src/script-src/style-src/connect-src/img-src/font-src/media-src/frame-src/object-src/base-uri but no worker-src, so blob:-based Web Workers (e.g. MapLibre GL JS) are blocked by the script-src fallback. A fix PR is already open from the reporter.

## Change summary

MCP app webview's injected CSP omits worker-src, blocking blob-based Web Workers used by some MCP UI resources (e.g. MapLibre GL JS basemap tiles).

## Best solution

Land the reporter's own PR https://github.com/microsoft/vscode/pull/332264, which adds a worker-src 'self' blob: directive to the CSP built in _injectPreamble; a maintainer should review and merge it (or decide whether to scope it to resourceDomains as the author offered).
