# Issue #309282 — Copy Line Up/Down commands do not preserve more than two multi-cursors on the same line

[https://github.com/microsoft/vscode/issues/309282](https://github.com/microsoft/vscode/issues/309282)

## Summary

Confirmed bug: the deduplication loop in AbstractCopyLinesAction only tracks a single `prev` winner, so with 3+ cursors on the same line all but one are marked `ignore` and their cursor positions are lost after the copy. An open PR (#312513) is in flight to fix this — keeping open until it merges.

## Change summary

Copy Line Up/Down drops cursors beyond the second when multiple cursors sit on the same line.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/312513 which preserves all multi-cursors through the copy-lines deduplication logic, then verify the fix with a test covering 3+ same-line cursors.
