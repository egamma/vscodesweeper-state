# Issue #309282 — Copy Line Up/Down commands do not preserve more than two multi-cursors on the same line

[https://github.com/microsoft/vscode/issues/309282](https://github.com/microsoft/vscode/issues/309282)

## Summary

The defect is conclusively present on current main, but an open PR already references and fixes this issue. Keep the issue open while that human-owned implementation is reviewed.

## Change summary

Copy Line Up and Copy Line Down discard all but two cursors when three or more cursors occupy the same source line.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/312513, whose targeted change gives ignored per-cursor commands distinct no-op ranges and adds end-to-end regression coverage for three and four cursors.
