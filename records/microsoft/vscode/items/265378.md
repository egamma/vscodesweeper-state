# Issue #265378 — Update assignment service change event to track queried treatments

[https://github.com/microsoft/vscode/issues/265378](https://github.com/microsoft/vscode/issues/265378)

## Summary

This team-authored Backlog debt remains outstanding: the assignment service still emits an uninformative `Event<void>` rather than reporting which previously queried treatments changed. The protected team-authored and accepted-Backlog rules require keeping it open.

## Change summary

Track queried treatment values in the core assignment service and include affected treatment names when assignments change.

## Best solution

Bring the core assignment service change event in line with the existing Copilot experimentation behavior: retain values only for treatments callers queried, compare them after assignment updates, and report only affected treatment names while preserving existing refetch consumers.
