## Change summary

In the Agents window single-pane layout, resizing the right panel below a certain width sometimes causes the panel to show the Search view instead of the Files list, and this state can persist even after switching tabs; using Toggle Side Panel to close/reopen restores the Files list correctly.

## Best solution

Belongs in src/vs/sessions/contrib/layout/browser/baseSessionLayoutController.ts (or the sibling desktop/web layout controllers) where single-pane resize logic decides which view to show — likely a stale/incorrect active-view restoration when the panel crosses a narrow-width threshold during resize. Needs a maintainer or the reporter to pin down the exact resize threshold logic before a fix lands.
