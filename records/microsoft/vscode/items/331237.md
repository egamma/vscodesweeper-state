# Issue #331237 — Agents window single pane: Resizing can hide file list and show search instead

[https://github.com/microsoft/vscode/issues/331237](https://github.com/microsoft/vscode/issues/331237)

## Summary

Team-authored bug filed today with clear repro steps and screenshots (plus a second corroborating occurrence in the reporter's own comment); this is a real defect in the Agents window's single-pane resizing behavior that needs a fix, not a triage close — team-authored items are protected from judgment closes anyway, and there's no fix commit yet.

## Change summary

In the Agents window single-pane layout, narrowing the right panel below a certain width causes it to show the Search view instead of the Files (explorer) list, even though `Toggle Side Panel` restores the correct Files view.

## Best solution

Trace the view-container width/visibility logic in src/vs/sessions (likely the panel resize handler that decides which view is active/visible below a width threshold) so narrowing the pane doesn't implicitly switch the active view away from Files; a maintainer familiar with the new single-pane layout (from #331070) should own the fix.
