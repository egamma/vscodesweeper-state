# Issue #157407 — Neo2 Layout Keybinding wrong key used

[https://github.com/microsoft/vscode/issues/157407](https://github.com/microsoft/vscode/issues/157407)

## Summary

Keep open: the reporter traced the collision to Chromium supplying keyCode 88 for both Neo2 ö and x, and current VS Code still relies on that value in keyCode dispatch mode. Switching to code is not a complete workaround because the report also identifies broken navigation-layer Escape handling.

## Change summary

Allow distinct Neo2 ö and x keybindings on Linux without sacrificing navigation-layer keys.

## Best solution

Resolve the Chromium keyCode collision or establish a compatible VS Code mapping strategy that distinguishes the two keys while preserving Neo2 navigation-layer semantics. Retest the supplied event cases on current Linux/X11 before choosing the ownership and implementation boundary.

## Evidence

- **Reporter diagnosis:** In the discussion supplied for https://github.com/microsoft/vscode/issues/157407, the reporter records ö as code=KeyX, key=ö, keyCode=88 and x as code=KeyQ, key=x, keyCode=88. Navigation-layer Escape instead arrives as code=KeyZ, key=Esc, keyCode=27. These observations explain both the collision and why physical-code dispatch is not a complete workaround.
- **Current keyCode dispatch path:** src/vs/workbench/services/keybinding/electron-browser/nativeKeyboardLayout.ts: KeyboardLayoutService.getKeyboardMapper selects FallbackKeyboardMapper whenever keyboard.dispatch is keyCode. src/vs/base/browser/keyboardEvent.ts: extractKeyCode maps the numeric browser keyCode without consulting e.key for ordinary keydown events. src/vs/workbench/services/keybinding/common/fallbackKeyboardMapper.ts: resolveKeyboardEvent constructs the chord from keyboardEvent.keyCode, so the reported equal numeric values remain indistinguishable on this path.
- **Navigation-layer boundary:** src/vs/workbench/services/keybinding/common/macLinuxKeyboardMapper.ts:937–1002 uses physical code for normal dispatch, with keyCode overrides for arrows, editing/navigation keys and numpad keys.
