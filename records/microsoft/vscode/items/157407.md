# Issue #157407 — Neo2 Layout Keybinding wrong key used

[https://github.com/microsoft/vscode/issues/157407](https://github.com/microsoft/vscode/issues/157407)

## Summary

The investigation identifies Chromium's Linux keyboard event data as the root cause: distinct Neo2 keys can produce the same legacy `keyCode`, while physical-code dispatch breaks the layout's navigation layer. This should remain open as an upstream keyboard-layout issue rather than being closed from source inspection.

## Change summary

Neo2 on Linux cannot assign distinct bindings to X and Ö while retaining navigation-layer keys because the available keyboard dispatch modes each lose necessary key information.

## Best solution

Track the Chromium/Electron keyboard-event limitation and determine whether VS Code's keyboard mapper can safely distinguish Neo2 logical keys without regressing navigation-layer handling.
