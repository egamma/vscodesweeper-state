# Issue #157407 — Neo2 Layout Keybinding wrong key used

[https://github.com/microsoft/vscode/issues/157407](https://github.com/microsoft/vscode/issues/157407)

## Summary

The root cause is Chromium reporting incorrect keyCodes for the Neo2 keyboard layout on Linux — an upstream issue in the Chromium engine that VS Code cannot fix in isolation. Keeping open as upstream.

## Change summary

Neo2 keyboard layout keybindings on Linux use wrong keyCodes because Chromium reports identical keyCode values for different Neo2 keys (e.g. ö and x both report keyCode 88).

## Best solution

Track as an upstream Chromium/Electron defect. A workaround would require Chromium to correctly distinguish Neo2 remapped keys in its key event model, or VS Code would need a Linux-specific Neo2 keymap override that compensates for the incorrect codes — but neither has been implemented and no Chromium bug fix is in sight.
