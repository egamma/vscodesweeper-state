# Issue #275338 — `/savePrompt` should more clearly reveal created prompt

[https://github.com/microsoft/vscode/issues/275338](https://github.com/microsoft/vscode/issues/275338)

## Summary

The discoverability problem remains relevant after `/savePrompt` became `/create-prompt`: generated prompts still travel through the generic chat-editing flow, which preserves chat focus and presents the file among edits. The assigned Backlog bug should remain open for a focused prompt-creation UX fix.

## Change summary

Make a prompt created from a conversation immediately visible in an editor and provide a clear link to it in the chat response.

## Best solution

The prompt-creation workflow should foreground or otherwise unmistakably reveal the created prompt and include a direct file link in its completion response, without changing normal background-opening behavior for unrelated agent edits.
