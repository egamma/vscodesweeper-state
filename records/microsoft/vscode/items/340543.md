# Issue #340543 — Cmd+Shift+A starts a new session

[https://github.com/microsoft/vscode/issues/340543](https://github.com/microsoft/vscode/issues/340543)

## Summary

Thanks for the report. The shortcut opens the Agents window but also sends the invoking workspace folder, which probably starts a new session instead of returning to the last active one. This is a team-authored, valid request, so it stays open.

## Change summary

Cmd+Shift+A should switch to the Agents window and keep the session that was already active, rather than starting a new session each time.

## Best solution

When the shortcut is used and an Agents window already exists, just focus it and preserve the current session selection. Only pass the folder and a new-session intent when no Agents window or session exists.
