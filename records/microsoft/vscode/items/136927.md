# Issue #136927 — Provide a extension api option to set the word-wrap state of a document upon opening.

[https://github.com/microsoft/vscode/issues/136927](https://github.com/microsoft/vscode/issues/136927)

## Summary

This remains a valid, accepted Backlog API request with 33 community upvotes. Current main still lacks a deterministic extension API for setting an editor's initial word-wrap state.

## Change summary

Allow extensions to specify the initial word-wrap state when showing a text document.

## Best solution

Extend the editor API, likely `TextDocumentShowOptions` or writable `TextEditorOptions`, with an explicit per-editor word-wrap override while preserving user configuration when omitted.
