# Issue #284185 — Worktrees not preserving last selected location

[https://github.com/microsoft/vscode/issues/284185](https://github.com/microsoft/vscode/issues/284185)

## Summary

The regression remains in current source: a repository without a remembered worktree location never saves its first selected destination, so subsequent creation prompts return to the default. Keep this open in the Git area; the defect is bounded and ready for implementation.

## Change summary

Restore remembering the last successfully selected worktree destination for subsequent worktree creation.

## Best solution

Persist the parent directory of a successfully created worktree even when no destination was previously saved, and reuse it in subsequent creation prompts. Preserve existing branch naming, default paths for untouched repositories, and repository-specific storage.
