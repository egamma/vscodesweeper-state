# Issue #284185 — Worktrees not preserving last selected location

[https://github.com/microsoft/vscode/issues/284185](https://github.com/microsoft/vscode/issues/284185)

## Summary

Still reproduces on current main: the worktree root is never persisted the first time a user customizes the path, because the save condition in `createWorktree` requires an already-stored root to be truthy before updating it.

## Change summary

When creating a worktree with a custom path for the first time, the chosen directory is not saved — subsequent worktree creations revert to the default path instead of remembering the last-used location.

## Best solution

Fix the guard in `extensions/git/src/repository.ts` line ~1971: change `if (defaultWorktreeRoot && !pathEquals(...))` to `if (!defaultWorktreeRoot || !pathEquals(...))` so that the worktree root is persisted even when no previous value exists in global state.
