# Issue #340311 — Feature request: Allow path-scoped agent approvals outside the workspace

[https://github.com/microsoft/vscode/issues/340311](https://github.com/microsoft/vscode/issues/340311)

## Summary

Reasonable, well-articulated request for a narrower, path-scoped auto-approval grant for agent tool calls outside the workspace; current settings (`chat.tools.edits.autoApprove`, `chat.tools.global.autoApprove`) only offer workspace-scoped or fully global auto-approval, so a real gap exists, but the design (storage format, symlink/canonicalization handling, revocation UI) needs maintainer input.

## Change summary

Add a user-level allowlist so agent tool approvals can be scoped to specific absolute paths/directories outside the current workspace, without enabling global auto-approval.

## Best solution

Design a user-level path-scoped auto-approve mechanism (likely alongside the existing terminal command-line auto-approve pattern in src/vs/workbench/contrib/terminalContrib/chatAgentTools, generalized to file read/edit tools) with canonicalized paths, symlink safety, and a visible/revocable grants UI — this needs a product design decision before implementation.
