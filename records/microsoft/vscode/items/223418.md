# Issue #223418 — Cmd-Down escapes Find/Replace field

[https://github.com/microsoft/vscode/issues/223418](https://github.com/microsoft/vscode/issues/223418)

## Summary

The unwanted focus transfer remains in current source and is already documented in an older, open issue. Consolidate this macOS report with that issue, preserving the requirement for Cmd-Down navigation within Find and Replace inputs.

## Change summary

Cmd-Down should navigate within the focused Find or Replace input instead of transferring focus to the editor.

## Best solution

Consolidate the hard-coded focus-transfer problem under https://github.com/microsoft/vscode/issues/175444, where a maintainer has already proposed making the shortcut rebindable. Preserve this report's macOS native-navigation expectation when deciding the default behavior.

This is the same unwanted focus transfer in the same widget, not merely a related keyboard issue.
- **Maintainer-confirmed ownership of the underlying work:** https://github.com/microsoft/vscode/issues/175444#issuecomment-1508606574 confirms the hard-coded handler and proposes replacing it with a command so users can rebind the shortcut.
