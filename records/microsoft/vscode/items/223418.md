# Issue #223418 — Cmd-Down escapes Find/Replace field

[https://github.com/microsoft/vscode/issues/223418](https://github.com/microsoft/vscode/issues/223418)

## Summary

The unexpected focus transfer remains in current source and is already documented in an older, open issue with the same observable symptom. Consolidate this report there, preserving the macOS expectation that Cmd-Down navigates within the input.

## Change summary

Cmd-Down moves focus from the Find or Replace input to the editor instead of moving the cursor within the input on macOS.

## Best solution

Resolve the hard-coded Find/Replace focus transfer under https://github.com/microsoft/vscode/issues/175444, including this report's macOS native-navigation expectation alongside the existing request to make the shortcut rebindable.

This matches the observable focus escape here, not merely a neighboring keyboard problem.
