# Issue #345909 — Agents: marking a merged side chat as done also marks the main session with an open PR as done

[https://github.com/microsoft/vscode/issues/345909](https://github.com/microsoft/vscode/issues/345909)

## Summary

Confirmed in current source: the suggestion checks the displayed side chat's merged PRs but archives its entire containing session. Keep open to preserve the main session's independent completion state.

## Change summary

Accepting a merged side chat's completion suggestion incorrectly marks its main session with an open PR as done.

## Best solution

The completion suggestion should act on the chat whose PRs established eligibility, leaving the main session and other chats unchanged. Preserve existing main-chat completion behavior and stale-action protection.
