# Issue #345623 — Agent Host: unsent drafts create real AHP sessions on remote hosts

[https://github.com/microsoft/vscode/issues/345623](https://github.com/microsoft/vscode/issues/345623)

## Summary

The current source still creates backend sessions for unsent Agents-window drafts, relying on deferred announcements that conforming remote hosts need not implement. Keep this team-authored interoperability report open; the linked provider-side PR remains an unmerged workaround, not a VS Code fix.

## Change summary

Keep unsent drafts client-local so selecting a remote host and folder does not create sessions visible to other clients.

## Best solution

Use the documented pre-creation configuration flow for remote drafts and create the AHP session on first send, preserving the selected configuration. Evaluate the linked provider-side workaround without making its VS Code-specific announcement suppression a requirement for conforming hosts.
