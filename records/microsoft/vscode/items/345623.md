# Issue #345623 — Agent Host: unsent drafts create real AHP sessions on remote hosts

[https://github.com/microsoft/vscode/issues/345623](https://github.com/microsoft/vscode/issues/345623)

## Summary

The premature session creation remains in current source: opening a draft starts backend creation without waiting for Send. Keep this team-authored interoperability report open; the linked external PR is an unmerged workaround, not a completed VS Code fix.

## Change summary

Unsent Agents-window drafts create real sessions on conforming remote AHP hosts and appear in other clients' session lists.

## Best solution

Keep unsent remote drafts in the documented pre-creation configuration flow and create their AHP session on first Send, preserving selected configuration. Evaluate the linked host-side workaround without making undocumented notification suppression a requirement for conforming hosts.
