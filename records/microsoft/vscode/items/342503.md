# Issue #342503 — MCP: error can be very verbose

[https://github.com/microsoft/vscode/issues/342503](https://github.com/microsoft/vscode/issues/342503)

## Summary

The MCP detail view still displays the entire runtime error, including the HTTP response's HTML body. Keep this open as a bounded presentation improvement: the reported 405 should be understandable without reading transport diagnostics.

## Change summary

Show a concise MCP HTTP failure instead of a verbose transport error containing raw HTML.

## Best solution

Present HTTP 405 Method Not Allowed clearly in the MCP detail error card, without displaying the response body by default. Preserve useful diagnostic information and meaningful messages for errors without an HTTP status.
