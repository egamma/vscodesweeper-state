# Issue #342503 — MCP: error can be very verbose

[https://github.com/microsoft/vscode/issues/342503](https://github.com/microsoft/vscode/issues/342503)

## Summary

The MCP details view still displays the entire runtime error, including an HTML response body, instead of emphasizing the actionable HTTP status. Keep this open as diagnostic-presentation polish; the current source confirms the reported behavior.

## Change summary

Present verbose MCP connection failures concisely, showing HTTP 405 Method Not Allowed without an inline dump of the response HTML.

## Best solution

Make the MCP details error card lead with a concise, actionable failure description while retaining access to the original diagnostic. Agree on how users reveal the full message before implementing the presentation change.
