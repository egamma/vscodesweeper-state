# Issue #342320 — Agent host (Copilot): converting a workspaceless chat with set_workspace misses the entire prompt cache

[https://github.com/microsoft/vscode/issues/342320](https://github.com/microsoft/vscode/issues/342320)

## Summary

Keep open: the merged resume/fork fix explicitly excludes workspace-conversion cache loss. Current main also offers opt-in prompt reordering, but its effect on this conversion is unverified; the supplied steps and measurements suffice to retest without requesting more information.

## Change summary

Converting a workspaceless Copilot chat with set_workspace causes the next model call to rewrite the entire prompt cache instead of reusing its stable prefix.

## Best solution

Preserve reusable tools and system-instruction prefixes across workspace conversion while accurately updating workspace context and customizations. Diagnose the actual model-facing tool changes and cache breakpoints before deciding which changes belong in the host versus the Copilot SDK.
