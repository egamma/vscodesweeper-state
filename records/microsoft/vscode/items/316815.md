# Issue #316815 — Browser crashes in OSS

[https://github.com/microsoft/vscode/issues/316815](https://github.com/microsoft/vscode/issues/316815)

## Summary

Team-authored bug report about Playwright-driven browser crashing during navigation with ERR_ABORTED / frame-detached errors. The reporter suspects low memory but isn't sure. The error path in playwrightService.ts on current main still re-throws non-timeout navigation errors without specific handling for frame-detached scenarios. No fix found, no duplicate identified — keeping open.

## Change summary

The integrated browser (Playwright) crashes with net::ERR_ABORTED / frame-detached errors when an agent navigates to a URL via the open_browser_page tool.

## Best solution

Investigate whether the frame-detached / ERR_ABORTED error in PlaywrightSession.openPage (src/vs/platform/browserView/node/playwrightService.ts:410) should be caught and surfaced as a retryable user-facing error rather than crashing the browser view. The electron-main browserView.ts already ignores ERR_ABORTED (-3) on did-fail-load; similar resilience may be needed in the Playwright navigation path.
