# Issue #325446 — Plan Mode export wastes AI credits by invoking an agent to copy existing text into an editor tab

[https://github.com/microsoft/vscode/issues/325446](https://github.com/microsoft/vscode/issues/325446)

## Summary

Confirmed on current main: the Plan Mode 'Open in Editor' handoff sends a new agent request via the IHandOff mechanism (prompt: 'Open the plan'), invoking the model unnecessarily to reproduce already-generated text. No fix has landed.

## Change summary

Plan Mode's 'Open in Editor' action invokes a new expensive model request to copy already-generated plan text into an editor, wasting AI credits.

## Best solution

Replace the 'Open in Editor' handoff with a local deterministic action that opens the plan content in an untitled editor without a model invocation. The handoff definition lives in the plan mode's prompt file (parsed via IHandOff in src/vs/workbench/contrib/chat/common/promptSyntax/), and the execution goes through the widget's executeHandoff path — a new local code path should intercept this specific handoff and use IEditorService.openEditor with the existing plan content instead.
