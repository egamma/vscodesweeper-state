# Issue #325446 — Plan Mode export wastes AI credits by invoking an agent to copy existing text into an editor tab

[https://github.com/microsoft/vscode/issues/325446](https://github.com/microsoft/vscode/issues/325446)

## Summary

Keep open: the current Plan agent still explicitly submits a model request for “Open in Editor,” so deterministic export remains missing. This requests a change to the deliberately configured handoff, rather than a malfunction of that handoff; the verified related issues do not establish an older canonical for the same symptom.

## Change summary

Open an already-generated plan in an untitled Markdown editor without submitting another model request.

## Best solution

Make the built-in Plan export action a local operation that preserves the existing plan text and does not initiate a chat turn. Preserve Start Implementation and ordinary agent handoffs, and settle which existing plan artifact the export action represents alongside the related artifact-selection discussion.
