# Issue #335819 — Delete is disabled for an automation with a running session without explanation

[https://github.com/microsoft/vscode/issues/335819](https://github.com/microsoft/vscode/issues/335819)

## Summary

Keep open: current agent-host automations still disable Delete during an active run without explaining why. This team-authored report identifies a remaining UX gap; no verified duplicate or issue-referencing fix was found.

## Change summary

Explain why an automation cannot be deleted during an active run, or support confirmed deletion that stops the run.

## Best solution

Make the automation menu explain the active-run restriction and the available next step. Treat stopping a run as part of deletion as a separate lifecycle decision rather than silently weakening the existing removal guard.
