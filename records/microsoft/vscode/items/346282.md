# Issue #346282 — Search tools fails slowly with 'Tool called for unknown chat session'

[https://github.com/microsoft/vscode/issues/346282](https://github.com/microsoft/vscode/issues/346282)

## Summary

Keep open: the reported ordering is consistent with tool execution reaching an unpublished chat model, but the reopening race is not conclusively reproduced. Current main restores history before publishing the model; the supplied scenario and timestamps suffice to guide a focused retest.

## Change summary

Tool discovery fails when a background chat is reopened before its model is ready, requiring a model-driven retry.

## Best solution

Coordinate client-tool execution with chat restoration so a valid pending session can finish discovery without an unknown-session failure. Establish the cause of the preceding dispatch delay separately, preserving rejection of genuinely unknown sessions.
