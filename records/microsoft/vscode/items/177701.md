# Issue #177701 — Ability to ignore `star-activation` warning

[https://github.com/microsoft/vscode/issues/177701](https://github.com/microsoft/vscode/issues/177701)

## Summary

Keep open: current source still emits the star-activation diagnostic without a workspace suppression option. This accepted Backlog request has 25 upvotes, and the activation alternatives discussed in the thread do not cover its full scope.

## Change summary

Allow extension developers to suppress the star-activation diagnostic through workspace settings while retaining other manifest diagnostics.

## Best solution

Provide an opt-in, workspace-scoped suppression mechanism in the built-in extension-editing linter, preserving the default performance advisory and unrelated diagnostics. A maintainer should settle the public configuration contract before implementation.
