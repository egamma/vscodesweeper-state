# Issue #137638 — VSCode opens the wrong folder in Windows 10 start menu when there are folders with the same name

[https://github.com/microsoft/vscode/issues/137638](https://github.com/microsoft/vscode/issues/137638)

## Summary

Still plausibly an issue on main: the Windows Jump List uses basename-only titles, so two folders with the same leaf name (e.g. foo/baz and bar/baz) get identical Jump List entry titles, which Windows may resolve incorrectly. The full URI is passed in args but Windows might match by title.

## Change summary

VS Code opens the wrong folder from the Windows Start menu when two recently-opened folders share the same leaf name.

## Best solution

Disambiguate Jump List titles when multiple recent folders share the same basename — include the parent directory (similar to how tab titles are disambiguated). The fix would be in `getWindowsJumpListLabel` in `src/vs/platform/workspaces/electron-main/workspacesHistoryMainService.ts`.
