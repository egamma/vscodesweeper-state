# Issue #337395 — Markdown Editor: autolinks, backslash escapes, character references, and inline HTML disappear from rendered text

[https://github.com/microsoft/vscode/issues/337395](https://github.com/microsoft/vscode/issues/337395)

## Summary

Well-diagnosed bug in the (opt-in) built-in Markdown Editor: the reporter reproduced and screenshotted every case in the table, and the root-cause analysis (inline AST builder only handling a subset of micromark inline token types) is precise and plausible; routing to the markdown-editor area since it isn't yet labeled.

## Change summary

In the built-in rich Markdown Editor (vscode.markdown.editor), autolinks, backslash escapes, character references, and inline HTML tags are silently dropped from the rendered text instead of being rendered like in the Markdown Preview.

## Best solution

Fix the inline AST builder to also emit text/element nodes for autolinkProtocol/autolinkEmail, characterEscapeValue, characterReferenceValue, and htmlText(Data) tokens, not just the currently-handled subset — this affects the separately-published @vscode/markdown-editor package (extensions/markdown-language-features depends on it as `@vscode/markdown-editor`), whose source isn't in this checkout, so the actual patch lands there.
