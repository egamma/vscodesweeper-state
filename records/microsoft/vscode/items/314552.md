## Summary

Keep open for security and extension-platform review. The runtime-permissions half overlaps an open canonical request, but mandatory Marketplace static analysis remains distinct, and the security-sensitive scope precludes an automated close.

## Change summary

Require extensions to declare capabilities, enforce those declarations at runtime, expose permissions to users, and statically analyze Marketplace submissions.

## Best solution

Consolidate runtime capability declarations and permission UX with https://github.com/microsoft/vscode/issues/52116, while separately scoping publication-time analysis with Marketplace security owners. Any design needs a threat model and compatibility plan covering direct Node.js access, child processes, extension dependencies, and existing extensions.
