# Issue #270305 — GitHub Copilot content-based exclusions are bypass when logged in with an alias_microsoft account

[https://github.com/microsoft/vscode/issues/270305](https://github.com/microsoft/vscode/issues/270305)

## Summary

Keep open: this team-authored, reopened bug reports a security-sensitive content-exclusion bypass, and a maintainer subsequently restored it, applied `bug` and `content-exclusions`, and assigned it. The proposed duplicate concerns public-code response blocking rather than disclosure of excluded file content.

## Change summary

Content-based exclusions are not enforced by the Explain command when Copilot is authenticated with an `alias_microsoft` account.

## Best solution

Ensure the identity used to fetch and evaluate content-exclusion rules is the same identity authenticated to Copilot, including multi-account alias scenarios, and cover Explain with a regression test proving excluded file contents never enter the request.
