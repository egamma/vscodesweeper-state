# Issue #328822 — Agents Window PR Failed Checks icon has bad contrast

[https://github.com/microsoft/vscode/issues/328822](https://github.com/microsoft/vscode/issues/328822)

## Summary

Team-authored screenshot bug, traced conclusively in source: the failed-checks PR icon uses `charts.orange`, which resolves through `minimap.findMatchHighlight` to `editor.findMatchHighlightBackground` (`#EA5C0055`, hcDark/hcLight both `null`) — a semi-transparent background-highlight color never meant to render as an opaque icon foreground, which explains the washed-out contrast in the screenshot.

## Change summary

The 'checks failed' PR icon in the Agents window renders in a low-contrast, semi-transparent orange rather than a solid, clearly visible color.

## Best solution

In `computePullRequestIcon` (src/vs/sessions/contrib/github/common/types.ts), stop using `charts.orange` for the failing-CI `gitPullRequestError` icon since its default resolves to a translucent search-highlight color with no high-contrast theme values; use a solid, purpose-built warning/error foreground instead (e.g. `editorWarning.foreground` or `problemsWarningIcon.foreground`, both of which define real dark/light/hcDark/hcLight values).
