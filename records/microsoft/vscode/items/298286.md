# Issue #298286 — Changes to what gets installed

[https://github.com/microsoft/vscode/issues/298286](https://github.com/microsoft/vscode/issues/298286)

## Summary

The reporter's core complaint is valid: the Inno Setup installer line for policy files uses `policies\*` without the `recursesubdirs createallsubdirs` flags, so only the top-level ADMX file is installed — the ADML language files in subdirectories (en-us, fr-fr, etc.) are silently skipped. The ZIP distribution includes them because it's a flat copy of the build output. The `info-needed` label can be removed since the reporter clarified the issue.

## Change summary

Windows EXE installer does not copy ADML group policy language files (located in subdirectories under `policies/`), making the ADMX file unusable in gpedit.msc.

## Best solution

Add `recursesubdirs createallsubdirs` flags to the policies line in `build/win32/code.iss` (line 102) so that ADML language files in subdirectories are installed alongside the ADMX file, matching the ZIP distribution.
