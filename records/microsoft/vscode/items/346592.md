# Issue #346592 — Agents window: after Escape in Find Session, focus stays on the last match and the open session loses its highlight

[https://github.com/microsoft/vscode/issues/346592](https://github.com/microsoft/vscode/issues/346592)

## Summary

The current source retains search-result focus after Escape, so Enter can open a different session. Keep this team-authored bug open; restoring the active session's highlight and keyboard target remains necessary.

## Change summary

Restore the open session's highlight and keyboard focus after dismissing Find Session, and preserve its highlight through filter changes.

## Best solution

Make the Sessions list return to the currently shown session or chat when search is dismissed, while preserving normal search navigation and deliberate multi-selection. Filter refreshes should not leave the open session without its highlight.
