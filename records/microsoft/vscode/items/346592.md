# Issue #346592 — Agents window: after Escape in Find Session, focus stays on the last match and the open session loses its highlight

[https://github.com/microsoft/vscode/issues/346592](https://github.com/microsoft/vscode/issues/346592)

## Summary

Keep open: the Windows confirmation corroborates the Ubuntu report, and current source still returns DOM focus without restoring the open session's row. Cancelling Find can therefore leave Enter targeting the last search match.

## Change summary

Restore the open session's highlight and keyboard focus after cancelling Find Session, including after relevant filter changes.

## Best solution

Restore the main window's session as the list's selected and focused row after search cancellation, without opening another session or changing saved filters. Preserve deliberate activation of search results and cover the reported filter-change behavior with regression checks.
