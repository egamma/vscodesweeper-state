# Issue #251392 — SCM - Flat Source Control View for Multi-Root Workspaces (Monorepo-Like Behavior)

[https://github.com/microsoft/vscode/issues/251392](https://github.com/microsoft/vscode/issues/251392)

## Summary

The requested unified multi-repository workflow remains missing: existing list mode retains repository groups and separate commit inputs. Keep this accepted Backlog request open; the verified related issues do not cover its full scope.

## Change summary

Add an optional unified changes view with cross-repository staging, a shared commit message, and coordinated commits and pushes.

## Best solution

Provide an opt-in SCM workflow for logically related repositories while preserving the existing independent-repository experience. SCM and Git owners should settle coordinated-operation scope and partial-failure behavior before implementation.
