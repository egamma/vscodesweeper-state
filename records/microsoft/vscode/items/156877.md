# Issue #156877 — Quick pick: allow to handle middle mouse button specifically

[https://github.com/microsoft/vscode/issues/156877](https://github.com/microsoft/vscode/issues/156877)

## Summary

Keep open: the convenience pick API still does not expose middle-click acceptance to its callers, although the underlying widget handles it. The related Open Recent request was declined, but that narrower decision does not resolve this accepted API request.

## Change summary

Let callers of the quick-pick convenience API distinguish middle-click selection from ordinary acceptance.

## Best solution

Provide an acceptance-context contract in the quick-input platform API so convenience-picker clients can distinguish middle-click without accessing the widget directly. Preserve existing keyboard-modifier behavior and default picker dismissal semantics.
