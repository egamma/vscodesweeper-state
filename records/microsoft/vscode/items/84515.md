# Issue #84515 — Add vscode.workspace.fs.createWriteStream().

[https://github.com/microsoft/vscode/issues/84515](https://github.com/microsoft/vscode/issues/84515)

## Summary

A real extension API gap remains: current main exposes chunk operations only to file-system provider implementations, not consumers through `workspace.fs`. This issue is the established tracker and remains appropriately backlogged.

## Change summary

Expose streaming or random-access chunked file reads and writes through `vscode.workspace.fs` for large-file and incremental-I/O workloads.

## Best solution

Finalize a consumer-side random-access or streaming API that works across local, remote, and contributed file systems, building on the existing `fsChunks` provider primitives. The API design should cover offsets, lifecycle safety, backpressure, and providers lacking native chunk support.
