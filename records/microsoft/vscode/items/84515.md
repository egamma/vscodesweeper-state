- **Proposal remains provider-only:** src/vscode-dts/vscode.proposed.fsChunks.d.ts explicitly references https://github.com/microsoft/vscode/issues/84515 and adds optional open, close, read and write methods only to FileSystemProvider. src/vs/workbench/api/common/extHostFileSystem.ts:161–165 still gates these provider capabilities through checkProposedApiEnabled(extension, 'fsChunks').
