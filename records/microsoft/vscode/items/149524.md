# Issue #149524 — Bracket Pair Guides overlap non-indented text

[https://github.com/microsoft/vscode/issues/149524](https://github.com/microsoft/vscode/issues/149524)

## Summary

Keep open: current guide placement still provides no separation from unindented text, and existing settings do not offer the requested selective suppression. The older related reports concern different rendering symptoms and do not absorb this request.

## Change summary

Improve bracket pair guide readability beside unindented text through spacing or selective guide suppression.

## Best solution

Retain useful bracket pair guides without letting them compete with source text, especially in unindented C++ namespace bodies. The editor owner should choose between consistent guide separation and selective suppression before introducing additional settings.

## Evidence

- **Remaining placement gap:** In src/vs/editor/common/model/guidesTextModelPart.ts, GuidesTextModelPart.getLinesBracketGuides computes guideVisibleColumn as Math.min(startVisibleColumn, endVisibleColumn, pair.minVisibleColumnIndentation + 1). An unindented body can therefore place the guide at visible column 1; there is no selective suppression for column-zero guides or insufficiently indented blocks.
- **Current rendering:** In src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts, IndentGuidesOverlay.prepareRender places a visible-column guide at leftOffset + (guide.visibleColumn - 1) * this._spaceWidth. The theming participant draws its vertical stroke with an inset 1px box-shadow, without a leftward separation offset. This establishes the placement concern from source, but actual glyph overlap on the reporter's display was not executed or verified.
- **Existing-capability check:** GuideOptions in src/vs/editor/common/config/editorOptions.ts registers editor.guides.bracketPairs as true, 'active', or false, plus horizontal-guide and highlighting controls. Disabling guides or limiting them to the active pair is only a workaround: neither preserves other guides while hiding column-zero or insufficiently indented guides, nor creates clearance from text.
