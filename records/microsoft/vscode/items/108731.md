# Issue #108731 — Remote-SSH & WSL: Support trash

[https://github.com/microsoft/vscode/issues/108731](https://github.com/microsoft/vscode/issues/108731)

## Summary

Keep open: current main still lacks remote trash support, and this 81-upvote Backlog request is the canonical issue for both Remote-SSH and WSL.

## Change summary

Move files deleted through Remote-SSH and WSL to the remote system's trash instead of deleting them permanently.

## Best solution

Add a safe remote implementation of the file-provider Trash capability, accounting for remote platform trash conventions and filesystem boundaries, then expose the normal Explorer trash behavior for Remote-SSH and WSL resources.
