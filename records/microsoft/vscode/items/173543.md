# Issue #173543 — user installed fonts not loaded after a reboot

[https://github.com/microsoft/vscode/issues/173543](https://github.com/microsoft/vscode/issues/173543)

## Summary

This is an upstream issue: Windows 11's Font Cache Service does not reliably serve per-user installed fonts to Chromium/Electron after a reboot. VS Code has no custom font-loading code — it relies entirely on Chromium's font enumeration. The workaround is 'Install for all users'. Keeping open as the canonical tracker for this upstream problem.

## Change summary

Per-user installed fonts on Windows 11 disappear from VS Code after a reboot until the Windows Font Cache is cleared or fonts are reinstalled system-wide.

## Best solution

Track upstream: this is a Windows Font Cache Service / Chromium interaction bug. The workaround ('Install for all users') is well-documented in the thread. If Electron or Chromium adds support for the Windows Local Font Access API or improves per-user font enumeration, this resolves. Consider adding a note in VS Code docs about the Windows per-user font limitation.
