# Issue #339850 — Double scrollbar shows up when using session grids on small window sizes

[https://github.com/microsoft/vscode/issues/339850](https://github.com/microsoft/vscode/issues/339850)

## Summary

Credible, freshly-filed visual bug in the actively-developed session grid feature: a contributor attached a screenshot showing overlapping scrollbars at minimum window/session size, and the issue is already correctly labeled bug + agents-window. Keeping open; root cause needs diagnosis across the nested scroll containers before a fix is attempted.

## Change summary

When a session grid is resized down to its minimum size, scrollbars from the grid cell and the session's own history/prompt area overlap instead of only one owning the scroll.

## Best solution

Diagnose which of the nested scroll containers (the grid cell's DomScrollableElement in customViewNode.ts / customViewGridPart, versus the session view's own chat-history scroll area in sessionView.ts/chatView.ts) should own vertical scrolling at minimum size, and suppress the redundant one; also consider the reporter's secondary ask to cap the growing prompt-box height so more of the history stays visible.
