# Issue #341449 — Quick Search: Escape after previewing a match in another file leaves no element focused

[https://github.com/microsoft/vscode/issues/341449](https://github.com/microsoft/vscode/issues/341449)

## Summary

Thanks for the very thorough report. The source is consistent with it: PickerEditorState.restore() reopens the original editor with preserveFocus: true, so Quick Access cannot restore focus to the original editor's detached element. Focus is left on <body>.

## Change summary

After Escape in Quick Search following a preview of a match in another file, no element has keyboard focus even though the original editor is restored.

## Best solution

When the picker is dismissed with Escape and the editor state is restored, explicitly focus the restored original editor. Alternatively, make the quick input's focus restoration fall back to the active editor group when the previously focused element is detached.

- **Trace:**

The previously focused element was detached while the preview was shown, so the quick input's focus restore has nothing to focus and focus ends on body.
