## Summary

Confirmed on main: the experimental welcome-phrases setting uses a bare `{name}` placeholder instead of the `${name}` convention used elsewhere in the product, exactly as the (team-authored) report states. This is a real, bounded consistency fix, not something to close.

## Change summary

The `sessions.chat.experimental.welcomeMessages` setting's name placeholder is `{name}` instead of the standard `${name}` template format used elsewhere in VS Code.

## Best solution
