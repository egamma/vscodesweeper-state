# Issue #213720 — boolean options are not deprecated and marked as will be deprecated?

[https://github.com/microsoft/vscode/issues/213720](https://github.com/microsoft/vscode/issues/213720)

## Summary

Still valid on current main: both `editor.codeActionsOnSave` and `notebook.codeActionsOnSave` schemas still include boolean `true`/`false` in their enum values (lines 69 and 98–99 of codeActionsContribution.ts). The deprecation started in d2028ff9c76 but was never completed.

## Change summary

Remove boolean `true`/`false` from the `codeActionsOnSave` configuration schema enum so that using them shows a warning in settings.json, while still supporting them in code for backward compatibility.

## Best solution

Remove `true` and `false` from the `enum` arrays in `codeActionsOnSaveSchema` and `notebookCodeActionsOnSaveSchema` in `src/vs/workbench/contrib/codeActions/browser/codeActionsContribution.ts`, and remove `'boolean'` from `type` in `additionalProperties`. The runtime code in `saveParticipants.ts` already handles boolean values, so users with existing boolean settings will still work but see a JSON validation warning.
