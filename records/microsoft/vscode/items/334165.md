# Issue #334165 — Markdown Editor: Ability to copy comments in Agent window

## Summary

Real, unaddressed gap: the agent-window review-comments popup has no copy affordance, and losing carefully-written comments after a stuck agent run is a legitimate pain point. Already correctly labeled feature-request/agents-window with a Backlog milestone, so this can stay open as-is.

## Change summary

Add a way to copy the list of markdown-file review comments shown in the Agent window's 'View Comments' popup, since they currently can only be viewed, not copied like other attachments.

## Best solution

Add a copy action (toolbar button or context-menu item) to the feedback comments tree in src/vs/sessions/contrib/agentFeedback/browser/agentFeedbackContextView.ts (AgentFeedbackContextView / FeedbackCommentRenderer) that serializes the file+comment list to the clipboard, consistent with how other chat attachments support copy.
