# Issue #334165 — Markdown Editor: Ability to copy comments in Agent window

[https://github.com/microsoft/vscode/issues/334165](https://github.com/microsoft/vscode/issues/334165)

## Summary

Fresh, plausible feature request (filed hours ago) asking for a way to copy the text of markdown editor review comments attached to a chat/agent request; I found no existing copy affordance for this attachment type in the chat code, so it's a real gap worth routing to the chat/comments area rather than closing.

## Change summary

When markdown editor comments are attached to a chat/agent session, there is no way to copy their text — only a small hover list ('View Comments') with no copy action, risking loss of manually authored review comments.

## Best solution

Add a copy action (or 'Copy All') to the comments attachment's hover/list view in the chat widget, mirroring the copy support other attachment types already have — likely in src/vs/workbench/contrib/chat/browser (attachment rendering) alongside the existing chatCopyActions.ts infrastructure.
