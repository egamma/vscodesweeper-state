# Issue #341950 — Column selection paste into a single cursor: separate setting from editor.multiCursorPaste, and avoid trailing-space padding

[https://github.com/microsoft/vscode/issues/341950](https://github.com/microsoft/vscode/issues/341950)

## Summary

Thanks for the detailed report. The code confirms that the new block paste into a single cursor is gated only by `editor.multiCursorPaste === 'spread'`, and it pads every pasted line to the block width. The request for an independent setting and for no padding where no text follows is a design question for the editor owners, so this stays open.

## Change summary

Column-selection paste into one cursor shouldn't be tied to `editor.multiCursorPaste: spread`, and it shouldn't add trailing-space padding when no text follows the paste position.

## Best solution

Stop padding pasted lines when nothing follows on the line. Padding would stay only where text to the right needs to stay aligned. Optionally add a dedicated setting for single-cursor block paste.
