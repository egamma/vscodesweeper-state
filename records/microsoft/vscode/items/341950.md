# Issue #341950 — Column selection paste into a single cursor: separate setting from editor.multiCursorPaste, and avoid trailing-space padding

[https://github.com/microsoft/vscode/issues/341950](https://github.com/microsoft/vscode/issues/341950)

## Summary

Keep open: current source still couples single-cursor block paste to multi-cursor distribution and deliberately pads copied rows, including when pasting into an empty document. This requests independent control and revised padding semantics, neither of which the existing setting provides.

## Change summary

Allow independent control of single-cursor column paste and avoid generated trailing padding when no destination text follows the pasted row.

## Best solution

Preserve ordinary multi-cursor distribution while allowing users to opt out of single-cursor rectangular insertion, and avoid unnecessary generated trailing spaces without disturbing suffix alignment. Agree on the new control's default and padding semantics before changing the editor's documented and tested behavior.
