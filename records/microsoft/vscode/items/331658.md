# Issue #331658 — Forward Port Option Missing from Ports/Terminal Interface

[https://github.com/microsoft/vscode/issues/331658](https://github.com/microsoft/vscode/issues/331658)

## Summary

This is a how-to/support question, not a bug: the Ports view and its 'Forward a Port' action are only enabled in a remote context (SSH/WSL/Containers/Codespaces) or once a running port is auto-detected (e.g. via a debug session), not simply by running a Node app in a plain local terminal.

## Change summary

Reporter can't find the 'Forward Port' option after starting a local Node.js server on port 8000 in plain desktop VS Code.

## Best solution

Point the reporter to the Ports view / port forwarding docs and note that forwarding is aimed at remote scenarios or auto-detected ports; they can manually add a port via the Ports panel (Ports: Focus on Ports View) and 'Forward a Port', or start the app under a debug session so it's auto-detected.
