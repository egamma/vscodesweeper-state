# Issue #313143 — SSH connection

[https://github.com/microsoft/vscode/issues/313143](https://github.com/microsoft/vscode/issues/313143)

## Summary

The reported server-installation failure is addressed by a concrete Node.js fix adopted by current main. Propose closing as completed, rather than duplicating the older report, which is now closed.

## Change summary

Remote-SSH server installation fails repeatedly when Node.js's undici WebAssembly parser cannot allocate guard regions under restricted Linux virtual-memory limits.

## Best solution

Use the adopted Node.js runtime that automatically disables WebAssembly trap-handler guard regions when the process address-space limit is too small. This removes the reported allocation failure without requiring administrators to grant unlimited virtual memory.
