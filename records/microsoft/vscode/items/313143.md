# Issue #313143 — SSH connection

[https://github.com/microsoft/vscode/issues/313143](https://github.com/microsoft/vscode/issues/313143)

## Summary

VS Code Server installation fails on memory-constrained remote machines because Node.js v22's bundled undici module requires WebAssembly instantiation that exceeds available memory. A team member (alexdima) is already actively triaging — the reporter answered the memory question but awaits a follow-up. Keeping open.

## Change summary

VS Code Server integrity check fails with 'WebAssembly.instantiate(): Out of memory' on remote machines with restricted virtual memory (~3.8 GB), entering an infinite retry loop.

## Best solution

The root cause is upstream in Node.js v22's undici module using WebAssembly for HTTP parsing. The team should determine whether the server installation can avoid the WebAssembly-dependent code path (e.g. by setting --no-wasm or using a fallback HTTP parser), or document the minimum memory requirement for remote hosts. alexdima is already engaged and should follow up with the reporter's memory info.
