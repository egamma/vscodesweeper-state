## Summary

Keep open: the installation failure matches the diagnosed Node.js/V8 WebAssembly address-space limitation on restricted Linux servers. Newer runtime mitigation is promising, but this review has not established a distinct fixing commit and verified coverage of the reported installation path.

## Change summary

Remote-SSH server installation fails its integrity check and repeatedly retries when Node.js cannot allocate WebAssembly memory under a restricted virtual-memory limit.

## Best solution

Confirm that the bundled server runtime handles the reporter's approximately 3.8 GB address-space limit during installation and startup, and that allocation failures do not cause repeated downloads. Distinguish virtual address-space reservations from physical RAM when answering the administrator's sizing question; no universally safe allocation follows from this report.
