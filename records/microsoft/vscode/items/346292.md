# Issue #346292 — MCP OAuth: refresh token dropped when token endpoint doesn't rotate it, forcing re-auth every ~2 hours

[https://github.com/microsoft/vscode/issues/346292](https://github.com/microsoft/vscode/issues/346292)

## Summary

The reported refresh-token loss is confirmed in current main: a successful non-rotating refresh replaces the stored token without retaining its refresh token, preventing the next silent refresh. Keep open for a bounded authentication fix.

## Change summary

Retain the existing OAuth refresh token when a successful refresh response omits a replacement.

## Best solution

DynamicAuthProvider should support successive silent refreshes for non-rotating authorization servers while continuing to adopt replacement refresh tokens when servers rotate them.
