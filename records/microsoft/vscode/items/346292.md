# Issue #346292 — MCP OAuth: refresh token dropped when token endpoint doesn't rotate it, forcing re-auth every ~2 hours

[https://github.com/microsoft/vscode/issues/346292](https://github.com/microsoft/vscode/issues/346292)

## Summary

The defect remains in current source: a successful refresh response without refresh_token replaces the stored credential, causing the next renewal to discard the session. Independent confirmations across three authorization servers support keeping this open as a bounded authentication bug.

## Change summary

Preserve a valid existing refresh token when a successful OAuth refresh response omits its replacement.

## Best solution

DynamicAuthProvider should support repeated silent renewals with non-rotating refresh tokens while honoring replacement tokens when supplied. Cover both behaviors in the existing authentication tests without changing concurrent-refresh or invalid-grant handling.
