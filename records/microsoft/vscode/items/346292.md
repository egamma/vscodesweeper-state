# Issue #346292 — MCP OAuth: refresh token dropped when token endpoint doesn't rotate it, forcing re-auth every ~2 hours

[https://github.com/microsoft/vscode/issues/346292](https://github.com/microsoft/vscode/issues/346292)

## Summary

Keep open: current main still discards the existing refresh token when a successful refresh response omits its replacement. The source confirms the reported failure, independently reproduced on macOS and Windows.

## Change summary

Preserve refreshability across successful OAuth refreshes when the authorization server does not rotate refresh tokens.

## Best solution

DynamicAuthProvider should retain the existing refresh token when a successful response omits one, while honoring newly issued replacements. Cover consecutive refreshes in the existing authentication unit suite without changing expiry, scope, or failure-handling semantics.
