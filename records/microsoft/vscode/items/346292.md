# Issue #346292 — MCP OAuth: refresh token dropped when token endpoint doesn't rotate it, forcing re-auth every ~2 hours

[https://github.com/microsoft/vscode/issues/346292](https://github.com/microsoft/vscode/issues/346292)

## Summary

The refresh-token loss remains directly traceable in current main and is independently confirmed against three authorization servers. Keep this open as a bounded authentication bug; the related reports concern different failure paths.

## Change summary

Preserve a usable OAuth refresh token when a successful refresh response omits its replacement.

## Best solution

DynamicAuthProvider should support repeated non-rotating refreshes while adopting replacement refresh tokens when supplied. Cover both behaviors in its existing unit-test suite without changing authentication failure handling or cross-window coordination.
