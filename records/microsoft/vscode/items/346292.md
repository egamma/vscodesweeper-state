# Issue #346292 — MCP OAuth: refresh token dropped when token endpoint doesn't rotate it, forcing re-auth every ~2 hours

[https://github.com/microsoft/vscode/issues/346292](https://github.com/microsoft/vscode/issues/346292)

## Summary

Keep open: current main still discards a valid refresh token when a successful refresh response omits its replacement. The source matches both the original macOS report and the independent Windows confirmation.

## Change summary

Preserve OAuth session refreshability when authorization servers do not rotate refresh tokens.

## Best solution

Successful refreshes should retain the existing refresh token when no replacement is issued and adopt a replacement when supplied. Cover consecutive refreshes in the DynamicAuthProvider tests without changing revocation or refresh-failure handling.
