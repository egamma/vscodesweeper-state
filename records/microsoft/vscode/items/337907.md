# Issue #337907 — Reporting an issue for an extension fails silently if that extension does not have an issue reporting URL

[https://github.com/microsoft/vscode/issues/337907](https://github.com/microsoft/vscode/issues/337907)

## Summary

Confirmed on main by tracing the code: when an extension's manifest has neither a `bugs.url` nor a `repository` field, `createIssue()` in baseIssueReporterService.ts computes an empty issue URL and bails out with only a `console.error`, so clicking Submit silently does nothing — no dialog, no toast.

## Change summary

Clicking Submit in the issue reporter does nothing when the target extension has no configured bug-report or repository URL.

## Best solution

In createIssue() (src/vs/workbench/contrib/issue/browser/baseIssueReporterService.ts), when getIssueUrl() returns empty for the extension case, show a user-facing dialog/notification via IIssueFormService (mirroring the existing showClipboardDialog() pattern) instead of only logging to console.
