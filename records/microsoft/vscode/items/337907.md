# Issue #337907 — Reporting an issue for an extension fails silently if that extension does not have an issue reporting URL

[https://github.com/microsoft/vscode/issues/337907](https://github.com/microsoft/vscode/issues/337907)

## Summary

Keep open: the supplied extension and steps suffice to retest, but current main has distinct legacy and wizard reporters with different missing-URL handling. The wizard already displays a warning; that does not establish that the reported silent submission failure is resolved.

## Change summary

Reporting an issue for an extension without an issue-reporting destination should explain why submission cannot proceed instead of silently doing nothing.

## Best solution

Ensure the affected built-in issue reporter visibly explains that the extension provides no reporting destination, retaining the draft and avoiding submission to an unrelated tracker. First establish whether the supplied reproduction follows the legacy reporter or the wizard and whether its repository-URL fallback is available.
