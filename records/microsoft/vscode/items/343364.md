# Issue #343364 — Agent Host: one workspace folder from an extension file system (abap:) breaks agents/skills discovery for all folders

[https://github.com/microsoft/vscode/issues/343364](https://github.com/microsoft/vscode/issues/343364)

## Summary

Keep open: multiple reporters confirm discovery failures, including silently discarded agent selections. Current main filters virtual additional folders during launch but still passes them unfiltered through customization refresh.

## Change summary

Prevent extension-backed workspace folders from disabling native-folder and user-level customization discovery or silently replacing the selected custom agent.

## Best solution

Keep native customization discovery consistent across initial launch, refresh, and resume in the Copilot agent host. Preserve valid workspace and user customizations in mixed workspaces, and visibly report an unavailable selected agent rather than silently running the default.
