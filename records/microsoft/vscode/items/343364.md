# Issue #343364 — Agent Host: one workspace folder from an extension file system (abap:) breaks agents/skills discovery for all folders

[https://github.com/microsoft/vscode/issues/343364](https://github.com/microsoft/vscode/issues/343364)

## Summary

The current discovery code still converts every workspace URI to a native path and discards the entire customization result when one discovery request fails. Keep this open: preserving local-folder discovery in a mixed workspace is distinct from enabling agent access to virtual files.

## Change summary

Prevent an extension-backed workspace folder from suppressing agents and skills discovered in valid local folders.

## Best solution

Keep customization discovery working for native workspace roots when additional roots have no native filesystem representation. Preserve existing multi-root discovery and primary-folder hook semantics without expanding this fix into virtual-file editing or virtual-only session support.
