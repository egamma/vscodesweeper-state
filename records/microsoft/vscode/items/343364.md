# Issue #343364 — Agent Host: one workspace folder from an extension file system (abap:) breaks agents/skills discovery for all folders

[https://github.com/microsoft/vscode/issues/343364](https://github.com/microsoft/vscode/issues/343364)

## Summary

The mixed-workspace discovery failure remains traceable on current main: a refresh path forwards unfiltered virtual roots despite filtering elsewhere. The latest report also confirms that discovery failure silently replaces the selected custom agent; keep this open for diagnosis and correction.

## Change summary

Prevent extension-backed workspace folders from suppressing local agent and skill discovery or silently discarding a selected agent.

## Best solution

Native discovery should retain usable local roots without interpreting virtual URIs as filesystem paths. Discovery failure that prevents resolving the selected agent should produce a visible failure rather than send the turn as the default agent.
