# Issue #343364 — Agent Host: one workspace folder from an extension file system (abap:) breaks agents/skills discovery for all folders

## Summary

The failure path remains in current main: extension-backed workspace roots become native project paths, and one discovery rejection discards the entire customization inventory. Keep this distinct from the related virtual-file editing and Codex startup reports.

## Change summary

Prevent a non-native workspace folder from suppressing agents and skills discovered in valid local folders.

## Best solution

Keep native customization discovery working for supported roots in mixed workspaces, excluding extension-backed roots from native-path discovery requests without changing the workspace itself. Supporting agent read/edit operations on virtual files is separate work.
