# Issue #328800 — Browser Comments: Screenshot doesn't include entire dom element

[https://github.com/microsoft/vscode/issues/328800](https://github.com/microsoft/vscode/issues/328800)

## Summary

Tracing the capture path confirms a plausible root cause even though the maintainer hasn't reproduced it live yet: element screenshots (used by the new 'Comment on Elements' / 'Add to Chat' flow) are captured via `webContents.capturePage(screenRect)`, which only returns pixels already rendered in the current on-screen viewport — an element taller than the visible browser view will be clipped, unlike the separate full-page path which correctly uses CDP's `captureBeyondViewport`.

## Change summary

When commenting on/attaching a large DOM element in the Integrated Browser, the captured element screenshot is cropped and doesn't show the whole element.

## Best solution

In `BrowserView.captureScreenshot` (src/vs/platform/browserView/electron-main/browserView.ts), route the `pageRect` capture branch through the same CDP `Page.captureScreenshot` mechanism already used by `_captureFullPageScreenshot` (with `clip` sized/offset to the element and `captureBeyondViewport: true` when the rect exceeds the current viewport) instead of `webContents.capturePage`, which is viewport-bound.

## Evidence

- **capture path:** src/vs/platform/browserView/electron-main/browserView.ts:810-860 — when `options.pageRect` is set, it's converted to `screenRect` and passed to `this._view.webContents.capturePage(options.screenRect, { stayHidden: true })`, which per Electron's API only captures the currently-rendered visible surface.
- **contrast with full-page path:** The sibling `_captureFullPageScreenshot` (same file, ~line 863) explicitly uses CDP `Page.captureScreenshot` with `captureBeyondViewport: true` to handle content taller than the viewport — that mechanism is not used for the element/`pageRect` capture branch.
- **call site:** src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorChatFeatures.ts:437-441 calls `model.captureScreenshot({ quality: 90, pageRect: bounds, awaitNextPaint: true })` where `bounds` is the element's viewport-relative box-model rect — for an element taller than the browser view, this rect exceeds the visible surface `capturePage` can return.
