# Issue #328759 — Transferring dictation targets does not work

[https://github.com/microsoft/vscode/issues/328759](https://github.com/microsoft/vscode/issues/328759)

## Summary

The editor-to-chat microphone failure remains reproducible from current source: the chat shortcut stops the globally active editor session and returns without starting chat dictation. Keep this accepted, team-authored bug open; lower-level takeover support does not resolve the chat entry-point behavior.

## Change summary

Switching dictation targets should end the previous session and start recording into the newly selected target in one invocation.

## Best solution

Make the chat dictation entry point distinguish toggling its own target from taking over another target, while preserving existing same-target stop/cancel and push-to-talk behavior. Retest the reported command-palette transitions alongside the confirmed editor-to-chat failure.
