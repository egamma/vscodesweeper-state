# Issue #328759 — Transferring dictation targets does not work

[https://github.com/microsoft/vscode/issues/328759](https://github.com/microsoft/vscode/issues/328759)

## Summary

Keep open: the editor-to-chat microphone failure remains directly traceable in current main. The chat action stops whichever editor owns dictation and returns without starting dictation in the requested chat input, despite the shared session supporting takeover.

## Change summary

Starting dictation on another target should end the previous session and start recording on the requested target.

## Best solution

Make dictation entry points distinguish stopping their own session from taking over another target's session. Preserve same-target toggle behavior and the single-session constraint; check the reported command-palette transitions alongside the confirmed chat-microphone failure.
