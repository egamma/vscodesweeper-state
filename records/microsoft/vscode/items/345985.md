# Issue #345985 — remote.defaultExtensionsIfInstalledLocally zips and uploads local extensions instead of installing from the Marketplace (gallery manifest not yet available at window restore)

[https://github.com/microsoft/vscode/issues/345985](https://github.com/microsoft/vscode/issues/345985)

## Summary

The startup race remains in current source: pending Marketplace initialization can incorrectly select local packaging and tunnel upload. Keep this open while the linked fix PR is reviewed.

## Change summary

Remote default-extension installation uploads locally packaged extensions when Marketplace initialization has not finished, causing avoidable delays.

## Best solution

Ensure Marketplace initialization completes before deciding whether these extensions require local packaging, while preserving fallback for genuinely unavailable Marketplace extensions. Review the existing implementation candidate at https://github.com/microsoft/vscode/pull/346030 rather than starting competing work.
