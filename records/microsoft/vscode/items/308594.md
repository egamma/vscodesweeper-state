# Issue #308594 — Allow removal of image messages from context window.

[https://github.com/microsoft/vscode/issues/308594](https://github.com/microsoft/vscode/issues/308594)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/306383 tracks the same unrecoverable 400 response caused by oversized browser/tool-generated screenshots. This report adds useful evidence that restoring before the image can revert agent-authored files, which should be carried into the canonical issue.

## Change summary

Allow an oversized image introduced by a tool call to be removed from conversation context without rolling back subsequent agent-authored file changes.

## Best solution

Resolve https://github.com/microsoft/vscode/issues/306383 by preventing oversized tool-generated images from poisoning replayed history and by providing recovery that excludes the offending image without reverting workspace edits.
