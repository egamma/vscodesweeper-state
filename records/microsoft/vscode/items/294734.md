# Issue #294734 — Chat Linkification: when I click on `proxy.ts:22-27` I expect line 27 to be highlighted too

[https://github.com/microsoft/vscode/issues/294734](https://github.com/microsoft/vscode/issues/294734)

## Summary

Still reproduces on main: when clicking a chat inline anchor with a multi-line range (e.g. `proxy.ts:22-27`), only the start position is passed in the editor selection options — the endLineNumber/endColumn are omitted, so only line 22 through the start of 27 is highlighted instead of the full range.

## Change summary

Clicking a chat inline anchor like `file.ts:22-27` does not fully select the end line because the selection omits `endLineNumber` and `endColumn`.

## Best solution

In `chatInlineAnchorWidget.ts`, both the `openEditorWithSelection` function (line ~512) and the side-group opener (line ~448) should include `endLineNumber` and `endColumn` from `target.range`/`location.range` in the `selection` object so the full range is highlighted when clicking.
