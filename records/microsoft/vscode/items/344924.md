# Issue #344924 — Copilot harness: retain local memories

[https://github.com/microsoft/vscode/issues/344924](https://github.com/microsoft/vscode/issues/344924)

## Summary

Keep open: current main offers repository-local Copilot Memory, but that does not retain the Local harness's existing user, repository, and session memory files. The related feedback thread and user-memory report do not own this request's full scope.

## Change summary

Optionally let Copilot harness sessions reuse the Local harness's inspectable, editable local memory files, including session-scoped notes.

## Best solution

Provide an optional local-file memory mode for the Copilot harness that preserves the existing memory scopes and management experience without requiring cloud memory storage. Account explicitly for the existing repository-local Copilot Memory option rather than treating it as equivalent to Local harness memory.
