# Issue #344924 — Copilot harness: retain local memories

[https://github.com/microsoft/vscode/issues/344924](https://github.com/microsoft/vscode/issues/344924)

## Summary

Keep open for local, file-based user memory in the Copilot harness, as the maintainer explicitly agreed. The existing repository-local setting does not satisfy that request.

## Change summary

Allow Copilot harness sessions to reuse inspectable local memory files rather than requiring cloud-backed or repository-only memory.

## Best solution

Provide optional local, file-based user memory accessible across Copilot harness conversations and workspaces, coordinated with the related user-memory report. Clarify separately whether session memory and existing Local harness file compatibility are included.
