# Issue #274167 — Handle command substitions/complex destinations in file write detection

[https://github.com/microsoft/vscode/issues/274167](https://github.com/microsoft/vscode/issues/274167)

## Summary

A real gap remains on current main: command-substitution destinations are conservatively blocked rather than fully analyzed. The merged safety work intentionally retained this issue as a TODO.

## Change summary

Improve terminal file-write detection for redirection destinations containing command substitutions or other dynamic expressions.

## Best solution

Teach the terminal command analyzer to represent complex destinations accurately while preserving conservative approval behavior: auto-approve only when static analysis proves the resolved target remains inside the workspace, otherwise require confirmation.
