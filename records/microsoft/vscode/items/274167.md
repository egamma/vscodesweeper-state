# Issue #274167 — Handle command substitions/complex destinations in file write detection

[https://github.com/microsoft/vscode/issues/274167](https://github.com/microsoft/vscode/issues/274167)

## Summary

Keep open: command-substitution destinations are detected, but current main still conservatively requires approval rather than resolving them. The linked merged PR explicitly implements only part of this request and retains a TODO referencing this issue.

## Change summary

Handle command substitutions and other complex output destinations appropriately in terminal file-write detection.

## Best solution

Define which dynamic destinations can be classified safely under the existing outside-workspace approval policy, then support that defined subset while retaining explicit approval for unresolved destinations. Detection must not execute arbitrary substitutions merely to determine their output path.
