# Issue #349632 — Linux .deb: the `editor` alternative returns at once, so `git commit` aborts

[https://github.com/microsoft/vscode/issues/349632](https://github.com/microsoft/vscode/issues/349632)

## Summary

The documented Debian editor alternative still invokes the non-waiting launcher on current main, allowing Git to abort before editing finishes. Keep this open for a packaging and documentation fix; the related Snap registration request does not cover this defect.

## Change summary

Make the documented Linux editor-alternative setup wait for editing to finish instead of returning immediately.

## Best solution

Provide a synchronous editor-alternative contract while preserving ordinary code command behavior, with consistent Debian package lifecycle handling and Debian/Snap setup instructions. Prefer retaining a working alternative given Debian Policy 11.4; any removal needs an explicit maintainer decision.
