# Issue #64328 — Wasted space in the multiline search input

[https://github.com/microsoft/vscode/issues/64328](https://github.com/microsoft/vscode/issues/64328)

## Summary

The multiline Search input still reserves the controls' width across every line, so the requested layout improvement remains relevant. Keep this team-authored, accepted backlog request open for a design decision; no fixing commit or eligible duplicate canonical was established.

## Change summary

Let multiline search queries use more of the input's width without overlapping the search-option controls.

## Best solution

Agree on a responsive layout that gives wrapped queries more usable width while keeping the options discoverable and input sizing accurate. Revisit the proposed separate controls row against the later concern about visual crowding before implementing it in the Search input and its shared sizing infrastructure.
