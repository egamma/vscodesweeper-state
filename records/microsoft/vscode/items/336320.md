# Issue #336320 — Modern UI - Connected tabs feedback

[https://github.com/microsoft/vscode/issues/336320](https://github.com/microsoft/vscode/issues/336320)

## Summary

Active design-feedback thread on the experimental Modern UI 'connected tabs' style; a related refinement PR (#337126) already merged, and the reporter's own latest comment narrows the remaining gap to a per-theme border difference (Dark Modern vs Dark 2026) that they suspect is a theming choice rather than a missing implementation.

## Change summary

Visual polish requests for the Modern UI connected-tab style: larger radius/outline/spacing on the active tab, and a background-color inversion so the tabs container matches the workbench background (which also leaked into Classic UI and the Agents customization editor).

## Best solution

Continue iterating on src/vs/workbench/contrib/modernUI/browser/media/tabs.css and the shared theme tokens in src/vs/workbench/common/theme.ts (e.g. tab.activeBorder/tab.activeBorderTop) — a maintainer should decide whether Dark Modern should also apply an active-tab border like Dark 2026, since the color/border values are theme-defined, not hardcoded.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/modernUI/browser/media/tabs.css`, `src/vs/workbench/common/theme.ts`
- **Validation:** A visual/manual check comparing the active tab across Dark Modern and Dark 2026 themes in Modern UI after any token change, ensuring both meet whatever consistency decision is made.
- **Trace:**

  > src/vs/workbench/contrib/modernUI/browser/media/tabs.css sets --modern-ui-editor-tab-active-border and --modern-ui-editor-tab-active-border-top to transparent by default; theme.ts registers TAB_ACTIVE_BORDER/TAB_ACTIVE_BORDER_TOP so individual color themes can override them. Reporter observed Dark 2026 supplies a visible active-tab border while Dark Modern does not, and background-color choices for the tabs container also affect Classic UI and the Agents customization editor. Do not restructure the tab rendering pipeline; the boundary is which theme tokens get updated and to what values.
- **Open decisions:**
  - Should Dark Modern (and other built-in dark themes) get an active-tab border like Dark 2026, and if so what color/weight?
  - Should the tabs-container background be inverted to match the workbench background as the reporter suggests, and should that apply to Classic UI too, or only Modern UI?
  - Is the 'connected' vs 'pill' style choice for active vs inactive tabs something to formalize, or left to individual theme authors?
