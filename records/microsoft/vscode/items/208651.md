# Issue #208651 — Quick search - provide history

[https://github.com/microsoft/vscode/issues/208651](https://github.com/microsoft/vscode/issues/208651)

## Summary

Quick Search still lacks query-history navigation, but the older, open quick-input history request already owns that capability. Consolidate there while preserving this thread's requirement to navigate history without interfering with result selection.

## Change summary

Allow keyboard navigation through previously entered Quick Search queries, including when search results are present.

## Best solution

Track query-history cycling in https://github.com/microsoft/vscode/issues/18232, with Quick Search as an explicit consumer and history shortcuts kept distinct from result-navigation shortcuts.
