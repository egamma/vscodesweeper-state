# Issue #283221 — Changing the GitHub Copilot model in one workspace affects another, even in a different context.

[https://github.com/microsoft/vscode/issues/283221](https://github.com/microsoft/vscode/issues/283221)

## Summary

Current main no longer lets one chat's model choice replace another conversation's selected model. The model-selection architecture now stores intent per conversation and treats profile-level selection only as a seed for conversations without their own choice.

## Change summary

Keep an existing chat's selected Copilot model isolated when another chat context or VS Code workspace selects a different model.

## Best solution

Keep the per-conversation model ownership implemented in commit d9a8a27adef621fc7587d0a5d776cfd99e1b3e39; the existing Opus conversation now outranks the profile preference changed by another workspace.
