# Issue #327649 — Queued GitHub Copilot commands merged and use wrong model.

[https://github.com/microsoft/vscode/issues/327649](https://github.com/microsoft/vscode/issues/327649)

## Summary

The defect remains source-reproducible on current main: consecutive steering messages are deliberately merged, but routing and model options are taken only from the first message, so later custom prompts can lose command recognition and their selected model.

## Change summary

Separately submitted Copilot follow-ups can be combined into one request and executed with the first follow-up's model.

## Best solution

Keep compatible ordinary steering messages batchable, but preserve separate turns whenever queued inputs have distinct model or command-routing semantics so each submitted custom prompt uses its own captured options.
