# Issue #327649 — Queued GitHub Copilot commands merged and use wrong model.

[https://github.com/microsoft/vscode/issues/327649](https://github.com/microsoft/vscode/issues/327649)

## Summary

Current main conclusively contains this defect: consecutive Enter-submitted steering prompts are merged, reparsed as one message, and sent using only the first prompt's model options.

## Change summary

Multiple prompts submitted during compaction lose their individual slash-command parsing and model selections.

## Best solution

Adjust chat queue processing so steering requests with distinct slash commands, models, or other incompatible send options remain separate and execute sequentially, while retaining safe merging for compatible plain steering messages.
