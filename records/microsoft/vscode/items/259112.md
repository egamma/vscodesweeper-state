# Issue #259112 — Auto-update to host architecture when running under emulation

[https://github.com/microsoft/vscode/issues/259112](https://github.com/microsoft/vscode/issues/259112)

## Summary

Team-authored feature request still unimplemented on main — the darwin update service still relies solely on `process.arch` without detecting ARM64 translation. Keeping open in Backlog.

## Change summary

Auto-update to the native (host) architecture when VS Code detects it is running under ARM64 emulation on macOS.

## Best solution

In `src/vs/platform/update/electron-main/updateService.darwin.ts`, check `app.runningUnderARM64Translation` and, when true, use the arm64 asset ID instead of the x64 one derived from `process.arch`. This lets users who migrated from Intel Macs get the native build on next update without manual intervention.
