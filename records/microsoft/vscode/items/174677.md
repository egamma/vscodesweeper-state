# Issue #174677 — Zen Mode

[https://github.com/microsoft/vscode/issues/174677](https://github.com/microsoft/vscode/issues/174677)

## Summary

Keep open for design discussion: existing settings can reduce interruptions, but Toggle Zen Mode does not provide the requested reversible switch between automatic assistance and quiet editing. The older Zen Mode Settings issue is related, but does not report the same intrusive completion, hover, and live-diagnostic experience required for a duplicate close on this re-reviewed item.

## Change summary

Provide a quick, reversible quiet-editing mode that suppresses unsolicited suggestions, hovers, and diagnostic interruptions while preserving assistance on demand.

## Best solution

Define an opt-in quiet-editing experience that temporarily suppresses automatic editor interruptions, retains explicit assistance, and restores normal settings on exit. Coordinate its configuration semantics with https://github.com/microsoft/vscode/issues/45617 while deciding whether diagnostics should merely be hidden or actually deferred until save.

- **Behavior:**

  > The reporter wants to alternate quickly between normal editor assistance and quiet editing without permanently disabling useful features or changing profiles. Quiet editing should avoid the agreed unsolicited popups and diagnostic interruptions while retaining explicitly requested assistance. Leaving it should restore the user's normal behavior without a window reload. The design must distinguish suppressing diagnostic presentation from deferring diagnostic computation until save.
- **Trace:**

  > workbench.action.toggleZenMode delegates to Layout.toggleZenMode in src/vs/workbench/browser/layout.ts; its current transition handles layout, line numbers, tabs, and notifications, not suggestions, hovers, or problems visibility. Source inspection establishes a missing coordinated mode, not a defect in existing Zen Mode. https://github.com/microsoft/vscode/issues/45617 contains related configuration-override design discussion, but is not a verified same-symptom duplicate for this re-reviewed report. Uncertainty begins at the mode's product scope and whether diagnostics are hidden or deferred.
- **Open decisions:**
