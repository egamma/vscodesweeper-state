The ask — don't show suggestions unless explicitly invoked — is already covered by existing settings, so this can be closed as as-designed with a pointer to those settings.

## Change summary

Reporter wants VS Code to stop automatically popping up the suggestion/acceptance box while typing, showing it only when explicitly requested.

## Best solution

Point the reporter to `editor.quickSuggestions` (set to `off` to require explicit `Ctrl+Space` invocation) and `editor.inlineSuggest.enabled` (set to `false` to disable ghost-text/Copilot-style inline suggestions); no core change needed.
