# Issue #333170 — Not to show suggestions until and unless asked

[https://github.com/microsoft/vscode/issues/333170](https://github.com/microsoft/vscode/issues/333170)

## Summary

VS Code already supports showing completion suggestions only when explicitly requested. The existing settings cover this request without changing the default experience for other users.

## Change summary

Show editor completion suggestions only on explicit user request rather than automatically while typing.

## Best solution

Use editor.quickSuggestions=false and editor.suggestOnTriggerCharacters=false to disable automatic completion popups while retaining the explicit editor.action.triggerSuggest command.
