# Issue #338697 — Tab in opening counterpart of auto-closing pair does not work

[https://github.com/microsoft/vscode/issues/338697](https://github.com/microsoft/vscode/issues/338697)

## Summary

Thanks for the report. This is an acknowledged edge case in editor auto-closing, and an open PR already references it, so the issue stays open while that PR is reviewed. I did not trace the source myself.

## Change summary

An autoClosingPairs entry whose `open` ends in a tab character (`begin\t`) never inserts its `close` text, because Tab is not handled as typed text.

## Best solution

Review and land, or close, the linked PR https://github.com/microsoft/vscode/pull/339232. Any fix would sit in the auto-closing logic in src/vs/editor/common/cursor, and it should not change normal Tab handling.
