# Issue #325227 — Fish Shell Tab Completion Not Work

[https://github.com/microsoft/vscode/issues/325227](https://github.com/microsoft/vscode/issues/325227)

## Summary

Fish shell tab completion breaks when `editor.accessibilitySupport` is set to `on`, which enables xterm.js's `screenReaderMode`. The reporter narrowed it down and zsh works fine, suggesting the interaction between xterm.js screen-reader mode and fish's completion system. Routing to the terminal area for investigation.

## Change summary

Fish shell tab completion stops working in the integrated terminal when `editor.accessibilitySupport` is set to `on`.

## Best solution

Investigate how xterm.js's `screenReaderMode` (set via `updateAccessibilitySupport()` in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts:1988`) interferes with fish shell's tab completion. The root cause may be in xterm.js's keyboard handling under screen reader mode, or in how VS Code's terminal passes key events when accessibility is enabled. If the issue is in xterm.js, file upstream at xtermjs/xterm.js.
