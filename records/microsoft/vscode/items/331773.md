# Issue #331773 — It always asks to "Sign in to use GitHub Copilot" in new tab

[https://github.com/microsoft/vscode/issues/331773](https://github.com/microsoft/vscode/issues/331773)

## Summary

Reasonable, independently-confirmed report that the Copilot sign-in dialog reappears every time a new native tab/window is opened on macOS, even though (presumably) the user is already signed in; needs chat-entitlement engineering investigation rather than a close.

## Change summary

With native tabs enabled on macOS, opening a new tab/project repeatedly triggers the 'Sign in to use GitHub Copilot' dialog instead of recognizing the existing session.

## Best solution

Chat team should investigate how `ChatSetupRunner`/`IChatEntitlementService` resolve entitlement state for a freshly created native-tab window — likely a race where entitlement is still `Unknown` when the auto-run/dialog check fires for the new window, per src/vs/workbench/contrib/chat/browser/chatSetup/chatSetupRunner.ts (`getDialogTitle`, `showDialog`) — and ensure it awaits/reuses the resolved account state instead of re-prompting.
