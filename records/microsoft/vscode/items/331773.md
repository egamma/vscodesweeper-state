# Issue #331773 — It always asks to "Sign in to use GitHub Copilot" in new tab

[https://github.com/microsoft/vscode/issues/331773](https://github.com/microsoft/vscode/issues/331773)

## Summary

This is a real, widely-confirmed regression — the 'Sign in to use GitHub Copilot' prompt repeatedly reappears even after signing in, across 1.134–1.136.1 on both macOS and Windows — so it should stay open as a bug rather than info-needed; a maintainer already asked for confirmation and multiple users have supplied logs and a workaround, so the info-needed label no longer fits.

## Change summary

VS Code repeatedly shows the 'Sign in to use GitHub Copilot' prompt on new windows/tabs even though the user is already authenticated.

## Best solution

Investigate the GitHub/Copilot authentication session refresh path (likely related to the device-bound token / MSAL+WAM issue tracked in https://github.com/microsoft/vscode/issues/319673, or the sibling report https://github.com/microsoft/vscode/issues/333139) — multiple reporters confirm a sign-out/sign-in cycle temporarily clears it, pointing at a stale or invalid cached session/token being reused instead of refreshed.
