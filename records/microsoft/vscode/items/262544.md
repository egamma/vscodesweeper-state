# Issue #262544 — Task with process option prepends workspace directory

[https://github.com/microsoft/vscode/issues/262544](https://github.com/microsoft/vscode/issues/262544)

## Summary

Real bug confirmed in source: when a process-type task command resolves to an absolute path (e.g. via a variable like `${command:python.interpreterPath}`), the task system incorrectly prepends the workspace cwd. An open PR (#262547) is already addressing this.

## Change summary

Process-type tasks prepend the workspace directory to an already-absolute command path, breaking execution.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/262547 which fixes the absolute-path handling in the task terminal system's command resolution.
