# Issue #184406 — editor.renderFinalNewline is misleading

[https://github.com/microsoft/vscode/issues/184406](https://github.com/microsoft/vscode/issues/184406)

## Summary

Valid polish request: the setting name `editor.renderFinalNewline` is misleading — it controls the line number of the trailing empty line, not the newline character itself. The description is accurate but the name and option values (`off`/`on`/`dimmed`) don't convey the actual behavior. Still unfixed on current main.

## Change summary

The setting `editor.renderFinalNewline` has a misleading name and option values that suggest it controls rendering of the newline character, when it actually controls the line number display for the last empty line.

## Best solution

Renaming the setting is a breaking change (it would invalidate existing user/workspace settings), so the practical improvement is to add `enumDescriptions` to the three options (`off`, `on`, `dimmed`) that clearly explain they control the *line number* of the trailing empty line — similar to how `renderLineHighlight` documents its enum values. The description already says 'Render last line number' which is correct; richer per-value descriptions would close most of the confusion gap without a rename.
