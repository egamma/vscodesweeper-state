# Issue #297437 — Search subagent gaps with vscode custom agents

[https://github.com/microsoft/vscode/issues/297437](https://github.com/microsoft/vscode/issues/297437)

## Summary

Keep open as a team-authored architecture discussion: current main still implements search-specific runtime behavior outside the custom-agent contract, and the thread has not settled which capabilities should become public agent metadata, hooks, or remain private.

## Change summary

Determine how a custom agent can reproduce the search subagent's request budget, final-request guidance, model-dependent availability, hidden-model selection, and reference-to-snippet expansion.

## Best solution

Define the smallest reusable custom-agent contract for deterministic request budgets, model-based availability, and safe result transformation, while leaving search-specific policy private where it does not generalize. Resolve each gap explicitly so the bespoke search implementation can either migrate to a normal custom agent or document why it cannot.
