# Issue #107919 — Setting to follow to running cells in a notebook

[https://github.com/microsoft/vscode/issues/107919](https://github.com/microsoft/vscode/issues/107919)

## Summary

The request for an automatic scroll-to-follow-running-cell mode during notebook execution remains unimplemented. Current main has a manual 'Go to Running Cell' command and a `notebook.scrolling.revealNextCellOnExecute` setting for step-execution, but no auto-follow mode for 'Run All'.

## Change summary

Add a setting that automatically scrolls the notebook viewport to follow the currently executing cell during 'Run All'.

## Best solution

Implement a `notebook.scrolling.followRunningCell` setting (or similar) in `src/vs/workbench/contrib/notebook/browser/controller/executeActions.ts` that listens to cell execution state changes and reveals the running cell. The 'Go to Running Cell' action's reveal logic (`handleAutoReveal`) and the execution state service already provide the building blocks.
