# Issue #28235 — Provide Task Runner viewlet

[https://github.com/microsoft/vscode/issues/28235](https://github.com/microsoft/vscode/issues/28235)

## Summary

This is the canonical team-authored tracking issue for a dedicated Task Runner viewlet/sidebar. The core ask — a task explorer view in the sidebar with task discovery, status, and in-place configuration — remains unimplemented on current main. Tasks still run exclusively through the terminal panel and the command-palette quick picker. Multiple satellite issues (#160648, #148028, #152657, #110998) were closed as duplicates of this one. Team-authored, On Deck milestone, 37 upvotes — keeping open.

## Change summary

Provide a dedicated Task Runner viewlet in the sidebar showing discovered tasks, running status, execution history, and in-place configuration.

## Best solution

Implement a tree-view-based task explorer in the sidebar (Activity Bar) that surfaces auto-detected and configured tasks, shows run/stop controls, displays execution status (exit code, duration), and supports in-place problem-matcher configuration — reducing the dependency on JSON editing and the command palette for task workflows.
