# Issue #28235 — Provide Task Runner viewlet

[https://github.com/microsoft/vscode/issues/28235](https://github.com/microsoft/vscode/issues/28235)

## Summary

Keep open: current task commands and the npm Scripts view do not provide the requested persistent, provider-independent task overview. This team-authored, accepted request is itself the canonical target of later Task Explorer reports; extension feasibility is not a maintainer decision to decline it.

## Change summary

Provide a persistent task UI for discovering available tasks, seeing running tasks, and accessing execution and configuration actions.

## Best solution

Retain this issue as the canonical request and have the tasks/UX owners settle the remaining UI scope and whether it should ship built-in or through an extension. Preserve terminal-backed execution rather than treating the existing npm-only view or transient task picker as complete coverage.
