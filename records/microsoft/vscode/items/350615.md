[https://github.com/microsoft/vscode/issues/350615](https://github.com/microsoft/vscode/issues/350615)

## Summary

Keep open: Agents SSH still uses ssh2, whose FIDO key support remains an open upstream limitation, compounded by incomplete identity selection in VS Code. This team-authored report has no verified fixing commit or canonical duplicate.

## Change summary

Agents window SSH connections fail with FIDO-backed keys while troubleshooting lists identities that authentication does not attempt.

## Best solution

Provide end-to-end FIDO authentication through a capable native SSH transport or adopted upstream support, with diagnostics distinguishing configured identities from actual authentication attempts. Preserve Windows executable selection and hardware touch/PIN handling; adding default key filenames alone is insufficient.
