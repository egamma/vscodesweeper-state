The reported crash has a bisected upstream Node/base64 cause, and upstream changes suggest it may already be resolved. Keep this upstream tracking issue open: the current bundled runtime has not been verified on the reported configuration, and no eligible canonical duplicate was found.

## Change summary

Prevent the remote extension host from executing AVX-512 base64 instructions when Linux has disabled AVX-512 support.

## Best solution
