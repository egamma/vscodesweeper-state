# Issue #289972 — multi device folders in workspace

[https://github.com/microsoft/vscode/issues/289972](https://github.com/microsoft/vscode/issues/289972)

## Summary

The requested cross-device workspace conflicts with the established one-remote-authority-per-window design. Current source deliberately rejects workspace folders belonging to another remote authority, so this can be closed as designed.

## Change summary

Allow one multi-root workspace and its AI context to include folders hosted on multiple tunneled devices.

## Best solution

Keep each remote authority isolated to its own VS Code window rather than combining multiple devices in one workspace; supporting this request would require revisiting the remote-window architecture rather than a bounded workspace-folder enhancement.

- **Proposed comment:**

  > Thanks for the request. A remote VS Code window intentionally supports a single remote authority: the existing design decision is documented at https://github.com/microsoft/vscode/issues/94191#issuecomment-608285021, and current workspace code continues to reject folders from a different remote authority. Combining folders from multiple tunneled devices in one workspace is therefore not supported by the current remote-window architecture.
