# Issue #340058 — [Error] unhandlederror-Timed out waiting for URI handler

[https://github.com/microsoft/vscode/issues/340058](https://github.com/microsoft/vscode/issues/340058)

## Summary

Automated error-dashboard report of a real unhandled-rejection bug: `extHostAuthentication.ts` fires `this._proxy.$waitForUriHandler(appUri)` with `void` and no `.catch`, so the 5-minute timeout rejection in `mainThreadAuthentication.ts#$waitForUriHandler` surfaces as an unhandled error even though the result is intentionally unused.

## Change summary

Dynamic/loopback OAuth sign-in logs an 'unhandlederror-Timed out waiting for URI handler' whenever the fire-and-forget URI-handler registration times out.

## Best solution

Attach a no-op/log-only `.catch()` to the fire-and-forget `this._proxy.$waitForUriHandler(appUri)` call in `extHostAuthentication.ts` so the expected 5-minute timeout (the real auth result comes from `server.waitForOAuthResponse()`, not this call) no longer produces an unhandled rejection.
