# Issue #343886 — Nesting a renamed session that used a subagent shows its old title, and Undo keeps it

[https://github.com/microsoft/vscode/issues/343886](https://github.com/microsoft/vscode/issues/343886)

## Summary

The reported title mismatch remains in current source: hidden subagent chats prevent a session rename from reaching its default chat, whose stale title is then used on promotion. Keep this open for a bounded title-synchronization fix.

## Change summary

Preserve a renamed session's title in its main chat, nested row, and subsequent Undo or Promote to Session when it contains only hidden subagent descendants.

## Best solution

Make session/default-chat title synchronization respect the distinction between hidden tool descendants and independently titled public chats. Preserve existing independent titles for genuinely multi-chat sessions and retain the user's title across nesting, promotion, and restoration.
