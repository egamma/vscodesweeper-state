# Issue #154417 — update the language pack and then click reload then the shown language is changed to English

[https://github.com/microsoft/vscode/issues/154417](https://github.com/microsoft/vscode/issues/154417)

## Summary

Keep this as the established report for language-pack updates followed by a window reload reverting the UI to English. Multiple reporters confirmed the behavior, and maintainers consolidated later reports here; current-source inspection does not establish a complete fix.

## Change summary

After a language-pack update, reloading the window displays English even though Chinese remains the configured display language.

## Best solution

Preserve the selected display language across language-pack updates and window reloads in the native localization lifecycle. First verify the reported sequence in a current packaged build, distinguishing whole-workbench fallback from extension-only translation failures.
