# Issue #320236 — Copilot System prompt always trips Azure OpenAI Jailbreak filter

[https://github.com/microsoft/vscode/issues/320236](https://github.com/microsoft/vscode/issues/320236)

## Summary

The Copilot system prompt triggers Azure OpenAI's jailbreak content filter when using BYOK with Azure endpoints, making agent mode unusable for BYOK-Azure users. A second user has confirmed a similar experience. The bug is in-scope — the system prompt is assembled by the Copilot extension in this repo — but more investigation is needed to determine whether the prompt content or the Azure request format is the root cause.

## Change summary

Copilot's system prompt consistently triggers Azure OpenAI's jailbreak content filter when using BYOK with Azure OpenAI endpoints, blocking agent-mode requests with HTTP 400.

## Best solution

Investigate the system prompt content sent via the BYOK Azure OpenAI path (`extensions/copilot/src/extension/byok/node/azureOpenAIEndpoint.ts` and prompt assembly) to identify what triggers Azure's jailbreak detector. The fix likely involves adjusting prompt phrasing or splitting the system message to avoid the filter, or adding Azure-specific content-filter configuration headers. The `model-byok` label and Copilot team should own this.
