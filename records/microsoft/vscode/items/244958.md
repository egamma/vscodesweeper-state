# Issue #244958 — Debug Toolbar in issue reporter

[https://github.com/microsoft/vscode/issues/244958](https://github.com/microsoft/vscode/issues/244958)

## Summary

Still reproduces on main: the debug toolbar follows `layoutService.activeContainer` without filtering out non-workbench windows like the issue reporter. No fix has landed.

## Change summary

The floating debug toolbar appears inside the issue reporter window when a debug session is active and the issue reporter becomes the active container.

## Best solution

Guard `doShowInActiveContainer()` in `src/vs/workbench/contrib/debug/browser/debugToolBar.ts` to skip appending the toolbar when the active container belongs to a non-workbench auxiliary window (such as the issue reporter). The `onDidChangeActiveContainer` handler (line 208) should check whether the new container is suitable before calling `doShowInActiveContainer()`.
