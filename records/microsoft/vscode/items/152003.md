# Issue #152003 — VirtualFileSystem Workspace Trust API

[https://github.com/microsoft/vscode/issues/152003](https://github.com/microsoft/vscode/issues/152003)

## Summary

Keep open: this team-authored `api-proposal` tracks an unresolved API-design question, and proposal-tracking issues remain open until the API owners finalize or explicitly abandon them. Current main still offers file-system providers no way to influence workspace trust.

## Change summary

Allow virtual file-system providers to supply information used when determining workspace trust.

## Best solution

The workspace-trust and API owners should define whether provider input is scheme-wide or resource-specific, establish safe precedence against user and remote trust decisions, and then either advance the resulting proposed API through finalization or explicitly abandon the proposal.
