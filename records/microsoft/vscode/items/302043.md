# Issue #302043 — Terminal commands are always cropped after N character

[https://github.com/microsoft/vscode/issues/302043](https://github.com/microsoft/vscode/issues/302043)

## Summary

The defect remains on current main: terminal tool headers truncate commands to 50 characters before responsive layout occurs. Route this confirmed, bounded chat-terminal UI bug to the terminal area.

## Change summary

Terminal tool headers should use the available row width before ellipsis-truncating long commands.

## Best solution

Preserve the complete command in the collapsible header and let the existing responsive, single-line ellipsis layout determine what fits at the current width, without changing the command output or expansion behavior.
