# Issue #302043 — Terminal commands are always cropped after N character

[https://github.com/microsoft/vscode/issues/302043](https://github.com/microsoft/vscode/issues/302043)

## Summary

The fixed character cap remains on current main: terminal-tool headers discard command text after 50 characters regardless of available width. Keep this accepted UX improvement open; the thread has not settled single-line ellipsis versus bounded wrapping.

## Change summary

Make collapsed terminal-tool command titles respond to available width instead of truncating at a fixed character count.

## Best solution

Let the chat terminal header use the available space while keeping long commands visually bounded and preserving expansion and terminal actions. Decide whether the header stays single-line or permits a limited number of wrapped lines before implementation.
