# Issue #311867 — Plan->Agent doesnt give permissions to edit code

[https://github.com/microsoft/vscode/issues/311867](https://github.com/microsoft/vscode/issues/311867)

## Summary

Keep open as a confirmed Plan-to-Agent handoff bug. The reporter supplied the requested log, and a newer independent report shows that implementation handoffs can still lose the approved plan, while no merged fix or open fixing PR was found.

## Change summary

Starting implementation from a completed Plan session switches to Agent without reliably carrying the approved plan or granting the expected editing capability.

## Best solution

Make the Plan-to-Agent handoff preserve the authoritative plan and activate an editing-capable Agent context before submitting the implementation request, with an integration-level regression test covering the complete transition.
