# Issue #235535 — preview flag not respected for custom editor

[https://github.com/microsoft/vscode/issues/235535](https://github.com/microsoft/vscode/issues/235535)

## Summary

Already fixed and shipped: the issue author's own PR #235533 was merged, moving the spread operator so user-provided options (including `preview: true` → `pinned: false`) override the default `pinned: true`. The fix landed in 1.97.0.

## Change summary

The `preview` option passed to `vscode.openWith` for custom editors was ignored because a hardcoded `pinned: true` was placed after the user options spread, always overriding it.

## Best solution

Keep the shipped fix from commit 648def3 (1.97.0). The open PR #255247 proposes removing the `pinned: true` default entirely, which is a separate behavioral change — that can be evaluated independently. This issue is resolved.
