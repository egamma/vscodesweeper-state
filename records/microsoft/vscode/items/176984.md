# Issue #176984 — Workspace edits with metadata do not show labels that docs say are rendered prominently

[https://github.com/microsoft/vscode/issues/176984](https://github.com/microsoft/vscode/issues/176984)

## Summary

A real gap remains: refactor previews still default to grouping by file, which hides edit metadata labels. The Backlog milestone and existing under-discussion classification support keeping this open for an API and UX decision.

## Change summary

Show workspace-edit metadata labels by default, or clarify and adjust the API when labels are not displayed.

## Best solution

Decide whether labeled edits should default to type grouping in `BulkEditPane`; alternatively, let extensions request that presentation through `WorkspaceEditMetadata` as tracked by https://github.com/microsoft/vscode/issues/207580. If file grouping remains the default, update the API documentation to describe when labels appear.
