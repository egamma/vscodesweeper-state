# Issue #171920 — File Watcher overwrites external file changes for Jupyter Notebooks

[https://github.com/microsoft/vscode/issues/171920](https://github.com/microsoft/vscode/issues/171920)

## Summary

Keep open as the canonical notebook external-change bug. Current source intends to reload clean notebook working copies, while multiple recent reports confirm that external `.ipynb` edits still remain stale.

## Change summary

Externally modifying a saved Jupyter notebook does not refresh its open notebook editor, risking later overwrite of the disk changes.

## Best solution

Ensure clean notebook working copies reliably reload after file-system changes, including atomic replacement by formatters and agents, while preserving conflict protection for genuinely dirty notebooks. The fix likely belongs in notebook serialization/working-copy integration.
