## Summary

The reporter is on 1.124.2, which includes the earlier clipping fix (d1627066acf9, shipped in 1.120.0), yet the last items in Chat Customization lists (MCP, Skills) are still clipped. Significant layout and style changes have landed since that fix, suggesting a regression or a related but distinct clipping scenario. Routes to the chat area for investigation.

## Change summary

Last items in Chat Customization list widgets (MCP, Skills, etc.) are clipped and not visible even when scrolled to the bottom.

## Best solution

Investigate the layout calculation in `aiCustomizationManagementEditor.ts` (line ~480: `height - 16`) against the actual CSS padding/border of the content containers (`padding: 40px 40px 16px`, `border: 1px`) and the internal list widget layout in `aiCustomizationListWidget.ts`. The hardcoded `height - 16` deduction may not account for all vertical chrome (content container padding, border, section headers). A dynamic measurement approach — similar to what was done for the sidebar header in the earlier fix — would be more robust.
