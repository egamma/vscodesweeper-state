# Issue #327574 — SCM origin URLs to launch/copy for browsing, create issue etc

[https://github.com/microsoft/vscode/issues/327574](https://github.com/microsoft/vscode/issues/327574)

## Summary

This customizable remote-link launcher is well suited to an extension, with an existing extension already identified by the reporter and a closely matching core request previously declined.

## Change summary

Add SCM actions that open or copy customizable repository-hosting URLs such as the repository page and new-issue form.

## Best solution

Provide this through an extension that derives configurable links from the Git remote; keep VS Code's built-in hosting actions limited to provider-contributed workflows.

## Vision fit

- **Fit:** rejected
- **Reason:** Custom host-specific URL templates are specialized functionality that can be delivered through the extension ecosystem without expanding core SCM configuration.
- **Evidence:** Public roadmap value: “The power lives in extensions,” while the default editor should remain lightweight and fast.
