## Summary

The empty-scope token-handling failure diagnosed in the discussion is addressed by a merged fix present on current main. Propose closing as completed: session construction no longer reads incompatible JWT scope claims when the requested scopes are empty.

## Change summary

OAuth-authenticated MCP connections fail without a Bearer token after session retrieval throws during scope handling.

## Best solution
