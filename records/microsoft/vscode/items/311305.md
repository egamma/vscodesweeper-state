# Issue #311305 — Missing Bearer token error when connecting to MCP behind OAuth

[https://github.com/microsoft/vscode/issues/311305](https://github.com/microsoft/vscode/issues/311305)

## Summary

Keep open: an independent reproduction and stack trace identify a core OAuth session failure, not merely malformed server metadata. Current source handles part of the diagnosed empty-scope case, but neither a complete fixing commit nor an older same-symptom canonical has been established.

## Change summary

OAuth-protected HTTP MCP connections fail with a session-filtering TypeError and a missing Bearer token despite successful authorization.

## Best solution

Ensure successful OAuth authorization yields a usable authentication session and an Authorization header for the MCP request, including when the server supplies default scopes. Investigate the token-to-session conversion in extHostAuthentication.ts against the reported Okta and Sumo Logic cases before deciding whether the current empty-scope handling fully resolves this report.
