# Issue #338541 — Sessions list items can be cut off by pills

[https://github.com/microsoft/vscode/issues/338541](https://github.com/microsoft/vscode/issues/338541)

## Summary

Credible, screenshot-confirmed visual bug from a team member testing the sub-chats work (#338224): the last item in a scrollable Sessions list is clipped by a status/changes pill when file changes are present. I could not pin the exact overlapping element or root cause in the source, so this stays open rather than being treated as a confirmed close candidate.

## Change summary

When the Sessions list is scrollable and a 'file changes' pill is visible, the last visible session row gets cut off by the pill instead of being fully shown.

## Best solution

Trace which floating/absolute-positioned element (a details-row diff/status pill or a list-level overlay) overlaps the last row, and either reserve bottom padding on the list scrollable area or adjust that element's stacking/position so it never clips list content in `src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts` and `media/sessionsList.css`.
