# Issue #174088 — Git - Provide icon buttons for common source control actions

[https://github.com/microsoft/vscode/issues/174088](https://github.com/microsoft/vscode/issues/174088)

## Summary

Keep open under the existing Git/UX discussion: the reporter clarified that Fetch, Pull, Push, and Sync should be directly accessible from the Source Control toolbar. Current menu registrations and the conditional Sync action button only partially cover that request.

## Change summary

Provide Source Control toolbar icon buttons for Fetch, Pull, Push, and Sync instead of requiring the overflow menu.

## Best solution

Agree on a compact, discoverable presentation of common remote Git operations in the Source Control view, then implement it through the Git extension's SCM menu contributions. Preserve existing commit and repository-context behavior rather than treating a conditional Sync button or a separate graph toolbar as full coverage.
