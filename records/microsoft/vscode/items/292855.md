# Issue #292855 — "open folder" or "open file" opens on wrong display when logged in via ssh

[https://github.com/microsoft/vscode/issues/292855](https://github.com/microsoft/vscode/issues/292855)

## Summary

Keep open: the report supplies concrete steps to retest a native file picker appearing on the console display instead of the SSH-forwarded display. Current main has changed its Electron runtime and Linux desktop identity since the report, but source inspection cannot establish whether this environment-dependent defect is resolved.

## Change summary

Open File and Open Folder dialogs appear on the local graphical console when VS Code is launched through SSH with an X11-forwarded DISPLAY.

## Best solution

Ensure native file pickers appear on the display hosting the requesting VS Code window, without requiring the graphical console to be disabled. First reproduce the same-user console-plus-SSH setup and determine whether display selection fails in VS Code's window selection or Electron's native dialog backend.
