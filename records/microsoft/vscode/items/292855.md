# Issue #292855 — "open folder" or "open file" opens on wrong display when logged in via ssh

[https://github.com/microsoft/vscode/issues/292855](https://github.com/microsoft/vscode/issues/292855)

## Summary

Likely an Electron/GTK upstream issue — VS Code delegates file dialogs to Electron's native dialog API, which uses GTK on Linux; display routing with X11 forwarding is not controlled by VS Code. Requesting confirmation on whether the VS Code window itself appears on the correct display.

## Change summary

The native 'Open Folder' dialog appears on the local graphical display (:0.0) instead of the X11-forwarded display (localhost:10.0) when connected via SSH.

## Best solution

Clarify whether the VS Code window itself opens on the correct display. If the window is correct but only the dialog is wrong, this is an Electron bug (Electron parents the GTK dialog to the wrong display). File upstream at https://github.com/electron/electron. If both window and dialog are wrong, the DISPLAY variable isn't being inherited properly by Electron.
