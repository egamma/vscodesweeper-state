# Issue #178042 — Keybindings generated using `Define Keybindings` command is not formatted.

[https://github.com/microsoft/vscode/issues/178042](https://github.com/microsoft/vscode/issues/178042)

## Summary

Still reproduces on main: when the 'Define Keybinding' button inserts a keybinding after an existing entry, SmartSnippetInserter prepends only a comma without a newline, producing unformatted output on the same line as the prior entry's closing brace.

## Change summary

Keybinding snippet inserted via the 'Define Keybinding' button lacks a newline before the new entry, breaking JSON formatting in keybindings.json.

## Best solution

In `src/vs/workbench/contrib/preferences/common/smartSnippetInserter.ts`, change the `AFTER_OBJECT` prepend from `','` to `',\n'` (or apply a document format-on-insert) so that the generated keybinding starts on a new line. The snippet itself already includes internal newlines and tabs.
