## Summary

Keep open: current source still passes an ambiguous upstream name to Git, matching the report's fetch of tag main instead of branch main. The full log also shows a concurrent-fetch failure; the related older issue does not cover the persistent branch/tag collision.

## Change summary

After merging a PR and returning to main, Sync Changes fails to retrieve remote branch commits when a same-named tag exists, with an additional overlapping-fetch error in the log.

## Best solution

Ensure built-in Git pull and sync reliably target the configured upstream branch even when a tag shares its name. Separately establish whether the automatic post-merge failure is entirely covered by the existing concurrent-fetch issue before treating this report as resolved.
