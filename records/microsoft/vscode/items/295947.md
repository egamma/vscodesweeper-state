# Issue #295947 — Browser: DevTools becomes blank on overlaps

[https://github.com/microsoft/vscode/issues/295947](https://github.com/microsoft/vscode/issues/295947)

## Summary

Still reproduces on main: the screenshot/placeholder path only captures the page's webContents, not the devtools webContents, so docked DevTools go blank when overlapping UI triggers the placeholder. The related issue #322208 was closed back to this one after fixing the stretching regression, but the core blank-devtools problem remains unfixed.

## Change summary

Docked DevTools in the Integrated Browser become completely blank when overlapping UI elements trigger the placeholder screenshot path, because the screenshot does not include the DevTools webContents.

## Best solution

Extend the screenshot capture in `src/vs/platform/browserView/electron-main/browserView.ts` to also call `webContents.devToolsWebContents.capturePage()` when devtools are docked, then composite the two images into the placeholder. Guard against popped-out DevTools (skip the devtools capture when undocked).
