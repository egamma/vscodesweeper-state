# Issue #335425 — Integrated terminal inserts IME-committed text twice (WeChat IME voice input, Windows)

[https://github.com/microsoft/vscode/issues/335425](https://github.com/microsoft/vscode/issues/335425)

## Summary

Well-diagnosed report: text committed as a whole sentence via the TSF/IME commit channel (WeChat voice input) gets duplicated in the integrated terminal but not in the editor or other apps, pointing at xterm.js's composition handling rather than VS Code's own code — this is an upstream terminal-frontend issue in the family of prior 'IME text doubled' reports.

## Change summary

WeChat IME voice-dictated text is inserted twice into the VS Code integrated terminal on Windows, while the same input works correctly in the editor area and other apps.

## Best solution

Track as upstream in xterm.js's CompositionHelper (src/browser/input/CompositionHelper.ts) — the prior Sogou/Chinese-IME doubling reports (issues #235138, #135940, #141578) were fixed there via xtermjs/xterm.js#3533, but this report shows the whole-sentence TSF commit path used by WeChat's voice input still triggers the same double-insert; needs a fresh upstream repro/fix rather than a VS Code-side change.
