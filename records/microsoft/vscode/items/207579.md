# Issue #207579 — Refactor preview is missing checkboxes on groups

[https://github.com/microsoft/vscode/issues/207579](https://github.com/microsoft/vscode/issues/207579)

## Summary

Keep this accepted feature request open: current source still renders category headers without checkboxes, despite supporting category-wide toggling. Its 23 upvotes and Backlog promotion establish community demand; the existing keyboard and context-menu actions do not cover the requested visible affordance.

## Change summary

Show checkboxes on refactor-preview category headers so users can discover and toggle selection of an entire group.

## Best solution

Make category selection visibly discoverable and consistent with file and edit selection in the bulk-edit preview, while preserving existing group-toggle semantics and keyboard navigation. Treat the reporter's additional check/uncheck-all request as a separate scope consideration rather than a prerequisite.
