# Issue #26289 — [json] use the schemastore catalog

[https://github.com/microsoft/vscode/issues/26289](https://github.com/microsoft/vscode/issues/26289)

## Summary

Still valid: the JSON language server does not fetch or use the SchemaStore catalog (catalog.json) for automatic schema associations. Schema associations today come only from extensions, user settings, and a dynamic internal source — no catalog integration exists on current main.

## Change summary

Automatically associate JSON files with schemas from the SchemaStore catalog so users get validation, completions, and hovers without manual configuration or installing per-schema extensions.

## Best solution

Implement fetching of the SchemaStore catalog (https://www.schemastore.org/api/json/catalog.json) in the JSON language features client, using catalog entries as fallback associations when no extension or user setting already covers a file pattern. Add a `json.schemaStore.enable` setting (default true) so users can disable it, and ensure extension/user-setting associations always take precedence. The work lives in `extensions/json-language-features/client/src/jsonClient.ts` around `computeSchemaAssociations`. PR https://github.com/microsoft/vscode/pull/69132 was an earlier attempt that stalled — its approach and review feedback are worth revisiting.
