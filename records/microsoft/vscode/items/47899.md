# Issue #47899 — Allow webviews to be shown in modal windows

[https://github.com/microsoft/vscode/issues/47899](https://github.com/microsoft/vscode/issues/47899)

## Summary

The internal modal editor infrastructure now exists (modalEditorPart.ts, used by Settings, extensions, issue reporter), but no extension API is exposed for opening webviews in modals. The feature request for an extension-facing API remains valid and unimplemented.

## Change summary

Allow extensions to show webview content in modal/popup windows instead of only as editor tabs.

## Best solution

Expose a proposed extension API (e.g. on `window` or `WebviewPanel`) that lets extensions open a webview panel in the modal editor part. The internal infrastructure in `src/vs/workbench/browser/parts/editor/modalEditorPart.ts` already supports webview editors in modals — the gap is the public API surface.
