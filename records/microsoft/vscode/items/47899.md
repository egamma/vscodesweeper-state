# Issue #47899 — Allow webviews to be shown in modal windows

[https://github.com/microsoft/vscode/issues/47899](https://github.com/microsoft/vscode/issues/47899)

## Summary

Keep this accepted API request open: extensions still lack an explicit modal target for webview creation. The related ViewColumn.Modal PR remains open, and its current changes do not cover the webview-specific target-group handling.

## Change summary

Allow extensions to present graphical forms, previews, and wizards in modal webviews rather than editor tabs.

## Best solution

Review https://github.com/microsoft/vscode/pull/307838 for end-to-end webview support, including creation and reveal through the webview-specific group resolver. Retain this request until a supported API actually opens webviews in the modal overlay; exposing the enum alone is insufficient.
