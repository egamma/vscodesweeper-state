# Issue #175330 — Diagnostics jump around in the minimap when scrolling

[https://github.com/microsoft/vscode/issues/175330](https://github.com/microsoft/vscode/issues/175330)

## Summary

Still reproducible on main: the minimap decoration Y-position depends on `startLineNumber` which is computed with `Math.floor` and can shift ±1 during sub-line scrolling despite an anti-flicker guard. No fix has been committed for this specific jitter.

## Change summary

Minimap diagnostics (decorations) visually jump ±1 line while smoothly scrolling, because the minimap layout's startLineNumber computation introduces rounding jitter.

## Best solution

The rounding in `MinimapLayout.create` (line 377 of `src/vs/editor/browser/viewParts/minimap/minimap.ts`) that computes `startLineNumber` via `Math.floor` causes the decoration canvas to shift by one minimap line during sub-pixel scroll increments. The existing anti-flicker guard (lines 386–398) mitigates but does not fully prevent this. A fix would stabilize the decoration rendering relative to the scroll position, likely by anchoring the decoration canvas offset more smoothly rather than relying solely on integer line snapping.
