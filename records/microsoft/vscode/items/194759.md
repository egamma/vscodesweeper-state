# Issue #194759 — Fallback to default language if `files.associations` points to a invalid language

[https://github.com/microsoft/vscode/issues/194759](https://github.com/microsoft/vscode/issues/194759)

## Summary

A real gap remains on current main: an unavailable language ID in `files.associations` overrides the built-in association and ultimately selects plain text. The issue is already correctly classified and routed, with `keep` explicitly signaling that it should remain open.

## Change summary

Fall back to the built-in file association when a configured association references a language that is unavailable.

## Best solution

After extension language contributions are known, ignore an applicable configured association whose language ID is not registered and continue to the platform association, while preserving configured precedence when that language becomes available.
