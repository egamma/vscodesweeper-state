# Issue #121896 — Absolute Path for Full Path Snippet Variables 

[https://github.com/microsoft/vscode/issues/121896](https://github.com/microsoft/vscode/issues/121896)

## Summary

A real capability gap remains on main: path snippet variables still return display labels that may abbreviate the home directory. Keep this Backlog feature request open for product discussion.

## Change summary

Provide snippet variables that resolve file and directory paths without abbreviating the user's home directory as `~`.

## Best solution

Preserve the existing variables for compatibility while exposing untildified absolute variants for `TM_DIRECTORY` and `TM_FILEPATH`, using the label service's existing `noPrefix` option and documenting their cross-platform behavior.

## Evidence
