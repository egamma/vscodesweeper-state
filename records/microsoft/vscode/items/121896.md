# Issue #121896 — Absolute Path for Full Path Snippet Variables 

[https://github.com/microsoft/vscode/issues/121896](https://github.com/microsoft/vscode/issues/121896)

## Summary

Keep open: current snippet path variables still use display labels that can abbreviate the home directory, and no absolute-path variants cover the request. The issue is already correctly routed to snippets; no verified canonical or fixing commit was found.

## Change summary

Provide full-path snippet variables that expand the home directory rather than inserting a tilde-abbreviated path.

## Best solution

Provide an explicit way to obtain non-abbreviated file and directory paths in the snippet variable resolver while preserving existing variables and target-platform path formatting. The snippet owner should decide the public variable names and behavior for remote or non-file resources before implementation.
