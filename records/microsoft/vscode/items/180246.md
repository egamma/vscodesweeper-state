# Issue #180246 — Markdown: Shell fenced code block have incorrect synthax highlighting after indent

[https://github.com/microsoft/vscode/issues/180246](https://github.com/microsoft/vscode/issues/180246)

## Summary

Confirmed upstream grammar bug: the TextMate markdown grammar from textmate/markdown.tmbundle doesn't handle syntax highlighting of fenced code blocks when indented inside list items. The upstream issue (textmate/markdown.tmbundle#55) is still open, and VS Code imports this grammar — so no fix is possible on the VS Code side until the upstream grammar is updated.

## Change summary

Shell fenced code blocks inside indented markdown list items lose syntax highlighting.

## Best solution

Wait for the upstream fix at https://github.com/textmate/markdown.tmbundle/issues/55 and then update the grammar in `extensions/markdown-basics/syntaxes/markdown.tmLanguage.json`. Alternatively, per the closed https://github.com/microsoft/vscode/issues/237316, the team considered switching to a new markdown grammar — if that happens it may resolve this class of issues.
