# Issue #200867 — Setting editor.find.seedSearchStringFromSelection to Always does not always seed the Find Widget

[https://github.com/microsoft/vscode/issues/200867](https://github.com/microsoft/vscode/issues/200867)

## Summary

Current behavior intentionally limits normal Find seeding to single-line selections. The identical multiline request was previously declined as out of scope, so this should be classified consistently rather than retained as a bug.

## Change summary

Seed the editor Find Widget from selections containing newlines when `editor.find.seedSearchStringFromSelection` is `always`.

## Best solution

Keep normal Ctrl+F seeding restricted to one line and use the existing “Find with Selection” command when a multiline selection must populate the Find Widget.
