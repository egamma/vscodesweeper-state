# Issue #200867 — Setting editor.find.seedSearchStringFromSelection to Always does not always seed the Find Widget

[https://github.com/microsoft/vscode/issues/200867](https://github.com/microsoft/vscode/issues/200867)

## Summary

The reporter's newline trigger still fails in current source: Find and Replace explicitly exclude multiline selections from search-string seeding. Keep this older, already-triaged report as the canonical issue; a newer report independently confirms the same behavior.

## Change summary

With editor.find.seedSearchStringFromSelection set to always, opening Find or Replace should seed the search field from selected text containing a newline.

## Best solution

Make ordinary Find and Replace honor the selection-seeding setting for multiline text while preserving regex handling, search-scope settings, and focused-input behavior. Consolidate the matching newer report at https://github.com/microsoft/vscode/issues/307720 into this issue.
