## Summary

Keep open: current workspace and host selection provide useful building blocks, but do not establish the requested independent, extensible new-session environment choice. This team-authored request has no verified fixing commit or canonical duplicate.

## Change summary

Add an extensible environment picker independent of source and harness selection, with explicit compatibility feedback and preserved selection.

## Best solution

Establish a provider-neutral environment-selection contract across the new-session composer, provider capabilities, session creation, and restoration. Reuse existing environment metadata and connection infrastructure while keeping source, environment, and harness choices distinct.
