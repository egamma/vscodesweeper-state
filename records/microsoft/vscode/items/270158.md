# Issue #270158 — [Bug] IME fails in Integrated Terminal when "Screen Reader Optimized" mode is active

[https://github.com/microsoft/vscode/issues/270158](https://github.com/microsoft/vscode/issues/270158)

## Summary

Confirmed bug: IME composition input is broken in the integrated terminal when screenReaderMode is active via xterm.js. A second user independently confirmed on macOS with the built-in Pinyin IME. No fix exists on current main.

## Change summary

IME input (Chinese/CJK composition) fails silently in the integrated terminal when 'Screen Reader Optimized' mode is active.

## Best solution

The conflict is between xterm.js's screenReaderMode and IME composition events. The fix likely needs to happen in xterm.js itself (upstream) or in how VS Code mediates between accessibility mode and IME input in the terminal. The terminal team should investigate whether screenReaderMode can coexist with composition events, or whether a workaround is needed in the terminal input path.
