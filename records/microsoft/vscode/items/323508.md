# Issue #323508 — Context window widget missing from AHP sessions

[https://github.com/microsoft/vscode/issues/323508](https://github.com/microsoft/vscode/issues/323508)

## Summary

Keep open as the canonical upstream-tracking issue: current main still cannot render the context widget when Auto routes to a model omitted from the SDK model catalog. The team-authored issue is protected from judgment closes, and no referenced fix or older canonical covers this same symptom.

## Change summary

Show the context-window usage widget in Agent Host sessions when Auto selects a model that is absent from the model picker catalog.

## Best solution

The Copilot SDK should expose the routed model's context-window limits even when that model is omitted from the selectable catalog; Agent Host can then publish those limits so the existing widget renders the Auto-routed session accurately.
