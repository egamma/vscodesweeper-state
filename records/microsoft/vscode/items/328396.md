# Issue #328396 — File changes get overzealously reported to many sessions

[https://github.com/microsoft/vscode/issues/328396](https://github.com/microsoft/vscode/issues/328396)

## Summary

Current main can attribute repository-wide branch changes to every observed session sharing that repository. This team-authored correctness bug should remain open and route to the Agent Host and Agents Window owners.

## Change summary

Sessions that made few or no edits display file-change totals produced by other sessions in the same repository.

## Best solution

Make each session's list and title summary reflect its session changeset rather than the shared branch changeset, while retaining branch-wide changes as a separately selectable view.
