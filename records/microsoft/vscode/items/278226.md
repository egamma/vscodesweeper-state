# Issue #278226 — lack of horizontal slider when code is marked (red) for removal

[https://github.com/microsoft/vscode/issues/278226](https://github.com/microsoft/vscode/issues/278226)

## Summary

Keep open: the current inline chat-edit review renderer omits deleted-text width from the editor's horizontal scroll extent. When the removed text is wider than all remaining lines, its right-hand portion can remain inaccessible; the issue already has the appropriate area label.

## Change summary

Allow horizontal scrolling through long red deletion previews while Copilot edits await Keep or Undo.

## Best solution

Make the inline chat-edit review surface account for the width of pending deleted text, so users can inspect the entire original line without switching views. Preserve existing wrapping, Keep/Undo behavior, and the normal diff editor.
