# Issue #208276 — [linked rename] Linked Editing does't work well

## Summary

The bug remains valid after the previous fix: a maintainer confirmed the exact behavior after the issue was closed, causing it to be reopened. An open PR now directly addresses the remaining failure, so the issue should stay open until that fix is reviewed and merged.

## Change summary

Linked editing loses synchronization when an HTML opening tag with attributes has its entire tag name deleted before a replacement is typed, causing the closing tag to remain empty or be deleted.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/310383 if its regression tests and provider-requery guard correctly preserve synchronization through the intermediate empty-tag state; otherwise continue the fix in the same linked-editing code path.
