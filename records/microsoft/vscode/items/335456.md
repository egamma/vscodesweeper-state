# Issue #335456 — I lost all my claude code sessions

[https://github.com/microsoft/vscode/issues/335456](https://github.com/microsoft/vscode/issues/335456)

## Summary

The lost/deleted sessions are transcripts under `~/.claude/projects/`, managed by the third-party 'Claude Code for VS Code' extension (publisher Anthropic, `anthropic.claude-code`) — comment 2 traces it to that extension's own 'Archive Inactive Sessions' setting, which has no VS Code-core counterpart. This isn't VS Code's own Agents Window session catalog or agentHost storage.

## Change summary

Claude Code sessions/transcripts disappear entirely (from disk, not just the UI list) after a period of inactivity or a window reload.

## Best solution

Route this to the Claude Code extension's own repo (github.com/anthropics/claude-code) — its 'Archive Inactive Sessions' cleanup logic appears to be deleting transcripts rather than archiving them, which is a bug in the extension, not in VS Code core.
