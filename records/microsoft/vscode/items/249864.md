# Issue #249864 — Double-clicking the symbol from outline does not jump correctly

[https://github.com/microsoft/vscode/issues/249864](https://github.com/microsoft/vscode/issues/249864)

## Summary

Confirmed in source on current main: the outline pane hard-codes double-click as 'select the full symbol range' without checking `workbench.list.openMode`, so users who set that option to `doubleClick` get unexpected text selection instead of a cursor jump.

## Change summary

When `workbench.list.openMode` is `doubleClick`, double-clicking a symbol in the Outline view selects the entire symbol range instead of just jumping to the symbol position.

## Best solution

In `outlinePane.ts`, the `isDoubleClick` logic that passes `select: true` to `reveal()` should also check the configured `workbench.list.openMode` — when it's `doubleClick`, a double-click is the normal 'open' gesture, so `select` should be `false`. Only treat double-click as 'select the range' when the open mode is the default (single-click opens).
