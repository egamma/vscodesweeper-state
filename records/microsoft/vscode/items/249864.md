# Issue #249864 — Double-clicking the symbol from outline does not jump correctly

[https://github.com/microsoft/vscode/issues/249864](https://github.com/microsoft/vscode/issues/249864)

## Summary

The reported selection behavior remains in current main: with double-click opening enabled, Outline still interprets the opening gesture as a request to select the entire symbol. Keep this open; the related reports do not own this same observable defect.

## Change summary

Opening an Outline symbol with workbench.list.openMode set to doubleClick selects its full range instead of navigating to its declaration with a collapsed cursor.

## Best solution

Outline should distinguish ordinary navigation under double-click opening from deliberate whole-symbol selection, while preserving existing single-click-mode behavior and the protection against follow-cursor navigation races.

## Evidence

- **Current source reproduces the trigger:** In src/vs/platform/list/browser/listService.ts, ResourceNavigator reads workbench.list.openMode and suppresses pointer opening when it equals doubleClick, but onMouseDblClick still emits the opening event with its dblclick browser event. In src/vs/workbench/contrib/outline/browser/outlinePane.ts:312-324, that event unconditionally becomes select=true in newOutline.reveal(...), regardless of the configured opening mode.
- **Selection reaches the editor:** src/vs/workbench/contrib/codeEditor/browser/outline/documentSymbolsOutline.ts:227-232 chooses entry.symbol.range when select is true, rather than Range.collapseToStart(entry.symbol.selectionRange). codeEditorDocumentSymbolAdapter in documentSymbolEditor.ts then passes that range as the editor selection. This directly explains the reporter's unexpected selection without executing the application.
- **Reporter diagnosis:** The reporter's 2025-10-09 comment on https://github.com/microsoft/vscode/issues/249864 identifies the same hard-coded double-click handling in outlinePane.ts. The corresponding behavior is still present in the inspected main checkout.
