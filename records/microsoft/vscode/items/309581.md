# Issue #309581 — Diff does not "follow" the agent into separate worktrees

[https://github.com/microsoft/vscode/issues/309581](https://github.com/microsoft/vscode/issues/309581)

## Summary

Keep open to clarify whether explicit chat relocation satisfies the request or whether automatic CWD-following remains desired. Current source supports moving a conversation between folders and worktrees, but deliberately does not infer workspace changes from ordinary agent activity; this team-authored request cannot be declined on that basis.

## Change summary

Let a conversation retain its context while Changes and Files follow the folder or worktree where the agent continues working.

## Best solution

Evaluate the existing chat workspace-relocation flow against the reporter's existing-worktree scenario. If automatic following remains necessary, define which agent directory changes should retarget Changes and Files without disturbing other chats or treating temporary shell navigation as a workspace change.
