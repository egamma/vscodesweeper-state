# Issue #77769 — Scrolling can be improved

[https://github.com/microsoft/vscode/issues/77769](https://github.com/microsoft/vscode/issues/77769)

## Summary

The precision-scrolling gap remains on current main, and this Backlog item is the best open issue owning it. Existing sensitivity settings affect wheel input, not scrollbar-thumb dragging.

## Change summary

Allow finer scrollbar-thumb control when navigating very large files, such as by holding a modifier while dragging.

## Best solution

Add a precision or zoomed drag mode to the shared scrollbar implementation in `src/vs/base/browser/ui/scrollbar/abstractScrollbar.ts`, preserving normal drag behavior while making very large documents navigable.
