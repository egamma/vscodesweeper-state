# Issue #300149 — Integrated browser: Enable Http Basic Authentication

[https://github.com/microsoft/vscode/issues/300149](https://github.com/microsoft/vscode/issues/300149)

## Summary

Genuine gap: the integrated browser's `login` event handler in `browserView.ts` only supplies proxy auth credentials for the tunnel proxy — HTTP Basic Authentication challenges from web pages are silently ignored, so the user gets an unauthorized response with no prompt. The feature request is valid and still unaddressed on main.

## Change summary

Allow the integrated browser to handle HTTP Basic Authentication challenges so users (and agents) can access password-protected pages.

## Best solution

Extend the `webContents.on('login', ...)` handler in `src/vs/platform/browserView/electron-main/browserView.ts` to detect non-proxy `authInfo` (where `authInfo.isProxy === false` and `authInfo.scheme === 'basic'`) and surface a credential prompt to the user or agent. Related issue https://github.com/microsoft/vscode/issues/326591 (password autofill in integrated browser) is adjacent but distinct — that one is about autofill integration, this one is about supporting the auth flow at all.
