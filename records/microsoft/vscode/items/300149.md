# Issue #300149 — Integrated browser: Enable Http Basic Authentication

[https://github.com/microsoft/vscode/issues/300149](https://github.com/microsoft/vscode/issues/300149)

## Summary

HTTP Basic Authentication still lacks an interactive sign-in path in the integrated browser. Keep this accepted On Deck request open: URL-embedded credentials are only a partial workaround, and no verified older canonical owns the remaining work.

## Change summary

Allow users to authenticate to HTTP Basic-protected pages inside the integrated browser without embedding credentials in the URL.

## Best solution

Provide a user-controlled HTTP authentication prompt in the integrated browser so an authenticated page can subsequently be shared with an agent without putting credentials in its URL. Credential visibility and session handling need explicit human review.
