# Issue #312784 — No way to see what model Auto resolves to in debug logs

[https://github.com/microsoft/vscode/issues/312784](https://github.com/microsoft/vscode/issues/312784)

## Summary

Valid feature gap: the chat debug logs panel shows 'Auto' as the model but doesn't display which model Auto resolved to, unlike the main chat UI which renders a ChatAutoModeResolutionContentPart. No fix found on main.

## Change summary

Show the resolved model name in the debug logs panel when Auto mode is used.

## Best solution

Surface the auto-mode resolution (the resolved model name) in the chatDebugModelTurnContentRenderer or chatDebugOverviewView, similar to how the main chat widget renders ChatAutoModeResolutionContentPart with the routed model name. The model turn event already carries `content.model` — the fix likely needs the debug event pipeline to include the resolved model ID when Auto mode selects it.
