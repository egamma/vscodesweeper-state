# Issue #135275 — Snippets in sidebar search results visually blend with filenames

[https://github.com/microsoft/vscode/issues/135275](https://github.com/microsoft/vscode/issues/135275)

## Summary

Keep open: the Search view still lacks the filename-versus-snippet color distinction a maintainer endorsed in the discussion. Existing settings provide decorations and layout choices, not the requested visual hierarchy, and no qualifying canonical or concrete fix was found.

## Change summary

Make filename rows visually distinct from code snippets in sidebar search results so users can scan file boundaries.

## Best solution

Give Search result filenames a consistent, theme-aware visual distinction from snippet rows, following the maintainer's Peek-view precedent while preserving selection contrast and file-decoration semantics.
