# Issue #338183 — Disable automatic expansion of editor group on click

[https://github.com/microsoft/vscode/issues/338183](https://github.com/microsoft/vscode/issues/338183)

## Summary

The behavior is intentional in one narrow sense (VS Code auto-restores a group that is sitting at its minimum width/height when it becomes active, part of the minimize/maximize-group feature), but there's no setting to opt out, and it can trigger unexpectedly whenever equally-split groups happen to sit at their minimum width in a narrow window — worth tracking as a request for an opt-out rather than closing.

## Change summary

Add a setting to prevent an editor group from auto-expanding (and shrinking its neighbors) simply because the user clicked into it to give it focus.

## Best solution

Either add a setting (e.g. under workbench.editor.*) to disable the auto-restore-on-focus behavior in EditorPart.doRestoreGroup, or tighten the heuristic so it only fires for groups explicitly minimized via the 'Minimize Other Editor Groups' action rather than any group that happens to be at its minimum size.
