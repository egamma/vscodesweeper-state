Fresh feature request (1 day old, bot just started the 60-day Backlog Candidates clock) asking for a setting to prevent editor groups from auto-resizing when focused by click; I could not find any existing setting covering this (only `workbench.editor.centeredLayoutAutoResize`, which is scoped to centered layout, not plain multi-group splits), so a real gap likely remains.

Add a setting to disable automatic resizing/expansion of an editor group when it is focused by clicking, so side-by-side groups keep fixed widths.
