# Issue #283167 — Copilot - allow custom instructions for generating docs

[https://github.com/microsoft/vscode/issues/283167](https://github.com/microsoft/vscode/issues/283167)

## Summary

The request for a `docsGeneration.instructions` setting remains unimplemented on current main — the Copilot extension has instruction settings for code, tests, commit messages, PR descriptions, and review selection, but not for doc generation. Valid feature gap, keeping open.

## Change summary

Allow custom instructions for Copilot's 'Generate Docs' functionality, analogous to the existing codeGeneration.instructions and testGeneration.instructions settings.

## Best solution

Add a `github.copilot.chat.docsGeneration.instructions` setting in `extensions/copilot/package.json` and wire it into the `generate_docs` intent prompt pipeline, following the same pattern as the existing generation instruction settings in `extensions/copilot/src/platform/configuration/common/configurationService.ts`.
