# Issue #309432 — Can't get from Agent Customizations to a regular code editor tab

[https://github.com/microsoft/vscode/issues/309432](https://github.com/microsoft/vscode/issues/309432)

## Summary

Valid polish request from a team member: when viewing an instruction inside the Agent Customizations modal editor, there's no way to open just that instruction file in a regular editor tab — the 'Open Modal Editor in Main Window' command moves the entire Customizations view. The right-click -> Open workaround only works from the list, not after clicking into an instruction. No fix commits reference this issue.

## Change summary

Opening an instruction from the Agent Customizations modal editor should allow opening just that file in a regular code editor tab, rather than moving the entire Customizations view.

## Best solution

Add an action (e.g. toolbar button or context menu item) within the instruction detail view in Agent Customizations that opens only the underlying instruction file in a standard editor tab via IEditorService, rather than invoking the modal-editor-to-main-window command which moves the whole Customizations editor pane. Likely in the AI Customization management editor code under `src/vs/workbench/contrib/chat/browser/aiCustomization`.
