# Issue #231837 — gif/video support in chat

[https://github.com/microsoft/vscode/issues/231837](https://github.com/microsoft/vscode/issues/231837)

## Summary

Valid feature request from a team member. GIF support exists but only reads the first frame; there is no video (mp4/webm/mov) support in chat at all. The gap remains on current main.

## Change summary

Support multi-frame GIF and video attachments in chat, enabling use cases like attaching screen recordings for debugging help or GIFs in release notes.

## Best solution

Implement frame-extraction for GIFs and video files (mp4/webm) before sending to the language model, following the OpenAI cookbook approach mentioned in the comments. This would live in `src/vs/workbench/contrib/chat/browser/chatImageUtils.ts` (frame extraction) and the paste/attachment pipeline. The LLM API constraint (no native video) means frames must be sampled and sent as individual images with a token cap.
