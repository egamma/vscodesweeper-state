# Issue #330061 — Use $XDG_STATE_HOME for `APPLICATION_SHARED` storage (`~/.<app>-shared/sharedStorage/state.vscdb`)

[https://github.com/microsoft/vscode/issues/330061](https://github.com/microsoft/vscode/issues/330061)

## Summary

The XDG compliance gap remains on current main: application-shared state still defaults directly under the user's home directory. This focused path is distinct from the older umbrella and `argv.json` issues, so it should remain open as actionable platform debt.

## Change summary

Use `$XDG_STATE_HOME`, with its standard fallback, for Linux application-shared storage and migrate existing shared state from the legacy home-directory path.

## Best solution

On Linux, resolve application-shared state beneath `${XDG_STATE_HOME:-$HOME/.local/state}` while preserving `--shared-data-dir`, portable-mode behavior, and existing defaults on other platforms. Existing shared storage should be migrated without losing state or repeatedly reading the legacy database.
