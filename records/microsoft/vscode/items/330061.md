# Issue #330061 — Use $XDG_STATE_HOME for `APPLICATION_SHARED` storage (`~/.<app>-shared/sharedStorage/state.vscdb`)

## Summary

Confirmed on current main: `appSharedDataHome` in environmentService.ts hardcodes `~/.<app>-shared/` with no `$XDG_STATE_HOME` resolution, so the gap is real. It's a legitimate, narrowly scoped debt item distinct from the decade-old umbrella #3884, but changing a default storage path is a product decision (migration/compat risk) that needs maintainer sign-off, not an automated close or fix.

## Change summary

Default `appSharedDataHome` (shared storage state.vscdb) should resolve under `$XDG_STATE_HOME` instead of hardcoding `~/.<app>-shared/`.
