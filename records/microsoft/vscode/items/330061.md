# Issue #330061 — Use $XDG_STATE_HOME for `APPLICATION_SHARED` storage (`~/.<app>-shared/sharedStorage/state.vscdb`)

[https://github.com/microsoft/vscode/issues/330061](https://github.com/microsoft/vscode/issues/330061)

## Summary

Real, well-evidenced XDG-compliance gap: `appSharedDataHome` in environmentService.ts hardcodes `~/.<app>-shared/` with no `$XDG_STATE_HOME` fallback. Fresh report (0 days old, 11 upvotes) that a maintainer hasn't triaged yet — routing to the right area rather than closing.

## Change summary

Default the shared-storage state.vscdb path to `$XDG_STATE_HOME/<app>-shared/` instead of `~/.<app>-shared/`, with a one-time migration of any existing db.

## Best solution

A maintainer should weigh in on changing the default in `EnvironmentService.appSharedDataHome` (src/vs/platform/environment/common/environmentService.ts, lines ~150-163) with a lazy one-time migration from the old path — this is a narrow, well-scoped follow-up to PR #311317, not a duplicate of the decade-old umbrella #3884.
