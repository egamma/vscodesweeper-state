# Issue #256046 — Adopting variable font sizes in `createDecorationsCollection` code

[https://github.com/microsoft/vscode/issues/256046](https://github.com/microsoft/vscode/issues/256046)

## Summary

Keep open for an editor API decision: Monaco still accepts font decoration properties without the CSS-generation path that makes them visible. The team-authored request remains unresolved; the investigation PR was closed without merging, and the related wrapping work does not settle this API contract.

## Change summary

Make Monaco decoration collections support font styling properties, or clarify the supported contract for applying variable fonts through CSS classes.

## Best solution

Settle whether Monaco decoration options should apply font properties directly or require caller-owned CSS classes, then make the public types, documentation, and rendering behavior agree. Keep advanced wrapping fixes separate from this API decision.
