# Issue #187147 — fuzzyScore boostFullMatch:false incorrect when pattern ends with uppercase

[https://github.com/microsoft/vscode/issues/187147](https://github.com/microsoft/vscode/issues/187147)

## Summary

Still reproduces on main: when `boostFullMatch: false`, uppercase characters in common-prefix positions are treated as gap locations, causing an asymmetric end-of-word penalty (-3 vs -5) that makes a full match score differently than a partial match. An open PR (https://github.com/microsoft/vscode/pull/187149) exists but has not been merged.

## Change summary

fuzzyScore with `boostFullMatch: false` incorrectly scores a full match differently from a prefix match when the pattern ends with an uppercase letter, because uppercase positions in the common prefix are treated as gap locations with a reduced penalty.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/187149, which fixes the gap-location logic for uppercase characters in common prefixes. The fix is in `src/vs/base/common/filters.ts` in the `_doScore` function's `isGapLocation` determination.
