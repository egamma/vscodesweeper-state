# Issue #316964 — Spastic flickering of mermaid diagram

[https://github.com/microsoft/vscode/issues/316964](https://github.com/microsoft/vscode/issues/316964)

## Summary

Still unfixed on main — the mermaid chat output renderer has no content-hash caching to prevent redundant re-renders during streaming. The related issue #319248 provides a more detailed reproduction and suspected root cause.

## Change summary

Mermaid diagrams in Copilot Chat flicker/re-render spastically, likely due to the chat markdown renderer re-rendering closed code blocks on every streaming token.

## Best solution

Add a content-hash short-circuit in the mermaid rendering path (either in the chat markdown renderer or in the mermaid extension's chatOutputRenderer.ts) so that a closed mermaid code block whose source hasn't changed is not re-rendered. Issue https://github.com/microsoft/vscode/issues/319248 provides more detailed analysis and may be the better canonical tracking issue if the team prefers the more specific report.
