# Issue #332991 — Determine whether or not new worktree is needed via agent vs checkbox

[https://github.com/microsoft/vscode/issues/332991](https://github.com/microsoft/vscode/issues/332991)

## Summary

Keep open for a product decision: current defaults, remembered choices, and agent isolation tools do not establish the requested automatic decision based on active changes. The discussion explicitly asks to preserve deterministic user control while considering a less cluttered entry point.

## Change summary

Let the agent determine when a new worktree is needed instead of requiring an upfront checkbox choice.

## Best solution

Define an automatic isolation experience that explains its decision and preserves an explicit user override for investigations and parallel work. Decide its relationship to remembered workspace preferences and existing confirmation flows before changing the Agents Window controls.
