# Issue #332991 — Determine whether or not new worktree is needed via agent vs checkbox

[https://github.com/microsoft/vscode/issues/332991](https://github.com/microsoft/vscode/issues/332991)

## Summary

Keep open: current defaults and agent-triggered worktree relocation partially address the workflow, but do not establish automatic isolation based on active changes. The thread leaves a product decision about reducing the checkbox's prominence while retaining deterministic user control.

## Change summary

Determine when a session needs a worktree automatically instead of requiring an upfront checkbox choice.

## Best solution

Define an automatic isolation experience that explains when a worktree is needed while preserving an explicit override for investigation and parallel-work workflows. Evaluate the existing remembered selection and agent relocation tool before deciding whether to hide or consolidate the checkbox.
