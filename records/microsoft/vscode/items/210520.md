# Issue #210520 — getMarkdownHeadersInCell does not handle headers with HTML tags

[https://github.com/microsoft/vscode/issues/210520](https://github.com/microsoft/vscode/issues/210520)

## Summary

Still reproduces on main: `getMarkdownHeadersInCell` in foldingModel.ts only uses `marked.lexer` for markdown syntax headers, with no HTML tag fallback — so cells with HTML headers (e.g. `<h1>`) don't create foldable regions. An open PR (#251150) exists but has not merged.

## Change summary

Notebook cells using HTML header tags (e.g. `<h1>`) are not foldable, even though they appear in the outline.

## Best solution

Unify the header detection so `getMarkdownHeadersInCell` (or the folding model's call site) falls back to HTML `<h1>`–`<h6>` tags the same way the outline entry factory does. Review and land or close the open PR https://github.com/microsoft/vscode/pull/251150 which targets this exact fix.
