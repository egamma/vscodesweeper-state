# Issue #347104 — No Canvas support in auxiliary agents window

[https://github.com/microsoft/vscode/issues/347104](https://github.com/microsoft/vscode/issues/347104)

## Summary

Keep open: current source supports routing canvases into chat windows but still explicitly hides Canvas actions in auxiliary windows. The supplied steps suffice to retest whether the remaining failure is action availability, canvas transfer, or both.

## Change summary

A session's canvas becomes unavailable after moving the session to a new auxiliary Agents window.

## Best solution

Preserve access to the moved chat's canvases in its destination window, including appropriate Canvas actions, without exposing unrelated chats' canvases or changing provider ownership.
