# Issue #64358 — consider to allow for variable substitution in the inputs section

[https://github.com/microsoft/vscode/issues/64358](https://github.com/microsoft/vscode/issues/64358)

## Summary

This is the canonical feature request for variable substitution in the `inputs` section of tasks.json/launch.json. It has 57 upvotes (well above the 20-upvote Backlog threshold), multiple closed duplicates point here, and the feature remains unimplemented on current main — the `info.default` value is used raw without variable resolution.

## Change summary

Allow non-interactive predefined variables (like `${env:...}`, `${config:...}`, `${workspaceFolder}`, `${file}`) to be resolved within the `inputs` section of tasks.json and launch.json, particularly in the `default` field.

## Best solution

Implement variable resolution for non-interactive variables within input definitions in `baseConfigurationResolverService.ts`. Before presenting the input UI (around line 277 for promptString, line 316 for pickString), resolve the `info.default` value through the existing variable resolver, excluding interactive variables (`${input:...}`, `${command:...}`) to avoid recursion. This is a well-scoped change in the configuration resolver service.
