# Issue #304106 — Images preview: how do I zoom out?

[https://github.com/microsoft/vscode/issues/304106](https://github.com/microsoft/vscode/issues/304106)

## Summary

Keep open: Images Preview supports zooming out through modifier-click, modifier-scroll, and pinch, but still provides no visible zoom-out control or explanatory hint. This team-authored request concerns discoverability, and the existing gestures do not fully address it.

## Change summary

Make zooming out in Images Preview discoverable without requiring knowledge of hidden mouse or trackpad gestures.

## Best solution

Provide a discoverable, keyboard-accessible way to reduce image zoom in the image carousel while preserving existing gestures and workbench-wide zoom shortcuts. Agree with the maintainer whether this should be an explicit control or guidance exposing the existing interactions.
