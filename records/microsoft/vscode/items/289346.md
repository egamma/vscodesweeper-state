# Issue #289346 — Chat markdown rendering of numbered lists is misleading

[https://github.com/microsoft/vscode/issues/289346](https://github.com/microsoft/vscode/issues/289346)

## Summary

Still reproduces on main: the chat markdown renderer uses standard marked.js ordered-list behavior which renumbers user-typed list items sequentially, making it look like the agent received a different message. No fix has landed.

## Change summary

Numbered lists in chat user messages are renumbered by Markdown rendering, misrepresenting what was typed.

## Best solution

Customize the marked.js list renderer in `src/vs/workbench/contrib/chat/browser/widget/chatContentMarkdownRenderer.ts` to preserve the original start number (using the `start` attribute on `<ol>`) for user message content, so typed numbering is faithfully displayed.
