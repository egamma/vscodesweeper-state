# Issue #289346 — Chat markdown rendering of numbered lists is misleading

[https://github.com/microsoft/vscode/issues/289346](https://github.com/microsoft/vscode/issues/289346)

## Summary

The discussion confirms a real chat UX papercut: standard Markdown normalization changes explicitly entered list numbers, making replies to numbered questions appear different from what the user sent. A maintainer acknowledged the annoyance, and no evidence establishes a duplicate or completed fix.

## Change summary

Preserve the numbers users explicitly type in numbered lists when rendering their chat messages.

## Best solution

Adjust chat's user-message Markdown rendering so explicitly entered ordered-list markers remain visually faithful, while preserving standard Markdown behavior for assistant-authored content and ordinary sequential lists.
