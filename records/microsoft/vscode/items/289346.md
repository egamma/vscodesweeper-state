# Issue #289346 — Chat markdown rendering of numbered lists is misleading

[https://github.com/microsoft/vscode/issues/289346](https://github.com/microsoft/vscode/issues/289346)

## Summary

Keep open: current chat rendering still applies Markdown's sequential numbering, making replies to selected numbered questions misleading. The maintainer acknowledged the annoyance; questionnaires mitigate the workflow but do not resolve ordinary typed replies.

## Change summary

Make submitted chat messages faithfully display explicitly numbered answers instead of silently renumbering them.

## Best solution

Preserve the meaning of numbered question references in submitted user messages without changing the underlying prompt. Agree on how this interacts with conventional Markdown auto-numbering before changing the shared chat renderer.
