# Issue #337392 — Zsh terminal revive reuses VS Code temporary ZDOTDIR as USER_ZDOTDIR

[https://github.com/microsoft/vscode/issues/337392](https://github.com/microsoft/vscode/issues/337392)

## Summary

The current source still permits revived zsh terminals to treat VS Code's injected directory as the user's configuration directory. Keep this open while the directly linked, open fixing PR is reviewed.

## Change summary

Revived zsh terminals should load the same user configuration as fresh terminals instead of reusing the shell-integration temporary ZDOTDIR as USER_ZDOTDIR.

## Best solution

Review https://github.com/microsoft/vscode/pull/340229 for the reported revive case and preservation of genuine custom ZDOTDIR values, then land an appropriate fix before resolving this issue.

## Evidence

- **Current injection defect:** src/vs/platform/terminal/node/terminalEnvironment.ts:252–254 sets the injected ZDOTDIR and derives USER_ZDOTDIR from env?.ZDOTDIR without excluding that same temporary directory. An environment carrying the prior injected value therefore produces the two identical values reported in https://github.com/microsoft/vscode/issues/337392.
- **Revive and reinjection path:** PtyService._reviveTerminalProcess in src/vs/platform/terminal/node/ptyService.ts passes terminal.processLaunchConfig.env into createProcess. TerminalProcess.start in src/vs/platform/terminal/node/terminalProcess.ts:211–218 runs getShellIntegrationInjection against the launch environment and applies its envMixin back to that environment.
- **Observable configuration failure:** src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-rc.zsh sources $USER_ZDOTDIR/.zshrc and has an early recursion guard. When USER_ZDOTDIR identifies the injected directory, this selects the injected script again rather than the user's normal configuration, matching the restart-and-revive trigger in the report. This was established by source inspection, not runtime execution.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/340229 was verified OPEN with mergedAt null. Its body explicitly says Fixes #337392 and describes excluding the injected ZDOTDIR during USER_ZDOTDIR selection, with regression tests in src/vs/platform/terminal/test/node/terminalEnvironment.test.ts. The PR reports a failing-before/passing-after check; those results were not independently executed in this read-only review.
