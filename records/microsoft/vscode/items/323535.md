# Issue #323535 — adding session to a group will reorder workspaces

[https://github.com/microsoft/vscode/issues/323535](https://github.com/microsoft/vscode/issues/323535)

## Summary

Current source explains the reported reorder, but the intended behavior when grouping the last session from a workspace is not settled. This team-authored issue must remain open rather than receiving a judgment close.

## Change summary

Adding the only visible session from the top workspace to a custom group removes that workspace section and causes the remaining workspace sections to fall back to alphabetical order.

## Best solution

Decide whether workspace sections that have not been manually reordered should preserve their current relative order across group-membership changes, then encode that behavior in the Sessions list and a focused regression test.
