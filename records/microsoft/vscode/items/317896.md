# Issue #317896 — Update installation hangs at Extracting Files step (very last step)

[https://github.com/microsoft/vscode/issues/317896](https://github.com/microsoft/vscode/issues/317896)

## Summary

Known, team-acknowledged bug: PowerShell invocations during the Windows update/install process (Appx package management, context menu COM surrogate killing) can hang indefinitely. The team member confirmed the root cause and expressed intent to remove PowerShell from setup, but this hasn't been fully implemented yet.

## Change summary

VS Code update installation hangs at 'Extracting Files' step due to a PowerShell process that becomes unresponsive during the Appx package install/update phase.

## Best solution

Remove or replace all PowerShell invocations in `build/win32/code.iss` with native Inno Setup or compiled helper approaches (as dmitrivMS suggested). The Appx Add/Remove and tunnel process termination calls at lines ~1703–1759 are the likely culprits for this reporter's hang.
