# Issue #182979 — Terminal panel overwrites `terminalEditorActive` context key when a terminal editor is present

[https://github.com/microsoft/vscode/issues/182979](https://github.com/microsoft/vscode/issues/182979)

## Summary

Thanks for the report. A maintainer-team member re-confirmed the behavior in March 2026, the issue is labeled confirmed and help wanted, and the earlier fix claim was refuted, so it stays open. I found no other fix commit.

## Change summary

terminalEditorActive turns false when the terminal panel is focused, even though the active editor is still a terminal editor.

## Best solution

Decide the intended semantics of terminalEditorActive (does the active editor have a terminal, or is focus inside the terminal editor?), then make the key reflect that. Consider deprecating it in favor of activeEditor == 'terminalEditor' if the old behavior has to be preserved for existing keybindings.
