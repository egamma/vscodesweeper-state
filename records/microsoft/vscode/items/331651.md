## Summary

The unhandled rejection remains possible on current main: tool-call telemetry starts an asynchronous endpoint lookup without awaiting or handling it, so a server-backoff rejection can escape after the tool itself completes.

## Change summary

Prevent expected Auto model endpoint-resolution failures during tool-call telemetry from surfacing as unhandled errors.

## Best solution

Keep tool-call telemetry best-effort: contain endpoint-resolution failures within the telemetry path while preserving the completed tool result and retaining model metadata when resolution succeeds.
