# Issue #342500 — Migrate MCP: Handle destination server name conflict

[https://github.com/microsoft/vscode/issues/342500](https://github.com/microsoft/vscode/issues/342500)

## Summary

Keep open as a request for interactive MCP migration conflict resolution. Current source deliberately rejects differing same-name destination servers and reports an error; it does not offer Replace, Create a Copy, or Cancel.

## Change summary

Offer explicit conflict-resolution choices when migrating an MCP server into a destination containing a different server with the same name.

## Best solution

Provide a reviewed conflict-resolution flow in the Customizations migration UI, preserving both configurations unless the user explicitly authorizes replacement. Retain the existing equivalent-target handling and concurrent-edit protections.
