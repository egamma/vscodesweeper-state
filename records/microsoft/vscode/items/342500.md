# Issue #342500 — Migrate MCP: Handle destination server name conflict

[https://github.com/microsoft/vscode/issues/342500](https://github.com/microsoft/vscode/issues/342500)

## Summary

Keep open as a request for interactive MCP migration conflict resolution. Current code deliberately rejects conflicting destination entries and reports an error; it does not offer Replace, Create a Copy, or Cancel.

## Change summary

Offer explicit conflict-resolution choices when migrating an MCP server whose name already exists at the destination.

## Best solution

Provide a conflict-resolution flow in the customization migration editor that supports replacing the destination, migrating under a distinct name, or canceling without changing either configuration. Preserve the existing safeguards against accidental overwrites and concurrent configuration changes.
