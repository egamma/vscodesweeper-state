# Issue #300632 — Sandbox should be linked to auto approve/permissions dropdown somehow

[https://github.com/microsoft/vscode/issues/300632](https://github.com/microsoft/vscode/issues/300632)

## Summary

Team-authored feature request for per-session sandbox controls, auto-approve integration, and sandbox visibility in the UI. Active development is happening in the sandbox area (agent-sandbox label, related code in agentHost and terminalContrib), but these specific UX affordances are not yet implemented. Keeping open per team-member policy.

## Change summary

Sandbox mode should be controllable per-session, linked to auto-approve/permissions settings, and visually indicated in the UI.

## Best solution

Integrate sandbox toggle and status indicator into the session-level permissions/auto-approve dropdown (likely in `src/vs/workbench/contrib/chat/browser/widget/input/permissionPickerActionItem.ts` and related session settings). The per-session sandbox control and visibility work should coordinate with the agent-host sandbox engine (`src/vs/platform/agentHost/node/copilot/agentHostSandboxEngine.ts`) and the sessions provider layer.
