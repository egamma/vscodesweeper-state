# Issue #186614 — Enable COI for desktop with `credentialless `

[https://github.com/microsoft/vscode/issues/186614](https://github.com/microsoft/vscode/issues/186614)

## Summary

COI for desktop remains blocked on an upstream Chromium performance regression (https://issues.chromium.org/issues/375314974). The enable attempt (PR #231665) was reverted (PR #231899) and current main still uses the opt-in `--enable-coi` flag. This stays open until upstream resolves the BrowsingInstance swap overhead.

## Change summary

Enable Cross-Origin Isolation on desktop by default using `COEP: credentialless`, removing the need for the `--enable-coi` CLI flag.

## Best solution

Wait for the upstream Chromium fix (https://issues.chromium.org/issues/375314974) to land in a shipped Electron version, then re-enable COI by default — the implementation path is already proven by the reverted PR https://github.com/microsoft/vscode/pull/231665.
