# Issue #186614 — Enable COI for desktop with `credentialless `

[https://github.com/microsoft/vscode/issues/186614](https://github.com/microsoft/vscode/issues/186614)

## Summary

Keep open: current main still gates desktop COI behind --enable-coi and uses require-corp rather than credentialless. The enabling changes were reverted, and the maintainer identified Chromium startup performance as a prerequisite for adoption.

## Change summary

Enable desktop cross-origin isolation using COEP: credentialless to allow cross-origin resources without CORP headers.

## Best solution

Adopt credentialless desktop COI once the Chromium startup blocker and embedded-content compatibility are addressed. Preserve this issue as the adoption tracker; neither the existing opt-in flag nor the reverted enabling PR delivers the requested default behavior.
