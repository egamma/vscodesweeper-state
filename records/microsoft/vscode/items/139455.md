Current source exposes Execute Cell in the command palette, addressing part of the discoverability complaint, but does not establish that execution without advancing works with the reported CH-DE keyboard; the existing steps and follow-up suffice to retest.

## Change summary

Notebook cell execution shortcuts fail on an iPad with a CH-DE keyboard, while the working Shift+Enter alternative advances or creates a cell.

## Best solution

Make execution without advancing reliable for the reported iPadOS keyboard configuration and discoverable through notebook commands. First distinguish browser keyboard-event delivery and mapping from notebook focus and command enablement; fixing discoverability alone does not resolve the reported shortcut failure.
