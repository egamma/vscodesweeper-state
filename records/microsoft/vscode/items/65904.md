# Issue #65904 — Emmet dollar sign $ being automatically escaped within abbreviation text when no star * operator

[https://github.com/microsoft/vscode/issues/65904](https://github.com/microsoft/vscode/issues/65904)

## Summary

Confirmed upstream bug in the emmet library — the $ numbering token is escaped when the repeater (*) is applied externally to a custom snippet rather than embedded in the snippet definition. Already correctly labeled upstream with the upstream issue linked.

## Change summary

Emmet custom snippets with $ in text nodes don't apply numbering when the * repeater is applied externally (e.g., test*2) rather than internally in the snippet definition.

## Best solution

Awaits a fix in the upstream emmetio/emmet library (https://github.com/emmetio/emmet/issues/686). Once fixed upstream, update @vscode/emmet-helper to pull in the fix. No action in VS Code core can resolve this.
