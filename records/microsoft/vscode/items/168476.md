# Issue #168476 — Add please colors to the outline panel.

[https://github.com/microsoft/vscode/issues/168476](https://github.com/microsoft/vscode/issues/168476)

## Summary

This accepted Backlog feature request remains necessary: current VS Code colors symbol icons, but not outline names, arguments, or return types. It exceeded the 20-upvote threshold and no canonical issue owns the remaining work.

## Change summary

Allow themes to colorize outline symbol names and separately style argument and return-type details.

## Best solution

Design generalized outline label/detail theming in the outline and document-symbol rendering path, without language-specific parsing. Separate argument and return-type styling may require richer structured symbol metadata because providers currently supply one opaque `detail` string.
