# Issue #303552 — User message disappears when using `/fork` on CLI chat with one message

[https://github.com/microsoft/vscode/issues/303552](https://github.com/microsoft/vscode/issues/303552)

## Summary

Keep open: two maintainers confirmed the rendering defect, and current source still allows a contributed CLI fork to reuse request identities from the source session. The team-authored issue has no referenced fixing commit or verified duplicate, so the hard keep-open rule applies.

## Change summary

Forking a one-message Copilot CLI conversation initially hides the copied user message until scrolling or reopening forces a rerender.

## Best solution

Ensure chat-list element identity distinguishes copied turns belonging to different sessions while remaining stable within one session, so opening a CLI fork renders its complete history immediately without requiring scrolling.
