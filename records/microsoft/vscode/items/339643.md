# Issue #339643 — Agent host (Copilot): most of the system prompt is re-written to the prompt cache in every session

[https://github.com/microsoft/vscode/issues/339643](https://github.com/microsoft/vscode/issues/339643)

## Summary

A fix landed on main (merged PR #339985, commit 280a9749) but it's an opt-in setting that's off by default, and the PR description itself says the flag has no effect until a separate SDK bump lands — so the reported inefficiency is not actually resolved for default users yet. Also carries a real version milestone (1.142.0), which independently blocks any close.

## Change summary

Most of the Copilot agent-host system prompt (~20K chars of fixed instructions) is re-written to the provider's prompt cache every session instead of being reused, because one per-session line (the session folder path) sits in the same cache block as the fixed text.

## Best solution

Track the remaining work: land the `@github/copilot-sdk` bump referenced in PR #339985 (currently pinned to 1.0.17-preview.8 on main, needs 1.0.17-preview.9+) and consider flipping `chat.copilot.stabilityOrderedPrompt.enabled` to true by default once the stability-ordered layout has been evaluated in practice.
