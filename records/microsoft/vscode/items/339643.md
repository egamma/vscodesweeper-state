# Issue #339643 — Agent host (Copilot): most of the system prompt is re-written to the prompt cache in every session

[https://github.com/microsoft/vscode/issues/339643](https://github.com/microsoft/vscode/issues/339643)

## Summary

The VS Code-side fix (PR #339985, an opt-in `chat.copilot.stabilityOrderedPrompt.enabled` setting sending a `STABILITY_ORDERED_SYSTEM_PROMPT_V2` feature flag) already merged before this issue was reopened, but the reporter's own follow-up comment says the upstream Copilot SDK doesn't yet honor the flag, so the cache-write inefficiency persists; per the reopened-issue rule, that pre-reopen PR cannot be cited as a completed fix.

## Change summary

Every new agent-host session rewrites ~20K characters of otherwise-identical system prompt to the provider's prompt cache because the one varying line (session folder) sits in the same cache block as the fixed instructions, wasting cache-write tokens/cost on every session start.

## Best solution

Keep tracking until the upstream Copilot CLI SDK actually implements support for the `STABILITY_ORDERED_SYSTEM_PROMPT_V2` flag; once it does, verify the opt-in setting (`chat.copilot.stabilityOrderedPrompt.enabled`, default off in src/vs/platform/agentHost/common/copilotCliConfig.ts) delivers the measured cache-reuse improvement before considering flipping its default or closing this issue.
