# Issue #339643 — Agent host (Copilot): most of the system prompt is re-written to the prompt cache in every session

[https://github.com/microsoft/vscode/issues/339643](https://github.com/microsoft/vscode/issues/339643)

## Summary

Thanks for the detailed measurements. PR 339985 added an opt-in setting, but it is off by default, so default sessions still write the per-session block to the prompt cache. The issue was reopened for that reason and should stay open until the default is decided.

## Change summary

The per-session system prompt block, which includes the session folder, shares one cache block with about 20K characters of fixed text, so every new session rewrites it to the cache.

## Best solution

Decide whether to turn `chat.copilot.stabilityOrderedPrompt.enabled` on by default. The refactorbench eval shows cache hit improving from 94.2% to 96.8% with no resolution drop. Alternatively, have the SDK keep the session folder out of the shared block.
