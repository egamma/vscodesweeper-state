# Issue #339643 — Agent host (Copilot): most of the system prompt is re-written to the prompt cache in every session

[https://github.com/microsoft/vscode/issues/339643](https://github.com/microsoft/vscode/issues/339643)

## Summary

Keep this open: current main wires an opt-in stability-ordered prompt layout and bundles a newer SDK, but the optimization remains disabled by default and its current runtime behavior was not verified. The earlier integration predates the reopening and does not establish a completed fix.

## Change summary

Avoid rewriting thousands of stable system-prompt tokens when starting another Copilot agent-host session with the same workspace, tools, and settings.

## Best solution

Validate the runtime's stability-ordered layout through the existing chat.copilot.stabilityOrderedPrompt.enabled integration, then decide its rollout after evaluating cache reuse and model behavior. Keep the runtime responsible for cache-block construction and preserve session-specific instructions.
