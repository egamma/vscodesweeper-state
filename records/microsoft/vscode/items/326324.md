# Issue #326324 — SSH askpass shows yes/no host-fingerprint prompt instead of PIN input for FIDO2/security-key authentication

[https://github.com/microsoft/vscode/issues/326324](https://github.com/microsoft/vscode/issues/326324)

## Summary

Verified duplicate root cause: `handleSSHAskpass()` in extensions/git/src/askpass.ts only special-cases 'passphrase' prompts and otherwise unconditionally falls into the host-authenticity yes/no quick pick — this is the exact same misclassification bug already tracked by the open, broader issue #276691, which has an open fix PR.

## Change summary

OpenSSH's FIDO2 PIN prompt ('Enter PIN for authenticator:') is misclassified as a host-fingerprint confirmation, showing a yes/no quick pick instead of a PIN input box.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/276691 and land https://github.com/microsoft/vscode/pull/299382, which reworks handleSSHAskpass() to explicitly gate the authenticity branch on `/authenticity/i` and forwards any other (keyboard-interactive/PIN) prompt to an InputBox — this covers the FIDO2 PIN case reported here too.
