# Issue #331615 — Slash commands don't auto-complete in the Automations UI

[https://github.com/microsoft/vscode/issues/331615](https://github.com/microsoft/vscode/issues/331615)

## Summary

Team-authored, still-open bug with a clear source-level explanation: the Automations dialog's prompt input never registers with IChatWidgetService, so the chat completion providers (which key off `getWidgetByInputUri`) silently no-op, disabling slash-command (and agent/@) autocomplete in that surface.

## Change summary

Slash-command autocomplete does not appear when typing `/` in the Automations create/edit dialog's prompt input.

## Best solution

In src/vs/sessions/contrib/automations/browser/automationDialog.ts, make the dialog's ChatInputPart discoverable to IChatWidgetService (e.g. register the stub widget, or add a fallback lookup path in chatInputCompletions.ts) so SlashCommandCompletions/AgentCompletions resolve a widget for the dialog's input model URI.

## Evidence

- **dialog uses a stub widget:** src/vs/sessions/contrib/automations/browser/automationDialog.ts:1056-1081 creates a `stubWidget: IMinimalChatWidget` (a plain object implementing only a subset of IChatWidget) and calls `chatInput.render(promptHost, initialPrompt, stubWidget as IChatWidget)` — it is never passed to any widget-registration API.
- **only ChatWidget registers with the service:** src/vs/workbench/contrib/chat/browser/widget/chatWidget.ts:1138 is the sole call site of `this.chatWidgetService.register(this)`; the dialog's stand-alone ChatInputPart bypasses this entirely.
- **completion providers require a registered widget:** src/vs/workbench/contrib/chat/browser/widget/input/editor/chatInputCompletions.ts SlashCommandCompletions provider does `const widget = this.chatWidgetService.getWidgetByInputUri(model.uri); if (!widget || !widget.viewModel) { return; }` — since the dialog's input model was never registered, `getWidgetByInputUri` (src/vs/workbench/contrib/chat/browser/widget/chatWidgetService.ts, `this._widgets.find(w => isEqual(w.input.inputUri, uri))`) returns undefined and no suggestions are computed.
