# Issue #172743 — Cannot Continue On from Tunnels in vscode.dev to Codespaces

[https://github.com/microsoft/vscode/issues/172743](https://github.com/microsoft/vscode/issues/172743)

## Summary

The underlying cross-extension-host communication problem (UI extension unable to access git extension API in tunnel scenario) does not appear to have been fixed in the VS Code core. No commit references this issue, and the architectural limitation described in comments still exists. Keeping open as a tracked bug in the Backlog.

## Change summary

Continue Working On to Codespaces fails from tunnel connections in vscode.dev because the Codespaces extension (UI host) cannot access the git extension API (workspace host).

## Best solution

Provide a mechanism for UI extensions to query JSON-serializable repo context from workspace extensions (or an async API proxy across extension hosts), enabling the Continue On flow to work when connected to tunnels in vscode.dev.
