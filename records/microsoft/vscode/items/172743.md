# Issue #172743 — Cannot Continue On from Tunnels in vscode.dev to Codespaces

[https://github.com/microsoft/vscode/issues/172743](https://github.com/microsoft/vscode/issues/172743)

## Summary

Keep open: the discussion confirms a tunnel-to-Codespaces failure across extension hosts. Current Git commands provide serializable repository context, but their adoption by the Codespaces destination is unverified; no qualifying post-reopen fix or canonical duplicate was established.

## Change summary

Continue Working On from a Git repository opened through a tunnel in vscode.dev fails when selecting Codespaces.

## Best solution

Make the Codespaces destination obtain the tunnel workspace's Git context across extension hosts and complete the handoff without requiring browser-side extensions to access workspace-side exports. First establish whether the existing Git API commands are already used by that destination and reproduce the remaining failure.
