# Issue #322765 — ssh sessions to multiple remote hosts with synced view

[https://github.com/microsoft/vscode/issues/322765](https://github.com/microsoft/vscode/issues/322765)

## Summary

This requests a multi-host file synchronization and deployment system built into VS Code core — editing a file locally and automatically pushing it to a set of remote servers, with diff detection, test gating, and grouped host management. This is a specialized deployment/orchestration workflow well beyond the scope of a code editor and belongs in dedicated tooling or an extension.

## Change summary

Add built-in support for editing files locally and automatically syncing/deploying them to multiple remote SSH hosts with diff highlighting and test gating.

## Best solution

This workflow is better served by dedicated deployment tools (rsync, Ansible, CI/CD pipelines) or a purpose-built VS Code extension. The referenced issue https://github.com/microsoft/vscode/issues/200524 tracks SSH host grouping in the Remote SSH extension context, but the full sync/deploy pipeline described here is outside core's scope. An extension using the FileSystemProvider API and Remote SSH could potentially implement parts of this.
