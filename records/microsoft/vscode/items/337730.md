# Issue #337730 — Automations and Customizations sidebar entries look like tree group headers but behave inconsistently

[https://github.com/microsoft/vscode/issues/337730](https://github.com/microsoft/vscode/issues/337730)

## Summary

Freshly filed, team-authored design observation that traces cleanly to the code: Automations and Customizations rows are built with the same `renderSection`/collapsible tree-element shape as real group headers, but wired to navigation/modal commands instead of expand/collapse — this needs a design decision on visual differentiation, not a mechanical fix.

## Change summary

The Automations and Customizations sidebar rows look identical to real collapsible tree group headers (same indentation/icon/weight) but behave as navigation/modal commands instead of expand-collapse, with inconsistent badge support between the two.

## Best solution

Give Automations/Customizations a visually distinct affordance from real collapsible groups (e.g., different icon treatment, no chevron, consistent badge support) in src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts, where both are built via the same `renderSection` helper (see the `AUTOMATIONS_SECTION_ID`/`CUSTOMIZATIONS_SECTION_ID` branches around line 4225) as the ordinary Pinned/Chats sections.
