# Issue #240722 — System Context Menu is not displayed properly depending on the mouse cursor position

[https://github.com/microsoft/vscode/issues/240722](https://github.com/microsoft/vscode/issues/240722)

## Summary

Keep open with the existing Electron routing. A later workaround addresses Windows title-bar menu interception, but the evidence does not establish that it fixes Alt+Space opening the sticky-scroll context menu.

## Change summary

Alt+Space should open the native Windows system menu regardless of whether the mouse is over sticky scroll, an editor title, or the window title bar.

## Best solution

Establish whether Electron still dispatches a renderer context-menu event when Alt+Space is pressed over sticky scroll, and resolve that event-routing behavior without changing legitimate right-click menus. The title-bar workaround alone is insufficient evidence to close the full report.
