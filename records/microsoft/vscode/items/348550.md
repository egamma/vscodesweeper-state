# Issue #348550 — MCP `envFile`: multi-line quoted values (e.g. private keys) are parsed incorrectly

[https://github.com/microsoft/vscode/issues/348550](https://github.com/microsoft/vscode/issues/348550)

## Summary

The reported parsing defect remains present in current source. Keep this open while the two linked implementation candidates are reviewed; neither has merged.

## Change summary

MCP envFile parsing truncates multi-line quoted values and interprets their interior lines as separate environment assignments.

## Best solution

Review and land one of https://github.com/microsoft/vscode/pull/348551 or https://github.com/microsoft/vscode/pull/348612, preserving existing single-line behavior while supporting multi-line quoted values.
