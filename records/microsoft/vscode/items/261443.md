## Summary

The multi-diff editor still ignores the editor's wheel sensitivity settings in current source. Keep this correctly routed issue open while the existing fix proposals are reviewed; neither has merged.

## Change summary

Make scrolling in the commit multi-diff view respect the editor's configured scroll sensitivity.

## Best solution

Have the multi-diff container honor the existing editor scrolling settings, including subsequent configuration changes, rather than introducing a separate setting. Review https://github.com/microsoft/vscode/pull/331057 alongside the earlier proposal and land the appropriate fix before closing this issue.
