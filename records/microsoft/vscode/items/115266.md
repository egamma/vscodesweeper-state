# Issue #115266 — Support minimap for native notebooks

[https://github.com/microsoft/vscode/issues/115266](https://github.com/microsoft/vscode/issues/115266)

## Summary

Thanks for the context. This remains the canonical, highly supported notebook-minimap request; current main still lacks the capability, and its Backlog status plus 490 community upvotes requires keeping it open.

## Change summary

Add a notebook-level minimap for navigating code, markdown, and rendered outputs in long native notebooks.

## Best solution

Implement a notebook-level minimap alongside the virtualized notebook list, using outline information for structure and lightweight representations of code, markdown, and outputs. The design should avoid enabling separate minimaps inside every cell editor.
