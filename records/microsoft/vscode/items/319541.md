# Issue #319541 — Agents window: MCP tools are listed/startable but execution fails with "No MCP client found for tool ID"

[https://github.com/microsoft/vscode/issues/319541](https://github.com/microsoft/vscode/issues/319541)

## Summary

The Agents window advertises and starts configured MCP servers but the active agent session can still lack the corresponding MCP client, causing valid tool calls to fail immediately. The detailed cross-surface comparison and exact error establish an actionable Agents-window integration defect that should remain open.

## Change summary

Ensure MCP servers shown and started in the Agents window are attached to the active agent session before their tools are exposed or invoked.

## Best solution

Make MCP availability session-consistent in the Agents window: either attach newly started MCP clients to the active session and refresh its tools, or expose those tools only after a new session has incorporated the server, with clear UI guidance.
