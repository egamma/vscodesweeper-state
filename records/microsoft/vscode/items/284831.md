# Issue #284831 — INI Language Detection Overly Aggressive with Non-English Characters

[https://github.com/microsoft/vscode/issues/284831](https://github.com/microsoft/vscode/issues/284831)

## Summary

The older, open language-detection issue already tracks non-English plain text incorrectly switching to INI, with a maintainer-confirmed reproduction. Consolidate this report there while preserving its precise 20/21-character boundary and multilingual examples.

## Change summary

Non-English plain text is automatically classified as INI when a continuous sequence reaches 21 characters.

## Best solution

Track correction of these INI false positives in https://github.com/microsoft/vscode/issues/131450, retaining this report's threshold examples as additional detection samples. Plain multilingual prose should remain Plain Text without sacrificing detection of genuine INI content.
