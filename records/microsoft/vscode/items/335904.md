# Issue #335904 — Show all accounts used by AI providers and MCP servers in the profile menu

[https://github.com/microsoft/vscode/issues/335904](https://github.com/microsoft/vscode/issues/335904)

## Summary

Keep open as a feature request: the current profile panel still has provider-specific Copilot and ChatGPT sections rather than a complete AI-account overview. Existing account-management capabilities provide useful prior art, but do not cover the requested surface or identify which accounts AI features use.

## Change summary

Show all identities used by AI providers, MCP servers, and inference in the Copilot profile menu, with discoverable inspection and management actions.

## Best solution

Define a consistent, provider-independent account presentation in the profile panel that identifies each account's AI consumers and links to appropriate management actions. Reuse the existing authentication and account-management capabilities without confusing all signed-in accounts with accounts actively used by AI features.
