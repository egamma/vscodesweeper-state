# Issue #279528 — Deleting a line should mark occurences in editor

[https://github.com/microsoft/vscode/issues/279528](https://github.com/microsoft/vscode/issues/279528)

## Summary

Still reproduces on main: the onDidChangeModelContent handler unconditionally stops all highlights without re-triggering them when the cursor position hasn't changed. An open PR (#279820) exists but hasn't merged.

## Change summary

Deleting a line clears occurrence highlights and does not re-trigger them because the cursor position doesn't change.

## Best solution

Land or iterate on the open PR https://github.com/microsoft/vscode/pull/279820, which addresses this by refreshing occurrence highlighting after content changes that don't move the cursor. The fix belongs in `src/vs/editor/contrib/wordHighlighter/browser/wordHighlighter.ts` around the `onDidChangeModelContent` handler (line ~287).
