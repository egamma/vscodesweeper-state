# Issue #191132 — Support aliasing URLs in the Output window

[https://github.com/microsoft/vscode/issues/191132](https://github.com/microsoft/vscode/issues/191132)

## Summary

Existing document-link APIs appear to support clickable aliases in custom-language Output channels without printing the destination URL. Keep this team-authored Backlog request open while the area owner confirms that approach; no issue-referencing implementation commit or verified older duplicate was established.

## Change summary

Let extensions display concise, descriptive links in the Output panel instead of lengthy destination URLs.

## Best solution

Establish whether a custom-language Output channel with a DocumentLinkProvider satisfies the request, and document that supported approach if it does. A provider can associate the displayed alias range with a separate target URI; built-in Markdown rendering or a new Output API should not be assumed necessary.
