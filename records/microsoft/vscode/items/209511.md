[https://github.com/microsoft/vscode/issues/209511](https://github.com/microsoft/vscode/issues/209511)

## Summary

Team-authored umbrella issue tracking incremental adoption of command descriptions/keywords across the codebase. Partially addressed by several merged PRs, but the approach is still under discussion (description vs. keywords, performance/bundle-size concerns), and the owner re-assigned himself in Dec 2025 to continue thinking through the strategy. Keep open.

## Change summary

Add descriptions or keywords to core commands so the Command Palette's similarity search can match user queries more accurately.

## Best solution

Tyler owns this and needs to resolve the open design question — `description` (human-readable, heavier) vs. `keywords` (lighter, search-only) vs. both — and address the ~1% bundle-size concern raised by jrieken. Once the approach is settled, the remaining unchecked commands across the codebase can be incrementally adopted. An LLM-assisted generation flow (as jrieken suggested) could reduce the authoring burden.
