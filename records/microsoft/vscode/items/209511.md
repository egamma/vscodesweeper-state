# Issue #209511 — Give Core Commands good descriptions

[https://github.com/microsoft/vscode/issues/209511](https://github.com/microsoft/vscode/issues/209511)

## Summary

Keep this team-authored, cross-area adoption umbrella open: merged contributions represent partial progress, not completion. The owner reaffirmed the goal in December 2025, while guidance on descriptions, keywords, and resource costs remains unresolved.

## Change summary

Improve core-command search metadata so the Command Palette finds relevant commands beyond their titles.

## Best solution

Retain this as the adoption tracker and establish sustainable metadata-authoring guidance before expanding coverage across command owners. Preserve existing API descriptions and evaluate search-quality gains alongside localization, startup-size, and maintenance costs.
