# Issue #339148 — Dictation intermittently omits word spaces and inserts literal <en-US> tags

[https://github.com/microsoft/vscode/issues/339148](https://github.com/microsoft/vscode/issues/339148)

## Summary

Fresh, detailed report of a correctness bug in the on-device dictation backend; the reporter self-confirmed it across multiple sessions with concrete garbled-transcript examples, but with no other confirmations yet and an uncertain root cause (glue code vs. the bundled ASR model), this stays open rather than closing or demoting to needs-info.

## Change summary

Dictation via the chat input's microphone button intermittently drops spaces between words and sometimes inserts a literal `<en-US>` language tag into the transcript.

## Best solution

Investigate whether the missing spaces/`<en-US>` leakage originate in the Foundry Local on-device ASR model's raw segment text or in VS Code's transcript-join logic (`transcriptSeparator`/`appendTranscriptChunk`/`TranscriptAccumulator` in src/vs/platform/localTranscription/node/localTranscriptionService.ts), and add defensive stripping of special/language tokens from backend output regardless of cause.
