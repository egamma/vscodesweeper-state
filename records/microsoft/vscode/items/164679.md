# Issue #164679 — browser password auto complete function working unexpectedly on Quick Pick Input

## Summary

Keep open as a browser-autofill interoperability issue. Maintainers confirmed that ordinary autocomplete suppression did not work, and the linked fix attempt was closed without merging because it did not resolve the behavior.

## Change summary

Prevent saved Git credentials from causing browser password suggestions in unrelated web VS Code inputs.

## Best solution

Establish a browser-supported way to distinguish credential prompts from subsequent ordinary Quick Inputs, preserving password masking and normal keyboard interaction. Track the browser-side behavior and validate any VS Code mitigation against the original save-credentials flow in Chrome, Edge, and Safari.
