# Issue #137632 — With `md.supportHtml = true` and VS Code Remote SSH, a single img tag on compleition items cannot be loaded

[https://github.com/microsoft/vscode/issues/137632](https://github.com/microsoft/vscode/issues/137632)

## Summary

The HTML-only image failure remains traceable in current source: HTML image destinations bypass the URI collection needed for remote extension-host transport. Keep this accepted backlog bug open; the existing reproduction distinguishes it from the broader remote-image issue.

## Change summary

HTML-only images in completion documentation should load from remote workspaces without requiring a Markdown image referencing the same file.

## Best solution

Make supported HTML image destinations participate in remote URI transport consistently with Markdown images. Preserve existing local rendering, URI resolution, and HTML sanitization behavior.
