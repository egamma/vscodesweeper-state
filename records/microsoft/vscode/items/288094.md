# Issue #288094 — When Copilot Chat Errors, it should RETRY instead of haltung

[https://github.com/microsoft/vscode/issues/288094](https://github.com/microsoft/vscode/issues/288094)

## Summary

Automatic recovery for transient Copilot Chat failures is implemented on current main: network errors and selected server errors are retried automatically, while autonomous agent modes retry broader request failures up to three times.

## Change summary

Automatically retry recoverable Copilot Chat model errors instead of stopping the agentic workflow and requiring a manual retry.

## Best solution

Keep the shipped bounded retry policy: retry transient network and server failures automatically while excluding cancellation, quota, rate-limit, refusal, and other errors where repeating the same request is inappropriate.
