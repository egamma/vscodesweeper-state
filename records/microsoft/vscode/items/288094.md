# Issue #288094 — When Copilot Chat Errors, it should RETRY instead of haltung

[https://github.com/microsoft/vscode/issues/288094](https://github.com/microsoft/vscode/issues/288094)

## Summary

Auto-retry on transient errors during agentic sessions has been implemented on main — the tool-calling loop now automatically retries up to 3 times in auto-approve and autopilot modes, showing recovery progress to the user without halting the flow.

## Change summary

When Copilot Chat hits a model error during agentic coding, it stops and asks the user to manually retry instead of retrying automatically.

## Best solution

Keep the shipped auto-retry behavior in the tool-calling loop (up to 3 retries for transient errors in auto-approve/autopilot modes). No further change needed — the central ask is addressed. Rate-limited and quota-exceeded errors still surface to the user, which is intentional.
