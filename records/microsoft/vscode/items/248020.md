# Issue #248020 — Missing dependency: libX11-xcb

[https://github.com/microsoft/vscode/issues/248020](https://github.com/microsoft/vscode/issues/248020)

## Summary

Confirmed gap: libX11-xcb is not in the RPM or Debian dependency lists (build/linux/rpm/dep-lists.ts, build/linux/debian/dep-lists.ts). The reporter correctly notes it was mentioned in #95627 but never actually added when dependency generation landed.

## Change summary

VS Code RPM/DEB packages are missing libX11-xcb as a declared dependency, causing silent launch failure on fresh RHEL installs.

## Best solution

Add `libX11-xcb.so.1()(64bit)` to the RPM dep lists and the equivalent `libx11-xcb1` to the Debian dep lists in build/linux/rpm/dep-lists.ts and build/linux/debian/dep-lists.ts. Verify whether Electron 42 still links against it (it may have been absorbed into libX11 in newer distros).
