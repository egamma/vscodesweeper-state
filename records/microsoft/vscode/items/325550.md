# Issue #325550 — Log Panel: Clicking on nodes in Log View collapses tree node

[https://github.com/microsoft/vscode/issues/325550](https://github.com/microsoft/vscode/issues/325550)

## Summary

Valid polish issue from a team member: clicking tree nodes in the Agent Debug Log Panel both shows details and collapses/expands the node, making browsing cumbersome. The relevant code is not on public main, so no fix can be verified. Keeping open.

## Change summary

Clicking tree nodes in the Log Panel's tree view should only show details, not also collapse/expand the node — collapse/expand should be limited to the chevron icon.

## Best solution

Update the tree widget configuration for the Agent Debug Log Panel's log view to use `expandOnlyOnTwistieClick` (or equivalent option), so that clicking a node selects it and shows details on the right without toggling its expanded/collapsed state. The collapse/expand behavior should only trigger on the chevron/twistie icon.
