# Issue #325550 — Log Panel: Clicking on nodes in Log View collapses tree node

[https://github.com/microsoft/vscode/issues/325550](https://github.com/microsoft/vscode/issues/325550)

## Summary

Keep open: the Log View still combines selecting details with toggling expandable rows under the default tree configuration. A global setting offers a workaround, but does not settle this team-authored request for a better interaction in this specific view.

## Change summary

Allow selecting Log View rows to inspect details without also collapsing or expanding their children.

## Best solution

Make detail inspection independent of expansion in the Agent Debug Logs tree, retaining explicit twistie controls and keyboard navigation. The area owner should settle whether this view should override the global tree expansion preference.
