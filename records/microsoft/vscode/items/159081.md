# Issue #159081 — Include full extension author name when creating issues via issue reporter

[https://github.com/microsoft/vscode/issues/159081](https://github.com/microsoft/vscode/issues/159081)

## Summary

The newer reporter and generated issue bodies include full publisher names, but the legacy reporter still truncates its on-screen author column to three characters regardless of authentication. Keep this accepted request open for the remaining UI behavior; the implementation is only partial.

## Change summary

Show full extension publisher names in the issue reporter and submitted issues, retaining truncation only for unauthenticated URL-based submission.

## Best solution

Make publisher identification consistent across the legacy reporter, the newer wizard, and generated issue bodies, while preserving a deliberate URL-length fallback for unauthenticated submission.
