# Issue #303491 — `Chat: Install Plugin From Source` passes a raw Windows path to git when connected via WSL Remote, instead of translating it to a `/mnt/c/...` path.

[https://github.com/microsoft/vscode/issues/303491](https://github.com/microsoft/vscode/issues/303491)

## Summary

The reported WSL clone-path failure is fixed on current main: plugin Git operations now run locally through the shared process instead of passing a Windows cache path to remote Git.

## Change summary

Install agent plugins from source without passing Windows filesystem paths to Git running inside WSL.

## Best solution

Keep the local-clone architecture introduced by commit 89d0d1310ff53737033e18826f5ecd64678dc84b; broader remote plugin discovery and skill-path problems remain tracked by https://github.com/microsoft/vscode/issues/298701.
