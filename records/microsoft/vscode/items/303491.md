# Issue #303491 — `Chat: Install Plugin From Source` passes a raw Windows path to git when connected via WSL Remote, instead of translating it to a `/mnt/c/...` path.

## Summary

Verified duplicate of #298701, which tracks the same root cause — plugin installation passes raw Windows paths instead of WSL-translated paths when connected via WSL Remote. The canonical issue is open, labeled bug, and on the On Deck milestone.

## Change summary

The 'Chat: Install Plugin From Source' command passes a raw Windows path (e.g. `c:\Users\...`) to git clone inside WSL instead of translating it to a `/mnt/c/...` path, causing the clone to fail.
