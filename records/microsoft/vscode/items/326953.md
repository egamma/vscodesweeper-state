# Issue #326953 — Typography: semibold 600 font weight feels too heavy in product

[https://github.com/microsoft/vscode/issues/326953](https://github.com/microsoft/vscode/issues/326953)

## Summary

Real design feedback that's being actively worked, not stale: a merged PR already softened tabs to regular weight, but the underlying acceptance criteria (decide whether to revert the semibold token globally or keep carving out per-surface exceptions) is still open, so this should stay open as an ongoing UX decision.

## Change summary

Feedback that the UI Modernization semibold (600) font-weight token reads too heavy/chunky on surfaces like tabs and action items; asks whether to revert to 500 or add targeted per-surface exceptions.

## Best solution

Keep tracking the broader token decision here — https://github.com/microsoft/vscode/pull/330266 already landed a targeted exception (editor tabs now use `--vscode-fontWeight-regular`, confirmed on main in src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css:50), but `fontWeightSemiBold` itself is still 600 in src/vs/platform/theme/common/sizes/baseSizes.ts:77-79 and other surfaces (composite bar labels, settings tabs, action items) haven't been revisited; the design team should finish the surface-by-surface review the acceptance criteria calls for.
