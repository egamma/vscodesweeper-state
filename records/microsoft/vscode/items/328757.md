# Issue #328757 — Workbench > Experimental: Modern UI

[https://github.com/microsoft/vscode/issues/328757](https://github.com/microsoft/vscode/issues/328757)

## Summary

Multiple independent reporters confirm severe UI stuttering (resizing, panels, typing) after the experimental Modern UI (`workbench.experimental.modernUI`) was auto-enabled, resolved by disabling the setting — a real, still-open perf regression in an actively developed feature (commits landing this week), so it should stay open and route to the perf/workbench owners rather than close.

## Change summary

Enabling (or being auto-enrolled into) the experimental Modern UI causes severe, inconsistent lag across resizing, panels, and typing; disabling it restores normal performance.

## Best solution

Perf-profile the Modern UI style-override path (src/vs/workbench/contrib/styleOverrides/browser/styleOverrides.contribution.ts and its media/*.css rules toggled via the `.style-override` class) for layout-thrash or repaint cost under resize/typing, since the feature is under active iteration (e.g. commit 6ecc5b70, d7b0502d this week); also check why the setting appears to auto-enable outside Insiders per one commenter.
