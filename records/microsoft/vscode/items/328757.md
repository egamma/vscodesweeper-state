# Issue #328757 — Workbench > Experimental: Modern UI

[https://github.com/microsoft/vscode/issues/328757](https://github.com/microsoft/vscode/issues/328757)

## Summary

Multiple independent users report severe UI stutter (resizing, typing) specifically when `workbench.experimental.modernUI` is enabled, consistently resolved by disabling it — a real and reproducible performance regression tied to the new style-override experiment, not yet fixed on main.

## Change summary

Enabling the experimental Modern UI setting (or having it auto-enabled) causes severe, inconsistent UI lag across resizing, panel operations, and typing; disabling it restores normal performance.

## Best solution

Route to the workbench/UX team owning `src/vs/workbench/contrib/styleOverrides` to profile the Modern UI style-override path (CSS class toggling, box-shadow/rounded-corner rules, relayout on layout-affecting modules) for the reported stutter; no fix is visible on main yet.
