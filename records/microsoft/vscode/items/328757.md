# Issue #328757 — Workbench > Experimental: Modern UI

[https://github.com/microsoft/vscode/issues/328757](https://github.com/microsoft/vscode/issues/328757)

## Summary

Multiple independent reporters confirm severe UI stuttering (typing, resizing, panels) that stops the moment `workbench.experimental.modernUI` is disabled — this is a distinct performance regression tied to the new Modern UI rendering path, separate from the aesthetic complaints in the other Modern UI issues, and should be routed to the team owning that feature for profiling.

## Change summary

Enabling the new experimental Modern UI causes widespread, inconsistent stuttering/lag across core interactions (typing, resizing, panels); disabling it restores normal performance.

## Best solution

Route to whoever owns the Modern UI/workbench rendering work to profile the perf regression (layout thrashing, extra repaints/animations, or a new compositing path introduced with Modern UI); worth checking whether it correlates with the reported auto-enablement on non-Insiders builds (see comment from aasherber-fadv) since that would broaden exposure significantly.
