# Issue #35744 — Customizable status bar item locations

[https://github.com/microsoft/vscode/issues/35744](https://github.com/microsoft/vscode/issues/35744)

## Summary

This remains the canonical, highly supported request for user-controlled status bar ordering. Current main supports visibility and code-defined priorities but not user-defined placement, and the Backlog milestone, `keep` label, and 715 upvotes strongly support keeping it open.

## Change summary

Allow users to reorder status bar entries and move them between the left and right groups.

## Best solution

Add user-controlled ordering to the status bar model, ideally through an accessible customization UI with profile-persisted state that handles built-in and extension entries while preserving sensible defaults for unknown items.
