# Issue #311539 — Reference scripts and current cwd from hook definitions is too hard

[https://github.com/microsoft/vscode/issues/311539](https://github.com/microsoft/vscode/issues/311539)

## Summary

Valid feature request: user-level hooks in `~/.copilot/hooks` lack built-in environment variables (e.g. `HOOK_DIR`) to reference sibling scripts or the hook's own directory, making portable user-level hook authoring unnecessarily difficult. No implementation exists on main.

## Change summary

Provide environment variables in hook execution context so user-level hooks can reference scripts relative to their own location without hardcoding paths.

## Best solution

Inject built-in environment variables (like `HOOK_DIR` for the hook file's parent directory, and optionally `WORKSPACE_DIR`) into the hook process environment during execution in `hookSchema.ts` / the hook execution layer, similar to Claude Code's approach. The workaround of `BASH_SOURCE` works for bash but not cross-platform or for the `cwd` field itself.
