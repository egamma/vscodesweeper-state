# Issue #249792 — Git - adopt `matchesGlob` in favor of picomatch

[https://github.com/microsoft/vscode/issues/249792](https://github.com/microsoft/vscode/issues/249792)

## Summary

The cleanup remains outstanding: Git still uses picomatch for branch-protection rules and declares both its runtime and type dependencies. No canonical duplicate or open migration PR was found; keep this accepted, team-authored debt open.

## Change summary

Replace the built-in Git extension's picomatch usage with Node's path.matchesGlob.

## Best solution

Use the native matcher for Git branch protection and remove the redundant dependencies, provided existing configured and provider-contributed protection rules retain their behavior. Establish compatibility across supported runtimes and platforms before making the substitution.
