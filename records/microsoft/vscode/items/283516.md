# Issue #283516 — SCM repo tags Checkout bad dialog

[https://github.com/microsoft/vscode/issues/283516](https://github.com/microsoft/vscode/issues/283516)

## Summary

Confirmed bug still present on main — the early-return path in `_checkout()` when a treeish string is passed directly (e.g. from tag checkout in the Repositories view) doesn't catch `DirtyWorkTree` errors, so users see a raw error dialog instead of the Stash/Migrate/Force options. An open PR (#304760) addresses this.

## Change summary

Checking out a tag from the SCM Repositories view with uncommitted changes shows a raw error dialog instead of the Stash & Checkout / Migrate Changes / Force Checkout options.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/304760, which wraps the treeish early-return path in `_checkout()` with the same `DirtyWorkTree` error handling that the QuickPick flow already has.
