# Issue #286605 — Source Control panel – Staged file status

[https://github.com/microsoft/vscode/issues/286605](https://github.com/microsoft/vscode/issues/286605)

## Summary

The staged-status decoration remains incorrect on current main: unstaged modifications overwrite the shared file badge used by both SCM rows. Keep this correctly routed Git bug open; no verified older canonical owns the same symptom.

## Change summary

A newly added staged file should retain its green A badge when subsequent unstaged edits give its Changes entry an orange M badge.

## Best solution

Make SCM status badges reflect each resource group's status independently, while preserving working-tree decoration precedence in Explorer and existing staging and diff behavior.
