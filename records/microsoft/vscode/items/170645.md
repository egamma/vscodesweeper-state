# Issue #170645 — Remote IPC layer improvements

[https://github.com/microsoft/vscode/issues/170645](https://github.com/microsoft/vscode/issues/170645)

## Summary

Keep open: current IPC exposes socket draining and chunks large WebSocket messages, but it still lacks the bounded, channel-aware flow control requested here. This is also a team-authored item with no explicitly linked completing commit.

## Change summary

Improve remote IPC throughput and responsiveness by applying backpressure while allowing unrelated messages to proceed.

## Best solution

Implement bounded per-channel or stream-aware flow control in the remote IPC protocol, preserving interleaving of small messages during large transfers, and benchmark file import/export over constrained remote connections.
