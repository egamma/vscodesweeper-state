# Issue #133143 — Prevent custom menu dismissal when being updated on startup

[https://github.com/microsoft/vscode/issues/133143](https://github.com/microsoft/vscode/issues/133143)

## Summary

Fixed on main and shipped in 1.73.0 — the custom menubar no longer dismisses when updated during startup, thanks to deferred updates while focus is inside the menubar.

## Change summary

Custom title bar menu gets dismissed mid-interaction when extensions register menu items during startup.

## Best solution

Keep the shipped fix in commit 8b61395f087 (1.73.0); no further change needed. The menubar now defers updates while focus is inside it and replays them on blur.
