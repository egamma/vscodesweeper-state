# Issue #258314 — Can't test an extension in vscode.dev with an API proposal

[https://github.com/microsoft/vscode/issues/258314](https://github.com/microsoft/vscode/issues/258314)

## Summary

Keep open for an explicit, supported vscode.dev development workflow. Core can already enable proposed APIs through a hidden workspace payload, but installing a local web extension does not activate or expose that mechanism.

## Change summary

Allow locally installed web extensions to exercise declared proposed APIs while being tested on vscode.dev.

## Best solution

Expose or document a deliberate vscode.dev extension-development flow that reloads with the `enableProposedApi` payload, preferably scoped to the extension under test rather than silently enabling proposals for ordinary installed extensions.
