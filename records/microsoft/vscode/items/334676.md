# Issue #334676 — Session status dot should be on the left

[https://github.com/microsoft/vscode/issues/334676](https://github.com/microsoft/vscode/issues/334676)

## Summary

Keep open: current rich links still place session/chat status after the text, so the requested left-side grouping remains missing. The earlier vertical-alignment fix does not implement this separate, team-authored design request.

## Change summary

Place the session/chat rich-link status indicator on the left beside the semantic icon rather than after the text.

## Best solution

Agree on a consistent leading status treatment for session/chat rich links, then apply it in ChatRichLink while preserving status meaning, accessible labels, and link behavior. Keep this separate from vertical alignment and the broader needs-input redesign.
