# Issue #334676 — Session status dot should be on the left

[https://github.com/microsoft/vscode/issues/334676](https://github.com/microsoft/vscode/issues/334676)

## Summary

Keep open: session/chat rich-link status indicators still follow the title on current main, so the requested leading placement remains unimplemented. The originating discussion explicitly separates this design request from the earlier vertical-centering defect.

## Change summary

Move the session/chat rich-link status indicator to the left, next to the chat icon, rather than after the title.

## Best solution

Agree on a leading status treatment for session/chat rich links, then implement it in ChatRichLink while preserving link behavior and status accessibility. Keep this separate from vertical-centering fixes and the command-center needs-input redesign.
