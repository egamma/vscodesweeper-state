# Issue #107821 — Git conflict resolution "accept both changes" deletes lines not related with the conflict

[https://github.com/microsoft/vscode/issues/107821](https://github.com/microsoft/vscode/issues/107821)

## Summary

Still reproduces on main: the merge-conflict codelens race condition remains unfixed. Stale conflict ranges from pre-edit codelens objects cause incorrect line deletions when accepting conflicts in rapid succession.

## Change summary

Accepting merge conflicts quickly via codelens deletes unrelated lines because stale pre-edit conflict ranges are applied after the document has shifted.

## Best solution

Serialize conflict resolution edits or invalidate/re-resolve the conflict object against the current document state before applying the edit. The fix belongs in `extensions/merge-conflict/src/commandHandler.ts` (the `accept` method should `await` the `commitEdit` and the codelens provider should guard against applying stale ranges). Also, `conflict.commitEdit` at line 248 is not awaited, which allows concurrent edits.
