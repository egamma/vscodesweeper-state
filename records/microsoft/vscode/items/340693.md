# Issue #340693 — Cloud chat shows internal default repository ID in picker

[https://github.com/microsoft/vscode/issues/340693](https://github.com/microsoft/vscode/issues/340693)

## Summary

Thanks for the report. The Cloud session provider seeds new untitled sessions with the internal sentinel as the selected repository, and this is still the case on main. An open PR already targets it, so this stays open until that PR is reviewed and merged.

## Change summary

The Cloud chat repository picker shows the internal value ___vscode_repository_default___ instead of a user-facing label.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/340694. The provider should stop publishing the synthetic default as the selected repository option and use the existing first-workspace-repository fallback, or show a placeholder label.
