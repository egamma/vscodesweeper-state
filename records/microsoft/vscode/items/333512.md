# Issue #333512 — Can't create terminal in Agents Window while automations view is open

[https://github.com/microsoft/vscode/issues/333512](https://github.com/microsoft/vscode/issues/333512)

## Summary

Keep open: current source still prevents the terminal panel from becoming visible while Automations is active, even after an explicit terminal creation command. The remaining work is to reconcile that command with the custom-view exclusivity contract.

## Change summary

Creating a terminal from the Agents Window command palette while Automations is open produces no visible terminal.

## Best solution

Make explicit terminal creation yield a visible, usable terminal without disturbing session ownership or terminal persistence. Agree whether the command should leave Automations or whether the layout should support displaying the terminal alongside it.
