# Issue #334938 — Claude does not return DirectoryCustomization for empty target directories

[https://github.com/microsoft/vscode/issues/334938](https://github.com/microsoft/vscode/issues/334938)

## Summary

Confirmed on main: `mapDiscoveredCustomizations` only pushes an agents/skills/rules `DirectoryCustomization` when the bucket already has children, so empty-but-writable target folders are never advertised as migration destinations. An open PR already fixes exactly this path, so this should stay open pending that PR landing rather than being auto-fixed or closed.

## Change summary

Claude's customization discovery omits DirectoryCustomization entries for empty target directories, so the migration service can't offer them as destinations.

## Best solution

Land https://github.com/microsoft/vscode/pull/334942, which removes the `bucket.agents.length > 0` / skills / rules guards in claudeSessionCustomizationDiscovery.ts so directories are always published (with matching test updates); no further design decision is needed once that PR is reviewed and merged.
