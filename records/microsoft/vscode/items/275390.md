# Issue #275390 — Make it easy to copy command output button in terminal tool output

[https://github.com/microsoft/vscode/issues/275390](https://github.com/microsoft/vscode/issues/275390)

## Summary

Keep open: the current chat terminal output toolbar still lacks an invocation-specific copy action, and existing terminal commands only partially cover the request. The issue is already correctly routed; related newer reports do not qualify as duplicate canonicals for this re-reviewed, team-authored item.

## Change summary

Provide an easy way to copy a terminal tool invocation's output without selecting it manually inside the chat preview.

## Best solution

Provide a discoverable, keyboard-accessible copy action for the individual chat terminal output, following existing chat toolbar conventions. Settle whether truncated previews copy the preview or the full captured output before implementation.
