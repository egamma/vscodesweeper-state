## Evidence

- **canonical issue:** https://github.com/microsoft/vscode/issues/148974 is older, remains open, and reports the same observable symptom: files and folders at the same level are not vertically aligned under icon themes without folder icons. Its discussion also identifies switching to an icon theme with folder icons as an incomplete workaround because users lose their preferred rich icons.
- **same theme-dependent behavior:** The reporter confirmed that the Minimal icon theme improves alignment but sacrifices rich icons, matching the theme-dependent behavior documented in https://github.com/microsoft/vscode/issues/148974.
- **existing indentation setting:** src/vs/platform/list/browser/listService.ts registers `workbench.tree.indent` as a numeric setting with a 4–40 pixel range, while src/vs/workbench/contrib/files/browser/views/explorerViewer.ts reads it and updates the Explorer alignment offset when it changes.
- **current alignment path:** src/vs/workbench/contrib/files/browser/views/explorerView.ts toggles `align-icons-and-twisties` based on whether the active theme supplies file and folder icons; explorerViewer.ts separately compensates for nested items when themes hide arrows or omit folder icons.
