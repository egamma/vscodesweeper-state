# Issue #347742 — Enable code splitting for workbench.desktop.main so gated features can lazy-load JS and CSS

[https://github.com/microsoft/vscode/issues/347742](https://github.com/microsoft/vscode/issues/347742)

## Summary

Keep open: current production bundling still lacks the requested dynamic-import boundaries and lazy CSS loading. This team-authored infrastructure request has a source-confirmed capability gap and needs a build/runtime design pass.

## Change summary

Allow gated desktop workbench features to defer implementation JavaScript and CSS without duplicating shared services or registries.

## Best solution

Establish a supported desktop workbench lazy-loading contract covering shared module identity, feature styles, localization, source maps, and packaging. Preserve eager registrations and demonstrate that disabled features avoid loading their deferred implementation and CSS without regressing startup.
