# Issue #298565 — Copilot Chat Sessions Not Appearing in History After Creating New Session

[https://github.com/microsoft/vscode/issues/298565](https://github.com/microsoft/vscode/issues/298565)

## Summary

The reported refresh-only session-list failure was fixed on main: newly started local chat sessions are now published to the list when their first request arrives, without requiring Refresh or an extension reload.

## Change summary

Completed local Copilot Chat sessions were saved but remained absent from the Sessions panel after starting another session until the list or extension was refreshed.

## Best solution

Keep the fix from https://github.com/microsoft/vscode/commit/5bee7afe1c7cc5436ed1e3bad12083374e4c50ed, which publishes the newly qualifying session immediately and includes regression coverage for the first-request transition.
