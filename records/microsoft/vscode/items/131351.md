# Issue #131351 — [FR] Filter commands by source improvements

[https://github.com/microsoft/vscode/issues/131351](https://github.com/microsoft/vscode/issues/131351)

## Summary

The request for better discoverability of @source filters in the Keyboard Shortcuts editor remains valid — the search widget still uses a basic SearchWidget with no autocomplete for @source, and the filter options remain hidden in the overflow menu.

## Change summary

Make the @source filter in the Keyboard Shortcuts editor more discoverable by adding autocomplete suggestions and/or exposing filter options in the table header.

## Best solution

Add completion/suggestion support to the keybindings search widget so that typing `@source` triggers completions (like `@source:user`, `@source:extension`, `@source:system`), similar to how the Settings editor search offers suggestions. The implementation would live in `src/vs/workbench/contrib/preferences/browser/keybindingWidgets.ts` or the editor's search setup.
