# Issue #335476 — Current turn changes are intermittently missing from chat responses

[https://github.com/microsoft/vscode/issues/335476](https://github.com/microsoft/vscode/issues/335476)

## Summary

Fixed on current main: per-turn file-change subscriptions now resolve the host-advertised changeset address instead of constructing an address that can miss the resource and leave the changes pill without data.

## Change summary

Agent turns that modified files intermittently completed without showing the View Current Turn Changes entry.
