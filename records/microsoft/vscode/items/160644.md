# Issue #160644 — Git - Cannot add merge change if file is deleted

[https://github.com/microsoft/vscode/issues/160644](https://github.com/microsoft/vscode/issues/160644)

## Summary

The staging gap remains in current source: deleting a both-modified conflict leaves both staging commands trying to scan a nonexistent file before staging its deletion. Keep this issue open; the related deletion-conflict reports concern different user actions.

## Change summary

Allow a conflicted file deleted from the working tree to be staged as a deletion through the Merge Changes plus buttons.

## Best solution

Make individual and group staging support an intentionally deleted conflicted file without requiring its recreation. Preserve conflict checks for existing files and the established prompts for deleted-by-us/deleted-by-them conflicts; any additional deletion decoration can be considered separately.
