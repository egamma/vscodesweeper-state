# Issue #343665 —  Agent in Local harness blocks on "Allow task creation and execution?" even with "Allow all" permission level

[https://github.com/microsoft/vscode/issues/343665](https://github.com/microsoft/vscode/issues/343665)

## Summary

Task creation explicitly requires confirmation even under Allow all, and an existing test enforces that exception. Keep this open for an owner decision: the permission picker promises automatic approval of all tool calls without explaining the task exception, so the reported inconsistency remains.

## Change summary

Make Local task creation compatible with unattended Allow all execution, or clearly disclose its mandatory-confirmation exception.

## Best solution

Reconcile the Local permission contract with task creation: decide whether this operation should honor Allow all or remain an explicit exception. If confirmation remains mandatory, explain that limitation in the permission UI rather than promising approval of every tool call.
