# Issue #343665 —  Agent in Local harness blocks on "Allow task creation and execution?" even with "Allow all" permission level

[https://github.com/microsoft/vscode/issues/343665](https://github.com/microsoft/vscode/issues/343665)

## Summary

Task creation deliberately requires confirmation even under Allow all, but the permission picker promises to auto-approve all tool calls without explaining this exception. Keep this open for a decision on unattended task creation or clearer permission messaging rather than treating the existing guard as an accidental approval failure.

## Change summary

Allow unattended task creation and execution under Allow all, or explicitly explain that this tool always requires manual approval.

## Best solution

Make the Local permission contract consistent with task-tool behavior: either explicitly support unattended task creation or clearly disclose the mandatory confirmation exception. The existing tested restriction should not be removed without an owner decision.
