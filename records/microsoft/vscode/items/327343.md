# Issue #327343 — Single Panel Detail Panel: File keeps closing

[https://github.com/microsoft/vscode/issues/327343](https://github.com/microsoft/vscode/issues/327343)

## Summary

Two UX improvement requests for the Agents window's single-pane detail panel: (1) the Files tab should not close when a selected file is closed, and (2) the Changes view should support single-file-at-a-time viewing. Both are actionable polish items for the relatively new single-pane layout. No existing duplicate found.

## Change summary

Files tab in single-pane detail panel disappears when a selected file is closed, and Changes view lacks a single-file viewing mode.

## Best solution

The Files tab closing behavior (item 1) is the more impactful issue — when a pinned Files tab opens a file editor, closing that editor should restore the Files tree view rather than removing the tab entirely. This likely involves `SinglePaneDetailVisibilityStrategy` or the editor tab lifecycle in `src/vs/sessions/contrib/layout/browser/singlePane/`. Issue https://github.com/microsoft/vscode/issues/326625 is related (wrong detail panel shown when opening files) but covers a different scenario. Item 2 (single-file Changes mode) is a separate feature request worth tracking alongside the existing Changes view work.
