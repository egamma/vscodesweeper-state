[https://github.com/microsoft/vscode/issues/327343](https://github.com/microsoft/vscode/issues/327343)

## Summary

Genuine, specific UX feedback on the experimental `sessions.layout.singlePaneDetailPanel` setting in the Agents window; the described close-behavior gap is plausible given the current strategy code and no fix or duplicate exists yet, so it should stay open and route to the layout/agents-window owners.

## Change summary

In the Agents window's single-pane detail panel mode, closing the currently-open file from the Files tab collapses the whole Files tree tab instead of returning to the file-picker placeholder; separately, the Changes view lacks a single-file-at-a-time mode.

## Best solution

Have the sessions/layout owners evaluate the two UX proposals against `singlePaneDetailPanelStrategy.ts` / `singlePaneManagedTabsStrategy.ts` — likely as small follow-ups to the still-active singlePaneDetailPanel work in `src/vs/sessions/contrib/layout/browser/singlePane/`.
