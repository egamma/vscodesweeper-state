# Issue #344770 — Malformed URI in DataTransferFile when dropping files from Windows Explorer into an extension TreeView

[https://github.com/microsoft/vscode/issues/344770](https://github.com/microsoft/vscode/issues/344770)

## Summary

The reported malformed URI is directly explained by current source: native filesystem paths are parsed as serialized URIs before reaching the extension's drop handler. Keep this open as a confirmed core bug.

## Change summary

Files dropped from Windows Explorer into an extension TreeView expose a DataTransferFile.uri whose scheme is the drive letter instead of file.

## Best solution

Ensure native dropped-file paths produce correctly normalized file URIs in the shared data-transfer conversion, while preserving file contents, URI-list behavior, and undefined URIs when no native path is available.
