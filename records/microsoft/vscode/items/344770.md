# Issue #344770 — Malformed URI in DataTransferFile when dropping files from Windows Explorer into an extension TreeView

[https://github.com/microsoft/vscode/issues/344770](https://github.com/microsoft/vscode/issues/344770)

## Summary

The reported defect remains in current main: native filesystem paths are parsed as serialized URIs before reaching the extension's drop handler. Keep this open; the source directly explains the malformed Windows drive-letter scheme.

## Change summary

Files dropped from Windows Explorer into an extension TreeView expose malformed DataTransferFile.uri values.

## Best solution

Ensure native dropped files expose correctly constructed filesystem URIs through the shared data-transfer conversion, preserving file contents, browser behavior, and existing URI-list handling.
