# Issue #126804 — Using left/right arrow keys to jump between wrapped lines causes cursor to skip a character

[https://github.com/microsoft/vscode/issues/126804](https://github.com/microsoft/vscode/issues/126804)

## Summary

Valid feature request with a concrete proposed approach from a maintainer (hediet: add a cursor stop at wrapping points for single cursor, skip it for multiple cursors). No implementation has landed — the behavior is unchanged on current main. Stays open for eventual implementation.

## Change summary

Add a cursor stop at word-wrap points when using a single cursor, so left/right arrow navigation feels natural at line-wrap boundaries (matching Visual Studio behavior).

## Best solution

Implement hediet's suggestion: add a cursor stop at the wrapping point for single-cursor navigation but skip it when multiple cursors are active. The change would likely touch `MoveOperations.moveLeft`/`moveRight` in `src/vs/editor/common/cursor/cursorMoveOperations.ts` and the view-model's `normalizePosition` handling of `PositionAffinity` at wrap boundaries.
