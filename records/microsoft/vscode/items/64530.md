[https://github.com/microsoft/vscode/issues/64530](https://github.com/microsoft/vscode/issues/64530)

## Summary

The References view still does not distinguish the definition file, and an open PR explicitly targets this request. Keep the issue open while that implementation is reviewed; it is not yet completed.

## Change summary

Distinguish files containing a symbol's definition from reference-only files, with a suggested collapse behavior for definition-only results.

## Best solution

Review https://github.com/microsoft/vscode/pull/338453 for the definition-file indicator and settle whether definition-only files need special expansion behavior. Keep this issue tracking the requested outcome until the accepted implementation lands.
