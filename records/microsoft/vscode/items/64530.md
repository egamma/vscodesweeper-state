# Issue #64530 — Highlight file containing definition

[https://github.com/microsoft/vscode/issues/64530](https://github.com/microsoft/vscode/issues/64530)

## Summary

The requested distinction remains absent on current main, and the issue is already accepted into the Backlog with `help wanted`; it should remain open for implementation and UX direction.

## Change summary

Visually distinguish the file containing a symbol's definition in the References view and avoid auto-expanding it when its only result is that definition.

## Best solution

Have the References view resolve the definition at the search origin, mark the matching file and reference in its model, and render an accessible definition indicator. The tree should use that metadata when deciding whether a single-result definition file starts collapsed.
