# Issue #254313 — No highlight in template string if enabled preferTreeSitter.typescript in Abyss color theme

[https://github.com/microsoft/vscode/issues/254313](https://github.com/microsoft/vscode/issues/254313)

## Summary

Still reproduces on main: the Abyss theme (and 12 other built-in themes) lack a `meta.template.expression` tokenColors rule, so tree-sitter template-string expressions inherit the string color instead of resetting to the default foreground.

## Change summary

With tree-sitter enabled for TypeScript and the Abyss theme, variables inside template strings are colored as strings instead of being reset to default text color.

## Best solution

Add a `meta.template.expression` tokenColors reset rule to the Abyss theme (and the other 12 built-in themes missing it: dark_modern, dark_plus, light_modern, light_plus, 2026-dark, 2026-light, kimbie-dark, quietlight, red, solarized-dark, solarized-light, tomorrow-night-blue). The base themes (dark_vs, light_vs, hc_black, hc_light) and Monokai variants already have it.
