Keep open: current Tree-sitter captures still let interpolated variables inherit Abyss's green string foreground. The earlier template-expression fix is present, but Abyss lacks the matching foreground reset, so it does not resolve this theme-specific report.

## Change summary

TypeScript template interpolations should retain normal expression coloring when Tree-sitter highlighting and the Abyss theme are enabled.
