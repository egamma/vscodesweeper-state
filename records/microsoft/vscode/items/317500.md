# Issue #317500 — Language model per-model settings are saved to the wrong provider group when multiple groups share the same vendor

[https://github.com/microsoft/vscode/issues/317500](https://github.com/microsoft/vscode/issues/317500)

## Summary

The reported provider-group selection defect was fixed on current main by PR https://github.com/microsoft/vscode/pull/322974. The service now resolves an unconfigured model through its model-to-group mapping instead of selecting the first group with the same vendor.

## Change summary

Per-model configuration changes were persisted under the first provider group sharing the model's vendor rather than the group that supplied the selected model.

## Best solution

Keep the shipped model-to-group lookup from commit fa3b663f7234b8a6965d921bbe2f855c13e54a17 and its regression test; no further change is needed for this report.
