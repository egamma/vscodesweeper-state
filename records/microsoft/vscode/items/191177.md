# Issue #191177 — Ref tree item in zone widget cannot repeat click

[https://github.com/microsoft/vscode/issues/191177](https://github.com/microsoft/vscode/issues/191177)

## Summary

The repeat-click failure remains in current source: the references preview skips revealing the same reference object even after its cursor or viewport has moved. Keep this open for a bounded fix in the Peek References widget.

## Change summary

Clicking the already-selected reference should restore its location in the peek editor after the user moves the cursor or scrolls away.

## Best solution

Make explicit activation of the current reference restore its preview location without changing normal single-click preview, double-click navigation, or modifier-click behavior.
