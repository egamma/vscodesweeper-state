# Issue #120604 — Allow app icon to be configured

[https://github.com/microsoft/vscode/issues/120604](https://github.com/microsoft/vscode/issues/120604)

## Summary

This remains a valid, highly supported Backlog feature request. Current main has no user-facing app-icon configuration, and its 106 community upvotes exceed the Backlog promotion threshold.

## Change summary

Allow users to select the VS Code application icon from a supported set of alternatives.

## Best solution

Keep this as the canonical app-icon customization request and have the branding and platform owners decide whether to offer a small curated set, including a more visually distinctive option, without permitting arbitrary branding.
