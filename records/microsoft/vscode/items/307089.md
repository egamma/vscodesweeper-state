The 408 'Timed out reading request body' error with code `user_request_timeout` is a server-side response from the GitHub Copilot backend — it does not originate from any VS Code client code. The error message, error code, and HTTP status are absent from the entire VS Code codebase (including the built-in Copilot extension). This is transient service-side behavior, not an actionable VS Code bug.
