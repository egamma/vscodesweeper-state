## Summary

Still valid: the object widget's 'Item'/'Value' column headers are hardcoded strings with no extension point for customization. The request remains unimplemented on main.

## Change summary

Allow settings with object widgets to provide custom labels for the 'Item' and 'Value' column headers in the settings UI.

## Best solution
