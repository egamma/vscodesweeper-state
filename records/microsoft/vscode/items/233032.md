# Issue #233032 — Allow settings with object widgets to configure labels for `item`/`value`

[https://github.com/microsoft/vscode/issues/233032](https://github.com/microsoft/vscode/issues/233032)

## Summary

The requested capability is still missing: object-setting headers remain fixed to “Item” and “Value,” with no setting-specific header descriptions. Keep this accepted backlog request open; the related UI-density exploration does not cover the same work.

## Change summary

Allow object-setting definitions to supply meaningful key/value column labels and optionally explanatory header tooltips.

## Best solution

Provide optional setting-definition metadata for object-widget headings and descriptions, retaining the existing localized headings as defaults. This belongs in the shared Settings editor presentation contract rather than a user-facing customization setting.
