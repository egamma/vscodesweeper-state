# Issue #332127 — Markdown task list checkboxes render incorrectly in preview

[https://github.com/microsoft/vscode/issues/332127](https://github.com/microsoft/vscode/issues/332127)

## Summary

Confirmed real gap on main: the built-in Markdown preview's markdown-it instance has no GFM task-list plugin, so `[ ]`/`[x]` render as literal bracket text rather than checkboxes. An open PR (#332137, from the same author, 'Fixes #332127') implements the fix — this should be routed to the markdown area for review rather than closed.

## Change summary

Markdown preview shows `[ ]`/`[x]` as literal bracket characters instead of rendered GFM task-list checkboxes.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332137, which adds a `markdown-it` core rule (extensions/markdown-language-features/src/extensions/taskList/taskList.ts) to detect task markers and emit disabled `<input type=checkbox>` elements plus supporting CSS in media/markdown.css.
