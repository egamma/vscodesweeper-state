# Issue #343929 — Composer with collapsed icons make it hard to differentiate between workspace and branch

[https://github.com/microsoft/vscode/issues/343929](https://github.com/microsoft/vscode/issues/343929)

## Summary

Keep open: current source still gives the workspace picker and the Branch isolation option the same folder icon, making their collapsed forms ambiguous. This is actionable team-authored design feedback, not grounds for a judgment close.

## Change summary

Make the collapsed workspace and Branch isolation controls visually distinguishable in the Agents Window composer.

## Best solution

Give the workspace and Branch isolation controls distinct, understandable identities when their labels are hidden, while preserving their tooltips, accessible names, and existing selection behavior.

- **Existing capability is only a workaround:** src/vs/sessions/contrib/chat/browser/iconOnlySessionPickers.ts exposes the "Collapse to Icon" context-menu toggle and persists per-picker choices.
