# Issue #296792 — loading session fails after "move chat into new window"

[https://github.com/microsoft/vscode/issues/296792](https://github.com/microsoft/vscode/issues/296792)

## Summary

This exact moved-chat restoration failure was subsequently reproduced in https://github.com/microsoft/vscode/issues/336748 and fixed by merged, verified PR https://github.com/microsoft/vscode/pull/337232. The fix is present in release 1.140.0, so this can be closed as completed.

## Change summary

Chat sessions moved into an auxiliary window could become impossible to reopen after closing the window or restarting VS Code.

## Best solution

Keep the shipped session-lifetime fix from commit 14200868c7fb67eb932fbdf69abbe0f87b5da837, which retains the chat model throughout a window move and preserves persisted sessions when models unload.
