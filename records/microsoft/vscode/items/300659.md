A reporter confirmed corrected menu text in that related thread, but the change does not address installation opt-out, and this report subsequently received a recurrence confirmation.
- **Current installer integration:** build/win32/code.iss:107-109 installs the shell AppX artifacts when ShouldUseWindows11ContextMenu is true; that predicate at lines 1564-1570 checks Windows version and forced classic-menu mode, not installer task selection. The localized ContextMenu Title registry entry at line 1275 is separately gated by addcontextmenufiles. Package registration alone therefore does not prove whether an opted-out entry should be visible.
- **Shell visibility boundary:** resources/win32/appx/AppxManifest.xml registers file and directory Explorer verbs. build/win32/explorer-dll-fetcher.ts fetches vscode-explorer-command v8.0.0-398351. Upstream main was not established as identical to the packaged DLL, so the reporter's actual registry and package state remain necessary to diagnose the residual behavior.
