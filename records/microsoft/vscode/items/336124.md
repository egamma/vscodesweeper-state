# Issue #336124 — Step Out action is incorrectly enabled when the active thread has only one stack frame

[https://github.com/microsoft/vscode/issues/336124](https://github.com/microsoft/vscode/issues/336124)

## Summary

Current main enables Step Out whenever debugging is stopped, without considering the active thread's stack depth. Keep the issue open while the linked fix attempt at https://github.com/microsoft/vscode/pull/336125 is reviewed.

## Change summary

Disable the Step Out action when the active thread has no parent stack frame.

## Best solution

Review and land or revise https://github.com/microsoft/vscode/pull/336125, ensuring every Step Out command surface follows an accurate active-thread stack-depth context and that transitions between one and multiple frames are tested.
