# Issue #313971 — ✨ Add "regenerate title(using llm)" action for copilot chat session

[https://github.com/microsoft/vscode/issues/313971](https://github.com/microsoft/vscode/issues/313971)

## Summary

Valid feature request for a user-triggered 'regenerate title with LLM' action on chat sessions. The codebase already has auto-title generation infrastructure (AgentHostSessionTitleController) that seeds and refines titles at session start / first turn, but no user-facing command to re-trigger LLM title generation later in a conversation. No duplicate found — the closed PRD #308186 was about auto-generated titles, and #283514 is about manual rename of local sessions.

## Change summary

Add a user-facing action to regenerate a chat session's title using an LLM, so that titles stay meaningful after multi-turn conversations evolve beyond the initial topic.

## Best solution

Add a 'Regenerate Title' command (alongside the existing /rename slash command) that re-invokes the title generation pipeline in AgentHostSessionTitleController using the full conversation context. The infrastructure for LLM-based title generation already exists; the gap is a user-triggered entry point. Surface it in the chat session context menu and as a slash command.
