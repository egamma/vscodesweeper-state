# Issue #341711 — Bring your own key (BYOK) models aren't supported in remote Copilot sessions.

[https://github.com/microsoft/vscode/issues/341711](https://github.com/microsoft/vscode/issues/341711)

## Summary

Thanks for the report. The message quoted in the issue describes a known limitation: BYOK models are only available through the local agent harness, which can reach the language models window. A remote session cannot use them. This reads as a feature request for BYOK support in remote sessions. A possibly related issue (332085) was suggested in the thread, but I could not verify it because GitHub API access was unavailable. It stays open for maintainer triage.

## Change summary

Support bring-your-own-key models in remote (SSH) Copilot agent sessions.

## Best solution

Let the remote agent host use BYOK models, for example by forwarding the local language-model provider or credentials. Alternatively, document the limitation and the workaround of configuring the Copilot CLI/SDK with BYOK environment variables on the remote host. If issue 332085 owns the same work, consolidate there once it is verified as open and as broad or broader.
