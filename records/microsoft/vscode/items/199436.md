# Issue #199436 — Git - Handle rebase when pulling & syncing

[https://github.com/microsoft/vscode/issues/199436](https://github.com/microsoft/vscode/issues/199436)

## Summary

Keep this accepted Backlog request open: git.autoStash provides an opt-in workaround, but does not provide the requested safeguards or conditional post-commit behavior. The Git area is already correct; a maintainer should settle the user-visible behavior before implementation.

## Change summary

Handle Pull and Sync more gracefully when rebase encounters uncommitted changes, including conditional handling of post-commit Sync.

## Best solution

Provide actionable handling of dirty-repository rebase attempts in the built-in Git extension, respecting the user's autostash preference. Decide whether automatic post-commit Sync should prompt, skip, or offer Push when local changes remain rather than silently changing the configured operation.

## Evidence

Repository.pullFrom and Repository._sync in extensions/git/src/repository.ts both pass this preference to the pull operation. extensions/git/src/git.ts adds --autostash for Git >= 2.27, while Repository.maybeAutoStash handles older Git.
