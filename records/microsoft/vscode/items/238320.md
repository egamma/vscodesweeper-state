# Issue #238320 — SCM Graph - Add support for graph for remote repositories

[https://github.com/microsoft/vscode/issues/238320](https://github.com/microsoft/vscode/issues/238320)

## Summary

Keep open: the linked fix corrects when the Graph view appears, but does not add commit history for remote repositories. The accepted Backlog request remains distinct from that visibility bug.

## Change summary

Display repository commit history in the Source Control Graph when opening a GitHub repository through Remote Repositories.

## Best solution
