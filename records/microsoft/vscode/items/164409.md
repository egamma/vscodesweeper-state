# Issue #164409 — codicon under block cursor is not displayed properly

[https://github.com/microsoft/vscode/issues/164409](https://github.com/microsoft/vscode/issues/164409)

## Summary

Still present on main: the block cursor DOM element overlays inline codicon decorations (e.g. debug stack frame icons), hiding them. The cursor renders only the text character and token class, with no accounting for inline decorations at that position. No fix found in git history.

## Change summary

Codicon inline decorations (e.g. debug stack frame icons) become invisible when a block cursor is positioned on top of them.

## Best solution

The block cursor rendering in `viewCursor.ts` needs to account for inline decorations at the cursor position — either by adjusting z-index layering, compositing the decoration into the cursor element, or making the cursor element transparent to the decoration layer. The fix would be in `src/vs/editor/browser/viewParts/viewCursors/viewCursor.ts` and possibly `viewCursors.css`.
