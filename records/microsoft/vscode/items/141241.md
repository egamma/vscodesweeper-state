# Issue #141241 — Changing brackets pair in code (feature request)

[https://github.com/microsoft/vscode/issues/141241](https://github.com/microsoft/vscode/issues/141241)

## Summary

Keep open: built-in bracket removal and selection provide a workaround, but do not directly replace a bracket pair or offer Python list/tuple conversion. The maintainer discussion supports exploring the interaction, while leaving its language-specific versus generic scope unresolved.

## Change summary

Provide an action to change an existing bracket pair, such as converting Python `[1, 2, 3]` to `(1, 2, 3)`, without editing each delimiter separately.

## Best solution

Decide whether this is a generic, explicitly invoked delimiter-editing action or a Python-aware refactoring. Preserve the enclosed content for generic replacement; any Python conversion must account for tuple syntax rather than promising semantic conversion from delimiter replacement alone.
