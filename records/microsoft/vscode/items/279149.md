# Issue #279149 — Prevent same version update with new update flow

[https://github.com/microsoft/vscode/issues/279149](https://github.com/microsoft/vscode/issues/279149)

## Summary

The developer update command still accepts a matching installer without comparing its identity with the running build. Keep this team-authored issue open: existing installer version metadata does not supply the requested same-version protection.

## Change summary

Prevent Developer: Apply Update from File from applying an installer for the running version, using embedded installer identity.

## Best solution

Make the Windows manual-update path recognize and reject an already-installed build before starting setup, while preserving legitimate updates and interrupted-update recovery.
