# Issue #150651 — Dedicated key/command for word-based suggestions

[https://github.com/microsoft/vscode/issues/150651](https://github.com/microsoft/vscode/issues/150651)

## Summary

The requested provider-specific command remains absent on current main. Related issues discuss mixing or asynchronously loading providers, but neither owns this distinct manual word-only invocation.

## Change summary

Add a keybindable command that immediately shows only word-based completion suggestions, independently of language-specific providers.

## Best solution

Add an editor command that locates the built-in word-based completion provider and invokes the existing filtered suggestion path, preserving the normal Trigger Suggest behavior.

## Evidence

- **available mechanism:** SuggestController already accepts a `Set<CompletionItemProvider>` filter, while src/vs/editor/browser/services/editorWorkerService.ts registers the built-in `WordBasedCompletionItemProvider`; no user-facing command connects the two.

- **async issue distinction:** https://github.com/microsoft/vscode/issues/107343 tracks progressively displaying results from multiple providers, a broader provider scheduling and ranking problem rather than word-only invocation.
