# Issue #150651 — Dedicated key/command for word-based suggestions

[https://github.com/microsoft/vscode/issues/150651](https://github.com/microsoft/vscode/issues/150651)

## Summary

Keep open: current settings enable word-based suggestions but do not provide an independent word-only command that bypasses language-server completion. The older related issues concern mixing or progressively displaying suggestions, not this dedicated invocation.

## Change summary

Provide a bindable command that immediately requests only word-based suggestions, independently of language-server completion.

## Best solution

Consider an explicit word-only suggestion command in the editor suggest area, preserving ordinary IntelliSense behavior and avoiding calls to semantic completion providers. Decide whether explicit invocation should override settings that disable automatic word-based suggestions.
