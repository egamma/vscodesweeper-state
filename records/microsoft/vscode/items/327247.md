# Issue #327247 — Support DocumentSymbolProvider in CustomTextEditor

[https://github.com/microsoft/vscode/issues/327247](https://github.com/microsoft/vscode/issues/327247)

## Summary

Keep this accepted API request open: current source provides opt-in custom-text-editor outlines through a proposed API, but not the stable extension contract requested. The linked implementation PR remains open and needs a maintainer disposition.

## Change summary

Allow custom text editors to populate the native Outline from document symbols and reveal selected symbols inside their custom presentation.

## Best solution

Evaluate the existing customTextEditorNavigation proposal against the requested outline and symbol-navigation behavior, and reconcile it with the contributor's open PR before deciding the stable API contract. Keep broader webview-panel and non-text-editor support distinct from the central custom-text-editor request.
