# Issue #319722 — Extension API to programmatically delete chat sessions

[https://github.com/microsoft/vscode/issues/319722](https://github.com/microsoft/vscode/issues/319722)

## Summary

Genuine API gap: extensions that consume (not provide) chat sessions have no public API to delete, open, or list sessions. The existing proposed `chatSessionsProvider` API exposes a `delete()` on `ChatSessionItemCollection`, but that is provider-side and not finalized. The consumer-side management API requested here remains missing. Team-authored, no duplicate found — keeping open.

## Change summary

Request for a public extension API to programmatically delete, open, and list chat sessions, avoiding orphan entries caused by direct file deletion.

## Best solution

Design a consumer-facing chat session management API (delete/open/list) on the `vscode.chat` namespace, likely building on the internal `IChatService.removeHistoryEntry()` and `ChatWidgetService.openSession()`. The proposed `chatSessionsProvider` API covers the provider side but not consumer extensions that need lifecycle management. Area: chat/API.
