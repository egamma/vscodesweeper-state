# Issue #319722 — Extension API to programmatically delete chat sessions

[https://github.com/microsoft/vscode/issues/319722](https://github.com/microsoft/vscode/issues/319722)

## Summary

A supported extension API for deleting existing VS Code-owned chat sessions remains missing. Keep this team-authored request open: the provider-side collection API and interactive deletion commands do not cover it, and the related requests do not own its full scope.

## Change summary

Expose supported chat-session lifecycle operations to extensions, principally selective deletion, with direct navigation and enumeration requested in the follow-up.

## Best solution

Have the chat API owners define a supported session-management contract that preserves storage, model, and UI consistency without extensions accessing private files or databases. Coordinate navigation and enumeration with the existing related requests, while deciding separately whether startup repair and retention configuration belong in this work.
