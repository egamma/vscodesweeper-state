[https://github.com/microsoft/vscode/issues/289657](https://github.com/microsoft/vscode/issues/289657)

## Summary

Keep open: the discussion includes a recent confirmation that agent commands still use PowerShell instead of Git Bash. Current main supports an explicit agent terminal profile, but that does not establish that the reported WSL/bash workflow is resolved.

## Change summary

Agent build commands run in a newly created PowerShell terminal rather than the intended WSL/bash environment.

## Best solution

Make the intended WSL/bash execution environment reliably selectable through the existing agent terminal-profile configuration, with commands generated for that shell. Evaluate the linked PR separately: its SSH quoting changes do not address terminal-profile selection.
