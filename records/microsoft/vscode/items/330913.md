## Summary

Team-authored debt/refactor proposal (connor4312, MEMBER) from a day ago; it's not yet implemented — resolveCustomizationEnablement is still called explicitly at many publication sites on main — so it stays open as a real, unshipped design change.

## Change summary

Refactor the customization emit/publish helper to resolve enablement internally so callers can no longer skip it, converting a recurring bug class into a compile-time impossibility.

## Best solution

Land the structural refactor described: change the publish/emit helper in customizationEnablementGate.ts (and its call sites in copilotAgentSession.ts, codexAgent.ts, claudeAgentSession.ts, mcpCustomizationController) to accept unresolved customizations and resolve internally, keeping the existing customizationEnablementGate.test.ts gate test meaningful.
