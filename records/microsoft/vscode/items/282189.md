# Issue #282189 — InlineCompletion Not Triggered on accepting when "command" option provided to InlineCompletionItem.

[https://github.com/microsoft/vscode/issues/282189](https://github.com/microsoft/vscode/issues/282189)

## Summary

Keep open pending a current-build check of the acceptance-command timing. The reporter documented a repeatable failure and a delayed-trigger workaround, but current source has ordering that appears to address it; no concrete fixing commit was established.

## Change summary

Accepting an inline completion with an attached command suppresses subsequent provider invocation, including an immediate explicit trigger from that command.

## Best solution

Ensure that attaching an acceptance command does not suppress follow-up inline completion requests, and that editor.action.inlineSuggest.trigger works inside that command without a timer. First reproduce the extension-host scenario against the current implementation to establish whether any defect remains.
