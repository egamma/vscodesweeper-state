# Issue #342147 — Agent Host: MCP servers sharing a resource receive the same OAuth token despite distinct client IDs

[https://github.com/microsoft/vscode/issues/342147](https://github.com/microsoft/vscode/issues/342147)

## Summary

Keep open for human review: current main still resolves distinct pending MCP authentication requests with the same supplied token when resource and scopes match. The credential-isolation concern is security-sensitive, so the hard keep-open rule applies.

## Change summary

Prevent concurrent Agent Host MCP authentication requests for distinct OAuth clients from receiving one another's credentials.

## Best solution

Preserve authentication-request and OAuth client/account identity throughout the workbench-to-host handoff so only the intended pending callback receives each credential. Human owners should assess the security implications and protocol compatibility, including the related provider-identity concern, before implementation.
