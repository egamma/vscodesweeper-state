# Issue #257583 — Copilot plugin will inflate .git folders

[https://github.com/microsoft/vscode/issues/257583](https://github.com/microsoft/vscode/issues/257583)

## Summary

Confirmed still present on main: the `getGithubRemoteFromSshConfig` fallback in the Copilot code-search repo tracker runs `git fetch --dry-run` to resolve SSH remote info, which downloads git objects and inflates `.git` folders. The bug is real and unfixed.

## Change summary

Copilot's code-search repo tracker runs `git fetch --dry-run` to resolve SSH remote info, which downloads git objects into `.git` and triggers the user's SSH agent without respecting autofetch settings.

## Best solution

Replace the `git fetch --dry-run` call in `getGithubRemoteFromSshConfig` (extensions/copilot/src/platform/workspaceChunkSearch/node/codeSearch/repoTracker.ts) with a non-fetching approach — e.g. `git remote -v` combined with `ssh -G <host>` to resolve the SSH hostname — so no objects are downloaded and no SSH key is touched unexpectedly.
