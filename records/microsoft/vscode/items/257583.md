## Change summary

Copilot's automatic repository identification reportedly triggers expensive Git fetches that grow .git and can prompt for SSH-key access.

## Best solution

Resolve repository identity without an implicit object-fetching operation while preserving SSH-alias support in CodeSearchRepoTracker. Establish which repository configurations produce disk growth, and assess the separately reported unexpected SSH-agent access before choosing the replacement behavior.
