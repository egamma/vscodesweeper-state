# Issue #335145 — Editor highlights individual letters instead of semantic symbols

[https://github.com/microsoft/vscode/issues/335145](https://github.com/microsoft/vscode/issues/335145)

## Summary

This is the existing, intentional `editor.selectionHighlight` feature ("highlight matches similar to the selection") — selecting any text, including a single character, highlights textual matches by design; it's not meant to be semantic symbol highlighting.

## Change summary

Reporter expects selecting a character/word to only highlight semantic symbol occurrences, not every textual match.

## Best solution

Point the reporter at the `editor.selectionHighlight` setting (to disable the text-match highlighting on selection) and `editor.occurrencesHighlight` (which already provides semantic occurrence highlighting for the symbol under the cursor when nothing is selected).

- **Proposed comment:**

  > Thanks for the report. What you're seeing is the `editor.selectionHighlight` setting — it highlights textual matches of whatever you've selected, by design, and can be turned off if you find it noisy. Separately, VS Code already has semantic symbol-occurrence highlighting via `editor.occurrencesHighlight` (set to `singleFile` or `multiFile`), which highlights real symbol references based on the language service when your cursor is on a symbol (no selection required). Closing as as-designed, but please reopen if `occurrencesHighlight` isn't giving you the semantic behavior you expect.
