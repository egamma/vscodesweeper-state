# Issue #335145 — Editor highlights individual letters instead of semantic symbols

[https://github.com/microsoft/vscode/issues/335145](https://github.com/microsoft/vscode/issues/335145)

## Summary

This is the intentional `editor.selectionHighlight` feature (plain-text match highlighting for the current selection), distinct from semantic occurrences highlighting, and it's already user-configurable — so this closes as designed rather than a bug.

## Change summary

Selecting a single character highlights every literal occurrence of that character in the file instead of only semantic symbol references.

## Best solution

Keep the shipped behavior: `editor.selectionHighlight` intentionally does a plain-text 'similar to selection' match (src/vs/editor/contrib/multicursor/browser/multicursor.ts, `SelectionHighlighter`/`SelectionHighlighterState.findMatches` calls `model.findMatches` on the literal selected text). Semantic symbol highlighting is a separate feature (`editor.occurrencesHighlight`) that only activates for a word under the cursor without a selection, via language providers. Reporter can disable selection highlighting via `editor.selectionHighlight: false` if the noise is unwanted.
