# Issue #335145 — Editor highlights individual letters instead of semantic symbols

[https://github.com/microsoft/vscode/issues/335145](https://github.com/microsoft/vscode/issues/335145)

## Summary

This is the `editor.selectionHighlight` feature working as intended — it highlights textual matches similar to the current selection (including a single selected character), which is a different, deliberately separate feature from semantic symbol/occurrence highlighting that only kicks in when the cursor sits on a word with no selection.

## Change summary

Selecting a single character highlights every textual occurrence of that character in the file, rather than only semantic symbol references.

## Best solution

Keep the shipped behavior; point the reporter at the `editor.selectionHighlight` setting (can be disabled or tuned via `editor.selectionHighlightMaxLength`) if the textual-match highlighting for short selections is unwanted — semantic-only highlighting already exists separately via cursor placement (`editor.occurrencesHighlight`).
