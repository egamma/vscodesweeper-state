# Issue #335145 — Editor highlights individual letters instead of semantic symbols

[https://github.com/microsoft/vscode/issues/335145](https://github.com/microsoft/vscode/issues/335145)

## Summary

The reported highlighting is the editor's intentional selection-match behavior, separate from semantic symbol occurrences. Existing settings let users disable textual selection matches while retaining semantic occurrence highlighting.

## Change summary

Use semantic symbol references rather than literal text matches when a character or substring is selected.

## Best solution

Keep selection matching and semantic occurrence highlighting as separate behaviors. Users who only want semantic symbol occurrences can disable `editor.selectionHighlight` while leaving `editor.occurrencesHighlight` enabled.
