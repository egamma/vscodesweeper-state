# Issue #344329 — Hidden subagent sessions appear in Sessions after a VS Code restart

[https://github.com/microsoft/vscode/issues/344329](https://github.com/microsoft/vscode/issues/344329)

## Summary

Keep open: another user confirms the restart-dependent session-list problem on 1.144.0. Current source explicitly excludes recognized subagents, but the path that loses or bypasses that classification remains unconfirmed.

## Change summary

Internal subagent transcripts become visible as ordinary Sessions entries after restarting VS Code.

## Best solution

Preserve internal subagent classification across session discovery and restart so only user conversations appear in Sessions, while child transcripts remain accessible through their parent. First identify which provider publishes the leaked entries; preserve genuine forks and peer conversations.
