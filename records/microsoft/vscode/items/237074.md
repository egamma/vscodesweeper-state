# Issue #237074 — Support Notebook Cell Level metadata such as Freeze/protect cell / skip execution/collapsed

[https://github.com/microsoft/vscode/issues/237074](https://github.com/microsoft/vscode/issues/237074)

## Summary

This feature request for cell-level metadata (editable, deletable, skip-execution/frozen) is not implemented on current main. The cell editable context key is still derived from notebook-level readOnly state, and NotebookCellMetadata remains a generic bag with no typed per-cell editability or execution-skip support. With 38 upvotes and the canonical status (issue #158715 was closed as a duplicate of this), it should remain open.

## Change summary

Support Jupyter notebook cell-level metadata (editable, deletable, frozen/skip-execution) so individual cells can be protected from editing or excluded from Run All.

## Best solution

Implement per-cell metadata support: read `editable`/`deletable` from cell metadata to control the cell editor's read-only state and deletion preconditions, and add a `run_control.frozen` (or equivalent) flag that causes Run All to skip frozen cells. The cell context key infrastructure in `cellContextKeys.ts` and the execution service in `notebookExecutionServiceImpl.ts` are the likely integration points. The `help wanted` label is appropriate — this is a well-scoped contribution opportunity.
