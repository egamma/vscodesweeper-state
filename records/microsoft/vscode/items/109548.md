# Issue #109548 — "Go to Symbol in Workspace..." - searching for symbols using more than one word/substring

[https://github.com/microsoft/vscode/issues/109548](https://github.com/microsoft/vscode/issues/109548)

## Summary

Keep this accepted feature request open: current source partially supports ordered substrings but does not cover the requested order-independent matching within a symbol name. The explicitly linked implementation PR remains open and should receive maintainer review rather than a competing implementation.

## Change summary

Allow workspace symbol searches to match multiple substrings within one symbol name, regardless of their order, while preserving symbol-and-container searches.

## Best solution

Review https://github.com/microsoft/vscode/pull/151859 against the full request, including reversed terms such as `three one` and `tw on`, and retain existing container filtering. Land an implementation that covers those cases without requiring language providers to return candidates they cannot currently discover.
