## Summary

Plausible JSDoc/IntelliSense gap for array-of-typedef parameters, but the actual type resolution, completion, and rename logic for JSDoc types is implemented in the TypeScript language service (tsserver, the `typescript` npm package from microsoft/TypeScript), not in the VS Code client extension — routing to the typescript area rather than closing.

## Change summary

When a JSDoc `@param` is typed as an array of a custom typedef, autocomplete/hover/rename only work correctly on the first array element instead of all elements.
