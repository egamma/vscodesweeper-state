# Issue #325731 — cannot rename session name

[https://github.com/microsoft/vscode/issues/325731](https://github.com/microsoft/vscode/issues/325731)

## Summary

This report and its comments describe the same session-rename persistence defect already tracked by the older, better-diagnosed https://github.com/microsoft/vscode/issues/316994 — rename applied via the in-session context menu doesn't persist, while renaming from the sessions list (or clicking the title) sticks.

## Change summary

Renaming an agent/chat session via the offered rename option doesn't actually change the session's title.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316994, which tracks the same rename-doesn't-persist defect with a clear repro (rename via in-session context menu reverts on navigating away, while list/title-click rename sticks) — fixing the title-commit path in src/vs/sessions/browser/parts/sessionHeader.ts and ISessionsManagementService.renameSession resolves both.
