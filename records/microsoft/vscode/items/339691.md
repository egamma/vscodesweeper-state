# Issue #339691 — Agents - picking a model expands collapsed group

[https://github.com/microsoft/vscode/issues/339691](https://github.com/microsoft/vscode/issues/339691)

## Summary

Team-authored bug report (filed while testing #339373) with an attached repro video; the code shows a plausible concrete mechanism — picking a model returns focus into the chat group's input, which triggers the same auto-expand-on-focus logic meant for deliberate group navigation. Team-authored items can't be closed on judgment alone, and no fix commit exists yet, so this stays open.

## Change summary

In the Agents window split layout, choosing a model from the model picker in a collapsed (minimized) chat group unexpectedly expands that group to full size.

## Best solution

Have the group's focus-driven auto-expand heuristic in chatGroupsView.ts ignore focus returning from the model picker selection, so picking a model doesn't resize a background/collapsed group the way a deliberate click into its body does.
