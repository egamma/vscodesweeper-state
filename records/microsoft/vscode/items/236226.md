# Issue #236226 — Should View use `canToggleVisibility`

[https://github.com/microsoft/vscode/issues/236226](https://github.com/microsoft/vscode/issues/236226)

## Summary

Team-authored polish issue that remains valid: the views listed (Comments, Chat, Search, Testing, Popular Extensions) still have `canToggleVisibility: false` on current main. The related PR #235846 addressed terminal/other views but did not cover the items in this issue.

## Change summary

Several views unnecessarily prevent users from hiding them via `canToggleVisibility: false`; only Explorer and UserDataSync Conflicts should keep that restriction.

## Best solution
