## Summary

The core defect — 'Allow all files in this repository for this session' silently failing when git root detection fails — was fixed in commit b2099b82ac1 and shipped in 1.115.0. The fix falls back to allowing the specific folder when no git root is found, addressing both the silent-failure UX and the dirname edge case functionally.

## Change summary

Clicking 'Allow all files in this repository for this session' silently did nothing when the target path was not inside a detectable Git repository, with no error message or fallback.

## Best solution

Keep the shipped fix in commit b2099b82ac1 (1.115.0); no further change is needed. The fix makes the action fall back to allowing the specific folder when git root detection fails, so the button is never a no-op.
