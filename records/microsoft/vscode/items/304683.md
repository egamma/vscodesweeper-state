# Issue #304683 — "Allow all files in this repository for this session" fail silently for external paths

[https://github.com/microsoft/vscode/issues/304683](https://github.com/microsoft/vscode/issues/304683)

## Summary

The repository-root detection defect remains in current source, although failed detection now grants folder access rather than doing nothing. Keep this open to correct directory-root lookup and settle how unsuccessful repository detection should be communicated.

## Change summary

Make external-path repository approval correctly detect directory targets and clearly communicate when repository-wide approval cannot be granted.

## Best solution

Repository approval should resolve the repository containing the actual target, including when list_dir targets the repository root itself. When no repository is found, the UI should accurately communicate the resulting permission scope rather than silently presenting folder approval as repository approval.
