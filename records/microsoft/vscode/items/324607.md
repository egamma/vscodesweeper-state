# Issue #324607 — Updating does not delete the temp installer

[https://github.com/microsoft/vscode/issues/324607](https://github.com/microsoft/vscode/issues/324607)

## Summary

Keep open: the Windows updater still retains the downloaded installer after completion; cache cleanup is tied to downloading another update rather than completing the current one. No fixing commit or verified older canonical was found.

## Change summary

Remove the downloaded temporary Windows installer after its update completes.

## Best solution

Give downloaded update packages a completion-aware cleanup lifecycle in the Windows updater, preserving packages needed by active installers or pending update recovery.
