# Issue #324607 — Updating does not delete the temp installer

[https://github.com/microsoft/vscode/issues/324607](https://github.com/microsoft/vscode/issues/324607)

## Summary

Valid bug filed by a team member while testing #324437 — the downloaded installer exe persists in the cache directory after the update completes. The cleanup method exists but may not run at the right lifecycle point post-update.

## Change summary

The downloaded update installer (e.g. CodeSetup-<quality>-<version>.exe) is not deleted from the cache directory after the update completes successfully.

## Best solution

Ensure the `cleanup()` method in `updateService.win32.ts` runs after the update is successfully applied and the new version starts — likely in the initialization path of the new version, cleaning up the previous version's installer package from the cache directory.
