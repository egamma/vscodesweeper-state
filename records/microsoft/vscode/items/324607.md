# Issue #324607 — Updating does not delete the temp installer

[https://github.com/microsoft/vscode/issues/324607](https://github.com/microsoft/vscode/issues/324607)

## Summary

Confirmed on main: the downloaded installer (CodeSetup-*.exe) is only removed by the next check-for-updates cycle, not right after a successful install, leaving stale installer files on disk in the meantime. Already assigned to dmitrivMS, so this just needs the fix landed.

## Change summary

After a Windows update finishes installing, the downloaded CodeSetup-*.exe temp installer stays on disk instead of being deleted.

## Best solution

In src/vs/platform/update/electron-main/updateService.win32.ts, remove the installer package (or call the existing `cleanup()` helper) once the poll loop in doApplyUpdate sees the install reach Ready/complete, instead of waiting for the next checkForUpdates() to prune old versions.
