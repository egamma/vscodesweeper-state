# Issue #306504 — Sessions App: The overlay editor preview button should replace the text editor.

[https://github.com/microsoft/vscode/issues/306504](https://github.com/microsoft/vscode/issues/306504)

## Summary

Keep open for the Sessions owners to reconcile with the newer Markdown experience. In-place switching now exists, but the general-purpose modal's original preview button still invokes the side-preview command, and no verified fix explicitly references this team-authored issue.

## Change summary

Make the Sessions Markdown preview button replace the source editor in place, with an easy way to switch back.

## Best solution

Resolve whether the current rich Markdown experience satisfies the plan/spec workflow while preserving the general-purpose modal behavior discussed by maintainers, or whether its existing preview button should also switch in place. Existing in-place commands can support that outcome without treating side-by-side preview as a broken feature.
