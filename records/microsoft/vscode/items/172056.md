# Issue #172056 — "Change All Occurrences" cursors get out of sync if one is moved with mouse

[https://github.com/microsoft/vscode/issues/172056](https://github.com/microsoft/vscode/issues/172056)

## Summary

Confirmed, team-reproduced bug: multi-cursor selections from 'Change All Occurrences' get desynchronized when one cursor is repositioned via mouse click. A MEMBER (ulugbekna) posted a reproduction video in December 2023. No fix commit references this issue, and no duplicate was found.

## Change summary

Using 'Change All Occurrences' and then clicking the mouse to reposition one cursor causes the selections across occurrences to fall out of sync, so subsequent edits (e.g. backspace) affect each occurrence differently.

## Best solution

Fix the mouse-click handling in the multi-cursor/selection controller so that clicking inside one of multiple synchronized selections either collapses all cursors consistently or repositions all cursors to the equivalent offset within their respective selections. The fix likely involves `src/vs/editor/contrib/multicursor/browser/multicursor.ts` and/or the mouse handler in `src/vs/editor/browser/controller/`.
