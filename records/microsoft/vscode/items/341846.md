# Issue #341846 — Copilot rejects valid MCP arguments with nullable oneOf schemas

[https://github.com/microsoft/vscode/issues/341846](https://github.com/microsoft/vscode/issues/341846)

## Summary

Thanks for the detailed diagnosis. The tool input validator still uses Ajv with coerceTypes: true, which can make both oneOf branches match for nullable schemas, so valid arguments get rejected.

## Change summary

Tool input validation rejects valid arguments for nullable oneOf schemas because Ajv type coercion makes both branches match.

## Best solution

In BaseToolsService.validateToolInput, validate the raw input without coercion first and only fall back to the coercing validator if that fails, so inputs that already satisfy the schema are accepted unchanged.
