# Issue #247070 — Terminal state's shell type should be faster

[https://github.com/microsoft/vscode/issues/247070](https://github.com/microsoft/vscode/issues/247070)

## Summary

Team-authored debt item that remains valid. The Windows shell type detection still relies on async process tree traversal with an initial delay, while macOS detection is immediate. The related PR #251065 was closed without merging, so the gap persists on current main.

## Change summary

Windows terminal shell type detection is slower than macOS because it requires async process tree traversal instead of using the already-known shell executable at creation time.

## Best solution

Use the shell executable from `IShellLaunchConfig.executable` (already known at terminal creation) to determine shell type immediately in `WindowsShellHelper`, falling back to async process tree detection. The fix lives in `src/vs/platform/terminal/node/windowsShellHelper.ts` and `src/vs/platform/terminal/node/terminalProcess.ts`.
