- **Delayed Windows detection remains:** src/vs/platform/terminal/node/windowsShellHelper.ts initializes _shellType as undefined. Its constructor starts checkShell(), which is decorated with debounce(500), awaits timeout(300), and then asynchronously traverses the process tree before publishing the detected type. src/vs/platform/terminal/node/terminalProcess.ts:185-189 constructs the helper using only the process ID.
