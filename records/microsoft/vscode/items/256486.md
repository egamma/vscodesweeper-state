# Issue #256486 — Add a `contexts` field to the .md metadata for a custom chat mode

[https://github.com/microsoft/vscode/issues/256486](https://github.com/microsoft/vscode/issues/256486)

## Summary

Valid feature request for a `contexts` metadata field in custom chat mode `.md` files. Not yet implemented — the prompt header parser has `tools`, `model`, `agents`, and a minimal `context` (singular string) attribute, but no array-based `contexts` field for auto-attaching files/folders/codebase references. The reporter found a partial workaround via markdown link syntax, but the declarative frontmatter approach remains unimplemented. Keeping open as a reasonable enhancement with the existing label and milestone.

## Change summary

Allow custom chat mode `.md` files to declare a `contexts` array in frontmatter metadata to auto-attach files, folders, or codebase references to every request using that mode.

## Best solution

Add a `contexts` array attribute to `PromptHeaderAttributes` and wire it through `PromptHeader`, `IChatMode`, and the chat submission flow so that declared context references are auto-attached. The existing `context` (singular string) attribute in `promptFileParser.ts` may serve as a starting point. The reporter's markdown-link workaround partially addresses the use case but lacks the declarative, always-attached semantics.
