Valid feature request for a decoration offset retrieval API. No implementation exists on main, the issue is in the Backlog milestone, and with 10 upvotes it has reasonable community interest. Keeping open for the area owner to evaluate.

## Change summary

Allow editor overlay widgets to retrieve the horizontal offset of inline decorations (e.g. inline suggestions) to avoid overlapping them.

## Best solution

Add an API on the editor view layer (alongside `getOffsetForColumn`) that returns the right-edge offset of inline decorations at a given line/column, enabling overlay widgets to position themselves without occluding decoration text. The work likely touches `src/vs/editor/browser/editorBrowser.ts` and the visible-line rendering internals.
