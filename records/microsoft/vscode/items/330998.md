# Issue #330998 — Modern UI: Hovered inactive unfocused editor tabs have a strange background

[https://github.com/microsoft/vscode/issues/330998](https://github.com/microsoft/vscode/issues/330998)

## Summary

Confirmed on current main: Modern UI's transparent-hover override in tabs.css (src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css:92) is scoped only to `.editor-group-container.active`, so unfocused editor groups still get the legacy `tab.unfocusedHoverBackground` background painted directly on `.tab` (injected in multiEditorTabsControl.ts:2498-2505) behind the rounded `.tab-fill` pill, exactly as the reporter diagnosed.

## Change summary

In Modern UI, hovering an inactive tab in an unfocused (unfocused) editor group shows a mismatched rectangular background behind the rounded tab pill.

## Best solution

Add a parallel transparent-background override for `.editor-group-container:not(.active) ... .tab:not(.selected):hover` in tabs.css, mirroring the existing `.active` rule at line 92, so the legacy `tab.unfocusedHoverBackground` color painted by multiEditorTabsControl.ts is neutralized for unfocused groups the same way it already is for the active group.
