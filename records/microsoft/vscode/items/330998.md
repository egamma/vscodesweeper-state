# Issue #330998 — Modern UI: Hovered inactive unfocused editor tabs have a strange background

[https://github.com/microsoft/vscode/issues/330998](https://github.com/microsoft/vscode/issues/330998)

## Summary

Confirmed on main: Modern UI's hover-transparency override only targets `.editor-group-container.active`, so hovered tabs in unfocused editor groups fall through to the legacy `tab.unfocusedHoverBackground` square instead of the transparent modern pill styling, causing the mismatched background the reporter shows.

## Change summary

In Modern UI, hovering an inactive tab in an unfocused editor group shows the legacy square hover background instead of the transparent modern pill styling, so it visually clashes with the hover action button background.

## Best solution

Extend the transparent hover-background override in tabs.css to also apply to non-active (unfocused) editor groups, mirroring the `.active` selector at line 92, so hover styling is consistent regardless of group focus.
