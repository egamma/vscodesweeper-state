The report predates this checkout; current source still contains the recovery mechanism, but inspection did not confirm the failure or identify a fixing commit.

## Change summary

Selecting “Don't restore editors” in the crash dialog reportedly reopens the same files and triggers another crash.

## Best solution

Make the crash-dialog recovery choice reliably prevent restoration of the previous editor session. First distinguish ordinary editor-state restoration from backup recovery or another editor-opening source, while preserving unsaved data and normal unchecked Reopen behavior.
