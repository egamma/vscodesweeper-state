# Issue #95332 — Git - Timeline support for folders

[https://github.com/microsoft/vscode/issues/95332](https://github.com/microsoft/vscode/issues/95332)

## Summary

Keep open: folder-scoped Git history remains missing from Timeline, and the Source Control Graph does not cover that scope. This accepted Backlog request has 39 upvotes, and a maintainer already consolidated a later folder/workspace Timeline request here.

## Change summary

Allow selecting a folder in Timeline to view Git commits affecting that folder and its descendants, equivalent to gitk -- <folder>.

## Best solution

Provide folder-scoped Git history through the existing Timeline surface, preserving file history behavior and offering meaningful folder commit actions. Keep bulk local-history recovery as related work rather than assuming it is delivered by Git folder history.

Later discussion also requests non-Git local-history aggregation and bulk recovery; the plan must explicitly distinguish those capabilities from the original Git history request.

  > files.openTimeline in src/vs/workbench/contrib/timeline/browser/timeline.contribution.ts accepts a URI, but the Explorer menu excludes folders.
