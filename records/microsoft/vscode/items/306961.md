# Issue #306961 — Sessions App: Cannot attach file from chosen branch

[https://github.com/microsoft/vscode/issues/306961](https://github.com/microsoft/vscode/issues/306961)

## Summary

Team-authored issue, still unfixed on main. The file picker in the Sessions App uses the current on-disk workspace folder when attaching context, so files that only exist in a selected (but not yet checked-out) branch cannot be referenced. Hard keep-open due to MEMBER authorship.

## Change summary

When starting a new session with a chosen branch in the Sessions App, the file attachment picker only shows files from the currently checked-out branch, not the selected target branch.

## Best solution

The session workspace picker (sessionWorkspacePicker.ts) and its file-listing logic need to resolve files from the selected branch ref (e.g. via git show or a virtual filesystem for the branch) rather than the on-disk working directory. This likely involves the workspace context service and the new-session flow in the Agents window.
