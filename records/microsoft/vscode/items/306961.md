# Issue #306961 — Sessions App: Cannot attach file from chosen branch

[https://github.com/microsoft/vscode/issues/306961](https://github.com/microsoft/vscode/issues/306961)

## Summary

Team-authored bug with active discussion and 'On Deck' milestone. The file picker in the Sessions App is scoped to on-disk workspace files, so when a user selects a branch that isn't checked out yet, files unique to that branch aren't available as context. No fix commit references this issue.

## Change summary

In the Sessions App, starting a new worktree session with a non-checked-out branch prevents attaching files that only exist in that branch as context.

## Best solution

When a branch is selected in the new-session picker but the worktree hasn't been created yet, the file picker/completions provider should query the git tree of the selected branch (e.g. via `git ls-tree`) rather than relying solely on the on-disk workspace folder. The fix likely involves the file completion handler in `src/vs/sessions/` and possibly the workspace folder management layer to provide a virtual or git-based file listing for the selected branch before the worktree is materialized.
