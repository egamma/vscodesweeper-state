# Issue #334305 — Consider JetBrains Mono for Modern UI typography and density

[https://github.com/microsoft/vscode/issues/334305](https://github.com/microsoft/vscode/issues/334305)

## Summary

Keep open for design consideration: Compact Mode addresses spacing, but does not evaluate or adopt JetBrains Mono for workbench typography. The related font-customization request does not cover the same product decision, so it is not a verified duplicate.

## Change summary

Evaluate JetBrains Mono for Modern UI typography to improve readability and density on smaller displays.

## Best solution

Have the workbench design owners assess whether JetBrains Mono improves small-size legibility and actual space utilization against the existing platform fonts, preserving consistent type roles and localized font fallbacks. Decide adoption from those comparisons rather than assuming a monospace font reduces layout dimensions.
