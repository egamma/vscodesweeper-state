# Issue #325062 — Dropdown menu subheader text color isn't accessible in selected state

[https://github.com/microsoft/vscode/issues/325062](https://github.com/microsoft/vscode/issues/325062)

## Summary

This should stay open: it is a team-authored accessibility bug with concrete contrast evidence and no linked fix or verified duplicate. The next step is for the owning UI/accessibility area to decide whether the dropdown subheader should use an existing token in selected state or needs a new color token.

## Change summary

Dropdown menu subheader text uses a low-contrast color in the selected state in the default dark theme.

## Best solution

Adjust the selected-state dropdown subheader foreground to meet WCAG contrast in default dark mode, ideally by reusing the correct existing color token; introduce a new token only if no current menu/list token covers subheaders in selected items.
