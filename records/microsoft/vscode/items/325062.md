# Issue #325062 — Dropdown menu subheader text color isn't accessible in selected state

[https://github.com/microsoft/vscode/issues/325062](https://github.com/microsoft/vscode/issues/325062)

## Summary

Legitimate accessibility bug filed by a team member — the dropdown separator/subheader text uses `--vscode-descriptionForeground` which doesn't change on focus/selection, producing a 3.21:1 contrast ratio against the focused background. No fix found on current main; keeping open.

## Change summary

Dropdown menu subheader/separator text has insufficient contrast (3.21:1) against the focused/selected row background in dark theme, failing WCAG AA for normal text.

## Best solution

Introduce a focused-state override for the separator decorator text color (currently `var(--vscode-descriptionForeground)` in `selectBoxCustom.css` line 102) so it meets WCAG AA (4.5:1) against the focused row background. This may require a new color token or reusing an existing focus-foreground token. The design team (@mrleemurray) is already tagged to determine the right token.
