- **Current scheduling path:** src/vs/editor/contrib/suggest/browser/suggestModel.ts:418-453 selects an inline-completion wait when quickSuggestions uses offWhenInlineCompletions and inline suggestions are enabled. _waitForInlineCompletionsAndTrigger waits while the inline model is loading, suppresses language suggestions when an inline result exists, and has a 750 ms fallback at lines 502-520. This directly explains the reported difference between enabled and disabled inline suggestions.
- **Existing configurable behavior:** src/vs/editor/common/config/editorOptions.ts:3815-3819 defaults other tokens to offWhenInlineCompletions. Setting editor.quickSuggestions.other to on bypasses that wait in SuggestModel while retaining inline suggestions. The maintainer documents this configuration at https://github.com/microsoft/vscode/issues/317863#issuecomment-4519342542. It provides independent language-completion triggering, but does not itself supply AI ranking or multiple AI entries in the completion widget.
