# Issue #265106 — why does organize import suggests the true and false if it only accepts the string

[https://github.com/microsoft/vscode/issues/265106](https://github.com/microsoft/vscode/issues/265106)

## Summary

The misleading completion remains on current main: the schema declares string values but includes boolean `true` and `false` in its completion enum. A maintainer has confirmed these are legacy compatibility values and accepted eventually deprecating them, so this should remain open as a bounded cleanup.

## Change summary

Stop suggesting legacy boolean values for `editor.codeActionsOnSave` entries such as `source.organizeImports` when the setting expects string values.

## Best solution

Keep legacy configurations compatible through the existing migration/runtime handling, but expose only `always`, `explicit`, and `never` as current setting completions.
