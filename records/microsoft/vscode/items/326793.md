# Issue #326793 — Cannot see chart text in Windows' high contrast modes

[https://github.com/microsoft/vscode/issues/326793](https://github.com/microsoft/vscode/issues/326793)

## Summary

This remains a source-confirmed accessibility bug in the built-in Mermaid chat renderer. Route it to the Mermaid and accessibility owners.

## Change summary

Mermaid diagram text becomes invisible in chat when Windows forced-colors mode is active.

## Best solution

Make the Mermaid webview preserve readable SVG text, node, and edge contrast under Windows forced-colors, likely in its shared theme or diagram styles, and verify every built-in Windows high-contrast palette.
