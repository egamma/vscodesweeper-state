# Issue #236745 — editorHoverVisible keybinding condition does not work

[https://github.com/microsoft/vscode/issues/236745](https://github.com/microsoft/vscode/issues/236745)

## Summary

The reported context mismatch remains in current source: hover visibility is editor-scoped, while shortcuts invoked from the search input resolve against that input's context. Keep this open; the existing Hide Hover command does not solve its conditional-keybinding failure.

## Change summary

Make editorHoverVisible usable for conditional shortcuts when an editor hover is visible but keyboard focus is outside the editor.

## Best solution

Allow the reported hover-visibility condition to control an explicitly configured shortcut outside the editor, while preserving editor-specific hover actions and existing Escape behavior elsewhere.
