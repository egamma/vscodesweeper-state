# Issue #263091 — Modify tab size, font-size, color, and padding.

[https://github.com/microsoft/vscode/issues/263091](https://github.com/microsoft/vscode/issues/263091)

## Summary

Current settings cover tab height tiers, width, and colors, but not tab-specific font size or padding. Keep this open for a coherent density decision rather than adding several independent styling knobs.

## Change summary

Allow editor tabs to use less space through configurable height, font size, colors, and padding.

## Best solution

Extend the existing tab-density model with useful supported tiers rather than arbitrary per-property styling. Continue using theme colors for color customization, and coordinate workbench font sizing with https://github.com/microsoft/vscode/issues/519 and broader density design with https://github.com/microsoft/vscode/issues/168671.
