# Issue #314388 — Runtime errors when prompt/agent references model or agent that doesn't exist

[https://github.com/microsoft/vscode/issues/314388](https://github.com/microsoft/vscode/issues/314388)

## Summary

This remains a valid feature request: prompts and custom agents should not silently fall back when an explicitly referenced model or agent cannot be resolved. No older issue with the same observable symptom is identified, and the report is specific enough for design and implementation planning.

## Change summary

Validate model and agent references in prompts and custom agents before execution, and surface an error instead of silently using a fallback.

## Best solution

Resolve all explicitly declared model and agent references before starting a chat turn, block execution when any reference is unavailable, and show a concise diagnostic identifying the invalid reference. The design should distinguish an explicit unavailable reference from configurations that intentionally omit a model and inherit the current selection.
