# Issue #193328 — allow opening previous projects from terminal like `code -p linux` instead of passing the full path 

[https://github.com/microsoft/vscode/issues/193328](https://github.com/microsoft/vscode/issues/193328)

## Summary

Keep open: the CLI still lacks a way to open a recently used project by name, and the existing Open Recent picker does not satisfy the terminal-only workflow. A maintainer endorsed the idea; no verified canonical or landed implementation was found.

## Change summary

Allow opening a previously visited project from any terminal directory using its name instead of its full path.

## Best solution

Provide CLI access to the existing recent-workspace history for opening projects by name, with explicit missing-name and ambiguous-name behavior. Settle the matching contract before implementation while preserving ordinary path-based opening.
