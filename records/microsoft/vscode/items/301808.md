Keep open as an upstream shell-grammar problem: the supplied arithmetic shifts match an acknowledged defect in the grammar bundled with VS Code. The linked VS Code reports are closed, so they are not valid duplicate targets.

## Change summary

Correct shell syntax highlighting for arithmetic expressions containing left shifts so subsequent code is not interpreted as a here-document.

## Best solution

Resolve the arithmetic-versus-here-document parsing defect in jeff-hykin/better-shell-syntax, then adopt the corrected grammar in VS Code's built-in shellscript extension. Preserve this report's nested arithmetic and CIDR sample as an integration check.
