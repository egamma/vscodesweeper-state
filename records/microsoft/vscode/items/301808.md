# Issue #301808 — Can't hightlight shell code correctly

[https://github.com/microsoft/vscode/issues/301808](https://github.com/microsoft/vscode/issues/301808)

## Summary

Known upstream grammar bug: the shell TextMate grammar (from jeff-hykin/better-shell-syntax) misparses `<<` inside arithmetic expressions as a here-document. The upstream issue is still open; multiple prior VS Code duplicates were closed with `upstream-issue-linked`. This should be labeled upstream and linked to the canonical grammar issue.

## Change summary

Shell script syntax highlighting breaks on bitwise shift operators (`<<`) inside arithmetic expressions like `$(( a << 24 ))`.

## Best solution

Label as `upstream-issue-linked` and link to https://github.com/jeff-hykin/better-shell-syntax/issues/104. The fix must come from the upstream grammar; once it ships, a grammar update PR in VS Code will pick it up. No core code change is needed.
