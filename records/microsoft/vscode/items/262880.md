# Issue #262880 — SCM Graph - follow Git Worktree selection

[https://github.com/microsoft/vscode/issues/262880](https://github.com/microsoft/vscode/issues/262880)

## Summary

Valid enhancement request accepted by the team (help wanted). The SCM Graph currently pins to a manually-selected branch and doesn't reset when the user switches worktrees/repositories. The reporter wants an option to auto-follow. No implementation found on main.

## Change summary

Add an option for the SCM Graph view to automatically follow worktree/repository selection instead of staying pinned to a manually-selected branch.

## Best solution

Add a setting or toggle in the SCM Graph view that controls whether switching repositories/worktrees resets the branch filter to 'auto' (following the current branch) or keeps the pinned selection. The logic lives in `SCMTreeViewModel._repositoryFilterState` in `src/vs/workbench/contrib/scm/browser/scmHistoryViewPane.ts` — when the active repository changes, the filter state for the new repository should default to 'auto' unless the user has explicitly opted to pin.
