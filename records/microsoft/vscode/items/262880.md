# Issue #262880 — SCM Graph - follow Git Worktree selection

[https://github.com/microsoft/vscode/issues/262880](https://github.com/microsoft/vscode/issues/262880)

## Summary

Keep open as a feature request: the maintainer confirmed that explicit graph branch selection intentionally pins the filter, while the reporter wants optional following after that selection. Current Auto modes provide following only without an explicit reference filter; the requested transition behavior remains a product decision.

## Change summary

Allow the SCM Graph to resume following the active repository/worktree when selection changes, even after manually viewing another branch.

## Best solution

Provide a deliberate follow-versus-pin behavior for graph reference selection, preserving the ability to inspect other branches. The SCM owner should settle whether following after a repository/worktree switch is opt-in or the default before implementation.
