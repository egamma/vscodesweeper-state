## Change summary

Pulling main while the background-session pending-changes prompt is open causes unrelated pulled changes to appear in the session after selecting Skip Changes.

## Best solution

Ensure that repository updates made while session initialization is awaiting confirmation are not presented as agent-authored edits. Reproduce the reported timing first, then establish whether the incorrect comparison originates in worktree metadata, repository-state freshness, or edit-session baseline capture.
