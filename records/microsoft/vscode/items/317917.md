# Issue #317917 — Add setting to suppress terminal context menu when mouse reporting is active

[https://github.com/microsoft/vscode/issues/317917](https://github.com/microsoft/vscode/issues/317917)

## Summary

Well-scoped feature request for a new terminal setting to suppress the VS Code context menu when xterm mouse reporting is active. No existing setting or capability covers this; no duplicate found. Currently in Backlog Candidates with the community upvote process underway.

## Change summary

Allow the integrated terminal to pass right-click events through to the pty instead of showing the VS Code context menu when terminal mouse reporting mode is active.

## Best solution

Add a new value (e.g. `passthrough`) to `terminal.integrated.rightClickBehavior` (or a dedicated boolean setting) that checks xterm's mouse-reporting mode flag before opening the context menu; the implementation would live in `terminalInstance.ts` around `handleMouseEvent` (line ~2530) and would need access to the xterm instance's mode flags. Keep open for the community process.
