# Issue #193603 — [wsl] Can't run `code .` when offline and VS Code got updated

[https://github.com/microsoft/vscode/issues/193603](https://github.com/microsoft/vscode/issues/193603)

## Summary

The failure was independently confirmed on the then-current stable release, but the affected installation flow belongs to the VS Code-team-owned Remote - WSL extension. Keep the bug open and move it to the Remote Development tracker rather than closing it as extension-caused.

## Change summary

Updating the local VS Code client removes the usable WSL server before confirming that its replacement can be downloaded, leaving offline users unable to run `code .`.

## Best solution

In Remote - WSL's server installation flow, stage and validate the replacement before removing the previous server, or transfer the matching server payload from the local client, so a failed download does not destroy the last usable installation.
