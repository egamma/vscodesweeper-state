# Issue #247901 — Add a "disable" option on tool confirmations

[https://github.com/microsoft/vscode/issues/247901](https://github.com/microsoft/vscode/issues/247901)

## Summary

Valid feature request: the tool confirmation UI currently offers Allow (with scopes) and Skip, but no option to disable the tool entirely. The feature has not been implemented on main.

## Change summary

Add a "disable" action on tool confirmation prompts so users can turn off a tool directly from the confirmation dialog.

## Best solution

Add a "Disable Tool" action to `additionalPrimaryActions()` in `ToolConfirmationSubPart` (and its post-execute counterpart) that toggles the tool's enablement state via the tool picker / `ChatSelectedTools` infrastructure, and reflects the change in the tool picker widget as discussed in the comments.
