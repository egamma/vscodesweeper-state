# Issue #247901 — Add a "disable" option on tool confirmations

[https://github.com/microsoft/vscode/issues/247901](https://github.com/microsoft/vscode/issues/247901)

## Summary

Team-authored feature request to add a 'disable' action on tool confirmation dialogs — still unimplemented on main. Keeping open per team-member policy.

## Change summary

Add a 'disable' action on tool confirmation prompts so users can turn off unwanted tools directly from the confirmation UI.

## Best solution

Add a 'Disable Tool' button/action to the tool confirmation widget (likely in `abstractToolConfirmationSubPart.ts` or `chatToolConfirmationSubPart.ts`) that toggles the tool off via the existing tool enablement model. The tool picker already supports enable/disable — this surfaces the same data model from the confirmation flow. Per the discussion, the disabled state should also be reflected in the tool picker for that workspace.
