# Issue #223553 — Node process in terminal not killed when VSCode is closed (Windows)

[https://github.com/microsoft/vscode/issues/223553](https://github.com/microsoft/vscode/issues/223553)

## Summary

Keep this as the canonical Windows terminal-process cleanup report: independent reports confirm development servers surviving closure of the last window, and maintainers have consolidated duplicates here. Current-source inspection identifies asynchronous shutdown paths but does not establish a fix or conclusively identify the cause.

## Change summary

Windows terminal-launched Node development servers remain running and occupy their ports after the last VS Code window closes.

## Best solution

Diagnose last-window shutdown through terminal disposal, the PTY host, and Windows process termination, then ensure ordinary terminal-launched development servers exit without manual port cleanup. Distinguish that failure from graceful-signal requests and task-only termination regressions before choosing the fix.
