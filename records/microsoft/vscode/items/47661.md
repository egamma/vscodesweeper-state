# Issue #47661 — Add a toggle to maximize a single view

[https://github.com/microsoft/vscode/issues/47661](https://github.com/microsoft/vscode/issues/47661)

## Summary

A meaningful gap remains for split terminals and arbitrary views. The request has 78 community upvotes and is already in the Backlog, so it should remain open.

## Change summary

Add a reversible toggle that maximizes the focused split terminal or view while preserving its previous layout.

## Best solution

Extend terminal split layout handling in `terminalGroup.ts` with a command that saves pane proportions, shows only the active terminal, and restores the previous layout when toggled. The existing editor-group behavior can serve as the interaction precedent.
