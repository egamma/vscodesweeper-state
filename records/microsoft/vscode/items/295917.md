# Issue #295917 — chat references never lead to exact code locations that chat intended to reference, but lead to definitions instead

[https://github.com/microsoft/vscode/issues/295917](https://github.com/microsoft/vscode/issues/295917)

## Summary

Keep open as a request for context-specific code citations: current symbol links deliberately resolve definitions, rather than the particular call discussed in the response. Explicit file-and-line links support precise navigation, but do not automatically address this distinction.

## Change summary

Make chat references to method usages navigate to the specific call site being discussed instead of the method or type definition.

## Best solution

Have chat distinguish definition references from usage citations and provide an explicit workspace location when discussing a particular call. Preserve definition navigation when the response actually refers to the symbol's declaration.
