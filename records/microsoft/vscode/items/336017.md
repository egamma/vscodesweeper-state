# Issue #336017 — Feature request: explicitly open folder in new window

[https://github.com/microsoft/vscode/issues/336017](https://github.com/microsoft/vscode/issues/336017)

## Summary

Legitimate gap: the command to open a folder in a new window already exists (`workbench.action.files.openFolderInNewWindow`) but isn't exposed anywhere in the File menu, so users must know to invoke it via the Command Palette. Demand is thin (0 reactions, single reporter) so this stays open as under-discussion rather than something to act on immediately.

## Change summary

Add a menu option to explicitly open a folder in a new window, alongside the existing 'Open Folder...' menu item that reuses the current window.

## Best solution

Register a menu item for the existing `workbench.action.files.openFolderInNewWindow` command in `MenuId.MenubarFileMenu` (near the other '2_open' group entries in src/vs/workbench/browser/actions/workspaceActions.ts), mirroring how OpenFolderAction is already registered there — no new command logic needed, just menu wiring.
