# Issue #336017 — Feature request: explicitly open folder in new window

[https://github.com/microsoft/vscode/issues/336017](https://github.com/microsoft/vscode/issues/336017)

## Summary

The underlying capability already exists as commands (`workbench.action.files.openFolderInNewWindow`, `workbench.action.files.openFileFolderInNewWindow`) but they aren't surfaced in the File menu, so the request is really about menu discoverability, not new functionality — a real, if narrow, gap.

## Change summary

Add an explicit 'Open Folder in New Window' option to the File menu instead of relying solely on the `window.openFoldersInNewWindow` setting or Command Palette.

## Best solution

Register a menu item (e.g. in the File menu, possibly as an alt/hidden action shown with a modifier key like other menus do) pointing at the existing `workbench.action.files.openFolderInNewWindow` command in src/vs/workbench/browser/actions/workspaceCommands.ts, so users get the option without needing the Command Palette or a global setting toggle.
