# Issue #297829 — Open Worktree context menu items no-op for Copilot CLI sessions from terminal

[https://github.com/microsoft/vscode/issues/297829](https://github.com/microsoft/vscode/issues/297829)

## Summary

Keep open: the reporter reproduced the exact terminal-created-session workflow after both earlier fixes, and the maintainer acknowledged fixing a different workflow. A linked implementation candidate remains open, while current source still exposes a branch-copy action that silently returns without worktree metadata.

## Change summary

Make session context-menu actions work meaningfully, or clearly indicate unavailability, for Copilot CLI sessions started directly in an integrated terminal.

## Best solution

Review the existing implementation candidate against the reporter's no-worktree scenario, not only externally created worktrees. Session actions should use the session's actual working location and branch where available, without offering silent no-ops when the required context is absent.
