# Issue #188273 — Files in .gitignore missing from search when Exclude Git Ignore is off

[https://github.com/microsoft/vscode/issues/188273](https://github.com/microsoft/vscode/issues/188273)

## Summary

Keep open for the maintainer-accepted clarification of search setting descriptions: current main still contains the ambiguous wording. Disabling search.useIgnoreFiles resolves the original search confusion, but does not complete the documentation improvement agreed in the thread.

## Change summary

Clarify that the search ignore settings exclude matching files from searches, and explain which directories the parent-ignore setting covers.

## Best solution

Improve the three ignore-setting descriptions in search.common.contribution.ts so their exclusion semantics, search scope, and parent-directory scope are explicit. Preserve the existing defaults and the separation between Explorer visibility and search behavior.
