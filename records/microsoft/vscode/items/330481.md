# Issue #330481 — Context window option is gone

[https://github.com/microsoft/vscode/issues/330481](https://github.com/microsoft/vscode/issues/330481)

## Summary

Multiple independent reporters confirm the context-size picker intermittently disappears from the model config button; a maintainer (lramos15) is already actively investigating and has requested (and partly received) debug-view data, so this stays open pending root-cause confirmation rather than closing.

## Change summary

The context window size selector in the model picker's config button intermittently vanishes, reappearing only after actions like a manual context compaction or leaving/returning to the conversation.

## Best solution

Root-cause the intermittent disappearance in ModelPickerConfiguration.renderButton (src/vs/workbench/contrib/chat/browser/widget/input/modelPicker/modelPickerConfiguration.ts) — it hides the config button entirely when `_getConfigProperty('tokens')` finds no schema property, which happens whenever the selected model's `configurationSchema` isn't populated yet; this is the same class of model-metadata timing race already called out in comments referencing issues #320393 and #321781 in chatModelConfigurationStore.ts and chatContextUsageWidget.ts. Confirm with the attached Chat Debug View data whether the schema is briefly missing/empty for the affected models.

## Evidence

- **hides button on missing schema:** src/vs/workbench/contrib/chat/browser/widget/input/modelPicker/modelPickerConfiguration.ts renderButton() sets `button.style.display = 'none'` whenever `!effortConfig && !tokensConfig`, i.e. when the selected model's configurationSchema has no 'tokens'-group property at render time.
- **known related timing races:** chatModelConfigurationStore.ts and chatContextUsageWidget.ts both have existing comments documenting model-metadata/config-schema availability races (issues #320393 and #321781) that this symptom closely matches — schema not yet available at initial render, later becoming available after a re-render (e.g. after a manual compact).
- **multiple reporters:** DovieW (author), a coworker, and jan-schuermeier all confirm the same disappearance on Stable/Insiders, Windows and macOS, across all models — reducing the odds this is a one-off local glitch.
