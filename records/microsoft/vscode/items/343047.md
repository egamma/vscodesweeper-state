# Issue #343047 — Chat Customizations: Browse can take ~17 seconds to load; investigate caching and progress

[https://github.com/microsoft/vscode/issues/343047](https://github.com/microsoft/vscode/issues/343047)

## Summary

Keep open: current source confirms that Browse waits for all queried sources before publishing available results. Existing caching and generic loading feedback only partially address the report; the approximately 17-second duration and connectors attribution still need measurement.

## Change summary

Make Customizations Browse responsive to independently completing sources, with meaningful progress, safe cache reuse, and privacy-safe latency diagnostics.

## Best solution

Allow available Browse results to appear while slow sources remain pending, retaining source-specific failures and cancellation guarantees. Establish freshness and ordering semantics before extending the existing caches, and measure source-category and total loading latency without collecting endpoint or content data.
