# Issue #317276 — Custom agent selection silently reverts to generic Agent mid-session; chat dropdown still shows the stale (correct) selection while the runtime has switched

[https://github.com/microsoft/vscode/issues/317276](https://github.com/microsoft/vscode/issues/317276)

## Summary

Keep open: independent reporters, including a maintainer, confirm silent mid-session custom-agent resets across Local and Copilot CLI harnesses. Current source exposes a plausible discovery-to-fallback path, but neither a complete diagnosis nor a verified fix covers this report.

## Change summary

Preserve the selected custom agent throughout a conversation and prevent the picker from misrepresenting the agent used by subsequent requests.

## Best solution

Make custom-agent identity reliable across discovery refreshes and session transitions, with the picker and request execution agreeing on the active agent. Diagnose the Local and Copilot CLI cases before treating CLI marker-file persistence as the solution.
