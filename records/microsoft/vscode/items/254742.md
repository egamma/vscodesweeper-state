# Issue #254742 — Add API for telling chat about webviews/custom editors

[https://github.com/microsoft/vscode/issues/254742](https://github.com/microsoft/vscode/issues/254742)

## Summary

The requested capability now exists as a proposed API, but it is not available through the stable extension API. Keep this older request open while the API owners resolve finalization; the related proposal is newer and cannot be its duplicate canonical under the re-review rules.

## Change summary

Let extensions supply meaningful chat context for webviews and custom editors instead of relying on HTML, accessibility snapshots, or underlying text files.

## Best solution

Finalize a supported tab/resource context API that lets webview and custom-editor extensions provide their own semantic content, preserving user control over attachment. Coordinate that remaining work with https://github.com/microsoft/vscode/issues/271104 rather than introducing a separate implementation.
