# Issue #254742 — Add API for telling chat about webviews/custom editors

[https://github.com/microsoft/vscode/issues/254742](https://github.com/microsoft/vscode/issues/254742)

## Summary

The requested semantic context API now exists as a proposal, but remains gated rather than available as stable extension API. Keep this older request open: the linked proposal tracks the remaining API work, but is newer and cannot be a duplicate target under the re-review rules.

## Change summary

Allow extensions to supply meaningful chat context for webviews and custom editors instead of relying on raw HTML, accessibility output, or backing-file text.

## Best solution

Finish evaluating and stabilizing the tab/resource context API through https://github.com/microsoft/vscode/issues/271104, confirming that extension-authored context covers both webview panels and custom editors. Avoid introducing a parallel API for this request.
