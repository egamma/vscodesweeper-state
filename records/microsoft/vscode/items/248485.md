# Issue #248485 — Feature request: 'accept word part' feature for inline suggestions (like `cursorWordPartRight`)

[https://github.com/microsoft/vscode/issues/248485](https://github.com/microsoft/vscode/issues/248485)

## Summary

The requested word-part acceptance command remains missing: existing inline-suggestion commands accept whole words or lines, while word-part navigation operates on document text. Keep this accepted Backlog request open; no canonical owning the same capability was found.

## Change summary

Provide an optional command that accepts the next word part of an inline suggestion, matching cursorWordPartRight semantics without requiring a default keybinding.

## Best solution

Provide a separately bindable word-part acceptance action in the editor's inline-completions area, consistent with existing word-part navigation. Preserve the current whole-word and whole-line acceptance behavior.
