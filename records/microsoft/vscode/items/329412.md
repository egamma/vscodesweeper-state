## Summary

Fresh, unrouted, credible report against the experimental Hybrid Markdown editor: HTML tags like <details>/<summary>/<kbd> aren't parsed into rendered widgets the way the built-in preview does, and there's no comparable HTML-element handling visible in the editor's webview source — this looks like a real gap rather than a misreport, so routing it to the markdown-editor area rather than closing.

## Change summary

In the experimental Hybrid Markdown editor (workbench.editor.markdownDefaultEditorInAgentsWindow), raw HTML tags such as <details>, <summary>, and <kbd> show up as plain unrendered text instead of being rendered like the built-in Markdown preview does.

## Best solution
