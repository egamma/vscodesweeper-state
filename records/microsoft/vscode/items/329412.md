# Issue #329412 — Hybrid Markdown editor: HTML tags (<details>, <summary>, <kbd>) are not rendered

[https://github.com/microsoft/vscode/issues/329412](https://github.com/microsoft/vscode/issues/329412)

## Summary

Keep open as a request for HTML rendering support in the experimental Markdown editor. The adopted parser deliberately preserves unsupported HTML blocks as source, and no verified canonical or fixing commit covers the requested behavior.

## Change summary

Render details/summary sections and styled kbd elements in the Hybrid Markdown editor rather than displaying their HTML source.

## Best solution

Establish support for these standard HTML elements in the hybrid editor's parser and view, preserving Markdown source and editing behavior. The rendering capability belongs primarily in the adopted @vscode/markdown-editor package, with VS Code integration covering both editing and reading presentations.
