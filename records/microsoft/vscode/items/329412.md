# Issue #329412 — Hybrid Markdown editor: HTML tags (<details>, <summary>, <kbd>) are not rendered

[https://github.com/microsoft/vscode/issues/329412](https://github.com/microsoft/vscode/issues/329412)

## Summary

Keep open: another user confirmed the rendering discrepancy on October 15, and no concrete fixing commit or qualifying duplicate was identified. The report provides sufficient steps to investigate HTML rendering in both editor modes.

## Change summary

Render standard HTML elements such as details, summary, and kbd in the Hybrid Markdown Editor instead of displaying their markup as text.

## Best solution

Provide supported HTML rendering in the Markdown Editor while preserving source text and existing editing behavior. Investigate the editor model/view pipeline separately from the Markdown Preview renderer, then establish coverage for collapsible sections and inline keyboard styling.

- **Behavior:**

  > Standard HTML elements in a Markdown document currently appear as raw markup in the Hybrid Markdown Editor, unlike Markdown Preview. A details/summary section should render as a collapsible section and kbd content should receive keyboard styling in the rendered presentation. Verify both editing and reading/locked modes without losing or rewriting the underlying HTML when users edit surrounding Markdown or switch modes.
- **Trace:**
