# Issue #144222 — Text selection highlight dissappears after right-clicking text in textbox

[https://github.com/microsoft/vscode/issues/144222](https://github.com/microsoft/vscode/issues/144222)

## Summary

Keep open: this is a team-authored bug with maintainer-confirmed root cause, and there is no provided fixing PR/commit that explicitly references https://github.com/microsoft/vscode/issues/144222. The discussion identifies the textbox selection loss as a visual/focus issue in custom context menus and distinguishes the command palette dismissal as a separate known issue.

## Change summary

On Windows, right-clicking selected text in VS Code textboxes makes the selection highlight and textbox focus ring disappear while the context menu is open.

## Best solution

The owning workbench/theme owners should either make textboxes keep visible inactive selection/focus styling while custom context menus are open, or adopt the menu shadow-DOM focus behavior where appropriate; the command palette dismissal should remain tracked separately.
