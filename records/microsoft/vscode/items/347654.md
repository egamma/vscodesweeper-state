# Issue #347654 — Agents window freezes on every send when there are thousands of external Copilot CLI sessions

[https://github.com/microsoft/vscode/issues/347654](https://github.com/microsoft/vscode/issues/347654)

## Summary

Keep open: current source confirms that every new-session send awaits a full catalog refresh and synchronously processes all returned sessions. The reported unresponsive-window samples identify this same path; the existing steps are sufficient for performance retesting.

## Change summary

Prevent thousands of external Copilot CLI sessions from blocking new-session sends and chat opening in the Agents window.

## Best solution

Remove whole-catalog reconciliation from the new-session send critical path while preserving correct session graduation, cancellation, and reconnect behavior. Address large-catalog responsiveness separately from the optional product decision about hiding sessions whose working directories no longer exist.
