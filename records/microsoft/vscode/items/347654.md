[https://github.com/microsoft/vscode/issues/347654](https://github.com/microsoft/vscode/issues/347654)

## Summary

Keep open: current main still awaits a full session refresh on each new-session send and synchronously visits every listed adapter. The supplied steps and unresponsive-window samples suffice to retest; the exact freeze and latency remain unverified without execution.

## Change summary

Prevent large external Copilot CLI session catalogs from blocking new-session sends and chat opening in the Agents window.

## Best solution
