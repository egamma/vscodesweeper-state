# Issue #333519 — Agents Window doesn't respect custom instructions to "never commit"

[https://github.com/microsoft/vscode/issues/333519](https://github.com/microsoft/vscode/issues/333519)

## Summary

Current behavior matches the documented instruction-pattern semantics: `**/*.*` is file-specific, while `**`, `**/*`, and `*` are always applied. Because this is a team-authored issue and no single follow-up product change has been selected, it should remain open rather than receive a judgment close.

## Change summary

Ensure an Agents Window session honors a global instruction intended to prevent commits and pushes.

## Best solution

Use `applyTo: '**'` for the reported always-on rule. If product work remains, the owner should choose between broadening universal-pattern recognition, warning when a near-universal pattern is file-scoped, or allowing trusted reads of indexed user instruction files.
