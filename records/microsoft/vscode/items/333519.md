# Issue #333519 — Agents Window doesn't respect custom instructions to "never commit"

[https://github.com/microsoft/vscode/issues/333519](https://github.com/microsoft/vscode/issues/333519)

## Summary

Real, actively-investigated bug: the Agents Window doesn't reliably honor a pattern-scoped custom instruction (`applyTo: **/*.*`) telling it never to commit, and a maintainer has already traced the root cause into the runtime's instruction-classification logic — this needs a code fix, not a close.

## Change summary

A global custom instruction with `applyTo: **/*.*` telling the agent to never commit is ignored, and the Agents Window commits and pushes anyway.

## Best solution

Fix the runtime's `has_specific_apply_to` classification (or the equivalent VS Code-side instruction inlining logic referenced in the comment) so that broad-but-technically-pattern-specific `applyTo` globs like `**/*.*` are either treated as universal or reliably loaded before the first tool-using request, so 'never commit' style guardrails are honored from turn one.
