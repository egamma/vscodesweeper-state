# Issue #324310 — BYOK Custom Endpoints Blocked by GitHub Sign-In Without Copilot

[https://github.com/microsoft/vscode/issues/324310](https://github.com/microsoft/vscode/issues/324310)

## Summary

Confirmed logic bug on current main: `isClientBYOKAllowed` in byokProvider.ts returns false when a GitHub session exists but no Copilot token is present, blocking independent BYOK endpoints. An open PR (#324311) targets the fix.

## Change summary

BYOK custom endpoint models fail when the user is signed into GitHub without a Copilot entitlement, even though those endpoints are independent of Copilot.

## Best solution

Land https://github.com/microsoft/vscode/pull/324311 (or equivalent fix) to decouple BYOK provider registration from Copilot entitlement status when the user has a GitHub session but no Copilot token. The fix belongs in `extensions/copilot/src/extension/byok/common/byokProvider.ts` — specifically in `isClientBYOKAllowed`.
