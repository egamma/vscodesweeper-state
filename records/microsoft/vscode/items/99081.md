# Issue #99081 — Settings sync - Cannot dismiss "Configure..." quick pick dialog

[https://github.com/microsoft/vscode/issues/99081](https://github.com/microsoft/vscode/issues/99081)

## Summary

Still valid: quick picks with `ignoreFocusOut` still have no mouse-accessible dismiss mechanism beyond Escape. The discussed close-button solution was never implemented. Multiple duplicates have been filed over the years, confirming ongoing user confusion.

## Change summary

Non-dismissible quick picks (those with `ignoreFocusOut: true`) cannot be closed by clicking outside or via a visible close button — only Escape or OK works.

## Best solution

Add an automatic close (X) button to the quick pick title bar whenever `ignoreFocusOut` is `true`, as proposed in the discussion. The implementation would live in `src/vs/platform/quickinput/browser/quickInputController.ts` — when setting up the title bar, conditionally add a close action to the right toolbar when `ignoreFocusOut` is set. This addresses an accessibility gap (mouse/touch-only users) that the team agreed on but never shipped.
