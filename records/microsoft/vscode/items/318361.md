# Issue #318361 — Support percentage-based and/or per-model context summarization thresholds

[https://github.com/microsoft/vscode/issues/318361](https://github.com/microsoft/vscode/issues/318361)

## Summary

Valid feature request to make the summarization threshold model-aware or percentage-based. The setting currently only accepts a flat number; no existing capability covers this. Keeping open for the community process.

## Change summary

Allow the context summarization threshold to be specified as a percentage of the model's context window or as per-model overrides, not just a flat token number.

## Best solution

Extend the setting schema in `extensions/copilot/package.json` to accept a string (percentage) or an object (per-model overrides), and update the consumption logic in `extensions/copilot/src/platform/configuration/common/configurationService.ts` to resolve the effective threshold based on the active model's context size.
