# Issue #318361 — Support percentage-based and/or per-model context summarization thresholds

[https://github.com/microsoft/vscode/issues/318361](https://github.com/microsoft/vscode/issues/318361)

## Summary

The central request is implemented: the summarization threshold now accepts a numeric ratio that automatically follows the active model's effective context window, while retaining absolute token counts. The proposed per-model map was an alternative, so its absence does not leave the central ask unresolved.

## Change summary

Allow conversation summarization thresholds to scale with the active model's context window instead of requiring a fixed token count.

## Best solution

Close as completed by commit 991f245d7725aba3714c0ae1ecd1092a69d44135 and document the supported numeric syntax: 0.7 for 70%, or 120000 for an absolute token budget.
