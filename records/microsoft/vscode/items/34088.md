# Issue #34088 — Enable fuzzy matching for picker

[https://github.com/microsoft/vscode/issues/34088](https://github.com/microsoft/vscode/issues/34088)

## Summary

Keep open: current QuickPick filtering still lacks arbitrary non-contiguous matching, including the reported `he_` example. This accepted, 42-upvote request needs a decision on default behavior versus extension opt-in, not a staleness close or consolidation into a general ranking tracker.

## Change summary

Allow QuickPick queries to match characters appearing in order in a label even when intervening characters are skipped.

## Best solution

Provide genuine subsequence filtering for extension QuickPicks while preserving predictable highlighting, ranking, and responsiveness. Decide whether this becomes the default or an explicit extension API option before implementation.
