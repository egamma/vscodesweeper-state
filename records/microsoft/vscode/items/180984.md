# Issue #180984 — Reopening a file (notebook) should open it as a notebook instead of as a text file

[https://github.com/microsoft/vscode/issues/180984](https://github.com/microsoft/vscode/issues/180984)

## Summary

Keep open: Quick Open history still preserves the previously resolved text-editor override, preventing a newly installed notebook provider from becoming the automatic choice. The maintainer discussion supports improving this behavior, but leaves the policy for retaining editor choices unresolved.

## Change summary

Reopening a notebook from Quick Open history after installing its provider should not retain an incidental text-editor fallback.

## Best solution

Make history-based reopening adopt a newly available notebook editor when the previous text view was an automatic fallback, while preserving deliberate editor choices. Agree on those retention semantics before changing the history/resolver contract.
