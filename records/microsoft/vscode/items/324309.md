# Issue #324309 — One editor window, many projects: give the editor the same session-switching sidebar as the Agents window

[https://github.com/microsoft/vscode/issues/324309](https://github.com/microsoft/vscode/issues/324309)

## Summary

Verified duplicate: the older open canonical issue already tracks keeping multiple independent workspaces available in one VS Code window, including separate project context and quick switching. This report contributes a Sessions-sidebar UX proposal and a working prototype, but no distinct requirement remains outside that canonical scope.

## Change summary

Add a Sessions-style sidebar to the regular editor for switching among warm, isolated project workspaces without separate visible OS windows.

## Best solution

Consolidate the sidebar design, isolation requirements, and window-coordination prototype on https://github.com/microsoft/vscode/issues/43188. Any implementation should preserve each workspace's editor, terminal, extension-host, settings, search, and SCM context while providing one coordinated switching surface.
