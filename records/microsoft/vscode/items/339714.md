# Issue #339714 — Expect no welcome message when mode set to `replace` with empty list

[https://github.com/microsoft/vscode/issues/339714](https://github.com/microsoft/vscode/issues/339714)

## Summary

The reported behavior remains on main: replace mode with an empty phrase list returns the default greetings. Keep this team-authored request open; the requested improvement conflicts with an explicitly documented and tested fallback, rather than exposing an accidental rendering failure.

## Change summary

Allow an explicitly empty welcome-message list in replace mode to display no welcome message.

## Best solution

Make the empty-list behavior consistent with the setting's promise that replace mode uses only custom phrases, while retaining default greetings for ordinary append mode. Preserve the existing global hide setting as an independent control.
