[https://github.com/microsoft/vscode/issues/348131](https://github.com/microsoft/vscode/issues/348131)

## Summary

The reported retry path remains present on current main: an empty BYOK response becomes Unknown, and Autopilot retries it before consulting task completion. Keep open for a bounded correction that preserves genuine error recovery.

## Change summary

Accept an empty successful follow-up after task_complete without three erroneous Autopilot retries.

## Best solution

Standard Autopilot should recognize successful task completion when the subsequent provider response completes without content, avoiding recovery requests and misleading messages while retaining retries for genuine failures.
