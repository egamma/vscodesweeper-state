# Issue #348131 — Autopilot treats empty output produced by `openai.gpt-6.1-sol` as error

[https://github.com/microsoft/vscode/issues/348131](https://github.com/microsoft/vscode/issues/348131)

## Summary

The current source explains the reported retries: an empty language-model response becomes Unknown, and Autopilot retries it before checking task completion. Keep this open as a bounded completion-handling bug.

## Change summary

Accept a successfully completed empty response after task_complete succeeds without issuing three recovery retries.

## Best solution

Standard Autopilot should finish normally when a successful task_complete is followed by a completed empty response, while retaining genuine error handling and existing stop-hook semantics.
