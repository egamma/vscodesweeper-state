# Issue #328932 — Markdown editor: Expose a stable accessible textbox identity

[https://github.com/microsoft/vscode/issues/328932](https://github.com/microsoft/vscode/issues/328932)

## Summary

Verified duplicate: the same author filed issue #327536 two days prior diagnosing the identical root cause (the unnamed EditContext `div` host in the Markdown editor) with a broader expected-behavior scope (textbox semantics, multiline, name, selection/caret info, read-only state) — this issue is a narrower, more detailed restatement of the same defect, so it should consolidate there.

## Change summary

Give the Markdown editor's EditContext-based editing host a stable `role="textbox"` accessible identity (name, `aria-multiline`, synchronized `aria-readonly`) that persists across editing/locked mode.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/327536, which already tracks the same missing editable-text accessibility semantics (role, multiline, name, read-only-on-lock) for the same focusable `div` host in the Agents window Markdown editor; the actual fix lands in the `@vscode/markdown-editor` package (microsoft/vscode-packages repo, `packages/core/src/view/editorView.ts`), not in microsoft/vscode itself.
