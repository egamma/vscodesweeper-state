# Issue #337451 — Support rich text and Markdown tables for AI agent conversations in the integrated terminal

[https://github.com/microsoft/vscode/issues/337451](https://github.com/microsoft/vscode/issues/337451)

## Summary

Keep open as a terminal feature request: the inspected terminal settings and rendering path do not provide an interactive Markdown rendering mode. Neither verified related issue owns this request, and there is no maintainer decision supporting a scope-based close.

## Change summary

Add optional streaming Markdown formatting, including readable tables and a raw-output toggle, within interactive integrated-terminal agent conversations.

## Best solution

Have the terminal owner assess whether optional structured-output rendering belongs in the terminal or should be supplied by CLI applications or an extension-backed surface. Any accepted solution should preserve terminal interaction and raw output while making streamed tables readable without a separate preview.
