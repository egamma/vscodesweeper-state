# Issue #158644 — Git - Push (and Sync) does not respect remote.pushdefault configuration

[https://github.com/microsoft/vscode/issues/158644](https://github.com/microsoft/vscode/issues/158644)

## Summary

Push and Sync still explicitly target the pull upstream, overriding the configured push destination. Keep this open while the linked implementation PR is reviewed; an open fixing PR is not a completed fix.

## Change summary

Honor Git's configured push destination in triangular workflows while retaining the upstream branch as the pull source.

## Best solution

Review https://github.com/microsoft/vscode/pull/323650 against the triangular-workflow requirements before landing it. Ensure default Push and Sync respect push configuration, and assess whether the refined publish-button and push-status requirements remain outstanding.
