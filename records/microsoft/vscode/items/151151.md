# Issue #151151 — Image stays broken when re-executing Markdown cell

[https://github.com/microsoft/vscode/issues/151151](https://github.com/microsoft/vscode/issues/151151)

## Summary

Still reproduces on main: the markup preview skips re-rendering when content is unchanged, so broken images (or stale cached images) persist after re-execution. Multiple open PRs attempt to fix it but none have merged.

## Change summary

Re-executing a notebook markdown cell without changing its content does not re-render images, so broken or stale images persist.

## Best solution

Land one of the open fix PRs (https://github.com/microsoft/vscode/pull/319247 is the most recent). The fix should add a force-render path in `showMarkupPreview` in `backLayerWebView.ts` when execution is explicitly triggered, bypassing the `sameContent` short-circuit at line 1358–1360.
