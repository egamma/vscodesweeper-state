# Issue #211262 — VS-Code Insiders - 1.89.0 broke Jupyter PowerToys Execute Group feature

[https://github.com/microsoft/vscode/issues/211262](https://github.com/microsoft/vscode/issues/211262)

## Summary

This is a confirmed Jupyter PowerToys extension regression rather than a VS Code core defect. It should be transferred to the extension's tracker, where the same failure remains open and the recovery release can be resolved.

## Change summary

Restore Jupyter PowerToys Execute Group commands that became disabled after the VS Code and Jupyter updates around version 1.89.

## Best solution

Transfer the report to https://github.com/microsoft/vscode-jupyter-powertoys and consolidate it with https://github.com/microsoft/vscode-jupyter-powertoys/issues/90. The extension owners should verify that the metadata fix in https://github.com/microsoft/vscode-jupyter-powertoys/commit/bc4f73e516b055a4c14ddb168015a3da5e254462 is published and restores persisted run groups on current VS Code and Jupyter versions.
