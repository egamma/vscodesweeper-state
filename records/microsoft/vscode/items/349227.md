# Issue #349227 — TypeScript 'using' declaration incorrectly marked as value never read

[https://github.com/microsoft/vscode/issues/349227](https://github.com/microsoft/vscode/issues/349227)

## Summary

The diagnostic originates in TypeScript, whose maintainers previously retained this behavior for implicitly disposed resources. Keep open as upstream rather than treating it as a VS Code diagnostic-rendering defect.

## Change summary

Avoid reporting a using binding as unread when its resource is implicitly disposed at scope exit.

## Best solution

Any change to this diagnostic belongs in TypeScript's unused-binding analysis, with VS Code continuing to display the language service's diagnostics consistently. The existing upstream decision recommends an underscore-prefixed binding for resources intentionally used only through disposal.
