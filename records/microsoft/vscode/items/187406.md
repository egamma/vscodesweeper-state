# Issue #187406 — Symbolic link of keybindings.json between Windows and WSL2 are not working.

[https://github.com/microsoft/vscode/issues/187406](https://github.com/microsoft/vscode/issues/187406)

## Summary

Fixed on main since 1.84.0: the atomic-write symlink bypass (commit e933c1d7b29) covers keybindings.json the same way it covers settings.json — both are registered in `fileUserDataProvider.ts` and the disk provider now detects symlinks and falls back to a direct write that preserves the link.

## Change summary

VS Code's atomic write for keybindings.json replaces the symlink with a regular file instead of writing through it.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/194856 — the fix shipped in 1.84.0 covers keybindings.json identically to settings.json. No further work needed.
