# Issue #285507 — Detect adding files to git index made via the command line and auto keep

[https://github.com/microsoft/vscode/issues/285507](https://github.com/microsoft/vscode/issues/285507)

## Summary

Valid polish request: the SCM working set controller only reacts to branch (history item ref) changes, not to staging changes made via CLI. The feature gap remains on current main — no related changes have landed since the issue was filed.

## Change summary

When files are staged via the CLI (`git add`), the SCM panel detects the change but the editor working set doesn't auto-keep those files, unlike when staging via the SCM panel's + button.

## Best solution

Extend `SCMWorkingSetController` in `src/vs/workbench/contrib/scm/browser/workingSet.ts` to listen for resource-group changes (staging events) in addition to history-item-ref changes, and auto-keep editors for newly staged files — mirroring the behavior that already exists when staging via the SCM panel UI.
