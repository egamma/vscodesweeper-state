# Issue #311166 — Copilot Chat: skills should declare capability requirements, and the platform should surface unmet ones

[https://github.com/microsoft/vscode/issues/311166](https://github.com/microsoft/vscode/issues/311166)

## Summary

Valid, well-scoped feature request from a team member. Skill frontmatter today supports only name/description/argument-hint/user-invocable/disable-model-invocation/context, but not tools/mcp-servers/hooks/model — the asymmetry with agent frontmatter is confirmed in current main. No implementation work has landed.

## Change summary

Allow SKILL.md frontmatter to declare capability requirements (tools, MCP servers, hooks, model) and surface unmet requirements as diagnostics.

## Best solution

Extend `skillAttributes` in `src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptFileAttributes.ts` with tools/mcp-servers/hooks/model fields mirroring agent attributes, then wire up validation in the prompt validator and surface diagnostics in the Problems panel and Chat Customizations editor. The comment from pbmol confirms real-world silent degradation pain.
