[https://github.com/microsoft/vscode/issues/289936](https://github.com/microsoft/vscode/issues/289936)

## Summary

The API cleanup merged, but the core cleanup remains: current main still combines getAgentChangesSummary with hasValidDiff and actively uses summary-only changes for local and cached sessions. Keep this open to settle the remaining representation boundary.

## Change summary
