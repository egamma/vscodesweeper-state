# Issue #302155 — Confusing names/slash commands

[https://github.com/microsoft/vscode/issues/302155](https://github.com/microsoft/vscode/issues/302155)

## Summary

The naming inconsistency remains on current main: the picker calls the mode “Bypass Approvals,” while slash-command discovery exposes `/yolo` and `/allow-all`. The obsolete enabled-state concern has been addressed, but choosing one public vocabulary remains an open UX decision.

## Change summary

Use consistent, state-aware names for the slash commands and picker that control whether agent tool approvals are bypassed.

## Best solution

Choose one user-facing name for this permission mode and use it consistently in the picker, slash-command discovery, descriptions, and documentation. Preserve old command spellings only if compatibility requires aliases, and avoid offering aliases that do not change the current state.
