# Issue #229548 — Dragging a file over Inline Chat or Chat editor should show message `Hold shift to drop into Chat`

[https://github.com/microsoft/vscode/issues/229548](https://github.com/microsoft/vscode/issues/229548)

## Summary

Keep open: the Shift modifier makes the drop work, but the existing overlay describes dropping into the editor rather than attaching the file to Inline Chat, so the requested contextual feedback remains missing. This is a team-authored feature request in the Backlog, and no verified older canonical owns the same observable request.

## Change summary

Show contextual drop feedback such as “Hold Shift to drop into Chat” when dragging a file over Inline Chat or Quick Chat.

## Best solution

Provide a chat-specific drag overlay that clearly distinguishes attaching the dragged file to Chat with Shift from the editor's normal file-drop behavior, consistently across Inline Chat and Quick Chat.
