# Issue #284243 — [Feature] : Add “Open in Integrated Terminal” option to editor tab context menu

[https://github.com/microsoft/vscode/issues/284243](https://github.com/microsoft/vscode/issues/284243)

## Summary

The same request was previously declined as an extension candidate, and a minimal extension now provides it. Adding another unconditional editor-tab menu item would conflict with the established goal of keeping that menu lean.

## Change summary

Add an editor-tab context-menu command that opens an integrated terminal in the selected file's parent directory.

## Best solution

Use the existing Terminal Here extension or another extension contributing this command to the editor-tab menu, rather than expanding the core menu.

## Vision fit

- **Fit:** rejected
- **Reason:** This optional workflow shortcut is implementable through the extension ecosystem and would add niche surface to an already crowded core menu.
- **Evidence:** Public values: “The power lives in extensions” and VS Code should remain a lightweight, fast text editor out of the box.
