# Issue #92174 — Improve parameter hints UX

[https://github.com/microsoft/vscode/issues/92174](https://github.com/microsoft/vscode/issues/92174)

## Summary

The requested single-line, horizontally centered parameter hints remain unsupported by the current widget and its settings. The older positioning request concerns above/below placement, not this report's wrapping and horizontal alignment, so it does not absorb the work.

## Change summary

Make parameter signatures easier to read by avoiding unnecessary wrapping and centering the hints popup horizontally around the cursor.

## Best solution

Design a readable, viewport-aware parameter-hints layout in the editor contribution that addresses both signature wrapping and horizontal placement. Settle how signatures wider than the available viewport remain readable without changing documentation, overload navigation, or other editor widgets.
