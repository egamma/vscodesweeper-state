[https://github.com/microsoft/vscode/issues/92174](https://github.com/microsoft/vscode/issues/92174)

## Summary

The two core requests — single-line parameter signature display and horizontal centering at the cursor — remain unimplemented on current main. The widget still uses a multi-line wrapping layout (max-width 440px) and positions at the cursor's left edge, not centered.

## Change summary

Make parameter hints display the signature on a single line and center the widget horizontally at the cursor position, like IntelliJ.

## Best solution

Rework the parameter hints widget layout to render the signature portion on a single non-wrapping line (with horizontal scroll or ellipsis for very long signatures) and adjust the content widget positioning logic in parameterHintsWidget.ts to center the widget over the cursor column rather than left-aligning it.
