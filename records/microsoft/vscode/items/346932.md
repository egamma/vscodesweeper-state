# Issue #346932 — Inbox mode: Undo banners are unnecessary for non-destructive single-session actions

[https://github.com/microsoft/vscode/issues/346932](https://github.com/microsoft/vscode/issues/346932)

## Summary

Keep open as actionable UI polish: current Inbox actions show Undo banners even for one non-destructive session change. A maintainer also confirms that these banners obstruct list interactions.

## Change summary

Reserve session-list Undo banners for destructive actions or actions affecting multiple sessions.

## Best solution

Single-session Inbox triage should update the list without an Undo overlay, while bulk triage and destructive-action recovery remain available. Preserve accessible action feedback without announcing an Undo control that is not shown.
