## Best solution

Ask the reporter to confirm network connectivity from the remote host (can it reach api.githubcopilot.com:443?), check proxy settings (http.proxy, HTTP_PROXY env var), and review the firewall/endpoint guidance at https://github.blog/changelog/2024-11-04-copilot-subscription-based-network-routing-is-now-enforced/. If the Node fetcher genuinely doesn't respect VS Code's proxy settings in remote environments, that would be a real bug — but the report needs that detail.
