# Issue #331294 — Sent session gets marked as an archived session

[https://github.com/microsoft/vscode/issues/331294](https://github.com/microsoft/vscode/issues/331294)

## Summary

Team-authored bug with a real milestone (1.134.0) and an open fixing PR already referencing this work, so it stays open per the milestone and open-PR keep-open rules — no completed fix exists on main yet.

## Change summary

Omni chat marks a session as archived/read-only (and blocks sending) even for a normal, non-archived session, apparently affecting all new sessions.

## Best solution

Land https://github.com/microsoft/vscode/pull/331322 (filters archived/read-only sessions out of omni chat pending items) so archived sessions are correctly excluded and the read-only banner/behavior stops appearing for active sessions.
