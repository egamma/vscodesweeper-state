# Issue #127454 — Invalid find matches

[https://github.com/microsoft/vscode/issues/127454](https://github.com/microsoft/vscode/issues/127454)

## Summary

Properly triaged upstream Chromium bug — window.find() treats diacritical characters as matching their base characters (Chromium issue 71741, open since 2008). VS Code cannot fix this; it stays open as an upstream tracker.

## Change summary

Webview find-in-page matches 'code' when searching for 'cöde' due to Chromium's window.find() treating diacritics as equivalent to base characters.

## Best solution

This depends on Chromium fixing https://bugs.chromium.org/p/chromium/issues/detail?id=71741. If the team decides to work around it, the webview find implementation could bypass window.find() for queries containing diacritical characters and use a custom DOM traversal instead — but that's a significant effort for an edge case.
