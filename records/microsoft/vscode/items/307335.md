# Issue #307335 — Copilot login failed (PermissiveAuthRequiredError: Permissive authentication is required)

[https://github.com/microsoft/vscode/issues/307335](https://github.com/microsoft/vscode/issues/307335)

## Summary

The reporter isolated a reproducible authentication failure to minimal-permission mode and confirmed that removing the setting restores Copilot. Keep this open: refusing expanded permissions is intentional, but that does not establish that ordinary Copilot Chat should fail or report an already signed-in account as signed out.

## Change summary

Copilot reports GitHub login failure when minimal authentication permissions are configured, despite an existing GitHub sign-in.

## Best solution

Establish whether the minimal-mode session lookup loses an otherwise usable GitHub session, and preserve basic Chat access where minimal credentials suffice. Features requiring expanded permissions should explain that limitation without presenting it as a general login failure.
