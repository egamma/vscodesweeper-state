# Issue #168680 — Settings editor dropdown is still visible after closing editor

[https://github.com/microsoft/vscode/issues/168680](https://github.com/microsoft/vscode/issues/168680)

## Summary

Keep open: a maintainer confirmed reproduction with editor.closeEmptyGroups disabled, and the current editor-close path still lacks explicit dismissal of the settings dropdown. No verified fixing commit or older canonical reporting the same symptom was found.

## Change summary

Closing the Settings editor with Cmd+W can leave its expanded dropdown visible when editor.closeEmptyGroups is false.

## Best solution

Ensure a Settings dropdown disappears when its owning editor closes, including when the empty editor group remains. Establish a focused regression check for that lifecycle without changing setting values or unrelated context views.
