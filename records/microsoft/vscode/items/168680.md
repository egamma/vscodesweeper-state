# Issue #168680 — Settings editor dropdown is still visible after closing editor

[https://github.com/microsoft/vscode/issues/168680](https://github.com/microsoft/vscode/issues/168680)

## Summary

Still reproduces on main: the settings editor dropdown (a SelectBox using ContextViewService) is not dismissed when the editor tab is closed via Cmd+W, because there is no lifecycle hook that hides the context view when the editor is disposed. Confirmed on current sources — no fix commit references this issue.

## Change summary

The settings editor dropdown remains visible after the editor is closed with Cmd+W.

## Best solution

When the settings editor is disposed, ensure any open context view (dropdown overlay) is hidden — either by calling `hideContextView()` from the editor's dispose path, or by having the SelectBox widget detect its container's removal from the DOM and self-close. The fix likely belongs in `src/vs/workbench/contrib/preferences/browser/settingsWidgets.ts` or at the ContextView/SelectBox base level.
