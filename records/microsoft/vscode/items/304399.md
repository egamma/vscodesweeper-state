## Change summary

## Best solution

This is most likely an environment issue (lost execute permission on the rg binary, noexec mount, or admin policy). The reporter should check `ls -la` on the ripgrep binary path and verify the filesystem mount options. If the execute bit is missing, `chmod +x` on the binary resolves it. If the issue persists after reinstalling the server, it may warrant deeper investigation into how VS Code Server sets binary permissions during installation.
