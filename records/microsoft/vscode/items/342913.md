# Issue #342913 — Agents Window: support drag-and-drop reordering of composer pickers

[https://github.com/microsoft/vscode/issues/342913](https://github.com/microsoft/vscode/issues/342913)

## Summary

Keep open: the existing experimental setting changes Environment's position, but does not provide the requested drag interaction or equivalent keyboard reorder actions. The assigned 1.144.0 milestone also requires keeping this scheduled follow-up open.

## Change summary

Support persistent, accessible drag-and-drop reordering of desktop Agents Window composer pickers, initially Environment relative to Workspace.

## Best solution

Extend the Sessions composer with discoverable pointer and keyboard reordering backed by one ordering preference, preserving draft state, selections, focus, and matching DOM/navigation order. Settle the collapsed-rail, narrow-layout, and unavailable-picker behavior before implementation.
