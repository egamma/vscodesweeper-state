# Issue #326590 — Ctrl+Backslash in Quick Open file menu should trigger Open to the Side

[https://github.com/microsoft/vscode/issues/326590](https://github.com/microsoft/vscode/issues/326590)

## Summary

The requested default shortcut remains missing: Ctrl+Backslash is registered for Split Editor, not acceptance of the selected Quick Open file. Existing shortcut customization does not fully cover the requested default behavior, and no verified open canonical was found.

## Change summary

Make Ctrl+Backslash open the selected Quick Open file to the side, like Alt+Enter.

## Best solution

Decide whether Quick Open should give Ctrl+Backslash a context-specific Open to the Side binding while preserving Split Editor outside the picker and the existing Alt+Enter behavior. Any such binding should follow the configured side-by-side direction.
