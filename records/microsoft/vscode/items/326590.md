# Issue #326590 — Ctrl+Backslash in Quick Open file menu should trigger Open to the Side

[https://github.com/microsoft/vscode/issues/326590](https://github.com/microsoft/vscode/issues/326590)

## Summary

This is a valid Quick Open keybinding consistency request. The action is configurable today, but Ctrl+Backslash is not its default binding.

## Change summary

Make Ctrl+Backslash open the selected Quick Open file to the side, matching the editor split shortcut.

## Best solution

Consider binding Ctrl+Backslash to `workbench.action.alternativeAcceptSelectedQuickOpenItem` while file Quick Open is active, with context and precedence that avoid invoking the ordinary Split Editor action.

- **Reason:** Using the established split-editor shortcut for the equivalent Quick Open operation would make keyboard interaction more uniform.
