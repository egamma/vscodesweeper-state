# Issue #317285 — I'd really like to be able to 'colour code' projects

[https://github.com/microsoft/vscode/issues/317285](https://github.com/microsoft/vscode/issues/317285)

## Summary

A real Agents window usability gap remains: existing customization can distinguish the active workspace globally or assign project icons, but cannot give each concurrently visible project's chat a persistent color. Keep this Backlog request open for design discussion.

## Change summary

Allow users to assign colors to project folders so chats from different projects are visually distinguishable.

## Best solution

Add an accessible per-folder accent option to the Agents window project customization model and surface it on the project icon and corresponding session header or input. Color should supplement, not replace, the existing project name and configurable icon.
