# Issue #232931 — Conditional breakpoint is not being hit with source-mapped TypeScript variables in VSCode

[https://github.com/microsoft/vscode/issues/232931](https://github.com/microsoft/vscode/issues/232931)

## Summary

Keep open: source-mapped variable names remain unsupported in the conditional-breakpoint evaluation path inspected. The existing rename setting covers other evaluation contexts, and no verified open canonical or fixing commit establishes that this request is resolved.

## Change summary

Allow conditional breakpoints in source-mapped TypeScript to reference original variable names when generated JavaScript renames them.

## Best solution

Support scope-aware original-name evaluation in the bundled JavaScript debugger's conditional-breakpoint path, preserving the distinction between the renamed local argument and an outer variable with the same original name.
