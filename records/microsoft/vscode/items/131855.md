# Issue #131855 — ctrl+z undo both auto-indentation and default behavior

[https://github.com/microsoft/vscode/issues/131855](https://github.com/microsoft/vscode/issues/131855)

## Summary

The reported behavior remains in current main: Tab replaces an empty line with the complete language-derived indentation as one undoable edit, so Ctrl+Z cannot retain the ordinary one-tab indentation. The related paste issue discusses the opposite grouping for a different operation and does not absorb this report.

## Change summary

Undoing language-aware indentation inserted by Tab should leave the normal single-tab indentation rather than returning to the start of the line.

## Best solution

Preserve Tab's language-aware indentation behavior while making its automatic portion independently undoable, so the first undo leaves one normal indentation step; keep paste undo semantics and non-empty-line Tab behavior unchanged.
