## Summary

Verified duplicate: auto-indentation inserting an extra undo stop (so ctrl+z undoes the indent separately from the user action) is the same root cause as the canonical issue #30406. Team member @hediet already linked them.

## Change summary

Pressing ctrl+z after auto-indentation undoes only the auto-indent instead of the full user action (e.g. Tab), requiring a second undo.

Consolidate on https://github.com/microsoft/vscode/issues/30406, which tracks the general problem of auto-indentation inserting extra undo items. Fixing the undo-stop grouping there resolves this Tab case as well.
