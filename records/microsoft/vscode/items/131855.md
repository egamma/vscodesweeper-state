# Issue #131855 — ctrl+z undo both auto-indentation and default behavior

[https://github.com/microsoft/vscode/issues/131855](https://github.com/microsoft/vscode/issues/131855)

## Summary

The undo behavior remains in current main: Tab applies computed auto-indentation as one edit, so undo cannot preserve the ordinary tab-stop indentation. The related paste issue does not fully cover this Tab-specific behavior.

## Change summary

Undoing Tab-triggered auto-indentation should retain the indentation that a normal Tab would have inserted.

## Best solution

Separate the ordinary Tab insertion from the additional auto-indentation adjustment in undo history, while preserving current selection and multi-cursor behavior. Add a cursor regression test for undo on an empty continuation line.
