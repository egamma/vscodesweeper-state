# Issue #327605 — No "Show Less" with the first prompt.

[https://github.com/microsoft/vscode/issues/327605](https://github.com/microsoft/vscode/issues/327605)

## Summary

The inconsistency remains visible in current source: ordinary first requests render their full Markdown without a disclosure control, so a long initial prompt can still consume the chat viewport. The existing bug should remain open for a bounded chat-renderer fix.

## Change summary

Allow a long first chat prompt to be collapsed with the same disclosure behavior available for later prompts.

## Best solution

Give long first-request bubbles the established prompt disclosure behavior while preserving full rendering for short prompts, editing, pending requests, and confirmations.
