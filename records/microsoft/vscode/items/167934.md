# Issue #167934 — EOL says elsewhere modified but no modication was ever done

[https://github.com/microsoft/vscode/issues/167934](https://github.com/microsoft/vscode/issues/167934)

## Summary

Still reproduces on main: the Settings Editor shows 'Modified elsewhere' when a setting has language-specific default overrides (e.g., Shell Script sets files.eol to \n), even though the user never modified anything. The wording incorrectly implies user action.

## Change summary

The 'Modified elsewhere' indicator in the Settings Editor misleadingly shows for settings with language-specific default overrides, implying the user changed something when they didn't.

## Best solution

Change the indicator label for the `overriddenDefaultsLanguageList` case to something like 'Has language-specific defaults' or 'Default varies by language' to distinguish extension/language-contributed defaults from actual user modifications. The fix lives in `src/vs/workbench/contrib/preferences/browser/settingsEditorSettingIndicators.ts` around lines 432-434.
