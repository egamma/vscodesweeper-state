# Issue #167934 — EOL says elsewhere modified but no modication was ever done

[https://github.com/microsoft/vscode/issues/167934](https://github.com/microsoft/vscode/issues/167934)

## Summary

Keep open for clearer Settings editor wording: current main still displays “Modified elsewhere” when only a built-in language default exists. The configuration behavior is intentional, but the indicator still conflates shipped defaults with explicit configuration.

## Change summary

Distinguish language-specific defaults from settings explicitly modified in another scope.

## Best solution

Make the Settings indicator clearly distinguish contributed language defaults from explicit user, remote, or workspace overrides. Preserve Shell Script’s LF default and the intentional distinction between selecting a default-valued option and using Reset Setting.
