# Issue #283975 — Git fetch from other branches

[https://github.com/microsoft/vscode/issues/283975](https://github.com/microsoft/vscode/issues/283975)

## Summary

Keep open while the two linked implementation candidates are reviewed. Existing fetch commands do not cover updating selected local branches without checkout, and the maintainer has already supported adding an action in the Repositories view.

## Change summary

Allow updating one or multiple inactive local branches from their remotes without checking them out, equivalent to git fetch <remote> <branch>:<branch>.

## Best solution

Review the linked PRs against the original local-branch-update requirement and the maintainer's Repositories-view direction. The finished feature should advance selected local branch refs without changing the active branch or working tree; fetching remote-tracking refs alone does not satisfy the request.
