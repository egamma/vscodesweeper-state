# Issue #331497 — Requests to run outside sandbox are STILL clipped, rendering the feature useless

[https://github.com/microsoft/vscode/issues/331497](https://github.com/microsoft/vscode/issues/331497)

## Summary

Same reporter as microsoft/vscode#327969 (who supplied a confirmed screenshot repro there) now confirms on 1.133 that the fix (PR #328150) did not actually resolve the truncation — and their read of the code matches what I found: that PR only touched `.chat-confirmation-widget2 .chat-title` wrapping and the terminal code-editor resize observer, not the elicitation-based 'run outside the sandbox' confirmation path.

## Change summary

The 'run command outside the sandbox' confirmation prompt truncates the command text regardless of window width, with no tooltip to see the full command.

## Best solution

Have the terminal/chat area owner check whether the automatic-sandbox-retry prompt (built via `ChatElicitationRequestPart` in `_promptForAutomaticSandboxRetry`/`runInTerminalTool.ts`, rendered by `ChatElicitationContentPart` → `ChatConfirmationWidget`) is the affected surface — that widget's message area uses a `DomScrollableElement` with `horizontal: ScrollbarVisibility.Hidden` (chatConfirmationWidget.ts), which can silently clip an unbroken long command with no visible scrollbar or tooltip, unlike the widget2/editor-pool path that PR #328150 fixed.
