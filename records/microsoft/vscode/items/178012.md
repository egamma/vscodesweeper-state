# Issue #178012 — Always show arrow in suggest item

[https://github.com/microsoft/vscode/issues/178012](https://github.com/microsoft/vscode/issues/178012)

## Summary

The discoverability gap remains on current main: suggestion details are still exposed through an arrow hidden until the focused row is hovered. This team-authored UX request should remain open for a design decision.

## Change summary

Make the control for expanding suggestion documentation persistently visible or show documentation by default.

## Best solution

Choose a consistent suggest-widget design that exposes documentation without requiring pointer hover, likely by keeping the expansion affordance visible on the focused expandable item while preserving keyboard access and compact layout.
