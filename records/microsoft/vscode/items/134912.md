# Issue #134912 — Test API: Cursor should be placed prior to inline error message

[https://github.com/microsoft/vscode/issues/134912](https://github.com/microsoft/vscode/issues/134912)

## Summary

Keep open: testing still permits a cursor stop after its inline message, and the maintainer discussion explicitly supports suppressing that position. Existing injected-text controls provide the underlying capability, but testing has not adopted it for this case.

## Change summary

Keep the editor cursor at the end of the source code, before an inline test error message.

## Best solution

Make inline testing messages behave as post-line annotations rather than additional cursor destinations, while preserving their hover and click interactions. Keep this narrowly scoped to testing rather than changing navigation around all injected text.
