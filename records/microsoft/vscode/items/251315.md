# Issue #251315 — Support JSON schema draft 2020-12

[https://github.com/microsoft/vscode/issues/251315](https://github.com/microsoft/vscode/issues/251315)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/155379 tracks the same unsupported `$dynamicRef` and meta-schema behavior underlying this MCP failure. Consolidating there preserves one canonical implementation discussion while carrying over the distinct consequence that affected MCP tools are omitted.

## Change summary

Support JSON Schema Draft 2020-12 features so valid MCP tool schemas are accepted instead of causing the tools to be omitted.

## Best solution

Implement `$dynamicRef`, `$dynamicAnchor`, and the associated Draft 2020-12 meta-schema behavior through the JSON language service work tracked by https://github.com/microsoft/vscode/issues/155379; the MCP validation path will then accept these schemas without maintaining a separate validator workaround.
