# Issue #148226 — VSCode’s renderer helper process using 100% of CPU

[https://github.com/microsoft/vscode/issues/148226](https://github.com/microsoft/vscode/issues/148226)

## Summary

Keep open: multiple independent reports confirm sustained helper CPU usage, including extension-free installations and processes surviving application quit. No verified fix or canonical issue accounts for the full reported behavior; process-specific profiling is needed to separate the causes.

## Change summary

VS Code helper processes consume sustained CPU and drain battery, sometimes remaining active after VS Code quits.

## Best solution

Identify the runaway process and hot stack, then address the responsible execution or shutdown path so an idle window does not sustain heavy CPU usage and application-owned helpers terminate on quit. Separate confirmed extension, terminal, and tree-rendering causes rather than treating every high-CPU helper as the same defect.
