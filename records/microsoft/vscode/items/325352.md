# Issue #325352 — `terminalIsOpen` includes hidden extension terminals, making terminal keybindings unreliable

[https://github.com/microsoft/vscode/issues/325352](https://github.com/microsoft/vscode/issues/325352)

## Summary

The requested distinction is still missing: current terminal context keys cannot express whether any non-background panel or editor terminal exists. Route this to the terminal area as a feature request; the cited panel-command decisions do not settle this narrower context-key request.

## Change summary

Expose a context key that distinguishes user-accessible panel/editor terminals from hidden background terminals.

## Best solution

Expose whether any foreground terminal exists, including terminals in inactive editor tabs or a collapsed panel, while preserving existing terminalIsOpen semantics for compatibility. Hidden extension terminals should continue operating without influencing that new condition.
