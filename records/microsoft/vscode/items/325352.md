# Issue #325352 — `terminalIsOpen` includes hidden extension terminals, making terminal keybindings unreliable

[https://github.com/microsoft/vscode/issues/325352](https://github.com/microsoft/vscode/issues/325352)

## Summary

Well-documented feature request for a context key that reflects only user-visible terminal instances. The existing `foregroundInstances` getter already provides the right data; only a new context key is missing.

## Change summary

Request a context key (e.g. `terminalVisibleIsOpen`) that excludes hidden/background extension terminals, so keybindings can distinguish when no user-visible terminal exists.

## Best solution

Add a new context key (e.g. `terminalVisibleIsOpen`) in `src/vs/workbench/contrib/terminal/common/terminalContextKey.ts` and wire it up in `_handleInstanceContextKeys` in `terminalService.ts` using `foregroundInstances.length > 0` instead of `instances.length > 0`. This is a small, localized change.
