# Issue #162117 — Edit session semantics are not easy to understand

[https://github.com/microsoft/vscode/issues/162117](https://github.com/microsoft/vscode/issues/162117)

## Summary

A real UX gap remains: current main still exposes Cloud Changes separately from Continue Working On without clearly communicating its application-wide consent, cloud storage, and one-way transfer semantics.

## Change summary

Clarify how Cloud Changes relates to Continue Working On, including enablement scope, storage, restoration, and whether changes remain synchronized.

## Best solution

Revisit the end-to-end Continue Working On flow through UX research, then either contain Cloud Changes consent within that flow or make the standalone account actions explain their application scope, cloud upload, and one-way restoration behavior.

- **Reason:** Making a core cross-environment workflow understandable advances the project's commitment to simple, consistent workbench interactions.
