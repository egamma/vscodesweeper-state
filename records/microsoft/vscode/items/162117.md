# Issue #162117 — Edit session semantics are not easy to understand

[https://github.com/microsoft/vscode/issues/162117](https://github.com/microsoft/vscode/issues/162117)

## Summary

Keep open for the requested end-to-end UX discussion. Renaming Edit Sessions to Cloud Changes and improving documentation address part of the confusion, but the Accounts menu still exposes enablement separately from Continue Working On, and the thread's product questions remain unsettled.

## Change summary

Make the relationship between Continue Working On, Cloud Changes enablement, and restoring working changes understandable in the UI.

## Best solution

Evaluate the Accounts-menu entry and Continue Working On flow together so users understand application-wide enablement, one-way transfer rather than continuous synchronization, and what restoration does. Preserve the existing optional transfer behavior; settle the entry-point design with UX feedback before implementation.
