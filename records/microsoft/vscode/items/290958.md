# Issue #290958 — non-merged agent.md files aren't shown as cloud custom agent

[https://github.com/microsoft/vscode/issues/290958](https://github.com/microsoft/vscode/issues/290958)

## Summary

The local-only agent warning exists, but newly created agent files still do not automatically refresh the cloud picker. Keep this reopened issue open: the thread confirms the remaining reload requirement, and current source has no local-agent change subscription.

## Change summary

Show newly created local-only custom agents in the cloud picker with an unavailable indication without requiring a window reload.

## Best solution

Refresh the cloud custom-agent options when local agent files change, preserving the existing locked state and remote-availability warning. Local discovery must not imply that an unpushed agent can run in the cloud.
