# Issue #290958 — non-merged agent.md files aren't shown as cloud custom agent

[https://github.com/microsoft/vscode/issues/290958](https://github.com/microsoft/vscode/issues/290958)

## Summary

The core 'local agent is invisible' complaint was fixed by microsoft/vscode-copilot-chat PR #3215 (merged 2026-01-28, body says 'fixes ... microsoft/vscode/issues/290958'), which added a locked/disabled 'Missing from {org}/{repo}' entry for local-only agent files. But the issue was reopened specifically because that fix still requires a window reload to show up, and current main still has no fix for that: there is no file watcher on `.github/agents`, the picker options are served from a 15-minute in-memory TTL cache, and the only cache-busting command is not exposed in the command palette. The previously refuted commit ff3d578f doesn't exist in either repo's accessible history, so no post-reopen fix can be cited.

## Change summary

A locally created (not yet pushed/merged) custom agent `.md` file doesn't appear in the Cloud Agent dropdown without reloading the window, and there's no indication to the user that this is why.

## Best solution

Add a file watcher for `.github/agents/**/*.md` in copilotCloudSessionsProvider.ts (microsoft/vscode-copilot-chat) that invalidates the existing options cache (`_optionsCache`) and fires `onDidChangeChatSessionProviderOptions` on change, so the already-implemented local-only indicator appears immediately instead of after a window reload.
