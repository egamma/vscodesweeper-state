# Issue #62663 — API should support to create a folder

[https://github.com/microsoft/vscode/issues/62663](https://github.com/microsoft/vscode/issues/62663)

## Summary

The requested atomic, undoable folder creation operation remains absent from the public WorkspaceEdit API. This team-authored Backlog request should stay open.

## Change summary

Add explicit folder creation support to WorkspaceEdit and corresponding LSP resource operations.

## Best solution

Expose a folder-create WorkspaceEdit operation with preview, metadata, and undo support, then coordinate the equivalent LSP resource operation. `workspace.fs.createDirectory` is not a substitute because it cannot participate in an atomic workspace edit.
