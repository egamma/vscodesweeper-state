# Issue #337391 — Figma remote MCP fails with -32601 after updating to VS Code 1.139.0

[https://github.com/microsoft/vscode/issues/337391](https://github.com/microsoft/vscode/issues/337391)

## Summary

This is a credible MCP negotiation regression in the Copilot runtime bundled by Agent Host, not an extension-ownership issue. Current main carries a newer runtime that may include the reported upstream fix, but without an identifiable upstream fixing commit or a current verification, the issue should remain open and be routed to MCP ownership.

## Change summary

Make remote MCP negotiation fall back to the standard initialization flow when `server/discover` returns JSON-RPC `-32601`.

## Best solution

The bundled Copilot runtime should treat `server/discover` method-not-found as a compatibility signal, continue with legacy MCP initialization, and retain a regression test covering a server such as Figma that does not implement discovery. After VS Code adopts a runtime containing that change, verify the remote endpoint before closing.
