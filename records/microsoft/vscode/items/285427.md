Legitimate feature request that passed the community upvote threshold (22 👍) and was promoted to the Backlog. The capability to reference folder-level tasks from workspace-level task definitions in multi-root workspaces does not exist on current main — keeping open as an accepted backlog item.

## Change summary

Allow workspace-level task definitions to reference and invoke folder-level tasks in multi-root workspaces.

## Best solution

Implement a mechanism in the task system (likely in `src/vs/workbench/contrib/tasks/`) to allow `tasks.json` at the workspace level to reference tasks defined in individual folder `.vscode/tasks.json` files, enabling composite workspace tasks that orchestrate folder-level builds.
