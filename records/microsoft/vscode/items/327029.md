# Issue #327029 — Agents window: sessions hang silently mid-turn, no error (subagent deselection stall / unanswered permission prompts)

[https://github.com/microsoft/vscode/issues/327029](https://github.com/microsoft/vscode/issues/327029)

## Summary

Keep open: the September confirmation independently reproduces invisible permission waits in both subagents and parallel top-level calls. Current source contains related routing and lifecycle improvements, but neither a fix covering both signatures nor a canonical owning the full report was established.

## Change summary

Copilot CLI sessions silently stop progressing after subagent deselection or wait indefinitely on permission requests that users cannot see or answer.

## Best solution

Make pending approvals visible and actionable from the parent chat, with an accurate waiting status and explicit handling of abandoned child work. Diagnose the deselection-only stall separately unless evidence establishes the same cause; preserve permission enforcement rather than bypassing it.
