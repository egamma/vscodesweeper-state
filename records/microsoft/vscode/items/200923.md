# Issue #200923 — Don't prompt for user confirmation when workspace typescript.tsserver.nodePath is set to "node"

[https://github.com/microsoft/vscode/issues/200923](https://github.com/microsoft/vscode/issues/200923)

## Summary

Keep open: current source still prompts for a workspace Node installation discovered through the value "node", and the maintainer approved removing that prompt specifically for this value. An open implementation PR already references this issue and should be reviewed rather than starting competing work.

## Change summary

Skip the additional TS Server Node confirmation when the workspace setting is exactly "node", while retaining confirmation for explicit executable paths.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/253264 against the approved literal-"node" scope, including the current js/ts.tsserver.node.path setting and legacy typescript.tsserver.nodePath alias. Preserve workspace-trust gating and confirmation for other configured paths.
