# Issue #337936 — Clicking "disable AI features" on github copilot chat incorrectly does not set "disable AI features" setting to true, causing a soft-lock

[https://github.com/microsoft/vscode/issues/337936](https://github.com/microsoft/vscode/issues/337936)

## Summary

Confirmed in source: DisableAIFeaturesInWorkspaceAction.run() only flips the extension's enablement state and never writes chat.disableAIFeatures, unlike the symmetric Enable action which does — exactly matching the reporter's repro of the setting staying unchecked after disabling.

## Change summary

Clicking "Disable AI Features" (in a workspace) disables the Copilot Chat extension but leaves the chat.disableAIFeatures setting unchecked, confusing users about the actual state and requiring a manual toggle workaround.

## Best solution

In DisableAIFeaturesInWorkspaceAction.run() (src/vs/workbench/contrib/extensions/browser/extensionsActions.ts), also call configurationService.updateValue(ChatAIDisabledSettingId, true, ConfigurationTarget.WORKSPACE) after setEnablement, mirroring EnableAIFeaturesInWorkspaceAction.run()'s symmetric reset to false.
