# Issue #207925 — Git - Can't stage changing in parent repository

[https://github.com/microsoft/vscode/issues/207925](https://github.com/microsoft/vscode/issues/207925)

## Summary

Keep open: individual staging discards the selected SCM repository's context and resolves the file to the innermost repository instead. The source still contains this defect, and the August 2026 confirmation supports continued tracking.

## Change summary

Staging a file tracked by both a parent and nested repository should update the index of the repository whose SCM row was selected.

## Best solution

Make individual SCM staging honor the selected resource's owning repository, so independently tracked nested files can be staged in either index. Preserve URI-only command resolution, mixed-repository selections, and genuine submodule handling.
