## Change summary

Newly opened notebooks and newly inserted Markdown cells sometimes display incomplete or code-cell toolbars until focus changes.

## Best solution

Ensure notebook cell-title actions reflect each cell's type and Markdown edit state on initial rendering and insertion, without requiring a cell or application focus change. Investigate the context-key and toolbar initialization lifecycle using the reporter's restart scenarios before choosing a bounded correction.
