# Issue #314704 — Switching to markdown preview view always open the preview at the top of the file

[https://github.com/microsoft/vscode/issues/314704](https://github.com/microsoft/vscode/issues/314704)

## Summary

Fixed on main: commit 9a6cabf8846 ensures the active editor's scroll position is passed to the preview when toggling, so the preview no longer resets to the top of the file.

## Change summary

Switching from markdown source to preview via Toggle Preview always opened the preview at the top of the file instead of preserving the scroll position.

## Best solution

Keep the shipped fix in commit 9a6cabf8846; no further change needed. The `openDynamicPreview` method now reads the active editor's visible line and passes it as the starting scroll location.
