# Issue #334916 — Claude: skills not found when added after the session starts

[https://github.com/microsoft/vscode/issues/334916](https://github.com/microsoft/vscode/issues/334916)

## Summary

Freshly filed, clearly-described bug in the still-actively-developed Claude customizations/skills feature: a skill added mid-session isn't picked up by either the model or the chat customizations dialog until a new session starts, even though `ClaudeCustomizationWatcher` is supposed to watch `.claude/skills` and trigger a republish.

## Change summary

A skill file added to `.claude/skills/<name>/SKILL.md` after a Claude chat session has started is not surfaced to the model or the chat customizations dialog until a new session is started.

## Best solution

Trace why the mid-session refresh path (ClaudeCustomizationWatcher → onDidCustomizationsChange → AgentSideEffects._publishSessionCustomizations → agent.getChatCustomizations) isn't reaching either the customizations dialog or the model's system-prompt skill list for a newly-added skill directory, and fix the gap (likely in src/vs/platform/agentHost/node/claude/customizations/claudeSessionCustomizationDiscovery.ts or claudeAgentSkillScan.ts, or in how the Claude SDK builds its system prompt once per session).
