# Issue #13516 — Horizontal scrollbar doesn’t shrink after the long line getting shortened

[https://github.com/microsoft/vscode/issues/13516](https://github.com/microsoft/vscode/issues/13516)

## Summary

The gap remains on current main for virtualized documents. This is the oldest canonical report and should remain open rather than being superseded by newer issue https://github.com/microsoft/vscode/issues/169485.

## Change summary

Recalculate the editor's horizontal scroll width after its longest line is shortened or removed.

## Best solution

Implement efficient width invalidation or tracking for shortened lines without measuring every virtualized line or regressing editor performance, and consolidate the additional reproduction and decoration details from https://github.com/microsoft/vscode/issues/169485 here.
