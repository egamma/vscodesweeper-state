# Issue #162743 — Additional actions in Refactor Preview panel

[https://github.com/microsoft/vscode/issues/162743](https://github.com/microsoft/vscode/issues/162743)

## Summary

A real API gap remains: extensions cannot contribute contextual feedback actions to Refactor Preview. The request is already correctly classified and should remain under discussion while the command and UX contract is designed.

## Change summary

Allow extensions to add feedback actions, such as thumbs-up or thumbs-down commands, to the Refactor Preview panel.

## Best solution

Define an extension API that attaches trusted commands or a constrained menu contribution to workspace-edit metadata, then render those actions separately from Apply and Discard in the bulk-edit preview.
