## Summary

Still open — the default git worktree location in dev containers lacks write permission, and the team discussion (chrmarti's comment outlining mounting trade-offs) has not yet reached a resolution. No fix commit found on main.

## Change summary

The default worktree folder path (`/workspaces/<repo>.worktree`) is not writable inside a dev container, causing worktree creation to fail.

## Best solution

The team needs to decide on the right default worktree location strategy for dev containers — chrmarti outlined three options (changing container permissions, mounting the parent folder, or conditionally mounting the worktree folder). This likely needs a coordinated change between the git/worktree isolation logic and the dev containers mount configuration.
