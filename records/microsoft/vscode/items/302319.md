# Issue #302319 — Invalid images from tool result not ignored

[https://github.com/microsoft/vscode/issues/302319](https://github.com/microsoft/vscode/issues/302319)

## Summary

The defect remains on current main: tool-result image parts are accepted solely from their declared MIME type, so malformed WebP bytes are serialized into the next model request instead of being ignored.

## Change summary

Ignore invalid images returned by tools so malformed WebP data cannot cause the model request to fail.

## Best solution

Validate tool-result image bytes before adding them to model context, omit malformed images while preserving the tool's remaining text content, and leave valid image handling unchanged.
