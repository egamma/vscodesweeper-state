# Issue #296038 — When /compact fails for auth token refresh, the error says otherwise.

[https://github.com/microsoft/vscode/issues/296038](https://github.com/microsoft/vscode/issues/296038)

## Summary

Still reproducible from current source: `/compact` discards the underlying 401 failure details and streams a generic Markdown error, bypassing the standard chat retry UI. The accepted `bug` should remain open for a bounded error-propagation fix.

## Change summary

When manual conversation compaction fails because authentication expired, show the relevant request error and normal retry affordance instead of an internal summarization/TSX error.

## Best solution

Preserve the failed summarization response's actionable error information through the manual `/compact` path and return standard chat error details so users receive the same retry experience as other failed chat requests.
