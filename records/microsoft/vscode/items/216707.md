# Issue #216707 — Text highlighting can be problematic when searching with regular expressions

[https://github.com/microsoft/vscode/issues/216707](https://github.com/microsoft/vscode/issues/216707)

## Summary

Keep open and classify as a bug: the current search-result lifecycle can leave previous editor highlights behind when a replacement regex search fails. The newer related report confirms the same symptom, but cannot be the duplicate canonical for this re-reviewed, older issue.

## Change summary

Remove stale editor search highlights after a regex search fails and its results are cleared.

## Best solution

Ensure clearing search results also releases decorations retained from the previous query, including after a regex error before any replacement results arrive. Preserve normal search-on-type transitions and visible regex error reporting.
