# Issue #216707 — Text highlighting can be problematic when searching with regular expressions

[https://github.com/microsoft/vscode/issues/216707](https://github.com/microsoft/vscode/issues/216707)

## Summary

Already triaged feature request in Backlog with area label assigned. The behavior (stale highlights persisting when regex becomes invalid) is a minor polish issue with 0 community upvotes after 2+ years. No fix or duplicate found on main.

## Change summary

When a regex search becomes invalid (e.g. adding `[]`), the previous valid match highlights persist in the editor even after results are cleared.

## Best solution

The find model's `research()` method calls `_decorations.set(findMatches, findScopes)` with the result of `_findMatches` — when the regex is invalid, `model.findMatches()` returns empty results but the decorations from the prior valid search may linger in certain close/clear flows. A fix would ensure decorations are explicitly cleared when the search string produces a regex parse error. Low priority given zero community demand.
