# Issue #310714 — When updating VSC if one window has an ongoing copilot session only that window is re-opened when VSC restarts after update

[https://github.com/microsoft/vscode/issues/310714](https://github.com/microsoft/vscode/issues/310714)

## Summary

Still present on main. The window-state save logic in `windowsStateHandler.ts` only records `openedWindows` when `getWindowCount() > 1` at shutdown time. In the update flow, other windows are closed first (reducing the count), so by the time the last Copilot window closes and `saveWindowsState` fires, only that single window is persisted as `lastActiveWindow`. On restart, only it is restored.

## Change summary

When updating VS Code with multiple windows open and one has a running Copilot session, only the Copilot window is restored after update because other windows were closed before state was saved.

## Best solution

The shutdown/update path in `windowsStateHandler.ts` needs to capture all open window states before any windows are closed for the update, rather than reading them at `onBeforeShutdown` time when the count may already be 1. The fix likely involves snapshotting window state earlier in the update flow, or tracking windows that were closed as part of the update sequence in `lifecycleMainService.ts`.
