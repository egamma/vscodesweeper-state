# Issue #341361 — Git - Show a hint when repositories exist deeper than git.repositoryScanMaxDepth

[https://github.com/microsoft/vscode/issues/341361](https://github.com/microsoft/vscode/issues/341361)

## Summary

Thanks for the well-traced request. Nothing in the git extension warns when the scan stops at git.repositoryScanMaxDepth, so a real discoverability gap remains. Keeping it open for community feedback.

## Change summary

Show a hint in Source Control when Git repositories exist just past git.repositoryScanMaxDepth, instead of only offering Initialize Repository.

## Best solution

During the workspace scan, detect `.git` entries in folders just past the depth limit. Surface a Source Control hint or welcome-view message that points to git.repositoryScanMaxDepth, and stop leading with Initialize Repository in that case.
