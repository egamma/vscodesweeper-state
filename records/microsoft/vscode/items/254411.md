# Issue #254411 — Add setting to show tree view item icons without hover effect in Activity Bar

[https://github.com/microsoft/vscode/issues/254411](https://github.com/microsoft/vscode/issues/254411)

## Summary

Valid feature request with 22 upvotes, promoted to Backlog. No existing general setting covers tree-item inline action visibility — only `workbench.view.alwaysShowHeaderActions` (view header) and `scm.alwaysShowActions` (SCM-specific) exist. A real gap remains for extension-contributed tree views.

## Change summary

Add a setting to make tree view item inline actions (e.g. star, refresh) always visible instead of only on hover.

## Best solution

Introduce a general setting (e.g. `workbench.tree.alwaysShowInlineActions`) that toggles the hover-only CSS for tree item action bars across all tree views, mirroring the pattern already established by `scm.alwaysShowActions` for the SCM tree. Implementation would live in the tree view rendering layer (`src/vs/workbench/browser/parts/views/`) and the base list/tree CSS. Extensions contributing tree views via the API would inherit the behavior automatically.
