# Issue #325653 — Per-agent MCP server scoping via optional "agents" field in mcp.json

[https://github.com/microsoft/vscode/issues/325653](https://github.com/microsoft/vscode/issues/325653)

## Summary

Per-agent MCP process lifecycle scoping remains a distinct capability gap, so keep this request open. The context-cost premise needs qualification: current tool selection already excludes disabled tools, while server autostart is not scoped to the active custom agent.

## Change summary

Allow MCP servers to activate only for specified custom agents and stop after no active session needs them, preserving existing configuration behavior.

## Best solution

Evaluate per-agent server activation separately from existing per-agent tool selection, including shared-server ownership across concurrent sessions and compatibility with global enablement. Decide the configuration contract before adopting an agents field; existing tool filtering and global autostart controls do not supply the requested lifecycle semantics.
