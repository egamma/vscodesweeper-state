# Issue #287311 — chat request fails with `Unexpected token '<', "<!DOCTYPE "... is not valid JSON`

[https://github.com/microsoft/vscode/issues/287311](https://github.com/microsoft/vscode/issues/287311)

## Summary

The service outage was transient, but the accepted product bug remains: current model-metadata handling can expose raw HTML/JSON parsing failures instead of a user-friendly service error. A maintainer explicitly requested better rendering, so a decline close is barred and no fixing commit was found.

## Change summary

Render a clear service-unavailable error instead of exposing `Unexpected token '<'` and related model-resolution failures when Copilot endpoints return HTML during an outage.

## Best solution

Normalize malformed or non-JSON model-service responses into a localized temporary-service error while retaining the response details in logs; model selection should recover normally after the endpoint becomes healthy.
