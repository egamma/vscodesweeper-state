# Issue #307647 — Chat sessions overview shows changes but I cannot "Keep" them

[https://github.com/microsoft/vscode/issues/307647](https://github.com/microsoft/vscode/issues/307647)

## Summary

Keep open: two users confirmed that the sessions overview can retain stale change counts after all edits are kept, including on version 1.133.0. Current source has explicit cache-clearing behavior, but it depends on the Copilot sessions provider publishing an authoritative zero-change summary, so the remaining synchronization failure needs diagnosis.

## Change summary

After chat edits are kept, the sessions overview can continue showing added or removed lines even though the session and affected files no longer offer a Keep action.

## Best solution

Ensure accepting all session edits immediately publishes and propagates an authoritative zero-change state to the sessions overview, clearing both the displayed pill and its persisted optimistic cache. First reproduce against current main and determine whether the stale value originates in the Copilot session model or in the sessions cache refresh path.
