# Issue #236272 — Title bar too big in some screens, does not scale with zoom

[https://github.com/microsoft/vscode/issues/236272](https://github.com/microsoft/vscode/issues/236272)

## Summary

Keep this open as an Electron/XWayland runtime issue: multiple users reported the title bar retaining the startup scale, and a VS Code maintainer identified the runtime boundary. The related native-Wayland request is broader and does not report the same observable symptom, so it does not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

The custom title bar retains an incorrect scale when VS Code runs under XWayland or when display scaling changes, while the workbench can be corrected through zoom or runtime scale options.

## Best solution

Create a minimal Electron Window Controls Overlay reproduction for the stale title-bar scale and file it upstream, then track the Electron fix and its adoption in VS Code. Native Wayland remains a workaround and separately tracked direction, not a substitute for diagnosing the XWayland/Xorg runtime behavior.
