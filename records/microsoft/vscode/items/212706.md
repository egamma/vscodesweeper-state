# Issue #212706 — `vscode.workspace.openNotebookDocument` sporadically fails with `Error: NO notebook document for 'untitled:Untitled-1.ipynb?jupyter-notebook'`

[https://github.com/microsoft/vscode/issues/212706](https://github.com/microsoft/vscode/issues/212706)

## Summary

Keep open: a team member reported a recurring notebook API race, and current main retains the failing create-then-immediate-lookup path with no fixing commit referencing this issue.

## Change summary

Creating an untitled notebook with initial content can return before the extension host has registered the new document, causing `openNotebookDocument` to throw.

## Best solution

Synchronize untitled notebook creation with the extension-host document delta before returning from `workspace.openNotebookDocument`, and add a repeated or timing-controlled API test covering creation with initial content. Investigate the lifecycle ordering alongside https://github.com/microsoft/vscode/issues/230589 without treating its distinct event-ordering symptom as a duplicate.
