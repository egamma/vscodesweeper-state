# Issue #161977 — Merge UI: Cannot click to select removed text field

[https://github.com/microsoft/vscode/issues/161977](https://github.com/microsoft/vscode/issues/161977)

## Summary

Keep open: current source still leaves deletion-alignment view zones without a click-to-focus path. This is accepted, team-authored work, and the older related reports do not track the same observable symptom.

## Change summary

Clicking the empty conflict rectangle representing removed text should select that conflict, as clicking its text-bearing counterpart does.

## Best solution

Make the merge editor's deletion-alignment region reliably activate its associated conflict when clicked, while preserving ordinary text selection, conflict actions, and alignment behavior.
