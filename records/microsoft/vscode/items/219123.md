# Issue #219123 — Cut node fade applies to all inline folders

[https://github.com/microsoft/vscode/issues/219123](https://github.com/microsoft/vscode/issues/219123)

## Summary

The visual defect remains on current main: cutting the final folder in a compact Explorer chain applies opacity to the shared row container, fading every inline folder instead of only the cut segment.

## Change summary

In compact-folder mode, visually fade only the folder that was cut rather than the entire combined Explorer row.

## Best solution

Give each label segment in a compact Explorer row its own cut-state styling while preserving the existing whole-row treatment for ordinary, non-compressed items.
