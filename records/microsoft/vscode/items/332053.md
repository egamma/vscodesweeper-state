# Issue #332053 — Agent Host drops completed Copilot CLI reasoning when delta events are absent

[https://github.com/microsoft/vscode/issues/332053](https://github.com/microsoft/vscode/issues/332053)

## Summary

Confirmed in current source: the live Copilot CLI adapter never surfaces completed reasoning when no delta preceded it, and an open PR (#332054) already targets this exact gap, so the fix should land through that PR rather than being closed here.

## Change summary

Agent Host's live Copilot CLI adapter drops completed reasoning summaries when `assistant.reasoning_delta` events never fired, even though the completed `assistant.reasoning`/`reasoningText` data is available.

## Best solution

Land the fix via the already-open PR https://github.com/microsoft/vscode/pull/332054 (or an equivalent), which should render completed reasoning as a fallback in copilotAgentSession.ts only when no live delta part exists for the current parent/subagent scope.
