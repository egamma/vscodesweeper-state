# Issue #348540 — Chat won't give response

[https://github.com/microsoft/vscode/issues/348540](https://github.com/microsoft/vscode/issues/348540)

## Summary

Keep open: the discussion supplies a confirmed idle-connection reproduction, and current source still permits a silent WebSocket stall to wait indefinitely. This is an actionable Copilot client recovery issue, not grounds for an extension or network-support close.

## Change summary

Copilot requests can remain unanswered after reusing an idle WebSocket, while cancelling and retrying restores responses.

## Best solution

Provide bounded, explicit recovery from silent WebSocket stalls without discarding conversation context or interrupting legitimate long-running responses. Establish the timeout and retry contract before implementation, keeping network configuration and the separately reported HTTP timeout gap outside this initial fix.
