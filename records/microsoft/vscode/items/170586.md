# Issue #170586 — Live Share notebook serializer not being called when opening a notebook file on guest

[https://github.com/microsoft/vscode/issues/170586](https://github.com/microsoft/vscode/issues/170586)

## Summary

Keep open: the discussion confirms the wrong serializer on initial guest connection, and the merged PR adds diagnostics rather than fixing selection. This team-authored report has neither a verified fixing commit nor an open canonical duplicate; current behavior still needs investigation.

## Change summary

Opening a shared notebook on a Live Share guest selects the built-in serializer instead of the shared notebook serializer, blocking co-editing.

## Best solution

Establish the serializer-registration and notebook-type selection order during initial guest connection, then resolve the confirmed ownership boundary between VS Code notebook resolution and Live Share registration. The guest should use the shared serializer on first open without requiring the host to close and reopen the notebook.
