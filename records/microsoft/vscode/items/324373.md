# Issue #324373 — Feedback on how having an AI assistant as a copilot affects my coding

[https://github.com/microsoft/vscode/issues/324373](https://github.com/microsoft/vscode/issues/324373)

## Summary

VS Code already provides global and workspace-level switches for disabling built-in AI features, plus a separate toggle for inline suggestions. This is best handled as a question about the existing controls.

## Change summary

Provide a switch to disable the AI assistant after signing in, particularly when coding suggestions appear slower.

## Best solution

Use `chat.disableAIFeatures` to disable and hide all built-in Copilot features, or run `GitHub Copilot: Toggle (Enable/Disable) Inline Suggestions` when only completions should be paused.
