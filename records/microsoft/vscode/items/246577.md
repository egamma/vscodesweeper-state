# Issue #246577 — Cant open md with Code.exe

[https://github.com/microsoft/vscode/issues/246577](https://github.com/microsoft/vscode/issues/246577)

## Summary

File associations not working in portable mode is by design — portable mode intentionally avoids Windows registry modifications to leave no traces on the machine, which means it cannot register as the default handler for file types.

## Change summary

Opening .md files via Windows file associations does not work when VS Code is in portable mode.

## Best solution

This is an inherent limitation of portable mode — the whole point is to avoid modifying the host system (no registry writes). The user should either use the installed version for file associations, or use drag-and-drop / 'Open with' as workarounds. The codebase explicitly skips registry updates in portable mode (see workspacesHistoryMainService.ts comments: 'Skip in portable mode to avoid leaving traces on the machine').

  > Thanks for the report. This is expected behavior for portable mode — portable mode is specifically designed to avoid leaving any traces on the host system, which means it cannot write to the Windows registry to register file associations. This is an intentional trade-off: if VS Code modified the registry for file associations, it would no longer be truly "portable" (leaving behind registry entries when the folder is moved or deleted).

  > - Use "Open with" from the Windows context menu
  > - If you need file associations, consider using the standard installer version instead of portable mode
