# Issue #309595 — Changes Panel: The left and right arrow buttons in the View All Changes window don't show a hand cursor when hovered over

[https://github.com/microsoft/vscode/issues/309595](https://github.com/microsoft/vscode/issues/309595)

## Summary

Keep open: the modal editor's enabled navigation arrows still lack the pointer-cursor styling applied to text buttons. The maintainer's comment supports addressing this consistency gap; no verified duplicate or fixing commit was found.

## Change summary

Show a hand cursor over enabled Previous and Next arrows in the View All Changes modal.

## Best solution

Make the modal editor's enabled navigation arrows convey clickability consistently with other buttons, while preserving the default cursor and non-interactive behavior at disabled boundaries. Keep this fix bounded rather than requiring a workbench-wide cursor audit.
