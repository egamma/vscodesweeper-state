# Issue #299513 — issue with claude code in github copilot

[https://github.com/microsoft/vscode/issues/299513](https://github.com/microsoft/vscode/issues/299513)

## Summary

Still reproduces on main: `claudeCodeAgent.ts` unconditionally passes `allowDangerouslySkipPermissions: true` to the Claude Agent SDK, and the SDK rejects this flag when the process runs as root — making Claude Code completely unusable in root-user Remote SSH / devcontainer sessions. Routing to the Claude agent area for triage.

## Change summary

Claude Code fails with exit code 1 when VS Code Remote SSH connects as root, because the hardcoded `allowDangerouslySkipPermissions: true` flag is rejected by the Claude Agent SDK under root privileges.

## Best solution

In `extensions/copilot/src/extension/chatSessions/claude/node/claudeCodeAgent.ts`, detect when the extension host is running as root (`process.getuid?.() === 0`) and either omit the `allowDangerouslySkipPermissions` flag or use the SDK's permission-mode API to handle permissions without requiring that flag. The SDK's own security check is legitimate, so the extension needs to work within it rather than always asserting the flag.
