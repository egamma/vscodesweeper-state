# Issue #250444 — Add a custom icon for prompt, chat mode and instruction files

[https://github.com/microsoft/vscode/issues/250444](https://github.com/microsoft/vscode/issues/250444)

## Summary

The requested icons remain missing: the built-in Seti theme recognizes prompt, instruction, and agent files but deliberately renders all of them with the generic Markdown glyph. The new glyphs must first be contributed to the upstream Seti font, so this should remain open as upstream work.

## Change summary

Give prompt, custom-agent/chat-mode, and instruction files distinct icons instead of the shared Markdown file icon.

## Best solution

Add visually distinct prompt, instruction, and agent glyphs and file associations to https://github.com/jesseweed/seti-ui, then regenerate the bundled Seti font and icon-theme JSON in `extensions/theme-seti` using the documented update workflow.

## Vision fit

- **Fit:** aligned
- **Reason:** Distinct file icons improve recognition and consistency for first-class AI customization artifacts without adding new persistent UI.
- **Evidence:** Durable themes: AI-assisted development and Workbench & core UX; the design principle that sameness should signal sameness supports distinguishing files with meaningfully different roles.
