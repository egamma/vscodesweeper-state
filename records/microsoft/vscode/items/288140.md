# Issue #288140 — MCP tools incorrectly marked as "User disabled" when multiple VS Code windows connect to same SSE server

[https://github.com/microsoft/vscode/issues/288140](https://github.com/microsoft/vscode/issues/288140)

## Summary

Keep open: the discussion supplies a concrete tool-count-dependent failure and request-log observations sufficient to retest, including reproduction in a single window. Current source has evolved to include tool-search and grouping paths, but still emits the misleading disabled-by-user error; the original tool omission has not been conclusively reproduced on current main.

## Change summary

Enabled MCP tools disappear from the model's available tool list and subsequent calls incorrectly report that the user disabled them.

## Best solution

Establish where selected tools become unavailable during request assembly, then preserve their discoverability and distinguish grouping-related unavailability from explicit user disablement. Investigate the Copilot tool-selection path rather than assuming competing SSE connections are responsible.
