# Issue #155874 — File Decorations for Search Folders 

[https://github.com/microsoft/vscode/issues/155874](https://github.com/microsoft/vscode/issues/155874)

## Summary

Still unimplemented on main: the FolderMatchRenderer's `setFile` calls (lines 255, 257 in searchResultsView.ts) do not pass `fileDecorations` options, so search-result folders show no decorations. The author's note about needing a design decision for aggregating child decorations remains open.

## Change summary

Show file decorations on folder entries in the search results tree that reflect the decorations of their contained file matches.

## Best solution

Design and implement folder-level decoration aggregation in `FolderMatchRenderer` (src/vs/workbench/contrib/search/browser/searchResultsView.ts). The main challenge is deciding how to merge multiple child decorations into a single folder decoration — the author flagged this as needing discussion. Once resolved, add `fileDecorations: { colors: true, badges: true }` to the `setFile` calls at lines 255/257, but with a custom decoration provider that reflects only visible search-result children rather than all directory contents.
