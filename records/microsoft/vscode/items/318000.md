# Issue #318000 — Improve SKILL metrics for Github Copilot

[https://github.com/microsoft/vscode/issues/318000](https://github.com/microsoft/vscode/issues/318000)

## Summary

This is a valid, still-unimplemented enterprise observability request for Copilot skills. Current OpenTelemetry support exposes skill invocations and model-level token usage, but not enterprise aggregation or token and monetary cost attributed to individual skills, so it should be routed to chat customizations.

## Change summary

Expose enterprise-wide skill usage frequency and average prompt, execution, and monetary costs, optionally broken down by model.

## Best solution

Extend the governed Copilot observability surface with skill-level usage and cost-attribution signals that enterprise collectors can aggregate by skill and model, with explicit semantics for prompt-inclusion versus execution costs.
