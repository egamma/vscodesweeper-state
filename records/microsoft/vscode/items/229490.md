# Issue #229490 — Idea: Indicate if file is opened in tab

[https://github.com/microsoft/vscode/issues/229490](https://github.com/microsoft/vscode/issues/229490)

## Summary

A real gap remains: chat file completions identify only the active file, not every file currently open in an editor. This team-authored feature request should remain open.

## Change summary

Indicate in chat file suggestions whether each matching file is already open in an editor tab.

## Best solution

Enrich file completion labels in `chatInputCompletions.ts` with open-editor state while retaining the existing stronger treatment for the active file.
