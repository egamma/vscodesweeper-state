[https://github.com/microsoft/vscode/issues/229490](https://github.com/microsoft/vscode/issues/229490)

Keep open: chat file suggestions annotate the first history entry as “Active file,” but do not identify other files currently open in tabs. The central request remains uncovered; this is also a team-authored item with no verified fix or qualifying older duplicate.
