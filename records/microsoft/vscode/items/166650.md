# Issue #166650 — CodeLens widgets aren't tappable on mobile devices

[https://github.com/microsoft/vscode/issues/166650](https://github.com/microsoft/vscode/issues/166650)

## Summary

Keep open: current source still disconnects touch activation from the mouse-down event that executes CodeLens commands. The linked implementation PR remains open and should be evaluated rather than starting a competing fix.

## Change summary

Tapping a CodeLens action on a touch device does not execute its command, although mouse activation works.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/166653 against the current editor input pipeline so a CodeLens tap executes its command once without disrupting touch scrolling, selection, or mouse activation.
