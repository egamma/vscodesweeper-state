# Issue #166650 — CodeLens widgets aren't tappable on mobile devices

[https://github.com/microsoft/vscode/issues/166650](https://github.com/microsoft/vscode/issues/166650)

## Summary

Still reproduces on main: CodeLens widgets only listen for `onMouseDown` events, but touch taps go through the gesture system which dispatches via `viewController.dispatchMouse` without triggering the widget click path. The author's open PR #166653 remains unmerged.

## Change summary

CodeLens widgets cannot be activated by touch/tap on mobile or touchscreen devices because gesture events bypass the widget click handler.

## Best solution

Review and land (or close with feedback) the author's open PR https://github.com/microsoft/vscode/pull/166653, which makes the pointer/touch handler emit widget-compatible events on tap. The fix lives in `src/vs/editor/browser/controller/pointerHandler.ts`.
