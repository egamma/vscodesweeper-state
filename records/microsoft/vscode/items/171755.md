# Issue #171755 — Code lens is not accessible via screen reader

[https://github.com/microsoft/vscode/issues/171755](https://github.com/microsoft/vscode/issues/171755)

## Summary

The core accessibility gap remains: no audio signal when landing on a line with code lenses, and no next/prev code lens navigation. The existing 'Show CodeLens Commands for Current Line' command helps but doesn't address discoverability for screen reader users.

## Change summary

Code lenses are not announced or navigable via screen reader — users have no non-visual indication that a line has lenses, and no keyboard-only way to jump between them.

## Best solution

Add an accessibility signal (audio cue) when the cursor lands on a line with code lenses, and add next/previous code lens navigation commands. The signal registration belongs in the accessibility signal infrastructure and the navigation in `src/vs/editor/contrib/codelens/browser/codelensController.ts`.
