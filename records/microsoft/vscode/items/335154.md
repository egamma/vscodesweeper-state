# Issue #335154 — References can cut off file extension

[https://github.com/microsoft/vscode/issues/335154](https://github.com/microsoft/vscode/issues/335154)

## Summary

The current Agents Window composer still end-truncates reference pills, so a long filename can lose its identifying extension. This is a bounded visual-polish issue in the Sessions attachment surface and should remain open.

## Change summary

Keep compound file extensions such as `.json.gz` visible when a reference pill must truncate a long filename.

## Best solution

References in the new-session composer should retain the meaningful filename suffix while fitting within the existing compact pill width; other attachment types and the pill layout should remain unchanged.
