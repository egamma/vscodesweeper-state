# Issue #332518 — Power-save blocker does not cover custom LanguageModelChatProvider models

[https://github.com/microsoft/vscode/issues/332518](https://github.com/microsoft/vscode/issues/332518)

## Summary

Traced and confirmed: the power-save blocker is acquired only inside ChatMLFetcher.fetch (extensions/copilot/src/extension/prompt/node/chatMLFetcher.ts), so third-party LanguageModelChatProvider requests and inter-request tool/build activity aren't covered — but an open PR already targets this exact gap, so this should stay open pending that PR rather than be treated as a fresh fix target.

## Change summary

The sleep-prevention power-save blocker added for #276546 only wraps Copilot's own ChatMLFetcher request path, so Agent sessions using third-party model providers (or long tool/build calls between requests) don't keep the system awake.

## Best solution

Land/refine https://github.com/microsoft/vscode/pull/332534 ("Chat: Prevent sleep during agent requests"), which appears to move or extend the power-save blocker to the Agent/session execution lifecycle so it's provider-independent; this issue should close once that PR merges and covers the described gap.
