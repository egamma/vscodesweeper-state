# Issue #344705 — Agents window: show a session's pull request changes in the Changes view

[https://github.com/microsoft/vscode/issues/344705](https://github.com/microsoft/vscode/issues/344705)

## Summary

Current main already provides an Open Pull Request Changes action on PR dropdown entries, but it opens a separate multi-file diff rather than adding PR scopes to the Changes picker. Keep this request open for that remaining integration; the related issues inspected do not own the same capability.

## Change summary

Expose each associated pull request as a selectable Changes scope and provide a matching shortcut from its PR dropdown entry.

## Best solution

Allow associated PR diffs to be reviewed alongside existing session and turn scopes in Changes, reusing the existing PR identity and diff-loading infrastructure. Treat contributable menus and extension APIs as a separate optional design decision rather than a prerequisite.
