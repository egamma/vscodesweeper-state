# Issue #234812 — Don't import XYZ.contribution-files from non contribution/entry-files

[https://github.com/microsoft/vscode/issues/234812](https://github.com/microsoft/vscode/issues/234812)

## Summary

The requested lint boundary remains unenforced: ordinary modules still import contribution files that export registration results. Keep this engineering debt open; the existing consumers make rollout a planning task rather than an isolated rule addition.

## Change summary

Enforce that contribution files export nothing and are imported only by contribution or entry files.

## Best solution

Establish lint enforcement for contribution-module isolation while preserving intentional entry-point registration. Inventory existing violations and plan their migration so enforcement does not disrupt editor or workbench initialization.
