# Issue #257270 — Settings UI eats escape, preventing hiding of notifications

[https://github.com/microsoft/vscode/issues/257270](https://github.com/microsoft/vscode/issues/257270)

## Summary

The Settings search still claims Escape when its input is empty, preventing dismissal of an unfocused notification toast. Keep this open while the explicitly linked fixing PR is reviewed.

## Change summary

Allow Escape to dismiss notification toasts when the focused Settings search has no query to clear.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/318074 if its behavior is correct: empty Settings search should leave Escape available to notification dismissal, while a nonempty search should retain its clear-query behavior.
