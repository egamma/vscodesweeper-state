# Issue #338965 — Emojis disappear from unselected in-progress session titles

[https://github.com/microsoft/vscode/issues/338965](https://github.com/microsoft/vscode/issues/338965)

## Summary

Confirmed via source: the unselected in-progress title shimmer in sessionsList.css clips `.session-title` text with `-webkit-text-fill-color: transparent`, which also makes color emoji glyphs disappear; selecting the row removes the clipping class and restores them. This is a real, bounded rendering bug worth fixing.

## Change summary

Emoji in an in-progress Agents window session title vanish while the row is unselected (shimmer effect clips text color), and reappear on selection.

## Best solution

Keep the real title text as a solid base layer and move the clipped-gradient shimmer onto a separate aria-hidden overlay/clone, as the reporter's suggested fix outlines, so color emoji always render; add a component-fixture regression covering selected/unselected + reduced-motion states.
