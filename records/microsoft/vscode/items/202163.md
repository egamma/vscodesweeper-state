# Issue #202163 — `languages.match` doesn't work for notebook cell documents in document close events

[https://github.com/microsoft/vscode/issues/202163](https://github.com/microsoft/vscode/issues/202163)

## Summary

The notebook-cell close-event defect remains in current source: languages.match discovers notebook membership only through live notebooks and cells, which are removed before the text-document close callback. Keep this team-authored API bug open; the related trust-transition issue does not establish a fix for this lifecycle.

## Change summary

Preserve notebook-aware document-selector matching for notebook cell documents during text-document close events.

## Best solution

Notebook-qualified selectors should retain enough notebook context to match the closing cell during its close callback, without exposing closed notebooks or deleted cells in the live workspace collections or changing event ordering.

## Evidence

- **Current matching path:** src/vs/workbench/api/common/extHost.api.impl.ts:670-676 implements languages.match by searching extHostNotebook.notebookDocuments and each notebook's current getCells() for the TextDocument object. It passes undefined notebook context to score when that search fails; src/vs/editor/common/languageSelector.ts:98-105 then returns 0 for a notebookType-qualified selector.
- **Notebook closure reproduces the defect in source:** src/vs/workbench/api/common/extHostNotebook.ts:615-624 deletes the notebook from _documents before forwarding removal of its cell text documents. ExtHostDocumentsAndEditors.acceptDocumentsAndEditorsDelta deletes and disposes those documents before firing onDidRemoveDocuments, and src/vs/workbench/api/common/extHostDocuments.ts:42-45 forwards the close callback. Calling languages.match there cannot find the removed notebook.
- **Cell deletion has the same lifecycle gap:** src/vs/workbench/api/common/extHostNotebookDocument.ts:357-389 removes deleted cells from _cells before forwarding removedDocuments. Therefore the live-cell search also loses notebook membership when an individual cell closes through deletion.
