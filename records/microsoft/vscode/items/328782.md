# Issue #328782 — Pick up on manually spoken punctuation

[https://github.com/microsoft/vscode/issues/328782](https://github.com/microsoft/vscode/issues/328782)

## Summary

Team-authored feature request from active dictation work; already correctly labeled feature-request/dictation, so it just needs product/engineering follow-up on the ASR/cleanup pipeline — no reason to close.

## Change summary

Requests that dictation recognize manually spoken punctuation keywords (e.g. 'question mark', 'period', 'exclamation mark') the way other dictation systems do, rather than only inferring punctuation from pauses/inflection.

## Best solution

Extend the dictation pipeline (chatSpeechToTextService.ts / dictationSession.ts, and the experimental LLM cleanup prompt in createDictationCleanupSystemPrompt) to recognize spoken punctuation command words either at the ASR layer or as an explicit substitution pass before/alongside the existing filler-stripping and LLM cleanup steps.
