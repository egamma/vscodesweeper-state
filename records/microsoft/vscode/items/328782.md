# Issue #328782 — Pick up on manually spoken punctuation

[https://github.com/microsoft/vscode/issues/328782](https://github.com/microsoft/vscode/issues/328782)

## Summary

Keep open: current dictation supports automatic punctuation cleanup, but explicit spoken punctuation commands are not established as supported. This team-authored request remains distinct from the older report about punctuation inserted during pauses.

## Change summary

Recognize dictated punctuation names such as “question mark,” “exclamation mark,” “bang,” and “period” as punctuation commands.

## Best solution

Define and support spoken punctuation commands in built-in dictation, distinguishing commands from literal mentions of punctuation names. Establish the behavior across available transcription backends and when language-model cleanup is unavailable.
