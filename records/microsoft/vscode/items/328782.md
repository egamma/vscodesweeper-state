# Issue #328782 — Pick up on manually spoken punctuation

[https://github.com/microsoft/vscode/issues/328782](https://github.com/microsoft/vscode/issues/328782)

## Summary

Keep open: current dictation cleanup restores inferred punctuation but does not explicitly support spoken punctuation commands. The older related reports cover automatic sentence formatting, not this same observable request, and no verified fix or canonical duplicate was found.

## Change summary

Recognize spoken punctuation names such as question mark, exclamation mark, bang, and period as punctuation when used as dictation commands.

## Best solution

Define spoken-punctuation semantics for built-in dictation, including how command usage differs from literal mentions, then validate the resulting transcript behavior. The existing transcript-finalization and cleanup pipeline is the relevant starting point; automatic punctuation alone does not satisfy this request.
