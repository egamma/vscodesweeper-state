# Issue #199765 — Font weight incorrectly applied using Iosevka font

[https://github.com/microsoft/vscode/issues/199765](https://github.com/microsoft/vscode/issues/199765)

## Summary

VS Code already ships the `editor.fontVariations` setting (default: false) that, when set to `true`, translates `editor.fontWeight` into the CSS `font-variation-settings: 'wght' N` property — the correct mechanism for variable fonts like Iosevka. Without it, the browser/Electron rasterizer rounds weights to platform-mapped values. This is as-designed: the opt-in control exists.

## Change summary

Numeric font-weight values do not render correctly for variable fonts (Iosevka) without also enabling `editor.fontVariations`.

## Best solution

Close as *as-designed. The `editor.fontVariations: true` setting already delivers the requested behavior by translating font-weight into `font-variation-settings: 'wght' N`. The default is intentionally `false` because not all fonts are variable.

  > ```
