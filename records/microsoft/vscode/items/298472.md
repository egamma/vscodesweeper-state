# Issue #298472 — PreToolUse 'continue' blocks tool but doesn't terminate loop

[https://github.com/microsoft/vscode/issues/298472](https://github.com/microsoft/vscode/issues/298472)

## Summary

Team-authored bug, still present on main. The PreToolUse hook's `continue: false` maps to a `deny` permissionDecision that blocks the tool call but does not signal the agentic loop to terminate — the loop keeps running despite the hook's intent to stop processing.

## Change summary

When a PreToolUse hook returns `continue: false` with a `stopReason`, the tool is blocked but the agent loop continues instead of terminating immediately.

## Best solution

Propagate the hook's stop signal from `_handlePreToolUseDenial` back to the agentic loop so it terminates. The `IToolResult` returned by `_handlePreToolUseDenial` (in `src/vs/workbench/contrib/chat/browser/tools/languageModelToolsService.ts`) needs a mechanism — e.g. a `shouldStopLoop` flag or a specific error kind — that the caller in the agent loop checks to break out. The `IChatHookPart.stopReason` already models this on the rendering side but is not wired into loop control.
