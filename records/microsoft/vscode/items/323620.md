# Issue #323620 — Autopilot/Bypass silently skips user-requested high-risk actions with no opt-out

[https://github.com/microsoft/vscode/issues/323620](https://github.com/microsoft/vscode/issues/323620)

## Summary

Current main still deliberately hard-skips red-rated tool calls in local Advanced Autopilot sessions, with no confirmation fallback and independently of the visible risk-assessment setting. Plain Bypass Approvals now avoids this gate, but the Autopilot behavior and its public contract remain an open chat-tools product decision.

## Change summary

Provide a supported way to proceed when Autopilot classifies an explicitly requested destructive tool call as high risk, or clearly document that such calls are non-bypassable.

## Best solution

Have the chat-tools owners define one consistent contract for red-rated actions in Advanced Autopilot: either offer an explicit one-time confirmation, expose a deliberate override, or document the hard stop and its difference from Bypass Approvals. The implementation and permissions UI should then enforce and describe that decision consistently.
