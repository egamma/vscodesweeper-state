# Issue #242156 — Add basic toml support

[https://github.com/microsoft/vscode/issues/242156](https://github.com/microsoft/vscode/issues/242156)

## Summary

Keep open for a maintainer product decision: current main still lacks built-in TOML highlighting, and this canonical request earned 59 upvotes and promotion to the Backlog. It asks to reconsider an established extension-first decision rather than duplicating existing work.

## Change summary

Provide basic TOML syntax highlighting and language configuration out of the box, particularly where third-party extensions cannot be installed.

## Best solution

The languages-basic maintainers should explicitly decide whether TOML's increased use and the lack of a verified extension justify revisiting the 2018 extension-first policy. If accepted, the end state would be a minimal maintained TOML language contribution covering file association, highlighting, and basic editing behavior without bundling an LSP.
