# Issue #241638 — Inconsistent Debug Console Hover Styling: list.hoverBackground Applies, but list.hoverForeground Does Not

[https://github.com/microsoft/vscode/issues/241638](https://github.com/microsoft/vscode/issues/241638)

## Summary

The styling inconsistency remains source-reproducible on current main: the list row receives `list.hoverForeground`, but Debug Console child elements retain their directly assigned foreground colors. This is a bounded Debug Console theming bug and should remain open.

## Change summary

Make Debug Console rows honor `list.hoverForeground` when hovered, including message severity text and source links.

## Best solution

Make Debug Console message and source elements inherit the list hover foreground while a non-selected row is hovered, without changing their normal severity colors or focused-selection styling.
