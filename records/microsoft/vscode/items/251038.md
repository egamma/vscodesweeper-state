# Issue #251038 — Feature Idea: Source Control like the Jetbrains IDE's

[https://github.com/microsoft/vscode/issues/251038](https://github.com/microsoft/vscode/issues/251038)

## Summary

Keep this accepted Backlog request open. Current VS Code provides several requested capabilities, but the broader unified, provider-neutral source-control workflow remains only partially covered, with no verified canonical issue owning the full scope.

## Change summary

Provide a more cohesive built-in source-control experience spanning repository navigation, hosting authentication, cloning, synchronization, conflict resolution, blame, and history.

## Best solution

Define the remaining provider-neutral SCM integration work as focused Git/SCM improvements, while leaving hosting-provider authentication and specialized workflows to provider extensions. Existing history, repositories, merge-editor, clone, synchronization, and blame capabilities should form the unified foundation rather than being duplicated.
