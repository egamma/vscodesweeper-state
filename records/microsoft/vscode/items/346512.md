# Issue #346512 — Markdown Editor does not support Ctrl+Insert / Shift+Insert for copy/paste

[https://github.com/microsoft/vscode/issues/346512](https://github.com/microsoft/vscode/issues/346512)

## Summary

Keep open: the standard Windows text editor already registers these shortcuts, but the Markdown Editor uses a separate keyboard and clipboard implementation. Those existing registrations do not establish that the requested Markdown Editor behavior is covered.

## Change summary

Support Ctrl+Insert for copying and Shift+Insert for pasting in the Markdown Editor on Windows.

## Best solution

Make the Markdown Editor honor the same Windows clipboard shortcuts as the text editor, preserving its existing selection and paste behavior. First establish whether the missing handling is in the webview integration or its imported keyboard profiles.
