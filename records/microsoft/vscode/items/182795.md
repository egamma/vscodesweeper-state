# Issue #182795 — Simple browser will be opened multiple times with race

[https://github.com/microsoft/vscode/issues/182795](https://github.com/microsoft/vscode/issues/182795)

## Summary

The race condition between show() and restore() in SimpleBrowserManager is still present on current main — no fix has merged despite multiple PR attempts. Keeping open as a valid, labeled help-wanted bug.

## Change summary

Simple Browser can open duplicate panels when a command triggers show() before the webview serializer's restore() has run during window reload.

## Best solution

Add a pending/deferred pattern in SimpleBrowserManager so that show() awaits any in-flight restore before deciding to create a new view. The fix is small and localized to extensions/simple-browser/src/simpleBrowserManager.ts. One of the open PRs (https://github.com/microsoft/vscode/pull/324379 or https://github.com/microsoft/vscode/pull/285633) should be reviewed and landed.
