# Issue #332169 — Model description (vision, thinking, etc)  disappears if more than 2 "other" providers are added.

[https://github.com/microsoft/vscode/issues/332169](https://github.com/microsoft/vscode/issues/332169)

## Summary

Traced this on main: the model picker's 'Other Models' section deliberately blanks the per-model `description` (from `model.metadata.detail`) whenever more than one vendor group is shown, to avoid repeating the vendor name — but this same code path also wipes out provider-supplied capability text (e.g. 'vision, thinking') that has nothing to do with the vendor name, which is exactly what the reporter observes with 3+ providers.

## Change summary

Model capability descriptions (vision, thinking, etc.) for third-party providers vanish from the model picker's 'Other Models' list once more than one non-featured vendor group is present.

## Best solution

In modelPickerItemPrimitives.ts (`createModelAction`) and modelPickerItemSections.ts (`appendOtherModels`), stop suppressing the whole `detail` string whenever group headers are shown; only drop it when it is redundant with the group/vendor label already shown in the header, so provider-supplied capability text survives.
