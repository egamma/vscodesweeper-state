# Issue #314224 — ChatDebugFileLogger fails on Windows: EINVAL mkdir for path with trailing ':' (copilotcli:)

[https://github.com/microsoft/vscode/issues/314224](https://github.com/microsoft/vscode/issues/314224)

## Summary

Still reproduces on main: sessionId values containing Windows-reserved characters (like `copilotcli:`) are used unsanitized as directory names in `_ensureSession`, causing `mkdir` to fail with EINVAL on Windows. The child label IS sanitized (line 334) but the parent sessionId path segment (line 359) is not.

## Change summary

ChatDebugFileLogger fails to create debug log directories on Windows when the session identifier contains a colon.

## Best solution

Sanitize `sessionId` the same way child labels are sanitized (stripping `[/\:*?"<>|\x00-\x1f]`) before using it as a path segment in `_ensureSession`, `_resolveHistoricalSessionDir`, and `_resolveParentSessionDir` in `extensions/copilot/src/extension/chat/vscode-node/chatDebugFileLoggerService.ts`. A helper like `sanitizePathSegment(id)` applied consistently at every `URI.joinPath(dir, sessionId)` call site would prevent the class of bug.
