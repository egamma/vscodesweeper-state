## Summary

Keep open: the logger still uses session identifiers directly in directory paths, so the reported `copilotcli:` input produces an invalid Windows directory name. The related report was closed as a duplicate of this issue, not as evidence of a fix.

## Change summary

Ensure chat debug logging can write session logs on Windows when a session identifier contains a colon.
