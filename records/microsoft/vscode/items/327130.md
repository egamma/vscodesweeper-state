# Issue #327130 — gen_ai.agent.name never reflects the active custom agent for top-level (non-subagent) sessions

[https://github.com/microsoft/vscode/issues/327130](https://github.com/microsoft/vscode/issues/327130)

## Summary

The requested identity is still absent from the standard foreground agent-name fields. Current source deliberately separates custom-mode names from metric identity to limit cardinality, so this needs an OTel contract decision rather than a straightforward missing-wire fix.

## Change summary

Expose the directly selected custom agent's name in foreground invoke_agent spans, session-start events, and agent metrics.

## Best solution

Define a consistent foreground custom-agent identity contract in the local Copilot Chat OTel pipeline, explicitly resolving the existing metric-cardinality tradeoff. Document which fields identify the participant versus the selected persona, and ensure exported signals follow that contract.
