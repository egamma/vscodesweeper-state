# Issue #145672 — QuickInput error aligns weirdly

[https://github.com/microsoft/vscode/issues/145672](https://github.com/microsoft/vscode/issues/145672)

## Summary

Keep open for a focused design decision: current QuickInput still replaces the prompt with validation text, and the maintainer discussion explicitly asks for less disruptive placement. Existing area labels are appropriate; no verified canonical issue covers the same presentation problem.

## Change summary

Make QuickInput validation messages feel integrated with the picker and avoid obscuring the instructions needed to correct invalid input.

## Best solution

Agree on a shared QuickInput validation presentation that keeps instructions available, supports multiline errors, and avoids disruptive layout changes. Implement the chosen interaction in the platform quickinput UI rather than adding a per-consumer workaround.
