# Issue #239671 — `Content-Type: application/json` caused the lint error for ```sh ``` block for markdown(.md) file

[https://github.com/microsoft/vscode/issues/239671](https://github.com/microsoft/vscode/issues/239671)

## Summary

Still reproduces on current main — the bundled shell TextMate grammar (from jeff-hykin/better-shell-syntax) mis-tokenizes shell code after a `Content-Type: application/json` header in a curl command, causing broken syntax highlighting for subsequent lines. No grammar update has addressed this pattern. Keeping open as a valid grammar bug.

## Change summary

Shell syntax highlighting in markdown fenced code blocks breaks after a curl `-H "Content-Type: application/json"` line, causing incorrect tokenization of subsequent commands.

## Best solution

Fix the tokenization in the upstream shell grammar (jeff-hykin/better-shell-syntax) or patch the vendored grammar in `extensions/shellscript/syntaxes/shell-unix-bash.tmLanguage.json`. The `application/json` inside the double-quoted string likely triggers a scope that doesn't close properly, affecting subsequent lines.
