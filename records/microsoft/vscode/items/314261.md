# Issue #314261 — Invalid directories in the workspace picker

[https://github.com/microsoft/vscode/issues/314261](https://github.com/microsoft/vscode/issues/314261)

## Summary

Keep open: current main removes a missing local workspace only after it is selected, but the picker still presents that stale entry as valid beforehand. This team-authored Backlog item describes a remaining, source-confirmed workspace-picker papercut.

## Change summary

Show an accessible warning on recent local workspace entries whose directories no longer exist, so users can identify and remove them before selection.

## Best solution

Mark unavailable local recent workspaces in the Agents Window picker before selection, with an accessible warning and explanation, while preserving the existing removal action and leaving valid, remote, and virtual workspaces unchanged.
