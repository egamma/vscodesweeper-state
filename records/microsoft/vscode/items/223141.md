# Issue #223141 — lessen extension activation from debugging

[https://github.com/microsoft/vscode/issues/223141](https://github.com/microsoft/vscode/issues/223141)

## Summary

Keep open: current task lookup still activates all task-provider types when an extension-provided task label is absent from workspace configuration. The configured-task fast path does not cover this maintainer-supported optimization, and no verified canonical or explicitly linked fixing commit establishes completion.

## Change summary

Reduce unrelated extension activation when debugging references an extension-provided task that is not configured in tasks.json.

## Best solution

Make repeated lookup of known extension-provided task labels avoid unnecessary provider activation while preserving task discovery and existing task-selection semantics. Establish the correctness and validation contract for provider hints before implementing the optimization in the task service.

- **Trace:**
