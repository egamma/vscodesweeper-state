# Issue #292154 — switchAgent tool is pretty frustrating with 5.2 codex

[https://github.com/microsoft/vscode/issues/292154](https://github.com/microsoft/vscode/issues/292154)

## Summary

The switchAgent tool is reported to be invoked inappropriately/repeatedly by the Codex 5.2 model. The tool is still experimental (behind a flag) and has received description improvements, but no targeted fix for the repeated-invocation frustration is evident on main.

## Change summary

The switchAgent tool fires too eagerly or repeatedly with the Codex 5.2 model, frustrating users who didn't intend to switch agents.

## Best solution

Improve the model description guardrails or add invocation-limiting logic (e.g., don't offer switchAgent after files have already been edited in the session, or after it was already called once). The tool lives in `extensions/copilot/src/extension/tools/vscode-node/switchAgentTool.ts` with its description in `extensions/copilot/package.json`.
