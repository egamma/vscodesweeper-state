# Issue #317554 — VS Code Installing Alpine Server on RHEL and Ubuntu

[https://github.com/microsoft/vscode/issues/317554](https://github.com/microsoft/vscode/issues/317554)

## Summary

The logs confirm that Remote-SSH selects the Alpine/musl server for Ubuntu and RHEL hosts. This belongs in the VS Code-team-owned Remote Development tracker, where the same underlying detection defect is already being investigated.

## Change summary

Remote-SSH incorrectly downloads the Alpine server binary for glibc-based Ubuntu and RHEL hosts, preventing remote connections.
