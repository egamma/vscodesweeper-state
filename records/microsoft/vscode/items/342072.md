# Issue #342072 — BYOK requests ignore per-chat reasoning effort and use the shared model setting

[https://github.com/microsoft/vscode/issues/342072](https://github.com/microsoft/vscode/issues/342072)

## Summary

The current source still drops per-chat reasoning effort before the BYOK provider request, allowing the shared model configuration to take effect. Keep this open while the linked implementation PR is reviewed and landed.

## Change summary

Preserve each chat's selected reasoning effort when sending requests to a BYOK model shared by multiple chats.

## Best solution

BYOK requests should honor the originating chat's explicit reasoning effort while retaining shared model defaults when no per-chat override exists. Review the implementation candidate at https://github.com/microsoft/vscode/pull/342080 against the two-chat Low/High reproduction before closing this issue.
