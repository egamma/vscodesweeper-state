# Issue #331608 — Agent Host: Click to open doesn't work for skills used as slash commands in message being edited

[https://github.com/microsoft/vscode/issues/331608](https://github.com/microsoft/vscode/issues/331608)

## Summary

The defect remains visible in current source: editing restores Agent Host skills as dynamic variables, but the input decoration's click path only opens separately resolved prompt slash commands. The issue is team-authored and describes a bounded, actionable Agent Host UI bug, so it should remain open.

## Change summary

Skills inserted as slash commands cannot open their SKILL.md resource when a previously sent chat request is edited.

## Best solution

Preserve the restored Agent Host skill's resource as an actionable editor target while editing a request, so its displayed click affordance opens the same SKILL.md URI carried by the original completion.
