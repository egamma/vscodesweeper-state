# Issue #335773 — Agents window PR form: Expect link to PR to be provided

[https://github.com/microsoft/vscode/issues/335773](https://github.com/microsoft/vscode/issues/335773)

## Summary

Team-authored bug report about the Agents Window PR creation flow lacking an in-product link/notice after a PR is created; the reporter found the link only via hovering the session in the list. No fix is visible on main, and this is a UX gap worth addressing rather than closing.

## Change summary

After using Create PR in the Agents Window, no link to the newly created PR is surfaced in the chat output or header area — it's only discoverable by hovering the session in the session list.

## Best solution

Surface the PR link directly where the reporter expects it — either as a chat message from the agent after creation or in the header alongside the Mark Ready / Merge controls — likely touching src/vs/sessions/contrib/changes/browser/createPullRequestWidget.ts, createPullRequestChatRequest.ts, or the github contrib area (pullRequestHover.ts / pullRequestIconStatus.ts) where PR state is already surfaced in the UI.
