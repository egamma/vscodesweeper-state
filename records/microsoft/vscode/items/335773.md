# Issue #335773 — Agents window PR form: Expect link to PR to be provided

[https://github.com/microsoft/vscode/issues/335773](https://github.com/microsoft/vscode/issues/335773)

## Summary

The original core ask (surface a link to the created PR) was fixed by https://github.com/microsoft/vscode/pull/335729 — current main's agentHostSessionInputPills.ts shows a Pull Request pill above the chat input with hover details, which vritant24 confirmed. But the issue was reopened because a maintainer (vritant24) found the pill too easy to miss and wants a more visible chat-view notification; that remains unimplemented, so this stays open as a real, team-acknowledged follow-up rather than a complete fix.

## Change summary

Agents window PR creation should surface an in-product link/notice to the newly created PR, not just a hover-only pointer.

## Best solution

Add a more visible acknowledgement when a PR is created — e.g. a chat-view message or the existing promotion/notification surface vritant24 mentions — since the pill above the input is easily missed; a maintainer should pick the surface (chat message vs. notification vs. 'mark as done'-style banner).
