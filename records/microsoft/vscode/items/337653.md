[https://github.com/microsoft/vscode/issues/337653](https://github.com/microsoft/vscode/issues/337653)

## Summary

This matches a startup-race risk the team has already identified and documented in an in-repo design plan for the Claude native model catalogue, so it's a real, known bug — not yet fixed on main — and should stay open while that work lands.

## Change summary

After restart, the Claude agent host model picker shows the first native model (Fable) instead of the saved selection (Opus), even though turns still route correctly to Opus.

## Best solution

Land the native-model restoration fix already scoped in the team's own phase19 plan (risk R4) so the picker label reconciles with the saved model id once the async native catalogue arrives, instead of degrading to models[0].
