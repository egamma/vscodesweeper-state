## Summary

Keep open: independent reports confirm incorrect restored selection, occasional execution on the fallback model, and misleading historical model attribution. Current source contains restoration safeguards, but a complete fix for these reported outcomes has not been established.

## Change summary

Preserve the selected Claude model across restart and accurately identify the model that executed each turn.

## Best solution

Ensure restored Claude conversations retain their authoritative model while discovery completes, without persisting a temporary picker fallback. Historical model indicators and usage records should reflect each turn's executed model rather than the current selection.
