# Issue #316977 — Mermaid block flickers when opening markdown file

[https://github.com/microsoft/vscode/issues/316977](https://github.com/microsoft/vscode/issues/316977)

## Summary

Team-authored visual bug about Mermaid blocks briefly rendering as raw text before the diagram loads when opening a markdown file. No fix commit references this issue, and the related streaming-flicker issue #319248 is also still open. Keeping open.

## Change summary

Mermaid fenced code blocks in markdown files briefly render as plain text before the diagram replaces them, causing a visible flicker on file open.

## Best solution

The mermaid-markdown-features extension's markdown preview integration should hide or placeholder the mermaid block content until the diagram renderer is ready, avoiding the text-then-diagram flash. The fix likely lives in `extensions/mermaid-markdown-features/preview-src/markdown/index.ts` or the shared `diagramManager.ts`. The related issue https://github.com/microsoft/vscode/issues/319248 (streaming re-render flicker) may share root cause and could be addressed together.
