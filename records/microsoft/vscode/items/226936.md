# Issue #226936 — CodeLens - Actual Command Not Found Error

[https://github.com/microsoft/vscode/issues/226936](https://github.com/microsoft/vscode/issues/226936)

## Summary

Still reproduces on main — the race condition between onDidChangeCodeLenses refreshing widgets and resolveCodeLens completing is unguarded; clicking during the resolve window yields 'command not found'. Confirmed active by a team member (hediet) in Aug 2025.

## Change summary

Clicking a CodeLens during the resolve window after onDidChangeCodeLenses fires produces an 'Actual command not found' error because the widget's command map is cleared before resolution completes.

## Best solution

Guard the click handler in codelensController.ts (line ~273) to either retain the previous command until the new resolve completes, or suppress the error and retry/resolve on demand when the command is missing. The fix is localized to the resolve-click interaction in codelensController.ts and codelensWidget.ts.
