# Issue #329339 — Commit generation personalized instruction doesn't work

[https://github.com/microsoft/vscode/issues/329339](https://github.com/microsoft/vscode/issues/329339)

## Summary

This is the same failure already tracked (and actively reconfirmed) in the open issue #316002: setting any non-empty `commitMessageGeneration.instructions` entry causes commit message generation to silently fail with a 422 Unprocessable Entity / promptFiltered response — proposing a duplicate close to consolidate the discussion.

## Change summary

Setting a personalized commit-message-generation instruction (e.g. "Use Conventional Commits.") causes commit message generation to fail with an unprocessable-entity error that doesn't occur when the instruction is absent.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316002 — despite its title mentioning Japanese text, commenters there (including on VS Code 1.130.0/1.131.0, close to this report's 1.132.0) reproduced the identical 422/promptFiltered failure with plain English and Chinese instructions too, so it already tracks the general root cause: any non-empty `commitMessageGeneration.instructions` value trips a prompt-filter/validation failure server-side for the commit-message endpoint.
