[https://github.com/microsoft/vscode/issues/297353](https://github.com/microsoft/vscode/issues/297353)

## Summary

Model-specific commit attribution remains missing: current main still appends a fixed Copilot trailer. Keep this team-authored request open; the later attribution discussion explicitly identifies it as the tracking issue for model information.

## Change summary

Include the model used for AI-generated edits in commit attribution rather than identifying only Copilot.

## Best solution

Provide accurate model-specific attribution for committed AI edits, coordinated with the attribution-format discussion at https://github.com/microsoft/vscode/issues/313962. Settle the public trailer format and mixed-model semantics before implementation, while preserving existing attribution opt-out behavior.
