# Issue #347196 — Add a keyboard shortcut

[https://github.com/microsoft/vscode/issues/347196](https://github.com/microsoft/vscode/issues/347196)

## Summary

Keep open: quoting selected response text already exists, but the current implementation does not expose it as a keyboard-bindable command. Related requests address quotation affordances rather than this specific keyboard-access gap.

## Change summary

Expose Quote in Chat as a command that users can assign a keyboard shortcut in the Agents Window.

## Best solution

Provide a keyboard-bindable command that appends the selected assistant-response text to the originating conversation's draft, preserving the existing Quote behavior and read-only restrictions.
