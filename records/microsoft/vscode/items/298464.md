# Issue #298464 — Support adding hyphen and underscore when applying the kekab-case and snake_case actions

[https://github.com/microsoft/vscode/issues/298464](https://github.com/microsoft/vscode/issues/298464)

## Summary

Valid feature request: the Snake Case and Kebab Case transforms don't replace spaces, unlike the snippet parser equivalents which do. A team member has already encouraged a PR contribution; the community upvote process is running. Keep open.

## Change summary

The Transform to Snake Case and Transform to Kebab Case editor actions should replace spaces with underscores and hyphens respectively, not just handle camelCase boundaries.

## Best solution

Add a `.replace(/\s+/g, '_')` step to `SnakeCaseAction._modifyText` and a `.replace(/\s+/g, '-')` step to `KebabCaseAction._modifyText` in `src/vs/editor/contrib/linesOperations/browser/linesOperations.ts`. The snippet parser's `_toSnakeCase` already does this (`.replace(/[\s\-]+/g, '_')`), so there's precedent. A team member has invited the reporter to submit a PR.
