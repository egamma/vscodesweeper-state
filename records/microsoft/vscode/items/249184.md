# Issue #249184 — SCM - Allow configuration via settings(.json) of quick diff decoration toggle state

[https://github.com/microsoft/vscode/issues/249184](https://github.com/microsoft/vscode/issues/249184)

## Summary

Keep open: current source still exposes per-provider diff visibility through a context-menu toggle and profile storage, not settings.json. Existing SCM settings do not independently control staged and working-tree decorations.

## Change summary

Expose quick diff provider visibility through settings so staged and working-tree decorations can be configured without GUI interaction.

## Best solution

Provide discoverable, declarative visibility controls in SCM settings that support user, workspace, and profile configuration while preserving independent staged and working-tree visibility. Define how those settings interact with existing menu toggles and saved preferences before implementation.
