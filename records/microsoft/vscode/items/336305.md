# Issue #336305 — Agent Host steering starts a new turn instead of steering the active turn

Fresh, well-diagnosed bug: steering during an active Copilot Agent Host turn doesn't interrupt it, it queues a new turn — the reporter's own debug logs show the pending message correctly marked `kind: steering` but the SDK recording `delivery: idle` instead of injecting into the live turn.
