# Issue #345421 — Secondary button background color is transparent

[https://github.com/microsoft/vscode/issues/345421](https://github.com/microsoft/vscode/issues/345421)

## Summary

Dark Modern's transparent secondary-button background is an intentional theme change, not a missing color. The authored change explicitly replaces the previous opaque fill while retaining a hover background.

## Change summary

Restore an opaque background for secondary buttons in Dark Modern.

## Best solution

Keep the intentional Dark Modern styling; users wanting filled secondary buttons can override button.secondaryBackground through workbench.colorCustomizations.
