## Summary

Well-diagnosed upstream Electron/Chromium GPU-compositing regression on Wayland, already correctly labeled bug/upstream/electron/wayland; the reporter bisected it and identified the fix (Electron 42.10.0+), but current main is only on Electron 42.8.1 (per .npmrc) and the recently merged bump PR only goes to 42.9.3 and doesn't reference this issue, so the fix hasn't landed.
