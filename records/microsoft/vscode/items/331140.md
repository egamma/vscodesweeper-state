## Change summary

MCP App webviews remain blank in auxiliary chat windows because they initially register against the main window while their container is detached.

## Best solution

Review, runtime-test, and land https://github.com/microsoft/vscode/pull/334718 so the MCP App webview resolves its target window after its container has been attached.
