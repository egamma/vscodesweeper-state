# Issue #258808 — Customizable Cancel Button Label in withProgress

[https://github.com/microsoft/vscode/issues/258808](https://github.com/microsoft/vscode/issues/258808)

## Summary

Keep open in the Backlog: 23 community upvotes passed the promotion threshold, and current main still exposes only a boolean cancellation option through the extension API despite already supporting custom labels internally.

## Change summary

Allow extensions using `window.withProgress` notifications to customize the cancellation button label.

## Best solution

Extend `ProgressOptions.cancellable` or add a dedicated label property in the public API, then preserve that string through `ExtHostProgress` to the existing notification progress implementation.
