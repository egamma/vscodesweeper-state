# Issue #122321 — Show Line Numbers should be in View menu

[https://github.com/microsoft/vscode/issues/122321](https://github.com/microsoft/vscode/issues/122321)

## Summary

The notebook line number toggle is still only in the NotebookEditorLayoutConfigure submenu (gear icon on editor title), not in the global View menu. The suggestion to unify placement with text editor options like 'render whitespace' remains unaddressed — keeping open as the team-authored discussion it is.

## Change summary

Move the notebook 'Show Line Numbers' toggle from the editor title gear menu into the global View menu, aligning placement with similar text editor options.

## Best solution

Move `notebook.toggleLineNumbersFromEditorTitle` into `MenuId.MenubarViewMenu` alongside render-whitespace and render-control-characters, and consider whether a parallel toggle for regular text editors should exist in the same menu for consistency.
