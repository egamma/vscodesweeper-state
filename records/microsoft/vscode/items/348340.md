# Issue #348340 — Combine follow-up messages queued during a Chat response

[https://github.com/microsoft/vscode/issues/348340](https://github.com/microsoft/vscode/issues/348340)

## Summary

The requested composer-only batching is not supported by the current queue implementation. Keep this open as a feature request; batching must preserve the distinction between related follow-ups and independently configured requests.

## Change summary

Combine consecutive main Chat composer follow-ups into one ordered, newline-separated queued prompt without changing steering, voice input, or the Agents window.

## Best solution

Define composer-only batching semantics that preserve attachments, model selections, and prompt-command intent while leaving steering, voice, and Agents window behavior unchanged. Account for the separate-request expectation documented in https://github.com/microsoft/vscode/issues/327649 before adopting automatic merging.
