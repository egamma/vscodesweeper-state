# Issue #323588 — Clicking on approval message should open corresponding chat

[https://github.com/microsoft/vscode/issues/323588](https://github.com/microsoft/vscode/issues/323588)

## Summary

The navigation defect remains source-reproducible on current main: approval content can identify a specific chat, but activating its session row opens only the session and can leave a different chat active.

## Change summary

Clicking an approval message in a multi-chat session should open the chat that owns that approval.

## Best solution

Preserve the owning chat identity when selecting an approval for display, and activate that chat when the approval-bearing row is opened while leaving ordinary session-row and Allow-button behavior unchanged.
