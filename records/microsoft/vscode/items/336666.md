# Issue #336666 — Agent session context transfer truncates delegated results without a lossless handoff

[https://github.com/microsoft/vscode/issues/336666](https://github.com/microsoft/vscode/issues/336666)

## Summary

Keep open and route to Agent Host: current source explicitly clips completed assistant replies even at full detail, without exposing a continuation mechanism. This team-authored request identifies a real lossless-retrieval gap, not evidence that stored conversation content is destroyed.

## Change summary

Provide a supported way to retrieve the complete delegated response when session-context output truncates it.

## Best solution

Retain bounded context reads while making omitted completed-response content recoverable without rerunning the delegated task or anticipating a shared-file workaround. Choose the externally visible retrieval contract before implementation.
