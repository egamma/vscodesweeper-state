# Issue #292476 — Do not auto-install Github Copilot on Remote

[https://github.com/microsoft/vscode/issues/292476](https://github.com/microsoft/vscode/issues/292476)

## Summary

Valid feature request: the `remote.defaultExtensionsIfInstalledLocally` mechanism does not track explicit user uninstalls, so extensions like Copilot are reinstalled on every remote connection if present locally. The user has a workaround (clearing the setting), but the default behavior doesn't respect explicit remote uninstalls.

## Change summary

Extensions listed in `remote.defaultExtensionsIfInstalledLocally` are reinstalled on remote hosts every connection even after the user explicitly uninstalls them from the remote.

## Best solution

Track explicit remote uninstalls (e.g. via a storage key per remote authority) in `InstallRemoteExtensionsContribution.installExtensionsIfInstalledLocallyInRemote()` so that once a user uninstalls a default extension from the remote, it is not auto-reinstalled on subsequent connections. The workaround of editing the `remote.defaultExtensionsIfInstalledLocally` setting should also be documented more prominently.
