# Issue #343101 — Agent Host fails on NixOS because bundled copilot-runtime lacks execute permission

[https://github.com/microsoft/vscode/issues/343101](https://github.com/microsoft/vscode/issues/343101)

## Summary

Keep open: independent evidence confirms a Nix packaging permission defect, while current VS Code source still leaves bundled-runtime executability unchecked. The packaging fix belongs in Nixpkgs, but the misleading Agent Host startup diagnostic remains relevant here.

## Change summary

Preserve executable permissions for the Nix-packaged Copilot runtime and expose the underlying launch failure instead of a destroyed-stream error.

## Best solution

Nixpkgs should preserve the bundled runtime's executable permissions during repackaging. VS Code should retain this report for the Agent Host diagnostic gap so a bundled runtime that cannot launch produces an actionable error without obscuring the cause behind subsequent stream failures.
