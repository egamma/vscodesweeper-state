## Summary

Keep open for the Agent Host startup-diagnostics defect: the report demonstrates an executable-permission failure, independently confirmed in the discussion, while users see a misleading destroyed-stream error. The Nix packaging repair belongs in the existing Nixpkgs report, but that does not resolve VS Code's error-reporting concern.

## Change summary

## Best solution

Track the Nix package permission repair in https://github.com/NixOS/nixpkgs/issues/573021 and retain this issue for actionable Agent Host launch diagnostics. Bundled-runtime startup failures should identify the inaccessible executable and underlying cause instead of exposing a secondary JSON-RPC stream error.
