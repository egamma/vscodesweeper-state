# Issue #296016 — net::ERR_CONNECTION_TIMED_OUT: [object Object].

[https://github.com/microsoft/vscode/issues/296016](https://github.com/microsoft/vscode/issues/296016)

## Summary

The malformed error detail remains possible on current main: Copilot passes the Electron network error message through to users without filtering the appended `[object Object]`. The underlying timeout is expected on a slow connection, but its presentation is a valid, bounded bug.

## Change summary

Copilot network failures expose the meaningless text `[object Object]` in the user-facing error detail.

## Best solution

Keep the useful Chromium error code while omitting non-descriptive object stringification from Copilot's user-facing network error formatter, with coverage for Electron errors shaped like the report.
