# Issue #296016 — net::ERR_CONNECTION_TIMED_OUT: [object Object].

[https://github.com/microsoft/vscode/issues/296016](https://github.com/microsoft/vscode/issues/296016)

## Summary

Already fixed on main and shipped in 1.116.0. The `[object Object]` in the error message was caused by `collectSingleLineErrorMessage` falling back to `.toString()` on error cause objects that lacked `.message` and `.code` properties; commit d21f0f967c8 removed that fallback.

## Change summary

Network error messages displayed `[object Object]` to the user when the error cause was a plain object without a message property.

## Best solution

Keep the shipped fix in commit d21f0f967c8 (1.116.0); no further change is needed. The reporter should update to a recent VS Code build to get the fix.
