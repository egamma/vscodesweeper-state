# Issue #293784 — auto try again

[https://github.com/microsoft/vscode/issues/293784](https://github.com/microsoft/vscode/issues/293784)

## Summary

Valid feature request: auto-retry with backoff for transient API errors already exists in autoApprove/autopilot modes but not in the default permission level. Extending this to the default agent mode would address the reported UX gap. Keeping open for product decision on the right default behavior.

## Change summary

Automatically retry transient Copilot API errors during agent execution instead of stopping and requiring the user to manually click 'Try Again'.

## Best solution

Extend the existing auto-retry logic in `extensions/copilot/src/extension/intents/node/toolCallingLoop.ts` (the `shouldAutoRetry` method and the retry path at line ~1190) to also cover the default permission level, not just `autoApprove`/`autopilot`. The backoff and max-retry cap (currently 3) are already implemented — the gate is the permission-level check at line 686. A product decision is needed on whether default-mode users should see a notification of the retry (like autopilot does) or whether it should be silent.
