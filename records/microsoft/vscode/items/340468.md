# Issue #340468 — External session creation can stall in prepareTurn while CopilotClient auth restart is deferred

[https://github.com/microsoft/vscode/issues/340468](https://github.com/microsoft/vscode/issues/340468)

## Summary

Credible, well-diagnosed deadlock: the reporter's described mechanism matches current main exactly, and they say a fix with regression coverage is already in progress and will be linked as a PR — keeping this open for that PR rather than closing or routing elsewhere.

## Change summary

Creating a new external Agent Host session can hang forever in prepareTurn when a concurrent in-flight chat's turn causes a global CopilotClient restart to be deferred, creating a circular wait between the parked restart and the new session's launch.

## Best solution

Land the reporter's proposed fix (apply the latest token via gitHubAuth.setCredentials to the new SDK session for a token-only auth change, keeping the global restart parked) once the linked PR arrives; until then this documents a real deadlock in _ensureClientForSession/_requestClientRestart.
