# Issue #342265 — Copilot apply_patch converts space indentation to tabs in files without existing indentation

[https://github.com/microsoft/vscode/issues/342265](https://github.com/microsoft/vscode/issues/342265)

## Summary

Confirmed in current source: apply_patch defaults an indentation-free file to tabs and converts correctly space-indented additions accordingly. Keep this open as a bounded Copilot editing bug; the supplied YAML example identifies the failing path precisely.

## Change summary

Make apply_patch use effective resource- and language-specific editor indentation settings when existing content provides no indentation preference.

## Best solution

For inconclusive indentation detection, apply_patch should respect the target file's effective editor settings, including language overrides and indentation width. Preserve existing content-based detection when the file establishes a style.
