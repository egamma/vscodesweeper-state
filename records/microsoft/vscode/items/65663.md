# Issue #65663 — Temporarily Set Configuration For Save Operation

[https://github.com/microsoft/vscode/issues/65663](https://github.com/microsoft/vscode/issues/65663)

## Summary

A real API gap remains, and this Backlog feature request has 40 community upvotes. The existing resource-aware settings do not let extensions temporarily control save behavior for an individual file.

## Change summary

Allow extensions to override built-in whitespace and newline save behavior on a per-file save operation.

## Best solution

Design an API or configuration mechanism that lets EditorConfig-like extensions supply per-resource save behavior without granting them broad authority to suppress unrelated save participants. Built-in EditorConfig support could reduce one use case, but would not cover ESLint and other extensions needing the same capability.
