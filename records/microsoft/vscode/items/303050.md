# Issue #303050 — Launch system package manager update when available

[https://github.com/microsoft/vscode/issues/303050](https://github.com/microsoft/vscode/issues/303050)

## Summary

Reasonable Linux-specific feature request but complex (privilege escalation, distro variance) with no community traction. The community upvote process ran its course with 0 votes; leaving for the established lifecycle process to handle closure.

## Change summary

When VS Code is installed via a system package manager on Linux, the update button should invoke that package manager instead of opening the download page.

## Best solution

The current Linux update service (`src/vs/platform/update/electron-main/updateService.linux.ts`) explicitly notes it doesn't detect the installed package type (line 78–79). Implementing this would require detecting the install method, handling privilege escalation for apt/pacman/dnf, and dealing with distro variance — a non-trivial surface. In practice, users who installed via the official apt/yum repo already receive updates through their system updater automatically. This is best left to the community process to close for lack of traction, or reconsidered if demand grows.
