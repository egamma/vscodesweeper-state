The SSH host-authenticity prompt does exist on current main (shipped in 1.72), but the thread shows it did not resolve this reporter's Windows case and a second user reconfirmed in 2024; the behavior is environment-dependent (which ssh.exe / OpenSSH build is in use) and cannot be verified from source, so this needs the missing environment details rather than a close.

## Change summary
