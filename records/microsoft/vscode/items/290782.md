# Issue #290782 — No proper progress in Chat while waiting on remote index to be built

[https://github.com/microsoft/vscode/issues/290782](https://github.com/microsoft/vscode/issues/290782)

## Summary

Still reproduces on main: a prior review's implemented-on-main close (citing commit ea1d598a) was refuted, and tracing the current code confirms the gap is still there — the remote code-search index wait has no dedicated progress message, so the chat UI just shows generic 'thinking'.

## Change summary

When Copilot Chat has to wait for a GitHub/ADO remote code-search index to finish building before it can search the workspace, the chat shows no progress indicator reflecting that wait — it looks like the model is just thinking.

## Best solution

Thread a progress callback into CodeSearchRepo.prepareSearch / CodeSearchChunkSearch.prepareSearchWorkspace / searchWorkspace so that while status is BuildingIndex a message like 'Building workspace index…' is reported via ChatResponseProgressPart2, the same mechanism already used for 'Collecting workspace information'.
