# Issue #195920 — Long/multiline test failure messages are not all readable when using actual/expected diff

[https://github.com/microsoft/vscode/issues/195920](https://github.com/microsoft/vscode/issues/195920)

## Summary

Still valid on current main: when a TestMessage.diff has a multiline message, the peek title truncates it to the first line (via `firstLine()`) and the Test Results pane only shows the diff editor without the descriptive message text. No fix or related change has landed.

## Change summary

When using TestMessage.diff with a multiline message, the full descriptive text is not visible — the peek title truncates to the first line, and the Test Results pane omits the message entirely above the diff.

## Best solution

In `DiffContentProvider.update()` (testResultsOutput.ts), render the full `message.message` text in a section above the diff editor within the `messageContainer`. In `testingOutputPeek.ts`, consider allowing the peek title to show the full multiline message or at least a more generous truncation. The `MessageStackFrame` label in testResultsViewContent.ts may also need adjustment to display multiline messages.
