# Issue #82236 — Completion should be able to retrigger completions when accepted

[https://github.com/microsoft/vscode/issues/82236](https://github.com/microsoft/vscode/issues/82236)

## Summary

A real API gap remains: retriggering works through a specially recognized command, but completion items still lack an explicit retrigger property and users lack the requested setting. The Backlog item is already correctly routed to API and suggest.

## Change summary

Add an explicit completion-item retrigger capability and a setting controlling retrigger-after-accept behavior.

## Best solution

Represent retrigger-after-accept as a typed CompletionItem capability, preserve compatibility with `editor.action.triggerSuggest`, and add an editor setting that controls whether accepted completions may retrigger suggestions.
