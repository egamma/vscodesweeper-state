# Issue #282796 — Move chat into secondary side-bar doesn't work with VScode version version 1.107

[https://github.com/microsoft/vscode/issues/282796](https://github.com/microsoft/vscode/issues/282796)

## Summary

The imported-chat move failure was caused by releasing the source model before the sidebar acquired it. Commit 14200868c7fb67eb932fbdf69abbe0f87b5da837 now retains the model throughout that handoff and adds direct sidebar-move regression coverage, so this can close as completed.

## Change summary

Moving an imported chat from an editor into the secondary side bar failed because the destination attempted to restore a session file that did not exist.

## Best solution

Keep the session-handoff behavior implemented by https://github.com/microsoft/vscode/commit/14200868c7fb67eb932fbdf69abbe0f87b5da837, which preserves the in-memory chat until the destination sidebar acquires it.
