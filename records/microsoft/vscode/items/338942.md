# Issue #338942 — Restart to Update is silently failing on Mac

[https://github.com/microsoft/vscode/issues/338942](https://github.com/microsoft/vscode/issues/338942)

## Summary

This is almost certainly the same macOS 'Restart to Update' failure actively tracked (and assigned to maintainers) in #310927, but the reporter's ShipIt log shows a different failure signature (a plist attribute-parsing error, not the checksum mismatch discussed there) on a very new macOS build (Darwin 27.0.0) — that's close enough to a platform-specific variant that I'm not proposing a duplicate close outright; a maintainer should confirm whether it's the same root cause before merging.

## Change summary

On macOS, clicking 'Restart to Update' quits the app but the update never installs; ShipIt_stderr.log shows a plist attribute-string parsing error and the app just sits un-updated.

## Best solution

Have the engineers already assigned to https://github.com/microsoft/vscode/issues/310927 (deepak1556, dmitrivMS) triage this alongside that cluster — confirm whether the new 'Unrecognized attribute string flag' ShipIt error on Darwin 27.0.0 (likely a very new macOS build) is the same underlying Squirrel.Mac/ShipIt defect or a new OS-compatibility break in Electron's bundled native updater (not in src/vs/platform/update/electron-main/updateService.darwin.ts itself, which only calls electron.autoUpdater.quitAndInstall()).
