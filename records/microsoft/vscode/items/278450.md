# Issue #278450 — GHCP Code Review does not respect Git worktree boundaries

[https://github.com/microsoft/vscode/issues/278450](https://github.com/microsoft/vscode/issues/278450)

## Summary

The repository-specific review buttons still discard their invocation context, and the review collector combines changes from every Git repository, including other worktrees. Keep this open in chat-review; the reported boundary violation remains visible in current source.

## Change summary

Code review invoked from one worktree's Source Control section includes uncommitted changes from other worktrees.

## Best solution

Repository-specific SCM review actions should review only the originating checkout, preserving staged versus unstaged scope. Retain existing behavior for context-free invocations and unrelated review entry points, and carry this isolation requirement into the planned review-engine replacement.
