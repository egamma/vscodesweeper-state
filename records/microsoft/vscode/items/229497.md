# Issue #229497 — SCM Graph - Limit Number Of Lines

[https://github.com/microsoft/vscode/issues/229497](https://github.com/microsoft/vscode/issues/229497)

## Summary

Keep open: the screenshot requests limiting simultaneous graph lanes, and current source still allocates graph width from the full lane count. Existing pagination and reference filters do not deliver that capability; no qualifying fix or canonical duplicate was established.

## Change summary

Limit the number of simultaneously displayed SCM graph lines so complex histories do not crowd out commit labels.

## Best solution

Design a bounded-width graph presentation in the SCM history view that preserves readable commit labels and understandable ancestry. The maintainer should first decide how excess lanes are represented and how users inspect connections outside the visible limit.
