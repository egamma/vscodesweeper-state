# Issue #57370 — Settings decoration: Modified in Folder

[https://github.com/microsoft/vscode/issues/57370](https://github.com/microsoft/vscode/issues/57370)

## Summary

Still unimplemented on main: the settings editor's overriddenScopeList only checks workspace/remote/user scopes but never iterates workspace folders to show folder-level modifications. Team-authored, milestone On Deck — stays open.

## Change summary

Show a 'Modified in Folder' decoration in the settings editor when a setting has been overridden in one or more workspace folders.

## Best solution

Extend the overriddenScopeList logic in settingsTreeModels.ts to inspect each workspace folder (via the configuration service's inspect API) and push folder-scope entries, then render them in settingsEditorSettingIndicators.ts. Performance concern (noted in comments) can be mitigated by lazy evaluation at render time.
