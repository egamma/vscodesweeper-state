# Issue #209088 — SCM - find a git repository by search in the SCM view

[https://github.com/microsoft/vscode/issues/209088](https://github.com/microsoft/vscode/issues/209088)

## Summary

Keep open: repository-name search in the Source Control view remains missing, and the reporter explicitly explained why Find in Tree does not cover it. The existing repository picker and related filtering requests do not fully satisfy this accepted Backlog request.

## Change summary

Allow users to find a repository by name in the Source Control view without scrolling through dozens of repositories.

## Best solution

Support repository-name discovery or filtering in the SCM view using the established tree-search interaction where practical. Preserve access to the matching repository's changed files and source-control actions without requiring users to know a changed filename.
