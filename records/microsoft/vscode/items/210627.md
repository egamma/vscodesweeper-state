# Issue #210627 — [A11y] Focus changes to custom editor when clicking on notebook toolbar overflow menu

[https://github.com/microsoft/vscode/issues/210627](https://github.com/microsoft/vscode/issues/210627)

## Summary

Keep open: the report and independent confirmation establish unwanted editor activation when opening menus beside a webview. No qualifying fix or older canonical with the same observable symptom was verified; the supplied steps suffice for a current-build retest.

## Change summary

Opening a notebook toolbar overflow menu unexpectedly activates a custom editor in the adjacent editor group.

## Best solution

Preserve the invoking notebook's active editor group while its overflow menu is open and after dismissal, without disrupting legitimate webview focus or webview-owned context menus. Diagnose the current focus-event sequence before choosing a bounded correction.
