# Issue #272350 — GPT-5-Codex (Preview) produces invalid links to project files in its outputs

[https://github.com/microsoft/vscode/issues/272350](https://github.com/microsoft/vscode/issues/272350)

## Summary

Still active: the Feb 2026 fix (f340d3616a8, shipped in 1.110) addresses inline references inside code spans/fenced blocks, but reporters confirm the issue persists through v1.123 (June 2026) in other contexts. Team members acknowledge the bug and it carries the On Deck milestone — keep open.

## Change summary

Chat inline references render as literal `_vscodecontentref_` URLs instead of clickable file links, corrupting the response output across multiple models.

## Best solution

Extend the `annotateSpecialMarkdownContent` logic in `src/vs/workbench/contrib/chat/common/widget/annotations.ts` to handle remaining edge cases where inline references are emitted as raw markdown link text (false-positive file detection, references in contexts the `isInsideCodeContext` guard doesn't catch). The related open issue https://github.com/microsoft/vscode/issues/280165 (auto-linking breaking copy-paste) may share root cause and should be considered together.
