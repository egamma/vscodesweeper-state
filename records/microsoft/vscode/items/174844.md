# Issue #174844 — Unable to select settings UI boolean setting descriptions

[https://github.com/microsoft/vscode/issues/174844](https://github.com/microsoft/vscode/issues/174844)

## Summary

Still reproduces on main: the boolean setting description's MOUSE_DOWN handler calls DOM.EventHelper.stop(e) to toggle the checkbox, which prevents text selection. The bug is real, confirmed, and unfixed.

## Change summary

Text in boolean (checkbox) setting descriptions cannot be selected/copied because the mousedown handler prevents default behavior.

## Best solution

Distinguish between a click-to-toggle gesture and a text-selection drag in the MOUSE_DOWN handler on `.setting-item-description` inside `SettingBoolRenderer`. One approach: only toggle the checkbox on a clean click (no drag detected), and let text selection proceed by not calling `stop(e)` when the user is dragging to select. The fix lives in `src/vs/workbench/contrib/preferences/browser/settingsTree.ts` around line 2125.

This prevents all text selection in boolean setting descriptions. The fix: move the checkbox toggle logic to a CLICK (or MOUSE_UP) handler instead of MOUSE_DOWN, so that native text selection via click-and-drag is not suppressed. Alternatively, detect whether the interaction is a drag (selection attempt) vs a clean click, and only toggle+stop on a clean click. The checkbox toggle behavior for simple clicks must be preserved — clicking the description should still toggle the setting. Only the text-selection prevention should be removed.
