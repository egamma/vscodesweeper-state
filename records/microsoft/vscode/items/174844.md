# Issue #174844 — Unable to select settings UI boolean setting descriptions

[https://github.com/microsoft/vscode/issues/174844](https://github.com/microsoft/vscode/issues/174844)

## Summary

Boolean setting descriptions still cancel the mouse event that normally starts text selection. Keep this confirmed, team-authored bug open; selecting from the title remains a workaround, not a fix.

## Change summary

Allow users to select and copy boolean setting descriptions directly in the Settings editor.

## Best solution

Make boolean descriptions selectable while retaining ordinary description-click checkbox activation, embedded-link navigation, and disabled-setting behavior. The relevant interaction belongs to SettingBoolRenderer in the Settings editor.

- **Current source directly blocks selection:** src/vs/workbench/contrib/preferences/browser/settingsTree.ts:2119–2143, SettingBoolRenderer.renderValue, registers a MOUSE_DOWN listener on enabled boolean descriptions.
