# Issue #308272 — Thinking effort hover/tooltip takes overrides warning tooltip

[https://github.com/microsoft/vscode/issues/308272](https://github.com/microsoft/vscode/issues/308272)

## Summary

Team-authored bug (hard keep-open). The warning badge icon in the model picker has no managed hover of its own, so when hovered, the nearby config button's 'Configure Model' tooltip takes precedence — the warning text is never surfaced on hover.

## Change summary

Hovering the warning badge icon on a degraded model in the chat model picker shows the thinking-effort 'Configure Model' tooltip instead of the model's warning message.

## Best solution

Add a `setupManagedHover` on the `_badgeIcon` element in `ChatModelPickerWidget._renderLabel()` (around line 1252 in `chatModelPicker.ts`) that surfaces the model's `warningText` when the badge is a warning. This keeps the warning discoverable on hover alongside the existing rich hover in the dropdown.
