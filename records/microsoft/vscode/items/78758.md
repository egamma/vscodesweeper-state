# Issue #78758 — [themes] Show extension info in Preferences: Color Theme panel

[https://github.com/microsoft/vscode/issues/78758](https://github.com/microsoft/vscode/issues/78758)

## Summary

The requested inline extension attribution remains absent on current main. The picker now provides a per-theme Manage button and the Extensions view offers a filtering workaround, but neither displays the providing extension beside each installed theme as requested.

## Change summary

Show each installed color theme's providing extension in the Color Theme picker so users can identify and uninstall unwanted theme extensions.

## Best solution

Keep the existing Manage action and add concise extension attribution to installed extension-contributed theme entries, without adding metadata noise to built-in themes.
