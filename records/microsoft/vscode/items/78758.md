# Issue #78758 — [themes] Show extension info in Preferences: Color Theme panel

[https://github.com/microsoft/vscode/issues/78758](https://github.com/microsoft/vscode/issues/78758)

## Summary

The central user need is implemented: each installed extension-contributed theme now has an inline Manage Extension action that opens its exact provider in the Extensions view, where it can be inspected or uninstalled.

## Change summary

Expose which extension provides each entry in the Color Theme picker so unwanted theme extensions can be identified and removed.

## Best solution

Keep the shipped inline Manage Extension action rather than adding persistent publisher text to every picker row; it identifies the exact provider and takes the user directly to its management surface.
