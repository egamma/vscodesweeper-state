# Issue #78758 — [themes] Show extension info in Preferences: Color Theme panel

[https://github.com/microsoft/vscode/issues/78758](https://github.com/microsoft/vscode/issues/78758)

## Summary

The reporter's central goal is implemented and shipped: every extension-contributed theme now has a Manage Extension button that opens its exact provider, allowing the unwanted theme extension to be identified and uninstalled.

## Change summary

Expose which extension contributes each entry in the Color Theme picker so users can manage or uninstall unwanted theme extensions.

## Best solution

Keep the shipped per-theme Manage Extension action, which resolves provider discovery without adding persistent metadata to every picker row.
