# Issue #196435 — Extension under development doesn't appear as an option in the issue reporter

[https://github.com/microsoft/vscode/issues/196435](https://github.com/microsoft/vscode/issues/196435)

## Summary

Still reproduces on main: the issue reporter populates the extension picker via `extensionManagementService.getInstalled()`, which does not include extensions running in the Extension Development Host. The bug is confirmed in both the browser and electron-browser issue service paths.

## Change summary

Extensions under development (loaded via Extension Development Host) do not appear in the issue reporter's extension picker.

## Best solution

When building the extension list for the issue reporter, also include extensions from `IExtensionService.extensions` that are running in the development extension host (i.e., extensions with `ExtensionHostKind.LocalProcess` from a development host or those not returned by `getInstalled()`). The fix touches `src/vs/workbench/contrib/issue/browser/issueService.ts` and `src/vs/workbench/contrib/issue/electron-browser/issueService.ts` where the extension data array is built.
