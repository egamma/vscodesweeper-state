# Issue #196435 — Extension under development doesn't appear as an option in the issue reporter

[https://github.com/microsoft/vscode/issues/196435](https://github.com/microsoft/vscode/issues/196435)

## Summary

Keep open: the issue reporter still enumerates installed extensions, leaving development-only extensions unavailable for testing issue-reporting integrations. Although an older decision described this as intentional, this report was subsequently accepted with the bug label and Backlog milestone, so that precedent does not justify a decline close.

## Change summary

Include the extension being debugged in the extension development host's Report Issue picker.

## Best solution

Allow extension authors to select their development extension and exercise its issue-reporting integration without installing it first. Preserve the existing installed-extension behavior outside extension development hosts.
