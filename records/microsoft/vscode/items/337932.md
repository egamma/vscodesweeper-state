# Issue #337932 — vscode.dev/agents: links and small interactive elements in chat are not tappable in Chrome on Android

[https://github.com/microsoft/vscode/issues/337932](https://github.com/microsoft/vscode/issues/337932)

## Summary

Traced and confirmed on main: touch taps on markdown links (and any click-only interactive element) inside a `ListView`-hosted chat transcript are swallowed because `Gesture` calls `preventDefault()` on `touchend` once it dispatches its synthetic tap event, which suppresses the browser's synthetic `click` — and `markdownRenderer.ts` only listens for `click`/`auxclick`, never the gesture tap event.

## Change summary

On vscode.dev/agents in Chrome for Android, tapping Markdown links or small interactive elements in chat does nothing because touch taps never fire a click event.

## Best solution

Have the markdown link/action handler in `renderMarkdown` also register as a Gesture target and listen for the `-monaco-gesturetap` event (mirroring the existing pattern in `src/vs/base/browser/ui/button/button.ts` L167-169), routing it through the same `activateLink` path used for click/keydown.
