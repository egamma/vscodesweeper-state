# Issue #328244 — Subagents cannot access chat image attachments available to the parent agent

[https://github.com/microsoft/vscode/issues/328244](https://github.com/microsoft/vscode/issues/328244)

## Summary

Current main confirms the attachment context is lost when launching a subagent. This team-authored, source-reproducible bug should remain open for an attachment-forwarding design.

## Change summary

Allow subagents to consume image attachments supplied to their parent agent.

## Best solution

Forward user-approved attachments as native subagent context, or copy them into a child-readable session artifact directory, while preserving content-exclusion boundaries. Cover image delegation and attachment access with focused chat subagent tests.
