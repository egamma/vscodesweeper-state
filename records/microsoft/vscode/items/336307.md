# Issue #336307 — Copilot Cloud or Local labels on chat sessions

[https://github.com/microsoft/vscode/issues/336307](https://github.com/microsoft/vscode/issues/336307)

## Summary

Reasonable, not-yet-implemented request: today the local/cloud distinction is only surfaced via the hover tooltip and the accessible name, not as a persistent, always-visible marker on each Agent Sessions list row, so a user scanning the list can't tell same-named local vs. cloud sessions apart at a glance.

## Change summary

Add a persistent Local/Cloud badge (with tooltip/accessible name) to each row in the Agents/Chat sessions list so same-named sessions can be told apart without opening them.

## Best solution

Extend the row renderer in src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsViewer.ts (where providerLabel is already computed and used for the aria-label and hover title) to also render a small always-visible provider badge/tag next to the item, reusing session.element.providerLabel/providerType so no new data plumbing is needed.

## Evidence

- **providerLabel exists but isn't a visible badge:** agentSessionsModel.ts defines providerType/providerLabel per session (e.g. Local/Cloud/Background), and agentSessionsViewer.ts already uses session.element.providerLabel only for the row's aria-label (line ~1042) and in sessionSummaryHover.ts for the hover title (`session-summary-hover-provider` span) — neither is visible without opening the session or hovering/using a screen reader.
- **row icon does not clearly convey provider:** In agentSessionsViewer.ts renderElement(), the details icon shown per row is session.element.icon (a session-type icon) or hidden entirely for Background sessions in status-only icon mode; there is no dedicated Local/Cloud badge element rendered inline in the row.
