# Issue #336307 — Copilot Cloud or Local labels on chat sessions

[https://github.com/microsoft/vscode/issues/336307](https://github.com/microsoft/vscode/issues/336307)

## Summary

Keep open: current provider names, hover content, and conditional icons only partially cover the requested persistent Local/Cloud distinction. The newer related report points back to this issue, so this remains the appropriate place to settle the presentation.

## Change summary

Show a persistent, accessible Local or Cloud indicator on session-list rows so identically named sessions can be distinguished without opening them.

## Best solution

Provide a consistent, compact execution-location indication in the Chat sessions list and Agents sidebar that remains identifiable while sessions are working. Coordinate the broader remote-location and workspace-visibility requirements from https://github.com/microsoft/vscode/issues/336997 without conflating execution location with provider identity.
