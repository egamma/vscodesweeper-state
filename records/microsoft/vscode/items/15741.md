# Issue #15741 — Allow code to open directories in nautilus file manager

[https://github.com/microsoft/vscode/issues/15741](https://github.com/microsoft/vscode/issues/15741)

## Summary

The inode/directory MIME type was intentionally removed in PR #209510 to prevent VS Code from hijacking default file-manager behavior on some distros. The issue was reopened by a team member to explore whether it can be re-added safely. Two open PRs (#281867, #311053) attempt this. Still under active discussion with no resolution.

## Change summary

Re-add inode/directory MIME type to the .desktop file so directories can be opened with VS Code from Nautilus/file managers without VS Code becoming the default file manager.

## Best solution

A maintainer needs to decide whether re-adding `inode/directory` to the desktop file (possibly with xdg-mime commands to avoid becoming the default handler) is acceptable. The two open PRs (#281867 and #311053) are implementation candidates. The trade-off is user convenience vs. the mime-pollution regression on some DEs (especially Xfce).
