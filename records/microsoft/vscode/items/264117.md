# Issue #264117 — "Remove keybinding" can delete the wrong keyboard shortcut

[https://github.com/microsoft/vscode/issues/264117](https://github.com/microsoft/vscode/issues/264117)

## Summary

Still reproduces on main: `findUserKeybindingEntryIndex` in keybindingEditing.ts matches only on `command` and `when`, ignoring `args` and `key`, so it always finds the first matching entry rather than the specific one the user selected.

## Change summary

Removing a keybinding when multiple entries share the same command and when clause (but differ in args) always removes the first match instead of the selected one.

## Best solution

Extend `findUserKeybindingEntryIndex` in `keybindingEditing.ts` to also compare `args` (using `objects.equals`, as `areSame` already does) and the `key` field against the keybinding item being removed, so the correct entry is identified.
