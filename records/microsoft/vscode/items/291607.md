## Summary

The requested session-scoped approval remains unavailable: current source rejects inline environment assignments before considering an exact-command approval. Keep this accepted On Deck request open; existing approval options and the related issues do not cover its narrow scope.

## Change summary

Allow users to approve an exact terminal command, including its inline environment variable assignments, for the current chat session.

## Best solution

Provide narrowly scoped session approval for an explicitly selected command such as `TZ=UTC yarn jest`, retaining the environment names and values in the approval identity without granting blanket terminal approval. Preserve explicit deny rules and confirmation requirements for unsafe or unanalyzable shell syntax.
