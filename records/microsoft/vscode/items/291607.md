# Issue #291607 — Add option to allow specific inline environment variables

[https://github.com/microsoft/vscode/issues/291607](https://github.com/microsoft/vscode/issues/291607)

## Summary

Valid open feature request: the transient env var hard deny (added after a reverted general fix) blocks legitimate commands like `TZ=UTC yarn jest`. The ask is to allow specific inline env var patterns for the session rather than blanket-denying them. No implementation exists on main.

## Change summary

Allow specific inline environment variable prefixes (e.g. `TZ=UTC yarn jest`) to pass terminal command auto-approval instead of being unconditionally denied.

## Best solution

Extend the auto-approve analyzer in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/commandLineAnalyzer/autoApprove/commandLineAutoApprover.ts` to strip known-safe env var prefixes before matching against allow/deny rules, or add a session-scoped allowlist for specific command lines including their env var prefixes. The earlier general approach was reverted (commit ba8e9678ebe) due to edge cases, so a more targeted solution — e.g. allowing the exact command line with its env vars via session rules or `matchCommandLine` — is the likely path.
