# Issue #344520 — Chat in welcome is using 'local' by default

[https://github.com/microsoft/vscode/issues/344520](https://github.com/microsoft/vscode/issues/344520)

## Summary

The configured Agent Sessions Welcome page still initializes Local unconditionally, bypassing the default-session selection used by the chat panel and editor. Keep this open to bring the startup surface into alignment; its registration and startup handler remain present on main.

## Change summary

The Agent Sessions Welcome startup editor defaults to Local rather than following the main window's effective chat-session default.

## Best solution

If retained, the welcome page should select and create the same initial session type as other main-window chat surfaces. The maintainers should settle the reporter's alternative of retiring this startup editor before investing in its maintenance.
