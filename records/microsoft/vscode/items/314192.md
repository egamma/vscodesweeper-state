# Issue #314192 — Text can become unreadable when fish overlap

[https://github.com/microsoft/vscode/issues/314192](https://github.com/microsoft/vscode/issues/314192)

## Summary

The readability gap remains on current main: aquarium mode deliberately makes the session surfaces transparent, while no style protects foreground text from moving fish. This team-authored Backlog item should remain open for a visual-treatment decision.

## Change summary

Keep session text legible when aquarium fish move underneath it.

## Best solution

Choose a theme-aware treatment that preserves the aquarium effect while maintaining text contrast, including high-contrast themes, and scope it to aquarium mode without changing ordinary session rendering.

## Plan brief

- **Likely files:** `src/vs/sessions/contrib/aquarium/browser/media/aquarium.css`, `src/vs/sessions/contrib/aquarium/browser/aquariumOverlay.ts`
- **Validation:** Enable `sessions.developerJoy.enabled`, activate the aquarium, and verify representative session text remains readable while light and dark fish overlap it in default dark, default light, high-contrast dark, and high-contrast light themes; confirm aquarium-off rendering is unchanged.
- **Behavior:**

  > When aquarium mode is active, session text must remain readable as fish of any species and size move beneath it. The aquarium should remain visible and animated rather than being hidden by an opaque full-surface layer. The treatment must work in default light, default dark, and both high-contrast themes, while aquarium-off session rendering remains unchanged.
- **Trace:**

  > Aquarium activation in `createActiveAquarium` at src/vs/sessions/contrib/aquarium/browser/aquariumOverlay.ts inserts `.agents-aquarium-water` as the first child of the sessions part and adds `aquarium-active`. In src/vs/sessions/contrib/aquarium/browser/media/aquarium.css, that state deliberately clears the backgrounds of `.session-view`, `.session-view-content`, and `.chat-group-view`, exposing moving fish directly beneath foreground content; no aquarium-scoped text-contrast treatment follows. Keep the boundary to aquarium-active presentation and do not alter normal session backgrounds, fish movement, pointer handling, or the reduced-motion behavior. The report originated as a visual follow-up to https://github.com/microsoft/vscode/issues/313981.
- **Open decisions:**
  - Should aquarium readability be provided by a localized translucent surface behind text-bearing content, a theme-aware text shadow, or another treatment with equivalent contrast?
  - Should high-contrast themes retain the aquarium with a dedicated contrast treatment or suppress decorative overlap around text entirely?
