# Issue #339586 — Codex Agent Host pins SDK 0.153.0 and rejects GPT-6 with ChatGPT authentication

[https://github.com/microsoft/vscode/issues/339586](https://github.com/microsoft/vscode/issues/339586)

## Summary

The 400 error comes from OpenAI's Codex backend rejecting gpt-6-luna for ChatGPT-authenticated accounts — that policy lives upstream in the bundled @openai/codex SDK/service, not in VS Code's own Agent Host code; I found no model-support filtering logic in VS Code that could be patched to fix this directly.

## Change summary

Codex Agent Host sessions using ChatGPT authentication fail immediately when sending a prompt to GPT-6 Luna, even though the model appears selectable in the picker.

## Best solution

Confirm with the bundled Codex SDK's upstream release notes whether a newer version lifts this ChatGPT-auth model restriction, and in the meantime have the Agent Host model picker filter out models the current auth mode can't use instead of surfacing a model that immediately 400s.
