# Issue #315085 — Ctrl+I shortcut (Inline Chat) defaults to Sidebar Chat after first use of Chat View

[https://github.com/microsoft/vscode/issues/315085](https://github.com/microsoft/vscode/issues/315085)

## Summary

The Ctrl+I routing is intentional for files participating in a chat editing session, and the existing `inlineChat.askInChat` setting provides the requested always-inline behavior.

## Change summary

Keep Ctrl+I opening Inline Chat after a file has participated in Sidebar Chat.

## Best solution

Keep the context-aware default and use `"inlineChat.askInChat": false` for users who want Ctrl+I to always open regular Inline Chat.
