# Issue #315085 — Ctrl+I shortcut (Inline Chat) defaults to Sidebar Chat after first use of Chat View

[https://github.com/microsoft/vscode/issues/315085](https://github.com/microsoft/vscode/issues/315085)

## Summary

This is by design: when a file belongs to a chat editing session, the `inlineChat.askInChat` setting (default: `true`) redirects Ctrl+I to the sidebar chat instead of inline chat. The reporter can set `"inlineChat.askInChat": false` to restore the old behavior.

## Change summary

Ctrl+I opens the sidebar chat instead of inline chat when the active file has been edited by a chat session.

## Best solution

Keep the shipped behavior. The `inlineChat.askInChat` setting already provides an opt-out. The context key `inlineChatFileBelongsToChat` correctly tracks whether the file belongs to a chat editing session, and the keybinding `when` clauses correctly route Ctrl+I to `AskInChatAction` vs `StartSessionAction` based on that state.

## Evidence

- **keybinding design:** `StartSessionAction` (inlineChat.start) binds Ctrl+I with `when: CTX_INLINE_CHAT_FILE_BELONGS_TO_CHAT.negate() || CTX_ASK_IN_CHAT_ENABLED.negate()` at src/vs/workbench/contrib/inlineChat/browser/inlineChatActions.ts:57-62. `AskInChatAction` (inlineChat.askInChat) binds the same key with `when: CTX_INLINE_CHAT_FILE_BELONGS_TO_CHAT && CTX_ASK_IN_CHAT_ENABLED` at lines 410-414. These are mutually exclusive and intentional.
- **context key tracking:** `CTX_INLINE_CHAT_FILE_BELONGS_TO_CHAT` is set via an autorun at src/vs/workbench/contrib/inlineChat/browser/inlineChatController.ts:168-189 — it checks whether the current editor's model URI matches any entry in any chat editing session.
- **setting default:** The `inlineChat.askInChat` setting defaults to `true` (src/vs/workbench/contrib/inlineChat/common/inlineChat.ts:60-64), described as 'Controls whether files in a chat editing session use Ask in Chat instead of Inline Chat.'
- **user workaround:** Setting `"inlineChat.askInChat": false` in user settings disables the redirect and restores Ctrl+I to always open inline chat.
