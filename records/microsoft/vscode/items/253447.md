# Issue #253447 — Make blue button hover feedback consistent

[https://github.com/microsoft/vscode/issues/253447](https://github.com/microsoft/vscode/issues/253447)

## Summary

Still open on main — no commit references this issue and the inconsistency in button hover styles persists across different views. The base button widget supports hover via `--vscode-button-hoverBackground` but not all blue buttons in the workbench use the standard widget or its `default-colors` class consistently.

## Change summary

Blue (primary) buttons have inconsistent hover feedback — some show a background change on hover, others do not.

## Best solution

Audit all primary button usages to ensure they consistently use the `default-colors` class and the `--vscode-button-hoverBackground` CSS variable, or unify via a global hover rule on `.monaco-button` that doesn't require the opt-in class.
