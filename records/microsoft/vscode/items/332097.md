## Summary

Confirmed on main: CodexAgent registers onNotification handlers for many turn/item events but has none for turn/plan/updated, so plan snapshots are dropped instead of being surfaced as TodoList cards. An open PR from the same author already addresses this, so it should be reviewed/landed rather than treated as unfixed work needing a new implementer.

## Best solution

Land https://github.com/microsoft/vscode/pull/332099, which registers turn/plan/updated and maps plan steps into the existing TodoList primitives per the mapping described in the issue.
