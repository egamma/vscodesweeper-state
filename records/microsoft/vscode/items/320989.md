# Issue #320989 — [Feature]Stable installation path required: commit ID breaks third-party integrations

[https://github.com/microsoft/vscode/issues/320989](https://github.com/microsoft/vscode/issues/320989)

## Summary

VS Code already provides a stable CLI entry point at <installation>\bin\code.cmd that resolves the commit-specific cli.js internally. The inverse-search integration can use that entry point without tracking internal installation paths.

## Change summary

Provide an update-stable launch path for third-party integrations such as SumatraPDF inverse search.

## Best solution

Use the existing bin\code.cmd launcher with --reuse-window --goto "file:line" for inverse search, invoking it through cmd.exe when the integration requires an executable. Preserve versioned application resources rather than making integrations depend on cli.js.
