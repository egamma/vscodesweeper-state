## Summary

Decline close (as-designed) gated off: the issue carries `under-discussion` — the owner has not decided yet. Original assessment: A stable integration entry point already exists: the installed bin\code.cmd launcher resolves the version-specific cli.js internally. Inverse search can use the supported --goto option without embedding a commit ID.

## Change summary

Provide an update-independent launch path for third-party integrations such as SumatraPDF inverse search.

## Best solution

Configure integrations against the stable code launcher with --reuse-window --goto, rather than the internal cli.js path; retain versioned application resources.
