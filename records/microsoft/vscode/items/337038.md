# Issue #337038 — Chat tab - move "Copy Link" to the bottom of the menu

[https://github.com/microsoft/vscode/issues/337038](https://github.com/microsoft/vscode/issues/337038)

## Summary

Team-authored polish request from a maintainer testing a just-landed feature (#336937); the code confirms the current menu order and the requested reorder is a small, well-bounded change.

## Change summary

In the Agents Window chat tab context menu, move the 'Copy Link' action to the bottom (below Delete Chat) instead of its current position between Rename and Delete.

## Best solution

Reorder the action groups passed to `Separator.join` in `_createChatTab`'s context-menu handler in chatCompositeBar.ts so `copyLinkAction` comes after `deleteAction`.
