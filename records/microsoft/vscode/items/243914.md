# Issue #243914 — Make sure fish shell integration script contains thorough encoding

[https://github.com/microsoft/vscode/issues/243914](https://github.com/microsoft/vscode/issues/243914)

## Summary

The gap is still present on main: the fish `__vsc_escape_value` function (line 128–131 of shellIntegration.fish) only escapes backslashes and semicolons, while the bash and zsh equivalents do thorough byte-by-byte encoding that also hex-encodes control characters below 0x20. This debt item remains valid.

## Change summary

Align the fish shell integration script's `__vsc_escape_value` function with the thorough encoding already used in the bash and zsh scripts.

## Best solution

Rewrite `__vsc_escape_value` in `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.fish` to iterate byte-by-byte and hex-encode control characters (below 0x20), matching the pattern in `shellIntegration-bash.sh` lines 151–185 and `shellIntegration-rc.zsh` lines 120–145.
