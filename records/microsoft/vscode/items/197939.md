# Issue #197939 — Let extensions configure the "Start Discussion" for new comments

[https://github.com/microsoft/vscode/issues/197939](https://github.com/microsoft/vscode/issues/197939)

## Summary

Still unimplemented on main: CommentOptions has only `prompt` and `placeHolder` — no `threadLabel` property exists. Team-authored feature request in the Backlog with recent extension-author interest; keeping open.

## Change summary

Let extensions configure the label shown on new comment threads (e.g. "Start Discussion") via a `threadLabel` property on `CommentOptions`.

## Best solution

Add a `threadLabel` (or `defaultThreadLabel`) property to `CommentOptions` in the comments API so extensions can customize the gutter-click label for new threads. The implementation would touch `src/vscode-dts/vscode.d.ts` (API surface), the comment controller internal model, and the comment thread widget rendering in `src/vs/workbench/contrib/comments/`.
