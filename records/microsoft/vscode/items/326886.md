# Issue #326886 — GitHub Copilot extension can't be re-enabled via the Extensions window after disabling it

[https://github.com/microsoft/vscode/issues/326886](https://github.com/microsoft/vscode/issues/326886)

## Summary

The defect remains on main: disabling Copilot through the Running Extensions menu creates an enablement state that the Extensions UI cannot reverse. This team-authored issue should remain open for a targeted fix.

## Change summary

Allow the built-in GitHub Copilot Chat extension to be re-enabled individually after it was disabled through Running Extensions.

## Best solution

Make the Copilot-specific enable action handle `DisabledGlobally` as well as `chat.disableAIFeatures`, restoring consistent extension and configuration state without requiring Enable All Extensions.
