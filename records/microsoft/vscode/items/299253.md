## Summary

Likely a real regression in keyboard layout handling for Swiss German (de_CH) on Linux, introduced in v1.109 — possibly tied to the Electron 39.3.0 bump in that cycle. No fix found on main; the issue is already correctly labeled.

## Change summary

Ctrl+Shift+` shortcut on Swiss German Linux keyboards is recorded as [Equal]/^ instead of backtick since v1.109, making the binding non-functional.

There is no `de-swiss.linux.ts` layout file in `src/vs/workbench/services/keybinding/browser/keyboardLayouts/` — adding one may help. The fix likely belongs in the keybinding dispatch or layout detection layer.
