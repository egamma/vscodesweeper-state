# Issue #269489 — `LanguageModelChatInformation#capabilities` should be optional

[https://github.com/microsoft/vscode/issues/269489](https://github.com/microsoft/vscode/issues/269489)

## Summary

The required capabilities object is intentional API design: maintainers explicitly chose it to ensure model providers consider important capabilities such as tool calling rather than accidentally omitting them.

## Change summary

Make LanguageModelChatInformation.capabilities optional when a language model declares no capabilities.

## Best solution

Keep LanguageModelChatInformation.capabilities required, allowing providers with no supported capabilities to declare an empty object explicitly.
