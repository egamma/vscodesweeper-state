# Issue #337196 — Windows 11 + NVIDIA RTX 4090 + AOC Q27G10E2: Monitor black screen caused by MPO (Multi-Plane Overlay), resolved by disabling MPO

[https://github.com/microsoft/vscode/issues/337196](https://github.com/microsoft/vscode/issues/337196)

## Summary

The reporter's own extensive testing shows this is a Windows DWM Multi-Plane Overlay + NVIDIA driver + specific monitor compatibility issue, not something caused by VS Code (it also happens with WeChat, persists with --disable-gpu and --disable-extensions, and disappears on Linux with identical hardware). Root cause lives outside this repo, so keeping this open as an upstream report rather than proposing a close.

## Change summary

Monitor intermittently goes black when hardware-accelerated apps (including VS Code) render, traced by the reporter to Windows MPO interacting with an NVIDIA RTX 4090 and an AOC monitor; disabling MPO via registry fixes it.

## Best solution

No VS Code-side fix exists here; the reporter has already isolated the cause to Windows DWM/MPO plus the NVIDIA driver and a specific monitor. Best outcome is a maintainer acknowledging this is an OS/driver-level display issue (not VS Code-specific, since --disable-gpu and --disable-extensions did not help) and pointing to Microsoft/NVIDIA channels, or closing as out-of-scope/not-a-vscode-bug once confirmed.
