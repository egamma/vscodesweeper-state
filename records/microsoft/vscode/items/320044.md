# Issue #320044 — Remote session/task persistence: Detach, preserve, and reattach all active tasks, terminals, and extension processes in VS Code Remote

[https://github.com/microsoft/vscode/issues/320044](https://github.com/microsoft/vscode/issues/320044)

## Summary

Keep this accepted Backlog request open: 49 community upvotes demonstrate traction, and current persistence covers only parts of the requested remote-session lifecycle. The newer terminal-orchestration issue is narrower and references this broader request rather than replacing it.

## Change summary

Allow an entire remote workspace session—including terminals, tasks, extension processes, debugging, and associated state—to survive client disconnection and reattach later.

## Best solution

Treat this as the canonical cross-component request for a server-owned, detachable remote-session lifecycle. A phased implementation should extend existing terminal and task reconnection infrastructure while defining explicit persistence contracts for extension-host and debugger state.
