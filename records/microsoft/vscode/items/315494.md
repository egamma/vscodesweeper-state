# Issue #315494 — Webview workers can no longer load webview resources after #311844

[https://github.com/microsoft/vscode/issues/315494](https://github.com/microsoft/vscode/issues/315494)

## Summary

Confirmed on current main: blob workers inside webview iframes cannot resolve the owning webview ID, so resource fetches hang. An open PR (#315495) exists to fix this — keeping open until it lands.

## Change summary

After #311844, workers created inside webview iframes can no longer load webview resources because `getWebviewIdForClient` returns null for blob-URL clients.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/315495 which resolves the webview ID for worker clients via origin matching in the service worker. Review should confirm it fails closed when multiple webviews share an origin.
