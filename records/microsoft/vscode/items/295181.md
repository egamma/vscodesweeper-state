# Issue #295181 — GitHub Copilot Chat: Org-wide custom agents from .github-private only appear from one org when user belongs to multiple orgs (regression in VS Code 1.109)

[https://github.com/microsoft/vscode/issues/295181](https://github.com/microsoft/vscode/issues/295181)

## Summary

Confirmed from source: the org custom agent discovery architecture is single-org by design — `getPreferredOrganizationName()` returns one org and agents are only fetched from that org. No multi-org aggregation has landed. This is a valid feature gap that remains open.

## Change summary

Custom agents from `.github-private` repos are only loaded from a single GitHub organization, even when the user belongs to multiple orgs with distinct agents.

## Best solution

Extend `GitHubOrgChatResourcesService` and `GitHubOrgCustomAgentProvider` to aggregate agents across all user orgs (or at least workspace-relevant orgs) rather than selecting a single preferred org. The TODO on line 186 of `githubOrgChatResourcesService.ts` already acknowledges multi-root workspace support is needed. The `provideCustomAgents` method should iterate over all accessible orgs and merge the results.
