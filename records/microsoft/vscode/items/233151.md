# Issue #233151 — [WSL2] Use relative paths when linking to files

[https://github.com/microsoft/vscode/issues/233151](https://github.com/microsoft/vscode/issues/233151)

## Summary

Still reproduces on main: the relative file URI resolution in the link handler is gated on `modelUri.scheme === Schemas.file`, which excludes WSL2/remote connections where the scheme is `vscode-remote`. The fix that landed for #90848 (commit 5af7860ca23) only addressed the local `file://` case.

## Change summary

Ctrl+clicking a `file://./relative.ts` link in WSL2 fails because the relative path resolution code requires the model URI scheme to be `file`.

## Best solution

Extend the relative-path resolution guard in `src/vs/editor/contrib/links/browser/links.ts` (line ~234) to also handle `vscode-remote` scheme URIs, resolving the relative path against the remote model URI rather than requiring a local `file` scheme.
