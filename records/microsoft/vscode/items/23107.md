# Issue #23107 — Allow to configure editor auto reload behaviour

[https://github.com/microsoft/vscode/issues/23107](https://github.com/microsoft/vscode/issues/23107)

## Summary

A real configuration gap remains on current main, and this 68-upvote Backlog request was explicitly reopened by a maintainer after reconsideration. The existing save-conflict setting covers overwriting at save time, not whether clean buffers reload automatically or prompt on external changes.

## Change summary

Allow users to configure how editors react when an open file changes on disk, including automatic reload, confirmation, preservation, or overwrite behavior.

## Best solution

Add an external-change policy around the stored working-copy reload path, with a non-blocking choice to reload or preserve the current buffer as dirty. The design should define interactions with dirty buffers, auto save, deleted files, and `files.saveConflictResolution` without weakening the default data-loss protections.
