# Issue #175121 — Fonts are gray/dimmed

[https://github.com/microsoft/vscode/issues/175121](https://github.com/microsoft/vscode/issues/175121)

## Summary

The dimmer foregrounds shown in the screenshot are intentional theme colors rather than a functional defect, and VS Code already exposes supported customization points and high-contrast themes for users who need darker text.

## Change summary

Make the default light theme use plain black text instead of lower-contrast gray text across workbench UI elements.

## Best solution

Keep the default theme behavior and direct users who need stronger contrast to built-in high-contrast themes or `workbench.colorCustomizations` for `foreground`, `descriptionForeground`, and `tab.inactiveForeground`.
