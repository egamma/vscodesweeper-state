# Issue #340232 — Agent Host should preserve and render MCP embedded resources and resource links

[https://github.com/microsoft/vscode/issues/340232](https://github.com/microsoft/vscode/issues/340232)

## Summary

Team-authored (and inherently protected from judgment closes) tracking issue describing a real, verified fidelity gap in the Copilot Agent Host adapter: MCP embedded resources and resource_link blocks are dropped instead of being rendered, unlike the Local Harness path. Work is explicitly blocked on an upstream SDK change, so this stays open as a tracked gap.

## Change summary

The Copilot Agent Host path flattens MCP embedded text resources into plain text and drops resource_link blocks entirely, losing URI/MIME/annotations/metadata that the Local Harness preserves and renders.

## Best solution

Keep tracking until github/copilot-sdk#2816 exposes the preserved typed MCP result; then extend appendSdkToolResultContent in src/vs/platform/agentHost/node/copilot/mapSessionEvents.ts to map embedded resources and resource_link into AHP tool-result content, coordinating with microsoft/agent-host-protocol#504 if AHP's resource types need extending, and update the test at mapSessionEvents.test.ts accordingly.
