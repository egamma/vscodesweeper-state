[https://github.com/microsoft/vscode/issues/340232](https://github.com/microsoft/vscode/issues/340232)

## Summary

Keep open: current main still flattens embedded text resources and drops resource links in the Copilot Agent Host mapper. The protocol discussion resolved the representation question, not this implementation gap, and explicitly identifies this issue as the remaining VS Code work.

## Change summary

Preserve MCP-generated artifacts as separately identifiable, readable resource outputs through the Copilot Agent Host harness.

## Best solution

Complete the existing AHP resource-reference path: embedded artifacts and MCP resource links should become separately displayed, lazily readable resources with meaningful filenames and content types. Follow the protocol maintainer's documented mapping rather than requiring lossless MCP metadata transport or new AHP types.
