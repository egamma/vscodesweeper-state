# Issue #245323 — Folder settings label not vertically aligned

[https://github.com/microsoft/vscode/issues/245323](https://github.com/microsoft/vscode/issues/245323)

## Summary

Still reproduces on main: the folder settings tab label in the settings editor header lacks vertical alignment for its flex children (title, details, dropdown icon).

## Change summary

The folder settings label in the settings editor header is not vertically aligned with its sibling elements.

## Best solution

Add `align-items: center` (or `baseline`) to the `.folder-settings` flex container in `src/vs/workbench/contrib/preferences/browser/media/settingsWidgets.css` and remove the manual `padding-top: 8px` on the dropdown icon that was compensating for the lack of alignment.
