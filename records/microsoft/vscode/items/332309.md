# Issue #332309 — Markdown editor: in "Open as Preview", Find is unreachable until the preview is clicked, and the Edit > Find menu never works

[https://github.com/microsoft/vscode/issues/332309](https://github.com/microsoft/vscode/issues/332309)

## Summary

Traced conclusively in the checkout: the new Markdown WYSIWYG editor's `registerCustomEditorProvider` call never sets `enableFindWidget: true`, so the built-in webview find command stays disabled and Edit > Find/Ctrl+F never opens it — a real gap, not user error, so this should be routed to the markdown area rather than closed.

## Change summary

In the Markdown 'Open as Preview' editor, Ctrl+F needs an extra click to work at all, and the Edit > Find menu item never opens Find.

## Best solution

Add `webviewOptions: { enableFindWidget: true }` to the `vscode.window.registerCustomEditorProvider(MarkdownEditorProvider.viewType, ...)` call in extensions/markdown-language-features/src/extension.shared.ts, matching how the classic preview panel already enables it in previewManager.ts/preview.ts; separately confirm whether the webview should also receive initial keyboard focus on open.
