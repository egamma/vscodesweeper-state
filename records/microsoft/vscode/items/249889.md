Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/186319 tracks the same observable problem—debug hovers are too constrained and cannot be resized. This report adds useful evidence about the current 550px width cap, which should be carried into the canonical discussion.

## Change summary
