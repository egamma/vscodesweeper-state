## Summary

Valid team-authored feature request for NES to consider error locations when manually triggered. No implementation found on main — the inlineEditTriggerer and nextEditProvider show no diagnostic/marker awareness for jump targets.

## Change summary

When manually triggering NES, it should look for next edit suggestions at the next error location even if further away from the cursor.
