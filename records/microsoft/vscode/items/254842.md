# Issue #254842 — Bug Report: Space Key Not Working When Assigned as Shortcut in VS Code

[https://github.com/microsoft/vscode/issues/254842](https://github.com/microsoft/vscode/issues/254842)

## Summary

This is as-designed: binding the Space key to a command means that key triggers the command instead of its default text-insertion action. This is fundamental keyboard-shortcut behavior, not a bug.

## Change summary

Assigning the Space key as a keyboard shortcut causes it to stop inserting spaces in the editor.

## Best solution

Close as designed — keybindings intentionally override default key behavior. The user should use a modifier combination (e.g., Ctrl+Space) or add a `when` clause (e.g., `!editorTextFocus`) to avoid overriding text input.
