# Issue #254842 — Bug Report: Space Key Not Working When Assigned as Shortcut in VS Code

[https://github.com/microsoft/vscode/issues/254842](https://github.com/microsoft/vscode/issues/254842)

## Summary

An active Space shortcut consumes text input through the normal keybinding dispatch path; a when clause can restrict it to contexts outside the editor. Keep this open for the keybindings owner to resolve the existing bug classification rather than proposing an as-designed close against accepted triage.

## Change summary

Preserve normal space insertion in the editor when Space is assigned to a command intended for use elsewhere.

## Best solution

Use the existing keybinding when clause to express where the shortcut should apply, preserving ordinary typing elsewhere. The keybindings owner should determine whether any remaining issue concerns shortcut-editing guidance rather than changing global dispatch semantics.

- **Proposed comment:**

  > Thanks for the report. A Space shortcut takes precedence over inserting a space wherever its “When” condition matches. To use it outside the editor while preserving spaces during code entry, set its “When” condition to `!editorTextFocus` in Keyboard Shortcuts. This excludes the editor, but not other text-input controls. Leaving this open for the keybindings owner to review the existing bug classification and whether the shortcut editor needs clearer guidance.
