## Change summary

Expose soft and hard repository reset operations through VS Code's Git UI.

## Best solution

Design a Git command that lets users select a target commit and reset mode, with explicit confirmation for destructive hard resets. The implementation belongs in the built-in Git extension's command registration and command handler.
