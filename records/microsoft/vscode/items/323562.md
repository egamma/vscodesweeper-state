# Issue #323562 — Sign in to use Copilot is no-op

[https://github.com/microsoft/vscode/issues/323562](https://github.com/microsoft/vscode/issues/323562)

## Summary

Valid bug with an open fix PR (#324609) — the model picker shows a 'Sign in' button that does nothing for users with cached entitlements. Keeping open pending the PR landing.

## Change summary

The model picker's 'Sign in to use Copilot' button is a no-op for users whose entitlement is cached (Free/Pro/EDU) but whose setup isn't marked complete, because the triggered command takes a silent no-op path for non-Unknown entitlements.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/324609 which scopes the sign-in affordance to only signed-out / sign-up users, eliminating the no-op state.
