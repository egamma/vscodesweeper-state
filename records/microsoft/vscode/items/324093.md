# Issue #324093 — Add a confirmation dialog with option to revert instead to "Git: Undo Last Commit" when last commit has been pushed

[https://github.com/microsoft/vscode/issues/324093](https://github.com/microsoft/vscode/issues/324093)

## Summary

The pushed-commit confirmation and revert alternative remain missing from the built-in Git command. Classify this as a feature request and route it to Git; the related graph-action request does not cover this command-specific safeguard.

## Change summary

When Undo Last Commit targets a pushed commit, offer confirmation with a history-preserving revert alternative.

## Best solution

Provide a pushed-commit-aware choice in the built-in Git undo workflow, preserving the existing undo behavior for unpublished commits. The Git owner should settle how publication is determined and how uncertain remote state is presented before implementation.
