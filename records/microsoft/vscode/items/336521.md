# Issue #336521 — 🐛 Copilot agent-host sessions: `#` cannot reference tools (parity gap with Local chat)

[https://github.com/microsoft/vscode/issues/336521](https://github.com/microsoft/vscode/issues/336521)

## Summary

Well-diagnosed parity gap, confirmed in source: agent-host chat sessions have no tool-completion provider and no `supportsToolAttachments` capability flag, so `#tool` completions never appear (unlike Local sessions). Routing to the chat/agent-host area for implementation.

## Change summary

Typing `#` in a Copilot agent-host chat session shows no tool completions, unlike Local sessions which do.

## Best solution

Add an `AgentHostToolCompletionProvider` (mirroring `AgentHostFileCompletionProvider` in src/vs/platform/agentHost/node/agentHostFileCompletionProvider.ts) registered alongside the other providers in agentHostContributions.ts, and set `supportsToolAttachments: true` in the agent-host session capabilities in agentHostChatContribution.ts once the provider exists.
