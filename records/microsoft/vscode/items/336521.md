# Issue #336521 — 🐛 Copilot agent-host sessions: `#` cannot reference tools (parity gap with Local chat)

[https://github.com/microsoft/vscode/issues/336521](https://github.com/microsoft/vscode/issues/336521)

## Summary

A real Agent Host parity gap remains on current main: its input-completion path deliberately replaces local completions but has no corresponding tool-reference provider or attachment mapping. Route this to the Agent Host/chat owners for a protocol and UX decision rather than closing it.

## Change summary

Provide `#tool` completions and tool-reference semantics in Copilot Agent Host sessions comparable to Local chat.

## Best solution

Define how tool references are represented across AHP, expose the appropriate session tool inventory through Agent Host completions, and preserve the selected tool reference when the message is sent. The result should match Local chat's observable `#tool` behavior without re-enabling unrelated in-process completion providers for Agent Host widgets.
