# Issue #143672 — Selecting a part in the layout picker should highlight it

[https://github.com/microsoft/vscode/issues/143672](https://github.com/microsoft/vscode/issues/143672)

## Summary

A real UX gap remains: the current Customize Layout picker indicates option state but does not highlight the corresponding workbench part. The accepted Backlog item already has the correct layout routing.

## Change summary

Highlight the corresponding workbench region when an item is focused in the Customize Layout picker.

## Best solution

Add transient workbench-part highlighting driven by active-item changes in `CustomizeLayoutAction`, with cleanup when focus changes or the picker closes.
