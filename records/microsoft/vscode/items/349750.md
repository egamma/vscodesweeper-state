# Issue #349750 — hide Quick access bar in window title

[https://github.com/microsoft/vscode/issues/349750](https://github.com/microsoft/vscode/issues/349750)

## Summary

The requested hide option already exists: disabling window.commandCenter removes the title-bar quick-access control and restores the text title.

## Change summary

Allow hiding the title-bar quick-access control to leave more room for dragging the window while retaining Ctrl+P.

## Best solution

Use the existing window.commandCenter setting or the title-bar context menu's Command Center toggle; no new capability is needed.
