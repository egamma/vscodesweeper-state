# Issue #210122 — Unable to operate other files in the file manager when having a png floating window

[https://github.com/microsoft/vscode/issues/210122](https://github.com/microsoft/vscode/issues/210122)

## Summary

Confirmed regression still present on main. The webview focus-polling hack from commit d4b4c327 (the `vscode-context-menu-visible` class check) causes a floating webview to falsely report itself as focused, stealing focus from the explorer and misdirecting context-menu operations. No fix has been committed.

## Change summary

Right-clicking a file in the explorer targets the wrong file when a PNG (webview-based custom editor) is open in a floating/auxiliary window.

## Best solution

The focus-tracking workaround in `src/vs/workbench/contrib/webview/browser/pre/index.html` (line 66) needs to be scoped so it doesn't falsely claim focus when the webview is in an auxiliary window and another window's explorer has focus. The fix should preserve the copy/cut fix from #206529 while not breaking cross-window focus. @mjbvz was tagged to investigate.
