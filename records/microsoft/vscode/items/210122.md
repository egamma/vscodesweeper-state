# Issue #210122 — Unable to operate other files in the file manager when having a png floating window

[https://github.com/microsoft/vscode/issues/210122](https://github.com/microsoft/vscode/issues/210122)

## Summary

The reported context-menu focus regression is addressed by a landed fix that stops unrelated context menus from marking every webview as focused. Current source retains that fix, supporting closure as completed.

## Change summary

With a PNG preview in a floating window, Explorer context-menu actions target the active file instead of the right-clicked file.

## Best solution

Treat this as resolved by commit 9e4f826b181b0e04c66a80b9e83e5fd6356cda4f, which confines context-menu focus tracking to the webview that actually opened the menu.
