# Issue #158271 — Make `IMarkerService#read` ignore unsupported schemes by default

[https://github.com/microsoft/vscode/issues/158271](https://github.com/microsoft/vscode/issues/158271)

## Summary

The debt remains: `IMarkerService#read` still does not filter unsupported schemes by default — callers (markersModel, markersTable, markersTreeViewer, MarkerStats) each manually check `unsupportedSchemas`, and a `// TODO this is a hack` comment at line 115 of markerService.ts confirms the intent is unfulfilled.

## Change summary

Move unsupported-scheme filtering into `IMarkerService#read` so callers don't each need to check manually.

## Best solution

Push the `unsupportedSchemas` check into `MarkerService.read()` (or the underlying iteration in `_read`), then remove the redundant per-caller checks in markersModel.ts, markersTable.ts, markersTreeViewer.ts, and MarkerStats._resourceStats — collapsing five filter sites into one.
