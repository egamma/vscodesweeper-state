# Issue #334099 — Agents window chat tab shortcuts override terminal tabs

[https://github.com/microsoft/vscode/issues/334099](https://github.com/microsoft/vscode/issues/334099)

## Summary

Confirmed in source: the chat-tab navigation keybindings in sessionsActions.ts only negate EditorAreaFocusContext, not terminal focus, so Cmd+Shift+[/] steals the shortcut from terminal tabs. An open PR already fixes this — best to land that rather than duplicate the work.

## Change summary

In the Agents window, Cmd+Shift+[ and Cmd+Shift+] switch chat tabs instead of terminal tabs when a terminal tab is focused.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/330095 ("Fix chat tab shortcuts in terminal"), which should scope the NavigateNextChatAction/NavigatePreviousChatAction keybindings in src/vs/sessions/contrib/sessions/browser/sessionsActions.ts to exclude terminal focus, consistent with how #332029 removed these shortcuts from session navigation.
