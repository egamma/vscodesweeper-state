# Issue #334099 — Agents window chat tab shortcuts override terminal tabs

[https://github.com/microsoft/vscode/issues/334099](https://github.com/microsoft/vscode/issues/334099)

## Summary

The shortcut conflict is present on current main, but an open PR already references and addresses this issue. Keep the issue open while that fix is reviewed.

## Change summary

In an Agents window with multiple chats, Cmd+Shift+[ and Cmd+Shift+] switch chat tabs instead of terminal groups while the terminal is focused.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330095, which scopes chat-tab shortcuts away from terminal focus and adds keybinding-resolution coverage for both focus states.
