# Issue #56719 — [npm] hover should show relevant latest version

[https://github.com/microsoft/vscode/issues/56719](https://github.com/microsoft/vscode/issues/56719)

## Summary

A real gap remains: the built-in npm hover still reports only the package's globally latest version, without considering the declared semver range. The request has no community upvotes and an extension workaround exists, so it should remain open for product discussion rather than be closed or prioritized.

## Change summary

Show the newest npm package version compatible with a dependency's declared `^`, `~`, or other semver range in the package.json hover.

## Best solution

If adopted in core, the npm package.json hover should preserve the globally latest version while also showing the highest published version satisfying the dependency's declared range. Maintainers should first decide whether this small npm workflow enhancement belongs in the built-in extension or should remain extension-provided.
