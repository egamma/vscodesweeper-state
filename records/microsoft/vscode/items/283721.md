# Issue #283721 — Linkify settings in chat

[https://github.com/microsoft/vscode/issues/283721](https://github.com/microsoft/vscode/issues/283721)

## Summary

A real gap remains: chat linkification handles files and symbols but not setting identifiers. This team-authored feature request should remain open for implementation.

## Change summary

Turn setting identifiers mentioned in chat responses into links that open the corresponding Settings UI entry.

## Best solution

Extend the Copilot response-linkification pipeline to recognize valid setting identifiers such as `editor.minimap.enabled` and open Settings with an exact-ID query, while leaving unrecognized inline code unchanged.
