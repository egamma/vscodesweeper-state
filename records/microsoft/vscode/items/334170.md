# Issue #334170 — Claude sessions never appear in Agent Sessions view — chat discovery race condition swallows "SDK not ready" as success

[https://github.com/microsoft/vscode/issues/334170](https://github.com/microsoft/vscode/issues/334170)

## Summary

The startup race remains in current main: Claude discovery treats an initially unavailable SDK as a successful, memoized discovery pass, so a later readiness transition can leave external sessions undiscovered. The issue should remain open as a source-confirmed bug.

## Change summary

Retry or re-trigger Claude external-session discovery when SDK readiness changes shortly after the initial startup probe.

## Best solution

Make the Claude discovery lifecycle tolerate a transient false readiness probe and enumerate sessions once the SDK becomes locally available, without causing discovery itself to download the SDK or changing download-consent behavior.
