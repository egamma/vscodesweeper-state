# Issue #325618 — Regression: Copilot Chat MCP fails on Dataverse server due to strict tool schema validation (array parameter missing items)

[https://github.com/microsoft/vscode/issues/325618](https://github.com/microsoft/vscode/issues/325618)

## Summary

Confirmed on current main by tracing the code: normalizeToolSchema throws on any single tool with an invalid schema (e.g. array without items), and every caller invokes it inline with no isolation, so one bad MCP tool definition aborts the entire chat request instead of being skipped.

## Change summary

A single MCP tool with an invalid JSON schema (array type missing items) causes Copilot Chat to fail entirely instead of just excluding that tool.

## Best solution

In extensions/copilot/src/extension/tools/common/toolSchemaNormalizer.ts, make the per-tool try/catch in normalizeToolSchema skip and warn (via onFix) on an invalid tool instead of re-throwing, so valid tools from the same MCP server remain usable — this directly delivers the two 'Expected Result' options in the report.
