# Issue #325618 — Regression: Copilot Chat MCP fails on Dataverse server due to strict tool schema validation (array parameter missing items)

[https://github.com/microsoft/vscode/issues/325618](https://github.com/microsoft/vscode/issues/325618)

## Summary

Keep open: current source still turns one tool's missing array items into a fatal failure of the entire tool-list normalization. Independent Dataverse and Kit confirmations support retaining this older report; the related report is newer and is not an eligible duplicate target.

## Change summary

Prevent an MCP tool with an array parameter lacking items from breaking chat requests and unrelated valid tools.

## Best solution

Keep valid tools and chat usable when a tool fails the missing-items restriction, with an explicit warning identifying the affected tool. Address this bounded failure-isolation defect in Copilot's tool schema normalization without broadly relaxing other schema validation.
