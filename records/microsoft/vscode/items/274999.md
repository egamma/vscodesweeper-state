# Issue #274999 — Make zero-based offsets the default?

[https://github.com/microsoft/vscode/issues/274999](https://github.com/microsoft/vscode/issues/274999)

## Summary

Zero-based navigation is available, but one-based offsets remain the default, so the requested default change is not implemented. Keep the existing under-discussion classification: the maintainer prefers the current default pending feedback, and the reporter's String.at comparison remains relevant to that decision.

## Change summary

Make character-offset navigation zero-based by default to match offsets supplied by debuggers and other tools.

## Best solution

Retain the persisted zero-based toggle while gathering evidence about offset-navigation workflows before deciding whether to change the default in AbstractGotoLineQuickAccessProvider. Treat this as a default-selection decision, not a missing navigation capability or a defect in line numbering.
