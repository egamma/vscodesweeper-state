# Issue #136241 — Decorations flickering on editor change

[https://github.com/microsoft/vscode/issues/136241](https://github.com/microsoft/vscode/issues/136241)

## Summary

Keep this accepted editor-API request open: current source still clears extension decorations when switching models, and the merged sample improvement only removes an artificial delay. With 41 upvotes and maintainer interest, the remaining persistence capability warrants consideration; no verified canonical owns the same editor-switch symptom.

## Change summary

Allow extension decorations to survive switching away from and back to an unchanged document without disappearing and being repainted.

## Best solution

Define an opt-in extension-decoration persistence contract that avoids repaint gaps while preserving editor-specific decorations and reliable cleanup. The editor-API owners should settle its lifetime and split-editor semantics; removing throttling from extension callbacks is only a partial mitigation.
