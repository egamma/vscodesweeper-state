# Issue #320882 — Use WebView2 instead of Electron V8 on the Windows platform.

[https://github.com/microsoft/vscode/issues/320882](https://github.com/microsoft/vscode/issues/320882)

## Summary

The same optional WebView2 runtime migration has been repeatedly declined, including an exact request closed as out of scope. VS Code remains tightly integrated with Electron, Chromium, and Node.js, and maintainers report that WebView2 would not inherently improve performance.

## Change summary

Allow Windows users to replace VS Code's Electron renderer with WebView2, optionally or by default.

## Best solution

Retain Electron as the unified desktop runtime and address measurable performance or rendering defects individually. Any future runtime migration should remain a project-wide architectural decision rather than a user-selectable Windows setting.

## Vision fit

- **Fit:** rejected
- **Reason:** A second platform-specific desktop runtime and configuration path conflicts with the goal of a lightweight product with uniform interactions, without an established performance benefit.
- **Evidence:** Public values: “Performance trumps functionality” and “Simple, uniform UI and UI interactions.”
