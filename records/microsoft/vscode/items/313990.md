# Issue #313990 — missing mechanism for setting default permissions for the "Copilot CLI" session created by hand off from "Local" session

[https://github.com/microsoft/vscode/issues/313990](https://github.com/microsoft/vscode/issues/313990)

## Summary

Implemented on current main: Copilot CLI and other agent-host sessions now have a dedicated default configuration setting whose approvals value is applied when the new session is created.

## Change summary

Provide a configurable default permission level for Copilot CLI sessions created by handing off a Local session.

## Best solution

Use the shipped `chat.defaultConfiguration.approvals` setting for new Copilot CLI sessions; keep `chat.permissions.default` scoped to Local sessions.
