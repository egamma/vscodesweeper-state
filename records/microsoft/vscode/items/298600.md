# Issue #298600 — Improve multiline text support in askQuestions tool in Copilot Chat

[https://github.com/microsoft/vscode/issues/298600](https://github.com/microsoft/vscode/issues/298600)

## Summary

The multiline-input gap remains on current main and no older canonical issue owns the same observable request. Keep it open and route it to the chat askQuestions area for a keyboard-interaction decision.

## Change summary

Allow askQuestions text answers and select-question freeform answers to accept, display, and scroll multiline content consistently.

## Best solution

Use a multiline control for text questions, preserve multiline paste and scrolling across all freeform fields, and establish consistent Enter/newline versus submit behavior without regressing keyboard accessibility.
