# Issue #212034 — Maximizing the current editor while in zen mode causes current editor group size toggle state to be lost

[https://github.com/microsoft/vscode/issues/212034](https://github.com/microsoft/vscode/issues/212034)

## Summary

Keep this open as the canonical report: the restore failure was confirmed during triage and a newer issue reports the same Zen Mode maximize/unmaximize symptom on VS Code 1.109.3. Current source still routes this sequence through interacting centered-layout and grid cached-size paths, with no issue-linked fix.

## Change summary

Unmaximizing an editor group while Zen Mode is active fails to restore the groups' custom sizes, leaving the active group expanded and the others collapsed or incorrectly resized.

## Best solution

Preserve the editor grid's pre-maximize group proportions across Zen Mode's centered-layout relayout, then restore those proportions when the group is unmaximized. Consolidate the newer https://github.com/microsoft/vscode/issues/295430 report into this older canonical issue.

- **Behavior:**

  > With multiple editor groups at custom unequal sizes, entering Zen Mode and toggling Maximize Editor Group on and off must restore every group's original proportions. Other groups must not remain collapsed, and Toggle Editor Group Sizes must not be needed to recover the layout. The behavior should match unmaximizing outside Zen Mode and should hold for nested row-and-column layouts.
- **Trace:**

  > The command reaches `EditorPart.toggleMaximizeGroup` in src/vs/workbench/browser/parts/editor/editorPart.ts, which delegates hiding and restoration to `GridView.maximizeView` and `exitMaximizedView` in src/vs/base/browser/ui/grid/gridview.ts. Grid restoration depends on cached visible sizes, and its existing unit test only covers maximize/unmaximize without an intervening outer relayout. Zen Mode activates centered layout in src/vs/workbench/browser/layout.ts; `CenteredViewLayout` in src/vs/base/browser/ui/centered/centeredViewLayout.ts resizes the wrapped editor view as dimensions change. The later https://github.com/microsoft/vscode/issues/295430 confirms that this interaction still changes split proportions. The investigation boundary is editor-grid sizing during centered Zen Mode; normal maximize restoration, non-Zen layouts, and the semantics of Toggle Editor Group Sizes must remain unchanged.
