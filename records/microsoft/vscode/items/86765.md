# Issue #86765 — [scss] provide hover for scss functions

[https://github.com/microsoft/vscode/issues/86765](https://github.com/microsoft/vscode/issues/86765)

## Summary

The capability remains missing on current main: VS Code delegates SCSS hover to vscode-css-languageservice, whose hover implementation does not handle function calls. Keep this open as an upstream language-service feature gap.

## Change summary

Show Sass function signatures and documentation when hovering over function calls in SCSS.

## Best solution

Add SCSS function hover support in microsoft/vscode-css-languageservice, with tests covering built-in Sass functions, then consume the updated language-service version in VS Code.
