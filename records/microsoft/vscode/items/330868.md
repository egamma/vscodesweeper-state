# Issue #330868 — Set Agents window as the default main window

[https://github.com/microsoft/vscode/issues/330868](https://github.com/microsoft/vscode/issues/330868)

## Summary

Keep open as a feature request: explicit Agents-window launch support exists, but it does not provide the persistent default requested here. No verified canonical or fixing commit was found.

## Change summary

Allow users to persistently select the Agents window as the default when launching VS Code or opening a workspace.

## Best solution

Decide whether ordinary application and workspace launches should honor an opt-in Agents-window preference, with explicit rules for existing-window restoration and file-opening behavior. Preserve the editor-first default for users who have not opted in.
