# Issue #230233 — Terminal search highlights update really slowly

[https://github.com/microsoft/vscode/issues/230233](https://github.com/microsoft/vscode/issues/230233)

## Summary

Keep open: delayed terminal-search highlights have a maintainer-confirmed reproduction, and no verified fix was found. Related search-performance reports do not establish a duplicate covering this report's live highlight-update symptom.

## Change summary

Terminal search highlights lag behind inserting or removing spaces before a matching word in the terminal command line.

## Best solution

Make active search highlights track terminal command-line edits promptly without introducing expensive full-buffer searches on every edit. Diagnose the buffer-change refresh path through the xterm search addon before deciding whether the correction belongs in VS Code integration or upstream.
