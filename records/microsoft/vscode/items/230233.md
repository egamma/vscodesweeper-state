# Issue #230233 — Terminal search highlights update really slowly

[https://github.com/microsoft/vscode/issues/230233](https://github.com/microsoft/vscode/issues/230233)

## Summary

Confirmed terminal search highlight perf issue, still unfixed on main. The bug was re-confirmed on stable 1.96.0 and no related fix commit has landed; keeping open.

## Change summary

Terminal find-in-terminal search highlights update very slowly when editing the search query (e.g. inserting/removing characters).

## Best solution

Investigate the xterm search addon's incremental highlight update path — the current flow in `terminalFindWidget.ts` calls `findPrevious` with `incremental: true` on each keystroke, which appears to re-scan and re-decorate the full scrollback. A debounce, virtualized decoration update, or an upstream xterm search addon optimization would address this. The fix likely touches `src/vs/workbench/contrib/terminalContrib/find/browser/terminalFindWidget.ts` and possibly the xterm `@xterm/addon-search` package.
