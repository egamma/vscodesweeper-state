# Issue #247149 — Links inside a VSCode Walkthrough description are not displayed in VS Code accessible view

[https://github.com/microsoft/vscode/issues/247149](https://github.com/microsoft/vscode/issues/247149)

## Summary

Confirmed on current main: the accessible view for walkthroughs intentionally filters out ILink nodes from the description, dropping all hyperlink text. This is a real accessibility gap with a clear fix location.

## Change summary

Links inside walkthrough step descriptions are not rendered in the VS Code accessible view, leaving blank gaps where link text should appear.

## Best solution

In `gettingStartedAccessibleView.ts` line 129, change the filter to include link labels (e.g. `typeof node === 'string' ? node : node.label`) so that link text appears in the accessible view content alongside the surrounding text.
