# Issue #303308 — Test results panel vertical/horizontal splitting

[https://github.com/microsoft/vscode/issues/303308](https://github.com/microsoft/vscode/issues/303308)

## Summary

Keep open: current Test Results layout controls swap left and right but cannot stack the panes above and below. The request has 25 upvotes and was accepted into Backlog; no verified canonical or linked open implementation PR was found.

## Change summary

Allow the Test Results output and test tree to stack vertically instead of always appearing side by side, particularly in a narrow sidebar.

## Best solution

Support a stacked layout in the Test Results view while retaining the existing side-by-side layout and tree-position control. Decide whether orientation is explicitly selected or adapts to available space before implementation.
