# Issue #277852 — Increase visual hierarchy of agent selection

[https://github.com/microsoft/vscode/issues/277852](https://github.com/microsoft/vscode/issues/277852)

## Summary

Valid team-authored UX feature request to color-differentiate chat modes (Agent, Ask, Plan, Edit, Custom) in the prompt area. Not yet implemented on main — the mode picker uses icons but no color-based visual hierarchy. Keeping open.

## Change summary

Color-code non-default chat mode selections (Ask/Plan/Edit in teal, Custom in purple) to prevent users from accidentally sending prompts to the wrong mode.

## Best solution

Implement foreground color differentiation in `modePickerActionItem.ts` (and possibly `chatInputPart.ts`) so that non-default mode selections stand out visually. This ties into the broader prompt-area redesign tracked in https://github.com/microsoft/vscode/issues/272502 — coordinate with that effort to avoid conflicting layouts.
