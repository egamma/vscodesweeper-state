# Issue #269258 — Can't trigger "changed 1 file" button with keyboard

[https://github.com/microsoft/vscode/issues/269258](https://github.com/microsoft/vscode/issues/269258)

## Summary

Current main substantially redesigned this control into a native button with a dedicated click handler, but the redesign does not reference this team-authored issue and no current keyboard verification covers Enter or Space. The team-authored protection therefore requires keeping it open until a maintainer verifies the behavior or links an explicit fix.

## Change summary

Keyboard activation of the chat file-changes button toggles the surrounding disclosure instead of opening the file changes.

## Best solution
