# Issue #307368 — Remote tunnel connection broken after each update

[https://github.com/microsoft/vscode/issues/307368](https://github.com/microsoft/vscode/issues/307368)

Keep open: the Windows service update/reconnection failure has not been demonstrated fixed. Tunnel hosting and readiness reporting have changed since the report, but the supplied Windows-host/macOS-client steps are sufficient to retest without requesting basic reproduction information.

## Change summary

Updating the Windows tunnel host and macOS client breaks reconnection until the Windows service is reinstalled, and the host can remain stuck displaying “Starting remote tunnel.”

## Best solution

Ensure Windows updates preserve a working tunnel service and allow the updated macOS client to reconnect without manual service reinstallation. Verify the separate startup-progress symptom against the current readiness implementation before treating either symptom as resolved.
