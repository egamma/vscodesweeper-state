# Issue #338776 — SCSS syntax highlighting misses scroll-state queries and scroll-driven animation properties

[https://github.com/microsoft/vscode/issues/338776](https://github.com/microsoft/vscode/issues/338776)

## Summary

Confirmed gap in the shared CSS grammar: modern scroll-driven-animation and container-query-related properties aren't in the property-names list SCSS reuses, so they render unhighlighted — a real, bounded grammar update.

## Change summary

SCSS syntax highlighting doesn't recognize scroll-state container queries or scroll-driven animation properties (view-timeline-*, animation-timeline, animation-range, scroll-timeline*).

## Best solution

Add the missing modern CSS property names (view-timeline-name, view-timeline-axis, view-timeline-inset, animation-timeline, animation-range, animation-range-start, animation-range-end, scroll-timeline, scroll-timeline-name, scroll-timeline-axis) to the property-names pattern in extensions/css/syntaxes/css.tmLanguage.json, which extensions/scss/syntaxes/scss.tmLanguage.json includes via `source.css#property-names`.
