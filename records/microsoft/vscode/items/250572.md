## Change summary

Continuous element selection in Live Preview remains visibly enabled but stops attaching elements after focus moves to Settings and returns.

## Best solution

Keep selection state synchronized with the Live Preview inspection session: when focus loss detaches the debugger, reset the active selection UI so it cannot advertise a nonfunctional picker.
