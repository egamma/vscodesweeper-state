# Issue #290605 — Don't hardcode agent sessions

[https://github.com/microsoft/vscode/issues/290605](https://github.com/microsoft/vscode/issues/290605)

## Summary

Keep open: current main still overrides contributed session metadata with provider-specific names, icons, and descriptions. The sessions-app work did not complete the main-window cleanup, as the author explicitly noted when reopening this issue.

## Change summary

Derive agent-session presentation and supported capabilities from contributions rather than hardcoded provider identities.

## Best solution

Make contributed metadata authoritative across the main-window session list, picker, hover, and continuation surfaces, so adding or renaming a contributed provider does not require matching presentation changes in core. Preserve intentional local-session behavior and existing routing, availability, and permission boundaries.
