# Issue #250925 — Text in a new file completely locks up VS Code

[https://github.com/microsoft/vscode/issues/250925](https://github.com/microsoft/vscode/issues/250925)

## Summary

The reporter themselves traced the freeze to Windows (the 'Beta: Use Unicode UTF-8 for worldwide language support' region setting) rather than VS Code, and a team member could not reproduce it on macOS or Windows 11 — so this can be closed as not reproducible.

## Change summary

Typing/pasting a string containing the 🕹️ emoji into an untitled file made VS Code lock up when closing the tab on Windows 11 24H2.

## Best solution

Close as not reproducible: the hang is an OS-level issue tied to the Windows UTF-8 beta region setting (it also froze Windows Explorer with the same emoji in a file name), not a defect in VS Code's code.
