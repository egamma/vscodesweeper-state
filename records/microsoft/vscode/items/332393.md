- **Behavior:**

  > An MCP server that is loaded and available to the Copilot harness should be discoverable when the user types its matching # reference prefix. Accepting a suggestion should produce a usable reference to the intended MCP tool or server, without requiring the user to memorize its full name. Verify the reported apple-developer-docs case in both harnesses and preserve existing file and chat references.
- **Trace:**

  > ToolCompletions in src/vs/workbench/contrib/chat/browser/widget/input/editor/chatInputCompletions.ts deliberately returns no suggestions for agent-host-backed widgets; Local instead enumerates enabled selected tools and toolsets. AgentHostInputCompletions delegates completion requests through the chat session service to AgentHostCompletions. Inspected host providers cover files, chats, skills, and slash commands, rather than MCP tool references. The trace has not established how session-specific SDK tool metadata should become reference suggestions or how accepted tool references are consumed by CopilotAgentSession, so this requires planning across the completion and request boundaries. Preserve host-owned discovery, existing tool permissions, and Local behavior. Coordinate with https://github.com/microsoft/vscode/issues/340041; https://github.com/microsoft/vscode/issues/330764 describes a separate toolset-range attribution defect.
