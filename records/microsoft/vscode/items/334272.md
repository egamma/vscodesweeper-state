# Issue #334272 — Chat: Plugins command does nothing in the Agents window

[https://github.com/microsoft/vscode/issues/334272](https://github.com/microsoft/vscode/issues/334272)

## Summary

Confirmed from source: the shared `Chat: Plugins` command opens the classic Extensions viewlet, which the Agents window never registers, so it silently no-ops there. Still open, no fix on main; keeping open with a concrete implement-ready trace.

## Change summary

Running `Chat: Plugins` (workbench.action.chat.managePlugins) in the Agents window does nothing.

## Best solution

In the Agents window, `ManagePluginsAction` should open the existing `AICustomizationManagementEditor` on its Plugins section (as `src/vs/sessions/contrib/sessions/browser/customizationsToolbar.contribution.ts` already does) instead of calling the classic Extensions viewlet search.
