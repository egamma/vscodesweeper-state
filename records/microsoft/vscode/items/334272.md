# Issue #334272 — Chat: Plugins command does nothing in the Agents window

[https://github.com/microsoft/vscode/issues/334272](https://github.com/microsoft/vscode/issues/334272)

## Summary

Traced on main: `Chat: Plugins` (workbench.action.chat.managePlugins) always opens the Extensions viewlet, which is never registered in the Agents window, so the command silently no-ops there — matches the report exactly.

## Change summary

Running the `Chat: Plugins` command from the Agents window has no visible effect.

## Best solution

In ManagePluginsAction.run (src/vs/workbench/contrib/chat/browser/actions/chatPluginActions.ts), branch on IsSessionsWindowContext and route to the Agents window's own customizations entry point (sessions.customization.overview / OPEN_CUSTOMIZATIONS_COMMAND_ID) instead of IExtensionsWorkbenchService.openSearch, which depends on the Extensions viewlet that only the full workbench registers.
