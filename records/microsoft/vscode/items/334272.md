# Issue #334272 — Chat: Plugins command does nothing in the Agents window

[https://github.com/microsoft/vscode/issues/334272](https://github.com/microsoft/vscode/issues/334272)

## Summary

The defect remains on current main: `Chat: Plugins` always invokes an Extensions search, even though the Agents window provides a dedicated Plugins section in the Customizations editor. The source path is confirmed and bounded enough for a focused fix.

## Change summary

Make the `Chat: Plugins` command open the Plugins customization UI when invoked from the Agents window while preserving its existing behavior in the regular workbench.

## Best solution

Route the command according to `IAICustomizationWorkspaceService.isSessionsWindow`: open the Plugins section through `AICustomizationManagementCommands.OpenEditor` in the Agents window and retain the existing `@agentPlugins` Extensions search elsewhere.
