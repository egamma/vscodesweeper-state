# Issue #334272 — Chat: Plugins command does nothing in the Agents window

[https://github.com/microsoft/vscode/issues/334272](https://github.com/microsoft/vscode/issues/334272)

## Summary

Confirmed in source: `Chat: Plugins` (`ManagePluginsAction` in chatPluginActions.ts) always calls `IExtensionsWorkbenchService.openSearch('@agentPlugins ')`, which opens the classic Extensions viewlet — a view container that does not exist in the Agents window. `openSearch` silently no-ops (`ExtensionsWorkbenchService#openSearch: extension view pane container was not available`), matching the reported "no visible effect".

## Change summary

Running the `Chat: Plugins` command from the Command Palette while in the Agents window does nothing instead of opening a plugins UI.

## Best solution

In `ManagePluginsAction.run` (src/vs/workbench/contrib/chat/browser/actions/chatPluginActions.ts), branch on `IWorkbenchEnvironmentService.isSessionsWindow` and route to `AICustomizationManagementCommands.OpenEditor` with `AICustomizationManagementSection.Plugins` (the same mechanism already used elsewhere, e.g. chatSlashCommands.ts) instead of `IExtensionsWorkbenchService.openSearch`, which only works in the core workbench window.
