# Issue #334662 — Agent Merge is not initiated for all PRs created against different base branches in one session

[https://github.com/microsoft/vscode/issues/334662](https://github.com/microsoft/vscode/issues/334662)

## Summary

Keep open: current main still models one Agent Merge target per working folder, so two pull requests from different branches in the same folder cannot be monitored concurrently. The member-authored report leaves a product decision between multi-PR support and an explicit single-PR selection experience.

## Change summary

Support Agent Merge for multiple pull requests created from one session, or clearly identify and allow selection of the single managed pull request.

## Best solution

Define the Agent Merge ownership contract per pull request rather than implicitly per current folder branch, then either support concurrent targets or expose an explicit selected-PR control and clearly communicate the one-target limitation.
