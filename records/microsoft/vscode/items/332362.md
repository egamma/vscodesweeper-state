## Change summary

The 'Sandboxing for terminal' standalone toggle switch in the agents-window permission picker visually pokes outside the top/bottom border of its containing row.

## Best solution

Fix the CSS for the inline pill switch used by standalone toggles (`.action-list-item-inline-toggle .monaco-custom-toggle.action-list-inline-switch` and the `.has-standalone-toggle` row rules) in src/vs/platform/actionWidget/browser/actionWidget.css so the 16-18px switch is fully contained within the 24px action row instead of overflowing its border, then verify against the existing permissionPickerList component fixture.
