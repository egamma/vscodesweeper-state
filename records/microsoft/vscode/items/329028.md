## Summary

A well-scoped, team-authored organizational-cleanup task to move reusable terminal auto-approval helpers from the workbench layer into `vs/platform/terminal/common/autoApprove` so both workbench and Agent Host can share them — the work is still open on main and follows directly from recent related PRs.

## Change summary

Audit runInTerminalHelpers.ts and related terminal auto-approval code, moving pure/shared logic to a lower platform layer and renaming ambiguous helpers, without changing workbench policy/UI/localization.
