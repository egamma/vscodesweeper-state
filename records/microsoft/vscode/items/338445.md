# Issue #338445 — Terminal created with `location: { parentTerminal }` is not split when parent has a numeric ID

[https://github.com/microsoft/vscode/issues/338445](https://github.com/microsoft/vscode/issues/338445)

## Summary

Confirmed on current main: `_deserializeParentTerminal` only matches parent terminals via their temporary UUID string key, never numeric instance IDs, so splits silently fall back to a new group. An open PR already targets this exact fix, so this should stay open pending review of that PR.

## Change summary

`vscode.window.createTerminal({ location: { parentTerminal } })` fails to split when the parent terminal has a numeric (opened/restored) ID instead of a temporary UUID.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/338451, which should make `_deserializeParentTerminal` resolve numeric IDs the same way `_getTerminalInstance` already does (falling back to `_terminalService.getInstanceFromId` when the id isn't a string).
