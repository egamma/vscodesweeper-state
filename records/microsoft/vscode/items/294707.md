# Issue #294707 — "Scroll to Previous Command" and "Scroll to Next Command" not working the same way as their keyboard shortcut equivalents

[https://github.com/microsoft/vscode/issues/294707](https://github.com/microsoft/vscode/issues/294707)

## Summary

Still reproduces on main: the ScrollToPreviousCommand action handler does not call `activeInstance.focus()` after scrolling, unlike ScrollToNextCommand — when invoked via menu (which steals focus), subsequent mark navigation breaks because the viewport tracking logic in the mark tracker gets out of sync.

## Change summary

Using 'Scroll to Previous Command' and 'Scroll to Next Command' from the terminal menu behaves differently from their keyboard shortcut equivalents, with navigation getting 'trapped'.

## Best solution

Add `activeInstance.focus()` to the ScrollToPreviousCommand action handler (line 897 of terminalActions.ts) to match the ScrollToNextCommand handler's behavior, ensuring focus returns to the terminal after menu-triggered navigation.
