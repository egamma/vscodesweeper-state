# Issue #236671 — Formatting changes ending on \r result in an extra new line

[https://github.com/microsoft/vscode/issues/236671](https://github.com/microsoft/vscode/issues/236671)

## Summary

The bug remains source-reproducible on current main and should stay open under editor-textbuffer. The first fix covered direct model edits but not the actual formatting pipeline, and the reporter confirmed the problem persisted before the issue was reopened.

## Change summary

Formatting a CRLF document with an LSP edit whose replacement ends in a lone carriage return inserts an unintended blank line.

## Best solution

Preserve the replacement's intended CRLF-boundary semantics through formatting's minimal-edit computation, with an end-to-end regression test that passes the reported edit through the worker and applies its result to the text model.

- **bypassed safeguard:** src/vs/editor/common/model/textModel.ts::_validateEditOperation only strips replacement text that still ends in a lone carriage return.
