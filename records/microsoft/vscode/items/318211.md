# Issue #318211 — [Insiders] BYOK not showing reasoning tokens in chat

[https://github.com/microsoft/vscode/issues/318211](https://github.com/microsoft/vscode/issues/318211)

## Summary

The reported issue — reasoning tokens streamed in `delta.reasoning` not being shown — was fixed three days after this report by adding `reasoning` (and `reasoning_content`) field support to the thinking-delta extraction pipeline. The fix shipped in 1.123.0.

## Change summary

BYOK models streaming reasoning tokens in `choices[0].delta.reasoning` (e.g. llama-cpp, OpenRouter) did not display thinking/reasoning text in Copilot Chat.

## Best solution

Keep the shipped fix (commit a21f814cede); no further change needed. The reporter should update to VS Code 1.123.0+ where reasoning deltas from `delta.reasoning` are extracted and displayed.
