# Issue #282167 — SCM - Include dynamic information in custom instructions

[https://github.com/microsoft/vscode/issues/282167](https://github.com/microsoft/vscode/issues/282167)

## Summary

Keep open for a focused decision on dynamic instruction values. Current commit generation includes the branch name, but it does not expand instruction placeholders, and its system rules still tell the model to remove issue references.

## Change summary

Allow commit-generation instructions to use current workspace information, especially extracting a Jira ticket prefix from the selected repository's branch name.

## Best solution

Make branch-derived ticket prefixes reliably usable through commit-generation instructions without requiring checkout hooks or settings rewrites. Decide whether existing repository context is the supported contract or whether explicit dynamic placeholders are needed, and ensure commit-format guidance is consistent with that contract.
