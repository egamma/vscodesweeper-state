# Issue #282102 — Installing an MCP server from a web registry fails silently when a MCP registry policy is set

[https://github.com/microsoft/vscode/issues/282102](https://github.com/microsoft/vscode/issues/282102)

## Summary

The silent failure remains on current main: a by-name MCP deep link that cannot be resolved from the configured registry returns as handled after writing only to the log. The maintainer-confirmed error-notification work should remain open.

## Change summary

Show an actionable error when an MCP install deep link names a server that the policy-configured registry cannot resolve.

## Best solution

Have the MCP workbench deep-link flow notify the user when the active registry cannot resolve the requested server, while preserving the policy boundary that prevents fallback to another registry.
