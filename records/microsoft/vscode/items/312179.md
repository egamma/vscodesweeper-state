# Issue #312179 — Allow folders with skills shipped via extensions to be read without user confirmations

[https://github.com/microsoft/vscode/issues/312179](https://github.com/microsoft/vscode/issues/312179)

## Summary

Verified duplicate: the older open canonical issue tracks scoped approval for skill tool calls and explicitly documents the same symptom—extension-contributed skills repeatedly prompting when reading bundled auxiliary files.

## Change summary

Allow an extension to mark its bundled skill directory as trusted so read_file can access skill resources without repeated confirmation.

## Best solution

Consolidate the permission design in https://github.com/microsoft/vscode/issues/293276, including its proposed extension-scoped trust for read-only access to files beneath an installed extension's own directory.
