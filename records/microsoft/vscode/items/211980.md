# Issue #211980 — Offering When Clause context for snippet activation

[https://github.com/microsoft/vscode/issues/211980](https://github.com/microsoft/vscode/issues/211980)

## Summary

The accepted Backlog request remains necessary: current main supports language, path, and file-glob filtering, but not context-key-controlled snippet contributions. Its 25 community upvotes also exceed the backlog threshold.

## Change summary

Allow extension-contributed snippet files to use a `when` clause for conditional availability.

## Best solution

Extend the snippets contribution schema and service in `src/vs/workbench/contrib/snippets/browser/snippetsService.ts` to evaluate an optional context-key expression and refresh availability when relevant context changes.

- **Reason:** This strengthens the extension contribution model while avoiding separate extensions or additional built-in UI for each framework version.
