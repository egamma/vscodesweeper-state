## Change summary

Background agent session fails silently in the UI without showing the underlying error message; users must resume in integrated terminal to discover the error.

## Best solution

Ensure that when a background agent session terminates with an error, the error message (or a meaningful summary) is surfaced in the session UI — either in the session details panel or as a notification. The rich error forwarding infrastructure (src/vs/platform/agentHost/node/shared/forwardedChatError.ts) may already cover API-level errors; this likely needs coverage for agent process-level failures too.
