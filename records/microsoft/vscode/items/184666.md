# Issue #184666 — Toggle line comment doesn't work for multiple lines in CSS

[https://github.com/microsoft/vscode/issues/184666](https://github.com/microsoft/vscode/issues/184666)

## Summary

Keep open: the current line-comment fallback still removes delimiters belonging to two separate CSS comments, producing invalid CSS. The verified older related requests concern comment style, not this corruption symptom, so they do not meet the stronger duplicate bar for a re-reviewed issue.

## Change summary

Toggling line comments across separately commented CSS declarations removes the first opening delimiter and the last closing delimiter, leaving unmatched comment tokens.

## Best solution

Make Toggle Line Comment correctly uncomment the selected, independently commented CSS declarations without leaving unmatched delimiters. Preserve the existing whole-block behavior for ordinary selections; the optional line-by-line commenting style remains separate work.

In src/vs/editor/contrib/comment/browser/lineCommentCommand.ts, _gatherPreflightCommentStrings therefore returns null and getEditOperations calls _executeBlockComment.
