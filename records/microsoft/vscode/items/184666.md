# Issue #184666 — Toggle line comment doesn't work for multiple lines in CSS

[https://github.com/microsoft/vscode/issues/184666](https://github.com/microsoft/vscode/issues/184666)

## Summary

Verified duplicate: the older open CSS-specific issue already tracks making Toggle Line Comment apply block-comment tokens line by line, which fully covers the requested behavior and avoids the nested-token corruption demonstrated here.

## Change summary

Make Toggle Line Comment process each selected CSS line independently instead of wrapping the whole selection in one block comment.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/166944 and account there for this report's important case: toggling several already-commented CSS lines must not leave unmatched comment delimiters.
