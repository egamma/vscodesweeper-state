# Issue #337026 — Open Agents Window from WSL Dev Container doesn't work well

[https://github.com/microsoft/vscode/issues/337026](https://github.com/microsoft/vscode/issues/337026)

## Summary

The WSL Dev Container handoff remains broken on current main: its UNC source path is classified as a desktop file workspace, so the Agents Window selects the local provider instead of the originating WSL workspace. This team-authored On Deck issue should remain open for a focused fix.

## Change summary

Opening the Agents Window from a Dev Container running on WSL fails to preserve the source workspace, which also makes the files list incorrect.

## Best solution

Preserve the WSL distribution, Linux source path, and Dev Container preference when translating the editor workspace into the Agents Window handoff, while retaining current behavior for local, SSH, Tunnel, volume-backed, and invalid Dev Container authorities.
