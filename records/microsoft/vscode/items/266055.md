# Issue #266055 — Add Support for Image Generation in GitHub Copilot Responses for Game Assets and Scenes

[https://github.com/microsoft/vscode/issues/266055](https://github.com/microsoft/vscode/issues/266055)

## Summary

Keep open: native image generation for Copilot is accepted backlog work with active implementation and upstream-runtime dependencies. Current main supports generated-image rendering and Codex generation, but the central Copilot subscription workflow is not yet fully available.

## Change summary

Allow Copilot chat to generate visual assets, display them in responses, and save them into a project.

## Best solution

Complete the native Copilot runtime integration in https://github.com/microsoft/vscode/pull/337624 and its upstream runtime counterpart, then expose generated assets through the existing preview and Save experience. The separate BYO Microsoft MAI prototype in https://github.com/microsoft/vscode/pull/335735 may remain an optional provider path rather than replacing native Copilot support.

## Evidence

- **active native implementation:** Draft https://github.com/microsoft/vscode/pull/337624 maps Copilot runtime image-generation events into durable chat results and depends on an active upstream runtime counterpart; it remains open, so the issue must not be closed before that work lands.
- **current partial support:** Merged https://github.com/microsoft/vscode/pull/330247 added image generation for the Codex agent host and the current source renders `image_gen.imagegen` results through src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/stateToProgressAdapter.ts and src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/chatGeneratedImageResultSubPart.ts. Its validation explicitly found that Copilot-subscription models did not expose the image-generation tool, so it does not complete this request.
- **alternative provider work:** Draft https://github.com/microsoft/vscode/pull/335735 adds a user-configured Microsoft MAI endpoint, preview, Save, and persistence, but explicitly does not enable native image generation on the conversational model or include generation in Copilot usage.
