# Issue #329146 — Go to Symbol in Editor: fuzzy-match the query against a symbol's full ancestor path (e.g. `prod port` → `production.server.port`)

[https://github.com/microsoft/vscode/issues/329146](https://github.com/microsoft/vscode/issues/329146)

## Summary

The requested ancestor-path matching remains absent from current main, and the reviewed related issues do not own this capability. Keep it open as under-discussion for the feature-request process; inactivity and zero upvotes do not establish a closing reason.

## Change summary

Allow Go to Symbol in Editor to distinguish repeated symbol names using ordered fuzzy queries against their full ancestor paths.

## Best solution

Provide ancestor-aware matching and highlighted ancestor descriptions in the editor symbol picker, preserving whole-label matches and deliberately addressing compatibility with existing leaf-first container queries. Separator syntax and Outline filtering can remain separate follow-up scope.
