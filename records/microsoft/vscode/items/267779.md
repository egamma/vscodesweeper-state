# Issue #267779 — Edits should be presented in order

[https://github.com/microsoft/vscode/issues/267779](https://github.com/microsoft/vscode/issues/267779)

## Summary

Keep open: current source still selects the next edit relative to the cursor after keeping a clicked change, rather than relative to that change. The discussion leaves this navigation policy unsettled, and the existing reveal setting does not provide the requested ordering.

## Change summary

After keeping an individual Copilot change, reveal the next pending change after the accepted change even when the cursor is elsewhere.

## Best solution

Make change-by-change review advance predictably from the change the user resolved, while preserving cursor-relative behavior for explicit next/previous navigation. Confirm that interaction distinction with the area owner before implementation.
