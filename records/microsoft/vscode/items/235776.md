## Change summary

After toggling terminal size to content width (Alt+Z), the vertical scrollbar renders in the wrong position when scrolling down.

## Best solution

Fix the vertical scrollbar position in the toggle-size-to-content-width flow in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts`. This likely requires triggering an xterm layout refresh or manually adjusting the viewport element's position after the resize completes.
