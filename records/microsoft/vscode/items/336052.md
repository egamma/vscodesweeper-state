# Issue #336052 — Reopen with... does not appear for untitled files when a custom editor is opened

[https://github.com/microsoft/vscode/issues/336052](https://github.com/microsoft/vscode/issues/336052)

## Summary

Traced on main: `getAvailableEditorIds` deliberately zeroes out available editor ids (and thus hides Reopen With...) for any untitled-scheme editor whose editorId isn't the default text editor, which explains exactly the reported symptom. It's filed by a team member as a bug, and the guardrail comment suggests intentional design tension rather than an obvious defect, so this needs a maintainer call on whether/how to relax it — not a mechanical close.

## Change summary

The 'Reopen Editor With...' command/menu item is missing when an untitled resource is currently opened in a custom (non-default) editor.

## Best solution

In src/vs/workbench/common/contextkeys.ts, getAvailableEditorIds() explicitly returns [] for untitled + non-default editorId, citing serialization concerns across extensions; a maintainer should decide whether Reopen With can still be surfaced safely in this case (e.g. only disabling actual reopen-with-serialization rather than hiding the whole affordance), then adjust getAvailableEditorIds accordingly.
