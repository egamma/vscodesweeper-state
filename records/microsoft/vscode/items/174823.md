# Issue #174823 — Workspace Trust - should be made accessible more easily.

[https://github.com/microsoft/vscode/issues/174823](https://github.com/microsoft/vscode/issues/174823)

## Summary

Keep open: trusted workspaces still lack the persistent, discoverable entry point requested here. The existing command opens the page, but requires knowing what to search for—the friction this request explicitly describes.

## Change summary

Make Workspace Trust management discoverable from a stable UI entry point even after a workspace becomes trusted.

## Best solution

Consider a Workspace Trust entry in the Manage/settings menu that opens the existing editor without changing trust. Preserve the Restricted Mode status-bar indicator's warning-only purpose unless the area owner explicitly chooses a different design.
