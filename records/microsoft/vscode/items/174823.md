# Issue #174823 — Workspace Trust - should be made accessible more easily.

[https://github.com/microsoft/vscode/issues/174823](https://github.com/microsoft/vscode/issues/174823)

## Summary

Valid feature request — the statusbar shield is intentionally hidden once a workspace is trusted, making the Workspace Trust editor harder to rediscover. The request for a persistent entry point (statusbar item or menu entry) remains unaddressed on current main. Already labeled under-discussion in Backlog.

## Change summary

Request a persistent UI entry point (status bar icon or menu item) to access the Workspace Trust editor even when the workspace is already trusted.

## Best solution

Add a configurable statusbar item or menu entry that remains visible in trusted workspaces, linking to the Manage Workspace Trust editor. The change would be in `src/vs/workbench/contrib/workspace/browser/workspace.contribution.ts` — specifically the `updateStatusbarEntry` method which currently clears the entry on trust. However, this is a UX/design decision that needs maintainer input on whether always-visible trust UI is desirable vs. the current minimal approach.
