# Issue #284514 — new workspace with `.` char

[https://github.com/microsoft/vscode/issues/284514](https://github.com/microsoft/vscode/issues/284514)

## Summary

Keep open: current source rejects the exact dot-root file tree shown in the report before generating a workspace preview. This team-authored, accepted bug remains necessary; supporting a root marker requires distinguishing it from a literal directory name.

## Change summary

Copilot workspace scaffolding cannot process a project tree whose root is represented by a single dot.

## Best solution

Support the dot as a logical project-root marker throughout Copilot's preview and creation flow, without weakening validation of actual file and directory names. Agree on destination selection and existing-file handling before implementing creation into an existing directory.
