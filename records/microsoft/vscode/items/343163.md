# Issue #343163 — Agents Window: PR/review polling continues every minute after persistent 403/404 responses

[https://github.com/microsoft/vscode/issues/343163](https://github.com/microsoft/vscode/issues/343163)

## Summary

The reported failure-amplification path remains present in current main: retained PR models reschedule every minute after persistent access or missing-resource failures. Keep this open; the retry and recovery policy needs a bounded product decision before implementation.

## Change summary

Prevent inaccessible pull requests from repeatedly fetching metadata and reviews at the normal successful-polling cadence while preserving recovery.

## Best solution

Give the Sessions GitHub PR model a bounded, recoverable polling policy for persistent authorization and not-found failures. Preserve successful polling, explicit refresh, account/resource recovery, shared ownership, and cancellation.
