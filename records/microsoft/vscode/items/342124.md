# Issue #342124 — Allow extensions to hide individual editor groups via `vscode.setEditorLayout`

[https://github.com/microsoft/vscode/issues/342124](https://github.com/microsoft/vscode/issues/342124)

## Summary

The requested extension-facing capability is missing: current layout commands cannot independently hide one editor group while preserving the others. Keep this open for an API-scope decision; the cited earlier UI requests do not establish that this narrower extension point was declined.

## Change summary

Expose individual editor-group visibility through vscode.setEditorLayout and vscode.getEditorLayout while preserving hidden groups' editors and layout state.

## Best solution

Have the editor-layout owner decide whether independent group visibility should become part of the layout command contract. If accepted, let extensions supply the interaction without adding built-in UI, with explicit round-trip, activation, and all-hidden semantics.
