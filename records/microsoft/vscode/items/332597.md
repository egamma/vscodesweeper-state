# Issue #332597 — Expose `turnId` to `LanguageModelChatProvider.provideLanguageModelChatResponse()`

[https://github.com/microsoft/vscode/issues/332597](https://github.com/microsoft/vscode/issues/332597)

## Summary

Keep open: current provider options still lack a documented, stable user-turn identifier. The older session-identity requests do not establish the same turn-scoped contract, and this Backlog Candidates item should continue through the community process.

## Change summary

Expose an optional user-turn identifier to language model providers that remains stable across tool continuations and changes for the next user turn.

## Best solution

Define a supported turn-correlation contract at the language model provider boundary, distinct from conversation identity and individual model-request identity. Specify its availability for direct API calls, background requests, and subagents before adopting it as a public API.
