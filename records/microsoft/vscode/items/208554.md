# Issue #208554 — Disable multi selection for notebook outline view

[https://github.com/microsoft/vscode/issues/208554](https://github.com/microsoft/vscode/issues/208554)

## Summary

Keep open: notebook outlines already disable gesture-based multi-selection, but entries from the same cell share an identity, allowing selection restoration to select several entries. The linked PR was closed without merging and did not address this behavioral path.

## Change summary

Make notebook outline selection remain single-entry, consistent with text-file outlines.

## Best solution

Ensure notebook outline entries are independently identifiable so selection and focus survive tree restoration without spreading to other entries from the same cell. Preserve the existing single-selection interaction policy and notebook navigation behavior.
