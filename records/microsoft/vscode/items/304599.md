# Issue #304599 — Inline affordance queue's prompts rather than sending to new chat sessions

[https://github.com/microsoft/vscode/issues/304599](https://github.com/microsoft/vscode/issues/304599)

## Summary

Keep open: Explain still submits into the existing panel session, and the discussion explicitly supports giving independent Explain and Review actions their own sessions. Current inline-to-panel continuation already creates a new session, so the remaining work needs to distinguish independent actions from contextual Ask in Chat.

## Change summary

Start independent inline-affordance Explain and panel-directed Review requests in separate sessions rather than queueing them behind an unrelated running chat.

## Best solution

Make independent panel-directed actions start their own conversations without interrupting or adding prompts to an existing session. Preserve contextual Ask in Chat routing to the session that owns the file changes, and establish whether any current Review path still requires panel-session isolation.
