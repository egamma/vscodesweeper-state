# Issue #321712 — Add a font family setting for code blocks in Markdown Preview

[https://github.com/microsoft/vscode/issues/321712](https://github.com/microsoft/vscode/issues/321712)

## Summary

Custom preview CSS already allows an independent code-block font, but the requested dedicated setting remains absent. Keep this under discussion: an earlier maintainer response preferred CSS over additional styling settings, while this report supplies a specific CJK alignment rationale for reconsideration.

## Change summary

Add a Markdown Preview code-block font-family setting independent of editor fonts and preview prose fonts.

## Best solution

Retain custom CSS as the supported solution unless the Markdown maintainer accepts the CJK alignment case as sufficient justification for a dedicated setting. Resolve that product decision before implementation; changing editor.fontFamily is not an equivalent solution.

  > Thanks for explaining the CJK alignment use case.
