# Issue #321712 — Add a font family setting for code blocks in Markdown Preview

[https://github.com/microsoft/vscode/issues/321712](https://github.com/microsoft/vscode/issues/321712)

## Summary

Legitimate feature request for a separate font-family setting for code blocks in Markdown Preview. No existing setting covers this — `markdown.preview.fontFamily` controls the body text, while code blocks inherit `--vscode-editor-font-family`. No duplicate found.

## Change summary

Allow users to configure a separate font family for code blocks in the Markdown Preview, independent of `editor.fontFamily` and `markdown.preview.fontFamily`.

## Best solution

Add a `markdown.preview.codeFontFamily` setting in the markdown-language-features extension. Register it in `package.json`, read it in `previewConfig.ts`, pass it as a CSS variable (e.g. `--markdown-code-font-family`) in `documentRenderer.ts`, and consume it in `markdown.css` on the `code` selector (line 405) with a fallback to the current `--vscode-editor-font-family` default.
