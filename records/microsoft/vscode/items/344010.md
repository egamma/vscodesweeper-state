# Issue #344010 — Voice Mode cannot reject a permission by saying the displayed “Skip” action

[https://github.com/microsoft/vscode/issues/344010](https://github.com/microsoft/vscode/issues/344010)

## Summary

Keep open as voice-interaction polish: current source confirms that the displayed “Skip” action is not a supported spoken rejection phrase. The router already supplies approve/reject clarification, but whether that guidance reaches the user reliably in the reported live flow remains unverified.

## Change summary

Make spoken rejection discoverable and consistent with the permission card’s displayed “Skip” action in GPT Live Voice Mode.

## Best solution

Align the permission card and Voice Mode’s rejection vocabulary, either through an explicit supported rejection alias or clear spoken guidance. Preserve deterministic phrase matching, pending-request identity checks, and the distinction between rejecting a tool and skipping a question form.
