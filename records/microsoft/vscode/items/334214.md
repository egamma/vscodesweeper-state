# Issue #334214 — Copilot questions unreadable

[https://github.com/microsoft/vscode/issues/334214](https://github.com/microsoft/vscode/issues/334214)

## Summary

Real contrast bug in the newly-built Copilot chat 'question carousel' (multiple-choice prompt) widget: the reporter's screenshots show a selected answer rendered as dark text on a dark-blue background, and it persists after upgrading to the latest stable build.

## Change summary

The highlighted/selected answer (and its hover subtext) in a Copilot multiple-choice question is rendered with low-contrast dark-on-dark-blue styling, making it unreadable.

## Best solution

Have the chat/agent-sessions area owner check the color-token wiring in src/vs/workbench/contrib/chat/browser/widget/chatContentParts/media/chatQuestionCarousel.css — several rules (`.chat-question-list-item.selected`, its focused variant, and the always-on `.codicon-check` rule which unconditionally uses `--vscode-list-activeSelectionForeground`) mix active/inactive selection background and foreground tokens in ways that can produce a dark-blue background paired with a dark/black foreground depending on focus state and theme; verify each background/foreground pair actually correlates (active bg with active fg, inactive bg with inactive fg) across Dark Modern/Light/HC themes.

A state where the dark-blue active background pairs with a foreground meant for a different state would reproduce the reported black-on-blue look.
