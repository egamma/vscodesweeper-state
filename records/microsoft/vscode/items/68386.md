# Issue #68386 — Split JSON settings editor discussion issue

[https://github.com/microsoft/vscode/issues/68386](https://github.com/microsoft/vscode/issues/68386)

## Summary

The split JSON settings editor was intentionally replaced as the default in VS Code 1.31; the old behavior remains available via `workbench.settings.useSplitJSON`, and a maintainer stated the split editor is 'considered deprecated.' This is as-designed.

## Change summary

Request to restore the split JSON settings editor (default settings on left, user settings on right) as the default experience.

## Best solution

Close as designed — the team deliberately moved to a single JSON editor in 1.31 and provides `workbench.settings.useSplitJSON` for users who prefer the old behavior. No change to the default is planned; the split editor is deprecated.
