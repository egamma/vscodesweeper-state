# Issue #310902 — Show More Info In HELP/ABOUT

[https://github.com/microsoft/vscode/issues/310902](https://github.com/microsoft/vscode/issues/310902)

## Summary

Legitimate niche feature request for portable-mode users who want to see the executable path in Help > About. The about dialog currently shows version/commit/date/runtime info but not the launch path. Low community traction (0 upvotes in 60 days) but the request is valid for its audience.

## Change summary

Show the VS Code executable path in the Help > About dialog so portable-mode users can identify which installation they are running.

## Best solution

Add `process.execPath` to the about dialog details string in `src/vs/platform/dialogs/electron-browser/dialog.ts` (`createNativeAboutDialogDetails`). This is a small, low-risk change that would help portable-mode users distinguish installations. Alternatively, could be scoped to only show when running in portable mode.
