# Issue #310902 — Show More Info In HELP/ABOUT

[https://github.com/microsoft/vscode/issues/310902](https://github.com/microsoft/vscode/issues/310902)

## Summary

The running executable's location is still absent from Help > About, so the requested distinction between installed and USB copies remains missing. Keep this accepted Backlog request open; neither its low vote count nor the earlier automated closure establishes a reason to decline it.

## Change summary

Display the running VS Code executable's path in Help > About so users can distinguish local and portable installations.

## Best solution

Expose the actual running executable's absolute path in the desktop About dialog and its copied details, rather than the workspace directory or shell's resolved code command. Keep additional environment fields outside the initial scope unless maintainers identify a concrete need.
