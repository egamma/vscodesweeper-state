# Issue #210704 — Code symbols in Notebook outline is not when the text in a code cell is updated

[https://github.com/microsoft/vscode/issues/210704](https://github.com/microsoft/vscode/issues/210704)

## Summary

Still reproduces on main: when cell content changes, the outline calls `recomputeState()` which reads from `cellOutlineEntryCache`, but never calls `cacheSymbols()` to refresh the cache — so code symbol entries in the notebook outline go stale after editing.

## Change summary

Notebook outline code symbols are not refreshed when a code cell's text is edited.

## Best solution

In `notebookOutline.ts`, the `onDidChangeContent` handler for `ChangeCellContent` should trigger `computeSymbols()` (or a cell-scoped `cacheSymbols`) before `recomputeState()`, so edited cells get their document symbols re-resolved. PR #227638 improved precaching but explicitly noted it didn't fix this issue.
