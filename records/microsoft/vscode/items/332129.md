# Issue #332129 — New chats remain stuck in Agent Host after switching back to Local Chat due to persisted chat.userSelectedSessionType

[https://github.com/microsoft/vscode/issues/332129](https://github.com/microsoft/vscode/issues/332129)

## Summary

The defect remains in current main, but an open PR directly fixes it and adds focused regression tests. Keep the issue open while that human-owned implementation is reviewed.

## Change summary

Disabling the Copilot harness does not override a persisted Agent Host Copilot session type, leaving new chats routed through Agent Host instead of Local Chat.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333155, which makes the remembered Copilot selection yield when the local harness is explicitly enabled and the Copilot harness is neither preferred nor the default, while preserving explicit Claude and Codex selections.
