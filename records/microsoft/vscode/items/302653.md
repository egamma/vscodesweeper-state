# Issue #302653 — Copilot CLI: Shows `Apply` button even when there are no changes to apply

[https://github.com/microsoft/vscode/issues/302653](https://github.com/microsoft/vscode/issues/302653)

## Summary

The same misleading Apply button for non-worktree Copilot CLI sessions is already tracked by an older, verified open issue. Propose consolidating this report into that issue.

## Change summary

Hide the Apply button when a Copilot CLI session edits the workspace directly and there is nothing to transfer from a worktree.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/300828, which explicitly reproduces the same workspace-isolation behavior. Preserve changed-file review while making Apply unavailable when the edits already reside in the target workspace.
