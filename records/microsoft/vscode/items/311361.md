# Issue #311361 — feat: Reply to Selected Part of Copilot Chat Responses (Quoted / Anchored Replies)

[https://github.com/microsoft/vscode/issues/311361](https://github.com/microsoft/vscode/issues/311361)

## Summary

Keep open as a partially implemented feature request. Current main has the requested Quote-to-input flow only in an experiment-gated Agents Window menu, while the default selection UI opens a side-question input and the ordinary Chat view still offers copy actions rather than adding selected response text to the current prompt.

## Change summary

Let users select part of a Copilot Chat response and insert it as quoted context into the current conversation input.

## Best solution

Finish the existing response-selection product decision and rollout in the Agents Window so Quote is discoverable without manually enabling an experimental setting, then decide whether the ordinary Chat view requires parity. Review or resolve the active configuration work in https://github.com/microsoft/vscode/pull/338431 rather than starting a competing implementation.
