# Issue #122657 — [folding] region ranges not restored when editor is opened the first time.

[https://github.com/microsoft/vscode/issues/122657](https://github.com/microsoft/vscode/issues/122657)

## Summary

The bug remains open and relevant: manual folding state is stored on shutdown, but on a fresh startup it can be restored before language-specific region markers are registered, causing previously folded `#region` ranges to reopen.

## Change summary

Restore manually folded region ranges when a file is first opened after restarting VS Code.

## Best solution

Make folding restoration resilient to language configuration arriving after the editor model is initialized, while preserving current manual-fold persistence and provider-change behavior.
