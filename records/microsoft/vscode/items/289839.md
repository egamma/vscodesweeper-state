# Issue #289839 — Find control is cut off and almost invisible when Chat has been opened in full screen mode and then closed

[https://github.com/microsoft/vscode/issues/289839](https://github.com/microsoft/vscode/issues/289839)

## Summary

The defect remains source-reproducible on current main: a user-resized find widget is width-constrained when the editor returns from a maximized secondary side bar, but its child layout is skipped, leaving most controls clipped.

## Change summary

Restoring the editor after maximizing and closing Chat can clip a widened Find control until it is nearly invisible.

## Best solution

Keep the resized Find control within the restored editor bounds and recompute its responsive child layout whenever the editor width changes, without changing normal Find behavior or the secondary-side-bar maximize flow.
