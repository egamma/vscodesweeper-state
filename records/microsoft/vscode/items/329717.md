# Issue #329717 — Allow Modern UI-specific overrides for colors in theme definitions

[https://github.com/microsoft/vscode/issues/329717](https://github.com/microsoft/vscode/issues/329717)

## Summary

Active, productive discussion: a contributor already landed generic `surface.*`/`editor.border` color tokens (src/vs/workbench/common/theme.ts, documented in src/vs/workbench/contrib/styleOverrides/README.md) that cover most of the reporter's ask, and is deliberately keeping the issue open to resolve the remaining edge case (per-mode override for tokens like `activityBar.dropBorder` that still resolve differently in classic vs. modern UI).

## Change summary

Theme authors want a way to define Modern UI-specific color overrides, since some existing token defaults resolve differently (or worse) under the modern layout than under classic UI.

No core code change is needed until that design call is made.
