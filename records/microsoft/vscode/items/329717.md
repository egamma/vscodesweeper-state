# Issue #329717 — Allow Modern UI-specific overrides for colors in theme definitions

[https://github.com/microsoft/vscode/issues/329717](https://github.com/microsoft/vscode/issues/329717)

## Summary

Fresh, coherent feature request asking for a way to give theme colors different values for Modern UI vs classic UI; no existing schema support found and no canonical issue owns this exact ask, so it should be routed to the themes/modernization owners rather than closed.

## Change summary

Let theme authors specify Modern-UI-specific overrides for the `colors` section of a color theme definition, since colors currently render differently (and sometimes inconsistently) between Modern UI and classic UI.

## Best solution

A themes-area maintainer should weigh in on schema design (e.g. extending src/vs/workbench/services/themes/common/colorThemeSchema.ts and the ColorThemeData loading path) to decide whether/how conditional overrides keyed on the Modern UI state should be exposed; until then this is a design question, not a mechanical fix.
