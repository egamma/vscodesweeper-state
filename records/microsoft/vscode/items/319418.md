# Issue #319418 — GitHub Copilot sees "compilerError" for diagnostics instead of the "C/C++ IntelliSense" diagnostic source

[https://github.com/microsoft/vscode/issues/319418](https://github.com/microsoft/vscode/issues/319418)

## Summary

Keep open: Copilot still renders diagnostics without their source under a compiler-specific tag, and the updated request for selective diagnostic exclusion remains unmet. The team-authored thread needs a product/API decision rather than an extension-caused close.

## Change summary

Allow extensions to distinguish or exclude IntelliSense diagnostics from Copilot context without changing their user-visible diagnostic source.

## Best solution

Use accurate diagnostic terminology and provenance in Copilot prompts, with an agreed mechanism for excluding unreliable diagnostics while preserving Problems-panel visibility. Settle the exclusion contract before implementing it across diagnostic consumers.
