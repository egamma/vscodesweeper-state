# Issue #324646 — Skills: nested skill directory discovery (organizational subfolders + nested project subdirectories)

[https://github.com/microsoft/vscode/issues/324646](https://github.com/microsoft/vscode/issues/324646)

## Summary

Current main still supports only flat skill discovery, leaving both requested organizational patterns unimplemented. This member-authored feature request should remain open for design and performance decisions.

## Change summary

Discover skills recursively within configured roots and support directory-scoped skills colocated in nested monorepo projects.

## Best solution

Extend skill discovery around `PromptFilesLocator` with a cached, watcher-driven index: identify skills by the directory containing `SKILL.md`, associate nested `.github/skills` roots with their project directory, and resolve collisions in favor of the narrowest applicable scope.
