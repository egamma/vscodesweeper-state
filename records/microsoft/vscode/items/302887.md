# Issue #302887 — Renamed chat reverts when chat is selected from sessions

[https://github.com/microsoft/vscode/issues/302887](https://github.com/microsoft/vscode/issues/302887)

## Summary

The older, open local-session rename issue explicitly reports the same symptom: a title changed from the sessions list reverts when the chat is opened. Consolidate this report there; the persistence gap remains visible in current source.

## Change summary

Renaming a chat from the sessions list should persist the new title when the chat is selected again.

## Best solution

Track the persistence defect in https://github.com/microsoft/vscode/issues/283514 so renaming an unloaded local session survives reopening, just as renaming an active session does.
