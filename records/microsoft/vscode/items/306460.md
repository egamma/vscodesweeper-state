# Issue #306460 — Git - Commit message template is trimmed of comments and whitespace before it is shown to the user.

[https://github.com/microsoft/vscode/issues/306460](https://github.com/microsoft/vscode/issues/306460)

## Summary

The SCM input still deliberately strips template comments and surrounding whitespace before display. Keep this open as a request to preserve instructional templates: existing editor support is only a workaround, and no verified open canonical covers the same behavior.

## Change summary

Preserve comments and blank lines from commit.template when presenting it in the Source Control commit input.

## Best solution

Support viewing the full instructional template during SCM commit authoring without inadvertently committing its comments or changing literal commit-message semantics. The Git extension owner should settle that presentation-versus-submission contract before implementation.
