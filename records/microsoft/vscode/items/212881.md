# Issue #212881 — Add navigation buttons to test coverage elements

[https://github.com/microsoft/vscode/issues/212881](https://github.com/microsoft/vscode/issues/212881)

## Summary

The requested navigation remains missing: coverage bars do not reveal the Coverage view, and neither coverage toolbar offers navigation to the associated test run. Existing commands provide only partial workarounds, and the canonical search found no older issue owning this request.

## Change summary

Provide navigation from editor coverage bars to the Coverage view and from both coverage toolbars to the corresponding run in Test Results.

## Best solution

Keep this request in the testing coverage backlog for a UI decision on these contextual navigation affordances. Any Results action should select the run associated with the displayed coverage, rather than indiscriminately opening the latest run.
