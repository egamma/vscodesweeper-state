# Issue #198304 — Quick chat should not listen to main container changes only

[https://github.com/microsoft/vscode/issues/198304](https://github.com/microsoft/vscode/issues/198304)

## Summary

The reported container mismatch remains in current source: Quick Chat can appear in a floating window, but its height limit and layout listener still use the main window. Keep this open in the existing Quick Chat and auxiliary-window areas.

## Change summary

Make Quick Chat respond to layout changes and dimensions of the window containing its visible widget.

## Best solution

Quick Chat should derive its height constraints from its actual hosting container and respond to that container's layout changes, including after reopening in another window. Preserve existing dynamic sizing, sash behavior, and hidden-widget scroll preservation.
