# Issue #281925 — Apply the hover.hidingDelay to when hover.sticky is false

[https://github.com/microsoft/vscode/issues/281925](https://github.com/microsoft/vscode/issues/281925)

## Summary

Keep open: current source still explicitly restricts hover hidingDelay to sticky mode, so the requested independent timing remains unavailable. A maintainer deliberately split this request from the older report; neither that closed report nor the open sibling owns the same remaining work.

## Change summary

Honor editor.hover.hidingDelay when editor.hover.sticky is false.

## Best solution

Allow non-sticky editor hovers to respect the configured dismissal delay without making them sticky. Preserve existing sticky-mode interaction and keep the separate showing-versus-hiding precedence request outside this change.
