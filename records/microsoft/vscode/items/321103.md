# Issue #321103 — Copilot Chat sends full active file even when implicit context is disabled

[https://github.com/microsoft/vscode/issues/321103](https://github.com/microsoft/vscode/issues/321103)

## Summary

Current main intentionally supplements ranged file references with a whole-file summary, and the cited settings control automatic editor context rather than this attachment-rendering policy. The request remains necessary as a user-facing context-control decision and should be routed to the chat area.

## Change summary

Avoid sending supplemental whole-file content when a user deliberately provides only a file selection, particularly when implicit active-editor context is disabled.

## Best solution

Define a clear policy for ranged file references and expose predictable control over supplemental whole-file context. Prefer sending only the requested excerpt when broad context is disabled, while preserving explicit full-file attachments and any deliberately enabled summary behavior.
