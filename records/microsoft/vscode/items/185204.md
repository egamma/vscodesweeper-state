# Issue #185204 — Reconsider the request to allow modals in Simple Browser and other WebViews

[https://github.com/microsoft/vscode/issues/185204](https://github.com/microsoft/vscode/issues/185204)

## Summary

Legitimate feature request with 61 upvotes, already in the Backlog. The `allow-modals` sandbox attribute has not been added to webview iframes on current main — the gap remains real. Keeping open for the area owner to decide.

## Change summary

Allow `window.alert()`, `window.confirm()`, and `window.prompt()` modals in Simple Browser and other WebViews by adding `allow-modals` to the iframe sandbox attribute.

## Best solution

Add an `allowModals` option (similar to the existing `allowScripts`/`allowForms`/`allowDownloads` pattern) in the webview sandbox configuration at `src/vs/workbench/contrib/webview/browser/pre/index.html` and propagate it through the webview options interfaces. The decision on whether to expose this to all webviews or only Simple Browser is a product call for the webview area owner.
