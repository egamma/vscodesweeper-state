# Issue #185204 — Reconsider the request to allow modals in Simple Browser and other WebViews

[https://github.com/microsoft/vscode/issues/185204](https://github.com/microsoft/vscode/issues/185204)

## Summary

Keep open: current webview sandboxes still block the requested JavaScript dialogs, and this accepted Backlog request has 61 upvotes. Supporting legacy applications remains a real gap, but enabling native dialogs requires an explicit maintainer decision about UI consistency and sandbox permissions.

## Change summary

Allow legacy applications embedded in Simple Browser and other webviews to use window.alert(), window.confirm(), and window.prompt().

## Best solution

Resolve whether a supported, explicitly controlled dialog capability can preserve synchronous legacy application behavior without compromising webview isolation or trusted UI. Existing asynchronous extension-message workarounds do not satisfy applications whose source cannot be changed.
