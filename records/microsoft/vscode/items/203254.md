# Issue #203254 — Provide API for skipped ranges in test coverage

[https://github.com/microsoft/vscode/issues/203254](https://github.com/microsoft/vscode/issues/203254)

## Summary

Team-authored feature request for skipped/excluded ranges in the test coverage API. The current finalized API (StatementCoverage, BranchCoverage, DeclarationCoverage) has no concept of skipped/excluded lines — only covered and uncovered states. This remains an unimplemented gap; keeping open per team-member rule.

## Change summary

Add API support for marking lines/ranges as skipped or excluded in test coverage results, distinct from uncovered.

## Best solution

Extend the test coverage API (likely StatementCoverage and FileCoverageDetail types in src/vscode-dts/vscode.d.ts and their internal counterparts in src/vs/workbench/contrib/testing/common/) with a skipped/excluded state, and add corresponding UI rendering in the coverage gutter decorations. This would allow coverage tools like gcovr to faithfully represent lines excluded from analysis.
