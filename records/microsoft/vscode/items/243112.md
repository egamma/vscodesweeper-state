# Issue #243112 — Code snippet editor has many editor features that are not working

[https://github.com/microsoft/vscode/issues/243112](https://github.com/microsoft/vscode/issues/243112)

## Summary

Most originally reported noise has been cleaned up, and the remaining language-navigation actions are intentionally supported. A real UX question remains around generic entries such as Command Palette, so this should stay open as focused context-menu polish rather than as a broken-feature bug.

## Change summary

Limit the chat code-snippet editor context menu to actions that are meaningful and functional for embedded, read-only code blocks.

## Best solution

Retain the workspace-aware navigation, Explain, and Copy actions that operate meaningfully from code blocks, while auditing generic editor contributions and excluding entries that provide no snippet-specific value. The area owners should explicitly decide whether Command Palette belongs in this embedded-editor menu.
