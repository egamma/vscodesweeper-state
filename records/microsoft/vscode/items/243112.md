# Issue #243112 — Code snippet editor has many editor features that are not working

[https://github.com/microsoft/vscode/issues/243112](https://github.com/microsoft/vscode/issues/243112)

## Summary

Significant cleanup has been done since filing — many non-functional commands (peek variants, declarations, references, Copy as, Share, Go to related test, Copilot Review) have been removed from the code block context menu. However, open questions from the Sept 2025 audit remain: Go to Definition, Go to Type Definition, and Go to Implementations still appear without the `isInEmbeddedEditor` guard, and the Command Palette entry is still surfaced. The issue is partially addressed but not fully resolved.

## Change summary

Reduce the code snippet (chat code block) editor context menu to only contextually appropriate entries, removing non-functional or confusing editor features.

## Best solution

Decide whether Go to Definition, Go to Type Definition, and Go to Implementations belong in code block context menus (mjbvz argues they do work for workspace symbols — comment 5). If they stay, address the remaining UX issues (e.g. references opening the code block as a text editor). If not, add `isInEmbeddedEditor.toNegated()` guards to those three commands in `src/vs/editor/contrib/gotoSymbol/browser/goToCommands.ts`. Also evaluate whether the Command Palette entry should appear in code blocks.
