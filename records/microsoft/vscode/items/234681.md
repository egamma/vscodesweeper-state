# Issue #234681 — weird behaviour in some cases when assigning multiple keybindings

[https://github.com/microsoft/vscode/issues/234681](https://github.com/microsoft/vscode/issues/234681)

## Summary

The keybinding overwrite remains reproducible from current source: editing the second binding's condition selects the first entry with the same command and original condition, ignoring its key. Keep this open in keybindings-editor; the reporter confirmed that the separate shifted-character display problem was resolved.

## Change summary

Changing the condition of a newly added keyboard shortcut unexpectedly overwrites an existing shortcut for the same command.

## Best solution

Ensure condition edits target the selected user keybinding without changing sibling bindings, with regression coverage for adding a second shortcut that initially inherits the first shortcut's condition.
