# Issue #161586 — Close, minimize and maximize buttons missing on macOS after using the restart to update option

[https://github.com/microsoft/vscode/issues/161586](https://github.com/microsoft/vscode/issues/161586)

## Summary

Still open: the 10s fullscreen-timeout workaround (commit 1a37acbdf9c, shipped in 1.87.0) mitigates one scenario, but community reports as recently as July 2025 indicate the traffic lights still disappear in other cases (non-fullscreen windows after update restart). The `confirmation-pending` label is appropriate — a fuller fix hasn't landed.

## Change summary

macOS window close/minimize/maximize buttons disappear after using the 'Restart to Update' option, particularly on non-fullscreen windows.

## Best solution

Investigate the remaining reproduction path: non-fullscreen windows losing traffic lights after restart-to-update. The fullscreen-restore timeout (1a37acbdf9c) only covers the fullscreen case. The root cause may involve incorrect `mode` in persisted window state (mode 3 / fullscreen applied to a window that was actually non-fullscreen), or an Electron race during rapid window re-creation on update. A team member should attempt reproduction on current stable with multiple windows and the update-restart flow.
