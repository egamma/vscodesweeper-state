# Issue #288166 — Source Control icon could indicate if branch is behind

[https://github.com/microsoft/vscode/issues/288166](https://github.com/microsoft/vscode/issues/288166)

## Summary

The Source Control activity badge intentionally represents local pending changes, while incoming commits are indicated by the Git status-bar sync item. An exact maintainer precedent confirms this division is by design.

## Change summary

Show an indication on the Source Control activity icon when the current Git branch is behind its upstream.

## Best solution

Keep the activity badge scoped to local pending changes and use the existing status-bar sync indicator for upstream divergence.

## Vision fit

- **Fit:** aligned
- **Reason:** Making incoming Git changes easier to notice supports the developer inner loop, although the existing UI intentionally presents that state elsewhere.
- **Evidence:** Durable theme: developer inner loop, including SCM/GitHub integration.
