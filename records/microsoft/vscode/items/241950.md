# Issue #241950 — Selection includes inline values, except last, but not on clipboard

[https://github.com/microsoft/vscode/issues/241950](https://github.com/microsoft/vscode/issues/241950)

## Summary

Open visual polish issue: notebook inline value decorations appear in the text selection highlight but aren't on the clipboard, creating a confusing visual. Assigned to Yoyokrazy and labeled under-discussion — no fix has landed on main. Stays open for the assignee to investigate.

## Change summary

Notebook inline value decorations are visually included in cell selection (Ctrl+A) except on the last line, even though they are not copied to clipboard.

## Best solution

The inline value decorations should either be excluded from the selection highlight entirely (so the visual matches the clipboard), or the behavior should be documented as expected. The fix likely lives in how the notebook inline variable decorations interact with editor selection rendering, around `src/vs/workbench/contrib/notebook/browser/contrib/notebookVariables/notebookInlineVariables.ts` and the underlying editor decoration model.
