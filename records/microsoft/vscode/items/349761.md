# Issue #349761 — Quick Open defaults to the previous worktree copy of a file after switching folder location

[https://github.com/microsoft/vscode/issues/349761](https://github.com/microsoft/vscode/issues/349761)

## Summary

Keep open: folder-location switches restore location-specific editors but retain shared Quick Open history, allowing the previous worktree's file to outrank the current folder's copy. This contradicts the worktree test plan's isolation expectation; no fixing commit or verified canonical was identified.

## Change summary

Quick Open selects the previous worktree's recently opened app.ts after switching back to the original folder.

## Best solution

Make Quick Open respect the active folder location so an inactive worktree's history entry does not take precedence over the current folder's matching file. Preserve normal history behavior outside folder-location switching rather than disabling history globally.
