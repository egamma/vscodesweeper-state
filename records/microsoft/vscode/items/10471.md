# Issue #10471 — Lift `setContext` from a command to proper API

[https://github.com/microsoft/vscode/issues/10471](https://github.com/microsoft/vscode/issues/10471)

## Summary

A meaningful API gap remains despite `setContext` becoming a documented API command. This Backlog request has 103 community upvotes and continues to collect concrete read/scoping use cases, so it should remain open.

## Change summary

Expose context keys through a proper extension API, including lifecycle-safe creation and a viable way to inspect relevant context.

## Best solution

Design a scoped context-key API for extension-owned keys and separately define safe focused-context evaluation semantics; avoid a raw global `getContext` API that ignores VS Code's multiple context containers.

- **Fit:** aligned
- **Reason:** A well-defined context-key API improves extension interoperability and enables accessibility tooling without adding default UI surface.
