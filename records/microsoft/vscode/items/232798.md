# Issue #232798 — Layout Controls: move them to respective corners

[https://github.com/microsoft/vscode/issues/232798](https://github.com/microsoft/vscode/issues/232798)

## Summary

Keep open for a workbench layout decision: partial improvements landed, but the central request to place each layout toggle near the part it controls remains unresolved. The thread contains maintainer support as well as open UX questions around movable panels and layout discoverability.

## Change summary

Distribute the primary sidebar, panel, and secondary sidebar layout controls to the corresponding workbench corners, potentially removing the centralized layout picker.

## Best solution
