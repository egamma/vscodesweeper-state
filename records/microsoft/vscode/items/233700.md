# Issue #233700 — Unexpected indentation

[https://github.com/microsoft/vscode/issues/233700](https://github.com/microsoft/vscode/issues/233700)

## Summary

The completed multiline assignment still leaves the following line at continuation indentation in current source. Keep this maintainer-authored report open: the discussion supplies a concrete reproduction, and the related syntax-aware indentation proposal is not a verified duplicate of this symptom.

## Change summary

Restore statement-level indentation after a semicolon-terminated multiline JavaScript conditional assignment instead of carrying continuation indentation into the following comment or statement.

## Best solution

Make Enter recognize the end of the multiline assignment without incorrectly outdenting multiline template literals. Resolve this concrete case within the editor indentation work, using the linked syntax-aware proposal as design context rather than replacing the bug with that broader request.
