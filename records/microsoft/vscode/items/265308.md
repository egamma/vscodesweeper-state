# Issue #265308 — Add git diff-like buttons to find-and-replace preview

[https://github.com/microsoft/vscode/issues/265308](https://github.com/microsoft/vscode/issues/265308)

## Summary

Keep open: applying individual replacements directly from the preview remains distinct from the existing search-result actions and generic diff revert controls. The issue is already appropriately routed, and no verified canonical owns this request.

## Change summary

Add an inline action in the find-and-replace preview to apply the corresponding replacement without locating it in the search-results tree.

## Best solution

Provide a preview-local replacement action integrated with the search replacement model, preserving the existing replacement and preview-refresh behavior. Define whether each action applies one search match or all matches represented by a diff block before implementing it.
