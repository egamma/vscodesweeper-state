# Issue #250024 — Significant VSCodeVim performance slowdowns tied to visible size of another extension's static TreeView

[https://github.com/microsoft/vscode/issues/250024](https://github.com/microsoft/vscode/issues/250024)

## Summary

Keep open: the reporter reproduced the visibility-dependent Vim slowdown with Microsoft's tree-view sample after disabling both originally suspected TreeView extensions. That is actionable evidence of a possible core performance problem; current-source inspection identifies a relevant investigation path but does not establish the cause or a fix.

## Change summary

Holding remapped Vim movement keys accumulates cursor movement disproportionately when more rows of an otherwise static extension TreeView are visible.

## Best solution
