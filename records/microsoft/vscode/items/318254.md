# Issue #318254 — OSC52 unsupported in `code serve-web`

[https://github.com/microsoft/vscode/issues/318254](https://github.com/microsoft/vscode/issues/318254)

## Summary

The OSC 52 clipboard failure remains directly traceable on current main: web clipboard writes are stored in memory instead of reaching the system clipboard. Keep this open while the two existing fix PRs are reviewed.

## Change summary

OSC 52 sequences targeting the system clipboard in a code serve-web terminal fail to update the browser user's clipboard.

## Best solution

Review and land an appropriate fix from https://github.com/microsoft/vscode/pull/318255 or https://github.com/microsoft/vscode/pull/334287 so system-clipboard targets reach the browser clipboard implementation while preserving primary-selection behavior and browser permission requirements.
