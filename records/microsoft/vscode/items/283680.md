Team-authored bug about chat UI not properly handling canceled requests — the 'Report Issue' button doesn't appear and 'generating...' persists. No fix commit references this issue, and the report lacks reproduction steps. Keeping open for the owning team.

## Change summary

After canceling a Copilot chat request, the 'Report Issue' button is unavailable and the progress indicator still shows 'generating...'.

## Best solution

Investigate the cancel flow in the chat response lifecycle — ensure that cancellation properly finalizes the response state so that (1) the footer toolbar (including Report Issue) renders for canceled responses, and (2) the working-progress indicator is dismissed. The relevant rendering logic is in `src/vs/workbench/contrib/chat/browser/widget/chatListRenderer.ts` around the `shouldShowWorkingProgress` and `finalizeCompletedResponseParts` methods.
