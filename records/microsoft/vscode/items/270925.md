# Issue #270925 — SCM: newlines appear as paragraph breaks in commit tooltips

[https://github.com/microsoft/vscode/issues/270925](https://github.com/microsoft/vscode/issues/270925)

## Summary

Still reproduces on main: line 125 of extensions/git/src/hover.ts replaces every newline with a double newline, causing all single line breaks in commit messages to render as paragraph breaks. An open PR (#301633) exists to fix this.

## Change summary

Single newlines in multi-line commit messages render as paragraph breaks in the SCM history item hover tooltip, making 72-column wrapped prose appear as separate paragraphs.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/301633, which adds intelligent newline handling (joining soft wraps, preserving list markers, keeping double newlines as paragraph breaks) in `extensions/git/src/hover.ts`.
