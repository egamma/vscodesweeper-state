# Issue #307963 — Extremely slow search in Keyboard shortcut panel

[https://github.com/microsoft/vscode/issues/307963](https://github.com/microsoft/vscode/issues/307963)

## Summary

The reported freeze was caused by exponential recursion when matching dot-separated command IDs and was fixed by memoizing the matcher. The fix is present on current main and shipped in VS Code 1.119.0, so this can be closed as completed.

## Change summary

Searching the Keyboard Shortcuts editor for dot-separated command IDs such as `workbench.action.` freezes the renderer for several seconds.

## Best solution

Keep the matcher memoization from commit 7641886941d240ecf7784b302a8ada29022ecccd and its performance regression test; users should update to VS Code 1.119.0 or later.
