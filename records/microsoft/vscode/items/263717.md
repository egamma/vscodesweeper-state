# Issue #263717 — Selecting text longer that window is impossible

[https://github.com/microsoft/vscode/issues/263717](https://github.com/microsoft/vscode/issues/263717)

## Summary

The bug remains on current main: Chat explicitly permits text selection, but its virtualized list does not enable the list framework's user-selection support, so dragging beyond the viewport cannot auto-scroll. The newer Copy All capability is useful but does not cover selecting an arbitrary range.

## Change summary

Dragging a text selection beyond the visible Copilot Chat viewport should auto-scroll so users can select long or partial response ranges.

## Best solution

Enable the existing virtual-list user-selection behavior for Chat and cover drag-selection auto-scroll with a ChatListWidget browser test, while preserving the existing Copy All command and pending-request drag behavior.
