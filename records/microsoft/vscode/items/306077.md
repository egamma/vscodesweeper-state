# Issue #306077 — Permission settings(bypass/default/autopilot)on prompt file level

[https://github.com/microsoft/vscode/issues/306077](https://github.com/microsoft/vscode/issues/306077)

## Summary

This is a valid, currently unimplemented request for prompt-scoped permission modes. It should remain open and route to the prompt customization owners for security and policy design.

## Change summary

Allow a prompt file to select Default Permissions, Bypass Approvals, or Autopilot for its invocation.

## Best solution

Define a validated prompt-frontmatter permission attribute and apply it when the prompt runs, while preserving enterprise restrictions and requiring appropriate confirmation for elevated modes.
