# Issue #242712 — Line wrapping in terminal search

[https://github.com/microsoft/vscode/issues/242712](https://github.com/microsoft/vscode/issues/242712)

## Summary

Still reproduces on main: the terminal find widget's result count element (`.matchesCount`) has a fixed 73px width but no `white-space: nowrap` or `overflow: hidden`, so the "X of Y" text can cause a line break when the count string is long enough. No fix has landed.

## Change summary

The terminal find widget's result count string wraps to a second line, making the widget taller than intended.

## Best solution

Add `white-space: nowrap` and `overflow: hidden` (or `text-overflow: ellipsis`) to the `.matchesCount` element in `src/vs/workbench/contrib/codeEditor/browser/find/simpleFindWidget.css`, preventing the count text from wrapping inside its fixed-width container.
