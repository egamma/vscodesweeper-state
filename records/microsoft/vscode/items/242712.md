# Issue #242712 — Line wrapping in terminal search

[https://github.com/microsoft/vscode/issues/242712](https://github.com/microsoft/vscode/issues/242712)

## Summary

The terminal find counter still has a fixed-width, wrapping layout on current main, so sufficiently long match counts can break onto another line. Keep this open in terminal-find; no verified canonical or completed fix was found.

## Change summary

Keep large terminal search match counts from wrapping the find widget onto a second line.

## Best solution

Keep the match-position counter and navigation controls aligned on one row when terminal searches return many matches, while preserving narrow-panel behavior and accessible result announcements.
