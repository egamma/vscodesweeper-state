# Issue #242712 — Line wrapping in terminal search

[https://github.com/microsoft/vscode/issues/242712](https://github.com/microsoft/vscode/issues/242712)

## Summary

Still reproduces on main: the `.matchesCount` element in `simpleFindWidget.css` has a fixed 73px width but no `white-space: nowrap`, so when the result-count text (e.g. "1234 of 5678") exceeds ~68px of usable width, it wraps and increases the widget height, causing a visible line break in the terminal find bar.

## Change summary

The terminal find widget's "X of Y" result-count text wraps to a second line when the match count string is wide enough, visually breaking the single-line find bar layout.

## Best solution

Add `white-space: nowrap` (and optionally `overflow: hidden; text-overflow: ellipsis`) to `.monaco-workbench .simple-find-part .matchesCount` in `src/vs/workbench/contrib/codeEditor/browser/find/simpleFindWidget.css`. This is the same pattern used elsewhere for fixed-width text containers in the workbench.
