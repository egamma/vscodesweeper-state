## Summary

The requested SVG CSS properties are now part of the CSS language service data consumed by VS Code, so their use no longer produces unknown-property diagnostics. The upstream implementation and subsequent VS Code dependency update provide concrete evidence that this request is completed.

## Change summary

Recognize SVG geometry and presentation properties such as `x`, `y`, `cx`, `cy`, `r`, `d`, `dominant-baseline`, and `vector-effect` in CSS, SCSS, and Less.
