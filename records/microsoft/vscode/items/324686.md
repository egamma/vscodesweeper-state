# Issue #324686 — Split terminal

[https://github.com/microsoft/vscode/issues/324686](https://github.com/microsoft/vscode/issues/324686)

## Summary

Low-traction feature request to temporarily hide/collapse individual panes in a split terminal group. VS Code already offers resize-pane commands and an unsplit command, but no temporary hide/collapse of a single split pane. Routing to the terminal area for visibility.

## Change summary

Allow temporarily hiding or collapsing individual split terminal panes to give more width to the active pane.

## Best solution

The existing `Resize Terminal Left/Right` commands and `Unsplit Terminal` command partially address the need. A "maximize pane" toggle within a split terminal group (similar to how some multiplexers like tmux handle zoom) would be the ideal solution if the team decides to pursue it. This is related to the broader request in https://github.com/microsoft/vscode/issues/47661 (toggle maximize a single view). The request could benefit from clearer description of the expected UX — whether it's a per-pane collapse, a zoom/maximize toggle, or something else.
