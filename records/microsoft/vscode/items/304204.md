# Issue #304204 — expected "reopen editor" to include "open in image preview"

[https://github.com/microsoft/vscode/issues/304204](https://github.com/microsoft/vscode/issues/304204)

## Summary

A real discoverability gap remains: Images Preview is available from Explorer but is not registered as an editor resolver, so it cannot appear under Reopen Editor With. This team-authored feature request should remain open in the image-carousel area.

## Change summary

Make the Images Preview carousel available when choosing how to reopen an image from its editor tab.

## Best solution

Provide an editor-tab entry point that opens the active image and its sibling images in Images Preview. If placed under Reopen Editor With, preserve the carousel's collection-building behavior rather than treating its in-memory editor input as an ordinary single-resource custom editor.
