# Issue #334217 — VSCode 1.137.0-insider: Chats in Agents Window not working/not doing anything

[https://github.com/microsoft/vscode/issues/334217](https://github.com/microsoft/vscode/issues/334217)

## Summary

Route this to the Agents Window and Agent Host owners. A later report confirms the new-session symptom on Stable, while this older report also covers existing chats and therefore should not be closed into that narrower issue.

## Change summary

Messages submitted in new or existing Agents Window chats remain indefinitely on Considering or Working without producing a response, while regular editor chat continues to work.

## Best solution

Ensure both new and resumed Agents Window chats either dispatch their turn to Agent Host and reach a terminal state or fail promptly with a visible error. Reproduce both variants on current main and distinguish the pre-dispatch failure confirmed for new sessions from the other known Agent Host hang mechanisms.
