## Change summary

Restored editor-area terminals intermittently start in another project's directory when alternating Windows folders and running WSL inside the terminal.

## Best solution

Ensure terminal restoration preserves the correct workspace's terminal identity and working-directory state. First distinguish an incorrectly attached terminal process from a correctly restored Windows shell that starts its nested WSL shell in an unexpected directory.
