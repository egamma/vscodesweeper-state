# Issue #185611 — getOnTypeFormattingEdits not triggered on selected code

[https://github.com/microsoft/vscode/issues/185611](https://github.com/microsoft/vscode/issues/185611)

## Summary

The capability remains absent on current main, and maintainer discussion supports allowing it once the trigger position is handled correctly. This team-authored Backlog request should remain open.

## Change summary

Allow on-type formatting providers to run when typing a trigger character surrounds a selection.

## Best solution

Teach `FormatOnType` to invoke the provider with the opening trigger character's correct position after a single-selection surround operation, while preserving multi-cursor safeguards and avoiding the inconsistent position previously reported in https://github.com/microsoft/vscode/issues/131700.
