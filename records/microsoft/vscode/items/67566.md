# Issue #67566 — Revealing in the editor should be aware of how much space the command palette is using

[https://github.com/microsoft/vscode/issues/67566](https://github.com/microsoft/vscode/issues/67566)

## Summary

Keep open: symbol previews still center within the editor without accounting for the quick pick's overlapping footprint. The maintainer endorsed improving this interaction, and existing alignment controls do not deliver automatic unobscured previews.

## Change summary

Reveal the active symbol in the unobscured portion of the editor while the symbol quick pick is open.

## Best solution

Make symbol preview positioning account for the quick pick's actual overlap with the editor when usable space remains. Agree on a fallback for layouts where the picker covers the entire available editor before implementing the interaction.
