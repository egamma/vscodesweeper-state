# Issue #286513 — Title bar visibility regression in 1.107.1

[https://github.com/microsoft/vscode/issues/286513](https://github.com/microsoft/vscode/issues/286513)

## Summary

Keep open as an Electron-related GNOME decoration regression: the reporter supplied a completed bisect, and maintainers attributed the result to Electron 39. No verified fixing commit or older canonical reporting the same symptom was established.

## Change summary

Restore the previously undecorated GNOME window when using native title bars with custom title-bar visibility set to never.

## Best solution

Identify the Electron/Chromium native-decoration change responsible for the bisected regression and resolve it on the GNOME windowing path. Preserve the distinction between hiding VS Code's custom title bar and controlling native window decorations.
