# Issue #285334 — Opus doesn't support SVGs?

[https://github.com/microsoft/vscode/issues/285334](https://github.com/microsoft/vscode/issues/285334)

## Summary

Verified duplicate: the older open issue reports the same observable failure—an SVG attached to Chat is rejected instead of being supplied as text—and already owns the required work.

## Change summary

Allow an SVG attached to Chat to be treated as an editable text/code file rather than an unsupported image.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/270607 and make Chat pass SVG files as textual file context while retaining the restriction against sending them as model image inputs.
