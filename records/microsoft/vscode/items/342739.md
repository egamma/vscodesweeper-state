# Issue #342739 — Model vendor tabs are inconsistent

[https://github.com/microsoft/vscode/issues/342739](https://github.com/microsoft/vscode/issues/342739)

## Summary

The different tab sets are intentional: ordinary model selection uses the current session's model pool, while Compare Models exposes models across execution harnesses. An existing test explicitly expects the exact Copilot-only to Copilot/Claude/Codex transition reported here.

## Change summary

The model picker gains Claude and Codex tabs when entering Compare Models from a Copilot session.

## Best solution

Keep the separate model pools and explain that comparison tabs represent execution harnesses, not merely model vendors; ordinary selection remains scoped to the current session.
