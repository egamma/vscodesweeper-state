# Issue #187643 — view is not updated for markdown cell content change

[https://github.com/microsoft/vscode/issues/187643](https://github.com/microsoft/vscode/issues/187643)

## Summary

Still reproduces on main: in a split notebook editor, the markup cell preview in one pane does not update when the cell content is edited in the other pane. The content change notification path requires resolveTextModel() to have been called, which may not happen for a cell that's been in preview mode from the start. No fix commit found.

## Change summary

Markdown cell preview does not update in a split notebook editor when the cell content is changed in the other editor pane.

## Best solution

The markup cell view model in the preview-side editor needs to listen for content changes on the underlying NotebookCellTextModel (which is shared across view models) rather than relying solely on the text model reference that's only resolved when the cell enters edit mode. The fix likely belongs in markupCellViewModel.ts or the notebook editor widget's cell synchronization logic.
