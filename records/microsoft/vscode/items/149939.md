# Issue #149939 — Add support for extension-less files on Mac

[https://github.com/microsoft/vscode/issues/149939](https://github.com/microsoft/vscode/issues/149939)

## Summary

A real macOS integration gap remains: current packaging registers specific extensions but not extensionless files. This team-authored Backlog request should stay open, reinforced by the maintainer invitation to contribute a pull request.

## Change summary

Register VS Code as an eligible macOS Open With application for files without extensions.

## Best solution

Extend the macOS bundle metadata generated from `build/lib/electron.ts` with an appropriately scoped generic document type, then verify that extensionless files offer VS Code in Finder's Open With menu without undesirably claiming unrelated file types.
