# Issue #318887 — Erro de compactação mesmo em projeto pequenoi, não executa mais nada

[https://github.com/microsoft/vscode/issues/318887](https://github.com/microsoft/vscode/issues/318887)

## Summary

The error comes from OpenAI's Codex extension while decoding a remote context-compaction response, not from VS Code core. This should be closed as caused by an externally owned extension and reported to OpenAI's tracker.

## Change summary

OpenAI Codex context compaction fails because a remote response contains the unsupported value `auto` where the extension expects `high` or `original`.

## Best solution

OpenAI should make the Codex client and remote compaction service agree on the accepted response variants, or make the client tolerate the service's `auto` value. Track that work in https://github.com/openai/codex/issues rather than VS Code core.
