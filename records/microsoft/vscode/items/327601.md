# Issue #327601 — Add "Reset to commit" action to the file timeline right-click menu in VS Code

[https://github.com/microsoft/vscode/issues/327601](https://github.com/microsoft/vscode/issues/327601)

## Summary

This is a valid, currently missing Git timeline capability. Route it to the Git timeline owners rather than closing it; the related SCM Graph work targets a different surface.

## Change summary

Add soft and hard reset-to-commit actions to Git commit items in the file Timeline context menu.

## Best solution

Implement reusable reset-to-commit commands in the built-in Git extension, coordinating with https://github.com/microsoft/vscode/pull/273616, then contribute them to `timeline/item/context` with confirmation that clearly distinguishes soft and destructive hard resets.
