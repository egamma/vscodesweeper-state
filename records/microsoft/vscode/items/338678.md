# Issue #338678 — Agents Window: side-by-side sessions show a distracting full-height divider

[https://github.com/microsoft/vscode/issues/338678](https://github.com/microsoft/vscode/issues/338678)

## Summary

Confirmed on current main: SessionsPart._gridSeparatorBorder falls back to agentsPanelBorder, which SplitView renders as a full-height 1px separator line, exactly as described — a real visual bug worth fixing, not a close.

## Change summary

In the Agents Window, side-by-side session views show a distracting full-height divider line instead of a quiet resize boundary.

## Best solution

Change SessionsPart._gridSeparatorBorder (src/vs/sessions/browser/parts/sessionsPart.ts) to return contrastBorder when defined, else Color.transparent, dropping the agentsPanelBorder fallback so the sash provides the resize affordance instead of a static line.
