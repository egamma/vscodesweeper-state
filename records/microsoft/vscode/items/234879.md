# Issue #234879 — SCM Graph - Add horizontal scrollbar for source control graph

[https://github.com/microsoft/vscode/issues/234879](https://github.com/microsoft/vscode/issues/234879)

## Summary

Keep open: the Source Control Graph still explicitly disables horizontal scrolling, and the existing workbench setting cannot override it. This requests a missing capability rather than demonstrating a regression in supported behavior.

## Change summary

Allow horizontal scrolling when Source Control Graph content exceeds the panel width, preferably including Shift+wheel support.

## Best solution

Make wide graph content accessible through the SCM history tree using consistent workbench scrolling interactions, while preserving normal vertical navigation and acceptable rendering performance.
