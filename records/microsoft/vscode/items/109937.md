# Issue #109937 — Render new lines in suggest widget details

[https://github.com/microsoft/vscode/issues/109937](https://github.com/microsoft/vscode/issues/109937)

## Summary

The current `auto-wrap` heuristic in the suggest details header was an intentional design refinement (from https://github.com/microsoft/vscode/issues/99370 and https://github.com/microsoft/vscode/issues/109717). The reporter wants newlines in the detail text to always render visibly — a reasonable polish request that tensions with the prior decision. No upvotes and stale since 2021, but already labeled `under-discussion` so it stays open for maintainer judgment.

## Change summary

Suggest widget detail view collapses authored newlines in the header text when the auto-wrap heuristic activates, making multi-line detail strings appear as a single paragraph.

## Best solution

A maintainer in the `suggest` area should decide whether the `auto-wrap` heuristic in `suggestWidgetDetails.ts` (line 161) should use `white-space: pre-wrap` instead of `white-space: normal` so that authored newlines are preserved while still allowing long lines to wrap. The CSS rule lives in `src/vs/editor/contrib/suggest/browser/media/suggest.css` line 405–408.
