# Issue #174999 — Allow me to search for markdown headers without manually inserting `-` delimiters

[https://github.com/microsoft/vscode/issues/174999](https://github.com/microsoft/vscode/issues/174999)

## Summary

Still unimplemented on main. The related PR #306561 was closed without merging. The feature request for fuzzy-matching markdown headers by natural text (with spaces) remains a valid gap — the current completion requires typing slugified dashes. Labeled `help wanted` and on the `On Deck` milestone, so it stays open.

## Change summary

Allow searching for markdown headers by natural text with spaces instead of requiring slugified dash-delimited names in the link autocomplete.

## Best solution

Implement the approach mjbvz suggested: add a 'Markdown: Insert Link to Header in File' command that shows a quick pick with all headers for fuzzy matching by natural text, inserting the properly slugified link. This would live in `extensions/markdown-language-features/src/commands/insertResource.ts` alongside the existing `InsertLinkFromWorkspace` and `InsertImageFromWorkspace` commands. The closed PR #306561 could serve as a reference implementation.
