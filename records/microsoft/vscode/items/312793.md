## Summary

Fixed on main by a generic error-handling guard in getChatHistoryImpl that catches any corrupted-session error (including this schema validation failure) and returns empty history instead of propagating the exception. Shipped in 1.122.0.

## Change summary

Opening a Copilot CLI session whose file was written by an older SDK version throws an unhandled 'Session file is corrupted' error because the newer SDK schema requires `compactionTokensUsed.input`.

## Best solution

Keep the shipped fix in commit 382e40aeea8 (1.122.0). The catch block in `getChatHistoryImpl` now gracefully handles any schema validation failure from `sessionManager.getSession()`, returning empty history instead of an unhandled error. No further change needed for this specific error bucket.
