[https://github.com/microsoft/vscode/issues/334542](https://github.com/microsoft/vscode/issues/334542)

## Summary

Keep open: current main still renders GitHub context as separate attachments, and the merged restoration PR deliberately postponed unified inline presentation rather than implementing it. This team-authored request records an accepted direction that existing inline-reference support only partially covers.

## Change summary

Present GitHub issues, pull requests, and other attached context consistently as pills within the chat input instead of separate attachments.
