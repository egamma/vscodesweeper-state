# Issue #288698 — Tool picker doesn't work properly when editing a prompt

[https://github.com/microsoft/vscode/issues/288698](https://github.com/microsoft/vscode/issues/288698)

## Summary

Fixed on current main: edited inline requests now snapshot the tool and instruction selections from the editor being submitted before that editor is disposed, preventing the bottom composer’s tool selection from overriding the edit.

## Change summary

Disabling the terminal execution tool while editing an earlier prompt was ignored when the edited request was submitted.

## Best solution

Keep the request-edit routing introduced by commit 78db8bfcd7073e5d0d4190b35ddab72cbc2922b8, which submits the edited prompt with the model, mode, tools, and subagents selected in its inline editor.
