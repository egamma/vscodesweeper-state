# Issue #336511 — Missing / commands for chat interface

[https://github.com/microsoft/vscode/issues/336511](https://github.com/microsoft/vscode/issues/336511)

## Summary

Both commands exist in the reported Insiders source, but only for supported Agent Host sessions: `/btw` is restricted to the Agents Window and `/goal` is a Copilot Agent Host alias for Plan mode. The remaining request appears to be parity for regular editor Chat, which is a valid chat-area feature request rather than a missing implementation across all chat surfaces.

## Change summary

Make the `/btw` side-question and `/goal` planning commands available in the regular chat interface.

## Best solution

Define provider-neutral regular-chat semantics for these commands: `/goal` should enter the existing Plan experience, while `/btw` should become available only after regular Chat can create and present a side conversation without disturbing the active request.
