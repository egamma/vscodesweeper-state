# Issue #266421 — MCP.json no error checking in user config, works in local vscode/mcp.json

[https://github.com/microsoft/vscode/issues/266421](https://github.com/microsoft/vscode/issues/266421)

## Summary

The inconsistency remains on current main: the MCP schema validates workspace `.vscode/mcp.json`, but the JSON validation contributions do not associate that schema with the user-profile `mcp.json`. This team-authored, accepted Backlog bug must remain open and has a bounded source-level diagnosis.

## Change summary

Apply MCP JSON schema validation consistently to user-profile `mcp.json`, including invalid remote server URLs.

## Best solution

Associate `vscode://schemas/mcp` with the default and named-profile user MCP resources, while retaining the existing workspace association, so both configuration scopes receive identical diagnostics and completions.
