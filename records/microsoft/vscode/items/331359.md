# Issue #331359 — When Codex or Claude already have models, you can no longer click Copilot if it has no models

[https://github.com/microsoft/vscode/issues/331359](https://github.com/microsoft/vscode/issues/331359)

## Summary

Team-authored bug report from today with no fix commit yet; traced the disabling logic in the session type picker that matches the described behavior, so it stays open and gets routed to the owning area.

## Change summary

In the Agents window session-type picker, when Codex/Claude have models configured but Copilot doesn't, the Copilot option is disabled/unclickable, preventing the user from selecting it to set it up.

## Best solution

In sessionTypePicker.ts, an unavailable session type (no models) is rendered as a fully disabled action-list item, so there's no way to click into it to configure models; the picker should let users select/open an unavailable-but-configurable provider (e.g. Copilot with zero models) rather than blocking the click entirely.
