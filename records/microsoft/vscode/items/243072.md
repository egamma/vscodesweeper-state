Keep open: the linked PR was explicitly an initial experimental adoption, while current main advertises the Marketplace flag but does not use it in gallery queries. This team-authored Backlog item therefore lacks evidence of complete implementation.

## Change summary

Use the Marketplace `IncludeLatestPrereleaseAndStableVersionOnly` query flag to reduce extension-query payloads while retaining the latest stable and pre-release versions.
