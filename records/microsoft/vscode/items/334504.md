# Issue #334504 — [Remote-SSH / Auth] PendingMigrationError: navigator is now a global in nodejs during extension initialization

[https://github.com/microsoft/vscode/issues/334504](https://github.com/microsoft/vscode/issues/334504)

## Summary

This is the same `PendingMigrationError: navigator is now a global in nodejs` error already tracked broadly (and with a documented workaround) by open issue #252077, which covers exactly this Remote-SSH/GitHub-authentication scenario among many others — consolidating there rather than tracking a new, narrower report.

## Change summary

Connecting via Remote-SSH throws PendingMigrationError: navigator is now a global in nodejs from the github-authentication and remote-ssh extensions during extension host startup, blocking Copilot auth initialization.

## Best solution

Close as a duplicate of https://github.com/microsoft/vscode/issues/252077, which already tracks this exact error message across Remote-SSH, WSL, and Copilot scenarios, documents the root cause (Node's global `navigator` colliding with extension code expecting the browser global) and the `extensions.supportNodeGlobalNavigator` setting workaround (implemented in src/vs/server/node/extensionHostConnection.ts and src/vs/platform/extensions/electron-main/extensionHostStarter.ts).
