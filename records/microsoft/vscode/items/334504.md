## Summary

Verified duplicate: this is another report of the well-tracked 'navigator is now a global in nodejs' Remote-SSH problem, already owned by the open, actively-discussed, maintainer-assigned canonical issue.

## Change summary

Remote-SSH sessions log PendingMigrationError ('navigator is now a global in nodejs') during extension activation (github-authentication, Remote-SSH, Copilot Chat), coinciding with extensions failing to initialize or the remote extension host restarting.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/252077 (open, labeled `debt`/`remote`/`ssh`, assigned to the engineer who owns the `PendingMigrationError` mechanism in src/vs/base/common/errors.ts and src/vs/platform/telemetry/common/errorTelemetry.ts) — it already tracks this exact symptom across many Remote-SSH users, with the `extensions.supportNodeGlobalNavigator` setting/workaround discussed at length there.
