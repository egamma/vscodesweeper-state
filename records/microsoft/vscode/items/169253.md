# Issue #169253 — Git - Untracked Folders

[https://github.com/microsoft/vscode/issues/169253](https://github.com/microsoft/vscode/issues/169253)

## Summary

This is a team-authored feature request for showing untracked folders in Source Control to avoid the performance cost of `git status -uall` in large monorepos. WIP commits exist on a branch but the work was tabled (comment 3) and never landed on main — current code still uses `-uall`. The issue remains valid and unimplemented; keeping open in Backlog.

## Change summary

Show untracked folders in the Source Control view instead of always running `git status -uall`, improving performance for large monorepos.

## Best solution

Implement the two-pass approach from comment 2: run `git status` (without `-uall`) to detect untracked folders, then selectively call `git status -uall folder1 folder2` to expand them. This lives in `extensions/git/src/git.ts` (the `getStatus` method) and `extensions/git/src/repository.ts`. The earlier WIP branch (commits 86209d2, e1045eb, dad1087) may provide a starting point, though the API gaps noted in comment 3 may still apply. The related community PR https://github.com/microsoft/vscode/pull/136698 (a simpler `statusArgs` setting) was closed in favor of this work — a commenter (comment 5) asks it be reconsidered as a stopgap.
