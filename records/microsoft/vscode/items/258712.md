# Issue #258712 — Runtime Status of GitHub Copilot Chat always reports 0 requests recently

[https://github.com/microsoft/vscode/issues/258712](https://github.com/microsoft/vscode/issues/258712)

## Summary

The bug remains source-reproducible on current main: language-model requests no longer update the extension-feature access data displayed by Runtime Status. The request path and regression are identified, so this is a bounded implementation candidate.

## Change summary

GitHub Copilot Chat's Runtime Status reports zero recent chat requests even after requests have been made.

## Best solution

Restore request attribution from the language-model request path to `LanguageModelStatsService`, preserving one usage record per successfully started extension request and covering it with a `MainThreadLanguageModels` regression test.
