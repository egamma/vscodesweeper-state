# Issue #243771 — sometimes when the terminal is wrapped, suggestions aren't provided

[https://github.com/microsoft/vscode/issues/243771](https://github.com/microsoft/vscode/issues/243771)

## Summary

Still reproduces on main: the `getCommand` call in `figInterface.ts` returns `null` when the terminal input wraps (newlines inflate `cursorIndex`), suppressing suggestions. The author noted this awaits their own command-parsing work. Team-authored, keeping open.

## Change summary

Terminal suggestions silently fail when the command line wraps across multiple lines because the cursor index includes newline characters.

## Best solution

Fix the cursor-index / command-line normalization in `extensions/terminal-suggest/src/fig/figInterface.ts` (and likely in the shell-parser layer) to strip or account for newlines injected by wrapping, so `getCommand` no longer returns `null`. The author indicated this would be addressed as part of adding custom command parsing.
