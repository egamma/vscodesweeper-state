# Issue #330398 — Dismissing a promo banner in one window should dismiss it in all windows.

[https://github.com/microsoft/vscode/issues/330398](https://github.com/microsoft/vscode/issues/330398)

## Summary

Team-authored (alexr00, MEMBER), brand-new feature request filed today — a hard keep-open case regardless of merits, and the source confirms the underlying gap is real: banner dismissal state isn't synced across windows.

## Change summary

When a user dismisses a promo banner in one window, it should also be dismissed in any other currently-open windows (not just future sessions).

## Best solution

In src/vs/workbench/browser/parts/banner/bannerPart.ts, hide()/show() only mutate local part state with no cross-window broadcast; wiring banner dismissal through a cross-window storage change event (similar to how other per-window UI state syncs via IStorageService with StorageScope.APPLICATION/PROFILE and onDidChangeValue) would let other windows react and hide the same banner live.
