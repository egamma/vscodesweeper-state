# Issue #124393 — [json] show number of children in JSON arrays

[https://github.com/microsoft/vscode/issues/124393](https://github.com/microsoft/vscode/issues/124393)

## Summary

This remains a valid Backlog feature request with 25 community upvotes. Current main has no JSON setting, command, hover augmentation, or folding annotation that exposes an array's item count, and no eligible older open canonical owns the request.

## Change summary

Show the number of elements in a JSON array through hover information or an inline editor annotation.

## Best solution

Expose JSON array counts through a lightweight, consistent editor affordance without adding always-on visual noise or changing behavior for other languages. A maintainer should first choose whether that affordance belongs in JSON hover output or the folded-range presentation.

## Plan brief

- **Likely files:** `extensions/json-language-features/server/src/jsonServer.ts`, `extensions/json-language-features/package.json`, `src/vs/editor/contrib/folding/browser/folding.ts`
- **Validation:** Add an automated JSON language-feature or editor-folding test proving that a JSON array with a known number of elements exposes the selected count presentation, while non-array JSON and other language folding remain unchanged.
- **Behavior:**

  > Users inspecting a JSON array can determine its number of top-level elements without manually counting them. The count should be available from the array delimiter or collapsed range through the interaction chosen by the maintainer. Nested arrays must report their own direct element counts, and non-array JSON values must not receive an array count. Existing JSON hover, schema information, and folding behavior must otherwise remain unchanged.
- **Trace:**

  > The built-in JSON server handles hover and folding in extensions/json-language-features/server/src/jsonServer.ts. `connection.onHover` delegates directly to `languageService.doHover`, while `connection.onFoldingRanges` delegates directly to `languageService.getFoldingRanges`; there is no count-enrichment layer. The JSON configuration in extensions/json-language-features/package.json exposes no existing count feature. The related open request https://github.com/microsoft/vscode/issues/272740 is newer and broader, so it is not a canonical for this re-reviewed issue. The uncertainty begins at presentation ownership: JSON-specific hover can use the parsed JSON document, whereas a persistent collapsed-range annotation involves the editor folding surface and must not become an inconsistent language-specific decoration.
- **Open decisions:**
  - Should the count appear only when hovering the JSON array delimiter, or persist inline when the array is folded?
