## Summary

The requested worktree setup capabilities are implemented: ignored dependencies can be copied through git.worktreeIncludeFiles, and initialization commands can run through worktree-created tasks. Propose closing as completed; dependency copying is now configurable rather than automatic.

## Change summary

Support preparing newly created Copilot CLI worktrees with dependencies and configurable initialization commands.

## Best solution

Use git.worktreeIncludeFiles to copy ignored dependency folders, or tasks with runOptions.runOn set to worktreeCreated for installation and submodule initialization. Preserve opt-in setup rather than disabling language features in worktrees.
