# Issue #276834 — CLI worktree: node modules not copied over to the worktree folder

[https://github.com/microsoft/vscode/issues/276834](https://github.com/microsoft/vscode/issues/276834)

## Summary

Both proposals from this issue have been implemented on main and shipped: `git.worktreeIncludeFiles` for copying files (including node_modules) on worktree creation, and `TaskRunOn.WorktreeCreated` for running post-creation tasks. This can be closed as completed.

## Change summary

When creating a git worktree, node_modules and other dependency folders are not copied over, causing TypeScript errors; the reporter also requested extensible post-creation scripts.

## Best solution

Keep the shipped behavior: `git.worktreeIncludeFiles` (experimental, 1.109) lets users specify glob patterns for files to copy on worktree creation, and `TaskRunOn.WorktreeCreated` (1.112) enables running tasks automatically after worktree creation — together these cover both proposals.
