# Issue #338508 — Terminal-completion auto-turn loses custom agents and subagent invocation tool

[https://github.com/microsoft/vscode/issues/338508](https://github.com/microsoft/vscode/issues/338508)

## Summary

Detailed, technically credible report of a race between a terminal-completion auto-turn (system-initiated 'Steering' request) and the chat request's available tool/customization set, but the reporter themselves could not pin the exact trigger or root cause, and no one else has confirmed it — asking for more detail before diagnosis is warranted.

## Change summary

After a background terminal command finishes, the automatic follow-up chat turn it triggers sometimes has a reduced tool set (missing runSubagent) and zero discovered custom agents, stalling a pending subagent handoff until the user sends a normal message.

## Best solution

If reproducible, ensure the system-initiated 'Steering' request built by RunInTerminalTool.commandDetection.onCommandFinished (src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/runInTerminalTool.ts) resolves the same fresh customization/tool set as a normal user turn, rather than a stale or partially-initialized snapshot; likely intersects the Agent Host customization/tool computation in agentHostSessionHandler.ts.
