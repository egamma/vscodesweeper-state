[https://github.com/microsoft/vscode/issues/174255](https://github.com/microsoft/vscode/issues/174255)

## Summary

This team-authored Backlog request remains unimplemented in the extension page: current main displays only `activateCallTime` in Runtime Status, despite retaining all three timing components. No open canonical issue or competing pull request was found, so the request should remain open.
