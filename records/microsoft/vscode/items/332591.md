# Issue #332591 — Avoid remote agent warning when no remote authority is configured

[https://github.com/microsoft/vscode/issues/332591](https://github.com/microsoft/vscode/issues/332591)

## Summary

Confirmed on main: the warning log fires unconditionally whenever `_remoteAgentService.getConnection()` is undefined, even when no `remoteAuthority` was configured at all (the normal web/local case) — it should only warn when a remote authority was set but the connection failed.

## Change summary

VS Code Web logs a misleading 'No remote agent connection available. Not connecting.' warning even when no remote authority is configured.

## Best solution

In `EditorRemoteAgentHostServiceClient`'s constructor, only log the warning when `environmentService.remoteAuthority` is truthy but `connection` is still undefined; skip the warning silently on the normal no-remote path.
