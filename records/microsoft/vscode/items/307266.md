# Issue #307266 — Support per-profile AppUserModelID and taskbar icon on Windows

[https://github.com/microsoft/vscode/issues/307266](https://github.com/microsoft/vscode/issues/307266)

## Summary

Per-profile Windows taskbar identity and independent Jump Lists remain missing. Related requests cover icon customization or profile pinning, but neither establishes a canonical issue or a decline decision covering this request's full scope.

## Change summary

Give Windows profiles distinct taskbar groups, pinnable custom icons, and independent Jump Lists.

## Best solution

Have the profile and Windows integration owners decide whether profiles should have independent shell identities, including profile-preserving launches and separate recent-item lists. Treat this as a coordinated product capability rather than assuming a profile-name suffix on the process-wide AppUserModelID delivers the whole experience.
