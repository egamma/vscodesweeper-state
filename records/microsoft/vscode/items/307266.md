# Issue #307266 — Support per-profile AppUserModelID and taskbar icon on Windows

[https://github.com/microsoft/vscode/issues/307266](https://github.com/microsoft/vscode/issues/307266)

## Summary

The same per-profile OS application identity was previously declined as out of scope. The custom taskbar-icon subset remains tracked separately, but profile-specific grouping and Jump Lists do not need another issue.

## Change summary

Give each Windows profile its own AppUserModelID, taskbar group, Jump List, and configurable icon.

## Best solution

Retain VS Code's single application identity and follow https://github.com/microsoft/vscode/issues/248638 for the accepted taskbar-icon customization work; do not add profile-specific Windows application identities or Jump Lists.

## Vision fit

- **Fit:** rejected
- **Reason:** Creating platform-specific application identities and configurable icons for individual profiles adds niche configuration and OS surface to the default product.
- **Evidence:** Values and guardrails favor a lightweight default experience and uniform UI rather than per-feature visual customization and configuration sprawl.
