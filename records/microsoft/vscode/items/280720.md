# Issue #280720 — `chat.tools.eligibleForAutoApproval` setting doesn't work with tools from extensions

[https://github.com/microsoft/vscode/issues/280720](https://github.com/microsoft/vscode/issues/280720)

## Summary

Keep open: current source still suggests unqualified extension tool names in settings but checks qualified names at runtime, allowing a configured false value to be ignored. This is a VS Code configuration/enforcement mismatch, not an extension-owned defect.

## Change summary

Extension tools configured as ineligible for automatic approval execute without the expected confirmation and restriction disclaimer.

## Best solution

Make the tool identifiers offered by chat.tools.eligibleForAutoApproval agree with runtime eligibility matching, so configuring an extension tool as false reliably requires confirmation. Preserve qualified identifiers and existing legacy-name compatibility.
