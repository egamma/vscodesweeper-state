# Issue #334093 — [error] Failed to compute embeddings for tools: Error: Error fetching embeddings: 422

[https://github.com/microsoft/vscode/issues/334093](https://github.com/microsoft/vscode/issues/334093)

## Summary

Fresh, well-documented report (attached Copilot Chat log and tool-search debug JSON) that the remote embeddings backend is returning 422 for this user, and the tool-search embedding pipeline has no fallback when that happens — tools whose embeddings can't be computed simply never surface in search results. Real gap, but too new (0 comments, same day) and too dependent on an external service response to close yet.

## Change summary

When the remote embeddings endpoint returns HTTP 422, `#toolSearch` can't find/return tools whose embeddings failed to compute, making explicitly-enabled non-built-in tools effectively uncallable by name.

## Best solution

Add graceful degradation in ToolEmbeddingsComputer/ToolSearchTool for embeddings-service failures (e.g. fall back to substring/name matching against the tool name+description, or surface the failure to the caller instead of silently dropping the tool from results) in src/extension/tools/common/virtualTools/toolEmbeddingsComputer.ts and src/extension/tools/node/toolSearchTool.ts; separately, the 422 itself may indicate a payload issue worth checking server-side (batch size/format) for this user's tool set.
