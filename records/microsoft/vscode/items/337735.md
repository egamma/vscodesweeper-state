# Issue #337735 — Latest VS Code regressed consistently inserting text with tools like Windows voice access

[https://github.com/microsoft/vscode/issues/337735](https://github.com/microsoft/vscode/issues/337735)

## Summary

Confirmed regression: a contributor identified the cause as recent native EditContext changes and an open revert PR (#338393) is already up to fix it — nothing to close or hand to an agent while a human-owned fix is in flight.

## Change summary

Text dictated via Windows Voice Access (and likely other IME/accessibility input tools using the native EditContext) stops being inserted into the editor after the first phrase, regressing from 1.138.0 to 1.139.0/1.140.0.

## Best solution

Land the revert in https://github.com/microsoft/vscode/pull/338393 (which reverts the deferred native EditContext refresh from the fix for the large case-conversion freeze, issue #262473); track the freeze fix separately if it needs to be reapplied without this regression.
