# Issue #140056 — There should be a way in the vscode API to resolve configuration variables

[https://github.com/microsoft/vscode/issues/140056](https://github.com/microsoft/vscode/issues/140056)

## Summary

Still an open, valid feature request with 35 upvotes in the Backlog. No API for resolving configuration variables (${workspaceFolder}, ${env:...}, ${config:...}) has been added to the extension API, and the related PR #148514 was closed without merging due to design concerns. The gap remains real.

## Change summary

Expose a VS Code extension API to resolve configuration variables like ${workspaceFolder}, ${env:VAR}, and ${config:setting} so extensions don't have to re-implement variable substitution.

## Best solution

Design and expose a variable-resolution API for extensions — either a standalone `workspace.resolveVariables(string)` method or enriched `WorkspaceConfiguration.getResolved()` accessors. The internal `IConfigurationResolverService` (src/vs/workbench/services/configurationResolver/) already does this work; the challenge is finding a performant, well-scoped API surface. The stalled PR #148514 and its design feedback are the starting point.
