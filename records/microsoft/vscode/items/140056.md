# Issue #140056 — There should be a way in the vscode API to resolve configuration variables

[https://github.com/microsoft/vscode/issues/140056](https://github.com/microsoft/vscode/issues/140056)

## Summary

The requested extension API remains missing, but the older, verified-open issue https://github.com/microsoft/vscode/issues/46471 already tracks the same observable limitation and fully covers this request. Propose consolidating there, preserving this report's API alternatives and the maintainer's design concerns.

## Change summary

Expose VS Code's variable-resolution capabilities to extensions so configuration values containing workspace, environment, and configuration references need not be expanded independently.

## Best solution

Consolidate the API work in https://github.com/microsoft/vscode/issues/46471, carrying forward the standalone resolver and getResolved alternatives. Resolve the API design and performance concerns before implementing it, without changing existing configuration-read semantics implicitly.
