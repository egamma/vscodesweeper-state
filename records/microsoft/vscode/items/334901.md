# Issue #334901 — Review comments clipped in multi-file diff editor

[https://github.com/microsoft/vscode/issues/334901](https://github.com/microsoft/vscode/issues/334901)

## Summary

The clipping path remains in current main: the Agents review overlay does not opt into editor overflow, while multi-file diff items hide overflowing content. This team-authored issue should remain open; there is no issue-linked fix commit or verified older duplicate.

## Change summary

Expanded PR review comments are clipped at the boundary of their file entry in the Agents Window multi-file diff editor.

## Best solution

Keep the review overlay fully visible when it extends beyond an individual multi-file diff entry, while preserving its line anchor and constraining it to the overall editor viewport. Add a multi-file diff component fixture that covers an expanded comment near an entry boundary.
