# Issue #326978 — Chat scroll-down ("jump to bottom") button never appears — inline display:'' is overridden by `.interactive-session .chat-scroll-down { display: none }` (dead `show-scroll-down` class)

[https://github.com/microsoft/vscode/issues/326978](https://github.com/microsoft/vscode/issues/326978)

## Summary

Team-authored cleanup issue for dead CSS and fragile visibility logic around the chat scroll-down button. PR #326961 fixed the immediate visibility bug, but the dead `show-scroll-down` class and conflicting display mechanisms remain on current main. Valid debt item to keep open.

## Change summary

Remove dead `show-scroll-down` CSS class and consolidate the chat scroll-down button's visibility to a single toggle mechanism instead of competing inline styles and CSS rules.

## Best solution

Clean up in `src/vs/workbench/contrib/chat/browser/widget/media/chat.css`: remove the dead `.interactive-session.show-scroll-down .chat-scroll-down` rule, and either drive visibility purely via inline styles (as PR #326961 does with `display: flex`) or purely via a toggled class — not both. A small DOM-level test that the button becomes visible when not scrolled to bottom would prevent regression.
