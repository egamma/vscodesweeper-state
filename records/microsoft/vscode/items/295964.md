# Issue #295964 — file comparison selection is inverted

[https://github.com/microsoft/vscode/issues/295964](https://github.com/microsoft/vscode/issues/295964)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/226883 already tracks the inconsistent left/right ordering of files selected for comparison across Explorer, Open Editors, and editor tabs.

## Change summary

Restore predictable comparison ordering so the first selected file appears on the left and the second appears on the right.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/226883 and make Compare Selected use one documented ordering rule across Explorer, Open Editors, and editor tabs.
