# Issue #235393 — Update Button missing

[https://github.com/microsoft/vscode/issues/235393](https://github.com/microsoft/vscode/issues/235393)

## Summary

This is as-designed: the user-setup installation intentionally disables updates when VS Code is run as administrator, because the user-level installer cannot safely update under elevated privileges. The reporter confirmed running as admin with user setup.

## Change summary

The 'Check for Updates' option is missing from the Help menu when running VS Code user-setup as administrator on Windows.

## Best solution

Close as designed. The update mechanism is intentionally disabled when the user-setup variant runs elevated — this prevents corruption. The reporter should run VS Code as a standard user (not admin) to see the update button, as suggested by team members in comments.
