[https://github.com/microsoft/vscode/issues/312303](https://github.com/microsoft/vscode/issues/312303)

## Summary

The modal dialog ordering issue when multiple Remote-SSH windows lose connection is owned by the Remote-SSH extension (microsoft/vscode-remote-release). This should be moved to that tracker so the Remote team can address it.

## Change summary

When multiple Remote-SSH windows lose connection, the reconnection dialogs are modal and must be dismissed in a specific order, blocking interaction with other windows.

## Best solution

Move this issue to microsoft/vscode-remote-release where the Remote-SSH team owns the reconnection dialog lifecycle. The core remote reconnection handler in VS Code shows a progress notification, but the SSH-specific connection-lost modal dialogs are driven by the Remote-SSH extension.
