# Issue #312303 — Remote connection locks other windows

[https://github.com/microsoft/vscode/issues/312303](https://github.com/microsoft/vscode/issues/312303)

## Summary

Keep this report open to investigate cross-window dialog blocking on Linux. The reporter repeated the same behavior on a newer build, and a maintainer identified native Linux dialog handling as a possible cause; neither a fix nor a qualifying duplicate is established.

## Change summary

After several Remote-SSH windows lose their connections, reconnect dialogs must be dismissed in a particular order because they block interaction with one another.

## Best solution

Ensure reconnect dialogs do not prevent interaction with dialogs belonging to other VS Code windows. First distinguish VS Code dialog ownership from Electron/GTK modality on Ubuntu Wayland; retain this issue as the canonical report for the repeated filing.
