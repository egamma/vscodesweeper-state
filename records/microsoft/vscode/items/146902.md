# Issue #146902 — Confusing suffix on description of boolean property of settings object

[https://github.com/microsoft/vscode/issues/146902](https://github.com/microsoft/vscode/issues/146902)

## Summary

Still reproduces on main: the ObjectSettingCheckboxWidget appends the property key name in parentheses after the description text (e.g. 'Controls ... (enabled)'), which is confusing for boolean object properties that already have a meaningful description.

## Change summary

Boolean properties of object settings show a confusing parenthesized suffix of the JSON property name after the human-readable description.

## Best solution

Remove or conditionally hide the `(${item.key.data})` suffix in `ObjectSettingCheckboxWidget.renderEdit` when a `keyDescription` is already present, since the property name is redundant for most users and only useful for JSON editing.
