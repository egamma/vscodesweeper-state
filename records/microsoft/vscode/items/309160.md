# Issue #309160 — Terminal: Missing devicePixelRatio listener causes misalignment on zoom

[https://github.com/microsoft/vscode/issues/309160](https://github.com/microsoft/vscode/issues/309160)

## Summary

Real bug — the terminal canvas uses `window.devicePixelRatio` for dimension calculations but has no listener for DPR/zoom changes, so it renders with stale dimensions until a manual re-layout is triggered. An open community PR (#309165) addresses this but has not been reviewed.

## Change summary

Terminal canvas misaligns (clipping, blank space, detached ghost text) when the editor zoom level changes because no listener triggers a layout recalculation on devicePixelRatio change.

## Best solution

Review and land (or close with feedback) the open PR https://github.com/microsoft/vscode/pull/309165, which adds `PixelRatio.onDidChange` and `onDidChangeZoomLevel` listeners to `TerminalInstance` — matching the established pattern used by the editor, color picker, debug toolbar, and other components.
