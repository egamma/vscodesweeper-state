# Issue #337397 — Browser integration in VS Code does not support Ctrl+Insert / Shift+Insert for copy/paste

[https://github.com/microsoft/vscode/issues/337397](https://github.com/microsoft/vscode/issues/337397)

## Summary

Plausible parity request for the integrated Browser view: Ctrl+Insert/Shift+Insert already work for copy/paste in the text editor on Windows/Linux, but the embedded Chromium browser content doesn't recognize these as clipboard shortcuts (neither does that upstream in stock Chrome/Edge). No maintainer input or community demand yet (0 reactions, filed hours ago), so this stays open as a fresh feature request rather than being closed.

## Change summary

Add Ctrl+Insert (copy) and Shift+Insert (paste) keyboard shortcut support inside the VS Code integrated Browser view.

## Best solution

If pursued, extend the existing before-input-event forwarding in src/vs/platform/browserView/electron-main/browserView.ts (currently only forwards unhandled keys when the page isn't visible/available) to also recognize Ctrl+Insert/Shift+Insert while the page is available and invoke webContents.copy()/paste() directly, mirroring how the editor's own clipboard.ts binds these keys on Windows/Linux.

## Evidence

- **editor precedent:** src/vs/editor/contrib/clipboard/browser/clipboard.ts binds KeyMod.CtrlCmd|KeyCode.Insert (copy) and KeyMod.Shift|KeyCode.Insert (paste) as secondary keybindings on Windows/Linux native builds, so VS Code's own editor already supports this convention.
- **browser view key handling:** src/vs/platform/browserView/electron-main/browserView.ts's before-input-event handler (lines 478-508) only forwards key events to the workbench when the page is not visible/available or crashed; when the page is available, Chromium handles keys natively, and stock Chromium does not map Ctrl+Insert/Shift+Insert to copy/paste, so the gap likely matches stand-alone browser behavior too.
- **no clipboard shortcut feature file:** No file under src/vs/workbench/contrib/browserView registers Ctrl+Insert/Shift+Insert or any browser-specific clipboard command; only native Electron context-menu roles ('copy'/'paste') exist in browserViewMainService.ts.
