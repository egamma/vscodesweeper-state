# Issue #347835 — Agent Host: a local agent plugin (chat.pluginLocations) keeps running from a stale copy after a file in a subfolder is added

[https://github.com/microsoft/vscode/issues/347835](https://github.com/microsoft/vscode/issues/347835)

## Summary

The stale-copy defect remains in current source: plugin revisions depend only on the root directory's modified time, so nested additions can leave the persisted Agent Host copy unchanged. Keep open for a bounded customization-sync fix.

## Change summary

Refresh Agent Host plugin copies when nested plugin files change, without requiring a root-folder modification and host restart.

## Best solution

Plugin revision tracking should reflect nested content changes and deliver refreshed customizations to subsequent Agent Host chats while preserving caching for unchanged plugins and retained revisions used by existing sessions.
