# Issue #347835 — Agent Host: a local agent plugin (chat.pluginLocations) keeps running from a stale copy after a file in a subfolder is added

[https://github.com/microsoft/vscode/issues/347835](https://github.com/microsoft/vscode/issues/347835)

## Summary

Keep open: current source derives configured-plugin revisions solely from the root directory's modification time, so nested changes can indefinitely reuse a stale Agent Host copy. The report provides sufficient reproduction steps and a workaround that matches this path.

## Change summary

Refresh configured local plugins in Agent Host chats when their nested files change, without requiring a root-directory timestamp change and host restart.

## Best solution

Make configured-plugin revision detection reflect nested plugin changes so newly started Agent Host chats receive the current plugin contents. Preserve reuse of unchanged revisions and avoid overwriting copies retained by running sessions.
