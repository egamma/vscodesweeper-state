# Issue #347835 — Agent Host: a local agent plugin (chat.pluginLocations) keeps running from a stale copy after a file in a subfolder is added

[https://github.com/microsoft/vscode/issues/347835](https://github.com/microsoft/vscode/issues/347835)

## Summary

The stale-copy path remains in current source: local plugin revisions depend only on the root directory's modified time, so adding agents/b.md can leave Agent Host using its cached revision.

## Change summary

Nested changes to locally configured plugins should reach new Agent Host chats without touching the plugin root or restarting the host.

## Best solution

Make forwarded plugin revision tracking reflect nested content changes and deliver those revisions through the existing customization refresh path. Preserve cache reuse for unchanged plugins and retained revisions used by existing sessions.
