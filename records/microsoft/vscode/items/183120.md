# Issue #183120 — Debugging indicators can mess with tab spacing

[https://github.com/microsoft/vscode/issues/183120](https://github.com/microsoft/vscode/issues/183120)

## Summary

Keep open: the current debug indicator still injects a character that participates in subsequent tab expansion, including when its CSS removes it from normal layout. The supplied canonical candidate concerns a different behavior, and no verified fix or duplicate was found.

## Change summary

Stopping or stepping in the debugger can change the rendered width of tabs on the highlighted source line.

## Best solution

Preserve each source tab's normal expansion when displaying the stack-frame column indicator, while retaining the indicator and its existing placement behavior. Keep the correction specific to debug decoration behavior unless broader injected-text changes are demonstrably necessary.
