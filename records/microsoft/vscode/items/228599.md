# Issue #228599 — Consider how we might improve navigation to chat response content for screen reader users

[https://github.com/microsoft/vscode/issues/228599](https://github.com/microsoft/vscode/issues/228599)

## Summary

Keep open for an accessibility design decision: current main retains listitem roles, and the proposed document-role PR closed without merging. Moving actions to the footer partially addresses the original navigation overhead, but does not establish an efficient cross-platform route into rendered response content.

## Change summary

Improve screen reader navigation directly into rendered chat response content while preserving access to links, response actions, neighboring messages, and the input.

## Best solution

Establish a discoverable way to enter and leave rendered response content without traversing unrelated controls or compromising conversation navigation. Choose the interaction with NVDA, JAWS, Orca, and VoiceOver compatibility in mind rather than treating a document-role substitution as sufficient.
