# Issue #340844 — Copilot Chat does not map properly custom agent model setting to task tool model list

[https://github.com/microsoft/vscode/issues/340844](https://github.com/microsoft/vscode/issues/340844)

## Summary

Thanks for the report. The description is complete enough to retest: a custom agent's model setting, the model ID the task tool lists, and an `invalid_model` result. I could not confirm it from source because it depends on the model catalog and BYOK/OpenAI vendor setup, and the reporter says only some machines are affected. It stays open for an owner to look at.

## Change summary

A custom agent's configured model name ("GPT-6 Sol (openai)") does not match the model ID format listed by the task/subagent tool, so running it as a subagent fails with `invalid_model`.

## Best solution

Make subagent model resolution (runSubagentTool.ts resolveSubagentModel and the model list shown to the tool) accept the same "Model Name (Vendor)" form the custom agent editor suggests. A model the user selected should never produce `invalid_model`. Then work out why it differs between machines, for example a different set of available models or vendors.
