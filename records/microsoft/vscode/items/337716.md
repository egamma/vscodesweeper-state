# Issue #337716 — Agents window: add separation around sticky user messages and keep session sashes unobstructed with custom backgrounds

[https://github.com/microsoft/vscode/issues/337716](https://github.com/microsoft/vscode/issues/337716)

## Summary

Fresh, well-diagnosed report (0 days old) that matches current main exactly: the custom-background sticky-scroll CSS hides both scroll shadows and leaves a full-width sticky surface with no bottom gap, which can compete with the inter-session grid sash. Real gap remains; the issue itself lists several viable design directions, so it needs a maintainer's design call before implementation.

## Change summary

In the Agents window, a sticky (pinned) user request lacks breathing room and a scroll-shadow cue when a custom chat background is enabled, and its full-width sticky surface can interfere with the inter-session resize sash.

## Best solution

Scope a fix to the Sessions custom-background presentation: add bottom spacing/an inset content band for the sticky row, restore a theme-aware scroll-edge treatment, and ensure the sticky surface's hit area doesn't extend into the SerializableGrid sash region — but the exact treatment (reserve space vs. restore the tree's shadow vs. inset to the content band) is a design choice worth settling first.
