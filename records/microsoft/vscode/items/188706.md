# Issue #188706 — Editor does not re-evaluate indentation after quickfix 

[https://github.com/microsoft/vscode/issues/188706](https://github.com/microsoft/vscode/issues/188706)

## Summary

Keep open: the current quick-fix edit path changes indentation text without refreshing the model's indentation options, which format-on-save subsequently passes to the formatter. This team-authored, accepted bug has no verified fix or older same-symptom canonical issue.

## Change summary

After a quick fix converts a space-indented file to tabs, saving should not convert it back because the editor retained stale indentation options.

## Best solution

Keep the editor's detected indentation consistent with an indentation-changing quick fix before subsequent formatting uses it. Scope the correction to this workflow without changing ordinary typing, explicitly configured indentation, or unrelated workspace edits.
