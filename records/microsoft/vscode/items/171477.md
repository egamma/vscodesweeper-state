# Issue #171477 — Diff/Merge Editor: Improve Horizontal Scrolling

[https://github.com/microsoft/vscode/issues/171477](https://github.com/microsoft/vscode/issues/171477)

## Summary

Keep open: diff and merge editors synchronize horizontal positions, but their independent scroll ranges still leave the requested improvement unmet. This is accepted, team-authored work; no qualifying fix or older canonical was identified.

## Change summary

Allow either synchronized horizontal scrollbar to reveal the full content of both editors without switching scrollbars.

## Best solution

Provide a coordinated horizontal scroll range for participating diff and merge panes so the shorter-content pane can drive scrolling through the longer pane's content, while preserving existing vertical alignment and ordinary editor behavior.
