# Issue #275655 — Polish shell integration message for slow shell startups

[https://github.com/microsoft/vscode/issues/275655](https://github.com/microsoft/vscode/issues/275655)

## Summary

Keep this as the canonical notification-polish item: current main still recommends enabling shell integration when detection times out, without explaining slow startup or pointing to the timeout setting. Later reports were explicitly consolidated here, and the desired wording and notification frequency remain unsettled.

## Change summary

Make chat terminal shell-integration guidance accurate and less repetitive when shell startup exceeds the detection timeout.

## Best solution

Provide actionable guidance that distinguishes unavailable shell integration from delayed detection, with an agreed per-terminal notification frequency. Review the launch-preference cache without changing command execution or timeout defaults beyond the agreed scope.
