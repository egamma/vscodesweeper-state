# Issue #311559 — [Error] chatagenterror-Open a GitHub repository to use the cloud agent.

[https://github.com/microsoft/vscode/issues/311559](https://github.com/microsoft/vscode/issues/311559)

## Summary

Still reproduces on main: the Copilot extension throws a plain `Error` for this validation message instead of using the new `ChatExpectedError` name, so it still pollutes the chatAgentError telemetry bucket. The core-side suppression mechanism landed in 3727d0cef92 but the extension hasn't adopted it for this throw site.

## Change summary

The user-facing validation message 'Open a GitHub repository to use the cloud agent' is logged as an error in telemetry because it's thrown as a plain Error instead of a ChatExpectedError.

## Best solution

Update the `throw new Error(…)` in `extensions/copilot/src/extension/chatSessions/vscode-node/copilotCloudSessionsProvider.ts` (and the two similar sites in `copilotCloudGitOperationsManager.ts`) to throw with `name = 'ChatExpectedError'` so the `isExpectedError` suppression in `mainThreadChatAgents2.ts` filters them from telemetry.
