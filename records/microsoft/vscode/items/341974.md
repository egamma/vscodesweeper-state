# Issue #341974 — Copilot models disappear when a second GitHub account used

## Summary

Thanks for the detailed report. It describes a clear scenario (two GitHub accounts, Copilot pinned to the enterprise one, models vanish once the second account's session initializes) with logs showing the token and model metadata fetched successfully. I did not trace the Copilot Chat account-change handling in source, and the multi-account flow needs live auth, so this stays open and unconfirmed.

## Change summary

Copilot's model picker shows 'No models are available' after a second GitHub account session initializes, even though Copilot is pinned to the enterprise account.

## Best solution

Make Copilot's handling of authentication session change events ignore sessions from accounts the Copilot extension is not assigned to, so the model registry is not cleared or refreshed with the wrong session. The likely place is the Copilot Chat auth/model refresh code under extensions/copilot.
