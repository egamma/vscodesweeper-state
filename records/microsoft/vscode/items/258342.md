# Issue #258342 — `Chat: Show Chats` command doesn't respect Chat in Editor

[https://github.com/microsoft/vscode/issues/258342](https://github.com/microsoft/vscode/issues/258342)

## Summary

The reported path was removed on main: the legacy `Chat: Show Chats` command and picker were retired, so they can no longer open the secondary sidebar or route the selected chat there.

## Change summary

Make the Show Chats command preserve the editor location when invoked from a Chat Editor.

## Best solution

Keep the completed migration away from the legacy chat-history picker and use the current Sessions experience for navigating chats; no change to the retired command is needed.
