## Summary

This is a bug in the Python Environments extension (ms-python.vscode-python-envs) or the Python extension (ms-python.python), which are Microsoft extensions maintained outside this repository. The built-in python extension in microsoft/vscode only provides language grammars — the interpreter picker, Conda discovery, and environment management all live in the external extensions.
