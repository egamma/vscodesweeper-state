# Issue #325133 — Agents window should support the same local Copilot agent harness as the Chat view

[https://github.com/microsoft/vscode/issues/325133](https://github.com/microsoft/vscode/issues/325133)

## Summary

The Agents window already has a LocalChatSessionsProvider (gated behind `sessions.chat.localAgent.enabled`) that wraps local in-process chat sessions, and related issues track specific parity gaps — but there is no single canonical issue that fully absorbs this umbrella request for complete local Copilot agent harness parity. Keeping open as a valid feature request that aligns with current agent-experience priorities.

## Change summary

The Agents window should support the same local Copilot agent harness (with full tool, MCP, model, and session parity) as the Chat view sidebar.

## Best solution

This is a valid umbrella-style request. The local agent provider exists at `src/vs/sessions/contrib/providers/localChatSessions/` but is behind a feature gate and has known parity gaps (MCP/BYOK per https://github.com/microsoft/vscode/issues/317895, session visibility per https://github.com/microsoft/vscode/issues/325132). Route to the agents-window area owner to assess whether this umbrella adds value beyond the individual tracked items, or whether it should be consolidated into https://github.com/microsoft/vscode/issues/325132.
