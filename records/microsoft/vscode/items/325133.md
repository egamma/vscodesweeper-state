# Issue #325133 — Agents window should support the same local Copilot agent harness as the Chat view

[https://github.com/microsoft/vscode/issues/325133](https://github.com/microsoft/vscode/issues/325133)

## Summary

The same local Copilot harness request is already tracked by an older, verified open issue. Consolidate there while preserving this report's emphasis on native workbench capabilities and compatible session continuation.

## Change summary

Let the Agents window run the Chat view's native local Copilot harness without requiring users to switch backends, with compatible history and capability parity.

## Best solution

Track native local-harness availability and its capability and session-continuation requirements in https://github.com/microsoft/vscode/issues/318358. Local-model support through the Copilot CLI harness addresses part of the concern, but does not establish that the original workbench harness is supported.
