# Issue #338171 — The tab icon is missing if the filename is 'git', regardless of its extension.

[https://github.com/microsoft/vscode/issues/338171](https://github.com/microsoft/vscode/issues/338171)

## Summary

Confirmed on main: the connected-tab width compression in multiEditorTabsControl.ts measures a short name's minimum width using the first grapheme plus an ellipsis, which can exceed the full short name's actual width, so names like 'git' get wrongly flagged narrow and lose their icon. Two open PRs (#339489, #340028) already target this fix, so the issue stays open pending one of them landing.

## Change summary

Tab icons disappear for short filenames (e.g. 'git.sh') in connected/compact tab mode because the narrow-width heuristic misfires.

## Best solution

Land one of the open fix PRs (#339489 or #340028) against layoutConnectedTabLabels in multiEditorTabsControl.ts so the minimum-width estimate for short names never exceeds the full rendered name width.

## Evidence

- **source trace:** src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts layoutConnectedTabLabels() computes minimumNameWidth from only the first grapheme + '…', then marks a tab 'connected-tab-narrow' (hiding the icon via CSS) when tab.offsetWidth < minimum + 22; for short names like 'git' the truncated-form estimate can exceed the real rendered width, misfiring.
- **maintainer repro:** benibenj (CONTRIBUTOR) reproduced in a clean profile and traced it to the connected-tab compression work from #335605, confirming other short names ('it.sh', 'iii.sh') are affected while longer ones ('gitx.sh', 'github.sh') are not.
