# Issue #338171 — The tab icon is missing if the filename is 'git', regardless of its extension.

[https://github.com/microsoft/vscode/issues/338171](https://github.com/microsoft/vscode/issues/338171)

## Summary

Confirmed root cause on main (connected-tab width measurement misclassifies short names like 'git' as narrow, hiding the icon); a contributor already opened a fix PR, so this stays open pending review/merge rather than any close.

## Change summary

Tab icon disappears for filenames whose base name is short (e.g. 'git.sh') because the compressed-tab layout mistakenly marks the tab as narrow.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/339489, which targets the minimum-width calculation in multiEditorTabsControl.ts's layoutConnectedTabLabels.

## Evidence

- **root cause confirmed:** src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts layoutConnectedTabLabels() computes minimumNameWidth from the ellipsized form (first grapheme + '…') and compares tab.offsetWidth < minimum + 22 to toggle 'connected-tab-narrow'; for short names like 'git' the ellipsized measurement can exceed the full name's rendered width, so the tab is wrongly flagged narrow and the icon is hidden via CSS.
- **contributor repro:** benibenj (CONTRIBUTOR) reproduced in a clean profile with extensions disabled, traced it to the same connected-tab compression work (referenced as #335605), and confirmed the calculation is still on main as of 2026-09-28.
- **open fix PR:** cdce8p opened https://github.com/microsoft/vscode/pull/339489 ('Fix missing tab icons for short file names') with a possible fix; it is still open/unmerged.
