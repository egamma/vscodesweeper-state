Keep open: the report independently demonstrates the public MCP registry rejecting its own continuation cursor. Current main has changed pagination and added bounded recovery, but that mitigation does not establish that the registry defect is resolved.

## Change summary

MCP Gallery browsing fails when the registry rejects a continuation cursor returned by its own preceding page.
