# Issue #328072 — Error on generating commit message by copilot

[https://github.com/microsoft/vscode/issues/328072](https://github.com/microsoft/vscode/issues/328072)

## Summary

Same underlying defect as the older, open https://github.com/microsoft/vscode/issues/316204: the git commit-message generator's request to gpt-4o-mini is rejected server-side with `422 promptFiltered`, and the extension silently returns undefined with no user-visible error — traced in gitCommitMessageGenerator.ts, which only special-cases QuotaExceeded/RateLimited and otherwise swallows every other ChatFetchResponseType (including PromptFiltered) without any notification.

## Change summary

Generating a commit message with GitHub Copilot fails silently (empty message box, no error) whenever `github.copilot.chat.commitMessageGeneration.instructions` is set to a non-empty value; server logs show `422 promptFiltered`.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316204, which already tracks the same `promptFiltered` 422 / silent-failure defect for gitCommitMessageGenerator (opened earlier, with a clean innocuous-diff repro and the same 'no user-facing error' observation). The unique detail here — that adding any custom commitMessageGeneration.instructions text reliably triggers the false-positive content filter — should be added as a comment on the canonical issue.
