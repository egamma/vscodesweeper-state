## Summary

Verified duplicate of the open, older, and much more thoroughly investigated https://github.com/microsoft/vscode/issues/316204, which tracks the exact same promptFiltered 422 failure from gitCommitMessageGenerator when custom commitMessageGeneration.instructions are set — proposing consolidation there.

## Change summary

Generating a commit message via the sparkle icon silently fails (422 promptFiltered) when custom github.copilot.chat.commitMessageGeneration.instructions are configured.

## Best solution

Consolidate discussion on https://github.com/microsoft/vscode/issues/316204, which already has the workaround (switch away from gpt-4o-mini) and root-cause discussion (content filter over-triggering on custom instructions); separately, gitCommitMessageGenerator.ts silently returns undefined on any non-success ChatFetchResponseType (including Filtered), so no error surfaces to the user — worth fixing regardless of the underlying filter behavior.
