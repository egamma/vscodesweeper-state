# Issue #328072 — Error on generating commit message by copilot

[https://github.com/microsoft/vscode/issues/328072](https://github.com/microsoft/vscode/issues/328072)

## Summary

Well-documented, reproducible bug: setting `github.copilot.chat.commitMessageGeneration.instructions` causes the commit-message request to be rejected server-side with `422 promptFiltered`, silently producing no message. Already assigned to the git feature owner (lszomoru), but carries no area labels yet, so routing it helps triage visibility; not closing since it's a confirmed, unresolved defect.

## Change summary

Generate Commit Message in Source Control fails silently (422 promptFiltered) whenever custom `commitMessageGeneration.instructions` are configured.

## Best solution

This belongs with the git/commit-message-generation feature (extensions/copilot/src/extension/prompt/node/gitCommitMessageGenerator.ts and prompts/node/git/gitCommitMessagePrompt.tsx); the owner needs to determine why adding CustomInstructions to the prompt trips the model's content filter (promptFiltered) and either adjust how instructions are rendered/tagged or surface a visible error instead of silently returning undefined. Already assigned to lszomoru; a near-duplicate report (https://github.com/microsoft/vscode/issues/333107, filed later, also assigned to lszomoru) should likely be consolidated into this older, better-diagnosed thread.
