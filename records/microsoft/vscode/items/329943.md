# Issue #329943 — agentHost: a transient git failure can permanently freeze a folder-isolated session's project

[https://github.com/microsoft/vscode/issues/329943](https://github.com/microsoft/vscode/issues/329943)

## Summary

The reported failure remains source-reproducible: a transient worktree lookup failure becomes a persisted checkout-root project that subsequent metadata reads treat as resolved. Keep this issue open; neither the linked PR nor the related reports establish a fix or a valid duplicate.

## Change summary

Prevent transient Git failures from permanently assigning folder-isolated sessions to the wrong project.

## Best solution

Project resolution should distinguish confirmed repository identity from a temporary fallback, allowing subsequent metadata resolution to recover after Git becomes available. The resolution and persistence contract must also account for the reader treating any stored project as resolved, not only the explicit resolved marker.
