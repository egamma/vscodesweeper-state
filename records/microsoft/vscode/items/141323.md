# Issue #141323 — Add fn+F as full screen shortcut on macOS Monterey

[https://github.com/microsoft/vscode/issues/141323](https://github.com/microsoft/vscode/issues/141323)

## Summary

Keep open: maintainers identified an Electron native-menu change needed for macOS Fn+F support, and the inspected source does not establish that it has landed. This accepted Backlog item has 21 upvotes; the existing Ctrl+Cmd+F shortcut does not satisfy the request.

## Change summary

Support macOS Monterey's Fn+F full-screen shortcut while retaining compatibility with existing shortcuts and OS-level remapping.

## Best solution

Provide native Fn+F full-screen handling in Electron's Cocoa menu integration and adopt it on VS Code's full-screen command path. Preserve Ctrl+Cmd+F and user-defined OS shortcuts rather than replacing them with a hardcoded Fn-only binding.
