# Issue #141323 — Add fn+F as full screen shortcut on macOS Monterey

[https://github.com/microsoft/vscode/issues/141323](https://github.com/microsoft/vscode/issues/141323)

## Summary

This is a valid upstream issue requiring a change in Electron's menu controller to support macOS Monterey's fn+F fullscreen shortcut. A team member confirmed the needed Electron change in Dec 2023, and Electron has not yet shipped the fix. Keeping open as upstream.

## Change summary

Support fn+F as the fullscreen shortcut on macOS Monterey and later, matching native app behavior.

## Best solution

The fix belongs in Electron's `shell/browser/ui/cocoa/electron_menu_controller.mm`, mirroring the Chromium change at https://chromium-review.googlesource.com/c/chromium/src/+/3437253. Once Electron ships this, VS Code picks it up with an Electron version bump. Track upstream and nudge the Electron issue if one exists.
