# Issue #141323 — Add fn+F as full screen shortcut on macOS Monterey

[https://github.com/microsoft/vscode/issues/141323](https://github.com/microsoft/vscode/issues/141323)

## Summary

This remains valid upstream work: Electron's current macOS menu controller still lacks Chromium's alternate full-screen menu item needed to support both Fn+F and Control+Command+F. The accepted Backlog request has 21 upvotes, and no older canonical issue owning the same observable behavior was found.

## Change summary

Support macOS Monterey's Fn+F full-screen shortcut while retaining the traditional Control+Command+F shortcut and system-level remapping.

## Best solution

Implement alternate macOS full-screen key-equivalent support in Electron, then adopt the Electron release in VS Code while preserving the existing Control+Command+F binding.
