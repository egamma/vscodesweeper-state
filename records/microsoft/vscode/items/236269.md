# Issue #236269 — Move Editor Actions should apply to selected tabs, and add sorting and reordering operations

[https://github.com/microsoft/vscode/issues/236269](https://github.com/microsoft/vscode/issues/236269)

## Summary

The move-command portion was implemented, but current main still applies Change Language Mode only to the active editor and provides no command for alphabetically sorting or reversing selected tabs. Those remaining requests are distinct, unresolved product choices, so the issue is still necessary.

## Change summary

Extend selected-tab operations to language-mode changes and add commands for alphabetically sorting or reversing selected tabs.

## Best solution

Preserve the shipped multi-selection behavior for editor move commands, then decide whether the remaining language-mode and ordering operations belong in core or require exposing selected editors through an extension API. If accepted, treat language changes and tab ordering as separate scoped changes because their implementation and performance constraints differ.

## Vision fit

- **Fit:** aligned
- **Reason:** Consistent operations over selected tabs improve a core workbench workflow, while an extension-based implementation would currently require an API for accessing the selected-editor set.
- **Evidence:** Durable themes: Workbench & core UX and Extension ecosystem; the values also favor simple, uniform UI interactions and powerful extensions.
