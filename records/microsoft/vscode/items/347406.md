## Evidence

- **Path defect confirmed in source:** In src/vs/base/common/uriTemplate.ts, UriTemplate._expand prefixes scalar and exploded path values with '/', but pushes unexploded map and array values without that prefix. The isPath finalizer concatenates values with filtered.join(''), so {/var,list} with var='hello' and list=['a','b'] produces '/helloa,b'; two lists and scalar-plus-map follow the same failing path.
- **Undefined fragment defect confirmed in source:** UriTemplate._expand skips absent, undefined and null values, then unconditionally evaluates prefix + vals.join(',') for isFragment. Resolving https://example.com/item{#section} with {} therefore appends '#'. A defined empty string instead contributes an entry to vals and must remain distinct from an undefined variable.

Its diff adds the missing path prefixes, guards empty map path expansion, conditions fragment prefix emission on vals.length, and adds regression cases in src/vs/base/test/common/uriTemplate.test.ts.
