# Issue #337517 — Copilot Chat does not dismiss previous question carousel when prompts are edited

[https://github.com/microsoft/vscode/issues/337517](https://github.com/microsoft/vscode/issues/337517)

## Summary

Current main still retains the input-mounted question carousel when an edited request replaces its original request. This source-confirmed, team-authored bug should remain open for a bounded lifecycle fix.

## Change summary

Dismiss the unanswered question carousel belonging to an old response when its prompt is edited and resent.

## Best solution

Clear the carousel associated with the removed request during the edit/resend lifecycle while preserving carousels belonging to other requests or sessions.
