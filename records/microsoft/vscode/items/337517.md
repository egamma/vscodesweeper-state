# Issue #337517 — Copilot Chat does not dismiss previous question carousel when prompts are edited

[https://github.com/microsoft/vscode/issues/337517](https://github.com/microsoft/vscode/issues/337517)

## Summary

Team-authored bug filed today with a clear source-level cause: the edit-and-resubmit path clears the tool confirmation carousel but not the question carousel, so a stale multi-choice question widget lingers after the originating prompt is edited. Kept open per the team-authored protection rule; no fix has landed on main yet.

## Change summary

Editing a previous prompt after the agent asked a multi-choice question leaves the old question carousel UI visible instead of dismissing it.

## Best solution

In the edit-and-resend flow in chatWidget.ts (where `this.inputPart?.clearToolConfirmationCarousel()` is called for an in-progress edit), also call the existing `this.inputPart?.clearQuestionCarousel()` so the stale question carousel is dismissed alongside the tool confirmation carousel.
