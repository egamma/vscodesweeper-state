Team-authored bug with clear steps and a second user confirming it; the question carousel stays interactive after the originating prompt is edited. It is kept open; I did not trace the edit/checkpoint path in source.

## Change summary

Editing the prompt that triggered a question carousel leaves the stale carousel visible and unresponsive.

## Best solution
