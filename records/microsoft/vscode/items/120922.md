# Issue #120922 — The scroll bar  is not accessible through keyboard key present on the error pop-up

[https://github.com/microsoft/vscode/issues/120922](https://github.com/microsoft/vscode/issues/120922)

## Summary

Still reproduces on main: the scrollbar in the marker navigation error popup (Shift+F8) has no keyboard scrolling support — the `ScrollableElement` is `aria-hidden` and has no key handlers, so when a long error message overflows, keyboard-only users cannot scroll the content.

## Change summary

The scrollbar in the error/marker popup (Shift+F8) cannot be controlled via keyboard, making overflowing error messages inaccessible to keyboard-only users.

## Best solution

Add keyboard scroll support (e.g. arrow key handlers) to the `MessageWidget` in `src/vs/editor/contrib/gotoError/browser/gotoErrorWidget.ts` so that when the error popup content is focused, arrow keys scroll the content. This could be done at the `ScrollableElement` level or specifically in the marker widget.
