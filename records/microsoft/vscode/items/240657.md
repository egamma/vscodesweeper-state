# Issue #240657 — Git - Reveal in Explorer View not working for diff file view

[https://github.com/microsoft/vscode/issues/240657](https://github.com/microsoft/vscode/issues/240657)

## Summary

Still reproduces on main: the `revealInExplorer` command in `fileCommands.ts` checks `contextService.isInsideWorkspace(uri)` which returns false for `git:`-scheme URIs from SCM diff editors, silently falling through to the Open Editors path. An open PR (#307590) proposes a fix — keeping open for that PR to land.

## Change summary

Right-clicking a SCM diff editor tab and selecting 'Reveal in Explorer View' does nothing because the git-scheme URI fails the workspace check.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/307590, which resolves non-file-scheme URIs to their underlying `file:` URI before the workspace check in `src/vs/workbench/contrib/files/browser/fileCommands.ts`. The approach is sound: git-scheme URIs preserve the original file path, so converting the scheme recovers the real workspace resource.
