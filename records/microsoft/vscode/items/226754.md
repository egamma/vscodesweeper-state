# Issue #226754 — SCM Graph - On refresh, do not lose the current selection

[https://github.com/microsoft/vscode/issues/226754](https://github.com/microsoft/vscode/issues/226754)

## Summary

Team-authored issue; the requested selection-preservation on refresh is not yet implemented — `_refresh()` still clears state and resets scroll to 0 without saving or restoring the selected node.

## Change summary

SCM Graph refresh should preserve the currently selected commit and reveal it after the tree reloads.

## Best solution

In `SCMHistoryViewPane._refresh()` (src/vs/workbench/contrib/scm/browser/scmHistoryViewPane.ts), capture the current tree selection before `_updateChildren()`, then after the tree rebuilds, look up the matching node by identity and call `tree.setSelection` / `tree.reveal` instead of unconditionally resetting `scrollTop` to 0. This would also unblock automatic refresh on fetch.
