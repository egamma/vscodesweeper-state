# Issue #344122 — Built-in skills are enabled again after restart after being disabled

## Change summary

Preserve disabled built-in skills across VS Code application updates.

## Best solution

Ensure the same built-in skill remains disabled after an application update, both in Agent Customizations and when supplying skills to the agent. Investigate prompt-file enablement identity across installation-location changes without changing repository-skill precedence.

- **Behavior:**
