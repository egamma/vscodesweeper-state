# Issue #344122 — Built-in skills are enabled again after restart after being disabled

[https://github.com/microsoft/vscode/issues/344122](https://github.com/microsoft/vscode/issues/344122)

## Summary

Keep open: the reporter clarified that application updates, not ordinary restarts, reset disabled built-in skills. Current source persists disablement by installation-specific URI, so relocating bundled resources during an update loses the match.

## Change summary

Preserve disabled built-in skills across application updates so they do not unexpectedly compete with repository skills.

## Best solution

The same built-in skill should retain its enabled or disabled state when its installation location changes, consistently in the Customizations editor, skill discovery, and slash commands. Preserve existing profile scope and keep unrelated skills independently controllable.
