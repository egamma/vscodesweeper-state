# Issue #344122 — Built-in skills are enabled again after restart after being disabled

[https://github.com/microsoft/vscode/issues/344122](https://github.com/microsoft/vscode/issues/344122)

## Summary

Keep open: the reporter clarified that application updates, not ordinary restarts, reset disabled skills. Current source persists absolute skill URIs, so a changed extension installation path loses the association with the disabled skill.

## Change summary

Preserve built-in skill disablement across application and bundled-extension updates.

## Best solution

Keep a contributed skill's disabled state associated with the same logical contribution across installation-path changes, and honor that state consistently in customization presentation and skill invocation.
