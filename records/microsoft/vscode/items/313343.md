# Issue #313343 — Agents Mobile: Sessions List Uses Sidebar Icon Instead of Overlay-Appropriate Icon

[https://github.com/microsoft/vscode/issues/313343](https://github.com/microsoft/vscode/issues/313343)

## Summary

The mobile sessions toggle still uses desktop sidebar glyphs even though it opens a full-width overlay. Keep this team-authored, accepted issue open for an overlay-appropriate icon design; no verified fix or canonical duplicate was found.

## Change summary

Use iconography that represents opening the mobile sessions overlay rather than toggling a desktop sidebar.

## Best solution

Give the mobile sessions toggle an understandable navigation affordance for its overlay presentation, while preserving desktop sidebar icons, existing toggle behavior, and accessible open/close labels. Agree on the mobile icon and its open-state presentation before implementation.
