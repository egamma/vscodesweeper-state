# Issue #276318 — Unable to view some HPP files in Merge Editor

[https://github.com/microsoft/vscode/issues/276318](https://github.com/microsoft/vscode/issues/276318)

## Summary

Acknowledged unfixed bug: the merge editor fails to open certain files due to a URI resolution problem in the git extension's openMergeEditor flow. A team member (hediet) confirmed the URI issue and tagged the area owner. No fix has been committed on main. The On Deck milestone and team-member engagement mean this should stay open.

## Change summary

Opening HPP files with merge conflicts in the Merge Editor throws 'Unable to resolve nonexistent file' because the constructed git: URIs fail to resolve through the GitFileSystemProvider.

## Best solution

Investigate and fix the URI construction in `extensions/git/src/commands.ts` (`openMergeEditor`) or the URI resolution in `extensions/git/src/fileSystemProvider.ts` — hediet's comment points at the URIs passed to `_open.mergeEditor` as the likely root cause. The reporter's logs show the git FS provider returns FileNotFound for commit-ref URIs that should be resolvable. May be related to how `toGitUri` or `toMergeUris` constructs paths for deeply nested files or specific repository layouts.
