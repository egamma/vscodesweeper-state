# Issue #4490 — Macro recording

[https://github.com/microsoft/vscode/issues/4490](https://github.com/microsoft/vscode/issues/4490)

## Summary

Highly popular feature request (1228 upvotes) for macro recording — no implementation exists on main; well above the 20-upvote backlog threshold and should remain open.

## Change summary

Add the ability to record a sequence of editor inputs/commands and replay them, similar to Notepad++, Vim, or Sublime Text.

## Best solution

Implement a built-in macro recording and playback system (record keystrokes/commands, replay N times, optionally save and bind to keybindings). Given the massive demand and that extensions like geddski/macros only partially cover this without true recording, a core implementation or a first-class extension API enabling recording would best serve the community.
