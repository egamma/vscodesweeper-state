# Issue #295163 — Advanced line wrapping causes horizontal scrolling if decorations are used

[https://github.com/microsoft/vscode/issues/295163](https://github.com/microsoft/vscode/issues/295163)

## Summary

Keep open: current source measures advanced wrapping without the inline decoration styles that change the displayed text width. An open PR explicitly targets this issue, so the next step is to review that implementation rather than close the report or start a competing fix.

## Change summary

Advanced line wrapping ignores width-changing decorations, causing incorrect wrap positions and horizontal scrolling on bold proportional-font text.

## Best solution

Make advanced wrapping account for the decorated text's actual metrics while preserving existing indentation and injected-text behavior. Review and bring https://github.com/microsoft/vscode/pull/199021 into alignment with the current wrapping interfaces before landing it.
