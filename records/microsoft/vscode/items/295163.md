# Issue #295163 — Advanced line wrapping causes horizontal scrolling if decorations are used

[https://github.com/microsoft/vscode/issues/295163](https://github.com/microsoft/vscode/issues/295163)

## Summary

Keep open: advanced wrapping still measures text without ordinary inline decorations, so bold text can overflow its calculated wraps. An open PR explicitly targets this issue and should be reviewed rather than starting a competing implementation.

## Change summary

Advanced line wrapping should account for width-changing decorations so wrapped bold text does not introduce horizontal scrolling.

## Best solution

Review and land the applicable fix from https://github.com/microsoft/vscode/pull/199021 so advanced wrapping measures the decorated text consistently with its displayed appearance, while preserving existing indentation and injected-text behavior.
