# Issue #154758 — Error: unknown text editor

[https://github.com/microsoft/vscode/issues/154758](https://github.com/microsoft/vscode/issues/154758)

## Summary

The race condition remains on current main — `$acceptEditorPropertiesChanged` still throws 'unknown text editor' at line 108 of extHostTextEditors.ts when the editor is removed before the property-change message arrives. No fix commit references this issue.

## Change summary

A race between editor removal and property-change delivery causes 'unknown text editor' errors in the extension host RPC layer.

## Best solution

Guard `$acceptEditorPropertiesChanged` to silently return (or log a warning) when the editor ID is no longer tracked, rather than throwing — this is a benign race between main-thread editor lifecycle and extension-host message delivery. The fix belongs in `src/vs/workbench/api/common/extHostTextEditors.ts`.
