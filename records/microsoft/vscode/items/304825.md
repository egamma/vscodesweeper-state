# Issue #304825 — New default theme fails to distinguish resolved v.s. unresolved tokens.

[https://github.com/microsoft/vscode/issues/304825](https://github.com/microsoft/vscode/issues/304825)

## Summary

The report remains actionable: current main still gives the new default dark theme very low contrast between default/unresolved-like foregrounds, which weakens a semantic-token cue that Dark Modern made clearer. This should stay open and route to the theme/coloring owners rather than be closed as preference-only.

## Change summary

The new default dark theme makes resolved and unresolved Python tokens too similar to distinguish visually.

## Best solution
