## Summary

Keep open for a theme-design decision: current source retains the nearly identical foreground colors reported here. The rendering follows the palette, but the requested visual distinction remains missing; neither the older theme-migration discussion nor the newer variable-color report qualifies as a duplicate canonical.

## Change summary

Make resolved variables and properties visually distinguishable from unresolved identifiers in the new default dark theme.
