# Issue #312697 — Renaming sessions started from copilot cli has no effect

[https://github.com/microsoft/vscode/issues/312697](https://github.com/microsoft/vscode/issues/312697)

## Summary

Still reproduces on main: renaming a Copilot CLI session from the Sessions view falls into the non-agent-host branch, calling only `chatService.setChatSessionTitle` which doesn't propagate the rename to the CLI backend. The CLI service has a `renameSession` method but it's never invoked from the Sessions view rename action for CLI sessions.

## Change summary

Renaming a Copilot CLI session from the Sessions view has no effect because the rename isn't propagated to the CLI backend.

## Best solution

The rename action in `agentSessionsActions.ts` needs a branch for Copilot CLI sessions (providerType `copilotcli`) that delegates to `ICopilotCliSessionService.renameSession` rather than only updating the local chat model title. The CLI service already exposes the method at line 1266 of `copilotcliSessionService.ts`.
