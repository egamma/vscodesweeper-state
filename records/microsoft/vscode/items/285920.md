# Issue #285920 — Feature Request: Expose Copilot Chat theming tokens

[https://github.com/microsoft/vscode/issues/285920](https://github.com/microsoft/vscode/issues/285920)

## Summary

Keeping this open as a narrow theming feature request: current source has chat-related colors, but I did not find a dedicated `copilot.*` color-token surface that lets users make Copilot Chat light while the rest of the workbench stays dark. The request is directionally in scope for editor theming, but it needs an area-owner product/API decision rather than a cleanup close.

## Change summary

Expose official Copilot Chat color tokens, or a Copilot-specific theme mode, so users can style the Copilot panel independently from the rest of the UI.

## Best solution

Let the chat/theming owners decide whether Copilot Chat should get dedicated theme color IDs or reuse existing chat/workbench color IDs; if accepted, document the supported color customizations in the theming contribution surface rather than relying on container inheritance.
