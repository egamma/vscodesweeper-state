# Issue #285920 — Feature Request: Expose Copilot Chat theming tokens

[https://github.com/microsoft/vscode/issues/285920](https://github.com/microsoft/vscode/issues/285920)

## Summary

Existing chat.* tokens customize individual elements, but do not provide an independently light Chat surface within a dark workbench. Keep this request open for a theming scope decision; no verified canonical or implementation covers the central ask.

## Change summary

Allow users to give Copilot Chat a light appearance independently of the rest of the workbench.

## Best solution

Decide whether Chat should support independently scoped surface colors within the existing theming system. If accepted, cover the transcript, input, and embedded code consistently while preserving inherited workbench colors by default.

## Evidence

- **Existing tokens only partially cover the request:** src/vs/workbench/contrib/chat/common/widget/chatColors.ts registers chat.requestBackground, chat.requestBubbleBackground, chat.avatarBackground, chat.avatarForeground, and other element-specific colors. These are existing official chat.* tokens, but they do not establish a separate Chat-wide background, foreground, or light theme.
- **Chat still inherits its host surface:** src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatViewPane.ts:1062-1111 constructs ChatWidget with listBackground and inputEditorBackground from getLocationBasedColors(), listForeground from SIDE_BAR_FOREGROUND, and resultEditorBackground from editorBackground. src/vs/workbench/browser/parts/views/viewPane.ts:832-860 selects PANEL_BACKGROUND for the panel and SIDE_BAR_BACKGROUND for sidebar locations, explaining the reporter's partial workaround.
- **Shared colors prevent complete independent theming:** src/vs/workbench/contrib/chat/browser/widget/media/chat.css also uses shared foreground, input.background, input.foreground, textLink.foreground, and editor.background tokens. Customizing request bubbles alone therefore does not deliver a coherent light Chat surface while keeping other UI dark.
