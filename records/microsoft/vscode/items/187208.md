# Issue #187208 — Restart TS Server when tsconfig is changed in a monorepo

[https://github.com/microsoft/vscode/issues/187208](https://github.com/microsoft/vscode/issues/187208)

## Summary

Valid feature request with strong community support (118 upvotes). The TS extension has a manual `typescript.reloadProjects` command but no automatic restart/reload when tsconfig or project structure changes invalidate the server state in monorepos. No implementation found on main.

## Change summary

Automatically restart or reload the TypeScript language server when tsconfig.json changes or project structure changes invalidate the server's state in a monorepo.

## Best solution

Implement automatic detection of tsconfig.json changes (and possibly broader project-structure changes like file overwrites) in `extensions/typescript-language-features` that triggers a `reloadProjects` call or a full server restart, with debouncing to avoid thrashing. The file watching infrastructure (`fileWatchingManager.ts`) and the existing `reloadProjects` command provide the foundation.
