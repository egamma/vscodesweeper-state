# Issue #197184 — Highlight in issue reporter if issue is from a pre-release that happened after latest release version

[https://github.com/microsoft/vscode/issues/197184](https://github.com/microsoft/vscode/issues/197184)

## Summary

Keep open: the issue reporter records an extension's version but does not distinguish a pre-release newer than the latest stable release. Both related requests were explicitly closed in favor of this issue, and no verified open canonical was found.

## Change summary

Highlight extension issue reports filed against a pre-release newer than the extension's latest stable release.

## Best solution

Expose this distinction in the issue reporter's generated report so extension maintainers can recognize unreleased-version feedback. Keep any automatic priority policy separate from the factual version annotation.
