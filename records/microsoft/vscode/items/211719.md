# Issue #211719 — Default keybinds using `Ctrl+Alt+[Key]` do not work on windows

[https://github.com/microsoft/vscode/issues/211719](https://github.com/microsoft/vscode/issues/211719)

## Summary

Still present on main: several default keybindings use `Ctrl+Alt+[Key]` on Windows (e.g. auxiliary bar toggle at `Ctrl+Alt+B`), contradicting the project's own documented policy that such bindings should not exist because they produce characters on international layouts.

## Change summary

Default keybindings using `Ctrl+Alt+[Key]` conflict with character input on international keyboard layouts (e.g. EurKEY) on Windows.

## Best solution

Audit all `KeyMod.CtrlCmd | KeyMod.Alt | KeyCode.*` primary keybindings in `src/vs/workbench/` and either gate them with a `win:` override that uses a different chord, or restrict the current binding to `linux:`/`mac:` only. The auxiliary bar toggle (`Ctrl+Alt+B`) in `auxiliaryBarActions.ts` is the most visible example but at least ~20 others exist.
