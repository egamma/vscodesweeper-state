  > Thanks for the report! This sounds like a common Git gotcha rather than a VS Code issue: `.gitignore` only prevents *untracked* files from being added — if the folder was already committed/tracked before you added it to `.gitignore`, Git will keep tracking it. You'd need to untrack it first with `git rm -r --cached <folder>` and then commit that change.
  >
