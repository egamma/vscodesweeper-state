# Issue #349768 — Walkthrough steps unreadable with large text size: header doesn't scroll and steps area collapses to a sliver

[https://github.com/microsoft/vscode/issues/349768](https://github.com/microsoft/vscode/issues/349768)

## Summary

Keep open: current source retains the constrained-height layout implicated in the report, and the related width fixes do not address disappearing steps. The supplied steps suffice to retest on Windows at 200% text size; that platform-dependent rendering was not exercised.

## Change summary

Walkthrough headers and the telemetry footer consume the available height at enlarged Windows text sizes, leaving steps unreadable or inaccessible.

## Best solution

Make the GettingStartedPage details layout preserve access to every step when enlarged text exceeds the editor height, without reducing the requested text size. Validate built-in and extension walkthroughs, keyboard navigation, and footer overlap while preserving the existing narrow-layout media behavior.
