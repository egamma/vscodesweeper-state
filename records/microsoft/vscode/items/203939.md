# Issue #203939 — Cannot undo changes after opening an active file in Hex Editor

[https://github.com/microsoft/vscode/issues/203939](https://github.com/microsoft/vscode/issues/203939)

## Summary

Confirmed, assigned bug with a clear reproduction path — undo history is lost when opening a text file in a custom editor and then returning. No fix has been committed on main; the issue remains valid and should stay open.

## Change summary

Opening a file in a custom editor (e.g. Hex Editor) and closing it clears the text editor's undo history for that file.

## Best solution

The core custom editor infrastructure needs to preserve the text model's undo/redo stack when a resource is temporarily opened in a different editor type. The fix likely involves the editor resolver or custom editor input lifecycle in `src/vs/workbench/contrib/customEditor/browser/` and possibly how the undo/redo service handles resource element lifecycle. Related issue https://github.com/microsoft/vscode/issues/103645 tracks broader custom-editor undo/save problems and may share the same root cause.
