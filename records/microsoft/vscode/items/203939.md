# Issue #203939 — Cannot undo changes after opening an active file in Hex Editor

[https://github.com/microsoft/vscode/issues/203939](https://github.com/microsoft/vscode/issues/203939)

## Summary

Keep open: current core custom-editor disposal still deletes the file's entire undo/redo stack, including earlier text edits, even when the custom editor made no changes. The existing custom-editors routing is appropriate; this is not grounds to move the report to the Hex Editor tracker.

## Change summary

Preserve saved text-edit undo history when a file is opened in Hex Editor and closed without making changes there.

## Best solution

Opening and closing an unmodified custom editor should leave the text editor's prior undo/redo history intact. Address the core custom-document lifecycle in mainThreadCustomEditors.ts while preserving cleanup of disposed custom-document callbacks.
