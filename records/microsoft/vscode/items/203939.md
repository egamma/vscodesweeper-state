# Issue #203939 — Cannot undo changes after opening an active file in Hex Editor

[https://github.com/microsoft/vscode/issues/203939](https://github.com/microsoft/vscode/issues/203939)

## Summary

The undo-history loss remains source-reproducible: closing an editable custom editor deletes the entire undo/redo stack for the underlying file, including earlier text-editor changes. Keep this in custom-editors; the implicated cleanup is in VS Code core, not the Hex Editor extension.

## Change summary

Preserve saved text-editor undo history when the same file is opened and closed in Hex Editor without further edits.

## Best solution

Custom-editor disposal should preserve unrelated text-editor history for the same resource while ensuring disposed custom-document callbacks cannot subsequently run. Cover the reported no-custom-edits transition with a regression test in the main-thread custom-editor suite.
