# Issue #337984 — Agents window: Stop and Mark as Done don't work while a new session is still being created

[https://github.com/microsoft/vscode/issues/337984](https://github.com/microsoft/vscode/issues/337984)

## Summary

Real bug in the Agents window session creation flow, and an open PR from the same author already fixes it — keep this open for the PR to land rather than closing or treating it as unclaimed work.

## Change summary

Stop and Mark as Done silently fail for a brand-new Agent Host session while the host is still setting up the worktree, because the window only holds a draft session until the host announces the real one.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/337985, which fixes exactly this (announces the session on early Stop, and archives the draft immediately for Mark as Done), then close this issue as completed once merged.
