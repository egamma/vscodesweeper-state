# Issue #257673 — Long bg commands or tasks without begins/ends patterns might be considered idle when they're not

[https://github.com/microsoft/vscode/issues/257673](https://github.com/microsoft/vscode/issues/257673)

## Summary

Keep open: current terminal execution has stronger completion handling, but background tasks without begin/end matchers can still return on output silence without establishing completion. This team-authored, accepted request remains the canonical discussion, with an unresolved choice about how to handle tasks whose readiness cannot be determined.

## Change summary

Distinguish temporary output silence from completion or readiness when agents run long commands and background tasks without begin/end problem matchers.

## Best solution

Make agent-facing results distinguish confirmed completion, background readiness, and an output snapshot from a still-running task. Preserve matcher-based readiness for watchers and choose an explicit fallback for tasks without readiness signals rather than treating silence as completion.
