# Issue #205533 — Suggest Widget Details: Empty Message

[https://github.com/microsoft/vscode/issues/205533](https://github.com/microsoft/vscode/issues/205533)

## Summary

The requested distinction between hidden details and unavailable details is still missing from the current suggest widget. Keep this open under the existing discussion; no verified older canonical or existing setting covers the request.

## Change summary

Make it clear when suggestion details are enabled but the selected suggestion has no details, potentially through a "No details" message.

## Best solution

Provide an intentional, unobtrusive distinction between disabled details and absent content in the suggestion-details UI. The maintainer should decide whether an empty-state message or the reporter's alternative of preventing details toggling is the preferred interaction.
