# Issue #205533 — Suggest Widget Details: Empty Message

[https://github.com/microsoft/vscode/issues/205533](https://github.com/microsoft/vscode/issues/205533)

## Summary

A minor polish request to show a "No details" placeholder in the suggest widget when the focused completion has no documentation or detail text. The current behavior silently hides the details pane, which can confuse users about whether details are disabled or simply absent. Low traction (2 upvotes in ~2.5 years) and already labeled under-discussion — keeping open for the community process.

## Change summary

Show an explicit placeholder message (e.g. "No details") in the suggest widget's details pane when a completion item has no documentation or detail text.

## Best solution

In `SuggestDetailsWidget.clearContents()` (or the `renderItem` path when `canExpandCompletionItem` is false), render a localized "No details available" placeholder instead of leaving the pane empty/hidden. The change would be small and localized to `src/vs/editor/contrib/suggest/browser/suggestWidgetDetails.ts`. However, this is a UX decision that needs maintainer input on whether a visible placeholder is preferred over the current collapse behavior.
