# Issue #56834 — Show file picker for 'path' string settings

[https://github.com/microsoft/vscode/issues/56834](https://github.com/microsoft/vscode/issues/56834)

## Summary

This feature request for a file/folder picker in the settings editor for path-type string settings remains unimplemented on current main. The issue is team-authored and in the Backlog — it stays open.

## Change summary

Show a file/folder picker widget for settings whose values are file or directory paths, instead of requiring manual text entry.

## Best solution

Implement a browse button alongside the text input for string settings that are known to be file/folder paths (via a `format` hint or naming convention). The settings tree renderer in `src/vs/workbench/contrib/preferences/browser/settingsTree.ts` would need a new rendering path that invokes `showOpenDialog` and writes the result back to the setting value.
