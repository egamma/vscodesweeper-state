# Issue #231140 — Git - status is triggering far too often on a large repo (during build)

[https://github.com/microsoft/vscode/issues/231140](https://github.com/microsoft/vscode/issues/231140)

## Summary

Keep open: Git still schedules refreshes for ignored build-output changes, and the maintainer acknowledged that the working-tree listener should probably account for .gitignore. The linked draft implementation remains open and needs maintainer review.

## Change summary

Avoid Git refresh activity caused solely by changes to ignored build outputs while preserving automatic refresh for meaningful repository changes.

## Best solution

Review https://github.com/microsoft/vscode/pull/246661 against Git ignore semantics and the watcher API, then land a working implementation or resolve that attempt before pursuing another. Preserve refreshes for tracked files and relevant Git metadata without requiring users to disable autorefresh or duplicate ignore rules manually.
