# Issue #293521 — Confusing terminology and UX around agent types

[https://github.com/microsoft/vscode/issues/293521](https://github.com/microsoft/vscode/issues/293521)

## Summary

Keep open for documentation and discoverability improvements: organization-level describes where a custom agent is distributed, not where it executes. Current documentation clarifies some of this distinction, but the cloud picker still suppresses custom-agent discovery when multiple GitHub repositories are present, leaving the reporter's central confusion unresolved.

## Change summary

Clarify custom-agent provenance versus execution target, supported frontmatter, and why cloud custom-agent selection disappears in multi-repository workspaces.

## Best solution

Explain organization, workspace, and user scope separately from Local/Cloud execution, including target-specific frontmatter support. Make the cloud picker's repository-dependent availability explicit rather than silently omitting the custom-agent choice.
