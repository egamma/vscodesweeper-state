# Issue #303777 — Support skill-scoped hooks (on-load) in SKILL.md

[https://github.com/microsoft/vscode/issues/303777](https://github.com/microsoft/vscode/issues/303777)

## Summary

Valid feature request — agent files support a `hooks` frontmatter attribute, but SKILL.md files do not. The requested `onLoad` hook with skill-scoped lifecycle is a new capability that doesn't exist today.

## Change summary

Add support for lifecycle hooks (e.g. `onLoad`) in SKILL.md frontmatter, so skills can deterministically run platform-level side effects when loaded.

## Best solution

Extend `skillAttributes` in `src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptFileAttributes.ts` to include a `hooks` attribute (similar to what `agentAttributes` already has), and wire up the skill-loading pipeline to execute those hooks before skill content is injected. This requires design decisions on hook timing, error handling, and model-visibility semantics specific to skills.
