# Issue #260864 — Consider adding auto approval for fetches when the URL is mentioned in the chat message

[https://github.com/microsoft/vscode/issues/260864](https://github.com/microsoft/vscode/issues/260864)

## Summary

The central request is implemented: explicitly mentioned URLs automatically bypass fetch confirmation. The implementation uses prompt inclusion as consent rather than adding the suggested opt-in dropdown setting, and URL-specific approval controls also address the follow-up concern.

## Change summary

Automatically approve fetching URLs explicitly included in a user's chat message without granting blanket permission to the fetch tool.

## Best solution

Close as completed by commit d68a730e8d9034e7f65ff129fbf29690a0526212. Keep the existing explicit-URL auto-approval behavior and the separate chat.tools.urls.autoApprove controls for persistent URL-pattern approvals.
