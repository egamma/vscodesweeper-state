[https://github.com/microsoft/vscode/issues/339723](https://github.com/microsoft/vscode/issues/339723)

## Summary

This is a same-day internal design question from a core contributor about why sandbox.network settings (chat.agent.sandbox.network.allowedDomains/deniedDomains/allowNetwork, defined in src/vs/platform/sandbox/common/settings.ts and src/vs/platform/networkFilter/common/settings.ts) live in VS Code user settings rather than being owned/resolved by the agent host, and whether they should be per-session — it needs a maintainer architecture discussion, not a close.

## Change summary
