# Issue #9078 — support font-size in DecorationRenderOptions

[https://github.com/microsoft/vscode/issues/9078](https://github.com/microsoft/vscode/issues/9078)

## Summary

A real API gap remains on current main: internal decoration rendering supports font sizes, but the public types and extension-host converters still omit them. With 30 upvotes and a Backlog milestone, this established request should remain open.

## Change summary

Expose supported font-size styling for text decorations and their before/after attachments.

## Best solution

Add `fontSize?: string` to `ThemableDecorationRenderOptions` and `ThemableDecorationAttachmentRenderOptions`, pass it through the extension-host converters, and cover both decoration forms with API and rendering tests.

## Evidence

- **public API gap:** On current main, `src/vscode-dts/vscode.d.ts` defines neither `fontSize` on `ThemableDecorationRenderOptions` nor on `ThemableDecorationAttachmentRenderOptions`.
- **conversion gap:** `src/vs/workbench/api/common/extHostTypeConverters.ts` explicitly copies supported decoration properties but omits `fontSize` for both normal decorations and attachments, so an undeclared property is discarded.
- **rendering groundwork:** Merged PR https://github.com/microsoft/vscode/pull/252308 and commit 474b70cbb72c626f2baadde3181dbaf9cb403f6e added variable-font handling to the editor; `src/vs/editor/browser/services/abstractCodeEditorService.ts` now supports `fontSize` internally.
- **community support:** The request has 30 community upvotes, exceeding the 20-upvote Backlog threshold, and is assigned to the Backlog milestone.
