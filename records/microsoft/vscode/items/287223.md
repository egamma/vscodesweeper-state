# Issue #287223 — [Copilot] #githubRepo search tool should have customizable results count

[https://github.com/microsoft/vscode/issues/287223](https://github.com/microsoft/vscode/issues/287223)

## Summary

Valid feature request — the #githubRepo tool hardcodes 64 results (confirmed on current main at line 63 of githubRepoSemanticSearchTool.tsx), and the tool's input schema has no parameter to control the count. The request to make this configurable is reasonable and not yet addressed. Currently in the Backlog Candidates community process with 10 days remaining and 0 upvotes.

## Change summary

Allow users to control the number of results returned by the #githubRepo search tool, which currently hardcodes 64 results, consuming context window quickly.

## Best solution

Add an optional `count` (or `maxResults`) parameter to the `GithubRepoToolParams` interface and the tool's `inputSchema` in `package.json`, defaulting to a smaller value (e.g. 10–20) and capping at 64. Pass it through to the `semanticSearch` call on line 63 of `githubRepoSemanticSearchTool.tsx`. This would let the model (or the user via prompt) request fewer results to conserve context window budget.
