# Issue #329919 — on narrow layout the third option is much wider

[https://github.com/microsoft/vscode/issues/329919](https://github.com/microsoft/vscode/issues/329919)

## Summary

Traced the defect in current main's CSS: in the narrow prompt-options layout, when three flex items wrap two-per-row, the lone third item on its own row grows to fill the full row width because `flex-grow: 1` is still applied, making it look disproportionately wide compared to the first two.

## Change summary

In the new-session prompt options widget, when the container is narrow (2-per-row wrap), the third/last option stretches to fill its row instead of staying the same width as the other two.

## Best solution

In src/vs/sessions/contrib/chat/browser/media/newSessionPromptOptions.css, prevent the lone last item in the `@container (max-width: 720px)` two-per-row rule from flex-growing to fill its row (e.g. `flex-grow: 0` with `max-width` matching the basis, or center it via `justify-content` on a wrapper) so it renders at the same width as the first two options, as the reporter suggests.
