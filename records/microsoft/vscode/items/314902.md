## Summary

This report uses the exact macOS Insiders build affected by the confirmed provisioning/signing regression, which broke terminal processes, updates, and other bundled subprocesses. The packaging change was reverted in commit 85177ecfed406e4c24a9cb1c291c6b8bb2b6aaf9, and affected installations require reinstalling a current Insiders build because their updater is also broken.

## Change summary

On macOS arm64 Insiders build 43d0ed45492d, extension signature verification fails, file search returns no results, and integrated terminals immediately exit.

## Best solution

Keep the reverted macOS provisioning/signing configuration from https://github.com/microsoft/vscode/commit/85177ecfed406e4c24a9cb1c291c6b8bb2b6aaf9 and direct users of the affected build to reinstall the current Insiders application.
