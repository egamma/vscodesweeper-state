# Issue #75559 — Builtin support for reading files from their zip archives

[https://github.com/microsoft/vscode/issues/75559](https://github.com/microsoft/vscode/issues/75559)

## Summary

Keep open: built-in archive browsing remains absent, this accepted Backlog request has 644 community upvotes, and the maintainer explicitly left it open for possible future reconsideration. The ZipFS extension is a useful workaround, but it does not satisfy the central request for transparent built-in handling.

## Change summary

Allow VS Code to browse and read files directly inside ZIP archives, including navigation from file paths and language features.

## Best solution

Make extension-backed archive file systems seamless through stable filesystem and search-provider integration, keeping ZIP-specific implementation outside the lightweight core unless maintainers explicitly choose a built-in read-only provider. In particular, complete the open file-search API work so Quick Open and related workflows work uniformly with virtual file systems.

## Vision fit

- **Fit:** rejected
- **Reason:** Bundling ZIP-specific functionality into core cuts against the lightweight-default and extension-ecosystem guardrails when a functioning extension implementation already exists.
