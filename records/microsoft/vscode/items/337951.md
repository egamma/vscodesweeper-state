# Issue #337951 — "Agent Debug Logs" setting is missing / not available to enable

[https://github.com/microsoft/vscode/issues/337951](https://github.com/microsoft/vscode/issues/337951)

## Summary

The screenshots confirm a recent-build reproduction, and the same button path remains on current main. Both underlying settings are registered, so the failure appears to be a settings-search or experimental-setting visibility integration bug rather than a missing feature.

## Change summary

Clicking Enable in Settings from Agent Debug Logs opens Settings with no matching enable toggle.

## Best solution
