# Issue #348996 — Call Stack view focus to the wrong session/threads when stepping/resuming in another debug session

The delayed focus-transfer path on current main explains the reported switch to another suspended session. Keep this open while the linked implementation candidate is reviewed.

## Change summary

Resuming or slowly stepping one debug session unexpectedly transfers Call Stack focus to another suspended session.

## Best solution

Preserve the user's selected debug session across resume and slow stepping, including its subsequent stop, without disrupting explicit session changes. Review https://github.com/microsoft/vscode/pull/348974 against that behavior before landing a fix.
