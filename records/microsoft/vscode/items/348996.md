# Issue #348996 — Call Stack view focus to the wrong session/threads when stepping/resuming in another debug session

[https://github.com/microsoft/vscode/issues/348996](https://github.com/microsoft/vscode/issues/348996)

## Summary

Keep open while the linked implementation candidate is reviewed. Current source supports the slow-step focus handoff, but maintainer guidance distinguishes stepping, which should retain focus, from ordinary resume, which should transfer focus to a stopped session.

## Change summary

The Call Stack switches away from the selected debug session during a slow step or resume when another session remains stopped.

## Best solution

Review https://github.com/microsoft/vscode/pull/348974 against the established distinction: retain focus during stepping while preserving intentional focus handoff on ordinary resume. Resolve this issue only after the accepted behavior is implemented.
