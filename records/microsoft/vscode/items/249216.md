# Issue #249216 — Simple browser fails to select element

[https://github.com/microsoft/vscode/issues/249216](https://github.com/microsoft/vscode/issues/249216)

## Summary

The reported desktop Simple Browser path has been replaced by the integrated browser, whose native element-selection implementation no longer uses the failing webview target-discovery flow. This can be closed as completed.

## Change summary

Selecting a locally hosted page element in Simple Browser failed with a `No target found` error instead of attaching the element to chat.

## Best solution

Keep desktop Simple Browser commands routed to the integrated browser, where element selection and chat attachment operate directly on the owned browser view rather than discovering a nested webview target.
