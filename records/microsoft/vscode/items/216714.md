[https://github.com/microsoft/vscode/issues/216714](https://github.com/microsoft/vscode/issues/216714)

## Summary

The Windows arrow-symbol request is fully covered by an older, verified open issue requesting the same keybinding-label formatting on non-Mac platforms. Consolidate there rather than track the Windows case separately.
