# Issue #216714 — DownArrow, LeftArrow, etc. should be symbols on Windows

[https://github.com/microsoft/vscode/issues/216714](https://github.com/microsoft/vscode/issues/216714)

## Summary

Still unfixed on main: arrow key labels on Windows use text ('DownArrow') instead of symbols ('↓'). The Mac/Linux mapper has the symbol mapping but Windows does not. Team-authored item, keeping open.

## Change summary

Show arrow key symbols (←↑→↓) instead of text names (LeftArrow, UpArrow, etc.) in keybinding labels on Windows.

## Best solution

Add arrow-symbol cases to the Windows keyboard mapper's `_getLabel` path (or in the `_keyCodeToLabel` initialization in `WindowsKeyboardMapper` at src/vs/workbench/services/keybinding/common/windowsKeyboardMapper.ts), mirroring what `macLinuxKeyboardMapper.ts` and `usLayoutResolvedKeybinding.ts` already do for macOS.
