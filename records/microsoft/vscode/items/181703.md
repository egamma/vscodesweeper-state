# Issue #181703 — Allow to preserve all state in the duplicated new window

[https://github.com/microsoft/vscode/issues/181703](https://github.com/microsoft/vscode/issues/181703)

## Summary

A real gap remains on current main: workspace duplication copies folders and settings but not workspace-scoped UI and extension state. The existing `keep` label and maintainer acceptance favor retaining this for product discussion.

## Change summary

Make a duplicated workspace window preserve workspace-scoped state, including extension enablement and UI state.

## Best solution

Extend `workbench.action.duplicateWorkspaceInNewWindow` to migrate the relevant workspace storage into the newly created untitled workspace without coupling the two windows' subsequent state.
