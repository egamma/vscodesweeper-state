# Issue #254179 — Window resize lag when a webview is visible

[https://github.com/microsoft/vscode/issues/254179](https://github.com/microsoft/vscode/issues/254179)

## Summary

This is a macOS Electron regression (bisected to the Electron 35 upgrade) causing resize lag with visible webviews. It persisted through Electron 37 and no fix has been found on main. The related Windows issue #327134 was closed as caused by a third-party extension (KeyHop), but this macOS report is independent of that — it reproduces with all extensions disabled. The root cause likely lives in Chromium/Electron's resize handling on macOS.

## Change summary

Resizing the VS Code window on macOS is noticeably laggy when any webview is visible, a regression introduced with the Electron 35 upgrade.

## Best solution

Investigate whether newer Electron/Chromium versions (currently at 42.5.0 on main) have resolved the macOS webview resize lag, or file an upstream Electron issue with the bisection evidence if it persists. A reporter confirmation on the latest Insiders build would clarify whether this is still live.
