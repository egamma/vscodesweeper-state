# Issue #206840 — `selectHighlights` selects wrong value when search is set to regex

[https://github.com/microsoft/vscode/issues/206840](https://github.com/microsoft/vscode/issues/206840)

## Summary

The reported selection mismatch remains in current source with the default settings: a visible regex search overrides the editor selection even when the editor has text focus. Keep this open for a bounded correction that preserves regex selection when Find is focused.

## Change summary

Select All Occurrences and Change All Occurrences select the Find query instead of the selected editor text when an unfocused Find widget has regex enabled.

## Best solution

Make occurrence selection use the selected editor text when the editor has text focus, while preserving Find-focused regex matching, existing match-case and whole-word settings, search scope, and primary-cursor placement.
