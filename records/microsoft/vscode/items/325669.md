# Issue #325669 — Please allow toggline AI code suggestions

[https://github.com/microsoft/vscode/issues/325669](https://github.com/microsoft/vscode/issues/325669)

## Summary

The central request is already supported through visible Copilot menus, without using a Developer command. The title-bar Chat menu offers inline-suggestion enable/disable controls, and the Status Bar Copilot menu also provides checkboxes and Snooze.

## Change summary

Provide an easily accessible graphical control to turn AI code suggestions off and back on while coding.

## Best solution

Use the existing title-bar Chat menu's Configure Inline Suggestions action or the Copilot Status Bar controls, rather than adding another dedicated toggle. These already provide the requested graphical enable/disable workflow.

  > Thanks for the request. You can use the Chat menu in the title bar → Configure Inline Suggestions... → Disable Inline Suggestions (or Enable Inline Suggestions) without running a Developer command. The Copilot icon in the Status Bar also opens graphical controls for all languages or the current language, plus Snooze for a temporary pause. These controls update `github.copilot.enable`; see https://code.visualstudio.com/docs/editing/ai-powered-suggestions#_enable-or-disable-inline-suggestions.
