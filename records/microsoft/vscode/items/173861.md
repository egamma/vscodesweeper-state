# Issue #173861 — Proxy agent patch prevents extensions from re-using HTTP connections

[https://github.com/microsoft/vscode/issues/173861](https://github.com/microsoft/vscode/issues/173861)

## Summary

The connection-reuse gap remains deliberately unresolved in the currently bundled proxy agent: forwarding `keepAlive` was reverted after causing a separate regression, and the corresponding socket-reuse test is still skipped. Keep this open while the proxy-agent implementation reconciles both behaviors.

## Change summary

VS Code's proxy patch replaces an extension's keep-alive HTTP(S) agent without preserving its connection-reuse behavior.

## Best solution

Fix connection reuse in microsoft/vscode-proxy-agent without restoring the fetch regression from https://github.com/microsoft/vscode/issues/228872, then enable its skipped socket-reuse test and update the bundled dependency in VS Code.
