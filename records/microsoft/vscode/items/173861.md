# Issue #173861 — Proxy agent patch prevents extensions from re-using HTTP connections

[https://github.com/microsoft/vscode/issues/173861](https://github.com/microsoft/vscode/issues/173861)

## Summary

Still reproduces on main: the keepAlive pass-through in @vscode/proxy-agent remains commented out (line 352 of node_modules/@vscode/proxy-agent/out/index.js) due to regression #228872. The original fix (v0.23.0) was reverted and has not been re-landed.

## Change summary

VS Code's proxy agent patch prevents extensions from reusing HTTP connections because the keepAlive flag from the original agent is not forwarded.

## Best solution

Re-implement the keepAlive pass-through in @vscode/proxy-agent without triggering the fetch regression from #228872 — likely requires distinguishing keepAlive behavior for direct socket connections vs. fetch-based requests. The fix lives in the microsoft/vscode-proxy-agent repo.
