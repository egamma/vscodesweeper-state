# Issue #341863 — Copilot chat 

[https://github.com/microsoft/vscode/issues/341863](https://github.com/microsoft/vscode/issues/341863)

## Summary

Thanks for the report. Copilot Chat in a WSL2 remote window shows a 3–4 minute delay before responses appear, and a second user sees the same with the Copilot harness in remote sessions. The report has no chat debug logs or timing trace to show where the delay occurs, and I did not trace the code path, so it can't be verified yet.

## Change summary

Copilot Chat responses in WSL2 remote sessions are surfaced 3–4 minutes late even though the model replies in about 1s; disabling the Codebase Semantic Index or switching the harness to Local improves it.

## Best solution

Capture a timed trace of a slow request in the remote window (Chat Debug view / Copilot Chat log, with the Semantic Index on and off) to find the blocking step, most likely in the remote Copilot harness or the semantic index check. Then fix it in the Copilot extension code at extensions/copilot.
