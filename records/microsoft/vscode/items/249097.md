# Issue #249097 — Issue reporter looks all white?

[https://github.com/microsoft/vscode/issues/249097](https://github.com/microsoft/vscode/issues/249097)

## Summary

Keep open: this team-authored, accepted Backlog bug remains present in current source. Light themes leave `input.border` unset, while the legacy issue reporter depends on that token to distinguish its text fields from the white background.

## Change summary

Issue Reporter text inputs and text areas lack visible boundaries in light themes, making the form appear almost entirely white.

## Best solution

Give the legacy Issue Reporter form controls a visible light-theme affordance consistent with standard workbench inputs, without changing high-contrast behavior or unrelated theme defaults.
