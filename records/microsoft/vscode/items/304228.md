[https://github.com/microsoft/vscode/issues/304228](https://github.com/microsoft/vscode/issues/304228)

## Summary

The reported cross-chat thinking-effort propagation is addressed by the merged per-editor model-configuration fix. Current source keeps existing chats' configurations independent, so propose closing as completed rather than as designed.

## Change summary

Changing thinking effort in one existing chat should not change another existing chat using the same model.

## Best solution

Retain the independent configuration snapshots implemented in commit 037f7fbe03f78896c841adfd57aea4e0c85ccbc7: existing chats keep their selected effort, while new chats can inherit saved defaults.
