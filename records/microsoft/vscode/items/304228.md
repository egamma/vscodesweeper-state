## Summary

The behavior reported after reopening was fixed on current main: each open chat editor now keeps its own model-configuration snapshot, so changing thinking effort in one no longer changes another. The fix landed after the reopen and has an exact cross-editor regression test.

## Change summary

Keep thinking-effort selections isolated per chat session while allowing newly opened chats to inherit the latest default.
