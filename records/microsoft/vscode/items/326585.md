# Issue #326585 — Terminal renders badly in light mode with gpu acceleration

[https://github.com/microsoft/vscode/issues/326585](https://github.com/microsoft/vscode/issues/326585)

## Summary

Real, well-documented visual defect (screenshots + confirmed reproducibility), but the rendering path involved is the `@xterm/addon-webgl` GPU renderer (an external xterm.js dependency, `package.json` pins `@xterm/addon-webgl@^0.20.0-beta.291`), not code owned by this repo — classifying as upstream and keeping open rather than closing.

## Change summary

Terminal text renders thin/jagged in light theme specifically when GPU acceleration (WebGL renderer) is enabled; dark theme and non-GPU rendering are unaffected.

## Best solution

Route to the terminal area for triage; the actual fix (if any) likely needs to land in the xterm.js WebGL addon's glyph/font-atlas rasterization, which VS Code's terminal only consumes via `src/vs/workbench/contrib/terminal/browser/xterm/xtermTerminal.ts` (gpuAcceleration setting selects the WebGL addon). A maintainer should confirm with xterm.js maintainers whether this is a known WebGL renderer/ANGLE antialiasing issue.
