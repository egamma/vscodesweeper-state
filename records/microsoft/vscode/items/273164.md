# Issue #273164 — include extra info in `aria-description` instead of `aria-label`

[https://github.com/microsoft/vscode/issues/273164](https://github.com/microsoft/vscode/issues/273164)

## Summary

Team-authored accessibility improvement request: move supplementary info from aria-label to aria-description so screen readers announce the element's text content first, then the description. Keeping open — authored by a team member.

## Change summary

Extra contextual info appended to aria-label should use aria-description instead, so screen readers announce the primary text content before the supplementary details.

## Best solution

Audit UI components that pack extra info into aria-label (tabs, action items, tree nodes, status bar, etc.) and migrate the supplementary portion to aria-description. The accessibility area already owns this; @rperez030 and @jooyoungseo are named as co-requesters and likely collaborators on the implementation.
