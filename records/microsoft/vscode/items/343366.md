[https://github.com/microsoft/vscode/issues/343366](https://github.com/microsoft/vscode/issues/343366)

## Summary

Keep this team-authored tracking item open as packaging debt. Current source still deliberately packages a version-matched extension runtime separately from the core SDK runtime; reducing that duplication requires resolving their compatibility and independent-update requirements.

## Change summary

Reduce bundled Copilot native-runtime duplication and investigate unnecessary cross-architecture binaries in macOS packages.

## Best solution

Establish whether the built-in extension and Agent Host can share a supported runtime contract while preserving standalone Marketplace/VSIX operation and update compatibility. Packaging should follow that ownership decision; assess the x64 server's extra arm64 search binaries separately from runtime consolidation.
