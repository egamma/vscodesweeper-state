# Issue #229011 — Git - vscode does not respect GIT_AUTHOR_NAME/EMAIL in pre-commit hook failures, setting git.requireGitUserConfig=false has no effect 

[https://github.com/microsoft/vscode/issues/229011](https://github.com/microsoft/vscode/issues/229011)

## Summary

The reported error replacement remains in current source: a failing pre-commit hook triggers config-only identity checks that hide the original failure when identity comes from environment variables. Keep this open in the Git area; the older related reports do not establish a canonical for this specific failure.

## Change summary

Preserve the actual pre-commit hook failure instead of incorrectly reporting missing Git user configuration when environment-provided identity is valid.

## Best solution

Git commit error handling should distinguish genuine identity failures from hook failures using Git's effective identity semantics. A rejected hook must remain rejected and its diagnostic must remain available, without requiring identity to be stored in Git configuration.
