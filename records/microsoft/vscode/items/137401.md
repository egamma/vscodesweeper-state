# Issue #137401 — "Keybinding" shown is misleading for Ctrl-modified keyboard layouts (like Dvorak+QWERTY)

[https://github.com/microsoft/vscode/issues/137401](https://github.com/microsoft/vscode/issues/137401)

## Summary

Keep open: the current Windows mapper still derives display labels without considering Ctrl, and shortcut search still matches both serialized and displayed labels. The report supplies sufficient steps to retest; its custom Windows layout was not exercised, so present-day reproduction remains unverified.

## Change summary

Display and search shortcuts consistently for Windows layouts that switch from Dvorak to QWERTY while Ctrl is held, including chords that release Ctrl.

## Best solution

Make shortcut labels reflect the effective modifier-dependent layout without changing working dispatch or stored bindings. Confirm the native mapping for the reported layout first, then resolve the misleading search results alongside the label mismatch.
