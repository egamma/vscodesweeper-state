# Issue #137401 — "Keybinding" shown is misleading for Ctrl-modified keyboard layouts (like Dvorak+QWERTY)

[https://github.com/microsoft/vscode/issues/137401](https://github.com/microsoft/vscode/issues/137401)

## Summary

Still relevant on current main: the Windows keyboard mapper resolves keybinding labels purely from keyCode without accounting for layouts where Ctrl changes the physical-to-logical mapping, so labels are incorrect for Dvorak+QWERTY users.

## Change summary

Keybinding labels and search results are incorrect/misleading for keyboard layouts where Ctrl changes the physical-to-logical key mapping (e.g. Dvorak+QWERTY).

## Best solution

The WindowsKeyboardMapper's `_getLabel` and related methods need to account for layouts that remap keys under Ctrl. The label shown to the user should reflect the actual key produced when Ctrl is held, not the unmodified layout character. This is a complex keyboard-layout edge case that likely requires deeper plumbing in `windowsKeyboardMapper.ts`.
