# Issue #194276 — Support extension contributed icons in the icon picker

[https://github.com/microsoft/vscode/issues/194276](https://github.com/microsoft/vscode/issues/194276)

## Summary

Extension-contributed icons still do not appear in the user-profile icon picker on current main. Keep this accepted Backlog request open; the existing icon contribution API supplies the icons, but the picker only exposes a fixed built-in list.

## Change summary

Allow extensions to contribute custom icons that users can select in the profile icon picker.

## Best solution

Expose eligible extension-contributed theme icons alongside the existing profile icons, preserving the curated built-in selection and existing profile behavior. Establish which contributed icons qualify before implementing the picker integration.

## Vision fit

- **Fit:** aligned
- **Reason:** Connecting extension-provided icons to the existing profile picker supports extension customization and recognizable workspace profiles without adding a separate UI surface.
- **Evidence:** Public values: “The power lives in extensions” and “Simple, uniform UI and UI interactions”; durable themes: extension ecosystem and workbench profiles.
