# Issue #194276 — Support extension contributed icons in the icon picker

[https://github.com/microsoft/vscode/issues/194276](https://github.com/microsoft/vscode/issues/194276)

## Summary

Keep open: the terminal-specific picker now appears to consume the icon registry, but the profile icon picker still uses a fixed built-in icon list, matching the remaining extension-contributed profile icon request discussed by maintainers.

## Change summary

Allow extension-contributed themable icons, likely filtered by a naming convention such as `profile-icon-*`, to appear in the icon picker used for profile/custom icon selection.

## Best solution

Decide the intended extension-icon surface for the shared icon picker, then wire the user profile picker to include approved extension-contributed icons while keeping the picker usable and deduped. The terminal-specific part can stay separated in https://github.com/microsoft/vscode/issues/194311 or current terminal picker behavior.
