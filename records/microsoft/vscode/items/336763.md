## Summary

Detailed report, but I could not conclusively confirm the defect from source alone: the markdown drop provider (ResourcePasteOrDropProvider in dropOrPasteResource.ts) and the workbench drop-into-editor overlay (editorDropTarget.ts) don't appear to special-case folders vs. `.md` files, so the reported file-vs-folder asymmetry isn't obvious from a static read — this needs a live repro or reporter confirmation (e.g. with extensions disabled, which the reporter hasn't tried yet).

## Change summary

Dragging a workspace `.md` file into the Markdown source editor always opens it instead of inserting a Markdown link, even with `markdown.editor.drop.enabled: "always"` and Shift held, while dragging a folder correctly inserts a link.
