# Issue #240896 — `DebugSession` is never disposed?

[https://github.com/microsoft/vscode/issues/240896](https://github.com/microsoft/vscode/issues/240896)

## Summary

Keep open to resolve DebugSession ownership: current main disposes some replaced sessions, but still contains an explicit disposal TODO and a creation path that abandons a session without cleanup. Inactive sessions are intentionally retained for console history and extension-host reattachment, so disposing every session when its adapter ends would be incorrect.

## Change summary

Audit and complete DebugSession disposal without breaking intentionally retained or reusable sessions.

## Best solution

Establish complete lifecycle ownership for DebugSession, including abandoned creation paths and eventual cleanup of retained sessions. Preserve debug-console history and extension-host reattachment rather than enabling unconditional disposal on adapter termination.
