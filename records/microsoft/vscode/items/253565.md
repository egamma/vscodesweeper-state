# Issue #253565 — When creating an issue about an extension, Issue Reporter doesn't adequately identify which extension the user picked

[https://github.com/microsoft/vscode/issues/253565](https://github.com/microsoft/vscode/issues/253565)

## Summary

Still valid on current main: the issue reporter's serialized body includes only 'Extension version: X.Y.Z' but omits the extension name and ID, making it hard to identify which extension a filed issue is about. A team member acknowledged and mentioned upcoming template work, but the gap remains.

## Change summary

When filing an issue about an extension via the Issue Reporter, the generated issue body does not include the extension's name or ID — only its version number.

## Best solution

Include the extension display name and ID (e.g. 'Extension: GitHub Copilot (github.copilot)') in the serialized issue body alongside the existing 'Extension version' line. The fix belongs in `issueReporterModel.ts` in `getExtensionVersion()` (or a sibling method) and the wizard overlay's submit path.
