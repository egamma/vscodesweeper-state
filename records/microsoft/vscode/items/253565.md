# Issue #253565 — When creating an issue about an extension, Issue Reporter doesn't adequately identify which extension the user picked

[https://github.com/microsoft/vscode/issues/253565](https://github.com/microsoft/vscode/issues/253565)

## Summary

Keep open: the newer reporter wizard includes extension identity, but the legacy serializer still emits only the selected extension's version. The linked example and maintainer acknowledgment suffice to retest; the reporter has since gained multiple submission paths, so coverage needs checking across them.

## Change summary

Ensure generated extension reports unambiguously identify the extension selected by the user.

## Best solution

Generated reports should retain the selected extension's identifier and version regardless of reporter entrypoint. Preserve the wizard's existing identity metadata and address any remaining legacy or built-in-extension reporting gaps.
