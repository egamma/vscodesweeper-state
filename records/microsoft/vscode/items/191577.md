# Issue #191577 — Copy image output is quite slow

[https://github.com/microsoft/vscode/issues/191577](https://github.com/microsoft/vscode/issues/191577)

## Summary

Still reproduces on main: the image copy path in webviewPreloads.ts draws the image to a canvas and calls toBlob synchronously in the webview, which is inherently slow for ~200kb+ images. No fix commit references this issue.

## Change summary

Copying notebook image output to clipboard takes several seconds for a ~200kb image.

## Best solution

Optimize the copy path in webviewPreloads.ts — for images already available as data URIs or blobs (e.g. PNG outputs), skip the canvas round-trip and write the existing blob directly to the clipboard via navigator.clipboard.write, avoiding the re-encoding overhead.
