# Issue #36700 — Allow to open two distinct editors side by side in one group

[https://github.com/microsoft/vscode/issues/36700](https://github.com/microsoft/vscode/issues/36700)

## Summary

Keep open: VS Code implemented same-file splitting, layout toggling, focus switching, and joining, but the central remaining request—showing two distinct editors within one tab—remains unsupported. This Backlog request has 194 community upvotes and is the maintainer-selected canonical issue for that capability.

## Change summary

Allow one editor tab to contain two distinct editors in a horizontal or vertical split, with focus and join controls.

## Best solution

Extend the existing side-by-side editor model to compose two independently selected editor inputs in one tab while preserving the current split layout, focus, and join commands. Keep the broader Vim-style grid-layout work separate in https://github.com/microsoft/vscode/issues/143024.
