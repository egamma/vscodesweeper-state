# Issue #336123 — VS Code Settings Sync remote not deleting

[https://github.com/microsoft/vscode/issues/336123](https://github.com/microsoft/vscode/issues/336123)

## Summary

Current source confirms a Settings Sync deletion failure can be silently swallowed, leaving remote data intact with no actionable error. This should remain open and route to the Settings Sync owners.

## Change summary

Clearing Settings Sync cloud data can leave stale settings and extensions on the server, which are restored when synchronization is enabled again.

## Best solution

Make remote clearing report failure instead of completing silently, so users can retry without enabling synchronization or unintentionally merging stale cloud state. Preserve the existing remote-only `Clear Data in Cloud...` action and make its outcome reliable.
