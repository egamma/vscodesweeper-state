# Issue #320433 — BYOK offline mode not working when vscode logged in

[https://github.com/microsoft/vscode/issues/320433](https://github.com/microsoft/vscode/issues/320433)

## Summary

Still reproduces on main: chatRequiresSetup forces setup when entitlement is `Available` (signed in but not signed up for Copilot Free), even when BYOK models are configured. The BYOK bypass was only added for the `Unknown` (signed-out) case, not the `Available` case.

## Change summary

BYOK offline models cannot be used when logged in with a GitHub account that hasn't signed up for Copilot Free, because the setup gate doesn't check hasByokModels for the `Available` entitlement state.

## Best solution

Add a `&& !context.hasByokModels` guard to the `context.entitlement === ChatEntitlement.Available` condition in `chatRequiresSetup` (line 191 of chatEntitlementService.ts), so that BYOK users bypass the forced sign-up prompt regardless of their entitlement state.
