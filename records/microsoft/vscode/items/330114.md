# Issue #330114 — Agent Host doesn't discover hooks from installed plugins (discoverHooks() lacks a plugin search root)

[https://github.com/microsoft/vscode/issues/330114](https://github.com/microsoft/vscode/issues/330114)

## Summary

Traced and confirmed on main: `discoverHooks()` in sessionCustomizationDiscovery.ts uses a hand-rolled scanner over a hardcoded `searchRoots`/`fixedDiscoveryFiles` list with no entry for installed-plugin directories, while `discoverAgents()`/`discoverSkills()` delegate to plugin-aware SDK RPCs — so plugin-shipped hooks are structurally invisible to the Agent Host even though the plugin's other customizations are discovered correctly.

## Change summary

Agent Host's hook discovery never scans installed-plugin directories (hooks.json / hooks/hooks.json), so plugin-provided hooks don't appear in the Agent Customizations panel, unlike agents/skills from the same plugin.

## Best solution

Wire plugin directory info (already tracked as `pluginDir`/`ISyncedCustomization` via `IAgentPluginManager` and the `PluginController` in copilotAgent.ts) into `SessionCustomizationDiscovery`, and add hook search roots for each synced plugin dir in `discoverHooks()` — mirroring how `discoverAgents`/`discoverSkills` already get plugin coverage through the SDK RPCs.
