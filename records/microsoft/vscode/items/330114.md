# Issue #330114 — Agent Host doesn't discover hooks from installed plugins (discoverHooks() lacks a plugin search root)

[https://github.com/microsoft/vscode/issues/330114](https://github.com/microsoft/vscode/issues/330114)

## Summary

Keep open: plugin hooks still cannot reach the Agent Host customization list through the current plugin-expansion path. Host-side discovery has improved since the report, but the UI expands only agents, skills, commands, and rules, omitting hooks even when the host publishes them.

## Change summary

Show installed plugins' hooks in the Agent Host customization panel alongside their skills and agents.

## Best solution

Make the Agent Host customization item pipeline expose plugin hook entries for supported Copilot and Claude plugin formats, preserving provenance and enablement. Treat hook visibility separately from runtime execution; the missing list entries do not establish that the runtime never loads those hooks.
