# Issue #275215 — Unclear that thinking did not make changes

[https://github.com/microsoft/vscode/issues/275215](https://github.com/microsoft/vscode/issues/275215)

## Summary

Keep open: this team-authored `plan-item` is a protected planning artifact, and current source still uses a completion checkmark for thinking groups regardless of whether they performed a mutating action.

## Change summary

Make collapsed chat thinking clearly distinguish reasoning and read-only tool use from actions that changed files or other state.

## Best solution

The chat-response UX should communicate completion without implying that changes occurred, while making any mutating tool activity independently visible. Keep this planning item open until the chat-response owners settle that affordance.
