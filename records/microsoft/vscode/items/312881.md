# Issue #312881 — Truncation in sessions lists can hide deleted line counts

[https://github.com/microsoft/vscode/issues/312881](https://github.com/microsoft/vscode/issues/312881)

## Summary

Keep open: current session-row styles still allow diff counts to be clipped without an overflow indication, and no verified fix or canonical duplicate was found. The list implementations have evolved since the report, but the supplied narrow-versus-wide comparison gives sufficient steps to retest the current UI.

## Change summary

Narrow session lists can hide the deleted-line count while leaving the added-line count visible, misleading users about the changes.

## Best solution

Ensure session-row change summaries do not silently present additions as the complete summary when deletions are clipped. Reproduce at supported narrow list widths in both the workbench and Agents Window, then preserve the summary's meaning without changing diff computation or session-loading behavior.
