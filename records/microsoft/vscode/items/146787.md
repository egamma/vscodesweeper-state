# Issue #146787 — Scrolling suggestion docstrings with PgUp/PgDn does not work when only one suggestion

[https://github.com/microsoft/vscode/issues/146787](https://github.com/microsoft/vscode/issues/146787)

## Summary

A real keyboard-navigation gap remains on current main: Page Up/Down cannot reach the existing documentation-scroll path when one focused suggestion is present. The Backlog milestone and existing suggest/UX labels remain appropriate.

## Change summary

Allow Page Up/Down to scroll focused suggestion documentation when the list contains only one item.

## Best solution

Permit `selectNextPageSuggestion` and `selectPrevPageSuggestion` while `suggestWidgetDetailsFocused` is true, regardless of suggestion count, while retaining the current single-item restrictions for ordinary list navigation.
