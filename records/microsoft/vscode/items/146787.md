# Issue #146787 — Scrolling suggestion docstrings with PgUp/PgDn does not work when only one suggestion

[https://github.com/microsoft/vscode/issues/146787](https://github.com/microsoft/vscode/issues/146787)

## Summary

Keep open: current source still blocks documentation paging when exactly one suggestion is selected, even after focusing its details. This is a bounded defect in an existing keyboard interaction rather than a missing scrolling feature.

## Change summary

Make PgUp/PgDn scroll focused suggestion documentation when only one completion is available.

## Best solution

Allow the existing documentation paging interaction independently of completion count while preserving ordinary single-suggestion editor paging when documentation is not focused.
