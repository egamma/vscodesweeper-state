# Issue #321541 — AHP: Background terminal causes agent response to never finish

[https://github.com/microsoft/vscode/issues/321541](https://github.com/microsoft/vscode/issues/321541)

## Summary

Team-authored bug report (MEMBER) with a team member already investigating — hard keep-open rule applies. The bug describes a real agent-session UX defect where background terminal monitoring prevents the agent response from completing.

## Change summary

When an agent session starts a background terminal to monitor a server, the agent response never transitions out of 'working' state even after the agent's reply is complete, because the background terminal process keeps the response alive.

## Best solution

The agent host's response lifecycle should distinguish between foreground tool execution (which blocks completion) and background terminal monitoring (which should not). The fix likely involves the agent host's terminal/tool completion tracking so that background-mode terminals don't hold the response open. DonJayamanne is already investigating.
