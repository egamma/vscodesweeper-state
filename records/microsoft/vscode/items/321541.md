## Summary

Team-authored bug about background terminals keeping agent responses in a perpetual 'working' state. DonJayamanne indicated they are looking into it. ## Change summary

When a session starts a background terminal to monitor a server, the agent response never transitions out of the 'working' input state even though the agent is done, and stopping it triggers an unwanted second response.

## Best solution

Verify whether the orphan-task_complete fix (e3170aadf88) and the background-agent-complete copy change (6bc81dad5c2) together resolve the reported STR. If the bug persists, the agent host's turn-completion logic in `src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts` likely needs to detect when the primary turn content is complete even while a background terminal agent remains running, and transition input state accordingly.
