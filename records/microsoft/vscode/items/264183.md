# Issue #264183 — Console host / terminal tab will not exit after using `code` to open the first Code window, until all Code windows are closed

[https://github.com/microsoft/vscode/issues/264183](https://github.com/microsoft/vscode/issues/264183)

## Summary

A real Windows-specific bug where the CLI launcher's spawned Code.exe process holds a console reference, preventing the terminal tab from closing until all VS Code windows exit. Still reproduces on 1.120.0 per reporter's May 2026 update; maintainer couldn't reproduce but conversation is active.

## Change summary

Running `code; exit` in PowerShell blocks the terminal tab from closing when the command opens the first VS Code window, until all Code windows are closed.

## Best solution

Investigate whether the Windows spawn in `src/vs/code/node/cli.ts` needs additional process creation flags (e.g., `CREATE_BREAKAWAY_FROM_JOB` or ensuring the child's console handle is fully released). The `detached: true` + `ELECTRON_NO_ATTACH_CONSOLE` combination may not be sufficient for Windows Terminal's process tracking. The maintainer's inability to reproduce suggests a configuration-specific trigger worth narrowing down further.
