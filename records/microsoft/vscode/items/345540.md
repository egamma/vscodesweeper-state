# Issue #345540 — Inbox: What do I "Select to inspect"?

[https://github.com/microsoft/vscode/issues/345540](https://github.com/microsoft/vscode/issues/345540)

## Summary

The current Inbox still displays “Select to inspect” as passive text inside the already-selected item's evidence pane. Keep this team-authored feedback open: the instruction does not identify an actionable target, and the linked test plan does not replace this specific finding.

## Change summary

Make the Inbox artifact inspection instruction identify what users can actually select.

## Best solution

Make the artifact hint self-explanatory and consistent with the available inspection controls, preserving existing evidence navigation. Decide whether this location needs explanatory text or an explicit inspection action.
