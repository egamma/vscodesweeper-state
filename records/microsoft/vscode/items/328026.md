# Issue #328026 — Allow configuring the content width of the experimental Markdown editor

[https://github.com/microsoft/vscode/issues/328026](https://github.com/microsoft/vscode/issues/328026)

## Summary

Current main has no configuration path for the experimental Markdown editor's content width, so this remains a valid feature request and should be routed to the Markdown editor owners.

## Change summary

Allow users to widen or remove the experimental Markdown editor's approximately 900-pixel content limit.

## Best solution

Give the experimental editor a responsive readable/full-width choice, preferably avoiding arbitrary per-pixel configuration. Register it in the Markdown extension configuration and pass the selected width through MarkdownEditorProvider to EditorView.
