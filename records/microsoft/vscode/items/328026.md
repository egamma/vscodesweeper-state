# Issue #328026 — Allow configuring the content width of the experimental Markdown editor

[https://github.com/microsoft/vscode/issues/328026](https://github.com/microsoft/vscode/issues/328026)

## Summary

Well-diagnosed, unaddressed feature request: the experimental hybrid Markdown editor hardcodes a 900px `max-width`, with no setting to override it, and no existing capability (`markdown.styles` only applies to the classic preview) covers this — should be routed to the markdown area for consideration.

## Change summary

Add a user/workspace setting to configure or disable the fixed ~900px content width of the new hybrid `vscode.markdown.editor` (Markdown Editor Experimental).

## Best solution

Add a setting such as `markdown.editor.maxContentWidth` (numeric px or `full`/unlimited) that is threaded into the `@vscode/markdown-editor` component's content width option and applied in extensions/markdown-language-features/src/preview/markdownEditorProvider.ts; a commenter already showed that simply removing the CSS `max-width` reflows correctly, suggesting the change is localized to how the width value is passed to the bundled `@vscode/markdown-editor` package.
