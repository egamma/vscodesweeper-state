# Issue #306383 — session unrecoverable from "image dimensions exceed max size" error

[https://github.com/microsoft/vscode/issues/306383](https://github.com/microsoft/vscode/issues/306383)

## Summary

Verified duplicate: the older open issue tracks the same observable failure—an oversized image remains in chat history and makes subsequent requests fail, leaving the session unrecoverable.

## Change summary

Browser-tool screenshots exceeding the model's many-image dimension limit become stuck in chat history and prevent the session from continuing.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/280486 and ensure oversized images from tools are resized or excluded before submission, while allowing an affected chat to recover without losing prior work.
