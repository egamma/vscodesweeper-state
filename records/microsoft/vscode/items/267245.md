# Issue #267245 — No way to escape from VisualMode to NormalMode on Jupyter Focused Cell

[https://github.com/microsoft/vscode/issues/267245](https://github.com/microsoft/vscode/issues/267245)

## Summary

Keep open for notebook keybinding investigation: the maintainer explicitly supported letting Vim handle the first Escape before notebook focus changes. Current Escape handling includes selection guards, so the original interaction needs retesting; the report already supplies sufficient steps and a workaround.

## Change summary

Escape should exit Vim Visual Mode in a notebook cell without moving focus out of the cell editor.

## Best solution

Preserve notebook cell-editor focus while Vim exits Visual Mode, while retaining the notebook's normal Escape-to-container behavior once Vim is in Normal Mode. First establish which keybinding wins with current VS Code and VSCodeVim.
