# Issue #330433 — Markdown Editor: Mermaid rendering doesn't use dark theme

[https://github.com/microsoft/vscode/issues/330433](https://github.com/microsoft/vscode/issues/330433)

## Summary

The Markdown Editor still initializes Mermaid with a fixed light/default theme on current main, independently of the active VS Code theme. Keep this confirmed rendering defect open; the older preview and stylesheet issues do not establish a matching duplicate.

## Change summary

Mermaid diagrams in the Markdown Editor use light-theme styling in dark VS Code themes, making sequence-diagram text and arrows difficult to read.

## Best solution

Make the Markdown Editor's Mermaid rendering follow the active VS Code theme, including theme changes while the document remains open, without changing classic Markdown Preview behavior or introducing a custom stylesheet requirement.
