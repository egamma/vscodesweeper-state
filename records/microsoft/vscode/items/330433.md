# Issue #330433 — Markdown Editor: Mermaid rendering doesn't use dark theme

[https://github.com/microsoft/vscode/issues/330433](https://github.com/microsoft/vscode/issues/330433)

## Summary

Traced on main: the new Markdown Editor's custom Mermaid code-block renderer hardcodes `theme: 'default'` (light) and never checks the webview's dark/light state, unlike the adjacent comments-view code in the same file which does check `document.body.classList.contains('vscode-light')`. A real, narrow gap.

## Change summary

In the (new) Markdown Editor, Mermaid diagram blocks always render with the light theme instead of following the active VS Code color theme, unlike Markdown Preview which renders them correctly.

## Best solution

In extensions/markdown-language-features/markdown-editor-src/editor.ts, make loadMermaid()/renderCustomCodeBlock detect the current theme (as the nearby `isLight = document.body.classList.contains('vscode-light')` check already does for the comments view) and initialize/re-render Mermaid with `theme: 'dark'` when appropriate, ideally reacting to theme changes the same way the mermaid-markdown-features preview extension does in preview-src/shared/vsCodeTheme.ts.
