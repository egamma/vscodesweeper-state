# Issue #337614 — Scrolling a fully collapsed Git commit multi-diff stalls the renderer

[https://github.com/microsoft/vscode/issues/337614](https://github.com/microsoft/vscode/issues/337614)

## Summary

Well-diagnosed perf bug (profiled, with before/after captures) that already has an open, non-merged fixing PR (#337615, 'Fixes #337614') — per policy this stays open for the human owner of that PR rather than being treated as agent-ready or closed.

## Change summary

Scrolling a fully collapsed Git commit multi-diff editor causes long main-thread tasks because collapsed rows still eagerly construct full DiffEditorWidget instances and the template pool is too small to reuse headers across a scroll.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/337615, which defers DiffEditorWidget construction until a file is actually expanded, releases invisible bindings before acquiring new templates, and raises the pool's retained-template limits.
