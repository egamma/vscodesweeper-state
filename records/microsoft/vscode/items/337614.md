# Issue #337614 — Scrolling a fully collapsed Git commit multi-diff stalls the renderer

[https://github.com/microsoft/vscode/issues/337614](https://github.com/microsoft/vscode/issues/337614)

## Summary

Well-diagnosed performance bug in the multi-diff editor's virtualized row templates, and there's already an open PR (#337615) fixing it — keeping this open for that PR to land rather than closing or treating it as agent-ready.

## Change summary

Scrolling a fully collapsed Git commit multi-diff editor causes renderer stalls because collapsed rows still construct full DiffEditorWidget instances and the template pool thrashes during fast scrolling.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/337615, which lazily creates the diff editor only on expansion, releases invisible bindings first, and bounds template reuse for collapsed headers.
