# Issue #196054 — recent project menu on small window is too wide

[https://github.com/microsoft/vscode/issues/196054](https://github.com/microsoft/vscode/issues/196054)

## Summary

Still reproducible on main: the submenu positioning logic in `calculateSubmenuMenuLayout` handles horizontal overflow by repositioning, but when a long path makes the submenu wider than the window, the overlap fallback (line 863-866) places the submenu directly over the parent menu entry, causing accidental activation. No max-width or truncation is applied to menu item labels.

## Change summary

The File > Open Recent submenu can grow wider than the window when paths are long, causing it to overlap the parent menu and trigger accidental item activation on mouse-up.

## Best solution

Apply a max-width constraint (or label truncation with ellipsis) to menu items so the submenu never exceeds viewport width, and improve the overlap fallback in `calculateSubmenuMenuLayout` so overlapping submenus don't position items directly under the cursor.
