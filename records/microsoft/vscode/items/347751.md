# Issue #347751 — Make ask_user extensible, skill-aware, and repository-governed

[https://github.com/microsoft/vscode/issues/347751](https://github.com/microsoft/vscode/issues/347751)

## Summary

Keep open as a feature request: existing question tools support rich choices, but do not establish the requested repository-defined resolver and approval protocol. The proposal needs a product decision about enforceable workflow contracts before implementation.

## Change summary

Allow repository Skills to govern clarification workflows, decision sequencing, presentation, and separate edit-plan approval.

## Best solution

Define the supported repository-level decision-workflow contract across the Copilot runtime and VS Code question UI, preserving permission enforcement independently. Existing instructions and tool selection can shape interactions, but should not be presented as guarantees of serialized decisions or explicit edit-plan authorization.
