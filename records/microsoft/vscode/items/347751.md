# Issue #347751 — Make ask_user extensible, skill-aware, and repository-governed

[https://github.com/microsoft/vscode/issues/347751](https://github.com/microsoft/vscode/issues/347751)

## Summary

Keep open as a feature request: existing skill loading and question controls do not establish repository-defined decision protocols. The proposed resolver contract and its relationship to edit authorization need product consideration.

## Change summary

Allow repository skills to govern ambiguity resolution, chat-first decision presentation, and separately approved edit plans.

## Best solution

Define whether repository skills can supply an opt-in decision-workflow contract across Copilot runtime and Chat UI, preserving the default experience and authoritative permission controls. Distinguish conversational decision acceptance from authorization to execute edits.
