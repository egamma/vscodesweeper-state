# Issue #280794 — Should `run in background` warn if you have selected an invalid agent or model?

[https://github.com/microsoft/vscode/issues/280794](https://github.com/microsoft/vscode/issues/280794)

## Summary

Keep open for a shared chat UX decision about unsupported agent/model fallback. Existing prompt diagnostics provide partial feedback, but do not establish destination-specific warning coverage when choosing Continue in; the maintainer explicitly extended the concern to general chat.

## Change summary

Make unsupported agent or model selections visible to users rather than silently substituting defaults when submitting or continuing a prompt.

## Best solution

Provide consistent, destination-aware feedback when an explicitly requested agent or model cannot be honored, covering both Continue in and general chat. Decide whether submission continues with an explained fallback or waits for the user to choose a supported alternative.
