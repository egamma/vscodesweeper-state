# Issue #260393 — Clean up auth provider account usage if extensions are uninstalled

[https://github.com/microsoft/vscode/issues/260393](https://github.com/microsoft/vscode/issues/260393)

## Summary

Automatic cleanup remains disabled on current main, so uninstalling an extension leaves its account usage and access records behind. Keep this accepted, team-authored issue open; the related reauthentication fix did not implement safe cleanup.

## Change summary

Clean up authentication usage and access for removed extensions and MCP servers without revoking access for consumers that remain installed.

## Best solution

Restore lifecycle-aware cleanup in the authentication contribution after establishing a complete, reliable inventory of installed consumers. Preserve installed-but-inactive extensions and built-in consumers, and avoid the reload-time access revocation documented in the related issue.
