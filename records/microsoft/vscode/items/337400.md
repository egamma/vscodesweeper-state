# Issue #337400 — MacOS: Ctrl+T and Ctrl+P cancel if window focus is taken away

[https://github.com/microsoft/vscode/issues/337400](https://github.com/microsoft/vscode/issues/337400)

## Summary

Quick Open intentionally closes when focus is lost by default. The existing workbench.quickOpen.closeOnFocusLost setting provides the requested behavior, and a maintainer has explicitly confirmed this policy for switching applications.

## Change summary

Keep filename and workspace-symbol pickers visible with their typed input when switching away from VS Code and back.

## Best solution

Keep the configurable default behavior and advise the reporter to set workbench.quickOpen.closeOnFocusLost to false.
