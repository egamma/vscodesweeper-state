[https://github.com/microsoft/vscode/issues/275985](https://github.com/microsoft/vscode/issues/275985)

## Summary

Valid feature request, already triaged by a team member as such. The simple file dialog only filters by dot-prefix, not by OS-level hidden attributes. No work has landed on main to address this — the request remains open.

## Change summary

The simple file dialog's 'Hide dot files' toggle should also hide OS-hidden files/folders on Windows (those with the Hidden attribute), not just dot-prefixed entries.

## Best solution

Extend the filtering in `simpleFileDialog.ts` (around line 1116) to also check the OS hidden attribute on Windows via `stat` metadata, and rename the toggle label to reflect the broader semantics (e.g. 'Hide hidden files'). The `diskFileSystemProvider.ts` may need to surface the hidden attribute if it doesn't already.
