# Issue #292149 — Cursor missing from code screen after using search function

[https://github.com/microsoft/vscode/issues/292149](https://github.com/microsoft/vscode/issues/292149)

This is a known Windows 11 24H2 Chromium/Electron cursor-disappearance bug, not a VS Code defect. The reporter confirms it also happens in Discord. Multiple duplicate reports exist (e.g. #236842, #252765, #239283); the root cause is upstream in the Windows cursor rendering or Chromium's interaction with it. ## Change summary

  > Thanks for the report. This is a known Windows 11 24H2 bug that affects Chromium-based applications (including VS Code's Electron shell and other apps like Discord, as you noted). The root cause is in Windows' cursor rendering, not in VS Code itself.
  > 
  > In the meantime, here are workarounds that have helped others:
  > - **Change your Windows mouse pointer style or increase the pointer size** (Windows Settings → Bluetooth & devices → Mouse → Mouse pointer).
  > - **Disable hardware acceleration** in VS Code: open the Command Palette (`Ctrl+Shift+P`), run `Preferences: Configure Runtime Arguments`, add `"disable-hardware-acceleration": true`, and restart.
  > 
  > See also https://github.com/microsoft/vscode/issues/236842 and https://github.com/microsoft/vscode/issues/252765 for related reports.
