# Issue #244271 — Pasting text from one note into chat adds image attachment 

[https://github.com/microsoft/vscode/issues/244271](https://github.com/microsoft/vscode/issues/244271)

## Summary

The defect remains source-reproducible on current main: chat's image paste edit does not yield to plain text when the clipboard contains both representations, so OneNote's incidental image becomes an attachment. The expected behavior is already clear from the maintainer discussion and the editor's normal paste precedent.

## Change summary

Pasting copied OneNote text into chat also creates an unwanted image attachment from the clipboard's image representation.

## Best solution

Automatic chat paste should prefer `text/plain` whenever it is available while retaining the image edit as an explicit Paste As choice, matching normal editor paste behavior.
