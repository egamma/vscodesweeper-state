# Issue #350692 — Agent Host: scoped Copilot runtime drops any env var whose name contains TOKEN/SECRET/_KEY/PASSWORD (e.g. a *_SECRETS_ROOT path), so agent shells lose user config mid-session

[https://github.com/microsoft/vscode/issues/350692](https://github.com/microsoft/vscode/issues/350692)

## Summary

Current source confirms that scoped Copilot runtimes discard ordinary configuration variables such as MY_APP_SECRETS_ROOT. Keep this open for human review because correcting the overmatching touches the credential-isolation boundary.

## Change summary

Preserve non-credential user configuration in agent shells when a Copilot session starts or resumes in a scoped runtime.

## Best solution

Define a credential-isolation contract that preserves legitimate shell configuration consistently across runtime replacement without allowing ambient provider credentials to override the selected identity. Resolve the filtering behavior in the Copilot runtime environment construction path.

## Evidence

- **Current-source confirmation:** src/vs/platform/agentHost/node/copilot/copilotCliEnvironment.ts:27-36 filters inherited names with unanchored TOKEN, _KEY, SECRET, and PASSWORD alternatives when omitAmbientAuthentication is true. MY_APP_SECRETS_ROOT matches SECRET and is omitted regardless of its directory-path value; the unscoped path preserves it.
- **Runtime adoption:** src/vs/platform/agentHost/node/copilot/copilotAgent.ts:5296 passes scoped !== undefined into _createCopilotCliEnvironment. Lines 11334-11347 construct that environment from process.env, and lines 5440-5463 supply the resulting env to RuntimeConnection.forSpawnedStdio. The reported omission therefore reaches the actual scoped runtime launch.
- **Existing coverage and remaining gap:** src/vs/platform/agentHost/test/node/copilotAgent.test.ts:16645-16661 checks that scoped environments omit GH_TOKEN, COPILOT_SDK_AUTH_TOKEN, and OPENAI_API_KEY while preserving PATH. The following test preserves GIT_CONFIG_* groups. Neither covers the reported non-credential names containing credential-like substrings.
- **Security-sensitive boundary:** https://github.com/microsoft/vscode/pull/341455 is merged and establishes separately owned Copilot clients to prevent work from silently selecting another connection's more powerful credential. Relaxing the environment filter requires human review of that isolation contract; this is not evidence that the reported configuration loss is intentional.
