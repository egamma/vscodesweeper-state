# Issue #137101 — Cursor Follow Outline

[https://github.com/microsoft/vscode/issues/137101](https://github.com/microsoft/vscode/issues/137101)

## Summary

This accepted Backlog request still represents a real gap: Outline navigation only reveals a symbol after an open action, while “Follow Cursor” operates in the opposite direction. With 22 community upvotes, it should remain open.

## Change summary

Add an opt-in inverse Follow Cursor behavior that reveals Outline symbols in the editor while navigating the Outline without requiring Enter on each item.

## Best solution

Add an explicit Outline interaction mode that previews the focused symbol through the existing reveal path while preserving normal scrolling and explicit-open behavior. The trigger should be focus or selection changes rather than raw viewport scrolling, which has no unique target symbol.
