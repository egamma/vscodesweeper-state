# Issue #344124 — Agents window: Akusto #kusto tool in a background session opens Kusto Explorer in the focused session

[https://github.com/microsoft/vscode/issues/344124](https://github.com/microsoft/vscode/issues/344124)

## Summary

Keep open: current source still routes extension webview opens to the active editor group without originating-session context. Layout ownership has evolved since the report, but the supplied steps suffice to retest; the related closed Inbox issue does not resolve this background-tool scenario.

## Change summary

Prevent a background session's tool-created editor from appearing in the focused session's editor tabs.

## Best solution

Establish a supported session-aware contract for tool-driven editor presentation that leaves the focused session undisturbed. Decide whether background tools can target their originating session or must defer presentation until explicit user action.
