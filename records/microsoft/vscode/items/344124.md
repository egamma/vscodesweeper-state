# Issue #344124 — Agents window: Akusto #kusto tool in a background session opens Kusto Explorer in the focused session

[https://github.com/microsoft/vscode/issues/344124](https://github.com/microsoft/vscode/issues/344124)

## Summary

Keep open: the current webview-opening path targets the active editor group without carrying the invoking session, supporting the reported cross-session tab placement. This team-authored report identifies a platform gap; suppressing Akusto's automatic reveal would mitigate the symptom without resolving session-aware editor ownership.

## Change summary

A background session's extension tool opens its Kusto Explorer webview in the foreground session's editor working set.

## Best solution

Background tool activity should not add editors to an unrelated focused session. Agree on an extension-facing contract for session-targeted editor opens or background-reveal suppression, while preserving ordinary editor-opening behavior and explicit user commands.
