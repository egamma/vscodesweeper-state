# Issue #293635 — Feature Request: Allow selective addition of error problems to Copilot context

[https://github.com/microsoft/vscode/issues/293635](https://github.com/microsoft/vscode/issues/293635)

## Summary

A real gap remains in the current Problems attachment picker: users can attach one diagnostic or all diagnostics, but cannot bulk-attach by severity. Route this feature request to the chat area for a product decision on how severity selection should interact with existing Problems filters.

## Change summary

Allow users to attach only selected diagnostic severities, especially errors, to Copilot Chat context.

## Best solution

Let the Problems context picker attach errors, errors and warnings, or all problems while retaining individual-problem selection. The chosen scope should be explicit and predictable rather than silently inheriting unrelated Problems-panel state.

- **Behavior:**

  > When a workspace has mixed errors, warnings, and informational diagnostics, the Problems chat-context picker lets the user attach a severity-limited aggregate, including errors only, without attaching less severe diagnostics. Individual diagnostic attachment and an all-problems choice remain available. Acceptance should verify the choices and resulting diagnostic sets for mixed severities.
- **Trace:**

  > MarkerChatContextPick.getPicksForQuery in src/vs/workbench/contrib/markers/browser/markersChatContext.ts reads Error, Warning, and Info markers, creates one pick per marker, and creates only one aggregate `All Problems` attachment with `filterSeverity: MarkerSeverity.Info`. IDiagnosticVariableEntryFilterData in src/vs/workbench/contrib/chat/common/attachments/chatVariableEntries.ts already carries `filterSeverity`; extHostTypeConverters.ts converts it to DiagnosticSeverity and excludes less severe diagnostics. The boundary is the Problems attachment experience: preserve individual picks, existing diagnostic conversion semantics, and unrelated Problems-panel filtering. https://github.com/microsoft/vscode/issues/277231 establishes that individual and multi-selected Problems attachment is separate existing behavior.
- **Open decisions:**
  - Should aggregate attachment offer fixed severity presets regardless of the Problems panel state, or attach exactly the severities currently enabled by the panel's Error, Warning, and Info filters?
