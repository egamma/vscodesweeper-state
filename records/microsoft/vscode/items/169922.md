# Issue #169922 — "Reveal in Explorer View" misbehaves with out-of-workspace files

[https://github.com/microsoft/vscode/issues/169922](https://github.com/microsoft/vscode/issues/169922)

## Summary

The defect remains source-reproducible on current main: invoking the command for an out-of-workspace tab focuses the Open Editors view, whose selection continues to follow the active editor rather than the requested tab. The issue was deliberately reopened and reclassified as a bug after the maintainer proposed disabling the misleading entry, but the final user-visible behavior remains undecided.

## Change summary

Ensure that “Reveal in Explorer View” does not focus an unrelated workspace file when invoked from an out-of-workspace editor tab.

## Best solution

Choose whether the editor-tab action should be unavailable for out-of-workspace resources or should reveal the requested tab in Open Editors, then make the menu and command behavior consistently implement that choice without affecting in-workspace reveal.
