# Issue #243533 — Search results appear for excluded files when file is opened

[https://github.com/microsoft/vscode/issues/243533](https://github.com/microsoft/vscode/issues/243533)

## Summary

Keep open: current source still allows open-editor matches to bypass configured search exclusions. The exclusion check reads top-level patterns, while QueryBuilder places search.exclude settings in folder-query patterns.

## Change summary

Ensure files excluded from workspace search remain excluded when opened in an editor.

## Best solution

Make open-editor search honor the applicable workspace-folder exclusions, preserving existing explicit include/exclude behavior and searches outside workspace folders. Cover the reported open-versus-closed distinction with a regression check.
