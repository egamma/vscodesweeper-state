# Issue #329142 — Add a way to override using Wayland instead of X11 in the Snap package.

[https://github.com/microsoft/vscode/issues/329142](https://github.com/microsoft/vscode/issues/329142)

## Summary

The Snap launcher still unconditionally appends the X11 backend flag, so the requested opt-in remains missing. Keep this request open and coordinate it with the existing native-Wayland packaging PR rather than closing it against a related default-backend request.

## Change summary

Allow users of the official Snap package to explicitly select native Wayland instead of the launcher's forced X11 backend.

## Best solution

Provide an explicit Wayland opt-in that the Snap launcher honors while preserving the existing default for users who do not opt in. Review the overlapping work in https://github.com/microsoft/vscode/pull/199052 and account for the known Snap GTK schema incompatibility before treating native-Wayland launch as supported.
