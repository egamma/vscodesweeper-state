# Issue #193094 — Occurrences Highlight obscurely affected by Editor Search options

[https://github.com/microsoft/vscode/issues/193094](https://github.com/microsoft/vscode/issues/193094)

## Summary

The coupling remains on current main and a maintainer supports decoupling selection highlights from hidden Find options. This is intentional legacy behavior needing a UX decision, so the existing under-discussion issue should remain open.

## Change summary

Make selection-occurrence highlighting independent of hidden Match Case and Match Whole Word state, or expose that state clearly.

## Best solution

Decide whether non-collapsed selection highlighting should use independent matching semantics while preserving the established collapsed-cursor and Cmd+D behavior; implement that distinction in the multicursor selection-highlighter path.
