# Issue #334261 — Add `modernSideBar` to override Modern UI colors.

[https://github.com/microsoft/vscode/issues/334261](https://github.com/microsoft/vscode/issues/334261)

## Summary

Keep open: existing sidebar and surface tokens allow customization, but do not provide independent Modern UI-only overrides for sidebar colors. No verified older open issue owns this specific request.

## Change summary

Expose Modern UI-specific sidebar color overrides so themes can support modern and classic layouts independently.

## Best solution

Define a consistent theme-color contract for Modern UI sidebar overrides, including primary and secondary sidebars, while preserving existing sideBar.* behavior in classic UI. Decide which sidebar tokens need independent modern values before expanding the public color API.
