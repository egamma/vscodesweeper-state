# Issue #334261 — Add `modernSideBar` to override Modern UI colors.

[https://github.com/microsoft/vscode/issues/334261](https://github.com/microsoft/vscode/issues/334261)

## Summary

Legitimate, freshly-filed request: Modern UI has per-component override colors for the activity bar and tabs (`modernActivityBar.*`, `modernTab.*`, `modernEditorTab.*`) but no analogous `modernSideBar.*` set, and the only related token (`surface.background`/`surface.foreground`/`surface.border`) appears used for the splash screen and floating "card" surfaces rather than as a documented, reliable way to restyle the live docked side bar under Modern UI.

## Change summary

Add `modernSideBar.*` color tokens so theme authors/users can override the side bar's appearance specifically when Modern UI is enabled, mirroring the existing `modernActivityBar`/`modernTab`/`modernEditorTab` tokens.

## Best solution

If the intent is that `surface.background`/`surface.foreground`/`surface.border` already cover this (per the Modern UI README's framed-container-surface model), a maintainer should confirm that and point the reporter there, closing as as-designed with those token names. If not, this belongs in `src/vs/workbench/common/theme.ts` and `src/vs/workbench/services/themes/browser/` alongside the existing modern-tab/activity-bar color contributions.
