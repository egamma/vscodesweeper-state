# Issue #299452 — Bypass Approvals/Autopilot - audit summary

[https://github.com/microsoft/vscode/issues/299452](https://github.com/microsoft/vscode/issues/299452)

## Summary

A real auditability gap remains: current session state records tool-confirmation provenance, but no end-of-session, easily parsed audit summary exposes Autopilot decisions and automatically approved tools. This member-authored request is protected from judgment closes, and no older canonical with the same observable request was found.

## Change summary

Provide a machine-readable end-of-session audit summary of Autopilot decisions and tools run through Bypass Approvals or Autopilot.

## Best solution

Define a stable session audit representation that distinguishes explicit approval, setting-driven approval, and approval-free execution, then expose it at session completion or through the existing export surface alongside a concise record of autonomous decisions.
