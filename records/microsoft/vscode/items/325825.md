# Issue #325825 — Configure Tools selection still does not persist in VS Code 1.128.0

[https://github.com/microsoft/vscode/issues/325825](https://github.com/microsoft/vscode/issues/325825)

## Summary

The custom-tool-set case remains broken on current main and is distinct from the hidden built-in tool-set regression fixed by https://github.com/microsoft/vscode/pull/324157. Route this confirmed bug to the chat tools/toolsets owners.

## Change summary

Tool selections made through Configure Tools are discarded when a custom tool set contains the same tools.

## Best solution

Correct result collection in `chatToolPicker.ts` so unchecked representations beneath a disabled user tool set do not override the independently selected instance of the same tool, while preserving partial-deselection behavior for enabled tool sets.
