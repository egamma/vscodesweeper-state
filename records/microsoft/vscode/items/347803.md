# Issue #347803 — chat.defaultModel cannot consistently identify a BYOK provider across Local and Copilot Agent Host

[https://github.com/microsoft/vscode/issues/347803](https://github.com/microsoft/vscode/issues/347803)

## Summary

Keep open: current source confirms that configured defaults resolve by target-dependent metadata IDs rather than stable provider identity. The supplied reproduction distinguishes this from picker visibility and conversation-transfer issues.

## Change summary

Provider-qualified BYOK defaults resolve inconsistently between Local and Copilot Agent Host, with fallback to another provider when resolution fails.
