# Issue #298568 — Add command to insert selected editor text into Copilot Chat input at cursor position

[https://github.com/microsoft/vscode/issues/298568](https://github.com/microsoft/vscode/issues/298568)

## Summary

A real capability gap remains on current main: VS Code can attach an editor selection to Chat, but has no command that inserts the selected text into the prompt at its cursor. The request has limited traction and no maintainer decision, so it should remain open as under discussion rather than be closed.

## Change summary

Add a bindable command that inserts the active editor selection as editable plain text at the current cursor position in the Chat input without creating an attachment.

## Best solution

Provide a Chat command that preserves the existing prompt, inserts the selected editor text at the Chat input selection, and leaves it editable without adding context or changing conversation state. It should follow the existing Chat widget-targeting convention across panel, editor, and window hosts.
