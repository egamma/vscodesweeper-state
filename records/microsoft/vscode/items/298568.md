# Issue #298568 — Add command to insert selected editor text into Copilot Chat input at cursor position

[https://github.com/microsoft/vscode/issues/298568](https://github.com/microsoft/vscode/issues/298568)

## Summary

A real chat-input capability gap remains: the existing selection command creates an attachment rather than inserting editable text. Route to chat input and keep under discussion.

## Change summary

Add a command that inserts the active editor selection as plain text at the retained Copilot Chat input cursor.

## Best solution

Add a core chat action in `chatContextActions.ts` that reads the active editor selection and applies it through `widget.inputEditor.executeEdits` at the retained input selection, without creating an attachment.
