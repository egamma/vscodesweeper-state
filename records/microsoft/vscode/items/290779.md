# Issue #290779 — Letters are not centered in keys in Welcome page

[https://github.com/microsoft/vscode/issues/290779](https://github.com/microsoft/vscode/issues/290779)

## Summary

Still present on main: the Welcome page's CSS override for `.monaco-keybinding-key` uses `display: inline-block` instead of the base style's `inline-flex` + `align-items: center`, causing letters to not be vertically centered in keybinding keys.

## Change summary

Letters in keybinding key labels on the Welcome page are left/top-aligned instead of centered.

## Best solution

In `src/vs/workbench/contrib/welcomeGettingStarted/browser/media/gettingStarted.css` (line ~539), change `display: inline-block` to `display: inline-flex; align-items: center; justify-content: center;` — or remove the override entirely so the base `keybindingLabel.css` centering applies.
