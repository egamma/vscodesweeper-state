# Issue #346007 — Copilot apply_patch converts literal \t after a comment prefix into a TAB character

[https://github.com/microsoft/vscode/issues/346007](https://github.com/microsoft/vscode/issues/346007)

Keep open: current source confirms that Update File converts literal backslash-t after a comment prefix into a tab, corrupting inserted content. The related indentation report concerns a different transformation and does not absorb this defect.

## Change summary
