# Issue #331248 — Chat Title: Generated Title Casing is different between the Agents/Editor window

[https://github.com/microsoft/vscode/issues/331248](https://github.com/microsoft/vscode/issues/331248)

## Summary

Traced in the current source: the sticky chat-title header in the editor/panel chat view (`ChatViewTitleControl`/`ChatViewTitleLabel`) renders the AI-generated conversation title through `.chat-view-title-label`, which has `text-transform: uppercase` — so the same title shows in ALL CAPS there while other surfaces (e.g. the Agents window/session list) render it with normal casing.

## Change summary

The AI-generated chat title is rendered in all-caps in the editor/panel chat view's sticky title header, but in normal casing in the Agents window.

## Best solution

Drop (or scope down) the `text-transform: uppercase` rule on `.chat-view-title-label` in chatViewTitleControl.css so the generated conversation title renders with its natural casing, matching how it's shown in the Agents window/session list.
