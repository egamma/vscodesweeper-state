# Issue #331248 — Chat Title: Generated Title Casing is different between the Agents/Editor window

[https://github.com/microsoft/vscode/issues/331248](https://github.com/microsoft/vscode/issues/331248)

## Summary

Team-authored issue with a real milestone (1.137.0) assigned, so it stays open regardless; a maintainer has already confirmed the Agents Window casing is intentional and left the decision on whether the Editor window should match to another maintainer — this is an open product decision, not something to close.

## Change summary

Chat-generated titles render in ALL CAPS in the Editor window (via CSS text-transform: uppercase on .chat-view-title-label) but keep their original casing in the Agents Window, creating an inconsistent presentation of the same generated title.

## Best solution

Awaiting @justschen's decision on whether src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/media/chatViewTitleControl.css should drop its `text-transform: uppercase` on `.chat-view-title-label` to match the Agents Window's original-case rendering, or whether the Agents Window should instead be updated to uppercase for consistency.
