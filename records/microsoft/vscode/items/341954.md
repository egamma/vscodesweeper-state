[https://github.com/microsoft/vscode/issues/341954](https://github.com/microsoft/vscode/issues/341954)

## Summary

Thanks for the detailed UX feedback. Existing settings only hide the tab scrollbar or make it larger, so the request to move it out of the tab area is not covered. It is a new feature request with no maintainer input or demand yet, so it stays open.

## Change summary

Place the editor tab horizontal scrollbar so it does not visually overlap the tab headers.

## Best solution

Let the community and the workbench owners weigh in on whether the scrollbar should be repositioned (e.g. below the tabs or reserved space). Meanwhile, users can set workbench.editor.titleScrollbarVisibility to hidden if they want no scrollbar.
