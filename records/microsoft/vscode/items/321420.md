# Issue #321420 — Selecting 200K context size for Claude Sonnet 4.6 has maxPromptTokens: 936000 (1M)

[https://github.com/microsoft/vscode/issues/321420](https://github.com/microsoft/vscode/issues/321420)

## Summary

Fixed on main and shipped in 1.126.0. The context-size model-picker selection was not being applied to the agent endpoint, so the full 1M native window was always used. A series of commits introduced `applyContextSizeOverride` and wired it into the agent intent path.

## Change summary

Selecting 200K context size for Claude Sonnet 4.6 in the model picker still sent requests with the full 1M context window (maxPromptTokens: 936000).

## Best solution

Keep the shipped fix. The `applyContextSizeOverride` function (introduced in bb215ba65e1, refined in 4972ac9c099 and 0acd78faaf5) now correctly clamps the endpoint's `modelMaxPromptTokens` to the user's picker selection, including a default-tier fallback when there is a long-context surcharge. No further change needed.
