# Issue #318839 — REGRESSION: new default dark theme is absolute crap for syntax highlight

[https://github.com/microsoft/vscode/issues/318839](https://github.com/microsoft/vscode/issues/318839)

## Summary

This is an in-scope theme quality complaint about the new default dark theme, and current main still ships Dark 2026 as the default dark theme; it should be routed to the theme owners rather than closed from cleanup.

## Change summary

Improve or reconsider Dark 2026's default syntax colors, especially for PHP, after users were migrated from the previous dark default.

## Best solution

Have the themes area decide whether Dark 2026's token colors need adjustment or whether migration/default-theme behavior should change; keep Dark Modern available as the user workaround.

- **history:** Commit 11a2e60f4f254f7e6576a171f9cb385ab8e37806 added the 2026 themes and made the experimental themes the new default; later theme-syntax color changes in PR https://github.com/microsoft/vscode/pull/320953 were reverted by 77f8b67c2c1eced2ae12e3e0a1dbbca311abafa0, so there is no clear implemented-on-main fix to cite.
- **discussion:** Three follow-up comments report similar dissatisfaction and confirm switching back to Dark Modern restores the preferred appearance.
