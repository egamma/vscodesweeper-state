# Issue #303523 — Profile-level Git author identity for Source Control commits

[https://github.com/microsoft/vscode/issues/303523](https://github.com/microsoft/vscode/issues/303523)

## Summary

The built-in Git extension still lacks a profile-scoped commit identity override. Route this unlabeled request to Git for a scope decision; the earlier equivalent request was closed for insufficient votes, not because the capability was implemented or explicitly rejected.

## Change summary

Allow profile-specific Git name and email overrides for Source Control commits without modifying Git configuration or terminal behavior.

## Best solution

The Git owner should evaluate an opt-in, profile-scoped identity for UI-initiated commits, preserving normal Git configuration and terminal semantics. If accepted, its remote-profile behavior and author-versus-committer semantics need an explicit contract.
