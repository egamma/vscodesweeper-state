# Issue #303523 — Profile-level Git author identity for Source Control commits

[https://github.com/microsoft/vscode/issues/303523](https://github.com/microsoft/vscode/issues/303523)

## Summary

Well-scoped feature request for profile-level Git author identity in Source Control commits. No existing setting or duplicate covers this. The git extension already uses `-c` overrides at commit time (user.useConfigOnly), so the plumbing is partially in place. Routes to the git/scm area for evaluation.

## Change summary

Allow VS Code profiles to specify Git user.name and user.email, applied via `-c` overrides when committing through the Source Control UI.

## Best solution

Add `git.profileCommitUserName` and `git.profileCommitUserEmail` settings (profile-scoped), and pass them as `-c user.name=…` / `-c user.email=…` in the commit method in `extensions/git/src/git.ts` — the same pattern already used for `user.useConfigOnly`. This keeps it contained to VS Code UI commits without touching git config files.
