[https://github.com/microsoft/vscode/issues/309600](https://github.com/microsoft/vscode/issues/309600)

## Summary

Keep open: a maintainer confirmed an inconsistency between single-file and default multi-file diff editors, where only the former automatically adds review comments to chat context. The newer related issue is not a valid canonical for this re-reviewed item.

## Change summary

Make comments created in the multi-file diff editor appear as context in the chat input, with coherent feedback/comment terminology.

## Best solution

Align the multi-file diff editor with the single-file flow so submitted comments are visibly attached to the next chat turn, while using consistent terminology before and after submission.
