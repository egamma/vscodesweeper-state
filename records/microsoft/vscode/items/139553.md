# Issue #139553 — Emmet JSX Intellisense doesn't appear when directly next to a closing parentheses

[https://github.com/microsoft/vscode/issues/139553](https://github.com/microsoft/vscode/issues/139553)

## Summary

Still reproduces on main: the emmet `extract` function (from `@emmetio/abbreviation` via `@vscode/emmet-helper`) with `lookAhead: true` rejects abbreviations when a closing parenthesis immediately follows the cursor position. Already properly labeled with `emmet-parse` and in the Backlog.

## Change summary

Emmet abbreviation completions don't trigger in JSX/TSX when the cursor is directly before a closing parenthesis.

## Best solution

The fix likely belongs in the upstream `@emmetio/abbreviation` extract logic or in the `@vscode/emmet-helper` wrapper — either the lookAhead scan needs to treat `)` as a valid boundary character, or the extraction in `defaultCompletionProvider.ts` should pass `lookAhead: false` for markup in JSX contexts where brackets are common.
