# Issue #274111 — Switching between agent types breaks if images present in history

[https://github.com/microsoft/vscode/issues/274111](https://github.com/microsoft/vscode/issues/274111)

## Summary

The reported model-switch failure is fixed on current main: historical images are now filtered according to the newly selected model's vision capability before constructing the request.

## Change summary

Switching from a vision-capable chat agent to a model without image support caused a 400 response because images remained in the replayed conversation history.

## Best solution

Keep the capability-aware historical-image handling introduced by commit e7bc310ccb523a03ffd04dacba3ccb22e1952154; non-vision models receive the prior text history without image content.
