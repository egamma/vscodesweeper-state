# Issue #347298 — Agents window comment widget doesn't allow to create a new line with `shift+enter`

[https://github.com/microsoft/vscode/issues/347298](https://github.com/microsoft/vscode/issues/347298)

## Summary

Keep open: the new-comment input intercepts Shift+Enter as submission, preventing a newline. The assigned 1.147.0 milestone also protects this issue from cleanup closure.

## Change summary

Allow Shift+Enter to insert a newline when composing a new comment in the Agents window.

## Best solution

The new-comment composer should support Shift+Enter consistently with existing edit and reply composers, while preserving Enter to add feedback and Alt+Enter to add and submit.
