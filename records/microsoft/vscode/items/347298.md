# Issue #347298 — Agents window comment widget doesn't allow to create a new line with `shift+enter`

[https://github.com/microsoft/vscode/issues/347298](https://github.com/microsoft/vscode/issues/347298)

## Summary

Keep open: the current new-comment input intercepts Shift+Enter as submission instead of allowing a newline. The assigned 1.148.0 milestone also requires preserving the issue for its scheduled work.

## Change summary

Allow Shift+Enter to insert a newline when composing a comment in the Agents window.

## Best solution

The Agents window new-comment composer should support multiline input with Shift+Enter while preserving Enter to add feedback and Alt+Enter to add and submit.
