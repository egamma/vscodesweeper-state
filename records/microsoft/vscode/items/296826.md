# Issue #296826 — Background agent session: Closing terminal opened via  `Resume in Integrated Terminal` says `Closing will terminate the processes running in this terminal` - but unclear what that means

[https://github.com/microsoft/vscode/issues/296826](https://github.com/microsoft/vscode/issues/296826)

## Summary

Valid UX concern: the terminal close confirmation dialog is generic and doesn't distinguish between killing a standalone process and closing a view into a background agent session. The user can't tell whether dismissing the terminal will terminate the agent. No fix found on main.

## Change summary

When closing a terminal opened via 'Resume in Integrated Terminal' for a background agent session, the generic 'Closing will terminate the processes running in this terminal' dialog doesn't clarify whether the background agent itself will be killed.

## Best solution

The Copilot CLI session terminal integration should either (a) customize the close confirmation to explain that the background agent session continues independently, or (b) suppress the confirmation entirely if closing the terminal view doesn't actually stop the agent. The relevant terminal confirmation logic is in `src/vs/workbench/contrib/terminal/browser/terminalEditorInput.ts` (lines 107–117), and the resume-in-terminal flow is in `extensions/copilot/src/extension/chatSessions/vscode-node/copilotCLIChatSessionsContribution.ts` (`resumeCopilotCLISessionInTerminal`).
