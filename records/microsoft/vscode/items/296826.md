# Issue #296826 — Background agent session: Closing terminal opened via  `Resume in Integrated Terminal` says `Closing will terminate the processes running in this terminal` - but unclear what that means

[https://github.com/microsoft/vscode/issues/296826](https://github.com/microsoft/vscode/issues/296826)

## Summary

Keep open as a session-lifecycle UX clarification: the resume command launches or reveals an actual CLI terminal, but its generic close warning still does not explain the consequences for the background agent. The reporter supplied the requested steps; no additional basic reproduction information is needed.

## Change summary

Clarify what closing a terminal opened through a background session's resume action does to the CLI process and background session.

## Best solution

Make the resume/close experience distinguish terminating the terminal's CLI process from deleting session history or stopping independently running background work. Establish the actual background-session consequences before presenting session-specific guidance, while retaining normal terminal termination protection.
