# Issue #291172 — Testing: Subagent list items have visually clipped focus outline

[https://github.com/microsoft/vscode/issues/291172](https://github.com/microsoft/vscode/issues/291172)

## Summary

The clipping cause identified by a maintainer remains on current main: rounded, overflow-hidden nested chat lists contain rows whose inset focus outline uses a different corner radius. This team-authored On Deck issue should remain open as a bounded accessibility and visual-consistency bug.

## Change summary

Keyboard-focused items in subagent and chat reference lists have visibly clipped focus-outline corners.

## Best solution

Keep the keyboard focus indicator fully visible and geometrically consistent around every nested chat-list row, including the first and last items, without changing shared list behavior or the surrounding chat layout.
