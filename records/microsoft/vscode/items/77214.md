# Issue #77214 — Have a command that clears all problems that are from tasks.

[https://github.com/microsoft/vscode/issues/77214](https://github.com/microsoft/vscode/issues/77214)

## Summary

Keep this accepted, team-authored request open: current task commands do not provide task-only problem clearing, and shared diagnostic ownership remains a substantive constraint. The older related requests do not establish a duplicate of this specific task-scoped command.

## Change summary

Provide an explicit command to clear task-generated problems without clearing unrelated diagnostics, potentially accepting a specific task parameter.

## Best solution

Provide task-scoped clearing that preserves language-service diagnostics and their incremental updates, including when task configuration changes leave older problems behind. Resolve the shared-owner lifecycle boundary before treating this as a small command addition.
