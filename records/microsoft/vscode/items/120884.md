# Issue #120884 — Code screen will move up after write a unimported package method and undo

[https://github.com/microsoft/vscode/issues/120884](https://github.com/microsoft/vscode/issues/120884)

## Summary

The request to record scroll position in the undo stack remains unimplemented on current main — the undo stack (`SingleModelEditStackData` in `editStack.ts`) stores cursor state and text changes but not scroll position. Keeping open as a valid feature request in the Backlog.

## Change summary

When undoing an auto-import that added lines above the cursor, the viewport shifts down because the scroll position is not restored with the undo.

## Best solution

Extend the editor undo stack to capture and restore the scroll top alongside cursor state, so that undo/redo of edits that insert or remove lines above the viewport also restores the viewport position. The likely files are `src/vs/editor/common/model/editStack.ts` (to store scroll position in `SingleModelEditStackData`) and the suggest/undo integration in `src/vs/editor/contrib/suggest/`.
