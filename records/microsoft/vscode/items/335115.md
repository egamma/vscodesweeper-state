# Issue #335115 — Webview resource path containment bypass

[https://github.com/microsoft/vscode/issues/335115](https://github.com/microsoft/vscode/issues/335115)

Security advisory disclosure (CVE-2026-81383) for a webview path-containment bypass, filed by a VS Code team member with the fix already released in 1.136.2 — carries the `security` label and an assigned real milestone, so this stays open per the hard keep-open rules regardless of the fix status.

## Change summary

A webview could escape its configured localResourceRoots because backslash path separators weren't normalized before the containment check on non-file resource schemes, letting scripts in the webview read resources outside the intended sandbox.
