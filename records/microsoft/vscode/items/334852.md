# Issue #334852 — Custom agents fail as subagents due to "displayName: Required" while frontmatter does not need it

[https://github.com/microsoft/vscode/issues/334852](https://github.com/microsoft/vscode/issues/334852)

## Summary

This is a real, already-known issue: VS Code's own E2E test suite documents this exact failure as a deliberately-skipped known issue awaiting a fix in the bundled Copilot SDK/runtime, so it stays open as an upstream tracking item rather than a VS Code core bug to close.

## Change summary

Repository custom agents (`.github/agents/*.agent.md`) fail as subagents with `displayName: Required` because the bundled Copilot runtime's validation boundary treats an SDK-optional field as required.

## Best solution

Keep tracking upstream: the fix belongs in the bundled `@github/copilot-sdk` runtime (currently `1.0.13-preview.4`), not in `copilotPluginConverters.ts`. Once a fixed SDK build ships, un-gate `AGENT_HOST_RUN_KNOWN_ISSUES` for the `custom agent without a display name completes as a subagent` test in src/vs/platform/agentHost/test/node/e2e/suites/subagentSuite.ts and remove the corresponding KNOWN_ISSUES.md entry.
