# Issue #279957 — Tool picker/dropdown should be configurable from the outside

[https://github.com/microsoft/vscode/issues/279957](https://github.com/microsoft/vscode/issues/279957)

## Summary

The architectural debt remains on current main: model eligibility for editor-inline chat is still hardcoded inside the shared chat input model-filtering path instead of being supplied by the widget consumer. A maintainer endorsed the external callback design, while the prior implementation PR was closed without merging.

## Change summary

Allow chat-widget consumers to configure which language models appear in their model picker instead of embedding surface-specific filtering in the shared input component.

## Best solution

Expose a model-filter callback through the chat widget view/input options, apply it consistently to the input's selectable model pool, and have the inline-chat consumer supply its tool-calling requirement. Preserve the existing session-type, mode, visibility, and hidden-model filtering behavior.
