# Issue #348237 — Agent Host can silently orphan provider-initiated work and hang client tools

[https://github.com/microsoft/vscode/issues/348237](https://github.com/microsoft/vscode/issues/348237)

## Summary

The reported lifecycle gap remains in current source: system-sourced SDK work without host provenance bypasses turn creation, while client tool handlers can still wait for results. Keep open; choosing a visible non-user lifecycle versus explicit rejection needs a maintainer decision.

## Change summary

Prevent provider-initiated follow-up work from losing responses and leaving client tool requests unresolved after a command turn ends.

## Best solution

Ensure independently executing provider work either acquires a correctly attributed host lifecycle or receives an explicit failure that settles its tool requests. Preserve suppression of genuine runtime context injections and do not present system-authored work as user input.
