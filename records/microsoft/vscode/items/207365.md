# Issue #207365 — Rendering paused for long line for performance reasons. This can be configured via `editor.stopRenderingLineAfter`.

[https://github.com/microsoft/vscode/issues/207365](https://github.com/microsoft/vscode/issues/207365)

## Summary

The warning remains incorrect on current main: it uses full model-line coordinates even though truncation is applied to individual rendered view lines, so wrapping can produce a warning when no content was actually omitted.

## Change summary

Show the long-line rendering warning only where `editor.stopRenderingLineAfter` has actually truncated visible content, including the unwrapped-line cutoff rather than normally rendered wrapped text.

## Best solution

Align the hover warning with actual rendered view-line overflow while preserving the long-line performance safeguard and the separate tokenization warning.
