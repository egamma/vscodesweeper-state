## Summary

Verified duplicate of #167921 — the exact same report that variable substitution (including `${command:pickProcess}`) runs before `preLaunchTask` in debug configurations. The canonical issue is open, labeled, and has team acknowledgment.

## Change summary

The `${command:pickProcess}` variable in a debug attach configuration resolves before `preLaunchTask` runs, so the process picker appears before the task has a chance to start the target process.
