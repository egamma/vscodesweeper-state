# Issue #128923 — Allow exact and excluded matches in fuzzy search

[https://github.com/microsoft/vscode/issues/128923](https://github.com/microsoft/vscode/issues/128923)

## Summary

Keep open: quoted contiguous matching is implemented, but minus-prefixed exclusion remains unsupported in current Quick Open. This accepted Backlog request has 22 upvotes; the related design issue is newer and does not qualify as a canonical for this re-reviewed item.

## Change summary

Allow fuzzy-search queries to require contiguous matches with quotes and exclude unwanted terms with a minus prefix.

The thread supports preserving literal leading-minus searches when there is no positive term, a lone minus, and quoted leading-minus text. - **Trace:**

  > prepareQuery in src/vs/base/common/fuzzyScorer.ts splits on spaces, recognizes quotes, and leaves minus-prefixed pieces as positive patterns. doScoreItemFuzzyMultiple requires every piece to match, establishing why exclusions are absent today. AnythingQuickAccessProvider.getFileSearchResults in src/vs/workbench/contrib/search/browser/anythingQuickAccess.ts retrieves candidates using the first piece and filters afterward; its result-limit fallback also uses the full original query, so candidate retrieval must be considered alongside scoring. Existing quote tests are in src/vs/base/test/common/fuzzyScorer.test.ts. Preserve unmodified-query ranking, configured file exclusions, quoted matching, and ordinary hyphenated filename searches; broader scoring alignment across other pickers is outside this request. - **Open decisions:**
