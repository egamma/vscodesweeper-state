# Issue #336426 — Agent customization migration view jitters and becomes temporarily empty while session runs

[https://github.com/microsoft/vscode/issues/336426](https://github.com/microsoft/vscode/issues/336426)

## Summary

The unnecessary refresh path remains on current main: migration recomputation applies and fully rebuilds the visible page even when the resulting candidates and destinations are unchanged. This team-authored bug should remain open for a focused update-suppression fix.

## Change summary

Keep the customization migration view stable when agent or harness notifications do not change its migration data.

## Best solution

Preserve the existing migration data while recomputation is pending and skip applying or rendering results that are equivalent to the currently displayed candidates and destination folders.
