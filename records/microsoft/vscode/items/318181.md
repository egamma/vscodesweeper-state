# Issue #318181 — Support for xAI SuperGrok/SuperGrok Heavy OAuth with BYOK.

[https://github.com/microsoft/vscode/issues/318181](https://github.com/microsoft/vscode/issues/318181)

## Summary

Keep this accepted Backlog request open: current xAI BYOK configuration accepts an API key but does not provide subscription OAuth sign-in or automatic token renewal. The request has 25 upvotes, and the related issues do not own this specific capability.

## Change summary

Support xAI subscription OAuth authentication and token renewal in the existing BYOK model-provider experience.

## Best solution

Provide a supported xAI sign-in and renewable credential lifecycle for BYOK without requiring users to repeatedly paste expiring tokens, while preserving API-key authentication and existing BYOK policy enforcement. Confirm the supported provider authorization contract and user-facing account-management scope before implementation.
