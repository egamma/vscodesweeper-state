# Issue #318181 — Support for xAI SuperGrok/SuperGrok Heavy OAuth with BYOK.

[https://github.com/microsoft/vscode/issues/318181](https://github.com/microsoft/vscode/issues/318181)

## Summary

Legitimate feature request that just earned its 20 community upvotes and was promoted to Backlog by the established process. Asks for OAuth token flow support in the BYOK model configuration, specifically for xAI endpoints. No reason to close — the community process validated it and it aligns with current BYOK work.

## Change summary

Support OAuth-based authentication (not just static API keys) for BYOK model providers like xAI, so tokens can be refreshed automatically instead of requiring manual replacement on expiry.

## Best solution

Extend the BYOK authentication layer to support OAuth flows (authorization code + token refresh) alongside static API keys. The reporter's proof-of-concept branch demonstrates feasibility using a loopback redirect server. Implementation would likely touch the model provider configuration and authentication infrastructure under the Copilot/chat extensions and platform auth services.
