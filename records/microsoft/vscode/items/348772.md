# Issue #348772 — Provide a supported request-purpose hint to language model providers across utility paths

[https://github.com/microsoft/vscode/issues/348772](https://github.com/microsoft/vscode/issues/348772)

## Summary

The supported provider-purpose contract remains missing: current source confirms the workbench-only private hint and its absence from Agent Host utility requests. Keep this open for API-owner consideration; related model-configuration requests do not cover the same contract.

## Change summary

Expose an optional, documented request-purpose hint consistently to language model providers across utility paths.

## Best solution

Have the language model API owners define the optional purpose contract and its compatibility semantics, then carry known purposes through both utility paths without changing model routing or user configuration.
