# Issue #331385 — Enabling External sessions fires 1000 root/sessionAdded events

[https://github.com/microsoft/vscode/issues/331385](https://github.com/microsoft/vscode/issues/331385)

## Summary

Team-authored performance/design discussion about the agent host protocol: enabling the external-sessions filter causes many `root/sessionAdded` notifications to be sent in quick succession, causing UI churn. Connor4312 already proposed a lighter fix (renderer-side debounce) over a protocol change; no fix has landed yet, so this stays open.

## Change summary

Toggling the 'external sessions' AgentHost config setting causes ~1000 `root/sessionAdded` notifications to fire in a burst, each triggering incremental UI updates/churn in the renderer.

## Best solution

Add a debounce/coalescing step on the renderer side where `root/sessionAdded` notifications are consumed (src/vs/platform/agentHost/browser/remoteAgentHostProtocolClient.ts dispatches these via `_onDidNotification`), rather than changing the wire protocol — as suggested by connor4312. Alternatively, move filtering into `listSessions` so a config change doesn't require replaying add/remove events for every session.
