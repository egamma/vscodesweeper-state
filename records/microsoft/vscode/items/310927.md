# Issue #310927 — Restart to Update not working on Mac

[https://github.com/microsoft/vscode/issues/310927](https://github.com/microsoft/vscode/issues/310927)

## Summary

Root cause is upstream in Squirrel.Mac/Electron: ShipIt stops applying updates after its log files rotate to the 100th file. Multiple users confirm this on macOS across stable and insiders. No fix exists in VS Code's codebase — it must come from Electron.

## Change summary

macOS auto-update silently fails: clicking 'Update Now' quits VS Code but does not apply the update or relaunch, because Squirrel.Mac's ShipIt helper breaks after 100 log rotations.

## Best solution

Track the upstream Electron fix at https://github.com/electron/electron/issues/52284. Once Electron ships a patched Squirrel.Mac, bump VS Code's Electron dependency. A possible interim workaround could be documented (deleting old ShipIt logs from ~/Library/Caches/com.microsoft.VSCode.ShipIt), or VS Code could proactively clean up stale ShipIt logs before triggering the update.
