Reasonable privacy-focused idea, but coding-time tracking (active-time measurement, per-language/workspace stats, status bar display) is exactly the kind of self-contained capability well served by extensions (WakaTime, Code Time, etc.) using existing APIs — no maintainer has weighed in, so this stays open rather than closing on a vision read alone.
