# Issue #191782 — Visual Studio Code installer fails to register file associations for supported file types

[https://github.com/microsoft/vscode/issues/191782](https://github.com/microsoft/vscode/issues/191782)

## Summary

A valid bug with an open fix PR (https://github.com/microsoft/vscode/pull/293033) that explicitly targets this issue — keeping open until that PR lands.

## Change summary

The Windows installer's 'Register Code as an editor for supported file types' option fails to properly register file associations under the Applications and Capabilities registry keys, preventing users from setting defaults via Windows Settings.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/293033 which registers supported file types under the Applications and Capabilities registry keys on Windows, fixing both the 'Open With' and standard-user default-app scenarios.
