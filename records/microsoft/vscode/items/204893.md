# Issue #204893 — Allow globally disabling extensions from withinn an untrusted workspace

[https://github.com/microsoft/vscode/issues/204893](https://github.com/microsoft/vscode/issues/204893)

## Summary

The requested affordance remains absent on current main: globally disabling an extension is supported by the enablement service in an untrusted workspace, but the Extensions UI only offers Disable when the extension is currently enabled. The existing empty-window workaround does not cover the central ask of managing it without leaving the untrusted workspace.

## Change summary

Offer the global Disable action for extensions automatically disabled by Workspace Trust.

## Best solution

Let the extension editor's global Disable action remain available for an installed extension in `DisabledByTrustRequirement` state, while retaining the existing `canChangeEnablement` restrictions and leaving workspace-scoped enablement behavior unchanged.
