# Issue #339451 — Integrated Browser blocks Encrypted Media on every page; videos won't play

[https://github.com/microsoft/vscode/issues/339451](https://github.com/microsoft/vscode/issues/339451)

## Summary

Likely an Electron/Chromium packaging limitation (no Widevine CDM bundled for VS Code's Electron build) rather than a bug in VS Code's own browserView code — I found no explicit encrypted-media handling or blocking logic in the integrated browser source, which is consistent with this being inherited upstream behavior; already assigned to a team member, so keeping open for their investigation.

## Change summary

The Integrated Browser's permission-check/webPreferences setup blocks the Encrypted Media Extensions API on every page, so DRM-protected video (YouTube, Instagram) won't play.

## Best solution

A maintainer needs to confirm whether VS Code's Electron build can register/bundle a Widevine CDM component for the integrated browser (as desktop Chrome does) — if that's not feasible for licensing/build reasons, document this as a known Integrated Browser limitation rather than attempting a code fix.
