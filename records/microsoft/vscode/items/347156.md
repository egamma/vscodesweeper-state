# Issue #347156 — Can't create worktree session in chat window

[https://github.com/microsoft/vscode/issues/347156](https://github.com/microsoft/vscode/issues/347156)

## Summary

Keep open: the referenced test plan establishes that chat windows support creating sessions, but the reported missing isolation controls remain unconfirmed in the current shared composer implementation. The report and linked test scenario provide enough context to retest; no verified fix or matching canonical was found.

## Change summary

The new-session composer in a chat window does not offer the worktree/branch picker.

## Best solution

Make supported branch and worktree choices available when creating a session in a chat window, with the same provider-dependent behavior as the main window and without changing another composer's draft.
