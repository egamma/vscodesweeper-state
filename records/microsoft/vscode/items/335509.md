# Issue #335509 — Built-in GitHub MCP server does not appear in Chat Customizations

[https://github.com/microsoft/vscode/issues/335509](https://github.com/microsoft/vscode/issues/335509)

## Summary

Correctly diagnosed architectural gap: the built-in GitHub MCP server is synthesized purely inside Agent Host's per-harness SDK config (Claude/Codex/Copilot) and never registered as an MCP collection in the standard `IMcpRegistry`/`IMcpWorkbenchService` that the Chat Customizations editor's MCP Servers tab reads from, so it structurally cannot appear there today.

## Change summary

Enabling the built-in GitHub MCP server doesn't make it visible or manageable in the Chat Customizations editor's MCP Servers tab.

## Best solution

Project Agent Host's built-in per-harness MCP servers (starting with `GITHUB_MCP_SERVER_NAME` in src/vs/platform/agentHost/node/shared/githubMcpServer.ts) into the Customizations editor's MCP data model — either as a synthetic MCP collection surfaced through `IMcpWorkbenchService`/`mcpListWidget.ts`, or as a new `ICustomizationItemProvider` source — so users can find and manage it alongside ordinary configured servers.

## Evidence

- **built-in server is harness-internal only:** src/vs/platform/agentHost/node/shared/githubMcpServer.ts defines `createGitHubMcpServerConfiguration`/`resolveGitHubMcpServerConfiguration`; it's consumed directly by claudeAgentSession.ts, codexAgent.ts, and copilotAgent.ts to inject the server into each SDK's own MCP config — never through the shared MCP registry.
- **MCP tab reads a different system:** src/vs/workbench/contrib/chat/browser/aiCustomization/mcpListWidget.ts sources its list from `IMcpWorkbenchService`/`mcpRegistry.collections` (workspace/user/extension-declared servers), which has no path for Agent Host's harness-injected servers.
- **spec hints at a related but distinct concept:** src/vs/sessions/AI_CUSTOMIZATIONS.md mentions 'MCP collection exclusions that do not hide host-published servers', and claudeSessionCustomizationDiscovery.ts's `createClaudeInternalMcpServerCustomization` models the GitHub MCP server as a *session-scoped* customization item, separate from the global editor's MCP tab.
