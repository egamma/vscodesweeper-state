# Issue #331102 — Tunnel Agent Host retries offline cached tunnels on every window focus

[https://github.com/microsoft/vscode/issues/331102](https://github.com/microsoft/vscode/issues/331102)

## Summary

Confirmed in source: `_resumeReconnects` (tunnelAgentHost.contribution.ts) clears any pause state and immediately retries every disconnected cached tunnel on focus, with no distinction between offline-host, auth, or exhausted-backoff pause reasons — `_pauseReconnect` takes a `reason` parameter but only records the address in a plain `Set<string>`, discarding the reason. An open PR (#331103) already targets exactly this fix, so the issue should stay open for that PR to land rather than being closed or auto-fixed here.

## Change summary

Focusing the VS Code window resumes reconnect attempts for every cached tunnel unconditionally, including tunnels paused because their host is confirmed offline, causing repeated futile connection attempts on each focus.

## Best solution

Land https://github.com/microsoft/vscode/pull/331103 ("tunnels: preserve reconnect pause reasons"), which should make `_resumeReconnects` skip tunnels paused for `hostOffline` (and similar non-recoverable-by-focus reasons) unless tunnel discovery has actually confirmed the host is back online.
