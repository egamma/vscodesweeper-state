# Issue #332328 — Copilot: Run Code Review: TypeError: Cannot read properties of undefined (reading 'files')

[https://github.com/microsoft/vscode/issues/332328](https://github.com/microsoft/vscode/issues/332328)

## Summary

Traced a real bug in current main: `github.copilot.chat.codeReview.run` is an internal command meant to be invoked programmatically with a `CodeReviewInput` argument, but unlike every sibling review command it has no `commandPalette` `when: false` entry, so it's exposed as "Chat: Run Code Review" and crashes with the exact reported TypeError when run with no argument.

## Change summary

Running "Chat: Run Code Review" from the Command Palette throws `TypeError: Cannot read properties of undefined (reading 'files')`.

## Best solution

Add a `commandPalette` menu entry with `"when": "false"` for `github.copilot.chat.codeReview.run` in extensions/copilot/package.json, matching all its sibling `github.copilot.chat.review.*` internal commands, so it can no longer be invoked directly by users without the required input.
