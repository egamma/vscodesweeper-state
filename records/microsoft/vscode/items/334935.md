# Issue #334935 — Markdown Editor: escaped dollar signs (\$, &#36;) disappear, and two prices in one paragraph render as inline math

[https://github.com/microsoft/vscode/issues/334935](https://github.com/microsoft/vscode/issues/334935)

## Summary

Credible, well-diagnosed bug in the built-in Markdown Editor's math rendering (micromark-extension-math has no closing-delimiter adjacency check, unlike the Markdown Preview's KaTeX plugin); the real fix lives in the private `@vscode/markdown-editor` package this extension depends on, which isn't in this checkout, so it stays open rather than closing or claiming a fix.

## Change summary

In the hybrid Markdown Editor, escaped/entity dollar signs (\$, &#36;, &dollar;) vanish and two dollar amounts in one paragraph get misparsed as inline math, unlike the correct behavior in Markdown Preview.

## Best solution

Fix in the `@vscode/markdown-editor` package (consumed via extensions/markdown-language-features/package.json, `@vscode/markdown-editor: ^0.0.2-99`): either add the same closing-delimiter adjacency guard the Preview's `@vscode/markdown-it-katex` uses, or honor escaped/entity dollar signs before micromark-extension-math tokenizes them, and/or wire `markdown.math.enabled` (currently only implemented in extensions/markdown-math) to this editor.
