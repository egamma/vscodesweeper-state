# Issue #334935 — Markdown Editor: escaped dollar signs (\$, &#36;) disappear, and two prices in one paragraph render as inline math

[https://github.com/microsoft/vscode/issues/334935](https://github.com/microsoft/vscode/issues/334935)

## Summary

Well-documented, reproducible rendering bug in the built-in hybrid Markdown Editor: escaped/entity dollar signs vanish and multi-price prose gets misparsed as inline math, while the plain Markdown Preview handles the same text correctly. Routing to the markdown area rather than closing.

## Change summary

In the WYSIWYG Markdown Editor, `\$`, `&#36;`, `&dollar;` disappear and two dollar amounts in one paragraph get wrongly rendered as inline KaTeX math.

## Best solution

Fix belongs in the `@vscode/markdown-editor` package (an external npm dependency, version `^0.0.2-95` per `extensions/markdown-language-features/package.json`) that bundles micromark + micromark-extension-math without the closing-delimiter adjacency guard the Preview's `@vscode/markdown-it-katex` renderer has; align its math tokenizer behavior with the Preview, or wire `markdown.math.enabled` into this editor as the reporter suggests.
