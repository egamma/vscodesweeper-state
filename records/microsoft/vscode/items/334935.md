# Issue #334935 — Markdown Editor: escaped dollar signs (\$, &#36;) disappear, and two prices in one paragraph render as inline math

[https://github.com/microsoft/vscode/issues/334935](https://github.com/microsoft/vscode/issues/334935)

## Summary

Well-diagnosed bug in the built-in Markdown Editor's math rendering, confirmed with --disable-extensions and cross-checked against the raw micromark tokenizer; routing to the markdown area since the underlying rendering code lives in the external @vscode/markdown-editor package this repo depends on, not in code present in this checkout.

## Change summary

In the WYSIWYG Markdown Editor, escaped/entity dollar signs (\$, &#36;, &dollar;) vanish and two dollar amounts in one paragraph get misrendered as inline KaTeX math, while the plain Markdown Preview handles the same file correctly.

## Best solution

Fix belongs in the `@vscode/markdown-editor` package (extensions/markdown-language-features depends on it via `@vscode/markdown-editor: ^0.0.2-90`): either drop/guard `micromark-extension-math`'s `singleDollarTextMath` to match the preview's closing-delimiter adjacency rule from `@vscode/markdown-it-katex`, or wire `markdown.math.enabled` into the editor so users can disable math there.
