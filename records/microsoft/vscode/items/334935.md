# Issue #334935 — Markdown Editor: escaped dollar signs (\$, &#36;) disappear, and two prices in one paragraph render as inline math

[https://github.com/microsoft/vscode/issues/334935](https://github.com/microsoft/vscode/issues/334935)

## Summary

Keep open: the adopted Markdown editor package still omits escaped characters and character references from its inline text construction and enables math tokenization unconditionally. Neither related report qualifies as a canonical duplicate for this re-reviewed issue.

## Change summary

Preserve literal dollar signs in the hybrid Markdown Editor and avoid interpreting ordinary price pairs as inline math.

## Best solution

Correct literal-character handling and currency-versus-math parsing in @vscode/markdown-editor, then adopt the corrected behavior in VS Code's hybrid editor. Preserve valid math rendering and the existing Markdown Preview behavior; disabling math alone would not resolve missing escaped characters.
