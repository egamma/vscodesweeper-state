# Issue #266654 — Emmet abbreviations not working when parent element contains inline style

[https://github.com/microsoft/vscode/issues/266654](https://github.com/microsoft/vscode/issues/266654)

## Summary

Still reproduces on main: when an HTML element has a `style` attribute, the emmet completion provider accesses `styleNode.value.start` without guarding against `value` being undefined, causing 'Cannot read properties of undefined (reading start)'.

## Change summary

Emmet abbreviations fail inside elements that have an inline style attribute because the completion provider does not guard against an undefined `value` on the style attribute node.

## Best solution

Guard `styleNode.value` access in `defaultCompletionProvider.ts` (line ~118) and `util.ts` `isStyleAttribute` (line ~714) against undefined before accessing `.start`/`.end`. A contributor has expressed interest in fixing this.
