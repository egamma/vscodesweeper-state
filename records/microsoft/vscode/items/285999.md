Team-authored bug report about a visual rendering glitch where markdown paragraphs starting with a link render the link on its own line instead of inline. No fix commit references this issue; keeping open and routing to the chat area.

## Change summary

When a markdown paragraph begins with a link, the link text is rendered on a separate line instead of inline with the rest of the paragraph.
