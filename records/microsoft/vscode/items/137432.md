[https://github.com/microsoft/vscode/issues/137432](https://github.com/microsoft/vscode/issues/137432)

## Summary

Current source still probes repository roots before applying exclusions, but it rejects exactly matched ignored repositories before opening them or requesting status. Ask for current settings and Git output to distinguish slow discovery on SSHFS from the reported unwanted repository opening.

## Change summary

Prevent automatic Git detection from scanning or opening an excluded repository on an SSHFS mount while retaining detection elsewhere.

## Best solution

Establish which Git command stalls and whether the resolved repository root matches git.ignoredRepositories. - **Current editor detection path:** extensions/git/src/model.ts:531–560 routes visible file editors through onDidChangeVisibleTextEditors to openRepository(path.dirname(uri.fsPath)). Neither files.exclude nor repositoryScanIgnoredFolders is consulted on this path.
- **Discovery precedes exclusion, but opening is guarded:** extensions/git/src/model.ts:600–629 resolves the repository root before calling shouldRepositoryBeIgnored. extensions/git/src/git.ts:510–524 invokes git rev-parse --show-toplevel during that resolution.
