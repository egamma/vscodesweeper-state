# Issue #137432 — Git - git.autoRepositoryDetection does not honour git.ignoredRepositories nor files.exclude

[https://github.com/microsoft/vscode/issues/137432](https://github.com/microsoft/vscode/issues/137432)

## Summary

Keep open: current Git discovery has separate folder-scan exclusions and checks ignored repository roots before opening them, but still accesses candidate directories before that check. The supplied reload-and-open-file steps suffice to retest the SSHFS problem; neither its reported SCM registration nor the multi-hour scan has been confirmed on current main.

## Change summary

Automatic Git discovery scans an excluded SSHFS repository and reportedly adds it to Source Control despite repository and file exclusions.

## Best solution

Establish which discovery operation accesses the excluded mount, then make repository exclusions effective for that automatic-discovery path while preserving detection elsewhere. Verify repository registration separately from filesystem traversal, and keep any wildcard or files.exclude contract expansion distinct from fixing exact repository exclusions.
