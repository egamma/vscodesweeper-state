# Issue #333759 — Linux: `editor.smoothScrolling` setting has no effect

[https://github.com/microsoft/vscode/issues/333759](https://github.com/microsoft/vscode/issues/333759)

## Summary

Real, traceable bug: the mouse-wheel physical/touchpad classifier that gates smooth scrolling multiplies incoming wheel deltas by the window zoom factor (Chrome-only compensation), and at fractional zoom factors this turns otherwise-integer physical-mouse deltas non-integer, so the classifier scores them as "not a physical mouse wheel" and `editor.smoothScrolling` silently never animates — a commenter independently confirmed the zoomLevel>1.3 threshold that matches this mechanism.

## Change summary

On Linux, `editor.smoothScrolling: true` has no visible effect — mouse-wheel scrolling still jumps line by line instead of animating.

## Best solution

In `MouseWheelClassifier.acceptStandardWheelEvent`/`_computeScore` (src/vs/base/browser/ui/scrollbar/scrollableElement.ts), decouple the zoom-factor compensation used for the modulo/acceleration check from the integer-ness check, or otherwise account for fractional zoom factors, so a physical mouse's constant-integer deltas are still classified correctly once scaled by a non-integer `pageZoomFactor`; verify against the reporter's zoomLevel>1.3 threshold.

## Evidence

- **gating logic:** src/vs/base/browser/ui/scrollbar/scrollableElement.ts:546-548 — smooth scrolling only applies `setScrollPositionSmooth` when `classifier.isPhysicalMouseWheel()` is true; otherwise it falls back to `setScrollPositionNow` (no animation).
- **zoom-factor multiplication:** scrollableElement.ts:107-117 `acceptStandardWheelEvent`: on Chrome (Electron is always Chromium) it feeds `e.deltaX * pageZoomFactor` / `e.deltaY * pageZoomFactor` into the classifier instead of the raw deltas.
- **integer check:** scrollableElement.ts:146-189 `_computeScore`/`_isAlmostInt`: non-integer deltas add +0.25 to the score, and a score > 0.5 means the source is classified as a touchpad, not a physical mouse wheel — a fractional `pageZoomFactor` (e.g. from a non-round window.zoomLevel) turns integer wheel steps non-integer here.
- **corroborating comment:** Sunlight-Rim reports smooth scrolling breaks specifically once window.zoomLevel > 1.3 and works again at zoomLevel 0.99 — consistent with the zoom-factor multiplication pushing deltas off-integer at higher, less "round" zoom factors.
