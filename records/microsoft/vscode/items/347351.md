# Issue #347351 — Agent Host BYOK bridge hardcodes 128-tool ceiling; no way for a provider to declare the model's real tool limit

[https://github.com/microsoft/vscode/issues/347351](https://github.com/microsoft/vscode/issues/347351)

## Summary

The provider-specific tool-limit gap remains on main. An existing numeric toolCalling capability provides a starting point, but its value is discarded before reaching the BYOK bridge; the newer tool-search regression does not supersede this request.

## Change summary

Allow BYOK providers to declare their model's maximum tool-definition count instead of always truncating requests at 128.

## Best solution

Honor provider-declared tool-definition limits end to end, preferably using the existing numeric capabilities.toolCalling contract, while retaining the conservative fallback for unspecified models. Coordinate provider-neutral tool search separately so large tool catalogs remain discoverable without requiring every definition on every request.
