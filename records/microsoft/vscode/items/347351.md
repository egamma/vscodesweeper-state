# Issue #347351 — Agent Host BYOK bridge hardcodes 128-tool ceiling; no way for a provider to declare the model's real tool limit

[https://github.com/microsoft/vscode/issues/347351](https://github.com/microsoft/vscode/issues/347351)

## Summary

Keep open: current source discards an already-supported numeric tool limit and unconditionally caps BYOK requests at 128. The existing API contract makes this a metadata-propagation defect, not necessarily a request for a new API.

## Change summary

Honor provider-declared per-request tool limits instead of imposing 128 tools on every Agent Host BYOK model.

## Best solution

Preserve the existing numeric capabilities.toolCalling contract through model metadata and the BYOK bridge, and honor it when limiting requests while retaining the existing fallback for undeclared limits. Treat BYOK tool-search support as complementary work rather than a replacement for respecting model limits.
