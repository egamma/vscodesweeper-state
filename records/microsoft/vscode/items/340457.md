## Summary

Thanks for the detailed report. On current main, `tryShowOnboarding()` is still called from the constructor at startupPage.ts:103 and checks `sentiment.hidden` at line 249, with no wait for extension registration. This matches the reporter's diagnosis. An open PR already references the issue.

## Change summary

The onboarding overlay ignores `chat.disableAIFeatures` when the value comes from an extension's configurationDefaults, because the gate runs before extensions are registered.

## Best solution
