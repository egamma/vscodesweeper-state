[https://github.com/microsoft/vscode/issues/306247](https://github.com/microsoft/vscode/issues/306247)

## Summary

Wildcard matching, domain-level approval, and a minimal approval-management UI already exist, but automatic consolidation of redundant stored rules and the requested Settings-editor experience remain unaddressed. Keep this open as a feature request focused on those remaining gaps; no verified canonical issue was found.

## Change summary

Reduce URL auto-approval settings clutter through broader approval patterns, easier management, and consolidation of redundant entries.

## Best solution

Build on the existing URL approval manager rather than introducing wildcard support again. Evaluate a discoverable cleanup or grouping experience that preserves rule ordering, explicit denials, and separate request/response permissions instead of treating every child rule as redundant.
