[https://github.com/microsoft/vscode/issues/258439](https://github.com/microsoft/vscode/issues/258439)

## Summary

The detached checkpoint hover remains source-reproducible on current main: transcript scrolling moves the focused action but neither dismisses nor repositions its managed hover. This team-authored bug should remain open for a bounded chat UI fix.

## Change summary
