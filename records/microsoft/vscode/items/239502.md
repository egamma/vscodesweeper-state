# Issue #239502 — Allow quotes in default link provider for source locations

[https://github.com/microsoft/vscode/issues/239502](https://github.com/microsoft/vscode/issues/239502)

## Summary

The requested quoted source-location format remains unsupported on main, and this Backlog request has 24 community upvotes. Keep it open for implementation in the output link detector.

## Change summary

Recognize quoted file paths followed by line and column numbers, such as `"/path/file.c":12:4`, as one navigable source link.

## Best solution

Add a dedicated quoted-path pattern to `OutputLinkComputer.createPatterns` that captures line and column numbers outside the closing quote, with coverage in the output link provider tests.

## Evidence

- **current source:** `src/vs/workbench/contrib/output/common/outputLinkComputer.ts` excludes single and double quotes from valid path characters, while its `:line:column` pattern requires those suffixes immediately after the captured path; therefore `"/path/file.c":12:4` links only the inner path.
- **existing tests:** `src/vs/workbench/contrib/output/test/browser/outputLinkProvider.test.ts` covers quoted paths and unquoted `:line:column` paths separately, but not line and column suffixes following a closing quote.
- **prior behavior decision:** Commit e9f90c2abc99e77f78174e5b990335123a3abb2b intentionally excluded quotes from path matches to fix https://github.com/microsoft/vscode/issues/206001, so supporting this format needs a distinct quoted-location pattern rather than reverting that protection.
