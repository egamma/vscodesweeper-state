# Issue #159029 — Merge editor accessibility improvements

[https://github.com/microsoft/vscode/issues/159029](https://github.com/microsoft/vscode/issues/159029)

## Summary

Partial progress has been made — an accessibility help dialog exists and merge editor commands are registered in the command palette — but the central ask of accessibility signals (audio cues) for resolved/unresolved conflict lines in the 3-way merge editor remains unimplemented. Keeping open as a valid accessibility feature request.

## Change summary

Improve merge editor accessibility with audio cues for conflict states, tab-stop on Accept Merge, and better ARIA labeling.

## Best solution

Implement AccessibilitySignal entries for merge conflict line states (resolved vs. unresolved) in the merge editor, similar to how diff editor audio cues work. The merge editor accessibility help provider already exists in `src/vs/workbench/contrib/mergeEditor/browser/mergeEditorAccessibilityHelp.ts`; the signals would need to be added in `src/vs/platform/accessibilitySignal/` and wired into the merge editor view. The tab-stop and ARIA label improvements are smaller follow-ups.
