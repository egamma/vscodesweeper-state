## Summary

Detailed, well-documented report of the built-in Git diff editor failing to resolve a `git:` URI on Windows, backed by internal extension logs; it matches the failure signature of the already-tracked issue https://github.com/microsoft/vscode/issues/297275 but the reporter explicitly shows it reproduces even without the drive-root workspace condition that issue is scoped to, so it isn't a clean duplicate — routing to the git area for a maintainer to confirm whether it's the same underlying regression or a distinct case.

## Change summary
