# Issue #190549 — Incorrect indentation when passing snippet string as argument in inline suggestions

[https://github.com/microsoft/vscode/issues/190549](https://github.com/microsoft/vscode/issues/190549)

## Summary

The placeholder-dependent indentation change remains reproducible from current source: accepting a snippet enables whitespace adjustment that neither its preview nor the plain-text path applies. Keep this accepted inline-completions bug open; the related extension PR removed tab stops as a workaround, not a core fix.

## Change summary

Accepting a multiline inline suggestion containing snippet placeholders adds indentation that is absent from the preview and from equivalent suggestions without placeholders.

## Best solution

Make accepted inline-completion snippets preserve the indentation displayed in their preview while retaining working tab stops. Keep ordinary snippet insertion semantics unchanged.
