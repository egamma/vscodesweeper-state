# Issue #191868 — Add a Settings to Opt Out for the Inlay Hints Click Automatic Populate

[https://github.com/microsoft/vscode/issues/191868](https://github.com/microsoft/vscode/issues/191868)

## Summary

A real gap remains on current main: users cannot disable double-click insertion without also hiding inlay hints. The Backlog milestone and maintainer agreement support keeping this request open.

## Change summary

Add an editor setting that prevents double-clicking an inlay hint from applying its text edits.

## Best solution

Add an `editor.inlayHints` option that disables text-edit acceptance while preserving visible hints, and use it to gate both the double-click handler and its hover instruction.

## Vision fit

- **Fit:** unclear
- **Reason:** Preventing accidental source edits improves core editor UX, but another narrowly scoped setting adds configuration complexity.
- **Evidence:** The durable workbench and core UX theme supports safer interactions, while the lean-default guardrail cautions against configuration sprawl.
