# Issue #191868 — Add a Settings to Opt Out for the Inlay Hints Click Automatic Populate

[https://github.com/microsoft/vscode/issues/191868](https://github.com/microsoft/vscode/issues/191868)

## Summary

Keep open: current source still applies provider-supplied edits on double-click, with no setting to disable insertion while retaining visible hints. The thread supports an editor-level control, and the verified related issues do not own this request.

## Change summary

Allow users to disable double-click insertion from inlay hints without hiding the hints.

## Best solution

Provide an editor-level control separating hint visibility from double-click acceptance, with hover guidance reflecting whether insertion is available. Settle the default behavior with the area maintainer before implementation.
