# Issue #204712 — Find in expanded text lines only (ignoring all collapsed lines)

[https://github.com/microsoft/vscode/issues/204712](https://github.com/microsoft/vscode/issues/204712)

## Summary

Keep this accepted editor-find request open: current Find settings do not exclude folded lines, and the source still searches them and unfolds regions when navigating to matches. The older request is closed, while the newer matching request cannot supersede this re-reviewed item.

## Change summary

Add an optional document Find mode that excludes collapsed lines and preserves folded regions during match navigation.

## Best solution

Provide an opt-in folded-line exclusion mode in the editor Find surface while preserving ordinary whole-document search by default. Keep this issue as the existing accepted tracking item and consolidate newer matching reports here.

Manually verify Ctrl+F and next/previous navigation in a document with nested folded regions; verify replacement behavior against the maintainer's chosen contract.
- **Behavior:**

  > Users fold unrelated code to keep it out of their current task, but document Find still includes hidden matches and unfolds those regions during navigation. An optional exclusion mode should search expanded document lines, including expanded lines outside the viewport, while leaving collapsed regions intact. Acceptance should cover match counts, next/previous navigation, nested folds, and unchanged default search behavior. Workspace Search is not required by this report.
- **Trace:**

  > FindModelBoundToEditorModel._findMatches in src/vs/editor/contrib/find/browser/findModel.ts derives text-model search ranges from explicit scopes, not folding visibility; _setCurrentFindMatch selects and reveals matches. FoldingController.revealCursor in src/vs/editor/contrib/folding/browser/folding.ts expands collapsed regions containing a selection, explaining the observed interaction. EditorFind in src/vs/editor/common/config/editorOptions.ts offers cursorMoveOnType and autoFindInSelection but neither delivers folded-line exclusion. Shared Find state and widget behavior live in findState.ts and findWidget.ts, and findModel.ts also handles replacement, leaving the replacement contract to be settled. Preserve ordinary cursor-driven unfolding outside the optional Find mode and do not extend this work to workspace Search without a separate decision. https://github.com/microsoft/vscode/issues/235358 was directed into this issue; https://github.com/microsoft/vscode/issues/324071 is a younger matching request.
- **Open decisions:**
  - Should folded-line exclusion be a per-search Find-widget toggle, a persistent editor setting, or both?
  - When exclusion is enabled, should Replace and Replace All also exclude collapsed lines?
