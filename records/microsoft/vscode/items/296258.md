# Issue #296258 — Copilot circumvents file exclusions

[https://github.com/microsoft/vscode/issues/296258](https://github.com/microsoft/vscode/issues/296258)

## Summary

Keep open for human security and product review: the terminal fallback was independently confirmed, and command approval does not enforce file exclusions. GitHub currently documents content exclusion as unsupported in Agent mode, so the remaining work is an exclusion-enforcement capability rather than a proven regression against a supported guarantee.

## Change summary

Prevent Copilot agents from accessing GitHub-excluded files through terminal commands after direct file access is blocked.

## Best solution

Establish an explicit agent-mode content-exclusion contract and enforce any promised boundary across file tools and terminal execution. Command-specific approval rules must not be presented as equivalent to excluded-file access protection.
