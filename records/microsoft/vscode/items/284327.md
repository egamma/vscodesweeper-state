# Issue #284327 — monaco editor should disable line-number manipulating API

[https://github.com/microsoft/vscode/issues/284327](https://github.com/microsoft/vscode/issues/284327)

## Summary

Still unfixed on main: the interactive window's input editor uses a plain CodeEditorWidget without overriding updateOptions to block line-number changes from extensions. The same pattern was fixed for comment editors in commit 2e461da9213 but never applied here.

## Change summary

Extensions like Vim can toggle line numbers in the interactive window input editor, causing visual glitches (line numbers too close to text).

## Best solution

Apply the same updateOptions override pattern used in SimpleCommentEditor (commit 2e461da9213) to the interactive window's input CodeEditorWidget, stripping lineNumbers from extension-initiated option updates.
