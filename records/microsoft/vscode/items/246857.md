# Issue #246857 — Markdown inside of CompletionItem documentation does not wrap text in code block

[https://github.com/microsoft/vscode/issues/246857](https://github.com/microsoft/vscode/issues/246857)

## Summary

Still reproduces on main: the suggest widget's markdown documentation renders code blocks with `white-space: pre` (no wrapping), while the hover widget uses `pre-wrap` — an inconsistency that causes long code blocks in CompletionItem docs to overflow without wrapping or scrollbar.

## Change summary

Markdown code blocks inside CompletionItem documentation do not wrap text, unlike the same content rendered in Hover.

## Best solution

Change the `white-space` for `.monaco-tokenized-source` inside suggest detail markdown docs from `pre` to `pre-wrap` (matching the hover widget), in both `src/vs/editor/contrib/suggest/browser/media/suggest.css` and `src/vs/workbench/services/suggest/browser/media/suggest.css`.
