# Issue #246857 — Markdown inside of CompletionItem documentation does not wrap text in code block

[https://github.com/microsoft/vscode/issues/246857](https://github.com/microsoft/vscode/issues/246857)

## Summary

The wrapping mismatch remains in current source: completion documentation explicitly prevents tokenized code blocks from wrapping, while hover code blocks wrap by default. Keep this issue open in its existing editor areas; the discussion independently confirms the clipping and explains why supplying detail is only a workaround.

## Change summary

Make fenced Markdown code blocks in completion documentation wrap without losing syntax highlighting or requiring a CompletionItem.detail field.

## Best solution

Completion documentation should display complete, syntax-highlighted code blocks at the available widget width, consistently with hover documentation and independently of whether detail is supplied. Address the bounded suggest-details rendering path rather than changing language-server output or global Markdown rendering.
