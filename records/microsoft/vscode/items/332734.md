# Issue #332734 — ScopedProgressIndicator stores whileStart and whileDelay swapped in showWhile

[https://github.com/microsoft/vscode/issues/332734](https://github.com/microsoft/vscode/issues/332734)

## Summary

Confirmed on main: ScopedProgressIndicator.showWhile constructs ProgressIndicatorState.While with whileStart and whileDelay swapped relative to the constructor's parameter order. Currently latent (the replay math is symmetric), but a fixing PR is already open, so this should stay open pending that PR landing rather than being closed now.

## Change summary

showWhile passes (delay, Date.now()) into a constructor expecting (whileStart, whileDelay), storing the two swapped.

## Best solution

Review and land the linked PR https://github.com/microsoft/vscode/pull/332735, which reorders the arguments at the `new ProgressIndicatorState.While(...)` call site in src/vs/workbench/services/progress/browser/progressIndicator.ts (~line 305) to match the constructor's declared `whileStart`, `whileDelay` order, plus the regression test it adds.
