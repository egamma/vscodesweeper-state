## Change summary

Keyboard-opening a commit's multi-file diff should focus readable diff content so screen readers announce lines during arrow-key navigation.

## Best solution

Verify focus transfer into a rendered text diff when opening changes from the Source Control Graph and reopening the editor from Open Editors. If focus still fails, resolve the multi-diff initialization or restoration timing without stealing focus from preserveFocus opens.
