# Issue #273732 — Terminal suggest hijacks listing files

[https://github.com/microsoft/vscode/issues/273732](https://github.com/microsoft/vscode/issues/273732)

## Summary

Keep open to investigate why aliases and commands disappear from terminal suggestions, allowing Enter to submit a filename instead of the existing `l` alias. Current main has additional suggestion-selection controls, but the supplied steps, settings, and logs suffice to retest; neither a concrete fix nor a qualifying canonical duplicate was established.

## Change summary

Terminal suggestions replace the `l` listing alias with a filename and execute it when Enter is pressed with runOnEnter set to always.

## Best solution

Restore reliable discovery and prioritization of the reporter's existing alias in the built-in terminal completion provider. Preserve the documented runOnEnter behavior rather than treating its default setting as a fix for missing completions.
