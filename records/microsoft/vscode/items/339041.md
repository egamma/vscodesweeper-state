# Issue #339041 — The `preserveInput` options are not working

[https://github.com/microsoft/vscode/issues/339041](https://github.com/microsoft/vscode/issues/339041)

## Summary

Traced to source: `QuickAccessController` in src/vs/platform/quickinput/browser/quickAccess.ts only remembers the typed filter value in `lastAcceptedPickerValues` inside the `picker.onDidAccept` listener (line ~231) — if the picker is dismissed without accepting (e.g. clicking away to blur it, as described), the typed text is never stored, so `preserveInput`'s `DefaultQuickAccessFilterValue.LAST` lookup comes back empty next time. This affects all three preserveInput settings (`search.quickAccess`, `workbench.commandPalette`, `workbench.quickOpen`) since they share this controller.

## Change summary

The `*.preserveInput` settings (quick open, command palette, quick text search) don't restore the last typed text if the quick pick was dismissed by losing focus instead of accepting an item.

## Best solution

In QuickAccessController.registerPickerListeners, also persist the current picker value into lastAcceptedPickerValues (or an equivalently-named map) on picker.onDidHide, not only onDidAccept, so a blurred/cancelled quick pick still preserves what was typed per the setting's own description ("the last typed input... should be restored").
