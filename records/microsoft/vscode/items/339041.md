# Issue #339041 — The `preserveInput` options are not working

[https://github.com/microsoft/vscode/issues/339041](https://github.com/microsoft/vscode/issues/339041)

## Summary

The reported clearing is explainable from current source: opening through the Command Center bypasses input restoration, and dismissing without accepting never saves the query. Keep this open to reconcile the behavior with the settings' promise to restore the last typed input.

## Change summary

Restore the previous typed query when reopening the top search control after dismissing it by clicking elsewhere, with preserveInput enabled.

## Best solution

Make Command Center reopening consistent with the documented preserve-input settings while retaining explicit-prefix behavior and existing defaults. Confirm whether preservation should include dismissed queries, since the shared provider contract currently specifies the last accepted query.
