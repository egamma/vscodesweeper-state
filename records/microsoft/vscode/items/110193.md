# Issue #110193 — Add option to hide the "suggestion window" when press key left or right [old pattern]

[https://github.com/microsoft/vscode/issues/110193](https://github.com/microsoft/vscode/issues/110193)

## Summary

Valid feature request for a built-in setting to dismiss the suggest widget on left/right arrow keys, reverting to pre-1.51 behavior. A keybinding workaround exists but no built-in setting has been added. Low traction (3 upvotes over 5+ years) and already labeled under-discussion — leaving open for the community process.

## Change summary

Request a built-in setting to dismiss the suggest widget when pressing left or right arrow keys, instead of refiltering completions at the new cursor position.

## Best solution

If this gains traction, add a setting like `editor.suggest.dismissOnCursorMove` that cancels completions on CursorChangeReason.Explicit in `_onCursorChange` (suggestModel.ts) instead of calling `_refilterCompletionItems`. Until then, the custom keybinding workaround from the comments is sufficient for the few users who want this.
