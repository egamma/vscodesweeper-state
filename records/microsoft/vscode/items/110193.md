# Issue #110193 — Add option to hide the "suggestion window" when press key left or right [old pattern]

[https://github.com/microsoft/vscode/issues/110193](https://github.com/microsoft/vscode/issues/110193)

## Summary

Keep open under discussion: current source still retains suggestions during horizontal cursor movement, and no dedicated setting restores the old behavior. The reporter accepted the custom-keybinding workaround but explicitly retained the settings request.

## Change summary

Provide an option to dismiss the suggestion widget when moving the cursor left or right, without disabling suggestions.

## Best solution

Resolve whether the suggest editor options should support dismissing suggestions on horizontal cursor movement while preserving normal cursor navigation. The existing hideSuggestWidget bindings remain a useful workaround, but they replace the arrow-key action rather than configuring suggestion persistence.
