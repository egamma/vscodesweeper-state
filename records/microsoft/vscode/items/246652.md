## Change summary

Diff-editor gutter and toolbar menu updates evaluate context rules after their scoped context key service has been disposed.

## Best solution

Ensure diff-editor teardown ends menu subscriptions and deferred updates before they can evaluate a disposed context scope, while preserving normal menu refreshes. Establish whether the gutter and toolbar failures share a lifecycle defect before consolidating this accepted diff-editor report into a generic toolbar issue.
