# Issue #201795 — Conflict between status bar items of different ext hosts

[https://github.com/microsoft/vscode/issues/201795](https://github.com/microsoft/vscode/issues/201795)

## Summary

Still reproduces on current main: the auto-generated status bar item ID uses a per-extension-host counter (`ID_GEN++`), so two extension hosts can produce colliding IDs. The linked fix PR #201796 is still open and unmerged. Keeping open as a valid debt item with an existing PR.

## Change summary

Status bar items created without an explicit `id` across different extension hosts can collide, causing items to merge unexpectedly.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/201796 which addresses this by preventing ID conflicts across extension hosts. The fix likely belongs in `src/vs/workbench/api/common/extHostStatusBar.ts` — the generated `_entryId` needs to incorporate the extension host identity or use a globally unique scheme.
