# Issue #347682 — Error toggling GitHub environment sharing in VS Code

[https://github.com/microsoft/vscode/issues/347682](https://github.com/microsoft/vscode/issues/347682)

## Summary

GitHub environment sharing still fails when probing an empty Windows removable drive returns UNKNOWN. Both commenters confirm that removing the empty drive letters restores sharing; this workaround does not resolve the underlying defect.

## Change summary

Allow GitHub environment sharing to start when Windows has empty removable-drive slots.

## Best solution

Make filesystem-root discovery tolerate empty removable drives without requiring Windows drive-letter changes. Preserve reporting of genuine filesystem failures and the exclusion of network-backed drives.
