# Issue #347682 — Error toggling GitHub environment sharing in VS Code

[https://github.com/microsoft/vscode/issues/347682](https://github.com/microsoft/vscode/issues/347682)

## Summary

Keep open: current source lets an UNKNOWN stat failure on an empty Windows drive abort GitHub environment sharing entirely. The reported failure matches this path; no verified fix or canonical duplicate was established.

## Change summary

Allow GitHub environment sharing to start when Windows exposes removable-drive letters without inserted media.

## Best solution

Recognize unavailable removable drives during filesystem-root discovery without preventing sharing of usable local drives. Preserve network-drive exclusions and explicit reporting of unrelated filesystem failures.
