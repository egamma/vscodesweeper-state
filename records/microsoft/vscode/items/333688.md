# Issue #333688 — Fish stay on after turning off aquarium

[https://github.com/microsoft/vscode/issues/333688](https://github.com/microsoft/vscode/issues/333688)

## Summary

Confirmed on current main: unchecking Aquarium hides only its toggle while leaving the active overlay and fish running. This team-authored issue should remain open for a bounded state-management fix and regression test.

## Change summary

Unchecking Aquarium from the Agents window context menu should turn off the active aquarium instead of only hiding its toggle.

## Best solution

When the Aquarium context-menu item is unchecked, stop the active aquarium and persist its disabled state while hiding the action; showing the action again should not unexpectedly restart the aquarium.
