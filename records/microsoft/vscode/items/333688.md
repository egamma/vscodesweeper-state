# Issue #333688 — Fish stay on after turning off aquarium

[https://github.com/microsoft/vscode/issues/333688](https://github.com/microsoft/vscode/issues/333688)

## Summary

Real, confirmed bug in the new aquarium easter egg: hiding the aquarium via the context menu only hides the toggle button, it doesn't actually deactivate the fish overlay. A MEMBER's AI verification confirmed the repro on current main, and I traced the same gap in the source.

## Change summary

Unchecking 'Aquarium' from the context menu hides the toggle button but leaves the fish swimming and the water overlay active.

## Best solution

In src/vs/sessions/contrib/aquarium/browser/aquariumOverlay.ts, make reconcileActivation()/setActionVisible() treat action-visibility the same as host-visibility: when the action is toggled off, deactivate any active aquarium (and require actionVisible in the activation condition) so hiding the toggle also tears down the running aquarium.
