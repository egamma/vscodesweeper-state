# Issue #332261 — Change Tab Display Size is unavailable in read-only/diff editors

[https://github.com/microsoft/vscode/issues/332261](https://github.com/microsoft/vscode/issues/332261)

## Summary

Confirmed on main: showIndentationPicker() in editorStatus.ts blocks the entire indentation picker (including the non-mutating Change Tab Display Size action) whenever the active editor is read-only. An open PR already targets this exact fix and references closing this issue, so it should stay open until that PR lands.

## Change summary

The tab-size/indentation picker in the status bar is entirely unavailable in read-only editors (e.g. Git diff views), even for actions like Change Tab Display Size that don't modify document content.

## Best solution

Land (or review) https://github.com/microsoft/vscode/pull/332304, which allows changing tab display size and other non-modifying view options in read-only editors while keeping actual mutating actions (indent-using-spaces/tabs, detect indentation) disabled or hidden.
