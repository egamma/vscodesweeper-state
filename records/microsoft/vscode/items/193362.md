## Summary

The requested owner-qualified emitter stack-frame names remain unsupported in the inspected source. Keep this team-authored Backlog request open; existing debugger customization provides the rendering mechanism, but not the emitter ownership information.

## Change summary

Make emitter fire stack frames identify the owning class and event field instead of displaying only Emitter.fire.

Provide useful owner-and-event descriptions for emitters during source debugging without changing event delivery or imposing unnecessary runtime and retention costs. Settle the development-only contract and initial adoption scope before implementation.
