# Issue #335982 — Terminal replay can drop acknowledgements for live output and leave the PTY paused

[https://github.com/microsoft/vscode/issues/335982](https://github.com/microsoft/vscode/issues/335982)

## Summary

The replay/live-output acknowledgement race remains present in current main and can leave an individual terminal permanently paused. Route this unlabeled report to terminal; the class-level defect is established even though its connection to the original interactive incident remains unconfirmed.

## Change summary

Prevent live terminal output processed during replay from losing flow-control acknowledgements and permanently blocking the PTY.

## Best solution

Ensure replay and concurrent live output retain their order while every live-output acknowledgement reaches the host exactly once. Cover the same-task write-callback race with a deterministic terminal regression test, preserving suppression of replay-only acknowledgements.
