# Issue #329440 — Agent Host session refresh stalls while remote exporter drains oversized events

[https://github.com/microsoft/vscode/issues/329440](https://github.com/microsoft/vscode/issues/329440)

## Summary

Team-authored bug with a detailed, code-verified root cause (session teardown blocking on remote-exporter HTTP 413 backoff loop) and two independent production incidents; a fix is already in progress as an open PR in the separate copilot-agent-runtime repo, so this stays open pending that merge rather than closing.

## Change summary

Restoring a large Copilot CLI session and then triggering a structural config change (tools/plugins/MCP/roots) causes session refresh to hang for 10+ minutes because runtime destruction synchronously waits on the remote session exporter to drain a huge backlog through repeated HTTP 413 responses.

## Best solution

Land github/copilot-agent-runtime#15087 (the linearizable Open→Closing→Sealed→Released teardown redesign that decouples session release from network export drain), then verify on Agent Host that resumeSession no longer blocks on export; also consider the suggested defensive timeout in Agent Host so a stuck refresh surfaces a terminal error instead of hanging indefinitely.
