# Issue #287159 — Git - checkout picker should display git worktree information

[https://github.com/microsoft/vscode/issues/287159](https://github.com/microsoft/vscode/issues/287159)

## Summary

Team-authored feature request (MEMBER). The checkout picker currently shows branch/tag names with ahead/behind and commit date info but does not indicate which worktree a branch is checked out in. Worktree infrastructure exists in the git extension but is not surfaced in the checkout picker items. Keeping open per team-member policy.

## Change summary

Display git worktree information (e.g. which worktree a branch is checked out in) in the checkout branch/tag picker.

## Best solution

Enhance `BranchItem`/`CheckoutItem` in `extensions/git/src/commands.ts` to query worktree state and display the worktree path or name in the description/detail of branches that are checked out in a worktree. The worktree data is already available via `repository.getWorktrees()` / `repository.getWorktreeDetails()` — it just needs to be cross-referenced with branch refs shown in `createCheckoutItems()`.
