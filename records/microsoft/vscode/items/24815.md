# Issue #24815 — Allow to reset “Don't Show Again” preference

[https://github.com/microsoft/vscode/issues/24815](https://github.com/microsoft/vscode/issues/24815)

## Summary

The requested reset capability remains absent on current main. This accepted Backlog request has 50 community upvotes and should remain open.

## Change summary

Provide an in-product way to inspect and reset preferences created by “Don't Show Again” notification actions.

## Best solution

Add notification-preference management under the workbench notifications area, backed by a registry that can enumerate and clear `neverShowAgain` storage keys across application, profile, and workspace scopes.
