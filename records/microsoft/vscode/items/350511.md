# Issue #350511 — New Chat should open in chat editor when using setting `"chat.viewSessions.openChatIn": "editorArea"`

[https://github.com/microsoft/vscode/issues/350511](https://github.com/microsoft/vscode/issues/350511)

## Summary

Keep open: current source deliberately starts the new-chat composer in the Chat view and moves the chat into an editor only after its first request. The team-authored request asks for an earlier transition that existing session-opening behavior does not provide.

## Change summary

Make the Chat view's plus button immediately open a new chat editor when chat.viewSessions.openChatIn is editorArea.

## Best solution

Make new-chat creation consistent with the selected editor-area destination, including the empty composer rather than only the submitted session. Preserve existing chatPanel and chatArea behavior and decide whether the same destination rule should apply to other New Chat entry points.
