# Issue #229940 — Source Control Graph - "Go to file" opens full path and does not update explorer

[https://github.com/microsoft/vscode/issues/229940](https://github.com/microsoft/vscode/issues/229940)

## Summary

Keep open in the Backlog: current main fixes the full-path editor title but intentionally opens the historical, read-only resource, so the requested Explorer synchronization or editable-file navigation remains unresolved.

## Change summary

Make the SCM graph multi-diff action navigate to a normally named file that can be located in Explorer, rather than only opening the historical read-only resource.

## Best solution

Define separate actions for opening the historical revision and navigating to the current workspace file, preserving the former while letting the latter reveal the editable resource in Explorer. Coordinate this with https://github.com/microsoft/vscode/issues/250938, which tracks the editable-file action but does not fully cover Explorer synchronization.
