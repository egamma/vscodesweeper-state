# Issue #308818 — Persistent prompts about starting and trusting MCP servers

[https://github.com/microsoft/vscode/issues/308818](https://github.com/microsoft/vscode/issues/308818)

## Summary

The discussion narrowed this to duplicate manual and Cursor-discovered configurations, with removing those configurations stopping the prompts. Subsequently landed collision handling addresses the reported same-name duplication even when the server arguments differ.

## Change summary

Deduplicate MCP servers discovered through configuration files and extensions so overlapping definitions do not produce redundant startup interactions.

## Best solution

Treat the reported same-name deduplication request as implemented by commit 20cf0c727688e6e05e8acec03c8f27ec28ebc30f, keeping chat.mcp.collisionBehavior at its default disable value. Preserve independent trust checks for the selected configuration; deduplication must not implicitly transfer extension trust to manually configured commands.
