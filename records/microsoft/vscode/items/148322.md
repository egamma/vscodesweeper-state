# Issue #148322 — Git - Out of workspace diff does not survive a reload

[https://github.com/microsoft/vscode/issues/148322](https://github.com/microsoft/vscode/issues/148322)

## Summary

The restoration gap remains in current source: Git resource reads discover missing repositories only in empty or Agents windows, not ordinary workspaces. Keep this correctly routed issue open for a bounded Git provider fix.

## Change summary

Restore a Git diff for a file outside the workspace after reloading, without requiring that file to be open separately.

## Best solution

Allow restored Git resources to resolve their repository in an ordinary workspace when it has not yet been discovered. Preserve repository trust checks and existing repository-opening policies.
