# Issue #148322 — Git - Out of workspace diff does not survive a reload

[https://github.com/microsoft/vscode/issues/148322](https://github.com/microsoft/vscode/issues/148322)

## Summary

The bug likely still reproduces on main. The `getOrOpenRepository` fix (f06f86226ba) only discovers repositories in empty/agent-sessions windows, not when workspace folders are open but the diffed file lives outside them. The original scenario — a file outside the workspace with folders open — remains unhandled.

## Change summary

Git diff editors for files outside the workspace fail to restore after a window reload because the repository is not discovered on startup.

## Best solution

Extend `getOrOpenRepository` in `extensions/git/src/fileSystemProvider.ts` to also attempt repository discovery when the file's repository is not among the already-open ones, even when workspace folders are present — as joaomoreno's comment suggested. The FS provider's async methods should discover the repository on demand rather than assuming it is already in the model.
