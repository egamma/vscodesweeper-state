# Issue #336405 — No sound is played in "About" dialog or when closing not saved file since 1.136

[https://github.com/microsoft/vscode/issues/336405](https://github.com/microsoft/vscode/issues/336405)

## Summary

A fresh, well-diagnosed regression: VS Code delegates message-box display entirely to Electron's native `dialog.showMessageBox` (no custom beep/sound code exists in this repo), and the reporter bisected the missing system sound to the Electron 42.8.1→42.10.0 bump between 1.135.0 and 1.136.0, plausibly a backported GTK message-box fix (electron/electron#52410). This is an upstream Electron/Linux-desktop-integration defect, not a VS Code core bug, so it should stay open and tracked against Electron rather than closed.

## Change summary

On Linux/Wayland, no system sound plays for the About dialog or the unsaved-changes confirmation dialog since 1.136.0, a regression from 1.135.0.

## Best solution

Track this as an upstream Electron issue: file/link the report against electron/electron (or the vscode Electron issue tracker) referencing electron/electron#52410, and consider filing a regression report with Electron so the sound behavior on GTK/Wayland message boxes is restored; VS Code's own `dialogMainService.ts` needs no change since it only calls the native API.
