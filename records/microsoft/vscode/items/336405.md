# Issue #336405 — No sound is played in "About" dialog or when closing not saved file since 1.136

[https://github.com/microsoft/vscode/issues/336405](https://github.com/microsoft/vscode/issues/336405)

## Summary

Well-diagnosed regression traced by the reporter to the Electron bump between 1.135.0 and 1.136.0 (Electron 42.8.1 → 42.10.0, Chromium unchanged); the root cause is in Electron's native message-box/beep handling, not VS Code's own code, so this should stay open and tracked as upstream rather than closed.

## Change summary

System sound no longer plays for the About dialog or the 'Save changes?' prompt on Linux/Wayland since VS Code 1.136.0.

## Best solution

Track as an Electron regression; confirm whether it still reproduces once VS Code ships with a newer Electron (main's .npmrc already pins 43.6.0, past the reporter's 42.10.0), and if so file/link the issue upstream at electron/electron.
