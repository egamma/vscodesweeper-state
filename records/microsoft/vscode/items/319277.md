# Issue #319277 — BYOK Azure provider: Support Anthropic-format deployments on Azure AI Services

[https://github.com/microsoft/vscode/issues/319277](https://github.com/microsoft/vscode/issues/319277)

## Summary

Valid feature request: the BYOK Azure provider's `resolveAzureUrl` only recognizes three Azure hostnames and speaks only OpenAI chat-completions format; Claude models deployed via Azure AI Foundry (`services.ai.azure.com/anthropic/v1/messages`) are unsupported. No work toward this exists on current main.

## Change summary

Support Anthropic-format Claude deployments on Azure AI Services (services.ai.azure.com) in the BYOK Azure provider.

## Best solution

Extend `resolveAzureUrl` in `extensions/copilot/src/extension/byok/vscode-node/azureProvider.ts` to recognize `services.ai.azure.com` hosts, and when the URL targets an `/anthropic/` path, delegate to the existing Anthropic streaming logic in `AnthropicLMProvider` rather than the OpenAI chat-completions path. The reporter's suggested approach of reusing the Anthropic SDK client with a custom `baseURL` is a reasonable starting point.
