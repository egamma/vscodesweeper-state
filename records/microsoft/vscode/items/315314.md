# Issue #315314 — Hydrating large chat session items block renderer during startup

[https://github.com/microsoft/vscode/issues/315314](https://github.com/microsoft/vscode/issues/315314)

## Summary

Still open — a team member (connor4312) identified the root cause as large chat session item hydration blocking the renderer at startup, not the MCP registry fetch. Two fix PRs (#315421, #321992) were closed without merging, and no fixing commit references this issue. The perf regression remains on current main.

## Change summary

Hydrating large chat session items blocks the renderer during startup, causing 1–2 second UI freezes.

## Best solution

Defer or chunk the hydration of large chat session items (especially those with binary content) so they don't block the renderer's critical startup path. The fix likely lives in `src/vs/workbench/api/browser/mainThreadChatSessions.ts` around the session item resolution/hydration code that connor4312 identified.
