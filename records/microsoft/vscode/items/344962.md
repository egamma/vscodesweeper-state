# Issue #344962 — MCP password inputs are lost on other machines with Settings Sync: encrypted `mcpInputs` is synced but its key is machine-local

[https://github.com/microsoft/vscode/issues/344962](https://github.com/microsoft/vscode/issues/344962)

## Summary

The reported storage mismatch remains in current main: Settings Sync transfers encrypted MCP inputs without their machine-local encryption key. Keep this credential-storage issue open for human review; the supplied reproduction steps are sufficient.

## Change summary

Preserve each machine's saved MCP password inputs when Settings Sync exchanges user-profile state.

## Best solution

Keep MCP password inputs encrypted and machine-local so incoming synced state cannot replace them, while preserving the existing synchronization of non-secret inputs. Account for existing mixed mcpInputs records without syncing encryption keys or weakening password protection.
