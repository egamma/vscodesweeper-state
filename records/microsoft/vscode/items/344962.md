# Issue #344962 — MCP password inputs are lost on other machines with Settings Sync: encrypted `mcpInputs` is synced but its key is machine-local

[https://github.com/microsoft/vscode/issues/344962](https://github.com/microsoft/vscode/issues/344962)

## Summary

Keep open: current source still syncs MCP password ciphertext while retaining its encryption key locally, allowing other machines to overwrite saved inputs with undecryptable data.

## Change summary

Prevent Settings Sync from invalidating machine-local MCP password inputs.

## Best solution

Keep saved password inputs local to each machine while preserving synchronization of non-secret inputs. Preserve recoverable existing secrets during the storage transition and cover repeated two-machine sync cycles.
