# Issue #206424 — Double clicking on outline entry sometimes results in jumping to another item

## Summary

Keep open: the linked PR added a timing-based workaround, but it does not establish that the reported navigation race is fully resolved. The supplied double-click and Follow Cursor scenario is sufficient to retest; current source differs from the original report.

## Change summary

Double-clicking an Outline symbol can navigate to or focus a different symbol when Follow Cursor reacts during the interaction.

## Best solution

Ensure an Outline double-click consistently acts on the symbol the user clicked, without Follow Cursor redirecting the interaction. First reproduce against the existing 150 ms workaround and determine whether a remaining race requires an Outline-local or shared list-navigation correction.
