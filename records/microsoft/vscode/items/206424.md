# Issue #206424 — Double clicking on outline entry sometimes results in jumping to another item

[https://github.com/microsoft/vscode/issues/206424](https://github.com/microsoft/vscode/issues/206424)

## Summary

A workaround was merged in commit 1d5c97906e0 (timeout-based debounce for single-click reveals), but the commit only formally fixes #206426, referencing this issue with 're' — the underlying tree/list double-click event issue noted in the comments may remain unresolved. Keeping open per team-authored item rules (no closing reference to this issue number).

## Change summary

Double-clicking an outline entry causes the cursor to jump to that symbol, which triggers 'follow cursor' to refocus a different outline entry before the double-click handler fires.

## Best solution

The timeout workaround in outlinePane.ts addresses the symptom but the root cause — the tree widget firing the open event twice on double-click (as noted by joaomoreno: `onMouseDblClick` not checking `openOnSingleClick`) — may still need a proper fix in the list/tree layer (`src/vs/platform/list/browser/listService.ts`).
