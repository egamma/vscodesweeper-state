# Issue #316980 — Markdown-mermaid themes do not apply to notebooks

[https://github.com/microsoft/vscode/issues/316980](https://github.com/microsoft/vscode/issues/316980)

## Summary

Keep open: the notebook Mermaid renderer still lacks a path for receiving the configured Mermaid theme, so it falls back to defaults. The existing notebook and mermaid labels correctly route this accepted, team-authored bug.

## Change summary

Notebook Mermaid diagrams ignore changes to markdown-mermaid.darkModeTheme.

## Best solution

Make notebook Mermaid diagrams honor the configured light and dark Mermaid themes, including updates to already-rendered diagrams, while preserving Markdown preview behavior.

## Evidence

- **Reported trigger:** https://github.com/microsoft/vscode/issues/316980 provides concrete steps: render a Mermaid diagram in notebook Markdown, change markdown-mermaid.darkModeTheme, and observe that the diagram does not adopt it. There are no comments or linked fixing PRs in the supplied context.
- **Notebook configuration gap:** extensions/mermaid-markdown-features/preview-src/notebook/index.ts initializes Mermaid through loadExtensionConfig() at activation and on Markdown rendering. Its activate() function registers Mermaid syntax but neither injects configuration nor subscribes to configuration messages.
- **Default fallback:** extensions/mermaid-markdown-features/preview-src/shared/index.ts implements loadExtensionConfig() by looking for document.getElementById('markdown-mermaid'). Without that element it returns defaultExtensionConfig, whose darkModeTheme and lightModeTheme are both 'vscode'. Refreshing VsCodeMermaidThemeTracker therefore does not recover the user's configured Mermaid theme.
- **Preview-only delivery and refresh:** extensions/mermaid-markdown-features/src/markdownMermaid/config.ts reads the workspace settings and serializes them through injectMermaidConfig(). In src/extension.ts that injection is installed in the Markdown preview plugin; the configuration-change listener invokes markdown.preview.refresh, with no notebook configuration-delivery or refresh counterpart.
- **Current capability does not cover the report:** preview-src/shared/vsCodeTheme.ts supports explicit Mermaid themes as well as VS Code-derived colors, and the notebook renderer refreshes theme variables before rendering. Those capabilities do not deliver markdown-mermaid.darkModeTheme settings into the notebook renderer.
