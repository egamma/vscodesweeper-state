The report describes TypeScript server performance issues (hangs/crashes) when opening a JS file without a jsconfig in a large project over Remote SSH, but lacks a minimal reproduction and specific details about the project structure that would let anyone investigate.

## Change summary

TypeScript language service hangs and crashes when parsing JavaScript files in a large project folder without a jsconfig.json, with the inferred project loading the entire directory tree.

## Best solution

Needs clarification on the project size/structure and whether adding a jsconfig.json with appropriate `exclude` patterns resolves the issue. If the root cause is tsserver's inferred-project behavior on large directories, this may be an upstream TypeScript issue to file at microsoft/TypeScript. The VS Code TS extension's inferred project config (src/vs/../../extensions/typescript-language-features/src/tsconfig.ts) passes through to tsserver — VS Code itself has limited control over how tsserver scans inferred projects.
