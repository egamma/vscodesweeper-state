# Issue #163396 — Suggestion preview (ghost text) disappears with incomplete trigger

[https://github.com/microsoft/vscode/issues/163396](https://github.com/microsoft/vscode/issues/163396)

## Summary

The reported preview gap remains traceable in current source: incomplete-completion retriggers retain the suggest widget but leave its preview using a stale replacement range until new results arrive. Keep this open in inline-completions; no verified older canonical owns the same symptom.

## Change summary

Keep valid suggestion-preview ghost text visible while an incomplete completion provider refreshes after further typing.

## Best solution

Keep the preview synchronized with the still-selected suggestion and current text during incomplete-provider refreshes, without retaining previews that no longer match. Cover the pending-provider interval in the suggest widget model tests.
