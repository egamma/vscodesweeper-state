# Issue #3742 — Add setting to automatically hide the side bar

[https://github.com/microsoft/vscode/issues/3742](https://github.com/microsoft/vscode/issues/3742)

## Summary

This remains the canonical, strongly supported request for an automatically dismissing or overlay Primary Side Bar. Current main provides manual toggling and a narrower Activity Bar setting, but not the requested behavior.

## Change summary

Add a configurable mode that automatically hides the Primary Side Bar after focus leaves it, preferably displaying it as an overlay without resizing editors.

## Best solution

Implement a coherent auto-hide or overlay mode in the workbench layout and Primary Side Bar, covering activation by click or hover and dismissal on editor focus without shifting editor content.
