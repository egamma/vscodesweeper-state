# Issue #259972 — Show Built-in Tools at the bottom, collapsed or in a seperate tab

[https://github.com/microsoft/vscode/issues/259972](https://github.com/microsoft/vscode/issues/259972)

## Summary

The remaining request is still applicable on current main: Built-in Tools is the first section and starts expanded, while Connected Sources and Extension Tools follow below it. The preferred hierarchy is a product choice, so this should remain open under discussion.

## Change summary

Prioritize custom and MCP tools in the tools-management view by collapsing or moving Built-in Tools, or separating the categories into tabs.

## Best solution

Make connected and extension-provided tools reachable in the initial viewport without requiring users to collapse or scroll past Built-in Tools, while keeping built-in tools readily discoverable and keyboard accessible.
