# Issue #316888 — GitHub Copilot conversation compaction corrupts Markdown export

[https://github.com/microsoft/vscode/issues/316888](https://github.com/microsoft/vscode/issues/316888)

## Summary

The corruption remains source-reproducible on current main: the completed compaction task and subsequent assistant Markdown are exported as adjacent inline segments with no separator.

## Change summary

Copy All concatenates the completed conversation-compaction notice directly with the following assistant response in exported Markdown.

## Best solution

Keep task/status content structurally separate from subsequent response Markdown in the chat response text representation, with regression coverage for a completed progress task followed by Markdown.
