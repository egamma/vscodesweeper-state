# Issue #328033 — disable-model-invocation dosen't work

[https://github.com/microsoft/vscode/issues/328033](https://github.com/microsoft/vscode/issues/328033)

## Summary

Current main can invoke a model-disabled custom agent: explicit subagent allow-lists bypass the visibility flag, and the invocation path performs no final visibility check.

## Change summary

Ensure agents with `disable-model-invocation: true` cannot be selected or executed by the `runSubagent` model tool.

## Best solution

Require model-invocable visibility both when constructing the available-agent list and when resolving `runSubagent` requests, while preserving direct user invocation.
