# Issue #328033 — disable-model-invocation dosen't work

[https://github.com/microsoft/vscode/issues/328033](https://github.com/microsoft/vscode/issues/328033)

## Summary

The defect remains source-reproducible on current main: `disable-model-invocation` is parsed correctly, but explicit subagent allowlists can override it during prompt construction and `runSubagent` does not enforce model invocability at dispatch. This should remain open and be routed to the custom-agent/subagent owners.

## Change summary

Prevent models from invoking custom agents whose frontmatter sets `disable-model-invocation: true`, including explicit-name, current-agent, and allowlisted invocation paths.

## Best solution

Treat model invocability as a mandatory runtime constraint, not only a prompt-visibility hint: disabled agents must be excluded from every generated subagent list and rejected by `runSubagent`, while remaining manually selectable by users.
