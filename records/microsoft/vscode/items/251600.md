# Issue #251600 — Invalid string length

[https://github.com/microsoft/vscode/issues/251600](https://github.com/microsoft/vscode/issues/251600)

## Summary

The failure remains possible on main: repeated small edits append indefinitely to one internal string until the JavaScript engine rejects its length. The existing editor-textbuffer routing is appropriate, so this should remain open.

## Change summary

Repeated editor edits can exhaust the piece tree's single change-buffer string and throw `RangeError: Invalid string length`.

## Best solution

Bound or rotate the mutable change buffer in `PieceTreeBase.createNewPieces` while preserving pieces that reference earlier buffers, with a configurable low-limit regression test covering repeated small edits.
