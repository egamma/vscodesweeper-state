# Issue #331477 — Agents window: disable-model-invocation: true prevents manual slash invocation of Agent Skills

[https://github.com/microsoft/vscode/issues/331477](https://github.com/microsoft/vscode/issues/331477)

## Summary

The bug remains actionable and is independently reproduced on Insiders: the Agents window advertises user-invocable skills but omits their instructions when `disable-model-invocation: true`. The closed https://github.com/microsoft/vscode/issues/333700 points back here as the canonical report rather than replacing it.

## Change summary

Manual slash invocation in the Agents window should load a skill even when automatic model invocation is disabled.

## Best solution

Keep model availability and explicit user invocation as separate capabilities in the Agent Host customization pipeline, and ensure slash-command dispatch resolves user-invocable skills regardless of `disable-model-invocation`.
