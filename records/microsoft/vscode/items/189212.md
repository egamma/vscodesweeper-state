- **Proposed comment:**

  > Thanks for the sample and workaround. Editor find-and-replace uses JavaScript regular expressions: \W includes Malayalam characters, so `([^e\W])-"` excludes them. The negated `[^e\p{L}]` class also excludes letters rather than selecting them. For the supplied text, try `([\p{L}\p{M}])-"` with replacement `$1 -"`; this includes letters and combining marks. Keeping this discussion open to distinguish clearer regex guidance from a change to word-character semantics.
