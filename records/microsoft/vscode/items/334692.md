# Issue #334692 — Reveal for comments just opens the line/file, does not reveal the comments

[https://github.com/microsoft/vscode/issues/334692](https://github.com/microsoft/vscode/issues/334692)

## Summary

The member-authored report provides a credible visual reproduction, and current main still routes Reveal through a path where opening the editor and expanding the matching comment widget are separate steps. The exact failure remains undiagnosed, so this should stay open for a focused reproduction and trace.

## Change summary

The Agents Window comment banner's Reveal action opens the affected file and selects the line but does not display the associated PR comments.

## Best solution

Make comment reveal complete only after the target editor's feedback contribution has resolved the session, rendered the matching comment widget, and expanded it; cover the full banner-to-widget flow with a regression test.
