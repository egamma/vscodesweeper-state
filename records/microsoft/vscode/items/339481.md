# Issue #339481 — Add a dedicated link color token for hover/widget/tooltip content

[https://github.com/microsoft/vscode/issues/339481](https://github.com/microsoft/vscode/issues/339481)

## Summary

The requested hover-scoped link override remains missing: current editor and workbench hovers use global link colors despite independently configurable hover backgrounds. Keep this open as a feature request; no verified canonical or existing capability covers the central ask.

## Change summary

Allow theme authors to customize hover-content link colors independently of links elsewhere.

## Best solution

Provide a documented theme-token contract for links on independently themed hover surfaces, preserving current global-color defaults. Maintainers should settle whether its scope includes shared workbench tooltips and how hovered or active links inherit the override before accepting an implementation.
