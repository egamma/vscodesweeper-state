# Issue #170705 — PHP formatting on typing

[https://github.com/microsoft/vscode/issues/170705](https://github.com/microsoft/vscode/issues/170705)

## Summary

Still reproducible on main: the root cause identified by roblourens — `getInheritIndentForLine` uses the model's top-level language (php) instead of the scoped language (html) when computing inherited indentation — remains unfixed. The issue should be routed to the autoindent area.

## Change summary

Closing HTML tags in PHP files lose their indentation because the auto-indent logic looks up indent rules for the model's language (php) instead of the scoped language (html) at the relevant line.

## Best solution

Fix `getInheritIndentForLine` in `src/vs/editor/common/languages/autoIndent.ts` to compute a `ScopedLineTokens` for the previous line and use that language for indent-rule lookup (as roblourens suggested in comment 3), rather than `model.tokenization.getLanguageId()`. This affects all embedded-language scenarios (PHP+HTML, Razor, etc.).
