# Issue #170705 — PHP formatting on typing

[https://github.com/microsoft/vscode/issues/170705](https://github.com/microsoft/vscode/issues/170705)

## Summary

The issue remains actionable: a maintainer traced the PHP/HTML embedded-language indentation failure to inconsistent language selection in the auto-indent path, and no fixing commit or canonical issue is identified. It should stay open in the editor/PHP area for a focused correction and regression test.

## Change summary

Typing an HTML closing tag inside an indented PHP document can remove all leading indentation because inherited indentation rules are evaluated against PHP instead of the embedded HTML language.

## Best solution

Make inherited-indent evaluation consistently use the embedded language at the relevant line, then add a regression test covering nested HTML typed inside a PHP document while preserving normal HTML and PHP indentation behavior.
