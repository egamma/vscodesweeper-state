# Issue #109277 — Let extensions hook into url opening

[https://github.com/microsoft/vscode/issues/109277](https://github.com/microsoft/vscode/issues/109277)

## Summary

Keep open: external URI opening hooks exist, but remain a proposed API rather than a stable extension contract. The api-proposal label and assigned 1.143.0 milestone independently require leaving this with the API owners.

## Change summary

Allow extensions to handle external URLs with activation, selective acceptance, opener selection, configurable defaults, and fallback to the system browser.

## Best solution

Have the API owners complete their review of the existing externalUriOpener proposal and explicitly decide its stable contract or disposition. Preserve this issue as the proposal tracker; the built-in implementation does not by itself complete API finalization.
