# Issue #109277 — Let extensions hook into url opening

[https://github.com/microsoft/vscode/issues/109277](https://github.com/microsoft/vscode/issues/109277)

## Summary

This is the tracking issue for the `externalUriOpener` proposed API, which is fully implemented as a proposal (with infrastructure in `src/vs/workbench/contrib/externalUriOpener/`, extension host support, and the simple-browser extension already consuming it) but has not yet been finalized. The issue should remain open until the API is promoted from proposed to stable.

## Change summary

Let extensions register openers that can intercept and handle external URI opening (e.g. open localhost links in an in-editor browser preview instead of the system browser).

## Best solution

Finalize the `externalUriOpener` proposed API — the implementation is mature (used by the built-in simple-browser extension, has settings integration, priority system, and activation events). The remaining work is an API finalization review to promote it from `vscode.proposed.externalUriOpener.d.ts` to the stable `vscode.d.ts` surface.
