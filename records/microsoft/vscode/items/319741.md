# Issue #319741 — An easy way to disable credential sharing to dev containers

[https://github.com/microsoft/vscode/issues/319741](https://github.com/microsoft/vscode/issues/319741)

## Summary

This is a Dev Containers credential-forwarding request owned by the VS Code Remote Development family, so it should remain open and be moved to microsoft/vscode-remote-release. That tracker already has an older open issue covering the same user-visible need.

## Change summary

Provide an easily discoverable setting that prevents Dev Containers from sharing host Git and other credentials.

Consolidate the request into https://github.com/microsoft/vscode-remote-release/issues/9466 and provide a trusted user-level setting that disables all credential forwarding into Dev Containers without being overridable by container-controlled workspace configuration.
