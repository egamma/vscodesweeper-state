## Summary

Team-authored, actively-diagnosed bug: dbaeumer traced the root cause to the Claude Agent SDK always spawning its `Bash` tool via Git Bash on Windows, where `gh` isn't on PATH even though it works fine from PowerShell/the Editor window's own terminal — no fix has landed yet, so this stays open.

## Change summary

In the Agents Window, the Claude agent reports `gh` isn't authenticated because its Bash tool runs commands through Git Bash on Windows, where `gh` isn't resolvable, even though the same prompt works from the Editor window.
