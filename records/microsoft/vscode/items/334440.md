# Issue #334440 — Agent Window claims I am not logged into gh although I am

[https://github.com/microsoft/vscode/issues/334440](https://github.com/microsoft/vscode/issues/334440)

## Summary

Keep open: the reporter traced the misleading authentication claim to Claude using Git Bash on Windows, where gh was unavailable, while the same prompt worked in the Editor window. No verified fix or canonical issue establishes that this shell-selection problem is resolved.

## Change summary

Claude sessions in the Agents window should not mistake gh being unavailable in their Windows shell for the user being logged out.

## Best solution

Make Windows Claude command execution use an environment that can access the user's installed tools, and distinguish command-discovery failures from authentication failures. First establish whether the remaining failure originates in SDK shell selection, the supplied environment, or interpretation of the command result.
