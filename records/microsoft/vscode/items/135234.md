# Issue #135234 — Bug of recognizing a JavaScript comment instead of URL

[https://github.com/microsoft/vscode/issues/135234](https://github.com/microsoft/vscode/issues/135234)

## Summary

The supplied example exposes a defect in the upstream HTML grammar that is still present in the bundled source. Keep this report open; the newer grammar-replacement issue is related but cannot serve as the canonical for this re-reviewed, older report.

## Change summary

URLs inside JavaScript strings in HTML event-handler attributes are incorrectly highlighted as line comments.

## Best solution

Correct the upstream HTML grammar's event-handler string handling and adopt the correction in VS Code, preserving actual JavaScript comments and HTML attribute boundaries. Coordinate with the existing HTML grammar replacement work without requiring a replacement to resolve this specific defect.
