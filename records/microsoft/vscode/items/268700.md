# Issue #268700 — get_changed_files does not work in msbench

[https://github.com/microsoft/vscode/issues/268700](https://github.com/microsoft/vscode/issues/268700)

## Summary

Team-authored bug, still open. The `get_changed_files` tool fails in msbench because `gitService.getRepository()` and `gitService.activeRepository` both return undefined for the `/testbed` path, even though git is available. The fallback error message is misleading. No fix has landed on the scmChangesTool itself since the report.

## Change summary

The `get_changed_files` tool returns 'The workspace does not contain a git repository' in msbench benchmarks despite a valid git repo at `/testbed`.

## Best solution

Investigate why `IGitService.getRepository()` fails to resolve `/testbed` in the msbench environment — likely the git extension's repository discovery doesn't cover the msbench workspace setup. The fix likely lives in `extensions/copilot/src/platform/git/` (repository resolution) or in the msbench harness configuration. A fallback that shells out to `git` directly (as other msbench test cases do) could also work.
