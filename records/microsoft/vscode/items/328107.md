# Issue #328107 — Terminal auto-approve: assignments and method invocations bypass sub-command checks

[https://github.com/microsoft/vscode/issues/328107](https://github.com/microsoft/vscode/issues/328107)

## Summary

Confirmed on current main: executable assignments and PowerShell method invocations are omitted from auto-approval analysis. This security-sensitive approval bypass must remain open for maintainer handling.

## Change summary

Terminal auto-approval can approve command lines containing unexamined assignments or PowerShell method invocations.

## Best solution

Make the workbench terminal parser fail closed when executable syntax is not covered by captured command spans, with regression coverage for Bash assignments, PowerShell environment assignments, and nested method invocations. Coordinate the longer-term shared approval engine under https://github.com/microsoft/vscode/issues/326766.
