# Issue #174917 — Notebook cells should be resizable

[https://github.com/microsoft/vscode/issues/174917](https://github.com/microsoft/vscode/issues/174917)

## Summary

Valid feature request for drag-resizable notebook cells. No implementation exists on current main — notebook cells have no sash/splitter mechanism for user-driven resizing. Low community traction (1 upvote) but the request is reasonable and unaddressed.

## Change summary

Allow users to drag the edges of notebook cells to resize them, similar to how editors in the workbench can be resized.

## Best solution

Implement a sash-based resize handle on notebook cell boundaries (especially output areas) so users can drag to adjust cell height. This would live in the notebook cell parts layer (src/vs/workbench/contrib/notebook/browser/view/cellParts/) and replace reliance on settings like notebook.output.textLineLimit for controlling visible output size.
