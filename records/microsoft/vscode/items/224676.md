# Issue #224676 — Call-site sometimes off-screen when clicking thru (Python) call stack

[https://github.com/microsoft/vscode/issues/224676](https://github.com/microsoft/vscode/issues/224676)

## Summary

The defect remains plausible and source-reproducible on current main: selecting another frame reveals its line before the exception widget for the top frame is removed, so disposing that view zone can move the revealed line outside the viewport.

## Change summary

Keep the selected call-stack frame's source line visible when navigating away from the top exception frame.

## Best solution

Make stack-frame navigation account for removal of the exception widget before the final viewport position is established, while preserving the existing centered reveal and exception-widget behavior. Add a regression check for navigating from the exception frame to another frame in the same editor.
