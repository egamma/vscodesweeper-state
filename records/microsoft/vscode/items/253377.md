# Issue #253377 — Poor contrast with variable decorations in chat panel, especially on hover

[https://github.com/microsoft/vscode/issues/253377](https://github.com/microsoft/vscode/issues/253377)

## Summary

The contrast concern remains actionable: variable decorations retain fixed slash-command colors while the surrounding request bubble changes background on hover. This member-authored accessibility polish issue has no issue-linked implementing commit or canonical duplicate, so it should remain open.

## Change summary

Improve the readability of variable decorations in chat requests, particularly when the request bubble is hovered.

## Best solution
