# Issue #253377 — Poor contrast with variable decorations in chat panel, especially on hover

[https://github.com/microsoft/vscode/issues/253377](https://github.com/microsoft/vscode/issues/253377)

## Summary

Team-authored accessibility/polish issue that remains unfixed on main. The variable decoration colors (`chatSlashCommandForeground`/`chatSlashCommandBackground`) and hover states have not been updated to improve contrast since this was filed.

## Change summary

Variable decorations in the chat panel have poor contrast, especially on hover, making text difficult to read.

## Best solution

Improve the contrast ratio of the `chatSlashCommandForeground`/`chatSlashCommandBackground` color pair in `src/vs/workbench/contrib/chat/common/widget/chatColors.ts`, and define explicit `buttonHoverBackground`/`buttonHoverForeground` values in `chatMarkdownDecorationsRenderer.ts` (lines 179, 216) instead of leaving `buttonHoverBackground: undefined`. The input editor decorations in `chatInputEditorContrib.ts` also reuse the same colors and likely need a hover-state treatment.
