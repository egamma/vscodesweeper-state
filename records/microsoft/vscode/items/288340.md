# Issue #288340 — Small icons in chat input look terrible on standard DPI monitors

[https://github.com/microsoft/vscode/issues/288340](https://github.com/microsoft/vscode/issues/288340)

## Summary

Keeping this open: the report has concrete screenshots and maintainer discussion confirming the small chat icons are a real visual issue, but the current thread indicates the fix needs design work rather than a simple revert to 16px codicons.

## Change summary

Small icons in the chat input and related chat UI render poorly on standard-DPI displays because codicons are being displayed below their normal 16x16 size.

## Best solution

Have the chat input/design owners settle the intended icon assets and sizing for the chat input and chat sessions list, likely using purpose-built small icons where necessary instead of scaling standard codicons down.
