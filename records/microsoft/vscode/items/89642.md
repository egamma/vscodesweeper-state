# Issue #89642 — Call Hierarchy view doesn't show number of callers

[https://github.com/microsoft/vscode/issues/89642](https://github.com/microsoft/vscode/issues/89642)

## Summary

The caller-count display remains missing from the current Call Hierarchy peek. Keep this accepted Backlog request open; no verified canonical issue or landed implementation was found.

## Change summary

Display the number of callers for the selected symbol in the Call Hierarchy view, potentially in its title.

## Best solution

Expose a concise count of the root symbol's incoming callers in the existing Call Hierarchy peek, clearly distinguishing caller symbols from individual call sites and avoiding recursive traversal solely to compute the count.

## Evidence

- **Current title lacks a count:** src/vs/workbench/contrib/callHierarchy/browser/callHierarchyPeek.ts, CallHierarchyTreePeekWidget._updatePreview, sets the incoming-call title to "Callers of '{0}'" using only element.model.root.name. Neither that title nor a populated meta-title displays a caller count.
- **Existing capability does not cover the request:** CallHierarchyTreePeekWidget.showModel expands the root and inspects root.children.length to display "No callers" for an empty result, but does not display the numeric count for nonempty results. callHierarchyTree.ts, CallRenderer.renderElement, renders symbol names and details without a count; the callHierarchy contribution has no registered count-display setting.
- **Caller symbols versus call sites:** src/vs/workbench/contrib/callHierarchy/browser/callHierarchyTree.ts, DataSource.getChildren, maps each incoming-call result to one Call and preserves its fromRanges as locations. A caller-symbol count and a call-site count are therefore distinct quantities.
- **Canonical search:** Repository issue searches for call hierarchy with number/count, callers with count, and references to 89642 found no verified canonical owning this display request. https://github.com/microsoft/vscode/issues/135972 was read and remains open, but requests filtering and depth limits rather than a caller count; it is also newer than this re-reviewed issue.
- **Discussion and accepted scope:** https://github.com/microsoft/vscode/issues/89642 requests "X Callers of 'Area'".
