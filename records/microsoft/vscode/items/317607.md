[https://github.com/microsoft/vscode/issues/317607](https://github.com/microsoft/vscode/issues/317607)

## Summary

This is a verified duplicate of the older, open session-restoration issue: reopening pending Copilot edits replaces newer file contents with a stale snapshot. The nested-workspace reproduction adds useful evidence to that canonical report.

## Change summary

Reopening a Copilot conversation with unaccepted edits silently overwrites changes saved through a nested workspace.

## Best solution

Consolidate this reproduction into https://github.com/microsoft/vscode/issues/313703 and review its existing fix candidate, https://github.com/microsoft/vscode/pull/313793. Restoring a conversation should preserve newer file contents rather than silently replace them.
