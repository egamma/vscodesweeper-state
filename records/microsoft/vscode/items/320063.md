# Issue #320063 — "Open New External Terminal" does not correctly work with GNOME's default terminal emulator `ptyxis` . Fails to open window  that is navigated to the directory

[https://github.com/microsoft/vscode/issues/320063](https://github.com/microsoft/vscode/issues/320063)

## Summary

Real gap: `LinuxExternalTerminalService.spawnTerminal` has no ptyxis-specific argument handling (unlike ghostty, gnome-terminal, cmder, wt), so the cwd is passed only via the spawned process's `cwd` option, which ptyxis ignores. As ptyxis becomes the default GNOME terminal on Ubuntu 26.04+, this will grow in impact.

## Change summary

Opening an external terminal with ptyxis on Linux does not navigate to the target directory — ptyxis ignores the spawned process's cwd and needs explicit CLI flags.

## Best solution

Add ptyxis-specific handling in `LinuxExternalTerminalService.spawnTerminal` and `runInTerminal` (in `src/vs/platform/externalTerminal/node/externalTerminalService.ts`), similar to the existing ghostty block. Ptyxis likely needs `--new-window` and a working-directory flag passed as explicit arguments. Also consider updating `getDefaultTerminalLinuxReady` to detect ptyxis as the default terminal on modern GNOME sessions.
