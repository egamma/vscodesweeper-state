# Issue #326153 — Duplicate groups and tools appear in the model's available tool list. After the 1.129.0 upgrade, third-party plugins cannot correctly register tool sets, causing entire batches of tools to be hidden and unselectable.

[https://github.com/microsoft/vscode/issues/326153](https://github.com/microsoft/vscode/issues/326153)

## Summary

The duplicate tool groups issue is a confirmed regression from #322620 (1.127) as identified by a team member. The proposed API issue is *as-designed* (the 1.128.1 behavior was the bug). The duplicate-tools part remains unfixed on main and warrants staying open.

## Change summary

Since 1.127, the Configure Tools picker shows duplicate entries — both synthetic per-extension tool sets and standalone tool entries — because the synthetic sets are not properly hidden.

## Best solution

Fix the duplicate rendering in the tools picker by ensuring synthetic per-extension tool sets created by Chat Customizations (#322620) are properly deduplicated or hidden in the picker UI. The proposed API complaint is working-as-intended (proposed APIs require enablement).
