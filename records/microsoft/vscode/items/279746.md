# Issue #279746 — Adopt shrinking toolbars in view pane containers

[https://github.com/microsoft/vscode/issues/279746](https://github.com/microsoft/vscode/issues/279746)

## Summary

Keep open: this Backlog exploration requests responsive overflow behavior for view-pane title actions, and the maintainer discussion confirms that the current toolbar cannot preserve right-side actions while collapsing left-side actions. No verified implementation or older canonical issue is present.

## Change summary

Adopt shrinking toolbars in view pane containers so narrow views move lower-priority actions into the overflow menu without rendering problems.

## Best solution

Explore a view-pane title action layout that keeps actions to the right of the separator visible and collapses actions to its left into the `...` menu, either by extending the toolbar's middle-overflow semantics or composing two toolbars; settle the observable separator and overflow behavior before implementation.
