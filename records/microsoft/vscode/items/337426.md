# Issue #337426 — Cannot tell blocked sessions (too sublte)

[https://github.com/microsoft/vscode/issues/337426](https://github.com/microsoft/vscode/issues/337426)

## Summary

Team-authored (alexdima), brand-new report about the Agents Window's compact list view making it too subtle to spot a session blocked on user input; no fix exists yet, so this stays open for design/implementation.

## Change summary

In the compact Sessions view rendering, it's hard to visually distinguish a session that is blocked waiting on user input from other sessions.

## Best solution

Add a clearer visual affordance (icon, color, or badge) for blocked state in the compact row renderer, likely in src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts or blockedSessionsList.ts, in coordination with the cc'd designers/engineers on the thread.
