# Issue #337426 — Cannot tell blocked sessions (too sublte)

[https://github.com/microsoft/vscode/issues/337426](https://github.com/microsoft/vscode/issues/337426)

## Summary

Keep open as Agents Window polish: current main recognizes blocked sessions, but its low-opacity warning pulse and compact callout can still lack sufficient visual hierarchy. This team-authored issue has no issue-referencing fix, and the older silent-hang report concerns a distinct failure mode.

## Change summary

Make sessions waiting for user input unmistakable in the compact Sessions list.

## Best solution

Give `NeedsInput` rows a persistent, clearly ranked attention treatment in compact view that remains legible when selected, focused, hovered, or reduced motion is enabled, while preserving approval-callout precedence and dense completed rows.
