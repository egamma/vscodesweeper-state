# Issue #316370 — Agent hooks lifecycle events for Skills

[https://github.com/microsoft/vscode/issues/316370](https://github.com/microsoft/vscode/issues/316370)

## Summary

Valid feature request for adding skill lifecycle hook events (e.g. PreSkillUse/PostSkillUse). The current HookType enum in hookTypes.ts covers tool, session, subagent, and compaction events but has no skill-related hooks. No existing capability covers this use case.

## Change summary

Add hook lifecycle events for Skills (e.g. PreSkillUse/PostSkillUse) so extension authors can monitor or intercept skill invocations.

## Best solution

Extend the HookType enum in `src/vs/workbench/contrib/chat/common/promptSyntax/hookTypes.ts` with skill lifecycle events (PreSkillUse/PostSkillUse), add corresponding entries in HOOKS_BY_TARGET and HOOK_METADATA, and wire up the skill execution path to fire these hooks. The ask is well-scoped and follows the existing pattern for PreToolUse/PostToolUse.
