# Issue #348581 — Fast-exiting background tasks still lose diagnostics after completion

[https://github.com/microsoft/vscode/issues/348581](https://github.com/microsoft/vscode/issues/348581)

## Summary

Keep open: current source still allows background-task completion to delete diagnostics already published by the same run. The earlier merged fix waits for queued lines but does not resolve this cleanup defect.

## Change summary

Preserve all collected task diagnostics after a fast-exiting background task completes, including repeated runs.

## Best solution

Ensure background-task completion removes stale diagnostics without treating diagnostics published during the current run as stale. Cover completion and repeated runs with the real marker service.
