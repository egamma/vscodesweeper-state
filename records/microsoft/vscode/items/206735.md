# Issue #206735 — `Vscode.Window.onDidCloseTerminal` not invoked even terminal is halted in a specific case

[https://github.com/microsoft/vscode/issues/206735](https://github.com/microsoft/vscode/issues/206735)

## Summary

Still reproduces on main: when a terminal in the editor area is moved (dragged to another group), `_removeInstance` disposes the `onDisposed` listener, and the `onDidVisibleEditorsChange` handler re-adds the instance without re-registering it — so when the terminal is later closed, `onDidDisposeInstance` never fires and the extension API `onDidCloseTerminal` is never invoked.

## Change summary

`vscode.window.onDidCloseTerminal` fails to fire after a terminal in the editor area is moved between editor groups.

## Best solution

In `terminalEditorService.ts`, the `onDidVisibleEditorsChange` handler (line ~88) re-adds the terminal to `instances` and `_editorInputs` but skips re-registering the `onDisposed`/`onDidFocus`/capability listeners that `_registerInstance` sets up. It should call `_registerInstance` (or at minimum re-register the dispose listener) instead of manually pushing into the arrays.
