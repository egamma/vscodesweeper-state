# Issue #163234 — Panels create actions that are disposed of on startup

[https://github.com/microsoft/vscode/issues/163234](https://github.com/microsoft/vscode/issues/163234)

## Summary

The startup inefficiency remains directly visible on current main: hidden view containers still cause composite actions to be created and immediately disposed. The newer https://github.com/microsoft/vscode/issues/171119 reports the same path, but cannot be the duplicate canonical for this re-reviewed, older issue.

## Change summary

Avoid creating panel composite actions during startup when the associated view container will immediately be hidden.

## Best solution

Keep composite actions lazy for hidden view containers while preserving action initialization for visible, active, and subsequently revealed containers in `PaneCompositeBar`.
