# Issue #313029 — Support for agent plugin repos without the `.git` preffix

[https://github.com/microsoft/vscode/issues/313029](https://github.com/microsoft/vscode/issues/313029)

## Summary

The defect remains directly visible on current main: plugin entries using a `url` source are rejected solely because the URL lacks a `.git` suffix. This team-authored issue should remain open for the bounded parser and test correction.

## Change summary

Allow agent-plugin marketplace entries to reference valid Git repositories, including Azure DevOps repositories, whose URLs do not end in `.git`.

## Best solution

Make plugin `url` source parsing accept suffixless Git URLs consistently with marketplace references and `git-subdir` sources, while retaining the existing required-field and metadata validation.
