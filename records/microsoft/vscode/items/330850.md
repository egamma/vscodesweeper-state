# Issue #330850 — Option to download vscode server remote dev from host connected internet

[https://github.com/microsoft/vscode/issues/330850](https://github.com/microsoft/vscode/issues/330850)

## Summary

Remote-SSH already supports downloading VS Code Server locally without first waiting for the remote download to fail. This concerns a VS Code-team-owned extension, so propose transferring the thread to its owning tracker rather than closing it here.

## Change summary

Avoid lengthy remote download timeouts when installing VS Code Server on an SSH host without outbound internet access.

## Best solution

Use the existing remote.SSH.localServerDownload setting to always download locally and transfer the server over SSH. Any remaining delay with that configuration should be assessed in microsoft/vscode-remote-release, preserving this thread through a maintainer transfer.

This directly addresses the requested way to bypass the remote network timeout.
- **Ownership:** The same official documentation identifies Remote-SSH as the extension responsible for installing VS Code Server on the SSH host.
