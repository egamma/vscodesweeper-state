# Issue #127764 — Support using option key on MacOS for Escape-Codes

[https://github.com/microsoft/vscode/issues/127764](https://github.com/microsoft/vscode/issues/127764)

## Summary

Keep open as the VS Code tracker for upstream Option-key escape-sequence support. The existing Meta setting provides partial coverage, but neither a complete implementation nor a canonical duplicate covering this terminal request was established.

## Change summary

Support iTerm2-style Option-key escape sequences so macOS users can invoke their ZSH widget bindings in the integrated terminal.

## Best solution

Resolve the keyboard-input behavior tracked in https://github.com/xtermjs/xterm.js/issues/4904, then ensure VS Code adopts it on the integrated-terminal path while preserving normal macOS character input when the option is disabled.
