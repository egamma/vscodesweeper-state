[https://github.com/microsoft/vscode/issues/127764](https://github.com/microsoft/vscode/issues/127764)

Keep open: xterm.js still lacks the required escape-code option, and the upstream implementation PR was closed without merging. The request also passed the feature-request backlog threshold with 22 upvotes.

## Best solution
