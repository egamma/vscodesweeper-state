# Issue #275018 — Changing default profile to bash on macOS does not update run_in_terminal prompt

[https://github.com/microsoft/vscode/issues/275018](https://github.com/microsoft/vscode/issues/275018)

## Summary

The bug remains on current main: the run_in_terminal definition is derived from the selected shell, but its registration is not refreshed when either the default terminal profile or chat-specific terminal profile changes.

## Change summary

Changing the terminal profile leaves the run_in_terminal model description referring to the previously selected shell until VS Code reloads.

## Best solution

Refresh the run_in_terminal tool data when any platform-specific default or chat terminal profile setting changes, preserving the existing tool implementation and cache optimization.
