# Issue #275018 — Changing default profile to bash on macOS does not update run_in_terminal prompt

[https://github.com/microsoft/vscode/issues/275018](https://github.com/microsoft/vscode/issues/275018)

## Summary

Still reproduces on main: the run_in_terminal tool description is only re-registered when sandbox settings change, not when the terminal profile changes. The config listener in ChatAgentToolsContribution omits terminal profile and chat agent profile settings, so the tool description stays stale (e.g. still says 'zsh' after switching to bash). Team-authored — keeping open.

## Change summary

Changing the default terminal profile or the chat agent terminal profile does not update the run_in_terminal tool's shell-specific description until reload.

## Best solution

Add the terminal default-profile settings (`terminal.integrated.defaultProfile.*`) and the chat agent terminal profile setting (`chat.tools.terminal.terminalProfile.*`) to the `onDidChangeConfiguration` listener in `ChatAgentToolsContribution` so that `_registerRunInTerminalTool()` is called when those change. Additionally, the upstream caching issue in the Copilot extension's `toolsService.ts` (tools cached by object identity, not content) needs to be addressed — possibly via an `onDidChangeLMTools` event — so the extension picks up the re-registered description.
