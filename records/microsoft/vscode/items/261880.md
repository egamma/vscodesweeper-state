# Issue #261880 — Markdown Image Hover Preview broken for file paths exceeding 259

[https://github.com/microsoft/vscode/issues/261880](https://github.com/microsoft/vscode/issues/261880)

## Summary

Root cause is confirmed in Electron's registerFileProtocol (electron/electron#49101, now closed). An open PR #309363 proposes a VS Code-side workaround. Keeping open — the PR needs review and the upstream fix hasn't shipped to VS Code's Electron yet.

## Change summary

Markdown image hover preview fails on Windows when the image file path exceeds MAX_PATH (259 chars), due to Electron's registerFileProtocol not using extended-length path prefixes.

## Best solution

Land the open PR (https://github.com/microsoft/vscode/pull/309363) which adds a `\\?\` long-path prefix in `protocolMainService.ts` before passing paths to Electron's callback, or wait for the Electron fix to ship. The PR is ready for review.
