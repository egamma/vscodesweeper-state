# Issue #335687 — Agent Host downloads Claude SDK 0.3.239 / Claude Code 2.1.239, but Fable 5.1 requires >= 2.1.251

[https://github.com/microsoft/vscode/issues/335687](https://github.com/microsoft/vscode/issues/335687)

## Summary

Keep open: the discussion confirms recurring model/runtime incompatibility and misleading update guidance, not merely the original Fable version mismatch. Main now pins a newer SDK, but that does not establish that the compatibility and diagnostic gap is resolved.

## Change summary

Agent Host exposes Claude models that its separately managed runtime cannot execute, then gives update instructions for unrelated Claude installations.

## Best solution

Keep model availability consistent with the Agent Host runtime's capabilities and make compatibility failures identify the VS Code-managed runtime and the appropriate update action. Coordinate runtime freshness policy with https://github.com/microsoft/vscode/issues/332295 without losing this report's distinct error-guidance requirement.
