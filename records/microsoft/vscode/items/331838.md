# Issue #331838 — Touch: dragging inside a menu dismisses the open submenu instead of scrolling

[https://github.com/microsoft/vscode/issues/331838](https://github.com/microsoft/vscode/issues/331838)

## Summary

Well-diagnosed touch-input bug in the submenu dismissal logic, confirmed against current main, and already has an open fixing PR — keep this open for the PR to land rather than closing or auto-fixing.

## Change summary

On touch screens, dragging to scroll inside an open submenu instead dismisses the submenu, because the parent menu's onScroll handler closes it unconditionally even for phantom (unclamped) scroll events that never move the content.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/331839, which gates the submenu-dismissal onScroll handler in src/vs/base/browser/ui/menu/menu.ts on `e.scrollTopChanged || e.scrollLeftChanged` as the reporter proposed.
