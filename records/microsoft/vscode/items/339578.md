# Issue #339578 — Azure DevOps MCP Server disconnects and fails often

[https://github.com/microsoft/vscode/issues/339578](https://github.com/microsoft/vscode/issues/339578)

## Summary

Keep open for MCP authentication investigation: the attached log documents a working connection followed by failed reauthentication and HTTP 401, and a maintainer independently confirms the regression. The inspected related issues do not establish a duplicate, and no concrete fixing commit was identified.

## Change summary

Azure DevOps remote MCP connections repeatedly lose authentication during agent tool use and sometimes require account removal and sign-in to recover.

## Best solution

Establish why the built-in MCP HTTP transport cannot recover authentication on this Azure DevOps endpoint, then restore reliable token renewal and actionable recovery without requiring account removal. Correlate MCP and Microsoft authentication traces before deciding whether the defect is in client recovery or the remote service.

  > The attached MCP log at https://github.com/user-attachments/files/33023166/azure-devops-mcp-server-log.txt shows successful discovery followed by consent/cancellation errors and a scope transition to undefined.
