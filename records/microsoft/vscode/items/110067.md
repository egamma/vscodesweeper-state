# Issue #110067 — Implement Debugger Modules View

[https://github.com/microsoft/vscode/issues/110067](https://github.com/microsoft/vscode/issues/110067)

## Summary

The debugger still lacks a core Modules view even though DAP defines module requests and events; the existing adapter API and extension implementations provide the data path, not the requested built-in table UI. No verified older canonical owns the same request, so this should remain open in the debug backlog.

## Change summary

Add a debugger Modules view that displays loaded module metadata supplied through DAP.

## Best solution

Add a core debug Modules view with table-oriented columns for the useful DAP Module fields, refresh it from `module` events, and request paged module data from the active debug session.
