# Issue #287552 — Chat: `chat.tools.terminal.autoApprove` is not resource scoped

[https://github.com/microsoft/vscode/issues/287552](https://github.com/microsoft/vscode/issues/287552)

## Summary

Still unfixed on main: the `chat.tools.terminal.autoApprove` setting lacks `ConfigurationScope.RESOURCE` scope, so it cannot be configured per-folder in multi-root workspaces. The Copilot-generated PR #287553 was closed without merging.

## Change summary

The `chat.tools.terminal.autoApprove` setting is not resource-scoped, preventing per-folder configuration in multi-root workspaces.

## Best solution

Add `scope: ConfigurationScope.RESOURCE` to the `chat.tools.terminal.autoApprove` and `chat.tools.terminal.ignoreDefaultAutoApproveRules` setting registrations in `terminalChatAgentToolsConfiguration.ts`, and update `CommandLineAutoApprover` to resolve config using the terminal's cwd as the resource URI — essentially the approach from the closed PR #287553, but properly reviewed and landed.
