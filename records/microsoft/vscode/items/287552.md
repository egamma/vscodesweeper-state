# Issue #287552 — Chat: `chat.tools.terminal.autoApprove` is not resource scoped

[https://github.com/microsoft/vscode/issues/287552](https://github.com/microsoft/vscode/issues/287552)

## Summary

The per-folder configuration gap remains in current main: terminal approval rules are resolved without a resource and shared across folders. The linked implementation PR was closed without merging, so this issue still needs a fix.

## Change summary

Make terminal auto-approval rules apply independently to each folder in a multi-root workspace.

## Best solution

Resolve both sub-command and full-command-line approval rules against the terminal's original working-directory resource, with folder-isolated caching and configuration-change invalidation. Preserve existing denial precedence, session rules, default-rule handling, and enterprise controls.
