# Issue #123303 — Cursors are not merged in this case

[https://github.com/microsoft/vscode/issues/123303](https://github.com/microsoft/vscode/issues/123303)

## Summary

The bug remains on current main: disabling `editor.multiCursorMergeOverlapping` prevents normalization of all intersecting selections, although the intended exception is only for touching collapsed cursors. The issue should remain open for a bounded editor fix.

## Change summary

With `editor.multiCursorMergeOverlapping` disabled, Cmd/Ctrl+D can leave intersecting selections instead of merging them.

## Best solution

Enforce the intended selection-normalization semantics in the cursor collection layer: intersecting non-empty selections should merge while distinct or merely touching collapsed cursors remain allowed when the setting is disabled.
