# Issue #308673 — GitHub Copilot extension doesn't stay logged in

[https://github.com/microsoft/vscode/issues/308673](https://github.com/microsoft/vscode/issues/308673)

## Summary

The attached log confirms a repeatable authentication failure after roughly 30 minutes: VS Code still finds the stored GitHub session, but GitHub rejects its access token with 401 responses. The multi-machine correlation warrants investigation by the authentication area.

## Change summary

Copilot Chat becomes signed out every 20–30 minutes when the same account is used on two machines.

## Best solution

Determine why authenticating on another machine invalidates the existing VS Code GitHub OAuth token, then preserve independent sessions or refresh the invalidated session without deactivating Copilot Chat.
