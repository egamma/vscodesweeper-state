# Issue #349993 — Manage Language Models: docking modal editor restores duplicate Copilot groups in 1.147.0

[https://github.com/microsoft/vscode/issues/349993](https://github.com/microsoft/vscode/issues/349993)

## Summary

The docking path loses the harness scope in current source: scope belongs to the original pane's widget and is not restored when the input opens in the destination group. Keep this post-fix report open; the configuration-name observation remains a separate, unconfirmed lead.

## Change summary

Preserve the selected harness and its visible Copilot groups when moving Manage Language Models from a modal editor into the main editor area.

## Best solution

The management editor should retain its harness scope across pane recreation, including filtering provider status groups, without changing unrelated providers or model settings. Investigate configuration renaming separately rather than treating it as an established cause or workaround.
