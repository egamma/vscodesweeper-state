# Issue #346487 — Keep Pinned Editor Tabs Fixed While Scrolling Normal Tabs

[https://github.com/microsoft/vscode/issues/346487](https://github.com/microsoft/vscode/issues/346487)

## Summary

The central request already has a built-in option: workbench.editor.pinnedTabSizing set to compact or shrink keeps pinned tabs stationary while normal tabs scroll underneath. The default normal sizing intentionally scrolls pinned tabs with the other tabs.

## Change summary

Keep pinned editor tabs visible while horizontally scrolling normal tabs.

## Best solution

Use the existing compact or shrink pinned-tab sizing for stationary pinned tabs in the same row; retain the separate-row setting as an alternative layout.

- **Proposed comment:**

  > Thanks for the request. Set `"workbench.editor.pinnedTabSizing": "shrink"` (shortened filenames) or `"compact"` (icons) to keep pinned tabs fixed in the same row while normal tabs scroll underneath. The default `"normal"` sizing scrolls them together.

## Evidence

- **Existing setting:** src/vs/workbench/browser/workbench.contribution.ts:270-279 registers workbench.editor.pinnedTabSizing with normal, compact, and shrink values; normal is the default.
- **Stationary pinned tabs:** src/vs/workbench/browser/parts/editor/media/multieditortabscontrol.css:241-254 applies position: sticky to compact and shrink pinned tabs, explicitly allowing normal tabs to scroll underneath. src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts:1812-1817 supplies their horizontal offsets.
- **Space limitation:** src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts:2439-2475 reserves the pinned-tab width, excluding normal sizing. When pinned tabs leave insufficient room for normal tabs, sticky positioning is deliberately disabled so all tabs remain reachable.
- **Discussion and alternative:** The contributor comment on https://github.com/microsoft/vscode/issues/346487 suggests workbench.editor.pinnedTabsOnSeparateRow as a workaround. Unlike that layout change, compact and shrink sizing provide stationary pinned tabs within the same row.
