## Summary

Team-authored bug about the save confirmation dialog in vscode.dev not properly handling Escape/Cancel when a dirty notebook triggers it during a profile switch. No fix commit found referencing this issue; the doShowSaveConfirm code does define a cancelButton, but the interaction with the notebook-specific profile-switch flow may not propagate the cancel result correctly.
