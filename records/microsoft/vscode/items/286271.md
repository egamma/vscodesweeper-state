# Issue #286271 — Allow creating Worktrees from branch context menu

[https://github.com/microsoft/vscode/issues/286271](https://github.com/microsoft/vscode/issues/286271)

## Summary

Valid feature request from a team member: the branch context menu in the SCM Repositories view lacks a 'Create Worktree' action. The `git.repositories.createWorktree` command exists but is only surfaced in the worktrees artifact group context menu, not on individual branch items. Hard keep-open (MEMBER author).

## Change summary

Add a 'Create Worktree' option to the branch context menu in the SCM Repositories view so users can create a worktree directly from a branch.

## Best solution

Add a `scm/artifact/context` menu entry for `git.repositories.createWorktree` (or a new branch-aware variant) gated on `scmArtifactGroupId == branches`, passing the selected branch as the commitish/branch. The command handler in `extensions/git/src/commands.ts` (`_createWorktree`) already accepts branch info; the gap is purely the menu contribution in `extensions/git/package.json`.
