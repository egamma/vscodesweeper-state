# Issue #30795 — Can the VSCode gutter be made smaller, i.e., decreased size/width?

[https://github.com/microsoft/vscode/issues/30795](https://github.com/microsoft/vscode/issues/30795)

## Summary

A supported compact-gutter configuration remains missing. This Backlog feature request has 153 community upvotes and is already correctly routed to editor-core, so it should remain open.

## Change summary

Allow users to reduce the editor gutter width without disabling useful features such as folding.

## Best solution

Provide a supported compact-gutter configuration, likely by formalizing `editor.lineDecorationsWidth` and the relevant line-number sizing control while preserving folding commands. Coordinate with https://github.com/microsoft/vscode/issues/93887 rather than adding overlapping settings.
