# Issue #339173 — Terminal shortcuts should take priority over VS Code commands when alternate buffer is active

[https://github.com/microsoft/vscode/issues/339173](https://github.com/microsoft/vscode/issues/339173)

## Summary

Keep open as a terminal feature request: existing settings support terminal-focused shortcut forwarding, but do not automatically change priority when the alternate buffer becomes active. The claim that commandsToSkipShell disables shortcuts outside the terminal is not supported by the source.

## Change summary

Automatically prioritize terminal application shortcuts while a focused terminal uses the alternate buffer, preserving normal VS Code shortcuts elsewhere.

## Best solution

Have the terminal owner decide whether alternate-buffer activation should change shortcut priority, including which workbench and accessibility shortcuts remain available. Preserve normal-buffer behavior and shortcuts outside the terminal; existing terminal-wide forwarding is a workaround, not complete coverage of the requested automatic behavior.
