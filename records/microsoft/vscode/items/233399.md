# Issue #233399 — Vscode does not open links in default browser

[https://github.com/microsoft/vscode/issues/233399](https://github.com/microsoft/vscode/issues/233399)

## Summary

Keep open for Linux Snap browser-resolution investigation: multiple reports confirm that VS Code selects a different browser or installation than the host default. The explicit-browser workaround does not resolve automatic default selection, and no verified fix or eligible duplicate canonical was found.

## Change summary

Opening an HTTP link from the VS Code Snap package can launch the wrong browser despite the host default being configured correctly.

## Best solution

Make external HTTP/HTTPS opening from the Snap package honor the host's browser association, including user-local desktop entries. First isolate whether the discrepancy originates in VS Code's environment handling, Electron's opener, or Snap/XDG integration; investigate the Windows debug-terminal report separately unless a shared cause is established.
