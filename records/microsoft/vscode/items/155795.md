# Issue #155795 — Remove workaround in launch config arg escaping

[https://github.com/microsoft/vscode/issues/155795](https://github.com/microsoft/vscode/issues/155795)

## Summary

Keep this team-authored cleanup open: the temporary `<` and `>` escaping exceptions remain on current main, and the prerequisite C/C++ debug-adapter adoption is still outstanding.

## Change summary

Remove the launch-argument escaping workaround that treats standalone `<` and `>` as shell operators.

## Best solution

After the C/C++ debug adapter adopts `argsCanBeInterpretedByShell`, remove the standalone `<`/`>` exceptions from all three shell paths in `prepareCommand` and update the corresponding terminal tests to require normal escaping.
