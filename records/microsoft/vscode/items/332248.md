# Issue #332248 — Remote SSH doesn't have VS server package

[https://github.com/microsoft/vscode/issues/332248](https://github.com/microsoft/vscode/issues/332248)

## Summary

Keep open: another user confirms the ARM32 server download failure, and current build templates explicitly exclude armhf server artifacts. The older ARM32 support request is related, but reports an unsupported-platform error rather than this download-404 symptom, so it does not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Remote-SSH connections to a Raspberry Pi fail because the requested server-linux-armhf package returns HTTP 404.

## Best solution

Have the server-distribution and Remote-SSH owners reconcile ARM32 artifact availability with connection behavior: supported targets need a downloadable matching server, while unsupported targets need an explicit compatibility diagnostic rather than a missing-package download failure. Coordinate the support-policy decision with https://github.com/microsoft/vscode/issues/326232.
