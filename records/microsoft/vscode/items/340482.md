# Issue #340482 — Agents Window feels persistently sluggish, with additional freezes when switching sessions

[https://github.com/microsoft/vscode/issues/340482](https://github.com/microsoft/vscode/issues/340482)

## Summary

Thanks for the report and for narrowing it down. The reporter says the Agents Window lag goes away after disabling `chat.agentSessions.sessionStorageCleanupSuggestion.enabled`, which points to the worktree cleanup scan in the Agents Window. Nothing is fixed yet, so this stays open.

## Change summary

The Agents Window is sluggish, with roughly one-second freezes on session switch, for a user with hundreds of worktrees. The reporter attributes it to the worktree cleanup suggestion scan.

## Best solution

Make the worktree cleanup measurement cheap for users with hundreds of worktrees, so it does not block or flood the renderer. Options include running it off the main thread, batching, and bounding how often it rescans. It should not re-run on every session change.
