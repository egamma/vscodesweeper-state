# Issue #316766 — Agents App: Allow me to cancel a commit while it's in progress

[https://github.com/microsoft/vscode/issues/316766](https://github.com/microsoft/vscode/issues/316766)

## Summary

Keep open: the Agents window's Commit & Sync path still lacks cancellation of the upload stage, and git.supportCancellation does not cover that path. The older cancellation reports are related but do not establish a canonical for this re-reviewed Agents-specific request.

## Change summary

Allow users to cancel an accidentally started Commit & Sync operation, particularly a long-running upload.

## Best solution

Provide an explicit cancellation control for the network stage of Agents window Commit & Sync, retaining completed local commits and accurately refreshing operation state afterward. Treat cancellation of local commits or hooks as a separate scope decision rather than assuming it is equivalent to stopping an upload.
