# Issue #175234 — Support hover popup webview

[https://github.com/microsoft/vscode/issues/175234](https://github.com/microsoft/vscode/issues/175234)

## Summary

Well-articulated feature request with 95 upvotes, already promoted to Backlog. No implementation exists on current main — the hover API still only supports MarkdownString/string content, with no webview-in-hover capability. The request is distinct from #3220 (custom peek widgets) as the author explains. Stays open as a valid backlog item.

## Change summary

Allow extensions to render custom interactive HTML/webview content inside editor hover popups, similar to the built-in color picker.

## Best solution

Design and implement a proposed extension API that lets extensions contribute webview-backed hover content (combining the webview API with the hover provider API). The API surface would live in `src/vscode-dts/` as a proposed API, with implementation in the editor hover contribution (`src/vs/editor/contrib/hover/`) and the extension host API layer (`src/vs/workbench/api/`). Given 95 upvotes, this deserves periodic re-evaluation for scheduling.
