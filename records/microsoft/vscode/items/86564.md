# Issue #86564 — Support local paths in hover MarkdownString

[https://github.com/microsoft/vscode/issues/86564](https://github.com/microsoft/vscode/issues/86564)

## Summary

The requested relative-link capability is implemented through MarkdownString.baseUri, and TypeScript hovers supply the current document URI, covering the original same-file example. Cross-file documentation origins and remote/web image loading remain separately tracked limitations.

## Change summary

Resolve relative links and image paths in hover markdown against the associated source file rather than the filesystem root.

## Best solution

Close this capability request as completed by commit 69896100ed4c84cda2b605a10ad339a5da8913bb and the subsequent stable API finalization. Keep the distinct defining-file-origin and remote/web image problems in their existing trackers.
