# Issue #86564 — Support local paths in hover MarkdownString

[https://github.com/microsoft/vscode/issues/86564](https://github.com/microsoft/vscode/issues/86564)

## Summary

The central ask — relative paths in hover MarkdownString — was implemented via the `baseUri` API (finalized March 2022) and is actively used by the TypeScript extension. The last commenter confirmed it works. This can be closed as completed.

## Change summary

Support relative/local paths in hover MarkdownString so links and images resolve relative to the defining file.

## Best solution

Keep the shipped `MarkdownString.baseUri` API (finalized in commit a068ebee8db, shipped in VS Code 1.66). The TypeScript extension already sets `baseUri` for hovers and completions. No further core change needed.
