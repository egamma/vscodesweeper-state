# Issue #301149 — Linux apt repo lags behind stable release feed: UI advertises 1.111.0, but packages.microsoft.com only offers 1.110.1

[https://github.com/microsoft/vscode/issues/301149](https://github.com/microsoft/vscode/issues/301149)

## Summary

Valid report of a recurring delay between the VS Code stable release feed (and in-app updater) advertising a new version and the packages.microsoft.com apt repository actually publishing it. Multiple commenters confirm this recurs across releases. The root cause is in the publishing infrastructure, not in the VS Code source; no code fix on main resolves it.

## Change summary

The official Microsoft apt repository publishes new stable VS Code releases days after the direct .deb download and in-app update feed already advertise them, causing confusing update notifications for Linux users.

## Best solution

Either align the apt repo publication timing with the update feed and direct download availability, or suppress the in-app update notification for users whose install method is apt-managed (related request tracked in https://github.com/microsoft/vscode/issues/302104). The fix lives in the release pipeline infrastructure, not in the VS Code source tree.
