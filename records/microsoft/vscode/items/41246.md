# Issue #41246 — Git - add of file with unicode name fails in Git panel

[https://github.com/microsoft/vscode/issues/41246](https://github.com/microsoft/vscode/issues/41246)

## Summary

The original Windows cmd-prompt pathspec problem was confirmed fixed back in 2018, and the long-running follow-on (macOS folders/files with decomposed/Unicode-normalized names failing to stage) is fixed on main by two 2025 commits that changed git add/diff/etc. to use a relative pathspec resolved against both the repo root and its real (symlink-resolved) path, rather than an absolute path that could byte-mismatch an NFD-on-disk directory name.

## Change summary

Staging files whose path (or an ancestor folder) contains certain Unicode characters fails with 'fatal: pathspec ... did not match any files' or '... is outside repository'.

## Best solution

Treat as fixed by the relative-pathspec rework merged via PRs #242889 and #245001 (commits d16352ab45590781c4690c72d530f5e81373c82b and 5c0d4e2422c4d4cbf7af353cac4e4d263cf95545), which ships in VS Code 1.99 — close as completed, pointing reporters still on older builds to update.
