# Issue #92357 — Settings Sync : Allow for custom backend service end points

[https://github.com/microsoft/vscode/issues/92357](https://github.com/microsoft/vscode/issues/92357)

## Summary

Still a valid open feature request with strong community support (76 upvotes). The sync store URL remains hardcoded from product.json with no extension API or user setting to configure a custom backend — the feature has not been implemented.

## Change summary

Allow users or extensions to configure custom backend service endpoints for Settings Sync instead of being locked to Microsoft's servers.

## Best solution

Expose a Settings Sync backend provider API (similar to the auth provider API) that extensions can implement, enabling alternative backends like GitHub Enterprise, GitLab, or self-hosted services. The store management service in src/vs/platform/userDataSync/common/userDataSyncStoreService.ts would need to support dynamic endpoint configuration beyond what product.json dictates.
