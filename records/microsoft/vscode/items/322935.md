# Issue #322935 — Model picker: add settings to disable "Auto" grouping and expand "Other Models" by default

[https://github.com/microsoft/vscode/issues/322935](https://github.com/microsoft/vscode/issues/322935)

## Summary

The requested preferences remain absent on current main: promoted models are removed from the full list and Other Models is explicitly collapsed on each open. No older canonical owns these same presentation preferences, but with no community or maintainer signal after 98 days this should remain open as under discussion rather than move directly to implementation.

## Change summary

Add user preferences to disable the model picker's promoted/recent grouping and to open Other Models expanded by default.

## Best solution

The chat UX owners should decide whether to expose two settings, persist the user's expansion choice, or simplify the picker without additional configuration. Any accepted design should cover both the flat-list preference and the repeated expansion friction across the flat and tabbed picker implementations.
