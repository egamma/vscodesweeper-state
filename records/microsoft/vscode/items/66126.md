# Issue #66126 — Emmet toggle comment not working correctly for jsx

[https://github.com/microsoft/vscode/issues/66126](https://github.com/microsoft/vscode/issues/66126)

## Summary

Still reproduces on main: the Emmet toggle comment implementation uses HTML comment syntax (`<!-- -->`) for JSX files, but JSX requires `{/* */}` syntax. The parser doesn't detect JSX comment blocks, so uncommenting also fails. A maintainer confirmed this is technical debt (comment 5–6).

## Change summary

Emmet toggle comment wraps JSX elements in HTML comments instead of JSX-compatible `{/* */}` comments, and cannot uncomment JSX comment blocks.

## Best solution

Add JSX-aware comment toggling in `extensions/emmet/src/toggleComment.ts` that uses `{/* */}` syntax when the language is `javascriptreact` or `typescriptreact`, and teach the parser to recognize JSX comment blocks for uncommenting.
