# Issue #66126 — Emmet toggle comment not working correctly for jsx

[https://github.com/microsoft/vscode/issues/66126](https://github.com/microsoft/vscode/issues/66126)

## Summary

Keep open: the current Emmet command still handles JSX through HTML parsing and HTML comment delimiters, without recognizing selected JSX comment blocks. This matches the maintainer's diagnosis; no fixing commit or qualifying canonical duplicate was established.

## Change summary

Make Emmet Toggle Comment correctly recognize and uncomment JSX comment blocks in JavaScript React content.

## Best solution

Support JSX comment recognition and reversible toggling in the built-in Emmet command while preserving existing HTML and stylesheet behavior. Establish the boundary between command-local handling and the shared parser before implementing, rather than attempting a general JSX parser overhaul.
