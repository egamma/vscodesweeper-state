# Issue #81010 — Enter in the middle of a line comment should create a new line comment

[https://github.com/microsoft/vscode/issues/81010](https://github.com/microsoft/vscode/issues/81010)

## Summary

A real gap remains for line comments containing an auto-closed bracket. Comment continuation was added for ordinary text after the cursor, but current token processing removes the closing brace before evaluating that rule.

## Change summary

Continue a JavaScript line comment when Enter splits an auto-closed brace pair inside the comment.

## Best solution

Route this to basic-language and auto-indentation ownership. Preserve enough information about non-whitespace comment text after the cursor to trigger comment continuation without allowing commented brackets to activate normal brace indentation.
