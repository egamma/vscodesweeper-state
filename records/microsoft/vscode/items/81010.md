# Issue #81010 — Enter in the middle of a line comment should create a new line comment

[https://github.com/microsoft/vscode/issues/81010](https://github.com/microsoft/vscode/issues/81010)

## Summary

Keep open: ordinary JavaScript line-comment continuation now exists, but the reported brace-only suffix still bypasses it because comment brackets are removed before evaluating Enter rules. The original steps remain sufficient to exercise this remaining gap, although the old extra-blank-line symptom has changed.

## Change summary

Pressing Enter between braces inside a JavaScript line comment should keep the closing brace commented out.

## Best solution

Make comment continuation honor non-whitespace comment text after the cursor, including a closing brace, without treating commented brackets as executable code. Preserve the established behavior of not continuing a comment when Enter is pressed at its end.
