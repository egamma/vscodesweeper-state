# Issue #133073 — Actions are unclickable in Modal dialog when opened through a CodeLens (and all mouse event on the system disabled)

[https://github.com/microsoft/vscode/issues/133073](https://github.com/microsoft/vscode/issues/133073)

## Summary

Keep open: the discussion contains an independent reproduction, and a later Linux report describes the same CodeLens-triggered native-dialog failure. Current source retains the mouse-down execution path; neither a verified fix nor an eligible open canonical was found.

## Change summary

Opening a native modal warning from a CodeLens on Linux makes dialog buttons and other applications unresponsive to mouse clicks until Escape is pressed.

## Best solution

Restore mouse interaction for native dialogs opened by CodeLens commands without requiring extension authors to add delays or users to switch dialog styles. Diagnose the Linux input-grab interaction between CodeLens mouse-down execution and Electron's native dialog before choosing a bounded core fix or establishing upstream ownership.
