[https://github.com/microsoft/vscode/issues/115365](https://github.com/microsoft/vscode/issues/115365)

## Summary

Markdown tree labels are implemented and verified as a proposed API, but the `api-proposal` tracking issue must remain open until the API owners finalize or abandon it.

## Change summary

Allow extension-provided tree item labels to use a supported inline subset of MarkdownString formatting.
