# Issue #115365 — Allow TreeItem.label to support MarkdownString

[https://github.com/microsoft/vscode/issues/115365](https://github.com/microsoft/vscode/issues/115365)

## Summary

Basic Markdown tree-label support has landed behind a proposed-API gate, but it has not become stable API. Keep this api-proposal tracking issue open for the API owners' finalization decision.

## Change summary

Allow extension tree-item labels to use Markdown formatting, particularly strikethrough, without replacing the tree with a webview.

## Best solution

Retain this issue to track evaluation and finalization of treeItemMarkdownLabel. The API owners should settle the supported formatting contract and stable declaration shape; the existing proposed implementation already covers whole-label strikethrough, bold, and italics.

- **Merged implementation:** https://github.com/microsoft/vscode/pull/272435 is merged and explicitly references this issue in its closing syntax. It introduced basic MarkdownString tree-label support, but its existence does not establish stable API finalization.
- **Current proposed capability:** src/vscode-dts/vscode.proposed.treeItemMarkdownLabel.d.ts defines TreeItemLabel2.label as string | MarkdownString. - **Stable API and runtime gate:** src/vscode-dts/vscode.d.ts still declares TreeItem.label as string | TreeItemLabel and TreeItemLabel.label as string. In src/vs/workbench/api/common/extHostTreeViews.ts, toTreeItemLabel checks checkProposedApiEnabled(extension, 'treeItemMarkdownLabel') before accepting a nested MarkdownString label.
