# Issue #163954 — API to disable bracket pair colorization for specific ranges

[https://github.com/microsoft/vscode/issues/163954](https://github.com/microsoft/vscode/issues/163954)

## Summary

Keep open: the extension-facing range-exclusion capability remains missing, and hiding bracket colors alone would not resolve inactive brackets corrupting active-code nesting. The older related request discusses highlighting suppression, but does not clearly own this full behavior.

## Change summary

Allow extensions to exclude inactive source ranges from bracket pair colorization so unmatched brackets there do not disrupt active-code colors.

## Best solution

Define an extension-facing exclusion contract for bracket colorization that handles active-code nesting without making synchronous typing behavior depend on asynchronous extension results. Coordinate with the semantic-token highlighting request while retaining this report's inactive-preprocessor acceptance case.
