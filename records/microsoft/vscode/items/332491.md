# Issue #332491 — Copilot start a new session and consume tokens automatically

[https://github.com/microsoft/vscode/issues/332491](https://github.com/microsoft/vscode/issues/332491)

## Summary

Plausible real bug: in Autopilot mode, `ChatWidget.renderChatSuggestNextWidget()` auto-fires the next handoff (e.g. 'Start Implementation') based on the widget's current mode/permission state and last completed item — this is called from multiple session-switch code paths (`setModel`, `completedRequest` handler), so stale Autopilot permission or a race during navigation back/new-session could cause an unrelated/new session to auto-execute a handoff and burn tokens. Fresh report (same day), no corroborating comments yet, so keeping open for area-team investigation rather than closing.

## Change summary

After running a Plan in Autopilot mode, navigating back to the session list or starting a new session sometimes auto-triggers the 'Start implementation' handoff and consumes tokens without user action.

## Best solution

Chat/Agent Sessions team should audit `renderChatSuggestNextWidget()` and its call sites in src/vs/workbench/contrib/chat/browser/widget/chatWidget.ts (notably around `setModel`'s calls at lines ~2775 and ~2789, and the Autopilot auto-handoff branch at ~1697-1706) to ensure the auto-send-handoff check is scoped to the exact session/view-model instance and can't fire against a session the user has since navigated away from or a freshly created one.
