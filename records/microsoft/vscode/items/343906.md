# Issue #343906 — Moving a chat into another session and nesting a session can only be done by drag and drop

[https://github.com/microsoft/vscode/issues/343906](https://github.com/microsoft/vscode/issues/343906)

## Summary

The keyboard-accessibility gap remains in current main: users can reorder or promote nested chats, but cannot initiate either cross-session move without dragging. Keep this open as an accessibility bug in the Agents Window sessions list.

## Change summary

Make moving a nested chat into another session and nesting a single-chat session under another session operable without drag and drop.

## Best solution

Provide keyboard- and screen-reader-operable equivalents for both existing drag operations, preserving provider eligibility, move feedback, Undo, and selection behavior.
