Team-authored feature request to make undo confirmation dialogs less jarring. No implementation found on main; the existing `explorer.confirmUndo` setting controls undo confirmation levels but doesn't address the 'smooth/unobtrusive' UX goal described here. Stays open as valid unimplemented work.

## Change summary

Make undo actions less intrusive by replacing or softening the current modal confirmation pop-ups with unobtrusive UI patterns (e.g., toast notifications with undo affordance).

## Best solution
