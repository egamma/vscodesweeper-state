# Issue #100611 — Fail to load timeline info when activate timeline view using keyboard shortcut

[https://github.com/microsoft/vscode/issues/100611](https://github.com/microsoft/vscode/issues/100611)

## Summary

Team-authored issue — hard keep-open. The `files.openTimeline` command is designed as a context-menu action that expects a URI argument; when invoked via keyboard shortcut with no argument, it does nothing useful (the handler silently returns). The workaround (`timeline.focus`) is correct and documented by commenters.

## Change summary

The `files.openTimeline` command fails to load timeline info when invoked via keyboard shortcut because it expects a URI argument that isn't provided.

## Best solution

Either make `files.openTimeline` fall back to the active editor's URI when no argument is supplied (in `src/vs/workbench/contrib/timeline/browser/timeline.contribution.ts`, the `OpenTimelineAction.handler`), or deprecate/alias it in favor of `timeline.focus` for keyboard-shortcut use. The handler at line 72–80 silently returns when `arg` is not a URI — it should derive the URI from the active editor resource.
