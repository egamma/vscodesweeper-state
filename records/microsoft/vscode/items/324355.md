# Issue #324355 — TreeView scrolling performance degradation caused by MenuService with heavy context menus

[https://github.com/microsoft/vscode/issues/324355](https://github.com/microsoft/vscode/issues/324355)

## Summary

Genuine performance bug in MenuService's menu rebuild path during TreeView scrolling, with an open PR (#324358) already submitted by the reporter that demonstrates ~35–40% renderElement time reduction through caching. Keeping open for the PR to land.

## Change summary

TreeView scrolling performance degrades to 100–200 ms animation frames when extensions register heavy context menus, due to repeated sorting and context-key-expression processing in MenuService on every render cycle.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/324358, which caches sorted menu arrays, stable MenuRegistry arrays, and ContextKeyExpression.keys() results — the fixes are localized to `src/vs/platform/actions/common/menuService.ts` and the menu registry, with measured 35–40% improvement.
