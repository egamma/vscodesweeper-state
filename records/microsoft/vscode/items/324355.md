# Issue #324355 — TreeView performance degradation caused by MenuService with heavy context menus

[https://github.com/microsoft/vscode/issues/324355](https://github.com/microsoft/vscode/issues/324355)

## Summary

Real, well-diagnosed performance issue in MenuService's `_sort`/`_collectContextKeysAndSubmenuIds`/`getMenuItems` path for TreeView item rendering with heavy `view/item/context` menu contributions; the reporter already opened a fixing PR, so this should stay open pending that PR's review/merge rather than being closed now.

## Change summary

Large `view/item/context` menu contributions (own or from other installed extensions) cause repeated, expensive menu rebuild/sort work during TreeView scrolling and expand/collapse, degrading rendering FPS.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/324358 (caches stable MenuRegistry arrays, sorted MenuInfo results, and ContextKeyExpression.keys()), then evaluate the reporter's follow-up idea of per-view/per-extension menu contribution buckets as a separate, larger design discussion.
