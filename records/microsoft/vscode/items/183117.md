# Issue #183117 — Select previous word in JSON string sometimes also selects `"`, but not always

[https://github.com/microsoft/vscode/issues/183117](https://github.com/microsoft/vscode/issues/183117)

## Summary

Keep open for a decision on quote boundaries during word navigation. Current source explains the reported difference as deliberate separator grouping, but the accepted Backlog item has neither a verified fix nor a canonical duplicate.

## Change summary

Make backward word navigation and selection stop inside the opening quote of punctuation-only JSON strings, as they do for ordinary text strings.

## Best solution

Decide whether string delimiters should form independent word-navigation boundaries in the shared editor word-operations area. Preserve existing punctuation navigation elsewhere unless a broader behavior change is explicitly accepted.
