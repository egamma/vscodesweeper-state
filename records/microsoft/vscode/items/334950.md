# Issue #334950 — Codex customizations should publish writable migration destinations

[https://github.com/microsoft/vscode/issues/334950](https://github.com/microsoft/vscode/issues/334950)

## Summary

The defect remains source-reproducible on current main: Codex still omits empty destinations and publishes existing instruction and native-skill containers as non-writable. This member-authored issue should remain open for a bounded Codex customization fix.

## Change summary

Publish real writable Codex customization destinations for supported workspace and user agent, instruction, and skill migrations, including empty destinations.

## Best solution

Make the Codex customization snapshot consistently include every supported writable workspace and user destination, while retaining synthetic read-only containers only for effective catalog display. The shared source-folder and migration services should then work without Codex-specific behavior.
