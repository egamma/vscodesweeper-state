# Issue #347810 — BYOK custom reasoning effort values are filtered out by Copilot harness (Local supports them)

[https://github.com/microsoft/vscode/issues/347810](https://github.com/microsoft/vscode/issues/347810)

## Summary

Keep open as a BYOK parity feature request: current main deliberately restricts Copilot effort values to a shared vocabulary, including provider-advertised values. The existing aliases and capability overrides do not support custom values either.

## Change summary

Allow Copilot BYOK models to expose and forward provider-advertised custom reasoning efforts without widening other models' accepted values.

## Best solution

Support model-scoped custom reasoning efforts throughout Copilot BYOK publication, session creation, and model switching, while preserving standard-model validation and bounded telemetry classifications.
