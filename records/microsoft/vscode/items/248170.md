# Issue #248170 — Cannot connect to MCP server via SSE using trusted developer certificate

[https://github.com/microsoft/vscode/issues/248170](https://github.com/microsoft/vscode/issues/248170)

## Summary

The root cause — Electron's boringssl being stricter than plain Node.js for self-signed and server-auth certificates in `tls.getCACertificates` — was likely addressed by commit 015aef6054c (distro bump, shipped in 1.115.0), but no maintainer or reporter has confirmed this issue is resolved, and some commenters reported broader TLS failures beyond just dotnet dev certs. Keeping open for confirmation.

## Change summary

MCP servers using HTTPS with trusted self-signed developer certificates (e.g. dotnet dev-certs) fail to connect from VS Code because Electron's Node.js TLS validation is stricter than standalone Node.js.
