# Issue #168954 — Jupyter: move cell up/down buttons

[https://github.com/microsoft/vscode/issues/168954](https://github.com/microsoft/vscode/issues/168954)

## Summary

The move cell up/down commands exist but are only surfaced in the cell toolbar overflow menu (and only when drag-and-drop is disabled). The request for visible primary toolbar buttons remains unimplemented; 28 upvotes and active team discussion justify keeping this open.

## Change summary

Add visible move-cell-up/down buttons to the notebook cell toolbar instead of burying them in the overflow menu behind a setting.

## Best solution

Make the move-up/down buttons configurable as primary cell toolbar actions (visible by default or user-configurable via the toolbar customization mechanism discussed in comment 11). The commands already exist in `cellCommands.ts`; the change is surfacing them in a primary toolbar group rather than gating on `config.notebook.dragAndDropEnabled === false`.
