# Issue #286478 — Copilot sending backtick followed by a number is always seen as vscodecontentref

[https://github.com/microsoft/vscode/issues/286478](https://github.com/microsoft/vscode/issues/286478)

## Summary

Verified duplicate of #295507, which was fixed in commit f340d3616a8 (PR #296201). Both issues describe the same root cause: inline references falling inside an unclosed backtick code context render as literal `_vscodecontentref_` URLs. The fix detects unclosed code contexts and emits plain labels instead of markdown links.

## Change summary

When the model outputs text with a backtick followed by a number (e.g. .NET generic type `List`1`), subsequent inline references render as raw `http://_vscodecontentref_/N` URLs instead of interactive widgets.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/295507 — the fix in commit f340d3616a8 (PR #296201) added `isInsideCodeContext` detection to `annotateSpecialMarkdownContent`, which prevents inline reference links from being emitted inside unclosed code spans or fenced blocks. No further change needed.
