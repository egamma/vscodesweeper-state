# Issue #263499 — Split individual chat response parts to list rows

[https://github.com/microsoft/vscode/issues/263499](https://github.com/microsoft/vscode/issues/263499)

## Summary

The architectural refactoring to split response parts into individual list rows has not been implemented. The renderer still renders all parts within a single response element, and the related tracking issue #290490 lists this as outstanding work.

## Change summary

Long chat responses render all parts in a single list element, causing editor freezes when opening sessions with long agent trajectories.

## Best solution

Refactor the chat list renderer so response parts become child rows in the tree/list, enabling incremental/virtualized rendering. This is tracked as part of the broader chat perf work in https://github.com/microsoft/vscode/issues/290490.
