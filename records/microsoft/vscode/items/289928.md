# Issue #289928 — Feature: Register github.copilot.chat.review.patches command

[https://github.com/microsoft/vscode/issues/289928](https://github.com/microsoft/vscode/issues/289928)

## Summary

This requests a new public command on the Copilot extension to let third-party extensions invoke code review on arbitrary patches. The command doesn't exist on main, the referenced PR #3120 is in another repo, and VS Code's extension API is not the right channel for external extensions to drive Copilot review programmatically — this is an API/integration request that belongs in the Copilot extension's own planning, not an external feature request.

## Change summary

Add a `github.copilot.chat.review.patches` command so external extensions can invoke Copilot code review on arbitrary diffs/patches.

## Best solution

This is an extension-API surface request: external extensions want to programmatically invoke Copilot's review on arbitrary patches. The right path is for the Copilot team to decide whether to expose such an API as part of their extension's contract. Since Copilot Chat is a built-in extension in this repo, the feature request is in-scope for microsoft/vscode — but it needs a product decision from the Copilot team on whether to expose a public command for third-party consumption. Keeping it open for team routing is reasonable; closing as out-of-scope is also defensible since exposing internal commands as public API requires deliberate design.
