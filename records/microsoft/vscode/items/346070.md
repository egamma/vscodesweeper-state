## Summary

Both reported defects remain in current source: native Claude models advertise no vision support, and image attachments become text references rather than image blocks. Keep this report open because the older capability-labeling issue covers only the first half.

## Change summary

Make pasted images usable in Claude sessions through accurate model capabilities and actual image content in outgoing prompts.

Native Claude image-capable models should advertise vision, and supported attached images should reach Claude directly in ordinary and steering messages.
