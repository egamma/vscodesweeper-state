# Issue #346070 — Agent Host (Claude): pasted images are marked unsupported on native Claude models, and the Claude prompt resolver never sends image blocks

[https://github.com/microsoft/vscode/issues/346070](https://github.com/microsoft/vscode/issues/346070)

## Summary

Both defects remain in current source: native Claude models advertise no vision support, and image attachments reach the SDK only as textual references. Keep this report open because the earlier capability-labeling issue covers only the first defect.

## Change summary

Make Claude image attachments accurately advertised and delivered as image content rather than requiring a discretionary Read tool call.

## Best solution

Provide consistent image-input support across native and Copilot-routed Claude sessions, covering both model capabilities and SDK message construction while preserving ordinary file references.
