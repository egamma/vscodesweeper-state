# Issue #25391 — Editor drag and drop mouse feedback missing

[https://github.com/microsoft/vscode/issues/25391](https://github.com/microsoft/vscode/issues/25391)

## Summary

The underlying UX gap remains on main: editor text dragging uses a generic arrow for moves rather than prominent drag feedback. Keep this open as editor drag-and-drop polish pending a UX decision.

## Change summary

Provide clearer mouse-pointer feedback while dragging selected text within the editor.

## Best solution

Choose a cross-platform move/drag cursor or drag image for editor text moves while preserving the existing copy cursor when the modifier key is held, implemented in the editor drag-and-drop contribution.
