# Issue #25391 — Editor drag and drop mouse feedback missing

[https://github.com/microsoft/vscode/issues/25391](https://github.com/microsoft/vscode/issues/25391)

## Summary

Keep open for a UX decision about clearer text-drag feedback. Current source changes the pointer to a generic arrow for moves and a copy cursor for copies, but this does not establish that the reporter's request for prominent dragging feedback is satisfied.

## Change summary

Provide recognizable mouse-pointer feedback while dragging selected text within the editor.

## Best solution

Make an active text drag clearly distinguishable from ordinary pointing, with consistent move-versus-copy feedback in the editor drag-and-drop contribution. First assess the existing arrow and copy cursors on macOS and agree whether a more explicit drag affordance is needed.
