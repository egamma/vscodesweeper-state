# Issue #320818 — Regression: spaces render too wide with a custom monospaced font

[https://github.com/microsoft/vscode/issues/320818](https://github.com/microsoft/vscode/issues/320818)

## Summary

The cross-browser reproduction supports the existing upstream classification: the custom font renders spaces too widely in both desktop VS Code and vscode.dev in Chrome. Keep this open while the Chromium font-rendering regression is isolated and reported upstream.

## Change summary

A custom monospaced font that aligned correctly in VS Code 1.110.1 renders spaces wider than other single-cell characters in newer Chromium-based builds.

## Best solution

Reduce this to a standalone Chromium HTML/font reproduction that compares U+0020 and U+00A0, then track the resulting Chromium issue here. VS Code should retain the report until the responsible Chromium behavior or a safe editor-side compatibility measure is identified.
