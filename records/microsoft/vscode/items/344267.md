# Issue #344267 — Chat slash-command autocomplete hides long hyphenated plugin skill names when searching by plugin prefix

[https://github.com/microsoft/vscode/issues/344267](https://github.com/microsoft/vscode/issues/344267)

## Summary

The reported failure is present in current main: suffix aliases precede the namespaced command and can push its plugin prefix beyond the fuzzy matcher's 128-character search window. Keep this open as a bounded chat-completion bug.

## Change summary

Long hyphenated plugin skill names disappear from slash-command suggestions when searched by plugin prefix, despite remaining discoverable by suffix.

## Best solution

Ensure chat slash-command filtering preserves plugin-prefix discoverability for long skill names while retaining suffix matching and existing command insertion behavior. Cover the reported names with regression assertions in the existing prompt slash command matching suite.
