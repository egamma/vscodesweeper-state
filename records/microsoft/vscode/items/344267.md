# Issue #344267 — Chat slash-command autocomplete hides long hyphenated plugin skill names when searching by plugin prefix

[https://github.com/microsoft/vscode/issues/344267](https://github.com/microsoft/vscode/issues/344267)

## Summary

The reported filtering defect remains in current main: suffix aliases precede the namespaced command, pushing its plugin prefix beyond the fuzzy scorer's 128-character limit. Keep this open for a bounded autocomplete correction.

## Change summary

Keep long hyphenated plugin skills discoverable in slash-command autocomplete when searching by plugin prefix.

## Best solution

Make plugin-prefix matching independent of accumulated suffix-alias length while preserving suffix discovery, existing command labels, and insertion behavior.
