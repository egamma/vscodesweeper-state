# Issue #338493 — Agent Customizations: Keep row actions aligned when status indicators are shown

[https://github.com/microsoft/vscode/issues/338493](https://github.com/microsoft/vscode/issues/338493)

## Summary

Confirmed on main: for MCP server rows with a compatibility warning/error but no runtime state icon, McpServerItemRenderer.updateStatus appends the compatibility icon directly into the trailing `.mcp-server-actions` container before the management buttons, shifting Start/toggle/overflow controls versus rows without a compatibility icon — exactly the misalignment shown in the report.

## Change summary

Compatibility status icon is inserted into the trailing action area, misaligning row controls (Start button, enablement toggle, overflow menu) versus rows without a status icon.

## Best solution

Move the compatibility icon out of `.mcp-server-actions` and place it inline with the compatibility message (the `.mcp-server-compatibility-message` element already rendered in the secondary line via `updateMcpCompatibilityMessage`), so the actions container only ever holds actual action controls and stays aligned across rows.
