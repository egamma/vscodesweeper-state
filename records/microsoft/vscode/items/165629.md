# Issue #165629 — [Notebooks] - "go to most recently failed cell" still in toolbar after restarting kernel and clearing outputs

[https://github.com/microsoft/vscode/issues/165629](https://github.com/microsoft/vscode/issues/165629)

## Summary

Still reproduces on main — the failed-cell listener only watches cell add/remove, not metadata changes when outputs are cleared or kernel restarted. An open PR (#282613) is attempting the fix, so this stays open pending that PR's review and merge.

## Change summary

The 'Go to most recently failed cell' toolbar button persists after restarting the kernel or clearing outputs because the execution state service doesn't listen for metadata changes.

## Best solution

Review and land (or close) https://github.com/microsoft/vscode/pull/282613, which adds an `onDidChangeInternalMetadata` listener to clear the failed-cell state when `lastRunSuccess` becomes `null`. The fix is in `src/vs/workbench/contrib/notebook/browser/services/notebookExecutionStateServiceImpl.ts`.
