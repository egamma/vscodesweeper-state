## Summary

Team-authored bug report with a root cause already identified by a second maintainer (chat list renderer re-renders on send/scroll/session load, causing vertical jitter while a Mermaid diagram streams). No fix has landed yet, so this stays open per the team-authored keep-open rule.

## Change summary

## Best solution
