# Issue #336283 — Prevent GitHub Copilot Voice Mode from talking to me while muted.

[https://github.com/microsoft/vscode/issues/336283](https://github.com/microsoft/vscode/issues/336283)

## Summary

Fresh, well-reasoned request against a young core feature (Agents Voice Mode): mic mute only gates capture, not TTS playback, so Copilot keeps talking while the user is muted — a real gap, not covered by existing settings.

## Change summary

Muting the microphone in GitHub Copilot Voice Mode should also suppress or defer spoken progress/completion updates instead of letting Copilot talk over the muted user.

## Best solution

Have voice mode treat mic-mute as a signal to suppress or queue TTS playback (progress updates and completion summaries), likely in voiceSessionController.ts / the ttsPlaybackService, with a short deferred summary offered on unmute — needs a product decision on the exact UX, not a mechanical fix.
