# Issue #289101 — Proposal: Allow for a `reason` to be included in a `TextEdit`

[https://github.com/microsoft/vscode/issues/289101](https://github.com/microsoft/vscode/issues/289101)

## Summary

Keep open: current TextEdit objects do not carry source-edit reasons, and the cited formatting helpers still return edits without provider attribution. An open draft PR explores that attribution path, but does not settle the broader TextEdit proposal.

## Change summary

Allow TextEdit objects to carry an optional source-edit reason that consumers can use when attribution is otherwise unavailable.

## Best solution

Evaluate the attribution approach in https://github.com/microsoft/vscode/pull/289177 before deciding whether reason metadata belongs on individual TextEdit objects or alongside a provider's edit batch. The intended end state is reliable formatter attribution through edit transformation and application without losing existing caller-supplied reasons.
