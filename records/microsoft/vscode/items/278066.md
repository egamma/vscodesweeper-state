# Issue #278066 — Adopt gh.com private marketplace policy

[https://github.com/microsoft/vscode/issues/278066](https://github.com/microsoft/vscode/issues/278066)

## Summary

Active team plan-item for enterprise private marketplace support via gh.com API endpoint. The existing infrastructure supports private marketplace via GPO policy (`extensions.gallery.serviceUrl`), but the gh.com dynamic endpoint adoption and client-side de-duplication logic described here are not yet implemented. Keep open as planned work.

## Change summary

Adopt a gh.com API endpoint that returns private marketplace URLs per enterprise, with client-side de-duplication when a user belongs to multiple enterprises or has both GPO and gh.com configuration.

## Best solution

Implement the gh.com endpoint consumption in the gallery manifest service (likely `extensionGalleryManifestService.ts`), with client-side logic to pick the first enterprise with a private marketplace policy set and to prefer gh.com over GPO when both are configured. The open design questions (multi-enterprise de-dupe, GPO vs gh.com precedence) noted in the issue and comments should be resolved by the team before implementation.
