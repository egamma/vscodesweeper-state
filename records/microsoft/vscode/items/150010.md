# Issue #150010 — Testing: regarding to refreshHandler 

[https://github.com/microsoft/vscode/issues/150010](https://github.com/microsoft/vscode/issues/150010)

## Summary

Keep open: extension-initiated test discovery still lacks a controller-level way to participate in the Test Explorer's refresh/cancel lifecycle. The existing progress API covers the progress bar, but not the requested cancellation control.

## Change summary

Let extensions expose automatic test rediscovery as controller-level activity, showing progress and replacing Refresh with Cancel even before any TestItem exists.

## Best solution

Provide a testing API contract for extension-initiated discovery activity that integrates with the existing refresh progress and cancellation lifecycle. Preserve the distinction between discovery and test execution, and define how cancellation and overlapping discovery operations behave.

- **Current public API:** src/vscode-dts/vscode.d.ts:18451–18545 defines TestController, including refreshHandler at line 18522. Its documentation describes a callback invoked by the refresh button and recommends filesystem watchers for realtime updates; it exposes no controller-level discovery activity or busy-state API.
- **Refresh lifecycle remains workbench-owned:** src/vs/workbench/contrib/testing/common/testServiceImpl.ts:355–381 sets testing.isRefreshing and manages cancellation tokens within refreshTests/cancelRefreshTests. src/vs/workbench/contrib/testing/browser/testExplorerActions.ts:1723–1793 switches Refresh and Cancel using that context key and wraps the refresh action in view progress. Reporting unrelated view progress does not enter this lifecycle.
- **Calling the handler directly is insufficient:** src/vs/workbench/api/common/extHostTesting.ts:168–173 stores refreshHandler and updates controller capabilities; $refreshTests at lines 387–388 invokes it from the workbench. An extension calling its own discovery callback does not pass through TestService.refreshTests and therefore does not activate its refresh/cancel state.
