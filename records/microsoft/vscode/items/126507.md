# Issue #126507 — [scss] map value override => identifier expected

[https://github.com/microsoft/vscode/issues/126507](https://github.com/microsoft/vscode/issues/126507)

## Summary

The SCSS validator still appears to reject valid Sass module-variable assignment, with multiple independent confirmations through December 2025. The On Deck milestone does not bar triage, but there is no verified fix or older canonical issue owning the same observable diagnostic.

## Change summary

Accept assignments to variables qualified by a Sass module namespace without reporting `scss(css-identifierexpected)`.

## Best solution

Update the SCSS parser used by the built-in CSS language features so a namespaced variable can appear on the left side of an assignment, while preserving normal identifier diagnostics for invalid selectors and declarations.
