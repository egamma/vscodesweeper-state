# Issue #344359 — Automations: "Done" button feels broken

[https://github.com/microsoft/vscode/issues/344359](https://github.com/microsoft/vscode/issues/344359)

## Summary

Keep open: archiving works, but Automations history still mixes archived and active sessions without the explicit treatment requested. This team-authored usability issue needs a presentation decision, not a judgment close.

## Change summary

Make the result of marking an automation run Done clearly visible in Automations history, with an archived indicator, section, or filter.

## Best solution

Give archived automation runs a persistent, understandable treatment in Automations history while preserving access to their conversations and Restore action. Decide whether this is an explicit row indicator or a separate archived section/filter before implementation.
