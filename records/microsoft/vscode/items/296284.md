# Issue #296284 — Copilot Review appears to do nothing in a Jupyter Notebook

[https://github.com/microsoft/vscode/issues/296284](https://github.com/microsoft/vscode/issues/296284)

## Summary

The Copilot Review feature in notebooks fails to surface results to the user — the inline overlay doesn't work in notebook cells and no fallback reveals the Comments panel. Still present on main with no fix found.

## Change summary

Copilot Review in Jupyter Notebooks completes silently without showing results to the user; results are only visible if the user manually opens the Comments tab.

## Best solution

When review comments are added for a notebook document and the inline overlay cannot be shown, the review service should fall back to revealing the Comments panel (via `workbench.panel.comments.focus` or similar) so users can see and navigate the results. The fix likely lives in `extensions/copilot/src/platform/review/vscode/reviewServiceImpl.ts` — detect the notebook context and reveal the panel as a fallback.
