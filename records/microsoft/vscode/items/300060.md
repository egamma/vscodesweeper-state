# Issue #300060 — Startup Profiler timeout (15s delay) and IPC failure on Fedora 42 (KDE Plasma/Wayland)

[https://github.com/microsoft/vscode/issues/300060](https://github.com/microsoft/vscode/issues/300060)

## Summary

The exact 'FAILED to start profiling for renderer/extHost' failure reported here was a real CLI bug (malformed debug-port args), already fixed and shipped — current main no longer has the buggy code, so this can be closed as completed rather than attributed to Fedora/D-Bus.

## Change summary

`code --prof-startup` fails to connect to the renderer/extHost inspector ports and hits a 15s timeout, producing a near-useless profile.

## Best solution

Keep the shipped fix in commit 72cfebb6ffada6ae87d98440dddeed88b9968cd8 (PR #307849, 1.116.0); the CLI now passes bare ports to `--remote-debugging-port`/`--inspect-brk-extensions` instead of `host:port`, which is what broke CDP/inspector connections. No further action needed beyond asking the reporter to confirm on a current build.
