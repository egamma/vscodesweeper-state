# Issue #125310 — iPad: context menu appears when releasing a long tap

[https://github.com/microsoft/vscode/issues/125310](https://github.com/microsoft/vscode/issues/125310)

## Summary

Still reproduces on main: the Gesture class in touch.ts dispatches the Contextmenu event only inside onTouchEnd (after finger release), never during the hold. The iOS-native behavior would fire it while the finger is still down.

## Change summary

On iPad, the context menu only appears after releasing a long tap instead of appearing while the finger is still held down.

## Best solution

Add a timer-based context menu trigger in `src/vs/base/browser/touch.ts` that fires the Contextmenu gesture event after HOLD_DELAY elapses during `touchstart`/`touchmove`, without waiting for `touchend`. Platform detection (iOS vs Windows) may be needed per the discussion to respect native conventions.
