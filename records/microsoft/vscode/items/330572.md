# Issue #330572 — Expose peer-chat discovery and stable chat identifiers for agent-host sessions

[https://github.com/microsoft/vscode/issues/330572](https://github.com/microsoft/vscode/issues/330572)

## Summary

A concrete, well-scoped Agent Host feature request that isn't yet covered by the existing session server tools — worth keeping open for product/maintainer scoping rather than closing.

## Change summary

Add session-scoped peer-chat discovery (list siblings, get own reference) and by-title messaging between chats in the same Agent Host session, plus an optional 'Copy Chat Reference' UI action.

## Best solution

Extend the existing session server-tool surface in src/vs/platform/agentHost/node/shared/sessionServerTools.ts (alongside send_message/create_chat/get_current_session) with a session-scoped list-chats tool and a way to resolve/target a peer chat by title, rather than requiring an already-known agent-host-session:// link from create_chat.
