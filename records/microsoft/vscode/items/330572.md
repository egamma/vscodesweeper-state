# Issue #330572 — Expose peer-chat discovery and stable chat identifiers for agent-host sessions

[https://github.com/microsoft/vscode/issues/330572](https://github.com/microsoft/vscode/issues/330572)

## Summary

Keep open as a feature request: current orchestration tools can message a known chat reference, but do not expose sibling-chat discovery or the invoking peer chat's own reference. No verified older canonical covers the same observable limitation.

## Change summary

Expose session-scoped discovery, stable chat references, and messaging for manually created peer chats.

## Best solution

Extend the Agent Host orchestration surface so agents can discover manually created peers and obtain their own stable reference, with clearly attributed incoming messages. Establish session-membership and title-ambiguity semantics before exposing the capability.
