# Issue #348707 — Agents window: new session after deleting the dev container fails because the new container is stopped

[https://github.com/microsoft/vscode/issues/348707](https://github.com/microsoft/vscode/issues/348707)

## Summary

Keep open: the current lifecycle code allows idle shutdown during reconnect and pending first-send preparation, consistent with the maintainer's diagnosis. The existing area labels are appropriate.

## Change summary

Prevent idle auto-stop from stopping a replacement Dev Container while a new Agents window session is starting.

## Best solution

Make container inactivity accounting respect reconnect and pending session startup, including when a previously queued stop finally executes. Preserve normal idle shutdown and explicit archive/delete cleanup.
