# Issue #305818 — Detect, surface, and recover orphaned Copilot Chat sessions from moved/renamed/deleted workspaces

[https://github.com/microsoft/vscode/issues/305818](https://github.com/microsoft/vscode/issues/305818)

## Summary

A real recovery gap remains for sessions orphaned by workspace moves or renames outside an active VS Code transition. The request has reached the Backlog with 64 upvotes and should remain open under the chat area.

## Change summary

Discover, browse, and safely relink local Copilot Chat sessions whose original workspace path no longer exists.

## Best solution

Add workspace-independent discovery metadata for local chat sessions, surface unavailable workspaces in Chat history, and provide an explicit relink/import flow. Keep automatic path heuristics advisory so sessions are never silently associated with the wrong project.
