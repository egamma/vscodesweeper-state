# Issue #232857 — Incorrect scaling detection on Linux (GNOME)

[https://github.com/microsoft/vscode/issues/232857](https://github.com/microsoft/vscode/issues/232857)

## Summary

Keep open in the existing Electron/Linux area: multiple reporters confirm incorrect scaling, and switching to native Wayland reportedly avoids it. No concrete fixing commit or canonical issue covering the same dynamic scale-change failure was established.

## Change summary

Changing a secondary monitor's scaling on GNOME incorrectly scales VS Code on the primary monitor and can leave its content and window decorations mismatched.

## Best solution

Resolve monitor-specific scale-change handling in Electron/Chromium's Linux display backend, then confirm that changing the secondary monitor's scale leaves the primary-monitor window correctly sized and usable. Native Wayland is a reported workaround, not established complete coverage, particularly given the reported IME tradeoff.
