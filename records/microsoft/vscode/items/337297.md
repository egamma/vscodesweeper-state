# Issue #337297 — Workspace picker: use compact Remove icon and tighten submenu spacing

[https://github.com/microsoft/vscode/issues/337297](https://github.com/microsoft/vscode/issues/337297)

## Summary

Fresh, well-scoped UI polish request confirmed against current main: the remove action still renders the regular `close` codicon (not the compact variant), and the toolbar/submenu-indicator CSS still leaves a fixed 10px margin creating the visible gap in the screenshot.

## Change summary

In the workspace picker's Use Local / Use Dev Container submenu rows, use the compact close icon for Remove and reduce the gap between the Remove icon and the submenu chevron.

## Best solution

Swap `Codicon.close` for `Codicon.closeCompact` in the toolbar-remove action of `actionList.ts`, and tighten the `.action-list-item-toolbar` / `.action-list-submenu-indicator` margins in `actionWidget.css` for the inline-description layout used by the workspace picker submenu rows.
