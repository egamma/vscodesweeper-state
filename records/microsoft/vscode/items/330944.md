# Issue #330944 — vscode Agents Window + Editor combined (alt+tab) experience 

[https://github.com/microsoft/vscode/issues/330944](https://github.com/microsoft/vscode/issues/330944)

## Summary

The Agents Window already provides the requested single-window workflow: users can switch between chat-only, combined chat/editor, and maximized editor presentations with built-in commands and keybindings.

## Change summary

Provide a single-window Agents experience with quick switching between agent-focused and code-focused views.

## Best solution

Keep the existing single-pane Agents Window workflow: Toggle Side Panel switches between chat-only and the combined editor/detail pane, while Maximize Editor Area provides a code-focused presentation.

## Vision fit

- **Fit:** aligned
- **Reason:** Fast movement between agent work and code editing directly supports VS Code's AI-assisted development and core workbench UX themes.
- **Evidence:** Durable themes: AI-assisted development and Workbench & core UX.

  > Thanks for the suggestion. The Agents Window now supports this workflow in one window: **Toggle Side Panel** (`workbench.action.agentToggleSidePanel`, Ctrl/Cmd+Alt+B) switches between chat-only and the combined editor/detail pane, and **Maximize Editor Area** (Ctrl/Cmd+Alt+E) switches to a code-focused view.

## Evidence

- **built-in commands:** src/vs/sessions/contrib/layout/browser/baseSessionLayoutController.ts registers `workbench.action.agentToggleSidePanel` with Ctrl/Cmd+Alt+B; src/vs/sessions/contrib/editor/browser/editor.contribution.ts registers `workbench.action.agentSessions.maximizeMainEditorPart` and its restore counterpart with Ctrl/Cmd+Alt+E.
- **existing implementation:** https://github.com/microsoft/vscode/commit/afd0948308e3e953b514def11be67cefd46e894e, merged before this report, maps the side-panel command to the editor pane in the single-pane Agents layout.
