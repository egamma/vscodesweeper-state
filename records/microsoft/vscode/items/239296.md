# Issue #239296 — Console stacktraces when resizing window/pane using fish shell and tide prompt

[https://github.com/microsoft/vscode/issues/239296](https://github.com/microsoft/vscode/issues/239296)

## Summary

Legitimate bug confirmed by multiple users — EPIPE errors when resizing the terminal with fish shell + tide prompt (async prompt rendering). No fix found on main; the maintainer's diagnostic questions were answered but no resolution was reached. Keeping open as a real terminal defect affecting fish+tide users.

## Change summary

Resizing the terminal pane with fish shell and tide prompt causes unhandled EPIPE errors printed to the console.

## Best solution

The EPIPE occurs because tide's async prompt re-rendering writes to a pipe that's been closed during resize. The fix likely involves either handling EPIPE gracefully in the PTY write path (src/vs/platform/terminal/node/terminalProcess.ts) or ensuring the resize sequence doesn't break the pipe mid-write. The xterm.js layer should also be investigated — the maintainer asked the reporter to test the xterm.js demo but that wasn't possible. The terminal team should attempt reproduction with fish+tide locally.
