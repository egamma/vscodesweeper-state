# Issue #321676 — Revisit pricing properties for Agent Host Copilot CLI/SDK scenarios

[https://github.com/microsoft/vscode/issues/321676](https://github.com/microsoft/vscode/issues/321676)

## Summary

Keep open as protocol-design debt. Current main adds a validated TypeScript facade for pricing metadata, but both Agent Host model contracts still transport it through an open `_meta` bag, so the requested protocol-shape decision remains unresolved; this is also a protected team-authored issue.

## Change summary

Decide whether Agent Host pricing metadata should become a strongly typed protocol field instead of remaining in the generic `_meta` property bag.

## Best solution

Have the Agent Host Protocol owners decide whether pricing is a stable first-class `SessionModelInfo` contract or intentionally namespaced extensible metadata, then update the source protocol and VS Code's generated copy consistently. Keep error-code metadata as a separately bounded follow-up unless the chosen contract establishes a common typed extension mechanism.
