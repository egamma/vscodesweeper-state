# Issue #335331 — Outdated JSDoc on TextEditor.viewColumn ("when the editor column is larger than three")

## Summary

Confirmed on main: the JSDoc for TextEditor.viewColumn still claims the value is undefined 'when the editor column is larger than three,' but extHostTypeConverters.ts's ViewColumn.to() returns position + 1 unconditionally for any valid group column, so the cap-at-three behavior no longer exists. An open PR already fixes this exact wording, so this stays open pending review/merge rather than being closed now.
