# Issue #335331 — Outdated JSDoc on TextEditor.viewColumn ("when the editor column is larger than three")

[https://github.com/microsoft/vscode/issues/335331](https://github.com/microsoft/vscode/issues/335331)

## Summary

The JSDoc really is outdated — traced in the checkout: `ViewColumn.to()` in extHostTypeConverters.ts returns `position + 1` for any valid group column, so `viewColumn` is never `undefined` merely for being beyond column three. An open PR already proposes the exact one-line doc fix, so this should stay open pending that PR landing rather than being closed now.

## Change summary

The `TextEditor.viewColumn` JSDoc in vscode.d.ts still claims the value is `undefined` when the editor column is larger than three, which hasn't been true since `ViewColumn` was expanded and the converter made dynamic.

## Best solution

Merge the linked PR https://github.com/microsoft/vscode/pull/335335 which removes the obsolete clause from src/vscode-dts/vscode.d.ts; no further investigation needed once that lands.
