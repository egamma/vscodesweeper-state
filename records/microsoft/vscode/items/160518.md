# Issue #160518 — Command palette and customize layout hide behind the WCO

[https://github.com/microsoft/vscode/issues/160518](https://github.com/microsoft/vscode/issues/160518)

## Summary

The Windows native-WCO case remains reproducible from current source: quick input is centered into the full window while its window-control avoidance is enabled only for custom-drawn controls. This should remain open as a bounded quick-input/title-bar regression.

## Change summary

In a narrow Windows window, the Command Palette and Customize Layout quick pick extend beneath the native window-control overlay.

## Best solution

Keep top-aligned quick inputs within the unobscured title-bar bounds whenever native WCO controls are present, including after window resizing or restoring a dragged position, without changing custom/hidden-control behavior.
