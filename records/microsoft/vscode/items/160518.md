# Issue #160518 — Command palette and customize layout hide behind the WCO

[https://github.com/microsoft/vscode/issues/160518](https://github.com/microsoft/vscode/issues/160518)

## Summary

This is the canonical issue for titlebar items being obscured by Window Controls Overlay on narrow windows. Multiple duplicates (#170349, #197988, #199450) point here. No fix commit references this issue, and the titlebar CSS does not guard against the overlap. Confirmed and still valid on main.

## Change summary

Command palette and layout customization controls hide behind WCO (min/max/close) buttons when the VS Code window is resized narrow.

## Best solution

The titlebar layout (src/vs/workbench/browser/parts/titlebar/) needs to account for WCO bounding rect width when computing available space for titlebar-right items, preventing them from rendering underneath the window controls. This likely involves CSS or layout logic changes in titlebarPart.ts and titlebarpart.css to respect the WCO geometry.
