# Issue #331202 — Given a chat group trying to dock a chat to the bottom shows a drag affordance that doesn't work

[https://github.com/microsoft/vscode/issues/331202](https://github.com/microsoft/vscode/issues/331202)

## Summary

The bug remains on current main: dragging a group's sole chat over its own bottom edge displays a split affordance, but the drop handler deliberately treats that operation as a no-op. Keep this open for a bounded Agents Window fix.

## Change summary

Hide the unusable split affordance when a group's sole chat is dragged onto an edge of its own group.

## Best solution

Make the chat-grid drop overlay reflect whether the prospective operation is valid: a sole chat dragged over its own group must not advertise an edge split, while valid cross-group moves and multi-tab splits remain available.
