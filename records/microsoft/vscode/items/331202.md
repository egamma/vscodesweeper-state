# Issue #331202 — Given a chat group trying to dock a chat to the bottom shows a drag affordance that doesn't work

## Summary

Team-authored bug (lramos15, MEMBER) with an assigned real milestone (1.135.0) — both hard keep-open rules apply, so this cannot be proposed for closure regardless of any other evidence.

## Change summary

Dragging a chat group in the Agents Window toward a bottom-dock position shows a drag affordance (drop indicator) even though bottom-docking isn't actually supported there, unlike editor group layouts which suppress the affordance for invalid drop targets.

## Best solution

In the Agents Window drag-and-drop controller (src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts, the onDragOver/onHeaderDragOver logic around SessionsListDragAndDrop), suppress the drop-effect/indicator when the target position isn't a valid dock location, mirroring how the editor group's drag-and-drop controller already hides the affordance for unsupported drop zones.
