# Issue #207521 — If a URI contains an authority component, then the path component must either be empty or begin with a slash ("/") character

[https://github.com/microsoft/vscode/issues/207521](https://github.com/microsoft/vscode/issues/207521)

## Summary

The root cause — a URI path missing a leading slash when authority is present during terminal split — was fixed in commit da7155bb4f5 and shipped in 1.121.0. The fix addresses exactly the code path shown in the original and subsequent stack traces.

## Change summary

Creating or splitting a terminal in a remote/multi-root workspace throws a UriError because the cwd path lacks a leading slash when the URI has an authority component.

## Best solution

Keep the shipped fix (da7155bb4f5, 1.121.0). No further change needed — the URI path is now correctly prefixed with '/' when authority is present in `_splitTerminal`.
