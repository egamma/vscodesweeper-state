# Issue #207521 — If a URI contains an authority component, then the path component must either be empty or begin with a slash ("/") character

Verified duplicate: the URI error in `_splitTerminal` was fixed by commit da7155bb4f5 (May 2026), which was tracked and closed via the error-telemetry issue #316035. The stack traces match the same code path.

## Change summary

Creating or splitting a terminal with a remote authority throws a UriError because the cwd path lacks a leading slash.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316035 — the fix (prepend `/` to the path when an authority is present) already landed in commit da7155bb4f5 and shipped in Insiders. No further work needed.
