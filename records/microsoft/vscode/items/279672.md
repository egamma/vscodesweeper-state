[https://github.com/microsoft/vscode/issues/279672](https://github.com/microsoft/vscode/issues/279672)

## Summary

Valid feature request to add GPO/policy support for the `github-enterprise.uri` setting. The infrastructure exists in VS Code (the `policy` field on configuration properties), but it has not been added to this setting. A team member acknowledged it without a timeline — keeping open on On Deck.

## Change summary

Allow enterprise admins to configure the GitHub Enterprise URL via system-wide GPO/MDM policy rather than requiring per-user configuration.

## Best solution

Add a `policy` field to the `github-enterprise.uri` configuration registration in `extensions/github-authentication/package.json`, following the existing pattern in `src/vs/platform/configuration/common/configurationRegistry.ts`. This is a small change but requires a product decision on the policy name and whether it should be restrictive or a default.
