## Summary

Keep open: manual enterprise URL configuration exists, but the checked-in enterprise policy catalog does not expose it for GPO deployment. The setting has since gained a plural replacement, so the policy contract needs to account for both configuration forms.

## Change summary

Allow administrators to provision GitHub Enterprise instance URLs centrally through Windows Group Policy.

Provide an administrator-managed enterprise instance configuration through the existing extension-configuration policy system, with documented behavior for the current plural setting and deprecated singular setting. Preserve ordinary user configuration when no policy is present.
