# Issue #307817 — Background compaction can replay tool invocations and duplicate side effects

[https://github.com/microsoft/vscode/issues/307817](https://github.com/microsoft/vscode/issues/307817)

## Summary

Keep open: duplicate external side effects remain unverified, not disproven. Background summarization now reuses rendered messages rather than rerendering tool-bearing history, but the supplied trigger and observed result suffice for a targeted retest; no concrete fix was established for this broader report.

## Change summary

Prevent background compaction or summarize/resume from executing a pending logical tool invocation twice and duplicating external side effects.

## Best solution

Establish whether the current local-agent compaction path can still duplicate a pending invocation, using a controlled side-effecting tool. The finished behavior should preserve one execution and one interactive wait point per logical invocation without suppressing intentionally repeated tool calls.
