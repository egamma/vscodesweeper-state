# Issue #302104 — Debian/apt: unhelpful update notifications

[https://github.com/microsoft/vscode/issues/302104](https://github.com/microsoft/vscode/issues/302104)

## Summary

Keep this accepted, community-supported request open: current Linux update handling still offers a separate download without detecting package-managed installations. Older work overlaps the notification problem, but does not fully cover this report's additional request for timely APT repository publication.

## Change summary

Make Debian-installed VS Code respect package-manager updates and avoid advertising downloads while the APT repository lacks the advertised release.

## Best solution

Package-managed Debian installations should not offer an unnecessary manual download, and update announcements should be consistent with repository availability. Coordinate the overlapping Linux update UX work with https://github.com/microsoft/vscode/issues/43671 and investigate publication delays using https://github.com/microsoft/vscode/issues/301149.
