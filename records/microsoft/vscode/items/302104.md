# Issue #302104 — Debian/apt: unhelpful update notifications

[https://github.com/microsoft/vscode/issues/302104](https://github.com/microsoft/vscode/issues/302104)

## Summary

Valid feature request with strong community support (32 upvotes, promoted to Backlog). The Linux update service doesn't detect deb/apt installation and always offers a manual download — no existing setting or code path suppresses this for package-manager installs. Stays open as the canonical tracker.

## Change summary

When VS Code is installed via apt/deb, suppress the 'Download Update' button since updates should come through the package manager.

## Best solution

Detect the installation method on Linux (deb/rpm package vs tarball) in `src/vs/platform/update/electron-main/updateService.linux.ts` and suppress the download-update UI when installed via a system package manager, directing users to their package manager instead. The APT repo lag (#301149) is a separate infrastructure concern.
