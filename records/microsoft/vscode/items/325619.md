# Issue #325619 — C# triple quotes are auto closed even when every auto-close setting is set to never/disabled

[https://github.com/microsoft/vscode/issues/325619](https://github.com/microsoft/vscode/issues/325619)

## Summary

The auto-closing behavior for C# triple quotes (raw string literals) is almost certainly caused by the external `ms-dotnettools.csharp` extension, not VS Code core. The built-in C# language configuration defines only a standard `"` auto-closing pair, and the core auto-closing logic at `src/vs/editor/common/cursor/cursorTypeEditOperations.ts:217` explicitly returns null when `autoClosingQuotes` is `"never"`. The extra quotes must originate from the external extension's auto-edit or formatting providers. This issue should be moved to the C# extension's tracker.

## Change summary

Typing triple quotes in a C# file produces six quotes even when all auto-close settings are set to never.

## Best solution

Move this issue to https://github.com/dotnet/vscode-csharp where the C# extension team can investigate whether their auto-edit or on-type-formatting provider for raw string literals respects the editor's `autoClosingQuotes` setting.
