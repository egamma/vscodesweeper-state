# Issue #333459 — Report issue window asked for confirmation before closing window

[https://github.com/microsoft/vscode/issues/333459](https://github.com/microsoft/vscode/issues/333459)

## Summary

Traced the classic (non-wizard) issue reporter flow and confirmed the reporter window is designed to stay open after filing, but the only close-confirmation suppression is wired to the Cmd/Ctrl+W keydown handler — there's no post-submit UI state (e.g. auto-close or a clear "issue filed" message) covering other ways of closing the window, matching the confusing modal and busted styling mjbvz reports.

## Change summary

After successfully filing an issue via the Report Issue window, closing the window still shows a "your input will not be saved" confirmation instead of auto-closing or confirming the issue was filed.

## Best solution

In src/vs/workbench/contrib/issue/browser/baseIssueReporterService.ts and electron-browser/issueReporterService.ts (classic reporter) and issueReporterOverlay.ts/issueReporterEditorPane.ts (wizard reporter), give the window a clear post-submit state — either auto-close after createIssue()/submitToGitHub() succeeds, or update the close-confirmation copy/flow to reflect that the report was already filed, and fix the overlay styling that renders 'busted' behind the modal in that state.
