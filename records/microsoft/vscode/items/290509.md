## Evidence

- **Editor identity collision on current main:** extensions/git/src/commands.ts:4754-4784, Commands._viewStash, uses stash.hash for displayed diff contents but constructs multiDiffSourceUri from stash@{stash.index}. After creating B, both the existing A editor and the newly requested B editor have the stash@{0} source identity. src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditorInput.ts:299-305 compares editors by that source URI, conclusively exposing the reported collision without executing the checkout.
- **Actions resolve the shifted index:** extensions/git/src/commands.ts:4724-4751, getStashFromUri, parses the stored index and looks it up in the current stash list. stashPopEditor (4592-4600), stashApplyEditor (4627-4635), and stashDropEditor (4673-4681) use that result, so an editor displaying A can operate on B after creation shifts A's index. Wrong targeting is established; actual data loss was not demonstrated.
