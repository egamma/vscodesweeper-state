# Issue #344559 — Agent host: viewing a non-resident Copilot CLI session resumes the SDK session and replays its whole event journal

[https://github.com/microsoft/vscode/issues/344559](https://github.com/microsoft/vscode/issues/344559)

## Summary

Keep open: the discussion independently confirms repeated host-side restore delays, and current source still allows history reads to resume cold SDK sessions. Existing event filtering reduces replay overhead but does not eliminate the reported restore path.

## Change summary

Opening a non-resident Copilot CLI chat resumes its SDK session and reconstructs its history before returning the subscription snapshot.

## Best solution

Make viewing completed Copilot chats independent of execution-runtime restoration and avoid repeatedly reconstructing unchanged history. Preserve transcript fidelity and bounded memory use while keeping unrelated host sessions responsive.
