# Issue #332808 — Unwanted `.claude` folder and `.claude.json` file

[https://github.com/microsoft/vscode/issues/332808](https://github.com/microsoft/vscode/issues/332808)

## Summary

Confirmed, root-caused bug (a 1.134 regression left a stale Claude Agent SDK cache that 1.135 then reuses, causing unwanted claude.exe execution/network calls) with a maintainer-identified fix plan (bump the pinned SDK version) that has not yet landed on main; a real version milestone (1.136.0) is assigned, so this stays open per the milestone keep-open rule regardless.

## Change summary

VS Code 1.135 silently creates a `.claude`/`.claude.json` cache and launches `claude.exe` (triggering firewall prompts) even for users who never touched the Claude agent feature, due to a stale SDK download cached by a bug in 1.134.

## Best solution

Land the SDK version bump maintainer TylerLeonhardt described (updating `build/agent-sdk/agents/claude/package.json`/lockfile) so the cache key changes and the stale 1.134 download is no longer reused; separately address the `VSCODE_AGENT_HOST_CLAUDE_AGENT_ENABLED` env var still being set even when `chat.agentHost.claudeAgent.enabled` is false per the last comment.
