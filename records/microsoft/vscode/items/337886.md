## Summary

Confirmed on main: `buildOptions` in claudeSdkOptions.ts unconditionally sets `disallowedTools: ['WebSearch']`, even though the file already computes `isProxy` to gate other proxy-only settings (ANTHROPIC_BASE_URL, subprocess env). The stated rationale (CAPI doesn't support WebSearch) only applies to the proxy transport, not native Anthropic auth. An open PR already proposes the fix, so this should stay open pending that PR rather than being treated as a fresh implementation task.
