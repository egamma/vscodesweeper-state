## Summary

Confirmed from source: `buildOptions` in claudeSdkOptions.ts hardcodes `disallowedTools: ['WebSearch']` for both transports even though the restriction is only needed for the CAPI proxy path, and an open PR (#337887) already proposes the transport-scoped fix — keeping this open pending that PR's review/merge rather than closing early.

## Change summary

Claude agent host disables WebSearch for native (Anthropic-auth) sessions even though the restriction only applies to the Copilot proxy transport.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/337887, which scopes `disallowedTools: ['WebSearch']` to `transport.kind === 'proxy'` using the same `isProxy` flag already used for `ANTHROPIC_BASE_URL`/subprocess env, so native sessions regain WebSearch.
