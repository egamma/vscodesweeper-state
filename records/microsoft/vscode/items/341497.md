# Issue #341497 — Ask and Plan missing from agent picker — VS Code 1.141.0

[https://github.com/microsoft/vscode/issues/341497](https://github.com/microsoft/vscode/issues/341497)

## Summary

Thanks for the report. The thread points to the session target defaulting to the Copilot (Agent Host) harness instead of Local, and that harness does not offer Ask/Plan or Configure Tools. This looks like an intentional default rollout rather than a defect, but the discoverability and parity gap deserves a maintainer's look, so I'm keeping it open.

## Change summary

Ask and Plan modes and Configure Tools disappear from the chat picker when the session target is Copilot, which has become the default for some users.

## Best solution

Maintainers should decide whether the Copilot harness should gain Ask/Plan parity, or whether the default should remain Local for users who relied on those modes. If neither, the UI should make the session-target switch discoverable.
