# Issue #310829 — Agent mode can access other Agent files through vscode-userdata uris, other modes or sub-agents can't

[https://github.com/microsoft/vscode/issues/310829](https://github.com/microsoft/vscode/issues/310829)

## Summary

This is primarily a usage and API question rather than an actionable defect: custom agents cannot inherit another agent definition by reading its generated cache file, although extensions can enumerate available agents through a proposed API.

## Change summary

Allow a custom agent or subagent to reuse the built-in Plan agent definition without invoking Plan as a subagent.

## Best solution

Keep shared planning behavior in the custom agent, an instruction file, or a reusable skill rather than depending on Copilot's generated global-storage cache. Extensions needing discovery can use the proposed `vscode.chat.getCustomAgents` API, while `.agent.md` files themselves cannot invoke that extension API.
