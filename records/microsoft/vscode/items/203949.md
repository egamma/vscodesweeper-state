# Issue #203949 — Search: allow multi-select and open in editor

[https://github.com/microsoft/vscode/issues/203949](https://github.com/microsoft/vscode/issues/203949)

## Summary

The requested bulk-open operation remains missing: Search supports multiple selection, but its opening actions still operate on the focused result only. Keep this accepted Backlog request open; the related requests inspected do not own the same Search-view behavior.

## Change summary

Allow selected files in Search results to be opened together as individual editors.

## Best solution

Provide a selection-aware opening action in the Search view that opens each selected file as an individual editor, preserving the existing single-result navigation behavior.

## Evidence

- **Existing selection support:** src/vs/workbench/contrib/search/browser/searchView.ts:994 enables multipleSelectionSupport. Its onContextMenu method also forwards the selected elements, so selection itself is already available.
- **Remaining capability gap:** OpenMatchAction and OpenMatchToSideAction in src/vs/workbench/contrib/search/browser/searchActionsNav.ts both call SearchView.open with tree.getFocus()[0], rather than opening the selection. SearchView.open in searchView.ts:2239 resolves one resource and calls IEditorService.openEditor once.
- **Similarly named command is different:** src/vs/workbench/contrib/searchEditor/browser/searchEditor.contribution.ts:349-374 registers search.action.openInEditor as Open Results in Editor and invokes createEditorFromSearchResult for the search results. This creates a Search Editor, not individual editors for selected files.
- **Older related request is a different surface:** https://github.com/microsoft/vscode/issues/55146 is open and predates this issue, but its body requests multiple selection and opening all matches in Quick Open. It does not establish ownership of bulk opening selected entries in the Search results tree, so it does not meet the re-review duplicate bar.
- **Historical report does not resolve this request:** https://github.com/microsoft/vscode/issues/41623 is closed and concerns successive search-result openings replacing the preview editor. The maintainer's answer at https://github.com/microsoft/vscode/issues/41623#issuecomment-358052208 describes opening individual results in another editor group, not opening a selection together.
