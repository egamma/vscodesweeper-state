# Issue #263129 — Easy "#selection" addition in Chat

[https://github.com/microsoft/vscode/issues/263129](https://github.com/microsoft/vscode/issues/263129)

## Summary

Keep this open for the chat UX owner: current main now automatically exposes editor selections as implicit context and lets users pin them, but the issue's accepted polish direction has not been explicitly declared complete. The existing polish label and maintainer statement that the implicit-context flow was being improved also bar a judgment close.

## Change summary

Make it easier to accumulate selected editor ranges in chat without repeatedly typing `#selection` or moving focus between the editor and chat input.

## Best solution

Have the chat UX owner decide whether the current implicit-selection and Pin Selection flow fully satisfies the request or whether selections should additionally be insertable as editable text in the prompt. Preserve the low-friction ability to select and accumulate multiple ranges without repeatedly focusing the chat input.
