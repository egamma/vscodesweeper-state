# Issue #329308 — Support custom icons for custom agents in the chat agent picker (`icon` frontmatter in `.agent.md`)

## Summary

Just entered Backlog Candidates (bot comment posted yesterday, 60-day upvote window just started) and has 0 upvotes so far — per policy this stays open as a feature request under community consideration, not closed for lack of traction yet.

## Change summary

Add an `icon` frontmatter field to `.agent.md` custom agents so they render a codicon in the chat agent picker, matching built-in modes.

## Best solution

Genuine, well-scoped gap: `CustomChatMode.icon` in src/vs/workbench/contrib/chat/common/chatModes.ts hard-codes `constObservable(undefined)` and `PromptHeaderAttributes` in promptFileParser.ts has no `icon` field, so custom agents can never show an icon today. Implementation would touch the frontmatter parser, `CustomChatMode`, and `modePickerActionItem.ts` rendering — worth tracking for backlog promotion if it gathers upvotes.
