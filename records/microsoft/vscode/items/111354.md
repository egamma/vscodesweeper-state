# Issue #111354 — Code Lens Should Respect Command's Enablement

[https://github.com/microsoft/vscode/issues/111354](https://github.com/microsoft/vscode/issues/111354)

## Summary

The requested command-disable behavior remains missing on current main, and a maintainer explicitly endorsed disabling rather than hiding the CodeLens. This team-authored Backlog request should remain open.

## Change summary

Render CodeLens commands as disabled when their contributed command enablement clause evaluates false.

## Best solution

Resolve each CodeLens command's registered precondition, update its enabled state when relevant context keys change, and block invocation through both mouse and accessible command-picker paths while disabled. This likely belongs in the CodeLens controller and widget.
