# Issue #330745 — Agents window: Keep Add Tab visible when the editor area is hidden

[https://github.com/microsoft/vscode/issues/330745](https://github.com/microsoft/vscode/issues/330745)

## Summary

Valid, well-traced UX gap in the Agents window's new single-pane detail layout: the Add Tab menu is gated on the editor group actually being present (`IsTopRightEditorGroupContext` in the `addTabLayoutWhen` clause), so it disappears whenever the editor area is hidden — this is current design, not a defect, and needs a UX decision rather than a mechanical fix.

## Change summary

In the Agents window single-pane detail panel, hide/show the editor area also hides the Add Tab (+) affordance, making it feel dependent on an unrelated toggle.

## Best solution

Design an Add Tab affordance that stays available in the detail-only state (e.g. render it in the detail panel's own header rather than the editor group's title bar), likely touching src/vs/sessions/contrib/editor/browser/addTabActions.ts (the `addTabLayoutWhen`/`IsTopRightEditorGroupContext` gating) and the single-pane layout controller; this is squarely Agents-window UX work already flagged by related issues #324359, #325498, #329781.
