# Issue #247984 — Enabling Tree Sitter removes minty fields in builtInExtensionsCG.ts

[https://github.com/microsoft/vscode/issues/247984](https://github.com/microsoft/vscode/issues/247984)

## Summary

Still reproduces on main: the tree-sitter TypeScript highlights query (`build/node_modules/tree-sitter-typescript/queries/highlights.scm`) lacks `property_identifier` captures, so property accesses lose their theme-specific coloring (e.g. Night Owl's mint fields) when tree-sitter is enabled. The JavaScript highlights query has `(property_identifier) @property` but the TypeScript one does not.

## Change summary

Enabling tree-sitter for TypeScript drops syntax highlighting for property identifiers (fields), removing theme-specific coloring such as Night Owl's mint-colored fields.

## Best solution

Add `(property_identifier) @property` (and possibly `(shorthand_property_identifier)` and member-expression property captures) to the TypeScript tree-sitter highlights query, mirroring the JavaScript query's existing captures. This likely requires updating the upstream `tree-sitter-typescript` grammar queries or overriding them in the VS Code build.
