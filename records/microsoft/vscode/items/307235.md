# Issue #307235 — Copilot Chat randomly switched to Cloud Agent

[https://github.com/microsoft/vscode/issues/307235](https://github.com/microsoft/vscode/issues/307235)

## Summary

Team-authored bug report about the cloud agent unexpectedly activating and creating PRs without user intent. No fix commit references this issue, and the underlying cause (how the cloud agent setting got enabled without user action) is unclear — keeping open for investigation.

## Change summary

Copilot Chat unexpectedly started cloud agent sessions that created PRs when the user only asked questions, with no indication of how the cloud agent setting became enabled.

## Best solution

Investigate how `chat.cloudAgent.enabled` can become enabled without explicit user action — possibly via an A/B experiment flag or a default-true setting. Consider adding a confirmation prompt or clearer UX before the cloud agent creates PRs, and ensure the session type picker makes the active session type obvious so users are never surprised by cloud agent behavior.
