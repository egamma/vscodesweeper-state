# Issue #287781 — Investigate why SI warning shows when rich is enabled

[https://github.com/microsoft/vscode/issues/287781](https://github.com/microsoft/vscode/issues/287781)

## Summary

The SI warning banner ('Enable shell integration to improve command detection') can still appear even when rich shell integration is active, due to a timing/state issue in `refreshShellIntegrationQuality`. The accessibility-specific fix in commit 7133939e50f only addressed the screen-reader + pwsh case; the general case described here remains unfixed on main.

## Change summary

The 'Enable shell integration' warning shows in the Terminal output channel when running a command from Copilot in a non-background terminal, even though rich shell integration is already active.

## Best solution

Investigate the timing gap between terminal creation (where `shellIntegrationQuality` starts at `None`) and the post-execution `refreshShellIntegrationQuality` call at line 2453 of `runInTerminalTool.ts`. The `refreshShellIntegrationQuality` method in `toolTerminalCreator.ts` (line 135) only upgrades quality if command detection capability is present — the root cause likely involves the capability not being available at the moment `refreshShellIntegrationQuality` is called, despite rich SI being active. The fix should ensure the quality is reliably upgraded before the banner decision at line 2455.
