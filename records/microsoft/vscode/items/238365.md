# Issue #238365 — Wrong Keyboard Layout and ignored settings - happens on `vscode.dev`

[https://github.com/microsoft/vscode/issues/238365](https://github.com/microsoft/vscode/issues/238365)

## Summary

The saved keyboard layout is still ignored during browser startup: the service applies it before layout definitions finish loading, then initialization unconditionally starts autodetection. Keep this open; the current source explains the reload failure.

## Change summary

Honor the explicitly selected keyboard layout after reloading vscode.dev instead of reverting to an automatically detected or US layout.

## Best solution

Browser keyboard-layout initialization should preserve a valid explicit keyboard.layout selection, with the active mapper and status-bar indicator agreeing after reload. Retain automatic detection when the setting is autodetect.
