# Issue #345469 — Enable preview for alerts in issue reporter preview

[https://github.com/microsoft/vscode/issues/345469](https://github.com/microsoft/vscode/issues/345469)

## Summary

The issue reporter's local preview does not enable the alert syntax already supported by the shared renderer. Keep this request open; the related Markdown Editor report concerns a separate rendering surface.

## Change summary

Render GitHub-style Markdown alerts in the issue reporter's Preview tab.

## Best solution

Support GitHub-style alerts in the reporter's local preview while preserving its existing Markdown safety restrictions and ordinary blockquote rendering.

## Evidence

- **Reporter capability gap:** src/vs/workbench/contrib/issue/browser/issueReporterOverlay.ts:816–825, renderDescriptionPreview(), renders new MarkdownString(text) without enabling alert syntax.
- **Existing renderer is opt-in:** src/vs/base/common/htmlContent.ts:50–69 defaults supportAlertSyntax to false. src/vs/base/browser/markdownRenderer.ts installs createAlertBlockquoteRenderer only when that flag is enabled; it supports NOTE, TIP, IMPORTANT, WARNING and CAUTION. The shared capability therefore exists but does not currently deliver the reporter's central ask.
- **Extension boundary:** src/vs/platform/markdown/browser/markdownRenderer.ts, MarkdownRendererService.render(), delegates to the built-in renderMarkdown implementation. The reporter does not use the Markdown extension preview pipeline, explaining why installing a Markdown preview extension does not enable alerts here.
- **Preview introduction:** https://github.com/microsoft/vscode/pull/343634 merged on 2026-10-23 and introduced the experimental reporter's Write/Preview tabs. It establishes the preview surface, not implementation of this alert request.
- **Related issue is not a canonical:** https://github.com/microsoft/vscode/issues/344931 is open, but its body concerns alerts in the experimental Markdown Editor, not the issue reporter. Its scope does not absorb this reporter-specific request.
