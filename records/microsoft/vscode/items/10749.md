# Issue #10749 — Improve editor.trimAutoWhitespace or cursor navigation

[https://github.com/microsoft/vscode/issues/10749](https://github.com/microsoft/vscode/issues/10749)

## Summary

Consolidate this request into the open SmartIndent issue, which explicitly covers placing the caret at the appropriate indentation when returning to blank lines with either the mouse or arrow keys. Disabling whitespace trimming is only a workaround, not the requested end state.

## Change summary

Preserve or recover the appropriate indentation when navigating back to blank lines without disabling automatic whitespace cleanup.

## Best solution

Deliver indentation-aware blank-line navigation through https://github.com/microsoft/vscode/issues/16998, retaining this report's requirement that automatic whitespace cleanup remain enabled. The alternative selective-trimming design is separately tracked in https://github.com/microsoft/vscode/issues/209939.
