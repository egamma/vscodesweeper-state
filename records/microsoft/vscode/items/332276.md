# Issue #332276 — External agent host sessions: user messages sent from VS Code show added metadata

[https://github.com/microsoft/vscode/issues/332276](https://github.com/microsoft/vscode/issues/332276)

## Summary

Genuine cross-client leak in the agent-host sync path: VS Code-only "host instructions" (rename hints, artifact-tool guidance, plan links, etc.) are appended to the outgoing turn and end up stored as part of the visible transcript, so external AHP clients (Copilot/ChatGPT/Claude apps) render this VS Code metadata as if it were part of the user's message.

## Change summary

When a chat session is shared between VS Code and an external agent-host app, messages sent from VS Code show extra host-injected metadata/instructions in the external app's conversation view.

## Best solution

In the agent host chat-contributions pipeline (src/vs/platform/agentHost/node/agentHostChatContributionsService.ts and agentSideEffects.ts, which turn per-contribution `instructions` into `hostInstructions` consumed by codexAgent.ts / claudeAgentSession.ts / copilotAgentSession.ts), either stop embedding these instructions in the persisted/visible transcript or mark them so other AHP clients can filter them out of the rendered conversation instead of showing raw appended text.
