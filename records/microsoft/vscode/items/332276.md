## Summary

The cross-client transcript mismatch remains actionable Agent Host polish: external ChatGPT and Claude views expose repository context alongside text entered in VS Code. This team-authored issue has no verified duplicate or explicitly linked fix, so it must remain open.

## Change summary

Keep VS Code-added repository and workspace context out of the user-message text rendered by external agent applications.

## Best solution

Preserve the exact user-authored text in provider-native conversation history while conveying repository, workspace, and host instructions through provider-supported non-user-message context channels. Cover Copilot, Codex/ChatGPT, and Claude independently so continuing an external session from VS Code remains interoperable.
