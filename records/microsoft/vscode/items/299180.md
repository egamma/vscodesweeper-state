# Issue #299180 — Session name should be the last user prompt in the session

[https://github.com/microsoft/vscode/issues/299180](https://github.com/microsoft/vscode/issues/299180)

## Summary

A real product gap remains: current main generates and preserves a title from the first request rather than tracking the latest prompt. The older issue covering the same stale-title symptom is closed, so it cannot serve as a duplicate canonical; keep this request open as under discussion.

## Change summary

Dynamically update a chat session's name from its most recent user prompt so the Sessions sidebar reflects the conversation's current focus.

## Best solution

Define a stable automatic-retitling policy for evolving chats, including when updates occur and how explicit user renames remain protected. The Sessions list should continue consuming the provider-owned title observable rather than independently deriving names from transcript rows.
