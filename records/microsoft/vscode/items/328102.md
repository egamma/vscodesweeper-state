# Issue #328102 — `grep_search.includePattern` still silently fails for backslash workspace-root prefixes on Windows

[https://github.com/microsoft/vscode/issues/328102](https://github.com/microsoft/vscode/issues/328102)

## Summary

The workspace-name separator defect remains in current source: prefix recognition splits only on forward slashes, so equivalent Windows backslash patterns lose their workspace scope. Keep this report open; the related older file_search issue describes a different observable failure and does not meet the re-review duplicate bar.

## Change summary

Make Windows backslash workspace-name-prefixed grep_search patterns resolve equivalently to their forward-slash counterparts.

## Best solution

Ensure explicit, recursive, and mixed-separator workspace-name prefixes select the intended root consistently on Windows, with regression coverage for root isolation. Preserve existing absolute-path, root-relative, single-root, and explicit-working-directory behavior.
