# Issue #328102 — `grep_search.includePattern` still silently fails for backslash workspace-root prefixes on Windows

[https://github.com/microsoft/vscode/issues/328102](https://github.com/microsoft/vscode/issues/328102)

## Summary

The remaining workspace-name separator defect is confirmed in current source: backslashes prevent the search adapter from recognizing and removing the root prefix. Keep this issue open; the older related report concerns a different observable globstar failure and does not satisfy the stronger duplicate bar for this re-review.

## Change summary

Make Windows backslash and mixed-separator workspace-name-prefixed grep_search patterns resolve equivalently to forward-slash patterns.

## Best solution

Provide separator-equivalent workspace-folder scoping at the Copilot search adapter boundary, preserving the core glob contract and existing search scopes. Cover explicit and recursive patterns through both input resolution and direct invocation.
