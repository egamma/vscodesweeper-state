# Issue #279275 — Inconsistent Sidebar Width Reset Behavior

[https://github.com/microsoft/vscode/issues/279275](https://github.com/microsoft/vscode/issues/279275)

## Summary

Keep open for the layout owner's decision: double-click currently fits the active view's preferred width rather than restoring a universal default. The reported difference remains in the source, but changing that established behavior requires a UX decision; neither a completed fix nor a qualifying duplicate was established.

## Change summary

Make double-clicking the primary sidebar boundary restore the same width regardless of the active view.

## Best solution

Resolve whether sidebar double-click should restore a uniform default or retain view-specific optimal sizing in SidebarPart.preferredWidth. If uniform sizing is accepted, preserve ordinary manual resizing and avoid expanding this issue into per-view width persistence or configuration.
