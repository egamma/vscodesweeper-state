# Issue #194322 — Process Explorer memory usage doesn't add up to Activity Monitor

[https://github.com/microsoft/vscode/issues/194322](https://github.com/microsoft/vscode/issues/194322)

## Summary

The mismatch remains on current main: Process Explorer derives memory from `ps` percentage-of-physical-memory data, which excludes memory categories reported by macOS Activity Monitor. The issue is already correctly routed and remains the canonical report.

## Change summary

Make Process Explorer report process memory accurately enough to identify the processes responsible for the memory shown by macOS Activity Monitor.

## Best solution

Define a meaningful cross-platform memory metric, collect an Activity Monitor-comparable footprint on macOS and an equivalent metric on Linux, and clearly label the displayed metric in Process Explorer.
