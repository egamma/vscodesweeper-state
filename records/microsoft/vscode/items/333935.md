# Issue #333935 — Agent Host: Copilot SDK tool-search override regressed after runtime Rust port

[https://github.com/microsoft/vscode/issues/333935](https://github.com/microsoft/vscode/issues/333935)

## Summary

Team-authored, reopened regression that multiple independent commenters (including one from today) confirm still reproduces on 1.137.0/1.138.0; the actual fix lives in the external github/copilot-agent-runtime repo (linked PR #18448), so this stays open pending that upstream fix landing and shipping.

## Change summary

The Copilot SDK/runtime's Rust port stopped honoring VS Code's tool_search_tool override (natural-language {query} schema, overridesBuiltInTool, toolSearch.enabled), so tool search silently falls back to the runtime's built-in regex search or direct tool invocation.

## Best solution

Land and ship github/copilot-agent-runtime#18448 (or an equivalent runtime fix), then bump the @github/copilot-sdk dependency in package.json and verify the override in src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts (_createClientSdkTools) is once again honored end-to-end.
