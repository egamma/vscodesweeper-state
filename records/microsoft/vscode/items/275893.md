# Issue #275893 — Chat confirmation buttons should be a toolbar for accessibility

[https://github.com/microsoft/vscode/issues/275893](https://github.com/microsoft/vscode/issues/275893)

## Summary

The accessibility gap remains in current source: confirmation actions are individually tabbable buttons without toolbar semantics or local arrow-key navigation. The linked report supplies the reproduction and explicitly separates this remaining work from the accessibility fixes completed there.

## Change summary

Make chat confirmation actions an accessible toolbar with arrow-key navigation rather than separate Tab stops.

## Best solution

Give the shared chat confirmation action rows standard accessible-toolbar behavior while preserving approval choices, dropdown actions, and focus restoration. Arrow keys within the action row must navigate its controls rather than switch the surrounding confirmation carousel.
