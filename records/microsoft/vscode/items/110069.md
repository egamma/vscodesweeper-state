# Issue #110069 — Suggestion details shown on the left of suggestion list hide text and cursor

[https://github.com/microsoft/vscode/issues/110069](https://github.com/microsoft/vscode/issues/110069)

## Summary

The left-side placement remains intentional but can obscure the cursor in narrow windows. This is a valid IntelliSense layout polish request, distinct from the configurable bottom-placement request.

## Change summary

Avoid positioning suggestion details over the code and cursor when horizontal space is constrained.

## Best solution

Refine `SuggestDetailsOverlay` to prefer a vertical placement when a west placement would obscure the active editing area, while keeping https://github.com/microsoft/vscode/issues/30140 focused on an explicit always-below option.
