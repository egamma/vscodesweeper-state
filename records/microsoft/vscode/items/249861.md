# Issue #249861 — Restoring multiple SSH workspaces fails when restoring more than one workspace

[https://github.com/microsoft/vscode/issues/249861](https://github.com/microsoft/vscode/issues/249861)

## Summary

Confirmed race condition in concurrent SSH session restore, with multiple community reproductions and an open community PR (#321348) that directly addresses it — keeping open for the PR to land or for a team fix.

## Change summary

Restoring multiple SSH remote windows simultaneously causes all but one to fail with AuthChallengeBadToken due to a connection-caching race condition.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/321348 (or an equivalent fix) which adds a pending-connections cache in `src/vs/platform/agentHost/node/sshRemoteAgentHostService.ts` to deduplicate concurrent connection attempts. The fix is small and localized.
