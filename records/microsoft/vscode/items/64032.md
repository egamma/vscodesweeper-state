# Issue #64032 — Emmet support for custom HTML tags / attributes

[https://github.com/microsoft/vscode/issues/64032](https://github.com/microsoft/vscode/issues/64032)

## Summary

Keep open: HTML custom data still does not feed Emmet's completion and expansion configuration. Custom Emmet snippets are a partial workaround, and neither related issue owns this remaining integration work.

## Change summary

Make custom HTML tag and attribute definitions available to Emmet so its features recognize them consistently.

## Best solution

Let Emmet consume the custom HTML definitions already supplied through html.customData and extension contributions, without requiring users to duplicate them as Emmet snippets. Establish the expected tag and attribute behavior before implementing the integration, then update the linked limitations documentation.
