# Issue #64032 — Emmet support for custom HTML tags / attributes

[https://github.com/microsoft/vscode/issues/64032](https://github.com/microsoft/vscode/issues/64032)

## Summary

Still a valid open request: while HTML custom data feeds into HTML language features, Emmet's own tag/attribute registry does not consume custom data, so custom HTML elements don't get full Emmet expansion support. Milestone is Backlog with 11 upvotes — stays open for the community process.

## Change summary

Custom HTML tags and attributes should be registered in Emmet's internal registry so all Emmet features (expansion, wrap, etc.) work with them.

## Best solution

Bridge the HTML custom data contribution point into Emmet's tag/attribute registry so that extensions providing custom element definitions also get Emmet expansion support for those elements. The work likely lives in `extensions/emmet/` and the `@vscode/emmet-helper` package.
