# Issue #334567 — Customization migration: Review link doesn't bring me to exact customizations to migrate

[https://github.com/microsoft/vscode/issues/334567](https://github.com/microsoft/vscode/issues/334567)

## Summary

Traced this in the source: the migration hint's `Review customizations` link only ever carries a coarse `{migration: true}` (file migrations) or `{section: McpServers}` argument, never a `revealUri`/`migrationCategory`, so clicking it can only land the user on a general page/tab, not the specific item — confirming the reporter's observation is a real gap, not a fluke of stale UI state.

## Change summary

Clicking `Review customizations` from the chat migration hint opens the Customizations UI but doesn't navigate to the specific customization(s) flagged for migration.

## Best solution

Extend `ICustomizationMigrationHint` (in customizationMigrationService.ts) to carry enough identity (e.g. a migrationCategory or revealUri) for the flagged item(s), and thread it through `computeMigrationHint` in customizationMigrationServiceImpl.ts and the reviewArguments construction in chatServiceImpl.ts so `OpenEditor` can call `revealCustomizationByUri`/pass a `migrationCategory` instead of only a generic section/migration flag.
