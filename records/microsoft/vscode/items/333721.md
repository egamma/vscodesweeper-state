# Issue #333721 — Got Error Open "New Chat Window" GitHub Copilot

[https://github.com/microsoft/vscode/issues/333721](https://github.com/microsoft/vscode/issues/333721)

## Summary

This is the exact same 'Not allowed to create elements in child window JavaScript context' crash reported (and fixed) in the identical, closed duplicate https://github.com/microsoft/vscode/issues/333729 — a maintainer confirmed the fix shipped in v1.136.0, and current main contains the guard.

## Change summary

Opening the Chat 'New Window'/auxiliary editor threw an error because a chat-pet host element was created against the auxiliary window's document, which forbids createElement.

## Best solution

Keep the shipped fix: `ChatPetWidgetCoordinator.createDormantHost()` in src/vs/workbench/contrib/chat/browser/widget/chatPetWidgetService.ts now explicitly builds the parked host in the main window realm (`dom.$('div')` against the main document) instead of the auxiliary window's, with a dedicated regression test ('parks the pet of an auxiliary window host in the main realm') asserting exactly this. Nothing further to change beyond confirming on the latest build.
