# Issue #241960 — The completions should show up if I use `sudo`

[https://github.com/microsoft/vscode/issues/241960](https://github.com/microsoft/vscode/issues/241960)

## Summary

Keep open: current source includes a sudo completion spec but does not provide the wrapped command's completions. The terminal maintainer acknowledged the missing behavior, and no verified canonical or landed implementation was found.

## Change summary

Provide terminal command and argument completions when a command is prefixed with sudo and its options.

## Best solution

Make terminal suggestions recognize the command position following sudo options and offer that command's normal subcommands, flags, and arguments afterward. Preserve sudo's own option completions and ensure accepting a suggestion leaves the sudo prefix intact.

Assert command suggestions at the wrapped command position, parity with unprefixed git subcommand/option suggestions afterward, and replacement ranges that preserve the prefix; retain coverage for sudo's own options and ordinary unprefixed commands.
- **Behavior:**

  > Terminal suggestions should recognize a command invoked through sudo rather than treating its entire tail as ordinary sudo arguments. At the command position after sudo and its options, offer executable suggestions; after a selected command, offer its normal subcommands, flags, and arguments. Accepting a completion must preserve sudo and its option values. Sudo option completion and unprefixed command completion must remain available.
- **Trace:**

  > The sudo spec in extensions/terminal-suggest/src/completions/upstream/sudo.ts already marks its positional argument isCommand: true. However, getTokenType in src/tokens.ts treats the position after sudo as TokenType.Argument, getCompletionItemsFromSpecs in src/terminalSuggestMain.ts only adds executable suggestions for TokenType.Command, and getFigSuggestions in src/fig/figInterface.ts chooses the spec from the first word. The isCommand recursion in src/fig/autocomplete-parser/parseArguments.ts is commented out, establishing why the bundled spec alone does not deliver the request. The existing Terminal Suggest tests exercise this provider with supplied specs, available commands, and mocked external execution, providing a validation seam. Preserve original cursor/replacement coordinates, sudo option-value handling, and non-sudo behavior; other wrappers and privileged execution are outside this request. The desired direction is recorded at https://github.com/microsoft/vscode/issues/241960#issuecomment-2683338678; planning should establish supported sudo invocation forms before implementation.
