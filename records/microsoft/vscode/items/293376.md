# Issue #293376 — GitHub Copilot fails to connect deployed model via Microsoft Azure AI Foundry — deployment loop and extension error

[https://github.com/microsoft/vscode/issues/293376](https://github.com/microsoft/vscode/issues/293376)

## Summary

The deployment loop is owned by the Microsoft Foundry Toolkit extension: its language-model provider emits the exact deployment prompt after deciding the model is not configured. This should close as caused by a non-VS Code-team-owned extension and continue in that extension's tracker.

## Change summary

Foundry Toolkit repeatedly treats an already deployed Azure AI Foundry model as undeployed when exposing it to Copilot.

## Best solution

Foundry Toolkit should correct its deployment-status reconciliation so a model that was deployed successfully is returned to VS Code's language-model API as configured.
