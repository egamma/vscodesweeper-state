# Issue #330722 — Agents Window: Left-align capability pills above the input

[https://github.com/microsoft/vscode/issues/330722](https://github.com/microsoft/vscode/issues/330722)

## Summary

The centering is intentional current behavior (documented in the CSS itself), not a bug — this is a legitimate polish request to change a deliberate design choice, best routed to the Agents Window/chat owners to weigh in on.

## Change summary

Capability pills (subagent, browser, background-activity) shown above the Agents window chat input are horizontally centered; the reporter wants them left-aligned with the input area instead.

## Best solution

This is a design decision, not a defect: `.session-chat-input-toolbar` in src/vs/sessions/contrib/chat/browser/media/sessionChatInputToolbar.css explicitly sets `justify-content: center` with a comment stating the pills are 'centered above the chat input' by design. Route to the Agents Window/chat UI owners to decide whether left-alignment better fits the input's design language; if agreed, the fix is a one-line change to that rule plus a check of chatTurnPills.css and sessionActivityPill.css for any width assumptions.
