# Issue #330722 — Agents Window: Left-align capability pills above the input

## Summary

Confirmed in source: the pill row above the Agents Window input is deliberately center-aligned (`justify-content: center`), matching the reporter's description exactly. This is a legitimate, low-risk visual-consistency ask already correctly labeled `polish`/`agents-window`, so it stays open for a maintainer to decide on the alignment change.

## Change summary

Capability pills (subagent, browser, etc.) shown above the Agents Window chat input are horizontally centered; the request is to left-align them with the input area instead.

## Best solution

If the team agrees left-alignment reads better, change `.session-chat-input-toolbar` in src/vs/sessions/contrib/chat/browser/media/sessionChatInputToolbar.css from `justify-content: center` to `justify-content: flex-start` and update the accompanying comment that currently documents the centering intent.
