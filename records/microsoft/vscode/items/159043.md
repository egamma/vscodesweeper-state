# Issue #159043 — Web doesn't pick up changes from desktop

[https://github.com/microsoft/vscode/issues/159043](https://github.com/microsoft/vscode/issues/159043)

## Summary

Keep open: Cloud Changes still transfers snapshots rather than continuously publishing subsequent desktop edits, so reloading web does not satisfy the requested roaming behavior. The maintainer suggested periodic storage and the reporter requested clearer handoff semantics; neither is grounds for an as-designed close of this accepted Backlog request.

## Change summary

Make the desktop-to-web continuation model clearer and address the expectation that later desktop edits become available when web reloads.

## Best solution

Decide whether Continue Working On should remain an explicitly explained snapshot handoff or support ongoing publication of changes. Preserve source edits and existing conflict safeguards unless a separate product decision explicitly changes those semantics.
