# Issue #159043 — Web doesn't pick up changes from desktop

[https://github.com/microsoft/vscode/issues/159043](https://github.com/microsoft/vscode/issues/159043)

## Summary

A real capability gap remains: Cloud Changes still does not continuously transfer desktop edits to web. Keep this open for a product decision on conflict-safe periodic storage and clearer Continue Working On semantics.

## Change summary

Automatically make edits created after a desktop-to-web transition available in the web workspace, or clarify that the transition is a one-time transfer.

## Best solution

Design conflict-safe periodic Cloud Changes storage for concurrent clients; until then, clearly tell the origin client that later edits are not transferred and provide an explicit store action.
