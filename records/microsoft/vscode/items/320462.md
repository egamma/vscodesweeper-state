# Issue #320462 — Recency order isn't preserved when searching for sessions

[https://github.com/microsoft/vscode/issues/320462](https://github.com/microsoft/vscode/issues/320462)

## Summary

Team-authored bug: when the sessions list find widget filters sessions, the filtered results lose the recency sort order established by `sortSessions()`. Still reproduces on main — no fix found in git history. Keeping open per team-author rule.

## Change summary

Searching/filtering sessions in the Agents window sessions list does not preserve the recency (updated/created) sort order — older sessions appear above newer ones in filtered results.

## Best solution

The `sortSessions()` helper in `sessionsList.ts` sorts by sort key before rendering, but the tree's `TreeFindMode.Filter` path may re-render the tree children without re-applying that sort. The fix likely belongs in the render pipeline around lines 1958–2017 of `sessionsList.ts` (the `filtered` → sections flow) or in how `WorkbenchObjectTree` `setChildren` is called after filtering — ensure the sort comparator is applied after the find-widget filter narrows the session set.
