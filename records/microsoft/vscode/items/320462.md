# Issue #320462 — Recency order isn't preserved when searching for sessions

[https://github.com/microsoft/vscode/issues/320462](https://github.com/microsoft/vscode/issues/320462)

## Summary

The defect remains on current main: entering a search query makes the generic Quick Pick sorter rank matches by fuzzy relevance instead of preserving the Sessions Picker's priority and recency order. This team-authored, accepted bug is parked in On Deck and should remain open for a focused fix.

## Change summary

Searching the Sessions Picker reorders matching sessions by fuzzy-match relevance, allowing old sessions to appear ahead of recent ones.

## Best solution

Filtering the Sessions Picker by title or workspace should retain the ordering already computed by its needs-input, unread, recently-opened, and other-session groups, including MRU order within each group.
