# Issue #29351 — [Feature request] Hide cursor while typing

[https://github.com/microsoft/vscode/issues/29351](https://github.com/microsoft/vscode/issues/29351)

## Summary

A real gap remains: current main cannot hide the pointer while typing, and no canonical issue owns the request. Keep this accepted Backlog feature open; its 132 community upvotes exceed the promotion threshold.

## Change summary

Add an option that hides the mouse pointer during keyboard input and restores it when the pointer moves.

## Best solution

Add an editor setting that temporarily applies a hidden pointer style after typing and restores the configured pointer style on mouse movement, focus loss, or editor disposal. This belongs in the editor input/view layer and must behave consistently across desktop and web platforms.
