# Issue #332622 — Insiders: New Chat Window throws error

[https://github.com/microsoft/vscode/issues/332622](https://github.com/microsoft/vscode/issues/332622)

## Summary

Reproducible on Insiders and traced in source: opening a new Chat Window/pet host tries to create a DOM element in a child (auxiliary) window's document, which the browser disallows, throwing a crash on New Chat Window. An open PR already targets this exact fix, so the issue should stay open until it merges.

## Change summary

Clicking 'New Chat Window' in Insiders 1.136.0 throws 'Not allowed to create elements in child window JavaScript context' and fails to open the window.

## Best solution

Land https://github.com/microsoft/vscode/pull/332696, which creates the parked/dormant chat pet host in the main window's document instead of the auxiliary window's document, then close this issue as fixed.
