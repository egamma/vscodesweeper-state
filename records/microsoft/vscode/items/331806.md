# Issue #331806 — Feature request: invoke multiple Agent Skills from any position in Copilot Chat messages

[https://github.com/microsoft/vscode/issues/331806](https://github.com/microsoft/vscode/issues/331806)

## Summary

Confirmed against current main: `tryToParseSlashCommand` in chatRequestParser.ts deliberately rejects a slash command once any non-whitespace text part precedes it, and only ever parses one slash-command part per message, so the reported behavior is real and by design today. This is a legitimate feature request for richer inline/multi-skill invocation, not a bug — it needs a product/UX decision, so it stays open.

## Change summary

Allow `/` to trigger Agent Skill/prompt-file autocomplete anywhere in a Copilot Chat message (not just at the start), and support selecting multiple skills as structured references/chips in one message.

## Best solution

This would require reworking `ChatRequestParser.tryToParseSlashCommand` (src/vs/workbench/contrib/chat/common/requestParser/chatRequestParser.ts, around lines 204-215) to permit slash matches after arbitrary text, plus composer/autocomplete changes in widget/input/editor/chatInputCompletions.ts and chatInputEditorContrib.ts to support multiple structured skill chips — a maintainer product call on composer UX, not a quick fix.
