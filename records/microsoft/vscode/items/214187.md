[https://github.com/microsoft/vscode/issues/214187](https://github.com/microsoft/vscode/issues/214187)

## Summary

The requested extension-controlled opt-out is still missing: current source prepends statusBarCommands to repository toolbars unconditionally. Keep this accepted Backlog request open; no verified canonical issue or landed implementation was found.

## Change summary

Allow SCM extensions to retain SourceControl.statusBarCommands in the status bar without also displaying them in SCM repository toolbars.

## Best solution

Provide an explicit, backward-compatible SCM API contract for status-bar-only commands, preserving existing toolbar behavior for extensions that do not opt out. Apply the contract consistently to both SCM repository-row surfaces without changing status bar presentation.
