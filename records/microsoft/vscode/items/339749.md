# Issue #339749 — Editor tab border color merges with editor group border color

[https://github.com/microsoft/vscode/issues/339749](https://github.com/microsoft/vscode/issues/339749)

## Summary

Traced in source: the new 2026 Dark theme (`extensions/theme-defaults/themes/2026-dark.json`) overrides `tab.border` with a solid color but never overrides `editorGroup.border`, so it inherits the semi-transparent `#FFFFFF17` from its `dark_modern.json` base — that transparency is exactly why the editor group border visually blends into the tab border in the screenshot.

## Change summary

In the new 2026 Dark theme, the editor group border looks like it bleeds into/merges with the tab border instead of reading as a distinct line.

## Best solution

Add an explicit, opaque `editorGroup.border` override to `extensions/theme-defaults/themes/2026-dark.json` (and verify `2026-light.json`, which already inherits an opaque value and looks unaffected) tuned to the new 2026 palette, the same way `tab.border` and `editorGroupHeader.tabsBorder` are already overridden there.
