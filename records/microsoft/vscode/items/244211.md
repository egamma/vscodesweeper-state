# Issue #244211 — Spurious configuration addon overlay creating fresh launch.json

[https://github.com/microsoft/vscode/issues/244211](https://github.com/microsoft/vscode/issues/244211)

## Summary

The bug remains present on current main: creating the first launch.json can leave the debug configuration picker open over the newly created file. The report has complete steps and the current source still contains the asynchronous path that allows the picker to outlive configuration creation.

## Change summary

Creating the first launch.json reveals the file but leaves a debugger-selection overlay covering the editor.

## Best solution

Ensure the debug configuration quick pick is dismissed once the selected debugger has created and opened launch.json, while preserving cancellation, multi-root folder selection, and normal Add Configuration behavior.
