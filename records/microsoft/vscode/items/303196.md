# Issue #303196 — getWorkerBootstrapUrl duplicates query parameters and mishandles fragments when scriptPath contains an existing query string or fragment

[https://github.com/microsoft/vscode/issues/303196](https://github.com/microsoft/vscode/issues/303196)

## Summary

The URL reconstruction defects remain in current main, including the additional case where a question mark inside a fragment is mistaken for a query delimiter. Keep this open for a bounded worker-bootstrap correction.

## Change summary

Preserve existing worker URL query parameters exactly once, replace existing fragments with the worker label, and distinguish query delimiters from question marks inside fragments.

## Best solution

Make worker bootstrap URL handling in src/vs/platform/webWorker/browser/webWorkerServiceImpl.ts respect query and fragment boundaries while preserving relative URL support, COI parameters, and existing cross-origin behavior.
