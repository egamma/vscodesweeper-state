# Issue #330046 — Unable to use keyboard to navigate to Release Notes button

[https://github.com/microsoft/vscode/issues/330046](https://github.com/microsoft/vscode/issues/330046)

## Summary

Team-authored, reopened accessibility bug with a confirmed reproduction (sbatten reproduced on macOS with video/screenshot evidence) — no fix commit exists on main, so this stays open per the team-authored keep-open rule and the reopened-issue bar.

## Change summary

Keyboard users cannot Tab/arrow-navigate from the Update button to the Release Notes button in the update notification popup, and the release notes keybinding isn't recognized while the update button has focus.

## Best solution

Fix keyboard focus traversal in the custom update tooltip widget (src/vs/workbench/contrib/update/browser/updateTooltip.ts), which manually manages tabIndex/arrow-key handling for its buttons (e.g. releaseNotesButton.tabIndex logic around line 406) — ensure Tab/Down-arrow correctly moves focus to the Release Notes button and that registered keybindings like Cmd+K Cmd+I are dispatched while the popup has focus.
