# Issue #162770 — errors thrown by openerService.resolveExternalUri not surfaced to MainThreadWindow.$asExternalUri in VS Code Web

[https://github.com/microsoft/vscode/issues/162770](https://github.com/microsoft/vscode/issues/162770)

## Summary

Resolver failures are still swallowed on current main for HTTP/HTTPS asExternalUri calls. Keep this open while the explicitly linked, still-open fix PR is reviewed; it is not yet completed work.

## Change summary

Expose external URI resolution failures to calling extensions instead of silently returning the original HTTP/HTTPS URI.

## Best solution

Review https://github.com/microsoft/vscode/pull/325925 against the agreed exception-propagation behavior, preserving the distinction between an unhandled HTTP/HTTPS URI and a genuine resolver failure. Keep this issue open until the accepted fix lands.
