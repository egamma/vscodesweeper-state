# Issue #334887 — Duplicate entries in Agent drop-down

[https://github.com/microsoft/vscode/issues/334887](https://github.com/microsoft/vscode/issues/334887)

## Summary

The duplicate rows remain possible on current main: custom agents are keyed and coalesced only by URI, so the same plugin agent discovered through distinct client and host URIs is rendered twice. This team-authored report should remain open until that discovery identity is reconciled.

## Change summary

Installing the frontend-web-dev plugin causes each of its two custom agents to appear twice in the Agents Window agent picker.

## Best solution

Reconcile client-synced and host-discovered representations of the same plugin agent before they reach ChatModes, while preserving genuinely distinct agents that happen to share a display name.
