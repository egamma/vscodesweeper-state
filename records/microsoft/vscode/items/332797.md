# Issue #332797 — Custom editor (e.g. Markdown preview) missing bottom border

[https://github.com/microsoft/vscode/issues/332797](https://github.com/microsoft/vscode/issues/332797)

## Summary

The missing bottom frame is a confirmed shared workbench rendering defect, not Markdown-extension behavior. It remains relevant on current main and should be routed to the Modern UI/layout owners.

## Change summary

Custom-editor-like surfaces render the editor frame on three sides but lose its bottom edge.

## Best solution

Make the shared editor card/frame remain visible above custom-editor webview overlays and other editor content, including in the Agents Window, without changing ordinary editor sizing or extension-provided content.

  > A custom editor such as the built-in Markdown editor must show the same complete editor frame as an ordinary editor, including the bottom edge. The Agents Window must preserve that bottom edge for its equivalent editor card. Acceptance requires all four edges to remain visible across default and compact Modern UI layouts without adding an inner border to extension content or changing editor dimensions.
- **Trace:**

  > Modern UI paints the editor card frame on `.part.editor` in src/vs/workbench/contrib/modernUI/browser/media/editorBorder.css. Custom editor content follows WebviewEditor.claimWebview in src/vs/workbench/contrib/webviewPanel/browser/webviewEditor.ts, then OverlayWebview mounts the iframe overlay at the workbench root and anchors it to the editor pane; floatingPanels.css supplies overlay corner clipping but no independent frame preservation. The Agents Window has parallel card rules in src/vs/sessions/browser/media/workbench.css and connected-frame rules in src/vs/sessions/browser/parts/media/editorPart.css. ## Evidence

- **confirmed reproduction:** The issue records independent confirmation in both the built-in Markdown custom editor and the Agents Window, establishing that this is shared workbench rendering rather than Markdown-specific styling.
- **editor frame path:** src/vs/workbench/contrib/modernUI/browser/media/editorBorder.css draws the Modern UI frame on `.part.editor` with an inside border and `overflow: hidden`; this is the shared frame whose bottom edge is reported missing.
- **custom editor overlay path:** src/vs/workbench/contrib/webviewPanel/browser/webviewEditor.ts anchors custom-editor webviews to the editor pane parent, while src/vs/workbench/contrib/webview/browser/overlayWebview.ts mounts the overlay at the workbench root. src/vs/workbench/browser/media/floatingPanels.css rounds `.webview-overlay-content` but does not independently preserve the editor frame above it.
