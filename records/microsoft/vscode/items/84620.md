# Issue #84620 — Git Merge Resolve Dialog

[https://github.com/microsoft/vscode/issues/84620](https://github.com/microsoft/vscode/issues/84620)

## Summary

The merge editor (enabled via `git.mergeEditor` setting) already provides this workflow: after resolving conflicts, 'Complete Merge' (Ctrl+Enter) saves and stages the file automatically via `git.acceptMerge`. This covers the requested behavior.

## Change summary

Request for VS Code to prompt the user to mark a file as resolved in Git after all merge conflicts in that file are resolved.

## Best solution

The merge editor (`git.mergeEditor: true`) delivers exactly this: 'Complete Merge' saves the result and stages the file via `repository.add()`. The inline merge-conflict codelens flow doesn't auto-stage, but the merge editor is the intended path for conflict resolution. Close as covered by existing functionality.
