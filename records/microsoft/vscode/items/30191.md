# Issue #30191 — Change Vertical Scrollbar Width

[https://github.com/microsoft/vscode/issues/30191](https://github.com/microsoft/vscode/issues/30191)

## Summary

A real gap remains: editor scrollbar dimensions are configurable, but Explorer and other workbench list scrollbars are not. This 84-upvote Backlog item is the oldest and best-supported canonical request, so it should remain open.

## Change summary

Allow users to increase the width of vertical scrollbars in the Explorer and other workbench panels.

## Best solution

Add supported workbench-wide scrollbar size and visibility settings through the shared list options in `src/vs/platform/list/browser/listService.ts`, while retaining editor-specific settings. Consolidate the newer https://github.com/microsoft/vscode/issues/160804 request into this canonical issue.
