# Issue #174722 — Deleted files move to another directory, not to trash

[https://github.com/microsoft/vscode/issues/174722](https://github.com/microsoft/vscode/issues/174722)

## Summary

Confirmed upstream issue: VS Code calls Electron's shell.trashItem() which is the correct macOS API, but OneDrive's CloudStorage integration mishandles it. Already correctly labeled upstream with an open Electron issue (electron/electron#38541). No VS Code-side fix is possible; keeping open to track upstream progress.

## Change summary

Deleting files inside OneDrive/CloudStorage folders on macOS moves them to the OneDrive root instead of the system Trash.

## Best solution

The fix must come from OneDrive's macOS client (or from Electron adopting a workaround). VS Code's role is to track the upstream Electron issue (electron/electron#38541) and update Electron when a fix ships there. Internal cross-team escalation to the OneDrive team (both are Microsoft) would be the most productive path forward.
