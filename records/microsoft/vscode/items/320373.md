# Issue #320373 — Agent Window: constant errors from old sessions

[https://github.com/microsoft/vscode/issues/320373](https://github.com/microsoft/vscode/issues/320373)

## Summary

Valid bug, still reproducible on main: archived/done sessions remain in the metadata store's folder-to-session index, so repository state changes trigger worktree diff computations for sessions whose worktrees no longer exist, spamming the log every few seconds. Already assigned to joshspicer.

## Change summary

After marking agent sessions as done, deleted worktrees and branches continue to produce constant warning/error log spam because the metadata store still tracks those sessions in its folder index.

## Best solution

Filter out archived sessions in `ChatSessionMetadataStoreImpl.getSessionIdsForFolder()` (or in `_updateFolderIndex` when `archived` is set), so that `clearChangesCacheForAffectedSessions` in `chatSessionRepositoryTracker.ts` no longer iterates over sessions whose worktrees have been cleaned up. Alternatively, guard the `_getWorktreeChanges` path to silently skip sessions whose worktree path doesn't exist on disk.
