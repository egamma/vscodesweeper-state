# Issue #328987 — [Error] unhandlederror-ListError [NotebookCellList] Invalid index -1

[https://github.com/microsoft/vscode/issues/328987](https://github.com/microsoft/vscode/issues/328987)

## Summary

Legitimate stable-release regression (875 affected users, new in 1.131.0) with a race in notebook cell relayout during re-entrant scroll — but an open PR already targets this exact issue, so the fix lane should not compete with it; keep open pending merge.

## Change summary

NotebookCellList.getCellViewScrollTop throws 'Invalid index -1' when a re-entrant scroll event fires layoutEditor for a cell that has just been removed/re-indexed from the view model.

## Best solution

Land and ship https://github.com/microsoft/vscode/pull/329003, which adds a guard in CodeCellLayout.layoutEditor (codeCell.ts) to skip relayout when the cell is no longer resolvable via getCellIndex, before the crash-causing getAbsoluteTopOfElement/getCellViewScrollTop call.
