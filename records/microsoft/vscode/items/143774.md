## Change summary

Allow extensions to use codicons or ThemeIcon values for editor gutter decorations instead of supplying image files.

## Best solution

Extend the editor decoration API and rendering pipeline to accept ThemeIcon for gutter icons, including animated codicon modifiers, while retaining URI-based icons.
