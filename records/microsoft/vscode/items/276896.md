# Issue #276896 — Search Editor tab labels don't reload correctly

[https://github.com/microsoft/vscode/issues/276896](https://github.com/microsoft/vscode/issues/276896)

## Summary

The inactive-tab label defect remains in current main: restored search configuration is available, but the tab name ignores it until the editor resolves. The linked fix PR was closed without merging, and no matching open canonical was found.

## Change summary

Preserve query-specific Search Editor tab labels after reloading the window, including tabs that have not been activated.

## Best solution

Restored Search Editor inputs should expose their query-specific names before activation, without eagerly resolving search-result models. Preserve existing saved-file naming, query truncation, and subsequent label updates.
