# Issue #342402 — When "editor.wordSegmenterLocales" is configured, `cursorWordStartRight` fails to move the cursor to the end of the line if there is a '。' (Japanese full-stop) at the end of the line.

## Summary

Keep open: current source can return the same word start repeatedly when Japanese segmentation encounters trailing '。'. The report provides sufficient examples, and the failure is traceable in core word navigation.

## Change summary

Make cursorWordStartRight advance past Japanese full stops at line endings and before whitespace or other punctuation when Japanese word segmentation is enabled.

## Best solution
