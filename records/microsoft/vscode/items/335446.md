# Issue #335446 — Agents windows - Custom agent selector doesn't work

[https://github.com/microsoft/vscode/issues/335446](https://github.com/microsoft/vscode/issues/335446)

## Summary

Keep open: an independent reporter confirmed that clicking a listed custom agent does not select it in the Agents window, including on the then-latest release. Current source has explicit selection wiring, but neither a fixing commit nor an older canonical covering this immediate selection failure was established.

## Change summary

Selecting a custom agent in the Agents window should activate it and update the selector, as it does in the editor Chat view.

## Best solution

Diagnose the Agents-window selection-to-provider state transition and ensure an explicit selection updates both the displayed agent and the agent used for the conversation. Distinguish this immediate click failure from later selection loss during submission or session switching.
