# Issue #335446 — Agents windows - Custom agent selector doesn't work

[https://github.com/microsoft/vscode/issues/335446](https://github.com/microsoft/vscode/issues/335446)

## Summary

Real, independently confirmed bug (three separate reporters) in the Agents window's custom-agent picker; the current-main code path is intricate (observable session state, storage, provider.setAgent, and async chat-input-mode syncing with its own debug logging), so I can't pin the exact defect from source alone — routing to the chat/sessions area for a deeper look rather than closing.

## Change summary

In the Agents window, choosing a custom agent from the agent dropdown doesn't actually activate it (the dropdown selection has no effect), while the equivalent picker in regular VS Code Chat works fine.

## Best solution

Someone with a running build should trace why `ModePicker._selectMode` / `AgentHostAgentPickerContribution._selectMode` → `provider.setAgent` isn't reflected back into the active session's mode and the visible chat input (see `_syncChatInputMode`/`_syncVisibleChatInputMode`'s async apply()+waitForPendingUpdates race in agentHostAgentPicker.ts); the embedded `[AGPK]`/`[AgentHostAgentPickerProbe]` logging suggests this exact sync path is already under active investigation.
