# Issue #192775 — [folding] Imports are not collapsed added first

[https://github.com/microsoft/vscode/issues/192775](https://github.com/microsoft/vscode/issues/192775)

## Summary

The bug remains present on main: imports folded by default are only collapsed when a model is first attached, while a later edit that inserts a line before the folded range can leave that new import visible.

## Change summary

Keep automatically inserted imports collapsed when `editor.foldingImportsByDefault` is enabled and the import block is already folded.

## Best solution

Preserve the import fold across edits that extend the same imports region, while retaining the existing one-time initial-collapse behavior for unrelated folding ranges.
