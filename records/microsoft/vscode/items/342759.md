# Issue #342759 — Copilot agent harness prompts for approval for fetch tool twice

## Summary

Keep open for diagnosis: the supplied harness, model, version and fetch steps suffice to retest the repeated approval. Current main has approval handoff and separate pre-fetch/result confirmation paths, but source inspection does not establish whether these are redundant prompts or distinct approvals, and no concrete fix was identified.

## Change summary

The Copilot harness reportedly asks for approval twice when fetching a single web page.

## Best solution

Establish which permission stage produces each prompt, then eliminate any repeated approval of the same operation while preserving distinct network-access and fetched-content consent where required. Investigate the Copilot permission-to-client-tool handoff rather than suppressing fetch confirmations globally.
