# Issue #316159 — [Agents App] "New session" feels like "start over" — parallelism is undiscoverable

[https://github.com/microsoft/vscode/issues/316159](https://github.com/microsoft/vscode/issues/316159)

## Summary

Keep open for a focused UX decision: current onboarding teaches concurrent sessions and worktree isolation, but its experiment and first-use gates do not establish that the reported discoverability problem is resolved. The New Session action still does not explain parallelism at its entry point.

## Change summary

Make it clear that starting another session can run a separate task concurrently without stopping the current agent.

## Best solution

Make the New Session entry point communicate that existing tasks can continue, with isolation guidance accurate to the selected workspace mode. Evaluate the existing onboarding against the study's misunderstanding before deciding whether additional contextual copy or an affordance change is necessary.

Any explanation of separate worktrees must match the selected isolation mode. Acceptance should exercise the entry point during a running task and verify both comprehension cues and continued execution of the original task.
