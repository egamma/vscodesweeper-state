# Issue #316159 — [Agents App] "New session" feels like "start over" — parallelism is undiscoverable

[https://github.com/microsoft/vscode/issues/316159](https://github.com/microsoft/vscode/issues/316159)

## Summary

Valid feature request backed by usability research: the 'New Session' action in the Agents Window does not communicate that sessions run in parallel with their own worktrees, leading users to serialize their work unnecessarily. No code changes have addressed the discoverability gap on current main.

## Change summary

Make it discoverable that opening a new session in the Agents Window creates an independent parallel worktree rather than replacing the current task.

## Best solution

Improve the 'New Session' action labeling and/or add contextual education (tooltip, onboarding tour step, or prompt) explaining that new sessions run in parallel in their own worktree. The entry points are in `src/vs/sessions/contrib/sessions/browser/newSessionActionViewItem.ts` and `src/vs/sessions/contrib/chat/browser/newChatWidget.ts`. The existing onboarding tour infrastructure (`src/vs/sessions/contrib/onboardingTours/`) could host a parallel-session education step.
