# Issue #306934 — Add "Disable AI Features" to enterprise policy

[https://github.com/microsoft/vscode/issues/306934](https://github.com/microsoft/vscode/issues/306934)

## Summary

The requested device-wide policy is still missing: current main exposes chat.disableAIFeatures as a user setting without policy metadata. Existing enterprise controls do not directly cover the request, and the previously linked request was closed for insufficient votes rather than implemented.

## Change summary

Allow administrators to enforce Chat: Disable AI Features through enterprise device policies, including Linux JSON policy files.

## Best solution

Provide an administrator-enforced counterpart to chat.disableAIFeatures through VS Code's device-policy configuration system, preserving the existing user preference when no policy applies. The enterprise-policy owner should decide whether to accept this capability before implementation.
