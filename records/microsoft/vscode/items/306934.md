# Issue #306934 — Add "Disable AI Features" to enterprise policy

[https://github.com/microsoft/vscode/issues/306934](https://github.com/microsoft/vscode/issues/306934)

## Summary

Valid feature request — the `chat.disableAIFeatures` setting exists but lacks a `policy` property, so it cannot be enforced via enterprise policy (MDM/GPO/JSON policy file). Other chat settings like `chat.approvedAccountOrganizations` already have policy support, but this one does not. The gap is real and still present on current main.

## Change summary

Allow enterprise administrators to enforce the `chat.disableAIFeatures` setting via device management policies (GPO, MDM, JSON policy file).

## Best solution

Add a `policy` block to the `chat.disableAIFeatures` configuration registration in `src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts`, following the same pattern used by `chat.approvedAccountOrganizations` and other policy-enabled settings. This is a small, well-patterned change in the configuration contribution.
