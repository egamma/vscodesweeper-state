# Issue #243235 — BadInstallScript Result

[https://github.com/microsoft/vscode/issues/243235](https://github.com/microsoft/vscode/issues/243235)

## Summary

This is a Remote-SSH extension issue (ms-vscode-remote.remote-ssh) — the error originates entirely within the extension's install script handler. The issue should be moved to the Remote Development tracker.

## Change summary

Remote-SSH extension fails with 'BadInstallScriptResult' when connecting to a Linux host with useExecServer disabled.

## Best solution

Move this issue to microsoft/vscode-remote-release where the Remote-SSH team owns the install-script logic. The workaround (enabling remote.SSH.useExecServer) suggests the non-exec-server path has a regression in the 0.118.0 extension version.
