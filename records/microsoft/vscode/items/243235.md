## Summary

This is a confirmed Remote-SSH defect and should remain open but be moved to the VS Code team's Remote Development tracker, where the responsible extension is maintained.

## Change summary

Opening a folder over Remote-SSH reports BadInstallScriptResult on the initial connection and succeeds only after retrying or enabling the exec server.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release and investigate why the legacy install path produces empty output when `remote.SSH.useExecServer` is disabled, while the subsequent exec-server connection succeeds.
