# Issue #66162 — Find usages (find all file references / find all folder references)

[https://github.com/microsoft/vscode/issues/66162](https://github.com/microsoft/vscode/issues/66162)

## Summary

Keep open: file-reference support has partially landed for specific languages, but folder references and a language-neutral provider remain real gaps. The Backlog request has 52 community upvotes and should remain its canonical tracker.

## Change summary

Expose commands and Explorer actions for finding every reference to a file or to files contained in a folder.

## Best solution

Establish the language-neutral file-reference provider tracked by https://github.com/microsoft/vscode/issues/134405, then add a cancellable folder-reference command that aggregates provider results for files under the selected folder. Keep this issue as the canonical user-facing folder workflow.
