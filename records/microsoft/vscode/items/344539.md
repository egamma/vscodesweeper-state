# Issue #344539 — Customizations: Allow removing MCP servers from the UI

[https://github.com/microsoft/vscode/issues/344539](https://github.com/microsoft/vscode/issues/344539)

## Summary

Keep open: current source offers uninstall for some MCP sources, but agent-host-only rows lack removal and a source-removal explanation. The related reports cover different problems, not this source-aware management gap.
