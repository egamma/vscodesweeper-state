# Issue #141500 — QuickPick allow the mixing of checkbox items with non-checkbox items

[https://github.com/microsoft/vscode/issues/141500](https://github.com/microsoft/vscode/issues/141500)

## Summary

Current QuickPick internals already support mixing checkbox rows with ordinary rows, but separators do not define a group's selection mode. Keep this accepted, team-authored request open: no verified issue-referencing fix establishes completion, and no eligible canonical duplicate was found.

## Change summary

Allow one QuickPick to contain checkbox groups and ordinary selectable groups, distinguished by separators.

## Best solution

Have the QuickPick owner determine whether the existing per-item support satisfies the intended internal use case or whether separator-defined selection groups remain necessary. Any remaining work should establish consistent activation and selection semantics without changing existing homogeneous pickers.
