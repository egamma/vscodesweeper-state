# Issue #275046 — Agent file editor - migration quick fix removes editor focus

[https://github.com/microsoft/vscode/issues/275046](https://github.com/microsoft/vscode/issues/275046)

## Summary

Still present on main: the migration code action in `promptCodeActions.ts` uses an `IWorkspaceFileEdit` (file rename) without any mechanism to restore editor focus after the rename completes. No fix commit found. Team-authored issue — keeping open.

## Change summary

Invoking the quick fix to migrate a legacy `.chatmode` file to an agent file causes the editor to lose focus.

## Best solution

The code action apply path (in `src/vs/editor/contrib/codeAction/browser/codeAction.ts`) or the bulk edit service should ensure that when a workspace file edit renames the currently-focused editor's file, focus is restored to the editor showing the new resource. Alternatively, the migration code action itself could include a follow-up command that re-focuses the renamed file's editor.
