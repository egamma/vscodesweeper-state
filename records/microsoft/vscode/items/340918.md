# Issue #340918 — Markdown preview: one long unbreakable token makes all lines in a word-wrapped code block wrap at that token's width

[https://github.com/microsoft/vscode/issues/340918](https://github.com/microsoft/vscode/issues/340918)

## Summary

Thanks for the detailed report. The CSS cause is confirmed on main: `pre code` is `display: inline-block` and `body.wordWrap pre` only sets `pre-wrap`. An open PR already references the issue, so it stays open.

## Change summary

In Markdown preview with word wrap on, one long unbreakable token makes every line in a code block wrap at that token's width.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/340919, which makes `body.wordWrap pre code` a block box so it wraps at the `pre` width. Check how it overlaps with https://github.com/microsoft/vscode/pull/330494.
