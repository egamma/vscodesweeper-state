# Issue #134409 — Add a description to a vscode.TestTag

[https://github.com/microsoft/vscode/issues/134409](https://github.com/microsoft/vscode/issues/134409)

## Summary

The requested capability remains missing: TestTag exposes only an ID, and filter suggestions still display the controller label rather than extension-provided tag descriptions. Keep this accepted Backlog request open; no qualifying canonical duplicate was found.

## Change summary

Allow extensions to supply a human-readable label or description for TestTag suggestions in the Test Explorer filter.

## Best solution

Provide an optional tag-description API and surface that metadata in Test Explorer filter completions while preserving existing tag identity and filtering syntax. The testing API owner should settle the public contract before implementation.
