[https://github.com/microsoft/vscode/issues/309403](https://github.com/microsoft/vscode/issues/309403)

## Summary

The primary concern occurs specifically while Remote-SSH restores a connection, so it should be transferred to the VS Code team's Remote Development tracker for diagnosis. The word-wrap persistence request is a separate core-editor concern already represented by the resource-specific settings discussion.

## Change summary

Determine why menus remain disabled for about a minute after a Remote-SSH reload and support remembering a word-wrap override for an individual file.

## Best solution

Have the Remote Development owners determine whether Remote-SSH connection restoration is unnecessarily delaying workbench readiness. Keep per-file word-wrap persistence consolidated with https://github.com/microsoft/vscode/issues/35350 rather than coupling it to the reconnect investigation.
