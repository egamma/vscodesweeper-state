# Issue #293239 — Add Ollama support to Background Agents

[https://github.com/microsoft/vscode/issues/293239](https://github.com/microsoft/vscode/issues/293239)

## Summary

BYOK model support (including Ollama) in background agents and the Agents window has been implemented on main since late June 2026. The agent host now serves BYOK models by default, so this request is fulfilled.

## Change summary

Allow users to select BYOK models (including Ollama) for background agent sessions, not just the default Copilot models.

## Best solution

Keep the shipped implementation: BYOK models are now enabled by default in the agent host configuration and the Agents window registers the BYOK language-model handler. Ollama models configured via the BYOK provider are available in background agent sessions. No further change needed.
