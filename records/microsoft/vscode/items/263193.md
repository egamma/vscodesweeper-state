Confirmed and reproduced by the terminal maintainer — Kali Linux's default bash prompt breaks shell integration's preexec hook, preventing command completion signals. No fix has landed on main yet.

## Change summary

Shell integration's preexec and command-complete hooks fail with Kali Linux's default bash prompt, causing agent/Copilot terminal commands to hang after the first execution.

The fix likely needs to handle Kali's prompt framework gracefully so the C/E/D sequences still fire.
