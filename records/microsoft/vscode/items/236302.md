# Issue #236302 — Command Center should shrink when not enough space

[https://github.com/microsoft/vscode/issues/236302](https://github.com/microsoft/vscode/issues/236302)

## Summary

Still reproduces on main: the command center uses a fixed `width: 38vw` with no flex-shrink, so when the menu bar has longer labels (e.g. localized menus, or even English on smaller windows), menu items get pushed out of view. Team members confirmed and agreed to fix but it remains unaddressed.

## Change summary

The Command Center's fixed width prevents the menu bar from displaying all items when space is tight, especially with localized (longer) menu labels or smaller windows.

## Best solution

Allow the command center to shrink when the titlebar left section (menu bar) needs more space — likely by enabling `flex-shrink` on `.titlebar-center` (currently commented out at line 88 of titlebarpart.css) and/or reducing the command center's `width: 38vw` or adding a `min-width` that allows shrinking. The compact-mode infrastructure already exists and could be leveraged.
