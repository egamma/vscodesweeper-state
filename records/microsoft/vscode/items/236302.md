# Issue #236302 — Command Center should shrink when not enough space

[https://github.com/microsoft/vscode/issues/236302](https://github.com/microsoft/vscode/issues/236302)

## Summary

Keep open: confirmed reports and the current title-bar allocation support the accepted bug that menus overflow before the Command Center meaningfully yields space. This issue already has the correct routing and remains the canonical report for that symptom.

## Change summary

Let the Command Center shrink under width pressure so ordinary windows retain their full application menu when sufficient total space exists.

## Best solution

Make title-bar allocation accommodate the application menu before sending entries into overflow, while retaining a usable Command Center and visible window controls. Preserve menu overflow for genuinely narrow windows rather than promising every menu will always fit.
