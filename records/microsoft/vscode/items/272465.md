# Issue #272465 — Warning in dev console: Settings not included in settingsLayout.ts: github.copilot.chat.agent.terminal.allowList, github.copilot.chat.agent.terminal.denyList

[https://github.com/microsoft/vscode/issues/272465](https://github.com/microsoft/vscode/issues/272465)

## Summary

Still reproduces on main: the deprecated `github.copilot.chat.agent.terminal.allowList/denyList` settings are registered as core settings without `extensionInfo`, so `resolveSettingsTree` places them in `coreSettingsGroups` and they appear as leftover settings not mapped in the TOC layout. A small fix is needed.

## Change summary

Dev console warns about deprecated terminal agent settings not being included in settingsLayout.ts.

## Best solution

Either filter out deprecated settings from the `leftoverSettings` warning in `settingsEditor2.ts` (so deprecated settings never trigger the warning), or add these specific settings to a deprecated/hidden section of the TOC layout. The former is more general and prevents future recurrences.
