# Issue #340720 — Allow user to create a new branch in new session composer

[https://github.com/microsoft/vscode/issues/340720](https://github.com/microsoft/vscode/issues/340720)

## Summary

Team-authored feature request from a UX study. The Agents window branch picker only selects existing branches, and the checkout has no create-branch capability. Keep it open.

## Change summary

Let the Agents window new-session branch picker create a new branch instead of only selecting existing ones.

## Best solution

Add a 'Create new branch…' entry to the branch picker. It should take a name, create the branch from the current or base branch, and select it for the session. This most likely belongs in src/vs/sessions/contrib/chat/browser/branchPicker.ts and agentHostSessionConfigPicker.ts.

- **Reason:** It removes a context switch in the new-session composer, which sits in the AI-assisted development and developer inner-loop themes.
