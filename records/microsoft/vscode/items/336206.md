# Issue #336206 — Activity Bar container can remain pinned but invisible in a Remote-SSH workspace

[https://github.com/microsoft/vscode/issues/336206](https://github.com/microsoft/vscode/issues/336206)

## Summary

The inconsistent pinned-but-invisible state remains possible on current main: workspace visibility excludes the container while pinning updates only its independent profile state. This is a source-confirmed, team-authored bug and should remain open for a bounded workbench fix.

## Change summary

Reconcile Activity Bar pinning and workspace visibility so an available extension-contributed container cannot remain pinned but absent.

## Best solution

Maintain an invariant that a pinned, available view container is visible, including when persisted profile and workspace state are restored. Cover both restoration of a pinned/hidden item and pinning an already-hidden item without changing legitimate hide-if-empty behavior.
