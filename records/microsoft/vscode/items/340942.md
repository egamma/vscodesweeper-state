# Issue #340942 — Agent host: any file change under ~ triggers customization rediscovery for every session (watched resource includes user home / workspace root)

[https://github.com/microsoft/vscode/issues/340942](https://github.com/microsoft/vscode/issues/340942)

## Summary

Thanks for the detailed trace. The code on main still matches the report: the discovered directory itself, which can be the home or workspace root, is added to resourcesToWatch, and the global onDidFilesChange handler matches it with affects(). Any change under that root then refreshes every session.

## Change summary

Discovery refresh fires for every session on any file change under ~ or a worktree root, because root and ancestor directories are watched resources matched with affects().

## Best solution

Match changes only against the precise customization files and directories. Use a non-descendant check for ancestor and root entries, and do not add the container root as a watched resource. Add a regression test for unrelated changes under ~ and ~/.copilot.
