# Issue #161347 — A misalignment of a few menu's shortcut keys (macOS)

[https://github.com/microsoft/vscode/issues/161347](https://github.com/microsoft/vscode/issues/161347)

## Summary

Still present on main — Electron does not support rendering arbitrary keybinding labels as right-aligned accelerators in native menus; VS Code falls back to appending `[binding]` inline. The upstream limitation remains unresolved.

## Change summary

Non-native keybindings (chords, multi-key sequences) appear inline in brackets in macOS native menus instead of right-aligned as accelerators.

## Best solution

Electron needs to support rendering arbitrary strings as accelerator labels in native menus (not just valid Electron accelerator sequences). Until that lands upstream, VS Code's fallback in `src/vs/platform/menubar/electron-main/menubar.ts` is the only option. Keep open as upstream.
