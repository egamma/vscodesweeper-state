# Issue #161347 — A misalignment of a few menu's shortcut keys (macOS)

[https://github.com/microsoft/vscode/issues/161347](https://github.com/microsoft/vscode/issues/161347)

## Summary

Keep open: current source still appends unsupported native-menu keybindings to command labels in brackets. This is the accepted tracking issue for an Electron menu-rendering limitation; custom context menus only partially work around it.

## Change summary

Display keyboard chords and other unsupported shortcuts in the right-aligned shortcut column of macOS native menus instead of appending them to command names.

## Best solution

Enable arbitrary shortcut display labels in Electron native menus, then adopt that capability in VS Code's application-menu and native-context-menu paths without changing shortcut execution. Retain this issue as the canonical tracker until that capability is available and integrated.
