# Issue #161347 — A misalignment of a few menu's shortcut keys (macOS)

[https://github.com/microsoft/vscode/issues/161347](https://github.com/microsoft/vscode/issues/161347)

## Summary

Keep open: current source still appends unsupported native-menu shortcuts in brackets beside the command text. This issue already owns the consolidated reports, and custom context menus do not resolve the macOS application-menu requirement.

## Change summary

Display chords and other unsupported shortcuts in the right-aligned shortcut column of macOS native menus instead of appending them to command labels.

## Best solution

Provide Electron support for arbitrary shortcut-display labels in native menus, then use it in VS Code's application and context menus without changing command execution or keybinding semantics. Retain this issue as the canonical tracker for that integration.
