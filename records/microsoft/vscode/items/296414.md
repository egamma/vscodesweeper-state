# Issue #296414 — Sync ~/.copilot/skills via Settings Sync

[https://github.com/microsoft/vscode/issues/296414](https://github.com/microsoft/vscode/issues/296414)

## Summary

Valid feature request from a team member with strong community support (25 upvotes). Settings Sync currently handles Settings, Keybindings, Snippets, Prompts, Tasks, MCP, Extensions, GlobalState, and Profiles — but not `~/.copilot/skills`. No implementation exists on main. Should be routed to settings-sync for triage.

## Change summary

Sync the `~/.copilot/skills/` directory across machines via Settings Sync, similar to how MCP config and prompt files are already synced.

## Best solution

Add a new `SyncResource.Skills` enum value and a corresponding synchronizer (analogous to the existing Prompts and MCP synchronizers) in `src/vs/platform/userDataSync/` to sync the `~/.copilot/skills/` directory. The infrastructure pattern is already established — Prompts and MCP were added recently as sync resources.
