# Issue #219138 — Accessibility:  "Dark high contrast theme" cursor disappears and stops blinking after a time

[https://github.com/microsoft/vscode/issues/219138](https://github.com/microsoft/vscode/issues/219138)

## Summary

Keep open for the high-contrast cursor-default decision requested in the discussion. Manual cursor customization already exists, but it does not deliver the proposed accessible default; the reported disappearance has not been established as a focused-editor defect.

## Change summary

Make the default editor cursor easier to locate in high-contrast themes, potentially by using a block cursor.

## Best solution

Decide whether high-contrast themes should select a more visible editor cursor by default while preserving explicit user preferences. The terminal already defaults to a block cursor, so its focused-cursor default needs no equivalent change.
