# Issue #229154 — Window size becomes the size of the monitor when transferring maximized window across differently scaled monitors

[https://github.com/microsoft/vscode/issues/229154](https://github.com/microsoft/vscode/issues/229154)

## Summary

Keep open as an Electron mixed-DPI window-restoration issue. VS Code already persists normal bounds before restoring the maximized state, but the reported cross-monitor restore behavior has no verified fix or eligible duplicate.

## Change summary

Preserve appropriately scaled unmaximized window dimensions after restarting a maximized window and transferring it between 200% and 100% scale monitors.

## Best solution

Electron should preserve and correctly scale a maximized window's normal bounds during cross-monitor moves. Keep this report as the VS Code tracking case until that behavior is verified for the complete restart, transfer, and unmaximize sequence.
