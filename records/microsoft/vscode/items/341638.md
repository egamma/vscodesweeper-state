[https://github.com/microsoft/vscode/issues/341638](https://github.com/microsoft/vscode/issues/341638)

## Summary

Keep open: the web Agents entrypoint still lacks a presenter required to construct ChatWidget, matching the confirmed blank-conversation regression. The maintainer has identified a bounded registration defect; the separate tunnel-service and BYOK discovery inconsistencies remain unproven.

## Change summary

Remote-tunnel web Agents lists sessions but fails to render their conversation contents and input.

## Best solution

Make the web Agents chat-widget dependency graph constructible without activating desktop-only local-host contributions, preserving desktop continuation behavior. Cover the production web registration boundary with a regression test and assess the additional discovery symptoms separately.
