# Issue #341638 — Chat Session contents dont show up at all in remote tunnel web view.

[https://github.com/microsoft/vscode/issues/341638](https://github.com/microsoft/vscode/issues/341638)

## Summary

Thanks for the report and the regression range. A contributor traced it to a missing IAgentHostPolicyContinuationPresenter registration in the web Agents entrypoint, and current main still has that gap, so this stays open until a fix lands.

## Change summary

Chat transcript and input never render in the Agents web client (tunnel/mobile) because the chat widget fails to construct.

## Best solution

Register an IAgentHostPolicyContinuationPresenter in the web Agents entrypoint (or make the dependency optional) so ChatWidget can be created there.
