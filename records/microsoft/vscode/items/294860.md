# Issue #294860 — case-sensitivity of exclude patterns inconsistent between file explorer and search

[https://github.com/microsoft/vscode/issues/294860](https://github.com/microsoft/vscode/issues/294860)

## Summary

Confirmed on main: the explorer parses `files.exclude` globs case-sensitively (no `ignoreCase` option in `glob.parse`), while the search view sets `ignoreGlobCase: !isLinux` making the same globs case-insensitive on Windows/macOS. The inconsistency causes search to exclude files that the explorer shows.

## Change summary

On Windows/macOS, `files.exclude` glob patterns are case-sensitive in the file explorer but case-insensitive in search, causing search to miss files that are visible in the explorer.

## Best solution

Align the glob-case behavior: either pass `ignoreCase` (derived from the filesystem's case sensitivity) to `glob.parse` in the explorer's `FilesFilter.updateConfiguration`, or make the search query builder respect the same case-sensitive semantics the explorer uses. The fix belongs in `src/vs/workbench/contrib/files/browser/views/explorerViewer.ts` (the `updateConfiguration` method around line 1340) or in `src/vs/workbench/contrib/search/browser/searchView.ts` (the `ignoreGlobCase` assignment at line 1673), depending on which behavior is considered correct for Windows.
