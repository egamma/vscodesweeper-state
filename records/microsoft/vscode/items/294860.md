# Issue #294860 — case-sensitivity of exclude patterns inconsistent between file explorer and search

[https://github.com/microsoft/vscode/issues/294860](https://github.com/microsoft/vscode/issues/294860)

## Summary

Current source still applies different case rules to the same files.exclude pattern in Explorer and Search on Windows. Keep this accepted Backlog bug open; the remaining decision is how to reconcile those rules without unintentionally changing existing exclusion behavior.

## Change summary

Make shared exclusion patterns behave consistently between Explorer and workspace text search.

## Best solution

Establish consistent case semantics for files.exclude across Explorer and Search, while preserving intentional search-specific exclusions. Decide whether Explorer should adopt platform-sensitive matching or Search should distinguish shared exclusions from other search globs, then cover the reported Windows example with regression checks.
