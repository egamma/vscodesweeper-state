# Issue #327618 — NES: `triggerAnimation()` returns a never-settling promise under reduced motion, hanging the onboarding loop

[https://github.com/microsoft/vscode/issues/327618](https://github.com/microsoft/vscode/issues/327618)

## Summary

Confirmed on current main: reduced-motion handling returns a permanently pending animation promise, blocking the first-time NES onboarding loop.

## Change summary

Make NES animation helpers settle immediately when reduced motion suppresses animation.

## Best solution

Change both animation helpers to return `Promise<void>`, resolve immediately under reduced motion, and otherwise await the real animation's completion.
