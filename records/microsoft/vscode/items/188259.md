# Issue #188259 — Allow contributing to the context menu in the TreeView's empty space 

[https://github.com/microsoft/vscode/issues/188259](https://github.com/microsoft/vscode/issues/188259)

## Summary

Valid, unimplemented feature request with strong community support (27 upvotes). The TreeView context menu handler in treeView.ts explicitly returns early when the clicked element is null (empty space), confirming the gap. Already in Backlog — should stay open.

## Change summary

Allow extensions to contribute context menu items to the empty area below tree items in a TreeView, similar to Explorer's behavior.

## Best solution

Add a new menu contribution point (e.g. `view/emptyContext`) and wire it into `TreeView.onContextMenu` in `src/vs/workbench/browser/parts/views/treeView.ts` so that when `node === null`, the tree still shows contributed actions. The extension point registration would go in `src/vs/workbench/services/actions/common/menusExtensionPoint.ts`. The `vscode.d.ts` API documentation should mention the new contribution point.
