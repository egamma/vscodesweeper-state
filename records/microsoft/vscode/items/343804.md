# Issue #343804 — Agent Host: terminal confirmation in Copilot (Agent Host) chat omits the command explanation and description shown by the Local harness

[https://github.com/microsoft/vscode/issues/343804](https://github.com/microsoft/vscode/issues/343804)

## Summary

Keep open: current source confirms that Copilot terminal confirmations use a generic header without the supplied description. The explanation footer follows a separate assessment path, so restoring the description alone would not resolve the full report.

## Change summary

Show the agent-supplied command description and explanatory context in Copilot Agent Host terminal confirmations, matching the Local harness experience.

## Best solution

Preserve command context through the Copilot permission-display and workbench confirmation paths so users can understand the requested operation without deciphering the raw command. Diagnose the explanation footer separately from the header, retaining the distinction between agent-authored intent and an actual risk assessment.
