# Issue #336431 — "Change Completions Model" is missing

[https://github.com/microsoft/vscode/issues/336431](https://github.com/microsoft/vscode/issues/336431)

## Summary

The 'Change Completions Model' command exists and is contributed by the Copilot extension, but it is intentionally gated behind an enablement condition requiring multiple available completion models and non-web context — the reporter's environment likely only exposes a single completion model, so the command palette correctly hides it.

## Change summary

Reporter cannot find the 'Change Completions Model' command in the command palette, even though it's documented in GitHub's docs and referenced in a Copilot settings description.

## Best solution

No code change needed — the command is only surfaced via `enablement: github.copilot.completions.hasMultipleModels && !isWeb` in extensions/copilot/package.json (command `github.copilot.chat.openModelPicker`), driven by `ModelPickerManager.hasMultipleModels()` in extensions/copilot/src/extension/completions-core/vscode-node/extension/src/modelPicker.ts. If the docs should clarify this precondition, that's a documentation follow-up, not a code fix.

  > Thanks for the report. The "Change Completions Model" command (`github.copilot.chat.openModelPicker`) does exist, but it's only shown in the Command Palette when multiple completion models are available to your account/organization (and not in web builds) — see the `enablement` clause in `extensions/copilot/package.json` and `ModelPickerManager.hasMultipleModels()`. If your Copilot plan currently only offers one completion model, the command is intentionally hidden rather than missing. Closing as as-designed, but please reopen if you believe multiple models should be available and aren't showing up.
