# Issue #167885 — Editor find input controls are visually grouped but not programmatically associated / focus order inconsistent

[https://github.com/microsoft/vscode/issues/167885](https://github.com/microsoft/vscode/issues/167885)

## Summary

The accessibility gap remains on current main, while the desired focus order conflicts with intentional fast navigation between Find and Replace. Keep this open for the acknowledged UI and interaction design work.

## Change summary

Programmatically associate Find and Replace options with their inputs and provide a logical, consistent keyboard focus order.

## Best solution

Reorganize the editor find widget into labeled semantic Find and Replace groups while retaining an efficient way to switch directly between the two inputs. The interaction design should be agreed before implementation.
