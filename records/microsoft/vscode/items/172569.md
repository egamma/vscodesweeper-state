# Issue #172569 — High contrast panel section header outlines don't include problem count

[https://github.com/microsoft/vscode/issues/172569](https://github.com/microsoft/vscode/issues/172569)

## Summary

Confirmed visual bug still present on main: in high contrast themes, the panel section header border/outline is drawn on the `.action-label` element, but the badge (problem count) is a sibling inside the parent `.action-item`, so the outline doesn't visually encompass the count. No fix has been committed.

## Change summary

In high contrast themes, the panel section header outline excludes the problem count badge because the outline targets `.action-label` while the badge sits in the parent `.action-item`.

## Best solution

Move the border/outline from `.action-label` to `.action-item` (or adjust the DOM/CSS so the badge is visually included within the outlined region) in the panel section header rendering path. The fix likely touches `src/vs/base/browser/ui/splitview/paneview.ts` (where `headerBorder` is applied as `border-top` on the header element) and possibly the composite bar CSS that renders the action items in the panel header.
