# Issue #330164 — Identical images from different tool calls are shown twice in chat

[https://github.com/microsoft/vscode/issues/330164](https://github.com/microsoft/vscode/issues/330164)

## Summary

Real, well-diagnosed bug with an active fixing PR (#330165, 'Fixes #330164') from the same author already open — the fix is in progress by a human, so this should stay open until that PR lands rather than being closed or auto-fixed now.

## Change summary

When an agent uses two different tools (e.g. run_in_terminal then view_image) that both surface the same underlying image, chat renders the identical image twice because each tool call gets a distinct vscode-chat-response-resource URI.

## Best solution

Land the fix in https://github.com/microsoft/vscode/pull/330165, which reworks image completion handling in mapSessionEvents.ts and chatThinkingExternalResourcesWidget.ts so terminal-owned image resources aren't duplicated by other tool completions; once merged this issue can close as completed.
