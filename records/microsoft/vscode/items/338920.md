# Issue #338920 — Markdown links drop non-line fragments like #page=3 when opening files (PDF links always open on page 1)

[https://github.com/microsoft/vscode/issues/338920](https://github.com/microsoft/vscode/issues/338920)

## Summary

Confirmed in current main's source: `openResolvedDocumentLink` in openDocumentLink.ts only preserves `L<line>`-style fragments, dropping anything else (like `#page=3`) before calling `vscode.open`. A fix is already proposed in open PR #332661, so this should stay open and land via that PR rather than being closed or treated as a fresh agent task.

## Change summary

Markdown links to non-text files with non-line fragments (e.g. `file.pdf#page=3`) lose the fragment when opened, so PDF viewers always open at page 1.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332661, which preserves non-line fragments for file links; that directly fixes the code path traced in this issue.
