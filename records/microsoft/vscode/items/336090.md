# Issue #336090 — Agents window: context window usage indicator is not rendered for BYOK models when signed out

[https://github.com/microsoft/vscode/issues/336090](https://github.com/microsoft/vscode/issues/336090)

## Summary

Plausible, unrouted bug: the context-usage widget hides whenever it can't compute a positive total context window, and third-party BYOK models get no fallback for missing token limits — this matches the reported symptom, though the exact tie to signed-out state (versus BYOK generally) isn't fully pinned down from source alone.

## Change summary

The context-window usage ring in the Agents window composer never renders for BYOK models when the user is signed out (using chat.agentHost.allowSignedOutWhenUsable).

## Best solution

In src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostLanguageModelProvider.ts, ensure third-party BYOK models (not just Copilot-billed ones) get a usable maxInputTokens/maxOutputTokens — e.g. from the model's configSchema contextSize — so ChatContextUsageWidget.resolveContextWindow() (chatContextUsageWidget.ts) doesn't short-circuit on a zero/undefined context window.
