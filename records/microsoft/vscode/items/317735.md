# Issue #317735 — Pylance errors from chat virtual documents

[https://github.com/microsoft/vscode/issues/317735](https://github.com/microsoft/vscode/issues/317735)

## Summary

The issue describes Pylance producing false errors when Copilot chat creates virtual documents for attached notebooks. It's unclear whether the fix belongs in VS Code core (virtual documents should be excluded from language server analysis) or in Pylance (it should ignore certain URI schemes). The current labels (notebook, virtual-documents) are appropriate, and the issue needs investigation to determine root cause ownership.

## Change summary

Pylance reports dozens of false import errors when a Jupyter notebook is attached to a Copilot chat session, because chat's virtual document for the notebook is picked up by the language server at a path that can't resolve project imports.

## Best solution

Investigate whether chat's virtual document registration for notebook attachments exposes content to language services inappropriately (core fix in the chat content provider or virtual document scheme handling), or whether Pylance needs to filter out these schemes (extension fix in microsoft/pylance-release). If core, ensure virtual documents for chat attachments are properly excluded from language server analysis — possibly by using a scheme that language extensions conventionally skip.
