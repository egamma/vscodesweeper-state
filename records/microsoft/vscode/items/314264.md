# Issue #314264 — chat.tools.terminal.autoApproveWorkspaceNpmScripts does not auto-approve npm scripts defined in workspace subfolders

[https://github.com/microsoft/vscode/issues/314264](https://github.com/microsoft/vscode/issues/314264)

## Summary

The compound-command case remains reproducible from current source: npm script approval uses the terminal's initial directory rather than the directory selected by a preceding cd. Keep this open in terminal-auto-approve; subfolder scripts already work when the supplied CWD points directly to their package.

## Change summary

Resolve workspace npm script approval against the effective working directory of the npm invocation, including commands preceded by cd and npm's ancestor-package lookup.

## Best solution

Make npm script approval match the package npm will actually execute within the workspace, while retaining explicit denials and conservative handling of unknown shell state. Do not approve a script merely because its name appears in some other workspace package.
