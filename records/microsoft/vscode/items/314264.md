# Issue #314264 — chat.tools.terminal.autoApproveWorkspaceNpmScripts does not auto-approve npm scripts defined in workspace subfolders

[https://github.com/microsoft/vscode/issues/314264](https://github.com/microsoft/vscode/issues/314264)

## Summary

Confirmed on current main: the npm auto-approver only checks the exact cwd for package.json and does not traverse parent directories, so monorepo subfolder scripts are never auto-approved.

## Change summary

The `chat.tools.terminal.autoApproveWorkspaceNpmScripts` setting fails to auto-approve npm scripts defined in workspace subfolder package.json files.

## Best solution

Extend `_getPackageJsonScripts` in `npmScriptAutoApprover.ts` to walk up the directory tree (staying within the workspace) until a `package.json` containing the target script is found, mirroring npm's own resolution behavior. Additionally, when a compound command includes a `cd` prefix, the approval check should resolve the effective cwd from that prefix.
