# Issue #245260 — ShellIntegration-bash is not properly escaping windows paths

[https://github.com/microsoft/vscode/issues/245260](https://github.com/microsoft/vscode/issues/245260)

## Summary

Still reproduces on main: the fix PR was merged then reverted, and the `echo -e` pattern that interprets escape sequences in Windows paths (e.g. `\t`, `\n`) remains in the shell integration script. The bug is real and unresolved.

## Change summary

Bash shell integration uses `echo -e` to parse environment variable values, which interprets backslash sequences in Windows paths as escape characters (tabs, newlines, etc.).

## Best solution

Replace the `echo -e` calls on lines 76, 85, 94 of `shellIntegration-bash.sh` with a mechanism that does not interpret backslash escapes — the original fix PR (#245264) used parameter expansion but was reverted due to side effects; a revised approach is needed.
