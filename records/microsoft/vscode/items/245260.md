# Issue #245260 — ShellIntegration-bash is not properly escaping windows paths

[https://github.com/microsoft/vscode/issues/245260](https://github.com/microsoft/vscode/issues/245260)

## Summary

Keep open: current Bash shell integration still interprets literal Windows path backslashes as escape sequences when applying environment-variable collections. The previous fix was reverted, and no verified canonical issue covers this report's full symptom.

## Change summary

Preserve Windows paths when Bash shell integration applies environment-variable collections, without corrupting PATH or introducing control characters.

## Best solution

Make Bash environment-variable collection application preserve literal path characters while correctly decoding the existing colon transport encoding. Cover replacement, prepend, and append operations, including the URL and PATH regression that caused the previous fix to be reverted.
