# Issue #317272 — Inline Widgets: Uncommitted changes widget breaks flow and hard to understand for new users

[https://github.com/microsoft/vscode/issues/317272](https://github.com/microsoft/vscode/issues/317272)

## Summary

Keep open for the planned UX work: current main still presents technical, repository-generic wording after prompt submission, while a maintainer has explicitly assigned the styling work. As a team-authored UX issue with accepted direction, it is protected from a judgment close.

## Change summary

Make the uncommitted-changes decision in new agent sessions easier to understand through clearer wording, richer change context, remembered choices, or placement before prompt submission.

## Best solution

Present the decision before work starts, identify the repository by name, describe the choice in task-oriented language, and retain the user's choice at an explicitly chosen scope. Preserve access to the affected-file diff while avoiding worktree and commit terminology unless users request details.
