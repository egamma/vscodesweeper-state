# Issue #212455 — Can't see blinking cursor when it's moved before a closing character like ) or }

[https://github.com/microsoft/vscode/issues/212455](https://github.com/microsoft/vscode/issues/212455)

## Summary

The report describes a real editor-rendering layering problem that still appears plausible on current main: bracket-match decorations are rendered in the same view-layer system as the cursor, and the selected bracket border can visually coincide with the cursor column. It is already routed to editor rendering and should stay open for an area-owner decision rather than being closed from the reporter's theme-specific screenshots.

## Change summary

When the caret is before a bracket, the matching-bracket highlight border can overlap the blinking cursor and make the cursor hard to see in some themes.

## Best solution

Have the editor rendering owner decide whether the cursor should be painted above bracket-match decorations, or whether the bracket-match border should avoid the caret edge when it coincides with the cursor. The likely area is the editor view rendering/decorations path and bracket matching contribution.
