# Issue #195111 — Enable accepting an Emmet abbreviation suggestion without expanding it

[https://github.com/microsoft/vscode/issues/195111](https://github.com/microsoft/vscode/issues/195111)

## Summary

Keep open: current Emmet completions insert the expansion, with no inspected setting or acceptance command that inserts only the suggested abbreviation. The existing emmet routing is correct; the remaining work needs an interaction-design decision.

## Change summary

Allow accepting a suggested Emmet abbreviation as editable abbreviation text before expanding it.

## Best solution

Provide a discoverable way to complete an abbreviation such as input:ch to input:checkbox, continue composing its attributes and classes, and expand it afterward. Decide the acceptance interaction while preserving the existing direct-expansion workflow.
