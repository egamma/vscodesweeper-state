# Issue #307547 — `runSubagent` tool not available to custom agents invoked as subagents (nested subagent invocation broken)

[https://github.com/microsoft/vscode/issues/307547](https://github.com/microsoft/vscode/issues/307547)

## Summary

Keep open: multiple reports confirm that nested custom agents do not consistently receive the subagent invocation tool despite the enabling setting and documented configuration. The behavior should be clarified and made consistent in the chat subagent implementation.

## Change summary

Allow a custom agent running as a subagent to invoke an allowed nested subagent when its frontmatter and the nested-invocation setting permit it.

## Best solution

Trace custom-agent tool resolution across nested agent-host sessions and ensure the subagent tool is exposed at depth 2 when the setting, tool declaration, and agent allowlist all permit it, while preserving recursion and depth safeguards.
