# Issue #156635 — Slow to populate the Terminal > Integrated > Tabs: Default Icon dropdown

[https://github.com/microsoft/vscode/issues/156635](https://github.com/microsoft/vscode/issues/156635)

## Summary

Keep open: the merged optimization only speeds up subsequent openings, while current source still renders and measures every description on the first opening. Maintainers and duplicate reports confirmed the slowdown; the remaining work is cold-open performance, not Codicon rendering correctness.

## Change summary

Opening the terminal default-icon dropdown initially stalls the Settings editor while all icon descriptions are rendered and measured.

## Best solution

Reduce cold-open work in the custom SelectBox without losing correct description sizing, Codicon previews, keyboard navigation, or viewport placement. Establish a current performance baseline and regression check before choosing an optimization.
