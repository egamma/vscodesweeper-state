# Issue #202024 — Definition Completion is not invoked for non-word tokens (like ++ operators) when ctrl-hovering

[https://github.com/microsoft/vscode/issues/202024](https://github.com/microsoft/vscode/issues/202024)

## Summary

The requested provider-specific trigger mechanism remains absent on current main. Keep the request open for API design discussion; the existing language-wide word pattern is only a partial workaround.

## Change summary

Allow Ctrl+hover definition lookup on operator tokens such as `++` without broadening the language's global word pattern.

## Best solution

Add optional definition-provider trigger metadata used by Ctrl+hover, retaining the language word pattern as the default. This should affect definition-link discovery without changing completion, highlighting, or other word-based behavior.
