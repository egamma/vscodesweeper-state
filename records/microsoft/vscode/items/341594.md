# Issue #341594 — Allow extension tests to run without showing a window on macOS

[https://github.com/microsoft/vscode/issues/341594](https://github.com/microsoft/vscode/issues/341594)

## Summary

Thanks for the detailed proposal. The request is for a new CLI flag to run extension tests with a hidden window on macOS. The electron-main window code has no `show: false` or `showInactive` path, and the issue is hours old with no discussion, so it stays open for the community process.

## Change summary

Add a CLI flag so extension-host test runs on macOS create the window without showing or focusing it.

## Best solution

Decide whether a hidden-window mode for extension tests is acceptable in core. If it is, honor it only together with --extensionTestsPath in the electron-main window creation, then have @vscode/test-electron expose it.
