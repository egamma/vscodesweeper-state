# Issue #153213 — Have `MergeEditorTabInput`-API and `openTab`-API

[https://github.com/microsoft/vscode/issues/153213](https://github.com/microsoft/vscode/issues/153213)

## Summary

Keep open as an API proposal: merge-editor tab inspection shipped only as proposed API, while extensions still open merge editors through the private `_open.mergeEditor` command. The `api-proposal` label independently requires owner-led finalization or abandonment rather than a cleanup close.

## Change summary

Expose merge-editor tabs through the extension API and provide a supported API for extensions to open them.

## Best solution

The API owners should settle the public opening contract, replace the Git extension's private `_open.mergeEditor` dependency, and finalize `TabInputTextMerge` into stable `vscode.d.ts`; alternatively, explicitly abandon the proposal after reviewing its remaining consumers.
