# Issue #323603 — Feature request: React-Grab-like customizable element-selection context for the integrated browser

[https://github.com/microsoft/vscode/issues/323603](https://github.com/microsoft/vscode/issues/323603)

## Summary

Legitimate feature request from a team member for a page-provided hook to customize the element-selection context payload sent to chat from the integrated browser. No existing capability covers this — the current `createElementContextValue` in `browserEditorChatFeatures.ts` builds a fixed snippet with no extensibility point. The Backlog Candidates community process is running (28 of 60 days elapsed).

## Change summary

Allow repos to provide a custom hook (e.g. a global function on the page) that enriches or replaces the context payload when selecting an element in the integrated browser for chat.

## Best solution

Add an optional page-side hook (e.g. `window.__vscodeIntegratedBrowserGetContext`) that `BrowserEditorChatIntegration` invokes during element selection, falling back to the current `createElementContextValue` when absent. The implementation would live in `src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorChatFeatures.ts` and the preload/webview bridge layer. A documented API shape and security review (running arbitrary page code in a trust context) would be needed before shipping.
