# Issue #286847 — Copilot setting focus to terminal ruins experience when terminal is also in right pane

[https://github.com/microsoft/vscode/issues/286847](https://github.com/microsoft/vscode/issues/286847)

## Summary

Keep open: current source still automatically reveals the terminal when terminal output is enabled, replacing Chat when their separate view containers share the right sidebar. The proposed fix was closed without merging, and the issue was reopened after the maintainer tested a different, vertically stacked layout.

## Change summary

Prevent agent terminal commands from switching away from Chat when Terminal and Chat occupy mutually exclusive views in the same right pane.

## Best solution

Keep the active Chat surface visible during ordinary agent command execution when revealing Terminal would replace it. Preserve terminal reveal behavior in non-conflicting layouts and explicitly requested terminal interactions.
