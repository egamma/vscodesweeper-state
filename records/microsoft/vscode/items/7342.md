# Issue #7342 — take advantage of tsserver model of code for faster TypeScript builds

[https://github.com/microsoft/vscode/issues/7342](https://github.com/microsoft/vscode/issues/7342)

## Summary

A real gap remains: VS Code still launches a separate `tsc` process for builds instead of reusing tsserver's in-memory project model. The required builder and emit capabilities fundamentally belong in TypeScript, so this should remain open as upstream work.

## Change summary

Reuse tsserver's parsed and type-checked project model to accelerate TypeScript checking and emission.

## Best solution

TypeScript should expose an efficient project build and emit operation through tsserver, after which the built-in TypeScript extension can use it instead of spawning `tsc`. Project-wide diagnostics remain separately tracked by https://github.com/microsoft/vscode/issues/13953.
