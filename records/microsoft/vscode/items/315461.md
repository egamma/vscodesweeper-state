# Issue #315461 — Markdown Language Features: Default Preview key combination (Ctrl Shift V) conflicting with Terminal default Paste key combination

[https://github.com/microsoft/vscode/issues/315461](https://github.com/microsoft/vscode/issues/315461)

## Summary

Already fixed on main and shipped in 1.120.0. The `markdown.togglePreview` keybinding now includes `!terminalFocus` in its when clause, so Ctrl+Shift+V pastes in the terminal as expected.

## Change summary

Ctrl+Shift+V in the terminal triggers Markdown preview instead of pasting when a Markdown file is active in the editor.

## Best solution

Keep the shipped fix (commits 02103bdd482 + a8479a54933); no further change needed. Reporter was on 1.119.0 — updating to 1.120.0+ resolves the conflict.
