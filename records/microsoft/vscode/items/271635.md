# Issue #271635 — Workspace trust: sometimes extensions are enabled before a workspace is trusted, then get disabled when I press the trust button

[https://github.com/microsoft/vscode/issues/271635](https://github.com/microsoft/vscode/issues/271635)

## Summary

Keep open for investigation of extension availability after granting workspace trust. The thread contains a maintainer-confirmed related reproduction and increasingly frequent failures affecting built-in Git; the possible trust-boundary concern requires human review, not a cleanup close.

## Change summary

Granting workspace trust intermittently unloads the theme and leaves Git and other extension functionality unavailable, especially in directories under /tmp.

## Best solution

Establish the startup and trust-transition failure behind the missing extensions, separating cached theme appearance and settings-write timing from actual extension activation. Restore expected functionality in trusted workspaces while preserving restrictions before trust is granted.
