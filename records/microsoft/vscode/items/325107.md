[https://github.com/microsoft/vscode/issues/325107](https://github.com/microsoft/vscode/issues/325107)

## Summary

Keep open: independent reporters confirm that Azure DevOps semantic indexing remains unauthorized after successful Microsoft sign-in. Current source explains the displayed error but does not establish why authorization fails; neither the historical retry fix nor the related request-deduplication issue resolves this report.

## Change summary

Azure DevOps semantic indexing remains unavailable after a successful Microsoft/AAD sign-in with an account that can access the repository.

## Best solution

Diagnose the Microsoft-session-to-ADO semantic-search authorization boundary in the bundled Copilot code, then restore indexing access for eligible accounts. Distinguish session or request defects from endpoint access requirements without assuming that working Git credentials establish semantic-search authorization.
