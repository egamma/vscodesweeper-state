# Issue #297363 — Memory picker lacks connection to chat widget

[https://github.com/microsoft/vscode/issues/297363](https://github.com/microsoft/vscode/issues/297363)

## Summary

Keep open: the memory picker still selects session files from the active chat without identifying the owning session. The existing command does not cover the requested session attribution or cross-session browsing, and no verified canonical was found.

## Change summary

Make the memory picker's relationship to chat sessions explicit, potentially by listing memory files from multiple sessions with session labels.

## Best solution

Make session ownership visible in the Show Memory Files picker in ToolsContribution while retaining separate user and repository scopes. A maintainer should settle whether the picker remains active-session-only with explicit attribution or becomes a grouped cross-session browser.
