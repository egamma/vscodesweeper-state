# Issue #19534 — Customizing the rendering of matching brackets

[https://github.com/microsoft/vscode/issues/19534](https://github.com/microsoft/vscode/issues/19534)

## Summary

Keep open in the Backlog: current theming supports bracket-match background, border, and foreground colors, but not the requested underline, bold, or selectable border style. With 113 community upvotes, this remains an accepted and well-supported feature gap.

## Change summary

Allow users or themes to render matching brackets with styles such as underline or bold instead of the fixed rectangular border.

## Best solution

Add a narrowly scoped bracket-match rendering-style option in the editor bracket-matching contribution while preserving the current outline as the default and continuing to use the existing theme colors.
