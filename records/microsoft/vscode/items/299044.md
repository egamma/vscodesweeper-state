## Summary

Thanks for the report and confirmation. Plan mode is violating its stated read-only behavior by allowing mutating tool calls, so this should remain open for diagnosis in the core Copilot plan-mode path.

## Change summary

Prevent Claude Sonnet 4.6 from editing files or running commands while Copilot Chat is in Plan mode.

## Best solution

Enforce Plan mode's read-only contract at the tool-availability or execution boundary rather than relying only on model instructions, while retaining any non-mutating tools needed to inspect the workspace and produce a plan.
