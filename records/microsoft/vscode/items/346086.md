# Issue #346086 — Agents window: show Claude and Codex usage limits (5-hour / weekly) for agent host sessions

[https://github.com/microsoft/vscode/issues/346086](https://github.com/microsoft/vscode/issues/346086)

## Summary

Keep open: the ChatGPT account menu already displays both usage windows and reset times, but Claude subscription usage and an indicator visible while typing remain missing. The related newer requests do not establish a canonical duplicate.

## Change summary

Display Claude and Codex subscription usage percentages and reset times in the Agents window without requiring users to leave their session.

## Best solution

Extend the existing account-usage experience to Claude and provide a compact, account-aware indicator visible during chat input. Decide its placement and warning behavior before implementation; a customizable status-bar framework is not required to deliver the central request.

- **Trace:**
