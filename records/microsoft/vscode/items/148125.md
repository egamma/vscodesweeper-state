# Issue #148125 — Support DAP's ValueFormat for formatting values in variables list

[https://github.com/microsoft/vscode/issues/148125](https://github.com/microsoft/vscode/issues/148125)

## Summary

A real debug UX and protocol-integration gap remains: extensions can currently rewrite DAP traffic through a DebugAdapterTracker, but VS Code still lacks built-in controls that send the standardized ValueFormat fields. The Backlog milestone and limited demand favor keeping this classified as a feature request rather than treating the middleware workaround as complete coverage.

## Change summary

Add built-in variables-view formatting controls and propagate DAP ValueFormat options, initially including hexadecimal number display.

## Best solution

Implement format selection in the debug variables UI and consistently pass the selected ValueFormat through scopes, variables, and evaluate requests, while preserving adapters' existing default formatting when no option is selected.
