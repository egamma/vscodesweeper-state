# Issue #325684 — Agent Sessions: clicking inline tool-result images opens sidecar tab instead of Image Carousel

[https://github.com/microsoft/vscode/issues/325684](https://github.com/microsoft/vscode/issues/325684)

## Summary

The bug remains on current main: Agent Sessions resolves and renders response-image URIs, but the Markdown response path does not wire ordinary inline images to the carousel click behavior. A maintainer acknowledged the report as a valid catch, so it should remain open for a focused fix.

## Change summary

Clicking an inline image referenced by an Agent Sessions response opens a side editor instead of the enabled Image Carousel.

## Best solution

Make response Markdown images use the Image Carousel when `imageCarousel.chat.enabled` is enabled, while preserving the existing opener behavior when it is disabled and leaving non-image response links unchanged.

## Evidence

- **confirmed report:** The reporter reproduced the behavior with two independently generated PNG files, after reload and with `imageCarousel.chat.enabled` explicitly enabled; a maintainer acknowledged it as a valid catch at https://github.com/microsoft/vscode/issues/325684#issuecomment-4962216858.
- **current source path:** src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatMarkdownContentPart.ts transforms response image URIs through `IChatSessionsService.resolveChatResponseUri`, then delegates decoration to `ChatMarkdownDecorationsRenderer`; that renderer scans only `a` elements and adds no carousel interaction to rendered `img` elements.
- **missing integration:** src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatInlineAnchorWidget.ts opens recognized image file anchors through `IChatImageCarouselService`, but that behavior is limited to anchors accepted by `renderFileAnchor`; ordinary inline Markdown images remain on the generic Markdown opener path.
- **existing capability:** The carousel service and attachment integration landed in https://github.com/microsoft/vscode/commit/4c822235d64e2486552fd52187d1b2a29fa8f4f1, but its diff did not cover this Agent Sessions inline-response-image path.
- **canonical search:** No older open issue with the same observable symptom was found. https://github.com/microsoft/vscode/issues/336296 concerns downloading remote-session images rather than opening inline images in the carousel.
