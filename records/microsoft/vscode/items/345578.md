# Issue #345578 — Sessions with child chats revert to unread after "Mark as Read" in the editor window

[https://github.com/microsoft/vscode/issues/345578](https://github.com/microsoft/vscode/issues/345578)

## Summary

The editor's read command still optimistically marks a multi-chat session read while the host rejects that state because its chats remain unread. This report remains necessary; the inspected related issues do not cover the same failing flow.

## Change summary

Make explicit read operations in the editor window produce a durable, truthful read state for sessions containing child chats.

## Best solution

Align the editor session row and its read commands with the host's per-chat read contract, including a working bulk-read operation. Preserve independent child read state and the host's aggregate rules rather than masking unread chats with a temporary session flag.
