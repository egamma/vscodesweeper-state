# Issue #345578 — Sessions with child chats revert to unread after "Mark as Read" in the editor window

[https://github.com/microsoft/vscode/issues/345578](https://github.com/microsoft/vscode/issues/345578)

## Summary

The current source still permits the editor to show a multi-chat session as read without clearing its chats' unread state. Keep this open: the host explicitly rejects that aggregate read transition, and the related reports do not establish an equivalent canonical.

## Change summary

Make explicit read actions on sessions containing child chats produce a consistent read state that survives refresh and restart.

## Best solution

Align the editor's read actions with the host's per-chat read aggregate, preserving the rule that unread counted chats keep their session unread. Settle whether the parent action acknowledges all counted chats or exposes their independent read state, then verify persistence through refresh and restart.
