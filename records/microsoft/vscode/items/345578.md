# Issue #345578 — Sessions with child chats revert to unread after "Mark as Read" in the editor window

[https://github.com/microsoft/vscode/issues/345578](https://github.com/microsoft/vscode/issues/345578)

## Summary

The editor's parent-level read operation still conflicts with the host's multi-chat read aggregate: the editor optimistically shows read, while the host retains unread children and rejects the aggregate read transition. Keep this open; current source explains the reported persistence mismatch.

## Change summary

Make explicit Mark as Read and Mark All as Read operations on multi-chat sessions persist across refresh and restart in the normal editor window.

## Best solution

Make the editor's session-level read commands successfully clear the relevant conversations' unread state without weakening the host's aggregate-read invariant. Preserve independent child-chat operations, opaque host-advertised identities, and older-host compatibility.
