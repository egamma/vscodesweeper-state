# Issue #344876 — Canvases should adapt to the host app and its theme

[https://github.com/microsoft/vscode/issues/344876](https://github.com/microsoft/vscode/issues/344876)

## Summary

Keep open as a feature request: the inspected canvas presentation path does not expose a documented host identity and semantic theme contract to providers. Existing editor theming and browser inspector theme propagation do not satisfy the requested cross-host, live-updating presentation context.

## Change summary

Expose host identity and semantic appearance context so canvas providers can adapt to each host and follow theme changes without changing their open input.

## Best solution

Define a documented, optional presentation contract shared with the canvas SDK, then connect VS Code's active theme to canvas content with live updates and predictable fallbacks. Keep canvas identity, content, actions, and caller-supplied input independent of host appearance.
