# Issue #326538 — Language Models panel mixes LLM providers and chat session agents, appearing as confusing duplicates

[https://github.com/microsoft/vscode/issues/326538](https://github.com/microsoft/vscode/issues/326538)

## Summary

Confirmed in current source: agent-host chat sessions (Claude, Copilot CLI, Codex) each register their own `AgentHostLanguageModelProvider` vendor, so they surface as separate, greyed-out entries in the Manage Language Models panel alongside real LLM provider extensions with the same display name, exactly as reported. This is a real, still-open UX/architecture gap in an actively evolving area (model-byok), not something fixed on main.

## Change summary

The Manage Language Models panel mixes true LLM provider entries with agent-host chat-session-agent vendors that happen to share display names (e.g. 'Claude', 'Copilot'), making them look like duplicates.

## Best solution

In `src/vs/workbench/contrib/chat/browser/chatManagement/chatModelsViewModel.ts` / `agentHostLanguageModelProvider.ts`, either exclude agent-host session vendors from the provider list entirely (since their models are already deduped elsewhere per the existing 'Agent-host BYOK models are copies...' comment) or render them under a clearly separate 'Chat Agents' section with distinct labeling, rather than as greyed, crossed-eye entries in the same flat list as model providers.
