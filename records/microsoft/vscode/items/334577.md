# Issue #334577 — Customizations migration: Hint disappears or reappears unexpectedly through reloads, settings changes

[https://github.com/microsoft/vscode/issues/334577](https://github.com/microsoft/vscode/issues/334577)

## Summary

The repeated hint in `once` mode was fixed, but the reload-disappearance symptom remains explainable on current main: the workbench injects the hint locally while restored Agent Host responses are rebuilt from provider history. This team-authored issue should remain open and route to the Agent Host/customizations owners until the intended persistence behavior is decided.

## Change summary

Make customization migration hints behave consistently through session reloads, response completion, and changes between `once` and `always` modes.

## Best solution

Prefer preserving a migration notification as part of the response it accompanied while separately retaining the per-session `once` state, so reload neither removes historical context nor causes another hint. Confirm that persistence contract with the chat/customizations owners before implementation because the original report explicitly leaves the expected reload behavior open.
