# Issue #326629 — Forking a conversation and changing mode deletes your prompt and starts blank "implementation"

[https://github.com/microsoft/vscode/issues/326629](https://github.com/microsoft/vscode/issues/326629)

## Summary

The current source confirms a mode change can reprocess a completed Plan response's automatic handoff, replacing the draft with “Start implementation” and submitting it. This is a core chat-input bug and should remain open.

## Change summary

Switching a forked conversation from Agent to Plan can erase the draft and automatically submit an implementation handoff.

## Best solution

In `ChatWidget`, trigger an automatic Plan-to-implementation handoff only when the relevant response first completes, never during generic rerenders such as a user-initiated mode change, and preserve any existing draft.
