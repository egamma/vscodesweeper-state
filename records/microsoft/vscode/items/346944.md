# Issue #346944 — worktree cleanup: improve the hover

[https://github.com/microsoft/vscode/issues/346944](https://github.com/microsoft/vscode/issues/346944)

## Summary

Keep open: the cleanup workspace hover still displays an unlabeled URI, and information remains split across column-specific hovers. Current source uses mouse-anchored hovers, so the reported positioning problem still needs visual confirmation.

## Change summary

Make worktree cleanup hovers explain their paths and metadata clearly, avoid raw file URLs, and remain close to the relevant entry.

## Best solution

Provide clearly labeled, human-readable workspace and worktree details in the cleanup editor, with predictable hover placement. Decide whether those details should be consolidated into one row-wide hover or remain column-specific.
