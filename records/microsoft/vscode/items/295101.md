# Issue #295101 — Feature Request: 'Edit in settings.json' shortcut from Settings GUI

[https://github.com/microsoft/vscode/issues/295101](https://github.com/microsoft/vscode/issues/295101)

## Summary

Valid feature request: an 'Edit in settings.json' shortcut for all settings (not just complex ones) does not exist on current main, and an open PR is already implementing it.

## Change summary

Add an 'Edit in settings.json' button/action for all individual settings in the Settings GUI, not just complex settings.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/295102 which adds the 'Edit in settings.json' shortcut to all setting types. The existing infrastructure in `SettingComplexRenderer` and the `_onDidOpenSettings` event already handles navigating to a specific setting key in the JSON file — extending it to other renderers via the gear menu is straightforward.
