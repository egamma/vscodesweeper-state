# Issue #273678 — Chat close button disappears in narrowest width

[https://github.com/microsoft/vscode/issues/273678](https://github.com/microsoft/vscode/issues/273678)

## Summary

Fixed on current main: Chat-specific header actions now overflow as the secondary side bar narrows, while the separate maximize and close controls remain visible.

## Change summary

Keep the Chat pane close action accessible when the secondary side bar is reduced to its narrowest width.

## Best solution

Retain the responsive auxiliary-bar toolbar behavior from commit f3e4cb8b7e29118bc78ec631d4f5fc6fc51f9e12, which moves Chat actions into the overflow menu before they can obscure the global close control.
