# Issue #291901 — Out of bounds text selection behaves weird

[https://github.com/microsoft/vscode/issues/291901](https://github.com/microsoft/vscode/issues/291901)

## Summary

Well-documented bug with word-wrapped out-of-bounds mouse selection behaving inconsistently compared to every other text application. An open community PR (https://github.com/microsoft/vscode/pull/262910) exists but has not been merged — the issue should stay open until that PR lands or an alternative fix is applied.

## Change summary

When selecting text with the mouse and dragging outside the editor bounds to the right, the selection endpoint jumps incorrectly onto the next wrapped line instead of staying at the end of the current wrapped line.

## Best solution

Review and land the open community PR https://github.com/microsoft/vscode/pull/262910, which fixes the out-of-bounds mouse position calculation in the editor's mouse handler to match the behavior of other text applications (gedit, LibreOffice, browsers, etc.).
