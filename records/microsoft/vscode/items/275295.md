# Issue #275295 — Created file from plan mode handoff is linkified in chat

[https://github.com/microsoft/vscode/issues/275295](https://github.com/microsoft/vscode/issues/275295)

## Summary

Current main still omits `untitled:` from chat's allowed link schemes, so the Plan handoff's created-file reference cannot be rendered as an actionable chat link. This team-authored polish item remains necessary and should stay open.

## Change summary

Make the untitled plan document created by the Plan mode “Open in Editor” handoff an actionable link in chat.

## Best solution

Allow trusted `untitled:` resource links through the chat markdown renderer while leaving the general markdown sanitizer unchanged, with a renderer test covering the preserved target.
