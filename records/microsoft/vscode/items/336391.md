# Issue #336391 — Chat panel hangs indefinitely when the Copilot backend process dies without automatic restart

[https://github.com/microsoft/vscode/issues/336391](https://github.com/microsoft/vscode/issues/336391)

## Summary

Keep open: manually terminating the backend and sending another message provides sufficient steps to retest the silent hang, even though spontaneous shutdowns lack a deterministic trigger. Current main has evolved SDK integration and some closed-connection recovery, but neither a fixing commit nor coverage of this exact process-death scenario was established.

## Change summary

Copilot Chat remains indefinitely pending after its backend exits instead of reporting a failure and allowing recovery.

## Best solution

Ensure backend termination settles affected chat requests with an actionable error and allows subsequent requests to reconnect without restarting the extension host. First identify the integration used by the reported conversation and reproduce process termination both during a turn and between turns.
