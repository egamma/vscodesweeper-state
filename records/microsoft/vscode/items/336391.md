# Issue #336391 — Chat panel hangs indefinitely when the Copilot backend process dies without automatic restart

[https://github.com/microsoft/vscode/issues/336391](https://github.com/microsoft/vscode/issues/336391)

## Summary

Thorough investigation, but there's no deterministic repro yet — the reporter couldn't pin down what triggers the backend death or confirm it isn't tied to their unusually large workspace, so this needs a confirmed reproduction before further triage.

## Change summary

When the headless Copilot CLI backend process dies unexpectedly, the Chat panel hangs indefinitely on a spinner instead of detecting the dead connection and recovering or surfacing an error.

## Best solution

If a deterministic trigger can be identified (or telemetry from `reportCopilotClientOperationFailure`/`reportCopilotClientRecovery` in copilotFailureTelemetry.ts shows a gap), extend the existing reactive `connectionClosed` recovery in `copilotAgent.ts` (`_handleClientOperationFailure` / `_runClosedConnectionRecovery`) with a proactive liveness check so a dead backend is detected even when no RPC call is currently failing.
