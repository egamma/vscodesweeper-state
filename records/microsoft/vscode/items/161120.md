# Issue #161120 — Define ordering when multiple outlines are present

[https://github.com/microsoft/vscode/issues/161120](https://github.com/microsoft/vscode/issues/161120)

## Summary

A real extension API gap remains: provider ordering exists internally but extensions cannot explicitly control it. The accepted Backlog request has 27 community upvotes and should remain open.

## Change summary

Allow extensions to define which document-symbol provider appears first when multiple outlines contribute to one document.

## Best solution

Define a stable ordering mechanism for document-symbol providers, likely through `DocumentSymbolProviderMetadata`, and apply it consistently to Outline, breadcrumbs, and other symbol consumers.
