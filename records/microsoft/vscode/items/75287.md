Keep open: the later discussion narrowed this from the `.ico` to Windows Start tile assets, and current main still only declares 70x70 and 150x150 tile PNGs rather than higher-density scale variants. ## Change summary

The Windows Start menu tile icon appears blurry or jagged on HiDPI systems because the packaged tile assets lack sufficient resolution/intermediate sizes.

## Best solution

Have the Windows/icon owners decide the correct tile asset set and add the needed high-DPI/intermediate VisualElements assets under `resources/win32`, with visual verification on a scaled Windows display.
