# Issue #333462 — Very confusing free Copilot Pro upgrade flow

[https://github.com/microsoft/vscode/issues/333462](https://github.com/microsoft/vscode/issues/333462)

## Summary

Active, well-diagnosed bug: a maintainer confirmed the model-list-not-refreshing issue traces to a no-op refreshToken call, a 10-minute CAPI model cache with no token-change listener, a one-shot window-focus entitlement check, and a missed upgrade-success callback on the free-upgrade path. No fix has landed yet, so this stays open.

## Change summary

After a free Copilot Pro upgrade inside VS Code, the model picker keeps showing the pre-upgrade/upgrade-prompt UI until the window is manually reloaded, and the upgrade flow itself is confusing (dead-end free page, then a paid-upgrade page shown despite already being upgraded).

## Best solution

Fix the entitlement refresh pipeline in the Copilot extension: make refreshToken force a re-fetch, invalidate/refresh the cached CAPI /models response on token change, and retry the window-focus entitlement check instead of firing once — plus handle the free-upgrade completion path that currently skips the return_to callback.
