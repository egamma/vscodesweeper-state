# Issue #145018 — Allow setting font weights or semibold/thin/heavy... in fontStyle in tokenColors

[https://github.com/microsoft/vscode/issues/145018](https://github.com/microsoft/vscode/issues/145018)

## Summary

This remains a valid Backlog feature request with 37 upvotes. Current main supports only boolean bold styling for tokens, not granular font weights, and no open canonical issue supersedes it.

## Change summary

Allow token color rules to assign numeric or named font weights such as thin, semibold, or heavy.

## Best solution

Add a separate `fontWeight` property to token theme settings and carry it consistently through TextMate and semantic-token resolution and rendering, without multiplying `fontStyle` combinations.
