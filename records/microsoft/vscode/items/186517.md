# Issue #186517 — Git - Performance Improvement: Revert Selected Ranges Should Not Replace The Entire Document

[https://github.com/microsoft/vscode/issues/186517](https://github.com/microsoft/vscode/issues/186517)

## Summary

The diff editor has targeted revert actions, but the original Git command still replaces the entire document. Keep this accepted cleanup open: the maintainer explicitly identified normal-editor integration as remaining work.

## Change summary

Revert selected Git changes without replacing unchanged document content or unnecessarily invalidating editor state.

## Best solution

Complete the transition to targeted editor-owned revert behavior, including the normal-editor workflow and existing Git command entry points. Treat staging and unstaging parity as a separate scope decision rather than assuming the diff-editor gutter actions complete this issue.
