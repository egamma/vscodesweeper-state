# Issue #327958 — Terminal in an auxiliary window stops rendering on U+2591: custom glyph rasterizer calls createElement in a child window

[https://github.com/microsoft/vscode/issues/327958](https://github.com/microsoft/vscode/issues/327958)

## Summary

The report identifies a concrete xterm.js WebGL rasterizer incompatibility with VS Code auxiliary windows. Keep it open and route it to the terminal maintainers for upstream coordination.

## Change summary

Shade block characters stop WebGL terminal rendering after the terminal is moved into an auxiliary window.

## Best solution

Fix xterm.js CustomGlyphRasterizer so temporary canvases use an explicitly supported document or canvas factory, then consume the corrected xterm.js version in VS Code.
