# Issue #276044 — Tasks misses basic editor support

[https://github.com/microsoft/vscode/issues/276044](https://github.com/microsoft/vscode/issues/276044)

## Summary

Keep open: the current tasks schema still accepts the background-only matcher in the report, while the task parser rejects it. Built-in JSON validation does not cover this missing constraint, and no verified open canonical was found.

## Change summary

Provide actionable editor diagnostics for invalid task problem matchers before saving, rather than relying on generic task errors.

## Best solution

Make tasks.json editor validation express the matcher requirements enforced by the task parser, including the need for a pattern or an inherited base matcher. Preserve valid base-derived matchers and identify the missing requirement directly in the editor.
