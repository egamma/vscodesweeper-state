# Issue #335802 — Modern UI - Add padding to Chat session widgets

[https://github.com/microsoft/vscode/issues/335802](https://github.com/microsoft/vscode/issues/335802)

## Summary

Traced this in the modernUI padding stylesheet: the chat/agent-session list rows are deliberately excluded from the generic pane-row inset rules and instead get their own `.agent-session-item` padding, but unlike the generic rows that stylesheet has no `.modern-ui-compact` override for the chat session rows — so they keep full-size padding in Compact density while everything else around them shrinks, matching the reporter's 'only in Compact' observation.

## Change summary

In the experimental Modern UI with Compact density enabled, Chat session list rows (New Chat Editor and the sidebar chat view) keep full-size padding instead of the tighter compact spacing used elsewhere.

## Best solution

Add a `.modern-ui.modern-ui-compact` override in modernUI/browser/media/padding.css for `.chat-viewpane .agent-session-item` (and related chat-view-title padding) mirroring the existing compact override already applied to generic `.monaco-list-row` at line ~70, so chat session rows shrink consistently with the rest of the compact layout.
