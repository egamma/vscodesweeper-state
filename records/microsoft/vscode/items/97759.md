# Issue #97759 — No images in jsdoc hover or notebooks in remote/web

[https://github.com/microsoft/vscode/issues/97759](https://github.com/microsoft/vscode/issues/97759)

## Summary

Still an open architectural gap: images in JSDoc hovers and notebooks cannot load from remote/virtual file systems because no service worker or protocol handler exists outside webviews to resolve those URIs. No fixing commit found on main.

## Change summary

Images referenced in JSDoc comments (via markdown) render correctly in local windows but are broken in remote/web because the hover renderer cannot resolve remote filesystem URIs.

## Best solution

Implement a mechanism (likely a service worker or protocol handler outside the webview context) that can resolve remote/virtual filesystem image URIs for the markdown renderer used in hovers and notebooks. The `remoteImageIsAllowed` sanitizer hook and `baseUri` support exist but are insufficient — actual image byte fetching from virtual schemes needs a new transport layer in `src/vs/base/browser/markdownRenderer.ts` or a companion service.
