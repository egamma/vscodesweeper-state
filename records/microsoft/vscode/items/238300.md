# Issue #238300 — Can't Install Latest VS Code: Dependency Issues with .deb Package

[https://github.com/microsoft/vscode/issues/238300](https://github.com/microsoft/vscode/issues/238300)

## Summary

Still reproduces: the .deb package declares dependencies using pre-t64 package names (e.g. `libasound2`) that Ubuntu 24.04+ renamed with a `t64` suffix, causing GUI installers (QAPT, gdebi) to fail dependency resolution. CLI `dpkg -i` works as a workaround since it skips strict resolution. No fix found on main.

## Change summary

Installing VS Code's .deb package via GUI package installers on Ubuntu 24.04+ fails with 'Cannot satisfy dependencies' due to the Debian t64 package renaming transition.

## Best solution

Update the sysroot or dependency calculation (build/linux/debian/) to emit t64-aware package names or add alternatives (e.g. `libasound2 | libasound2t64`) so GUI installers can resolve dependencies on distributions that completed the t64 transition. The fix lives in `build/linux/debian/dep-lists.ts` and/or the sysroot used by `calculate-deps.ts`.
