# Issue #185200 — Allow EnvironmentVariableCollection to unset variables

[https://github.com/microsoft/vscode/issues/185200](https://github.com/microsoft/vscode/issues/185200)

## Summary

Valid feature request with 14 upvotes, still unimplemented on main — the EnvironmentVariableMutatorType enum only has Replace/Append/Prepend and no proposed API exists for unsetting variables. Keeping open in the Backlog.

## Change summary

Allow extensions to unset (remove) environment variables via EnvironmentVariableCollection, rather than only replacing/appending/prepending.

## Best solution

Add an `Unset` entry to `EnvironmentVariableMutatorType` (in `src/vs/platform/terminal/common/environmentVariable.ts` and the stable API in `vscode.d.ts`), wire it through `applyToProcessEnvironment` to `delete env[variable]`, and expose it via a new method or by accepting `undefined` as the value in `replace()`. The API shape proposed by Tyriar in Comment 2 is a reasonable starting point, though the breaking-change concern needs resolution — a new enum value with a dedicated `unset(variable)` method avoids breaking the existing `replace` signature.
