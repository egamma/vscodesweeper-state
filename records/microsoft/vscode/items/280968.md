# Issue #280968 — Support starting new sessions from IChatWidgetService

[https://github.com/microsoft/vscode/issues/280968](https://github.com/microsoft/vscode/issues/280968)

## Summary

The requested service-level operation is still missing on current main: callers must separately create a chat model reference, open its URI, and dispose the temporary reference. This team-authored debt remains valid and has no open canonical issue or fixing PR.

## Change summary

Add a one-step IChatWidgetService operation that creates a new local chat session directly in a requested view or editor target without exposing a model reference to the caller.

## Best solution

Centralize new-session creation and lifetime handoff in IChatWidgetService, then migrate callers such as inline chat and the new-chat actions away from manually creating session resources or model references.
