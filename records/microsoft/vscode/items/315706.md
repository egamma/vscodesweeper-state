# Issue #315706 — Cannot re-enable AI features for a workspace after disabling

[https://github.com/microsoft/vscode/issues/315706](https://github.com/microsoft/vscode/issues/315706)

## Summary

The workspace re-enable action remains incorrectly disabled on current main after AI features are disabled for that workspace. The defect is directly visible in the action-state logic, and this team-authored Backlog issue should remain open for a bounded fix.

## Change summary

Re-enable the “Enable AI Features (Workspace)” action after AI features have been disabled for the current workspace.

## Best solution

Make the workspace enable action available whenever the Copilot Chat extension is disabled for that workspace, then restore both extension enablement and the workspace AI setting without changing global AI preferences.
