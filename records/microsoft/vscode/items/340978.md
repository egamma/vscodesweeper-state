# Issue #340978 — Agent Host customization sync re-runs every ~50 ms with Claude/Codex agents enabled, pinning main process at ~2.6 cores

[https://github.com/microsoft/vscode/issues/340978](https://github.com/microsoft/vscode/issues/340978)

## Summary

Thanks for the thorough investigation. The report is complete (clean-profile repro, settings bisection, fs-call counts, hot path), but I could not confirm the self-triggering loop from source alone, so it stays open for a maintainer to retest and diagnose.

## Change summary

With the Claude and Codex agent-host session types enabled, the customization scope re-resolves about every 50 ms, which pins the main process CPU.

## Best solution

Find which trigger (prompts or skills change events, the plugins autorun, or the MCP servers autorun) re-fires after each resolve in the agent host customization scope. Break the loop, for example by not scheduling when the resolved result is unchanged. Also avoid re-listing every prompt storage on each pass.
