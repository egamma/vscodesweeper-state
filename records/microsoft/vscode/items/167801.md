## Summary

The reported replacement still follows directly from current source: Preserve Case capitalizes the replacement using the initial U in Utils.uuidv4(). Keep this accepted bug open; handling removal of a qualified prefix needs an explicit behavior decision without breaking existing capitalization rules.

## Change summary

Replacing Utils.uuidv4() with uuidv4() while Preserve Case is enabled produces Uuidv4() instead of the requested uuidv4().

## Best solution

Define how Preserve Case handles removal of a qualified identifier prefix, then support the reported lowercase result consistently in editor and workspace replacement while retaining established case-preservation behavior for ordinary replacements.
