# Issue #344607 — UX / UI: Model picker became difficult to use

[https://github.com/microsoft/vscode/issues/344607](https://github.com/microsoft/vscode/issues/344607)

## Summary

Keep open for the model-picker owner's design discussion: provider icons and type-to-search help, but neither fully addresses identifying inactive providers without trial and error. Current source deliberately labels only the active tab, so this is a usability improvement rather than a confirmed functional defect.

## Change summary

Make model providers and local model groups readily identifiable when choosing a model, without repeatedly switching icon-only tabs.

## Best solution

Provide an understandable multi-provider browsing experience even when providers share a generic icon, while retaining cross-provider keyboard search. The model-picker owner should decide whether persistent provider names, a list presentation, or another discoverable design best achieves that.
