# Issue #303788 — Windows: First VS Code instance sometimes replaces PATH with full Visual Studio DevShell environment

[https://github.com/microsoft/vscode/issues/303788](https://github.com/microsoft/vscode/issues/303788)

## Summary

The launch-dependent PATH replacement needs further isolation before attributing it to VS Code startup. The report distinguishes manually disabled extensions from --disable-extensions, but there is no independent reproduction or conclusive failing path in current source.

## Change summary

Launching the first VS Code instance from Explorer sometimes gives integrated PowerShell a Visual Studio DevShell PATH that omits user paths.

## Best solution

Identify whether the altered PATH originates in the Explorer-inherited process environment, terminal configuration, persisted extension environment collections, or PowerShell startup. Correct the responsible path once a fresh-data, no-extension, no-PowerShell-profile comparison establishes where the replacement occurs.

This path does not launch a Visual Studio developer shell; source inspection therefore does not substantiate the claimed startup mechanism.
- **Terminal environment composition:** src/vs/workbench/contrib/terminal/common/terminalEnvironment.ts:createTerminalEnvironment copies the base environment, then merges configured and launch-specific environment overrides. src/vs/workbench/contrib/terminal/browser/terminalProcessManager.ts:_resolveEnvironment subsequently applies extension environment collections, separately from the useShellEnvironment choice. Changing terminal.integrated.inheritEnv alone does not isolate all possible PATH modifications.
- **Pre-activation mutation remains possible:** src/vs/workbench/contrib/terminal/common/environmentVariableService.ts:EnvironmentVariableService restores persisted extension environment collections from workspace storage in its constructor and invalidates unregistered extensions asynchronously. Consequently, observing a modification before extension activation does not by itself exclude an extension-provided collection. This is a diagnostic lead, not proof that it caused this report.
