# Issue #158036 — Overlapping scrollbar doesn't scroll outer scrollbar

[https://github.com/microsoft/vscode/issues/158036](https://github.com/microsoft/vscode/issues/158036)

## Summary

The recording and maintainer diagnosis confirm a workbench split-view layout bug: the Debug views should shrink to the available height rather than create an outer scrollbar. The issue remains useful because no verified fix or canonical issue currently owns that exact symptom.

## Change summary

Debug sidebar views retain excessive minimum heights in a short window, causing nested and outer scrollbars instead of resizing to fit.

## Best solution

Trace the minimum-size propagation for Debug view panes through the workbench pane composite and split-view widget, then make those views shrink within the available sidebar height while preserving each view's internal scrolling.
