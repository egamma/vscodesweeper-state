# Issue #209374 — OSC hyperlinks are not restored properly on reconnect

[https://github.com/microsoft/vscode/issues/209374](https://github.com/microsoft/vscode/issues/209374)

## Summary

Keep open: terminal reconnection still serializes the buffer through an xterm.js addon that preserves text and styling but omits OSC 8 hyperlink destinations. The remaining work belongs in upstream serialization, followed by adoption and verification in VS Code.

## Change summary

Preserve OSC 8 hyperlink destinations and activation when terminal contents are restored after a window reload.

## Best solution

Make xterm.js serialization round-trip OSC 8 hyperlink metadata, then consume that implementation in VS Code's persistent-terminal replay path. Restored links should retain their original targets while continuing to respect existing activation modifiers and scheme permissions.
