# Issue #348501 — The comment widget should remember the last resize

[https://github.com/microsoft/vscode/issues/348501](https://github.com/microsoft/vscode/issues/348501)

## Summary

Keep open: current source already remembers a resized thread within the window session, but does not establish a shared or durable size preference. This team-authored request has no verified issue-referencing fix that would justify closing it.

## Change summary

Remember the user's chosen floating comment widget size instead of repeatedly using the default.

## Best solution

Establish whether the requested size preference applies to other threads or survives window reloads, then preserve it at that scope in the comments contribution. Retain the existing per-thread layout restoration and editor/content size constraints.
