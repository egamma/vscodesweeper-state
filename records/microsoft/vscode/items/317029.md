# Issue #317029 — Integrated Browser: Not sure how draging works

[https://github.com/microsoft/vscode/issues/317029](https://github.com/microsoft/vscode/issues/317029)

## Summary

Active design discussion between team members about the integrated browser's element selection UX (Ctrl+Shift+C rectangle-drag behavior). The interaction is confusing — it looks like drag-and-drop but is actually range selection. Team-authored and still under discussion; no resolution yet.

## Change summary

The integrated browser's element selection tool (Ctrl+Shift+C) draws a rectangle that looks like a drag gesture but is actually range selection, and the resulting selection doesn't produce a screenshot of the selected area.

## Best solution

Clarify the rectangle-selection UX in the integrated browser's element picker: either make the drawn rectangle produce a screenshot of that exact area (as aeschli expected), or change the visual affordance so it doesn't suggest drag-and-drop. The discussion between aeschli and kycutler is still open on which direction to take.
