# Issue #317029 — Integrated Browser: Not sure how draging works

[https://github.com/microsoft/vscode/issues/317029](https://github.com/microsoft/vscode/issues/317029)

## Summary

Keep open for the browser owner's UX decision: element selection still draws a rectangle but attaches the containing element, rather than that exact region. A separate area-screenshot command covers the desired image capture, but does not resolve the confusing affordance reported here; this team-authored item has no verified factual close.

## Change summary

Clarify the integrated browser's drag-selection feedback so the drawn region does not imply an exact screenshot crop when an enclosing element will be attached.

## Best solution

Make the element picker's visual feedback clearly communicate which element will be attached, while keeping exact-region screenshot capture distinguishable through Add Area Screenshot to Chat. The browser owner should settle whether the element-selection rectangle should remain or be replaced by element-only feedback.
