# Issue #190426 — Set output height limit and scrolling for non-text stream outputs

[https://github.com/microsoft/vscode/issues/190426](https://github.com/microsoft/vscode/issues/190426)

## Summary

The request for height limits and scrolling on non-text (rich/HTML) notebook outputs remains unimplemented on current main. The existing `notebook.output.scrolling` setting only governs text outputs; rich renderer outputs rendered in the webview have no equivalent height cap.

## Change summary

Non-text notebook outputs (dataframes, HTML renderers) lack a configurable height limit and scrollable region, unlike text outputs which respect `notebook.output.scrolling`.

## Best solution

Extend the output scrolling/height-limit mechanism in the notebook webview preloads and backLayerWebView to apply a max-height + overflow:auto to non-text renderer output containers when `notebook.output.scrolling` is enabled, bringing parity with the text output behavior.
