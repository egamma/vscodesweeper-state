# Issue #5940 — Handle pasting code from column selection specially

[https://github.com/microsoft/vscode/issues/5940](https://github.com/microsoft/vscode/issues/5940)

## Summary

Keep open: current main still loses rectangular semantics when a copied column is pasted at one cursor, and no canonical issue fully owns this distinct behavior. This is also a team-authored, accepted Backlog request with substantial community support.

## Change summary

Preserve rectangular column-selection semantics when pasting the copied block at a different single-cursor location.

## Best solution

Extend the editor paste operation to recognize column-selection clipboard metadata and distribute its rows across consecutive destination lines, padding where required. Keep virtual-space support in https://github.com/microsoft/vscode/issues/13960 separate, since basic block paste can be improved without implementing general virtual navigation.
