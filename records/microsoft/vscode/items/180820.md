# Issue #180820 — SCM - highlight repositories with uncommitted changes

[https://github.com/microsoft/vscode/issues/180820](https://github.com/microsoft/vscode/issues/180820)

## Summary

Current VS Code offers per-repository change badges, but they are hidden by default and do not provide change-dependent repository-name highlighting. Keep this accepted Backlog request open: no eligible fixing commit or verified canonical duplicate establishes a factual close.

## Change summary

Make repositories with uncommitted changes easier to distinguish in a workspace containing many repositories.

## Best solution

Evaluate the remaining discoverability gap against the existing scm.providerCountBadge setting before adding another visual mechanism. Any further improvement should make changed repositories recognizable at a glance while retaining a consistent, theme-aware SCM presentation.

- **Current rendering boundary:** src/vs/workbench/contrib/scm/browser/scmRepositoryRenderer.ts, RepositoryRenderer.renderElement, sets each repository badge from provider.count or getRepositoryResourceCount and records data-count.
