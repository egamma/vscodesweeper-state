# Issue #180820 — SCM - highlight repositories with uncommitted changes

[https://github.com/microsoft/vscode/issues/180820](https://github.com/microsoft/vscode/issues/180820)

## Summary

Nonzero repository badges already provide an explicit indicator through scm.providerCountBadge="auto", but remain hidden by default. Keep this accepted Backlog UX request open: a decline close would contradict its triage, and no verified post-report fix establishes completion of the requested highlighting.

## Change summary

Make repositories with uncommitted changes easier to identify when working across many repositories.

## Best solution

Use the existing nonzero count badges as the baseline, and have the SCM owner decide whether their discoverability or default presentation needs improvement. Preserve consistent workbench indicators rather than introducing repository-specific font colors without a design decision.
