# Issue #180820 — SCM - highlight repositories with uncommitted changes

[https://github.com/microsoft/vscode/issues/180820](https://github.com/microsoft/vscode/issues/180820)

## Summary

The central request is now covered by setting scm.providerCountBadge to auto: repositories with changes display a numeric badge, while clean repositories have no badge. Propose closing as completed, with the setting explained to the reporter.

## Change summary

Make repositories with uncommitted changes easy to distinguish in a multi-repository Source Control view.

## Best solution

Use the existing scm.providerCountBadge: auto behavior to distinguish changed repositories without introducing a separate font color. Filtering or sorting repositories remains separate work tracked by existing requests.
