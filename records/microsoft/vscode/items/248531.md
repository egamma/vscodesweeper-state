# Issue #248531 — cellPart toolbar leak

[https://github.com/microsoft/vscode/issues/248531](https://github.com/microsoft/vscode/issues/248531)

## Summary

Confirmed leak on current main: cell toolbar event listeners are registered to the component-lifetime disposable store instead of the cell-specific one, so they accumulate across render/unrender cycles. An open PR (#253762) addresses this but has not merged.

## Change summary

Notebook cell toolbar event listeners leak because they are registered with `this._register()` instead of `this.cellDisposables` in `setupChangeListeners`.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/253762 (or an equivalent fix) that changes `this._register(menu.onDidChange(...))` and `this._register(toolbar.onDidChangeDropdownVisibility(...))` in `setupChangeListeners` to use `this.cellDisposables.add(...)` so they are disposed on `unrenderCell`.
