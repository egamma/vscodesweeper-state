# Issue #279184 — Provide the ability to disable extension specific instructions in agent mode

[https://github.com/microsoft/vscode/issues/279184](https://github.com/microsoft/vscode/issues/279184)

## Summary

The motivating Azure case was fixed in that extension, while current VS Code still does not expose a generic disable action for extension-contributed instructions. Because this is a team-authored Backlog request without an explicitly linked fixing commit, it should remain open for the customizations owners to decide whether a broader override is still wanted.

## Change summary

Allow users to prevent an extension-contributed instruction file from being automatically included in agent prompts.

## Best solution

Keep extension instructions without `applyTo` available for on-demand loading and require extensions to avoid `applyTo: '**'` unless unconditional inclusion is intentional. The customizations owners should decide whether a separate user-controlled override is needed beyond that authoring contract now that the reported Azure misuse is fixed.
