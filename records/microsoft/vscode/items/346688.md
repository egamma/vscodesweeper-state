# Issue #346688 — MCP install prompt shows internal fields, and the installed server is listed by its registry ID

[https://github.com/microsoft/vscode/issues/346688](https://github.com/microsoft/vscode/issues/346688)

## Summary

Keep open: current source explicitly produces the reported installation details, and Gallery installation does not preserve the friendly name through its configuration write. This team-authored presentation issue needs a focused design pass, not a judgment close.

## Change summary

Make MCP Gallery installation prompts readable and show the catalog display name for installed servers instead of their registry ID.

## Best solution

Present the server's friendly name and meaningful execution details without empty environment data or internal field inventories. Preserve opaque configuration identities while making installed Gallery servers recognizable, with a defined fallback when catalog metadata is unavailable.
