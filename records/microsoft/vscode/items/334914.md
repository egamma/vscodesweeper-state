# Issue #334914 — Add confirmation dialog when expanding folders with an excessive number of image files

[https://github.com/microsoft/vscode/issues/334914](https://github.com/microsoft/vscode/issues/334914)

## Summary

Reasonable perf/safety request: expanding a folder with hundreds of thousands of files can freeze the UI with no way to cancel. No existing setting or guard covers this today, so it's a legitimate but unrouted feature request that should go to the explorer/files area owners for a product decision on scope and threshold design.

## Change summary

Add a confirmation dialog (or cancel option) before expanding an Explorer folder that contains an excessive number of files/images, to prevent UI freezes.

## Best solution

Route to the Explorer area owners to weigh a lightweight pre-expansion guard (or, more simply, a cancellable/async expansion with a busy indicator) in src/vs/workbench/contrib/files/browser/views/explorerViewer.ts and explorerView.ts; a configurable threshold setting like the reporter's suggested explorer.confirmOnLargeFolder is one option, but the more foundational fix may be making folder resolution cancellable so no threshold is needed.
