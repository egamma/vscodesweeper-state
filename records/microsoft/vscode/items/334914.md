# Issue #334914 — Add confirmation dialog when expanding folders with an excessive number of image files

[https://github.com/microsoft/vscode/issues/334914](https://github.com/microsoft/vscode/issues/334914)

## Summary

No existing setting or guard covers this — expanding a folder with hundreds of thousands of files can still freeze the Explorer UI with no way to cancel, so this is a real, unaddressed gap worth tracking as a feature request.

## Change summary

Add a threshold-based confirmation dialog (and/or cancel option) before expanding an Explorer folder containing an excessive number of files/images.

## Best solution

Belongs in the Explorer file tree resolution path (src/vs/workbench/contrib/files/browser/views/explorerView.ts and the underlying ExplorerItem/FileService resolve calls) — either add a cheap child-count pre-check with a confirm dialog, or at minimum make folder expansion cancellable so a runaway readdir doesn't freeze the UI; a configurable threshold setting would need product buy-in given the added complexity for a niche case.
