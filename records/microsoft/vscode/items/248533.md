# Issue #248533 — Accept all incoming or current changes for merge conflicts requires manual file saving and staging and does not work on .bin files

[https://github.com/microsoft/vscode/issues/248533](https://github.com/microsoft/vscode/issues/248533)

## Summary

Current main confirms the reported behavior: the SCM actions edit text documents without saving or staging them, while binary conflicts receive no applicable text edit. Existing issues cover saving and staging separately, but neither owns the binary-file failure, so this broader report should remain open.

## Change summary

Make SCM Accept All Current/Incoming fully resolve selected conflicts, including binary files, without requiring separate save and stage operations.

## Best solution

Move SCM resource conflict resolution to a Git-aware path that can choose the index's current or incoming side for both text and binary files, then save and stage only after resolution succeeds. Coordinate the overlapping save and staging work with https://github.com/microsoft/vscode/issues/169923 and https://github.com/microsoft/vscode/issues/250857.
