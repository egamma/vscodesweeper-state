# Issue #196764 — allow configuring the ghost text style

[https://github.com/microsoft/vscode/issues/196764](https://github.com/microsoft/vscode/issues/196764)

## Summary

The ghost text font style is still hardcoded as italic in CSS with no user-configurable setting; the request remains valid and unimplemented. Team-authored accessibility feature request — keeping open.

## Change summary

Allow users to configure the ghost text font style (e.g. italic vs normal) for inline completions and suggestions.

## Best solution

Add an editor setting (e.g. `editor.inlineSuggest.fontStyle`) that controls the CSS `font-style` applied to `.ghost-text-decoration` in `src/vs/editor/contrib/inlineCompletions/browser/view/ghostText/ghostTextView.css`. The color is already configurable via `editorGhostText.foreground`/`background`/`border` theme tokens; font style is the missing dimension, especially important for accessibility (italic text is harder to read for some users).
