No fix referencing this issue exists on main. Keeping open per team-authored item policy.

## Change summary

Screen readers skip filename reference links in Copilot chat responses, leaving bulleted file lists empty for assistive technology users.

## Best solution

Investigate why `inlineReference` parts in `src/vs/workbench/contrib/chat/browser/accessibility/chatResponseAccessibleView.ts` (lines 303-319) are not surfacing to screen readers — possible causes include inline references being embedded within markdown content rather than appearing as separate `inlineReference` response parts, or the accessible view text not being properly structured for ARIA consumption. The fix likely involves ensuring file references produce readable text in the accessible view output regardless of how they arrive in the response model.
