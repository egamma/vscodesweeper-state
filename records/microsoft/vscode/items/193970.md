# Issue #193970 — Adjust save location of local history

[https://github.com/microsoft/vscode/issues/193970](https://github.com/microsoft/vscode/issues/193970)

## Summary

Keep open: this accepted Backlog request remains unimplemented, and the current `keep` label explicitly protects it from an out-of-scope cleanup. Local History still uses a fixed remote or user-data location, so rebuilding an ephemeral dev container can discard it.

## Change summary

Allow users to choose a persistent storage location for Local History, particularly across dev-container rebuilds.

## Best solution

Provide a supported Local History storage override suitable for ephemeral remote environments, while retaining the current remote-host default so history continues to travel across clients. The design should account for workspace moves, URI hashing, concurrent windows, and untrusted or shared workspace directories.
