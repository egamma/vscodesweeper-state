# Issue #238052 — Format on save is aborted when interacting with the editor

[https://github.com/microsoft/vscode/issues/238052](https://github.com/microsoft/vscode/issues/238052)

## Summary

Confirmed on main: format-on-save is cancelled when the cursor moves because `formatDocumentWithProvider` uses `EditorStateCancellationTokenSource` with `CodeEditorStateFlag.Position`, which cancels formatting on any cursor position change — even though the user did not edit content.

## Change summary

Format-on-save is aborted (formatting and save are both lost) when the user clicks or moves the cursor in the editor while the formatter is running.

## Best solution

In `FormatOnSaveParticipant.participate()`, pass just the text model (not the editor) to `formatDocumentWithSelectedProvider`, so the formatting path uses `TextModelCancellationTokenSource` (which only cancels on content changes) instead of `EditorStateCancellationTokenSource` with position tracking. Alternatively, remove `CodeEditorStateFlag.Position` from the flags in `formatDocumentWithProvider` when `mode === FormattingMode.Silent`.
