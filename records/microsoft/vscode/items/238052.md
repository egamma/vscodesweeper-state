# Issue #238052 — Format on save is aborted when interacting with the editor

[https://github.com/microsoft/vscode/issues/238052](https://github.com/microsoft/vscode/issues/238052)

## Summary

Keep open: current source still cancels pending format-on-save edits when the caret moves or the editor switches models. The formatter cancellation is confirmed; whether saving also stops depends on how the provider handles cancellation.

## Change summary

Allow pending format-on-save operations to finish when users move the caret or switch editor tabs without changing the document.

## Best solution

Make format-on-save independent of navigation-only editor changes while retaining protection against stale edits and explicit cancellation. Preserve the existing format-before-save ordering rather than saving unformatted content first.
