# Issue #286628 — Gemini handling for image/gif needs improvement

[https://github.com/microsoft/vscode/issues/286628](https://github.com/microsoft/vscode/issues/286628)

## Summary

Still open on main: GIF images are accepted and sent to Gemini models without filtering or conversion, even though Gemini does not support image/gif. The media_type fix (PR #2717) was ported, but the unsupported-format filtering (open PR #2933 in vscode-copilot-chat) has not landed. The issue is team-authored and the work remains.

## Change summary

Gemini models reject image/gif attachments, but VS Code does not filter or convert GIF images before sending them to Gemini.

## Best solution

Implement GIF filtering/conversion for Gemini: either block GIF attachment when a Gemini model is selected, convert GIF to PNG on upload via the image service, and retroactively drop GIF references from conversation history on model switch. The open PR https://github.com/microsoft/vscode-copilot-chat/pull/2933 is a prior attempt at the filtering half; the in-repo work likely touches `extensions/copilot/src/platform/endpoint/node/chatEndpoint.ts` (image limit/filtering path), `extensions/copilot/src/platform/image/` (conversion), and the conversation/attachment layer for retroactive cleanup.
