[https://github.com/microsoft/vscode/issues/313505](https://github.com/microsoft/vscode/issues/313505)

## Summary

A feature request for automatic synthetic data generation from sensitive CSV inputs before Copilot processes them. The capability is specialized enough to likely belong in an extension or external tooling rather than core, but no maintainer has weighed in yet — keeping open for community input.

## Change summary

Add a flag in Copilot that converts CSV inputs into synthetic data with matching headers, types, and distributions to avoid sending sensitive data in prompts.

## Best solution

This is best served by an extension or external preprocessing tool — generating synthetic data with matching distributions is a data-science concern outside core editor/AI scope. A privacy-focused extension could intercept context before it reaches the model. If the team sees broader demand, a generic 'redact before sending' hook in the Copilot context pipeline could be considered.
