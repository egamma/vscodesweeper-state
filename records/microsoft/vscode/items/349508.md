# Issue #349508 — chat.mcp.apps.enabled: false is bypassed in Agent Host sessions

[https://github.com/microsoft/vscode/issues/349508](https://github.com/microsoft/vscode/issues/349508)

## Summary

The setting bypass remains in current main: Agent Host enables MCP Apps unconditionally, and the chat renderer mounts their UI without consulting the setting. Keep this open for an end-to-end correction covering rendering and capability negotiation.

## Change summary

Honor chat.mcp.apps.enabled=false in Agent Host sessions without advertising interactive capabilities that the client will not render.

## Best solution

Make disabled MCP Apps consistently unavailable in chat presentation and MCP initialization, including newly created and resumed Agent Host sessions. Preserve ordinary tool execution and the existing enabled behavior; hiding the form alone does not satisfy the report.
