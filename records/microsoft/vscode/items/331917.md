# Issue #331917 — Title bar background is applied to entire window in experimental Modern UI

[https://github.com/microsoft/vscode/issues/331917](https://github.com/microsoft/vscode/issues/331917)

## Summary

Confirmed intentional but under-considered design tension in Modern UI's floating-panels module: the title bar color is deliberately used as the whole-window backdrop, which clashes badly with the common practice of customizing titleBar.activeBackground/inactiveBackground per window for disambiguation. Worth routing to the modernUI/theming owners for a design call rather than a plain as-designed close.

## Change summary

With Modern UI's floating-panels layout active, a custom titleBar.activeBackground/inactiveBackground color is painted across the entire window backdrop, not just the title bar.

## Best solution

Have the modernUI/theming owners reconsider the floating-panels shell backdrop source — e.g. derive it from a neutral surface/editor-background token instead of the user's titleBar customization, or expose an explicit token for it — so per-window titleBar color-coding keeps working without recoloring the whole shell.

- **Proposed comment:**

  > Thanks for the detailed report and screenshots. I traced this: with Modern UI's floating-panels layout on, the side bar/panel render as cards over a shared backdrop, and that backdrop intentionally uses the title bar's active/inactive background color (src/vs/workbench/browser/media/floatingPanels.css, fed from src/vs/workbench/browser/parts/titlebar/titlebarPart.ts). That's why a custom `titleBar.activeBackground`/`titleBar.inactiveBackground` — commonly used to color-code windows — now tints the whole window instead of just the title bar. Routing this to the Modern UI/theming owners to decide whether the shell backdrop should come from a neutral token instead.

## Evidence

- **CSS var source:** src/vs/workbench/browser/parts/titlebar/titlebarPart.ts:849-857 computes the title bar's active/inactive background color and writes it onto the workbench container as `--modern-ui-shell-background`, so any `titleBar.activeBackground`/`titleBar.inactiveBackground` customization flows directly into the shell backdrop.
