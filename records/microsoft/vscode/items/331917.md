# Issue #331917 — Title bar background is applied to entire window in experimental Modern UI

[https://github.com/microsoft/vscode/issues/331917](https://github.com/microsoft/vscode/issues/331917)

## Summary

This matches the Modern UI design as currently documented — the module's README states the shell gutters intentionally use the active/inactive titleBar background — but the reporter's underlying complaint (that titleBar color customization now bleeds across the whole window instead of just the title bar strip) is a legitimate design concern for a still-experimental feature, so it's worth keeping open for maintainer review rather than closing as as-designed.

## Change summary

With Modern UI enabled, `titleBar.activeBackground`/`inactiveBackground` colorCustomizations now tint the whole window shell/gutters, not just the title bar strip.

## Best solution

Reconsider whether the Modern UI 'shell gutter' background should keep following titleBar.* (as documented in src/vs/workbench/contrib/modernUI/README.md) or fall back to a neutral/surface color instead, so per-window titleBar color customizations used for window disambiguation don't visually take over the whole editor.
