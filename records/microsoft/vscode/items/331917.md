# Issue #331917 — Title bar background is applied to entire window in experimental Modern UI

[https://github.com/microsoft/vscode/issues/331917](https://github.com/microsoft/vscode/issues/331917)

## Summary

Traced this in the Modern UI floating-panels CSS: the shell backdrop showing through the card gutters is intentionally painted with the title bar color, so a customized `titleBar.activeBackground`/`titleBar.inactiveBackground` deliberately tints the whole window in this experimental layout — this is documented, intentional behavior rather than a bug.

## Change summary

With the experimental Modern UI (floating panels) enabled, setting `titleBar.activeBackground`/`inactiveBackground` via `workbench.colorCustomizations` tints far more of the window than just the title bar.

## Best solution

Keep the shipped design as intentional (`src/vs/workbench/browser/media/floatingPanels.css` lines 145-148 explicitly document the title bar color as the shell backdrop), but this is fresh, experimental design feedback worth relaying to the Modern UI owners — they may want a dedicated shell/backdrop color token (`surface.*`-style) instead of reusing `titleBar.*` so per-window color customizations don't recolor the whole shell.
