# Issue #268692 — An OS keyring couldn't be identified

[https://github.com/microsoft/vscode/issues/268692](https://github.com/microsoft/vscode/issues/268692)

## Summary

Keep open as an upstream Chromium/Electron keyring-detection issue. Multiple users confirm the failure, and successful manual backend overrides do not establish that automatic detection has been fixed.

## Change summary

Automatically recognize the available Linux keyring on COSMIC so account sign-in can persist credentials without a manual password-store override.

## Best solution

Correct desktop/backend detection in Chromium and adopt the fix through Electron on VS Code's safeStorage path. Preserve encrypted credential storage and use the documented gnome-libsecret override as an interim workaround, not as evidence of completion.
