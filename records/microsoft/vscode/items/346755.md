# Issue #346755 — Text editor decorations are not rendered at all when fontWeight or fontStyle is set (1.145.2)

[https://github.com/microsoft/vscode/issues/346755](https://github.com/microsoft/vscode/issues/346755)

## Summary

Keep open: the six-variant reproduction is sufficient to retest against current main, but its fresh-profile failure has not been confirmed. An older report identifies a matching font-decoration filtering path, although this report does not establish that its prerequisite is active.

## Change summary

Decorations containing non-empty fontWeight or fontStyle lose all rendering, including their background and other decoration components.

## Best solution

Preserve non-font decoration components when font customization is disabled. Retest the supplied extension with the effective variable-font setting and accessibility mode recorded to determine whether the existing filtering defect explains the fresh-profile result.
