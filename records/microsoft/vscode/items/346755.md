# Issue #346755 — Text editor decorations are not rendered at all when fontWeight or fontStyle is set (1.145.2)

[https://github.com/microsoft/vscode/issues/346755](https://github.com/microsoft/vscode/issues/346755)

## Summary

Keep open: the supplied six-line repro is sufficient to retest, but its temporary-profile failure is not conclusively explained by current main's conditional font-decoration filtering. An older report documents the same disappearance with variable fonts disabled; verify that connection before consolidating.

## Change summary

Decorations containing non-empty fontWeight or fontStyle lose all visual components, including backgrounds, gutter icons and overview ruler marks.

## Best solution

Preserve extension decorations and ordinary bold/italic styling without silently dropping their unrelated visual components. Determine whether this repro exercises the filtering defect tracked at https://github.com/microsoft/vscode/issues/330695 or exposes a separate default-profile regression.
