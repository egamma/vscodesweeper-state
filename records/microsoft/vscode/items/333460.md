The report contains a credible confirmed reproduction: semantic search works when explicitly invoked through `#codebase`, but the enabled Codebase/search tool is absent from model tool snapshots in main Agent sessions and subagents. This is a recent, actionable Copilot core bug and should remain open for agent-host/chat investigation.

## Change summary
