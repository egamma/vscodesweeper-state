# Issue #336472 — Separate agent task completion from long-running background processes

[https://github.com/microsoft/vscode/issues/336472](https://github.com/microsoft/vscode/issues/336472)

## Summary

This asks for the same outcome already deeply diagnosed and tracked in the open, assigned issue https://github.com/microsoft/vscode/issues/336348 (and its sibling https://github.com/microsoft/vscode/issues/336461): separate foreground task completion from a still-running background process/shell, instead of waiting on whole-session idle. Proposing a duplicate close so the fix effort consolidates on the canonical, already-investigated report.

## Change summary

Request that an agent session report task completion independently of a long-running background process it intentionally left running, instead of staying in a 'Thinking/Analyzing' state indefinitely.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/336348, which already traces the root cause (Agent Host waits on the SDK's whole-session `session.idle` instead of the foreground-only `assistant.idle`) in copilotSessionWrapper.ts/copilotAgentSession.ts and lays out a proposed fix and regression checklist; this issue's sub-session ownership idea is one possible implementation detail, not a distinct requirement beyond decoupling foreground completion from background activity.
