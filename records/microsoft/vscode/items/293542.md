# Issue #293542 — package search form keeps resetting query terms

[https://github.com/microsoft/vscode/issues/293542](https://github.com/microsoft/vscode/issues/293542)

## Summary

Valid bug: the Extensions view filter submenu actions (e.g. 'Show Installed Extensions') call `openSearch('@installed ')` which replaces the entire search query, discarding any user-entered terms. The sort submenu correctly preserves the query via `Query.parse`/`Query.toString`. Needs area routing.

## Change summary

Applying a filter from the Extensions view filter menu (e.g. narrowing to installed) discards the user's existing search terms instead of preserving them.

## Best solution

The filter actions in `extensions.contribution.ts` (lines ~1145–1200) should parse the current search value, prepend/append the filter keyword while preserving existing text — matching how the sort actions already work at line 1281. Fix is localized to filter action `run` implementations.
