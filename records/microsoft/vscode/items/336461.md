# Issue #336461 — Agent response remains in Working after the final answer while background tasks run

[https://github.com/microsoft/vscode/issues/336461](https://github.com/microsoft/vscode/issues/336461)

## Summary

The defect remains source-reproducible on current main: Copilot Agent Host completes an active turn only from `session.idle`, which remains deferred while attached background work runs. The team-authored issue should stay open because both linked fix attempts were closed without merging and no later fix is present.

## Change summary

Complete the foreground agent response after its final answer without waiting for attached shells or background agents to finish.

## Best solution

Complete the foreground protocol turn from the guarded root-agent idle signal while retaining `session.idle` as a compatibility fallback, and keep background-task execution and completion reporting independent of the completed response.
