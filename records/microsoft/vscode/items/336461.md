# Issue #336461 — Agent response remains in Working after the final answer while background tasks run

[https://github.com/microsoft/vscode/issues/336461](https://github.com/microsoft/vscode/issues/336461)

## Summary

Team-authored, well-diagnosed bug: current main still gates protocol turn completion on the SDK's terminal `session.idle`, which is deferred until attached background shells/agents drain, so a finished response stays in Working. Two linked PRs (336463, 336467) attempting a fix are both closed without any trace of the proposed `assistant.idle` signal in the codebase, so no fix has landed on main — this stays open.

## Change summary

When background/attached shells or agents outlive a turn, the final agent response stays stuck in a Working/Analyzing state (no Copy or footer) until those background tasks finish, because turn completion waits on session-level idle rather than the foreground agent's own idle signal.

## Best solution

Land a fix in src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts (and copilotSessionWrapper.ts's onIdle wiring) that completes the protocol turn on the SDK's foreground `assistant.idle` when available, keeping `session.idle` as a fallback, while still tracking background task lifetime separately — likely a rework of one of the two closed PRs (336463/336467).
