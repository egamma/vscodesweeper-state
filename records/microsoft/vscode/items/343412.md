[https://github.com/microsoft/vscode/issues/343412](https://github.com/microsoft/vscode/issues/343412)

## Summary

The Agents Window loads SCM services but not the existing Source Control Graph view registration, so the requested integrated history surface remains missing. Keep this as a feature request; no verified canonical or landed implementation was established.

## Change summary

Expose an integrated Git history graph in the Agents Window with commit inspection, diffs, branch navigation, and filtering.
