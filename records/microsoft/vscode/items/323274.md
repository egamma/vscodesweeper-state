# Issue #323274 — Copilot Chat: switching from Agent to Plan mode mid-conversation auto-injects \"Start implementation\" and begins executing

[https://github.com/microsoft/vscode/issues/323274](https://github.com/microsoft/vscode/issues/323274)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/307385 owns the same Plan/Autopilot automatic implementation handoff and the product decision around requiring user confirmation. This report adds a mode-switch retrigger and cross-platform confirmation that should be preserved in the canonical discussion.

## Change summary

Prevent switching from Agent to Plan over an existing conversation from injecting and submitting a synthetic "Start implementation" message.

## Best solution

Resolve the behavior in https://github.com/microsoft/vscode/issues/307385 by deciding whether Plan mode should suspend Autopilot handoffs or require explicit confirmation; the implementation must also ensure rerendering a completed response after a mode change cannot replay the handoff.
