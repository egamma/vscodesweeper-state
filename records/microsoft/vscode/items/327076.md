[https://github.com/microsoft/vscode/issues/327076](https://github.com/microsoft/vscode/issues/327076)

## Summary

A real behavior-setting request that remains unsupported on main. It should stay open through the Backlog Candidates voting period and be routed to untitled-editor owners.

## Change summary

Allow untouched, empty untitled editors associated with file paths to close without a save prompt or creating the file.

## Best solution

Let the community process determine demand; if accepted, add an opt-in untitled-editor setting that keeps associated empty files clean until their contents change, while preserving dirty state for restored backups and non-empty initial content.
