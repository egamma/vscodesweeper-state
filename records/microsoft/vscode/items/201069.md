# Issue #201069 — Cannot test Web Extensions in WSL2 or Dev Containers

[https://github.com/microsoft/vscode/issues/201069](https://github.com/microsoft/vscode/issues/201069)

## Summary

The unsupported remote web-extension development path remains on current main, and this issue is the canonical request referenced by subsequent reports. Keep it open under discussion rather than closing an established, unresolved feature gap.

## Change summary

Allow web extensions located in WSL or Dev Containers to run in an Extension Development Host, or clearly diagnose the unsupported configuration.

## Best solution

Teach the extension-development launch and scanning flow to make a remotely located development extension available to the local web-worker extension host. Until that is supported, detect this configuration and show a clear error with the local-source or test-web workaround.
