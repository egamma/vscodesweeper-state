## Summary

Keep open for human security review: the security label explicitly bars a cleanup close. Existing approval controls do not establish that the requested session-wide trust degradation is implemented, and the related closed planning item is not proof of completion.

## Change summary

Restrict automatic tool approvals as a chat session encounters internet content or suspected prompt injection, with different trust requirements for different commands.

## Best solution

Have the chat security owners reconcile this proposal with current approval enforcement and the closed implementation item, then define the remaining session-trust behavior. The intended outcome is risk-sensitive approval restrictions that follow the session's exposure, rather than only static tool permissions or individual URL confirmations.
