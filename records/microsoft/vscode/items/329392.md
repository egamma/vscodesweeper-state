# Issue #329392 — Slow sash resizing with chat sessions

[https://github.com/microsoft/vscode/issues/329392](https://github.com/microsoft/vscode/issues/329392)

## Summary

Team-authored performance bug reported today with a concrete stack trace, and a maintainer is already actively investigating — this is squarely in the hard keep-open lane for team-authored issues, and there's no fix commit yet to justify any close.

## Change summary

Resizing the sash next to the chat sessions control causes synchronous layout thrashing (forced reflow) and feels slow.

## Best solution

Fix belongs in ChatViewPane.layoutSessionsControl (src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatViewPane.ts): the style writes on sessionsControlContainer are immediately followed by offsetWidth/offsetHeight reads on sessionsContainer (lines ~1663-1679), forcing synchronous style recalculation on every sash pointermove. Batching writes/reads (e.g. caching dimensions or deferring the read to a rAF) would remove the thrash; justschen is already investigating per the comment thread.
