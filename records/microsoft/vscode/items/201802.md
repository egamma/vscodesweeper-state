# Issue #201802 — Ruler labels

[https://github.com/microsoft/vscode/issues/201802](https://github.com/microsoft/vscode/issues/201802)

## Summary

Keep open: current rulers support columns and colors, but neither descriptive labels nor displayed column numbers. The request remains distinct from the related issues and is already appropriately routed to editor-core.

## Change summary

Allow editor rulers to display descriptive names or column numbers so users can distinguish multiple line-length conventions.

## Best solution

An editor-core design decision on optional ruler annotations that identify each limit without obscuring text or cluttering the editor. Existing numeric and colored ruler configurations should retain their current behavior.
