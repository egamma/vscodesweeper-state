# Issue #296426 — Rendering for extension info is broken when clicking show suggestion nudge (with many suggestions)

[https://github.com/microsoft/vscode/issues/296426](https://github.com/microsoft/vscode/issues/296426)

## Summary

The defect remains source-reproducible on current main: Show Recommendations opens every suggested extension individually, and the modal-editor experiment turns those concurrent opens into stacked overlays. The issue should remain open for a bounded extension-recommendations fix.

## Change summary

Showing a notification containing several extension recommendations opens multiple overlapping extension-detail overlays and leaves the workbench visually corrupted until each is closed.

## Best solution

Show the recommendations as one Extensions view search result without opening a modal detail editor for every recommendation; preserve single-extension and installation behavior outside this action.
