# Issue #166161 — Issue with "reopen editor with" -> Jupyter notebook

[https://github.com/microsoft/vscode/issues/166161](https://github.com/microsoft/vscode/issues/166161)

## Summary

Team-authored bug that remains unfixed on main. The discussed solution (adding an untitled fallback to notebook service) was never implemented. Keeping open per team-author policy and because the defect persists.

## Change summary

When using 'Reopen Editor With' -> Jupyter Notebook on an untitled file, debugging (Run By Line) opens a plain text editor instead of staying in the notebook cell, because the cell URI lacks the notebook-type query string.

## Best solution

Implement the untitled fallback discussed in comment 11: when the notebook service encounters a cell URI from an unknown provider on an untitled resource, it should look up the currently open editor to determine the notebook type. The fix likely lives in `src/vs/workbench/contrib/notebook/browser/services/notebookServiceImpl.ts` around the `getContributedNotebookTypes` / editor resolution logic.
