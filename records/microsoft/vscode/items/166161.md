# Issue #166161 — Issue with "reopen editor with" -> Jupyter notebook

[https://github.com/microsoft/vscode/issues/166161](https://github.com/microsoft/vscode/issues/166161)

## Summary

The extensionless untitled-cell resolution gap remains in current source: notebook registrations require a matching filename pattern, so generic debugger navigation falls back to a text editor. Keep this accepted notebook bug open; the maintainer discussion already establishes the intended fallback behavior.

## Change summary

Navigating to a paused cell in an untitled text document reopened as a Jupyter notebook opens a plain text editor instead of revealing the notebook cell.

## Best solution

Resolve an extensionless untitled cell URI through its existing notebook and provider, preserving the original resource and revealing the requested cell. Keep this in the core notebook editor-resolution path rather than requiring debugger-specific notebook knowledge or saving before debugging.
