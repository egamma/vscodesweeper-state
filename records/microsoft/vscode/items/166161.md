# Issue #166161 — Issue with "reopen editor with" -> Jupyter notebook

[https://github.com/microsoft/vscode/issues/166161](https://github.com/microsoft/vscode/issues/166161)

## Summary

Still open — the discussed untitled notebook fallback for cell URI resolution was never implemented; no commit references this issue and the code path still lacks the proposed fix.

## Change summary

When using 'Reopen Editor With' to open an untitled file as a Jupyter notebook, debugging (Run By Line) opens a plain text editor instead of pausing in the notebook cell because the cell URI lacks notebook-type info.

## Best solution

Implement the untitled fallback in the notebook editor input factory (notebookServiceImpl.ts) so that when a vscode-notebook-cell URI is resolved and the notebook type cannot be determined from the URI alone, the service checks open editors to find the already-open notebook and reuses it.
