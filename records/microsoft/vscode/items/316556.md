# Issue #316556 — shellIntegration.executeCommand() read() stream never ends for multi-line commands on Linux/bash

[https://github.com/microsoft/vscode/issues/316556](https://github.com/microsoft/vscode/issues/316556)

## Summary

Verified duplicate of #250764 — both report that multi-line commands on Linux/bash lose the `]633;D` completion marker, breaking both `read()` stream completion and `onDidEndTerminalShellExecution`. The reporter confirmed this in comment 4, and no fix has landed on main.

## Change summary

The `AsyncIterable<string>` returned by `TerminalShellExecution.read()` never completes for multi-line commands on Linux/bash because the `]633;D` shell integration marker is lost after multi-line input sequences.
