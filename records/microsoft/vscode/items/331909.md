# Issue #331909 — Integrated Browser intermittently drops initial localhost navigation in Remote Tunnel after idle

[https://github.com/microsoft/vscode/issues/331909](https://github.com/microsoft/vscode/issues/331909)

## Summary

Keep open while the linked fix proposal is reviewed and validated against the idle Remote Tunnel scenario. Current source still has the reported readiness limitations; although the surrounding navigation code has changed, the supplied steps suffice to retest the intermittent failure.

## Change summary

Initial Integrated Browser navigation to remote localhost can fail after Remote Tunnel idles and never recover without another navigation.

## Best solution

Review https://github.com/microsoft/vscode/pull/331912 and validate that the first unchanged URL reaches the remote server after at least 60 seconds idle, without manual retries or duplicate requests. Preserve bounded, visible failure handling when the connection cannot recover.
