## Summary

The readMore icon in the suggest widget uses position:absolute without vertical centering — the CSS on current main still has no top/transform to center it within the row, so the issue persists.

## Change summary

The 'Read More' chevron icon in the autocomplete suggestion list is not vertically centered within the row.
