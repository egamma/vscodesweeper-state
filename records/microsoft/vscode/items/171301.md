# Issue #171301 — the length of Command center should as same as command palette

[https://github.com/microsoft/vscode/issues/171301](https://github.com/microsoft/vscode/issues/171301)

## Summary

The requested sizing remains absent on main, and this accepted Backlog request has 22 community upvotes. Keep it open for a responsive-width design decision alongside the competing need to preserve title-bar menu space.

## Change summary

Make the Command Center as wide as the 600px Command Palette where available.

## Best solution

Define responsive Command Center sizing that reaches the Command Palette's width on roomy windows while shrinking before title-bar menus collapse, coordinating with https://github.com/microsoft/vscode/issues/236302.
