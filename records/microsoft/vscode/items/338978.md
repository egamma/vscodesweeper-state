# Issue #338978 — Agents: support additional skill folders

[https://github.com/microsoft/vscode/issues/338978](https://github.com/microsoft/vscode/issues/338978)

## Summary

VS Code intentionally does not let Agent Host/Copilot CLI inherit `chat.agentSkillsLocations` automatically — that's a documented, shipped design decision with an explicit migration path instead, not a gap.

## Change summary

Make the Agents app (Agent Host) automatically read additional skill folders from `chat.agentSkillsLocations`, the same setting VS Code's local chat harness uses.

## Best solution

Keep the current design: configured `chat.agentSkillsLocations` folders are surfaced for explicit migration in the AI Customization editor (Migrations tab) rather than silently inherited, consistent with harness-owned discovery.

- **Proposed comment:**

  > Thanks for the report. This is actually intentional: Agent Host harnesses (including the Agents app / Copilot CLI) own their own customization discovery and deliberately don't inherit VS Code-specific settings like `chat.agentSkillsLocations` automatically — see the setting's own description and the established direction tracked in https://github.com/microsoft/vscode/issues/332083. Instead, configured skill folders are surfaced for explicit migration in the AI Customization editor's Migrations tab, so you can move them into a supported Copilot CLI skill location. I'll close this as working as designed, but please follow #332083 for the broader migration/registration work.
