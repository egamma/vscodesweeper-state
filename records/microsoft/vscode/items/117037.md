# Issue #117037 — Files open in wrong window

[https://github.com/microsoft/vscode/issues/117037](https://github.com/microsoft/vscode/issues/117037)

## Summary

Linux-specific window focus tracking bug that has persisted across multiple reporters and versions. The most recent commenter (July 2026) traced one instance to an extension-created editor group stealing files, but the original 2021 reports predate that scenario — the underlying `lastFocusTime`-based window selection may still be unreliable on Linux/Wayland. No fix commit references this issue.

## Change summary

Using File > Open or Ctrl+O from one VS Code window causes the file to open in a different (often maximized) window on Linux.

## Best solution

Investigate the `getLastFocused` window selection logic in `src/vs/platform/windows/electron-main/windows.ts` on Linux/Wayland — the `lastFocusTime` tracking may be unreliable when Chromium's focus events don't fire correctly. The latest commenter's finding about editor groups stealing files (comment 17) may be a separate issue worth splitting out, since it involves extension behavior rather than cross-window focus.
