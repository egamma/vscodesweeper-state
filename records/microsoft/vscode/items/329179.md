# Issue #329179 — Copilot Chat can act on truncated tool-result previews instead of the full payload

[https://github.com/microsoft/vscode/issues/329179](https://github.com/microsoft/vscode/issues/329179)

## Summary

Keep open: current source distinguishes truncated previews from full tool payloads, but does not establish that the assistant retrieves omitted content before making conclusions. Current main includes disk-backed result handling; the reported MCP flow and payload sizes suffice to retest whether this addresses the observed failure.

## Change summary

Prevent Copilot Chat from treating a truncated large tool-result preview as the complete payload when summarizing or acting on it.

## Best solution

Establish which model-facing result path the project-cache MCP response takes, then ensure omitted content is retrieved before completeness-dependent assertions, or that the assistant explicitly limits its conclusions to the available excerpt. Preserve bounded context usage rather than indiscriminately inserting every large payload into the prompt.
