# Issue #340454 — Watermark keeps `Open Chat` after chat is disabled

[https://github.com/microsoft/vscode/issues/340454](https://github.com/microsoft/vscode/issues/340454)

## Summary

Thanks for the detailed report. The code on main confirms it: the watermark never re-evaluates its entries when context keys change, and a stale cachedWhen value short-circuits the live check. Keep open as a confirmed, bounded papercut.

## Change summary

The empty-editor watermark keeps showing 'Open Chat' after chat.disableAIFeatures is enabled.

## Best solution

Re-render the watermark when a context key used by its entries changes, and update cachedWhen from the live evaluation at that point instead of only at shutdown. Prefer the live value over the cache once context keys have settled.
