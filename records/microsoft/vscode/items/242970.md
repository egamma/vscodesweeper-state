# Issue #242970 — Regression: GDK_SCALE and GDK_DPI_SCALE environment variables are ignored

## Summary

Keep open as an apparent Electron/Chromium Linux scaling regression. Independent confirmations and matching Chrome behavior support runtime ownership, but neither a concrete fix nor an older canonical covering this exact symptom was established.

## Change summary

Linux UI scaling changed in VS Code 1.98 when GDK_SCALE=2 and GDK_DPI_SCALE=0.5 are set, producing an oversized interface.

## Best solution

Track any upstream resolution here until its adoption in VS Code is verified; explicit device-scale overrides remain workarounds, not proof of resolution.
