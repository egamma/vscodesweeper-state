# Issue #341550 — Custom agent does not have access to the tools configured in YAML frontmatter when executed as subagent

[https://github.com/microsoft/vscode/issues/341550](https://github.com/microsoft/vscode/issues/341550)

## Summary

Keep open as a Copilot custom-agent tool-availability bug. The reporter narrowed the failure to search/web groups, and an independent commenter confirms it in 1.143.1 specifically with the Copilot harness while the local harness works; no verified fix or eligible duplicate was established.

## Change summary

Custom agents invoked as subagents lose access to search and web tools selected in their YAML frontmatter.

## Best solution

Make the Copilot harness honor configured search/web tool references when invoking custom subagents, within the session's existing tool restrictions. Diagnose the frontmatter-to-runtime tool resolution boundary using the working local harness as a comparison.
