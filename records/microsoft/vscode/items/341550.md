# Issue #341550 — Custom agent does not have access to the tools configured in YAML frontmatter when executed as subagent

[https://github.com/microsoft/vscode/issues/341550](https://github.com/microsoft/vscode/issues/341550)

## Summary

Keep open: the report provides sufficient steps to retest specialist subagents losing configured search and web capabilities, and the reporter confirms persistence in 1.142.0. Current main has separate local and SDK-backed tool-provisioning paths; inspection does not establish that either fixes this reported outcome.

## Change summary

Custom agents invoked as subagents fail to use search and web tools enabled in their YAML frontmatter.

## Best solution

Make configured search and web capabilities usable by the named specialist when delegated to, subject to existing tool restrictions. First reproduce with captured tool definitions to identify whether the failure is frontmatter translation, runtime provisioning, or misleading model guidance.
