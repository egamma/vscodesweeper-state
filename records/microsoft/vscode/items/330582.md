# Issue #330582 — Subagent spawn in ACP/agent-host mode silently falls back to default model (claude-sonnet-5) when session uses BYOK, charging Copilot AI credits instead of BYOK provider

[https://github.com/microsoft/vscode/issues/330582](https://github.com/microsoft/vscode/issues/330582)

## Summary

Real and well-diagnosed report, but the actual defect lives in the `@github/copilot-sdk` runtime that the Copilot CLI harness embeds — VS Code only wires BYOK providers into the initial session config once at launch; subagent-process model selection happens entirely inside that external SDK, which this repo doesn't own.

## Change summary

In agent-host/ACP mode with a BYOK model selected, subagent spawns (general-purpose/explore/research) silently fall back to Copilot's default `claude-sonnet-5` instead of inheriting the parent session's BYOK model, quietly billing Copilot credits.

## Best solution

The fix needs to happen in the Copilot CLI runtime (`@github/copilot-sdk`, currently pinned at 1.0.10-preview.0 in package.json) so that spawned subagent processes inherit the parent session's `providers`/`models` config the same way the main session does; vscode's role here is at most surfacing a warning or filing this against the SDK team, not patching agentHost code.
