# Issue #170607 — set decoration's opacity is not working

[https://github.com/microsoft/vscode/issues/170607](https://github.com/microsoft/vscode/issues/170607)

## Summary

The defect remains source-reproducible on current main: unused-code styling has greater CSS specificity than an extension decoration's explicit opacity, so the extension cannot restore full opacity.

## Change summary

An editor decoration configured with opacity 1 remains faded when it overlaps code marked unnecessary or unused.

## Best solution

Honor an explicit editor-decoration opacity when it overlaps unnecessary-code styling, while preserving the theme's normal fading for unused code that has no explicit opacity override.
