## Evidence

- **Activation trigger:** extensions/typescript-language-features/package.json includes onLanguage:jsonc among its activation events. In extensions/typescript-language-features/src/extension.ts, activate calls suggestNativePreview without checking whether a JavaScript or TypeScript editor is active.
- **Current source defect:** extensions/typescript-language-features/src/ui/suggestNativePreview.ts checks dismissal state, window activity, installation/configuration, plugins, and experiment eligibility before showing the notification, but never checks the active document language or window kind. Thus an eligible fresh profile can receive the suggestion after opening hook JSONC without any JavaScript or TypeScript file.
