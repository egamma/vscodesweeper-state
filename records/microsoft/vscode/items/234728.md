# Issue #234728 — [Bug] `"editor.glyphMargin": false` not working for diff editors

[https://github.com/microsoft/vscode/issues/234728](https://github.com/microsoft/vscode/issues/234728)

## Summary

The original pane still overrides editor.glyphMargin=false when displaying a side-by-side diff. Keep this correctly routed bug open; the shared editor source confirms a bounded configuration defect.

## Change summary

Honor editor.glyphMargin=false in the original pane of side-by-side diff editors.

## Best solution

Both visible diff panes should honor the configured glyph-margin visibility at creation and after option updates, while preserving the hidden original pane's existing inline-mode behavior.
