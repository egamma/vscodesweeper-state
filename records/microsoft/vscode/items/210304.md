# Issue #210304 — Add a preRestartCommand / command equivalents of debug lifecycle hooks

[https://github.com/microsoft/vscode/issues/210304](https://github.com/microsoft/vscode/issues/210304)

## Summary

Team-authored feature request for command-based (not task-based) debug lifecycle hooks, specifically preRestartCommand. The existing preRestartTask/postRestartTask only support tasks, not extension commands with arguments — the requested capability is not yet implemented. Keeping open per team-author rule.

## Change summary

Add command-based equivalents (e.g. preRestartCommand) to the debug lifecycle hooks, allowing extensions to run commands with arguments (including the debug session) on restart.

## Best solution

Add a `preRestartCommand` (and potentially other lifecycle-command hooks) to the debug launch configuration schema in `src/vs/workbench/contrib/debug/common/debug.ts` and wire them up in `src/vs/workbench/contrib/debug/browser/debugService.ts` alongside the existing task-based hooks. This would let extensions like Vitest and Playwright properly handle restart during test-run debug sessions without needing a separate correlation mechanism between debug sessions and test runs.
