# Issue #101135 — Support FilesDirectories for file systems

[https://github.com/microsoft/vscode/issues/101135](https://github.com/microsoft/vscode/issues/101135)

## Summary

A real extension API and Explorer capability gap remains on current main. The request earned 25 upvotes and was explicitly promoted to the Backlog, so it should remain open.

## Change summary

Allow a filesystem resource to expose both readable file content and directory children, with suitable Explorer and breadcrumb interactions.

## Best solution

Define supported semantics for combined `FileType.File | FileType.Directory`, then preserve both identities through the file service and Explorer model so the resource can expand and open. Existing `readFile` and `readDirectory` methods could serve the same URI without adding a specialized read method.
