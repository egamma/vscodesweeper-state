## Summary

The reported interaction is fixed on current main: indentation-changing keystrokes now apply pair autoclosing in the same operation. Commit 8ca1b8c195bcef349aa0ab8ca6fb440cd82933ff introduced the relevant behavior, so this can be closed as completed.

## Change summary
