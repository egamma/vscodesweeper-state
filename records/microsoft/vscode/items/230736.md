## Summary

Valid feature request for notebook API to insert markup cells in edit mode (enabling ghost cell UX). A maintainer (rebornix) acknowledged the request and proposed approaches but no implementation has landed on main.

## Change summary

Allow notebook extensions to insert markup cells in edit mode and/or support decorations for markup cells in preview mode, enabling a ghost cell UX.

## Best solution

Extend the `notebook.cell.insertMarkdownCellBelow` command (or the notebook API) to accept an argument for initial edit mode, and adjust markup cell rendering to honor it — as rebornix suggested.
