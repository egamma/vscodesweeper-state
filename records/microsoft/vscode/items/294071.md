# Issue #294071 — Support HEIF screenshots on Mac

[https://github.com/microsoft/vscode/issues/294071](https://github.com/microsoft/vscode/issues/294071)

## Summary

HEIF remains unsupported on current main, and a maintainer has confirmed that model support is upstream while explicitly leaving client-side conversion open for investigation. This should remain open under the existing upstream and chat-vision classifications.

## Change summary

Allow HEIF screenshots to be attached to Copilot Chat, converting them to PNG or JPEG when models cannot consume HEIF directly.

## Best solution

Provide a reliable HEIF-to-supported-format conversion in the chat attachment pipeline if it can be done without an unsuitable size or performance cost; otherwise track the upstream image-decoding or model-format capability needed to support it.
