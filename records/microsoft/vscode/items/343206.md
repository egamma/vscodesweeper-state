# Issue #343206 — Bad display of AI category bar

[https://github.com/microsoft/vscode/issues/343206](https://github.com/microsoft/vscode/issues/343206)

## Summary

The screenshot shows the model-provider tabs overflowing the picker, and current source still permits this when many providers are configured. Keep this open: shrinking the selected label cannot accommodate an arbitrarily long row of fixed-width provider buttons.

## Change summary

Keep the model picker's provider category bar contained and usable when many model providers are available.

## Best solution

Provide overflow handling for the model-provider tab strip while keeping every provider reachable and the trailing actions unobstructed. Preserve the current compact presentation when the tabs fit.
