# Issue #343206 — Bad display of AI category bar

[https://github.com/microsoft/vscode/issues/343206](https://github.com/microsoft/vscode/issues/343206)

## Summary

The screenshot shows the model picker's provider bar overflowing its popup. Current source still permits this with many configured providers: the popup has a fixed width, but provider buttons have non-shrinking minimum widths and no overflow handling.

## Change summary

Keep the model picker's provider tabs and trailing actions contained and accessible when many providers are configured.

## Best solution

Make the model picker accommodate provider counts that exceed its available header width without painting controls outside the popup or making providers unreachable. Preserve model selection, search, keyboard navigation, and the normal small-provider layout.
