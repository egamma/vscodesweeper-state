# Issue #341708 — Linux/KDE: changing Plasma colors crashes VS Code with SIGSEGV; preloading both GTK integration modules avoids it

[https://github.com/microsoft/vscode/issues/341708](https://github.com/microsoft/vscode/issues/341708)

## Summary

Thanks for the detailed report. The crash looks like a GTK module-lifetime problem in Electron/Chromium that surfaces when KDE Plasma's colorreload and window-decorations GTK modules unload. It was only seen on KDE Plasma 5.27 with X11. I could not verify it from source, so it stays open as an upstream issue.

## Change summary

VS Code's main process segfaults when the KDE Plasma color scheme changes, because of the colorreload and window-decorations GTK modules.

## Best solution

Track this as an upstream Electron/Chromium GTK module-lifetime issue and link it to the Chromium report. Confirm whether the Electron version bundled with VS Code has the same cause, then pick up the fixed Electron release or evaluate a mitigation.
