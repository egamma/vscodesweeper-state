# Issue #310166 — Agents app support for remote SSH-like development environments

[https://github.com/microsoft/vscode/issues/310166](https://github.com/microsoft/vscode/issues/310166)

## Summary

Remote SSH support is substantially present on current main, but the open draft PR https://github.com/microsoft/vscode/pull/327797 explicitly contributes additional Windows-remote support to this issue. The issue should remain open while that human-owned implementation is reviewed and its remaining cross-platform scope is assessed.

## Change summary

Support Agents Window sessions across SSH-like remote environments, including remote filesystems, terminals, processes, and consistent local/remote workflows.

## Best solution
