# Issue #310166 — Agents app support for remote SSH-like development environments

[https://github.com/microsoft/vscode/issues/310166](https://github.com/microsoft/vscode/issues/310166)

## Summary

The Agents window already has remote SSH support on main — including SSH connections (`RemoteAgentHostEntryType.SSH`), WSL, tunnels, remote file system and terminal integration, workspace pickers with a 'Remote' group, and managed auto-reconnect. The capability is marked experimental but actively ships. Proposing close as the central ask is covered.

## Change summary

Support for running agent sessions in the Agents window when connected to remote SSH-like development environments.

## Best solution

The requested capability already exists on current main: the Agents window supports remote agent hosts via SSH (`IRemoteAgentHostSSHConnection`), WSL, and dev tunnels, with remote file system, terminal, and workspace integration. Users can enable it via the `remoteAgentHosts.enabled` setting. No additional core change is needed — ongoing refinement of the experimental remote agent host surface will continue to improve the experience.
