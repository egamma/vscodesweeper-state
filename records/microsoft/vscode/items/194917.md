# Issue #194917 — compare with saved not working

[https://github.com/microsoft/vscode/issues/194917](https://github.com/microsoft/vscode/issues/194917)

## Summary

Still reproduces on main — the Compare with Saved command uses a text content provider that doesn't support notebooks or custom editors. An open PR (#282368) proposes the fix using a file system provider approach suggested by maintainers.

## Change summary

The 'Compare with Saved' command fails for notebooks and custom editors because it relies on TextFileContentProvider, which only supports text models.

## Best solution

Land or iterate on https://github.com/microsoft/vscode/pull/282368, which replaces TextFileContentProvider with a file system provider (following the LocalHistoryFileSystemProvider pattern) so the diff editor delegates to editor-specific diff implementations for notebooks and custom editors.
