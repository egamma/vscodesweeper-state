# Issue #325510 — Attach debugger from integrated browser's toolbar

[https://github.com/microsoft/vscode/issues/325510](https://github.com/microsoft/vscode/issues/325510)

## Summary

Valid feature request — the integrated browser has CDP plumbing and a toolbar system, but no toolbar action to attach VS Code's JavaScript debugger to the browser's page. The infrastructure exists to support this; the gap is a user-facing action wiring them together.

## Change summary

Add an 'Attach Debugger' action to the integrated browser's toolbar that attaches VS Code's JS debugger to the browser view without requiring a manual launch.json configuration.

## Best solution

Add a new action in the `BrowserActionGroup.Tools` group on `MenuId.BrowserActionsToolbar` (in `src/vs/workbench/contrib/browserView/electron-browser/features/`) that starts a debug session of type `editor-browser` with `request: attach` targeting the current browser view. The CDP connection infrastructure already exists in `BrowserViewDebugger`; the action needs to bridge it to `IDebugService.startDebugging()`.
