# Issue #345065 — Dictation reports “Could not download” after successful local model installation on Apple Silicon

[https://github.com/microsoft/vscode/issues/345065](https://github.com/microsoft/vscode/issues/345065)

## Summary

Keep open: the reporter recovered after updating, but another participant still reports failure on 1.145.3. Current source confirms that runtime provisioning errors can incorrectly produce model-download guidance even after successful model installation.

## Change summary

Locally installed dictation models can remain unusable while the notification hides the underlying runtime or initialization failure.

## Best solution

Report the actual preparation failure without assuming the model download failed or recommending an ineffective model reinstall. Preserve cached-model reuse and investigate any remaining native initialization failure separately using the exposed diagnostics.
