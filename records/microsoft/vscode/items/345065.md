# Issue #345065 — Dictation reports “Could not download” after successful local model installation on Apple Silicon

[https://github.com/microsoft/vscode/issues/345065](https://github.com/microsoft/vscode/issues/345065)

## Summary

Keep open: the Windows follow-up confirms that successful model import can still lead to misleading model-download guidance, and current source preserves that error conflation. The Apple Silicon installation checks distinguish the original case from the Windows runtime-download failure; its underlying initialization failure remains undiagnosed.

## Change summary

Use an imported dictation model when its dependencies are available, and accurately identify runtime provisioning, model download, or initialization failures otherwise.

## Best solution

Make local dictation preparation errors identify the failing component and offer recovery appropriate to that component. Retest the supplied Apple Silicon steps and capture the underlying initialization error before treating the Windows runtime workaround as a solution for both platforms.
