# Issue #345065 — Dictation reports “Could not download” after successful local model installation on Apple Silicon

[https://github.com/microsoft/vscode/issues/345065](https://github.com/microsoft/vscode/issues/345065)

## Summary

Keep open: the reporter recovered after updating, but later Windows and macOS reports remain unresolved, and current source still misreports runtime network failures as model-download failures. The misleading diagnostic is source-confirmed; the original Apple Silicon initialization failure is not independently diagnosed.

## Change summary

After successful local model installation, dictation can incorrectly report a model-download failure and recommend reinstalling the model instead of exposing the actual preparation error.

## Best solution

Make dictation preparation failures accurately identify the failing component and preserve the underlying diagnostic, without suggesting that importing a model repairs a missing runtime. Treat the reporter's recovery as individual confirmation, not proof that all reported failures are fixed.
