[https://github.com/microsoft/vscode/issues/345065](https://github.com/microsoft/vscode/issues/345065)

## Summary

Keep open: the discussion confirms misleading model-download errors after successful local installation, and current source still conflates runtime, catalog, and model failures. The Windows runtime workaround does not establish the cause of the Apple Silicon failure.

## Change summary

Make locally installed dictation models usable, or report the actual runtime or model initialization failure instead of misleading download guidance.
