# Issue #283164 — Copilot Chat Only Fetches the First #fetch URL in Prompts

[https://github.com/microsoft/vscode/issues/283164](https://github.com/microsoft/vscode/issues/283164)

## Summary

Keep open for the maintainer-supported retrieval reliability improvement. Current code supports multiple URLs, but that does not guarantee that the model requests every supplied resource; the discussion identifies a product-contract gap rather than a confirmed first-URL-only implementation defect.

## Change summary

Reliably include every explicitly requested external resource in Copilot Chat context rather than leaving some URLs unfetched.

## Best solution

Provide a reliable way to supply multiple external resources while preserving model-driven fetching for autonomous tasks. Settle whether that guarantee belongs to explicit URL attachments or changes to the existing tool-reference experience, following the maintainer's distinction between those contracts.
