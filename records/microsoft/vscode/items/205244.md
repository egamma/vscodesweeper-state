# Issue #205244 — Cannot view changes from timeline before file renamed

[https://github.com/microsoft/vscode/issues/205244](https://github.com/microsoft/vscode/issues/205244)

## Summary

Keep open: current source follows renames when listing Git history but still opens historical comparisons using the current filename. The verified related reports are newer than this issue, so they cannot replace it under the re-review duplicate rule.

## Change summary

Git Timeline comparisons should open the correct historical file contents before and across committed renames.

## Best solution

Make Git Timeline comparisons respect the file's path at each compared revision, retaining existing working-tree and index behavior. Keep this older report as the tracking issue for the matching symptoms in the newer reports.
