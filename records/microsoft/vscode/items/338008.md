# Issue #338008 — Workbench.colorCustomizations setting not working

[https://github.com/microsoft/vscode/issues/338008](https://github.com/microsoft/vscode/issues/338008)

## Summary

This was a regression in the Modern UI Connected tabs rendering that suppressed `tab.activeBorder`/`tab.activeBorderTop` (and related) color customizations; it was fixed and merged on 2026-10-02 in PR #338796, confirmed by current-main tests that explicitly assert these colors render correctly again.

## Change summary

After updating to 1.139, `workbench.colorCustomizations` for tab border colors (e.g. `tab.activeBorder`, `tab.activeBorderTop`) stopped being applied to the active editor tab.

## Best solution

Keep the shipped fix from PR https://github.com/microsoft/vscode/pull/338796 (merge commit a60fe63050fc3817468ce34821ba9b4a87cc3910), which restores active top/bottom, hover, selected, modified, and unfocused tab border customizations for Connected/Modern UI tabs; ask the reporter to confirm on a build containing this change (milestone 1.141.0).
