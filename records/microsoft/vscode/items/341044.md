# Issue #341044 — Settings editor shows inherited values in the Agents window but the default in the editor window

[https://github.com/microsoft/vscode/issues/341044](https://github.com/microsoft/vscode/issues/341044)

## Summary

Thanks for the report. The inconsistency is visible in source: the Agents window deliberately shows the inherited value, while the editor window's Workspace tab shows the schema default. Which behavior should win is a product decision, so this stays open.

## Change summary

Settings editor shows the inherited value for non-overridden settings in the Agents window scope, but the schema default in the editor window's Workspace scope.

## Best solution

Pick one display rule for non-overridden settings and apply it in both windows in settingsTreeModels.ts. Mirroring the Agents-window inherited display in the Workspace tab is the likely direction, but a maintainer should confirm.
