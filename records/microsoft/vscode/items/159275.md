# Issue #159275 — Sticky keys and context menu keybinding (Shift F10)

[https://github.com/microsoft/vscode/issues/159275](https://github.com/microsoft/vscode/issues/159275)

## Summary

Nearly four-year-old report with no reproduction confirmation and multiple Electron upgrades since filing; the behavior likely depends on how Chromium/Electron propagates Windows Sticky Keys modifier state to DOM keyboard events. Needs a retest on a current build before further triage.

## Change summary

When Windows Sticky Keys is active, pressing Shift then F10 sequentially does not open the context menu in VS Code, although it works when the keys are held simultaneously.

## Best solution

Ask the reporter to retest on the latest VS Code. If still reproducible, this is likely an upstream Chromium/Electron issue with how the Sticky Keys modifier state is propagated to KeyboardEvent.shiftKey — VS Code reads `e.shiftKey` directly from the DOM event (src/vs/base/browser/keyboardEvent.ts:149) and has no custom Sticky Keys handling. If confirmed upstream, file against Electron/Chromium and classify as `upstream`.
