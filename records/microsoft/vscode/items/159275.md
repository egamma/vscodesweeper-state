# Issue #159275 — Sticky keys and context menu keybinding (Shift F10)

[https://github.com/microsoft/vscode/issues/159275](https://github.com/microsoft/vscode/issues/159275)

## Summary

The reporter reconfirmed the bug on VS Code 1.127.0, and current main still requires Shift to be reported on the F10 keyup event before list and tree context menus open. This remains a valid Windows accessibility bug rather than a stale or duplicate report.

## Change summary

With Windows Sticky Keys enabled, pressing and releasing Shift followed by F10 does not open the focused list or tree item's context menu.

## Best solution

Make list and tree context-menu keyboard activation honor the Windows Sticky Keys sequence while preserving ordinary Shift+F10, the Context Menu key, VoiceOver activation, and native context-menu deduplication.
