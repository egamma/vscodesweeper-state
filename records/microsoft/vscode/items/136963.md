# Issue #136963 — [bug] Virtual Keyboard covers cursor and code on iOS/iPad if below keyboard waterline 

[https://github.com/microsoft/vscode/issues/136963](https://github.com/microsoft/vscode/issues/136963)

## Summary

Keep open: a maintainer confirmed that opening the iPad keyboard still hides the cursor until typing begins, and the inspected layout path does not explicitly reveal it. No verified fixing commit or canonical owning this specific remaining behavior was found.

## Change summary

Opening the iOS/iPadOS software keyboard after tapping near the bottom of a text editor hides the cursor and surrounding code.

## Best solution

Keep the focused editing position visible when the software keyboard reduces the usable viewport, without requiring an edit. Confirm current Safari event ordering and establish regression coverage while preserving ordinary resize and scroll behavior.
