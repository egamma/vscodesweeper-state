# Issue #215608 — "A setting has changed that requires a restart to take effect." needs more info

[https://github.com/microsoft/vscode/issues/215608](https://github.com/microsoft/vscode/issues/215608)

## Summary

Keep open: the restart dialog still omits the setting that triggered it, and the discussion establishes demand for that diagnostic information. The WSL workaround addresses one reported trigger, not the missing explanation in the core dialog.

## Change summary

Identify the setting responsible for a restart or reload prompt so users can diagnose repeated prompts.

## Best solution

Make SettingsChangeRelauncher explain which setting changes require restarting or reloading, while preserving its existing trigger rules. Decide whether identifying an initiating extension is also part of the supported diagnostic contract.
