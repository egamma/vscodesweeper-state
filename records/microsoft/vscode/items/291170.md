# Issue #291170 — Testing: Subagent thinking part includes repeated text

[https://github.com/microsoft/vscode/issues/291170](https://github.com/microsoft/vscode/issues/291170)

## Summary

The repeated text remains source-reproducible on current main: a single-line subagent prompt is used as both the collapsible title and its expanded markdown content. This team-authored, accepted bug should remain open for a bounded UI fix.

## Change summary

Expanding the prompt section for a subagent with a short, single-line prompt repeats the section title as its entire body.

## Best solution

Render a short single-line subagent prompt once rather than presenting identical title and body text, while preserving multiline prompts and the existing truncation behavior.
