# Issue #306385 — empty code block renderings

[https://github.com/microsoft/vscode/issues/306385](https://github.com/microsoft/vscode/issues/306385)

## Summary

The defect remains source-reproducible on current main: completed empty Markdown fences bypass the existing empty-block suppression and create visible code-block editors. This team-authored issue should remain open for a bounded chat-rendering fix.

## Change summary

Empty fenced code blocks in chat responses render as large blank code-block surfaces.

## Best solution

Chat should omit completed code blocks that contain no renderable content while preserving incomplete streaming behavior and contributed output renderers that legitimately handle empty input.
