# Issue #280526 — Todo response is sometimes just left as "Starting"

[https://github.com/microsoft/vscode/issues/280526](https://github.com/microsoft/vscode/issues/280526)

## Summary

The defect remains source-reproducible on current main: todo invocations still pass through the generic pinned tool-grouping path despite having durable todo-specific presentation. Maintainers identified the same cause and the intended direction, so this should remain open for a bounded renderer fix.

## Change summary

Todo tool responses can remain labeled with an in-progress "Starting" message instead of consistently presenting their completed todo-specific state.

## Best solution

Keep todo-list tool invocations outside collapsed thinking/tool-call groups so their durable todo presentation remains visible and transitions consistently from the invocation message to the completed message.
