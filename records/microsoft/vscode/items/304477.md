# Issue #304477 — search.exclude does not work for "Go to Symbol in Workspace"

[https://github.com/microsoft/vscode/issues/304477](https://github.com/microsoft/vscode/issues/304477)

## Summary

Keep open as a feature request: the previously announced filtering was explicitly withdrawn, and current source still does not apply search.exclude in the workspace-symbol picker. The Markdown exclusion request remains unmet; the older open reports reviewed do not clearly absorb its full scope.

## Change summary

Honor search.exclude patterns such as **/.dart_tool/** when displaying workspace symbols, including Markdown headings.

## Best solution

Establish supported exclusion behavior for workspace-symbol providers, including the built-in Markdown provider, so generated-folder headings can be excluded without disabling useful symbols. Preserve other Markdown language features rather than indiscriminately removing excluded documents from their shared workspace index.
