# Issue #325939 — winpty has been removed

[https://github.com/microsoft/vscode/issues/325939](https://github.com/microsoft/vscode/issues/325939)

## Summary

This is a support question about the terminal not working after winpty removal, filed by a user on a very old Windows 10 build (10240, the original RTM release). A team member has already responded with the `windowsUseConptyDll` workaround. The winpty removal was intentional (commit acb22942b01, PR #289025) and the error path already surfaces guidance.

## Change summary

User cannot open the integrated terminal on Windows 10 build 10240 after winpty support was removed.

## Best solution

The team member's suggestion to enable `terminal.integrated.windowsUseConptyDll` is the correct path. If even the bundled conpty DLL doesn't work on this ancient Windows build (10240 lacks modern ConPTY), the user would need to upgrade Windows. No code change is needed — the removal was deliberate and the error message already links to the migration guide.
