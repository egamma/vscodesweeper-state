# Issue #341066 — [Error] [GitHub.copilot-chat] unhandlederror-Permissive authentication is required

[https://github.com/microsoft/vscode/issues/341066](https://github.com/microsoft/vscode/issues/341066)

## Summary

New error in Copilot Chat 0.69.0. The repository-search command calls getUserRepositories with silent auth and no error handling, so a user without a permissive GitHub session gets an unhandled PermissiveAuthRequiredError. Keeping open to add handling for that case.

## Change summary

The repository-picker search command lets PermissiveAuthRequiredError escape as an unhandled error when no permissive GitHub session exists.

## Best solution

In copilotCloudSessionsProvider.ts, handle PermissiveAuthRequiredError in the SEARCH_REPOSITORIES_COMMAND_ID handler, either returning an empty list or prompting for the permissive session. Then confirm the error bucket drops in the next release.
