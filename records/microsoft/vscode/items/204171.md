# Issue #204171 — Folding in notebook sticky scroll shifts position

[https://github.com/microsoft/vscode/issues/204171](https://github.com/microsoft/vscode/issues/204171)

## Summary

Still reproducible on main: notebook sticky scroll folding calls focusCell() which repositions the viewport, unlike the text editor sticky scroll which keeps the entry in place after fold/unfold.

## Change summary

Folding/unfolding a notebook sticky scroll entry shifts its position instead of keeping it stationary like the text editor's sticky scroll.

## Best solution

After toggling the fold state in NotebookStickyLine.toggleFoldRange(), avoid calling focusCell() (or adjust the scroll logic) so the sticky scroll entry remains visually stable — matching the text editor's behavior where the entry stays in place for easy re-toggle.
