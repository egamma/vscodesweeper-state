# Issue #204171 — Folding in notebook sticky scroll shifts position

[https://github.com/microsoft/vscode/issues/204171](https://github.com/microsoft/vscode/issues/204171)

## Summary

The notebook sticky-scroll folding path still explicitly navigates to the underlying heading after toggling, displacing the entry the user clicked. Keep this open: the current source confirms the unwanted navigation, and the older related reports do not establish a duplicate of this interaction.

## Change summary

Keep a notebook sticky-scroll heading anchored when its folding chevron is toggled so the same control remains available to toggle again.

## Best solution

Make folding through notebook sticky scroll preserve the clicked heading's visual position across folding and unfolding, consistent with text-editor sticky scroll. Preserve the separate behavior where clicking the heading text navigates to its cell.
