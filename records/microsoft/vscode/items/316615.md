# Issue #316615 — Support multiple active chat tabs/sessions concurrently

[https://github.com/microsoft/vscode/issues/316615](https://github.com/microsoft/vscode/issues/316615)

## Summary

Verified duplicate: the older open https://github.com/microsoft/vscode/issues/316260 requests the same pane-resident tabs for concurrently active, independent chat sessions and fully owns this work.

## Change summary

Allow multiple independent chat sessions to remain open as tabs or side-by-side views within the Chat panel.

## Best solution

Consolidate the request on https://github.com/microsoft/vscode/issues/316260 and design pane-resident session tabs there, preserving independent context while keeping chat out of the file-editor area. The Agents Window remains the existing multi-session alternative, but it does not replace the requested Chat-panel workflow.
