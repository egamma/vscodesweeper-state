# Issue #251353 — Replace dialog is not updated when selection changes

[https://github.com/microsoft/vscode/issues/251353](https://github.com/microsoft/vscode/issues/251353)

## Summary

Confirmed in current source: when 'Find in Selection' is checked, changing the editor selection does not update the search scope — `_updateSearchScope()` is only called on find/replace input focus, not on selection change.

## Change summary

Replace All with 'Find in Selection' enabled ignores new selections; users must close and reopen the dialog to update the scope.

## Best solution

In `findWidget.ts`, call `_updateSearchScope()` from the `onDidChangeCursorSelection` handler (around line 230) when the toggle is already checked, so the search scope updates live as the user selects new text in the editor.
