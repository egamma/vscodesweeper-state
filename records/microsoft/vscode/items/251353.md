# Issue #251353 — Replace dialog is not updated when selection changes

[https://github.com/microsoft/vscode/issues/251353](https://github.com/microsoft/vscode/issues/251353)

## Summary

The selection-update behavior is already explicitly tracked by the older, open issue https://github.com/microsoft/vscode/issues/116827. Its third requirement covers this same observable symptom: changing the selection while Replace remains open does not retarget Find in Selection.

## Change summary

Replace All should operate on a newly selected text range without requiring the Replace widget to be closed and reopened.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode/issues/116827, preserving its regex-enabled, repeated Replace All reproduction. That issue explicitly owns updating the search scope when the editor selection changes.
