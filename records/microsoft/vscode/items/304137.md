# Issue #304137 — Active vs inactive selection in ask_questions

[https://github.com/microsoft/vscode/issues/304137](https://github.com/microsoft/vscode/issues/304137)

## Summary

Team-authored bug report; the CSS rules for active vs inactive selection exist in chatQuestionCarousel.css but the active-selection rule targets `.chat-question-list:focus` while focus is typically set on the outer container (`this.domNode`) or individual list items, so the active styling never triggers. Still open on main.

## Change summary

In the ask_questions carousel, selected list items always show inactive selection colors even when the list has keyboard focus, because the CSS active-selection rule targets `.chat-question-list:focus` but focus lands on a different element.

## Best solution

Fix the focus target so the `.chat-question-list` element receives focus (or adjust the CSS selector to match where focus actually lands, e.g. `:focus-within`). The fix is localized to `chatQuestionCarouselPart.ts` and `chatQuestionCarousel.css`.
