# Issue #314837 — Microsoft login is missing from main modal

[https://github.com/microsoft/vscode/issues/314837](https://github.com/microsoft/vscode/issues/314837)

## Summary

Current behavior is intentional: Agents authenticates through GitHub Copilot, while Microsoft authentication is a separate Settings Sync identity. Because this is a team-authored issue and no qualifying factual close applies, it must remain open.

## Change summary

Offer Microsoft-account authentication alongside the existing GitHub, Google, and Apple choices in the initial Agents sign-in modal.

## Best solution

Keep Copilot authentication and Settings Sync authentication distinct unless the Copilot identity contract gains Microsoft-account support; meanwhile, consider clarifying the Agents modal so users understand that its choices authenticate GitHub Copilot rather than VS Code Settings Sync.
