# Issue #327616 — NES: gutter indicator is focusable but has no role, no accessible name, and cannot be operated by keyboard

[https://github.com/microsoft/vscode/issues/327616](https://github.com/microsoft/vscode/issues/327616)

## Summary

Confirmed in current main: the focusable NES gutter indicator lacks button semantics and keyboard handlers, while its menu opens only on mouse hover. This should remain open under its existing accessibility classification.

## Change summary

Make the NES gutter indicator identifiable and operable by keyboard, including access to its action menu.

## Best solution

Update the gutter indicator in `gutterIndicatorView.ts` with a localized accessible name, button semantics, Enter/Space activation, and a keyboard path to open the menu; coordinate menu navigation semantics with https://github.com/microsoft/vscode/issues/327617.
