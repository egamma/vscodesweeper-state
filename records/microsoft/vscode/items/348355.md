# Issue #348355 — Delegated Custom Agent loses write tools

[https://github.com/microsoft/vscode/issues/348355](https://github.com/microsoft/vscode/issues/348355)

## Summary

Keep open: the report provides sufficient steps to retest, and current source shows different tool preparation for directly selected and delegated custom agents. That asymmetry is a diagnostic lead, not proof that the reported read-only restriction still occurs.

## Change summary

Delegating to a custom Developer agent removes its editing and execution tools despite those tools working when the agent is selected directly.

## Best solution

Establish where tool availability diverges between direct selection and task delegation, then preserve the custom agent's supported tool configuration consistently while retaining applicable permission restrictions.
