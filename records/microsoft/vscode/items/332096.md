# Issue #332096 — Agent Host worktree include copying misses collapsible nested ignored directories

[https://github.com/microsoft/vscode/issues/332096](https://github.com/microsoft/vscode/issues/332096)

## Summary

Confirmed in source: `_getWorktreeIncludePaths` in agentHostGitService.ts only collapses directories reported wholly-ignored by `git ls-files --directory` at the top level (since git stops descending once a dir is wholly ignored) and marks the whole root non-collapsible if any file inside doesn't match a glob — it never looks for a fully-matched nested subtree to collapse separately, so every matched file in that subtree is copied individually. An open PR (#332098) already targets this fix, so this should stay open pending review/merge rather than being closed as completed.

## Change summary

Worktree include-file copying fails to collapse fully-matched nested directories inside a partially-ignored-and-matched parent, causing tens of thousands of per-file copy operations instead of one directory copy.

## Best solution

Review and land the linked PR https://github.com/microsoft/vscode/pull/332098, which adds a collapse helper to find the highest fully-matched nested directories within a partially matched wholly-ignored root, per the reporter's proposed fix and test plan.
