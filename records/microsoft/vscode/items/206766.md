# Issue #206766 — RISC-V Support

[https://github.com/microsoft/vscode/issues/206766](https://github.com/microsoft/vscode/issues/206766)

## Summary

Keep this accepted, well-supported request open: current server build targets still exclude RISC-V. Upstream prerequisites have progressed, but experimental Node.js support and merged ripgrep binaries do not establish supported VS Code remote connections.

## Change summary

Support connecting VS Code to Linux RISC-V machines with a compatible remote server.

## Best solution

Provide a supported Linux/riscv64 remote-server distribution and compatible extension execution without requiring unofficial editor forks. First reassess the runtime prerequisite and decide whether experimental Node.js support is sufficient for a VS Code server support tier.
