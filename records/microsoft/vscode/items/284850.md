# Issue #284850 — Error when use Dev Containers

[https://github.com/microsoft/vscode/issues/284850](https://github.com/microsoft/vscode/issues/284850)

## Summary

This is a Dev Containers regression with an open fixing PR in the VS Code team's Dev Containers repository. It should remain open and be transferred to the Remote Development tracker rather than closed as extension-caused.

## Change summary

VS Code 1.107.1 can stall indefinitely while installing the VS Code Server in a Dev Container, while 1.107.0 succeeds.

## Best solution

Review and land https://github.com/microsoft/vscode-remote-containers/pull/1062, then verify that VS Code Server downloads complete before installation proceeds. Transfer this issue to https://github.com/microsoft/vscode-remote-release so the Dev Containers owners can track the fix and release.
