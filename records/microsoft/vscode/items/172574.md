# Issue #172574 — Switch back to previous application after "code --wait"

[https://github.com/microsoft/vscode/issues/172574](https://github.com/microsoft/vscode/issues/172574)

## Summary

This remains the canonical, accepted Backlog request for returning focus after `code --wait`; current main still only waits for editor closure and has no originating-application restoration mechanism.

## Change summary

Return focus to the application that invoked `code --wait` after the opened editor closes.

## Best solution

Extend the CLI launch/wait flow to capture the originating foreground application and restore it after the wait marker is deleted, using platform-specific implementations and preserving existing behavior through an opt-in flag if necessary.
