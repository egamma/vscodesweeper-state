# Issue #291017 — Confusing UX around tab vs not tab page

[https://github.com/microsoft/vscode/issues/291017](https://github.com/microsoft/vscode/issues/291017)

## Summary

Team-authored UX feedback on the agents window: the transition from the welcome page tab into a maximized chat session is confusing, confirmed by another team member. Stays open for design iteration.

## Change summary

The transition from the agents welcome page (a tab) into an agent session (a full-page view without standard tab affordances) is disorienting — Cmd+W closes the window, and returning to the welcome page is non-obvious.

## Best solution

Redesign the welcome-page-to-session transition so users understand they are navigating within the agents window, with a clear back affordance and consistent keyboard shortcut behavior (Cmd+W should not close the OS window). The welcome view should remain easily accessible even after opening a session.
