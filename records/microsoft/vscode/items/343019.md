# Issue #343019 — Pending inlay hint requests are not cancelled on document edits, allowing stale positions to render

[https://github.com/microsoft/vscode/issues/343019](https://github.com/microsoft/vscode/issues/343019)

## Summary

The defect is present in current main: document edits cancel an unassigned token source, leaving the actual pending inlay-hint request eligible to render stale positions. Keep this open for a bounded controller fix and regression test.

## Change summary

Prevent inlay-hint responses computed before a document edit from rendering at obsolete positions.

## Best solution

Make pending-request invalidation in InlayHintsController effective immediately on document edits, while preserving debounced refreshes and position tracking for already-rendered hints.
