# Issue #327384 — Cloud Session should be able to check out into a work tree.

[https://github.com/microsoft/vscode/issues/327384](https://github.com/microsoft/vscode/issues/327384)

## Summary

Keep open for transfer to the Microsoft GitHub Pull Requests extension tracker, which owns the delegated checkout workflow. Existing worktree checkout support is not currently exposed by the cloud-session Checkout action.

## Change summary

Allow a cloud session's Checkout flow to create a Git worktree when the current workspace conflicts with the pull request.

## Best solution

Move this issue to https://github.com/microsoft/vscode-pull-request-github and integrate cloud-session checkout with that extension's worktree checkout capability, preferably using the unified UI tracked by https://github.com/microsoft/vscode-pull-request-github/issues/8716.
