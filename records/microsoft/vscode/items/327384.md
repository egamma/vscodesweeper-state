# Issue #327384 — Cloud Session should be able to check out into a work tree.

[https://github.com/microsoft/vscode/issues/327384](https://github.com/microsoft/vscode/issues/327384)

## Summary

Keep open: the inspected cloud checkout entry point delegates to GitHub Pull Requests without selecting a worktree destination. Existing Git worktree commands do not establish that the requested conflict-dialog option exists, and no qualifying fix or duplicate was found.

## Change summary

Offer checkout into a separate Git worktree when a cloud session cannot be checked out because of conflicts in the current working directory.

## Best solution

Provide a worktree checkout option in the cloud-session checkout conflict flow, preserving the current working directory and its changes. Coordinate the cloud-session entry point with the GitHub Pull Requests checkout implementation rather than treating standalone worktree creation as equivalent.
