# Issue #307702 — Copy and paste from Explorer to Chat view should attach the image

[https://github.com/microsoft/vscode/issues/307702](https://github.com/microsoft/vscode/issues/307702)

## Summary

The bug remains on current main: Explorer copy stores selected resources in the clipboard service, but Chat's paste providers never consume that resource list, so non-image files become path text instead of attachments. A maintainer also confirmed the reproduction, and this team-authored Backlog bug should remain open.

## Change summary

Copying a file in Explorer and pasting it into Chat should attach the file, consistently with drag and drop.

## Best solution

Make Chat resolve resources copied from Explorer into the same file, folder, or image attachment entries used by drag and drop, while preserving ordinary text-paste behavior and announcing the attached context to screen-reader users.
