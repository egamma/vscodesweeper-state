# Issue #323723 — Cannot include a new line in local file search bar while in a Jupyter notebook file

[https://github.com/microsoft/vscode/issues/323723](https://github.com/microsoft/vscode/issues/323723)

## Summary

Keep open as a notebook find/replace capability gap: the current implementation constructs single-line inputs rather than the multiline controls available in ordinary editors. The older related request covers replacement text only, so it does not establish a canonical for this report's Find and Replace scope.

## Change summary

Allow Ctrl+Enter to insert literal newlines into both fields of the notebook-local Find and Replace widget.
