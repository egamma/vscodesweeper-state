# Issue #323723 — Cannot include a new line in local file search bar while in a Jupyter notebook file

[https://github.com/microsoft/vscode/issues/323723](https://github.com/microsoft/vscode/issues/323723)

## Summary

Confirmed bug: the notebook find widget's key handler does not handle Ctrl+Enter for newline insertion, unlike the regular editor's FindWidget. The gap is clear in the source.

## Change summary

Ctrl+Enter does not insert a newline in the notebook find/replace widget, although it works in the regular editor's find widget.

## Best solution

Add Ctrl+Enter handling in `NotebookFindWidget._onFindInputKeyDown` and `_onReplaceInputKeyDown` (in `src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFindWidget.ts`) to insert a newline via `this._findInput.inputBox.insertAtCursor('\n')`, mirroring the pattern in `src/vs/editor/contrib/find/browser/findWidget.ts` lines 893–902 and 932–938.
