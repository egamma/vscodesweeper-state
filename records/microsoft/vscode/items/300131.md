# Issue #300131 — Terminal - Cannot input after git asking for ssh passphrase

[https://github.com/microsoft/vscode/issues/300131](https://github.com/microsoft/vscode/issues/300131)

## Summary

This is the same kitty-keyboard-protocol + fish-shell regression fixed in 1.112.0 via an xterm.js bump. The commenter's workaround (disabling kitty keyboard) confirms the same root cause as the canonical tracker #295372, which was fixed and verified. The fix shipped in 1.112.0.

## Change summary

Terminal input becomes unresponsive when a program disables echo (e.g. SSH passphrase prompt) in fish shell, due to the kitty keyboard protocol enabled by default in 1.110.

## Best solution

Keep the shipped xterm.js fix (commit 4fb8242c5fc, 1.112.0). No further change needed — the reporter's version (1.110.1) predates the fix. Close as completed.
