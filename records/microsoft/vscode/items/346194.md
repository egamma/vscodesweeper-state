# Issue #346194 — Agents window: a fetch cancelled by Mark as Done shows as "Fetched" in the transcript

[https://github.com/microsoft/vscode/issues/346194](https://github.com/microsoft/vscode/issues/346194)

## Summary

Keep open: current history reconstruction can turn an unfinished tool request into a successful completed call, explaining the misleading Fetched transcript. The report provides sufficient reproduction steps and cancellation evidence.

## Change summary

A fetch cancelled through background-session Mark as Done is incorrectly restored as successfully fetched.

## Best solution

Restored Copilot transcripts should distinguish cancelled or skipped tool requests from successful executions, while preserving genuine completed results even when their enclosing turn is cancelled.
