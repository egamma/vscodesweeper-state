[https://github.com/microsoft/vscode/issues/173159](https://github.com/microsoft/vscode/issues/173159)

Keep open: editor links still lack screen-reader discovery, and the existing Open Link command does not cover that gap. The maintainer explicitly requested a link accessibility signal and better command discoverability; the related items do not establish completion or an older canonical.

## Change summary

Make detected links discoverable and their opening action accessible to screen-reader users in text and Markdown source editors.

## Best solution

- **Current link implementation:** src/vs/editor/contrib/links/browser/links.ts: LinkDetector.updateDecorations and LinkOccurrence._getOptions represent detected links through inline styling and hoverMessage. OpenLinkAction registers editor.action.openLink and opens the link at each selection endpoint, but supplies no default keybinding or link-discovery mechanism. Existing opening support therefore only partially covers the report.

The inspected default native edit-context path cannot expose detected editor URLs as semantic links; no VoiceOver execution was performed.
