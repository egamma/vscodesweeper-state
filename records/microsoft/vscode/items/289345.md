# Issue #289345 — Agents: globally unique URIs

[https://github.com/microsoft/vscode/issues/289345](https://github.com/microsoft/vscode/issues/289345)

## Summary

Cloud sessions now use stable task-based URIs rather than repository-local pull request numbers, substantially addressing the original concern. Keep this open until the broader cross-workspace, profile, and machine identity guarantee is established; neither related issue is a verified canonical for that scope.

## Change summary

Ensure chat session resources identify sessions globally without collisions, so resource-keyed state can safely follow sessions across environments.

## Best solution

Establish the provider-wide session identity contract and audit remaining providers against it, preserving the existing task-based cloud identity. Separate any remaining identity gaps from the subsequent work of roaming read/archive state, rather than assuming that unique URIs alone implement synchronization.
