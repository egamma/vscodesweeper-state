# Issue #315131 — Completion-inserted `()` no longer tracked as auto-closed pair

[https://github.com/microsoft/vscode/issues/315131](https://github.com/microsoft/vscode/issues/315131)

## Summary

The regression remains present on current main and is conclusively traceable through the editor source. Route this to the editor area as a correctness bug affecting completion-inserted auto-closing pairs.

## Change summary

Completion snippets that insert paired delimiters no longer receive auto-closed-pair behavior when accepted through the suggest controller.

## Best solution

Restore auto-closing-pair tracking for snippet edits originating from suggestions while preserving the structured suggest edit reason introduced by https://github.com/microsoft/vscode/pull/252666. Add focused cursor coverage proving that Backspace removes both completion-inserted parentheses and that overtyping behavior remains intact.
