# Issue #315131 — Completion-inserted `()` no longer tracked as auto-closed pair

[https://github.com/microsoft/vscode/issues/315131](https://github.com/microsoft/vscode/issues/315131)

## Summary

Confirmed regression on current main: PR #252666 changed the edit source for suggest-triggered snippet insertions from 'snippet' to 'suggest', but cursor.ts line 469 still gates _findAutoClosingPairs on source === 'snippet', so completion-inserted brackets are no longer tracked as auto-closed pairs.

## Change summary

Completions that insert function calls with parentheses (e.g. `foo()`) via snippets no longer register the inserted brackets as auto-closed pairs, breaking the special backspace and overtype behaviors.

## Best solution

Widen the guard in src/vs/editor/common/cursor/cursor.ts (line 469) to also call _findAutoClosingPairs when the source is 'suggest' (or when the reason metadata indicates the edit originated from a snippet path). The fix is small and localized to cursor.ts; the suggest controller and snippet session are correct in their new reason-reporting — only the consumer needs updating.
