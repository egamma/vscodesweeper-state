# Issue #339547 — Background task completion error event omits the final resource

[https://github.com/microsoft/vscode/issues/339547](https://github.com/microsoft/vscode/issues/339547)

## Summary

Confirmed in source: WatchingProblemCollector.tryFinish fires onDidFindErrors by reading MarkerService before resetCurrentResource() flushes the pending current-resource markers, so the completion event can miss or misreport the final resource's diagnostics. An open PR already targets this, so the issue should stay open for that PR to land rather than being closed now.

## Change summary

Background task watcher's completion (onDidFindErrors/BackgroundProcessingEnds) event can omit diagnostics for the last-processed resource because they haven't been flushed into MarkerService yet when the event fires.

## Best solution

Land (or review) the open fix PR https://github.com/microsoft/vscode/pull/339551, which flushes the current resource's markers before firing the completion notification in WatchingProblemCollector.tryFinish.
