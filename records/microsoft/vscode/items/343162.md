Keep open: current source still makes every artifact reevaluation eligible to retry an unchanged commit after a failed lookup. The report supplies a concrete characterization, and the issue already has the appropriate area labels.

## Change summary

Prevent presentation-only artifact updates from repeatedly requesting the same GitHub commit metadata after persistent access or missing-resource failures.
