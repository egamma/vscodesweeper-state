Current source contains steering-admission guards and ordering tests, but these do not establish that this cross-chat scenario is resolved; the supplied steps suffice to retest.

## Change summary

Preserve the original request before a subsequent steering correction when an agent sends work to another chat.

## Best solution

Ensure cross-chat steering reaches the receiving conversation after its original request and modifies that work without losing its context. Retest the reported sleep-command scenario and compare host dispatch order with the provider's actual conversation before choosing a fix.
