# Issue #145768 — Provide support for separate aria label for the customButton on quickpick component

[https://github.com/microsoft/vscode/issues/145768](https://github.com/microsoft/vscode/issues/145768)

## Summary

The quick-pick custom button still has no independently configurable accessible label. Keep this accepted Backlog request open; the linked merged accessibility PR did not implement it.

## Change summary

Allow a quick-pick custom button to have an accessible label separate from its visible text and the input box label.

## Best solution

Expose an optional accessible-name override through the internal quick-pick interface and honor it on the custom button, preserving the existing visible-text naming behavior when no override is supplied.
