# Issue #319383 — add project manager

[https://github.com/microsoft/vscode/issues/319383](https://github.com/microsoft/vscode/issues/319383)

## Summary

Project-template management is established extension territory rather than a VS Code core feature. Existing triage precedent covers the full request, including language-specific templates and C/C++ build options.

## Change summary

Add a project manager that creates projects from bundled C/C++, web, Electron, and Tauri templates and supports renaming and deletion.

## Best solution

Language and framework extensions should provide their own template catalogs and creation workflows, while ordinary project folders remain manageable through the Explorer. Users wanting a general built-in creation path can also use Copilot's current new-workspace scaffolding flow.

## Vision fit

- **Fit:** rejected
- **Reason:** Bundling and maintaining framework-specific project templates in core conflicts with the lean default experience and is well suited to extensions.
- **Evidence:** Values and guardrails: “Out of the box, VS Code is a text editor: lightweight and fast” and “The power lives in extensions.”

  > Thanks for the suggestion. Current VS Code also offers Copilot's `#new` scaffolding flow for general project creation, while fixed C/C++, Vite, Electron, and Tauri template workflows are best provided by extensions or the framework tooling.
