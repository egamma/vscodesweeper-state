# Issue #61298 — Show Timestamp while Debugging

[https://github.com/microsoft/vscode/issues/61298](https://github.com/microsoft/vscode/issues/61298)

## Summary

This remains a valid, well-supported Debug Console feature request. Maintainers explicitly chose a protocol-level design for consistent timestamp formatting, and the required protocol work remains open, so neither a duplicate nor a completed close is justified.

## Change summary

Add an optional timestamp display for Debug Console output, comparable to Chrome DevTools.

## Best solution

Define timestamp metadata for debug output in the Debug Adapter Protocol, then add a VS Code Debug Console setting and renderer support so timestamps are displayed consistently across adapters.
