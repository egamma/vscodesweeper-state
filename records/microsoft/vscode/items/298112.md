# Issue #298112 — Autosave feature for chats; ability to make imported chat the current chat

[https://github.com/microsoft/vscode/issues/298112](https://github.com/microsoft/vscode/issues/298112)

## Summary

This is a duplicate of the older open issue tracking imported chats not becoming persistent, resumable sessions. Current source already saves ordinary local chats but explicitly excludes imported chats, leaving the canonical issue to own the remaining gap.

## Change summary

Persist chats automatically and allow an imported transcript to become the active, resumable chat rather than a temporary editor session.

## Best solution

Resolve https://github.com/microsoft/vscode/issues/291986 by making an import create or fork into a normal persisted session that appears in session history and can be resumed after its editor closes.
