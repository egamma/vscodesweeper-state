# Issue #94513 — Terminal canvas context loss is not handled

[https://github.com/microsoft/vscode/issues/94513](https://github.com/microsoft/vscode/issues/94513)

## Summary

Fully resolved: the canvas renderer was removed entirely from VS Code's terminal, and WebGL context loss is now handled with a graceful fallback to the DOM renderer. The upstream xterm.js issue is also closed.

## Change summary

Terminal canvas context loss was not handled, causing rendering failures when the GPU reclaimed canvas contexts.

## Best solution

Keep the shipped behavior: canvas renderer removed (commit 6cdd364d933), WebGL context loss handled via onContextLoss fallback to DOM. No further work needed.
