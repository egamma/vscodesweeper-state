# Issue #241951 — Shell Type not resolving properly

[https://github.com/microsoft/vscode/issues/241951](https://github.com/microsoft/vscode/issues/241951)

## Summary

The shellType tab-title variable still resolves incorrectly on main — on window reload, every terminal gets the default profile's shell type instead of its own, because the initial guess (line 563) runs after the SLC executable is overwritten with the default profile (lines 550–556), and the pty-reported shell type may not arrive in time or at all for reconnected sessions.

## Change summary

The `${shellType}` variable in `terminal.integrated.tabs.title` resolves to the default profile's shell type instead of the actual shell's type after a window reload.

## Best solution

The initial shell-type guess in `_initDimensions` (terminalInstance.ts ~line 563) should use the profile-specific executable, not the already-overwritten SLC executable. For reconnected/persisted sessions, the persisted shell type should be restored from the attach data rather than re-guessed from the (default) executable. The fix is localized to `terminalInstance.ts` around the `guessShellTypeFromExecutable` call and the `attachPersistentProcess` reconnect path.
