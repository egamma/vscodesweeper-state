## Change summary

After reloading a window, the terminal title's ${shellType} variable can identify the default profile instead of the terminal's actual shell.

## Best solution

Ensure restored terminals report their own shell type independently of the current default profile. First confirm whether the incorrect value persists after reattachment or results from initialization timing, then address that path in terminal restoration and shell-type propagation.
