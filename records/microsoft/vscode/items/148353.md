# Issue #148353 — vscode.dev has bad behavior when opening an unknown file type

[https://github.com/microsoft/vscode/issues/148353](https://github.com/microsoft/vscode/issues/148353)

## Summary

Still reproduces on main: the media-preview extension has no handling for the `untitled:` scheme that Safari/Firefox produce when opening binary files on vscode.dev. No fix has merged; an open PR (#290258) acknowledges the root cause requires core changes.

## Change summary

Opening an image file on vscode.dev in Safari/Firefox shows blank content because the `untitled:` scheme used for non-File-System-Access-API browsers cannot be read by custom editors.

## Best solution

A core-level fix is needed so that binary file contents opened via Safari/Firefox's upload flow are accessible to custom editors (media-preview, image-preview). The open PR https://github.com/microsoft/vscode/pull/290258 documents the limitation — the real fix likely lives in how the web file opener stores binary content (e.g. using blob URIs or making untitled content readable by IFileService for binary files).
