# Issue #90611 — Git - Git does not show gutters unless file is opened from changed files tab

[https://github.com/microsoft/vscode/issues/90611](https://github.com/microsoft/vscode/issues/90611)

## Summary

Keep open for Git path-identity handling: multiple reports confirm that Explorer-opened files lack diff gutters while SCM-opened versions work. The maintainer identified a symlink/canonical-path mismatch, but the supplied evidence establishes neither a complete fix nor a policy-valid duplicate.

## Change summary

Show Git diff gutters consistently when a tracked file is opened through a differently cased or symlinked path.

## Best solution

Make the built-in Git integration associate editor resources with their tracked repository paths despite casing or symlink aliases, without globally changing how VS Code preserves symlink paths. Verify both the original Windows casing case and the independently confirmed symlink case.
