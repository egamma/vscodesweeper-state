## Summary

Well-diagnosed, reproducible hang: a subagent's tool call is announced but never executed and its turn never closes. An open PR (#334072) already targets this exact issue with `Fixes #333931`, is assigned to a maintainer, and includes new regression tests — so this stays open pending that PR landing rather than being closed or auto-fixed independently.

## Change summary

In a dev container, a subagent's announced tool call is never executed and never times out, so its turn (and the parent's spawning turn) stays open forever, and the chat spins indefinitely.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/334072, which detaches a subagent's chat observation from the parent turn's disposable store (so a chat created after the parent turn completes is still observed, claimed, and executed) and adds targeted regression tests; that directly closes this issue via its `Fixes #333931` reference.
