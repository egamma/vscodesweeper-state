# Issue #333931 — Agent host: a subagent's tool call is never executed and its turn is never closed, so the chat spins forever

[https://github.com/microsoft/vscode/issues/333931](https://github.com/microsoft/vscode/issues/333931)

## Summary

Well-diagnosed, reproducible hang where a subagent's tool call is announced but never executed and its turn never closes; an open PR from the same reporter already claims to fix it, so this should stay open pending review/merge of that PR rather than any close.

## Change summary

A subagent's `Bash` tool call gets stuck in `handleCanUseTool` with no confirmation ever surfaced, so the tool never runs, `subagent_completed` never fires, and the subagent's (and its parent's) chat turn stays open forever.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/334072 ("Keep observing a subagent whose chat outlives its spawning turn", opened by the same reporter, body states `Fixes #333931`), which fixes the parent-turn-scoped subagent chat subscription that this issue traces the hang to; keep the issue open until that merges and is verified.
