# Issue #230033 — Git - GIT_ASKPASS fails on concurrent / interleaved username & password requests

[https://github.com/microsoft/vscode/issues/230033](https://github.com/microsoft/vscode/issues/230033)

## Summary

The reported interleaving still fails in current source: the first password request consumes the shared credential cache entry, leaving the second request to prompt manually. Keep this open in the Git area; the existing timeout does not resolve concurrent credential consumption.

## Change summary

Concurrent Git commands requesting credentials for the same authority unexpectedly fall back to password prompts and disrupt private-dependency fetching.

## Best solution

Make the built-in Git HTTPS askpass flow handle overlapping credential exchanges without unexpected password prompts, while preserving bounded credential retention, ordinary sequential authentication, and SSH behavior.
