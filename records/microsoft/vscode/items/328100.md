# Issue #328100 — terminal flickers while resizing

[https://github.com/microsoft/vscode/issues/328100](https://github.com/microsoft/vscode/issues/328100)

## Summary

Team-authored bug report with an open fixing PR already referencing it — keep open until that PR lands rather than closing or auto-fixing.

## Change summary

Terminal canvas/grid flickers and stretches while the terminal panel is being resized, because column and row updates to xterm are not synchronized during active drag-resize.

## Best solution

Land https://github.com/microsoft/vscode/pull/330901 (or an equivalent fix) to synchronize the row/column resize passes in TerminalResizeDebouncer so xterm's canvas doesn't stretch/squish between the DOM resize and the debounced column update.

- **contributor diagnosis:** A comment identifies the root cause in src/vs/workbench/contrib/terminal/browser/terminalResizeDebouncer.ts: vertical resizes (_resizeYCallback) run synchronously per frame while horizontal resizes (_debounceResizeXScheduler) are debounced ~100ms, so cols/rows go out of sync mid-drag and xterm's renderer stretches until the debounce fires.
