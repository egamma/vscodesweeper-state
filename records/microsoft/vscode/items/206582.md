# Issue #206582 — Allow changing the font color of an editor widget

[https://github.com/microsoft/vscode/issues/206582](https://github.com/microsoft/vscode/issues/206582)

## Summary

The theming gap remains on current main: embedded editor widgets still require CSS overrides to use a foreground other than `editor.foreground`. This team-authored Backlog request should remain open for an editor-theming design.

## Change summary

Provide a supported way for a CodeEditorWidget instance to override its text foreground color.

## Best solution

Add a scoped foreground-color option to `CodeEditorWidget` that updates the editor and token default foreground without requiring consumers to target generated token classes such as `.mtk1`.
