# Issue #177914 — localize info messages in notebook output

[https://github.com/microsoft/vscode/issues/177914](https://github.com/microsoft/vscode/issues/177914)

## Summary

The localization gap remains in current main: notebook output notices, link labels, tooltips, and accessible names are still hard-coded in English. Keep this team-authored report open; the linked merged PR added an accessible label but did not localize it.

## Change summary

Localize the built-in notebook renderer's output truncation and full-output informational UI.

## Best solution

Make the informational UI in extensions/notebook-renderers/src/textHelper.ts follow the display language, including accessible names and tooltips, while preserving output content and command links. Establish translation delivery and extraction for the browser-side renderer before treating this as a string-only cleanup.
