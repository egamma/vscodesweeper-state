# Issue #134588 — Add setting to keep tab characters in HTML clipboard

[https://github.com/microsoft/vscode/issues/134588](https://github.com/microsoft/vscode/issues/134588)

## Summary

Valid feature request to preserve tab characters in HTML clipboard output instead of converting them to spaces. Confirmed and reframed by alexdima as a feature request. Still unimplemented on current main — the tab-to-spaces conversion is hardcoded in `tokenizeLineToHTML`. Low traction (0 upvotes) but already triaged to On Deck.

## Change summary

Add a setting to preserve tab characters (instead of converting to spaces) in the HTML clipboard data generated when copying code from the editor.

## Best solution

Add an option (e.g. `editor.clipboard.keepTabsInHtml`) that, when enabled, emits a `\t` character in the HTML output of `tokenizeLineToHTML` instead of expanding tabs to spaces. The fix is localized to `src/vs/editor/common/languages/textToHtmlTokenizer.ts` and `src/vs/editor/common/viewModel/viewModelImpl.ts`. The container div already uses `white-space: pre`, so literal tabs would render correctly. Given 0 upvotes over nearly 4 years, this is low priority but a clean, small change if someone picks it up.
