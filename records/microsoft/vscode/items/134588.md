# Issue #134588 — Add setting to keep tab characters in HTML clipboard

[https://github.com/microsoft/vscode/issues/134588](https://github.com/microsoft/vscode/issues/134588)

## Summary

Still valid: tabs are converted to spaces in the HTML clipboard path (`tokenizeLineToHTML`), and no setting exists to preserve them. The request has 0 upvotes and sits in On Deck, but the behavior gap is real — Xcode and Visual Studio both preserve tabs in their HTML clipboard output.

## Change summary

Add a setting to preserve tab characters (instead of converting to spaces) in the HTML placed on the clipboard when copying syntax-highlighted code.

## Best solution

Add an option (or respect the file's `insertSpaces` setting) in the `tokenizeLineToHTML` path in `src/vs/editor/common/languages/textToHtmlTokenizer.ts` to emit `&#9;` or a `<span>` with a tab character instead of expanding tabs to spaces. The call site is `src/vs/editor/common/viewModel/viewModelImpl.ts` around line 1129. Low upvote count suggests this can stay parked until demand grows.
