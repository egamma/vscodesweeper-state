# Issue #134588 — Add setting to keep tab characters in HTML clipboard

[https://github.com/microsoft/vscode/issues/134588](https://github.com/microsoft/vscode/issues/134588)

## Summary

The requested combination remains unavailable on current main: VS Code still expands tabs to spaces in its syntax-highlighted HTML clipboard payload. The existing setting can omit HTML entirely, but that also removes syntax coloring, so it is only a partial workaround.

## Change summary

Allow copied syntax-highlighted HTML to retain tab characters so rich-text consumers such as Word preserve indentation tabs.

## Best solution

Determine whether rich HTML copying should preserve literal tabs universally or through an opt-in editor setting, while leaving the plain-text clipboard payload and syntax coloring intact. Compatibility across major rich-text paste targets should guide that product decision.
