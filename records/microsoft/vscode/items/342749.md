# Issue #342749 — How to stop or change all prompts at once?

[https://github.com/microsoft/vscode/issues/342749](https://github.com/microsoft/vscode/issues/342749)

## Summary

Keep open as a feature request: Compare Models can launch several attempts together, but the current source does not expose the corresponding stop-all and edit-and-relaunch workflow. This is a concrete usability gap, not merely a how-to question.

## Change summary

Allow users to stop an entire comparison and relaunch its participants with a corrected shared prompt instead of updating each session individually.

## Best solution

Provide comparison-scoped cancellation and a way to revise the shared prompt and launch another comparison with the previous participant configuration, without affecting unrelated sessions or rewriting existing attempt history.
