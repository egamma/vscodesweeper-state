# Issue #312528 — Create Copilot Chat settings for setting a global Custom Agent as default Agent

[https://github.com/microsoft/vscode/issues/312528](https://github.com/microsoft/vscode/issues/312528)

## Summary

The requested capability already exists: `chat.newSession.defaultMode` accepts a custom-agent name or identifier and applies it to new empty chat sessions.

## Change summary

Allow a globally available custom agent containing organization-specific context to be selected by default for new Copilot Chat sessions.

## Best solution

Set `chat.newSession.defaultMode` in user settings to the custom agent's name or identifier; the existing mode-resolution path will select it when each new chat session starts.
