# Issue #284172 — Attached files do not update on file events

[https://github.com/microsoft/vscode/issues/284172](https://github.com/microsoft/vscode/issues/284172)

## Summary

Keep open: current main removes an attachment when its old URI is deleted but has no path to update the attachment's URI and displayed name after an Explorer rename. The related merged PR addressed deletion rather than this rename behavior.

## Change summary

When an explicitly attached file is renamed in Explorer, update its chat attachment to reference and display the new file instead of retaining or removing the old reference.

## Best solution

Keep explicit chat file attachments synchronized with successful file moves, including their URI, identity, displayed basename, and watcher lifecycle, while preserving the existing behavior that removes genuinely deleted attachments.
