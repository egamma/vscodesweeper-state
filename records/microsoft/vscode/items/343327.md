# Issue #343327 — Keep/Undo review workflow is difficult to discover after Agent Host transition

[https://github.com/microsoft/vscode/issues/343327](https://github.com/microsoft/vscode/issues/343327)

## Summary

Keep open for review-workflow discoverability and terminology improvements. Current main includes Agent Host Keep/Undo controls, but their availability does not fully address explaining the workflow when users choose a harness or encounter direct file edits.

## Change summary

Make edit-review behavior, access to Keep/Undo, and the distinction between closing a view and rejecting edits understandable across Local and Agent Host sessions.

## Best solution

Explain the available review workflow at the harness-selection and edit-review entry points, using terminology that accurately distinguishes undoing edits from dismissing a view. Build on the Agent Host review controls already present on main rather than treating switching to Local as the only solution.
