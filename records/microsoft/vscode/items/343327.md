# Issue #343327 — Keep/Undo review workflow is difficult to discover after Agent Host transition

[https://github.com/microsoft/vscode/issues/343327](https://github.com/microsoft/vscode/issues/343327)

## Summary

Keep open as a discoverability and terminology request. Current main already provides Agent Host Keep/Undo controls, but their existence does not resolve the reported difficulty understanding harness differences and finding the review workflow.

## Change summary

Make edit-review capabilities and edit-application behavior easier to understand across Local and Agent Host sessions.

## Best solution

Make available review controls discoverable and explain accurately when each harness writes files versus offers subsequent review. Preserve the existing Agent Host working-set controls, and distinguish closing a view from undoing edits rather than renaming Close without establishing its actual behavior.
