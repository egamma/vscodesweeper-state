# Issue #316356 — Hidden PowerShell spawned during update check to terminate dllhost.exe processes

[https://github.com/microsoft/vscode/issues/316356](https://github.com/microsoft/vscode/issues/316356)

## Summary

Already fixed: the runtime `killContextMenuComSurrogate` call in the update service was reverted in PR #316264 (merged 2026-05-13, shipped in 1.121.0). The hidden PowerShell spawn no longer occurs during update checks on current main or 1.121+.

## Change summary

VS Code 1.120 spawns a hidden PowerShell process to kill dllhost.exe COM surrogate during update checks, triggering security software alerts.

## Best solution

Keep the shipped revert (commit a6e058c0dbd); the COM surrogate termination now only runs inside the Inno Setup installer (where elevated context makes it acceptable), not at runtime. No further change needed.
