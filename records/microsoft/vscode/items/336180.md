# Issue #336180 — Custom agent Markdown link does not load referenced .instructions.md file

[https://github.com/microsoft/vscode/issues/336180](https://github.com/microsoft/vscode/issues/336180)

## Summary

Well-diagnosed, source-confirmed bug: the currently selected custom agent's own `.agent.md` file is never added to the variable set that `_addReferencedInstructions` scans, so markdown links inside the agent body to `.instructions.md` files are silently dropped, unlike `.prompt.md` references which are attached and thus scanned.

## Change summary

A custom agent's Markdown link to an `.instructions.md` file is not resolved into the request context when the agent is selected directly (works fine from a `.prompt.md` file or with `applyTo: '**'`).

## Best solution

In chatServiceImpl.ts's `collectInstructions()`, seed the `ComputeAutomaticInstructions` variable set with the active custom agent's own file/body (or otherwise feed its parsed body into `_addReferencedInstructions`) so its markdown links are resolved the same way `.prompt.md` references already are.

## Evidence

- **referenced-instructions scan scope:** src/vs/workbench/contrib/chat/common/promptSyntax/computeAutomaticInstructions.ts:575-591 — `_addReferencedInstructions` only walks `attachedContext.asArray()` entries that are `isPromptFileVariableEntry`; it never looks at the active custom agent's own body.
- **variable set seeding:** src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts:1671-1685 — `collectInstructions()` seeds `variableSet` only from `options?.attachedContext` (explicit user attachments); the custom agent selected via `options?.modeInfo?.modeInstructions` is a separate field never merged into this set, so its markdown-linked instructions can't be picked up.
- **why .prompt.md works:** A `.prompt.md` file used as a launcher is itself added as a `PromptFileVariableEntry` in attachedContext, so its body IS parsed and its `fileReferences` resolved — explaining the reporter's control experiment 2 passing while the direct agent selection (control absent) fails.
