# Issue #318152 — Chat session history lost when switching between GitHub-authenticated and BYOK/anonymous mode – sessions still on disk but inaccessible

[https://github.com/microsoft/vscode/issues/318152](https://github.com/microsoft/vscode/issues/318152)

## Summary

Valid bug confirmed in source: session metadata stored with StorageScope.PROFILE becomes inaccessible on auth-state change. An open PR (#318173) is already addressing this — keeping open pending that fix.

## Change summary

Chat session history becomes invisible when switching between GitHub-authenticated and BYOK/anonymous mode because session metadata is stored per-profile.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/318173 which addresses session persistence across auth transitions, or decouple session metadata from StorageScope.PROFILE so it survives login/logout transitions.
