# Issue #227119 — Editor GPU: Support custom glyphs

[https://github.com/microsoft/vscode/issues/227119](https://github.com/microsoft/vscode/issues/227119)

## Summary

The editor GPU renderer still rasterizes box-drawing and block characters from the font rather than drawing cell-filling custom glyphs. Keep this accepted Backlog request open; the older GPU tracking issue discusses the capability but does not establish a same-symptom duplicate under the re-review rules.

## Change summary

Support custom box-drawing and block glyphs in the GPU editor renderer so adjoining characters connect despite line-height or letter-spacing changes.

## Best solution

Provide cell-aware rendering for box-drawing and block characters within the editor GPU pipeline, preserving ordinary text rendering and the DOM fallback. Agree on whether this overrides font-provided shapes automatically or is independently configurable before implementation.
