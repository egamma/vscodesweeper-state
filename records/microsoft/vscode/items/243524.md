# Issue #243524 — Latex rendering not working as expected in Python notebook

[https://github.com/microsoft/vscode/issues/243524](https://github.com/microsoft/vscode/issues/243524)

## Summary

Still reproduces on main: the notebook markdown-it renderer passes `text/latex` content directly to markdown-it without wrapping it in math delimiters, so raw LaTeX (without `$`) is rendered as plain text instead of being processed by KaTeX.

## Change summary

IPython `Latex()` output (mime type `text/latex`) is not rendered as math in notebook cells unless manually wrapped in `$` delimiters.

## Best solution

In `extensions/markdown-language-features/notebook/index.ts`, detect `text/latex` mime type and wrap the content in `$$...$$` delimiters before passing to markdown-it, so KaTeX processes it correctly — matching Jupyter's behavior where `text/latex` content is always treated as math.
