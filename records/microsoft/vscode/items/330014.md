# Issue #330014 — Chat sticky scroll: Don't see banner for most messages with smaller resized window

[https://github.com/microsoft/vscode/issues/330014](https://github.com/microsoft/vscode/issues/330014)

## Summary

Team-authored report on the brand-new prompt-timeline sticky header, so hard keep-open rules apply regardless of judgment; traced the gating code and the described gap is real but looks like a design threshold question (needs a maintainer decision), not a clear-cut, citable fix.

## Change summary

In a resized/small chat window, the sticky prompt banner rarely appears while scrolling, unlike in a larger window.

## Best solution

This is a chat/prompt-timeline UX decision: `_createStickyHeader` in promptTimelineWidgetContrib.ts only shows the header once `model.activePinned` is true (the active prompt has scrolled above the viewport). In a small window, each prompt's content fits mostly within the viewport, so it rarely gets pinned — the maintainers should decide whether `activePinned` (or its underlying scroll threshold) should be relaxed for short viewports, or whether this converges with the broader 'always show banner' ask in https://github.com/microsoft/vscode/issues/330010.
