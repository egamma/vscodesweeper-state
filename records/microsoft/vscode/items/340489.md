# Issue #340489 — Agent Host retries orphaned Claude sessions forever (sourceUnresolvable), pinning ~170% CPU

[https://github.com/microsoft/vscode/issues/340489](https://github.com/microsoft/vscode/issues/340489)

## Summary

Keep open: the detailed CPU and retry measurements have independent corroboration, and existing source-level parking does not establish that this reported loop is fixed. This older report should remain the investigation anchor rather than being folded into the newer corroborating issue.

## Change summary

Prevent catalog reconciliation of discovered sessions with missing source transcripts from causing sustained CPU usage and repeated database access and logging.

## Best solution

Make unresolved-session parking effective across the Agent Service listing and repair lifecycle, so unchanged missing sources cannot repeatedly trigger reconciliation. Preserve recovery when sources return and avoid deleting catalog entries merely because one provider lookup fails.
