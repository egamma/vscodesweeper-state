# Issue #336420 — Terminal command highlighting

[https://github.com/microsoft/vscode/issues/336420](https://github.com/microsoft/vscode/issues/336420)

## Summary

The visual command highlighting the reporter is describing is already user-controllable: the command guide hover highlight and the gutter/overview command decorations both have settings to turn them off, so this isn't a defect to fix — it's a preference already covered by existing settings.

## Change summary

Reporter wants VS Code to stop highlighting/decorating commands in the integrated terminal, calling the current visual treatment hard to read.

## Best solution

Point the reporter at `terminal.integrated.shellIntegration.showCommandGuide` (set to `false` to stop the on-hover command highlight) and `terminal.integrated.shellIntegration.decorationsEnabled` (set to `never` to remove the gutter/overview-ruler command markers) — between the two, all the shell-integration visual command indicators can be disabled without any code change.
