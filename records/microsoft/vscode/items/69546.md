## Summary

The requested behavior remains absent on current main, and a maintainer explicitly accepted it as contribution work. No older issue owns the same Tab-completion symptom, so this should remain open in the JSON backlog.

## Change summary

When accepting a schema-less JSON property completion with Tab, insert the property colon instead of only quoting the property name.

## Best solution

Implement and test the completion behavior in microsoft/vscode-json-languageservice, then update VS Code's bundled language-service dependency. Preserve existing schema-backed completions, which already insert a colon and an appropriate value placeholder.
