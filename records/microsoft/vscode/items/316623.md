# Issue #316623 — Hide minimap when holding hotkey for go-to-definition by mouse

[https://github.com/microsoft/vscode/issues/316623](https://github.com/microsoft/vscode/issues/316623)

## Summary

This is a valid editor interaction gap: mouseover minimap auto-hide can obstruct a Ctrl/Cmd-click target at the viewport edge. The related shortcut-customization issue does not own this modifier-aware minimap behavior, and no existing setting fully covers it.

## Change summary

Keep an auto-hidden minimap from appearing while the go-to-definition mouse modifier is held, so edge-of-editor symbols remain clickable.

## Best solution

Define modifier-aware behavior for `editor.minimap.autohide: "mouseover"` in the editor minimap implementation, preserving ordinary hover reveal while preventing it from intercepting an active go-to-definition gesture.
