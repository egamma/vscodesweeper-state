# Issue #316623 — Hide minimap when holding hotkey for go-to-definition by mouse

[https://github.com/microsoft/vscode/issues/316623](https://github.com/microsoft/vscode/issues/316623)

## Summary

A distinct feature request to suppress the minimap autohide-on-mouseover reveal while the Ctrl modifier is held (go-to-definition mode). No existing setting or behavior covers this interaction, and no duplicate was found.

## Change summary

When `editor.minimap.autohide` is `mouseover`, the minimap appears and obscures edge-of-screen symbols while holding Ctrl to click-through for go-to-definition.

## Best solution

In the minimap autohide mouseover logic (src/vs/editor/browser/viewParts/minimap/minimap.ts, CSS class `minimap-autohide-mouseover`), suppress the reveal when a go-to-definition modifier key is held. This is a small, localized UX polish to the existing autohide feature. Alternatively, consider whether the minimap should yield to any click-intent modifier.
