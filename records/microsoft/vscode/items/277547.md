# Issue #277547 — Add icons to Agents

[https://github.com/microsoft/vscode/issues/277547](https://github.com/microsoft/vscode/issues/277547)

## Summary

Keep open: this team-authored Backlog feature request defines a real responsive-chat UX improvement, and the discussion has not yet settled the public icon format for custom agent files. The newer custom-icon issue is related but cannot serve as the canonical duplicate for this re-reviewed item.

## Change summary

Show recognizable icons for built-in and custom agents in the prompt control and agent selector so agents remain distinguishable at narrow widths.

## Best solution

Design the prompt control and picker to show stable built-in agent icons and a generic fallback, then define an interoperable `icon` frontmatter contract for custom agents that works beyond VS Code's codicon UI.
