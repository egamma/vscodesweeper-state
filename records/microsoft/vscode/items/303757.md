# Issue #303757 — Copilot CLI broken in Remote SSH (Fedora 43 x86_64) due to missing pty.node

[https://github.com/microsoft/vscode/issues/303757](https://github.com/microsoft/vscode/issues/303757)

## Summary

Duplicate of https://github.com/microsoft/vscode/issues/313700, which is the tracked canonical issue (labeled `chat-ext-issue`) for the same pty.node loading failure in Remote SSH Linux environments. Both report the identical error path — `Cannot find module './prebuilds/linux-x64/pty.node'` from the Copilot SDK — in the same Remote SSH scenario.

## Change summary

Copilot CLI agent mode fails silently in Remote SSH to Linux because the native pty.node module cannot be found by the Copilot SDK.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/313700, which already carries the `chat-ext-issue` label and tracks the same pty.node remote-SSH failure. The nodePtyShim mechanism in `extensions/copilot/src/extension/chatSessions/copilotcli/node/nodePtyShim.ts` was brought back for the marketplace route (commit 17c5c32122f, April 30 2026) but may still have gaps in remote-server environments; fixes should land against the canonical issue.
