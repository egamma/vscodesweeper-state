# Issue #303757 — Copilot CLI broken in Remote SSH (Fedora 43 x86_64) due to missing pty.node

[https://github.com/microsoft/vscode/issues/303757](https://github.com/microsoft/vscode/issues/303757)

## Summary

The missing Linux `pty.node` path is fixed on current main: Copilot CLI now materializes VS Code's platform-native node-pty files before importing the SDK, so this can close as completed.

## Change summary

Copilot CLI could not send prompts from a Remote-SSH Linux workspace because its SDK package lacked `prebuilds/linux-x64/pty.node`.

## Best solution

Keep the runtime node-pty shim introduced by commit 17c5c32122f71707abd6ea0f8f3265fd5f161680 and its tests, which ensure separately installed Copilot Chat extensions receive the native binary expected by the SDK.
