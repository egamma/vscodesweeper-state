# Issue #165034 — Improve telemetry ergonomics/perf

[https://github.com/microsoft/vscode/issues/165034](https://github.com/microsoft/vscode/issues/165034)

## Summary

The telemetry ergonomics and allocation gaps remain on current main, but the desired enforcement and payload-mutation contracts were never settled. Keep this open for a focused design pass covering compile-time, CI, and runtime validation.

## Change summary

Make invalid telemetry names fail early and reduce telemetry-processing allocations by defining whether payloads may be cleansed in place.

## Best solution

Define one authoritative grammar and enforcement point for telemetry event/property names, then explicitly decide and document whether logging consumes and mutates payload objects. Validate the resulting contract with negative extraction/type fixtures and telemetry-service allocation or identity tests.
