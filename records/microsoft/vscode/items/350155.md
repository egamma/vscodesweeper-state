## Summary

The stale-environment path remains in current main: subsequent connections can bypass environment updates, while crash recovery reuses the launching connection's snapshot. Keep this core Agent Host bug open; the related credential-forwarding draft does not cover SSH-agent forwarding.

Keep agent Git credential and SSH forwarding usable after the connection that launched the shared remote agent host disconnects.
