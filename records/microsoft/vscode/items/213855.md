# Issue #213855 — recording `ctrl+alt+pgdown` key in keyboard shortcut editor yields "ctrl+alt+unknown"

[https://github.com/microsoft/vscode/issues/213855](https://github.com/microsoft/vscode/issues/213855)

## Summary

Still present on main: the keybinding recording widget shows 'unknown' for Ctrl+Alt+PageDown because the browser keyboard event likely delivers a keyCode of 0 in that modifier combination, which maps to KeyCode.Unknown and surfaces as 'unknown' in getUserSettingsLabel(). No fix commit references this issue.

## Change summary

Recording Ctrl+Alt+PageDown in the keyboard shortcuts editor displays 'ctrl+alt+unknown' instead of 'ctrl+alt+pagedown'.

## Best solution

The fix likely belongs in the keyboard event resolution path — either in extractKeyCode (src/vs/base/browser/keyboardEvent.ts) to fall back to the event's `code` property when `keyCode` is 0 but `code` is valid, or in the macLinuxKeyboardMapper's resolveKeyboardEvent to prefer the scan code mapping when keyCode comes through as Unknown but a valid code string is present.
