# Issue #121203 — Folding: sometimes can not be folded and touch registered as double click

[https://github.com/microsoft/vscode/issues/121203](https://github.com/microsoft/vscode/issues/121203)

## Summary

Keep open: the reported duplicate touch-event path remains in current source, and folding retains mouse-down state after toggling. A maintainer also confirmed the iPad reproduction in December 2024.

## Change summary

Touching a folding decoration can expand and collapse the same region during one interaction, leaving it apparently unchanged.

## Best solution

Make folding decoration activation produce one toggle per completed interaction despite the reported duplicate release sequence. Preserve desktop folding modifiers and existing editor selection and pointer-capture behavior.
