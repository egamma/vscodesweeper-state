# Issue #344156 — Universal Control: duplicate modifier keyup events cancel keyboard chords on macOS

[https://github.com/microsoft/vscode/issues/344156](https://github.com/microsoft/vscode/issues/344156)

## Summary

Duplicate modifier releases can still cancel pending keyboard chords in current main. Keep this open while the author's linked fix proposal is reviewed; their physical Universal Control reproduction and successful backport support the diagnosis.

## Change summary

Prevent duplicate modifier keyup events delivered through macOS Universal Control from cancelling multi-chord keybindings.

## Best solution

Review and, if suitable, land https://github.com/microsoft/vscode/pull/344157 so duplicate releases do not synthesize modifier double taps, while intentional double taps and ordinary chord handling remain intact.
