# Issue #290715 — Zen Mode is not using space well while center mode.

[https://github.com/microsoft/vscode/issues/290715](https://github.com/microsoft/vscode/issues/290715)

## Summary

Verified duplicate: the older open centered-layout issue covers the same observable problem—sidebars consume editor width while unused centered-layout margins remain—and explicitly includes the laptop-screen case and automatically dropping centered layout when side UI opens.

## Change summary

Make Zen Mode's centered layout use screen space more efficiently when sidebars open, with an easy way to disable centering on smaller displays.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/60900 and make centered layout account for the whole workbench so sidebars use available margins before shrinking or shifting the editor. Existing manual controls can remain while that canonical issue owns any adaptive behavior.
