- **CLI still launches the executable:** resources/win32/bin/code.cmd runs the adjacent product executable with ELECTRON_RUN_AS_NODE=1 to execute cli.js. src/vs/code/node/cli.ts removes that variable from the child environment and, on Windows, launches process.execPath. Finding code.cmd with where.exe therefore does not establish that the working launch bypasses code.exe or uses the same installation as the shortcut.

The Unix shell-resolution mechanism cannot be assumed to explain this Windows launch difference; inherited environment and installation differences remain unconfirmed possibilities.

Nothing supplied establishes that this is the failing stage in this report.
