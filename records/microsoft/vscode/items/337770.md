# Issue #337770 — Large Agent Host file responses block the UI

[https://github.com/microsoft/vscode/issues/337770](https://github.com/microsoft/vscode/issues/337770)

## Summary

Fresh, team-authored perf report with a confirmed source-level mechanism (synchronous base64 decode and log stringify-then-truncate on the main/render thread), but payload sizes and the actual fix speedup are explicitly unmeasured — real work, no reason to close.

## Change summary

Large Agent Host file responses spend hundreds of ms doing synchronous base64 decoding and JSON/log work on the render thread, freezing the UI briefly.

## Best solution

Investigate moving the decode/stringify-truncate work off the main render thread (or chunking/streaming it) in AgentHostFileSystemProvider.readFile and AhpJsonlLogger.log, guided by measured payload sizes from real sessions before committing to an approach.
