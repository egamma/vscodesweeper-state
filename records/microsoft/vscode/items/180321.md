# Issue #180321 — Webview View fails to get focus

[https://github.com/microsoft/vscode/issues/180321](https://github.com/microsoft/vscode/issues/180321)

## Summary

Still present on main: when `WebviewViewPane.focus()` is called before the webview overlay is created or fully mounted, the optional chaining (`this._webview.value?.focus()`) silently does nothing — the first 1-2 programmatic focus calls are lost.

## Change summary

Programmatic `focus()` command on a webview view silently fails during the initial activation window before the webview iframe is mounted.

## Best solution

Queue/defer the focus intent in `WebviewViewPane.focus()` when `this._webview.value` is not yet available, and replay it once the webview is created and mounted — similar to how `WebviewState.Initializing` queues messages.
