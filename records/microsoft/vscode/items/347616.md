# Issue #347616 — Please consider keeping Local harness as optional extension

[https://github.com/microsoft/vscode/issues/347616](https://github.com/microsoft/vscode/issues/347616)

## Summary

Keep open for a maintainer decision on preserving Local as a supported optional harness. The 36 upvotes demonstrate substantial demand; current selection settings and restored Ask/Plan functionality do not settle the request for availability after deprecation.

## Change summary

Preserve the Local harness beyond its announced retirement, potentially as an optional extension.
