# Issue #347616 — Please consider keeping Local harness as optional extension

[https://github.com/microsoft/vscode/issues/347616](https://github.com/microsoft/vscode/issues/347616)

## Summary

Keep open for a maintainer decision on preserving Local as an optional extension. Current harness-selection settings and restored Ask/Plan support do not satisfy continued availability after deprecation, and the related feedback issue does not meet the stronger duplicate bar.

## Change summary

Retain the Local harness as an optional VS Code extension after its planned removal.

## Best solution

Evaluate an independently installable Local harness that preserves its in-editor workflow without adding default overhead. Decide the support and extension-API boundary before committing to extraction; track individual Copilot parity gaps separately.
