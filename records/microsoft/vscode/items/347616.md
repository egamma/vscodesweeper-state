# Issue #347616 — Please consider keeping Local harness as optional extension

[https://github.com/microsoft/vscode/issues/347616](https://github.com/microsoft/vscode/issues/347616)

## Summary

Keep open for a maintainer decision on retaining Local as an optional extension. Existing harness-selection settings do not address long-term availability, and the request has substantial community support.

## Change summary

Preserve the Local harness as an optional VS Code extension after its planned removal.

## Best solution

Decide whether Local can remain a supported, opt-in extension and define its maintenance and compatibility boundaries. Track specific Copilot harness parity gaps separately without treating partial parity as fulfillment of this retention request.
