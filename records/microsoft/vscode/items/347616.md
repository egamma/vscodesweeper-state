# Issue #347616 — Please consider keeping Local harness as optional extension

[https://github.com/microsoft/vscode/issues/347616](https://github.com/microsoft/vscode/issues/347616)

## Summary

Keep open for a maintainer decision on preserving Local as an optional extension after deprecation. Current harness-selection settings and restored Ask/Plan functionality do not satisfy that long-term request, and the related newer feedback issue does not meet the re-review duplicate bar.

## Change summary

Preserve the Local harness as an optional VS Code extension rather than removing it.

## Best solution

Decide whether a separately maintained, opt-in Local harness is a supported long-term option, including its extension API requirements and maintenance ownership. Evaluate the thread's migration concerns separately; addressing individual parity gaps does not itself settle the preservation request.
