# Issue #102043 — [Request] Provide file-specific onDidChangeSemanticTokens event

[https://github.com/microsoft/vscode/issues/102043](https://github.com/microsoft/vscode/issues/102043)

## Summary

File-scoped semantic-token invalidation remains absent; the implemented caching workaround does not eliminate provider-wide refresh requests. Keep this team-authored Backlog request open: no referenced fix or eligible older canonical was found, and the related API discussion records a decision to retain global invalidation.

## Change summary

Allow semantic-token providers to invalidate individual documents without refreshing unaffected documents served by the same provider.

## Best solution

Have the API owners reconcile this efficiency request with the documented provider-wide invalidation decision in https://github.com/microsoft/vscode/issues/130486. If targeted invalidation is reconsidered, preserve existing global refresh behavior while allowing extensions to identify affected documents without requiring redundant provider calls.
