# Issue #128153 — Native Notebooks - Keyboard shortcut for navigating in/out of notebook

[https://github.com/microsoft/vscode/issues/128153](https://github.com/microsoft/vscode/issues/128153)

## Summary

Keep open: the discussion confirms that a second Escape loses the notebook cell's focus, and current action registrations retain a relevant list-clearing path. This team-authored report has no verified fixing commit or qualifying canonical duplicate; the intended second-Escape behavior still needs a maintainer decision.

## Change summary

Repeated Escape followed by Tab can lose the user's position instead of returning keyboard focus to the same notebook cell.

## Best solution

Make notebook keyboard navigation preserve a predictable return to the previously active cell. Decide whether a second Escape should retain cell focus or leave the cell while remembering where keyboard navigation should resume, without changing unrelated lists.
