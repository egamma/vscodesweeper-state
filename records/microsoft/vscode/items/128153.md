# Issue #128153 — Native Notebooks - Keyboard shortcut for navigating in/out of notebook

[https://github.com/microsoft/vscode/issues/128153](https://github.com/microsoft/vscode/issues/128153)

## Summary

Still present on main: pressing Escape twice in a notebook cell editor moves focus to the list view container (via generic list widget behavior), which is undiscoverable — no notebook-specific handling prevents the second Escape from leaving the cell context.

## Change summary

Pressing Escape twice in a notebook cell editor moves focus away from the cell to an undiscoverable list container, and Tab then lands on a different cell.

## Best solution

Add a keybinding or focus-trap that prevents the second Escape (when `notebookCellListFocused && !inputFocus`) from moving focus out of the selected cell's container — similar to the workaround in comment 4 that binds Escape to a no-op in that context. The fix belongs in `src/vs/workbench/contrib/notebook/browser/controller/editActions.ts` or as a default keybinding override.
