# Issue #328370 — Chat history items do not take the max width of the chat into account

[https://github.com/microsoft/vscode/issues/328370](https://github.com/microsoft/vscode/issues/328370)

## Summary

Current main contains a width-accounting mismatch in the Agents Window chat layout. Route this confirmed visual bug to the chat area.

## Change summary

Chat history rows are laid out without correctly accounting for the chat surface's 950px maximum content width.

## Best solution

Make `ChatWidget.layout` preserve the full Agents Window list width while sizing and centering history-item content against the 950px maximum defined in `src/vs/sessions/browser/media/style.css`.
