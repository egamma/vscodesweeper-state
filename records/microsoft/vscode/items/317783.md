# Issue #317783 — too fast scrolling when drag&drop into editor (holding shift)

[https://github.com/microsoft/vscode/issues/317783](https://github.com/microsoft/vscode/issues/317783)

## Summary

The recording and two independent reports confirm a current editor drag-and-drop autoscroll regression: scrolling begins well before the pointer reaches the editor edge and becomes especially aggressive in short editor panes. The editor owner also acknowledged that the recorded behavior is bad, so this should remain open for diagnosis and correction.

## Change summary

Dragging selected text or an Explorer item into an editor while holding Shift can trigger premature, rapidly accelerating vertical autoscroll, particularly in short or split editor panes.

## Best solution

Adjust the editor drag-and-drop autoscroll calculation so its activation zone and speed remain usable relative to the visible editor height, including short split panes, while preserving proportional acceleration when the pointer genuinely approaches or crosses an edge.
