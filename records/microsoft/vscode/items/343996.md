# Issue #343996 — Working set: Selected file row text turns white and becomes unreadable (on default theme)

[https://github.com/microsoft/vscode/issues/343996](https://github.com/microsoft/vscode/issues/343996)

## Summary

Keep open: current source forces a hover background onto selected working-set rows without changing their selection foreground, explaining the unreadable text and icons. Two open PRs explicitly reference this issue; review those candidates rather than starting another implementation.

## Change summary

Keep working-set file names, paths, and action icons readable when a selected row is hovered in the default light theme.

## Best solution

Preserve theme-consistent foreground/background pairs across working-set hover, selection, and focus states. Review the focused fix in https://github.com/microsoft/vscode/pull/344045 alongside the overlapping change in https://github.com/microsoft/vscode/pull/344133, and keep this issue open until a fix lands.
