# Issue #168431 — Progress location for comments

[https://github.com/microsoft/vscode/issues/168431](https://github.com/microsoft/vscode/issues/168431)

## Summary

Keep this API proposal open: current APIs still lack comment-local progress, and the discussion explicitly asks for progress alongside optimistic comments. The api-proposal label reserves completion and finalization decisions for the API owners.

## Change summary

Let extensions visibly indicate that a comment or comment thread is awaiting completion of an asynchronous operation.

## Best solution

Provide an API-owner-approved comment-local progress contract that preserves responsive optimistic comments while clearly distinguishing an in-flight submission from a saved comment. Keep this core API proposal separate from the GitHub Pull Requests extension's failure-handling issue.
