# Issue #168431 — Progress location for comments

[https://github.com/microsoft/vscode/issues/168431](https://github.com/microsoft/vscode/issues/168431)

## Summary

Still an open gap: the comments API has no progress-location mechanism for async comment creation. Team-authored, On Deck milestone, and the underlying need (showing progress during remote API calls) remains unaddressed on current main.

## Change summary

Add a progress indicator to the comments API so extensions can show progress while creating or submitting comments asynchronously.

## Best solution

Extend the comments API (likely in `src/vs/workbench/contrib/comments/` and a proposed API in `src/vscode-dts/`) with a progress location or an 'in-progress' state on CommentThread/Comment, letting extensions signal that a comment submission is in flight. The related GHPRI issue (vscode-pull-request-github#4291) provides a concrete use case for validation.
