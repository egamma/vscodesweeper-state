# Issue #337480 — Text Editor tab bar and inactive tab color has been messed up by latest update

[https://github.com/microsoft/vscode/issues/337480](https://github.com/microsoft/vscode/issues/337480)

## Summary

Multiple independent users (with screenshots) confirm the modern-UI editor tab bar and inactive tabs now render washed-out/low-contrast in the default Modern Dark theme; this is part of the in-flux 'modernization' rollout and the exact regressing color token/commit can't be pinned down from a shallow checkout, so it stays open pending maintainer follow-up.

## Change summary

After a recent update, the editor tab bar and inactive tab background turned a washed-out bright gray in the default dark theme, reducing readability versus the prior darker look.

## Best solution

A maintainer working on the modernization/modern-tabs rollout should compare the new modern tab color resolution (src/vs/workbench/services/themes/browser/modernTabColorCustomizations.ts and the MODERN_EDITOR_TAB_INACTIVE_BACKGROUND default in src/vs/workbench/common/theme.ts) against the pre-update tab colors and tune the default so inactive tabs keep sufficient contrast against the editor background.
