# Issue #337480 — Text Editor tab bar and inactive tab color has been messed up by latest update

[https://github.com/microsoft/vscode/issues/337480](https://github.com/microsoft/vscode/issues/337480)

## Summary

A VS Code maintainer confirmed in-thread that this was a regression from the Modern UI 'connected tabs' rework, and it was fixed by PR #337126, which restored the legacy tab colors while scoping the new connected-tab palette to the connected style; that commit is already merged into main.

## Change summary

The Modern Dark theme's inactive tab and tab-bar colors became washed-out/gray after the latest update, hurting readability, as a regression from the connected-tabs redesign.

## Best solution

Keep the shipped fix in commit ab8f31f (PR #337126, 'Editor: Refine connected tabs UI') which reintroduces per-theme classic tab colors (`editorGroupHeader.connectedTabsBackground`, `tab.inactiveForeground` contrast fix) while keeping the connected style's palette separate; no further core change needed beyond it reaching a stable release.
