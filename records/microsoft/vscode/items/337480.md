# Issue #337480 — Text Editor tab bar and inactive tab color has been messed up by latest update

[https://github.com/microsoft/vscode/issues/337480](https://github.com/microsoft/vscode/issues/337480)

## Summary

Two independent users confirm (with screenshots) that the tab bar and inactive tabs look washed-out/low-contrast on the default Dark Modern theme right after updating to 1.139.0. Source confirms `workbench.experimental.modernUI` now defaults to `true` with `modernUIEditorTabStyle` defaulting to `connected`, matching the newly-merged connected-tabs redesign (PR #335605) — a plausible, broad-impact cause, though I couldn't pin the exact contrast defect in the static theme tokens.

## Change summary

After the latest update, the editor tab bar and inactive tabs render in a washed-out, low-contrast light gray on the default Dark Modern theme, hurting readability.

## Best solution

Have the modernUI/tabs owners verify the connected-tabs contrast on the default themes against the 1.139.0 release build (not just the PR's dev-time captures) and adjust `editorGroupHeader.connectedTabsBackground`/`tab.inactiveForeground`-related computed styles if the shipped result diverges from what was validated in https://github.com/microsoft/vscode/pull/335605.

## Evidence

- **modernUI default:** src/vs/workbench/browser/workbench.contribution.ts sets `[LayoutSettings.MODERN_UI]` default to `true` and `[LayoutSettings.MODERN_UI_EDITOR_TAB_STYLE]` default to `ModernUIEditorTabStyle.Connected` — so every default-config user on 1.139.0 now gets the new connected-tab styling without opting in.
- **likely source PR:** Comment from unknownconstant points to https://github.com/microsoft/vscode/pull/335605 ('Editor: refine connected document tabs...'), merged into milestone 1.139.0, which introduced the connected-tabs visual redesign this report describes.
- **theme tokens look normal in isolation:** extensions/theme-defaults/themes/dark_modern.json and 2026-dark.json define reasonable dark values for tab.inactiveBackground/editorGroupHeader.connectedTabsBackground (e.g. #181818/#2B2B2B, #191A1B/#202122) — the washed-out look isn't from an obviously wrong static color, so the defect (if real) is likely in a computed/composited style path in src/vs/workbench/contrib/modernUI/browser/media/tabs.css rather than the theme JSON itself.
- **multiple confirmations:** Two independent reporters (raphaelsetin, plus the original author) posted screenshots showing the same washed-out tab bar on 1.139.0.
