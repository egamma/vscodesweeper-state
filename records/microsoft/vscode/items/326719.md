# Issue #326719 — Surface AH MCP disablement in a better way

[https://github.com/microsoft/vscode/issues/326719](https://github.com/microsoft/vscode/issues/326719)

## Summary

Keep open: this team-authored Backlog request identifies a real Agent Host UX gap where policy-based MCP disablement is visible only in debug logs.

## Change summary

Surface policy-disabled Agent Host MCP servers prominently in the UI and avoid describing the built-in GitHub MCP server as third-party.

## Best solution

Expose policy disablement and its reason through the Agent Host protocol, then render an actionable status in the MCP customization UI, including accurate classification for the built-in GitHub server.

- **Reason:** Clear policy state and enterprise-aware MCP messaging improve the agent experience and enterprise administration.
