# Issue #326719 — Surface AH MCP disablement in a better way

[https://github.com/microsoft/vscode/issues/326719](https://github.com/microsoft/vscode/issues/326719)

## Summary

Keep open: the originating discussion establishes a specific need to explain Agent Host account-policy MCP disablement in the UI. Current code has general MCP policy messaging, but that does not establish coverage of the runtime account-policy case; no qualifying fix or canonical duplicate was verified.

## Change summary

Clearly explain when account policy prevents an Agent Host MCP server from running, including the GitHub Enterprise server.

## Best solution

Expose the runtime's authoritative policy-blocked state in the Agent Host MCP management experience, distinguishing it from user disablement and authentication failure. Explain the restriction without implying that the user can override it or that the GitHub server is necessarily third-party.
