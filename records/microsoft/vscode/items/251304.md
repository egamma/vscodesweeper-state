# Issue #251304 — `policy.name` as a constant variable causes policy file generation to fail

[https://github.com/microsoft/vscode/issues/251304](https://github.com/microsoft/vscode/issues/251304)

## Summary

The policy-generation redesign removed the source parser that rejected constant identifiers. Current generation consumes exported runtime configuration values, so this can be closed as completed.

## Change summary

Allow policy names to reference string constants without breaking policy file generation.

## Best solution

Keep the runtime policy-data export introduced in commit d72d6a24245db6cc9d80988f7cda1305a385037c; it supports evaluated constant names without maintaining a separate TypeScript identifier resolver.
