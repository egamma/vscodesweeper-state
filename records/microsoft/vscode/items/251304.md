# Issue #251304 — `policy.name` as a constant variable causes policy file generation to fail

[https://github.com/microsoft/vscode/issues/251304](https://github.com/microsoft/vscode/issues/251304)

## Summary

The underlying problem — the policy generation script's inability to parse constant variable references — was resolved by a complete architecture change in commit d72d6a24245 (Oct 2025), which replaced the static TypeScript parser with a runtime JSON export. However, since the fix commit does not reference this issue and the author is a team member, keeping open for the author to close.

## Change summary

The build/lib/policy.ts generation script could not parse policy names stored in constant variables, requiring hardcoded string literals.

## Best solution

This is resolved: the policy generation pipeline was rewritten in https://github.com/microsoft/vscode/commit/d72d6a24245 to use a runtime JSON export (`policyData.jsonc`) instead of static TypeScript parsing, so constant references are no longer an issue. The author can close this as completed.
