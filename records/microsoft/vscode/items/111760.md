# Issue #111760 — [html] handle HTML-escaped characters in JavaScript attribute properties

[https://github.com/microsoft/vscode/issues/111760](https://github.com/microsoft/vscode/issues/111760)

## Summary

The bug remains source-reproducible on current main: HTML quote entities in JavaScript event attributes reach the TypeScript validator without decoding and produce false syntax diagnostics.

## Change summary

Accept HTML-escaped double quotes such as `&quot;` and `&#34;` inside JavaScript-valued HTML attributes.

## Best solution

Decode supported HTML quote entities in embedded JavaScript attribute regions while preserving source offsets, with regression coverage for both the generated embedded document and resulting diagnostics.
