# Issue #210560 — msCompile problem matcher does not match note: lines which are important for context

[https://github.com/microsoft/vscode/issues/210560](https://github.com/microsoft/vscode/issues/210560)

## Summary

The built-in msCompile matcher still excludes MSVC note diagnostics, dropping the application-source location needed to understand template errors. Keep this reopened issue in tasks; the defect is confirmed in current source and is not owned by the C++ extension.

## Change summary

Include MSVC note diagnostics in msCompile results so compiler errors retain navigable context pointing to the user's source.

## Best solution

The built-in msCompile matcher should expose file-and-location-bearing note diagnostics as informational problems while preserving existing error and warning matching. The supplied compiler output provides a bounded regression case for the tasks matcher suite.
