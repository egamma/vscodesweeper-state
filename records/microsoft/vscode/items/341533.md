The report is complete but not deterministically reproducible. It stays open for the Agent Host owners, mainly for the recovery and error-surfacing improvements.

## Change summary

After a long turn, the native session lock times out and the Agent Host session stays unusable, with later turns reported as modelSelectionFailed.

## Best solution

Surface the real error rather than classifying it as modelSelectionFailed (see agentSideEffects.ts, where stage 'modelSelection' maps to that error type). Pursue the lock-retention root cause with the Copilot SDK/runtime owners.
