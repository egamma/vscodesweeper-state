# Issue #334423 — Agent host: a slash command is never executed when the turn carries host context

[https://github.com/microsoft/vscode/issues/334423](https://github.com/microsoft/vscode/issues/334423)

## Summary

Traced and confirmed on current main: `resolvePromptToContentBlocks` in claudePromptResolver.ts unconditionally splits the prompt and appended context (attachments, snapshot notes, reference reminder) into multiple `text` content blocks whenever any attachment is present — including when the prompt is a slash command. This is a real, unfixed defect worth keeping open and routing to a fix.

## Change summary

A slash command typed in the agent chat silently stops being recognized by the Claude CLI whenever the turn also carries attachments/context, because the host splits the message into multiple text content blocks instead of one.

## Best solution

In `resolvePromptToContentBlocks` (src/vs/platform/agentHost/node/claude/claudePromptResolver.ts), detect when `prompt` is a slash command and merge all generated text blocks into the first block (joined with the existing separators) before returning, leaving any non-text blocks (e.g. future image blocks) untouched — matching the issue's own suggested fix and its verified reproduction table.
