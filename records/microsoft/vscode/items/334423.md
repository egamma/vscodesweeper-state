# Issue #334423 — Agent host: a slash command is never executed when the turn carries host context

[https://github.com/microsoft/vscode/issues/334423](https://github.com/microsoft/vscode/issues/334423)

## Summary

Traced on current main: `resolvePromptToContentBlocks` (src/vs/platform/agentHost/node/claude/claudePromptResolver.ts) always emits separate text blocks for feedback/simple/reference context on top of the prompt block whenever attachments are present, exactly the multi-text-block shape the issue shows breaking Claude CLI slash-command detection — a real, still-open defect worth fixing.

## Change summary

Slash commands silently stop executing (the model answers from its own knowledge instead) whenever the turn also carries attachment/context text, because the host sends the prompt as more than one text content block.

## Best solution

Merge the appended context/attachment text blocks into the first text block in resolvePromptToContentBlocks (or at the SDKUserMessage build site in claudeAgent.ts/claudeAgentSession.ts) so a turn's textual content is always a single text block, matching the working case the reporter already validated in their table.
