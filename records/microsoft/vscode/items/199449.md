# Issue #199449 — Allow cwd to be implicitly determined for terminal commit message quickfix

[https://github.com/microsoft/vscode/issues/199449](https://github.com/microsoft/vscode/issues/199449)

## Summary

Keep open: the terminal commit-message command still unconditionally asks for a workspace folder in multi-root workspaces. Shell integration now exposes working directories, but the quick-fix path does not use them, so the accepted improvement remains outstanding.

## Change summary

Infer the repository from the originating terminal command's working directory instead of showing an unnecessary workspace-folder picker.

## Best solution

Generate the commit message for the repository associated with the originating terminal command when its working directory identifies one unambiguously. Preserve folder selection when that context is unavailable or ambiguous, without changing unrelated commit-generation entry points.
