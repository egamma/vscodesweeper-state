# Issue #248032 — Python Environment setting is not showing when searched

[https://github.com/microsoft/vscode/issues/248032](https://github.com/microsoft/vscode/issues/248032)

## Summary

Still reproduces on main: machine-scoped settings are hidden from search results in User scope on remote environments due to the stricter matchesScope check. The team is actively discussing the correct UX (hide, show with warning, etc.).

## Change summary

Machine-scoped extension settings (e.g. python-envs.terminal.autoActivationType) don't appear in Settings Editor search results when in User scope on a remote/WSL environment, even though they appear in the table of contents.

## Best solution

Decide whether to show machine-scoped settings in search with a scope-mismatch indicator, hide them consistently (also from TOC), or relax the search filter. The fix lives in `settingsTreeModels.ts` matchesScope or the search filtering layer that calls it.
