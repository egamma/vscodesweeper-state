# Issue #332181 — Exclude panel from badge

[https://github.com/microsoft/vscode/issues/332181](https://github.com/microsoft/vscode/issues/332181)

## Summary

Selective exclusion of a view's badge contribution is not covered by the existing controls. Keep this request open and route it to the workbench views area for a decision on a consistent per-view control.

## Change summary

Allow users to exclude an individual view, such as Stasher, from its containing Activity Bar badge without suppressing the source-control changes count.

## Best solution

Have the workbench views owner assess a general per-view badge-contribution preference rather than a Stasher-specific exception. An extension-side option is a possible workaround, but does not provide the requested user-controlled behavior across views.
