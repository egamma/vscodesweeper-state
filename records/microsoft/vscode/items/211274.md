# Issue #211274 — Notebook editor can take a long time to open

[https://github.com/microsoft/vscode/issues/211274](https://github.com/microsoft/vscode/issues/211274)

## Summary

Team-authored intermittent notebook open performance issue — custom markdown rendering can take up to 9+ seconds. Some related perf fixes landed (webview perf mark, styles loading), but none references this issue and the intermittent nature makes it unclear whether it's fully resolved.

## Change summary

Opening a notebook editor sometimes takes up to 10 seconds due to slow custom markdown rendering in the webview.

## Best solution

Investigate the intermittent delay in the custom markdown rendering path (the `customMarkdownLoaded` perf mark in `notebookEditorWidget.ts`). The webview communication or markup cell initialization likely has a race or queuing bottleneck when multiple notebooks are opened sequentially.
