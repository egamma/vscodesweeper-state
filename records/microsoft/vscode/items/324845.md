# Issue #324845 — Fuzzy search pattern doesn't match words if it's corresponding parts start not after a delimiter/from a capital letter

[https://github.com/microsoft/vscode/issues/324845](https://github.com/microsoft/vscode/issues/324845)

## Summary

The reported filtering matches the documented default: IntelliSense requires its first match at a word start. Setting editor.suggest.matchOnWordStartOnly to false enables the requested lowercase substring matching.

## Change summary

Include git.autofetch when typing fetch in Settings JSON completions, even though the matching substring begins inside a lowercase word.

## Best solution

Keep the configurable word-start filtering behavior and explain editor.suggest.matchOnWordStartOnly: false; the fuzzy scorer already supports weak first matches.

  > Thanks for the report. IntelliSense requires the first matching character to be at a word start by default, so `fetch` matches `git.autoFetch` but not `git.autofetch`. Set `"editor.suggest.matchOnWordStartOnly": false` to include matches inside lowercase words.
