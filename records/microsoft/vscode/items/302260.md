# Issue #302260 — Browser: Favicon contrast

[https://github.com/microsoft/vscode/issues/302260](https://github.com/microsoft/vscode/issues/302260)

## Summary

Valid polish request for the integrated browser: favicons can have poor contrast when the VS Code theme differs from the system theme. A team member already triaged it to the Backlog as a feature request. No fix has landed on main.

## Change summary

Favicon icons in the integrated browser can be hard to see when the VS Code theme doesn't match the system theme, because Electron picks the favicon variant based on the system theme.

## Best solution

Use CSS media emulation on the browser WebContents to align `prefers-color-scheme` with the active VS Code theme, so sites serve the correct favicon variant. The team member noted this is costly for a minor issue, so it may be best addressed alongside other browser theming/emulation work in `src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorEmulationFeatures.ts`.
