# Issue #347005 — Dragging the main chat tab out opens the nested chat

[https://github.com/microsoft/vscode/issues/347005](https://github.com/microsoft/vscode/issues/347005)

## Summary

The current source explains the wrong-chat move: an explicitly dragged main chat is resolved as its session's selected nested chat. Keep this open for a bounded correction that preserves the dragged chat's identity.

## Change summary

Dragging an inactive main chat tab into a new window opens the selected nested chat instead.

## Best solution

Explicit chat-tab moves should open the named chat regardless of selection, while session-level opening should retain its existing selected-chat behavior.
