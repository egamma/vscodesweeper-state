[https://github.com/microsoft/vscode/issues/324574](https://github.com/microsoft/vscode/issues/324574)

## Summary

Team-authored bug report about Files tab in the Agents window detail panel not populating for folder (non-worktree) sessions. No fix referencing this issue exists on main. Keeping open for the area owner.

## Change summary

The Files tab in the Agents window detail panel shows no files for existing folder-based sessions, while worktree sessions correctly display their files.

## Best solution

Investigate why `agentHostSessionFiles.ts` / `changesView.ts` produces an empty file list for folder sessions — likely the `reduceSessionFiles` filter in `agentHostSessionFiles.ts` (line ~361) strips all edits when `folderRoots` matches the workspace root of a folder session (no worktree indirection). The fix belongs in the changes/files pipeline under `src/vs/sessions/contrib/`.
