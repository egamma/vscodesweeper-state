# Issue #345513 — Keep agent inbox stable while I'm reading

[https://github.com/microsoft/vscode/issues/345513](https://github.com/microsoft/vscode/issues/345513)

## Summary

Keep open: current Inbox ordering remains live while a user reads focused rows; only inline question controls pause list updates. The remaining work is to define reading-time stability without suppressing useful session updates.

## Change summary

Keep Inbox rows from reordering underneath the user while they are reading.

## Best solution

Give the Inbox a reading-time ordering policy that preserves the user's place while session activity continues. Agree when deferred ordering takes effect, retaining deliberate sorting and filtering.
