# Issue #332537 — Troubles installing dictation functionality manually

[https://github.com/microsoft/vscode/issues/332537](https://github.com/microsoft/vscode/issues/332537)

## Summary

Real reported friction confirmed in source (the model-picker's `.zip` extension filter combined with folder selection), and an open PR already targets exactly this issue, so it should stay open pending that PR landing rather than being closed now.

## Change summary

On networks that block automatic model download, manually installing the dictation model/runtime is confusing: the file picker doesn't accept `.zip` packages, error messaging is misleading once the model is installed but the runtime isn't, and docs don't cover the separate runtime package.

## Best solution

Land https://github.com/microsoft/vscode/pull/332998, which removes the restrictive `.zip` extension filter in `installDictationModelAction.ts` per its description ("Fixes #332537"); after that merges, consider a follow-up to improve the error message/docs for the separate Foundry Local runtime download so users aren't left needing to reverse-engineer the runtime layout as this reporter did.
