# Issue #338549 — Sandbox on Ubuntu 26 with network disabled rejects even pwd command

[https://github.com/microsoft/vscode/issues/338549](https://github.com/microsoft/vscode/issues/338549)

## Summary

Thanks for the report. The issue is team-authored and complete: with sandbox on and network disabled on Ubuntu 26.04, Bubblewrap's loopback setup (RTM_NEWADDR) fails with EPERM, so every command fails. I could not verify this without running it. A later commenter hit a related Ubuntu 26.04 sandbox failure with the Copilot harness (a missing slirp4netns), which is a different symptom. The issue should stay open.

## Change summary

On Ubuntu 26.04 with sandbox enabled and network disabled, Bubblewrap cannot configure the loopback interface (EPERM), so even ls and pwd fail.

## Best solution

Make the Linux sandbox startup handle hosts that deny loopback setup. Either avoid the failing netlink call in the no-network configuration, or surface a clear 'sandbox unavailable' message with the fix. Check the Ubuntu 26.04 AppArmor user-namespace and network restrictions.
