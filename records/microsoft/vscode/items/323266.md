# Issue #323266 — AI Chat: Add on/off toggles in the Customizations view to enable/disable each MCP server, tool, agent, skill, instruction, and plugin

[https://github.com/microsoft/vscode/issues/323266](https://github.com/microsoft/vscode/issues/323266)

## Summary

The Customizations view already has enable/disable toggles for many item types (MCP servers, tools with checkboxes, plugins with checkboxes, automations with eye/eyeClosed icons, and instructions/agents via context menu and inline hover actions). Some of the requested functionality is already shipped; the remaining gap is a visible always-on toggle control (as opposed to context menu or hover-reveal actions) for instructions and agents, plus category-level master toggles.

## Change summary

Add visible on/off toggles for every item type (MCP servers, tools, agents, skills, instructions, plugins) in the Customizations view, plus category-level master toggles.

## Best solution

The core enablement infrastructure already exists (`EnablementModel`, `enablementActions.ts`, checkboxes in tools/plugins lists, inline hover eye icons for instructions/agents). The realistic remaining work is (1) promoting the hover-only eye icon toggles for instructions and agents to always-visible inline toggles, and (2) adding per-category master toggles — both are polish improvements on an already-functional system. Route to the ai-customizations area for the team to evaluate the UX tradeoff of always-visible toggles vs. hover-reveal.
