# Issue #203329 — Multi Diff Editor: Moving the stash of one editor does not move the stash of all the other editors

[https://github.com/microsoft/vscode/issues/203329](https://github.com/microsoft/vscode/issues/203329)

## Summary

Keep open: current source still gives each embedded diff editor its own sash position, so resizing one does not align the others. This team-authored Backlog request remains a concrete multi-diff usability improvement, with no verified older canonical or fixing commit found.

## Change summary

Synchronize the original/modified split position across all editors within a multi-diff editor when any one sash is moved.

## Best solution

Provide a shared split position within each multi-diff editor, including rows materialized later through virtualization, while preserving independent behavior for ordinary diff editors. Settle whether that shared preference should survive reopening before implementation.
