# Issue #328340 — [Regression in 1.131] vscode_askQuestions auto-fills "user is not available" instead of prompting; Plan mode also auto-switches to Agent

[https://github.com/microsoft/vscode/issues/328340](https://github.com/microsoft/vscode/issues/328340)

## Summary

Keep open and route to Chat: an independent report confirms that questions are still answered automatically after about five seconds when another chat is awaiting plan review. Current source limits this response to Autopilot or `chat.autoReply`, so the reported non-Autopilot behavior indicates stale or cross-chat permission/configuration state that still needs diagnosis.

## Change summary

Interactive Chat questions can be answered as though the user were unavailable, and Plan sessions can begin implementation, without the user enabling those autonomous actions.

## Best solution

Keep question and handoff state scoped to the chat and request that initiated it: an interactive question must remain pending until answered or explicitly skipped, while automatic answers and plan-to-implementation handoffs must occur only for the applicable Autopilot or auto-reply session. Diagnose the shared state/race before deciding whether the two symptoms require separate fixes.

- **Trace:**
