# Issue #332263 — please support jump to specified folder in the explorer

[https://github.com/microsoft/vscode/issues/332263](https://github.com/microsoft/vscode/issues/332263)

## Summary

Confirmed gap in current source: Quick Open's absolute-path matching (`getAbsolutePathFileResult` in anythingQuickAccess.ts) only accepts results where `stat.isFile` is true, so pasting a folder path is silently dropped and the picker shows no matches — this is a real, narrow product gap, not a bug in existing intended behavior.

## Change summary

Pasting an absolute folder path into Quick Open ('Go to File...') should reveal/expand that folder in the Explorer, but currently shows no matching results.

## Best solution

Extend `getAbsolutePathFileResult`/`getRelativePathFileResults` in src/vs/workbench/contrib/search/browser/anythingQuickAccess.ts to also recognize directory stats and, when selected, call the existing 'reveal in explorer' behavior (e.g. the same command used by 'Reveal in Explorer View') instead of trying to open the folder as an editor.
