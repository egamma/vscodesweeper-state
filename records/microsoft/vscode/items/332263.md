# Issue #332263 — please support jump to specified folder in the explorer

[https://github.com/microsoft/vscode/issues/332263](https://github.com/microsoft/vscode/issues/332263)

## Summary

The requested folder-path navigation is still missing from Quick Open. Keep this open for feature-owner consideration: existing commands do not cover the paste-and-reveal workflow, and the closely matching reports found are closed rather than valid duplicate targets.

## Change summary

Allow pasting an absolute folder path into Quick Open to reveal that folder and its contents in the Explorer.

## Best solution

Have the Quick Open owner assess direct navigation to an existing workspace folder, preserving file-opening behavior and remote path resolution. Opening a folder as a new workspace or opening a file inside it is not equivalent to revealing the folder in the current Explorer.
