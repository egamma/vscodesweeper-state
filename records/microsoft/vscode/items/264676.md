# Issue #264676 — Should I be asked if I want to open the worktree?

[https://github.com/microsoft/vscode/issues/264676](https://github.com/microsoft/vscode/issues/264676)

## Summary

Team-authored issue (hard keep-open). The gap is confirmed on current main: `_createWorktree` in `extensions/git/src/commands.ts` ends without offering to open the new worktree. The infrastructure to open worktrees (current window / new window) already exists in the same file.

## Change summary

After creating a worktree via the quick pick flow, offer to open it in the current window, a new window, or not at all.

## Best solution

After the successful `repository.createWorktree()` call in `_createWorktree`, show a quick pick or information message offering 'Open in Current Window' / 'Open in New Window' / 'Don't Open', reusing the existing `openWorktreeInCurrentWindow` and `openWorktreeInNewWindow` methods already in `commands.ts`.
