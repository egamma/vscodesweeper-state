# Issue #264676 — Should I be asked if I want to open the worktree?

[https://github.com/microsoft/vscode/issues/264676](https://github.com/microsoft/vscode/issues/264676)

## Summary

Keep open: successful worktree creation still ends without offering to open it. The existing opening commands and conflict prompts do not cover this post-creation UX request, and no qualifying canonical or referenced fix was found.

## Change summary

After creating a worktree interactively, offer to open it in the current window, open it in a new window, or leave it unopened.

## Best solution

The built-in Git creation flow should finish with an explicit choice about opening the newly created worktree, without requiring users to discover separate SCM actions. Preserve noninteractive worktree creation behavior for API consumers.
