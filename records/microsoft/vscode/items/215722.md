# Issue #215722 — editor.action.nextMatchFindAction won't scroll to target when followed by closeFindWidget

[https://github.com/microsoft/vscode/issues/215722](https://github.com/microsoft/vscode/issues/215722)

## Summary

The requested find-next-and-close workflow is now implemented through `editor.find.closeOnResult`, which closes the widget only after navigation lands on the match and therefore avoids the original command-ordering problem.

## Change summary

A compound keybinding running Find Next followed by Close Find Widget closed before the editor scrolled to an off-screen match.

## Best solution

Use `editor.find.closeOnResult: true` with the normal `editor.action.nextMatchFindAction` keybinding; commit 22933cea7b65c18ba29aa7f52937f13b22bd2eb5 added this supported atomic behavior and shipped in 1.112.0.
