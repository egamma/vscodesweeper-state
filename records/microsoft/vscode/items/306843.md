# Issue #306843 — Improve Read Aloud by Skipping Non-Essential Content

[https://github.com/microsoft/vscode/issues/306843](https://github.com/microsoft/vscode/issues/306843)

## Summary

Keep open as a request for cleaner chat narration. Existing code-block filtering does not cover repeated tool labels or line references, and no verified open canonical owns the same observable symptom.

## Change summary

Make chat Read Aloud omit non-essential line numbers and repeated structural labels while preserving meaningful response text.

## Best solution

Provide speech-specific content selection in the chat synthesizer rather than narrating the general-purpose response representation. Establish which tool and reference details should remain audible, preserving meaningful numbers, code content when requested, and existing copy-text behavior.
