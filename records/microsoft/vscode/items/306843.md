# Issue #306843 — Improve Read Aloud by Skipping Non-Essential Content

[https://github.com/microsoft/vscode/issues/306843](https://github.com/microsoft/vscode/issues/306843)

## Summary

Keep open: Read Aloud still includes tool-invocation text, and the existing code-block filter does not cover repeated read labels or file-range metadata. No verified open canonical owns this specific request; the narration policy needs an accessibility-informed product decision.

## Change summary

Make chat Read Aloud omit repetitive structural content and line-number metadata while preserving meaningful conversational text.

## Best solution

Define a speech-specific content policy in the chat narration path that separates conversational text from repetitive tool metadata without changing copied responses or screen-reader content. Decide whether concise narration becomes the default or an optional mode.
