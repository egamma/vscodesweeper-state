# Issue #337937 — Terminal: Environment variable corruption and display overwrite when PATH contains carriage return

[https://github.com/microsoft/vscode/issues/337937](https://github.com/microsoft/vscode/issues/337937)

## Summary

Real, source-confirmed bug on main: Append/Prepend mutators concatenate onto the raw existing env var value without trimming a trailing/leading CR, corrupting PATH and its terminal display on Windows. An open PR already targets the exact fix, so this stays open for that PR to land rather than being closed now.

## Change summary

When PATH (or another env var) has a trailing carriage return, extension-driven Append/Prepend mutations concatenate right after the `\r`, corrupting the value and garbling its terminal display.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/337938, which sanitizes trailing/leading newlines before Append/Prepend in MergedEnvironmentVariableCollection.applyToProcessEnvironment.
