# Issue #247623 — preview opens in inconsistent group

[https://github.com/microsoft/vscode/issues/247623](https://github.com/microsoft/vscode/issues/247623)

## Summary

Keep open: the preview action still requests a generic side opening without anchoring it to the originating notebook, consistent with the reported placement problem. The original steps suffice to retest; the focus-sensitive UI behavior was not executed.

## Change summary

Opening another notebook output preview while the previous preview has focus places it beside that preview rather than beside the notebook.

## Best solution

Make output-preview placement consistently relative to the originating notebook, independent of which preview currently has focus. First confirm the toolbar invocation preserves preview focus and establish a regression check for the resulting editor-group placement.
