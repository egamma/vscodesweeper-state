# Issue #247623 — preview opens in inconsistent group

[https://github.com/microsoft/vscode/issues/247623](https://github.com/microsoft/vscode/issues/247623)

## Summary

Still open on main: the output preview open action in cellOutputActions.ts (line 176) calls `openerService.open()` without specifying a target editor group, so when the previously opened preview has focus, the next preview opens beside it rather than beside the notebook. No fix referencing this issue has landed.

## Change summary

Opening a second notebook output in preview opens it beside the first preview editor instead of beside the notebook.

## Best solution

The `OpenCellOutputInEditorAction` in `src/vs/workbench/contrib/notebook/browser/controller/cellOutputActions.ts` should resolve the notebook's editor group and pass it (or `SIDE_GROUP` relative to the notebook) when opening the output preview URI, so the preview always opens beside the notebook regardless of which editor currently has focus.
