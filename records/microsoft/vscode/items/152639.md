# Issue #152639 — Duplicate entries in edit breakpoint and related submenus

[https://github.com/microsoft/vscode/issues/152639](https://github.com/microsoft/vscode/issues/152639)

## Summary

The bug was reproduced and diagnosed by maintainers, and current source still has inconsistent duplicate checks between requested and debugger-resolved breakpoint positions. No fixing commit or open canonical issue was found, so the backlog item remains necessary.

## Change summary

Adding an inline breakpoint where an existing line breakpoint resolved creates two breakpoints at the same displayed column and duplicate submenu entries.

## Best solution

Reproduce the reported line-breakpoint-to-inline-breakpoint transition against current main, then make breakpoint insertion consistently recognize an existing breakpoint at the displayed resolved position without changing how genuinely distinct breakpoint locations are represented.
