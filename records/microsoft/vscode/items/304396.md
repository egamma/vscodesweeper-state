# Issue #304396 — Accessible editor does not announce initial value unless focused

[https://github.com/microsoft/vscode/issues/304396](https://github.com/microsoft/vscode/issues/304396)

## Summary

The reported focus-dependent content omission remains in current main: both native screen-reader content implementations return before populating an unfocused editor's textbox. Keep this open; the supplied sample is sufficient, and the correction is bounded to native editor accessibility.

## Change summary

Expose the editor's initial content and subsequent model value changes to screen-reader browsing without requiring editor focus.

## Best solution

Keep the native editor's accessible textbox content accurate while unfocused, preserving paged rendering and focus-dependent selection handling. Cover both simple and rich screen-reader content without moving focus or disturbing another control's selection.
