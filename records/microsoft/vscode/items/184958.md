# Issue #184958 — Fix a browser sniff for Firefox support of async clipboard

[https://github.com/microsoft/vscode/issues/184958](https://github.com/microsoft/vscode/issues/184958)

## Summary

The obsolete Firefox clipboard gate remains on current main and can suppress the editor's Paste command despite async clipboard support. Keep this accepted bug open; the linked fork PR is explicitly an experiment, not a landed upstream fix.

## Change summary

Detect async clipboard read support independently of Firefox's legacy execCommand paste support.

## Best solution

Make editor Paste availability reflect the browser's actual clipboard capabilities while preserving legacy fallback behavior. Review the linked experimental patch for that full requirement before considering an upstream contribution.
