# Issue #306686 — No way to see model incident message in model picker

[https://github.com/microsoft/vscode/issues/306686](https://github.com/microsoft/vscode/issues/306686)

## Summary

Still unfixed on main: model incident/degradation messages have no UI surface in the current model picker after the hover was removed. The team discussed a solution (use the tips/chat upgrade widget above chat input) but it hasn't been implemented yet.

## Change summary

After the model picker hover was removed, there is no way for users to see CAPI model incident/degradation messages.

## Best solution

Implement the agreed-upon approach from the discussion: show the degradation message in the tips/chat upgrade widget above the chat input when the degraded model is selected, making it non-dismissible. This belongs in `src/vs/workbench/contrib/chat/browser/widget/input/chatModelPicker.ts` and the chat input part.
