# Issue #293275 — Skills: Dynamic context injection (shell command preprocessing in prompt files)

[https://github.com/microsoft/vscode/issues/293275](https://github.com/microsoft/vscode/issues/293275)

## Summary

Valid feature request from a team member, tracked internally. Dynamic context injection via shell command preprocessing in prompt files is not yet implemented on main — the prompt syntax infrastructure exists but has no shell-execution preprocessing. Keeping open.

## Change summary

Allow prompt files and skills to run shell commands at invocation time and inject their stdout into the prompt before it reaches the model.

## Best solution

Implement shell command preprocessing (e.g. `` !`command` `` syntax) in the prompt syntax layer under `src/vs/workbench/contrib/chat/common/promptSyntax/`, gated by workspace trust, with timeout and error surfacing. The hooks infrastructure (`hookActions.ts`, `hookUtils.ts`) may offer reusable shell-execution patterns but the preprocessing itself is a new capability in the prompt rendering pipeline.
