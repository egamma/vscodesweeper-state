# Issue #140868 — [linked editing] stops when tag name gets empty and end tag is on same line

[https://github.com/microsoft/vscode/issues/140868](https://github.com/microsoft/vscode/issues/140868)

## Summary

The attribute-dependent empty-tag failure remains present on current main and has an active fix in https://github.com/microsoft/vscode/pull/310383. This re-reviewed issue predates the newer report that the PR references, so it should remain open rather than being closed as a duplicate of that younger issue.

## Change summary

Linked editing loses the opening/closing tag association after an attributed opening tag's name becomes empty, so retyping no longer updates the closing tag.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/310383, whose regression tests and fix directly cover deleting and retyping an attributed HTML tag name; associate this older report with that fix before closing it as completed.
