# Issue #304197 — Implementation leaks when using 'Show and Focus Terminal'

[https://github.com/microsoft/vscode/issues/304197](https://github.com/microsoft/vscode/issues/304197)

## Summary

Team-authored issue flagging a real design problem in the agent sandbox terminal integration — sandbox implementation details leak to the user when 'Show and Focus Terminal' is used. Assigned to alexdima and dileepyavan, actively under discussion with a potential approach noted. Should stay open.

## Change summary

Using 'Show and Focus Terminal' during sandboxed agent execution reveals sandbox implementation details (e.g. wrapping commands) that should be hidden from the user.

## Best solution

Resolve the design tension between using a real terminal for `run_in_terminal` commands and hiding sandbox internals — either by switching to `bash -c` wrapping (as alexdima suggested) or by filtering/masking the sandbox scaffolding in the terminal UI. The fix likely touches `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/runInTerminalTool.ts` and related sandbox forwarding code.
