# Issue #309028 — Allow clearing the undo/redo stack of a custom editor

[https://github.com/microsoft/vscode/issues/309028](https://github.com/microsoft/vscode/issues/309028)

## Summary

Valid feature request for a missing custom-editor API surface — no existing mechanism to clear the undo/redo stack. The predecessor issue #296528 was closed accidentally by a mismatched commit ref. Currently in the Backlog Candidates community process with 15/20 upvotes; should remain open.

## Change summary

Allow custom editor extensions to programmatically clear the VS Code undo/redo stack when the editor's internal state no longer supports those operations.

## Best solution

Add a new event (e.g. `onDidEditStackClear`) or method to the `CustomEditorProvider` API surface in `src/vscode-dts/vscode.d.ts` that lets extensions signal VS Code to discard accumulated undo/redo entries. The implementation would live in `src/vs/workbench/api/common/extHostCustomEditors.ts` and the corresponding main-thread custom-editor handling. This is a real API gap — no workaround exists today.
