# Issue #339901 — Compare button behaves weirdly in the context of the model picker

[https://github.com/microsoft/vscode/issues/339901](https://github.com/microsoft/vscode/issues/339901)

## Summary

The reported inconsistency remains in current source: Compare is an icon-only workflow toggle beside provider tabs, and activating it preserves the selected provider. Keep this team-authored UX issue open; neither a qualifying fix nor an older duplicate with the same observable symptom was established.

## Change summary

Make comparison setup clearly distinguishable from provider selection, with an understandable label and navigation state.

## Best solution

Give comparison setup an explicitly identified workflow entry rather than an affordance that looks like another provider tab. Settle whether setup remains in the picker or moves into guided chat, coordinating with the existing comparison-redesign work and active polish PR.
