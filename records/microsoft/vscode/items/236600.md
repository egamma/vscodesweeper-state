# Issue #236600 — Support collapsing/expanding notebook cell comments

[https://github.com/microsoft/vscode/issues/236600](https://github.com/microsoft/vscode/issues/236600)

## Summary

The capability remains absent on current main: notebook comment collapse delegates to a no-op, while no notebook affordance exists for restoring a collapsed thread. The issue is correctly routed and should remain open for UX design and implementation.

## Change summary
