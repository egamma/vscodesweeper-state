# Issue #184638 — Git - Diff decorations not working

[https://github.com/microsoft/vscode/issues/184638](https://github.com/microsoft/vscode/issues/184638)

## Summary

Keep open: the thread supplies a concrete reproduction involving a symlinked directory inside the repository, and current source still uses the alias path to retrieve the Git baseline. Repository-root symlink improvements do not establish that this distinct case is fixed.

## Change summary

Git diff gutter decorations are missing when a tracked file is edited through an internal symlinked directory.

## Best solution

Make Git quick diff resolve the tracked target correctly for files opened through an internal directory symlink, while preserving the intentional treatment of Git-tracked symlink entries. Use the supplied directory layout to establish regression coverage before broadening the work to blame or history.

- **Behavior:**

Direct Git-tracked symlink entries, ignored files, and untracked files must retain their existing semantics.
- **Trace:**

  > GitQuickDiffProvider.provideOriginalResource in extensions/git/src/quickDiffProvider.ts creates a baseline URI from the unresolved editor path; toGitUri in extensions/git/src/uri.ts preserves that path.
