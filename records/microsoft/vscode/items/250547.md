# Issue #250547 — MCP Oauth: Default auth strategy does not redirect on Ubuntu 22.04

[https://github.com/microsoft/vscode/issues/250547](https://github.com/microsoft/vscode/issues/250547)

## Summary

Keep open: the default authentication flow now uses loopback, but that change bypasses rather than establishes a fix for the Ubuntu protocol-handler failure. The original VM/install details and recorded flow suffice for a targeted retest; the September 2026 report also warrants checking the remaining redirect behavior before closing.

## Change summary

MCP OAuth using the default redirect strategy failed to return to Insiders on an Ubuntu 22.04 VM installed from the website's Debian package, while loopback authentication worked.

## Best solution

Retest the recorded Ubuntu flow and distinguish successful token acquisition from browser-to-Insiders handoff. Preserve loopback as the reliable local default, and establish whether a remaining Linux protocol-handler or callback-registration defect needs correction.
