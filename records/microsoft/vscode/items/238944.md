# Issue #238944 — Should quick open remember it was sticked to a window side?

[https://github.com/microsoft/vscode/issues/238944](https://github.com/microsoft/vscode/issues/238944)

## Summary

Quick open still restores proportional coordinates rather than its attachment to a window edge, and restoration can introduce horizontal drift. Keep this issue as the canonical report for edge-position persistence; the related resize report was explicitly consolidated here.

## Change summary

Preserve quick open's edge or corner placement when reopening it or restoring it in a differently sized window.

## Best solution

Make quick input positioning retain edge attachment across reopening, resizing, and restoration in another window size, without changing ordinary free positioning or the existing top and center presets.
