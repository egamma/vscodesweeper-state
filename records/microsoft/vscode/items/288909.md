# Issue #288909 — Quick chat overflows actions out of view when model has a long name

[https://github.com/microsoft/vscode/issues/288909](https://github.com/microsoft/vscode/issues/288909)

## Summary

Still reproduces on main: the quick chat widget does not constrain the model picker label width, so long model names push toolbar actions out of view. No fix commit references this issue.

## Change summary

Quick chat toolbar actions overflow out of view when the selected model has a long name.

## Best solution

Add overflow/text-overflow constraints on the model picker label within the quick chat's toolbar layout (likely in the chat input CSS or the chatInputPart layout logic) so the model name truncates with ellipsis rather than pushing actions off-screen.
