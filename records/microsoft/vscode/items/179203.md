# Issue #179203 — vscode.workspace.findFiles returns nothing if executed early in extension startup

[https://github.com/microsoft/vscode/issues/179203](https://github.com/microsoft/vscode/issues/179203)

## Change summary

Early calls to workspace.findFiles intermittently return no matches, preventing extensions from discovering tests or projects until the window is reloaded.

## Best solution

Make startup-time workspace.findFiles searches reliably discover existing matching files without requiring extension-side retries. Reproduce the selfhost test-provider reload scenario and identify where workspace, filesystem, or search-provider readiness causes the empty result before choosing a bounded fix.
