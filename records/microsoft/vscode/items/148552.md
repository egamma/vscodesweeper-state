# Issue #148552 — Show bracket pair colorization enabled in token inspector

[https://github.com/microsoft/vscode/issues/148552](https://github.com/microsoft/vscode/issues/148552)

## Summary

The token inspector still does not explain bracket-pair colorization, and this issue is already the canonical request for that gap. Keep the accepted, team-authored Backlog item open; disabling or customizing bracket colors does not satisfy the requested notice.

## Change summary

Show a notice when the inspected token is colored by bracket-pair colorization rather than its token theme rules.

Make the existing token inspector identify bracket-pair colorization affecting the inspected position while preserving its TextMate and semantic-token diagnostics. Keep this issue as the canonical request rather than changing bracket-coloring behavior.
