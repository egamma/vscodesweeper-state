# Issue #173306 — Git - Close repository (Git) doesn't forget openened parent repository

[https://github.com/microsoft/vscode/issues/173306](https://github.com/microsoft/vscode/issues/173306)

## Summary

The reported reopening after a reload is addressed by persisted closed-repository state. Built-in commands also let users reopen closed repositories or select discovered parent repositories without manually locating their folders.

## Change summary

Closing an accidentally opened parent Git repository should prevent automatic reopening in the next session and provide an easy way to reopen it deliberately.
