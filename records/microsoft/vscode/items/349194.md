# Issue #349194 — my code is erased when i save it

[https://github.com/microsoft/vscode/issues/349194](https://github.com/microsoft/vscode/issues/349194)

## Summary

The reported import removal matches the installed Go extension's documented default behavior: organizing imports on save removes unused imports. This is extension-provided behavior, not evidence that VS Code's file-saving code erases arbitrary code.

## Change summary

Preserve the image/color import when saving a Go source file.

## Best solution

Explain Go's automatic unused-import cleanup and how to disable source.organizeImports for Go files. Any removal of an import that is actually used should be investigated in the Go extension's tracker with a complete sample.

- **Proposed comment:**

  > Thanks for the report. The Go extension automatically organizes imports on save, including removing imports that are not used in the file. To keep unused imports while editing, set `"[go]": { "editor.codeActionsOnSave": { "source.organizeImports": "never" } }` in your settings.
  > 
  > If `image/color` is used in the file and still gets removed, please report that at https://github.com/golang/vscode-go/issues with a complete example.
