# Issue #331393 — Disable the pet’s peeking animation

[https://github.com/microsoft/vscode/issues/331393](https://github.com/microsoft/vscode/issues/331393)

## Summary

An existing setting already covers this: `workbench.reduceMotion` (set to "on") makes the chat pet render with static sprites instead of its looping animations, which removes the persistent peeking motion described here.

## Change summary

Requests a way to reduce or disable the VS Code pet's repeated peeking-up-and-down motion above the chat input bar.

## Best solution

Point the reporter at `workbench.reduceMotion: "on"` (or the OS-level reduced-motion setting via `"auto"`), which chatPetWidget.ts already honors to swap animated sprites for static ones; the pet can also be turned off entirely via its enable/disable toggle if no motion at all is preferred.
