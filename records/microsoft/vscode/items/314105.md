# Issue #314105 — Update button shows up a second too late on new windows

[https://github.com/microsoft/vscode/issues/314105](https://github.com/microsoft/vscode/issues/314105)

## Summary

The accidental-click problem is fixed on main: the dynamically appearing Update button was moved out of the center-adjacent title-bar area to a dedicated rightmost toolbar.

## Change summary

Prevent a delayed Update button from appearing beneath a title-bar double-click and unexpectedly restarting all VS Code windows.

## Best solution

Keep the placement introduced by https://github.com/microsoft/vscode/pull/329239, which moves the Update button away from the draggable title area; users who do not want the indicator can also disable `update.titleBar`.
