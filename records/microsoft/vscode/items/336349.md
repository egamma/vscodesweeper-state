# Issue #336349 — Agent Host sub-agent completion triggers premature native notification on Windows

[https://github.com/microsoft/vscode/issues/336349](https://github.com/microsoft/vscode/issues/336349)

## Summary

Keep open: a team-authored report provides a concrete Windows reproduction showing that sub-agent completion is incorrectly surfaced as completion of the user-facing parent turn. No verified duplicate, merged fix, or open fixing PR is present in the supplied record.

## Change summary

Native completion notifications fire when Agent Host sub-agents finish, even while their parent turn remains active.

## Best solution

Tie native completion notification eligibility to the user-facing parent turn or session lifecycle, while preserving notifications when that parent finishes or requires user attention.
