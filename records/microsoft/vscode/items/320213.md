# Issue #320213 — Allow hiding upgrade-only Copilot models from the model picker

[https://github.com/microsoft/vscode/issues/320213](https://github.com/microsoft/vscode/issues/320213)

## Summary

Keep open as the canonical Backlog Candidates request while community voting remains active. Current main still presents upgrade-only featured models outside the existing model-visibility controls.

## Change summary

Allow users to hide upgrade-only or otherwise unavailable Copilot models from the model picker.

## Best solution

Expose unavailable featured models in Chat: Manage Language Models and persist their visibility using the existing hidden-model mechanism, so users can remove upgrade entries without disabling usable models.

## Vision fit

- **Fit:** aligned
- **Reason:** Extending the existing model-management controls reduces noise in a central AI workflow without adding a separate UI surface.
- **Evidence:** This supports the public value of simple, uniform UI interactions and aligns with current agent-experience priorities.
