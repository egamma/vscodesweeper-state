# Issue #308639 — Copilot Chat fails on macOS arm64 with Electron fetcher: “Cannot convert argument to a ByteString … char 65279 (U+FEFF)” (regression between 1.110.1 and 1.115.0)

[https://github.com/microsoft/vscode/issues/308639](https://github.com/microsoft/vscode/issues/308639)

## Summary

This is a duplicate of #315612, which identified the root cause — a UTF-8 BOM (U+FEFF) in `telemetry.devDeviceId` being passed as an HTTP header value, rejected by undici's ByteString converter. Fixed in commit 15c518a9b and shipped in VS Code 1.121.0.

## Change summary

Copilot Chat fails with ByteString error when `telemetry.devDeviceId` in global storage contains a BOM character (U+FEFF), causing all fetch requests to fail via Electron's undici layer.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/315612, which was the canonical issue. The fix (stripping BOM from device ID in `src/vs/base/node/id.ts` and `src/vs/platform/telemetry/node/telemetryUtils.ts`) shipped in 1.121.0. Users on older builds should update; users whose storage is already corrupted can manually remove the BOM from `storage.json`.
