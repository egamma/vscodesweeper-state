# Issue #308639 — Copilot Chat fails on macOS arm64 with Electron fetcher: “Cannot convert argument to a ByteString … char 65279 (U+FEFF)” (regression between 1.110.1 and 1.115.0)

[https://github.com/microsoft/vscode/issues/308639](https://github.com/microsoft/vscode/issues/308639)

## Summary

Already fixed on main and shipped: the root cause was a UTF-8 BOM (U+FEFF) in the telemetry device ID being passed as an HTTP header, which undici's ByteString converter rejected. Commit 15c518a9 strips the BOM from the device ID, resolving the issue. Shipped in 1.121.0.

## Change summary

Copilot Chat fails with a ByteString error because the telemetry device ID contains a UTF-8 BOM character (U+FEFF) that exceeds the ByteString limit of 255.

## Best solution

Keep the shipped fix in commit 15c518a9b04bd5e376279cd3daa6127fed9a3dc0 (strips UTF-8 BOM from device ID). No further change needed — updating to VS Code 1.121.0+ resolves the issue.
