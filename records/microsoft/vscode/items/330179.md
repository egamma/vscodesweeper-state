# Issue #330179 — The completion for skills and the like in Chat Input of Agents Window seems to have a zordering issue

[https://github.com/microsoft/vscode/issues/330179](https://github.com/microsoft/vscode/issues/330179)

## Summary

Fresh, precisely self-diagnosed bug: the Agents window's Aquarium stylesheet unconditionally sets `position: relative; z-index: 1` on `.part.sessionspart > .title/.content`, creating a stacking context that traps the chat completion widget beneath the bottom panel's labels/sash even when the aquarium is inactive. Confirmed in source and via runtime `elementsFromPoint` per the reporter.

## Change summary

Completion suggestions (skills, slash commands, etc.) in the Agents window chat input render underneath the bottom panel's tab labels and the split-view resize sash.

## Best solution

Scope the `position: relative; z-index: 1` rule on `.part.sessionspart > .title/.content` in aquarium.css to only apply when `.aquarium-active` is present (the class is already toggled in aquariumOverlay.ts), so the stacking context is only created while the aquarium decoration is actually rendering.
