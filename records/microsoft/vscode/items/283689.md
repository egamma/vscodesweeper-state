# Issue #283689 — Problems -> View as Table shows `-` for Code when it exists in Tree view

[https://github.com/microsoft/vscode/issues/283689](https://github.com/microsoft/vscode/issues/283689)

## Summary

The defect is directly reproducible from current source, and open PR https://github.com/microsoft/vscode/pull/335209 provides a focused fix with regression coverage. Keep the issue open until that PR is reviewed and merged or otherwise resolved.

## Change summary

The Problems table displays `-` instead of a diagnostic code whenever the diagnostic has a code but no source.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/335209, which makes the table renderer handle diagnostic codes independently of the optional source and tests both plain and linked codes.
