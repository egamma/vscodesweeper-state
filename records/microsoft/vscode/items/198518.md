# Issue #198518 — Cannot create new profile via copying default one

[https://github.com/microsoft/vscode/issues/198518](https://github.com/microsoft/vscode/issues/198518)

## Summary

The original remote-window bug remains present on current main: copying a profile's extensions unconditionally throws `Not Supported` whenever a remote extension-management server exists. Multiple recent WSL and SSH reports confirm the same extension-copy trigger, so this canonical issue should remain open for a core fix.

## Change summary

Creating a profile by copying the Default profile fails in remote windows when extension copying is selected.

## Best solution

Support profile-extension copying across the local and remote extension-management servers associated with a remote window, preserving existing local-only and web behavior. Creating or duplicating a profile from Default should copy the appropriate local and remote extensions without requiring export/import or disabling the Extensions resource.
