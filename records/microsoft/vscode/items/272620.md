# Issue #272620 — CLI sessions are sorted by creation time instead of last update time

[https://github.com/microsoft/vscode/issues/272620](https://github.com/microsoft/vscode/issues/272620)

## Summary

Still reproduces on main: CLI session timing is never refreshed when new activity occurs in an existing session, so sorted-by-updated lists retain the original position.

## Change summary

After sending a message in an old CLI session, the session does not move to the top of the sessions list because its timing is never updated with the current request time.

## Best solution

In `constructSessionItemFromWrappedSession` in `copilotcliSessionService.ts`, update the timing's `endTime`/`lastRequestEnded` to `Date.now()` when the session has active or recently-completed requests, rather than always reusing the cached timing from initial creation.
