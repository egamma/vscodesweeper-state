# Issue #132539 — Keybinding when clause has context for extension is enabled/installed

[https://github.com/microsoft/vscode/issues/132539](https://github.com/microsoft/vscode/issues/132539)

## Summary

Implemented and shipped in VS Code 1.131.0: keybindings can now test whether an extension is installed and enabled using `extensionEnabled:<lowercased extension id>`.

## Change summary

Allow a keybinding when-clause to apply only while its corresponding extension is installed and enabled.

## Best solution

Use the shipped `extensionEnabled:<lowercased extension id>` context key to guard extension-specific keybindings, preserving the default binding while that extension is unavailable.
