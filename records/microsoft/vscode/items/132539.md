## Summary

The requested extension-enabled context now exists on main as extensionEnabled:<lowercased extension id>. Propose closing as completed: this lets the reporter gate the custom Enter binding without requiring cooperation from rust-analyzer.

## Change summary

Allow keybinding when clauses to check whether an extension is installed and enabled, preventing unavailable extension commands from intercepting normal editor input.
