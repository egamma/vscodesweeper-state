# Issue #176983 — WorkspaceEdits with "isRefactoring: false" metadata show in "Refactor Preview" pane

[https://github.com/microsoft/vscode/issues/176983](https://github.com/microsoft/vscode/issues/176983)

## Summary

The naming mismatch remains in current source: non-refactoring edits requiring confirmation still open the statically named Refactor Preview. Keep this open for a terminology decision and clarification of what isRefactoring controls.

## Change summary

Use appropriate preview terminology for non-refactoring workspace edits and clarify the isRefactoring metadata documentation.

## Best solution

Make the bulk-edit preview terminology accurately cover non-refactoring changes while preserving confirmation behavior. Decide whether the shared preview should have a neutral name universally or distinguish refactoring sessions, and document the metadata's actual effect.
