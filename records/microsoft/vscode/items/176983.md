# Issue #176983 — WorkspaceEdits with "isRefactoring: false" metadata show in "Refactor Preview" pane

[https://github.com/microsoft/vscode/issues/176983](https://github.com/microsoft/vscode/issues/176983)

## Summary

Still valid on current main: the bulk-edit preview pane is hardcoded as "Refactor Preview" regardless of whether the edit's `isRefactoring` metadata is false. The label should be generic or conditional.

## Change summary

WorkspaceEdits with `isRefactoring: false` still display in a pane titled "Refactor Preview", which is confusing for non-refactoring edits.

## Best solution

Make the bulk-edit preview pane title dynamic — use "Refactor Preview" only when `isRefactoring` is true, and a generic label like "Edit Preview" otherwise. The hardcoded string is in `src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts` (line 354) and the view/command registrations in `bulkEdit.contribution.ts`. The `isRefactoring` flag would need to be threaded from `mainThreadBulkEdits.ts` through to the pane.
