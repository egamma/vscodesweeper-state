## Summary

Keep open: the report provides sufficient steps to retest mouse access to terminal status actions. Current source already anchors the hover to the tab entry, so the reported premature dismissal needs runtime diagnosis rather than a speculative close.

## Change summary

Terminal status hover actions become unreachable when moving from the right-side warning badge toward the hover beside the vertical tab list.

## Best solution
