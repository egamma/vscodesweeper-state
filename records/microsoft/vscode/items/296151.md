# Issue #296151 — [Bug] “Word wrap” lacks `overflow-wrap: break-word`, for ligatures whose widths exceed that of the viewport.

[https://github.com/microsoft/vscode/issues/296151](https://github.com/microsoft/vscode/issues/296151)

## Summary

The wrapping defect remains on current main, but an open PR already references and targets it. Keep the issue open while that implementation is reviewed and validated.

## Change summary

Word wrapping should break a ligature wider than the editor viewport instead of allowing horizontal overflow.

## Best solution

Review and validate https://github.com/microsoft/vscode/pull/309258, including normal text and CJK wrapping behavior, then land it if the broader `word-break: break-all` semantics are acceptable.

## Evidence
