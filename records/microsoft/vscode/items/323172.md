The report describes a BYOK custom endpoint reasoning model (Qwen3-VL-235B) that sends `delta.reasoning` chunks but fails to produce usable output. However, without executing the code, it is unclear whether the full end-to-end flow works correctly for this model — the user sees thinking content but an error in the final response, and the smaller Qwen model (which does not use `delta.reasoning`) works fine.
