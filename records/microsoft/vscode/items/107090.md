# Issue #107090 — Add selection to next Find match does not work with Regex Find Mode

[https://github.com/microsoft/vscode/issues/107090](https://github.com/microsoft/vscode/issues/107090)

## Summary

Confirmed still broken on main: MultiCursorSession never stores or passes isRegex from the find state, so Ctrl+D always searches with isRegex=false. Multiple community PRs are open attempting the fix.

## Change summary

Ctrl+D (addSelectionToNextFindMatch) ignores regex mode in the find widget, always searching with isRegex=false.

## Best solution

Accept and merge one of the open community PRs (e.g. https://github.com/microsoft/vscode/pull/326936 or https://github.com/microsoft/vscode/pull/322873). The fix is small: add an `isRegex` field to `MultiCursorSession`, populate it from `findState.isRegex` in the `create` factory, and pass it through in `_getNextMatch()` and `_getPreviousMatch()` instead of the hardcoded `false`. The `selectAll` method already handles regex correctly and serves as the pattern.
