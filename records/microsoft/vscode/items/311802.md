# Issue #311802 — Start implementation posts into current Plan session instead of handing off to implementation

[https://github.com/microsoft/vscode/issues/311802](https://github.com/microsoft/vscode/issues/311802)

## Summary

The Plan-to-implementation handoff remains broken in recent Insiders builds despite an earlier merged race-condition fix. Multiple users confirm that Start Implementation leaves the conversation under Plan-only restrictions, so this needs further diagnosis rather than closure.

## Change summary

Start Implementation must enter an implementation-capable agent while preserving the approved plan and conversation context.

## Best solution

Trace the Plan handoff path after the mode-switch race fix and make the transition complete before the implementation message is dispatched, preserving or explicitly transferring the approved plan. Add coverage for the affected provider/model path and for retained plan context.
