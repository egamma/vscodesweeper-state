# Issue #33752 — Create an option to position the intellisense parameter info top or bottom.

[https://github.com/microsoft/vscode/issues/33752](https://github.com/microsoft/vscode/issues/33752)

## Summary

The requested placement option remains absent on current main, and this Backlog feature request has strong community support with 267 upvotes. It should remain open as the canonical request for configurable top-or-bottom parameter-hint placement.

## Change summary

Allow users to choose whether parameter hints appear above or below the cursor.

## Best solution

Decide how parameter hints should coordinate with the suggest widget, then expose a placement preference through `IEditorParameterHintOptions` and apply it in `ParameterHintsWidget.getPosition()`. Keep the separate docked-panel design discussion in https://github.com/microsoft/vscode/issues/149270.
