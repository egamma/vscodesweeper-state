# Issue #33752 — Create an option to position the intellisense parameter info top or bottom.

[https://github.com/microsoft/vscode/issues/33752](https://github.com/microsoft/vscode/issues/33752)

## Summary

Keep open: current parameter hints still hard-code an above-first placement, with no user-selectable positioning option. This accepted Backlog request has 267 upvotes; hover positioning and docked-documentation workarounds do not satisfy its central ask.

## Change summary

Allow users to choose whether parameter information appears above or below the cursor without disabling signature help.

## Best solution

Provide a parameter-hints placement preference in the editor configuration, retaining the existing default and signature-help behavior. Establish what happens when the preferred side lacks space; keep docked panels and completion-documentation positioning outside this request.
