# Issue #87741 — Auto save & new line prevents undo from working

[https://github.com/microsoft/vscode/issues/87741](https://github.com/microsoft/vscode/issues/87741)

## Summary

Still reproduces on main: FinalNewLineParticipant creates a separate undo entry via editor.executeEdits(), so with auto-save the inserted newline is the top undo action and gets re-added immediately after undo, trapping the user in a loop. The fix for #90100 addressed format-on-save undo stops but did not touch this save participant.

## Change summary

With `files.insertFinalNewline` and `files.autoSave: afterDelay`, undo removes the auto-inserted newline instead of the user's edit, and auto-save immediately re-inserts it, making undo effectively broken.

## Best solution

Align FinalNewLineParticipant with TrimWhitespaceParticipant and TrimFinalNewLinesParticipant by using model.pushEditOperations() directly (preserving selections) instead of editor.executeEdits(), so the save-participant edit merges with the user's edit rather than creating a separate undo entry. The fix is localized to doInsertFinalNewLine in src/vs/workbench/contrib/codeEditor/browser/saveParticipants.ts.
