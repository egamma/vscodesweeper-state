# Issue #87741 — Auto save & new line prevents undo from working

[https://github.com/microsoft/vscode/issues/87741](https://github.com/microsoft/vscode/issues/87741)

## Summary

The bug remains visible in current source: the final-newline save participant records its automatic edit in the model's undo stack, and the existing tests do not cover undoing the preceding user edit under auto-save.

## Change summary

With auto-save and `files.insertFinalNewline` enabled, the automatically inserted newline prevents Undo from reaching the user's preceding edit.

## Best solution

Make final-newline insertion preserve the preceding user edit's expected undo behavior while retaining the configured newline on save, and cover the auto-save/undo cycle in the save-participant tests.
