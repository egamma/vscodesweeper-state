# Issue #325174 — Agents window says no model available when a workspace is not selected

[https://github.com/microsoft/vscode/issues/325174](https://github.com/microsoft/vscode/issues/325174)

## Summary

Still open on main — the model picker shows "No models available" when the Agents window is opened in a transient (no-workspace) session because no provider/agent harness is active yet, but the picker renders its empty state instead of hiding. No fix commit references this issue.

## Change summary

Agents window displays a "No models available" message when launched with `--transient` and no workspace is open, instead of hiding the model picker.

## Best solution

In `src/vs/sessions/contrib/chat/browser/modelPicker.ts`, the `_shouldShowPicker` method should account for the case where no provider or agent harness is selected yet (session is undefined or has no provider) and hide the picker entirely rather than falling through to the no-Auto-model empty-state branch. DonJayamanne's comment aligns: hide the picker until a harness is chosen.
