# Issue #336736 — Custom endpoints can send unsupported sampling parameters

[https://github.com/microsoft/vscode/issues/336736](https://github.com/microsoft/vscode/issues/336736)

## Summary

The requested model-specific constraint enforcement is still missing. Current modelOptions deliberately yield to explicit request options, including Agent temperature, so this needs a BYOK contract decision rather than closing as fixed or treating documented precedence as an implementation regression.

## Change summary

Allow custom endpoint models to enforce required sampling values without changing global Agent settings or overriding ordinary models' explicit request options.

## Best solution

Support model-specific sampling constraints at the final BYOK request boundary while preserving existing modelOptions default semantics for unconstrained models. Decide how constraints are declared before changing the configuration and request contract.
