# Issue #349947 — VS Code Server has grown 4x since 1.100, mostly from two Copilot runtimes

[https://github.com/microsoft/vscode/issues/349947](https://github.com/microsoft/vscode/issues/349947)

## Summary

Keep open: current server packaging still includes independently versioned Copilot runtimes. Related issues cover desktop runtime duplication, Mermaid assets, and old-server cleanup, but none owns the full remote-server footprint problem.

## Change summary

Reduce VS Code Server download and installation size, principally the cost of shipping two Copilot runtimes.

## Best solution

Define a smaller remote-server runtime distribution model that preserves native/JavaScript compatibility and offline deployment. Coordinate runtime consolidation with the desktop packaging issue while keeping server-specific delivery requirements here.
