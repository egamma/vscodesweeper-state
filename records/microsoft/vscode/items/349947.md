# Issue #349947 — VS Code Server has grown 4x since 1.100, mostly from two Copilot runtimes

[https://github.com/microsoft/vscode/issues/349947](https://github.com/microsoft/vscode/issues/349947)

## Summary

Keep open: current server packaging still includes independently versioned Copilot runtimes. Related issues cover runtime sharing, Mermaid duplication, and cache retention individually, but none owns the full server-footprint problem reported here.

## Change summary

Reduce VS Code Server download and installed size, particularly the cost of shipping two Copilot runtimes.

## Best solution

Reduce the remote server's mandatory payload while preserving runtime compatibility and installation on disconnected machines. Coordinate runtime sharing with the existing desktop packaging discussion and leave Mermaid deduplication and cache retention in their existing issues.
