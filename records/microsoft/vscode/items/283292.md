# Issue #283292 — Make sure the ref is set before accessing the element. Maybe wrong initialization order?

[https://github.com/microsoft/vscode/issues/283292](https://github.com/microsoft/vscode/issues/283292)

## Summary

Bug is still live on main: `triggerAnimation()` accesses `_iconRef.element` before the ref is set during DOM rendering. An open PR (https://github.com/microsoft/vscode/pull/315078) targets this fix via the duplicate #305729. Keep open as the canonical issue.

## Change summary

The gutter indicator for inline edits throws when `triggerAnimation()` is called before the icon ref's DOM element has been rendered.

## Best solution

Land or review https://github.com/microsoft/vscode/pull/315078, which gates the animation on the icon being mounted. Close #305729 as a duplicate of this issue once the fix merges. The fix should guard `_iconRef.element` access in `triggerAnimation()` and the `onMouseMove` handler (line 145) in `gutterIndicatorView.ts`.
