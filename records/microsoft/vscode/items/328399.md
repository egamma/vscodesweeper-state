# Issue #328399 — macOS: VS Code 1.131 blocks Local Network access for integrated terminal/Remote-SSH (regression, works on 1.130)

[https://github.com/microsoft/vscode/issues/328399](https://github.com/microsoft/vscode/issues/328399)

## Summary

Well-corroborated regression (7+ independent reporters, 14 upvotes) affecting macOS Local Network access for the integrated terminal and Remote-SSH since 1.131; a collaborator is already engaged and requested a bisect, so this stays open pending root-cause confirmation rather than being closed or left purely at info-needed.

## Change summary

On macOS, VS Code 1.131+ silently blocks LAN traffic (ping/ssh/mDNS) from processes spawned by the integrated terminal, even though the Local Network TCC permission appears granted; 1.130 is unaffected.

## Best solution

Root-cause the suspected Electron 42.6→42.7 bump's effect on the app's Local Network/NECP entitlement handling for child processes (deepak1556 is already investigating); a fix likely lives in the Electron packaging/entitlements config rather than TypeScript source, so this needs vendor/Electron-side or build/entitlement investigation, not a quick code patch.
