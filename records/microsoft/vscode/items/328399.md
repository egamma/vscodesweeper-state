# Issue #328399 — macOS: VS Code 1.131 blocks Local Network access for integrated terminal/Remote-SSH (regression, works on 1.130)

[https://github.com/microsoft/vscode/issues/328399](https://github.com/microsoft/vscode/issues/328399)

## Summary

Multiple independent users confirm the same regression (LAN access broken in 1.131/1.132, restored by downgrading to 1.129/1.130) and a VS Code maintainer is actively engaged, requesting a bisect to narrow the range — this should stay open pending that investigation, not be closed or left unrouted.

## Change summary

On macOS, VS Code 1.131+ appears to break Local Network / LAN connectivity (ping, ssh, Remote-SSH) from its integrated terminal and spawned child processes, likely tied to a TCC/Local-Network-permission regression, while downgrading to 1.129/1.130 restores it.

## Best solution

Keep tracking under the maintainer's (deepak1556) active investigation; the next concrete step is a reporter-run `npx @vscode/vscode-bisect -q insider -g 1.129 -b 1.131` to identify the exact regressing commit/PR, since the maintainer could not reproduce on their own machine and no macOS bundle/entitlement change has been confirmed as the cause yet.
