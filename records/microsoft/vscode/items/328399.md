# Issue #328399 — macOS: VS Code 1.131 blocks Local Network access for integrated terminal/Remote-SSH (regression, works on 1.130)

## Summary

Keep open: later reports confirm that normal app launches still block LAN access despite enabled permissions, and the issue was reopened after an earlier close. The strongest new lead is macOS matching Insiders to stable through a shared Mach-O UUID, but neither a complete diagnosis nor a fixing commit is established.

## Change summary

Restore local-network access for integrated-terminal and Remote-SSH subprocesses when VS Code is launched normally on macOS with permission granted.

## Best solution

Resolve macOS Local Network process-attribution failures in coordination with the Electron runtime and VS Code macOS packaging owners. Verify the shared-LC_UUID hypothesis against both stable-only failures and stable/Insiders coexistence, with an outcome that survives relaunches and updates without resetting system privacy state.
