# Issue #328399 — macOS: VS Code 1.131 blocks Local Network access for integrated terminal/Remote-SSH (regression, works on 1.130)

[https://github.com/microsoft/vscode/issues/328399](https://github.com/microsoft/vscode/issues/328399)

## Summary

Well-confirmed regression: many independent macOS 1.131/1.132 users report the integrated terminal and Remote-SSH losing Local Network (LAN) access after an Electron bump, with downgrade to 1.130 as a reliable workaround; a maintainer (deepak1556) is actively investigating and could not repro locally, and the last comment reports it working again on 1.133 — but there's no cited fix commit yet to justify a completed close.

## Change summary

On macOS, VS Code 1.131+ silently denies Local Network (LAN) traffic (ping/ssh/mDNS/broadcast) from processes spawned by the integrated terminal or Remote-SSH, even though the Local Network permission toggle appears granted; downgrading to 1.130 restores LAN access.
