# Issue #317006 — [Bug] Incomplete Sanitization in fileActions.ts: Only '*' Escaped Allows Markdown Formatting Injection in File Error Messages

[https://github.com/microsoft/vscode/issues/317006](https://github.com/microsoft/vscode/issues/317006)

## Summary

The formatting defect remains on current main: invalid filenames escape `*` but leave other delimiters recognized by the formatted-text renderer unescaped. The maintainer has classified this as a low-impact rendering annoyance rather than a security issue, so it should remain open as a bounded papercut.

## Change summary

Prevent invalid filenames from introducing unintended formatting into Explorer validation messages.

## Best solution

Ensure filename text is rendered literally inside the intentionally bold validation-message wrapper while preserving the surrounding message formatting and existing filename validation behavior.
