# Issue #227982 — Notebook Diff Editor layout issues when cells have a horizontal scrollbar

[https://github.com/microsoft/vscode/issues/227982](https://github.com/microsoft/vscode/issues/227982)

## Summary

The notebook diff height estimator still omits horizontal scrollbar space, while the rendered editor includes it and subsequently updates cell height. Keep this open while the existing fixing PR is reviewed; it has not merged.

## Change summary

Notebook diff cells with horizontally overflowing content shift layout because their estimated editor height excludes the horizontal scrollbar.

## Best solution

Review https://github.com/microsoft/vscode/pull/282373 against the actual rendered editor heights, including cells without overflow and configured scrollbar sizes, and land it if it resolves the mismatch without introducing later height corrections.
