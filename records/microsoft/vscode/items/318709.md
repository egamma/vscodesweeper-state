# Issue #318709 — Terminal local file links are mis-tokenized around CJK punctuation

[https://github.com/microsoft/vscode/issues/318709](https://github.com/microsoft/vscode/issues/318709)

## Summary

Valid bug, still present on main. The local file link parser's regex character classes in `terminalLinkParsing.ts` don't exclude CJK sentence/separator punctuation (，。：；！？、), so these characters are matched as part of the path, causing link detection to fail. Well-scoped report with an offered PR contribution.

## Change summary

Terminal local file link detection treats CJK sentence/separator punctuation as valid path characters, causing paths surrounded by CJK text to be mis-tokenized and fail file resolution.

## Best solution

Add CJK sentence/separator punctuation (，。：；！？、 at minimum) to the excluded-character classes in `ExcludedPathCharactersClause` and `ExcludedStartPathCharactersClause` (and their Windows variants) in `src/vs/workbench/contrib/terminalContrib/links/browser/terminalLinkParsing.ts`. The reporter has offered to submit a PR — accepting that contribution is the natural path. Related issue https://github.com/microsoft/vscode/issues/303101 covers the same gap in URL link detection (different code path, `LinkComputer`).
