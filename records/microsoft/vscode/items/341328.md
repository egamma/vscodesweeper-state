# Issue #341328 — Agent Host bug

[https://github.com/microsoft/vscode/issues/341328](https://github.com/microsoft/vscode/issues/341328)

## Summary

Thanks for the report. The Agent Host terminal path spawns node-pty without any Windows-specific options, unlike the regular editor terminal. That plausibly explains the console flash, but it can't be confirmed without running on Windows. The report is complete enough to retest, so it stays open.

## Change summary

On Windows, each PowerShell tool call from the Agents window briefly shows an external console window, while the same command in a normal editor window stays embedded.

## Best solution

Make AgentHostTerminalManager._spawnPty pass the same Windows pty options the regular terminal uses (useConpty, plus useConptyDll where applicable), and check that the host process doesn't spawn a visible console. Confirm on Windows with an Agents-window tool call.
