# Issue #292969 — Up arrow in PowerShell terminals types the wrong command

[https://github.com/microsoft/vscode/issues/292969](https://github.com/microsoft/vscode/issues/292969)

## Summary

Keep open: agent-created PowerShell terminals install a session-wide history filter that also excludes manually typed commands. The confirmed reproduction matches this current-source behavior; the older history-navigation report does not establish the same defect.

## Change summary

Manually entered commands in agent-created PowerShell terminals should remain available through Up/Down history navigation.

## Best solution

Preserve history for manually entered commands while continuing to exclude agent-executed commands when chat.tools.terminal.preventShellHistory is enabled. Establish a PowerShell/PSReadLine regression check covering both input sources in the same terminal.
