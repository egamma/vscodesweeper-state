# Issue #75005 — Quickpick loses active item if items are updated

[https://github.com/microsoft/vscode/issues/75005](https://github.com/microsoft/vscode/issues/75005)

## Summary

The focus reset remains source-reproducible: refreshing items selects the first entry even when the previously active object remains present. Keep this report open; the related focus-preservation report is newer and cannot be its duplicate canonical under the re-review rules.

## Change summary

Preserve the active Quick Pick item when an extension refreshes the list using the same item objects, including updates to their detail text.

## Best solution

Refreshing surviving item objects should retain keyboard focus and redraw their details without a spurious active-item change. Preserve existing behavior for initial population, genuinely replaced or removed items, and explicit activeItems assignments.
