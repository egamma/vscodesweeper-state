# Issue #336976 — Debug API: allow extensions to programmatically focus an existing debug session

[https://github.com/microsoft/vscode/issues/336976](https://github.com/microsoft/vscode/issues/336976)

## Summary

Legitimate API gap: there is no public way to programmatically move VS Code's active debug UI focus to another running session — the only existing command (`workbench.action.debug.focusProcess`) is internal and takes an `IDebugSession`, not the public `vscode.DebugSession`. Worth routing to the debug/API area for design input; too new (0 days, no upvotes/discussion) to judge scope or shape yet.

## Change summary

Add a supported extension API (or command) to focus an existing debug session, so the debug toolbar/console/call stack follow a session selected programmatically.

## Best solution

Debug/API owners should decide the shape of a `vscode.debug.focusSession(session)`-like API (or a documented command taking a session ID) that internally calls the same path as `debugService.focusStackFrame(...)` used by `workbench.action.debug.focusProcess`.
