# Issue #207580 — Allow WorkspaceEditMetadata to control whether changes are grouped by label by default

[https://github.com/microsoft/vscode/issues/207580](https://github.com/microsoft/vscode/issues/207580)

## Summary

A real API gap remains on current main, and the request has already earned Backlog placement with 59 community upvotes. The existing user-level grouping preference does not let an edit provider select the appropriate default.

## Change summary

Allow workspace-edit metadata to request that labeled changes initially appear grouped by label in the refactor preview.

## Best solution

Extend the workspace-edit API and bulk-edit transport with an edit-level grouping preference, then have BulkEditPane honor it for the initial view without overriding subsequent user toggles.
