# Issue #327009 — Agent Mode: Cant view diffs in WSL

[https://github.com/microsoft/vscode/issues/327009](https://github.com/microsoft/vscode/issues/327009)

## Summary

Real bug: the Agents window's agent-host file system provider fails to read files via `vscode-agent-host://wsl__debian/...` URIs because no connection is registered for the WSL authority when opening diffs. The WSL agent host contribution wires connections but the file system read path can't resolve the authority at diff-view time.

## Change summary

Viewing file diffs in the Agents window's change review panel fails with 'No connection for authority: wsl__debian' when the session is running over WSL.

## Best solution

The agent host file system provider (`src/vs/platform/agentHost/common/agentHostFileSystemProvider.ts`) needs its authority map populated for WSL connections. The `RemoteAgentHostContribution` and `WSLAgentHostContribution` wire live connections for session operations, but the file system provider's `_authorities` map may not be populated or may lose the entry. The fix likely involves ensuring the WSL connection authority is registered with the agent host file system provider when the WSL connection is established, and kept alive for the duration of the session.
