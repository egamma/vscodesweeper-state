# Issue #327009 — Agent Mode: Cant view diffs in WSL

[https://github.com/microsoft/vscode/issues/327009](https://github.com/microsoft/vscode/issues/327009)

## Summary

Real, independently-confirmed bug: opening a diff (or the plan viewer) for a WSL-backed agent session intermittently fails with 'No connection for authority' even though the underlying WSL connection is alive, pointing to a race or lookup mismatch in the agent-host file system provider's authority routing rather than an actual disconnect.

## Change summary

In an Agents window session on a WSL workspace, clicking a changed file in the Changes view (or opening the plan panel) throws a FileSystemError 'No connection for authority: wsl__<distro>' instead of showing the diff/content.

## Best solution

Investigate AHPFileSystemProvider._getConnection in src/vs/platform/agentHost/common/agentHostFileSystemProvider.ts together with how `agentHostAuthority()`/`wsl:<distro>` addresses are registered in src/vs/sessions/contrib/providers/remoteAgentHost/browser/remoteAgentHost.contribution.ts and wslAgentHost.contribution.ts — likely a timing gap (editor resolves the URI before/after `registerAuthority` runs for that window) or a distro-name casing mismatch between the registered authority and the authority encoded in generated URIs.
