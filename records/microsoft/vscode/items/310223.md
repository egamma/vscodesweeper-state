# Issue #310223 — Allow github.copilot.chat.commitMessageGeneration.instructions to read files outside of the workspace

[https://github.com/microsoft/vscode/issues/310223](https://github.com/microsoft/vscode/issues/310223)

## Summary

Keep open as a feature request: the three settings still resolve file entries relative to workspace folders, and existing personal instruction discovery does not cover these operation-specific prompts. No verified canonical issue owns the same request.

## Change summary

Allow commit-message, selection-review, and pull-request-description instructions to reference shared files outside the workspace.

## Best solution

Support explicitly configured absolute and home-relative instruction files across these three operations while preserving workspace-relative behavior. Settle configuration-scope and remote-home semantics before implementation.

- **Trace:**

  > CustomInstructionsService.fetchInstructionsFromSetting inspects workspace-folder, workspace, and global values, but collectInstructionsFromSettings merges them without retaining their origin. _collectInstructionsFromFile then joins every reference to each workspace folder; it does not use the home-relative or absolute-location logic found elsewhere in the same service. CustomInstructions consumes this loader for the three requested settings, and selection review has another direct consumer in githubReviewAgent.ts. Commit and pull-request prompts disable general code-generation instructions, so personal instruction discovery is not equivalent coverage.
