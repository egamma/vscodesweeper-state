# Issue #340740 — Agent Window: Quick chats trapped in custom group

[https://github.com/microsoft/vscode/issues/340740](https://github.com/microsoft/vscode/issues/340740)

## Summary

Confirmed in source: drag-and-drop back out of a custom group is not supported for quick chats, because the code that resolves the return section never yields the Chats section. The context menu's 'Remove from Group' still works as a workaround.

## Change summary

A quick chat moved into a custom group cannot be dragged back to the default 'Chats' section; only other custom groups accept it.

## Best solution

Let grouped quick chats return to the 'Chats' section on drag-out. getUngroupedSectionIdOfSession should return QUICK_CHATS_SECTION_ID for quick chats, and resolveRemoveFromGroupTarget should accept that section id as a drop target.

## Evidence

- **drag-out resolution:** In src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts, getUngroupedSectionIdOfSession returns undefined for quick chats (`|| isQuickChatSession(session)`). It only ever returns `workspace:*` or the External section id.
- **section drop target:** resolveRemoveFromGroupTarget (about line 3355) accepts a section header as a drop target only when its id starts with `workspace:` or equals the External section id. QUICK_CHATS_SECTION_ID ('quickchats') is rejected, so dropping on 'Chats' does nothing.
- **workaround:** getGroupSessionActions (about line 5723) adds a 'Remove from Group' context-menu action for any grouped session, so the keyboard and menu path is not blocked.
