# Issue #13960 — Virtual Space is not implemented.

[https://github.com/microsoft/vscode/issues/13960](https://github.com/microsoft/vscode/issues/13960)

## Summary

Virtual space remains unimplemented on main, and two open PRs are attempting the work. Keep the accepted, highly supported Backlog request open while maintainers converge on a sufficiently localized implementation.

## Change summary

Add an opt-in editor mode allowing cursors and rectangular selections to extend beyond the physical end of lines.

## Best solution

Consolidate the work into one implementation that limits virtual-space state propagation while preserving cursor movement, typing, paste, rendering, and column-selection behavior. Review and resolve the technical concerns on https://github.com/microsoft/vscode/pull/228680 or https://github.com/microsoft/vscode/pull/310341 rather than starting another implementation.
