## Evidence

- **Existing POSIX capability and remaining gap:** src/vs/platform/terminal/node/terminalProcess.ts maps the exact name 'codex' to GeneralShellType.Codex. However, _setupTitlePolling polls node-pty's process property every 200 ms on non-Windows platforms, and _sendProcessTitle classifies its sanitized basename; this path does not inspect descendant command lines to identify agents hidden behind another executable.
- **Partial cross-platform fallback:** src/vs/workbench/contrib/terminal/browser/terminalInstance.ts:_onTitleChange recognizes several agent CLIs through OSC title patterns. Codex is explicitly excluded from agentCliTitlePatterns with the comment 'codex does not report osc title.' terminal.integrated.tabs.allowAgentCliTitle controls title presentation, not a stronger POSIX process-identification mechanism.
- **Windows comparison:** src/vs/platform/terminal/node/windowsShellHelper.ts:getShellName requests process-tree command lines, and traverseTree recognizes npm-installed agents inside node.exe using package-path patterns, including Codex. This helper is Windows-only and does not supply the requested macOS/Linux behavior.
