# Issue #338412 — Exclamation mark command runs under wrong working directory

[https://github.com/microsoft/vscode/issues/338412](https://github.com/microsoft/vscode/issues/338412)

## Summary

Confirmed bug (peer/sub-chat `!` commands run in the main chat's working directory instead of their own), and an open PR already has a fix with a regression test in progress — keep open and let that PR land rather than proposing a close or an agent task.

## Change summary

Running a `!` bang command in a sub/peer chat executes it using the main chat's working directory instead of the sub-chat's own directory.

## Best solution

Land https://github.com/microsoft/vscode/pull/340474, which resolves the working directory from the invoking chat's effective state instead of the main chat's; the issue closes automatically once that PR merges.
