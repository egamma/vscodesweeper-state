# Issue #239878 — Git - Open Git commit online in any hosting site, not just GitHub

[https://github.com/microsoft/vscode/issues/239878](https://github.com/microsoft/vscode/issues/239878)

## Summary

The built-in blame hover still restricts remote commit links to github.com, so support for GitLab and self-hosted services remains missing. An open PR explicitly targets this issue; keep it open while that implementation candidate is reviewed.

## Change summary

Allow commits shown in built-in Git blame to open in the browser on GitLab, GitHub Enterprise, and other Git hosting services.

## Best solution

Review https://github.com/microsoft/vscode/pull/282970 against the full hosting-neutral request, including host-specific commit paths and self-hosted remote URLs. Land an implementation that opens the correct remote commit while preserving existing GitHub behavior.
