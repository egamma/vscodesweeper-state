# Issue #336492 — Retain configured terminals

[https://github.com/microsoft/vscode/issues/336492](https://github.com/microsoft/vscode/issues/336492)

## Summary

VS Code already persists terminals (including their custom icons) across window close/reopen via built-in settings that are enabled by default; the reporter likely isn't aware of this existing behavior/settings, or has them disabled.

## Change summary

Requests that terminals opened in a workspace (including custom icons) be preserved and restored when VS Code is closed and reopened.

## Best solution

Point the reporter to `terminal.integrated.enablePersistentSessions` (default true) and `terminal.integrated.persistentSessionReviveProcess` (default `onExit`), which already restore terminal sessions — including their shell launch config/icon via `ISerializedTerminalState.shellLaunchConfig` — across window close/reopen; if it's genuinely not working for them, that would be a separate, narrower bug report with specific repro steps.
