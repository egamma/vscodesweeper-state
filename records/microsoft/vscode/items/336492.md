# Issue #336492 — Retain configured terminals

[https://github.com/microsoft/vscode/issues/336492](https://github.com/microsoft/vscode/issues/336492)

## Summary

Workspace terminal persistence, including custom icons, is already supported. The existing settings cover restoration after closing any window, so the requested capability does not require a new feature.

## Change summary

Preserve opened terminals and their custom icons when closing and reopening the same workspace.

## Best solution

Use terminal.integrated.enablePersistentSessions together with terminal.integrated.persistentSessionReviveProcess set to onExitAndWindowClose. If ordinary terminals still disappear with these settings, investigate that separately as a persistence failure with precise reproduction steps.

- **Proposed comment:**

  > Thanks for the request. VS Code already supports retaining terminals and their custom icons for the same workspace. Set `terminal.integrated.enablePersistentSessions` to `true` and `terminal.integrated.persistentSessionReviveProcess` to `"onExitAndWindowClose"` to restore them after individual window closures as well as application exit.
  > 
  > Restoration recreates shell processes; it does not resume running applications. If ordinary terminals still disappear with those settings, please report the exact close/reopen steps and whether other VS Code windows remained open so we can investigate a persistence bug.
