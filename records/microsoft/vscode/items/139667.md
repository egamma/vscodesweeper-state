# Issue #139667 — Find regex error overlaps window

[https://github.com/microsoft/vscode/issues/139667](https://github.com/microsoft/vscode/issues/139667)

## Summary

The layout defect remains possible on current main: an oversized regex validation message cannot fit vertically and may be moved beside the find input, overlapping window UI.

## Change summary

Keep long regular-expression validation errors within the window and preserve visibility of the useful syntax error.

## Best solution

Constrain or summarize find-widget regex errors before displaying them, retaining the actionable parser error while truncating the echoed pattern. The change likely belongs in the editor find validation path, with InputBox behavior reviewed to avoid regressions for other consumers.
