# Issue #239124 — notebook inline values are not accessible to screen reader users

[https://github.com/microsoft/vscode/issues/239124](https://github.com/microsoft/vscode/issues/239124)

## Summary

Keep open: current notebook accessibility paths still do not expose execution inline values through the Accessible View or cell ARIA labels. The maintainer's requested accessibility workflow remains meaningful; neither a qualifying fix nor an older canonical with the same symptom was established.

## Change summary

Expose notebook execution inline values in the Accessible View, provide configurable default-on ARIA inclusion, and add a reading command/keybinding documented in notebook accessibility help.

## Best solution

Make the existing notebook inline values available through the notebook accessibility surfaces without requiring users to print variables or inspect visual decorations. Preserve the maintainer's specified default-on ARIA inclusion and complete the command, keyboard access, and help experience together.
