# Issue #239124 — notebook inline values are not accessible to screen reader users

[https://github.com/microsoft/vscode/issues/239124](https://github.com/microsoft/vscode/issues/239124)

## Summary

Team-authored accessibility feature request for notebook inline values. The four concrete asks (accessible view integration, ARIA label setting, keybinding/command, help dialog entry) remain unimplemented on current main — no accessibility support exists in the inline variables controller.

## Change summary

Notebook inline values (shown after cell execution) are not accessible to screen reader users — no accessible view, ARIA labels, keybinding, or help dialog integration exists.

## Best solution

Implement the four items from the feedback: (1) surface inline values in the notebook accessible view, (2) add a setting controlling ARIA label inclusion (default on), (3) register a command/keybinding to read inline values, (4) mention the setting in the notebook accessibility help dialog. Work lives in `src/vs/workbench/contrib/notebook/browser/contrib/notebookVariables/notebookInlineVariables.ts` and the notebook accessible-view provider.
