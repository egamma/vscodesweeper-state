- **Python command ownership:** https://github.com/microsoft/vscode-python/blob/main/package.json binds Shift+Enter to python.execSelectionInTerminal for Python editors. TerminalCodeExecutionProvider.execute in https://github.com/microsoft/vscode-python/blob/main/src/client/terminals/codeExecution/terminalCodeExecution.ts initializes the Python REPL and calls executeCommand(code, true).
- **Extension handles explicit paste delimiters:** TerminalService.executeCommand and sendPythonShellCommand in https://github.com/microsoft/vscode-python/blob/main/src/client/common/terminal/service.ts handle Python REPL input separately. sendPythonShellCommand explicitly recognizes strings beginning with ESC[200~ and ending with ESC[201~, forwards them through terminal.sendText, and sends carriage return separately. This establishes a relevant extension-owned investigation path, not proof of the particular failure.
- **Core boundary and setting limitation:** In the checkout, src/vs/workbench/api/browser/mainThreadTerminalService.ts:222-224 forwards extension text to instance.sendText without requesting bracketed-paste wrapping. src/vs/workbench/contrib/terminal/browser/terminalInstance.ts:1417-1432 wraps only when forceBracketedPasteMode and the terminal mode are enabled, then writes the supplied text. The ignoreBracketedPasteMode setting is passed to xterm in browser/xterm/xtermTerminal.ts; it does not strip escape sequences already supplied through extension sendText.
