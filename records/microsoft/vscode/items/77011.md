# Issue #77011 — [css] Shorthand properties: show label for each value in hover

[https://github.com/microsoft/vscode/issues/77011](https://github.com/microsoft/vscode/issues/77011)

## Summary

A real capability gap remains: current CSS hover provides property documentation but does not identify the positional meaning of values in shorthand properties. The behavior is owned by the CSS language service and no older canonical issue was found, so this should remain open in the existing CSS area.

## Change summary

Show contextual labels for each positional value of CSS shorthand properties such as margin, padding, box-shadow, and text-shadow.

## Best solution

Design the positional-value help in microsoft/vscode-css-languageservice, then expose it through the existing hover or completion response consumed by VS Code; the UX should cover shorthand grammar without changing ordinary property documentation.
