# Issue #284538 — SCM - Show the number of modifications

[https://github.com/microsoft/vscode/issues/284538](https://github.com/microsoft/vscode/issues/284538)

## Summary

The per-file modification count remains missing from Git status decorations. Keep this accepted Backlog request open; existing count settings and related statistics requests do not cover the same behavior.

## Change summary

Show a per-file modification count alongside or instead of the M status indicator.

## Best solution

Define whether the count represents changed lines or diff hunks, then assess a compact per-file presentation that preserves status readability. The existing Git decoration provider is the relevant boundary, rather than the aggregate Source Control badge.
