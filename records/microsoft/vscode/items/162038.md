# Issue #162038 — Merge Editor: "Accept all change from Left / Right" Available all the time, and isn't really undoable

[https://github.com/microsoft/vscode/issues/162038](https://github.com/microsoft/vscode/issues/162038)

## Summary

The bulk-accept commands still remain enabled after their side has been accepted, and accepted non-conflicting changes can lack visible removal lenses. Keep this team-authored issue open: current undo/reset support partially addresses recovery, but neither a complete referenced fix nor an older canonical covering the full report was established.

## Change summary

Make bulk acceptance reflect the remaining applicable changes and provide a discoverable way to reverse accepted changes.

## Best solution

The merge editor should communicate when bulk acceptance has nothing left to do and provide discoverable recovery for changes it accepts, including non-conflicting ranges. Preserve automatic merging of non-conflicting changes; resetting to the auto-merged result is not equivalent to reversing a user's last bulk action.
