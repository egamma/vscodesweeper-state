# Issue #157233 — Integrated terminal: Inserting X selections requires precise mouse positioning

[https://github.com/microsoft/vscode/issues/157233](https://github.com/microsoft/vscode/issues/157233)

## Summary

Still reproduces on main: middle-click (X11 primary selection) paste in the terminal fails when clicking on an area with existing text. The code only calls `this.focus()` on middle click but does not clear the xterm selection or prevent xterm from intercepting the event, so the paste never reaches the shell. The upstream xterm.js issue was closed as a VS Code-side problem.

## Change summary

Middle-click paste (X11 primary selection) in the integrated terminal only works when clicking on blank space, not on existing text.

## Best solution

The middle-click handler in `terminalInstance.ts` (line ~2518) needs to clear any xterm.js selection and possibly prevent the default mouse handling so the X11 primary selection paste event propagates correctly regardless of whether the click lands on existing text. The fix is localized to the terminal mouse event handling.
