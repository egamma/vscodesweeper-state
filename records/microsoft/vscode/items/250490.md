# Issue #250490 — UX bug: unexpected hover behaviour - attached file

[https://github.com/microsoft/vscode/issues/250490](https://github.com/microsoft/vscode/issues/250490)

## Summary

Keep open: ordinary file attachments still lack the body-hover feedback suggested by the reporter and accepted by a maintainer. Opening the file and removing its attachment are intentionally separate actions; the remaining work is making that distinction visually discoverable.

## Change summary

Give an attached file's icon-and-filename region hover feedback distinct from its remove button.

## Best solution

Provide consistent hover feedback for the attachment's file-opening region while preserving the remove button's independent feedback and behavior. This follows the direction already accepted in the discussion rather than changing the attachment into a removal toggle.
