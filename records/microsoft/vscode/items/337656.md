# Issue #337656 — Copilot Chat - Use monochrome VS Code icon for reasoning

[https://github.com/microsoft/vscode/issues/337656](https://github.com/microsoft/vscode/issues/337656)

## Summary

This is genuine design feedback about the animated VS Code logo shown during chat 'working'/reasoning progress — it is intentionally colored today via dedicated theme tokens, so this is a product-direction question for a maintainer, not a bug or something already fixed.

## Change summary

Use a monochrome (theme-foreground) icon instead of the colored VS Code logo for the Copilot Chat reasoning/working progress indicator.

## Best solution

A maintainer decides whether the default working-progress icon should switch to a neutral/monochrome color; in the meantime the color is already themeable via `chat.workingProgressStableIconForeground` / `chat.workingProgressInsidersIconForeground`.
