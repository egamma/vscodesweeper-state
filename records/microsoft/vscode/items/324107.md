# Issue #324107 — Agent window session in a new worktree doesn't open editor in the worktree location immediately

[https://github.com/microsoft/vscode/issues/324107](https://github.com/microsoft/vscode/issues/324107)

## Summary

Keep open: the current editor-opening action uses the active chat's working directory immediately, even while worktree creation is pending and that directory still describes the original checkout. No verified older canonical or issue-referencing fix was found.

## Change summary

Opening a newly started worktree session in the editor initially opens the original repository rather than the session's isolated worktree.

## Best solution

Make the Agents Window editor handoff respect pending worktree creation and open only the intended session workspace. Decide whether an early invocation waits for readiness or the action remains unavailable until the worktree is ready.
