# Issue #64311 — Search: find, replace input boxes miss scrollbar

[https://github.com/microsoft/vscode/issues/64311](https://github.com/microsoft/vscode/issues/64311)

## Summary

Keep open: current Search view CSS explicitly hides the find input's custom scrollbar, so the requested overflow affordance is not fully delivered. The existing search label is appropriate, and no verified canonical issue was found.

## Change summary

Expose scrollbars when Search view find and replace inputs contain overflowing text, including the horizontal case raised in the discussion.

## Best solution

Make overflowing search inputs expose a usable scrollbar consistent with other workbench inputs, while preserving multiline wrapping and history navigation. Check find and replace separately because their scrollbar styling differs.
