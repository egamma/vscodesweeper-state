# Issue #336703 — Remote GitHub agent sessions cannot be dismissed from the Sessions list

[https://github.com/microsoft/vscode/issues/336703](https://github.com/microsoft/vscode/issues/336703)

## Summary

Confirmed on current main: the archived-state logic in agentSessionsModel.ts still trusts `canSetChatSessionItemArchived` for GitHub cloud sessions even though the cloud backend doesn't persist the mutation, so Done/dismiss has no visible effect — exactly the reported symptom. A coding-agent PR (#336705, 'Fixes #336703') proposed the fix but is closed and its diff is not present on main, so this stays open.

## Change summary

Remote/cloud GitHub agent sessions in the Sessions list cannot be opened or dismissed (Done has no effect and they stay in the list forever).

## Best solution

Have the Sessions/agent-sessions model track archived/done state locally for GitHub cloud sessions (instead of delegating to `chatSessionsService.setChatSessionItemArchived`) until the cloud backend itself supports archive mutations — the closed PR #336705 sketches this exact approach and its test can be reused/adapted.
