## Summary

The missing-fetch-URL defect remains in current main: Copilot's single-remote fast path passes undefined into a parser that calls trim(). Keep this open as a bounded Copilot Git-context bug; the report describes failed chat requests, not a demonstrated process crash.

## Change summary

Copilot Chat requests fail when the repository's only remote defines pushurl but no fetch URL.

## Best solution

Copilot's Git-context helpers should handle a push-only remote as having no usable fetch URL, without throwing or blocking chat. Preserve valid remote ordering and leave the reporter's push-prevention configuration unchanged.
