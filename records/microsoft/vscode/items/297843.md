# Issue #297843 — Fix "Directory Already Exists" Error When Re-adding a Plugin Marketplace Repository in GitHub Copilot

[https://github.com/microsoft/vscode/issues/297843](https://github.com/microsoft/vscode/issues/297843)

## Summary

Already fixed and shipped. The race condition that allowed concurrent clones to the same directory was resolved by serializing `ensureRepository` calls through a `SequencerByKey`, shipped in 1.112.0.

## Change summary

Re-adding a plugin marketplace repository URL causes a fatal git clone error because concurrent `ensureRepository` calls bypass the exists-check and attempt duplicate clones.

## Best solution

Keep the shipped fix in commit e7e6cbe3a9e (1.112.0); no further change is needed. The `SequencerByKey` serialization in `ensureRepository` prevents concurrent clones to the same target directory.
