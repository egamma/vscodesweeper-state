# Issue #328120 — Consider combining tools and MCP server tools

[https://github.com/microsoft/vscode/issues/328120](https://github.com/microsoft/vscode/issues/328120)

## Summary

Keep open for design discussion and route to the MCP/tools owners. Current main presents closely related capabilities as separate peer sections, while their different management responsibilities make the proposed hierarchy a product-design decision.

## Change summary

Present MCP servers as a subset of Tools in the Agent Customizations view instead of as a separate section.

## Best solution

Decide whether Tools should become the unified capability browser, with MCP servers represented as tool-providing groups while retaining server configuration, marketplace, status, and detail workflows. The likely implementation spans the customization editor section model and both dedicated list widgets.
