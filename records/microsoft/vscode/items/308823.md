# Issue #308823 — Copilot Chat: SSE stream inactivity timeout (60s) should be configurable — causing mid-stream failures under backend congestion

[https://github.com/microsoft/vscode/issues/308823](https://github.com/microsoft/vscode/issues/308823)

## Summary

Valid feature request to make the Copilot Chat SSE stream inactivity timeout configurable. The hardcoded 60s timeout in the networking layer causes mid-stream failures under transient backend congestion. No existing setting covers this, and no recent work on main addresses it. Routing to the Copilot area for the team to evaluate.

## Change summary

The SSE stream inactivity timeout (60s) is hardcoded in the Copilot extension's networking layer, causing failures when the backend pauses mid-stream for longer than 60 seconds.

## Best solution

Expose the post-first-chunk SSE inactivity timeout as a configurable setting (e.g. `github.copilot.advanced.streamIdleTimeoutMs`) with a sensible default, and also fix the GOAWAY retry guard to match the custom error message shape alongside the Node built-in error code. The networking code lives in `extensions/copilot/src/platform/networking/`.
