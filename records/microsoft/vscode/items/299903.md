# Issue #299903 — Linkification broken in gpt-5.4

[https://github.com/microsoft/vscode/issues/299903](https://github.com/microsoft/vscode/issues/299903)

## Summary

Team-filed bug about chat link resolution failing for relative-path markdown links returned by gpt-5.4. No fix commit references this issue; the link resolution code on main (`resolveChatResponseUri`) still doesn't appear to handle relative workspace paths in the format the model emits. Keeping open per team-authored protection.

## Change summary

Markdown links with relative workspace paths (e.g. `[file](path/to/file.ts#L123)`) returned by gpt-5.4 are not rendered as clickable links in chat responses.

## Best solution

The chat markdown content renderer's link resolution pipeline (`resolveChatResponseUri` and its callers in `chatMarkdownContentPart.ts`) needs to handle relative workspace-path hrefs that the model emits, resolving them against the workspace root to produce clickable file links. This may also involve prompt-side guidance to the model to emit links in a format VS Code already supports.
