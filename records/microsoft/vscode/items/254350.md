# Issue #254350 — Copilot doesn't understand Git renames

[https://github.com/microsoft/vscode/issues/254350](https://github.com/microsoft/vscode/issues/254350)

## Summary

Keep open: current source loses rename information before commit-message generation, explaining why staged moves are described as additions. The existing git label is appropriate, and no qualifying canonical or open fixing PR was identified.

## Change summary

Generated commit messages should describe staged file renames and moves rather than incorrectly treating them as new files.

## Best solution

Ensure the commit-message generation context faithfully represents Git-recognized renames, including their original and destination paths, while preserving accurate descriptions of accompanying content edits.
