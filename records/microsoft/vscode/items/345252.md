# Issue #345252 — Chat issue artifacts open inside VS Code despite default external URI opener setting

[https://github.com/microsoft/vscode/issues/345252](https://github.com/microsoft/vscode/issues/345252)

## Summary

Keep open: the Agents-window issue artifact invokes a core command that opens the GitHub Pull Requests webview without consulting the configured external URI opener. The current source establishes a concrete bypass of the reported preference.

## Change summary

GitHub issue artifacts should respect the configured external URI opener instead of unconditionally opening an internal webview.

## Best solution

Make issue-artifact navigation honor workbench.externalUriOpeners, including wildcard default-browser selection, while preserving contextual issue targeting and existing behavior when no preference is configured.
