# Issue #264651 — Alignment of `Open` and `Closed` feels off in issue reporter `Similar issues`

[https://github.com/microsoft/vscode/issues/264651](https://github.com/microsoft/vscode/issues/264651)

## Summary

Team-authored visual polish issue — the alignment of Open/Closed state badges in the issue reporter's similar issues section remains unfixed on main. The old (non-wizard) issue reporter path is still reachable via the `issueReporter.wizard.enabled` setting, and its CSS for `.issue-state` has misaligned padding. The new wizard path renders states as plain text spans with simpler styling that may also warrant review.

## Change summary

The 'Open' and 'Closed' state badges in the issue reporter's similar issues list are slightly misaligned vertically with the info icon.

## Best solution

Fix the vertical alignment in `src/vs/workbench/contrib/issue/browser/media/issueReporter.css` — the `.issue-state` flex container's child elements (`.codicon`, `.label`, `.issue-icon`) have inconsistent `padding-top` values (lines 452–476). Consider aligning items via `align-items: center` on the flex parent instead of manual padding. If the old issue reporter path is being deprecated in favor of the wizard, this may also be addressed by completing that migration.
