# Issue #156656 — [html] Duplicate double quotes are inserted for HTML attributes when working over SSH

[https://github.com/microsoft/vscode/issues/156656](https://github.com/microsoft/vscode/issues/156656)

## Summary

The remote-latency race was fixed after this report: snippet insertion now rejects an edit when the renderer model has advanced beyond the extension host's version, preventing delayed quote insertion after the user manually types a quote.

## Change summary

Prevent delayed HTML attribute quote completion over Remote SSH from adding duplicate quotes after a manually typed quote.

## Best solution

Keep the model-version guard added by commit 1846f69774571e62bf81c16b2496ae739978277b; it prevents stale extension-host snippet edits from modifying a newer renderer document.
