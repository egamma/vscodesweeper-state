# Issue #333836 — Unexpected layout when switching sessions

[https://github.com/microsoft/vscode/issues/333836](https://github.com/microsoft/vscode/issues/333836)

## Summary

Current main confirms the reported behavior: single-pane mode deliberately applies one shared Editor/Details visibility profile to every existing session. This team-authored report should remain open for the Agents Window owners to decide whether session-specific visibility should be restored.

## Change summary

Remember side-pane visibility independently for each session instead of carrying the same layout across session switches.

## Best solution

Decide whether single-pane Editor/Details visibility is session-specific or workspace-wide, then align the visibility store, switch strategy, persistence contract, and focused session-switch tests with that decision.
