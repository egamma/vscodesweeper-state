# Issue #325507 — Public API to observe agent/subagent chat session lifecycle & status from an extension

[https://github.com/microsoft/vscode/issues/325507](https://github.com/microsoft/vscode/issues/325507)

## Summary

Genuine feature request for a read-only extension API to observe built-in agent/subagent session lifecycle and status. No such API exists on current main — the proposed `chatSessionsProvider` API only lets extensions provide their own sessions, not observe the built-in agent's. The request is well-scoped and privacy-conscious.

## Change summary

Add a read-only extension API to observe chat/agent session lifecycle events (status changes, subagent spawns/completions) for the built-in Copilot agent sessions.

## Best solution

Design a proposed API surface (e.g. `onDidChangeChatSessionStatus`, `onDidChangeSubagents`) that exposes session lifecycle and parent-child delegation links without message content. This fits naturally alongside the existing `chatSessionsProvider` proposed API and the internal session status infrastructure already used by the Agents window UI. Route to the `api-proposal` and `agents` area owners for design review.

## Evidence

There is no event or accessor to observe the built-in agent's sessions or subagent delegations.
- **internal data exists:** The Agents window UI already surfaces subagent status (sessionRunningSubagentsControl.ts, agentSessionsModel.ts with ChatSessionStatus enum), meaning the internal infrastructure exists but is not exposed through the extension API.
