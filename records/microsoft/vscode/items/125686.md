# Issue #125686 — iPadOS: first and last status bar item cannot be tapped on

[https://github.com/microsoft/vscode/issues/125686](https://github.com/microsoft/vscode/issues/125686)

## Summary

The general status bar touch issue was partially fixed (commit fcbf1eb903a), but the original corner-item problem persists — iPadOS reserves screen edges for system gestures, blocking taps on the first and last status bar items. The issue remains valid and unfixed on main.

## Change summary

On iPadOS, the first and last status bar items cannot be tapped because they fall within the OS system gesture zones at screen corners.

## Best solution

Either add padding/inset to keep interactive status bar items away from iPadOS system gesture zones, or reorder items so the outermost slots are non-interactive spacers. The fix likely lives in `src/vs/workbench/browser/parts/statusbar/statusbarPart.ts` and related CSS, with platform detection gating.
