# Issue #338395 — Please do not deprecate/remove custom skill locations (`chat.agentSkillsLocations`)

[https://github.com/microsoft/vscode/issues/338395](https://github.com/microsoft/vscode/issues/338395)

## Summary

Genuine product-direction pushback against a planned deprecation of `chat.agentSkillsLocations` and the Local agent harness in favor of migrating to the Agent Customizations editor's supported locations — this is a maintainer decision, not something to triage-close; two independent commenters corroborate real workflow dependence (npm-distributed skills, toolchain-scoped skill folders).

## Change summary

Requests that the deprecated `chat.agentSkillsLocations` setting (and custom skill locations generally) not be removed, since it enables workflows like distributing skills via package managers.

## Best solution

A maintainer who owns the Agent Host customization migration should weigh in on whether the migration path (Agent Customizations editor) can support package-manager-distributed or toolchain-scoped skill locations before the setting is removed; until then this stays open as product feedback.
