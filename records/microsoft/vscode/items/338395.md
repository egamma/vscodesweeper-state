# Issue #338395 — Please do not deprecate/remove custom skill locations (`chat.agentSkillsLocations`)

[https://github.com/microsoft/vscode/issues/338395](https://github.com/microsoft/vscode/issues/338395)

## Summary

This is pushback against an already-announced deprecation (`chat.agentSkillsLocations` carries a `markdownDeprecationMessage` saying the setting and the Local agent harness will be removed), not a new ask or a bug — the maintainers have already stated a direction opposite to what the reporters want, so the right outcome is to keep this open as a discussion record rather than close it either way.

## Change summary

Requests that VS Code keep custom skill locations (`chat.agentSkillsLocations`) rather than deprecating/removing them, since they're used to deliver versioned skills/instructions via package managers (npm) without manual copying.

## Best solution

Leave open as a community signal on the deprecation; a maintainer should weigh the npm/package-manager workflow described here against the Agent Customizations editor migration path before the setting is actually removed, and decide whether the migration story needs to support external/generated skill sources.
