# Issue #348307 — Terminal glyphs render extremely small with excessive spacing after Insiders update on macOS arm64; GPU acceleration off fixes it

[https://github.com/microsoft/vscode/issues/348307](https://github.com/microsoft/vscode/issues/348307)

## Summary

The reported WebGL font regression is addressed by a concrete fix already present on main. VS Code now normalizes canvas font assignments before loading the terminal's WebGL renderer, preventing the tiny fallback glyphs.

## Change summary

Terminal GPU rendering produces tiny, widely spaced glyphs after the Insiders update, while disabling GPU acceleration restores normal text.

## Best solution

Treat this as completed by commit 24eb4d0ee2ef46f2dd4918b8e0596801e5296396, which applies a VS Code-side workaround for the Chromium font-parsing regression.
