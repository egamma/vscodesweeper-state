# Issue #325362 — Agents window: redesign the 'needs input' UI (proposal + user testing)

[https://github.com/microsoft/vscode/issues/325362](https://github.com/microsoft/vscode/issues/325362)

## Summary

Keep open for design evaluation: current source still replaces the command-center context with the attention message, continuously pulses session rows, and uses different attention colors. The command-center blink is already finite, but that only partially addresses this team-authored proposal.

## Change summary

Unify needs-input indicators into a calmer, consistent treatment that preserves active-session identity, with user testing to choose the final presentation.

## Best solution

Evaluate the proposed variants against the current Agents window, then agree on a coordinated title-bar, list, and tab treatment that preserves session identity without continuous attention animation. Settle badge-count semantics explicitly rather than treating existing CI inclusion as a decision for the redesign.
