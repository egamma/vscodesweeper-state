# Issue #289294 — Wrong diff is shown after git pull during session

[https://github.com/microsoft/vscode/issues/289294](https://github.com/microsoft/vscode/issues/289294)

## Summary

Keep open: current source still folds overlapping non-agent changes into the chat edit diff, matching the maintainer's explanation of the git-pull symptom. No qualifying fix or verified older duplicate was found; this team-authored report should not be declined as intentional behavior.

## Change summary

Prevent changes pulled from Git during an active chat editing session from being incorrectly included in the agent's edit diff.

## Best solution

Make chat edit attribution preserve unrelated pulled changes without presenting them as agent-authored edits. The chat editing owner should settle how overlapping external changes affect the review baseline while preserving legitimate agent changes.
