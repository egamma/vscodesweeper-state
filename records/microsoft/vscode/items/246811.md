# Issue #246811 — Debug restart missing call to `onDidTerminateDebugSession`

[https://github.com/microsoft/vscode/issues/246811](https://github.com/microsoft/vscode/issues/246811)

## Summary

Keep open in debug: the linked investigation records a missing termination callback during restart, including a mock-debug start/start/end log. Current source forwards termination events without filtering restarts, but the asynchronous lifecycle failure remains undiagnosed; neither a verified fix nor a matching canonical issue was found.

## Change summary

Restarting a debug session whose adapter lacks supportsRestartRequest can omit onDidTerminateDebugSession, leaving the previous Dart test run incorrectly active.

## Best solution

Restore reliable termination notifications for the stop-and-start restart path without changing native adapter restart semantics. Diagnose where adapter shutdown, workbench session termination, or extension-host delivery loses the event before selecting a bounded fix.
