## Summary

Keep open as Copilot workflow feedback: existing browser tools support page reuse and DOM inspection, but those capabilities do not establish the requested early switch to instrumentation when clean sessions fail to reproduce.

Have Copilot prioritize consented instrumentation in the affected browser when repeated clean-session tests provide no useful evidence.

Evaluate an evidence-driven browser-debugging workflow in Copilot's agent guidance, preserving page-sharing approval and isolation restrictions. Distinguish reusing an integrated browser page from accessing an affected external browser profile.
