# Issue #330416 — Do not show promo banner for new users

[https://github.com/microsoft/vscode/issues/330416](https://github.com/microsoft/vscode/issues/330416)

## Summary

Valid, unaddressed request: `ChatPromoNotificationContribution` shows promo notifications purely based on model/harness eligibility with no first-session or new-user deferral. A team member has already engaged with concrete implementation options, so this should stay open and route to the chat area for a product decision.

## Change summary

Suppress the chat promo banner for brand-new users until they've used the product a bit (e.g. sent a few requests or spent some time in a session).

## Best solution

Add a deferral gate in src/vs/workbench/contrib/chat/browser/chatPromoNotification.ts (e.g. skip showing until firstSessionDate/isFirstSession is false, or until some elapsed time/request count), per the two options cwebster-99 already proposed in the thread.
