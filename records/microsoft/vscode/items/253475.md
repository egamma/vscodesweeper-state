# Issue #253475 — trying to bind ctrl+shift+u doesn't work, 'u' is described as "keyincomposition"

[https://github.com/microsoft/vscode/issues/253475](https://github.com/microsoft/vscode/issues/253475)

## Summary

Verified duplicate: this is a specific instance of the keybinding recorder widget being affected by IME/composition events, which is already tracked by the open canonical issue #246197.

## Change summary

Ctrl+Shift+U cannot be bound as a keybinding on Linux because the keybinding recorder interprets the resulting composition event as 'keyincomposition' instead of the intended key chord.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/246197 — fixing the keybinding definition widget to properly handle/ignore composition events will resolve both the IME case and the Linux Ctrl+Shift+U case.
