# Issue #331987 — Agent host client tool is cancelled when the derived request collection reads empty for a tick

[https://github.com/microsoft/vscode/issues/331987](https://github.com/microsoft/vscode/issues/331987)

## Summary

The cancellation remains reproducible from the current source: the host publishes an empty `inputNeeded` collection while transitioning a client tool from confirmation to execution, and the workbench interprets that tick as withdrawal of the request. This should remain open and be routed to the agent-host/chat-tools owners.

## Change summary

Prevent an in-flight agent-host client tool from being cancelled during the confirmation-to-execution request transition.

## Best solution

Keep the client-tool request continuously represented while it changes from confirmation to execution, without weakening cancellation when the host genuinely removes a request. The fix belongs in the session input-needed synchronization path, with a regression test covering every published intermediate state.

## Evidence
