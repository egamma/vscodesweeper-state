## Summary

Keep open: current Command Palette code still orders similar commands by their original TF-IDF scores without an additional relevance pass. This team-authored Backlog request has no verified fix or older canonical reporting the same symptom.

## Change summary

Improve similar-command ranking so a command matching both words in a query can outrank a command repeating only one word.

## Evidence

- **Current ranking path:** src/vs/platform/quickinput/browser/commandsQuickAccess.ts, AbstractCommandsQuickAccessProvider._getPicks, builds one TF-IDF index over all command picks, normalizes scores, retains scores above 0.5, and selects at most five results.
