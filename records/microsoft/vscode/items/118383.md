# Issue #118383 — Can’t debug VS Code extensions on iPadOS PWA

[https://github.com/microsoft/vscode/issues/118383](https://github.com/microsoft/vscode/issues/118383)

## Summary

Keep open as an upstream iPadOS PWA windowing limitation. The maintainer confirmed that launching the extension-development window replaces the original PWA, and current source still requires a separate window; no verified fix resolves that remaining case.

## Change summary

Allow extension debugging from an iPadOS Codespaces PWA without replacing the workspace that launched the debug session.

## Best solution

Preserve both the originating Codespaces workspace and the extension-development host during debugging. The debug owners should reassess current iPadOS standalone-window behavior and determine whether WebKit now supports this flow or whether a supported alternative is needed.
