# Issue #118383 — Can’t debug VS Code extensions on iPadOS PWA

[https://github.com/microsoft/vscode/issues/118383](https://github.com/microsoft/vscode/issues/118383)

## Summary

Keep open as an upstream iPadOS PWA limitation: extension debugging requires a second browser context, while an installed PWA replaces its existing window instead of opening another one. The issue already has the appropriate upstream, debug, and ios-ipados routing labels.

## Change summary

Allow a VS Code extension development host to open while debugging from a Codespaces PWA on iPadOS.

## Best solution

Preserve this as the focused record for iPadOS PWA extension-host debugging until the platform supports multiple PWA windows or VS Code can provide the development host without requiring a second top-level browser context.
