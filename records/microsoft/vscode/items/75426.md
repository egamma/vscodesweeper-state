# Issue #75426 — Breakpoint moves with copy line up/down action

[https://github.com/microsoft/vscode/issues/75426](https://github.com/microsoft/vscode/issues/75426)

## Summary

The behavior is unchanged on current main — Copy Line Down inserts the copy at the original position, causing breakpoints and other decorations to follow the displaced line. Two team members disagree on whether this is as-designed or a bug, and the issue is correctly labeled under-discussion. Stays open.

## Change summary

Breakpoints (and other line-associated data) move to the copied line instead of staying on the original line when using Copy Line Up/Down.

## Best solution

Decide whether CopyLinesCommand should insert the duplicate above/below such that decorations remain on the original line, or whether a deeper mechanism to clone line-associated data is needed. The fix would be in `src/vs/editor/contrib/linesOperations/browser/copyLinesCommand.ts` (or equivalent) — the insertion direction determines which line inherits the tracked positions. A team decision is needed since two members (alexdima and hediet) expressed opposing views.
