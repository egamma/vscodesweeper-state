# Issue #3884 — Revisit VS Code folder structure for app data, settings, extensions

[https://github.com/microsoft/vscode/issues/3884](https://github.com/microsoft/vscode/issues/3884)

## Summary

This remains the canonical, highly supported request for separating VS Code configuration, durable data, extensions, and disposable caches according to platform conventions. Current main only partially supports XDG paths, so the central gap remains.

## Change summary

Reorganize VS Code's per-user directories by purpose and platform, with migration from existing locations.

## Best solution

Define separate platform-aware configuration, data, cache, and extension roots in the environment service, then migrate existing installations without breaking CLI overrides or portable mode. Narrower XDG issues should remain linked to this canonical design effort.
