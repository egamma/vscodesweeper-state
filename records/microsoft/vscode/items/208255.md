# Issue #208255 — Auto-load workspace file if it is the only workspace file in the folder root

[https://github.com/microsoft/vscode/issues/208255](https://github.com/microsoft/vscode/issues/208255)

## Summary

Keep this accepted Backlog request open: it has 45 community upvotes, and current main still only prompts rather than automatically opening the sole workspace file.

## Change summary

Allow a repository to automatically open its sole root-level `.code-workspace` file when users open the folder.

## Best solution

Add a carefully scoped opt-in to `WorkspacesFinderContribution` that opens a single root workspace automatically while preserving selection behavior for multiple workspace files and avoiding reopen loops.
