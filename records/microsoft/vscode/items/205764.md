# Issue #205764 — Opening an additional issue reporter doesn't work

[https://github.com/microsoft/vscode/issues/205764](https://github.com/microsoft/vscode/issues/205764)

## Summary

Still present on main for the legacy issue reporter path (the default): `hasToReload()` in `issueFormService.ts` silently focuses the existing window without updating its data when a second `openIssueReporter` call arrives. The new wizard path (editor pane) would handle re-opening naturally, but the wizard is behind an experiment flag and off by default.

## Change summary

Opening a second issue reporter (e.g. from an extension) while one is already open silently does nothing — no warning, no data update.

## Best solution

In the legacy issue reporter path, when `hasToReload()` detects an existing window, either prompt the user to overwrite the current data and re-render, or close-and-reopen with the new data. The wizard editor-pane path already sidesteps this by using `editorService.openEditor`. Once the wizard becomes the default, this issue is largely moot for desktop — but the web legacy path would still need a fix. Alternatively, accelerating the wizard rollout would resolve this organically.
