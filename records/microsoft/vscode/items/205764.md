# Issue #205764 — Opening an additional issue reporter doesn't work

[https://github.com/microsoft/vscode/issues/205764](https://github.com/microsoft/vscode/issues/205764)

## Summary

The silent refocus path remains in the current legacy issue reporter: opening it again with extension details returns without updating the form or warning the user. Keep this team-authored, accepted bug open; the linked replacement proposal was closed without merging.

## Change summary

Opening an extension issue reporter while the basic reporter is open should provide feedback rather than silently ignore the supplied details.

## Best solution

Make repeated opens explicitly acknowledge the existing reporter and preserve its draft; if replacement is offered, require confirmation before displaying the new extension details. This belongs in the issue reporter service's existing-window handling.
