# Issue #336579 — Extension that runs inline code with instant feedback, displaying runtime values in your editor as you type.

[https://github.com/microsoft/vscode/issues/336579](https://github.com/microsoft/vscode/issues/336579)

## Summary

Requests a Quokka.js-style inline runtime value overlay for many languages, built into core — but this exact capability already exists and thrives as third-party extensions, which is strong precedent that it belongs there, not in core.

## Change summary

Add a built-in feature that shows live runtime values (print output, return values, identifiers) inline in the editor as you type, across many languages.

## Best solution

Point the reporter at existing extensions (e.g. Quokka.js, or CodeTour/Runner-style tools) that already deliver this; the capability is fully buildable via the existing extension API (inline decorations, language runtimes) and doesn't need to live in core.

## Vision fit

- **Fit:** rejected
- **Reason:** This is a heavyweight, language-specific runtime-execution feature that would add significant surface and complexity to the default editor, cutting against the 'lightweight text editor out of the box' value and the 'power lives in extensions' principle — and it's already proven out as an extension.
- **Evidence:** Values: 'Out of the box, VS Code is a text editor: lightweight and fast... The power lives in extensions.'
