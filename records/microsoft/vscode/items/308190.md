# Issue #308190 — Dark2026  insufficient syntax highlighting of search results

[https://github.com/microsoft/vscode/issues/308190](https://github.com/microsoft/vscode/issues/308190)

## Summary

Keep open as theme polish: current 2026 Dark still gives the active and other search matches the same base color with only a small opacity difference. Color customization offers a workaround, but does not address the requested improvement to the built-in defaults.

## Change summary

Make the current search match clearly distinguishable from other matches in the built-in 2026 Dark theme, including multiple matches on one line.

## Best solution

Improve the active-match visual hierarchy in extensions/theme-defaults/themes/2026-dark.json using the existing search-match color tokens, while preserving text readability and other themes. The theme owner should settle the intended contrast treatment before implementation.
