# Issue #277083 — git blame info in wrong place

[https://github.com/microsoft/vscode/issues/277083](https://github.com/microsoft/vscode/issues/277083)

This is the same line-deletion rendering defect already tracked by the verified, older open issue https://github.com/microsoft/vscode/issues/246105. Consolidate there, preserving this report's empty-line reproduction and GitLens comparison.

## Change summary

Deleting an empty line with Ctrl+Shift+K moves the built-in inline Git blame annotation ahead of the following line's code.

## Best solution

Resolve the editor-decoration positioning defect tracked by https://github.com/microsoft/vscode/issues/246105 so inline blame remains after code when deleting lines; carry this report's reproduction details into that discussion.
