# Issue #341390 — Assisted Permissions mode in Enterprise Managed environments not working alongside `disableBypassPermissionsMode`

[https://github.com/microsoft/vscode/issues/341390](https://github.com/microsoft/vscode/issues/341390)

## Summary

Team-authored, freshly filed bug with clear steps and an expected-behavior table. The flag that bypasses the Assisted judge comes from the Copilot SDK/runtime, so the root cause could not be confirmed from this checkout. Keep open.

## Change summary

With an enterprise policy that has deny rules, ordinary commands like `ls` get an implicit default-ask. That flags the call as requiring managed approval, which skips the Assisted-mode judge and prompts the user.

## Best solution

The runtime/SDK should treat implicit default-ask the same as an explicit ask in Assisted mode (judge first, then ask the user). If it keeps setting managedApprovalRequired for that case, the agent host should stop letting that flag bypass the judge for implicit asks.
