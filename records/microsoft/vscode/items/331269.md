# Issue #331269 — no workspace differentiation for paths in a permission widget

[https://github.com/microsoft/vscode/issues/331269](https://github.com/microsoft/vscode/issues/331269)

## Summary

Keep open: current source still displays basename-only file references in permission confirmations, leaving identical hook filenames ambiguous across workspace folders. The existing hover provides additional context, but does not satisfy the request for differentiation in the visible permission widget.

## Change summary

Make file-creation permission confirmations identify the destination workspace folder in multi-root workspaces.

## Best solution

Show enough workspace-folder and path context in the permission confirmation to distinguish identically named hook files before approval, including for keyboard and screen-reader users. Keep permission enforcement, resource destinations, and unrelated chat-reference presentation unchanged.
