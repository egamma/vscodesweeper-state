# Issue #331269 — no workspace differentiation for paths in a permission widget

[https://github.com/microsoft/vscode/issues/331269](https://github.com/microsoft/vscode/issues/331269)

## Summary

Team-authored, already correctly labeled (polish/under-discussion/agent-host); a real gap remains in the permission/confirmation widget for multi-root workspaces, and no fixing commit exists yet on main, so this stays open.

## Change summary

In a multi-root workspace, the agent's file-creation permission/confirmation widget doesn't indicate which workspace folder the file will be created in, so approving is ambiguous when multiple workspaces share the same relative path.

## Best solution

Extend the tool confirmation UI (chatConfirmationWidget.ts / chatConfirmationContentPart.ts and the relevant edit/create-file tool confirmation payload) to include the owning workspace folder name alongside the relative path when more than one root is open — likely surfaced via the same path-rendering helper used elsewhere for multi-root labels.
