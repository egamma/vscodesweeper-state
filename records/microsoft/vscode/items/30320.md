# Issue #30320 — Cannot move last cursor position when using multi-cursor

[https://github.com/microsoft/vscode/issues/30320](https://github.com/microsoft/vscode/issues/30320)

## Summary

A real capability gap remains: current keyboard commands can change which cursor is primary, but cannot move only the last-added cursor while preserving the others. Keep this Backlog request open under discussion.

## Change summary

Add a keyboard command for moving the last-added cursor independently within a multi-cursor selection.

## Best solution

Add directional commands that operate only on the last-added or focused cursor, likely alongside the multicursor actions in `src/vs/editor/contrib/multicursor/browser/multicursor.ts`, while leaving all other cursor positions unchanged.

## Evidence
