# Issue #298732 — Nudge mac users to install code command if not present

[https://github.com/microsoft/vscode/issues/298732](https://github.com/microsoft/vscode/issues/298732)

## Summary

The existing installation command covers installation, not the requested detection and discovery flow. Keep this team-authored request open; the timing and persistence of the nudge need a product decision.

## Change summary

Detect when the macOS code command is unavailable on PATH and offer a discoverable route to install it.

## Best solution

Provide a restrained, dismissible macOS onboarding experience that detects CLI availability and leads into the existing installation command without changing installation or privilege-consent behavior.
