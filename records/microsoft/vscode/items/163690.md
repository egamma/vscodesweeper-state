# Issue #163690 — Slow updates on Debian GNU/Linux

## Summary

Still unfixed on main — the debian postinst/postrm scripts still call `update-mime-database` without `-n`. An open PR (#318436) addresses this but has not merged yet.

## Change summary

VS Code's Debian package install/update is slow because `update-mime-database` runs a full rebuild every time, even when nothing changed.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/318436 which adds `-n` to the `update-mime-database` calls in the Debian and RPM packaging scripts, avoiding unnecessary rebuilds.
