# Issue #335396 — Agents window: support window.title (or equivalent) for the center title bar text

[https://github.com/microsoft/vscode/issues/335396](https://github.com/microsoft/vscode/issues/335396)

## Summary

Well-diagrammed and technically accurate request: the Agents window title bar intentionally omits `window.title` rendering, per the code comment in titlebarPart.ts. It's a reasonable ask for a brand-new Preview surface, but needs a maintainer product decision on how (or whether) to extend window identification theming to the title text.

## Change summary

Extend `window.title` (or a new dedicated setting) to the Agents window's center toolbar text so multi-profile users can visually distinguish Agents windows the way they already can with `agents.background`/`agentsPanel.foreground` theming.

## Best solution

A sessions-window maintainer should decide whether to wire `WindowTitle` (or a subset of its variables) into `src/vs/sessions/browser/parts/titlebarPart.ts`, or introduce a dedicated `agents.window.title`-style setting; this is a design/product call for the still-young Agents window feature, not something to resolve unilaterally here.
