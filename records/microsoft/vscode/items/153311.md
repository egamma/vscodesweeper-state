# Issue #153311 — Git - Lots of vscode socket files left in /tmp when using SSH

[https://github.com/microsoft/vscode/issues/153311](https://github.com/microsoft/vscode/issues/153311)

## Summary

Keep open for investigation of remote socket cleanup and the multi-user permissions concern. The discussion independently confirms leftover sockets after shutdown, and neither the historical fixes nor the related workaround establishes that the full report is resolved.

## Change summary

Prevent obsolete Git and core IPC socket files from accumulating after remote SSH sessions, and assess their permissions on shared Linux hosts.

## Best solution

Establish lifecycle ownership and safe cleanup for Git and core IPC sockets, distinguishing abandoned files from listeners belonging to surviving remote processes. Have a maintainer assess the permissions concern separately; Pyright temporary directories have different ownership and should not determine the disposition of the core socket report.
