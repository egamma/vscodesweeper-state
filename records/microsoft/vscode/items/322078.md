# Issue #322078 — Ctrl-Clicking a link in the terminal opens the file path on the line above instead

[https://github.com/microsoft/vscode/issues/322078](https://github.com/microsoft/vscode/issues/322078)

## Summary

Real bug in the terminal multi-line link detector: its `lineNumberPrefixMatchers` regex falsely matches timestamps (e.g. `10:44:38`) as line:col references, then scans up to find a valid file path on the previous line. Since this detector has higher priority than the URI link detector, it shadows the actual URL on the same line.

## Change summary

Ctrl-clicking a URL in terminal output opens a file path from the line above when the current line starts with a timestamp that matches the multi-line link detector's regex.

## Best solution

Fix the `lineNumberPrefixMatchers` regex in `src/vs/workbench/contrib/terminalContrib/links/browser/terminalMultiLineLinkDetector.ts` to reject matches that look like timestamps (e.g. when the match has more than one colon-separated group of digits, or the line continues with non-whitespace after the line:col prefix in a way that doesn't match known compiler/linter output patterns). Additionally, the buffer range should probably not span the entire line, as that shadows other valid link types on the same line.

## Evidence

- **regex false positive:** The regex `/^ *(?<link>(?<line>\d+):(?<col>\d+)?)/` in terminalMultiLineLinkDetector.ts line 36 matches timestamps like `10:44:38` — it captures `10:44` as line=10, col=44.
- **priority shadowing:** In terminalLinkManager.ts lines 82–86, TerminalMultiLineLinkDetector is registered before TerminalUriLinkDetector, so it wins when both produce links.
- **full-line buffer range:** terminalMultiLineLinkDetector.ts lines 121–126 set the buffer range to the entire line (`endColumn: 1 + text.length`), covering any URL that might exist elsewhere on the line.
- **upward scan finds file:** Lines 99–110: the detector scans upward and stops at the first line not starting with digits — if that line happens to be a valid file path, it creates a link to it.
