# Issue #196759 — SCM - Gutter diff provider selection when multiple providers available

[https://github.com/microsoft/vscode/issues/196759](https://github.com/microsoft/vscode/issues/196759)

## Summary

The central request is implemented: the editor gutter's Diff Decorations submenu lets users toggle individual quick diff providers independently of SCM selection. Propose closing as completed; settings-based configuration is tracked separately.

## Change summary

Allow users to choose which quick diff providers contribute editor gutter decorations when multiple SCM providers overlap.

## Best solution

Use the shipped Diff Decorations submenu to hide unwanted providers and retain the desired provider's gutter markers. Keep settings-based configuration in https://github.com/microsoft/vscode/issues/249184 and API finalization in https://github.com/microsoft/vscode/issues/169012.
