# Issue #339439 — Copilot CLI agent session: view tool returns only text for images, model never receives image data

[https://github.com/microsoft/vscode/issues/339439](https://github.com/microsoft/vscode/issues/339439)

## Summary

Keep open: the `view` tool that drops image bytes before they reach the model is a built-in tool exposed by the `@github/copilot-sdk` dependency (pinned in package.json at 1.0.17-preview.0), not something this repository's Agent Host code constructs — the vscode-side code only maps/displays the SDK's emitted tool-result events for UI purposes.

## Change summary

In a Copilot CLI agent session, the `view` tool's result for an image file is a 31-character text receipt with no image content part, so the model never receives the image bytes (workaround: attach the image directly to the prompt).

## Best solution

Fix belongs upstream in `@github/copilot-sdk`'s `view` tool implementation, which must include an image content part in the tool result sent to the model (as the SDK's `view_image` tool and the classic Chat view's `view_image` tool already do). Once the SDK ships a fix, bump the `@github/copilot-sdk` dependency version here.
