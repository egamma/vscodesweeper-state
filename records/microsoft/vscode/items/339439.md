# Issue #339439 — Copilot CLI agent session: view tool returns only text for images, model never receives image data

[https://github.com/microsoft/vscode/issues/339439](https://github.com/microsoft/vscode/issues/339439)

## Summary

Real, well-diagnosed regression specific to BYOK models in Copilot CLI agent sessions where the `view` tool's image result is dropped before reaching the model. An open PR (#339830) already targets this exact fix, so it should land there rather than being closed here; the related issue (#339595) is both closed and numerically younger, so it cannot serve as a duplicate canonical.

## Change summary

In a Copilot CLI agent session with a BYOK model that supports image input, the `view` tool's image content is replaced by a 31-character text receipt and never reaches the model, unlike the classic Chat view's `view_image` tool.

## Best solution

Land https://github.com/microsoft/vscode/pull/339830 ("agentHost: forward tool-result images to BYOK models"), which appears to directly address this regression by forwarding tool-result images to BYOK model requests.
