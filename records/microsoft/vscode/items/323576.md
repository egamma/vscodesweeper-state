# Issue #323576 — context window and reasoning picker are gone after switch back from ahp copilot to local harness.

[https://github.com/microsoft/vscode/issues/323576](https://github.com/microsoft/vscode/issues/323576)

## Summary

The bug remains source-reproducible on current main: the ordinary Agents composer does not enable the provider-scoped model-configuration adapter, so context-window and reasoning controls disappear or lose their state during handoff. The newer https://github.com/microsoft/vscode/issues/337876 documents the same root cause, but it is younger than this re-reviewed issue and therefore cannot be its duplicate canonical.

## Change summary

Preserve the context-window and reasoning configuration controls when handing a session back from the Agent Host Copilot harness to the local harness.

## Best solution

Connect the ordinary Agents composer model picker to the session provider's model-configuration access, then cover harness and draft-to-running handoffs with a regression test that verifies both picker visibility and configuration persistence.
