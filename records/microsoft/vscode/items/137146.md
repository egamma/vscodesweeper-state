# Issue #137146 — "Don't show again" button does not work and is misleading

[https://github.com/microsoft/vscode/issues/137146](https://github.com/microsoft/vscode/issues/137146)

## Summary

Keep open: the built-in Git warning still offers an unqualified “Don't Show Again” action that saves only workspace settings. The suppression works within its scope, but the wording does not communicate that scope.

## Change summary

Make the Git large-change warning's dismissal wording accurately describe whether suppression applies to the current workspace or all workspaces.

## Best solution

Make the action's promised scope match its persisted effect in the built-in Git extension. Explicit workspace-scoped wording would preserve current behavior; global suppression remains available through the user setting git.ignoreLimitWarning.
