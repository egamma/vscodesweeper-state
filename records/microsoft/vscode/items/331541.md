# Issue #331541 — Allow creator sessions to answer child input requests

[https://github.com/microsoft/vscode/issues/331541](https://github.com/microsoft/vscode/issues/331541)

## Summary

Keep open: current session tools can message another conversation but cannot submit a typed answer to its pending input request. The related merged PRs explicitly leave this capability to this issue; the older orchestration issue does not report the same missing response behavior.

## Change summary

Let a creator conversation answer a delegated child's active input request through a validated, provider-neutral tool without bypassing user approvals.

## Best solution

Provide a typed response flow that completes the exact child's pending request, rejects invalid or stale answers, and preserves explicit user confirmation. Reconcile the requested creator-coordination policy with the current chat-addressed delegation model before implementation.

- **Behavior:**

  > A creator conversation can discover sufficient structured context and answer a supported active input request in its delegated child without opening that child.
