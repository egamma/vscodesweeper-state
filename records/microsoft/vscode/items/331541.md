Fresh, team-authored feature request (same day, no traction yet) proposing a typed orchestration tool so a creator session can answer a delegated child session's pending input request; already correctly labeled feature-request/agents, and it's tied to active, related orchestration work, so it stays open for normal development.

## Change summary

Add a typed orchestration tool letting a creator agent session respond directly to a child session's active input request instead of having to open the child session.

## Best solution

Implement as a new orchestration tool alongside the cross-session delegation/notification work in src/vs/platform/agentHost (building on the existing ChatInputRequest / respondToUserInputRequest flow in copilotAgentSession.ts), targeting a specific child session + request id, validating the answer against the request's question type, and respecting coordinateWithCreator policy.
