## Summary

Keep open: the Configure Tools capability does not resolve this report about inconsistent selection and misleading tool references. Selection handling has changed since the report, but the supplied toolset and prompt suffice to retest; current source still contains the placeholder and toolset-reference paths implicated here.

## Change summary

Custom toolsets can disagree with built-in tool selections, while editing references presented to the model do not match its callable tools.

## Best solution

Diagnose these together across workbench tool selection and Copilot prompt construction without removing intentional model-specific editing-tool selection.
