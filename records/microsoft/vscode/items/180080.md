# Issue #180080 — Notebook cell language selection UI doesn't use custom language icons

[https://github.com/microsoft/vscode/issues/180080](https://github.com/microsoft/vscode/issues/180080)

## Summary

Still reproduces on main: the notebook cell language picker uses `getIconClasses` with a fake resource URI, which resolves file-icon-theme icons but not custom language icons contributed via `languages[].icon` in extension manifests. An open PR (#282367) is attempting to fix this.

## Change summary

Notebook cell language picker shows the default icon instead of custom language icons contributed by extensions.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/282367 (or equivalent fix) that switches to `getIconClassesForLanguageId` so the picker resolves language icons contributed via `languages[].icon` in extension manifests.
