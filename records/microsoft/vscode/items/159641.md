# Issue #159641 — Submenu should use `shortTitle` or be configurable to do so

[https://github.com/microsoft/vscode/issues/159641](https://github.com/microsoft/vscode/issues/159641)

## Summary

Keep this accepted Backlog request open: editor context submenus still use full command titles, and extensions cannot request short titles for those placements. The maintainer acknowledged this gap; no verified open canonical or completed implementation was found.

## Change summary

Allow submenu commands to display their existing shortTitle while retaining descriptive full titles in the Command Palette.

## Best solution

Support concise command labels in context submenus using command-owned shortTitle metadata, without introducing arbitrary placement-specific titles. A maintainer should choose between automatic submenu selection and an explicit contribution option, and document which menu surfaces use each title.
