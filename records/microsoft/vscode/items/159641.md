# Issue #159641 — Submenu should use `shortTitle` or be configurable to do so

[https://github.com/microsoft/vscode/issues/159641](https://github.com/microsoft/vscode/issues/159641)

## Summary

The extension API gap remains on current main: editor context submenus still render command titles without requesting `shortTitle`. The issue is already correctly classified and routed, so it should remain open.

## Change summary

Allow submenu command entries to render their contributed `shortTitle` instead of the full command title.

## Best solution

Define when submenu surfaces use `shortTitle`, preferably making editor context submenus request it consistently; if that cannot be inferred safely, expose an explicit submenu option while preserving full titles in the command palette.
