# Issue #342507 — `MCP: Open User Configuration` should offer all user locations

[https://github.com/microsoft/vscode/issues/342507](https://github.com/microsoft/vscode/issues/342507)

## Summary

The requested harness-aware configuration picker is still missing: the command opens only the current VS Code profile's MCP file. Existing migration and add-server flows provide partial access to other locations, but do not fulfill this command's requested behavior.

## Change summary

Make MCP: Open User Configuration offer all valid user configuration locations for the active harness, with recommendation and existence indicators, file creation, and access to MCP customizations.

## Best solution

Provide a harness-aware user-location picker for workbench.mcp.openUserMcpJson that retains access to the legacy profile file, prioritizes the recommended location, includes missing files with explicit creation behavior, and links to MCP customizations. Consider exposing the same command from the customization interface without changing workspace configuration commands.
