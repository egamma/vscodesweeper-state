# Issue #232741 — terminal history does not work or gets wrong version of fish_history - Linux Snap

[https://github.com/microsoft/vscode/issues/232741](https://github.com/microsoft/vscode/issues/232741)

## Summary

This is a specific symptom of the XDG_DATA_HOME override in the snap launch script, which is the same root cause tracked by the open canonical issue #237608. The fish shell picks up the wrong history file because snap redirects XDG_DATA_HOME to a snap-local path.

## Change summary

Fish shell history in the VS Code snap terminal shows wrong (bash) history content because XDG_DATA_HOME is overridden to a snap-local path.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/237608 which tracks the XDG_DATA_HOME override removal. A fix branch (`robo/revert_xdg_data_home_overriding`) exists but hasn't merged yet — landing it resolves this issue along with trash and font misconfigurations.
