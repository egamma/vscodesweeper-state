# Issue #172299 — Trust UI should better differentiate selected and tabbed 

[https://github.com/microsoft/vscode/issues/172299](https://github.com/microsoft/vscode/issues/172299)

## Summary

Keep open: a maintainer confirmed the selection-versus-keyboard-focus confusion, and current source still uses matching colors in the Modern themes. The trust editor's styling has since changed, so the supplied trusted/untrusted scenarios should be retested visually before declaring this team-authored report resolved.

## Change summary

Make the current workspace trust state visually distinguishable from keyboard focus on the opposite trust card, including when the action buttons are below the viewport.

## Best solution

Ensure the workspace trust editor communicates persistent trust state separately from keyboard focus across dark, light, and high-contrast themes. Retest both directions with the buttons outside the viewport, preserving keyboard navigation and trust-changing behavior.
