# Issue #281696 — ctrl + shift + 1 replace causes error messages

[https://github.com/microsoft/vscode/issues/281696](https://github.com/microsoft/vscode/issues/281696)

## Summary

The primary reported error — 'service accessor is only valid during the invocation of its target method' — was fixed on main and shipped. The `performReplace` function in searchActionsRemoveReplace.ts was using a stale `ServicesAccessor` after `await` calls; commit 3f2c82db55c corrected this by extracting `IInstantiationService` before the awaits and wrapping post-await service access in `invokeFunction`.

## Change summary

Using Ctrl+Shift+1 to replace a search match via keyboard triggered 'service accessor is only valid' errors because the action's ServicesAccessor was used after async gaps.

## Best solution

Keep the shipped fix. The stale-accessor bug is resolved; the secondary 'element' error on last-match replace is a minor edge case that can be tracked separately if it still reproduces.
