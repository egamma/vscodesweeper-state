# Issue #295863 — Welcome page and chat open one first open

[https://github.com/microsoft/vscode/issues/295863](https://github.com/microsoft/vscode/issues/295863)

## Summary

Keep open: maintainers confirmed the duplicate chat surfaces and agreed they should be mutually exclusive. Current source still limits startup suppression to new workspaces, and the linked fix attempt was closed without merging.

## Change summary

Prevent the Agent Sessions Welcome page and the standalone Chat view from displaying duplicate chat interfaces simultaneously.

## Best solution

Honor the agreed mutual-exclusion behavior when either surface is opened, including experiment activation after initial startup and explicit Chat toggles. Preserve ongoing chat sessions and unrelated editors rather than treating this solely as a fresh-workspace layout default.
