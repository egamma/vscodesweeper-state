# Issue #350701 — Should provide option for "Set next statement" to set the current debug point

[https://github.com/microsoft/vscode/issues/350701](https://github.com/microsoft/vscode/issues/350701)

## Summary

The requested capability already exists as Debug: Jump to Cursor, with Set Next Statement as a Command Palette alias. Its availability intentionally depends on the active debugger supporting execution relocation.

## Change summary

Provide an editor context-menu action that moves the next execution point without executing intervening code.

## Best solution

Use the existing debug.jumpToCursor command with a supporting debugger; no additional core action is needed. The report does not identify a debugger-specific gap.

  > Thanks for the request. VS Code already provides this through **Debug: Jump to Cursor** (`debug.jumpToCursor`) in the editor context menu; **Debug: Set Next Statement** is also available in the Command Palette. While paused, select the target location to skip intervening code without executing it. These actions appear only when the active debugger supports changing the execution location.
