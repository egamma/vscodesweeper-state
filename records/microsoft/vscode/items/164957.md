# Issue #164957 — "Load More Stack Frames" is incorrectly displayed after debug adapter has sent the full stack

[https://github.com/microsoft/vscode/issues/164957](https://github.com/microsoft/vscode/issues/164957)

## Summary

The report contains a credible protocol-level reproduction, and the maintainer agreed that identical frame IDs expose behavior that should be handled better. The Backlog milestone does not block reassessment, but there is no cited fix or verified canonical issue supporting closure.

## Change summary

After continuing to another breakpoint with stable stack-frame IDs, the Call Stack view can retain a stale “Load More Stack Frames” entry after the adapter has returned every frame.

## Best solution

Ensure a top-of-stack refresh notifies the Call Stack view when stack completeness changes, even if the refreshed frames compare equal to the previous stack, while preserving normal incremental stack loading.
