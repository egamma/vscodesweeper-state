# Issue #310360 — UI: Separate "Delete Cell" icon from "More Actions" menu in Notebooks.

[https://github.com/microsoft/vscode/issues/310360](https://github.com/microsoft/vscode/issues/310360)

## Summary

Valid UX polish request to reduce accidental cell deletion by increasing visual/spatial separation between the delete icon and the more-actions menu. The delete button already has its own dedicated toolbar (separate from the title toolbar), but both render adjacent in the same container — the spatial proximity is the concern.

## Change summary

Move the notebook cell delete icon further from the more-actions menu (or into it) to reduce accidental clicks.

## Best solution

Route to the notebook area owner to evaluate whether increasing the gap, reordering, or nesting the delete action inside the overflow menu would reduce misclicks without harming discoverability. The implementation lives in `src/vs/workbench/contrib/notebook/browser/view/cellParts/cellToolbars.ts` (the `deleteToolbar` placement) and `MenuId.NotebookCellDelete`.
