# Issue #310360 — UI: Separate "Delete Cell" icon from "More Actions" menu in Notebooks.

[https://github.com/microsoft/vscode/issues/310360](https://github.com/microsoft/vscode/issues/310360)

## Summary

The requested separation remains absent from current source, and existing notebook settings do not provide it. Keep this open for a notebook-toolbar design decision: earlier discussion explains the deliberate placement for repeated deletion, but does not conclusively reject every safer arrangement.

## Change summary

Separate Delete Cell from More Actions, or place deletion inside the overflow menu, to reduce accidental pointer activation.

## Best solution

Choose a notebook-cell toolbar arrangement that distinguishes destructive deletion from menu access while preserving efficient repeated deletion and keyboard access. Evaluate that tradeoff against the earlier maintainer discussion before changing the default layout.
