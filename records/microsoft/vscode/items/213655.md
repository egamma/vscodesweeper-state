# Issue #213655 — Notebook does not clear dirty indicator after saving

[https://github.com/microsoft/vscode/issues/213655](https://github.com/microsoft/vscode/issues/213655)

## Summary

Valid unfixed bug: the notebook dirty indicator persists after save when a notebook.format code action modifies content during the save flow. No fix commit references this issue and the underlying mechanism still appears susceptible on main.

## Change summary

Notebook dirty indicator does not clear after saving when a notebook.format code action is configured as a save participant.

## Best solution

The save flow in the notebook working copy model needs to re-snapshot or re-hash content after save participants (like notebook.format) have modified cells, so the post-save state matches what was actually written to disk. The fix likely belongs in `src/vs/workbench/contrib/notebook/common/notebookEditorModel.ts` or in how `src/vs/workbench/contrib/notebook/browser/contrib/saveParticipants/saveParticipants.ts` interacts with the working copy lifecycle.
