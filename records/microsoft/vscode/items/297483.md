# Issue #297483 — Provide way to understand why a given chat operation was approved

[https://github.com/microsoft/vscode/issues/297483](https://github.com/microsoft/vscode/issues/297483)

## Summary

Implemented on current main: completed tool calls now explain whether approval came from a setting or a session/workspace/profile approval, including bypass/auto-approve mode.

## Change summary

Show why an individual chat tool operation ran without prompting, such as session approval or global auto-approve mode.

## Best solution

Keep the shipped inline approval explanation on each affected tool call, with links to the relevant setting or approval editor; this provides the requested provenance without requiring a separate hover.
