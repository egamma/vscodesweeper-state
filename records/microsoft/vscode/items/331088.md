# Issue #331088 — Commit message generation customization has regressed

[https://github.com/microsoft/vscode/issues/331088](https://github.com/microsoft/vscode/issues/331088)

## Summary

This matches an already well-documented, open issue: commit message generation silently fails (spinner spins, no message) whenever `github.copilot.chat.commitMessageGeneration.instructions` is set, and works again once the setting is removed — this is the exact symptom and workaround already tracked by an open, heavily-confirmed report.

## Change summary

Enabling custom commit-message-generation instructions makes 'Generate Commit Message' silently fail (spinner briefly spins, then nothing); removing the instructions restores normal behavior.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316204, which tracks the same 'promptFiltered (422)' failure triggered by commit-message custom instructions — multiple commenters there reproduce with plain ASCII/English instruction text and confirm removing the setting fixes it, and it in turn points to https://github.com/microsoft/vscode/issues/316002 as the likely root-cause content-filter over-triggering.
