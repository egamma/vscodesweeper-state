## Summary

Two independent reporters describe the same symptom (Copilot's 'Generate Commit Message' spinner stops with no result when commit-message custom instructions are configured), but neither report includes logs, the exact instructions used, extension/model version, or a traced failure — I could not pin the regression to a specific code change in extensions/copilot/src/extension/prompt or the customInstructions pipeline from static reading alone.

## Change summary

Copilot's commit message generation silently fails to produce a message when 'github.copilot.chat.commitMessageGeneration.instructions' (or similar custom instructions) is set, but works when the custom instructions are removed.
