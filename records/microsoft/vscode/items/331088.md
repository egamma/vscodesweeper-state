# Issue #331088 — Commit message generation customization has regressed

[https://github.com/microsoft/vscode/issues/331088](https://github.com/microsoft/vscode/issues/331088)

## Summary

Real regression: generating a commit message with `chat.commitMessageGeneration.instructions` set silently fails (spinner stops, no message, no error) while it works with instructions removed. Two independent reporters confirm it, and a workaround (overriding `chat.utilitySmallModel`) fixes it for at least one — pointing at the default `copilot-utility-small` model (gpt-4o-mini, per extensions/copilot/src/platform/endpoint/node/copilotChatEndpoint.ts) struggling once custom instructions are appended to the commit-message prompt.

## Change summary

Copilot's 'Generate Commit Message' silently produces nothing when custom commit-message instructions are configured, but works fine without them.

## Best solution

Someone owning extensions/copilot/src/extension/prompt/node/gitCommitMessageGenerator.ts and gitCommitMessagePrompt.tsx should investigate why adding custom instructions makes the default copilot-utility-small model (gpt-4o-mini) fail — a token-limit/format issue is the leading theory given the utilitySmallModel override workaround — and also fix that GitCommitMessageGenerator.generateGitCommitMessage swallows any non-success fetch (returns undefined with no notificationService call), so users get a silent no-op instead of an actionable error.
