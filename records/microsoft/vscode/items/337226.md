## Change summary

serve-web / code-server render a silent blank white page (no actionable error) when an edge proxy (e.g. Cloudflare Rocket Loader) rewrites inline bootstrap `<script>` tags, because the per-request CSP nonce/hash introduced in commit 90c5812 no longer tolerates proxy-rewritten markup the way the old static nonce did.
