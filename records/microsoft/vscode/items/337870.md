# Issue #337870 — Allow configuring max lines and height for Chat Sticky Scroll (e.g., chat.stickyScroll.maxLineCount)

[https://github.com/microsoft/vscode/issues/337870](https://github.com/microsoft/vscode/issues/337870)

## Summary

The exact one-line behavior has changed on current main, which now clamps sticky prompts to two lines, but the requested configurability and adjustable pinning behavior remain absent. No older issue found owns this full request, so it should remain open as a feature request.

## Change summary

Allow users to configure the visible height and activation behavior of pinned prompt headers in Chat Sticky Scroll.

## Best solution

The chat UX owners should decide on a bounded chat-specific control for sticky prompt height and whether the header should remain hidden while its source prompt is still visibly adjacent, without copying editor sticky-scroll settings that do not map cleanly to chat.
