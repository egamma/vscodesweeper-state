# Issue #337870 — Allow configuring max lines and height for Chat Sticky Scroll (e.g., chat.stickyScroll.maxLineCount)

[https://github.com/microsoft/vscode/issues/337870](https://github.com/microsoft/vscode/issues/337870)

## Summary

Reasonable ask for the new prompt-timeline sticky header, but it's a fresh, zero-upvote report with two bundled design questions (line-count/height control, and pinning-threshold behavior) that a maintainer would need to weigh before any change; nothing on main covers it yet.

## Change summary

Add a setting like chat.stickyScroll.maxLineCount to control the pinned chat prompt header's line count/height, and reconsider when the header should stay pinned vs. hide if the actual prompt is already visible.

## Best solution

If pursued, extend PromptTimelineStickyHeader (currently a fixed single-line label) with an optional line-count/height setting analogous to editor.stickyScroll.maxLineCount, and decide the pinning-visibility heuristic separately — but this needs product buy-in first since it's a new, unrequested customization surface for a young feature.
