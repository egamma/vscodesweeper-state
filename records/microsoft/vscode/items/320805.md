# Issue #320805 — `reasoningEffort` setting is applied to the wrong custom endpoint

[https://github.com/microsoft/vscode/issues/320805](https://github.com/microsoft/vscode/issues/320805)

## Summary

Fixed on main: model configuration updates now resolve the provider group that owns the selected model instead of using the first group sharing its vendor.

## Change summary

Changing reasoning effort for one custom endpoint writes the setting into another endpoint when multiple groups share the `customendpoint` vendor.

## Best solution

Keep the model-to-provider-group resolution introduced by commit fa3b663f7234b8a6965d921bbe2f855c13e54a17, including its regression test for multiple same-vendor custom endpoint groups.
