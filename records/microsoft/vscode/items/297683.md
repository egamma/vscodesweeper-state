# Issue #297683 — Streaming args for edits shows partial paths

[https://github.com/microsoft/vscode/issues/297683](https://github.com/microsoft/vscode/issues/297683)

## Summary

Keep open: current source still turns an incomplete streamed edit path into a file link. The maintainer discussion supports waiting for the complete path, and the related creation issue does not resolve this editing case.

## Change summary

Avoid displaying partial file paths while an agent's edit-tool arguments are streaming.

## Best solution

Edit-tool progress should show generic activity until the target path is complete, then display the stable file reference while edit content continues streaming. Preserve existing edit execution and line-count progress.
