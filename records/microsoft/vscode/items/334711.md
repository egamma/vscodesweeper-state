# Issue #334711 — Ignore parser treats literal exclamation marks as negation

[https://github.com/microsoft/vscode/issues/334711](https://github.com/microsoft/vscode/issues/334711)

## Summary

Confirmed in source: the shared IgnoreFile parser treats any `!` in a gitignore line as a negation prefix and strips all exclamation marks via `line.replace(/!/g, '')`, misclassifying filenames containing literal `!` characters. An open PR already addresses this, so the fix lane should defer to it rather than proposing an auto-fix.

## Change summary

IgnoreFile parser misclassifies gitignore lines containing a literal (non-leading or escaped) `!` as negation, causing wrong include/exclude results for filenames with `!` in them.

## Best solution

Land the fix in the linked PR (or an equivalent one) that only treats a genuine leading `!` (respecting `\!` escaping) as negation instead of `line.includes('!')` / `line.replace(/!/g, '')` in src/vs/workbench/services/search/common/ignoreFile.ts.
