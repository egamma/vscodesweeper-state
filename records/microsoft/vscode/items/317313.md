## Summary

Keep open: the current cloud-session confirmation flow still checks the active local repository for changes without establishing that it matches the selected GitHub repository. This supports the reported unnecessary commit/delegate prompt; no verified canonical or issue-linked fix was found.

## Change summary

Avoid prompting to commit local changes when a new cloud session targets an unrelated GitHub repository.

## Best solution
