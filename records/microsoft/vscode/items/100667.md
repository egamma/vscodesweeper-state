# Issue #100667 — Alt+Backspace to delete previous character without smart indentation-aware deletion

[https://github.com/microsoft/vscode/issues/100667](https://github.com/microsoft/vscode/issues/100667)

## Summary

The requested per-keystroke bypass remains distinct from disabling smart indentation globally. Keep this accepted Backlog request open: the inspected deletion commands do not expose that bypass, and no verified canonical issue owns the same request.

## Change summary

Provide an alternate Backspace action that deletes one character without deleting whitespace back to the previous indentation stop.

## Best solution

Provide a bindable character-deletion action that can coexist with normal indentation-aware Backspace. Any default Alt+Backspace binding should be considered separately against existing platform shortcuts.
