# Issue #328551 — Show download and installation progress when installing extension

[https://github.com/microsoft/vscode/issues/328551](https://github.com/microsoft/vscode/issues/328551)

## Summary

This detailed proposal matches extension-installation progress work that maintainers have repeatedly declined as out of scope, most recently when an equivalent request was redirected to the established decision.

## Change summary

Show byte-level download progress, transfer speed, and installation stages while installing Marketplace extensions, including on remote hosts.

## Best solution

Retain the standard indeterminate installation indicator and logs rather than adding a detailed core progress protocol and UI; reconsider the prior scope decision only if maintainers choose to reopen https://github.com/microsoft/vscode/issues/56023.

## Vision fit

- **Fit:** rejected
- **Reason:** Detailed per-stage installation UI and cross-layer progress plumbing conflict with the preference for a simple, uniform, lightweight default experience.
- **Evidence:** Values and guardrails: “Simple, uniform UI and UI interactions” and a lightweight, fast editor out of the box.
