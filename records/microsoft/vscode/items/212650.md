# Issue #212650 — Support multiple `SemanticTokensProvider` per document selector

[https://github.com/microsoft/vscode/issues/212650](https://github.com/microsoft/vscode/issues/212650)

## Summary

A real capability gap remains on main: VS Code queries equally ranked providers but uses only the first successful token result. With 26 upvotes and placement in the Backlog, this should remain open.

## Change summary

Allow semantic-token results from multiple providers matching one document to be combined rather than selecting one provider's result.

## Best solution

Add editor-level composition of semantic-token streams, including legend mapping, overlap precedence, incremental result tracking, and provider disposal, in the semantic-tokens pipeline.
