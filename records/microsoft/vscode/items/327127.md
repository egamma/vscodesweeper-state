# Issue #327127 — Agent Host: Allow option to restore web_fetch access to private networks

[https://github.com/microsoft/vscode/issues/327127](https://github.com/microsoft/vscode/issues/327127)

## Summary

Keep open for a human security and product decision on explicitly authorized private-network fetching. Existing URL approvals do not establish that this capability is available, and the request concerns a security boundary, so neither closing nor agent implementation is appropriate.

## Change summary

Allow explicitly authorized Agent Host web_fetch requests to internal sites whose DNS resolves to private or local addresses.

## Best solution

Determine whether the runtime can safely support narrowly scoped private-network authorization while preserving default address blocking and administrator restrictions. Any approved capability should be enforced by the runtime, with URL approval remaining distinct from permission to cross a network boundary.
