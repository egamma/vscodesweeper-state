## Evidence

- **Exact failing source path:** In src/vs/workbench/contrib/codeEditor/browser/toggleWordWrap.ts, ToggleWordWrapAction.run writes the new transient state to the active modified model, but updates the other model only if canToggleWordWrap returns true. That helper explicitly rejects the original editor while the diff renders inline, so the reporter's inline toggle does not synchronize both models.
- **Persistent original-side override:** src/vs/editor/browser/widget/diffEditor/components/diffEditorEditors.ts:141-155 sets both wordWrapOverride1 and wordWrapOverride2 to 'off' for the hidden original editor, but restores only wordWrapOverride1 when side-by-side rendering resumes. src/vs/editor/common/config/editorOptions.ts:2932-2933 gives a non-'inherit' wordWrapOverride2 precedence, explaining the original side remaining unwrapped.
- **Controller does not repair the transition reliably:** ToggleWordWrapController in src/vs/workbench/contrib/codeEditor/browser/toggleWordWrap.ts only reapplies transient state on wrappingInfo changes, model changes, or transient-property events, and refuses to apply it while the original editor is inline. Restoring side-by-side alone can leave wrappingInfo unchanged because the stale override continues to disable wrapping.
- **Open fixing PR:** https://github.com/microsoft/vscode/pull/339565 was verified OPEN with no merge commit and explicitly states 'Fixes #199341'. Its proposed changes address both restoration of the original editor's override and synchronization of inline toggles. This is an existing human-owned implementation candidate, not a landed fix.
- **Discussion and duplicate direction:** The supplied discussion includes independent reproduction and the double-Alt+Z workaround. https://github.com/microsoft/vscode/issues/217386 is CLOSED after a maintainer marked it a duplicate of this issue in https://github.com/microsoft/vscode/issues/217386#issuecomment-3669843512; its root-cause analysis is at https://github.com/microsoft/vscode/issues/217386#issuecomment-2711750462.
