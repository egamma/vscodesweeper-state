# Issue #331494 — Provide a way to return to the regular editor from the new Markdown experience

[https://github.com/microsoft/vscode/issues/331494](https://github.com/microsoft/vscode/issues/331494)

## Summary

VS Code already ships exactly this capability: the generic 'Reopen Editor With...' command lets you switch any custom editor (including the new Markdown editor) back to the plain Text Editor, from both the Command Palette and the editor tab's right-click menu.

## Change summary

Requests an obvious button/command/menu action to leave the new Markdown editing experience and return to the regular text editor.

## Best solution

Point the reporter at the existing 'Reopen Editor With...' command (workbench.action.reopenWithEditor), available via the Command Palette and by right-clicking the editor tab, then choosing 'Text Editor'.

  > Thanks for the report! There's already a built-in way to do this: right-click the editor tab (or open the Command Palette) and choose "Reopen Editor With...", then pick "Text Editor". That switches the current document out of the new Markdown editor back to the plain text editor, and works the same way for any custom editor in VS Code. Closing as as-designed, but let us know if that path doesn't work for the new Markdown experience specifically.
