# Issue #331048 — Unresolved variable triggers unwanted auto-rename

[https://github.com/microsoft/vscode/issues/331048](https://github.com/microsoft/vscode/issues/331048)

## Summary

This is the suggest widget's commit-character behavior, not an 'auto-rename' feature: typing `;` while the suggestion list is open accepts the currently highlighted entry (here, the import `Field`, fuzzy-matched against the unresolved `field`). That's intentional and already user-controllable via `editor.acceptSuggestionOnCommitCharacter`.

## Change summary

Typing a semicolon after an unresolved lowercase variable reference silently replaces it with a similarly-named imported identifier.

## Best solution

Point the reporter at `editor.acceptSuggestionOnCommitCharacter: false` (or `editor.suggest.insertMode`) to stop commit characters from accepting suggestions; this is existing, documented suggest-widget behavior (src/vs/editor/common/config/editorOptions.ts, src/vs/editor/contrib/suggest/browser/suggestCommitCharacters.ts) rather than a distinct 'auto-rename' defect.
