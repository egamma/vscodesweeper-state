# Issue #325650 — Can't tab to editor type dropdown

[https://github.com/microsoft/vscode/issues/325650](https://github.com/microsoft/vscode/issues/325650)

## Summary

The keyboard-accessibility defect is present on current main: the editor-type control is mouse-clickable but cannot receive keyboard focus or activation. It should remain open for a focused breadcrumbs accessibility fix.

## Change summary

Make the breadcrumbs editor-type dropdown reachable and operable by keyboard.

## Best solution

Update the editor-type control in `breadcrumbsControl.ts` to follow the appropriate button or toolbar keyboard pattern, including focusability, Enter/Space activation, logical navigation from breadcrumbs, and a visible focus indicator.
