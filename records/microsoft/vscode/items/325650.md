# Issue #325650 — Can't tab to editor type dropdown

[https://github.com/microsoft/vscode/issues/325650](https://github.com/microsoft/vscode/issues/325650)

## Summary

The editor-type dropdown remains mouse-only on current main: its button-role div has neither a tab stop nor keyboard activation, and breadcrumb arrow navigation cannot reach it. Keep this accepted accessibility bug open; the source identifies a bounded fix lane.

## Change summary

Make the editor-type dropdown reachable and operable through normal keyboard navigation.

## Best solution

Provide conventional keyboard access to the breadcrumbs editor-type control, including focus, activation, and focus restoration after dismissing its menu, without changing editor selection or default-association behavior.
