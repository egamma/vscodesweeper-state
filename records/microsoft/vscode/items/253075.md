# Issue #253075 — refine/generate alt text quick fix actions overwrite the image location and alt text tags

[https://github.com/microsoft/vscode/issues/253075](https://github.com/microsoft/vscode/issues/253075)

## Summary

The defect remains in current source: the alt-text quick fix identifies the image path but does not identify or constrain edits to the alt-text span, allowing inline chat to replace the surrounding image syntax. This team-authored, accepted bug should remain open for a bounded fix.

## Change summary

Generate/Refine Alt Text can replace an image's location and Markdown or HTML delimiters instead of changing only its alt text.

## Best solution

Generate and refine actions should limit the editable range to the alt-text value while preserving the image source, delimiters, and other attributes for Markdown, HTML, and Learn Markdown images.
