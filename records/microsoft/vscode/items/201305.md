# Issue #201305 — Explorer: NPM when pasting a file repeatedly

[https://github.com/microsoft/vscode/issues/201305](https://github.com/microsoft/vscode/issues/201305)

## Summary

The bug remains present on current main: repeated Cmd+V events can start overlapping Explorer copy operations without backpressure, producing concurrent target selection, bulk edits, and progress UI. No older issue with the same observable symptom or fixing PR was found.

## Change summary

Holding the Explorer paste keybinding repeatedly launches enough overlapping file-copy operations to overwhelm the paste flow.

## Best solution

Make repeated Explorer paste requests execute with bounded concurrency while preserving one uniquely named copy per accepted paste invocation.
