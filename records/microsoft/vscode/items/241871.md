# Issue #241871 — Dragging from Firefox doesn't work

[https://github.com/microsoft/vscode/issues/241871](https://github.com/microsoft/vscode/issues/241871)

## Summary

The Firefox drop path remains broken on current main: the drag overlay accepts an HTML payload, but the drop resolver rejects it unless the same payload also contains a URI-list entry. This team-authored bug should remain open for a bounded compatibility fix.

## Change summary

Dragging a web image from Firefox on Linux into panel chat shows an attachment overlay but creates no attachment when dropped.

## Best solution

Make chat's web-image drop handling resolve the Firefox payload accepted during drag-over, while preserving existing Chrome, Edge, Safari, file-image, and internal-resource behavior.
