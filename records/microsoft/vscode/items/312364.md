# Issue #312364 — Indicador ficheros modificados

[https://github.com/microsoft/vscode/issues/312364](https://github.com/microsoft/vscode/issues/312364)

## Summary

Existing Explorer decorations partially address the request, but do not establish modification tracking for manual FTP publishing or provide the requested alternative folder indicator. Keep this open for a product decision; no verified canonical issue or complete implementation was found.

## Change summary

Make modified files easier to distinguish from their containing folders, including files changed by workspace-wide text replacement.

## Best solution

Evaluate a clearer, theme-aware distinction between directly modified files and folders containing changes within the shared Explorer decoration system. Establish whether the FTP workflow needs saved-change tracking beyond existing Git status before expanding core behavior.
