# Issue #312364 — Indicador ficheros modificados

[https://github.com/microsoft/vscode/issues/312364](https://github.com/microsoft/vscode/issues/312364)

## Summary

VS Code already provides color and badge decorations for SCM-modified files in the Explorer (propagated to parent folders), controlled by `explorer.decorations.colors` and `explorer.decorations.badges`. The core ask is already covered; the specific icon shape changes are a niche visual preference beyond what core provides.

## Change summary

Request for differentiated visual indicators (icons, colors) for modified files vs. folders containing modified files in the Explorer.

## Best solution

The existing `explorer.decorations.colors` and `explorer.decorations.badges` settings already provide color-coded and badge-decorated modified-file indicators in the Explorer, propagated to parent folders. The SCM view further highlights all changed files. The specific icon-shape customization requested is niche visual polish already addressable via icon themes (extensions).

- **Proposed comment:**

  > Thanks for the suggestion! VS Code already provides visual indicators for modified files in the Explorer:
  > 
  > - **Color decorations** — modified files are tinted (green for added, yellow/orange for modified) when `explorer.decorations.colors` is enabled (on by default).
  > - **Badge decorations** — letter badges like "M" (modified) appear next to file names when `explorer.decorations.badges` is enabled.
  > - These decorations **propagate to parent folders**, so you can quickly spot which directories contain changes.
  > 
  > For the search-and-replace scenario, files modified by a mass replacement will show as modified in the SCM view and Explorer once saved.
  > 
  > For different icon shapes, icon-theme extensions on the Marketplace can customize file icons per state. Since the core ask is already addressed by existing functionality, I'm closing this as designed. If you have a more specific gap that the current decorations don't cover, please open a new issue with details.
