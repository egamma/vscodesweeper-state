# Issue #334075 — Model picker is too wide due to 90px minimum width

[https://github.com/microsoft/vscode/issues/334075](https://github.com/microsoft/vscode/issues/334075)

## Summary

Fresh, self-diagnosed report from a VS Code team member with an exact root cause and line reference; confirmed the constant is still present on main, so this stays open for a fix — team-authored issues are protected from judgment closes anyway.

## Change summary

The chat model picker enforces a 90px minimum name width (60px label + 30px chrome), making it wider than needed in compact chat input layouts and causing tooltip overlap.

## Best solution

Reduce or make configurable the MODEL_PICKER_MINIMUM_NAME_WIDTH constant in modelPickerWidget.ts for compact layouts, likely reusing/adjusting the existing MODEL_PICKER_COMPACT_NAME_WIDTH path already used when `compact && !showModelLabel`.
