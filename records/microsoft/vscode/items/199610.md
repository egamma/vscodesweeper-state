# Issue #199610 — Truncate long inlay hints

[https://github.com/microsoft/vscode/issues/199610](https://github.com/microsoft/vscode/issues/199610)

## Summary

Implemented and shipped in VS Code 1.94: inlay hints have a default per-line limit and users can configure or disable truncation.

## Change summary

Add a configurable editor-controlled length limit for inlay hints.

## Best solution

Keep the shipped `editor.inlayHints.maximumLength` setting, which defaults to 43 and accepts `0` for unlimited hints; no further implementation is needed.
