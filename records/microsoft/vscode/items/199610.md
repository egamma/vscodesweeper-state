# Issue #199610 — Truncate long inlay hints

[https://github.com/microsoft/vscode/issues/199610](https://github.com/microsoft/vscode/issues/199610)

## Summary

The central request is implemented: VS Code truncates inlay hints by default and exposes a configurable length limit, documented in version 1.94. Optional viewport-aware limits and automatic full-label hover remain possible follow-up improvements, not prerequisites for the requested default limit.

## Change summary

Limit long inlay hints consistently across languages and let users configure the truncation threshold.

## Best solution

Close the delivered default-limit and configurability request as completed; users can adjust editor.inlayHints.maximumLength or set it to 0 for unlimited hints. Treat viewport-aware budgeting, separate per-hint limits, and automatic full-label hover as distinct follow-up requests.
