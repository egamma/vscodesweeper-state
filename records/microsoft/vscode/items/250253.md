# Issue #250253 — Accessibility: Walkthrough Page Titles Violate "1.3.1 Info and Relationships" Requirement

[https://github.com/microsoft/vscode/issues/250253](https://github.com/microsoft/vscode/issues/250253)

## Summary

The restored walkthrough still loses its descriptive editor title on current main: serialization omits the title, and restoration does not reconstruct it. Keep this accepted Backlog bug open; the related accessibility reports concern different symptoms.

## Change summary

Walkthrough editor titles should identify the displayed walkthrough and retain that identity after restarting VS Code.

## Best solution

Make each walkthrough's editor title reflect its displayed walkthrough title consistently across opening, navigation, and restoration, while preserving the generic Welcome title for the walkthrough index.
