# Issue #250253 — Accessibility: Walkthrough Page Titles Violate "1.3.1 Info and Relationships" Requirement

[https://github.com/microsoft/vscode/issues/250253](https://github.com/microsoft/vscode/issues/250253)

## Summary

Confirmed on current main: the GettingStartedInputSerializer does not persist walkthroughPageTitle, so reopened walkthroughs always show the generic "Welcome" title. A real accessibility gap for screen reader users navigating multiple walkthrough tabs.

## Change summary

Reopened walkthrough editors lose their specific title and display generic "Welcome" because the serializer omits walkthroughPageTitle.

## Best solution

Fix GettingStartedInputSerializer to either serialize/deserialize walkthroughPageTitle, or resolve it from selectedCategory via the walkthrough service during deserialization. The latter is more robust since categories already carry walkthroughPageTitle.
