# Issue #316190 — Agent Debug Logs stats resets

[https://github.com/microsoft/vscode/issues/316190](https://github.com/microsoft/vscode/issues/316190)

## Summary

The report describes token usage stats dropping when re-opening a session in the Agent Debug Logs panel, but the reproduction is under-specified — it's unclear whether this affects live sessions (where the fallback usage source changes) or finished sessions (where events.jsonl is authoritative), or whether the session was still running. More detail is needed to trace the root cause.

## Change summary

Token usage stats in the Agent Debug Logs panel reset to lower values when navigating away from a session and reopening it.

## Best solution

The debug provider in `src/vs/workbench/contrib/chat/browser/chatDebug/agentHostChatDebugProvider.ts` re-reads `events.jsonl` each time a session is opened and uses different usage sources for live vs. finished sessions (live AIU from chat state vs. cumulative totals from `session.shutdown`). The reporter needs to clarify whether the session was still active (live) or completed, and ideally provide the `events.jsonl` file or screenshots before/after re-opening. With that, the team can determine whether the drop stems from the live-to-shutdown usage fallback logic, an incomplete shutdown summary, or a truncated events file.

## Evidence

- **usage source architecture:** In `src/vs/workbench/contrib/chat/browser/chatDebug/agentHostChatDebugProvider.ts`, stats are re-derived from `events.jsonl` on every open. Live sessions use `sumChatStateUsage()` (AIU only, lines 572–587), while finished sessions use `extractSessionUsageTotals()` from `session.shutdown` (lines 515–545). Switching between these sources when a session ends mid-view could explain the drop.
- **overview tiles computed from events:** `chatDebugOverviewView.ts` lines 296–300 sum `inputTokens`/`outputTokens`/`totalTokens` across all `modelTurn` events. These per-turn values are back-filled from totals (lines 473–492 of agentHostChatDebugProvider.ts); if the totals source changes, so do the tiles.
