## Summary

Keep open: the report provides sufficient steps to retest a substantial drop in session statistics, and the reporter confirmed persistence in 1.121.0. Current source has bounded event retention and asynchronous history backfill, but inspection did not establish whether the reported drop remains permanent or identify a fixing commit.

## Change summary

Agent Debug Logs tool-call and token totals drop substantially when a long-running session is reopened from the session list.

## Best solution

Make the same session's statistics consistent before and after navigation, without double-counting replayed events or losing accumulated usage because the displayed event history is bounded. First distinguish incomplete history backfill from permanently omitted events on the reporter's navigation path.
