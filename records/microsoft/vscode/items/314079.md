# Issue #314079 — Install agent plugin specific version or provide branch name

[https://github.com/microsoft/vscode/issues/314079](https://github.com/microsoft/vscode/issues/314079)

## Summary

Marketplace branch/tag references are supported, but they do not provide extension-style selection of a plugin's historical versions. Keep this request open: the existing support is partial, and no verified canonical or qualifying implementation commit establishes completion.

## Change summary

Allow installing a specific agent-plugin version or selecting a marketplace branch or tag.

## Best solution

Document the existing `chat.plugins.marketplaces` syntax `owner/repo#ref`, and decide whether plugins should additionally expose historical-version selection. Selecting a marketplace revision must be distinguished from selecting the version of a plugin hosted in a separate repository.
