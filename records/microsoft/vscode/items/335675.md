# Issue #335675 — Automations overflow menu hover should be just "More Actions..."

[https://github.com/microsoft/vscode/issues/335675](https://github.com/microsoft/vscode/issues/335675)

## Summary

Valid, freshly-filed polish request tracing directly to a specific hover/aria label in the automations card UI; the exact wording and code location are confirmed on main, so this stays open for a small copy fix rather than closing.

## Change summary

The automations card's 'more actions' button hover/aria label reads 'More Actions for {automation name}' and should be shortened to just 'More Actions...' with a trailing ellipsis.

## Best solution

Update the two `localize('moreActionsForAutomation', ...)` call sites in src/vs/sessions/contrib/sessions/browser/views/automationsView.ts (lines 574 and 649) to a shorter 'More Actions...' string (dropping the per-automation name and adding the ellipsis, consistent with other 'More Actions...' labels elsewhere in the codebase like paneCompositePart.ts and scmInput.ts), and update the matching expectation in automationsView.test.ts.
