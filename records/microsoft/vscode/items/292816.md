# Issue #292816 — integrated Terminal on vscode that supports kitty protocol so I can use ctrl+enter shortcut on kiro cli without sending prompt

[https://github.com/microsoft/vscode/issues/292816](https://github.com/microsoft/vscode/issues/292816)

## Summary

The requested Kitty keyboard protocol support is implemented and enabled by default; release notes confirm availability to all users in VS Code 1.109.5. Replacing the integrated terminal with Alacritty is not necessary for this capability.

## Change summary

Support the Kitty keyboard protocol so terminal applications can distinguish Ctrl+Enter from ordinary Enter.

## Best solution

Use the existing integrated terminal with terminal.integrated.enableKittyKeyboardProtocol enabled. Kitty-aware applications can receive distinct modified-Enter sequences; the application determines what those shortcuts do.
