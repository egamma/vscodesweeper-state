# Issue #331621 — Automation sessions should be promotable to normal sessions

[https://github.com/microsoft/vscode/issues/331621](https://github.com/microsoft/vscode/issues/331621)

## Summary

Keep open: current source still excludes automation sessions from the normal sessions list, with no promotion capability found. The related open request is newer and cannot replace this previously reviewed, team-authored item.

## Change summary

Allow automation sessions to enter the normal sessions list through explicit UI actions, user interaction, or an agent tool.

## Best solution

Provide promotion that makes an automation conversation accessible alongside normal sessions while preserving its automation history and identity. Settle whether user replies and requests for input cause persistent promotion or temporary visibility before implementing the interaction and tool surfaces.
