# Issue #331621 — Automation sessions should be promotable to normal sessions

[https://github.com/microsoft/vscode/issues/331621](https://github.com/microsoft/vscode/issues/331621)

## Summary

Clear, well-formed feature request from a contributor active in this exact area; no existing mechanism promotes an automation session into the regular sessions list, so this should stay open for product/design decision.

## Change summary

Add a way (manual, semi-manual on user input, or agent-triggered) to promote an automation session into a normal, listed session.

## Best solution

Design and implement a promotion path in src/vs/sessions/contrib/automations (automationService.ts/automationRunner.ts) and the sessions list/provider layer (services/sessions/browser/sessionsManagementService.ts, contrib/sessions/browser/views/sessionsList.ts) that reclassifies an automation session as a normal session, likely alongside the existing 'promote' patterns used for quick chats (baseAgentHostSessionsProvider.ts's `_promoteToQuickChatIfWorkspaceless`).
