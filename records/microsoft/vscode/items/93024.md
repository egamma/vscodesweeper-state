# Issue #93024 — Minor UI inconsistencies: Input theme references

[https://github.com/microsoft/vscode/issues/93024](https://github.com/microsoft/vscode/issues/93024)

## Summary

Still valid on main: the Settings editor search box only overrides the border token (`settingsTextInputBorder`) but not background/foreground, so `settings.textInputBackground`/`settings.textInputForeground` do not apply to the search input. A team member endorsed the idea of either applying existing tokens or adding dedicated search tokens.

## Change summary

The Settings editor search input is not styleable via `settings.textInputBackground`/`settings.textInputForeground` — only `input.background`/`input.foreground` apply.

## Best solution

Add `inputBackground: settingsTextInputBackground` and `inputForeground: settingsTextInputForeground` to the `styleOverrides` in `settingsEditor2.ts` (line ~838), consistent with how settings text inputs in `settingsTree.ts` and `settingsWidgets.ts` already use all three tokens. Alternatively, register dedicated `settings.searchBackground`/`settings.searchForeground` tokens with fallbacks.
