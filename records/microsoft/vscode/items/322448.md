# Issue #322448 — Stepping sometimes causes focus to pass to another thread

Keep open: current source still transfers focus after a slow step, and an open PR explicitly targets this issue. Review that implementation against the agreed distinction between stepping, continuing, and hitting a breakpoint.

## Change summary

Preserve the active debugging thread during slow stepping instead of automatically focusing another stopped thread or session.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/324631 once its behavior is satisfactory: stepping should retain focus, ordinary Continue should retain sensible focus handoff, and breakpoint hits should receive focus.
