# Issue #295943 — Feature Request: Add file deletion tool support for non-OpenAI models in agent mode

[https://github.com/microsoft/vscode/issues/295943](https://github.com/microsoft/vscode/issues/295943)

## Summary

Valid feature request: non-OpenAI models (Claude, Gemini) in agent mode lack file deletion capability. The `apply_patch` tool supports deletion but is gated to GPT-family models only in `modelSupportsApplyPatch()`. Non-OpenAI models use `replace_string_in_file`/`multi_replace_string_in_file` which have no deletion semantics, and there is no standalone `delete_file` tool. The gap remains on current main.

## Change summary

Non-OpenAI models in agent mode cannot delete files because `apply_patch` (the only tool with deletion support) is restricted to GPT-family models.

## Best solution

Either introduce a standalone `delete_file` tool available to all models, or extend the edit-tool surface for non-OpenAI models to support file deletion — the capability gap lives in `chatModelCapabilities.ts` (model gating) and the tool registration in `extensions/copilot/src/extension/tools/`. The related external PR (microsoft/vscode-copilot-chat#4180) was closed without merging, so this remains unaddressed.
