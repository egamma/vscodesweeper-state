# Issue #342723 — Image preview gallery does not update when additional generated images complete

[https://github.com/microsoft/vscode/issues/342723](https://github.com/microsoft/vscode/issues/342723)

## Summary

The current source still snapshots the conversation's images when the preview opens and provides no update path for later completions. Keep this collaborator-authored report open: its detailed reproduction matches that path, and reopening is a workaround rather than a fix.

## Change summary

Keep an open Images Preview synchronized with successfully completed image-generation results, or indicate that newer images are available.

## Best solution

Connect the chat-backed preview to subsequent image completions so its thumbnails, count, and navigation reflect the available results without reopening, while preserving the selected image and keeping ordinary static image collections unchanged.
