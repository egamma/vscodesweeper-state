# Issue #332313 — Add a minimize/collapse action for long-running progress notifications

[https://github.com/microsoft/vscode/issues/332313](https://github.com/microsoft/vscode/issues/332313)

## Summary

This capability already exists: clicking the toast's chevron-down (Hide) action moves the ongoing operation to a status-bar/window progress indicator while it keeps running, then clicking the bell in the status bar re-shows the full notification.

## Change summary

Add a minimize/collapse action so a long-running progress notification can be tucked into the status bar instead of staying visible in the editor area.

## Best solution

No change needed — the existing 'Hide' chevron on notification toasts already switches long-running progress notifications to a compact window/status-bar progress indicator (see progressService.ts's onVisibilityChange/createWindowProgress), and clicking the status bar bell restores the full toast/notification center.

## Evidence

- **status-bar fallback on hide:** src/vs/workbench/services/progress/browser/progressService.ts (withNotificationProgress, ~lines 339-357): notification.onDidChangeVisibility triggers createWindowProgress() when the toast is hidden and the task is not done, switching the same progress to ProgressLocation.Window (status bar); it is cleaned up again once the toast is shown or the task completes.
