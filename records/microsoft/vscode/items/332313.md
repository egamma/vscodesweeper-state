# Issue #332313 — Add a minimize/collapse action for long-running progress notifications

[https://github.com/microsoft/vscode/issues/332313](https://github.com/microsoft/vscode/issues/332313)

## Summary

Current VS Code already lets users hide progress toasts with Escape while preserving progress in the status bar, but it lacks the requested discoverable per-notification minimize action. The issue is still within its Backlog Candidates voting period, so the remaining UX request should stay open under discussion.

## Change summary

Add a visible minimize or collapse action for long-running progress notifications so they stop covering the editor while continuing in the background.

## Best solution

Provide a discoverable, keyboard-accessible hide action on active progress toasts that uses the existing hidden-notification lifecycle: keep the operation in the notification center, show its ongoing status-bar progress, and allow reopening it without cancellation.

## Evidence

- **existing hidden behavior:** src/vs/workbench/browser/parts/notifications/notificationsCommands.ts registers `notifications.hideToasts` on Escape whenever notification toasts are visible, so users can already hide the toast without cancelling its operation.
- **status-bar continuation:** src/vs/workbench/services/progress/browser/progressService.ts creates window/status-bar progress when an active progress notification becomes hidden and links it to `notifications.showList`; it removes that status entry when the notification becomes visible again or completes.
- **remaining UX gap:** src/vs/workbench/browser/parts/notifications/notificationsViewer.ts suppresses the close action while progress is active and only offers expand/collapse for message details; it does not expose a per-toast action corresponding to `notifications.hideToasts`.
- **established progress model:** https://github.com/microsoft/vscode/issues/90274 was completed after maintainers chose the current model: Escape hides active progress notifications and ongoing progress remains represented in the status bar.
