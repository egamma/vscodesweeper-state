# Issue #314532 — Co-Author: Commits

[https://github.com/microsoft/vscode/issues/314532](https://github.com/microsoft/vscode/issues/314532)

## Summary

This requests parsing region comments for authorship markers and auto-injecting co-author trailers into git commits — a highly opinionated workflow that belongs in an extension rather than the core editor.

## Change summary

Automatically parse code region comments for 'Generated by:' / 'Created by:' markers and add co-author trailers to git commits.

## Best solution

Build this as a Marketplace extension that hooks into the SCM pre-commit flow — it can scan staged diffs for authorship markers and prepopulate co-author trailers. The core SCM API already supports commit message manipulation, and an extension can implement any parsing heuristic without burdening the default experience.
