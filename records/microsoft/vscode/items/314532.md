# Issue #314532 — Co-Author: Commits

[https://github.com/microsoft/vscode/issues/314532](https://github.com/microsoft/vscode/issues/314532)

## Summary

Keep open as a distinct feature request: existing AI attribution does not derive co-authors from source-region comments or offer the requested pre-commit review of those inferred authors. The related attribution discussions do not establish a canonical issue covering this marker-based workflow.

## Change summary

Infer editable commit co-author trailers from attribution markers in newly added source regions, including AI models and human contributors.

## Best solution

Evaluate an opt-in extension or Git integration that recognizes explicit attribution markers only in committed additions and lets users review inferred trailers before committing. A product decision is needed on the marker convention and how names without email addresses become valid Git co-author identities; there is no basis here for declaring an industry-wide standard.
