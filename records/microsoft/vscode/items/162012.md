# Issue #162012 — Creating a new setting profile opens the folder in a workspace

[https://github.com/microsoft/vscode/issues/162012](https://github.com/microsoft/vscode/issues/162012)

## Summary

Keep open: a maintainer confirmed this as an Explorer refresh bug, and current source still contains the implicated profile-switch and file-system-provider refresh path. The issue is team-authored, no referenced fix exists, and reproducing the web-only transition against current main is still needed.

## Change summary

Creating and entering a settings profile in a single-folder web workspace makes Explorer render that folder as a one-folder multi-root workspace.

## Best solution

Explorer should retain its single-folder presentation while a profile switch restarts extension hosts and file-system providers are re-registered; only an actual workspace-state transition should select the multi-root tree input.
