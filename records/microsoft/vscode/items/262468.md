# Issue #262468 — Ctrl+C not working to end a process in external cmd.exe terminal

[https://github.com/microsoft/vscode/issues/262468](https://github.com/microsoft/vscode/issues/262468)

## Summary

Verified duplicate of #205417 — both report Ctrl+C not working in external cmd.exe terminals launched from VS Code on Windows, caused by the same spawn path in WindowsExternalTerminalService.spawnTerminal.

## Change summary

Ctrl+C fails to send SIGINT to running processes in external cmd.exe terminals launched from VS Code on Windows.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/205417, which is the older canonical issue tracking the same root cause — the `cp.spawn` call in `WindowsExternalTerminalService.spawnTerminal` (src/vs/platform/externalTerminal/node/externalTerminalService.ts:71) inherits VS Code's console control handler settings, suppressing Ctrl+C in the spawned terminal. The fix likely involves adjusting the spawn options or using a creation flag to reset Ctrl+C handling for the child process.
