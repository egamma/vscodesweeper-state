# Issue #262468 — Ctrl+C not working to end a process in external cmd.exe terminal

[https://github.com/microsoft/vscode/issues/262468](https://github.com/microsoft/vscode/issues/262468)

## Summary

The failure is confirmed in the discussion and matches the older, verified open issue about Ctrl+C not reaching programs in Windows external terminals. Consolidate there, preserving this report's reproduction details and workaround limitations.

## Change summary

Programs running in a VS Code-launched external Windows command prompt fail to receive Ctrl+C, although the same programs respond normally in a manually launched command prompt.

## Best solution

Track and resolve external-terminal Ctrl+C delivery in https://github.com/microsoft/vscode/issues/205417, preserving normal interruption of child programs rather than relying on Ctrl+Break remapping.
