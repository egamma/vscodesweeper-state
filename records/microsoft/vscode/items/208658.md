[https://github.com/microsoft/vscode/issues/208658](https://github.com/microsoft/vscode/issues/208658)

## Summary

This is a specific monitor-switching case of the saved workbench-layout request already tracked by the older open canonical issue. That issue explicitly includes preserving view sizes and switching between layouts for laptop and widescreen displays.

## Change summary

Provide responsive or saved workbench layouts, or a layout API, so sidebar, editor, and panel dimensions can be restored when display dimensions change.
