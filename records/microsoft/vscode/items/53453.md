[https://github.com/microsoft/vscode/issues/53453](https://github.com/microsoft/vscode/issues/53453)

## Summary

The core ask — cloud sign-in with synced settings/extensions and switchable per-language profiles — is now substantially delivered by Settings Sync and the Profiles feature on current main, but this checkout is shallow (single commit, no history) so I can't responsibly cite a fixing commit SHA, and the prior review's citation for this exact issue was already refuted by a second pass; keeping it open rather than re-attempting an unsupported close.

## Change summary

Request for a Microsoft-account-backed cloud profile that syncs settings, keybindings, themes, and installed extensions, with the ability to maintain and switch between multiple named profiles (e.g. PHP vs. Markdown).

## Best solution

Current main already covers nearly all of this via Settings Sync (src/vs/workbench/contrib/userDataSync) for cloud account sign-in and syncing settings/keybindings/extensions, plus Profiles (src/vs/workbench/contrib/userDataProfile) for named, switchable configuration sets that can themselves be synced. A maintainer who can confirm the shipping commit/release should close this as completed; absent that, the remaining open thread (per-language default settings scoping) is tracked by https://github.com/microsoft/vscode/issues/176813.
