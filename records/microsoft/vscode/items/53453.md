## Summary

Fully implemented and shipped: Settings Sync (GA since 1.48, 2020) provides cloud-based sync of settings, extensions, keybindings, and themes via Microsoft/GitHub account; User Profiles (GA since 1.75, Jan 2023) allows creating and switching between distinct configurations. Together they deliver exactly what this issue requests.

## Change summary

Allow users to log in with a cloud account and sync settings/extensions/themes across machines, plus support multiple switchable profiles for different workflows.
