# Issue #191215 — editor.find.cursorMoveOnType Non-Functional in Notebooks

[https://github.com/microsoft/vscode/issues/191215](https://github.com/microsoft/vscode/issues/191215)

## Summary

Notebook Find still lacks the requested cursor-and-viewport navigation while typing. Keep this accepted Backlog request open: existing navigation commands require an explicit action, and the older related reports do not describe the same observable symptom.

## Change summary

Make Notebook Find honor editor.find.cursorMoveOnType so typing reveals the active result before Enter advances to the next match.

## Best solution

Extend notebook search-as-you-type behavior to respect the cursor-movement preference while preserving the non-scrolling behavior when disabled. This belongs in the core notebook find model and widget, not the Jupyter extension.

## Evidence

- **Existing capability and remaining gap:** src/vs/editor/common/config/editorOptions.ts registers editor.find.cursorMoveOnType with default true. Current notebookFindReplaceWidget.ts reads editor.find.history, editor.find.replaceHistory, and notebook find filters, but does not consume cursorMoveOnType; the notebook configuration registration offers search-target filters rather than navigation-on-type.
- **Current notebook search path:** In src/vs/workbench/contrib/notebook/browser/contrib/find/findModel.ts, search-string changes trigger research(); _research() selects a current match through _updateCurrentMatch(), which updates decorations and match information without calling revealCellRange(). Explicit find() does call revealCellRange() and advances an already-selected match. This explains why typing can establish the first match without revealing it, then Enter reveals the next.
- **Explicit navigation is only a workaround:** src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFindWidget.ts maps Enter to find(false). notebookFind.ts registers notebook.find, notebook.findNext.fromWidget, and notebook.findPrevious.fromWidget; these explicit actions do not supply the requested automatic navigation while typing.
