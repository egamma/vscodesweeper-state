# Issue #191215 — editor.find.cursorMoveOnType Non-Functional in Notebooks

[https://github.com/microsoft/vscode/issues/191215](https://github.com/microsoft/vscode/issues/191215)

## Summary

The notebook find widget has its own implementation separate from the editor's find controller and does not read or honor `editor.find.cursorMoveOnType`. This is a real gap — the setting works in regular editors but not in the notebook find surface. Already correctly labeled as feature-request in Backlog.

## Change summary

The `editor.find.cursorMoveOnType` setting has no effect in the notebook find widget — typing doesn't move the view to the current match until Enter is pressed.

## Best solution

Wire up the `editor.find.cursorMoveOnType` setting in the notebook find model so that `_updateCurrentMatch` (in `src/vs/workbench/contrib/notebook/browser/contrib/find/findModel.ts`) calls `revealCellRange` when the setting is enabled, similar to how the editor find model gates cursor movement on the same option.
