# Issue #183503 — Settings editor: focus border is cut off

[https://github.com/microsoft/vscode/issues/183503](https://github.com/microsoft/vscode/issues/183503)

## Summary

Confirmed visual bug still present on main — the settings editor focus outline is clipped when clicking the empty space to the left, due to `overflow: hidden` on the container. No fix commit references this issue, and two other issues (#208060, #233256) were closed as duplicates of this canonical report.

## Change summary

The settings editor shows a focus outline that is cut off at the bottom edge when clicking empty space to the left of the settings content.

## Best solution

Fix the outline clipping in `src/vs/workbench/contrib/preferences/browser/media/settingsEditor2.css` — either fully suppress the outline on the focusable container element (the `outline: none` on `.editor-instance#workbench\.editor\.settings2:focus` may need `!important` or to target the correct focused element), or adjust `overflow: hidden` to `overflow: clip` with appropriate padding to avoid clipping outlines.
