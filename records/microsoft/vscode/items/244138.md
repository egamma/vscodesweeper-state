# Issue #244138 — Disabled and enabled (workspace) extension Disable button dropdown contains both "Disable" and "Disable (Workspace)" items

[https://github.com/microsoft/vscode/issues/244138](https://github.com/microsoft/vscode/issues/244138)

The defect remains directly traceable on current main, but three open PRs already reference and address it. Keep the issue open while maintainers select, review, and land one implementation.

## Change summary

When an extension is globally disabled but workspace-enabled, its details view incorrectly offers both global and workspace Disable actions instead of only Disable (Workspace).

Review and land one focused implementation, preferably the variant with regression coverage in https://github.com/microsoft/vscode/pull/337023, then close the competing PRs and let the merged fix complete this issue.
