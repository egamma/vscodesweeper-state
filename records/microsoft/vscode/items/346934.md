# Issue #346934 — Inbox mode: Sessions cannot be dragged between groups

[https://github.com/microsoft/vscode/issues/346934](https://github.com/microsoft/vscode/issues/346934)

## Summary

Keep open as a feature request: Inbox mode explicitly disables placement drag and drop, and existing triage actions do not provide the requested gesture. Meaningful drop targets need defined triage semantics rather than arbitrary movement between status-derived categories.

## Change summary

Allow dragging sessions between Inbox categories where the destination represents a meaningful user action.

## Best solution

Support drops that correspond to explicit Inbox triage actions while preserving automatic status classification and saved non-Inbox organization. Decide which destinations are valid and what each drop means before implementation.
