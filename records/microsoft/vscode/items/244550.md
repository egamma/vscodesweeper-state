# Issue #244550 — SCM: Add a options to commit without verify when run git's hooks fail

[https://github.com/microsoft/vscode/issues/244550](https://github.com/microsoft/vscode/issues/244550)

## Summary

Keep open: existing no-verify commands do not provide the requested retry action in the hook-failure dialog. A maintainer approved the work, and an open PR explicitly targets this issue.

## Change summary

Offer an explicit way to retry a failed SCM commit without running Git hooks.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/273679, particularly its hook-failure detection and retry behavior. Preserve the existing opt-in and confirmation safeguards rather than bypassing hooks automatically.
