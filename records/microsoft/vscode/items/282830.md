# Issue #282830 — Link to edit a global setting from a non-default profile opens wrong settings.json file

[https://github.com/microsoft/vscode/issues/282830](https://github.com/microsoft/vscode/issues/282830)

## Summary

Valid feature request: when a setting is applied to all profiles, the 'Edit in settings.json' link should open the default profile's settings.json rather than the active profile's. Already triaged into Backlog with the correct area label.

## Change summary

Clicking 'Edit in settings.json' for a setting marked 'Apply to all Profiles' should open the default profile's settings.json instead of the current profile's.

## Best solution

In `settingsEditor2.ts` `openSettingsFile()`, check whether the setting key is applied to all profiles (via `IUserDataProfilesService`) and, if so, open the default profile's settings.json. This is a small localized change in the settings editor contrib.
