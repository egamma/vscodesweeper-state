# Issue #344651 — Agents window - have only 2 workspaces but it gives "show fewer workspaces" button

[https://github.com/microsoft/vscode/issues/344651](https://github.com/microsoft/vscode/issues/344651)

## Summary

Keep open: the two-workspace toggle remains in current source, and a maintainer confirmed the exact behavior on recent Insiders. The remaining work is a presentation decision: avoid hiding small workspace sets or explain the age-based toggle more clearly.

## Change summary

Make the workspace visibility toggle understandable when the Agents window contains only two workspaces.

## Best solution

Make the small-workspace list self-explanatory without sacrificing older-workspace discovery. Agree whether small lists should bypass age-based hiding or retain it with clearer wording, then cover that behavior in the SessionsList tests.
