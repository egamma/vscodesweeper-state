# Issue #344651 — Agents window - have only 2 workspaces but it gives "show fewer workspaces" button

[https://github.com/microsoft/vscode/issues/344651](https://github.com/microsoft/vscode/issues/344651)

## Summary

Keep open as small-list UX polish. Current source deliberately offers “Show fewer workspaces” when older workspaces have been revealed, even with only two workspaces; whether that control is useful at such a small count remains a product decision.

## Change summary

Avoid a confusing “Show fewer workspaces” affordance when the Agents window contains only two collapsed workspaces.

## Best solution

Have the Sessions list owner settle the small-list presentation rule so the control communicates a useful reduction rather than unnecessary chrome. Preserve access to older workspaces and keep workspace visibility separate from whether each workspace's sessions are expanded.
