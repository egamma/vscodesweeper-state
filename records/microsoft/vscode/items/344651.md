# Issue #344651 — Agents window - have only 2 workspaces but it gives "show fewer workspaces" button

[https://github.com/microsoft/vscode/issues/344651](https://github.com/microsoft/vscode/issues/344651)

## Summary

The two-workspace toggle remains in current source. A maintainer has acknowledged the confusing presentation and suggested improvements; keep this open for a choice between changing small-list capping and clarifying the wording.

## Change summary

Make the older-workspace visibility toggle understandable when the Agents window contains only two workspaces.

## Best solution

Make the sessions list explain its age-based filtering without implying that two workspaces are excessive. Decide whether small workspace lists should bypass filtering or retain filtering with clearer action text.
