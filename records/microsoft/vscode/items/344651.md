# Issue #344651 — Agents window - have only 2 workspaces but it gives "show fewer workspaces" button

[https://github.com/microsoft/vscode/issues/344651](https://github.com/microsoft/vscode/issues/344651)

## Summary

Keep open for the maintainer-supported polish improvement: current source still offers age-based workspace collapsing with only two workspaces. The behavior is intentional, but the footer does not explain why this small list can be reduced.

## Change summary

Make the workspace reduction toggle understandable when the Agents window contains only two collapsed workspace sections.

## Best solution

Make the small-list experience self-explanatory without compromising older-workspace management in larger lists. A maintainer should choose between exempting small lists from age-based partitioning and retaining that behavior with clearer wording.
