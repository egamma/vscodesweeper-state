## Evidence

- **Reported trigger:** https://github.com/microsoft/vscode/issues/234137 reports that workspace.openNotebookDocument(mementoValue as Uri) duplicates an untitled notebook with the same URI when it is hidden behind a text editor, while the visible case works. The report includes a recording and identifies Native REPL restoration as the affected workflow.
- **Original investigation:** https://github.com/microsoft/vscode-python/pull/24148#discussion_r1847016066 explicitly asks whether the notebook document is open when its editor is not shown after reloading VS Code, and whether restoration should inspect the matching tab. This makes unresolved editor restoration versus an already-live document an important diagnostic distinction.
- **Current API path:** src/vs/workbench/api/common/extHostNotebook.ts: ExtHostNotebookController.openNotebookDocument returns the cached API notebook when the URI is already in _documents. Otherwise, src/vs/workbench/api/browser/mainThreadNotebookDocuments.ts: $tryOpenNotebook resolves that URI and retains a model reference; this method does not itself open an editor.
- **Current model and visibility handling:** src/vs/workbench/contrib/notebook/common/notebookEditorModelResolverServiceImpl.ts: validateResourceViewType consults an existing notebook model and resolve acquires a reference keyed by the validated resource. src/vs/workbench/api/browser/mainThreadNotebookDocumentsAndEditors.ts constructs document state from listNotebookDocuments independently of visible editors. These paths do not establish that hiding a live notebook alone currently produces a duplicate.
- **Restoration boundary:** src/vs/workbench/api/common/extHostNotebook.ts: showNotebookDocument selects the 'repl' editor view for asRepl, separately from notebook.notebookType. src/vs/workbench/contrib/notebook/common/notebookEditorInput.ts also has a side-loaded-model listener that resolves existing inputs when their notebook model appears. Restoration needs investigation across these boundaries before assigning a root cause.
