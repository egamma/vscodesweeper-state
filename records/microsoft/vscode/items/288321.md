# Issue #288321 — Worktree problems showing in problems view

[https://github.com/microsoft/vscode/issues/288321](https://github.com/microsoft/vscode/issues/288321)

## Summary

Keep open: the Problems view has no session-aware exclusion for background worktrees, and existing filters only partially address the request. This team-authored item has neither a verified fixing commit nor an eligible duplicate canonical.

## Change summary

Exclude diagnostics belonging to background agent-session worktrees from the main workspace's Problems view.

## Best solution

Make Problems view visibility distinguish background-session worktrees from the user's active workspace without suppressing ordinary workspace diagnostics. Establish how diagnostics should behave when the user explicitly opens a background-worktree file before implementing the session-aware behavior.
