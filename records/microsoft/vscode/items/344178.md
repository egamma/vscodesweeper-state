# Issue #344178 — Harness automatically switches to Copilot when the context is reset

[https://github.com/microsoft/vscode/issues/344178](https://github.com/microsoft/vscode/issues/344178)

## Summary

The requested persistence of the selected harness is already covered by an older, open request, including an explicit report that selecting Local is undone by subsequent chats. Consolidate this report there, preserving its Windows reproduction.

## Change summary

Keep the explicitly selected Local session target when starting a new chat instead of switching back to Copilot.

## Best solution

Consolidate harness-selection persistence in https://github.com/microsoft/vscode/issues/337676, including honoring an explicit Local selection across New Chat. The current Copilot-preference override is deliberate in source and tests, so changing its precedence belongs in that existing product request.
