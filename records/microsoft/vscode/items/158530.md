# Issue #158530 — Welcome views should use primary + secondary button styles

[https://github.com/microsoft/vscode/issues/158530](https://github.com/microsoft/vscode/issues/158530)

## Summary

Keep open: this team-authored UX proposal identifies a real welcome-view hierarchy problem, while the discussion leaves the user-visible selection and ordering of a single primary action unresolved. No verified older canonical with the same observable request is present.

## Change summary

Render welcome-view actions with one primary button and the remaining actions as secondary rather than styling every action as primary.

## Best solution

Define a deterministic welcome-view action hierarchy that supports contributions from multiple sources, then render only the selected general action as primary while preserving discoverability for extension-contributed alternatives.
