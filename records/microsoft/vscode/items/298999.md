# Issue #298999 — [Feature Request] Separate invocation namespace for prompt files vs skills in the slash picker

[https://github.com/microsoft/vscode/issues/298999](https://github.com/microsoft/vscode/issues/298999)

## Summary

Keep open: current completions still do not distinguish prompt files from skills by type. Visibility filtering is partially supported internally, but it does not resolve the navigation request; no qualifying older canonical or concrete fixing commit was established.

## Change summary

Make large slash-command lists easier to navigate by distinguishing prompt files, skills, and built-in commands, or providing supported visibility controls.

## Best solution

Choose a consistent type-discovery interaction for the existing slash picker, preserving established invocation syntax unless a separate namespace is explicitly approved. Reconcile prompt-file visibility support with its frontmatter validation rather than treating the existing internal filtering as complete coverage.
