# Issue #298999 — [Feature Request] Separate invocation namespace for prompt files vs skills in the slash picker

[https://github.com/microsoft/vscode/issues/298999](https://github.com/microsoft/vscode/issues/298999)

## Summary

Valid feature request from a team member — the asymmetry between skills (which have `user-invokable` frontmatter) and prompt files (which always appear) remains on current main, and no grouping or namespace separation has been added to the slash picker.

## Change summary

Provide a way to separate or filter prompt files vs skills in the slash picker, which currently shows all entries in one flat list.

## Best solution

Add visibility/grouping controls to the slash picker — either section headers in the completion list, a separate prefix for prompt files, or `user-invokable` parity in prompt file frontmatter. The work likely touches the slash command completion provider and the prompt/skill registration in `extensions/copilot/` and `src/vs/platform/agentPlugins/common/pluginParsers.ts`.
