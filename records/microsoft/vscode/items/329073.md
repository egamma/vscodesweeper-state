# Issue #329073 — "Discard Edits" button looks like a spinner, is actually a button

[https://github.com/microsoft/vscode/issues/329073](https://github.com/microsoft/vscode/issues/329073)

## Summary

Confirmed in source: the inline 'Discard Edits' confirm label reuses the same `chat-thinking-shimmer` animation as the in-progress 'thinking' indicator, so the confirmation button visually reads as a loading spinner rather than a static button — routing to the chat area for a CSS/label fix.

## Change summary

The inline confirm state of the checkpoint-restore action ('Discard Edits') animates with a shimmering gradient, making it look like a spinner instead of a clickable confirmation button.

## Best solution

In src/vs/workbench/contrib/chat/browser/widget/media/chat.css, stop reusing `chat-thinking-shimmer` (line ~4350) for the `.chat-restore-checkpoint-item.confirming .action-label:first-child` state — use a static, clearly-button-styled treatment (e.g. solid background/border, no animation) so it reads as an actionable confirm button, possibly also tweaking the wording per the reporter's suggestion (e.g. a question mark).
