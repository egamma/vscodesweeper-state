# Issue #335330 — Agent cannot access files within folder when using remote ssh

[https://github.com/microsoft/vscode/issues/335330](https://github.com/microsoft/vscode/issues/335330)

## Summary

This Remote-SSH/NFS workspace-root canonicalization bug was fixed after the report was filed. Current code compares the resolved file path with the resolved workspace root, preventing in-workspace files from being misclassified as external.

## Change summary

Agent file tools request external-file permission for files inside a Remote-SSH workspace when the workspace path and its resolved NFS path differ.

## Best solution

Keep the fix from https://github.com/microsoft/vscode/pull/336243, including its regression coverage for a symlinked workspace root; no additional implementation is indicated by this report.
