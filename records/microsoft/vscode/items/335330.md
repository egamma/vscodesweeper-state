# Issue #335330 — Agent cannot access files within folder when using remote ssh

[https://github.com/microsoft/vscode/issues/335330](https://github.com/microsoft/vscode/issues/335330)

## Summary

The reported workspace-versus-canonical-path permission mismatch is addressed by a landed fix that resolves the workspace root before checking containment. Propose closing as completed based on the source trace; the reporter's SSH/NFS environment was not executed.

## Change summary

Copilot incorrectly requests external-file permission when reading an existing file inside a Remote-SSH workspace whose filesystem path resolves differently.

## Best solution

Keep the canonical workspace-root containment check introduced in bd41432b04c4789797177a81289585ddb2e3ac76, allowing reads within the resolved workspace while retaining confirmation for genuinely external targets.
