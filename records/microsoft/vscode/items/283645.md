# Issue #283645 — Support Scoped permissions to Singular Organization or Repo

[https://github.com/microsoft/vscode/issues/283645](https://github.com/microsoft/vscode/issues/283645)

## Summary

Keep open: current authentication supports minimal or broad OAuth permissions, not access limited to a selected repository or organization. This security-sensitive request has 21 upvotes, and a maintainer explicitly identifies it as the tracking issue for the missing permission granularity.

## Change summary

Allow Copilot authentication to grant access only to selected GitHub repositories or organizations rather than all repositories accessible to the account.

## Best solution

Authentication owners should retain this issue for repository- and organization-restricted authorization, coordinating the GitHub authorization capability and its adoption in VS Code. Minimal authentication is a partial alternative, not completion of the request, because it does not enable selectively authorized private-repository features.
