# Issue #258219 — Toggle chat mode command works when dropdown is disabled

[https://github.com/microsoft/vscode/issues/258219](https://github.com/microsoft/vscode/issues/258219)

## Summary

The bug remains source-reproducible on current main: Ctrl+. invokes the mode picker while a chat request is active, even though mode switching is disabled in that state.

## Change summary

Prevent the chat mode picker keyboard command from opening while the current request is in progress.

## Best solution

Make the mode-picker command and its Ctrl+. keybinding follow the same request-in-progress availability contract as mode switching, while preserving normal picker behavior when the chat is idle.
