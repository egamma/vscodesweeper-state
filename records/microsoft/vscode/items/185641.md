# Issue #185641 — Perl syntax highlighting bug with embedded JavaScript

[https://github.com/microsoft/vscode/issues/185641](https://github.com/microsoft/vscode/issues/185641)

## Summary

Still reproduces on current main — the Perl grammar's HTML HEREDOC embedding wraps each line individually with `text.html.basic`, but the HTML grammar's multi-line `<script>` block spans past the line boundary, preventing the HEREDOC end-marker from being recognized when `</script>` is the last content before the terminator line. No fix has landed; the Perl grammar file has not been updated since before the issue was filed.

## Change summary

Perl syntax highlighting fails to revert from HTML mode after an HTML HEREDOC containing a `<script>` block when `</script>` ends the last content line before the HEREDOC terminator.

## Best solution

Fix the interaction in the Perl TextMate grammar (`extensions/perl/syntaxes/perl.tmLanguage.json`) where the line-by-line HTML embedding (lines ~1510–1522, `begin: "^"`, `end: "\n"`, including `text.html.basic`) interacts badly with the HTML grammar's multi-line `<script>` scope. Alternatively, update the upstream `textmate/perl.tmbundle` grammar and pull the fix. The Ruby variant reported in the comments suggests a similar pattern in `extensions/ruby/syntaxes/ruby.tmLanguage.json`.
