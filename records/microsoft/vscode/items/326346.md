# Issue #326346 — Copilot Chat sessions not synchronized even though chat.sessionSync.enabled is true

[https://github.com/microsoft/vscode/issues/326346](https://github.com/microsoft/vscode/issues/326346)

## Summary

Working as designed: Chat session sync currently only supports repos with a github.com remote, and the reporter's workspace is backed by an internal Bitbucket server — a contributor confirmed this twice, and the source (`getGitHubRepoInfoFromContext` / `getGithubRepoIdFromFetchUrl`) only recognizes github.com remote URLs, so `_resolveRepository` returns `undefined` and sync is disabled with reason `no_repo`.

## Change summary

Session Sync (`chat.sessionSync.enabled`) doesn't sync local chat sessions to the Copilot Desktop app / github.com/copilot/agents even though the setting is enabled.

## Best solution

Keep the current scope (github.com-hosted repos only) as the shipped design; if broader git-host support is desired, that would need a separate, explicit feature request rather than being read into this bug report.
