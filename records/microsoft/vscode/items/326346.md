# Issue #326346 — Copilot Chat sessions not synchronized even though chat.sessionSync.enabled is true

[https://github.com/microsoft/vscode/issues/326346](https://github.com/microsoft/vscode/issues/326346)

## Summary

Keep open as a request for session sync with non-GitHub repositories: the maintainer-confirmed restriction remains in current source. The Azure Repos comment also identifies a separate Chronicle query gap, so closing the whole thread as designed would discard actionable feedback.

## Change summary

Support cloud session sync for Bitbucket and Azure Repos workspaces without making their locally indexed sessions disappear from Chronicle results.

## Best solution

Have the session-sync owner decide the supported contract for non-GitHub repository sessions, including their cloud identity and eligibility. Separately establish how Chronicle should retain access to local-only sessions when cloud sync is enabled.
