## Change summary

With `chat.agentHost.allowSignedOutWhenUsable` enabled and local BYOK models configured (working fine in the main Chat panel), the Agents window still shows a GitHub sign-in prompt instead of opening signed-out, contrary to the 1.133 release notes for this experimental setting.

## Best solution

Have the reporter confirm exact repro details (BYOK provider used, whether a regular editor window with the model registered was open alongside the Agents window, and Agent Host/Copilot output logs); if confirmed, the likely area is the sign-out window gate in src/vs/sessions/browser/sessionsAuthGate.ts together with how src/vs/platform/agentHost/node/copilot/copilotAgent.ts populates `_byokModels` from the `IByokLmBridgeRegistry` (src/vs/platform/agentHost/node/byokLmBridgeRegistry.ts) — that registry only reports models once some window has actively pushed a snapshot, which could explain a signed-out user still being gated if no serving connection has registered yet when the Agents window opens.

## Evidence

- **per-agent auth requirement:** src/vs/sessions/contrib/providers/agentHost/browser/baseAgentHostSessionsProvider.ts `resolveAgentAuthRequirement()` (used at line 2708) returns `GitHub` unless the agent's protected resources have dropped the requirement and it has at least one advertised model.
- **Copilot agent BYOK gating:** src/vs/platform/agentHost/node/copilot/copilotAgent.ts line ~1183-1186 only marks the Copilot protected resource `required: false` when `allowSignedOutWhenUsable` is on AND `this._byokModels.length > 0`, where `_byokModels` comes from `IByokLmBridgeRegistry.getModels()` (src/vs/platform/agentHost/node/byokLmBridgeRegistry.ts), which is populated only once a renderer connection has actively pushed a model snapshot — a timing/serving-connection dependency that could plausibly leave the Agents window gated even when a BYOK model works fine in a regular Chat window.
- **setting description:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts around line 1641 documents the setting as explicitly experimental, consistent with the rough edges reported here.
