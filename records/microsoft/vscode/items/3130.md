# Issue #3130 — Allow customization of mouse shortcuts

[https://github.com/microsoft/vscode/issues/3130](https://github.com/microsoft/vscode/issues/3130)

## Summary

Still the canonical, unimplemented request for general mouse-button/modifier bindings in keybindings.json; only narrow slices have shipped (editor.mouseMiddleClickAction, multiCursorModifier), so this stays open as the umbrella for the broader capability.

## Change summary

Allow users to customize mouse-button and mouse+modifier shortcuts (e.g. alt+click add cursor, middle-click actions) rather than having them hard coded.

## Best solution

Keep open as the canonical umbrella and, when the team picks it up, design a keybindings.json mouse-gesture syntax (button + modifiers) on top of the newer Electron mouse-button events, covering editor, terminal links, lists/tabs — not just the editor-only settings that exist today.
