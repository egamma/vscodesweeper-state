# Issue #340248 — Extension Incompatibility in vscode.dev Environment

[https://github.com/microsoft/vscode/issues/340248](https://github.com/microsoft/vscode/issues/340248)

## Summary

Reports a transient version-skew issue where vscode.dev's deployed VS Code version (1.140.0) lags behind the minimum engine version (^1.141.0) required by the latest GitHub Pull Requests/Repositories extension builds — this is an operational deployment-timing gap, not a code defect in this repository, and it typically self-resolves once the web host rolls forward.

## Change summary

On vscode.dev, users cannot install current GitHub Pull Requests / GitHub Repositories extension versions because the production web build (1.140.0) is behind the extensions' required engine version (^1.141.0).

## Best solution

No code change needed in microsoft/vscode core; this resolves itself when vscode.dev's deployed version catches up to 1.141.0+. If it persists for more than a few days, it may be worth flagging to whichever team manages the vscode.dev release cadence, but that's an operational/deployment concern rather than a source fix.
