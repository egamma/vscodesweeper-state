# Issue #302181 — Skills duplication when 'Agent Skills Location' overlaps with 'Plugin Locations'

[https://github.com/microsoft/vscode/issues/302181](https://github.com/microsoft/vscode/issues/302181)

## Summary

The skills duplication was addressed after this report, but the expanded MCP case remains relevant: current main disables colliding MCP servers while retaining each entry in management UI data. Route this older issue to AI customization/MCP management rather than closing it or making it a duplicate of the younger related report.

## Change summary

Deduplicate skills and MCP servers discovered through overlapping standalone and plugin locations so users do not see indistinguishable repeated entries.

## Best solution

Preserve the existing deterministic skill and MCP collision precedence, then make every MCP management surface consistently represent collision losers—either omit them or clearly identify them as disabled duplicates with their source. Consolidate the remaining UI decision and evidence here because this issue predates https://github.com/microsoft/vscode/issues/316362.
