# Issue #302181 — Skills duplication when 'Agent Skills Location' overlaps with 'Plugin Locations'

[https://github.com/microsoft/vscode/issues/302181](https://github.com/microsoft/vscode/issues/302181)

## Summary

Keep open: current slash-command discovery can still expose the same skill file twice when standalone and plugin locations overlap, because the two discoveries receive different command names. MCP collision handling now exists, but that does not establish that the reporter's Configure Tools duplication is resolved.

## Change summary

Avoid duplicate skill entries from overlapping standalone and plugin discovery, and address the reported analogous MCP duplication in Configure Tools.

## Best solution

Present one skill entry for the same underlying file without collapsing distinct skills from different plugins. Establish which command identity survives overlapping discovery, and assess the MCP UI symptom separately from the collision handling that already prevents same-named servers from being enabled together by default.
