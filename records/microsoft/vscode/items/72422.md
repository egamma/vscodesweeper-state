# Issue #72422 — [folding] selecting first line of folded range does not select full folded range

[https://github.com/microsoft/vscode/issues/72422](https://github.com/microsoft/vscode/issues/72422)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/59657 reports the same observable behavior—selecting the line number of a collapsed range selects only its first line rather than the complete folded range.

## Change summary

Make line selection on a collapsed range include the entire hidden range so copying, moving, or deleting the selection operates on the complete block.

## Best solution

Consolidate the selection behavior and its copy/delete use cases on https://github.com/microsoft/vscode/issues/59657; selecting the full folded range there resolves this report's central problem. The separate cursor-at-end and Enter behavior remains tracked by https://github.com/microsoft/vscode/issues/91600.
