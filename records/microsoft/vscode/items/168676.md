# Issue #168676 — Extension commands do not show any status indicator while waiting for activation

[https://github.com/microsoft/vscode/issues/168676](https://github.com/microsoft/vscode/issues/168676)

## Summary

Still valid: the command service has no progress indicator during extension activation or extension host startup. The existing ExtensionActivationProgress only fires after onWillActivateByEvent, leaving a gap during host startup. Team members agreed on a command-service-level indicator (comments 11–12) but it was never implemented.

## Change summary

Show a status indicator in the command service when a command triggers extension activation, especially covering the extension host startup gap.

## Best solution

Add a progress indicator in the command service (src/vs/workbench/services/commands/common/commandService.ts) that shows while awaiting activation in executeCommand — covering both the extension host startup delay and the activation itself. This was the agreed direction between alexdima and jrieken in the thread.
