# Issue #188246 — incorrect indentation detection

[https://github.com/microsoft/vscode/issues/188246](https://github.com/microsoft/vscode/issues/188246)

## Summary

The supplied formatted HTML still yields an eight-space guess in current source: repeated eight-space transitions outweigh the four-space indentation evidence. Keep this open; the related closed HTML report concerns a different case and does not establish a fix or a full-scope decline.

## Change summary

Reopening HTML formatted with four-space indentation incorrectly detects eight-space indentation when inline nested elements produce deeper continuation lines.

## Best solution

Improve indentation inference so the supplied four-space HTML retains its indentation on reopening, while preserving correct detection of genuinely eight-space files. Evaluate the shared heuristic against existing indentation cases before choosing an adjustment; language-specific parsing is not the established detection model.
