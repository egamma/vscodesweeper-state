# Issue #315718 — Agents window should make it easier to start a new project

[https://github.com/microsoft/vscode/issues/315718](https://github.com/microsoft/vscode/issues/315718)

## Summary

Keep open: the Agents window still offers folder selection rather than an explicit new-project entry point. Folder creation inside the subsequent dialog provides a workaround, but does not address the requested discoverability.

## Change summary

Make starting a new project discoverable from the Agents window workspace dropdown.

## Best solution

Provide a clearly named new-project entry point in the Agents workspace picker that lets users create and select a project folder, while retaining the existing open-folder workflow.
