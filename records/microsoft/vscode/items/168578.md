# Issue #168578 — A setting to make the bracket pair highlight border highlight the same brackets as the bracket pair guides

[https://github.com/microsoft/vscode/issues/168578](https://github.com/microsoft/vscode/issues/168578)

## Summary

Keep this accepted feature request open: current settings do not make bracket-match borders follow the active bracket guides, and no verified canonical absorbs that requirement. It has 23 community upvotes and explicit maintainer interest in an optional setting.

## Change summary

Provide an opt-in setting that makes bracket-match borders identify the same enclosing pair as the active bracket guides at bracket boundaries.
