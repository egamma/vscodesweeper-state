# Issue #342876 — Provide authoritative harness identification for enterprise migration and MCP configuration

[https://github.com/microsoft/vscode/issues/342876](https://github.com/microsoft/vscode/issues/342876)

## Summary

Keep open as a feature request: current identity prompts describe Copilot branding or SDK usage, but do not establish the requested stable, cross-harness runtime identification contract for migration skills.

## Change summary

Expose authoritative active-harness identification to agents and skills, ideally with a corresponding SDK/runtime API.

## Best solution

Define a runtime-owned harness identity contract that skills can consume consistently across Local and Copilot sessions, distinguishing harness identity from model identity and UI branding. Keep MCP credential handling separate: identifying a harness does not establish its authentication capabilities or authorize access to secrets.
