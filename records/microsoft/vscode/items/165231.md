# Issue #165231 — Use the Flyweight pattern to encode tokens

[https://github.com/microsoft/vscode/issues/165231](https://github.com/microsoft/vscode/issues/165231)

## Summary

Team-authored tokenization memory optimization proposal. The current encoding still uses a full Uint32Array (4 bytes per token metadata); no flyweight/dictionary encoding has been implemented on main. Stays open as an unimplemented optimization idea in the Backlog.

## Change summary

Use a flyweight/dictionary pattern for token metadata to reduce memory usage to roughly one quarter of the current encoding.

## Best solution

Implement a dictionary-based token metadata encoding in the tokenization layer (src/vs/editor/common/tokens/) so that repeated metadata values share a single dictionary entry, reducing per-token storage from 4 bytes to 1–2 bytes. Requires careful benchmarking of both memory and CPU impact on large files.
