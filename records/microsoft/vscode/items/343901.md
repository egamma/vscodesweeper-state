# Issue #343901 — Allow right click to hide options

[https://github.com/microsoft/vscode/issues/343901](https://github.com/microsoft/vscode/issues/343901)

## Summary

Keep open: existing picker context menus support collapsing labels to icons, but do not let users hide the session-options disclosure itself. This team-authored request needs a product decision between optional visibility and removing the disclosure.

## Change summary

Allow users to hide individual session-option controls, including the disclosure toggle, through a context menu, or remove the redundant toggle.

## Best solution

Let users retain compact session pickers without an unwanted disclosure control. Decide whether the disclosure should remain optionally available or disappear, preserving keyboard access and existing options-visibility behavior where retained.
