# Issue #349485 — Agents window: Go to File on a remote agent host follows symlink loops and ignores `.git/info/exclude`

[https://github.com/microsoft/vscode/issues/349485](https://github.com/microsoft/vscode/issues/349485)

## Summary

The current source confirms both defects: remote filename search recursively follows directory aliases without cycle detection and never loads `.git/info/exclude`. Keep this report open; the related Explorer request and ignore-parser PR do not cover the full problem.

## Change summary

Make remote Agents-window Go to File terminate on symlink cycles and honor repository-local Git exclusions.

## Best solution

Restore cycle-safe remote filename enumeration and Git exclusion parity without disabling legitimate symlink traversal. Preserve cancellation, shared caching, remote URI identity, and compatibility with other filesystem providers and conforming agent hosts.
