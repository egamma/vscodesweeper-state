# Issue #349485 — Agents window: Go to File on a remote agent host follows symlink loops and ignores `.git/info/exclude`

## Summary

Keep open: current source confirms unchecked recursive traversal, missing repository-local excludes, and a bypassed absolute-path lookup in session-scoped search. The report supplies a complete reproduction; no verified canonical covers all three failures.

## Change summary

Remote agent-host Go to File traverses symlink cycles, ignores .git/info/exclude, and fails to resolve absolute or home-relative host paths directly.

## Best solution

Restore remote Go to File parity: terminate cyclic traversal, honor repository-local search ignores, and resolve explicit paths on the session's owning host without waiting for workspace enumeration. Address the filesystem/search and session-scoped path-resolution boundaries together while preserving cancellation, ignore overrides, and remote access checks.
