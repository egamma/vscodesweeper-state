# Issue #321806 — Flexible "Centered Layout"

[https://github.com/microsoft/vscode/issues/321806](https://github.com/microsoft/vscode/issues/321806)

## Summary

This is a valid request to change Centered Layout semantics rather than a defect with a settled expectation. The current behavior centers the editor within the remaining editor area, while the report asks for window-relative centering plus a minimum usable width; with limited demand and no maintainer decision, it should remain open for discussion.

## Change summary

Make Centered Layout remain aligned to the whole window and stop reserving centering margins when doing so would make the editor too narrow.

## Best solution

Define responsive Centered Layout behavior in the workbench layout area: preserve a useful minimum editor width as sidebars or window tiling reduce space, and decide whether centering should be relative to the full window or the available editor region. Consider the comment's configurable-width request separately from the central responsive-layout behavior to avoid unnecessary configuration complexity.
