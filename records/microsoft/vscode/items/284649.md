# Issue #284649 — Feature Request: Secure, Policy-Enforced Context Retention Architecture for GitHub Copilot Chat

[https://github.com/microsoft/vscode/issues/284649](https://github.com/microsoft/vscode/issues/284649)

## Summary

This security-sensitive feature request remains broader than current memory and managed-permission support: current main has scoped persistent memory and partial expiration, but not the requested policy-governed retention, context allow/deny controls, and audit architecture. It should remain open under discussion rather than be closed for age or lack of reactions.

## Change summary

Provide policy-enforced, auditable Copilot Chat context retention with scoped memory, expiration, administrative controls, isolation, and data-leakage protections.

## Best solution

Define retention and context-access controls in the shared Copilot runtime managed-settings contract, with authoritative enforcement where context is collected or persisted, while VS Code supplies only editor-owned configuration and visibility. The design should specify storage lifetimes, repository and file scoping, audit events, service boundaries, and which guarantees require Copilot service changes.
