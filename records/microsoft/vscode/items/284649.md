# Issue #284649 — Feature Request: Secure, Policy-Enforced Context Retention Architecture for GitHub Copilot Chat

[https://github.com/microsoft/vscode/issues/284649](https://github.com/microsoft/vscode/issues/284649)

## Summary

Keep open as a security-sensitive Copilot architecture request. Current main provides opt-in session sync, organization-level disabling, repository exclusions, and deletion, but the broader retention-lifetime, auditability, and context-governance requirements remain unaddressed.

## Change summary

Provide policy-enforced Copilot context retention with expiration, scoped authorization, isolation, auditing, and controls against sensitive-data ingestion.

## Best solution

Define the retention and context-access contract in the shared Copilot managed-settings/runtime layer, where enforcement can cover storage and model execution, while retaining VS Code configuration policy only for editor-owned behavior. The design should specify retention lifetimes, deletion guarantees, authorization scopes, audit events, and the trust boundaries between VS Code, the runtime, and the service.
