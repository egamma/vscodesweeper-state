# Issue #346925 — MD Editor: add comment widget should allow sending the comment to chat immediately with `option/alt+enter`

[https://github.com/microsoft/vscode/issues/346925](https://github.com/microsoft/vscode/issues/346925)

## Summary

The Markdown comment widget lacks the normal editor's Add and Submit path. Keep this request open: submitting existing feedback separately does not cover sending the draft immediately with Option/Alt+Enter.

## Change summary

Support Option/Alt+Enter in the Markdown editor's comment input to add the comment and immediately submit it to chat.

## Best solution

Give Markdown comments the same explicit Add and Submit interaction as normal-file feedback, while preserving the existing add-only behavior.
