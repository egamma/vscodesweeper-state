# Issue #226423 — Allow more than 9 items in the title bar

[https://github.com/microsoft/vscode/issues/226423](https://github.com/microsoft/vscode/issues/226423)

## Summary

Keep open under discussion: the fixed nine-action title-bar limit remains a real UX gap, and a maintainer has endorsed exploring a width-based alternative. The Backlog milestone permits merits-based review, but there is no verified implementation or older same-symptom canonical supporting closure.

## Change summary

Replace the title-bar toolbar's fixed nine-item cap with capacity based on available width so additional actions remain visible when space permits.

## Best solution

Let the workbench title-bar toolbar display as many actions as fit its available width, moving only overflowed actions into the overflow menu while preserving responsive layout and window-control space.
