# Issue #86184 — Suggest widget has greyscale rendering

[https://github.com/microsoft/vscode/issues/86184](https://github.com/microsoft/vscode/issues/86184)

## Summary

A real suggest-widget rendering gap remains on current main. The issue is already correctly routed and should stay open as targeted visual polish.

## Change summary

Render suggest-widget text with subpixel antialiasing instead of grayscale antialiasing on supported Linux and Windows displays.

## Best solution

Give the suggest list's composited rows layer an opaque `editorSuggestWidget.background` while preserving the scrolling optimization, likely through the list styles in `suggestWidget.ts`.
