# Issue #329343 — Switching between chats doesn't persist the scroll location for the chat

[https://github.com/microsoft/vscode/issues/329343](https://github.com/microsoft/vscode/issues/329343)

## Summary

This is the exact scenario fixed by the general 'preserve scroll position between sessions' change that landed on main a few days after this was filed — closing as completed.

## Change summary

In the Agents Window, using `/btw` to branch a side chat and then switching back to the original chat resets the transcript scroll to the bottom instead of restoring the prior position.

## Best solution

Keep the fix from commit aa5ead32578 (PR #329844): ChatView now saves/restores per-resource scroll state via SessionsChatViewStateService whenever setChat swaps the bound chat resource, which covers the `/btw` side-chat round trip described here.
