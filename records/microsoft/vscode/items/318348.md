# Issue #318348 — Make the notebook's scrollbar resizable

[https://github.com/microsoft/vscode/issues/318348](https://github.com/microsoft/vscode/issues/318348)

## Summary

Valid feature request: the notebook's page-level scrollbar size is not configurable — the existing `editor.scrollbar.verticalScrollbarSize` only applies to Monaco editor instances, not the notebook list scrollable. No setting or configuration for this exists on current main.

## Change summary

Allow configuring the notebook page scrollbar size, similar to `editor.scrollbar.verticalScrollbarSize` for text editors.

## Best solution

Expose a notebook-specific scrollbar size setting (e.g. `notebook.scrollbar.verticalScrollbarSize`) that feeds into the `NotebookCellList`'s `ScrollableElement` options, or unify the workbench list scrollbar sizing under the existing `editor.scrollbar` settings. The implementation would likely touch `src/vs/workbench/contrib/notebook/browser/view/notebookCellList.ts` where the list's scrollable element is created.
