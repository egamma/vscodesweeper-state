# Issue #318348 — Make the notebook's scrollbar resizable

[https://github.com/microsoft/vscode/issues/318348](https://github.com/microsoft/vscode/issues/318348)

## Summary

Notebook page-scrollbar sizing remains a real configuration gap: the text-editor scrollbar settings do not control the notebook's outer cell list. The older workbench scrollbar request is related, but it does not establish the same notebook-specific symptom required to close this re-reviewed item as a duplicate.

## Change summary

Allow users to enlarge the notebook page scrollbar, preferably through sizing settings consistent with other editor and workbench surfaces.

## Best solution

Provide consistent scrollbar-size configuration that includes the notebook's outer cell list, rather than requiring users to target a narrow page scrollbar while nested cells consume scrolling. Coordinate the configuration contract with the existing workbench scrollbar discussion without treating that related discussion as a verified notebook duplicate.
