# Issue #164060 — unknown webview view

[https://github.com/microsoft/vscode/issues/164060](https://github.com/microsoft/vscode/issues/164060)

## Summary

The error path remains on current main — `getWebviewView` in mainThreadWebviewViews.ts still throws an unguarded 'unknown webview view' when an extension interacts with a disposed/removed webview view. The race condition is unresolved.

## Change summary

Extensions calling $setWebviewViewTitle (or similar) on a webview view that has already been disposed triggers an unhandled 'unknown webview view' error.

## Best solution

Guard `getWebviewView` to return gracefully (log a warning or silently no-op) when the handle is missing from `_webviewViews`, since this is a known race between extension host messages and view disposal. The fix belongs in `src/vs/workbench/api/browser/mainThreadWebviewViews.ts`.
