# Issue #329313 — Hybrid Markdown editor: Cut and paste do nothing in Editing mode

[https://github.com/microsoft/vscode/issues/329313](https://github.com/microsoft/vscode/issues/329313)

## Summary

Well-diagnosed bug in the experimental Hybrid Markdown editor's Editing mode — cut/paste keyboard shortcuts (and paste context menu) are no-ops because clipboard events aren't routed to the custom EditorModel. An open PR (#329397) with "Fixes #329313" already implements the fix, so this should stay open until that PR merges rather than being closed now.

## Change summary

In the experimental Hybrid Markdown editor's Editing mode, Cut (Cmd/Ctrl+X) and Paste (Cmd/Ctrl+V) do nothing, while typing, deletion, and copy work correctly.

## Best solution

Review and land the fix in https://github.com/microsoft/vscode/pull/329397, which adds explicit clipboard/keydown handlers in extensions/markdown-language-features/markdown-editor-src/editor.ts to apply StringEdit replacements to the EditorModel; close this issue once that PR merges.
