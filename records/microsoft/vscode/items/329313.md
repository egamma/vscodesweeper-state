# Issue #329313 — Hybrid Markdown editor: Cut and paste do nothing in Editing mode

[https://github.com/microsoft/vscode/issues/329313](https://github.com/microsoft/vscode/issues/329313)

## Summary

Real bug in the experimental Hybrid Markdown editor's Editing mode, confirmed independently on macOS and Windows, with an open PR from the original reporter already proposing a fix — keep open until that PR is reviewed and merged.

## Change summary

In the experimental Hybrid Markdown editor's Editing mode, Cut and Paste (keyboard shortcuts, and on Windows also via context menu per one commenter) do nothing, while typing, deleting, and copy all work.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/329397, which intercepts webview clipboard events/keydowns and applies edits directly to the Markdown EditorModel; keep the issue open until that PR merges.
