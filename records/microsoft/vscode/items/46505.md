# Issue #46505 — Feature Request : SHOW / HIDE comments in editor

[https://github.com/microsoft/vscode/issues/46505](https://github.com/microsoft/vscode/issues/46505)

## Summary

Keep this canonical feature request open. It has 273 community upvotes and remains materially unsatisfied: current folding and extension workarounds do not remove full-line and inline comments from the editor layout.

## Change summary

Add a language-aware editor mode that temporarily hides comments without changing the underlying document.

## Best solution

Design a language-aware editor visualization that removes comment-only lines from layout, suppresses inline comments where practical, and reveals hidden comments for navigation and editing. It likely belongs in the editor rendering/folding area and must preserve model positions, accessibility, diagnostics, and language-feature behavior.
