# Issue #118833 — Notebook output must support more ANSI sequences

[https://github.com/microsoft/vscode/issues/118833](https://github.com/microsoft/vscode/issues/118833)

## Summary

The gap remains: notebook output ANSI handling on current main is still limited to backspace, carriage return, and a single hard-coded ESC[A (cursor up 1 line). The broader CSI sequences requested (ESC[K, ESC[nA, ESC[nB) are not implemented.

## Change summary

Notebook output should support additional ANSI escape sequences (cursor movement, erase-in-line) so progress bars and terminal-style output render correctly.

## Best solution

Implement a more holistic ANSI sequence processor in `src/vs/workbench/contrib/notebook/common/notebookCommon.ts` (around the `compressStreamBuffer`/`formatStreamText` functions) that handles at minimum ESC[K (erase in line), ESC[nA/ESC[nB (cursor up/down n lines), and ideally a broader subset of CSI sequences. This would eliminate workarounds in the Jupyter extension and fix progress bar rendering for Julia, R, and Python kernels.
