# Issue #273097 — Terminal link hover stopped being a link

[https://github.com/microsoft/vscode/issues/273097](https://github.com/microsoft/vscode/issues/273097)

## Summary

Still unfixed on main: the terminal link hover tooltip renders as plain text rather than a styled clickable link. Both community fix PRs were closed without merging; no other fix has landed.

## Change summary

Terminal link hover tooltip text lost its visual link styling (underline/link color), so clicking the text in the hover no longer looks or behaves like a hyperlink.

## Best solution

Restore the visual link presentation in the terminal hover tooltip — either fix the CSS selector matching for links inside the xterm-hover or ensure the markdown link rendered by `_getLinkHoverString` produces a proper `<a>` tag in the tooltip DOM. The fix lives in the intersection of `src/vs/workbench/contrib/terminalContrib/links/browser/terminalLinkManager.ts` (hover string construction) and the hover widget rendering pipeline.
