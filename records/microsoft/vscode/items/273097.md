# Issue #273097 — Terminal link hover stopped being a link

[https://github.com/microsoft/vscode/issues/273097](https://github.com/microsoft/vscode/issues/273097)

## Summary

Keep open: current source can strip the terminal hover's link when its target is a raw file path, preventing mouse-only activation. Related reports consolidate here, and neither linked fix proposal was merged.

## Change summary

Restore clickable terminal hover links so detected files can be opened without holding a keyboard modifier.

## Best solution

Preserve a clickable hover action for detected terminal file links, including Windows paths and paths containing spaces, while retaining existing file-opening behavior and shared markdown sanitization protections.
