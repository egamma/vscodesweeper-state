# Issue #337255 — Cannot rearrange chats that appear in the session list

[https://github.com/microsoft/vscode/issues/337255](https://github.com/microsoft/vscode/issues/337255)

## Summary

Keep open: current main supports drag-and-drop ordering only within compatible sections, while fixed placement and grouping rules can still prevent the user-defined ordering requested here. This is also a team-authored product request, so it should remain open unless an explicitly linked implementation or canonical duplicate is found.

## Change summary

Allow users to manually arrange chats in the Sessions list, including placing finished chats at the top.

## Best solution

Define how explicit user ordering interacts with workspace/date grouping and archived or finished state, then make the chosen order persistent across reloads. The key product decision is whether manual placement may cross or override section boundaries rather than remaining section-local.

- **Open decisions:**
