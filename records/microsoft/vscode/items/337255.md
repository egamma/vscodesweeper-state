# Issue #337255 — Cannot rearrange chats that appear in the session list

[https://github.com/microsoft/vscode/issues/337255](https://github.com/microsoft/vscode/issues/337255)

## Summary

Team-authored feature request (author is a VS Code maintainer) asking for manual ordering/pinning of sessions in the Agents Window session list — current code only supports automatic grouping/sorting (by date/recency via `groupByDate`/`SessionsSorting`), with no drag-to-reorder or pin mechanism, so this is a real, unimplemented gap that should stay open for design.

## Change summary

Allow reordering (e.g. pinning finished chats to the top) of chats in the Agents Window session list; currently no drag & drop or other means exists to do this.

## Best solution

Design a pin/manual-order mechanism for the sessions list (likely in src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts, alongside the existing SessionsSorting/groupByDate logic) — decide whether it's a per-session pinned flag or a fully custom order, and how it persists and interacts with the existing date-based grouping.

- **Trace:**

  > sessionsList.ts groups/sorts sessions purely via groupByDate() and SessionsSorting (by created/updated timestamp) with no persisted manual order or pin flag; existing drag-and-drop code (chatGroupDropTarget.ts, sessionDropTarget.ts) moves sessions between groups/panels rather than reordering within a group. Boundary: don't disturb the existing date-based grouping fallback or the cross-panel drag targets. Where uncertainty starts: whether the reorder is a lightweight 'pin to top' flag or a fully general custom order, and how/where it's persisted (per-workspace vs. global state).
- **Open decisions:**

  - Should a manually ordered/pinned session still move between the existing date-based groups (Today/This Week/Older), or should pinning create its own group?
