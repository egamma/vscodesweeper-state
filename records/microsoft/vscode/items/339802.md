# Issue #339802 — [Error] unhandlederror-[UriError]: If a URI contains an authority component, then the path component must begin with a slash — a

[https://github.com/microsoft/vscode/issues/339802](https://github.com/microsoft/vscode/issues/339802)

## Summary

Confirmed regression in the agent-host URI wrapper, and a fix is already up as an open PR that names this issue — per policy this stays open for that PR to land rather than being closed now.

## Change summary

Wrapping an opaque URI with a rootless path (e.g. `untitled:Untitled-1`) into an agent-host URI throws a UriError because RFC 3986 requires an authority-bearing URI's path to be empty or start with `/`.

## Best solution

Review and merge https://github.com/microsoft/vscode/pull/339814, which synthesizes a leading slash for rootless paths in `wrapAgentHostUri` (src/vs/platform/agentHost/common/agentHostUri.ts) and records a `rootlessPath` flag so the original path is restored on unwrap, with a matching round-trip test added.
