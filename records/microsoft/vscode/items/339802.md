## Change summary

A path-less agent-host URI with a non-empty authority throws a UriError when constructed via `toAgentHostUri`/`wrapAgentHostUri`, surfacing as an unhandled error in agent session customizations/input pills.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/339814, which wraps agent-host URIs with rootless paths so `wrapAgentHostUri` never passes an empty path alongside a non-empty authority to `URI.from`.
