# Issue #291990 — Copilot CLI shim (copilot.ps1) fails to find npm-installed binary on Windows when both are in PATH

[https://github.com/microsoft/vscode/issues/291990](https://github.com/microsoft/vscode/issues/291990)

## Summary

Still reproduces on main: the `Find-RealCopilot` function in `copilotCLIShim.ps1` uses `Get-Command copilot` which resolves the `.ps1` shim before `copilot.cmd` from npm, and stripping the shim directory from PATH doesn't help because PowerShell's `Get-Command` for the bare name `copilot` won't match `copilot.cmd`. The bug is confirmed in current source with no fix landed.

## Change summary

The PowerShell shim's `Find-RealCopilot` function fails to discover an npm-installed `copilot.cmd` on Windows because `Get-Command copilot` does not resolve `.cmd` extensions.

## Best solution

Update `Find-RealCopilot` in `copilotCLIShim.ps1` to explicitly probe for `copilot.cmd` (and `copilot.exe`) in PATH directories or via `npm config get prefix`, rather than relying solely on `Get-Command copilot` which misses `.cmd` files in PowerShell.
