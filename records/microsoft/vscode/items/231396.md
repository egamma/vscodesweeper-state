[https://github.com/microsoft/vscode/issues/231396](https://github.com/microsoft/vscode/issues/231396)

## Summary

The keyboard invocation still has a source-confirmed failure: the command assumes a URI argument that an ordinary keybinding does not supply. Keep this report open; the newer command-improvement collection is related but does not meet the re-review duplicate bar.

## Change summary

Invoking multiDiffEditor.goToFile through a keybinding while a diff file is focused throws instead of opening that file.

## Best solution

Make the command usable from the focused multi-diff entry without requiring a URI argument, while preserving explicit-resource toolbar behavior, target-file overrides, and selection handling.
