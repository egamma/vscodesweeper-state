# Issue #138762 — Code Lenses are trimmed to the line length

[https://github.com/microsoft/vscode/issues/138762](https://github.com/microsoft/vscode/issues/138762)

## Summary

The requested capability remains absent on main, and this accepted Backlog feature request has 33 community upvotes. It should remain open for CodeLens UX design rather than be closed or reclassified.

## Change summary

Allow CodeLens commands that exceed the available editor width to remain accessible, potentially by wrapping them across multiple rows.

## Best solution

Design an overflow treatment in the CodeLens widget that preserves access to every command without unexpectedly obscuring code or destabilizing editor layout; wrapping, an overflow menu, or another compact presentation should be evaluated in the code-lens area.
