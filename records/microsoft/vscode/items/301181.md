## Summary

Valid feature request to extend org-level sync to also distribute skills — instructions sync already exists (`GitHubOrgInstructionsProvider`), and the remaining gap is skills from org repos. The issue has hit the 20-upvote threshold for backlog promotion. Routing to copilot/chat-prompts for area ownership.

## Change summary

Extend GitHub org repository synchronization to distribute skills (SKILL.md) alongside agents and instructions.

## Best solution

Add a `GitHubOrgSkillsProvider` analogous to the existing `GitHubOrgInstructionsProvider` and `GitHubOrgCustomAgentProvider`, extending `getCacheSubdirectory` and `isValidFile` in `githubOrgChatResourcesService.ts` to handle `PromptsType.skill`. The reporter's claim that instructions are not synced is outdated — instructions already sync via `GitHubOrgInstructionsProvider`; only skills remain. Consider consolidating with https://github.com/microsoft/vscode/issues/291685 which covers the same broader sharing need.
