# Issue #138998 — column number bug with emojis

[https://github.com/microsoft/vscode/issues/138998](https://github.com/microsoft/vscode/issues/138998)

## Summary

Still reproduces on main: `CursorColumns.toStatusbarColumn` uses `CodePointIterator` (counts individual code points) instead of `GraphemeIterator` (counts grapheme clusters), so multi-code-point emoji sequences inflate the status bar column number.

## Change summary

Status bar column number is incorrect when the line contains multi-code-point emojis (skin-toned, ZWJ sequences, flag emojis).

## Best solution

Replace `CodePointIterator` with `GraphemeIterator` in `CursorColumns.toStatusbarColumn` (`src/vs/editor/common/core/cursorColumns.ts`), mirroring the approach already used in `columnFromVisibleColumn` at line 83 of the same file. Update the tests in `cursorColumns.test.ts` to include ZWJ emoji test cases.
