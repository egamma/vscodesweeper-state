# Issue #283617 — Cloud agent to continue after VS Code is closed

[https://github.com/microsoft/vscode/issues/283617](https://github.com/microsoft/vscode/issues/283617)

## Summary

Current source delegates cloud work to server-side tasks, but it does not establish that the full requested experience—continued execution after exit plus emailed results—is covered. Keep this accepted Backlog request open; no qualifying canonical or post-reopen fix was verified.

## Change summary

Allow cloud agents to finish after VS Code closes and email their results to the initiating account.

## Best solution

Establish whether existing cloud-task execution and account notifications already deliver both parts of the request. Retain server-side execution independent of the editor, and have the cloud-agent owners decide whether existing completion notifications suffice or a results-email capability remains necessary.
