## Evidence

- **Verified open canonical:** https://github.com/microsoft/vscode/issues/57488 was created on 2018-08-29 and remains OPEN with bug and git labels. Its discussion includes the same KDE/KWallet helper bypass and repeated GUI authentication prompts, not merely unrelated SSH connection failures.
- **Matching symptom and workaround:** https://github.com/microsoft/vscode/issues/57488#issuecomment-1413903793 explicitly describes KDE with KWallet/ksshaskpass and configuring GIT_ASKPASS, SSH_ASKPASS and SSH_ASKPASS_REQUIRE while disabling git.useIntegratedAskPass. https://github.com/microsoft/vscode/issues/57488#issuecomment-2072932511 confirms repeated pull/push/fetch prompts stop with that configuration. This report links that comment, and Rua confirmed the same workaround on 2025-07-09 while requesting a built-in fix.
- **Current source explains the exact trigger:** extensions/git/src/askpass.ts:45-48 replaces SSH_ASKPASS with the built-in script and SSH_ASKPASS_REQUIRE with force. Askpass.getEnv at lines 161-164 supplies those overrides when git.useIntegratedAskPass is enabled; extensions/git/src/main.ts:82 passes them into Git, and extensions/git/src/git.ts:695 merges them after process.env. Thus GUI Git bypasses the reporter's inherited ksshaskpass configuration.
- **GUI versus terminal behavior:** Askpass.handleSSHAskpass in extensions/git/src/askpass.ts:115-143 returns a fresh input-box response for passphrase requests without wallet retrieval or passphrase caching. Askpass.getTerminalEnv at lines 166-169 supplies only the Git askpass environment, not the SSH overrides, explaining why terminal Git can still use the configured SSH helper.
- **Existing capability is a workaround:** extensions/git/package.json:3957-3960 registers git.useIntegratedAskPass with default true. Setting it false makes Askpass.getEnv return no overrides, preserving inherited helpers, but does not add KWallet interoperability to the built-in handler. Source inspection therefore supports consolidation, not an implemented-on-main or as-designed close; no runtime reproduction was performed.
