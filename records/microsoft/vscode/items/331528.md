# Issue #331528 — Promo banner close action shows underline on hover

[https://github.com/microsoft/vscode/issues/331528](https://github.com/microsoft/vscode/issues/331528)

## Summary

Traced on main: the generic 'links in a notice' hover rule in chatInputNotice.css also matches the notice's icon-button actions (dismiss/mute), so the close (X) action on the promo notification gets an underline on hover even though it's not a text link. Real, small, localized CSS specificity bug — keep open and route to the chat area for a fix.

## Change summary

The close (X) action on the chat input promo notification shows a text underline on hover, when it should just change color like other icon buttons.

## Best solution

Scope the underline-on-hover rule in chatInputNotice.css so it only applies to genuine text links, not to `.chat-input-notice-action .action-label` icon buttons (dismiss, mute) that happen to be rendered as `<a>` elements by the shared ActionBar/ActionViewItem.
