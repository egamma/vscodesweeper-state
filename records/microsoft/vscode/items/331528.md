# Issue #331528 — Promo banner close action shows underline on hover

[https://github.com/microsoft/vscode/issues/331528](https://github.com/microsoft/vscode/issues/331528)

## Summary

Real, source-confirmed CSS bug in the chat input notice (promo banner) component; it already carries the correct area label and a real release milestone (1.135.0), so per the hard keep-open rules this cannot be proposed for closing regardless of how fixable it looks.

## Change summary

The close action on the chat input promo/notification banner shows a text underline on hover, which should not happen for an icon-only action button.

## Best solution

Scope the underline rule in chatInputNotice.css so it only applies to genuine text links, not ActionBar action-label anchors used for icon actions like the close button.
