# Issue #336560 — Copilot refuses to implement an explicitly requested in-app help page due to bundled frontend instructions

[https://github.com/microsoft/vscode/issues/336560](https://github.com/microsoft/vscode/issues/336560)

## Summary

Confirmed on main: the design-instructions guideline in the GPT-6/GPT-5.5 agent prompts (e.g. extensions/copilot/src/extension/prompts/node/agent/openai/gpt6Prompt.tsx line 112) tells the model not to use visible in-app text describing app features/usage, with no carve-out for a user-explicitly-requested help/documentation page — matching the reporter's transcript. This is a real prompt-wording gap, not fixed by the most recent prompt update (commit 7f9e1f90, PR #336859, which touched this file but not this line).

## Change summary

Copilot's agent-mode frontend design instructions cause it to refuse building an explicitly user-requested in-app help page, citing a blanket 'no explanatory in-app text' rule as higher priority than the user's request.

## Best solution

Soften the design_instructions line in the OpenAI agent prompts (gpt6Prompt.tsx, gpt55Prompt.tsx, gpt55BasePrompt.tsx, gpt56Prompt.tsx) so it still discourages unsolicited explanatory UI clutter but explicitly allows a dedicated, user-requested help/documentation surface.
