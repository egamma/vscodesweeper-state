# Issue #336560 — Copilot refuses to implement an explicitly requested in-app help page due to bundled frontend instructions

[https://github.com/microsoft/vscode/issues/336560](https://github.com/microsoft/vscode/issues/336560)

## Summary

Traced in source: the agent's built-in `design_instructions` block (used for aesthetically-oriented app generation) contains an absolute rule against in-app explanatory text, with no carve-out for an explicitly requested help/documentation page — a real prompt-design gap, so this should route to the Copilot Chat prompt owners rather than close.

## Change summary

Copilot refuses to build an explicitly requested in-app help page because a bundled system-prompt rule against unsolicited in-app explanatory text is applied absolutely, even overriding clear user intent.

## Best solution

Add an explicit-request exception to the `design_instructions` guidance (e.g. "...unless the user explicitly asks for in-app help/documentation") in extensions/copilot/src/extension/prompts/node/agent/openai/{gpt6Prompt,gpt55Prompt,gpt55BasePrompt,gpt56Prompt}.tsx, so the rule still discourages unsolicited UI clutter without blocking deliberate user requests.
