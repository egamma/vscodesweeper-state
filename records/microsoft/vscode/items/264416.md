# Issue #264416 — Custom instructions sometimes removed during summarization

[https://github.com/microsoft/vscode/issues/264416](https://github.com/microsoft/vscode/issues/264416)

## Summary

The report contains direct prompt logs showing that oversized custom instructions triggered pruning which removed the active user request and system context. Current main has substantially changed compaction, but no commit conclusively fixes this case, and newer reports have been consolidated into this issue.

## Change summary

Oversized custom instructions can cause conversation summarization or prompt pruning to discard essential instructions and the active user request, producing a generic no-task response.

## Best solution

Keep the active user request and required system context through compaction, and handle instructions that cannot fit with deterministic truncation or an explicit prompt-budget error rather than sending a degraded prompt.
