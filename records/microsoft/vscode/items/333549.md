## Summary

Real regression in 1.135.0: run_in_terminal throws an unhandled 'The terminal was closed' error when the terminal is disposed mid-execution, instead of treating that as cancellation. A fix is already proposed in an open PR referencing this issue, so no close is warranted yet.

## Change summary

The run_in_terminal chat tool throws an unhandled 'The terminal was closed' error (instead of cancelling gracefully) when the terminal is disposed during execution.
