# Issue #209417 — Block cursor should not be on inlay hint

[https://github.com/microsoft/vscode/issues/209417](https://github.com/microsoft/vscode/issues/209417)

## Summary

Keep open: block-cursor-aware inlay-hint navigation remains missing, and two open PRs explicitly address this issue. The original fix was insufficient and its cursor-style normalization was subsequently removed; the next step is maintainer review of the existing implementation candidates.

## Change summary

Make block cursors skip uneditable inlay hints and highlight the source character that editing commands will affect.

## Best solution

Review and reconcile https://github.com/microsoft/vscode/pull/297108 and https://github.com/microsoft/vscode/pull/336103 against the maintainer's cursor-stop requirements, then land a solution that skips hints for block cursors without regressing ordinary caret navigation or injected-text handling.
