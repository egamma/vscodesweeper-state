# Issue #309507 — Thai combining characters not rendering while typing in Terminal (WSL)

[https://github.com/microsoft/vscode/issues/309507](https://github.com/microsoft/vscode/issues/309507)

## Summary

Thai combining characters are Unicode non-spacing marks; their disappearance during terminal rendering is the same root cause tracked by the open upstream issue about incorrect advance widths for non-spacing-mark characters in xterm.js.

## Change summary

Thai combining characters (vowels/tone marks) disappear while typing in the integrated terminal but display correctly after pressing Enter.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/251102, which tracks the upstream xterm.js Unicode width issue (xtermjs/xterm.js#2668) covering non-spacing marks — Thai combining characters are exactly this class of character.
