# Issue #296243 — Handle rate limit errors more gracefully

[https://github.com/microsoft/vscode/issues/296243](https://github.com/microsoft/vscode/issues/296243)

## Summary

Valid UX improvement request from a team member to add a "Retry with Auto" inline action button on rate-limit errors. The error messaging infrastructure exists but no actionable button has been implemented yet; the feature remains unaddressed on main.

## Change summary

Add an inline "Retry with Auto" button to rate-limit error messages so users can switch to Auto model with one click instead of manually retrying.

## Best solution

Extend the rate-limit error rendering path (chatErrorMessages.ts → chatListRenderer.ts) to include a confirmationButton or dedicated content part that retries the last request with the Auto model selected. The chatErrorConfirmationPart.ts pattern already supports inline buttons on errors.
