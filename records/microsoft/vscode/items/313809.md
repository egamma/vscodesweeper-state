# Issue #313809 — Support shell-profile config for remote agent hosts (`IRemoteAgentHostService` connections)

[https://github.com/microsoft/vscode/issues/313809](https://github.com/microsoft/vscode/issues/313809)

## Summary

Team-authored debt issue tracking a real gap: remote agent hosts have no user-controllable shell configuration. The local-side work landed in PR #313679, but the remote-side follow-up described here remains unimplemented on main. Keeping open.

## Change summary

Provide a way for users to configure the shell used by remote agent hosts (SSH/tunnel/WebSocket), which currently fall through to getSystemShell() with no override.

## Best solution

Implement approach (a) as the author recommends: document the existing `defaultShell` key in `agent-host-config.json` for remote deployments, and optionally add a `code agent-host --default-shell` CLI flag. The config key already exists in `src/vs/platform/agentHost/common/agentHostCustomizationConfig.ts` — the gap is documentation, discoverability, and possibly the CLI flag.
