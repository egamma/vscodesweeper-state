# Issue #129724 — Prevent menu dismissal due to updates for toolbar dropdowns

[https://github.com/microsoft/vscode/issues/129724](https://github.com/microsoft/vscode/issues/129724)

## Summary

Still valid debt: the core ToolBar class has no built-in mechanism to defer action updates while a dropdown is visible. The notebook workaround (defer-then-apply pattern) is still replicated in at least three places under src/vs/workbench/contrib/notebook/browser/.

## Change summary

Move the 'defer toolbar action updates while dropdown is open' logic from per-consumer workarounds into the core ToolBar widget.

## Best solution

Add dropdown-visibility-aware update deferral directly in src/vs/base/browser/ui/toolbar/toolbar.ts (around `setActions`/`updateActions`), then remove the duplicated workarounds in notebookEditorToolbar.ts, cellToolbars.ts, and notebookOutline.ts.
