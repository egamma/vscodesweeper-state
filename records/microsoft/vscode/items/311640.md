## Summary

Team-authored feature request for an AI-powered review/explanation of tool-call confirmations, showing what a command does and how dangerous it is. Keeping open — needs explicit maintainer judgment.

## Change summary

Add an option for a secondary AI (without prior context) to review and explain pending tool-calls/commands at the confirmation step, including a danger assessment.

Implement a confirmation-review panel or inline explanation in the agent confirmation UI that invokes a separate (selectable) model to summarize what the proposed tool-call does and rate its risk, helping users make informed approve/deny decisions.
