# Issue #83294 — Web: allow to use Fira Code in editor (Safari)

[https://github.com/microsoft/vscode/issues/83294](https://github.com/microsoft/vscode/issues/83294)

## Summary

Keep this as the canonical request for custom editor fonts in Safari. Current font-family handling supplies a fallback but does not deliver Fira Code to the page; maintainers have explicitly consolidated related requests here.

## Change summary

Allow the web editor to use Fira Code in Safari when the browser cannot access the locally installed font.

## Best solution

Decide whether the web workbench should provide a supported way to load editor fonts into the page, rather than relying on Safari's access to installed fonts. Preserve existing fallback behavior and standalone Monaco support for fonts supplied by its embedding page.
