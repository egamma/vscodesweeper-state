# Issue #83294 — Web: allow to use Fira Code in editor (Safari)

[https://github.com/microsoft/vscode/issues/83294](https://github.com/microsoft/vscode/issues/83294)

## Summary

This remains the canonical feature request for Safari web-font support. Current main only applies the configured font-family and does not load an editor font, so the Safari limitation remains.

## Change summary

Allow VS Code for Web in Safari to use Fira Code or another user-selected font unavailable through Safari's local-font access.

## Best solution

Decide on a generic, secure mechanism for deployments or users to provide web fonts without bundling Fira Code in the default client; otherwise document Safari fallback families clearly.
