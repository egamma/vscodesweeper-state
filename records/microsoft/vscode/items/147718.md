# Issue #147718 — Markdown preview resets when switching tabs

[https://github.com/microsoft/vscode/issues/147718](https://github.com/microsoft/vscode/issues/147718)

## Summary

Still reproduces on main: the preview forces a full page reload when not visible, resetting scroll position. An open PR (#307245) already targets this fix — the issue should stay open until that PR is resolved.

## Change summary

Markdown preview resets scroll position when the user switches tabs and returns, because the webview is fully reloaded while hidden.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/307245, which defers the preview refresh until the panel becomes visible again, avoiding the full page reload that destroys scroll state.

## Evidence

- **bug confirmed in source:** In `extensions/markdown-language-features/src/preview/preview.ts` line 322, `shouldReloadPage` includes `!this.#webviewPanel.visible`, so any content update while the preview is hidden triggers a full HTML reload (`webview.html = html`), destroying scroll state.
- **open fix PR:** https://github.com/microsoft/vscode/pull/307245 ('fix: defer markdown preview refresh when panel is hidden') is open since 2026-04-01, explicitly closing #147718. It defers the refresh via a `#needsRefresh` flag and an `onDidChangeViewState` listener.
