# Issue #203531 — Inconsistent behavior of diff line border

[https://github.com/microsoft/vscode/issues/203531](https://github.com/microsoft/vscode/issues/203531)

## Summary

Keep open: current source still gives inline deleted-text tokens separate borders rather than consistently rendering the whole-line treatment used by editor-backed changes. The related issues do not provide a valid canonical for this report.

## Change summary

Make deleted-line borders consistent between inline and side-by-side diffs, without unintended vertical borders at token boundaries.

## Best solution

Give inline deleted lines the same whole-line border semantics as side-by-side deleted lines while preserving character-change highlighting and high-contrast styling. Keep the adjacent-line displacement report separate.
