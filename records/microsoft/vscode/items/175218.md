# Issue #175218 — Profile badge background colour too strong in light theme compared to dark theme

[https://github.com/microsoft/vscode/issues/175218](https://github.com/microsoft/vscode/issues/175218)

## Summary

Keep open: current source retains the light profile badge color that contrasts strongly with the classic light theme's dark activity bar. The related styling PR does not resolve this distinction, and a maintainer has expressed interest in investigating it.

## Change summary

Make the profile initials badge quieter against the classic light theme's activity bar without degrading its readability.

## Best solution

Agree on a subdued profile badge treatment for the classic light themes, preserving readability and the existing modern, dark, and high-contrast theme behavior. This belongs in the profile badge theme defaults or built-in theme overrides, rather than requiring users to customize colors.
