# Issue #166805 — [Bug] Diff Editors are not in the back/forward history

[https://github.com/microsoft/vscode/issues/166805](https://github.com/microsoft/vscode/issues/166805)

## Summary

Returning to a closed SCM or Timeline diff remains unsupported by the navigation-history implementation. Keep this feature request open in its existing areas: the merged open-side command does not deliver the return journey, and no verified older canonical owns the same symptom.

## Change summary

Allow Back and Forward navigation to restore a diff editor after it has been closed or replaced while reviewing a file.

## Best solution

Support reconstructible diff entries in workbench navigation history without retaining disposed editor inputs or disabling editor cleanup. Preserve both compared resources and their revision identity, and keep cursor-position improvements tracked separately.
