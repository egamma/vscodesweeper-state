# Issue #227592 — [json] Intellisense doesn't suggest objects as a possibility when next to string enums

[https://github.com/microsoft/vscode/issues/227592](https://github.com/microsoft/vscode/issues/227592)

## Summary

The completion gap remains in the current JSON language service: enum suggestions prevent the structural object suggestion from being added. This is dependency-owned work and should remain open under the existing JSON area.

## Change summary

Offer an object completion when an array item schema allows both string enum values and an object through `anyOf`.

## Best solution

Update `vscode-json-languageservice` so structural object and array alternatives remain available alongside enum or default-value completions, with a completion test covering this mixed `anyOf` schema; then consume the updated service in VS Code.
