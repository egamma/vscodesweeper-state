# Issue #583 — Support autoClosingPairs for strings like `begin` and `end`

[https://github.com/microsoft/vscode/issues/583](https://github.com/microsoft/vscode/issues/583)

## Summary

Multi-character pairs are partially supported, but the requested word-boundary behavior remains absent: `begin` closes immediately and therefore also triggers inside identifiers. This backlog request exceeded the 20-upvote threshold and should remain open.

## Change summary

Allow word-like auto-closing pairs such as `begin`/`end` to activate only after a word delimiter rather than inside identifiers.

## Best solution

Add opt-in word-boundary or deferred-trigger semantics to language configuration auto-closing pairs, while preserving immediate matching for punctuation-based multi-character pairs. The implementation belongs in the editor auto-closing matcher and its cursor tests.
