Keep open: independent commenters confirm that MCP management disappears in WSL Agents sessions, with additional server duplication and launch failures. Current source has harness-dependent customization visibility, but no verified fix or canonical issue establishes that this report's full behavior is resolved or already owned elsewhere.

## Change summary

Restore usable MCP management and tool access in Agents windows connected to WSL without mixing or duplicating Windows and WSL servers.
