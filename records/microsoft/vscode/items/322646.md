# Issue #322646 — Could we add collapsable sections to Chat prompts and a search option

[https://github.com/microsoft/vscode/issues/322646](https://github.com/microsoft/vscode/issues/322646)

## Summary

Transcript search has been implemented, but collapsing complete prompt/response turns remains a real gap. Keep this open and route it to the chat area for the remaining UX request.

## Change summary

Allow users to search long chat transcripts and collapse individual prompt/response sections.

## Best solution

Add an accessible, keyboard-operable disclosure for each conversation turn in the chat transcript, keeping the prompt identifiable while collapsing its response. Find navigation should automatically expand a collapsed turn when revealing a match.
