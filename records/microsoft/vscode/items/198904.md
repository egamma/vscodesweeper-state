# Issue #198904 — When actions.find has a "User" source, workbench.action.terminal.focusFind stops working

[https://github.com/microsoft/vscode/issues/198904](https://github.com/microsoft/vscode/issues/198904)

## Summary

Confirmed bug still present on main: editing a default keybinding's 'when' expression and reverting it back leaves a stale negation entry in keybindings.json that shadows other keybindings for the same key combo.

## Change summary

Modifying a default keybinding's 'when' expression in the GUI and reverting it leaves a 'User' source entry with a negation that prevents the terminal find command from matching.

## Best solution

When editing a user keybinding back to match its original default exactly (same key, command, and when), the edit operation should detect equivalence with the default and remove both the user entry and its negation entry — effectively performing a reset. The fix belongs in `doEditKeybinding` in `src/vs/workbench/services/keybinding/common/keybindingEditing.ts`.
