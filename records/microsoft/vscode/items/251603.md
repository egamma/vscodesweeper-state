# Issue #251603 — Issue: GitHub Copilot toolsets.jsonc file not syncing across devices

[https://github.com/microsoft/vscode/issues/251603](https://github.com/microsoft/vscode/issues/251603)

## Summary

A real gap remains on current main: user toolset files live beside prompts but are excluded from the Settings Sync resource that synchronizes prompts and instructions. The request should remain open in the Backlog while maintainers decide how toolset synchronization is exposed.

## Change summary

Synchronize user-profile `.toolsets.jsonc` files across devices alongside Copilot prompt and instruction files.

## Best solution

Include user-profile toolset definitions in Settings Sync while preserving their filenames and contents, with an explicit product decision on whether they belong under the existing “Prompts and Instructions” resource or a separately controllable toolsets resource.

- **Likely files:** `src/vs/platform/userDataSync/common/promptsSync/promptsSync.ts`, `src/vs/platform/userDataSync/test/common/promptsSync.test.ts`, `src/vs/workbench/services/userDataSync/common/userDataSync.ts`

- **Behavior:**

  > A valid user-profile `.toolsets.jsonc` file synchronizes between devices with its filename and JSONC content preserved. Creating, updating, or deleting the file propagates through Settings Sync consistently with prompt and instruction files. Workspace-scoped toolsets and unrelated files in the profile prompts directory remain outside this issue. Users can understand and control which Settings Sync category owns toolsets.
- **Trace:**

  > UserToolSetsContributions in src/vs/workbench/contrib/chat/browser/tools/toolSetsContribution.ts discovers `.toolsets.jsonc` files under the current profile's `promptsHome`. PromptsSynchronizer in src/vs/platform/userDataSync/common/promptsSync/promptsSync.ts watches that same directory, but getPromptsFileContents filters for four Markdown suffixes and therefore never uploads toolset files. The existing merge and apply pipeline is filename/content based, with coverage in src/vs/platform/userDataSync/test/common/promptsSync.test.ts. Keep workspace toolset discovery from https://github.com/microsoft/vscode/issues/251515 out of scope; this issue concerns user-profile synchronization only. The uncertainty starts at the public Settings Sync grouping: toolsets could inherit the existing “Prompts and Instructions” toggle or receive distinct resource semantics.
- **Open decisions:**
  - Should user toolsets synchronize under the existing “Prompts and Instructions” Settings Sync resource and toggle, or be exposed as a separately controllable toolsets resource?
