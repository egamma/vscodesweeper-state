# Issue #332715 — TernarySearchTree.deleteSuperstr deletes unrelated sibling keys

[https://github.com/microsoft/vscode/issues/332715](https://github.com/microsoft/vscode/issues/332715)

## Summary

Confirmed real bug in `TernarySearchTree.deleteSuperstr`: it wipes `node.left`/`node.right` in addition to `node.mid`, deleting unrelated sibling keys that merely sort near the same position rather than true superstrings. An open PR already fixes this, so the issue stays open pending that PR's review/merge.

## Change summary

`deleteSuperstr` incorrectly clears `left`/`right` sibling subtrees, deleting unrelated keys instead of only true superstrings under `mid`.

## Best solution

Land the fix in the already-open PR https://github.com/microsoft/vscode/pull/332716, which limits the removal to `node.mid` and preserves `node.left`/`node.right`; add a regression test covering a sibling at the terminal node (e.g. `set('d'); set('e'); deleteSuperstr('d')` should keep `e`).
