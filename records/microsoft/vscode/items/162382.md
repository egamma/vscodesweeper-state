# Issue #162382 — Spinning icons are blurry on standard DPI screens

[https://github.com/microsoft/vscode/issues/162382](https://github.com/microsoft/vscode/issues/162382)

## Summary

Keep open for the low-DPI rendering investigation maintainers accepted. The status-bar icon-size change improved the appearance, but neither that change nor the discussion establishes that animation-related blurring is resolved across the workbench.

## Change summary

Improve the sharpness and visual consistency of spinning icons on standard-DPI displays without increasing animation resource costs.

## Best solution

Assess stationary versus animated codicons at standard DPI using the current base icon size, then establish a shared rendering approach that improves sharpness without sacrificing CPU efficiency, vector scaling, theming, or reduced-motion behavior.
