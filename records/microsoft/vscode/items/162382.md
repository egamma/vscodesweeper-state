# Issue #162382 — Spinning icons are blurry on standard DPI screens

[https://github.com/microsoft/vscode/issues/162382](https://github.com/microsoft/vscode/issues/162382)

## Summary

The core blurriness issue (CSS animation compositing degrades icon rendering on standard DPI screens) remains unresolved on main. Recent commits addressed wobble and performance but not the rasterization quality. Team members confirmed it's still an issue on lower-res screens (Oct 2025) and noted improvement from the 16px status bar icon size change, but no fundamental fix has landed.

## Change summary

Spinning codicon icons appear blurry on standard DPI screens because CSS animation compositing degrades rasterization quality compared to static icons.

## Best solution

Investigate alternative rendering approaches (stepped discrete transforms, pre-rasterized frames, or SVG-based animation) for the codicon spin animation that avoid the compositing-layer blur on 1x displays. The relevant CSS is in `src/vs/base/browser/ui/codicons/codicon/codicon-modifiers.css`. The 16px size increase partially mitigated it but didn't eliminate the root cause.
