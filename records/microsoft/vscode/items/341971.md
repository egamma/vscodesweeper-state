# Issue #341971 — Agent Customizations: separate local and remote User MCP server configurations

[https://github.com/microsoft/vscode/issues/341971](https://github.com/microsoft/vscode/issues/341971)

## Summary

The requested local/remote distinction remains missing from MCP group headers on current main. Keep this open for a presentation decision coordinated with the storage/provenance grouping proposal; existing configuration commands and destination pickers only partially address the request.

## Change summary

Distinguish local and remote user MCP configurations in Customizations and clearly identify the destination of group-level creation actions.

## Best solution

Make configuration origin and creation destination understandable without inspecting file paths, while preserving distinct same-name servers and existing execution semantics. Decide whether local/remote user subgroups or explicit provenance within User best fits the shared Customizations hierarchy.
