# Issue #341971 — Agent Customizations: separate local and remote User MCP server configurations

[https://github.com/microsoft/vscode/issues/341971](https://github.com/microsoft/vscode/issues/341971)

## Summary

Keep open: current source explicitly combines local and remote user MCP servers under one User group. The configuration-opening commands distinguish those sources, but do not satisfy the requested grouping and destination clarity in Agent Customizations.

## Change summary

Distinguish local and remote user MCP configurations in Agent Customizations, including the destination of each group's add action.
