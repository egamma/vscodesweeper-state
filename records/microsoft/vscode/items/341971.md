# Issue #341971 — Agent Customizations: separate local and remote User MCP server configurations

[https://github.com/microsoft/vscode/issues/341971](https://github.com/microsoft/vscode/issues/341971)

## Summary

Thanks for the clear report. The MCP list widget groups RemoteUser entries under the single 'User' group, so local and remote user configs are indistinguishable by heading. This is a reasonable UX improvement and stays open.

## Change summary

Show separate groups for local and remote User MCP configurations in Agent Customizations, and make the + action indicate its target.

## Best solution

Add a distinct 'User (Remote: <name>)' group in mcpListWidget.ts for RemoteUser-scoped entries, and label the add action with its target config.
