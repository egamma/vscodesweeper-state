# Issue #331572 — chat sessions are gone

[https://github.com/microsoft/vscode/issues/331572](https://github.com/microsoft/vscode/issues/331572)

## Summary

Keep open: current source can copy chat transcripts during a workspace transition while losing the index that makes them discoverable. The report also includes returning to the original folder, which is not fully covered by the older migration reports.

## Change summary

Chat history becomes inaccessible after switching between single-folder and multi-root workspace identities, despite transcript files remaining on disk.

## Best solution

Preserve discoverability of existing sessions through workspace transitions, and provide a supported recovery path for already-orphaned transcripts. Review https://github.com/microsoft/vscode/pull/305109 for index preservation, while explicitly checking whether it covers the reported return-to-folder scenario without changing workspace isolation unintentionally.

- **Source-confirmed index loss:** src/vs/workbench/services/workspaces/electron-browser/workspaceEditingService.ts:184-198 switches storage before firing the workspace-transition event. src/vs/platform/storage/common/storageService.ts:194-207 closes the old workspace database and initializes the new one; switchData in src/vs/platform/storage/common/storage.ts only emits change notifications, rather than copying old entries.

This establishes an index-loss path without executing the application.
