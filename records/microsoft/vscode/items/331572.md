# Issue #331572 — chat sessions are gone

[https://github.com/microsoft/vscode/issues/331572](https://github.com/microsoft/vscode/issues/331572)

## Summary

Verified duplicate: the older open canonical issue covers chat sessions disappearing from the Sessions UI when a workspace identity changes, including migration and recovery of the resulting orphaned sessions.

## Change summary

Preserve indexed chat-session history when switching between a folder and a workspace so sessions do not disappear after restart.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/305818 and preserve or reconstruct the session index when workspace storage changes; that canonical also owns recovery of sessions already orphaned by workspace-identity changes.
