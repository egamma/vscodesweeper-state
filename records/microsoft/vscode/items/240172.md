# Issue #240172 — Allow to disable `ino` detection for workspace identity

[https://github.com/microsoft/vscode/issues/240172](https://github.com/microsoft/vscode/issues/240172)

## Summary

The requested opt-out remains absent on current main, and the maintainer agreed that a setting preserving the default behavior would be reasonable. The issue is already correctly routed and should remain open in the Backlog.

## Change summary

Allow Linux users to exclude a folder's inode from workspace identity so editor state survives filesystems that assign unstable inode values.

## Best solution

Add an opt-in setting that derives single-folder workspace identity from its path without inode salt, while retaining inode-based identity by default and documenting the state-isolation tradeoff.
