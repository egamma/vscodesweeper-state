# Issue #344478 — Windows: GUI executable launched as process task exits but task remains active (missing terminal exit notification)

[https://github.com/microsoft/vscode/issues/344478](https://github.com/microsoft/vscode/issues/344478)

## Summary

The current source confirms a stalled exit path when a Windows process starts with PID 0 and exits without producing terminal output. Keep this open: the supplied Notepad task provides concrete steps, and no fixing commit or matching open canonical was found.

## Change summary

A Windows GUI process task remains active after its executable exits, preventing a normal subsequent launch.

## Best solution

Make the terminal lifecycle complete for silent Windows processes, delivering the exit notification that allows the task system to retire the finished instance. Preserve startup ordering and trailing-output delivery for ordinary terminals.
