# Issue #341831 — Allow hideUnchangedRegions to hide ALL unchanged regions

[https://github.com/microsoft/vscode/issues/341831](https://github.com/microsoft/vscode/issues/341831)

## Summary

Thanks for the request. The settings schema restricts both settings to a minimum of 1, but the runtime option validation already clamps from 0, so lifting the schema minimum looks like a small change. Whether 0 behaves sensibly in the collapsed-region logic and UI is unverified, so this stays open.

## Change summary

Allow 0 as a value for diffEditor.hideUnchangedRegions.contextLineCount and minimumLineCount so all unchanged lines can be hidden.

## Best solution

Lower the `minimum` to 0 for both settings in editorConfigurationSchema.ts after confirming that the unchanged-region logic and widget behave correctly at 0, especially for minimumLineCount.
