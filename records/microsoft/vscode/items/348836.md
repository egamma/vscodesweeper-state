## Evidence

- **Selection copy gap:** src/vs/workbench/contrib/chat/browser/widget/chatListWidget.ts, handleCopy(), only considers selections touching anchors or images; its intercepted plain-text output is still selection.toString(). It does not substitute LaTeX for rendered equations.
- **Existing capability is partial:** src/vs/workbench/contrib/chat/browser/actions/chatCopyActions.ts registers workbench.action.chat.copyKatexMathSource (Copy Math Source), which copies data-latex for an equation. This separate context-menu command neither changes ordinary selection copying nor restores delimiters. workbench.action.chat.copyItem copies selected DOM text when a selection exists, or the whole message's Markdown otherwise.
- **Source representation:** src/vs/workbench/contrib/markdown/common/markedKatexExtension.ts stores token.text in the rendered container's data-latex attribute. Tokenizers trim that text and exclude the original delimiters, so the existing attribute alone does not preserve the exact requested source.
