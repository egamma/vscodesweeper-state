# Issue #337964 — [Feature Request] Display token and cost consumption of external Gateways (e.g., Vercel AI Gateway)

[https://github.com/microsoft/vscode/issues/337964](https://github.com/microsoft/vscode/issues/337964)

## Summary

Keep open for the existing Backlog Candidates community review: token reporting already has an extension-facing hook, but the inspected contracts do not provide gateway-denominated spending in the native usage display. No verified canonical issue covers this request, and its 60-day review window is still underway.

## Change summary

Expose provider-reported token consumption and external gateway spending in native chat and agent usage displays, correlated with the active session.

## Best solution

Evaluate a provider-neutral usage and monetary-cost contract that gateway integrations can populate and the native UI can display without treating external charges as Copilot credits. Gateway-specific metadata parsing should remain with the provider integration rather than requiring core to understand arbitrary billing headers.
