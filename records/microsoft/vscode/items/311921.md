# Issue #311921 — Agents App: Huge text

[https://github.com/microsoft/vscode/issues/311921](https://github.com/microsoft/vscode/issues/311921)

## Summary

Current main still renders Markdown headings substantially larger than surrounding Agents chat text, matching the supplied skill-output example. This is an unresolved chat typography polish issue that should be routed to the chat area.

## Change summary

Markdown headings in Agents chat responses can appear disproportionately large relative to normal response text.

## Best solution

Choose a calmer heading hierarchy for Markdown rendered in Agents chat, likely by adjusting the shared chat heading type roles or defining an appropriate Sessions-specific scope. Preserve ordinary response text, code blocks, accessibility scaling, and the user's overall `chat.fontSize` preference.
