# Issue #289224 — vscode corrupts source code when toggling comments on folded regions

[https://github.com/microsoft/vscode/issues/289224](https://github.com/microsoft/vscode/issues/289224)

## Summary

The editor is behaving as designed: folding changes visibility, not the underlying selection range, so selecting only the visible fold header comments only that line. A maintainer confirmed that extending the line selection to the beginning of the next visible line includes the folded block.

## Change summary

Make Toggle Line Comment treat selection of a folded region's visible header as selection of all hidden lines in that region.

## Best solution

Keep comment commands operating on the actual model selection. To comment the folded block, select from its first line through the beginning of the next unfolded line, as demonstrated by the maintainer.
