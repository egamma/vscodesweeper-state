# Issue #170639 — "Customize layout" UI is very confusing

[https://github.com/microsoft/vscode/issues/170639](https://github.com/microsoft/vscode/issues/170639)

## Summary

The Customize Layout quickpick still exists on current main with the same UX patterns the issue describes — Modes section uses checkmark-style option items (CreateOptionLayoutItem) for independently toggleable states (Full Screen, Zen Mode, Centered Layout), and Visibility toggles use button icons whose active/inactive state is not immediately visible without hovering. The feedback remains valid.

## Change summary

The Customize Layout quickpick uses the same UI element style for mutually-exclusive radio choices and independent toggles, making it confusing to determine what's active and whether selections are exclusive.

## Best solution

Redesign the Customize Layout quickpick in src/vs/workbench/browser/actions/layoutActions.ts to visually distinguish radio-button groups (Panel Alignment, Sidebar Position) from independent toggles (Visibility, Modes), and make active/inactive state visible without hover — potentially using different icons, separators with clearer semantics, or a richer quick-pick item style.
