# Issue #328937 — Markdown editor: Plain-clicking rendered links in Editing mode prevents caret placement

[https://github.com/microsoft/vscode/issues/328937](https://github.com/microsoft/vscode/issues/328937)

## Summary

Team-authored bug report (protected from judgment closes regardless) describing a concrete, well-diagnosed interaction bug in the experimental hybrid Markdown editor; the actual `LinkViewNode` code lives in the external `@vscode/markdown-editor` package, not this checkout, so I can't independently trace or confirm a fix boundary here — this stays open pending a fix in that package.

## Change summary

In the experimental Markdown editor's Editing mode, an ordinary click on a rendered link opens the link instead of placing the caret, because `LinkViewNode`'s open-on-primary-click logic is keyed off block-active state rather than the editor's Editing/Locked mode.

## Best solution

Fix belongs in the `@vscode/markdown-editor` package's `LinkViewNode` component: gate ordinary-click-to-open behavior on the editor-wide Locked mode (via `model.readonlyMode`/lock state) rather than per-block `blockActive`, so Editing mode always allows caret placement and Locked mode preserves click-to-open.
