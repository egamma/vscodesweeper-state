# Issue #328937 — Markdown editor: Plain-clicking rendered links in Editing mode prevents caret placement

[https://github.com/microsoft/vscode/issues/328937](https://github.com/microsoft/vscode/issues/328937)

## Summary

Keep this team-authored interaction-polish request open: the discussion offers an alternative interaction, but does not establish that ordinary clicks prioritize editing as requested. No verified canonical duplicate or issue-referencing fix was found.

## Change summary

Make ordinary clicks on rendered Markdown links prioritize editing in Editing mode, reserving navigation for Cmd/Ctrl-click or an explicit action.

## Best solution

Establish a consistent mode-sensitive link interaction contract for the hybrid Markdown editor: ordinary clicks edit in Editing mode, modified clicks open links, and Locked mode retains ordinary-click navigation. Confirm the current component behavior before changing the integration or its underlying editor package.
