# Issue #332025 — Allow copilot to refresh the tests in the test pane

[https://github.com/microsoft/vscode/issues/332025](https://github.com/microsoft/vscode/issues/332025)

## Summary

Real, traceable gap in the built-in `runTests` chat tool: it discovers tests via `testsInFile`/`collection.expand`, which triggers a test item's `resolveHandler` only for items already known in the tree, but never calls `ITestService.refreshTests()`, which is what drives a controller's `refreshHandler` to discover brand-new tests. So Copilot can miss tests that only appear after a full refresh.

## Change summary

Let Copilot's test-running tool trigger a full test discovery refresh (not just resolve/expand of already-known items) so it can find and run tests that are only registered via a controller's refresh/resolve handler.

## Best solution

In `RunTestTool` (src/vs/workbench/contrib/testing/common/testingChatAgentTool.ts), have `_getFileTestsToRun`/`invoke` call `ITestService.refreshTests()` (at least as a fallback when no tests are found for the given files) before falling back to reporting 'No tests found', so lazily-discovered tests are picked up the same way a manual Explorer refresh would surface them.
