# Issue #340062 — Advanced Autopilot falsely rejects completed requests and enters a retry loop

[https://github.com/microsoft/vscode/issues/340062](https://github.com/microsoft/vscode/issues/340062)

## Summary

Reasonable report about Advanced Autopilot's LLM-based goal classifier (chat.autopilot.advanced.enabled) being over-conservative and triggering retry loops; the behavior traces to an intentionally strict, 'when in doubt reply NO' system prompt rather than a deterministic code defect, and a related calibration issue (https://github.com/microsoft/vscode/issues/321314) is already open and assigned, so this stays open for the feature owner to weigh.

## Change summary

Advanced Autopilot's goal-completion evaluator falsely judges finished work or informational replies as incomplete, forcing unnecessary continuation turns.

## Best solution

Tune the goal classifier's system prompt in extensions/copilot/src/extension/intents/node/toolCallingLoop.ts (_runAutopilotGoalClassifier) to better recognize implicit mode confirmations and recommendations-in-answers as non-blocking, without regressing its intentional 'reply NO when in doubt' safety bias; the owner tracking https://github.com/microsoft/vscode/issues/321314 is a natural place to coordinate this tuning.
