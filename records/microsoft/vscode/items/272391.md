# Issue #272391 — Language status bar blinky thing every time I open a chat diff

[https://github.com/microsoft/vscode/issues/272391](https://github.com/microsoft/vscode/issues/272391)

## Summary

The noisy animation path still exists on current main, and maintainers agreed that the Completions language-status item is undesirable. Keep this team-authored papercut open while deciding whether to remove that item after extension unification or retain it with less frequent updates.

## Change summary

Stop the Editor Language Status indicator from repeatedly flashing and wiggling when Copilot completion status changes during diff opening, file switching, or offline operation.

## Best solution

Remove the redundant Completions language-status item once the unified Copilot menu fully owns its status and controls, while preserving the separately useful NES progress indication. If the item must remain, its updates should not repeatedly retrigger the language-status attention animation.
