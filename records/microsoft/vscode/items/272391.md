# Issue #272391 — Language status bar blinky thing every time I open a chat diff

[https://github.com/microsoft/vscode/issues/272391](https://github.com/microsoft/vscode/issues/272391)

## Summary

Keep open: the source still contains both the repeated language-status animation and the Completions status item identified in the discussion. Maintainers supported removing that item while retaining useful completion progress, but the broader animation policy remains unsettled.

## Change summary

Reduce distracting language-status flashing and wiggling when opening diffs or switching editors while completion availability remains unchanged.

## Best solution

Make routine editor navigation quiet while preserving discoverable language/completion diagnostics and useful NES progress. Follow the maintainers' direction on retiring the redundant Completions language-status item, and settle whether repeated alerts from other language statuses also need different behavior.
