# Issue #333309 — [Feature] Improved Recent Files menu list

[https://github.com/microsoft/vscode/issues/333309](https://github.com/microsoft/vscode/issues/333309)

## Summary

The current menu already separates files from the combined folders/workspaces block, while preserving recency within that block is intentional. A maintainer previously declined the same workspace-versus-folder split because it would disrupt switching to the previously opened workspace or folder.

## Change summary

Group entries in the File > Open Recent menu more explicitly by item type, including separate workspace, file, and profile sections.

## Best solution

Keep the existing two-block presentation: recently opened folders and workspaces remain together in recency order, with files in a separate block. Profiles are not a persisted recent-entry type in the current workspace-history model.

## Vision fit

- **Fit:** unclear
- **Reason:** Grouping could improve visual hierarchy, but further splitting the recency list conflicts with the established workflow of quickly returning to the previously opened folder or workspace.
- **Evidence:** The vision favors simple, uniform UI interactions, but does not prescribe how recent-item categories should be grouped.
