# Issue #205930 — API: allow to pass in a suggested file name to `saveAs` method

[https://github.com/microsoft/vscode/issues/205930](https://github.com/microsoft/vscode/issues/205930)

## Summary

The accepted API request remains unimplemented on current main, and no open canonical issue absorbs it. The existing `api` and `file-io` routing is appropriate.

## Change summary

Allow `workspace.saveAs` to accept a suggested filename or path for the save dialog.

## Best solution

Add an optional save-as options object containing a suggested target URI, then propagate it through the extension-host protocol to the existing internal `suggestedTarget` save path.
