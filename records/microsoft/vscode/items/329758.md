## Summary

Verified duplicate of the open canonical issue https://github.com/microsoft/vscode/issues/307385, which tracks Autopilot automatically sending the Plan-to-Agent implementation handoff. Maintainer triage has already consolidated reports of this exact mode-switch trigger there.

## Change summary

Switching from Agent to Plan mode with Autopilot enabled sends “Start implementation” and returns the session to Agent mode without user input.

## Best solution
