# Issue #329758 — Switching to Plan mode while Autopilot is enabled immediately starts trying to implement something

[https://github.com/microsoft/vscode/issues/329758](https://github.com/microsoft/vscode/issues/329758)

## Summary

Same root cause as the open, actively-discussed canonical issue: with Autopilot enabled, switching to/staying in Plan mode gets automatically overridden back to Agent-mode implementation. This report shows the same behavior triggers even with no prompt entered yet, but the underlying mechanism and fix are the same as the canonical.

## Change summary

With Autopilot enabled, switching the chat to Plan mode immediately gets reverted and Copilot sends itself a 'Start implementation' instruction instead of waiting in Plan mode.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/307385, where a Copilot Chat collaborator (justschen) already acknowledged this is a deliberate-but-debatable Autopilot behavior and left the door open to changing it (e.g. disabling Autopilot when Plan mode is selected, or not auto-answering/auto-progressing plan-mode sessions).
