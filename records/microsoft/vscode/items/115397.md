# Issue #115397 — Git - clicking on a path segment for a file on git index opens empty picker

[https://github.com/microsoft/vscode/issues/115397](https://github.com/microsoft/vscode/issues/115397)

## Summary

Still reproduces on main: the git filesystem provider's `stat()` always returns `FileType.File` and `readDirectory()` throws 'Method not implemented', so breadcrumb navigation for git-scheme URIs shows an empty picker. The related PR #115464 was closed without merging.

## Change summary

Clicking a breadcrumb path segment for a file in the git index opens an empty picker because the git filesystem provider doesn't support directory listing.

## Best solution

Implement `readDirectory()` in `extensions/git/src/fileSystemProvider.ts` using git tree-listing (e.g. `git ls-tree`), and make `stat()` return `FileType.Directory` for paths that are tree objects rather than blobs. Alternatively, surface a placeholder message or disable clickability when the filesystem cannot enumerate siblings.
