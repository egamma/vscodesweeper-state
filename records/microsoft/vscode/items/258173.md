# Issue #258173 — Split terminal with inherited paths does not work when starting from a WSL terminal

[https://github.com/microsoft/vscode/issues/258173](https://github.com/microsoft/vscode/issues/258173)

## Summary

Keep open: current source can pass a WSL-reported Linux working directory directly to the Windows terminal launcher when splitting with inherited cwd. The issue already has appropriate area labels, and no verified canonical or fixing commit was found.

## Change summary

Splitting a WSL terminal with terminal.integrated.splitCwd set to inherited fails with a starting-directory error, while initial and workspaceRoot work.

## Best solution

Ensure inherited splitting from a local Windows-hosted WSL terminal supplies a working directory valid for the destination backend, consistent with the setting's documented Windows behavior. Preserve remote Linux cwd inheritance and existing non-WSL splitting.
