# Issue #341511 — Cannot edit terminal commands before approval anymore

[https://github.com/microsoft/vscode/issues/341511](https://github.com/microsoft/vscode/issues/341511)

## Summary

Thanks for the report. Current main deliberately makes the terminal command read-only in agent-host-backed chat sessions, which matches the reported symptom (cursor works, typing does nothing, the unmodified command runs). Whether the read-only state is the intended end state or a regression from earlier editable behavior needs a maintainer decision.

## Change summary

The terminal command in a tool-approval prompt can no longer be edited before approval in Copilot agent chat.

## Best solution

Either let the agent-host adapter return a user-edited command to the host so the approval prompt is editable again, or keep it read-only and make that visible (for example, signal read-only state in the UI).
