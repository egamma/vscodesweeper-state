# Issue #267476 — Source Control: Cannot commit no-diff merge resolution when other modified tracked files are unstaged

[https://github.com/microsoft/vscode/issues/267476](https://github.com/microsoft/vscode/issues/267476)

## Summary

The reported merge-completion blocker remains in current source: Continue enters ordinary smart-commit prompting before checking whether a merge is in progress. Keep this correctly routed Git bug open.

## Change summary

Allow a resolved merge with no staged diff to be committed while unrelated tracked modifications remain unstaged.

## Best solution

The built-in Git extension should finalize the resolved merge using the existing index without requiring or automatically staging unrelated working-tree changes. Preserve ordinary smart-commit behavior outside this merge-completion case.
