# Issue #340603 — Copilot often unresponsive when working with non-git projects

[https://github.com/microsoft/vscode/issues/340603](https://github.com/microsoft/vscode/issues/340603)

## Summary

Keep open: the attached profile substantiates an extension-host stall during Copilot-triggered Git process creation, and current main retains that fallback path. The supplied scenario and Git-disable comparison suffice to retest; the Windows-specific process-launch cause remains unconfirmed.

## Change summary

Copilot chat stops responding in non-Git Salesforce workspaces, with responsiveness restored by disabling workspace Git integration.

## Best solution

Investigate the native process-launch stall reached through Copilot's Git remote lookup and ensure non-Git workspaces remain responsive with Git integration enabled. Preserve legitimate parent-repository discovery and content-exclusion behavior rather than treating every folder without a local .git directory as repository-free.
