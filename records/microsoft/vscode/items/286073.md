# Issue #286073 — `Copy Breadcrumbs Path` should not be in editor title context menu

[https://github.com/microsoft/vscode/issues/286073](https://github.com/microsoft/vscode/issues/286073)

## Summary

Keep open under discussion: current main still places the command in the editor-title context menu, while the closed prototype did not resolve consistent behavior across tab modes. This is also a team-authored product-design request, so no judgment-based close is appropriate.

## Change summary

Move Copy Breadcrumbs Path from the editor-title context menu to a context menu on individual breadcrumb items.

## Best solution

Settle on one coherent breadcrumb context-menu model for single-tab, multi-tab, and no-tab configurations, then implement item-aware copy actions in the breadcrumbs widget and control without transient global context-key state.
