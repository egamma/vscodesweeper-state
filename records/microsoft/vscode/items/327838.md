# Issue #327838 — Subagent tool call hint can have an extra line break

[https://github.com/microsoft/vscode/issues/327838](https://github.com/microsoft/vscode/issues/327838)

## Summary

The visual defect remains source-reproducible on current main: subagent prompt titles are shortened by character count but are not constrained to one responsive line. This team-authored, accepted bug should remain open.

## Change summary

Long subagent tool-call hints can wrap onto a short second line instead of truncating responsively within the available chat width.

## Best solution

Make subagent prompt and result titles remain on one responsive line with width-based truncation, while preserving the complete content when expanded and for accessibility.
