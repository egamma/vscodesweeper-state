# Issue #330206 — Outgoing Changes UI Bug

[https://github.com/microsoft/vscode/issues/330206](https://github.com/microsoft/vscode/issues/330206)

## Summary

Plausible, traceable visual glitch in the SCM Graph's incoming/outgoing-changes marker on hover — the CSS hover rules only restyle the first two circles, leaving the dashed ring's gaps exposed against the newly recolored inner circle, which matches the reported pentagon-hole look.

## Change summary

Hovering an Outgoing/Incoming Changes marker in the SCM Graph shows a distracting pentagon-shaped hole where the dashed ring meets the highlighted inner circle.

## Best solution

In src/vs/workbench/contrib/scm/browser/media/scm.css, extend the `:hover ... circle:nth-of-type(2)` (and related) rules to also account for the third (dashed) circle drawn for incoming/outgoing markers in scmHistory.ts, so the dash gaps don't show the background through the hover-highlighted ring; this needs a maintainer/designer call on solid-vs-dashed-vs-hidden per the reporter's suggestions.
