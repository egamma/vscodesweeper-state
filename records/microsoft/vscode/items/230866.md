# Issue #230866 — problems with Undo/Redo in jsx/tsx file after pasting tag name

[https://github.com/microsoft/vscode/issues/230866](https://github.com/microsoft/vscode/issues/230866)

## Summary

The undo/redo corruption is attributed to the third-party Auto Rename Tag extension rather than VS Code core, so this should close as caused by an extension.

## Change summary

Pasting a JSX/HTML tag name while Auto Rename Tag is enabled creates repeated linked renames that corrupt the undo/redo history.

## Best solution

Address the undo-history behavior in the Auto Rename Tag extension; in VS Code, disable that extension and use the built-in `editor.linkedEditing` setting for linked tag editing.
