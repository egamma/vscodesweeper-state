# Issue #230866 — problems with Undo/Redo in jsx/tsx file after pasting tag name

[https://github.com/microsoft/vscode/issues/230866](https://github.com/microsoft/vscode/issues/230866)

## Summary

Decline close (out-of-scope) gated off: the issue carries the `bug` label — the owner already triaged it as accepted work. Original assessment: The reported undo/redo corruption is caused by the third-party Auto Rename Tag extension, not VS Code's JSX/TSX editing path. The built-in linked-editing feature provides the intended paired-tag behavior without the extension-generated undo entries.

## Change summary

Pasting a JSX tag name while Auto Rename Tag is enabled creates repeated tag-renaming undo entries and prevents redoing later edits.

## Best solution

Track and correct the undo-stack behavior in the Auto Rename Tag extension; VS Code users can disable that extension and enable `editor.linkedEditing` for built-in paired-tag editing.
