# Issue #230866 — problems with Undo/Redo in jsx/tsx file after pasting tag name

[https://github.com/microsoft/vscode/issues/230866](https://github.com/microsoft/vscode/issues/230866)

## Summary

The undo/redo corruption is caused by the third-party `auto-rename-tag` extension (by formulahendry), not VS Code core. A contributor confirmed this, and the reporter's extension list shows the extension installed. VS Code's built-in `editor.linkedEditing` setting provides the same tag-renaming functionality without the undo stack issue.

## Change summary

Undo/redo breaks in JSX/TSX files after pasting a tag name, producing repeated rename oscillations and losing redo history.

## Best solution

Close as caused by the third-party `auto-rename-tag` extension. The reporter should disable that extension and enable VS Code's built-in `editor.linkedEditing` setting, which provides equivalent paired-tag renaming without corrupting the undo stack.
