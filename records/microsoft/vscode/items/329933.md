# Issue #329933 — Tasks with quoting escape does not escape “ and ” character when run under PS

[https://github.com/microsoft/vscode/issues/329933](https://github.com/microsoft/vscode/issues/329933)

## Summary

The escape-mode defect remains in the checked-out main: PowerShell task arguments leave U+201C and U+201D unescaped even though PowerShell interprets them as quotation marks. The supplied example uses strong quoting instead, so it does not exercise the reported escape path; that distinction should be preserved when validating the fix.

## Change summary

Preserve literal left and right double quotation marks in PowerShell task arguments configured with escape quoting.

## Best solution

Make PowerShell task escape quoting preserve both smart double quotation marks as literal argument content, with focused regression coverage. Keep strong and weak quoting, other shells, and explicitly supplied quoting options unchanged.
