# Issue #336681 — Browser use in the agents window on remote agent hosts not working

[https://github.com/microsoft/vscode/issues/336681](https://github.com/microsoft/vscode/issues/336681)

## Summary

Team-authored bug report, but it demonstrates exactly the gap already tracked by the open canonical feature request #331926 (integrated browser doesn't treat a remote AHP host as a proxy authority in the Agents window) — proposing a duplicate close so the two threads consolidate; the direct-file-open failure noted here should be carried into that thread as extra evidence.

## Change summary

In the Agents window, opening a page in the built-in browser (either directly as a file or via a server the agent starts) fails when the session is connected to a remote AHP host, even though the equivalent flow works from a normal remote-SSH window.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/331926, which already asks for the remote AHP host to be treated as an integrated-browser proxy authority in the Agents window — implementing that closes this report's server-open failure, and the direct-file-open failure should be folded in there as an additional repro detail rather than tracked separately.
