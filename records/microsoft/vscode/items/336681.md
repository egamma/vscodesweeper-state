# Issue #336681 — Browser use in the agents window on remote agent hosts not working

[https://github.com/microsoft/vscode/issues/336681](https://github.com/microsoft/vscode/issues/336681)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/331926 tracks the same Agents window failure to route integrated-browser traffic through a remote AHP host.

## Change summary

Allow an agent running on a remote Agent Host to open files or HTTP services from that host in the integrated browser.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/331926 and implement remote AHP hosts as integrated-browser proxy targets, preserving the selected session's isolation and enabling access to services bound on that host.
