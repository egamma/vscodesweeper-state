# Issue #339191 — MCP servers are missing in remote windows

[https://github.com/microsoft/vscode/issues/339191](https://github.com/microsoft/vscode/issues/339191)

## Summary

Real, already-being-worked bug: MCP collections registered via extension hosts can collide between local and remote authorities, causing remote MCP servers to be dropped. An open PR already targets this exact mechanism, so the issue should stay open pending that fix landing.

## Change summary

MCP servers/tools configured and visible in a local window are missing when the same workspace is opened in a remote window.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/339249, which disambiguates MCP collection IDs by remote authority in mainThreadMcp.ts and extensionMcpDiscovery.ts so local and remote extension-host registrations stop overwriting each other.
