Verified duplicate of #317033, which is the older, more actively discussed canonical issue for the same markdown preview scroll-locking bug. Multiple commenters on both issues confirm the same behavior persists through 1.131.0.

## Change summary

Exiting the markdown preview locks the editor's scroll position to the preview's last scroll offset, causing the editor to jump back to that position on every tab switch.
