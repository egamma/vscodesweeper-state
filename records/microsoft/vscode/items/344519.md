# Issue #344519 — Agent host: Mission Control retries reuse a failed repository lookup forever

[https://github.com/microsoft/vscode/issues/344519](https://github.com/microsoft/vscode/issues/344519)

## Summary

Confirmed in current source: failed registration retains its rejected promise, so the five-second retry cannot perform another Git lookup. Keep open to restore metadata replication recovery without affecting local chat.

## Change summary

Allow Mission Control registration to recover from a transient repository-root or remote lookup failure.

## Best solution

Subsequent registration attempts should resolve repository metadata afresh after failure, while concurrent attempts still share one lookup and successful registrations retain their established project identity.
