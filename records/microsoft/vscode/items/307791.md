# Issue #307791 — The Rulers are nearly invisible in the new default light theme

[https://github.com/microsoft/vscode/issues/307791](https://github.com/microsoft/vscode/issues/307791)

## Summary

The report has a credible reproduction on current/default light theme behavior and an independent confirmation that editor rulers are nearly invisible; it should stay open for the theme/editor owners rather than be closed as stale or unsupported.

## Change summary

The new default light theme makes configured editor rulers much fainter than comparable light themes, reducing their usability.

## Best solution

Adjust the Light 2026 / default light theme ruler token so `editorRuler.foreground` has enough contrast while preserving the intended low-contrast visual style for other decorations.
