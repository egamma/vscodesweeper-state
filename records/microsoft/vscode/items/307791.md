# Issue #307791 — The Rulers are nearly invisible in the new default light theme

[https://github.com/microsoft/vscode/issues/307791](https://github.com/microsoft/vscode/issues/307791)

## Summary

Keep this open and route it to themes: Light 2026 still assigns nearly white rulers against a white editor background. Color overrides provide a workaround, but do not address the requested improvement to the bundled theme.

## Change summary

## Evidence

- **Current theme contrast:** extensions/theme-defaults/themes/2026-light.json explicitly sets editorRuler.foreground to #F7F7F7 and editor.background to #FFFFFF. This retains the low-contrast combination reported in https://github.com/microsoft/vscode/issues/307791.
- **Rendering path:** EditorRulers.validate in src/vs/editor/common/config/editorOptions.ts gives numeric rulers no explicit color. src/vs/editor/browser/viewParts/rulers/rulers.ts then uses the default CSS shadow from rulers.css, which references --vscode-editorRuler-foreground. RulersGpu._updateEntries in src/vs/editor/browser/viewParts/rulersGpu/rulersGpu.ts likewise resolves editorRuler.foreground.

Neither improves Light 2026 out of the box. Light Modern has no ruler override and uses the registered light default, Color.lightgrey (#D3D3D3), against the same white editor background.
