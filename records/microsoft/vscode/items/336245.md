# Issue #336245 — GH copy link button does not provide visual feedback

[https://github.com/microsoft/vscode/issues/336245](https://github.com/microsoft/vscode/issues/336245)

## Summary

Traced on main: the GitHub-issue/PR "Copy Link" (and "Copy Commit Hash") toolbar actions in the session artifacts pill just call the clipboard service with no visual confirmation, unlike the established checkmark-swap pattern VS Code already uses for chat response copy buttons.

## Change summary

The copy-link icon on session artifact entries (PRs/issues) gives no temporary checkmark/confirmation after a successful copy.

## Best solution

Give the artifact pill's copy actions (in src/vs/sessions/contrib/chat/browser/sessionArtifacts.ts) the same copied-state feedback as ChatCopyActionViewItem in src/vs/workbench/contrib/chat/browser/actions/chatCopyActions.ts (icon swaps to Codicon.check briefly after copy) — likely via a small dedicated action view item for these toolbar actions rather than the default one.
