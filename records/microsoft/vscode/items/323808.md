# Issue #323808 — Telemetry: `agentHost.turnCompleted.permissionLevel` is provider-specific and shouldn't live on the generic turn event

[https://github.com/microsoft/vscode/issues/323808](https://github.com/microsoft/vscode/issues/323808)

## Summary

The reported telemetry mismatch remains in current main: shared turn telemetry still reads only autoApprove and emits permissionLevel for every provider. Keep this accepted, team-authored issue open; the replacement telemetry contract needs agreement before removing the existing dimension.

## Change summary

Remove Copilot-specific permissionLevel from generic turn-completed telemetry while preserving accurate permission/config reporting in provider-owned events.

## Best solution

Keep shared turn measurements provider-neutral and retain permission analysis through explicitly provider-owned, classified telemetry. Agree on the replacement event's snapshot and correlation semantics without folding the separate warm-up timing concern into this cleanup.
