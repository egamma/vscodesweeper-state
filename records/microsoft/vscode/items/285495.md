# Issue #285495 — Auto-download restarts on page refresh, causing multiple VS Code installer downloads

[https://github.com/microsoft/vscode/issues/285495](https://github.com/microsoft/vscode/issues/285495)

## Summary

Keep open as a website download-flow improvement: the current page still initiates a download on each load, and no maintainer decision establishes whether refresh should suppress it. The discussion identifies a legitimate retry use case that any change should preserve.

## Change summary

Prevent refreshing the download confirmation page from automatically starting another installer download, while retaining an explicit retry option.

## Best solution

Have the website owner decide whether automatic downloading should occur only on the initial download navigation, with subsequent reloads offering an explicit retry. Preserve recovery from failed downloads rather than assuming the browser can report successful completion.
