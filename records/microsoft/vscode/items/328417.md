# Issue #328417 — Agents Window: New quick chat is not working

[https://github.com/microsoft/vscode/issues/328417](https://github.com/microsoft/vscode/issues/328417)

## Summary

The failure path exists in source: session creation errors are swallowed, leaving the workspace composer unchanged with no user-facing explanation. This should remain open as an Agents Window bug.

## Change summary

Creating either a quick chat or workspace session can leave the Agents Window stuck on the workspace picker after sessions and workspaces are cleared.

## Best solution

Make session creation react to agent-host readiness and surface actionable errors instead of silently retaining the workspace picker. The quick-chat action should not appear operational when no provider session type is available.
