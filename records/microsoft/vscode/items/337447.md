# Issue #337447 — Markdown editor: support GitHub footnotes ([^1])

[https://github.com/microsoft/vscode/issues/337447](https://github.com/microsoft/vscode/issues/337447)

## Summary

Genuine gap: the new WYSIWYG Markdown editor (backed by the external `@vscode/markdown-editor` npm package) has no GitHub-footnote support, and — since that editor uses its own parser/view rather than the extensible `markdown-it` preview pipeline — extensions can't patch it in. No canonical duplicate owns this specific request, so it stays open as a feature request.

## Change summary

Add GitHub-style footnote (`[^1]` / `[^1]: ...`) parsing and rendering to the new custom Markdown editor.

## Best solution

Wire up `micromark-extension-gfm-footnote` (already a transitive dependency via `micromark-extension-gfm`) in the `@vscode/markdown-editor` package's micromark pipeline alongside the existing frontmatter/gfm-table/task-list/strikethrough/math extensions, and render references as superscript links with a definitions list, matching GitHub's rendering.
