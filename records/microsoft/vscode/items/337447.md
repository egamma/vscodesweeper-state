# Issue #337447 — Markdown editor: support GitHub footnotes ([^1])

[https://github.com/microsoft/vscode/issues/337447](https://github.com/microsoft/vscode/issues/337447)

## Summary

Valid, well-documented feature request: the new Markdown editor's bundled parser doesn't wire up GFM footnote support, and there's no maintainer discussion yet — keeping open as a feature-request for the markdown-language-features area.

## Change summary

The new WYSIWYG-style Markdown editor doesn't render GitHub-style footnotes (`[^1]` references and `[^1]: ...` definitions); they show as literal text instead of superscript links + a footnotes section.

## Best solution

Add the footnote micromark extension (`micromark-extension-gfm-footnote`, already a transitive dependency) to the editor's parser configuration in the `@vscode/markdown-editor` package, then bump the pinned version in extensions/markdown-language-features/package.json once available.
