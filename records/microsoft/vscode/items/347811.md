# Issue #347811 — Preserve the collaborative, in-editor experience: feedback on Local vs. Copilot harness

[https://github.com/microsoft/vscode/issues/347811](https://github.com/microsoft/vscode/issues/347811)

## Summary

Keep open as product feedback about preserving collaborative in-editor workflows. Existing Agent Host terminal integration partially addresses the request, but the optional custom terminal tool explicitly excludes Windows and does not settle the broader experience commitment.

## Change summary

Preserve human-agent collaboration through shared, reusable editor terminals and session continuity as the Copilot harness evolves.

## Best solution

Have the chat and terminal owners define supported shared-terminal interaction and continuity in the in-editor Copilot experience, including Windows. Evaluate that outcome separately from whether the legacy Local harness itself must remain available.
