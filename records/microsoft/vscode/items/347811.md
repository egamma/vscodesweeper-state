# Issue #347811 — Preserve the collaborative, in-editor experience: feedback on Local vs. Copilot harness

[https://github.com/microsoft/vscode/issues/347811](https://github.com/microsoft/vscode/issues/347811)

## Summary

Keep open as actionable feedback about preserving collaborative in-editor workflows. Existing Agent Host terminal integration only partially covers the request, with the custom terminal tool explicitly unavailable on Windows.

## Change summary

Preserve an in-editor collaborative agent experience with shared, interactive terminals and configurable execution behavior.

## Best solution

Have the chat and terminal maintainers assess shared terminal interaction and session continuity in the Copilot harness, including Windows support. Preserve the requested collaborative workflow without presupposing that retaining the Local harness is the necessary implementation.
