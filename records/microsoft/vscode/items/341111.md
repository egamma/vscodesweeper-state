## Change summary

Backspace at the start of a list item in the Markdown Editor deletes the hidden space after the marker, leaving a literal '-' instead of removing the bullet.

## Best solution

Decide the intended backspace semantics in the Markdown Editor. The likely end state is that backspace at the start of a list item's text removes or outdents the list marker, as most WYSIWYG Markdown editors do, with the case list kept narrow (list items, possibly blockquotes and headings).
