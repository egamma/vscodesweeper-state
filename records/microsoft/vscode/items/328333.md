# Issue #328333 — Even if there’s no updated version available, VS Code still tries to update.

[https://github.com/microsoft/vscode/issues/328333](https://github.com/microsoft/vscode/issues/328333)

## Summary

Keep open: the reporter describes an installer that fails replacing a DLL and returns on every launch, and a maintainer independently confirms the recurring launch symptom. Current source still supports replaying a pending installer independently of checking for a newer release; neither a fixing commit nor an older canonical covering this exact symptom was established.

## Change summary

Prevent a failed Windows update from repeatedly reopening the installer on startup when no newer release is available.

## Best solution

Diagnose the pending-update recovery and installer failure together, distinguishing a legitimate unfinished update from replaying an already-installed version. Preserve recovery of interrupted updates while eliminating repeated attempts to overwrite the running installation.
