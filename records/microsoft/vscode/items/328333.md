# Issue #328333 — Even if there’s no updated version available, VS Code still tries to update.

[https://github.com/microsoft/vscode/issues/328333](https://github.com/microsoft/vscode/issues/328333)

## Summary

This is the same recurring Windows update failure tracked by the open, actively-discussed canonical issue https://github.com/microsoft/vscode/issues/294546 — the Inno-based updater fails with 'Access denied' trying to overwrite an install-dir DLL because another process (commonly a dllhost.exe COM surrogate, often AV-related) still holds a file handle, and the installer re-prompts on every launch until it's resolved.
