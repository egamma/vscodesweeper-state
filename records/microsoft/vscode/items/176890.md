# Issue #176890 — Make the Command Palette show the keybindings corresponding to the command being displayed

[https://github.com/microsoft/vscode/issues/176890](https://github.com/microsoft/vscode/issues/176890)

## Summary

Still valid on main: the Command Palette uses `lookupKeybinding(commandId)` which doesn't consider args, so it shows the first keybinding for a command regardless of argument differences. No fix or related work found.

## Change summary

Command Palette shows a custom keybinding (with different args) instead of the keybinding that matches the no-args invocation triggered by selecting the palette item.

## Best solution

Enhance the keybinding lookup in `src/vs/platform/quickinput/browser/commandsQuickAccess.ts` (line 280) to filter by args — either show only the keybinding whose args match what the palette would invoke, or prefer the no-args binding when the palette entry has no args. Requires extending `lookupKeybinding` or post-filtering `lookupKeybindings` results.
