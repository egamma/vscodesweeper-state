# Issue #260069 — Illegal value for lineNumber

[https://github.com/microsoft/vscode/issues/260069](https://github.com/microsoft/vscode/issues/260069)

## Summary

Already fixed on main and shipped in 1.104.0. The crash-site fix in commit b47dabb2 added a `lineNumber < 1` guard to `reportIfInvalid` and converted the checks to an `else if` chain, preventing the throw. Current code on main confirms the guard is present.

## Change summary

Semantic token validation threw 'Illegal value for lineNumber' when a token's computed lineNumber was < 1, because `reportIfInvalid` lacked a guard and fell through to `getLineLength`.

## Best solution

Keep the shipped fix — the `lineNumber < 1` guard in `sparseMultilineTokens.ts` prevents the crash. No further change needed.
