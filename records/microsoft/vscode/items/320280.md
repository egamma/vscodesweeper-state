# Issue #320280 — Incorrect autolink in JSON schema description

[https://github.com/microsoft/vscode/issues/320280](https://github.com/microsoft/vscode/issues/320280)

## Summary

Confirmed bug in the bundled marked.js GFM autolink _backpedal regex: when a URL is followed by `)/`, the backpedal fails to trim the unmatched `)` because the trailing `/` prevents the end-of-string lookahead from firing. The bug is still present on current main.

## Change summary

GFM autolink in hover markdown incorrectly includes trailing `)/` as part of the URL when rendering JSON schema descriptions.

## Best solution

Fix the `_backpedal` regex in `src/vs/base/common/marked/marked.js` to correctly strip unmatched trailing `)` even when followed by `/` or other non-punctuation characters. The regex at line ~1218 needs to account for `/` in the trailing-punctuation trimming logic. This could also be addressed by updating the vendored marked.js to a newer version if upstream has fixed this.
