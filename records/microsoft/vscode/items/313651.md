# Issue #313651 — Agents app keeps signing out when launching EDH for my VS Code extension

[https://github.com/microsoft/vscode/issues/313651](https://github.com/microsoft/vscode/issues/313651)

## Summary

Keep open: launching an Extension Development Host reportedly invalidates the Agents sign-in state and prevents recovery until that host closes. The team-authored report has a confirmed workflow blocker, but no verified fix or same-symptom canonical was found.

## Change summary

Launching an Extension Development Host from Agents signs out the parent app and prevents signing back in while the development host remains open.

## Best solution
