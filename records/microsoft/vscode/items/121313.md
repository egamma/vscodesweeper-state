[https://github.com/microsoft/vscode/issues/121313](https://github.com/microsoft/vscode/issues/121313)

Keep open: current notebook execution still excludes markup cells, so the requested SOS workflow remains unsupported. The linked issues do not own the same work, and this team-authored request needs a notebook API decision rather than a judgment close.

## Change summary

Allow an extension to enable execution of rendered Markdown cells through a notebook controller supplied by another extension.

## Best solution

Define an opt-in notebook execution contract that supports executable markup while retaining Markdown rendering and leaving ordinary markup cells non-executable. Notebook API owners should settle how a companion extension and the selected controller negotiate this capability.
