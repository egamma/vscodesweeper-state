# Issue #281223 — Background/Cloud chats are not restored in sidebar after reload/restart

[https://github.com/microsoft/vscode/issues/281223](https://github.com/microsoft/vscode/issues/281223)

## Summary

The restoration bug was independently reproduced and explicitly remains after the related URI fix, so it should stay open for the chat agent session-persistence path.

## Change summary

Background and cloud chats opened in the sidebar disappear after a window reload or restart while local chats are restored.

## Best solution

Make sidebar restoration resolve persisted background and cloud sessions to their post-reload provider session identity, while preserving existing local-chat restoration and intentional clear-on-restart behavior.
