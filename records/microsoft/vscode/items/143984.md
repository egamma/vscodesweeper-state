# Issue #143984 — Markdown Preview pane Scrolling Unhelpfully

[https://github.com/microsoft/vscode/issues/143984](https://github.com/microsoft/vscode/issues/143984)

## Summary

Still reproduces on current main: markdown preview scroll sync breaks when custom CSS extensions change element sizes, and also with sticky scroll. Multiple related fixes have landed (code block scrolling, EOF crawl) but none address this specific issue, and the most recent comment (June 2026) confirms it persists.

## Change summary

Markdown preview scroll sync breaks when preview styling extensions change font sizes or spacing, causing the preview to not scroll to the bottom and to jump unexpectedly when typing.

## Best solution

The scroll-sync logic in `extensions/markdown-language-features/preview-src/scroll-sync.ts` calculates positions using `getBoundingClientRect()` which should handle custom CSS, but the interaction with `scrollBeyondLastLine: false` and modified line heights likely causes the mismatch. The fix should ensure scroll sync accounts for actual rendered heights at the document boundaries, particularly when scrollBeyondLastLine is disabled and custom styles alter spacing. The `help wanted` label is appropriate — a focused community contribution targeting the EOF scroll boundary case with custom CSS would resolve this.
