# Issue #339537 — Disposed task providers retain discovered custom-execution callbacks

[https://github.com/microsoft/vscode/issues/339537](https://github.com/microsoft/vscode/issues/339537)

## Summary

Team-authored, well-diagnosed memory-retention bug with an open fixing PR (#339553) already attached — keep open for that PR to land rather than closing or re-diagnosing.

## Change summary

Disposing a task provider after successful custom-execution discovery leaves the callback/payload entry in ExtHostTask's `_providedCustomExecutions2` cache, leaking the closure and its backing buffer indefinitely.

## Best solution

Land (or iterate on) https://github.com/microsoft/vscode/pull/339553, which removes the corresponding `_providedCustomExecutions2` entries when a task provider is disposed/unregistered.
