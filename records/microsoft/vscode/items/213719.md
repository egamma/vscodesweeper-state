# Issue #213719 — notebook.codeActionsOnSave doesn't respect "never"

[https://github.com/microsoft/vscode/issues/213719](https://github.com/microsoft/vscode/issues/213719)

## Summary

The reported settings interaction remains in current source: "never" suppresses the configured code-action save participant, but format-on-save independently invokes notebook formatting actions. Keep this open for a decision on whether exclusions should also govern that formatting path; the original design explicitly provides separate triggers.

## Change summary

Make a notebook formatting action's "never" setting suppress its execution even when notebook format-on-save is enabled.

## Best solution

Settle and document whether notebook.codeActionsOnSave exclusions override notebook.formatOnSave.enabled. If exclusions should apply across both save participants, enforce that consistently without changing explicit Format Notebook behavior.
