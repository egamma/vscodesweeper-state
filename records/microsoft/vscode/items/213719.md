# Issue #213719 — notebook.codeActionsOnSave doesn't respect "never"

[https://github.com/microsoft/vscode/issues/213719](https://github.com/microsoft/vscode/issues/213719)

## Summary

Still reproduces on main: NotebookFormatOnSaveParticipant calls checkAndRunFormatCodeAction with an empty excludes array, ignoring notebook.codeActionsOnSave "never" entries when notebook.formatOnSave.enabled is true.

## Change summary

Setting notebook.codeActionsOnSave to "never" for a notebook.format code action kind does not prevent it from running when notebook.formatOnSave.enabled is true.

## Best solution

checkAndRunFormatCodeAction (called from NotebookFormatOnSaveParticipant) should read the notebook.codeActionsOnSave setting and pass matching "never" entries as excludes, so that explicitly disabled format actions are not triggered by formatOnSave.
