# Issue #305794 — agentPlugins with devcontainer story

[https://github.com/microsoft/vscode/issues/305794](https://github.com/microsoft/vscode/issues/305794)

## Summary

Legitimate feature request for devcontainer-level agent plugin configuration. The plugin settings (`chat.plugins.enabledPlugins`, `chat.plugins.marketplaces`, `chat.plugins.paths`) are all scoped to APPLICATION or MACHINE, confirming the reporter's observation that they cannot be set at workspace scope. A team member (chrmarti) is actively engaged; the issue is properly labeled and routed.

## Change summary

Allow agent plugin marketplaces and enabled plugins to be configured at workspace scope so devcontainer customizations can automatically install and enable plugins.

## Best solution

Widen the configuration scope of the relevant plugin settings (at minimum `chat.plugins.enabledPlugins` and `chat.plugins.marketplaces`) to allow workspace-level values, then add devcontainer customization support (analogous to extensions and settings) so that `devcontainer.json` can declare agent plugins. The containers team and chat/plugins owners need to coordinate on the design, especially around security implications of workspace-scoped plugin enablement.
