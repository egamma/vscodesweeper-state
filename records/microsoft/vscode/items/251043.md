# Issue #251043 — Accessible diff viewer up/down focuses out of accessible diff view

[https://github.com/microsoft/vscode/issues/251043](https://github.com/microsoft/vscode/issues/251043)

## Summary

Still reproduces on main: the notebook cell navigation keybindings (arrow up/down) lack a guard for the accessible diff viewer being visible, so pressing arrow keys while in the accessible diff view moves focus to a different cell instead of navigating within the diff view. The team has agreed on a fix approach (adding a context key) but it hasn't been implemented yet.

## Change summary

In notebook diff, pressing arrow up/down in the accessible diff viewer moves focus to a different cell instead of navigating within the diff view.

## Best solution

Add `EditorContextKeys.accessibleDiffViewerVisible.negate()` (or a new focused-specific context key as discussed) to the when clauses for the notebook cell navigation keybindings in `src/vs/workbench/contrib/notebook/browser/contrib/navigation/arrow.ts`, so that arrow keys don't trigger cell focus changes while the accessible diff viewer is active. The existing `accessibleDiffViewerVisible` context key from `src/vs/editor/common/editorContextKeys.ts` may suffice, or a new focused variant may be needed per the discussion.
