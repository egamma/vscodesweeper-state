# Issue #251043 — Accessible diff viewer up/down focuses out of accessible diff view

[https://github.com/microsoft/vscode/issues/251043](https://github.com/microsoft/vscode/issues/251043)

## Summary

Keep open: a maintainer confirmed that notebook cell-list navigation intercepts arrows inside the accessible diff viewer, and the proposed focus-context solution received approval. No qualifying fix or older canonical reporting this same symptom was established; this team-authored issue remains necessary.

## Change summary

Up and Down in a notebook's accessible diff viewer move focus to another cell instead of navigating the displayed diff lines.

## Best solution

Ensure accessible diff navigation retains focus within the viewer and takes precedence over notebook cell-list navigation, following the maintainer-approved focus-context direction. Preserve ordinary cell navigation when focus is outside the viewer.
