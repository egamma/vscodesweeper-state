# Issue #339293 — jupyter notebooks loose computation references

[https://github.com/microsoft/vscode/issues/339293](https://github.com/microsoft/vscode/issues/339293)

## Summary

This is about Jupyter kernel/session reconnection against a persistent remote Jupyter server, which is owned by the VS Code-team Jupyter extension (microsoft/vscode-jupyter), not by notebook core — proposing a move of the issue to that tracker rather than a close.

## Change summary

After an SSH drop or browser reload, VS Code does not reattach the notebook to the still-running kernel on a persistent remote Jupyter server, so running state and outputs are lost and subsequent cells execute against a new process.

## Best solution

Transfer the issue to microsoft/vscode-jupyter so the kernel/session-reconnect owners can look at remote persistent-server reattachment after a connection drop or reload; no change in vscode core is implied by the report.
