# Issue #321678 — Hard to close tabs for diffs created by AH chat

[https://github.com/microsoft/vscode/issues/321678](https://github.com/microsoft/vscode/issues/321678)

## Summary

Team-authored UX rough edge that still stands on current main: the single-file diffs opened from chat/Agent Host pills are opened without a preferred editor label, so the diff tab falls back to '<name> ↔ <name>' plus a forced description built from absolute agent-host paths — a very wide tab whose close button is hard to hit.

## Change summary

Opening a diff from an Agent Host chat pill creates an extremely long editor tab that is hard to close with the mouse.

## Best solution

Give chat-opened diffs the same concise preferred label the local chat-editing path already uses (localize('diff.generic', '{0} (changes from chat)', basename(uri))) at the remaining chat/AH open sites, so the tab shows a short file-scoped title instead of a path-derived name plus forced description.
