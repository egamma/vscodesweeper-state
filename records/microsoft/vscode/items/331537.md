## Summary

Fresh maintainer-filed visual bug (screenshot only, no repro steps or comments) — the chat input's completion suggest description popup appears to render behind an editor placed in the sidebar. Team-authored, so this stays open and just needs area routing rather than a judgment close.

## Change summary

When an editor is shown in the sidebar (or an aux-bar editor part) alongside the chat input's completions dropdown, the suggest widget's description/details box renders underneath the sidebar editor instead of on top of it.

## Best solution

Route to the chat/editor-suggest owners to check stacking context: the completion details container (`.suggest-details-container`, z-index 41) is a very low z-index compared to editor/sidebar surfaces (e.g. modal editor part at z-index 2540), so an editor hosted in the sidebar likely creates a stacking context that sits above the chat completion popup; needs a maintainer to confirm the exact DOM nesting from the screenshot and adjust the layering.
