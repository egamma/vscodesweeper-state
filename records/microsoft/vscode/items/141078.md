# Issue #141078 — SCM - hard to see the file list visual structure

[https://github.com/microsoft/vscode/issues/141078](https://github.com/microsoft/vscode/issues/141078)

## Summary

Keep open: current SCM settings do not provide the compact, aligned path presentation requested, and the issue has substantial community support. The linked contribution remains open and needs a maintainer design decision rather than a competing implementation.

## Change summary

Provide a compact SCM file presentation that makes directory relationships easy to scan without reconstructing paths from tree ancestors.

## Best solution

Resolve the presentation direction in https://github.com/microsoft/vscode/pull/149821: evaluate aligned path-first rows against the team's proposed path deduplication, ensuring the chosen design preserves directory context while scrolling and filename readability in narrow views.
