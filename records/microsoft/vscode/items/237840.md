# Issue #237840 — [Firefox] File tree context menu shows just "Paste" and opens unreliably

[https://github.com/microsoft/vscode/issues/237840](https://github.com/microsoft/vscode/issues/237840)

## Summary

The Firefox bug remains present on current main: opening the Explorer context menu awaits an asynchronous clipboard read, which Firefox exposes as the native Paste prompt before VS Code shows its own menu. The issue should remain open while the Firefox behavior and the broader editor/terminal reports are addressed without regressing Chromium clipboard support.

## Change summary

In Firefox web builds, right-clicking the file tree can show a native Paste-only prompt or both that prompt and VS Code's Explorer context menu.

## Best solution

Avoid invoking Firefox's permission-gated asynchronous clipboard read merely to open a context menu, while retaining the in-memory resource state fallback and Chromium's supported cross-window resource clipboard behavior. Decide whether the same work should cover the editor and integrated-terminal manifestations reported in the thread.
