# Issue #265910 — Saving 7MB notebook takes more than 1 minute

[https://github.com/microsoft/vscode/issues/265910](https://github.com/microsoft/vscode/issues/265910)

## Summary

Valid performance bug: saving a 7MB notebook over SSH takes >60 seconds despite the experimental `remoteSave` setting being enabled. The issue is still open — no fix has landed on main for this scenario, and the maintainer's suggested mitigations did not resolve it.

## Change summary

Saving a large (~7MB, 40 images) Jupyter notebook over an SSH remote connection takes over one minute even for trivial edits, far slower than JupyterLab's 20-second save of the same file.

## Best solution

Investigate the notebook save pipeline for remote/SSH scenarios — the incremental-save path (`notebook.experimental.remoteSave`) is not delivering the expected speedup. The bottleneck likely lies in the data transfer or serialization between processes in the remote extension host architecture. The comparison with JupyterLab (20s vs 60s+) suggests VS Code is doing unnecessary work or roundtrips.
