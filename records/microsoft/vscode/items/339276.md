# Issue #339276 — A single MCP tool with an incomplete (but JSON-Schema-legal) array parameter blocks registration of every tool from that server

[https://github.com/microsoft/vscode/issues/339276](https://github.com/microsoft/vscode/issues/339276)

## Summary

Same symptom as the older, open #325618: strict Copilot tool-schema validation rejects an MCP tool's array parameter that has no `items`. Proposing a duplicate close so the discussion lands in one place. The code path is still present on main.

## Change summary

An MCP tool with an array parameter lacking `items` makes Copilot's tool-schema validation throw, which breaks the whole chat request for every tool.

## Best solution

Fix it once under https://github.com/microsoft/vscode/issues/325618. Either accept a missing `items` as an unconstrained array in toolSchemaNormalizer.ts, or drop or skip only the offending tool and log a warning, so other tools and servers stay usable.
