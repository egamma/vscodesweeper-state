# Issue #337211 — Fix the same colour token for var name and it's value in Dark 2026 theme

[https://github.com/microsoft/vscode/issues/337211](https://github.com/microsoft/vscode/issues/337211)

## Summary

Plausible, source-backed contrast defect in the brand-new 'Dark 2026' theme's tokenColors: the variable-definition scope (`entity.name` / `meta.definition.variable`) and the variable-reference scope (`variable`) both resolve to the same `#ffa657`, which can read as 'name and value look identical' exactly as the reporter describes; picking a better-differentiated color needs a design call, not a mechanical fix.

## Change summary

In the Dark 2026 color theme, the syntax-highlighting color for a variable's name and the color used where that variable is read/assigned looks identical, making code harder to scan versus Dark Modern.

## Best solution

A theme maintainer should revisit the Dark 2026 `tokenColors` in extensions/theme-defaults/themes/2026-dark.json and give variable-definition vs. variable-reference (or name vs. assigned value, depending on what the screenshot shows) more contrast, the way Dark Plus/Dark Modern's blue `#9CDCFE` reads cleanly against its keyword/storage colors.
