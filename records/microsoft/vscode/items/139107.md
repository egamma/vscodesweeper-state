# Issue #139107 — Colorize background like in CoenraadS/Bracket-Pair-Colorizer-2

[https://github.com/microsoft/vscode/issues/139107](https://github.com/microsoft/vscode/issues/139107)

## Summary

The requested bracket-background colorization remains missing: native bracket colors affect foregrounds, while guide colors affect guide lines. Keep this accepted Backlog request open; the older related requests do not establish the same observable requirement needed for a duplicate close on re-review.

## Change summary

Support coloring bracket-character backgrounds using bracket-pair colors, as Bracket Pair Colorizer 2 could do.

## Best solution

Provide an optional, theme-compatible way to give bracket characters backgrounds corresponding to their pair colors, without changing default rendering or sacrificing native colorization performance. Resolve whether this applies only to the active scope or to all colorized pairs before implementation.
