# Issue #144244 — [less] Build-in LESS syntax hint error, multiple '&'

[https://github.com/microsoft/vscode/issues/144244](https://github.com/microsoft/vscode/issues/144244)

## Summary

The defect remains in the current CSS language service: its selector-preview builder interprets the second adjacent `&` as a descendant clone. Keep this open as an upstream language-service issue.

## Change summary

LESS hover renders nested `&&` as a descendant relationship instead of the compound selector produced by LESS.

## Best solution

Correct adjacent parent-selector expansion in `microsoft/vscode-css-languageservice` so `.link { && {} }` previews the compound `.link.link` semantics, add a LESS selector-printing regression test, and then consume the corrected service in VS Code.
