# Issue #283106 — Local session not cleared after delegating to background with changes

[https://github.com/microsoft/vscode/issues/283106](https://github.com/microsoft/vscode/issues/283106)

## Summary

Keep open: delegation cleanup has changed since the report, but the dirty-worktree-specific failure is not proven fixed. The supplied clean-versus-dirty comparison is sufficient to retest; current source still has a confirmation-sensitive, 30-second cleanup window.

## Change summary

Successful delegation to a background agent leaves the original local chat uncleared and unarchived when the repository has uncommitted changes.

## Best solution

Make successful background delegation consistently archive the original local session and clear its chat when chat.exitAfterDelegation is enabled, including after uncommitted-change confirmation. First establish whether the remaining failure comes from confirmation timing or another lifecycle transition; retain the original chat on cancellation or failure.
