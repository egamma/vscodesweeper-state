# Issue #306156 — Window title is not centered

[https://github.com/microsoft/vscode/issues/306156](https://github.com/microsoft/vscode/issues/306156)

## Summary

The left-aligned window title in compact mode is an intentional design choice from the 'Compact agent status' feature (PR #300560), but with 15 upvotes it represents meaningful community feedback that the visual change is jarring. Worth reviewing the design decision.

## Change summary

Window title text is left-aligned instead of centered when the agent status compact mode is enabled (the default).

## Best solution

The titlebar team should evaluate whether the title label can remain centered even in compact mode (e.g. by centering the label within the available space rather than left-aligning it with `margin: auto auto auto 0`), or provide a more discoverable way to restore centered behavior than the hidden setting workaround.
