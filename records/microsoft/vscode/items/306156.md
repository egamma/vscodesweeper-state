# Issue #306156 — Window title is not centered

[https://github.com/microsoft/vscode/issues/306156](https://github.com/microsoft/vscode/issues/306156)

## Summary

The left-aligned label is intentional in compact mode, including when the unified agents bar is disabled. The existing chat.agentsControl.enabled setting restores the centered presentation, as the reporter already confirmed.

## Change summary

Restore centered window-title text inside the command center instead of the compact mode's left-aligned label.

## Best solution

Keep the intentional compact layout and use "chat.agentsControl.enabled": "hidden" for the centered presentation without agent status, or "badge" to retain a separate status badge.

- **Fit:** aligned
- **Reason:** Consistent titlebar presentation fits the workbench UX theme, but the existing configuration already provides the requested centered presentation.
