# Issue #187955 — Incorrect $PATH order in task shell

[https://github.com/microsoft/vscode/issues/187955](https://github.com/microsoft/vscode/issues/187955)

## Summary

Keep open: multiple reporters and a maintainer confirmed that shell tasks reorder PATH and select different executables from interactive terminals. Current source retains the relevant login-shell path, but no verified fixing commit or eligible canonical issue establishes that this reopened report is resolved.

## Change summary

Shell tasks on macOS reorder user-configured PATH entries behind system directories, causing the wrong toolchain executable to run.

## Best solution

Resolve the task shell startup and inherited-environment interaction so ordinary tasks preserve user-configured executable precedence without requiring per-task PATH repairs. Investigate login versus interactive initialization first, preserving explicit automation profiles and task shell overrides.
