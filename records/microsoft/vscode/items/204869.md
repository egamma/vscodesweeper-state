# Issue #204869 — Allow hovers to opt in to wrapping content

[https://github.com/microsoft/vscode/issues/204869](https://github.com/microsoft/vscode/issues/204869)

## Summary

A real hover-layout gap remains on main: ordinary hovers reposition before constraining their width. This team-authored Backlog request should remain open.

## Change summary

Allow hover callers to prefer wrapping content before the hover moves to another side of its target.

## Best solution

Extend the workbench hover options with a wrapping preference and apply it in `HoverWidget.adjustHorizontalHoverPosition`, constraining available width before considering relocation. Cover both preferred wrapping and existing default placement behavior in hover service tests.
