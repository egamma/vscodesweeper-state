# Issue #275225 — Any tool approval should be separately indented

[https://github.com/microsoft/vscode/issues/275225](https://github.com/microsoft/vscode/issues/275225)

## Summary

Keep open for the requested UX decision: current source still places server-wide approval controls alongside individual tools, rather than above them in the hierarchy. The discussion identifies an unresolved pre-/post-approval grouping problem, not an agreed indentation fix; this team-authored issue should retain its under-discussion status.

## Change summary

Make the relationship between server-wide tool approval controls and individual tool approvals visually clearer.

## Best solution

Agree on an approval-management hierarchy that clearly distinguishes server-wide controls from individual tools while representing tools with both pre- and post-approval coherently. Then apply that design in LanguageModelToolsConfirmationService without changing permission semantics.
