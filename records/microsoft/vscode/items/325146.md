# Issue #325146 — Remote-SSH: Avoid connection reconnects on workspace change

[https://github.com/microsoft/vscode/issues/325146](https://github.com/microsoft/vscode/issues/325146)

## Summary

This is a Remote-SSH connection-lifecycle feature request owned by the VS Code Remote Development team. It should remain open and be transferred to the Remote Development tracker rather than closed as caused by an extension.

## Change summary

Reuse an established Remote-SSH connection when switching workspaces on the same host, avoiding repeated setup delays.

## Best solution

Have Remote-SSH preserve or reuse the host connection and remote server state when opening another folder on the same authority, provided doing so does not compromise workspace isolation. The design belongs in the Remote-SSH connection lifecycle maintained in https://github.com/microsoft/vscode-remote-release.
