# Issue #325146 — Remote-SSH: Avoid connection reconnects on workspace change

[https://github.com/microsoft/vscode/issues/325146](https://github.com/microsoft/vscode/issues/325146)

## Summary

Move this request to the Remote-SSH tracker rather than close it. Avoiding repeated SSH setup when switching workspaces remains a distinct request; the checked related issues concern reconnection after connection loss or workspace-trust failures.

## Change summary

Reuse an established SSH connection when switching between workspaces on the same remote host, avoiding repeated setup delays.

## Best solution

Support same-host workspace changes without unnecessarily repeating SSH connection setup, while preserving workspace-specific extension and storage isolation. The Remote-SSH owners should assess the transport lifecycle together with core workspace reload behavior.

- **Current workspace lifecycle:** src/vs/workbench/services/workspaces/electron-browser/workspaceEditingService.ts: NativeWorkspaceEditingService.enterWorkspace stops extension hosts and explicitly reloads remote windows, with a comment identifying the reload as a workaround until restarting works.
