# Issue #314086 — /chronicle:standup empty on Monday

[https://github.com/microsoft/vscode/issues/314086](https://github.com/microsoft/vscode/issues/314086)

## Summary

Valid feature request with no duplicate. The `/chronicle:standup` SKILL.md explicitly hardcodes a 24-hour lookback window, which misses Friday activity when run on Monday. The fix would make the standup prompt weekend-aware.

## Change summary

Running `/chronicle:standup` on Monday should look back to the previous Friday instead of only the last 24 hours.

## Best solution

Update the Standup workflow in `extensions/copilot/assets/prompts/skills/chronicle/SKILL.md` (lines 29–36) to use a weekend-aware time window — e.g. look back 72 hours on Monday (or detect the day of week and adjust the interval to reach the previous workday). The prompt file `extensions/copilot/assets/prompts/chronicle-standup.prompt.md` may also need a hint about this behavior.
