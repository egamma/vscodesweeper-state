# Issue #314086 — /chronicle:standup empty on Monday

[https://github.com/microsoft/vscode/issues/314086](https://github.com/microsoft/vscode/issues/314086)

## Summary

Keep open: Chronicle still explicitly defaults to the last 24 hours, leaving Friday's activity outside a Monday standup. This requests a business-day-aware default rather than reporting a deviation from the current prompt's instructions.

## Change summary

Include the previous Friday's sessions automatically when generating a standup on Monday.

## Best solution

Make Chronicle's default standup window account for weekends while preserving explicitly requested date ranges. Keep the standup prompt and Chronicle skill consistent about that behavior.
