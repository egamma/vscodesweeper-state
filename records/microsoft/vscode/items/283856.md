# Issue #283856 — Chat input part must not depend on `IAgentSessionsService.model`

[https://github.com/microsoft/vscode/issues/283856](https://github.com/microsoft/vscode/issues/283856)

## Summary

The reported dependency remains on current main: ChatInputPart still observes the agent sessions view model for changed files and pull-request context. The linked cleanup PR was closed without merging, so this remains necessary architectural work.

## Change summary

Remove the chat input's dependency on the agent sessions view model while preserving session-specific changed-file behavior.

## Best solution

Make the chat input consume file-change state from its chat model, following the maintainer-endorsed direction, without losing background-session changes or toolbar behavior. Account for the additional session-model dependency used for pull-request context before treating the cleanup as complete.
