# Issue #321070 — feature request: add Copilot cost overview by workspace

[https://github.com/microsoft/vscode/issues/321070](https://github.com/microsoft/vscode/issues/321070)

## Summary

Keep open as a feature request: current quota and session-cost displays do not provide a workspace-level spending overview. The older project-tagging request is related, but does not clearly own the requested in-editor overview.

## Change summary

Show detailed Copilot spending attributed to individual workspaces directly within VS Code.

## Best solution

Decide the scope and accounting source for a workspace-level cost overview in the chat usage experience, distinguishing measured credit consumption from monetary charges. Coordinate attribution requirements with the existing project-tagging request without treating its GitHub billing report as equivalent to an in-editor overview.
