# Issue #48123 — editor.action.sortLinesAscending has confusing sort order for symbols

[https://github.com/microsoft/vscode/issues/48123](https://github.com/microsoft/vscode/issues/48123)

## Summary

The built-in editor commands still use locale-aware collation without an ASCII/code-unit sorting option; the Explorer setting does not cover this request. Keep this accepted, well-supported request open for a decision on exposing alternative ordering and preserving the current default.

## Change summary

Provide predictable ASCII ordering for editor line sorting, including punctuation and case, through an alternative command or configurable sorting mode.

## Best solution

Offer an explicit editor line-sorting mode that produces ASCII order for ASCII input without unintentionally changing existing locale-aware workflows. Decide whether this belongs in a separate command or an editor setting before implementation.
