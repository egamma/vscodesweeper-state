# Issue #48123 — editor.action.sortLinesAscending has confusing sort order for symbols

[https://github.com/microsoft/vscode/issues/48123](https://github.com/microsoft/vscode/issues/48123)

## Summary

Keep open: this team-authored Backlog request has 66 community upvotes, and current main still lacks a configurable editor line-sorting order.

## Change summary

Provide an ASCII/code-point sorting option for Sort Lines so punctuation and prefixes can follow programming-tool conventions.

## Best solution

Preserve locale-aware sorting as the compatibility default, but add an editor line-sorting mode or separate command for Unicode/code-point ordering. The implementation belongs in the line-operations contribution around `SortLinesCommand`, modeled on the Explorer's lexicographic option.
