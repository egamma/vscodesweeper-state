# Issue #336994 — Chat Customizations: 'Local', 'Remote' are confusing

[https://github.com/microsoft/vscode/issues/336994](https://github.com/microsoft/vscode/issues/336994)

## Summary

Thanks for the report. The 'Local' and 'Remote' group labels are still generic on current main, with no explanation beyond a skills-only tooltip. This looks like a real labeling and clarity gap in the Chat Customizations list, so it stays open.

## Change summary

The Chat Customizations skills page shows 'Local' and 'Remote' groups next to Workspace, User and Extensions, and their meaning is unclear when the harness runs on the local workspace.

## Best solution

Rename or relabel the remote-host and remote-client groups so they say what they are (for example, tied to the active harness name). Alternatively, hide the groups when the harness is local. Make sure the group descriptions are shown for every section, not only Skills.
