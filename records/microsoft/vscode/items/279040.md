# Issue #279040 — Allow to use `applyEdit` w/ AI-review UI from tools and also refactorings

[https://github.com/microsoft/vscode/issues/279040](https://github.com/microsoft/vscode/issues/279040)

## Summary

Keep open: the public workspace edit API still cannot associate edits with a chat request and its native review UI. Maintainers explicitly supported this direction and consolidated an older request here; neither existing bulk-edit preview nor the closed UI-removal PR resolves the API gap.

## Change summary

Allow extension tools and refactorings to submit edits through VS Code's native tracked-edit review experience without requiring access to a chat response stream.

## Best solution

Provide an opt-in, supported edit-review API following the maintainer's preferred workspace.applyEdit direction, while preserving ordinary applyEdit behavior. Define how standalone refactorings and externally performed edits participate before implementing the public contract.
