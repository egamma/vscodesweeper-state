# Issue #273203 — Auto complete doesn't realize we are using React 19

[https://github.com/microsoft/vscode/issues/273203](https://github.com/microsoft/vscode/issues/273203)

## Summary

The gap remains on current main: NES receives TypeScript and compiler-option traits, but not the installed React type-library version, so it lacks the context needed to distinguish React 19 behavior. The issue is already routed to NES and should remain open for a scoped design and implementation.

## Change summary

Next Edit Suggestions repeatedly proposes converting React 19 function components to the obsolete `React.forwardRef` pattern despite `@types/react@19` being installed.

## Best solution

Provide NES with the resolved versions of standard or globally contributing type libraries, including `@types/react`, so suggestions follow the APIs available to the active TypeScript project.
