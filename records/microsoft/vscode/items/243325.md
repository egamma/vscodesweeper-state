# Issue #243325 — Folder Auto-Collapses After Window Switch in VS Code

[https://github.com/microsoft/vscode/issues/243325](https://github.com/microsoft/vscode/issues/243325)

## Summary

This remains a confirmed Explorer bug: returning focus triggers a full refresh that can render a compact folder as an ordinary collapsed folder, losing the user's visible expansion state. A maintainer confirmed that diagnosis, and current main still contains the implicated focus-refresh and compressible-tree path.

## Change summary

Creating a single-child folder hierarchy and switching away from VS Code causes the Explorer folder to appear collapsed when focus returns.

## Best solution

Preserve the compact folder's expanded presentation when the Explorer refreshes after window focus, with a regression test covering the create-nested-folder, focus-refresh sequence.
