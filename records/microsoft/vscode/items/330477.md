# Issue #330477 — Copilot Agent Host not able to switch account

[https://github.com/microsoft/vscode/issues/330477](https://github.com/microsoft/vscode/issues/330477)

## Summary

Keep open: multiple reporters confirm that Copilot Agent Host uses the wrong account, including after restarts, and the issue was reopened after the suggested workaround failed. Current source exposes an account-selection gap, but its contribution to the reported execution-time switching still needs diagnosis.

## Change summary

Ensure Copilot Agent Host honors the selected Copilot account without requiring other GitHub accounts to be signed out.

## Best solution

Make Agent Host authentication consistently follow the user's Copilot account selection for new requests and after host restarts, while preserving separate repository authentication. Diagnose initial credential selection separately from live credential propagation before consolidating this with restart-related reports.
