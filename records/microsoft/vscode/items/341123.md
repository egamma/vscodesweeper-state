## Summary

Thanks for the detailed follow-up. I did not trace the source this pass, so I could not confirm the suspected credential-routing mismatch, and I found no cited fix after #340547. ## Change summary

Copilot Connectors (WorkIQ, Kusto) Sign In reports success, but the gateway still rejects the connector's credential with insufficient_scope.

## Best solution

Make connector Sign In update the same account credential source that managed connector HTTP requests use, preserving the selected account. Only report authentication success after the connector connects or lists tools, and surface an actionable failure when the gateway rejects the credential.
