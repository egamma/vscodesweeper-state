# Issue #322409 — Context window size in donut doesn't match selection

[https://github.com/microsoft/vscode/issues/322409](https://github.com/microsoft/vscode/issues/322409)

## Summary

Keep open as UX polish: current main intentionally shows the selected input-token tier in the picker but the combined input-plus-output window in the usage widget, without making that distinction clear. The later exact report is under discussion, and because this re-reviewed issue predates it, the newer issue cannot be its duplicate canonical.

## Change summary

Make the context-size picker and context-usage widget communicate consistently when the selected input limit is smaller than the model's total input-plus-output window.

## Best solution

Choose and consistently communicate the two quantities: either present the total effective context in both surfaces or explicitly label the picker as the input limit and show the output reserve separately in the usage details. Consolidate the newer discussion at https://github.com/microsoft/vscode/issues/323463 into this older report rather than closing this report as its duplicate.
