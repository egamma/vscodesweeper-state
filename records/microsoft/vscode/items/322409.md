# Issue #322409 — Context window size in donut doesn't match selection

[https://github.com/microsoft/vscode/issues/322409](https://github.com/microsoft/vscode/issues/322409)

## Summary

Team-authored test finding still awaiting confirmation from the area owner (lramos15) on whether the picker vs. donut discrepancy is intentional or a display bug. Keeping open until that call is made.

## Change summary

The context-window size shown in the donut widget (input + output tokens, e.g. 400K) does not match the size shown in the model picker (input tokens only, e.g. 272K), confusing users about how much context is available.

## Best solution

Clarify whether the donut should show the same input-only budget as the picker, or if the picker should surface the combined input+output window. The discrepancy lives in `resolveContextWindow()` in `chatContextUsageWidget.ts` (line 406: `totalContextWindow = maxInputTokens + maxOutputTokens`) versus the picker which displays only `contextSize` (the input budget). Once lramos15 confirms the intended behavior, either align the two displays or add a label distinguishing input-only from total window.
