## Summary

Plausible bug report about parent agent sessions terminating when a sub-agent is launched in the Agents window. There is active development on subagent support (read-only tabs, status pills, multi-chat), but the report lacks logs or version-specific details to confirm the defect. ## Change summary

Parent agent session terminates immediately when it delegates work to a sub-agent via the task tool, instead of waiting for the sub-agent result.

The agent-host team should investigate whether the agent host harness correctly keeps the parent session alive during sub-agent delegation, or whether this is a known limitation of the current runtime.
