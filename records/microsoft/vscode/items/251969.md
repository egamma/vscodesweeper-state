# Issue #251969 — SCM Graph - Allow git branches graph to set auto with other branches

[https://github.com/microsoft/vscode/issues/251969](https://github.com/microsoft/vscode/issues/251969)

## Summary

Keep open: the graph still treats Auto and explicit branch selections as mutually exclusive, so the requested combined filter remains missing. The older related requests do not own the full capability.

## Change summary

Allow the SCM Graph to follow the current branch automatically while also retaining explicitly selected branches.

## Best solution

Support a graph filter combining dynamically resolved Auto references with explicitly selected references, without requiring users to reselect their current branch after switching branches. Preserve the existing Auto-only, manual-only, and All modes.
