# Issue #330201 — Add setting to disable code block copy buttons in Markdown preview

[https://github.com/microsoft/vscode/issues/330201](https://github.com/microsoft/vscode/issues/330201)

## Summary

The Markdown preview already has an intentional extensibility mechanism (contributed preview CSS for extension authors, plus the user-facing `markdown.styles` setting) that fully covers hiding `.code-block-copy-button`; the reporter's own use case (Marp for VS Code) already adopted this and shipped a fix, and the reporter is unsure the request is still needed.

## Change summary

Add a setting or opt-out mechanism so Markdown preview extensions (e.g. Marp) can disable the injected code-block copy button.

## Best solution

No new core setting needed: extension authors hide `.code-block-copy-button` via contributed preview CSS (documented at https://code.visualstudio.com/api/extension-guides/markdown-extension#changing-the-look-of-the-markdown-preview-with-css), and end users can do the same with `markdown.styles` (registered in extensions/markdown-language-features/package.json, line 1562).
