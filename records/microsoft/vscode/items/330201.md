# Issue #330201 — Add setting to disable code block copy buttons in Markdown preview

[https://github.com/microsoft/vscode/issues/330201](https://github.com/microsoft/vscode/issues/330201)

## Summary

Keep open for a product decision about an explicit copy-button opt-out. Marp has resolved the reported presentation problem, but current VS Code still lacks a setting or contribution that prevents button injection; CSS hiding is an existing workaround.

## Change summary

Allow users or Markdown preview extensions to disable fenced-code-block copy buttons.

## Best solution

Decide whether the Markdown preview should expose an explicit opt-out beyond its existing CSS customization mechanisms. Preserve the default copy-button experience and distinguish preventing injection from hiding the resulting controls.
