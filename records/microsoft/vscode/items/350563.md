# Issue #350563 — Experiment-controlled settings accept treatments of the wrong type or outside the setting's enum

[https://github.com/microsoft/vscode/issues/350563](https://github.com/microsoft/vscode/issues/350563)

## Summary

The reported validation gap remains on current main: non-array treatments bypass schema checks, and invalid startup treatments stop subsequent resolution. Keep this open for a bounded configuration fix; the report establishes a defensive defect, not a currently failing production treatment.

## Change summary

Reject and log experiment treatments that violate the setting's type or enum, preserving defaults and allowing startup settings to await a valid treatment.

## Best solution

Non-keyed experiment defaults should respect their setting's declared type and enum while preserving existing array decoding, user-setting precedence, assignment metadata, and startup latching after a valid value.
