# Issue #290572 — KeyboardInterrupt seen in terminal when launching python debugger

[https://github.com/microsoft/vscode/issues/290572](https://github.com/microsoft/vscode/issues/290572)

## Summary

Keep open: first-launch Python debugging is interrupted without user input, independently confirmed in the discussion, and the reported activation fix did not resolve Windows. No verified fix or eligible duplicate establishes completion of this team-authored report.

## Change summary

Prevent unsolicited KeyboardInterrupt errors when first launching the Python debugger in a virtual environment.

## Best solution

Ensure debugger launch and Python environment activation do not interrupt each other's commands in the integrated terminal. Terminal and debugger owners should establish which caller injects the interrupt before deciding whether the remaining change belongs in core or a VS Code-owned Python extension.
