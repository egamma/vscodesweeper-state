# Issue #290572 — KeyboardInterrupt seen in terminal when launching python debugger

[https://github.com/microsoft/vscode/issues/290572](https://github.com/microsoft/vscode/issues/290572)

## Summary

Team-authored issue about a race condition where the Python debugger sends commands to the terminal before the prompt input model is ready, causing spurious KeyboardInterrupt. No fix on main references this issue; the problem spans VS Code's terminal readiness API and the Python debugger extension's command timing.

## Change summary

First-time Python debug launch triggers a spurious KeyboardInterrupt in the terminal because the debugger sends commands before the terminal prompt is ready.

## Best solution

Either the terminal needs a more robust API for extensions to await prompt readiness before sending commands (core-side), or the Python Debugger extension needs to adopt the same readiness check pattern already used by the Python Environments extension (extension-side). Both sides may need work given the Windows-specific failure after the vscode-python fix attempt.
