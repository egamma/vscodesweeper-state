# Issue #242956 — Suggest widget height for fewer than twelve items is calculated incorrectly

[https://github.com/microsoft/vscode/issues/242956](https://github.com/microsoft/vscode/issues/242956)

## Summary

Still reproduces on main: the suggest widget height calculation includes `borderHeight` when computing inner height, adding 2–4 extra pixels. An open PR (#242958) addresses this but has not merged.

## Change summary

Suggest widget shows extra whitespace at the bottom when fewer than twelve items are displayed, because border height is included in the inner height calculation.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/242958, which removes `borderHeight` from the suggest widget height calculation — the same pattern as the earlier fix in commit d66eb6b for the default-size case.

## Evidence

- **source trace:** In src/vs/editor/contrib/suggest/browser/suggestWidget.ts, lines 839, 856, and 864, `info.borderHeight` is added to the inner height calculations. Since the result is used to set the inner (content-box) height, the border pixels are double-counted, producing 2px (normal) or 4px (HC) extra whitespace.
- **open PR:** https://github.com/microsoft/vscode/pull/242958 ('Remove border height from suggest widget height calculation') references Fixes #242956 but is still open and unmerged as of current main.
- **prior fix:** Commit d66eb6b82f4fd73db17a4b7cc0799f90a09207bc fixed the analogous issue for the default (≥12 items) size, confirming the pattern.
