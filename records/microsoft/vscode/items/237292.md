# Issue #237292 — Hardware acceleration creates memory Leak on 1.96.2; eventually caps RAM and freezes computer

[https://github.com/microsoft/vscode/issues/237292](https://github.com/microsoft/vscode/issues/237292)

## Summary

The memory leak occurs in the Chromium GPU process via NVIDIA's NvMessageBus.dll — this is an upstream driver/Chromium interaction issue, not a VS Code code defect. The workaround (disabling hardware acceleration) confirms the root cause is in the GPU pipeline. No VS Code code change addresses this, and no other reporters have confirmed it on current builds.

## Change summary

With hardware acceleration enabled on NVIDIA GPUs, the Chromium GPU subprocess leaks memory until the system freezes.

## Best solution

Classify as upstream (Chromium/NVIDIA driver interaction). The reporter's workaround (disable-hardware-acceleration) is the correct mitigation. If this affects more users on newer Electron versions, it should be reported upstream to Chromium's GPU process bug tracker. The issue could also benefit from a check on the latest Insiders build with updated Electron to see if newer Chromium resolves it.
