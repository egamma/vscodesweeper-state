# Issue #326393 — Chat vs Conversation vs Chat naming is confusing

[https://github.com/microsoft/vscode/issues/326393](https://github.com/microsoft/vscode/issues/326393)

## Summary

Team-authored UX/naming-consistency observation about the new Agents window; confirmed on current main that terminology overlaps (e.g. `chatCompositeBar.conversations` renders as 'Chats' while related context keys and comments refer to a 'Conversations' menu). No fix has landed and this is squarely a design decision, not a mechanical implementation gap, so it stays open for the team to settle the naming.

## Change summary

The Agents window UI mixes 'Chats', 'Sessions', and 'Conversations' inconsistently for related-but-distinct concepts, confusing users.

## Best solution

A designer/maintainer on the Agents window (src/vs/sessions) should pick a consistent vocabulary for folder-level sessions vs. per-session chat threads vs. the chats menu, then apply it across sessionsActions.ts, contextkeys.ts, and the accessibility help strings.
