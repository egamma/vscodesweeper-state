# Issue #326393 — Chat vs Conversation vs Chat naming is confusing

[https://github.com/microsoft/vscode/issues/326393](https://github.com/microsoft/vscode/issues/326393)

## Summary

Keep open for a terminology decision: current Agents and Chat surfaces use “chat,” “session,” and “conversation” for overlapping concepts. This is a team-authored UX issue, so a judgment-based close is barred, and no factual fix or canonical duplicate was found.

## Change summary

Define and consistently apply distinct user-facing names for quick chats, workspace-scoped sessions, and individual conversation threads.

## Best solution

Establish a single product taxonomy for the container and thread concepts, then apply it consistently across the Agents window, Chat commands, accessibility labels, and supporting descriptions without changing the underlying session model.
