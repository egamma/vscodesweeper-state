# Issue #301590 — Request for folder settings interface in the .code-workspace file

[https://github.com/microsoft/vscode/issues/301590](https://github.com/microsoft/vscode/issues/301590)

## Summary

The requested syntax is intentionally unsupported: folder-scoped settings belong in each workspace folder's `.vscode/settings.json`, and maintainers have explicitly declined adding a second per-folder settings mechanism inside `.code-workspace` files.

## Change summary

Allow each folder entry in a multi-root `.code-workspace` file to contain its own settings object.

## Best solution

Keep the existing configuration model: place resource-scoped settings in each folder's `.vscode/settings.json` and reserve the `.code-workspace` `settings` section for workspace-wide values.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding a second representation for folder settings would create configuration and interaction complexity that conflicts with VS Code's preference for simple, uniform behavior.
- **Evidence:** Value and guardrail: “Simple, uniform UI and UI interactions” and a lean default experience.
