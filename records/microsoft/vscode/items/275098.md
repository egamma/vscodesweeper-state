# Issue #275098 — Difficult to review output - allow summarization?

[https://github.com/microsoft/vscode/issues/275098](https://github.com/microsoft/vscode/issues/275098)

## Summary

Keep open: the current post-approval UI still displays tool results directly, rather than offering the isolated summarization step requested here. This team-authored, accepted request needs a decision about the approval and data-flow contract, not a decline or staleness close.

## Change summary

Allow an isolated, untrusted summarizer to condense tool output before the user approves its delivery to the main agent.

## Best solution

Define a security-reviewed summarization flow for tool-result post-approval that reduces the material users must inspect without silently allowing unreviewed original output into the main agent. The contract must establish what the summarizer can access and exactly which content approval releases.
