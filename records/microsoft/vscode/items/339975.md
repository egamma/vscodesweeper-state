# Issue #339975 — --goto rejects relative filenames containing only digits

[https://github.com/microsoft/vscode/issues/339975](https://github.com/microsoft/vscode/issues/339975)

## Summary

Confirmed on current main: `parseLineAndColumnAware` in extpath.ts treats a purely-numeric first segment as line data instead of the filename, so `--goto 123:5:2` throws instead of resolving the file `123`. An open PR already proposes a fix, so this should stay open pending that review rather than being closed or auto-fixed independently.

## Change summary

`code --goto 123:5:2` (or any numeric-only relative filename) fails to parse because the parser consumes the mandatory FILE segment as the LINE number when it is all-digits.

## Best solution

Review and land the linked fix PR (https://github.com/microsoft/vscode/pull/339976), which patches `parseLineAndColumnAware` in src/vs/base/common/extpath.ts to preserve a numeric-only first segment as the path.
