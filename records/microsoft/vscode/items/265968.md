# Issue #265968 — Add Support for PDF File Parsing in GitHub Copilot Context Addition

[https://github.com/microsoft/vscode/issues/265968](https://github.com/microsoft/vscode/issues/265968)

## Summary

Keep open: native PDF handling exists for vision-capable models, but a maintainer reopened this Backlog item to track making Vision generally available when enterprise policy disables preview features. The remaining work is an upstream service rollout with substantial community demand, not a missing bounded parser in VS Code.

## Change summary

Allow GitHub Copilot to consume attached PDF documents as chat context, including for enterprise users who disable preview features.

## Best solution

Make PDF-capable Vision support generally available to eligible enterprise plans without requiring preview features, while preserving model capability checks. When policy or model capabilities still block a PDF, clearly explain that limitation instead of attempting an unrelated script fallback.
