# Issue #147752 — Line Endings Selector showing wrong Line Endings in Diff View

[https://github.com/microsoft/vscode/issues/147752](https://github.com/microsoft/vscode/issues/147752)

## Summary

The reported mismatch remains traceable in current source: the line-ending selector reads the modified diff model regardless of which side has focus. Keep this open for a focused editor-status correction; the related reports do not establish a canonical duplicate.

## Change summary

The line-ending selector shows the modified file's LF when the original CRLF side of a Git diff is focused.

## Best solution

Make the EOL status unambiguous when focus moves between diff sides: show the focused model's actual line ending, or hide the selector on the read-only original side. Preserve writable-file EOL conversion and avoid broad changes to diff rendering or Git normalization.
