# Issue #17901 — Add extension point for custom "prefix behaviors" in command palette

[https://github.com/microsoft/vscode/issues/17901](https://github.com/microsoft/vscode/issues/17901)

## Summary

A real API gap remains: VS Code has an internal prefix-based Quick Access provider registry, but extensions cannot register providers. Keep this Backlog request open under discussion rather than closing it for age or low engagement.

## Change summary

Allow extensions to register custom command-palette prefixes that activate their own Quick Access behavior.

## Best solution

Design a public extension API over the existing Quick Access provider model, including prefix ownership, lifecycle, cancellation, help entries, and collision handling. The likely implementation spans the public API declaration and extension-host/main-thread Quick Input bridge.
