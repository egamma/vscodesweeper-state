# Issue #312794 — Plus Button Position Confusing

[https://github.com/microsoft/vscode/issues/312794](https://github.com/microsoft/vscode/issues/312794)

## Summary

Keep open as Agents Window polish. Current main puts the session toolbar beside the chat tabs, but “New Chat in This Session” remains a secondary overflow action rather than the browser-like plus affordance requested here; the team-authored Backlog item cannot receive a judgment close.

## Change summary

Place the control for creating another chat beside the chat tabs so its relationship to those tabs is immediately clear.

Expose “New Chat in This Session” as a clear tab-strip action adjacent to the chat tabs, while preserving its existing Ctrl/Cmd+T behavior and accessible action label. Validate the hierarchy in the Agents Window chat-tab component rather than adding another top-level session-header action.
