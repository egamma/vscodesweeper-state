# Issue #294610 — Editor scroll happening too near the cursor initial position when moving text selection

[https://github.com/microsoft/vscode/issues/294610](https://github.com/microsoft/vscode/issues/294610)

## Summary

Plausible bug — editor scroll during selection drag triggers too early at larger font sizes. The reporter identified font size 20 as the trigger and a contributor confirmed different behavior at default size 14, but the exact threshold mismatch hasn't been traced in code. Routing to the editor area for investigation.

## Change summary

When editor font size is set to 20, dragging a selection triggers auto-scroll too close to the cursor's starting position, rather than only near the editor edges.

## Best solution

Investigate whether the drag-scroll threshold in `src/vs/editor/browser/controller/mouseHandler.ts` (`_getPositionOutsideEditor`) and the minimal-reveal padding in `src/vs/editor/browser/viewParts/viewLines/viewLines.ts` (`_computeScrollTopToRevealRange`) need to account for line height or font size when determining how close to the editor edge the cursor must be before auto-scroll kicks in. Related: https://github.com/microsoft/vscode/issues/218248 covers a similar problem for drag-and-drop text movement.
