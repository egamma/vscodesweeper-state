# Issue #286087 — Can VsCode extension share the same Monaco Editor instance/component with the VsCode?

[https://github.com/microsoft/vscode/issues/286087](https://github.com/microsoft/vscode/issues/286087)

## Summary

Keep this accepted API request open: extensions can open VS Code's diff editor, but cannot embed its editor component through the current public API. The older webview-editor request is related, but does not establish the same reported diff-loading problem required for a duplicate close on re-review.

## Change summary

Allow extensions to reuse VS Code's editor component for embedded diffs instead of loading a separate Monaco distribution.

## Best solution

Establish whether the native-editor embedding work should explicitly support extension-hosted diff views and resource reuse. Preserve vscode.diff as the existing solution for comparisons that can open in a normal editor tab.
