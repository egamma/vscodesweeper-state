# Issue #293025 — Inconsistent keyboard shortcut for inserting new line between Source Control input and Find widget

[https://github.com/microsoft/vscode/issues/293025](https://github.com/microsoft/vscode/issues/293025)

## Summary

Keep open as a keyboard-consistency feature request: current Find deliberately uses Shift+Enter for Find Previous and Ctrl+Enter for newline insertion. The requested consistency remains absent, but changing it requires weighing discoverability against existing navigation shortcuts.

## Change summary

Provide a consistent, discoverable newline-insertion shortcut across Source Control and Find inputs.

## Best solution

Evaluate a discoverable multiline-input convention that preserves Find's established next/previous-match navigation and Source Control's accept-input shortcut. The current bindings explain the difference but do not satisfy the requested consistency.
