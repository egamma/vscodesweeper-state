# Issue #332202 — Search bar pushes content down instead of overlaying it

[https://github.com/microsoft/vscode/issues/332202](https://github.com/microsoft/vscode/issues/332202)

## Summary

This is intentional behavior controlled by the `editor.find.addExtraSpaceOnTop` setting (default true), which adds a view zone above the first line so the Find widget doesn't cover code — the reporter can disable it in settings.

## Change summary

Opening the Find widget (Cmd+F) shifts the editor content down by roughly one line instead of overlaying it.

## Best solution

Point the reporter to `"editor.find.addExtraSpaceOnTop": false` in settings, which removes the reserved space and keeps the Find widget purely as an overlay; no code change needed.

  > Thanks for the report. This is expected behavior: the Find widget reserves a small view zone above the first line so it doesn't cover code you might want to search — this is controlled by the `editor.find.addExtraSpaceOnTop` setting (default `true`). Setting `"editor.find.addExtraSpaceOnTop": false` in your settings will make the widget overlay the content without shifting it. Closing as as-designed, but feel free to reopen if this doesn't address what you're seeing.
