# Issue #332202 — Search bar pushes content down instead of overlaying it

[https://github.com/microsoft/vscode/issues/332202](https://github.com/microsoft/vscode/issues/332202)

## Summary

The editor intentionally reserves space above the document while Find is visible. The existing editor.find.addExtraSpaceOnTop setting disables that space and provides the requested overlay behavior.

## Change summary

Keep document content stationary beneath an overlay when opening and closing the editor Find widget.

## Best solution

Preserve the configurable behavior and explain that setting editor.find.addExtraSpaceOnTop to false prevents Find from adding document space.
