[https://github.com/microsoft/vscode/issues/312810](https://github.com/microsoft/vscode/issues/312810)

## Summary

Keep open: current inline-chat code still permits delayed progress writes after request completion, and telemetry added through October reports continuing closed-stream errors. The related open reports are newer and involve different producers, so neither qualifies as a canonical duplicate for this re-reviewed issue.

## Change summary

Prevent asynchronous Copilot response producers from writing to a response stream after its request has ended.

## Best solution

Make background progress work respect the lifetime of its owning request while preserving progress during active requests and existing closed-stream API diagnostics. Separate the inline-chat and hook-related telemetry signatures before treating any individual fix as resolving the whole report.
