## Summary

The inline-chat response-stream race remains on current main and has substantial cross-platform telemetry impact. Keep this issue open for a localized lifecycle fix.

## Change summary

Inline chat can asynchronously push a progress message after VS Code has closed its response stream.

## Best solution

Tie contextual-progress work to the lifetime of `InlineChatIntent.handleRequest` in `extensions/copilot/src/extension/inlineChat2/node/inlineChatIntent.ts`, preventing delayed progress after completion or cancellation while preserving progress for active requests.
