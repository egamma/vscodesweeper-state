# Issue #312810 — [Error] [GitHub.copilot-chat] unhandlederror-Response stream has been closed

[https://github.com/microsoft/vscode/issues/312810](https://github.com/microsoft/vscode/issues/312810)

## Summary

Active race condition in the Copilot extension's response stream handling — the extension pushes data after VS Code core has closed the stream. Still reproduces on current main across multiple code paths and extension versions, affecting thousands of users. Should stay open for a fix.

## Change summary

The Copilot extension throws 'Response stream has been closed' when async operations (inline chat intent processing, edit tracking, hook processing) attempt to push to a ChatAgentResponseStream after VS Code core has closed it.

## Best solution

Guard all async push paths in the Copilot extension (chatResponseStreamImpl.ts callers like inlineChatIntent.ts, externalEditTracker.ts, hookResultProcessor.ts) to check the cancellation token or stream-closed state before calling stream methods. The throw originates from `extHostChatAgents2.ts:85` (`throwIfDone`), but the fix belongs in the extension callers that race against stream closure.
