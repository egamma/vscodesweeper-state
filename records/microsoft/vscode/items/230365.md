# Issue #230365 — Terminal search gives up after only 1000 search highlights

[https://github.com/microsoft/vscode/issues/230365](https://github.com/microsoft/vscode/issues/230365)

## Summary

The search highlight limit was raised from 1000 to 20000 (commit bfa8c6695a4, shipped in 1.100.0), and the upstream 'search is too slow' issue (xtermjs/xterm.js#5176) was closed. However, the upstream 'search is not incremental' issue (xtermjs/xterm.js#5177) remains open, and the core UX concern — that the terminal skips matches in the middle rather than stopping at a well-defined point — has not been addressed. Keeping open as the upstream work is incomplete.

## Change summary

Terminal search highlights are unreliable when the number of matches exceeds the highlight limit, skipping matches in the middle rather than stopping at a defined boundary.

## Best solution

The remaining work depends on upstream xtermjs/xterm.js#5177 (incremental search) landing, which would let the terminal render highlights progressively without a hard cutoff that skips middle matches. Once that ships, VS Code can adopt it and potentially remove or further raise the limit. The `help wanted` label is appropriate.
