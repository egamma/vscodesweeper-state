# Issue #263309 — Git - When cloning repo should specify that password can be a token

[https://github.com/microsoft/vscode/issues/263309](https://github.com/microsoft/vscode/issues/263309)

## Summary

The HTTPS credential prompt still lacks token guidance when authentication falls back to manual input. Keep this accepted Backlog item open as a bounded wording improvement; existing GitHub sign-in does not cover the full request.

## Change summary

Clarify that the password requested during HTTPS Git authentication may need to be a personal access token rather than an account password.

## Best solution

Make the built-in Git extension's manual HTTPS credential prompt explain token use without implying that every Git server rejects passwords. Preserve automatic credential providers, credential masking, and SSH prompts.
