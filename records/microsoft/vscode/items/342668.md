# Issue #342668 — Copilot harness does not support chat.hookFilesLocations setting

[https://github.com/microsoft/vscode/issues/342668](https://github.com/microsoft/vscode/issues/342668)

## Summary

Keep open for the owning maintainer to reconcile requested hook-location compatibility with the established migration direction. Current main explicitly limits this setting to the Local harness; moving the hook to a supported directory is a workaround, not support for the configured location.

## Change summary

Preserve execution of hooks stored in locations configured through chat.hookFilesLocations when switching from Local to Copilot.

## Best solution

Provide an explicit, supported transition for existing custom hook locations rather than silently losing their behavior. The published direction favors migration to harness-owned locations; the owner should resolve whether this report requires direct location support or a migration experience that preserves the workspace's intent.
