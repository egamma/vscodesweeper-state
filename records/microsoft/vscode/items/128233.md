# Issue #128233 — Custom dialog removes leading whitespace from lines

[https://github.com/microsoft/vscode/issues/128233](https://github.com/microsoft/vscode/issues/128233)

## Summary

Still reproduces on main: the dialog message container uses `white-space: normal` which collapses leading whitespace. A maintainer already identified the fix location but it was never applied.

## Change summary

Custom dialogs strip leading whitespace from lines because the CSS uses `white-space: normal` instead of `pre-wrap`.

## Best solution

Change `white-space: normal` to `white-space: pre-wrap` on the `.dialog-message-container` selector in `src/vs/base/browser/ui/dialog/dialog.css` (line 102), preserving the word-wrap behavior while respecting whitespace. Needs testing that long unbroken lines still wrap.
