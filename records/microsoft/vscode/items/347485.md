# Issue #347485 — Feature Request: separate Confirm Before Close into separate Confirm Before Quit and Confirm Before Window Close settings

[https://github.com/microsoft/vscode/issues/347485](https://github.com/microsoft/vscode/issues/347485)

## Summary

Independent quit and window-close confirmation remains unavailable. The same request was previously closed for insufficient community upvotes, not a substantive scope decision, and no open canonical was found.

## Change summary

Allow application quitting to require confirmation while individual windows close without prompting.

## Best solution

Provide independently configurable quit and window-close confirmation if maintainers accept the additional configuration surface, preserving existing defaults and distinguishing macOS window closure from application exit.

- **Fit:** aligned
- **Reason:** Independent confirmation supports multi-window workflows by protecting a disruptive application-wide action without interrupting routine window closure.
