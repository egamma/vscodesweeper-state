# Issue #347485 — Feature Request: separate Confirm Before Close into separate Confirm Before Quit and Confirm Before Window Close settings

[https://github.com/microsoft/vscode/issues/347485](https://github.com/microsoft/vscode/issues/347485)

## Summary

The requested distinction is missing: window closing and application quitting still share one confirmation setting. Keep this open as a feature request; the keybinding workaround does not provide independent confirmation policies.

## Change summary

Allow application quit confirmation without requiring confirmation when closing an individual window.

## Best solution

Provide independent window-close and application-quit confirmation policies while preserving existing defaults and honoring the distinction in both keyboard commands and native menus.
