# Issue #255581 — VS Code deb package overriding commented out `vscode.sources`

[https://github.com/microsoft/vscode/issues/255581](https://github.com/microsoft/vscode/issues/255581)

## Summary

Still reproduces on main: the postinst script unconditionally overwrites vscode.sources when the file exists (line 78–79), ignoring commented-out lines despite the header promising comments are preserved.

## Change summary

The deb package postinst script overwrites commented-out lines in vscode.sources on reinstall/upgrade, contradicting the file's own header comment.

## Best solution

In `resources/linux/debian/postinst.template`, when `CODE_SOURCE_PART_DEB822` already exists, check whether the active (uncommented) entries are present before overwriting. If all entries are commented out, either skip writing or preserve the commented state. Alternatively, remove the misleading 'You may comment out this entry' header comment if the team decides not to honor it.
