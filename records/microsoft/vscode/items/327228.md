# Issue #327228 — `npm view --json` returns an array since npm 12 and breaks hover metadata in package.json

[https://github.com/microsoft/vscode/issues/327228](https://github.com/microsoft/vscode/issues/327228)

## Summary

Confirmed on main: `npmView()` in packageJSONContribution.ts doesn't handle npm 12's array-wrapped `npm view --json` output, so hover metadata silently disappears — an open PR already fixes it, so this stays open pending review/merge rather than closing.

## Change summary

npm 12+ changed `npm view --json` to return an array, breaking package.json hover metadata (latest version, description, homepage) in the built-in npm extension.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/327951, which adds an `Array.isArray` guard in `npmView()` (extensions/npm/src/features/packageJSONContribution.ts) and includes unit tests; close this issue once that PR merges.
