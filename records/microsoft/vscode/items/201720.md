# Issue #201720 — Abnormal syntax highlight for Perl in Search Editor ("search.action.openNewEditor")

[https://github.com/microsoft/vscode/issues/201720](https://github.com/microsoft/vscode/issues/201720)

## Summary

The remaining missing Perl POD heading highlighting is supported by current source: Search Editor prefixes each source line, while the embedded Perl grammar requires POD headings at the physical start of a line. Keep this open in search-editor; the reporter's clarified sample and steps are sufficient.

## Change summary

Perl POD section headers lose their syntax highlighting in Search Editor compared with the same file in a normal text editor.

## Best solution

Make Search Editor preserve Perl POD heading recognition despite its result-line prefixes, without changing ordinary Perl highlighting or the selectable search-result format. Establish tokenization regression coverage before choosing the implementation boundary.
