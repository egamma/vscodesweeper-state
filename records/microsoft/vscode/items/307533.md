# Issue #307533 — Sessions: Pinning while in progress removes pin after completed

[https://github.com/microsoft/vscode/issues/307533](https://github.com/microsoft/vscode/issues/307533)

## Summary

Team-authored bug with no fixing commit found on main. The pin-state management in SessionsListModelService looks correct in isolation (status transitions only call markUnread, not unpin), but the broader session lifecycle — visible-sessions grid replacement, session re-creation on completion — could still clear the pin via deleteSession. No commit references this issue, so the bug likely persists.

## Change summary

Pinning a session while it is in progress causes the pin to reset when the session's turn completes, moving it back to its workspace/project group.

## Best solution

Trace the exact session lifecycle event that fires when a turn completes (the onDidChangeSessions path in sessionsListModelService.ts) and confirm whether the session is surfaced as `removed` + `added` rather than `changed` — if so, that triggers `deleteSession` which clears the pin. The fix would preserve pinned state across session identity changes, likely in `sessionsListModelService.ts` and possibly `visibleSessions.ts`.
