## Summary

The renderer-crash root cause has been fixed on main: agent-session caches now retain aggregate change counts instead of full per-file arrays, and providers defer detailed changes until explicitly resolved.

## Change summary

Prevent large imported CLI session histories from creating an unbounded renderer cache that can crash the window.
