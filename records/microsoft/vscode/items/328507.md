# Issue #328507 — Chat scroll indicator doesn't go to short last message

[https://github.com/microsoft/vscode/issues/328507](https://github.com/microsoft/vscode/issues/328507)

## Summary

The current source confirms that a short final request cannot be aligned by the prompt timeline because trailing viewport space is reserved only for response rows. Keep this team-authored issue open and route it to the Agents chat area.

## Change summary

Allow the prompt timeline indicator to navigate fully to a short final user message.

## Best solution

Reserve enough trailing scroll space to reveal a settled final request near the viewport top, while preserving the intentional compact spacing for queued or steering requests beneath an active response.
