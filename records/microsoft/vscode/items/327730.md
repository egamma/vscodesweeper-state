# Issue #327730 — Maximized window edge triggers resize cursor and fails scrollbar hit testing

[https://github.com/microsoft/vscode/issues/327730](https://github.com/microsoft/vscode/issues/327730)

## Summary

Keep open as an upstream window-edge hit-testing issue: the reporter confirmed it after upgrading, and another Ubuntu/GNOME/Wayland user independently confirmed it. Older reports establish the same resize-versus-scroll symptom in tiled windows, but do not explicitly establish coverage of this maximized-window case.

## Change summary

Prevent the rightmost edge of a maximized window from intercepting vertical-scrollbar interaction as horizontal window resizing.

## Best solution

Resolve Electron's native window-edge hit testing so a maximized window delivers right-edge pointer interaction to its scrollbar. Correlate the maximized GNOME/Wayland case with the existing tiled-window reproduction before consolidating the reports.
