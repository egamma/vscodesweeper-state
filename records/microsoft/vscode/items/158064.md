# Issue #158064 — Turn quick access prefixes into blocks so that they can be easily cleared

[https://github.com/microsoft/vscode/issues/158064](https://github.com/microsoft/vscode/issues/158064)

## Summary

The linked slash-command PR is not a fix for this Quick Access request; it only changed chat slash commands, while current Quick Access still stores provider prefixes as plain input text and selection offsets.

## Change summary

Turn Quick Access provider prefixes such as `>` and `?` into removable/autocompletable token blocks.

## Best solution

Keep the Backlog request open for the quick-open owners to decide/design; an implementation would need to live in the Quick Input/Quick Access UI rather than the chat slash-command block work.
