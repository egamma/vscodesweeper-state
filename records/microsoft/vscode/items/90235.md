[https://github.com/microsoft/vscode/issues/90235](https://github.com/microsoft/vscode/issues/90235)

## Summary

Keep this exploration open: current CodeLens rendering still reserves space above source lines, and no built-in line-end mode covers the request. Exploration items are protected from closure; 91 upvotes and a maintainer-directed duplicate also support retaining this discussion.

## Change summary

Explore configurable line-end CodeLens rendering that preserves source-line layout while retaining the existing above-line presentation.

## Best solution

Use this issue to evaluate an optional line-end presentation in the editor's CodeLens renderer, preserving the existing mode. Resolve discoverability on long lines and presentation of multiple or lengthy commands before committing to the alternative.
