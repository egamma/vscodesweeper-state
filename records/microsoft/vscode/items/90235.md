# Issue #90235 — Explore line-end-rendering of code lenses

[https://github.com/microsoft/vscode/issues/90235](https://github.com/microsoft/vscode/issues/90235)

## Summary

The requested alternate CodeLens placement remains absent on main, and this is the established canonical issue with 91 community upvotes. Keep it open for backlog consideration and design discussion.

## Change summary

Add a configurable mode that renders CodeLens commands at the end of their source line instead of above it.

## Best solution

Design an optional end-of-line CodeLens mode in the editor while preserving the current above-line default, with defined behavior for long lines, overflow, accessibility, and multiple lenses.
