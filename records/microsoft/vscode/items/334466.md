# Issue #334466 — Agent merge should not restrict `gh` cli access as it greatly limits its ability

[https://github.com/microsoft/vscode/issues/334466](https://github.com/microsoft/vscode/issues/334466)

## Summary

Keep open for the existing design discussion. Current main deliberately blocks GitHub CLI, GitHub MCP, and direct API access during unattended Agent Merge turns, while dedicated tools cover workflow reruns and review-thread resolution; whether broader access is worth the safety tradeoff remains unsettled.

## Change summary

Allow Agent Merge turns to use the GitHub CLI so they can perform GitHub operations that dedicated Agent Merge tools cannot complete.

## Best solution

Settle the unattended-workflow trust boundary first, then either close demonstrated capability gaps in the dedicated, scoped GitHub tools or introduce an explicit user-visible mode that permits broader GitHub access with clearly defined authorization and supervision semantics.
