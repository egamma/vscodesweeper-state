# Issue #65876 — Overriding the default 'type' command and then calling the default 'type' command results in significantly slower execution time

[https://github.com/microsoft/vscode/issues/65876](https://github.com/microsoft/vscode/issues/65876)

## Summary

Keep open in the Backlog: the extension-host round trip for an overridden `type` command remains on current main, and the affinity setting is only a partial workaround. The request has 97 community upvotes and was explicitly promoted to the Backlog.

## Change summary

Reduce the per-keystroke latency incurred when an extension overrides `type` and delegates to `default:type`.

## Best solution

Provide a low-latency interception or delegation path for typing extensions that avoids two extension-host RPC transitions per keystroke. Retain `extensions.experimental.affinity` as isolation from other extensions, but do not treat it as resolving the baseline round-trip and frame-miss cost.
