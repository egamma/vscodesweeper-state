# Issue #326962 — Bug / UX Flaw: workbench.action.openAgentsWindow breaks default text editing binding (Toggle Block Comment)

[https://github.com/microsoft/vscode/issues/326962](https://github.com/microsoft/vscode/issues/326962)

## Summary

Valid keybinding conflict on Linux: Open Agents Window (Ctrl+Shift+A, weight WorkbenchContrib=200) takes precedence over Toggle Block Comment (Ctrl+Shift+A on Linux, weight EditorContrib=100) when the editor has focus, because the Agents Window when clause does not exclude editorTextFocus.

## Change summary

On Linux, Ctrl+Shift+A opens the Agents Window instead of toggling a block comment when the editor has focus.

## Best solution

Add `EditorContextKeys.editorTextFocus.toNegated()` to the Agents Window keybinding's `when` clause (in `src/vs/workbench/contrib/chat/electron-browser/agentSessions/agentSessionsActions.ts` line 98), or change the Linux binding to a chord like `Ctrl+K Ctrl+A`. The screen-reader conflict was already addressed in commit 66436519738 with the same pattern (adding a negated context); this is the analogous fix for the editor-focus case on Linux.
