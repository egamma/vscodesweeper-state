# Issue #320851 — Delete Cell button is not accessible using arrow key navigation in notebook toolbar:A11y_Visual Studio Code Jupyter Extensions_Home_Keyboard

[https://github.com/microsoft/vscode/issues/320851](https://github.com/microsoft/vscode/issues/320851)

## Summary

Legitimate accessibility bug — the delete button lives in a separate ToolBar instance from the main cell toolbar, preventing arrow-key traversal between them. No fix on main; team-authored issue stays open.

## Change summary

The Delete Cell button in the notebook cell toolbar is not reachable via arrow key navigation because it's in a separate toolbar element from the other cell actions.

## Best solution

Unify the delete action into the same WorkbenchToolBar as the other cell toolbar actions (or implement a roving tabindex across both toolbar containers) so arrow keys traverse all items in the cell toolbar row as a single group. The fix belongs in `src/vs/workbench/contrib/notebook/browser/view/cellParts/cellToolbars.ts`.
