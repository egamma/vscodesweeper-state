# Issue #348082 — [Agents] Terminal approval handling leads to unresponsive subagents

[https://github.com/microsoft/vscode/issues/348082](https://github.com/microsoft/vscode/issues/348082)

## Summary

Keep open: the report provides sufficient steps to retest intermittent failures after approval in both windows. Current source contains subagent permission-routing safeguards, but inspection did not establish whether they cover this failure.

## Change summary

Parallel subagents intermittently fail to start approved terminal commands, sometimes after unexpectedly prompting for an explicitly allowed command.

## Best solution

Identify where an approved child tool loses progress between the confirmation action, pending permission settlement, and terminal execution. Preserve legitimate policy-required prompts while ensuring accepted approvals reach the requesting subagent.
