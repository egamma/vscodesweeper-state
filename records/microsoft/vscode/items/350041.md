[https://github.com/microsoft/vscode/issues/350041](https://github.com/microsoft/vscode/issues/350041)

## Summary

Existing commands provide chat-area visibility and additional space, but do not cover the requested discoverable layout buttons. Keep this open as a UI affordance request rather than treating it as an unanswered how-to.

## Change summary

Provide discoverable buttons to show, hide, and maximize the chat area alongside the existing side-bar controls.
