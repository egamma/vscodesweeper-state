# Issue #301278 — Readable tsx output for tool calls in the log

[https://github.com/microsoft/vscode/issues/301278](https://github.com/microsoft/vscode/issues/301278)

## Summary

Keep open: current tool logging still serializes prompt-tsx results as JSON, and the debug viewer pretty-prints that JSON rather than extracting readable text. This team-authored request identifies a remaining improvement; no verified canonical or issue-referencing fix was found.

## Change summary

Provide a basic readable text representation of prompt-tsx tool results in chat diagnostic logs.

## Best solution

Make prompt-tsx tool results readable in diagnostic output without changing the actual tool response sent to the model. Establish whether readable text replaces the serialized diagnostic result or accompanies an inspectable raw representation.
