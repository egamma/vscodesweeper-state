# Issue #217387 — Language type icon overriding file autocompletion

[https://github.com/microsoft/vscode/issues/217387](https://github.com/microsoft/vscode/issues/217387)

## Summary

Still reproduces on main: when editor font size is large, file-type icons in the suggest widget remain at a fixed 16px background-size while the row grows, causing visual misalignment. No fix has landed.

## Change summary

File-type icons in autocomplete stay 16px when editor font size is increased, creating a visual mismatch with the larger suggest widget rows.

## Best solution

In the suggest widget renderer's `configureFont` function (suggestWidgetRenderer.ts), or via a CSS override in suggest.css, scale the `.monaco-icon-label::before` background-size to match the computed line height — similar to how `icon.style.height` and `icon.style.width` are already set to `lineHeightPx`.
