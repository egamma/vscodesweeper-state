# Issue #320820 — Voice input should mute mic routing to other apps (e.g. Teams) while active

[https://github.com/microsoft/vscode/issues/320820](https://github.com/microsoft/vscode/issues/320820)

## Summary

This is a valid, still-unimplemented feature request in the existing dictation area. Current voice capture only owns VS Code's MediaStream and provides no mechanism for muting microphone input in other applications, while no open canonical issue owns this exact request.

## Change summary

Temporarily prevent calling applications from receiving microphone audio while VS Code dictation or Voice Mode is listening.

## Best solution

First establish whether supported OS-level audio-session APIs can provide safe, reversible cross-application microphone isolation on each desktop platform. If not, retain shared capture behavior rather than relying on invasive or platform-specific manipulation of other applications.

## Evidence

- **current capture path:** On current main, `ChatSpeechToTextService._acquireStream` in `src/vs/workbench/contrib/chat/browser/speechToText/chatSpeechToTextService.ts` requests an ordinary `navigator.mediaDevices.getUserMedia` stream; `_stopCapture` stops only that stream's tracks. There is no interaction with other applications' audio sessions.
- **Voice Mode path:** `MicCaptureService._startCapture` in `src/vs/workbench/contrib/chat/browser/voiceClient/micCaptureService.ts` likewise acquires a standard MediaStream with channel, sample-rate, echo-cancellation, and noise-suppression constraints, none of which requests exclusive microphone access.
- **related issue:** https://github.com/microsoft/vscode/issues/204722 concerns degraded Teams audio while older speech keyword recognition kept the microphone active. It was closed as an upstream SDK problem and does not own this request to deliberately block other applications while active.
- **existing capability check:** The current source supports selecting, starting, stopping, and locally muting VS Code's microphone capture, but no setting or command provides cross-application microphone isolation.
