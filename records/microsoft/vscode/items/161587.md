# Issue #161587 — Merge editor: provide labels for undo operations to help local history timeline

[https://github.com/microsoft/vscode/issues/161587](https://github.com/microsoft/vscode/issues/161587)

## Summary

Keep open: the merged PR labels the save before conflict resolution, but current conflict-acceptance edits still create generic text-edit undo entries. Semantic operation labels remain missing, and the maintainer explicitly distinguished that remaining work from the save-source improvement.

## Change summary

Give merge-editor conflict-resolution operations meaningful undo labels that local history can display instead of "File Saved".

## Best solution

Preserve meaningful conflict-resolution identity through the merge editor's undo entries so local history can distinguish accepting either side. Retain existing undo grouping, conflict-handled state restoration, and the separate pre-resolution save label.
