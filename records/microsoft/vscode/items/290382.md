# Issue #290382 — VS Code does not properly interpret GitHub Copilot in-chat code references

[https://github.com/microsoft/vscode/issues/290382](https://github.com/microsoft/vscode/issues/290382)

## Summary

Valid bug: relative file path links generated by the LLM in chat markdown responses are not properly resolved against workspace folders, causing 'file not found' errors when clicked. The `resolveChatResponseUri` mechanism exists for agent host sessions but standard Copilot chat sessions may not resolve workspace-relative paths correctly.

## Change summary

Clicking relative file path links in Copilot chat responses fails with 'file not found' in multi-root workspaces.

## Best solution

The chat markdown rendering's `resolveChatResponseUri` path (or the content provider for standard Copilot chat) needs to resolve relative file paths against workspace folders — similar to how `WorkingDirectory.resolveRelativePath` works but checking all workspace folders, not just the first. The fix likely belongs in the Copilot extension's session content provider or in `chatMarkdownContentPart.ts`'s URI transform logic.
