# Issue #207748 — Possible perf issue due to unnecessary rendering of outputs when outputs are not visible

[https://github.com/microsoft/vscode/issues/207748](https://github.com/microsoft/vscode/issues/207748)

## Summary

Still valid on main: the notebook output rendering path eagerly renders outputs for all cells that get their template instantiated, regardless of viewport visibility. No fix commit references this issue, and the `createOutput` path in `cellOutput.ts` still passes `createWhenIdle: false` unconditionally when showing outputs.

## Change summary

Notebook outputs are rendered (images sent to webview) even for cells not currently visible in the viewport, causing unnecessary work and potential freezes with many output-heavy cells.

## Best solution

Defer output rendering for cells outside the viewport — either gate `viewUpdateShowOutputs` on viewport intersection or pass `createWhenIdle: true` for off-screen cells. The existing `requestCreateOutputWhenWebviewIdle` infrastructure already supports deferred creation; the gap is that `cellOutput.ts` line 240 and line 610 always pass `false` for `createWhenIdle`.
