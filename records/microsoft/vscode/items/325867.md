# Issue #325867 — Remote - SSH session failed on macOS - UnpackFailed

[https://github.com/microsoft/vscode/issues/325867](https://github.com/microsoft/vscode/issues/325867)

## Summary

This is a Remote - SSH extension issue (the extension downloads and unpacks the server binary, and the update endpoint is serving a zip file named .tar.gz for darwin-arm64). The issue belongs in the Remote SSH tracker and should be moved there.

## Change summary

Remote SSH connection to macOS fails because the VS Code server download for darwin-arm64 is a zip archive but is expected to be a gzipped tar, causing UnpackFailed.

## Best solution

Move this issue to https://github.com/microsoft/vscode-remote-release so the Remote SSH team can investigate whether the update endpoint is serving the wrong format for cli-darwin-arm64 or the unpacking logic needs to handle zip archives.
