# Issue #325867 — Remote - SSH session failed on macOS - UnpackFailed

[https://github.com/microsoft/vscode/issues/325867](https://github.com/microsoft/vscode/issues/325867)

## Summary

The detailed logs and archive inspection confirm a Remote-SSH installation bug: the macOS ARM64 server is downloaded as a ZIP but extracted as gzip. Remote-SSH is VS Code-team-owned, so this should be transferred to microsoft/vscode-remote-release rather than closed.

## Change summary

Remote-SSH fails to install the VS Code server on an Apple Silicon Mac because it treats a downloaded ZIP archive as a gzipped tarball.

## Best solution

Handle the macOS ARM64 server archive according to its actual format in Remote-SSH's server installation path, and preserve this report and its diagnostic logs by transferring it to https://github.com/microsoft/vscode-remote-release.
