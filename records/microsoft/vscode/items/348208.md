# Issue #348208 — Agent-host Copilot sessions add `Co-authored-by: Copilot` by default: silently introduced `chat.agentHost.copilot.includeCoAuthoredBy` defaults to on, overriding `git.addAICoAuthor: off`

[https://github.com/microsoft/vscode/issues/348208](https://github.com/microsoft/vscode/issues/348208)

## Summary

Keep open for a unified attribution and consent decision. Current source deliberately preserves the independent, enabled-by-default Agent Host setting; the existing opt-out does not satisfy the requested default, precedence, and consent guarantees.

## Change summary

Make agent-created commit attribution opt-in, consistent with Git attribution preferences, documented, and respected across session lifecycles and subagents.

## Best solution

Establish a coherent attribution contract across Git UI and Copilot Agent Host commits, with documented opt-out precedence and consent before attribution. Coordinate runtime-owned subagent inheritance separately rather than treating the existing Agent Host toggle as complete coverage.
