# Issue #348208 — Agent-host Copilot sessions add `Co-authored-by: Copilot` by default: silently introduced `chat.agentHost.copilot.includeCoAuthoredBy` defaults to on, overriding `git.addAICoAuthor: off`

[https://github.com/microsoft/vscode/issues/348208](https://github.com/microsoft/vscode/issues/348208)

## Summary

Keep open for an attribution-consent and configuration-consistency decision. Current source deliberately defaults agent-host attribution to true independently of git.addAICoAuthor; the related settings-file report does not cover this request's default, consent, and precedence requirements.

## Change summary

Make agent-created commit attribution opt-in and consistent with existing Git attribution preferences across session lifecycles and subagents.

## Best solution

Establish a coherent attribution and consent contract for Git UI and agent-host commits, with discoverable documentation and consistent lifecycle behavior. Coordinate runtime-owned subagent behavior rather than treating the existing independent opt-out as full coverage.
