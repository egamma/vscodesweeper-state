# Issue #336886 — Diff View menu shows wrong selected layout with workspace-folder-specific `diffEditor.renderSideBySide`

[https://github.com/microsoft/vscode/issues/336886](https://github.com/microsoft/vscode/issues/336886)

## Summary

Well-diagnosed, reproducible bug: the Diff View submenu's checked state is resolved via `config.*` context keys through the plain `IConfigurationService`, without the modified resource used by the actual diff editor/command path, so folder-scoped `diffEditor.renderSideBySide` overrides can desync the menu from the real layout.

## Change summary

In a multi-root workspace with a folder-level `diffEditor.renderSideBySide` override, the Diff View (Inline/Side by Side) menu shows the wrong checked item because it doesn't use the same resource-aware config resolution as the diff editor itself.

## Best solution

Make the Diff View menu's checked state resource-aware — likely by resolving `diffEditor.renderSideBySide` for the diff editor's modified resource (mirroring what `DiffEditorCommandsService.setViewMode()` and `AbstractTextEditor` already do) rather than through the global `config.*` context key, which has no resource context.
