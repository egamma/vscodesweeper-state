# Issue #336886 — Diff View menu shows wrong selected layout with workspace-folder-specific `diffEditor.renderSideBySide`

[https://github.com/microsoft/vscode/issues/336886](https://github.com/microsoft/vscode/issues/336886)

## Summary

The checked layout still uses resource-unaware configuration on current main, while the diff editor uses the modified resource's effective settings. Keep this open as a confirmed menu-state bug; the reporter has also offered to contribute a fix.

## Change summary

Make Diff View's checked mode reflect the effective configuration of the current diff editor in a multi-root workspace.

## Best solution

The Diff View menu should report the modified resource's configured mode and stay synchronized when resources or settings change, without changing configuration-write targets or automatic and temporary layout behavior.
