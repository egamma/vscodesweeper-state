# Issue #132725 — Emmet with percentage unit does not trigger in CSS-in-JS

[https://github.com/microsoft/vscode/issues/132725](https://github.com/microsoft/vscode/issues/132725)

## Summary

Still reproduces on main: Emmet's abbreviation extraction in JS/TS files uses markup/jsx syntax mode, not stylesheet mode, so CSS abbreviations with unit suffixes like `w100p` fail to expand in CSS-in-JS object contexts. No fix has been committed.

## Change summary

Emmet abbreviations with percentage units (e.g. `w100p` → `width: 100%`) do not trigger in CSS-in-JS style objects within JavaScript files.

## Best solution

Emmet's completion provider needs CSS-in-JS context detection — when the cursor is inside a JS/TS object literal that looks like a style declaration, switch to stylesheet syntax for abbreviation extraction and expansion. This is a non-trivial parsing problem (the `emmet-parse` label acknowledges it) and likely requires heuristic detection of CSS-in-JS patterns in `defaultCompletionProvider.ts`.
