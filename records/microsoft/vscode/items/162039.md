# Issue #162039 — Merge Editor: A way to look through automatically resolved "conflicts"

[https://github.com/microsoft/vscode/issues/162039](https://github.com/microsoft/vscode/issues/162039)

## Summary

Keep open: current merge-editor navigation still skips handled changes, so the requested final-review workflow remains missing. Existing visibility controls and related issues do not cover navigating every merge block.

## Change summary

Provide next/previous navigation through all merge blocks, including automatically resolved and manually accepted changes.

## Best solution

Provide an explicit all-changes review navigation experience in the merge editor while preserving the existing unhandled-conflict navigation. It should remain useful when no unresolved conflicts remain and should not change resolution state.
