# Issue #209814 — InlineCompletion selectedSuggestInfo context enrichment

[https://github.com/microsoft/vscode/issues/209814](https://github.com/microsoft/vscode/issues/209814)

## Summary

The requested snippet context remains unavailable to inline completion providers. Keep this accepted Backlog request open for an API-owner decision; the discussion questions the proposed abstraction but does not establish a rejection.

## Change summary

Expose selected suggestion placeholder or cursor-placement information so inline completion providers can augment snippet arguments rather than only extend flattened text.

## Best solution

Agree on a minimal provider-facing contract for selected suggestion insertion positions and snippet-aware augmentation, preserving the abstraction between suggestions and inline completions. Resolve whether this information belongs in VS Code's completion context or should be obtained from language providers before committing to an API.
