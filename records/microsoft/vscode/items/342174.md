# Issue #342174 — Colour picker disappears when mouse goes off the edge

[https://github.com/microsoft/vscode/issues/342174](https://github.com/microsoft/vscode/issues/342174)

## Summary

This duplicates an older, verified-open report of the color picker dismissing while the mouse button remains held outside its bounds. Consolidate on that issue, which already has an open fix candidate.

## Change summary

Keep the color picker open during a held-button drag beyond its bounds, clamp the selected color to the edge, and commit the selection on release.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode/issues/327430 and review the existing implementation candidate at https://github.com/microsoft/vscode/pull/327575. Preserve the existing edge clamping while ensuring hover dismissal cannot interrupt an active color-selection drag.

The missing behavior is maintaining the enclosing hover through the drag, not adding edge clamping.
