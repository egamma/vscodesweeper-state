# Issue #317089 — Agents app shouldn't show any input until there is definitely a host

[https://github.com/microsoft/vscode/issues/317089](https://github.com/microsoft/vscode/issues/317089)

## Summary

Keep open: current source still renders the workspace picker while host discovery is unresolved, then replaces it when discovery finds no hosts. This team-authored report identifies a concrete remaining startup-state defect.

## Change summary

Prevent the Agents web workspace picker and session input from appearing before a host is known to be available.

## Best solution

The web new-session surface should withhold workspace selection and session input while no host is confirmed, distinguish discovery from a completed empty result, and reveal the controls when a host becomes available. Preserve the functional local workspace picker on desktop.
