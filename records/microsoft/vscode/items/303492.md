# Issue #303492 — Add "reveal session folder in file explorer" action on the session entry in the sessions list for cli

[https://github.com/microsoft/vscode/issues/303492](https://github.com/microsoft/vscode/issues/303492)

## Summary

Keep open: existing debug-log viewing and export actions do not reveal the original CLI session directory. The maintainer discussion favors a debugging command rather than a sessions-list menu entry; settle that presentation before implementation.

## Change summary

Provide a session-specific action to reveal the Copilot CLI session's diagnostic folder in the system file explorer.

## Best solution

Provide a developer-oriented command that resolves the chosen CLI session to its actual persisted directory and reveals it in the system file explorer, honoring COPILOT_HOME. Confirm whether command-only access satisfies the request before adding sessions-list context-menu surface.
