# Issue #339309 — Claude agent host: between-turn 'resume rebuild' kills subagents and drops replies

[https://github.com/microsoft/vscode/issues/339309](https://github.com/microsoft/vscode/issues/339309)

## Summary

Keep open: current source still replaces a live Claude subprocess for between-turn configuration drift without checking background work, and result handling can consume a pending user prompt for an unrelated SDK result. Independent reports through 1.143.1 corroborate the consequences; no verified fix or eligible canonical establishes that this broader report is resolved.

## Change summary

Preserve running Claude background tasks across ordinary between-turn updates and prevent SDK-generated notice results from completing unrelated user turns.

## Best solution

Make Claude configuration reconciliation respect live background work while preserving required configuration boundaries, and give unsolicited SDK activity turn ownership independent of pending user requests. Treat subagent survival and visible reply delivery as separate acceptance requirements.
