# Issue #311068 — MCP tool results for large files are silently truncated with a vscode-chat-response-resource:// hint that does not work

[https://github.com/microsoft/vscode/issues/311068](https://github.com/microsoft/vscode/issues/311068)

## Summary

The reported failure was credible and deterministic, but current main now makes chat-response resources readable by `read_file`: it exempts the URI scheme from the external-file rejection and registers a filesystem provider that resolves the referenced tool output.

## Change summary

Large MCP file results expose a `vscode-chat-response-resource://` recovery URI that `read_file` rejected as outside the workspace.

## Best solution

Keep the implementation introduced in commit dd7687527a42277a9625f06391880cb5aaa4fc83, where `read_file` accepts the response-resource scheme and the workbench filesystem provider resolves its tool-result content.
