## Summary

The broken MCP resource handoff was fixed after this report by commit 2f36dfd543178c66ef817342e2ad5f1fa1c4f430. Current `main` constructs the resource URI with the streamed tool-call ID that owns the stored result, allowing `read_file` to resolve it.

## Change summary

Large GitHub MCP file results were truncated with a recovery hint pointing to a `vscode-chat-response-resource://` URI that `read_file` could not access.
