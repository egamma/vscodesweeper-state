- **Behavior:**

  > Viewing a continuously appended remote log reportedly causes renderer memory to grow rapidly until the window crashes. Automatic file refresh should remain usable without runaway retained memory disproportionate to the document size. Reproduce the supplied Windows-to-Linux scenario, record the writer's rate and file growth, and verify that memory settles after writing stops. Unsaved editor changes must remain protected.

This traces a relevant core path but does not identify the retained objects or confirm the OOM; diagnosis must begin with reproduction and heap evidence. Preserve dirty-model protection, automatic refresh, and existing undo behavior unless evidence demonstrates a necessary behavioral change.
