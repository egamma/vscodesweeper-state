# Issue #339467 — Model Switcher cannot be opened on a Tablet PC

[https://github.com/microsoft/vscode/issues/339467](https://github.com/microsoft/vscode/issues/339467)

## Summary

Traced in source: the model picker's custom `_registerButtonAction` only wires up mousedown (pointerdown only on iOS) plus keydown, unlike the standard `Button` widget which also listens for the `Gesture.Tap` event (`-monaco-gesturetap`) synthesized by VS Code's own touch module for pen/touch input. That gap plausibly explains why touch/pen taps open other buttons but not this one on a Windows tablet.

## Change summary

On a Windows Tablet PC, finger/pen taps on the chat model picker button do nothing, though mouse clicks work and most other VS Code buttons respond fine to touch.

## Best solution

Add a `Gesture.Tap` (TouchEventType.Tap) listener alongside the existing mousedown/keydown handlers in `_registerButtonAction` in modelPickerWidget.ts, matching the pattern already used by the shared `Button` widget.
