## Change summary

Workspace search with a subfolder include pattern returns only open-file matches even when the open-editors restriction is disabled.

## Best solution

Ensure a subfolder-filtered workspace search returns matching unopened files when the open-editors toggle is off, while retaining open-editor-only behavior when it is on. Reproduce the reported scenario and inspect the generated query and disk-search provider results before choosing the fix.
