# Issue #175295 — A "tight layout" mode that reduces vertical spacing

[https://github.com/microsoft/vscode/issues/175295](https://github.com/microsoft/vscode/issues/175295)

## Summary

Valid feature request with 18 upvotes; current main still hardcodes cellTopMargin (6px), cellBottomMargin (6px), and editorTopPadding (12px) without user-facing settings to reduce them. The existing `notebook.compactView` only controls horizontal margins and markdown cell spacing, not the vertical spacing the reporter requests. This is the canonical issue for vertically compact notebooks (#147244 was merged into it).

## Change summary

Request to expose notebook vertical spacing (cell top/bottom margins, editor top padding) as user-configurable settings or a 'tight layout' mode.

## Best solution

Expose `notebook.cellTopMargin`, `notebook.cellBottomMargin`, and honor `editor.padding.top`/`editor.padding.bottom` in notebook cell editors (or a unified 'tight vertical layout' toggle). The hardcoded values live in `src/vs/workbench/contrib/notebook/browser/notebookOptions.ts` (lines ~229–230 for margins, line ~139 for editorTopPadding). This is the canonical issue — #147244 was merged here.
