# Issue #121851 — Process explorer difficult / impossible to use via screen reader

[https://github.com/microsoft/vscode/issues/121851](https://github.com/microsoft/vscode/issues/121851)

## Summary

The accessibility defect remains on current main: Process Explorer exposes only process names to assistive technology, does not focus a row when opened, and refreshes the tree every second. This is the canonical report and should remain open.

## Change summary

Make Process Explorer usable with screen readers by providing stable focus, meaningful row and column information, and non-disruptive refresh behavior.

## Best solution

Update the Process Explorer tree in src/vs/workbench/contrib/processExplorer/browser/processExplorerControl.ts to focus a useful row on entry, expose CPU, memory, PID, units, and hierarchy through accessible labels or grid-style navigation, and prevent periodic updates from repeatedly interrupting speech.
