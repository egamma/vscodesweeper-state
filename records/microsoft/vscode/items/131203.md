# Issue #131203 — Make horizontal cursor scroll padding configurable

[https://github.com/microsoft/vscode/issues/131203](https://github.com/microsoft/vscode/issues/131203)

## Summary

A real horizontal configurability gap remains on main, and the editor maintainer explicitly reopened the issue after confirming it. It already has the correct area label and Backlog milestone.

## Change summary

Allow users to configure how much horizontal space cursor-driven scrolling preserves around the cursor.

## Best solution

Add a supported editor setting analogous to `editor.cursorSurroundingLines`, backed by the existing horizontal reveal-padding machinery in `ViewLines`; preserve the distinct semantics of `editor.scrollBeyondLastColumn`.
