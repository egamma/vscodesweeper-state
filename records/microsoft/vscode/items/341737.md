[https://github.com/microsoft/vscode/issues/341737](https://github.com/microsoft/vscode/issues/341737)

## Summary

Keep open for the newly started Backlog Candidates community-review period. The existing "default" value partially addresses the request, but does not consistently separate all external opens from dialog opens across platforms.
