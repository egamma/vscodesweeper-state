# Issue #335652 — Choose Folder: Make parent folder of current folder the starting point

[https://github.com/microsoft/vscode/issues/335652](https://github.com/microsoft/vscode/issues/335652)

## Summary

Keep open: the Agents Window folder browser still does not explicitly start from the selected folder's parent. Existing dialog defaults only partially cover the request, and no verified fix or eligible canonical was found.

## Change summary

Start the Agents Window's Choose Folder dialog at the parent of the currently selected folder to make sibling workspaces easier to select.

## Best solution

Make local folder browsing in SessionWorkspacePicker use the current selection's parent as its starting location, retaining existing fallback behavior when no suitable local selection exists. Keep this separate from expanding the workspace picker's search scope.
