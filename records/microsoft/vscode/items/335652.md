# Issue #335652 — Choose Folder: Make parent folder of current folder the starting point

[https://github.com/microsoft/vscode/issues/335652](https://github.com/microsoft/vscode/issues/335652)

## Summary

Real, unaddressed request: the Agents Window folder pickers (e.g. `NewSessionPickFolderQuickPickAction` in `newSessionFolderQuickPickAction.ts`, `_browseForLocalFolder` in `sessionWorkspacePicker.ts`) call `fileDialogService.showOpenDialog` with no `defaultUri`, so the dialog falls back to the home folder as reported. It also carries the milestone `1.140.0` and is filed by a VS Code collaborator, both of which independently block a close here.

## Change summary

Make the 'Choose Folder' dialog in the Agents Window start from the parent of the current folder instead of the home folder.

## Best solution

Have the relevant `showOpenDialog` call sites in `src/vs/sessions/contrib/chat/browser/` pass a `defaultUri` derived from the parent of the currently active/most-recent workspace folder; a maintainer should confirm which 'current folder' reference to use (active window vs. most-recently-used) before implementing across the several call sites.
