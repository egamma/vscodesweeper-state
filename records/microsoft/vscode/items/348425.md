# Issue #348425 — worktree creation times out in agent window

[https://github.com/microsoft/vscode/issues/348425](https://github.com/microsoft/vscode/issues/348425)

## Summary

Keep open: the available checkout retains an unconditional three-minute worktree creation deadline, matching the reported failure during checkout progress. The checkout predates the affected build; the supplied Windows scenario and diagnostic suffice to retest without requesting basic reproduction details.

## Change summary

Large repositories cannot start worktree-isolated agent sessions when checkout exceeds three minutes.

## Best solution

Allow slow, progressing worktree creation to finish while retaining bounded handling of stalled operations and explicit isolation failures. Reproduce the large-repository case and settle the timeout behavior in the Agent Host Git service.
