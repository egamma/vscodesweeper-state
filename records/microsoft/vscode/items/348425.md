# Issue #348425 — worktree creation times out in agent window

[https://github.com/microsoft/vscode/issues/348425](https://github.com/microsoft/vscode/issues/348425)

## Summary

Current source still imposes the exact three-minute deadline reported, killing worktree checkout even while files are being populated. Keep open to address large-repository creation failures; the timeout policy needs a maintainer decision.

## Change summary

Creating an isolated Agents Window session fails when a large repository takes longer than 180 seconds to check out.

## Best solution

Allow legitimately slow worktree creation to finish while retaining protection against stalled Git operations and preserving isolation on failure. Decide whether this uses an adjustable deadline or progress-aware timeout behavior.
