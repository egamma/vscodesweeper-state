# Issue #226825 — SCM Graph - Support collapsing commits belonging to merge commits

[https://github.com/microsoft/vscode/issues/226825](https://github.com/microsoft/vscode/issues/226825)

## Summary

Keep open: the graph still lacks collapsible groups of commits introduced by a merge. Existing expansion controls show changed files, and the related requests do not establish a canonical duplicate.

## Change summary

Allow commits introduced by a merge to be collapsed and expanded inline in the Source Control Graph.

## Best solution

Provide an optional, reversible merge-history folding interaction in the SCM graph without conflating it with changed-file expansion. Whether groups start collapsed remains a product decision; preserve access to individual commits and accurate graph relationships.
