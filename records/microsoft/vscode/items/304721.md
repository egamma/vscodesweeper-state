# Issue #304721 — Support contributing agent skill folders with supporting files from extensions

[https://github.com/microsoft/vscode/issues/304721](https://github.com/microsoft/vscode/issues/304721)

## Summary

The core functionality already works — supporting files alongside SKILL.md are resolved when referenced via markdown links — but the team consensus (aeschli, sevoku, garrytrinder) is that docs should be clarified and a sample added to vscode-extension-samples. Keeping open as a documentation/polish item.

## Change summary

Extension authors want to contribute a skill folder (SKILL.md + supporting files) via the `chatSkills` contribution point, but the docs only mention pointing to a single file.

## Best solution

Update the VS Code docs and the `chatSkills` path description (line 58 of `src/vs/workbench/contrib/chat/common/promptSyntax/chatPromptFilesContribution.ts`) to clarify that supporting files relative to SKILL.md are automatically available when markdown-linked from SKILL.md. Add a multi-file skill sample to `microsoft/vscode-extension-samples` as garrytrinder suggested.
