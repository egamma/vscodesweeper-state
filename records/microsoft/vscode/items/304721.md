# Issue #304721 — Support contributing agent skill folders with supporting files from extensions

[https://github.com/microsoft/vscode/issues/304721](https://github.com/microsoft/vscode/issues/304721)

## Summary

The requested multi-file skill behavior already works when supporting files are stored beside and linked from `SKILL.md`, but maintainers agreed that this implicit behavior needs clearer documentation and likely a sample. Because this is a team-authored request with an agreed documentation gap and no cited implementing commit, it should remain open.

## Change summary

Document how extensions can package and reference supporting files alongside a contributed agent skill, potentially with an extension sample.

## Best solution

Clarify the Agent Skills documentation that a `chatSkills` path identifies `SKILL.md` while relative Markdown links can reach packaged sibling resources, and add a minimal multi-file skill example to microsoft/vscode-extension-samples.
