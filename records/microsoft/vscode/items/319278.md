# Issue #319278 — Chat: Custom session titles are lost after extension update / index rebuild

[https://github.com/microsoft/vscode/issues/319278](https://github.com/microsoft/vscode/issues/319278)

## Summary

Thanks for the detailed report. The core code path is plausible but I could not confirm the failure from source, so it stays open. The checkout shows a rename on a session that is not loaded in memory updates only the index, not the .jsonl file. The report's mention of the extension updating or rebuilding the index is unexplained.

## Change summary

Renaming a chat session updates the stored index but reportedly not the session's .jsonl customTitle, so titles revert to the default after an index rebuild.

## Best solution

Make the rename path persist customTitle to the session file even when the session model is not loaded, or make the index rebuild preserve existing custom titles. Then confirm what actually triggers an index rebuild.
