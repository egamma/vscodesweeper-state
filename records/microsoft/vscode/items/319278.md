Its discussion covers renames reverting and nonpersistent titles, not merely the availability of a rename command. https://github.com/microsoft/vscode/issues/283514#issuecomment-3722506706 identifies renaming a disposed model and updating only the store; https://github.com/microsoft/vscode/issues/283514#issuecomment-4341676610 reports nonpersistent renames.
- **Current source confirms the persistence gap:** The local Rename action in src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsActions.ts calls ChatService.setChatSessionTitle. In src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts:424-436, that method changes customTitle only when a live model exists, then updates the store and invokes saveState. saveState:360-382 writes transcripts only for live models. ChatSessionStore.setSessionTitle in src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts:510-518 changes only index.entries[sessionId].title. Consequently, renaming an unloaded historical session does not update its transcript.
- **Transcript restoration and append-log semantics:** ChatSessionStore.readSessionFromLocation in src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts:653-708 restores serialized data from the transcript without reconciling its customTitle with the index. src/vs/workbench/contrib/chat/common/model/chatSessionOperationLog.ts:200-203 includes customTitle in the mutation-log schema, so a durable rename may appear in an appended operation rather than the first line. First-line absence alone is not proof of loss, but the unloaded-session path independently confirms a missing write. No execution or extension-update-triggered index rebuild was attempted.
- **Existing implementation candidate:** https://github.com/microsoft/vscode/pull/323323 is OPEN and unmerged. It targets the canonical issue and explicitly diagnoses setSessionTitle updating the index without updating the session file. Its proposed index-preference behavior should not be assumed to protect titles when the index itself is rebuilt.
- **Distinct related report:** https://github.com/microsoft/vscode/issues/340488 is open but reports entire conversations overwritten with requests: [] while customTitle remains intact.
