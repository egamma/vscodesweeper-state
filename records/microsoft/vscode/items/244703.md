# Issue #244703 — Prevent CustomEditor from Opening When a File is Opened from Search or GitLens

[https://github.com/microsoft/vscode/issues/244703](https://github.com/microsoft/vscode/issues/244703)

## Summary

Valid feature request for adding `when` clause support to `customEditors` contribution point, allowing extensions to conditionally activate custom editors based on context. No such capability exists on current main; the open PR #244749 has not been merged. Keeping open for maintainer review.

## Change summary

Add `when` clause support to the `customEditors` extension point so extensions can conditionally control when their custom editor is activated based on context (e.g., not when opening from search or GitLens).

## Best solution

Evaluate adding a `when` clause to the `customEditors` contribution schema in `src/vs/workbench/contrib/customEditor/common/extensionPoint.ts` and wiring it through the editor resolution logic. The open PR https://github.com/microsoft/vscode/pull/244749 attempts this but needs maintainer review from the custom-editors area owner (@mjbvz). The existing `priority` field partially addresses editor selection but lacks contextual awareness.
