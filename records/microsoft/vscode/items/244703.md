# Issue #244703 — Prevent CustomEditor from Opening When a File is Opened from Search or GitLens

[https://github.com/microsoft/vscode/issues/244703](https://github.com/microsoft/vscode/issues/244703)

## Summary

Keep open: custom editor contributions still lack contextual eligibility, and existing priority controls do not selectively bypass a default editor for Search or GitLens. The linked implementation PR remains open and should receive an API/design review rather than starting a competing implementation.

## Change summary

Allow extensions to prevent automatic custom editor selection for particular opening contexts while retaining it elsewhere.

## Best solution

Review https://github.com/microsoft/vscode/pull/244749 and settle whether contextual contribution conditions reliably express the originating navigation action. Deliver a supported conditional-selection contract without requiring extensions to inspect transient global focus state.
