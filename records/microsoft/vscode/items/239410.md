# Issue #239410 — `diffView` throws `Illegal value for lineNumber`. Consistent repro included.

[https://github.com/microsoft/vscode/issues/239410](https://github.com/microsoft/vscode/issues/239410)

## Summary

Still reproduces on current main: `normalizeRangeMapping` in diffEditorViewModel.ts calls `getLineMaxColumn()` with potentially stale/out-of-bounds line numbers without validation, causing 'Illegal value for lineNumber'. A fix was attempted on a side branch (69fe56d6cbf) but never merged to main.

## Change summary

During diffView operations, `TextModel.getLineMaxColumn()` throws `BugIndicatingError('Illegal value for lineNumber')` when diff results contain stale line numbers.

## Best solution

Guard `normalizeRangeMapping` in `src/vs/editor/browser/widget/diffEditor/diffEditorViewModel.ts` to validate that `originalRange.endLineNumber` and `modifiedRange.endLineNumber` are within model bounds before calling `getLineMaxColumn()`. An unmerged fix exists at commit 69fe56d6cbf on a side branch — review and land it (or a refined version) on main.
