# Issue #168675 — Debugging untitled file in IW shows unbound breakpoints

[https://github.com/microsoft/vscode/issues/168675](https://github.com/microsoft/vscode/issues/168675)

## Summary

Still reproduces on main: the `isDirty` guard in `debugModel.ts` unconditionally marks breakpoints as unverified for dirty/untitled files, with no mechanism for adapters to opt out. The issue remains valid and unfixed.

## Change summary

Breakpoints in untitled/dirty files in the Interactive Window appear unverified because `Breakpoint.verified` always returns false when the file is dirty.

## Best solution

Add a capability flag (in `DebugSessionOptions` or adapter `package.json` contribution) letting debug adapters signal they support debugging dirty/unsaved files, then skip the `isDirty` guard in `Breakpoint.verified` when that flag is set. The fix lives in `src/vs/workbench/contrib/debug/common/debugModel.ts` (the `get verified()` and `get message()` accessors).
