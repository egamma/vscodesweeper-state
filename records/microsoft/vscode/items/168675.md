# Issue #168675 — Debugging untitled file in IW shows unbound breakpoints

[https://github.com/microsoft/vscode/issues/168675](https://github.com/microsoft/vscode/issues/168675)

## Summary

The breakpoint model still overrides adapter verification whenever the source is dirty, including untitled files. Keep this accepted, team-authored issue open; the adapter opt-in contract remains unresolved.

## Change summary

Breakpoints in untitled Python files debugged through the Interactive Window appear unbound despite the adapter supporting unsaved source.

## Best solution

Allow sessions that explicitly support debugging unsaved source to display adapter-verified breakpoints correctly, while preserving dirty-source safeguards for other debuggers. Decide the opt-in contract before implementation.
