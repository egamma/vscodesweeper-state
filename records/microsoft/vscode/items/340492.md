# Issue #340492 — Pinned files

[https://github.com/microsoft/vscode/issues/340492](https://github.com/microsoft/vscode/issues/340492)

## Summary

Thanks for the report. When a file is opened from the OS on a fresh launch, VS Code opens that file and skips restoring the previous session by default. The `window.restoreWindows: preserve` setting keeps the previous session alongside it.

## Change summary

Pinned tabs from the previous session are not restored when VS Code is launched by opening a file from the OS file explorer.

## Best solution

Keep the shipped behavior and point the reporter to `window.restoreWindows: "preserve"`, which restores the last session's windows even when launched with a file.

  > Thanks for the report. When VS Code is launched by opening a file from the OS (for example Explorer > Open with Code), it opens that file and by default does not restore the previous session, which is why your pinned tabs are not reopened. If you want them restored in that case, set `window.restoreWindows` to `preserve`, which restores the previous windows alongside the file you opened. If you would like different default behavior, please open a feature request describing it.
