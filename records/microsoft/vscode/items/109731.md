# Issue #109731 — Suggest detail does not shrink to fit content when resized

[https://github.com/microsoft/vscode/issues/109731](https://github.com/microsoft/vscode/issues/109731)

## Summary

Still present on main: after a user resize, the suggest detail pane uses the locked-in `_userSize` for the rest of the session, so it won't shrink to fit smaller content until suggest is re-triggered. Team-authored and under-discussion — keeping open.

## Change summary

The suggest detail view does not shrink to fit shorter content after the user manually resizes it larger; it stays at the enlarged size until suggest is re-triggered.

## Best solution

In `SuggestDetailsOverlay._placeAtAnchor`, treat `_userSize` as a maximum rather than a fixed size: use `Math.min(_userSize.height, widget.size.height)` for the height dimension so the detail pane can shrink to fit shorter content while still respecting the user's width preference. The fix is localized to `suggestWidgetDetails.ts`.
