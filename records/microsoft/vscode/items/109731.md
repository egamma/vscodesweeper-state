# Issue #109731 — Suggest detail does not shrink to fit content when resized

[https://github.com/microsoft/vscode/issues/109731](https://github.com/microsoft/vscode/issues/109731)

## Summary

Keep open for the existing sizing discussion: current source still preserves the details panel's height during horizontal resizing rather than fitting it to reflowed content. This team-authored issue has neither a verified fixing commit nor an older canonical reporting the same symptom.

## Change summary

Recalculate the suggest details panel's content-fitting height when its width is manually resized, avoiding unused vertical space.
