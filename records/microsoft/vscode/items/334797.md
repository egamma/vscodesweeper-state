# Issue #334797 — Opening PR in a new tab in Agents window results in overly wide PR view

[https://github.com/microsoft/vscode/issues/334797](https://github.com/microsoft/vscode/issues/334797)

## Summary

Fresh, well-evidenced visual bug in the Agents Window: opening a PR/issue link from a PR description in a new tab renders the overview webview too wide for its pane, with a horizontal scrollbar and clipped title text. Worth routing to the sessions/Agents Window layout code, but too new (0 days, no maintainer follow-up) to attach a close verdict.

## Change summary

Clicking a PR link inside a PR description in the Agents Window opens a new tab whose PR/issue overview content renders overly wide (overflowing/scrolling horizontally) instead of fitting the pane.

## Best solution

Investigate the width/resize handling for PullRequestOverview and IssueOverview webview tabs opened via the single-pane layout in src/vs/sessions/contrib/layout/browser/singlePane/ (e.g. singlePaneSharedHelpers.ts's isEditorWithoutDockedDetails full-presentation path, and the New/Existing session strategies that react to it) — the new tab likely isn't triggering a proper webview layout/resize pass when it becomes active, leaving stale/incorrect width.
