# Issue #343322 — Word breaks in streamed chat responses: empty thinking markers split markdown parts

[https://github.com/microsoft/vscode/issues/343322](https://github.com/microsoft/vscode/issues/343322)

## Summary

Keep open: current source still allows an empty thinking marker to split otherwise mergeable markdown chunks. The changing-ID reasoning case has partial coverage on main, but that does not resolve the original text-fragmentation report.

## Change summary

Preserve continuous answer text and reasoning when local/BYOK streams interleave empty thinking markers or emit per-delta reasoning IDs.

## Best solution

Ensure empty reasoning markers do not introduce paragraph boundaries in live or restored answers, while preserving meaningful reasoning/tool boundaries and markdown permissions. Retain the existing handling of untimed reasoning chunks with changing IDs rather than removing reasoning-ID distinctions indiscriminately.
