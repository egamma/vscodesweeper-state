# Issue #332919 — Agents Window: Better skill set configuration for a workspace

[https://github.com/microsoft/vscode/issues/332919](https://github.com/microsoft/vscode/issues/332919)

## Summary

New, plausible feature request: the Agents Window doesn't currently surface workspace-configured skill locations (e.g. `chat.agentSkillsLocations`) the way normal chat does, so users can't build a per-workspace skill set there. No related issue or maintainer discussion yet; routing to the customizations area for triage.

## Change summary

Allow configuring which skills (globally/project/framework-scoped) are available to the Agents Window per workspace, matching the configurability already available via chat.agentFilesLocations/chat.agentSkillsLocations outside the Agents Window.

## Best solution

Have the Agents Window's customization/skill discovery path (src/vs/sessions/contrib/providers/agentHost/browser/agentHostSkillButtons.ts and related aiCustomizationWorkspaceService/promptsService code) honor `chat.agentSkillsLocations` the same way normal chat does, and surface configured skill folders in the '/' picker and the Agent Customization view.
