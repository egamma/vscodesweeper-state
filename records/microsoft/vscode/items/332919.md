# Issue #332919 — Agents Window: Better skill set configuration for a workspace

[https://github.com/microsoft/vscode/issues/332919](https://github.com/microsoft/vscode/issues/332919)

## Summary

The exact capability requested — configurable, workspace-scoped skill folders for the Agents Window — already ships as `chat.agentSkillsLocations`, which supports relative (workspace), `~/` (global), and absolute (narrowly-scoped) paths and is already wired into the Copilot CLI/Agents Window skill discovery.

## Change summary

Allow customizing which skill folders/skills are exposed to the agent per workspace (global vs. project vs. narrowly-scoped skill sets), since `chat.agentFilesLocations` folders aren't picked up as skills in the Agents Window.

## Best solution

Point the reporter at `chat.agentSkillsLocations` (not `chat.agentFilesLocations`, which is for agent/mode definition files) — it accepts workspace-relative paths, `~/`-prefixed global paths, and absolute paths, matching the global/project/narrow split they described, and is already consumed by `CopilotCLISkills.getSkillsLocations()` for the Agents Window.
