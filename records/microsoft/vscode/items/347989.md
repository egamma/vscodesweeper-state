Keep open: current source prevents automatic tours from starting over an existing dialog, but does not dismiss an active spotlight when a dialog opens. Its callout remains above the folder trust dialog, matching the reported obstruction.

Prevent the first-run workspace tour tip from obscuring a folder trust dialog opened during the tour.
