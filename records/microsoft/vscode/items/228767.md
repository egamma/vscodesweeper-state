# Issue #228767 — Switching between panes after changing clipboard with globalFindClipboard=true causes search field to be focused erroneously

[https://github.com/microsoft/vscode/issues/228767](https://github.com/microsoft/vscode/issues/228767)

## Summary

The focus-stealing path remains on current main: synchronizing the macOS find clipboard selects and focuses the find input after the user focuses an editor pane. Keep this open for a targeted editor-find fix.

## Change summary

With globalFindClipboard enabled, clicking another editor pane after the shared find text changes focuses that pane's find input instead of the editor.

## Best solution

Update the global find clipboard synchronization in src/vs/editor/contrib/find/browser/findWidget.ts so it can refresh the search string without selecting or focusing the find input, preserving the user's editor focus.
