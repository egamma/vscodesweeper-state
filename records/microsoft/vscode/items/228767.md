[https://github.com/microsoft/vscode/issues/228767](https://github.com/microsoft/vscode/issues/228767)

## Summary

The current source still selects the Find input when pane focus triggers synchronization of a different global find clipboard term. Keep this open while the existing fix candidate, https://github.com/microsoft/vscode/pull/332583, is reviewed and landed.

## Change summary

Switching editor panes with editor.find.globalFindClipboard enabled can redirect keyboard focus from the editor into its Find input.

## Best solution

Review https://github.com/microsoft/vscode/pull/332583 against the supplied two-pane reproduction, preserving clipboard synchronization without stealing editor focus and retaining deliberate Find-input focus behavior.
