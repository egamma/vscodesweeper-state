# Issue #173000 — GitHub - Add support for `.issuetracker` file in Source Control feature

[https://github.com/microsoft/vscode/issues/173000](https://github.com/microsoft/vscode/issues/173000)

## Summary

Keep open: built-in GitHub issue linking covers part of the request, but repository-defined mappings for Jira, GitLab, and other trackers remain unsupported. No older canonical issue owning that capability was identified, and the Backlog milestone records accepted, unscheduled work.

## Change summary

Support repository-local `.issuetracker` regex-to-URL mappings so issue references in SCM commit messages become clickable links.

## Best solution

Provide configurable tracker links through the Git history message-link provider mechanism, potentially via an extension that reads `.issuetracker`. Preserve existing GitHub linking; the maintainer should settle ownership and configuration-format support before implementation.
