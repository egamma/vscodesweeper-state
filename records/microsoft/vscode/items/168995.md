# Issue #168995 — Merge Editor: Option To Show All Diffs

[https://github.com/microsoft/vscode/issues/168995](https://github.com/microsoft/vscode/issues/168995)

## Summary

Keep open: the existing Show Non-Conflicting Changes option exposes change blocks but does not enable all detailed diff highlights. This team-authored Backlog request still identifies a meaningful gap, and no qualifying fix or canonical duplicate was established.

## Change summary

Provide an option to display all merge-editor diffs, including automatically handled non-conflicting changes such as the supplied vscode property update.

## Best solution

Offer a merge-editor view that exposes detailed differences for non-conflicting changes as well as conflicts, while preserving the focused default experience. The area owner should decide whether this extends Show Non-Conflicting Changes or warrants a separate display mode.
