# Issue #98603 — Custom editors cannot be opened when a single-folder workspace has Been Extended To A Multi-Folder Workspace

[https://github.com/microsoft/vscode/issues/98603](https://github.com/microsoft/vscode/issues/98603)

## Summary

Still a valid open bug — no fix commit references this issue, and the underlying problem (webviews detaching from extensions when the extension host restarts on workspace folder change) has not been broadly addressed. The `onWillStop` veto in customTextEditorModel.ts only prevents the restart for text-based custom editors, not webview-based ones opened after the restart.

## Change summary

Custom editors (webview-based) crash or become detached when a single-folder workspace is extended to a multi-folder workspace because the extension host restarts.

## Best solution

Ensure webview-backed custom editors survive extension host restarts triggered by workspace folder changes, or that newly opened custom editors in added folders work correctly post-restart. The fix likely involves `src/vs/workbench/contrib/webviewPanel/` and the webview lifecycle management during extension host transitions.
