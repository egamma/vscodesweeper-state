# Issue #98603 — Custom editors cannot be opened when a single-folder workspace has Been Extended To A Multi-Folder Workspace

[https://github.com/microsoft/vscode/issues/98603](https://github.com/microsoft/vscode/issues/98603)

## Summary

Keep open: the supplied sample and steps suffice to retest, but current restart-confirmation handling differs from the original report and the failure opening a new custom editor remains unverified. No issue-referencing fix or eligible older duplicate was established for this team-authored report.

## Change summary

Opening a custom editor in a newly added workspace folder fails after converting a single-folder window into a multi-root workspace.

## Best solution

Ensure newly opened custom editors resolve against the active extension host after workspace conversion. Diagnose that failure separately from recovery of already-open webviews, preserving unsaved content rather than indiscriminately closing panels.
