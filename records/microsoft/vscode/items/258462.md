# Issue #258462 — Hover explaining `Optimizing tool selection...`

## Summary

The explanatory gap remains: current code reports tool-selection optimization and its completion, but does not explain what it means. Keep this team-authored polish request open; the related reports concern different presentation problems.

## Change summary

## Best solution
