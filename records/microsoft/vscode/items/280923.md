# Issue #280923 — Find Next / Find Next Selection not working in notebooks

[https://github.com/microsoft/vscode/issues/280923](https://github.com/microsoft/vscode/issues/280923)

## Summary

Still reproduces on main: `NextSelectionMatchFindAction` (Ctrl+Shift+F3) has no notebook-level implementation — only `NextMatchFindAction` and `PreviousMatchFindAction` received notebook overrides via `addImplementation` in notebookFind.ts. The selection-match variants are `EditorAction` subclasses that only operate on a single cell's `CommonFindController`.

## Change summary

"Find Next Selection" (Ctrl+Shift+F3) and "Find Previous Selection" do nothing in notebook editors because no notebook-level find implementation exists for these commands.

## Best solution

Add notebook-level implementations for `NextSelectionMatchFindAction` and `PreviousSelectionMatchFindAction` in `src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFind.ts`, following the same pattern used for `NextMatchFindAction`/`PreviousMatchFindAction` — seed the notebook find widget's search string from the current cell editor selection, then navigate. The F3 intermittent-stop issue the reporter mentions may be a separate timing concern with the widget-focused keybinding path.
