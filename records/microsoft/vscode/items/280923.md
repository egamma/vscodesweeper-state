[https://github.com/microsoft/vscode/issues/280923](https://github.com/microsoft/vscode/issues/280923)

## Summary

Keep open: Find Next Selection still exits without doing anything because notebook cell editors exclude the find controller that this command requires. Ordinary F3 navigation has notebook-specific handling, but that does not cover the selection command or establish that the reported intermittent navigation failure is resolved.

## Change summary

Make selection-based find navigation work in notebook code cells and investigate ordinary next/previous navigation stopping.
