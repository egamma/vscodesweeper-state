# Issue #344028 — Webviews: Ctrl+C / context-menu Copy of selected text copies nothing when the webview's last focused element is editable (regression in 1.143.0)

[https://github.com/microsoft/vscode/issues/344028](https://github.com/microsoft/vscode/issues/344028)

## Summary

This is the same webview copy regression already reported in the open canonical issue: copying selected response text unexpectedly focuses the input and copies nothing. Consolidate there, preserving this report's Linux reproduction and precise focus-restoration diagnosis.

## Change summary

Copying selected non-editable webview text fails when native command dispatch restores focus to a previously focused editable element.

## Best solution

Resolve the shared regression under https://github.com/microsoft/vscode/issues/343489 so copying preserves the current document selection without breaking editable-target restoration for other native commands.
