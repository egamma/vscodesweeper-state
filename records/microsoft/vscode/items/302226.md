# Issue #302226 — Chat agent debug log view: Import should have a nicer title

[https://github.com/microsoft/vscode/issues/302226](https://github.com/microsoft/vscode/issues/302226)

## Summary

Still unfixed on main: the logs view breadcrumb (chatDebugLogsView.ts line 325) uses only chatService.getSessionTitle() without falling back to the imported session title, so imported logs show a cryptic resource identifier. The home view handles this correctly but the logs view doesn't.

## Change summary

When importing a debug log file, the breadcrumb in the logs view should show the original chat title instead of a cryptic resource URI.

## Best solution

In chatDebugLogsView.ts updateBreadcrumb(), add a fallback to chatDebugService.getImportedSessionTitle() (and getHistoricalSessionTitle()) similar to the title resolution logic already in chatDebugHomeView.ts lines 167–189.
