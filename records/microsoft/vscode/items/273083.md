# Issue #273083 — Chat todos: revisit icons used for tasks and in progress

[https://github.com/microsoft/vscode/issues/273083](https://github.com/microsoft/vscode/issues/273083)

## Summary

Keep open: current source still uses a static record icon for in-progress todos, and the proposed spinner PR was closed without merging. Maintainers still need to settle collapsed-header visibility and how progress indicators behave when a request stops.

## Change summary

Refine todo status glyphs and use a familiar progress indicator without implying activity after a request ends.

## Best solution

Finish the todo widget's status-icon design with appropriately weighted pending indicators and recognizable active-progress feedback. Settle the collapsed-header and interrupted-request presentation before implementing, without adding a new model-facing todo status.

  > Todo indicators should communicate pending, active, and completed work using familiar visual conventions, with pending glyphs subordinate to task text. A progress animation must not imply active execution after the request stops or finishes, even if stored todos remain in-progress. Expanded rows and the collapsed summary must follow the agreed visibility and inactive-state presentation. Preserve accessible task-status labels and the existing model-facing status contract.
