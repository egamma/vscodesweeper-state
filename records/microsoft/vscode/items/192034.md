# Issue #192034 — toggleFindWholeWord command does not work for Jupyter Notebooks

[https://github.com/microsoft/vscode/issues/192034](https://github.com/microsoft/vscode/issues/192034)

## Summary

Valid feature request — the `toggleFindWholeWord` command is registered as an `EditorCommand` scoped to `EditorContextKeys.focus`, so it only works inside a text editor cell, not at the notebook level. The notebook find widget has whole-word support in its state but no command bridges the editor toggle to it when a notebook is active.

## Change summary

The `toggleFindWholeWord` keyboard shortcut does not toggle whole-word matching in the notebook find widget.

## Best solution

Register notebook-level actions (or `addImplementation` overrides like `StartFindAction` already has) for `toggleFindWholeWord`, `toggleFindCaseSensitive`, and `toggleFindRegex` in `notebookFind.ts` that delegate to the `NotebookFindContrib`'s find state, following the same pattern used for `NextMatchFindAction`/`PreviousMatchFindAction`.

## Evidence

- **command registration:** src/vs/editor/contrib/find/browser/findController.ts:1097-1109 registers `toggleFindWholeWord` as a `FindCommand` (an `EditorCommand`) with `kbExpr: EditorContextKeys.focus` — only fires when an editor has focus.
- **no notebook bridge:** src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFind.ts hooks `StartFindAction`, `StartFindReplaceAction`, `NextMatchFindAction`, and `PreviousMatchFindAction` via `addImplementation`, but no such hook exists for the toggle commands (`ToggleWholeWordCommand`, `ToggleCaseSensitiveCommand`, `ToggleRegexCommand`).
- **notebook widget has the state:** src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFindReplaceWidget.ts:456 shows `_findInput.setWholeWords(!!this._state.wholeWord)` — the widget already supports toggling whole-word internally, just not from the keyboard command.
