# Issue #219122 — TreeError [FileExplorer] Data tree node not found: ExplorerItem: base

[https://github.com/microsoft/vscode/issues/219122](https://github.com/microsoft/vscode/issues/219122)

## Summary

The cut-state update remains unsafe on current main: replacing a cut item rerenders the previous ExplorerItem without checking whether that item is still represented in the tree, producing the reported TreeError. This is a bounded File Explorer bug and should remain open.

## Change summary

Cutting a nested Explorer item after cutting its parent can show a "Data tree node not found" error.

## Best solution

Make File Explorer cut-state rendering tolerate previous and current cut items that are no longer represented by a tree node, while preserving clipboard contents and cut decorations for items that remain visible.
