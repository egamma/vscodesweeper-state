## Summary

Team-authored feature request to allow starting cloud agent sessions from local workspace folders. A team member confirmed this is the intended tracking issue for that capability, with a separate issue (https://github.com/microsoft/vscode/issues/306455) covering the interim picker-hiding UX. ## Change summary

Allow users to create Copilot cloud sessions when selecting a local folder backed by a GitHub repository, rather than restricting cloud sessions to GitHub repo selection only.
