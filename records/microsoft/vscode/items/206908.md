# Issue #206908 — Programmatically setting focus causes custom hover to show

[https://github.com/microsoft/vscode/issues/206908](https://github.com/microsoft/vscode/issues/206908)

## Summary

The unwanted custom hover is a confirmed workbench interaction bug: restoring focus after a programmatic UI transition is interpreted like deliberate keyboard focus and immediately opens the hover. The Backlog milestone does not bar triage, and the discussion leaves a real accessibility-sensitive behavior decision unresolved.

## Change summary

Prevent programmatic focus restoration from automatically showing a custom hover while retaining keyboard-accessible hover behavior.

## Best solution

Define a consistent workbench-hover policy that distinguishes programmatic focus restoration from deliberate keyboard navigation, while preserving an accessible way to inspect hover content from the keyboard.
