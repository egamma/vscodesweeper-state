## Summary

Still reproduces on main: the `intersectDiffWithRange` function in `staging.ts` keeps the full original line range when original and modified sides have different line counts, causing partial-hunk staging to include more content than selected. No fix has landed.

## Change summary

## Best solution

Fix the else branch of `intersectDiffWithRange` in `extensions/git/src/staging.ts` (lines 134–141) to properly narrow the original range when the hunk has unequal original/modified line counts, rather than preserving the full original range. The `applyLineChanges` function may also need adjustment to handle the narrowed original range correctly.
