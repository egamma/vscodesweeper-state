# Issue #66801 — Input variables only work with one configuration in a compound launch config

[https://github.com/microsoft/vscode/issues/66801](https://github.com/microsoft/vscode/issues/66801)

## Summary

The reported compound-launch failure was fixed and verified through the later same-symptom report https://github.com/microsoft/vscode/issues/141514. Current main serializes interactive variable resolution so one launch configuration's prompt no longer dismisses another and prevents the remaining sessions from starting.

## Change summary

Input-variable prompts from concurrent configurations caused all but one configuration in a compound debug launch to be canceled.

## Best solution

Keep the shipped input-resolution queues introduced by commits 0f2239fc7c2703312928b6f7ff9ce6642d2e3354 and 0dddb856fd89d55b1dadc97ab49aca800f3eb8ff; no further change is needed for the reported failure mode.
