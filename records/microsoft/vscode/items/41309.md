# Issue #41309 — Add an optional configurable toolbar below the menu

[https://github.com/microsoft/vscode/issues/41309](https://github.com/microsoft/vscode/issues/41309)

## Summary

Keep this canonical Backlog request open: 411 community upvotes demonstrate sustained demand, and current title-bar controls do not provide an arbitrary user-configurable command toolbar.

## Change summary

Add an optional toolbar where users can place frequently used VS Code and extension commands.

## Best solution

Design an opt-in command strip using the existing workbench menu/action infrastructure, with user-managed commands and an extension contribution point, while preserving VS Code's lean default layout. The layout area should determine whether this belongs below the menu or within the customizable title bar.

## Vision fit

- **Fit:** unclear
- **Reason:** An optional toolbar improves command discoverability but introduces another configurable UI surface, creating tension with the lightweight and uniform-UI guardrails.
- **Evidence:** Public values emphasize both a lightweight editor and simple, uniform UI; the durable workbench UX theme also supports improving first-run discoverability.
