# Issue #41309 — Add an optional configurable toolbar below the menu

[https://github.com/microsoft/vscode/issues/41309](https://github.com/microsoft/vscode/issues/41309)

## Summary

Keep this accepted Backlog request open: existing title-bar actions provide partial coverage, but not an optional toolbar below the menu populated with user-selected commands. The 412 upvotes demonstrate substantial demand, and the verified related issues do not supersede this request.

## Change summary

Provide an optional, user-configurable toolbar below the menu for invoking chosen commands without remembering keyboard shortcuts.

## Best solution

Agree on a lightweight, opt-in command toolbar that supports built-in and extension commands while preserving the default editor layout. Define its placement and customization persistence with the workbench layout owner before implementation.
