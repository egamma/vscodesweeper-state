[https://github.com/microsoft/vscode/issues/297651](https://github.com/microsoft/vscode/issues/297651)

## Summary

A real gap remains on current main: Settings Sync handles MCP servers and prompts, but Chat Tools enablement is machine-local and has no selectable sync category.

## Change summary

Add Copilot Chat tool enablement as a separately configurable Settings Sync resource.
