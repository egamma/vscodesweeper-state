# Issue #126913 — Workspace Trust - Investigate what it means to support the notion of trust for virtual workspaces

[https://github.com/microsoft/vscode/issues/126913](https://github.com/microsoft/vscode/issues/126913)

## Summary

Keep this team-authored exploration open: general virtual-workspace trust remains unresolved, and exploration issues are protected from closure. The existing workspace-trust routing is appropriate.

## Change summary

Investigate trust participation and reusable URI aliases for extension-provided virtual workspaces, including startup activation and virtual-document boundaries.

## Best solution

Workspace Trust and extension API owners should settle how virtual workspace providers participate in trust calculations without unsafe early activation or mismatched provider ownership. Preserve workspace folders as the primary scope, with loose virtual documents considered separately, as established in the discussion.
