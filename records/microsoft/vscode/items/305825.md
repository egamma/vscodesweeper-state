# Issue #305825 — VC automatically switches windows-focus when a running task in a different window prompts the user.

[https://github.com/microsoft/vscode/issues/305825](https://github.com/microsoft/vscode/issues/305825)

## Summary

The background-chat focus theft was fixed after this report: question prompts now auto-focus only when focus is already inside that same chat widget. The fix is present on current main and was reported as shipped in VS Code 1.125.0.

## Change summary

A prompt appearing in another running Copilot Chat conversation could steal keyboard focus and redirect typing or an unintended answer to that conversation.

## Best solution

Keep the shipped focus guard from commit 3ef7eb46a8b5a830654d23b60b22dd1f686bc6c9, which preserves focus outside the chat receiving a new question.
