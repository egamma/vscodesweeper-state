# Issue #208199 — Focused search buttons border color update

[https://github.com/microsoft/vscode/issues/208199](https://github.com/microsoft/vscode/issues/208199)

## Summary

Still reproduces on main: the toggle buttons (Match Case, Match Whole Word, etc.) have no focus border style in non-HC themes — confirmed by reading toggle.css which has no :focus rule for .monaco-custom-toggle outside HC themes. A team member already confirmed this should be fixed.

## Change summary

Focused search toggle buttons (Match Case, Match Whole Word) have no visible focus indicator because their border-color on focus matches the background.

## Best solution

Add a :focus-visible rule for .monaco-custom-toggle in toggle.css that applies var(--vscode-focusBorder) as the border-color, so keyboard users can see which toggle button has focus in all themes.
