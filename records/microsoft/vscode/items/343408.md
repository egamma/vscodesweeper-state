# Issue #343408 — Mac on Device Support

[https://github.com/microsoft/vscode/issues/343408](https://github.com/microsoft/vscode/issues/343408)

## Summary

Keep open as a request to extend built-in on-device model support to Apple Silicon. Current source explicitly restricts this feature to NVIDIA GPUs, so sufficient unified memory or configuring llama-server does not satisfy the request today.

## Change summary

Support downloading and running built-in on-device models on capable Apple Silicon Macs.

## Best solution

Have the on-device model owners assess Apple Silicon support, including Metal runtime compatibility and unified-memory admission, and establish supported hardware and model requirements before implementation.
