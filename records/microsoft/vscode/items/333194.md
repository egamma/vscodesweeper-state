# Issue #333194 — Last update 1.135 broke AI chat in new window

[https://github.com/microsoft/vscode/issues/333194](https://github.com/microsoft/vscode/issues/333194)

## Summary

Confirmed on current main: opening chat in a new (auxiliary) window throws exactly the reported error, because ChatPetWidgetCoordinator.createDormantHost() uses dom.$('div') — which resolves the ambient global `document` — instead of explicitly using the main window's document, so it hits the auxiliary window's overridden (throwing) document.createElement.

## Change summary

Choosing 'New Chat Window' in the Copilot chat sidebar throws 'Not allowed to create elements in child window JavaScript context' and fails to open.

## Best solution

Fix ChatPetWidgetCoordinator.createDormantHost() in src/vs/workbench/contrib/chat/browser/widget/chatPetWidgetService.ts to build the parked-pet parent element via the main window's document explicitly (e.g. `mainWindow.document.createElement('div')`, imported from base/browser/window.js) instead of `dom.$('div')`, matching the pattern already used elsewhere in the chat code (e.g. chatWidget.test.ts's `mainWindow.document.createElement('div')`).
