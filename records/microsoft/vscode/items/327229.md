# Issue #327229 — Terminal fails to launch due to outdated libnode.so dependency on Linux

[https://github.com/microsoft/vscode/issues/327229](https://github.com/microsoft/vscode/issues/327229)

## Summary

This is a distro-packaging issue, not a VS Code core bug. Official builds bundle Electron (which includes Node.js/libnode), so they never depend on a system libnode.so. The reporter's Debian-packaged code-oss links against system Node.js, and when the distro updates that library, the native node-pty module breaks. The fix belongs in the distro package, not in this repo.

## Change summary

Integrated terminal fails to launch on a distro-packaged code-oss when the system libnode.so version changes.

## Best solution

This belongs with whoever packages code-oss for the reporter's Linux distribution — they need to rebuild node-pty against the updated system libnode, or bundle the correct version. VS Code's official builds and source builds already avoid this by shipping their own Electron/Node.js.
