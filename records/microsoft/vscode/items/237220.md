# Issue #237220 — Support data URI's in image preview, so it could be used from extensions

[https://github.com/microsoft/vscode/issues/237220](https://github.com/microsoft/vscode/issues/237220)

## Summary

Direct data-URI support remains missing from the built-in image preview. Keep this accepted request open while its existing implementation candidate, https://github.com/microsoft/vscode/pull/237222, is reviewed.

## Change summary

Allow extensions to preview in-memory images supplied as data URIs using the built-in image preview editor.
