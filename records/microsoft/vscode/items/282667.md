# Issue #282667 — Add an 'open in codespace' button to coding agent sessions

[https://github.com/microsoft/vscode/issues/282667](https://github.com/microsoft/vscode/issues/282667)

## Summary

Keep open: current cloud-session actions open the task in a browser or check out its pull request locally, but do not provide the requested checkout-free Codespace handoff. The existing area label is appropriate; the remaining work requires coordination with the Codespaces integration.

## Change summary

Add an Open in Codespace action to completed coding-agent sessions that uses the session's repository and ref without requiring a local checkout.

## Best solution

Provide a completed-session action that opens the coding agent's repository at its associated ref in a Codespace without depending on local Git state. Establish the supported Codespaces handoff contract before implementing the cloud-session integration.
