# Issue #337924 — incorrect language detection

[https://github.com/microsoft/vscode/issues/337924](https://github.com/microsoft/vscode/issues/337924)

## Summary

Copilot Chat's response language is not detected from the conversation text — it's driven by VS Code's configured display language (`vscode.env.language`), overridable via `chat.localeOverride`. The `ru` locale almost certainly reflects the user's VS Code display language setting, not a bug in language detection.

## Change summary

Copilot Chat replied in Russian during an all-Ukrainian conversation, and gave inconsistent explanations for why when asked.

## Best solution

As-designed: response locale comes from `chat.localeOverride` (default `auto`, which falls back to `vscode.env.language`), not from detecting the conversation's language. The user should check/change their VS Code display language (Command Palette → "Configure Display Language") or set `chat.localeOverride` explicitly (e.g. to `auto`/`en`) if they don't want responses to follow the display language.
