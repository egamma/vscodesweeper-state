# Issue #211635 — Mark cache directories with a CACHEDIR.TAG file to avoid backing up unnecessary data

[https://github.com/microsoft/vscode/issues/211635](https://github.com/microsoft/vscode/issues/211635)

## Summary

Keep this accepted, community-supported request open: the inspected cache-management paths do not provide CACHEDIR.TAG markers. The older folder-layout issue concerns cache placement rather than backup exclusion and does not absorb this request.

## Change summary

Mark regenerable cache directories with standards-compliant CACHEDIR.TAG files so compatible backup tools can exclude them.

## Best solution

Provide cache tags for verified cache-only directory trees, independently of any future directory-layout migration. Establish the coverage boundary first so settings, local history, recovery backups, and other persistent user data remain eligible for backup.
