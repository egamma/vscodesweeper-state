# Issue #340666 — Keyboard focus indicator is not visible on the currently selected control in the left navigation:A11y_VisualStudioCode_Leftnavigation_Keyboard

[https://github.com/microsoft/vscode/issues/340666](https://github.com/microsoft/vscode/issues/340666)

## Summary

Thanks for the report. In the Activity Bar CSS the default outline is removed and focus is shown only by a left/right border, and a checked item gets the same border. A keyboard-focused selected item therefore likely looks identical to an unfocused selected item. The report is complete but I could not run it, and the 1.41.0 version it lists is far older than current main, so it stays open as an accessibility bug.

## Change summary

The selected Activity Bar item shows no distinct keyboard focus indicator.

## Best solution

Give the focused item a distinct, high-contrast-safe indicator in the Activity Bar CSS, for example an outline using the focusBorder color, so it is distinguishable from the merely checked state.

- **Behavior:**

  > When a keyboard-focused Activity Bar item is also the selected (checked) item, a visible focus indicator must distinguish it from the unfocused selected state, in default and high-contrast themes. Non-selected focused items and mouse-click behavior (`.clicked`) are unchanged.
- **Trace:**

  > activitybarpart.css:56 removes the outline. activityaction.css:79-98 applies the same left/right border to `.checked` and `:focus` via `.active-item-indicator:before`, so the two states coincide on the selected item. The `.clicked:focus` rule at line 107 must keep suppressing the cue for mouse use. Where the uncertainty starts: the exact visual treatment, for example an outline with `--vscode-focusBorder`, an inset outline, or a background change.
- **Open decisions:**

## Evidence

- **outline removed:** src/vs/workbench/browser/parts/activitybar/media/activitybarpart.css:56-57 sets `.action-item:focus { outline: 0 !important }` with the comment that the activity bar indicates focus with custom styling.
- **same indicator for checked and focused:** src/vs/workbench/browser/parts/activitybar/media/activityaction.css:79-98 draws the same `.active-item-indicator:before` border for `.checked` and `:focus`, both full height on a checked item. The focus cue is indistinguishable from the selected cue.
- **high contrast:** activityaction.css:101-126 hides the checked indicator when not focused and removes the outline in HC themes. In default themes the selected-and-focused case has no extra cue.
