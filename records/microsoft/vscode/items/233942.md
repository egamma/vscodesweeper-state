# Issue #233942 — Semantic tokens are causing a large changed range onTokensChanged event to fire

[https://github.com/microsoft/vscode/issues/233942](https://github.com/microsoft/vscode/issues/233942)

## Summary

Still present on main: `setSemanticTokens` fires `onTokensChanged` for the entire document range (line 1 to line count) rather than computing the actual diff. The related PR #233947 listed this as a follow-up, not a fix. The issue remains a valid optimization request.

## Change summary

Semantic token updates fire a token-changed event covering the entire document even when only a subset of lines actually changed, forcing downstream consumers to invalidate unnecessarily.

## Best solution

Compute a diff between the old and new semantic tokens in `setSemanticTokens` (and potentially `setPartialSemanticTokens`) so the emitted `ranges` only cover lines whose tokens actually changed, reducing unnecessary cache invalidation in consumers like the GPU renderer.
