# Issue #339441 — Allow configuring which terminal profiles are elevated into the AI group

[https://github.com/microsoft/vscode/issues/339441](https://github.com/microsoft/vscode/issues/339441)

## Summary

The requested control is still missing: current source groups custom profiles by hardcoded name matching, without a configurable membership override. The older opt-out request addresses disabling grouping, not including additional profiles, so it does not fully absorb this request.

## Change summary

Allow users to choose which custom terminal profiles appear in the elevated AI group without renaming them.

## Best solution

Have the terminal owner decide whether user-defined profiles should expose explicit grouping metadata or another membership control. Any accepted design should support custom-named agent profiles and coordinate with the separate grouping opt-out request.
