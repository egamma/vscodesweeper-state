# Issue #280537 — The output in the chat keeps moving back to the top

[https://github.com/microsoft/vscode/issues/280537](https://github.com/microsoft/vscode/issues/280537)

## Summary

The terminal-output scrolling regression was fixed after this report and shipped in 1.108.0. The fix prevents detached chat rows from reporting invalid height changes that moved the viewport away from the active response.

## Change summary

Chat repeatedly jumps to earlier conversation content while an agent command produces terminal output, hiding current output and approval controls.

## Best solution

Keep the shipped disconnected-row height guard from commit d68eb349b2ab8568a670f3fb29f505429602021c. Residual scrolling problems involving asynchronously rendered large code blocks remain separately tracked by https://github.com/microsoft/vscode/issues/246523.
