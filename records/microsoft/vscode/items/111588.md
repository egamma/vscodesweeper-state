# Issue #111588 — Cache welcome views

[https://github.com/microsoft/vscode/issues/111588](https://github.com/microsoft/vscode/issues/111588)

## Summary

The central request remains unimplemented: welcome contributions are now registered in batches, but they are not persisted and restored optimistically during startup. Keep this open under discussion because the existing mitigation does not eliminate the initial late-content transition.

## Change summary

Cache extension-contributed welcome-view content so empty views do not visibly change while extensions are processed after startup or reload.

## Best solution

Persist resolved `viewsWelcome` contributions keyed by the installed-extension state, restore them before extension processing, and replace or invalidate the cache once current contributions are available. This likely belongs in the welcome-view contribution handling under `src/vs/workbench/contrib/welcomeViews/common/`.
