# Issue #111588 — Cache welcome views

[https://github.com/microsoft/vscode/issues/111588](https://github.com/microsoft/vscode/issues/111588)

## Summary

Keep open: current code batches extension-contributed welcome content, but does not restore it optimistically across reloads. That may reduce the original churn without delivering the requested startup stability; reassess the remaining transition before designing persistence.

## Change summary

Preserve empty-view welcome content across startup and reload so it does not appear late or change repeatedly while extensions are processed.

## Best solution

Make welcome content stable during startup while preserving current context conditions and reconciling changed extension contributions. First establish what flicker remains with today's batched registration, then decide whether optimistic restoration is necessary and how provisional command actions should behave.
