# Issue #333458 — Terminal doesn't focus if you click the blank space below a copilot terminal widget

[https://github.com/microsoft/vscode/issues/333458](https://github.com/microsoft/vscode/issues/333458)

## Summary

Confirmed in source: the `.terminal-inline-chat` container is absolutely positioned with `top` set to the cursor row and `bottom: 0`, so it spans down to the bottom of the terminal viewport even though the visible inline-chat widget only fills the top portion — the leftover blank area is still part of that DOM element and intercepts clicks meant for the terminal underneath. A contributor has already volunteered to send a fix, so this should stay open for their PR.

## Change summary

Clicking the blank space below the terminal's inline Copilot chat widget doesn't focus the terminal (so Escape doesn't close the widget), because the widget's container extends past its visible content.

## Best solution

Constrain `.terminal-inline-chat`'s effective height/pointer-events to its actual content (e.g. size the container to the widget's real height instead of `bottom: 0`, or set `pointer-events: none` on the empty container and `pointer-events: auto` only on `.inline-chat`) in terminalChatWidget.css / terminalChatWidget.ts, matching the fix already proposed by Chethan616 in the comments.
