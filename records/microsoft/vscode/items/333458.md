# Issue #333458 — Terminal doesn't focus if you click the blank space below a copilot terminal widget

[https://github.com/microsoft/vscode/issues/333458](https://github.com/microsoft/vscode/issues/333458)

## Summary

Freshly reported, plausible UI bug: the terminal inline chat widget is an absolutely-positioned overlay (`.terminal-inline-chat`, `position: absolute; z-index: 100`) anchored to the bottom of the terminal element with `height: auto !important`, and clicking the visually blank strip below the rendered widget content doesn't route focus back to the terminal instance. Already correctly labeled `bug`/`terminal`/`terminal-inline-chat`, so no routing needed — just needs a maintainer to reproduce and pin down the exact click-target/overlay mismatch.

## Change summary

Clicking the blank space below the terminal inline-chat (Copilot) widget doesn't focus the terminal, so Escape doesn't dismiss the widget as expected.

## Best solution

Investigate the terminal-inline-chat overlay's DOM/CSS bounds vs. its visible content in src/vs/workbench/contrib/terminalContrib/chat/browser/terminalChatWidget.ts and media/terminalChatWidget.css — likely the container or a child element extends (or its click target is computed) beyond the visually rendered widget, swallowing clicks that should fall through to the terminal (`this._instance.focus()`).
