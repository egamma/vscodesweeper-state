# Issue #334248 — Agent Host file monitor watches session roots recursively, ignoring files.watcherExclude

[https://github.com/microsoft/vscode/issues/334248](https://github.com/microsoft/vscode/issues/334248)

## Summary

Traced this in current main and it holds: the agent host's changeset file monitor hardcodes DEFAULT_AGENT_HOST_WATCH_EXCLUDES and never consults the user's files.watcherExclude, so it can watch far more of a large workspace than the primary workbench watcher does. This is a real, well-diagnosed gap worth routing to the owning area.

## Change summary

Agent Host's recursive session-root file watcher ignores the user's files.watcherExclude setting, watching directories (e.g. node_modules) the workbench watcher correctly excludes.

## Best solution

In agentHostChangesetFileMonitorCoordinator.ts's _ensureRootWatcher, merge the resolved files.watcherExclude patterns for the repository root (via IConfigurationService, already available in the agent host node process — see devContainerAgentHostService.ts and nodeAgentHostStarter.ts) into the excludes array passed to AgentHostFileMonitorService.acquire, alongside DEFAULT_AGENT_HOST_WATCH_EXCLUDES.
