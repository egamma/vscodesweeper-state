# Issue #331578 — Support configuring the utility model with the Agent Host Copilot Harness

[https://github.com/microsoft/vscode/issues/331578](https://github.com/microsoft/vscode/issues/331578)

## Summary

Brand-new, team-authored feature request describing a real gap: utility models in the Agent Host Copilot harness can't yet be configured to use BYOK models when the user isn't signed into GitHub. Nothing to close; this needs implementation work in the agent host/chat model-selection code.

## Change summary

Allow the utility model to be configured with BYOK models in the Agent Host Copilot Harness, not just the Local harness, for users not signed in to GitHub.

## Best solution

Extend the Copilot Agent Host harness's model configuration (alongside src/vs/workbench/contrib/chat/browser/utilityModelContribution.ts and the agent host's copilotApiService.ts) so the utility model can be pointed at a BYOK model when no GitHub session is present, matching the flexibility already available for the Local harness.
