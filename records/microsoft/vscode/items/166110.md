## Summary

Team-authored polish request for the merge editor: add a hover that summarizes what changed (added/removed/modified lines) so users don't need the base view to understand a conflict. No implementation found on current main — the merge editor has no hover provider or tooltip summarizing changes. Keeping open.

Implement a hover participant or hover provider in `src/vs/workbench/contrib/mergeEditor/browser/` that, when hovering over a conflict region, shows a concise summary of additions, modifications, and deletions relative to the base — reducing reliance on the full base view for understanding changes.
