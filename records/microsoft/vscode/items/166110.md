# Issue #166110 — 3-way merge: Have a hover to understand a change

[https://github.com/microsoft/vscode/issues/166110](https://github.com/microsoft/vscode/issues/166110)

## Summary

Keep open: current merge-editor controls provide comparisons and deletion markers, but not a per-change hover explaining additions, modifications, and removals while the base view is hidden. This team-authored, accepted request has no verified fixing commit or qualifying duplicate.

## Change summary

Show a hover explaining each merge input's changes relative to the base, including deleted content, without opening the base view.

## Best solution

Provide an on-demand, per-input change explanation in the merge editor that makes removed base content understandable without changing the layout. Preserve the existing base-view and comparison commands as complementary inspection tools.
