# Issue #325252 — "Generate Commit Message" does not work with BYOK

[https://github.com/microsoft/vscode/issues/325252](https://github.com/microsoft/vscode/issues/325252)

## Summary

The SCM sparkle still routes signed-out BYOK users through Copilot setup before reaching the commit-message generator, although that generator already supports configured BYOK utility models. Keep this report open; the newer exact-symptom report is closed and cannot serve as its duplicate canonical.

## Change summary

Generate commit messages using configured BYOK utility models without requiring GitHub sign-in.

## Best solution

Make the SCM input action honor BYOK readiness consistently with Chat and reach the existing utility-model generator without unnecessary Copilot setup. Preserve workspace trust, disabled-AI behavior, and onboarding for users without usable models.
