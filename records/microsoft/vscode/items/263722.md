# Issue #263722 — Code-Insiders blocks sleep and there is no way to disable this feature

[https://github.com/microsoft/vscode/issues/263722](https://github.com/microsoft/vscode/issues/263722)

## Summary

The report shows a Linux sleep inhibitor attributed to Code-Insiders, but the truncated output does not establish whether it blocks sleep or only delays it. Request current-build confirmation and complete inhibitor details before deciding whether VS Code or Electron needs a change.

## Change summary

Code-Insiders reportedly prevents Ubuntu from sleeping merely by being open, without an available opt-out.

## Best solution

Establish which component creates the inhibitor and whether it actually prevents automatic or explicit suspend. If ordinary idle startup causes unintended sleep prevention, correct that lifecycle rather than assume a global disable flag is necessary.
