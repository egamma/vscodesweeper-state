# Issue #328339 — API: Allow extensions to specify initial selection state for MCP server tools

[https://github.com/microsoft/vscode/issues/328339](https://github.com/microsoft/vscode/issues/328339)

## Summary

Keep open: the current MCP extension API still lacks per-tool initial selection defaults. Existing user-controlled selection does not satisfy this team-authored request, and the agent-host-mitigated label alone does not establish completion.

## Change summary

Allow extensions to register MCP tools as initially unchecked for chat while preserving programmatic invocation and user opt-in.

## Best solution

Have the MCP API owners define an extension-provided initial-selection contract that preserves explicit user choices and defaults unspecified tools to enabled. Keep selection separate from tool registration and invocation availability.
