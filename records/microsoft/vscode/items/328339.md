# Issue #328339 — API: Allow extensions to specify initial selection state for MCP server tools

[https://github.com/microsoft/vscode/issues/328339](https://github.com/microsoft/vscode/issues/328339)

## Summary

Keep open as a valid extension API request. Current MCP metadata can describe tool availability but cannot declare an initially disabled selection state, and the team-authored item is protected from judgment closes.

## Change summary

Allow an MCP server definition provider to register individual tools as unchecked by default while retaining programmatic invocation.

## Best solution

Extend MCP tool metadata with a backward-compatible initial-selection property and carry it through the extension-host conversion into chat tool enablement, without overriding a user's persisted choice. The API shape belongs near `src/vscode-dts/vscode.proposed.mcpToolDefinitions.d.ts` and `src/vs/workbench/api/common/extHostMcp.ts`, with consumption in the MCP tool contribution and selected-tools state.
