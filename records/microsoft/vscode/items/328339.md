# Issue #328339 — API: Allow extensions to specify initial selection state for MCP server tools

[https://github.com/microsoft/vscode/issues/328339](https://github.com/microsoft/vscode/issues/328339)

## Summary

Well-scoped, concrete extension API gap — no way for an MCP server definition to mark a tool unchecked-by-default while keeping it invocable — and confirmed unimplemented on current main; routing to the MCP/API area owners for consideration.

## Change summary

Let extensions specify that an MCP tool should start unchecked in Configure Tools (while remaining invocable) instead of always defaulting to enabled.

## Best solution

Extend the proposed API in src/vscode-dts/vscode.proposed.mcpToolDefinitions.d.ts (or the McpServerDefinitionProvider surface) with a per-tool default-enabled flag, honored in the tool enablement defaults path in src/vs/workbench/contrib/chat/browser/widget/input/chatSelectedTools.ts; needs an API owner decision (likely @connor4312, who owns the adjacent mcpToolDefinitions proposal) before implementation.
