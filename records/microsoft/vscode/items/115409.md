# Issue #115409 — Settings editor: Support .enabled to hide other settings in the namespace by convention 

[https://github.com/microsoft/vscode/issues/115409](https://github.com/microsoft/vscode/issues/115409)

## Summary

Still a valid feature request — no mechanism exists on current main to conditionally hide settings based on a `.enabled` sibling. The parent issue #70589 remains open and the discussion shows unresolved UX questions (hide vs. gray out).

## Change summary

Settings editor should hide (or gray out) child settings when a parent `.enabled` setting is disabled, reducing noise for features the user has turned off.

## Best solution

Resolve the UX question (hide completely vs. show grayed-out with a hint) and implement in the settings tree model/renderer. This is part of the broader settings-organization work tracked by https://github.com/microsoft/vscode/issues/70589.
