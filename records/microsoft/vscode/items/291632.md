# Issue #291632 — Right-Click > "Copy" on image in Copilot Chat copies the entire history instead of just the screenshot

[https://github.com/microsoft/vscode/issues/291632](https://github.com/microsoft/vscode/issues/291632)

## Summary

The underlying bug remains on current main: an image target is not distinguished by the Chat context menu, so “Copy” serializes chat text rather than copying the image. Route this to the Chat image area for a cross-platform clipboard design and fix.

## Change summary

Right-clicking a screenshot in Chat and choosing Copy should copy the screenshot, not the surrounding chat content.

## Best solution

Give Chat images a target-specific Copy action that writes the displayed image to the system clipboard across desktop and web, while preserving the existing response-text Copy and Copy All actions for non-image targets.
