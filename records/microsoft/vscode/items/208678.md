# Issue #208678 — Download Code from Currently Opened Folder in VSCode Workspace

[https://github.com/microsoft/vscode/issues/208678](https://github.com/microsoft/vscode/issues/208678)

## Summary

The request to expose `explorer.download` as an extension-callable command that accepts arbitrary URIs remains unimplemented — the handler still reads from the explorer selection/roots with no URI arguments. Team-authored, labeled team-low-hanging, keeping open.

## Change summary

Allow extensions to programmatically download workspace files by passing a list of URIs to the `explorer.download` command.

## Best solution

Extend `downloadFileHandler` in `src/vs/workbench/contrib/files/browser/fileActions.ts` to accept an optional array of URIs as command arguments, falling back to the current explorer-selection behavior when none are provided. This gives extensions like Azure Functions the ability to trigger downloads without requiring the user to manually right-click in the explorer.
