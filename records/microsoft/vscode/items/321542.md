[https://github.com/microsoft/vscode/issues/321542](https://github.com/microsoft/vscode/issues/321542)

## Summary

The requested Azure DevOps PR workflow remains missing from the inspected built-in surfaces, and no verified open canonical owns its full scope. Keep this open for an ownership and product-scope decision; existing extension APIs provide building blocks, not the requested first-party solution.

## Change summary

Provide first-party Azure DevOps PR management and inline review comments, with Microsoft authentication and support for cloud and on-premises instances.

## Best solution

Evaluate a first-party Azure DevOps review extension using the existing comments and authentication APIs rather than adding provider-specific review infrastructure to core. Establish ownership and supported authentication/server configurations before committing to GitHub workflow parity.

These commands do not provide Azure DevOps PR discovery or inline review.
- **Reusable APIs, not a delivered integration:** src/vscode-dts/vscode.d.ts exposes comments.createCommentController and CommentController.createCommentThread at lines 17789–17813, authentication.getSession, and SecretStorage. extensions/microsoft-authentication/package.json contributes the microsoft authentication provider.
