# Issue #180582 — Proposal: Canonical URI identity provider

[https://github.com/microsoft/vscode/issues/180582](https://github.com/microsoft/vscode/issues/180582)

## Summary

This is the tracking issue for the `canonicalUriProvider` proposed API. The proposal exists in `src/vscode-dts/vscode.proposed.canonicalUriProvider.d.ts` and has implementation in the workbench, but it remains a proposed (not finalized) API — the issue should stay open to track finalization.

## Change summary

Introduce a canonical URI identity provider API so extensions can declare URI equivalences across filesystems, enabling workspace trust and edit sessions to recognize the same repository across protocols/remotes.

## Best solution

Finalize the `canonicalUriProvider` proposed API when the surface is stable and adoption is sufficient, then close this tracking issue. The API shape has already been iterated (PR #182667) and is actively used by the continue-working-on and workspace-trust features.
