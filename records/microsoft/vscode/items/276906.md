# Issue #276906 — rm `run_task` in favor of an execute strategy on `run_in_terminal`

[https://github.com/microsoft/vscode/issues/276906](https://github.com/microsoft/vscode/issues/276906)

## Summary

Team-authored plan item (MEMBER). The `run_task` tool still exists as a separate entry in `TerminalToolId` on current main — the consolidation into `run_in_terminal` via an execute strategy has not landed yet. Keeping open per hard keep-open rule.

## Change summary

Remove the separate `run_task` chat tool and fold its functionality into `run_in_terminal` as an execute strategy, reducing the number of tools exposed to the agent.

## Best solution

Implement a task-aware execute strategy on the `run_in_terminal` tool so that when the agent's command matches a configured task, it runs via the task system automatically. Remove `run_task` (and likely `create_and_run_task`) from `TerminalToolId` and the Copilot tool names. The consolidation lives in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/` and the tool registration in `extensions/copilot/src/extension/tools/`.
