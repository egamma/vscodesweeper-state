# Issue #172349 — Tabs do not align to tab stops when emoji are used

[https://github.com/microsoft/vscode/issues/172349](https://github.com/microsoft/vscode/issues/172349)

## Summary

Still reproduces on main: the column model in `_nextVisibleColumn` assigns emoji a fixed width of 2, but the actual rendered glyph width varies by font and platform, so the tab stop after an emoji lands at the wrong visual position. No fix has been committed.

## Change summary

Tab characters after emoji do not align to the correct tab stop because the column model's emoji width assumption (2 columns) doesn't match the actual rendered glyph width.

## Best solution

The editor's column model (`CursorColumns._nextVisibleColumn` in `src/vs/editor/common/core/cursorColumns.ts`) needs to reconcile the assumed emoji width (2 columns) with the actual rendered width. The GPU renderer work (issue https://github.com/microsoft/vscode/issues/221145) may eventually address this via measured glyph widths, but the DOM renderer still uses the column model directly. A targeted fix would measure or correct the tab rendering when emoji precede a tab character.
