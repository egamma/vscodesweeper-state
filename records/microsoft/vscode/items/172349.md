# Issue #172349 — Tabs do not align to tab stops when emoji are used

[https://github.com/microsoft/vscode/issues/172349](https://github.com/microsoft/vscode/issues/172349)

## Summary

Keep open: current DOM rendering still expands tabs using logical columns rather than the preceding text's measured width, leaving a plausible alignment gap for emoji. Full-width normalization and experimental GPU rendering have been added since the report, but neither establishes that this case is fixed; the supplied two-line sample is sufficient to retest.

## Change summary

Text following a tab is horizontally misaligned when an emoji precedes that tab.

## Best solution

Ensure the editor places text following tabs on the appropriate visual tab stops even when fallback emoji glyphs have fractional character-cell widths. First reproduce the supplied macOS example against current DOM rendering, then establish regression coverage without changing document contents or unrelated cursor semantics.
