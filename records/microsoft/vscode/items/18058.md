# Issue #18058 — Evaluate selected expression on hover while debugging?

[https://github.com/microsoft/vscode/issues/18058](https://github.com/microsoft/vscode/issues/18058)

## Summary

Still a valid, unimplemented feature request with 15 upvotes. The debug hover on current main uses EvaluatableExpressionProvider or word-based fallback but never checks editor selection — the requested behavior remains missing.

## Change summary

When debugging, evaluate and display the result of a user-selected expression on hover over the selection.

## Best solution

Modify the debug hover compute path (src/vs/workbench/contrib/debug/browser/debugHover.ts) to detect when the hovered position falls within the editor's current selection, and if so, use the selected text as the expression to evaluate rather than calling the EvaluatableExpressionProvider. A setting to toggle this behavior would address the side-effect concern raised in comments.
