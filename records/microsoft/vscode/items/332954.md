# Issue #332954 — kernel issue

[https://github.com/microsoft/vscode/issues/332954](https://github.com/microsoft/vscode/issues/332954)

## Summary

This is the intended, documented consequence of removing Winpty support: ConPTY (and the bundled conpty.dll fallback) requires Windows 10 1809+ (build 17763+), and the reporter's OS is build 10.0.14393 (Windows 10 1607, from 2016) — far below that minimum, so the terminal cannot launch on either the system or bundled ConPTY implementation.

## Change summary

Terminal fails to launch on an old Windows build with 'Cannot launch conpty' after Winpty was removed.

## Best solution

No code change needed — this is the expected outcome of dropping Winpty support in 1.109 for OS versions that predate ConPTY. The reporter would need to upgrade Windows to 1809+ (or a supported release) to use the integrated terminal.
