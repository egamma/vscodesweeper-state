# Issue #322214 — cannot edit a md file and open a different one as Preview

[https://github.com/microsoft/vscode/issues/322214](https://github.com/microsoft/vscode/issues/322214)

## Summary

Keep open while the linked PR is reviewed: ordinary tab pinning does not lock a Markdown preview's resource, although dedicated preview-locking commands already support editing a different file. The remaining question is whether pinning should also stop the preview from following the active Markdown editor.

## Change summary

Make a pinned Markdown preview retain its original document when another Markdown file becomes active.

## Best solution

Review https://github.com/microsoft/vscode/pull/327193 and settle whether tab pinning should imply resource locking, preserving existing unlocked-preview behavior. The existing preview-locking commands already provide the reporter's underlying workflow.

  > Thanks for the report. To keep one Markdown file in preview while editing another, use “Markdown: Toggle Preview Locking” on the preview, or open it with “Markdown: Open Locked Preview to the Side”. Preview locking is currently separate from tab pinning; https://github.com/microsoft/vscode/pull/327193 proposes changing the pinned-tab behavior, so this issue should remain open while that proposal is reviewed.
