# Issue #322214 — cannot edit a md file and open a different one as Preview

[https://github.com/microsoft/vscode/issues/322214](https://github.com/microsoft/vscode/issues/322214)

## Summary

Confirmed Markdown preview bug with an open fixing PR; keep the issue open and route it to the Markdown area while that PR is reviewed.

## Change summary

Pinning a Markdown preview tab does not prevent it from switching to another Markdown file opened for editing.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/327193, which guards dynamic preview updates when the corresponding webview tab is pinned.
