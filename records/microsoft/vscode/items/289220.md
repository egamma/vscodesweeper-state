# Issue #289220 — GitHub Copilot summarization strategy setting to truncate earliest conversation

[https://github.com/microsoft/vscode/issues/289220](https://github.com/microsoft/vscode/issues/289220)

## Summary

Keep open for product discussion. Current settings can disable summarization or enable Responses API truncation, but there is no supported strategy selector that consistently provides sliding-window behavior across models and endpoints.

## Change summary

Provide a configurable Copilot context-management strategy that can discard the oldest conversation turns instead of summarizing them.

## Best solution

Expose a supported context-management setting with clearly defined summarize, truncate-oldest, and disabled modes, implemented consistently across endpoint types. Any plugin hook for custom context management should be evaluated separately as an extension-API design.
