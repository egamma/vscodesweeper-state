# Issue #229606 — ASCII characters should not be part of the editing undo/redo stack

[https://github.com/microsoft/vscode/issues/229606](https://github.com/microsoft/vscode/issues/229606)

## Summary

Keep open: a maintainer confirmed that undo can restore intermediate Pinyin instead of removing the committed Chinese text, particularly with slow typing and with either input implementation. Current source inspection establishes the relevant composition paths but not a fix or a qualifying canonical duplicate.

## Change summary

Undoing committed Chinese IME input should not expose intermediate ASCII composition text as separate undo states.

## Best solution

Make undo of the reported Chinese composition remove the committed text without restoring intermediate Pinyin, consistently across native EditContext and textarea input. First capture the slow-typing event sequence on current macOS, then establish a regression check in the editor input/cursor suites without changing Korean undo granularity.
