# Issue #206362 — `contextualTitle` not showing on view container

[https://github.com/microsoft/vscode/issues/206362](https://github.com/microsoft/vscode/issues/206362)

## Summary

This remains the canonical open bug for custom panel containers losing the sole view's visible title. A later report reproduced the same symptom and was closed into this issue, while no fixing commit references either report.

## Change summary

A custom panel container with one visible view shows only the container title, hiding the view name and its associated view-header interactions.

## Best solution

Keep the sole view identifiable in a panel, either through the combined container/view title or a visible view header, while preserving the documented rule that `contextualTitle` applies when a view moves outside its original container. The remaining-view menu and drag targets must also remain reachable after another view is hidden.

- **Trace:**

  > Extension contributions are converted to `IViewDescriptor` objects in src/vs/workbench/api/browser/viewsExtensionPoint.ts, where `contextualTitle` becomes `containerTitle`. `ViewContainerModel.updateContainerInfo()` in src/vs/workbench/services/views/common/viewContainerModel.ts selects the displayed container title, while `ViewPaneContainer.getTitle()` in src/vs/workbench/browser/parts/views/viewPaneContainer.ts already computes a combined container/view title for a merged sole view. Preserve multi-view titles and the documented moved-view contextual-title semantics.

## Evidence

- **confirmed canonical:** https://github.com/microsoft/vscode/issues/230383 reported the same missing view name in the Panel on VS Code 1.93.1; a maintainer closed that report as a duplicate of https://github.com/microsoft/vscode/issues/206362.
- **current title path:** src/vs/workbench/api/browser/viewsExtensionPoint.ts assigns `contextualTitle` to `IViewDescriptor.containerTitle`; src/vs/workbench/browser/parts/views/viewPaneContainer.ts then intends to combine the container title and pane title in `ViewPaneContainer.getTitle()` when a sole view is merged.
