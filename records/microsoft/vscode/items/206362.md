# Issue #206362 — `contextualTitle` not showing on view container

[https://github.com/microsoft/vscode/issues/206362](https://github.com/microsoft/vscode/issues/206362)

## Summary

Still present on current main: when a panel view container has a single view and `isViewMergedWithContainer()` is true, the view's own name can be hidden in favor of the container title. No fixing commit found. The related issue #230383 was closed as a duplicate of this one, confirming it as the canonical tracker.

## Change summary

When a contributed view is the sole view in a panel container, only the container title is displayed — the view's own name is not shown, despite being different.

## Best solution

Fix the merged-view title logic in `src/vs/workbench/browser/parts/views/viewPaneContainer.ts` (`getTitle()`) and/or the panel tab title rendering to include the view name when it differs from the container title. The `getTitle()` method already composes `containerTitle: paneItemTitle` when they differ, but the panel tab or composite title update may not be calling it correctly or at the right time. The secondary issue in comment 1 (losing the context menu when hiding views) may warrant a separate fix or the same pass.
