# Issue #309992 — Chat Sessions Controller : resource alias never removed once registered

[https://github.com/microsoft/vscode/issues/309992](https://github.com/microsoft/vscode/issues/309992)

## Summary

The inverse resource alias still survives session disposal and deletion on current main, so the lifecycle cleanup remains outstanding. Current documentation and tests deliberately preserve that alias for option lookups; this team-authored Backlog item should remain open rather than be declined as designed.

## Change summary

Give registered chat-session resource aliases a bounded lifetime without breaking option resolution after session materialization.

## Best solution

Define when an alias is no longer needed by a surviving or reopened real session, then release obsolete mappings at that lifecycle boundary. Preserve option selections across untitled-to-real session transitions.
