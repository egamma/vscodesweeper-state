# Issue #332422 — Markdown Editor: allow scrolling beyond the last line (respect editor.scrollBeyondLastLine)

[https://github.com/microsoft/vscode/issues/332422](https://github.com/microsoft/vscode/issues/332422)

## Summary

Keep open as a feature request: the rich Markdown Editor does not receive editor.scrollBeyondLastLine, although the Markdown Preview does. No verified older canonical owns this requested behavior.

## Change summary

Make the built-in rich Markdown Editor honor editor.scrollBeyondLastLine so users can write at the document end without adding blank lines.

## Best solution

Support the existing resource-scoped editor.scrollBeyondLastLine preference in the rich Markdown Editor, including changes while it is open, without altering document contents or introducing another setting.
