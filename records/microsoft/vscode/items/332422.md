# Issue #332422 — Markdown Editor: allow scrolling beyond the last line (respect editor.scrollBeyondLastLine)

[https://github.com/microsoft/vscode/issues/332422](https://github.com/microsoft/vscode/issues/332422)

## Summary

Traced on main: the Markdown Editor's webview scroll container (#editor in markdownEditor.css) has no scroll-beyond-last-line handling, unlike the text editor and Markdown Preview which both honor editor.scrollBeyondLastLine — this is a real, currently-missing behavior in a brand-new feature, not yet routed to an area owner.

## Change summary

Request that the new built-in Markdown Editor honor the existing editor.scrollBeyondLastLine setting so the last line isn't pinned to the viewport's bottom edge.

## Best solution

In extensions/markdown-language-features, wire editor.scrollBeyondLastLine into the Markdown Editor's initial state (following the existing richLinksEnabled pattern in markdownEditorProvider.ts's #configureWebview/encodeWebviewInitialState) and add matching bottom padding/margin to the #editor scroll container in markdown-editor-src/markdownEditor.css, mirroring how the Markdown Preview already applies its scrollBeyondLastLine class.
