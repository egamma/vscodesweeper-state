# Issue #270064 — Git Commit keeps suggesting to create a branch, even though main isn't protected

[https://github.com/microsoft/vscode/issues/270064](https://github.com/microsoft/vscode/issues/270064)

## Summary

Team-authored issue reporting a false-positive branch protection prompt. The team is actively investigating — trace telemetry was added in May 2026 (commit 75e023baf01) to help diagnose this class of issue. No fix has landed yet; keeping open per team-member authorship rule.

## Change summary

Git commit action incorrectly prompts to create a new branch on an unprotected main branch, even though neither `git.branchProtection` nor GitHub rulesets protect it.

## Best solution

Investigate the root cause of the false-positive `isBranchProtected()` result — likely stale data restored from `globalState` in `GitHubBranchProtectionProvider` before the API call completes, or a race between the settings-based `GitBranchProtectionProvider` and the GitHub provider. The trace telemetry from commit 75e023baf01 should help narrow it down. Fix in `extensions/git/src/repository.ts` and/or `extensions/github/src/branchProtection.ts`.
