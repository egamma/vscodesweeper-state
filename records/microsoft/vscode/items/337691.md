# Issue #337691 — New windows are blank after VS Code package is upgraded while an older instance is running on Linux

[https://github.com/microsoft/vscode/issues/337691](https://github.com/microsoft/vscode/issues/337691)

## Summary

Keep open in install-update: an independent commenter confirms that upgrading the Linux package while VS Code is running leaves new windows blank and unresponsive. No matching canonical or concrete fix was established; the supplied steps are sufficient for targeted investigation.

## Change summary

Opening a new window after an in-place Linux package upgrade fails while existing windows continue working.

## Best solution

Establish where the surviving process and replaced installation become incompatible, then make new-window creation recover safely without disrupting existing windows or unsaved edits. Investigate desktop startup and window loading alongside Linux package-update handling.
