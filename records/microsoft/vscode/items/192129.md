## Change summary

Add an API and UI for displaying inline diff previews of suggested code edits within comment cards, enabling code review extensions to show reviewers' suggested changes directly in the comment widget.

## Best solution

Continue the API design discussion between the VS Code team and interested contributors. The two main approaches — markdown-based suggestion syntax (simpler, GitHub-compatible) vs. WorkspaceEdit-based API (more flexible, supports multi-location edits) — need a final decision from the area owner. Once decided, a community PR implementing the chosen approach in `src/vs/workbench/contrib/comments/` would be welcome per alexr00's comment.
