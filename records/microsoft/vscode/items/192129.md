# Issue #192129 — Provide diff view inside comment card to preview suggested edits

[https://github.com/microsoft/vscode/issues/192129](https://github.com/microsoft/vscode/issues/192129)

## Summary

Keep open as an API proposal with explicit maintainer support. The inspected comment APIs and rendering path do not provide the requested suggestion-aware diff preview, and API-proposal tracking issues must remain open for their owners to resolve.

## Change summary

Display suggested code changes as inline diffs within review comment cards instead of requiring a separate preview.

## Best solution

Provide a resource-conscious, provider-independent suggestion preview in the comments contribution. The API owners should settle how suggestions are supplied and how edits outside the commented range are represented, building on the maintainer-supported Markdown approach and the subsequent structured-edit feedback.
