The editor Find widget still lacks smart-case behavior on current main. Keep this accepted, community-supported request open while its linked implementation candidate is reviewed.

## Change summary

Support automatic case-sensitive matching for uppercase queries in the in-editor Find widget, analogous to search.smartCase.
