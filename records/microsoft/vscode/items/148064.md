# Issue #148064 — Report Issue should warn on outdated VS Code / Extension

[https://github.com/microsoft/vscode/issues/148064](https://github.com/microsoft/vscode/issues/148064)

## Summary

The VS Code outdated-version warning in the issue reporter has been implemented (update banner via commit 2c076f5582e), but the request also asks for warnings about outdated extensions, which is not yet implemented. Keeping open for the remaining extension-update part. This is a team-authored issue so cannot close without an explicit issue reference in the fix commit.

## Change summary

The issue reporter should warn users when VS Code or installed extensions are outdated before filing a bug report.

## Best solution

The VS Code update banner is shipped. The remaining work is to check whether the selected extension (when filing against an extension) has a newer version available and warn the user to update it first. This belongs in `src/vs/workbench/contrib/issue/` — the issue reporter overlay and editor pane code that already queries the update service for the VS Code banner could similarly query extension gallery versions.
