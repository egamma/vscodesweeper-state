# Issue #104259 — Problem with including markdown as language for Emmet

[https://github.com/microsoft/vscode/issues/104259](https://github.com/microsoft/vscode/issues/104259)

## Summary

The reported configuration conflict remains in current source: Markdown is excluded by default, and that exclusion blocks an explicit Markdown-to-HTML inclusion before Emmet resolves the mapping. Keep this accepted Backlog bug open; the existing workaround does not eliminate the configuration trap.

## Change summary

Explicitly including Markdown for Emmet does not enable abbreviations unless the user also removes Markdown from emmet.excludeLanguages.

## Best solution

Make an explicit Markdown inclusion usable without requiring users to discover and clear the default exclusion, while preserving Markdown's default opt-out and deliberate user exclusions. Keep completion suggestions and the Expand Abbreviation command consistent.
