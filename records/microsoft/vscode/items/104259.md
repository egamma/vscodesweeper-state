# Issue #104259 — Problem with including markdown as language for Emmet

[https://github.com/microsoft/vscode/issues/104259](https://github.com/microsoft/vscode/issues/104259)

## Summary

Still reproduces on main: `emmet.excludeLanguages` (which defaults to `["markdown"]`) is checked first and causes an early return before `emmet.includeLanguages` is ever consulted, making the include setting ineffective without also clearing the exclude.

## Change summary

Setting `emmet.includeLanguages: {"markdown": "html"}` does not enable Emmet in markdown because `excludeLanguages` (which defaults to `["markdown"]`) takes unconditional precedence.

## Best solution

In `defaultCompletionProvider.ts` and `abbreviationActions.ts`, check whether a language appears in `includeLanguages` before honoring its presence in `excludeLanguages` — an explicit include should override the default exclude. The fix is small and localized to those two files.
