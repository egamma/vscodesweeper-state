# Issue #23707 — Several fonts at the same time for different elements of the code

[https://github.com/microsoft/vscode/issues/23707](https://github.com/microsoft/vscode/issues/23707)

## Summary

The central request is implemented: themes and users can assign different font families to TextMate scopes within the same editor. The implementing commit adds both configuration support and token-level rendering, so this can be closed as completed.

## Change summary

Allow different code elements, comments, and Markdown regions to use different font families within one document.

## Best solution

Use theme tokenColors or editor.tokenColorCustomizations.textMateRules with settings.fontFamily, retaining editor.fontFamily as the base font. Track remaining token-font refinements separately in https://github.com/microsoft/vscode/issues/263545.
