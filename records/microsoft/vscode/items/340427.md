# Issue #340427 — ModernUI Tab is surpressing all the Text

[https://github.com/microsoft/vscode/issues/340427](https://github.com/microsoft/vscode/issues/340427)

## Summary

Credible visual feedback on the brand-new, still-experimental Modern UI tabs (`workbench.experimental.modernUI`): the integrated close-button/action space and shrink-mode label squeezing plausibly leave too little room for icon+text with many tabs open, exactly as the screenshots show. Already correctly labeled `workbench-tabs`/`modernization`; this is WIP feedback for the feature owners, not a close candidate.

## Change summary

With Modern UI tabs enabled and many tabs open, tab labels (and sometimes the file-type icon) become unreadable because the integrated close-button area and shrink-mode sizing leave too little width for the label.

## Best solution

Feature owners of the Modern UI experiment should tune the shrink/compact tab sizing in src/vs/workbench/contrib/modernUI/browser/media/tabs.css and the sizing logic in multiEditorTabsControl.ts/editorTabsControl.ts so labels stay legible at high tab counts; the multi-line tab request is a separate, lower-priority ask worth tracking separately if pursued.

## Evidence

- **plausible cause traced:** src/vs/workbench/contrib/modernUI/browser/media/tabs.css reserves a 24px fixed .tab-actions width (lines ~402-423) and only applies flex:1/min-width:0 label shrinking in .sizing-shrink/.sizing-fixed tabs (lines ~383-393); multiEditorTabsControl.ts also special-cases a 28px MODERN_UI_COMPACT_PINNED_TAB_WIDTH — consistent with labels/icons getting squeezed out at high tab counts as shown in the reporter's screenshots.
