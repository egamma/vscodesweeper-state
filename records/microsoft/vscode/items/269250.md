# Issue #269250 — [json] show a notification when retrying to load a schema fails

[https://github.com/microsoft/vscode/issues/269250](https://github.com/microsoft/vscode/issues/269250)

## Summary

Keep open as an under-discussion JSON UX request: maintainers confirmed that schema-load failures already surface details in the editor and Problems view, but retrying from the status bar gives no direct feedback or route to those details.

## Change summary

Show useful failure feedback, including the affected schema, when retrying a JSON schema load fails.

## Best solution

When a schema retry fails, reveal or offer to reveal the corresponding Problems entry while identifying the schema URL and preserving the existing editor diagnostics as the authoritative error detail.
