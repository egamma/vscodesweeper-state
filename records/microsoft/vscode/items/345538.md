# Issue #345538 — "New Session" button in Inbox looks out of place

[https://github.com/microsoft/vscode/issues/345538](https://github.com/microsoft/vscode/issues/345538)

## Summary

The Inbox still places New Session beside search, sorting, and filtering with the same secondary-control styling. Keep this team-authored polish request open; the remaining decision is whether to remove the redundant action or retain it separately.

## Change summary

Remove or visually separate the Inbox's redundant New Session action from its filtering and sorting controls.

## Best solution

Keep the Inbox toolbar focused on managing its contents while preserving discoverable, keyboard-accessible session creation. Prefer removing the redundant toolbar entry if the existing title-bar action covers both entering and returning to new-session composition.
