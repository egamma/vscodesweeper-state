# Issue #345538 — "New Session" button in Inbox looks out of place

[https://github.com/microsoft/vscode/issues/345538](https://github.com/microsoft/vscode/issues/345538)

## Summary

Keep open as actionable Inbox design polish: current source still places New Session beside search and sort with the same secondary styling. Removing that affordance versus retaining a clearly separated action remains a user-visible design choice; this team-authored report should not receive a judgment close.

## Change summary

Remove or visually separate the redundant New Session action from Inbox filtering and sorting controls.

## Best solution

Give Inbox a clear hierarchy between list controls and session creation without sacrificing the ability to leave a selected conversation and return to the new-session composer. Decide whether the toolbar action is necessary before changing its placement or appearance.
