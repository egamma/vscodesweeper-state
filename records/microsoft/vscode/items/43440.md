# Issue #43440 — Option to disable font ligatures in certain syntactical constructs like strings

[https://github.com/microsoft/vscode/issues/43440](https://github.com/microsoft/vscode/issues/43440)

## Summary

A meaningful syntax-scoped ligature gap remains on current main. With 51 community upvotes and an existing Backlog milestone, this should remain open as an accepted, unscheduled feature request.

## Change summary

Allow font ligatures to be disabled selectively for syntax constructs such as strings or comments while remaining enabled elsewhere.

## Best solution

Design syntax-token-aware font-feature settings in the editor rendering and token-theme pipeline, while preserving the existing global and language-specific controls. This needs maintainer design because ligature shaping and token boundaries interact.
