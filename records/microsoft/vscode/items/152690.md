# Issue #152690 — Add setting editor.inlayHint.defaultFontSizePercentage

[https://github.com/microsoft/vscode/issues/152690](https://github.com/microsoft/vscode/issues/152690)

## Summary

A real gap remains: current main supports only an absolute inlay-hint font size, not a size relative to the editor font. This team-authored Backlog request should remain open for an editor UX decision.

## Change summary

Allow inlay-hint text to use a font size expressed relative to the editor font size.

## Best solution

Decide whether `editor.inlayHints.fontSize` should accept a relative representation or gain a percentage companion, while preserving uniform user-controlled styling across languages. The implementation would belong in the inlay-hints editor option and layout calculation.
