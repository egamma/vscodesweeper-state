# Issue #152690 — Add setting editor.inlayHint.defaultFontSizePercentage

[https://github.com/microsoft/vscode/issues/152690](https://github.com/microsoft/vscode/issues/152690)

## Summary

Relative inlay-hint sizing remains unsupported: the existing setting accepts an absolute size or inherits the full editor font size, not a configurable percentage. Keep this team-authored Backlog request open; neither the extension workaround nor the related appearance issues completes it.

## Change summary

Allow inlay-hint text to remain proportionally smaller than editor text when the editor font size changes.

## Best solution

Have the inlay-hints owner decide whether to support user-controlled relative sizing while preserving existing absolute-size behavior. Retain the thread's distinction between user styling preferences and extension-imposed language-specific defaults.

- **Current rendering behavior:** src/vs/editor/contrib/inlayHints/browser/inlayHintsController.ts:747–765, InlayHintsController._getLayoutInfo, uses the configured absolute font size; zero, values below 5, and values above the editor font size fall back to the full editor font size.
