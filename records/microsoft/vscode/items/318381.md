# Issue #318381 — Add a setting to not resolve shell configuration and not inherit environment from cli

[https://github.com/microsoft/vscode/issues/318381](https://github.com/microsoft/vscode/issues/318381)

## Summary

Keep open as a feature request: existing controls can skip shell-environment resolution or change terminal inheritance, but do not provide the requested application-wide opt-out from the launching CLI environment. No verified older canonical covers both parts of the request.

## Change summary

Provide a setting that prevents shell configuration resolution and isolates VS Code from environment variables inherited from its CLI launcher.

## Best solution

Decide whether VS Code should expose an application-level environment-isolation mode, with explicit semantics for essential OS variables and extension-host inheritance. Existing shell-resolution and terminal-only controls should not be presented as satisfying the broader request.
