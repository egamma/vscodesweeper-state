# Issue #346470 — Copilot Fusion: Option to select model family

[https://github.com/microsoft/vscode/issues/346470](https://github.com/microsoft/vscode/issues/346470)

## Summary

Keep open as a feature request: existing model choices and Fusion effort levels do not provide automatic routing restricted to a selected model family. The related model-configuration proposal does not explicitly cover this capability.

## Change summary

Allow Copilot Fusion to route within a selected model family while retaining unrestricted Auto as an option.

## Best solution

Evaluate a family restriction within Fusion's existing model configuration, preserving unrestricted routing by default. Treat the comment's complexity-specific model preferences as an additional design request rather than an already-agreed requirement.
