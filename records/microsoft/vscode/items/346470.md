# Issue #346470 — Copilot Fusion: Option to select model family

[https://github.com/microsoft/vscode/issues/346470](https://github.com/microsoft/vscode/issues/346470)

## Summary

Keep open as a feature request: existing Fusion effort controls do not let users restrict automatic selection to a model family. The related model-configuration proposal does not cover this specific routing preference.

## Change summary

Allow Copilot Fusion to select models within a chosen family while retaining unrestricted Auto behavior.

## Best solution

Consider a runtime-supported family preference exposed through Fusion's existing model picker, preserving unrestricted Auto by default and respecting model availability and managed restrictions. Treat complexity-specific model assignments from the comment as an additional design request, not an established requirement.
