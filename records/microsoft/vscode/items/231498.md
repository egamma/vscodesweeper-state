# Issue #231498 — SCM - Git commit view: Show message on top of diffs

[https://github.com/microsoft/vscode/issues/231498](https://github.com/microsoft/vscode/issues/231498)

## Summary

Keep open: the commit diff editor still lacks a persistent full-message display, and the existing hover and editor title do not cover the request. A related multi-diff view-zone request is newer and cannot serve as a duplicate canonical for this re-reviewed item.

## Change summary

Display the full commit message above its diffs in a collapsible, height-limited region with scrolling.

## Best solution

Provide persistent commit-message context in the SCM history diff editor without requiring the graph hover to remain open. Coordinate the design with https://github.com/microsoft/vscode/issues/242279 while preserving this issue's specific collapse and scrolling requirements.
