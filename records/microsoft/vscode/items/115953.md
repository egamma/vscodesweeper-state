# Issue #115953 — Search: Arrow navigation broken

[https://github.com/microsoft/vscode/issues/115953](https://github.com/microsoft/vscode/issues/115953)

## Summary

Keep open: clearing the Search input still discards a not-yet-recorded query, and clearing a recalled query leaves the history cursor positioned to skip it on the next Up Arrow. The thread contains a maintainer confirmation, and current source exposes both paths.

## Change summary

Preserve access to the most recent search string through arrow-key history after clearing search results, including repeated clear-and-recall cycles.

## Best solution

Make Search's clear-and-recall behavior reliably recover the cleared query without skipping history entries. Keep this bounded to Search input history; restoring native Ctrl+Z behavior for programmatic edits is a separate concern.
