# Issue #328533 — Missing confirmation for subagent tool after steering

[https://github.com/microsoft/vscode/issues/328533](https://github.com/microsoft/vscode/issues/328533)

## Summary

The defect remains on main: steering replaces the observed turn and disposes the graph exposing the subagent confirmation. This team-authored issue should remain open.

## Change summary

A tool confirmation requested by a running subagent is no longer exposed in the parent chat after the user sends a steering message.

## Best solution

Surface session-level `inputNeeded` entries independently of the currently observed turn in `agentHostSessionHandler.ts`, preserving the originating subagent chat URI when dispatching the answer.
