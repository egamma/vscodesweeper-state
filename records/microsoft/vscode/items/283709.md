# Issue #283709 — Expanded run notebook cell confirmation does not show full cell content

[https://github.com/microsoft/vscode/issues/283709](https://github.com/microsoft/vscode/issues/283709)

## Summary

The mismatch remains in current source: expanding the confirmation reveals a cell preview that was already truncated before rendering. Keep this team-authored polish issue open; the original discussion explicitly raises a design constraint around arbitrarily long cells.

## Change summary

Make expanded notebook-cell execution confirmations provide complete review context rather than ending unexpectedly with an ellipsis.

## Best solution

Make the confirmation's expansion affordance accurately communicate what it reveals and provide an explicit way to inspect the complete cell before approval. Settle whether complete content belongs inside the expanded confirmation or in the linked notebook, accounting for very large cells.
