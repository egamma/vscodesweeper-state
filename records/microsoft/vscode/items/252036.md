# Issue #252036 — Markdown link intellisense starting directory

[https://github.com/microsoft/vscode/issues/252036](https://github.com/microsoft/vscode/issues/252036)

## Summary

Legitimate feature request for a configurable root directory for markdown link path completions — no existing setting covers this, and no duplicate was found. Stays open in Backlog Candidates for the community process.

## Change summary

Allow configuring the starting directory for markdown link intellisense so tools like mkDocs can use a subdirectory (e.g. /docs) as the link root.

## Best solution

Add a setting like `markdown.links.pathCompletionRoot` to the markdown-language-features extension that lets users specify a workspace-relative directory as the base for link path completions. This would live in the markdown language service's path completion provider.
