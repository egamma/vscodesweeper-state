## Summary

Keep open in the Markdown backlog: the existing completion settings do not expose the requested configurable link root. The older image-root request concerns preview rendering, not the same observable completion behavior, so it is related rather than a verified duplicate.

## Change summary

Allow Markdown link IntelliSense to use a configurable content root such as a MkDocs project's docs directory.

## Best solution
