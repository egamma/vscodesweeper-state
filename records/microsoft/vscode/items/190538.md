## Summary

Valid display bug in the Keyboard Shortcuts table view — the Period key label renders as `<` instead of `.` or `>`. The underlying keybinding mapper code (macLinuxKeyboardMapper.ts) hasn't changed since the report; no fix commit exists. The reproduction depends on the specific keyboard layout data reported by the Linux OS at runtime, which makes it hard to verify from source alone.

## Change summary

The Keyboard Shortcuts table view displays `Ctrl + Shift + <` instead of the correct `Ctrl + Shift + .` (or `>`) for a user-defined keybinding, despite keybindings.json storing it correctly.

## Best solution

A test with the reporter's actual layout data would confirm.
