# Issue #350358 — Agents window: Submit Feedback discards the message being typed in the chat input

[https://github.com/microsoft/vscode/issues/350358](https://github.com/microsoft/vscode/issues/350358)

## Summary

The current source confirms that submitting feedback clears an unrelated, unsent chat draft. Keep this open; a related open PR proposes draft preservation for agent-host submissions, but does not establish a complete, landed fix.

## Change summary

Submitting review feedback erases the chat draft without sending or recording its text.

## Best solution

Feedback submission should preserve unrelated draft text and attachments while delivering the feedback and retaining acceptance, queueing, and failure-recovery behavior. Review the overlapping draft-preservation work in https://github.com/microsoft/vscode/pull/347192 and ensure coverage also includes non-agent-host submissions and Alt+Enter.
