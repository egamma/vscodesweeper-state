# Issue #314080 — No progress shown between terminal prompts

[https://github.com/microsoft/vscode/issues/314080](https://github.com/microsoft/vscode/issues/314080)

## Summary

Keep this accepted, team-authored request open: current terminal tools provide individual invocation messages and running indicators, but those do not establish continuous feedback between interactive prompts. No verified canonical or issue-referencing fix was found.

## Change summary

Show reassuring progress while an agent handles successive prompts from an interactive terminal command.

## Best solution

Make the chat-terminal workflow visibly distinguish waiting for the next prompt, processing an answer, and waiting for user input throughout an interactive command. First establish which transition in the reported multi-prompt flow loses feedback; existing per-tool messages should not be mistaken for coverage of the whole interaction.
