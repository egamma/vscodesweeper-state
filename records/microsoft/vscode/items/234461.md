# Issue #234461 — Make "Reopen editor with" have a higher priority than the "editor.defaultBinaryEditor" setting.

[https://github.com/microsoft/vscode/issues/234461](https://github.com/microsoft/vscode/issues/234461)

## Summary

The confirmed bug remains on current main: an explicit “Reopen Editor With” choice of the text editor is discarded when binary detection redirects the file to `workbench.editor.defaultBinaryEditor`.

## Change summary

Make an explicit editor choice from “Reopen Editor With” take precedence over the configured default binary editor.

## Best solution

Honor the explicitly selected editor for that open operation while retaining `workbench.editor.defaultBinaryEditor` for ordinary binary-file opens that have no explicit override.
