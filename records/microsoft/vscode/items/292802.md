# Issue #292802 — Two edits on the same sensitive file appears are two separate files

[https://github.com/microsoft/vscode/issues/292802](https://github.com/microsoft/vscode/issues/292802)

## Summary

The misleading duplicate-file presentation remains reproducible from current source: each sensitive-edit diff fence creates an independent diff part, even when multiple fences identify the same resource.

## Change summary

Multiple edits to separate regions of one sensitive file are presented as edits to multiple files in the approval UI.

## Best solution

Render all sensitive-edit hunks for the same resource as one file-level confirmation entry while preserving each changed region and the existing approval behavior.
