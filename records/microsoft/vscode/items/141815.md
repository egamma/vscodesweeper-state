# Issue #141815 — Highlight current word in json sometimes matches a single double quote

[https://github.com/microsoft/vscode/issues/141815](https://github.com/microsoft/vscode/issues/141815)

## Summary

The quote-only word match is resolved by the landed change that removed JSON's quoted-token word pattern. JSON now uses natural-word boundaries rather than treating an entire quoted string as a word.

## Change summary

Placing the cursor after the closing quote of a JSON string sometimes highlights every quotation mark instead of the string.

## Best solution

Retain the natural-word behavior introduced by https://github.com/microsoft/vscode/commit/375681e51e14b2a1c6c2ad83d80663d2a65560d6 and close this quote-matching defect as completed; whole-string word matching is no longer the intended JSON behavior.
