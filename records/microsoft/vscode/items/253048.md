## Summary

Keep open under discussion: current VS Code provides explicit instruction-generation commands, but they do not address the reported GitHub Coding Agent behavior when a natural-language issue asks generically for Copilot instructions.

## Change summary

Make GitHub Copilot Coding Agent infer that a request for repository-level Copilot instructions should create `.github/copilot-instructions.md` without requiring the exact path.
