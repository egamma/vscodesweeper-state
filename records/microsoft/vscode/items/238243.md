# Issue #238243 — macOS titlebar/windowTitle cuts large paths

[https://github.com/microsoft/vscode/issues/238243](https://github.com/microsoft/vscode/issues/238243)

## Summary

A real title-bar usability gap remains on current main: the Command Center has a fixed responsive width and ellipsizes long titles despite potentially unused space. The requested configurable width and alignment do not exist, and no verified canonical reports the same observable symptom.

## Change summary

Allow long macOS window titles to use more available title-bar space, with optional control over title width and alignment.

## Best solution

Make the title-bar center allocation adapt to the actual space left by menus and controls so long titles use available room without disrupting surrounding actions; title-bar owners should decide whether a separate alignment setting is warranted or whether responsive layout alone should solve the central problem.

## Evidence

- **current layout:** src/vs/workbench/browser/parts/titlebar/media/titlebarpart.css assigns the centered title region 60% of the title bar and gives the Command Center a width of 38vw capped at 600px; `.search-label` uses ellipsis overflow, so long configured titles remain truncated.
- **missing configuration:** src/vs/workbench/browser/workbench.contribution.ts registers `window.title`, `window.titleSeparator`, and the boolean `window.commandCenter`, but no title-width or `window.title.align` setting.
- **related issue:** https://github.com/microsoft/vscode/issues/236302 is older but reports the opposite observable problem—an overly wide center region hiding menu items in smaller windows—so it is not a same-symptom canonical under the re-review duplicate rule.
- **related width request:** https://github.com/microsoft/vscode/issues/171301 is an older request to match the Command Center and Command Palette widths, but it does not own this report's macOS long-path truncation and alignment requirements.
- **alignment remains unsettled:** Current compact agent-control mode left-aligns the Command Center label in src/vs/workbench/browser/parts/titlebar/commandCenterControl.ts and titlebarpart.css, while https://github.com/microsoft/vscode/issues/307224 reports that mode-dependent alignment as inconsistent; this is not a general user-selectable title alignment.
