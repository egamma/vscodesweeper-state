# Issue #265248 — Empty chat view after disabling copilot chat extension

[https://github.com/microsoft/vscode/issues/265248](https://github.com/microsoft/vscode/issues/265248)

## Summary

The view-management defect remains visible in current source, and the linked draft PR is still open. Keep the issue open while https://github.com/microsoft/vscode/pull/266219 is reviewed or replaced.

## Change summary

Disabling Copilot Chat and reloading leaves an empty Chat container in the Secondary Side Bar until the sidebar is collapsed.

## Best solution

Finish the view-management fix so a hide-if-empty container closes when context-key changes deactivate its last view, while reopening it when a view becomes active again; review and land or supersede https://github.com/microsoft/vscode/pull/266219.
