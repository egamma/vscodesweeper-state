## Summary

This is a valid, broader chat-navigation request not fully covered by existing work. Route it to the chat and Agents window owners for design discussion.

## Change summary

Add a chat overview ruler showing the viewport, user and assistant turns, context consumption, and failed operations.

## Best solution

Build on the existing Agents window prompt-timeline rail and the open Chat View marker PR, ideally sharing a ruler abstraction across both surfaces. Context and failure layers need separate UX and data-model decisions rather than additional independent settings by default.
