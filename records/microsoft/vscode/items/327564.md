## Summary

Current main partially addresses transcript navigation with an Agents-window prompt timeline and a separate context-usage widget, but it does not provide assistant-turn demarcation, historical context heat, or error markers. The broader request remains distinct and should be routed to the chat area rather than closed as a duplicate.

## Change summary

Add an interactive chat overview ruler showing viewport position, user and assistant turns, context growth, and failed turns across chat surfaces.

## Best solution

Preserve keyboard navigation and accessible text equivalents rather than making color or pointer interaction the only way to consume the information.
