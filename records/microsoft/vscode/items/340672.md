# Issue #340672 — Claude agent: skills from VS Code agent plugins are not suggested before the first message

[https://github.com/microsoft/vscode/issues/340672](https://github.com/microsoft/vscode/issues/340672)

## Summary

Thanks for the detailed report and analysis. The source confirms it: Claude's getSessionCustomizations returns synced plugin customizations without children, and the slash-completion provider skips customizations that have no children. Codex attaches children via parsedPluginChildren.

## Change summary

Claude harness doesn't suggest skills from synced VS Code agent plugins as slash completions until after the first message.

## Best solution

In claudeAgentSession, parse synced plugins and attach children to the projected synced plugin customizations, reusing the Codex parsedPluginChildren helper (moved to a shared location).
