# Issue #264752 — Git commit suggestions in terminal aren't very useful without expansion

[https://github.com/microsoft/vscode/issues/264752](https://github.com/microsoft/vscode/issues/264752)

## Summary

The requested inline commit-title preview remains missing: current code sends the subject to expanded documentation, not the suggestion row. Keep this accepted Backlog request open; the older description-visibility report concerns command flags rather than the same reporter-observable symptom.

## Change summary

Show a commit-subject preview beside each hash in terminal suggestions without requiring the details panel.

## Best solution

Git commit suggestions should display an inline subject preview while continuing to insert only the commit hash and retaining full documentation in the details panel. Address this in the bundled terminal-suggest provider using the existing suggestion-row presentation capabilities.
