# Issue #188782 — Default themes (light+, dark+, etc) support indent colorization

[https://github.com/microsoft/vscode/issues/188782](https://github.com/microsoft/vscode/issues/188782)

## Summary

The default themes still only define a single indent guide color (background1/activeBackground1) rather than the multi-color (1–6) colorization matching bracket pairs. The request remains unimplemented on main — keeping open as a polish item for the themes area.

## Change summary

Add multi-color indent guide colorization (background1–6, activeBackground1–6) to VS Code's default themes, matching bracket pair colors.

## Best solution

Add bracket-pair-matching indent guide colors (editorIndentGuide.background1–6 and activeBackground1–6) to Dark Modern, Light Modern, Dark+, and Light+ theme JSON files in extensions/theme-defaults/themes/. A design review with the themes owner would determine the exact palette.
