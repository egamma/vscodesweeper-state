# Issue #188782 — Default themes (light+, dark+, etc) support indent colorization

[https://github.com/microsoft/vscode/issues/188782](https://github.com/microsoft/vscode/issues/188782)

## Summary

The default-theme palette request remains unimplemented: per-level indent colors are configurable, but the bundled themes still use a single neutral indent color. Keep this team-authored, accepted backlog item open for a theme-design decision.

## Change summary

Give the default themes multicolor indentation guides with palettes consistent with bracket-pair colorization.

## Best solution

Agree on active and inactive indentation palettes for the bundled light and dark themes, then deliver them through the existing per-level theme colors without requiring user customization or a new rendering mechanism.

## Plan brief

- **Likely files:** `extensions/theme-defaults/themes/dark_vs.json`, `extensions/theme-defaults/themes/light_vs.json`, `extensions/theme-defaults/themes/dark_plus.json`, `extensions/theme-defaults/themes/light_plus.json`, `extensions/theme-defaults/themes/dark_modern.json`, `extensions/theme-defaults/themes/light_modern.json`, `extensions/theme-defaults/themes/2026-dark.json`, `extensions/theme-defaults/themes/2026-light.json`
- **Validation:** After agreeing on the palette, inspect a bracketless Python sample with at least six indentation levels in each selected bundled theme without workbench.colorCustomizations. Confirm the intended repeating palette, active-guide distinction, and readability; verify explicit user color overrides and bracket-pair guides remain unchanged.
- **Behavior:**

  > The selected bundled themes should display distinguishable indentation-level colors without requiring manual color customization. The palette should be visually consistent with bracket-pair colorization while keeping inactive guides quiet and the active guide recognizable. Acceptance should cover nested indentation in a bracketless language, light and dark theme variants, and preservation of explicit user overrides.
- **Trace:**

  > The existing implementation already exposes editorIndentGuide.background1–6 and activeBackground1–6 in src/vs/editor/common/core/editorColorRegistry.ts. The theming participant in src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts cycles nontransparent color pairs independently of bracket-pair colors. Dark+ and Light+ inherit their single neutral pair from dark_vs.json and light_vs.json; modern and 2026 variants have additional inheritance and overrides to consider. https://github.com/microsoft/vscode/pull/178112 supplies the mechanism but not the requested defaults. Keep the existing rendering, guide settings, and user-customization contracts unchanged. The unresolved boundary is the intended palette and which bundled variants should adopt it, not how to implement color cycling.
- **Open decisions:**
  - Should active indentation colors match bracket-pair foregrounds exactly, and what subdued palette should inactive indentation guides use?
  - Which bundled theme variants should adopt multicolor indentation by default, particularly modern, 2026, and high-contrast themes?

## Evidence

- **Existing capability does not fulfill the request:** https://github.com/microsoft/vscode/pull/178112 merged on 2023-07-05 and introduced configurable per-level indent colors before this issue was filed. The issue explicitly acknowledges that capability and requests bundled default palettes instead; manual color overrides are therefore a workaround, not completion.
- **Current default themes:** extensions/theme-defaults/themes/dark_plus.json includes dark_vs.json, and light_plus.json includes light_vs.json. dark_vs.json defines only editorIndentGuide.background1 (#404040) and activeBackground1 (#707070); light_vs.json likewise defines only background1 (#D3D3D3) and activeBackground1 (#939393). Searching the bundled theme JSON files found no per-level indent palette for levels 2–6.
- **Current rendering path:** src/vs/editor/common/core/editorColorRegistry.ts defaults editorIndentGuide.background2–6 and activeBackground2–6 to transparent. The theming participant in src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts filters transparent indent-color pairs and cycles the remaining pairs by level, so the default single pair repeats rather than inheriting bracket colors.
- **Settings boundary:** src/vs/editor/common/config/editorOptions.ts registers editor.guides.indentation and editor.guides.bracketPairs separately. Enabling bracket-pair guides does not supply a multicolor palette for indentation-only structure.
- **Discussion and remaining decision:** https://github.com/microsoft/vscode/issues/188782#issuecomment-1650368396 asks whether the palettes should match bracket colors exactly. The author prefers consistency but remains open to experimentation, and the subsequent contributor comment supplies a concrete Dark+ palette with separate active and inactive colors.
