# Issue #195768 — Terminal profile default discovery isn't working as expected

[https://github.com/microsoft/vscode/issues/195768](https://github.com/microsoft/vscode/issues/195768)

## Summary

Keep open: the discussion confirms that Dock-launched VS Code can drop Homebrew fish from terminal profiles when shell-environment resolution fails or omits Homebrew from PATH. The current source retains that lookup behavior, and an open fixing PR should be reviewed before considering closure.

## Change summary

Discover the user's installed login-shell profile even when its executable directory is absent from the GUI-launched process's resolved PATH.

## Best solution

Review https://github.com/microsoft/vscode/pull/339556 against the reported missing-profile and stale-SHELL scenarios, including preservation of normal PATH precedence. Keep this reopened issue open until the implementation is accepted and merged.
