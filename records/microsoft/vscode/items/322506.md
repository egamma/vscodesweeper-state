## Summary

Valid feature request for configurable agent-host discovery paths. Related to but distinct from the `.agents` directory tracking issue (#292410) — this specifically asks for a user-facing setting to override hardcoded search roots, which neither the tracking issue nor #326789 fully absorbs.

## Change summary

Allow users to configure the directories the agent host scans for agents, skills, and instruction files, instead of relying on hardcoded paths.

## Best solution

Route to the chat-prompts area for evaluation.
