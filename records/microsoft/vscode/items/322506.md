# Issue #322506 — [Feature Request] Allow configuring Copilot agent/skill/instruction discovery paths via settings

[https://github.com/microsoft/vscode/issues/322506](https://github.com/microsoft/vscode/issues/322506)

## Summary

A real configurability gap remains in the Agent Host, but the request has no direct community traction and needs product discussion around the configuration contract. The related issues cover standardized `.agents` defaults rather than arbitrary discovery roots, so neither is a valid duplicate canonical.

## Change summary

Allow workspace and user settings to add custom Agent Host discovery paths for agents, skills, instructions, and related instruction files.

## Best solution

Define one trusted, typed customization-location contract shared with the Agent Host, preserving the existing defaults while supporting workspace-relative and user-home paths. It should integrate with the current customization configuration flow rather than copy the deprecated Local-harness-only location settings.
