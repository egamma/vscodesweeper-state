# Issue #272828 — Chat response: consistently render code as Code

[https://github.com/microsoft/vscode/issues/272828](https://github.com/microsoft/vscode/issues/272828)

## Summary

The screenshot confirms that code-like output can arrive as plain Markdown instead of inline or fenced code. Current prompts request Markdown formatting but do not consistently state or enforce the rule across every model path, and no eligible canonical or concrete fixing commit was found.

## Change summary

Make Copilot Chat consistently format code identifiers and snippets as inline or fenced Markdown code.
