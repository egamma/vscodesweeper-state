Community pushback on the opt-out Modern UI rounded-corners experiment; the setting to disable it already exists, so this is design feedback for the modernization team to weigh, not a defect to fix or a mechanical close.

## Change summary

Reporter (and several commenters) object to the new rounded-corner / margin styling introduced by the Modern UI experiment and ask that it not ship as default.
