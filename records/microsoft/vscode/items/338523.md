# Issue #338523 — "\b" search (with regex enabled) will report false positives if next letter contains diacritics

[https://github.com/microsoft/vscode/issues/338523](https://github.com/microsoft/vscode/issues/338523)

## Summary

The reported match follows JavaScript regular-expression semantics: ä is not a word character for \b, even with Unicode mode enabled. The existing Match Whole Word option covers the stated goal without changing regex syntax.

## Change summary

Treat accented letters as word characters when searching for standalone B rather than matching the B in Bänder.

## Best solution

Preserve standard JavaScript regex semantics. For this search, use literal B with Match Whole Word enabled; the editor's whole-word filtering uses editor.wordSeparators rather than regex \b.

- **Proposed comment:**

  > Thanks for the report. Regex search follows JavaScript semantics: `\b` uses the regex definition of a word character, which does not include `ä`, even in Unicode mode. Consequently, `\bB\b` matches the `B` in `Bänder` as designed.
  > 
  > To select standalone `B` in the editor, turn off regex search, enter `B`, and enable **Match Whole Word** (`toggleFindWholeWord`). This uses `editor.wordSeparators` and excludes `Bänder` with the default settings.
