# Issue #347583 — Add a basic main menu to the Agents window

[https://github.com/microsoft/vscode/issues/347583](https://github.com/microsoft/vscode/issues/347583)

## Summary

Keep open: the Agents window registers main-menu contents, but its custom title bar does not expose a menu. Existing native-menu support and Command Palette actions only partially cover the requested discoverable Help menu on Windows.

## Change summary

Expose a basic main menu in the Agents window, including discoverable help and diagnostic actions.

## Best solution

Provide a keyboard-accessible Help menu in the Agents window's custom-titlebar experience, reusing existing menu contributions. Decide the initial menu scope without requiring users to switch windows or change title-bar styles.

## Evidence

- **Existing menu contents:** src/vs/sessions/browser/parts/menubar.contribution.ts registers File, Edit, Selection, View, Go, Terminal, and Help under MenuId.MenubarMainMenu; src/vs/sessions/sessions.common.main.ts imports this contribution. Registered contents alone do not provide a visible custom menu.
- **Custom-titlebar gap:** src/vs/sessions/browser/parts/titlebarPart.ts explicitly describes a title bar with no menubar. src/vs/sessions/browser/workbench.ts:3361 implements toggleMenuBar() as a no-op, so the existing toggle does not expose the requested surface.
- **Native-menu capability:** src/vs/sessions/electron-browser/sessions.main.ts:148-149 creates NativeMenubarControl only on macOS or when hasNativeMenu() is true. src/vs/platform/window/common/window.ts ties native-menu availability on Windows to native title-bar/menu configuration; this does not supply a menu within the custom-titlebar experience.
- **Partial alternative:** src/vs/sessions/sessions.common.main.ts imports workbench/browser/actions/helpActions.ts, where workbench.action.openDocumentationUrl is registered with f1: true and contributes to MenubarHelpMenu. Documentation is therefore available through the Command Palette, but this does not satisfy the requested discoverable main menu.
