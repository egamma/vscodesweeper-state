# Issue #347583 — Add a basic main menu to the Agents window

[https://github.com/microsoft/vscode/issues/347583](https://github.com/microsoft/vscode/issues/347583)

## Summary

Keep open: the Agents window registers main-menu contents, but its custom title bar does not render a main menu. Existing native-menu support does not fully cover the requested Windows experience.

## Change summary

Provide a discoverable main menu in the Agents window, including standard help and diagnostic actions.

Expose the existing shared menu infrastructure from the Agents window's custom title bar, with an appropriate Help menu. Maintainers should settle the initial menu scope while preserving existing native-menu behavior.
