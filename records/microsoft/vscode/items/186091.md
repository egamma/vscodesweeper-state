# Issue #186091 — auto jump to first conflict when open file from source control panel

[https://github.com/microsoft/vscode/issues/186091](https://github.com/microsoft/vscode/issues/186091)

## Summary

Valid feature request: auto-scroll to the first inline merge conflict marker when opening a file from the SCM panel. The merge editor already does this (scrolls to first conflict on open), but the regular text editor with inline conflict markers does not. Still unimplemented on main.

## Change summary

Auto-jump to the first merge conflict marker when opening a conflicted file from the source control panel.

## Best solution

Implement auto-navigation to the first conflict in the `extensions/merge-conflict` built-in extension (or in the SCM open-file flow) when a file with conflict markers is opened from the SCM panel, aligning with the diff editor's existing auto-scroll-to-first-change behavior. The `merge-conflict.next` command infrastructure already exists in `extensions/merge-conflict/src/commandHandler.ts`.
