# Issue #316997 — [Bug] Incomplete Sanitization in searchIntent.ts: Unescaped Backtick Breaks Markdown Table Cell in Copilot Search Results

[https://github.com/microsoft/vscode/issues/316997](https://github.com/microsoft/vscode/issues/316997)

## Summary

Current main still embeds pipe-escaped values inside a single-backtick Markdown code span, so a value containing a backtick can corrupt the rendered table. Although the demonstrated impact is limited to formatting, the report describes an injection concern and must remain open for human security handling.

## Change summary

Ensure Copilot search-result parameters containing backticks cannot break Markdown table cells or inline-code spans.

## Best solution

Make `jsonToTable` serialize arbitrary parameter values without allowing Markdown delimiters to alter the table structure, with focused coverage for backticks, pipes, and combined inputs.
