# Issue #170670 — Inlay hints request sent on both press and release hotkey

[https://github.com/microsoft/vscode/issues/170670](https://github.com/microsoft/vscode/issues/170670)

## Summary

Current source still schedules inlay-hint requests on both modifier press and release. Keep the existing discussion open: the maintainer confirmed the behavior but left unresolved whether the extra request warrants changing.

## Change summary

Avoid an additional inlay-hint provider request when releasing Ctrl+Alt in offUnlessPressed mode.

## Best solution

Determine whether hiding hints needs a provider refresh or can safely reuse the existing hints without extra requests. Any optimization should preserve hint freshness and both modifier-controlled visibility modes in InlayHintsController.
