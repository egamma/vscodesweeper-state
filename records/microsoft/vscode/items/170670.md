# Issue #170670 — Inlay hints request sent on both press and release hotkey

[https://github.com/microsoft/vscode/issues/170670](https://github.com/microsoft/vscode/issues/170670)

## Summary

Still present on main: when using `offUnlessPressed`, releasing the Ctrl+Alt hotkey triggers a redundant inlay hints provider request even though hints are about to be hidden. The guard at line 214 correctly prevents duplicate mode-change events, but both press and release are genuine mode changes (Invisible→Normal and Normal→Invisible), each scheduling a server request via `scheduler.schedule(0)`. The release-time request is unnecessary overhead since the result will be rendered invisible.

## Change summary

In `offUnlessPressed` mode, releasing the Ctrl+Alt hotkey sends a redundant inlay hints request to the language server even though the hints will be hidden.

## Best solution

In `inlayHintsController.ts` around line 219, skip `scheduler.schedule(0)` when the new render mode is `RenderMode.Invisible` — the cached hints are sufficient for hiding, no fresh server request needed. This is a small perf optimization that avoids wasted server round-trips on every hotkey release.
