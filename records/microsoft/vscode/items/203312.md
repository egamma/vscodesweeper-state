[https://github.com/microsoft/vscode/issues/203312](https://github.com/microsoft/vscode/issues/203312)

## Summary

The inline layout still constructs independently highlighted hidden-line drag controls in both editor columns, operating on the same unchanged region. Keep this accepted diff-editor bug open; no verified fix or older canonical owns this specific duplicated-control symptom.

## Change summary
