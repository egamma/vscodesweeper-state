# Issue #288177 — Failed to copy 1 file to worktree

[https://github.com/microsoft/vscode/issues/288177](https://github.com/microsoft/vscode/issues/288177)

## Summary

Team-authored polish issue: the warning message for failed worktree file copies is not actionable — it doesn't name the failing file or suggest what to do. Still present on current main (line 2111 of extensions/git/src/repository.ts shows the generic warning). Keeping open for improvement.

## Change summary

The 'Failed to copy N file(s) to worktree' warning is too generic and not actionable for the user.

## Best solution

Improve the warning message to include the failing file path(s) and/or suppress warnings for known-benign failures (like .asar files in node_modules), or at minimum link to the Git output log so users don't have to hunt.
