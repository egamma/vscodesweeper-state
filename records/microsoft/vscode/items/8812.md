# Issue #8812 — request: ease-out transition for TextEditorDecorationType (extension API)

[https://github.com/microsoft/vscode/issues/8812](https://github.com/microsoft/vscode/issues/8812)

## Summary

The extension API still lacks timed fading for editor decorations. Keep this accepted Backlog request open: the reporter's workaround removes the highlight abruptly, and the maintainer identified rendering constraints rather than declining the capability.

## Change summary

Allow extensions to apply a brief highlight that fades out smoothly through TextEditorDecorationType.

## Best solution

If pursued, provide a bounded transient-highlight capability whose timing survives viewport changes and decoration rerendering without sacrificing editor performance. Establish those observable lifecycle semantics before exposing a general CSS transition option.
