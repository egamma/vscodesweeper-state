# Issue #8812 — request: ease-out transition for TextEditorDecorationType (extension API)

[https://github.com/microsoft/vscode/issues/8812](https://github.com/microsoft/vscode/issues/8812)

## Summary

A real extension API gap remains, but the requested CSS transition conflicts with the editor's virtualized decoration lifecycle. Keep it open for API design rather than closing based on age or the partial workaround.

## Change summary

Allow extensions to display a text-editor decoration that fades out after briefly highlighting a range.

## Best solution

Design a lifecycle-aware, one-shot decoration effect that preserves editor virtualization and avoids restarting animations when lines are rerendered; otherwise formally document the timed-disposal workaround.
