# Issue #342514 — `code -w -g file:line` does not exit when the tab is closed (`code serve-web` only)

[https://github.com/microsoft/vscode/issues/342514](https://github.com/microsoft/vscode/issues/342514)

## Summary

Confirmed in current source: the browser opens the file after stripping the line/column suffix, but waits for the original suffixed URI to close. Closing the actual tab therefore never releases the waiting CLI process; this is correctly routed to workbench-cli.

## Change summary

Make browser-hosted `code --wait --goto file:line` exit after the requested file's editor closes.

## Best solution

The browser host's wait tracking should identify the same resource that its goto handling opens, while preserving cursor placement and existing editor-close/save semantics.
