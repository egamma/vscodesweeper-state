# Issue #275360 — Clone a repro when opening a PR

[https://github.com/microsoft/vscode/issues/275360](https://github.com/microsoft/vscode/issues/275360)

## Summary

Team-authored feature request to offer a clone flow when opening a PR from an unenrolled repo. The related implementation PR in vscode-pull-request-github was closed without merging, so this remains unimplemented. Stays open for the area owner.

## Change summary

When opening a PR via URI handler for a repo not locally cloned, VS Code should offer to clone the repo first and then open the PR.

## Best solution

Implement the clone-then-open-PR flow in the GitHub Pull Requests extension (vscode-pull-request-github). The URI handler that processes PR open requests should detect when the repo isn't locally available and trigger the standard clone flow before proceeding. The closed PR https://github.com/microsoft/vscode-pull-request-github/pull/8412 was an attempt at this — a new implementation attempt in that extension is the right path.
