# Issue #322651 — Org-managed policy distribution and audit

[https://github.com/microsoft/vscode/issues/322651](https://github.com/microsoft/vscode/issues/322651)

## Summary

Legitimate enterprise governance feature request for centrally managed and auditable Copilot agent policies. Aligns with current enterprise-management priorities but is broad and spans VS Code core and GitHub service-side concerns; routing to the policy area for triage.

## Change summary

Add org-level policy pack distribution, versioning, override visibility, and audit logging for Copilot agent workflows.

## Best solution

Clarify scope: the VS Code side would extend the existing policy infrastructure (src/vs/platform/policy/) to consume org-pushed Copilot agent policy packs and surface version/override visibility in settings UI. The audit-trail and org-level push mechanisms likely live on the GitHub/Copilot service side. A maintainer should decide which pieces belong in VS Code core vs. the service, and whether the closed https://github.com/microsoft/vscode/issues/274341 and https://github.com/microsoft/vscode/issues/261462 already cover parts of this ask.
