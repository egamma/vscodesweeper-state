# Issue #270937 — Graphical lock-out bugs with scaling enabled (Ubuntu 25.10)

[https://github.com/microsoft/vscode/issues/270937](https://github.com/microsoft/vscode/issues/270937)

## Summary

Keep open: the report and independent scaling-toggle workaround support a real loss of pointer interaction after mixed-scale monitor transitions. No concrete fix or older canonical owning this exact failure was established.

## Change summary

Moving VS Code between 125% and 100% displays on Ubuntu Wayland leaves much of the window unclickable, including notifications, Chat, and portions of menus.

## Best solution

Restore correct pointer hit testing across mixed-scale monitor transitions, first isolating whether the mismatch originates in the renderer or Electron/Wayland window input handling. Preserve fractional scaling rather than requiring users to disable it.
