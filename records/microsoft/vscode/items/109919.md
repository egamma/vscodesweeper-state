# Issue #109919 — getLanguageConfiguration() API method is missing

[https://github.com/microsoft/vscode/issues/109919](https://github.com/microsoft/vscode/issues/109919)

## Summary

Legitimate, well-upvoted API feature request (38 upvotes) that has been accepted into the Backlog with `api-proposal` label but has no implementation or proposed API definition on current main. Should remain open.

## Change summary

Expose a `getLanguageConfiguration()` API method in the `vscode.languages` namespace so extensions can read language configuration (comments, brackets, etc.) for a given language ID.

## Best solution

Design and ship a proposed `vscode.languages.getLanguageConfiguration(languageId)` API returning a read-only subset of `LanguageConfiguration` (comment rules, brackets, autoClosingPairs). The internal `ILanguageConfigurationService.getLanguageConfiguration()` already exists and powers editor features — the work is defining the public API surface and wiring a proxy through the extension host. A proposed API `.d.ts` file (`vscode.proposed.languageConfiguration.d.ts`) is the natural next step.
