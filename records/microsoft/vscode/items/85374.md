# Issue #85374 — Option to widen the command palette

[https://github.com/microsoft/vscode/issues/85374](https://github.com/microsoft/vscode/issues/85374)

## Summary

Keep open: current main still limits ordinary Quick Open and Command Palette width, and linked resize PRs remain unmerged. This well-supported backlog request needs review of the existing contributions, not another competing implementation.

## Change summary

Allow widening Quick Open and the Command Palette so long file paths can be distinguished without hovering over individual results.

## Best solution

Review the existing resize contributions and settle on a supported way to widen the shared quick-input widget within window bounds. Assess whether persistent manual resizing adequately covers the original request for automatic sizing or an explicit width option.
