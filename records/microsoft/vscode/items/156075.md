# Issue #156075 — [Emmet] per-language "Trigger expansion on tab" 

[https://github.com/microsoft/vscode/issues/156075](https://github.com/microsoft/vscode/issues/156075)

## Summary

Still broken on main: the fix (PR #157035) was reverted in commit 50140a53cc2 because it broke command-palette expansion, and no replacement fix was landed. The setting is declared language-overridable but the code reads it without a language/document scope, so per-language overrides have no effect on tab expansion.

## Change summary

Per-language override of `emmet.triggerExpansionOnTab` doesn't work because the code reads the setting without a document scope.

## Best solution

Re-implement language-scoped config reads at lines 304 and 421 of `extensions/emmet/src/abbreviationActions.ts`, passing the active editor's document to `getConfiguration('emmet', editor.document)`, while distinguishing keybinding-triggered vs command-palette-triggered invocations (the unsolved problem from comment 6).
