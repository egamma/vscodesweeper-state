# Issue #156075 — [Emmet] per-language "Trigger expansion on tab" 

[https://github.com/microsoft/vscode/issues/156075](https://github.com/microsoft/vscode/issues/156075)

## Summary

Per-language Tab expansion remains broken: the setting permits language overrides, but the Tab keybinding reads its unscoped value. The earlier fix was reverted after breaking explicit expansion commands, so this reopened issue still owns unfinished work.

## Change summary

Honor language-specific emmet.triggerExpansionOnTab values without disabling explicit Emmet expansion or acceptance of completion suggestions.

## Best solution

Make automatic Tab expansion honor the current document's effective language setting while preserving explicit expansion through the Command Palette and custom shortcuts, independently of that setting.
