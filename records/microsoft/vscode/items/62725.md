# Issue #62725 — Exclude gitignored files from file watcher

[https://github.com/microsoft/vscode/issues/62725](https://github.com/microsoft/vscode/issues/62725)

## Summary

Keep open in the Backlog: current main still requires manually maintained watcher exclusions, and 99 community upvotes demonstrate sustained demand well above the promotion threshold.

## Change summary

Add an option for file watching to automatically exclude paths matched by repository ignore files.

## Best solution

Add an opt-in file-watcher setting whose exclusions follow `.gitignore` changes, with defined behavior for nested files, negation, and explicit `files.watcherExclude` overrides. The implementation likely belongs in `WorkspaceWatcher`, reusing the existing ignore-file parser where practical.
