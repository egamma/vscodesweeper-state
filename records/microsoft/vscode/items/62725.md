# Issue #62725 — Exclude gitignored files from file watcher

[https://github.com/microsoft/vscode/issues/62725](https://github.com/microsoft/vscode/issues/62725)

## Summary

Keep open: automatic gitignore-based workspace watcher exclusions remain missing, and the request has substantial community support. The open Git-specific PR addresses a narrower consumer, not the recursive workspace watcher's resource usage.

## Change summary

Provide an option to exclude gitignored paths from file watching without duplicating ignore rules in files.watcherExclude.

## Best solution

Offer opt-in ignore-aware workspace watching that reduces underlying watcher scope, with defined nested-ignore, negation, and ignore-file update semantics. Coordinate with the existing Git-specific PR, while keeping filesystem attributes, network-drive defaults, and watcher diagnostics as separate requests.
