# Issue #322334 — Add Confirmation Dialog for "Close All Editors" Command

[https://github.com/microsoft/vscode/issues/322334](https://github.com/microsoft/vscode/issues/322334)

## Summary

Keep open under discussion: a maintainer questioned the proposed setting's discoverability and suggested improving the existing reopen command instead, but the desired recovery behavior and scope are not yet settled.

## Change summary

Protect users from accidental “Close All Editors” invocations, either through optional confirmation or by restoring all editors with the reopen command.

## Best solution

Prefer a discoverable recovery path that makes “Reopen Closed Editor” restore the complete batch closed by “Close All Editors,” while preserving its existing single-editor behavior for ordinary closes; a maintainer should first decide whether that replaces or complements confirmation.
