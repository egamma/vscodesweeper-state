# Issue #316303 — Agent Plugin Marketplace: support plugins that re-declare the same root path

[https://github.com/microsoft/vscode/issues/316303](https://github.com/microsoft/vscode/issues/316303)

## Summary

Keep open: current source still conflates marketplace entries sharing a source directory, and does not retain their separate component declarations. No verified canonical or existing setting covers the requested capability.

## Change summary

Support independently installable named marketplace plugins that share a repository root but declare different skills or MCP configurations.

## Best solution

Support distinct marketplace plugin identities independently of their shared source directory, preserving each entry's component declarations through installation and discovery. Existing directory-based plugins should retain their current behavior.
