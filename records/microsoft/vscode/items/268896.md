# Issue #268896 — Editor focus conflict after first layout

[https://github.com/microsoft/vscode/issues/268896](https://github.com/microsoft/vscode/issues/268896)

## Summary

Keep open while the linked focus-tracking fix is reviewed. The reporter supplied a runnable reproduction; current source still lacks the proposed reconciliation, but browser focus behavior has not been reverified against current main and the supplied steps suffice to retest.

## Change summary

Initializing two editor columns while the browser window is unfocused can leave both editors reporting focus and send typing to the wrong file.

## Best solution

Ensure native EditContext focus state follows the actually focused editor after initial layout, so typing affects only the clicked editor. Review the existing implementation candidate at https://github.com/microsoft/vscode/pull/268897 against the supplied reproduction rather than starting a competing fix.
