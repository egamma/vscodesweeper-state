Keep open: multiple reporters confirm sustained helper-process CPU usage, including with extensions disabled and native Apple Silicon builds. The discussion contains several different triggers, but no verified common root cause, complete fix, or canonical duplicate.

VS Code helper processes sustain excessive CPU usage on macOS, making the editor sluggish and draining battery even while idle.
