- **Proposed comment:**

  > Thanks for the report. The blue outline indicates that the Welcome page has keyboard focus; it is intentional for accessibility and disappears when focus moves to a control within the page.
  > 
  > To hide this outline, add `"workbench.colorCustomizations": { "focusBorder": "#00000000" }` to your settings JSON, merging it with any existing color customizations. This also hides focus indicators on other controls that use `focusBorder`, so keeping a visible focus color is recommended for keyboard navigation.
