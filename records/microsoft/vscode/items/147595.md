# Issue #147595 — getSystemProxyURI does not support NO_PROXY env variable

[https://github.com/microsoft/vscode/issues/147595](https://github.com/microsoft/vscode/issues/147595)

## Summary

A real gap remains on current main: the VS Code Server Node request service selects HTTP(S) proxies without consulting `NO_PROXY`. The issue already has the correct `proxy` area label and should remain open.

## Change summary

Honor `NO_PROXY` and `no_proxy` when VS Code Server's Node request service selects a proxy for an HTTP or HTTPS request.

## Best solution

Use the shared `@vscode/proxy-agent` resolution semantics for Node request-service traffic, including re-evaluating exclusions when redirects change the destination, instead of introducing another copied `NO_PROXY` parser.

- **Trace:**
