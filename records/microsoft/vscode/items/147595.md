# Issue #147595 — getSystemProxyURI does not support NO_PROXY env variable

[https://github.com/microsoft/vscode/issues/147595](https://github.com/microsoft/vscode/issues/147595)

## Summary

Still unimplemented on main: `getSystemProxyURI` in `src/vs/platform/request/node/proxy.ts` does not check `NO_PROXY`/`no_proxy` before returning a proxy URI. The related PR #147981 was closed without merging. The feature gap remains real and valid.

## Change summary

VS Code Server ignores the `NO_PROXY` environment variable, sending all requests through the proxy even for hosts that should be bypassed.

## Best solution

Add `NO_PROXY`/`no_proxy` checking in `getSystemProxyURI` (in `src/vs/platform/request/node/proxy.ts`) so that requests to hosts listed in the no-proxy variable bypass the proxy. This is a small, well-scoped change. Issue https://github.com/microsoft/vscode/issues/200464 asks for a broader bypass-proxy setting and could absorb this, but the two are complementary — env-var support here, UI setting there.
