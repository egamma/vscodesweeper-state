## Summary

Valid open question about session source differentiation in AHP — the existing `showExternalSessions` setting may not correctly distinguish CLI-originated sessions from VS Code-originated ones when all flow through the Copilot SDK. No evidence of resolution on main.

## Change summary

Differentiate the source of agent sessions (CLI vs. VS Code) when all come through the Copilot SDK in AHP, so the showExternalSessions filter works correctly.

## Best solution

Implement session source tagging in the agent host session provider so that sessions created via CLI can be distinguished from those created in the VS Code/Agent Window, allowing the existing `showExternalSessions` setting to filter appropriately.
