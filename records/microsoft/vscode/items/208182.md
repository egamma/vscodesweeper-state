# Issue #208182 — Custom Hover can flicker when hovering over pointer

[https://github.com/microsoft/vscode/issues/208182](https://github.com/microsoft/vscode/issues/208182)

## Summary

This remains a confirmed but low-impact workbench-hover bug: two maintainers reproduced the cursor flicker when the pointer sits on an action-toolbar boundary. Current source includes later hover-lifecycle improvements, but no evidence establishes that they resolved this exact case.

## Change summary

Prevent the mouse cursor and custom hover from flickering when the pointer rests on the boundary of an Explorer action-toolbar element.

## Best solution

Reproduce the exact Explorer toolbar-boundary scenario on current Windows and determine whether the hover is repeatedly crossing its target boundary. If it persists, stabilize that hover lifecycle without changing normal hover dismissal or pointer interaction.
