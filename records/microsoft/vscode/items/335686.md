# Issue #335686 — `automation.created` telemetry does't include how it was created

[https://github.com/microsoft/vscode/issues/335686](https://github.com/microsoft/vscode/issues/335686)

## Summary

Fresh, reasonable telemetry enhancement request: the `automation.created` event currently has no field distinguishing how the automation was authored (dialog vs. import vs. duplicate vs. template), and this isn't yet implemented on main.

## Change summary

Add a `creationSource` dimension ('dialog' | 'import' | 'duplicate' | 'template') to the `automation.created` telemetry event.

## Best solution

Extend `IAutomationDefinitionTelemetry`/`AutomationCreatedClassification` in src/vs/platform/agentHost/node/agentHostAutomationTelemetry.ts with a bounded `creationSource` field, threaded through from wherever `AutomationCreateRequestedAction` originates (dialog, import flow, duplicate action, or template) so `_handleCreate` in agentHostAutomationService.ts can populate it when calling `logAutomationCreated`.
