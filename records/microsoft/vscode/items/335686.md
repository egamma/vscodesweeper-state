# Issue #335686 — `automation.created` telemetry does't include how it was created

[https://github.com/microsoft/vscode/issues/335686](https://github.com/microsoft/vscode/issues/335686)

## Summary

Keep open: current automation creation telemetry still lacks creation-source attribution. This is a team-authored enhancement parked in On Deck, and inspection found neither a referenced implementation nor a verified duplicate.

## Change summary

Distinguish dialog, import, duplicate, and template creation in automation.created telemetry.

## Best solution

Provide a bounded, content-free creation-source dimension that preserves the originating workflow even when several workflows share the review dialog. Agree how agent-tool creation fits the taxonomy before carrying attribution through the creation boundary.
