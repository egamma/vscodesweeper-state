# Issue #335686 — `automation.created` telemetry does't include how it was created

[https://github.com/microsoft/vscode/issues/335686](https://github.com/microsoft/vscode/issues/335686)

## Summary

Reasonable telemetry-quality request: the `automation.created` event (src/vs/platform/agentHost/node/agentHostAutomationTelemetry.ts) currently has no field for how the automation was created. It's a genuine gap, but adding it means extending the create action across the protocol and several UI call sites plus a new GDPR-classified field, which needs an owner decision on the exact shape.

## Change summary

Add a `creationSource` (dialog/import/duplicate/template) dimension to the `automation.created` telemetry event.

## Best solution

Extend `AutomationCreateRequestedAction`/`IAutomationDefinitionTelemetry` with a bounded creation-source field, threaded from the UI call sites in agentHostAutomationStore.ts (which already distinguish `imported`, but not duplicate/template/dialog) down to `logAutomationCreated`; the telemetry owner (ulugbekna) should confirm the exact enum values and classification comment before implementation.
