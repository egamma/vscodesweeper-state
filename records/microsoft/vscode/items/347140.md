# Issue #347140 — On Hold is too limiting. I'm gonna end up having many many things "on hold"

[https://github.com/microsoft/vscode/issues/347140](https://github.com/microsoft/vscode/issues/347140)

## Summary

Keep open: Inbox mode currently flattens held sessions into one category, losing the folder organization this workflow needs. This team-authored request identifies a remaining capability gap, not a broken implementation of the current grouping contract.

## Change summary

Allow sessions within On hold to be broken into manageable groups, such as by folder.

## Best solution

Support meaningful organization within On hold without requiring users to leave Inbox mode or lose their existing session organization. Decide whether this should use automatic folder subgroups, custom groups, or both.
