# Issue #339710 — Agents - attempt grid feedback

[https://github.com/microsoft/vscode/issues/339710](https://github.com/microsoft/vscode/issues/339710)

## Summary

Fresh, team-authored bug report from testing the new agents attempts-grid feature (follow-up to #339373): clicking another session while the attempts grid is open opens the new session in place of the prior active one instead of closing the grid. Team-authored issues are protected from judgment closes and there is no fix commit yet, so this stays open.

## Change summary

When an attempts grid is showing for a multi-attempt prompt, clicking a different session in the sessions list replaces the previously active session inside the grid instead of closing the grid and opening the newly selected session.

## Best solution

In the sessions window's session-selection handling, ensure selecting a different session from the list tears down/closes the active attempts-comparison grid state before opening the newly selected session, rather than substituting it into the existing grid.
