# Issue #339710 — Agents - attempt grid feedback

[https://github.com/microsoft/vscode/issues/339710](https://github.com/microsoft/vscode/issues/339710)

## Summary

The reported navigation behavior remains in current source: selecting an unrelated session replaces one attempt pane rather than leaving the comparison grid. Keep this team-authored report open; ordinary user-created grids intentionally preserve their other panes, so the correction must be comparison-specific.

## Change summary

Selecting another session from the sidebar should leave the attempts grid and display the selected session alone.

## Best solution

Make ordinary sidebar navigation out of a comparison leave the attempts arrangement without closing or deleting its sessions. Preserve existing pane-replacement behavior for ordinary user-created grids and explicit open-to-side actions.
