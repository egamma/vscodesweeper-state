# Issue #204010 — Show log-point message in decoration

[https://github.com/microsoft/vscode/issues/204010](https://github.com/microsoft/vscode/issues/204010)

## Summary

Valid feature request from a team member. The logpoint message is not shown as an inline decoration on current main — only as a glyph margin hover. The request remains unimplemented.

## Change summary

Show the logpoint message text as an inline after-content decoration at the end of the line, so users can visually relate debug console output to source code.

## Best solution

Add an `after` inline decoration in `getBreakpointDecorationOptions` (in `src/vs/workbench/contrib/debug/browser/breakpointEditorContribution.ts`) that renders `breakpoint.logMessage` as end-of-line text when the breakpoint is a logpoint. This mirrors how other features (e.g. inline blame, CodeLens) use `afterContentClassName` decorations.
