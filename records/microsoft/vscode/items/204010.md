# Issue #204010 — Show log-point message in decoration

[https://github.com/microsoft/vscode/issues/204010](https://github.com/microsoft/vscode/issues/204010)

## Summary

This remains a valid debug UX request: logpoints show only a generic glyph in the gutter, so identical terminal output cannot be mapped back to a particular logpoint without inspecting each breakpoint. The Backlog milestone and team-authored status reinforce keeping it open for a product/design decision.

## Change summary

Show each logpoint's message as an inline end-of-line editor decoration so emitted output can be related to its source location.

## Best solution

Add a concise inline logpoint-message decoration in the debug editor contribution, with truncation or hover behavior for long messages and without changing breakpoint execution or terminal output semantics.
