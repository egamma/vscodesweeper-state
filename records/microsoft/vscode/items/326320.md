Plausible bug in Copilot Chat session rename persistence. Recent fixes (ece376a4dbf) addressed agent-host session rename persistence; the local session rename path may have similar issues. ## Change summary

Renaming a Copilot Chat session does not persist: the list does not auto-update, the old name appears in the chat header, and the name reverts on restart.

## Best solution

Verify the three symptoms on current main. The `LocalAgentSessionsController.refresh()` method (localAgentSessionsController.ts) only detects newly-added items, not updated labels for existing items — though `tryUpdateLiveSessionItem` should handle live-model changes via `model.onDidChange`. For history sessions (not in `_sessionModels`), `setChatSessionTitle` updates the store index but fires no event to refresh the list. If the bug reproduces, ensure `setChatSessionTitle` triggers a list refresh for both live and history sessions, and that the chat editor title bar also reads the updated custom title.
