# Issue #326320 — Renaming Copilot Chat Sessions Doesn't Stick

[https://github.com/microsoft/vscode/issues/326320](https://github.com/microsoft/vscode/issues/326320)

## Summary

Verified duplicate of the older, open report at https://github.com/microsoft/vscode/issues/302887: renaming from the sessions list fails to persist, and opening the chat restores the old title. Both threads also confirm the same title-picker workaround.

## Change summary

Renaming a Copilot chat from the sessions list should update immediately and preserve the new title when opening the chat or restarting VS Code.
