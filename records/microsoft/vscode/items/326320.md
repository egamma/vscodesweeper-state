# Issue #326320 — Renaming Copilot Chat Sessions Doesn't Stick

[https://github.com/microsoft/vscode/issues/326320](https://github.com/microsoft/vscode/issues/326320)

## Summary

Verified duplicate: this is the same rename-doesn't-persist bug already tracked (and root-caused) by the open, better-diagnosed https://github.com/microsoft/vscode/issues/318442, which has an open fix PR covering exactly these symptoms.

## Change summary

Renaming a Copilot Chat session doesn't update the sessions list without a manual refresh, doesn't update the in-chat title, and reverts to the old name after closing/reopening or relaunching.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/318442 and land https://github.com/microsoft/vscode/pull/318667, which fixes both root causes: `LocalAgentsSessionsController.refresh()` not detecting updated (only new) items, and `renameChat()` calling the sync in-memory `setSessionTitle()` instead of the persisting `setChatSessionTitle()`.
