# Issue #293377 — Copilot Chat's "Restore Checkpoint" and edit previous message features do not work

[https://github.com/microsoft/vscode/issues/293377](https://github.com/microsoft/vscode/issues/293377)

## Summary

The failure was independently confirmed on VS Code 1.109.0, but a maintainer could not reproduce it in Stable or Insiders and requested diagnostics that were never supplied. Current source still intends Restore Checkpoint to restore both the workspace and transcript, so confirmation on a current build is needed before determining whether this regression remains.

## Change summary

Restoring a checkpoint or resubmitting an edited earlier message reverts files but leaves the later chat history visible and in context.

## Best solution

Reproduce the workflow on the latest VS Code and Copilot build, distinguishing checkpoints with file edits from chat-only checkpoints; then fix the checkpoint timeline or transcript-disablement path so workspace and chat state return to the same request boundary. The separate request for chat-only rollback should be evaluated independently after the restoration defect is diagnosed.
