# Issue #315186 — Extension API: how to retrieve focused view ID during keybinding command execution?

[https://github.com/microsoft/vscode/issues/315186](https://github.com/microsoft/vscode/issues/315186)

## Summary

Valid feature request for an API to retrieve the focused tree view during command execution. A team member acknowledged the pain point, and an open community PR (#316601) is in review — keep open for that PR to land.

## Change summary

Extensions sharing a TreeDataProvider across multiple views have no reliable way to determine which view is focused during keybinding command execution, forcing massive command duplication.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/316601, which proposes `vscode.window.focusedTreeView` and `onDidChangeFocusedTreeView`. The PR's design checklist (naming, filtering, object isolation) needs maintainer decisions before merge. The underlying `ViewsService.onDidChangeFocusedView` already exists internally, so the plumbing is straightforward.
