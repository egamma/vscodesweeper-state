# Issue #295337 — 2026 Themes: Italic variants

[https://github.com/microsoft/vscode/issues/295337](https://github.com/microsoft/vscode/issues/295337)

## Summary

Keep open for a theme-design decision: current 2026 themes use italics for selected scopes, but do not establish the broader italic syntax styling requested here. Existing customization settings offer a workaround, and neither candidate canonical meets the duplicate bar for this re-reviewed item.

## Change summary

Use italic font variants more broadly in the 2026 themes' syntax highlighting.

## Best solution

Have the default-theme owners decide which syntax categories, if any, should gain italic emphasis in both 2026 themes while preserving a consistent, readable hierarchy. Retain theme-scoped token customization for individual preferences rather than assuming a new setting or separate theme variant is necessary.
