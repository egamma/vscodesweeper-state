## Summary

Keep open as a small 2026-theme design request: current main already has some italic token rules in the 2026 themes, but there is no issue-linked fixing commit and the broader ask for more italic treatment is still a product/theme judgment.

## Change summary

Use italic font-style variants more deliberately in the 2026 Light and Dark themes to improve code readability and aesthetics.

## Best solution

Let the theme owners decide whether to expand the `fontStyle: "italic"` token rules in `extensions/theme-defaults/themes/2026-light.json` and `extensions/theme-defaults/themes/2026-dark.json`, or intentionally keep the current limited italic use for invalid and markup scopes.
