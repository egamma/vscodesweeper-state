## Summary

The central ask — a way to disable the new rounded/padded 'Modern UI' styling — is already covered by the existing `workbench.experimental.modernUI` setting, confirmed working by a contributor in the thread; closing as as-designed with a pointer to that setting.

## Change summary

Reporter dislikes the increased corner rounding and padding in the new Modern UI (introduced 1.133.0) and asks for a way to restore the previous compact look.

## Best solution

Point reporters at `workbench.experimental.modernUI: false` (registered in src/vs/workbench/browser/workbench.contribution.ts, default false, but auto-enabled via an A/B experiment per `experiment: { mode: 'auto' }`), which already restores the pre-Modern-UI layout; no code change needed for this specific request.
