## Summary

Thanks for the report, but the exact ask — an option to disable the new rounded/padded look and restore the previous compact UI — already ships as settings, confirmed working in this thread, so this is as-designed rather than a gap.

## Change summary

VS Code 1.133's Modern UI adds rounded corners and extra padding throughout the workbench; the reporter asks for a setting to disable it and restore the previous, denser look.

## Best solution

Direct users to `workbench.experimental.modernUI: false` (full revert to the previous square/dense look) and `window.density.layout: compact` (keeps Modern UI but removes gaps/reduces internal spacing) — both already exist and cover this request; no further change needed here beyond documentation/awareness.
