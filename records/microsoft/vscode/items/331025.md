# Issue #331025 — Too much padding and rounded corners. Activity Bar on the left looks broken..

[https://github.com/microsoft/vscode/issues/331025](https://github.com/microsoft/vscode/issues/331025)

## Summary

The central ask — an option to disable the new rounded/padded UI and restore the previous compact look — is already covered by the existing `workbench.experimental.modernUI` setting, confirmed working by a contributor in the thread; closing as as-designed since the requested opt-out already exists.

## Change summary

Reporter wants an option to turn off the new Modern UI's rounded corners and extra padding introduced in 1.133.0 and restore the previous compact layout.

## Best solution

Point reporters at `workbench.experimental.modernUI: false` (already confirmed to work in the thread) to restore the previous compact look; the modern UI's styling — corners, padding, headers — is implemented as a cohesive package in src/vs/workbench/contrib/modernUI/browser (see roundedCorners.css, padding.css, paneHeaders.css) gated by that single setting, so the opt-out already exists as designed.
