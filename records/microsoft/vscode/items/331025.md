[https://github.com/microsoft/vscode/issues/331025](https://github.com/microsoft/vscode/issues/331025)

## Summary

The new rounded/padded look is the intentional 'Modern UI' experiment and there is already a working opt-out — `workbench.experimental.modernUI: false` — confirmed both in the source and by a contributor in the thread, so this is as-designed rather than a bug.

## Change summary

Reporter wants an option to disable the increased corner rounding and padding introduced by the new Modern UI in 1.133.0.

## Best solution

Point reporters at `workbench.experimental.modernUI: false`, which fully disables the roundedCorners/padding CSS modules (src/vs/workbench/contrib/modernUI/browser/modernUI.contribution.ts, media/roundedCorners.css, media/padding.css); consolidate the broader 'don't like the new UI' sentiment on the existing threads (e.g. https://github.com/microsoft/vscode/issues/326146 and https://github.com/microsoft/vscode/issues/325240) rather than tracking each symptom separately.
