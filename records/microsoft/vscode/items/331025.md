# Issue #331025 — Too much padding and rounded corners. Activity Bar on the left looks broken..

[https://github.com/microsoft/vscode/issues/331025](https://github.com/microsoft/vscode/issues/331025)

## Summary

This is the same underlying request as the broader tracked complaint about the new Modern UI Update (rounded corners, padding, reduced density) — the ask (an option to disable/restore the old compact look) is already answered by the `workbench.experimental.modernUI` setting, and the remaining 'give us a way to keep the old look' signal is already consolidated in the open canonical issue.

## Change summary

Requests an option to disable the excessive corner-rounding and padding introduced by VS Code 1.133's Modern UI Update, to restore the previous, more compact interface.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/326146 (open, same 'preserve/keep old UI' ask) — the `workbench.experimental.modernUI: false` setting (registered in src/vs/workbench/browser/workbench.contribution.ts, `LayoutSettings.MODERN_UI`) already restores the prior compact look, and there's also `workbench.experimental.window.density: compact` (`LayoutSettings.MODERN_UI_DENSITY`) for reducing spacing while keeping the new UI on.
