# Issue #322929 — Give parallel sessions and agents more prominent visual identity

[https://github.com/microsoft/vscode/issues/322929](https://github.com/microsoft/vscode/issues/322929)

## Summary

Valid, UX-research-backed feature request from a team member to improve visual attribution and status visibility for concurrent agents and sessions in the Agents window. The Agents window already has a running-subagents chip (`SessionRunningSubagentsControl`) but lacks per-agent color coding, swimlanes, and error/stall notifications — the core asks remain unaddressed.

## Change summary

Give parallel sessions and concurrent agents distinct visual identities (color coding, status indicators, error notifications) so users can track interleaved agent activity at a glance.

## Best solution

Design and implement per-agent visual differentiation in the Agents window chat transcript — likely touching `src/vs/sessions/contrib/chat/browser/` for rendering and `src/vs/sessions/common/theme.ts` for color tokens. The existing `SessionRunningSubagentsControl` covers running-status at the input level but not inline transcript attribution, stall/error notifications, or visual separation of concurrent outputs. This is a design-heavy workstream that should be driven by the UX findings cited in the issue.
