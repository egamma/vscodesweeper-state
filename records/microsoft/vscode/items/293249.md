# Issue #293249 — Find input isn't pre-populated on open in Extension preview

[https://github.com/microsoft/vscode/issues/293249](https://github.com/microsoft/vscode/issues/293249)

## Summary

Still reproduces on main: the webview find widget never seeds from selected text because there is no mechanism to retrieve the selection from the webview content. The `showFind` method passes `undefined` to `reveal()`, and the webview message protocol has no `getSelection` message.

## Change summary

Opening Find (Ctrl+F) in a webview (e.g. Extension preview) does not pre-populate the search box with the currently selected text.

## Best solution

Add a `getSelection` message to the webview message protocol so the host can request the selected text from the webview iframe. Then have `showFind()` in `webviewElement.ts` request the selection and pass it as `initialInput` to `reveal()`. This requires changes in both the webview host code and the webview-side script that handles messages.
