# Issue #293249 — Find input isn't pre-populated on open in Extension preview

[https://github.com/microsoft/vscode/issues/293249](https://github.com/microsoft/vscode/issues/293249)

## Summary

The selection-seeding gap remains in current source: opening Find in an extension README reveals the widget without supplying selected text. Keep this open under webview; the related integrated-browser fixes use a different path.

## Change summary

Opening Find in an extension README should pre-populate its input with the selected text.

## Best solution

Make the extension README's webview Find honor the current text selection when opened, while preserving existing search behavior when nothing is selected. Address this in the shared webview find-opening path rather than the integrated browser.
