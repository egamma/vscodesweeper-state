# Issue #180429 — Allow editor cursor blinking rate to match rate provided by the OS

[https://github.com/microsoft/vscode/issues/180429](https://github.com/microsoft/vscode/issues/180429)

## Summary

Keep open: the editor still uses fixed cursor animation timing rather than the operating system's blink rate. The existing style setting only partially addresses the accessibility need, and no qualifying canonical or fixing commit was established.

## Change summary

Allow the editor cursor to follow the operating system's configured blink interval, including disabled blinking.

## Best solution

Provide OS-derived caret timing to the custom editor cursor through a platform-neutral boundary, with defined interaction with editor.cursorBlinking and a fallback where system timing is unavailable. First establish the current Electron API capability and agree on the default behavior.
