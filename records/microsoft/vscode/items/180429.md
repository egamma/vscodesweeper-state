# Issue #180429 — Allow editor cursor blinking rate to match rate provided by the OS

[https://github.com/microsoft/vscode/issues/180429](https://github.com/microsoft/vscode/issues/180429)

## Summary

Team-authored accessibility feature request that remains unimplemented — requires upstream Electron API exposure for OS caret blink rate. No related commits or code changes found on main.

## Change summary

Allow the editor cursor blink rate to use the OS-provided caret blink time instead of a hardcoded interval.

## Best solution

Upstream work needed in Electron to expose the OS caret blink time (GetCaretBlinkTime on Windows, equivalent on other platforms) to JS. Once available, integrate it as a 'system' option for the `editor.cursorBlinking` setting or a separate `editor.cursorBlinkingRate` setting. Blocked on Electron API.
