# Issue #335178 — fix-ci-failures skill can wait forever when there are no failures

[https://github.com/microsoft/vscode/issues/335178](https://github.com/microsoft/vscode/issues/335178)

## Summary

Real, well-diagnosed bug in the fix-ci-failures skill's guidance: `gh pr checks --watch --fail-fast` blocks indefinitely on non-CI gates (e.g. approval requirements on a draft PR). An open PR already fixes exactly this, so the issue should stay open until that PR merges.

## Change summary

The fix-ci-failures skill tells the agent to run `gh pr checks --watch --fail-fast`, which can hang forever waiting on a permission/approval gate rather than an actual CI job.

## Best solution

Land https://github.com/microsoft/vscode/pull/335174, which rewrites the relevant SKILL.md guidance to classify pending checks via `gh api .../check-runs`, distinguish policy/approval gates from real workflow jobs, and bound any `--watch --fail-fast` invocation to one-minute intervals — this is precisely the fix requested here.
