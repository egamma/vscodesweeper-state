# Issue #323820 — Ability to limit search to within the current function scope

[https://github.com/microsoft/vscode/issues/323820](https://github.com/microsoft/vscode/issues/323820)

## Summary

Keep open as a feature request: existing selection-based Find does not provide automatic restriction to the enclosing function. No verified older canonical was found, and there is no maintainer decision supporting a scope-based close.

## Change summary

Allow editor Find to search only within the current function without requiring the user to select that function first.

## Best solution

Evaluate an explicit enclosing-function scope for editor Find that does not require changing the editor selection. Define language-support and nested-function behavior before implementation, while preserving existing whole-file and Find in Selection behavior.
