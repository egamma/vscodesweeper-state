# Issue #183388 — Find stops working on extremely long input ("Invalid regular expression" warning thrown)

[https://github.com/microsoft/vscode/issues/183388](https://github.com/microsoft/vscode/issues/183388)

## Summary

The long-query failure remains plausible on current main and this is the established canonical issue. It is already correctly classified and routed as editor-find polish.

## Change summary

Make editor Find remain focusable and avoid an invalid-regular-expression warning after an extremely long plain-text query is pasted.

## Best solution

Harden the editor find pipeline against oversized plain-text queries, preserving widget focus and reporting any practical limit locally instead of surfacing a RegExp exception. The likely boundary is the find controller/widget and text-model search preparation.
