# Issue #183388 — Find stops working on extremely long input ("Invalid regular expression" warning thrown)

[https://github.com/microsoft/vscode/issues/183388](https://github.com/microsoft/vscode/issues/183388)

## Summary

Keep this as the canonical report for oversized queries breaking editor Find: a recent commenter confirms the failure, and maintainers already consolidated two reports here. Current source still permits search execution errors to interrupt the Find-focus path; the precise current-runtime trigger needs confirmation before implementation.

## Change summary

After an oversized query is pasted into editor Find, Ctrl+F reports an invalid regular expression instead of refocusing the Find input.

## Best solution

Keep editor Find usable and refocusable even when a query exceeds the search engine's capabilities, with a recoverable input error rather than a failed command. Diagnose the oversized-query failure through the editor Find controller and text-model search path, preserving ordinary literal and regex search behavior.
