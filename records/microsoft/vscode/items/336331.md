# Issue #336331 — Unwanted Copilot install and usage

[https://github.com/microsoft/vscode/issues/336331](https://github.com/microsoft/vscode/issues/336331)

## Summary

GitHub Copilot (completions) ships as a built-in extension bundled with VS Code and is enabled by default when a user signs in, which is a deliberate product decision, not a bug — and VS Code already ships a control to turn it off entirely, so this is best closed as-designed rather than kept open as an undecided feature request.

## Change summary

Reporter wants Copilot to be opt-in rather than bundled/enabled by default after signing into GitHub.

## Best solution

Point the reporter at the `chat.disableAIFeatures` setting (src/vs/platform/chat/common/chatSettings.ts, `ChatAIDisabledSettingId`), which disables and hides built-in AI features including inline suggestions and chat; the default-on bundling of Copilot itself is an intentional product choice that only a maintainer/product owner could change, not a defect.
