# Issue #183437 — Mouse wheel scroll does not respect windows mouse settings

[https://github.com/microsoft/vscode/issues/183437](https://github.com/microsoft/vscode/issues/183437)

## Summary

Still present on main: VS Code's scroll logic uses a hardcoded SCROLL_WHEEL_SENSITIVITY=50px multiplier rather than mapping to actual editor line height, so while the system 'lines to scroll' count is partially incorporated via wheelDeltaY, the 'one screen at a time' setting and fine-tuned line counts don't translate accurately.

## Change summary

Mouse wheel scrolling does not fully respect Windows system mouse settings for 'lines to scroll at a time' or 'one screen at a time'.

## Best solution

The scroll path in src/vs/base/browser/ui/scrollbar/scrollableElement.ts should translate wheel deltas into actual editor line heights (or viewport height for page mode) rather than using the hardcoded 50px constant. The StandardWheelEvent normalization in mouseEvent.ts also lacks DOM_DELTA_PAGE handling, though Electron may never emit that mode.
