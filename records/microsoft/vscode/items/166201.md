# Issue #166201 — Color completion not previewing colors when non-hex variables are present

[https://github.com/microsoft/vscode/issues/166201](https://github.com/microsoft/vscode/issues/166201)

## Summary

Keep open: the report provides a sample and concrete typing sequences sufficient to retest the disappearing previews. Current completion code was inspected, but neither a current reproduction nor a fixing commit was established; the related reports do not own this exact behavior.

## Change summary

SCSS variable suggestions intermittently lose color previews and value information after typing a property value when hex and non-hex variables coexist.

## Best solution

Preserve color metadata and previews for existing hex-variable suggestions throughout the colon, space, dollar-sign, and backspace completion sequence. First determine whether the metadata disappears in the CSS provider response or during editor suggestion reuse; keep broader color-format support and cross-file completion separate.
