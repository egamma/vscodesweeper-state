# Issue #166201 — Color completion not previewing colors when non-hex variables are present

[https://github.com/microsoft/vscode/issues/166201](https://github.com/microsoft/vscode/issues/166201)

## Summary

Keep this accepted Backlog request open: current main still relies on parsing completion text for color previews, and this remains the canonical issue for making color completion metadata reliable.

## Change summary

Make SCSS color-variable suggestions consistently retain their color previews when hexadecimal and non-hexadecimal variables are mixed.

## Best solution

Replace the suggest widget's heuristic parsing of labels, details, and documentation with explicit color metadata that CSS completion providers and LSP clients can supply, while preserving semantic variable suggestions across trigger and filtering updates.
