# Issue #244605 — Regex Tree Sitter: Look around expressions not colored correctly

[https://github.com/microsoft/vscode/issues/244605](https://github.com/microsoft/vscode/issues/244605)

## Summary

Partially fixed by two merged PRs, but a team member confirmed on April 30 2025 that `?!` coloring is still off in themes like Monokai and Night Owl. No further fix has landed, so the issue remains open.

## Change summary

Regex lookaround expressions (`?!`, `?=`, `?<=`, `?<!`) and the `=` symbol are not colored correctly in Tree Sitter mode compared to TextMate.

## Best solution

The remaining gap is the `?!` / `?=` coloring mismatch in non-Dark+ themes (Monokai, Night Owl). The tree-sitter regex highlights likely need an additional query or scope adjustment so that lookahead/lookbehind operators match the TextMate scoping across all bundled themes.
