# Issue #350590 — Reusing a dedicated task terminal after a nonzero exit loses the next onDidEndTaskProcess event

[https://github.com/microsoft/vscode/issues/350590](https://github.com/microsoft/vscode/issues/350590)

## Summary

The reported failure is traceable in current main: a retained failed task terminal keeps its exiting flag across reuse, suppressing the second exit notification. Keep this open and route it to the terminal area.

## Change summary

Reusing a dedicated terminal after a failed task with close enabled loses the subsequent task-process completion event and leaves the task active.

## Best solution

Each reused terminal process should have an independent exit lifecycle, emitting completion exactly once and allowing task tracking to finish. Preserve the existing policy that retains failed task output.
