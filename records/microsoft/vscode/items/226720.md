# Issue #226720 — `FileSearchProviderOptions#session` should not be `undefined`

[https://github.com/microsoft/vscode/issues/226720](https://github.com/microsoft/vscode/issues/226720)

## Summary

The defect remains in current source: file searches without a cache key pass undefined as the new provider's session, contradicting its required object contract and breaking WeakMap-based caches. Keep this correctly routed issue open.

## Change summary

Ensure FileSearchProviderOptions.session is always an object suitable for use as a WeakMap key.

## Best solution

Honor the new file-search provider's session contract for uncached searches while preserving shared session identity for cached searches, cache invalidation, and legacy provider cancellation semantics.
