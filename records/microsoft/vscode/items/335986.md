# Issue #335986 — VS Code's terminal audio/accessibility signals are intrusive, confusing, and absurdly difficult to disable

[https://github.com/microsoft/vscode/issues/335986](https://github.com/microsoft/vscode/issues/335986)

## Summary

Keep open as a terminal audio discoverability request. Current settings and the signal-configuration command provide partial coverage, but neither supplies the requested terminal-only master control; the claimed unconditional default sounds are not supported by current source.

## Change summary

Make terminal audio feedback easier to identify and disable together, and reconsider automatic command-completion sounds.

## Best solution

Improve discovery of terminal sound controls through the existing accessibility-signal configuration surface, preserving useful screen-reader feedback. An area owner should decide whether a terminal-wide sound override is warranted and how it interacts with individual signal settings.
