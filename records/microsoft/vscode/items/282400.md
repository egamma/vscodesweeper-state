# Issue #282400 — auto indent error

[https://github.com/microsoft/vscode/issues/282400](https://github.com/microsoft/vscode/issues/282400)

## Summary

The current C++ indentation path still inherits the continuation line's eight spaces after the terminating semicolon instead of returning to four. Keep this report open: the older related reports cover different observable cases, not this multiline ternary.

## Change summary

Pressing Enter after a completed multiline C++ ternary statement should restore the statement's base indentation.

## Best solution

Make C++ Enter indentation recognize the end of a multiline statement and resume its base indentation without globally outdenting every semicolon. Assess this against the existing tree-sitter autoindent direction, preserving intentional indentation and unrelated language behavior.
