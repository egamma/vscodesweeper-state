# Issue #339972 — Chat: agent reply degenerates into an unbounded stream of spaces (claude-opus-5.5), bloating the session file

[https://github.com/microsoft/vscode/issues/339972](https://github.com/microsoft/vscode/issues/339972)

## Summary

Thanks for the detailed, content-free diagnosis. Tracing the Copilot agent session code confirms the gap: `_emitMarkdownDelta` in copilotAgentSession.ts unconditionally appends every streamed delta to the markdown part and persists it, with no guard against a long run of repeated whitespace — so a misbehaving model/proxy stream really would bloat the session JSONL and slow the chat view exactly as described. Worth keeping open for a maintainer to decide where a cutoff/guard belongs.

## Change summary

A degenerate agent reply that streams only spaces is saved and re-rendered in full, growing the chat session JSONL unbounded and eventually making the extension host unresponsive.

## Best solution

Add a runaway-content guard in the Copilot agent session streaming path (around `_emitMarkdownDelta` in src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts) that detects a long run of repeated whitespace/characters, stops persisting/re-streaming it verbatim, and avoids resending the degenerate run as conversation history on the next turn.
