# Issue #204031 — Don't link the variable viewer to just notebooks

[https://github.com/microsoft/vscode/issues/204031](https://github.com/microsoft/vscode/issues/204031)

## Summary

Valid feature request still under discussion — the NotebookVariableProvider API remains proposed and exclusively tied to NotebookController on current main; no generalization has landed.

## Change summary

Decouple the variable viewer from notebooks so extensions like Julia can show variables from REPL processes and other non-notebook contexts.

## Best solution

Generalize the proposed NotebookVariableProvider API to support non-notebook variable sources (REPLs, test processes). The built-in REPL UI work mentioned by amunger (notebook-controller-backed REPL) may partially address this, but a fully decoupled VariableProvider API would serve more use cases. Keep open for the team to design the right lifetime/attachment model.
