# Issue #331463 — Command+A is not working on debug console

[https://github.com/microsoft/vscode/issues/331463](https://github.com/microsoft/vscode/issues/331463)

## Summary

The Debug Console output is a virtualized list (with text selectable via mouse drag, per repl.css's `user-select: text`), but there's no Cmd/Ctrl+A binding that selects all of its text the way a terminal or editor does — only a 'Copy All' context-menu/command action exists. A maintainer already asked for clarification and the reporter gave a clear, reasonable ask, so this is an open feature gap rather than a bug or something to close.

## Change summary

Cmd+A in the Debug Console does not select all text/output the way it does in the terminal or a text editor.

## Best solution

Route to the debug/repl area (src/vs/workbench/contrib/debug/browser/repl.ts) for a maintainer product decision on whether Cmd/Ctrl+A should select-all-as-text in the console output (in addition to the existing repl.action.copyAll / workbench.debug.action.copyAll commands), since the output is a WorkbenchList and not a plain text region.
