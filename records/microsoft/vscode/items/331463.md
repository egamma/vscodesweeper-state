# Issue #331463 — Command+A is not working on debug console

[https://github.com/microsoft/vscode/issues/331463](https://github.com/microsoft/vscode/issues/331463)

## Summary

Not a bug so much as a real gap: the Debug Console output is rendered as a virtualized list widget, not a text buffer, so there's no character-level text selection or select-all — 'Copy All' is the only bulk-copy path today. Reporter already clarified the ask, so this should move from info-needed to a proper feature-request in the debug/debug-console area rather than stay pending.

## Change summary

Cmd+A (Select All) does nothing in the Debug Console output; the reporter wants it to select all text like a terminal or editor.

## Best solution

Decide whether the REPL list view (src/vs/workbench/contrib/debug/browser/repl.ts) should gain a 'select all rows + copy' keybinding (Cmd/Ctrl+A) alongside the existing 'Debug: Console Copy All' command (repl.action.copyAll), or whether this stays a documented limitation of the list-based console; no maintainer has decided yet.
