# Issue #297281 — Duplication of MCP browse experience

[https://github.com/microsoft/vscode/issues/297281](https://github.com/microsoft/vscode/issues/297281)

## Summary

MCP browsing still has separate Extensions and Customizations surfaces on current main. Keep this open to complete the maintainer-supported consolidation into Customizations while preserving icons and the existing popularity information.

## Change summary

Unify MCP server discovery in Customizations without losing the icons and ratings/popularity information available in the older experience.

## Best solution

Make Customizations the coherent destination for MCP discovery, retaining the older browser's useful server metadata and installation capabilities. Settle how this works when the newer Discover experience is disabled before retiring the separate Extensions browser.
