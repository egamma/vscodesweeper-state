# Issue #297281 — Duplication of MCP browse experience

[https://github.com/microsoft/vscode/issues/297281](https://github.com/microsoft/vscode/issues/297281)

## Summary

The duplication still exists on current main — the extensions viewlet retains its `@mcp` search path alongside the newer AI Customizations view's MCP/plugin widgets. Active development is consolidating MCP into the customization view, but the unification isn't complete yet; keeping open.

## Change summary

Two separate browse surfaces exist for discovering MCP servers (extensions view via @mcp query and the AI Customizations editor); the request is to consolidate into one experience with ratings and icons.

## Best solution

Remove the MCP server browse path from the extensions viewlet (`src/vs/workbench/contrib/extensions/browser/extensionsViewlet.ts`) once the AI Customizations view's plugin/MCP list widgets (`src/vs/workbench/contrib/chat/browser/aiCustomization/pluginListWidget.ts`, `mcpListWidget.ts`) fully support ratings and icons. The team consensus (aeschli's comment) is to move everything MCP to the customization view.
