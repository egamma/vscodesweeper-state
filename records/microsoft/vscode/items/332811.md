# Issue #332811 — Create Plugin generates a legacy-format plugin instead of Agent Plugins 1.0

[https://github.com/microsoft/vscode/issues/332811](https://github.com/microsoft/vscode/issues/332811)

## Summary

Confirmed on main: `writePluginToDisk` in createPluginAction.ts still writes the legacy OpenPlugin layout (`.plugin/plugin.json`, flat `rules/`/`commands/`/`agents/`/`hooks/`, `.mcp.json`) instead of Agent Plugins 1.0, and `detectPluginFormat` correctly classifies the output as OpenPlugin — a real defect. An open PR (#332828) already targets this exact fix, so this should stay open pending review/merge of that PR rather than being auto-fixed or closed.

## Change summary

The 'Chat: Create Plugin' action scaffolds a plugin in the legacy OpenPlugin format (`.plugin/plugin.json`, flat component dirs, `.mcp.json`) instead of the Agent Plugins 1.0 layout (root `plugin.json` with `$schema`, `mcp.json`, components under `com.github.copilot/`).

## Best solution

Land https://github.com/microsoft/vscode/pull/332828 ("chat: choose compatibility when creating Agent Plugins"), updating writePluginToDisk in src/vs/workbench/contrib/chat/browser/actions/createPluginAction.ts to emit the Agent Plugins 1.0 structure and updating the accompanying tests in createPluginAction.test.ts.
