# Issue #337293 — GitHub Copilot in VS Code 1.138.0 does not respect "Preview" features disabled in the Enterprise policies for Autopilot

[https://github.com/microsoft/vscode/issues/337293](https://github.com/microsoft/vscode/issues/337293)

## Summary

Current behavior is intentional: Editor preview policy was explicitly decoupled from tool approvals and elevated permission levels before 1.138. Enterprises must use the dedicated bypass-permissions control to disable Autopilot.

## Change summary

Make the enterprise setting that disables preview features also disable the Autopilot permission level.

## Best solution

Keep preview-feature policy separate from approval policy, and use `permissions.disableBypassPermissionsMode=disable` or an explicit `ChatToolsAutoApprove=false` device policy when an organization needs to prevent Autopilot and other elevated permission modes.
