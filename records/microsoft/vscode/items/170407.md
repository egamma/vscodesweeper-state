# Issue #170407 — Two extensions with conflicting custom semantic tokens cause vscode to crash

[https://github.com/microsoft/vscode/issues/170407](https://github.com/microsoft/vscode/issues/170407)

## Summary

Still reproduces on main: getTypeHierarchy in tokenClassificationRegistry.ts follows the superType chain in an unbounded while loop with no cycle detection, so two extensions creating a circular superType relationship (e.g. operator→punctuation→operator) cause an infinite loop and crash.

## Change summary

Two extensions that define circular superType relationships among custom semantic token types cause an infinite loop and crash in VS Code.

## Best solution

Add cycle detection to `getTypeHierarchy` in `src/vs/platform/theme/common/tokenClassificationRegistry.ts` — either track visited types in a Set during the while loop, or cap the iteration depth. Optionally, validate at registration time in `registerTokenType` and reject or warn on cycles.
