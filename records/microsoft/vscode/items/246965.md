# Issue #246965 — custom shortcut issue

[https://github.com/microsoft/vscode/issues/246965](https://github.com/microsoft/vscode/issues/246965)

## Summary

Legitimate bug: on macOS with the ABC input method, Option+I and Option+U are dead keys that trigger composition mode, causing the keybinding to match but the command to not execute. The dispatch sets `isComposing` context key to true before dispatch, which likely prevents the command invocation path in the editor's key handling.

## Change summary

Custom keybindings using Option+I or Option+U on macOS ABC input method match the binding but fail to invoke the command because the keys are dead keys that trigger composition mode.

## Best solution

The keybinding dispatch needs to handle the case where a user has explicitly bound a dead-key combination — either by not entering composition mode for explicitly-bound shortcuts, or by allowing the command to execute despite the composition state. The fix likely involves the interaction between `isComposingGlobalContextKey` (set at keybindingService.ts:282) and how the editor's `softDispatch` or text input handling suppresses commands during composition.
