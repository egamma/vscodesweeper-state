# Issue #322067 — GitHub Copilot's BYOK feature supports passing custom parameters (e.g. `thinking.type`)

[https://github.com/microsoft/vscode/issues/322067](https://github.com/microsoft/vscode/issues/322067)

## Summary

The core ask — passing arbitrary custom parameters (e.g. `thinking.type`) to BYOK model endpoints — is not yet implemented. Commit 4034ee46add added `modelOptions` support but only for `temperature` and `top_p` with `additionalProperties: false`, so custom/thinking parameters cannot be passed. Already promoted to Backlog with 29 upvotes; keeping open.

## Change summary

Allow BYOK custom endpoint models to send arbitrary request parameters (e.g. `thinking.type`, `thinking.budget_tokens`) beyond the current `temperature`/`top_p` allowlist.

## Best solution

Extend the `modelOptions` schema in `extensions/copilot/package.json` and the `_applyConfiguredModelOptions` method in `extensions/copilot/src/extension/byok/node/openAIEndpoint.ts` to support additional parameters — at minimum `thinking` configuration for Messages API endpoints, and ideally a mechanism for arbitrary pass-through parameters. Closely related to https://github.com/microsoft/vscode/issues/319037 which tracks the `thinking` parameter specifically for Messages API.
