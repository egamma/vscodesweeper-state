# Issue #267796 — Add horizontal tab bar for terminals in a standalone window

[https://github.com/microsoft/vscode/issues/267796](https://github.com/microsoft/vscode/issues/267796)

## Summary

Keep open as a feature request for independent auxiliary-window layout. Existing horizontal editor tabs require changing the shared tab setting, which does not satisfy the reporter's Single Tab main-window workflow; independent status-bar visibility also remains missing.

## Change summary

Allow standalone terminal windows to display multiple horizontal tabs and control status-bar visibility independently of the main editor window.

## Best solution

Decide auxiliary-window layout semantics in the shared editor/workbench area: terminal windows should offer local terminal switching without requiring multiple tabs in the main window, and local status-bar changes should not alter the main window. Existing editor tabs should be considered before introducing a separate terminal-only tab system.
