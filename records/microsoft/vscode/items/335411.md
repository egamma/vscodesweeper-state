# Issue #335411 — Source Control Repositories view re-expands repositories with submodules on every visibility change

[https://github.com/microsoft/vscode/issues/335411](https://github.com/microsoft/vscode/issues/335411)

## Summary

Traced and confirmed in `scmRepositoriesViewPane.ts`: the parent repository is force-expanded via `updateParentRepository` on every re-registration of existing submodule repositories when the view becomes visible again, and the stale `viewState` captured once in `renderBody` is reused on each visibility toggle instead of the live tree state — this is a real, localized bug worth routing to the SCM area.

## Change summary

The Source Control Repositories view re-expands a collapsed parent repository containing submodules every time the view is hidden and shown again.

## Best solution

Land the reporter's proposed fix in src/vs/workbench/contrib/scm/browser/scmRepositoriesViewPane.ts: capture tree.getViewState() on hide and reuse it on show, and only auto-expand a parent when it gains its first child rather than on every re-registration.
