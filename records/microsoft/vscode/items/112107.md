# Issue #112107 — Add exists() function to FileSystemProvider

[https://github.com/microsoft/vscode/issues/112107](https://github.com/microsoft/vscode/issues/112107)

## Summary

The public API gap remains on current main: extensions must still call `stat` and catch errors. This team-authored Backlog request should stay open for API design.

## Change summary

Provide a public filesystem existence check that does not require extensions to interpret exceptions from `stat`.

## Best solution

Add `FileSystem.exists(uri)` to `workspace.fs`, mapping only `FileNotFound` to `false` while preserving other errors. This can reuse the existing file-service operation without requiring every `FileSystemProvider` implementation to add a new method.
