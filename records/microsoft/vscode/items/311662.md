# Issue #311662 — Source Control - Git - Submodule behaviour

[https://github.com/microsoft/vscode/issues/311662](https://github.com/microsoft/vscode/issues/311662)

## Summary

A real Git integration gap remains: branch checkout does not update submodule worktrees to the newly checked-out gitlinks. The merge-conflict concern is already covered by an open issue, but that narrower canonical does not absorb the checkout request.

## Change summary

Update submodule worktrees when switching the parent repository branch, and improve recovery from submodule merge conflicts.

## Best solution

The Git area should decide whether parent branch checkout should optionally run a safe submodule update, preserving local submodule changes and avoiding destructive defaults. Consolidate the merge-conflict behavior on https://github.com/microsoft/vscode/issues/164900 and keep this issue focused on checkout behavior.
