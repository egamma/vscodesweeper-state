# Issue #276105 — Lots of tools I didn't choose in my tool set

[https://github.com/microsoft/vscode/issues/276105](https://github.com/microsoft/vscode/issues/276105)

## Summary

Keep open: the behavior is explained by `edit` being a nested tool set, but the current flat quick pick obscures that expansion. A maintainer has identified a concrete UX improvement—rendering tools and tool sets hierarchically—and the team-authored issue is protected from judgment closes.

## Change summary

Make the tool-set quick pick distinguish explicitly selected tools from tools included through nested tool sets.

## Best solution

Represent nested tool sets as a hierarchy in the tool-selection quick pick so users can see that selecting `edit` includes its member tools, while preserving the current tool-set expansion semantics.
