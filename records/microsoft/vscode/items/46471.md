# Issue #46471 — Expose API for variable substitution in contributed configuration

[https://github.com/microsoft/vscode/issues/46471](https://github.com/microsoft/vscode/issues/46471)

## Summary

A substantial API gap remains on current main, and this well-supported Backlog request is the best canonical issue for it. Existing task-specific resolution and internal resolver plumbing do not let extensions generally resolve or contribute variables.

## Change summary

Expose extension APIs for resolving VS Code substitution variables and contributing custom variables for use in configuration.

## Best solution

Retain this as the canonical API-design issue and define a scoped asynchronous extension API for resolving supported variables and registering namespaced custom variables. The design should explicitly address workspace context, command/input interaction, configuration compatibility, and extension lifecycle.
