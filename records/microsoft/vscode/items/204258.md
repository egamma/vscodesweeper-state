# Issue #204258 — Configurable Position for Accessibility-Related Text Notifications in Code Editor

[https://github.com/microsoft/vscode/issues/204258](https://github.com/microsoft/vscode/issues/204258)

## Summary

Keep open: current accessibility-signal settings control enablement and delays, but do not offer announcement-before-line ordering. The maintainer identified a real tradeoff—assertive announcements can suppress line speech—so this needs accessibility design and screen-reader evaluation rather than a simple switch.

## Change summary

Allow editor accessibility announcements, such as errors on a line, to be read before the line text instead of after it.

## Best solution

Establish whether an opt-in editor announcement mode can deliver the signal before long-line speech without losing the line content. Preserve the existing polite default and evaluate the speech and braille behavior with affected users before settling the configuration contract.
