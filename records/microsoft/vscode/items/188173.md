# Issue #188173 — Add an API to get a terminal's selection

[https://github.com/microsoft/vscode/issues/188173](https://github.com/microsoft/vscode/issues/188173)

## Summary

The selection API exists only as a proposed API and remains intentionally unfinalized while the broader terminal-buffer design is explored. This active API-proposal issue should remain open until that design either stabilizes or supersedes it.

## Change summary

Expose the active terminal's selected text through the stable extension API.

## Best solution

Resolve the selection API as part of the terminal-buffer API tracked by https://github.com/microsoft/vscode/issues/207504, then either finalize a compatible stable API here or explicitly retire the standalone proposal.
