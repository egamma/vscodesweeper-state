# Issue #200865 — breakpoint decorations are not always hidden for folded regions

[https://github.com/microsoft/vscode/issues/200865](https://github.com/microsoft/vscode/issues/200865)

## Summary

Keep open: current source still allows wrapped lines to mask folded lines in the decoration-query fast path, leaving hidden breakpoint decorations visible. The issue already has the appropriate debug and editor-folding labels.

## Change summary

Hide breakpoint decorations inside folded regions regardless of how many view lines unrelated wrapped text contributes.

## Best solution

Make editor view-model decoration queries consistently exclude decorations confined to hidden lines, while preserving decorations on visible wrapped lines and existing range-spanning behavior.
