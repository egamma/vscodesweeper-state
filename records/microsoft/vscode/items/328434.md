# Issue #328434 — Enhanced support for legacy terminal shells

[https://github.com/microsoft/vscode/issues/328434](https://github.com/microsoft/vscode/issues/328434)

## Summary

Keep open as a feature request: existing terminal capture and selection tools only partially cover shell-independent context, and agent terminals do not inherit an active shell's post-launch environment. Related requests do not own the full scope.

## Change summary

Make recent output from legacy-shell terminals available to Copilot without manual selection, and optionally preserve sourced environment changes when creating agent terminals.

## Best solution

Provide an explicit, bounded way for Copilot to obtain recent output from a user terminal without requiring shell integration, reusing existing capture infrastructure. Evaluate active-session environment continuity separately, since adding tcsh shell integration alone would not deliver that behavior.

## Evidence

- **Existing capture infrastructure:** extensions/copilot/src/platform/terminal/vscode/terminalBufferListener.ts already captures onDidWriteTerminalData without checking shell integration, retaining 40 data events. getBufferForTerminal defaults to a 16,000-character tail, and TerminalServiceImpl exposes these buffers. This is not a configurable last-N-lines context feature; capture infrastructure alone does not establish that arbitrary active-terminal output reaches the model.
- **Existing context tools are partial coverage:** src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/getTerminalLastCommandTool.ts requires CommandDetection and returns an unavailable-capability message otherwise. getTerminalOutputTool.ts requires an execution ID registered by RunInTerminalTool, rather than reading any user terminal. terminal.chatAgentTools.contribution.ts offers Add Terminal Selection to Chat, which avoids copy/paste but still requires manual selection.
- **Existing settings do not deliver the central ask:** src/vs/workbench/contrib/terminal/common/terminalConfiguration.ts registers terminal.integrated.scrollback and terminal.integrated.env.linux: these control retained terminal lines and configured launch variables, respectively, not automatic Copilot context or environment changes sourced inside an already-running shell. terminalChatAgentToolsConfiguration.ts exposes agent terminal profiles but no corresponding last-N-lines context option.
- **Agent terminal creation:** src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/toolTerminalCreator.ts, ToolTerminalCreator._createCopilotTerminal, constructs launch configuration from agent-specific variables and the selected profile's environment, then calls ITerminalService.createTerminal. It does not derive the new terminal's environment from the active shell's current session.
