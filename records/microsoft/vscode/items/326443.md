# Issue #326443 — Marketplace search results are misleading for Python formatters

[https://github.com/microsoft/vscode/issues/326443](https://github.com/microsoft/vscode/issues/326443)

## Summary

The misleading result reflects a real formatter-discovery gap, but the requested ranking, capability labeling, and filtering are enhancements rather than broken formatter behavior. The issue should remain open and be routed to the Marketplace/extensions owners.

## Change summary

Improve Marketplace discovery so searches for Python formatters prioritize or filter to extensions that actually provide document formatting.

## Best solution

Establish a trustworthy formatter-capability signal that Marketplace search and extension details can expose, rather than relying only on search text or the publisher-selected Formatters category. Preserve the existing no-provider flow that opens a language-specific formatter search.
