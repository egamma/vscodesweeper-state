# Issue #95423 — ${file} - must be the current opened file, but points to the name of output pane

[https://github.com/microsoft/vscode/issues/95423](https://github.com/microsoft/vscode/issues/95423)

## Summary

The defect remains source-reproducible on current main: debug variable substitution still prefers the extension host's active text editor, which can be the focused Output view, over the active editor tab. The issue should remain open for a bounded fix that preserves remote resolution behavior.

## Change summary

When the Output pane has focus, debug substitution resolves `${file}` to the output channel resource instead of the file open in the active editor tab.

## Best solution

Make extension-host file-variable resolution use the active editor-part resource when a panel-backed text editor has focus, while retaining the current behavior for ordinary editors, notebooks, diffs, custom editors, and remote workspaces.
