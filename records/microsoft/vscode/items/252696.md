# Issue #252696 — Remove discoverability feature for suggest

[https://github.com/microsoft/vscode/issues/252696](https://github.com/microsoft/vscode/issues/252696)

## Summary

The temporary terminal-suggest discoverability feature remains wired into current main, so the planned cleanup is still necessary. The maintainers explicitly agreed to remove it and subsequently deferred the timing; neither the original implementation nor the closed color-feedback issue completes that work.

## Change summary

Retire the temporary discoverability treatment introduced for terminal suggestion configuration.

## Best solution

Remove the temporary first-use highlighting and its onboarding bookkeeping while preserving terminal suggestions, configuration access, and first-show latency telemetry. Confirm whether the permanent Learn More action should also disappear, since the discussion only floated that additional removal.

- **Trace:**

  > TerminalSuggestAddon._ensureSuggestWidget registers an onDidShow handler that calls _updateDiscoverabilityState, which constructs TerminalSuggestShownTracker and updates the widget element.
