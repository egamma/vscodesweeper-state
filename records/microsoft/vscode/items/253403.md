## Summary

Team-authored polish request for warning users when starting duplicate cloud agent sessions on the same issue. No implementation found on main; the request remains valid.

## Change summary

Users can start multiple cloud agent sessions on the same GitHub issue without any deduplication warning, risking wasted capacity and conflicts.

## Best solution

Add a confirmation prompt or warning when a user attempts to start a cloud agent session on an issue that already has an active agent session, especially across collaborators. This likely belongs in the cloud agent session creation flow.
