# Issue #253403 — able to start work on the same PR 3 times

[https://github.com/microsoft/vscode/issues/253403](https://github.com/microsoft/vscode/issues/253403)

## Summary

Keep open: the request concerns repeated cloud-agent work on the same issue, not the same PR. Current source has task-local safeguards, but they do not establish coverage of the requested issue-level warning, especially when a coworker initiated the existing work.

## Change summary

Warn before starting another cloud-agent task for an issue that already has an agent working on it.

## Best solution

Provide an issue-aware warning that identifies existing active work and lets the user deliberately proceed with another task. Establish whether the available GitHub task data can detect coworkers' work before committing to that scope.
