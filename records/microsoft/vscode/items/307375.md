# Issue #307375 — bug: treeView: drag-and-drop does not work when the tree view is initially empty

[https://github.com/microsoft/vscode/issues/307375](https://github.com/microsoft/vscode/issues/307375)

## Summary

Still reproduces on main: when a tree view with a DnD controller is initially empty, the welcome view's CSS (`display: none`) hides the tree container, preventing drop events from reaching the list view. The existing guard at line 1143 of treeView.ts only prevents the `hide` class — it doesn't account for the welcome-view CSS mechanism.

## Change summary

Drag-and-drop into an extension tree view does not work when the tree starts with zero elements, because the welcome view hides the tree container.

## Best solution

Update `shouldShowWelcome()` in `CustomTreeViewPane` (src/vs/workbench/browser/parts/views/treeView.ts, line 136) to return `false` when the tree view has a `dragAndDropController` set — similar to the existing guard in `updateContentAreas()` at line 1143. This ensures the tree container stays visible (and receives drop events) even when it has no items.
