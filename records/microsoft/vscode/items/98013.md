# Issue #98013 — Support Language, not just Editor Language in the keybindings "when" property.

[https://github.com/microsoft/vscode/issues/98013](https://github.com/microsoft/vscode/issues/98013)

## Summary

The requested embedded-language keybinding context remains missing, but the verified open issue https://github.com/microsoft/vscode/issues/107989 covers the same capability. Consolidate there while preserving this report's Vue HTML selection-formatting example.

## Change summary

Allow keybinding when clauses to match the embedded language at the cursor rather than only the document's language.

## Best solution

Track the embedded-language context capability in https://github.com/microsoft/vscode/issues/107989, retaining the existing document-level editorLangId behavior and carrying over the Vue formatting and regex-matching use cases.
