# Issue #237359 — Can't use Notebook Find (ctrl+f) in notebook diff viewer

[https://github.com/microsoft/vscode/issues/237359](https://github.com/microsoft/vscode/issues/237359)

## Summary

Still reproduces on main: Ctrl+F in a notebook diff viewer (side-by-side mode) fails because `getNotebookEditorFromEditorPane` returns `undefined` — `inlineNotebookEditor` only exists when `_inlineView` is true. The find infrastructure has no path for the side-by-side diff case.

## Change summary

Ctrl+F (notebook find) does not work in the notebook diff viewer when comparing notebook versions side-by-side.

## Best solution

Extend the notebook diff editor to support find in side-by-side mode, either by exposing a notebook editor for the modified side or by adding a dedicated find contribution to the diff editor that can search across both sides. Likely files: `src/vs/workbench/contrib/notebook/browser/diff/notebookDiffEditor.ts` and `src/vs/workbench/contrib/notebook/browser/notebookBrowser.ts`.
