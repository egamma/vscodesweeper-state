# Issue #282318 — Selecting property in parameter list after selecting property type definition does not highlight usages of that property

[https://github.com/microsoft/vscode/issues/282318](https://github.com/microsoft/vscode/issues/282318)

## Summary

Still reproduces on main: the word highlighter's early-return optimization skips re-querying when the cursor moves between already-highlighted ranges, causing stale highlights when the language server returns asymmetric results. An open PR (#294658) addresses the related issue but has not merged.

## Change summary

When clicking from one highlighted occurrence to another (e.g. between a property type definition and its destructured parameter), the document highlights do not update because the highlighter assumes highlights are symmetric.

## Best solution

Land (or close and rework) the open PR https://github.com/microsoft/vscode/pull/294658 which changes the early-return optimization in `src/vs/editor/contrib/wordHighlighter/browser/wordHighlighter.ts` (lines 680-686) to only skip re-fetching when the cursor stays within the original query word range, not any highlighted range. This issue and #294657 share the same root cause.
