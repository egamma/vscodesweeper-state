# Issue #282318 — Selecting property in parameter list after selecting property type definition does not highlight usages of that property

[https://github.com/microsoft/vscode/issues/282318](https://github.com/microsoft/vscode/issues/282318)

## Summary

The missing highlight is a confirmed editor refresh problem, not the intentional distinction between type-property and local-variable references. The older, open asymmetric-highlighting issue tracks the same observable failure when moving between already highlighted occurrences.

## Change summary

Refresh occurrence highlights when moving from a destructured parameter's type property to its local binding so body usages become highlighted.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode/issues/238301, preserving the TypeScript destructuring example and provider logs as an acceptance case for refreshing asymmetric highlight sets.
