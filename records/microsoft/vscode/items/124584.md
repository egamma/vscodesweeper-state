# Issue #124584 — Terminal.creationOptions API shows default options in remotes

[https://github.com/microsoft/vscode/issues/124584](https://github.com/microsoft/vscode/issues/124584)

## Summary

Still reproduces on main: for UI-created terminals in remote scenarios, `Terminal.creationOptions` surfaces default/unresolved shell launch config values because the shell resolution happens on the remote side after `_onTerminalOpened` fires.

## Change summary

Terminal.creationOptions API returns default options instead of the actual resolved options for UI-created terminals in remote scenarios.

## Best solution

Update `_onTerminalOpened` in `src/vs/workbench/api/browser/mainThreadTerminalService.ts` (or the terminal instance lifecycle) to populate `shellLaunchConfig` with the resolved remote options before notifying the ext host, or defer the notification until resolution completes. The related closed issue https://github.com/microsoft/vscode/issues/135570 was closed as a duplicate of this one, confirming the same root cause.
