# Issue #312891 — `/chronicle` may not include empty workspace sessions

[https://github.com/microsoft/vscode/issues/312891](https://github.com/microsoft/vscode/issues/312891)

## Summary

Team-authored bug report about /chronicle excluding empty workspace sessions. The session tracker stores sessions without cwd/repository when no workspace folder is open, but the chronicle query prompts and cloud exporter likely filter or group by repository, omitting these sessions. No fix commit references this issue.

## Change summary

The /chronicle command omits sessions that were run in an empty workspace (no folder opened).

## Best solution

Ensure chronicle queries and the standup prompt include sessions where `cwd` and `repository` are NULL/empty, perhaps grouping them under an "(empty workspace)" heading. The fix likely touches the chronicle prompt files (e.g. `extensions/copilot/assets/prompts/chronicle-standup.prompt.md`) and possibly the `sessionStoreSqlTool.ts` model description or `remoteSessionExporter.ts` query logic.
