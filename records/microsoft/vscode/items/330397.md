# Issue #330397 — Add a diarized meeting mode for continuous agent orchestration

[https://github.com/microsoft/vscode/issues/330397](https://github.com/microsoft/vscode/issues/330397)

## Summary

Keep open: existing dictation and Voice Mode provide useful foundations but do not cover speaker-attributed meeting transcripts with continuous orchestration. This team-authored request needs product and cross-layer design, not a judgment close.

## Change summary

Add continuous meeting transcription with speaker attribution, timestamped transcript retention, and periodic context delivery to a dedicated agent that delegates work to other sessions.

## Best solution

Design an opt-in meeting workflow that preserves a raw speaker-attributed transcript and keeps an orchestration session responsive while delegated work runs elsewhere. Establish the transcript lifecycle and context-delivery contract before selecting a transcription backend or implementing session integration.
