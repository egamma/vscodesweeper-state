# Issue #336534 — Add an indicator for chat sessions with unkept file changes

[https://github.com/microsoft/vscode/issues/336534](https://github.com/microsoft/vscode/issues/336534)

## Summary

Reasonable, freshly-filed request to distinguish chat sessions with unkept/pending edits from those without in the Agent Sessions view; no canonical issue found among related items, and it's too new to judge community traction.

## Change summary

Add a visible indicator/filter in the Chat/Agent Sessions list to identify sessions that still have un-kept (pending) file edits, plus a way to review/keep/discard them, and the reporter also notes the +/- diff counter used to distinguish this seems to now render for all sessions rather than just ones with pending changes.

## Best solution

In src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsViewer.ts, the +/- diff badge (renderDiff, getAgentChangesSummary) currently reflects total diff stats rather than 'has un-kept changes' state — worth checking with the Agent Sessions/chat editing team whether the badge should differentiate pending vs. already-kept edits, and whether a dedicated filter for 'pending changes' sessions is worth adding to agentSessionsFilter.ts.
