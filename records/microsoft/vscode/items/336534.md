# Issue #336534 — Add an indicator for chat sessions with unkept file changes

[https://github.com/microsoft/vscode/issues/336534](https://github.com/microsoft/vscode/issues/336534)

## Summary

Keep open: current session cards expose change statistics but do not distinguish edits awaiting Keep, and the available filters do not cover that state. Older related reports do not own the full requested discovery and filtering capability.

## Change summary

Distinguish chat sessions with unkept edits from sessions with historical changes, ideally with filtering and access to the affected files.

## Best solution

Expose pending-review state separately from historical change totals in Chat session history, with a clear path back to the affected files and existing Keep/Undo controls. Decide the indicator and filtering scope before implementation.
