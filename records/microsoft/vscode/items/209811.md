# Issue #209811 — Using `\w` in Find dialog doesn't find non-English Unicode characters

[https://github.com/microsoft/vscode/issues/209811](https://github.com/microsoft/vscode/issues/209811)

## Summary

The matching behavior is intentional ECMAScript semantics, but the report identifies a real documentation gap. A team member labeled it after that distinction was already documented, so it should remain open as editor-find polish.

## Change summary

Document that editor Find uses JavaScript regular expressions, where `\w` excludes most non-ASCII letters, and describe Unicode property escapes such as `\p{L}`.

## Best solution

Update the Advanced Find and Replace documentation to identify the JavaScript/ECMAScript regex dialect and provide a Unicode-letter example using `\p{L}`.
