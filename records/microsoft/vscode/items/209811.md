# Issue #209811 — Using `\w` in Find dialog doesn't find non-English Unicode characters

[https://github.com/microsoft/vscode/issues/209811](https://github.com/microsoft/vscode/issues/209811)

## Summary

Current editor Find preserves JavaScript regex semantics, so Unicode mode does not make \w match ä; the remaining actionable gap is documenting the regex flavor and Unicode alternatives. Keep this accepted issue open: its existing bug label bars an as-designed decline, and the contributor's explanation is not a later maintainer decision.

## Change summary

Clarify why editor Find's \w excludes letters such as ä and document how to match Unicode letters.

## Best solution

Document the editor Find regex engine, its \w semantics, and Unicode property escapes in the advanced find-and-replace documentation. Preserve existing JavaScript pattern compatibility rather than silently redefining \w.
