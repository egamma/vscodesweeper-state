# Issue #206795 — Double-clicking on `...` used as argument value selects more than `...`

[https://github.com/microsoft/vscode/issues/206795](https://github.com/microsoft/vscode/issues/206795)

## Summary

Still reproduces on main: double-clicking `...` selects all adjacent separator characters (e.g. `=...)):`) because the word selection logic groups all consecutive word-separator-class characters into one 'separator word' without distinguishing between different separator characters.

## Change summary

Double-clicking on Python's `...` (Ellipsis literal) selects more than just the three dots, pulling in adjacent punctuation like `=`, `)`, and `:`.

## Best solution

Refine the separator-word grouping in `cursorWordOperations.ts` so that double-clicking a run of identical separator characters (like `...`) selects only that run, not adjacent but different separators. The fix is localized to `_findPreviousWordOnLine` / `_findNextWordOnLine` / `_findEndOfWord` but is a design decision about whether separator words should group heterogeneous separators — needs an editor-area owner's call.
