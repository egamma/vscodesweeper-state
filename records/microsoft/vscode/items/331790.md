# Issue #331790 — Copilot edit tools report success even when the underlying FileSystemProvider.writeFile fails

[https://github.com/microsoft/vscode/issues/331790](https://github.com/microsoft/vscode/issues/331790)

## Summary

Current main still reports unconditional success after a failed save: the chat-editing path discards the save result, and the internal edit tool observes only that editing ended. This is a confirmed core bug that should remain open and route to the chat edit-tools area.

## Change summary

Copilot edit tools claim that a file was updated even when its FileSystemProvider rejects the underlying write and nothing is persisted.

## Best solution

Carry the asynchronous save outcome through chat-edit completion to the invoking tool so a failed provider write produces a tool error while preserving the dirty editor and existing user-facing save notification.
