# Issue #349647 — Screen Reader Optimized indicator opens a misleading "enable?" prompt; answering "No" silently disables screen reader mode

[https://github.com/microsoft/vscode/issues/349647](https://github.com/microsoft/vscode/issues/349647)

## Summary

The misleading enabled-state prompt and its destructive No action are confirmed in current source. Keep this open for the accessibility owner; the separate claim that Yes leaves the notification open is contradicted by the shared notification implementation.

## Change summary

Clicking Screen Reader Optimized asks to enable an already-enabled mode, while No disables it.

## Best solution

Make the indicator's interaction accurately describe the current mode and require an explicitly named disable action before turning it off. Decide whether the indicator remains a state-aware prompt or follows the documented direct-toggle behavior, without expanding this into an automatic-detection redesign.
