# Issue #245617 — “Go to failed cell” doesn’t reveal error line in large cells

[https://github.com/microsoft/vscode/issues/245617](https://github.com/microsoft/vscode/issues/245617)

## Summary

Still reproduces on main: the 'Go to Most Recently Failed Cell' action calls `focusNotebookCell(lastFailedCell, 'container')` which reveals the cell but does not scroll to the error line within a large cell. An open community PR (#307553) is attempting a fix.

## Change summary

Clicking 'Go to failed cell' in the notebook toolbar reveals the top of the cell instead of scrolling to the error line when the cell is taller than the viewport.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/307553 which targets this exact issue. The fix needs to retrieve the error line from execution state and use a line-aware reveal (e.g. `revealOffsetInCenter` or `focusNotebookCell` with a line range) instead of plain container focus.
