Keep open for the confirmed remaining custom-agent model-resolution failure. Explicit provider-qualified task.model reportedly works in 1.138, but selecting the same BYOK model through .agent.md frontmatter still fails; current source preserves that frontmatter value without resolving it.

## Change summary

Ensure Agent Host subagents can select configured BYOK models through both explicit task.model overrides and custom-agent model declarations.
