# Issue #134405 — Add file references provider 

[https://github.com/microsoft/vscode/issues/134405](https://github.com/microsoft/vscode/issues/134405)

## Summary

Valid unimplemented API proposal — no `FileReferenceProvider` or equivalent exists on current main; the `keep` label signals team intent to retain this request.

## Change summary

Add a VS Code extension API (`FileReferenceProvider`) that lets language extensions report references to a given file, enabling consistent cross-language 'find file references' and safe-delete flows.

## Best solution

Implement a proposed `FileReferenceProvider` API in `src/vscode-dts/` with a corresponding registration point, integrating with the references viewlet. This would replace the custom per-language workarounds (Markdown, TypeScript) and unblock LSP standardization (microsoft/language-server-protocol#2047).
