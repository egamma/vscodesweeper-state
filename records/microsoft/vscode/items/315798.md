# Issue #315798 — chat debug view UI changes drastically when moved to another group

[https://github.com/microsoft/vscode/issues/315798](https://github.com/microsoft/vscode/issues/315798)

## Summary

Still open — the chat debug editor (a singleton EditorPane) renders incorrectly when dragged to another editor group. No fix commit references this issue, and the bug is plausibly caused by the singleton lifecycle not properly re-initializing the view state when the editor pane is recreated in a new group.

## Change summary

The Agent Debug Logs editor UI changes drastically when the editor tab is dragged into a different editor group.

## Best solution

Investigate `ChatDebugEditor.setEditorVisible` and `createEditor` lifecycle — when the singleton input moves to a new group, a new `ChatDebugEditor` pane is created but the view state and sub-views may not be correctly initialized or the old pane's DOM may be detached without the new one picking up the active session context. The fix likely lives in `src/vs/workbench/contrib/chat/browser/chatDebug/chatDebugEditor.ts`.
