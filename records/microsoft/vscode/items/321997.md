# Issue #321997 — Impossible to copy links from the copilot chat produced by agent

[https://github.com/microsoft/vscode/issues/321997](https://github.com/microsoft/vscode/issues/321997)

## Summary

Current main already ships a dedicated 'Copy Link' entry in the chat transcript context menu (plus selection-aware Copy), so the reported gap appears resolved — but this is a team-authored item and no commit or PR references #321997, so the implemented-on-main bar is not met and it stays open for the author to confirm and close.

## Change summary

Right-clicking a link in a Copilot chat response offered only 'Copy', which copied the whole conversation, with no way to copy the link target itself.

## Best solution

Confirm on a current build that the chat context menu's 'Copy Link' (workbench.action.chat.copyLink, group '0_link') covers the case and close as completed; no further code change looks necessary.
