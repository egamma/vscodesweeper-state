# Issue #336522 — Status bar changes colors when not focued

[https://github.com/microsoft/vscode/issues/336522](https://github.com/microsoft/vscode/issues/336522)

## Summary

A second reporter confirmed with a video that the status bar reverts to the default blue background when the window loses focus, even with `statusBar.background` overridden via `workbench.colorCustomizations`; setting the undocumented `statusBar.inactiveBackground` color works around it. The code path in statusbarPart.ts should fall back to the user's `statusBar.background` override when `statusBar.inactiveBackground` is unset, so the root cause needs further investigation (possibly theme resolution in a split/auxiliary window) before a fix can be scoped.

## Change summary

Status bar background reverts to the default blue color on window blur, ignoring the user's `statusBar.background` override, unless `statusBar.inactiveBackground` is also set.
