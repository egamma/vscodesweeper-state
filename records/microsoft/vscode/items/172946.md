## Summary

Keep open: multiple reporters confirm disruptive scrolling during manual merge resolution, including with extensions disabled. This issue already owns a duplicate report, and neither a verified fix nor an older canonical covering the full report was found.

## Change summary

The merge editor reportedly omits diffs for a moved file and repeatedly scrolls away from manual edits in the Result pane.

## Best solution

Make manual conflict resolution preserve the editing position while diffs and alignment update, and establish whether the moved-file diff failure remains a separate defect. Diagnose the viewport behavior in the merge editor and the renamed-file inputs in the built-in Git extension before selecting a bounded fix.
