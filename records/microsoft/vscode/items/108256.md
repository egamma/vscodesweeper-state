# Issue #108256 — resources#relativePath does not honour path casing strategy

[https://github.com/microsoft/vscode/issues/108256](https://github.com/microsoft/vscode/issues/108256)

## Summary

Still valid on current main: the `relativePath` method in `ExtUri` still has the `file` scheme special case (line 239 of src/vs/base/common/resources.ts) that bypasses `_ignorePathCasing`, exactly as described. The fix commit (9997c23708a) never landed on main, and PR #108796 was closed without merging.

## Change summary

ExtUri.relativePath bypasses the _ignorePathCasing strategy for file:// URIs by early-returning through a file-scheme special case that delegates to Node's paths.relative.

## Best solution

Remove or rework the `from.scheme === Schemas.file` early-return in `ExtUri.relativePath` (src/vs/base/common/resources.ts:239-242) so that file URIs flow through the `_ignorePathCasing` logic. The challenge noted in the discussion is ensuring all callers pass canonical URIs or use `IUriIdentityService.extUri` — the closed PR #108796 uncovered drive-letter casing issues that need addressing as part of the fix.
