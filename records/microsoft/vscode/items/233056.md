# Issue #233056 — TreeView: MaxCallStackError - Nesting

[https://github.com/microsoft/vscode/issues/233056](https://github.com/microsoft/vscode/issues/233056)

## Summary

Keep open: the merged PR fixes oversized sibling insertion, but current source still recursively constructs deeply nested trees and can exhaust the call stack. The older rendering-hang issue overlaps with scrolling performance, not the full expansion and collapse failure reported here.

## Change summary

Deeply nested extension TreeViews overflow the call stack during expansion and can leave collapse, focus, and scrolling broken.

## Best solution

Make deep-tree construction and subsequent expansion/collapse stack-safe while preserving tree state and event semantics. Coordinate scrolling-performance work with https://github.com/microsoft/vscode/issues/213839 without treating that narrower rendering diagnosis as completion of this report.
