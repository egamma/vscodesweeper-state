# Issue #233056 — TreeView: MaxCallStackError - Nesting

[https://github.com/microsoft/vscode/issues/233056](https://github.com/microsoft/vscode/issues/233056)

## Summary

Partially fixed: PR #236493 addressed the sibling expand/collapse stack overflow in listView.ts, but the nesting-related MaxCallStackError remains — `createTreeNode` in indexTreeModel.ts is still purely recursive with no depth guard, and the related issue #213839 is still open.

## Change summary

Deeply nested TreeView data causes MaxCallStackError due to unbounded recursion in the tree model and async data tree.

## Best solution

Convert the recursive `createTreeNode` in `src/vs/base/browser/ui/tree/indexTreeModel.ts` (and the recursive `asTreeElement` in `asyncDataTree.ts`) to iterative implementations or add a depth cap, addressing both this issue and the related https://github.com/microsoft/vscode/issues/213839.
