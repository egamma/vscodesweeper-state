# Issue #319396 — Page jumps around while taking a full page screenshot

[https://github.com/microsoft/vscode/issues/319396](https://github.com/microsoft/vscode/issues/319396)

## Summary

Keep open: full-page capture still has no capture-specific presentation to mask page transitions. This team-authored UX improvement has neither a verified fixing commit nor an open canonical duplicate.

## Change summary

Hide distracting page transitions while the integrated browser captures a full-page screenshot.

## Best solution

Provide a stable, temporary capture presentation in the integrated browser without including that presentation in the resulting screenshot. Agree on the progress treatment, then verify that native-view masking preserves capture output and restores normal interaction.
