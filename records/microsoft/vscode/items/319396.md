# Issue #319396 — Page jumps around while taking a full page screenshot

[https://github.com/microsoft/vscode/issues/319396](https://github.com/microsoft/vscode/issues/319396)

## Summary

Valid polish request from a team member: the full-page screenshot capture in the integrated browser visibly scrolls the page, and the suggestion is to mask that with an overlay/blur + spinner. No fix has landed on main; the issue is still actionable.

## Change summary

Full-page screenshot capture in the integrated browser causes visible page jumping as it scrolls to capture beyond the viewport.

## Best solution

Add a visual overlay (e.g. blur + "Capturing…" spinner) in the browser editor while the CDP `Page.captureScreenshot` with `captureBeyondViewport` is in flight, hiding the scroll/layout shifts from the user. The overlay logic likely belongs in `src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorChatFeatures.ts` (around `addFullPageScreenshotToChat`) coordinated with the overlay manager.
