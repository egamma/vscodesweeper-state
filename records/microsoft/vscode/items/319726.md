# Issue #319726 — Failed to open chat session: Illegal argument: character must be non-negative

[https://github.com/microsoft/vscode/issues/319726](https://github.com/microsoft/vscode/issues/319726)

## Summary

The selection-coordinate mismatch identified in the discussion remains in current main: loading a CLI session with a zero-based selection can throw and prevent its history from opening. Keep this team-authored report open; the source confirms a remaining defect, not a completed fix or verified duplicate.

## Change summary

Opening Copilot CLI chat history fails when a selection attachment is converted into a range with negative coordinates.

## Best solution

Make selection attachment production and history reconstruction consistently honor the SDK's zero-based contract, preserving exact selection locations from both editor context and prompt references. Cover zero-coordinate selections and nonzero round trips in the existing Copilot CLI unit suites.
