# Issue #300070 — Broken GPT5.4 in chat interface

[https://github.com/microsoft/vscode/issues/300070](https://github.com/microsoft/vscode/issues/300070)

## Summary

The reported GPT-5.4 failure after adding many images was fixed by limiting accumulated base64 image data in chat requests. The same image-triggered 413 failure was verified in related reports and closed after the fix shipped in VS Code 1.116.

## Change summary

Sending a GPT-5.4 agent request with ten images caused Copilot Chat to fail while another model handled the same request.

## Best solution

Keep the shipped image-budget behavior from commit 4fa2ff42e96aed774d211ec4e0f605fea6a6eeb0, which substitutes placeholders before accumulated image data makes the request exceed the service limit.
