# Issue #317902 — `@types/vscode` `vscode.lm.selectChatModels` return type is limited

[https://github.com/microsoft/vscode/issues/317902](https://github.com/microsoft/vscode/issues/317902)

## Summary

The `@types/vscode` type for `selectChatModels` is correct — it returns `LanguageModelChat[]`. The extra properties the reporter sees at runtime (`capabilities`, `pricing`, etc.) come from proposed APIs that have not been finalized and are intentionally excluded from the stable type contract.

## Change summary

Reporter observes that the runtime objects returned by `selectChatModels` have more properties (like `capabilities`) than the `LanguageModelChat` type declares.

## Best solution

Close as a question: the stable type is correct. The additional runtime properties are declared in proposed API files (`vscode.proposed.languageModelCapabilities.d.ts`, `vscode.proposed.languageModelPricing.d.ts`) and will appear in `@types/vscode` only once finalized.

  > 
  > Proposed APIs are available at runtime but excluded from `@types/vscode` until they are finalized. Extensions can opt in by enabling the corresponding proposed API in their `package.json`. See the [proposed API guide](https://code.visualstudio.com/api/advanced-topics/using-proposed-api) for details.
