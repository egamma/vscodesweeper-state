# Issue #317902 — `@types/vscode` `vscode.lm.selectChatModels` return type is limited

[https://github.com/microsoft/vscode/issues/317902](https://github.com/microsoft/vscode/issues/317902)

## Summary

The stable API declaration promises `LanguageModelChat[]`, but the runtime objects expose additional internal model metadata and a differently shaped capabilities object. The declared return type is intentionally the narrower public contract; however, the report identifies a real API-boundary mismatch worth clarifying rather than closing from the current evidence.

## Change summary

Clarify or correct the stable TypeScript return contract for `vscode.lm.selectChatModels` so it accurately describes the supported consumer-visible model objects.

## Best solution

Have the extension API owners decide which runtime fields are intentionally public, then either normalize the ext-host DTO into the documented `LanguageModelChat` contract or formally expose the supported metadata through the stable API without leaking internal-only fields.
