# Issue #304680 — The function of adding change summaries and reviews can be included in the git panel.

[https://github.com/microsoft/vscode/issues/304680](https://github.com/microsoft/vscode/issues/304680)

## Summary

The requested workflow is already available: Copilot provides commit-message generation and code review in Source Control, with review suggestions that can be applied or passed into chat for fixes.

## Change summary

Add Source Control actions to generate a commit summary, review pending changes, and carry review findings into a conversation for quick fixes.

## Best solution

Use the existing Generate Commit Message and Code Review actions rather than introduce parallel buttons. Existing review comments already support applying suggestions and continuing in inline chat with an automatically populated fix prompt.

  > - Generate Commit Message (`github.copilot.git.generateCommitMessage`) fills the commit input with a generated summary.
