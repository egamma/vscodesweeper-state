# Issue #337421 — Generated commit messages often don't accurately describe the actual changes

[https://github.com/microsoft/vscode/issues/337421](https://github.com/microsoft/vscode/issues/337421)

## Summary

Thanks for the report. This is quality feedback on LLM-generated commit messages: the output is model-dependent and non-deterministic, not a deterministic defect, so there is no code path to trace. It stays open as product feedback for the Copilot commit-message prompt, which lives in this repo.

## Change summary

Commit messages generated from the Source Control sparkle button sometimes use the wrong conventional-commit type, run too long, and speculate about changes instead of describing the diff.

## Best solution

Tune the commit-message generation prompt so it picks the commit type from the diff (a version bump is a chore, not a fix), keeps the subject line short, and describes only what is visible in the diff. The related model-selection and chat-context work in https://github.com/microsoft/vscode/issues/273271 may also help.
