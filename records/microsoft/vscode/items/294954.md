# Issue #294954 — Simplify "Checkout" menu when only one branch exists

[https://github.com/microsoft/vscode/issues/294954](https://github.com/microsoft/vscode/issues/294954)

## Summary

The requested interaction simplification is still missing: current main creates a Checkout submenu even for a single eligible reference. Keep the existing under-discussion classification; no verified canonical owns this specific behavior.

## Change summary

Show a direct "Checkout <branch-name>" action instead of a submenu when a commit has only one checkout target, with ellipsis for long names.

## Best solution

Consider a direct, branch-named Checkout action for a single eligible target while retaining the submenu for multiple targets. Agree on long-name presentation and how branch, remote-branch, and tag references affect eligibility before changing the shared SCM menu behavior.
