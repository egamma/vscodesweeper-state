# Issue #302891 — Allow for extensions and settings to be imported between Insiders and Stable

[https://github.com/microsoft/vscode/issues/302891](https://github.com/microsoft/vscode/issues/302891)

## Summary

A real onboarding gap remains: current setup offers Settings Sync and manual profile import, but does not detect another VS Code channel and offer to transfer its setup. This team-authored feature request should remain open for product design.

## Change summary

Offer first-run import of extensions, settings, and related setup between installed Stable and Insiders channels.

## Best solution

Add an explicit, consent-based onboarding step that detects the sibling channel and selectively imports its profile resources, while preserving intentional Stable/Insiders isolation. Reuse the profile import and user-data migration services rather than creating another transfer format.
