# Issue #302891 — Allow for extensions and settings to be imported between Insiders and Stable

[https://github.com/microsoft/vscode/issues/302891](https://github.com/microsoft/vscode/issues/302891)

## Summary

Keep open: profile import and Settings Sync provide manual transfer options, but the inspected onboarding flow does not offer to import an existing Stable or Insiders setup. This team-authored request needs a product decision on import scope and conflict behavior; no qualifying fix or older canonical was established.

## Change summary

Offer a setup-import step when someone first launches Stable or Insiders and already uses the other edition.

## Best solution

Provide an optional first-run import offer for the other edition's existing local setup, without requiring prior profile export or Settings Sync enrollment. Define which customizations transfer and how existing destination settings and profiles are handled before implementation.
