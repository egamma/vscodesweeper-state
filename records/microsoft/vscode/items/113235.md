# Issue #113235 — Make distinction when removing leading whitespace from trailing whitespace

[https://github.com/microsoft/vscode/issues/113235](https://github.com/microsoft/vscode/issues/113235)

## Summary

The clarified request is implemented: trailing-whitespace cleanup can now preserve multiline string contents, including embedded Markdown line breaks. Propose closing as completed rather than adding a leading-whitespace trimming setting.

## Change summary

Allow whitespace cleanup outside string literals without removing meaningful trailing spaces from embedded Markdown documentation.

## Best solution

Use files.trimTrailingWhitespace together with files.trimTrailingWhitespaceInRegexAndStrings set to false. This provides the syntax-aware distinction identified in the discussion without stripping source-code indentation.
