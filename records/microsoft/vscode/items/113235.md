# Issue #113235 — Make distinction when removing leading whitespace from trailing whitespace

[https://github.com/microsoft/vscode/issues/113235](https://github.com/microsoft/vscode/issues/113235)

## Summary

Implemented and shipped in VS Code 1.88.0: trailing whitespace can now be preserved inside tokenized strings and regexes while still being trimmed elsewhere.

## Change summary

Allow trailing-whitespace trimming to preserve semantically significant spaces inside multiline documentation strings.

## Best solution

Use `files.trimTrailingWhitespaceInRegexAndStrings: false`; commit c7578a33664f2e1879008fdad16a1a1ca5846161 added this language-overridable behavior and its token-aware trimming logic.
