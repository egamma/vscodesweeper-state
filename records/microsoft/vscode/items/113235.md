# Issue #113235 — Make distinction when removing leading whitespace from trailing whitespace

[https://github.com/microsoft/vscode/issues/113235](https://github.com/microsoft/vscode/issues/113235)

## Summary

Thanks for the report. The literal ask (a separate leading-whitespace trim) doesn't match the real problem: trailing-whitespace trimming breaks Markdown hard line breaks inside strings. A setting for that now exists, but I can't cite a clean fix commit, and the earlier fix claim was refuted, so this stays open.

## Change summary

Avoid trimming trailing whitespace inside embedded Markdown (multiline strings such as Elixir @doc), which removes Markdown hard line breaks.

## Best solution

Point the reporter at `files.trimTrailingWhitespaceInRegexAndStrings`, which can be set to false per language, and have a maintainer decide whether that satisfies the request or whether embedded-language awareness is still wanted. Retitle or close after that.
