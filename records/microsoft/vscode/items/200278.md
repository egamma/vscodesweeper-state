# Issue #200278 — Unified URL line number context menu

[https://github.com/microsoft/vscode/issues/200278](https://github.com/microsoft/vscode/issues/200278)

## Summary

A real UX gap remains: current main still lacks a Share submenu for the line-number context menu. Maintainers previously accepted this request into the Backlog with `continue-working-on`, so it should remain open.

## Change summary

Consolidate overlapping URL-copying and remote-opening commands in the editor line-number context menu.

## Best solution

Define a coherent line-number Share/Open Remote menu structure and expose the appropriate contribution point so built-in and external providers can place related actions consistently, coordinated with https://github.com/microsoft/vscode/issues/176316.
