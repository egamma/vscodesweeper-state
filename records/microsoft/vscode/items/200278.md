# Issue #200278 — Unified URL line number context menu

[https://github.com/microsoft/vscode/issues/200278](https://github.com/microsoft/vscode/issues/200278)

## Summary

Keep open: current source still separates the built-in vscode.dev link action from the shared-menu infrastructure, and the experimental Share command does not unify the line-number menu. The related API and context-menu cleanup issues do not meet the stronger duplicate bar for this previously reviewed request.

## Change summary

Organize line-number context-menu actions for copying and opening remote file or commit URLs into a more coherent, easier-to-navigate surface.

## Best solution

Agree on a consistent grouping for line-number link actions, coordinating the built-in GitHub contribution with extension-contributed remote actions while keeping Open Changes separate. Preserve URL targets and line selections rather than treating different destinations as interchangeable.

## Evidence

- **Existing capability does not cover the request:** extensions/github/package.json contributes github.copyVscodeDevLink directly to editor/lineNumber/context in group 1_cutcopypaste@2, while other editor surfaces contribute link commands to dedicated Share menus. Copying a link is already supported; unified line-number menu organization is not.
- **Experimental Share is not a replacement:** src/vs/workbench/contrib/share/browser/share.contribution.ts registers workbench.action.share behind workbench.experimental.share.enabled, which defaults to false.
