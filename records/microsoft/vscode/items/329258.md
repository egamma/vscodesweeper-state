# Issue #329258 — Can't create Sandbox on Windows when BaseContainer is velocity-gated and bfscfg.exe is unavailable

[https://github.com/microsoft/vscode/issues/329258](https://github.com/microsoft/vscode/issues/329258)

## Summary

Real, current gap: VS Code still bundles @microsoft/mxc-sdk@0.6.1 while npm's latest is 0.7.0, and the reporter's cited fallback bug (missing Tier 3/AppContainer fallback when velocity-gated features are unavailable) lives in that upstream SDK, not in VS Code's own sandbox glue code.

## Change summary

On Windows, enabling the experimental agent sandbox fails with E_NOTIMPL when required velocity-gated OS features and BfSCfg.exe aren't available, because mxc-sdk doesn't fall back to the AppContainer backend.

## Best solution

Bump the @microsoft/mxc-sdk dependency (currently 0.6.1 in package.json and remote/package.json) to 0.7.0 or later, which the reporter says contains the Tier 3 fallback fix; this is a dependency-version bump, not a VS Code core logic change.
