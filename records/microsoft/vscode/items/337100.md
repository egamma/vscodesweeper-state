[https://github.com/microsoft/vscode/issues/337100](https://github.com/microsoft/vscode/issues/337100)

## Summary

Keep open as an Agents Window discoverability issue: independent session panes are intentional and have a Close action, but the reporter could neither find that action nor discover how to return to one pane. The team-authored item is protected from a judgment close, and the exact entry path remains unknown.

## Change summary

Make it clear how to close an independently split session pane or return the Agents Window to a single-session arrangement.

## Best solution

Ensure every independent session pane exposes a readily discoverable exit path, and make the single-session arrangement discoverable from the Session Layout controls. First establish whether the reported build failed to render the existing Close action or whether its placement was insufficiently apparent.
