# Issue #174965 — Standardize how the quick pick indicates the active item

[https://github.com/microsoft/vscode/issues/174965](https://github.com/microsoft/vscode/issues/174965)

## Summary

Keep open: current source still marks the current window with descriptive text and an action icon, but the current profile with a checkmark. This team-authored consistency proposal remains unresolved and needs agreement on the shared presentation before implementation.

## Change summary

Standardize how quick picks identify the currently applied item independently of keyboard focus or selection.

## Best solution

Agree on a consistent, accessible current-item convention and apply it to the window and profile pickers without changing their navigation or actions. Preserve the distinction between the currently applied item and the row being focused or selected.
