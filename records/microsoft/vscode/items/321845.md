# Issue #321845 — Source control tab showing incorrect branch (Capitalization)

[https://github.com/microsoft/vscode/issues/321845](https://github.com/microsoft/vscode/issues/321845)

## Summary

The reporter confirmed the branch-name mismatch after upgrading to 1.125.0, and current source contains a plausible case-insensitive branch-resolution path that can replace HEAD's spelling. Keep this open for Git-area diagnosis; no verified duplicate or fixing commit was found.

## Change summary

The Source Control panel displays the capitalized branch instead of the lowercase branch selected in Git when branch names differ only by case.

## Best solution

Make the built-in Git extension report the actual checked-out branch consistently with Git, including its associated branch metadata. First distinguish ambiguous ref selection in VS Code from Windows loose/packed-ref casing behavior; the report does not establish that commits actually went to another branch.
