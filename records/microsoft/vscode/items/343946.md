# Issue #343946 — Undoing a session promotion displays a timed dialog with no option

[https://github.com/microsoft/vscode/issues/343946](https://github.com/microsoft/vscode/issues/343946)

## Summary

Keep open as UI polish: the post-undo confirmation still displays a countdown despite offering only Dismiss. Current source and existing tests explicitly retain this behavior; there is no verified fix or duplicate supporting closure of this team-authored report.

## Change summary

Hide the visible countdown on the informational confirmation shown after undoing a session promotion.

## Best solution

Show the completed undo confirmation without implying an expiring opportunity to act. Preserve automatic dismissal, the countdown on actionable Undo notices, and progress feedback while a move is running.
