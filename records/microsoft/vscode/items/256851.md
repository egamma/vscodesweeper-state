# Issue #256851 — Do not move my cursor while typing

[https://github.com/microsoft/vscode/issues/256851](https://github.com/microsoft/vscode/issues/256851)

## Summary

The Tab/NES conflict remains source-reproducible on current main for non-empty pasted lines. This should stay open as the oldest sufficiently detailed report of the general indentation conflict; related open reports are either narrower or newer.

## Change summary

Pressing Tab to indent pasted code can instead accept a multi-line next edit suggestion and move the cursor away from the line being edited.

## Best solution

Preserve Tab's indentation behavior when the caret is in the indentation of a non-empty line, while leaving the NES visible and available through its explicit accept command or configured keybinding.
