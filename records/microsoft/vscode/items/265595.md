# Issue #265595 — editor.inlineSuggest.suppressSuggestions is not working

[https://github.com/microsoft/vscode/issues/265595](https://github.com/microsoft/vscode/issues/265595)

## Summary

Confirmed source-reproducible: the extension host API adapter hardcodes `suppressSuggestions: false` on every inline completion result, causing the provider-level context key to always override the user setting `editor.inlineSuggest.suppressSuggestions`. The user setting is never consulted. The new `offWhenInlineCompletions` default for `editor.quickSuggestions` (shipped Feb 2026) provides a workaround via a separate code path, but the reported setting remains broken.

## Change summary

The `editor.inlineSuggest.suppressSuggestions` setting has no effect because the extension API adapter hardcodes the provider-level flag to `false`, which always overrides the user setting.

## Best solution

Change `suppressSuggestions: false` to `suppressSuggestions: list?.suppressSuggestions` (or `undefined`) in `src/vs/workbench/api/common/extHostLanguageFeatures.ts` line 1508, so the provider-level context key is `undefined` when the extension doesn't set it, allowing `canShowQuickSuggest` in `suggestModel.ts` to fall through to the user setting. The `offWhenInlineCompletions` default mitigates the issue for most users, but the setting should work as documented.
