# Issue #265595 — editor.inlineSuggest.suppressSuggestions is not working

[https://github.com/microsoft/vscode/issues/265595](https://github.com/microsoft/vscode/issues/265595)

## Summary

Keep open: current source contains a concrete path that bypasses editor.inlineSuggest.suppressSuggestions for extension-provided completions. The issue already has the appropriate area label, and no verified older canonical owns this symptom.

## Change summary

Enabling editor.inlineSuggest.suppressSuggestions fails to prevent automatic suggestion-widget activation while Copilot ghost text is visible.

## Best solution

Make the documented editor setting effective for extension-provided inline completions that do not specify a suppression override. Preserve manual IntelliSense activation and the separate quickSuggestions modes.
