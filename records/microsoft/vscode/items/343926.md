# Issue #343926 — GitHub - publish flow never completes when the repository name quick pick is dismissed

[https://github.com/microsoft/vscode/issues/343926](https://github.com/microsoft/vscode/issues/343926)

## Summary

The cancellation defect is present in current source: dismissing the repository-name picker re-enters a wait on an already-hidden picker, preventing publication from returning. Keep this open while the linked fix candidate is reviewed.

## Change summary

Dismissing the GitHub repository-name picker leaves publishRepository pending and prevents an awaiting git.publish command from completing.

## Best solution

Cancellation should finish the publish operation, dispose the picker, and create no repository or remote, while preserving normal publication and existing-name retry behavior. Review https://github.com/microsoft/vscode/pull/343927 against that outcome before closing the issue.
