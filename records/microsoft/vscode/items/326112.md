# Issue #326112 — Sometimes can't start 3rd party plugins during VS Code start

[https://github.com/microsoft/vscode/issues/326112](https://github.com/microsoft/vscode/issues/326112)

## Summary

This is the same long-standing webview Service Worker registration failure tracked by the open, broader canonical issue https://github.com/microsoft/vscode/issues/125993 (open since 2021, labeled bug/upstream/chromium/webview), which already has years of confirmations across platforms and extensions, including a very recent 2026 comment about the Codex webview specifically — proposing a duplicate close to consolidate.

## Change summary

Third-party extension webviews (Cline, Codex, Claude) intermittently fail to load with 'Could not register service worker: InvalidStateError: Failed to register a ServiceWorker: The document is in an invalid state' after repeated restarts.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/125993, which already tracks this exact Service Worker registration InvalidStateError across many extensions, platforms, and VS Code versions since 2021 and is labeled `upstream`/`chromium` — the root cause lives in the Service Worker/Chromium layer, not in this specific extension or a new defect.
