# Issue #202118 — Parsing of .gitignore files doesn't match git, causing cmd+p to not find any files

[https://github.com/microsoft/vscode/issues/202118](https://github.com/microsoft/vscode/issues/202118)

## Summary

Keep open as an upstream search issue: maintainers confirmed the ignore-pattern mismatch in standalone ripgrep, and the linked upstream report remains open with its owner acknowledging the bug. Current VS Code still delegates file enumeration and ignore-file interpretation to ripgrep.

## Change summary

Make Quick Open find files beneath directories when a .gitignore character class contains an escaped slash, matching Git's interpretation.

## Best solution

Resolve the character-class/path-separator mismatch in ripgrep's ignore matching, then adopt the corrected implementation in VS Code. Retain this issue as the downstream tracker until the reported pattern behaves consistently with Git.
