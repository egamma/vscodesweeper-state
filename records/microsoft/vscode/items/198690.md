# Issue #198690 — Configuration/Settings examples do not show in the settings view for extensions

[https://github.com/microsoft/vscode/issues/198690](https://github.com/microsoft/vscode/issues/198690)

## Summary

The Settings editor still does not expose schema-provided examples for free-form string settings. Keep this accepted Backlog request open: existing controls do not cover it, and the related issues checked do not qualify as duplicate canonicals.

## Change summary

Display and suggest extension configuration examples in the graphical Settings editor while retaining arbitrary string input.

## Best solution

Support configuration-schema examples in the Settings editor's metadata and string-setting controls, without treating examples as an exhaustive enum or requiring extension authors to duplicate them in descriptions.
