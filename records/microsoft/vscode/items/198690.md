# Issue #198690 — Configuration/Settings examples do not show in the settings view for extensions

[https://github.com/microsoft/vscode/issues/198690](https://github.com/microsoft/vscode/issues/198690)

## Summary

The Settings UI still does not surface JSON schema `examples` from extension configurations; no implementation exists on current main. Valid feature request, appropriately labeled and milestoned in Backlog.

## Change summary

Display JSON schema `examples` values in the Settings webview for extension configuration properties, similar to how they appear as completions in settings.json.

## Best solution

Extend the settings tree renderer in `src/vs/workbench/contrib/preferences/browser/settingsTree.ts` to read and display `examples` from the configuration schema — likely as suggested values or a dropdown for string-type settings. The schema data is already available; it's a matter of surfacing it in the UI.
