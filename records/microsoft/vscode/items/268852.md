# Issue #268852 — having github copilot or github copilot chat extension in your .code-profile crashes vscode profile when importing .code-profile

## Summary

Verified duplicate: the open canonical issue tracks the same profile-import failure when Copilot Chat is resolved as an older marketplace extension despite already shipping as a newer built-in extension.

## Change summary

Importing a .code-profile containing GitHub Copilot Chat aborts extension installation and leaves the requested profile uncreated.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/320154 and make profile import recognize the built-in Copilot Chat installation instead of attempting an older gallery installation that aborts the entire profile creation.
