# Issue #268852 — having github copilot or github copilot chat extension in your .code-profile crashes vscode profile when importing .code-profile

[https://github.com/microsoft/vscode/issues/268852](https://github.com/microsoft/vscode/issues/268852)

## Summary

The silent profile-import failure remains traceable on current main: importing the deprecated `github.copilot` entry can migrate installation to an older gallery build of the built-in Copilot Chat extension, trigger the built-in downgrade guard, and cause profile creation to be silently rolled back. Keep this older report open; the matching open report https://github.com/microsoft/vscode/issues/320154 is younger and cannot become the canonical target for this re-reviewed issue.

## Change summary

Importing a `.code-profile` containing GitHub Copilot entries aborts extension installation and leaves the requested profile uncreated.

## Best solution

Make profile import treat the already-present built-in Copilot Chat extension as satisfying the deprecated Copilot entry without weakening the general built-in downgrade guard, and surface any remaining import failure instead of silently discarding the profile. Consolidate the newer diagnostics from https://github.com/microsoft/vscode/issues/320154 with this older report.
