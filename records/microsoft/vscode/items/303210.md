[https://github.com/microsoft/vscode/issues/303210](https://github.com/microsoft/vscode/issues/303210)

## Summary

The reported prompt and interpreter detection are owned by the VS Code team's Python Environments extension. This should be moved to its tracker so the owning team can investigate why the interpreter on PATH was not discovered.

## Change summary

Opening a Copilot session activates Python environment discovery, which incorrectly reports that Python is unavailable and offers to install it through uv.

## Best solution

Move the issue to https://github.com/microsoft/vscode-python-environments and investigate why its system-Python manager produced an empty environment collection despite Python reportedly being on PATH; the uv prompt should appear only when no usable interpreter is actually available.
