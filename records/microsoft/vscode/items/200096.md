# Issue #200096 — Not able to report issues while container is starting

[https://github.com/microsoft/vscode/issues/200096](https://github.com/microsoft/vscode/issues/200096)

## Summary

The default classic reporter still waits for remote extension enumeration before opening, so Help: Report Issue can appear to do nothing during container initialization. The opt-in wizard opens before enumeration, but that does not resolve the default path.

## Change summary

Allow Help: Report Issue to open while a remote container is still initializing.

## Best solution

Make the issue reporter usable before the remote connection and extension inventory are ready, while preserving accurate diagnostic data when available. Keep this in the core issue-reporter area rather than moving it to Dev Containers.
