# Issue #318442 — Renaming a session requires reload

[https://github.com/microsoft/vscode/issues/318442](https://github.com/microsoft/vscode/issues/318442)

## Summary

Team-authored bug with two open fix PRs (#318667 and #323323), neither merged yet. Keep open — the author is a MEMBER and the fix is actively in flight.

## Change summary

Renaming a chat session in the VS Code editor window does not persist the new name until the window is reloaded; forking a renamed session also reverts the title.

## Best solution

Land one of the two open PRs (https://github.com/microsoft/vscode/pull/318667 or https://github.com/microsoft/vscode/pull/323323) that fix the dual root causes: (A) the refresh path not detecting title changes on history sessions, and (B) renameChat calling the in-memory-only setSessionTitle instead of the persisting setChatSessionTitle. The fork-revert issue from the first comment may need a separate follow-up.
