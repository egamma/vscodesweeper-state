# Issue #202615 — indicate when action appears/ status changes to screen reader users

[https://github.com/microsoft/vscode/issues/202615](https://github.com/microsoft/vscode/issues/202615)

## Summary

Team-authored accessibility feature request for notebook status bar screen reader announcements. Not yet implemented on main — cellStatusPart.ts only sets static aria-labels on items, with no dynamic announcements when actions appear or status changes.

## Change summary

Screen reader users should be notified when notebook cell status bar actions appear or status changes.

## Best solution

Add ARIA live-region announcements or use the accessibility signal service in cellStatusPart.ts to notify screen reader users when status bar items appear, disappear, or change state. This aligns with existing VS Code accessibility announcement patterns (e.g. verbosity settings gating announcements).
