# Issue #318576 — Agents window: couldn't disable built-in Github mcp server in agents customization.

[https://github.com/microsoft/vscode/issues/318576](https://github.com/microsoft/vscode/issues/318576)

## Summary

Still present on main: the context menu handler for built-in MCP server items in the agents customization view only handles plugin-provided builtins. The built-in GitHub MCP server (provided by the Copilot extension, not a plugin) hits an early return with no menu, so there's no way to disable it via right-click.

## Change summary

Right-clicking the built-in GitHub MCP server in the Agents customization MCP tab shows no context menu, preventing users from disabling it.

## Best solution

Add a context menu action for non-plugin built-in MCP server items in `mcpListWidget.ts` that toggles the relevant VS Code setting (e.g. the `github.copilot.chat.gitHubMcpServer` family of settings). The `onContextMenu` handler's `builtin-item` branch currently returns early when `getPluginUriFromCollectionId` is falsy — it needs a fallback path that offers a disable/enable toggle for extension-provided builtins.
