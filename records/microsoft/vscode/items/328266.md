# Issue #328266 — Cmd+Delete in inline "Ask a question" hover deletes the last chat turn instead of editing the focused input

[https://github.com/microsoft/vscode/issues/328266](https://github.com/microsoft/vscode/issues/328266)

## Summary

Real bug: Cmd+Delete in the inline 'Ask a question' hover input is captured by a chat editing keybinding (e.g. delete-last-request/undo) instead of the focused text input, and the reporter has already opened an open PR that fixes it — so this should stay open until that PR lands, not be closed as completed.

## Change summary

Cmd+Delete typed into the inline chat 'Ask a question' hover input is intercepted by a chat-session keybinding and deletes the last chat turn instead of editing the input.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330054, which scopes the destructive chat editing keybindings in src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingActions.ts to not fire when focus is in a text input (including the inline question editor).
