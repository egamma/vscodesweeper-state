# Issue #328266 — Cmd+Delete in inline "Ask a question" hover deletes the last chat turn instead of editing the focused input

[https://github.com/microsoft/vscode/issues/328266](https://github.com/microsoft/vscode/issues/328266)

## Summary

Traced on main: the inline 'Ask a question' textarea in `ResponseSelectionSideChatController` only stops propagation for Escape/Enter on `keydown`, so Cmd+Delete (and other keys) bubble to the global keybinding dispatcher, where `workbench.action.chat.undoEdits` (mac: CtrlCmd+Backspace) fires and silently removes the last chat request/turn.

## Change summary

Typing Cmd+Delete while focused in the inline 'Ask a question' hover input deletes the last chat turn instead of editing the input's text.

## Best solution

In `src/vs/sessions/contrib/chat/browser/responseSelectionSideChatController.ts`, stop propagation for all `keydown` events on `this._input.inputElement` (not just Escape/Enter), matching the existing `keypress` handler, so chat-level keybindings like `workbench.action.chat.undoEdits` never see keystrokes meant for this plain `<textarea>`.
