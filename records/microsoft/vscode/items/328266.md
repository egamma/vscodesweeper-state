# Issue #328266 — Cmd+Delete in inline "Ask a question" hover deletes the last chat turn instead of editing the focused input

[https://github.com/microsoft/vscode/issues/328266](https://github.com/microsoft/vscode/issues/328266)

## Summary

Current main still allows the chat checkpoint-removal keybinding while the native Ask Question textarea is focused, so this is a confirmed Agents-window bug that should remain open.

## Change summary

Cmd+Delete in the response-selection Ask Question input removes the latest chat turn instead of editing the input text.

## Best solution

Exclude native input focus from the destructive chat checkpoint keybindings in `chatEditingActions.ts`, covering the response-selection textarea without changing Delete behavior elsewhere in the transcript.
