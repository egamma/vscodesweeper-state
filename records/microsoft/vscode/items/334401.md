# Issue #334401 — Why does VSCode Chat using a third party API provider Ollama fail, if Github is experiencing an outage? That makes no sense at all. The whole point is for the harness to be not reliant on a single provider

[https://github.com/microsoft/vscode/issues/334401](https://github.com/microsoft/vscode/issues/334401)

## Summary

Thanks for the report. The expectation that a bring-your-own-key model such as Ollama keeps working during a GitHub outage is reasonable. Chat sign-in, entitlement and session setup may still depend on GitHub services. I did not trace the code, and the only error detail is in a screenshot, so I'm keeping this open rather than closing it from a shallow read.

## Change summary

Chat with a local Ollama model fails intermittently while GitHub is having an outage, and the reporter expects it to work independently of GitHub.

## Best solution

Decide whether chat with BYOK or local models should avoid blocking on GitHub entitlement and token calls. If so, make those calls non-blocking or degrade gracefully when GitHub is unreachable. A maintainer should check which GitHub request produces the error shown in the screenshot.
