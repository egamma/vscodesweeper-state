  > Thanks for the context. That message can cover both extension activation and initial MCP provider discovery, before a named MCP server starts. On an affected machine, capture **Developer: Show Running Extensions** while the hang is visible, then collect the affected session's logs using **Developer: Open Logs Folder** and **Developer: Open Extension Logs Folder**. Please include the VS Code and Copilot Chat versions, OS, installed extension IDs and versions, sign-in state, and the time the request stalled; redact credentials and private content before sharing. If a named MCP server appears, its **Show Output** action can provide additional server-specific details.
