# Issue #331852 — [regression] Paste in chat changed functionality; now unusable; regresses months of fixes

[https://github.com/microsoft/vscode/issues/331852](https://github.com/microsoft/vscode/issues/331852)

## Summary

Confirmed regression, actively acknowledged by the responsible maintainer (lramos15) in the thread, who is already planning to raise the threshold — this stays open pending that follow-up work rather than being closed.

## Change summary

In 1.134, pasting long/multi-line text into the chat input now defaults to an uneditable 'attachment' instead of inserting inline Markdown/plain text, and Ctrl+Shift+V no longer reliably gives plain text.

## Best solution

Land lramos15's promised threshold adjustment (chat.pasteAsAttachmentThreshold) and consider exposing a simpler on/off toggle for auto-attachment so users don't have to compute a 'very large number' in settings.json; the code path is src/vs/workbench/contrib/chat/browser/widget/input/editor/chatPasteProviders.ts (PasteHtmlProvider yields to the `chat.attach.text` kind once minLength/line-count are exceeded).
