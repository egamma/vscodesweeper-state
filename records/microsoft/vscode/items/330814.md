# Issue #330814 — Clipboard writes are not visible to other applications since 1.133.0 (Windows)

[https://github.com/microsoft/vscode/issues/330814](https://github.com/microsoft/vscode/issues/330814)

## Summary

Detailed, methodical single-reporter regression on Windows tying clipboard write failure to the 1.133.0 Electron bump, but it's only one day old with no other confirmations, and clipboard interop with the OS/Electron/Chromium can't be verified from source alone — needs a reproduction check on the latest Insiders build before triage can proceed further.

## Change summary

On Windows, since 1.133.0, text copied from VS Code (editor, terminal, or the About dialog's Copy button) can no longer be pasted into other applications — Windows clipboard history shows a blank entry, suggesting VS Code is writing a format other apps can't consume.

## Best solution

Ask the reporter to confirm on the latest Insiders build (main is already on Electron 42.8.1, one patch ahead of the reported 42.8.0) and, if it still reproduces, have someone with Windows hardware inspect what clipboard formats VS Code registers via `src/vs/workbench/services/clipboard/electron-browser/clipboardService.ts` and the underlying Electron `clipboard.writeText`/`clipboard.write` call — likely related to the stray 'Chromium Web Custom MIME Data Format' entry described in https://github.com/microsoft/vscode/issues/117879.
