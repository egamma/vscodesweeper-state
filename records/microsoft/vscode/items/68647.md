# Issue #68647 — Allow dynamic location of textmate grammar

[https://github.com/microsoft/vscode/issues/68647](https://github.com/microsoft/vscode/issues/68647)

## Summary

A real extension API gap remains on current main: TextMate grammars must still be declared at a static extension-relative path. Keep this routed to the API backlog for a lifecycle and activation decision.

## Change summary

Allow extensions to register or replace dynamically generated TextMate grammars at runtime.

## Best solution

Design an API for registering and disposing runtime TextMate grammars, including explicit activation, retokenization, and background-tokenizer synchronization semantics. The implementation would primarily belong in the TextMate workbench service and extension-host language API.

## Evidence
