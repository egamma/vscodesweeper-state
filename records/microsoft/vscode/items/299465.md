## Summary

This is the earlier, narrower report of the same double-click punctuation selection inconsistency that is more thoroughly described in #305977 by the same author. The later issue is the better canonical since it has broader scope and detail — proposing duplicate close against it.

## Change summary

Double-clicking on the closing single-quote in `foo 'bar' baz` does not select the quote; instead it selects the adjacent word or space.

Consolidate on https://github.com/microsoft/vscode/issues/305977 which is the more detailed report of the same root cause (the strict less-than boundary check for separator words in `cursorWordOperations.ts`). Fix the word-select logic there.
