# Issue #173643 — Support find widget in WebviewViewProvider

[https://github.com/microsoft/vscode/issues/173643](https://github.com/microsoft/vscode/issues/173643)

## Summary

Valid feature request with 42 upvotes, already promoted to Backlog. The API gap is confirmed on current main: `registerWebviewViewProvider` still lacks `enableFindWidget` while `registerCustomEditorProvider` and `WebviewPanel` both expose it.

## Change summary

Allow extensions to enable the built-in find widget in WebviewView (sidebar/panel webviews), matching the existing capability available in WebviewPanel.

## Best solution

Add `enableFindWidget` to the `webviewOptions` parameter of `registerWebviewViewProvider` (and/or to the `WebviewView` interface), wiring it through the same find-widget plumbing already used by `WebviewPanel` in `mainThreadWebviewPanels.ts` and `overlayWebview.ts`.
