# Issue #88885 — Readonly ranges/lines in the editors

[https://github.com/microsoft/vscode/issues/88885](https://github.com/microsoft/vscode/issues/88885)

## Summary

Keep open: current editor and file-level read-only controls do not provide protected ranges inside an otherwise editable document. This team-authored Backlog request remains a distinct editor capability gap; no qualifying fix or canonical duplicate was established.

## Change summary

Allow selected ranges or lines to remain visible and copyable but read-only while the rest of the document stays editable.

## Best solution

Define an editor-core protected-range contract usable by extension-backed documents and built-in editors, preserving selection and copying while specifying how edits that overlap protected content behave. Coordinate the shared editor capability with the related Monaco discussion rather than treating whole-document read-only mode as coverage.
