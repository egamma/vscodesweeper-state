# Issue #88885 — Readonly ranges/lines in the editors

[https://github.com/microsoft/vscode/issues/88885](https://github.com/microsoft/vscode/issues/88885)

## Summary

A real editor-core capability gap remains: current main supports making an entire editor read-only, but not protected ranges. This team-authored Backlog request should remain open, with the related Monaco discussion informing its design.

## Change summary

Allow selected ranges or lines in an otherwise editable text editor to be marked read-only.

## Best solution

Design range-level edit protection in editor core, including enforcement across every editing command and clear visual or message feedback, then expose it where extensions need to present partially editable documents. Coordinate with https://github.com/microsoft/monaco-editor/issues/953, while preserving this issue's VS Code extension scenario.
