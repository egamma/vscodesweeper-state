# Issue #340902 — Slow startup time if update pending

[https://github.com/microsoft/vscode/issues/340902](https://github.com/microsoft/vscode/issues/340902)

## Summary

Thanks for the report. On Windows, a pending versioned update is applied at launch, which would explain the 30–50 second delay. This looks like a startup-experience gap rather than a clear bug, so it stays open for the update owners to review.

## Change summary

Launching VS Code on Windows with a downloaded update pending delays startup by 30–50 seconds while the update installs, and the user wants to defer the install.

## Best solution

Let the user start immediately and defer applying the pending update, or apply it without blocking window startup. This would be a change in the Windows update service (updateService.win32.ts).
