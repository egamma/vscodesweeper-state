# Issue #283382 — Nicer looking errors for response errors in panel chat

[https://github.com/microsoft/vscode/issues/283382](https://github.com/microsoft/vscode/issues/283382)

## Summary

Keep open for a focused error-presentation design pass. Current source still exposes provider messages in a bordered notification with an error icon by default; the UI refresh tracker explicitly leaves this work outstanding.

## Change summary

Make panel-chat response errors calmer, more readable, and clearer about recovery without losing diagnostic information.

## Best solution

Agree on a consistent response-error hierarchy separating a plain-language explanation and recovery action from technical diagnostics. Apply it to the chat response renderer while preserving meaningful severity distinctions and existing retry behavior.
