# Issue #283382 — Nicer looking errors for response errors in panel chat

[https://github.com/microsoft/vscode/issues/283382](https://github.com/microsoft/vscode/issues/283382)

## Summary

Keep open for a focused chat error-presentation design pass. Current source still exposes technical diagnostics inline and centers the icon beside multiline messages; the linked discussion supplies concrete UX goals, and the newer refresh tracker explicitly lists this work as unfinished.

## Change summary

Make panel-chat response failures calmer and easier to understand, with clearer recovery actions and less prominent technical diagnostics.

## Best solution

Agree on a response-error presentation that leads with a concise explanation and recovery action while keeping diagnostic details available without dominating the conversation. Apply that design to the shared chat error widgets and message construction, preserving meaningful severity distinctions.
