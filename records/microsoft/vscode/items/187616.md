# Issue #187616 — Scrollback position toggle in Interactive Window

[https://github.com/microsoft/vscode/issues/187616](https://github.com/microsoft/vscode/issues/187616)

## Summary

The bug is still present on main: when a single cell's output fills the viewport in the Interactive Window, `_cellAtBottom` returns true because the cell occupies the entire visible range, causing `_scrollIfNecessary` to auto-scroll on every output resize even when the user has scrolled up within that cell's output.

## Change summary

Interactive Window auto-scrolls to the bottom when output grows within a single cell that fills the viewport, even when the user has scrolled up to review earlier output.

## Best solution

The `_cellAtBottom` check in `interactiveEditor.ts` needs to account for whether the user's scroll position is within the output scroll container of that cell, not just whether the cell is the last visible one. The fix likely involves checking the output container's scroll state (whether it's scrolled to its own bottom) before triggering auto-scroll on output resize.
