# Issue #187616 — Scrollback position toggle in Interactive Window

[https://github.com/microsoft/vscode/issues/187616](https://github.com/microsoft/vscode/issues/187616)

## Summary

Keep open: current source still treats the last cell being visible as being scrolled to the bottom, matching the reporter's viewport-filling output case. Disabling the existing auto-scroll setting does not prevent this path from forcing the window to the bottom.

## Change summary

Preserve the Interactive Window's scrollback position while a viewport-filling cell continues producing output.

## Best solution

Make scrolling during output growth distinguish the actual bottom position from merely viewing the last cell. Preserve the existing interactiveWindow.alwaysScrollOnNewCell setting and intentional scrolling when executing new cells.
