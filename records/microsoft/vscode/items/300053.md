# Issue #300053 — Add "Move To -> Editor Area" to Integrated Terminal Panel Context Menu

[https://github.com/microsoft/vscode/issues/300053](https://github.com/microsoft/vscode/issues/300053)

## Summary

The current separation is intentional: the panel-level “Move To” menu relocates the entire Terminal view container, while moving one terminal into the editor is exposed on that terminal's own tab context menu. The reporter subsequently found that existing per-terminal entry, so the central discoverability path is already present.

## Change summary

Expose “Move Terminal into Editor Area” from the integrated terminal panel's broader context-menu surface.

## Best solution

Keep the container-location menu limited to Panel, Primary Side Bar, and Secondary Side Bar, and retain “Move Terminal into Editor Area” on the individual terminal tab context menu where its per-session scope is clear.

## Vision fit

- **Fit:** aligned
- **Reason:** Keeping container-level and per-terminal movement commands on contextually distinct menus supports consistent interaction semantics without duplicating commands.
- **Evidence:** Value: “Simple, uniform UI and UI interactions.”
