# Issue #326730 — Cursor jumps to the line above after accepting an inline completion that adds an auto-import

[https://github.com/microsoft/vscode/issues/326730](https://github.com/microsoft/vscode/issues/326730)

## Summary

The cursor jump is conclusively present in current main: accepting an inline completion resets the selection using coordinates that do not account for preceding additional text edits. Route this confirmed bug to inline completions.

## Change summary

Accepting an inline completion with an auto-import leaves the cursor one line above its intended position.

## Best solution

Transform the primary edit's resulting cursor position through additional text edits before setting the editor selection in the inline-completion acceptance path.
