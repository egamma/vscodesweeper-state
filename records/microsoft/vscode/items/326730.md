# Issue #326730 — Cursor jumps to the line above after accepting an inline completion that adds an auto-import

[https://github.com/microsoft/vscode/issues/326730](https://github.com/microsoft/vscode/issues/326730)

## Summary

Still reproduces on main: when an accepted inline completion carries additionalTextEdits that add a line above (an auto-import), the cursor selection is computed from the main edit alone and then applied after the combined edit, leaving the cursor one line above. Keeping it open as a bounded, agent-implementable fix in the inline completions accept path.

## Change summary

Accepting an inline ghost-text suggestion that also inserts an auto-import leaves the cursor one line above where it should be.

## Best solution

In InlineCompletionsModel.accept, compute the post-accept selections from the combined edit (main replacements plus additionalTextEdits) rather than from the main edits only, so line shifts introduced by the auto-import edit are accounted for.
