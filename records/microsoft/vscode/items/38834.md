# Issue #38834 — ANSI color support in edit buffer

[https://github.com/microsoft/vscode/issues/38834](https://github.com/microsoft/vscode/issues/38834)

## Summary

The core editor still does not interpret ANSI styling, and this heavily supported Backlog request remains the canonical issue for that gap. The available extension preview is useful but does not provide ANSI rendering in the editable buffer.

## Change summary

Render ANSI color and style escape sequences in editable text files without displaying the control sequences.

## Best solution

Provide an opt-in ANSI-aware editor mode that preserves model offsets and editing behavior while rendering SGR colors/styles and omitting escape sequences from the visual and copied text. The implementation likely belongs in editor rendering, unless an extension API can first support the same editable-buffer behavior faithfully.

## Evidence

- **current source:** Current main's src/vs/editor/common/viewLayout/viewLineRenderer.ts treats characters below code point 32, including ESC, as control characters and assigns them the `mtkcontrol` token; it contains no ANSI/SGR interpretation path.
- **existing setting:** src/vs/editor/common/config/editorOptions.ts registers only `editor.renderControlCharacters`, described as controlling whether control characters are rendered; it does not colorize or consume ANSI sequences.
- **canonical search:** Repository issue searches for ANSI colors and editor escape sequences found https://github.com/microsoft/vscode/issues/38834 as the only open issue directly covering ANSI rendering in the edit buffer; related OutputChannel, terminal, and notebook reports are closed or concern different surfaces.
- **community demand:** The issue has 379 community upvotes and is assigned to the Backlog milestone, so it should not be retired through the stale feature-request process.
- **partial workaround:** The VT100 Syntax Highlighting extension at https://github.com/TobiasFaller/vscode-vt100-syntax-highlight now offers an ANSI preview, but the discussion distinguishes that read-only preview from rendering and editing the original buffer while hiding escape sequences.
