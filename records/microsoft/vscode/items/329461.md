# Issue #329461 — Issue in switching branches

[https://github.com/microsoft/vscode/issues/329461](https://github.com/microsoft/vscode/issues/329461)

## Summary

This matches the recently-fixed 'quick picks closing immediately' bug: PR #329327 (merged 2026-08-06T09:33:51Z, commit b966285933b27aaa9be0904c1c6f2bbe666aefa9) fixed toolbar/menu mouse-out handling reclaiming focus from a just-opened quick pick, which is exactly the branch-picker-flashes-and-reverts symptom described here. The fix is present on current main.

## Change summary

Clicking the branch indicator in the status bar and selecting a different branch immediately reverts to the same branch instead of switching, since the Modern UI rollout began.

## Best solution

Treat as fixed by commit b966285933b27aaa9be0904c1c6f2bbe666aefa9 (PR https://github.com/microsoft/vscode/pull/329327), which makes closing context views inert during their close animation so toolbar/status-bar menus can no longer steal focus back and force-close a newly opened quick pick. This is main-only as of now (merged after 1.132.0 shipped); ask the reporter to confirm on Insiders or the next stable release.
