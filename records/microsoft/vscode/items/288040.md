# Issue #288040 — Unsure what Apply button is for in Cloud Agent session

[https://github.com/microsoft/vscode/issues/288040](https://github.com/microsoft/vscode/issues/288040)

## Summary

Team-authored issue requesting better UX clarity for the 'Apply' button in Cloud Agent sessions — the button label is just 'Apply' with no tooltip explaining what it does. Keeping open as it's filed by a MEMBER and still unresolved.

## Change summary

The 'Apply' button in Cloud Agent session toolbar has no tooltip, leaving users unsure of its purpose.

## Best solution

Add a descriptive tooltip to the `github.copilot.chat.applyCopilotCLIAgentSessionChanges.apply` command when rendered in the `chat/input/editing/sessionToolbar` menu. The full command title 'Apply Changes to Workspace' (already in `package.nls.json`) could serve as the tooltip text. As @alexr00 suggested, this may also involve allowing contributions to provide tooltips for `chat/input/editing/sessionToolbar` items more generally, likely touching `src/vs/workbench/contrib/chat/browser/widget/input/chatInputPart.ts` and possibly the `MenuWorkbenchButtonBar` API.
