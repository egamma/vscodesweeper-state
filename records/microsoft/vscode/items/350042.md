# Issue #350042 — Focusing a chat should also select the corresponding session in the list

[https://github.com/microsoft/vscode/issues/350042](https://github.com/microsoft/vscode/issues/350042)

## Summary

The sessions list does not follow focus switches between already-open chats: current synchronization follows model changes or active-editor changes instead. Keep this open as a bounded chat-selection synchronization bug.

## Change summary

Keep the sessions-list selection synchronized with the focused chat when chat editors and the chat area coexist.

## Best solution

The Chat view’s sessions list should identify the focused chat without moving keyboard focus or reopening its session. Cover switching in both directions between an existing chat editor and the chat area.
