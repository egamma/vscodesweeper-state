# Issue #302234 — Bring this Copilot CLI terminal linking into Core

[https://github.com/microsoft/vscode/issues/302234](https://github.com/microsoft/vscode/issues/302234)

## Summary

Team-authored discussion about moving the Copilot CLI terminal link feature from the Copilot extension into VS Code core. The feature still lives entirely in extensions/copilot; no core implementation exists yet. Keeping open for the team to decide.

## Change summary

Move the Copilot CLI terminal file-link detection (session-state paths) from the Copilot extension into VS Code's core terminal link infrastructure.

## Best solution

If the team decides to proceed, the link-provider logic in extensions/copilot/src/extension/chatSessions/vscode-node/copilotCLITerminalLinkProvider.ts would move into src/vs/workbench/contrib/terminal/ as a built-in link handler for session-state paths, removing the dependency on having the Copilot Chat extension installed. The decision hinges on whether Copilot CLI users will always have the Chat extension.
