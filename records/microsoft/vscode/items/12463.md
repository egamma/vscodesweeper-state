# Issue #12463 — Allow to specify the tsconfig.json filename explicitly 

[https://github.com/microsoft/vscode/issues/12463](https://github.com/microsoft/vscode/issues/12463)

## Summary

Still a valid, popular feature request (114 upvotes) with no implementation on main — the TypeScript extension has no setting to specify a custom tsconfig filename, and the upstream tsserver API to support it remains absent.

## Change summary

Allow users to explicitly specify which tsconfig.json file VS Code's TypeScript language service should use for a project, rather than relying on automatic file-name-based discovery.

## Best solution

This requires upstream TypeScript server support (the ability to tell tsserver which config file to use for a project). The closed upstream issue (microsoft/TypeScript#11224) never delivered the needed API. A new upstream request or a VS Code-side workaround (e.g. using project references or solution-style tsconfigs) would be needed. Given 114 upvotes and On Deck status, this should stay open as a tracked community request.
