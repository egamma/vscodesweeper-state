# Issue #341326 — Agents window: Claude shows no models for a normal claude.ai login (account check ignores OAuth login), and SDK is never re-downloaded after an update

[https://github.com/microsoft/vscode/issues/341326](https://github.com/microsoft/vscode/issues/341326)

## Summary

Keep open: current source rejects the reported OAuth account shape and consequently publishes no native Claude models, matching the independent Windows confirmation. SDK upgrade handling has existing setup machinery and a related report of successful first-use upgrades, but that does not resolve the separate account-detection defect.

## Change summary

Recognize valid Claude.ai OAuth accounts in the Agents window and provide a usable recovery path when an update changes the required Claude SDK version.

## Best solution

Make native Claude model discovery recognize the authenticated OAuth account shape while continuing to reject genuinely unconfigured accounts. Retest the reported upgrade scenario through the existing consent-aware SDK setup flow and ensure users cannot become stranded without either models or an actionable download path.
