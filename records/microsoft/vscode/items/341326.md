# Issue #341326 — Agents window: Claude shows no models for a normal claude.ai login (account check ignores OAuth login), and SDK is never re-downloaded after an update

[https://github.com/microsoft/vscode/issues/341326](https://github.com/microsoft/vscode/issues/341326)

## Summary

Thanks for the detailed report. The account check on main only counts a non-firstParty provider, a tokenSource other than 'none', or an apiKeySource as signed in. The reporter's claude.ai OAuth login returned none of those, so the models list is published empty. The SDK re-download problem is a separate concern that I could not trace here.

## Change summary

Claude in the Agents window shows no models for a claude.ai OAuth login, and the pinned SDK is not re-downloaded after a VS Code update.

## Best solution

Treat a returned email or subscriptionType as a signed-in account in isClaudeAccountSetUp, with a unit test. Separately, make the agent host download the pinned SDK version when the cache is missing, or show a clear prompt. Consider splitting the SDK-download problem into its own issue.
