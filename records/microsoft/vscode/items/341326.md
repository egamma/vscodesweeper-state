# Issue #341326 — Agents window: Claude shows no models for a normal claude.ai login (account check ignores OAuth login), and SDK is never re-downloaded after an update

[https://github.com/microsoft/vscode/issues/341326](https://github.com/microsoft/vscode/issues/341326)

## Summary

Keep open: current source still rejects the reported claude.ai OAuth account shape and discards its native models. The SDK-update complaint needs separate verification against the current consent-aware setup flow; that partial improvement does not resolve the confirmed account-check defect.

## Change summary

Recognize existing claude.ai OAuth sessions in the Agents window and provide a reachable download or update flow when the pinned Claude SDK is missing.

## Best solution

Valid native Claude OAuth accounts should expose their SDK models without requiring a manually exported token, while genuinely unconfigured accounts remain unavailable. After a pinned SDK update, users should have a reachable activation or download path that preserves the existing consent and background-download boundaries.
