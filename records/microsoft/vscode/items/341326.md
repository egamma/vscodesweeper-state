- **Two independent failure stages:** https://github.com/microsoft/vscode/issues/341326 reports that installing SDK 0.3.281 manually cleared the missing-SDK condition but left native account detection failing. - **Authoritative authentication decision:** https://github.com/microsoft/vscode/issues/333738#issuecomment-5737308066 explicitly acknowledges that the subprocess can use a claude.ai keychain login but states that VS Code intentionally excludes subscription authentication under Anthropic's SDK integration restrictions. The maintainer declined recognizing loggedIn, authMethod, or subscription fields. This precedent covers the authentication request, but not the separate SDK download problem.
- **Current account gate matches the reported result:** src/vs/platform/agentHost/node/claude/claudeTransportMode.ts:isClaudeAccountSetUp accepts a non-firstParty provider, a non-none tokenSource, or a defined apiKeySource. ClaudeAgent._fetchNativeModels in src/vs/platform/agentHost/node/claude/claudeAgent.ts consequently returns an empty native catalog.
