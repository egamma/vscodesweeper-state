# Issue #334576 — Plan - Start Plan With Autopilot doesn't go into agent mode reliably

[https://github.com/microsoft/vscode/issues/334576](https://github.com/microsoft/vscode/issues/334576)

## Summary

Three independent reporters confirm Autopilot's plan-to-agent transition sometimes fails to complete even though the UI shows agent mode, and it correlates with specific models (GPT-family) more than others — this is a real, reproduced issue but the root cause isn't clearly localized from the checkout alone.

## Change summary

Clicking 'Start Plan With Autopilot' sometimes leaves the session stuck showing plan-mode behavior despite the UI indicating agent mode, requiring a manual mode toggle to recover.

## Best solution

Chat/Copilot team should investigate extensions/copilot/src/extension/chatSessions/copilotcli/node/exitPlanModeHandler.ts's resolveAutopilot path and the SDK's exit_plan_mode.requested event emission for the affected models — if the model never emits that event (or the UI mode indicator desyncs from the underlying session permission level), the auto-approval logic never runs and the session appears stuck.
