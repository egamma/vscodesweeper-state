# Issue #334576 — Plan - Start Plan With Autopilot doesn't go into agent mode reliably

[https://github.com/microsoft/vscode/issues/334576](https://github.com/microsoft/vscode/issues/334576)

## Summary

Multiple independent reporters across three VS Code releases (1.136–1.138) confirm the same symptom: after Autopilot/Plan mode finishes, the UI shows Agent mode but the session doesn't actually resume as an agent turn, requiring a manual mode toggle. The behavior correlates with specific models (GPT 5.6/6 family vs. Claude), pointing at a race or state-sync issue in the plan→agent handoff rather than something I can pin to one file from source alone.

## Change summary

Clicking 'Start Plan With Autopilot' sometimes leaves the chat stuck showing Agent mode in the UI while the session behaves as if still in Plan mode, requiring a manual toggle to Plan then back to Agent to unstick it.

## Best solution

Needs live debugging of the plan-review → 'Start Implementation' handoff path (chatPlanReviewPart.ts / chatHandoffs / agentHostSessionHandler.ts) to find why the UI mode indicator and the actual agent-host session mode can desync for some models; likely a maintainer session with repro access to the affected models is needed before a fix can be scoped.
