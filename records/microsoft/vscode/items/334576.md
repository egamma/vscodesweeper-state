# Issue #334576 — Plan - Start Plan With Autopilot doesn't go into agent mode reliably

[https://github.com/microsoft/vscode/issues/334576](https://github.com/microsoft/vscode/issues/334576)

## Summary

Two independent users (across 1.136.1 and 1.137.0) report the same symptom: after Plan Mode completes with Autopilot selected, the exit-plan-mode flow silently stalls (a system notification flashes and dismisses) and the UI shows agent mode while the session is actually stuck, requiring a manual plan→agent toggle. The code in exitPlanModeHandler.ts always resolves `approved: true` in the autopilot branch, so the stall likely originates in SDK-side event/timing behavior (or model-specific behavior per comment 1, e.g. gpt-6-astra) rather than an obviously broken line in this repo, so I can't pinpoint a concrete fix from source alone.

## Change summary

Clicking 'Start Plan With Autopilot' sometimes leaves the agent stuck in Plan Mode instead of automatically continuing into Agent/implementation mode, even though the UI shows Agent mode.

## Best solution

Needs investigation from the Copilot Chat/Agent Host team into the exit_plan_mode.requested handling in extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotcliSession.ts and exitPlanModeHandler.ts, likely correlating with SDK/model-specific timing (per comment 1's gpt-6-astra note) to find why the UI mode state and the underlying session state can diverge.
