# Issue #345458 — Windows terminal: pasting a passphrase into ssh-keygen from a pwsh terminal can silently create SSH keys with a 1-character passphrase (Ctrl+V sends raw ^V instead of pasting)

[https://github.com/microsoft/vscode/issues/345458](https://github.com/microsoft/vscode/issues/345458)

## Summary

Current source supports the reported PowerShell paste race: Ctrl+V can send a control character to a child program before delayed shell detection updates the binding context. Keep this security-sensitive report open and route it to terminal ownership.

## Change summary

Prevent PowerShell-specific Ctrl+V handling from silently substituting U+0016 for clipboard text at child-program passphrase prompts.

## Best solution

Ensure terminal paste routing distinguishes an interactive PowerShell prompt from a running child program without relying solely on delayed shell-type detection, while preserving the intended PSReadLine paste behavior. Terminal maintainers should assess the reported credential-protection impact.
