# Issue #318103 — Agents Window: support extension development workflow (extensionDevelopmentPath + debugger)

[https://github.com/microsoft/vscode/issues/318103](https://github.com/microsoft/vscode/issues/318103)

## Summary

Valid feature request for extension development support in the Agents Window. The gap is real: the extensionHost debug type does not handle `--agents`, and the Agents Window does not propagate `extensionDevelopmentPath` to its extension host. No implementation exists on current main.

## Change summary

Enable the standard extension development workflow (extensionDevelopmentPath + debugger) to work with the Agents Window, so extension authors can develop and debug extensions targeting the Agents Window.

## Best solution

Two changes are needed: (1) teach the extensionHost debug adapter (in `src/vs/workbench/contrib/debug/browser/extensionHostDebugService.ts` and the Electron launch path) to recognize an `--agents` flag and open the Agents Window instead of a regular editor window, and (2) have the Agents Window's extension host inherit `extensionDevelopmentPath` from the launching Development Host so that the in-development extension is loaded. This is core infrastructure work — not an extension candidate — since it requires changes to the debug adapter and the Agents Window's extension host lifecycle.
