# Issue #270454 — SCM - vscode doesn't remember collapsed state of `staged changes`

[https://github.com/microsoft/vscode/issues/270454](https://github.com/microsoft/vscode/issues/270454)

## Summary

Team-authored bug that is still reproducible on main: the auto-reveal logic in `onDidActiveEditorChange` calls `expandTo` which unconditionally expands collapsed groups. An open community PR (#305267) exists but has not merged. Keeping open per team-authored rule and open-PR rule.

## Change summary

When a staged file is open in the editor and the user switches away from the SCM view and back, the collapsed 'Staged Changes' group is auto-expanded by the reveal logic, discarding the user's collapsed state.

## Best solution

The fix should check whether the user has explicitly collapsed a group before expanding it during auto-reveal. The open PR at https://github.com/microsoft/vscode/pull/305267 attempts this — a maintainer should review it for correctness (it needs to respect the collapsed state while still revealing when appropriate). The related issue https://github.com/microsoft/vscode/issues/326345 covers the reload case and may or may not be the same root cause.
