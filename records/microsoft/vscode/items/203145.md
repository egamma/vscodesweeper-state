# Issue #203145 — Testing #203097: Calling `Fold cell` makes screen jump down

[https://github.com/microsoft/vscode/issues/203145](https://github.com/microsoft/vscode/issues/203145)

## Summary

Team-authored bug, still present on main — no commit references this issue, and the fold-via-command-palette path in foldingController.ts does not include scroll-anchor logic to keep the folded header visible after cells are removed from the view.

## Change summary

Calling 'Fold Cell' from the command palette causes the notebook viewport to jump away from the folded header, unlike folding via the chevron.

## Best solution

Add scroll-position anchoring in the fold action path (foldingController.ts or notebookCellList.ts setHiddenAreas) so that after folding, the header cell remains visible in the viewport — matching the behavior when folding via the chevron click.
