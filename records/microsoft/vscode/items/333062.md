# Issue #333062 — "Reindent Lines" doesn't work correctly with square brackets

[https://github.com/microsoft/vscode/issues/333062](https://github.com/microsoft/vscode/issues/333062)

## Summary

Confirmed root cause in extensions/rust/language-configuration.json: indentationRules omits square brackets from increaseIndentPattern/decreaseIndentPattern, causing indent drift on Reindent Lines. An open PR (#333326) already fixes this, so it should be left to land rather than closed or auto-fixed now.

## Change summary

Reindent Lines misindents Rust code containing square-bracket blocks (e.g. vec![...]) because the language configuration's indent rules don't account for [/].

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333326, which adds [/] symmetrically to extensions/rust/language-configuration.json's indentationRules, mirroring typescript-basics' handling of all three bracket types.

## Evidence

- **root cause verified:** extensions/rust/language-configuration.json indentationRules: increaseIndentPattern is `^.*\{[^}"']*$|^.*\([^\)"']*$` and decreaseIndentPattern is `^\s*(\s*\/[*].*[*]\/\s*)*[})]` — neither pattern includes `[` or `]`, exactly matching the commenter's diagnosis and the reported bad output.
- **comparison:** extensions/typescript-basics/language-configuration.json's decreaseIndentPattern is `^\s*[\}\]\)].*$`, correctly covering all three bracket types, confirming the rust config is the outlier.
