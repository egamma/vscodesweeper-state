# Issue #333062 — "Reindent Lines" doesn't work correctly with square brackets

[https://github.com/microsoft/vscode/issues/333062](https://github.com/microsoft/vscode/issues/333062)

## Summary

The Rust indentation rules on current main still omit square brackets, explaining the reported indentation drift. Keep this open while the existing fixing PR is reviewed and landed.

## Change summary

Make Reindent Lines correctly indent Rust square-bracket expressions without shifting subsequent statements or closing braces.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333326 after confirming that it preserves correct indentation for both vec![...] and foo(vec![...]) in the supplied sample.
