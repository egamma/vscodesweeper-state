# Issue #329605 — Modern UI: close button overlay causes accidental tab closure when clicking the filename

[https://github.com/microsoft/vscode/issues/329605](https://github.com/microsoft/vscode/issues/329605)

## Summary

Fresh, well-documented regression tied to the just-merged Modern UI tabs redesign, which intentionally moved tab actions to render over tab content — for short filenames this puts the close button over clickable label text, risking accidental tab closes. No maintainer has weighed in yet; routing to the editor/workbench area for review rather than closing.

## Change summary

In the new Modern UI tab design, the close (x) button overlaps the tab's filename text, making part of the filename clickable as a close action and risking accidental tab closure.

## Best solution

Adjust the tab layout in src/vs/workbench/browser/parts/editor/media/multieditortabscontrol.css / editorTabsControl.ts so the close button's hit target doesn't overlap the visible label text — e.g. reserve label width for the action area or increase hit-target isolation — as a follow-up to the redesign landed in PR #328111.
