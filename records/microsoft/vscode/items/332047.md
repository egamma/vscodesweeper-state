# Issue #332047 — Agent host: restored Claude sessions lose their slash commands, skills and agents until the next message

[https://github.com/microsoft/vscode/issues/332047](https://github.com/microsoft/vscode/issues/332047)

## Summary

Confirmed on current main: `ClaudeAgent.getChatCustomizations` (src/vs/platform/agentHost/node/claude/claudeAgent.ts, ~line 2587) resolves only via `_findChatByUri`, returning `[]` when a chat's live runtime isn't resident (after idle eviction or restore), so restored sessions show no slash commands/skills until the next message. An open PR (#332055) already implements the suggested fix.
