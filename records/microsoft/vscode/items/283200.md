# Issue #283200 — Agent misses user edits - EditedFileEvents missing

[https://github.com/microsoft/vscode/issues/283200](https://github.com/microsoft/vscode/issues/283200)

## Summary

Keep open: this team-authored On Deck issue has a concrete reproduction showing that the agent can receive stale file context after a user manually edits an agent-modified file. No explicit fixing commit or older open canonical with the same observable symptom is identified.

## Change summary

Ensure a subsequent agent request includes edited-file events when the user manually changes a file previously edited by the agent.

## Best solution

Preserve and inject user-edit notifications across agent turns so the next request knows that an agent-edited file changed outside the agent; add regression coverage for agent edit, manual edit, then follow-up request.
