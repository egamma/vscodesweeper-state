# Issue #283200 — Agent misses user edits - EditedFileEvents missing

[https://github.com/microsoft/vscode/issues/283200](https://github.com/microsoft/vscode/issues/283200)

## Summary

Team-filed bug (MEMBER author) — hard keep-open rule applies. The defect appears to still exist on main: user manual edits to agent-modified files are not reliably surfaced as EditedFileEvents in subsequent agent prompts, causing the agent to miss user changes.

## Change summary

When a user manually edits a file that the agent previously modified, the EditedFileEvents hints are missing from the agent prompt, so the agent doesn't see the user's edits.

## Best solution

Ensure that user manual edits to agent-modified files trigger `notifyEditingAction` with `userModified` outcome so that `EditedFileEvents` are populated in the next request's prompt context. The gap likely lies in the editing session's file-change detection not firing `chatEditingSessionAction` user actions for manual edits — the wiring between the editing session's document change tracking and `IChatService.notifyUserAction` needs to cover this path.
