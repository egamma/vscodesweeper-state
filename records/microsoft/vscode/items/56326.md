# Issue #56326 — Support auto update for Windows and Linux ZIP

[https://github.com/microsoft/vscode/issues/56326](https://github.com/microsoft/vscode/issues/56326)

## Summary

Still valid: the Windows and Linux ZIP/portable update paths only surface AvailableForDownload — they never auto-download and apply in-place like macOS does. The gap remains on current main.

## Change summary

Request seamless in-place auto-update for Windows and Linux ZIP (portable) installations, matching macOS behavior.

## Best solution

Implement an in-place update mechanism for the Archive update type on Windows and Linux in the update service (updateService.win32.ts / updateService.linux.ts). The download+overwrite flow would need to handle swapping files while the process is running — likely requiring an external helper or a restart-and-apply approach. This is non-trivial due to file-locking on Windows and the need to preserve the data folder.
