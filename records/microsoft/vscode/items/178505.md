# Issue #178505 — Allow extensions to specify the schema for arguments to contributed commands

[https://github.com/microsoft/vscode/issues/178505](https://github.com/microsoft/vscode/issues/178505)

## Summary

Valid feature request to let extensions declare JSON schemas for command arguments (enabling autocomplete in keybindings.json). Not yet implemented on main; the current workaround (contributing jsonValidation) is clunky but functional.

## Change summary

Allow extensions to specify a JSON schema for their contributed commands' arguments so users get autocompletion in keybindings.json.

## Best solution

Extend the `contributes.commands` extension point to accept an optional `args` schema property, and wire it into the keybindings.json schema generation (similar to how built-in commands like `workbench.action.tasks.runTask` register theirs via `ICommandHandlerDescription`). This touches the commands extension point schema and the keybindings JSON validation pipeline.
