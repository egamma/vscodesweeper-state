# Issue #236404 — Devcontainers ignores terminal profile settings from settings.json when opening local integrated terminal

[https://github.com/microsoft/vscode/issues/236404](https://github.com/microsoft/vscode/issues/236404)

## Summary

Keep open: current core terminal code explicitly selects the local system shell instead of the configured default profile when creating a local terminal in a remote window. The reported behavior remains source-reproducible and is already correctly routed.

## Change summary

Honor the configured local terminal profile when using Create New Integrated Terminal (Local) from a Dev Container workspace.

## Best solution

Resolve the configured profile against the local terminal backend and local operating system, preserving its executable and arguments while retaining the existing system-shell fallback when no valid default profile exists. This belongs in core terminal creation, not an extension-tracker transfer.
