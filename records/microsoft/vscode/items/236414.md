# Issue #236414 — Grouping/sorting of notebook command 

[https://github.com/microsoft/vscode/issues/236414](https://github.com/microsoft/vscode/issues/236414)

## Summary

Keep open: notebook commands now have some explicit grouping, but the toolbar still flattens secondary groups without separators, so the requested organization is not demonstrably complete. The existing notebook area labels remain appropriate.

## Change summary

Organize notebook commands into coherent layout, kernel, and export groups with predictable ordering.

## Best solution

Provide consistent semantic grouping across the notebook overflow menu and its command contributions, coordinating Jupyter-owned actions where necessary. Preserve the distinction between layout, kernel operations, and export rather than relying only on alphabetical ordering.
