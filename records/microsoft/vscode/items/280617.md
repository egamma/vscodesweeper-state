# Issue #280617 — Support actioning session widgets that require input in the session hover

[https://github.com/microsoft/vscode/issues/280617](https://github.com/microsoft/vscode/issues/280617)

## Summary

Current main already renders chat content in session hovers and offers inline approval actions, but reliable interaction with the complete approval widget is not established. Keep this team-authored request open: no verified duplicate or issue-referencing fix establishes completion.

## Change summary

Allow users to answer pending approval and input widgets directly inside a session hover without opening the session.

## Best solution

Establish whether the current session hover supports complete approval interactions in the stacked layout, including moving focus or the pointer into its controls. Retain this request for any remaining full-widget capability; distinguish that scope from the narrower pointer-dismissal defect reported in https://github.com/microsoft/vscode/issues/322393.
