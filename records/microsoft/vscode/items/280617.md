# Issue #280617 — Support actioning session widgets that require input in the session hover

[https://github.com/microsoft/vscode/issues/280617](https://github.com/microsoft/vscode/issues/280617)

## Summary

Team-authored feature request (MEMBER) for actionable approval widgets in the session hover. The hover currently renders chat content read-only via ChatListWidget but does not support interactive input like tool-approval buttons. Recent work (d769f0decad) surfaced sessions requiring input in the agents titlebar, but the hover itself remains non-interactive. Keeping open per team-authored rule.

## Change summary

Allow users to take actions (e.g. approve tool invocations) directly from the session hover widget, rather than having to open the full session.

## Best solution

Extend `AgentSessionHoverWidget` (src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionHoverWidget.ts) to render interactive approval/confirmation widgets when the session is blocked on user input, so users can act without switching context. The recent blocked-sessions titlebar work (d769f0decad) provides the detection infrastructure; the hover needs the interactive rendering path.
