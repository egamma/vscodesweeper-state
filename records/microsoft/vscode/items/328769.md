## Summary

Active, unresolved bug report from a VS Code team member: the Nemotron 3.5 ASR streaming model gets stuck (Listening state with no audio captured, mic toggle unresponsive) on the reporter's Arch Linux system, while other models (nemotron-speech-streaming-en-0.6b, MAI) work fine for them.
