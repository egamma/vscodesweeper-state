# Issue #334400 — Git - Support `git rebase --onto` (transplant a range of commits)

[https://github.com/microsoft/vscode/issues/334400](https://github.com/microsoft/vscode/issues/334400)

## Summary

The built-in Git API supports --onto, but the user-facing rebase commands still accept only one ref. Keep this distinct request open and route it to Git for a decision on the two-ref command and menu integration.

## Change summary

Expose a rebase command that selects a new base and an upstream cutoff to transplant a range of commits from the current branch.

## Best solution

Provide a user-facing two-ref rebase workflow in the built-in Git extension, using its existing --onto support and conflict handling while preserving ordinary Rebase Branch behavior. Decide whether graph entry points belong in the initial scope.
