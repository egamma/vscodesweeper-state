# Issue #334400 — Git - Support `git rebase --onto` (transplant a range of commits)

[https://github.com/microsoft/vscode/issues/334400](https://github.com/microsoft/vscode/issues/334400)

## Summary

Reasonable, well-scoped ask for `git rebase --onto` support that VS Code's Git extension genuinely lacks today — routing to the git area for triage rather than closing.

## Change summary

Add a 'Git: Rebase Onto...' command supporting the three-argument `git rebase --onto <newbase> <upstream> [<branch>]` form, exposed in the command palette, branch context menu, and Graph view.

## Best solution

Extend extensions/git/src/git.ts's rebase() (currently only supports plain `git rebase <branch>`, see line 2504) and extensions/git/src/commands.ts to add an --onto variant with a new command and two quick-pick ref prompts; Graph view integration can follow as a stretch goal.
