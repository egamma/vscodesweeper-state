# Issue #169923 — Merge conflict: save the file when choosing "accept all"

[https://github.com/microsoft/vscode/issues/169923](https://github.com/microsoft/vscode/issues/169923)

## Summary

Still reproduces on main: the `acceptAllResources` method in the merge-conflict extension applies workspace edits to resolve conflict markers across multiple files but never saves the documents afterward, leaving them dirty and opened in editor tabs. The fix would be a small addition to save the documents after the edit is applied.

## Change summary

When using 'Accept All Current/Incoming' on multiple files in the SCM Merge Changes group, the files are left unsaved and opened in editor tabs instead of being saved automatically.

## Best solution

After `vscode.workspace.applyEdit(edit)` in `acceptAllResources` (extensions/merge-conflict/src/commandHandler.ts ~line 294), save each modified document via `document.save()`. This is a small, localized fix in the merge-conflict built-in extension.
