# Issue #339719 — Copilot Connectors: connection-action telemetry includes connector names

[https://github.com/microsoft/vscode/issues/339719](https://github.com/microsoft/vscode/issues/339719)

## Summary

Confirmed on main: the connection-action telemetry event explicitly includes the connector's public name as a classified field, which the linked test-plan issue (#338176) says should not happen. This is a clean, bounded telemetry-privacy fix.

## Change summary

`copilotConnectors.connectionAction` telemetry events include `connectorName`, which should be excluded per the additional telemetry checks specified in #338176.

## Best solution

Drop the `connectorName` field (and its classification entry) from `CopilotConnectorConnectionActionEvent`/`CopilotConnectorConnectionActionClassification` in copilotConnectorsService.ts, and update the existing unit tests that currently assert on it.
