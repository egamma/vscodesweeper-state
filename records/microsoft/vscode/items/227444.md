# Issue #227444 — Emmet dot snippet is triggered after quotes

[https://github.com/microsoft/vscode/issues/227444](https://github.com/microsoft/vscode/issues/227444)

## Summary

Still reproduces on main: Emmet's abbreviation extraction in HTML treats `.` immediately after a quote as a valid class-shortcut abbreviation, offering an unwanted `div.class` snippet expansion.

## Change summary

Emmet incorrectly triggers a dot-based snippet (e.g. `div.class`) when typing a period immediately after a closing quote in an HTML file.

## Best solution

Add a guard in `extensions/emmet/src/defaultCompletionProvider.ts` (around line 131, after `extractAbbreviation` returns) to reject expansions where the character immediately before the abbreviation range is a quote character (`"` or `'`). This prevents false-positive Emmet completions after quoted text.
