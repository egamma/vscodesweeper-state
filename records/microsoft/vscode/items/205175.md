# Issue #205175 — (Ctrl + Shift) Multi-text Selection: Incorrect Selection Relative to Selections

[https://github.com/microsoft/vscode/issues/205175](https://github.com/microsoft/vscode/issues/205175)

## Summary

Confirmed bug in multi-cursor word selection. Ctrl+Shift+Right incorrectly calculates selection endpoints relative to the primary cursor instead of each individual cursor.

## Change summary

Multi-cursor word selection with Ctrl+Shift+Right produces incorrect selection ranges when cursors are positioned before quoted strings.

## Best solution

Fix word-navigation commands so each cursor independently computes its word boundary from its own position, preserving consistent selection behavior across all cursors.
