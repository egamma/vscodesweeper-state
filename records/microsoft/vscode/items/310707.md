# Issue #310707 — search highlight barely visible

[https://github.com/microsoft/vscode/issues/310707](https://github.com/microsoft/vscode/issues/310707)

## Summary

The default 2026 themes still use low-opacity find-match colors, and the minimap inherits the same secondary-match color, so the reported visibility regression remains on current main. Route this to editor find, minimap, and theming owners rather than closing it.

## Change summary

Search matches became difficult to distinguish in the editor and minimap after the new default themes shipped.

## Best solution

Raise the visibility of non-current search matches in the new default themes, using a dedicated `minimap.findMatchHighlight` color if necessary to preserve the intended in-editor palette while making minimap markers distinct.
