# Issue #207033 — VS Code should default to Wayland when possible

[https://github.com/microsoft/vscode/issues/207033](https://github.com/microsoft/vscode/issues/207033)

## Summary

Keep open: native Wayland defaults are reported working in some non-Snap installations, but the current official Snap launcher still explicitly forces X11. The accepted request is therefore not fully delivered, and an existing open PR should be evaluated before starting competing work.

## Change summary

Prefer native Wayland automatically on supported Linux Wayland sessions without requiring users to modify launchers or supply flags.

## Best solution

Provide consistent automatic display-backend selection across official Linux packages, retaining appropriate X11 fallback and explicit overrides. Evaluate https://github.com/microsoft/vscode/pull/199052 against current Electron behavior; its opt-in Snap implementation alone would not satisfy the requested default.
