# Issue #340732 — pasting with multiple lines copied from multiple cursors is now unusable (and does not respect settings)

[https://github.com/microsoft/vscode/issues/340732](https://github.com/microsoft/vscode/issues/340732)

## Summary

Thanks for the report. I couldn't confirm a regression from the source: the report doesn't say how the multiple cursors were created or what exact text and result were involved, and the shallow git history has no identifiable recent change.

## Change summary

After copying with multiple cursors and pasting multi-line text into a single cursor or line, the pasted lines overwrite existing line content instead of being inserted as before.

## Best solution

Establish whether the copy came from a real column (box) selection, which triggers block paste, or from added cursors. Then either fix the paste path to honor the overtype and multiCursorPaste settings or document the behavior as intended.
