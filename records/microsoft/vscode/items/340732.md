# Issue #340732 — pasting with multiple lines copied from multiple cursors is now unusable (and does not respect settings)

[https://github.com/microsoft/vscode/issues/340732](https://github.com/microsoft/vscode/issues/340732)

## Summary

Keep open: single-cursor column paste is intentionally coupled to multi-cursor distribution, leaving no setting that preserves both previous workflows. The overwrite allegation is not established by the source, which still checks the overtype setting.

## Change summary

Restore newline-inserting single-cursor paste without disabling line distribution across multiple cursors.

## Best solution

Provide an independently selectable legacy single-cursor paste behavior while preserving multi-cursor distribution. Decide the default with the editor owner; investigate any actual unselected-text replacement separately from the intentional block-paste behavior.

Replacing unselected destination text must continue to depend on overtype mode and editor.overtypeOnPaste.
