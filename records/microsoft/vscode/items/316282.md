# Issue #316282 — Copilot CLI session fails in detached HEAD state due to incorrect branch selection

[https://github.com/microsoft/vscode/issues/316282](https://github.com/microsoft/vscode/issues/316282)

## Summary

Still reproduces on main: in detached HEAD state, the branch picker falls through to `branches[0]` (alphabetically first) because `HEAD.name` is undefined, causing the session to use a non-existent checkout. Team-authored, no fix found.

## Change summary

Starting a Copilot CLI session from a detached HEAD folder auto-selects an arbitrary branch instead of respecting the detached state, causing runtime errors.

## Best solution

In `_loadBranches` and the `currentBranchName` derived, detect detached HEAD (commit exists but name is undefined) and either skip branch auto-selection or fall back to workspace isolation mode, similar to the empty-repo guard at line 364–366. The fix belongs in `src/vs/sessions/contrib/providers/copilotChatSessions/browser/copilotChatSessionsProvider.ts`.
