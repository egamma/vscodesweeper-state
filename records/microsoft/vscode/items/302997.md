# Issue #302997 — VS Code Speech: Add right click to read aloud selected text

[https://github.com/microsoft/vscode/issues/302997](https://github.com/microsoft/vscode/issues/302997)

## Summary

Keep open: existing Read Aloud operates on a response, and Voice Mode's concise narration does not provide playback of the exact text the user selects. No verified older, open canonical owns this selection-specific request.

## Change summary

Allow selected text in a chat response to be read aloud through a context-menu action, with blockquote-only playback offered as an alternative.

## Best solution

Provide an accessible, selection-scoped playback action in the chat read-aloud surface so users can listen to the exact passage they are reviewing without narrating the surrounding response. Account for the newer Voice Mode direction without treating generated summaries as equivalent to verbatim selection playback.
