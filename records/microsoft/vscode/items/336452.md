# Issue #336452 — Diff Editor hides semantically significant YAML indentation changes

[https://github.com/microsoft/vscode/issues/336452](https://github.com/microsoft/vscode/issues/336452)

## Summary

The built-in YAML extension already ships `diffEditor.ignoreTrimWhitespace: false` as a language default, which should prevent exactly the hidden-indentation problem described — a contributor made the same point in the thread — so more info is needed to tell whether the reporter's file wasn't actually in YAML language mode, had a personal override, or there's a real gap in how that default is applied to git/SCM diffs.

## Change summary

Diff Editor hides indentation-only changes in YAML files because trim-whitespace is ignored by default, even though indentation is semantically significant in YAML.

## Best solution

Confirm with the reporter that the file's language mode was YAML and that no user/workspace setting overrides `diffEditor.ignoreTrimWhitespace`; if the built-in default is being bypassed for git-diff/SCM views specifically, that's a distinct, narrower bug worth its own trace once reproduced.
