# Issue #119290 — [scss] SCSS Validator doesn't like brackets

[https://github.com/microsoft/vscode/issues/119290](https://github.com/microsoft/vscode/issues/119290)

## Summary

The SCSS parser in the upstream vscode-css-languageservice does not support bracketed lists — the fix belongs in that dependency (issue #231 there is still open). Keeping open as an upstream issue since it's tracked in a Microsoft-owned repo.

## Change summary

SCSS validator incorrectly flags bracketed list syntax (e.g. `[1, 2]`) as errors.

## Best solution

Implement bracketed list support in the SCSS parser in vscode-css-languageservice (https://github.com/microsoft/vscode-css-languageservice/issues/231); once shipped there, bump the dependency in `extensions/css-language-features/server/package.json` to pick it up.
