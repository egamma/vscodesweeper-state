## Summary

Brand-new, team-authored (MEMBER) task describing a real, currently-unimplemented gap: existing migration code only moves workspace `.vscode/mcp.json` to `.mcp.json`, not user-data-dir MCP servers to `~/.copilot/mcp-config.json`. Nothing here supports a close; it's a legitimate open work item that needs design before implementation.

## Change summary

Offer to migrate MCP servers currently configured in the VS Code user data directory (`mcp.json`) to the Copilot agent host's `~/.copilot/mcp-config.json` as the workspace mcp.json format is deprecated.

## Best solution

Extend the existing McpServerCustomizationMigrator (src/vs/workbench/contrib/chat/browser/aiCustomization/mcpServerCustomizationMigration.ts), which currently only migrates `.vscode/mcp.json` → `.mcp.json`, to also detect and offer migration for user-level MCP config into the Copilot agent host's config file, likely coordinated with the broader customization-migration tracking issues.
