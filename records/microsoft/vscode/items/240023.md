[https://github.com/microsoft/vscode/issues/240023](https://github.com/microsoft/vscode/issues/240023)

## Summary

The same loss of relative alignment during selected-line indent/outdent is already tracked by the older, open issue https://github.com/microsoft/vscode/issues/63388. Its report and discussion cover both block comments and non-tabstop indentation, meeting the stronger duplicate bar for this re-reviewed item.

## Change summary

Preserve relative spacing when indenting or unindenting selected lines instead of snapping each line independently to a tabstop.

Consolidate the remaining alignment-preservation work in https://github.com/microsoft/vscode/issues/63388, carrying over this report's Plain Text reproduction and wrapped-argument example. The existing editor.useTabStops setting provides the requested fixed-width behavior when disabled.

This supplies the requested behavior for the reported spaces-only examples.
