[https://github.com/microsoft/vscode/issues/332727](https://github.com/microsoft/vscode/issues/332727)

## Summary

Reasonable cross-product architecture request, and VS Code's agent host already has partial infrastructure moving in this direction (a shared `~/.copilot` home used across providers), but the request also asks to fold in VS Code's own `%APPDATA%/Code/User` prompt/agent storage and the separate Copilot Desktop app, which is a broader product decision this repo alone can't settle — keeping open for maintainer input rather than closing.

## Change summary

Requests a single unified `~/.copilot`-style home directory shared by VS Code, Copilot CLI, and the Copilot Desktop app for agents/skills/prompts/instructions/hooks/MCP config, instead of assets being split between `.copilot` and VS Code's own user data folder.

## Best solution

Route to the agent-host/customizations owners: `src/vs/platform/agentHost/common/copilotHome.ts` already centralizes a `.copilot` root used by the agent host for cross-provider customization discovery (see `sessionCustomizationDiscovery.test.ts`), so the remaining gap is whether VS Code's own workbench-authored prompts/agents (stored under the app's user data dir) should also live there — that's a product call for the customizations/agent-host team, not something to decide here.
