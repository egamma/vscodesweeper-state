# Issue #229970 — SCM - Going up past the start of a commit message goes into history and sometimes loses the commit message you were typing

[https://github.com/microsoft/vscode/issues/229970](https://github.com/microsoft/vscode/issues/229970)

## Summary

Keep open as the existing SCM report for unreliable draft restoration during commit-message history navigation. Removing the Up-arrow binding addresses accidental navigation, but neither that workaround nor Undo establishes that returning through history reliably restores the draft.

## Change summary

Commit-message history navigation can unexpectedly replace an unfinished message, and navigating forward sometimes fails to restore it.

## Best solution

Ensure SCM history navigation reliably preserves and restores unfinished commit messages across repeated backward/forward navigation. Retain the existing keybinding customization as an opt-out; investigate the reported restoration failure separately from any decision to change default shortcuts.
