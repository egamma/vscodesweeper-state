# Issue #339865 — Moving chat in the grid behavior is inconsistent

[https://github.com/microsoft/vscode/issues/339865](https://github.com/microsoft/vscode/issues/339865)

## Summary

Keep open: directional movement still targets a neighboring leaf, so its result depends on nested split orientation rather than consistently joining an adjacent row. The issue is already correctly routed to agents-window.

## Change summary

Make Move Session Above and Below consistently join an adjacent row, creating a row when none exists.

## Best solution

Provide predictable row-aware vertical movement within the Sessions grid while preserving live conversations, drafts, focus, and unaffected pane sizes. Clarify how an adjacent row is identified in uneven nested layouts before implementing that contract.
