# Issue #257960 — Git stash created by lint-staged not visible in VS Code's "View Stash" panel

[https://github.com/microsoft/vscode/issues/257960](https://github.com/microsoft/vscode/issues/257960)

## Summary

Confirmed bug: the stash parsing regex in `extensions/git/src/git.ts` requires the `(WIP )?on <branch>: <description>` format, silently dropping stashes with custom messages (e.g. lint-staged). An open PR (#301113) already addresses this — keeping open until it lands.

## Change summary

Git stashes created with custom messages (e.g. by lint-staged) are invisible in VS Code's Source Control stash panel because the parser regex rejects non-standard reflog subjects.

## Best solution

Land https://github.com/microsoft/vscode/pull/301113, which refactors `parseGitStashes()` to use a permissive regex that captures stashes regardless of message format, then optionally extracts branch name from the standard `on <branch>:` pattern. Also consolidates https://github.com/microsoft/vscode/issues/262360 as a duplicate of this issue.
