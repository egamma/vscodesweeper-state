# Issue #301871 — Quick Open % symbol search preview closes picker when resolving a Custom Editor (Webview focus theft)

[https://github.com/microsoft/vscode/issues/301871](https://github.com/microsoft/vscode/issues/301871)

## Summary

Confirmed on current main: the % text search quick access previews files via transient editor open with preserveFocus:true, but webview-based custom editors steal focus on creation, triggering the quick input's blur→hide path. The defect is still present.

## Change summary

Quick Open % text search picker closes when arrowing to a result in a file associated with a webview-based Custom Editor, because the webview steals focus despite preserveFocus:true.

## Best solution

The webview editor pane (WebviewEditor) should respect the preserveFocus option during setInput/setVisible — skip calling this.webview.focus() when the editor was opened with preserveFocus:true. The fix likely involves src/vs/workbench/contrib/webviewPanel/browser/webviewEditor.ts (the focus() override at line 99) and possibly the editor group's activation logic ensuring it doesn't call focus() on a pane opened with preserveFocus. An alternative is for the quick input to set ignoreFocusOut during transient preview opens, but that's a broader workaround.
