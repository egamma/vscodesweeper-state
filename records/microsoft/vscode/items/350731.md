# Issue #350731 — Bug P2 Copilot: terminalCommands map is never cleared on terminal close, so closed terminals and up to 40 command outputs each stay in extension host memory

[https://github.com/microsoft/vscode/issues/350731](https://github.com/microsoft/vscode/issues/350731)

## Summary

Confirmed in current main: closing a terminal removes its buffer but leaves its command history strongly retained. Keep this open for a bounded lifecycle cleanup in the built-in Copilot terminal listener.

## Change summary

Release closed terminals and their retained command outputs from Copilot's terminal history cache.

## Best solution

Terminal-specific cached history should end with the terminal's lifetime, while open terminals retain their existing command-history behavior and limits.
