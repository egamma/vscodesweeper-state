# Issue #39888 — Feature Request: Keybinding Overloading

[https://github.com/microsoft/vscode/issues/39888](https://github.com/microsoft/vscode/issues/39888)

## Summary

A real capability gap remains: current keybinding dispatch selects one applicable command rather than offering all matches. The request earned 26 upvotes and was explicitly promoted to the Backlog, so it should remain open.

## Change summary

Optionally present a command-selection menu when multiple applicable commands share a keybinding.

## Best solution

Add an opt-in synchronous conflict picker in the keybinding dispatch path while preserving the current precedence behavior by default. Keybinding owners should assess its interaction and latency implications before implementation.

- **Reason:** Resolving shortcut conflicts could improve predictable workbench interactions, but an invocation-time menu also adds UI and configuration complexity not directly addressed by the vision.
- **Evidence:** The public values favor simple, uniform UI interactions and a lightweight default experience; these considerations pull in different directions here.
