## Summary

The VS Code update mechanism correctly serves the architecture of the running binary (via `process.arch`). The user had an amd64 build installed on an arm64 Chromebook — the fix is to install the arm64 .deb initially, not a code change.

## Change summary

User on arm64 Chromebook received an amd64 .deb update because their existing VS Code installation was the amd64 build.

## Best solution

This is a support question: the user needs to uninstall the amd64 version and install the arm64 .deb from https://code.visualstudio.com/download. The update service correctly offers packages matching the running process architecture (`process.arch` in `updateService.linux.ts` line 38).
