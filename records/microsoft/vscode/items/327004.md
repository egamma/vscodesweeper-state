[https://github.com/microsoft/vscode/issues/327004](https://github.com/microsoft/vscode/issues/327004)

## Summary

Team-authored bug report about browser tool calls losing their rich rendering (detail and link to the browser tab) after a VS Code restart. No fix found on main; keeping open for the author/area owner to address.

## Change summary

Browser tool calls in Agent Host sessions degrade to a raw tool name with no detail or link after restarting VS Code.

## Best solution

The chat tool invocation rendering for browser tools needs to handle the deserialized/restored session state — likely the tool result or confirmation sub-part loses its browser-specific data (URL, tab reference) during serialization/deserialization in the chat model. The fix likely belongs in the browser tool rendering path under `src/vs/workbench/contrib/browserView/electron-browser/` or the chat tool invocation parts under `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/`.
