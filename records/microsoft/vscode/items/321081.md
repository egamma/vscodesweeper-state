# Issue #321081 — "Open Quick Access" panel directly into "commands" or add setting to choose default behavior

[https://github.com/microsoft/vscode/issues/321081](https://github.com/microsoft/vscode/issues/321081)

## Summary

The mouse-click workflow still lacks a configurable Commands default. Keep this request open for discussion: existing commands offer alternative entry points, but do not change what clicking the Command Center opens.

## Change summary

Allow clicking the Command Center to open Commands directly, or let users choose its default search tab.

## Best solution

Decide whether the Command Center should support a user-selected initial mode, including Commands, while preserving existing explicit file, session, and command entry points. Coordinate with the related default-mode requests without treating their different requested behaviors as duplicates.
