# Issue #329065 — Images Preview does not provide a way to copy or save images

[https://github.com/microsoft/vscode/issues/329065](https://github.com/microsoft/vscode/issues/329065)

## Summary

Confirmed by reading the source: the Image Carousel ("Images Preview") editor has no context menu, no copy/save action, and no reveal/open-source action anywhere in its implementation — this is a real, currently-missing capability in a young preview feature, and the author is a VS Code team member so this stays open regardless.

## Change summary

The Images Preview (image carousel) editor lets you navigate and zoom images but offers no way to copy, save, open, or reveal the displayed image.

## Best solution

Add a context-menu (or toolbar) affordance on the main image in src/vs/workbench/contrib/imageCarousel/browser/imageCarouselEditor.ts that supports copy-to-clipboard, save-as, and — when the image originates from a workspace file — open/reveal-in-explorer, consistent with the standard binary/image editor's existing copy/save actions.
