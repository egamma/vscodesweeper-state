# Issue #340226 — Inline chat terminal stops updating for long-running background shells

[https://github.com/microsoft/vscode/issues/340226](https://github.com/microsoft/vscode/issues/340226)

## Summary

Real, well-diagnosed bug with a clear repro and precise analysis from the reporter; an open PR (#340234, by the same author) already targets this exact issue with 'Resolves: #340226', stacked on the just-merged #340222. Keep open until that PR lands.

## Change summary

The inline chat terminal for an Agent Host background shell stops rendering new output partway through a long run, even though the window keeps receiving and the tool call keeps its terminal subscription until after the shell exits.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/340234, which gives the inline chat terminal of Agent Host output-only shells the host's full scrollback (mirroring the fix #340222 made for the Background Shells preview) so it no longer drops old rows while scrolled up.
