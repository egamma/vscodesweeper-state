# Issue #251325 — Accessibility: Insufficient contrast for file path in VSCode Panel failing WCAG 1.4.3 Contrast (Minimum) Requirement

[https://github.com/microsoft/vscode/issues/251325](https://github.com/microsoft/vscode/issues/251325)

## Summary

Legitimate accessibility concern: the light theme descriptionForeground (#717171) yields ~4.48:1 contrast against white backgrounds, just under the WCAG 4.5:1 minimum. Still present on current main — no fix found.

## Change summary

File-path description text in panels uses a foreground color (#717171 in light theme) that falls slightly below the WCAG 2.1 AA contrast minimum of 4.5:1.

## Best solution

Darken the light-theme `descriptionForeground` value in `src/vs/platform/theme/common/colors/baseColors.ts` from `#717171` to something like `#6e6e6e` or darker to meet 4.5:1 against the panel background, while preserving the visual distinction from primary labels.
