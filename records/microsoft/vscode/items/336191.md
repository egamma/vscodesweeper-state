# Issue #336191 — Splitting a reconnected terminal editor reuses its PTY; closing the copy terminates the original

[https://github.com/microsoft/vscode/issues/336191](https://github.com/microsoft/vscode/issues/336191)

## Summary

The shared-PTY defect remains traceable in current main: copying a restored terminal preserves its persistent-process attachment, and disposing the copy shuts down that same process. Route this unlabeled report to the terminal area; no verified canonical duplicate or open implementation PR was found.

## Change summary

Splitting a reconnected terminal editor must create an independent process so closing the copy leaves the original terminals running.

## Best solution

Make native terminal-editor copies launch independent sessions while preserving normal profile resolution, working-directory behavior, and editor-selection semantics. Keep persistent-process attachment exclusive to restoration rather than copying.
