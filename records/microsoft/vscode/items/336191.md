# Issue #336191 — Splitting a reconnected terminal editor reuses its PTY; closing the copy terminates the original

[https://github.com/microsoft/vscode/issues/336191](https://github.com/microsoft/vscode/issues/336191)

## Summary

The persistent-process attachment still flows into terminal editor copies on current main, allowing the copy to reuse and terminate the original PTY. Keep this actionable report open and route it to the terminal area.

## Change summary

Splitting a reconnected terminal editor should create an independent process whose disposal does not terminate the source terminal.

## Best solution

Make native terminal editor copies launch independent processes while preserving appropriate profile and working-directory behavior. Keep normal editor selection, terminal restoration, and editor moves unchanged.
