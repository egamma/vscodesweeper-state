# Issue #321148 — SCM sidebar Commit & Push keyboard shortcut

[https://github.com/microsoft/vscode/issues/321148](https://github.com/microsoft/vscode/issues/321148)

## Summary

Keep open as a feature request: the underlying combined operation and SCM input context already exist, but there is no directly bindable Commit & Push action that targets the focused SCM repository independently of the default commit action.

## Change summary

Allow a keyboard shortcut to invoke Commit & Push from the SCM message input without changing the default commit action or binding Push separately.

## Best solution

Provide a discoverable, bindable Commit & Push action that uses the repository associated with the focused SCM input and leaves ordinary commit behavior unchanged. Reuse the existing combined commit operation rather than treating commit and push as unrelated commands.

  > Thanks for the request. The SCM input already exposes the `scmRepository` keybinding context, and Git implements Commit & Push internally through `git.commit`. A composite binding can invoke that operation, but with multiple repositories it asks you to choose a repository rather than using the focused SCM input. Keeping this open for a directly bindable action that preserves your default commit behavior.
