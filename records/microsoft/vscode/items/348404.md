# Issue #348404 — New border makes tabs harder to click

[https://github.com/microsoft/vscode/issues/348404](https://github.com/microsoft/vscode/issues/348404)

## Summary

Keep open: current source still reserves a gutter and border above editor tabs when the title bar is hidden, consistent with the reported loss of screen-edge targeting. Compact density now removes the gutter but retains the border; the supplied steps suffice for a desktop retest.

## Change summary

Restore top-screen-edge tab activation when title and menu bars are hidden.

## Best solution

Preserve reliable screen-edge tab targeting in chrome-hidden layouts without requiring users to disable Modern UI. Confirm the desktop hit-testing behavior in default and compact density before settling the layout change.
