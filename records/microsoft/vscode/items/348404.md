# Issue #348404 — New border makes tabs harder to click

[https://github.com/microsoft/vscode/issues/348404](https://github.com/microsoft/vscode/issues/348404)

## Summary

Keep open: current main still reserves an outer gutter above the editor when the title bar is hidden, consistent with the reported loss of screen-edge tab targeting. The supplied settings and steps suffice to retest; the native Kubuntu interaction remains unverified.

## Change summary

Restore screen-edge tab clicking when the title and menu bars are hidden.

## Best solution

Preserve top-edge tab targeting in fullscreen and title-bar-hidden layouts without requiring users to abandon the modern UI. Confirm the native hit-testing behavior, then address the editor's exposed-edge layout and tab hit targets together.
