# Issue #312848 — Extension Signature Verification Failed: SSH FS

[https://github.com/microsoft/vscode/issues/312848](https://github.com/microsoft/vscode/issues/312848)

## Summary

This is a Void Linux Code OSS packaging problem rather than a defect in an official VS Code distribution: the package omitted the required `@vscode/vsce-sign` module. Maintainers have consistently redirected identical reports to the downstream package distributor.

## Change summary

Installing any extension from the Void Linux Code OSS package fails because extension signature verification cannot load `@vscode/vsce-sign`.

## Best solution

The Void Linux package should include the `@vscode/vsce-sign` dependency required by the extension-management code; this needs to be corrected in the downstream package distribution.
