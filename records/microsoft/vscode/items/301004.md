## Summary

The missing cancellation affordance is a valid bug symptom, but the report does not identify the action or state transition that leaves the chat showing “Working” while VS Code considers the response inactive. ## Change summary

A Copilot agent turn can remain stalled on “Working” while the chat presents no Stop button or other way to cancel it.

## Best solution

Keep the Stop action available for every incomplete chat turn and ensure cancellation reaches the pending request even if provider, tool, and response-progress state diverge. First capture a current trace showing whether the response was incorrectly completed, the pending request was dropped, or an unresolved tool call remained.
