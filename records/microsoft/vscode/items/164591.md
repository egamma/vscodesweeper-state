# Issue #164591 — Set scrollTop on textArea on all platforms, not only mac

[https://github.com/microsoft/vscode/issues/164591](https://github.com/microsoft/vscode/issues/164591)

## Summary

Still open: on current main the textarea scrollTop is set only on macOS or when accessibility support is Enabled. A Windows user running Magnifier without a screen reader still hits the old path. The earlier fix claim was refuted, so no fix is cited.

## Change summary

Windows Magnifier does not follow the caret because the hidden textarea's scrollTop is not set on non-Mac platforms.

## Best solution

Align the textarea scrollTop with the cursor line on all platforms in the textarea editor context's non-visible-textarea render path, so users no longer need editor.accessibilityPageSize set to 1.
