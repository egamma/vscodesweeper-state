[https://github.com/microsoft/vscode/issues/164591](https://github.com/microsoft/vscode/issues/164591)

## Summary

The specific Windows Magnifier repro was partially addressed by commit 7cc154201cc (fixing #105558), which sets scrollTop when accessibility support is enabled. However, this issue's broader request — setting scrollTop unconditionally on all platforms — remains unimplemented on current main (line 793 of textAreaEditContext.ts still gates on `isMacintosh || accessibilitySupport === Enabled`). Team-authored, On Deck milestone — keeping open.

## Change summary

Set the textarea's scrollTop on all platforms unconditionally, not only on macOS or when accessibility support is enabled.
