# Issue #164591 — Set scrollTop on textArea on all platforms, not only mac

[https://github.com/microsoft/vscode/issues/164591](https://github.com/microsoft/vscode/issues/164591)

## Summary

The core problem — Windows Magnifier not following the text caret — was fixed in commit 7cc154201cc by extending the scrollTop-setting branch to fire whenever accessibility support is enabled (on any OS), not only on macOS. This shipped in 1.84.0 and the fix remains on current main.

## Change summary

Windows Magnifier does not follow the text caret because the textarea's scrollTop is only set on macOS, not on Windows or other platforms.

## Best solution

Keep the shipped fix (scrollTop set when accessibility support is enabled on any platform). The fix in commit 7cc154201cc addresses the actual user scenario — Windows Magnifier requires accessibility support to be enabled, so the accessibility-gated condition covers it without unconditionally changing behavior on all platforms. No further change needed.
