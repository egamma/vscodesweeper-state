# Issue #340735 — Prompt name matching degraded (regression)

[https://github.com/microsoft/vscode/issues/340735](https://github.com/microsoft/vscode/issues/340735)

## Summary

Thanks for the detailed report. The prompt slash-command filter text appears to add word-suffix aliases, so '/library-documentation' also matches a '/documentation' alias and surfaces for '/document-'. This looks like a real ranking regression, and it needs a fix in the chat input completions.

## Change summary

Typing '/document-' in chat lists unrelated prompts such as library-documentation, and does not rank the prefix match first.

## Best solution

Make prompt slash-command completions rank prefix matches first and stop segment-suffix aliases from matching a typed trailing '-'. The fix belongs in getPromptSlashCommandFilterText or the promptSlashCommands provider, with a regression test.
