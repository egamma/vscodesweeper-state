# Issue #324081 — Agent window SSH does not work well with keys

[https://github.com/microsoft/vscode/issues/324081](https://github.com/microsoft/vscode/issues/324081)

## Summary

The Windows SSH-agent authentication gap remains on current main: Agent Window only discovers an agent through `SSH_AUTH_SOCK`, so the standard Windows OpenSSH agent can be running with a loaded key while the connection falls through to password authentication.

## Change summary

Make Agent Window SSH use keys loaded in the standard Windows OpenSSH Authentication Agent instead of prompting for a password or failing authentication.

## Best solution

Recognize the standard Windows OpenSSH agent endpoint when no explicit `IdentityAgent` or `SSH_AUTH_SOCK` is configured, while preserving explicit `IdentityAgent`, Unix socket, key-file, and keyboard-interactive behavior.
