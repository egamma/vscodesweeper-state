# Issue #324081 — Agent window SSH does not work well with keys

[https://github.com/microsoft/vscode/issues/324081](https://github.com/microsoft/vscode/issues/324081)

## Summary

Keep open: independent reports confirm that Agents Window authentication fails or prompts for a password where OpenSSH and normal Remote-SSH authenticate successfully with keys. Current source supports several previously missing authentication paths, but does not establish that the Windows agent case is resolved; this team-authored issue has no verified issue-referencing fix.

## Change summary

Make Agents Window SSH use working public-key and SSH-agent identities without unnecessary password prompts or authentication failures.

## Best solution

Diagnose the Windows OpenSSH-agent discovery and identity-selection path in SSHRemoteAgentHostMainService, then make the confirmed key-authentication scenario succeed without a remote-account password. Keep host-certificate negotiation and GSSAPI support separate from this key-authentication defect.
