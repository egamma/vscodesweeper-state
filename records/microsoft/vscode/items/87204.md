# Issue #87204 — Add a command to add multicursors to all Highlight Occurences

[https://github.com/microsoft/vscode/issues/87204](https://github.com/microsoft/vscode/issues/87204)

## Summary

A real capability gap remains: current multicursor commands select textual matches, while semantic document highlights only support navigation. The request is already correctly routed and should remain open for a command and keybinding decision.

## Change summary

Add a command that creates multicursor selections from all semantic document highlights for the symbol at the cursor.

## Best solution

Add a distinct editor command in the word-highlighting contribution that converts the current document-highlight ranges into selections, preserving the existing textual multicursor commands and leaving keybinding assignment as a separate decision.
