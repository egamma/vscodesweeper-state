# Issue #336738 — Agents window: let us center the bottom panel instead of it always spanning full width

[https://github.com/microsoft/vscode/issues/336738](https://github.com/microsoft/vscode/issues/336738)

## Summary

Legitimate feature request: the Agents window layout hardcodes panel alignment to 'justify' with a no-op setPanelAlignment, confirmed on main, so users can't center the panel or use Toggle Maximized Panel — no canonical issue tracks this specific ask, so it stays open.

## Change summary

Allow the bottom panel in the Agents window to be center-aligned (leaving the right sidebar full height) instead of always spanning full width.

## Best solution

Extend the Agents window layout (src/vs/sessions/browser/workbench.ts) to support 'center' panel alignment alongside 'justify', wiring setPanelAlignment/getPanelAlignment to the grid the way the main workbench layout does, which would also unblock 'View: Toggle Maximized Panel'.
