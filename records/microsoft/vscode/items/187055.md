# Issue #187055 — Bad completion ranking changes valid variable name to class name when pressing "."

[https://github.com/microsoft/vscode/issues/187055](https://github.com/microsoft/vscode/issues/187055)

## Summary

Still reproduces on main: the fuzzyScore algorithm does not prefer exact-case matches over case-insensitive ones. A skipped failing test was added in Dec 2023 (cafbf86532b) confirming the defect, but no fix has landed.

## Change summary

Typing a lowercase variable name followed by '.' replaces it with the uppercase class name because fuzzyScore ranks case-insensitive matches equally.

## Best solution

Update the fuzzyScore function in src/vs/base/common/filters.ts to boost exact-case matches over case-insensitive ones (e.g. 'a' should rank above 'A' when the pattern is 'a'), then unskip the test in filters.test.ts.
