# Issue #235795 — Add Cell toolbar remains sticky in blank notebook

[https://github.com/microsoft/vscode/issues/235795](https://github.com/microsoft/vscode/issues/235795)

## Summary

Still reproduces on main: the top insert toolbar's `emptyNotebook` CSS class (which forces `opacity: 1`) is added when a blank notebook opens, but the `onDidChangeViewCells` listener that calls `updateClass()` to remove it is only registered inside `onDidChangeModel` — so when cells are added to the same model, `updateClass()` may never fire and the toolbar stays permanently visible.

## Change summary

The 'Add Cell' toolbar at the top of a blank notebook remains always-visible (sticky) even after cells are added, instead of reverting to hover-only.

## Best solution

In `notebookTopCellToolbar.ts`, register the `onDidChangeViewCells` listener immediately when the model is already present (not only inside `onDidChangeModel`), so `updateClass()` fires when cells are added to the initially-attached model. The CSS and class-toggle logic is correct — only the event wiring needs fixing.
