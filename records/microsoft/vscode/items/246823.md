- **Likely files:** `extensions/typescript-language-features/src/languageFeatures/hover.ts`, `extensions/typescript-language-features/src/tsServer/server.ts`
- **Validation:** Retest an affected project on current VS Code: hover local and imported values after project initialization, then invoke Go to Definition on an import while its target file is closed and again while it is open. Semantic types should become available, and navigation should reach the same definition in both cases. Capture TS Server events to distinguish continuing project loading from incorrect routing.
- **Behavior:**

  > The reported failure leaves variable hovers at '(loading...) any' indefinitely rather than providing semantic type information. Cross-file Go to Definition reportedly stops at the import unless the destination file is already open. After project initialization, hovers should provide the appropriate semantic information and navigation should not depend on opening the destination first. A temporary loading indicator during actual initialization remains valid.
- **Trace:**

  > TypeScriptHoverProvider in extensions/typescript-language-features/src/languageFeatures/hover.ts requests quickinfo and prefixes syntax-server results with '(loading...)' when semantic support is available. SyntaxRoutingTsServer in extensions/typescript-language-features/src/tsServer/server.ts routes quickinfo and definition requests to the syntax server during project loading, with semantic-server completion or diagnostic events clearing that state. This is a plausible shared path, not a conclusively traced defect: the missing evidence is whether the affected project fails to finish loading, omits an expected event, or continues receiving incorrectly routed requests. Independent confirmation was consolidated here from https://github.com/microsoft/vscode/issues/246486. Start by reproducing and inspecting TS Server events using the existing typescript.openTsServerLog command; logs may contain project content and paths. Preserve responsive syntax-only results during legitimate loading, and do not hide the prefix or substitute a type as a cosmetic resolution.
