## Summary

Still open and unfixed on main — the '(loading...) any' hover is produced when the syntax server responds but the semantic server never finishes loading. Issue #246486 was closed as a duplicate of this one, confirming it as the canonical tracker. No fix commit found.

## Change summary

TypeScript hover shows '(loading...) any' permanently when the semantic server fails to load or is too slow, with no mechanism to refresh the hover once semantic information becomes available.

## Best solution

Investigate why the semantic TS server never completes loading for affected projects (possibly a large/complex tsconfig or a stuck project load), and consider adding a hover-refresh mechanism so stale syntax-only hovers update once the semantic server is ready. The fix likely involves `extensions/typescript-language-features/src/languageFeatures/hover.ts` and the project-loading lifecycle in `typescriptServiceClient.ts`.
