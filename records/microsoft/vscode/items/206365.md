# Issue #206365 — Menubar disappears, wrong fullscreen detection

[https://github.com/microsoft/vscode/issues/206365](https://github.com/microsoft/vscode/issues/206365)

## Summary

Still reproduces on main: the `detectFullscreen()` heuristic in `src/vs/base/browser/dom.ts` incorrectly detects fullscreen when the browser window fills a secondary monitor without a taskbar, causing the menubar to hide under the `classic` visibility setting.

## Change summary

On vscode.dev with `menuBarVisibility: classic`, moving the window to a secondary screen without a taskbar causes the menubar to disappear because the fullscreen heuristic triggers falsely.

## Best solution

Improve the fullscreen detection heuristic in `detectFullscreen()` (`src/vs/base/browser/dom.ts`) — the `innerHeight === screen.height` check (line ~1778) is too aggressive for multi-monitor setups without taskbars. A more reliable approach might combine the Fullscreen API check with the `guess: true` path to avoid hiding UI based on a heuristic that the code itself acknowledges is unreliable.
