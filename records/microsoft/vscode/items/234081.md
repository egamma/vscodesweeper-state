# Issue #234081 — Updates not being installed automatically

[https://github.com/microsoft/vscode/issues/234081](https://github.com/microsoft/vscode/issues/234081)

## Summary

This is as-designed behavior on Linux: VS Code's Linux update service only notifies about available updates and opens the download page — it does not auto-install. Auto-updates on Linux are expected to come from the system package manager (apt/snap).

## Change summary

Reporter expects VS Code to automatically install updates on Linux, but the Linux update service only checks for updates and opens a download page.

## Best solution

Close as as-designed. On Linux, VS Code intentionally defers update installation to the system package manager. Users who installed via .deb/.rpm repos or snap receive auto-updates through those channels; tarball/ZIP users must update manually. Issue #56326 tracks the feature request for auto-update support in non-package-manager installs.

  > Thanks for the report. On Linux, VS Code intentionally does not auto-install updates itself — it checks for new versions and notifies you, but installation is expected to go through your system package manager. If you installed VS Code via the Microsoft apt/yum repository or via Snap, updates arrive automatically through those channels (e.g. `sudo apt update && sudo apt upgrade`). If you're using the tarball/ZIP download, manual updating is expected — https://github.com/microsoft/vscode/issues/56326 tracks the feature request to improve that experience.
