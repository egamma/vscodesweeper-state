# Issue #240869 — Terminal output wrapping breaks ProblemMatcher matching.

[https://github.com/microsoft/vscode/issues/240869](https://github.com/microsoft/vscode/issues/240869)

## Summary

The terminal-width-dependent truncation and missed diagnostics are already tracked by the open issue https://github.com/microsoft/vscode/issues/150285. Despite its $msCompile title, that discussion explicitly covers custom problem matchers and non-MSBuild tools, so it owns the reported scope.

## Change summary

Task problem matching should capture complete diagnostic lines independently of terminal width, visibility, and visual wrapping.

## Best solution

Consolidate the reports under https://github.com/microsoft/vscode/issues/150285 and resolve width-dependent diagnostic truncation for both built-in and custom matchers, retaining this report's minimal echo task and Windows 24H2 details.
