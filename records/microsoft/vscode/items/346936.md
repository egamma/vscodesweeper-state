# Issue #346936 — Inbox mode: Ready to Merge sessions have no inline Merge action

[https://github.com/microsoft/vscode/issues/346936](https://github.com/microsoft/vscode/issues/346936)

## Summary

The requested row-level Merge action remains missing. Existing inline actions address checks and comments, but do not expose merging directly from Ready to Merge session rows.

## Change summary

Expose Merge directly on eligible session rows in the Agents window’s Inbox Mode.

## Best solution

Make the session’s available pull-request merge operation directly accessible from its Ready to Merge row, preserving provider eligibility, confirmation, and operation-state handling rather than introducing different merge semantics.
