# Issue #187498 — Keyboard Shortcuts User Interface: Keybinding Can Be Overriden By An Invisible Object From keybindings.json

[https://github.com/microsoft/vscode/issues/187498](https://github.com/microsoft/vscode/issues/187498)

## Summary

Still present on main: the Keyboard Shortcuts UI does not surface that a removal entry (negative command like `-workbench.action.terminal.sendSequence`) in keybindings.json shadows a user-added positive entry, leaving users confused about why their keybinding doesn't work.

## Change summary

The Keyboard Shortcuts editor shows a keybinding as active even when a removal entry in keybindings.json negates it, giving no visual indication of the conflict.

## Best solution

The keybindings editor should detect when a positive user keybinding is negated by a removal entry (negative command prefix `-`) later in keybindings.json and display a visual indicator or warning, similar to how other conflicts are surfaced. Likely files: `src/vs/workbench/contrib/preferences/browser/keybindingsEditor.ts` and `src/vs/workbench/contrib/preferences/browser/keybindingsEditorModel.ts`.
