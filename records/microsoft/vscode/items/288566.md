# Issue #288566 — Allow agent to push a terminal into the background

[https://github.com/microsoft/vscode/issues/288566](https://github.com/microsoft/vscode/issues/288566)

## Summary

Still a valid open request. While idle-silence auto-promotion and background detach rewriting exist on current main, there is no explicit agent-initiated tool or action to push a running foreground terminal into background mode. The core ask — let the agent deliberately move a sync terminal to background when it realizes the command is long-running — remains unimplemented.

## Change summary

Allow the agent to explicitly push a running foreground terminal execution into background mode so it can continue other work without waiting.

## Best solution

Add a new terminal tool (or extend `run_in_terminal` / `send_to_terminal`) that lets the agent explicitly promote a running sync terminal to background, returning a terminal ID for later polling via `get_terminal_output`. The idle-silence heuristic covers some cases but is not a substitute for intentional agent control. Implementation likely touches `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/` and the tool ID registry.
