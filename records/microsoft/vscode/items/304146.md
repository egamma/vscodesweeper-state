## Summary

Valid feature request from a team member: the Chat Customization UI should always show the built-in GitHub MCP server with easy enable/disable and variant selection. The MCP list widget already discovers built-in servers but lacks the promoted UX described here. No fix commit references this issue.

## Change summary

The built-in GitHub MCP server should always appear in the Chat Customization editor with a checkbox to enable/disable and a way to choose variants (e.g. readonly).

## Best solution

Enhance `mcpListWidget.ts` in the aiCustomization area to always surface the GitHub MCP server entry (even when disabled), with a toggle checkbox and a variant selector (e.g. dropdown for readonly vs full). The team discussion suggests this may also involve simplifying the settings model so readonly is a variant rather than a separate setting.
