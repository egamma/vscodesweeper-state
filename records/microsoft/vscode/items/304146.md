# Issue #304146 — Chat customization: promote the built-in Github MCP server

[https://github.com/microsoft/vscode/issues/304146](https://github.com/microsoft/vscode/issues/304146)

## Summary

Keep open: current source supports listing registered GitHub MCP servers, but does not satisfy the request to advertise the server while disabled and offer convenient variant selection. The author corrected the original enablement misunderstanding, and a maintainer accepted the broader direction subject to a service-cost constraint.

## Change summary

Make the built-in GitHub MCP server discoverable in Chat Customizations before enabling it, with convenient enablement and variant controls.

## Best solution

Expose the built-in GitHub MCP server and its supported variants in Chat Customizations without automatically starting it or adding tools to requests merely to advertise it. Preserve the existing opt-in behavior until the maintainer's service-cost prerequisite for always-available behavior is resolved.
