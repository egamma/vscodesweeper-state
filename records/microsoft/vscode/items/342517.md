# Issue #342517 — Comparison view only allows one item to be expanded

[https://github.com/microsoft/vscode/issues/342517](https://github.com/microsoft/vscode/issues/342517)

## Summary

Keep open: current source still restricts the comparison scorecard to one expanded evaluation, and the maintainer confirms that this is intentional for space reasons. This team-authored request is protected from an as-designed close; the remaining question is how to support reading evaluations together without overcrowding the scorecard.

## Change summary

Allow simultaneous review of multiple evaluation details, potentially by opening them as Markdown files.

## Best solution

Resolve the product decision about a larger evaluation-review surface or Markdown access while preserving the compact scorecard where space is constrained. The current single-expansion behavior does not satisfy the requested simultaneous comparison.
