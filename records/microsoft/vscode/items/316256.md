# Issue #316256 — "Extensions have been modified on disk. Please reload the window."

[https://github.com/microsoft/vscode/issues/316256](https://github.com/microsoft/vscode/issues/316256)

## Summary

Keep open: multiple reporters captured the false reload notification with German, Japanese, and Chinese localization, and a maintainer accepted the localization-sensitive cache comparison as the investigation direction. Current main contains language-scoped cache handling, but there is no different, verified fix after the previously refuted fix claim.

## Change summary

Localized extension manifests can intermittently invalidate the extension scan cache and falsely report that extensions were modified on disk.

## Best solution

Make extension-cache creation and validation use a stable, equivalent localization state so unchanged built-in extensions cannot trigger cache invalidation, while preserving notifications for genuine on-disk modifications.
