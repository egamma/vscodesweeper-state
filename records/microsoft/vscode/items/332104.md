# Issue #332104 — Chat sessions disappear from history but remain in Chat Debug view; Export finds no data

[https://github.com/microsoft/vscode/issues/332104](https://github.com/microsoft/vscode/issues/332104)

## Summary

Verified duplicate: this is the same core `ChatSessionStore` bug already tracked in detail by https://github.com/microsoft/vscode/issues/321290, where a session's index entry gets incorrectly marked empty/hidden despite the underlying transcript/data still existing, breaking history visibility and the Export feature.

## Change summary

Long-running Copilot Chat agent sessions vanish from the Chat History/Sessions panel (some shown with malformed titles and 0 turns) even though the session data still exists on disk, and Export Copilot Chat cannot find it.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/321290, which already has forensic detail (the `chat.ChatSessionStore.index` entry is written with `isEmpty: true` even though the corresponding transcript/session content is non-empty) pointing at src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts; the fix should make the empty/hidden determination more robust (e.g. don't trust a stale `isEmpty` flag when other session artifacts prove otherwise) and give Export a fallback path.
