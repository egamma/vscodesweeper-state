# Issue #307565 — Session History List Disappears, Making Previous Sessions Inaccessible

[https://github.com/microsoft/vscode/issues/307565](https://github.com/microsoft/vscode/issues/307565)

## Summary

Confirmed bug: ChatSessionStore hardcodes a 50-session limit at line 37 of chatSessionStore.ts, trimming older sessions from the index even when the data files remain on disk. An open PR (https://github.com/microsoft/vscode/pull/310911) already targets this issue — keep open until that PR lands.

## Change summary

Chat session history is silently trimmed to 50 entries, making older sessions inaccessible in the UI despite their data files persisting on disk.

## Best solution

Land https://github.com/microsoft/vscode/pull/310911, which replaces the hardcoded `maxPersistedSessions = 50` in `src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts` with the user-configured retention limit, so users with more than 50 sessions retain access to all of them.
