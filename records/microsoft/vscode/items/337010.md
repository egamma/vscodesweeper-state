# Issue #337010 — Web UI doesn't show the same chats when start the tunnel via command line

[https://github.com/microsoft/vscode/issues/337010](https://github.com/microsoft/vscode/issues/337010)

## Summary

Team-authored bug, confirmed by a collaborator (amunger): the local app and the tunnel-connected web UI each maintain an independent set of agent sessions, so chats started/visible in one don't show in the other. Author is a MEMBER, so this stays open regardless of staleness pending an actual architectural fix.

## Change summary

When running `code-insiders agent --tunnel`, the sessions/chats visible in the web UI opened via the tunnel differ from those shown in the desktop app for the same host.

## Best solution

Unify session enumeration/storage so a tunnel-connected client and the local app agree on one canonical session list, likely in the agent host / sessions session-listing service (src/vs/sessions/services/sessions, src/vs/sessions/contrib/tunnelHost) rather than each host tracking sessions independently.
