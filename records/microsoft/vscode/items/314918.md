# Issue #314918 — Chat: Run command approval prompt truncates command

[https://github.com/microsoft/vscode/issues/314918](https://github.com/microsoft/vscode/issues/314918)

## Summary

Valid bug — the terminal command confirmation dialog clips long commands due to a CSS max-height constraint on the message container, preventing users from reviewing the full command before approving.

## Change summary

The run-command approval prompt truncates long terminal commands, making it impossible to review the full command before approving or denying execution.

## Best solution

Increase or remove the `max-height: min(200px, 30vh)` constraint on `.chat-confirmation-widget-message` inside the tool carousel (chatToolConfirmationCarousel.css line 234), or make the container scrollable so the full command is accessible. The editor already has `wordWrap: 'on'`, so the fix is purely about allowing the container to show more lines. The expanded state (`min(500px, 55vh)`) may also need adjustment for very long commands, or the user should be able to scroll within the confirmation area.
