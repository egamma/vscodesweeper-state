# Issue #339471 — Allow configuring the default search mode of the Command Center

[https://github.com/microsoft/vscode/issues/339471](https://github.com/microsoft/vscode/issues/339471)

## Summary

Keep open as a feature request: the Command Center does not expose a configurable initial search mode, and existing shortcuts or input-preservation settings do not deliver the requested mouse-first workflow. No verified open duplicate or maintainer decision supports closing it.

## Change summary

Allow clicking the Command Center to open a configured search mode, such as Workspace Symbols, without typing its prefix each time.

## Best solution

Have the Command Center and Quick Access owners assess an opt-in initial-mode preference that preserves the existing default and keyboard-command behavior. Keep the request available for community feedback before committing to an additional setting.

## Evidence

- **Current click path:** src/vs/workbench/browser/parts/titlebar/commandCenterControl.ts binds the central search target to workbench.action.quickOpenWithModes. In src/vs/workbench/browser/actions/quickAccessActions.ts, its classic path calls quickAccess.show(undefined, { preserveValue: true, providerOptions }); it reads no initial search-mode preference.
- **Existing setting does not cover the request:** src/vs/workbench/browser/workbench.contribution.ts registers workbench.quickOpen.preserveInput to restore previously typed input, not choose a default provider. src/vs/platform/quickinput/browser/quickAccess.ts selects the provider from the supplied value before applying default-filter restoration, and skips that restoration when preserveValue is true. This does not configure Command Center clicks to start in Workspace Symbols.
- **Alternative entry points:** workbench.action.quickOpen accepts an explicit prefix, but the Command Center invokes the distinct workbench.action.quickOpenWithModes action without a configurable prefix. The experimental unified path in src/vs/workbench/contrib/chat/browser/agentSessions/experiments/unifiedQuickAccess.ts defines sessions, commands, and files tabs, rather than a configurable Workspace Symbols initial mode.
- **Related request is not a canonical:** https://github.com/microsoft/vscode/issues/214324 requested globally swapping file and command search defaults and prefixes; it was closed through the feature-request upvote process, not a maintainer rejection of an opt-in symbol-mode preference.
