# Issue #312512 — Support opening file with path enclosed in "" on Windows

[https://github.com/microsoft/vscode/issues/312512](https://github.com/microsoft/vscode/issues/312512)

## Summary

Keep open: Quick Open still passes enclosing quotes into absolute-path detection, so its existing quote-aware search normalization does not fully cover pasted Windows clipboard paths. No verified canonical or existing setting was found that delivers this request.

## Change summary

Allow Ctrl+P to open an absolute Windows file path pasted with enclosing double quotes.

## Best solution

Quick Open should recognize a double-quoted absolute Windows path as the same file as its unquoted form, while preserving existing quoted-search semantics for ordinary queries.
