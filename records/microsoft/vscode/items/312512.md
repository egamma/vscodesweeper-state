# Issue #312512 — Support opening file with path enclosed in "" on Windows

[https://github.com/microsoft/vscode/issues/312512](https://github.com/microsoft/vscode/issues/312512)

## Summary

Valid feature request: Quick Open (Ctrl+P) does not strip enclosing double quotes from pasted Windows paths. No existing implementation or duplicate found on main.

## Change summary

When pasting a Windows path copied via right-click → 'Copy as path' into Quick Open, the enclosing double quotes prevent the file from being found.

## Best solution

Strip leading and trailing double quotes from the filter input in AnythingQuickAccessProvider (src/vs/workbench/contrib/search/browser/anythingQuickAccess.ts) before resolving the path, so that pasting a quoted absolute path works the same as an unquoted one.
