# Issue #317117 — ChatInput: element outline highlighting is inconsistent (input and Credit Limit Reached have outlines, todos don't)

[https://github.com/microsoft/vscode/issues/317117](https://github.com/microsoft/vscode/issues/317117)

## Summary

Keep open: the designer settled the direction—highlight only the chat input—but current CSS still propagates the input's focus border onto the informational notification banner. Later notice and stack restructuring does not eliminate this remaining polish task.

## Change summary

Keep the Credit Limit Reached banner visually secondary instead of highlighting its border when the chat input is focused.

## Best solution

Honor the designer's input-only highlighting direction in the chat notification styling, without extending the highlight over todos or the whole stack. Preserve keyboard-focus indicators on the banner and its controls, plus warning/error severity styling.
