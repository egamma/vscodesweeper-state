# Issue #273815 — Allow prompts to run in without any instruction files

[https://github.com/microsoft/vscode/issues/273815](https://github.com/microsoft/vscode/issues/273815)

## Summary

Keep open: this team-authored Backlog feature request identifies a concrete customization gap—prompt files can select an agent but cannot opt out of workspace instruction files. No discussion, implementation evidence, or verified older canonical settles the request.

## Change summary

Add prompt-file front matter that runs a prompt without loading repository or workspace instruction files.

## Best solution

Define an explicit prompt-file isolation contract in the chat customizations model, then ensure prompt execution suppresses workspace instruction discovery while preserving the prompt's own body, references, selected agent, and required safety or product-level instructions.
