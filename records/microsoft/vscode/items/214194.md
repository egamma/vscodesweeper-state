# Issue #214194 — editor.find.autoFindInSelection does not treat block selection as multiline

[https://github.com/microsoft/vscode/issues/214194](https://github.com/microsoft/vscode/issues/214194)

## Summary

A real behavior gap remains on current main, but equivalent column-selection behavior has historically been treated as a feature request. It is already routed to editor find and appropriately remains under discussion.

## Change summary

Treat a rectangular selection spanning multiple lines as multiline for editor.find.autoFindInSelection.

## Best solution

Update the multiline checks in the editor find controller and widget to consider all selections produced by column selection, with tests covering rectangular selections, while preserving existing single-selection behavior.
