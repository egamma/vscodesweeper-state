# Issue #213469 — Revert and Stage block buttons are very close together

[https://github.com/microsoft/vscode/issues/213469](https://github.com/microsoft/vscode/issues/213469)

## Summary

The older, open issue https://github.com/microsoft/vscode/issues/211390 tracks the same diff-gutter button proximity and accidental reverts without confirmation. Consolidate this report there, retaining the discussion about avoiding intrusive confirmation dialogs.

## Change summary

Make the diff editor's adjacent Stage Block and Revert Block actions harder to confuse or misclick.

## Best solution

Consolidate the design discussion in https://github.com/microsoft/vscode/issues/211390 and distinguish destructive revert actions from staging without unnecessarily interrupting repeated edits.
