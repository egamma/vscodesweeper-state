# Issue #334064 — Show a direct link when there is only one reference

[https://github.com/microsoft/vscode/issues/334064](https://github.com/microsoft/vscode/issues/334064)

## Summary

The single-reference shortcut remains missing in current source. The linked implementation PR was closed without merging, so it does not establish completion; keep this request open.

## Change summary

Display a response's sole reference as a direct metadata link, retaining the dropdown for multiple references.

## Best solution

Provide a directly actionable metadata link when a response contains one reference, while preserving the existing collapsible list for multiple references. Decide whether the shortcut covers all reference types or only GitHub issues and pull requests, as the closed proposal did.
