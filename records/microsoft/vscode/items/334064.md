# Issue #334064 — Show a direct link when there is only one reference

[https://github.com/microsoft/vscode/issues/334064](https://github.com/microsoft/vscode/issues/334064)

## Summary

The requested chat-response polish remains missing on current main: a single reference is still rendered as an expandable “Used 1 reference” row. Route it to the chat response area; the behavior is clearly specified and the implementation boundary is small.

## Change summary

Render a lone GitHub issue or pull-request reference as a direct metadata link while retaining the collapsible list for multiple references.

## Best solution

Show a keyboard-accessible, accurately labeled direct link for a single GitHub issue or pull request, while preserving the existing disclosure list and interaction model for multiple or non-GitHub references.
