# Issue #335188 — Allow worktree code isolation for sessions started in the Chat view

[https://github.com/microsoft/vscode/issues/335188](https://github.com/microsoft/vscode/issues/335188)

## Summary

Well-documented feature request asking to bring the Agents-window worktree/code-isolation picker to Chat-view sessions; the docs explicitly confirm the current gap, and the checkout shows the underlying session-config properties (Isolation, Branch, WorktreeBranchPrefix, etc.) exist but are deliberately hidden from the chat-input chip lane, consistent with the reporter's claim that Chat view has no UI to opt into isolation.

## Change summary

Expose the same New Worktree + base branch isolation choice available in the Agents window to sessions started from the Chat view.

## Best solution

Surface a Chat-view entry point (chip/picker) for the existing Isolation/Branch/Worktree* session-config properties that agentHostChatInputPicker.ts already tracks but currently suppresses from the chat input chip lane, so Chat-view sessions can opt into worktree isolation at parity with the Agents window.
