# Issue #335188 — Allow worktree code isolation for sessions started in the Chat view

[https://github.com/microsoft/vscode/issues/335188](https://github.com/microsoft/vscode/issues/335188)

## Summary

Legitimate, well-scoped gap: worktree/code-isolation is intentionally gated to the Agents window today, and the Chat view always uses the current workspace — this is a real feature request, not a duplicate of the already-shipped Agents-window worktree work.

## Change summary

Expose the New Worktree + base branch code-isolation option for sessions started in the Chat view, at parity with the Agents window.

## Best solution

Extend the code-isolation picker (currently Agents-window-only per src/vs/workbench/contrib/chat/browser/actions/chatExecuteActions.ts and the agentSessions worktree flow) to also surface in the Chat view's session start UI; belongs with the chat/agent-sessions area owners to scope the review/integrate flow parity.
