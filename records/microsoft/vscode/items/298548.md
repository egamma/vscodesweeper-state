# Issue #298548 — "Split Editor Down" icon not shown when Browser focus steals Option key press

[https://github.com/microsoft/vscode/issues/298548](https://github.com/microsoft/vscode/issues/298548)

## Summary

Still present on main: the Integrated Browser's WebContentsView captures modifier key events (Option/Alt) and does not forward them to the VS Code renderer, so the split editor toolbar icon never toggles to the 'Split Down' variant while the browser has focus. No fix has been committed. Team-authored — keeping open.

## Change summary

The split editor icon does not toggle to the horizontal (Split Down) variant when pressing Option while the Integrated Browser has focus.

## Best solution

Forward modifier key events (keydown/keyup for Alt/Option) from the WebContentsView back to the VS Code renderer process so that modifier-dependent UI (like the split editor icon toggle) works regardless of which view has focus. The fix likely involves the Electron main-process browser view code (`src/vs/platform/browserView/electron-main/browserView.ts`) or the preload script (`src/vs/platform/browserView/electron-browser/preload-browserView.ts`) forwarding modifier state via IPC.
