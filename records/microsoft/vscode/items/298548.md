# Issue #298548 — "Split Editor Down" icon not shown when Browser focus steals Option key press

[https://github.com/microsoft/vscode/issues/298548](https://github.com/microsoft/vscode/issues/298548)

## Summary

Keep open: the current browser keyboard bridge still excludes standalone Option/Alt presses, leaving the editor toolbar's alternate-action state unchanged while the page has focus. The issue already has the correct area label, and no verified fix or older same-symptom canonical was found.

## Change summary

Make the Split Editor icon reflect the held Option/Alt modifier when an integrated browser page has focus.

## Best solution

Keep workbench modifier-dependent toolbar state synchronized with native browser focus, including key release and focus transitions, without changing which shortcuts or editing keys the page handles.
