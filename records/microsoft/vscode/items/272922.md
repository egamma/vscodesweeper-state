- **Reporter supplied actionable reproduction:** https://github.com/microsoft/vscode/issues/272922 describes typing `<` inside `$ ... $` or `$$ ... $$` and receiving an unwanted `>`; the reporter confirmed persistence after upgrading from 1.105.0 to 1.105.1.
- **Current auto-closing path:** extensions/markdown-basics/language-configuration.json declares the `<`/`>` auto-closing pair with only a string exclusion. src/vs/editor/common/cursorCommon.ts:157 obtains auto-closing pairs from the document language. In src/vs/editor/common/cursor/cursorTypeEditOperations.ts, _findAutoClosingPairOpen selects from those outer-language pairs; getAutoClosingPair checks scoped token types but does not replace the pair configuration with the embedded language's configuration.
- **Math scopes do not exclude the pair:** extensions/markdown-math/package.json maps meta.embedded.math.markdown to latex without a string token-type override. The inline and block grammars use that embedded scope, so ordinary mathematical content does not satisfy Markdown's string exclusion. The inline single- and double-dollar match rules also require closing delimiters before recognizing those complete inline expressions.
