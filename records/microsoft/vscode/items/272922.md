# Issue #272922 — [Markdown] Do not auto close angle brackets inside latex blocks

[https://github.com/microsoft/vscode/issues/272922](https://github.com/microsoft/vscode/issues/272922)

## Summary

Still reproduces on main: typing `<` inside markdown math blocks (`$...$`/`$$...$$`) auto-closes to `<>` because the embedded math scopes aren't classified as a `string` standard token type, so the `notIn: ["string"]` guard in the markdown language configuration never kicks in. Two open PRs (#325464, #309365) already target this exact issue, so it stays open rather than being fixed or closed.

## Change summary

Markdown's angle-bracket auto-closing pair should not trigger inside LaTeX math blocks (`$...$`/`$$...$$`), since `<` there usually means "less than", not an HTML tag opener.

## Best solution

Land one of the two open PRs: #325464 (tag `meta.embedded.math.markdown` with the `string` token type in markdown-math's grammar contribution) or the more general #309365 (make auto-closing respect the embedded language's own `autoClosingPairs`, which also fixes the broader issue https://github.com/microsoft/vscode/issues/133397). Either closes this cleanly; no further diagnosis needed.

## Evidence
