# Issue #330446 — [Agents window] /clear command no longer closes session and opens a new one

[https://github.com/microsoft/vscode/issues/330446](https://github.com/microsoft/vscode/issues/330446)

## Summary

Confirmed regression on current main: `/clear` in the Agents window archives nothing and opens no new session, because the shared `/clear` handler in chatSlashCommands.ts is written against classic-workbench APIs that don't reach the sessions window's own session model. An open PR (#330453) already targets a fix, so this stays open and unlabeled rather than closed.

## Change summary

In the Agents window, typing `/clear` no longer archives the current session or opens a new one, though it still works in the sidebar Chat view.

## Best solution

Land https://github.com/microsoft/vscode/pull/330453 (or an equivalent fix), which splits `/clear` into a classic-workbench registration and a new sessions-window-specific registration (src/vs/sessions/contrib/chat/browser/clearSlashCommand.contribution.ts) that uses ISessionsManagementService.archiveSession() and ISessionsService.openNewSession() instead of the workbench-only agentSessionsService/ACTION_ID_NEW_CHAT path.
