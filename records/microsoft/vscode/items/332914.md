# Issue #332914 — Modern UI: vertically align status bar items

[https://github.com/microsoft/vscode/issues/332914](https://github.com/microsoft/vscode/issues/332914)

## Summary

Fresh, screenshot-confirmed visual bug in the still-experimental Modern UI status bar: the git-branch pill renders taller than neighboring status bar item pills, and the Modern UI-specific status bar CSS has no rule normalizing item/pill height. Already labeled `modernization` and just picked up an assignee via the engineering bot, so this is on the normal in-progress triage path.

## Change summary

Under the Modern UI experiment, status bar items are not vertically aligned/equal-height — one pill (e.g. the git branch item) renders taller than its neighbors.

## Best solution

Add a height-normalizing rule (or align the label height override) in src/vs/workbench/contrib/modernUI/browser/media/statusBar.css so every `.statusbar-item`/`.statusbar-item-label` pill in the Modern UI status bar renders at the same height regardless of icon/content composition.

## Evidence

- **Modern UI status bar CSS:** src/vs/workbench/contrib/modernUI/browser/media/statusBar.css only adds border-radius/margin/padding rules for pills (compact-left/right, end items); it has no rule equalizing item or label height across items with different icon/content shapes.
- **base status bar CSS:** src/vs/workbench/browser/parts/statusbar/media/statusbarpart.css sets `align-items: center` and `height: 100%` on `.statusbar-item-label`, but that alone doesn't guarantee equal outer pill height once Modern UI adds its own borders/padding per item.
- **experimental gating:** The feature is behind `LayoutSettings.MODERN_UI` per src/vs/workbench/services/layout/browser/layoutService.ts — an opt-in experiment, not the default experience.
