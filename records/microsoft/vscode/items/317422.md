# Issue #317422 — Can't Re-Open Different Projects Easily in VS Code

[https://github.com/microsoft/vscode/issues/317422](https://github.com/microsoft/vscode/issues/317422)

## Summary

The missing capability is persistent access to selected projects rather than an undifferentiated recent-history list. The older, open request for pinning projects in Open Recent covers that gap; reopening a workspace with its previous tabs is already supported.

## Change summary

Provide an in-app list of selected projects that can be reopened with their previous editor tabs.

## Best solution

Consolidate the project-selection requirement into https://github.com/microsoft/vscode/issues/163509, retaining this reporter's Ubuntu workflow and launcher-alias workaround. Pinned folders and workspaces can use the existing workspace-specific editor restoration rather than introducing a separate project-session system.
