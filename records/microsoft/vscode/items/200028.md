# Issue #200028 — Diagnostic Invalid Position

[https://github.com/microsoft/vscode/issues/200028](https://github.com/microsoft/vscode/issues/200028)

## Summary

Team-authored bug describing a race condition where TypeScript reports diagnostics computed against a stale model version, causing squiggles to appear on wrong lines after edits. No fix commit references this issue and the underlying problem (no version-id check in the diagnostic push path) appears to persist on main.

## Change summary

Diagnostics jump to incorrect positions when lines are inserted because TypeScript reports diagnostics computed against an older model version.

## Best solution

The TypeScript extension should either attach the model version used during computation to reported diagnostics (so the receiver can discard stale ones), or check whether the document changed during async diagnostic computation and skip reporting if it did. The fix likely lives in `extensions/typescript-language-features/src/` in the diagnostic reporting path, or on the receiving side in `src/vs/workbench/api/common/extHostDiagnostics.ts` by adding version validation.
