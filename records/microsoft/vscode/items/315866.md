## Summary

The test report identifies an activation-time CMake Tools prompt in an Agents Window worktree session. CMake Tools is not a VS Code-team-owned extension, so the issue should remain open here only long enough for the responsible area to route it; it must not be closed as a core defect or transferred under the owned-extension rule.

## Change summary

## Best solution
