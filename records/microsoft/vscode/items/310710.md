# Issue #310710 — Integrated browser "edit mode": use inline text edits as a signal for Copilot edits

[https://github.com/microsoft/vscode/issues/310710](https://github.com/microsoft/vscode/issues/310710)

## Summary

Valid, community-promoted feature request (22 upvotes) for an integrated-browser inline text-edit mode that feeds Copilot edits. No implementation exists on main; the related WYSIWYG issue #282975 was closed as not-planned, but this proposal is deliberately lighter-weight (Copilot-as-bridge, not deterministic DOM-to-source mapping). Stays open in Backlog.

## Change summary

Add an edit mode in the integrated browser where text in DOM elements becomes temporarily editable, and text diffs are used as signals for Copilot to propose source-file edits.

## Best solution

Design and implement a contenteditable overlay mode in the integrated browser (src/vs/workbench/contrib/browserView) that captures text diffs and feeds them as context to the Copilot agent for proposing source edits. The feature should be scoped to text content initially, with the browser as the interaction surface and Copilot generating normal code edits for review.
