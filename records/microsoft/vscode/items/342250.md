# Issue #342250 — Feature Request: Make human-supervised agent workflows a first-class option

[https://github.com/microsoft/vscode/issues/342250](https://github.com/microsoft/vscode/issues/342250)

## Summary

Keep open as a feature request: existing permission selectors and terminal controls cover parts of the proposal, but do not establish the complete supervised workflow requested. The explicit security-model concerns also warrant human review rather than an automated close.

## Change summary

Provide an easily selectable supervised agent workflow combining observable execution, single-action approval defaults, and file-change review before local application.

## Best solution

Have the chat owners evaluate a coherent supervised configuration using the existing permission and terminal surfaces, with an explicit decision about preview-before-application semantics for file changes. Preserve autonomous workflows without treating current configurable approvals as equivalent to the requested supervision guarantees.
