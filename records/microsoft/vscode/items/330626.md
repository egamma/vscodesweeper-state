# Issue #330626 — Simple file dialog: clicking a child of / updates the path but does not refresh the folder contents (regression in 1.133.0)

## Summary

Clear regression in the simple file dialog's root-navigation logic, and a fix is already up as an open PR referencing this issue — keep open until it merges rather than closing now.

## Change summary

In the simple (remote/WSL) file dialog, clicking a child folder while at `/` updates the path text but doesn't refresh the listing, so browsing away from root is stuck.
