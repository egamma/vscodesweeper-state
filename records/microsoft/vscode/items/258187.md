# Issue #258187 — Open file descriptors are leaked in the integrated terminal

[https://github.com/microsoft/vscode/issues/258187](https://github.com/microsoft/vscode/issues/258187)

## Summary

Keep this public tracker open as the maintainer requested: descriptor inheritance is attributed to node-pty, and the verified macOS fix does not establish resolution of the Linux checkpointing failure. The report also raises a potential security concern, which requires human review rather than a cleanup close.

## Change summary

Prevent unintended file descriptors from reaching integrated-terminal child processes and interfering with CRIU checkpointing.

## Best solution

Establish that node-pty prevents unintended descriptor inheritance on the Linux terminal-spawn path and that CRIU can checkpoint affected processes. Separately distinguish the reported remote-server descriptor growth and container socket-scanning buildup from the original inheritance defect.
