# Issue #330381 — Integrated browser: Closing a page after resuming deferred Playwright code logs unhandled rejections

[https://github.com/microsoft/vscode/issues/330381](https://github.com/microsoft/vscode/issues/330381)

## Summary

Well-diagnosed bug with an open fixing PR (#330382) that references this issue directly ('Fixes #330381'); per policy an open linked PR keeps the issue open until it merges, rather than closing it as implemented.

## Change summary

Closing an integrated-browser page while a resumed run_playwright_code deferred call is still pending causes the shared process to log an unhandled promise rejection for each stored resume promise.

## Best solution

Land or iterate on PR https://github.com/microsoft/vscode/pull/330382, which marks each deferred promise handled immediately while preserving its rejected state for the next waitForDeferredResult observer; close this issue once that PR merges.
