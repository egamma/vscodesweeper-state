# Issue #300696 — Feature Request: Expose Current Integrated Browser URL to Extensions

[https://github.com/microsoft/vscode/issues/300696](https://github.com/microsoft/vscode/issues/300696)

## Summary

The requested API already exists as a proposed extension API (`vscode.proposed.browser.d.ts`). The `BrowserTab` interface exposes `url`, `title`, and `icon`; `onDidChangeBrowserTabState` fires when URL/title/icon changes; `activeBrowserTab` and `browserTabs` give full tab access. This covers all the scenarios described — the remaining step is for the API to be finalized (stabilized), which is tracked by the related issue.

## Change summary

Expose the current URL of Integrated Browser tabs to extensions via a stable API.

## Best solution

The proposed API in `src/vscode-dts/vscode.proposed.browser.d.ts` already delivers every capability requested here (current URL, URL change events, active tab, tab enumeration). The remaining work is API finalization, which is tracked by https://github.com/microsoft/vscode/issues/300319. This issue can be closed as the capability is implemented; the reporter should enable the `browser` proposed API to use it today and follow the canonical issue for stabilization.
