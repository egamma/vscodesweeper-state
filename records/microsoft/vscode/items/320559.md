# Issue #320559 — Key combination ALT + NUM 009 does not work - follow up

[https://github.com/microsoft/vscode/issues/320559](https://github.com/microsoft/vscode/issues/320559)

## Summary

The reporter has responded to the info-needed request, confirming ALT+NUM 009 does not insert a tab on the latest Insiders build. This is a real editor input regression (worked in 1.100.2) that should be routed to the editor-input area for investigation.

## Change summary

Windows Alt+Numpad 009 no longer inserts a tab character in the editor, which worked in VS Code 1.100.2.

## Best solution

Investigate the editor's textarea input layer (src/vs/editor/browser/controller/editContext/textArea/) to understand why Windows Alt+Numpad character entry for control characters like tab (ASCII 9) no longer reaches the editor. The Tab key's keybinding interception may be preventing the Alt+Numpad input method from generating the corresponding character. The old issue https://github.com/microsoft/vscode/issues/263965 had the same report but was auto-closed without resolution.
