# Issue #148698 — Allow to restore all fullscreen windows

[https://github.com/microsoft/vscode/issues/148698](https://github.com/microsoft/vscode/issues/148698)

## Summary

Keep open as an Electron-owned limitation. Current VS Code source deliberately preserves the one-native-fullscreen-window-per-display restriction while the confirmed upstream issue remains open.

## Change summary

Restore every previously fullscreen VS Code window as fullscreen after restarting.

## Best solution

Electron should support opening multiple native fullscreen windows on one macOS display in https://github.com/electron/electron/issues/34367; VS Code can then remove its defensive state-normalization workaround in `src/vs/platform/windows/electron-main/windowsStateHandler.ts`.
