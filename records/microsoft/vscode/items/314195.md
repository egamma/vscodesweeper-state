# Issue #314195 — Make fishtank activation button stop wiggling after I've clicked on it

[https://github.com/microsoft/vscode/issues/314195](https://github.com/microsoft/vscode/issues/314195)

## Summary

The requested polish remains necessary on current main: every inactive aquarium button wiggles indefinitely, including after the user has activated it. The behavior is source-confirmed, bounded to the Sessions aquarium contribution, and ready for implementation.

## Change summary

Stop the Agents aquarium activation button's attention animation permanently after the user first clicks it.

## Best solution

Retain the discovery animation for users who have never activated the aquarium, then persist that the action has been acknowledged and keep the inactive button still on subsequent toggles and reloads.
