# Issue #292095 — Permission to read prompt file already attached?

[https://github.com/microsoft/vscode/issues/292095](https://github.com/microsoft/vscode/issues/292095)

## Summary

The defect remains actionable: a subagent does not inherit the parent turn's attached-resource authorization, so reading the same prompt file is treated as a new sensitive-file access. Maintainer comments confirm both the behavior and an unresolved product decision about authorization inheritance versus prompting.

## Change summary

Allow a subagent to read a prompt file already attached to its parent conversation without being blocked as an unauthorized sensitive-file access.

## Best solution

Define the authorization boundary for delegated agents, then make subagent file access either inherit permission for resources explicitly attached to the parent turn or request a user-approved exception when access falls outside that boundary.
