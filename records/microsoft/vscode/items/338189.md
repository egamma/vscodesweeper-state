# Issue #338189 — Agents: multiline approval row grows to thousands of pixels during sticky scrolling

[https://github.com/microsoft/vscode/issues/338189](https://github.com/microsoft/vscode/issues/338189)

## Summary

Confirmed on current main via source: `.session-approval-row` in sessionsList.css has no explicit line-height, so StickyScrollWidget.probeDynamicHeights's placeholder-block measurement feeds back into row height as the reporter traced. This is a fresh, precisely diagnosed team-authored bug report; keep open for the fix to land.

## Change summary

A sticky session row with a multiline pending approval balloons to thousands of pixels because StickyScrollWidget's dynamic-height probing measures placeholder blocks that inherit the full row line-height, creating a feedback loop.

## Best solution

Apply the reporter's verified fix: set an explicit `line-height: 18px` (or equivalent) on `.session-approval-row` in src/vs/sessions/contrib/sessions/browser/media/sessionsList.css so the placeholder blocks used during dynamic-height probing don't inherit the inflated row line-height, breaking the StickyScrollWidget feedback loop.
