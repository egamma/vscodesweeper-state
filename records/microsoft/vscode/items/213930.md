# Issue #213930 — Git - revert hunks of old commits (not only for staged changes)

[https://github.com/microsoft/vscode/issues/213930](https://github.com/microsoft/vscode/issues/213930)

## Summary

Historical-commit hunk reversion remains a distinct capability gap: the existing Git revert commands operate on working-tree changes, not arbitrary committed changes. Keep this accepted Backlog request open; no verified older canonical covers the same behavior.

## Change summary

Allow selected hunks, files, or folders from an old Git commit to be restored to their pre-commit contents in the working tree without creating a commit.

## Best solution

Provide a historical-diff action that applies selected pre-commit content to working-tree files without changing Git history. Define how it handles intervening edits and conflicts before extending the existing working-tree revert behavior.
