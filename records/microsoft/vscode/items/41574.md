# Issue #41574 — Can we get a few more pixels for clicking the cursor at the beginning of a line?

[https://github.com/microsoft/vscode/issues/41574](https://github.com/microsoft/vscode/issues/41574)

## Summary

Verified duplicate: the well-supported open canonical issue covers adding clickable space before the first character, including preventing accidental folding clicks. Consolidating there preserves this report's useful evidence about the misleading I-beam boundary.

## Change summary

Increase the clickable text-side area before column one so placing the caret or starting a selection does not accidentally target the folding gutter.

## Best solution

Resolve https://github.com/microsoft/vscode/issues/135114 by providing a small clickable content-side padding that maps clicks to column one while leaving folding and other gutter targets distinct.
