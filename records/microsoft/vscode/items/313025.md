# Issue #313025 — `openManagementEditor` doesn't respect `workbench.editor.useModal: "off"`

[https://github.com/microsoft/vscode/issues/313025](https://github.com/microsoft/vscode/issues/313025)

## Summary

The reported setting bypass was fixed by the merged modal-editor preference change. Tracing the command on current main shows that opening Customizations now honors workbench.editor.useModal: "off".

## Change summary

Opening Customizations should respect the explicit opt-out from modal editors instead of requiring users to move the editor manually.

## Best solution

Close as completed by commit ea8e43b23fd8812b123f139de25209f8705945ad, retaining modal presentation when enabled and ordinary editor-group presentation when the setting is off.
