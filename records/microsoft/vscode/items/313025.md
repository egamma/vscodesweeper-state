# Issue #313025 — `openManagementEditor` doesn't respect `workbench.editor.useModal: "off"`

[https://github.com/microsoft/vscode/issues/313025](https://github.com/microsoft/vscode/issues/313025)

## Summary

Fixed on main and shipped in 1.124.0: the `RequiresModal` capability now respects `workbench.editor.useModal: 'off'`, so the AI Customizations editor opens as a normal tab when the user has disabled modals.

## Change summary

The `openManagementEditor` command opens the AI Customizations editor in a modal overlay even when `workbench.editor.useModal` is set to `'off'`.

## Best solution

Keep the shipped fix in commit ea8e43b23fd (1.124.0); no further change needed. The `RequiresModal` capability now checks the `useModal` setting and defers to the user's `'off'` preference.
