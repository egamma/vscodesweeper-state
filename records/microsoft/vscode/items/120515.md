# Issue #120515 — Can open VS Code while it's being updated

[https://github.com/microsoft/vscode/issues/120515](https://github.com/microsoft/vscode/issues/120515)

## Summary

The update infrastructure has been substantially reworked since 2021 (cross-app coordination, mutex detection, `/nocloseapplications` flag), which likely mitigates this scenario, but no commit directly references this issue and no one has confirmed the fix. Keeping open due to team authorship rules not applying (NONE association) but insufficient evidence for a definitive close.

## Change summary

Reopening VS Code immediately after closing it while a background update is in progress causes the update to forcibly close the newly opened window.

## Best solution

Verify whether the current update infrastructure (especially the `/nocloseapplications` Inno flag and the session-ending flag mechanism in `updateService.win32.ts`) still allows this race condition on modern Windows builds. If the issue persists, the update service should detect an active VS Code instance before applying the update and defer until the user explicitly triggers restart-to-update.
