# Issue #120515 — Can open VS Code while it's being updated

[https://github.com/microsoft/vscode/issues/120515](https://github.com/microsoft/vscode/issues/120515)

## Summary

The reported reopen-during-update sequence is now guarded before the workbench starts: Windows setup installations wait for the active background update or refuse startup. Propose closing as implemented, based on the landed startup guard and its current source path.

## Change summary

Prevent an immediately reopened Windows VS Code window from becoming usable and then being forcibly closed by a pending background update.

## Best solution

Retain the pre-workbench update guard introduced in 4c5bfb172a2d7fe6efe1d1010219f2141bd7f7ab and subsequently refined to wait for setup completion; the reported interruption no longer requires separate implementation.
