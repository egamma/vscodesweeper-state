# Issue #130287 — Controlling vertical space between output elements.

[https://github.com/microsoft/vscode/issues/130287](https://github.com/microsoft/vscode/issues/130287)

## Summary

The request for user-configurable vertical spacing between output elements within a notebook cell remains unaddressed on current main — no setting or API exposes this. Existing options (compactView, outputLineHeight) do not control inter-output-element gaps.

## Change summary

Allow users to control or reduce vertical whitespace between multiple output elements rendered within a single notebook cell.

## Best solution

Expose a `notebook.output.elementSpacing` (or similar) setting that controls the margin/padding between sibling output elements inside a cell's output container. The layout constants live in `src/vs/workbench/contrib/notebook/browser/notebookOptions.ts` (hardcoded `cellOutputPadding: 8`), and the rendered structure is in `view/cellParts/cellOutput.ts`. Alternatively, the webview-side CSS for `.output-element` could respect a configurable gap.
