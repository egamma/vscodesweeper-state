# Issue #130287 — Controlling vertical space between output elements.

[https://github.com/microsoft/vscode/issues/130287](https://github.com/microsoft/vscode/issues/130287)

## Summary

Keep open: current notebook settings do not expose control over spacing between separate HTML outputs. The newer tight-layout discussion overlaps, but cannot replace this older, re-reviewed request.

## Change summary

Allow reducing or collapsing vertical space between notebook output elements produced by separate display(HTML(...)) calls.

## Best solution

Provide a consistent compact presentation for consecutive notebook outputs, with host layout measurements matching the rendered spacing. Decide whether this belongs in compact mode or a dedicated output-spacing control, coordinating with the related tight-layout discussion.
