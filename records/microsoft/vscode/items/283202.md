# Issue #283202 — enhancement: enable extensions (spell checker) access in copilot prompt window

[https://github.com/microsoft/vscode/issues/283202](https://github.com/microsoft/vscode/issues/283202)

## Summary

VS Code already exposes chat-input documents and renders diagnostics for their resources; the missing spell-checking support was in Code Spell Checker's scheme allowlist and was fixed there in August 2026.

## Change summary

Allow extension-provided spell-checking diagnostics to display squiggles in the Copilot Chat prompt input.

## Best solution

Keep VS Code's existing chat-input document synchronization and diagnostic rendering, with spell-checking support supplied by Code Spell Checker 4.7.0 or later.

- **Reason:** Allowing an extension to enhance the prompt input follows VS Code's extension-first product model without adding spell checking to core.

## Evidence

- **VS Code extension access:** src/vs/workbench/contrib/chat/browser/widget/input/chatInputPart.ts creates the `chatSessionInput` model with `isForSimpleWidget` set to false; src/vs/editor/common/model.ts therefore permits synchronization, and MainThreadDocumentsAndEditors publishes synchronized models to the extension host even though the simple-widget editor object itself is omitted.
- **diagnostic rendering:** src/vs/editor/common/services/markerDecorationsService.ts attaches marker decorations to every text model and updates them when extension diagnostics change, so diagnostics targeting the chat-input URI produce the requested squiggles without exposing the widget as `window.visibleTextEditors`.
- **extension fix:** https://github.com/streetsidesoftware/vscode-spell-checker/commit/e4ce9fecd37a5c2247ee7926f4e123831c70f945 adds `chatSessionInput` to Code Spell Checker's enabled schemes and forces VS Code DiagnosticCollection rendering for that scheme, directly changing the reported outcome when a misspelled word is typed in Chat.
- **shipping release:** The extension fix is contained in Code Spell Checker 4.7.0, released on 2026-08-24: https://github.com/streetsidesoftware/vscode-spell-checker/releases/tag/code-spell-checker-v4.7.0.
