# Issue #342291 — Agent picker: add a setting to hide/disable the built-in "Copilot" agent (agent-host-copilotcli)

[https://github.com/microsoft/vscode/issues/342291](https://github.com/microsoft/vscode/issues/342291)

## Summary

The selective opt-out remains missing on current main: Copilot passes provider filtering and its dynamically registered picker contribution has no visibility gate. Existing default-harness controls do not remove that entry, so keep this request open.

## Change summary

Allow users to suppress the built-in Copilot agent-host picker entry without disabling Local, other providers, or all AI features.

## Best solution

Provide a supported workbench picker-visibility preference, with consistent default-selection behavior and clearly defined treatment of existing sessions. Keep presentation preferences separate from runtime authorization and enterprise requirements.
