# Issue #342291 — Agent picker: add a setting to hide/disable the built-in "Copilot" agent (agent-host-copilotcli)

[https://github.com/microsoft/vscode/issues/342291](https://github.com/microsoft/vscode/issues/342291)

## Summary

Keep open as a feature request: current main still lacks an independent opt-out for the dynamically registered Copilot picker entry. Existing harness-preference settings change selection defaults, not visibility, and do not satisfy the request.

## Change summary

Provide a supported way to hide the agent-host-copilotcli picker entry without disabling other chat providers or all AI features.

## Best solution

Support selective harness visibility in the workbench picker while preserving the default experience and access to existing conversations. Maintainers should settle whether this is a picker-only preference or provider disablement, including its interaction with managed requirements that mandate the Copilot harness.
