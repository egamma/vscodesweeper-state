# Issue #290402 — Discarding file changes from SCM view should work as `undo` for Chat

[https://github.com/microsoft/vscode/issues/290402](https://github.com/microsoft/vscode/issues/290402)

## Summary

Team-authored feature request: when a user discards Chat-made file changes via the SCM view (e.g. git discard), Chat's keep/undo UI should reflect that the changes were reverted — currently it shows +0/-0. Keeping open per hard keep-open rule (MEMBER author).

## Change summary

Discarding Chat-generated file changes from the SCM view does not propagate as an undo in the Chat editing session, leaving the keep/undo UI showing +0/-0 diffs.

## Best solution

The Chat editing entry (likely `chatEditingModifiedDocumentEntry.ts`) needs to detect when its tracked document is reverted externally (e.g. via SCM discard / git checkout) and treat that as equivalent to an undo — updating its snapshot state and the keep/undo diff accordingly. The `_textModelChangeService.undo()` path exists for the in-Chat undo action; the SCM discard path needs to converge with it or at least sync the entry's original-snapshot so the diff is accurate.
