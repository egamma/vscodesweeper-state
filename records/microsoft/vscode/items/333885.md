# Issue #333885 — Chat session and history disappear when opening a folder/project in a window that started with an empty workspace

[https://github.com/microsoft/vscode/issues/333885](https://github.com/microsoft/vscode/issues/333885)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/310586 reports the same observable symptom—local chat sessions disappear when an empty window transitions to an opened folder—and fully owns this workspace-transition gap.

## Change summary

Preserve the active Copilot Chat session and its history when opening a folder in the same window from an empty workspace.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/310586 and make the direct Open Folder reload path participate in chat-session migration or handoff, so empty-window sessions remain accessible in the resulting folder workspace.

## Evidence

- **canonical issue:** https://github.com/microsoft/vscode/issues/310586 is open, predates this report (2026-04-16 versus 2026-09-01), and describes the same reporter-observable sequence: create local chat sessions without a workspace, open a folder in the same window, and see those sessions disappear from the Sessions list.
- **source trace:** src/vs/workbench/browser/actions/workspaceActions.ts routes OpenFolderAction directly through IFileDialogService.pickFolderAndOpen, while src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts only migrates sessions after IWorkspaceEditingService.onDidEnterWorkspace. The direct folder-open reload therefore bypasses the migration event used by ChatSessionStore.
- **prior partial fix:** https://github.com/microsoft/vscode/commit/7393b0ec6071aca9ba95635a36588affb09db549 fixed session migration for workspace-ID transitions through onDidEnterWorkspace, closing https://github.com/microsoft/vscode/issues/289653, but the current Open Folder action follows a different path.
- **unique report evidence:** This report confirms the failure on Windows in VS Code 1.135.0 and notes that a separate empty window can still display the session, indicating that the transcript persists but is not surfaced after the workspace change.
