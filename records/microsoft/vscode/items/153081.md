# Issue #153081 — Reverse the visual logic of text link decorators

[https://github.com/microsoft/vscode/issues/153081](https://github.com/microsoft/vscode/issues/153081)

## Summary

Valid accessibility improvement request: links in VS Code UI rely only on color to distinguish them from surrounding text, which conflicts with W3C accessibility guidelines. The core link component (src/vs/platform/opener/browser/link.css) still uses only color differentiation with no underline. Already labeled under-discussion and accessibility — keeping open for a design decision.

## Change summary

Request to underline text links by default (removing underline on hover) instead of the current hover-to-underline pattern, for better accessibility per W3C guidelines.

## Best solution

Add a default `text-decoration: underline` to `.monaco-link` in `src/vs/platform/opener/browser/link.css` (and audit other link-styled elements), possibly behind an accessibility setting to let users choose. This is an accessibility/design call that needs maintainer input on whether to apply globally or gate behind a setting.
