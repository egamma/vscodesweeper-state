# Issue #186815 — Markdown Preview - Ghost Elements

[https://github.com/microsoft/vscode/issues/186815](https://github.com/microsoft/vscode/issues/186815)

## Summary

Confirmed upstream morphdom bug with duplicate HTML IDs still present on main — VS Code still uses morphdom 2.7.4 and the upstream issue (patrick-steele-idem/morphdom#205) appears unresolved. Correctly labeled as upstream with help wanted.

## Change summary

Markdown preview creates ghost/duplicate DOM elements when HTML nodes share the same `id` attribute, due to morphdom's ID-based node matching.

## Best solution

Either wait for an upstream fix to https://github.com/patrick-steele-idem/morphdom/issues/205, or work around it in VS Code's morphdom call by providing a custom `getNodeKey` option that avoids relying on duplicate IDs for node matching. The workaround would live in `extensions/markdown-language-features/preview-src/index.ts` around line 295.
