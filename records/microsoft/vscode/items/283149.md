# Issue #283149 — Unable to specify line numbers when providing file context in prompt files

[https://github.com/microsoft/vscode/issues/283149](https://github.com/microsoft/vscode/issues/283149)

## Summary

A real capability gap remains: prompt-file references can attach an entire file but cannot represent a target line range. Because this is a Backlog Candidates feature request, it should remain open under the community process and be classified as under discussion.

## Change summary

Allow references in prompt files to include only a specified range of lines from the referenced file.

## Best solution

Define a supported line-range syntax for prompt-file references and preserve that range through parsing, validation, and chat attachment construction so only the requested lines enter model context, while existing whole-file references remain unchanged.

## Evidence

- **attachment pipeline:** src/vs/workbench/contrib/chat/common/promptSyntax/computeAutomaticInstructions.ts resolves each reference to a URI and creates a whole-file prompt attachment with `toPromptFileVariableEntry`; src/vs/workbench/contrib/chat/common/attachments/chatVariableEntries.ts defines IPromptFileVariableEntry without a target range.
