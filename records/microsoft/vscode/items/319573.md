# Issue #319573 — Please suppress modal dialogs for connection problems

[https://github.com/microsoft/vscode/issues/319573](https://github.com/microsoft/vscode/issues/319573)

## Summary

Keep open as a request for less intrusive remote-connection failure handling. Current core code still deliberately presents modal dialogs; the existing dialog-style setting changes their appearance but does not suppress them, and no verified canonical covers the full request.

## Change summary

Replace or suppress blocking connection-failure dialogs while retaining useful, nonblocking connection status and recovery actions.

## Best solution

Have the remote-workbench owner decide how connection failures can remain conspicuous without blocking unrelated window interactions. Establish which native and in-window messages the reporter sees together before deciding whether suppression, deduplication, or notification-based presentation is appropriate.
