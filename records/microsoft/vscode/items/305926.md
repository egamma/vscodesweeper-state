# Issue #305926 — Git is watching all worktrees recursively

[https://github.com/microsoft/vscode/issues/305926](https://github.com/microsoft/vscode/issues/305926)

## Summary

Automatic worktree detection is now disabled by default, but opened worktree repositories still receive recursive watchers, including through Copilot session code. The original steps suffice to retest; the default-setting mitigation alone does not establish that the reported cross-window watcher load is resolved.

## Change summary

Avoid expensive recursive watching of unrelated session worktrees when opening their main repository in VS Code.

## Best solution

Establish which session or Git discovery paths still open unrelated worktrees in the ordinary VS Code window, then limit unnecessary repository watching while preserving status updates for worktrees the user is actively using.
