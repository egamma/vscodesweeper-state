# Issue #236722 — Spinning cursor

[https://github.com/microsoft/vscode/issues/236722](https://github.com/microsoft/vscode/issues/236722)

## Summary

This is a duplicate of #235959, which tracked slow paste in TypeScript files caused by the 'paste with imports' feature introduced in 1.96. The fix shipped in 1.98 (commit ae77c3ff426).

## Change summary

Pasting in TypeScript files shows a spinning cursor for several seconds due to the paste-with-imports feature computing import edits synchronously.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/235959 which already tracked and resolved this. The fix optimistically shows the paste result while TS server computes imports, eliminating the spinner in most cases.
