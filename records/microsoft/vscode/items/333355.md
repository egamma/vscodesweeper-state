[https://github.com/microsoft/vscode/issues/333355](https://github.com/microsoft/vscode/issues/333355)

## Summary

Well-diagnosed gap: BYOK groups sharing the same vendor/model display name can't be disambiguated in runSubagentTool's model param, confirmed in current source. This is a real, unaddressed request that needs an API/format decision, so routing to chat/BYOK area rather than closing.

## Change summary

Add an unambiguous model identifier format (vendor/group/id) for the runSubagent tool's model parameter so it can target a specific BYOK group when multiple groups expose a model with the same display name.
