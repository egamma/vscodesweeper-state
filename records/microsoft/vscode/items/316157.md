# Issue #316157 — [Agents App] No visible indicator when working inside a worktree

[https://github.com/microsoft/vscode/issues/316157](https://github.com/microsoft/vscode/issues/316157)

## Summary

Valid feature request backed by usability research. Current main has some worktree indicators (a different icon in the sessions list and branch name on hover), but no persistent, prominent branch/worktree label — the core ask remains unaddressed.

## Change summary

Display a persistent, visible indicator of the active worktree/branch name in the Agents window so users can tell at a glance whether they are working in a worktree.

## Best solution

Add the branch name alongside the workspace label in the sessions title bar pill (`sessionsTitleBarWidget.ts` `_renderActiveSession`) and in the sessions list details row (`sessionsList.ts`). The data is already available via `workspace.folders[0].gitRepository.branchName` and `workTreeUri`. The hover content (`sessionHoverContent.ts`) already renders both — the same info should surface persistently.
