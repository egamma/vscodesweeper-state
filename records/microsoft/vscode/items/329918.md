# Issue #329918 — Pasted image is attached and rendered in the request, but the model receives no image ("No image is attached to this request") — Claude Opus 5, 1.132.0

[https://github.com/microsoft/vscode/issues/329918](https://github.com/microsoft/vscode/issues/329918)

## Summary

The reporter self-diagnosed and closed this: image attachments are intentionally omitted from the model prompt when an org's Copilot policy sets `editor_preview_features=0`, confirmed by both the extension source and an existing unit test — this is by-design gating, not a regression of #297891.

## Change summary

Pasted image attachments render in the chat request bubble but are silently dropped before reaching the model, with the model claiming no image was attached.

## Best solution

Keep the org-policy gating in extensions/copilot/src/extension/prompts/node/panel/image.tsx (via `CopilotToken.isEditorPreviewFeaturesEnabled()`) as-is — it's intentional and tested — but consider a follow-up UX polish item so the chat UI surfaces a visible warning/notice when an attached image is dropped for policy reasons, instead of silently sending the request without it.
