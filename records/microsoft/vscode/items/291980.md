# Issue #291980 — Git Blame editor decoration does not show "Open in Github" option for repos cloned via SSH with a Github enterprise SSH CA 

[https://github.com/microsoft/vscode/issues/291980](https://github.com/microsoft/vscode/issues/291980)

## Summary

The reported defect remains in current main: GitHub remote detection requires the SSH username to be literal `git`, so organization-specific SSH CA usernames suppress the blame hover action. Keep this issue open; the related reports and active PRs do not cover that username format.

## Change summary

Recognize organization-specific SSH CA usernames on github.com remotes so Git blame offers Open on GitHub.

## Best solution

GitHub repository detection and commit-link generation should accept the reported organization-specific SSH username while preserving existing remote selection and github.com host restrictions.
