# Issue #309213 — Extension allowlist by publisher fails for remote extensions after version upgrade due to missing publisherDisplayName metadata

[https://github.com/microsoft/vscode/issues/309213](https://github.com/microsoft/vscode/issues/309213)

## Summary

The reporter supplied the requested metadata evidence, and the defect remains source-reproducible on current main: the remote VSIX fallback discards known gallery metadata before allowlist evaluation. No older issue with the same observable symptom or open fixing PR was found.

## Change summary

Remote extensions installed through the local-download VSIX fallback are temporarily or persistently blocked by publisher-based allowlists because publisher metadata is unavailable during enablement evaluation.

## Best solution

Ensure remote gallery installs retain their gallery identity and publisher metadata before the installed extension is returned and evaluated by the client-side allowlist, including fallback installs and updates.
