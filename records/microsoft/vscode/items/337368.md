# Issue #337368 — Clarify organization-managed Auto default in model picker

[https://github.com/microsoft/vscode/issues/337368](https://github.com/microsoft/vscode/issues/337368)

## Summary

Real, still-open gap: the model picker's config dropdown (modelPickerConfiguration.ts) marks a managed Auto default with a generic 'Default' description and no indication it comes from org policy versus the user's own choice. A maintainer has already engaged and explained this needs cross-product coordination (GitHub App, CLI), so it stays open and unassigned to an external contributor for now.

## Change summary

When an Auto tier default is set via organization-managed settings, the model picker should show a tooltip/accessible label distinguishing it from an ordinary user-set default.

## Best solution

Extend the config dropdown in src/vs/workbench/contrib/chat/browser/widget/input/modelPicker/modelPickerConfiguration.ts (and the managed-tier plumbing in chatModelConfigurationStore.ts / autoModeTiers.ts) to pass through a managed-vs-default distinction into the tooltip and ariaDescription, but only once the cross-product (GitHub App/CLI) presentation is settled by the team, per rwoll's comment.
