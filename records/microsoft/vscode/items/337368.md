# Issue #337368 — Clarify organization-managed Auto default in model picker

[https://github.com/microsoft/vscode/issues/337368](https://github.com/microsoft/vscode/issues/337368)

## Summary

Real, unimplemented follow-up: the model picker's Auto tier already tracks whether the default came from managed/org settings (`tierSource: 'managed'`), but nothing in the UI surfaces that distinction to the hover tooltip or accessible label — an external contributor has already offered to pick it up.

## Change summary

When the Auto tier's default is set by organization-managed policy, clarify that in the model picker's hover tooltip and accessible label, without changing presentation for ordinary (non-managed) defaults.

## Best solution

Extend ModelPickerAutoRow's tier tooltip/aria text to check the tier's source (already tracked as `AutoTierSourceConfigKey === 'managed'` in chatModelConfigurationStore.ts) and append an org-managed note only in that case; leave the non-managed path untouched.
