## Change summary

When Assisted Permissions or Allow All is enabled, denying an Anthropic-model tool call (found via tool_search_tool) causes the Copilot API to return a 400 'Tool reference not found in available tools' instead of relaying the denial back to the model, unlike the working manual-permissions flow.

## Best solution
