# Issue #347862 — Feature Request: Agents Overview Dashboard

[https://github.com/microsoft/vscode/issues/347862](https://github.com/microsoft/vscode/issues/347862)

## Summary

Keep open for product consideration: the Sessions sidebar already provides activity monitoring, but that only partially addresses the requested monitoring-first landing dashboard. The candidate Agents Council issue concerns a different orchestration system, not an equivalent overview of existing sessions.

## Change summary

Provide an Agents landing dashboard showing ongoing and completed tasks, progress, attention states, and quick actions.

## Best solution

Evaluate a monitoring-first landing experience built on the existing provider-neutral session catalog and Inbox classification, rather than introducing a separate status model. Keep the immediate scope to clear statuses and actionable task summaries; gamification is explicitly optional future work.
