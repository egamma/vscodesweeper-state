# Issue #275155 — Too many borders in our chat view

[https://github.com/microsoft/vscode/issues/275155](https://github.com/microsoft/vscode/issues/275155)

## Summary

This remains an accepted Backlog chat-polish request: current main still uses persistent strokes for the thinking activity hierarchy and file-name attachments. The broader chat-condensing issue improved adjacent presentation but explicitly left this issue for separate disposition, so it is not a canonical or completed fix.

## Change summary

Reduce persistent borders in chat thinking content and file-name presentation, and make their indentation visually consistent.

## Best solution

Give chat a calmer, consistent hierarchy by removing borders that do not communicate interaction or structure, while retaining focus, warning, high-contrast, and any deliberately chosen activity-connector strokes.
