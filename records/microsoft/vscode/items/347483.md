# Issue #347483 — Automations: let an automation decide when to notify

[https://github.com/microsoft/vscode/issues/347483](https://github.com/microsoft/vscode/issues/347483)

## Change summary

Allow an automation to decide from its findings whether a run should notify the user.

## Best solution

Provide an explicit run-level notification decision that keeps uneventful runs quiet while surfacing actionable findings. Define its relationship to execution failures and warning badges without treating those separate signals as equivalent.
