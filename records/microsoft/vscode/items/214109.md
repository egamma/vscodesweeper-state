# Issue #214109 — Make "Accept in Background" feature (aka right arrow) more discoverable

[https://github.com/microsoft/vscode/issues/214109](https://github.com/microsoft/vscode/issues/214109)

## Summary

Keep open: background acceptance exists, but the current file quick-access placeholder still does not explain its shortcut. This team-authored, accepted Backlog request remains necessary; no verified fix or older same-symptom canonical was found.
