# Issue #327390 — Eagerly re-check for PRs when a PR link is emitted in chat turn

[https://github.com/microsoft/vscode/issues/327390](https://github.com/microsoft/vscode/issues/327390)

## Summary

Keep open as Agents window polish. Current source retries PR discovery only when session GitHub metadata recomputes; a PR link appearing in chat does not trigger an eager refresh.

## Change summary

Use a PR link emitted in an agent chat turn to promptly refresh the session's pull-request association and icon.

## Best solution

Connect structured PR content or a validated GitHub pull-request URL from a completed chat turn to a session-scoped refresh of PR discovery, without adding unconditional polling. This likely belongs in the Agents window provider/GitHub integration around `SessionGitHubInfoResolver` and `GitHubService`.
