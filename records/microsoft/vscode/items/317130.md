# Issue #317130 — Can't disable commit message suggestions

[https://github.com/microsoft/vscode/issues/317130](https://github.com/microsoft/vscode/issues/317130)

## Summary

The underlying behavior is configurable, but current main lacks a discoverable SCM-local toggle. Route this feature request to SCM and inline completions.

## Change summary

Add a GUI action for disabling automatic Copilot inline suggestions in commit-message inputs while preserving on-demand generation.

## Best solution

Provide a keyboard-accessible SCM-input action that toggles `github.copilot.enable.scminput` without disabling the separate Generate Commit Message action. The generic Copilot status menu cannot currently perform this while an SCM input has focus.

- **Reason:** Discoverable control over automatic AI suggestions makes the agent-assisted editing experience less intrusive and more consistent.
- **Evidence:** The public roadmap includes AI-assisted development and simple, uniform UI interactions; it also aligns with current completions and consistent agent-experience priorities.

## Evidence

- **existing setting:** extensions/copilot/package.json registers `github.copilot.enable` with a `scminput` entry, and the reporter confirmed that setting it to false disables the automatic suggestions.
- **UI gap on main:** extensions/copilot/src/extension/completions-core/vscode-node/extension/src/statusBarPicker.ts only offers the language-specific enable/disable action when `window.activeTextEditor` exists; an SCM input is not an active text editor.
- **command limitation:** extensions/copilot/src/extension/completions-core/vscode-node/extension/src/config.ts derives the language for enable/disable commands from `window.activeTextEditor?.document.languageId`, so the generic command cannot target a focused SCM input.
