# Issue #317130 — Can't disable commit message suggestions

[https://github.com/microsoft/vscode/issues/317130](https://github.com/microsoft/vscode/issues/317130)

## Summary

The reporter confirmed that disabling commit-message suggestions works; the remaining request is a discoverable GUI toggle specifically for the commit input. Current controls do not clearly cover that narrower request, so keep it open as a feature request.

## Change summary

Provide a discoverable GUI control to disable automatic Copilot commit-message suggestions while retaining on-demand generation.

## Best solution

Expose the existing scminput completion preference through a clearly named commit-input control, without disabling completions in other languages or removing the Generate Commit Message action. This belongs in the SCM input and Copilot completion-control UX rather than a new independent configuration mechanism.
