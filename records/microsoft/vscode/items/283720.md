# Issue #283720 — Show icon instead of talking about the icon

[https://github.com/microsoft/vscode/issues/283720](https://github.com/microsoft/vscode/issues/283720)

## Summary

Keep open: command buttons provide a useful alternative, but do not satisfy the request to show the actual icons alongside navigation instructions. This team-authored, accepted Backlog request has no verified fixing commit or qualifying duplicate.

## Change summary

Show recognizable UI icons alongside Copilot's textual references to controls such as the gear and document icons.

## Best solution

Provide accurate visual references alongside textual descriptions when Copilot explains VS Code navigation, preserving accessible text and existing command buttons. Establish the supported scope and how icon identity is grounded before implementing the response contract.
