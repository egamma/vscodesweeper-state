# Issue #304936 — I have to modify my agents to allow them to use tools

[https://github.com/microsoft/vscode/issues/304936](https://github.com/microsoft/vscode/issues/304936)

## Summary

A real gap remains: current main deliberately writes tool-picker changes into a writable custom-agent file, while only extension-owned agents receive session-local changes. This team-authored request should remain open for a product decision on locally overriding tools for shared agents.

## Change summary

Allow a user to enable tools for a shared custom agent without modifying the repository's agent file.

## Best solution

Treat the agent file's tools as the shared baseline while offering an explicit user-local or session-local override that does not dirty the file. Maintainers should first choose the override's persistence and how the picker distinguishes editing shared metadata from applying a private selection.
