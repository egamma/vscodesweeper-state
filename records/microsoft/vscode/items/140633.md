## Summary

The reported filename-extension override is resolved in current main: language detection returns the language associated with the untitled URI before consulting the content classifier. A concrete post-report commit introduced that precedence, so this can be closed as completed.

## Change summary

Preserve Markdown mode when an extension opens an untitled document whose URI ends in .md, rather than replacing it with a content-based language guess.
