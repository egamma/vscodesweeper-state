# Issue #330695 — `editor.allowVariableFonts: false` silently prevents extension editor decorations from rendering

[https://github.com/microsoft/vscode/issues/330695](https://github.com/microsoft/vscode/issues/330695)

## Summary

The decoration loss is still present in current source: disabling variable fonts filters out entire decorations whenever fontWeight or fontStyle is nonempty, including "normal". Keep this open in the existing font-token-customization area; the report provides sufficient reproduction details.

## Change summary

Prevent disabling variable fonts from silently removing extension highlights that also specify ordinary font properties.

## Best solution

Preserve ordinary extension decorations and their non-font styling when variable fonts are disabled, including through accessibility mode, without bypassing restrictions on genuine variable-font behavior. Cover the extension-decoration conversion and viewport-filtering path with regression tests.
