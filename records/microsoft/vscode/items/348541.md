# Issue #348541 — Agents window: support Codex slash commands and make session recap/usage actions discoverable

[https://github.com/microsoft/vscode/issues/348541](https://github.com/microsoft/vscode/issues/348541)

## Summary

Keep open as a feature request: current main provides Codex context compaction and account usage details, but those do not satisfy the requested recap action and unified slash-command discoverability. The related usage-limit request covers only part of this scope.

## Change summary

Make supported Codex session controls, recap, and provider usage/status discoverable from the Agents window chat input.

## Best solution

Define the supported Agents-window command surface and expose session actions with clear descriptions and documented UI equivalents. Reuse existing account usage data, distinguish recap from context compaction, and coordinate usage presentation with https://github.com/microsoft/vscode/issues/346086.
