# Issue #148158 — Prevent menu selection from static mouse hover

[https://github.com/microsoft/vscode/issues/148158](https://github.com/microsoft/vscode/issues/148158)

## Summary

Still reproduces on main: the menu's MOUSE_OVER handler in menu.ts unconditionally changes focus when a mouseover event fires, without checking whether the mouse actually moved — a static cursor under a newly-opened menu triggers unwanted selection.

## Change summary

When a menu opens under a stationary mouse cursor, the browser fires a mouseover event that changes the focused menu item away from the keyboard-selected one.

## Best solution

Add mouse-movement tracking to the MOUSE_OVER handler in `src/vs/base/browser/ui/menu/menu.ts` (around line 193): record the mouse position on menu open and only change focus when the mouse has actually moved from that position. Similar patterns exist elsewhere in the codebase (e.g. suggest widget, quick pick).
