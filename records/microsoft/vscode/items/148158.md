# Issue #148158 — Prevent menu selection from static mouse hover

[https://github.com/microsoft/vscode/issues/148158](https://github.com/microsoft/vscode/issues/148158)

## Summary

The stationary-pointer selection bug was fixed after the prior review by merged PR https://github.com/microsoft/vscode/pull/329507. Current menu handling ignores synthetic mouseover events and regression tests explicitly cover this issue, so it can be closed as completed.

## Change summary

Opening a menu beneath a stationary mouse pointer unexpectedly moved keyboard selection to the item under the pointer.

## Best solution

Keep the fix from https://github.com/microsoft/vscode/commit/9e124ab7a5a8e5e9d630d8558bb6eca78c90f0eb, which changes menu hover activation to require actual pointer movement while preserving normal mouse-driven selection.
