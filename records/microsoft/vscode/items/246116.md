Keep open while the two linked implementation PRs are reviewed. The request has substantial community support, is in the Backlog, and now has competing scoped and comprehensive approaches that require maintainer evaluation.

## Change summary

Add an editor control or setting that renders Arabic and other bidirectional text with an appropriate RTL base direction.

## Best solution

Review and converge https://github.com/microsoft/vscode/pull/311934 and https://github.com/microsoft/vscode/pull/314365 around a consistent editor text-direction model, preserving stable code layout while supporting explicit RTL and contextual direction.
