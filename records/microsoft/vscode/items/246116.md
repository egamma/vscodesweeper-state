# Issue #246116 — Arabic RTL text not rendered correctly inside VS Code editor.

[https://github.com/microsoft/vscode/issues/246116](https://github.com/microsoft/vscode/issues/246116)

## Summary

Active feature request with 94 upvotes, promoted to Backlog, with two open community PRs (#311934, #314365) pursuing the implementation. The central ask — an opt-in setting or UI control to switch editor direction to RTL — is not yet shipped on main. Keeping open for the PRs to land.

## Change summary

Add a user-facing setting or UI control to render editor lines as RTL for Arabic and other right-to-left languages.

## Best solution

Land one of the open PRs (https://github.com/microsoft/vscode/pull/311934 or https://github.com/microsoft/vscode/pull/314365) after review, delivering an opt-in `editor.rtlAutoDetect` or equivalent setting that auto-detects RTL lines without changing default behavior. The decoration-based RTL support (commit 4846a428224) and `dir="auto"` on tokens (commit 18554b91593) are partial steps but don't give users a simple toggle.
