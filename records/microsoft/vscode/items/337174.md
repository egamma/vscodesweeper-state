## Summary

The malformed client_id blocks MCP authorization, but the available evidence does not establish where that value originates. Request the server configuration and sanitized authentication diagnostics before attributing this to VS Code or consolidating it with another report.

## Change summary

Meta MCP authorization fails with “Invalid App ID” because client_id contains callback URLs instead of the MCP client's registered identity.

## Best solution

Identify whether the incorrect identity originates in registration, saved or supplied client details, or the authorization handoff, then ensure the Meta flow preserves its actual MCP client identity. The reporter's WhatsApp app ID is not a substitute for that identity.
