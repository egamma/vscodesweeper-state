# Issue #337174 — Meta Social Technologies MCP OAuth URL has malformed client_id

[https://github.com/microsoft/vscode/issues/337174](https://github.com/microsoft/vscode/issues/337174)

## Summary

The reported client_id — `http://127.0.0.1:33418 https://vscode.dev/redirect` — is exactly VS Code's own two OAuth redirect URIs joined together, which strongly suggests the user pasted the value copied by the manual-client-registration fallback dialog into the wrong field, since that flow copies those same URIs to the clipboard right before prompting for a client ID with no validation to catch the mistake.

## Change summary

When an MCP server's authorization server doesn't support Dynamic Client Registration, VS Code's fallback dialog can lead a user to accidentally submit the redirect URIs as the client ID.

## Best solution

Add sanity validation to the client ID quick input in the manual client-registration flow (mainThreadAuthentication.ts $promptForClientRegistration) so an obviously-wrong value (containing a space, a newline, or matching the just-copied redirect URIs) is rejected with a clarifying message, and/or restructure the two-step copy-then-paste dialog so the copied text isn't likely to land in the wrong box.
