# Issue #128744 — DAP ContinuedEvent with allThreadsContinued=true causes selected debug session to change

[https://github.com/microsoft/vscode/issues/128744](https://github.com/microsoft/vscode/issues/128744)

## Summary

The session-switching behavior remains present in current source, but the thread ends with an unresolved product decision about whether that focus transfer is desirable for restart and other commands that work on running sessions. Keep this open under discussion in the debug area.

## Change summary

Avoid unexpectedly changing the selected debug session when a restarted session emits a DAP ContinuedEvent with allThreadsContinued=true.

## Best solution

Debug UI owners should settle whether an explicitly selected session should remain selected after an all-threads continue when the invoked toolbar action remains valid for running sessions, then encode that rule in focus-management tests.
