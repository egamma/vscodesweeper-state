# Issue #249249 — Make it easier to distinguish & trigger chat completion types

[https://github.com/microsoft/vscode/issues/249249](https://github.com/microsoft/vscode/issues/249249)

## Summary

The core request — scoped/tiered completions with category prefixes (#file:, #tool:, #sym:) and distinguishing icons — remains unimplemented on main. Completion items still use CompletionItemKind.Text with comments noting icons are disabled.

## Change summary

Make chat input completions easier to distinguish by type via scoped prefixes (#file:, #tool:) and/or icons, enabling tiered two-step completion flows.

## Best solution

Implement scoped completion categories in the chat input widget: typing `#` offers top-level categories (file, tool, sym), then a second completion resolves items within that category. Enable CompletionItemKind-based icons per category. This likely extends IChatContextPickService and the completion providers in chatInputCompletions.ts.
