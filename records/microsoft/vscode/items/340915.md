# Issue #340915 — Add "Maximize Primary Side Bar" for parity with Secondary Side Bar and Panel

[https://github.com/microsoft/vscode/issues/340915](https://github.com/microsoft/vscode/issues/340915)

## Summary

Primary Side Bar maximization remains a distinct capability gap in current main. Keep the request in its newly started Backlog Candidates community-review period; no verified canonical or landed implementation supports closing it.

## Change summary

Add a reversible Primary Side Bar maximize command and matching title bar button, equivalent to the Secondary Side Bar affordance.

## Best solution

If accepted through community review, provide Primary Side Bar maximize/restore behavior in the workbench layout service and sidebar actions, preserving the previous layout and supporting either sidebar position. Width adjustment and moving views to the Secondary Side Bar do not deliver the requested in-place parity.
