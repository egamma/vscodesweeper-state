# Issue #327643 — Terminals created for session stick around unnecessarily

[https://github.com/microsoft/vscode/issues/327643](https://github.com/microsoft/vscode/issues/327643)

## Summary

Keep open: current main still eagerly creates terminals when sessions are selected and retains them in the background when switching away. This is an improvement to an explicitly implemented lifecycle, and neither related report is a valid duplicate target for this re-reviewed, team-authored issue.

## Change summary

Avoid accumulating unused session terminals merely by alternating between new drafts and existing sessions in the Agents Window.

## Best solution

Make session browsing avoid allocating unused shells while preserving terminals that users or tasks actually use. Establish when automatic terminal creation should become necessary, then adjust the sessions terminal lifecycle without weakening session ownership or backend isolation.
