# Issue #327643 — Terminals created for session stick around unnecessarily

[https://github.com/microsoft/vscode/issues/327643](https://github.com/microsoft/vscode/issues/327643)

## Summary

Current main conclusively reproduces the eager creation path: merely selecting each session ensures a terminal for it. Keep this team-authored issue open and route it to the terminal area.

## Change summary

Avoid creating and retaining a terminal for every Agents window session visited when the user never uses its terminal.

## Best solution

Make session terminals lazy: retain default-cwd synchronization and surface existing session terminals, but create a new terminal only for an explicit terminal action or task execution. Update the terminal contribution tests that currently codify eager creation on session activation.
