# Issue #344817 — we should more visibly differentiate between type of customization and source

[https://github.com/microsoft/vscode/issues/344817](https://github.com/microsoft/vscode/issues/344817)

## Summary

Keep open as customization-discovery polish: the selected source is explicitly identified to screen readers, but its visible label can say only “GitHub Feed,” leaving the requested distinction implicit. This is a team-authored design request, with no verified fix or duplicate supporting closure.

## Change summary

Make customization sources such as GitHub Feed visibly distinguishable from customization types.

## Best solution

Make the source selector's role understandable at a glance while keeping customization type and source as independent filtering dimensions. Agree on the visible distinction before implementing focused presentation changes in the shared Discover page.
