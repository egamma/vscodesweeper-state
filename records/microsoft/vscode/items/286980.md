# Issue #286980 — Thinking block summary should linkify appropriately

[https://github.com/microsoft/vscode/issues/286980](https://github.com/microsoft/vscode/issues/286980)

## Summary

The defect remains on current main: thinking titles render as link-aware Markdown while streaming, but finalization replaces that content with plain text, so code or file references such as `_maxLineWidth` lose their links.

## Change summary

Preserve linkification for code and file references in a thinking block's collapsed summary after the response completes.

## Best solution

Keep finalized thinking summaries link-aware while preserving their current collapsed-title layout, accessibility label, diff statistics, and expand/collapse behavior.
