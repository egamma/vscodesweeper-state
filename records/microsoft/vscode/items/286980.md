[https://github.com/microsoft/vscode/issues/286980](https://github.com/microsoft/vscode/issues/286980)

## Summary

Still reproduces on main: `setFinalizedTitle` in chatThinkingContentPart.ts renders the collapsed summary as plain `textContent`, so code symbols like `_maxLineWidth` are never linkified — unlike the streaming title path which uses markdown rendering with `renderFileWidgets`.

## Change summary

Thinking block summaries should linkify code symbols (like `_maxLineWidth`) as clickable references, matching how they appear during streaming.

## Best solution

Refactor `setFinalizedTitle` to use the markdown renderer path (as the streaming title does at ~line 2290) so the finalized/collapsed summary also renders file widgets and code links via `renderFileWidgets`.
