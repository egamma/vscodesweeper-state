# Issue #145026 — Git - Request: don't save document on ranges revert (`git.revertSelectedRanges`)

[https://github.com/microsoft/vscode/issues/145026](https://github.com/microsoft/vscode/issues/145026)

## Summary

Keep open under discussion: selected-range revert still explicitly saves the document, and no existing Git setting covers the requested control. The Backlog milestone records accepted but unscheduled work; neither a completed fix nor a qualifying duplicate was established.

## Change summary

Allow Git selected-range reverts without an automatic save, avoiding save-participant edits and save-triggered rebuilds.

## Best solution

Provide an explicit persistence policy for selected-range reverts in the built-in Git extension. Distinguish bypassing save participants from avoiding disk writes entirely: only the latter addresses both parts of this request.
