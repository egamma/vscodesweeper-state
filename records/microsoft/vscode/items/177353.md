# Issue #177353 — Allow revealing path/file in OS from terminal or editor

[https://github.com/microsoft/vscode/issues/177353](https://github.com/microsoft/vscode/issues/177353)

## Summary

A real gap remains: VS Code can reveal an active editor or Explorer resource in the OS, but terminal and editor-content links only open inside VS Code. This request earned 22 upvotes and was explicitly promoted to the Backlog, so it should remain open.

## Change summary

Allow a path written in terminal output or editor content to be revealed in Finder, File Explorer, or the containing folder.

## Best solution

On desktop, add an alternate action for resolved local file and folder links in terminal output and editor content that invokes `revealFileInOS`; retain the current open-in-editor behavior as the default and omit the action where native OS integration is unavailable.

## Vision fit

- **Fit:** aligned
- **Reason:** This improves interoperability between command-line output, editor content, and native desktop file management without adding always-on UI.
- **Evidence:** Public value: “Allow for CLI / UI co-existence and interplay whenever possible.” It also fits the durable developer-inner-loop and workbench UX themes.
