# Issue #308918 — "retry" on async terminal steering message causes it to rerender incorrectly

[https://github.com/microsoft/vscode/issues/308918](https://github.com/microsoft/vscode/issues/308918)

## Summary

The reported rendering defect remains in current source: ordinary retry recreates the request without its system-initiated presentation metadata. Keep this team-authored issue open; neither an issue-referencing fix nor an older canonical with the same symptom was established.

## Change summary

Retrying a failed asynchronous terminal notification renders it as an ordinary user message instead of retaining its compact system-notification presentation.

## Best solution

Retried terminal notifications should retain their system-initiated identity, display label, and terminal correlation, while ordinary user-message retries retain their existing behavior.
