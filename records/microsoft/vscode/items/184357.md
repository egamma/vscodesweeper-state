# Issue #184357 — [Accessibility]: Make syntax highlight accessible to screen reader users via a speech scheme

[https://github.com/microsoft/vscode/issues/184357](https://github.com/microsoft/vscode/issues/184357)

## Summary

Keep open: current main has an opt-in rich screen-reader rendering path that may address the formatting-access approach endorsed in the discussion, but source inspection does not establish usable syntax-dependent speech. Validate that existing capability with screen readers before deciding what work remains.

## Change summary

Make syntax-token distinctions available to screen-reader users through formatting information or distinguishable speech.

## Best solution

Establish whether editor.renderRichScreenReaderContent exposes token formatting reliably to NVDA and JAWS, then agree on the remaining cross-screen-reader contract. Prefer preserving user-controlled screen-reader speech while making syntax information accessible rather than requiring a separate competing speech engine.
