# Issue #261978 — Select and move parts of conversation to a new chat to reduce context bloat

[https://github.com/microsoft/vscode/issues/261978](https://github.com/microsoft/vscode/issues/261978)

## Summary

The requested capability — forking a conversation from a specific point into a new chat to reduce context — is now implemented on main and shipped since VS Code 1.110. The 'Fork Conversation' action allows users to select a checkpoint in a chat and create a new session from that point.

## Change summary

Allow selecting parts of a conversation and moving them to a new chat to reduce context bloat.

## Best solution

Keep the shipped Fork Conversation feature (commit eadcfc24, VS Code 1.110+); it lets users fork from any checkpoint into a new session, addressing the core ask of reducing context by splitting conversations.
