# Issue #336380 — Debug toolbar remains active when running Flutter app without debugging

## Summary

Thin, single-reporter report filed hours ago with no confirmation from anyone else; the debug toolbar's step/continue controls are enabled based on the debug session's reported state (`CONTEXT_DEBUG_STATE`), which is driven by DAP events the debug adapter sends — so this most likely traces back to how the Dart-Code/Flutter debug adapter handles `noDebug` sessions rather than a core defect, but that's not confirmed.
