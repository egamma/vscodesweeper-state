# Issue #339589 — Expose the chat permission level (Default / Allow all / Autopilot) in agent hook input

[https://github.com/microsoft/vscode/issues/339589](https://github.com/microsoft/vscode/issues/339589)

## Summary

Well-reasoned, detailed request, but it's brand new (1 day old), from a first-time reporter, with no upvotes or maintainer engagement yet — too early to judge beyond classifying it and flagging the real design fork it raises.

## Change summary

Expose the active chat permission level (Default / Allow all / Autopilot) in the common hook input so a PreToolUse hook can relax its own `ask` decisions when the user already opted into fewer confirmations.

## Best solution

A maintainer who owns the hooks schema should decide between the two designs the reporter proposes — exposing a `permission_level` field directly vs. a `respectAutoApprove`/delegated-ask flag — before any implementation; either would close the gap confirmed in languageModelToolsService.ts and hookSchema.ts, where the current hook input (timestamp, hook_event_name, session_id, transcript_path, tool_name, tool_input, tool_use_id, cwd) has no permission-level field today.
