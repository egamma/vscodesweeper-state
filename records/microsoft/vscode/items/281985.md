# Issue #281985 — Git - Commit Message Generation Optional Context - chat history

[https://github.com/microsoft/vscode/issues/281985](https://github.com/microsoft/vscode/issues/281985)

## Summary

Keep open: Source Control commit-message generation still lacks optional conversation context. The closely related open issue is newer than this re-reviewed report, so it cannot serve as a duplicate canonical.

## Change summary

Allow commit-message generation to optionally use chat history to explain why changes were made.

## Best solution

Provide an opt-in way to include relevant conversation context in Source Control commit-message generation while retaining diffs as the authoritative description of changes. Decide which conversation and turns are eligible, coordinating with the related request at https://github.com/microsoft/vscode/issues/273271.
