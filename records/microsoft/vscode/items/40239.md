# Issue #40239 — Feature Request: Enable/disable extensions from config file

[https://github.com/microsoft/vscode/issues/40239](https://github.com/microsoft/vscode/issues/40239)

## Summary

This remains the canonical, highly supported request for declarative workspace extension enablement. Profiles and per-workspace UI state are partial alternatives, but neither provides repository-controlled configuration with an appropriate user-consent flow.

## Change summary

Allow a workspace configuration file to request enabling or disabling specified extensions.

## Best solution

Extend workspace extension configuration with consent-based enable/disable declarations, preserving each user's authority while allowing teams to share compatible extension sets. The implementation belongs in the extensions configuration schema and extension enablement service.
