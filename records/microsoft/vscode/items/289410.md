# Issue #289410 — Ability to select single or multiple elements from a web page

[https://github.com/microsoft/vscode/issues/289410](https://github.com/microsoft/vscode/issues/289410)

## Summary

Team-authored feature request for the integrated browser. Single element selection infrastructure exists on main (toggle, inspect, addToChat), but the full UX described here — visual selection feedback, multi-select with Command key, context attachments in the prompt area — is not yet implemented. Keeping open.

## Change summary

Allow users to single-select or multi-select DOM elements from the integrated browser and attach them as context to a chat prompt.

## Best solution

Build on the existing `BrowserViewInspector` element-selection infrastructure (`toggleElementSelection`, `onDidSelectElement`, `addToChat`) to add: (1) visible active/inactive selection highlights matching the design spec, (2) Command-key multi-select mode that accumulates selected elements, and (3) wiring selected elements into the chat prompt area as removable context chips. Work spans `src/vs/platform/browserView/` (inspector layer) and `src/vs/workbench/contrib/browserView/` (UX integration).
