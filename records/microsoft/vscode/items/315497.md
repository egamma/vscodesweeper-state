# Issue #315497 — Integrated Terminal: Backspace fails to remove multibyte UTF-8 characters from input buffer in Docker (Full characters remain as ghost bytes)

[https://github.com/microsoft/vscode/issues/315497](https://github.com/microsoft/vscode/issues/315497)

## Summary

The described behavior — backspace removing only one byte of a multi-byte UTF-8 character — is handled by the PTY line discipline, not by VS Code's terminal emulator. VS Code (via xterm.js) passes keystrokes through to the PTY and renders output; it does not manage the input buffer byte-level editing. This is very likely an upstream issue in ConPTY (Windows) or the Docker container's PTY. More info is needed to confirm whether this reproduces outside VS Code.
