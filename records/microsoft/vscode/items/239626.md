# Issue #239626 — Multiple Linux VNC sessions VS code does not open individual sessions

[https://github.com/microsoft/vscode/issues/239626](https://github.com/microsoft/vscode/issues/239626)

## Summary

Keep open in the Backlog: the request passed the community threshold with 33 upvotes, and current main still routes launches sharing a user-data directory to one Electron instance regardless of Linux DISPLAY.

## Change summary

Allow VS Code launches from separate Linux VNC/X displays to open on their originating display.

## Best solution

Make Linux instance selection display-aware, or provide a supported way to start a display-local instance while safely sharing normal settings and extensions. This likely belongs in the Electron main-process instance acquisition path rather than the remote extension layer.
