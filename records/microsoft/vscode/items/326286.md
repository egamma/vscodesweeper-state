# Issue #326286 — Long commands are truncated

[https://github.com/microsoft/vscode/issues/326286](https://github.com/microsoft/vscode/issues/326286)

## Summary

Multiple users confirmed that long commands remain visually truncated specifically in the unsandboxed-execution approval UI. This older report should remain the canonical issue; the later reports were closed without establishing a working fix.

## Change summary

The approval prompt for running a command outside the sandbox clips long command text, preventing users from inspecting the complete command before allowing it.

## Best solution

Ensure the entire command is inspectable in both inline and carousel sandbox-bypass confirmations, including after resizing, and add visual or layout-sensitive coverage that detects clipping rather than merely checking the editor model value.
