## Change summary

Chat session serialization throws RangeError: Invalid string length when a session grows too large (e.g. from large tool results), causing session loss.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/326633 which tracks the remaining Invalid string length occurrences after the fixes shipped. The core serialization path is now protected by stringifyEntryWithFallback and deepCloneWithFallback in objectMutationLog.ts, which truncate oversized strings instead of throwing.
