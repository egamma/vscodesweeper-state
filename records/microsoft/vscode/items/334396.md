# Issue #334396 — Add an option to expand "Completed N steps" by default

[https://github.com/microsoft/vscode/issues/334396](https://github.com/microsoft/vscode/issues/334396)

## Summary

Reasonable, well-scoped request: the "Completed N steps" disclosure currently always starts collapsed (with no user control), and no existing setting lets a user default it to expanded.

## Change summary

Add a setting so the chat response's collapsible "Completed N steps" summary defaults to expanded instead of collapsed.

## Best solution

Add a boolean config (e.g. under chat.* namespace) read where `details.open` is initialized in `ChatListItemRenderer` in src/vs/workbench/contrib/chat/browser/widget/chatListRenderer.ts (around line 2960), so `shouldAnimateInitialCollapse`/initial `details.open` respects the user preference instead of always starting collapsed.
