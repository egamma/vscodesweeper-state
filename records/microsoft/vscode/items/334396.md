# Issue #334396 — Add an option to expand "Completed N steps" by default

[https://github.com/microsoft/vscode/issues/334396](https://github.com/microsoft/vscode/issues/334396)

## Summary

The requested option already exists: setting `chat.agent.collapseCompletedResponses` to `false` leaves completed intermediate work expanded, so this can close as already supported.

## Change summary

Provide a preference that keeps the "Completed N steps" content expanded after an agent response finishes.

## Best solution

Keep the existing `chat.agent.collapseCompletedResponses` setting and direct users who prefer expanded intermediate work to set it to `false`.
