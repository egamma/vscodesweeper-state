# Issue #285171 — `#problems` can return stale values in chat

[https://github.com/microsoft/vscode/issues/285171](https://github.com/microsoft/vscode/issues/285171)

## Summary

Team members tried to reproduce the stale diagnostics but could not; the issue has been dormant for over 6 months with no confirmed repro steps, and the existing diagnosticsChanged push notification mechanism (with a 200ms debounce) is already in place on current main.

## Change summary

The `#problems` chat context variable can return stale diagnostics that were already fixed, because the language server hasn't yet pushed updated diagnostics by the time the tool reads them.

## Best solution

Close as not-reproducible given the team's inability to reproduce and 6+ months of inactivity. If the timing race recurs, a new issue with deterministic repro steps would be needed — the underlying architecture limitation (push vs pull diagnostics for the extension API) is tracked separately and the existing `diagnosticsChanged` notification with debouncing is already implemented in `extensions/copilot/src/extension/chatSessions/copilotcli/vscode-node/tools/push/diagnosticsChanged.ts`.
