# Issue #336175 — Product icon font does not scale in smart completion popups with editor/terminal zoom

[https://github.com/microsoft/vscode/issues/336175](https://github.com/microsoft/vscode/issues/336175)

## Summary

Reproducible in the source: the suggest widget's kind icon and status text don't participate in the font-zoom scaling that the label text gets, which explains the reported cut-off/oversized icons. Not old or discussed yet, so this is a straightforward route-to-area rather than a close.

## Change summary

In the editor and terminal smart-completion popups, the product/kind icon (and the 'Insert (↵)' status text) do not scale when the user zooms the editor/terminal font in or out, while the completion label text does.

## Best solution

In SuggestWidgetRenderer.configureFont() (src/vs/editor/contrib/suggest/browser/suggestWidgetRenderer.ts), also size the `.suggest-icon` container (and the terminal completions equivalent) relative to the computed suggestFontSize/lineHeight so the codicon glyph scales with the widget instead of staying pinned to codicon.css's hardcoded 16px; the status bar's 'Insert (↵)' hint likely needs the same treatment in suggestWidgetStatus.ts.
