# Issue #336175 — Product icon font does not scale in smart completion popups with editor/terminal zoom

[https://github.com/microsoft/vscode/issues/336175](https://github.com/microsoft/vscode/issues/336175)

## Summary

The current source still sizes completion text independently of product-icon glyphs in both editor and terminal suggestions. Keep this open: the scaling mismatch is identifiable, but the intended icon and secondary-label sizing across zoom levels needs agreement before implementation.

## Change summary

Prevent completion icons and the Insert hint from becoming inconsistently sized or clipped when editor or terminal font zoom changes.

## Best solution

Make both suggestion surfaces remain readable and unclipped across supported font sizes while preserving the hierarchy between completion text, icons, and secondary hints. Agree on how those secondary elements should respond to local font zoom, then cover both renderers with browser-level sizing checks.
