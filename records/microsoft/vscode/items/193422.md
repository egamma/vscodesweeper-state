# Issue #193422 — Avoid unnecessary repaint in minimap during typing

[https://github.com/microsoft/vscode/issues/193422](https://github.com/microsoft/vscode/issues/193422)

## Summary

Still reproduces on main: every keystroke triggers `onSelectionChanged`, which sets `_renderDecorations = true` and causes the decorations canvas to be fully cleared and redrawn via `clearRect` on the entire surface. No delta/incremental decoration rendering has been implemented.

## Change summary

Minimap decorations canvas is fully cleared and repainted on every keystroke because the cursor-move event triggers a full decoration re-render, causing unnecessary repaints visible under Chromium paint flashing.

## Best solution

Implement a delta rendering approach for the minimap decorations canvas (in `InnerMinimap.renderDecorations` in `src/vs/editor/browser/viewParts/minimap/minimap.ts`): track what was rendered in the previous frame and only touch the changed regions, similar to how the text layer already uses `putImageData` for incremental updates. Alternatively, skip `_renderDecorations` when only the cursor position changed within the same line and no decoration actually changed.
