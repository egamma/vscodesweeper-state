# Issue #242209 — Copy Selected Text In Cell Does Not Work

[https://github.com/microsoft/vscode/issues/242209](https://github.com/microsoft/vscode/issues/242209)

## Summary

Thanks for the report. Two other users confirm the same error on both local and remote setups. The command `editor.action.clipboardCopyAction` is registered in `src/vs/editor/contrib/clipboard/browser/clipboard.ts`, so the error probably comes from a context where the editor contribution isn't loaded, such as a webview or markdown preview. I couldn't pin down the trigger without running it, and the report is on 1.96.4, so it needs a retest on a current build.

## Change summary

Running the copy keybinding with selected text in a notebook cell shows "Contributed command 'editor.action.clipboardCopyAction' does not exist" instead of copying.

## Best solution

Find the focus context where the keybinding fires without the editor clipboard contribution loaded, then make copy work there or fall back to the native copy.
