Keep open: the supplied steps are sufficient to retest the narrow Debug Console header. Current main already has conditional filter relocation and toolbar-aware tab sizing, but source inspection alone does not establish whether these prevent the reported overlap.

## Change summary

Prevent panel tabs, the Debug Console filter, search action, and session picker from overlapping when the panel becomes narrow.
