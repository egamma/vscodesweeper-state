# Issue #229643 — SCM Graph - Unsure how to tell when graph is locked to a repository

[https://github.com/microsoft/vscode/issues/229643](https://github.com/microsoft/vscode/issues/229643)

## Summary

Keep open: the graph still displays the repository name without distinguishing automatic following from an explicitly selected repository. The maintainer acknowledged the picker inconsistency, and neither a referenced fix nor an eligible canonical duplicate was found for this team-authored Backlog item.

## Change summary

Make the SCM Graph's automatic versus explicitly selected repository mode distinguishable from the independent history-reference filter.

## Best solution

Provide a clear, consistent indication of repository-selection mode in the SCM Graph title controls, while retaining the resolved repository name and existing selection behavior. The SCM owner should settle the affordance without conflating repository Auto mode with the history-reference picker's Auto filter.
