# Issue #150837 — On save: Unable to write file, Cannot read properties of undefined (reading 'lineStarts')

[https://github.com/microsoft/vscode/issues/150837](https://github.com/microsoft/vscode/issues/150837)

## Summary

The defect remains in current main: a snapshot retains old pieces but reads them through mutable tree buffers that `setEOL` can replace. The existing `editor-textbuffer` routing is correct.

## Change summary

Saving can fail with an undefined `lineStarts` access when EOL normalization invalidates a live piece-tree snapshot.

## Best solution

Give `PieceTreeSnapshot` stable access to the buffers backing its captured pieces across EOL normalization, then add a regression test that creates a snapshot, changes EOL, and reads the original snapshot successfully.
