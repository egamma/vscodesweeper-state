[https://github.com/microsoft/vscode/issues/346454](https://github.com/microsoft/vscode/issues/346454)

## Summary

Keep open as a distinct permission-handling feature request. Existing command auto-approval does not establish temporary-file ownership, and the linked open draft proposal needs maintainer review rather than a competing implementation.

## Change summary

Allow policy-compliant cleanup of verified temporary workspace files created by Copilot during the current task without repeated approvals.

## Best solution

Evaluate the ownership-scoped cleanup contract and the candidate implementation at https://github.com/nbauma109/vscode/pull/1. Any accepted behavior should preserve enterprise restrictions and require approval when file ownership or temporary status cannot be established.
