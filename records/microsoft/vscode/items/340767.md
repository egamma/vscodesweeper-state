# Issue #340767 — Excessive upload traffic and reduced command visibility in VS Code 1.141.0

[https://github.com/microsoft/vscode/issues/340767](https://github.com/microsoft/vscode/issues/340767)

## Summary

Thanks for the report. The report is concrete: it names the version, the symptom (upload about 4x download during local agent sessions, and slower task completion), and the trigger (while the agent is working). It also raises an accessibility gap, since agent command activity is shown in Chat rather than the Terminal. I did not run the code or inspect network traffic, so I could not confirm or refute either point. The issue is kept open so a maintainer can retest and route it. Upload volume is plausibly explained by agent requests re-sending conversation context to the model, but that is unverified.

## Change summary

Local Copilot agent sessions in 1.141.0 upload much more data than before and run slower, and the user (a blind developer) cannot easily inspect which commands the agent runs.

## Best solution

Confirm whether the agent request payloads, such as context or tool output, grew in 1.141.0, and measure the upload. Separately, make sure the agent's executed commands are discoverable to screen-reader users in the Chat UI (accessible view or terminal output), and consider documenting what the agent sends.
