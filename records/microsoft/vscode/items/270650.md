# Issue #270650 — Copilot Agent prompts fail when chat.useNestedAgentsMdFiles is enabled with SSH FS folders

[https://github.com/microsoft/vscode/issues/270650](https://github.com/microsoft/vscode/issues/270650)

## Summary

The bug is confirmed and should remain open: enabling nested AGENTS.md discovery can block prompt submission when a workspace folder uses an SSH filesystem without a search provider. A maintainer identified the cause and the intended fallback, while the Backlog milestone does not bar normal triage.

## Change summary

Make Copilot Agent prompt submission continue when nested AGENTS.md discovery encounters an SSH-backed workspace folder without a registered search provider.

## Best solution

Fall back to ordinary file access for nested AGENTS.md discovery when the workspace scheme has no search provider, while preserving the existing search-provider path for supported schemes and avoiding automatic setting changes or new status-bar UI.
