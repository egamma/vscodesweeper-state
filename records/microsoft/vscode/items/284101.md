# Issue #284101 — Rename: manual trigger sparkle should probably replace other than insert

[https://github.com/microsoft/vscode/issues/284101](https://github.com/microsoft/vscode/issues/284101)

## Summary

Still present on main: manually re-triggering the rename sparkle inserts new candidates into the list rather than replacing existing ones, because `setCandidates` splices with 0 deletions. Team-authored polish item, keeping open.

## Change summary

When manually re-triggering the rename sparkle button, new AI suggestions should replace existing ones rather than being appended.

## Best solution

In `src/vs/editor/contrib/rename/browser/renameWidget.ts`, the `setCandidates` method (line 740) should clear the existing list items before inserting new ones — change `splice(0, 0, candidates)` to `splice(0, this._listWidget.length, candidates)`, and also clear the `_candidates` Set in `_updateRenameCandidates` when re-triggered manually so dedup doesn't filter out re-fetched names.
