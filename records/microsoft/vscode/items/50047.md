# Issue #50047 — Feature request: Allow Code Outline in Minimap location

[https://github.com/microsoft/vscode/issues/50047](https://github.com/microsoft/vscode/issues/50047)

## Summary

This remains a valid Backlog feature request with 44 community upvotes. The secondary side bar provides a useful workaround, but it does not provide the requested per-editor outline beside each editor.

## Change summary

Allow each editor's minimap area to display an outline or another navigation widget instead of the minimap.

## Best solution

Provide an optional editor-local outline accessory in the minimap region, designed to remain usable with narrow or multiple editor groups. Preserve the existing movable Outline view as the workspace-level alternative.
