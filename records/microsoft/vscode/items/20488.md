# Issue #20488 — [html] prevent that embedded grammars can corrupt syntax highlighting of rest of document

[https://github.com/microsoft/vscode/issues/20488](https://github.com/microsoft/vscode/issues/20488)

## Summary

Still a real gap — the fundamental TextMate grammar limitation for embedded languages remains. VS Code's tree-sitter work (which would properly solve this via language injection) is experimental and does not yet cover HTML. The issue is correctly labeled `upstream` and parked in Backlog.

## Change summary

Embedded grammars (CSS/JS in HTML) can corrupt syntax highlighting of the rest of the document when the embedded code is incomplete.

## Best solution

The long-term fix is tree-sitter with language injection for HTML, which would inherently scope embedded regions. VS Code has experimental tree-sitter for CSS/TypeScript but not HTML yet. Until then, the `while` rule workaround helps individual grammar authors but doesn't solve the general case. Keep open as the canonical tracking issue for this TextMate limitation.
