# Issue #339904 — Compare model picker loses context picker, thinking effort picker, and discount badges

[https://github.com/microsoft/vscode/issues/339904](https://github.com/microsoft/vscode/issues/339904)

## Summary

Team-authored, freshly-filed bug confirmed in source: the model picker's 'Compare Models' workflow branch renders a stripped-down item that skips badges, org-default badges, and the config-summary/details action that normal entries get, so the context picker, thinking-effort picker, and discount badges disappear while comparing models.

## Change summary

In the Agents Window model picker's Compare Models mode, entries render without the context-window picker, thinking-effort picker, and discount badges that the regular model picker shows.

## Best solution

In TabbedModelPicker._createModelItem (src/vs/workbench/contrib/chat/browser/widget/input/modelPicker/modelPickerTabbedWidget.ts), extend the `workflow && step` branch to also compute badge/additionalBadges/toolbarActions (details action) like the normal branch does, while keeping the checkbox select-on-click behavior for the comparison workflow.

- **Trace:**
