# Issue #327261 — Don't silently swallow "failed to delete" Worktree error

[https://github.com/microsoft/vscode/issues/327261](https://github.com/microsoft/vscode/issues/327261)

## Summary

The failure is conclusively present on main: archiving continues after worktree deletion fails, exposing the error only in logs. Route this team-authored bug to the Agent Host and Agents Window owners to define and implement the user-facing failure state.

## Change summary

Surface worktree deletion failures when marking an agent session as done instead of only logging a warning.

## Best solution

Propagate a structured cleanup failure from the Agent Host archive operation and present it in the Agents Window, ideally with the retained worktree path and a retry or manual-cleanup action.
