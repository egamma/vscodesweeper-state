# Issue #347195 — Copilot Agent edit/review functionality fails for files on UNC network paths

[https://github.com/microsoft/vscode/issues/347195](https://github.com/microsoft/vscode/issues/347195)

## Summary

Keep open: the discussion confirms a harness-specific UNC access failure that also blocks normal edit review. Switching to Local restores the workflow, but is a workaround rather than evidence that the Copilot harness is fixed.

## Change summary

Copilot Agent rejects UNC-hosted files accessible to the editor, preventing highlighted changes and Keep/Undo review.

## Best solution

Establish supported, explicitly authorized UNC access in the Copilot harness while preserving network-access restrictions, and verify the complete read/edit/review workflow. Diagnose the runtime-versus-host enforcement boundary before deciding whether existing host approval should apply or a separate authorization mechanism is needed.
