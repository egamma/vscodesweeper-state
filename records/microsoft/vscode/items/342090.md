# Issue #342090 — Setting a long delay for extension auto update delay (like 2 weeks) prevents update of frequently update extensions

[https://github.com/microsoft/vscode/issues/342090](https://github.com/microsoft/vscode/issues/342090)

## Summary

Keep open: current source still gates automatic updates using the extension-wide timestamp, and frequently published versions can continually postpone eligibility. The Marketplace confirmation strengthens the report; resolving same-channel starvation also requires settling version-selection behavior.

## Change summary

Prevent frequent extension publications from indefinitely delaying automatic updates, including stable updates held back by newer pre-releases.

## Best solution

Make update eligibility reflect the actual candidate version's publication age. Establish whether automatic updates should select the newest compatible, channel-appropriate version outside the delay window when the latest version is still too young.
