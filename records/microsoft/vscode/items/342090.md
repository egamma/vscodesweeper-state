# Issue #342090 — Setting a long delay for extension auto update delay (like 2 weeks) prevents update of frequently update extensions

[https://github.com/microsoft/vscode/issues/342090](https://github.com/microsoft/vscode/issues/342090)

## Summary

The starvation path remains in current source: each newer gallery version can reset the delay, and automatic updates skip the extension without considering older eligible releases. Keep this open; resolving it requires more than changing the timestamp field.

## Change summary

Prevent frequent extension publications from indefinitely postponing automatic updates when a long update delay is configured.

## Best solution

Automatic updates should continue progressing through compatible releases that have satisfied the configured publication-age delay, even while newer releases are published. Preserve the waiting period rather than eventually installing an insufficiently aged latest release.
