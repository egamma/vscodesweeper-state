# Issue #293255 — Issues in copilot chat Claude agent UI

[https://github.com/microsoft/vscode/issues/293255](https://github.com/microsoft/vscode/issues/293255)

## Summary

The provider-specific picker is correct when opened directly, but the keyboard command still routes through the last core chat widget rather than the active Agents composer. This can expose an unrelated local picker or do nothing, so the reported input-path inconsistency remains.

## Change summary

Opening the model picker by keyboard in a Claude agent session should show the same provider-filtered models as clicking the picker.

## Best solution

Make the model-picker keyboard command target the focused Agents composer and its input-scoped picker, while preserving the existing command behavior in regular Chat surfaces.
