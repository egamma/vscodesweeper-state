# Issue #324136 — Agent Host: bring back granular "sticky" terminal auto-approve controls (allow for session / always allow exact command line)

[https://github.com/microsoft/vscode/issues/324136](https://github.com/microsoft/vscode/issues/324136)

## Summary

Well-diagnosed, real gap confirmed in the checkout: the Agent Host's shell auto-approver has no session-sticky or exact-command-line persistence like the workbench's `_getSessionRules`; already correctly labeled (agent-host, terminal-auto-approve, on-testplan), so this should simply stay open for implementation.

## Change summary

Add granular sticky terminal auto-approve controls to Agent Host (allow-for-session and always-allow-exact-command-line), mirroring the workbench's session-scoped rules.

## Best solution

Extend `src/vs/platform/agentHost/node/sessionPermissions.ts` / `commandAutoApprover.ts` with a session-scoped command-line rule store analogous to `_getSessionRules` in the workbench's `commandLineAutoApprover.ts`, and add a persistence path for 'always allow exact command line' into `chat.tools.terminal.autoApprove`; the 'allow all in session' option needs explicit alignment with the permission/risk model as the author notes.
