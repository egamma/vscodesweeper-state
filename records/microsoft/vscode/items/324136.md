# Issue #324136 — Agent Host: bring back granular "sticky" terminal auto-approve controls (allow for session / always allow exact command line)

[https://github.com/microsoft/vscode/issues/324136](https://github.com/microsoft/vscode/issues/324136)

## Summary

Team-authored feature request for granular, command-level session-scoped terminal auto-approve in the Agent Host. Current AH session permissions only track tool-level grants (the whole 'shell' tool), not per-command-line sticky rules. The workbench side has richer session-rule support that the AH side lacks. Keeping open — real gap remains.

## Change summary

Add session-scoped and persistent per-command-line auto-approve controls to the Agent Host terminal approval flow, matching the granularity the workbench auto-approver already offers.

## Best solution

Extend `SessionPermissionManager._addToolToSessionPermissions` in `src/vs/platform/agentHost/node/sessionPermissions.ts` and `CommandAutoApprover` in `src/vs/platform/agentHost/node/commandAutoApprover.ts` to support session-scoped command-line rules (mirroring the workbench's `_getSessionRules` pattern) and an 'always allow exact command line' option that persists rules to `chat.tools.terminal.autoApprove`. Coordinate the 'allow all commands in session' option with the permissions / risk-assessment team before wiring it up.
