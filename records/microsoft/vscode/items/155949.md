# Issue #155949 — Conflict and change traversal buttons have the same icons in the compare changes view.

[https://github.com/microsoft/vscode/issues/155949](https://github.com/microsoft/vscode/issues/155949)

## Summary

The reported duplicate navigation controls remain explainable from current source: Compare Changes opens a synthetic diff, but conflict-navigation visibility retains context from the original file. Keep this accepted bug open; the maintainer's diagnosis still applies.

## Change summary

Compare Changes shows indistinguishable conflict and diff navigation buttons, requiring hover to identify their purpose.

## Best solution

Make conflict-navigation visibility reflect the active editor's actual conflict markers, so comparison documents do not inherit irrelevant controls. Preserve normal diff navigation and conflict navigation in the original file; this does not require rewriting the whole extension.
