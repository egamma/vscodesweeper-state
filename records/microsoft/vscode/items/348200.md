## Summary

The reported eager restore and first-send restart remain possible in current source. Keep this open: an existing draft PR addresses a related restore-time plugin omission, but its coverage assumes the client already published its plugins and does not establish a fix for this ordering.

## Change summary

Avoid redundant SDK restoration when a returning window publishes its synced plugins after session history loads.

Preserve legitimate configuration restarts and explicit canvas activation.
