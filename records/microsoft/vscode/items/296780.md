# Issue #296780 — Bug Report feature fails if user is not already signed into GitHub in a browser

[https://github.com/microsoft/vscode/issues/296780](https://github.com/microsoft/vscode/issues/296780)

## Summary

The 500 error occurs on GitHub.com's login/2FA flow, not in VS Code. VS Code's issue reporter simply opens a pre-filled URL in the user's default browser (via `openLink`); the authentication failure is entirely server-side on GitHub.com and outside VS Code's control.

## Change summary

User gets a GitHub 500 error during sign-in/2FA when filing an issue from VS Code's built-in issue reporter while not already logged into GitHub in their browser.

## Best solution

This is a GitHub.com server-side authentication issue. The reporter should contact GitHub Support (https://support.github.com) if the 500 error persists, or try signing into GitHub in their browser first before using the issue reporter.
