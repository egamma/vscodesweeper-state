# Issue #327036 — Modern UI - Double border for the integrated browser

[https://github.com/microsoft/vscode/issues/327036](https://github.com/microsoft/vscode/issues/327036)

## Summary

Valid visual bug — the integrated browser's container border (rendered via a `::before` pseudo-element in `browser.css`) likely doubles up with the editor pane's own border under the Modern UI refresh. No fix has landed on main since the report was filed, and the existing `browser-integration` and `modernization` labels are correct routing.

## Change summary

The integrated browser editor pane shows a double border under the Modern UI theme.

## Best solution

Adjust the browser container's border rendering in `src/vs/workbench/contrib/browserView/electron-browser/media/browser.css` (the `::before`/`::after` pseudo-elements on `.browser-container`) to account for the pane-level border that the Modern UI refresh introduces, so only one border is visible.
