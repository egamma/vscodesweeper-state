# Issue #245405 — API to save a non-active document without formatting

[https://github.com/microsoft/vscode/issues/245405](https://github.com/microsoft/vscode/issues/245405)

## Summary

The non-active-document save API gap remains on current main. Keep this accepted Backlog request open while its explicitly linked, still-open implementation proposal is reviewed; the older overlapping request should inform that review.

## Change summary

Allow extensions to save an arbitrary TextDocument without running formatting or other save participants.

## Best solution

Review https://github.com/microsoft/vscode/pull/245406 to settle the public save-options contract, including proposal gating and tests, while addressing the maintainer's concern about disk-save side effects. Coordinate the API decision with https://github.com/microsoft/vscode/issues/221614, which requests the same capability for document.save and workspace.save.
