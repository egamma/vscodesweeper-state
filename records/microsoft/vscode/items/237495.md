[https://github.com/microsoft/vscode/issues/237495](https://github.com/microsoft/vscode/issues/237495)

## Summary

Still reproduces on main: the notebook outline renderer unconditionally renders icons without checking the `outline.icons` setting, unlike the regular document symbols outline which gates icon rendering on that config value.

## Change summary

Setting `outline.icons` to `false` has no effect on notebook outline icons — they are always shown.

## Best solution

Guard the icon-rendering block in `NotebookOutlineRenderer.renderElement` (src/vs/workbench/contrib/notebook/browser/contrib/outline/notebookOutline.ts, ~lines 112-120) with a `this._configurationService.getValue(OutlineConfigKeys.icons)` check, mirroring the pattern in `DocumentSymbolsTree.ts` line 221.
