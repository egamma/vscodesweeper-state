# Issue #208771 — Debt: Do not hardcode menu height when activity bar bottom

[https://github.com/microsoft/vscode/issues/208771](https://github.com/microsoft/vscode/issues/208771)

## Summary

The debt remains on current main: compact menus opening above the bottom activity bar still assume every menu row is 30 pixels tall. The source retains an explicit TODO for this issue, and no commit referencing it or older canonical issue was found.

## Change summary

Remove the hardcoded menu-row height used to position the compact menu above a bottom-positioned activity bar.

## Best solution

Position the upward-opening compact menu from its rendered dimensions so differing action counts, row heights, zoom levels, and additional compact actions cannot misalign it.
