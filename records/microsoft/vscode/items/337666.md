# Issue #337666 — 1.139 can not see Use Dev Container menu for remote host

[https://github.com/microsoft/vscode/issues/337666](https://github.com/microsoft/vscode/issues/337666)

## Summary

Keep open as a release regression affecting remote Dev Container session selection. The current source intends to support SSH hosts, but the report postdates that implementation and there is no issue-linked fix; because this is team-authored, the unclear reproduction does not justify an info-needed or judgment close.

## Change summary

The Agents workspace picker offers Use Dev Container for a local checkout but omits it for an SSH-hosted checkout of the same repository.

## Best solution

Reproduce the 1.139 SSH flow and determine which remote availability prerequisite is failing, then preserve the Use Dev Container action whenever the connected SSH host advertises Dev Container support, has Docker available, and the selected folder contains a Dev Container configuration. Add regression coverage for the actual failing provider or connection state.
