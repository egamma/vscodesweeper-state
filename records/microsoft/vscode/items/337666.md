# Issue #337666 — 1.139 can not see Use Dev Container menu for remote host

[https://github.com/microsoft/vscode/issues/337666](https://github.com/microsoft/vscode/issues/337666)

## Summary

Team-authored bug report (hard keep-open) about the new experimental `chat.agentHost.devContainer.enabled` feature; source tracing shows a plausible root cause in the SSH availability check, but this stays open regardless since no fix commit referencing this 1-day-old issue exists.

## Change summary

With `chat.agentHost.devContainer.enabled` on, the workspace picker's 'Use Dev Container' menu appears for local workspaces but not for an SSH remote host with the same devcontainer config.

## Best solution

Trace whether DevContainerAgentHostConnector.isAvailable() in devContainerAgentHostConnector.contribution.ts requires an already-established remote connection (via remoteAgentHostService.getConnection) rather than connecting on demand like resolveDevContainerSourceConnection does — if so, that's why the menu never appears for an unconnected SSH host, and the fix is to make availability-checking also attempt/wait for a connection (or surface the gating reason to the picker).
