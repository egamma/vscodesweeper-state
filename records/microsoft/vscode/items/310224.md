Establish a repeatable failing case before choosing regression coverage.
- **Behavior:**

  > After connecting to a supported Linux host through Remote-SSH and opening a folder containing one Git repository, built-in Git integration should initialize and show repository changes. An update must not leave Source Control indefinitely displaying scanning while the Git output channel is absent. The thread confirms this failure on 1.116.0 and reports rollback or remote-server reinstallation as recovery paths. The planning session should first establish whether the same failure persists on a current build.
- **Trace:**

The incomplete remote node_modules explanation in https://github.com/microsoft/vscode/issues/310224 is unverified, and the trace does not yet identify the installer failure or a defective source branch.
