# Issue #338088 — Add guard clause for API key validation in AzureOpenAIEndpoint

## Summary

Valid, well-scoped defensive-programming suggestion: `getExtraHeaders()` in AzureOpenAIEndpoint and its parent OpenAIEndpoint build auth headers from `this._apiKey`/token without checking it's set. An open PR (#338089) from the same author already implements this guard clause, so the issue should stay open until that PR lands rather than being auto-fixed again.
