# Issue #241201 — Github Authentication Fails When Using SOCKS5 Proxy in `http.proxy` (Invalid URL Protocol)

[https://github.com/microsoft/vscode/issues/241201](https://github.com/microsoft/vscode/issues/241201)

## Summary

Genuine upstream limitation: Node.js/undici's fetch does not support SOCKS proxies. VS Code switched to Electron's fetch in 1.97.0 (commit 87ed97df), which surfaces this gap. The issue is correctly labeled `upstream` and `proxy`, and remains unresolved on current main — no fix or workaround beyond disabling `http.fetchAdditionalSupport`.

## Change summary

GitHub authentication (and other fetch-based requests) fails with SOCKS5 proxy URLs because undici's fetch only supports HTTP/HTTPS proxy protocols.

## Best solution

The root fix lives in nodejs/undici (https://github.com/nodejs/undici/issues/2224) adding SOCKS proxy support to fetch. On the VS Code side, the proxy resolver in `src/vs/workbench/api/node/proxyResolver.ts` could potentially detect a SOCKS proxy URL and fall back to the non-fetch path, or VS Code could document the `http.fetchAdditionalSupport: false` workaround more prominently. Keep tracking the undici issue.
