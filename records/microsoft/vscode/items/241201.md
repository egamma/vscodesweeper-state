# Issue #241201 — Github Authentication Fails When Using SOCKS5 Proxy in `http.proxy` (Invalid URL Protocol)

[https://github.com/microsoft/vscode/issues/241201](https://github.com/microsoft/vscode/issues/241201)

## Summary

Keep open as an upstream-tracked regression: multiple users confirm that SOCKS5 remains unsupported or disrupted on current releases, and the maintainer identified missing undici support as the blocker.

## Change summary

Restore GitHub authentication and other fetch-based networking through SOCKS5 proxies configured via `http.proxy`, system settings, or `--proxy-server`.

## Best solution

Track https://github.com/nodejs/undici/issues/2224 and preserve a documented fallback where possible; once undici supports SOCKS proxies, adopt that support in VS Code's Electron/Node fetch proxy path and validate GitHub authentication, Copilot, and MCP requests.
