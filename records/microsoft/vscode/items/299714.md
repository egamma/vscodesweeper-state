# Issue #299714 — Feature Request: Auto-expand or remember toggle state of "> Other Models" in Chat Picker

[https://github.com/microsoft/vscode/issues/299714](https://github.com/microsoft/vscode/issues/299714)

## Summary

The 'Other Models' section is hardcoded as collapsed by default with no persistence or setting to override it — the feature request is still valid and unimplemented on current main.

## Change summary

Request to auto-expand or remember the toggle state of the 'Other Models' section in the chat model picker.

## Best solution

Either persist the last toggled state of the 'Other Models' section across picker opens (via storage service), or add a setting like `chat.modelPicker.expandOtherModels` to keep it expanded by default. The change would be localized to `src/vs/workbench/contrib/chat/browser/widget/input/chatModelPicker.ts` around the `collapsedByDefault` option.
