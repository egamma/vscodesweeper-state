# Issue #309761 — Disabling extension-provided AI tools still leaves extension skills active for agent routing

[https://github.com/microsoft/vscode/issues/309761](https://github.com/microsoft/vscode/issues/309761)

## Summary

Keep open as a request for consistent control over extension-contributed AI capabilities. Current source exposes skill-disable actions only for built-in-source skills, leaving the reported extension-skill control gap; tool-to-skill coupling is not an established contract.

## Change summary

Allow users to stop an enabled extension's skills from influencing agent routing, either independently or alongside its disabled AI tools.

## Best solution

Provide an explicit way to disable extension-contributed skills without disabling the extension's non-AI functionality. Decide whether tool selection should also affect skills rather than implicitly assuming every skill depends on that extension's tools.
