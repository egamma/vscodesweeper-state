# Issue #309761 — Disabling extension-provided AI tools still leaves extension skills active for agent routing

[https://github.com/microsoft/vscode/issues/309761](https://github.com/microsoft/vscode/issues/309761)

## Summary

Valid feature request: extension-provided AI tools and plugin skills have independent enablement systems, so disabling tools does not cascade to skills. The gap is confirmed by the code architecture — no duplicate found.

## Change summary

Disabling an extension's AI tools should also disable (or provide a toggle for) that extension's contributed skills to prevent agent routing to unavailable tool paths.

## Best solution

Either cascade tool-set disablement from `IAgentHostToolSetEnablementService` to filter out skills whose parent tool set is disabled, or add per-skill enablement toggles in the Chat Customizations UI. The coordination would likely live where the active-client service assembles the tool/skill manifest for a session (around `agentHostActiveClientService.ts`).
