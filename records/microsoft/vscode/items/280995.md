# Issue #280995 — prompt file (slash command) won't use intended agent if run with "run in new chat"

[https://github.com/microsoft/vscode/issues/280995](https://github.com/microsoft/vscode/issues/280995)

## Summary

The defect remains on current main: Send to New Chat submits the saved prompt as a programmatic query after clearing the input, but prompt-file metadata is resolved from the now-empty current input. The intended custom agent is therefore never selected.

## Change summary

Running a prompt-file slash command with Ctrl+Shift+Enter should retain the prompt's configured agent in the new chat.

## Best solution

Preserve prompt-file parsing and metadata application when transferring an input to a new chat, so the prompt's configured agent, tools, and model are applied before the request is sent.
