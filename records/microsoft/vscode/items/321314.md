The missing-goal defect remains in current source: Advanced Autopilot evaluates the handoff text and current implementation rounds without including the preceding user requirement or Plan response. Keep this open; the supplied workflow is sufficient and the prompt-construction defect is confirmed.

## Change summary

Preserve the actual planning requirement and relevant plan context when evaluating completion after an Autopilot handoff.

## Best solution

Keep this bounded to evaluator context construction and preserve ordinary requests and existing continuation decisions.
