# Issue #321314 — Bug: Advanced Autopilot goal evaluation only gets "Start implementation" as original request

[https://github.com/microsoft/vscode/issues/321314](https://github.com/microsoft/vscode/issues/321314)

## Summary

Confirmed on current main: Plan handoffs replace the request with “Start implementation,” and the Advanced Autopilot classifier incorrectly treats that handoff text as the original goal.

## Change summary

Preserve the preceding Plan request and plan response when evaluating whether an Autopilot implementation completed its goal.

## Best solution

Build the classifier's goal context from the preceding Plan conversation turn when handling an implementation handoff, while retaining the current request for direct Autopilot sessions. Add regression coverage for the Plan-to-Autopilot path.
