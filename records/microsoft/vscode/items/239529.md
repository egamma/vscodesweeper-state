# Issue #239529 — When using "Open File on Remote From" the code lines selected are not preserved

[https://github.com/microsoft/vscode/issues/239529](https://github.com/microsoft/vscode/issues/239529)

## Summary

Still reproduces on main: `openVscodeDevLink` in the GitHub extension does not pass `useRange: true` to `getLink`, so line selections are dropped when opening on vscode.dev. The copy-link variant works correctly.

## Change summary

Opening a file on vscode.dev via the context menu does not preserve the selected line range in the generated URL.

## Best solution

Pass `true` for the `useRange` parameter in `openVscodeDevLink` (extensions/github/src/commands.ts line 29) to match the behavior of `copyVscodeDevLink`.
