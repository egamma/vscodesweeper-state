# Issue #47331 — [html][css] Investigate cross css/html, multi file support

[https://github.com/microsoft/vscode/issues/47331](https://github.com/microsoft/vscode/issues/47331)

## Summary

Team-authored feature request with strong community demand (72 upvotes). The HTML and CSS language servers are still separate on current main, and none of the described cross-file IntelliSense capabilities have been implemented. The open Volar integration PR (https://github.com/microsoft/vscode/pull/171547) is a potential implementation path but has not merged. Keeping open.

## Change summary

Merge the HTML and CSS language servers to provide cross-file, cross-language IntelliSense for class names, IDs, and CSS variables across HTML and CSS/LESS/SCSS files.

## Best solution

Land the Volar-based HTML extension integration (https://github.com/microsoft/vscode/pull/171547) or an equivalent architecture that merges the HTML and CSS language understanding into a single server, enabling workspace-wide class/ID completions, go-to-definition, and references across file boundaries. The open PR is the most promising vehicle — reviewing and landing it would deliver most of the requested capabilities.
