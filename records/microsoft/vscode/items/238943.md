# Issue #238943 — Quick open can appear out of view with multiple window sizes

[https://github.com/microsoft/vscode/issues/238943](https://github.com/microsoft/vscode/issues/238943)

## Summary

Keep open: current quick-input positioning mixes border-box and client dimensions, leaving a source-reproducible path for a bordered picker to extend beyond the smaller window. The issue already has the appropriate quick-pick area label.

## Change summary

Keep a dragged Quick Open widget fully within the window when its saved position is restored in a smaller window.

## Best solution

Make restored Quick Open positioning respect the widget's complete visible bounds, including its border, across differently sized windows. Preserve existing dragging, snapping, and position persistence semantics.
