Valid performance-oriented feature request with an open PR (#326333) from the author. ## Change summary

Allow webviews on Electron to load via a single iframe without service workers, improving load time and avoiding service-worker registration errors.

## Best solution

Review and iterate on PR https://github.com/microsoft/vscode/pull/326333 — it introduces a proposed `webviewNoServiceWorker` API for opt-in adoption by extensions. The architectural change is significant (touches webview protocol provider, resource loading, and extension API surface) and needs careful review for security (CSP, resource isolation) and backward compatibility before merging.
