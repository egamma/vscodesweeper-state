# Issue #212425 — Open files in new window BUT reveal (existing window) if already open

[https://github.com/microsoft/vscode/issues/212425](https://github.com/microsoft/vscode/issues/212425)

## Summary

A real capability gap remains on main, and the request was accepted into the Backlog after receiving 29 community upvotes. Existing settings cannot both prefer new windows and reveal a file already open in another window.

## Change summary

When an externally opened file is already open, focus its existing window instead of creating another window despite `window.openFilesInNewWindow` being enabled.

## Best solution

Extend main-process window selection in `windowsMainService.ts` to locate and focus a window already displaying the requested file before applying the new-window preference, without changing how unrelated files are opened.
