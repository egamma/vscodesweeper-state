# Issue #277596 — Chat: Make linkification for URLs found in subagents

[https://github.com/microsoft/vscode/issues/277596](https://github.com/microsoft/vscode/issues/277596)

## Summary

Still open on main: linkification is explicitly disabled for subagent requests (line 267 of defaultIntentRequestHandler.ts). The issue requests enabling it, and commit 4376f533b94 actually moved further away by intentionally disabling it — likely to avoid issues with the constraint that only previously-read files are linkified, which the issue body describes.

## Change summary

File and symbol references in chat subagent responses are not linkified, making plan-mode output less navigable.

## Best solution

Relax the linkification constraint so subagent-produced file/symbol references can be resolved and linked, possibly by expanding the set of known files beyond just previously-read ones, or by performing a workspace-wide symbol lookup for references in subagent output. The fix lives in `extensions/copilot/src/extension/prompt/node/defaultIntentRequestHandler.ts` around the linkification gate at line 267.
