## Summary

Keep open for a dismissal-interaction decision: the MCP command input deliberately survives focus loss, allowing Escape to target the underlying modal after an outside click. The maintainer explains that configuration but does not resolve the interaction concern; this team-authored issue is protected from an as-designed close.

Clarify and improve dismissal behavior when the MCP command input loses focus above a modal customization editor.
