# Issue #317187 — Token usage always shows 0 for models added via LanguageModelChatProvider extension API

[https://github.com/microsoft/vscode/issues/317187](https://github.com/microsoft/vscode/issues/317187)

## Summary

Genuine API gap: the `LanguageModelResponsePart` union type has no usage/token part, so extensions implementing `LanguageModelChatProvider` cannot report token usage back to VS Code. An open community PR already addresses this — keep open until it lands or an alternative ships.

## Change summary

Extensions using the `LanguageModelChatProvider` API cannot report token usage because no `LanguageModelResponsePart` variant exists for usage data.

## Best solution

Add a `LanguageModelUsagePart` (or equivalent) to the `LanguageModelResponsePart` union so extension-contributed models can report prompt/completion token counts through `progress.report()`. The open PR https://github.com/microsoft/vscode/pull/319686 is a community implementation candidate — review and land it (or a team-authored alternative) to close the gap.
