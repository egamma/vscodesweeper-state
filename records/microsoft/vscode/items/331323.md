# Issue #331323 — Image hovers are off

[https://github.com/microsoft/vscode/issues/331323](https://github.com/microsoft/vscode/issues/331323)

## Summary

Team member reports the chat image-attachment hover preview sizes images incorrectly (too small/cropped for large images, oversized box for small ones) while testing the Codex image-generation test plan item (#330903) — a real, freshly-observed layout defect worth routing to the chat/image-preview owners.

## Change summary

The image hover preview shown for chat image attachments/generated images is sized incorrectly: large images appear clipped/overlapping, small images are rendered inside an oversized box.

## Best solution

Fix the sizing rules for `.chat-attached-context-image` / `.chat-attached-context-image-container` in src/vs/workbench/contrib/chat/browser/widget/media/chat.css so the hover box matches the actual (possibly-scaled) image dimensions instead of forcing a fixed min-width/min-height (200px) and width/height:100% box that mismatches the thumbnail's intrinsic size.

- **suspicious CSS:** src/vs/workbench/contrib/chat/browser/widget/media/chat.css lines 3589-3599: `.chat-attached-context-image` sets `width: 100%; height: 100%;` together with `min-width: 200px; min-height: 200px; max-height: 350px;` while its container (`.chat-attached-context-image-container`, lines 3573-3578) has `height: auto`.
