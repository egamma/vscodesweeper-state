# Issue #106209 — Line highlight on search results doesn't work

[https://github.com/microsoft/vscode/issues/106209](https://github.com/microsoft/vscode/issues/106209)

## Summary

Keep open: current main still removes the search-result line highlight whenever the model's decorations change, matching the confirmed disappearing-highlight reports. This issue remains the canonical report; the earlier attempted fix does not resolve the reopened defect.

## Change summary

Keep the whole-line highlight visible when navigating multi-file search results despite unrelated editor decoration updates.

## Best solution

Make the search-result line highlight survive unrelated decoration changes while retaining intentional clearing when the user moves the editor cursor or leaves the highlighted result. Preserve existing theme colors and match styling rather than expanding this into a highlight-redesign request.
