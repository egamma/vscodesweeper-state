# Issue #316243 — Copilot CLI agent panel: CWD silently inherited from active terminal, not from open workspace

[https://github.com/microsoft/vscode/issues/316243](https://github.com/microsoft/vscode/issues/316243)

## Summary

The post-report Agents Window handoff implementation now explicitly transfers and selects the invoking VS Code workspace folder, and current session creation uses that selected folder as the Agent Host working directory without consulting the active terminal. This can be closed as completed.

## Change summary

Opening the Copilot CLI Agents Window could silently initialize its session from an unrelated active terminal directory instead of the open workspace.

## Best solution

Keep the workspace-handoff behavior implemented by commit d799cf2006076741e7df23831b7c25f216fab780: pass the invoking workspace folder into the Agents Window, wait for its provider and composer, and use that folder when creating the Agent Host session.
