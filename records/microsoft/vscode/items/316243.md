# Issue #316243 — Copilot CLI agent panel: CWD silently inherited from active terminal, not from open workspace

[https://github.com/microsoft/vscode/issues/316243](https://github.com/microsoft/vscode/issues/316243)

## Summary

Keep open: the reported steps suffice to retest unintended session scoping, but current source does not establish that a new CLI session inherits the active terminal's directory. CLI launch and folder-selection paths now coexist, so the affected launch surface needs to be reproduced before identifying a fix.

## Change summary

Launching a Copilot CLI agent session can silently scope it to an unrelated terminal directory instead of the open workspace.

## Best solution

Make ordinary new CLI sessions use a predictable workspace scope and clearly expose their effective working directory, while preserving explicitly selected folders and resumed-session directories. First reproduce the reported launch path on Windows and distinguish terminal creation from background chat-session initialization.
