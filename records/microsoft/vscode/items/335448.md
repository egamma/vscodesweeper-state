# Issue #335448 — Show rich GitHub issue previews with title and rendered body in hovers

[https://github.com/microsoft/vscode/issues/335448](https://github.com/microsoft/vscode/issues/335448)

## Summary

Partially implemented, not done: rich GitHub issue/PR hovers landed for Agents Window chat pills (merged PR #335583, verified by closed test issue #335896), but the issue's core ask — rich previews in Markdown documents and the regular editor window — is still missing, as confirmed by the newer, narrower gap report #337045. Keeps this open since a real piece of the request remains unimplemented on main.

## Change summary

Show a rich hover (title, rendered Markdown body, repo/number/state metadata, open-in-GitHub action) for GitHub issue references, instead of the current compact plain-text hover.

## Best solution

Land the remaining Markdown-editor/editor-window hover transport the author describes as already prototyped locally (stash `ich-github-issue-hovers-335448`) — reusing the existing `createIssueHover`/`createPullRequestHover` components in src/vs/sessions/contrib/github/browser/ — so regular Markdown documents and the editor window's chat view collections (tracked by https://github.com/microsoft/vscode/issues/337045) get the same rich previews the Agents Window already has.
