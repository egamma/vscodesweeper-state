# Issue #331203 — After moving chat unclear how to rejoin it to parent chat

[https://github.com/microsoft/vscode/issues/331203](https://github.com/microsoft/vscode/issues/331203)

## Summary

Team-authored UX gap in the new Agents Window multi-chat grouping: once a chat tab is dragged into its own group there's no drag-back affordance to rejoin it, and a second commenter confirms the confusion versus the sidebar version's behavior. Carries a real release milestone (1.135.0), so this stays open regardless.

## Change summary

When a chat tab is dragged out into a separate group in the Agents Window, there is no way to drag it back into the original group; only closing (which deletes it) or reopening via the chat icon works.

## Best solution

Add drag-and-drop support for moving a chat tab back into an existing tab group in the Agents Window multi-pane UI (likely src/vs/sessions/browser/singlePaneWorkbench.ts or the sessions/chat view drag handling in src/vs/sessions/contrib/chat/browser), matching the existing sidebar drag-to-reorder behavior TDIRivers references.
