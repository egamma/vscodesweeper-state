# Issue #331203 — After moving chat unclear how to rejoin it to parent chat

[https://github.com/microsoft/vscode/issues/331203](https://github.com/microsoft/vscode/issues/331203)

## Summary

Team-authored UX gap in the new Agents Window drag/drop model — once a chat tab is dragged into its own group, there's no way to drag it back or otherwise merge groups; keep open for a real fix, not a triage close.

## Change summary

After dragging a chat tab into a new editor group in the Agents Window, there's no way to drag it back into the original group — closing the tab deletes the chat instead of just detaching it.

## Best solution

Support dragging a chat tab back into another Agents Window group (or provide an explicit 'merge groups' affordance) in src/vs/sessions/browser/parts/*, matching the sidebar version's simpler behavior that a second reporter also expected.
