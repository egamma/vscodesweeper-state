- **Behavior:**

The current source differs from the original report through additional model-content events, so those changes must not be assumed to resolve the protocol symptom. Existing extHostNotebook tests inject notebook versions and do not establish cross-stream ordering. NotebookCellTextModel separately listens to the same text model, so relative listener registration and RPC delivery remain relevant to the reported stale notebook version.
