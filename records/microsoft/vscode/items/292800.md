# Issue #292800 — Chat: reduce size of editor scrollbars when embedded in chat

[https://github.com/microsoft/vscode/issues/292800](https://github.com/microsoft/vscode/issues/292800)

## Summary

A real chat UX gap remains: embedded diff editors still inherit the full editor scrollbar geometry, while only specific chat-input and height-capped code-block paths use a narrower scrollbar. Keep this open for a design decision that balances calmer embedded chrome with an accessible pointer target.

## Change summary

Use smaller scrollbars for editor surfaces embedded in chat so they obscure less content.

## Best solution

Define a consistent embedded-editor scrollbar treatment for chat, likely separating the visual slider width from its usable pointer target, and apply it to the relevant code and diff editor surfaces without changing the embedded terminal behavior declined in the discussion.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/codeBlockPart.ts`, `src/vs/editor/common/config/editorOptions.ts`
- **Validation:** Render chat responses containing horizontally and vertically overflowing code and diff editors; verify the chosen scrollbar treatment is visually compact, remains draggable, supports wheel/keyboard scrolling, and stays discoverable in default and high-contrast themes.
- **Behavior:**

  > Editor scrollbars embedded in chat should occupy less visual space and obscure less code than full editor scrollbars. Overflowing content must remain discoverable and reachable by mouse, wheel, and keyboard, with an adequate pointer target and visible focus/hover behavior. Ordinary editor scrollbars outside chat must remain unchanged. The embedded terminal should retain its current scrollbar treatment unless maintainers explicitly revisit that separate decision.
- **Trace:**

  > Chat code and diff editors are constructed in src/vs/workbench/contrib/chat/browser/widget/chatContentParts/codeBlockPart.ts. Height-capped CodeBlockPart instances receive a 7px vertical scrollbar, but DiffEditorWidget only overrides behavioral scrollbar options and therefore inherits the 12px horizontal and 14px vertical defaults from src/vs/editor/common/config/editorOptions.ts. The discussion's final maintainer comment declines narrowing the embedded terminal because its scrollbar appears only on hover/focus and benefits from a larger mouse surface: https://github.com/microsoft/vscode/issues/292800#issuecomment-3849777677. Keep the boundary to chat-hosted editor widgets; do not alter global editor defaults or the terminal path.
- **Open decisions:**
  - Which chat-hosted editor surfaces should use the compact treatment: response diff editors only, or all overflowing code and diff editors?
  - Should the visual slider become narrower while retaining a larger transparent pointer target, or should both the visual and interactive widths shrink?

## Evidence

- **current source gap:** In src/vs/workbench/contrib/chat/browser/widget/chatContentParts/codeBlockPart.ts, CodeBlockPart.createDiffEditor configures scrollbar behavior but does not override horizontalScrollbarSize or verticalScrollbarSize. It therefore retains the editor defaults of 12px horizontal and 14px vertical from src/vs/editor/common/config/editorOptions.ts.
- **partial later coverage:** https://github.com/microsoft/vscode/pull/310975 added a 7px vertical scrollbar only for height-capped code blocks associated with https://github.com/microsoft/vscode/issues/283242; its diff does not change the general embedded diff-editor path reported here.
- **chat input is separately narrowed:** https://github.com/microsoft/vscode/pull/298875 introduced a 7px vertical scrollbar for the chat input, showing an existing chat-specific compact treatment, but it does not cover response code/diff editors.
- **terminal scope decision:** The maintainer discussion at https://github.com/microsoft/vscode/issues/292800#issuecomment-3849777677 favors the embedded terminal's larger hover/focus scrollbar for usability. That settles the terminal tangent, not the original editor request.
- **canonical search:** Searches for chat embedded-editor scrollbar sizing found no older open issue with the same observable request; the mechanically suggested https://github.com/microsoft/vscode/issues/93772 concerns focus-follow-mouse and does not own this work.
