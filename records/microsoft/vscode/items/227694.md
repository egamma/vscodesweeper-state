# Issue #227694 — Incorrect behavior of granting access for the extension to existing authentication session using Manage Trusted Extensions functionality

[https://github.com/microsoft/vscode/issues/227694](https://github.com/microsoft/vscode/issues/227694)

## Summary

Keep open: granting access through Manage Trusted Extensions still leaves a pending Grant Access command registered on current main. The maintainer explicitly accepted this menu-cleanup defect as separate from the related authentication-event request.

## Change summary

Remove obsolete Accounts-menu access requests when an extension regains access through Manage Trusted Extensions.

## Best solution

Make pending extension access requests and their account badges reflect the current authorization state, regardless of which UI granted access. Preserve existing consent, account preferences, and provider session semantics; the separate authentication-event API discussion should remain separate.
