# Issue #317938 — Agent window: `@` mention does not trigger file/symbol reference picker in new sessions

[https://github.com/microsoft/vscode/issues/317938](https://github.com/microsoft/vscode/issues/317938)

## Summary

A real input-consistency gap remains on current main: the new-session composer only registers `#` file/folder references, while the established chat input accepts both `@` and `#`. The central file-attachment workflow is available through `#file`, but that does not satisfy the reported `@` parity or symbol-picker behavior.

## Change summary

Make file and symbol reference completion behave consistently in new and existing Agents window sessions when the user types `@`.

## Best solution

Choose one uniform reference syntax contract for new and running Agents sessions. If compatibility with the established chat input is retained, the new-session composer should offer equivalent `@` file/symbol completions while preserving its existing `#file` and `#session` behavior.
