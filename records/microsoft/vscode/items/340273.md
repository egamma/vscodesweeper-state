# Issue #340273 — StandAlone terminal

[https://github.com/microsoft/vscode/issues/340273](https://github.com/microsoft/vscode/issues/340273)

## Summary

Fresh (same-day), vague feature request for a terminal that lives independent of any workspace/editor window, with zero community traction so far; keep open to let it collect signal, but it overlaps with existing persistent-session support and may be better served by an extension or the OS's own terminal.

## Change summary

Requests a 'standalone' terminal that survives closing the editor window, not tied to any workspace.

## Best solution

Point the reporter at `terminal.integrated.enablePersistentSessions` (src/vs/workbench/contrib/terminal/common/terminalConfiguration.ts), which already keeps terminal processes/history alive across window reloads for a workspace; a terminal fully decoupled from any workspace concept is a bigger architectural ask that likely belongs in a dedicated extension or is better served by the OS's own terminal application, consistent with VS Code's 'lightweight editor, power lives in extensions' value.

## Vision fit
