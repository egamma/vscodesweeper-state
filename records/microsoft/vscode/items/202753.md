# Issue #202753 — find-replace preview scrolls off-screen when diffEditor.hideUnchangedRegions.enabled

[https://github.com/microsoft/vscode/issues/202753](https://github.com/microsoft/vscode/issues/202753)

## Summary

Keep open: the report provides sufficient steps to retest, but the blank viewport was not confirmed against current main. Diff layout and scroll preservation have changed since the report; the current preview path still reveals the match independently of asynchronous diff computation.

## Change summary

Search-and-replace previews can scroll their content out of view when unchanged regions collapse after opening a match near the bottom of a long file.

## Best solution

Keep the selected replacement visible after the preview diff finishes computing and collapses unchanged regions. First reproduce the original opening sequence and distinguish it from the replacement-application sequence reported in https://github.com/microsoft/vscode/issues/313203.
