# Issue #333722 — Report Issues doesn't show editor while in Automations

[https://github.com/microsoft/vscode/issues/333722](https://github.com/microsoft/vscode/issues/333722)

## Summary

The current source still allows Report Issue to open an editor underneath the full-surface Automations view. Keep this report open: the linked terminal issue describes a related but different observable failure, not a verified duplicate.

## Change summary
