# Issue #227764 — [html] highlighting does not detect end script tag in string literals

[https://github.com/microsoft/vscode/issues/227764](https://github.com/microsoft/vscode/issues/227764)

## Summary

Verified duplicate: the older open canonical issue tracks the same observable failure—an embedded grammar consuming an HTML closing boundary—and explicitly discusses `</script>` handling for embedded JavaScript.

## Change summary

HTML syntax highlighting does not terminate an embedded JavaScript region when `</script>` occurs inside a JavaScript string, despite browsers treating it as the script end tag.

## Best solution

Consolidate this case into https://github.com/microsoft/vscode/issues/20488, where the broader embedded-grammar boundary problem and the need for HTML-specific JavaScript end rules are already tracked.
