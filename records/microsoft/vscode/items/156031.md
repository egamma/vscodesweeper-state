# Issue #156031 — Typing a star in a comment block will lead to an extra end symbol

[https://github.com/microsoft/vscode/issues/156031](https://github.com/microsoft/vscode/issues/156031)

## Summary

Still unfixed on main — the auto-closing comment logic doesn't check whether the cursor is already inside an existing block comment, so typing `*` after `/*` in `/* */` inserts a duplicate `*/`. Two open community PRs attempt a fix but neither has merged.

## Change summary

Typing `*` inside an existing `/* */` block comment to convert it to `/** */` incorrectly inserts an extra `*/` end symbol.

## Best solution

Land a fix in `src/vs/editor/common/cursor/cursorTypeEditOperations.ts` that suppresses auto-closing the comment pair when the cursor is already inside a block comment. PR https://github.com/microsoft/vscode/pull/319405 or https://github.com/microsoft/vscode/pull/226074 may provide the implementation — a maintainer should review one of them.
