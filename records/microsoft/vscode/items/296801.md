# Issue #296801 — Extensions: MCP Servers view becomes empty when applying sort

[https://github.com/microsoft/vscode/issues/296801](https://github.com/microsoft/vscode/issues/296801)

## Summary

The bug remains on current main: the MCP Servers view removes only `@mcp`, so `@sort:name` reaches the gallery as literal search text and produces an empty result. The related fix PR was closed without merging.

## Change summary

Applying an `@sort:` qualifier to the MCP Servers search incorrectly empties the server list.

## Best solution

Ensure Extensions search qualifiers are not included in the MCP gallery's free-text query, while preserving ordinary MCP server text searches. Cover the qualifier path with a focused MCP view query test.
