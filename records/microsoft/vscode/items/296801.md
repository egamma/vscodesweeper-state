# Issue #296801 — Extensions: MCP Servers view becomes empty when applying sort

[https://github.com/microsoft/vscode/issues/296801](https://github.com/microsoft/vscode/issues/296801)

## Summary

Still reproduces on main: the `query()` method in `mcpServersView.ts` only strips `@mcp` from the search text, leaving `@sort:name` as a literal gallery search term that returns no results. The related fix PR was closed without merging.

## Change summary

Typing `@mcp @sort:name` in the Extensions search makes the MCP Servers view empty because the `@sort` qualifier is passed as literal search text to the gallery query.

## Best solution

Strip the `@sort` qualifier from the query text in `mcpServersView.ts` line 339, using the same regex pattern (`/@sort:(\w+)(-\w*)?/g`) already used in `extensionsViews.ts`. Optionally, apply the sort directive to the results as a follow-up.
