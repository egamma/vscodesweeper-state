# Issue #330452 — Linux Root mode

[https://github.com/microsoft/vscode/issues/330452](https://github.com/microsoft/vscode/issues/330452)

## Summary

This is an elevated PowerShell execution question, not an established VS Code defect. The built-in active-terminal selection command provides a way to send selected code to an elevated shell without running the editor as root.

## Change summary

Run selected PowerShell code against an elevated Linux session while developing a module that accesses privileged paths.

## Best solution

Keep VS Code unprivileged and use workbench.action.terminal.runSelectedText with a separate, active terminal running sudo pwsh. PowerShell F8 session integration is owned by the PowerShell extension and is distinct from sending text to the active terminal.

- **Proposed comment:**

  > Thanks for the context. You can keep VS Code running as your normal user, open a separate integrated terminal, run `sudo pwsh` there, and leave that terminal active. Select your PowerShell code and invoke **Terminal: Run Selected Text In Active Terminal** (`workbench.action.terminal.runSelectedText`); you can also assign that command a keyboard shortcut.
  > 
  > F8 is the PowerShell extension's `PowerShell.RunSelection` command. In the PowerShell Extension terminal, it evaluates code through the extension-managed session, not the nested elevated shell started by `sudo pwsh`. For elevated execution through that extension-managed session specifically, please ask in https://github.com/PowerShell/vscode-powershell.
