# Issue #284501 — changing exclude files for search with copilot suggestions

[https://github.com/microsoft/vscode/issues/284501](https://github.com/microsoft/vscode/issues/284501)

## Summary

Keep open: current search handling still discards manually requested semantic results when include/exclude patterns change, rather than preserving the user's expressed interest. The migrated discussion supports smart re-expansion, and no verified canonical or fixing commit was found.

## Change summary

Preserve semantic-search engagement while refining file filters, avoid unnecessary repeated queries, and reduce result-tree jumping.

## Best solution

Make file-filter refinements retain the user's semantic-search engagement and keep the results presentation stable in the Search view. Settle when cached results suffice versus when a fresh semantic query is necessary, without enabling automatic semantic searches for users who have not requested them.
