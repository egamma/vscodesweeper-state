# Issue #116913 — Git - VSC never sign the merge commit even if I turned `Enable Commit Signing` on

[https://github.com/microsoft/vscode/issues/116913](https://github.com/microsoft/vscode/issues/116913)

## Summary

The signing-setting gap remains in current main: ordinary commits honor git.enableCommitSigning, but automatically created merge commits do not. Keep this issue as the canonical report; the Ubuntu report was explicitly closed into it.

## Change summary

Honor git.enableCommitSigning when a branch merge automatically creates a commit.

## Best solution

Make merge-created commits honor the existing repository-scoped signing setting, while preserving Git configuration when that setting is disabled. Retain normal fast-forward and conflict-resolution behavior without introducing another setting.
