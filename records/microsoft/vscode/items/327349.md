# Issue #327349 — macOS terminal cwd detection mis-parses lsof output when an open file path contains "cwd"

[https://github.com/microsoft/vscode/issues/327349](https://github.com/microsoft/vscode/issues/327349)

## Summary

Confirmed on current main: the `grep cwd` in terminalProcess.ts matches file paths containing 'cwd', not just the FD column, corrupting cwd detection for affected setups (e.g. Nix with gettext).

## Change summary

macOS terminal cwd detection breaks when any open file path contains the substring 'cwd', causing session restore and split-terminal failures.

## Best solution

Replace the `lsof -OPln -p <pid> | grep cwd` invocation with `lsof -a -p <pid> -d cwd -F n` and parse the `n`-prefixed line, which unambiguously returns only the cwd. This also addresses the performance concern raised in #318863 by avoiding the full lsof dump.
