# Issue #311420 — Copilot custom agent handoff can keep the previous agent active instead of switching to the target agent

## Summary

PR #312302 fixed the primary race condition (mode switch not awaited), but PR #313082 is still open addressing remaining failure modes (delegated handoffs, custom-mode history leakage) — keeping open until that lands.

## Change summary

## Best solution
