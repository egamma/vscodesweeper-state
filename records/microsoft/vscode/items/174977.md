# Issue #174977 — Add option to not focus next search result

[https://github.com/microsoft/vscode/issues/174977](https://github.com/microsoft/vscode/issues/174977)

## Summary

Valid feature request — after a replace in the Search view, the next match is automatically focused and its file opened, which can be disorienting. No setting exists to control this; the auto-focus behavior is hardcoded in `searchActionsRemoveReplace.ts`. The request remains unimplemented on current main.

## Change summary

Add an option to prevent the Search view from automatically focusing the next result after performing a replace.

## Best solution

Add a `search.focusNextResultOnReplace` (or similar) boolean setting (defaulting to `true` for backward compatibility). In `searchActionsRemoveReplace.ts` (the replace action handler around lines 287–318), guard the `nextFocusElement` reveal/setFocus/open logic on this setting. When disabled, the tree focus should remain on the current position without opening a different file.
