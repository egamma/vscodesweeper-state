# Issue #174977 — Add option to not focus next search result

[https://github.com/microsoft/vscode/issues/174977](https://github.com/microsoft/vscode/issues/174977)

## Summary

Keep open: replacing a search result still explicitly opens the next result, and the existing preview setting does not provide an opt-out. This team-authored Backlog request remains a distinct enhancement, with no verified open canonical or concrete fixing commit found.

## Change summary

Allow replacing a Search view result without automatically switching the editor to the next result.

## Best solution

Provide an opt-out from editor navigation after replacement in the Search view while preserving the existing sequential-replacement workflow. Settle whether the next result should retain tree focus without opening its editor, or whether automatic tree advancement should also stop.
