# Issue #244607 — Clicking a cell output reference focuses the input cell

[https://github.com/microsoft/vscode/issues/244607](https://github.com/microsoft/vscode/issues/244607)

## Summary

The defect remains on current main: chat output references identify a specific output, but opening them selects only the containing cell. Route this to the notebook/chat owners because the original output-focus limitation no longer exists.

## Change summary

Clicking a notebook output attachment in chat should focus its referenced output rather than the cell input.

## Best solution

Pass the parsed output identity through the notebook editor-opening flow and invoke `focusNotebookCell(cell, 'output', { outputId })` after revealing the cell, likely across the notebook resolver and editor pane.
