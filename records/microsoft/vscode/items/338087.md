# Issue #338087 — Managed enabledPlugins refresh does not reconcile active Agent Host sessions

[https://github.com/microsoft/vscode/issues/338087](https://github.com/microsoft/vscode/issues/338087)

## Summary

Thanks for the detailed report. I could not confirm or rule out the live-refresh gap from a limited read of the source. The report has concrete expected behavior, but it is a cross-layer convergence problem that is parked in On Deck and ties into two runtime trackers. It stays open.

## Change summary

Managed enabledPlugins changes that arrive after an Agent Host session starts are not applied to the active session, which may need a new session or restart.

## Best solution

Add a host-side step that reacts to each applied managed-settings generation. It should reconcile plugin enablement and the skills, agents, hooks, MCP servers and extensions they contribute in active Agent Host sessions. Where live convergence is unsafe, it should say so and offer a recovery path. Add tests that add and withdraw enabledPlugins while a session is open.
