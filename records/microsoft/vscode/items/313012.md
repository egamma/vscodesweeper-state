# Issue #313012 — vscode-server cli 'code' tool does not report an error when called outside terminal

[https://github.com/microsoft/vscode/issues/313012](https://github.com/microsoft/vscode/issues/313012)

## Summary

Confirmed on current main: the remote CLI prints an error when invoked outside a VS Code terminal but exits with code 0 instead of non-zero. The fix is a one-line addition before the return.

## Change summary

The `code` remote-cli tool exits with code 0 even when it cannot run because it is invoked outside a VS Code terminal or WSL.

## Best solution

Add `process.exitCode = 1;` (or `process.exit(1)`) before the `return` at line 95 of `src/vs/server/node/server.cli.ts`, so the error message is accompanied by a non-zero exit code. A similar pattern already exists at line 478 of the same file.
