# Issue #198669 — Multi Diff Editor Revealing lines doesn't auto reveal after a threshold

[https://github.com/microsoft/vscode/issues/198669](https://github.com/microsoft/vscode/issues/198669)

## Summary

Keep open: unchanged-line disclosure still depends entirely on pointer displacement, so holding the drag above the viewport does not continue revealing lines. The closely related auto-scroll request is newer and cannot replace this re-reviewed report.

## Change summary

Continue revealing hidden context when a multi-diff disclosure border is dragged above the editor viewport, without requiring repeated drags.

## Best solution
