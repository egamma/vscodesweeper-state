Current main already contains an experiment-gated stale-cache notification with a Start New Chat action, substantially covering this request. Keep this team-authored issue open: the implementation does not explicitly reference it, and the owner should confirm intended session coverage and whether compaction guidance remains necessary.

## Change summary

Warn users when resuming a session whose prompt cache has expired, suggesting compaction or starting a new session.
