This is a duplicate of #313510 ('Agents: Terminal auto-closes a lot'), which was fixed by PR #318985 (merged 8 days after this issue was filed). The fix prevents the Agents window from killing terminals on session archive/re-emit.

## Change summary

The Agents window forcibly closes the integrated terminal and kills running processes when the user switches away and back.
