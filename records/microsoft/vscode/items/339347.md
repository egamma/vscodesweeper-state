# Issue #339347 — Automations can't switch between remote and local folders

[https://github.com/microsoft/vscode/issues/339347](https://github.com/microsoft/vscode/issues/339347)

## Summary

Keep open for a maintainer decision: current source deliberately retains an automation's owning host, and an existing test explicitly expects the reported local-folder rejection. Switching execution between local and remote hosts remains unsupported; the team-authored report should not be closed as designed.

## Change summary

Allow an existing automation to switch between remote and local workspaces without encountering an incompatible-host error.

## Best solution

Make cross-host workspace selection an explicit, understandable workflow in the automation dialog. The owner should decide whether that means transferring the automation or guiding users through duplication, with clear treatment of the original schedule and history.
