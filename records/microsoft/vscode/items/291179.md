# Issue #291179 — Adopt screenElement from xterm

[https://github.com/microsoft/vscode/issues/291179](https://github.com/microsoft/vscode/issues/291179)

## Summary

The upstream screenElement API has landed, but three production terminal paths still discover the screen through its CSS class. Keep this adoption cleanup open; the upstream implementation does not complete the VS Code work.

## Change summary

Adopt xterm's public screenElement property wherever VS Code currently locates the terminal screen through DOM selectors.

## Best solution

Terminal attachment, suggestions, and command guides should obtain the same screen element through xterm's supported API, preserving their existing lifecycle and behavior.
