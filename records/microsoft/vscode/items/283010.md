# Issue #283010 — Improve codelens and selection/decoration behaviour

[https://github.com/microsoft/vscode/issues/283010](https://github.com/microsoft/vscode/issues/283010)

## Summary

Still reproduces on main: codelens view zones don't participate in editor selection highlighting because no selection-background styling is applied to the view zone DOM. No fix has landed since the report.

## Change summary

When selecting code that spans a codelens line, the codelens background doesn't reflect the selection highlight color.

## Best solution

The codelens view zone (CodeLensViewZone in codelensWidget.ts) needs to react to selection changes and apply the editor selection background color to its DOM node when it falls within or adjacent to the current selection range. This likely involves listening to selection changes in the controller and toggling a CSS class on the view zone element.
