# Issue #327008 — Issue: Hide or disable the Cloud dropdown when a repository is selected

[https://github.com/microsoft/vscode/issues/327008](https://github.com/microsoft/vscode/issues/327008)

## Summary

Legitimate, already-routed polish report from a team member about a misleading dropdown affordance in the Agents window's cloud/workspace picker once a repository fixes the environment to Cloud; I couldn't pin down the exact control/guard on main, so this should stay open for a maintainer with UI context to confirm and fix.

## Change summary

When a GitHub repository is selected (forcing the Cloud environment), the picker still renders a chevron/dropdown affordance even though clicking it does nothing, misleading users into thinking it's broken.

## Best solution

In the Agents window new-chat workspace/environment picker (src/vs/sessions/contrib/chat/browser/sessionWorkspacePicker.ts and/or the repo-selection flow in repoPicker.ts), either disable/hide the dropdown chevron or make the control genuinely interactive (e.g. still openable to switch back to a local folder) once a repository selection has pinned the environment to Cloud.
