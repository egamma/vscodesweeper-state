# Issue #302307 — Unable to remove keyboard shortcut

[https://github.com/microsoft/vscode/issues/302307](https://github.com/microsoft/vscode/issues/302307)

## Summary

Still open on main — the remove-keybinding logic in the keybindings editor has not been fixed for these commands. Team-authored bug; no fix commit found.

## Change summary

Removing keyboard shortcuts for `workbench.action.chat.queueMessage` and `workbench.action.chat.steerWithMessage` via the Keyboard Shortcuts editor context menu has no effect.

## Best solution

Investigate the interaction between the `removeDefaultKeybinding` flow in `src/vs/workbench/services/keybinding/common/keybindingEditing.ts` and these commands' keybindings (which have complex `when` clauses). The `removeDefaultKeybinding` method relies on `resolvedKeybinding.getUserSettingsLabel()` producing a key string, and writes a negation entry — but something in the resolution or the `areSame` dedup check may prevent the negation from being written for keybindings bound to plain `Enter` with context-dependent `when` expressions.
