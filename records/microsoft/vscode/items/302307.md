# Issue #302307 — Unable to remove keyboard shortcut

[https://github.com/microsoft/vscode/issues/302307](https://github.com/microsoft/vscode/issues/302307)

## Summary

Keep open: the supplied steps suffice to retest, and a September report describes the same failure for both commands. Current main has evolved chat conditions and removal matching, but source inspection does not establish that this regression is fixed; this team-authored issue has no verified factual basis for closure.

## Change summary

Removing the Enter shortcuts for chat queueing and steering writes keybindings.json but leaves the shortcuts assigned.

## Best solution

Make Keyboard Shortcuts removal reliably disable the selected queueing or steering binding, including after its generated condition is saved and reloaded. Retain this older issue as the investigation anchor and incorporate the concrete removal rules from the newer report.
