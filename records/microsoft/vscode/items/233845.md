## Change summary

Bash shell integration scripts produce error messages (e.g. 'bash: VSCODE_INJECTION: unbound variable') when the user's shell runs with `set -u` (nounset mode).

## Best solution

Land the remaining `${VAR:-}` guards for all unprotected `VSCODE_*` variable references in `shellIntegration-bash.sh` — either by reviewing and merging the open PR #233527, or by extending the partial fix from commit a5da1917798 to cover the remaining sites (lines 31, 32, 54, 61, 73, 82, 91, 219, 223). The fix is mechanical: use `${VAR:-}` parameter expansion wherever an unset variable is tested or expanded.
