## Evidence

- **Current source defect:** src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-bash.sh sources ~/.bashrc during injected startup, allowing the reported `set -u` to take effect. Later it directly expands optional variables including `$STARSHIP_SESSION_KEY` and `$POSH_SESSION_ID`; an ordinary Bash environment without these prompt integrations encounters an unbound-variable error. The script also retains unguarded `$VSCODE_INJECTION`, `$VSCODE_SHELL_LOGIN`, and `$VSCODE_NONCE` expansions. This establishes remaining nounset incompatibility from source, not a runtime reproduction of the exact historical VSCODE_INJECTION message.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/233527 was verified OPEN with no merge commit. Its diff adds unset-safe expansions for VSCODE_INJECTION, VSCODE_SHELL_LOGIN, VSCODE_SHELL_INTEGRATION, VSCODE_NONCE, and VSCODE_STABLE in the Bash script. It is an existing human-owned fix candidate, not evidence of a landed fix.
