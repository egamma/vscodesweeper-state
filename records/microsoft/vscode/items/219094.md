# Issue #219094 — Extension Profiling Path PII-Masking Hides Relevant Information

[https://github.com/microsoft/vscode/issues/219094](https://github.com/microsoft/vscode/issues/219094)

## Summary

Still reproduces on current main — `rewriteAbsolutePaths` in `src/vs/platform/profiling/common/profiling.ts` still replaces full paths with `join('piiRemoved', basename(url))`, losing extension identity. No fix or setting has been added. Team-authored feature request; stays open.

## Change summary

Extension host CPU profile PII masking strips the extension name from paths, making saved profiles useless for identifying which extension owns a given script.

## Best solution

Preserve the extension identifier (publisher + name) in the rewritten path while still stripping the user-specific prefix — e.g. `join('piiRemoved', extensionId, basename(url))` — or add a hidden setting to disable the masking entirely. The fix touches `src/vs/platform/profiling/common/profiling.ts` (`rewriteAbsolutePaths`) and the call site in `src/vs/workbench/contrib/extensions/electron-browser/runtimeExtensionsEditor.ts`.
