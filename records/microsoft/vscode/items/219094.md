# Issue #219094 — Extension Profiling Path PII-Masking Hides Relevant Information

[https://github.com/microsoft/vscode/issues/219094](https://github.com/microsoft/vscode/issues/219094)

## Summary

Keep open: profiling deliberately masks absolute paths, but collapsing every extension script to a basename removes the extension identity needed to diagnose extension-host performance. The issue is team-authored, remains unresolved in the cited current path, and has multiple independent confirmations.

## Change summary

Preserve enough extension identity in saved extension-host CPU profiles to distinguish common entry-point filenames without exposing filesystem PII.

## Best solution

Replace basename-only masking for extension-owned scripts with a privacy-safe stable label that includes the extension identifier and extension-relative path, while continuing to remove user-specific absolute path components. The profiling and runtime-extensions owners should confirm the privacy boundary before implementation.
