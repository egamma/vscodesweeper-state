# Issue #105922 — Notebook diff: fully unaccassible

[https://github.com/microsoft/vscode/issues/105922](https://github.com/microsoft/vscode/issues/105922)

## Summary

Keep open as notebook-diff accessibility debt. The agreed text-diff fallback exists, but current source still exposes keyboard and labeling gaps in the notebook diff itself, and a later maintainer explicitly identified this issue as tracking that remaining work.

## Change summary

Make notebook differences navigable and readable with the keyboard and a screen reader, including an accessible next/previous-difference experience.

## Best solution

Complete accessible change navigation in the notebook diff while retaining the existing plain-text fallback. Establish the notebook-wide navigation and announcement contract before implementing changes across the diff container and embedded editors.

- **Behavior:**

  > Notebook change review must let keyboard and screen-reader users discover and read differences without requiring mouse interaction. The existing screen-reader text-diff fallback mitigates the original report but does not make the notebook diff itself accessible. Acceptance should cover added, deleted, and modified cells, forward and backward traversal, meaningful spoken context, and keyboard-operable collapsible sections. Preserve accessible review through the plain-text fallback.
- **Trace:**

  > NotebookProviderInfoStore in src/vs/workbench/contrib/notebook/browser/services/notebookServiceImpl.ts excludes notebook diff handling when screen-reader optimization is active. notebook.diff.switchToText in src/vs/workbench/contrib/notebook/browser/diff/notebookDiffActions.ts explicitly opens a default text diff. NotebookTextDiffEditor in src/vs/workbench/contrib/notebook/browser/diff/notebookDiffEditor.ts still disables list keyboard support, supplies null item ARIA labels, and implements nextChange()/previousChange() as list focus/reveal operations. The ordinary F7 commands in src/vs/editor/browser/widget/diffEditor/commands.ts target a focused text diff widget, so embedded cell review and notebook-wide review must be distinguished. The thread accepts the fallback as temporary, and https://github.com/microsoft/vscode/issues/226815#issuecomment-2313762466 associates later accordion keyboard gaps with this issue. Runtime screen-reader behavior was not exercised; retain the fallback and ordinary text-diff behavior while establishing the notebook-wide contract.
- **Open decisions:**
  - When the notebook diff has focus, should F7 and Shift+F7 traverse differences across the entire notebook, or review differences within the focused cell while separate commands move between changed cells?
