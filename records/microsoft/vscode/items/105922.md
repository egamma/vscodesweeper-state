# Issue #105922 — Notebook diff: fully unaccassible

[https://github.com/microsoft/vscode/issues/105922](https://github.com/microsoft/vscode/issues/105922)

## Summary

The core accessibility gap remains: notebook diff still lacks F7/Shift+F7 accessible diff navigation (no `KeyCode.F7` binding in the notebook contrib), and the accessibility provider's `getAriaLabel()` returns `null`. The 2020 partial fix only showed the text diff editor; the full accessible experience is still missing.

## Change summary

F7/Shift+F7 accessible diff navigation does not work in the notebook diff editor, making it inaccessible for screen reader users.

## Best solution

Wire up the standard accessible diff viewer (F7) for notebook diff cells — either by integrating `AccessibleDiffViewer` into the embedded diff editors or by providing an equivalent accessible navigation path. The accessibility provider in `notebookDiffEditor.ts` should also return meaningful aria labels instead of `null`.
