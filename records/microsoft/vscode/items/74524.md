# Issue #74524 — Add support to distinguish between diagnostics created by a reconciler and a builder

[https://github.com/microsoft/vscode/issues/74524](https://github.com/microsoft/vscode/issues/74524)

## Summary

This API feature request remains unimplemented — DiagnosticTag still only has Unnecessary and Deprecated, and no creator/kind distinction exists in the API or proposed APIs. Team-authored and still valid for the languages-diagnostics area.

## Change summary

Add an API mechanism (tag or property) to distinguish diagnostics from a reconciler vs. a builder, enabling better merging and avoiding stale/duplicate problems.

## Best solution

Design and finalize an extension API addition — either a new DiagnosticTag value or a `creator` property on Diagnostic — coordinated with the LSP spec discussion (microsoft/ms-lsp#32). The languages-diagnostics area owner should decide the shape.
