# Issue #335764 — Agents window `Create PR` button has to be tied to specific session

[https://github.com/microsoft/vscode/issues/335764](https://github.com/microsoft/vscode/issues/335764)

## Summary

Team-authored, day-old bug report about the Agents window's Create PR button requiring an active session — hard keep-open rule for team-authored issues applies, and no fix commit references this issue yet.

## Change summary

The Agents window `Create PR` button only appears when a specific session is active, not whenever there are uncommitted changes in the opened project.

## Best solution

In src/vs/sessions/contrib/changes/browser/changesView.ts, the button visibility/action logic is keyed off `sessionsService.activeSession` / `changesViewService.activeSessionResourceObs` (see lines ~180-201, ~423, ~597-620); this should be extended to also surface the action when uncommitted changes exist outside any active session.
