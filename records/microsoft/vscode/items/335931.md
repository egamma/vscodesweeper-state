# Issue #335931 — Webview widget of AI-agent extensions (Zoo Code, Cline) crashes to a blank gray panel; `[uncaught exception in main] TypeError: Titlebar overlay is not enabled` thrown from the guest-window claim path (`openGuestWindow`), Windows, 1.137.0

[https://github.com/microsoft/vscode/issues/335931](https://github.com/microsoft/vscode/issues/335931)

## Summary

This is a specific instance (Zoo Code/Cline webviews) of the same root-cause crash already tracked, with an identical stack signature, by the open and assigned https://github.com/microsoft/vscode/issues/316925 — proposing consolidation there rather than tracking the same bug twice.

## Change summary

Auxiliary/guest windows opened from an extension's webview (e.g. an auth popup or preview window) crash the main process with `TypeError: Titlebar overlay is not enabled`, killing the opener webview's surface.

## Best solution

Fix belongs in the guest-window claim path (`AuxiliaryWindow.doTryClaimWindow` → `BaseWindow.setWin` → `updateWindowControls` in src/vs/platform/windows/electron-main/windowImpl.ts and src/vs/platform/auxiliaryWindow/electron-main/auxiliaryWindow.ts), which calls `win.setTitleBarOverlay()` based on the global `useWindowControlsOverlay` config without checking whether this specific BrowserWindow instance was actually constructed with the `titleBarOverlay` option — that work should happen under the already-assigned https://github.com/microsoft/vscode/issues/316925 rather than in a second issue.
