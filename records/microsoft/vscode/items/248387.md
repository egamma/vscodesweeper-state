# Issue #248387 — use `export function x(...)` instead of `export const x`

[https://github.com/microsoft/vscode/issues/248387](https://github.com/microsoft/vscode/issues/248387)

## Summary

Keep open: the merged adoption PRs addressed portions of the cleanup, but current main still contains direct exported arrow functions covered by the guideline. The discussion explicitly preserves initialization-time function factories, so remaining work needs to distinguish those legitimate exceptions.

## Change summary

Adopt top-level exported function declarations instead of directly exported function expressions, preserving legitimate initialization-time factories.

## Best solution

Complete the remaining direct-export migration and establish lint enforcement consistent with the coding guideline. Preserve factories such as generateUuid that select or initialize their implementation once at module load.
