# Issue #329829 — VSCode on MacOS does not respect custom `defaults write -g NSConvolutionOverride1 -float 1` corner / window border radius

[https://github.com/microsoft/vscode/issues/329829](https://github.com/microsoft/vscode/issues/329829)

## Summary

Window corner rendering on macOS is drawn by the native window server (NSWindow), not by VS Code's own code, and `NSConvolutionOverride1` is an undocumented private macOS default affecting OS-level window compositing — so any artifact here is a Chromium/Electron/macOS window-chrome issue, not a VS Code defect.

## Change summary

Setting the undocumented macOS default `NSConvolutionOverride1` causes VS Code's window corners to render with a visible mismatched corner overlay.

## Best solution

Keep open as upstream: VS Code doesn't custom-draw window corners (checked windowImpl.ts/windows.ts — only titleBarStyle is set, corner radius/masking is native macOS/Electron BrowserWindow behavior), so any fix belongs in Electron's macOS BrowserWindow implementation or is simply an artifact of an unsupported private OS override; no core code change is applicable.
