# Issue #341039 — Upgrade built-in "Explore" agent model to latest modern relevant models.

[https://github.com/microsoft/vscode/issues/341039](https://github.com/microsoft/vscode/issues/341039)

## Summary

Thanks for the report. The Explore agent's default model list is hard-coded to Claude Haiku 4.5, then Gemini 3 Flash, then Auto. That is intended behavior, so this is a model-choice request rather than a defect. A user override exists, but it doesn't change the default. Keeping it open for the maintainers who own the default model choice.

## Change summary

Update the built-in Explore subagent's default fallback models to newer fast models.

## Best solution

Have the Copilot Chat maintainers review the fallback list in exploreAgentProvider.ts and update it to whichever current fast, low-cost models they want as the default. Users can already override the model today.
