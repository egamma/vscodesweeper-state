# Issue #201734 — No "Restart TS Server" when viewing diff editor

[https://github.com/microsoft/vscode/issues/201734](https://github.com/microsoft/vscode/issues/201734)

## Summary

The reopened defect remains in current source: focusing the `git:` side of a TypeScript diff causes the active-editor tracker to select that disabled document, after which `typescript.isManagedFile` is cleared and the restart command disappears.

## Change summary

Keep `TypeScript: Restart TS Server` available when either side of a TypeScript diff editor is focused, including a `git:`-backed original side.

## Best solution

Align `ActiveJsTsEditorTracker` with the disabled-scheme rules used by `ManagedFileContextManager`, so a disabled `git:` candidate does not hide the command when the same diff contains a managed TypeScript document. Preserve normal editor, notebook-cell, and non-TypeScript command visibility behavior.
