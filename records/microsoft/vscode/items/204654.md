# Issue #204654 — Unwanted scrolling in macOS with native trackpad and pinch zoom gesture.

[https://github.com/microsoft/vscode/issues/204654](https://github.com/microsoft/vscode/issues/204654)

## Summary

Still reproduces on current main. A fix landed in commit b9a487d07c9 (July 2025) but was inadvertently reverted — the pinch-gesture guard in mouseHandler.ts is no longer present, so pinch-to-zoom gestures on macOS still cause unwanted vertical scrolling when `editor.mouseWheelZoom` is disabled.

## Change summary

On macOS, performing a trackpad pinch-to-zoom gesture in the editor causes unwanted vertical scrolling when `editor.mouseWheelZoom` is disabled, instead of being ignored.

## Best solution

Re-apply the guard from commit b9a487d07c9 in `src/vs/editor/browser/controller/mouseHandler.ts`: when `mouseWheelZoom` is disabled, detect pinch gesture events (via `hasMouseWheelZoomModifiers`) and call `preventDefault()`/`stopPropagation()` before the early return so the event doesn't reach the scrollable element. The original fix was correct but was lost during subsequent refactoring.
