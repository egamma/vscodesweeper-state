# Issue #307458 — Disable auto-adding highlighted text to chat

[https://github.com/microsoft/vscode/issues/307458](https://github.com/microsoft/vscode/issues/307458)

## Summary

The requested control already exists: setting `chat.implicitContext.enabled.panel` to `never` disables implicit active-editor context in Chat, including highlighted selections.

## Change summary

Provide an option that prevents highlighted editor text from being automatically included as Chat context.

## Best solution

Use the existing `chat.implicitContext.enabled` configuration with `panel` set to `never`; this disables all implicit active-editor context, while explicitly attached context remains available.

## Vision fit

- **Fit:** aligned
- **Reason:** Giving users control over automatically shared Chat context supports predictable AI-assisted workflows.
- **Evidence:** Durable themes: AI-assisted development and workbench settings fidelity.

  > Thanks for the request. This can already be disabled by setting the Chat panel's implicit context mode to `never`:
  > 
  > ```json
  > "chat.implicitContext.enabled": {

  > ```

## Evidence
