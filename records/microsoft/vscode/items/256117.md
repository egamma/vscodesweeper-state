# Issue #256117 — Have the agent add breakpoints

[https://github.com/microsoft/vscode/issues/256117](https://github.com/microsoft/vscode/issues/256117)

## Summary

Keep open for design of a cohesive agent-debugging workflow: existing debug onboarding does not provide agent breakpoint placement or paused-session context. This team-authored request has explicit interest, and neither a referenced implementation nor an eligible open canonical was found.

## Change summary

Let the agent place debugger breakpoints and use context from a hit breakpoint.

## Best solution

Define a cohesive agent-debugging experience that supports breakpoint placement and inspection of paused-session context while preserving user-created breakpoints and normal debugging. Decide the agent's execution authority before implementing the debugger/tool integration.
