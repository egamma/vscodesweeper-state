# Issue #256117 — Have the agent add breakpoints

[https://github.com/microsoft/vscode/issues/256117](https://github.com/microsoft/vscode/issues/256117)

## Summary

Team-authored feature request (MEMBER) for adding a breakpoint-management tool to the agent surface. No existing agent tool for breakpoints exists on current main. Keeping open per hard keep-open rule for team-authored issues.

## Change summary

Allow agents to programmatically add breakpoints and read context from hit breakpoints during debugging sessions.

## Best solution

Implement a new built-in chat/agent tool (alongside existing debug tools like `resolveDebugEventDetails`) that can set, toggle, and remove breakpoints via `IDebugService`, and surface hit-breakpoint context back to the agent. The `debug` area label is already applied and correct.
