# Issue #124529 — command not working in NotebookCellStatusBarItemProvider

[https://github.com/microsoft/vscode/issues/124529](https://github.com/microsoft/vscode/issues/124529)

## Summary

Real bug still present on main — notebook cell status bar items with command objects (carrying arguments) fail because the delegate command forwarding doesn't work correctly in this path. An open PR (#282360) is attempting a fix.

## Change summary

NotebookCellStatusBarItemProvider fails when using a command object with arguments instead of a plain command string.

## Best solution

Review and land (or close and supersede) the open PR https://github.com/microsoft/vscode/pull/282360 which targets this issue. The proper fix likely needs to ensure the delegate command mechanism works end-to-end for notebook status bar items, or bypass it by resolving the command on the ext host side before sending to the workbench.
