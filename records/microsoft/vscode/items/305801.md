# Issue #305801 — Sessions: No way to differentiate between sessions windows when you pop out editors

[https://github.com/microsoft/vscode/issues/305801](https://github.com/microsoft/vscode/issues/305801)

## Summary

Valid request from a team member: the Agents window's simplified titlebar explicitly skips setting `document.title` (line 131: 'No window title to update'), so all auxiliary windows are indistinguishable in the OS taskbar/dock. Keeping open per team-authored policy.

## Change summary

When opening a session in a new window, the OS window title should reflect the active chat session name instead of a generic label.

## Best solution

Wire the active session's title into `document.title` for both the main Agents window and its auxiliary windows. The `SessionsTitlebarPart` (src/vs/sessions/browser/parts/titlebarPart.ts) currently stubs out `updateTitle` and `registerVariables` — the fix would listen to the active session's title observable and update `document.title` accordingly, similar to how the workbench's `WindowTitle` class manages its title template.
