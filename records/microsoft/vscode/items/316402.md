# Issue #316402 — The max context of OpenRouter Model is wrong, it should be 1M.

[https://github.com/microsoft/vscode/issues/316402](https://github.com/microsoft/vscode/issues/316402)

## Summary

Valid bug with an open fix PR (#323019) that explicitly references this issue — keep open until that PR merges.

## Change summary

OpenRouter models in BYOK report the wrong (smaller) max context window because the code reads `top_provider.context_length` instead of the model's top-level `context_length`.

## Best solution

Land https://github.com/microsoft/vscode/pull/323019, which switches OpenRouter model discovery to prefer the model's top-level `context_length` over the routed provider's smaller value, with the latter as fallback.
