# Issue #345856 — Copilot CLI chat: no discoverable way to revoke “Allow in this session” tool permissions

[https://github.com/microsoft/vscode/issues/345856](https://github.com/microsoft/vscode/issues/345856)

## Summary

Keep open for maintainer review of permission-revocation discoverability. Current main provides an editable session-settings surface, but that is not equivalent to a discoverable approval-management control; the permission-safety concern also warrants keeping this open.

## Change summary

Provide a discoverable way to inspect and revoke session tool approvals without discarding the conversation.

## Best solution

Make effective session grants discoverable and individually revocable, with a clear reset operation that preserves conversation history and inherited restrictions. Evaluate the default session-wide approval choice separately rather than treating approval-mode selection as revocation.
