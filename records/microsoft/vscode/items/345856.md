# Issue #345856 — Copilot CLI chat: no discoverable way to revoke “Allow in this session” tool permissions

[https://github.com/microsoft/vscode/issues/345856](https://github.com/microsoft/vscode/issues/345856)

## Summary

Keep open for human review of this security-sensitive permission-control request. Current source provides session-settings JSON editing, but that does not fully address discoverable revocation or the concern about overly broad default approvals.

## Change summary

Make Copilot CLI session tool grants discoverable and revocable without losing the conversation.

## Best solution

Provide an understandable session-grant management surface backed by authoritative permission configuration, preserving conversation history and enterprise restrictions. A maintainer should reconcile this request with the overlapping permission-control work in https://github.com/microsoft/vscode/issues/341619.
