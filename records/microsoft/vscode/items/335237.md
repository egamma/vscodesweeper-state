## Summary

Detailed, well-evidenced report, but it can only be reproduced through clangd 23.1.0+ (a third-party extension) and its LSP client library, and tracing the relevant core code (extHostLanguageFeatures' insert/replace range conversion, CompletionItem's editStart/editInsertEnd/editReplaceEnd assignment, and suggestController's insertMode replace logic) shows the ranges are threaded through and applied correctly for the described insert/replace shape — so the fault isn't obviously in VS Code core from source alone, and no isolated repro (bypassing clangd) has been done yet.

## Change summary

editor.suggest.insertMode: "insert" is reportedly ignored for LSP completions using InsertReplaceEdit (clangd 23.1.0+), causing the trailing identifier to be deleted instead of preserved.
