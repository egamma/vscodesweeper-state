# Issue #339177 — MCP migration picker: clicking a server row or checkbox does not reliably toggle selection

[https://github.com/microsoft/vscode/issues/339177](https://github.com/microsoft/vscode/issues/339177)

## Summary

Confirmed in source: the migration tree is configured with `openOnSingleClick: true`, so `tree.onDidOpen` fires on every row click and unconditionally calls `openMigrationItem()` instead of toggling selection; only the checkbox worked because its click handler stops propagation. An open PR already proposes the fix, so this stays open pending that PR rather than being closed now.

## Change summary

In the MCP migration picker, clicking a server row (as opposed to its checkbox) opens the item's details instead of toggling its selection, so the footer count and Migrate button don't update reliably.

## Best solution

Land https://github.com/microsoft/vscode/pull/339831, which changes the `tree.onDidOpen` handler in customizationMigrationDashboard.ts to toggle selection on a plain single click and reserve open-details behavior for double-click/keyboard activation/manual-review items.
