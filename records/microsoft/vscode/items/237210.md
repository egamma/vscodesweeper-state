[https://github.com/microsoft/vscode/issues/237210](https://github.com/microsoft/vscode/issues/237210)

## Summary

The maximize and Windows Snap failure is caused by the third-party Vibrancy Continued extension, not VS Code core. The extension's own tracker documents the exact behavior for this VS Code and extension version range.

## Change summary

Restore window maximization and Windows 11 Snap after reinstalling VS Code.

## Best solution

Disable Vibrancy through its command before uninstalling it, or update and configure the extension according to its documentation; extension-specific problems belong in https://github.com/illixion/vscode-vibrancy-continued/issues.
