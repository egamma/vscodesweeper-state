# Issue #239718 — Git - The .gitignore file does not respect exclusions when opening a remote repository

[https://github.com/microsoft/vscode/issues/239718](https://github.com/microsoft/vscode/issues/239718)

## Summary

The bug remains in current main: Explorer applies `.gitignore` filtering to remote repository resources without accounting for files already tracked by the repository, and an ignored parent directory prevents traversal to the tracked exceptions. The issue is already accepted in the Backlog under the appropriate `git` area.

## Change summary

Tracked files negated beneath an ignored directory disappear from Explorer when the repository is opened through Open Remote Repository.

## Best solution

Update Explorer's `.gitignore` integration to preserve repository resources known to be tracked, including tracked files beneath an ignored parent, while continuing to hide genuinely ignored untracked resources in local workspaces.

## Evidence
