## Summary

Recent-file prioritization now addresses part of the original feedback, but the inline picker still lacks the requested category-level navigation. Keep this team-authored request open; the closely related grouping request is newer and cannot be its duplicate canonical under the re-review rules.

## Change summary

Make the chat input's # context suggestions easier to navigate through discoverable context categories and file access consistent with Add Context.
