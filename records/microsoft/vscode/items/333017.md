# Issue #333017 — Context-size configuration is lost for extension-provided models in Agent Host

[https://github.com/microsoft/vscode/issues/333017](https://github.com/microsoft/vscode/issues/333017)

## Summary

The extension-provider context-size projection gap remains in current main: the BYOK bridge extracts reasoning effort but discards context-size choices. Keep this report open; the related reports do not provide an eligible canonical for this re-reviewed item.

## Change summary

Preserve extension-declared context-size choices and the selected value when a model is used through Local Agent Host.

## Best solution

Agent Host should expose the provider's declared context-size choices and honor the selection end to end, rather than merely restoring the dropdown. Establish whether the supported contract covers context size specifically or general provider configuration before implementing the bridge and request-path changes.
