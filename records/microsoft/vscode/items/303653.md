# Issue #303653 — After Keep still all edits are shown

[https://github.com/microsoft/vscode/issues/303653](https://github.com/microsoft/vscode/issues/303653)

## Summary

Keep open: the current source still includes accepted entries in View All Edits instead of limiting it to pending changes. A later report independently confirms the same symptom and was explicitly consolidated into this issue by a maintainer.

## Change summary

After keeping earlier agent edits and producing new changes, View All Edits includes previously accepted files alongside pending edits.

## Best solution

Make the pending-edits multi-diff reflect the current undecided changes while preserving accepted-edit history through the separate View Previous Edits action. Cover accepting edits and then continuing the same session, including reopening the diff editor.
