# Issue #233044 — Webview Panel with `enableFindWidget` does not work after Moving Editor Group into New Window

[https://github.com/microsoft/vscode/issues/233044](https://github.com/microsoft/vscode/issues/233044)

## Summary

Still reproduces on main: `setContextKeyService()` in `webviewElement.ts` does not propagate the new context key service to the find widget, so find highlighting breaks after moving to a new window. An open PR addresses this.

## Change summary

Webview find widget stops highlighting matches after the editor group is moved to a new window via 'Move Editor Group into New Window'.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/269509, which propagates the updated context key service to the `WebviewFindWidget` when `setContextKeyService()` is called on the webview element.
