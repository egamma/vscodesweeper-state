# Issue #315799 — Make test explorer opens popup when agents window starts

[https://github.com/microsoft/vscode/issues/315799](https://github.com/microsoft/vscode/issues/315799)

## Summary

The unwanted panel is created unconditionally by the third-party CMake Test Explorer extension during activation, not by VS Code's Test Explorer or Agents Window code. This should be handled in the extension's own tracker.

## Change summary

Prevent CMake Test Explorer's What's New panel from opening when the extension activates in an Agents Window.

## Best solution

Have CMake Test Explorer suppress or defer its activation-time What's New webview in Agents Windows, tracking the change in https://github.com/fredericbonnet/cmake-test-explorer/issues. The related public Agents Window detection API request remains tracked separately at https://github.com/microsoft/vscode/issues/315776.
