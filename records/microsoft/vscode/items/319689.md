# Issue #319689 — Show process name in Call Stack when only one debug session is active

[https://github.com/microsoft/vscode/issues/319689](https://github.com/microsoft/vscode/issues/319689)

## Summary

The single-session Call Stack still hides the session row and does not visibly identify the session in its header. Keep this open for the maintainer-supported improvement; a running-state hover exposes the name, but does not satisfy the request for persistent visibility.
