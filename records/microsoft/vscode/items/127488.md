# Issue #127488 — Focus stolen from Iframe search

[https://github.com/microsoft/vscode/issues/127488](https://github.com/microsoft/vscode/issues/127488)

## Summary

Keep open: a maintainer confirmed that typing during an in-flight iframe search loses focus, and no verified fix referencing this issue or qualifying older duplicate was found. Current source still performs asynchronous search and result-driven refocusing, but the original timing-dependent failure needs retesting.

## Change summary

Keep keyboard focus in the webview Find input when typing additional characters or spaces while a search is running.

## Best solution

Make webview Find accept uninterrupted typing while asynchronous searches complete, without sending spaces to the preview or unexpectedly scrolling it. Reproduce the original timing window before changing the Electron search and widget focus interaction.
