# Issue #127488 — Focus stolen from Iframe search

[https://github.com/microsoft/vscode/issues/127488](https://github.com/microsoft/vscode/issues/127488)

## Summary

Team-authored webview find widget focus-steal bug from 2021. A related fix (4010ceb4b59 for #127456) addressed copy/paste in the find box, but this specific focus-steal-while-typing issue has no explicit fixing commit. The hasFindResult callback does call focusFindBox(), but the underlying race between iframe focus and the find widget input may still exist.

## Change summary

Typing in the webview find widget causes focus to jump away mid-keystroke, particularly when pressing space or continuing to type while a find operation is in progress.

## Best solution

Investigate whether the webview iframe is reclaiming focus during incremental find operations (the `updateFind` path). The fix likely involves ensuring focus remains in the SimpleFindWidget input while the user is actively typing, possibly by deferring or guarding against focus changes triggered by webview content updates during find.
