# Issue #280907 — explore a replace_selection tool

[https://github.com/microsoft/vscode/issues/280907](https://github.com/microsoft/vscode/issues/280907)

## Summary

Keep open as a deliberate tool-design exploration. Current inline chat remains selection-aware but still requires general edit tools that repeat source text, so the proposed token-efficiency opportunity remains.

## Change summary

Explore an inline-chat tool that replaces the current editor selection without requiring the model to repeat the selected text.

## Best solution

Prototype a selection-scoped edit tool that binds the target URI and range from `ChatRequestEditorData`, accepts only replacement text, and measure token savings and edit reliability before adopting it.
