# Issue #347236 — Provide a Command Palette way to exit Inbox Mode

[https://github.com/microsoft/vscode/issues/347236](https://github.com/microsoft/vscode/issues/347236)

## Summary

The Command Palette exit path is genuinely missing: Inbox Mode only enables Inbox grouping, while alternative grouping commands are not exposed in the palette. Keep open for a decision on the exit interaction and grouping restoration.

## Change summary

Provide a discoverable Command Palette action to leave Inbox Mode, preferably restoring the previous grouping.

## Best solution

Provide a palette-accessible exit or toggle within the Sessions list actions, preserving existing grouping organization. Settle whether exit restores the previous grouping and whether the existing command toggles or remains an entry-only action.
