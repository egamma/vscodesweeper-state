# Issue #179915 — notebook search: output matches not disappearing when dismissed 

[https://github.com/microsoft/vscode/issues/179915](https://github.com/microsoft/vscode/issues/179915)

## Summary

Keep open: dismissing an output search result still has no path to remove its individual webview highlight. The current source confirms the gap described by the maintainer; the related closed issues do not establish a fix.

## Change summary

Dismissing a notebook output result from workspace search should remove its corresponding highlight in the notebook.

## Best solution

Synchronize dismissed workspace-search results with individual rendered-output highlights, preserving highlights for remaining results and keeping notebook-local Find independent.

- **Decoration updates omit rendered-output ranges:** src/vs/workbench/contrib/notebook/browser/contrib/find/findMatchDecorationModel.ts:109–144 updates input text decorations and cell overview-ruler indicators. webviewMatches only determines includeOutput for the ruler; it does not update the webview's stored highlight ranges.
