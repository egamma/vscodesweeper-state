# Issue #346197 — Agent selector is gone in 1.145.0

[https://github.com/microsoft/vscode/issues/346197](https://github.com/microsoft/vscode/issues/346197)

## Summary

The reported visibility changes exactly match the intentional, configurable relocation of the default Agent picker into Add Context. An existing setting restores the always-visible toolbar picker.

## Change summary

Keep the agent selector visible in the toolbar when the default Agent is selected.

## Best solution

Retain the configurable placement behavior and explain that setting sessions.chat.experimental.agentsPickerInAttachContextMenu to false keeps the picker in the toolbar.

- **Proposed comment:**

  > Thanks for the report. This is intentional placement behavior: when `sessions.chat.experimental.agentsPickerInAttachContextMenu` is enabled, the default Agent picker moves into `+` → Agent, while non-default selections remain in the toolbar. Set `"sessions.chat.experimental.agentsPickerInAttachContextMenu": false` to keep it visible in the toolbar; Cmd+. (`workbench.action.chat.openModePicker`) also continues to open it.

- **Behavior explicitly asserted:** src/vs/workbench/contrib/chat/test/browser/widget/input/modePickerActionItem.test.ts:187-209 asserts the exact reported sequence: default selection hides the toolbar picker when relocation is enabled, custom selection restores it, and returning to default hides it again. With the setting false, the picker remains in the toolbar. Tests were inspected, not executed.
