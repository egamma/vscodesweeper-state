# Issue #346197 — Agent selector is gone in 1.145.0

[https://github.com/microsoft/vscode/issues/346197](https://github.com/microsoft/vscode/issues/346197)

## Summary

The selector relocation is intentional and matches the reported default-versus-custom agent behavior exactly. An existing setting restores the always-visible toolbar picker.

## Change summary

Keep the agent selector visible in the toolbar even when the default Agent is selected.

## Best solution

Use "sessions.chat.experimental.agentsPickerInAttachContextMenu": false to retain the toolbar picker for default and non-default agents.

  > Thanks for the report. This is intentional when the Agent picker relocation setting is enabled: the default Agent picker moves into Add Context, while non-default selections remain in the toolbar. Set "sessions.chat.experimental.agentsPickerInAttachContextMenu": false in Settings JSON to keep the picker visible in the toolbar; Cmd+. also continues to open it.
