# Issue #127674 — Extension bisect does not consider "dependent" extensions when choosing what to disable

[https://github.com/microsoft/vscode/issues/127674](https://github.com/microsoft/vscode/issues/127674)

## Summary

The dependency-awareness gap remains on current main, and no canonical issue or implementation was found. Keep this Backlog request open under discussion.

## Change summary

Make Extension Bisect preserve valid extension dependency relationships when selecting extensions to disable.

## Best solution

Build the installed-extension dependency graph when bisect starts and constrain each disabled partition so an enabled extension never loses a required dependency. Add focused tests covering independent dependency chains and transitive dependencies.
