# Issue #324205 — Incorrect tools names in built-in Agents files

[https://github.com/microsoft/vscode/issues/324205](https://github.com/microsoft/vscode/issues/324205)

## Summary

Real, well-diagnosed bug: DEFAULT_READ_TOOLS in agentTypes.ts uses a lowercase 'github.vscode-pull-request-github/...' prefix for two tools, but the GitHub Pull Requests extension's actual published identifier is case-sensitively 'GitHub.vscode-pull-request-github', so those two tool references never resolve for built-in agents (Explore/Plan/Ask) even with the extension installed; a second reporter independently confirmed this affects all three built-in agents and traced it to the exact same file.

## Change summary

Built-in agent .agent.md files list two GitHub Pull Requests extension tools with an incorrect lowercase publisher-prefix casing, so those tools always resolve as 'Unknown tool'.

## Best solution

Fix the casing of the two tool ids in DEFAULT_READ_TOOLS (extensions/copilot/src/extension/agents/vscode-node/agentTypes.ts) to 'GitHub.vscode-pull-request-github/issue_fetch' and 'GitHub.vscode-pull-request-github/activePullRequest' so the built-in Explore/Plan/Ask agents actually get these tools when the extension is installed; separately confirm whether 'github/issue_read' needs the experimental MCP flag documented or enabled by default.
