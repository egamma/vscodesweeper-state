# Issue #324205 — Incorrect tools names in built-in Agents files

[https://github.com/microsoft/vscode/issues/324205](https://github.com/microsoft/vscode/issues/324205)

## Summary

The casing mismatch remains in current main and prevents the built-in Ask, Plan, and Explore agents from selecting the two GitHub Pull Requests tools. The separate github/issue_read warning depends on MCP availability, as the confirming comment explains.

## Change summary

Ensure built-in agents reference the GitHub Pull Requests issue_fetch and activePullRequest tools using names that resolve to the installed extension's tools.

## Best solution

Make the shared built-in agent tool references resolve against the GitHub extension's actual registered names, preserving the agents' read-only scope. Cover both tool lookup and enablement so hiding diagnostics cannot mask missing capabilities.
