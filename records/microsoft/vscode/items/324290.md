# Issue #324290 — Copying multiple empty selections adds blank lines when pasted into a single cursor

[https://github.com/microsoft/vscode/issues/324290](https://github.com/microsoft/vscode/issues/324290)

## Summary

Confirmed regression on current main: commit 20e65fd appends a trailing newline to each multicursorText entry, which then gets doubled by the join in clipboardUtils.ts. An open PR (#324294) exists but has not merged.

## Change summary

Copying from multiple empty selections and pasting into a single cursor inserts spurious blank lines, a regression from 1.108.0.

## Best solution

Fix the double-newline by either removing the trailing newline appended in getPlainTextToCopy (viewModelImpl.ts line 1033) or by changing clipboardUtils.ts to concatenate (not join) when the entries already carry line endings. PR https://github.com/microsoft/vscode/pull/324294 addresses this — review and land it.
