[https://github.com/microsoft/vscode/issues/311656](https://github.com/microsoft/vscode/issues/311656)

## Summary

The report has clear steps, but current source scopes the default Delete command to editor text focus, so the reported routing cannot be confirmed without keybinding diagnostics. A custom or overridden Delete binding is a plausible cause and should be ruled out before treating this as a core defect.

## Change summary

Pressing Delete while the editor Find input is focused removes text from the underlying document instead of the Find query.

## Best solution

Confirm which command wins the Delete keystroke using keyboard-shortcut troubleshooting and inspect the user's keybindings JSON. If the default `deleteRight` binding fires despite Find-input focus, preserve native deletion in the focused input and add a focused Find-widget regression test.
