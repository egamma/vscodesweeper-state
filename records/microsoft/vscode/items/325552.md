# Issue #325552 — Log Panel: Search Flow Chart nodes instead of filter?

[https://github.com/microsoft/vscode/issues/325552](https://github.com/microsoft/vscode/issues/325552)

## Summary

Keep open: the flow chart still filters and reconstructs the displayed graph rather than offering an in-place node search. This team-authored request needs a UX decision, and the older related issues do not cover the same observable problem.

## Change summary

Consider replacing flow-chart text filtering with node search that preserves the surrounding execution context.

## Best solution

Provide an understandable way to locate matching flow-chart nodes without implying that omitted execution steps never occurred. Decide whether text search should replace filtering or coexist with it, while preserving deliberate event-kind filtering.
