# Issue #282230 — NES Long distance hint: Widget should not show so much whitespace

[https://github.com/microsoft/vscode/issues/282230](https://github.com/microsoft/vscode/issues/282230)

## Summary

The whitespace problem remains in the current NES long-distance preview layout: deeply indented content can make the widget unnecessarily wide when the complete line fits. The older Long Distance Todo is an umbrella that links this specific work, not a same-symptom canonical for closing this re-reviewed issue.

## Change summary

Avoid displaying the full leading indentation as empty space in the NES long-distance hint when the target content fits inside the preview.

## Best solution

Keep the preview focused on the meaningful target content rather than allocating visual weight to leading indentation, while preserving the gutter indicator, line numbers, and jump behavior.
