# Issue #22040 — Trigger save even if file is not dirty through API

[https://github.com/microsoft/vscode/issues/22040](https://github.com/microsoft/vscode/issues/22040)

## Summary

The requested capability is available through the stable workspace.save(uri) API, which forces saving an opened editor even when it is clean. The implementation explicitly addresses this issue, and the API shipped in VS Code 1.86.

## Change summary

Allow extensions to save an unchanged file to disk, triggering save participants and external file watchers like the user Save action.

## Best solution

Use workspace.save(document.uri) when an extension needs explicit user-style saving of an opened file, while preserving TextDocument.save() semantics. Close this request as completed by the implemented and finalized API.
