# Issue #22040 — Trigger save even if file is not dirty through API

[https://github.com/microsoft/vscode/issues/22040](https://github.com/microsoft/vscode/issues/22040)

## Summary

Still open: `TextDocument.save()` has no option to force a save of a non-dirty file, and a maintainer agreed an opt-in option is the right direction. The related merged PR does not add it.

## Change summary

Let extensions force `TextDocument.save()` to touch the file on disk even when the document is not dirty.

## Best solution

Add an opt-in force option to the document save API, passed through `$trySaveDocument` to the text file service save call, as the maintainer suggested. Meanwhile, extensions can run the `workbench.action.files.save` command.
