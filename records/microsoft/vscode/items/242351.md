# Issue #242351 — Terminal zoom with mouse wheel conflicts with scrolling

[https://github.com/microsoft/vscode/issues/242351](https://github.com/microsoft/vscode/issues/242351)

## Summary

Still reproduces on main — the terminal zoom contribution never feeds the MouseWheelClassifier before querying it, causing Ctrl+wheel to scroll instead of zoom. An open PR (#310769) already targets this issue.

## Change summary

Ctrl+mouse wheel in the terminal scrolls instead of zooming when `terminal.integrated.mouseWheelZoom` is enabled and the buffer has scrollback content.

## Best solution

Review and land the open fix PR (https://github.com/microsoft/vscode/pull/310769), which mirrors the editor's proven classifier-feed flow and fixes the double-accumulation bug in `terminal.zoom.contribution.ts`.
