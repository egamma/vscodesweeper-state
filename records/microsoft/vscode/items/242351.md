- **Current source:** src/vs/workbench/contrib/terminalContrib/zoom/browser/terminal.zoom.contribution.ts, TerminalMouseWheelZoomContribution._setupMouseWheelZoomListener, queries MouseWheelClassifier.INSTANCE without feeding it the current event. These match the pending PR's diagnosis, but source inspection alone does not establish that its patch resolves every reported case.

This supports the stale-classification concern.
