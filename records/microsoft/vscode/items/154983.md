# Issue #154983 — API request - Support interactive window natively

[https://github.com/microsoft/vscode/issues/154983](https://github.com/microsoft/vscode/issues/154983)

## Summary

Significant progress has been made (the `notebookReplDocument` proposed API with `asRepl` and `replOptions` exists and is implemented), but the API remains in proposed state — not yet finalized. The issue tracks completing and stabilizing this API surface, so it should stay open.

## Change summary

Provide a stable extension API for creating and managing interactive/REPL windows natively, eliminating URI parsing hacks and command-based workarounds.

## Best solution

Finalize the `notebookReplDocument` proposed API (currently in `src/vscode-dts/vscode.proposed.notebookReplDocument.d.ts`) — move `asRepl` on `NotebookDocumentShowOptions` and `replOptions` on `NotebookEditor` to stable, and decide on remaining open questions (edit restrictions, the old `interactiveWindow` proposal cleanup).
