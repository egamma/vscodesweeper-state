Keep this API tracking issue open: current main implements the REPL opening and append-index capabilities as proposed API, not stable API. The api-proposal label explicitly protects it from closure, and a related implementation PR remains open.

## Change summary

Expose native notebook-backed interactive windows through APIs for opening the editor, representing its input cell, and appending history without special URI parsing or commands.
