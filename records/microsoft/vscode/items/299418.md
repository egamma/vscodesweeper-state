# Issue #299418 — Approvals - feedback on the picker/copy in the dialogs

[https://github.com/microsoft/vscode/issues/299418](https://github.com/microsoft/vscode/issues/299418)

## Summary

Keep open: current dialogs now describe the elevated permissions explicitly, but Autopilot still uses the reassuring rocket icon and softer picker copy, so the reported security-communication inconsistency remains. This is also a team-authored item with no issue-referencing fix commit, which rules out treating the partial improvements as a completed close.

## Change summary

Make the Bypass Approvals and Autopilot picker and confirmation dialogs communicate their security implications consistently, without making the more autonomous option appear safer.

## Best solution

Choose a consistent warning treatment for both elevated permission levels across the picker and confirmation dialog, while clearly distinguishing that Autopilot additionally continues autonomously. Preserve the existing confirmation, policy, and dismissal behavior and ensure the risk is conveyed in text rather than by icon alone.
