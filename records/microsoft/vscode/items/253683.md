# Issue #253683 — Support agent mode in the terminal

[https://github.com/microsoft/vscode/issues/253683](https://github.com/microsoft/vscode/issues/253683)

## Summary

A real capability gap remains: terminal inline chat is intentionally Ask-mode and command-oriented, while this canonical Backlog request seeks a full agentic terminal experience.

## Change summary

Merge terminal and agent input into one context-aware interface similar to Warp.

## Best solution

Extend terminal inline chat with an agent-capable interaction mode that retains terminal context and can execute multi-step work without moving the conversation to the Chat view. The terminal chat widget and its chat-agent tool integration are the likely implementation areas.

## Vision fit

- **Fit:** aligned
- **Reason:** Deeper agent integration in the terminal directly supports the AI-native editor while improving CLI and UI interplay.
- **Evidence:** Public value: “Allow for CLI / UI co-existence and interplay”; it also aligns with current agent-experience priorities around terminal integration and tool parity.
