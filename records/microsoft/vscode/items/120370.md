# Issue #120370 — Can not select text in markdown cell

[https://github.com/microsoft/vscode/issues/120370](https://github.com/microsoft/vscode/issues/120370)

## Summary

Still present on main: rendered markup cells set the entire cell element as draggable, which prevents normal text selection. Users must use workarounds (Ctrl+click, entering edit mode, or disabling DnD). No fix commit found.

## Change summary

Text selection in rendered markdown notebook cells is prevented because the cell element is marked draggable, causing mouse interactions to initiate drag instead of text selection.

## Best solution

Restrict the drag handle for markup cells to the left focus indicator margin (as code cells already do) rather than the entire cell content area, so text within the rendered markdown preview can be selected normally. The fix lives in `webviewPreloads.ts` (the MarkupCell class and MarkupCellDragManager) and potentially the backLayerWebView messaging.
