# Issue #327619 — `editor.inlineSuggest.edits.enabled` gates NES but is not registered in the configuration schema

[https://github.com/microsoft/vscode/issues/327619](https://github.com/microsoft/vscode/issues/327619)

## Summary

The schema/runtime mismatch remains in current main: the editor accepts an NES enablement option that its configuration schema does not expose. Keep this team-authored issue open; a maintainer should settle whether that option is a supported user setting or exclusively an internal editor option.

## Change summary

Resolve the mismatch between the working editor.inlineSuggest.edits.enabled switch and its absence from the settings schema.

## Best solution

Make NES enablement a deliberate, consistent configuration contract: either support a discoverable provider-independent editor switch or explicitly retain provider-owned user enablement. Account for existing settings.json values and programmatic editor consumers before removing the current gate.
