# Issue #288502 — Skills should support tools references and enforce them in system prompt

[https://github.com/microsoft/vscode/issues/288502](https://github.com/microsoft/vscode/issues/288502)

## Summary

The prompt file parser already supports `#tool:` references in SKILL.md files, and the customizations index resolves them. However, the specific ask — enforcing referenced tools in the system prompt so the model is guided to use them — may not be fully realized. A team member noted cross-engine portability concerns with VS Code-specific `#tool:` syntax. Keeping open as a feature request since the full enforcement behavior and cross-engine story remain unclear.

## Change summary

Allow `#tool:` references (e.g. `#tool:runSubagent`) inside SKILL.md files and have those tool references enforced in the system prompt sent to the model.

## Best solution

The infrastructure for parsing `#tool:` in SKILL.md exists in `promptFileParser.ts` (line 493) and tool references are resolved in `automaticInstructionsCollector.ts`. The remaining gap may be around explicit enforcement of skill-declared tools in the system prompt, and the cross-engine portability concern raised by @aeschli. This should be evaluated as part of the broader skills capability-declaration work tracked in https://github.com/microsoft/vscode/issues/311166.
