## Change summary

Expose Apple's native Translate action in the macOS editor context menu for selected foreign-language text.

## Best solution

Provide access to native Apple translation for selected editor text on supported macOS versions, without introducing a separate translation service. First establish Electron's supported integration path and how it interacts with VS Code's native and custom context menus.
