# Issue #336661 — Customization migration messages shows "hide for this workspace" in non-workspace chats

[https://github.com/microsoft/vscode/issues/336661](https://github.com/microsoft/vscode/issues/336661)

## Summary

Confirmed on main: the migration hint's dismiss link always reads "Hide for this workspace" regardless of session type, even for non-workspace (harness/cloud agent) chats where that wording doesn't apply — its own tooltip already says "for this harness", so the two are already inconsistent.

## Change summary

The customization migration hint's dismiss action label says "Hide for this workspace" even in chats that aren't tied to a workspace.

## Best solution

Make the dismiss link text session-aware (or generic, dropping the workspace-specific wording) so it matches the tooltip and the actual storage semantics for non-workspace/harness chat sessions.
