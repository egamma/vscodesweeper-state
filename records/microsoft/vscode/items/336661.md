# Issue #336661 — Customization migration messages shows "hide for this workspace" in non-workspace chats

[https://github.com/microsoft/vscode/issues/336661](https://github.com/microsoft/vscode/issues/336661)

## Summary

The issue is confirmed on current main: every customization migration notification offers “Hide for this workspace,” even when the migration service found only user-level customizations. The area is already correctly routed, and the remaining product decision is what dismissal scope a user-only notification should use.

## Change summary

Make the customization migration notification's dismissal action reflect whether the pending migrations are workspace-scoped or user-scoped.

## Best solution

Carry migration-scope information from the customization migration service into the chat notification and present a dismissal action whose wording and persistence scope match the candidates involved. Preserve the current workspace-specific behavior when workspace files or MCP servers are included.
