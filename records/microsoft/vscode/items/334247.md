# Issue #334247 — Copliot: Explore agents terminate without prompting or producing output

[https://github.com/microsoft/vscode/issues/334247](https://github.com/microsoft/vscode/issues/334247)

## Summary

Confirmed in source: when the search/explore subagent's tool-call loop hits its turn limit while the model is still issuing tool calls (no final textual answer yet), `mapLoopResponseToText` in searchSubagentTool.ts unconditionally returns the last round's (empty) response text, so the subagent silently reports nothing back to the parent agent. This is real and worth a targeted fix, so route-to-area rather than close.

## Change summary

Explore/search subagents that hit their internal tool-call limit mid-task terminate and return no output or explanation to the parent agent.

## Best solution

In extensions/copilot/src/extension/tools/node/searchSubagentTool.ts, have `mapLoopResponseToText` check `result.chatResult?.metadata?.maxToolCallsExceeded` (set in toolCallingLoop.ts's `hitToolCallLimit`) and, when the round text is empty, substitute a clear fallback message (similar to `CONTEXT_OVERFLOW_FALLBACK`) telling the parent agent the subagent ran out of turns before producing a final answer.
