# Issue #334247 — Copliot: Explore agents terminate without prompting or producing output

[https://github.com/microsoft/vscode/issues/334247](https://github.com/microsoft/vscode/issues/334247)

## Summary

Traced the root cause on main: subagents silently drop their work at the tool-call limit instead of producing a final report or extending automatically, matching the reporter's description exactly.

## Change summary

When a subagent (Explore/Search) hits the chat.agent.maxRequests limit, it stops without producing any output or warning, wasting the work already done.

## Best solution

In extensions/copilot/src/extension/intents/node/toolCallingLoop.ts, subagent requests (options.request.subAgentInvocationId set) should either auto-extend the limit like autopilot mode does (lines ~1444-1454) or force one final summarization turn before stopping, instead of silently breaking out of the loop with only a `maxToolCallsExceeded` metadata flag and no stream to show a confirmation.

## Evidence

- **hitToolCallLimit only prompts with a stream:** extensions/copilot/src/extension/intents/node/toolCallingLoop.ts:1691-1719 — `hitToolCallLimit` calls `stream.confirmation(...)` only `if (stream && this.options.onHitToolCallLimit === ToolCallLimitBehavior.Confirm)`; subagents run without an interactive `outputStream`, so nothing is shown and the loop just returns `lastResult` with `maxToolCallsExceeded: true` in metadata — no final report is produced.
- **limit is inherited via chat.agent.maxRequests:** extensions/copilot/src/extension/intents/common/agentConfig.ts:10-13 reads `chat.agent.maxRequests` via `getAgentMaxRequests`, used by agentIntent.ts/askAgentIntent.ts for the same toolCallLimit regardless of whether the request is a top-level agent or a subagent (`options.request.subAgentInvocationId`).
- **autopilot has an escape hatch subagents lack:** toolCallingLoop.ts:1443-1455 shows only `permissionLevel === 'autopilot'` silently extends the limit (up to 200); non-autopilot subagents fall straight into `hitToolCallLimit` with no stream and no extension, terminating without producing usable output.
