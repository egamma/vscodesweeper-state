# Issue #209902 — Search for symbols does not consider settings.exclude after window reload.

[https://github.com/microsoft/vscode/issues/209902](https://github.com/microsoft/vscode/issues/209902)

## Summary

Two team members (andreamah, jrieken) confirmed that `search.exclude` is a workspace/file search setting and is not expected to apply to symbol search (`#` quick open). Symbol filtering is the responsibility of the language extension providing the symbols. This is as-designed.

## Change summary

Symbol search via `#` in Quick Open returns results from folders listed in `search.exclude`.

## Best solution

Close as `*as-designed`: `search.exclude` governs file and text search, not workspace symbol providers. Users who want symbol filtering should configure it in their language extension (e.g. TypeScript's `search.exclude` is separate from workspace symbol results). If a language extension returns symbols from excluded paths, the fix belongs in that extension's configuration.

  > Thanks for the report. As noted by the team above, `search.exclude` is a workspace and file search setting — it governs text search and file search, not symbol search (`#` in Quick Open). Symbol results come from language extensions (e.g. TypeScript), and it's up to those extensions to decide which files to index and return symbols for.
