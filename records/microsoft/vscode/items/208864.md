# Issue #208864 — Support cell output toolbar contribution

[https://github.com/microsoft/vscode/issues/208864](https://github.com/microsoft/vscode/issues/208864)

## Summary

Still unimplemented: the NotebookOutputToolbar menu exists internally (MenuId.NotebookOutputToolbar in actions.ts) but is not exposed to extensions — it is absent from menusExtensionPoint.ts, so extensions cannot contribute commands to it. The feature request remains valid.

## Change summary

Allow extensions to contribute actions to the notebook cell output toolbar (e.g. 'Explain the output').

## Best solution

Register `notebook/cell/output` (mapped to MenuId.NotebookOutputToolbar) in src/vs/workbench/services/actions/common/menusExtensionPoint.ts, similarly to `notebook/cell/title` and `notebook/cell/execute`, so extensions can contribute items to the cell output toolbar menu.
