[https://github.com/microsoft/vscode/issues/208864](https://github.com/microsoft/vscode/issues/208864)

## Summary

The extension contribution gap remains: the output toolbar uses an internal menu that is not exposed through contributes.menus. Keep this request open; existing cell-title contributions do not cover output-specific actions, and no verified canonical or fixing PR was found.

## Change summary

Allow extensions to contribute notebook cell output toolbar actions, such as explaining an output.

## Best solution

Expose a supported output-toolbar menu contribution with an extension-safe invocation context identifying the relevant cell and output. Preserve the existing built-in output actions and establish the public contribution contract before implementation.
