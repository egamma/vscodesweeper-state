# Issue #214896 — Quoting issue with command sent to the terminal

[https://github.com/microsoft/vscode/issues/214896](https://github.com/microsoft/vscode/issues/214896)

## Summary

The failure is owned by the Python debugger's debugpy adapter, not VS Code's terminal handling. The matching Python Debugger report was fixed in debugpy, so this should be moved back to the owning tracker for release verification rather than closed here.

## Change summary

Quote Python interpreter and program paths containing spaces when debugpy requests shell-expanded arguments through DAP runInTerminal.

## Best solution

Verify that the debugpy fixes from https://github.com/microsoft/debugpy/pull/1981 and https://github.com/microsoft/debugpy/pull/1982 are included in the current Python Debugger extension, then resolve the matching report in https://github.com/microsoft/vscode-python-debugger/issues/233. The issue should live in the Python Debugger tracker because that extension owns the request construction and bundled debugpy version.

## Evidence

- **matching report:** https://github.com/microsoft/vscode-python-debugger/issues/233 documents the same `c:\Program` PowerShell failure when a Python interpreter under Program Files is launched with string-form arguments, including multiple confirmations and the array-form workaround.
- **root cause:** Current VS Code code in src/vs/workbench/contrib/debug/node/terminals.ts quotes PowerShell arguments unless `argsCanBeInterpretedByShell` is true. src/vs/workbench/api/node/extHostDebugService.ts passes the adapter-provided flag through to `prepareCommand`, matching the DAP contract.
- **adapter fix:** https://github.com/microsoft/debugpy/pull/1981 merged as https://github.com/microsoft/debugpy/commit/e5017d736052d8d84484cdfe05750bd61cc7c50f and explicitly fixes spaces in runInTerminal arguments by quoting them inside debugpy when shell interpretation is requested.
- **follow-up fix:** https://github.com/microsoft/debugpy/pull/1982 merged as https://github.com/microsoft/debugpy/commit/698499e9ec6cd6edcf0311bb3a0b0d57ad1198ad and extends the adapter-side quoting fix to Python program paths containing spaces.
- **maintainer assessment:** https://github.com/microsoft/vscode/issues/214896#issuecomment-3642665604 states that quoting belongs in debug land because the terminal receives the resulting raw command line.
