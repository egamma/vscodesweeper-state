# Issue #293880 — Communication record is missing after pressing "del" key in plan mode

[https://github.com/microsoft/vscode/issues/293880](https://github.com/microsoft/vscode/issues/293880)

## Summary

This was fixed on main: Delete can no longer invoke Undo Requests or Restore Checkpoint while focus is inside the question carousel, so editing a custom answer no longer removes the conversation.

## Change summary

Pressing Delete while editing a custom answer in the Ask Questions UI removed the preceding chat record or conversation.

## Best solution

Keep the focused-question-carousel guards added by commit 9497369946455ac0478669ec1a99d649052b7de9; they prevent chat-level destructive keybindings from handling text-editing keys.
