# Issue #335894 — Sessions list can show stale In Progress status when input is needed

[https://github.com/microsoft/vscode/issues/335894](https://github.com/microsoft/vscode/issues/335894)

## Summary

Team-authored, well-diagnosed bug in the Agents Window sessions list: verified against current main that the cached default-chat status can go stale after the 30s session-state subscription lease expires, causing the row to show In Progress instead of Input Needed until the session is reopened. No fix has landed yet, so this stays open.

## Change summary

The Sessions list can keep showing 'In Progress' for a session that actually needs input, until the user opens it, because the cached main-chat status goes stale after the provider's session-state subscription lease expires.

## Best solution

Fix belongs in src/vs/sessions/contrib/providers/agentHost/browser/baseAgentHostSessionsProvider.ts (the default-chat status cache / subscription lifecycle) and/or sessionsList.ts's getSessionRowStatus — either keep the lightweight summary subscription informed of default-chat status changes even after the full-state lease expires, or invalidate/refresh the cached override on lease release so the list re-derives status correctly.
