# Issue #272831 — Chat response: mix of ✅ in response

[https://github.com/microsoft/vscode/issues/272831](https://github.com/microsoft/vscode/issues/272831)

## Summary

The visual inconsistency remains possible on current main: product-generated progress uses Codicon checkmarks while model-authored Markdown preserves Unicode emoji. Collapsing more thinking output reduces its visibility but does not resolve the underlying mismatch.

## Change summary

Use a visually consistent checkmark treatment when chat responses combine product progress indicators with model-authored checkmark emoji.

## Best solution

Choose one presentation contract for checkmarks in chat responses, accounting for both rendered appearance and copied/exported Markdown, then apply it consistently across model-authored content and product-owned progress UI.
