# Issue #326310 — Make command risk assessment explanations respect `github.copilot.chat.localeOverride`

[https://github.com/microsoft/vscode/issues/326310](https://github.com/microsoft/vscode/issues/326310)

## Summary

Current main still generates risk explanations from an English-only prompt without consulting `github.copilot.chat.localeOverride`; route this confirmed, bounded bug to the chat tools and terminal chat owners.

## Change summary

Command risk assessment explanations remain in English when Copilot Chat is configured to respond in another language.

## Best solution

Make risk-assessment generation honor the existing Copilot locale override while preserving the language-independent risk classification and strict JSON contract, including after the locale changes during a session.
