# Issue #71800 — Mac shortcut not working (in vscode) [cmd+h or cmd+m]

[https://github.com/microsoft/vscode/issues/71800](https://github.com/microsoft/vscode/issues/71800)

## Summary

Partially fixed by PR #154648 (webview dispose now calls didBlur, restoring menu shortcuts after closing a webview), but the core issue remains: while a webview is focused, macOS system shortcuts Cmd+H and Cmd+M are blocked because Electron's setIgnoreMenuShortcuts(true) is called on webview focus. The issue has 123 upvotes, a `help wanted` label, and is accepted in the Backlog — it should stay open.

## Change summary

macOS system shortcuts Cmd+H (Hide) and Cmd+M (Minimize) do not work while a webview has focus, and historically remained broken even after the webview was closed or blurred.

## Best solution

The remaining gap is in `WindowIgnoreMenuShortcutsManager`: when a webview is focused it calls `setIgnoreMenuShortcuts(true)` which blanket-disables all native menu shortcuts, including macOS system ones like Cmd+H/Cmd+M. A fix would need to selectively allow system shortcuts through while still letting the webview capture other key combos — likely requiring Electron-level changes or a workaround that detects specific system shortcut keys and temporarily re-enables menu shortcuts. The `help wanted` label is appropriate; this is a good community contribution candidate.
