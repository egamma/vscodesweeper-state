## Summary

The report does not establish whether VS Code's explicit commit-signing setting was enabled. Request current reproduction details before deciding whether this is a configuration override or a remaining Git integration defect.

## Change summary

Committing through VS Code prompts for GPG signing despite repository-local commit.gpgsign=false.

## Best solution

When git.enableCommitSigning is false, ordinary Source Control commits should defer to Git's effective configuration, including repository-local signing overrides. Establish whether that path still fails; preserve the documented explicit-signing behavior when the VS Code setting is true.
