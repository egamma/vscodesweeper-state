[https://github.com/microsoft/vscode/issues/15106](https://github.com/microsoft/vscode/issues/15106)

## Summary

Keep this accepted Backlog request open. Current settings cover visibility, thickness, and page-wise track clicks, but supported scrollbar arrow controls and a consistent traditional-scrollbar mode remain missing.

## Change summary

Provide an optional traditional scrollbar with persistent visibility, larger dimensions, line-scroll arrow buttons, and page-wise track clicks.
