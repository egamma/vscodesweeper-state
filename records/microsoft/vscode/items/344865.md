# Issue #344865 — Add an option to add worktree to workspace

[https://github.com/microsoft/vscode/issues/344865](https://github.com/microsoft/vscode/issues/344865)

## Summary

Keep open: the requested worktree-to-workspace action is still missing, and a maintainer explicitly accepted both the context-menu action and the post-creation choice. The existing Add Folder to Workspace workflow is a workaround, not equivalent coverage.

## Change summary

Offer Add Worktree to Workspace from Source Control and after creating a worktree.

## Best solution

Provide a direct action that adds the selected worktree folder without replacing the current workspace, and offer it after successful worktree creation. Treat the GitHub Pull Requests workflow and worktree-location consistency as separate follow-up scope.
