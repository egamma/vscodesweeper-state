# Issue #344865 — Add an option to add worktree to workspace

[https://github.com/microsoft/vscode/issues/344865](https://github.com/microsoft/vscode/issues/344865)

## Summary

The built-in Git worktree commands still lack an Add to Workspace action and a post-creation destination choice. Keep this as a feature request; the existing folder-picker workaround does not cover the requested convenience.

## Change summary

Offer Add to Workspace for existing worktrees and a choice to open, add, or leave a newly created worktree.

## Best solution

Extend the built-in Git worktree experience with an Add to Workspace action and consider a post-creation destination chooser consistent with the existing Git initialization flow, preserving the option to leave the worktree unopened.
