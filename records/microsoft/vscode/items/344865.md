# Issue #344865 — Add an option to add worktree to workspace

[https://github.com/microsoft/vscode/issues/344865](https://github.com/microsoft/vscode/issues/344865)

## Summary

The requested shortcut remains missing: worktree actions open a window but cannot add the selected worktree to the current workspace, and creation offers no follow-up choice. The related workspace-level worktree request covers a different workflow, so it is not a verified duplicate.

## Change summary

Offer Add to Workspace for existing worktrees and a post-creation choice to open, add, or leave the worktree unopened.

## Best solution

Provide the workspace-add action in the built-in Git worktree surfaces, consistent with existing repository workflows. Consider the requested post-creation choices without changing the behavior of programmatic worktree creation.
