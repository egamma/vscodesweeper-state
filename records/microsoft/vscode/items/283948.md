# Issue #283948 — Support for Gemini Multimodal Capabilities in VS Code Copilot

[https://github.com/microsoft/vscode/issues/283948](https://github.com/microsoft/vscode/issues/283948)

## Summary

VS Code Copilot already supports Gemini models with image/vision capabilities (native provider, image attachments, screenshot context), but the request's core ask — Gemini Multimodal Live (real-time streaming audio/video) — is not implemented and is a genuinely distinct capability. Keeping open as a feature request in Backlog with 17 upvotes; below the 20-upvote promotion threshold but not stale enough for community closure.

## Change summary

Integrate Gemini's multimodal live capabilities (real-time audio, video, and cross-modal understanding) into VS Code Copilot beyond the existing image/vision support.

## Best solution

The static image/vision multimodal path is already implemented (Gemini native BYOK provider with vision capability, image attachments, screenshot context). The remaining gap is Gemini's Multimodal Live API for real-time streaming modalities (audio/video), which is a significant architectural addition. This should stay open as a feature request; the team can evaluate whether real-time multimodal streaming fits the editor's interaction model or is better served by an extension.
