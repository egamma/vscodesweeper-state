# Issue #332231 — regression in 1.134.0: cannot search old chat sessions via `workbench.action.quickOpen`

[https://github.com/microsoft/vscode/issues/332231](https://github.com/microsoft/vscode/issues/332231)

## Summary

The `agent ` prefix disappeared because an approved, merged change deliberately removed the legacy global session picker. Current VS Code retains a searchable session picker in the chat title, providing the alternative browsing route requested by the reporter.

## Change summary

Restore quick browsing of past agent chats through the `agent ` Quick Open prefix, or explain the replacement workflow.

## Best solution

Keep the deliberate retirement of the legacy Quick Open provider and explain the chat-title session picker, which searches historical sessions rather than only open editors. The sessions sidebar also provides a Find Agent Session action.

- **Proposed comment:**

  > Thanks for the report. The legacy `agent ` Quick Open provider was deliberately removed in https://github.com/microsoft/vscode/pull/329501, so that text now goes through file search.
  > 
  > To browse past chats, select the current chat's title to open the searchable session picker (`workbench.action.chat.pickAgentSession`). It includes historical sessions, not only currently open chats, while excluding archived sessions and honoring your session filters. You can also use the search button in the sessions sidebar (`agentSessionsViewer.find`).
