# Issue #332231 — regression in 1.134.0: cannot search old chat sessions via `workbench.action.quickOpen`

[https://github.com/microsoft/vscode/issues/332231](https://github.com/microsoft/vscode/issues/332231)

## Summary

Reasonable regression report: on current main, typing an `agent ` prefix into `workbench.action.quickOpen` has no special handling — it just falls through to the default `AnythingQuickAccessProvider` file search. The only place `agent ` is wired up as a session-search prefix is the experimental `UnifiedQuickAccess` widget, which lives behind its own command and the off-by-default `chat.unifiedAgentsBar.enabled` setting, not inside the standard Quick Open picker.

## Change summary

Typing `agent ` into the default Quick Open (`workbench.action.quickOpen`) used to browse/search past agent chat sessions; since 1.134.0 it only searches repo files and no longer surfaces sessions.

## Best solution

A chat/quick-open owner should confirm whether session search was intentionally moved into the new `UnifiedQuickAccess` experiment (`src/vs/workbench/contrib/chat/browser/agentSessions/experiments/unifiedQuickAccess.ts`, prefix `'agent '`, gated by `chat.unifiedAgentsBar.enabled`, default false) versus a real regression of a previously always-available capability — if intentional, document/promote the new command (`workbench.action.showAgentSessionsQuickAccess`); if not, restore an `agent ` prefix provider in the default `IQuickAccessRegistry`.
