# Issue #318383 — Can't exit when "Cannot reconnect. Please reload the window." dialogue shown

[https://github.com/microsoft/vscode/issues/318383](https://github.com/microsoft/vscode/issues/318383)

## Summary

Valid bug: the "Cannot reconnect" modal dialog shown by the remote reconnection failure handler blocks the macOS quit flow — Cmd+Q and Code > Quit are ignored while the dialog is open. The code at `src/vs/workbench/contrib/remote/browser/remote.ts:1008` still shows this dialog via `dialogService.confirm()` on current main with no special handling for app quit.

## Change summary

On macOS, VS Code cannot be quit (Cmd+Q / menu) while the "Cannot reconnect. Please reload the window." modal dialog is displayed after a remote SSH connection failure.

## Best solution

The reconnection-failure dialog should not block app quit. Either dismiss the dialog on shutdown, allow the quit lifecycle to proceed while the dialog is open, or switch to a non-blocking notification. The fix likely belongs in `src/vs/workbench/contrib/remote/browser/remote.ts` around the `dialogService.confirm()` call at line 1008, or in the dialog/lifecycle interaction layer.
