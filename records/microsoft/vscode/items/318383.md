# Issue #318383 — Can't exit when "Cannot reconnect. Please reload the window." dialogue shown

[https://github.com/microsoft/vscode/issues/318383](https://github.com/microsoft/vscode/issues/318383)

## Summary

Keep open: the reporter confirmed the failure after upgrading, and another user independently reproduced blocked macOS quit and system restart in October. Current source still presents the native reconnect-failure dialog; no applicable fixing commit or verified open canonical was found.

## Change summary

On macOS, a remote reconnection-failure dialog prevents normal application quit until the dialog is dismissed.

## Best solution

Allow normal application quit with remote failure dialogs outstanding, while preserving disconnected-window feedback and legitimate unsaved-change shutdown checks. Investigate the native dialog and application lifecycle interaction before choosing a workaround; the reconnect UI is implemented in VS Code core, not Remote-SSH.

With one or several remote failure dialogs outstanding, Cmd+Q and the application Quit menu should complete the normal shutdown flow without requiring manual dismissal of each dialog.
