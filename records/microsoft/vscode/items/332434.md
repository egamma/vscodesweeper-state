# Issue #332434 — Agent Host: dispatchAction does validate not whether clients can dispatch that action

[https://github.com/microsoft/vscode/issues/332434](https://github.com/microsoft/vscode/issues/332434)

## Summary

Confirmed still-present on main: the dispatchAction handler validates action family membership, not per-type client-dispatchability, so server-owned action types inside a permitted family can still be dispatched by a client. No fix has landed yet.

## Change summary

The AHP protocol server's dispatchAction guard checks action family (isSessionAction/isChatAction/etc.) instead of the per-type isClientDispatchable() check, letting clients dispatch server-owned action types.

## Best solution

Replace the family-membership guard in src/vs/platform/agentHost/node/protocolServerHandler.ts (around line 515) with a per-type isClientDispatchable(action) check from reducer-helpers.ts, rejecting server-owned actions explicitly; likely needs isClientDispatchable's type signature expanded to cover all dispatchable action unions.
