# Issue #332434 — Agent Host: dispatchAction does validate not whether clients can dispatch that action

[https://github.com/microsoft/vscode/issues/332434](https://github.com/microsoft/vscode/issues/332434)

## Summary

The validation gap remains on current main: `dispatchAction` accepts every action in several protocol families rather than checking whether the specific action is client-dispatchable. The merged automation work explicitly preserved this pre-existing gap for maintainer follow-up, so the issue should remain open.

## Change summary

Reject client-originated AHP actions whose individual action type is designated as server-owned.

## Best solution

Validate each incoming `dispatchAction` against the protocol's per-action origin metadata, reject server-owned actions without forwarding them to `AgentService`, and preserve dispatch of all currently permitted client actions.
