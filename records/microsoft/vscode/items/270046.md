# Issue #270046 — pressing ctrl+enter while focused on notebook inline chat should keep focus in the chat

[https://github.com/microsoft/vscode/issues/270046](https://github.com/microsoft/vscode/issues/270046)

## Summary

Still reproducible on main: the ExecuteCell action (Ctrl+Enter) in executeActions.ts has no inline-chat focus guard, so it moves focus to the cell container when inline chat is open. The old NotebookChatController handled this but was removed in the cleanup PR without an equivalent replacement.

## Change summary

Pressing Ctrl+Enter while focused on notebook inline chat moves focus to the cell container instead of keeping it in the chat widget.

## Best solution

Add a focus-retention guard in the ExecuteCell action (src/vs/workbench/contrib/notebook/browser/controller/executeActions.ts) that checks CTX_INLINE_CHAT_FOCUSED before moving focus, similar to how ExecuteCellSelectBelow already negates it in its keybinding precondition — or execute the cell without the focusNotebookCell call when inline chat has focus.
