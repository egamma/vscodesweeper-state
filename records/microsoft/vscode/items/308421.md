# Issue #308421 — Black background after space in terminal

[https://github.com/microsoft/vscode/issues/308421](https://github.com/microsoft/vscode/issues/308421)

## Summary

The primary reported symptom (black background after spaces in PowerShell) is caused by an outdated PSReadLine module shipping with Windows PowerShell 5.1, confirmed by multiple users and Microsoft's own docs. However, VS Code's xterm.css does contain a hardcoded `background: #000` on `.composition-view` (line 85) that is a legitimate minor styling issue, and an open PR (#312119) addresses it. Keeping open for the PR.

## Change summary

Black background rectangles appear after typing spaces in the VS Code terminal with PowerShell, caused by outdated PSReadLine sending incorrect VT escape sequences, compounded by a hardcoded black background in the terminal composition view CSS.

## Best solution

The reporter's problem is resolved by updating PSReadLine (`Install-Module PSReadline -Force`). The remaining VS Code-side improvement — replacing the hardcoded `background: #000` in `src/vs/workbench/contrib/terminal/browser/media/xterm.css` `.composition-view` with a theme-aware variable — is addressed by the open PR https://github.com/microsoft/vscode/pull/312119, which should be reviewed and landed or closed.
