[https://github.com/microsoft/vscode/issues/338079](https://github.com/microsoft/vscode/issues/338079)

## Summary

Likely related to a very similar, previously-fixed bug (#192954, fixed in commit 22aaa65 / 1.116.0) about editor associations not being respected for markdown on cold start, but that fix is already present on current main and the reporter is on 1.139.1 — so either this is a different trigger (not app cold-start) or a regression. Too thin to confirm from source alone; needs the reporter to clarify the exact trigger and settings.

## Change summary

After setting a non-default editor (e.g. Markdown Editor/Preview) as the default for .md files via 'reopen editor with' / editor associations, closing and reopening the file falls back to the plain text editor instead of honoring the configured default.

## Best solution

Confirm whether this reproduces only after a full VS Code restart (same class of race as #192954's cold-start cache-miss) or also within a running session/non-cold-start reopen; if the former, it may indicate the existing cache/user-association check in editorResolverService.ts still misses this path and needs a follow-up fix, if the latter it's a distinct bug in the same resolver area.
