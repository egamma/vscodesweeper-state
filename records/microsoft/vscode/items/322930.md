# Issue #322930 — Make the changes that an agent has made immediately obvious

[https://github.com/microsoft/vscode/issues/322930](https://github.com/microsoft/vscode/issues/322930)

## Summary

Keep open: this is a MEMBER-authored Agents Window UX work item with concrete study evidence and success criteria, and protected team-authored product issues should not be judgment-closed.

## Change summary

Make agent-created changes visible through a one-click, always-current diff from chat or agent activity, including previews before sensitive edit approvals.

## Best solution

Track and implement this in the Agents Window/chat UX: expose a reliable live diff from active agent activity, make changed files open to diffs rather than plain file contents, and include enough proposed-change detail in approval prompts for informed allow/deny decisions.
