# Issue #331021 — Allow configuring the window zoom increment/step

[https://github.com/microsoft/vscode/issues/331021](https://github.com/microsoft/vscode/issues/331021)

## Summary

Genuine gap confirmed on main: zoom in/out always changes the level by a whole increment (rounded via Math.round), and there's no setting to adjust that step size. Fresh report with no traction yet, so route it to the zoom area rather than close.

## Change summary

Add a setting (e.g. `window.zoomStep`) to control the increment used by Zoom In/Zoom Out, since it's currently fixed at one whole zoom level (~20%) per keypress.

## Best solution

Add a `window.zoomStep` (or similarly named) setting read in `BaseZoomAction.setZoomLevel` in src/vs/workbench/electron-browser/actions/windowActions.ts, replacing the hardcoded `+1`/`-1` increments in ZoomInAction/ZoomOutAction with a configurable step, while keeping the existing MIN/MAX zoom clamping and per-window/all-window target logic intact.
