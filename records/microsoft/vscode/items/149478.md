# Issue #149478 — Some keyboard shortcuts ignored in Safari/vscode.dev

[https://github.com/microsoft/vscode/issues/149478](https://github.com/microsoft/vscode/issues/149478)

## Summary

Still unfixed on main: browser-native shortcuts (Cmd+, in Safari, Cmd+K Cmd+T in Edge) intercept VS Code keybindings in vscode.dev, and the UI still displays these non-functional shortcuts. The team discussed but no resolution was implemented.

## Change summary

Some keyboard shortcuts (e.g. Cmd+, for settings, Cmd+K Cmd+T for themes) are intercepted by the browser in Safari/Edge on vscode.dev, yet the UI still displays them.

## Best solution

Either suppress display of non-functional shortcuts per browser (comment 7's suggestion), or find a way to preventDefault on these browser-intercepted keys in vscode.dev. The keybinding service could conditionally hide or mark shortcuts known to conflict with browser-native behavior on Safari/Edge.
