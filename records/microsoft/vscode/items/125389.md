# Issue #125389 — Remote terminals don't respect strictEnv

[https://github.com/microsoft/vscode/issues/125389](https://github.com/microsoft/vscode/issues/125389)

## Summary

Traced the current environment-resolution code for both local and remote terminal creation paths and found `strictEnv` is honored consistently in both — the local/remote divergence the report describes doesn't match current main's logic, so I'm proposing not-reproducible rather than re-citing the previously refuted fix commit.

## Change summary

A terminal created with `strictEnv: true` picks up `terminal.integrated.env.*` settings and extension `environmentVariableCollection` entries on remote-ssh/WSL/containers, even though they're correctly excluded locally.
