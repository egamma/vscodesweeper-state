# Issue #125389 — Remote terminals don't respect strictEnv

[https://github.com/microsoft/vscode/issues/125389](https://github.com/microsoft/vscode/issues/125389)

## Summary

The remote terminal code on current main properly respects strictEnv in both the environment-settings path (createTerminalEnvironment checks strictEnv at line 254) and the env-var-collection path (shouldUseEnvironmentVariableCollection returns !slc.strictEnv at line 127, used in remoteTerminalChannel.ts line 248). The bug appears resolved through restructuring and alignment fixes, though no commit explicitly references this issue.

## Change summary

Remote terminals ignore the strictEnv flag, applying terminal.integrated.env.* settings and extension environment variable collections even when strictEnv is true.

## Best solution

Close as completed — the remote terminal channel in src/vs/server/node/remoteTerminalChannel.ts now properly checks strictEnv in both the createTerminalEnvironment call (which short-circuits to only use shellLaunchConfig.env) and the shouldUseEnvironmentVariableCollection guard before applying extension env var collections. No further change is needed.
