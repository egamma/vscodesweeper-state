# Issue #331687 — revealFileInOS may ignore the passed URI or pick additional URIs from Explorer selection depending on UI state

[https://github.com/microsoft/vscode/issues/331687](https://github.com/microsoft/vscode/issues/331687)

## Summary

The defect remains present on current main, and an open PR explicitly fixes this issue by adding a URI-specific reveal command and migrating affected consumers. Keep the issue open until that PR is reviewed and either merged or replaced.

## Change summary

An explicit URI passed to `revealFileInOS` can be ignored in favor of the focused Explorer selection, causing callers to reveal the wrong resource.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/331755, or an equivalent implementation that preserves Explorer multi-selection semantics while giving explicit-URI callers a selection-independent reveal path.
