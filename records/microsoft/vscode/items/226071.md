# Issue #226071 — Unable to pass `target: Workspace`  to `workbench.action.openSettings2` command

[https://github.com/microsoft/vscode/issues/226071](https://github.com/microsoft/vscode/issues/226071)

## Summary

Still reproduces on main: the `sanitizeOpenSettingsArgs` function strips the `target` property from the command args, so it never reaches the settings editor even though the editor supports it.

## Change summary

The `workbench.action.openSettings2` command ignores the `target` option (e.g. `ConfigurationTarget.Workspace`) because argument sanitization drops it.

## Best solution

Add `target` passthrough in `sanitizeOpenSettingsArgs` (src/vs/workbench/contrib/preferences/browser/preferences.contribution.ts line ~184) so the settings editor receives it and switches to the workspace tab as intended.
