# Issue #282485 — Make default color decorator be followed only by string or empty space before determining if its a color

[https://github.com/microsoft/vscode/issues/282485](https://github.com/microsoft/vscode/issues/282485)

## Summary

The default color provider still recognizes an indented TypeScript private method named #add as a hex color. Keep this maintainer-authored follow-up open: disabling decorators is a workaround, and the related reports are closed rather than usable duplicate targets.

## Change summary

Prevent default hex-color detection from decorating non-color identifiers such as #add() while retaining legitimate color literals.

## Best solution

Make default color detection respect the intended trailing context without disabling legitimate color previews. Review the existing overlapping implementation candidates before starting another fix.
