# Issue #291169 — Testing: Approve tool result overflows container

[https://github.com/microsoft/vscode/issues/291169](https://github.com/microsoft/vscode/issues/291169)

## Summary

The subagent post-execution approval still has a source-visible layout defect on current main: its code block is rendered at the full chat-response width and is not relaid out to the narrower confirmation container. This is distinct from the older handoff-button overflow report and should remain open for a bounded chat UI fix.

## Change summary

Keep the tool-result code block contained within the approval widget when post-execution approval appears inside an expanded subagent.

## Best solution

Size post-approval result editors from their actual confirmation-message container and keep them synchronized when that container resizes, without changing approval behavior or ordinary tool-result presentation.
