# Issue #327212 — Chat custom endpoint: API key stored with trailing newline, causing 403 on all requests

[https://github.com/microsoft/vscode/issues/327212](https://github.com/microsoft/vscode/issues/327212)

## Summary

Confirmed on current main: the LanguageModelsService stores secret values (API keys) without trimming whitespace, causing 403s when the pasted key includes a trailing newline. The BYOK path in the Copilot extension trims on read, but the core chatLanguageModels.json path does not trim at all.

## Change summary

API keys pasted with trailing whitespace into the custom endpoint configuration dialog are stored verbatim, causing authentication failures.

## Best solution

Trim the secret value before storing it in `_resolveLanguageModelProviderGroup` (line ~2106 of `src/vs/workbench/contrib/chat/common/languageModels.ts`). A single `.trim()` on the value before the `_secretStorageService.set()` call fixes the core path. The BYOK path's `storeAPIKey` in `extensions/copilot/src/extension/byok/vscode-node/byokStorageService.ts` should also trim on store (it currently only trims on read), for defense-in-depth.
