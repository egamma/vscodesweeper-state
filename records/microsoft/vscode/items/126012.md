# Issue #126012 — Emmet wrap abbreviation behaviour change in JSX

[https://github.com/microsoft/vscode/issues/126012](https://github.com/microsoft/vscode/issues/126012)

## Summary

Still reproduces on main: the Emmet wrap abbreviation logic in JSX incorrectly expands the selection to the parent component when the cursor is inside a tag nested within curly braces. No fix has landed; #133650 was closed as a duplicate of this issue.

## Change summary

Emmet 'Wrap with Abbreviation' wraps the entire parent JSX component instead of just the selected line when used inside curly brackets (render props, expressions).

## Best solution

Fix the `wrapWithAbbreviation` range expansion in `extensions/emmet/src/abbreviationActions.ts` — the `isOffsetInsideOpenOrCloseTag` check needs to account for JSX expression containers (curly braces) so it doesn't walk up to the parent component. The `emmet-parse` label correctly identifies this as a parser-level issue in how the flat node tree represents JSX expressions.
