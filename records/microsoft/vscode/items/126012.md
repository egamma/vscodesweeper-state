# Issue #126012 — Emmet wrap abbreviation behaviour change in JSX

[https://github.com/microsoft/vscode/issues/126012](https://github.com/microsoft/vscode/issues/126012)

## Summary

Keep open as the established report for wrapping the wrong JSX component inside render props. Independent reports corroborate the selection expansion, current source retains the implicated range-promotion path, and no verified fix or eligible older same-symptom canonical was found.

## Change summary

Emmet Wrap with Abbreviation wraps the enclosing component instead of the selected JSX inside a render prop.

## Best solution

Make wrapping target the selected JSX within a render prop while preserving intentional whole-element wrapping when the cursor is actually inside that element's opening or closing tag. Establish the parser output for the reported cases before deciding the scope of the correction.
