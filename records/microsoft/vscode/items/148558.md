# Issue #148558 — Keep the current reference search results and open new reference in new view

[https://github.com/microsoft/vscode/issues/148558](https://github.com/microsoft/vscode/issues/148558)

## Summary

Keep open in the Backlog: 32 community upvotes exceed the promotion threshold, and current reference history does not provide multiple simultaneously visible result sets.

## Change summary

Allow users to preserve one Find All References result while opening another in a separate view.

## Best solution

Extend the built-in References view to support pinned or independently selectable result sessions, preserving each result tree and its selection while additional searches run.
