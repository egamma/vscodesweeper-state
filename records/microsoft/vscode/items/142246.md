# Issue #142246 — Multi-line Highlight

[https://github.com/microsoft/vscode/issues/142246](https://github.com/microsoft/vscode/issues/142246)

## Summary

The multi-cursor line highlighting behavior was an intentional change in 1.64 (commit ad6d1757c39, fixing #25221). This is as-designed — the editor now highlights every line with a cursor, which was a long-requested feature. The reporter is asking for the old behavior back, but there is no setting to limit highlights to only the primary cursor.

## Change summary

Request to revert multi-cursor line highlighting so only the primary cursor's line is highlighted, not all cursor lines.

## Best solution

Keep the shipped behavior. The multi-cursor line highlight was an intentional feature (https://github.com/microsoft/vscode/issues/25221). Users who find it distracting can set `editor.renderLineHighlight` to `none` or `gutter` to reduce visual noise, or customize `editor.lineHighlightBackground` / `editor.lineHighlightBorder` via their theme to make the highlight subtler.
