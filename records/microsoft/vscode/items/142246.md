# Issue #142246 — Multi-line Highlight

[https://github.com/microsoft/vscode/issues/142246](https://github.com/microsoft/vscode/issues/142246)

## Summary

The multi-cursor line highlight is intentional — it was a deliberate feature added in 1.64 via commit ad6d1757c39 to resolve the long-standing request #25221. The current behavior is as-designed, and the existing `editor.renderLineHighlight` setting (set to `none`) can disable line highlighting entirely.

## Change summary

Request to revert the 1.64 change that highlights all cursor lines, returning to only highlighting the primary cursor line.

## Best solution

Close as as-designed. The multi-cursor line highlight was a deliberate, community-requested feature (#25221, now closed and verified). Users who find it too obtrusive can set `editor.renderLineHighlight` to `none` or adjust the `editorLineHighlight` theme color to reduce contrast. A separate option to highlight only the primary cursor would be a new feature request with no traction (0 upvotes over 3+ years).
