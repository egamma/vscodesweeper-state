# Issue #347480 — Agents Window: set an emoji for a chat

[https://github.com/microsoft/vscode/issues/347480](https://github.com/microsoft/vscode/issues/347480)

## Summary

Keep open: existing group-icon customization does not provide an emoji marker for an individual chat. This team-authored, On Deck request remains distinct from the related colored-groups proposal.

## Change summary

Allow users to assign an emoji, such as a test tube or star, to individual chats in the Agents Window.

## Best solution

Provide an optional per-chat visual marker that makes selected chats recognizable without obscuring their execution or attention state. Settle its relationship to existing status icons before implementation.
