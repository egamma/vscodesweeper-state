# Issue #345594 — False positive: "agent tool must be included in tools" warning when agent/runSubagent is listed instead of the toolset alias

[https://github.com/microsoft/vscode/issues/345594](https://github.com/microsoft/vscode/issues/345594)

## Summary

The false warning remains reproducible from current source: agent-file validation requires the literal toolset alias even when the subagent tool is explicitly enabled. Keep open for a bounded validator correction.

## Change summary

Agent files listing agent/runSubagent alongside a nonempty agents attribute incorrectly receive a missing-agent-tool warning.

## Best solution

Make the agents-attribute diagnostic agree with actual subagent-tool availability, accepting the individual tool as well as its toolset alias while retaining warnings when dispatch is unavailable.
