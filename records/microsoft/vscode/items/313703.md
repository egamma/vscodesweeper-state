# Issue #313703 — Opening a chat session can silently dirty editor buffers and cause data loss

[https://github.com/microsoft/vscode/issues/313703](https://github.com/microsoft/vscode/issues/313703)

## Summary

Confirmed data-loss bug still present on main, with an open fix PR (#313793) that has not yet merged. Team-authored issue — keeping open for maintainer judgment.

## Change summary

Restoring a chat editing session unconditionally overwrites the editor buffer with stale snapshot content, silently dirtying it and risking data loss if the file changed since the snapshot was taken.

## Best solution

Land https://github.com/microsoft/vscode/pull/313793 (or an equivalent fix) that guards `resetDocumentValues` against restoring stale content — comparing on-disk state (mtime/hash) before writing the snapshot back, and skipping or prompting when the file has diverged.
