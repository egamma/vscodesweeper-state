# Issue #313703 — Opening a chat session can silently dirty editor buffers and cause data loss

[https://github.com/microsoft/vscode/issues/313703](https://github.com/microsoft/vscode/issues/313703)

## Summary

The stale-snapshot overwrite remains present in current main, with independent Windows and macOS confirmations of the data-loss risk. Keep this open while the linked, still-open fixing PR is reviewed.

## Change summary

Opening a historical chat session can replace newer file contents with persisted agent edits, dirtying the buffer and allowing save or autosave to discard newer work.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/313793 so reopening a session preserves newer live content without silently replaying stale edits. Preserve legitimate pending-edit restoration and assess normalization, unsaved buffers, and missing-file behavior before landing the fix.
