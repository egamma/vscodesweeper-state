# Issue #282433 — Integrated terminal on macOS freezes permanently after running a program that segfaults — Crashpad fatal error kills PTY host

[https://github.com/microsoft/vscode/issues/282433](https://github.com/microsoft/vscode/issues/282433)

## Summary

The bug is confirmed by a second reporter (neko-para) who verified that --disable-crash-reporter resolves it. The root cause is Crashpad's Mach exception port being inherited by PTY host child processes on macOS, causing the PTY host to crash when a child segfaults. No fix has landed on main. The issue should stay open as it's a real, confirmed bug with a plausible root cause.

## Change summary

On macOS, Crashpad's inherited Mach exception port kills the PTY host process when a child program segfaults, permanently freezing the integrated terminal.

## Best solution

Prevent the PTY host's child processes from inheriting Crashpad's Mach exception port, or reset the exception port in the PTY host utility process before spawning child processes. The fix likely lives in `src/vs/platform/utilityProcess/electron-main/utilityProcess.ts` or requires an Electron-level change to how exception ports are inherited by utility processes.
