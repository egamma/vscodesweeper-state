# Issue #328277 — Changing the reasoning effort causes overwrite of provider entry in chatLanguageModels.json

[https://github.com/microsoft/vscode/issues/328277](https://github.com/microsoft/vscode/issues/328277)

## Summary

The destructive rewrite is reproducible from current source: updating one model group replaces every entry sharing its vendor and name. Keep this open in the BYOK model area.

## Change summary

Changing a BYOK model's reasoning effort duplicates that provider entry over another provider entry with the same vendor and name.

## Best solution

Prevent model-setting updates from replacing multiple configuration entries. Maintainers should decide whether duplicate vendor/name identities are supported and updated by exact parsed range, or rejected with a clear diagnostic while directing users to place both models in one provider group.
