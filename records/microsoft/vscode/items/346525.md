# Issue #346525 — Keyboard focus unexpectedly moves between the Extension Welcome page and VS Code Welcome page when navigating with the Tab key:A11y_VisualStudioCode_Welcome_Keyboard

[https://github.com/microsoft/vscode/issues/346525](https://github.com/microsoft/vscode/issues/346525)

## Summary

The current source leaves controls on the inactive Welcome slide keyboard-focusable. Keep this open: the reported navigation crosses between visually hidden and displayed content because slide switching disables only native buttons and inputs.

## Change summary

Prevent Tab navigation from reaching controls on the inactive Welcome or extension walkthrough slide.

## Best solution

Ensure only the displayed Getting Started slide participates in keyboard navigation, while preserving navigation among its controls and normal movement out of the editor.
