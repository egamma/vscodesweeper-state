## Summary

The current Welcome editor leaves inactive slide controls keyboard-focusable: slide switching disables buttons and inputs but misses the custom startup checkbox and other focusable elements. Keep this open; the defect is in the core walkthrough host, not established as extension-owned.

## Change summary

Prevent keyboard navigation from entering an inactive Welcome or extension walkthrough slide.

## Best solution

Ensure only the displayed Welcome slide participates in keyboard navigation, restoring its controls when returning without trapping focus inside the editor.
