# Issue #291113 — Integrated Browser: Can't tell which browser tabs share sessions

[https://github.com/microsoft/vscode/issues/291113](https://github.com/microsoft/vscode/issues/291113)

## Summary

Keep open: current browser tabs still lack an at-a-glance storage/session distinction. The storage setting and scope-specific Clear Storage actions provide information, but do not cover the requested visual identification; no qualifying canonical or fixing commit was established.

## Change summary

Make browser tabs using different storage sessions visually distinguishable, particularly ephemeral versus persistent tabs.

## Best solution

Expose each browser tab's actual storage/session scope through a consistent, accessible indicator in the integrated browser UI, without changing existing sessions when the default storage setting changes. The area owner should settle the presentation and whether it identifies storage scope alone or individual shared sessions.
