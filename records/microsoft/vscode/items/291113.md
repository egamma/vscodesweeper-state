# Issue #291113 — Integrated Browser: Can't tell which browser tabs share sessions

[https://github.com/microsoft/vscode/issues/291113](https://github.com/microsoft/vscode/issues/291113)

## Summary

Team-authored feature request for visual differentiation between global and ephemeral browser sessions. No implementation found on current main — the tab label/icon code shows no ephemeral-specific indicator. Keeping open.

## Change summary

Browser tabs with different session types (global vs ephemeral) look identical, making it impossible to tell them apart.

## Best solution

Add a visual indicator (e.g. an incognito-style icon overlay or a tab description suffix) to ephemeral browser tabs so users can distinguish session types at a glance. The likely touch points are the browser editor input's `getName`/`getDescription`/icon methods and the tab management features in `src/vs/workbench/contrib/browserView/electron-browser/`.
