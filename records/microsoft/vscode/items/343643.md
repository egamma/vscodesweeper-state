# Issue #343643 — getContentsAsText() splits soft-wrapped rows into separate lines, so captured terminal output gains newlines inside tokens

[https://github.com/microsoft/vscode/issues/343643](https://github.com/microsoft/vscode/issues/343643)

## Summary

The soft-wrap defect remains directly visible in current main: marker-based terminal capture inserts newlines between physical rows without checking continuation state. Classify this as a core terminal bug and route it to the terminal area.

## Change summary

Preserve logical lines when capturing terminal output so soft wrapping does not insert newlines inside tokens.

## Best solution

Make marker-based terminal capture preserve soft-wrapped logical lines while retaining genuine line breaks, meaningful whitespace, and existing marker boundaries. Cover the behavior in the existing XtermTerminal capture tests and preserve command-echo and prompt filtering.
