# Issue #299185 — Error when trying to save a plan

[https://github.com/microsoft/vscode/issues/299185](https://github.com/microsoft/vscode/issues/299185)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/287667 reports the same Plan mode “Open in Editor” flow producing an incorrectly located untitled file that fails to save with a permissions error.

## Change summary

Opening a generated plan in the editor creates a prompt file whose save target resolves to the read-only filesystem root.

## Best solution

Consolidate the reports on https://github.com/microsoft/vscode/issues/287667 and fix the plan export flow there so it creates a genuinely untitled document with a valid Save As destination rather than resolving the filename against the filesystem root.
