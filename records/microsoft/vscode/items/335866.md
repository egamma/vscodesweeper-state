# Issue #335866 — [typescript] Coloring is broken for type assertion functions with multi-line generic return types

[https://github.com/microsoft/vscode/issues/335866](https://github.com/microsoft/vscode/issues/335866)

## Summary

Fresh, well-documented TextMate grammar bug: a type-predicate return type (`r is Required<A>`) that wraps across lines breaks TypeScript syntax coloring for the rest of the file. Reporter confirmed it in three separate environments (local VS Code, vscode.dev, StackBlitz), so this is a real, reproducible defect that should be routed to the TypeScript grammar owners.

## Change summary

Syntax highlighting breaks for all code after a method whose type-predicate return type (`r is Required<A>`) is split across multiple lines, when the asserted type is generic.

## Best solution

Needs a grammar-level fix in the bundled TypeScript.tmLanguage.json (generated from the upstream TypeScript-TmLanguage grammar via extensions/typescript-basics/build/update-grammars.mjs) — the type-predicate ('x is ...') pattern doesn't correctly close its match when the asserted type is a multi-line generic, causing the tokenizer state to leak into subsequent code.
