# Issue #271603 — Allow hiding of welcome prompts

[https://github.com/microsoft/vscode/issues/271603](https://github.com/microsoft/vscode/issues/271603)

## Summary

Valid, unimplemented feature request from a team member: the welcome-prompt cards in the chat widget (`ChatSuggestNextWidget`) currently have no context-menu entry to hide individual prompts. The request is assigned to the author and still needed.

## Change summary

Add a 'Hide Prompt' option to the context menu on chat welcome prompt cards so users can dismiss prompts they don't want to see.

## Best solution

Add a context-menu action (and backing storage/service method) to `ChatSuggestNextWidget` in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatSuggestNextWidget.ts` that lets users hide individual welcome prompts, persisting the choice so hidden prompts don't reappear. The existing `IContextMenuService` is already injected; the prompt buttons need a `contextmenu` listener with a 'Hide Prompt' action that stores the dismissed prompt identifier.
