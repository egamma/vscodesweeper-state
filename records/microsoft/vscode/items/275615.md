# Issue #275615 — SCM Graph - improve discoverability of commit expansion feature

[https://github.com/microsoft/vscode/issues/275615](https://github.com/microsoft/vscode/issues/275615)

## Summary

Keep open under discussion: current source still hides commit-row twisties and provides no expansion hint for double-click users. Existing commit expansion satisfies file browsing, but not its discoverability; no qualifying canonical duplicate was found.

## Change summary

Make SCM Graph commit expansion discoverable when workbench.tree.expandMode is set to doubleClick.

## Best solution

Provide a restrained, accessible indication that SCM Graph commits can expand to show changed files, while preserving the configured expansion gesture and graph readability. The SCM owner should settle whether that indication is a contextual hint or a visible expansion affordance.
