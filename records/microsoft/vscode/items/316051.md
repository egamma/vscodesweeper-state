## Change summary

Prevent an unrelated active editor from silently redirecting a follow-up in another Copilot Chat session to the wrong file.

## Best solution

Make ambient editor context predictable and controllable without overriding the ongoing session's task. Settle the reporter's proposed visibility-versus-suppression behavior, then validate the two-session scenario; investigate the later wrong-session submission report separately unless evidence establishes the same cause.
