# Issue #337975 — compareIgnoreCase sorts ASCII punctuation [\]^_` after letters, contradicting its own ordering contract

[https://github.com/microsoft/vscode/issues/337975](https://github.com/microsoft/vscode/issues/337975)

## Summary

Confirmed real bug via source inspection: compareSubstringIgnoreCase maps lowercase ASCII letters up to uppercase, putting punctuation 91-96 ([\]^_`) after letters, contradicting the test oracle's own lowercase-based contract. An open PR already proposes the fix, so this stays open pending that PR merging rather than being marked agent-ready.

## Change summary

compareIgnoreCase (and compareSubstringIgnoreCase) sorts ASCII punctuation [\]^_` after letters instead of before, inverting the intended lowercase-based ordering contract for letter/punctuation pairs in that range.

## Best solution

Merge the linked fix (map uppercase down to lowercase, code += 32, matching the test oracle) once reviewed — PR https://github.com/microsoft/vscode/pull/338056 already implements this with tests.
