# Issue #325485 — Set active hours in copilot chat

[https://github.com/microsoft/vscode/issues/325485](https://github.com/microsoft/vscode/issues/325485)

## Summary

This requests a digital-wellbeing / screen-time-limit feature for Copilot Chat usage, which is a personal productivity concern outside the scope of a code editor's core responsibilities. No similar feature or precedent exists in VS Code.

## Change summary

Allow users to configure active hours for Copilot Chat, with warnings or API-call blocking outside those hours.

## Best solution

This is a personal productivity / digital wellbeing concern best addressed by OS-level tools (Focus Assist on Windows, Focus on macOS, third-party app timers) or a dedicated extension that wraps the chat API with time-based guards. VS Code core should not gatekeep its own features on a schedule — that crosses from editor into parental-control territory.
