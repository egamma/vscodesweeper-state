# Issue #208985 — Declarative treesitter-based indentation rules

[https://github.com/microsoft/vscode/issues/208985](https://github.com/microsoft/vscode/issues/208985)

## Summary

Keep open: current indentation configuration still exposes regular-expression rules, not declarative tree-sitter indentation queries. Maintainers acknowledged the gap and left API and latency questions unresolved; existing tree-sitter highlighting support does not fulfill this request.

## Change summary

Allow language extensions to declare syntax-tree-aware indentation rules that work across Enter, paste, and line movement without extension-host correction passes.

## Best solution

Define a core indentation-query contribution contract with explicit parsing-latency and fallback behavior, preserving existing language configurations. Review the related open regex-indentation PR on its own merits; it does not supply the requested tree-aware capability.
