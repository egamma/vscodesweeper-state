# Issue #262227 — The json editor stops completing values after the character `+` is used

[https://github.com/microsoft/vscode/issues/262227](https://github.com/microsoft/vscode/issues/262227)

## Summary

Keep open: the current suggestion model still skips refiltering when typing a numeric word after '+', matching the confirmed diagnosis in the discussion. This is a core completion defect, not a problem owned by the extension supplying the setting.

## Change summary

JSON value completions stop tracking typed characters after '+' and can accept c++03 when the user has typed c++2.

## Best solution

Ensure an active completion session continues filtering and updating its edit extent across the reported word boundary, so c++2 matches c++20 without canceling and reopening suggestions. Preserve the existing suppression of automatic suggestions for standalone numeric words.
