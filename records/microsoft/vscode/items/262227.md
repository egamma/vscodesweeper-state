# Issue #262227 — The json editor stops completing values after the character `+` is used

[https://github.com/microsoft/vscode/issues/262227](https://github.com/microsoft/vscode/issues/262227)

## Summary

Still reproduces on main: the suggest model detects a new word at `+` (a word separator) and retriggers, but the retrigger does not refilter with the correct replace/insert range covering the full value including `+`. jrieken confirmed the root cause in comments; no fix has landed.

## Change summary

JSON settings completion breaks when typing past a `+` character in a value because the suggest model treats `+` as a word boundary and retriggers with an incorrect replace range.

## Best solution

Fix the retrigger path in `suggestModel.ts` (around line 752) so that when a new word is detected mid-completion, the replacement range is recalculated to cover the full completion item range rather than only the new word fragment. The JSON completion provider's supplied ranges should be respected over the editor's word-boundary detection.
