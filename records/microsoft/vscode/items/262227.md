- **Current source confirms the failing path:** src/vs/editor/contrib/suggest/browser/suggestModel.ts:67-85 makes LineContext.shouldAutoTrigger return false for numeric words. In _onNewContext, lines 754-769 detect a new word, retrigger only when shouldAutoTrigger is true, and then return unconditionally. A numeric suffix such as 2 consequently bypasses the completionModel.lineContext update and onDidSuggest notification below that branch, preserving the stale list.
