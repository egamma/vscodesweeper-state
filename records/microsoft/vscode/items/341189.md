# Issue #341189 — disable custom terminal tool of sandboxing enabled

[https://github.com/microsoft/vscode/issues/341189](https://github.com/microsoft/vscode/issues/341189)

## Summary

Team-authored, milestoned (1.143.0) enterprise-control request that is still unimplemented on main; keep open.

## Change summary

Force-disable the Agent Host custom terminal tool setting when enterprise managed settings enable sandboxing.

## Best solution

When managed settings indicate sandboxing is enabled, treat chat.agentHost.customTerminalTool.enabled as false at its consumers. Reuse the existing managed-settings sandbox detection.
