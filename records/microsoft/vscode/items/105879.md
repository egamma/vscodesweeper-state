# Issue #105879 — Webview View onDidChangeVisibility fired when moving the view

[https://github.com/microsoft/vscode/issues/105879](https://github.com/microsoft/vscode/issues/105879)

## Summary

Fixed on main since September 2020 — the guard in commit 50e35931712 suppresses the spurious onDidChangeVisibility event when the view is already disposed, which is exactly the reported issue.

## Change summary

WebviewView.onDidChangeVisibility fires a spurious visibility-change event on a view that is about to be disposed when dragging between containers.

## Best solution

Keep the shipped fix (commit 50e35931712, released in 1.50.0); no further change is needed.
