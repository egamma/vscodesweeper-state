# Issue #203806 — Editor Highlight text only shows 999 instances

[https://github.com/microsoft/vscode/issues/203806](https://github.com/microsoft/vscode/issues/203806)

## Summary

The selection highlighter still inherits the model's 999-match limit. Keep this open for the performance-conscious improvement discussed by the collaborator; existing settings do not address the match-count cap.

## Change summary

Improve selection-match highlighting in documents containing more than 999 occurrences of the selected text.

## Best solution

Establish a selection-highlighting policy that makes matches useful beyond the first 999 occurrences without introducing blocking searches or excessive decorations. Keep the change specific to selection highlighting rather than changing the shared model search default.
