# Issue #4994 — [rtl] Add Right-to-Left editing

[https://github.com/microsoft/vscode/issues/4994](https://github.com/microsoft/vscode/issues/4994)

## Summary

Keep open: current main has decoration-based RTL rendering but does not expose the requested editing-direction control. Three open PRs reference this issue, so the next step is maintainer review of those implementations, not closure or a competing agent session.

## Change summary

Allow users to switch editing direction for documents containing Persian/Farsi and mixed RTL/LTR text.

## Best solution

Deliver a supported editor-direction control that makes mixed-language Markdown comfortable to edit while preserving existing code-editing defaults. Review and reconcile the linked PRs' differing direction, detection, and persistence contracts before landing an implementation.
