# Issue #331027 — Agent Host stops detached shells when idle sessions are released

[https://github.com/microsoft/vscode/issues/331027](https://github.com/microsoft/vscode/issues/331027)

## Summary

Team-authored bug (roblourens). ## Change summary

Agent Host releases (destroys) an idle Copilot SDK session even while a detached shell it started is still running, killing the detached work before it can finish or notify.

## Best solution

A maintainer should close this manually, citing commit 962cde6575e27bdcf58c8aa2d411ae5170c31e88 (PR https://github.com/microsoft/vscode/pull/330132), which adds `hasRunningDetachedShells()` and wires it into `_canReleaseChat` in src/vs/platform/agentHost/node/copilot/copilotAgent.ts to defer idle release exactly as this issue proposed.
