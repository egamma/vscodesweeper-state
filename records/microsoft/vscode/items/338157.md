# Issue #338157 — Add a built‑in API for adding files to bookmarks and visually highlighting them

[https://github.com/microsoft/vscode/issues/338157](https://github.com/microsoft/vscode/issues/338157)

## Summary

The requested capability — visually highlighting/badging files in the Explorer for a bookmark-like feature — is already exposed via the stable `FileDecorationProvider` extension API, and several Bookmarks-style extensions on the Marketplace already build exactly this. This is squarely extension territory, not a core feature.

## Change summary

Add a built-in bookmarks feature that visually highlights bookmarked files in the file Explorer (icon/special display).

## Best solution

Point the reporter at `vscode.window.registerFileDecorationProvider` (stable API in vscode.d.ts) and existing Bookmarks/file-highlighting extensions on the Marketplace — the capability doesn't need to live in core.
