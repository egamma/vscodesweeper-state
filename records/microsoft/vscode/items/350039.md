# Issue #350039 — More obvious visual queue of which chat is active and which one isn't?

[https://github.com/microsoft/vscode/issues/350039](https://github.com/microsoft/vscode/issues/350039)

## Summary

Keep open as chat-area usability feedback: existing focus and theme treatments do not establish that the active conversation is sufficiently distinguishable beyond its input border. The appropriate additional cue needs a design decision.

## Change summary

Make the active chat easier to distinguish from inactive chats using an indicator beyond the input border color.

## Best solution

Evaluate active-chat hierarchy in the editor window's chat area and choose a consistent, theme-aware panel or header cue that distinguishes conversation activation from keyboard focus without adding distracting chrome.
