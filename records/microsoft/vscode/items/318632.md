# Issue #318632 — Agents Window - Import Session

[https://github.com/microsoft/vscode/issues/318632](https://github.com/microsoft/vscode/issues/318632)

## Summary

Valid feature request from a team member. Partial infrastructure exists (LocalChatSessionsProvider, OpenChatSessionInAgentsWindowAction), but importing arbitrary existing sessions — especially ones not created as agent-host or CopilotCLI sessions — into the agents window is not yet supported. Stays open as unfinished work.

## Change summary

Allow importing existing chat sessions (particularly local sessions created in the main workbench) into the agents window.

## Best solution

Extend the session migration or import path so that sessions not originally created through the agents window (e.g. standard workbench chat sessions) can be adopted by the LocalChatSessionsProvider or a dedicated import flow. The gating in OpenChatSessionInAgentsWindowAction (currently restricted to CopilotCLI and AgentHostCopilot session types) may need broadening, and the agents window's session view needs a way to discover and list pre-existing sessions from the workbench chat history.
