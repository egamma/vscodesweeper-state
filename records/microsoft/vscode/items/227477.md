# Issue #227477 — textsearchprovider - clarify that `includes` are relative to `folder`

[https://github.com/microsoft/vscode/issues/227477](https://github.com/microsoft/vscode/issues/227477)

## Summary

The documentation gap remains in the renamed textSearchProvider2 proposal: includes are still not documented as relative to folder. Keep this focused clarification open; the broader stabilization issue does not replace it.

## Change summary

Clarify why text search provider includes are folder-relative strings while excludes can specify their own base URI.

## Best solution

Document the established folder-relative meaning of includes in TextSearchProviderOptions.folderOptions, contrasting it with excludes accepting RelativePattern values with their own baseUri. Preserve the existing API shape and search behavior.
