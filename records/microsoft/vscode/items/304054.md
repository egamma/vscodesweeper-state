# Issue #304054 — Forking a chat should include an affordance

[https://github.com/microsoft/vscode/issues/304054](https://github.com/microsoft/vscode/issues/304054)

## Summary

The requested affordance (a link back to the original chat in a forked conversation) is not implemented on current main. The fork action sets a 'Forked: {title}' prefix but does not store or display a navigable reference to the source session.

## Change summary

When forking a chat, include a visible link back to the original conversation in the forked chat.

## Best solution

Track the source session resource in the forked session's data model and render a clickable 'Forked from …' banner below the last copied message, linking back to the original chat. The work lives in `src/vs/workbench/contrib/chat/browser/actions/chatForkActions.ts` (fork creation) and a new or existing chat widget rendering contribution.
