# Issue #298061 — Go to Line/Column - no line number in edit box

[https://github.com/microsoft/vscode/issues/298061](https://github.com/microsoft/vscode/issues/298061)

## Summary

Keep open: current source still opens Go to Line/Column without exposing the current cursor coordinates in its input or initial prompt. The reporter confirmed persistence in Insiders, and another user independently reported the same missing information without a screen reader.

## Change summary

Restore access to the current line and column when opening Go to Line/Column.

## Best solution

Make the current cursor coordinates discoverable visually and with a screen reader when Go to Line/Column opens, while preserving direct entry of navigation targets. Settle whether those coordinates belong in selected editable text or contextual information before implementing.
