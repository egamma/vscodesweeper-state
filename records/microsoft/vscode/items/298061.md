# Issue #298061 — Go to Line/Column - no line number in edit box

[https://github.com/microsoft/vscode/issues/298061](https://github.com/microsoft/vscode/issues/298061)

## Summary

The missing current position remains explainable on main: Ctrl+G initializes the input with only ':' and presents a generic prompt. Keep this accepted bug open; a maintainer should reconcile the requested Ctrl+G behavior with the separate cursor-position command endorsed in a later related discussion.

## Change summary

Opening Go to Line/Column no longer exposes the current cursor line and column for inspection.

## Best solution

Settle whether Go to Line/Column should again expose the current position, including visible and screen-reader access, rather than treating the separate announcement command as complete coverage. Preserve existing destination entry and navigation behavior.

- **Behavior:**

  > Users opening Go to Line/Column cannot inspect their current cursor position there; the input contains only the command prefix and the prompt asks for a destination. This affects both NVDA users and users relying on Ctrl+G to check their line. The maintainer must settle whether current-position inspection remains part of this dialog's contract. Acceptance should verify the chosen presentation with and without a screen reader while preserving destination entry, Enter navigation, and Escape cancellation.
