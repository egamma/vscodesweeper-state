# Issue #310586 — Copilot Chat sessions in a window with no folder/workspace open do not show local sessions from folder workspaces, despite docs saying the list shows all sessions across workspaces

[https://github.com/microsoft/vscode/issues/310586](https://github.com/microsoft/vscode/issues/310586)

## Summary

The report identifies a real gap between the documented behavior ('shows all sessions across your workspaces' in empty windows) and the implementation, which stores sessions per-workspace without cross-workspace aggregation. The migration logic only copies sessions forward during workspace transitions within the same window, but does not aggregate sessions from all workspace storages when displaying the list in an empty window.

## Change summary

Local Copilot Chat sessions are partitioned by workspace context; the empty-window session list does not aggregate sessions from all workspace storages as the documentation claims.

## Best solution

Either update `ChatSessionStore` (in `src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts`) to enumerate and aggregate sessions from all workspace storage folders when in an empty window, or update the Copilot Chat documentation at https://code.visualstudio.com/docs/copilot/chat/chat-sessions to accurately describe the workspace-scoped behavior. The migration logic (`handleWorkspaceTransition`) already handles forward transitions but doesn't cover the reverse or cross-workspace discovery.
