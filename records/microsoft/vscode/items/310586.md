# Issue #310586 — Copilot Chat sessions in a window with no folder/workspace open do not show local sessions from folder workspaces, despite docs saying the list shows all sessions across workspaces

[https://github.com/microsoft/vscode/issues/310586](https://github.com/microsoft/vscode/issues/310586)

## Summary

Keep open: current source still excludes other workspaces' persisted local chats from an empty window's Sessions list, contradicting the documented aggregation behavior. A maintainer has also consolidated a newer, independently reproduced workspace-transition report into this issue.

## Change summary

Make persisted local chats discoverable from an empty window as documented, rather than exposing only the empty-window storage bucket.

## Best solution

Make empty-window session discovery and reopening honor the documented cross-workspace behavior, including the reported Remote SSH workflow. Assess the workspace-transition symptom separately because current source contains migration logic that does not provide general cross-workspace aggregation.
