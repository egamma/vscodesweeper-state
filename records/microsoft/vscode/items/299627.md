# Issue #299627 — Copilot CLI: Misleading worktree icon and hover text, no visual distinction between worktree/workspace sessions

[https://github.com/microsoft/vscode/issues/299627](https://github.com/microsoft/vscode/issues/299627)

## Summary

Keep open: current source still describes Copilot CLI as always operating in an isolated worktree, although workspace sessions remain supported. The provider icon has changed, but the misleading hover and lack of reliable at-a-glance isolation information are not fully resolved.

## Change summary

Make Copilot CLI descriptions and recent-session presentation accurately distinguish worktree isolation from workspace execution.

## Best solution

Make the provider description truthful for both execution modes and provide an understandable, persistent isolation cue in recent sessions without conflating provider identity or session status with isolation. Coordinate the presentation with the broader Git/worktree UX discussion while retaining this concrete report.
