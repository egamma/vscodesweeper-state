# Issue #299627 — Copilot CLI: Misleading worktree icon and hover text, no visual distinction between worktree/workspace sessions

[https://github.com/microsoft/vscode/issues/299627](https://github.com/microsoft/vscode/issues/299627)

## Summary

Partially addressed on main — the icon was changed from a forking icon to Codicon.copilot (commit 35a23cd116e, April 2026), but the hover description at line 182 of agentSessions.ts still unconditionally mentions 'Git worktree' for all Copilot CLI sessions regardless of isolation mode, and there remains no visual distinction between worktree and workspace sessions in the sessions list.

## Change summary

Copilot CLI hover text always mentions worktree even for workspace sessions, and the sessions list provides no visual differentiation between the two isolation modes.

## Best solution

Update `getAgentSessionProviderDescription` for `AgentSessionProviders.Background` (in `src/vs/workbench/contrib/chat/browser/agentSessions/agentSessions.ts`) to be generic or context-aware, removing the unconditional 'Git worktree' reference. Add a distinguishing indicator (icon badge or label suffix) in the agent sessions viewer for worktree vs folder isolation.
