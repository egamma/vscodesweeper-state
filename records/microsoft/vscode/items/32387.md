# Issue #32387 — Can't drag selected text with Ctrl to second file

[https://github.com/microsoft/vscode/issues/32387](https://github.com/microsoft/vscode/issues/32387)

## Summary

Keep this open as the oldest canonical request for cross-editor text drag-and-drop. Current main still limits the operation to one editor model, while newer reports describe the same remaining gap.

## Change summary

Allow selected text to be moved or copied by dragging it between files in split editors.

## Best solution

Implement a cross-editor drag session that transfers the selected text and applies coordinated source and target model edits, preserving Ctrl-to-copy behavior. Consolidate the overlapping request at https://github.com/microsoft/vscode/issues/149184 into this canonical issue while treating its external-application support as an additional scope decision.
