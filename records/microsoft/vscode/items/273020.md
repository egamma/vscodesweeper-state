## Change summary

The compact application menu shows stale checked and enabled states on its first opening after an action state changes.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/329775 so overflow actions are composed from current menu state when the menu opens, with the included regression test preserving first-open correctness.
