# Issue #274673 — Copilot Chat does not load/takes very long to load models on remote

[https://github.com/microsoft/vscode/issues/274673](https://github.com/microsoft/vscode/issues/274673)

## Summary

Still relevant: the Copilot extension activation path awaits the experimentation service's `initialFetch` with no timeout, which can block model loading for 10+ minutes on remote connections with slow or unreliable network paths. The code path is unchanged on current main.

## Change summary

Copilot Chat takes 10–15 minutes to load models on remote servers because the experimentation service fetch blocks activation without a timeout.

## Best solution

Add a timeout (e.g. 5–10 seconds) to the `await expService.hasTreatments()` call in `extensions/copilot/src/extension/extension/vscode/extension.ts` so activation proceeds with cached/default treatments when the fetch is slow, rather than blocking indefinitely. The experimentation service can continue refreshing in the background.
