# Issue #203627 — Merge Editor creates empty file instead of deleting file when accepting Incoming delete (Only Incoming, no Current)

[https://github.com/microsoft/vscode/issues/203627](https://github.com/microsoft/vscode/issues/203627)

## Summary

Keep open: Complete Merge still saves and stages file contents without representing an accepted file deletion. The existing SCM deletion-resolution dialog provides a workaround, but does not correct the reported merge-editor behavior.

## Change summary

Accepting Incoming deletion while rejecting Current modification should stage a deleted file rather than an empty modified file.

## Best solution

Preserve file-deletion intent through the Git-to-merge-editor workflow so completing an explicitly accepted deletion removes and stages the file. Distinguish deletion from a legitimate empty file or manually emptied merge result.
