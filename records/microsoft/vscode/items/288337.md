# Issue #288337 — Ctrl/cmd+v should paste image data into copilot CLI

[https://github.com/microsoft/vscode/issues/288337](https://github.com/microsoft/vscode/issues/288337)

## Summary

Open feature request from a VS Code team member (Tyriar / Daniel Imms, the terminal maintainer) to support pasting image data via Ctrl/Cmd+V into the Copilot CLI running in the integrated terminal. No evidence of implementation on main — the terminal contribution has no image-paste handling, and the referenced external issue (github/copilot-cli#363) tracks the CLI-side counterpart. Keeping open as a valid, unimplemented feature request filed by a maintainer.

## Change summary

Support pasting clipboard image data into the Copilot CLI when it runs inside VS Code's integrated terminal.

## Best solution

Coordinate between the terminal input layer (intercepting image clipboard data on paste) and the Copilot CLI protocol (github/copilot-cli#363) to forward image payloads. The terminal side likely needs work in `src/vs/workbench/contrib/terminal/browser/` to detect image clipboard content and expose it, while the CLI side needs to accept it. This is a cross-team feature that the terminal and Copilot CLI teams should design together.
