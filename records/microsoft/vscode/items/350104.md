# Issue #350104 — [GB Cert][Visual Studio Code] File path links are only partially underlined in a narrow terminal

[https://github.com/microsoft/vscode/issues/350104](https://github.com/microsoft/vscode/issues/350104)

## Summary

Keep open: current source contains a wrapped wide-character range-conversion defect that can truncate terminal link underlining. The report supplies concrete Windows reproduction steps; no verified duplicate or fixing commit was found.

## Change summary

Underline the complete detected file path when GB18030 characters wrap across a narrow terminal.

## Best solution

Make terminal link buffer ranges cover the complete detected text across wide-character wrapping, preserving existing ASCII and supplementary-character behavior.

## Evidence

- **Concrete report:** https://github.com/microsoft/vscode/issues/350104 supplies folder and filename samples, a PowerShell command, resizing steps, and wide-versus-narrow screenshots for VS Code 1.147.0 on Windows. The extension-disabled answer is No, but no particular extension is identified.
- **Current source defect:** src/vs/workbench/contrib/terminalContrib/links/browser/terminalLinkHelpers.ts: convertLinkRangeToBuffer fixes endWrappedLineCount at Math.ceil(range.endColumn / bufferWidth), before accounting for wide-character cell expansion. Additional physical rows caused by that expansion are not necessarily scanned, so their width offsets are omitted.
- **Hand-traced counterexample:** For six width-two BMP characters across three four-column buffer rows, with startColumn=1 and endColumn=7, the helper scans only two rows and accumulates four extra cells. It returns end={x:2,y:3}, although the complete text ends at {x:4,y:3}. This is source reasoning, not an executed test.
- **Reported code path:** src/vs/workbench/contrib/terminalContrib/links/browser/terminalLocalLinkDetector.ts: detect obtains wrapped text using getXtermLineContent and passes detected string indices into convertLinkRangeToBuffer for both normal and fallback file-link detection.
- **Existing validation surface:** src/vs/workbench/contrib/terminalContrib/links/test/browser/terminalLinkHelpers.test.ts contains the convertLinkRangeToBuffer suite and buffer-cell fixtures covering ASCII, wide characters, emoji, and wrapped links. It provides a bounded regression-test location for expansion spanning additional physical rows.
