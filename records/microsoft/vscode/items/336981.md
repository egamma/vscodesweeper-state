# Issue #336981 — Agents window: Restore workspace button is not working

[https://github.com/microsoft/vscode/issues/336981](https://github.com/microsoft/vscode/issues/336981)

## Summary

Keep open: workspace restoration is an intended part of checkpoint undo, and neither a matching fix nor a canonical duplicate was verified. Current main has explicit file-restoration implementations rather than a history-only operation; the reported edit → restore → redo sequence suffices to retest the Windows/WSL failure, but source inspection alone did not confirm it.

## Change summary

Agents-window checkpoint restore and redo change conversation history without restoring the corresponding file contents.

## Best solution

Make checkpoint restore and redo consistently restore the corresponding workspace contents in the affected session provider, including WSL-backed files. First reproduce the reported sequence and distinguish missing edit snapshots from failed remote file operations; do not treat conversation truncation alone as successful restoration.
