# Issue #330645 — VS Code Interface Problem with Borders & Modern UI 😢

[https://github.com/microsoft/vscode/issues/330645](https://github.com/microsoft/vscode/issues/330645)

## Summary

Design feedback on the new experimental 'Modern UI' (borders/spacing/tabs) rolled out via A/B test in 1.133; the feature and its opt-out setting are real and confirmed on main, and this is community feedback during an active experiment rather than a bug, so it stays open for the team to weigh.

## Change summary

Reporter and many commenters dislike the visual changes (extra borders, spacing, tab styling) introduced by the new experimental Modern UI and want a way to disable it or have it reverted.

## Best solution

This belongs with the other Modern UI feedback threads under active design review (src/vs/workbench/contrib/modernUI/); the team already ships `workbench.experimental.modernUI: false` as an opt-out, confirmed in the code and repeated in comments — keep this open as design feedback, and a maintainer should decide whether to consolidate the cluster of near-duplicate Modern UI complaint issues onto one canonical thread.
