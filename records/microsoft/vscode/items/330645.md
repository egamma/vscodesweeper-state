# Issue #330645 — VS Code Interface Problem with Borders & Modern UI 😢

[https://github.com/microsoft/vscode/issues/330645](https://github.com/microsoft/vscode/issues/330645)

## Summary

The original request for a way to disable the additional Modern UI borders is already covered by an existing setting, which the reporter confirmed solved their problem. This does not establish that the later tab-border and theme-customization reports are resolved.

## Change summary

Provide a way to use current VS Code versions without the additional Modern UI borders and spacing.

## Best solution

Use workbench.experimental.modernUI=false for the currently supported Classic UI opt-out, without promising that it will remain indefinitely. Continue addressing specific tab-border and theme-customization defects independently of this answered opt-out request.

  > Thanks for the report. Setting `"workbench.experimental.modernUI": false` disables the Modern UI card borders and spacing, and you confirmed earlier that this solved your original request. This opt-out is temporary, as explained in https://github.com/microsoft/vscode/issues/334285; `"window.density.layout": "compact"` is also available for a denser Modern UI layout.
