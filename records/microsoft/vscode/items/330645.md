Verified duplicate: this is the same feedback thread as the older, actively-discussed canonical issue about the Modern UI experiment's new borders/gaps introduced in 1.133 — consolidating there keeps the design feedback in one place.

## Change summary

After updating to VS Code 1.133, the experimental Modern UI adds visible square borders/gaps around editor, sidebar, terminal, and other panels, and the reporter asks for a way to disable them (or a revert).

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/330258 ("The Modern UI went too far", open, labeled `ux`/`modernization`, created two days earlier with ongoing discussion of the exact same borders/gaps complaint) — that's where the UX team is already collecting this feedback; the `workbench.experimental.modernUI: false` setting (registered in src/vs/workbench/browser/workbench.contribution.ts) is the current workaround pending a design decision.
