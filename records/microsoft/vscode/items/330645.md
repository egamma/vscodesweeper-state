# Issue #330645 — VS Code Interface Problem with Borders & Modern UI 😢

[https://github.com/microsoft/vscode/issues/330645](https://github.com/microsoft/vscode/issues/330645)

## Summary

Design feedback on the intentional, actively-developed experimental 'Modern UI' (workbench.experimental.modernUI), which already ships with an off-switch — not a bug, but a live design discussion the maintainers should weigh given the volume of similar complaints.

## Change summary

Reporter and many commenters dislike the extra borders, padding, and rounded corners introduced by the new experimental Modern UI in 1.133, and want a way to turn it off or have it reverted.

## Best solution

This belongs with the design/workbench team's ongoing Modern UI experiment; the existing `workbench.experimental.modernUI: false` setting already covers the immediate ask, and the broader visual-design pushback (borders, spacing, tab styling, titleBar color scoping) should be triaged together with the many sibling feedback threads (e.g. https://github.com/microsoft/vscode/issues/331403, https://github.com/microsoft/vscode/issues/330258, https://github.com/microsoft/vscode/issues/329024) rather than resolved issue-by-issue.
