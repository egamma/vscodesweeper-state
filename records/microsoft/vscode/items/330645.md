# Issue #330645 — VS Code Interface Problem with Borders & Modern UI 😢

[https://github.com/microsoft/vscode/issues/330645](https://github.com/microsoft/vscode/issues/330645)

## Summary

The requested way to disable the additional Modern UI borders already exists: set workbench.experimental.modernUI to false. The reporter explicitly confirmed that this restored the desired interface, and current main still supports the setting.

## Change summary

Provide an option to use updated VS Code versions without the Modern UI's additional borders and floating-panel spacing.

## Best solution

Use the existing workbench.experimental.modernUI setting for the requested Classic UI appearance during the transition period. Keep long-term design feedback and the later tab-border customization reports distinct from this resolved request; the published transition discussion is at https://github.com/microsoft/vscode/issues/334285.
