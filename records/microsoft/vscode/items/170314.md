# Issue #170314 — Hidden Menu Bar Appears After Fast Scrolling

[https://github.com/microsoft/vscode/issues/170314](https://github.com/microsoft/vscode/issues/170314)

## Summary

Keep open in the existing Electron/menu area: the discussion confirms the Alt-scroll conflict and identifies native menu focus as Electron-owned. No concrete fix or verified duplicate was established.

## Change summary

Prevent releasing Alt after accelerated scrolling from revealing the native menu bar and resizing the editor on Linux.

## Best solution

Electron's native menu handling should distinguish a standalone Alt press from Alt used during scrolling, preserving intentional keyboard access without revealing the menu after fast scroll. Retain this issue to track that upstream behavior and its adoption in VS Code.
