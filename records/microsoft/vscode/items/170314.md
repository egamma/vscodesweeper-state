# Issue #170314 — Hidden Menu Bar Appears After Fast Scrolling

[https://github.com/microsoft/vscode/issues/170314](https://github.com/microsoft/vscode/issues/170314)

## Summary

Confirmed upstream issue in Electron's native menu bar focus handling on Linux — Alt key release after fast scroll triggers menu bar visibility. Already correctly labeled and triaged; no fix has landed in VS Code or been back-ported from Electron.

## Change summary

On Linux with native title bar, releasing Alt after fast-scrolling causes the hidden menu bar to appear.

## Best solution

The fix belongs in Electron's menu_bar.cc Alt-key focus callback (cited by deepak1556). VS Code could work around it by intercepting Alt keyup when preceded by a scroll event, but the proper fix is upstream. Keep open to track until Electron addresses it.
