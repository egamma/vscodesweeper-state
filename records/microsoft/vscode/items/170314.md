# Issue #170314 — Hidden Menu Bar Appears After Fast Scrolling

[https://github.com/microsoft/vscode/issues/170314](https://github.com/microsoft/vscode/issues/170314)

## Summary

Keep open as an Electron-owned menu interaction issue: the discussion independently confirms the symptom, and current source still combines Alt-based fast scrolling with Electron-controlled native menu activation. No verified fix or eligible older canonical was established.

## Change summary

Releasing Alt after fast scrolling should not reveal the hidden native menu bar or resize the editor on Linux.

## Best solution

Resolve the interaction between scrolling and Electron/Chromium's native menu focus handling while preserving intentional Alt-only menu access. Retain this issue to track the native Linux case; permanently disabling the menu or changing title-bar style does not satisfy the requested behavior.
