# Issue #337679 — Portable VS Code shares taskbar identity with installed VS Code (pinning, jump list, recent items)

[https://github.com/microsoft/vscode/issues/337679](https://github.com/microsoft/vscode/issues/337679)

## Summary

Confirmed on main: `app.setAppUserModelId(product.win32AppUserModelId)` in app.ts is called unconditionally regardless of portable mode, so a portable install shares taskbar identity with an installed copy. An open PR already targets the fix, and the issue carries a real milestone (1.140.0) — both bar a close for now.

## Change summary

On Windows, a portable VS Code copy shares the installed copy's AppUserModelID, so taskbar pinning, jump lists, and 'Recent' entries resolve to the wrong executable.

## Best solution

Land and verify https://github.com/microsoft/vscode/pull/337682, which gives portable mode a distinct AppUserModelID so Windows treats it as a separate taskbar app.
