# Issue #209500 — Image attachments in markdown are not uniquely named

[https://github.com/microsoft/vscode/issues/209500](https://github.com/microsoft/vscode/issues/209500)

## Summary

Both requests (UUID-style unique attachment names and empty alt text) remain unimplemented on current main. The feature request is valid and properly categorized in the Backlog; keeping open for community traction.

## Change summary

Request unique filenames (UUID-style) for pasted images in notebook markdown cells, and leave alt text empty instead of using the filename.

## Best solution

In `extensions/ipynb/src/notebookImagePaste.ts`, the `buildAttachment` function should generate a UUID-based filename (like JupyterLab's `4300d43e-b0fc-41d3-aaf2-5332b457888b.png`) instead of reusing the clipboard filename, and the snippet builder should use an empty alt text placeholder instead of the filename.
