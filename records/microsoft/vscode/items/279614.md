# Issue #279614 — Mousing over content after OSC 633 resurrects OSC 8 tooltip hover (ie, hyperlink tooltips are re-appearing when they shouldn't)

[https://github.com/microsoft/vscode/issues/279614](https://github.com/microsoft/vscode/issues/279614)

## Summary

The stale OSC 8 hover tooltip resurrection described here shares the same root cause as #228517 — missing leave/cleanup handlers in the terminal link manager. The fix in commit 28704d8c988 (shipped in 1.120.0) adds a `leave` handler that clears the hover state and an `onRender` listener that dismisses the tooltip when the link range is re-rendered, which directly covers this scenario.

## Change summary

Hovering over a terminal OSC 8 hyperlink, then moving the mouse down to a line with an OSC 633 sequence, causes the hyperlink tooltip to reappear unexpectedly.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/228517, which is the canonical issue for stale OSC 8 hover tooltips and was fixed by https://github.com/microsoft/vscode/pull/309539. No further work needed — the fix covers this exact class of tooltip resurrection bugs.
