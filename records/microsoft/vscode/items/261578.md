# Issue #261578 — on mcp.json make it easy to see exposed tools from a server

[https://github.com/microsoft/vscode/issues/261578](https://github.com/microsoft/vscode/issues/261578)

## Summary

The requested entry point is still missing: mcp.json displays the server's tool count with an empty command ID. The linked implementation PR was closed without merging, and its maintainer feedback establishes the intended direction.

## Change summary

Make the tool count above an MCP server in mcp.json clickable so users can inspect that server's tools and descriptions.

## Best solution

Open the existing Configure Tools picker from the server's tool-count CodeLens, with the server name prefilled in its filter, the matching server expanded, and unrelated groups collapsed, as requested by the maintainer on the closed PR.
