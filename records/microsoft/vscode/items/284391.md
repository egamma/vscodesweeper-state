[https://github.com/microsoft/vscode/issues/284391](https://github.com/microsoft/vscode/issues/284391)

## Summary

The rename action for agent sessions currently gates on Local and agent-host/remote session types but excludes Background (copilotcli). The feature request to allow renaming background sessions is still unimplemented on main.

## Change summary

Allow renaming background (Copilot CLI) sessions in the agents view, which is currently only possible for local and agent-host sessions.
