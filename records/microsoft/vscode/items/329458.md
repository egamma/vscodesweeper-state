# Issue #329458 — agents window will use key bindings from disabled extension

[https://github.com/microsoft/vscode/issues/329458](https://github.com/microsoft/vscode/issues/329458)

## Summary

Fresh, team-reported bug with a video demonstration: an extension's (vim) contributed keybinding still fires inside the Agents window's text editor even after the extension is disabled. No fix commit exists on main and no PR references it, so it stays open for investigation.

## Change summary

After disabling the vim extension and reloading, its Ctrl+F keybinding (page down) still triggers instead of the editor's Find widget when using a text editor opened from the Agents window.

## Best solution

Investigate how the Agents window's editor/keybinding resolution picks up extension-contributed keybindings — likely a stale or cached keybinding cache/keymap not being invalidated on extension enablement change specific to the agents-window extension host wiring (src/vs/sessions/sessions.common.main.ts, src/vs/sessions/browser/workbench.ts) versus the main workbench, where this class of bug does not seem to occur.
