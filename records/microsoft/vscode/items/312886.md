# Issue #312886 — Agents files change list captures horizontal scrolls

[https://github.com/microsoft/vscode/issues/312886](https://github.com/microsoft/vscode/issues/312886)

## Summary

The reported horizontal-scroll interception is actionable, but the current source does not establish the failing path and there is no subsequent reproduction confirmation. Request confirmation on current Agents Insiders and a recording before treating this as fixed or proposing a code change.

## Change summary

Horizontal scrolling over a non-horizontally-scrollable changes list should reach the enclosing Agents window instead of being intercepted.

## Best solution

Preserve horizontal wheel propagation to the enclosing scrollable layout when the changes list cannot scroll in that direction, while retaining normal list scrolling. Confirm the current failure and identify the consuming element before changing the Sessions changes view or shared scrolling infrastructure.
