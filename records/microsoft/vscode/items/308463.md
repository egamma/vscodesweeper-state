# Issue #308463 — Warning about invalid MCP tool name

[https://github.com/microsoft/vscode/issues/308463](https://github.com/microsoft/vscode/issues/308463)

## Summary

VS Code intentionally normalizes MCP tool names into its language-model-compatible namespace and warns when doing so. An older report covering dot-to-underscore normalization was explicitly closed as designed, so this is a request to change that established behavior rather than a current defect.

## Change summary

Allow dots in MCP tool names without warning or replacing them with underscores.

## Best solution

Keep the existing normalization unless the language-model tool pipeline can support dots consistently across providers; the original server name is already retained for calls, so MCP invocation remains interoperable.
