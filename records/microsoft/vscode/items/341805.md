# Issue #341805 — Agents window change count uses a stale local base branch when origin/<base> is unreadable

## Summary

Keep open: a maintainer confirmed the inflated change count on current Insiders, and the same incorrect fallback remains in main. The issue is already correctly routed.

## Change summary

An unreadable remote base ref causes session change counts to include upstream changes missing from the stale local base branch.

## Best solution

Honor the documented HEAD fallback when the remote base exists but is unusable, without changing legitimate local-only branch comparisons. Report the degraded baseline without repeating raw warnings on every refresh.
