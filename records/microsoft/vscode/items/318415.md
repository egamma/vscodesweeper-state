# Issue #318415 — BYOK UI: Group name should appear in UI of `Manage Language Models`

[https://github.com/microsoft/vscode/issues/318415](https://github.com/microsoft/vscode/issues/318415)

## Summary

Still present on main: in the model picker's "Other Models" section, group headers are suppressed when there is only one provider group (`showGroupHeaders = sortedBuckets.length > 1`), so BYOK users with a single custom group see no indication of where their models come from.

## Change summary

When only one provider group exists in the model picker (e.g. a single BYOK endpoint), the group name header is hidden, leaving users confused about the origin of listed models.

## Best solution

Change the `showGroupHeaders` guard in `chatModelPicker.ts` (around line 851) so the group header is shown even when there is only one provider bucket — at least when that bucket is not the default copilot vendor. This keeps the picker clean for the common single-vendor case while surfacing the group name for BYOK setups.
