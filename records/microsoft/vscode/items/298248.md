# Issue #298248 — `vscode.lm.registerTool` API broken in `1.109.0` release.

[https://github.com/microsoft/vscode/issues/298248](https://github.com/microsoft/vscode/issues/298248)

## Summary

The API was invoking the registered tool, but the 1.109 chat UI rendered the single tool call misleadingly. The rendering path was fixed on main, and both a maintainer and the reporter confirmed that the reported behavior no longer occurs in 1.110.

## Change summary

Tools registered through `vscode.lm.registerTool` appeared unavailable to the agent in VS Code 1.109 even though the tool configuration showed them as loaded.

## Best solution

Keep the shipped single-tool-call rendering fix from https://github.com/microsoft/vscode/commit/ec33e9db9a9e20fc6019c46d190ad6774a6d0cd8; the extension API invocation path itself does not need another change for this report.
