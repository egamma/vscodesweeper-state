# Issue #311488 — Misaligned view title and actions in stacked panels (extra top offset on non-first views)

[https://github.com/microsoft/vscode/issues/311488](https://github.com/microsoft/vscode/issues/311488)

## Summary

The alignment defect remains in the classic pane-header path on current main: later headers receive a real top border while the first header suppresses it, shifting centered contents within the fixed-height border box. Modern UI avoids the defect, but it can be disabled, so the underlying shared view layout should remain tracked.

## Change summary

Keep titles, twisties, and actions vertically aligned across first and subsequent views in a stacked view container.

## Best solution

Make the shared pane separator presentation avoid changing the content box while preserving the intentional absence of a separator above the first view. Follow the non-layout-affecting separator model already used by Modern UI and cover both first and subsequent stacked headers with a visual regression check.
