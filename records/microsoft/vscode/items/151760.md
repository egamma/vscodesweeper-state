# Issue #151760 — Expose the hostname (server name on which VSCode is running on)

[https://github.com/microsoft/vscode/issues/151760](https://github.com/microsoft/vscode/issues/151760)

## Summary

Keep open in the Backlog: the stable API still exposes only the remote type, while the requested authority remains proposed-only. The request surpassed the community threshold with 22 upvotes.

## Change summary

Expose the current remote server identity to extensions so they can adapt commands and views to the connected host.

## Best solution

API maintainers should determine whether to finalize `vscode.env.remoteAuthority` or expose a privacy-safe server identifier with clearer semantics, since a remote authority is not necessarily a literal hostname.

## Evidence
