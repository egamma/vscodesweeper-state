# Issue #348271 — GitHubService requests in web windows lack a shared remote execution path

[https://github.com/microsoft/vscode/issues/348271](https://github.com/microsoft/vscode/issues/348271)

## Summary

Keep open: the shared browser GitHub binding still lacks remote execution, while BrowserRequestService provides it. The welcome migration remains an open PR, so its reported regression is not established on main; the supplied scenario is sufficient to retest without requesting more information.

## Change summary

Preserve remote-only GitHub Enterprise reachability when web consumers migrate to the shared GitHub service.

## Best solution

Provide a shared, explicitly defined web/remote execution policy that preserves authorization, cancellation, deadlines, and ownership without replaying ambiguous writes. Coordinate the welcome migration with that capability rather than adding a consumer-specific transport exception.
