# Issue #286283 — [Editor] Incorrect word wrap for monospace CJK fonts

[https://github.com/microsoft/vscode/issues/286283](https://github.com/microsoft/vscode/issues/286283)

## Summary

Keep open: the discussion confirms CJK overflow with the default wrapping strategy, and current source still derives CJK widths from a potentially fallback-rendered fullwidth Latin glyph. The advanced strategy is a confirmed workaround, not a correction to the default measurement path.

## Change summary

Long Chinese lines overflow despite word wrap when the configured monospace font contains CJK glyphs but lacks the fullwidth Latin glyph used for width measurement.

## Best solution

Make default simple wrapping agree with the rendered CJK advances for the reported font configuration, without requiring advanced wrapping or changing the font's natural character widths. Establish a controlled font-based reproduction and regression check before changing the shared font measurements.
