# Issue #330974 — Automations: automation created via chat may select unavailable model causing run failure

[https://github.com/microsoft/vscode/issues/330974](https://github.com/microsoft/vscode/issues/330974)

## Summary

Keep open: chat-created automations still accept supplied model identifiers without an evident creation-time availability check. Execution has moved to host-owned automation services since the report; the supplied steps suffice to retest the original selection mismatch, but no verified fix or qualifying duplicate was found.

## Change summary

Prevent chat-created automations from silently saving a model unavailable on their execution host.

## Best solution

Make chat-driven automation creation use the target host's model availability and provide actionable feedback before accepting an incompatible selection. Preserve existing definitions and runtime failure reporting when model availability changes after creation.
