# Issue #330974 — Automations: automation created via chat may select unavailable model causing run failure

[https://github.com/microsoft/vscode/issues/330974](https://github.com/microsoft/vscode/issues/330974)

## Summary

Team-authored bug with a real version milestone (1.135.0) assigned — the hard keep-open rules protect it from any close regardless of staleness or evidence; the fix is still pending and belongs with the automations team.

## Change summary

An automation created via chat/agent can have a model selected at creation time that isn't available on the agent host that later runs it, causing the run to fail with no clear warning.

## Best solution

Validate the selected model against the target agent host's available models at automation-creation time (likely in src/vs/sessions/contrib/automations/browser/automationDialog.ts or automationService.ts), either restricting the picker to host-available models or recording a fallback/compatible model, and surface a clear warning if the mismatch can't be resolved at creation time.
