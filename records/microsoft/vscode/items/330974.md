# Issue #330974 — Automations: automation created via chat may select unavailable model causing run failure

## Summary

Team-authored bug report (benvillalobos, MEMBER) describing a real gap in the Automations feature: chat/agent-created automations can select a model that isn't available on the agent host that later runs them, causing run failures. No fix or PR found on main, and no maintainer-verifiable duplicate — keep open.

## Change summary

Automations created via chat/agent can pick a model at creation time that isn't available on the agent host that executes the automation, so the automation fails to run.

## Best solution

In the automation creation flow, constrain the model picker to models known to be available on the target agent host (or validate/fallback at save time) so automations don't persist an unrunnable model selection; likely touches the chat model-picker population logic referenced in the related issue https://github.com/microsoft/vscode/issues/330701 and the agent-host model resolution path.
