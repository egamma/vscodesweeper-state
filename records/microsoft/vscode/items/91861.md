# Issue #91861 — Minify dependencies and remove junk files

[https://github.com/microsoft/vscode/issues/91861](https://github.com/microsoft/vscode/issues/91861)

## Summary

The junk-file removal part has been substantially addressed via the `.moduleignore` mechanism (257 rules), but minifying shipped third-party dependency JS files in node_modules remains an open optimization. Low community traction (2 upvotes over 5+ years), but a valid engineering improvement — keep open in Backlog.

## Change summary

Minify shipped node_modules dependencies and remove unnecessary files (readmes, licenses, etc.) to reduce VS Code's install/download size.

## Best solution

The junk-removal ask is largely covered by `.moduleignore` (build/.moduleignore, 257 rules). The remaining gap is minifying third-party JS files in node_modules before packaging. This is an engineering/build-system improvement in the `build/gulpfile.vscode.ts` packaging pipeline — a minification pass (e.g. esbuild/terser) over dependency JS before asar packing. Low traction suggests this isn't urgent, but it's a valid perf/size optimization to keep on the backlog.
