# Issue #343776 — Copilot/AHP: Unsandboxed retries can repeat non-idempotent side effects without informing the agent

[https://github.com/microsoft/vscode/issues/343776](https://github.com/microsoft/vscode/issues/343776)

## Summary

Keep open for human review of sandbox retry semantics. The supplied steps and two-attempt observations suffice to retest, but source inspection did not establish the reported automatic replay on current main; this sandbox-sensitive report must not be closed through cleanup.

## Change summary

Unsandboxed retries can repeat a command's completed side effects while exposing only the final attempt to the agent.

## Best solution

Make any retry after partial execution explicit to both the approving user and the agent, preserving each attempt's outcome rather than presenting the replay as a single successful execution. Establish whether the replay originates in the SDK-owned shell path or the host override before assigning the implementation boundary.
