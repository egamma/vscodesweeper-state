## Summary

Keep open for human review because this concerns sandbox execution semantics and potentially repeated side effects. Current main delegates default shell execution to the SDK/runtime; the supplied steps suffice to retest, but automatic replay and the agent-visible result were not conclusively verified.

## Change summary

Make partially executed sandbox attempts and subsequent full-command retries explicit in approval and final tool results.

## Best solution
