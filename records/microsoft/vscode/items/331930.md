# Issue #331930 — Skip tool button in agent mode should have option to give alternative instruction

[https://github.com/microsoft/vscode/issues/331930](https://github.com/microsoft/vscode/issues/331930)

## Summary

Reasonable, actionable feature request for agent-mode chat: today skipping a tool only proceeds without running it, with no way to attach a redirecting instruction. No existing setting/command covers this, so it should be routed to the chat area for product consideration.

## Change summary

Add an inline instruction/redirect input alongside the 'Skip Tool' confirmation button so skipping a tool can also steer the agent's next step.

## Best solution

Chat team should consider extending chatToolConfirmationSubPart.ts / chatToolActions.ts (SkipToolConfirmationActionId) with an optional instruction input that gets passed back into the conversation when a tool is skipped, rather than requiring a full stop-and-retype.
