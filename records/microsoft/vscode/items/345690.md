# Issue #345690 — Improve readability of function signature tooltips by displaying parameters on separate lines

[https://github.com/microsoft/vscode/issues/345690](https://github.com/microsoft/vscode/issues/345690)

## Summary

Keep open as a feature request: parameter hints already emphasize the active parameter, but do not provide the requested structured multiline layout or separate styling for types. Related requests cover wrapping and syntax highlighting, not this full proposal.

## Change summary

Present complex signatures as separate component and parameter lines, with subdued types and emphasis on the active parameter.

## Best solution

Evaluate a consistent, accessible multiline presentation in the editor parameter-hints widget, accounting for the provider metadata needed to distinguish names from types across languages. Coordinate with the existing wrapping and highlighting requests without treating either narrower issue as a duplicate canonical.

## Evidence

- **Existing settings do not cover the request:** src/vs/editor/common/config/editorOptions.ts registers only editor.parameterHints.enabled and editor.parameterHints.cycle for parameter hints; neither controls signature layout or type styling.
- **Current rendering provides partial coverage:** ParameterHintsWidget.renderParameters in src/vs/editor/contrib/parameterHints/browser/parameterHintsWidget.ts splits the provider's signature.label into before, active-parameter, and after spans. parameterHints.css emphasizes the active span using editorHoverWidget.highlightForeground and bold text, but does not create per-parameter rows or distinguish type information.
- **Provider contract constrains semantic formatting:** SignatureInformation in src/vs/editor/common/languages.ts supplies a signature label and parameter labels or offsets, but no dedicated return-type, function-name, template, or parameter-type fields. The complete proposal needs design beyond changing text wrapping.
- **Related wrapping request is narrower:** https://github.com/microsoft/vscode/issues/201732 requests hanging indentation for soft-wrapped signature lines. Its body does not request separate return-type and parameter rows or the proposed type and active-line treatment.
- **Related highlighting request is narrower:** https://github.com/microsoft/vscode/issues/55044 requests syntax highlighting of SignatureInformation.label. It overlaps the readability concern but does not own the requested multiline layout.
- **Canonical search:** Read-only GitHub searches for open signature requests involving multiline presentation, separate lines, readability, and parameter-hint formatting did not establish a canonical covering the full proposal.
