# Issue #314763 — Better name for Agent Window in the window switcher

[https://github.com/microsoft/vscode/issues/314763](https://github.com/microsoft/vscode/issues/314763)

## Summary

Still present on main: the Agents Window reuses the standard `WindowTitle` class from the workbench, which builds its title from `window.title` settings and `productService.nameLong` — there is no special-casing for the Agents Window context. The OS-level window title, the Switch Window picker, and the dock icon all reflect the generic product name. Team-authored, keeping open.

## Change summary

The Agents Window should display "Agents Window" (or similar) in the OS window switcher, the Switch Window picker, and the dock icon, instead of the generic "Visual Studio Code - Insiders" title.

## Best solution

Override or extend the title computation in `src/vs/sessions/browser/parts/titlebarPart.ts` (which instantiates `WindowTitle`) to inject an Agents-Window-specific title template or prefix. The Switch Window picker in `src/vs/workbench/electron-browser/actions/windowActions.ts` reads `window.title` from `getWindows()`, so the native window title set via `document.title` / `nativeHostService` needs to reflect the new name. May also need changes in `src/vs/platform/windows/electron-main/windowImpl.ts` for the dock/taskbar label.
