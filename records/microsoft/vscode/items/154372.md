# Issue #154372 — editor.scrollbar.verticalScrollbarSize not respected

[https://github.com/microsoft/vscode/issues/154372](https://github.com/microsoft/vscode/issues/154372)

## Summary

Still reproduces on current main: `BaseCellEditorOptions.fixedEditorOptions` hardcodes `scrollbar.verticalScrollbarSize: 14` and spreads it after the user's editor config, overwriting user settings. With 35 upvotes and a Backlog milestone, this is a valid request that needs attention.

## Change summary

The `editor.scrollbar.verticalScrollbarSize` user setting is ignored in notebook cell editors because a hardcoded scrollbar object overwrites it.

## Best solution

In `src/vs/workbench/contrib/notebook/browser/viewModel/cellEditorOptions.ts`, restructure the spread in `_computeEditorOptions()` so that `fixedEditorOptions.scrollbar` is deep-merged with the user's `editor.scrollbar` settings rather than replacing the entire object. The fixed values (like `useShadows`, `alwaysConsumeMouseWheel`) should still apply, but user-configurable properties like `verticalScrollbarSize` and `horizontal` should be respected. The same hardcoded pattern in `diffCellEditorOptions.ts` and `notebookOutputEditor.ts` should also be addressed.
