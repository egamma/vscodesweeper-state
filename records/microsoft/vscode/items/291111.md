# Issue #291111 — Consider making the in-chat terminal header element sticky when scrolling super long code

[https://github.com/microsoft/vscode/issues/291111](https://github.com/microsoft/vscode/issues/291111)

## Summary

Keep open: current chat sticky scroll pins user prompts, not the terminal headers requested here. This team-authored Backlog request remains a distinct UX improvement, with no verified fixing commit or older canonical found.

## Change summary

Keep in-chat terminal headers visible while scrolling long commands or code, both before approval and after execution.

## Best solution

Provide consistent, locally scoped header visibility for pending and executed terminal command cards, preserving command context without obscuring content or conflicting with the transcript's sticky prompt header.
