# Issue #146653 — Source Control view ignores filesystem scheme

[https://github.com/microsoft/vscode/issues/146653](https://github.com/microsoft/vscode/issues/146653)

## Summary

Keep open and classify as a bug: the built-in Git extension still converts custom-scheme workspace folders into native filesystem paths during repository discovery. Current parent-repository checks limit some visible outcomes but do not prevent the incorrect filesystem scan.

## Change summary

Prevent custom-filesystem workspace folders from causing Git discovery of unrelated native repositories with matching paths.

## Best solution

Make automatic repository discovery in extensions/git/src/model.ts respect URI schemes consistently, while preserving normal native-folder discovery, including in WSL. A virtual folder must not cause Git to inspect or display repositories from the corresponding native path.
