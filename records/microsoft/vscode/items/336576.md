# Issue #336576 — Sign in to GitHub entry is missing after signing out of Copilot

[https://github.com/microsoft/vscode/issues/336576](https://github.com/microsoft/vscode/issues/336576)

## Summary

The bug remains source-reproducible on current main: completing setup persists `chatSetupCompleted=true`, but the Accounts sign-in action requires setup to be incomplete, so signing out cannot make that action visible again.

## Change summary

Signing out of Copilot after completing setup removes the GitHub/Copilot sign-in entry from the Accounts menu.

## Best solution

Keep the Accounts sign-in action available whenever Copilot is signed out and no default GitHub account is available, regardless of whether setup was completed previously.
