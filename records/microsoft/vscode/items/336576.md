# Issue #336576 — Sign in to GitHub entry is missing after signing out of Copilot

[https://github.com/microsoft/vscode/issues/336576](https://github.com/microsoft/vscode/issues/336576)

## Summary

Traced a plausible real cause in source: the Accounts-menu 'Sign in to GitHub' entry (ChatSetupFromAccountsAction) is only shown while `CONTEXT_DEFAULT_ACCOUNT_STATE` is not `Available`, i.e. it hides whenever a GitHub authentication session still exists — independent of whether the Copilot entitlement itself was separately signed out. If 'sign out of Copilot' doesn't also clear/refresh the underlying GitHub session or default-account state, the user is left with no visible way back in. This needs a maintainer/agent session to confirm exactly what UI action 'sign out of Copilot' performs before deciding whether this is a bug or as-designed.

## Change summary

After signing out of Copilot (but apparently keeping some GitHub session state), the 'Sign in to GitHub' entry disappears from the Accounts menu, leaving no way to sign back in.

## Best solution

Clarify what 'sign out of Copilot' does to the GitHub authentication session and `DefaultAccountStatus`; either make that sign-out also clear the default account session so the menu condition in chatSetupContributions.ts re-shows the sign-in entry, or add a distinct 'reconnect'/'sign in to GitHub Copilot' affordance when signed out of Copilot but the GitHub session persists.
