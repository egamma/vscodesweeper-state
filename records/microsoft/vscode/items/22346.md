# Issue #22346 — Feature request: highlight problem indicator with color when problems exist

[https://github.com/microsoft/vscode/issues/22346](https://github.com/microsoft/vscode/issues/22346)

## Summary

The requested conditional coloring of the status-bar problem counters remains missing on current main. This accepted Backlog request has 35 upvotes and an existing duplicate; no verified older canonical or shipped capability supersedes it.

## Change summary

Highlight the status-bar error and warning indicators with distinct colors when their respective counts are nonzero.

## Best solution

Provide theme-aware, severity-specific emphasis for nonzero problem counts while keeping zero-count indicators neutral. Settle the foreground-versus-background presentation with the UX owner before implementation, preserving compact layout and readable high-contrast behavior.
