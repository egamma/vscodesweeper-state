# Issue #254824 — Code CLI script fails with "Unable to determine app path from symlink" with bash 5.3

[https://github.com/microsoft/vscode/issues/254824](https://github.com/microsoft/vscode/issues/254824)

## Summary

Still reproduces on main: the nested parameter expansion `${SOURCE_DIR%%${SOURCE_DIR#*.app}}` in `resources/darwin/bin/code.sh` line 23 behaves differently in bash 5.3 vs 3.2, producing an empty string and triggering the 'Unable to determine app path' error. An open PR (#255558) exists but has not merged.

## Change summary

The `code` CLI shell script on macOS fails to resolve the .app path when invoked under bash 5.3 (e.g. Homebrew bash) due to a non-portable nested parameter expansion.
