## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/230136 tracks the same observable gap—extensions cannot dynamically associate a generated JSON schema with a document when static file globs are insufficient.

## Change summary

Expose an extension API for dynamically registering JSON schemas and associating or disassociating them with individual documents.

## Best solution

Consolidate API design and demand in https://github.com/microsoft/vscode/issues/230136. That issue already covers dynamic per-document schema association, dynamic schema content, activation concerns, and the possible design of programmatic contribution-point registration.
