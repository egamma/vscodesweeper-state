# Issue #234263 — Light bulb shows up for move to new file?

[https://github.com/microsoft/vscode/issues/234263](https://github.com/microsoft/vscode/issues/234263)

## Summary

Keep this open: the accepted Backlog bug reflects an upstream TypeScript language-service filtering gap, and a later report confirmed the same unwanted implicit refactoring behavior. The upstream report was closed administratively for the native language-service rewrite, not because the behavior was verified fixed.

## Change summary

Suppress the automatic light bulb when Move to File is the only available action and the cursor is not on a declaration name.

## Best solution

The TypeScript language service should offer Move to File for implicit requests only when the cursor is on a class, symbol, function, or other declaration name, while preserving the action for explicit refactoring requests. Verify that contract against the current built-in language service and track the fix in its active implementation.

## Evidence

- **intended behavior:** A VS Code maintainer states that prior work intended the action to appear only at top-level declarations: https://github.com/microsoft/vscode/issues/234263#issuecomment-2503634837.
- **current code path:** extensions/typescript-language-features/src/languageFeatures/refactor.ts:552-575 sends automatic requests to tsserver with triggerReason `implicit`; VS Code applies its declaration-name filter only for TypeScript API versions older than 5.4, so newer services own this filtering.
- **upstream implementation:** https://github.com/microsoft/TypeScript/pull/57080 attempted to reduce implicit Move to File actions in merge commit 60f93aa83ae644092ace6d729d0f10c42715292f, but its block-ancestor condition did not enforce the declaration-name-only contract.
- **later confirmation:** https://github.com/microsoft/TypeScript/issues/62780 reproduced the same observable symptom in VS Code 1.106.1, and https://github.com/microsoft/TypeScript/issues/62780#issuecomment-3549895399 confirms that implicit Move to File should appear only on a class, symbol, or function name.
- **not verified fixed:** https://github.com/microsoft/TypeScript/issues/62780 was bulk-closed under https://github.com/microsoft/TypeScript/issues/62827 because the language service was being rewritten; the closure explicitly did not verify whether individual bugs were resolved.
