# Issue #322911 — secondary side bar

[https://github.com/microsoft/vscode/issues/322911](https://github.com/microsoft/vscode/issues/322911)

## Summary

This is a valid, currently unmet layout request. Route it to the Secondary Side Bar and layout owners to evaluate an overlay mode that preserves editor space during Copilot-assisted code review.

## Change summary

Allow the Secondary Side Bar, particularly Copilot Chat, to float over the editor instead of consuming docked layout space.

## Best solution

Provide an opt-in, resizable overlay mode for the Secondary Side Bar that does not reflow the editor, while retaining the existing docked and detached-window modes.
