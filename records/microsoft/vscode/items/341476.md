[https://github.com/microsoft/vscode/issues/341476](https://github.com/microsoft/vscode/issues/341476)

## Summary

The current coverage API does not expose condition or MC/DC metrics independently, so this remains a valid extension-API request. Existing percentage settings and branch labels do not deliver the requested metric-specific native experience; no matching canonical was identified.

## Change summary

Extend native test coverage reporting and visualization to support condition and MC/DC coverage and potentially other extension-defined metrics.

## Best solution

Have the testing API owners assess a coverage model that preserves the semantics of condition and MC/DC results across reporting, aggregation, and editor presentation. Decide whether these should be explicit supported metrics or part of a general extensibility contract before implementation.
