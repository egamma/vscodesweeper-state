# Issue #144893 — Toggle all files in "refactor previews"

[https://github.com/microsoft/vscode/issues/144893](https://github.com/microsoft/vscode/issues/144893)

## Summary

A real Refactor Preview gap remains: current main can toggle only the focused category, file, or edit, with no command to check or uncheck the entire preview. The issue is already correctly routed and accepted into the Backlog.

## Change summary

Add a Refactor Preview action that checks or unchecks every file in the pending workspace edit.

## Best solution

Add a global check/uncheck action to the Refactor Preview title or context menu, backed by BulkEditPane and the shared checked-state model. Keep the existing per-category, per-file, and per-edit controls unchanged.
