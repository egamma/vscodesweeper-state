## Summary

The current source still transiently hides the focused Auto Update checkbox when its state changes, without restoring focus. Keep this report open for a bounded accessibility fix and subsequent tester verification.

## Change summary

Preserve keyboard focus and its visible indicator when checking or unchecking an extension's Auto Update checkbox.

## Best solution

The Extensions editor should retain focus on the same eligible Auto Update checkbox throughout a checked-state refresh, without changing auto-update settings or legitimate disabled/hidden behavior.
