# Issue #250814 — when the webview of my extension crash, how can i deal with it?

[https://github.com/microsoft/vscode/issues/250814](https://github.com/microsoft/vscode/issues/250814)

## Summary

Valid feature request for an extension API to detect when a webview renderer crashes or becomes unresponsive. The current API only exposes `onDidDispose` (fired on explicit close), with no crash or unresponsive notification. No existing setting, command, or API covers this; the request remains a real gap.

## Change summary

Provide an extension API to detect webview crashes or unresponsiveness so extensions can recover (e.g. reload the webview).

## Best solution

Add an event like `Webview.onDidBecomeUnresponsive` or `WebviewPanel.onDidCrash` to the extension API, potentially backed by Electron's `render-process-gone` / `unresponsive` events on the underlying webview. The implementation would live in `src/vs/workbench/contrib/webview/` and the API surface in `src/vscode-dts/`. This is a narrowly scoped API addition that serves extension authors who build rich webview-based UIs.
