# Issue #250814 — when the webview of my extension crash, how can i deal with it?

[https://github.com/microsoft/vscode/issues/250814](https://github.com/microsoft/vscode/issues/250814)

## Summary

Keep open: the public webview API still lacks crash or unresponsive notifications. Existing reload and messaging capabilities do not fully cover the requested automatic detection and recovery.

## Change summary

Provide an extension API to detect a crashed or unresponsive webview so the extension can recover its panel.

## Best solution

Have the webview/API owners decide whether to expose a supported failure notification and recovery contract, distinguishing crashes from temporary unresponsiveness and normal panel disposal. Manual reload and extension-managed message acknowledgements are partial workarounds, not equivalent coverage.
