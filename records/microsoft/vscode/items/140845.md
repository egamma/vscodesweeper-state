# Issue #140845 — Proposal: pin specific thread(s) when debugging

[https://github.com/microsoft/vscode/issues/140845](https://github.com/microsoft/vscode/issues/140845)

## Summary

Keep open: existing stepping shortcuts avoid clicking moving inline controls, but do not provide an ordered set of pinned threads or commands bound to those pins. The linked concurrency investigation provides relevant design context, not a verified duplicate of this specific interaction request.

## Change summary

Provide stable access to selected debug threads, optionally pinning them in selection order with stepping shortcuts that target those threads.

## Best solution

Define a focused-thread workflow in the debug Call Stack that preserves access to user-selected threads as other stacks change. Settle pin ordering and command-target semantics alongside the concurrency discussion without assuming that thread filtering alone satisfies this request.
