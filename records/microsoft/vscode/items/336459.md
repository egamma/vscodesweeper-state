# Issue #336459 — Add 'partial' option to `TreeItemCheckboxState` for a tri-state checkbox in `TreeItem`

[https://github.com/microsoft/vscode/issues/336459](https://github.com/microsoft/vscode/issues/336459)

## Summary

Legitimate, unimplemented API request: the internal `TriStateCheckbox`/dash-icon support already landed for internal widgets (e.g. quick input), but `TreeItemCheckboxState` still only exposes `Unchecked`/`Checked` — no 'partial' state exists in the public API on current main. The issue is already assigned to a VS Code team member, so it's on the right radar; route to the tree-view API area.

## Change summary

Extend the `TreeItemCheckboxState` extension API with a 'partial'/indeterminate state so tree items can show a dash-style tri-state checkbox.

## Best solution

Expose the existing internal tri-state checkbox support (added via the toggle/checkbox widget work referenced by the reporter) through the public `vscode.TreeItemCheckboxState` enum or a new checkbox state, likely touching src/vscode-dts/vscode.d.ts, src/vs/workbench/api/common/extHostTypes.ts, and src/vs/workbench/api/common/extHostTreeViews.ts plus the tree-view rendering code that maps checkbox state to an icon.
