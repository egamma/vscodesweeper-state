# Issue #336459 — Add 'partial' option to `TreeItemCheckboxState` for a tri-state checkbox in `TreeItem`

[https://github.com/microsoft/vscode/issues/336459](https://github.com/microsoft/vscode/issues/336459)

## Summary

The extension-facing TreeItem checkbox API still lacks a partial state. The existing internal tri-state widget does not satisfy this request, and the older related icon-design issue does not own the missing API capability.

## Change summary

Expose a partial checkbox state on TreeItem so extensions can indicate partially selected children.

## Best solution

Extend the tree-view checkbox API and its extension-host/workbench representation to support an accessible partial state, with defined interaction and parent/child propagation semantics. Reuse the existing tri-state checkbox behavior where appropriate rather than introducing a separate visual convention.
