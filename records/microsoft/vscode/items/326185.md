# Issue #326185 — http.noProxy config not work for agent host when request BYOK model

[https://github.com/microsoft/vscode/issues/326185](https://github.com/microsoft/vscode/issues/326185)

## Summary

The agent host sets HTTP_PROXY/HTTPS_PROXY env vars for the Copilot SDK subprocess but does not forward the http.noProxy setting as a NO_PROXY env var, so BYOK model endpoints listed in noProxy are still routed through the proxy. This is a real gap on current main.

## Change summary

When using a BYOK model with a local endpoint (e.g. 127.0.0.1), the http.noProxy setting is not forwarded to the Copilot SDK subprocess, causing requests to be routed through the proxy instead of connecting directly.

## Best solution

In `_configureProxyEnv` in `src/vs/platform/agentHost/node/copilot/copilotAgent.ts`, when setting `HTTP_PROXY`/`HTTPS_PROXY`, also read `http.noProxy` from the configuration service and set the `NO_PROXY` env var (comma-separated) so the SDK subprocess respects the user's noProxy list.
