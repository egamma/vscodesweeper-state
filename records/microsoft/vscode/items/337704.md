# Issue #337704 — Add a native "Toggle Line Numbers" command for the text editor

[https://github.com/microsoft/vscode/issues/337704](https://github.com/microsoft/vscode/issues/337704)

## Summary

Valid gap: confirmed on main there is no toggle command for `editor.lineNumbers` in the standard text editor, only notebook-specific ones — a small, well-precedented addition analogous to existing toggle commands.

## Change summary

Add a 'View: Toggle Line Numbers' command for the regular text editor, mirroring existing toggle commands like Toggle Minimap/Word Wrap.

## Best solution

Add a new `editor.action.toggleLineNumbers` Action2 in src/vs/workbench/contrib/codeEditor/browser/ (new file, following the toggleMinimap.ts/toggleWordWrap.ts pattern), registered in codeEditor.contribution.ts, toggling `editor.lineNumbers` between `off` and `on`.

- **Behavior:**

  > A new command (e.g. `editor.action.toggleLineNumbers`, title 'View: Toggle Line Numbers') is available in the Command Palette and can be bound to a keybinding. Invoking it toggles `editor.lineNumbers` between 'off' and 'on' for the active text editor's configuration scope. When the setting is currently 'relative' or 'interval', toggling turns it off; toggling again restores 'on' (matching the notebook toggle's off/non-off semantics). The command shows as checked/toggled in the Command Palette when line numbers are enabled, mirroring `editor.action.toggleMinimap`.

The closest core precedent is src/vs/workbench/contrib/codeEditor/browser/toggleMinimap.ts, a small Action2 reading/writing `editor.minimap.enabled` via IConfigurationService, registered via registerAction2 and imported in codeEditor.contribution.ts alongside toggleWordWrap.ts and toggleRenderWhitespace.ts. The boundary: do not touch notebook line-number commands or the `editor.lineNumbers` option's renderer implementation in src/vs/editor/common/config/editorOptions.ts — only add a new workbench-level command that reads/writes the configuration value, following the existing toggle-command family exactly.
