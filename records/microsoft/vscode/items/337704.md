# Issue #337704 — Add a native "Toggle Line Numbers" command for the text editor

[https://github.com/microsoft/vscode/issues/337704](https://github.com/microsoft/vscode/issues/337704)

## Summary

Reasonable, well-scoped request: there is genuinely no command to toggle `editor.lineNumbers` for the regular text editor, and VS Code already ships this exact pattern (toggle command + per-value actions) for several other editor display options, so this fits cleanly alongside them.

## Change summary

Add a 'Toggle Line Numbers' command (and ideally per-value set actions) for the standard text editor, mirroring the notebook-only commands that already exist.

## Best solution

Add `editor.action.toggleLineNumbers` in src/vs/workbench/contrib/codeEditor/browser/ following the toggleRenderWhitespace.ts/toggleMinimap.ts pattern: a binary toggle between 'on' and 'off' (the established convention for multi-value settings like editor.renderWhitespace), plus optional per-value actions (on/off/relative/interval) in an Appearance submenu.
