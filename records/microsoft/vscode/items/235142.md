# Issue #235142 — Task command hangs and doesn't recognize completion of detached processes

[https://github.com/microsoft/vscode/issues/235142](https://github.com/microsoft/vscode/issues/235142)

## Summary

Keep open: the report includes a complete Docker Compose reproduction and an independent zsh confirmation, but inspection did not establish a current fix or a qualifying canonical duplicate. Diagnose where shell exit or task completion is delayed before changing the preLaunchTask behavior.

## Change summary

A foreground shell task running docker compose up -d remains active when container initialization is delayed, blocking the debugger's preLaunchTask.

## Best solution

Ensure a foreground task completes when its shell command exits, independently of detached container lifetime. First distinguish a still-running Compose command from a missing terminal exit event or task-completion event; debugger attachment readiness remains a separate concern.
