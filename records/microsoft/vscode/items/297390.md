# Issue #297390 — Reloading window before committing changes evades co-authoring

[https://github.com/microsoft/vscode/issues/297390](https://github.com/microsoft/vscode/issues/297390)

## Summary

Still reproduces on main: the AI contribution tracking in AiContributionFeature is entirely in-memory (ResourceMap) with no persistence layer, so a window reload clears all tracked AI edits, causing the co-author trailer to be omitted on subsequent commits.

## Change summary

Reloading the window before committing loses AI edit tracking, so the Copilot co-author trailer is not appended to the commit message.

## Best solution

Persist the AI contribution state (or at least a per-file 'has AI contributions' flag) across window reloads — likely via IStorageService (workspace-scoped) in AiContributionFeature or in the git extension's repository logic. The fix touches `src/vs/workbench/contrib/editTelemetry/browser/aiContributionFeature.ts` and possibly `extensions/git/src/repository.ts`.
