# Issue #289208 — Increase sign in awareness from new welcome chat

[https://github.com/microsoft/vscode/issues/289208](https://github.com/microsoft/vscode/issues/289208)

## Summary

Keep open: cancelling setup still leaves a plain-text chat response without the requested sign-in action. Existing sign-in commands do not cover this contextual affordance, and no verified canonical or issue-referencing fix was found.

## Change summary

Provide a sign-in button in the setup-required chat response reached after skipping sign-in from the welcome page.

## Best solution

Make the setup-required response offer a discoverable, keyboard-accessible action that opens the existing Copilot sign-in flow. Preserve cancellation, workspace-trust guidance, and anonymous-chat behavior.
