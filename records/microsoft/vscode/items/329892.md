# Issue #329892 — Expose contextSizeOptions for BYOK models

[https://github.com/microsoft/vscode/issues/329892](https://github.com/microsoft/vscode/issues/329892)

## Summary

Real gap confirmed in source: the context-size selector is built only from `endpoint.tokenPricing.default.contextMax` (CAPI pricing data) in languageModelAccess.ts, which BYOK models never populate, so BYOK users truly lack this UI without the workaround the reporter describes.

## Change summary

Add a `contextSizeOptions`-style field to `BYOKModelCapabilities` so BYOK model definitions can drive the same context-size dropdown that built-in Copilot models get.

## Best solution

Extend `BYOKModelCapabilities` in extensions/copilot/src/extension/byok/common/byokProvider.ts with an optional context-size-tiers field, and thread it into `getContextSizeOptions` in extensions/copilot/src/extension/conversation/vscode-node/languageModelAccess.ts as an alternative source alongside `endpoint.tokenPricing`.
