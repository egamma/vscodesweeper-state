# Issue #316317 — git.addAICoAuthor is not tracking correctly

[https://github.com/microsoft/vscode/issues/316317](https://github.com/microsoft/vscode/issues/316317)

## Summary

Still unfixed on main: AI contribution tracking only covers documents open in the annotated-documents pipeline; hidden documents and agent-host edits (e.g. apply patch) are never tracked, so `hasAiContributions` returns false and the co-author trailer is never added.

## Change summary

AI-generated edits from agent-host operations (like apply patch) are not tracked, so the `git.addAICoAuthor` trailer is never appended to commit messages for those edits.

## Best solution

Widen the AI contribution tracking in `src/vs/workbench/contrib/editTelemetry/browser/aiContributionFeature.ts` to cover hidden/unopened documents and agent-host edits. The closed PR #316691 contains a working approach that can be salvaged and conflict-resolved by a team member.
