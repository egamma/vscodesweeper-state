# Issue #346102 — Use Compare Models to generate a plan, then implement it

[https://github.com/microsoft/vscode/issues/346102](https://github.com/microsoft/vscode/issues/346102)

## Summary

Keep open: Compare Models supports implementation comparison and synthesis, but does not yet provide the requested plan-review, editing, and implementation handoff. This team-authored request needs workflow design rather than a judgment close.

## Change summary

Extend Compare Models to compare plans, select or combine their strengths, edit the final plan, and launch its implementation.

## Best solution

Extend the existing Sessions comparison workflow with planning-aware evaluation and an editable final plan that can explicitly start an implementation session, while preserving implementation comparisons.

- **Behavior:**

  > Users can ask multiple models to plan the same task and inspect their plans side by side. They can select one plan or combine useful parts, edit the resulting plan, and explicitly launch implementation from that final content. A configured Judge evaluates the plans' strengths and gaps rather than requiring implementation diffs. Existing implementation comparisons remain available.
- **Trace:**

  > The existing comparison architecture is documented in src/vs/sessions/SESSION_COMPARISONS.md. IStartSessionComparisonOptions and ISessionComparison in services/sessions/common/sessionComparison.ts represent generic attempts but expose no dedicated planning workflow; synthesisPlan stores only additional instructions. SessionComparisonService.synthesize launches a new implementation using worktree evidence, while createSessionComparisonJudgePrompt evaluates code and validation results. SessionComparisonResult is the existing recommendation and synthesis surface. The unresolved design spans plan representation, editing, evaluation, and transfer into implementation; this review did not establish a complete contract for those transitions. Preserve provider-neutral orchestration, original attempts, and existing implementation-comparison behavior.
