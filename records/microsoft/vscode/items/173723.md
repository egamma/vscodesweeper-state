# Issue #173723 — Keybindings in the keybindings editor should use <kbd>

[https://github.com/microsoft/vscode/issues/173723](https://github.com/microsoft/vscode/issues/173723)

## Summary

The requested keyboard-input markup is still missing: the Keyboard Shortcuts editor renders its keycaps as spans. Existing spoken labels provide partial accessibility support, but do not satisfy the semantic-markup request.

## Change summary

Use semantic keyboard-input markup for keybindings displayed in the Keyboard Shortcuts editor.

## Best solution

Give displayed shortcut keys keyboard-input semantics while preserving their existing appearance, highlighting, and accessible labels. Keep general Markdown rendering separate from this editor-specific issue.
