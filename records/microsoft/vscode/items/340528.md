## Summary

Keep open as a feature request: Blobby already supports optional enablement and reduced-motion handling, but its animations are not connected to Voice Mode listening or playback. No verified canonical issue or landed implementation covers the requested integration.

## Change summary

Let Blobby optionally reflect Voice Mode listening, speaking, interruption, and completion without additional audio processing or changes to agent behavior.

## Best solution
