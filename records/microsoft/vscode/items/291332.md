# Issue #291332 — Test 12.2 fails for Codespaces which's a linux machine for Test 1

[https://github.com/microsoft/vscode/issues/291332](https://github.com/microsoft/vscode/issues/291332)

## Summary

Keep open: Search View still derives glob case sensitivity from the client OS, so a macOS client incorrectly requests case-insensitive matching against a Linux Codespace. The linked test plan explicitly requires the remote OS to determine this behavior.

## Change summary

Search include and exclude globs should respect Linux remote case sensitivity when VS Code runs on macOS.

## Best solution

Make Search View glob matching follow the searched environment rather than the client platform, preserving existing local-platform behavior and adding coverage for differing client and remote operating systems.
