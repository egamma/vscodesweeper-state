# Issue #264959 — Live editing OAI Compatible setting doesn't reflect changes in model picker

[https://github.com/microsoft/vscode/issues/264959](https://github.com/microsoft/vscode/issues/264959)

## Summary

Still reproduces on main: the LanguageModelsConfigurationService only reacts to file-system-level changes (saves) via fileService.onDidFilesChange, so in-editor edits to the OAI compatible config file are not reflected in the model picker until the file is saved. The bug remains open with no fix commit referencing this issue.

## Change summary

Editing OAI Compatible settings in the editor does not live-update the model picker until the file is saved.

## Best solution

Add a listener on the in-memory text model's content changes (e.g. via ITextModelService/onDidChangeContent) in LanguageModelsConfigurationService so that edits are picked up in real time, not just on file save. The fix is localized to src/vs/workbench/contrib/chat/browser/languageModelsConfigurationService.ts.
