# Issue #309434 — Can't get back to the list in Agent Customizations by clicking list entry

[https://github.com/microsoft/vscode/issues/309434](https://github.com/microsoft/vscode/issues/309434)

## Summary

Still reproduces on main: clicking the same section entry (e.g. Hooks) while in editor/detail view does not navigate back to the list because `selectSection` early-returns when `selectedSection === section`.

## Change summary

In Agent Customizations, clicking the current section's sidebar entry while viewing an item's detail/editor does not navigate back to the section list.

## Best solution

In `selectSection` (aiCustomizationManagementEditor.ts ~line 986), the early return when `selectedSection === section` should still invoke the `goBackToList`/`goBackFromMcpDetail`/`goBackFromPluginDetail`/`goBackFromToolDetail` calls when `viewMode` is not `'list'`, so that re-clicking the section returns to the list view.
