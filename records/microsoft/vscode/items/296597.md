[https://github.com/microsoft/vscode/issues/296597](https://github.com/microsoft/vscode/issues/296597)

## Summary

Keep open: current code has same-name collision handling, but that does not establish de-duplication between Claude-native servers and tools forwarded through VS Code's bridge. This team-authored request has neither a verified older canonical nor an explicitly issue-linked fixing commit.

Prevent Claude from receiving duplicate MCP tools when the same server is configured natively and exposed through VS Code.
