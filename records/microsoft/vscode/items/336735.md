# Issue #336735 — Codex Agent Host restarts the full MCP server set in an existing thread

[https://github.com/microsoft/vscode/issues/336735](https://github.com/microsoft/vscode/issues/336735)

## Summary

The report provides a credible same-thread reproduction and timestamped evidence that all configured MCP servers restart without an MCP configuration edit. This is a current Agent Host bug with no verified duplicate or merged fix, so it should remain open.

## Change summary

Continuing an existing Codex Agent Host thread can restart every configured MCP server when unrelated workspace or customization changes alter the materialized MCP signature.

## Best solution

Keep MCP server processes stable for the lifetime of a resumed Codex thread, and reload only servers whose effective MCP configuration changed. The Agent Host's pre-turn launch validation should distinguish MCP-relevant changes from unrelated workspace or customization invalidations.
