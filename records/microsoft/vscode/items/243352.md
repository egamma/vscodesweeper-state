# Issue #243352 — Show 'Files are Identical' popup / hint  when there are no changes in two files being compared.

[https://github.com/microsoft/vscode/issues/243352](https://github.com/microsoft/vscode/issues/243352)

## Summary

Keep open: current code provides a whitespace-only hint but excludes fully identical files. An open implementation PR already references this request, and the maintainer has asked for a unified comparison-state UI rather than a notification.

## Change summary
