# Issue #336091 — Auto Mode Model Switching and Usage Cost

[https://github.com/microsoft/vscode/issues/336091](https://github.com/microsoft/vscode/issues/336091)

## Summary

Keep open as a request for more predictable Auto routing and advance cost transparency. Existing routing explanations and manual model selection provide partial coverage, but neither establishes that the requested switch controls and cost warnings are already delivered.

## Change summary

Make Auto model changes predictable through advance explanations, cost warnings, conversation-level model control, and efficient context reuse.

## Best solution

Define an Auto-switching experience that communicates consequential model and cost changes before the next request, while retaining explicit model selection as the predictable alternative. Investigate the reported context-consumption increase separately before promising that summarization or model locking will reduce its cost.
