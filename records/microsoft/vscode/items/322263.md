# Issue #322263 — Copilot : Allow extensions to register custom sections in the Agent Customizations panel

[https://github.com/microsoft/vscode/issues/322263](https://github.com/microsoft/vscode/issues/322263)

## Summary

Well-researched feature request to let extensions register custom sections in the Agent Customizations panel. The proposed `chatSessionCustomizationProvider` API already allows custom type IDs via `new ChatSessionCustomizationType(id)`, but the management editor UI has hardcoded section metadata so custom types have no visible representation. This is a real gap in the proposed API surface — routing to the ai-customizations area for the team to consider as part of the API's finalization.

## Change summary

Allow extensions to register custom section types (with label, icon, description) in the Agent Customizations management editor, so that custom `ChatSessionCustomizationType` IDs created via the proposed API actually render in the UI.

## Best solution

When finalizing the `chatSessionCustomizationProvider` proposed API, add an extension point (declarative `contributes` or programmatic registration) that lets extensions supply UI metadata (label, icon, description) for custom `ChatSessionCustomizationType` IDs, so the management editor can render sections for extension-defined types. The hardcoded `sectionInfo` map in `aiCustomizationManagementEditor.ts` and `AICustomizationManagementSection` in `aiCustomizationWorkspaceService.ts` would need to become extensible.
