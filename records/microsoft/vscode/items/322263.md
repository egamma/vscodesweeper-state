# Issue #322263 — Copilot : Allow extensions to register custom sections in the Agent Customizations panel

[https://github.com/microsoft/vscode/issues/322263](https://github.com/microsoft/vscode/issues/322263)

## Summary

The extension-API gap remains: current main has an internal section registry, but extensions cannot register new management sections through the proposed customization-provider API. Keep this open for an API-owner scope decision; no verified canonical or completed implementation was found.

## Change summary

Allow extensions to contribute new customization categories with display metadata and items to the Agent Customizations management editor.

## Best solution

Decide whether extension-defined customization categories belong in the shared management editor and, if accepted, define a constrained contribution contract consistent across the editor workbench and Agents Window. Distinguish customization-item categories from arbitrary monitoring, account, or settings pages rather than assuming every suggested use case needs the same API.
