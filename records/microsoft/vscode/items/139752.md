# Issue #139752 — [json] Local JSON schemas should find each other based on their id fields

[https://github.com/microsoft/vscode/issues/139752](https://github.com/microsoft/vscode/issues/139752)

## Summary

A real capability gap remains: current JSON support resolves configured schema locations but does not discover workspace schemas by `$id`. The request is already correctly classified and parked in the Backlog.

## Change summary

Resolve remote JSON Schema references to local workspace schemas by indexing their `$id` values.

## Best solution

Add an efficient workspace schema registry keyed by `$id`, or an explicit workspace-relative alias mechanism, in the built-in JSON language feature. The design should avoid an unconditional expensive workspace scan and preserve standard JSON Schema URI semantics.
