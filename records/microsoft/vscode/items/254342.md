# Issue #254342 — ERR_CERT_COMMON_NAME_INVALID

[https://github.com/microsoft/vscode/issues/254342](https://github.com/microsoft/vscode/issues/254342)

## Summary

This is a transient server-side certificate issue — GitHub's infrastructure intermittently serves a `github.com` certificate for `api.individual.githubcopilot.com`, which VS Code correctly rejects. There is no VS Code code defect; multiple related issues have been closed with the same conclusion.

## Change summary

Intermittent ERR_CERT_COMMON_NAME_INVALID errors when VS Code connects to Copilot services.

## Best solution

Close as a service-side transient issue. The openssl evidence in the thread confirms a server/CDN misconfiguration serving the wrong certificate, not a VS Code client bug. Users experiencing this should retry, check for network intermediaries (proxies, Pi-hole, corporate firewalls), and report persistent issues to GitHub Support.
