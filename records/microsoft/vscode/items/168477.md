# Issue #168477 — Editor history should include editors that open inactive

[https://github.com/microsoft/vscode/issues/168477](https://github.com/microsoft/vscode/issues/168477)

## Summary

The requested history behavior remains absent on current main, and a maintainer explicitly accepted it as a backlog feature. It is already correctly classified and routed.

## Change summary

Include editors opened without becoming active in editor history and recent-file pickers.

## Best solution

Update the workbench history service to incorporate newly opened inactive editors without incorrectly promoting them as recently active, so Compare Active File With and other history consumers can find them.
