# Issue #168477 — Editor history should include editors that open inactive

[https://github.com/microsoft/vscode/issues/168477](https://github.com/microsoft/vscode/issues/168477)

## Summary

Keep this accepted backlog feature open: current history updates still depend on editor activation, so newly opened background editors can remain absent from the compare picker. The maintainer explicitly endorsed changing this behavior, and no verified canonical or concrete fix was found.

## Change summary

Include editors opened inactive in recently opened editor history without requiring users to activate each tab first.

## Best solution

Make recently opened editor history include newly opened, eligible background editors so both Compare Active File With and recent-file pickers offer them immediately. Preserve access to previously opened files and existing navigation-history semantics, with a maintainer decision on ordering inactive batch openings.
