# Issue #201555 — Moving outline view out of explorer makes command name weird

[https://github.com/microsoft/vscode/issues/201555](https://github.com/microsoft/vscode/issues/201555)

## Summary

Verified duplicate of #201085, which was fixed by removing the category from the focus view command registration — the same fix resolves this Outline view case.

## Change summary

Moving the Outline view out of the Explorer causes its 'Focus on Outline View' command to display a weird internal container ID as a prefix.

## Best solution

Close as duplicate of https://github.com/microsoft/vscode/issues/201085, which was fixed in commit a295ee87fa5 and shipped in 1.96.0.
