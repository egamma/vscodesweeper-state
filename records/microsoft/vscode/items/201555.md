# Issue #201555 — Moving outline view out of explorer makes command name weird

[https://github.com/microsoft/vscode/issues/201555](https://github.com/microsoft/vscode/issues/201555)

## Summary

Still reproduces on main: when a view (e.g. Outline) is dragged to its own container in the activity bar, the focus command category becomes the placeholder "User View Container", producing a weird command name like "User View Container: Focus on Outline View".

## Change summary

Moving a view like Outline out of Explorer into its own activity bar container produces a confusing command name in the command palette because the generated container's placeholder title leaks into the command category.

## Best solution

When registering the focus view action for views in generated containers, use the view's own name as the category (or omit the category) instead of the container's placeholder title "User View Container". The fix likely belongs in `src/vs/workbench/services/views/browser/viewsService.ts` around line 169 where `container.title` is passed to `registerFocusViewAction`, with a check for whether the container is a generated/placeholder container.
