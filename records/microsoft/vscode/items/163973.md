# Issue #163973 — Allow notebook renderers to access additional output mimes

[https://github.com/microsoft/vscode/issues/163973](https://github.com/microsoft/vscode/issues/163973)

## Summary

Keep this API proposal open: additional MIME access exists experimentally, but current source explicitly warns renderer authors not to ship extensions depending on it. The merged implementation does not complete the proposal's finalization lifecycle.

## Change summary

Allow notebook renderers to enumerate and retrieve other MIME representations of the output they are rendering.

## Best solution

The notebook API owners should decide whether to finalize the experimental additional-output access contract or explicitly abandon it. Automatic renderer fallback is related functionality, not a replacement for a renderer accessing alternative output data itself.
