# Issue #163973 — Allow notebook renderers to access additional output mimes

[https://github.com/microsoft/vscode/issues/163973](https://github.com/microsoft/vscode/issues/163973)

## Summary

The proposed API (`_allOutputItems`) was implemented via PR #163974 and shipped in 1.73.0, but it remains prefixed with `_` and warns 'DO NOT ship an extension that depends on it!' — finalization is still pending, so this issue should stay open to track that.

## Change summary

Allow notebook renderers to access all mime-typed data for an output item so they can fall back to rendering a different mime.

## Best solution

Finalize the `_allOutputItems` proposed API (remove the `_` prefix, drop the proposed-API warning) in `src/vs/workbench/contrib/notebook/browser/view/renderers/webviewPreloads.ts` and declare the corresponding stable API surface in the extension API types.
