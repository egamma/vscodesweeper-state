# Issue #225179 — Python: Improved Bracket Pair Detection for strings that contain `{{` 

[https://github.com/microsoft/vscode/issues/225179](https://github.com/microsoft/vscode/issues/225179)

## Summary

Keep this accepted Backlog request open: Python's bundled grammar still lacks bracket exclusions for escaped f-string braces, and disabling bracket pair colorization is only a workaround. No verified fixing commit or older open canonical was found.

## Change summary

Display escaped Python f-string braces as escape characters without disabling bracket pair colorization for actual expressions and dictionaries.

## Best solution

Make Python's bundled tokenization distinguish literal escaped braces from interpolation and dictionary delimiters, preserving normal bracket coloring in executable expressions. Investigate the existing grammar metadata boundary before changing the shared bracket engine.
