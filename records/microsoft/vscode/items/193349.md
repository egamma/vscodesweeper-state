# Issue #193349 — Bug: Links resolved incorrectly after editing - timing issue

[https://github.com/microsoft/vscode/issues/193349](https://github.com/microsoft/vscode/issues/193349)

## Summary

Keep open: current source still allows clicks to use a previously detected URL while asynchronous detection catches up after editing. The existing feature-request classification fits the maintainer's explanation; no verified canonical owns this exact timing behavior.

## Change summary

Make following an edited editor link use its current target rather than the previous target during the detection delay.

## Best solution

Improve link activation freshness in the editor link contribution while preserving asynchronous detection and its performance safeguards. Waiting for detection is a workaround, not coverage of the immediate-click request.
