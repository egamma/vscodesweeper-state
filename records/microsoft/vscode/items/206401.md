# Issue #206401 — Consider to move `NotebookContribution` off blocking startup

[https://github.com/microsoft/vscode/issues/206401](https://github.com/microsoft/vscode/issues/206401)

## Summary

Still open on current main — NotebookContribution remains registered with WorkbenchPhase.BlockStartup (line 895 of notebook.contribution.ts). The requested optimization has not been implemented.

## Change summary

Move NotebookContribution off WorkbenchPhase.BlockStartup to reduce startup blocking work.

## Best solution

Evaluate whether NotebookContribution can use a deferred phase (e.g. AfterRestored or EditorRegistered) instead of BlockStartup; its constructor only sets up an undo/redo comparison key and a comment decoration, neither of which is obviously startup-critical.
