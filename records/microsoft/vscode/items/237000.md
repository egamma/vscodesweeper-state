# Issue #237000 — Inline completions with multi cursor

[https://github.com/microsoft/vscode/issues/237000](https://github.com/microsoft/vscode/issues/237000)

## Summary

Keep this accepted feature request open: providers still receive only the primary cursor position, and secondary suggestions reuse its completion. The request has 23 upvotes, already passed community review, and no older same-symptom canonical was verified.

## Change summary

Expose all cursor positions to inline completion providers so they can account for each cursor's context.

## Best solution

Define a request-scoped multi-cursor provider contract in the editor and extension API. Distinguish exposing cursor context from supporting independently generated completions at each cursor, while preserving existing providers' behavior.
