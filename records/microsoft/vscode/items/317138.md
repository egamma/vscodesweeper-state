# Issue #317138 — Integrated browser element attachment opened untitled, dirty text file

[https://github.com/microsoft/vscode/issues/317138](https://github.com/microsoft/vscode/issues/317138)

## Summary

The requested polish remains necessary: clicking an element attachment still creates a populated untitled editor, which becomes dirty. A maintainer explicitly consolidated the later duplicate into this issue, so this remains the appropriate tracking item.

## Change summary

Open integrated-browser element attachments in a meaningfully titled, read-only editor that closes without a save prompt.

## Best solution

Element attachments should behave as inspectable artifacts rather than new editable documents: show their contents in a named, read-only editor without introducing unsaved work. Keep screenshot previews and attachment contents unchanged.
