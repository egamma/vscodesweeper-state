# Issue #314121 — Copilot subagent model-selection blocked when reviewer model cost tier exceeds parent session (Claude Opus 4.7 vs GPT-5.5)

[https://github.com/microsoft/vscode/issues/314121](https://github.com/microsoft/vscode/issues/314121)

## Summary

The reported cost-tier ceiling is intentional: maintainers have explicitly confirmed that a subagent cannot use a model more expensive than its parent model. Model-picker visibility indicates general availability, not eligibility for every subagent invocation.

## Change summary

Clarify whether a lower-cost parent session may invoke a higher-cost reviewer subagent and how model-picker availability relates to that restriction.

## Best solution

Keep the parent-tier guardrail and clarify in the subagent documentation that explicit model selection remains bounded by the parent model's multiplier. Users who need Claude Opus 4.7 for review should select an equal- or higher-tier parent model or use Opus as the primary model.
