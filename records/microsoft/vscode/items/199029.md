# Issue #199029 — Don't hide useful information from the suggestions list

[https://github.com/microsoft/vscode/issues/199029](https://github.com/microsoft/vscode/issues/199029)

## Summary

The information-loss gap remains on current main, and this accepted Backlog request is already routed to the appropriate UX and suggestions areas.

## Change summary

Preserve the distinguishing portion of completion-item details when the suggestions list is too narrow, potentially through suffix-aware truncation or an adaptive two-line layout.

## Best solution

Update the suggestion-row layout in `suggestWidgetRenderer.ts` and `suggest.css` to retain useful distinguishing detail under constrained widths, preferably through adaptive layout rather than another permanent configuration option.
