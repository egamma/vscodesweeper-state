# Issue #199029 — Don't hide useful information from the suggestions list

[https://github.com/microsoft/vscode/issues/199029](https://github.com/microsoft/vscode/issues/199029)

## Summary

Keep this accepted Backlog request open: current suggestion rows still truncate trailing information, and existing controls do not preserve distinguishing paths at a constrained width. A maintainer should choose the overflow presentation before implementation.

## Change summary

Preserve distinguishing names and path suffixes in narrow suggestion lists, potentially through leading truncation or a two-line layout.

## Best solution

Make similar completions distinguishable without requiring a substantially wider suggestion widget. Decide how names and descriptions share constrained space while retaining a consistent, scannable list.

- **Trace:**
