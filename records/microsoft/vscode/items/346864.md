## Summary

The tracked-file discard path still passes filenames as Git pathspecs, allowing a single-file discard to overwrite unrelated tracked edits. Keep this open while the linked fix PR is reviewed.

## Change summary

Discarding tracked '[target]' also discards edits in the unselected tracked file 't'.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/346865 so path-based checkout treats selected filenames literally while preserving branch checkout behavior.
