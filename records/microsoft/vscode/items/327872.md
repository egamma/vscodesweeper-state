# Issue #327872 — Enable some AI models for some users

[https://github.com/microsoft/vscode/issues/327872](https://github.com/microsoft/vscode/issues/327872)

## Summary

This is a valid, currently unsupported Copilot Business model-management request. It should remain open and be routed to language-model management because current VS Code consumes organization-managed model availability but provides no per-user administrative policy surface.

## Change summary

Allow Copilot Business administrators to enable selected premium AI models for only specific users or teams rather than the entire organization.

## Best solution

Provide organization administrators with user- or team-scoped model allowlists, and have each authenticated user's model metadata reflect the effective policy so VS Code exposes only the models assigned to that user.
