# Issue #327872 — Enable some AI models for some users

[https://github.com/microsoft/vscode/issues/327872](https://github.com/microsoft/vscode/issues/327872)

## Summary

This asks for per-user (rather than org-wide) enablement of specific Copilot models, which is an organization admin/policy control that lives in GitHub's Copilot Business admin console on github.com, not in VS Code client code — there is no VS Code setting or extension hook that could implement seat-level model policy.

## Change summary

Allow enabling specific AI models (e.g. Fable 5, GPT 5.6 Sol) for only a subset of users in a Copilot Business org, rather than org-wide.

## Best solution

This belongs to GitHub's Copilot Business/Enterprise admin policy settings (the org's Copilot policies page on github.com), not the VS Code client — the model list VS Code shows is already driven entirely by server-side org policy, so no client-side change could add per-user granularity.
