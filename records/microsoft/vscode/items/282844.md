# Issue #282844 — Report Issue dialog: Confirm Version Acknowledgement doesn't work

[https://github.com/microsoft/vscode/issues/282844](https://github.com/microsoft/vscode/issues/282844)

## Summary

Still present on current main: when an update is available, the classic issue reporter shows a disabled "Confirm Version Acknowledgement" button with no click handler (line 309 of baseIssueReporterService.ts). The user must check a separate acknowledgement checkbox to proceed, but the button's label misleads users into clicking it directly. The new wizard reporter (behind `issueReporter.wizard.enabled`) sidesteps this by not using the acknowledgement checkbox flow at all.

## Change summary

The "Confirm Version Acknowledgement" button in the classic Report Issue dialog is disabled with no click handler, so clicking it does nothing — users get stuck.

## Best solution

Either make the "Confirm Version Acknowledgement" button enabled with a click handler that sets `this.acknowledged = true` and calls `updateButtonStates()`, or clarify the UX so users understand they must check the acknowledgement checkbox first. Alternatively, if the new wizard reporter is expected to fully replace the classic flow, this may become moot — but the classic path is still the default.
