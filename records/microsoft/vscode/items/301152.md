# Issue #301152 — Add `model` field to Copilot agent hook inputs

[https://github.com/microsoft/vscode/issues/301152](https://github.com/microsoft/vscode/issues/301152)

## Summary

Valid, unimplemented feature request: the `model` field is still absent from hook inputs on current main. A team member has engaged, a duplicate (#318555) was closed into this issue, and it has 6 upvotes — it should stay open as the canonical tracker.

## Change summary

Add the active model name/slug to the common input payload sent to all Copilot agent hook events.

## Best solution

Add a `model` property to the `commonInput` object built in `extensions/copilot/src/extension/chat/vscode-node/chatHookService.ts` (around line 126) so every hook invocation receives the active model identifier. The model is available from the chat request or language-model session context. This brings VS Code hooks to parity with Claude Code hooks and unblocks policy/compliance extensions.
