# Issue #169362 — Order of "Recently opened" and "File (and symbol) results" should be reversed by default and/or configurable

[https://github.com/microsoft/vscode/issues/169362](https://github.com/microsoft/vscode/issues/169362)

## Summary

The requested workspace-first Quick Open ordering remains unavailable, but the open ranking issue explicitly covers workspace priority and history precedence. Consolidate there as a duplicate, preserving the requirement to retain access to recently opened files.

## Change summary

Prioritize current-workspace file and symbol results over recently opened files, by default or through configuration, without disabling history.

## Best solution

Track workspace-first ordering with history retained in https://github.com/microsoft/vscode/issues/27317, whose existing scope and discussion cover this behavior and its ranking tradeoffs.
