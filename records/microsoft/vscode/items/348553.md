# Issue #348553 — Always on Top is lost if the window is minimized when VS Code quits

[https://github.com/microsoft/vscode/issues/348553](https://github.com/microsoft/vscode/issues/348553)

## Summary

Keep open: current source persists Electron's transient minimized-window state instead of the user's Always on Top preference. The report supplies concrete macOS reproduction steps and identifies both main and detached windows as affected.

## Change summary

Preserve each window's Always on Top preference across quitting while minimized and restoring the session.

## Best solution

Persist the intended per-window Always on Top state independently of temporary native changes during minimization, covering both main and detached windows without changing explicit toggle behavior.
