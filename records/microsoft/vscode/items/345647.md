# Issue #345647 — Can we have an option to turn off all AI features?

[https://github.com/microsoft/vscode/issues/345647](https://github.com/microsoft/vscode/issues/345647)

## Summary

The built-in AI opt-out already exists, but release-note presentation does not honor it. Keep the remaining request open for a decision on whether disabling AI should also suppress AI-related release-note content.

## Change summary

Provide an AI opt-out that also avoids AI-related release notes.

## Best solution

Reuse chat.disableAIFeatures rather than introduce another general AI switch, and decide how release notes should respect that preference. Disabling every release note is an available workaround, not an AI-specific preference.
