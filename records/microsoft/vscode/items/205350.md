# Issue #205350 — Git - Warn Unsaved Files Before Typing Commit Message

[https://github.com/microsoft/vscode/issues/205350](https://github.com/microsoft/vscode/issues/205350)

## Summary

The reported need to retype the commit message warrants investigation, but the report does not identify the message-entry surface or the warning action that loses it. Current source preserves an existing Source Control message through the save prompt and checks dirty files before opening a separate message input.

## Change summary

Warn about unsaved files before commit-message entry so handling the warning does not require retyping the message.

## Best solution

Preserve the drafted commit message when saving files or cancelling the unsaved-files warning. Establish the affected commit-entry workflow before deciding whether an earlier warning is also needed in the Git or Source Control UI.
