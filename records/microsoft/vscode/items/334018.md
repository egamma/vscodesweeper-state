# Issue #334018 — Creating a search function in chat sessions

[https://github.com/microsoft/vscode/issues/334018](https://github.com/microsoft/vscode/issues/334018)

## Summary

VS Code already ships a Find-in-Chat feature (Ctrl+F while focused in a chat session, or the 'Find in Chat' command) that lets users search for words/concepts across the conversation, which appears to cover this request.

## Change summary

Requests a way to search for previously mentioned words or concepts within a chat/agent session's conversation history.

## Best solution

Point the reporter to the existing 'Find in Chat' command (Ctrl+F when focused in a chat session), registered in src/vs/workbench/contrib/chat/browser/actions/chatFindActions.ts — this already provides in-conversation search with next/previous, regex, whole-word, and case-sensitive options.

## Evidence

- **existing feature:** src/vs/workbench/contrib/chat/browser/actions/chatFindActions.ts registers ChatFindCommandId.Find ('workbench.action.chat.find', title 'Find in Chat') with f1:true and a Ctrl+F keybinding when ChatContextKeys.inChatSession is true and no editor is focused.
- **find widget implementation:** src/vs/workbench/contrib/chat/browser/widget/chatFind/chatFindWidget.ts implements a SimpleFindWidget-based ChatFindWidget with next/previous match, regex, whole-word, and case-sensitive toggles, plus chatFindModel.ts and chatFindHighlights.ts for highlighting matches across the conversation.
