# Issue #108264 — Add support for vertical tabs

[https://github.com/microsoft/vscode/issues/108264](https://github.com/microsoft/vscode/issues/108264)

## Summary

Keep this accepted Backlog request open. Current main still supports only horizontal editor tabs, and the movable Open Editors view remains a partial workaround rather than per-group vertical tabs.

## Change summary

Add configurable vertical editor tabs on the left or right of each editor group.

## Best solution

Add a supported editor-tab orientation setting and adapt the editor-group title layout, tab scrolling, actions, drag-and-drop, and breadcrumbs for left/right placement. Preserve per-editor-group ordering and pinning rather than substituting the global Open Editors view.
