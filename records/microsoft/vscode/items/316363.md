[https://github.com/microsoft/vscode/issues/316363](https://github.com/microsoft/vscode/issues/316363)

## Summary

Keep this as the canonical Hindi display-language request: a maintainer has consolidated four other reports here, and the supported localization inventory still lacks Hindi. The related contribution was closed without merging, so it does not complete the request.

## Change summary

Provide a Hindi language pack so users can use VS Code's interface in Hindi.

## Best solution

Retain this issue for a localization-owner decision on Hindi support, translation maintenance, and language-pack publication through the established localization pipeline. The existing display-language infrastructure can consume language packs, but it does not supply the missing Hindi translations.

## Evidence

- **Existing capability and remaining gap:** src/vs/workbench/contrib/localization/common/localizationsActions.ts registers workbench.action.configureLocale. LanguagePackBaseService.getAvailableLanguages() in src/vs/platform/languagePacks/common/languagePacks.ts discovers Marketplace language-pack extensions; this infrastructure enables selecting a published pack, not generating Hindi translations.
- **Supported language inventory:** build/lib/i18n.ts lists defaultLanguages and extraLanguages, neither containing Hindi. https://github.com/microsoft/vscode-loc/tree/main/i18n likewise has no Hindi pack, and https://github.com/microsoft/vscode-loc/blob/main/README.md lists supported languages without Hindi. This establishes the official-pack gap, not the absence of every third-party Marketplace offering.
- **Maintainer-selected canonical:** A maintainer explicitly marked four reports as duplicates of this issue: https://github.com/microsoft/vscode/issues/317547#issuecomment-4940276527, https://github.com/microsoft/vscode/issues/316872#issuecomment-4940276535, https://github.com/microsoft/vscode/issues/320751#issuecomment-4940276537, and https://github.com/microsoft/vscode/issues/318216#issuecomment-4940276533. All four are closed; the open-issue search for Hindi language returned this issue.
- **Contribution did not land:** https://github.com/microsoft/vscode/pull/316885 references this request but is closed with mergedAt null. Its description acknowledges incomplete translation coverage, and https://github.com/microsoft/vscode/pull/316885#issuecomment-5388260349 rejects adding generated scaffolding at the repository root, not Hindi support itself.
- **Localization ownership:** https://github.com/microsoft/vscode-loc/blob/main/README.md states that translation strings are managed on the Microsoft Localization Platform and exported for language-pack publication; translation-string pull requests are not accepted. Supporting Hindi therefore needs localization coordination rather than an isolated patch to the locale picker.
