# Issue #330366 — Option to not keep inactive tabs in memory

[https://github.com/microsoft/vscode/issues/330366](https://github.com/microsoft/vscode/issues/330366)

## Summary

This remains a valid Backlog Candidates feature request within its 60-day voting period. Current VS Code can limit open editors only by closing least-recently-used tabs; it cannot preserve those tabs as unloaded placeholders.

## Change summary

Add an optional LRU-style policy that releases resources held by inactive editors while preserving their tabs, view state, and safe restoration behavior.

## Best solution

Provide an opt-in inactive-editor suspension model for clean editors that preserves tab identity and view state while releasing reloadable resources; dirty contents and undo history must remain safe. The design should distinguish editor-model memory from window-level extension and renderer processes.
