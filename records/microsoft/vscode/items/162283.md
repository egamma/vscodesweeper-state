# Issue #162283 — Search decoration "badge" term ambiguous 

[https://github.com/microsoft/vscode/issues/162283](https://github.com/microsoft/vscode/issues/162283)

## Summary

The ambiguity remains: the current search setting still says only “use badges,” while search results contain both file decorations and a separate match-count badge. Keep this accepted Backlog polish open; no verified canonical or completed clarification was found.

## Change summary

Clarify that the search badge setting controls file-status decorations rather than search-result counts.

## Best solution

Make the search setting's description distinguish file-decoration badges, such as added/modified/deleted indicators, from match counts. Preserve the existing setting identifier and behavior rather than requiring a configuration migration for this wording improvement.
