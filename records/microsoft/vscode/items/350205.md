# Issue #350205 — Agents window: agent feedback of deleted non-agent-host sessions is never released from memory

[https://github.com/microsoft/vscode/issues/350205](https://github.com/microsoft/vscode/issues/350205)

## Summary

The deleted-session feedback leak remains in current source. Keep this issue open while the explicitly linked fixing PR is reviewed and merged.

## Change summary

Deleting a non-agent-host session leaves its feedback objects retained and eligible for fallback session lookup.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/350232 so deleted sessions release their in-memory feedback and notify listeners without disturbing annotations-backed cleanup.
