# Issue #235883 — tab is not aligned for 2 bytes languages like Korean, Chinese, Japanese

[https://github.com/microsoft/vscode/issues/235883](https://github.com/microsoft/vscode/issues/235883)

## Summary

The requested CJK tab alignment is now supported through editor.fullwidthCharacterWidth set to twoCells. Propose closing as completed while retaining font-defined widths as the default.

## Change summary

Align text following tabs when preceding Korean, Chinese, or Japanese characters have font widths that differ from two monospace cells.

## Best solution

Use editor.fullwidthCharacterWidth: "twoCells", implemented in commit 70a1d06d93f6a90d3cae4bf84754b096d818ef40, to align CJK characters and subsequent tab stops on the monospace grid without changing the default rendering.
