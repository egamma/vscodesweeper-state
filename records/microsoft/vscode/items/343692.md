# Issue #343692 — Copilot Chat model selection icons are confusing and inconsistent

[https://github.com/microsoft/vscode/issues/343692](https://github.com/microsoft/vscode/issues/343692)

## Summary

Keep open for model-picker design triage: current source assigns different meanings to selected-model icons and provider-tab icons, supporting the reported confusion. No verified fix or canonical duplicate establishes that this request is already covered.

## Change summary

Make selected-model iconography consistently distinguish Copilot-hosted models from BYOK models across chat harnesses.

## Best solution

Agree on a consistent visual contract for model identity versus hosting-provider identity across the selected-model chip and provider tabs. Users should be able to distinguish identically named Copilot and BYOK models without inferring their route from inconsistent glyphs.
