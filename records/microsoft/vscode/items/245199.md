# Issue #245199 — Settings editor: allow a query that combines `id` and `tag`

[https://github.com/microsoft/vscode/issues/245199](https://github.com/microsoft/vscode/issues/245199)

## Summary

Keep open: Settings already accepts mixed ID/tag queries, but applies intersection semantics, which does not deliver the apparent goal of showing the named setting alongside all next-edit-suggestion settings. No verified canonical or fixing commit establishes that this request is complete.

## Change summary

Allow a Settings search to combine an explicitly named setting with settings selected by a tag.

## Best solution

Establish whether the intended result is the union of the ID and tag matches, then define an explicit way to express that in Settings search without unexpectedly changing existing intersection queries.
