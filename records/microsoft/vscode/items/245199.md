# Issue #245199 — Settings editor: allow a query that combines `id` and `tag`

[https://github.com/microsoft/vscode/issues/245199](https://github.com/microsoft/vscode/issues/245199)

## Summary

Valid feature request — the settings editor currently ANDs all filter types together, so `@id:X @tag:Y` only shows settings matching both. The user wants OR semantics to see the id-matched setting alongside tag-matched settings.

## Change summary

Allow combining `@id:` and `@tag:` filters in the settings editor with OR semantics so both matching sets appear.

## Best solution

Change the filter composition in `settingsTreeModels.ts` (around line 1137) so that when both `idFilters` and `tagFilters` are populated, a setting passes if it matches either filter (OR), rather than requiring both (AND). The tricky part is preserving AND behavior for other combinations (e.g. tag+scope) while enabling OR for id+tag.
