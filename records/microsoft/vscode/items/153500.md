# Issue #153500 — Git - Should focus return to the SCM view after closing COMMIT_EDITMSG?

[https://github.com/microsoft/vscode/issues/153500](https://github.com/microsoft/vscode/issues/153500)

## Summary

Keep this accepted SCM keyboard-workflow improvement open: the commit editor still has no explicit return-focus behavior. Related terminal and SCM-navigation issues do not cover the same observable request.

## Change summary

Return focus to the SCM commit input after saving and closing COMMIT_EDITMSG so Publish Branch remains easily reachable by keyboard.

## Best solution

Provide predictable focus restoration for commits initiated from SCM, with the destination and focus-stealing policy agreed by the maintainer. Preserve terminal-initiated commits and unrelated editor-close behavior.
