# Issue #316162 — [Agents App] Users assume they must merge to main to preview/test worktree changes

[https://github.com/microsoft/vscode/issues/316162](https://github.com/microsoft/vscode/issues/316162)

## Summary

Keep open: current main supports running tasks in the session's worktree, but the Run action and isolation onboarding do not explicitly explain that previewing and testing require no merge. The study identifies a discoverability gap rather than a missing execution capability.

## Change summary

Make testing and previewing isolated worktree changes discoverable, and explain that merging into main is unnecessary.

## Best solution

Make the existing session-aware Run workflow clearly communicate where preview/test commands execute, with onboarding that distinguishes worktree isolation from branch switching. Build on the existing task runners rather than introduce a separate execution system.
