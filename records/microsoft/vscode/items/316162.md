# Issue #316162 — [Agents App] Users assume they must merge to main to preview/test worktree changes

[https://github.com/microsoft/vscode/issues/316162](https://github.com/microsoft/vscode/issues/316162)

## Summary

Valid UX feature request for the Agents window: users with branch-based mental models don't realize they can preview/test changes directly in the worktree without merging to main. No existing 'Preview in Worktree' action or onboarding education was found in current main. Routing to agents-window for triage.

## Change summary

Users assume they must merge agent worktree changes into main before they can preview or test them, breaking worktree isolation.

## Best solution

Add a discoverable 'Preview/Test in Worktree' action in the Agents window session UI, and include onboarding guidance (e.g. in the new-session tour at `src/vs/sessions/contrib/onboardingTours/`) explaining that the worktree is a fully functional, isolated copy they can run and test directly. The worktree-created task dispatcher (`src/vs/sessions/contrib/chat/browser/worktreeCreatedTaskDispatcher.ts`) already runs setup tasks on worktree creation — a preview action could build on similar infrastructure.
