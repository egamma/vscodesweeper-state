# Issue #226095 — Transparent image grid isn't intuitive

[https://github.com/microsoft/vscode/issues/226095](https://github.com/microsoft/vscode/issues/226095)

## Summary

Still reproduces on main: the transparency checkerboard background is applied directly to the `img` element that also receives `style.zoom`, so the grid scales with zoom. The original fix (PR #226505) was reverted due to regressions, and no replacement has landed.

## Change summary

The image preview transparency checkerboard grid scales with zoom, making small transparent images look like they have dark squares.

## Best solution

Move the checkerboard background to a separate wrapper div that doesn't receive the zoom transform, avoiding the regressions that caused the first attempt (PR #226505) to be reverted. The fix lives in `extensions/media-preview/media/imagePreview.css` and `imagePreview.js`.
