# Issue #338338 — If not signed in to dev tunnels already the "connect" command doesn't properly sign in

[https://github.com/microsoft/vscode/issues/338338](https://github.com/microsoft/vscode/issues/338338)

## Summary

Team-authored bug (alexr00) with a corroborating, detailed repro from another maintainer (alloy): connecting to a dev tunnel host when not yet signed in either hangs the sign-in progress notification indefinitely, or (from the host list) silently fails without prompting for sign-in at all, requiring a manual Command Palette run (sometimes twice). No fix has landed on main yet, so this stays open.

## Change summary

Running 'Connect to Remote Agent Host via Dev Tunnel' (or selecting a known tunnel host from the Agents list) while not signed in to dev tunnels doesn't properly complete sign-in — the progress spinner hangs, or the connect silently fails.

## Best solution

Make dev-tunnel sign-in reliable and consistent across both entry points: the explicit 'Connect via Dev Tunnel' command (promptToConnectViaTunnel in remoteAgentHostActions.ts, which already calls authenticationService.createSession) and selecting a known host directly from the Agents host list, which per alloy's comment appears to bypass that sign-in step entirely and fail without a usable prompt.
