# Issue #275029 — Terminal Completion: `commandLine` context sometimes includes the shell indicator and the working directory

[https://github.com/microsoft/vscode/issues/275029](https://github.com/microsoft/vscode/issues/275029)

## Summary

Keep open: the report identifies incorrect completion-provider context after resizing a PowerShell terminal, and no verified fix or qualifying canonical was found. This team-authored issue is protected from an uncertainty-based close; current reproduction still needs confirmation.

## Change summary

Resizing a PowerShell terminal can cause completion context.commandLine to include the shell prompt and working directory instead of only the command input.

## Best solution

Ensure terminal completion providers receive command input and its corresponding cursor index without prompt contamination across PowerShell terminal resizes. First capture the failing resize/repaint sequence and determine whether the command-start marker or column becomes incorrect in the prompt-input model.
