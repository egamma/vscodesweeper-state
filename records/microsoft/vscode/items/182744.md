# Issue #182744 — Undo/Redo <input /> is not working in vscode.CustomTextEditorProvider

[https://github.com/microsoft/vscode/issues/182744](https://github.com/microsoft/vscode/issues/182744)

## Summary

Keep open: current source still routes undo/redo to the custom editor's document before the focused webview input can handle it. The related report is newer and describes a different focus location, so it does not qualify as a duplicate canonical for this re-reviewed issue.

## Change summary

Undo/redo in a custom text editor's HTML input changes the backing document instead of the input's text.

## Best solution

Make undo/redo honor the focused HTML input's editing history while preserving custom-document undo/redo outside native text-editing controls. Cover both the original custom-editor input case and the related webview-view focus case.
