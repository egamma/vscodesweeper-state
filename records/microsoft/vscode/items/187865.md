# Issue #187865 — Notebook -- can't search rendered markdown in Firefox

[https://github.com/microsoft/vscode/issues/187865](https://github.com/microsoft/vscode/issues/187865)

## Summary

Still reproduces on main: the notebook find relies on `window.find()` traversing into Shadow DOMs where markdown previews are rendered, which Firefox does not support. No fix has landed.

## Change summary

Notebook find cannot locate matches in rendered markdown cells when using Firefox (vscode.dev).

## Best solution

Implement a Firefox-specific fallback for notebook find in rendered markdown — either walk the Shadow DOM text nodes manually or use the TreeWalker API to search shadow roots when `window.find()` fails to enter them. The fix would live in `src/vs/workbench/contrib/notebook/browser/view/renderers/webviewPreloads.ts` around the find function (line ~1442). Alternatively, classify as `upstream` if the team prefers to wait for Firefox to ship full Shadow DOM `window.find()` support.
