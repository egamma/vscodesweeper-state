# Issue #301701 — Searching for a commit (going from git blame to source control graph)

[https://github.com/microsoft/vscode/issues/301701](https://github.com/microsoft/vscode/issues/301701)

## Summary

A real SCM navigation gap remains: blame can open commit details, but cannot reveal that commit in the Source Control Graph. Route this feature request to the SCM area.

## Change summary

Allow users to search for or reveal a specific commit hash in the Source Control Graph from blame information or terminal links.

## Best solution

Add a graph command that accepts a repository and commit hash, loads the necessary history page, and reveals the matching item. Expose it from Git Blame and eventually terminal commit links.
