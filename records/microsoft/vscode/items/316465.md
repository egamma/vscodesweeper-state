# Issue #316465 — Agent window: when starting a new session via worktree+branch, the remote branch is used, not the local branch

[https://github.com/microsoft/vscode/issues/316465](https://github.com/microsoft/vscode/issues/316465)

## Summary

Keep open: the Copilot CLI worktree path deliberately substitutes the selected local branch's upstream, so unpushed local commits are still excluded. This needs a product decision about branch-selection semantics, not a stale-report close or consolidation into the newer Git/worktree umbrella.

## Change summary

Allow a local Copilot CLI worktree session to start from the selected local branch, including commits that have not been pushed.

## Best solution

Make the selected starting ref authoritative and understandable: selecting a local branch should preserve its local commits, while a remote-tracking starting point should be an explicit choice. Coordinate that contract with the related request for remote-tracking branch selection.
