# Issue #349402 — Agents window: allow customizing the layout, so chat can go on the right and the editor on the left

[https://github.com/microsoft/vscode/issues/349402](https://github.com/microsoft/vscode/issues/349402)

## Summary

Keep open: current Agents layout controls do not support placing the editor to the left of chat. Related sidebar-customization work does not cover this central request.

## Change summary

Allow swapping chat and editor positions in the Agents window and remember the chosen arrangement across restarts.

## Best solution

Provide a persistent desktop Agents layout choice for editor-left/chat-right while preserving the existing default and Editor/Details composition. Decide optional sidebar rearrangement separately from this central capability.
