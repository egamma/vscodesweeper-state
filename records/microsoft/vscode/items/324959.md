# Issue #324959 — Copilot Chat: All previous session history silently lost after upgrade (.json → .jsonl format migration not performed)

[https://github.com/microsoft/vscode/issues/324959](https://github.com/microsoft/vscode/issues/324959)

## Summary

The report remains necessary: multiple users confirm that persisted chat sessions become inaccessible after upgrade or workspace-identity changes, and one recovered them by rebuilding the session cache. The evidence points to a current discovery/index migration defect rather than deleted session files.

## Change summary

Preserve and rediscover existing Copilot Chat sessions when storage moves from legacy chat-session files to the agent-session cache and when a workspace receives a different storage identity.

## Best solution

Make chat session discovery reconcile legacy `chatSessions` data and orphaned workspace-storage buckets into the current session index without duplicating sessions, and provide a supported recovery path for already-unindexed histories.
