# Issue #81757 — API to toggle between flat tree (list) and tree for custom view

[https://github.com/microsoft/vscode/issues/81757](https://github.com/microsoft/vscode/issues/81757)

## Summary

This API feature request — allowing extensions to toggle between flat list and hierarchical tree rendering in custom tree views — remains unimplemented on current main. The TreeView API has no viewMode or flat-tree toggle surface. Team-authored and in Backlog; keeping open.

## Change summary

Expose an API for extensions to programmatically toggle between flat (list) and hierarchical (tree) rendering in custom tree views.

## Best solution

Add a `viewMode` property (or similar) to the `TreeView` API surface that lets extensions switch between flat list and tree rendering, similar to what built-in views like SCM history and debug already do internally. The implementation would likely touch `src/vs/workbench/api/common/extHostTreeViews.ts`, `src/vs/workbench/common/views.ts`, and the `TreeView` type in `src/vscode-dts/vscode.d.ts`.
