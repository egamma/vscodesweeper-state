[https://github.com/microsoft/vscode/issues/281007](https://github.com/microsoft/vscode/issues/281007)

## Summary

Current main explicitly replaces stale model names with a neutral “Models” label when sign-in is required, but this team-authored issue cannot be closed as implemented without a fixing commit or linked PR that references it. ## Change summary

Signing out leaves the model picker displaying the previously selected model even though that model is no longer available.

## Best solution
