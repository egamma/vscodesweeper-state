# Issue #268528 — Copilot agent fails to execute commands in ssh - impossible to work with remotely accessed shells

[https://github.com/microsoft/vscode/issues/268528](https://github.com/microsoft/vscode/issues/268528)

## Summary

Keep this canonical feature request open: VS Code loses command-boundary tracking inside SSH and other interactive subshells, and the documented workarounds do not provide reliable automatic agent execution.

## Change summary

Enable Copilot agents to execute and monitor commands reliably inside SSH, interactive containers, and similar subshells.

## Best solution

Teach terminal shell integration and the chat terminal tool to recognize subshell transitions and preserve or re-establish command tracking, with a reliable fallback when integration cannot be installed remotely.
