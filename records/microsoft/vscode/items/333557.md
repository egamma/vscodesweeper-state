# Issue #333557 — Using AI assisted customizations leads to unexpectedly high costs due to chat send

[https://github.com/microsoft/vscode/issues/333557](https://github.com/microsoft/vscode/issues/333557)

## Summary

Keep open: this team-authored test-plan follow-up records two concrete defects in AI-assisted customization—the selected chat model can create unexpectedly high cost without adequate disclosure, and the chat surface remains open without visible progress. The explicit `Testing #333535` context and confirmed run make this actionable rather than an info-needed case.

## Change summary

AI-assisted customization silently uses the current chat model and leaves an apparently idle chat window open while a long, costly request runs.

## Best solution

Make the customization flow clearly disclose or deliberately choose the model before sending, and show an unambiguous in-progress state in the originating chat surface until the request completes or is cancelled.
