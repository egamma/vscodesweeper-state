# Issue #333557 — Using AI assisted customizations leads to unexpectedly high costs due to chat send

[https://github.com/microsoft/vscode/issues/333557](https://github.com/microsoft/vscode/issues/333557)

## Summary

Fresh, team-authored bug report describing two distinct UX problems in the AI Customizer chat-send flow: the model picker silently defaults to an expensive model (Opus) without confirmation, and the chat UI leaves no visible progress indicator so users don't realize a costly request is in flight. No fix exists yet on main; routing to the AI customizations area owners.

## Change summary

Sending AI-assisted customizations to a model can silently use an expensive model and shows no progress in the UI while running, leading to surprise cost (77 cents, 2+ minutes) for the user.

## Best solution

Owners of the aiCustomization surface (src/vs/workbench/contrib/chat/browser/aiCustomization/) should add a visible cost/model confirmation before dispatch and surface in-progress state in the customizer UI rather than leaving the chat panel silently running.
