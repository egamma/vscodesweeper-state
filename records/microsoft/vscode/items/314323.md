# Issue #314323 — Confusing UI descriptions for `bypass approvals` vs `autopilot`

[https://github.com/microsoft/vscode/issues/314323](https://github.com/microsoft/vscode/issues/314323)

## Summary

Keep open: the current picker distinguishes automatic tool approval from autonomy, but still describes Autopilot as continuing until the task is done without explaining the concrete difference the reporter asked about. The maintainer discussion supports clarifying that distinction, and no qualifying fix or older same-symptom canonical issue was established.

## Change summary

Clarify how Autopilot differs from bypassing tool approvals and from asking a normal agent to complete a task.

## Best solution
