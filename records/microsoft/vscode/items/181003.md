[https://github.com/microsoft/vscode/issues/181003](https://github.com/microsoft/vscode/issues/181003)

## Summary

The requested full-width, selected-line comparison remains distinct from the merge editor's existing base pane and diff highlighting. Keep this accepted Backlog request open; no verified older canonical owns the same capability.

## Change summary

Add a compact comparison above the merge result showing corresponding base, current, and incoming lines at full width with changed portions highlighted.

## Best solution

An optional selected-line comparison within the merge editor would make long conflicting lines easier to inspect without changing merge resolution semantics. A maintainer should decide whether this additional surface warrants inclusion before implementation.
