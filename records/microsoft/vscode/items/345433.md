# Issue #345433 — Move Update and Agents buttons out of the title bar by default

[https://github.com/microsoft/vscode/issues/345433](https://github.com/microsoft/vscode/issues/345433)

## Summary

Keep open as a request to change default placement. Existing settings let users hide both title-bar buttons, but do not deliver the requested defaults or an Agents shortcut above Manage.

## Change summary

Hide Update and Open in Agents from the title bar by default, retaining updates in Manage and placing a hideable Agents shortcut above Manage.

## Best solution

Have the workbench design owners decide the default placement and discoverability tradeoff for these secondary actions. Preserve explicit visibility preferences and existing update controls; hiding today's buttons is a workaround, not full coverage.
