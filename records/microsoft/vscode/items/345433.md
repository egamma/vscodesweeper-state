# Issue #345433 — Move Update and Agents buttons out of the title bar by default

[https://github.com/microsoft/vscode/issues/345433](https://github.com/microsoft/vscode/issues/345433)

## Summary

Existing settings let users hide both title-bar buttons, but do not deliver the requested defaults or an Agents shortcut above Manage. Keep this open as a UI placement and default-behavior proposal; the related issues do not establish a canonical covering both requests.

## Change summary

Hide Update and Open in Agents from the title bar by default, retain updates in Manage, and provide an optional Agents shortcut above Manage.

## Best solution

Have the workbench owners evaluate the default placement of both actions together, preserving visibility controls and update access through Manage. Existing hide settings are a workaround, not completion of the requested Agents placement or default changes.
