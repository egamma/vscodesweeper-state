# Issue #210637 — Minimap section headers are not shown for regions in HTML and CSS

[https://github.com/microsoft/vscode/issues/210637](https://github.com/microsoft/vscode/issues/210637)

## Summary

Keep this accepted feature request open: current source still cannot extract names from the supplied HTML and CSS region comments. Custom header regexes offer a workaround, but do not provide automatic region support; 47 upvotes and the Backlog milestone support retaining the request.

## Change summary

Show clean minimap section titles for named HTML and CSS comment regions, with related demand for embedded-language regions.

## Best solution

Make built-in region headers recognize HTML and CSS region names without custom regexes or trailing comment delimiters. Plan the embedded-language and multiline scope with the maintainer while preserving existing folding behavior and JavaScript headers.

## Evidence

- **Current source explains the missing titles:** In src/vs/editor/common/services/findSectionHeaders.ts, collectRegionHeaders derives the title exclusively from lineContent.substring(match[0].length). The start expressions in extensions/html/language-configuration.json and extensions/css/language-configuration.json consume the entire supplied opening comment, including Test and its closing delimiter. The remaining substring is empty, so no header is emitted. The CSS expression has a capture group, but this collector does not use it.
- **Existing capability is a workaround:** src/vs/editor/common/config/editorOptions.ts registers editor.minimap.showRegionSectionHeaders and editor.minimap.markSectionHeaderRegex. The latter supports a named label group and multiline matching through collectMarkHeaders, allowing custom patterns to recognize these comments and exclude delimiters.
