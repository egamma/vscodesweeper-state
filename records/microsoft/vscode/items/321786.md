# Issue #321786 — The color of findRangeHighlightBackground should be transparent

[https://github.com/microsoft/vscode/issues/321786](https://github.com/microsoft/vscode/issues/321786)

## Summary

The report is valid on current main: the Dark 2026 theme still assigns an opaque color to `editor.findRangeHighlightBackground`, while the editor color registry documents that this color must not be opaque because it obscures content.

## Change summary

Dark 2026 should use a transparent `findRangeHighlightBackground` so selected text remains visible while searching in a selected range.

## Best solution

Adjust the Dark 2026 theme token for `editor.findRangeHighlightBackground` to an alpha color consistent with the editor color contract and verify the selected-range find overlay no longer hides selections.
