# Issue #287566 — inline chat file previews cover action buttons

[https://github.com/microsoft/vscode/issues/287566](https://github.com/microsoft/vscode/issues/287566)

## Change summary

Inline chat can size a file-content preview so that it partially covers the associated action buttons.

## Best solution

Ensure inline chat reserves space for its status/action row whenever a file preview is rendered or resized, with regression coverage for constrained editor dimensions and asynchronous preview layout.
