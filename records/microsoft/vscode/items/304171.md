# Issue #304171 — Guard the keyring access on macOS

[https://github.com/microsoft/vscode/issues/304171](https://github.com/microsoft/vscode/issues/304171)

## Summary

Keep open for human security review. The Copilot SDK sandbox integration now exposes a macOS Keychain policy, but VS Code does not explicitly configure it, so the requested credential-access hardening is not demonstrably complete.

## Change summary

Prevent sandboxed agent commands on macOS from accessing the user's Keychain by default.

## Best solution

Confirm the Copilot SDK runtime's omitted-policy semantics, then make denial of macOS Keychain access explicit in the Agent Host sandbox configuration while preserving only the narrowly scoped Git and GitHub credential injection paths.
