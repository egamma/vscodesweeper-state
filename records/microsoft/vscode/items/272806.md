# Issue #272806 — Please Fix GitHub Copilot Chat Prompt Recommendations to Support Chinese File Names

[https://github.com/microsoft/vscode/issues/272806](https://github.com/microsoft/vscode/issues/272806)

## Summary

This accepted Backlog bug should remain open: the reporter confirmed on a later Insiders build that a Chinese-named prompt is missing only from the initially opened Chat view and appears after New Chat. No canonical issue or valid post-review fix commit was found, and the previously cited fix was independently refuted.

## Change summary

Prompt-file recommendations whose names contain Chinese characters are omitted when Chat is first opened but appear after starting a new chat.

## Best solution

Make initial Chat empty-state initialization use the same resolved prompt recommendations as a newly created chat, preserving Unicode prompt names and updating when prompt discovery completes.
