# Issue #133136 — Show Running Extensions in a grid

[https://github.com/microsoft/vscode/issues/133136](https://github.com/microsoft/vscode/issues/133136)

## Summary

A real gap remains: current main still presents Running Extensions as fixed-height list rows rather than a grid. The profile-opening workflow has improved independently, but no canonical issue owns the remaining layout request, so this should stay open for design discussion.

## Change summary

Present running-extension status and timing information in a structured grid, with clearer actions and a more direct CPU-profile viewing workflow.

## Best solution

Have the extensions UX owners decide the grid's column hierarchy, responsive behavior, keyboard and screen-reader model, and whether the remaining CPU-profile requests should be separated; if accepted, replace the current row-oriented Running Extensions presentation without changing extension-host profiling semantics.
