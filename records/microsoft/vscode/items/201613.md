# Issue #201613 — Alt Shortcuts Don't Work Properly With Top Activity Bar

[https://github.com/microsoft/vscode/issues/201613](https://github.com/microsoft/vscode/issues/201613)

## Summary

The confirmed bug remains necessary: current main still mounts the compact menu inside the activity bar, so hiding the sidebar can hide its Alt-triggered menu and leave it misplaced when the sidebar returns. Maintainers agreed that the compact menu should live in the title bar for this layout.

## Change summary

With the activity bar at the top and the sidebar hidden, Alt menu shortcuts fail to display the compact application menu and leave it visually corrupted after the sidebar is revealed.

## Best solution

Keep the compact application menu in the title bar when the activity bar uses the top layout, so Alt+F remains available independently of sidebar visibility while other activity-bar layouts retain their existing behavior.
