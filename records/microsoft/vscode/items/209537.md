# Issue #209537 — [Bug]: Incorrect outdentation when several closing braces are found on the same line

[https://github.com/microsoft/vscode/issues/209537](https://github.com/microsoft/vscode/issues/209537)

## Summary

The reported limitation remains in current source: Reindent Lines reduces indentation only once for a line containing multiple closing braces. Keep this team-authored issue open; no verified fix or older duplicate covering the same symptom was found.

## Change summary

Make Reindent Lines account for multiple closing braces on one line instead of retaining excess indentation.

## Best solution

Make reindentation reflect the nesting levels closed by the reported brace sequence while preserving existing language-configuration behavior. The area owner should settle whether this belongs in an additive indentation-rule contract or syntax-aware indentation; the suggested capture-group enum is a proposal, not an accepted design.
