## Summary

Valid feature request from a team member, assigned to anthonykim1 in the Backlog. The terminal chat participant does not yet inject shell/REPL version information into its context — no related fix has landed on main.

## Change summary

The terminal chat participant should include the shell or REPL version (e.g. 'Python 3.12') in its context so Copilot can give more accurate suggestions.

## Best solution

Inject shell type and version metadata into the terminal chat participant's context in `src/vs/workbench/contrib/terminalContrib/chat/browser/terminalChatService.ts` (or the context-building path), so the model knows which shell/REPL and version it is generating suggestions for. This could extend to include recent command history and REPL state as anthonykim1 suggested.
