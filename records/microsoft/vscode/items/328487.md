# Issue #328487 — Improve pre-tool agent hooks to provide more MCP-specific information

[https://github.com/microsoft/vscode/issues/328487](https://github.com/microsoft/vscode/issues/328487)

## Summary

Keep open as a feature request: the current Local harness hook contract still omits structured MCP server identity and connection information. No verified older canonical owns this request; the metadata contract needs a maintainer decision.

## Change summary

Expose sufficient MCP server metadata to pre-tool hooks to identify the server behind an invocation without reverse-engineering its tool name.

## Best solution

Define a supported MCP identity and connection-metadata contract for pre-execution hooks, deciding whether it extends PreToolUse or warrants a separate event. Preserve existing hook inputs and explicitly define which configuration details are exposed.
