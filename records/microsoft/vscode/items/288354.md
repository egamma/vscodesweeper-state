# Issue #288354 — Tool progress update resets loading animation

[https://github.com/microsoft/vscode/issues/288354](https://github.com/microsoft/vscode/issues/288354)

## Summary

The reported loading-spinner reset is no longer present on current main: tool progress rows stopped using a recreated spinning icon, so this can close as completed.

## Change summary

Updating or reconfirming tool progress text repeatedly restarted the row's loading animation, leaving it visibly stuck near its first frames.

## Best solution

Keep the shipped progress treatment from commit 4046533c48ece86fdee0142c600f487ae85fd48b, where active tool rows no longer depend on a spinning icon that restarts whenever progress text is rendered again.
