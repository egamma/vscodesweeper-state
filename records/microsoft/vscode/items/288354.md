# Issue #288354 — Tool progress update resets loading animation

[https://github.com/microsoft/vscode/issues/288354](https://github.com/microsoft/vscode/issues/288354)

## Summary

The defect remains source-reproducible on current main: each executing-tool progress update replaces the loading icon's DOM node, restarting its CSS animation. No older canonical issue or valid post-review fix was found, so this should remain open.

## Change summary

Updating or reconfirming a tool's progress text repeatedly restarts the loading animation, leaving it visibly stuck near its first frames.

## Best solution

Keep the active tool's loading animation continuous while its progress text changes, without changing completed-tool rendering, accessibility announcements, or progress content.
