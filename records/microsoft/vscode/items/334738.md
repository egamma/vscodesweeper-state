# Issue #334738 — Clang should be agnostic about formatting as per the syntax definition.

[https://github.com/microsoft/vscode/issues/334738](https://github.com/microsoft/vscode/issues/334738)

## Summary

The request concerns clang-tidy's diagnostic policy, not VS Code's syntax definition. Both installed providers of C/C++ language tooling are outside the VS Code team's extension roster, so this belongs with the provider supplying the warning.

## Change summary

Stop reporting clang-tidy warnings for syntactically valid C indentation styles.

## Best solution
