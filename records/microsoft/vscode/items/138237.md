# Issue #138237 — Disassembly editor is not getting closed automatically after debug session ended

[https://github.com/microsoft/vscode/issues/138237](https://github.com/microsoft/vscode/issues/138237)

## Summary

Keep open: automatic closure of the Disassembly editor remains unsupported, and this accepted Backlog request reached 20 upvotes. The thread raises a genuine preference-versus-default decision that should be settled before implementation.

## Change summary

Automatically close the Disassembly editor when debugging ends instead of requiring manual closure.

## Best solution

Provide an agreed session-end lifecycle for the Disassembly editor in the debug contribution, accounting for users who want it retained. Decide whether automatic closure is optional or default, while preserving the editor during continuing debug sessions and restarts.
