# Issue #216913 — vscode.dev: better focus for the git password entry field when git pushing from terminal

[https://github.com/microsoft/vscode/issues/216913](https://github.com/microsoft/vscode/issues/216913)

## Summary

Keep open for theme and quick-input design work: the report concerns noticing an already-focused password prompt, not failure to focus it. Maintainers acknowledged the visibility problem; the closely related design issue is newer and cannot replace this re-reviewed report under the duplicate policy.

## Change summary

Make a Git password quick input sufficiently noticeable that a terminal push awaiting credentials does not appear to hang.

## Best solution

Establish consistent visual separation for small credential quick inputs while preserving the restrained appearance of larger pickers. Coordinate the design with https://github.com/microsoft/vscode/issues/237637 and evaluate current themes before choosing stronger elevation styling or an attention cue.
