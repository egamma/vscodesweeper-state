# Issue #160980 — Add version support for published diagnostics

[https://github.com/microsoft/vscode/issues/160980](https://github.com/microsoft/vscode/issues/160980)

## Summary

A real extension API gap remains: VS Code records the current model version when diagnostics are submitted, but extensions cannot provide the version against which diagnostics were computed. The request is already correctly routed and parked in Backlog.

## Change summary

Allow extensions publishing diagnostics to associate them with a document version so stale results can be rejected or adjusted.

## Best solution

Extend the diagnostics API and transport to preserve an extension-supplied document version, then use it to prevent older diagnostic results from replacing newer ones while retaining marker range tracking across edits.
