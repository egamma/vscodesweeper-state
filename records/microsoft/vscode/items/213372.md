# Issue #213372 — Invalid string length

[https://github.com/microsoft/vscode/issues/213372](https://github.com/microsoft/vscode/issues/213372)

## Summary

The oversized-string failure path remains on main, and no fixing commit references this team-authored telemetry issue. Keep it open for text-buffer investigation.

## Change summary

Reloading a very large text model can exceed V8's maximum string length while collecting replaced content for undo.

## Best solution

Avoid materializing the entire replaced range as one JavaScript string during model reload, or explicitly handle models exceeding the heap-operation threshold in `ModelService.updateModel` and the piece-tree edit path.
