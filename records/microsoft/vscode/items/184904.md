# Issue #184904 — [json] Schema changes not reflected if schema file has jsonc extension.

[https://github.com/microsoft/vscode/issues/184904](https://github.com/microsoft/vscode/issues/184904)

## Summary

The defect remains source-reproducible on current main: file-backed schemas are invalidated through a watcher restricted to `**/*.json`, so saved `.jsonc` schema changes do not trigger revalidation. The existing `json` area assignment is correct and the Backlog milestone does not prevent keeping this actionable bug open.

## Change summary

Changes saved to a local JSON Schema with a `.jsonc` extension should immediately refresh diagnostics in documents using that schema, as `.json` schema changes already do.

## Best solution

Include local `.jsonc` schema files in the JSON client's watched-file invalidation path while preserving existing `.json` behavior, and cover both extensions with a regression test.
