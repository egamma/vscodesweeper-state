# Issue #331100 — "Add feedback" and `/act-on-feedback` go overly narrow

[https://github.com/microsoft/vscode/issues/331100](https://github.com/microsoft/vscode/issues/331100)

## Summary

Reasonable UX wording feedback from a contributor: the "Add Feedback"/`/act-on-feedback` naming implies acting on a change request, which doesn't fit a user just asking a question via the same comment UI. Already correctly labeled `polish` + `agents-window`; this is a product/copy decision for the Agents Window team, not something to close or auto-fix.

## Change summary

The reporter wants the "Add Feedback" comment UI and `/act-on-feedback` skill to use more general wording (e.g. "Comment...") since it's also used to ask questions, not just to request changes.

## Best solution

A maintainer decides whether to rename the "Add Feedback" UI string and `/act-on-feedback` skill/command to something more general (e.g. "Comment"); this touches src/vs/sessions/contrib/agentFeedback/browser/agentFeedbackEditorInputContribution.ts (localized strings like `agentFeedback.addFeedback`) and the skill prompt in src/vs/sessions/skills/act-on-feedback/SKILL.md, but the wording/behavior tradeoff (would `/act-on-feedback` still make code changes for genuine feedback?) needs product judgment, not a mechanical fix.
