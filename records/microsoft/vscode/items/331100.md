# Issue #331100 — "Add feedback" and `/act-on-feedback` go overly narrow

[https://github.com/microsoft/vscode/issues/331100](https://github.com/microsoft/vscode/issues/331100)

## Summary

Fresh, reasonable UX-wording suggestion about the 'Add feedback' UI and the /act-on-feedback skill being too narrowly worded for what is really general commenting/Q&A on changes; needs a product/naming decision from the sessions/agents team, not an automatic fix.

## Change summary

Rename 'Add feedback' UI affordance and the /act-on-feedback slash command/skill to more general wording (e.g. 'Comment') since users also use it to ask questions, not just give feedback.

## Best solution

Have the Agents Window / agent-feedback owners decide on wording: note that src/vs/sessions/contrib/agentFeedback/browser/agentFeedbackEditorInputContribution.ts already differentiates 'Add Feedback' vs 'Add Comment' via _getPlaceholder() based on whether there are pending changes, so the fix may just be widening that heuristic or renaming the /act-on-feedback skill (src/vs/sessions/skills/act-on-feedback/SKILL.md) and its triggering copy to match a broader 'comment/ask' framing.
