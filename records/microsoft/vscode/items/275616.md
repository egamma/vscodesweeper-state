# Issue #275616 — Keystrokes for GitHub Copilot "Continue to iterate" prompt Continue/Pause options.

[https://github.com/microsoft/vscode/issues/275616](https://github.com/microsoft/vscode/issues/275616)

## Summary

Still valid on current main. The 'Continue to iterate?' prompt uses `stream.confirmation()` which renders via `ChatConfirmationContentPart` — a separate code path from tool confirmations. Tool confirmations have `Ctrl+Enter` / `Ctrl+Alt+Enter` keybindings (via `AcceptToolConfirmation` / `SkipToolConfirmation` actions gated on `chatHasToolConfirmation`), but the general confirmation widget has no keyboard shortcut support. A team member (roblourens) confirmed the gap in December 2025.

## Change summary

Add keyboard shortcuts for the Continue/Pause buttons on the 'Continue to iterate?' agent confirmation prompt.

## Best solution

Extend the existing `AcceptToolConfirmation` keybinding pattern to also cover `ChatConfirmationContentPart` prompts (the 'Continue to iterate?' flow), or wire a new context key and keybinding pair so Ctrl+Enter accepts and a secondary shortcut pauses. The confirmation widget lives in `chatConfirmationContentPart.ts`; the tool confirmation keybinding pattern in `chatToolActions.ts` is the model to follow.
