# Issue #160897 — Git - add submodule support to “git checkout”

[https://github.com/microsoft/vscode/issues/160897](https://github.com/microsoft/vscode/issues/160897)

## Summary

Keep this accepted Git feature request open: current checkout commands still offer no explicit submodule-recursion option. The request has 29 upvotes, and the maintainer acknowledged the gap while offering Git configuration as a workaround.

## Change summary

Allow VS Code's Git checkout command to update submodules using --recurse-submodules.

## Best solution

Provide an opt-in way to recurse into submodules during checkout through the built-in Git extension, without requiring global Git configuration. Agree on whether that choice is per checkout or a persisted repository-scoped preference, while preserving existing checkout behavior when it is not enabled.
