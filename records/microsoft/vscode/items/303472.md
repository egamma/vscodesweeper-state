# Issue #303472 — Title bar becomes hard to read when the window is inactive

[https://github.com/microsoft/vscode/issues/303472](https://github.com/microsoft/vscode/issues/303472)

## Summary

Already fixed on main: the specific inactive title bar opacity that made the foreground too dim was raised from 0.3 to 0.6, matching the maintainer follow-up in the issue.

## Change summary

Inactive VS Code windows made title bar text and title bar actions too light to read, and the opacity dimming also made `titleBar.inactiveForeground` look inconsistent with caption buttons.

## Best solution

Treat the shipped opacity increase in commit 9dcb3770d70761890506c9b4b764a8cb7b6d6e82 as the completed fix for readability; keep any broader request to remove inactive opacity entirely as a separate design discussion if users still need it.
