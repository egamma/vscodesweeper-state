# Issue #346518 — Remote-SSH(from Mac) to Windows waits 300 seconds for Agent Host Supervisor before opening the workspace

[https://github.com/microsoft/vscode/issues/346518](https://github.com/microsoft/vscode/issues/346518)

## Summary

Keep open: current CLI source still awaits supervisor readiness before starting the workspace server, permitting the reported 300-second delay. The latest successful connection does not eliminate this failure path.

## Change summary

Prevent unavailable Agent Host Supervisor provisioning from delaying ordinary Remote-SSH workspace startup for five minutes.

## Best solution

Decouple ordinary workspace-server availability from supervisor provisioning while preserving agent-host connectivity when ready. Diagnose the Windows readiness failure separately; an invalid download should not impose this startup penalty on editing.
