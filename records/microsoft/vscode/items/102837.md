# Issue #102837 — Allow extensions to contribute to peek widget title navigation action item

[https://github.com/microsoft/vscode/issues/102837](https://github.com/microsoft/vscode/issues/102837)

## Summary

A real extension API gap remains on current main: reference peek title actions are still hard-coded and no extension menu contribution targets that toolbar. The issue is already routed to the references area and has no verified canonical duplicate.

## Change summary

Allow extensions to add commands to reference peek title toolbars with the current peek location as command context.

## Best solution

Expose a stable reference-peek title menu contribution and populate it through the menu service, passing the currently displayed location to contributed commands. The API should follow the scoped-menu pattern used by the testing output peek.
