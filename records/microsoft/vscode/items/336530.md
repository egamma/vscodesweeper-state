# Issue #336530 — Sessions: In compact sessions list view `g` and `y` bottom is cutting

[https://github.com/microsoft/vscode/issues/336530](https://github.com/microsoft/vscode/issues/336530)

## Summary

Fresh, plausible visual bug: in compact sessions-list mode the title row is boxed to a fixed 16px height/line-height that leaves little to no room for descenders (g, y) at the 13px title font, matching the reporter's screenshot; a second screenshot shows the same clipping in the session workspace picker.

## Change summary

In the compact sessions list view (and the session workspace picker), descenders on letters like 'g' and 'y' are visually clipped at the bottom of the row.

## Best solution

A maintainer familiar with the sessions design tokens should adjust the compact row's title line-height/height (src/vs/sessions/contrib/sessions/browser/media/sessionsList.css, `.sessions-list-control.compact .session-title-row`) to leave descender clearance, and check the session workspace picker's analogous row styling for the same issue.
