# Issue #296731 — toggleQuickDiffWidgetFocus places cursor at (1,1) instead of at the change location

[https://github.com/microsoft/vscode/issues/296731](https://github.com/microsoft/vscode/issues/296731)

## Summary

The cursor-placement defect remains in current main: opening the quick diff reveals the change but positions only the outer editor, and toggling focus leaves the embedded editor's cursor at its initial position. Keep this open for a bounded SCM quick-diff fix.

## Change summary

Focusing the quick diff peek editor should place its cursor near the displayed change so arrow-key navigation does not jump to the beginning of the file.

## Best solution

Make the quick-diff widget's embedded-editor cursor agree with the displayed change when entering it through the focus command, while preserving focus return to the outer editor and normal diff navigation.
