# Issue #141987 — Usability: "source" (extension / owner) of a problem diagnostic not discoverable

[https://github.com/microsoft/vscode/issues/141987](https://github.com/microsoft/vscode/issues/141987)

## Summary

The accepted backlog request remains necessary: current main still discards extension identity before diagnostics reach the marker model and Problems UI. With 33 upvotes and several reports consolidated here, it should remain open.

## Change summary

Expose the extension responsible for each diagnostic in raw problem data and the Problems UI.

## Best solution

Carry the originating extension ID through the diagnostics protocol and marker model, then expose it in copied JSON and the Problems view, ideally with a direct route to the extension. Keep the extension-provided `source` as descriptive metadata rather than treating it as authoritative ownership.
