[https://github.com/microsoft/vscode/issues/231894](https://github.com/microsoft/vscode/issues/231894)

## Summary

Keep open: a maintainer confirmed that Writing Tools works in ordinary inputs but not in the editor. Electron has since added context-menu support, but current VS Code does not supply the required frame, and neither that upstream change nor the suggested shortcut establishes that the editor problem is resolved.

## Change summary

Enable macOS Writing Tools for selected editor text, with functional Edit-menu actions and context-menu access.
