# Issue #310726 — CLI for tunnels not accepting GitHub PATs for unclear reasons

[https://github.com/microsoft/vscode/issues/310726](https://github.com/microsoft/vscode/issues/310726)

## Summary

GitHub PATs are not supported for this tunnel authentication flow, as a maintainer previously documented. The apparent successful login stores the supplied credential; it does not establish that the tunnels service accepts it.

## Change summary

Explain why tunnel creation rejects GitHub PATs even after the CLI reports a stored GitHub login.

## Best solution

Use the supported GitHub device-code login through `code tunnel user login --provider github` without `--access-token`. Explain the distinction between storing credentials and authenticating successfully to the tunnels service rather than treating PAT rejection as a regression.
