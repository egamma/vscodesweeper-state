# Issue #335867 — Current prompt's margins look off in chat hover preview

[https://github.com/microsoft/vscode/issues/335867](https://github.com/microsoft/vscode/issues/335867)

## Summary

Team-authored visual-polish report on the agent session hover preview; the compact chat rendering used there plausibly collapses spacing between the prompt and reasoning sections, but no fix exists yet on main, so this stays open for a maintainer to visually tune.

## Change summary

In the hover that previews a chat session's current state, the margins between the prompt and the reasoning/thinking content look too tight, making the two hard to tell apart.

## Best solution

Adjust the compact-mode spacing in the agent session hover so the prompt and reasoning/thinking sections are visually distinct, likely by revisiting the `margin: 0 -8px` / zeroed `.interactive-item-container` padding override in agentSessionHoverWidget.css.
