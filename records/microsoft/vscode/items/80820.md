# Issue #80820 — "editor font zoom" does not persist

[https://github.com/microsoft/vscode/issues/80820](https://github.com/microsoft/vscode/issues/80820)

## Summary

Still valid: editor font zoom level is a transient in-memory value (`EditorZoom._zoomLevel` in `src/vs/editor/common/config/editorZoom.ts`) with no persistence mechanism. The request to persist it across restarts remains unimplemented on current main.

## Change summary

The "Increase/Decrease Editor Font Size" commands apply a temporary zoom multiplier that resets on restart, unlike window zoom which persists.

## Best solution

Persist the editor font zoom level to storage (e.g. via a workbench contribution that saves/restores `EditorZoom` state, or by writing it to `editor.fontSize` in user settings). The fix would likely touch `src/vs/editor/common/config/editorZoom.ts` and add a workbench-layer contribution to read/write the zoom level to storage on change and on startup. The related closed issues (#75397, #75156) were resolved with workarounds ("just change `editor.fontSize`"), not with an actual persistence implementation.
