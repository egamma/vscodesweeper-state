Real visual defect report against the brand-new, still-actively-iterated `workbench.experimental.modernUI` preview (confirmed by the reporter's own workaround of disabling the setting), but the report has no screenshot and I couldn't pin the exact asymmetric-border code path in the modernUI CSS from the description alone, so more detail is needed before this can be routed with confidence.

## Change summary

After the 1.134.0 update, all panels appear shifted right with a thicker left border and no right border, on both maximized and restored windows.

## Best solution
