Verified duplicate of the open, triaged issue #304214, which tracks the same missing 'Open with Code' folder context menu entry on Windows after updates. That issue is labeled and actively tracked with the right area owners.

## Change summary

After a VS Code auto-update on Windows, the 'Open with Code' context menu entry for folders disappears from Windows Explorer, leaving only the file entry.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/304214 which is the actively triaged canonical for this class of missing folder context menu entries.
