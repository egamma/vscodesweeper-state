# Issue #125777 — Ctrl + Shift + Click to trigger Go To References

[https://github.com/microsoft/vscode/issues/125777](https://github.com/microsoft/vscode/issues/125777)

## Summary

Keep open: current source still lacks a direct Ctrl+Shift+Click reference-navigation gesture, and the existing definition-to-references fallback does not cover symbols with multiple definitions. The broader mouse-customization request is related, but does not establish the same observable problem required for closing this re-reviewed, team-authored item as a duplicate.

## Change summary

Provide Ctrl+Shift+Click to navigate directly to a symbol's references, including symbols with multiple definition locations.

## Best solution

Provide a direct reference-navigation mouse gesture in the editor-symbol navigation area, independent of the number of definition results. Settle its modifier behavior across platforms and multi-cursor configurations while preserving ordinary definition navigation and selection gestures.
