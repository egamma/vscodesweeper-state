# Issue #107265 — Support tab completion / custom key handlers in QuickPick

[https://github.com/microsoft/vscode/issues/107265](https://github.com/microsoft/vscode/issues/107265)

## Summary

Keep open for an API and accessibility decision. Extension-contributed keybindings can implement tab completion, but QuickPick still exposes neither a completion event nor custom key handlers; the accepted Backlog request has no verified fix or matching older canonical.

## Change summary

Allow extensions to complete QuickPick input on Tab, including completing multiple matches to their common prefix.

## Best solution

Establish whether scoped extension commands are the supported solution or QuickPick needs a dedicated completion contract. Any supported approach must preserve keyboard access to the list and buttons rather than globally replacing Tab navigation.
