# Issue #330374 — Add "Copy Value and Expression" option to debug menu right click

[https://github.com/microsoft/vscode/issues/330374](https://github.com/microsoft/vscode/issues/330374)

## Summary

A real debug-workflow gap remains: current main can copy a selected value or expression separately and can copy all Watch entries, but cannot copy one selected expression together with its value. Keep the active Backlog Candidates request open and route it to the debug area.

## Change summary

Add a debug context-menu action that copies one selected expression and its current value together, such as `OCR_TYPE = 'HORIZ'`.

## Best solution

Add a single-selection command to the Variables and Watch context menus that combines the variable's evaluatable expression or name with the same current value produced by Copy Value, using a consistent text format.
