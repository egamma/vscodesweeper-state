# Issue #349685 — Source Control Graph shows the wrong avatar when a Git author name matches another user's GitHub display name

[https://github.com/microsoft/vscode/issues/349685](https://github.com/microsoft/vscode/issues/349685)

## Summary

The current source still permits a display-name collision to return another user's avatar. Keep this open while the linked fixing PR is reviewed and landed.

## Change summary

Source Control Graph displays the wrong author's avatar when a cached GitHub display name matches the commit's Git author name.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/349686 so avatar resolution uses authoritative author identity rather than display-name matches, preserving correct results across cached and batched requests.
