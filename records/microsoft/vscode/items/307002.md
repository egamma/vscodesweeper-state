## Summary

The reporter uses a third-party OpenRouter model (nvidia/nemotron) in agent mode. Terminal reuse in VS Code is automatic per chat session for foreground/sync commands — the code in `runInTerminalTool.ts` caches terminals per `chatSessionResource`. The most likely cause is the model issuing each command in background/async mode (which by design creates new terminals for parallel execution) or some other model-level tool-calling behavior. Without confirmation that this reproduces with a first-party model, this needs more information.
