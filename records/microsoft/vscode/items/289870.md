# Issue #289870 — Support an envFromInput field in launch.json

[https://github.com/microsoft/vscode/issues/289870](https://github.com/microsoft/vscode/issues/289870)

## Summary

Keep this accepted backlog request open: current input substitution does not turn one script's JSON output into multiple debug-process environment variables. The request has 23 upvotes, and the related reports inspected do not provide an eligible duplicate target or a completed implementation.

## Change summary

Allow a single script or task result to populate multiple launch environment variables without an intermediate secrets file or separate secret-store requests.

## Best solution

Define an in-memory environment-input contract across task execution, launch configuration resolution, and debug-adapter configuration. Area owners should settle execution timing, environment precedence, adapter compatibility, and secret-handling guarantees before implementation; existing per-variable inputs are only a partial workaround.
