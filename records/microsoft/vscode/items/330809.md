# Issue #330809 — Agents Window - Customization: Plugins updated not working correctly

[https://github.com/microsoft/vscode/issues/330809](https://github.com/microsoft/vscode/issues/330809)

## Summary

Real, corroborated bug in the Agents Window plugin update flow: two independent reporters describe 'Update Plugins' (and even reinstall) leaving a stale local git clone instead of pulling the remote's latest commit, and local-folder plugin changes requiring a full window restart to be picked up.

## Change summary

Updating (or reinstalling) an installed agent plugin/skill does not refresh the local checkout to match the remote repository; local-folder plugin changes only appear after restarting the Agents Window.

## Best solution

Have the chat customization/plugin owners trace the update path in src/vs/workbench/contrib/chat/browser/agentPluginRepositoryService.ts (pullRepository / _refreshRepository) and src/vs/platform/git/node/localGitService.ts (`git pull --ff-only` retry/hard-reset logic) against a real stale clone to find why the fast-forward/hard-reset path isn't landing new commits for some repos, and confirm the reinstall path actually re-clones/pulls instead of no-op'ing when the target directory already exists.
