Keep open: the discussion confirms stale plugin contents, and the reporter later isolates a remaining Agents Window skill-refresh problem while editor updates work. Current source has update and discovery mechanisms, but no verified fix or older canonical covers the full reported behavior.

## Change summary

Plugin updates and local plugin changes should refresh the skills available in the Agents Window without restarting it.

## Best solution

Establish where updated plugin contents stop propagating into the Agents Window's active harness, then restore live skill discovery across that boundary. Distinguish stale repository contents from stale discovered inventory rather than treating a successful pull as proof that the displayed skills refreshed.
