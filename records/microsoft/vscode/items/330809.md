# Issue #330809 — Agents Window - Customization: Plugins updated not working correctly

[https://github.com/microsoft/vscode/issues/330809](https://github.com/microsoft/vscode/issues/330809)

## Summary

Real bug traced in the Agents Window plugin/customization discovery code: the per-plugin component watcher is created non-recursive even though skills live in nested subdirectories, so content edits inside an already-discovered skill folder (from a git pull or a manual edit) never trigger a refresh until restart.

## Change summary

After 'Update Plugins' pulls a newer version of a git-sourced plugin, or after editing a locally-installed plugin's folder, the Agents Window Customization view keeps showing stale plugin content (skills/version) until VS Code is restarted.

## Best solution

In src/vs/workbench/contrib/chat/common/plugins/agentPluginServiceImpl.ts, watch each plugin component directory recursively (or explicitly watch each child skill/command subdirectory) so content changes to files already inside a discovered subdirectory retrigger `changeTrigger`, matching how readPluginSkills/readSkills resolve skills from `childDirectoriesOnly` subfolders.
