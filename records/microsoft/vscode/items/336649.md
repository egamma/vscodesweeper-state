## Summary

Real, unimplemented request: the MCP servers list (McpServersListView) only shows a per-item scope badge (McpServerScopeBadgeWidget) and has no User/Workspace grouping today, so this stays open. Milestone is Backlog (a holding bin), the issue was reopened after a prior close didn't stick, and there's no evidence of a canonical duplicate.

## Change summary

Group the MCP servers list UI into separate User and Workspace sections so configuration scope is clearer and troubleshooting is easier.

## Best solution

Design and implement scope-grouped sections in src/vs/workbench/contrib/mcp/browser/mcpServersView.ts (McpServersListView), building on the existing per-item McpServerScopeBadgeWidget rather than duplicating scope logic; a maintainer should first decide the grouping UI (collapsible sections vs. separate views) given the multiple ConfigurationTarget scopes (USER, USER_LOCAL, USER_REMOTE, WORKSPACE, WORKSPACE_FOLDER).
