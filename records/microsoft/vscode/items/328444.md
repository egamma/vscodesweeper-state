# Issue #328444 — Session irreversibly lost after changes to workspace folder and saving workspace

[https://github.com/microsoft/vscode/issues/328444](https://github.com/microsoft/vscode/issues/328444)

## Summary

Keep open: current source explains why the session becomes inaccessible after its original folder leaves the workspace. This is also a MEMBER-authored issue, so judgment-based closure is inappropriate.

## Change summary

Preserve access to an Agents Window session after changing workspace folders, saving the workspace, and reopening it.

## Best solution

Keep out-of-workspace agent-host sessions discoverable through a recovery or orphaned-session path, and provide an explicit way to rebind their workspace context rather than treating workspace-filter removal as session removal.
