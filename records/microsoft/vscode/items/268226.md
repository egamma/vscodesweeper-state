# Issue #268226 — Enhance Multi-Diff Navigation for Narrow/Mobile Screens

[https://github.com/microsoft/vscode/issues/268226](https://github.com/microsoft/vscode/issues/268226)

## Summary

Keep open: current multi-diff navigation does not provide direct selection of an arbitrary file within a narrow editor viewport. The linked outline request is related, but does not establish the same no-other-views requirement.

## Change summary

Provide compact, in-editor file navigation for reviewing large multi-file diffs on narrow or mobile screens.

## Best solution

Provide an on-demand file chooser within the multi-diff editor that reveals a selected file without opening another editor or sidebar and without requiring horizontal scrolling. Coordinate with the related outline request while preserving this issue's narrow-screen acceptance criteria.
