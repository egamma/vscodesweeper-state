# Issue #232258 — Powershell 7 Ctrl + G from Terminal fails for paths with space

[https://github.com/microsoft/vscode/issues/232258](https://github.com/microsoft/vscode/issues/232258)

## Summary

Still reproduces on main: `preparePathForShell` returns `& 'path'` for PowerShell paths with spaces, which is correct for invoking executables but wrong when used as an argument to `cd`. An open community PR (#313196) is already targeting this fix.

## Change summary

Ctrl+G (Go to directory) in the terminal generates `cd & 'path with space'` instead of `cd 'path with space'` for PowerShell, causing the command to fail.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/313196 (or an equivalent fix) that prevents the `&` call-operator prefix from leaking into `cd` commands. The fix boundary is the interaction between `preparePathForShell` (terminalEnvironment.ts line 347-348) and the `cd` command construction in `terminalRunRecentQuickPick.ts` line 355 — either the quick-pick caller should strip/not-request the `&` prefix, or `preparePathForShell` should accept a context parameter distinguishing 'execute' from 'argument' usage.
