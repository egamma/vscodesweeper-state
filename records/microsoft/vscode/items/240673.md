# Issue #240673 — Move Find Controls to left side

[https://github.com/microsoft/vscode/issues/240673](https://github.com/microsoft/vscode/issues/240673)

## Summary

The find widget position is hardcoded to the top-right corner (`OverlayWidgetPositionPreference.TOP_RIGHT_CORNER` in `findWidget.ts`). No setting exists to move it. This is a valid feature request with an accessibility angle, but low traction (1 upvote over 528 days). Keeping open for the community process.

## Change summary

Request to allow repositioning the editor find widget from the right side to the left side or as a top bar.

## Best solution

Add an `editor.find.position` setting (e.g. `right` | `left`) that controls the `OverlayWidgetPositionPreference` used in `src/vs/editor/contrib/find/browser/findWidget.ts`. The overlay widget API would need a `TOP_LEFT_CORNER` preference added to `src/vs/editor/browser/editorBrowser.ts`. Low traction suggests this is not urgent.
