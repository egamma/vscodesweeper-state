# Issue #290082 — Select type of browser data to delete

[https://github.com/microsoft/vscode/issues/290082](https://github.com/microsoft/vscode/issues/290082)

## Summary

Valid feature request from a team member. The current integrated browser clear-data implementation (`BrowserSession.clearData()`) is all-or-nothing — it clears trust, history, permissions, and all Electron session data in one shot with no granularity. The request for selective deletion (cookies, cache, local storage, etc.) is not yet implemented on main.

## Change summary

Allow users to choose which types of browser data (cookies, cache, local storage, etc.) to delete in the integrated browser, rather than clearing everything at once.

## Best solution

Extend the `clearData` path in `src/vs/platform/browserView/electron-main/browserSession.ts` to accept a set of data-type flags (Electron's `session.clearData` already supports category options), surface those choices in the UI commands registered in `browserDataStorageFeatures.ts`, and optionally integrate with the DevTools storage panel as the commenter suggests.
