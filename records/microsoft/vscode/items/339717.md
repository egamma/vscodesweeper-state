## Summary

Fresh, team-authored bug report (filed same day, testing the new attempt-comparison grid feature from #339373) describing stale grid UI after deleting an attempt group. No fix exists yet and this is too new to have landed on main — keep open regardless, per the team-authored protection rule.

## Change summary

After running 5 attempts in the comparison grid and deleting the attempt group via right-click, the grid UI doesn't clear and a new session visually takes the deleted group's place.

## Best solution
