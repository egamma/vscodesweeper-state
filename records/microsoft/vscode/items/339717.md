# Issue #339717 — Agents - deleting a attempt group does not clear the grid

[https://github.com/microsoft/vscode/issues/339717](https://github.com/microsoft/vscode/issues/339717)

## Summary

Keep open: the supplied five-attempt reproduction is sufficient to retest, and current source still separates comparison-group deletion from grid cleanup. The comparison lifecycle now archives records whose groups disappear, but that does not establish that the reported grid and new-session placement behavior is fixed.

## Change summary

Deleting an attempt group should clear its comparison grid instead of leaving the grid and placing a new session in the formerly active attempt pane.

## Best solution
