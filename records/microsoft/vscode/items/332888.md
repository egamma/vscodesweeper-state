# Issue #332888 — Support Ctrl+scroll wheel zoom for text in the Markdown preview

[https://github.com/microsoft/vscode/issues/332888](https://github.com/microsoft/vscode/issues/332888)

## Summary

Reasonable, accessibility-motivated feature request to add Ctrl+scroll zoom for the Markdown preview webview, mirroring editor.mouseWheelZoom; only 7 days old with no upvotes yet, so there's no basis to close it for staleness or lack of traction.

## Change summary

Add Ctrl+scroll wheel zoom for text size within the Markdown preview pane, independent of the editor's global zoom.

## Best solution

If pursued, this would live in extensions/markdown-language-features/src/preview (the preview webview and its previewManager.ts), adding a wheel-event listener gated on Ctrl that scales the rendered content's font-size, similar to how Mermaid diagram zoom is already handled there; a maintainer should weigh whether this belongs in core preview vs. staying with third-party extensions like markdown-preview-zoom.
