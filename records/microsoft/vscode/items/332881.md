# Issue #332881 — Agents Window: "Commit Changes" is not always available

[https://github.com/microsoft/vscode/issues/332881](https://github.com/microsoft/vscode/issues/332881)

## Summary

Fresh feature request (0 days old, no maintainer input) asking that 'Commit Changes' be available regardless of which changeset tab (Branch/Session/Uncommitted) is selected in the Agents Window changes view; the current gating is intentional-looking but not confirmed as-designed, so this needs a product call rather than an automated close.

## Change summary

In the Agents Window Changes tab, the 'Commit Changes' action is only available when 'Uncommitted Changes' is selected, not for other changeset views (e.g. Branch/Session Changes).

## Best solution

A maintainer should decide whether commit-capable operations should be surfaced for other changeset kinds (Branch/Session Changes) in src/vs/sessions/contrib/providers/agentHost/browser/agentHostSessionChangesets.ts, since operations per changeset are currently populated only for the changeset kind the backend marks as commit-capable (typically Uncommitted).
