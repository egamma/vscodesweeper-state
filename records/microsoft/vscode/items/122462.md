# Issue #122462 — Editing markdown cells and leaving edit mode breaks undo stack

[https://github.com/microsoft/vscode/issues/122462](https://github.com/microsoft/vscode/issues/122462)

## Summary

Still present on main: when a markdown cell exits edit mode its TextModel is disposed, invalidating undo/redo stack elements. The notebook layer has never implemented an IUndoRedoDelegate to revive disposed cell TextModels (as alexdima suggested in 2021), so the bug remains.

## Change summary

Editing a markdown cell and leaving edit mode (Ctrl+Enter) disposes the cell's TextModel, which corrupts the shared undo/redo stack and breaks subsequent undo operations in code cells.

## Best solution

Implement an IUndoRedoDelegate (analogous to ModelUndoRedoParticipant in src/vs/editor/common/services/modelUndoRedoParticipant.ts) for notebook cells, so that when undo/redo encounters a disposed markdown cell TextModel, it can revive it before replaying the edit. The fix lives in the notebook undo/redo contribution area (src/vs/workbench/contrib/notebook/browser/contrib/undoRedo/) and the notebook cell viewmodel layer.
