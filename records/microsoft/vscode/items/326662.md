# Issue #326662 — Scroll bar resets in agent chat tabwhen toggling different tabs

[https://github.com/microsoft/vscode/issues/326662](https://github.com/microsoft/vscode/issues/326662)

## Summary

Current main does not preserve per-chat transcript scroll positions when switching conversation tabs. This is a confirmed multi-chat sessions bug and should remain open for that area.

## Change summary

Switching between conversation tabs in an agent session loses each chat's transcript scroll position.

## Best solution

Store the outgoing ChatWidget scroll position by chat resource in ChatView and restore it after rebinding that resource, without changing new-chat auto-scroll behavior.
