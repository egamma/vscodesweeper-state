# Issue #326662 — Scroll bar resets in agent chat tabwhen toggling different tabs

[https://github.com/microsoft/vscode/issues/326662](https://github.com/microsoft/vscode/issues/326662)

## Summary

Fixed on current main by commit aa5ead32578c8e08d0de0e6c65be2623eabe309a, which preserves each chat editor's transcript position when switching tabs or sessions.

## Change summary

Switching from a lengthy agent chat editor tab to another tab and back lost the transcript's previous scroll position.

## Best solution

Keep the per-session view-state handling delivered by https://github.com/microsoft/vscode/commit/aa5ead32578c8e08d0de0e6c65be2623eabe309a; it captures the outgoing editor's offset and bottom-pinned state and restores them when that chat becomes active again.
