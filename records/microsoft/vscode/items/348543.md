# Issue #348543 — Copilot file tools access C:\workspace instead of a Dev Container workspace

[https://github.com/microsoft/vscode/issues/348543](https://github.com/microsoft/vscode/issues/348543)

## Summary

Keep open to investigate unintended host-side writes, independently of whether forcing Copilot onto the UI host is supported. The report provides sufficient reproduction steps; its older VS Code version needs retesting, and source inspection does not establish that current main resolves the problem.

## Change summary

Prevent Copilot workspace file operations from targeting C:\workspace when the intended workspace is /workspace inside a Dev Container.

## Best solution

Workspace file operations should preserve the remote workspace identity or explicitly reject the unsupported configuration without modifying host files. Have the Copilot tools owner assess the reported host-write boundary before consolidating this with broader UI-host support work.
