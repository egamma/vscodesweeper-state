# Issue #326126 — Some color theme settings and color customizations are ignored in modern UI mode

[https://github.com/microsoft/vscode/issues/326126](https://github.com/microsoft/vscode/issues/326126)

## Summary

Confirmed on current main: the modern UI CSS still forces `background-color: transparent !important` / `border-color: transparent !important` on the activity bar, status bar, and title bar, overriding any theme or user color customizations for those parts. A VS Code team member has already acknowledged this is a real regression and said they're redesigning the modern UI to restore color support, so this should stay open pending that work landing.

## Change summary

Enabling `workbench.experimental.modernUI` (now auto-rolled-out to some stable users) makes the activity bar, status bar, and title bar ignore `workbench.colorCustomizations`/theme colors because a built-in `!important` CSS rule forces them transparent.

## Best solution

Land the in-progress redesign (per hawkticehurst's comment) that reintroduces color support for these bars in `src/vs/workbench/browser/media/floatingPanels.css`, replacing the blanket `!important` transparency rule with one that respects `activityBar.background`/`statusBar.background`/`titleBar.activeBackground` etc. when set.
