# Issue #326126 — Some color theme settings and color customizations are ignored in modern UI mode

[https://github.com/microsoft/vscode/issues/326126](https://github.com/microsoft/vscode/issues/326126)

## Summary

Maintainer discussion confirms the modern UI transparency behavior regressed existing theme and color-customization workflows, and the responsible maintainer has said color support will be added back. Keep this open for the modernization/layout owners rather than closing while the fix is still pending.

## Change summary

Modern UI mode makes activity bar, status bar, and title bar backgrounds/borders transparent, ignoring existing theme and `workbench.colorCustomizations` values.

## Best solution

Restore explicit color support for the modern UI shell parts while preserving the intended unified surface design where possible, likely in the workbench layout/theming CSS for floating panels.
