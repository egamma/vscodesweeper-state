# Issue #173983 — Selecting text highlighting in large files silently drops highlighting of occurrences

[https://github.com/microsoft/vscode/issues/173983](https://github.com/microsoft/vscode/issues/173983)

## Summary

Still valid on current main: selection highlighting silently caps at 999 matches with no user feedback. The limit exists for performance reasons (confirmed by alexdima), but the request for feedback when the limit is hit remains unaddressed.

## Change summary

Selection text highlighting silently drops occurrences beyond 999 in large files with no indicator to the user.

## Best solution

Add a status bar indicator or editor notification when selection highlights are capped at the 999 limit, similar to how Find shows match counts. The fix would touch `SelectionHighlighter._setState` in `src/vs/editor/contrib/multicursor/browser/multicursor.ts` to surface when `findMatches()` returns the capped result count.
