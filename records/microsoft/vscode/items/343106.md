# Issue #343106 — Quick diff "deleted" gutter marker is drawn between lines 1 and 2 when the first line is deleted

[https://github.com/microsoft/vscode/issues/343106](https://github.com/microsoft/vscode/issues/343106)

## Summary

The reported deletion-marker displacement is confirmed in current source: a deletion before line 1 loses its boundary information when its decoration range is clamped. Keep this open for a bounded SCM gutter correction.

## Change summary

Deleting the first line places the quick diff deletion marker below the first remaining line instead of above it.

## Best solution

Make the SCM quick diff gutter accurately distinguish deletion before the first remaining line from deletion after it, preserving existing behavior for other deletion locations and provider styles.
