# Issue #343106 — Quick diff "deleted" gutter marker is drawn between lines 1 and 2 when the first line is deleted

[https://github.com/microsoft/vscode/issues/343106](https://github.com/microsoft/vscode/issues/343106)

## Summary

The reported placement error remains in the inspected main source: a deletion before line 1 receives the same bottom-edge decoration as an interior deletion. Keep this open for an SCM gutter correction; the report already supplies sufficient reproduction steps.

## Change summary

Display the quick diff deletion marker above the first surviving line when leading lines are deleted.

## Best solution

Make the SCM gutter indicate the actual deletion boundary, including the beginning of the file, while preserving interior deletion placement and existing provider styling.
