# Issue #343106 — Quick diff "deleted" gutter marker is drawn between lines 1 and 2 when the first line is deleted

[https://github.com/microsoft/vscode/issues/343106](https://github.com/microsoft/vscode/issues/343106)

## Summary

The reported placement error is confirmed in current source: a deletion before the first line becomes a line-1 decoration, but its marker is still anchored below that line. Keep this open for a bounded SCM gutter correction.

## Change summary

Show the quick-diff deletion marker above the first surviving line when content is deleted from the beginning of a file.

## Best solution

Make beginning-of-file deletion markers identify the correct boundary for primary, contributed, and secondary quick-diff providers, while preserving ordinary deletion placement and existing gutter interactions.
