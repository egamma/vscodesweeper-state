# Issue #313548 — Agent app: Auto-commit and stack work without manual git ceremony

[https://github.com/microsoft/vscode/issues/313548](https://github.com/microsoft/vscode/issues/313548)

## Summary

Create PR now includes committing pending changes, and the legacy CLI provider exposes opt-in auto-commit, but these only partially satisfy the request for automatic, logically grouped history. Keep this team-authored request open for a decision on the remaining automation and stacking semantics.

## Change summary

Let Agents Window users iterate and create pull requests without separate manual commits, with automatic logical commits during longer tasks.

## Best solution

Retain the integrated commit-and-create-PR flow and define consistent automatic-commit behavior for Agents Window sessions. Specify when logical commits are created and whether existing published history may ever be reorganized before extending automation.
