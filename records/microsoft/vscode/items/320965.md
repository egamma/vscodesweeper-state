# Issue #320965 — Reduce Reliance on Arrow Keys for Code Navigation

[https://github.com/microsoft/vscode/issues/320965](https://github.com/microsoft/vscode/issues/320965)

## Summary

Keep open for the established Backlog Candidates voting period and classify it as under discussion. VS Code already supports remapping cursor movement, but the report identifies an ergonomic gap without proposing a concrete additional interaction.

## Change summary

Provide a more ergonomic way to move between lines while typing without reaching for the arrow keys.

## Best solution

First determine what interaction should supplement customizable keybindings without conflicting with existing editing shortcuts. The `cursorDown` command and `editor.action.insertLineAfter` cover common cases, but not the reporter's scenario of moving into an existing next line.
