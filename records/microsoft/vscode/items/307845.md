## Summary

Valid feature request for an option to disable path auto-completion in the simple file dialog. A Copilot-authored PR (#308208) attempted to add a `files.simpleDialog.autoComplete` setting but was closed without merging. The autocomplete behavior remains unchanged on current main.

## Change summary

Request an option to disable the simple file dialog's path auto-completion, which moves the cursor to the end when a matching path is found mid-edit.

## Best solution

Add a setting (e.g. `files.simpleDialog.autoComplete`) to control whether the simple file dialog auto-completes path segments and repositions the cursor. The fix would be localized to `src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts` (the `setAutoComplete` method and cursor-positioning logic) and the files contribution registration. PR https://github.com/microsoft/vscode/pull/308208 explored this approach but was closed — a maintainer should decide whether to revive or redesign it.
