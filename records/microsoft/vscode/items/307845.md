# Issue #307845 — Add an option to disable cursor to the end when opening a file in remote.

[https://github.com/microsoft/vscode/issues/307845](https://github.com/microsoft/vscode/issues/307845)

## Summary

Keep open: the simple file dialog still explicitly moves the caret to the end after certain directory updates, and no existing setting covers the requested opt-out. This requests control over an intentional behavior; the related reports do not establish an older, open canonical for the same symptom.

## Change summary

Allow users to edit intermediate directory names in the remote file picker without matching an existing path moving the caret to the end.

## Best solution

Make intermediate path editing uninterrupted in the core simple file dialog while preserving deliberate directory navigation and completion. The area owner should decide whether caret preservation should be the default or an opt-out setting before adding configuration.
