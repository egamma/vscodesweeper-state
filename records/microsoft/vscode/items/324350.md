# Issue #324350 — Terminal gaps for AI agent orchestration workflows (scriptability, output read-back, session persistence)

[https://github.com/microsoft/vscode/issues/324350](https://github.com/microsoft/vscode/issues/324350)

## Summary

Valid feature request from a team member identifying real gaps in terminal APIs for AI agent orchestration. The three requested capabilities (output read-back, external CLI control, session persistence) are not implemented on main. A proposed `onDidWriteTerminalData` API exists but is explicitly not intended for stabilization due to performance concerns.

## Change summary

Terminal lacks output read-back, external CLI control, and session persistence — capabilities needed by AI agent orchestration tools that currently require tmux.

## Best solution

Design and stabilize terminal APIs in three areas: (1) a bounded output-capture API (addressing the performance concerns that blocked `onDidWriteTerminalData` stabilization, see #145234), (2) a CLI command like `code --terminal-send` for external scripting, and (3) opt-in process persistence surviving window close. These would let extension authors build native orchestration tools without requiring tmux.
