# Issue #324350 — Terminal gaps for AI agent orchestration workflows (scriptability, output read-back, session persistence)

[https://github.com/microsoft/vscode/issues/324350](https://github.com/microsoft/vscode/issues/324350)

## Summary

Keep this team-authored, cross-cutting terminal exploration open: existing APIs cover live command output and session restoration only partially, not the combined orchestration workflow. The verified related issues cover subsets rather than a canonical replacement.

## Change summary

Enable terminal orchestration through bounded output read-back, external script control, and live sessions that survive closing the editor.

## Best solution

Retain this as the requirements umbrella, distinguishing existing shell-integration streaming and process revival from missing late-attachment read-back and true detachment. Coordinate the persistence portion with the existing tmux and remote-session requests before defining new public contracts.

- **Existing output capability and limitation:** src/vscode-dts/vscode.d.ts:7947–7996 exposes TerminalShellExecution.read(): AsyncIterable<string>.
