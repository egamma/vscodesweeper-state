# Issue #344827 — Sessions started with the Copilot CLI aren't hosted by the agent host or shown in the Sessions view (Remote-SSH)

[https://github.com/microsoft/vscode/issues/344827](https://github.com/microsoft/vscode/issues/344827)

## Summary

Keep open: current main supports discovering external CLI sessions, but discovery is not agent-host execution ownership. Neither the existing visibility setting nor the related handoff work establishes the requested Remote-SSH, host-backed execution and bidirectional single-writer continuity.

## Change summary

Allow standalone Copilot CLI sessions on a Remote-SSH host to execute under the agent host and resume interchangeably in the CLI and VS Code with one active writer.

## Best solution

Define the CLI-to-agent-host execution and ownership contract for remote sessions, coordinating with the handoff work in https://github.com/microsoft/vscode/pull/342120 rather than creating a competing implementation. Distinguish external-session visibility from durable host ownership and preserve session identity and history across client handoffs.
