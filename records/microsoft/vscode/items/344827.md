# Issue #344827 — Sessions started with the Copilot CLI aren't hosted by the agent host or shown in the Sessions view (Remote-SSH)

[https://github.com/microsoft/vscode/issues/344827](https://github.com/microsoft/vscode/issues/344827)

## Summary

Keep open: external-session discovery already exists, but it does not establish that standalone CLI sessions execute inside the remote agent host or support the requested bidirectional, single-writer attachment. Related visibility work and an open handoff PR cover parts of this request, not its full scope.

## Change summary

Host standalone Copilot CLI sessions on the Remote-SSH agent host and allow continuation from either CLI or VS Code with one writer.

## Best solution

Establish a supported remote CLI-to-agent-host attachment and ownership contract, preserving conversation history and preventing concurrent writers. Coordinate with the existing handoff work rather than treating catalog visibility or legacy-session migration as equivalent to host-managed execution.
