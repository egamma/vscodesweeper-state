# Issue #335202 — Replace Activity Bar sizing presets with a numeric size setting

[https://github.com/microsoft/vscode/issues/335202](https://github.com/microsoft/vscode/issues/335202)

## Summary

Reasonable, well-argued request to replace the two-state Activity Bar/window density preset with a numeric size control; no existing setting covers this and no canonical duplicate was found, so it should stay open for maintainer/product triage.

## Change summary

Replace the Default/Compact Activity Bar sizing modes with a numeric icon-size setting so users can pick intermediate or larger/smaller sizes.

## Best solution

A maintainer should weigh in on whether `window.density.layout` (currently a `default`/`compact` enum in src/vs/workbench/browser/workbench.contribution.ts and consumed in activitybarPart.ts/layout.ts) should gain a numeric option, or whether this belongs to a separate, more targeted Activity Bar icon-size setting; the author has offered to contribute a PR, so this is a good candidate for a maintainer decision plus a route to the workbench/UX area.
