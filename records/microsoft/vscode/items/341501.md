# Issue #341501 — Dark 2026 default colors: active/inactive tab are almost impossible to tell apart (especially on cheap monitors)

[https://github.com/microsoft/vscode/issues/341501](https://github.com/microsoft/vscode/issues/341501)

## Summary

Thanks for the report. In the Dark 2026 theme the active tab background (#121314) and inactive tab background (#191A1B) are very close, with a border of only #2A2B2C. This is a theme design and contrast choice rather than broken behavior. It stays open as polish and may overlap existing Modern UI feedback.

## Change summary

The Dark 2026 theme's active and inactive tabs have too little contrast (about 1.1:1) to tell apart.

## Best solution

Adjust the Dark 2026 tab colors in extensions/theme-defaults/themes/2026-dark.json (for example a lighter inactive background, a stronger tab border, or a more visible active indicator) so the active tab is clearly distinguishable. Keep the change consistent with the Modern UI tab feedback in https://github.com/microsoft/vscode/issues/336320.
