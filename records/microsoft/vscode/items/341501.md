# Issue #341501 — Dark 2026 default colors: active/inactive tab are almost impossible to tell apart (especially on cheap monitors)

[https://github.com/microsoft/vscode/issues/341501](https://github.com/microsoft/vscode/issues/341501)

## Summary

Keep open for a default active-tab visibility improvement: a team member independently confirms the difficulty, and current connected-tab styling distinguishes explicit color customizations from theme-provided accents. The documented border workaround does not resolve the default-experience request.

## Change summary

Make the active editor tab clearly distinguishable from inactive tabs in Dark 2026 without requiring color customizations.

## Best solution

Agree on a sufficiently visible default active-tab indicator within the modern connected-tab design, then validate it across focused and unfocused groups. Preserve explicit user color overrides and high-contrast behavior.
