## Summary

A VS Code team member (hediet) independently reproduced and deeply diagnosed this on Windows Insiders, confirming multiple webviews (Markdown preview, GitHub PR, team tools) fail to register their service worker with an InvalidStateError right after an in-place auto-update, until VS Code is restarted — this is a real, confirmed bug, not something to close.

## Change summary

After VS Code auto-updates itself on Windows while running, existing webviews (Markdown preview and others) fail to load because their service worker registration throws InvalidStateError, until the window/app is restarted.
