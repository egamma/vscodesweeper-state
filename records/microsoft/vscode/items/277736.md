# Issue #277736 — Support Right-to-Left (RTL) Text for Persian in Copilot Chat

[https://github.com/microsoft/vscode/issues/277736](https://github.com/microsoft/vscode/issues/277736)

## Summary

A community PR (https://github.com/microsoft/vscode/pull/314365) is open and explicitly lists this issue in its 'Fixes' section, introducing a comprehensive bidirectional text direction model for the editor and chat surfaces. The issue should stay open until that PR is reviewed and either merged or closed.

## Change summary

Persian and other RTL text in Copilot Chat renders left-to-right instead of right-to-left, making mixed-language content hard to read.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/314365, which introduces an `editor.textDirection` setting and propagates direction through chat markdown rendering. The PR addresses this issue along with several other long-standing RTL requests.
