# Issue #234753 — Ctrl + z close the file under edit , KeyW confused with keycode key:z

[https://github.com/microsoft/vscode/issues/234753](https://github.com/microsoft/vscode/issues/234753)

## Summary

Keep open: an independent commenter confirms that Ctrl+Z closes the editor and is captured as Ctrl+W on Debian. The supplied troubleshooting log identifies incorrect shortcut resolution, but the cause of the intermittent layout mismatch remains undiagnosed.

## Change summary

Ctrl+Z on a French Linux keyboard layout intermittently invokes Close Editor instead of Undo, including when recording shortcuts.

## Best solution

Identify why the active native keyboard mapping disagrees with the received French-layout event, then ensure both shortcut dispatch and shortcut recording interpret Ctrl+Z consistently as Undo. Preserve intentional physical-key bindings and other layouts rather than globally changing dispatch semantics.

WorkbenchKeybindingService.resolveKeyboardEvent delegates through the desktop KeyboardLayoutService, whose validateCurrentKeyboardMapping is a no-op, to MacLinuxKeyboardMapper.resolveKeyboardEvent, which retains alphabetic scan codes.
