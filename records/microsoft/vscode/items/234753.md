# Issue #234753 — Ctrl + z close the file under edit , KeyW confused with keycode key:z

[https://github.com/microsoft/vscode/issues/234753](https://github.com/microsoft/vscode/issues/234753)

## Summary

Intermittent keyboard layout misdetection on Linux with French AZERTY layout — confirmed by a second user on Debian 13 in January 2026. The keyboard dispatch troubleshooting output shows the layout mapper incorrectly resolving KeyW as 'Z', causing Ctrl+Z to fire closeActiveEditor (Ctrl+W). No fix on main.

## Change summary

On Linux with French keyboard layout, VS Code intermittently confuses physical key positions (KeyW produces key 'z'), causing Ctrl+Z to trigger Ctrl+W (close editor).

## Best solution

Investigate the keyboard layout validation logic in `src/vs/workbench/services/keybinding/browser/keyboardLayoutService.ts` — specifically `_validateCurrentKeyboardMapping` and `_getBrowserKeyMapping` — for race conditions or stale layout data when the browser's `getLayoutMap()` API returns incorrect/incomplete mappings for non-US layouts on Linux. The intermittent nature (self-resolves without restart) suggests a timing or caching issue in layout detection.
