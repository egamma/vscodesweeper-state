# Issue #342820 — Agent plugins: marketplace install does a full git clone, slow or failing for large repositories

[https://github.com/microsoft/vscode/issues/342820](https://github.com/microsoft/vscode/issues/342820)

## Summary

Keep open as a plugin-install performance improvement: current source still performs unrestricted clones, and SHA-pin support did not reduce transfer size. The requested optimization remains missing; corporate-network resets themselves were not independently reproduced.

## Change summary

Reduce Git history downloaded during marketplace plugin installation while preserving branch, tag, and exact-commit selection.

## Best solution

Make plugin acquisition transfer only the history needed for the requested revision, while preserving exact SHA verification and subsequent updates. Start with history reduction; sparse checkout and blob filtering are optional follow-up optimizations.

- **Behavior:**

  > Installing a plugin from a repository with substantial history should not download unrelated historical revisions when only one requested revision is needed. Branch and tag sources must remain installable, and an explicit SHA must select exactly that commit even when it differs from the named ref's tip. Existing updates, authentication fallback, cancellation, and failure cleanup must continue to work. Acceptance should measure reduced acquired history and correct checked-out content, rather than relying on corporate-network timing.
- **Trace:**

  > AbstractGitPluginSource.ensure in src/vs/workbench/contrib/chat/browser/pluginSources.ts clones using descriptor.ref and then checks out descriptor.sha when present. NativePluginGitCommandService forwards the clone to LocalGitService.clone, whose command construction has no history limit; full-SHA refs still clone before an unrestricted fetch. LocalGitService tests currently encode that full-clone behavior. The remaining design investigation is how reduced acquisition interacts with SHA pins outside the initially selected tip and with AbstractGitPluginSource.update, which fetches pinned sources and pulls other sources. Preserve exact SHA verification, authentication retry, cancellation, and cleanup; do not expand this work into mandatory sparse checkout or change installed plugin contents. https://github.com/microsoft/vscode/pull/339022 establishes the existing exact-commit behavior that must remain intact.
