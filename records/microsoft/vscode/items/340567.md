# Issue #340567 — Regression: Chat slash command suggestions no longer prioritize prefix matches over fuzzy matches

[https://github.com/microsoft/vscode/issues/340567](https://github.com/microsoft/vscode/issues/340567)

## Summary

Thanks for the report. Two reporters see it, and the cause is visible in current source: prompt slash-command filterText lists word-suffix variants before the full command name, so a plain prefix match is no longer the best-scoring target.

## Change summary

Typing a prefix like `/pr-p` or `/mu` ranks fuzzy-only slash commands above the command whose name starts with that prefix.

## Best solution

Build the prompt slash-command filterText with the full `/name` first (then the space-separated display form), and keep the word-suffix variants only as later fallbacks. Prefix matches then outrank fuzzy ones, and suffix searches like `/step` keep working.
