# Issue #340567 — Regression: Chat slash command suggestions no longer prioritize prefix matches over fuzzy matches

[https://github.com/microsoft/vscode/issues/340567](https://github.com/microsoft/vscode/issues/340567)

## Summary

Thanks for the report. Two reporters see the same behavior, and the source points to a likely cause. The slash-command filterText now puts word-suffix aliases ahead of the full command name, so a typed prefix like `/pr-p` is no longer matched at the start of the filter text.

## Change summary

Typing a prefix of a custom slash command ranks it below fuzzy-only matches in the chat input suggestions.

## Best solution

Make the full `/name` the first token in the prompt slash command filterText (or otherwise give prefix matches a score boost), while keeping the word-suffix aliases for `/step`-style lookups. Add a test for prefix-over-fuzzy ordering.
