## Summary

Fresh, same-day report with a video showing the Agents Window session-comparison grid redrawing with a visible lag on window resize; no root cause traced yet and no linked fix, so this stays open for investigation.

## Change summary

When a multi-session comparison grid is visible in the Agents Window, resizing the whole window leaves the stale grid layout on screen for a noticeable moment before it catches up to the new size.
