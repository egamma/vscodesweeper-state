# Issue #250857 — git merge conflict: if you right click on a file and accept all incoming changes, or accept all current changes, the file should be staged

[https://github.com/microsoft/vscode/issues/250857](https://github.com/microsoft/vscode/issues/250857)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/248533 tracks the same Source Control context-menu behavior, including the missing save and stage after Accept All Incoming or Current.

## Change summary

Accepting all incoming or current merge-conflict changes from the Source Control context menu edits the file without saving or staging it, leaving the merge state and Merge Editor action visible.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/248533 and make the multi-resource Accept All commands complete the same save-and-stage workflow as accepting a merge through the Merge Editor.
