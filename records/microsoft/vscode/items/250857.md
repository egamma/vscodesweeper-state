# Issue #250857 — git merge conflict: if you right click on a file and accept all incoming changes, or accept all current changes, the file should be staged

[https://github.com/microsoft/vscode/issues/250857](https://github.com/microsoft/vscode/issues/250857)

## Summary

This is a feature request for the merge-conflict extension's 'Accept All Incoming/Current' SCM context-menu commands to also stage the file, matching the merge editor's behavior. Issue #260382 reports the same disconnect and is open — consolidating there.

## Change summary

When right-clicking a merge-conflicted file in the SCM panel and choosing 'Accept All Incoming' or 'Accept All Current', the file should be automatically staged rather than remaining in the merge-changes group.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/260382 which reports the same disconnect. A fix would involve the `acceptAllResources` method in `extensions/merge-conflict/src/commandHandler.ts` calling `git.stage` (or the git extension providing a richer integration) after resolving all conflict markers, mirroring what `git.acceptMerge` already does for the merge editor path.
