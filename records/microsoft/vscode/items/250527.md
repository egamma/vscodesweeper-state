# Issue #250527 — Follow agent execution should not be notebook specific

[https://github.com/microsoft/vscode/issues/250527](https://github.com/microsoft/vscode/issues/250527)

## Summary

Keep open for a consistent, discoverable control over following agent activity across text editors and notebooks. The inspected configuration still exposes notebook-specific following, and the related accessibility request was explicitly consolidated into this issue.

## Change summary

Generalize notebook-specific agent following into a configurable experience shared by text editors and notebooks.

## Best solution

Provide a discoverable agent-follow control with consistent reveal behavior across text editors and notebooks, including an option to avoid automatic navigation while the user works elsewhere. Settle its persistence and focus semantics before implementation.
