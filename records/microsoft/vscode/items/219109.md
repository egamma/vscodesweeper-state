# Issue #219109 — Strings in editor build use unicode escape sequences.

[https://github.com/microsoft/vscode/issues/219109](https://github.com/microsoft/vscode/issues/219109)

## Summary

Still present on main: the Monaco editor build's NLS output files use JSON.stringify which produces unicode escape sequences (\uXXXX) instead of plain UTF-8 characters, resulting in bloated output. No fix has been applied.

## Change summary

The editor-distro build produces bloated nls.messages.*.js files with unicode escape sequences instead of plain UTF-8 characters.

## Best solution

Replace bare JSON.stringify calls in build/lib/nls.ts (line 71) and build/lib/i18n.ts (line 363) with a variant that outputs plain UTF-8 — either a custom replacer or a post-stringify unescape step — so the NLS message JS files are smaller and more readable.
