# Issue #314066 — Terminal death recovery doesn't work

[https://github.com/microsoft/vscode/issues/314066](https://github.com/microsoft/vscode/issues/314066)

## Summary

Keep open: a maintainer confirmed the intermittent failure, and current source explicitly suppresses background exit notifications when the user closes a terminal. The lifecycle code has changed since the report; reconcile recovery expectations with intentional suppression before treating this team-authored issue as resolved.

## Change summary

After the user kills an agent terminal running npm run watch, the agent incorrectly believes the command is still running.

## Best solution

Keep the agent's terminal state accurate after termination without inadvertently restarting a command the user deliberately stopped. Retest closure before and after background notification registration, and decide whether user-initiated closure should update context silently or resume an agent turn.
