# Issue #203207 — User setup detects admin privileges incorrectly

[https://github.com/microsoft/vscode/issues/203207](https://github.com/microsoft/vscode/issues/203207)

## Summary

The admin detection logic in the user setup still relies on `native-is-elevated` which can produce false positives in locked-down enterprise environments with split UAC tokens. The code path is unchanged on current main, so the issue remains valid though niche.

## Change summary

VS Code user setup incorrectly detects admin privileges in enterprise environments, disabling auto-updates and potentially causing GPU-related startup failures.

## Best solution

Investigate whether `native-is-elevated` can be replaced or supplemented with a more reliable check for genuine elevation on Windows enterprise configurations with restricted UAC tokens. The fix would be in `src/vs/platform/native/electron-main/nativeHostMainService.ts` (the `isAdmin()` method).
