# Issue #340772 — Remote Agent Host sessions become undiscoverable after update to 1.141.0

[https://github.com/microsoft/vscode/issues/340772](https://github.com/microsoft/vscode/issues/340772)

## Summary

Team-authored, detailed report that Agent Host sessions created before a remote update can no longer be opened (the new runtime's session index is empty). I did not trace the code path in the checkout, so the cause is unconfirmed. It stays open: the item is team-authored and tied to a race with the update, so it is not closed on judgment.

## Change summary

After updating a remote Windows tunnel host to 1.141.0, existing Copilot CLI Agent Host sessions fail to open with 'Provider copilotcli is not ready' while new sessions work.

## Best solution

Make session discovery and migration after a host update retryable and non-destructive: rebuild the SDK session index from the intact session-state directories, and handle stale in-use locks from an orphaned old runtime. Check the issues the reporter cites (#339049, #340552) for overlap.
