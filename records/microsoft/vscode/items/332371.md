# Issue #332371 — unclear if how the session is reconciled when used between the two apps

[https://github.com/microsoft/vscode/issues/332371](https://github.com/microsoft/vscode/issues/332371)

## Summary

Keep open for an explicit multi-client session-semantics decision. The team-authored report demonstrates divergent live transcripts between VS Code and Copilot Desktop, and neither the linked test plan nor the current Sessions contract defines whether concurrent interaction is supported or how conflicts reconcile.

## Change summary

Define consistent transcript and context reconciliation when the same Agent Host session is continued concurrently from VS Code and Copilot Desktop.

## Best solution

Choose and document a multi-client contract for Agent Host chats: either maintain one authoritative ordered transcript that every connected client observes promptly, or enforce an explicit ownership/handoff model that prevents divergent concurrent turns. Then make reload and live-update behavior consistent with that contract.
