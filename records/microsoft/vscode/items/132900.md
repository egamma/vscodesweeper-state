# Issue #132900 — Add telemetry for extension host is detached

[https://github.com/microsoft/vscode/issues/132900](https://github.com/microsoft/vscode/issues/132900)

## Summary

A real telemetry gap remains on current main: startup success and failure are measured, but disconnect-runner state, socket closure, grace-time reduction, and termination causes are not emitted as telemetry. The only linked implementation PR was closed without merging, so there is no basis for a completed or duplicate close.

## Change summary

Add telemetry for extension-host readiness, renderer and socket disconnection, reconnection grace-time state, unhandled failures, and termination.

## Best solution

Extension-host owners should first decide which lifecycle signals remain operationally useful and define a privacy-compliant event schema, then add the selected measurements at the workbench/process boundary without transmitting unserializable promises or unrestricted error data.
