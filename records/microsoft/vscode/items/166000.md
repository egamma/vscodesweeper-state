# Issue #166000 — Timeline filename doesn't show when Timeline is moved to the bottom Panel

[https://github.com/microsoft/vscode/issues/166000](https://github.com/microsoft/vscode/issues/166000)

## Summary

Still reproduces on main: the Timeline view's filename (set via `updateTitleDescription`) is hidden when the view is merged with its container in the Panel, because the merged container header doesn't surface `titleDescription`. The original fix PR was reverted due to a double-header regression, and no alternative fix has landed.

## Change summary

Timeline view doesn't show the tracked filename when the view is moved to the Panel (or given its own view container), because view-container merging hides the view's title description.

## Best solution

Implement the alternative approach suggested by @benibenj in comment #5: show the filename as the first node in the tree (possibly as a sticky-scroll header), so it's visible regardless of where the view is hosted. This avoids the double-header regression that the reverted PR caused. The fix likely touches `src/vs/workbench/contrib/timeline/browser/timelinePane.ts` (rendering) and possibly `src/vs/workbench/browser/parts/views/viewPaneContainer.ts` (merging logic).
