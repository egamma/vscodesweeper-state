# Issue #166000 — Timeline filename doesn't show when Timeline is moved to the bottom Panel

[https://github.com/microsoft/vscode/issues/166000](https://github.com/microsoft/vscode/issues/166000)

## Summary

The bug remains on current main after the original fix was reverted: Timeline still stores the filename only in its hidden view-header description when its sole view is merged into a Panel container. Keep this accepted On Deck bug open and settle a Timeline-specific presentation that does not recreate the duplicate-header regression.

## Change summary

Keep the current or pinned Timeline filename visible when the Timeline view is moved into the bottom Panel or its own single-view container.

## Best solution

Show the Timeline's file context in a location that remains visible when the view header is merged, likely as Timeline-owned sticky list context, while retaining the Panel's single-header and single-action layout.
