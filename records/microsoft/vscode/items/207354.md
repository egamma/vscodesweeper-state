# Issue #207354 — Report Issue dialog does not work for the Jupter extension

[https://github.com/microsoft/vscode/issues/207354](https://github.com/microsoft/vscode/issues/207354)

## Summary

Keep open in issue-reporter: the supplied steps suffice to retest, and a maintainer identified unintended preview/auth behavior before the reporter confirmed persistence. The reporter implementation has since gained a separate wizard submission path, but source inspection does not establish that either path resolves the Jupyter template-chooser failure.

## Change summary

Previewing a Jupyter extension issue opens GitHub's template chooser without carrying the entered report into an issue draft.

## Best solution

Make the core issue reporter preserve the title and description through Jupyter's GitHub template-selection flow without requiring direct issue creation. First reproduce the browser handoff on current desktop VS Code and determine whether template routing or preview/auth state causes the failure.
