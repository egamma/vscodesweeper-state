# Issue #338415 — remote AH entries in recent folders do not show their remote

[https://github.com/microsoft/vscode/issues/338415](https://github.com/microsoft/vscode/issues/338415)

## Summary

Team-authored bug report (author is a COLLABORATOR) with no fix commit referencing this issue yet, so the hard keep-open rule for team-authored items applies regardless of other evidence; also a genuinely open, unverified defect worth tracking.

## Change summary

When a remote Agent Host tunnel workspace is opened via 'open in editor' and the editor window is later closed, the resulting recent-folder entry (and its Windows taskbar jump-list entry) doesn't show the remote tag other remote entries get.

## Best solution

Trace how recently-opened entries get their `remoteAuthority` for windows opened from an agent-host tunnel session (workspacesHistoryMainService.addRecentlyOpened is driven by `event.window.remoteAuthority` on IWorkspacesManagementMainService.onDidEnterWorkspace) and ensure that authority is populated/preserved for agent-host-tunnel-backed windows so the jump list label (getWindowsJumpListLabel) reflects it.
