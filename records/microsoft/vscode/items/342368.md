# Issue #342368 — Pressing Alt alone in an auxiliary window moves the focus to the main window's menu bar (Linux)

[https://github.com/microsoft/vscode/issues/342368](https://github.com/microsoft/vscode/issues/342368)

## Summary

Keep open: current source lets the main-window menubar react to Alt transitions originating in auxiliary windows and focus its own menu button. The report supplies concrete reproduction steps and window-activation logs; the older-version bot comment does not establish a fix.

## Change summary

Prevent Alt input in an auxiliary webview window from transferring focus to the main window's custom menubar, including when returning through Alt+Tab.

## Best solution

Keep keyboard-driven menubar activation local to the window receiving the input, preserving ordinary main-window Alt navigation and modifier handling elsewhere. Verify the auxiliary-webview Alt+Tab sequence on Linux/X11 alongside a regression test for cross-window Alt activation.
