# Issue #155762 — Move SimpleFindWidget into base

[https://github.com/microsoft/vscode/issues/155762](https://github.com/microsoft/vscode/issues/155762)

## Summary

The layering debt remains: SimpleFindWidget still lives in workbench, while tree and editor find widgets have separate implementations. Keep this accepted Backlog item open; the related filter-and-replace work does not cover the requested lower-layer extraction.

## Change summary

Make SimpleFindWidget reusable below workbench, retain service integration for higher-layer consumers, and reduce duplication with editor find.

## Best solution

Establish a service-independent shared find-widget surface usable from base, with higher-layer integration preserving existing find behavior. Plan the extraction boundary and input extensibility before migrating consumers, coordinating with the separate filter-and-replace consolidation request.
