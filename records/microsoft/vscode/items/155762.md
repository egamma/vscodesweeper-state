[https://github.com/microsoft/vscode/issues/155762](https://github.com/microsoft/vscode/issues/155762)

## Summary

SimpleFindWidget still lives in workbench/contrib — none of the three requested refactoring steps (move to base, allow service injection, have editor FindWidget extend it) have been done. The debt remains valid.

## Change summary

Move SimpleFindWidget from workbench/contrib into the base layer so it can be reused by list views and other base-layer components without layering violations.

## Best solution

Refactor SimpleFindWidget into src/vs/base (mirroring what was done for HoverWidget), with an optional service-injection extension point in platform/workbench, and unify the editor FindWidget on top of it. This is architectural debt that blocks cleaner find-widget reuse across layers.
