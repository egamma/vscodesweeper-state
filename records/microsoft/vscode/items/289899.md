# Issue #289899 — Don't ask to enable workspace trust in system folders and temp directories

[https://github.com/microsoft/vscode/issues/289899](https://github.com/microsoft/vscode/issues/289899)

## Summary

Keep open for the workspace-trust owner: current main suppresses startup prompts globally by default, but does not implement the requested folder-specific distinction. This changes a security-sensitive trust boundary, so a human should decide the remaining scope rather than proposing a close.

## Change summary

Suppress workspace-trust dialogs for temporary directories, home directories, and filesystem roots while retaining prompts where the decision is meaningful.

## Best solution

Determine whether the current global startup-prompt default satisfies the intended UX or whether folder-specific suppression remains necessary when prompting is enabled. Any suppression should preserve Restricted Mode and avoid implicitly trusting these directories or their descendants.
