# Issue #289899 — Don't ask to enable workspace trust in system folders and temp directories

[https://github.com/microsoft/vscode/issues/289899](https://github.com/microsoft/vscode/issues/289899)

## Summary

Valid feature request from a contributor. No implementation exists on current main — the workspace trust calculation in workspaceTrust.ts has no special handling for system folders, home directories, or temp directories. The request remains open.

## Change summary

Skip the workspace trust dialog when opening well-known system folders (e.g. `/tmp/`, `~/`, `C:\`) where the trust decision is not meaningful.

## Best solution

Add logic in `WorkspaceTrustManagementService.calculateWorkspaceTrust()` (src/vs/workbench/services/workspaces/common/workspaceTrust.ts) to implicitly trust well-known system and temp directories, or suppress the trust banner/dialog for them. The list of implicitly-trusted path prefixes should be platform-aware (e.g. `/tmp`, `os.tmpdir()`, home directory, filesystem roots).
