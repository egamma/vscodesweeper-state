# Issue #64657 — Way to Re-enter Context of the Placeholder Tab Progression While Using Snippets

[https://github.com/microsoft/vscode/issues/64657](https://github.com/microsoft/vscode/issues/64657)

## Summary

A real snippet-workflow gap remains on current main: leaving a placeholder disposes the session, so undo cannot restore tab-stop progression. Keep the Backlog request open for product discussion.

## Change summary

Allow undo to restore an accidentally exited snippet session at its previous placeholder.

## Best solution

Preserve enough snippet-session and placeholder state to restore progression when undo returns to the preceding edit, without changing explicit Escape or final-tab-stop cancellation.
