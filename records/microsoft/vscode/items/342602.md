# Issue #342602 — v143 picked up a lot of `done` sessions from outside of the profile being used

[https://github.com/microsoft/vscode/issues/342602](https://github.com/microsoft/vscode/issues/342602)

## Summary

Keep open: current main still surfaces archived, un-adopted legacy Copilot CLI sessions when migration is enabled, matching the maintainer's diagnosis. The maintainer has explicitly committed to withholding these sessions until the extension-host provider is retired; this is not a session-database upgrade failure.

## Change summary

Prevent archived legacy Copilot CLI sessions from other VS Code windows from unexpectedly appearing in the Agents window's Done list before adoption.

## Best solution

Honor the maintainer's stated direction by withholding un-adopted legacy CLI sessions from Agents-window listings while retaining native and already-adopted sessions. Proper scoping must be established before exposing those legacy sessions when the extension-host provider is retired.
