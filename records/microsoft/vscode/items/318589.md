# Issue #318589 — MCP servers for custom agents from copilot CLI don't start

[https://github.com/microsoft/vscode/issues/318589](https://github.com/microsoft/vscode/issues/318589)

## Summary

Keep open: another reporter confirmed the plugin variant, and current source still contains an agent-conversion path that omits embedded MCP definitions. Agent Host mitigation is not sufficient evidence of resolution, and no qualifying fix or canonical duplicate was established.

## Change summary

MCP servers declared in a Copilot CLI custom agent's YAML frontmatter do not start when that agent is selected in VS Code, including agents installed through plugins.

## Best solution

Ensure selecting a CLI-compatible custom agent preserves its embedded MCP configuration and makes its tools usable, for both personal agents and plugin agents. First establish which current harness paths still fail and distinguish native SDK discovery from VS Code's explicit agent conversion.
