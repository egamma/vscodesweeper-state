- **Behavior:**

  > Pressing Delete while nonempty text is selected in an editable editor should remove that selection. The reporter observes no effect on Windows 11 24H2 with VS Code 1.98.2, despite Backspace working and extensions being removed. Acceptance requires physical-key deletion to work, not merely successful direct invocation of the editing command. Existing Backspace, ordinary forward deletion, and read-only behavior must remain unchanged.
- **Trace:**

  > Current src/vs/editor/browser/coreCommands.ts registers CoreEditingCommands.DeleteRight for KeyCode.Delete with textInputFocus and dispatches to DeleteOperations.deleteRight. In src/vs/editor/common/cursor/cursorDeleteOperations.ts, getDeleteRightRange preserves nonempty selections and deleteRight builds an empty-string ReplaceCommand, so the inspected selection-handling path does not explain the failure. Investigation must first distinguish keyboard-event delivery and keybinding resolution from command execution; no runtime reproduction was performed in this read-only review. src/vs/editor/test/browser/controller/cursor.test.ts contains existing DeleteRight command coverage, but command-only coverage cannot prove physical-key dispatch. Keep unrelated keyboard layouts and platform-specific numpad behavior outside the fix unless reproduction establishes a connection.
