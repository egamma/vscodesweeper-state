# Issue #245002 — Vim write (:w) does not invoke Python Black 'editor.formatOnSave' on Mac

[https://github.com/microsoft/vscode/issues/245002](https://github.com/microsoft/vscode/issues/245002)

## Summary

Confirmed bug with root cause identified by a team member: when auto-save is enabled, an explicit `document.save()` call (e.g. from Vim's `:w`) short-circuits because the file is already not dirty, skipping save participants including format-on-save. Still unfixed on main.

## Change summary

When auto-save is enabled, Vim's `:w` (which calls `document.save()`) does not trigger format-on-save because the file is already saved and not dirty.

## Best solution

The early return in `textFileEditorModel.ts` at the `!options.force && !this.dirty` guard needs to still run save participants (format-on-save) for explicit save requests even when the model is not dirty. The fix should distinguish between auto-save (no participation needed) and explicit API-driven saves (participation expected).
