# Issue #245002 — Vim write (:w) does not invoke Python Black 'editor.formatOnSave' on Mac

[https://github.com/microsoft/vscode/issues/245002](https://github.com/microsoft/vscode/issues/245002)

## Summary

Keep open: the discussion identifies Auto Save as the missing trigger, and current source still explains why Vim's document.save() can skip formatting while File > Save works. This is not established as a Mac-only or third-party-extension defect.

## Change summary

Vim's :w fails to trigger format-on-save after Auto Save has already cleared the document's dirty state.

## Best solution

Make an explicit Vim write reliably provide the expected formatting behavior after Auto Save, while preserving ordinary automatic-save behavior. Maintainers should settle whether this belongs in the public document.save() contract or in explicit-save command usage before changing behavior for all extension callers.
