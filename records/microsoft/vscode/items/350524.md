# Issue #350524 — Color picker writes `rgb()` for short hex, named colors and opaque `hsla()`

[https://github.com/microsoft/vscode/issues/350524](https://github.com/microsoft/vscode/issues/350524)

## Summary

The current source confirms that short hex and opaque hsla() lose their notation family when the picker opens. Keep this team-authored bug open; named-color fallback still needs a product decision.

## Change summary

Preserve the original color notation family when selecting and applying a color presentation.

## Best solution

Make the shared color picker retain hex and HSL families when providers offer equivalent presentations, without requiring exact original spelling. Decide the fallback for named colors separately from palette support and modern CSS syntax.
