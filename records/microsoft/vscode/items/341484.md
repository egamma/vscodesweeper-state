# Issue #341484 — Agent Host (Copilot CLI): OAuth MCP server token never re-acquired after mid-session 401 — tools silently unavailable until new session

[https://github.com/microsoft/vscode/issues/341484](https://github.com/microsoft/vscode/issues/341484)

## Summary

Keep open: the report and follow-up establish loss of existing-session MCP access after a 401. Current source supports refresh callbacks, but no verified fix establishes that runtime catalog failures actually trigger them.

## Change summary

Recover OAuth-protected MCP tools in an existing Copilot Agent Host conversation after token expiry instead of repeatedly retrying with stale credentials.

## Best solution

Establish where the runtime's mid-session OAuth challenge stops reaching the host authentication bridge, then restore same-conversation authentication and tool availability. Preserve VS Code-owned credentials and surface an actionable authentication requirement when silent recovery fails.
