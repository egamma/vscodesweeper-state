# Issue #341484 — Agent Host (Copilot CLI): OAuth MCP server token never re-acquired after mid-session 401 — tools silently unavailable until new session

[https://github.com/microsoft/vscode/issues/341484](https://github.com/microsoft/vscode/issues/341484)

## Summary

Keep open: the detailed expiry logs and independent confirmation establish a mid-session MCP recovery failure. Current source handles SDK-issued refresh requests, but does not establish that catalog-level 401s reach that callback or restore tools in an existing conversation.

## Change summary

Restore OAuth-protected MCP tools in an existing Agent Host conversation after token expiry or successful reauthentication, without requiring a new conversation.

## Best solution

Establish where the runtime's catalog-level OAuth challenge stops reaching VS Code's authentication flow, then ensure successful authentication restores the affected conversation's tools. Preserve VS Code ownership of durable credentials and avoid automatically replaying side-effecting tool calls.
