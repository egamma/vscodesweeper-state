# Issue #246645 — VScode read Right Alt key as AltGr key in sometime

[https://github.com/microsoft/vscode/issues/246645](https://github.com/microsoft/vscode/issues/246645)

## Summary

A VS Code team member (alexdima) has explained that certain keyboard layouts designate the Right Alt key as AltGr by design — this is determined by the active Windows keyboard layout, not by VS Code. The `keyboard.mapAltGrToCtrlAlt` setting exists as the intended workaround. The intermittent nature likely reflects Windows switching between keyboard layouts (which can happen silently). Proposing close as as-designed.

## Change summary

Right Alt key is intermittently treated as AltGr, preventing Alt+key shortcuts from working when using Right Alt.

## Best solution

This is governed by the active Windows keyboard layout. Users whose layout maps Right Alt to AltGr can enable `keyboard.mapAltGrToCtrlAlt` to treat AltGr combinations as Ctrl+Alt, or switch to a layout that doesn't repurpose Right Alt. The intermittent behavior is likely caused by Windows automatically switching the active keyboard layout.

As Alex explained, this behavior comes from the active Windows keyboard layout: when your system switches to a layout that designates Right Alt as AltGr (which Windows can do silently via the language bar or keyboard shortcuts like Win+Space), VS Code correctly honors that mapping. To prevent the intermittent switching, you can also lock your Windows input method to a single keyboard layout (Settings → Time & Language → Typing → Advanced keyboard settings).
