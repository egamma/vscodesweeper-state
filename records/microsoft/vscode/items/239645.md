# Issue #239645 — `stopAll` in compound launch.json should show default action as stop, not disconnect

[https://github.com/microsoft/vscode/issues/239645](https://github.com/microsoft/vscode/issues/239645)

## Summary

Keep open: the toolbar still chooses Disconnect from the focused session's attach status without considering the compound's stopAll setting. The reported configuration remains present, and the existing Stop alternative does not resolve the incorrect default.

## Change summary

Make Stop the primary debug toolbar action for stopAll compounds, including when an attach session is focused.

## Best solution

Present Stop consistently as the primary toolbar action for stopAll compounds while preserving ordinary attach-session behavior outside those compounds. Retain existing secondary actions rather than expanding this fix into the optional removal of Disconnect.
