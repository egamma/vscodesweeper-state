# Issue #127 — Provide option to opt out of line ending normalisation for files

[https://github.com/microsoft/vscode/issues/127](https://github.com/microsoft/vscode/issues/127)

## Summary

This remains the canonical, highly supported request for preserving mixed line endings. Current main still normalizes them, and the Backlog milestone plus 139 community upvotes strongly support keeping it open.

## Change summary

Add an option to preserve each existing line-ending sequence instead of normalizing the entire file when it is edited.

## Best solution

Introduce a preservation mode that retains original separators while using the predominant or configured EOL for newly inserted lines. Thread it through text-file model creation into the piece-tree buffer and cover mixed CR, LF, and CRLF load-edit-save behavior.
