# Issue #296319 — Persistent suggestions about already-committed changes from different branches

[https://github.com/microsoft/vscode/issues/296319](https://github.com/microsoft/vscode/issues/296319)

## Summary

Keep open to investigate stale chat-edit review state across terminal-driven branch changes. The editing implementation has evolved since 1.109.4, but still persists pending snapshots; the reported commit, branch-switch, and reload sequence supplies enough detail to retest without requesting more information.

## Change summary

Already-committed chat edits remain marked Keep/Undo after switching Git branches and restarting VS Code.

## Best solution

Make chat-edit review state reconcile safely with externally committed work and branch changes, without treating old snapshots as pending edits in an unrelated branch. Preserve review of genuinely outstanding edits and avoid requiring Undo or destructive Git commands to dismiss stale state.
