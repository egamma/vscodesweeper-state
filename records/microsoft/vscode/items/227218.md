## Change summary

Moving a line through commented braces or switch cases unexpectedly changes the indentation of surrounding lines.

## Best solution

Make repeated line moves preserve the logical indentation of displaced comments and switch cases while retaining appropriate indentation adjustment for the selected line. Establish current regression cases in the move-lines command suite before changing the shared indentation behavior.
