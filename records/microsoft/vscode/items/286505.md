# Issue #286505 — Fish integration `__vsc_nonce` is broken

[https://github.com/microsoft/vscode/issues/286505](https://github.com/microsoft/vscode/issues/286505)

## Summary

Verified duplicate of the older, confirmed, and labeled issue #183972 which tracks the same root cause — the fish nonce variable is set with local scope (`set -l`) instead of global (`set -g`), making it empty when referenced in functions.

## Change summary

Fish shell integration sets `__vsc_nonce` with local scope (`set -l`), so it's empty when referenced in `__vsc_cmd_executed` and `__vsc_cmd_clear` functions.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/183972, which is the older canonical issue already confirmed and labeled `help wanted`. The fix is changing `set -l` to `set -g` on line 106 of `shellIntegration.fish`.
