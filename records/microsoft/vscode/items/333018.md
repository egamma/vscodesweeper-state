# Issue #333018 — Side chats don't allow multiple modes

[https://github.com/microsoft/vscode/issues/333018](https://github.com/microsoft/vscode/issues/333018)

## Summary

Keep open: current source still stores and changes Plan/Interactive mode at session scope, confirming the reported coupling between chats. The separate failure to respond while the main chat awaits plan approval remains unverified; no verified duplicate or issue-referencing fix supports closing this team-authored report.

## Change summary

Allow a side chat to discuss a pending plan in Interactive mode without changing the main chat's mode or disturbing its approval flow.

## Best solution

Make the selected chat's operating mode independent while preserving the main chat's pending plan approval. Coordinate the protocol and configuration boundary with the related per-chat configuration work, then verify the pending-approval scenario end to end.
