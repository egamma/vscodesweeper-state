# Issue #51806 — Add DecorationRangeBehavior.Word

[https://github.com/microsoft/vscode/issues/51806](https://github.com/microsoft/vscode/issues/51806)

## Summary

The requested DecorationRangeBehavior.Word has not been implemented — the enum still has only the four original open/closed variants. This is a valid API feature request filed by a prolific extension author (mjbvz), but it has very low community traction (2 upvotes over 7 years) and no maintainer discussion. Keeping open on its merits as an unresolved API gap.

## Change summary

Add a word-aware DecorationRangeBehavior variant that expands a decoration only when word characters are typed at its edges, not when non-word characters are typed.

## Best solution

If the team considers this worthwhile, add a `Word` (or `GrowsOnlyOnWordBoundary`) value to `TrackedRangeStickiness` in the editor text buffer layer, with corresponding `DecorationRangeBehavior.Word` in the extension API. The implementation would live in the piece-tree / text-buffer range-tracking logic. Given very low community signal, this could also be closed through the normal community-process stale path.
