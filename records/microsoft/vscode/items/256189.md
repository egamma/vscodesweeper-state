# Issue #256189 — Impove Source Control to fast review ai generated code: option to set hotkey for stage/unstage block

[https://github.com/microsoft/vscode/issues/256189](https://github.com/microsoft/vscode/issues/256189)

## Summary

Keyboard-bound Stage Block is now implemented, and multi-file diff navigation covers much of the requested review workflow. Keep this accepted Backlog request open because whole-block unstaging is not symmetrically available from the cursor, and the verified older issues do not fully cover its scope.

## Change summary

Enable keyboard-only review of generated Git changes, including block staging/unstaging and navigation between changed files.

## Best solution

Complete symmetric whole-hunk staging and unstaging from the keyboard, building on the existing cursor-based Stage Block command and multi-file diff navigation. Keep unstaging distinct from discarding edits, which already has a separate keyboard-accessible command.
