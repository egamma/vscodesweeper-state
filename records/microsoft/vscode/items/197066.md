# Issue #197066 — Configurable styling of the indent guide line

[https://github.com/microsoft/vscode/issues/197066](https://github.com/microsoft/vscode/issues/197066)

## Summary

Keep this accepted Backlog request open: current guide settings support visibility and highlighting, but not dashed strokes or configurable thickness. The older matching request is closed, and the overlapping open bracket-guide request is newer, so neither qualifies as a duplicate canonical.

## Change summary

Allow users to configure indentation-guide line style and thickness, including dashed lines.

## Best solution

Have the editor guide owners decide on a supported styling contract that preserves consistent defaults and theme colors across indentation and bracket guides. Coordinate the overlapping bracket-guide request without replacing this older report with a newer canonical.
