# Issue #247247 — can the fullscreen mode AT LEAST display a button to exit fullscreen mode?

[https://github.com/microsoft/vscode/issues/247247](https://github.com/microsoft/vscode/issues/247247)

## Summary

Keep open for discussion of a discoverable fullscreen exit control. Existing shortcuts, menu settings, and layout controls offer escape routes, but do not fully cover discovering how to exit after the menu bar disappears.

## Change summary

Provide a discoverable mouse-accessible control for exiting fullscreen when the menu bar is hidden.

## Best solution

Decide whether fullscreen should expose an exit control on demand, such as when the pointer reaches the top edge, without requiring prior configuration or shortcut knowledge. Preserve intentional fullscreen chrome hiding and treat the web Zen-mode synchronization report as separate work.
