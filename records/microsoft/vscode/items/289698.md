# Issue #289698 — Don't hardcode `untitled-` external chat session URI paths

[https://github.com/microsoft/vscode/issues/289698](https://github.com/microsoft/vscode/issues/289698)

## Summary

Still open: the hardcoded `untitled-` URI path pattern remains in at least 5 production files on current main, with no commits referencing this issue. The debt is real and unfixed.

## Change summary

Core chat code hardcodes `untitled-` URI paths for new/blank chat sessions instead of letting extensions control session URIs.

## Best solution

Introduce a proper API (or extend the existing session provider contract) so extensions supply session URIs for new/blank sessions, then remove all hardcoded `/untitled-${generateUuid()}` constructions from core. Key files: `chatClear.ts`, `chatNewActions.ts`, `chatActions.ts`, `chatSessions.contribution.ts`, `constants.ts`, `chatUri.ts`, and the agent host provisional session service.
