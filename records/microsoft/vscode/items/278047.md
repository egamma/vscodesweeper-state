# Issue #278047 — Keyboard Shortcuts overriden

[https://github.com/microsoft/vscode/issues/278047](https://github.com/microsoft/vscode/issues/278047)

## Summary

Verified duplicate of #293802, which was fixed in commit 68bc772a99c (shipped in 1.116.0). The fix makes keybinding removals resilient to when-clause changes across updates — exactly the scenario described here.

## Change summary

User keybinding removals (negative bindings) stop working after VS Code updates when the default keybinding's when clause becomes more specific.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/293802 which is closed/verified with the fix in commit 68bc772a99c. The reporter should update to 1.116+ to get the fix.
