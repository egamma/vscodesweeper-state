# Issue #278047 — Keyboard Shortcuts overriden

[https://github.com/microsoft/vscode/issues/278047](https://github.com/microsoft/vscode/issues/278047)

## Summary

The core issue — keybinding removals not surviving updates when the default when clause changed — was fixed in commit 68bc772a99c (milestone 1.116.0). The fix switched from strict equality to implication matching, so user removals remain effective even when the default when clause becomes more specific across versions.

## Change summary

User keybinding removals (negative entries in keybindings.json) stop working after VS Code updates when the system default when clause for that command changes.

## Best solution

Keep the shipped fix in commit 68bc772a99c (1.116.0). The keybinding resolver now uses implication-based matching for removals, so a removal targeting a broader when clause still applies when the default becomes more specific. If entirely new commands are registered with the same shortcut, those are separate bindings that need their own removal — that is by design.
