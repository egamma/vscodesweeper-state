# Issue #23921 — Symbol outline multi-line highlight is visually inconsistent when interleaved with code lens

[https://github.com/microsoft/vscode/issues/23921](https://github.com/microsoft/vscode/issues/23921)

## Summary

The visual inconsistency remains structurally possible on current main: symbol navigation highlights model lines, while CodeLens occupies a separate view zone. This is valid editor polish but needs a UX and implementation decision.

## Change summary

Extend a multi-line symbol-outline highlight across interleaved CodeLens view zones.

## Best solution

Decide whether editor range decorations should visually cover interleaved view zones, then implement the behavior generically in the editor/view-zone layer rather than special-casing symbol navigation.
