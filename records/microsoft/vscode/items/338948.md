# Issue #338948 — Modern UI - Connected Tabs hover background alignment discrepancy

[https://github.com/microsoft/vscode/issues/338948](https://github.com/microsoft/vscode/issues/338948)

## Summary

Traced to a real seam in the Modern UI connected-tab CSS: the close-button overlay (`.tab-actions`) is forced transparent in connected-tabs-labels mode, but its blending `::before` gradient still fades toward the opaque `modernEditorTab.hoverActionBackground` color, so a visible patch shows through whenever the tab's own hover background is semi-transparent. Keeping open as a confirmed, if niche, styling bug in an actively-developed experimental feature.

## Change summary

When Modern UI's 'connected' editor tab style is used with a semi-transparent `modernTab.hoverBackground`, a misaligned/extra background patch appears behind the tab close button on hover.

## Best solution

In src/vs/workbench/contrib/modernUI/browser/media/tabs.css, make the `.tab-actions::before` hover gradient consistent with the `--modern-ui-editor-tab-action-overlay-background: transparent` override that `.connected-tabs-labels` already applies to the box itself, so the fade doesn't end in an opaque color that shows through the semi-transparent tab background.
