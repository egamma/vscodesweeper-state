# Issue #343489 — Cmd+C copy shortcut freezes

[https://github.com/microsoft/vscode/issues/343489](https://github.com/microsoft/vscode/issues/343489)

## Summary

Keep open: current main restores a previously focused input before copying a selection in non-editable webview content, matching the reported selection loss and focus jump. Independent reports across extensions and platforms support a core webview regression, not an extension-specific failure.

## Change summary

Copying selected webview response text moves focus to the composer and fails to copy after upgrading to 1.143.0.

## Best solution

Preserve the user's selected webview text through keyboard and context-menu Copy while retaining legitimate editable-focus restoration for native commands. Cover both behaviors in the webview shell messaging tests.
