# Issue #343489 — Cmd+C copy shortcut freezes

[https://github.com/microsoft/vscode/issues/343489](https://github.com/microsoft/vscode/issues/343489)

## Summary

Keep open: the current webview shell restores a previously focused input before copying, without checking whether rendered text is selected. This matches the reported focus jump and failed copy, with independent confirmations across extensions and operating systems.

## Change summary

Copying selected rendered webview text moves focus to the composer and loses the selection instead of copying it.

## Best solution

Preserve rendered-text selections when webview clipboard commands execute, while retaining the existing restoration of editable targets when needed for native editing commands.
