# Issue #162508 — Git - Better handling (documentation) of background git commands and password prompting

[https://github.com/microsoft/vscode/issues/162508](https://github.com/microsoft/vscode/issues/162508)

## Summary

Keep open: existing authentication settings and troubleshooting documentation only partially address the request. The distinction between background and interactive authentication remains poorly explained, and the SSH failure shown does not trigger the existing autofetch suspension logic.

## Change summary

Clarify VS Code's Git/SSH authentication environment and improve background-fetch behavior and error reporting when renewable credentials expire.

## Best solution

Provide user-facing documentation distinguishing Source Control commands, silent autofetch, and integrated-terminal authentication, including the limits of SSH password prompting. Agree on the scope of targeted authentication-retry and error-reporting improvements without changing ordinary command-line Git behavior or introducing Kerberos-specific policy by default.
