# Issue #304581 — [BUG] VS Code Hangs when elicitation is requested with empty schema (i.e. user info not requested)

[https://github.com/microsoft/vscode/issues/304581](https://github.com/microsoft/vscode/issues/304581)

## Summary

The empty-schema hang remains source-reproducible on current main in the inline chat MCP elicitation path. The issue should stay open and route to the MCP/chat owners.

## Change summary

An MCP form elicitation with no schema properties leaves the tool call waiting indefinitely instead of presenting an accept/decline confirmation or completing with an explicit error.

## Best solution

Handle a valid empty form schema as a message-only confirmation in McpElicitationService, matching the existing non-chat fallback: accepting returns an empty content object, while cancellation or rejection returns the corresponding MCP action without leaving the tool call pending.
