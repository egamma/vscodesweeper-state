## Summary

The requested consolidation remains undone: ElementSizeObserver still measures CSS dimensions, while both GPU consumers use the separate device-pixel helper. Keep this bounded cleanup open under its existing debt and editor-gpu labels.

## Change summary

Consolidate device-pixel dimension observation from observeDevicePixelDimensions into ElementSizeObserver.

## Best solution

Provide shared CSS- and device-pixel size observation through ElementSizeObserver, preserving existing layout behavior and the GPU renderer's exact physical-pixel measurements without maintaining a separate GPU-specific observer.
