# Issue #235944 — Cell execution time verbosity - Time and Date formatting (internationalization)

[https://github.com/microsoft/vscode/issues/235944](https://github.com/microsoft/vscode/issues/235944)

## Summary

The request for configurable/locale-aware date and time formatting in notebook cell execution timestamps remains unimplemented. The existing `notebook.cellExecutionTimeVerbosity` setting controls what is shown but not the format, and a recent commit (4c41ee7baaf) actually hardcoded 24-hour format rather than respecting locale or offering configuration. Keeping open as a valid feature request in the Backlog.

## Change summary

Allow users to configure the date/time format (or respect system locale) for notebook cell execution timestamps in the status bar.

## Best solution

Add a setting (e.g. `notebook.cellExecutionTimeFormat`) that lets users choose between locale-default, ISO, 24-hour, or 12-hour time formatting for cell execution timestamps. The change would be localized to `executionStatusBarItemController.ts` in the `_getTimeItem` method. Alternatively, remove the `{ hour12: false }` override and let the platform locale drive the format, which would partially address the request with no new setting.
