[https://github.com/microsoft/vscode/issues/235944](https://github.com/microsoft/vscode/issues/235944)

## Summary

Keep open: notebook execution timestamps still use the UI language rather than independently configurable regional formatting. The existing verbosity setting does not cover the request, and no older open issue owning the same observable problem was identified.

## Change summary

Allow notebook cell execution timestamps to follow regional preferences or a configurable date/time format.

## Best solution

Define notebook execution timestamp formatting independently of the display language, consistently across the cell status bar and its tooltip. Decide whether honoring regional preferences satisfies the request or whether an explicit ISO/custom-format option is also needed.
