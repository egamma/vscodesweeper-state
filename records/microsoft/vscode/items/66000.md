# Issue #66000 — Scroll bar visibility should be configurable

[https://github.com/microsoft/vscode/issues/66000](https://github.com/microsoft/vscode/issues/66000)

## Summary

Keep open in the Backlog: the editor gained visibility settings, but the requested application-wide control remains missing. The request also has 21 community upvotes, meeting the Backlog threshold.

## Change summary

Provide a global setting that keeps scrollbars visible throughout the editor, Explorer, terminal, debug views, and other scrollable workbench surfaces.

## Best solution

Introduce a global scrollbar visibility preference at the shared ScrollableElement layer and adopt it consistently across workbench surfaces, while defining precedence for editor-specific settings. Respect the operating-system accessibility preference if Electron exposes a reliable API.
