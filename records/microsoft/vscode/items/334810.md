# Issue #334810 — perf(eslint): cache package.json read in AMD module import rule

[https://github.com/microsoft/vscode/issues/334810](https://github.com/microsoft/vscode/issues/334810)

## Summary

Confirmed on main: `.eslint-plugin-local/code-amd-node-module.ts` reads and parses `package.json` inside `create(context)`, which ESLint invokes per linted file, causing repeated redundant disk I/O. A PR already targets this fix, so the issue should stay open pending review/merge rather than being closed or auto-fixed here.

## Change summary

The AMD module import ESLint rule re-reads and re-parses package.json on every file instead of caching it once at module scope.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/334811 (or the author's proposed fix), moving the package.json read/parse to module scope in .eslint-plugin-local/code-amd-node-module.ts.
