# Issue #334810 — perf(eslint): cache package.json read in AMD module import rule

[https://github.com/microsoft/vscode/issues/334810](https://github.com/microsoft/vscode/issues/334810)

## Summary

Confirmed on main: the AMD-module-import ESLint rule reads and JSON-parses package.json inside create(), which runs once per linted file — a genuine, if narrow, dev-tooling perf issue. An open PR already targets the fix, so this should stay open pending that PR landing rather than being auto-fixed or closed.

## Change summary

Move the repeated package.json readFileSync/JSON.parse in the AMD-module-import ESLint rule out of create() so it only runs once per lint session instead of per file.

## Best solution

Land (or review) the linked fix PR https://github.com/microsoft/vscode/pull/334811, which hoists the package.json read to module scope in .eslint-plugin-local/code-amd-node-module.ts; no further product decision is needed.
