# Issue #315781 — GitHub-cli session gets automatically moved under parent git directory

[https://github.com/microsoft/vscode/issues/315781](https://github.com/microsoft/vscode/issues/315781)

## Summary

Keep open: current source still turns a selected repository subfolder into the parent repository's workspace group when Copilot project metadata arrives. The provider architecture has changed since the report, but the folder-to-parent grouping path remains; no verified canonical or fixing commit was found.

## Change summary

A Copilot CLI session started in a repository subfolder moves from that folder's section to the parent repository's section in the Agents Window.

## Best solution

Preserve the selected subfolder's session-list identity for ordinary folder-backed sessions while retaining the parent repository association for Git operations. Genuine worktree sessions should retain their existing repository grouping.
