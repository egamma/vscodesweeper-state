[https://github.com/microsoft/vscode/issues/274199](https://github.com/microsoft/vscode/issues/274199)

## Summary

The image preview intermittently fails over remote connections (SSH, WSL2, remote-tunnel). The only merged PR (#282279) added diagnostic logging, not a fix — the underlying issue remains open and confirmed by multiple users.

## Change summary

Images fail to display in the built-in image preview with 'An error occurred while loading the image', especially over remote connections.

## Best solution

Investigate the root cause of intermittent image load failures in the media-preview webview over remote connections. The diagnostic logging from PR #282279 should help — next step is collecting those console errors from affected users to identify whether this is a resource URI issue, a webview content security policy problem, or a connection/timeout issue in the remote file transfer path.
