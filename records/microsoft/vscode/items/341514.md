# Issue #341514 — Claude custom endpoint (Messages API): 400 "thinking block bound to a different conversation" mid-turn in long agent tool loops

[https://github.com/microsoft/vscode/issues/341514](https://github.com/microsoft/vscode/issues/341514)

## Summary

Thanks for the detailed report. The steps, logs and versions are complete, and the reporter confirmed the error persists on 1.141.1. I did not trace the history-replay path or confirm the defect from source, so it stays open for an owner to retest.

## Change summary

In long Messages-API tool loops with thinking enabled, the replayed history differs from what was originally sent, so Anthropic rejects the thinking-block signature with a 400 and the retries resend the same body.

## Best solution

Make replayed assistant and thinking history byte-identical to what was originally sent, and on this specific 400 retry once with the rejected thinking blocks dropped instead of resending the same body.
