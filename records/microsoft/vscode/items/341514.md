# Issue #341514 — Claude custom endpoint (Messages API): 400 "thinking block bound to a different conversation" mid-turn in long agent tool loops

[https://github.com/microsoft/vscode/issues/341514](https://github.com/microsoft/vscode/issues/341514)

## Summary

Keep this as the canonical BYOK thinking-signature investigation: independent reports confirm failed agent turns across Foundry, Bedrock, and direct Claude API access. Current source does not establish a fix, and the exact history mutation still needs diagnosis.

## Change summary

Long Claude BYOK tool loops fail when replayed thinking signatures no longer match their conversation prefix, and repeated retries do not recover.

## Best solution

Make the Copilot Messages API path preserve the conversation prefix associated with retained signed thinking, with bounded recovery when a provider rejects that binding. Diagnose the first changed request block and retain provider compatibility, tool-call pairing, and existing context-budget behavior.
