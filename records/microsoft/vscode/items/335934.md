# Issue #335934 — Support showing a markdown plan with comment features for Claude harness

[https://github.com/microsoft/vscode/issues/335934](https://github.com/microsoft/vscode/issues/335934)

## Summary

Confirmed on main: `buildExitPlanModeConfirmationState` in claudeInteractiveTools.ts still reads `input.plan`, a field the pinned `@anthropic-ai/claude-agent-sdk@0.3.258` no longer sends, so the confirmation card falls back to an empty plan. An open PR (#336288) already reworks this to use the shared plan-review widget, so the fix is in flight — keep the issue open for that PR to land.

## Change summary

Claude's ExitPlanMode confirmation shows an empty/plain-text plan instead of the annotatable markdown plan-review widget other agents (Copilot CLI/GitHub harness) use.

## Best solution

Land https://github.com/microsoft/vscode/pull/336288 (or an equivalent fix) that switches Claude's ExitPlanMode handling to emit the provider-agnostic `planReview` payload consumed by the workbench plan-review widget, replacing the current `input.plan`-based confirmation card in src/vs/platform/agentHost/node/claude/claudeInteractiveTools.ts.
