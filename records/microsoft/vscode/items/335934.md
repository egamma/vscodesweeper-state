# Issue #335934 — Support showing a markdown plan with comment features for Claude harness

[https://github.com/microsoft/vscode/issues/335934](https://github.com/microsoft/vscode/issues/335934)

## Summary

Real, well-scoped gap confirmed in the checkout: the Claude harness's ExitPlanMode handler renders a plain 2-button Approve/Deny confirmation card, not the richer markdown plan view with Implement/Autopilot actions that Copilot CLI sessions get — this is a known, deliberately deferred simplification, not yet filed as its own tracked item.

## Change summary

Claude harness sessions should show the plan in the same rich, annotatable markdown plan view with action buttons (Implement, Autopilot, etc.) that Copilot CLI sessions already get, instead of a plain text dump with a 2-button approve/deny card.

## Best solution

Extend src/vs/platform/agentHost/node/claude/claudeCanUseTool.ts's handleExitPlanMode (and claudeInteractiveTools.ts's buildExitPlanModeConfirmationState) to route through the same rich plan-review surface Copilot CLI sessions use (mirroring extensions/copilot/.../exitPlanModeHandler.ts and its vscode_reviewPlan tool), replacing the current simple pending_confirmation Approve/Deny card; this is exactly the 'richer IExitPlanModeResponse shape' the team's own phase7-plan.md already flags as deferred.
