# Issue #335934 — Support showing a markdown plan with comment features for Claude harness

[https://github.com/microsoft/vscode/issues/335934](https://github.com/microsoft/vscode/issues/335934)

## Summary

Confirmed on main: `buildExitPlanModeConfirmationState` in claudeInteractiveTools.ts reads `input.plan`, but the pinned Claude Agent SDK (0.3.258, per package.json) no longer sends a `plan` field on `ExitPlanModeInput`, so the confirmation card falls back to an empty markdown body instead of the rich plan-review widget. An open PR already targets this exact fix, so this should stay open pending that PR rather than being treated as something for an agent to pick up fresh.

## Change summary

Claude's ExitPlanMode confirmation shows a blank/empty plan instead of the markdown plan-review widget with approve/annotate UI that other agent harnesses (Copilot CLI, GitHub) get.

## Best solution

Land https://github.com/microsoft/vscode/pull/336288 ("Use the plan review widget for Claude ExitPlanMode"), which should source the plan content correctly (e.g. from the written plan file) and route it through the existing provider-agnostic `planReview` payload used by other agents.
