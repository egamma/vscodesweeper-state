## Change summary

With MiMo-V2.6-Pro via a PrimaLabs Custom Endpoint (BYOK Chat Completions), the assistant's final answer is split mid-sentence: the first half is hidden inside the collapsed 'Completed N steps' disclosure and only the continuation shows as the visible answer.

## Best solution

Once a raw SSE capture of an affected response is available, trace whether the 'final response' heuristic in chatListRenderer.ts (getFinalResponseStartIndex, which only treats a trailing *contiguous* run of markdownContent parts as the final answer) is incorrectly splitting a continuous answer because an unrelated content part lands between two markdown segments for this vendor's stream shape.
