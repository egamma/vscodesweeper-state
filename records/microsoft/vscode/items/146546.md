# Issue #146546 — Request of new feature: Format On Delay.

[https://github.com/microsoft/vscode/issues/146546](https://github.com/microsoft/vscode/issues/146546)

## Summary

The delayed-format behavior was explicitly declined because timer-triggered formatting can unexpectedly alter the editor and dismiss IntelliSense. Current main preserves that intentional design, so this can close as designed.

## Change summary

Automatically format the entire document after an inactivity delay, independently of delayed auto-save.

## Best solution

Keep formatting behind an explicit user signal; users can invoke `editor.action.formatDocument` when they want formatting without saving.

## Vision fit

- **Fit:** rejected
- **Reason:** An unsolicited whole-document edit during active interaction conflicts with predictable, uniform editor interactions.
- **Evidence:** Public value: “Simple, uniform UI and UI interactions.”

  > Thanks for the request. Formatting after an inactivity timer is intentionally not supported because it can unexpectedly move the cursor, change decorations, or dismiss active IntelliSense UI. Current behavior keeps whole-document formatting behind an explicit signal; `Format Document` (`editor.action.formatDocument`) can format without saving. Closing this as designed.
