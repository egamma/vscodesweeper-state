# Issue #146546 — Request of new feature: Format On Delay.

[https://github.com/microsoft/vscode/issues/146546](https://github.com/microsoft/vscode/issues/146546)

## Summary

Keep this accepted Backlog request open: current formatting options do not provide independent, delay-triggered whole-document formatting compatible with after-delay auto-save. The maintainer's interaction-safety concerns remain relevant, but neither a verified canonical duplicate nor a completed implementation was found.

## Change summary

Add optional whole-document formatting after an editing delay, independently of saving and compatible with files.autoSave set to afterDelay.

## Best solution

Define an opt-in delayed-formatting behavior in the editor formatting area that coexists with after-delay auto-save without disrupting active IntelliSense or other editor interactions. Resolve the interaction-safety contract before implementation rather than treating removal of the auto-save guard as the complete feature.
