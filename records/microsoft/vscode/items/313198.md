# Issue #313198 — Chat Debug: Add ability to filter by call type (tool calls vs internal agent calls)

[https://github.com/microsoft/vscode/issues/313198](https://github.com/microsoft/vscode/issues/313198)

## Summary

The requested separation already exists in the Chat/Agent Debug Logs filter menu: Tool Calls and Model Turns have independent visibility toggles, including in the exact VS Code commit reported here.

## Change summary

Allow MCP tool calls to remain visible while hiding internal Copilot model or agent calls in the Chat Debug view.

## Best solution

Use the existing More Filters menu, leave Tool Calls enabled, and disable Model Turns; preserve the current event-kind distinction between tool executions and LLM requests.
