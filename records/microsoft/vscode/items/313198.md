# Issue #313198 — Chat Debug: Add ability to filter by call type (tool calls vs internal agent calls)

[https://github.com/microsoft/vscode/issues/313198](https://github.com/microsoft/vscode/issues/313198)

## Summary

The requested separation already exists in the Chat Debug filter menu: tool calls, model turns, and subagent invocations have independent visibility toggles.

## Change summary

Allow Chat Debug users to show MCP tool calls while hiding internal Copilot model and agent calls.

## Best solution

Use the existing More Filters menu with Tool Calls enabled and Model Turns and Subagent Invocations disabled; this preserves the current event-kind model without adding redundant filters.
