# Issue #327041 — [agents window] Browsers get hidden in workspace-less chats

[https://github.com/microsoft/vscode/issues/327041](https://github.com/microsoft/vscode/issues/327041)

## Summary

Still reproduces on main: the detail-visibility strategy in the single-pane layout explicitly skips restoring the auxiliary bar for workspace-less sessions (`!hasWorkspace → return`), so switching away and back hides the browser with no recovery path. Team-authored bug, keeping open.

## Change summary

Browsers opened in workspace-less agent chats get permanently hidden when switching sessions and back, because the detail-panel restore logic early-returns for sessions without a workspace.

## Best solution

In `singlePaneDetailVisibilityStrategy.ts`, relax the `[D3a]` guard so that workspace-less sessions still participate in detail-panel visibility capture/restore — at minimum, track and restore the auxiliary-bar state when the session has an open browser view even without a workspace folder. The browser-view filter in `sessionBrowserView.ts` already scopes browsers to their owning session, so the restore just needs to show/hide the aux bar.
