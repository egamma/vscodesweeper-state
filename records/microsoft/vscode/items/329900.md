# Issue #329900 — 'Updating' badge on titlebar gearwheel is not circular

[https://github.com/microsoft/vscode/issues/329900](https://github.com/microsoft/vscode/issues/329900)

## Summary

Traced this in the CSS: the titlebar's `.badge.compact .badge-content` rule (min-width 12px, padding 0 2px) makes the progress badge oval, unlike the activity bar's analogous `.badge.progress-badge` rule (width 16px, padding 0) that was fixed for the referenced sibling issue #328371 but never mirrored into the titlebar stylesheet.

## Change summary

The 'Updating…' spinner badge shown on the titlebar gearwheel (manage/profile action) renders as an oval, not a circle, while the equivalent activity-bar badge was already fixed to be circular.

## Best solution

Add a titlebar-scoped `.badge.progress-badge .badge-content` override (fixed width equal to height, zero horizontal padding) in titlebarpart.css, mirroring the fix already applied to the activity bar in paneCompositePart.css.
