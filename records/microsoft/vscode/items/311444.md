# Issue #311444 — [Error] a.getId is not a function — explorerView / asyncDataTree

[https://github.com/microsoft/vscode/issues/311444](https://github.com/microsoft/vscode/issues/311444)

## Summary

The defect remains in current main: a stale root input can reach `AsyncDataTree.getDataNode()`, whose diagnostic path passes the root `TInput` to an identity provider expecting a child `T`, producing the reported `getId` TypeError. This issue is the maintainer-confirmed canonical report and should remain open for a bounded fix and regression test.

## Change summary

Prevent concurrent File Explorer root replacement and refresh from calling the child identity provider with the root input and throwing `getId is not a function`.

## Best solution

Make `AsyncDataTree` handle a stale root lookup without invoking the child identity provider on `TInput`, while preserving identity-enriched errors for actual child elements, and cover the concurrent `updateChildren`/`setInput` path with a unit test.
