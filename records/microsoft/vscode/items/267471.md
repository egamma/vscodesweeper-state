# Issue #267471 — Git Clone - local folder with space. Problem with path. Escapes "space" to %20

[https://github.com/microsoft/vscode/issues/267471](https://github.com/microsoft/vscode/issues/267471)

## Summary

Confirmed bug on current main: `encodeURI()` at line 480 of `extensions/git/src/git.ts` unconditionally encodes spaces in clone URLs, breaking local paths containing spaces. An open PR (#297212) proposes a fix but has not merged yet — keeping open.

## Change summary

Git clone of a local repository whose path contains spaces fails because VS Code encodes spaces to `%20` via `encodeURI()`.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/297212, which gates `encodeURI()` on remote URL schemes so local paths pass through unmodified. The fix is small and localized to `extensions/git/src/git.ts` line 480.

## Evidence

- **source confirmation:** extensions/git/src/git.ts line 480: `const command = ['clone', url.includes(' ') ? encodeURI(url) : url, folderPath, '--progress'];` — applies encodeURI unconditionally to any URL with spaces, including local paths.
- **open fix PR:** https://github.com/microsoft/vscode/pull/297212 is open and proposes gating encodeURI on a remote-scheme regex; not yet merged.
- **original cause:** The encodeURI was introduced in commit 1db0f527 (2018) to fix spaces in HTTP URLs but also affects local paths, which should not be URI-encoded.
- **workaround:** Using `file:///` protocol prefix works around the issue, as confirmed by the reporter in the comments.
