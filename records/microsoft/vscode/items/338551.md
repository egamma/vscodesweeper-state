# Issue #338551 — Workspace Trust shouldn't block create_remote_session

[https://github.com/microsoft/vscode/issues/338551](https://github.com/microsoft/vscode/issues/338551)

## Summary

Keep open for a maintainer decision about Workspace Trust during remote session creation. Current source explicitly enforces the reported restriction; this team-authored request questions a security boundary, so neither a judgment close nor autonomous implementation is appropriate.

## Change summary

Allow create_remote_session to create workspace-backed remote sessions without requiring the target workspace to be trusted beforehand.

## Best solution

Have the remote-session and Workspace Trust owners establish whether session creation should require prior trust or obtain authorization through the normal approval flow. Apply the agreed contract consistently to creation and subsequent remote messages without implicitly granting workspace trust.
