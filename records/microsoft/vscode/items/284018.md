The diagnostics confirm all fetchers time out through the proxy, and a maintainer already directed the reporter to the firewall troubleshooting docs. No follow-up in over seven months.

## Change summary

User behind a Zscaler corporate proxy cannot connect to GitHub Copilot services; all API requests time out.

## Best solution

The user's Zscaler proxy configuration needs to allowlist the GitHub Copilot endpoints listed in https://docs.github.com/en/copilot/troubleshooting-github-copilot/troubleshooting-firewall-settings-for-github-copilot. This is a network administration task, not a VS Code code change.
