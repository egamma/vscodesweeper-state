# Issue #286207 — terminal integrated suggest inserts wrong text when tab is pressed due to latency

[https://github.com/microsoft/vscode/issues/286207](https://github.com/microsoft/vscode/issues/286207)

## Summary

Keep open: current source still computes completion replacement from terminal-buffer state that can lag behind user input, allowing rapid Backspace then Tab to remove the command's separating space. The reporter confirmed the earlier proposed fix was insufficient on Insiders; no verified canonical or subsequent fixing commit was established.

## Change summary

Prevent terminal suggestions from inserting incorrect text or deleting command separators when Tab follows input whose shell echo has not arrived.

## Best solution

Make terminal suggestion acceptance safe when shell echo lags behind typing, without changing ordinary shell completion or correct replacement behavior. First establish deterministic delayed-echo coverage and determine the coordination boundary between prompt tracking and suggestion acceptance.
