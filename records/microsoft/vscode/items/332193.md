# Issue #332193 — workbench.experimental.modernUI on by default w/o a clear instruction how to turn it off

[https://github.com/microsoft/vscode/issues/332193](https://github.com/microsoft/vscode/issues/332193)

## Summary

The Modern UI Update is a real, documented setting (`workbench.experimental.modernUI`, default `false`) that can be flipped in Settings by searching 'Modern UI' — being auto-enabled for some users via an experiment rollout and reversible through that same setting is how VS Code's platform-wide settings-experiment mechanism intentionally works, not a defect in this feature.

## Change summary

Modern UI Update (rounded corners/floating panels) was auto-enabled for the reporter via an A/B experiment with no clear in-product pointer to the setting that disables it.

## Best solution

Keep the shipped design: the setting is documented in Settings UI (`workbench.experimental.modernUI`) with a description explaining exactly what it does; if there's a broader wish for experiments to announce themselves in-product when auto-toggled, that would need a separate, general feature request against the experimentation/configuration platform rather than this specific feature.

  > Thanks for flagging this. The rounded corners/floating panels come from the `#workbench.experimental.modernUI#` setting (default is `false`) — you were auto-opted into the experiment, but the setting itself is fully visible and documented: open Settings and search "Modern UI", or add `"workbench.experimental.modernUI": false` to settings.json, to turn it off. Auto-applying (and being able to reverse) an experiment through the normal settings UI is how VS Code's experimentation mechanism is designed to work across the board, so I'm closing this as as-designed — but it's useful feedback that the toggle wasn't easy to find.
