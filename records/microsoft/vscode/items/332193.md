# Issue #332193 — workbench.experimental.modernUI on by default w/o a clear instruction how to turn it off

[https://github.com/microsoft/vscode/issues/332193](https://github.com/microsoft/vscode/issues/332193)

## Summary

Real complaint about discoverability, not a code defect: `workbench.experimental.modernUI` (src/vs/workbench/browser/workbench.contribution.ts) defaults to `false` but carries `experiment: { mode: 'auto' }`, letting the A/B experimentation service flip it on for some stable-channel users without an obvious in-product pointer to the toggle.

## Change summary

Users report the Modern UI (rounded corners / floating panels) experiment got turned on for them with no clear guidance on how to disable it via settings.

## Best solution

Improve discoverability rather than change the rollout mechanism: consider a first-run/notification pointer to `#workbench.experimental.modernUI#` when the experiment auto-enables it, or reference the setting id directly in the experiment's release-notes/toast copy so users don't have to search forums; this belongs with whoever owns the Modern UI rollout (src/vs/workbench/contrib/modernUI).
