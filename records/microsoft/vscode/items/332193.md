# Issue #332193 — workbench.experimental.modernUI on by default w/o a clear instruction how to turn it off

[https://github.com/microsoft/vscode/issues/332193](https://github.com/microsoft/vscode/issues/332193)

## Summary

Real feedback about a rough experiment rollout, not a code defect: `workbench.experimental.modernUI` ships with `default: false` in source but is flipped on for a subset of stable users via `experiment: { mode: 'auto' }`, and there's no in-product notification pointing users at the setting or explaining how to opt out — several independent reporters had to find the setting key via search engines/Stack Overflow.

## Change summary

Modern UI Update experiment is being auto-enabled for stable users without a clear, discoverable way to turn it off.

## Best solution

This is a product decision for the modernization/experimentation owners: either tag `workbench.experimental.modernUI` with `'experimental'` (it currently lacks the tag that its sibling setting `workbench.experimental.modernUIUppercaseViewHeaders` has, which would surface it under the Settings UI's Experimental filter) and/or surface a one-time notification or release-note callout when the A/B experiment flips a user on, naming the setting to revert it.
