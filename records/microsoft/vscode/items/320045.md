# Issue #320045 — Error: VSCode Server fails, if update fails to download

[https://github.com/microsoft/vscode/issues/320045](https://github.com/microsoft/vscode/issues/320045)

## Summary

Verified duplicate: the older open issue reports the same WSL failure mode—removing the existing server before the replacement is safely installed leaves WSL connectivity broken when an update fails.

## Change summary

Make WSL server updates transactional so a failed download or installation does not leave the remote connection unusable.

## Best solution

Consolidate the reports on https://github.com/microsoft/vscode/issues/318088, preserving this report's additional evidence about failed installation after download and the manual archive workaround. The Remote-WSL updater should validate the replacement before activating it and avoid leaving a partially installed target.
