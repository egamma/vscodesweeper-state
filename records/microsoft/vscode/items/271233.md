# Issue #271233 — Markdown preview show cached file when switching to another tab and then switching back

[https://github.com/microsoft/vscode/issues/271233](https://github.com/microsoft/vscode/issues/271233)

## Summary

Confirmed bug — the markdown preview does not refresh when its panel becomes visible again after being hidden. An open PR (#308427) already targets this issue, so it should stay open pending that PR's resolution.

## Change summary

Markdown preview shows stale/cached content when switching away from the preview tab and back, because no refresh is triggered on panel re-visibility.

## Best solution

Land the fix in https://github.com/microsoft/vscode/pull/308427 which adds a refresh call when the webview panel's `onDidChangeViewState` fires with `visible: true`. The fix belongs in `extensions/markdown-language-features/src/preview/previewManager.ts` or the preview classes themselves.
