# Issue #340741 — Editor Window Chat: section bar "more" needs to be double clicked to expand/collapse

[https://github.com/microsoft/vscode/issues/340741](https://github.com/microsoft/vscode/issues/340741)

## Summary

Thanks for the report. The cause is visible in source: the editor-window sessions list sets `expandOnlyOnTwistieClick: true` for every row, including section headers. A single click on the "More" header therefore doesn't toggle it, while the Agents window list only applies that setting to session rows.

## Change summary

A single click on the "More" section header in the editor-window chat sessions list doesn't expand or collapse it. A double click is needed.

## Best solution

Make `expandOnlyOnTwistieClick` in agentSessionsControl.ts apply to session rows only, so section headers toggle on a single click as they do in the Agents window.
