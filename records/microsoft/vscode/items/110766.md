# Issue #110766 — Allow an output to go into full-screen mode

[https://github.com/microsoft/vscode/issues/110766](https://github.com/microsoft/vscode/issues/110766)

## Summary

Full-screen mode for notebook outputs remains unimplemented on current main — no fullscreen support exists in the webview or notebook output code. The issue is authored by a contributor (rebornix) and milestoned to Backlog; it stays open as a valid feature request with continued interest from extension authors.

## Change summary

Allow notebook outputs (and webview-hosted content like videos) to enter full-screen mode within VS Code.

## Best solution

Implement `allowfullscreen` / Fullscreen API pass-through for iframes hosting notebook outputs. This likely requires changes in the webview iframe sandboxing (adding `allow-presentation` or similar to the iframe sandbox attribute) and potentially Electron-level coordination for desktop. The notebook output webview layer and the base webview iframe setup are the likely targets.
