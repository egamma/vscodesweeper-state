# Issue #249087 — Git - Checkout command not allowing the option to stash or migrate any change you’ve made locally

[https://github.com/microsoft/vscode/issues/249087](https://github.com/microsoft/vscode/issues/249087)

## Summary

The named-branch git.checkout path still bypasses the dirty-worktree recovery dialog on current main. Keep this open while the existing fix candidate, https://github.com/microsoft/vscode/pull/249171, is reviewed.

## Change summary

Offer the existing stash and migrate recovery choices when git.checkout receives an explicit branch name, matching checkout through the branch picker.

## Best solution

Review and update https://github.com/microsoft/vscode/pull/249171 so explicit-branch checkout provides the same dirty-worktree recovery choices as picker-based checkout, while preserving current worktree-specific error handling.
