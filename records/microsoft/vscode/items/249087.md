# Issue #249087 — Git - Checkout command not allowing the option to stash or migrate any change you’ve made locally

[https://github.com/microsoft/vscode/issues/249087](https://github.com/microsoft/vscode/issues/249087)

## Summary

Confirmed bug: `_checkout` bypasses the DirtyWorkTree error-handling path when a branch name is passed directly. An open PR (#249171) already targets this. Keeping open for that PR to land.

## Change summary

When `git.checkout` is called programmatically with a branch name and there are uncommitted changes, it throws an error instead of offering stash/migrate/force options.

## Best solution

Land the open PR (https://github.com/microsoft/vscode/pull/249171) or an equivalent fix: wrap the direct `repository.checkout()` call at line 2854 of `extensions/git/src/commands.ts` with the same DirtyWorkTree error-handling that the interactive path uses (lines 2931–2978).
