# Issue #336376 — Copilot subagents receive mandatory tool_search instructions although Responses API disables tool search for subagents

[https://github.com/microsoft/vscode/issues/336376](https://github.com/microsoft/vscode/issues/336376)

## Summary

Confirmed on current main: the Responses API request builder in responsesApi.ts disables tool deferral for subagents (`shouldDeferTools = toolSearchEnabled && isAllowedConversationAgent && !isSubagent`) and sends ordinary tool schemas directly, but the shared prompt components (ToolSearchToolPromptOptimized, DeferredToolListReminder, Gpt55ReminderInstructions) gate only on `endpoint.supportsToolSearch` with no subagent awareness, so subagents still receive mandatory 'you MUST call tool_search first' instructions for tools that were never deferred. A team member also confirms this blocks a related extension.

## Change summary

Subagent requests disable tool_search/tool deferral but the prompt still tells the subagent it must call tool_search before using its (already-loaded) tools, an impossible/contradictory instruction.

## Best solution

Thread the effective per-request deferral decision (not just endpoint.supportsToolSearch) into the shared prompt components so subagent prompts skip the tool_search/deferred-tool-list guidance when deferral is actually disabled for that request; likely needs a subagent/telemetry-subType signal plumbed into prompt props alongside availableTools.

Non-subagent requests where deferral is genuinely enabled are unaffected. ## Evidence

- **request builder disables deferral for subagents:** extensions/copilot/src/platform/endpoint/node/responsesApi.ts: `const isSubagent = options.telemetryProperties?.subType?.startsWith('subagent') ?? false; const shouldDeferTools = toolSearchEnabled && isAllowedConversationAgent && !isSubagent;` — confirmed present on main.
- **prompt gate ignores subagent flag:** extensions/copilot/src/extension/prompts/node/agent/toolSearchInstructions.tsx ToolSearchToolPromptOptimized.render() and DeferredToolListReminder.render() both check only `!endpoint?.supportsToolSearch`, with no subagent/effective-deferral check, so they still emit 'You MUST use tool_search to load deferred tools BEFORE calling them.'
- **model-specific reminder repeats the issue:** extensions/copilot/src/extension/prompts/node/agent/openai/gpt55Prompt.tsx line 282: `const toolSearchEnabled = !!this.props.endpoint.supportsToolSearch;` — same endpoint-only gate, independent surface that would need the same fix.
- **no subagent signal plumbed to prompts:** grep shows `subType`/`isSubagent` only set in executionSubagentToolCallingLoop.ts and searchSubagentToolCallingLoop.ts (request telemetryProperties), and consumed in responsesApi.ts — none of the prompt-tsx render props for ToolSearchToolPromptOptimized/DeferredToolListReminder/Gpt55ReminderInstructions currently carry this flag.
