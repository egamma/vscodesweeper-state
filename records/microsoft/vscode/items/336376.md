# Issue #336376 — Copilot subagents receive mandatory tool_search instructions although Responses API disables tool search for subagents

[https://github.com/microsoft/vscode/issues/336376](https://github.com/microsoft/vscode/issues/336376)

## Summary

Traced and confirmed on current main: the Responses API request builder in responsesApi.ts disables tool deferral (and thus tool_search) for subagents, but the shared prompt guidance in toolSearchInstructions.tsx and the GPT-5.5 reminder in gpt55Prompt.tsx only check `endpoint.supportsToolSearch`, not the effective per-request deferral decision — so subagents can be told to call a tool that isn't in their request.

## Change summary

Copilot subagent prompts still emit mandatory 'you MUST call tool_search before using deferred tools' instructions even when the Responses API request builder has disabled tool search/deferral for that subagent, making an already-available tool appear blocked behind an absent discovery tool.

## Best solution

Thread the effective per-request deferral decision (the same `shouldDeferTools`/`isSubagent` condition computed in extensions/copilot/src/platform/endpoint/node/responsesApi.ts) into ToolSearchToolPromptOptimized/DeferredToolListReminder in toolSearchInstructions.tsx and into the GPT-5.5 reminder in gpt55Prompt.tsx, so prompt guidance and the serialized request always agree.
