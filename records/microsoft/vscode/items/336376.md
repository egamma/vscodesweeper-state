# Issue #336376 — Copilot subagents receive mandatory tool_search instructions although Responses API disables tool search for subagents

[https://github.com/microsoft/vscode/issues/336376](https://github.com/microsoft/vscode/issues/336376)

## Summary

Confirmed on current main: subagent Responses API requests eagerly include ordinary tools and omit tool search, while the generated prompt can still require tool search before those tools are called. This remains open and is blocking another VS Code extension workflow.

## Change summary

Make Copilot subagent prompts reflect the effective request-level tool-deferral policy so they never require an unavailable tool-search capability.

## Best solution

Derive one effective tool-deferral decision from endpoint capability, available tools, request location, and subagent status, then use it consistently for Responses API serialization, shared deferred-tool guidance, global deferred-tool context, and model-specific reminders.
