[https://github.com/microsoft/vscode/issues/349920](https://github.com/microsoft/vscode/issues/349920)

## Summary

The sandbox profiles editor still directs users to Remote Environments without explaining that it lives in the Agents window. Keep this team-authored wording issue open; the related naming discussion does not cover the missing window context.
