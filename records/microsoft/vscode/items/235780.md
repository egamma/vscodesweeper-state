# Issue #235780 — javascript output with </script> can close scripts

[https://github.com/microsoft/vscode/issues/235780](https://github.com/microsoft/vscode/issues/235780)

## Summary

The reported script truncation remains reproducible from current source: JavaScript output is serialized to HTML and reparsed, allowing a literal </script> inside valid JavaScript to terminate the script element. Keep this open in notebook-output; no verified canonical or fixing commit was found.

## Change summary

Render notebook JavaScript output containing literal script-closing tags without truncating execution or displaying the remaining source as HTML.

## Best solution

The built-in notebook renderer should preserve JavaScript output as executable source, including literal </script> strings, while retaining rendering hooks, module semantics, and workspace-trust restrictions.
