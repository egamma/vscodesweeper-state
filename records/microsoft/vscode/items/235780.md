# Issue #235780 — javascript output with </script> can close scripts

[https://github.com/microsoft/vscode/issues/235780](https://github.com/microsoft/vscode/issues/235780)

## Summary

Confirmed on current main: the `renderJavascript` function in the built-in notebook-renderers extension serializes user script content via `outerHTML` then parses it back with `innerHTML`, which causes `</script>` literals in the output to prematurely close the script tag.

## Change summary

JavaScript notebook output containing `</script>` breaks out of the script element, leaking remaining code as visible HTML.

## Best solution

In `extensions/notebook-renderers/src/index.ts`, the `renderJavascript` function should avoid the `outerHTML` → `innerHTML` round-trip. Instead, append the created script element directly to the container via DOM manipulation (appendChild), which avoids HTML parsing entirely and handles arbitrary script content safely.
