# Issue #310129 — 2026 New Theme: It is impossible to distinguish whether a file has been selected with the Ctrl key.

[https://github.com/microsoft/vscode/issues/310129](https://github.com/microsoft/vscode/issues/310129)

## Summary

Confirmed in source and still present on main: the 2026 light and dark themes define `list.focusBackground` identically to `list.activeSelectionBackground`, so a focused-but-unselected row and a selected row render the same, making ctrl-click toggle selection invisible — the previously cited fix commit doesn't exist on main, so this stays open.

## Change summary

In the new 2026 themes, ctrl-clicking to toggle a file's selection is visually indistinguishable because focused and selected rows share the same background color.

## Best solution

Give `list.focusBackground` a value distinct from `list.activeSelectionBackground` in extensions/theme-defaults/themes/2026-light.json and 2026-dark.json (or drop the redundant focusBackground override so it falls back to the outline-only focus indicator, as light_modern.json does), restoring the visual distinction between focus and selection.
