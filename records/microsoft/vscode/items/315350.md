# Issue #315350 — Agent Skills: only first 21 skills are invokable via skill() despite prompt advertising more

[https://github.com/microsoft/vscode/issues/315350](https://github.com/microsoft/vscode/issues/315350)

## Summary

Confirmed on current main: the skill tool's resolver only finds skills whose URIs appear as full `<skill><file>…</file></skill>` XML elements in the customizations index, but the token-budget truncation renders overflow skills as plain-text names without file URIs, making them unresolvable. A team member (pwang347) acknowledged this as a known bug.

## Change summary

Skills listed under "Additional skills available (invoke by name)" in the system prompt are not callable via the skill() tool because the truncation path omits their file URIs from the customizations index.

## Best solution

Either include the `<file>` URI for every skill in the customizations index (even truncated ones — e.g. a compact `<skill><name>…</name><file>…</file></skill>` block without the description), or teach `resolveSkillUri` to fall back to the `ICustomInstructionsService` skill registry directly when the index lookup misses, so all discovered skills remain invokable regardless of token-budget truncation.
