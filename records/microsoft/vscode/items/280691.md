# Issue #280691 — Background agent does not check for problems after finishing task

[https://github.com/microsoft/vscode/issues/280691](https://github.com/microsoft/vscode/issues/280691)

## Summary

Keep open: current main exposes diagnostics to Copilot CLI through an IDE MCP tool, but that does not establish that delegated background agents check their changes before finishing. No verified canonical or issue-referencing fix establishes completion of this team-authored Backlog request.

## Change summary

Have delegated background agents check for compile and lint problems after making changes, as foreground agents do.

## Best solution

Provide background agents with post-edit diagnostic validation for the files they actually changed, including isolated worktrees. First establish whether the existing IDE diagnostics integration reaches those sessions and whether its results describe the agent's working tree rather than the original workspace.
