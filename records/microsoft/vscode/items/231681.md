# Issue #231681 — Non-persisting window size after login

[https://github.com/microsoft/vscode/issues/231681](https://github.com/microsoft/vscode/issues/231681)

## Summary

This is by design: VS Code has the `window.restoreFullscreen` setting (defaults to false) that controls whether fullscreen is restored from a previous session. A macOS logout/login is treated as a new session, so fullscreen is only restored when this setting is enabled.

## Change summary

VS Code does not restore fullscreen window state after macOS logout/login.

## Best solution

Close as designed — the `window.restoreFullscreen` setting exists precisely for this. The reporter can set it to `true` to get the desired behavior.
