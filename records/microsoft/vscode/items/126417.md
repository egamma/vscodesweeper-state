# Issue #126417 — Support generic markup cells in notebooks

[https://github.com/microsoft/vscode/issues/126417](https://github.com/microsoft/vscode/issues/126417)

## Summary

Generic markup rendering has supporting infrastructure, but selecting a markup cell's MIME type remains a proposed API rather than a stable extension capability. Keep this tracking request open; the older MIME API proposal covers a prerequisite, not demonstrably the complete request.

## Change summary

Allow extensions to render notebook markup cells written in languages other than Markdown.

## Best solution

Provide a supported extension contract for selecting and rendering non-Markdown markup cells, preserving the distinction between source language and rendered MIME type. Coordinate the remaining public API decisions with https://github.com/microsoft/vscode/issues/126280 rather than treating the existing proposed API as completion.

Current upstream src/vs/workbench/contrib/notebook/browser/view/renderers/webviewPreloads.ts constructs MarkupCell output items using the supplied MIME type; infrastructure is therefore more general than Markdown alone.
