[https://github.com/microsoft/vscode/issues/126417](https://github.com/microsoft/vscode/issues/126417)

## Summary

This is a tracking issue for extending notebook markup cells beyond just markdown. While some infrastructure exists (CellKind.Markup, mime field in IMarkupCellInitialization, notebookRenderer extension point), the full generic markup cell support appears to still be incomplete work tracked here. Keeping open as accepted but unscheduled API work.

## Change summary

Support generic markup cells in notebooks beyond just markdown, allowing extensions to render other markup languages.

## Best solution

Complete the API surface so extensions can register custom renderers for non-markdown markup cell types with full parity (editing, previewing, accessibility). The notebook webview infrastructure already passes mime types; remaining work likely involves the editor experience and API finalization.
