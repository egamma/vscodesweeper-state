# Issue #341394 — Worktree sessions fail unrecoverably when Git LFS is missing from the checkout hook's PATH

[https://github.com/microsoft/vscode/issues/341394](https://github.com/microsoft/vscode/issues/341394)

## Summary

Keep open: current source propagates the checkout-hook failure and permanently latches the session's creation error. Preserving isolation is intentional, but handling the missing prerequisite without an unrecoverable session needs a maintainer decision.

## Change summary

Worktree-isolated Agents sessions become unusable when the repository's post-checkout hook cannot find Git LFS.

## Best solution

Provide an actionable, isolation-preserving recovery path for missing Git LFS during worktree creation. Retain the established prohibition on silently running in the original checkout, and decide whether recovery requires repairing PATH or supports an explicitly defined degraded checkout.
