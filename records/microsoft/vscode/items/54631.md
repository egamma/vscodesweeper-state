# Issue #54631 — [folding] Add keyboard shortcut to jump between #region and #endregion

[https://github.com/microsoft/vscode/issues/54631](https://github.com/microsoft/vscode/issues/54631)

## Summary

This remains a valid, unresolved editor-folding request: users can navigate matching brackets but not paired region markers. It should stay open under the Backlog feature-request process and be classified as under discussion rather than closed for age.

## Change summary

Add keyboard navigation between matching `#region` and `#endregion` markers, preferably through the existing jump-to-bracket command or a dedicated command.

## Best solution

Define region-pair navigation semantics in the editor folding model, then expose a command that jumps between a region's opening and closing markers without changing ordinary bracket navigation. A maintainer should first decide whether `editor.action.jumpToBracket` expands to regions or whether regions receive a separate command.

## Plan brief

- **Likely files:** `src/vs/editor/contrib/folding/browser/folding.ts`, `src/vs/editor/contrib/bracketMatching/browser/bracketMatching.ts`
- **Validation:** Add editor contribution tests proving that invoking the selected command on either marker moves the cursor to its matching region marker, while ordinary bracket matching and unmatched-marker behavior remain unchanged.
- **Behavior:**

  > Users can invoke a keyboard command while on a `#region` or `#endregion` marker to move the cursor to its matching marker, and invoke it again to return. Nested regions must resolve to the structurally matching marker, and unmatched markers must not move the cursor. Existing navigation for brackets must remain unchanged. The command must be available for keybinding without adding permanent UI.
- **Trace:**

  > The request sits at the boundary between the editor folding contribution, which owns region ranges, and bracket matching, which owns `editor.action.jumpToBracket`. The existing issue discussion does not settle whether region navigation should alter that command's observable contract or use a dedicated command. `workbench.action.gotoSymbol` is only a partial alternative because it navigates a list of names rather than toggling between paired markers. Keep language-specific region syntax in existing folding providers and avoid introducing a second parser for region markers.
- **Open decisions:**
  - Should `editor.action.jumpToBracket` also navigate matching region markers, or should region-pair navigation be exposed as a separate command with its own keybinding?
  - When the cursor is inside a region but not on either marker, should the command navigate that enclosing region or act only when the cursor is on a marker?
