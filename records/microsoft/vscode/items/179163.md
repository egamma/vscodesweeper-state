## Summary

Keep open: the reporter supplied before/after snapshots showing the merge base becoming empty while both inputs and the result remain unchanged. This is a concrete merge-state failure, not evidence that conflicts were successfully resolved; no verified fix or canonical duplicate was found.

## Change summary

Opening the merge editor causes discrete conflicts to become whole-file highlighting after a delay, while closing still reports unresolved conflicts.

Preserve the correct merge base throughout an active merge session so conflict ranges remain meaningful. Diagnose the base-content transition across Git resource refresh and merge-model initialization before choosing a bounded fix.
