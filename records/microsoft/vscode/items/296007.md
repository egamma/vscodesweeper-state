# Issue #296007 — Git - on displaying .patch files, for --word-diff format text is NOT colored as for typical format

[https://github.com/microsoft/vscode/issues/296007](https://github.com/microsoft/vscode/issues/296007)

## Summary

Keep open: the bundled Diff grammar still lacks recognition of inline word-diff markers, and the same gap exists in its upstream TextMate grammar. This is a grammar capability gap, not a Git diff-generation or terminal-coloring defect.

## Change summary

Highlight inline deletions and additions written as [-OLD-]{+NEW+} in saved Git word-diff .patch files.

## Best solution

Add word-diff recognition to the authoritative textmate/diff.tmbundle grammar, then incorporate the accepted grammar update into VS Code's built-in Diff language support while preserving ordinary patch highlighting.
