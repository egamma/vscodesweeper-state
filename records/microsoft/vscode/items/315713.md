# Issue #315713 — Poor truncation in Agents window getting started prompt

[https://github.com/microsoft/vscode/issues/315713](https://github.com/microsoft/vscode/issues/315713)

## Summary

Keep this accepted Backlog polish open: current main replaces the original prose-style header with responsive picker controls, but still deliberately keeps them on one row and hides labels instead of using available vertical space. The newer design reduces the original truncation, but does not settle the requested layout behavior.

## Change summary

Use available vertical space in the Agents Window new-session composer instead of truncating selected workspace and agent names into ambiguous labels.

## Best solution

Choose a responsive presentation that keeps consequential workspace and agent or harness selections understandable at narrow widths, potentially by allowing another row rather than ellipsizing or hiding multiple labels. Apply that decision consistently to the default and experimental new-session layouts.
