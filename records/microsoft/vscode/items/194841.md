# Issue #194841 — UI issue: Multi-line cells collapse into 1.5 lines after scrolling.

[https://github.com/microsoft/vscode/issues/194841](https://github.com/microsoft/vscode/issues/194841)

## Summary

Still a valid open bug: multi-line notebook cells collapse to ~1.5 lines after scrolling. Confirmed by a team member and multiple community reporters, most recently on v1.102.3 (July 2025). Several related cell-height fixes landed on main in late 2025/early 2026 but none explicitly target this issue.

## Change summary

Multi-line notebook code cells visually collapse into approximately 1.5 lines of height after scrolling them out of and back into the viewport.

## Best solution

Investigate whether the cell-height fixes in `src/vs/workbench/contrib/notebook/browser/view/cellParts/codeCell.ts` (commits d87d06f0e66, 5ad0c7c6219, a45fa6666ba) already resolve this on current main. If not, the virtualized cell list's height-restore logic on scroll-back needs to be traced — the editor layout height is likely not being recomputed when a recycled cell re-enters the viewport.
