# Issue #334541 — Plan is not shown when using Codex via Agent Host

[https://github.com/microsoft/vscode/issues/334541](https://github.com/microsoft/vscode/issues/334541)

## Summary

Real, fresh report with source evidence backing it: unlike Claude's `ExitPlanMode` handling, the Codex provider in the Agent Host has no `exit_plan_mode`/plan-rendering logic at all, so enabling Plan mode with Codex produces no visible Plan card in chat.

## Change summary

When using Codex via Agent Host in Plan mode, after the plan is ready no Plan UI is shown in chat (unlike other providers).

## Best solution

Give Codex's plan-mode flow the same chat-visible plan rendering that Claude gets via `handleExitPlanMode`/`buildExitPlanModeConfirmationState` in claudeCanUseTool.ts, or explicitly document/adjust Codex's 'input-request' plan style so the UI shows something equivalent instead of nothing; likely lives in src/vs/platform/agentHost/node/codex/ (event mapping) and the chat-side plan rendering contribution.
