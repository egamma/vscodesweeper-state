# Issue #334541 — Plan is not shown when using Codex via Agent Host

[https://github.com/microsoft/vscode/issues/334541](https://github.com/microsoft/vscode/issues/334541)

## Summary

Verified duplicate: the reporter's own link and the code both point to the same root cause already tracked (and more precisely diagnosed) by the older, open issue #332097 — CodexAgent never registers a `turn/plan/updated` handler, so plan snapshots are silently dropped.

## Change summary

When using Codex via Agent Host in Plan mode, the generated plan is never displayed in the chat UI once the turn completes.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/332097, which already names the exact fix: register `turn/plan/updated` in CodexAgent and map non-empty Codex plan snapshots into the existing TodoList representation.
