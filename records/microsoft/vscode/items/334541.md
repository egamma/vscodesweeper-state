# Issue #334541 — Plan is not shown when using Codex via Agent Host

[https://github.com/microsoft/vscode/issues/334541](https://github.com/microsoft/vscode/issues/334541)

## Summary

Verified duplicate: the underlying defect is fully diagnosed and tracked by the open, assigned https://github.com/microsoft/vscode/issues/332097, which owns the same (and broader) scope — CodexAgent never registers the `turn/plan/updated` notification, so plan snapshots are dropped. Traced this on current main: only `turn/started` and similar notifications are wired via `client.onNotification(...)` in codexAgent.ts, with no handler for `turn/plan/updated` anywhere.

## Change summary

When using Codex via Agent Host in Plan mode, the generated Plan is never shown in the chat transcript after the steps complete.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/332097, which already proposes the fix: register `turn/plan/updated` in CodexAgent (src/vs/platform/agentHost/node/codex/codexAgent.ts) and map non-empty Codex plan snapshots into the existing TodoList representation.
