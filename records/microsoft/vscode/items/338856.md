## Change summary

Add a 'Save Changes' option for editing a queued (non-last) message that updates it in place instead of moving it to the end of the queue.

## Best solution

If pursued, this belongs in the queued-message editing flow in chatWidget.ts's `_acceptInput` (the `editingPendingRequest` branch) plus `IChatService.removePendingRequest`/`setPendingRequests`, preserving the original queue index instead of re-appending; needs design input on whether this replaces or supplements 'Add to Queue' in the UI.
