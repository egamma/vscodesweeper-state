# Issue #346143 — Tools page shows connector IDs instead of connector names

[https://github.com/microsoft/vscode/issues/346143](https://github.com/microsoft/vscode/issues/346143)

## Summary

Confirmed in current source: Connected Sources renders and searches the runtime server name even when a human-readable connector display name is available. The issue remains actionable.

## Change summary

Display recognizable connector names instead of generated identifiers on the Tools page.

## Best solution

Connected Sources should use the available human-readable connector name consistently for presentation and search, retaining runtime identifiers for operations and falling back to the server name when display metadata is absent.
