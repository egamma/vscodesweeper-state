# Issue #341011 — Agents window: extensions.supportAgentsWindow cannot opt out extensions listed in sessionsWindowAllowedExtensions

[https://github.com/microsoft/vscode/issues/341011](https://github.com/microsoft/vscode/issues/341011)

## Summary

Thanks for the detailed report. Confirmed in source: allowlisted ids return early in _isDisabledBySessionsWindow, so an explicit `false` in extensions.supportAgentsWindow is never consulted. Whether the allowlist is meant to be overridable is a small product decision.

## Change summary

extensions.supportAgentsWindow: false is ignored for extensions in product.json sessionsWindowAllowedExtensions, and the setting is not registered in the Agents window (Unknown Configuration Setting).

## Best solution

Consult the configured per-extension value before the allowlist short-circuit so an explicit false disables the extension in the Agents window, and make the setting resolvable (registered) in the Agents window.
