# Issue #273774 — Chat input: group by context bucket in the suggest widget

[https://github.com/microsoft/vscode/issues/273774](https://github.com/microsoft/vscode/issues/273774)

## Summary

This is covered by the older, open completion-types request, which explicitly proposes top-level context buckets followed by prefix-scoped suggestions. Consolidate there while preserving this report's recent-history and Backspace navigation requirements.

## Change summary

Organize chat input suggestions into selectable context buckets with typed prefixes, scoped results, and recent context at the top level.

## Best solution

Track the bucket-first suggestion flow in https://github.com/microsoft/vscode/issues/249249, including recent-file shortcuts and returning to the top level by removing the prefix. That issue already owns the same scoped-completion design.
