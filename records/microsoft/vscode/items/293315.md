# Issue #293315 — Git diff colors in scrollbar render incorrectly in VS Code Dark (Experimental Dark) theme

[https://github.com/microsoft/vscode/issues/293315](https://github.com/microsoft/vscode/issues/293315)

## Summary

Still present on main: the 2026-dark theme sets editorOverviewRuler.modifiedForeground to green (#6ab890) while editorGutter.modifiedBackground defaults to blue (#0078D4), causing a color mismatch between the gutter and overview ruler for modified lines.

## Change summary

Git diff modification color in the overview ruler (scrollbar) is green instead of matching the blue gutter color in the 2026 Dark theme.

## Best solution

Align the editorOverviewRuler.modifiedForeground color in extensions/theme-defaults/themes/2026-dark.json with the gutter modified color — either set both to the same hue (blue or green) or remove the override so it derives from editorGutterModifiedBackground at 60% opacity (the default behavior).
