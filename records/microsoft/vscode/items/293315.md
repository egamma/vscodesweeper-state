[https://github.com/microsoft/vscode/issues/293315](https://github.com/microsoft/vscode/issues/293315)

## Summary

Keep open: the current Dark 2026 theme still assigns modified-line overview markers a green color while inheriting a blue modified-line gutter color. The reported mismatch is directly traceable in current source, and no verified canonical or open fixing PR was found.

## Change summary

Modified Git lines appear blue in the gutter but green in the overview ruler under the experimental dark theme.

## Best solution
