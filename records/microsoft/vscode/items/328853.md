# Issue #328853 — Configurable default Panel visibility

[https://github.com/microsoft/vscode/issues/328853](https://github.com/microsoft/vscode/issues/328853)

## Summary

Keep open through the established Backlog Candidates period. Current main has settings for the Panel's default location and maximization behavior, but no setting controlling its initial visibility, so the requested capability remains missing.

## Change summary

Add a setting that controls whether the Panel is hidden, visible, or maximized when a workspace or empty window is opened for the first time.

## Best solution

Provide a `workbench.panel.defaultVisibility` setting analogous to `workbench.secondarySideBar.defaultVisibility`, applying it only when initializing a new workspace or empty-window layout and preserving subsequent workspace-specific visibility choices.
