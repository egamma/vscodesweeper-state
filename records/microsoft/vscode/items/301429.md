## Summary

This update-sensitive keybinding reset was fixed on current main. Default-keybinding removals now remain effective when an update makes the command's `when` clause more specific.

## Change summary

Updating VS Code repeatedly restores a removed Open Chat shortcut, overriding the user's custom Ctrl/Cmd+I binding for Trigger Suggest.
