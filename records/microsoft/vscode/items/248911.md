# Issue #248911 — UI Flicker Observed During Image Rendering in VS Code Copilot Extension

[https://github.com/microsoft/vscode/issues/248911](https://github.com/microsoft/vscode/issues/248911)

## Summary

The flicker remains explainable on current main: streaming markdown updates replace previously rendered image DOM nodes, causing completed images to reload while later content arrives. The issue should remain open for a bounded rendering fix.

## Change summary

Streaming an HTML image, particularly inside a markdown table, repeatedly flashes or reloads the image before the response stabilizes.

## Best solution

Keep completed, unchanged images mounted across append-only chat markdown updates and avoid exposing incomplete image HTML while its tag is still streaming, without changing rendering of completed markdown.
