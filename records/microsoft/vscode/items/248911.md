# Issue #248911 — UI Flicker Observed During Image Rendering in VS Code Copilot Extension

[https://github.com/microsoft/vscode/issues/248911](https://github.com/microsoft/vscode/issues/248911)

## Summary

Acknowledged by team members (roblourens, mjbvz) as a real streaming bug where partial HTML tags render during markdown streaming, causing image flicker. No fix has landed on main — the issue remains valid and open.

## Change summary

Images in streamed markdown chat responses flicker because partial HTML (e.g. incomplete `<img>` tags) is rendered mid-stream before the full tag arrives.

## Best solution

Buffer or suppress rendering of incomplete HTML tags (especially `<img>`) during markdown streaming in the chat response pipeline. The fix likely belongs in the markdown content part rendering path (`src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatMarkdownContentPart.ts`) or the underlying markdown renderer, detecting and deferring partial HTML elements until the tag is complete.
