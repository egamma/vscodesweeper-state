# Issue #226816 — SCM Graph - Should selecting an item in the scm graph highlight the lines similar to indent guides in the editor?

[https://github.com/microsoft/vscode/issues/226816](https://github.com/microsoft/vscode/issues/226816)

## Summary

Selection-driven graph-line emphasis remains missing; existing selection styling and expanded-commit guides do not cover tracking a selected commit's lines while scrolling. Keep this accepted Backlog request open under the existing SCM and UX discussion.

## Change summary

Emphasize graph lines associated with the selected commit so they are easier to follow while scrolling.

## Best solution

Have the SCM and UX owners decide which connected lines selection should emphasize, particularly at merges, and assess a restrained visual treatment in the history graph renderer. Preserve existing branch colors, ordinary row selection, and expanded-commit guides.
