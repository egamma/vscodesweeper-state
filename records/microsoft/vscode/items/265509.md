# Issue #265509 — Issue Reporter has no Markdown preview

[https://github.com/microsoft/vscode/issues/265509](https://github.com/microsoft/vscode/issues/265509)

## Summary

Keep open: the new issue reporter wizard provides rendered Markdown review, but it remains gated behind a setting whose registered default is false. The maintainer accepted the preview request, and neither an older open canonical covering the full report nor a complete resolution was established.

## Change summary

Provide Markdown preview in the issue reporter, with related requests for image pasting, public-submission disclosure, and review on GitHub before creation.

## Best solution

Make rendered Markdown review reliably available in the supported issue-reporting experience, building on the wizard's existing Review step rather than adding a parallel preview system. Reconcile the image-paste and disclosure requests separately, preserving the existing ability to preview on GitHub before submitting.
