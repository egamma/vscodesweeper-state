# Issue #172378 — define a key as ctrl at windows, cmd at macos

[https://github.com/microsoft/vscode/issues/172378](https://github.com/microsoft/vscode/issues/172378)

## Summary

Valid feature request — VS Code's internal KeyMod.CtrlCmd abstracts Cmd/Ctrl per-platform for programmatic bindings, but there is no user-facing equivalent in keybindings.json. The gap remains on current main.

## Change summary

Expose a cross-platform modifier keyword (like Sublime's 'primary') in keybindings.json that maps to Cmd on macOS and Ctrl on Windows/Linux.

## Best solution

Add a user-facing modifier alias (e.g. 'primary+' or 'ctrlcmd+') in the keybinding parser (src/vs/base/common/keybindingParser.ts) that resolves to meta on macOS and ctrl elsewhere, eliminating the need for duplicate entries with when-clause workarounds. Low traction suggests this is a polish improvement rather than a priority.
