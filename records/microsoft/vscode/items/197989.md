# Issue #197989 — Workspace Trust - Untrusted files don't open in the same window via Open Recent

[https://github.com/microsoft/vscode/issues/197989](https://github.com/microsoft/vscode/issues/197989)

## Summary

The custom Open Recent menu still takes a different window-routing path from File → Open on Windows, explaining the unexpected new window. Keep this open in workspace-trust; the traced cause is menu routing rather than the untrusted-files setting.

## Change summary

Opening another untrusted file through Open Recent should reuse the current untrusted window under the reported settings, matching File → Open.

## Best solution

Make recent-file opening honor the same in-application window-selection semantics as File → Open, while preserving explicit new-window gestures, configured overrides, and workspace-trust checks.
