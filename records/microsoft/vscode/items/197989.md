# Issue #197989 — Workspace Trust - Untrusted files don't open in the same window via Open Recent

[https://github.com/microsoft/vscode/issues/197989](https://github.com/microsoft/vscode/issues/197989)

## Summary

Still reproduces on main: the Open Recent path uses hostService.openWindow which bypasses the workspace trust file-opening logic in the editor service. The trust-aware flow (security.workspace.trust.untrustedFiles = 'open') only applies when files are opened through the editor service, not through the window-level openWindow API used by Open Recent.

## Change summary

Opening an untrusted file via Open Recent opens a new window instead of reusing the current untrusted window, even when the untrustedFiles setting is 'open'.

## Best solution

The Open Recent file-open path in windowActions.ts (line ~212, `hostService.openWindow([pick.openable])`) needs to consult workspace trust settings before deciding on forceNewWindow behavior — either by routing through the editor service's trust-aware path, or by adding trust awareness to the window-opening decision in the host service / windows main service.
