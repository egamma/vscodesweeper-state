# Issue #330202 — Copilot does not learn from user-edited terminal commands before execution

[https://github.com/microsoft/vscode/issues/330202](https://github.com/microsoft/vscode/issues/330202)

## Summary

Keep open as a feature request: communicating an edited command to the agent is already supported on one execution path, but automatically reusing corrections in later suggestions is a distinct capability not established by the existing surfaces.

## Change summary

Use corrections made to Copilot-generated terminal commands as feedback for subsequent suggestions within the session or project.

## Best solution

Consider a scoped feedback mechanism for terminal suggestions that distinguishes reusable shell preferences from one-off command edits. Existing command-edit notifications and memory facilities provide building blocks, but the retention and generalization behavior needs a product decision.
