# Issue #311413 — Plan mode is not easily discoverable

[https://github.com/microsoft/vscode/issues/311413](https://github.com/microsoft/vscode/issues/311413)

## Summary

Plan selection is now exposed through Agent Host mode pickers, but that does not establish full coverage of the originally reported extension-host Copilot CLI surface. Keep this accepted On Deck request open until the remaining legacy-session discoverability is checked; no verified canonical owns the same request.

## Change summary

Make opting into Plan mode discoverable in Copilot CLI chat without requiring users to know the /plan command.

## Best solution

Provide a discoverable Plan selection on supported Copilot CLI chat surfaces, reusing the existing Agent Host mode picker where applicable. First establish whether the still-registered extension-host path remains user-accessible without an equivalent affordance; avoid adding redundant controls to already-covered Agent Host sessions.
