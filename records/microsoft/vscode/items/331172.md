# Issue #331172 — 3.7 Flash unavailable from Gemini model provider

[https://github.com/microsoft/vscode/issues/331172](https://github.com/microsoft/vscode/issues/331172)

## Summary

Confirmed live: the BYOK known-models feed (https://main.vscode-cdn.net/extensions/copilotChat.json) that drives the Gemini model provider's available-models list currently lists only up to `models/gemini-3.6-flash` — `gemini-3.7-flash` is genuinely missing from that catalog today, so the report is accurate.

## Change summary

Gemini 3.7 Flash, available in GitHub Copilot itself, doesn't show up as a selectable model when using the Gemini BYOK provider with an API key.

## Best solution

This isn't a code defect in microsoft/vscode: `GeminiNativeBYOKLMProvider` (extensions/copilot/src/extension/byok/vscode-node/geminiNativeProvider.ts) and `BYOKContrib._fetchKnownModelList` (extensions/copilot/src/extension/byok/vscode-node/byokContribution.ts) just consume a remotely hosted JSON catalog that isn't tracked in this repository. The fix is for the team to add a `gemini-3.7-flash` entry to that published catalog; no source change here will resolve it.
