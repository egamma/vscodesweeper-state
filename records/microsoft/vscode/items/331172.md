# Issue #331172 — 3.7 Flash unavailable from Gemini model provider

[https://github.com/microsoft/vscode/issues/331172](https://github.com/microsoft/vscode/issues/331172)

## Summary

Valid, reproducible-by-design gap: Gemini's BYOK provider sources its model capability metadata from a remote CDN config, not from this repo, so a newly released model (Gemini 3.7 Flash) is unavailable until that server-side list is updated — routing to the chat/model-byok area rather than closing.

## Change summary

Gemini 3.7 Flash, available directly in GitHub Copilot, does not show up as a selectable model when using the Gemini BYOK model provider with an API key.

## Best solution

No code change needed in this repo — the BYOK model list for the Gemini provider is fetched at runtime from https://main.vscode-cdn.net/extensions/copilotChat.json (see extensions/copilot/src/extension/byok/vscode-node/byokContribution.ts, `_fetchKnownModelList`); the Copilot Chat team needs to add gemini-3.7-flash's capabilities to that remote manifest.
