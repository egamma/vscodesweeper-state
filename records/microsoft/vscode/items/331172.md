# Issue #331172 — 3.7 Flash unavailable from Gemini model provider

[https://github.com/microsoft/vscode/issues/331172](https://github.com/microsoft/vscode/issues/331172)

## Summary

Confirmed by tracing the BYOK Gemini provider: the model allowlist that drives BYOK is fetched at runtime from a remote CDN JSON (not this repo's source), and the current copy of that file lists `models/gemini-3.6-flash` as the newest Gemini Flash entry but has no `gemini-3.7-flash` entry yet, so the native GeminiNativeBYOKLMProvider correctly filters it out — this is a remote allowlist gap, not a code defect, but it needs the Gemini model-info to be added upstream.

## Change summary

Gemini 3.7 Flash is selectable in GitHub Copilot's own model picker but is missing from the Gemini BYOK (bring-your-own-key) provider's model list.

## Best solution

Add a `models/gemini-3.7-flash` entry to the BYOK known-models data (the `Gemini` section of https://main.vscode-cdn.net/extensions/copilotChat.json, sourced from a Copilot-Chat-side config, not this repo) — GeminiNativeBYOKLMProvider.updateKnownModels only ever surfaces models present in that list (extensions/copilot/src/extension/byok/vscode-node/geminiNativeProvider.ts lines 52-63), so once the entry is published the model will appear automatically without any code change here.
