# Issue #343978 — Bug where recently git init repo does not offer to show compare models

[https://github.com/microsoft/vscode/issues/343978](https://github.com/microsoft/vscode/issues/343978)

## Summary

Keep open: current source permits comparisons without a remote when the draft exposes a branch and worktree isolation, but that does not establish support for a freshly initialized, uncommitted repository. The linked test plan supplies sufficient steps to retest; its discussion also identifies the missing branch/worktree options.

## Change summary

Compare Models is unavailable for a newly created folder after git init, including after reloading.

## Best solution

Establish whether repositories with no commits or remote are supported, then make comparison availability and the provider's branch/worktree capabilities consistent with that contract. Distinguish this case from a committed local repository without a remote, which current composer tests already cover.
