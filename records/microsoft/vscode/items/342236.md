[https://github.com/microsoft/vscode/issues/342236](https://github.com/microsoft/vscode/issues/342236)

Thanks for the report. Automatic activation of the selected Python environment is owned by the Python extensions; propose transferring this report to microsoft/vscode-python-environments for investigation, not closing it as extension-caused.

## Change summary

New terminals on Windows no longer automatically activate the selected Python virtual environment after recent updates.
