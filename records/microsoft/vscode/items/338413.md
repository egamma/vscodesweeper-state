# Issue #338413 — Allow to open terminal output in readonly editor also when it is not "too long"

[https://github.com/microsoft/vscode/issues/338413](https://github.com/microsoft/vscode/issues/338413)

## Summary

Keep open: current source deliberately restricts the read-only editor action to truncated terminal output, so the requested short-output capability remains missing. This is a team-authored enhancement, not a defect in the existing truncation behavior.

## Change summary

Offer the chat terminal card's read-only output editor action for short, non-truncated output as well.

## Best solution

Make completed Agent Host output-only command results readable in the existing read-only editor regardless of output length, while retaining accurate truncation guidance and existing live-terminal behavior.
