# Issue #338413 — Allow to open terminal output in readonly editor also when it is not "too long"

[https://github.com/microsoft/vscode/issues/338413](https://github.com/microsoft/vscode/issues/338413)

## Summary

Real, actionable UX gap confirmed in source: the 'Open Full Output (Read-Only)' action for chat terminal tool output is only ever created when output is truncated, so shorter (but still awkward-to-read) output never gets the read-only-editor option the reporter (a maintainer) is asking for while testing the related test-plan item.

## Change summary

Show the 'open terminal output in read-only editor' action even when the command output isn't long enough to be truncated.

## Best solution

Relax the truncated-only gate in ChatTerminalToolProgressPart._probeFullOutput so the read-only 'Open Full Output' action is offered whenever the output resource can be resolved, not only when `terminalCommandOutput.truncated === true`.
