# Issue #192719 — MacOS scrolling inertia is not cancelled when stopped

[https://github.com/microsoft/vscode/issues/192719](https://github.com/microsoft/vscode/issues/192719)

## Summary

The reported flow is plausible in the current editor scroll path, but this macOS/Chromium-dependent behavior has no recent confirmation and cannot be verified from source alone. Request confirmation on the latest Insiders build before keeping it as an active bug.

## Change summary

Typing after a fast macOS trackpad scroll reveals the cursor, but residual momentum wheel events move the editor viewport away again.

## Best solution

Confirm the behavior on current macOS and Electron first; if it persists, the editor should prevent residual momentum events from undoing the cursor reveal without changing ordinary trackpad scrolling.
