# Issue #339685 — Unclear if enabling `Permanently delete automatically completed sesions after N days` will intantly apply

[https://github.com/microsoft/vscode/issues/339685](https://github.com/microsoft/vscode/issues/339685)

## Summary

Keep open: the cleanup controls persist changes immediately, but their explanation still does not explicitly distinguish saving the setting from running permanent deletion. This team-authored UX report needs a decision on clearer immediate-apply feedback versus an explicit apply step.

## Change summary

Make it clear when enabling automatic session deletion takes effect and whether another confirmation or save action is required.

## Best solution

Make the Cleanup Settings section explain its activation semantics before users enable permanent deletion. Decide whether explicit immediate-apply wording is sufficient or whether these controls should stage changes behind an apply action; do not imply that persisting a setting necessarily deletes sessions synchronously.
