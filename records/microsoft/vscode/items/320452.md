# Issue #320452 — Background send does not notify when the background session fails

[https://github.com/microsoft/vscode/issues/320452](https://github.com/microsoft/vscode/issues/320452)

## Summary

Team-authored bug report: when a background session fails to start, the session silently disappears from the list with no notification or error feedback. Keeping open — author is a team member and the issue describes a real UX gap in the agents/sessions experience.

## Change summary

Background send sessions that fail to start silently disappear from the session list without notifying the user.

## Best solution

When a background session fails (for any reason), surface a notification or error state in the session list so the user knows what happened, rather than silently removing the entry. The fix likely lives in the agents window / sessions layer (`src/vs/sessions/`) or the chat background-send infrastructure.
