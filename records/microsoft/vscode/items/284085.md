# Issue #284085 — Enable runSubagent to accept user feedback

[https://github.com/microsoft/vscode/issues/284085](https://github.com/microsoft/vscode/issues/284085)

## Summary

Keep open: current main partially addresses the request by allowing the core `askQuestions` tool in subagents, but `runSubagent` remains a stateless, single-result invocation and does not automatically summarize parent context. The issue is team-authored, and the partial implementation does not reference this issue or establish that its broader requirements are complete.

## Change summary

Allow a coordinator custom agent's language-specific subagent to receive user feedback during execution and obtain useful summarized context from the parent conversation.

## Best solution

Define a supported interactive subagent contract that lets a selected custom agent request user input and resume without exposing the language-specific agent directly, while passing a bounded representation of relevant parent context. Preserve isolated tool lists and make the behavior explicit for parallel and nested subagents.

- **Likely files:** `src/vs/workbench/contrib/chat/common/tools/builtinTools/runSubagentTool.ts`, `src/vs/workbench/contrib/chat/test/common/tools/builtinTools/runSubagentTool.test.ts`, `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatSubagentOpenChat.ts`

- **Behavior:**

  > A user interacts only with the coordinator custom agent while it delegates to a language-specific custom subagent with its isolated tool list. When the subagent needs clarification, the user can respond and the same delegated task continues rather than terminating with a final report. The subagent receives the relevant parent context in a bounded form, without inheriting unrelated conversation or tools. Parallel or nested subagents must route each response to the correct invocation.
- **Trace:**

  > RunSubagentTool in src/vs/workbench/contrib/chat/common/tools/builtinTools/runSubagentTool.ts constructs an IChatAgentRequest from only `args.prompt`, then invokes the agent with an empty history array; its model description explicitly calls the invocation stateless. Structured user questions are partially supported after https://github.com/microsoft/vscode/pull/296361, while the legacy `copilot_askQuestions` tool remains disabled. Subagent presentation and opening are handled by src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatSubagentOpenChat.ts. Preserve custom-agent tool isolation, nesting-depth enforcement, and the coordinator as the sole user-visible agent; the uncertainty begins at the interaction lifetime and parent-context contract.
- **Open decisions:**
  - Should user feedback be limited to structured questions during one `runSubagent` invocation, or should users be able to send arbitrary follow-up messages to a persistent delegated conversation?
  - What parent context should a subagent receive automatically: a generated summary, selected recent turns, explicit coordinator-provided context, or a combination with a defined size and privacy boundary?
  - When several subagents request feedback concurrently, should the UI queue requests or expose independently addressable conversations?
