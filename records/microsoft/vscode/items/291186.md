# Issue #291186 — Won't be able to chat

[https://github.com/microsoft/vscode/issues/291186](https://github.com/microsoft/vscode/issues/291186)

## Summary

This is the known API-mismatch failure caused by running a stable Copilot Chat extension with VS Code Insiders. The supported combinations are Insiders with the extension pre-release, or stable VS Code with the stable extension.

## Change summary

Copilot Chat fails with an undefined `bind` error when extension version 0.36.2 runs against VS Code Insiders 1.109.

## Best solution

Use the Copilot Chat pre-release with VS Code Insiders, or use the stable extension with stable VS Code; no core behavior change is needed for this unsupported version pairing.
