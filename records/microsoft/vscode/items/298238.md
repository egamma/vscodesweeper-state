# Issue #298238 — Inline chat doesn't handle single-line monster files well

[https://github.com/microsoft/vscode/issues/298238](https://github.com/microsoft/vscode/issues/298238)

## Summary

The underlying defect remains in current main: large-file detection counts lines, and selection context expands a tiny selection to the entire line. An 18 MB single-line file therefore bypasses cropping and contributes oversized content to the prompt.

## Change summary

Inline chat should handle small selections in extremely long lines without including the entire oversized line or file.

## Best solution

Make inline-chat prompt context bounded for extremely long lines while preserving the actual selection and useful nearby context. Cover initial requests, cursor-only requests, and failed-edit feedback without changing inline chat's edit-only purpose.
