# Issue #298238 — Inline chat doesn't handle single-line monster files well

[https://github.com/microsoft/vscode/issues/298238](https://github.com/microsoft/vscode/issues/298238)

## Summary

The bug remains on main: inline chat classifies files as large solely by line count, so an 18 MB single-line file is attached in full despite a tiny selection.

## Change summary

Make inline chat crop extremely long single-line files instead of attaching the complete line and file.

## Best solution

Classify files using both line count and character size, then crop by character offsets around the cursor or exact selection while retaining the read-file fallback.
