## Summary

Thanks for the report. The a11y issue is complete, with steps, a measured ratio (2.30:1) and screenshots. I did not trace the focus styling in the source or retest it, so this stays open. The reported 1.41.0 build is old, so it is worth retesting on current Insiders with the given steps.

## Change summary

The keyboard focus outline on links in the Extensions view MCP Servers section, and on the welcome page Close button, measures 2.30:1 against its background, below the 3:1 WCAG 1.4.11 minimum.

## Best solution

Check the focus outline color used for links and buttons in the MCP Servers welcome section and on the welcome page. Make sure it uses a theme focusBorder token that gives at least 3:1 contrast in the default dark and light themes.
