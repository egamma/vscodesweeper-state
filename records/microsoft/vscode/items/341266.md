# Issue #341266 — Keyboard focus indicator has insufficient color contrast on links under the MCP Servers section:A11y_VisualStudioCode_Extensions_NonTextContrast

[https://github.com/microsoft/vscode/issues/341266](https://github.com/microsoft/vscode/issues/341266)

## Summary

Thanks for the report. It describes a specific accessibility gap: the focus outline on links in the MCP Servers welcome view measures 2.30:1, below WCAG 1.4.11. I could not measure the contrast without running the app, and the theme isn't stated. The report has enough to retest, so it stays open for the accessibility owners.

## Change summary

The keyboard focus outline on links in the Extensions > MCP Servers view (and similar Close buttons on the Welcome page) has less than 3:1 contrast.

## Best solution

Check which theme the contrast was measured in. If the default focusBorder color is the cause, adjust the focus styling for these links or buttons so it meets 3:1 against the adjacent background, ideally via the theme-level focus token rather than a per-component override.
