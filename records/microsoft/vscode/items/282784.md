# Issue #282784 — [feature request] prompt save/past with context menu

[https://github.com/microsoft/vscode/issues/282784](https://github.com/microsoft/vscode/issues/282784)

## Summary

A real discoverability and workflow gap remains: reusable prompts exist, but current main does not expose the requested save-and-insert workflow through the chat input context menu. With no verified older canonical and no maintainer decision, this should remain open as under discussion.

## Change summary

Add chat-input context-menu actions for saving a prompt or directive and inserting a previously saved one.

## Best solution

Use the existing user/workspace prompt customization model for storage, while offering a discoverable chat-input action to save the relevant input and choose a reusable prompt to insert. The interaction should complement existing slash-command access rather than create a separate snippet store.
