## Change summary

A literal $ORIGIN entry in LD_LIBRARY_PATH causes VS Code Server to reject an otherwise supported Ubuntu host during prerequisite detection.

## Best solution

Diagnose and correct the CLI prerequisite check so a supported host is not rejected because LD_LIBRARY_PATH contains a valid loader token, while preserving genuine library-version failures. This belongs in the server CLI unless reproduction establishes an external dependency defect.
