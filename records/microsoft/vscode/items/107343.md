# Issue #107343 — Asynchronously show completion items from different sources or extensions!

[https://github.com/microsoft/vscode/issues/107343](https://github.com/microsoft/vscode/issues/107343)

## Summary

The gap remains on current main, and this is the established canonical request for incremental completion results. Keep it open under discussion because implementing it requires deliberate ranking, provider-precedence, and selection-stability design.

## Change summary

Show fast completion results without waiting for every completion provider, then incrementally add slower results.

## Best solution

Evolve the suggest pipeline to publish staged completion updates while preserving provider-group precedence and stable selection. The maintainer-proposed approach—wait for the first non-simple provider, append later results without immediate resorting, and rerank after further typing—is the clearest starting design.
