# Issue #298291 — Worktree created by Copilot doesn't show up in the list of worktrees in the side panel

[https://github.com/microsoft/vscode/issues/298291](https://github.com/microsoft/vscode/issues/298291)

## Summary

Keep open: current main deliberately hides agent worktrees from the default multi-repository view, and the repository-explorer workaround does not satisfy the requested placement. The discussion also establishes a separate false-positive case affecting manually created worktrees; this team-authored item should not receive a judgment close.

## Change summary

Make Copilot-created worktrees accessible alongside ordinary worktrees in the default Source Control view, without accidentally hiding manually created worktrees with agent-like names.

## Best solution

Settle the intended visibility of agent-created worktrees in the default multi-repository view, preserving straightforward review and commit access. Separately ensure that ordinary worktrees are not suppressed merely because their directory names begin with copilot- or agents-.
