# Issue #182839 — editor.action.marker.next ignores Git conflicts

[https://github.com/microsoft/vscode/issues/182839](https://github.com/microsoft/vscode/issues/182839)

## Summary

Valid feature request: merge conflicts use editor decorations only and are not surfaced as diagnostics, so marker navigation (Alt+F8) cannot find them. A team member acknowledged this gap and suggested using diagnostics. Still unimplemented on main.

## Change summary

Request to surface Git merge conflicts as diagnostics so that editor.action.marker.next (Alt+F8) can navigate to them.

## Best solution

The built-in merge-conflict extension (extensions/merge-conflict/) should create a DiagnosticCollection for detected merge conflicts, so they appear in the Problems view and are reachable via marker navigation. This aligns with @chrmarti's suggestion in the thread.
