# Issue #308893 — Agents App: Changes reports `git diff --stat` instead of `git diff --stat -w`

[https://github.com/microsoft/vscode/issues/308893](https://github.com/microsoft/vscode/issues/308893)

## Summary

Keep open: Changes statistics still have whitespace-sensitive Git paths, and maintainers have expressed interest in making the counts agree with the displayed diff. The remaining decision is which whitespace policy should govern those statistics; no verified canonical or issue-referencing fix was found.

## Change summary

Exclude ignored whitespace changes from Agents Window Changes statistics so small substantive edits do not appear as whole-file rewrites.

## Best solution

Give Changes statistics a consistent, explicit whitespace policy that matches the user's review experience without hiding substantive edits. Resolve whether that policy follows an existing diff setting or a Changes-specific control, including whether it ignores only surrounding whitespace or all whitespace.
