# Issue #328222 — Feedback comments should be shown in UI

[https://github.com/microsoft/vscode/issues/328222](https://github.com/microsoft/vscode/issues/328222)

## Summary

Reasonable UX request for the Agents Window's feedback-comment flow; already correctly labeled `under-discussion` and `agents-window` by maintainers, recently filed (16 days) with only 1 upvote — no basis to close, just needs product/design follow-up.

## Change summary

When the agent replies after addressing feedback comments (PR/code-review style comments), the UI doesn't show which specific comment the reply is addressing, making it hard to correlate the response to the original feedback.

## Best solution

Product/design decision for the `src/vs/sessions/contrib/agentFeedback` area on how to surface the originating feedback comment text alongside the agent's reply (e.g. in the chat transcript or attachment context), rather than only bundling feedback as an opaque 'N feedback items' attachment as `agentFeedbackAttachment.ts` currently does.
