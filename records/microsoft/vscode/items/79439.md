# Issue #79439 — [css] code completion for gradient functions

[https://github.com/microsoft/vscode/issues/79439](https://github.com/microsoft/vscode/issues/79439)

## Summary

The request remains relevant: VS Code provides CSS function-name completion and hover documentation for gradients, but there is no clear built-in argument-completion path for values inside `linear-gradient()` or `radial-gradient()`. With no verified duplicate, implementation commit, or maintainer scope decision, this Backlog feature request should stay open under discussion.

## Change summary

Provide CSS code completions for valid arguments while editing `linear-gradient()` and `radial-gradient()` values.

## Best solution

Track this as a CSS language-service enhancement: define useful context-aware proposals inside gradient functions, including direction or shape keywords, color stops, and relevant position syntax, without flooding ordinary property-value completion.
