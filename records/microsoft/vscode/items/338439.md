# Issue #338439 — Integrated Browser: Unable to attach element as context if session hasn't started

[https://github.com/microsoft/vscode/issues/338439](https://github.com/microsoft/vscode/issues/338439)

## Summary

Keep open: current source still exposes a mismatch between browser attachment targeting and the Agents Window's separate new-session composer. The attachment code now waits for chat model initialization, but that does not establish coverage of this composer; the supplied steps are sufficient to retest.

## Change summary

Selecting a browser element should attach it to the Agents Window's new-session draft before the first message is sent.

## Best solution

Make browser element attachment reach the currently presented new-session composer without requiring a first message or targeting an older chat. Preserve the existing behavior for started sessions and the workbench-to-sessions layering boundary.
