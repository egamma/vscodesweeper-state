## Summary

Keep this API proposal open for the API owners' decision: current main still uses item-dependent alignment heuristics and exposes no extension-controlled alignment mode. The maintainer explicitly reconsidered the initial rejection and requested API discussion before implementation; the api-proposal label independently bars a cleanup close.

## Change summary

Allow extension authors to select a consistent icon/twistie alignment policy for custom tree views while preserving the existing default.

## Best solution

Resolve whether to support an explicit TreeViewOptions alignment policy through the API review process, including its public shape and leaf-item semantics. Coordinate that decision with the existing heuristic-fix PR rather than treating the heuristic improvements as delivery of this API.
