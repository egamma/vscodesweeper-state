# Issue #347305 — Markdown editor blocks the unattended restart for updates

[https://github.com/microsoft/vscode/issues/347305](https://github.com/microsoft/vscode/issues/347305)

## Summary

The current source still blocks unattended restarts for the built-in Markdown editor. An open draft PR explicitly fixes this issue, so keep it open pending review and merge.

## Change summary

Allow restorable Markdown editors to remain open during unattended update restarts without weakening protection for non-restorable webviews.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/347306 if its restoration guarantees hold, preserving restart blockers for non-restorable webviews and unbacked-up changes.

Neither owns the Markdown editor's webview.retainedContext defect.
