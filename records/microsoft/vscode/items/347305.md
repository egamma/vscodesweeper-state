# Issue #347305 — Markdown editor blocks the unattended restart for updates

[https://github.com/microsoft/vscode/issues/347305](https://github.com/microsoft/vscode/issues/347305)

## Summary

The current source still treats the built-in Markdown editor's retained webview as an unattended-restart blocker, regardless of document restoration support. Keep open for the assigned 1.148.0 milestone.

## Change summary

Allow unattended update restarts with restorable Markdown editors open while preserving blockers for non-restorable webviews.

## Best solution

Distinguish retained rendering context from non-restorable state in unattended-restart eligibility, so saved or safely backed-up Markdown documents do not block updates. Preserve existing protection for webviews whose state cannot survive restarting.
