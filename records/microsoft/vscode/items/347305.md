# Issue #347305 — Markdown editor blocks the unattended restart for updates

[https://github.com/microsoft/vscode/issues/347305](https://github.com/microsoft/vscode/issues/347305)

## Summary

The current source confirms that opening the built-in Markdown editor triggers the retained-context restart blocker regardless of whether its document is saved. Keep open for the assigned 1.147.0 milestone.

## Change summary

Allow unattended update restarts with restorable Markdown editors open while continuing to protect non-restorable webviews.

## Best solution

Make unattended-restart eligibility distinguish restorable Markdown editor state from genuinely non-restorable webview state, preserving document backup safeguards and fast tab switching.
