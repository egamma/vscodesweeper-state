# Issue #186604 — Inconsistent dropping of problem markers

[https://github.com/microsoft/vscode/issues/186604](https://github.com/microsoft/vscode/issues/186604)

## Summary

Still reproduces on main: extHostDiagnostics limits to 1000 per file while markerDecorationsService limits decorations to 500, causing a visible mismatch between the Problems view and editor squiggles. The maintainer acknowledged the complexity but no fix has landed.

## Change summary

Inconsistent diagnostic limits between the Problems view (1000) and editor decorations (500) cause confusing behavior where some diagnostics appear in Problems but lack editor squiggles.

## Best solution

Unify the two limits or make the decoration limit >= the diagnostics limit so users never see a diagnostic in the Problems view without a corresponding editor decoration. The constants live in `src/vs/workbench/api/common/extHostDiagnostics.ts` (line 235, 1000) and `src/vs/editor/common/services/markerDecorationsService.ts` (line 116, 500). Making this configurable would be a bonus.
