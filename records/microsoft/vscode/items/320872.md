# Issue #320872 — Outline drag-and-drop and layer visibility

[https://github.com/microsoft/vscode/issues/320872](https://github.com/microsoft/vscode/issues/320872)

## Summary

Two-part feature request: (1) outline DnD to rearrange code — previously closed as *out-of-scope in #68353, and (2) outline collapse-level layers — a new request with no canonical. Leaving open for the community upvote process given Backlog Candidates milestone, though part (1) has prior out-of-scope precedent.

## Change summary

Add drag-and-drop reordering of code symbols via the Outline panel, plus configurable collapse-level visibility layers.

## Best solution

The rearrange-by-DnD portion has established maintainer precedent as out-of-scope (https://github.com/microsoft/vscode/issues/68353). The collapse-layers portion is a distinct, potentially viable UX improvement to the Outline view — if the community upvotes it, route to the outline area owner. The existing `outline.collapseItems` setting only toggles all-collapsed vs all-expanded; per-depth-level collapse is not currently supported.
