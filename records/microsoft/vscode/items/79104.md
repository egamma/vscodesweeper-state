# Issue #79104 — macOS Text Selection: shift+left should expand selection

[https://github.com/microsoft/vscode/issues/79104](https://github.com/microsoft/vscode/issues/79104)

## Summary

Keep open: current source still contracts a double-click word selection on Shift+Left instead of extending its left edge. This accepted Backlog request has 20 upvotes and a recently consolidated duplicate; no existing capability or verified older canonical resolves it.

## Change summary

Support macOS-style directional expansion when Shift+Left first follows a double-click word selection.

## Best solution

Support choosing the opposite edge of an initial word selection as the anchor for macOS keyboard extension, including character- and word-level movement. Decide whether this becomes the macOS default or an opt-in behavior while preserving established selection behavior elsewhere.
