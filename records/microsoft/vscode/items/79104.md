# Issue #79104 — macOS Text Selection: shift+left should expand selection

[https://github.com/microsoft/vscode/issues/79104](https://github.com/microsoft/vscode/issues/79104)

## Summary

Keep open as the canonical macOS selection-behavior request. Current main retains the cross-platform anchor behavior, and the request has reached the 20-upvote Backlog threshold.

## Change summary

Make Shift+Left after a mouse-selected word expand from the word's left edge on macOS instead of shrinking its right edge.

## Best solution

Teach the editor cursor-selection path to choose the opposite edge as the anchor for the first Shift+Arrow movement on macOS, matching native controls while preserving existing behavior on other platforms.
