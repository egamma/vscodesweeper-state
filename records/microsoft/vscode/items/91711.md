# Issue #91711 — Diagnostic link hovers should show target

[https://github.com/microsoft/vscode/issues/91711](https://github.com/microsoft/vscode/issues/91711)

## Summary

Keep open: the Problems panel now exposes diagnostic link targets, but equivalent destination disclosure remains absent from editor diagnostic hovers and the Go to Error widget. This team-authored backlog request has no explicitly linked implementing commit or verified duplicate.

## Change summary

Show a diagnostic code link's destination before the user opens it.

## Best solution

Retain the existing target tooltip in both Problems panel modes and design a consistent, accessible destination preview for diagnostic links in `markerHoverParticipant.ts` and `gotoErrorWidget.ts`.
