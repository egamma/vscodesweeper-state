# Issue #349261 — Highlight over-length body lines in `git-commit`

[https://github.com/microsoft/vscode/issues/349261](https://github.com/microsoft/vscode/issues/349261)

## Summary

Body-line highlighting remains missing, and the maintainer explicitly confirmed the gap in current Insiders. Existing rulers and SCM input validation do not provide the requested highlighting in COMMIT_EDITMSG.

## Change summary

Highlight commit-message body text exceeding the intended line-length limit in the git-commit editor.

## Best solution

Extend the source Git commit grammar to highlight overlong body lines and incorporate the accepted grammar update into git-base. Keep configurable limits coordinated with https://github.com/microsoft/vscode/issues/317766.
