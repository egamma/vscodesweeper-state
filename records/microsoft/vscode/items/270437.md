# Issue #270437 — Bad terminal history navigation after terminal clear command

[https://github.com/microsoft/vscode/issues/270437](https://github.com/microsoft/vscode/issues/270437)

## Summary

The workaround (`windowsUseConptyDll: true`) is now the default since 1.121.0 — both reporters confirmed it resolves the issue. The underlying conpty clear behavior is fixed by the shipped DLL, so this can be closed as completed.

## Change summary

After clearing the terminal with Terminal: Clear, navigating command history with arrow-up renders commands at wrong positions in the viewport.

## Best solution

Keep the shipped default (`windowsUseConptyDll: true` since 1.121.0); no further change needed. The bundled conpty DLL handles the clear+history interaction correctly.
