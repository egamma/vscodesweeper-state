# Issue #312764 — Support all settings via JSON in a Group Policy (GPO)

[https://github.com/microsoft/vscode/issues/312764](https://github.com/microsoft/vscode/issues/312764)

## Summary

Legitimate feature request for a generic JSON-based GPO mechanism to control all settings, distinct from the current per-setting policy opt-in model. Already promoted to Backlog with 22 upvotes; no existing implementation or canonical duplicate covers this ask.

## Change summary

Allow enterprise admins to set arbitrary VS Code settings as a JSON blob via Group Policy (GPO), adding default and enforced layers to the settings resolution stack, rather than requiring each setting to individually opt in to policy support.

## Best solution

Extend the policy/managed-settings infrastructure (in `src/vs/platform/policy/` and `src/vs/platform/configuration/`) to support a generic JSON settings payload from GPO — a 'default settings' layer and an 'enforced settings' layer — that feeds into the existing configuration resolution cascade. This is a significant architecture change to the configuration system and needs a design discussion with the team before implementation.

- **managed settings infrastructure:** `src/vs/platform/policy/node/nativeManagedSettingsService.ts` and `src/vs/platform/policy/common/copilotManagedSettings.ts` implement the current managed-settings watcher, which is scoped to explicitly declared policy definitions — not arbitrary JSON.
