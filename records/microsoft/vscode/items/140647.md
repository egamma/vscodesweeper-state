# Issue #140647 — Activity bar activity indicator is `1px` but configured as `2px`

[https://github.com/microsoft/vscode/issues/140647](https://github.com/microsoft/vscode/issues/140647)

## Summary

The confirmed rendering bug remains in the classic Activity Bar: current CSS still requests a 2px border through the same geometry reported to render as 1px. Modern UI replaces this indicator by default, reducing its reach but not fixing the supported classic presentation.

## Change summary

Make the classic Activity Bar's selected-item indicator render at its configured 2px width across web, native-window, and left/right sidebar layouts.

## Best solution

Correct the classic indicator geometry in `activityaction.css` so two device-visible pixels remain inside the Activity Bar for both side placements and relevant window-frame modes, without changing Modern UI's filled selection treatment.
