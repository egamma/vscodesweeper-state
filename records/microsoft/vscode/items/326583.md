# Issue #326583 — Assisted approvals - label color choice

[https://github.com/microsoft/vscode/issues/326583](https://github.com/microsoft/vscode/issues/326583)

## Summary

The semantic color hierarchy remains reversed on current main: Assisted permissions uses the warning treatment while the more permissive Allow all mode uses info. This is a valid, bounded UI polish item and should remain open.

## Change summary

Make the permission-level colors communicate that Allow all is riskier than Assisted permissions.

## Best solution

Use the warning treatment for Allow all and the informational treatment for Assisted permissions consistently across the standard and combined permission pickers, including high-contrast themes.
