# Issue #346004 — Bring back a way to decline extension terminal environment contributions

[https://github.com/microsoft/vscode/issues/346004](https://github.com/microsoft/vscode/issues/346004)

## Summary

Route to terminal maintainers: current source offers relaunch but no non-destructive dismissal of the environment warning. The existing automatic-relaunch setting does not cover this request.

## Change summary

Allow users to suppress or dismiss terminal environment-contribution warnings without terminating an existing process.

## Best solution

Provide a non-destructive way to decline the relaunch warning while preserving the running terminal and its environment. Terminal maintainers should decide whether this is a restored global preference or a per-terminal dismissal.
