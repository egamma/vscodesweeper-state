# Issue #246719 — Copying with empty selection clears the clipboard when editor.emptySelectionClipboard=false in Web mode

[https://github.com/microsoft/vscode/issues/246719](https://github.com/microsoft/vscode/issues/246719)

## Summary

Still reproduces on main: in web mode, the browser handles Cmd/Ctrl+C natively (VS Code deliberately does not bind copy keybindings in the browser). The textarea/editContext copy event handler unconditionally calls ensureClipboardGetsEditorData(), which calls e.preventDefault() and writes empty text to the clipboard when emptySelectionClipboard=false and the selection is empty — clearing whatever was previously on the clipboard.

## Change summary

Pressing Cmd/Ctrl+C in web mode with an empty selection and editor.emptySelectionClipboard=false clears the clipboard instead of leaving it untouched.

## Best solution

In the copy event handlers (textAreaEditContextInput.ts line ~389 and nativeEditContext.ts line ~128), check whether emptySelectionClipboard is false and the generated dataToCopy.text is empty — if so, skip calling ensureClipboardGetsEditorData() so the browser's default (no-op) copy behavior is preserved, matching desktop behavior.
