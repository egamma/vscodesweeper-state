# Issue #246719 — Copying with empty selection clears the clipboard when editor.emptySelectionClipboard=false in Web mode

[https://github.com/microsoft/vscode/issues/246719](https://github.com/microsoft/vscode/issues/246719)

## Summary

The web copy-event path still writes empty text to the clipboard when editor.emptySelectionClipboard is false and every selection is empty. Keep this open: the desktop command guard does not protect browser-native copy shortcuts.

## Change summary

Preserve existing clipboard contents when copying an empty editor selection in web mode with editor.emptySelectionClipboard disabled.

## Best solution

Make the browser copy-event path honor the same no-op behavior as the desktop command when empty-selection copying is disabled, while preserving ordinary selection copying and enabled whole-line copying.
