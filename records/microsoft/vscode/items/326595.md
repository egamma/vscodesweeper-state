# Issue #326595 — Assisted approval - git commands not automatically approved

[https://github.com/microsoft/vscode/issues/326595](https://github.com/microsoft/vscode/issues/326595)

## Summary

Current main still routes the reported read-only Git command to explicit confirmation whenever the SDK marks it as a sandbox-bypass request. This team-authored test finding must remain open while maintainers decide whether safe Git operations should stay sandboxed or whether assisted approval may authorize a bypass.

## Change summary

Assisted permissions require manual approval for a read-only compound Git status/log command because it is classified as a sandbox-bypass request.

## Best solution

Keep genuine sandbox escapes behind explicit approval, while allowing safe read-only Git commands such as the reported status/log sequence to execute within the sandbox and participate in assisted approval. If that cannot be guaranteed, the permissions owners should explicitly settle whether the assisted judge may approve sandbox-bypass requests.
