# Issue #185061 — Expired auth notification is not dismissed after (re)sign-in

[https://github.com/microsoft/vscode/issues/185061](https://github.com/microsoft/vscode/issues/185061)

## Summary

Keep open for authentication-owned UX design: the discussion rejects arbitrary notification dismissal, but explicitly asks VS Code to handle lost-login state. This team-authored Backlog item has neither a verified canonical duplicate nor an issue-linked fix.

## Change summary

Stop showing an obsolete signed-out notification when the user starts signing in again.

## Best solution

Provide authentication-specific, state-aware feedback for lost sessions without adding arbitrary dismissal to the general notification API. Establish the UI lifecycle with the authentication and API owners, including what remains visible if reauthentication fails.
