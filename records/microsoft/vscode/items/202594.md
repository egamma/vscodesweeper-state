# Issue #202594 — Middle click on Linux can only paste from copied text, not from the Primary buffer

[https://github.com/microsoft/vscode/issues/202594](https://github.com/microsoft/vscode/issues/202594)

## Change summary

Linux editor middle-click paste can insert regular clipboard content instead of the independently selected PRIMARY text.

## Best solution

- **Trace:**

CopyPasteController.handlePaste consumes the event data transfer, then mergeInDataFromCopy supplements it with NativeClipboardService.readResources from the regular clipboard when no URI list is present.
