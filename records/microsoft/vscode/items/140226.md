# Issue #140226 — Dispatch a chord keybinding again if it is not followed by a second part

[https://github.com/microsoft/vscode/issues/140226](https://github.com/microsoft/vscode/issues/140226)

## Summary

Valid feature request: when a chord keybinding times out, dispatch the first-part keybinding instead of doing nothing. The 5-second timeout is hardcoded and not configurable. Already labeled under-discussion with maintainer engagement — keeping open.

## Change summary

When a chord keybinding (e.g., Cmd+K Cmd+G) times out without a second keypress, dispatch the matching single-key binding (e.g., Cmd+K for terminal clear) instead of silently leaving chord mode.

## Best solution

Make the chord timeout configurable and optionally dispatch the first-part keybinding on timeout. The implementation lives in `src/vs/platform/keybinding/common/abstractKeybindingService.ts` around `_scheduleLeaveChordMode` / `_leaveChordMode`. A maintainer decision is needed on whether fallback dispatch should be the default or opt-in, given the UX tradeoffs discussed in the thread.
