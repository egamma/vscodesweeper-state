# Issue #283155 — Opening a private repo should not open the auth modal directly until I use chat

[https://github.com/microsoft/vscode/issues/283155](https://github.com/microsoft/vscode/issues/283155)

## Summary

Keep open: current source still permits a startup scope-upgrade modal for users signed in through Settings Sync who open a private repository. This is accepted, team-authored UX work in Backlog, and neither a referenced fix nor a qualifying older open duplicate was established.

## Change summary

Defer Copilot's additional GitHub permission prompt until the user interacts with chat, rather than interrupting private-repository opening.

## Best solution

Keep workspace opening nonmodal for users with limited-scope GitHub sessions, requesting additional permissions through an explicit chat interaction when needed. Preserve Settings Sync authentication and the existing user-initiated permission upgrade flow.
