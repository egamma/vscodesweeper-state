# Issue #342814 — Claude Sonnet 5.5: user-facing text before a tool call is returned as a summarized progress-update thinking block and never reaches chat as text (display: "summarized" is hardcoded)

[https://github.com/microsoft/vscode/issues/342814](https://github.com/microsoft/vscode/issues/342814)

## Summary

Keep open: current main retains the summarized-thinking request and reasoning-only processing described in the report. The controlled run and response samples provide enough information to retest; the remaining uncertainty is provider-side classification and whether the proposed display mode works through Copilot's endpoint.

## Change summary

User-facing Claude progress messages before tool calls can arrive only as summarized thinking, leaving users without the findings or questions the model assumes they saw.

## Best solution

Preserve user-facing progress updates as visible, complete chat content while keeping ordinary reasoning separate and maintaining signed thinking history. Establish the supported provider contract before changing request options or response classification.
