# Issue #236298 — variable -> Rename symbol -> ctrl+enter (Preview); doesn't work, collides with Cell Execution shortcut

[https://github.com/microsoft/vscode/issues/236298](https://github.com/microsoft/vscode/issues/236298)

## Summary

The collision remains explainable from current source: Jupyter Keymap's Ctrl+Enter execution binding outranks Rename Preview and does not exclude an active rename widget. Keep the issue open and move it to the VS Code-team-owned Jupyter Keymap tracker rather than closing it as extension-caused.

## Change summary

Ctrl+Enter in a notebook's Rename Symbol input executes the cell instead of opening the rename preview.

## Best solution

Notebook execution shortcuts should yield to the active Rename Symbol interaction, while retaining normal cell execution outside that interaction. The conflicting contribution lives in microsoft/vscode-jupyter-keymap's package.json, so the owning tracker should carry the issue.
