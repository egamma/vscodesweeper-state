This is a PowerShell parser issue, not a VS Code bug. VS Code defaults to UTF-8 without BOM — it does not automatically add BOM for non-ASCII filenames. The described parsing failure is in PowerShell's tokenizer interacting with OneDrive metadata, which is outside VS Code's responsibility.
