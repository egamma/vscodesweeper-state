# Issue #326725 — Markdown Editor renders in the tab space instead of document spave

[https://github.com/microsoft/vscode/issues/326725](https://github.com/microsoft/vscode/issues/326725)

## Summary

Keep open: a team member reproduced this during the experimental Markdown editor test plan, with a screenshot showing editor content incorrectly rendered over the tabs. The current evidence points toward custom-editor restoration in the Agents window rather than Markdown rendering itself.

## Change summary

Switching away from and back to an Agents window session can render an unsaved Markdown custom editor over the editor tabs and retain the document unexpectedly.

## Best solution

Trace session working-set restoration for dirty custom text editors and ensure the restored Markdown webview remains bounded to the editor content area. Clarify whether retaining the dirty document is expected hot-exit behavior or part of the same restoration defect.
