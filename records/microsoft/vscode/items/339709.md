# Issue #339709 — "edit" Agents welcome message, choosing "Phrases" takes you to the settings editor, where you can't actually change anything

[https://github.com/microsoft/vscode/issues/339709](https://github.com/microsoft/vscode/issues/339709)

## Summary

Confirmed from source: the new 'Phrases' pick in Customize Welcome Message opens the generic Settings editor on an object-typed setting with array/enum sub-properties, which the Settings UI cannot render as editable controls — so the only way to actually change it is the 'Edit in settings.json' link, exactly as the reporter (a VS Code maintainer testing their own recent PR) describes. Team-authored, brand-new bug report; keep open.

## Change summary

The 'Phrases' option in the Agents 'Customize Welcome Message' picker opens the Settings editor for agentSessions.experimental.welcomeMessages, an object setting with no inline-editable UI, forcing an extra click into settings.json to make any change.

## Best solution

Either jump straight to settings.json pre-scrolled to this setting (skipping the intermediate Settings UI page) or replace the 'Phrases' pick with an inline editor similar to the existing 'Name' pick's quick-input flow, so users can add/replace phrases without leaving the Agents window.
