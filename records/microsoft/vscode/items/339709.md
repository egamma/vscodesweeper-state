# Issue #339709 — "edit" Agents welcome message, choosing "Phrases" takes you to the settings editor, where you can't actually change anything

[https://github.com/microsoft/vscode/issues/339709](https://github.com/microsoft/vscode/issues/339709)

## Summary

Keep open as a welcome-customization usability improvement: choosing Phrases still opens graphical Settings rather than taking the user directly to an editable destination. This team-authored report identifies an extra navigation step, not an inability to customize phrases altogether.

## Change summary

Make the welcome message's Phrases action reach an editable configuration without an additional switch to settings.json.

## Best solution

Have the Phrases entry reach an editable representation of sessions.chat.experimental.welcomeMessages directly, preserving the existing configuration format and Name workflow.
