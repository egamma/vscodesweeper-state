# Issue #144532 — JavaScript Debug Console mangles output that includes both CSS and Object specifiers

[https://github.com/microsoft/vscode/issues/144532](https://github.com/microsoft/vscode/issues/144532)

## Summary

The mixed `%c` and `%o` path remains structurally reproducible in current source: JavaScript Debug emits ANSI-formatted text plus an expandable wrapper whose child is named `arg2`, and VS Code renders that wrapper as the output row. No fixing commit or canonical issue was found, so the accepted debug backlog item should remain open.

## Change summary

Render JavaScript console output containing both CSS and object format specifiers without exposing ANSI escapes or a redundant `arg2` object layer.

## Best solution

Preserve the styled combined message while exposing the substituted object exactly once as the row's expandable value. Add JavaScript Debug integration coverage for mixed `%c`/`%o` output and retain existing behavior for other format-specifier combinations.
