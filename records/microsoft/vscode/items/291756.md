# Issue #291756 — Can't partially reapply changes from cloud agent

[https://github.com/microsoft/vscode/issues/291756](https://github.com/microsoft/vscode/issues/291756)

## Summary

Keep open for the working-set behavior decision explicitly requested by the maintainer. Current source still distinguishes remote cloud changes from outstanding background changes, and neither a qualifying fix nor an older canonical covering partial reapplication was established.

## Change summary

Allow cloud-session changes to be reapplied after reverting only some of the previously applied files, with understandable working-set behavior.

## Best solution

Define how cloud-session Apply behaves when the workspace already contains part of the session's changes, then support restoring the reverted portion without disturbing retained changes. Coordinate the cloud working-set contract and its GitHub Pull Requests integration rather than assuming background-session clearing semantics solve this workflow.
