# Issue #319191 — Unify Copilot model settings to dropdown like `chat.utilityModel`

[https://github.com/microsoft/vscode/issues/319191](https://github.com/microsoft/vscode/issues/319191)

## Summary

Valid feature request to convert free-form model-ID settings in the Copilot extension to dynamic-enum dropdowns like `chat.utilityModel`. The infrastructure exists (`DefaultModelContribution`) but the Copilot-owned settings haven't adopted it yet. Stays open as a reasonable polish/UX improvement.

## Change summary

Change Copilot model settings (selectedCompletionModel, askAgent.model, exploreAgent.model, implementAgent.model) from free-text inputs to dropdown selectors populated with available models.

## Best solution

Extend the `DefaultModelContribution` pattern (already used for `chat.utilityModel` via `src/vs/workbench/contrib/chat/browser/utilityModelContribution.ts`) to the Copilot-owned agent/completion model settings in `extensions/copilot/package.json`, converting them from plain strings to dynamic enums backed by `ILanguageModelsService`.
