# Issue #319191 — Unify Copilot model settings to dropdown like `chat.utilityModel`

[https://github.com/microsoft/vscode/issues/319191](https://github.com/microsoft/vscode/issues/319191)

## Summary

The requested Settings-editor dropdowns remain missing; the existing completions picker and chat-model API only partially address discovery. Keep this Backlog Candidates request open as under-discussion: the older related issues cover different observable problems, not this full request.

## Change summary

Provide discoverable model dropdowns for four Copilot settings instead of requiring manually entered model identifiers.

## Best solution

Offer model choices appropriate to each setting while preserving existing configured values and default behavior. Explain that extensions can enumerate chat models through vscode.lm.selectChatModels(), while inline-completion models use a separate catalog and already have a dedicated picker.
