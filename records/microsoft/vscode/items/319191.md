# Issue #319191 — Unify Copilot model settings to dropdown like `chat.utilityModel`

[https://github.com/microsoft/vscode/issues/319191](https://github.com/microsoft/vscode/issues/319191)

## Summary

A real discoverability and validation gap remains for the Ask and Implement model overrides. Keep this Backlog Candidates request open under discussion; existing pickers cover completions and Explore only partially.

## Change summary

Replace free-form Copilot model override settings with selectors backed by the currently available models, or expose a supported model-list API.

## Best solution

Use the core dynamic-model configuration mechanism for agent overrides, preserving existing values and precedence. The completion setting can continue directing users to its existing picker, while Ask and Implement need equivalent validated selection surfaces.
