# Issue #322216 — Copilot Chat BYOK `vendor: openai` appears to ignore `maxInputTokens` and `maxOutputTokens`

[https://github.com/microsoft/vscode/issues/322216](https://github.com/microsoft/vscode/issues/322216)

## Summary

Confirmed bug: OAIBYOKLMProvider.createOpenAIEndPoint resolves model info from discovered/known-model metadata and ignores user-configured maxInputTokens/maxOutputTokens. An open PR (https://github.com/microsoft/vscode/pull/323019) directly fixes this issue but has not yet merged.

## Change summary

BYOK models configured with `vendor: openai` ignore user-specified `maxInputTokens` and `maxOutputTokens`, using discovered metadata instead, which inflates the context window and can cause unexpected cost increases.

## Best solution

Land the open fix PR https://github.com/microsoft/vscode/pull/323019, which makes the OpenAI provider honor an explicitly configured models array and fall back to discovery only when none is given. The fix touches `extensions/copilot/src/extension/byok/vscode-node/openAIProvider.ts` and related files.
