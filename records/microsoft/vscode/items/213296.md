# Issue #213296 — Keybindings editor should use pills for tags such as `@command` and `+when`

[https://github.com/microsoft/vscode/issues/213296](https://github.com/microsoft/vscode/issues/213296)

## Summary

The keybindings search still displays command and when-clause filters as plain text, so the requested readability improvement remains missing. Keep this team-authored Backlog request open for interaction design; no qualifying older duplicate or concrete implementation was identified.

## Change summary

Represent keybindings search filters such as @command and +when as readable pills, optionally collapsing long when clauses with an expansion affordance.

## Best solution

Make structured filters distinguishable from free-text search without changing their matching semantics. Settle how pills are edited and how collapsed when clauses remain inspectable and keyboard-accessible before implementing the presentation change in the keybindings search widget.
