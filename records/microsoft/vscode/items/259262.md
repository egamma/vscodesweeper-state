# Issue #259262 — Show a more prominent call to action for adding a failed command to chat

[https://github.com/microsoft/vscode/issues/259262](https://github.com/microsoft/vscode/issues/259262)

## Summary

The underlying attachment support has landed, but the discoverability gap remains: current main still exposes Add to Chat through the command decoration menu rather than a prominent failed-command call to action.

## Change summary

Make attaching a failed terminal command and its output to chat more prominent and discoverable.

## Best solution

Design an accessible, unobtrusive action near failed command output in the terminal, reusing the existing command-specific chat attachment path while avoiding persistent clutter for successful commands.
