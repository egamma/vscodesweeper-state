# Issue #206193 — Inspect Context Keys Should Open JSON File instead of logging to dev console

[https://github.com/microsoft/vscode/issues/206193](https://github.com/microsoft/vscode/issues/206193)

## Summary

Keep open: Inspect Context Keys still logs the selected element's context to the developer console rather than opening searchable JSON. The request is team-authored, has maintainer support, and already carries the correct area label.

## Change summary

Make Inspect Context Keys open the selected element's context values in a searchable JSON editor instead of logging them to the developer console.

## Best solution

Present the selected element's effective context values as formatted JSON in a VS Code editor, preserving the existing element-selection and inherited-context behavior. This belongs in the existing developer action rather than a separate extension.
