# Issue #74891 — Expect minimap functionality and similar to xcode 11

[https://github.com/microsoft/vscode/issues/74891](https://github.com/microsoft/vscode/issues/74891)

## Summary

A real gap remains: VS Code can show explicit section markers in the minimap, but it does not automatically display document symbols like the Xcode screenshot. This backlog request has 25 community upvotes and should remain open.

## Change summary

Show class, method, property, and other symbol names alongside their positions in the minimap for rapid navigation.

## Best solution

Add an opt-in editor-minimap mode that obtains document symbols from language providers and renders selected symbol names at their minimap positions, with limits that preserve editor performance.
