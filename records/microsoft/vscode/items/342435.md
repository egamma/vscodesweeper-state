# Issue #342435 — Per-token fontFamily: comment lines collapse after toggling word wrap

[https://github.com/microsoft/vscode/issues/342435](https://github.com/microsoft/vscode/issues/342435)

## Summary

Keep open: current source admits font-family-only token decorations into custom line-height reconstruction, where their absent height becomes zero. Toggling word wrap rebuilds that layout, matching the reported overlapping comment rows.

## Change summary

Comment text and line numbers collapse after toggling word wrap when comment tokens have a custom font family.

## Best solution

Preserve normal row heights for token decorations that change only the font family, including across wrapping changes, while continuing to honor explicit custom line heights.
