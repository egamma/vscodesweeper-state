## Summary

Keep open for a targeted macOS keyboard check: the supplied Tab → Enter versus Space steps suffice to retest. Current custom-dialog code activates the focused button, but native dialogs delegate keyboard behavior to Electron/macOS, so source inspection cannot confirm or dismiss the reported result.

## Change summary

Pressing Enter after tabbing to a non-default modal-dialog action reportedly executes the default action instead, while Space executes the focused action.

## Best solution
