# Issue #336427 — Modal dialog boxes are incompatible with keyboard navigation

[https://github.com/microsoft/vscode/issues/336427](https://github.com/microsoft/vscode/issues/336427)

## Summary

Plausible accessibility defect in the modal dialog's keyboard handling, but the report is a single, untested description with no repro confirmation, and the code path I traced (Dialog's window-level Enter handler plus Button's own per-element Enter/Space handler) does not obviously reproduce the described behavior — asking for confirmation and more detail before further action.

## Change summary

Reporter says pressing Enter in a VS Code modal dialog always triggers the default/highlighted button instead of the button currently focused via Tab, while Space works correctly.

## Best solution

If confirmed, the fix likely lives in src/vs/base/browser/ui/dialog/dialog.ts's global 'keydown' Enter handler and/or src/vs/base/browser/ui/button/button.ts's per-button Enter/Space handler — need a reliable repro (with/without a screen reader) to pin down whether propagation is being stopped correctly for the focused button element.
