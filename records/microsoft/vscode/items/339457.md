# Issue #339457 — Unable to delete a model/model group from "Chat: Manage Language Models"

## Summary

Active, maintainer-confirmed bug ('it is a bug', per vritant24) in the new Manage Language Models BYOK UI — the delete action is missing for a provider group row in some configurations. The exact root cause is still being pinned down: the maintainer's initial single-group theory was contradicted by the reporter's follow-up (same missing-delete symptom with two groups), and the maintainer just asked for clarification on which provider's group is affected. Too early to close or confidently assign a fix.
