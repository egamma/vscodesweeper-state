# Issue #329530 — vs code crashes on standard user (non-admin rights)

[https://github.com/microsoft/vscode/issues/329530](https://github.com/microsoft/vscode/issues/329530)

## Summary

The startup crash is a known Electron 42.7.1 child-process-spawn bug for standard (non-admin) Windows users, already fixed by the Electron 42.8.0 bump merged to main before this issue was even filed; a maintainer confirmed 1.132.x won't get a backport since 1.133 (which already contains the fix) rolls to stable this week.

## Change summary

VS Code 1.132.0 stable crash-loops at startup for standard (non-admin) Windows users, with GPU/renderer/network-service launch failures (error_code=57) and crashpad failing to launch.

## Best solution

No core VS Code code change needed — the fix already shipped on main via the Electron 42.8.0 bump (commit 28cf0a82a08a5f8e9288d19b4218ec1eb5ee46a6, PR #328712); once 1.133 reaches stable this week, standard users on a fresh install will no longer hit this.
