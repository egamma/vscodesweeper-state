# Issue #329530 — vs code crashes on standard user (non-admin rights)

[https://github.com/microsoft/vscode/issues/329530](https://github.com/microsoft/vscode/issues/329530)

## Summary

Root cause was an Electron 42.7.1 runtime defect that made GPU/network/crashpad child-process spawning fail for non-admin (standard-user) Windows accounts; the fix (bumping to Electron 42.8.0) already merged to main before this issue was even filed, and main now ships 42.8.1, so this is fixed going forward.

## Change summary
