[https://github.com/microsoft/vscode/issues/319926](https://github.com/microsoft/vscode/issues/319926)

## Summary

The strict-allowlist behavior was fixed after the reporter's July confirmation: enabledPlugins now blocks only explicitly false entries and leaves unlisted plugins under user control. The concrete fix remains present on current main, so this can be closed as completed.

## Change summary

Enterprise enabledPlugins entries should enable or disable named plugins without blocking unlisted plugins from the same or other marketplaces.

## Best solution
