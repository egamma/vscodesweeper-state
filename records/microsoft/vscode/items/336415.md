# Issue #336415 — Agents Window: Failed to sign in to GitHub. Would you like to try again?

[https://github.com/microsoft/vscode/issues/336415](https://github.com/microsoft/vscode/issues/336415)

## Summary

Fresh, member-authored bug report with a detailed self-diagnosis (confirmed against current source) of a transient extension-host startup race that surfaces as a misleading GitHub sign-in failure in the Agents Window; no fix exists yet, so this stays open for follow-up.

## Change summary

When the Agents Window's local extension host fails to become ready within 60s (e.g. during an update race), the built-in GitHub auth provider never registers, and the resulting internal timeout is surfaced to the user as a misleading 'Failed to sign in to GitHub' popup instead of a clearer extension-host startup error.

## Best solution

Improve the user-facing error so an extension-host readiness timeout (as thrown in localProcessExtensionHost.ts) is not misreported as a GitHub sign-out/sign-in failure by authenticationService.ts; likely also worth surfacing or logging the underlying 60s extension-host timeout more visibly so users don't mistake it for revoked credentials.
