# Issue #343209 — Pinned tasks are not retained in a newly created workspace

[https://github.com/microsoft/vscode/issues/343209](https://github.com/microsoft/vscode/issues/343209)

## Summary

Keep open: current source contains a task-pin identity mismatch when a single-folder window becomes a workspace. The supplied steps are sufficient; the automated upgrade suggestion does not establish that this is fixed.

## Change summary

Retain pinned tasks when saving a folder as a workspace or adding another workspace folder.

## Best solution

Preserve recognition of existing task pins across workspace conversion without depending on presentation text that changes during that conversion. Keep unrelated workspaces isolated and distinguish tasks with identical labels in different folders.
