# Issue #343209 — Pinned tasks are not retained in a newly created workspace

[https://github.com/microsoft/vscode/issues/343209](https://github.com/microsoft/vscode/issues/343209)

## Summary

Task pins can disappear when a single-folder window becomes a workspace: pin matching depends on the task description, which gains a folder name during that transition. The source still contains this defect; keep the report open.

## Change summary

Retain pinned tasks when saving a folder as a workspace or adding another folder.

## Best solution

Preserve task pin identity across workspace conversion without depending on changing display descriptions, while keeping same-named tasks from different folders distinct.
