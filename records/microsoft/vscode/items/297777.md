# Issue #297777 — `provideChatSessionProviderOptions` only called once per window?

[https://github.com/microsoft/vscode/issues/297777](https://github.com/microsoft/vscode/issues/297777)

## Summary

Team-authored issue where the immediate bug was worked around via `onDidChangeChatSessionProviderOptions` (commit 24a9782e80f), but the broader API improvement — having core persist selected session options across new sessions — remains unimplemented. Keeping open as a future enhancement.

## Change summary

Chat session provider options reset to defaults on each new session because `provideChatSessionProviderOptions` is only called once per window, not per session.

## Best solution

Update the chat sessions API to let extensions mark which `ChatSessionProviderOptions` properties should persist across sessions and which should reset, as discussed in comment 3 by mjbvz. The extension-side workaround (firing `onDidChangeChatSessionProviderOptions`) is in place but a core-level persistence mechanism would be cleaner.
