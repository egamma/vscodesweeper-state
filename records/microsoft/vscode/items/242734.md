# Issue #242734 — SCM Graph - background color of current commit in graph

## Summary

The requested persistent background cue remains missing: the existing command selects the current commit, but does not distinguish it independently of selection. Keep this accepted Backlog request open; no verified canonical owns the same work.

## Change summary

Provide an optional subtle background highlight for the current commit in the Source Control Graph, independent of the selected row.
