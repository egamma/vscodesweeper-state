# Issue #338583 — Plugin marketplace: failed ref clone leaves an empty cache that blocks unpinned installs

[https://github.com/microsoft/vscode/issues/338583](https://github.com/microsoft/vscode/issues/338583)

## Summary

Confirmed from source: a failed SHA-pinned ref clone leaves behind the parent directory it created, and the unpinned lookup treats that leftover empty folder as an already-cloned repository, permanently blocking install/retry until a maintainer clears the cache by hand.

## Change summary

A failed ref-specific plugin clone leaves an empty parent cache directory that then poisons the unpinned marketplace source, so install and Retry Install both keep failing.

## Best solution

Reuse the existing `_pruneEmptyParents` helper (already used by `cleanupPluginSource`) from `_cloneRepository`'s failure path in agentPluginRepositoryService.ts so a failed clone never leaves an empty ancestor behind, and/or harden `ensureRepository`'s exists-check so an empty/non-repo folder is not treated as a valid cached clone.
