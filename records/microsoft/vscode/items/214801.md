# Issue #214801 — Feature request: Issue reporter could automatically append a tag for language pack issues

[https://github.com/microsoft/vscode/issues/214801](https://github.com/microsoft/vscode/issues/214801)

## Summary

Keep this accepted, team-authored request open: the inspected reporter submission path forwards the title without adding a language-pack tag. No verified older canonical or concrete implementing commit was found.

## Change summary

Automatically prefix language-pack issue titles with the affected language identifier, such as [zh-cn].

## Best solution

Have the issue reporter carry the selected language pack's language identifier into the issue title while preserving routing to vscode-loc. Derive the tag from the reported pack, not the user's current display language, and leave unrelated extension reports unchanged.
