# Issue #347580 — # Extension command contributed to `chat/input/status` never executes

[https://github.com/microsoft/vscode/issues/347580](https://github.com/microsoft/vscode/issues/347580)

## Summary

The reported command-dispatch failure remains traceable on current main: the chat status toolbar forwards a circular ChatWidget object into extension-host RPC serialization. Keep this open; the supplied extension is sufficient to exercise the defect, despite the automated upgrade reminder.

## Change summary

Extension commands contributed to chat input toolbars silently fail when their forwarded context contains the live ChatWidget.

## Best solution

Make extension-contributed chat toolbar commands execute without transporting internal widget objects, while preserving the originating-widget context needed by built-in actions. Keep the correction scoped to chat invocation contexts rather than silently discarding arbitrary arguments throughout the command API.
