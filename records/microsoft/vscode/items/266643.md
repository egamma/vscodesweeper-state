[https://github.com/microsoft/vscode/issues/266643](https://github.com/microsoft/vscode/issues/266643)

## Summary

Keep this accepted Backlog request open: current commands explain committed history or review uncommitted files, but do not provide the requested per-file explanation action in the Source Control context menu. No qualifying older canonical was identified.

## Change summary

Add a Source Control file context-menu action that asks Copilot to explain that file's changes, including changes not yet committed.

## Best solution

Provide a diff-aware explanation action for individual Source Control files, integrated with the existing SCM and Chat surfaces. Preserve the distinction between explaining changes and reviewing them for problems.
