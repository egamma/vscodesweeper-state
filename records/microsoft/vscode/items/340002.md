## Change summary

Request for a new `vscode.window.createExtensionDialog`-style API letting extensions show a true modal, floating, webview-backed dialog for complex data entry, distinct from `showInformationMessage(modal: true)`, QuickPick, or a full WebviewPanel tab.

## Best solution

If pursued, this needs a maintainer design discussion: a modal webview surface raises accessibility (focus trapping, screen reader), theming, and 'simple/uniform UI' concerns that go beyond a routine API addition — a narrower proposal (e.g. richer structured QuickInput, or a lightweight non-modal floating webview) might be preferred over full modality.
