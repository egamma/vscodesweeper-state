# Issue #349389 — Allow hiding title bar when activity bar is on top

[https://github.com/microsoft/vscode/issues/349389](https://github.com/microsoft/vscode/issues/349389)

## Summary

The requested combination remains unsupported: top-positioned activity bars force the web title bar to remain visible. Keep this open for a layout design decision; existing title-bar settings and the inspected related issues do not cover retaining access to the displaced controls.

## Change summary

Allow hiding the title bar with activity bars positioned at the top while keeping the application menu, Accounts, and Manage controls accessible elsewhere.

## Best solution

Provide a coherent title-bar-free web layout that retains horizontal sidebar activity bars and discoverable, keyboard-accessible global controls. The workbench layout owners should decide the alternative control placement before implementation.
