# Issue #305192 — Sessions: Input text box loses content on switching to another session (and back)

[https://github.com/microsoft/vscode/issues/305192](https://github.com/microsoft/vscode/issues/305192)

## Summary

This was fixed after the report: current session-switching code flushes unsent input, persists it per external session, and restores it when that session is reopened.

## Change summary

Switching away from a session and back could discard text typed but not submitted in its input box.

## Best solution

Keep the per-session draft persistence implemented by https://github.com/microsoft/vscode/commit/d52c531dd37a84b06c82921c1fdd714d6a9fd222; no further change is needed for the reported session-switch path.
