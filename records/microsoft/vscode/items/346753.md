# Issue #346753 — Undo of a multi-file workspace edit never asks whether to undo it across all files

[https://github.com/microsoft/vscode/issues/346753](https://github.com/microsoft/vscode/issues/346753)

The missing confirmation is confirmed in current source: a workspace undo element incorrectly matches itself as another member of its undo group. Keep this open while the existing fixing PR is reviewed.

## Change summary

Restore the choice between undoing a standalone multi-file workspace edit across all files or only the current file.
