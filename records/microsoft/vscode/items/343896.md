# Issue #343896 — Move Up/Down keyboard shortcut does nothing after clicking a nested session that isn't open

[https://github.com/microsoft/vscode/issues/343896](https://github.com/microsoft/vscode/issues/343896)

## Summary

The reported focus transition still disables the reorder shortcut on current main, contradicting the linked test plan's select-then-move workflow. Keep this open to reconcile that workflow with the existing, explicitly tested click-to-chat focus behavior.

## Change summary

Selecting an unopened nested session transfers focus to chat, preventing Move Up/Down from responding until the list is focused again.

## Best solution

Make the documented select-then-reorder workflow dependable in the Agents window without accidentally reordering sessions while users edit chat input. Settle the intended focus and shortcut contract, then cover the first-click transition rather than only testing moves with list focus already established.
