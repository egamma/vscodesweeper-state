## Summary

Still reproduces on main: the click handler in the Agents window sidebar always calls `openOverview()` which resets to the welcome page, ignoring which customization section was clicked. Team-authored, no fix found.

## Change summary

Clicking a specific customization section in the Agents window sidebar opens the generic overview/welcome page instead of navigating to that section.
