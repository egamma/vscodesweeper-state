# Issue #292984 — Starting a code review does not warn when cancelling existing review

[https://github.com/microsoft/vscode/issues/292984](https://github.com/microsoft/vscode/issues/292984)

## Summary

Still reproduces on main. When a new review starts, ReviewSession.executeWithProgress cancels any review already running with no warning or confirmation. The issue is team-authored and labeled bug, so the protection rules keep it open; no fix commit or canonical duplicate exists.

## Change summary

Starting a second code review (e.g. `Chat: Review` on a selection) silently cancels a review that is already in progress instead of warning the user first.

## Best solution

Before a new review cancels the one in progress, `doReview.ts` should ask the user to confirm. If they decline, the existing review keeps running.
