# Issue #204942 — Add option to automatically move files to current tab group on open

[https://github.com/microsoft/vscode/issues/204942](https://github.com/microsoft/vscode/issues/204942)

## Summary

Keep this accepted feature request open: current group-selection behavior does not provide automatic relocation of already-open editors, and the directly linked implementation PR remains open. The 71 upvotes and Backlog acceptance support reviewing that contribution rather than retiring the request for inactivity.

## Change summary

Add an opt-in setting that moves an already-open file into the active editor group when opened, rather than switching groups or opening another copy.

## Best solution

Review https://github.com/microsoft/vscode/pull/205442 and settle its interaction with workbench.editor.revealIfOpen, then land an opt-in relocation behavior that preserves default opening behavior and explicit group targeting.

- **Existing capability does not cover relocation:** src/vs/workbench/browser/workbench.contribution.ts registers workbench.editor.revealIfOpen as revealing an existing editor in its current group, or preferring the active group when disabled. In src/vs/workbench/services/editor/common/editorGroupFinder.ts, doFindGroup selects groupWithInputActive || groupWithInputOpened for reveal requests; otherwise it falls back to the active group. This path selects a destination but does not move the existing editor out of another group. Targeted searches found neither moveToActiveGroupIfOpen nor the earlier revealIfOpenInActiveGroup setting.
