# Issue #315694 — bad quoting can cause terminal to hang

[https://github.com/microsoft/vscode/issues/315694](https://github.com/microsoft/vscode/issues/315694)

## Summary

Fixed on main: commit 78e725faf17 explicitly fixes this issue by detecting shell continuation prompts (dquote>, quote>) and aborting with Ctrl+C instead of hanging indefinitely. A preceding commit c414bd93deb (PR #315885) also contributed a partial fix.

## Change summary

Unmatched quotes in a run_in_terminal command cause the shell to enter a continuation prompt (e.g. dquote>), hanging the terminal tool indefinitely.

## Best solution

Keep the shipped fix — continuation prompt detection and abort in all three execute strategies (rich, basic, none). No further change needed.
