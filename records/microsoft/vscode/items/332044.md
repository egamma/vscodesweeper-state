## Summary

Fresh, detailed report of Copilot Voice Mode misapplying voice.md instructions, but the actual defect (if any) lives in the realtime voice backend service, not in this repo's client code, so it can't be verified from the checkout; asking for build confirmation and follow-up detail before routing.

## Change summary

Custom instructions placed in voice.md (via 'Voice: Configure Voice Mode Instructions') have no effect on assistant narration, and instead the instruction text shows up in the recognized transcript of the user's own spoken prompt.

## Best solution

A Copilot Voice service owner should trace how `voice_instructions` (sent on start_session/resume_session) is consumed server-side — it may be getting applied to the wrong channel (input transcription vs. output narration instructions) — since the VS Code client only assembles and forwards the text correctly.
