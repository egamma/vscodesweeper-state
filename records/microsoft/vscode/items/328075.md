# Issue #328075 — GitHub Copilot `file_search` truncation can cause false “file does not exist” conclusions

[https://github.com/microsoft/vscode/issues/328075](https://github.com/microsoft/vscode/issues/328075)

## Summary

The defect is present in source: `file_search` truncates results to 20 by default and represents omitted matches only with `...`, allowing agents to mistake a partial inventory for a complete one.

## Change summary

Make `file_search` explicitly report when matching paths were omitted from its returned result set.

## Best solution

Update `FindFilesResult` to state how many of the total matches are shown and advise narrowing the query or increasing `maxResults`; cover truncated and complete result sets with focused tests.
