# Issue #328075 — GitHub Copilot `file_search` truncation can cause false “file does not exist” conclusions

[https://github.com/microsoft/vscode/issues/328075](https://github.com/microsoft/vscode/issues/328075)

## Summary

The misleading truncation remains on current main: `file_search` reports the total, returns the capped subset, and represents omitted results only with a trailing ellipsis. This is a bounded agent-tool output polish issue rather than a duplicate of the related search-scope defects.

## Change summary

Make `file_search` explicitly tell the model how many results were returned, that additional matches were omitted, and how to refine or repeat the search.

## Best solution

Have `FindFilesResult` emit an explicit, machine-comprehensible truncation notice such as “Showing 20 of 171 results; narrow the query or increase maxResults,” while preserving the existing file references and complete-result output.
