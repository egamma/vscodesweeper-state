# Issue #328079 — Can't close first chat in multi-chat

[https://github.com/microsoft/vscode/issues/328079](https://github.com/microsoft/vscode/issues/328079)

## Summary

The first chat remains intentionally non-closeable on current main, so the requested uniform close behavior is still missing. This team-authored request has no older canonical with the same symptom and should remain open for a product decision on last-visible-chat behavior.

## Change summary

Allow the first or main chat in a multi-chat agent session to be closed like the additional chat tabs.

## Best solution

Treat the main committed chat like peer chats for tab closing: hide it without deleting it and keep it reopenable from the Chats picker. Define explicitly what Close does when it targets the session's last visible chat.

- **Behavior:**

  > Every closeable committed chat tab in a multi-chat agent session, including the first or main chat, should expose consistent Close behavior. Closing a chat hides it without deleting its conversation and leaves it available from the Chats picker for reopening. Closing the active main chat must select a valid remaining visible chat. Acceptance must also cover the explicitly chosen behavior when the target is the last visible chat.
- **Trace:**

  > The restriction exists at two layers: ChatCompositeBar in src/vs/sessions/browser/parts/chatCompositeBar.ts omits the actions toolbar for `isMainChat`, while VisibleSession.closeChat in src/vs/sessions/services/sessions/browser/visibleSessions.ts rejects the main resource. SessionContextKeys consequently marks only non-main chats closeable, and CloseChatAction in src/vs/sessions/contrib/sessions/browser/sessionsActions.ts treats a main-chat close as chat-group removal rather than tab hiding. Existing tests encode this restriction in visibleSessions.test.ts and chatCompositeBar.test.ts. Keep provider deletion semantics and the main chat's role as the session identity unchanged; this request concerns view visibility and reopening, not deleting the provider-owned chat. The exact companion https://github.com/microsoft/vscode/issues/333988 is newer and cannot absorb this re-reviewed issue.
- **Open decisions:**
  - When the main chat is the last visible chat, should Close be unavailable, close the entire session surface, or leave the session with no visible chat?
