# Issue #328079 — Can't close first chat in multi-chat

[https://github.com/microsoft/vscode/issues/328079](https://github.com/microsoft/vscode/issues/328079)

## Summary

Confirmed on current main: the first/main chat is explicitly prevented from closing. Keep open because this team-authored report defines the expected multi-chat behavior and the gap requires changing the main-chat lifecycle.

## Change summary

Allow every chat tab in a multi-chat agent session, including the first tab, to be closed.

## Best solution

Support hiding the main chat while retaining a valid session and active-chat fallback, then allow the existing close action and tab toolbar on that chat. Preserve reopening and zero-visible-tab behavior in the visibility model.
