# Issue #332473 — execution_subagent detached terminal completion does not notify parent chat

[https://github.com/microsoft/vscode/issues/332473](https://github.com/microsoft/vscode/issues/332473)

## Summary

The missing completion notification is explained by current source: terminal commands invoked by a subagent explicitly bypass background notification registration, while execution_subagent returns only a static handoff note. Keep this team-authored report open; no verified canonical issue or qualifying fix was found.

## Change summary

Notify or resume the parent chat with the terminal ID, exit code, and final output when a command detached by execution_subagent completes.

## Best solution

Preserve parent-chat ownership of terminal work handed back by execution_subagent, delivering completion through the existing terminal notification lifecycle without attempting to resume the finished subagent loop. Preserve cancellation, notification deduplication, and the behavior of directly owned background terminals.
