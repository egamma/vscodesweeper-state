# Issue #116109 — Investigate debug UI for highly concurrent languages

[https://github.com/microsoft/vscode/issues/116109](https://github.com/microsoft/vscode/issues/116109)

## Summary

Valid, actively discussed feature request for debug UI improvements supporting highly concurrent languages (Go, C#, CUDA, Erlang). No implementation of thread paging, filtering, or parallel stacks exists on main — the core ask remains unaddressed.

## Change summary

Improve the debug UI to handle highly concurrent languages with many threads/goroutines/processes via paging, filtering, grouping, and focus-based views.

## Best solution

This is a substantial design effort spanning DAP protocol changes and VS Code debug UI. The next concrete step is deciding on an MVP (e.g. single-thread focus mode with a thread switcher, as davidfowl suggested) and iterating on the DAP spec proposals (microsoft/debug-adapter-protocol#159, #169). Related issues #140845 and #214824 track narrower sub-requests that could land independently.
