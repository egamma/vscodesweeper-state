# Issue #142922 — Debug Console Filter is a bit confusing

[https://github.com/microsoft/vscode/issues/142922](https://github.com/microsoft/vscode/issues/142922)

## Summary

The Debug Console still needs a clearer persistent indication that filtering is active and a true Find experience; the maintainer discussion endorses matching the Problems view, and no verified canonical issue absorbs the full request.

## Change summary

Make an active Debug Console filter obvious, provide an unambiguous way to clear it, and support finding output without hiding surrounding context.

## Best solution

Align the Debug Console's active-filter presentation with the Problems view and add a separate Find interaction that navigates matches while preserving surrounding output; retain Filter as a distinct operation.
