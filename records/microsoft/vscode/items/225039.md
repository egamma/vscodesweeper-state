# Issue #225039 — Context menu shows up on left click for deleted lines, not right click

[https://github.com/microsoft/vscode/issues/225039](https://github.com/microsoft/vscode/issues/225039)

## Summary

The inline diff's deleted-line menu still lacks right-click handling on main. Keep this open in diff-editor; the existing left-click lightbulb action is a separate interaction that should remain available.

## Change summary

Make the deleted-line context menu available through right-click without treating ordinary text clicks as menu activation.

## Best solution

Right-clicking deleted content in an inline diff should expose its applicable copy and revert actions, while ordinary left-click supports text selection and the lightbulb remains an explicit action-menu control.
