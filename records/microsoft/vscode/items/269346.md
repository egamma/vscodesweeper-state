# Issue #269346 — [html] Incorrect onclick attribute Parsing

[https://github.com/microsoft/vscode/issues/269346](https://github.com/microsoft/vscode/issues/269346)

## Summary

The defect remains on current main: HTML event-handler attributes are validated as embedded JavaScript without decoding HTML character references, causing valid handlers containing `&quot;` to receive JavaScript syntax errors.

## Change summary

Valid HTML character references inside inline event-handler attributes are incorrectly reported as JavaScript syntax errors.

## Best solution

Decode HTML character references in JavaScript attribute regions before TypeScript validation while preserving source offsets so diagnostics and language features continue to map to the original HTML document.
