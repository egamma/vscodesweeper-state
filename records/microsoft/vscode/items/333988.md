# Issue #333988 — Agents: cannot close the session's main chat tab

[https://github.com/microsoft/vscode/issues/333988](https://github.com/microsoft/vscode/issues/333988)

## Summary

Confirmed on main: `_createTab` in chatCompositeBar.ts gates the close affordance with `!isMainChat` (line 376), so the session's main chat tab has no close button by design. A team member already opened a fixing PR, so this should stay open for that PR to be reviewed and landed rather than closed now.

## Change summary

Allow the session's main chat tab to be closed/hidden like any other tab, as long as the session keeps at least one visible tab.

## Best solution
