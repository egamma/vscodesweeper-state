# Issue #265856 — Don't suggest illegal variable names

[https://github.com/microsoft/vscode/issues/265856](https://github.com/microsoft/vscode/issues/265856)

## Summary

A team member (hediet) already acknowledged this as inherent LLM behavior — "mistakes like this are in the nature of LLMs" — which is effectively an as-designed statement. Copilot completions are generated by a language model and may occasionally produce syntactically invalid suggestions; post-hoc keyword filtering is not currently part of the inline completions pipeline.

## Change summary

Copilot inline completion suggested renaming a misspelled variable `dlete` to `delete`, which is a reserved keyword in TypeScript.

## Best solution

Close as as-designed per the maintainer's assessment. LLM-generated completions are probabilistic and may occasionally suggest reserved keywords; adding a keyword-blocklist filter could be a future quality improvement but is not a bug in the current design.
