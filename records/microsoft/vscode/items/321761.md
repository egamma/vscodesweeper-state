# Issue #321761 — "Reserved for response" ignores `maxOutputTokens` for extension-contributed models (hard-coded to 8192)

[https://github.com/microsoft/vscode/issues/321761](https://github.com/microsoft/vscode/issues/321761)

## Summary

Confirmed on current main: `ExtensionContributedChatEndpoint.maxOutputTokens` is hard-coded to 8192 at extensions/copilot/src/platform/endpoint/vscode-node/extChatEndpoint.ts:67-70, ignoring the provider's declared value. An open PR (#323019) already addresses this — keep the issue open until that PR lands.

## Change summary

The "Reserved for response" bar in the context window widget always shows ~8192 tokens for extension-contributed models, regardless of the model's actual `maxOutputTokens`.

## Best solution

Land https://github.com/microsoft/vscode/pull/323019, which adds `maxOutputTokens` to the language-model capabilities API and consumes it in `extChatEndpoint.ts` with a fallback to 8192. The issue stays open until that PR merges.
