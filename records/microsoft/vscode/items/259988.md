# Issue #259988 — Cannot read properties of undefined (reading '1')

[https://github.com/microsoft/vscode/issues/259988](https://github.com/microsoft/vscode/issues/259988)

## Summary

Still reproduces on main: the canonical error-telemetry issue for a race condition in notebookSelectionHighlight.ts where `this.anchorCell` becomes undefined after an `await`, then is accessed without a null guard on line 64. Three other issues are closed as duplicates of this one.

## Change summary

TypeError crash when `this.anchorCell` is accessed after an async gap in the notebook selection highlighter's `onDidChangeActiveCell` handler.

## Best solution

Add a null guard for `this.anchorCell` after the `await Event.toPromise(...)` on line 58, before accessing `this.anchorCell[1]` on line 64. The `await` yields control, allowing a concurrent `onDidChangeActiveCell` to clear `anchorCell`.
