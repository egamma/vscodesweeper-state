# Issue #278895 — Improve JSON detection by checking if it can be parsed

[https://github.com/microsoft/vscode/issues/278895](https://github.com/microsoft/vscode/issues/278895)

## Summary

Keep open under discussion: parser-assisted detection remains a distinct proposal, and existing language settings do not guarantee automatic recognition of pasted JSON. The maintainer's performance concern needs measurements and a decision about ambiguous or truncated inputs before implementation.

## Change summary

Use syntax validation to improve automatic language detection of pasted JSON, potentially extending the approach to other structured formats.

## Best solution

Evaluate bounded JSON syntax recognition within the language-detection worker against the existing models, measuring accuracy, latency, and memory before deciding whether it should influence detection. Preserve explicit language choices and model fallback for content that does not qualify.

Explicitly selected language modes must remain unchanged, and performance must meet a maintainer-approved budget.
