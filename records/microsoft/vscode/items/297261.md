# Issue #297261 — Restart server duplicated in Context menu

[https://github.com/microsoft/vscode/issues/297261](https://github.com/microsoft/vscode/issues/297261)

## Summary

Still reproduces on main: AuthServerAction's constructor is a copy-paste from RestartServerAction, using the same action ID ('extensions.restart') and initial label ('Restart Server'), causing it to appear as a duplicate 'Restart Server' entry in the context menu when the auth action is present but not yet updated or when conditions cause both to show.

## Change summary

The MCP server context menu shows 'Restart Server' twice because AuthServerAction reuses RestartServerAction's ID and initial label.

## Best solution

Fix the copy-paste bug in AuthServerAction's constructor at src/vs/workbench/contrib/mcp/browser/mcpServerActions.ts:941 — give it a unique action ID (e.g. 'extensions.auth') and appropriate initial label. Additionally, the context menu consumers should filter out disabled/hidden actions before displaying them.
