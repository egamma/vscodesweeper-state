# Issue #310102 — Getting "Retried with Autopilot" messages with autopilot disabled

[https://github.com/microsoft/vscode/issues/310102](https://github.com/microsoft/vscode/issues/310102)

## Summary

The confusing 'Retried with Autopilot' retry wording was fixed in commit 0725586ae9 (PR #312458), which improved the messages to distinguish autopilot from auto-approve mode. Shipped in 1.118.0; the reporter was on 1.115.0.

## Change summary

Retry progress messages in chat sessions incorrectly mentioned 'Autopilot' even when only auto-approve (not autopilot) was enabled.

## Best solution

Keep the shipped fix in commit 0725586ae9 — the retry messages now correctly show 'Recovering from a request error…' for auto-approve mode and 'Autopilot: recovering from a request error…' only for actual autopilot mode. No further change needed.
