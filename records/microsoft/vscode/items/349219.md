# Issue #349219 — Copilot sessions disappear from the Sessions view after Save Workspace As on an untitled multi-root workspace

[https://github.com/microsoft/vscode/issues/349219](https://github.com/microsoft/vscode/issues/349219)

## Summary

The supplied checkout confirms the visibility failure: saving changes workspace-file identity, but agent-host sessions retain their original provenance and fail the strict identity filter. Keep this distinct from local-chat index migration and destructive session-deletion reports; the checkout predates the reported build, so a later fix is not established.

## Change summary

Preserve access to existing Copilot agent-host sessions after saving an untitled multi-root workspace.

## Best solution

Session association should survive the untitled-to-saved workspace transition and subsequent restarts, without mixing sessions from unrelated saved workspaces that share folders. Provide a safe recovery path for sessions already stranded on deleted untitled-workspace identities.
