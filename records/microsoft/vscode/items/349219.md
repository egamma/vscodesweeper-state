# Issue #349219 — Copilot sessions disappear from the Sessions view after Save Workspace As on an untitled multi-root workspace

[https://github.com/microsoft/vscode/issues/349219](https://github.com/microsoft/vscode/issues/349219)

## Summary

Keep open: current source confirms that saving the workspace changes its identity while agent-host sessions retain the old identity and are filtered out. Local-chat migration does not repair that association; this is missing visibility, not demonstrated data loss.

## Change summary

Preserve access to existing Copilot agent-host sessions when an untitled multi-root workspace is saved.

## Best solution

Sessions belonging to the untitled workspace should remain associated with its saved successor across restarts, without mixing sessions from independent workspace files that share folders. Establish the durable transition and recovery path rather than weakening workspace isolation globally.
