# Issue #327760 — Streaming terminal output not updating with async Terminal call

[https://github.com/microsoft/vscode/issues/327760](https://github.com/microsoft/vscode/issues/327760)

## Summary

Thanks for the report. This is a confirmed Agent Host regression against the terminal-streaming test plan and should remain open, routed to the Agent Host and chat-terminal owners.

## Change summary

Async built-in shell calls fail to stream subsequent output, and their partial output becomes unavailable after switching sessions.

## Best solution

Preserve and continuously update the non-PTY output channel through async handoff, then retain its snapshot and session association when switching sessions. The likely ownership spans the Agent Host shell-output channel and chat terminal renderer introduced by https://github.com/microsoft/vscode/pull/327067.
