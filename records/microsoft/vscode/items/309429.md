# Issue #309429 — Back shortcut doesn't work in Agent Customizations when on an MCP server

[https://github.com/microsoft/vscode/issues/309429](https://github.com/microsoft/vscode/issues/309429)

## Summary

The AI Customization editor does not integrate with VS Code's editor navigation history, so the mouse back button and `workbench.action.navigateBack` shortcut cannot return to the previous view when drilling into an MCP server detail. The editor would need to implement `IEditorPaneWithSelection` (or similar navigation-history integration) to support this. Team-authored polish item, keeping open.

## Change summary

The back mouse button / back shortcut does not navigate back from an MCP server detail view in the AI Customizations editor.

## Best solution

Implement `IEditorPaneWithSelection` or equivalent navigation-history integration in `AICustomizationManagementEditor` so that navigating into MCP detail (and other detail views) pushes a navigation entry, allowing `workbench.action.navigateBack` and mouse back button to return to the previous view. The related issue https://github.com/microsoft/vscode/issues/309420 was closed but may not have fully addressed the MCP server detail case.
