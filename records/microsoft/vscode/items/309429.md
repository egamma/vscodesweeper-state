# Issue #309429 — Back shortcut doesn't work in Agent Customizations when on an MCP server

[https://github.com/microsoft/vscode/issues/309429](https://github.com/microsoft/vscode/issues/309429)

## Summary

Keep open: MCP details have an explicit Back button, but standard back navigation is not connected to that in-editor transition. The related public report is closed, and no issue-referencing fix or open public canonical was found.

## Change summary

Make mouse-back and standard back shortcuts return from an MCP server's details to the originating Agent Customizations view.

## Best solution

Make standard back navigation honor the active customization detail view before falling through to editor or session history, preserving its existing return destination and focus behavior. Coordinate with the related navigation work without changing back navigation outside Customizations.
