## Summary

Valid feature request for supporting the non-standard `uniqueKeys` JSON Schema vocabulary in VS Code's JSON validator. No implementation exists on main; the capability gap is real but the vocabulary is a third-party extension to JSON Schema, not part of any official draft.

## Change summary

Support the `uniqueKeys` keyword from the json-everything array-ext vocabulary in VS Code's JSON validation for settings.json.

## Best solution

This is a niche vocabulary outside official JSON Schema specs. The most practical path for the reporter is to implement custom validation in their extension. If VS Code were to support this, it would belong in the vscode-json-languageservice (upstream dependency) rather than in core — consider whether this should be an upstream request to https://github.com/microsoft/vscode-json-languageservice.
