# Issue #328776 — Should we remove collapse button for plan mode?

[https://github.com/microsoft/vscode/issues/328776](https://github.com/microsoft/vscode/issues/328776)

## Summary

Keep open: this team-authored UX-polish issue identifies live, intentionally tested plan-review interactions, and a maintainer agreed the collapse control may not be useful while proposing further design exploration. The desired interaction still needs a product decision.

## Change summary

Simplify the plan-review card by reconsidering its collapse, edit/open, and feedback-close controls and tightening the feedback copy.

## Best solution

Give plan review one clear path into feedback, an intentional way to return attention to the chat, and concise action copy without redundant controls. The chat UX owner should first decide whether collapsing and a distinct feedback mode remain part of that interaction.
