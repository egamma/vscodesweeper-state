# Issue #336059 — Markdown Preview does not reveal the clicked Search result when it is the default editor for .md files

[https://github.com/microsoft/vscode/issues/336059](https://github.com/microsoft/vscode/issues/336059)

## Summary

Verified duplicate: the root cause is the same core API gap already tracked by the open, assigned issue #289785 — Search (and other location-carrying navigation) doesn't pass a target selection/range to any custom-editor/webview editor, including VS Code's own Markdown Preview when it's set as the default editor for .md files.

## Change summary

When Markdown Preview is the default editor for .md files, clicking a Search result (or other location-carrying navigation) doesn't scroll the preview to the matched line.

## Best solution

Fix the general gap in https://github.com/microsoft/vscode/issues/289785 (extend the custom editor open context with a target selection/range) — that would resolve this report as a side effect once the Markdown Preview extension consumes it; no separate core work is needed for this issue.
