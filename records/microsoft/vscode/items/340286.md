# Issue #340286 — Support workspace-scoped keyboard shortcuts

[https://github.com/microsoft/vscode/issues/340286](https://github.com/microsoft/vscode/issues/340286)

## Summary

Genuine gap: VS Code only supports a user/profile-scoped keybindings.json, not a project-committed one, and a maintainer comment only addressed the secondary ask (running a script via a shortcut, via tasks.json) — the core request is unaddressed. This just entered the 60-day Backlog Candidates upvote window, so it should stay open per the community process.

## Change summary

Allow a checked-in .vscode/keybindings.json so a project can define and share keyboard shortcuts without touching each user's global keybindings.

## Best solution

No existing surface covers project-scoped keybindings today; if demand grows (20+ upvotes) this would need design work in the keybinding service (src/vs/workbench/services/keybinding) to add a workspace-level keybindings resource layered under the user one, similar to how workspace settings layer over user settings.
