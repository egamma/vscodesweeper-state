Acceptance should cover first-run no-auth chat on Dev Box and a normal laptop, plus a deliberately non-responsive request.
- **Trace:**

The source trace does not establish which stage stalls or whether the late success is the same timed-out request, so correlate the request ID and timestamps before choosing a remedy.
