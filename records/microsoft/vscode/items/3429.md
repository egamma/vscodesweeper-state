# Issue #3429 — [themes] Themes don't support background styling

[https://github.com/microsoft/vscode/issues/3429](https://github.com/microsoft/vscode/issues/3429)

## Summary

Keep open: current token rendering still does not support theme-defined token backgrounds, and an open implementation PR explicitly references this issue. The remaining work is to evaluate that proposal and resolve its compatibility and decoration-layering concerns.

## Change summary

Support background colors on scoped theme rules, including TextMate themes, rather than rendering only foreground and font styles.

## Best solution

Evaluate https://github.com/microsoft/vscode/pull/212294 against both TextMate and standalone token rendering, preserving selection, search-match and word-highlight visibility. Settle backward compatibility for themes with previously ignored background rules before landing support.
