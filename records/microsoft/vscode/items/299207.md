# Issue #299207 — AI Customizations: Hover should be placed at mouse position and not element

[https://github.com/microsoft/vscode/issues/299207](https://github.com/microsoft/vscode/issues/299207)

## Summary

Still present on main: many hovers in the AI Customizations editor use `getDefaultHoverDelegate('element')` instead of `'mouse'`, causing the tooltip to overlap entries. Team-authored polish item — keeping open.

## Change summary

Hovers in the AI Customizations editor use element-anchored placement instead of mouse-anchored placement, causing tooltips to obscure adjacent entries.

## Best solution

Change the `getDefaultHoverDelegate('element')` calls in `src/vs/workbench/contrib/chat/browser/aiCustomization/aiCustomizationManagementEditor.ts` (and possibly other files in that directory) to `getDefaultHoverDelegate('mouse')` where the hover is on list/tree entries whose tooltip would block neighboring items. The list widget already uses `'mouse'` (lines 361/391 of `aiCustomizationListWidget.ts`) — apply the same pattern to the management editor's entry hovers.
