# Issue #236576 — Make editor dimming a core workbench feature

[https://github.com/microsoft/vscode/issues/236576](https://github.com/microsoft/vscode/issues/236576)

## Summary

A real architectural gap remains on main: unfocused dimming still depends on an explicit CSS allowlist, and newer editor types continue to expose omissions. This issue is the canonical tracker and should remain open.

## Change summary

Move unfocused editor dimming from fragile CSS overrides into a core workbench or editor abstraction.

## Best solution

Give editor or workbench-part abstractions native unfocused-dimming support, then remove the editor-type CSS allowlist from `unfocusedViewDimmingContribution.ts`. The implementation should consistently cover text, webview, notebook, chat, and future editor types without disrupting overlays or hover positioning.
