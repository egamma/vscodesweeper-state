# Issue #322981 — Feature Request: Isolated local sandboxes for parallel Copilot Chat operations

[https://github.com/microsoft/vscode/issues/322981](https://github.com/microsoft/vscode/issues/322981)

## Summary

The core isolation/worktree mechanism the reporter wants already exists in the Agents Window; the refined ask (after alexdima's reply) is to surface that same worktree-based sandboxing directly in the classic Copilot Chat panel without switching to the Agents Window. This is a genuine feature gap — the classic chat panel does not yet offer worktree-isolated sessions — and no canonical issue clearly owns this specific request. Keeping open as a feature request.

## Change summary

Allow spawning worktree-isolated parallel Copilot Chat sessions directly from the classic editor's chat panel, without requiring a switch to the Agents Window.

## Best solution

Route to the chat/agents-window area owners to evaluate whether classic-window chat should support worktree-isolated sessions inline, or whether the Agents Window remains the intended surface for this workflow. The underlying worktree infrastructure already exists in `src/vs/sessions/` and `src/vs/workbench/contrib/chat/browser/agentSessions/`; the question is UX surface, not plumbing.
