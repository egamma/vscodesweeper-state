# Issue #322981 — Feature Request: Isolated local sandboxes for parallel Copilot Chat operations

[https://github.com/microsoft/vscode/issues/322981](https://github.com/microsoft/vscode/issues/322981)

## Summary

Keep open for a focused Chat-panel integration decision. Current code already supports worktree-isolated Copilot CLI sessions in the classic window, but that does not establish completion of the reporter's clarified native Chat workflow and approval-to-publishing experience.

## Change summary

Enable parallel, worktree-isolated Copilot tasks directly from the classic Chat panel, with reviewed changes flowing into branch, commit, push, and pull-request actions.

Reuse the existing worktree/session infrastructure to provide a coherent isolation and review-to-publish workflow inside the classic editor. First establish whether the existing Copilot CLI session experience meets the intended execution requirements or whether native Local-agent support is also required.
