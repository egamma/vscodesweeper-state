# Issue #268442 — Weird bug when closing the auto quotation double quotes in any HTML file

[https://github.com/microsoft/vscode/issues/268442](https://github.com/microsoft/vscode/issues/268442)

Keep open: the supplied HTML completion steps are sufficient to retest, but the intermittent extra quote is not conclusively confirmed against current main. Current source includes snippet-pair tracking, so identifying why these completions lose overtype behavior requires tracing the actual inserted edit and subsequent typing.

## Change summary

Typing a closing double quote inside an HTML attribute populated through completion sometimes inserts an extra quote instead of moving past the existing one.

## Best solution

Make HTML attribute completions preserve closing-quote overtype behavior consistently for lang and meta charset attributes, without changing ordinary quote insertion or deliberately disabling overtype.
