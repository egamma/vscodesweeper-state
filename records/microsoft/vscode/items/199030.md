# Issue #199030 — File links: Support opening files with relative "file://" paths

[https://github.com/microsoft/vscode/issues/199030](https://github.com/microsoft/vscode/issues/199030)

## Summary

Relative file URI navigation is implemented and shipped. Current main resolves the supported `file://./…` and `file:///./…` forms relative to the containing file, including parent-directory traversal.

## Change summary

Allow portable file links in source comments without embedding machine-specific absolute paths.

## Best solution

Use `file:///./../../package.json` for the reported parent-relative case. The cross-platform correction landed in commit 5af7860ca23d38281f1f6d5b229b4668d2f13e24 and shipped in VS Code 1.88.0.
