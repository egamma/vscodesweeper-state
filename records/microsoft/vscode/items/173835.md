# Issue #173835 — Dragging view container with hidden views into another view container makes all visible

[https://github.com/microsoft/vscode/issues/173835](https://github.com/microsoft/vscode/issues/173835)

## Summary

Still reproduces on main: when a view container is dragged into another view container, all hidden views become visible because `moveViewsToContainer` defaults to `ViewVisibilityState.Expand` instead of preserving existing visibility state.

## Change summary

Dragging a view container with hidden views into another view container makes all hidden views visible.

## Best solution

Pass `ViewVisibilityState.Default` instead of omitting the `visibilityState` parameter in the two `moveViewsToContainer` calls in `viewPaneContainer.ts` (lines ~496 and ~963) that handle container-into-container drops, so that existing view visibility is preserved during the merge.
