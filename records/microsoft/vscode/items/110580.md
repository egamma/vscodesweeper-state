# Issue #110580 — [rename on type] stops when composing characters

[https://github.com/microsoft/vscode/issues/110580](https://github.com/microsoft/vscode/issues/110580)

## Summary

The bug remains in current main: linked editing processes intermediate composition model changes without observing composition start/end, allowing the temporary text to invalidate and clear the linked ranges.

## Change summary

Linked editing stops synchronizing related ranges when a character is entered through an IME or dead-key composition sequence.

## Best solution

Keep linked-editing state intact while composition is active and synchronize the completed text when composition ends, without changing ordinary typing, breakout, or provider word-pattern behavior.
