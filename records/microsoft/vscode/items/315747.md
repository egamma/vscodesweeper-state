# Issue #315747 — Plan content is different when editing

[https://github.com/microsoft/vscode/issues/315747](https://github.com/microsoft/vscode/issues/315747)

## Summary

Keep open: current main now labels the Copilot CLI content as a “Plan summary,” partially addressing the confusion, but the widget still renders only that summary while the complete plan opens separately as an editable Markdown document. The team-authored Backlog item also records an unresolved product choice between showing the full plan and making the summary/full-plan distinction clearer.

## Change summary

Make it clear that the rendered plan-review content is a summary and provide an obvious way to read the complete plan as rendered Markdown.

## Best solution

Use consistent summary labeling across plan-review providers and give users an obvious rendered view of the backing plan, without losing the concise review summary. A maintainer should first decide whether that is a summary/full-plan toggle, a separate preview action, or replacement of the summary.
