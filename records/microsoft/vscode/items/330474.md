# Issue #330474 — Voice "turn off" control is too subtle; users press Stop instead

[https://github.com/microsoft/vscode/issues/330474](https://github.com/microsoft/vscode/issues/330474)

## Summary

Keep open for a focused voice-control design review: current code provides disconnect actions, but their existence does not establish that users can distinguish turning off Voice Mode from stopping a request. This team-authored item has neither a verified canonical duplicate nor an issue-referencing fix that would justify closing it.

## Change summary

Make the control for turning off Voice Mode discoverable and distinguishable from the general Stop action.

## Best solution

Make the active Voice Mode control explain its turn-off action at a glance while keeping request cancellation and stopping listening distinct. Review the current segmented control and legacy disconnect button together before choosing the visual treatment.
