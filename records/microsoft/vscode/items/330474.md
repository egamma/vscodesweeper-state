# Issue #330474 — Voice "turn off" control is too subtle; users press Stop instead

[https://github.com/microsoft/vscode/issues/330474](https://github.com/microsoft/vscode/issues/330474)

## Summary

Fresh, credible UX report (with screenshot and internal Slack feedback) that the voice-mode 'turn off' affordance is too subtle, leading users to hit Stop instead — already correctly labeled ux/voice-mode, so it just needs a design decision, not a close.

## Change summary

Users can't easily find the 'turn off voice' control and hit the general Stop button instead, because the turn-off affordance is too subtle.

## Best solution

A designer/maintainer should decide on a clearer, more discoverable 'turn off voice' affordance in the chat input voice-mode control (src/vs/workbench/contrib/chat/browser/voiceClient/voiceModeActionViewItem.ts and its context-menu 'Disable Voice Mode' entry in micButtonMenuActions.ts) — e.g. a more visible icon/label state change while listening.
