# Issue #331129 — Normalize required semantics for ask-user questions across providers

[https://github.com/microsoft/vscode/issues/331129](https://github.com/microsoft/vscode/issues/331129)

## Summary

The provider inconsistency remains on current main: Copilot and Codex mark ordinary questions required while Claude leaves them optional, producing different Agents Window behavior for equivalent prompts. Keep this member-authored normalization issue open and settle the provider-neutral default before implementation.

## Change summary

Normalize whether ordinary ask-user questions are required across Copilot, Codex, and Claude while preserving schema-driven MCP elicitation requirements.

## Best solution

Define one provider-neutral rule for ordinary questions—preferably optional when the source protocol supplies no required signal—and enforce it with parity tests across all three mappings. Keep MCP elicitation requirements derived exclusively from each JSON Schema's required set.

MCP form elicitation remains unchanged: only properties listed in the JSON Schema required set block acceptance and display as required.
