# Issue #331129 — Normalize required semantics for ask-user questions across providers

[https://github.com/microsoft/vscode/issues/331129](https://github.com/microsoft/vscode/issues/331129)

## Summary

Confirmed on current main: ordinary ask-user questions are hardcoded `required: true` in the Copilot and Codex mappers but omit `required` (defaulting to falsy/optional) in Claude's mapper, producing a provider-dependent asterisk in the Agents Window for equivalent prompts. Real, well-diagnosed inconsistency; needs a product decision on the normalized default plus a small cross-file fix.

## Change summary

Normalize `required` semantics for ordinary ask-user questions so they don't vary by agent provider (Copilot/Codex/Claude), while leaving MCP elicitation's schema-derived `required` untouched.

## Best solution

Decide the correct default for ordinary ask-user questions (the issue suggests optional-unless-the-protocol-says-otherwise) and align copilotAgentSession.ts, codexUserInputMapper.ts, and claudeInteractiveTools.ts to that default, updating the existing unit tests (codexUserInputMapper.test.ts, claudeInteractiveTools.test.ts) that currently assert the old per-provider behavior.
