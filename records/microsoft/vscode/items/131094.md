# Issue #131094 — Configurable peek window position

[https://github.com/microsoft/vscode/issues/131094](https://github.com/microsoft/vscode/issues/131094)

## Summary

The configurability gap remains on current main, and no open canonical issue owns the same request. Keep it open for an editor UX decision and classify it as under discussion.

## Change summary

Allow the peek widget to appear above its source line or in another configurable location so it does not obscure following code.

## Best solution

Have the editor-symbols and UX owners decide whether `ZoneWidget` should support adaptive above/below placement or expose a narrowly scoped peek-position option; avoid a broader movable-pane system unless it benefits other zone widgets.
