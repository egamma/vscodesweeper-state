# Issue #131094 — Configurable peek window position

[https://github.com/microsoft/vscode/issues/131094](https://github.com/microsoft/vscode/issues/131094)

## Summary

Configurable peek placement remains missing: current source anchors the widget below the selected symbol, and existing settings do not change that placement. Keep this accepted Backlog request open; the related issues inspected do not own the same work.

## Change summary

Allow peek views to appear above the selected symbol or in a configurable fixed location so following source lines remain visible.

## Best solution

Evaluate an alternative placement for definition and reference peek views in the editor-symbols area, preserving the current below-symbol default. Above-symbol placement and a docked view have different interaction implications and need a product decision before implementation.
