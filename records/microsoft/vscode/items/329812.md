# Issue #329812 — apply_patch rejects multiple update blocks for the same file, which openai models try to do a lot

[https://github.com/microsoft/vscode/issues/329812](https://github.com/microsoft/vscode/issues/329812)

## Summary

Traced in the current parser source: `Parser.parse()` in `extensions/copilot/src/extension/tools/node/applyPatch/parser.ts` hard-rejects any patch with a second `*** Update File:` header for a path already in `this.patch.actions`, even when the two hunks touch disjoint regions of the same file — matching the reporter's exact error text (`Update File Error: Duplicate Path: ...`).

## Change summary

apply_patch throws a hard 'Duplicate Path' error when a single patch contains two separate 'Update File' blocks for the same path, forcing the agent to retry with multiple tool calls even when the edits don't overlap.

## Best solution

In `parser.ts`, let `parse()` merge additional `*** Update File:` blocks for an already-seen path into the existing `PatchAction.chunks` (continuing the match position from where the prior block left off) instead of throwing immediately, and only fail with a specific conflict error if the new chunk's context actually overlaps a previously-applied region.
