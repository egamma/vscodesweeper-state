# Issue #329812 — apply_patch rejects multiple update blocks for the same file, which openai models try to do a lot

[https://github.com/microsoft/vscode/issues/329812](https://github.com/microsoft/vscode/issues/329812)

## Summary

Confirmed on current main: the apply_patch parser unconditionally throws `Update File Error: Duplicate Path` on a second `*** Update File:` block for the same path (a straight port of OpenAI's reference apply_patch validation). This is intentional strict validation, not a broken-behavior bug, so it's a real enhancement request rather than a defect to auto-fix.

## Change summary

apply_patch hard-fails when a patch contains two separate Update File blocks for the same path, even when their edit regions don't overlap, forcing OpenAI models (which do this often) into extra retries/tool calls.

## Best solution

In extensions/copilot/src/extension/tools/node/applyPatch/parser.ts (Parser.parse / parse_update_file), replace the hard `Duplicate Path` throw with logic that merges multiple Update File blocks for the same path into one PatchAction's chunk list (in order) and only errors when two blocks touch overlapping/ambiguous regions; this needs new tests under the applyPatch tool area since none currently exist for this parser.
