# Issue #331227 — An automation that started yesterday but completed today looks confusing in the history list

[https://github.com/microsoft/vscode/issues/331227](https://github.com/microsoft/vscode/issues/331227)

## Summary

The timestamp mismatch remains in current source: history groups use the run's start date while row timestamps can reflect later activity or completion. Keep this accepted, team-authored issue open; choosing the intended grouping semantics still needs a maintainer decision.

## Change summary

Make automation history understandable when a run starts on one day and completes on another after the laptop resumes.

## Best solution

Give automation history an explicit, consistent temporal meaning across date groups and row timestamps. The owner should decide whether groups represent run starts or recent activity before changing the presentation.
