# Issue #331227 — An automation that started yesterday but completed today looks confusing in the history list

[https://github.com/microsoft/vscode/issues/331227](https://github.com/microsoft/vscode/issues/331227)

## Summary

Team-authored bug report describing a genuine grouping quirk in the automations history list, confirmed in source; the author explicitly poses an open design question (group by created vs. last-updated time) that needs a maintainer decision before any fix, so this stays open rather than closing.

## Change summary

The automations history list groups a run by its start date only, so a run that started yesterday and finished today shows up under "Yesterday" even though it just completed.

## Best solution

Decide the intended grouping semantic for automation runs (started-at vs. completed-at/updated-at) and adjust `groupRunsByDate`/`getDateBucket` in src/vs/sessions/contrib/sessions/browser/views/automationsView.ts accordingly, likely bucketing by the run's most recent relevant timestamp (e.g. completedAt when the run has finished) rather than always by startedAt.
