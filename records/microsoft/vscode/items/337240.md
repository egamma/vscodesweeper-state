[https://github.com/microsoft/vscode/issues/337240](https://github.com/microsoft/vscode/issues/337240)

## Summary

The older, open scrollbar request explicitly asks for arrow buttons that scroll one line per click, with discussion covering touchpad use and accessibility. It encompasses this request; consolidation should preserve the specific Terminal and Debug Output use case.

## Change summary

Provide scrollbar buttons for precise, line-by-line scrolling in output panels without requiring a mouse wheel or touchpad gestures.
