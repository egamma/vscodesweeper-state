# Issue #193268 — Tasks should add a new line before the VS Code format message if it's not at the start of a line

[https://github.com/microsoft/vscode/issues/193268](https://github.com/microsoft/vscode/issues/193268)

## Summary

Keep open: current source still permits a task completion message to start after existing terminal output. The Windows cancellation steps suffice to retest, but the reported Ctrl+C path was not confirmed against the current exit-handling code.

## Change summary

Ensure task completion messages begin at the left edge when cancellation leaves the terminal cursor partway through a line.

## Best solution

Task exit messages should begin on a fresh line when the terminal cursor is not already at column zero, without adding unnecessary blank lines. Confirm the Windows Ctrl+C case and cover the terminal exit-message path with a focused regression test.
