# Issue #166741 — Sticky scroll messes up accurate markdown scroll sync

[https://github.com/microsoft/vscode/issues/166741](https://github.com/microsoft/vscode/issues/166741)

## Summary

Still reproduces on main: the editor's visible ranges API doesn't subtract lines occluded by sticky scroll, so the markdown preview scroll sync drifts. The underlying architecture issue (sticky scroll as a contribution that core doesn't account for in visible-range calculation) remains unfixed.

## Change summary

Sticky scroll causes markdown preview scroll sync to drift because the editor's visible ranges include lines occluded by the sticky scroll header.

## Best solution

The editor core's `getCompletelyVisibleViewRange()` (in `src/vs/editor/common/viewModel/viewModelImpl.ts`) needs to account for lines occluded by the sticky scroll widget, advancing `completelyVisibleStartLineNumber` past those lines. This would fix the extension-facing `visibleRanges` and resolve the markdown preview drift without requiring workarounds in individual extensions.
