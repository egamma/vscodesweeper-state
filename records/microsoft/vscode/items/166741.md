# Issue #166741 — Sticky scroll messes up accurate markdown scroll sync

[https://github.com/microsoft/vscode/issues/166741](https://github.com/microsoft/vscode/issues/166741)

## Summary

The current source still combines sticky-scroll-aware reveals with an uncompensated top-visible-line calculation, explaining the delayed editor scrolling and backward preview jump. Keep this focused report open; the older related report does not establish the same sticky-scroll-specific defect as its canonical scope.

## Change summary

Keep Markdown preview and editor scroll positions synchronized when sticky scroll changes the editor's reveal offset.

## Best solution

Make Markdown's bidirectional scroll synchronization use compatible position anchors while preserving sticky-scroll-aware reveals. Establish whether that requires changing the public visible-ranges contract or a separate synchronization-specific mechanism before implementation.

- **Trace:**
