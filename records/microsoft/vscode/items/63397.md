# Issue #63397 — Git - Staging when ignoring whitespace, doesn't stage changed whitespace

[https://github.com/microsoft/vscode/issues/63397](https://github.com/microsoft/vscode/issues/63397)

## Summary

Keep open: selected-range staging still consumes whitespace-filtered display diffs, so selected indentation-only changes can be omitted from the index. This issue remains the canonical report; showing whitespace is a workaround, not a fix.

## Change summary

Stage Selected Ranges omits indentation-only changes within the selection when the diff editor hides whitespace changes.

## Best solution

Make selected-range staging include the actual whitespace changes within the selected lines independently of the diff's display setting, while preserving existing staged content and leaving unselected changes unstaged.
