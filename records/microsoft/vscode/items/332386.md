# Issue #332386 — esc does not close Achievements modal

[https://github.com/microsoft/vscode/issues/332386](https://github.com/microsoft/vscode/issues/332386)

## Summary

Confirmed in source: the Achievements editor (internally called the 'Achievements modal', see the `chatPetAchievementsFocused` context key description) only closes on Escape via per-card `Button.onDidEscape` handlers wired individually in `chatPetAchievementsWidget.ts`; there is no container-level Escape listener, so Escape does nothing unless focus happens to be on an achievement card button.

## Change summary

Pressing Escape while the pet Achievements modal is open doesn't dismiss it, unlike other VS Code modals.

## Best solution

Add a single Escape keydown handler at the widget/editor container level in ChatPetAchievementsWidget (or ChatPetAchievementsEditor.createEditor) that calls the existing `onDidRequestClose` callback, so Escape closes the view regardless of which element inside it currently has focus, matching the per-card behavior already present.
