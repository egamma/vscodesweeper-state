# Issue #276827 — Chat: Allow agents to provide options with one-click answers

[https://github.com/microsoft/vscode/issues/276827](https://github.com/microsoft/vscode/issues/276827)

## Summary

Valid feature request from a team member for richer inline QnA options in chat. Existing mechanisms (followups, elicitation/confirmation widgets) partially overlap but don't fully deliver the described seamless one-click option-selection flow in plan mode.

## Change summary

Allow agents to present multiple-choice options or pre-filled answers inline in chat responses that users can click to answer without typing.

## Best solution

Extend the chat response rendering to support agent-provided inline option buttons (beyond the current end-of-turn followups and tool-confirmation elicitation widgets) — likely in the chat content parts layer alongside chatElicitationContentPart.ts and chatFollowups.ts. The plan-mode QnA scenario is the golden path.
