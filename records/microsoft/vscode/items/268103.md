# Issue #268103 — Fetch tool should better indicate in UI when the request fails

[https://github.com/microsoft/vscode/issues/268103](https://github.com/microsoft/vscode/issues/268103)

## Summary

The requested failure indication is still missing: HTTP errors are detected, but fetch results lose that status before rendering a success checkmark. The linked warning-icon PR was closed without merging, so this accepted UI improvement should remain open.

## Change summary

Show a visible warning or error indicator when the fetch tool cannot retrieve a requested page, including HTTP 404 responses.

## Best solution

Make failed fetches visibly distinguishable from successful fetches in the collapsed result row, while preserving resource links, extracted error content, and existing approval behavior.
