# Issue #282656 — Delegating to Cloud/Background does not work in `Edit` mode

[https://github.com/microsoft/vscode/issues/282656](https://github.com/microsoft/vscode/issues/282656)

## Summary

Keep open: current delegation controls still lack an Edit-mode restriction. Edit mode is now deprecated and retained for the agent-disabled policy fallback, but that does not establish that the maintainer-requested restriction was implemented.

## Change summary

Restrict the chat Continue In experience to agent modes rather than offering it in Edit mode.

## Best solution

Make chat delegation availability respect the originating chat mode, preserving Agent/Plan delegation while excluding Edit mode. Account for the remaining policy-fallback Edit experience and keep unrelated editor-content continuation behavior unchanged.
