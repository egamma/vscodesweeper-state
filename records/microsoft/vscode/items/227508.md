# Issue #227508 — Tooltips Missing Name and Role Information

[https://github.com/microsoft/vscode/issues/227508](https://github.com/microsoft/vscode/issues/227508)

## Summary

The tooltip role already exists, but the reported status-bar controls still have no accessible description relationship to their tooltips. Keep this open for a bounded accessibility fix in the standard workbench hover path.

## Change summary

Expose status-bar tooltip descriptions to assistive technologies through an association with their triggering controls.

## Best solution

Make the plain-text status-bar tooltips programmatically associated with their controls, retaining the existing tooltip role and accessible control names. Preserve keyboard interaction and rich-hover behavior, and cover description lifetime with DOM regression tests.
