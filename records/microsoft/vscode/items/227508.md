# Issue #227508 — Tooltips Missing Name and Role Information

[https://github.com/microsoft/vscode/issues/227508](https://github.com/microsoft/vscode/issues/227508)

## Summary

The accessibility gap remains on current main: standard workbench hovers have `role="tooltip"`, but the hover has no ID and its triggering control is not associated through `aria-describedby`. This should stay open as a bounded workbench-hover bug.

## Change summary

Associate status-bar controls and other standard workbench-hover triggers with their tooltip so screen readers announce the tooltip information.

## Best solution

Complete the standard managed-hover accessibility contract by associating the actual triggering control with the rendered tooltip while preserving existing ARIA descriptions and removing only the hover-owned association when it closes.
