There are no confirming comments or linked fixing PRs in the supplied context.
- **Current completion filtering:** extensions/emmet/src/defaultCompletionProvider.ts, DefaultCompletionItemProvider.provideCompletionItemsInternal, filters excluded languages, leading // comments, invalid abbreviations, and selected JS/TS symbol or bracket noise. It has no explicit import/require module-specifier exclusion before calling helper.doComplete.
- **Location validation limitation:** extensions/emmet/src/abbreviationActions.ts, isValidLocationForEmmetAbbreviation, validates markup locations using node boundaries and backward scanning for angle brackets. It does not recognize JavaScript module strings; an import prefix without angle brackets is not rejected by that scan. This supports the diagnosis but does not independently confirm the helper's exact expansion.
