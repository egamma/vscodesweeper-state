# Issue #334453 — Copilot Git remote fallback fails for linked worktrees

[https://github.com/microsoft/vscode/issues/334453](https://github.com/microsoft/vscode/issues/334453)

## Summary

The linked-worktree fallback still fails on current main for file and nested-directory lookups. A worktree-aware helper now covers direct repository-root lookups, but the reported fallback remains unchanged; this team-authored issue should stay open.

## Change summary

Discover linked-worktree remotes through gitdir and optional commondir metadata instead of assuming .git is a directory.

## Best solution

Make repository-root fallback discovery honor the same Git metadata layouts as direct-root discovery, preserving ordinary repositories and opened-repository behavior. Have the owner review the content-exclusion implications of unsuccessful remote discovery.
