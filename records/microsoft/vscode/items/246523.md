# Issue #246523 — scroll behavior is not smooth sometimes

## Summary

Keep open: several users confirmed disruptive scroll jumps in long chat transcripts across macOS, Linux, and Windows, and the latest confirmation describes a repeatable tall-row layout trigger. Later changes improved adjacent performance and height-update paths, but no directly linked fix demonstrates that this team-authored issue's remaining behavior is resolved.

## Change summary

Scrolling backward through a long chat can jump in the opposite direction when a previously virtualized tall response is rendered and its row height changes.

## Best solution
