# Issue #228696 — Change the global `fetch` available in local extension hosts to be the one from Electron

[https://github.com/microsoft/vscode/issues/228696](https://github.com/microsoft/vscode/issues/228696)

## Summary

Team-authored tracking issue for switching extension hosts to Electron's fetch. The feature is partially implemented (behind `http.electronFetch`, disabled by default) and explicitly on hold by the author pending evaluation of Node.js' native fetch proxy support. Still an active work item.

## Change summary

Replace the global `fetch` in local extension hosts with Electron's network-stack-backed fetch to gain proxy and certificate handling.

## Best solution

Keep open as the author's tracking issue. The decision depends on how well Node.js' own fetch with proxy support (tracked in https://github.com/microsoft/vscode/issues/228697) works out. Once that evaluation concludes, either enable the existing `http.electronFetch` setting by default or retire it in favor of the Node.js path. The implementation lives in `src/vs/workbench/api/node/proxyResolver.ts`.
