# Issue #281733 — `apply_patch` fails to replace the whole contet of files

[https://github.com/microsoft/vscode/issues/281733](https://github.com/microsoft/vscode/issues/281733)

## Summary

The reported root cause is fixed on current main: file reads no longer use code fences by default, preventing ` ```markdown ` from being mistaken for file content during patch generation.

## Change summary

Whole-file `apply_patch` edits retained old content because fenced `read_file` output led the model to include a nonexistent Markdown fence in the removal hunk.

## Best solution

Keep the fence-free `read_file` output introduced by commit 121ef830316ee53d0a8c47a45db1b2b2934b8306; no additional `apply_patch` change is needed.
