## Summary

Valid feature request with a real API gap — the internal tree widget supports `relativeTop` alignment but the extension `TreeView.reveal()` API doesn't expose it. No work has been done on this. The Backlog Candidates community process is running (29 of 60 days elapsed, 0 upvotes so far); let it play out.

## Change summary

Expose scroll-alignment control (e.g. `center` vs `top`) in the `TreeView.reveal()` extension API and optionally add a user setting for built-in Explorer/SCM auto-reveal alignment.

## Best solution

The user-setting part (`explorer.revealAlignment`) is a separate, lower-priority addition. For now, let the backlog-candidates process gauge demand.
