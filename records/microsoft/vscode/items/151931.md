# Issue #151931 — Exception has occurred message looks out of place

[https://github.com/microsoft/vscode/issues/151931](https://github.com/microsoft/vscode/issues/151931)

## Summary

The close-button alignment received a partial fix, but the exception widget still uses a separate presentation rather than the peek-style header discussed in the thread. Keep this accepted Backlog polish item open to settle the remaining visual treatment.

## Change summary

Make the debugger exception message's typography and header actions consistent with comparable editor widgets.

## Best solution
