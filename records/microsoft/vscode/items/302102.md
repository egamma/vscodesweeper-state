# Issue #302102 — Sessions: File tree is not visible or discoverable on first use

[https://github.com/microsoft/vscode/issues/302102](https://github.com/microsoft/vscode/issues/302102)

## Summary

Keep open for a focused first-use UX assessment. Current main provides default Files presentation for workspace-backed drafts, but that does not establish that clone confirmation and file discoverability are resolved across the reported flows; no issue-referencing fix was found for this team-authored request.

## Change summary

Make project files immediately visible and discoverable after cloning or opening a repository, with clear confirmation of the repository's location.

## Best solution

Ensure the first repository-open or clone experience visibly orients users to their project files and confirms the selected location, using the existing Sessions Files surface. Assess the current draft presentation before adding UI, and settle how first-use guidance should coexist with saved layout preferences.
