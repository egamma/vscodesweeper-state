# Issue #178955 — Syntax highlighting for JavaScript in HTML file breaks when "if" is on the same line as closing tag

[https://github.com/microsoft/vscode/issues/178955](https://github.com/microsoft/vscode/issues/178955)

## Summary

Still present on main — the HTML TextMate grammar misparses the JS/HTML boundary when a closing brace precedes `</script>` on the same line without a semicolon, breaking syntax highlighting for subsequent script blocks. The grammar is sourced from textmate/html.tmbundle.

## Change summary

JavaScript syntax highlighting breaks in subsequent `<script>` tags when an `if` block's closing brace is on the same line as `</script>` without a trailing semicolon.

## Best solution

The fix belongs in the upstream TextMate HTML grammar (https://github.com/textmate/html.tmbundle). The `end` pattern for the embedded JS region (around line 1901 of `extensions/html/syntaxes/html.tmLanguage.json`) likely needs adjustment so that `}` immediately before `</script>` correctly terminates the JS scope. Alternatively, a local grammar patch (like the one at line 45324363153 for strings) could work around the upstream issue.
