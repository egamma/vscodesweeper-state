[https://github.com/microsoft/vscode/issues/178955](https://github.com/microsoft/vscode/issues/178955)

## Summary

The older, open canonical issue tracks JavaScript highlighting escaping a script tag when a semicolon is absent. A maintainer already consolidated an earlier report of this exact inline-if highlighting failure into that canonical, satisfying the stronger duplicate bar for this re-review.

## Change summary

An inline JavaScript if block immediately before </script> without a semicolon breaks highlighting in subsequent HTML and script blocks.
