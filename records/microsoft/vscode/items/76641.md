# Issue #76641 — Update detects code.exe instances from other users with seperate install folders

[https://github.com/microsoft/vscode/issues/76641](https://github.com/microsoft/vscode/issues/76641)

## Summary

Still a valid open bug — the inno-updater kills/detects code.exe processes across all user sessions rather than only the current user's install path. An open PR (microsoft/inno-updater#28) exists to fix it but hasn't merged yet.

## Change summary

On multi-user Windows machines, the VS Code updater fails because it detects code.exe processes running under other users' separate installs.

## Best solution

Land the fix in microsoft/inno-updater (PR #28 or equivalent) to either ignore 'access denied' when enumerating other users' processes or filter by install path, then bump the inno_updater.exe binary in this repo.
