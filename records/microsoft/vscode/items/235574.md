# Issue #235574 — Enhancing Debugging Experience: Adding Docstring and Type Hint Support to Debug Console

[https://github.com/microsoft/vscode/issues/235574](https://github.com/microsoft/vscode/issues/235574)

## Summary

VS Code core already supports `CompletionItem.detail` for debug console completions (confirmed by team member connor4312). The gap is largely in the debug adapter (e.g. debugpy) populating docstrings, type hints, and richer completion data — but there may still be core-side gaps (e.g. `documentation` field not being forwarded). Keeping open pending clarification of remaining limitations.

## Change summary

Request for docstring, type hint, and keyword argument suggestions in the debug console during Python debugging sessions.

## Best solution

Clarify whether the DAP `completions` response fully supports documentation/signature info or if the core needs to forward additional fields (e.g. a `documentation` property). If the gap is purely in the debug adapter, this should be redirected to the debugpy/Python debugger tracker. If core needs to expose more completion metadata from DAP, that's a small enhancement in `src/vs/workbench/contrib/debug/browser/repl.ts`.
