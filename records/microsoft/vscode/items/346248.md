# Issue #346248 — Chat agent: let the model replace a junk tool result with a one-line summary (model-judged context pruning)

[https://github.com/microsoft/vscode/issues/346248](https://github.com/microsoft/vscode/issues/346248)

## Summary

Keep open as a feature request: existing size-based offloading, conversation compaction, and Anthropic context editing do not provide model-selected, current-turn replacement with a summary while preserving the original transcript.

## Change summary

Allow the agent to replace a selected current-turn tool result in model context with a short summary, retaining the original output and a visible notice for users.

## Best solution

Evaluate selective tool-result replacement in the Copilot prompt/history pipeline, preserving transcript fidelity and provider tool-call consistency. Assess cache effects rather than assuming the proposed savings hold across providers.
