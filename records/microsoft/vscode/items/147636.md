# Issue #147636 — Show breadcrumbs whilst debugging

[https://github.com/microsoft/vscode/issues/147636](https://github.com/microsoft/vscode/issues/147636)

## Summary

This is the same debug-source breadcrumbs limitation previously tracked and explicitly declined in https://github.com/microsoft/vscode/issues/62290, so it can be closed as out of scope.

## Change summary

Show file and symbol breadcrumbs for read-only source documents supplied by a debug adapter.

## Best solution

Retain the current behavior: breadcrumbs remain limited to resources backed by a file-system provider, while debug-adapter virtual sources continue without breadcrumbs.
