# Issue #298401 — After updating to the latest version of VS Code, the coding process has become extremely laggy, and memory usage spikes dramatically.

[https://github.com/microsoft/vscode/issues/298401](https://github.com/microsoft/vscode/issues/298401)

## Summary

The underlying VS Code bug in the `selectChatModels` API — a recursion/feedback loop that caused runaway CPU when extensions called it repeatedly — was fixed in commit ca62bf6f0b5 and shipped in 1.123.0. The C/C++ extension also fixed their calling pattern on their side. Both fixes have landed, and the reporter confirmed the workaround resolved the symptom.

## Change summary

After updating VS Code, the C/C++ extension's copilot-hover feature triggered a feedback loop in the `selectChatModels` API, causing severe lag and memory spikes in Remote-WSL.

## Best solution

Keep the shipped fix (1.123.0): the `selectChatModels` API no longer recurses or creates feedback loops when called by extensions. The C/C++ extension also stopped calling it on every hover (vscode-cpptools PR #14327). No further change needed.
