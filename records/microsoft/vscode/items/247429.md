# Issue #247429 — [feat] Notebook: Toggle fold command

[https://github.com/microsoft/vscode/issues/247429](https://github.com/microsoft/vscode/issues/247429)

## Summary

Valid feature request — notebook folding currently has separate fold/unfold commands (`notebook.fold`, `notebook.unfold`) but no single toggle command. The toggle logic already exists in the mouse-click handler (`foldingController.ts:135-141`) but is not exposed as a keybindable command. Low traction (1 upvote), so this stays open for the community process.

## Change summary

Add a single "Toggle Fold" command for notebook sections that checks the current folding state and flips it, instead of requiring separate fold/unfold keybindings.

## Best solution

Add a `notebook.toggleFold` command in `src/vs/workbench/contrib/notebook/browser/controller/foldingController.ts` that reuses the existing toggle logic from the mouse-click handler (line ~135-141, which calls `getFoldingState` and flips the state). Wire it up with a keybinding and `f1: true`.
