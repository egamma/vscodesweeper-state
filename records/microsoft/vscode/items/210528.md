# Issue #210528 — Slow  edits and completions when editing Python code

[https://github.com/microsoft/vscode/issues/210528](https://github.com/microsoft/vscode/issues/210528)

## Summary

Team-authored perf issue about slow completions in Jupyter notebooks with Python — the root cause spans Pylance, Jupyter kernel completions, and possibly VS Code core (parameter hints/markdown rendering). No fix commit references this issue, and the investigation was still ongoing when discussion stopped. Keeping open.

## Change summary

Typing and completions become slow in Jupyter notebooks after executing cells, with lag in parameter hints and autocomplete popups.

## Best solution

The investigation narrowed the lag to kernel-side completions (not Pylance CPU time), but the VS Code core side — parameter hints rendering and markdown sanitization overhead — was also being explored (PR https://github.com/microsoft/vscode/pull/210524 was closed without merge, PR https://github.com/microsoft/vscode/pull/211591 added telemetry tracking). The issue needs a fresh look: gather telemetry from the parameter-hints tracking added in https://github.com/microsoft/vscode/pull/211591 to determine whether the VS Code core rendering path contributes meaningfully to the lag, or whether this should be transferred to the Jupyter extension tracker.
