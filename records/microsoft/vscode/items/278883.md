# Issue #278883 — Deleting files with vscode fs api can cause contributed custom text editors to not be able to open subsequent files with the same name

[https://github.com/microsoft/vscode/issues/278883](https://github.com/microsoft/vscode/issues/278883)

## Summary

Fixed on main: PR #287966 merged 2026-07-27 adds file-deletion cleanup to CustomEditorModelManager, directly referencing this issue. The fix has not yet shipped in a release.

## Change summary

After deleting a file via the VS Code FS API, custom text editors fail to open a recreated file with the same name because the model manager retains a stale cached reference.

## Best solution

Keep the shipped fix from PR #287966 (commit a5d4ba56); no further change needed. The two remaining open PRs (#305522, #320524) targeting the same issue can be closed as superseded.
