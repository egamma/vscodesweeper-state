# Issue #147447 — cmd+click behavior for Goto Definition and a Document Link

[https://github.com/microsoft/vscode/issues/147447](https://github.com/microsoft/vscode/issues/147447)

## Summary

The defect remains present on current main, but draft PR https://github.com/microsoft/vscode/pull/316840 already proposes a targeted fix. Keep the issue open while that human-owned implementation candidate is reviewed.

## Change summary

Cmd/Ctrl+click executes both document-link navigation and Go to Definition when providers return overlapping ranges.

## Best solution

Review and validate https://github.com/microsoft/vscode/pull/316840, which makes the document link win for Cmd/Ctrl+click while retaining Go to Definition through its other entry points; land it if the regression coverage and interaction behavior are acceptable.
