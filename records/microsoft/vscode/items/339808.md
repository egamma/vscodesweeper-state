## Summary

This is a security-sensitive sandbox/policy-enforcement report (a stricter local network restriction appears not to win over a more permissive managed policy), so it stays open regardless of other evidence; reproduction is also contested (reporter says it reproduces, a collaborator could not reproduce on Linux).

## Change summary

With a managed sandbox policy allowing outbound network (`allowOutbound: true`) and a stricter local user setting (`chat.agent.sandbox.network.allowNetwork: false`), network access to an external site still succeeds instead of being blocked by the stricter user setting.

## Best solution
