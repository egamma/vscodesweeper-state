[https://github.com/microsoft/vscode/issues/341245](https://github.com/microsoft/vscode/issues/341245)

## Summary

The public API still cannot open an editor directly into a floating window with initial bounds, compact mode and always-on-top, although the internal workbench supports it. Keep the existing area classification and let the newly started Backlog Candidates community-review period proceed.

## Change summary

Expose a supported extension API for opening editors directly into floating windows with initial size, compact mode and always-on-top options.

## Best solution

If accepted through community review, define a supported editor-opening target and window-options contract over the existing auxiliary-window infrastructure. Treat resizing existing windows as a separate optional scope decision rather than requiring extensions to use private commands.
