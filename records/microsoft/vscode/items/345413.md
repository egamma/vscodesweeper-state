# Issue #345413 — Improve visual effect of focus buttons in Copilot's request window

[https://github.com/microsoft/vscode/issues/345413](https://github.com/microsoft/vscode/issues/345413)

## Summary

Keep open: the permission carousel explicitly suppresses focused buttons' outlines and shadows, leaving the subtle background change described by the reporter. This is a bounded keyboard-focus accessibility defect.

## Change summary

Make the focused Copilot permission button clearly distinguishable when navigating with Tab or Shift+Tab.

## Best solution

Provide a theme-aware, per-button keyboard-focus indicator in the tool confirmation carousel, consistent with standard workbench buttons and visible in light, dark, and high-contrast themes.
