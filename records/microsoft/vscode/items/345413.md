# Issue #345413 — Improve visual effect of focus buttons in Copilot's request window

[https://github.com/microsoft/vscode/issues/345413](https://github.com/microsoft/vscode/issues/345413)

## Summary

Keep open as accessibility polish: confirmation-carousel styling suppresses individual button focus outlines, supporting the reported difficulty identifying the keyboard-focused action. Existing card-level highlighting does not identify which permission button will activate.

## Change summary

Make keyboard focus on Copilot permission buttons easier to distinguish when navigating from the input with Shift+Tab.

## Best solution

Provide a clearly distinguishable, theme-aware keyboard-focus indicator for each permission action, consistent with other workbench buttons. Assess the rendered carousel across standard and high-contrast themes without changing permission behavior.
