# Issue #212682 — DNS servers lack IPv6 support, DNS recursion fails causing connection timeouts.

[https://github.com/microsoft/vscode/issues/212682](https://github.com/microsoft/vscode/issues/212682)

## Summary

Still reproducing as of late 2025 — the root cause is Azure DNS infrastructure (nameservers for t-msedge.net and fb-t-msedge.net lack AAAA records), which breaks the CNAME resolution chain for IPv6-only resolvers. This is upstream of VS Code's code and requires an Azure infrastructure fix.

## Change summary

VS Code update checks fail on hosts with IPv6-only DNS resolvers because Azure nameservers in the CNAME chain lack AAAA records.

## Best solution

Continue escalation with the Azure CDN/Traffic Manager team to add AAAA records to the authoritative nameservers for t-msedge.net and fb-t-msedge.net domains. No code change in this repository can fix this — it's an infrastructure configuration gap on the Azure side.
