## Summary

Keep open as an Azure DNS infrastructure issue, not a Remote-SSH extension defect. The current endpoint resolves through a different DNS chain, but that observation does not establish that IPv6-only recursive resolution now works.

## Change summary

Ensure the VS Code update endpoint's complete DNS delegation and CNAME chain can be resolved by an IPv6-only recursive resolver.

The existing report provides sufficient diagnostic commands; resolution requires an IPv6-only recursive-resolution check, not merely a successful AAAA lookup through a dual-stack resolver.
