# Issue #288567 — Prompt tweaks around terminal isBackground description

[https://github.com/microsoft/vscode/issues/288567](https://github.com/microsoft/vscode/issues/288567)

## Summary

Partially addressed: `isBackground` is now deprecated in the tool schema in favor of a `mode` parameter, and the model description strongly steers toward sync. However, the broader prompt refinement this issue envisions — making it harder for the agent to launch background terminals, especially once #288566 (agent-initiated background push) lands — likely has more work remaining. Keeping open as the referenced capability (#288566) is still open.

## Change summary

Tweak the runInTerminal tool's prompt/schema to discourage agents from launching background terminals up front, since they can convert to background later.

## Best solution

Once https://github.com/microsoft/vscode/issues/288566 ships, revisit the `isBackground` parameter: consider removing it from the schema entirely (or hiding it from models) and updating the model description to point agents at the new 'push to background' capability instead. The remaining work lives in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/runInTerminalTool.ts`.
