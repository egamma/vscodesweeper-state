# Issue #283273 — VS Code does not open file paths with line numbers in plain text (.log) files

[https://github.com/microsoft/vscode/issues/283273](https://github.com/microsoft/vscode/issues/283273)

## Summary

Keep open: current source supports parenthesized line numbers in Log-language files, but detection depends on opened workspace folders. The report predates the current checkout and its sample suffices to retest; no confirmed reproduction or concrete fixing commit establishes that it is resolved.

## Change summary

Ctrl-clicking an absolute PHP file path ending in '(364)' in a .log file does not open the target at that line.

## Best solution

Establish whether navigation fails for a target inside an opened workspace in Log language mode, and restore that supported behavior if it does. If the failure is exclusively outside the workspace, evaluate consolidation with the existing outside-workspace link request rather than treating parentheses as the defect.
