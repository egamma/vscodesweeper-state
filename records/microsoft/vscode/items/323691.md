# Issue #323691 — Move Update version button away from top task bar

[https://github.com/microsoft/vscode/issues/323691](https://github.com/microsoft/vscode/issues/323691)

## Summary

The update button placement in the title bar is intentional and already configurable via the `update.titleBar` setting — users who find it disruptive can disable it. This is as-designed.

## Change summary

Request to move or remove the Update version button from the title bar to avoid accidental clicks.

## Best solution

Keep the current design: the `update.titleBar` setting already lets users hide the button from the title bar, with the update indicator available on the Manage gearwheel as an alternative. No core change needed.
