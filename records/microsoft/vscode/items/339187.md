# Issue #339187 — Agent turn should not end while background commands are still running

[https://github.com/microsoft/vscode/issues/339187](https://github.com/microsoft/vscode/issues/339187)

## Summary

Keep open: existing terminal tools cover output retrieval, termination, and timeout notices, but do not establish the requested grouped inventory and end-of-turn evaluation contract. The verified related issues cover narrower counter problems or the opposite completion symptom, not this full request.

## Change summary

Make agent completion account explicitly for outstanding background commands, with inspectable status, recoverable output, and lifecycle controls.

## Best solution

Define a background-work completion contract that distinguishes unfinished task dependencies from intentionally persistent servers, then expose the necessary inventory and controls on the standard Copilot Chat custom-model path. Reuse existing terminal output and termination capabilities rather than making every background process block completion.
