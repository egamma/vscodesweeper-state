# Issue #333471 — Windows CLI binary ignores product.overrides.json for application name and metadata

[https://github.com/microsoft/vscode/issues/333471](https://github.com/microsoft/vscode/issues/333471)

## Summary

The reported mismatch remains directly traceable in current main: CLI build variables honor product.overrides.json, but Windows executable metadata does not. Keep this open as a bounded build-script bug.

## Change summary

Windows CLI executable metadata should honor product.overrides.json when VSCODE_CLI_PRODUCT_JSON is unset.

## Best solution

Make Windows version-resource metadata follow the same product configuration precedence as CLI build variables, preserving explicit product-file selection and base defaults.
