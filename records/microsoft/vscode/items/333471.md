# Issue #333471 — Windows CLI binary ignores product.overrides.json for application name and metadata

[https://github.com/microsoft/vscode/issues/333471](https://github.com/microsoft/vscode/issues/333471)

## Summary

Confirmed by reading cli/build.rs on main: apply_win32_version_resources (lines 177-186) loads only product.json when VSCODE_CLI_PRODUCT_JSON is unset, while apply_build_environment_variables (lines 158-165) correctly merges product.overrides.json on top in the same fallback branch. The Win32 resource embedding (ProductName/FileDescription/etc., lines 205-213) therefore never sees override values.

## Change summary

Windows CLI binary metadata (ProductName/FileDescription) doesn't pick up nameLong/applicationName from product.overrides.json when building the Windows target without VSCODE_CLI_PRODUCT_JSON set.

## Best solution

Mirror the override-merge logic from apply_build_environment_variables into apply_win32_version_resources: after loading repo_dir.join("product.json"), also merge repo_dir.join("product.overrides.json") into the product map when it exists, before reading nameLong/applicationName.
