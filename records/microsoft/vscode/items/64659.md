# Issue #64659 — Support multiple lineComments in a language config to allow "Remove Line Comment" to work more reliably

[https://github.com/microsoft/vscode/issues/64659](https://github.com/microsoft/vscode/issues/64659)

## Summary

The capability remains absent from current main, and this issue is the canonical request with 23 community upvotes. It is already correctly classified and should remain open.

## Change summary

Allow language configurations to declare multiple line-comment tokens so comment commands can correctly remove alternatives such as `//` and `///`.

## Best solution

Extend the language-configuration schema, parser, and resolved comment configuration to retain an ordered token list, then make removal match the longest applicable token while preserving the primary token for adding comments. Cover the behavior in the editor comment-command tests.
