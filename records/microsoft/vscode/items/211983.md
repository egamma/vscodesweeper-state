# Issue #211983 — Cycle windows backward and forward by last used 

[https://github.com/microsoft/vscode/issues/211983](https://github.com/microsoft/vscode/issues/211983)

## Summary

This accepted Backlog request has 24 community upvotes, and current main still lacks MRU-ordered window switching. It should remain open under the established feature-request process.

## Change summary

Provide forward and backward cycling through VS Code windows in most-recently-used order.

## Best solution

Track or expose each main window's focus recency and use it to order the window quick switcher, with repeatable forward/backward commands and consideration for an opt-out setting.
