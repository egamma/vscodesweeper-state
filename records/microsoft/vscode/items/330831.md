# Issue #330831 — Modern UI: Some panel parts use Sidebar colors instead of Panel colors

[https://github.com/microsoft/vscode/issues/330831](https://github.com/microsoft/vscode/issues/330831)

## Summary

Reporter confirmed this was fixed in https://github.com/microsoft/vscode/pull/331485 and https://github.com/microsoft/vscode/pull/331467, and current main's CSS and a dedicated test confirm the fix — this can be closed as completed.

## Change summary

With Modern UI enabled, some panel parts (Problems, Output, Debug Console, relocated Explorer) rendered with Sidebar background/border colors instead of Panel colors, and the panel section header separator was drawn even in horizontal layouts.

## Best solution

Keep the shipped fix: src/vs/workbench/contrib/modernUI/browser/media/paneHeaders.css now scopes background-color and section-header-border rules separately to `.part.sidebar/.auxiliarybar` (sideBar tokens) vs `.part.panel` (panel tokens), and gates the header separator to vertical layouts only.
