# Issue #330831 — Modern UI: Some panel parts use Sidebar colors instead of Panel colors

[https://github.com/microsoft/vscode/issues/330831](https://github.com/microsoft/vscode/issues/330831)

## Summary

Confirmed on current main: the Modern UI style-override rules for pane headers/backgrounds unconditionally prefer `--vscode-sideBar-*` tokens (with `--vscode-panel-*` only as a CSS fallback), so panels that customize `panel.background`/`panelSectionHeader.border` differently from the sidebar incorrectly inherit sidebar colors.

## Change summary

When Modern UI is enabled, panel views (Problems, Output, Debug Console, and Explorer-in-panel) render with sidebar background/border colors instead of the configured panel colors.

## Best solution

Scope the pane background/border rules in src/vs/workbench/contrib/styleOverrides/browser/media/paneHeaders.css so panes inside `.part.panel` use `--vscode-panel-background`/`--vscode-panelSectionHeader-border` while panes inside `.part.sidebar`/`.part.auxiliarybar` keep the sideBar tokens, instead of relying on a single selector with a CSS variable fallback chain that always resolves to the sidebar token when both are set.
