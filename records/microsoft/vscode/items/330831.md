# Issue #330831 — Modern UI: Some panel parts use Sidebar colors instead of Panel colors

[https://github.com/microsoft/vscode/issues/330831](https://github.com/microsoft/vscode/issues/330831)

## Summary

Confirmed on main: the experimental Modern UI style-override CSS uses `.monaco-pane-view .pane` selectors without scoping to `.part.panel` vs `.part.sidebar`/`.part.auxiliarybar`, so views hosted in the panel (Problems, Output, Debug Console, or Explorer moved to the panel) render with sidebar background/border tokens instead of panel tokens.

## Change summary

When `workbench.experimental.modernUI` is enabled, panel-hosted pane views (Problems, Output, Debug Console, relocated Explorer) incorrectly pick up sideBar background/border colors instead of panel colors.

## Best solution

In src/vs/workbench/contrib/styleOverrides/browser/media/paneHeaders.css, scope the `.monaco-pane-view .pane` / `.pane-header` / `.pane-header::before` background and border rules by container (`.part.sidebar`/`.part.auxiliarybar` vs `.part.panel`), matching the pattern already used elsewhere in the same module (e.g. padding.css, roundedCorners.css use `.part.panel .pane-body...` scoping) so panel-hosted views use `panel.background`/`panelSectionHeader.border` while sidebar/auxiliary-bar views keep `sideBar.background`/`sideBarSectionHeader.border`. The separate ask (draw the section header border only when the panel is vertical) is a smaller polish item that can be folded into the same fix or tracked separately.
