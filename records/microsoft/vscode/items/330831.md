# Issue #330831 — Modern UI: Some panel parts use Sidebar colors instead of Panel colors

[https://github.com/microsoft/vscode/issues/330831](https://github.com/microsoft/vscode/issues/330831)

## Summary

The reporter and an independent commenter both confirmed this is fixed by PRs #331485/#331467, and current main's paneHeaders.css shows exactly the scoped-per-part CSS the commenter quoted from the shipped 1.135.0 build — this can be closed as completed.

## Change summary

In Modern UI, panel parts (Problems, Output, Debug Console, a panel-docked Explorer) picked up sideBar.background / sideBarSectionHeader.border instead of the panel's own color tokens.

## Best solution

Keep the shipped fix — paneHeaders.css now scopes the sideBar/panel background and section-header-border rules to `:is(.part.sidebar, .part.auxiliarybar)` vs `.part.panel` respectively, so panel parts no longer inherit sidebar colors.
