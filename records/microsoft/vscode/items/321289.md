# Issue #321289 — Notebook output Font Size/Family are not correct

[https://github.com/microsoft/vscode/issues/321289](https://github.com/microsoft/vscode/issues/321289)

## Summary

Confirmed in source: the `notebook-cell-output-font-family` CSS variable is defined in the webview but never applied to the output container's CSS rule — only `font-size` is applied. The font family setting is effectively ignored for outputs.

## Change summary

The `notebook.output.fontFamily` setting is ignored because the output container CSS rule in the notebook webview does not include a `font-family` declaration using the defined CSS variable.

## Best solution

Add `font-family: var(--notebook-cell-output-font-family);` to the `#container > div > div > div.output` CSS rule in `backLayerWebView.ts`, alongside the existing `font-size` declaration.
