# Issue #104436 — Add an api to determine runtime host environment (node, webworker)

[https://github.com/microsoft/vscode/issues/104436](https://github.com/microsoft/vscode/issues/104436)

## Summary

The API exists only as a proposal and has never been finalized, so the stable extension API still lacks the requested runtime-host signal. Recent Node worker isolation work reinforces the need to settle the runtime model before finalization.

## Change summary

Expose a stable extension API, and potentially a context key, identifying whether an extension runs with Node.js or Web Worker capabilities.

## Best solution

Review the current `extensionRuntime` proposal against process, Node worker, and Web Worker hosts, revise its semantics if necessary, then finalize it into `vscode.d.ts`; separately decide whether extensions need a corresponding when-clause context key.
