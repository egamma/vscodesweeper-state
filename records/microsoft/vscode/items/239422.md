## Summary

This is a known Windows 11 24H2 / Chromium bug causing mouse cursor disappearance in GPU-accelerated apps — not a VS Code defect. The canonical issue #236807 was closed after the reporter and commenters confirmed it's an upstream Windows/Chromium issue. Workarounds exist (disable GPU, change Windows pointer settings).

## Change summary

Mouse cursor disappears intermittently in VS Code with hardware acceleration enabled on Windows 11 24H2.

## Best solution

Close as upstream — the root cause is a Windows 11 24H2 / Chromium rendering bug affecting GPU-accelerated cursor rendering. Workarounds include disabling hardware acceleration (`--disable-gpu`) or changing the Windows mouse pointer style/size. The fix belongs in Windows or Chromium, not VS Code.

  > Thanks for the detailed report. This is a known Windows 11 24H2 bug affecting Chromium-based applications (including VS Code) — the mouse cursor disappears when GPU-accelerated cursor rendering interacts with certain Windows pointer settings. It was also reported in https://github.com/microsoft/vscode/issues/236807 and confirmed as an upstream issue.
  > 
  > **Workarounds:**
  > - Disable hardware acceleration: add `"disable-hardware-acceleration": true` to `argv.json` (or launch with `--disable-gpu`)
  > - Change your Windows mouse pointer style or increase the pointer size to 2+ in Windows Settings → Accessibility → Mouse pointer and touch
  > 
  > Since the root cause is in Windows / Chromium rather than VS Code, closing this as upstream. If a future Chromium or Windows update resolves the underlying bug, it should be fixed automatically.
