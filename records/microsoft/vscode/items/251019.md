# Issue #251019 — BYOK timeout for ollama models

[https://github.com/microsoft/vscode/issues/251019](https://github.com/microsoft/vscode/issues/251019)

## Summary

The BYOK Ollama request pipeline has no configurable or extended timeout for slow local inference — the bug is still present in the source on main. The built-in Ollama BYOK provider was recently deprecated in favor of the official Ollama extension (PR #323176), but the timeout issue was never fixed. Author is a team member, so keeping open.

## Change summary

BYOK requests to Ollama models time out during long inference (e.g. large local models like devstral:24b) because the fetch pipeline has no extended or configurable timeout.

## Best solution

If the built-in Ollama provider is being deprecated (PR https://github.com/microsoft/vscode/pull/323176), the team should decide whether to fix the timeout in the remaining built-in provider or ensure the official Ollama extension handles long inference gracefully. If the built-in provider remains usable during the deprecation period, adding a configurable request timeout in the OpenAI endpoint layer (`extensions/copilot/src/extension/byok/node/openAIEndpoint.ts`) or the abstract provider would resolve it.
