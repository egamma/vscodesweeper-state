# Issue #336880 — Extension signature verification fails with "Untrusted" / Internal Code 36

[https://github.com/microsoft/vscode/issues/336880](https://github.com/microsoft/vscode/issues/336880)

## Summary

The evidence isolates the failure to the bundled native vsce-sign verifier rather than an individual extension or VS Code profile. Current main still packages native verifier 2.0.6, so this should remain open and route to the extension-signature owners.

## Change summary

On the reported Windows configuration, the bundled signature verifier rejects valid Marketplace extension certificates as Untrusted with internal code 36.

## Best solution

Correct the certificate-usage evaluation in microsoft/vsce-sign, publish updated platform packages, and adopt that version in VS Code so valid Code Signing certificate chains are accepted without weakening signature enforcement.
