# Issue #336880 — Extension signature verification fails with "Untrusted" / Internal Code 36

[https://github.com/microsoft/vscode/issues/336880](https://github.com/microsoft/vscode/issues/336880)

## Summary

Well-documented, reproducible extension signature-verification failure (Internal Code 36 / 'Untrusted') affecting unrelated extensions/publishers on Windows, confirmed on a clean profile — a genuine bug in the vsce-sign trust-chain validation path, but this repo doesn't own the fix directly (the verifier is the external @vscode/vsce-sign native module), so routing to the area rather than closing.

## Change summary

Installing any Marketplace extension on Windows (e.g. Markdown All in One, Python) fails signature verification with Internal Code 36 ('Untrusted'), even though Windows itself validates the DigiCert code-signing chain as trusted.

## Best solution

Investigate/patch the chain-validation logic in the bundled @vscode/vsce-sign native verifier (reported divergence: Windows reports chain status 'None' while vsce-sign 2.0.6 reports 'NotValidForUsage' for the same DigiCert cert) and ship an updated vsce-sign version; this lives largely outside src/vs and likely in the separate vsce-sign project/dependency bump rather than this repo's TS code.
