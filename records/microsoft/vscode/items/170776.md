# Issue #170776 — Detect indentation from content confused by Doxygen comments

[https://github.com/microsoft/vscode/issues/170776](https://github.com/microsoft/vscode/issues/170776)

## Summary

The requested capability remains absent on current main: indentation detection is deliberately language-agnostic and counts Doxygen continuation alignment as indentation evidence. This is an accepted Backlog feature request with no verified canonical issue or completed implementation.

## Change summary

Make content-based indentation detection ignore indentation differences introduced by wrapped Doxygen comment lines.

## Best solution

Preserve the fast pre-tokenization detection path while finding a conservative way to exclude recognizable multiline-comment alignment from its evidence, with regression coverage for three-space C++ indentation and safeguards against changing ordinary text detection.
