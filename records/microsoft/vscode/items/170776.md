# Issue #170776 — Detect indentation from content confused by Doxygen comments

[https://github.com/microsoft/vscode/issues/170776](https://github.com/microsoft/vscode/issues/170776)

## Summary

Valid feature request — the indentation guesser in `indentationGuesser.ts` has no comment-awareness, so Doxygen-style continuation lines with alignment spacing genuinely skew the tab-size vote. The gap remains on current main; no fix or duplicate found.

## Change summary

The 'Detect Indentation from Content' heuristic is thrown off by multi-line block-comment continuation lines whose alignment spacing doesn't match the file's actual indentation unit.

## Best solution

Extend the alignment heuristic in `src/vs/editor/common/model/indentationGuesser.ts` to detect block-comment continuation patterns (lines starting inside a `/* … */` block whose extra indentation is alignment, not structural). The existing `looksLikeAlignment` flag only catches comma-terminated alignment; a similar guard for comment-interior lines would let the guesser skip those diffs.
