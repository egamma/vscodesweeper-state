# Issue #170776 — Detect indentation from content confused by Doxygen comments

[https://github.com/microsoft/vscode/issues/170776](https://github.com/microsoft/vscode/issues/170776)

## Summary

Keep open: the current indentation heuristic still lets wrapped Doxygen comments outweigh structural indentation. Manual settings provide a workaround, but do not deliver the requested automatic detection; no eligible canonical was found.

## Change summary

Improve indentation detection so wrapped Doxygen comments do not cause three-space C++ code to be detected as four-space code.

## Best solution

Make the editor's indentation inference distinguish comment alignment from structural indentation while preserving its lightweight, language-independent behavior. Retain this accepted request in editor-indent-detection; the newer PHP-comment report supplies related evidence, not a canonical for closing this older item.
