# Issue #313847 — AgentHost: Terminal shows previous command output until done

[https://github.com/microsoft/vscode/issues/313847](https://github.com/microsoft/vscode/issues/313847)

## Summary

Keep open: current source can associate a new Agent Host terminal invocation with the previous completed command. The related shell-integration tracker is newer than this re-reviewed report, so it cannot serve as a duplicate canonical.

## Change summary

An Agent Host terminal Run card displays the previous command's output while the next command runs.

## Best solution

Ensure each Agent Host Run card displays only output belonging to its own invocation, including before command-start metadata arrives. Coordinate that acceptance case with the shell-integration work at https://github.com/microsoft/vscode/issues/317789 without closing this older report.
