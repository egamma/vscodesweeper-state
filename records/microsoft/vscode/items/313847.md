# Issue #313847 — AgentHost: Terminal shows previous command output until done

[https://github.com/microsoft/vscode/issues/313847](https://github.com/microsoft/vscode/issues/313847)

## Summary

Still open and unfixed — the underlying root cause (partial shell integration in the agent host terminal) is tracked by the open issue https://github.com/microsoft/vscode/issues/317789, which hasn't landed yet. Team-authored, confirmed reproduced by multiple members, and actively being worked on.

## Change summary

The agent host terminal displays output from the previous command while the current command is still running, due to incomplete shell integration / command detection in the AHP terminal.

## Best solution

This is a symptom of the broader agent host shell integration gap tracked by https://github.com/microsoft/vscode/issues/317789 — bringing AHP terminal command detection closer to local shell integration (preserving OSC/data ordering, exposing prompt/command-start metadata) should resolve both this stale-output display and the related 'no output was produced' issue. Keep open until that work lands.
