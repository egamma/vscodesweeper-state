# Issue #281541 — Long distance widget is off screen

[https://github.com/microsoft/vscode/issues/281541](https://github.com/microsoft/vscode/issues/281541)

## Summary

The long-distance hint can still be placed below the viewport while its cursor anchor remains visible. Current placement code confirms a remaining defect; no fixing commit or verified duplicate was established.

## Change summary

Keep the long-distance NES preview visible when its cursor anchor is near the bottom of the editor.

## Best solution

Make long-distance hint placement account for the visible editor bounds, using space above the anchor when placement below would hide the preview. Preserve existing suggestion visibility and jump behavior.
