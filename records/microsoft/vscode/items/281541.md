# Issue #281541 — Long distance widget is off screen

[https://github.com/microsoft/vscode/issues/281541](https://github.com/microsoft/vscode/issues/281541)

## Summary

Still present on main: the long distance hint widget placement logic does not clamp to the editor's visible vertical viewport, so when the target line is near the bottom of the viewport the widget renders off-screen below it instead of flipping above.

## Change summary

The NES long distance hint widget can render off-screen below the viewport instead of positioning above when space below is insufficient.

## Best solution

Add vertical viewport bounds checking in the widget placement logic (longDistnaceWidgetPlacement.ts / inlineEditsLongDistanceHint.ts) so the widget flips above the cursor line when positioning it below would place it outside the editor's visible area.
