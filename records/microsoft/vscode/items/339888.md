# Issue #339888 — Provide a way to enter custom value for `untouched for`

[https://github.com/microsoft/vscode/issues/339888](https://github.com/microsoft/vscode/issues/339888)

## Summary

Real, scoped gap confirmed in the Sessions window's worktree cleanup editor: the "Untouched for" control is a plain `<select>` limited to 7/15/30/60/90 days with no way to enter a custom value. This is brand-new (0 upvotes, filed hours ago, no comments) but clearly actionable; the exact UI treatment (replace the dropdown vs. add a "Custom…" entry) is a small design call worth a quick plan pass.

## Change summary

Let users type a custom number of days for "untouched for" instead of only picking from preset options (7/15/30/60/90 days).

## Best solution

Extend the age select in SessionWorktreeCleanupEditor so users can enter an arbitrary day count, following the same checkbox+number-input pattern already used a few lines below for the automatic cleanup settings in the same file.
