# Issue #339888 — Provide a way to enter custom value for `untouched for`

[https://github.com/microsoft/vscode/issues/339888](https://github.com/microsoft/vscode/issues/339888)

## Summary

The manual worktree-cleanup editor still restricts “Untouched for” to five presets; custom day counts remain unsupported. Keep this team-authored request open: the existing numeric cleanup settings control different behavior, and the related feedback issues do not cover this request.

## Change summary

Allow users to enter a custom inactivity period for manual worktree cleanup instead of choosing only preset day counts.

## Best solution

Support a validated custom day count in the Sessions worktree-cleanup editor, updating eligibility and the storage summary while preserving existing session protections. Keep this manual filter distinct from automatic session-completion and deletion settings.
