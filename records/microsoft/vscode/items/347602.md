# Issue #347602 — Chat: "This is taking a little longer than usual" gives no indication of what the agent is stuck on

[https://github.com/microsoft/vscode/issues/347602](https://github.com/microsoft/vscode/issues/347602)

## Summary

Keep open as a request for actionable stall diagnostics. Current source still renders a generic inactivity message; the earlier foreground-tool fix does not provide the requested wait reason or duration.

## Change summary

Show the known activity or wait reason and elapsed waiting time when an agent request stalls.

## Best solution

Expose trustworthy wait-state context in the chat progress footer, distinguishing known model, tool, preparation, or retry activity from an unknown cause. Preserve existing foreground-tool suppression and avoid inferring a cause from inactivity alone.
