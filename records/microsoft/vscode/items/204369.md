# Issue #204369 — Error with Continue on Codespace

[https://github.com/microsoft/vscode/issues/204369](https://github.com/microsoft/vscode/issues/204369)

## Summary

The defect remains traceable on main: workspace-state migration transforms URI objects but misses URIs embedded inside serialized editor strings. Keep this team-authored Backlog issue open for a targeted Continue Working On fix.

## Change summary

Continuing from github.dev into a Codespace restores open editors with stale vscode-vfs URIs, causing missing-provider errors.

## Best solution

Transform resources inside serialized editor-input payloads before restoring transferred workspace state, while preserving unrelated opaque storage strings. Add coverage for transferring an open file from a vscode-vfs workspace to its Codespaces URI.
