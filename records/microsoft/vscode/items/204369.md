- **Trace:**

  > EditorPart uses USER-target workspace storage, and EditorGroupModel embeds each editor serializer's output as a string. FileEditorInputSerializer places resourceJSON inside that string. WorkspaceStateSynchroniser.apply parses the outer storage value, while the replacer returned by WorkspaceIdentityService.matches traverses URI objects but does not decode embedded serializer strings; conversion failures fall back to the unchanged storage value. This establishes the URI-restoration defect without execution, but not the command-collision cause. MainThreadComments.registerView registers workbench.action.focusCommentsPanel under a view-existence guard, so the collision needs a separate current-runtime trace. Preserve editor serializer compatibility, unrelated storage values, workspace identity matching, and working-change transfer.
