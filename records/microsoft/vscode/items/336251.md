## Summary

This recent feature request is still within the Backlog Candidates voting period and should remain open as under discussion. Current extension-facing file decorations cover colors and badges, but not a built-in workflow for assigning or synchronizing macOS Finder tags.

## Change summary

Add colored, Finder-like tags to files in the macOS Explorer so users can visually distinguish them.

First clarify whether the request is for VS Code-local labels or interoperability with native Finder tag metadata. Let the Backlog Candidates process establish demand; if pursued, reuse the Explorer decoration infrastructure and avoid changing file behavior on other platforms.
