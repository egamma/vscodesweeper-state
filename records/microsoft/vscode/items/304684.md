# Issue #304684 — Generate Commit Message succeeds in DevContainer but does not populate SCM input box

[https://github.com/microsoft/vscode/issues/304684](https://github.com/microsoft/vscode/issues/304684)

## Summary

The detailed logs confirm a remote-only correctness bug: generation completes successfully, but repository identity diverges between the Dev Container workspace and the Git model, so the visible SCM input is not populated. Current main retains the same repository-resolution and writeback path, with no matching fix or linked PR.

## Change summary

Generating a commit message in a Dev Container succeeds but writes to the wrong repository context instead of the visible SCM input box.

## Best solution

Make commit-message generation preserve the SCM repository selected by the input-box action across remote path resolution, and surface an error if that repository cannot be resolved rather than silently leaving the input empty.
