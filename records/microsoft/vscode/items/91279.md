# Issue #91279 — Use VS Code's syntax highlighting in Markdown preview

[https://github.com/microsoft/vscode/issues/91279](https://github.com/microsoft/vscode/issues/91279)

## Summary

Still valid: the Markdown preview uses highlight.js for code block syntax highlighting, not VS Code's TextMate grammars or semantic tokens. The underlying API request (https://github.com/microsoft/vscode/issues/56356) remains open. With 44 upvotes this is well above the backlog threshold and should stay open.

## Change summary

Use VS Code's own TextMate/semantic syntax highlighting in the Markdown preview's code blocks instead of highlight.js.

## Best solution

Implementing the syntax-highlighter API tracked in https://github.com/microsoft/vscode/issues/56356 would unblock this. Once extensions (and the built-in markdown extension) can access tokenized/colorized output from VS Code's grammar engine, the markdown preview can replace its highlight.js pipeline with editor-consistent highlighting. The markdown extension's `markdownEngine.ts` highlight function is the integration point.
