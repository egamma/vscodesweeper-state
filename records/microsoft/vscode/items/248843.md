# Issue #248843 — Overlay scrollbars in WebViews

[https://github.com/microsoft/vscode/issues/248843](https://github.com/microsoft/vscode/issues/248843)

## Summary

The webview scrollbar styling in index.html uses fixed 10px `::-webkit-scrollbar` rules with no overlay behavior — confirmed on current main. This is a real visual inconsistency with the rest of VS Code's overlay scrollbars, but it's a polish item rather than a bug since webviews are isolated browser contexts that can't reuse the editor's custom ScrollableElement.

## Change summary

Webview scrollbars are always visible and take up space, unlike the overlay scrollbars used in the rest of VS Code's UI.

## Best solution

Update the webview default styles in `src/vs/workbench/contrib/webview/browser/pre/index.html` to use CSS `overflow: overlay` (where supported) or `scrollbar-gutter: stable` plus transparent-on-idle thumb styling to approximate overlay scrollbar behavior. This is a self-contained CSS change in the webview pre-load HTML.
