# Issue #109221 — SCM Input - suggest widget is behind editor

[https://github.com/microsoft/vscode/issues/109221](https://github.com/microsoft/vscode/issues/109221)

## Summary

Still reproduces on Safari as of Dec 2024 (confirmed by a team member with video evidence). The z-index stacking context for the SCM suggest widget is broken specifically in Safari's rendering engine. No fix has landed on main.

## Change summary

The suggest widget in the SCM input renders behind the editor area in Safari due to a z-index stacking context issue.

## Best solution

Investigate Safari's stacking context behavior for the `.scm-overflow-widgets-container` (z-index 5000 in `src/vs/workbench/contrib/scm/browser/media/scm.css`) and the suggest widget (z-index 40 in `src/vs/editor/contrib/suggest/browser/media/suggest.css`). The overflow container's z-index should lift the suggest widget above the editor pane in all browsers. This may require a Safari-specific CSS workaround (e.g. `transform: translateZ(0)` or adjusting the stacking context hierarchy) or may be an upstream WebKit bug worth filing.
