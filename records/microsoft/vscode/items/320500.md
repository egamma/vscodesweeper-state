# Issue #320500 — Command risk assessment not shown in AHP prompts

[https://github.com/microsoft/vscode/issues/320500](https://github.com/microsoft/vscode/issues/320500)

## Summary

Still reproduces on main: the AHP/agent-host terminal tool confirmation prompts in the sessions/agents window do not render the risk assessment badge or terminal command summary that the workbench chat widget shows. No fix commit references this issue.

## Change summary

AHP-driven terminal tool confirmation prompts are missing the risk assessment badge and command summary that the standard chat widget's terminal tool confirmations display.

## Best solution

Integrate `createToolRiskBadge` (from `toolRiskBadgeHelper.ts`) and the terminal command summary rendering into the AHP confirmation flow in `src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/stateToProgressAdapter.ts` — this is the adapter that translates AHP state into chat progress, and it currently emits terminal tool confirmations without the risk or summary data that `chatTerminalToolConfirmationSubPart.ts` knows how to render.
