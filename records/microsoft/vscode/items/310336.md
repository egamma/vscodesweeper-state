# Issue #310336 — Ability to save diff views as a diff file

[https://github.com/microsoft/vscode/issues/310336](https://github.com/microsoft/vscode/issues/310336)

## Summary

Saving an arbitrary diff view as a .diff file remains a distinct capability gap in the inspected source. Keep this request open for scope and community discussion; the original request was closed for insufficient votes, not because the capability shipped or was explicitly rejected.

## Change summary

Provide a command to export a diff view as a .diff file without applying its changes.

## Best solution

Decide whether general text-diff export belongs in the core diff editor, with a reusable command that preserves the compared buffers without applying changes. Repository-specific export and chat-session export do not cover arbitrary diff views.
