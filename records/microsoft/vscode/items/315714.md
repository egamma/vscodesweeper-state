# Issue #315714 — Branch name in title is cutoff instead of `...`

[https://github.com/microsoft/vscode/issues/315714](https://github.com/microsoft/vscode/issues/315714)

## Summary

Team-filed polish issue about branch names being visually clipped in the Agents window title bar instead of showing an ellipsis. No fix referencing this issue found on main; the CSS for the workspace label element still lacks `text-overflow: ellipsis`.

## Change summary

Branch name text in the Agents window title bar is hard-clipped by `overflow: hidden` on the container rather than gracefully truncated with a `…` ellipsis.

## Best solution

Add `overflow: hidden; text-overflow: ellipsis;` to `.agent-sessions-titlebar-workspace` (or rework the flex layout so the workspace label can shrink with ellipsis when the container is too narrow) in `src/vs/sessions/contrib/sessions/browser/media/sessionsTitleBarWidget.css`. The current CSS comment says the workspace name 'must not be cropped', but the title bar container clips it anyway — so either the layout or that contract needs updating.
