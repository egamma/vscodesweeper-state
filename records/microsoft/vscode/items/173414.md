# Issue #173414 —  Dim Inactive Regions not working colorTheme Default High Contrast dark

## Summary

Decline close (out-of-scope) gated off: the issue carries `bug` and sits in Backlog — the owner already triaged it as accepted work. Original assessment: The C/C++ extension explicitly disables inactive-region dimming for the Default High Contrast theme, including in the reported extension version. Propose closing as caused by that extension rather than treating this as a VS Code theme defect.

## Change summary

Provide a visible indication of inactive C/C++ preprocessor regions in the default dark high-contrast theme.

## Best solution

The C/C++ extension should decide how to distinguish inactive preprocessor regions while preserving high-contrast readability. That behavior belongs in microsoft/vscode-cpptools, which owns both the theme-specific exclusion and the inactive-region decorations.
