# Issue #335868 — Info spotlight not screen reader accessible

[https://github.com/microsoft/vscode/issues/335868](https://github.com/microsoft/vscode/issues/335868)

## Summary

Freshly filed, team-authored accessibility bug in the new onboarding spotlight component: the info callout isn't reliably reachable/announced for screen reader users. Tracing the code supports the report, so this should stay open and route to the accessibility/onboarding area rather than close.

## Change summary

The onboarding 'spotlight' info card/callout cannot be focused by screen reader / keyboard users, so its content is never announced.

## Best solution

In src/vs/workbench/contrib/onboarding/browser/spotlight/spotlightOverlay.ts, ensure the callout (or its content) is reachable by keyboard/AT even for 'info'-only steps where focus currently only moves to the target or the next button — e.g. include the callout in the focus trap or set an appropriate aria-describedby/aria-label on the focused element pointing at the callout's title/description.
