# Issue #299967 — Failed to open chat session: Cannot read properties of undefined (reading 'match')

[https://github.com/microsoft/vscode/issues/299967](https://github.com/microsoft/vscode/issues/299967)

## Summary

Confirmed Copilot Chat history parsing bug: a malformed session entry with an undefined command reaches a `.match()` call and prevents that saved session from opening. The independent confirmation and stack trace make this actionable, but there is no verified fixing commit or same-symptom older canonical issue supporting closure.

## Change summary

Make existing Copilot CLI background chat sessions with missing terminal-command text open without throwing while parsing history.

## Best solution

Harden Copilot Chat's session-history conversion so malformed or legacy terminal-command records do not abort the entire session load, while preserving valid command entries and as much recoverable history as possible.
