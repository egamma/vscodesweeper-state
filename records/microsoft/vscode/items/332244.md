# Issue #332244 — Copilot "View All Edits" shows accepted/previous edits instead of only pending changed files

[https://github.com/microsoft/vscode/issues/332244](https://github.com/microsoft/vscode/issues/332244)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/303653 reports the same observable sequence—keep one batch of agent edits, continue editing, then see both batches in View All Edits. Current source also confirms that the chat list filters pending entries while the multi-diff maps every session entry.

## Change summary

Make View All Edits show only currently pending agent edits rather than previously accepted edits accumulated in the session.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode/issues/303653 and fix the shared multi-diff source so its normal view includes only entries whose state is Modified, while preserving the explicit previous-changes mode.
