# Issue #332244 — Copilot "View All Edits" shows accepted/previous edits instead of only pending changed files

[https://github.com/microsoft/vscode/issues/332244](https://github.com/microsoft/vscode/issues/332244)

## Summary

Traced on main: the 'View All Edits' multi-diff source lists every entry ever accumulated in the editing session regardless of state, instead of only the currently pending (Modified) ones, which is a real gap worth fixing in the chat editing multi-diff resolver.

## Change summary

'View All Edits' opens a multi-diff showing all files ever touched in the session (including already-accepted ones), instead of only the currently pending/undecided files that the chat's own file-count summary reports.

## Best solution

In ChatEditingMultiDiffSource._resources (src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingServiceImpl.ts), filter entries to `state.get() === ModifiedFileEntryState.Modified` when `_showPreviousChanges` is false (the 'View All Edits' path), matching the same filter chatInputPart.ts already applies for the pending-files count/list; leave the unfiltered/historical listing for the explicit 'View Previous Edits' action.
