# Issue #100976 — API for custom editors handling some menu actions

[https://github.com/microsoft/vscode/issues/100976](https://github.com/microsoft/vscode/issues/100976)

## Summary

Valid API gap: custom editors have no extension-facing hooks for Find, Select All, or clipboard operations. The webview panel handles find internally but doesn't expose it to extension authors. No progress found on main.

## Change summary

Request an extension API for custom editors to intercept and customize Find, Select All, Cut/Copy/Paste menu actions.

## Best solution

Expose optional method hooks on CustomEditorProvider (or via a capability interface) that let extensions handle find/clipboard commands within their custom editor webviews, similar to how the internal webview find commands work but delegated to the extension. This belongs in the custom-editors API surface area.
