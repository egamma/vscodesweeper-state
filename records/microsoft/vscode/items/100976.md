# Issue #100976 — API for custom editors handling some menu actions

[https://github.com/microsoft/vscode/issues/100976](https://github.com/microsoft/vscode/issues/100976)

## Summary

Keep open: existing webview find and DOM editing commands provide partial functionality, but do not deliver the requested unified API for custom editors to supply their own menu-action behavior. No verified older canonical was found.

## Change summary

Expose custom-editor handlers for standard menu actions such as Find, Select All, Cut, Copy, and Paste.

## Best solution

Have the custom-editor API owners assess a public command-handling contract for non-text editors, preserving existing webview DOM behavior as the default. The remaining requirement is custom semantics for standard actions, not merely enabling built-in text search or clipboard events.
