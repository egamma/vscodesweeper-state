# Issue #331168 — Markdown syntax highlighting: line-leading `$` starts a math block and affects the rest of the document

[https://github.com/microsoft/vscode/issues/331168](https://github.com/microsoft/vscode/issues/331168)

## Summary

Confirmed on current main: the single-dollar math-block TextMate rule still opens an unclosed math scope for lines like `$ echo` or `$PATH`, mis-highlighting the rest of the document — a real, unfixed grammar bug worth routing to the markdown area.

## Change summary

A line starting with a single `$` (e.g. a shell prompt) that has no closing `$` incorrectly starts a Markdown math block and breaks highlighting for the rest of the document.

## Best solution

Tighten the `single_dollar_math_block` begin regex in extensions/markdown-math/syntaxes/md-math-block.tmLanguage.json (currently `(?<=^\s*)(\$)(?![^$]*\$|\d)`) to also exclude common non-math patterns (trailing space/command text, `$VAR`/`$PATH`-style tokens) so a lone unmatched `$` doesn't hijack tokenization of the rest of the file; likely needs coordination with the upstream vscode-markdown-tm-grammar project.
