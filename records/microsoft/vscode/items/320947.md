# Issue #320947 — Copilot Chat add extra characters to terminal commands

[https://github.com/microsoft/vscode/issues/320947](https://github.com/microsoft/vscode/issues/320947)

## Summary

Keep open: multiple users confirm that agent-sent PowerShell commands acquire a literal Ctrl+U prefix, and current fallback execution strategies still send that character without checking shell bindings. The older related report covers first-command failures, but does not establish ownership of this report's subsequent-command and post-Start-Sleep failures.

## Change summary

Prevent terminal input cleanup from corrupting agent-sent PowerShell commands with a leading U+0015 character.

## Best solution

Agent terminal execution should preserve valid PowerShell commands without requiring users to customize PSReadLine bindings. Diagnose both fallback execution and the reported persistence after enabling Rich shell integration, preserving pending-input cleanup and accurate command completion.
