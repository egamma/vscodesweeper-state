# Issue #320947 — Copilot Chat add extra characters to terminal commands

[https://github.com/microsoft/vscode/issues/320947](https://github.com/microsoft/vscode/issues/320947)

## Summary

Still present on main: the none and basic terminal execute strategies send `\x15` (Ctrl+U) to clear pending input before agent commands, but PowerShell/PSReadLine may not consume this byte — especially before PSReadLine initialization or with non-default bindings — causing it to leak as a literal `^U` prefix on the command. A second reporter confirms the issue on 1.125.

## Change summary

Copilot agent terminal commands in PowerShell get a stray `^U` (U+0015) prefix, causing command failures and cascading agent confusion.

## Best solution

The none and basic execute strategies should use a PowerShell-appropriate line-clear sequence (e.g. `Escape` / `\x1b` which PSReadLine binds to `RevertLine` by default) instead of `\x15` when the shell is detected as PowerShell. The `isPowerShell()` helper already exists in `runInTerminalHelpers.ts`. The fix is localized to `noneExecuteStrategy.ts` and `basicExecuteStrategy.ts`.
