# Issue #325545 — Terminal Environment popup is clipped when content exceeds available height and action buttons become inaccessible

[https://github.com/microsoft/vscode/issues/325545](https://github.com/microsoft/vscode/issues/325545)

## Summary

Valid bug: the hover widget's action bar (e.g. 'Relaunch Terminal') sits outside the scrollable content area but inside the `overflow: hidden` container that receives a `maxHeight`. When markdown content is tall enough, the action bar is clipped. The fix belongs in the hover infrastructure, not terminal-specific code.

## Change summary

Terminal environment hover popup clips its action buttons when the content from many contributing extensions exceeds the available window height, with no scrollbar to reach them.

## Best solution

Make the hover widget's `containerDomNode` use a flex column layout so the scrollable content area (`DomScrollableElement`) takes `flex: 1` and shrinks to fit, while the `.status-bar` action row stays pinned at the bottom and never overflows. The fix is in `src/vs/base/browser/ui/hover/hoverWidget.css` and possibly `src/vs/platform/hover/browser/hover.css`. This benefits all hover consumers with actions, not just the terminal.
