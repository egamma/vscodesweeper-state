# Issue #315782 — Integrated Terminal: GPU texture cache residue under memory pressure

[https://github.com/microsoft/vscode/issues/315782](https://github.com/microsoft/vscode/issues/315782)

## Summary

The texture atlas and WebGL glyph cache are managed by xterm.js (@xterm/addon-webgl), not VS Code core. The report plausibly describes a real rendering issue but lacks concrete reproduction evidence (screenshots, consistent repro steps without Claude Code). Needs more info to determine whether this is upstream xterm.js, a Chromium/GPU driver issue, or something VS Code can mitigate.

## Change summary

Old terminal content appears as static bitmap residue overlaid on the current display after GPU memory pressure, specifically during Claude Code context compaction with many VS Code windows open.

## Best solution

Determine whether this is reproducible without Claude Code (pure xterm.js repro) and whether it's a xterm.js texture atlas invalidation bug or a Chromium/GPU driver issue. If it's xterm.js, file upstream at xtermjs/xterm.js. VS Code could potentially mitigate by calling `clearTextureAtlas()` more aggressively (similar to the existing OS-resume path in `terminalNativeContribution.ts`), but the root cause likely lives upstream.
