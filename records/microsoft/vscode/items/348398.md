[https://github.com/microsoft/vscode/issues/348398](https://github.com/microsoft/vscode/issues/348398)

## Summary

Keep open as background-shell UX polish: current source provides command and output inspection, but still places them behind a picker and details panel. Existing controls do not fully address the request for shallower access and a more usable output surface.

## Change summary

Make running background commands and their output easier to discover and inspect without nested interactions or cramped previews.

## Evidence

- **reported problem:** https://github.com/microsoft/vscode/issues/348398 describes multiple nested interactions to inspect background commands and cramped, collapsed output on VS Code 1.146.0; no comments establish a functional defect or an accepted design.
- **existing inspection capability:** src/vs/workbench/contrib/chat/browser/sessionBackgroundShellsControl.ts documents a Background Shells pill that opens a picker, then command details beside it. SessionBackgroundShellsControl._entry supplies expandable hover content, and _showDetails constructs the command/output view. Keyboard navigation exists, but does not remove the nested presentation.
- **output presentation:** src/vs/workbench/contrib/chat/browser/sessionBackgroundShellOutputView.ts renders an expanded read-only output terminal with Rows = 10. This provides live output, but remains inside the details panel; source inspection does not establish the reporter's exact visible two-line layout.
- **partial alternative:** src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/chatTerminalToolProgressPart.ts provides Show Output and workbench.action.chat.openTerminalFullOutput. The latter is conditional on resolvable retained output for a truncated non-PTY command, so it is not a general replacement for easily accessible live background-shell output.
- **related reports are not established duplicates:** https://github.com/microsoft/vscode/issues/347321 requests restoring visibility and a kill button for a stuck PowerShell command; https://github.com/microsoft/vscode/issues/348399 reports background execution blocking chat.
