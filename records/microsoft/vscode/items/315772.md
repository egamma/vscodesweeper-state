# Issue #315772 — Agents `changes` tab lists files from parent git repo with poor UI

[https://github.com/microsoft/vscode/issues/315772](https://github.com/microsoft/vscode/issues/315772)

## Summary

Two real UI bugs in the Agents window changes tab when a parent git repo has changes: files from the parent lack clear labeling, and diff stats show incorrect +0 -0. No fix found on main; routing to the sessions/agents area.

## Change summary

The Agents window changes tab shows parent-repo files with unclear provenance (only subtle `..` prefix) and incorrect `+0 -0` diff stats.

## Best solution

Fix the changes view to clearly indicate when files belong to a parent git repo (e.g., show the repo name or a visible path prefix), and ensure insertions/deletions are correctly computed for parent-repo files. The diff stats issue likely stems from how `agentHostSessionChangesets.ts` populates `insertions`/`deletions` for files outside the session's direct workspace repo.
