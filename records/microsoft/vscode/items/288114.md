# Issue #288114 — Chat: When switching from Plan to Start Implementation, input gets lost

[https://github.com/microsoft/vscode/issues/288114](https://github.com/microsoft/vscode/issues/288114)

## Summary

The defect remains directly visible on current main, but an open PR already references and targets it. Keep the issue open while that implementation is reviewed.

## Change summary

Starting implementation from Plan mode overwrites and permanently loses text already entered in the chat input.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/310967, ensuring Plan handoffs preserve a non-empty user draft while retaining the existing canned-prompt behavior for an empty input.
