Team-authored bug with partial fixes landed but no full resolution confirmed. ## Change summary

Chat question carousel doesn't scroll properly when the chat widget is constrained in a split editor layout — the carousel sizing is based on window size rather than the widget's available space.

## Best solution

Extend the available-height plumbing from PR #302670 to also cap the question carousel's max height relative to the chat widget's container, so the carousel scrolls correctly when space is constrained in split editors. The fix likely lives in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatQuestionCarouselPart.ts` and the chat input part layout code.
