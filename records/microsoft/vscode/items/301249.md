# Issue #301249 — Chat questions don't scroll

[https://github.com/microsoft/vscode/issues/301249](https://github.com/microsoft/vscode/issues/301249)

## Summary

Keep open: the question carousel still lacks the chat editor's available-height constraint, so resizing an individual editor can leave questions overflowing despite the input-editor fix. The thread confirms this distinction, and current source retains the missing connection.

## Change summary

Constrain question-carousel scrolling to the available height of an individual chat editor rather than the window height.

## Best solution

Make the question carousel honor the chat widget's height budget while keeping its question content scrollable and its controls reachable, both when an editor shrinks and when space is restored. Preserve the existing input-editor and tool-confirmation layout behavior.
