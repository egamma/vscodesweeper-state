# Issue #334186 — Send x-opencode-session header on API requests (required by OpenCode Go from 09/05)

[https://github.com/microsoft/vscode/issues/334186](https://github.com/microsoft/vscode/issues/334186)

## Summary

Thanks for the report — but Copilot Chat already lets users attach arbitrary custom headers per model via the custom-endpoint `requestHeaders` config, which several commenters confirmed works as a fix; hardcoding one third-party vendor's specific header requirement into core Copilot Chat isn't something the project should special-case.

## Change summary

Send a stable `x-opencode-session` header on all outbound inference requests so the OpenCode Go managed-inference API can route/optimize per conversation.

## Best solution

Point requesters at the documented `requestHeaders` field on custom endpoint models (`extensions/copilot/src/extension/byok/common/byokProvider.ts`), which already lets any user or vendor supply `x-opencode-session` (or any other header) per model — no core change needed for a single third-party vendor's routing header.
