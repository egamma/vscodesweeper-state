# Issue #334186 — Send x-opencode-session header on API requests (required by OpenCode Go from 09/05)

[https://github.com/microsoft/vscode/issues/334186](https://github.com/microsoft/vscode/issues/334186)

## Summary

The per-conversation header capability remains missing, but the older, open canonical issue explicitly covers both that capability and the same OpenCode Go MissingSessionID failure. Consolidate this accepted request there, preserving its provider-specific reproduction and community demand.

## Change summary

Send an x-opencode-session header whose value remains stable within a conversation and differs between conversations on OpenCode Go inference requests.

## Best solution

Track the work in https://github.com/microsoft/vscode/issues/316794 and provide conversation-aware custom header values that can satisfy OpenCode Go without sending its vendor-specific header to unrelated providers. Preserve this report's endpoint, failure details, and 90-upvote demand in the consolidation.
