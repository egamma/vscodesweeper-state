# Issue #334186 — Send x-opencode-session header on API requests (required by OpenCode Go from 09/05)

[https://github.com/microsoft/vscode/issues/334186](https://github.com/microsoft/vscode/issues/334186)

## Summary

Verified duplicate: the underlying ask — a way to send a stable, dynamically-generated per-conversation identifier on BYOK/custom-endpoint requests — is already tracked by the older, open, broader issue #316794, which covers both static custom headers and an automatic per-session identifier for exactly this class of provider.

## Change summary

OpenCode Go's gateway now rejects Copilot Chat requests that lack an `x-opencode-session` header carrying a stable per-conversation ID; requester wants VS Code/Copilot Chat to send it.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316794, which already asks for the general mechanism (configurable custom headers plus an automatically generated stable per-chat-session identifier for BYOK/OpenAI-compatible providers) that would satisfy this vendor's requirement without hardcoding a competitor's proprietary header name into core.
