# Issue #334186 — Send x-opencode-session header on API requests (required by OpenCode Go from 09/05)

[https://github.com/microsoft/vscode/issues/334186](https://github.com/microsoft/vscode/issues/334186)

## Summary

This is a specific instance (OpenCode Go's `x-opencode-session` header) of an older, broader, still-open request already assigned to the same engineer (vritant24) — sending a stable per-conversation identifier / custom static headers for BYOK/OpenAI-compatible providers. Proposing consolidation there rather than tracking the vendor-specific header separately.

## Change summary

Copilot Chat should send an `x-opencode-session` (or equivalent stable per-conversation) header on outbound requests to the OpenCode Go BYOK/custom-endpoint provider, since the vendor now rejects requests without one.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/316794, which already asks for exactly this capability in general form (custom static headers, or an automatically generated stable per-chat-session identifier, for BYOK/OpenAI-compatible providers) — implementing that would satisfy OpenCode Go's requirement (and any other provider with the same need) without a vendor-named header baked into core.
