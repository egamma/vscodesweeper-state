# Issue #334186 — Send x-opencode-session header on API requests (required by OpenCode Go from 09/05)

[https://github.com/microsoft/vscode/issues/334186](https://github.com/microsoft/vscode/issues/334186)

## Summary

Keep this accepted Backlog request open: current Custom Endpoint headers cannot express a stable, distinct identifier for each conversation. Static headers bypass the gateway rejection but do not satisfy conversation affinity; related session-header work remains open.

## Change summary

Allow OpenCode Go inference requests to carry an x-opencode-session identifier that remains stable within a conversation and differs between conversations.

## Best solution

Provide a provider-agnostic, opt-in way to populate configured headers from conversation identity, allowing OpenCode Go users to supply its required header without adding it to unrelated providers. Evaluate the existing header-middleware and session-context PRs before starting another implementation, and retain this report's gateway-specific acceptance case.
