# Issue #262906 — The ANSI reset escape doesn't terminate an hyperlink

[https://github.com/microsoft/vscode/issues/262906](https://github.com/microsoft/vscode/issues/262906)

## Summary

Correctly triaged as upstream — the OSC 8 hyperlink parsing and SGR reset handling lives entirely in xterm.js, not in VS Code's terminal contribution code. The issue is already labeled `upstream` and `terminal-links`; keeping it open to track until xterm.js addresses the behavior.

## Change summary

The ANSI SGR reset escape sequence (`\x1b[0m`) does not terminate an active OSC 8 hyperlink in the terminal, even though the spec treats hyperlinks as a character-cell attribute like color or bold.

## Best solution

This needs to be fixed in xterm.js's OSC 8 parser — when processing an SGR reset (code 0), it should also clear any active hyperlink state. The fix would land in VS Code via an xterm.js dependency bump. Track the upstream issue in xtermjs/xterm.js and bump the dependency once resolved.
