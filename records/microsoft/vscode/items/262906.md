# Issue #262906 — The ANSI reset escape doesn't terminate an hyperlink

[https://github.com/microsoft/vscode/issues/262906](https://github.com/microsoft/vscode/issues/262906)

## Summary

Keep open with the existing upstream classification. xterm.js explicitly preserves hyperlink state across SGR reset, so changing this behavior requires an upstream terminal-protocol decision rather than a VS Code link-handling fix.

## Change summary

Consider whether SGR reset (`ESC[0m`) should also terminate an active OSC 8 hyperlink.

## Best solution

Resolve the reset semantics with xterm.js while preserving terminal compatibility; VS Code should follow the upstream parser behavior rather than introduce its own override. The supported way to terminate a hyperlink today is an empty OSC 8 sequence.
