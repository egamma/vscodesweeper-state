# Issue #325743 — Toggle maximized terminal causes codex to render glitches

[https://github.com/microsoft/vscode/issues/325743](https://github.com/microsoft/vscode/issues/325743)

## Summary

Legitimate visual bug: when hiding a maximized panel via Ctrl+J, the layout code first un-maximizes (triggering a resize to the non-maximized height) before hiding it — this intermediate resize sends a spurious dimension change to the terminal's PTY, causing TUI apps like Codex to render glitches.

## Change summary

Toggling a maximized terminal panel hidden via Ctrl+J sends a spurious intermediate resize (at non-maximized dimensions) to TUI apps before the panel is actually hidden, causing rendering artifacts.

## Best solution

In `setPanelHidden` (src/vs/workbench/browser/layout.ts ~line 2087), suppress the terminal resize event during the un-maximize step before hiding, or batch the un-maximize and hide into a single layout pass so no intermediate dimensions are propagated to the PTY. The terminal instance's `_resize()` / layout path (src/vs/workbench/contrib/terminal/browser/terminalInstance.ts) could also guard against resizing when the panel is about to become hidden.
