# Issue #334631 — Agent host renders nothing for a skill that runs in a subagent

[https://github.com/microsoft/vscode/issues/334631](https://github.com/microsoft/vscode/issues/334631)

## Summary

Well-diagnosed, source-confirmed defect: a skill-spawned subagent (e.g. the built-in /code-review) has no toolUseId, so SubagentRegistry never registers it and the turn's entire output is dropped even though the SDK result text is available — this is a real gap that needs a fix, not a close.

## Change summary

When a skill runs as a subagent, the chat turn renders nothing (empty bubble) for the whole duration, and the result is silently discarded even though it completed successfully and is recoverable from the CLI's own transcript file.

## Best solution

In claudeSdkPipeline.ts's result branch (around line 692), surface the SDK result message's text as a response part when the turn ends having emitted zero response parts/tokens, and separately key SubagentRegistry (or add a fallback path) so skill-spawned agents without a toolUseId still get a subagent chat opened; the reporter's own local patch demonstrates this is tractable.

## Evidence

- **result text discarded:** src/vs/platform/agentHost/node/claude/claudeSdkPipeline.ts:692-709 handles `message.type === 'result'` only to settle the queue head and fire ChatTurnComplete; it never reads or forwards the result's text. grep across node/claude/*.ts shows the only other `.result` read is `claudeMapSessionEvents.ts:530`, used solely for the `is_error` case.
- **second root cause corroborated:** chatService.ts:1097 and languageModelToolsService.ts:398 confirm `hiddenAfterComplete` presentation exists and hides a tool invocation once complete — consistent with the reporter's claim that a backgrounded subagent's launch call (which completes in ~2s) hides the only affordance for a run that continues for minutes.
- **no existing fix on main:** `git log` on claudeSdkPipeline.ts and claudeSubagentRegistry.ts shows no recent commits touching this path; the reporter's suggested guard (surface result text only when zero tokens were spent) is not yet present.
