# Issue #334631 — Agent host renders nothing for a skill that runs in a subagent

[https://github.com/microsoft/vscode/issues/334631](https://github.com/microsoft/vscode/issues/334631)

## Summary

Still present on current main: a successful Claude SDK result containing the skill subagent's only output produces usage but no response part, after which the pipeline completes the turn. The final-output defect is source-confirmed and bounded, while progress, reload persistence, background presentation, and cancelled-session recovery are distinct follow-up problems.

## Change summary

A Claude skill executed through an unregistered subagent completes with an empty response because its result-only text is never rendered.

## Best solution

Surface a successful result's nonempty text exactly once when that turn emitted no assistant response content, without duplicating ordinary streamed responses. Keep progress, restored-history persistence, background-subagent presentation, and conversationless-session recovery as separate work because they have different lifecycle paths.
