# Issue #245807 — `"editor.unicodeHighlight.allowedLocales": {"de": true }` should stop highlighting of Germany umlauts

[https://github.com/microsoft/vscode/issues/245807](https://github.com/microsoft/vscode/issues/245807)

## Summary

The documented locale exemption conflicts with the current all-non-ASCII highlighting path, which bypasses allowedLocales. Keep this accepted Backlog bug open to resolve that configuration contract; neither candidate establishes a duplicate under the re-review rules.

## Change summary

Allowing German characters through editor.unicodeHighlight.allowedLocales does not suppress their Unicode highlights as the setting description promises.

## Best solution

Make the locale setting's documented guarantee and effective highlighting behavior agree. Preserve the established all-non-ASCII review mode unless the editor owner explicitly decides that locale exemptions should override it.
