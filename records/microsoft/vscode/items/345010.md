# Issue #345010 — Copilot Fusion ignores explicit multi-turn gating ("summarize plan before making changes") and applies edits immediately

[https://github.com/microsoft/vscode/issues/345010](https://github.com/microsoft/vscode/issues/345010)

## Summary

Keep open to investigate Fusion proceeding past a requested plan-approval boundary. Another user confirms the same observable failure during a cascade workflow; existing explicit planning modes do not establish that instructions in Agent mode are respected.

## Change summary

Honor requests to present a plan and await approval before editing, including across Fusion phases.

## Best solution

Ensure an explicit request to wait for approval remains effective throughout the Fusion workflow, rather than allowing a later phase to treat a planning-only response as incomplete implementation. Investigate the feedback-control visibility concern separately from execution gating.
