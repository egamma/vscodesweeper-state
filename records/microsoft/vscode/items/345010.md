# Issue #345010 — Copilot Fusion ignores explicit multi-turn gating ("summarize plan before making changes") and applies edits immediately

[https://github.com/microsoft/vscode/issues/345010](https://github.com/microsoft/vscode/issues/345010)

## Summary

Keep open: the reported approval-boundary failure has independent corroboration, including a Fusion review phase implementing a plan without approval. Existing planning workflows do not establish that natural-language approval requirements are respected in Agent mode; no verified fix or same-symptom canonical was found.

## Change summary

Copilot Fusion applies workspace edits before requested plan approval, with an additional request to retain feedback controls on tool-calling responses.

## Best solution

Honor explicit requests to wait for approval across every Fusion execution phase, while preserving ordinary authorized Agent execution. Diagnose the runtime-versus-host boundary before selecting a fix, and assess feedback visibility separately rather than assuming it shares the execution defect.
