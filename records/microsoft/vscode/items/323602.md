# Issue #323602 — Proposed API: opt-in, consent-gated camera/microphone access for extension webviews

[https://github.com/microsoft/vscode/issues/323602](https://github.com/microsoft/vscode/issues/323602)

## Summary

Well-structured feature request with 21 upvotes, already promoted to Backlog by the community process. The proposed API for consent-gated camera/microphone access in extension webviews is not implemented on main — the existing browser permission infrastructure (browserView) has not been extended to webviews. Stays open as a valid backlog item.

## Change summary

Allow extension webviews to request camera/microphone access via a declared, consent-gated opt-in API.

## Best solution

Extend the existing integrated-browser permission model (src/vs/platform/browserView/common/browserPermissions.ts and related files) to extension webviews: add a proposed API for declaring media device needs, inject iframe `allow` attributes only for declaring webviews, and reuse the consent UI/storage. The author's PoC commit provides a starting point. A team member should evaluate the security surface and decide on the consent UX and grant persistence model.
