# Issue #323602 — Proposed API: opt-in, consent-gated camera/microphone access for extension webviews

[https://github.com/microsoft/vscode/issues/323602](https://github.com/microsoft/vscode/issues/323602)

## Summary

Keep open: current source still blocks camera/microphone access for extension webviews, and this consent-gated API request has earned Backlog acceptance with 26 upvotes. A maintainer subsequently closed the older microphone report in favor of this issue, reinforcing its role as the tracking destination.

## Change summary

Provide an opt-in extension-webview API for camera and microphone access with explicit consent and revocable per-extension grants.

## Best solution

Have the webview and API owners define a consent-gated media-access contract that preserves default denial and provides trustworthy extension attribution and grant revocation. Resolve desktop, remote, and web permission semantics before accepting a production implementation.
