# Issue #310971 — Merge Conflict: detect and offer auto-resolution when both sides are identical

[https://github.com/microsoft/vscode/issues/310971](https://github.com/microsoft/vscode/issues/310971)

## Summary

Keep open while the linked implementation PR is reviewed. The inline merge-conflict extension still lacks identical-content detection and selective bulk resolution; the separate merge editor's existing auto-resolution does not provide the requested CodeLens workflow.

## Change summary

Recognize identical current and incoming conflict regions and offer an explicit acceptance action plus an Accept All Identical command.

## Best solution

Review https://github.com/microsoft/vscode/pull/310973 against the requested additive, opt-in behavior, including whether existing CodeLens actions remain available. Identical conflicts should resolve to one copy of the content, while selective bulk acceptance leaves non-identical conflicts untouched.
