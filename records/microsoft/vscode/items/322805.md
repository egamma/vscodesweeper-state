[https://github.com/microsoft/vscode/issues/322805](https://github.com/microsoft/vscode/issues/322805)

## Summary

Keep open: current source still retains marketplace registrations after uninstall, but standalone-plugin installation now avoids registering a marketplace, so the exact reported failure needs retesting. The supplied deleted-branch and cache-removal steps suffice; the report's unwanted-download security concern also requires human assessment rather than an automated close.

## Change summary

Uninstalling a source-installed plugin leaves an obsolete branch registered as a marketplace, causing later download attempts and installation errors.

## Best solution

Ensure obsolete source-install registrations cannot make installing a valid source fail or unexpectedly fetch an uninstalled source. Assess registration ownership and cleanup in the plugin installation and marketplace services without removing independently configured marketplaces or registrations needed by other plugins.
