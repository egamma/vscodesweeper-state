# Issue #281507 — VS Code freezes when expanding a folder containing extremely large number of files (300M+ files)

[https://github.com/microsoft/vscode/issues/281507](https://github.com/microsoft/vscode/issues/281507)

## Summary

The large-directory Explorer freeze remains actionable, and an open PR directly references and proposes to fix this issue. It must stay open while that implementation is reviewed because the PR has not merged and explicitly leaves OS-level directory enumeration as follow-up work.

## Change summary

Expanding a directory containing millions of files makes the Explorer and UI unresponsive because all entries are resolved and processed at once.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/320536 if its bounded paging approach adequately prevents the post-resolution UI freeze, then assess whether the remaining non-streaming directory enumeration requires separate file-service work.
