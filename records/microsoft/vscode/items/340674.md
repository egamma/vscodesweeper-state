# Issue #340674 — `code agent ps` fails with AHP protocol mismatch (CLI 0.9.0 vs. Agent Host 0.10.0) on Windows with VS Code 1.141.0

## Summary

Thanks for the detailed report. It is a credible, self-consistent report that the 1.141.0 CLI offers AHP 0.9.0 while the same-commit Agent Host requires ^0.10.0. It stays open for an owner to check the CLI's AHP version constant against the host's.

## Change summary

`code agent ps` on Windows 1.141.0 cannot initialize with the Agent Host because the CLI offers AHP 0.9.0 and the host requires ^0.10.0.

## Best solution

Make the CLI's offered AHP protocol version (AGENT_HOST_PROTOCOL_VERSION in cli/src/tunnels/agent_host.rs) track the Agent Host's version at build time, and fix the already-shipped release. Optionally add a release check that the two stay in sync.
