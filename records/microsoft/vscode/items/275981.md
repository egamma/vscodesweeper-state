# Issue #275981 — [Feedback] [Plan Mode] Confusing UX for "Open in Editor" option and .prompt.md file extension

[https://github.com/microsoft/vscode/issues/275981](https://github.com/microsoft/vscode/issues/275981)

## Summary

The UX gap remains on current main: Plan mode still presents “Open in Editor” and instructs the agent to create an untitled `.prompt.md` file. A maintainer agreed that plain Markdown would be better, while the exact action wording and focus behavior still need a product decision.

## Change summary

Make Plan mode's editor handoff clearly describe its result, use an ordinary Markdown filename, and visibly focus the newly created plan document.

## Best solution

Treat the handoff as exporting an editable plan artifact: use a label that clearly distinguishes it from starting implementation, create a plain `.md` document, and bring that document into focus for review.
