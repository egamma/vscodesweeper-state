# Issue #180793 — VS Code: on using the keys control + right/left keys and moving to next line the information of moving to next line is not read 

[https://github.com/microsoft/vscode/issues/180793](https://github.com/microsoft/vscode/issues/180793)

## Summary

The issue has two parts: line-number announcement on word-navigation across lines (a known limitation tracked upstream in monaco-editor#410, still open) and repeated-word reading (confirmed as a Chromium bug, reportedly fixed). The under-discussion label and existing workarounds (Ctrl+G, status bar) make this worth keeping open for the accessibility team to decide on.

## Change summary

Screen readers don't announce line changes when using Ctrl+Right/Left to navigate across line boundaries in the editor.

## Best solution

The accessibility team should decide whether to add an ARIA announcement or audio cue when word-navigation crosses a line boundary. The upstream monaco-editor#410 (line numbers not accessible) remains open and tracks the broader problem. The repeated-word sub-issue appears fixed by Chromium updates — verify on current builds and close that aspect if confirmed.
