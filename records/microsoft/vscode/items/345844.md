# Issue #345844 — Subagents only receive file-editing tools when their model family matches the parent session's model

[https://github.com/microsoft/vscode/issues/345844](https://github.com/microsoft/vscode/issues/345844)

## Summary

Keep open: the report provides a concrete parent/subagent model matrix sufficient to retest missing editing tools. Current source allows both editing-tool families, but existing subagent coverage deliberately stays within one model family and does not establish whether the reported runtime behavior persists.

## Change summary

Mixed-model subagents lose their model-appropriate file-editing tools when their model family differs from the parent session.

## Best solution

Ensure each subagent receives its own model-appropriate editing tools within the configured tool and permission restrictions. First reproduce the cross-family matrix and determine whether tool loss occurs in VS Code's session configuration or the bundled runtime.
