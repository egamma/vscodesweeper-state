# Issue #241973 — Inconsistent use of `Experimental` tag in Settings

[https://github.com/microsoft/vscode/issues/241973](https://github.com/microsoft/vscode/issues/241973)

## Summary

The experimental badge infrastructure is now in place (settings editor supports `@tag:experimental` filtering and badge display), but many settings with 'experimental' in their name or description still lack the `tags: ["experimental"]` annotation — the inconsistency reported here remains on current main.

## Change summary

Settings that are experimental lack the `experimental` tag annotation, leading to inconsistent badge display in the Settings UI.

## Best solution

Audit all settings with 'experimental' in their name or description and add `tags: ["experimental"]` to their registration so the settings editor badge renders consistently. PR #242990 attempted this but was closed without merge — its approach (adding tags to individual settings) is the right one.
