# Issue #281996 — markdown-it plugins do not work in walkthrough content

[https://github.com/microsoft/vscode/issues/281996](https://github.com/microsoft/vscode/issues/281996)

## Summary

Walkthrough content intentionally uses its own marked-based renderer (src/vs/workbench/contrib/markdown/browser/markdownDocumentRenderer.ts) that is separate from the Markdown Preview's extensible markdown-it pipeline. Extension-contributed markdown-it plugins do not apply here by design.

## Change summary

markdown-it plugins contributed via `extendMarkdownIt` are not invoked when rendering walkthrough markdown content.

## Best solution

Close as by-design. The walkthrough renderer uses a sandboxed `marked`-based pipeline for security and consistency; the `extendMarkdownIt` contribution point is exclusive to the Markdown Preview extension. If custom rendering in walkthroughs is desired, that would be a new feature request for a separate extension point.
