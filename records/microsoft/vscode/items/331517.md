# Issue #331517 — Automations should not rename themselves

[https://github.com/microsoft/vscode/issues/331517](https://github.com/microsoft/vscode/issues/331517)

## Summary

Keep open: Automations now execute in Agent Host, but their provenance still does not exclude them from automatic session naming, and history rows display the mutable session title. The team-authored report remains actionable; no verified canonical duplicate or explicitly linked fixing commit was found.

## Change summary

Keep automation runs recognizable instead of allowing automatic session naming to replace their automation identity.

## Best solution

Ensure each run retains a visible, stable association with its automation. Settle whether that means preserving the automation name as the session title or displaying automation identity separately from an independently generated run title.
