# Issue #263279 — Agent Mode: Disable tools by default besides core tools

[https://github.com/microsoft/vscode/issues/263279](https://github.com/microsoft/vscode/issues/263279)

## Summary

Keep open: saved tool selections and tool-search deferral partially address the workflow, but newly discovered tools still default to enabled. This team-authored Backlog request remains the consolidation point, with an unresolved product decision about opt-in defaults versus existing MCP setup expectations.

## Change summary

Allow a core-tools-only default, provide an easy way to select it, and show how many tools are enabled.

## Best solution

Define a discoverable core-tools-only preference that handles newly discovered extension and MCP tools consistently, while preserving explicit selections and custom-agent tool lists. Settle its default and scope with the area owner; reuse existing enabled-tool counts rather than introducing a competing count.

## Evidence

- **Current default remains permissive:** src/vs/workbench/contrib/chat/browser/widget/input/chatSelectedTools.ts: ChatSelectedTools.entriesMap enables an individual tool when currentMap.tools.get(tool.id) !== false and a tool set when currentMap.toolSets.get(toolSet.id) !== false. Unknown tools and tool sets therefore remain enabled; saved deselections do not establish a core-only default for future additions.
