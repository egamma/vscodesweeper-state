# Issue #102091 — Better API to associate a notebook cell document with its notebook

[https://github.com/microsoft/vscode/issues/102091](https://github.com/microsoft/vscode/issues/102091)

## Summary

A real API ergonomics gap remains: extensions can find the containing notebook by scanning cells, but current main still lacks the proposed direct lookup utility. Keep this open for an explicit notebook API design decision.

## Change summary

Provide an efficient API that maps a notebook cell's TextDocument back to its NotebookCell or NotebookDocument.

## Best solution

Decide in the notebook API finalization work whether to add a utility such as `notebooks.getNotebookCell(TextDocument)`. If the existing scan is intentionally the permanent API, document that decision and close as designed; otherwise implement the lookup without restoring the rejected `TextDocument.notebook` reference.
