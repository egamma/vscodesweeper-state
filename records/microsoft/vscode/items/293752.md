# Issue #293752 — Allow pre-loading skills for custom agents

[https://github.com/microsoft/vscode/issues/293752](https://github.com/microsoft/vscode/issues/293752)

## Summary

Valid feature request — VS Code's custom agent prompt header supports `tools` and `agents` but not `skills` pre-loading. Claude Code agents already have a `skills` attribute in their header schema (`claudeAgentAttributes`), but VS Code's `customAgentAttributes` lacks it. The request to add parity is well-supported and already on the On Deck milestone.

## Change summary

Allow custom agent definitions (.prompt.md) to specify skills that are pre-loaded into the agent's context at startup, rather than relying on dynamic skill discovery.

## Best solution

Add a `skills` header attribute to `customAgentAttributes` in `src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptFileAttributes.ts` (parity with `claudeAgentAttributes`), and wire the agent prompt resolution in `computeAutomaticInstructions.ts` to inject the named skills into the agent's system prompt. The 'load skill tool' (commit da39f2813c2) and the existing skill infrastructure already provide the building blocks.
