# Issue #209613 — Nested multi-workspaces

[https://github.com/microsoft/vscode/issues/209613](https://github.com/microsoft/vscode/issues/209613)

## Summary

This remains a valid Backlog request with 59 community upvotes. Although the hierarchical Explorer presentation overlaps with an older open request, automatic subproject discovery and nested workspace configuration remain distinct gaps.

## Change summary

Represent monorepo subprojects as automatically detected nested workspaces without duplicating them as top-level Explorer roots.

## Best solution

Design a nested workspace model in the workspaces and Explorer areas that preserves the physical hierarchy while allowing subprojects to contribute workspace-scoped configuration and tasks. Coordinate its hierarchical presentation with https://github.com/microsoft/vscode/issues/76904 rather than treating that narrower request as covering automatic discovery and sub-workspace semantics.
