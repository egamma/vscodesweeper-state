# Issue #343027 — Copilot runtime requests gh credentials for a Forgejo remote, triggering GNOME keyring dialogs

[https://github.com/microsoft/vscode/issues/343027](https://github.com/microsoft/vscode/issues/343027)

## Summary

Keep open for investigation of unnecessary credential discovery during Copilot initialization. Current main delegates execution to a packaged runtime, so source inspection cannot confirm the reported keyring interaction; the supplied steps and process traces suffice to retest without requesting more basic information.

## Change summary

Submitting a Copilot Chat message in a Forgejo repository launches GitHub CLI credential lookup for the Forgejo hostname and prompts to unlock an unrelated GNOME keyring.

## Best solution

Ensure repository initialization distinguishes non-GitHub remotes before attempting GitHub credential discovery, while preserving configured GitHub Enterprise authentication. Establish whether the incorrect host selection originates in the bundled runtime or its VS Code integration, and address that boundary without requiring users to unlock unrelated keyrings.
