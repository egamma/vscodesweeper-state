# Issue #115519 — Guide users to 'extension bisect' from the issue reporter dialog

[https://github.com/microsoft/vscode/issues/115519](https://github.com/microsoft/vscode/issues/115519)

## Summary

Keep open: Extension Bisect exists, but the inspected issue reporter surfaces do not guide users to start it when they cannot identify the responsible extension. This team-authored Backlog request remains actionable; no qualifying fix or older canonical was found.

## Change summary

Offer discoverable guidance and an action to start Extension Bisect from the issue reporter's extension-reporting flow.

## Best solution

Make extension isolation discoverable where the issue reporter asks users to identify an extension, reusing the existing Extension Bisect capability. Account for both the legacy reporter and the newer wizard without requiring users to know the command beforehand.
