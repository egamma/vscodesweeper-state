# Issue #345119 — Allow inlay hint providers to opt out of temporary truncation while typing

[https://github.com/microsoft/vscode/issues/345119](https://github.com/microsoft/vscode/issues/345119)

## Summary

The requested provider opt-out is missing: current source deliberately stabilizes hint lengths while typing, independently of maximumLength. Keep this open as an extension-API feature request; no verified canonical covers that capability.

## Change summary

Allow selected inlay hints to retain their complete labels during typing without changing default cursor-stability behavior.

## Best solution

Have editor/API owners assess an explicit opt-out from temporary hint-length stabilization, preserving existing defaults and the independent maximumLength setting. Keep broader virtual-text styling and decoration wrapping outside this request.
