# Issue #99155 — Problems view do not show markers when Show Active File filter is on

[https://github.com/microsoft/vscode/issues/99155](https://github.com/microsoft/vscode/issues/99155)

## Summary

This remains the canonical request for making the Problems view's Active File Only filter understand notebook cell resources. Current main still compares the notebook editor URI directly with marker resources, so cell diagnostics are excluded.

## Change summary

Show diagnostics from notebook cells when the Problems view is filtered to the active notebook.

## Best solution

Teach the Problems view to associate `vscode-notebook-cell` marker URIs with their containing notebook URI when applying Active File Only, with coverage for both tree and table modes.
