# Issue #99155 — Problems view do not show markers when Show Active File filter is on

[https://github.com/microsoft/vscode/issues/99155](https://github.com/microsoft/vscode/issues/99155)

## Summary

Keep open: the existing active-file filter still does not associate notebook-cell diagnostics with their containing notebook. This team-authored, accepted notebook-integration request remains necessary, and the related notebook report was explicitly consolidated here.

## Change summary

Make Show Active File Only include diagnostics from cells belonging to the active notebook.

## Best solution

Extend the Problems view's active-resource matching to recognize the containing notebook of cell diagnostics, while preserving their original cell resources for navigation and leaving ordinary-file filtering unchanged.
