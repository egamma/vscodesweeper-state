# Issue #41985 — Support reading/writing chunks in remote fs

[https://github.com/microsoft/vscode/issues/41985](https://github.com/microsoft/vscode/issues/41985)

## Summary

A real API gap remains: chunked provider operations exist only behind the proposed `fsChunks` API, so remote file-system extensions cannot rely on a stable API. The related streaming request covers a distinct consumer-side capability.

## Change summary

Expose stable chunked open, read, write, and close operations for remote file-system providers.

## Best solution

Resolve the remaining API design questions, then finalize `fsChunks` with explicit open modes and lifecycle semantics while preserving efficient transport through the extension-host bridge. Coordinate with the separate stream/consumer API tracked at https://github.com/microsoft/vscode/issues/84515.
