# Issue #336538 — Harness picker should not show the remote agent host name

## Summary

Freshly filed, well-diagnosed UX redundancy: the code confirms the harness (session type) label for remote agent hosts intentionally appends the host name, which duplicates the disambiguation already provided by the picker's section headers/workspace picker. Worth keeping open for a maintainer decision on how to trim the redundancy without losing multi-host disambiguation.

## Change summary

The harness/session-type picker shows the remote agent host name appended to each option (e.g. "Copilot [host]"), duplicating context already shown by the workspace picker.
