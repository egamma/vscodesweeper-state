# Issue #47559 — Expose `glyphMargin` support to extensions

[https://github.com/microsoft/vscode/issues/47559](https://github.com/microsoft/vscode/issues/47559)

## Summary

The requested extension-controlled gutter click interaction remains missing, but an open issue now explicitly tracks that same capability and the overlapping-icon concerns. Consolidate this request there rather than treating existing icon rendering or right-click menus as a completed implementation.

## Change summary

Allow extensions to attach click actions to their glyph-margin decorations.

## Best solution

Consolidate the remaining extension API work in https://github.com/microsoft/vscode/issues/224134, preserving this thread's bookmark-click use case and maintainer concern about competing decorations.

## Evidence

- **Shared interaction and collision scope:** The canonical's discussion addresses breakpoint coexistence, multiple competing icons, and gutter-action presentation: https://github.com/microsoft/vscode/issues/224134#issuecomment-2603302375. These include the rendering and interaction conflict raised by alexdima in this issue, while this thread additionally supplies the bookmark-click use case.
- **Existing capability is only partial:** src/vscode-dts/vscode.d.ts exposes DecorationRenderOptions.gutterIconPath and gutterIconSize for rendering icons. src/vs/workbench/services/actions/common/menusExtensionPoint.ts registers editor/lineNumber/context; EditorLineNumberContextMenu.doShow in src/vs/workbench/contrib/codeEditor/browser/editorLineNumberMenu.ts normally requires right-click or macOS Ctrl-click. These capabilities do not expose a direct left-click action on an extension's decoration.
- **Closed related issues do not establish completion:** https://github.com/microsoft/vscode/issues/114776 concerns internal GlyphWidgets and overlapping decorations, not completion of the extension click API. https://github.com/microsoft/vscode/issues/5455 was closed following adoption of the line-number context menu, but subsequent discussion explicitly distinguishes direct icon clicks from that menu: https://github.com/microsoft/vscode/issues/5455#issuecomment-1843821658.
