# Issue #302074 — my chats are visible to another user

[https://github.com/microsoft/vscode/issues/302074](https://github.com/microsoft/vscode/issues/302074)

## Summary

This is a support question about multi-user isolation on a shared AWS instance. Chat sessions are stored per-workspace in the OS user's data directory — two people sharing the same OS account and workspace will see each other's sessions by design. The fix is to use separate OS user accounts or separate VS Code profiles.

## Change summary

Two users on the same AWS instance sharing an OS account can see each other's Copilot chat sessions in the sessions tab.

## Best solution

Use separate OS user accounts on the AWS instance, or use separate VS Code profiles (File > Preferences > Profiles) so each user gets isolated storage. This is an environment configuration concern, not a VS Code defect.

  > Thanks for the report. VS Code stores chat sessions in the OS user's data directory, keyed by workspace. When two people share the same OS user account on a remote instance and open the same repository, they share the same storage — so each will see the other's chat sessions.
  > 
  > To get isolation, you have two options:
  > 1. **Use separate OS user accounts** on the AWS instance — each user gets their own VS Code data directory.
  > 2. **Use separate VS Code profiles** (File → Preferences → Profiles → Create Profile) — each profile has its own storage.
  > 
  > This is working as designed for the storage model, so I'm closing this as a support question. Please reopen or file a new issue if you believe there's a deeper problem after trying separate accounts/profiles.
