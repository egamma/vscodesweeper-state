# Issue #326603 — Copilot Agent Mode can stream stale previous-task response under a new user turn after cancel/resend

[https://github.com/microsoft/vscode/issues/326603](https://github.com/microsoft/vscode/issues/326603)

## Summary

The logged cancellation race was valid, but it is now fixed on main: stale actions retain their original turn identity and are dropped instead of being remapped into the replacement turn.

## Change summary

Prevent a cancelled Copilot CLI turn's late response from appearing under a newly submitted user turn.

## Best solution

Keep the turn-identity filtering merged in commit 7e2c92ba29411be5dfe7ef8526846f5193e881a1; its regression test directly covers stale response content arriving after cancellation and replacement-turn startup.
