# Issue #326603 — Copilot Agent Mode can stream stale previous-task response under a new user turn after cancel/resend

[https://github.com/microsoft/vscode/issues/326603](https://github.com/microsoft/vscode/issues/326603)

## Summary

The supplied AHP logs confirm the original cancellation/resend desynchronization, and it was subsequently fixed by preserving producer turn IDs and dropping stale actions instead of rewriting them onto the replacement turn.

## Change summary

Prevent output from a cancelled Copilot Agent Host turn from being streamed under a newly started user turn.

## Best solution

Keep the turn-identity filtering implemented in commit 7e2c92ba29411be5dfe7ef8526846f5193e881a1; stale response parts, usage, tool events, and completions from a cancelled turn must never mutate its replacement turn.
