# Issue #319905 — Please add menu to resize font size (zoom in/out) to new Copilot Agents window

[https://github.com/microsoft/vscode/issues/319905](https://github.com/microsoft/vscode/issues/319905)

## Summary

The Agents Window supports zoom, but its default Windows custom-titlebar layout still lacks a mouse-accessible zoom menu. Existing commands and settings are workarounds, and the verified related issues do not qualify as duplicate canonicals for this request.

## Change summary

Expose mouse-accessible Zoom In, Zoom Out, and Reset Zoom controls in the Agents Window.

## Best solution

Provide discoverable window-zoom menu controls in the Agents Window using the existing zoom commands and preserving their current window.zoomPerWindow semantics. This does not require independent panel zoom or a new font-scaling system.
