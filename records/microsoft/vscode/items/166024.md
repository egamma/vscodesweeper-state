# Issue #166024 — Cursor selection scroll down not working when status bar is hidden and in full screen mode

[https://github.com/microsoft/vscode/issues/166024](https://github.com/microsoft/vscode/issues/166024)

## Summary

Still reproduces on main: the OUTSIDE_EDITOR 'below' detection in _getPositionOutsideEditor requires the mouse Y to exceed the editor's bottom boundary, but in macOS fullscreen with hidden status bar, the editor fills the entire screen so the mouse can never go past it — auto-scroll during selection never triggers.

## Change summary

Drag-to-select text downward does not auto-scroll when the status bar is hidden and VS Code is in macOS full screen mode.

## Best solution

Add a margin/threshold near the editor bottom edge (e.g. last ~10px) that triggers the 'below' outside-editor detection even when the mouse can't physically leave the editor bounds, similar to how some apps handle screen-edge drag-scroll. The fix belongs in `src/vs/editor/browser/controller/mouseHandler.ts` in `_getPositionOutsideEditor`.
