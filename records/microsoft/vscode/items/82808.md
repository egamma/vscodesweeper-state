# Issue #82808 — Minimap: Render overview ruler decorations (for extension support)

[https://github.com/microsoft/vscode/issues/82808](https://github.com/microsoft/vscode/issues/82808)

## Summary

A real extension API gap remains on current main, and this Backlog request has 54 community upvotes. It should remain the canonical issue for extension-provided minimap decorations.

## Change summary

Allow extensions to render editor decorations in the minimap, analogous to overview-ruler decorations.

## Best solution

Expose minimap decoration options through `vscode.DecorationRenderOptions` and translate them in the extension-host API converter to the editor's existing `IModelDecorationMinimapOptions` rendering path.

- **Reason:** A small core API addition would let extensions provide specialized minimap integrations without adding those features to the default product.
