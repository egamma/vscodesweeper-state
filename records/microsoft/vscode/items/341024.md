# Issue #341024 — Feature request for `sessions.experimental.layoutScope`: Add option to remember bottom pane state as well, not just visibility

[https://github.com/microsoft/vscode/issues/341024](https://github.com/microsoft/vscode/issues/341024)

## Summary

Thanks for the feedback. In `chat` mode the bottom panel's visibility and selected view (for example Terminal vs Problems) are already remembered per chat. Which terminal instance is selected inside the Terminal view is not, and the layout docs say terminal behavior is deliberately independent of this setting. This is a fresh, zero-upvote request from testing an experimental feature, so it stays open for the feature owners to decide.

## Change summary

Remember the selected terminal in the bottom pane per chat when `sessions.experimental.layoutScope` is `chat`.

## Best solution

The feature owners decide whether per-chat terminal selection belongs in the experiment. If it does, that is a terminal-projection change in `SessionsTerminalContribution` rather than in the layout controller, and it would need the terminal-boundary section of `LAYOUT_CONTROLLER.md` revised.
