# Issue #341024 — Feature request for `sessions.experimental.layoutScope`: Add option to remember bottom pane state as well, not just visibility

[https://github.com/microsoft/vscode/issues/341024](https://github.com/microsoft/vscode/issues/341024)

## Summary

Keep open: chat-scoped layout remembers the selected bottom-panel view, but not the selected terminal instance requested here. Current configuration and architecture explicitly leave terminal behavior unchanged; that establishes a remaining feature gap, not grounds to decline this accepted Backlog request.

## Change summary

Remember and restore the last selected terminal separately for each chat when switching between chats in the Agents Window.

## Best solution

Define an opt-in per-chat terminal-selection memory in the Agents Window terminal contribution, coordinated with layout scope. Restoring a selection should preserve existing terminal sharing, backend matching, task reuse, and process lifecycle rather than require separate terminal ownership.
