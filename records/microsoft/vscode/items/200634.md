# Issue #200634 — Question mark disappears when the next colon is highlighted in high contrast themes

[https://github.com/microsoft/vscode/issues/200634](https://github.com/microsoft/vscode/issues/200634)

## Summary

This is a niche visual bug with a specific third-party font (JetBrains Mono) in high contrast themes, filed against VS Code 1.85. The report is nearly three years old with no confirmation from others; requesting the reporter verify on current builds before further investigation.

## Change summary

Question mark glyph in a `?:` ligature disappears when the colon portion is selected/highlighted in high contrast themes with JetBrains Mono font.

## Best solution

Request reproduction on current Insiders. If still reproducible, the root cause is likely in how the editor renders partial selections across ligature boundaries — the high contrast theme's distinct selection foreground color forces the browser to break the ligature glyph, and the non-selected half may not render correctly. The fix would be in the view line renderer's token splitting or decoration logic around ligature-aware spans.
