# Issue #117106 — Advanced wrapping strategy causes hangs for larger files

[https://github.com/microsoft/vscode/issues/117106](https://github.com/microsoft/vscode/issues/117106)

## Summary

The advanced wrapping strategy's large-file performance penalty is documented and intentional, but the reporter's refined ask — automatically falling back to `simple` for large files (similar to how tokenization is disabled) — is a real, unimplemented improvement. Current `largeFileOptimizations` skips tokenization for large files but does not guard the wrapping strategy. This stays open as a valid enhancement request.

## Change summary

When `editor.wrappingStrategy` is set to `advanced`, opening a large file causes a UI freeze because the DOM-based line-breaks computer runs on every line without a size guard.

## Best solution

Extend the existing `largeFileOptimizations` path (or `wrappingStrategy` resolution in `viewModelLines.ts`) to automatically fall back from `advanced` to `simple` when the file exceeds the large-file thresholds, similar to how tokenization is disabled. Show a notification so users understand the degradation. The guard belongs in `ViewModelLinesFromProjectedModel.createLineBreaksComputer` (around line 308–313 of `src/vs/editor/common/viewModel/viewModelLines.ts`).
