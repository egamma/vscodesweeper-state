Thanks for the report. The steps are concrete (remote agent host, merge a PR from a worktree session, start a new session on main, no Sync button until a manual git fetch). I couldn't confirm the missing fetch without running it, and the exact sync trigger on session start wasn't traced. Keeping open for a maintainer to retest with these steps.

## Change summary

A new Agents window session on main doesn't fetch from the remote on a remote agent host, so the Sync button doesn't appear until the user runs git fetch manually.

## Best solution

Make new-session creation (or the session's git state refresh) fetch from the remote on the agent host so the Sync/pull state reflects the merged PR. Check the fetch call in src/vs/platform/agentHost/node/agentHostGitService.ts and where it is invoked.
