# Issue #305919 — Vscode closing and switching workspace is slow

[https://github.com/microsoft/vscode/issues/305919](https://github.com/microsoft/vscode/issues/305919)

## Summary

This is the same extension-host shutdown regression reported in #305240, caused by a lifecycle refactoring that inadvertently blocked the UI on graceful extension-host shutdown. The fix (PR #304249) shipped in 1.114.0 — the reporter was on 1.113.0, the affected version.

## Change summary

Closing or switching workspaces in VS Code 1.113.0 shows a blocking "Stopping Extension Hosts" dialog, making the operation slow.

## Best solution

No further change needed — the fix in commit 0edbe88dcdf11bdb8778839b6fc9e80665ff417a (1.114.0) stopped blocking the window reload on extension-host graceful shutdown. Updating to 1.114+ resolves the issue.
