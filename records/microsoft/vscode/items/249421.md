# Issue #249421 — Git - Show a rich hover over the branch picker

[https://github.com/microsoft/vscode/issues/249421](https://github.com/microsoft/vscode/issues/249421)

## Summary

The branch picker still has a plain-text tooltip, so the rich-hover request remains unmet. An older issue covers copying the branch name, but does not own the broader commit and PR context proposed here.

## Change summary

Provide an interactive branch-picker hover for quickly copying the branch name and potentially viewing associated commit or PR information.

## Best solution

Design a lightweight branch hover with a discoverable copy action, coordinating that action with https://github.com/microsoft/vscode/issues/148069. Decide whether commit and PR information belongs in the initial scope, and account for the string-only SCM command-tooltip contract.
