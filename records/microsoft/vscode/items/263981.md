# Issue #263981 — Generate Tests action: The instructions.file is ignored 

[https://github.com/microsoft/vscode/issues/263981](https://github.com/microsoft/vscode/issues/263981)

## Summary

Likely still reproduces: the Generate Tests code lens action may not be passing the source file URI into the references that the AutomaticInstructionsCollector uses to match applyTo patterns in .instructions.md files. A similar bug was previously fixed for Code Review (commit d78d641547c) but no equivalent fix landed for the test generation path.

## Change summary

When using the Generate Tests action on a .cs file, .github/instructions/*.instructions.md files with matching applyTo patterns are ignored — the generated test disregards user-specified framework preferences.

## Best solution

Ensure the test generation intent passes the active source file URI as a reference into the AutomaticInstructionsCollector context, so that applyTo glob matching in .instructions.md files works correctly. The fix likely belongs in `extensions/copilot/src/extension/intents/node/testIntent/testFromSrcInvocation.tsx` or in the upstream request lifecycle that populates chatVariables before the intent's buildPrompt runs.
