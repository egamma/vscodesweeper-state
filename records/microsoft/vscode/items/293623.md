# Issue #293623 — Add copilot shortcut icon for the full screen users

[https://github.com/microsoft/vscode/issues/293623](https://github.com/microsoft/vscode/issues/293623)

## Summary

The requested fullscreen fallback remains absent on current main: Chat is exposed through the window title bar and a keyboard shortcut, but not through the editor-title toolbar that remains visible when `window.customTitleBarVisibility` is `windowed`. With no community or maintainer traction, this should remain open under discussion rather than enter implementation.

## Change summary

Show an Open Chat icon in the editor-title actions while fullscreen mode hides the custom title bar.

## Best solution

Decide whether the editor-title toolbar should provide a context-aware Open Chat fallback when the custom title bar is hidden, without duplicating the icon when the normal title-bar entry is visible. Any icon-only action should remain gated by Chat enablement and have a localized accessible label.
