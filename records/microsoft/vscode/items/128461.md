# Issue #128461 — Font size for the extra info in suggestion list became smaller and can't be changed, causing problems with some fonts

[https://github.com/microsoft/vscode/issues/128461](https://github.com/microsoft/vscode/issues/128461)

## Summary

Keep open under discussion: suggestion qualifiers and details still use a fixed smaller font ratio, with no independent sizing control. The existing suggestion font setting does not cover the request to preserve readable metadata without enlarging the whole list.

## Change summary

Allow suggestion-list metadata to remain readable with bitmap-derived fonts instead of forcing it to a smaller size than completion labels.

## Best solution

Have the suggest-area owner decide how secondary completion text can retain a usable font size while preserving the list's visual hierarchy. Address this within the editor suggestion widget rather than requiring unsupported modifications to application CSS.
