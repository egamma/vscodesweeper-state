# Issue #128461 — Font size for the extra info in suggestion list became smaller and can't be changed, causing problems with some fonts

[https://github.com/microsoft/vscode/issues/128461](https://github.com/microsoft/vscode/issues/128461)

## Summary

Still present on main: the suggest widget's qualifier-label and details-label use a hardcoded `font-size: 85%` that cannot be customized, making bitmap fonts illegible in those positions. The existing `editor.suggestFontSize` setting controls the base size but not this relative reduction. Keeping open as a polish item.

## Change summary

The qualifier and details labels in the suggest widget use a hardcoded 85% font-size relative to the suggest widget font, with no setting to override it.

## Best solution

Either remove the 85% reduction so these labels match the suggest widget font size, or expose a setting (or respect `editor.suggestFontSize` at 100% for these sub-elements). The fix is in `src/vs/editor/contrib/suggest/browser/media/suggest.css` lines 201 and 211, and the workbench counterpart at `src/vs/workbench/services/suggest/browser/media/suggest.css` lines 249 and 259.
