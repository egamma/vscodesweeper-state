# Issue #224233 — Installation error when home directory is read-only

[https://github.com/microsoft/vscode/issues/224233](https://github.com/microsoft/vscode/issues/224233)

## Summary

The `/home/root/.cache` directory is not created by the VS Code server code in this repository — the server's own `cacheHome` resolves to the `user-data-dir` under `REMOTE_DATA_FOLDER`, not `~/.cache`. The error originates from the Remote SSH extension's bootstrap or a system-level dependency during server setup. Since Remote SSH (`ms-vscode-remote.remote-ssh`) is a Microsoft-owned extension with its own tracker, this should be moved to `microsoft/vscode-remote-release`.

## Change summary

VS Code Remote SSH server startup emits an ENOENT error trying to create `/home/root/.cache` on systems with a read-only home directory, even when `remote.SSH.serverInstallPath` points elsewhere.

## Best solution

Move this issue to the `microsoft/vscode-remote-release` tracker where the Remote SSH team can evaluate whether the bootstrap script or server launch wrapper should respect `serverInstallPath` (or `XDG_CACHE_HOME`) for cache directory creation instead of defaulting to `$HOME/.cache`.
