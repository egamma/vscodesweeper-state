# Issue #224233 — Installation error when home directory is read-only

[https://github.com/microsoft/vscode/issues/224233](https://github.com/microsoft/vscode/issues/224233)

## Summary

The detailed server log confirms that Remote - SSH attempts to create `$HOME/.cache` despite installation being redirected to a writable path. This belongs with the VS Code-owned Remote Development extension and should be transferred rather than closed.

## Change summary

Avoid a Remote - SSH server startup error when the remote home directory is read-only and `remote.SSH.serverInstallPath` points to writable storage.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release and determine whether Remote - SSH should configure a writable cache location derived from the server installation path, while preserving the existing behavior for normal writable home directories.
