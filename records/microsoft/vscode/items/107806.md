# Issue #107806 — New search results cleared after search-and-replace operation finishes

[https://github.com/microsoft/vscode/issues/107806](https://github.com/microsoft/vscode/issues/107806)

## Summary

The race remains in current source: completing Replace All unconditionally clears the shared search results, even if a newer search has populated them. Keep this with the search area; the maintainer already suggested preventing searches during replacement.

## Change summary

A new workspace search loses its results when an earlier bulk replacement finishes saving files.

## Best solution

Make bulk replacement and subsequent searches coordinate so replacement completion cannot clear a newer query's results or overwrite its status. Settle whether searches should be blocked, deferred, or permitted during replacement, following the maintainer's suggested direction.
