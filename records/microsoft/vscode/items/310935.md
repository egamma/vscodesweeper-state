# Issue #310935 — Inability to select xHigh reasoning level for some models when the Session Target is set to Copilot CLI

[https://github.com/microsoft/vscode/issues/310935](https://github.com/microsoft/vscode/issues/310935)

## Summary

Keep open as an upstream Copilot CLI model-capability issue. Current VS Code source renders the reasoning efforts advertised by the Copilot runtime, while the discussion confirms the same tier-dependent omission occurs in the standalone CLI.

## Change summary

Copilot CLI sessions omit Extra High reasoning for models and account tiers where local VS Code sessions offer it.

## Best solution

The Copilot CLI runtime should advertise the authoritative reasoning-effort set for each model and entitlement tier; VS Code should continue projecting that schema and verify that affected models expose Extra High once the upstream metadata is corrected.
