# Issue #291992 — Enable users passing in custom system prompt for CAPI/BYOK models

[https://github.com/microsoft/vscode/issues/291992](https://github.com/microsoft/vscode/issues/291992)

## Summary

Current main supports system-prompt replacement through advanced debugging settings, but those overrides are global rather than model-specific. Keep this request open for the remaining model-scoped evaluation workflow; no verified older canonical owns that capability.

## Change summary

Allow users to configure custom system prompts for individual CAPI/BYOK models without editing extension source.

## Best solution

Provide model-scoped prompt overrides for evaluation workflows while retaining the existing default prompts for unmatched models. Decide the model-selection contract and its precedence over existing global debug overrides before implementation.
