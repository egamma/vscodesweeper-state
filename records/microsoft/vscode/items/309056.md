# Issue #309056 — MCP client: Extension host crashes when authenticating with /common authority on multi-account/multi-tenants machines (tag_7cisv)

[https://github.com/microsoft/vscode/issues/309056](https://github.com/microsoft/vscode/issues/309056)

## Summary

Keep open for the MSAL/WAM investigation: disabling the native broker resolves the reported crash, but does not resolve broker-backed authentication. Neither a concrete fix nor an older canonical covering the same extension-host crash was verified.

## Change summary

MCP authentication through the /common authority terminates the extension host on Windows machines with mixed personal and work accounts and multiple tenants.

## Best solution

Resolve the native MSAL/WAM failure while preserving /common account selection, token caching, and broker-backed Windows authentication. Retain the browser-based workaround as an opt-out, not as completion of the broker defect.
