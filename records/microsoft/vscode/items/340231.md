# Issue #340231 — Copilot Agent Host does not surface MCP progress notifications shown by Local Harness

[https://github.com/microsoft/vscode/issues/340231](https://github.com/microsoft/vscode/issues/340231)

## Summary

Thanks for the detailed report. This is a real gap: a search of the Agent Host platform and agent-session code found no handling of MCP progress tokens or progress notifications. The work also depends on an Agent Host Protocol (AHP) representation for running-tool progress, which is still being designed in the AHP repo. It stays open and should be routed to the agent-host owners.

## Change summary

Surface MCP notifications/progress messages on the running tool row in the Copilot Agent Host harness, as the Local harness does.

## Best solution

Land the AHP running-tool progress carrier (https://github.com/microsoft/agent-host-protocol/pull/405 or its replacement). Then map progress events from the Copilot SDK/runtime MCP client to the running tool call in the agent host adapter and render the latest message in the tool row, with an end-to-end test that emits several progress messages before a successful result.
