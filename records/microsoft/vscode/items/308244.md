# Issue #308244 — New 2026 color scheme: Hard to see enabled/disabled state of search mode buttons in text search bars

[https://github.com/microsoft/vscode/issues/308244](https://github.com/microsoft/vscode/issues/308244)

## Summary

This should stay open and be routed: the affected search option buttons use the 2026 theme `inputOption.active*` colors, and those colors are still present on current main. The report is a narrow visual contrast problem in the new built-in themes rather than a closeable support or duplicate issue from the provided context.

## Change summary

The Dark 2026 and Light 2026 themes make enabled search option buttons hard to distinguish from disabled/inactive states in text search inputs.

## Best solution

Have the Themes/Search owners adjust the 2026 theme `inputOption.activeBackground`, `inputOption.activeForeground`, or `inputOption.activeBorder` values so enabled find/search toggles have a clearer visual state without changing the shared toggle behavior.
