# Issue #335171 — Workspace should not need to be "trusted" to create a terminal

[https://github.com/microsoft/vscode/issues/335171](https://github.com/microsoft/vscode/issues/335171)

## Summary

Requiring workspace trust before creating a terminal is intentional, documented Workspace Trust behavior, and VS Code already ships a dedicated setting (`terminal.integrated.allowInUntrustedWorkspace`) to opt out — this is as-designed, not a bug.

## Change summary

Requester wants VS Code to allow creating a terminal in untrusted workspaces without prompting for trust, arguing a shell/terminal poses no special risk.

## Best solution

Point the reporter to the existing `terminal.integrated.allowInUntrustedWorkspace` setting (implemented in src/vs/workbench/contrib/terminal/browser/terminalInstance.ts `_trust()`) and the Workspace Trust docs already linked in the thread; close as as-designed since the requested override already exists.
