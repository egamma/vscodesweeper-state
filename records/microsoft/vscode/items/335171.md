# Issue #335171 — Workspace should not need to be "trusted" to create a terminal

[https://github.com/microsoft/vscode/issues/335171](https://github.com/microsoft/vscode/issues/335171)

## Summary

The terminal trust prompt is intentional and already has an explicit opt-out, but the reporter additionally requests changing the security boundary and clarifying the dialog. Keep this security-sensitive request open for human review rather than proposing a judgment close.

## Change summary

Allow terminals in untrusted workspaces by default and clarify whether the trust warning concerns shell behavior or VS Code executing workspace code.

## Best solution

Have the terminal and workspace-trust owners assess the requested threat-model change and clarify the prompt's shell-startup rationale. Preserve the existing security default unless that review explicitly approves changing it; the current opt-out already supports users whose shells do not automatically execute workspace content.
