# Issue #342719 — Plugins page toggle says Include/Exclude from Profile instead of Enable/Disable or Install/Uninstall

[https://github.com/microsoft/vscode/issues/342719](https://github.com/microsoft/vscode/issues/342719)

## Summary

Keep open: current source still uses Include/Exclude wording for plugin enablement, while installation controls exist but do not fully address the reported discoverability and Team-assigned opt-out concerns. This collaborator-authored report needs a UX decision, not a judgment close.

## Change summary

Make plugin enablement and installation controls clearly distinguish disabling a plugin from uninstalling it, including Team-assigned plugins.

## Best solution

Use clear, scope-aware enable/disable language consistently across plugin controls and accessible descriptions, with discoverable installation actions appropriate to the plugin's ownership. Establish the Team-assigned opt-out contract before treating a profile enablement toggle as equivalent to uninstalling.
