# Issue #320168 — Frequent update popups

[https://github.com/microsoft/vscode/issues/320168](https://github.com/microsoft/vscode/issues/320168)

## Summary

Keep this accepted request open: existing update modes do not establish a solution for repeated macOS administrator prompts while retaining automatic updates. The later managed-policy report adds a distinct scenario worth reproducing, and neither verified related issue covers the full request.

## Change summary

Reduce repeated update-related administrator prompts on managed Macs without requiring users to abandon automatic updates.

## Best solution

Provide a less disruptive authorization-retry experience for users without administrator credentials, while retaining automatic updates where permitted. Separately verify that an effective UpdateMode=none policy prevents update-helper initialization and prompts.
