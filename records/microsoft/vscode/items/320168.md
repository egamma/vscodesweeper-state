# Issue #320168 — Frequent update popups

[https://github.com/microsoft/vscode/issues/320168](https://github.com/microsoft/vscode/issues/320168)

## Summary

Valid feature request already promoted to Backlog: when UpdateMode policy is set to none, VS Code should suppress the macOS helper-installation prompt entirely, not just disable the update check loop. The current code disables update scheduling but the Electron/Squirrel helper prompt may still surface.

## Change summary

When update.mode is set to 'none' via MDM policy on macOS, VS Code still prompts to install the Squirrel auto-update helper, which is disruptive in managed enterprise environments.

## Best solution

Ensure the macOS update service (DarwinUpdateService) skips Electron autoUpdater initialization entirely — including setFeedURL and any helper registration — when the UpdateMode policy resolves to 'none' at startup. The fix belongs in src/vs/platform/update/electron-main/updateService.darwin.ts, gating Electron autoUpdater setup behind the mode check.
