# Issue #340687 — Insiders update regression: Local harness missing and older chat sessions disappear when opened

[https://github.com/microsoft/vscode/issues/340687](https://github.com/microsoft/vscode/issues/340687)

## Summary

Thanks for the detailed report. Local harness availability changed between two Insiders builds, and a rollback restores it. A comment from a team member points at managed settings (`vscode.temporaryDefaultToLocalHarness`) as a likely cause. I did not trace the code here, so I could not confirm that cause or the separate disappearing-sessions symptom. The report has enough detail to retest.

## Change summary

After updating Insiders, the Local harness is missing from the picker and older chat sessions vanish from the list when opened.

## Best solution

Restore Local harness availability for enterprise-managed accounts that did not opt out. Separately, make a failed restore of an older session show an actionable error instead of silently dropping the session and its history. Coordinate with the related harness-picker and session-deletion issues.
