# Issue #340687 — Insiders update regression: Local harness missing and older chat sessions disappear when opened

[https://github.com/microsoft/vscode/issues/340687](https://github.com/microsoft/vscode/issues/340687)

## Summary

Thanks for the detailed report and the rollback test. The Local harness disappears on the newer Insiders build and returns on the previous one, so this looks like a real regression. It likely overlaps with the existing Local-harness reports, and the older-session behavior may be a separate problem. Keeping it open and routing it to the chat area.

## Change summary

After updating to Insiders ed380adf, the Local harness is missing from the picker and older chat sessions disappear when opened.

## Best solution

Find the commit between ddcb6c27 and ed380adf that hides Local (possibly the enterprise-policy harness changes). Keep Local available when the setting is enabled. Make a failed restore of an older session show an actionable error and keep the persisted history instead of garbage-collecting it.
