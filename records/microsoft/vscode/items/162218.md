# Issue #162218 — Multiple formatters for python files should be a warning/info not an error?

[https://github.com/microsoft/vscode/issues/162218](https://github.com/microsoft/vscode/issues/162218)

## Summary

The formatting conflict status still unconditionally uses error severity, even when format on save is disabled. Keep this open for a severity decision; the existing configuration workaround does not address the requested presentation change.

## Change summary

Use a less alarming severity for multiple available formatters when no default formatter has been selected.

## Best solution

Make formatter-conflict severity reflect its actual impact, retaining the Configure action and existing formatter-selection behavior. Decide whether blocked format on save should remain an error while an otherwise idle conflict becomes informational.
