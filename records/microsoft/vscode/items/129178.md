# Issue #129178 — Unable to use shortcuts like Cmd+A, Cmd+C, Cmd+V inside an iframe inside a webview on macOS

[https://github.com/microsoft/vscode/issues/129178](https://github.com/microsoft/vscode/issues/129178)

## Summary

Keep open: multiple confirmations and the current command-routing code support a remaining macOS nested-iframe editing defect. Recent focus-restoration changes still execute commands against the outer webview document, and no verified fix or eligible older canonical was found.

## Change summary

Make Cmd+A, Cmd+C, Cmd+V and related editing shortcuts operate on the focused input inside a nested webview iframe on macOS.

## Best solution

Editing commands should reach the focused nested document, including cross-origin frames, without breaking workbench shortcuts or normal webview editing. The webview owner should settle the native-menu versus embedded-command routing boundary; per-extension scripts are workarounds, not a core resolution.
