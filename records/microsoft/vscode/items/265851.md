# Issue #265851 — Extension API: Text Document Content Change Inconsistency

[https://github.com/microsoft/vscode/issues/265851](https://github.com/microsoft/vscode/issues/265851)

## Summary

Team-authored bug tracking a real, telemetry-confirmed API inconsistency in text document content change events. The verification harness in the Copilot extension still actively detects mismatches on current main; no fix commit references this issue. Stays open.

## Change summary

The VS Code extension API's `onDidChangeTextDocument` event reports content changes that, when applied to the previous document state, do not produce the actual new document state — specifically for `file` scheme (connected to `reloadFromDisk`) and notebook cells.

## Best solution

Fix the two identified inconsistency sources: (1) the `reloadFromDisk` path for `file`-scheme documents, which likely replaces the entire buffer without emitting matching content-change events, and (2) a separate notebook-cell content change issue. The fix likely lives in `src/vs/workbench/api/common/extHostDocuments.ts` or the model-to-extension-host event translation layer. The telemetry harness in `extensions/copilot/src/extension/inlineEdits/vscode-node/parts/verifyTextDocumentChanges.ts` serves as the validation mechanism.
