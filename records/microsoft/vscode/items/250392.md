# Issue #250392 — Accessible Diff Viewer not focusable with keyboard shortcuts after switching to different editor group.

[https://github.com/microsoft/vscode/issues/250392](https://github.com/microsoft/vscode/issues/250392)

## Summary

The keyboard focus failure remains traceable in current source: returning to the diff editor focuses its hidden modified editor rather than the visible Accessible Diff Viewer. Keep this open under the existing accessibility and diff-editor labels.

## Change summary

Returning to an editor group containing an open Accessible Diff Viewer fails to restore keyboard focus to that viewer.

## Best solution

Returning to the diff editor should focus the visible Accessible Diff Viewer without changing the selected difference or line. Preserve normal editor focus when the viewer is closed and cover the return-focus behavior with a browser regression test.
