# Issue #347512 — Copilot runtime drops instruction files on a Windows sharing violation (os error 32)

[https://github.com/microsoft/vscode/issues/347512](https://github.com/microsoft/vscode/issues/347512)

## Summary

Keep open: repeated Windows CI failures directly link missing instructions to a Copilot runtime sharing violation. The runtime needs a fix; the process holding the file remains unidentified.

## Change summary

Prevent transient Windows file-sharing failures from silently omitting repository instructions for an entire Copilot session.

## Best solution

Make runtime instruction discovery tolerate transient sharing and lock violations without retaining a failed read as an instruction-free result. Investigate primary-working-directory concurrent reads, then validate both multi-root instructions and cold-start AGENTS.md loading without test-side delays or prewarming.
