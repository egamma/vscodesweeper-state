# Issue #174008 — Task problemMatcher with fileLocation method set to "search" only seems to work for background task

[https://github.com/microsoft/vscode/issues/174008](https://github.com/microsoft/vscode/issues/174008)

## Summary

Keep open: current source permits foreground task completion to publish diagnostics before asynchronous file searches finish, leaving the final diagnostic unpublished. The background workaround follows a different delivery path; this remains actionable in the tasks area.

## Change summary

Foreground tasks using problemMatcher fileLocation "search" can finish without publishing diagnostics that appear when the task uses background begin/end patterns.

## Best solution

Ensure foreground task diagnostic finalization includes all queued output processing and asynchronous file resolution before publishing markers and disposing the collector. Ordinary finite tasks should not require background patterns to populate Problems.
