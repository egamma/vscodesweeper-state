# Issue #272784 — Allow webviews and custom editors to customize tab tooltips

[https://github.com/microsoft/vscode/issues/272784](https://github.com/microsoft/vscode/issues/272784)

## Summary

Valid, unimplemented feature request: the WebviewPanel API has no tooltip property, so webview tabs just duplicate the title. No work has landed on main to address this.

## Change summary

Allow extensions to set a custom tooltip on webview panel and custom editor tabs, instead of the default title-as-tooltip behavior.

## Best solution

Add an optional `tooltip` property to `WebviewPanel` (and the custom editor equivalent) that extensions can set to override the default tab tooltip. For custom editors, default to showing the file path. The implementation would touch `src/vs/workbench/contrib/webviewPanel/browser/webviewEditorInput.ts` (override `getTitle` for tooltip verbosity) and the extension API surface in `vscode.d.ts`.
