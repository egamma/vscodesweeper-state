# Issue #337024 — Clarification on wording of sandboxing prompt

[https://github.com/microsoft/vscode/issues/337024](https://github.com/microsoft/vscode/issues/337024)

## Summary

Thanks for the report. The wording problem is still present on main, and a later comment shows that 'Allow in this Session' on the sandbox-bypass prompt disables sandboxing for the whole session. The prompt text and options should be clarified.

## Change summary

The 'Allow reading file outside of workspace?' prompt should say 'outside the workspace', and 'Allow in this Session' should make clear what it actually permits.

## Best solution

Change the title to 'outside the workspace'. Relabel the session option so it states its real scope (that file only, or sandbox off for the session), and keep a separate run-once option.
