# Issue #244043 — Support `downloadExtensionsLocally` in bulk extension install APIs, when in remote

[https://github.com/microsoft/vscode/issues/244043](https://github.com/microsoft/vscode/issues/244043)

## Summary

The inconsistency remains on current main: single remote gallery installs support local download and fallback, while the bulk API is forwarded directly to the remote extension-management channel. The issue should remain open for a bounded parity fix.

## Change summary

Make bulk remote extension installation honor `downloadExtensionsLocally` and the local-download fallback used by single-extension installation.

## Best solution

Bulk gallery installation through `NativeRemoteExtensionManagementService` should provide the same local download, remote transfer, fallback, result reporting, and dependency behavior as `installFromGallery`; once covered, `RemoteExtensionsInitializer` can use the bulk API instead of issuing individual installs.
