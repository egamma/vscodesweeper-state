# Issue #244043 — Support `downloadExtensionsLocally` in bulk extension install APIs, when in remote

[https://github.com/microsoft/vscode/issues/244043](https://github.com/microsoft/vscode/issues/244043)

## Summary

Still present on main: NativeRemoteExtensionManagementService overrides installFromGallery with downloadExtensionsLocally fallback but does not override the bulk installGalleryExtensions API, so bulk installs bypass the local-download path when the remote server cannot reach the marketplace.

## Change summary

Bulk extension install APIs (installGalleryExtensions) don't fall back to downloading extensions locally when in a remote context where the server can't reach the marketplace.

## Best solution

Override installGalleryExtensions in NativeRemoteExtensionManagementService (electron-browser/remoteExtensionManagementService.ts) to apply the same downloadExtensionsLocally logic that installFromGallery already has, then update remoteExtensionsInit.ts to use the bulk API.
