# Issue #344931 — GitHub Markdown Alerts not rendering in the new experimental Markdown Editor

[https://github.com/microsoft/vscode/issues/344931](https://github.com/microsoft/vscode/issues/344931)

## Summary

Keep open as a rendering-capability request for the experimental Markdown editor. The existing preview extension mechanism is separate from the new editor; its absence there does not establish a third-party extension defect or a regression in supported behavior.

## Change summary

Render GitHub-style Markdown alerts in the experimental Markdown editor, as the reporter's Markdown Alert extension does in the traditional preview.

## Best solution

Have the Markdown editor owners determine support for GitHub alert syntax and its relationship to preview extension compatibility. Preserve the existing preview integration; code-block editor contributions alone do not provide alert rendering.
