# Issue #168488 — VS Code for the Web: Settings for outline view not functioning well on iPadOS’s browser

[https://github.com/microsoft/vscode/issues/168488](https://github.com/microsoft/vscode/issues/168488)

## Summary

Keep open: a VS Code maintainer reproduced the pane-header action failure on iPadOS, and current main still routes touch gestures through overlapping dropdown and collapsible-header handlers without a cited fix or regression test.

## Change summary

Tapping Outline and other non-top view-header actions on iPadOS can collapse the view, misplace the menu, or leave menu items ineffective.

## Best solution

Make shared view-header actions handle a touch interaction exactly once: open the menu at the tapped action, execute its items, and never toggle the containing pane. Confirm the behavior on current iPadOS across Outline and another non-top view.
