# Issue #290922 — Can't use back button after creating agent session from welcome

[https://github.com/microsoft/vscode/issues/290922](https://github.com/microsoft/vscode/issues/290922)

## Summary

Keep open: the welcome-to-sidebar handoff still retains the welcome widget's session, allowing Back to target the hidden widget instead of the visible chat. This remains the canonical report; the related closed report was explicitly consolidated here.

## Change summary

Back stops working after a session created from the agent welcome page finishes or is stopped.

## Best solution

Ensure the welcome-to-sidebar transition leaves the visible chat as the session's sole widget owner, so Back and New Chat act on that chat without losing its conversation or interrupting its request.
