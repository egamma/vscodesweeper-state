# Issue #229571 — [tunnels] Remote Tunnels stays active after logging out

[https://github.com/microsoft/vscode/issues/229571](https://github.com/microsoft/vscode/issues/229571)

## Summary

This remains a valid, bounded Remote Tunnels lifecycle gap on current main: signing out removes the authentication session, but the active tunnel does not observe that event. The issue is already correctly routed and, as a team-authored accepted polish item, should remain open.

## Change summary

Turn off Remote Tunnel Access automatically when the account session that authenticated the tunnel is removed.

## Best solution

Signing out of the account backing an active remote tunnel should promptly stop that tunnel, while authentication changes for unrelated accounts or sessions should leave it running.
