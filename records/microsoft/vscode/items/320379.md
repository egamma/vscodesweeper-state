# Issue #320379 — Previews of Mermaid Gantt charts with are now black and White Only Code

[https://github.com/microsoft/vscode/issues/320379](https://github.com/microsoft/vscode/issues/320379)

## Summary

The reporter relies on mermaid's `themeCSS` frontmatter directive to inject custom CSS colors into Gantt charts. The built-in mermaid integration does not set `securityLevel: 'loose'`, so custom CSS injection via `themeCSS` is silently ignored — charts render in default (monochrome) colors. The issue already carries `info-needed` and a contributor has asked for clarification; keeping open pending the area owner's decision on whether `themeCSS` should be supported (it has security implications).

## Change summary

Mermaid Gantt charts using `themeCSS` frontmatter for custom colors render as black/white in VS Code's built-in mermaid preview, whereas the former third-party extension rendered them with colors.

## Best solution

The area owner should decide whether the built-in mermaid integration should support `themeCSS` (which requires `securityLevel: 'loose'` in mermaid's config, with security trade-offs) or whether this is intentionally unsupported. If unsupported, close as `*as-designed` and document the limitation; if supportable, consider a workspace-trust-gated opt-in for loose security level.
