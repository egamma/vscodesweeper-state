# Issue #208850 — Multi-selected tree view items all render inline actions

[https://github.com/microsoft/vscode/issues/208850](https://github.com/microsoft/vscode/issues/208850)

## Summary

Still reproduces on main: custom tree views (and several other views) include `.monaco-list-row.selected .actions { display: block }` CSS rules that show inline actions on all selected rows, not just the focused/hovered one. An open PR (#281931) is attempting to fix this.

## Change summary

When multiple tree items are selected, inline actions render on every selected row instead of only on the focused or hovered row.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/281931, which removes `.selected` from the action-visibility CSS selectors across affected views. The core fix site is `src/vs/workbench/browser/parts/views/media/views.css` line 252 (custom tree views), with similar patterns in terminal tabs and other contrib CSS. Care is needed to preserve keyboard accessibility — the focused-row selector must remain.
