# Issue #327195 — Open in Code not showing when installed via winget

[https://github.com/microsoft/vscode/issues/327195](https://github.com/microsoft/vscode/issues/327195)

## Summary

This is the Inno Setup installer working as designed: `addcontextmenufiles`/`addcontextmenufolders` are opt-in tasks, unchecked by default, and only get enabled for a scripted/silent install via an explicit `/MERGETASKS=` switch — a switch the winget manifest (a separate repository) doesn't pass. The reporter already traced this to needing a winget-pkgs change, and the team has previously declined the closely-related ask on the same theme.

## Change summary

"Open with Code" Explorer context menu entries are missing after installing VS Code via winget, unlike a manual install where the checkboxes can be selected.

## Best solution

No core code change is warranted: `build/win32/code.iss` already exposes `addcontextmenufiles`/`addcontextmenufolders` as installer tasks (unchecked by default, lines 88-89) that any silent installer, including winget's manifest, can enable via `/MERGETASKS=addcontextmenufiles,addcontextmenufolders`. The actual fix belongs in the winget-pkgs manifest for VS Code, as the reporter themselves identified.
