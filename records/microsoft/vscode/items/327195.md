# Issue #327195 — Open in Code not showing when installed via winget

[https://github.com/microsoft/vscode/issues/327195](https://github.com/microsoft/vscode/issues/327195)

## Summary

The missing entries follow the installer's explicit opt-in defaults, rather than a broken context-menu registration. The same winget request was previously closed as not planned with maintainer guidance on selecting the installation tasks.

## Change summary

Enable both Windows Explorer “Open with Code” actions by default when installing VS Code through winget.

## Best solution

Retain opt-in Explorer integration and provide the winget installer arguments that enable both actions. Changing the package's defaults would require revisiting the established decision, not fixing a registration defect.

- **Proposed comment:**

  > Thanks for the report and for confirming that selecting the installer options works. Both Explorer context-menu actions are opt-in by default; the same winget request was previously considered in https://github.com/microsoft/vscode/issues/190036 and closed as not planned.
  > 
  > To select both actions when installing through winget, use:
  > `winget install Microsoft.VisualStudioCode --override '/SILENT /mergetasks="!runcode,addcontextmenufiles,addcontextmenufolders"'`
  > 
  > The missing entries with the default installation are therefore expected behavior.
