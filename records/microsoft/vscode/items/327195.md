# Issue #327195 — Open in Code not showing when installed via winget

[https://github.com/microsoft/vscode/issues/327195](https://github.com/microsoft/vscode/issues/327195)

## Summary

Verified duplicate: the open canonical issue owns enabling Windows Explorer integration when silent installers such as WinGet cannot present the installer choices.

## Change summary

Enable the file and folder "Open with Code" context-menu actions by default for WinGet installations.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/134470 and provide a package-independent command for enabling the Explorer integration after installation.
