# Issue #327195 — Open in Code not showing when installed via winget

[https://github.com/microsoft/vscode/issues/327195](https://github.com/microsoft/vscode/issues/327195)

## Summary

The reporter is requesting a different winget installation default, not reporting that explicitly selected integration fails. Existing installer options provide a workaround but do not satisfy automatic enablement; keep this open for a decision on the default.

## Change summary

Enable both Windows Explorer “Open with Code” actions by default when installing through winget.

## Best solution

Decide whether the winget package should explicitly select both context-menu installation tasks on fresh installs, without changing interactive-installer defaults or overriding existing installation preferences. The current opt-in installer arguments remain a workaround, not completion of this request.
