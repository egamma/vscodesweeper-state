# Issue #166608 — "Go to bracket" jumps to random location on large files

[https://github.com/microsoft/vscode/issues/166608](https://github.com/microsoft/vscode/issues/166608)

## Summary

Keep open: the maintainer confirmed that incomplete tokenization makes bracket matching unreliable, and current source still permits navigation using incomplete bracket information. The issue is correctly routed; no fixing commit or verified canonical was established.

## Change summary

Go to Bracket should reach the matching outer bracket in a large file rather than an unrelated bracket.

## Best solution

Make explicit bracket navigation reliable while large-file tokenization is incomplete, without introducing an unbounded synchronous tokenization stall. Establish the user-visible behavior while an accurate match is unavailable and validate both bracket-tree and large-document fallback paths.
