# Issue #319293 — New Copilot Cli Session takes up the full window size

[https://github.com/microsoft/vscode/issues/319293](https://github.com/microsoft/vscode/issues/319293)

## Summary

Current main now offers an explicit way to open a Copilot CLI session beside the current session, while ordinary New intentionally continues to replace the active slot. This team-authored issue must remain open because the later implementation does not reference it, and the only closely matching issue is younger and already closed.

## Change summary

Avoid presenting a newly opened Copilot CLI session as a largely empty full-window surface.

## Best solution

A maintainer should confirm whether the shipped “New Copilot CLI Session to the Side” behavior fully addresses the reported UX. If not, define whether the ordinary command should open beside the current session by default or use a different bounded presentation.
