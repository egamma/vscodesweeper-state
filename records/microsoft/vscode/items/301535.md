# Issue #301535 — CihUb Copilot "switch to release version" does not appear to - 0.40.2026031302 (Pre-release)

[https://github.com/microsoft/vscode/issues/301535](https://github.com/microsoft/vscode/issues/301535)

## Summary

The switch could not install a release because no compatible release version existed for Copilot Chat; the same observable behavior was previously triaged as expected. This is a marketplace-version availability state rather than a failed downgrade with an available target.

## Change summary

Selecting “Switch to Release Version” left GitHub Copilot Chat on its installed pre-release version when no release version was available.

## Best solution

Keep extension-gallery availability authoritative: switching channels can only install a compatible release that exists, and the pre-release remains installed when there is no release target.
