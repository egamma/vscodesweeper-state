# Issue #339962 — Investigate Connected versus Pill tab height and original design intent

[https://github.com/microsoft/vscode/issues/339962](https://github.com/microsoft/vscode/issues/339962)

## Summary

Fresh, well-documented self-investigation into a measured tab-height discrepancy between the Connected and Pill tab styles; the reporter explicitly frames this as an open design question (intentional vs. divergence) that needs native-app verification and a maintainer design call before any geometry change, so this stays open.

## Change summary

Connected and Pill editor tab styles paint different active/inactive fill heights at the same density, and it's unclear whether that was an original design decision.

## Best solution

A design owner for the tab-style modernization work (workbench-tabs) should confirm in native Code OSS whether the taller Connected fill was intentional (e.g. tied to the active-fill extension over the separator) and, if not, align the two styles' visual heights while preserving Connected's active-tab join and stable row layout.
