# Issue #282354 — Two different resources using the same idP cause accounts to appear in duplicate

[https://github.com/microsoft/vscode/issues/282354](https://github.com/microsoft/vscode/issues/282354)

## Summary

Keep open: resource-specific authentication providers can still produce indistinguishable entries in the Accounts menu. This is accepted, team-authored Backlog work; neither a verified canonical duplicate nor an issue-referencing fix was found.

## Change summary

Make accounts for different MCP resources sharing an identity provider distinguishable and manageable.

## Best solution

Present distinguishable resource context in the Accounts menu while preserving resource-specific tokens and permissions. The authentication owner should settle whether these appear as separate resource-labeled entries or grouped account entries with resource-specific controls.
