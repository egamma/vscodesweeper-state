# Issue #237345 — Git - remote name should be considered when checking out a branch

[https://github.com/microsoft/vscode/issues/237345](https://github.com/microsoft/vscode/issues/237345)

## Summary

Keep open: remote checkout still lacks automatic remote-qualified local branch names. Existing branch-creation commands provide a manual workaround, not the requested automation, and no verified open canonical owns this request.

## Change summary

Allow remote branch checkout to automatically create distinct local branch names incorporating the remote name.

## Best solution

Support an opt-in naming policy for newly created remote-tracking branches in the built-in Git extension, preserving existing tracking-branch reuse and default naming behavior.
