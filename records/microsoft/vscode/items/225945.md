# Issue #225945 — Error: `No view is registered with id` might be caused by a race condition

[https://github.com/microsoft/vscode/issues/225945](https://github.com/microsoft/vscode/issues/225945)

## Summary

The stale extension-description path that left newly contributed views unregistered after an update was fixed on main, so this can be closed as completed.

## Change summary

Updating an extension that adds views and then restarting extensions could activate the new extension before its new view contributions were registered, producing a “No view is registered with id” error.

## Best solution

Keep the extension-update handling from commit 017685821d24aa27496b48ab5b70eac07bcbd776, which replaces the previous extension description during update processing so new contribution metadata is registered before activation.
