# Issue #287886 — agent thinks the edits went through when they didn't when doing jupyter notebook cell operations

[https://github.com/microsoft/vscode/issues/287886](https://github.com/microsoft/vscode/issues/287886)

## Summary

The central error-reporting defect remains in current source: when notebook edit confirmation times out, the tool explicitly tells the agent that editing succeeded. The original cause of the unapplied edits remains undiagnosed, but the misleading timeout response is independently actionable.

## Change summary

Notebook edit timeouts should reach the agent as an unconfirmed operation rather than a successful edit.

## Best solution

Make the notebook editing tool accurately distinguish confirmed completion from a timeout, allowing the agent to verify notebook content instead of assuming success. Preserve the existing successful-edit behavior and investigate the underlying application failure separately.
