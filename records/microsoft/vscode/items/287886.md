# Issue #287886 — agent thinks the edits went through when they didn't when doing jupyter notebook cell operations

[https://github.com/microsoft/vscode/issues/287886](https://github.com/microsoft/vscode/issues/287886)

## Summary

Still reproduces on main: when notebook cell text edits time out, the tool returns a success message ('Notebook edited successfully') to the agent, so the model never learns the edits failed. The info-needed label is appropriate to gather a reproducible notebook, but the underlying code path is confirmed buggy.

## Change summary

Agent is told notebook edits succeeded even when they timed out and weren't applied.

## Best solution

When `timeoutPromise.isResolved` is true in `editNotebookTool.tsx`, the tool result should either throw an error (so the agent retries) or return a message indicating the edits failed/timed out, rather than returning 'Notebook edited successfully'.
