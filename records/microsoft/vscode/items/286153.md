# Issue #286153 — Minimizing Agent Mode not obvious enough

[https://github.com/microsoft/vscode/issues/286153](https://github.com/microsoft/vscode/issues/286153)

## Summary

The restore affordance still uses the maximize glyph on current main, although its tooltip changes. Keep this team-authored UX feedback open for a consistent workbench-wide design decision, as the discussion requests.

## Change summary

Make restoring the expanded Agent Sessions layout more discoverable than an active toggle retaining the maximize icon.

## Best solution

Agree on a recognizable restore-state affordance across equivalent workbench maximize controls, rather than introducing an Agent Sessions-only exception. Preserve the distinction between restoring a layout, dismissing a view, and entering OS fullscreen.
