# Issue #132902 — Add telemetry to track reasons for disconnects

[https://github.com/microsoft/vscode/issues/132902](https://github.com/microsoft/vscode/issues/132902)

## Summary

Valid feature request to add telemetry for tracking remote disconnect reasons. The related PR #132903 was closed without merging, and no equivalent telemetry has been added to the remote connection infrastructure on current main. The request remains unaddressed.

## Change summary

Add telemetry to track the reasons why remote connections disconnect, to aid debugging.

## Best solution

Add telemetry events in the remote connection lifecycle (around `PersistentConnectionEventType.ConnectionLost` and `ReconnectionPermanentFailure` in `src/vs/platform/remote/common/remoteAgentConnection.ts`) that log disconnect reasons, reconnection attempt counts, and failure modes. This would help the team diagnose remote connection reliability issues.
