# Issue #132902 — Add telemetry to track reasons for disconnects

[https://github.com/microsoft/vscode/issues/132902](https://github.com/microsoft/vscode/issues/132902)

## Summary

The diagnostic gap remains on current main: remote connection telemetry records lifecycle transitions but not their causal reason. The original implementation attempt was closed unmerged with unresolved design and wiring concerns, so this should remain open under discussion rather than be treated as completed.

## Change summary

Add telemetry identifying why remote or extension-host connections disconnect to improve diagnosis.

## Best solution

Define a privacy-reviewed, bounded disconnect-reason taxonomy at the authoritative network and extension-host exit boundaries, then correlate it with the existing remote reconnection telemetry without transmitting raw errors or stack traces.
