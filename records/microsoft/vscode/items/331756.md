# Issue #331756 — Terminal: mouse wheel dead in full-screen TUI apps (alt buffer) since 1.105 — regression in bundled xterm.js

[https://github.com/microsoft/vscode/issues/331756](https://github.com/microsoft/vscode/issues/331756)

## Summary

Well-diagnosed upstream xterm.js regression with byte-level evidence and a linked (but not yet merged) upstream fix PR; VS Code's own terminal code doesn't touch this path, so nothing to change here until the dependency is bumped.

## Change summary

Mouse wheel scrolling silently does nothing in full-screen TUI apps (alt buffer) for trackpads/smooth wheels/low-sensitivity mice, due to an alt-buffer wheel gate xterm.js introduced in 5.6.0-beta.119.

## Best solution

Track xterm.js PR https://github.com/xtermjs/xterm.js/pull/6118 (fixes xtermjs/xterm.js#6105) and bump the bundled `@xterm/xterm` (and `@xterm/headless`) dependency in package.json once it merges and a release is cut; no VS Code-side code change is needed since the swallow logic lives entirely inside the xterm.js package.
