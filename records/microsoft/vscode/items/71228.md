# Issue #71228 — http.systemCertificates requires window reload

[https://github.com/microsoft/vscode/issues/71228](https://github.com/microsoft/vscode/issues/71228)

## Summary

The reload requirement when unchecking http.systemCertificates still exists on current main — it's a documented Node.js limitation (CAs stored statically in native code). Team-authored, parked in Backlog.

## Change summary

Disabling http.systemCertificates at runtime has no effect until the window is reloaded, due to Node.js storing root CAs statically.

## Best solution

Resolve only if Node.js gains an API to clear/reload its CA store at runtime, or if the experimental systemCertificatesV2 path avoids the static storage. Otherwise this remains a documented upstream limitation.
