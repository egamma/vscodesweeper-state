# Issue #71228 — http.systemCertificates requires window reload

[https://github.com/microsoft/vscode/issues/71228](https://github.com/microsoft/vscode/issues/71228)

## Summary

The reload requirement remains explicitly documented on current main and was attributed to Node.js storing added root CAs statically. Although this is effectively a documented upstream limitation, the issue is team-authored, so the hard keep-open rule bars an as-designed judgment close.

## Change summary

Turning off `http.systemCertificates` does not remove previously loaded OS certificates until the extension-host window reloads.

## Best solution

Keep the limitation documented unless the underlying Node.js certificate APIs gain a safe way to remove dynamically added root CAs; any eventual core change should preserve live configuration updates without retaining certificates after the setting is disabled.
