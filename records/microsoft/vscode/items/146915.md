# Issue #146915 — VSCode windows not staying in their respective virtual desktops on app restart

[https://github.com/microsoft/vscode/issues/146915](https://github.com/microsoft/vscode/issues/146915)

## Summary

Keep this accepted request open: current window-state persistence does not preserve virtual-desktop assignments, and Electron's application-window restoration request remains open. The related Windows reports are newer, while the older macOS report does not own the Windows-specific work.

## Change summary

Restore each VS Code window to its previous virtual desktop after quitting, restarting, or installing an update.

## Best solution

Provide supported native desktop-assignment restoration through Electron and integrate it with VS Code's saved window state. Keep this Windows restoration report distinct from macOS Spaces restoration and from unrelated minimized-state or RDP display-placement requests.
