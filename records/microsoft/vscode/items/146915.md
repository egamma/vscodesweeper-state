# Issue #146915 — VSCode windows not staying in their respective virtual desktops on app restart

[https://github.com/microsoft/vscode/issues/146915](https://github.com/microsoft/vscode/issues/146915)

## Summary

Keep open as an upstream-dependent Backlog request. Electron still lacks the window-restoration capability VS Code needs, and the request has 101 community upvotes.

## Change summary

Restore each VS Code window to its previous Windows virtual desktop or macOS Space after restarting the application.

## Best solution

Electron should provide cross-platform application-window restoration through https://github.com/electron/electron/issues/37494; VS Code can then persist or adopt that state in its native window restoration path under src/vs/platform/windows/electron-main/windowsStateHandler.ts.
