# Issue #199343 — Collapse file should preserve mouse location over icon

[https://github.com/microsoft/vscode/issues/199343](https://github.com/microsoft/vscode/issues/199343)

## Summary

Keep open: current source still permits a file's collapse control to move away from the pointer when collapse follows upward scrolling. Existing scroll anchoring improves some cases but does not preserve the clicked header in this path.

## Change summary

Collapsing a large file in the Multi Diff Editor should leave its expand control under the stationary mouse pointer.

## Best solution

Preserve the clicked file header's viewport position through individual collapse operations, independently of recent scroll direction. Retain existing directional anchoring for unrelated content-height updates.
