# Issue #199944 — Color picker is far too wide and does not remember when I resize it smaller

[https://github.com/microsoft/vscode/issues/199944](https://github.com/microsoft/vscode/issues/199944)

## Summary

The agreed improvement remains missing: the embedded color picker can still stretch with documentation, and shrinking the hover below its default maximum does not constrain subsequent hovers. Keep this open for the absolute picker-width limit the maintainer reaffirmed when reopening it.

## Change summary

Keep the editor’s embedded color picker reasonably compact instead of allowing wide documentation and hover sizing rules to stretch its controls.

## Best solution

Give the embedded color picker an absolute maximum width independent of the surrounding documentation, following the maintainer’s accepted direction. Preserve general hover sizing and persistence semantics; redesigning those is separate from this bounded improvement.
