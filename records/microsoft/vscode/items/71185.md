# Issue #71185 — Accessibility service not firing onDidChangeAccessibilitySupport

[https://github.com/microsoft/vscode/issues/71185](https://github.com/microsoft/vscode/issues/71185)

## Summary

Keep open as an upstream Windows accessibility-detection issue. The discussion confirms the failure after disabling NVDA, and current VS Code still depends on Electron's accessibility-change event; no verified fix or qualifying canonical duplicate was found.

## Change summary

Automatically leave screen-reader mode when NVDA stops on Windows, without requiring a full VS Code restart.

## Best solution

Have Chromium/Electron report assistive-technology disablement on Windows so VS Code receives the disabled state through its existing accessibility event bridge. Retest the NVDA start/stop sequence against the current runtime before concluding that the upstream limitation persists or is resolved.
