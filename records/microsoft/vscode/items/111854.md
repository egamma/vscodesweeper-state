# Issue #111854 — Allow extensions to contribute a default when clause to be used when a user add a key binding for the command

[https://github.com/microsoft/vscode/issues/111854](https://github.com/microsoft/vscode/issues/111854)

## Summary

A real extension API gap remains on current main: extensions cannot provide a default `when` expression for newly created user keybindings. The request is already accepted into the Backlog and correctly routed.

## Change summary

Allow extensions to supply the default `when` clause used when a user creates a keybinding for a command.

## Best solution

Add explicit default-keybinding context metadata to the extension contribution model and have the keybindings editor apply it when creating a user binding, without treating the metadata as an active default binding.
