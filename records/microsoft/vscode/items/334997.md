# Issue #334997 — After hitting the 'budget limit', increasing the budget, the chat won't continue

[https://github.com/microsoft/vscode/issues/334997](https://github.com/microsoft/vscode/issues/334997)

## Summary

Keep open while the GitHub billing team investigates the server-side quota cache. The client repeatedly received HTTP 402 `quota_exceeded` after the budget changed, and a maintainer confirmed that VS Code lacks insight into the responsible server-side state.

## Change summary

Increasing a Copilot usage budget does not promptly clear the exhausted-quota state, preventing chat requests for roughly 30 minutes.

## Best solution

The GitHub billing service should propagate budget changes promptly and return an updated entitlement on the next Copilot request. VS Code should continue presenting the server result accurately; the separate retry-continuation concern can be evaluated after the upstream quota state is reliable.

## Evidence

- **confirmed recurrence:** The reporter reproduced the delay multiple times and observed that the billing page remained in the exceeded state for roughly 30 minutes; updating the budget through https://github.com/settings/billing/budgets sometimes caused access to recover immediately.
- **maintainer diagnosis:** A VS Code maintainer states that the client has no insight into the server-side caches and forwarded the problem to the GitHub billing team: https://github.com/microsoft/vscode/issues/334997#issuecomment-5817114873
- **client boundary:** Current main maps `quota_exceeded` responses to quota UI in src/vs/workbench/contrib/chat/common/chatErrorMessages.ts and extensions/copilot/src/platform/chat/common/commonTypes.ts; the observed stale entitlement is supplied by the service rather than computed by those client paths.
- **prior report:** https://github.com/microsoft/vscode/issues/327322 reports the same observable symptom but is closed after recovery from an incident, and its maintainer explicitly invited a new issue if the problem recurred, so it cannot serve as an open duplicate canonical.
