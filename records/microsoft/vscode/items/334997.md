# Issue #334997 — After hitting the 'budget limit', increasing the budget, the chat won't continue

[https://github.com/microsoft/vscode/issues/334997](https://github.com/microsoft/vscode/issues/334997)

## Summary

This is a budget/quota propagation delay on GitHub's billing backend, not a VS Code defect — VS Code simply surfaces the server's `quota_exceeded` response, and the reporter's own comments confirm the fix (waiting, or re-editing on the billing/budgets page) resolves it server-side.

## Change summary

After raising the Copilot monthly budget, VS Code keeps reporting quota exceeded for up to ~30 minutes before the increase takes effect.

## Best solution

Nothing to change in VS Code core: the error is a passthrough of the backend's `quota_exceeded` code (extensions/copilot/src/extension/prompt/node/chatMLFetcher.ts) while the account's budget/quota state propagates on GitHub's billing systems; redirect to GitHub Support for the billing-side delay.
