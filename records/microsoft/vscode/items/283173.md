## Change summary

Creating a project with @workspace /new in Codespaces unexpectedly reloads the window into the generated subfolder, hiding the original repository root from Explorer.

## Best solution

Creating a project beneath the current Codespaces workspace should preserve the original workspace and leave the generated folder visible within it. Reproduce the browser flow and establish whether the existing subfolder guard is bypassed or the workspace switch originates elsewhere before changing the Copilot creation path.
