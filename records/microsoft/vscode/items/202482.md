# Issue #202482 — Code actions menu changes scroll position

[https://github.com/microsoft/vscode/issues/202482](https://github.com/microsoft/vscode/issues/202482)

## Summary

The issue remains necessary: current main still unconditionally reveals the code-action position while calculating the menu anchor, which can alter the editor scroll position before the menu opens.

## Change summary

Opening the code actions menu for a selection near the top of the viewport unexpectedly scrolls the editor.

## Best solution

Preserve the editor viewport when opening the code actions menu while continuing to anchor the widget at the relevant visible code position.
