# Issue #348630 — Copilot harness: models from `registerLanguageModelChatProvider` extensions work in local windows but not in remote (Remote-SSH/WSL/Dev Container) windows, which blocks the Local harness removal

[https://github.com/microsoft/vscode/issues/348630](https://github.com/microsoft/vscode/issues/348630)

## Summary

Keep open: remote extension-contributed models remain unsupported, and the planned plugin-based solution explicitly does not preserve that capability. The supplied reproduction and independent confirmation establish a concrete compatibility gap before Local harness removal.

## Change summary

Support extension-registered language models in remote Copilot-harness sessions without requiring providers to become agent-host plugins.

## Best solution

Resolve whether client-dependent extension providers remain supported during the harness migration, and provide a remote execution path or a viable replacement for their credential, connectivity and request-transformation requirements. Coordinate with the existing BYOK work without treating built-in Custom Endpoint support as sufficient coverage.
