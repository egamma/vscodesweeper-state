# Issue #249743 — Rename symbol (F2) and the following Home key closes the Rename symbol dialog

[https://github.com/microsoft/vscode/issues/249743](https://github.com/microsoft/vscode/issues/249743)

## Summary

Still reproducible on main: the rename widget defers input focus by 100ms via setTimeout, creating a race window where keystrokes (like Home) are processed by the editor instead of the rename input, causing the widget to dismiss.

## Change summary

Pressing Home quickly after F2 (Rename Symbol) closes the rename dialog instead of moving the cursor within the rename input.

## Best solution

Eliminate the 100ms setTimeout race in `_show()` by either focusing the input synchronously, suppressing editor key handling while the rename widget is visible but not yet focused, or guarding the `afterRender` cancel path against cursor movements triggered during the focus-delay window.
