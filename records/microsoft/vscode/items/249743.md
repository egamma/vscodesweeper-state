# Issue #249743 — Rename symbol (F2) and the following Home key closes the Rename symbol dialog

[https://github.com/microsoft/vscode/issues/249743](https://github.com/microsoft/vscode/issues/249743)

## Summary

The rename widget still becomes visible before its input receives focus, leaving a 100 ms window in which Home moves the editor cursor and cancels renaming. Keep this open: the reported keyboard sequence maps directly to the current source.

## Change summary

Pressing Home immediately after F2 can dismiss Rename Symbol instead of moving the caret within the rename input.

## Best solution

Make the visible rename input reliably receive immediate keyboard interaction without letting Home move the underlying editor cursor. Preserve normal cancellation when the user deliberately leaves the rename operation.
