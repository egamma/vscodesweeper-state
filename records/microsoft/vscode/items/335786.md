# Issue #335786 — Marking an active agent session as Done does not stop it

[https://github.com/microsoft/vscode/issues/335786](https://github.com/microsoft/vscode/issues/335786)

## Summary

Team-authored bug report, freshly filed and traced in source: 'Mark as Done' only archives the session UI-side and never stops the underlying agent execution, matching the reported behavior — this needs a maintainer decision on where to wire in a stop/confirmation before archiving, so it stays open.

## Change summary

Marking an actively-running agent session as Done archives it in the UI but leaves the agent running and consuming tokens in the background; restoring it shows it kept working.

## Best solution

In src/vs/sessions/services/sessions/browser/sessionsManagementService.ts, `archiveSession()` should check whether the session is actively running and either stop it (via the relevant provider) or prompt for confirmation before archiving, per the reporter's expected behavior; the UI-side confirmation dialogs for MarkAsDone in sessionsViewActions.ts would need updating too.
