# Issue #152806 — API: allow an extension to change the environment variables

[https://github.com/microsoft/vscode/issues/152806](https://github.com/microsoft/vscode/issues/152806)

## Summary

Keep open: current APIs modify terminal environments only, leaving the requested extension-host environment capability unresolved. This team-authored Backlog request has 27 community upvotes and remains appropriately classified as under discussion.

## Change summary

Allow extensions to contribute persistent environment-variable changes that apply to the extension host and its child processes.

## Best solution

Design an extension API, likely building on `EnvironmentVariableCollection`, with explicit extension-host targeting, persistence semantics, and safe restart or reload UX. Resolve the documented startup-order and long-running activation concerns through API review before implementation.
