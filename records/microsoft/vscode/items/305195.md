# Issue #305195 — Model Selection Submenu cannot show

[https://github.com/microsoft/vscode/issues/305195](https://github.com/microsoft/vscode/issues/305195)

## Summary

The auxiliary-window picker regression was fixed on main by the merged fix for the older canonical report, and the corrective layout guard remains in the current source. The model configuration submenu should no longer transfer focus to the main window and immediately dismiss.

## Change summary

Model configuration submenus flashed and closed immediately when opened from a standalone Chat window.

## Best solution

Keep the shipped ActionListWidget focus-restoration guard from commit d64acf25ce933b6451bea8ab188c0d374e679540; it directly addresses the premature cross-window focus that dismissed Chat picker menus.

## Evidence

- **canonical diagnosis:** The older canonical report https://github.com/microsoft/vscode/issues/304746 describes the same observable symptom: Chat model and mode pickers do not remain open in a floating window. Maintainers traced it to ActionListWidget restoring DOM focus during construction, before the widget was attached to the auxiliary window.
- **fix commit:** https://github.com/microsoft/vscode/commit/d64acf25ce933b6451bea8ab188c0d374e679540 merged https://github.com/microsoft/vscode/pull/305641. Its diff adds `_hasLaidOut`, gates the post-splice focus-restoration block on that flag, and sets the flag only from `layout()`, preventing the main window from taking focus and causing the picker to hide.
- **current source:** Current `src/vs/platform/actionWidget/browser/actionList.ts` retains `_hasLaidOut`, checks it before restoring list focus in `_applyFilter`, and sets it in `layout()`, so tracing the reported trigger on main no longer reaches the premature construction-time focus path.
- **independent confirmation:** https://github.com/microsoft/vscode/issues/306072 documents the same model-picker flash in detached Chat windows, including the main window stealing focus; a maintainer confirmed there that the fix was in Insiders and targeted the 1.114 build.
- **release:** Shipped in 1.114.0 — the earliest release tag containing d64acf25ce (verified against the repo's release tags).
