# Issue #332176 — Synchronize paired tag renaming

[https://github.com/microsoft/vscode/issues/332176](https://github.com/microsoft/vscode/issues/332176)

## Summary

This is already shipped: the `editor.linkedEditing` setting (formerly `editor.renameOnType`) synchronizes paired tag renames automatically, so the request is covered by existing, intentional behavior.

## Change summary

Renaming an opening HTML/XML tag should automatically rename its paired closing tag.

## Best solution

Point the reporter at `editor.linkedEditing` (enable it in settings) — it already does exactly this for HTML/XML-like languages via `LinkedEditingContribution` in src/vs/editor/contrib/linkedEditing/browser/linkedEditing.ts.

  > Thanks for the suggestion! This already exists — it's the `editor.linkedEditing` setting (the successor to the old `editor.renameOnType`). When enabled, renaming an opening HTML/XML tag automatically updates its paired closing tag as you type. It defaults to off, so you'll need to turn it on in Settings (`"editor.linkedEditing": true`).
