# Issue #317015 — [Bug] CWE-79 XSS in Notebook Renderer: kernel output HTML reaches element.innerHTML via passthrough TrustedTypes (webviewPreloads.ts:2989) — known-accepted

[https://github.com/microsoft/vscode/issues/317015](https://github.com/microsoft/vscode/issues/317015)

## Summary

Security-sensitive issue describing XSS via notebook kernel output. The behavior is confirmed in current main (passthrough TrustedTypes policy + innerHTML assignment still present), but it is a known-accepted design choice with sandboxing as the mitigation. Keeping open for a human security review.

## Change summary

Notebook renderer webview passes kernel HTML output through a no-op TrustedTypes policy directly to innerHTML, allowing script execution from malicious kernel output.

## Best solution

A human security reviewer should evaluate whether the existing sandboxing of the notebook webview is sufficient mitigation, or whether an additional sanitization pass (e.g. DOMPurify or stripping script tags) should be added before the innerHTML assignment. The team's current position is that renderer extensions own sanitization and the webview sandbox limits blast radius.
