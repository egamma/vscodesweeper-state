# Issue #315426 — The handling of characters with ambiguous widths

[https://github.com/microsoft/vscode/issues/315426](https://github.com/microsoft/vscode/issues/315426)

## Summary

A real editor capability gap remains for fonts that render East Asian Ambiguous characters as double-width. The request is correctly classified in Backlog Candidates and is still within its community-voting period.

## Change summary

Add an option that counts East Asian Ambiguous characters as two columns when calculating tab stops.

## Best solution

Provide an opt-in editor setting that applies Unicode East Asian Ambiguous width classification consistently to visible-column and tab-rendering calculations, with coverage for Greek and symbol characters.
