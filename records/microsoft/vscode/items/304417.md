# Issue #304417 — changes made in terminal

[https://github.com/microsoft/vscode/issues/304417](https://github.com/microsoft/vscode/issues/304417)

## Summary

Valid feature request for a consolidated diff/review UI when Copilot makes file changes through terminal commands rather than direct edits. A team member has engaged and is exploring implementation feasibility — keep open.

## Change summary

When Copilot agent makes changes via terminal commands, users want a final overview of all file changes with accept/reject controls, similar to the diff UI shown for direct code edits.

## Best solution

Implement terminal-driven change tracking so that when Copilot executes terminal commands that modify files, the resulting file diffs are surfaced in the same review UI (green dashed lines, accept/undo) used for direct edits. The member comment from @justschen suggests this is being explored in the terminal/chat-agent-editing area.
