# Issue #188450 — Allow different indentation settings in sections of the file

[https://github.com/microsoft/vscode/issues/188450](https://github.com/microsoft/vscode/issues/188450)

## Summary

A real capability gap remains: indentation whitespace options are model-wide even though VS Code recognizes embedded languages by position. This accepted Backlog request has 31 upvotes and should remain open.

## Change summary

Allow embedded sections of a file to use language-specific tab and space indentation settings.

## Best solution

Resolve indentation insertion options from the embedded language at each selection while retaining model-wide tab rendering where necessary. The editor-core implementation should also define predictable behavior for multi-cursor selections spanning languages.

- **Reason:** Language-aware indentation improves the core editing experience and enables language extensions to handle mixed-language documents correctly.

## Evidence

- **current source:** src/vs/editor/common/model.ts defines tabSize, indentSize, and insertSpaces as ITextModelUpdateOptions, making them model-wide rather than range- or language-specific.
- **indentation path:** src/vs/editor/contrib/indentation/common/indentation.ts obtains tabSize, indentSize, and insertSpaces from model.getOptions(), so indentation commands cannot vary these values by cursor position.
- **available language context:** src/vs/editor/common/services/textResourceConfigurationService.ts already resolves configuration overrides through model.getLanguageIdAtPosition when given a position, providing a plausible foundation for embedded-language-aware settings.
