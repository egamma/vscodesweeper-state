# Issue #244462 — Use same hover group for all copilot actions near input

[https://github.com/microsoft/vscode/issues/244462](https://github.com/microsoft/vscode/issues/244462)

## Summary

Keep open as focused chat-input UI debt: adjacent Copilot actions still use inconsistent hover mechanisms, so hover timing depends on which control is targeted.

## Change summary

Place all Copilot actions adjacent to chat inputs in one hover group so their hovers appear consistently and immediately when moving between them.

## Best solution

Migrate the remaining chat-input actions from deprecated managed hovers to `setupDelayedHover`, and give the left- and right-aligned action items one shared hover group while preserving their current toolbar layout and action behavior.
