# Issue #267005 — Turn off local indexing of files in the workspace (for working with large size repo under GVFS)

[https://github.com/microsoft/vscode/issues/267005](https://github.com/microsoft/vscode/issues/267005)

## Summary

Keep open: the GVFS hydration is credibly observed and current main still eagerly traverses the workspace for codebase indexing while VS Code is otherwise idle. The team-authored issue cannot be closed as implemented without a fixing commit or linked closing PR that explicitly references https://github.com/microsoft/vscode/issues/267005.

## Change summary

Prevent idle Copilot codebase indexing from hydrating files in very large GVFS/ProjFS workspaces, with a reliable way to disable that indexing.

## Best solution

Disabling `github.copilot.chat.workspace.enableCodeSearch` should prevent all eager workspace-index initialization and file traversal. The default-enabled path should also avoid content reads or other operations that hydrate placeholders until a user explicitly requests codebase search.
