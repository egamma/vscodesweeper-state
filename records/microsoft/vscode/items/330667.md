# Issue #330667 — New paste behavior in Github Copilot chat bar is not good

[https://github.com/microsoft/vscode/issues/330667](https://github.com/microsoft/vscode/issues/330667)

## Summary

Confirmed on current main: pasting text ≥1000 characters into the chat input now always creates a `Pasted text #N` attachment instead of inserting it inline, with no setting to opt out — a legitimate, recently-shipped behavior change worth a maintainer product call rather than a code defect.

## Change summary

Long pastes into the Copilot Chat input are converted into a `#attachment:Pasted text #N` reference (and become the session title) instead of appearing as inline text, with no way to disable it.

## Best solution

Have the chat/input owners weigh in on `PasteTextProvider.provideDocumentPasteEdits` and `createPastedTextArtifact` in src/vs/workbench/contrib/chat/browser/widget/input/editor/chatPasteProviders.ts (threshold `pastedTextArtifactMinLength = 1000`, no config) — either add a setting to gate/raise the threshold, or derive session titles from the first non-attachment text rather than the attachment placeholder.
