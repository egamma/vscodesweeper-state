# Issue #331260 — Model picker didn't update in an existing session when I signed in to Copilot

[https://github.com/microsoft/vscode/issues/331260](https://github.com/microsoft/vscode/issues/331260)

## Summary

Freshly filed, team-authored bug with a concrete repro from the author (signing back into Copilot after other-provider usage doesn't refresh the model picker's model list, though the Manage Models UI does update; a full VS Code restart is needed to fix it). This is a real, reproducible defect that should stay open and get routed to the chat/model-picker owners.

## Change summary

After signing out of and back into Copilot in an existing chat session, the model picker doesn't refresh to show Copilot's models again, even though the separate Manage Models UI does pick them up.
