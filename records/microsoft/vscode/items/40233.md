## Summary

Keep open: current main still loads only `.vscode/settings.json`, while the open PR https://github.com/microsoft/vscode/pull/269623 is an active implementation candidate explicitly reopened by a maintainer for further planning and discussion.

## Change summary

Add per-user, per-workspace settings that locally override shared `.vscode/settings.json` values without being committed.
