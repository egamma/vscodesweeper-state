# Issue #179474 — [Linux Mint] Program icon doesn't match Linux Mint theme

[https://github.com/microsoft/vscode/issues/179474](https://github.com/microsoft/vscode/issues/179474)

## Summary

Keep open for Linux desktop-integration investigation: current source still supplies a bundled window icon, but that alone does not establish how Mint selects the displayed icon. Packaging and Electron have changed since the report; the supplied Mint version, theme mismatch, and update-reset scenario suffice for an initial retest.

## Change summary

VS Code displays its default application icon instead of Linux Mint's themed icon, and manually replacing it does not survive updates.

## Best solution

Make the application participate correctly in Mint's desktop icon lookup, retaining the bundled icon as a fallback when the active theme provides none. First establish whether the mismatch occurs in the launcher or running-window icon, since those use different paths.
