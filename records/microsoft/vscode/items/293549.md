# Issue #293549 — Agents: Restore sessions when sending a new prompt

[https://github.com/microsoft/vscode/issues/293549](https://github.com/microsoft/vscode/issues/293549)

## Summary

Keep open: explicit Restore is available, but sending a prompt does not automatically revive an archived session. Current Agent Host sessions are read-only while archived, so this request now requires reconciling automatic revival with that explicit-restore contract; it is accepted, team-authored Backlog work.

## Change summary

Automatically unarchive an archived session when the user sends another prompt, returning it to active-session surfaces.

## Best solution

Agree on a consistent continuation experience for archived sessions across the Agents window and chat providers. If automatic revival is adopted, continuing the same conversation should restore its session and required workspace before dispatching the prompt, without making passive history viewing revive it.
