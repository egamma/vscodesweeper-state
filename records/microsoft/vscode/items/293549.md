# Issue #293549 — Agents: Restore sessions when sending a new prompt

[https://github.com/microsoft/vscode/issues/293549](https://github.com/microsoft/vscode/issues/293549)

## Summary

The requested revival behavior remains absent on current main: sending to an archived session does not unarchive it. This team-authored feature request should remain open.

## Change summary

Automatically restore an archived agent session to the active sessions list when the user sends it another prompt.

## Best solution

After a provider successfully accepts a request for an archived session, unarchive it through the sessions management layer so every provider, list, and command-center surface observes the same transition. Cover foreground and background sends with management-service tests.
