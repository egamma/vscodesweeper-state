# Issue #324989 — Feature Request: Add an interactive Inline Command History Search/Filter UI for Integrated Terminal

[https://github.com/microsoft/vscode/issues/324989](https://github.com/microsoft/vscode/issues/324989)

## Summary

The requested feature already exists as the built-in "Terminal: Run Recent Command" command, which provides a Quick Pick UI with fuzzy search over terminal command history, exactly matching the proposed behavior.

## Change summary

Add an interactive inline command history search/filter UI with fuzzy matching and quick execute for the integrated terminal.

## Best solution

Keep the shipped behavior — "Terminal: Run Recent Command" (`workbench.action.terminal.runRecentCommand`, bound to `Ctrl+Alt+R`) already provides a searchable Quick Pick of recent commands with fuzzy matching toggle, per-shell-profile history, and direct execution on Enter. No further change needed.

## Evidence

- **existing command:** The command `workbench.action.terminal.runRecentCommand` ("Terminal: Run Recent Command...") is registered in src/vs/workbench/contrib/terminalContrib/history/browser/terminal.history.contribution.ts with keybinding Ctrl+Alt+R (Ctrl+Opt+R on Mac).
- **fuzzy search support:** src/vs/workbench/contrib/terminalContrib/history/browser/terminalRunRecentQuickPick.ts implements a Quick Pick with a fuzzy search toggle button (`matchOnLabelMode: 'fuzzy' | 'contiguous'`), filtering commands as the user types.
- **per-profile history:** Command history is stored per shell type via `{ shellType: instance.shellType }` in the history contribution, matching the request for per-terminal-profile history.
- **quick execute:** Selecting a command from the Quick Pick pastes it into the terminal and can execute it, matching the proposed 'Quick Execute/Paste' behavior.
