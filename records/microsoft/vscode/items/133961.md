# Issue #133961 — Sparse top level menu when no window is opened

[https://github.com/microsoft/vscode/issues/133961](https://github.com/microsoft/vscode/issues/133961)

## Summary

Still valid on current main: the `shouldDrawMenu` method in the menubar only draws File, Help, and Window menus when no window is open on macOS; Edit/View/Go/Run/Terminal are hidden. The requested polish — showing all top-level menus with disabled items — has not been implemented.

## Change summary

On macOS with no open window, only File/Help/Window menus appear in the menu bar; the rest (Edit, View, Go, Run, Terminal) disappear entirely.

## Best solution

Extend `shouldDrawMenu` in `src/vs/platform/menubar/electron-main/menubar.ts` to return `true` for all menu IDs on macOS in the closedLastWindow/noActiveMainWindow state, so the full menu structure is preserved with items disabled — matching macOS HIG expectations.
