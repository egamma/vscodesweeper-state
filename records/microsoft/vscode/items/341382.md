# Issue #341382 — Linux Electron smoke tests are hitting the 20-minute step timeout

[https://github.com/microsoft/vscode/issues/341382](https://github.com/microsoft/vscode/issues/341382)

## Summary

Thanks for the detailed analysis. This is a team-authored CI/engineering issue filed one day ago. The 20-minute smoke step limit is still being hit on slower Linux runners, and there is no fix or canonical issue yet. It stays open.

## Change summary

The Linux Electron smoke step regularly reaches its 20-minute timeout because per-suite app launch overhead and new suites have increased total runtime.

## Best solution

Raise the smoke step's timeout-minutes as a short-term fix. Then cut app start/stop overhead by sharing an app instance across short suites and reducing restarts in the Data Loss suite. Also look into the Electron 43 launch slowdown tracked in https://github.com/microsoft/vscode/issues/341401.
