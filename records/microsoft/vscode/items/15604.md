# Issue #15604 — Simple way to temporarily turn off exclusions for QuickOpen files

[https://github.com/microsoft/vscode/issues/15604](https://github.com/microsoft/vscode/issues/15604)

## Summary

Keep open: Quick Open still lacks a temporary exclusion bypass for filename searches, and an open PR explicitly targets this request. Review that implementation candidate rather than closing the issue or starting competing work.

## Change summary

Allow users to temporarily include excluded and gitignored files in Quick Open without changing workspace settings or knowing their exact paths.

## Best solution

Provide a keyboard-accessible, temporary way to search excluded files while preserving normal exclusions when Quick Open is reopened. Review https://github.com/microsoft/vscode/pull/281303 against this goal and the thread's preference for a minimal Quick Open surface.
