## Summary

This is aggregated design feedback on the new Modern UI default (spacing, hover feel, theme flattening, discoverability of the opt-out), not a single reproducible bug — best kept open as design discussion rather than triaged as a closable defect.

## Change summary

Reporter and several commenters find the new default Modern UI cluttered, noisy, and harder to configure back to the classic look, with follow-up comments split between liking and disliking the new look and one raising an accessibility/spacing concern.
