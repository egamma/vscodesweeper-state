# Issue #269599 — Client sending models to Auto that are not in the Auto list

[https://github.com/microsoft/vscode/issues/269599](https://github.com/microsoft/vscode/issues/269599)

## Summary

Unable to reproduce on current main: the server-side fix was deployed in October 2025, a team member (lramos15) could not reproduce it even before that fix, and the client-side model selection logic has since been substantially reworked — including a direct fix for Auto mode sending the wrong model (commit 8b73af27497). No further reports in 10 months.

## Change summary

The VS Code client was sending models (notably gpt-4o) to the Auto model router that were not in the Auto model list, causing increased failure rates.

## Best solution

Close as not reproducible. The server-side mitigation was deployed in October 2025, and the client-side Auto mode model selection has been overhauled — most notably commit 8b73af27497 which fixed Auto mode to respect the router's `chosen_model` instead of blindly picking `candidate_models[0]`. If the issue resurfaces, a new report with logs would be needed.
