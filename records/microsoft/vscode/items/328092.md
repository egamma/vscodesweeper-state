# Issue #328092 — Feature Request: Proactive Extension Compatibility and Conflict Warning System

[https://github.com/microsoft/vscode/issues/328092](https://github.com/microsoft/vscode/issues/328092)

## Summary

A nearly identical extension-conflict warning request was explicitly closed as not planned, establishing a clear maintainer precedent for an out-of-scope close.

## Change summary

Add extension manifest metadata and UI warnings for known conflicts, redundancies, and dependency risks.

## Best solution

Keep conflict handling with extension authors and targeted recommendation rules rather than introducing a core-wide compatibility registry and warning system.

## Vision fit

- **Fit:** rejected
- **Reason:** A broad compatibility registry and several new warning surfaces add specialized UI and metadata complexity better handled by extensions or targeted recommendations.
- **Evidence:** Values and guardrails: “The power lives in extensions” and the default experience should remain lightweight with simple, uniform UI.
