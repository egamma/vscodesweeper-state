# Issue #339493 — Agent Host chat: responses render only after the turn completes, no streaming deltas

[https://github.com/microsoft/vscode/issues/339493](https://github.com/microsoft/vscode/issues/339493)

## Summary

Current main already sets `streaming: true` unconditionally for every Agent Host Copilot session launch (both create and resume), with a unit test asserting it — this is exactly the fix the report asks for, so the reported root cause no longer applies.

## Change summary

Agent Host chat renders the full assistant response only after the turn completes instead of streaming token-by-token, because the underlying Copilot SDK session isn't created with streaming enabled.

## Best solution

Keep the current session-launch config, which unconditionally passes `streaming: true` to the SDK for both create and resume plans in copilotSessionLauncher.ts (commit 5e86c7c4c2eb99b22e631e0aa4eb05f6b8b53f35); ask the reporter to confirm on a build containing this commit.
