# Issue #339493 — Agent Host chat: responses render only after the turn completes, no streaming deltas

[https://github.com/microsoft/vscode/issues/339493](https://github.com/microsoft/vscode/issues/339493)

## Summary

Keep open: current source still buffers BYOK output across the Agent Host bridge before emitting SSE. Independent Windows and macOS confirmations support the symptom, but the report's missing SDK streaming-option diagnosis does not match current main.

## Change summary

Agent Host chats using custom-endpoint BYOK models display responses only after generation completes instead of incrementally.

## Best solution

Deliver incremental BYOK text and reasoning through the renderer-to-host bridge and Responses proxy while preserving final output, tool calls, usage, and errors. Coordinate with the related streaming/cancellation report without treating the existing SDK streaming flag as a complete fix.
