# Issue #338686 — Enhance the tunnels action with remote agent host management UI

[https://github.com/microsoft/vscode/issues/338686](https://github.com/microsoft/vscode/issues/338686)

## Summary

The discoverability gap remains: the title-bar action toggles remote access rather than opening host management. Existing commands provide host status, rename, and reconnect separately, but do not deliver the requested consolidated entry point.

## Change summary

Make the tunnels action open a remote-management surface combining connection enablement, host status, rename, reconnect, and existing management functionality.

## Best solution

Provide a discoverable management entry point in the Agents Window that reuses existing host-management capabilities while clearly distinguishing sharing this machine from connecting to another host. Preserve existing authentication and connection-backend behavior.
