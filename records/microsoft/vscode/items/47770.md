# Issue #47770 — Select editor text via touch

[https://github.com/microsoft/vscode/issues/47770](https://github.com/microsoft/vscode/issues/47770)

## Summary

A meaningful touch-only selection gap remains on main, and this Backlog request has 48 community upvotes. The older, broader issue is the best canonical tracker rather than the narrower device-specific reports.

## Change summary

Support intuitive touch text selection while preserving touch scrolling in empty editor space.

## Best solution

Define touch selection gestures that coexist with scrolling, then implement them in `src/vs/editor/browser/controller/pointerHandler.ts`, ideally with selection handles or another interaction consistent across supported touch platforms.
