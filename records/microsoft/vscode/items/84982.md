# Issue #84982 — Allow detail option on task input pickString

[https://github.com/microsoft/vscode/issues/84982](https://github.com/microsoft/vscode/issues/84982)

## Summary

The requested per-option detail remains unsupported: current pickString inputs accept labels and values but cannot display a separate explanatory detail. Keep this accepted Backlog request open; it has 24 community upvotes and no verified canonical covering the same request.

## Change summary

Allow task pickString input options to include explanatory detail text alongside their labels and returned values.

## Best solution

Support optional per-option detail through the shared input configuration schema and configuration resolver, preserving existing string options, labels, default selection, and substituted values. Account for debug configurations because they consume the same input schema.
