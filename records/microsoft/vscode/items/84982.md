# Issue #84982 — Allow detail option on task input pickString

[https://github.com/microsoft/vscode/issues/84982](https://github.com/microsoft/vscode/issues/84982)

## Summary

Still unimplemented on main: pickString input options support only `label` and `value` — no `detail` property. The request is valid, community-promoted to backlog with 24 upvotes, and should remain open.

## Change summary

Allow a `detail` string on pickString task-input options so each choice can carry an explanatory description in the quick-pick UI.

## Best solution

Add an optional `detail` property to the pickString option object in `PickStringInputInfo`, the JSON schema, and the pick-item construction in `baseConfigurationResolverService.ts` so that `IQuickPickItem.detail` is populated. Small, localized change across three files.
