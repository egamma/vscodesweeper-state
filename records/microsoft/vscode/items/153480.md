# Issue #153480 — Stopping debug while pre-launch task runs causes popups

[https://github.com/microsoft/vscode/issues/153480](https://github.com/microsoft/vscode/issues/153480)

## Summary

The issue remains necessary: current main still allows a canceled debug launch's background pre-launch task to influence a subsequent launch, producing repeated task-status prompts even though debugging can continue after dismissing them.

## Change summary

Stopping a debug session while its pre-launch task runs, then restarting before that task exits, causes repeated task error popups.

## Best solution

Keep debug launch cancellation isolated from later launches: a restarted session should reuse or await the still-running pre-launch task without inheriting stale cancellation state or showing duplicate task-status prompts. The fix belongs at the debug/task coordination boundary.
