# Issue #326796 — If Copilot is suggesting inline code, the dropdown that shows functions and variables as i type does not trigger.

[https://github.com/microsoft/vscode/issues/326796](https://github.com/microsoft/vscode/issues/326796)

## Summary

The reported suppression matches the intentional default interaction between inline completions and the suggestion dropdown. The existing editor.quickSuggestions setting allows the dropdown to appear alongside Copilot suggestions.

## Change summary

Allow automatic function and variable suggestions to appear while Copilot is showing inline code.

## Best solution

Keep the configurable completion behavior and explain how to enable editor.quickSuggestions explicitly. No code change is needed for the reported automatic-dropdown behavior.

- **Proposed comment:**

  > Thanks for the report. By default, automatic suggestions are suppressed while inline completions are showing. To keep the function and variable dropdown appearing alongside Copilot, set `"editor.quickSuggestions": "on"` in your settings and leave `"editor.inlineSuggest.suppressSuggestions": false`.
  > 
  > This behavior is configurable and intentional, as explained in https://github.com/microsoft/vscode/issues/316305#issuecomment-5109798770. If the dropdown still fails with these settings, please share the language, a small code example, and whether Ctrl+Space opens it.

- **Current automatic-trigger path:** src/vs/editor/contrib/suggest/browser/suggestModel.ts:424-455 waits for inline completions only when the token's quickSuggestions value is offWhenInlineCompletions; _waitForInlineCompletionsAndTrigger returns without opening the dropdown when an inline suggestion is already showing.
