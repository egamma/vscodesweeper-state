# Issue #309490 — Integrated browser: `document.fullscreenEnabled` is `true` but `requestFullscreen()` will not be resolved/rejected

[https://github.com/microsoft/vscode/issues/309490](https://github.com/microsoft/vscode/issues/309490)

## Summary

Real bug, still present on main: the integrated browser grants the `fullscreen` permission (so `document.fullscreenEnabled` returns `true`) but never handles the Electron `enter-html-full-screen` event, causing `requestFullscreen()` to hang without resolving or rejecting.

## Change summary

Calling `document.body.requestFullscreen()` in the integrated browser returns a Promise that never resolves or rejects, even though `document.fullscreenEnabled` is `true`.

## Best solution

Either handle the `enter-html-full-screen` / `leave-html-full-screen` Electron WebContents events in the BrowserView to actually support fullscreen, or remove `'fullscreen'` from `ALWAYS_ALLOWED_PERMISSIONS` so that `document.fullscreenEnabled` correctly returns `false` and `requestFullscreen()` rejects immediately. The simpler and more honest fix is the latter — remove it from the always-allowed set — unless the team wants to invest in actual fullscreen support for embedded browser views.
