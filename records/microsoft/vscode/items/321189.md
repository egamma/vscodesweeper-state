# Issue #321189 — Inconsistent language for archiving a session

[https://github.com/microsoft/vscode/issues/321189](https://github.com/microsoft/vscode/issues/321189)

## Summary

Confirmed terminology inconsistency between Chat view ("Archive") and Agents Window ("Mark as Done") for the same underlying action. Both surfaces use `isArchived` internally, but the user-facing labels diverge. Team members are discussing alignment — keeping open for a decision.

## Change summary

The Chat view labels the session-dismiss action "Archive" while the Agents Window labels it "Mark as Done"; the filter sections similarly say "Archived" vs "Done".

## Best solution

Align the terminology across both surfaces. The main touch-points are: `src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsActions.ts` (uses "Archive"/"Unarchive"), `src/vs/sessions/contrib/sessions/browser/views/sessionsViewActions.ts` (uses "Mark as Done"), and their respective filter/viewer files. Whichever term the team picks, update the localized strings in both contribution trees so the user sees one consistent label.
