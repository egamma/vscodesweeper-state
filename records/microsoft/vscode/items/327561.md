# Issue #327561 — feat: Standardized Chat Panel Extension API (transcript access, scroll state, overlay decorations)

[https://github.com/microsoft/vscode/issues/327561](https://github.com/microsoft/vscode/issues/327561)

## Summary

A real extension-API gap remains on current main. Keep this recent Backlog Candidate open for community consideration and route it to the API owners.

## Change summary

Expose consent-gated APIs for extensions to inspect, navigate, observe scrolling in, and decorate chat transcripts.

## Best solution

API owners should evaluate a narrowly scoped, provider-aware observation API with explicit consent and privacy boundaries, separately from first-party scrollbar UI. The proposal should account for existing chat-session and output-renderer APIs without exposing unrestricted conversation data by default.
