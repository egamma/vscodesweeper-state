# Issue #227077 — pg up/down inside Ctrl+F

[https://github.com/microsoft/vscode/issues/227077](https://github.com/microsoft/vscode/issues/227077)

## Summary

Keep open: the reporter confirmed the unexpected background scrolling in a clean Edge session and supplied a video. Current source leaves Page Up/Down to native input handling, but does not conclusively establish the scrolling cause; no verified fix or eligible canonical was found.

## Change summary

Alternating Page Up and Page Down in a single-line editor Find query unexpectedly scrolls the background downward.

## Best solution

Preserve the editor viewport while Page Up/Down operates within the focused Find input. Reproduce the clean-browser case and distinguish native ancestor scrolling from editor-command dispatch before changing the find widget or shared scrolling infrastructure.
