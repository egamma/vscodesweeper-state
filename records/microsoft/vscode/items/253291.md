# Issue #253291 — chat.editRequests should not be a user visible setting

[https://github.com/microsoft/vscode/issues/253291](https://github.com/microsoft/vscode/issues/253291)

## Summary

The accepted cleanup remains necessary: `chat.editRequests` is still user-visible and current source retains all four experimental modes. No older open canonical issue owns this work.

## Change summary

Remove the user-visible `chat.editRequests` setting and retain only inline editing of previous chat requests.

## Best solution

Make inline request editing the single supported experience, remove the public configuration and obsolete mode branches, and preserve inline editing's keyboard access, attachments, model, and mode behavior.

- **Reason:** Removing an experimental multi-mode setting favors a simpler, uniform chat interaction while reducing configuration and maintenance overhead.
