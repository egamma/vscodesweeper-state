# Issue #341062 — MCP Servers: warnings about 'gallery' and 'version' are distracting

[https://github.com/microsoft/vscode/issues/341062](https://github.com/microsoft/vscode/issues/341062)

## Summary

Thanks for the report. The migration warnings 'Removes gallery…' and 'Removes version…' are generated from source in getMcpServerMigrationWarnings and are implementation-detail wording. The author is a contributor and states the intended wording (mention that the server will no longer be auto-updated), and no fix has landed. It stays open as polish.

## Change summary

Replace the 'gallery' and 'version' property names in MCP server migration warnings with a user-facing note that the server will no longer be auto-updated, or keep those fields.

## Best solution

Reword the migration warnings so they never mention the property names and only say the server will no longer be updated automatically. Optionally keep 'gallery' and 'version' in the migrated config so update support can be added later.
