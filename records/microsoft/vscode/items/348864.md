## Change summary

Allow the integrated browser to open Copilot-generated HTML and sibling assets from authorized remote session folders.

## Best solution

Establish an authority-scoped, security-reviewed contract for remote file authorization, then integrate it into browser trust-root discovery for remote agent hosts and SSH/WSL windows. Preserve rejection of unauthorized files rather than bypassing trust checks.
