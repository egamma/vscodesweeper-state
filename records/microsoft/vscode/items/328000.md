# Issue #328000 — Autopilot stops on a text-only response without calling task_complete

[https://github.com/microsoft/vscode/issues/328000](https://github.com/microsoft/vscode/issues/328000)

## Summary

This is intentional behavior: standard Autopilot treats a substantive text-only response as completion to avoid wasting additional model turns. Current main and its unit tests explicitly preserve this behavior.

## Change summary

Continue standard Autopilot after text-only responses until the model calls `task_complete`.

## Best solution

Keep the bounded text-only stopping safeguard introduced by https://github.com/microsoft/vscode/pull/312458; goal-classifier-based Advanced Autopilot is the appropriate mechanism for determining whether the underlying task is actually complete.

- **Reason:** More persistent agents support autonomous task completion, but unconditional continuation conflicts with the project's inference-efficiency priority.
- **Evidence:** The current agent-experience priorities emphasize both reliable autonomous execution and reducing unnecessary inference cost.
