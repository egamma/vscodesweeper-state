# Issue #325677 — Setting a send delay for prompts

[https://github.com/microsoft/vscode/issues/325677](https://github.com/microsoft/vscode/issues/325677)

## Summary

A real capability gap remains: chat submissions are dispatched immediately, with no configurable grace period for undoing an accidental send. With no matching older canonical, maintainer signal, or community demand yet, this should remain open as under discussion.

## Change summary

Add a configurable delay before sending a chat prompt, during which the user can cancel the pending submission from the UI or keyboard.

## Best solution

If accepted, provide an optional, disabled-by-default chat send grace period with a visible pending-send state and cancellable command/keybinding, while preserving immediate submission as the default.
