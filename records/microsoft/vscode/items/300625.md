# Issue #300625 — Input/output confirmation cuts off text

[https://github.com/microsoft/vscode/issues/300625](https://github.com/microsoft/vscode/issues/300625)

## Summary

The text-cutoff defect remains on current main: long confirmation messages are clipped at a fixed pixel height with a fade rather than truncated at a complete line with an ellipsis. The maintainer discussion confirms the intended presentation, and no fixing commit references this team-authored issue.

## Change summary

Long input/output confirmation text is cut through a line instead of ending cleanly with a multiline ellipsis.

## Best solution

Make collapsed tool-confirmation messages end on a complete line with a visible ellipsis while preserving the existing Show More behavior and correct rendering for mixed Markdown content.
