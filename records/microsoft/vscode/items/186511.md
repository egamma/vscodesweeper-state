# Issue #186511 — `files.simpleDialog` should be able to create paths

[https://github.com/microsoft/vscode/issues/186511](https://github.com/microsoft/vscode/issues/186511)

## Summary

Folder-only dialogs now offer to create missing paths, including nested folders, but mixed file/folder dialogs still reject them. Keep this team-authored request open: the likely-covering changes do not reference this issue, and the older related issue does not clearly own the same scope.

## Change summary

Allow the simple file dialog to create a nonexistent path interactively or through a setting.

## Best solution

Have the dialog owner reconcile this request with the existing folder-only creation flow and decide whether mixed file/folder pickers must support creation too. Preserve the shipped confirmation-based behavior and track any remaining capability here rather than introducing a redundant setting.
