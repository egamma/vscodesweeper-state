# Issue #327865 — Chat agent debug logging settings (`github.copilot.chat.agentDebugLog.*`) are undiscoverable in Settings search

[https://github.com/microsoft/vscode/issues/327865](https://github.com/microsoft/vscode/issues/327865)

## Summary

Current main confirms that partial-key searches exclude these advanced troubleshooting settings. This team-authored, source-reproducible bug should remain open while maintainers choose between correcting the settings' tags and changing advanced-setting search behavior.

## Change summary

Make Copilot agent debug logging settings discoverable when searching Settings by a partial key such as `agentDebugLog`.

## Best solution

Remove the `advanced` tag from user-facing agent debugging settings if they are intended to be discoverable, or update `SettingsEditor2.shouldShowSetting()` so an advanced setting already matched by search is not discarded solely because the query lacks its full identifier.
