# Issue #318896 — Add "Debug: On Errors"

[https://github.com/microsoft/vscode/issues/318896](https://github.com/microsoft/vscode/issues/318896)

## Summary

A real core debug feature gap remains: VS Code handles diagnostics after a configured pre-launch task, but it has no equivalent policy for diagnostics already published by language extensions. Route this to the debug area for a product decision rather than closing it.

## Change summary

Add a user-level debug policy that can continue, prompt, abort, or reveal Problems when error diagnostics exist before launching.

## Best solution

The debug area should decide whether global diagnostics are a reliable launch gate and define their scope and freshness semantics. If accepted, the behavior should live in the core debug launch flow so diagnostics from any language extension can participate without project tasks.
