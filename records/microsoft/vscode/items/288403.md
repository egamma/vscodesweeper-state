# Issue #288403 — Git Error with Submodule

[https://github.com/microsoft/vscode/issues/288403](https://github.com/microsoft/vscode/issues/288403)

## Summary

The built-in Git extension still has a source-confirmed path that produces an unhandled rejection when an ignore-decoration request fails with IsInSubmodule. Keep this open: the related reports do not provide an open canonical or a fix for the rejection behavior.

## Change summary

Opening a submodule file and reloading the window produces repeated unhandled Git-error promises in the developer console.

## Best solution

Make failed ignore-decoration requests settle without creating an additional unobserved rejection, while preserving genuine error reporting and existing submodule repository selection. Pin the reported failure with a regression test in the Git extension.
