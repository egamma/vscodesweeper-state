# Issue #269610 — Allow granular auto-approval settings for Copilot Chat tools

[https://github.com/microsoft/vscode/issues/269610](https://github.com/microsoft/vscode/issues/269610)

## Summary

The central request — granular per-tool auto-approval with enterprise policy support — has been implemented on main and shipped. The `chat.tools.eligibleForAutoApproval` setting lets users and orgs control which tools are eligible for auto-approval, alongside per-file edit approval and per-URL approval settings.

## Change summary

Allow users to configure auto-approval on a per-tool basis rather than globally, including enterprise policy support.

## Best solution

Keep the shipped `chat.tools.eligibleForAutoApproval` setting (with enterprise policy `ChatToolsEligibleForAutoApproval`), `chat.tools.edits.autoApprove` for file-level edit approval, `chat.tools.urls.autoApprove` for URL-level control, and `chat.permissions.default` for session-level default permission mode. No further change is needed — this can be closed as completed.
