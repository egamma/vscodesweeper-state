# Issue #332135 — minimize menu not being clickable

[https://github.com/microsoft/vscode/issues/332135](https://github.com/microsoft/vscode/issues/332135)

## Summary

Plausible but unconfirmed: a single report on Linux/X11/Cinnamon with a custom title bar describes the native WM window-menu (Minimize/Maximize/Move) not accepting clicks until the window is minimized. No repro confirmation from anyone else and no fixing commit found, so this needs more detail before triage can go further.

## Change summary

Right-clicking the VS Code title bar opens the OS window-management menu (Minimize/Maximize/Move), but its options don't respond to clicks until the VS Code window is minimized via the title bar button.

## Best solution

Ask the reporter whether the issue persists with `"window.titleBarStyle": "native"` (disabling VS Code's custom title bar) — the custom title bar applies `-webkit-app-region: drag` across most of its area (src/vs/workbench/browser/parts/titlebar/media/titlebarpart.css), which is a known class of interaction issue with native WM popups overlapping Electron drag regions on Linux. If it reproduces only with the custom title bar, this likely belongs with titlebar/Electron-drag-region handling; if it also happens with the native title bar, it's more likely an upstream Electron/GTK issue on Cinnamon/X11.
