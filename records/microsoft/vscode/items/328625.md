# Issue #328625 — WorkspaceTrustManagementService.setUrisTrust() resolves before asynchronous Workspace Trust transition completes

[https://github.com/microsoft/vscode/issues/328625](https://github.com/microsoft/vscode/issues/328625)

## Summary

Confirmed in source: `setUrisTrust()` at line 628 of workspaceTrust.ts calls `this.doSetUrisTrust(...)` without `await` or `return`, so the returned promise resolves before the trust transition (participants, persistence, `onDidChangeTrust`) completes. An open PR (#328626) from the same reporter already fixes this with a regression test — keep the issue open and let that PR land rather than auto-fixing here.

## Change summary

WorkspaceTrustManagementService.setUrisTrust() (and transitively setWorkspaceTrust()) resolves before the asynchronous trust transition, including participants and the onDidChangeTrust event, has actually completed.
