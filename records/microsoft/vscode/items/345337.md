# Issue #345337 — Editor window: pass the workspace folder (or offer a folder picker) to workspace remote agent hosts that share the filesystem

[https://github.com/microsoft/vscode/issues/345337](https://github.com/microsoft/vscode/issues/345337)

## Summary

Keep open: editor-window remote sessions still deliberately defer working-directory selection to the host, leaving the shared-filesystem scenario unsupported. The related workspace-host issue describes that default, not the same missing capability.

## Change summary

Allow editor Chat to pass or select a working directory for workspace-configured agent hosts that share the workspace filesystem.

## Best solution

Provide an explicit way to select a host-addressable project directory for new editor-window remote sessions, while preserving host-selected defaults for unrelated filesystems. A maintainer should settle workspace opt-in versus a directory picker before implementation.
