# Issue #345337 — Editor window: pass the workspace folder (or offer a folder picker) to workspace remote agent hosts that share the filesystem

[https://github.com/microsoft/vscode/issues/345337](https://github.com/microsoft/vscode/issues/345337)

## Summary

The shared-filesystem directory-selection gap remains in current source. The earlier workspace-host request deliberately leaves directory choice to the host, and the linked external PR explicitly does not address editor Chat.

## Change summary

Allow editor Chat sessions on shared-filesystem remote agent hosts to receive the workspace directory or an explicitly selected folder.

## Best solution

Provide an explicit directory-selection mechanism for editor Chat remote-host sessions, while preserving host-selected defaults when the filesystems differ. Define the opt-in or picker behavior before implementation.
