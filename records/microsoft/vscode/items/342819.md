# Issue #342819 — Allow staging selection-bound review comments from the regular editor and submitting them together to the current chat

[https://github.com/microsoft/vscode/issues/342819](https://github.com/microsoft/vscode/issues/342819)

## Summary

Keep open as a feature request: existing selection attachments and specialized feedback workflows do not cover staging selection-bound comments from arbitrary files in the regular editor. The reporter explicitly distinguishes this from the Agents window functionality.

## Change summary

Allow users to collect editable, selection-bound feedback across regular editor files and explicitly submit it together to the current chat.

## Best solution

Evaluate a shared workbench feedback workflow that preserves each comment's range and code context, flags stale anchors, and submits only on explicit user action. Reuse the existing feedback concepts without requiring the Agents window or treating a request for explanation as permission to edit.
