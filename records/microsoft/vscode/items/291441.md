# Issue #291441 — Keep new users on the welcome page after chat if not signed in

[https://github.com/microsoft/vscode/issues/291441](https://github.com/microsoft/vscode/issues/291441)

## Summary

Keep open for an onboarding behavior decision: current source still closes the welcome editor and maximizes Chat on submission without checking sign-in completion. This team-authored request has no verified fixing commit or older canonical covering the same sign-in interruption.

## Change summary

Keep welcome actions available when a new user's chat submission requires sign-in, including after dismissing the sign-in dialog.

## Best solution

Make the welcome-to-Chat transition respect incomplete onboarding so a sign-in interruption does not strand new users away from welcome actions. Decide when successful sign-in should trigger navigation, while preserving normal signed-in submissions and supported anonymous chat.
