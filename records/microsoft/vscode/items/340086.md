# Issue #340086 — VS Code BYOK Support in Copilot Chat

[https://github.com/microsoft/vscode/issues/340086](https://github.com/microsoft/vscode/issues/340086)

## Summary

Keep this team-authored BYOK status and architecture overview open: remote Copilot parity and window-independent continuity remain missing. The full body already selects Agent Host-owned model-provider plugins; this umbrella should retain that direction while the implementation work proceeds.

## Change summary

Support Copilot BYOK across remote environments, with models owned by the Agent Host so sessions can continue across clients and run without a connected window.

## Best solution

Deliver the selected plugin-provider architecture with host-owned provider lifecycle and configuration, including credential entry and migration from existing custom endpoints. Track the implementation through https://github.com/microsoft/vscode/issues/340335 while retaining this broader harness-support overview.
