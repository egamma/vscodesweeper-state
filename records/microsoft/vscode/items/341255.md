# Issue #341255 — Keyboard focus is not visible on the “Restart Extensions” button in the Extensions view:A11y_VisualStudioCode_Extensions_Keyboard

[https://github.com/microsoft/vscode/issues/341255](https://github.com/microsoft/vscode/issues/341255)

## Summary

Thanks for the detailed accessibility report. The report is complete: it has steps, a video and the WCAG criterion. I could not confirm the missing focus ring from source alone, so it stays open for a maintainer to retest. The 'Restart Extensions' button is the ExtensionRuntimeStateAction label (`prominent reload` classes). It is styled in extensionActions.css, which sets `outline-offset: 1px` but has no explicit `:focus` rule. Whether a ring appears depends on the global focus-outline styling and on how the button is hosted, which I did not check. The environment line says VS Code 1.41.0, which looks like a typo and should be confirmed against the real build.

## Change summary

The 'Restart Extensions' button in the Extensions view shows no visible keyboard focus indicator (WCAG 2.4.7).

## Best solution

Give the extension action label buttons an explicit `:focus-visible` outline using `--vscode-focusBorder` in extensionActions.css, so the indicator also shows in High Contrast themes. Then check the Welcome page 'Show welcome page on startup' checkbox, which the reporter says has the same problem.
