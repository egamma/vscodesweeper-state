# Issue #251644 — Chat window is not preserved when cloning a repo

[https://github.com/microsoft/vscode/issues/251644](https://github.com/microsoft/vscode/issues/251644)

## Summary

Part 1 (sidebar visibility) was addressed by changing the default of `workbench.secondarySideBar.defaultVisibility` to `visibleInWorkspace` in commit f16a8ea00fb (Aug 2025). Part 2 (preserving chat history across workspace transitions) remains an open design discussion with no resolution — keeping open as under-discussion.

## Change summary

Chat panel disappears and chat history is lost when cloning a repo and opening it in the current window.

## Best solution

The sidebar visibility concern is now resolved by the default change. The remaining gap is a mechanism to carry over active chat sessions during workspace transitions (similar to what `#new` does). A design decision is needed on whether this should be automatic or prompt-based, and which transitions qualify.
