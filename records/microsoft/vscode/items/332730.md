# Issue #332730 — WriteableStream.destroy leaves producers awaiting backpressure writes hung forever

[https://github.com/microsoft/vscode/issues/332730](https://github.com/microsoft/vscode/issues/332730)

## Summary

The pending-write hang is confirmed in current source. Keep this open while the existing fixing PR is reviewed; it has not merged.

## Change summary

Destroying a writeable stream should settle pending backpressure writes so awaiting producers can unwind and release resources.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332731 after confirming rejection handling and preservation of normal buffer-drain behavior. Pending writers should terminate on destruction rather than remain suspended indefinitely.
