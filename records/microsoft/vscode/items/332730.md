# Issue #332730 — WriteableStream.destroy leaves producers awaiting backpressure writes hung forever

[https://github.com/microsoft/vscode/issues/332730](https://github.com/microsoft/vscode/issues/332730)

## Summary

Confirmed real bug in WriteableStream.destroy(): pending backpressure write promises are cleared but never resolved/rejected, hanging producers forever; an open PR already fixes this, so the issue should stay open for that PR to land rather than being closed or auto-fixed.

## Change summary

WriteableStream.destroy() drops pending write() backpressure promises without settling them, permanently hanging any producer awaiting stream.write().

## Best solution

Land https://github.com/microsoft/vscode/pull/332731, which settles pending writes (e.g. by rejecting/erroring them) when the stream is destroyed, mirroring the pattern already used in ResourceQueue.dispose.
