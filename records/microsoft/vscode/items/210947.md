# Issue #210947 — AbstractContextKeyService has been disposed

[https://github.com/microsoft/vscode/issues/210947](https://github.com/microsoft/vscode/issues/210947)

## Summary

This is the canonical tracker for the disposed-ContextKeyService error, still present on main. Other issues (#210994, #246652, #310777) reference or duplicate it, and recent telemetry shows ~49,800 stable users affected in 1.115.0. Keeping open — the bug is real and actively impacting users.

## Change summary

AbstractContextKeyService throws 'has been disposed' when toolbar updates or menu actions fire after the context key service is already disposed, affecting tens of thousands of users.

## Best solution

The root cause is a lifecycle/disposal ordering issue: event listeners (toolbar updates, menu evaluations) fire after the ContextKeyService they depend on has been disposed. The fix likely needs to either guard the callers (toolbar.ts, menuService.ts) against a disposed service, or ensure disposal ordering so dependents are torn down before the ContextKeyService. The error path is still live on main at contextKeyService.ts:291–322.
