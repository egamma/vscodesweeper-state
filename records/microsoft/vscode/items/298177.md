# Issue #298177 — Cancel git clone does not kill the git process

[https://github.com/microsoft/vscode/issues/298177](https://github.com/microsoft/vscode/issues/298177)

## Summary

Keep open: clone cancellation still terminates only the immediate process, allowing Git child processes to survive on Windows. An open PR explicitly targets this issue and should be reviewed before considering completion.

## Change summary

Cancelling Git: Clone dismisses progress while descendant Git processes continue running and holding file resources.

## Best solution

Cancellation should terminate the clone's process tree and release its file handles without affecting unrelated processes. Review https://github.com/microsoft/vscode/pull/309248 against that behavior, including Windows descendant cleanup and safe cross-platform termination.
