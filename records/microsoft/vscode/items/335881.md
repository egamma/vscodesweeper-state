# Issue #335881 — Accidentally clicking off create PR in agents view causes description to be regenerated

[https://github.com/microsoft/vscode/issues/335881](https://github.com/microsoft/vscode/issues/335881)

## Summary

Fresh, team-authored bug report describing a real UX papercut in the Agents view PR-creation flow: clicking outside the create-PR widget while editing the AI-generated description wipes the user's edits. No fix commit exists yet, so this stays open.

## Change summary

Accidentally clicking away from the create-PR panel in the Agents view discards in-progress edits to the AI-generated PR description, which then gets regenerated from scratch.

## Best solution

Investigate the blur/dismiss handling in src/vs/sessions/contrib/changes/browser/createPullRequestWidget.ts and createPullRequestContextView.ts so an outside click preserves (or explicitly confirms discarding) any user edits to the generated description instead of silently regenerating it.
