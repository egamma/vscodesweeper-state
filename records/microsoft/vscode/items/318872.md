# Issue #318872 — Copilot Chat debug file logging omits per-turn events for empty-window chat sessions

[https://github.com/microsoft/vscode/issues/318872](https://github.com/microsoft/vscode/issues/318872)

## Summary

The reported empty-window logging gap was fixed on `main`: debug logs now fall back to global extension storage when workspace storage is unavailable. The merged fix includes regression coverage for writing and later resolving no-workspace session logs.

## Change summary

Copilot Chat debug logging omitted per-turn events when a CLI chat ran in an empty window without a workspace storage URI.

## Best solution

Keep the implementation from commit c0cc2ba1dcd5a77ecbdee6b248d9aca2e951f452, which writes empty-window debug logs under global storage while preserving workspace-scoped storage when a folder is open.
