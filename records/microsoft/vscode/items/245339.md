# Issue #245339 — Diff doesn't recognize matching lines

[https://github.com/microsoft/vscode/issues/245339](https://github.com/microsoft/vscode/issues/245339)

## Summary

Keep open: the current advanced diff algorithm still deliberately absorbs short matching lines into surrounding changes, which explains this example. No existing setting or verified older canonical fully covers the requested improvement.

## Change summary

Preserve meaningful matching lines such as HEIF, VP9, and WebP when comparing short lists against a much longer list.

## Best solution

Improve the advanced diff post-processing so meaningful isolated list entries can remain aligned without broadly abandoning the heuristics that suppress incidental matches in code. The diff-editor owner should establish the desired matching policy using this exact example.
