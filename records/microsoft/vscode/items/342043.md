# Issue #342043 — User mcp.json shows trailing-comma warnings despite MCP schema explicitly allowing them

[https://github.com/microsoft/vscode/issues/342043](https://github.com/microsoft/vscode/issues/342043)

## Summary

Keep open: current main associates the MCP schema with workspace mcp.json files but omits user-level files. This leaves the reported file using generic JSONC validation, which warns about trailing commas.

## Change summary

User-level mcp.json should receive the built-in MCP schema and accept trailing commas without warnings.

## Best solution

Make built-in MCP schema association consistent for user configuration files, including named profiles, while preserving generic JSONC trailing-comma warnings and existing workspace associations.
