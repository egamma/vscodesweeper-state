# Issue #342043 — User mcp.json shows trailing-comma warnings despite MCP schema explicitly allowing them

[https://github.com/microsoft/vscode/issues/342043](https://github.com/microsoft/vscode/issues/342043)

## Summary

Thanks for the detailed report. The suspicion in the report is right: the MCP schema is only associated with workspace `/.vscode/mcp.json`, and nothing associates it with the user-profile `mcp.json`, so its `allowTrailingCommas` is never applied there.

## Change summary

Trailing-comma warnings show in the user-level mcp.json even though the MCP schema allows trailing commas.

## Best solution

Add a schema association for the user/profile `mcp.json` (via `%APP_SETTINGS_HOME%/mcp.json`) in the configuration-editing extension's `jsonValidation`, so the user file gets the same schema and trailing-comma behavior as the workspace file.

## Plan brief

- **Likely files:** `extensions/configuration-editing/package.json`
- **Validation:** Manual: in a dev build, open the user profile mcp.json (and a non-default profile's mcp.json). Trailing commas should produce no warning, and schema completions and validation should work.
- **Behavior:**

  > Opening the user-level (and profile-level) mcp.json in JSON with Comments mode applies the MCP schema. Trailing commas and comments produce no warnings, and schema hover, completion and validation work as in `.vscode/mcp.json`. The workspace behavior is unchanged.
- **Trace:**

  > extensions/configuration-editing/package.json `jsonValidation` has `/.vscode/mcp.json` -> `vscode://schemas/mcp` only. The schema is registered in src/vs/workbench/contrib/mcp/browser/mcp.contribution.ts. Other user-level files use the `%APP_SETTINGS_HOME%/<file>` pattern, e.g. `tasks.json`. An entry for `%APP_SETTINGS_HOME%/mcp.json` is the likely fix. Not yet checked: whether the placeholder resolves for non-default profile folders. Do not change the schema or the json language server defaults.

## Evidence

- **schema allows commas:** src/vs/workbench/contrib/mcp/common/mcpConfiguration.ts:344-350: mcpServerSchema sets allowTrailingCommas and allowComments.
- **only workspace association:** extensions/configuration-editing/package.json (jsonValidation, ~line 127) maps only `/.vscode/mcp.json` to `vscode://schemas/mcp`. A grep of src and extensions for `schemas/mcp` finds no association for the user/profile file. The same block has `%APP_SETTINGS_HOME%/tasks.json` for the user tasks file, but no matching mcp entry.
- **why warnings appear:** extensions/json-language-features/server/src/jsonServer.ts:407 defaults trailingCommas to 'warning' for jsonc documents. A schema-level allowTrailingCommas is the only thing that suppresses it, and no schema is matched for the user file.
