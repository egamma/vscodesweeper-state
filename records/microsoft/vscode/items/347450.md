# Issue #347450 — Git: Revert Selected Ranges unexpectedly repositions editor viewport upward

Keep open: a maintainer confirmed the viewport jump in current Insiders, and the implicated whole-document replacement and reveal remain on main. The report is already correctly routed to Git.

## Change summary

Reverting selected Git changes unexpectedly scrolls the editor upward even when document layout and cursor position are unchanged.
