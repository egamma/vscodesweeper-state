# Issue #166886 — Opening walkthroughs automatically feels jarring

[https://github.com/microsoft/vscode/issues/166886](https://github.com/microsoft/vscode/issues/166886)

## Summary

Team-authored UX discussion about walkthrough auto-opening behavior that remains valid — the default is still `true` and the core jarring-experience concern (especially multiple walkthroughs opening simultaneously) is not fully resolved by the existing mitigations.

## Change summary

Installing extensions that contribute walkthroughs can cause one or more walkthrough tabs to auto-open unexpectedly, creating a jarring experience.

## Best solution

Revisit the default for `workbench.welcomePage.walkthroughs.openOnInstall` or replace the auto-open with a less intrusive notification (as suggested in the comments). At minimum, limit to a single walkthrough opening at once. The relevant logic is in `src/vs/workbench/contrib/welcomeGettingStarted/browser/gettingStartedService.ts` around line 441.
