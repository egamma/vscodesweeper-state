# Issue #166886 — Opening walkthroughs automatically feels jarring

[https://github.com/microsoft/vscode/issues/166886](https://github.com/microsoft/vscode/issues/166886)

## Summary

Keep open for a focused onboarding decision: current code mitigates automatic walkthrough opening but still enables it by default. The existing opt-out does not settle this team-authored request about the default experience and competing walkthroughs.

## Change summary

Make extension-install walkthrough discovery less disruptive and decide whether multiple walkthroughs should open automatically.

## Best solution

Agree on a less disruptive default for extension-install onboarding, including whether walkthroughs require explicit user intent and how competing contributions are handled. Retain explicit walkthrough access and the existing opt-out while evaluating the notification entry point suggested in the discussion.
