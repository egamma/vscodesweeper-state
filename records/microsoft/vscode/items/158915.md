# Issue #158915 — Shared noise for different cases

[https://github.com/microsoft/vscode/issues/158915](https://github.com/microsoft/vscode/issues/158915)

## Summary

The requested distinction remains absent on current main: “No Inlay Hints” still uses the error sound. This team-authored accessibility request should remain open.

## Change summary

Use a distinct, non-error accessibility sound when the current line has no inlay hints.

## Best solution

Add a dedicated informational/no-action sound in the accessibility signal media and map `AccessibilitySignal.noInlayHints` to it instead of `Sound.error`.
