# Issue #158915 — Shared noise for different cases

[https://github.com/microsoft/vscode/issues/158915](https://github.com/microsoft/vscode/issues/158915)

## Summary

The requested distinction is still missing: current source uses error.mp3 for both errors and the no-inlay-hints result. Keep this team-authored request open; the discussion supports distinct feedback, and no verified canonical or completed fix supersedes it.

## Change summary

Use a non-error sound when Read Line with Inlay Hints finds no hints on the current line.

## Best solution

Preserve affirmative feedback when the command finds no hints, but distinguish that informational result from an actual error. Confirm the proposed No Action Available sound with the accessibility owner rather than expanding this into general sound theming.
