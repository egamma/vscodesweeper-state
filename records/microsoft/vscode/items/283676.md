## Summary

Valid feature request from a team member to support dragging notebook cells into the chat input as context attachments. No implementation found on current main — the chat input's drop handling does not recognize notebook cells, and no commits reference this issue. Keeping open.

## Change summary

Allow dragging notebook cells into the chat input widget to attach them as context references.
