# Issue #283676 — Add the ability to drag notebook cells to attach as context in chat

[https://github.com/microsoft/vscode/issues/283676](https://github.com/microsoft/vscode/issues/283676)

## Summary

Keep open: dragging a notebook cell into chat still lacks the transfer payload and attachment handling needed to reference that cell. Existing output attachments do not cover the request, and a maintainer explicitly endorsed the capability.

## Change summary

Allow dragging a notebook cell into the chat input to attach a reference without manually finding its cell number.

## Best solution

Support cell-reference attachments through notebook-to-chat drag and drop while preserving notebook cell reordering and existing output attachments. Establish how the attachment identifies the cell and what context it supplies to the agent.

Confirm that the gesture does not move or delete cells, ordinary notebook reordering still works, and existing cell-output attachments remain unchanged.
- **Behavior:**

  > Dragging a notebook cell into the chat input should attach a reference to that cell without requiring the user to count cells or type a number. The submitted request should give the agent enough context to address the referenced cell. Attaching context must not modify the notebook, and existing notebook reordering and output attachment behavior must remain intact.
- **Trace:**

The local chat source and GitHub main notebook source establish the missing producer-to-consumer connection; runtime behavior was not exercised.
