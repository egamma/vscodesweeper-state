# Issue #322714 — Add option to automatically suppress Copilot inline completions during merge conflict resolution

[https://github.com/microsoft/vscode/issues/322714](https://github.com/microsoft/vscode/issues/322714)

## Summary

Keep open as a feature request: existing controls disable suggestions manually or by language, but do not provide automatic conflict-aware suppression and restoration. No verified canonical issue owns this request.

## Change summary

Add an option to suppress Copilot inline completions in unresolved-conflict files and the Merge Editor, restoring them automatically afterward.

## Best solution

Provide an opt-in, conflict-aware suppression policy within the built-in Copilot/editor integration, covering both ordinary files with conflict markers and Merge Editor sessions without changing users' normal completion preferences.
