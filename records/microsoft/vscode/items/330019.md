# Issue #330019 — Chat sticky scroll: No ellipsis in banner to indicate multi-line prompt

[https://github.com/microsoft/vscode/issues/330019](https://github.com/microsoft/vscode/issues/330019)

## Summary

Confirmed in source: the prompt-timeline sticky header's preview text only appends an ellipsis when the first line itself exceeds the length cap, but never when the prompt has additional lines beyond the first — so a short first line of a multi-line prompt renders with no visual cue that more text follows.

## Change summary

The chat sticky-scroll banner shows only the first line of a multi-line prompt with no ellipsis/indicator that the prompt continues onto more lines.

## Best solution

In `getPromptPreview` (src/vs/workbench/contrib/chat/browser/promptTimeline/promptTimelineModel.ts), append the truncation ellipsis whenever the original text contains more than one non-empty line, not only when the first line exceeds `MAX_PREVIEW_LENGTH`.
