# Issue #336105 — Smart window reuse: seamlessly accept files/folders in multi-root workspace windows from external tools

[https://github.com/microsoft/vscode/issues/336105](https://github.com/microsoft/vscode/issues/336105)

## Summary

The file-opening portion already works on current main, but opening a folder that is one root of an existing multi-root workspace still lacks equivalent matching. This remains a valid window-management feature request and should be routed to the workbench window area.

## Change summary

Reuse an existing multi-root workspace window when an external CLI or URL request opens a file or folder contained by that workspace.

## Best solution

Preserve the existing multi-root-aware file routing and extend folder-opening requests to recognize folders contained in an open workspace without changing behavior for unrelated folders.
