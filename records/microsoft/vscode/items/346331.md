# Issue #346331 — Support running and managing VS Code workspace tasks from Agents

[https://github.com/microsoft/vscode/issues/346331](https://github.com/microsoft/vscode/issues/346331)

## Summary

Keep open for the newly started Backlog Candidates community review. Existing task-running infrastructure provides partial coverage, but does not establish that Agents can discover and manage workspace tasks through agent tools.

## Change summary

Allow Copilot in Agents to discover, run, monitor, stop, and rerun workspace tasks while retaining terminal execution.

## Best solution

If accepted, provide session-aware task tools that preserve workspace-task execution semantics, output/status visibility, and normal approval controls. Reuse existing task infrastructure rather than treating shell-command execution as equivalent.
