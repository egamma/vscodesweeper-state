## Change summary

Clicking a subsession in the sessions list causes the list to visually jump instead of staying stable.

## Best solution

Have the sessions-area owner review `syncActiveChatSelection` in src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts, which does `this.tree.expand(session); this.tree.reveal(chatItem, 0.5);` on active-chat sync — expanding the parent then re-centering the revealed row is a likely cause of the perceived jump; decide whether centering-on-click is intended or should be softened (e.g. only reveal if not already visible).
