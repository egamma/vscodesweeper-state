# Issue #298998 — [Feature Request] Show source location for custom prompts and skills in the prompt picker (parity with agents)

[https://github.com/microsoft/vscode/issues/298998](https://github.com/microsoft/vscode/issues/298998)

## Summary

Valid feature request from a team member. The prompt/skill picker currently shows source location only in the tooltip (hover), not inline in the picker item like the agent picker does. The feature gap remains on current main.

## Change summary

Show the source file path or origin (workspace/user/extension) inline in the slash-command picker for prompts and skills, matching how custom agents display their source.

## Best solution
