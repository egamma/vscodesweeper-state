# Issue #298998 — [Feature Request] Show source location for custom prompts and skills in the prompt picker (parity with agents)

[https://github.com/microsoft/vscode/issues/298998](https://github.com/microsoft/vscode/issues/298998)

## Summary

The source-identification gap remains in the current slash picker: prompt and skill entries display their names and descriptions, but not their file paths or storage origins. Keep this team-authored request open; the related issues address different surfaces or capabilities.

## Change summary

Show the defining file path or workspace/user/extension origin beside custom prompt and skill entries in the chat slash picker.

## Best solution

Give prompt and skill completions a consistent secondary source indication while preserving their descriptions and invocation behavior. Existing command metadata already exposes file URIs and storage origins, so the remaining work belongs in the chat input completion presentation.
