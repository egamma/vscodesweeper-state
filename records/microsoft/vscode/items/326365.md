# Issue #326365 — Expensive fetch in Copilot code search for repo tracking

[https://github.com/microsoft/vscode/issues/326365](https://github.com/microsoft/vscode/issues/326365)

## Summary

The unnecessary background fetch is still present, but the older, open issue https://github.com/microsoft/vscode/issues/257583 already reports this same operation on large repositories. Consolidate this report there, preserving its explanation of dry-run network costs.

## Change summary

Avoid expensive Git fetch operations when Copilot code search only needs to resolve repository identity through SSH configuration.

## Best solution

Resolve repository identity without downloading repository objects, while preserving custom SSH alias support. Track that change in https://github.com/microsoft/vscode/issues/257583, which already requests replacing this exact metadata-discovery fetch.
