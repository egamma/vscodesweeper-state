# Issue #190749 — Restored terminals in editor area don't restore the current working directory from the previous session.

[https://github.com/microsoft/vscode/issues/190749](https://github.com/microsoft/vscode/issues/190749)

## Summary

Keep open: the clarified Remote-SSH, multi-root reproduction supplies enough detail to retest, and current source still contains a plausible remote-only restoration defect. The restoration code now exposes revived-process ID lookup, but remote editor restoration bypasses it; no verified post-reopen fix or eligible older canonical was found.

## Change summary

Restored terminal editors should retain their previous working directory instead of taking the workspace folder associated with the focused editor.

## Best solution

Make remote terminal-editor restoration reconnect to the correct persisted or revived process, preserving its working directory independently of editor focus. First reproduce the reported multi-root SSH restart and establish whether the failure is incorrect process attachment or loss of directory state.
