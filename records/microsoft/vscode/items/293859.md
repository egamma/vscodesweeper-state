# Issue #293859 — Agent fails to monitor background terminal state, causing redundant re-deployment

[https://github.com/microsoft/vscode/issues/293859](https://github.com/microsoft/vscode/issues/293859)

Keep open: terminal execution now has synchronous completion and background notifications, but these changes do not prove that the agent stops issuing duplicate deployments. The supplied build-then-deploy steps suffice to retest; a maintainer already identified tool-prompt guidance as the intended direction.

## Change summary

Prevent the agent from starting a second deployment while the deployment it already acknowledged is still running.

## Best solution

Ensure terminal tool instructions and running-command results consistently guide the agent to follow the existing execution through completion rather than launch it again. First reproduce the deployment sequence on current main and distinguish model instruction-following from missing or contradictory terminal-state guidance.
