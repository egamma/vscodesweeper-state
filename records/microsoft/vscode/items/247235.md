# Issue #247235 — Deleting JSX tag name and then typing a different tag name doesn't update closing tag

[https://github.com/microsoft/vscode/issues/247235](https://github.com/microsoft/vscode/issues/247235)

## Summary

The linked-editing session still ends when an opening tag name is completely deleted, and a contributor confirmed the same behavior in plain HTML. Keep the issue open while the directly linked fix PR is reviewed.

## Change summary

Preserve linked editing after an opening HTML or JSX tag name is fully deleted so typing its replacement updates the closing tag.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/304957 after adding regression coverage that fully deletes and retypes a linked tag name, including the reported tag-with-attributes case.
