[https://github.com/microsoft/vscode/issues/333974](https://github.com/microsoft/vscode/issues/333974)

## Summary

This combines a request for clarification with three distinct, already-understood profile behaviors: the Agents Window intentionally uses its own internal profile, the Default Profile cannot be deleted, and removing Default-profile folder associations is separately tracked in an open backlog issue.

## Change summary

Clarify why the Agents Window ignores the configured new-window profile and why the Default Profile and its folder associations cannot be deleted.

## Best solution

Keep the dedicated Agents profile and non-deletable Default Profile unless those product decisions change, while consolidating the remaining folder-association usability work in https://github.com/microsoft/vscode/issues/243017.
