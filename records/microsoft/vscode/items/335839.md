# Issue #335839 — Marking a running automation as Done does not stop its session

[https://github.com/microsoft/vscode/issues/335839](https://github.com/microsoft/vscode/issues/335839)

## Summary

Freshly filed, team-authored bug report; tracing the code confirms the described gap — marking a session/automation as Done only archives it without first stopping its in-flight request, so this stays open pending a fix.

## Change summary

Marking a running automation as Done archives it but leaves its underlying session actively running instead of stopping it first.

## Best solution

In SessionsManagementService.archiveSession (src/vs/sessions/services/sessions/browser/sessionsManagementService.ts), cancel/stop the session's active request (the same mechanism used by cancelCurrentRequestForSession) before delegating to the provider's archiveSession, so 'Mark as Done' always leaves no running work behind.
