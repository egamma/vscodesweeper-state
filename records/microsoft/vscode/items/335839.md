# Issue #335839 — Marking a running automation as Done does not stop its session

[https://github.com/microsoft/vscode/issues/335839](https://github.com/microsoft/vscode/issues/335839)

## Summary

Confirmed on main and by a second team member's independent repro (not just automations): `SessionsManagementService.archiveSession` flips the archived flag via the provider but never stops the underlying running request, so a session marked Done keeps working. Team-authored (MEMBER), so this stays keep-open per the protected-authorship rule regardless of severity; no fix commit exists to cite.

## Change summary

Marking a session (or automation) as Done archives it without cancelling its still-running request.

## Best solution

In `SessionsManagementService.archiveSession` (src/vs/sessions/services/sessions/browser/sessionsManagementService.ts), cancel the session's in-flight request (the existing `cancelCurrentRequest` path already used elsewhere) when its status is active before/while archiving, so the visible Done state matches reality.
