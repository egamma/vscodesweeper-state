# Issue #335839 — Marking a running automation as Done does not stop its session

[https://github.com/microsoft/vscode/issues/335839](https://github.com/microsoft/vscode/issues/335839)

## Summary

Confirmed from source: SessionsManagementService.archiveSession only calls the provider's archiveSession, never cancels the in-flight request, so marking a session Done leaves it running — a second maintainer reproduced the same behavior with a normal (non-automation) session.

## Change summary

Marking a running automation/session as Done archives it but does not stop its still-running chat session.

## Best solution

Have archiveSession() cancel the active request (via the existing cancelCurrentRequest path) when the session's status is active before/while archiving, in sessionsManagementService.ts.
