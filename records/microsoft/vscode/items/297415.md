## Summary

The setting description for `git.addAICoAuthor` still doesn't clarify it only applies to commits made from the Source Control view. The PR that attempted to fix this (#309134) was closed without merging, and no other fix has landed.

## Change summary

The `git.addAICoAuthor` setting description should clarify it only applies to commits made through the VS Code UI, not CLI commits.
