[https://github.com/microsoft/vscode/issues/173520](https://github.com/microsoft/vscode/issues/173520)

## Summary

The central request remains valid: the Debug Console already uses an editor, but it intentionally overrides or omits parts of the normal editor configuration. A maintainer explicitly expressed interest in applying more of the listed settings, and no canonical issue or completed implementation is identified.

## Change summary

Make Debug Console input behavior more consistent with regular editors by honoring additional editor settings such as auto-closing, auto-surround, and empty-selection clipboard behavior.

## Best solution

Define which regular editor settings are appropriate for REPL input, then apply those settings through the Debug Console input editor while preserving runtime-provided completions and other debugger-specific behavior.
