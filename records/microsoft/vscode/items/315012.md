# Issue #315012 — Feature Request: Manual Refresh Button for Agent Plugin Marketplaces

[https://github.com/microsoft/vscode/issues/315012](https://github.com/microsoft/vscode/issues/315012)

## Summary

The manual refresh capability now exists, but only as a Command Palette command; the requested discoverable refresh control beside configured marketplaces remains a real UI gap. Route this feature request to the agent plugins area rather than closing it as implemented.

## Change summary

Expose a manual refresh button in the Agent Plugins UI for configured plugin marketplaces.

## Best solution

Expose the existing `workbench.agentPlugins.refreshMarketplaces` operation from the marketplace-management UI, with the control's all-marketplaces or per-marketplace scope made clear while preserving the Command Palette entry.
