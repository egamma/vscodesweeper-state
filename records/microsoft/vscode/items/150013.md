# Issue #150013 — VS Code blocks Windows from shutting down when there is an update or confirm dialog

[https://github.com/microsoft/vscode/issues/150013](https://github.com/microsoft/vscode/issues/150013)

## Summary

Keep open: multiple users independently confirmed that pending updates block Windows shutdown, including a March 2026 report. Current source contains shutdown-aware installer safeguards, but those do not establish that the reported shutdown timeout or confirmation-dialog case is resolved.

## Change summary

Prevent pending VS Code updates and exit confirmation dialogs from causing Windows shutdown to stall or abort.

## Best solution

Establish which process blocks Windows session termination and ensure the update handoff respects shutdown without leaving an incomplete installation. Investigate confirmation dialogs separately and preserve recovery of unsaved work rather than adopting unconditional force termination.
