# Issue #349374 — Copilot Agent Host: support restarting one plugin MCP server in the current session

[https://github.com/microsoft/vscode/issues/349374](https://github.com/microsoft/vscode/issues/349374)

## Summary

Session-scoped MCP lifecycle controls already exist for AHP clients, but they do not establish the requested agent-callable restart contract with safe tool-call boundaries and explicit completion results. Keep this open as a feature request; operator-driven Stop/Start is only partial coverage.

## Change summary

Provide controlled restart of one plugin MCP server in an existing Copilot session, adopting an installed update without operator intervention or a shared Agent Host restart.

## Best solution

Define a supported caller and completion contract around the existing session-scoped lifecycle controls, preserving in-flight replies and runtime trust, permissions, and enablement. Establish whether installed plugin changes can be adopted by restarting only the target server rather than recreating the session runtime.
