# Issue #85418 — Disable overview ruler entirely

[https://github.com/microsoft/vscode/issues/85418](https://github.com/microsoft/vscode/issues/85418)

## Summary

Keep open: current workbench configuration still prevents disabling the overview ruler entirely, and the existing workarounds only partially cover the request. An open PR explicitly targets this issue; review that implementation rather than starting competing work.

## Change summary

Provide a supported setting to hide the editor overview ruler entirely while retaining normal scrollbar behavior.

## Best solution

Deliver a supported overview-ruler off mode that suppresses all its markers without disabling their underlying editor features. Review https://github.com/microsoft/vscode/pull/223118 against that requirement, including extension decorations and the notebook limitations reported in the thread.
