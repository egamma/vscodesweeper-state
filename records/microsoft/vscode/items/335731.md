# Issue #335731 — Restart to Update prompts once per window for active agent sessions

[https://github.com/microsoft/vscode/issues/335731](https://github.com/microsoft/vscode/issues/335731)

## Summary

Fresh, well-described UX report from a VS Code team member (hediet) about the shutdown confirmation flow for active agent sessions during Restart to Update; no fix has landed yet and the issue is already correctly labeled and routed, so it stays open.

## Change summary

Restart to Update currently prompts an 'active session' confirmation separately in every window that has a running local agent session, instead of a single app-level confirmation (or none, given the explicit restart intent).

## Best solution

In the shutdown-confirmation path (likely near onWillShutdown in src/vs/workbench/electron-browser/window.ts and the agents-window sessions management service), special-case ShutdownReason for update/restart so the per-window active-session confirmation is either skipped or consolidated into a single app-level prompt, while leaving quit/last-window-close/workspace-change/reload confirmations untouched.
