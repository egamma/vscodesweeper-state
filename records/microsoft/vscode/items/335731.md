# Issue #335731 — Restart to Update prompts once per window for active agent sessions

[https://github.com/microsoft/vscode/issues/335731](https://github.com/microsoft/vscode/issues/335731)

## Summary

The per-window confirmation path remains present: Restart to Update reaches each window as an ordinary quit, and active local sessions independently trigger confirmation. Keep this correctly routed issue open; the requested update-specific behavior is not implemented.

## Change summary

Avoid repeated active-session confirmations across windows during Restart to Update without weakening ordinary shutdown protections.

## Best solution

Distinguish an explicit update restart from ordinary shutdown throughout the lifecycle path so it does not produce per-window active-session prompts. Preserve existing protections and unrelated shutdown vetoes, and keep updater process-ordering changes outside this issue.
