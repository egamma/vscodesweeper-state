# Issue #331293 — Add setting to persist Screencast Mode (settings.json)

[https://github.com/microsoft/vscode/issues/331293](https://github.com/microsoft/vscode/issues/331293)

## Summary

Verified on main: Screencast Mode has only appearance settings (`screencastMode.fontSize`, `.mouseIndicatorColor`, etc. in developerActions.ts) — there is no `enabled`/on-off setting, and `ToggleScreencastModeAction` is a purely in-memory, static-disposable toggle with no persisted state across restarts or profiles. The request is a real, unimplemented gap.

## Change summary

Add a `workbench.screencastMode.enabled` setting so Screencast Mode's on/off state can be stored per profile in settings.json and persists across restarts.

## Best solution

Add a boolean configuration key (e.g. `screencastMode.enabled`) alongside the existing `screencastMode.*` settings in src/vs/workbench/browser/actions/developerActions.ts, and have the workbench read it on startup (and react to config changes) to enable/disable the overlay, instead of only exposing an ephemeral toggle action.
