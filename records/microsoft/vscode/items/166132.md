# Issue #166132 — Git - No prompt for SSH passphrase using remote-ssh

[https://github.com/microsoft/vscode/issues/166132](https://github.com/microsoft/vscode/issues/166132)

## Summary

Keep open: the discussion confirms missing SSH credential prompts in remote Git operations, and current troubleshooting documentation still acknowledges this limitation. Neither a concrete fix nor an open canonical owning this precise case was verified.

## Change summary

Remote Git push, pull, and fetch should prompt for a protected SSH key's passphrase instead of failing or waiting without a prompt.

## Best solution

Ensure explicit Git operations in remote workspaces can reach the built-in SSH passphrase prompt. Diagnose the remote Git process environment and askpass invocation before deciding whether the remaining defect belongs to built-in Git or Remote-SSH; terminal use and ssh-agent configuration are workarounds, not proof that prompting is fixed.
