# Issue #344742 — Flat File Explorer

[https://github.com/microsoft/vscode/issues/344742](https://github.com/microsoft/vscode/issues/344742)

## Summary

Keep open as a feature request: the screenshot asks for a single-directory browser with parent navigation, not compact folder rendering. Current Explorer settings do not cover that interaction, and the related folder-scoping request does not establish a duplicate.

## Change summary

Offer an optional single-directory File Explorer with navigation into folders, back to their parents, and keyboard support.

## Best solution

Evaluate an optional directory-browsing mode that preserves the workspace while showing only the current directory's immediate children. Decide whether this belongs in the built-in Explorer or an extension-provided view; folder scoping alone does not deliver the requested interaction.
