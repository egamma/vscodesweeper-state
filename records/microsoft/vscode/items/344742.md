# Issue #344742 — Flat File Explorer

[https://github.com/microsoft/vscode/issues/344742](https://github.com/microsoft/vscode/issues/344742)

## Summary

Keep this request in the existing Backlog Candidates community-review process. The screenshot asks for browsing one directory at a time, which current Explorer settings do not provide; no matching open canonical was verified.

## Change summary

Offer an optional single-directory Explorer with parent-folder navigation and keyboard support instead of an expanding folder tree.

## Best solution

Evaluate a single-directory browsing mode in the file Explorer if community interest supports it, preserving the existing tree as the default. Compact folders and keyboard file search are partial navigation aids, not substitutes for the requested browsing model.
