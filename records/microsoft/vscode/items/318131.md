# Issue #318131 — memory-tool invoked even though Copilot chat memory is disabled.

[https://github.com/microsoft/vscode/issues/318131](https://github.com/microsoft/vscode/issues/318131)

## Summary

Valid request: the team intentionally removed the `github.copilot.chat.tools.memory.enabled` setting in cf21e2032aa (2026-05-11), making the memory tool always-on with no user-facing disable mechanism. The issue asks for a way to opt out, which is a real gap — especially for enterprise users needing policy control.

## Change summary

Provide a setting or mechanism to completely disable the built-in memory tool so it cannot be invoked by the model.

## Best solution

Re-introduce a user/admin setting (or a `when` clause gated on configuration) that prevents the memory tool from being offered to models when disabled. The tool registration in `extensions/copilot/package.json` could add a `"when": "config.github.copilot.chat.tools.memory.enabled"` clause, and `memoryContextPrompt.tsx` should skip injecting memory instructions when the setting is off. Enterprise policy support (comment 1) would also be valuable.
