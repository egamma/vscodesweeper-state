# Issue #316410 — Implement a policy-settings mechanism for approving/blocking agent market-places

[https://github.com/microsoft/vscode/issues/316410](https://github.com/microsoft/vscode/issues/316410)

## Summary

The enterprise marketplace-control capability is implemented on main through ChatExtraMarketplaces and ChatStrictMarketplaces, rather than the requested ChatPluginsMarketplaces name. These policies supply managed sources and restrict marketplace discovery without replacing personal settings.

## Change summary

Allow enterprise administrators to supply approved agent plugin marketplaces and block discovery from other sources through policy.

## Best solution

Use ChatExtraMarketplaces to supply enterprise sources and ChatStrictMarketplaces to allow only approved sources; close this capability request as completed rather than introduce a redundant policy on chat.plugins.marketplaces. Keep the separate native-MDM object-format defect tracked independently.
