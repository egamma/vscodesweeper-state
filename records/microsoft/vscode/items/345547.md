# Issue #345547 — Worktree cleanup: What are 'Unknown' entries

[https://github.com/microsoft/vscode/issues/345547](https://github.com/microsoft/vscode/issues/345547)

## Summary

Keep open as worktree-cleanup UX polish: unknown age and storage are intentional for sessionless worktrees, but the report identifies an explanation gap. Using file modification time instead requires a decision about what “Last Used” means.

## Change summary

Make unknown worktree metadata and completed cleanup rows understandable, and consider a meaningful timestamp for worktrees without sessions.

## Best solution

Clearly distinguish unavailable session history from unmeasured disk usage and completed removal in the cleanup editor. Decide whether filesystem timestamps provide useful, accurately labeled information without implying session activity.

  - Should sessionless worktrees retain unknown Last Used with a clearer explanation, or expose a separately defined filesystem-modification timestamp; if the latter, what activity should that timestamp represent?
