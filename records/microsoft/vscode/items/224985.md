# Issue #224985 — Respect `editor.scrollbar.vertical/horizontal` in chat code blocks

[https://github.com/microsoft/vscode/issues/224985](https://github.com/microsoft/vscode/issues/224985)

## Summary

Chat code blocks still do not inherit the editor scrollbar visibility settings: their editor options omit the configuration values and ignore subsequent changes. Keep this open in panel-chat; the source confirms the reported gap.

## Change summary

Make chat code blocks respect editor.scrollbar.horizontal and editor.scrollbar.vertical.

## Best solution

Honor the configured scrollbar visibility when creating and updating chat code-block editors, while preserving explicit per-render overrides and existing scrolling and layout behavior.
