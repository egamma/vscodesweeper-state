# Issue #224985 — Respect `editor.scrollbar.vertical/horizontal` in chat code blocks

[https://github.com/microsoft/vscode/issues/224985](https://github.com/microsoft/vscode/issues/224985)

## Summary

Still reproduces on main: chat code block editors hardcode `scrollbar: { vertical: 'hidden' }` and the `IChatResultEditorOptions` interface does not include scrollbar settings, so user `editor.scrollbar.*` configuration is ignored.

## Change summary

Chat code blocks ignore the user's `editor.scrollbar.vertical` and `editor.scrollbar.horizontal` settings.

## Best solution

Extend `IChatResultEditorOptions` and `ChatEditorOptions` to read `editor.scrollbar.vertical` and `editor.scrollbar.horizontal` from configuration, and apply them when constructing the code block editor in `codeBlockPart.ts` — similar to how `wordWrap`, `fontLigatures`, etc. are already forwarded from config.
