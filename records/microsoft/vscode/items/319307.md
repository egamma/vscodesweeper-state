# Issue #319307 — Dragging already opened chat session view highlights half of view, not full view

[https://github.com/microsoft/vscode/issues/319307](https://github.com/microsoft/vscode/issues/319307)

## Summary

This remains a valid, source-confirmed Agents Window polish issue. Current main always displays a half-view insertion target even when the dragged session is the target itself and the eventual drop is intentionally a no-op; the maintainer comment also explicitly says the feedback needs adjustment.

## Change summary

Make the session drag overlay highlight the full existing view when dragging a visible session onto itself, while retaining half-view indicators for actual side-by-side insertion.

## Best solution

Keep the lightweight drag implementation but make its feedback match the resulting layout: show a full-view indicator for a self-drop and left/right half indicators only when the drop can insert or move another session.
