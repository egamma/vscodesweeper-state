# Issue #314405 — Copy-button from a code-block does not work while agent is still running

[https://github.com/microsoft/vscode/issues/314405](https://github.com/microsoft/vscode/issues/314405)

## Summary

Plausible bug with no fix on main: during streaming, the code block toolbar's copy button may fail to write to the clipboard due to DOM detach/reattach cycles or context timing. The visibility fix (7c4cbc79dc3) addressed the visual aspect but not the functional click/clipboard issue.

## Change summary

Clicking the copy button on a chat code block during streaming does not update the clipboard; it only works after the response completes.

## Best solution

The copy action reads `context.code` from the toolbar context set by `updateContexts()` in `codeBlockPart.ts`. During streaming DOM detach/reattach, the click event may be swallowed or the toolbar context may be stale. The fix should ensure the copy action defensively reads from the current text model at invocation time, or that the toolbar context is guaranteed fresh across reattachment cycles. The likely file is `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/codeBlockPart.ts`.
