# Issue #246507 — Offer "danger" (orange) style between "warning" (yellow) and "error" (red)

[https://github.com/microsoft/vscode/issues/246507](https://github.com/microsoft/vscode/issues/246507)

## Summary

Keep this accepted, well-supported request open: current diagnostic styling cannot distinguish lint errors from type-checking errors without changing their reported severity. The remaining question is whether that distinction should introduce a semantic severity or a separate presentation mechanism.

## Change summary

Offer an additional diagnostic color tier between warning and error so lint errors can be visually distinguished from type-checking errors.

## Best solution

Provide a consistent, themeable way to distinguish these diagnostics without misrepresenting their severity. Agree on the diagnostic/API contract first, including whether the distinction represents severity or provenance and how it appears beyond editor squiggles.
