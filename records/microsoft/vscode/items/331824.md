# Issue #331824 — Chat tab should have access to and be able to update Comments from PR code review directly.

[https://github.com/microsoft/vscode/issues/331824](https://github.com/microsoft/vscode/issues/331824)

## Summary

The request is for the GitHub Pull Requests extension's PR review comments/Comments tab to be exposed to chat/agent tools — that functionality lives in the separate microsoft/vscode-pull-request-github extension, not in vscode core, so this belongs there rather than being resolved in this repo.

## Change summary

Give the chat/agent tooling direct read/write access to PR review comments (the Comments tab) so it can navigate to, resolve, and reply to review threads instead of scraping GitHub via less reliable means.

## Best solution

Move/refile this against microsoft/vscode-pull-request-github, which owns the Comments tab, PR review-thread model, and any chat participant/tool surface for PRs; a maintainer there can decide whether resolving threads should be exposed as a chat tool.
