# Issue #331824 — Chat tab should have access to and be able to update Comments from PR code review directly.

[https://github.com/microsoft/vscode/issues/331824](https://github.com/microsoft/vscode/issues/331824)

## Summary

Keep open as an integration feature request: existing GitHub Pull Requests tools cover reading and resolving PR threads, but do not establish coverage of the requested provider-independent Comments workflow, replies, and account consistency. No verified older canonical owns the full request.

## Change summary

Let Chat work through IDE comment threads with code context, reply to and resolve them, and synchronize PR-backed changes using the appropriate account.

## Best solution

Establish the remaining Comments-to-Chat capability gap against the existing PR tools, then define a provider-aware integration that preserves thread identity and synchronizes supported actions. Keep the original comments workflow separate from the later debugger, authentication, and model-management requests.
