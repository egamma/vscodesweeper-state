# Issue #331915 — Automation X failed: Agent session failed should reveal the failed session

[https://github.com/microsoft/vscode/issues/331915](https://github.com/microsoft/vscode/issues/331915)

## Summary

Keep open: current automation failure notifications still lack a navigation action, while opening a run from automation history only partially addresses the request. Execution has moved into the Agent Host, so the notification-to-run association needs tracing against that lifecycle before implementation.

## Change summary

Allow an automation failure notification to open the specific failed session.

## Best solution

Provide an explicit action on an automation failure notification that opens its associated session without automatically stealing focus or selecting a different run. Preserve useful error reporting when failure occurs before any session exists.
