# Issue #334234 — SQL Language Mode  - auto inserting "EXECUTE " on (copy and) paste

[https://github.com/microsoft/vscode/issues/334234](https://github.com/microsoft/vscode/issues/334234)

## Summary

VS Code's built-in `sql` extension (extensions/sql) contains only a TextMate grammar and language-configuration.json (brackets/comments/folding) — no formatter, paste handler, or logic that could insert an `EXECUTE` keyword or reflow a pasted statement. The reporter's extension list includes `ms-mssql.mssql` (SQL Server), which provides T-SQL-aware formatting/format-on-paste; that third-party formatter is the far more likely source of this transformation.

## Change summary

Pasting SQL text (or saving) in SQL language mode causes text to be auto-reformatted, inserting the word "EXECUTE" and reflowing multi-line statements/comments incorrectly.

## Best solution

Ask the reporter to reproduce with all non-core extensions (especially ms-mssql.mssql) disabled; if it only occurs with mssql enabled, file it against https://github.com/microsoft/vscode-mssql (or the ms-mssql.mssql marketplace listing) since that extension owns SQL formatting behavior — core's SQL language contribution has no such logic.
