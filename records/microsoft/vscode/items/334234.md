# Issue #334234 — SQL Language Mode  - auto inserting "EXECUTE " on (copy and) paste

[https://github.com/microsoft/vscode/issues/334234](https://github.com/microsoft/vscode/issues/334234)

## Summary

The behavior described (SQL text reformatted and an `EXECUTE` keyword inserted on paste/save) is not something VS Code's built-in `sql` extension does — it only ships a TextMate grammar and language-configuration file, with no formatter or paste transform. The reporter's extension list includes `ms-mssql.mssql` (SQL Server / MSSQL extension), which provides SQL formatting including format-on-save, and this is the well-known source of statement reformatting like this.

## Change summary

Pasting (or saving) SQL text in SQL language mode gets reformatted and has an `EXECUTE` keyword inserted in front of statements, including reflowing multi-line comments.

## Best solution

Point the reporter at the MSSQL extension's own tracker (microsoft/vscode-mssql) since its SQL formatter/format-on-save is the actual source of the reformatting and EXECUTE insertion — VS Code core's built-in sql extension has no such logic.
