# Issue #334234 — SQL Language Mode  - auto inserting "EXECUTE " on (copy and) paste

[https://github.com/microsoft/vscode/issues/334234](https://github.com/microsoft/vscode/issues/334234)

## Summary

The behavior (auto-inserting `EXECUTE`, reordering comments in a SQL statement on paste/save) is SQL-formatting logic that isn't part of VS Code core — the built-in `sql` extension only ships a grammar and basic language-configuration, no formatter or paste provider. The reporter's extension list shows the SQL Server (mssql) extension installed, which is the likely source of this transformation.

## Change summary

Pasting (or saving) SQL text in a file with SQL language mode causes unwanted reformatting — inserting an `EXECUTE` keyword and moving inline comments — that undo restores correctly.

## Best solution

File this against the ms-mssql/vscode-mssql extension repository, which owns SQL formatting/paste behavior for `.sql` files; core VS Code has no SQL formatter to fix here.
