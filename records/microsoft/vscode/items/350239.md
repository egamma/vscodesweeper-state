# Issue #350239 — Default account service misses account changes that arrive during its first lookup

[https://github.com/microsoft/vscode/issues/350239](https://github.com/microsoft/vscode/issues/350239)

## Summary

The startup race remains in current main: account-change listeners are installed after the first asynchronous lookup, and a signed-out result has no automatic recovery. Keep this team-authored issue open for a bounded initialization fix.

## Change summary

Account changes during the initial default-account lookup can be lost, leaving a starting window incorrectly signed out.

## Best solution

DefaultAccountProvider initialization should converge on account changes received during its initial lookup, covering session, preference, remembered-account, and provider changes without requiring another event or reload.
