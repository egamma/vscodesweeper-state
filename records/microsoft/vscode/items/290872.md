# Issue #290872 — Cloud Session: Checkout and Apply still show when checking out the branch

[https://github.com/microsoft/vscode/issues/290872](https://github.com/microsoft/vscode/issues/290872)

## Summary

Keep open for state-aware cloud-session actions: current toolbar contributions do not establish that Checkout responds to the branch already being checked out. A maintainer explicitly consolidated the repeated-Apply report here, and no verified fixing commit or older same-symptom canonical was found.

## Change summary

Make cloud-session Checkout and Apply actions reflect checkout/application state and offer appropriate follow-up PR actions.

## Best solution

Make the cloud-session toolbar reflect the selected session's actual repository and PR state, avoiding redundant checkout or application while retaining useful follow-up actions. Settle hiding versus disabling with the maintainer, and coordinate additional PR actions with the related merge-action request rather than treating it as a duplicate.
