# Issue #131655 — [UI/UX] problem with disassembly page.

[https://github.com/microsoft/vscode/issues/131655](https://github.com/microsoft/vscode/issues/131655)

## Summary

The visual defect remains represented in current source: the instruction highlight is painted on a child element while the focus outline spans the complete table row. The issue was reopened after maintainers clarified the intended behavior, and no post-reopen commit explicitly fixes it, so this team-authored Backlog issue should remain open.

## Change summary

Make the disassembly current-instruction background fill the instruction portion of the row without extending into the breakpoint gutter or leaving a bottom gap.

## Best solution

Ensure the stack-frame highlight covers the full height of the disassembly instruction cell at custom editor font sizes while retaining the unhighlighted breakpoint gutter and its contrast.
