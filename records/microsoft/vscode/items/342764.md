# Issue #342764 — Agents ssh error

[https://github.com/microsoft/vscode/issues/342764](https://github.com/microsoft/vscode/issues/342764)

## Summary

The reported shell mismatch remains in current source: the Agents SSH installer sends POSIX variable-assignment syntax directly to the remote login shell. Keep this open as a core Agent Host bootstrap bug; the report supplies enough detail to diagnose it without requesting more information.

## Change summary

Agents-window SSH bootstrap fails with "Illegal variable name" when the remote login shell is tcsh, despite bash being available.

## Best solution

The Agents SSH bootstrap should run its POSIX snippets under a compatible interpreter independently of the remote login shell, allowing installation and connection without changing the user's shell. Preserve existing CLI reuse, fallback, and agent-launch behavior.
