# Issue #342764 — Agents ssh error

[https://github.com/microsoft/vscode/issues/342764](https://github.com/microsoft/vscode/issues/342764)

## Summary

The reported shell mismatch remains in current main: the Agents SSH installer sends POSIX assignments directly to the remote login shell. Keep this open; the existing Bash wrapper applies to agent startup, not the failing CLI installation.

## Change summary

Agents-window SSH bootstrap fails with "Illegal variable name" on a Linux host whose login shell is tcsh, despite Bash being available.

## Best solution

Ensure the Agents SSH bootstrap executes its POSIX scripts under a compatible interpreter without requiring users to change their login shell. Preserve existing CLI reuse, fallback, and agent-startup behavior.
