# Issue #342764 — Agents ssh error

[https://github.com/microsoft/vscode/issues/342764](https://github.com/microsoft/vscode/issues/342764)

## Summary

The reported shell mismatch remains in current main: the Agents SSH installer sends POSIX command substitution directly to the remote login shell. Keep this open as a core Agents connection bug; the report supplies sufficient details and does not need another information request.

## Change summary

Make Agents-window SSH bootstrap work with a tcsh login shell when a compatible sh/bash interpreter is available.

## Best solution

The Agents SSH bootstrap should execute its shell-dependent installation and maintenance commands with a compatible interpreter, without requiring users to change their login shell. Preserve existing CLI reuse, fallback, and connection behavior.
