# Issue #312113 — Remote Tunnels: 401 Unauthorized with Microsoft Account - "Anonymous has scopes []"

[https://github.com/microsoft/vscode/issues/312113](https://github.com/microsoft/vscode/issues/312113)

## Summary

Still a valid open bug: the CLI `code tunnel` command accepts `--provider microsoft` but Microsoft auth tokens are not fully supported by the dev tunnels API, resulting in 401 errors. PR #316300 removed the Microsoft auth option from the workbench UI but did not address the CLI path. Multiple users confirmed the issue, and a team member assigned it but no fix has landed for the CLI.

## Change summary

Using `code tunnel user login --provider microsoft` produces a token with empty scopes, causing the tunnel API to reject the request with 401 Unauthorized ('Anonymous has scopes []').

## Best solution

Either fix Microsoft auth end-to-end for the tunnel API, or remove/deprecate the `--provider microsoft` option from the CLI (as was done for the workbench UI in PR #316300). The CLI auth provider list in `cli/src/auth.rs` still includes `AuthProvider::Microsoft` — at minimum, a clear error or documentation is needed. The assignees (@joshspicer, @deepak1556) should decide on the path forward.
