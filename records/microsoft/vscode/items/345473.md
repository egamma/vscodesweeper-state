# Issue #345473 — Agents: Cloud workspace picker offers Open Folder, which always fails

[https://github.com/microsoft/vscode/issues/345473](https://github.com/microsoft/vscode/issues/345473)

## Summary

Keep open: the inspected main source still offers local-folder browsing in Cloud and can reject a GitHub checkout before its repository metadata resolves. No qualifying fixing commit or canonical duplicate was found.

## Change summary

Prevent Cloud's workspace picker from offering a dead-end local-folder selection with an unhelpful rejection.

## Best solution

Make Cloud workspace selection reflect actual eligibility, including pending GitHub repository discovery, and provide actionable repository-picker guidance for unsupported folders. Preserve the existing intended support for GitHub-backed local checkouts rather than treating every local folder as inherently incompatible.
