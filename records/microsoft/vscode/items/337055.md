# Issue #337055 — Modern UI ignores sideBarSectionHeader.background

[https://github.com/microsoft/vscode/issues/337055](https://github.com/microsoft/vscode/issues/337055)

## Summary

Traced in source: Modern UI's `paneHeaders.css` deliberately overrides the pane header background with `sideBar.background`/`panel.background` (`!important`) so headers blend into the sidebar/panel body at rest, rather than honoring `sideBarSectionHeader.background` — this is documented intent, not an oversight.

## Change summary

With `workbench.experimental.modernUI` enabled, a custom `sideBarSectionHeader.background` color is not applied to Side Bar section headers.

## Best solution

Keep the current Modern UI behavior — its README explicitly lists only `sideBarSectionHeader.border` as an honored override for section dividers, and the CSS comment explains headers are meant to match the surrounding surface, not a tinted strip. If the design should change, that's a product call for the Modern UI module owners, not a straightforward bug fix.

- **overriding rule:** src/vs/workbench/contrib/modernUI/browser/media/paneHeaders.css lines 82-88: `.modern-ui :is(.part.sidebar, .part.auxiliarybar) .monaco-pane-view .pane > .pane-header { background-color: var(--vscode-sideBar-background) !important; }` — this unconditionally overrides any pane-header background, including the section header's, with the sidebar's background.
