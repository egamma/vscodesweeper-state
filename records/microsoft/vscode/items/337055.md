# Issue #337055 — Modern UI ignores sideBarSectionHeader.background

[https://github.com/microsoft/vscode/issues/337055](https://github.com/microsoft/vscode/issues/337055)

## Summary

Confirmed intentional in the Modern UI CSS: the pane header background is force-set to `sideBar.background` so headers blend with the surrounding surface, and only `sideBarSectionHeader.border` is honored for the divider line — `sideBarSectionHeader.background` is deliberately not applied.

## Change summary

With `workbench.experimental.modernUI` enabled, `sideBarSectionHeader.background` no longer colors side bar section headers (e.g. Explorer/Outline).

## Best solution

Keep current Modern UI behavior — its README should continue to document that side bar section headers use `sideBar.background` plus `sideBarSectionHeader.border` only, not `sideBarSectionHeader.background`, so theme authors know which token to customize.

  > Thanks for the report. This is intentional in Modern UI: `src/vs/workbench/contrib/modernUI/browser/media/paneHeaders.css` (lines 82-84) deliberately overrides the section header background with `sideBar.background !important` so headers blend into the side bar body instead of showing a tinted strip — only `sideBarSectionHeader.border` is honored there, as documented in the Modern UI README. `sideBarTitle.background` is a separate token for the top-level title and isn't affected. Closing as as-designed, but feel free to open a follow-up if you'd like Modern UI to expose a distinct header background override.
