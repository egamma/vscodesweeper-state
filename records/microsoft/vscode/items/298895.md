# Issue #298895 — Reverse double-click bracket selection direction

[https://github.com/microsoft/vscode/issues/298895](https://github.com/microsoft/vscode/issues/298895)

## Summary

Keep open: current source still creates forward selections from either delimiter, and a maintainer explicitly endorsed tracking the direction improvement separately. The existing block-selection setting does not address selection direction.

## Change summary

Reverse the selection when double-clicking next to an opening bracket or quote so the active cursor stays at the clicked end.

## Best solution

Make delimiter-content selection preserve the clicked end as the active cursor: backward selection from the opening side and forward selection from the closing side, without changing which text is selected.
