# Issue #181571 — Improved visual image diffing in source control

[https://github.com/microsoft/vscode/issues/181571](https://github.com/microsoft/vscode/issues/181571)

## Summary

Keep open: the bundled image preview still lacks overlap or difference-highlighting modes, and custom-editor diff infrastructure does not itself deliver that capability. The accepted Backlog request needs a product decision about the image-comparison experience, not a staleness close.

## Change summary

Provide image-comparison modes that make subtle changes visible when reviewing source-control diffs.

## Best solution

Provide an opt-in image-comparison experience through custom-editor diff support, preserving ordinary side-by-side previews. Decide whether the bundled Media Preview extension supplies it and which comparison mode meets the request before implementation.

- **Behavior:**

  > Users reviewing image changes in Source Control need to identify subtle differences that separate previews make difficult to see. - **Trace:**

  > In extensions/media-preview/src/imagePreview/index.ts, ImagePreviewManager resolves individual custom documents and ImagePreview passes one src into its webview; extensions/media-preview/media/imagePreview.js renders a single image.
