# Issue #306021 — Copilot Continue back to Local missing

[https://github.com/microsoft/vscode/issues/306021](https://github.com/microsoft/vscode/issues/306021)

## Summary

Reverse handoff from a Copilot CLI session to the in-place Local provider is intentionally unsupported: current code explicitly excludes Local from Continue In targets, and a later maintainer-approved change reinforced that policy.

## Change summary

Add a Continue In Local option that carries a completed Copilot CLI worktree conversation back into the original local workspace.

## Best solution

Keep Continue In as a one-way handoff from Local to delegated execution providers; users who want to resume local execution should use a separate Local chat rather than retargeting the CLI session.

- **Fit:** aligned
- **Reason:** Smoother movement between local and delegated AI workflows is thematically aligned, although the requested reverse handoff conflicts with the current session model.
- **Evidence:** Durable themes: AI-assisted development and the developer inner loop.

  > Thanks for the report. Continue In is intentionally limited to delegated execution targets: Local is explicitly excluded by the current picker and provider capability code, consistent with https://github.com/microsoft/vscode/pull/323649. Returning a Copilot CLI session to Local within the same conversation is therefore not part of the current session model.

## Evidence

- **current source:** src/vs/workbench/contrib/chat/browser/agentSessions/agentSessions.ts explicitly returns false for `getAgentCanContinueIn(AgentSessionProviders.Local)`; the associated test asserts that Local cannot be a Continue In target.
- **picker policy:** src/vs/workbench/contrib/chat/browser/widget/input/delegationSessionPickerActionItem.ts states that the Sessions window must never offer the plain Local target and filters it from the Continue In picker.
- **maintainer precedent:** The merged, maintainer-approved https://github.com/microsoft/vscode/pull/323649 is titled “Hide Local from Continue In list of session types” and deliberately aligned the handoff picker with the product's Local visibility policy.
