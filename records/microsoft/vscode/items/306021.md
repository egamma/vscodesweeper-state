# Issue #306021 — Copilot Continue back to Local missing

[https://github.com/microsoft/vscode/issues/306021](https://github.com/microsoft/vscode/issues/306021)

## Summary

Feature request: the "Continue in..." dropdown currently offers Background, Cloud, and agent-host targets but does not offer "Local" as a return target from a CLI/Background session. This is a new capability, not a bug in existing behavior.

## Change summary

After a Copilot CLI (Background) session finishes with a worktree, add an option to continue the conversation back in Local mode.

## Best solution

Add `AgentSessionProviders.Local` as a "Continue In" target in `ChatContinueInSessionActionItem.actionProvider()` (in `src/vs/workbench/contrib/chat/browser/actions/chatContinueInAction.ts`) when the current session is a non-Local agent session. This would let users bring the context back to the local chat after a background session completes. The existing `getAgentCanContinueIn` already returns `true` for `Local`, so the plumbing partially exists — the UI action provider just doesn't expose it.
