# Issue #312908 — Chat model picker hides BYOK models when their `metadata.id` collides with another vendor's model

[https://github.com/microsoft/vscode/issues/312908](https://github.com/microsoft/vscode/issues/312908)

## Summary

Confirmed on current main: `buildModelPickerItems` in `chatModelPicker.ts` still adds bare `metadata.id` to the `placed` set (line 627) and filters `otherModels` by it (line 794), hiding BYOK models whose upstream id collides with a Copilot model. An open community PR (#312910) addresses it.

## Change summary

BYOK models with a `metadata.id` matching another vendor's model are incorrectly hidden from the chat model picker.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/312910 (or an equivalent fix): stop adding bare `metadata.id` to the `placed` set and filter `otherModels` by `identifier` only, so models from different vendors with the same upstream id coexist in the picker.
