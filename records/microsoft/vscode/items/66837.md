# Issue #66837 — Windows uninstaller should have option to also remove user data dir and extensions dir

[https://github.com/microsoft/vscode/issues/66837](https://github.com/microsoft/vscode/issues/66837)

## Summary

Still unimplemented on main: the Windows uninstaller (Inno Setup, build/win32/code.iss) only removes the PATH entry — no checkbox or option to delete user data or extensions directories. The feature request remains valid.

## Change summary

Add an option in the Windows uninstaller to optionally remove user data and extensions directories.

## Best solution

Add a checkbox to the Inno Setup uninstaller script (build/win32/code.iss) offering to remove %APPDATA%\Code and %USERPROFILE%\.vscode on uninstall, defaulting to unchecked for safety. This is a straightforward Inno Setup task in the [UninstallDelete] or CurUninstallStepChanged procedure.
