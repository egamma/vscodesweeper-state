# Issue #206643 — Git - Source Control tab doesn't respect global .gitignore for Git repositories

[https://github.com/microsoft/vscode/issues/206643](https://github.com/microsoft/vscode/issues/206643)

## Summary

Keep open: the Windows status mismatch has an independent confirmation, and neither a concrete fix nor a matching canonical was established. Current source delegates ignore handling to Git, so the next step is to diagnose why the extension and terminal observe different results.

## Change summary

Source Control lists files excluded by global core.excludesFile even when terminal git status reports a clean repository.

## Best solution

Make Source Control agree with Git's effective ignore configuration for the same repository, executable, and environment. First reproduce the Windows discrepancy and distinguish configuration or environment differences from stale status updates; do not introduce a separate ignore implementation.
