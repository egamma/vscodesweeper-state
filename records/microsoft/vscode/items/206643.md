# Issue #206643 — Git - Source Control tab doesn't respect global .gitignore for Git repositories

[https://github.com/microsoft/vscode/issues/206643](https://github.com/microsoft/vscode/issues/206643)

## Summary

The git extension calls `git status` which natively respects `core.excludesfile`, but the file watcher only monitors changes inside the repository — global gitconfig/gitignore edits outside the repo won't trigger a refresh. One commenter confirmed it works on macOS after a reload. The claim that it persists across restarts is unconfirmed by others and may be environment-specific. The milestone is On Deck (a holding bin), so it's eligible for normal triage. Keeping open as the core complaint — that live changes to global git config aren't picked up — is plausible from the code.

## Change summary

Source Control view doesn't update when the global `core.excludesfile` git configuration is changed outside the repository.

## Best solution

The git extension's file watcher (in `extensions/git/src/repository.ts`) only watches inside the repo root and `.git` directory. To pick up changes to `core.excludesfile` or global `.gitconfig`, the extension could either watch the global gitconfig path or expose a manual 'Refresh' command more prominently. A pragmatic fix: ensure that window focus or a manual refresh re-runs `git status` to pick up external config changes.
