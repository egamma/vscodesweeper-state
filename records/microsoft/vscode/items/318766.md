# Issue #318766 — Chat input: Look into number of dropdowns and interactive vs. plan mode

[https://github.com/microsoft/vscode/issues/318766](https://github.com/microsoft/vscode/issues/318766)

## Summary

Keep this team-authored UX exploration open: current source includes a combined mode-and-permissions picker, but that conditional capability does not establish completion of the broader dropdown-consolidation and Interactive/Plan design question. Later maintainer discussion explicitly supports further UX iteration.

## Change summary

Explore consolidating chat-input dropdowns and clarifying the relationship between agent selection and Interactive/Plan modes.

## Best solution

Have the chat-input owners assess the existing combined picker against this exploration and settle a coherent interaction model for agent selection, session modes, and permissions. Preserve their distinct meanings while making planning discoverable without requiring knowledge of slash commands.
