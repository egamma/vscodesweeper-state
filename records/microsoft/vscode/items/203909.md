# Issue #203909 — Wrong Webview View tab order / keyboard navigation order

[https://github.com/microsoft/vscode/issues/203909](https://github.com/microsoft/vscode/issues/203909)

## Summary

Verified duplicate: this reports the same Tab-key-can't-reach-webview-view problem that was fixed by PR #321468 (commit 992db109271) and closed as #314974. The fix shipped in 1.126.0.

## Change summary

Tab key cannot reach webview view content in the sidebar because the iframe overlay lives outside the normal DOM tab order.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/314974 — the fix (tabbable proxy container that forwards focus into the webview overlay) already shipped in 1.126.0 and directly resolves this report.
