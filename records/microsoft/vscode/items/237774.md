# Issue #237774 — "Find in Selection" toggle in text search is broken

[https://github.com/microsoft/vscode/issues/237774](https://github.com/microsoft/vscode/issues/237774)

## Summary

The defect remains in current main: Find in Selection snapshots the selection when enabled and does not refresh its search scope when the user subsequently changes the selection.

## Change summary

Find in Selection reports results for a stale selection and may replace the user's current selection when disabled.

## Best solution

Keep this older, deterministic report as the canonical issue and update the editor-find implementation so an explicit user selection can replace the stored search scope without confusing find-driven cursor movement for a new scope. Consolidate newer reports such as https://github.com/microsoft/vscode/issues/250617 here.
