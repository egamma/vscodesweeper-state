# Issue #296871 — Feature Request: First-class support for ephemeral / workspace-independent tasks

[https://github.com/microsoft/vscode/issues/296871](https://github.com/microsoft/vscode/issues/296871)

## Summary

Valid team-authored feature request, already labeled under-discussion. The sessions/agents infrastructure on main does not yet implement a workspace-independent or ephemeral session mode — the concept of launching a session without a meaningful workspace directory, bypassing trust prompts, and dynamically discovering repos mid-session remains an open gap.

## Change summary

Support ephemeral, workspace-independent Copilot sessions that don't require a workspace trust prompt or a fixed working directory.

## Best solution

Design a session mode in the Agents window (src/vs/sessions/) that can launch without a workspace folder, skip workspace trust for such sessions, and allow dynamic repo discovery mid-session. The related issue https://github.com/microsoft/vscode/issues/303018 (Sessions: Unclear how to initialize new project) overlaps on the 'no workspace at start' scenario but is narrower — both should be considered together.
