# Issue #350699 — postDebugTask runs twice when a debug session linked to a test run ends before the test run

[https://github.com/microsoft/vscode/issues/350699](https://github.com/microsoft/vscode/issues/350699)

## Summary

The reported race remains source-reproducible on current main: completing a correlated test run after adapter shutdown can re-enter session cleanup and launch the postDebugTask again. Keep this open for a bounded debug-session lifecycle fix.

## Change summary

Prevent duplicate postDebugTask execution and termination notifications when a correlated test run completes after its debug adapter exits.

## Best solution

Make end-of-session handling occur once per adapter lifecycle, including when correlated test completion overlaps postDebugTask startup. Preserve test cancellation, abnormal adapter-exit recovery, and session restart behavior.
