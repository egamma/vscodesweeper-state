## Summary

Detailed report of a hardcoded X-GitHub-Api-Version header breaking the model list on GHES, but a maintainer just asked (same day) whether the reporter is actually on GHES or GHE Cloud — since Copilot support differs between the two, that answer determines whether this is a real core bug or an unsupported configuration; the existing info-needed label is correct as-is.

## Change summary

On a GHES instance, every models.list request is rejected with 400 because the bundled Copilot SDK/extension code sends a future X-GitHub-Api-Version value the server doesn't support, leaving the model picker empty.
