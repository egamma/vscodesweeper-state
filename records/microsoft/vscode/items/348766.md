# Issue #348766 — Copilot Agent Host picker shows BYOK models marked isUserSelectable: false

[https://github.com/microsoft/vscode/issues/348766](https://github.com/microsoft/vscode/issues/348766)

## Summary

Confirmed in current source: the BYOK bridge loses provider selectability, and the host copy explicitly marks every model selectable. Keep open to restore picker parity without removing explicitly addressed models.

## Change summary

Honor extension-provided isUserSelectable: false in the Copilot Agent Host model picker while preserving explicit model resolution.

## Best solution

Preserve the provider's selectability intent when publishing bridged models, independently of catalogue membership and request routing. Cover ordinary picker exclusion alongside existing-session and utility-model resolution.
