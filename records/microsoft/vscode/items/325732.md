## Summary

The reporter describes a consistent failure to start Copilot Agent sessions, with GitHubLoginFailed and session-commit timeout errors despite valid auth and network. The report is detailed but no other users have confirmed it, and an open external PR (#325955) references this issue — keeping open pending investigation and PR review.

## Change summary

Copilot Agents window fails to create sessions, throwing GitHubLoginFailed and 'Timed out waiting for session commit' even when GitHub auth and network are healthy.

## Best solution

A maintainer should investigate whether the Copilot Student entitlement is properly recognized by the Agents session flow (the GitHubLoginFailed path in extensions/copilot/src/platform/authentication/ and the session-commit timeout in src/vs/sessions/contrib/providers/copilotChatSessions/browser/copilotChatSessionsProvider.ts). The open PR https://github.com/microsoft/vscode/pull/325955 should be reviewed for correctness — it may or may not address the root cause. If the Copilot Student plan simply isn't entitled for Agents sessions, the issue should be closed as *as-designed with a clear explanation.
