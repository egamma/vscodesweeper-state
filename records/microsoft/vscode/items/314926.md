# Issue #314926 — `Prompt input` merging command output with command.

[https://github.com/microsoft/vscode/issues/314926](https://github.com/microsoft/vscode/issues/314926)

## Summary

The prompt input model merges command output with the command text during long-running commands on bash/Linux, causing 'Copy command' to include output. The issue is reproducible per the reporter's videos and not fixed on current main. Related tracking issue https://github.com/microsoft/vscode/issues/317789 explicitly lists this as a symptom.

## Change summary

Terminal 'Prompt input' incorrectly includes command output text alongside the command, and 'Copy command' copies both command and output on bash/Fedora Linux with rich shell integration.

## Best solution

The root cause likely lives in the `PromptInputModel` sync logic (`src/vs/platform/terminal/common/capabilities/commandDetection/promptInputModel.ts`) misreading buffer lines during output — it needs better command-boundary guards when output is actively being written. The broader shell integration parity work tracked in https://github.com/microsoft/vscode/issues/317789 may subsume this for agent host terminals, but the local terminal path needs its own fix.
