# Issue #167306 — Gutter for local history modification

[https://github.com/microsoft/vscode/issues/167306](https://github.com/microsoft/vscode/issues/167306)

## Summary

This remains the canonical, community-promoted request for local-history gutter markers. Current main exposes local history through the Timeline but does not connect it to quick-diff gutter decorations.

## Change summary

Show resettable editor gutter markers for changes relative to local history when no Git repository is present.

## Best solution

Add a local-history quick-diff provider backed by IWorkingCopyHistoryService, with explicit baseline/reset and workspace-reopen semantics, while reusing the existing SCM quick-diff decoration infrastructure.
