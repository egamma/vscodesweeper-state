# Issue #331732 — platformIO build process - permission error

[https://github.com/microsoft/vscode/issues/331732](https://github.com/microsoft/vscode/issues/331732)

## Summary

The permission error happens inside PlatformIO's own build tooling (SCons/Python) invoked by the third-party PlatformIO IDE extension, not in any VS Code core component; this is not a VS Code defect.

## Change summary

Building a PlatformIO/Tasmota project inside the VS Code integrated terminal fails with a Python PermissionError writing a generated .cpp file, while the same build succeeds outside VS Code in PowerShell.

## Best solution

Report this to the PlatformIO IDE extension (platformio.platformio-ide) issue tracker — the failure originates in platformio's SCons build script (builder/main.py) trying to write tasmota.ino.cpp, likely due to a file lock/AV/permission conflict specific to how the task runs in VS Code's integrated terminal, not VS Code itself.
