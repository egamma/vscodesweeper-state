# Issue #193792 — Python + Juptyer recommendations shouldn't appear in a workbench without a gallery service

[https://github.com/microsoft/vscode/issues/193792](https://github.com/microsoft/vscode/issues/193792)

## Summary

The debt remains on current main: the notebook kernel picker still exposes Marketplace actions without checking gallery availability and still hardcodes the Python/Jupyter recommendation.

## Change summary

Suppress notebook extension recommendations when no gallery exists and move distro-specific kernel recommendations out of core source.

## Best solution

Gate kernel installation and Marketplace choices on the extension gallery manifest status, then source kernel recommendations from product or distribution contributions instead of `notebookBrowser.ts`.

- **Fit:** aligned
- **Reason:** Distribution-controlled recommendations keep core generic while respecting environments where extension installation is unavailable.
