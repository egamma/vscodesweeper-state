# Issue #313962 — Add `Assisted-by` instead of `Co-authored-by` for AI agents

[https://github.com/microsoft/vscode/issues/313962](https://github.com/microsoft/vscode/issues/313962)

## Summary

Keep this accepted feature request open: current Git integration still generates a fixed Co-authored-by trailer, not the requested Assisted-by attribution. The request has 77 upvotes, maintainer support, and no verified canonical duplicate or linked implementation PR.

## Change summary

Use an Assisted-by trailer for AI contributions, including agent and model identity, instead of treating AI tools as human co-authors.

## Best solution

Provide accurate, opt-in AI assistance attribution in the built-in Git integration while preserving human co-author trailers. Agree on the replacement and compatibility semantics, and coordinate model metadata with https://github.com/microsoft/vscode/issues/297353.

- **Trace:**

  > In extensions/git/src/repository.ts, appendAICoAuthorTrailer uses git.addAICoAuthor to select eligible contributions and appends the hard-coded AI_CO_AUTHOR_TRAILER. extensions/git/package.json exposes only off, chatAndAgent, and all, not a trailer format. The _aiEdits.hasAiContributions command in src/vs/workbench/contrib/editTelemetry/browser/aiContributionFeature.ts returns only a boolean, so the traced Git interface does not supply model identity; the availability and retention of richer provenance remain to be investigated. - **Open decisions:**
  - Should Assisted-by replace the AI-generated Co-authored-by trailer for all users who enable attribution, or should the existing format remain selectable?
