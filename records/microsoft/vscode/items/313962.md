# Issue #313962 — Add `Assisted-by` instead of `Co-authored-by` for AI agents

[https://github.com/microsoft/vscode/issues/313962](https://github.com/microsoft/vscode/issues/313962)

## Summary

Valid feature request with strong community support (64 upvotes, already in Backlog). The current `git.addAICoAuthor` setting hardcodes `Co-authored-by: Copilot <copilot@github.com>` — this asks for an `Assisted-by` trailer format option following the Linux kernel convention. No implementation exists on main.

## Change summary

Add support for the `Assisted-by` git commit trailer format (following the Linux kernel convention) as an alternative to the current hardcoded `Co-authored-by` trailer for AI-assisted commits.

## Best solution

Extend the `git.addAICoAuthor` setting (or add a sibling setting like `git.aiCommitTrailerFormat`) to let users choose between `Co-authored-by` and `Assisted-by` trailer formats. The implementation lives in `extensions/git/src/repository.ts` around the `AI_CO_AUTHOR_TRAILER` constant and `appendAICoAuthorTrailer` method.
