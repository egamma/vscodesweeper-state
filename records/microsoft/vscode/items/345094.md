# Issue #345094 — Agent Host: enabled WorkIQ connector is missing from one session while ready in others

[https://github.com/microsoft/vscode/issues/345094](https://github.com/microsoft/vscode/issues/345094)

## Summary

Connector changes still remain pending indefinitely while a session waits for user input within an active turn. The maintainer's diagnosis matches current source; keep this open to address the session-specific availability gap and its missing explanation.

## Change summary

An existing Agent Host session silently lacks enabled connectors while its active turn prevents reconciliation.

## Best solution

Make pending connector availability explicit for the affected session and provide a safe recovery path. Decide whether newly connected servers should become available during supported mid-turn boundaries or remain deferred with a clear explanation.
