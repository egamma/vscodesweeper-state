# Issue #331483 — Multi-row tab layout should reserve space for modification icons

[https://github.com/microsoft/vscode/issues/331483](https://github.com/microsoft/vscode/issues/331483)

## Summary

Real layout bug: the multi-row tab bar doesn't reserve space for the dirty/modified indicator, so tabs reflow and the editor content jumps when files are edited/saved. A contributor is already actively fixing it in an open PR, so this should stay open pending that merge rather than being closed.

## Change summary

In multi-row tab layout, tabs don't reserve space for the modified-file dot/badge, causing tabs to reflow into a new row (and the editor to shift) when a file becomes dirty.

## Best solution

Land the fix in the linked PR (reserve the tab action/indicator column up front in multiEditorTabsControl.ts so the dirty indicator toggling doesn't change tab width), then close this issue as completed once merged.
