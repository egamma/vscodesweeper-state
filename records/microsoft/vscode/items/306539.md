# Issue #306539 — Copilot CLI: Make git errors more actionable. Currently just says "Failed to execute git"

[https://github.com/microsoft/vscode/issues/306539](https://github.com/microsoft/vscode/issues/306539)

## Summary

Keep open: current source still creates generic Git errors on the built-in Git API path used by Copilot CLI auto-commit. This team-authored follow-up requests actionable diagnostics, not another fix for the original missing Git identity.

## Change summary

Include the failed Git command and useful failure context in Copilot CLI errors instead of only displaying "Failed to execute git".

## Best solution

Make Git failures reaching Copilot CLI identify the failing operation and explain recognized configuration problems, including missing user identity. Preserve existing Git error classifications and execution behavior; richer diagnostics on Copilot's separate subprocess path do not cover repository.commit().
