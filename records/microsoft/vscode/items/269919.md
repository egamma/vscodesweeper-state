# Issue #269919 — Copilot chat (Agent) via remote-SSH extension

[https://github.com/microsoft/vscode/issues/269919](https://github.com/microsoft/vscode/issues/269919)

## Summary

A maintainer explicitly confirmed that supporting locally hosted Copilot Agent access to an air-gapped Remote-SSH workspace is currently out of scope. The supported configuration runs Copilot on the remote extension host with outbound networking.

## Change summary

Support Copilot Agent file operations from the local extension host when the Remote-SSH host has no network access.

## Best solution

Keep the current remote-extension-host architecture and document that Copilot Agent requires outbound networking from the remote host; environments that are not strictly air-gapped should enable that access.
