# Issue #335158 — Resizing the Chat panel causes severe lag

[https://github.com/microsoft/vscode/issues/335158](https://github.com/microsoft/vscode/issues/335158)

## Summary

Legitimate, well-diagnosed performance bug filed by a VS Code team member with a captured performance recording; the code confirms the described pattern (resize triggers repeated mirror-width layout and output re-measurement on every ResizeObserver callback) and no fix has landed yet.

## Change summary

Dragging the Chat panel's resize divider causes severe UI-thread stutter/input lag when the chat contains expanded terminal-output previews.

## Best solution

Coalesce/debounce the terminal-output resize handling in ChatTerminalToolProgressPart (_handleResize / _layoutMirrorWidth / _layoutOutput) so width-measure-then-height-measure work isn't repeated synchronously on every resize tick — e.g. schedule at most one measure+layout pass per animation frame during an active drag.
