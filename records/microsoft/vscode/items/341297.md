## Summary

Thanks for the detailed report. When not signed in, the picker still preselects an unusable Copilot model, which is a rough edge for BYOK-only users. A `chat.defaultModel` setting exists on main but is experiment-gated, so it may not cover this yet. The request stays open for triage.

## Change summary

When not signed in to GitHub with only BYOK models configured, the chat model picker preselects an unusable Copilot model and shows the Copilot tab.

## Best solution

When the user has no Copilot entitlement and a usable BYOK model exists, default new chats to that model and hide or collapse the unusable Copilot models in the picker.
