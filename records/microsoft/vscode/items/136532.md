# Issue #136532 — Emmet for Yandex BEM doesn't work in JSX

[https://github.com/microsoft/vscode/issues/136532](https://github.com/microsoft/vscode/issues/136532)

## Summary

Confirmed bug still present on main: the BEM filter (`|bem`) does not produce correct BEM-expanded class names when used in JSX syntax. The emmet-helper code sets both `bem.enabled` and `jsx.enabled` but the BEM transformation doesn't apply correctly to the class names in the JSX output path.

## Change summary

Emmet BEM filter (`|bem`) produces literal class names like `__h1` and `--h2` instead of BEM-expanded names like `about__h1` in JSX/React files.

## Best solution

Debug the interaction between `bem.enabled` and `jsx.enabled` in the @vscode/emmet-helper expand path — the BEM transform may not be running before the JSX class→className mapping, or the emmet core library may not handle both options simultaneously. The fix likely belongs in the @vscode/emmet-helper package.
