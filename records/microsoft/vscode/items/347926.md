# Issue #347926 — "Match Whole Word" in "Search in Files" works incorrectly for non-ASCII words when the file has no open editors

[https://github.com/microsoft/vscode/issues/347926](https://github.com/microsoft/vscode/issues/347926)

## Summary

The supplied reproduction exposes a current source-level defect: closed-file searches omit whole-word boundaries for these non-ASCII terms, while open editors enforce word separators. Keep this open for a search-engine fix.

## Change summary

Make whole-word Search in Files results consistent for non-ASCII words regardless of whether the file has an open editor.

## Best solution

Closed-file whole-word searches should reject the embedded matches in the supplied Cyrillic, Greek, Arabic, and Hebrew examples, matching the editor's results without regressing existing punctuation and regex behavior.
