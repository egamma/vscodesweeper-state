# Issue #83196 — Enteraction appending text before the new line

[https://github.com/microsoft/vscode/issues/83196](https://github.com/microsoft/vscode/issues/83196)

## Summary

The EnterAction API still lacks any mechanism to append text to the line before the new line — only `appendText` (after) and `removeText` exist. An open PR (#320286) references this issue but is unmerged and takes a different approach (a toggle command rather than an API property). The feature gap remains.

## Change summary

Add a property to the EnterAction API that allows appending text to the end of the current line (before the newline) when Enter is pressed, enabling string-splitting workflows.

## Best solution

Extend the `EnterAction` interface (both internal in `src/vs/editor/common/languages/languageConfiguration.ts` and the public `vscode.d.ts` API) with an `appendTextBefore` property (or similar), and thread it through `getEnterAction` and `cursorTypeEditOperations.ts`. This is a public API change requiring careful design review. The open PR #320286 should be evaluated as a candidate implementation, though it takes a command-based approach rather than the API-level enhancement requested here.
