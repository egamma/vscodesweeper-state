# Issue #89292 — Improve discoverability of Compact Folders option

[https://github.com/microsoft/vscode/issues/89292](https://github.com/microsoft/vscode/issues/89292)

## Summary

Still valid on main: the `explorer.compactFolders` setting has no `keywords` property, so searching for 'flatten', 'empty folders', or 'merged' won't find it. The infrastructure to add keywords already exists and is used by settings search.

## Change summary

Add search keywords to the `explorer.compactFolders` setting so users searching for 'flatten', 'empty', or 'merged' can discover it.

## Best solution

Add a `keywords` array (e.g. `['flatten', 'flattened', 'empty', 'merge', 'merged']`) to the `explorer.compactFolders` registration in `src/vs/workbench/contrib/files/browser/files.contribution.ts`. The settings search infrastructure already consumes `keywords` from configuration properties.
