## Summary

The misleading missing-command error remains source-reproducible: VS Code executes the API task using its ShellExecution, then reparses a history representation that omits the command. This issue already owns the consolidated reports and should remain open for a task-history fix.

## Change summary

Valid extension-created shell tasks produce a missing-command error in Tasks output despite executing successfully.

## Best solution

Valid API-created shell tasks should execute and pass through task-history handling without false configuration errors, while genuinely invalid tasks.json entries retain their diagnostics. Preserve task identity, actual execution commands, and existing task-provider behavior.
