# Issue #30874 — Regex Find can cause VS Code to Freeze

[https://github.com/microsoft/vscode/issues/30874](https://github.com/microsoft/vscode/issues/30874)

## Summary

Still reproducible on current main — the editor's regex find path in `textModelSearch.ts` calls `RegExp.exec()` synchronously on the main thread with no timeout or cancellation guard, so any catastrophically backtracking pattern freezes the UI. The root cause is V8's backtracking regex engine (upstream), and no mitigation has been added in VS Code's search layer. With 46 upvotes and steady duplicate traffic, this remains a valid tracking issue.

## Change summary

Certain regex patterns in Find cause catastrophic backtracking in V8's RegExp engine, freezing the VS Code UI with no way to cancel.

## Best solution

Add a timeout or cancellation mechanism around `RegExp.exec()` calls in the editor find path (`src/vs/editor/common/model/textModelSearch.ts`, `Searcher.next()`), or move regex matching off the main thread so the UI stays responsive. Long-term, V8's non-backtracking regex engine (tracked in V8 issue 10765) would eliminate the root cause, but VS Code should have its own mitigation regardless. The existing `limitResultCount` only caps result count, not per-match execution time.
