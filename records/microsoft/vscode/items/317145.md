# Issue #317145 — Quick access renders icon syntax from arbitrary sources

[https://github.com/microsoft/vscode/issues/317145](https://github.com/microsoft/vscode/issues/317145)

## Summary

The reported defect remains in current source: quick access passes content-derived editor names into an icon-enabled label renderer. Keep this correctly routed issue open; the related filename report does not cover its broader browser-title and untitled-content scope.

## Change summary

Quick access interprets literal codicon syntax in browser titles and content-derived untitled editor names as icons instead of displaying the original text.

## Best solution

Display arbitrary editor names and resource descriptions literally in file/editor quick access, while preserving intentional icons supplied by commands and extension quick picks. Cover both reported editor types and preserve filtering, highlights, accessibility labels, and editor-opening behavior.
