# Issue #340466 — Windows emoji panel (Win+.) inserts nothing in the editor when `editor.editContext` is enabled

[https://github.com/microsoft/vscode/issues/340466](https://github.com/microsoft/vscode/issues/340466)

## Summary

Same regression as the older, broader, already-assigned issue #338128 (Windows emoji panel Win+. silently failing to insert): that issue is open, has a maintainer assigned, 10 reactions, and multiple confirmations across widgets — this report is a more specific diagnosis (narrows it to `editor.editContext: true`) rather than a distinct defect.

## Change summary

Selecting a character from the Windows emoji panel (Win+.) inserts nothing into the editor when `editor.editContext` is enabled; disabling the setting restores the behavior.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/338128 — the editContext diagnosis here is valuable extra evidence for that investigation (the synthetic-keystroke input path used by the emoji panel is likely swallowed by `nativeEditContext.ts`'s text/selection update handling), but the underlying defect and fix belong in that thread.
