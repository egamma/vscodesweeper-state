# Issue #89821 — Emmet match tag fails when tags contain comments jsx

[https://github.com/microsoft/vscode/issues/89821](https://github.com/microsoft/vscode/issues/89821)

## Summary

Still reproduces on main: the Emmet match-tag command uses `@emmetio/html-matcher` which cannot parse JSX comment syntax (`// ...` and `{/* ... */}` inside tags), causing it to fail to identify matching tag pairs. A team member (rzhao271) confirmed this is an upstream limitation in comment 4 and reopened the issue.

## Change summary

Emmet's Go To Matching Pair command fails in JSX/TSX files when tags contain inline comments or TypeScript type annotations that confuse the html-matcher parser.

## Best solution

The root cause is in `@emmetio/html-matcher` which doesn't understand JSX comment syntax. Either contribute a fix upstream, or pre-process JSX to strip comments before passing to the parser (in `extensions/emmet/src/parseDocument.ts` where `parse(document.getText())` is called). Alternatively, for JSX/TSX files, use vscode-html-languageservice's parser which may handle these better — the PR #112597 partially explored this but was insufficient.
