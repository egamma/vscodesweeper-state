# Issue #343960 — Smoke tests: slow stable VS Code download times out the root before-all hook with 0 tests run

[https://github.com/microsoft/vscode/issues/343960](https://github.com/microsoft/vscode/issues/343960)

## Summary

The current smoke runner still awaits the stable download inside its five-minute root setup hook without a separate download deadline, so a steadily progressing slow transfer can prevent every test from running. Keep this open to establish explicit download-failure behavior; the report already supplies sufficient diagnostic evidence.

## Change summary

Prevent a slow stable-build download from surfacing as an unexplained root setup timeout with zero smoke tests executed.

## Best solution

Give stable-build acquisition a bounded, actionable failure outcome identifying the version and latest transfer progress before the root hook expires. Preserve migration coverage by default; a maintainer should decide whether acquisition failure must fail the job or may explicitly skip only stable-to-insiders migration tests.
