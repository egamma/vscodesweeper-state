# Issue #120587 — Non-executable notebook code cells

[https://github.com/microsoft/vscode/issues/120587](https://github.com/microsoft/vscode/issues/120587)

## Summary

Keep open under discussion: unsupported-language code cells provide a partial workaround, but current source still restricts the language picker to kernel-supported languages and does not provide an explicit non-executable annotation mode. No verified older canonical issue or concrete fixing commit was found.

## Change summary

Support standalone, syntax-highlighted notebook annotation cells that cannot execute, including examples written in otherwise executable languages.

## Best solution

Decide whether notebook cells should support an explicit non-executable annotation mode, with language selection independent of the active kernel. Preserve ordinary code-cell execution and Markdown rendering; consider custom annotation renderers separately from the central request.
