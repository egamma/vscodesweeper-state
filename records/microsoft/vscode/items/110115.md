# Issue #110115 — Column-view (Miller columns) for the breadcrumbs 

[https://github.com/microsoft/vscode/issues/110115](https://github.com/microsoft/vscode/issues/110115)

## Summary

Persistent cascading columns remain distinct from the current breadcrumb picker and Outline tree. Keep this accepted Backlog request open: the suggested extension received mixed feedback, and the older related issue does not cover the same behavior.

## Change summary

Display breadcrumb alternatives or Outline symbols in persistent, adjacent Miller columns for hierarchical code navigation.

## Best solution

Evaluate an extension-based cascading symbol browser before adding another built-in navigation layout, using the existing prototype and feedback in this thread. Preserve this request until a maintainer settles whether that experience adequately covers the requested persistent Outline navigation.
