# Issue #110115 — Column-view (Miller columns) for the breadcrumbs 

[https://github.com/microsoft/vscode/issues/110115](https://github.com/microsoft/vscode/issues/110115)

## Summary

A real capability gap remains: current breadcrumbs and Outline use linear/tree presentations, not persistent Miller columns. Keep this Backlog request open for a product decision because the community extension is only a partial substitute and no canonical issue owns the work.

## Change summary

Provide a Miller-column presentation for breadcrumb or Outline navigation, keeping sibling symbols visible in cascading vertical columns.

## Best solution

Prefer an extension implementation using the existing Outline data where practical; if extension APIs prevent full fidelity, narrow this issue to the specific API gap. A core implementation would require an intentional alternate renderer for breadcrumbs or Outline rather than another minor setting.

## Vision fit

- **Fit:** rejected
- **Reason:** This is a specialized alternative navigation surface that can largely be delivered by an extension and would add complexity to the default workbench UI.
- **Evidence:** Values and guardrails: “The power lives in extensions” and the default experience should retain simple, uniform UI interactions.
