# Issue #336390 — Expanded Codex support in the agent host does not work

[https://github.com/microsoft/vscode/issues/336390](https://github.com/microsoft/vscode/issues/336390)

## Summary

Confirmed, actively-diagnosed bug: a maintainer (Giuspepe) identified the root cause as a deadlock in the harness picker — Codex won't load ChatGPT-subscription models until selected, but can't be selected until models are loaded, which also mis-shows an 'Upgrade' blocker for Copilot Free users. Multiple independent reporters confirm it and workarounds exist, but no fix has landed yet.

## Change summary

Enabling Codex agent-host support does not surface ChatGPT-provided models/agents in the Chat panel or Agents window until a manual workaround command is run, and the fix doesn't persist across restarts.

## Best solution

Fix the harness-picker deadlock in the agent-host chat integration so Codex's ChatGPT-subscription models are loaded/considered before or independently of the Codex selection state, likely in the agent-host chat contribution/model-picker code that gates on already-loaded models before enabling an entry.
