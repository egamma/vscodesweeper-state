# Issue #335227 — When using custom endpoints, virtual tools cause the model to fail to accurately discover the tools

[https://github.com/microsoft/vscode/issues/335227](https://github.com/microsoft/vscode/issues/335227)

## Summary

Real gap for BYOK/custom-endpoint users: virtual tool grouping's categorization quality is uneven and there's no user-facing control comparable to what first-party models get, but this needs a product decision (how to expose/tune categorization or tool search for custom endpoints) rather than a mechanical fix.

## Change summary

With a custom/BYOK endpoint and a large MCP tool set, the automatic virtual-tool grouping mis-categorizes tools and the user has no way to enable native tool-search or manually adjust the groups.

## Best solution

Consider exposing more explicit control over virtual tool grouping for BYOK/custom-endpoint sessions — e.g. surfacing `github.copilot.chat.virtualTools.threshold` more prominently (it can be set to 0 to disable grouping) and/or extending `ToolSearchTool` (currently gated as an `ICopilotModelSpecificTool`, tied to Anthropic-style native tool search per `extensions/copilot/src/extension/tools/node/toolSearchTool.ts` and `CUSTOM_TOOL_SEARCH_NAME` in `platform/networking/common/anthropic.ts`) to custom endpoints so they aren't limited to the LLM-based categorization fallback.

## Evidence

- **existing partial control:** extensions/copilot/package.json exposes `github.copilot.chat.virtualTools.threshold` (experimental, default 128); toolGrouping.ts:22-25 treats a value <= 0 as Infinity (disables grouping), so a coarse manual override already exists but isn't obviously discoverable or documented for this scenario.
- **tool search gating:** extensions/copilot/src/extension/tools/node/toolSearchTool.ts implements `ToolSearchTool` as an `ICopilotModelSpecificTool` referencing `CUSTOM_TOOL_SEARCH_NAME` from platform/networking/common/anthropic.ts, consistent with the reporter's claim that tool-search can't be explicitly enabled for arbitrary custom endpoints.
