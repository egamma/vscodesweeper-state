# Issue #171039 — Git - click Stage Changes should trigger files.autoSave first 

[https://github.com/microsoft/vscode/issues/171039](https://github.com/microsoft/vscode/issues/171039)

## Summary

Keep open: staging still checks conflict markers on disk without waiting for focus-change autosave, so resolved editor content can produce an unnecessary conflict warning. This issue already owns the confirmed duplicate report and is correctly routed to Git.

## Change summary

Finish focus-change autosave before checking merge conflicts and staging a resolved file.

## Best solution

Ensure the Stage Changes action observes completion of the applicable autosave before inspecting conflict markers or staging disk content. Preserve warnings for genuinely unresolved conflicts and respect configurations that disable autosave.
