# Issue #9604 — Indent Guides Have Breaks Where CodeLens UI is Rendered

[https://github.com/microsoft/vscode/issues/9604](https://github.com/microsoft/vscode/issues/9604)

## Summary

Keep open: current source still renders guides only within text-line overlays, leaving CodeLens view-zone gaps. This accepted request has 40 upvotes, and the related bracket-guide report is newer rather than a valid canonical for this re-reviewed item.

## Change summary

Render continuous indentation guides through CodeLens rows without extending them through diff or inline peek view zones.

## Best solution

Provide guide continuity through CodeLens space while preserving intentional gaps for embedded editors and diff alignment. Plan the shared view-zone rendering boundary with the editor maintainer, using this issue as the existing indentation-guide tracker.

- **Behavior:**

  > With indentation guides and CodeLens enabled, guides should remain continuous across CodeLens rows wherever the surrounding code has a continuing indentation guide. Acceptance includes scrolling and changes to CodeLens row height without gaps or misplaced guide segments.
