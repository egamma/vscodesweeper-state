# Issue #205254 — parentTerminal doesn't always work 

[https://github.com/microsoft/vscode/issues/205254](https://github.com/microsoft/vscode/issues/205254)

## Summary

Keep open: current source still drops parentTerminal after the parent receives its numeric instance ID. An open PR explicitly fixes this issue, so the next step is reviewing that implementation rather than closing the report or starting competing work.

## Change summary

Creating a terminal with an already-open parentTerminal opens a separate terminal group instead of a split.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/312550 so parent resolution supports both temporary extension-host UUIDs and numeric instance IDs. Coordinate with the overlapping https://github.com/microsoft/vscode/pull/338451 and verify both immediate and delayed split creation.
