# Issue #332107 — Rendered Markdown in Source Control injects diff markup into Mermaid code blocks, causing parse errors

[https://github.com/microsoft/vscode/issues/332107](https://github.com/microsoft/vscode/issues/332107)

## Summary

Real, reproducible bug in the Markdown preview's inline diff decoration wrapping Mermaid fence content with `<span data-diff-...>` markup that Mermaid then fails to parse — and a PR already claims to fix it, so this should stay open for review of that PR rather than an automated close.

## Change summary

Viewing a changed Markdown file's rendered diff in the Markdown Preview injects diff-highlight `<span data-diff-*>` tags into fenced Mermaid code blocks, breaking the Mermaid parser.
