# Issue #332272 — Pet: Not sure how I got the 'Skilled Builder' achievment

[https://github.com/microsoft/vscode/issues/332272](https://github.com/microsoft/vscode/issues/332272)

## Summary

Traced the mechanism: the 'Skilled Builder' achievement fires whenever any non-builtin skill item with source 'local'/'user' appears, with no distinction between a skill the human wrote themselves and one an agent created/edited on the user's behalf while carrying out an unrelated request — which explains the reporter's confusion about how they earned it.

## Change summary

Reporter is confused about why the Chat Pet 'Skilled Builder' achievement unlocked, since they never consciously added a custom skill.

## Best solution

Chat Pet team should decide whether `isUserAuthoredChatPetCustomization` in src/vs/workbench/contrib/chat/browser/chatPetAchievements.ts (used by ChatPetCustomizationAchievementContribution in chatPetAchievements.contribution.ts) should require a more explicit user-authoring signal, or whether the achievement description ('You added a custom skill') should be loosened to also cover skills an agent created during a session — either way this is a product-semantics call, not a bug fix.
