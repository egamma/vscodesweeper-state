# Issue #344563 — Copilot CLI (agent host) chat session is deleted when a folder is added to a single-folder window

## Summary

Verified duplicate of the older, open report https://github.com/microsoft/vscode/issues/343406: converting a single-folder window to an untitled multi-root workspace permanently deletes existing Copilot CLI sessions. Consolidate this local-Linux confirmation with that report while preserving its storage and log evidence.

## Change summary

Adding a folder to a single-folder window deletes an existing Copilot CLI agent-host conversation and its persisted history without a user deletion action.

## Best solution

Track the session-preservation fix in https://github.com/microsoft/vscode/issues/343406: workspace conversion and reconnection must retain conversations and their SDK backing storage rather than invoke destructive session disposal.
