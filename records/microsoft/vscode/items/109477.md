# Issue #109477 — Suggest widget: Details view doesn't resize width to fit content

[https://github.com/microsoft/vscode/issues/109477](https://github.com/microsoft/vscode/issues/109477)

## Summary

The suggest details panel's user-resized width is stored only in-memory (`_userSize` in `SuggestDetailsOverlay`) and is not persisted across sessions — unlike the main suggest widget list, which uses `PersistedWidgetSize` with `IStorageService`. The dynamic-width-to-content request was intentionally declined by jrieken as 'too nervous', but the persistence gap remains a valid polish item.

## Change summary

The suggest widget details view does not persist user-resized width across sessions, and does not dynamically resize width to fit content.

## Best solution

Add `PersistedWidgetSize`-style storage for the details panel's user-resized dimensions in `SuggestDetailsOverlay` (file: `src/vs/editor/contrib/suggest/browser/suggestWidgetDetails.ts`), mirroring the pattern already used by the main suggest widget in `suggestWidget.ts`. Dynamic content-based width resizing was already declined by the team.
