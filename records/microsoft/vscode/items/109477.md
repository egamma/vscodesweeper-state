# Issue #109477 — Suggest widget: Details view doesn't resize width to fit content

[https://github.com/microsoft/vscode/issues/109477](https://github.com/microsoft/vscode/issues/109477)

## Summary

Keep open: the details pane still lacks durable width persistence, which the reporter explicitly accepted as an alternative to automatic sizing. Current sizing support and the related session-memory change do not fully cover that request.

## Change summary

Automatically widen suggestion documentation to fit its content, or remember a manually chosen width across sessions.

## Best solution

Preserve the user's preferred documentation-pane width across sessions while constraining its displayed size to available space. This would satisfy the reporter's central need without introducing the automatic width changes the maintainer cautioned against.
