# Issue #314828 — Chat input: Combine the worktree/local picker with the branch picker

[https://github.com/microsoft/vscode/issues/314828](https://github.com/microsoft/vscode/issues/314828)

## Summary

Keep open for a focused interaction-design decision: desktop chat still exposes isolation and branch as separate controls, although phone layouts already share a selection sheet. This team-authored Backlog request has no verified issue-referencing fix or qualifying duplicate.

## Change summary

Combine the chat input's worktree/local selection and branch selection into one coherent picker.

## Best solution

Agree on a unified desktop selection experience that makes both the working location and branch understandable before sending a prompt, using the existing phone sheet as a design reference. Preserve provider-specific availability and read-only behavior rather than changing isolation semantics.
