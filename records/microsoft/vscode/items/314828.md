# Issue #314828 — Chat input: Combine the worktree/local picker with the branch picker

[https://github.com/microsoft/vscode/issues/314828](https://github.com/microsoft/vscode/issues/314828)

## Summary

Keep open: desktop session creation still exposes isolation and branch as separate pickers. The phone implementation combines their options in one sheet, but that does not complete this team-authored desktop UX request.

## Change summary

Combine the chat input's worktree/local selection and branch selection into one coherent picker.

## Best solution

Provide a unified desktop selection experience that clearly distinguishes working in the existing checkout from creating a worktree and choosing its base branch. Agree the interaction design first, using the existing phone sheet as relevant prior art without changing the underlying isolation and checkout semantics.

- **Trace:**

  > AgentHostSessionConfigPicker._renderConfigPickers currently creates distinct desktop triggers for Isolation and Branch. MobileAgentHostSessionConfigPicker._showPicker uses _showUnifiedRepoSheet only on phone layouts and delegates desktop behavior to the base implementation. Related design context is https://github.com/microsoft/vscode/issues/336620, which is newer and does not supersede this request.
