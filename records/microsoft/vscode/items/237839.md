# Issue #237839 — Focus on the Tab to the Left When Closing a Tab

[https://github.com/microsoft/vscode/issues/237839](https://github.com/microsoft/vscode/issues/237839)

## Summary

The requested left-neighbor focus behavior is still missing: existing settings offer most-recently-used focus or right-neighbor focus, not left-first closing. Keep this correctly routed feature request open; no older canonical covering the same observable request was verified.

## Change summary

Focus the neighboring tab to the left when closing the active editor, rather than selecting the right neighbor or the most recently used editor.

## Best solution

Consider an explicit left-neighbor close-focus policy in the editor-group model, preserving existing policies for users who prefer them. A maintainer should decide whether this warrants an additional preference or a change to the existing sequential policy.
