# Issue #237839 — Focus on the Tab to the Left When Closing a Tab

[https://github.com/microsoft/vscode/issues/237839](https://github.com/microsoft/vscode/issues/237839)

## Summary

A real capability gap remains: VS Code supports MRU or right-adjacent focus after closing a tab, but not consistently focusing the left neighbor. Keep this canonical request open under discussion rather than closing it for age or low engagement.

## Change summary

Allow closing an active editor tab to focus its immediate left neighbor.

## Best solution

Extend the editor-close focus configuration to offer explicit MRU, left-neighbor, and right-neighbor behaviors while preserving compatibility with the existing boolean setting. The implementation belongs in the workbench editor group model and its configuration registration.
