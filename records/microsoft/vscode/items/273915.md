# Issue #273915 — Exclude trailing/leading whitespace changes in content + whitespace change suggestions

[https://github.com/microsoft/vscode/issues/273915](https://github.com/microsoft/vscode/issues/273915)

## Summary

Keep open: current whitespace-only filtering does not remove incidental whitespace changes from suggestions that also change content. This team-authored request has neither a verified older canonical with the same symptom nor an identifiable fixing commit.

## Change summary

Exclude incidental leading and trailing whitespace changes from next edit suggestions that also contain substantive text changes.

## Best solution

NES should preserve the substantive suggestion without bundling unrelated boundary-whitespace edits. Establish the treatment of whitespace that is necessary for the content change, particularly indentation, before implementing mixed-edit normalization.
