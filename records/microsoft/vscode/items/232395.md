# Issue #232395 — Illegal value for lineNumber

[https://github.com/microsoft/vscode/issues/232395](https://github.com/microsoft/vscode/issues/232395)

## Summary

Fixed on main: the exact code path that threw (getBottomForLineNumber with startLineNumber - 1 when startLineNumber is 1, yielding illegal line 0) was guarded in commit 3f3807095ea, shipped in 1.104.0.

## Change summary

Diff editor gutter throws 'Illegal value for lineNumber' when a gutter item has startLineNumber beyond the model's line count and equals 1, passing 0 to getBottomForLineNumber.

## Best solution

Keep the shipped fix — the guard at line 124–129 of editorGutter.ts now checks `startLineNumber > 1` before calling `getBottomForLineNumber(startLineNumber - 1)`, falling back to 0 otherwise. No further change needed.
