# Issue #241968 — `i` should be marked as an alias of `install`

[https://github.com/microsoft/vscode/issues/241968](https://github.com/microsoft/vscode/issues/241968)

## Summary

Valid feature request from a team member. The terminal suggest infrastructure has an Alias kind, but subcommand alias detection (e.g. npm `i` → `install`) is not yet implemented. No fixing commit found on main.

## Change summary

Terminal suggest should mark `i` as an alias of `install` for npm subcommands, not treat it as a separate suggestion.

## Best solution

Extend the terminal suggest completion provider to recognize subcommand aliases (at least for npm, and potentially git) and present them with `TerminalCompletionItemKind.Alias` and an appropriate label indicating the canonical command. The alias infrastructure already exists; the gap is in the data/spec layer for npm subcommands.
