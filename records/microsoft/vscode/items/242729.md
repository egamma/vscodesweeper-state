# Issue #242729 — `zsh` `shellIntegration.env` is undefined in earlier .onDidChangeShellIntegration

[https://github.com/microsoft/vscode/issues/242729](https://github.com/microsoft/vscode/issues/242729)

## Summary

Still present on main: `setCwd` and `setEnv` fire separate `_fireChangeEvent()` calls, so early `onDidChangeShellIntegration` listeners see `env` as undefined when cwd fires first. Team-authored debt item, keeping open.

## Change summary

For zsh terminals, `shellIntegration.env` is undefined in earlier `onDidChangeShellIntegration` events because cwd and env are set and fired independently.

## Best solution

Batch or defer the change event so that both `cwd` and `env` are populated before the first `onDidChangeShellIntegration` fires, likely in `extHostTerminalShellIntegration.ts` around the `_fireChangeEvent` call sites. An alternative is to coalesce the two separate fires into a single microtask-deferred event.
