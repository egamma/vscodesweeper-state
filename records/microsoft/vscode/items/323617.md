# Issue #323617 — Hiding chats inside a session doesn't make sense

[https://github.com/microsoft/vscode/issues/323617](https://github.com/microsoft/vscode/issues/323617)

## Summary

Current main replaces the confusing checkbox picker with explicit Archive/Restore actions, but it still allows a running nested chat to be archived and removed from view without stopping its work. This team-authored UX issue has no explicitly linked fix, so it should remain open while the running-chat behavior is decided.

## Change summary

Make nested-chat management clearly distinguish switching or archiving a chat from controlling its active execution.

## Best solution

Choose and consistently expose a running-chat archive policy: prevent archiving until completion, stop the run before archiving, or preserve conspicuous progress visibility while it continues. The UI and accessibility text should make that lifecycle consequence explicit.
