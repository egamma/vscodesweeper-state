# Issue #133239 — Support remote extension host profiling

[https://github.com/microsoft/vscode/issues/133239](https://github.com/microsoft/vscode/issues/133239)

## Summary

The capability remains missing on current main: manual profiling explicitly targets the local process extension host. This team-authored request should remain open because there is no referenced implementation or verified open duplicate.

## Change summary

Allow the Running Extensions editor to capture a CPU profile from extensions running in a remote extension host.

## Best solution

Extend extension-host profiling to select and profile a remote host, including transporting its inspector data back to the local profile viewer, while preserving local-host profiling.
