# Issue #328924 — Accessibility: Mermaid diagrams frequently violate WCAG colour contrast requirements

[https://github.com/microsoft/vscode/issues/328924](https://github.com/microsoft/vscode/issues/328924)

## Summary

Confirmed and source-traced: the built-in Mermaid preview's VS Code theme mapping never sets Mermaid's sequence-diagram-specific theme variables (actorBkg, activationBkgColor, signalColor, sequenceNumberColor, etc.), so those elements fall back to Mermaid's stock base-theme defaults instead of contrast-safe VS Code colors — matching the reporter's measured 1.21:1 activation-bar and white-on-white text screenshots.

## Change summary

Mermaid diagrams rendered in the Markdown preview frequently have text/shape contrast well below WCAG requirements across several built-in VS Code themes.

## Best solution

Extend `computeVsCodeMermaidThemeVariables` in extensions/mermaid-markdown-features/preview-src/shared/vsCodeTheme.ts to also map the sequence-diagram-specific Mermaid variables (actorBkg, actorBorder, actorTextColor, actorLineColor, signalColor, signalTextColor, activationBkgColor, activationBorderColor, sequenceNumberColor, labelBoxBkgColor/BorderColor, loopTextColor) to VS Code colors, and verify resulting contrast against WCAG AA across the built-in light/dark/high-contrast themes.
