# Issue #232753 — arrow navigation diff view will go to prev/next cell

[https://github.com/microsoft/vscode/issues/232753](https://github.com/microsoft/vscode/issues/232753)

## Summary

Still reproduces on main: the accessible diff viewer uses a DOM keydown listener (line 401–419 of accessibleDiffViewer.ts) instead of keybinding commands, so arrow keys leak to the notebook cell list. The TODO@hediet comment confirming the intended fix is still present.

## Change summary

Arrow-key navigation in the inline-chat diff view within notebooks leaks to the cell list, causing unintended cell focus changes.

## Best solution

Convert the keydown-based arrow navigation in `accessibleDiffViewer.ts` (the TODO@hediet block at line 401) to proper keybinding commands with higher priority than `list.focusUp`/`list.focusDown`, so the diff viewer captures arrows before the notebook cell list does.
