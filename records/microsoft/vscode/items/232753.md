# Issue #232753 — arrow navigation diff view will go to prev/next cell

[https://github.com/microsoft/vscode/issues/232753](https://github.com/microsoft/vscode/issues/232753)

## Summary

Keep open: accessible diff arrow navigation still allows the containing notebook's list-navigation commands to run. A newer report confirms the same symptom and has maintainer agreement on addressing focus scoping, but cannot replace this older, previously reviewed issue.

## Change summary

Up and down arrows in a notebook's accessible diff viewer move between cells instead of remaining within the diff.

## Best solution

Make accessible diff navigation retain focus within the viewer without triggering the enclosing notebook list's navigation, while preserving normal cell navigation outside it. Coordinate the shared fix with https://github.com/microsoft/vscode/issues/251043.
