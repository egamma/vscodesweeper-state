# Issue #232753 — arrow navigation diff view will go to prev/next cell

[https://github.com/microsoft/vscode/issues/232753](https://github.com/microsoft/vscode/issues/232753)

## Summary

Still reproduces on main: the accessible diff viewer uses a DOM keydown listener (with a TODO@hediet to convert to commands) that loses priority to the notebook cell list's list.focusUp/Down keybindings. No fix commit found.

## Change summary

Arrow keys in the accessible diff viewer navigate to prev/next notebook cell instead of scrolling through the diff lines.

## Best solution

Convert the DOM keydown handler in accessibleDiffViewer.ts (line ~401) to registered keybinding commands with a when-clause scoped to the accessible diff viewer focus context, giving them higher priority than list.focusUp/Down.
