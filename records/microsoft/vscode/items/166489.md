# Issue #166489 — Support alt+enter in terminal quick fixes to add a command but not execute it

[https://github.com/microsoft/vscode/issues/166489](https://github.com/microsoft/vscode/issues/166489)

## Summary

Still open on main: the TODO at quickFix.ts:71 explicitly marks this as unimplemented. The `shouldExecute` plumbing exists but is never toggled by an alt-key modifier. The issue is authored by a core terminal contributor and parked On Deck — keeping open as a valid, unfinished feature request.

## Change summary

Allow alt+enter in terminal quick fixes to paste the command into the terminal without executing it, matching the run-recent-command behavior.

## Best solution

Wire the alt-key modifier through the quick-fix action menu so that when alt+enter is used, `shouldExecute` is set to `false` on the `ITerminalQuickFixTerminalCommandAction`. The plumbing (`shouldExecute` field, `onDidRequestRerunCommand` event) already exists in `src/vs/workbench/contrib/terminalContrib/quickFix/browser/quickFixAddon.ts`; the missing piece is detecting alt in the code-action accept path and threading it through. This also requires the editor code-action menu to support an alt-accept variant (per comment 3–5 discussion with @justschen).
