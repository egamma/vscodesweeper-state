## Summary

Valid, unimplemented feature request from a team member with 21 upvotes — auto-close the markdown preview pane when its source .md file is closed. No setting, command, or code path for this exists on current main. The Backlog milestone and community interest (above the 20-upvote threshold) warrant keeping it open.

## Change summary

Automatically close the markdown preview side panel when its associated .md file is closed or when the user switches to a non-markdown file.

## Best solution

Implement an auto-close (or auto-hide) behavior in the built-in markdown preview extension so that the preview panel is dismissed when the source markdown editor is closed. A setting (e.g. `markdown.preview.autoClose`) would let users opt in. The logic likely belongs in `extensions/markdown-language-features/src/` in the preview manager. Issue #91401 (closed as duplicate of this) adds useful design detail — tab-dependent preview and a pin button.
