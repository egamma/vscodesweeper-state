# Issue #271438 — Images do not render in Chat from coding agent in Sessions

[https://github.com/microsoft/vscode/issues/271438](https://github.com/microsoft/vscode/issues/271438)

## Summary

Current main still strips images from coding-agent session responses, and the existing test suite explicitly expects remote images to be absent. This team-authored, accepted bug must remain open while maintainers choose a secure authenticated-image policy.

## Change summary

Images embedded by a coding agent, particularly GitHub attachment images from private repositories, do not appear in the Sessions chat editor.

## Best solution

Render agent-produced image attachments through an authenticated, trusted resource path without enabling arbitrary remote-image loading for all chat Markdown. Preserve the current protection against untrusted external image URLs.

- **Trace:**

  > Chat responses are rendered through ChatContentMarkdownRenderer in src/vs/workbench/contrib/chat/browser/widget/chatContentMarkdownRenderer.ts, whose `getChatMarkdownRenderOptions` unconditionally rejects remote images. The issue discussion confirms the reported private GitHub URL also requires authentication, so merely allowing all HTTPS images would not solve the trigger and would weaken the existing security boundary. Preserve blocking for unrelated external URLs and avoid broad changes to general Markdown rendering. The related https://github.com/microsoft/vscode/issues/259021 was consolidated into this issue.
- **Open decisions:**
