# Issue #298748 — tunnel service does not persist after reboot on MacOS

[https://github.com/microsoft/vscode/issues/298748](https://github.com/microsoft/vscode/issues/298748)

## Summary

Keep open: current main still installs the macOS tunnel plist directly in the home directory rather than the login-loaded LaunchAgents directory. The August reproduction and successful relocation workaround match the source exactly.

## Change summary

Ensure an installed macOS tunnel service starts again after logout/login or reboot.

## Best solution

Make the CLI's macOS service installation persist as a per-user LaunchAgent, with consistent installation and removal behavior. Preserve the existing tunnel identity, authentication, arguments, and logging.
