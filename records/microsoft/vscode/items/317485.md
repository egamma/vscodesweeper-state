# Issue #317485 — agents: create pull request fails on worktree session

[https://github.com/microsoft/vscode/issues/317485](https://github.com/microsoft/vscode/issues/317485)

## Summary

Keep open: the reporter confirmed that valid worktree sessions intermittently reject Create PR until the window is reopened. The exact error path remains in current source, but neither a fixing commit nor an older canonical reporting the same symptom was established.

## Change summary

Create PR intermittently misidentifies a worktree session as unsupported and remains blocked until the Agents Window is reopened.

## Best solution

Make Create PR consistently resolve the selected session's valid worktree identity without requiring a window restart. First capture the failing session resource and worktree metadata to distinguish incorrect action targeting from stale or incomplete metadata.
