# Issue #586 — Link to a file position in Output Channel

[https://github.com/microsoft/vscode/issues/586](https://github.com/microsoft/vscode/issues/586)

## Summary

The requested capability shipped in VS Code 1.66.0: extensions can assign a language ID to an output channel and register a DocumentLinkProvider for relative paths, positions, or custom link text. This can be closed as completed.

## Change summary

Let extensions render links to workspace files and specific positions in output channels, including relative paths and custom display text.

## Best solution

Use `window.createOutputChannel(name, languageId)` with `languages.registerDocumentLinkProvider(languageId, provider)` to resolve output text to file URIs containing line and column fragments.
