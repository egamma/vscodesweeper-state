# Issue #334683 — Hitting a breakpoint always opens "Run and Debug" view

[https://github.com/microsoft/vscode/issues/334683](https://github.com/microsoft/vscode/issues/334683)

## Summary

This is the documented `debug.openDebug` setting working as designed — its default is `openOnDebugBreak`, which intentionally opens the Run and Debug view (in the sidebar) when a thread stops on a breakpoint; setting it to `neverOpen` (or `openOnFirstSessionStart`) gives the reporter the behavior they want.

## Change summary

Reporter wants breakpoint hits to stop force-opening the Run and Debug view/sidebar, even after they've hidden the primary side bar.

## Best solution

Point the reporter at the existing `debug.openDebug` setting (values `neverOpen` / `openOnSessionStart` / `openOnFirstSessionStart` / `openOnDebugBreak`, default `openOnDebugBreak`) which exactly controls this behavior; no code change needed.
