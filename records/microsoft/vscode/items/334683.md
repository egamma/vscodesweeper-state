# Issue #334683 — Hitting a breakpoint always opens "Run and Debug" view

[https://github.com/microsoft/vscode/issues/334683](https://github.com/microsoft/vscode/issues/334683)

## Summary

This is intentional behavior governed by the existing `debug.openDebug` setting, which defaults to `openOnDebugBreak` — the setting's whole purpose is to reveal the Run and Debug view when a breakpoint is hit, overriding a hidden sidebar. Setting it to `neverOpen` fully addresses the report.

## Change summary

Hitting a breakpoint always reopens the Run and Debug view/sidebar even when the sidebar was explicitly hidden.

## Best solution

Point the reporter at `debug.openDebug: neverOpen` (or `openOnSessionStart`/`openOnFirstSessionStart`) to stop the debug view from auto-opening on a breakpoint hit; no code change needed since the setting already exists for this exact purpose.
