# Issue #326591 — Feature Request: Support external browser password autofill in integrated browser

[https://github.com/microsoft/vscode/issues/326591](https://github.com/microsoft/vscode/issues/326591)

## Summary

Valid feature request for password autofill in the integrated browser. It is in the Backlog Candidates community voting window (7 of 60 days, 2 of 20 upvotes). The request hits a genuine Electron limitation — Electron's BrowserView runs in an isolated session without access to the host browser's password store — and no existing code or setting addresses it. Keep open for the community process.

## Change summary

Support auto-filling saved passwords from the system or default-browser credential manager inside VS Code's integrated browser.

## Best solution

This is fundamentally an Electron/Chromium platform limitation: the integrated browser's session is isolated from the OS password store. A solution would require either Electron-level credential-store integration or a VS Code–side bridge to the OS keychain (e.g. via `safeStorage` or platform APIs). The request is well-scoped but technically deep; let the community voting process decide priority. If it gains traction, the work would live in `src/vs/platform/browserView/electron-main/` and would likely need upstream Electron API support.
