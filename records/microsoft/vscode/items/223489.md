# Issue #223489 — Add a `when` property to `QuickInputButton`

[https://github.com/microsoft/vscode/issues/223489](https://github.com/microsoft/vscode/issues/223489)

## Summary

Keep open: declarative, context-dependent QuickInputButton visibility remains missing, and api-proposal tracking issues are protected from cleanup closes. The related inline-button proposal does not cover this request; a maintainer explicitly requested a separate issue.

## Change summary

Add an optional when-clause property to QuickInputButton so button visibility follows context changes without extensions replacing the buttons array.

## Best solution

Have the quick-input API owners define the context-evaluation and visibility contract for buttons on QuickPick and InputBox, then carry the proposal through implementation and API finalization. Preserve existing behavior for buttons without a condition.
