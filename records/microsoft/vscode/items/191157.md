# Issue #191157 — Recently opened project has the same name

[https://github.com/microsoft/vscode/issues/191157](https://github.com/microsoft/vscode/issues/191157)

## Summary

Keep open: the discussion confirms that copied vscode.dev file links can open a separate workspace, producing identical recent-project labels and hiding pending edits from the original workspace. Current source still distinguishes the reported URI representations; no fixing commit or verified older canonical was found.

## Change summary

Opening a copied vscode.dev link for the default branch creates a differently identified workspace with the same recent-project name and separate pending changes.

## Best solution

Make equivalent default-branch repository and file links resolve to a consistent workspace experience without stranding edits stored under either existing representation. Resolve the embedder normalization and state-migration behavior before treating this as a recent-history labeling fix.
