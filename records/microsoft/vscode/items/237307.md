# Issue #237307 — When pasting multiline text into a comment, it should keep all lines commented out

[https://github.com/microsoft/vscode/issues/237307](https://github.com/microsoft/vscode/issues/237307)

## Summary

Valid feature request that reached 23 upvotes and was promoted to Backlog. No implementation exists on current main — the clipboard/paste logic has no comment-continuation awareness. Stays open as an accepted backlog item.

## Change summary

Pasting multiline text into a commented line should prepend the comment prefix to all pasted lines, not just the first.

## Best solution

Implement comment-aware paste in the editor clipboard contrib (`src/vs/editor/contrib/clipboard/browser/clipboard.ts`): detect when the cursor is inside a line comment, and when pasting multiline content, prepend the appropriate comment prefix (from the language configuration) to each pasted line. This is a core editor behavior, not extension territory.
