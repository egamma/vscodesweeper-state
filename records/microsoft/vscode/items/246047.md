# Issue #246047 — Move "Add Context..." dialogue closer to the button

[https://github.com/microsoft/vscode/issues/246047](https://github.com/microsoft/vscode/issues/246047)

## Summary

The underlying quick pick anchor infrastructure landed (issue #238095 completed), but the chat 'Add Context' action still uses `quickAccess.show()` without passing an anchor, so the picker still opens at the top center. The request remains valid.

## Change summary

Move the 'Add Context' dialog closer to the button that invoked it instead of centering it at the top of the window.

## Best solution

Wire the anchor option through `quickAccess.show()` in `chatContextActions.ts` (line ~597) so the Add Context picker opens near the invoking button. The quick pick anchor infrastructure already exists (`IQuickPickOptions.anchor`); the gap is exposing it through the quick-access layer and passing the button element from the chat input widget.
