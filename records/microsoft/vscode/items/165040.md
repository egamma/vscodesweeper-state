# Issue #165040 — Set profile to have custom number of terminals at the same time by default

[https://github.com/microsoft/vscode/issues/165040](https://github.com/microsoft/vscode/issues/165040)

## Summary

Keep this accepted, community-supported request open: terminal profiles already preserve individual names, icons, and colors, but do not declaratively launch the requested set of terminals together. Session restoration and automatic tasks offer partial alternatives, not the same profile-level capability.

## Change summary

Provide a reusable default terminal setup containing separate command, Ruby console, and server terminals with distinct names, icons, and colors.

## Best solution

Enable a reusable, explicitly configured multi-terminal setup that reuses existing terminal profile customizations without duplicating restored sessions. Decide its activation and configuration scope before implementing it in the terminal profile and creation surfaces.
