# Issue #119025 — Display mixed line endings explicitly in status bar as "LF (mixed)" or "CRLF (mixed)"

[https://github.com/microsoft/vscode/issues/119025](https://github.com/microsoft/vscode/issues/119025)

## Summary

The requested mixed-EOL indicator remains absent on main, and this Backlog request has 46 community upvotes. It is distinct from displaying per-line endings and should remain open for editor text-buffer work.

## Change summary

Show when a file contains mixed line endings in the status bar instead of reporting only its predominant LF or CRLF sequence.

## Best solution

Retain mixed-EOL metadata detected while loading the text buffer and expose it to the editor status contribution, which should render a localized mixed-state label while preserving the existing EOL selection command.
