# Issue #331443 — Button missing a tooltip in the search panel

[https://github.com/microsoft/vscode/issues/331443](https://github.com/microsoft/vscode/issues/331443)

## Summary

The screenshot identifies the disabled Search only in Changed Files toggle. Its tooltip text exists, but disabled-toggle CSS prevents pointer events from reaching the hover target, so the discoverability defect remains on current main.

## Change summary

Show the changed-files search toggle's tooltip even when the control is disabled.

## Best solution

Keep the search filter discoverable while disabled without allowing activation or changing its SCM-based enablement. Preserve the existing tooltip and enabled-state filtering behavior.
