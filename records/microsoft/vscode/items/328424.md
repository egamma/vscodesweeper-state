# Issue #328424 — Review agent changes covers the Copilot tools menu

[https://github.com/microsoft/vscode/issues/328424](https://github.com/microsoft/vscode/issues/328424)

## Summary

The collision remains possible on current main: the pending-edit review toolbar is a fixed bottom-right overlay above the suggestion widget used by Inline Chat. This should stay open and be routed to the Inline Chat and edit-review owners.

## Change summary

The Keep/Undo review overlay obscures part of the tool or command suggestion menu opened with `#` or `/` in Inline Chat.

## Best solution

Keep the tool suggestion menu fully visible and interactive while pending-edit review controls are present, including in constrained editor layouts, without hiding change navigation or bulk review actions.

- **Trace:**

Inline Chat creates a separate overflow host in EditorBasedInlineChatWidget at src/vs/workbench/contrib/inlineChat/browser/inlineChatWidget.ts, and its Monaco suggestion widget uses z-index 40 in src/vs/editor/contrib/suggest/browser/media/suggest.css. ## Evidence

- **confirmed trigger:** The issue screenshot and steps show the collision after leaving agent edits pending and opening the `#` or `/` suggestion menu in Inline Chat.
