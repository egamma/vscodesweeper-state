# Issue #179952 — RunTask command lists duplicate tasks when a filter is applied

[https://github.com/microsoft/vscode/issues/179952](https://github.com/microsoft/vscode/issues/179952)

## Summary

Keep open: a maintainer reproduced the issue after the reporter clarified that `script`, not `label`, must change. Current source still exposes an identity mismatch between listed tasks and execution-time lookup; no verified fix or open canonical was found.

## Change summary

Changing an npm task's script while retaining its label produces duplicate-looking entries in the filtered Run Task picker, both executing the configured script.

## Best solution

Ensure the filtered picker distinguishes genuinely different task definitions and that execution preserves the selected task's identity after configuration reload. Retest the clarified reproduction before deciding whether the remaining defect is presentation, execution-time resolution, or both.
