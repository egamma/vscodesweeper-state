# Issue #313973 — Failed to inline attachments: getting signed attachment URLs for images

[https://github.com/microsoft/vscode/issues/313973](https://github.com/microsoft/vscode/issues/313973)

## Summary

Keep open as an upstream image-asset lifecycle defect. Multiple reporters confirm that signed attachments become inaccessible, and the client-side retry mitigation on current main does not prevent the underlying request failure.

## Change summary

Prevent Copilot Chat requests from failing when a previously attached image can no longer be signed or retrieved.

## Best solution

The Copilot service should keep image assets accessible for the conversation lifetime or refresh stale signed references. VS Code should also preserve the usable text conversation and continue gracefully when a historical image cannot be restored.
