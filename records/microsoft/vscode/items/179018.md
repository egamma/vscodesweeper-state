# Issue #179018 — Support keybindings with > 2 chords in "Define keybinding" widget

[https://github.com/microsoft/vscode/issues/179018](https://github.com/microsoft/vscode/issues/179018)

## Summary

Still unimplemented on main: the 'Define Keybinding' widget explicitly caps chord input at 2 (line 121 of keybindingWidgets.ts has `// TODO: limit chords # to 2 for now`). The underlying keybinding engine already supports >2 chords since PR #175253, but the widget UI was intentionally left limited. This is a valid follow-up from the same team member who co-authored the multi-chord support.

## Change summary

Allow the 'Define Keybinding' widget to accept more than 2 chords, matching the engine's existing capability.

## Best solution

Remove the 2-chord cap in `KeybindingsSearchWidget` (src/vs/workbench/contrib/preferences/browser/keybindingWidgets.ts, around line 121) and allow unbounded chord sequences in the widget, since the resolver already supports them.
