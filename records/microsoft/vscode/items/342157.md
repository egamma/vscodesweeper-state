# Issue #342157 — Add Pinned tab to the new model picker

[https://github.com/microsoft/vscode/issues/342157](https://github.com/microsoft/vscode/issues/342157)

## Summary

Cross-provider access to pinned models remains missing: current tabs partition models by provider, while global search does not provide a pinned-only destination. Keep this team-authored request open for a design decision that weighs faster switching against the maintainer's stated concern about a noisy home tab.

## Change summary

Provide a Pinned tab containing pinned models from all providers in the new model picker.

## Best solution

Resolve whether a cross-provider pinned destination should complement provider tabs, explicitly revisiting the earlier home-tab decision. If accepted, users should be able to browse and select their pinned models together without searching or switching providers; the reported search delay should be investigated separately.
