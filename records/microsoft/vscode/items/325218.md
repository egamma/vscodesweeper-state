## Summary

The blank Search tab now has a centered empty state, but this study's recommended top hint and example searches remain unaddressed. Keep this team-authored design request open to reconcile its recommendations with the subsequently merged design; no qualifying duplicate or fix explicitly referencing this issue was found.

## Change summary

Provide an informative Agents Window Search empty state using the study-preferred top hint, followed by example searches that clarify file-search scope.
