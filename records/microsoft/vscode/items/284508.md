## Summary

The command-applicability problem remains traceable on current main: @vscode can offer a palette search for Refresh Preview while that command is hidden in the current editor context. Keep this team-authored Backlog bug open; neither a qualifying fix nor an open canonical was established.

## Change summary

Prevent @vscode refresh-preview suggestions from producing an unusable command-palette button or changing the button text when clicked.

## Best solution
