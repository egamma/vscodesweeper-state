Team-authored API proposal issue that is actively being developed — the initial implementation landed via PR #271716 as a proposed API (`mcpToolDefinitions`), but the API has not yet been finalized. Must remain open as the tracking issue for finalization.

## Change summary

Allow MCP extensions to provide a static manifest of metadata (tools, instructions, capabilities) so VS Code can defer server startup until a tool is actually invoked.

## Best solution

Continue tracking this as the canonical issue for finalizing the `mcpToolDefinitions` proposed API. The next step is API finalization — moving the proposal to stable when the team is satisfied with the shape.
