# Issue #348505 — Adding a comment at the end of the viewport scrolls the view port

## Summary

Keep open for the assigned 1.148.0 milestone. The current floating-comment placement and reveal paths still permit opening a comment near the viewport bottom to scroll the editor instead of placing it above the line.

## Change summary

Opening a comment at the bottom of the viewport should place the widget above the line when space permits rather than scroll the editor.
