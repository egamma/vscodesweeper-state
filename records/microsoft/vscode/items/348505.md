# Issue #348505 — Adding a comment at the end of the viewport scrolls the view port

[https://github.com/microsoft/vscode/issues/348505](https://github.com/microsoft/vscode/issues/348505)

## Summary

Keep open: the floating comment placement can extend below the viewport and subsequently scroll the editor instead of opening above the line. The assigned 1.148.0 milestone independently requires keeping this scheduled issue open.

## Change summary

Opening a comment near the viewport bottom should prefer available space above the line rather than scrolling the editor.

## Best solution

Make automatic floating-comment placement consider the visible editor viewport before requesting a scroll, while preserving explicit reveal behavior and user-positioned widgets.
