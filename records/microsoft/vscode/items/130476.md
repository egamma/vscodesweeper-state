# Issue #130476 — VS code not preventing MacOS sleep

[https://github.com/microsoft/vscode/issues/130476](https://github.com/microsoft/vscode/issues/130476)

## Summary

Keep open and route to native OS integration. The request was promoted to Backlog with 55 upvotes, and current main only prevents sleep for Copilot chat requests—not for general tasks, terminals, or debug sessions.

## Change summary

Prevent macOS sleep or automatic restart while VS Code is running long-lived code, task, terminal, or debug operations.

## Best solution

Use the existing power service to hold a lifecycle-scoped `prevent-app-suspension` blocker during selected long-running task, terminal, and debug operations, with a clear battery and opt-in policy. Treat automatic-restart prevention separately because the current power blocker only addresses suspension.
