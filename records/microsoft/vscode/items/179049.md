# Issue #179049 — Printing special characters in integrated terminal coud crash remote extension

[https://github.com/microsoft/vscode/issues/179049](https://github.com/microsoft/vscode/issues/179049)

## Summary

Confirmed freeze when rendering long sequences of combining characters (e.g. 72× COMBINING GRAVE ACCENT) in the integrated terminal. Root cause is likely in xterm.js text rendering, which VS Code bundles; no fix commit referencing this issue was found on main despite many xterm.js version bumps since the report.

## Change summary

Printing sequences with many combining Unicode characters (e.g. combining grave accents) in the integrated terminal freezes VS Code.

## Best solution

The fix belongs in xterm.js's rendering pipeline — either clamping the number of combining marks rendered per cell or short-circuiting layout for degenerate glyph clusters. If xterm.js already addressed this in a recent beta, a targeted reproduction test against current main would confirm and this can be closed. Otherwise, file or find the upstream xterm.js issue and link it here.
