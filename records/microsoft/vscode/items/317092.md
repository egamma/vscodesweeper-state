# Issue #317092 — Could these diagrams have names somehow?

[https://github.com/microsoft/vscode/issues/317092](https://github.com/microsoft/vscode/issues/317092)

## Summary

The mermaid rendering infrastructure already accepts a title parameter from the tool, but the chat output HTML always shows the generic 'Mermaid Diagram' heading — the title is never surfaced in the visible UI. Still unfixed on main.

## Change summary

Multiple mermaid diagrams in chat all display the same generic 'Mermaid Diagram' label with no distinguishing name.

## Best solution

Use the `title` field (already decoded in `chatOutputRenderer.ts` line 34) in the webview HTML — both the `<title>` tag and as a visible header/label above the diagram. Also update the `aria-label` in `diagramManager.ts` to include the title when available. The LLM tool schema already declares `title?: string`, so the model can supply distinct names once the UI renders them.
