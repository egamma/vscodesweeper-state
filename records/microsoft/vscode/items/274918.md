# Issue #274918 — Instruction ApplyTo Not Applied - Open Editor Files Not Auto-Attached as Context

[https://github.com/microsoft/vscode/issues/274918](https://github.com/microsoft/vscode/issues/274918)

## Summary

Keep open for customization owners: current main forwards the active editor in several chat paths, but instruction matching still derives from attached or implicit context and does not consider every open editor tab. This is a team-authored, accepted bug with no explicitly linked fixing commit, so the hard keep-open rule applies.

## Change summary

Make `applyTo` instructions activate for relevant open editor files without requiring users to attach those files manually.

## Best solution

Define whether instruction applicability should use only the active editor or all open tabs, then consistently supply those paths to instruction matching across local Chat and Agent Host sessions without unnecessarily attaching every file's contents.
