# Issue #331953 — Add support performance measurement and statistics for Chat Session

[https://github.com/microsoft/vscode/issues/331953](https://github.com/microsoft/vscode/issues/331953)

## Summary

Reasonable, brand-new request (posted hours ago, no traction yet) for surfacing chat performance stats; time-to-first-token is already tracked extensively via ChatPerfMark and the chat debug view, but tokens-per-second is not, so a real (partial) gap remains — routing to the chat area for maintainer triage rather than closing.

## Change summary

Add performance metrics for chat/agent requests — time to first token and tokens generated per second — to help assess API/model performance.

## Best solution

Time-to-first-token is already instrumented (src/vs/workbench/contrib/chat/common/chatPerf.ts ChatPerfMark.FirstToken, and shown in the chat debug view via chatDebugModelTurnContentRenderer.ts / chatDebugCacheExplorerView.ts, plus copilot extension telemetry in chatMLFetcherTelemetry.ts). The remaining gap is a tokens-per-second metric and/or exposing these stats in a more end-user-visible surface than the internal chat debug view; a maintainer should decide whether to extend the existing chat debug/perf infrastructure or treat this as covered by it.
