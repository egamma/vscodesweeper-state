# Issue #328775 — Confirmation pending inside sub-agent still unclear.

[https://github.com/microsoft/vscode/issues/328775](https://github.com/microsoft/vscode/issues/328775)

## Summary

Team-authored UX feedback from active testing of the sub-agent confirmation flow in the Agents window; another maintainer already agreed and proposed follow-up ideas, so this should stay open and route to the owning area.

## Change summary

When multiple sub-agents have pending confirmations, the coloring cue is hard to associate at a distance, and the confirmation title doesn't clearly tie back to the sub-agent's pill name.

## Best solution

Improve the sub-agent confirmation dialog/title association with its pill (e.g. clearer naming/alignment) and consider a 'pending' pill affordance that scrolls to the responsible subagent when it's out of view, as justschen suggested — likely in the Agents window chat/subagent rendering code (src/vs/sessions or the workbench chat contrib subagent UI).
