# Issue #345801 — Markdown-based Copilot language modes prevent use of the configured Markdown formatter

[https://github.com/microsoft/vscode/issues/345801](https://github.com/microsoft/vscode/issues/345801)

## Summary

Keep open as a compatibility feature request: current provider matching requires explicit language support, so Markdown grammar reuse does not make Markdown formatters available to Skill or Agent documents. No verified canonical or landed implementation covers the requested fallback.

## Change summary

Preserve Markdown formatting for Skill and Agent documents without losing their specialized editing features.

## Best solution

Establish the supported formatter integration contract for Markdown-derived language modes. Explicit provider registration supports these modes today; automatic delegation would require a core design decision that preserves document identity and existing selector semantics.
