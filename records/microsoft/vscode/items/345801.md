# Issue #345801 — Markdown-based Copilot language modes prevent use of the configured Markdown formatter

[https://github.com/microsoft/vscode/issues/345801](https://github.com/microsoft/vscode/issues/345801)

## Summary

Keep open as a formatter-interoperability request: current provider matching requires explicit language support, and Markdown syntax does not confer formatter inheritance. The requested compatibility remains missing, but introducing delegation needs a supported contract rather than treating existing selector matching as defective.

## Change summary

Preserve access to Markdown formatters for Skill and Agent documents without losing their specialized editing features.

## Best solution

Establish a supported formatting integration contract for Markdown-derived language modes, preserving specialized editing and formatter opt-in boundaries. Explicit extension registrations can address individual formatters, but do not by themselves resolve the broader compatibility request.
