# Issue #345801 — Markdown-based Copilot language modes prevent use of the configured Markdown formatter

[https://github.com/microsoft/vscode/issues/345801](https://github.com/microsoft/vscode/issues/345801)

## Summary

Keep open as a formatter-integration feature request: current provider matching follows the documented language-ID contract, but it does not preserve Markdown formatter access for Skill and Agent modes. Biome has an open compatibility proposal; that does not resolve the broader VS Code request.

## Change summary

Preserve Markdown formatting for Skill and Agent files without losing their specialized editing features or requiring per-user language reassociations.

## Best solution

Establish the supported formatter integration contract for Markdown-derived modes, including whether compatibility remains explicit provider registration or gains an opt-in delegation mechanism. Preserve specialized editing features and existing provider-selection semantics.
