# Issue #129425 — Chosen user-settings debug launch configuration not remembered

[https://github.com/microsoft/vscode/issues/129425](https://github.com/microsoft/vscode/issues/129425)

## Summary

The configuration-change case remains reproducible from current source: editing any launch configuration can replace a selected user-settings configuration with the active workspace's configuration. The issue should remain open in the debug backlog.

## Change summary

Preserve the selected user-level debug launch configuration across window reloads and edits to launch configuration files.

## Best solution

Keep the selected launch source and configuration name when launch settings are reloaded, provided that configuration still exists; use the existing fallback selection only when the selected launch or configuration has disappeared.
