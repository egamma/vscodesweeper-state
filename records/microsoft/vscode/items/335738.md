# Issue #335738 — Add Feedback gutter button width grows with line-number digits

[https://github.com/microsoft/vscode/issues/335738](https://github.com/microsoft/vscode/issues/335738)

## Summary

Traced the root cause in the checkout: the feedback affordance is rendered via Monaco's `lineNumberClassName` decoration, which puts the `agent-feedback-glyph` class directly on the shared `.line-numbers` gutter element (see `agentFeedbackEditorInputContribution.ts` line ~351), and the CSS `::before` icon is positioned with `inset: 0` inside that same element (`agentFeedbackEditorInput.css`). Since `.line-numbers` width scales with the max line-number digit count in the file, the '+' affordance stretches with it on large files.

## Change summary

The Add Feedback gutter '+' button grows wider as a file's line count (and thus its line-number digit width) increases, instead of staying a compact fixed-size affordance.

## Best solution

In agentFeedbackEditorInput.css, give the `.line-numbers.agent-feedback-glyph.line-hover::before` icon a fixed small width (e.g. matching the codicon size) and center it within the gutter instead of `inset: 0`, so it no longer inherits the full width of the digit-scaled `.line-numbers` element.
