# Issue #114866 — Native Notebooks - Collapsing output from bottom leads to incorrect scroll location

[https://github.com/microsoft/vscode/issues/114866](https://github.com/microsoft/vscode/issues/114866)

## Summary

Keep open: the current collapse and list-layout paths still permit collapsing a tall, partially visible output to leave its cell above the viewport. The related scroll-design issue was closed without identifiable fix provenance for this case, and no qualifying canonical duplicate was found.

## Change summary

Keep the affected notebook cell visible when its long output is collapsed from near the bottom.

## Best solution

Make explicit output collapse preserve visibility of the affected cell in the notebook command/layout path, without changing ordinary scrolling or background output-resize behavior. Retain the top-of-output behavior that already works.
