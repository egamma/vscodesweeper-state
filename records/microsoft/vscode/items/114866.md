# Issue #114866 — Native Notebooks - Collapsing output from bottom leads to incorrect scroll location

[https://github.com/microsoft/vscode/issues/114866](https://github.com/microsoft/vscode/issues/114866)

## Summary

Keep open: current main does not preserve the collapsed cell in view, and the only matching implementation was abandoned off main. This is also a team-authored UX issue without a qualifying referenced fix or open canonical duplicate.

## Change summary

Keep a notebook cell visible when its long output is collapsed while viewing the output's bottom.

## Best solution

Define the desired anchoring behavior for shrinking notebook cells, then adjust `NotebookCellList.updateElementHeight2` so collapsing a long output reveals part of its owning cell without disturbing unrelated resize flows.
