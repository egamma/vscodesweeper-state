# Issue #277281 — Cannot complete a single task.

[https://github.com/microsoft/vscode/issues/277281](https://github.com/microsoft/vscode/issues/277281)

## Summary

Keep open as an upstream reliability limitation: the provider can report overload after streaming has begun, and the client is not given advance capacity information. Auto routing now reduces exposure by selecting a model before a turn, but current source does not preserve or reroute a response that fails mid-stream.

## Change summary

Avoid losing a long-running Copilot task when its selected model provider reports high demand after streaming has started.

## Best solution

The service and model providers should support capacity-aware routing or a resumable failover that preserves completed tool work and partial response state when overload occurs mid-turn. VS Code should continue presenting actionable retry timing and Auto routing, but cannot reliably fail early without an upstream availability signal.
