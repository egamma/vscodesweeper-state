# Issue #331876 — chat.tools.terminal.autoApprove

## Summary

This is feedback about where terminal approval rules are stored, rather than a demonstrated bug. Existing session-scoped approvals provide a nonpersistent alternative, but do not settle the objection to storing persistent approvals in user settings.

## Change summary

Reconsider storing persistent AI Chat terminal approval rules in chat.tools.terminal.autoApprove in user settings.

## Best solution

Establish whether the requested outcome is nonpersistent approvals or a separate store for persistent grants. Preserve explicit approval scopes; consider the storage-location feedback alongside the existing CLI/SDK permissions convergence discussion without treating the reports as proven duplicates.
