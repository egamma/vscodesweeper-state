# Issue #264983 — Hide 0x multiplier for custom models?

[https://github.com/microsoft/vscode/issues/264983](https://github.com/microsoft/vscode/issues/264983)

## Summary

The inconsistency remains possible on current main: model-picker presentation treats a numeric multiplier of zero as displayable pricing, so custom-model metadata containing `pricing: "0x"` and `multiplierNumeric: 0` renders the misleading label. The existing `bug` and `model-picker` triage should stand.

## Change summary

Hide the meaningless `0x` cost multiplier for custom models consistently across model-picker surfaces.

## Best solution

Treat a zero multiplier on a user-provided model as absent pricing throughout the picker row, hover, and details card, while preserving meaningful provider-supplied pricing and Copilot billing presentation.
