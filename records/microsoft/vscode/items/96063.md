# Issue #96063 — Auto-hide Activity Bar exactly like Windows taskbar

[https://github.com/microsoft/vscode/issues/96063](https://github.com/microsoft/vscode/issues/96063)

## Summary

This remains a valid, community-promoted Backlog request that current Activity Bar settings do not fully satisfy. Route it to the existing `layout` area rather than closing it.

## Change summary

Automatically hide the Activity Bar and reveal it on pointer proximity, like the Windows taskbar.

## Best solution

The layout owners should decide whether the Activity Bar can support edge-triggered reveal without harming discoverability, accessibility, or layout stability. If accepted, implement it alongside the Activity Bar location and visibility behavior.
