# Issue #158873 — Click in scroll decorations in diff editor doesn't always go to the clicked section

[https://github.com/microsoft/vscode/issues/158873](https://github.com/microsoft/vscode/issues/158873)

## Summary

Keep open: current source still mixes the full-height diff overview with the banner-shortened editor scrollbar, causing clicks to use different coordinates from the displayed decorations. The maintainer-confirmed report remains necessary; no verified canonical or qualifying fix was found.

## Change summary

Clicking diff overview decorations should navigate to the corresponding section even when the Unicode highlighting banner is visible.

## Best solution

Make the diff overview's decoration geometry, viewport indicator, and pointer navigation agree when an editor banner reserves vertical space, while preserving navigation without a banner.

With a banner, this origin and track height differ from the full-height diff overview displaying the clicked decoration.
