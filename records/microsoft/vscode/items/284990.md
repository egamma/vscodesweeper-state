# Issue #284990 — Command Palette cannot find related commands when Keyboard Shortcuts view is open

[https://github.com/microsoft/vscode/issues/284990](https://github.com/microsoft/vscode/issues/284990)

## Summary

Current source confirms that editor-only commands disappear when Keyboard Shortcuts replaces the active text editor. A maintainer identified this as likely intentional but assigned the editor owner for a decision, so this should be routed rather than closed.

## Change summary

Keep relevant editor commands discoverable in the Command Palette while the Keyboard Shortcuts editor is active.

## Best solution

The editor and quick-access owners should decide whether unavailable editor actions remain hidden or appear disabled; if the latter is accepted, command discovery should preserve the action label without allowing execution when no code editor is active.
