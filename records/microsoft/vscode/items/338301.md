# Issue #338301 — keyboard shortcut stopped working

[https://github.com/microsoft/vscode/issues/338301](https://github.com/microsoft/vscode/issues/338301)

## Summary

This is the same AltGr-vs-Ctrl+Alt keybinding conflict already tracked, confirmed, and assigned on microsoft/vscode#283735 — the reporter's Hungarian QWERTZ layout generates Í from AltGr+I (which Windows reports as Ctrl+Alt), colliding with their Ctrl+Alt+I shortcut, exactly the mechanism described there. Proposing a duplicate close to consolidate.

## Change summary

On Windows, the Ctrl+Alt+I keyboard shortcut stopped firing and instead inserts the character Í.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/283735, which is open, assigned, and tracks the general case: VS Code's KeybindingService cannot currently distinguish a genuine Ctrl+Alt chord from an AltGr-produced character on Windows layouts where AltGr+key yields a special character, so Ctrl+Alt shortcuts on those layouts lose to character insertion.
