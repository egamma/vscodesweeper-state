# Issue #338301 — keyboard shortcut stopped working

[https://github.com/microsoft/vscode/issues/338301](https://github.com/microsoft/vscode/issues/338301)

## Summary

This is the same Ctrl+Alt-vs-AltGr regression on Windows already tracked by the older, well-diagnosed https://github.com/microsoft/vscode/issues/283735 — Ctrl+Alt shortcuts are being interpreted as AltGr and produce the layout's alternate character (here Í on a Hungarian QWERTZ layout) instead of firing the keybinding. Proposing a duplicate close to consolidate the discussion.

## Change summary

Ctrl+Alt+I stopped triggering its keybinding on Windows and now inserts the character Í instead.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/283735, which already has a detailed comment thread analyzing the Ctrl+Alt/AltGr disambiguation problem and the `keyboard.mapAltGrToCtrlAlt` setting's interaction with it; fixing the dispatch/mapping logic there resolves this report too.
