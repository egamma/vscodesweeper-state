# Issue #314112 — Unable to differentiate between browser tabs to share with the agent when the url is the same

[https://github.com/microsoft/vscode/issues/314112](https://github.com/microsoft/vscode/issues/314112)

## Summary

Still reproduces on main: the tab-sharing carousel in `openBrowserTool.ts` builds options from editor title + truncated URL with no disambiguator, so tabs with identical URLs are indistinguishable. The focus-on-select issue also remains unaddressed. Team-authored, keeping open.

## Change summary

When the agent prompts the user to share a browser tab and multiple tabs share the same URL, the carousel options are visually identical, and selecting one does not bring the tab into focus.

## Best solution

In `_buildShareCarousel` (openBrowserTool.ts ~L228), add a disambiguator to the carousel label when multiple editors share the same URL — e.g. append a tab index or group position. For the focus issue, `_shareExistingPage` (or its caller) should reveal the selected editor via `IEditorService` after sharing.
