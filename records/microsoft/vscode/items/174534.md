# Issue #174534 — Bracket indent guides are only displayed on the active cursor

[https://github.com/microsoft/vscode/issues/174534](https://github.com/microsoft/vscode/issues/174534)

## Summary

Active bracket-pair guides still use only the primary cursor on current main. Keep this accepted request open while the existing implementation candidate is reviewed; its linked PR remains open and unmerged.

## Change summary

Display and highlight active bracket-pair guides for every cursor in a multi-cursor selection.

## Best solution

Make active bracket-pair guides reflect all cursor positions consistently with bracket highlighting. Review the existing implementation in https://github.com/microsoft/vscode/pull/175813 rather than starting a competing fix.
