# Issue #184172 — API to access the product configuration

[https://github.com/microsoft/vscode/issues/184172](https://github.com/microsoft/vscode/issues/184172)

## Summary

Team-authored feature request (hard keep-open). The proposed resolvers API added `commit` and `quality` to `env`, but the remaining properties (`serverDataFolderName`, `serverApplicationName`, `updateURL`) have not been exposed via any extension API on current main.

## Change summary

Expose product configuration properties (commit, quality, serverDataFolderName, serverApplicationName, updateURL) through a VS Code extension API, especially for web where extensions cannot read the install layout.

## Best solution

Decide whether to add the remaining product-configuration properties (`serverDataFolderName`, `serverApplicationName`, `updateURL`) to the proposed resolvers API or introduce a dedicated opaque product-configuration surface as connor4312 suggested. This is a remote/tunnel concern — the area owner should scope which properties to expose.
