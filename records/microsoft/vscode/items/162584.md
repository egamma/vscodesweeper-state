# Issue #162584 — F8 should be aware of recent changes and choose the next problem based on the cursor position

[https://github.com/microsoft/vscode/issues/162584](https://github.com/microsoft/vscode/issues/162584)

## Summary

Keep open: current navigation partially follows the cursor, but still uses diagnostic snapshots rather than edit-tracked ranges. The maintainer-supported request for reliable rapid fix-and-navigate behavior remains distinct from the related issues inspected.

## Change summary

Make repeated F8 navigation after quick fixes select the next problem reliably despite edits and delayed diagnostic recomputation.

## Best solution

Make editor problem navigation account for edit-adjusted locations and asynchronous diagnostic refreshes, preserving configured severity ordering and cross-file navigation. First establish a deterministic reproduction of the rapid quick-fix sequence and settle navigation behavior while diagnostics are pending.
