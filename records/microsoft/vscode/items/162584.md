# Issue #162584 — F8 should be aware of recent changes and choose the next problem based on the cursor position

[https://github.com/microsoft/vscode/issues/162584](https://github.com/microsoft/vscode/issues/162584)

## Summary

The requested navigation improvement remains relevant: current main still resets marker navigation after diagnostics change, making rapid fix-and-F8 sequences depend on timing.

## Change summary

Make F8 choose the next problem relative to the current cursor after recent diagnostic changes.

## Best solution

Update `MarkerList` in `src/vs/editor/contrib/gotoError/browser/markerNavigationService.ts` to preserve or rebase navigation against the live cursor when diagnostics change, including changes arriving during a rapid quick-fix workflow.
