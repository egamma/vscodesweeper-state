## Summary

Confirmed upstream xterm.js bug (xtermjs/xterm.js#5240) that remains open — the DOM renderer clips tall glyphs. Already correctly labeled and tracked; nothing to change.

## Change summary

Terminal DOM renderer clips the top of tall Unicode glyphs (e.g. U+23A1 ⎡) when using fonts like Consolas that vertically offset these characters.

## Best solution

Wait for the upstream fix in xtermjs/xterm.js#5240 to land and then pull it into VS Code's xterm.js dependency. No core VS Code change needed — the fix belongs in the xterm.js DOM renderer.
