# Issue #275218 — Anthropic BYOK leaves incomplete sentence before tool call

[https://github.com/microsoft/vscode/issues/275218](https://github.com/microsoft/vscode/issues/275218)

## Summary

The defect remains source-reproducible on current main: built-in BYOK providers expose completed tool calls but do not propagate the earlier tool-start and partial-argument events needed to flush the linkifier before a large call finishes.

## Change summary

Anthropic and OpenAI BYOK responses can leave the final words of assistant text hidden while lengthy tool-call arguments stream.

## Best solution

Carry tool-start and partial-input events across the built-in BYOK language-model bridge so the existing chat response processor can begin the invocation and flush pending linkified Markdown immediately, while preserving the completed tool-call behavior.
