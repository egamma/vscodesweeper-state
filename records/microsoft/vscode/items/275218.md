# Issue #275218 — Anthropic BYOK leaves incomplete sentence before tool call

[https://github.com/microsoft/vscode/issues/275218](https://github.com/microsoft/vscode/issues/275218)

## Summary

The BYOK streaming path still omits the early tool-start signal that flushes buffered sentence text. Keep this accepted, team-authored bug open; current source confirms the gap for Anthropic and the shared OpenAI-compatible path.

## Change summary

Display the complete preceding sentence while a BYOK model is still generating tool-call arguments.

## Best solution

Anthropic and OpenAI-compatible BYOK requests should expose the same early tool-invocation boundary as non-BYOK requests, allowing buffered prose to appear before large tool arguments finish streaming without executing an incomplete call.
