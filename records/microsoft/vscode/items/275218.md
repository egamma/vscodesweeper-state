# Issue #275218 — Anthropic BYOK leaves incomplete sentence before tool call

[https://github.com/microsoft/vscode/issues/275218](https://github.com/microsoft/vscode/issues/275218)

## Summary

Still unfixed on main: the Anthropic BYOK provider does not signal the linkifier to flush pending text when a tool_use content block starts, leaving an incomplete sentence visible before the tool call UI appears.

## Change summary

Anthropic BYOK chat responses show an incomplete trailing sentence before tool call rendering because the linkifier isn't flushed at that boundary.

## Best solution

In `extensions/copilot/src/extension/byok/vscode-node/anthropicProvider.ts`, when a `content_block_start` of type `tool_use` arrives, emit a `ChatPrepareToolInvocationPart` (or equivalent flush signal) into the progress stream before accumulating the tool call — mirroring how non-BYOK responses handle this transition. The OpenAI BYOK provider likely needs the same treatment.
