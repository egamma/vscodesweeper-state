# Issue #228100 — Shift is not recognised

[https://github.com/microsoft/vscode/issues/228100](https://github.com/microsoft/vscode/issues/228100)

## Summary

The Shift key reports keyCode 0 because the OS-level Ctrl+Shift language switch intercepts the modifier before VS Code receives it. The reporter's own workaround (changing the switch to Alt+Shift) confirms the OS is the source, but this may still be a VS Code Wayland/keyboard-layout handling gap. The issue is stale (683 days, no maintainer interaction) and needs confirmation on current builds.
