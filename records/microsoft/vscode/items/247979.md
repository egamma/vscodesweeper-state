# Issue #247979 — Ensure proper auth when reporting issue to prevent URL too long.

[https://github.com/microsoft/vscode/issues/247979](https://github.com/microsoft/vscode/issues/247979)

## Summary

Keep open: maintainers confirmed that a long Python issue template can fail when issue-reporter authentication is unavailable despite an existing Copilot sign-in. Current source provides long-URL mitigations, but these do not establish that authentication is handled correctly, and no issue-referencing fix was found for this team-authored report.

## Change summary

Ensure issue reporting handles GitHub authentication correctly so long extension-provided reports do not fail or lose their prefilled content.

## Best solution

Make the core issue-reporting flow reliably obtain appropriate GitHub authentication or provide a usable unauthenticated fallback that preserves the report. Retest the Python-generated template with Copilot signed in but issue-reporter authentication unavailable, covering both legacy and wizard reporting paths.
