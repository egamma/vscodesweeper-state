# Issue #342690 — Customizations can't install plugins for the Copilot harness in remote windows: "The selected agent does not support SDK plugin installation"

[https://github.com/microsoft/vscode/issues/342690](https://github.com/microsoft/vscode/issues/342690)

## Summary

The reported failure remains source-reproducible on current main: remote windows select an Agent Host client without installPlugin, while Discover advertises plugin installation and routes it to that missing capability. Keep this open for remote SDK-owned installation support; the SDK migration issue is closed and does not resolve this remaining path.

## Change summary

Make Customizations plugin installation work for the Copilot harness when its Agent Host runs remotely, without offering an unusable Install action.

## Best solution

Remote Copilot installations should reach the owning SDK inventory with the correct session, account, policy, and remote context. Unsupported hosts should expose an explicit unavailable state before installation, and recovery should not recreate the separate VS Code-owned inventory that the SDK migration deliberately removed.
