# Issue #329843 — Main process leaks all terminal output via Event.buffer on the localPty ProxyChannel — OOM-crashes the whole app silently

[https://github.com/microsoft/vscode/issues/329843](https://github.com/microsoft/vscode/issues/329843)

## Summary

Verified duplicate: this is the same main-process OOM root cause already tracked (with team confirmation) by the open canonical issue #234393, and an open PR (#323980, 'Fixes #234393') already implements the exact fix this report suggests — registering the localPty channel with unbuffered high-frequency events.

## Change summary

The main process's localPty ProxyChannel eagerly buffers every onProcessData event forever (no listener ever attaches on desktop), leaking terminal output strings until the main process OOM-crashes silently.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/234393 and land https://github.com/microsoft/vscode/pull/323980, which adds a `disableEventBuffering`/`unbufferedEvents`-style option to `ProxyChannel.fromService` and applies it to the `TerminalIpcChannels.LocalPty` registration in src/vs/code/electron-main/app.ts — this issue's detailed heap-snapshot evidence and Windows-specific data should be added as a comment on the canonical rather than tracked separately.
