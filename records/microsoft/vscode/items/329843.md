# Issue #329843 — Main process leaks all terminal output via Event.buffer on the localPty ProxyChannel — OOM-crashes the whole app silently

[https://github.com/microsoft/vscode/issues/329843](https://github.com/microsoft/vscode/issues/329843)

## Summary

Verified duplicate: this is an extremely well-diagnosed instance of the main-process pty-buffer OOM already tracked by open issue #234393, which an open fixing PR (#323980) explicitly targets — and maintainers already closed an equally detailed report (#307156) as a duplicate of #234393, establishing clear precedent.

## Change summary

The main process buffers every terminal onProcessData event forever via Event.buffer on the unlisted localPty ProxyChannel, causing an unbounded heap leak and eventual silent OOM crash.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/234393 and land https://github.com/microsoft/vscode/pull/323980 (adds a `disableEventBuffering`/unbuffered-events option for the LocalPty channel registration in src/vs/code/electron-main/app.ts); no separate fix is needed for this report.
