Keep open while reconciling the confirmed historical limitation with current source, which already attempts to fetch localized bundles from an extension's location. This team-authored, accepted request has neither an explicitly linked fixing commit nor a verified canonical duplicate.

## Change summary

Allow developers to test extension translations when installing a web extension from a localhost URL without publishing it.

## Best solution

Localization testing through Install Extension from Location should load the extension's locale-specific bundle without requiring Marketplace publication. Verify that workflow against the current web extension host before adding functionality, since the runtime bundle-fetching path already exists.
