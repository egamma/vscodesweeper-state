# Issue #182441 — Regression: TextEditorEdit.replace does not select empty selection anymore

[https://github.com/microsoft/vscode/issues/182441](https://github.com/microsoft/vscode/issues/182441)

## Summary

The regression remains in current main: cursor recovery now collapses an originally empty selection to the end of inserted text, including edits made through TextEditorEdit.replace. The issue should remain open because restoring the API behavior must preserve the separate multi-editor fix that introduced this regression.

## Change summary

TextEditorEdit.replace no longer leaves newly inserted text selected when replacing the editor's empty selection.

## Best solution

Restore the historical and documented distinction between replace and insert for an empty current selection, while retaining collapsed cursor recovery for edits arriving from another editor on the same model.
