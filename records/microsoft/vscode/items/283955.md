# Issue #283955 — Allow exporting flattened view for LLM's text response and toolcall results

[https://github.com/microsoft/vscode/issues/283955](https://github.com/microsoft/vscode/issues/283955)

## Summary

Keep open: session exports still serialize structured response metadata rather than providing the requested flattened tool-result view. The helper suggested in the discussion supports programmatic rendering, but does not establish that session export delivers this capability.

## Change summary

Provide a flattened text representation of model responses and tool results, including LanguageModelPromptTsxPart content, in exported chat sessions.

## Best solution

Offer a consumable flattened representation alongside the existing structured session data, preserving import compatibility. The chat export owners should first settle the output contract and treatment of non-text tool content.
