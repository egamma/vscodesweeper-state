# Issue #296820 — Command to restart specific extension host

[https://github.com/microsoft/vscode/issues/296820](https://github.com/microsoft/vscode/issues/296820)

## Summary

The capability remains absent on current main, and the existing extension-host label routes it correctly. This team-authored Backlog request should remain open for implementation or prioritization.

## Change summary

Add a command that restarts one selected extension host without disrupting the other running hosts.

## Best solution

Extend the extension service with a targeted restart operation keyed by running location or host manager, then expose a Developer command that lets users select the host while preserving unaffected hosts and their extension state.
