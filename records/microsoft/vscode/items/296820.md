# Issue #296820 — Command to restart specific extension host

[https://github.com/microsoft/vscode/issues/296820](https://github.com/microsoft/vscode/issues/296820)

## Summary

The requested selective restart is still missing: the developer command stops and starts all extension hosts, while remote crash recovery is not a command for restarting an arbitrary running host. Keep this accepted, team-authored Backlog request open; no verified canonical or fixing commit was found.

## Change summary

Provide a command that restarts one extension host without interrupting the others, enabling isolated playground-extension reloads.

## Best solution

Expose a targeted extension-host restart with a clear host-selection contract and preserve the other hosts' running extensions. Establish whether restarting the playground host also refreshes its changed package.json contributions, since that is the motivating workflow.
