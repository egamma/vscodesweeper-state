# Issue #164014 — window.zoomLevel causing blurry canvas

[https://github.com/microsoft/vscode/issues/164014](https://github.com/microsoft/vscode/issues/164014)

## Summary

The request to round zoom levels to Chromium's fixed zoom factors (avoiding non-integer devicePixelRatio values that cause blurry canvas) is still unaddressed on current main — `zoomLevelToZoomFactor` still uses `1.2 ** zoomLevel` without any rounding.

## Change summary

Canvas elements rendered in extensions appear blurry at non-integer devicePixelRatio values caused by VS Code's exponential zoom formula.

## Best solution

The maintainer concern (comment #3) was about risk of changing zoom behavior. The lowest-risk improvement would be an opt-in setting or snapping the computed zoom factor to the nearest Chromium-native level (1.0, 1.1, 1.25, 1.5, 1.75, 2.0…) in `src/vs/platform/window/common/window.ts:zoomLevelToZoomFactor`. Alternatively, this could be documented as a limitation with the workaround (set zoomLevel to log₁.₂(1.5) ≈ 2.22).
