# Issue #331935 — `SuggestModel._onNewContext` dereferences `_completionModel` inside the guard added for `_context` (incomplete fix for #170075)

[https://github.com/microsoft/vscode/issues/331935](https://github.com/microsoft/vscode/issues/331935)

## Summary

Confirmed on current main: the guard at suggestModel.ts line 755 only checks `this._context` before dereferencing `this._completionModel` on line 758, which the comment itself says can be cleared by the same cancel/retrigger race — an incomplete follow-up to #170075.

## Change summary

SuggestModel._onNewContext can throw TypeError reading getItemsByProvider on undefined _completionModel despite the prior fix guarding only _context.

## Best solution

Add the missing `this._completionModel` check to the guard at line 755 in src/vs/editor/contrib/suggest/browser/suggestModel.ts, matching the sibling branch further down that already checks both fields before proceeding.
