# Issue #331935 — `SuggestModel._onNewContext` dereferences `_completionModel` inside the guard added for `_context` (incomplete fix for #170075)

[https://github.com/microsoft/vscode/issues/331935](https://github.com/microsoft/vscode/issues/331935)

## Summary

Keep open: current main retains the incomplete reentrancy guard, allowing a replacement suggestion session to restore `_context` before `_completionModel` exists. The two historical reports are closed, and searches found no open canonical issue or competing PR.

## Change summary

Prevent an undefined completion-model dereference when synchronous tokenization cancels and re-triggers IntelliSense while processing a newly started word.

## Best solution

Make the new-word path in SuggestModel safe when tokenization replaces the active session, preserving the replacement request and normal completion reuse. Pin the reported sequence with a deterministic regression test in the existing SuggestModel suite.
