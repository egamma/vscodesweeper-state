# Issue #190848 — search match case not working for notebooks

[https://github.com/microsoft/vscode/issues/190848](https://github.com/microsoft/vscode/issues/190848)

## Summary

The case-matching defect remains source-reproducible in closed-notebook rich-content search: the search pattern reaches the cell matcher, but its case-sensitive flag does not. Keep this correctly routed search bug open; the related reports do not establish a duplicate canonical.

## Change summary

Make Search pane Match Case exclude differently cased notebook cell contents.

## Best solution

Notebook Search pane results should honor Match Case consistently for closed and open notebooks, preserving case-insensitive matching when the option is disabled. The remaining confirmed gap is in the extension-host closed-notebook search path and its CellSearchModel matcher.
