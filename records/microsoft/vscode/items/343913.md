# Issue #343913 — Sync model picker configuration (hidden/pinned models, BYOK) between editor window and Agents window

[https://github.com/microsoft/vscode/issues/343913](https://github.com/microsoft/vscode/issues/343913)

## Summary

Keep this team-authored request open: model visibility, pins, and recents remain profile-local and keyed by provider-specific identifiers. BYOK configuration already shares the default profile's language-models file, so that part needs a narrower diagnosis rather than another shared configuration store.

## Change summary

Share equivalent models' visibility, pins, recent usage, and BYOK setup between the editor and Agents windows.

## Best solution

Provide consistent model preferences across both windows through an explicit equivalence contract and shared preference persistence, without conflating unrelated providers or endpoints. Reuse the existing shared BYOK configuration and identify any remaining provider-availability or credential gap separately.

- **Behavior:**

  > Users should not repeat model curation when switching between the editor and Agents windows. Equivalent models should share hidden/visible state, pins, and recent usage in both directions, including after restart. A supported BYOK provider should require setup only once. Distinct providers or endpoints must not be merged merely because their models have the same display name.
- **Trace:**

  > LanguageModelsService in src/vs/workbench/contrib/chat/common/languageModels.ts persists exact model identifiers in profile-scoped storage for visibility, pins, and recents. AgentHostLanguageModelProvider publishes provider-qualified identifiers, so persistence sharing and model equivalence are separate requirements. The source establishes these boundaries but does not establish the remaining BYOK failure or the intended behavior with non-default editor profiles. Preserve unrelated profile-state isolation, endpoint distinctions, policy restrictions, and host-advertised identities.   - Should preferences be shared across all editor profiles, or only between the Agents window and its default-profile counterpart?

## Evidence

Pin and recent lookups match exact identifiers in the local model cache; these paths do not establish equivalence across providers.
