# Issue #139344 — User customizable ambiguous characters for Unicode Highlight

[https://github.com/microsoft/vscode/issues/139344](https://github.com/microsoft/vscode/issues/139344)

## Summary

Keep open: Unicode Highlight still has no setting for adding user-selected ambiguous characters. Existing exclusions and locale controls only partially address the request, and no older canonical covering the same capability was verified.

## Change summary

Allow users to add selected Unicode characters to highlighting without highlighting all non-ASCII text.

## Best solution

Consider an opt-in additional-character list within the existing Unicode Highlight configuration, preserving default behavior and avoiding blanket highlighting of everyday CJK text. Decide its interaction with locale and character exclusions before implementation.
