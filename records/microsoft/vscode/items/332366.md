# Issue #332366 — Able to enable/disable MCP server provided by the plugin in the customizations view

[https://github.com/microsoft/vscode/issues/332366](https://github.com/microsoft/vscode/issues/332366)

## Summary

Confirmed gap in current source: the plugin row's context menu in the Chat Customizations view only exposes plugin-level enable/disable, with no per-MCP-server enablement wired in, even though the underlying enablement machinery for individual MCP servers already exists elsewhere in the same feature area.

## Change summary

Right-clicking a plugin that provides an MCP server only offers enable/disable for the whole plugin, not for the MCP server independently.

## Best solution

Wire the plugin row's context menu (onContextMenu in pluginListWidget.ts, via getInstalledPluginContextMenuActions in agentPluginActions.ts) to also surface per-MCP-server enablement actions — mcpListWidget.ts already has getAgentHostMcpServerEnablementActions/getBuiltinMcpServerEnablementActions for exactly this purpose, so the fix is likely enumerating the plugin's contributed MCP servers and reusing that existing action-builder rather than inventing new enablement logic.
