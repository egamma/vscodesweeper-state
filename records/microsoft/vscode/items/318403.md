# Issue #318403 — Source Control accordion panels are not resizable like other accordions

[https://github.com/microsoft/vscode/issues/318403](https://github.com/microsoft/vscode/issues/318403)

## Summary

The requested manual resizing of the repositories list above Changes is already available through scm.repositories.visible: 0. The default fixed-height behavior is intentional and documented by the SCM maintainer.

## Change summary

Allow manually resizing the Source Control repositories section to display more repositories in large workspaces.

## Best solution

Use the existing scm.repositories.visible setting with value 0 to enable manual resizing, preserving the default automatic sizing for other users.
