# Issue #162025 — Hard to tell that Edit Sessions were turned on with two different auth providers

[https://github.com/microsoft/vscode/issues/162025](https://github.com/microsoft/vscode/issues/162025)

## Summary

The identity-mismatch UX gap remains on current main. This team-authored item is the oldest, best-diagnosed report and should remain the canonical issue.

## Change summary

Make Continue On identify or preserve the Cloud Changes authentication provider so users do not unknowingly select different identities.

## Best solution

Carry enough source authentication-provider context through Continue On to select or clearly recommend the matching destination identity, while avoiding account details in protocol URLs. The destination should explicitly explain a mismatch before attempting to restore changes.
