# Issue #335026 — Multi-file diff editor: Open File opens with cursor at the start of the file instead of where it was in the diff

[https://github.com/microsoft/vscode/issues/335026](https://github.com/microsoft/vscode/issues/335026)

## Summary

Keep open: the Agents Window desktop Changes editor still opens the workspace file without forwarding the diff cursor position. The generic multi-file diff action already preserves the selection, but that does not cover the desktop-specific action.

## Change summary

Preserve the diff cursor position when Open File switches to the regular file editor.

## Best solution

The Agents Window Changes editor should open the workspace file at the position being studied in the diff, consistently with the generic multi-file diff editor, while retaining its snapshot-to-workspace resource mapping.

Consequently, a newly opened file receives no instruction to reveal the cursor position from the diff.
