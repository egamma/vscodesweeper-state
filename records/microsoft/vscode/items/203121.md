# Issue #203121 — Make message scrollable

[https://github.com/microsoft/vscode/issues/203121](https://github.com/microsoft/vscode/issues/203121)

## Summary

Still unfixed on main: the MessageWidget in messageController.ts has no max-height or overflow/scroll constraint, so large markdown messages (e.g. from readonly FS providers) overflow the editor without scrolling. The issue is valid and actionable.

## Change summary

The editor overlay message widget does not scroll or cap its content when displaying large markdown messages.

## Best solution

Add a `max-height` and `overflow-y: auto` to the `.message` element in `src/vs/editor/contrib/message/browser/messageController.css`, and optionally cap the rendered markdown content in `messageController.ts` to prevent the widget from growing unboundedly.
