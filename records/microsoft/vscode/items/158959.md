# Issue #158959 — Test merge editor: compare with base should maybe open at the line where the merge editor was

[https://github.com/microsoft/vscode/issues/158959](https://github.com/microsoft/vscode/issues/158959)

## Summary

Keep open: this is mid-verification, and the current comparison command still uses the target input's cursor rather than the visible merge location. That leaves the reporter's reopened case—comparing an input without first clicking into it—unaddressed.

## Change summary

Open Compare With Base at the relevant merge location even when the compared input has not received a cursor click.

## Best solution

Preserve the user's relevant merge location when opening either input's comparison with base, including when synchronized scrolling has moved that input without moving its cursor. Complete verification of that case before closing the issue.
