# Issue #204103 — mouse text selection cursor turned white on light themes

[https://github.com/microsoft/vscode/issues/204103](https://github.com/microsoft/vscode/issues/204103)

## Summary

Well-triaged upstream Chromium/GPU-driver issue — the root cause is in Chromium's DirectComposition layer interacting with AMD (and some Intel) GPU drivers on Windows, causing the mouse cursor to render white on light backgrounds. Already labeled upstream/chromium/mitigated, assigned to deepak1556 and alexdima, with an upstream Chromium bug linked. Stays open as the canonical tracker for this widely-reported problem.

## Change summary

Mouse text-selection cursor turns white on light themes in VS Code on Windows, blending into the background and becoming invisible, particularly with AMD GPUs.

## Best solution

Continue tracking upstream: the fix must come from Chromium (DirectComposition cursor compositing) or AMD/Intel GPU drivers. VS Code can only mitigate via `--disable_direct_composition=1` or disabling GPU acceleration. When Chromium ships a fix and VS Code picks up the updated Electron, this resolves. The issue serves as the canonical tracker for dozens of duplicate reports and should remain open until the upstream fix lands.
