# Issue #344442 — Markdown editor removes trailing whitespace from the line with my cursor on it

[https://github.com/microsoft/vscode/issues/344442](https://github.com/microsoft/vscode/issues/344442)

## Summary

Keep open: the Markdown custom editor's cursor is not included in the autosave whitespace-trimming protection on current main. The source establishes a concrete failure path when files.trimTrailingWhitespace is enabled; no qualifying fix or canonical duplicate was established.

## Change summary

Preserve whitespace before the active Markdown editor cursor during autosave so pausing mid-sentence does not join subsequently typed words.

## Best solution

Give the Markdown custom editor the same cursor-aware autosave trimming behavior as the text editor, using its document-relative selection. Preserve configured trimming elsewhere and existing explicit-save behavior.
