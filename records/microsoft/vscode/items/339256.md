# Issue #339256 — Git: Stash messages appear garbled when i18n.logOutputEncoding is set

[https://github.com/microsoft/vscode/issues/339256](https://github.com/microsoft/vscode/issues/339256)

## Summary

Confirmed via source: getStashes() in extensions/git/src/git.ts omits the `-c i18n.logOutputEncoding=UTF-8` prefix that other git log-reading commands already use, so non-ASCII stash messages get mojibake when a repo sets i18n.logOutputEncoding/commitEncoding to a non-UTF-8 codec.

## Change summary

Stash messages are garbled (mojibake) when a repository's i18n.logOutputEncoding/commitEncoding is set to a non-UTF-8 encoding, because getStashes() doesn't force UTF-8 output like getCommit()/log()/blame() do.

## Best solution

Add `-c i18n.logOutputEncoding=UTF-8` to the git invocation in getStashes() (extensions/git/src/git.ts:3022), mirroring the pattern already used in getCommit(), log(), blame, and show (lines 1450, 1517, 2619, 3310, 3320, 3333).
