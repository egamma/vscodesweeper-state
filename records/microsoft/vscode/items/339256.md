# Issue #339256 — Git: Stash messages appear garbled when i18n.logOutputEncoding is set

[https://github.com/microsoft/vscode/issues/339256](https://github.com/microsoft/vscode/issues/339256)

## Summary

The encoding mismatch remains in current main: stash listing honors Git's configured output encoding, while VS Code decodes it as UTF-8. Route this bounded follow-up to the Git area; the earlier merged fix does not cover stash messages.

## Change summary

## Best solution

Make stash-message retrieval honor the Git extension's UTF-8 decoding contract without changing repository configuration, stash identities, or stash operations, and cover it with an encoding regression test.
