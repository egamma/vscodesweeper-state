# Issue #209539 — [Bug]: Incorrect indentation when there is text before the closing brace

[https://github.com/microsoft/vscode/issues/209539](https://github.com/microsoft/vscode/issues/209539)

## Summary

The reported indentation remains reproducible from the current source: Enter after the trailing closing brace inherits the property's indentation rather than the enclosing statement's indentation. Keep this team-authored bug open; no qualifying fix or same-symptom canonical was established.

## Change summary

Pressing Enter after an object property's trailing closing brace should return to the enclosing statement's indentation.

## Best solution

Make Enter infer the indentation outside the completed object without reformatting the existing lines. Establish a safe boundary for this behavior in the shared indentation machinery while preserving intentional indentation and language-specific rules.
