# Issue #110899 — Emmet extension still partially relies on core functionality

[https://github.com/microsoft/vscode/issues/110899](https://github.com/microsoft/vscode/issues/110899)

## Summary

The technical debt remains: `src/vs/workbench/contrib/emmet/browser/` still exists on current main, using internal APIs (TextMate grammar extension point, IExtensionService) to bridge the Tab-expand-abbreviation action into the extension. The issue is valid and unresolved.

## Change summary

Move the remaining Emmet core code (expand-abbreviation keybinding, grammar-scope detection) out of `src/vs/workbench/contrib/emmet/` and into the `extensions/emmet/` extension, using only the public VS Code API.

## Best solution

Expose whatever grammar/language detection the core emmetActions.ts needs via a public extension API (or find an existing API surface), then move the `ExpandAbbreviationAction` registration and its Tab keybinding into the extension, eliminating `src/vs/workbench/contrib/emmet/`.
