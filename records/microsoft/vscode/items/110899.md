# Issue #110899 — Emmet extension still partially relies on core functionality

[https://github.com/microsoft/vscode/issues/110899](https://github.com/microsoft/vscode/issues/110899)

## Summary

The architectural dependency remains on current main: core registers Emmet expansion and supplies embedded-language and grammar information to the extension. This team-authored backlog item remains necessary; the older disabled-command report was explicitly closed in its favor.

## Change summary

Make the built-in Emmet extension independent of Emmet-specific core functionality while preserving expansion behavior.

## Best solution

Make Emmet expansion extension-owned without regressing embedded-language detection, grammar-derived syntax fallback, or Tab precedence. Establish how the required language information can be obtained through supported extension APIs before removing the core bridge.
