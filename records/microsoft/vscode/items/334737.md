# Issue #334737 — Green Color Theme UI

[https://github.com/microsoft/vscode/issues/334737](https://github.com/microsoft/vscode/issues/334737)

## Summary

A green color theme is well supported by VS Code's theme extension point and belongs in the Marketplace rather than the bundled default experience. Established maintainer precedent classifies comparable theme requests as extension candidates.

## Change summary

Bundle a green UI color theme alongside VS Code's existing red theme.

## Best solution

Provide the green design as a color-theme extension using the existing `contributes.themes` API, allowing users to install it without expanding VS Code's bundled theme set.

## Vision fit

- **Fit:** rejected
- **Reason:** A color variant that can be delivered completely through the existing theme extension API belongs in the extension ecosystem rather than the lean default product.
- **Evidence:** Values and guardrails: “The power lives in extensions” and “Out of the box, VS Code is a text editor: lightweight and fast.”
