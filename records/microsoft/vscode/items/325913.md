# Issue #325913 — Bash shell integration: PROMPT_COMMAND array entries from other profile scripts get misreported as the current command

[https://github.com/microsoft/vscode/issues/325913](https://github.com/microsoft/vscode/issues/325913)

## Summary

Still reproduces on main: the bash shell integration script doesn't account for PROMPT_COMMAND being an array (bash 5.1+), causing surviving array entries from other profile scripts to be misreported as user commands via the DEBUG trap, and permanently breaking command detection for the session.

## Change summary

Bash shell integration misreports PROMPT_COMMAND array entries (e.g. from systemd's profile script) as user-entered commands, breaking command detection for the entire session.

## Best solution

Extend `__vsc_preexec` and the DEBUG trap handlers in `shellIntegration-bash.sh` to filter `$BASH_COMMAND` against all entries in the `PROMPT_COMMAND` array, not just the `__vsc_prompt*` prefix. The reporter's patch is well-reasoned and locally verified — it introduces a `__vsc_is_prompt_command_entry` helper that iterates the array. The fix should also properly save/restore the full PROMPT_COMMAND array at line 484 (`__vsc_original_prompt_command=("${PROMPT_COMMAND[@]}")`).
