## Summary

The current Bash integration still lets surviving PROMPT_COMMAND array entries consume the preexec state and masquerade as user commands. Keep this report open and route it to terminal; no verified canonical or landed fix covers this symptom.

## Change summary

Prevent foreign PROMPT_COMMAND array hooks from being reported as user commands or suppressing subsequent command detection.

## Best solution

Bash shell integration should preserve foreign prompt hooks while keeping prompt execution separate from user-command detection. Real commands must continue producing accurate OSC 633 command reports across successive prompts, with and without an existing DEBUG trap.
