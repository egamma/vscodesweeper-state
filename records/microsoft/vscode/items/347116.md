# Issue #347116 — Copying a running notebook cell lets later output change the saved copy

[https://github.com/microsoft/vscode/issues/347116](https://github.com/microsoft/vscode/issues/347116)

## Summary

The copied cell still shares mutable output storage on current main, allowing later appends to corrupt its saved snapshot. Keep open while the existing fixing PR is reviewed.

## Change summary

Copying a running notebook cell should preserve an independent snapshot of its outputs.

## Best solution

Ensure copied notebook outputs remain independent when either cell receives subsequent output, and review and land https://github.com/microsoft/vscode/pull/347117 if it satisfies that contract.
