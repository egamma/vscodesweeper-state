# Issue #347116 — Copying a running notebook cell lets later output change the saved copy

[https://github.com/microsoft/vscode/issues/347116](https://github.com/microsoft/vscode/issues/347116)

## Summary

The current source confirms that copied notebook cells share mutable output items, allowing later output to corrupt the copy's saved contents. Keep this open while the linked fix PR is reviewed.

## Change summary

Copied notebook cells should retain independent output snapshots when either cell receives subsequent output.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/347117 if it isolates copied outputs and preserves the copy-time contents through serialization, including appends in both directions.
