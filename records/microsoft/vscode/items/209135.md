# Issue #209135 — Cannot programmatically change notebook cell language to a specific language

[https://github.com/microsoft/vscode/issues/209135](https://github.com/microsoft/vscode/issues/209135)

## Summary

VS Code already supports programmatically changing a notebook cell's language through the public API; the reported command invocation passes its positional arguments in the wrong shape.

## Change summary

Allow an extension to change selected notebook cells to a specified language without opening the language picker.

## Best solution

Use `vscode.languages.setTextDocumentLanguage(cell.document, languageId)`, the supported public API for this operation. If invoking the internal command, pass the range and language as separate positional arguments.

- **Proposed comment:**

  > Thanks for the report. This is already supported through the public extension API:
  > 
  > ```ts
  > const cell = editor.notebook.cellAt(1);
  > await vscode.languages.setTextDocumentLanguage(cell.document, 'javascript');
  > ```
  > 
  > The internal `notebook.cell.changeLanguage` command expects the range and language as separate positional arguments (`{ start: 1, end: 2 }`, then `'javascript'`), rather than one `{ range, language }` object. The public API above is the supported approach for extensions, so the current behavior is as designed.

## Evidence

- **notebook support:** Commit 9fe7b6446dc4742b1a7edf624b93692d781094a6 explicitly added support for `setTextDocumentLanguage` on notebook cells; current implementation resolves the cell model and changes its language in src/vs/workbench/api/browser/mainThreadLanguages.ts:50-62.
