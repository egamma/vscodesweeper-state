## Change summary

After an unexpected Windows restart, a local chat session with an intact JSONL log and a non-empty, non-archived index entry no longer appears in the Sessions view, and Reindex Sessions doesn't restore it.

## Best solution

If confirmed, the likely fix is in ChatService.getHistorySessionItems (src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts), which requires `entry.initialLocation === ChatAgentLocation.Chat` — since `initialLocation` is an optional field on IChatSessionEntryMetadata (chatSessionStore.ts), any index entry written without it (e.g. from an interrupted/crash-time save) would be silently excluded from history even though isEmpty is false and it isn't archived. Confirming the entry's actual JSON would settle whether this is the cause.
