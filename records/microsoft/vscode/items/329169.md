# Issue #329169 — chat.useCustomizationsInParentRepositories does not discover agent skills through Git submodule .git files

[https://github.com/microsoft/vscode/issues/329169](https://github.com/microsoft/vscode/issues/329169)

## Summary

Confirmed in source: `findParentRepoFolders` treats any existing `.git` entry (file or directory) as a repo-root stop condition, so a submodule's `.git` gitlink file causes the walk-up to halt immediately at the workspace folder itself instead of continuing to the superproject root.

## Change summary

When a workspace folder is a Git submodule (its `.git` is a file, not a directory), `chat.useCustomizationsInParentRepositories` fails to discover skills/instructions in the enclosing superproject because parent-repo discovery incorrectly stops at the submodule.

## Best solution

In `extensions/copilot/src/platform/promptFiles/vscode-node/agentInstructionsLocator.ts`, have `findParentRepoFolders` only treat `.git` as a terminal repo root when it is a directory; when it's a file (submodule gitlink), keep walking up so the superproject root is still found.
