# Issue #335777 — Copilot Agent: In create_session with worktree: true allow to set the base branch

[https://github.com/microsoft/vscode/issues/335777](https://github.com/microsoft/vscode/issues/335777)

## Summary

Legitimate, unimplemented feature request: the `create_session` server tool has no parameter to choose the base branch/commit for a new worktree, and the underlying worktree-creation code always derives it from the repo's default or current branch rather than a caller-supplied ref.

## Change summary

Add an option to `create_session` (with `worktree: true`) to specify the base branch or commit the new worktree should be created from, instead of always branching off the default branch.

## Best solution

Extend the `create_session` input schema (src/vs/platform/agentHost/node/shared/sessionServerTools.ts) with an optional base-branch/ref parameter, and thread it through `worktreeIsolation.ts`'s worktree-creation path (currently `branchDefault = ... gitInfo.defaultBranch.name` around line 750, and the `baseBranch` resolution around line 909) so callers can override the default branch selection.
