# Issue #65648 — Bidi text edit support

[https://github.com/microsoft/vscode/issues/65648](https://github.com/microsoft/vscode/issues/65648)

## Summary

Keep open: Monaco's decoration-based RTL support does not itself deliver automatic line direction or a user-facing document-direction control. Two open PRs explicitly reference this request and should be reviewed before considering it completed.

## Change summary

Support automatic RTL direction for RTL-leading lines, or provide a user-facing document-direction override, with usable editing behavior.

## Best solution

Review the overlapping approaches in https://github.com/microsoft/vscode/pull/323328 and https://github.com/microsoft/vscode/pull/314365, and land an agreed user-facing direction model using the existing editor infrastructure. Keep this request open until the original mixed Persian/English example works without DOM manipulation, including correct alignment and editing coordinates.
