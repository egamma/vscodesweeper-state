# Issue #65648 — Bidi text edit support

[https://github.com/microsoft/vscode/issues/65648](https://github.com/microsoft/vscode/issues/65648)

## Summary

The core rendering prerequisite has landed, but the requested automatic or user-selectable line direction is not yet delivered in VS Code. The issue has strong demand and active design discussion, while two open PRs now overlap this area, so it should remain open pending consolidation and review.

## Change summary

Automatically display RTL-leading lines right-to-left, or provide a command or mode that lets users select text direction.

## Best solution

Define one coherent VS Code text-direction model covering default detection, explicit overrides, Unicode direction markers, cursor movement, and selection, then review the existing open implementations against it. Keep the low-level Monaco direction support stable and expose only the minimum API needed for language-aware extension overrides.
