## Summary

Team-authored feature request to broaden import NES triggers beyond recently-typed symbols to any edit producing not-found symbols. Hard keep-open (MEMBER author).

## Change summary

Extend import NES to trigger for any not-found symbol resulting from edits, not only symbols the user recently typed.

## Best solution

Expand the NES import-suggestion heuristic so that edits producing unresolved symbols (e.g. removing `this.` from a method call after extracting it) also trigger an import suggestion, rather than limiting to recently inserted text.
