# Issue #266366 — Prompts aren't updated when the prompt file updates

[https://github.com/microsoft/vscode/issues/266366](https://github.com/microsoft/vscode/issues/266366)

## Summary

The reported stale prompt description can no longer occur because suggested prompt-file actions were removed from the chat welcome view on current main. The removal is a concrete landed change, so this can be closed as completed.

## Change summary

Saving a changed prompt-file description did not refresh its prompt tile in the chat welcome view until VS Code reloaded.

## Best solution

Keep the current chat welcome design from commit 7bd7d524ed14a6b34deb529fd0694b32f9231b90, which no longer renders prompt-file suggestions and therefore removes the stale-description path.
