# Issue #341026 — GitHub Share menu should allowlist supported resource schemes

[https://github.com/microsoft/vscode/issues/341026](https://github.com/microsoft/vscode/issues/341026)

## Summary

Still present on main. The Share menu entries for the built-in GitHub extension use `resourceScheme != untitled`. `getLink` falls back to the workspace's GitHub repository and can call `ensurePublished` for a non-file resource. The issue is team-authored and carries the 1.143.0 milestone, so it stays open.

## Change summary

The GitHub Share menu and link builder should only accept supported resource schemes. Today they offer a Publish Branch & Copy Link prompt for Copilot CLI chat tabs.

## Best solution

Change the `when` clauses in extensions/github/package.json to an explicit allowlist of supported schemes (file, vscode-remote, vscode-vfs, and similar). Make `getLink` in extensions/github/src/links.ts return early for unsupported URIs before the repository fallback and `ensurePublished`. Apply the same allowlist approach in the GitHub Pull Requests extension.
