# Issue #341026 — GitHub Share menu should allowlist supported resource schemes

[https://github.com/microsoft/vscode/issues/341026](https://github.com/microsoft/vscode/issues/341026)

## Summary

Thanks for the detailed report. The built-in GitHub extension still gates its Share menu entries with `resourceScheme != untitled`, an exclusion list, so the entry also appears on `agent-host-copilotcli` chat tabs. Keeping this open and routing it to the GitHub area.

## Change summary

The GitHub Share menu entries should be shown only for an allowlist of supported resource schemes, and the link builder should reject unsupported resources before running Git actions.

## Best solution

Change the `when` clauses in extensions/github/package.json to an inclusion list of supported schemes (for example file and vscode-vfs). Add an early scheme check in the link command handlers in extensions/github/src/commands.ts, before the repository fallback and the publish prompt.
