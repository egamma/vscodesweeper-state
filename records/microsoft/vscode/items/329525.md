# Issue #329525 — Codespaces: ToDoWrite issues in .agent.md file

[https://github.com/microsoft/vscode/issues/329525](https://github.com/microsoft/vscode/issues/329525)

## Summary

Fresh, single-reporter issue that conflates several separate things: the canonical frontmatter tool name (`todo`) vs. its legacy alias (`todos`), unrelated harness-internal identifiers from other agent backends (Claude's `TodoWrite`, Copilot CLI's `manage_todo_list`), and non-deterministic body-text instructions to an LLM. Not enough to verify as a single defect; routing to the chat area for a maintainer to untangle.

## Change summary

Requests one clearly documented/aliased canonical identifier for the Todo tool that resolves consistently across `.agent.md` frontmatter, agent body instructions, and the normal Chat panel.

## Best solution

A chat/prompt-syntax maintainer should clarify (in docs and possibly via better validator messaging) that `todo` is the only supported frontmatter identifier for custom agents, that `TodoWrite`/`manage_todo_list` are internal names used only by other agent harnesses (Claude Code, Copilot CLI) and not valid `.agent.md` tool references, and that free-text body mentions of a tool name are natural-language hints to the model, not deterministic tool activations.

  > Thanks for the detailed write-up. A few things are getting conflated here that are worth separating: `todo` is the only supported frontmatter identifier for the native Todo tool (with `todos` as a legacy alias) — `TodoWrite` and `manage_todo_list` are internal identifiers used by other agent harnesses (Claude Code, Copilot CLI) and aren't meant to be valid `.agent.md` tool references. There is an existing 'unknown tool reference' diagnostic in the prompt validator that should flag unsupported names in frontmatter — if that isn't showing up for you in Codespaces Stable, that'd be useful to confirm separately. Routing this to the chat team so they can consider clearer documentation/validation messaging around tool-name aliasing across surfaces.
