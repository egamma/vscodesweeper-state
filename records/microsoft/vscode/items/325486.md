# Issue #325486 — [Vscode Agents] Need Speech-to-Text support in Agents window

[https://github.com/microsoft/vscode/issues/325486](https://github.com/microsoft/vscode/issues/325486)

## Summary

Valid feature request: the Agents window imports the speech service contribution but does not wire up the voice chat actions (mic button, dictation). The gap is confirmed in the source — the voice chat UI is registered only in the workbench's chat electron-browser contribution, not in the sessions layer.

## Change summary

The Agents window lacks speech-to-text / dictation support — no mic button appears in the chat input, unlike the main Copilot Chat view.

## Best solution

Wire the voice chat actions (StartVoiceChatAction, VoiceChatInChatViewAction, etc. from src/vs/workbench/contrib/chat/electron-browser/actions/voiceChatActions.ts) into the Agents window's chat contribution at src/vs/sessions/contrib/chat/electron-browser/chat.contribution.ts, or create a sessions-layer voice chat contribution that registers the mic button and dictation flow against the sessions chat widget. The speech service itself is already imported (sessions.common.main.ts line 'Speech' block).
