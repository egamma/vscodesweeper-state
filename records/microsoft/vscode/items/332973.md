# Issue #332973 — Show session has copilot comments / CI failures as OS notification or in command center

[https://github.com/microsoft/vscode/issues/332973](https://github.com/microsoft/vscode/issues/332973)

## Summary

Current main surfaces eligible CI failures in the command center, but pending review comments are still surfaced inside the active session rather than through that indicator or a dedicated OS notification. Keep this team-authored request open for the remaining cross-session discoverability work; no verified canonical owns its full scope.

## Change summary

Surface actionable session review comments and CI failures without requiring the user to open each session.

## Best solution

Extend the Agents Window's existing attention experience to make pending review comments discoverable across sessions, alongside CI failures. Agree on command-center coverage and whether background OS notifications are also needed, while preserving existing dismissal and Agent Merge behavior.

It surfaces failing checks for non-archived, inactive sessions with open, non-draft pull requests, except when Agent Merge handles CI. src/vs/sessions/contrib/sessions/browser/blockedSessionsIndicatorModel.ts provides the '1 session is failing CI' label, and sessionsTitleBarWidget.ts renders this model through Menus.CommandCenter.
- **Remaining comments gap:** src/vs/sessions/contrib/sessionInputBanners/browser/sessionInputBanners.ts derives its session from sessionsService.activeSession and requires SessionStatus.Completed.
