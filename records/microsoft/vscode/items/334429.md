# Issue #334429 — Markdown Editor is entirely unavailable

[https://github.com/microsoft/vscode/issues/334429](https://github.com/microsoft/vscode/issues/334429)

## Summary

Confirmed on main: the new Markdown Editor and Markdown Preview custom editors are registered with `selector.filenamePattern: "*.md"` only, while the `markdown` language (extensions/markdown-basics/package.json) recognizes many more extensions (`.markdown`, `.mkd`, `.mdown`, etc.). The reporter's file uses `.markdown`, so 'Reopen Editor With' correctly omits the WYSIWYG editor since its selector doesn't match — this is a real gap, not general unavailability.

## Change summary

The WYSIWYG Markdown Editor's 'Reopen Editor With' entry is missing for markdown files that don't use the `.md` extension (e.g. `.markdown`).

## Best solution

Widen the `customEditors` selectors for `vscode.markdown.editor` and `vscode.markdown.preview.editor` in extensions/markdown-language-features/package.json to cover the full markdown extension list already declared for the `markdown` language in extensions/markdown-basics/package.json, e.g. `*.{md,mkd,mkdn,mdwn,mdown,markdown,markdn,mdtxt,mdtext}` (brace-glob syntax is already used this way for media-preview's image/audio/video selectors).
