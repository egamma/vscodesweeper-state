# Issue #343421 — Agents Window: Make attached comments dragable

[https://github.com/microsoft/vscode/issues/343421](https://github.com/microsoft/vscode/issues/343421)

## Summary

The requested dragging capability is now available through the shared floating comment widget, with two experimental settings enabled. The Agents Window integration implements the direction suggested by the maintainer.

## Change summary

Allow attached comment popups to be dragged away from code they obscure.

## Best solution

Use the shared floating comment widget rather than adding dragging to the legacy Agents widget. Enable "chat.experimental.agentsWindowEditorComments": true and "comments.thread.experimental.style": "floating", then drag a comment's title bar.
