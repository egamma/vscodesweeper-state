# Issue #343421 — Agents Window: Make attached comments dragable

[https://github.com/microsoft/vscode/issues/343421](https://github.com/microsoft/vscode/issues/343421)

## Summary

The Agents Window comment widget remains anchored to the editor's right edge, with no user-controlled repositioning. Keep this request open: collapsing the widget or scrolling code out from underneath it provides workarounds, but neither delivers the requested dragging interaction.

## Change summary

Allow attached comment popups in the Agents Window to be dragged away from code they obscure.

## Best solution

Let users read an expanded comment alongside the underlying code without obstruction in the Sessions agent-feedback editor surface. The area owner should decide whether draggable positioning is the appropriate interaction, with equivalent keyboard access and predictable behavior during scrolling and resizing.
