# Issue #308846 — Source Control Graph gets stuck on "All" and history reference picker becomes unclickable

[https://github.com/microsoft/vscode/issues/308846](https://github.com/microsoft/vscode/issues/308846)

## Summary

Keep open: current source confirms that an empty Graph disables the reference picker, preventing recovery from the reported All state. The repository-specific reason All returns no history still needs diagnosis.

## Change summary

Switching the Source Control Graph from Auto to All can leave it empty with the reference picker disabled, preventing a switch back.

## Best solution

Keep reference selection usable when the selected repository has a history provider but the current filter returns no commits. Diagnose the All-mode history failure separately so recovery does not depend on fixing every possible provider error.

- **Behavior:**

  > When a valid repository's selected history filter produces an empty Graph, the user must still be able to open the history reference picker and select Auto or another reference. The All filter is persisted in workspace storage and resolves all provider references, unlike Auto's current/remote/base selection. extensions/git/src/historyProvider.ts returns an empty array after logged history retrieval errors, but the report does not identify the original error.
