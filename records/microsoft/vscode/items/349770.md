# Issue #349770 — Remote Environments: Should it be renamed to 'Connected Hosts'?

[https://github.com/microsoft/vscode/issues/349770](https://github.com/microsoft/vscode/issues/349770)

## Summary

Keep open for a terminology decision: the interface still says Remote Environments, although hosts can be local. Connected Hosts needs consideration because the same surface also manages available and offline hosts.

## Change summary

Reconsider the Remote Environments name so it accurately describes agent hosts running locally or remotely.

## Best solution

Choose consistent, location-neutral terminology for agent-host management that also covers disconnected hosts and sharing this computer. Apply the agreed wording across the editor, entry points, and accessibility help without changing connection behavior.
