[https://github.com/microsoft/vscode/issues/349770](https://github.com/microsoft/vscode/issues/349770)

## Summary

Keep open for a naming decision: the current UI still says Remote Environments despite supporting same-machine hosts. Connected Hosts needs consideration because the editor also manages available and offline entries.

## Change summary

Use a management-surface name that accurately includes agent hosts running locally or remotely.
