# Issue #194330 — Consider using experiment friendly name when using `Report Issue` command

[https://github.com/microsoft/vscode/issues/194330](https://github.com/microsoft/vscode/issues/194330)

## Summary

Keep open: the issue reporter still consumes assignment-context strings without resolving recognizable feature names. The discussion supports this improvement with a compact-ID fallback when names would exceed the submission URL limit; no verified duplicate was found.

## Change summary

Use recognizable experiment or feature-gate names in reported A/B experiment information, falling back to compact identifiers when necessary.

## Best solution

Make reported experiment information recognizable to feature owners while retaining useful assignment identity and protecting the issue submission payload. Establish how friendly names can be obtained for active assignments, honoring the maintainer-supported fallback to IDs when names exceed the URL budget.
