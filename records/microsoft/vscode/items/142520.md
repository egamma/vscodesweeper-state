# Issue #142520 — Opening a terminal in Multi-root workspace appends cwd option for new terminal. 

[https://github.com/microsoft/vscode/issues/142520](https://github.com/microsoft/vscode/issues/142520)

## Summary

Keep open: current source still prevents choosing another workspace root when a shared terminal cwd resolves to Build. The original path-concatenation problem was partially addressed, but the reporter's clarified default-versus-explicit-selection problem remains.

## Change summary

Allow a configured default terminal directory without overriding an explicitly chosen workspace root.

## Best solution

Provide an explicit workspace-root launch that can coexist with the configured default cwd. Settle its user-facing contract before changing the existing picker, which deliberately applies resource-scoped cwd overrides and deduplicates identical destinations.

- **Trace:**

The existing terminalActions.test.ts suite deliberately verifies this deduplication, and terminalConfiguration.ts describes the setting as an explicit resource-scoped start path.
