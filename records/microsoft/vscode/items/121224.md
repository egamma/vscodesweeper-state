# Issue #121224 — Document that http.proxy also configures Electron

[https://github.com/microsoft/vscode/issues/121224](https://github.com/microsoft/vscode/issues/121224)

## Summary

The documentation remains inaccurate: it says `http.proxy` is respected only by extensions and the CLI, while current VS Code source applies it to Electron sessions. This team-authored Backlog issue should remain open until the network documentation is corrected.

## Change summary

Document that the `http.proxy` setting configures Electron networking in addition to extension and CLI requests.

## Best solution
