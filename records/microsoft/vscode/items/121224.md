# Issue #121224 — Document that http.proxy also configures Electron

[https://github.com/microsoft/vscode/issues/121224](https://github.com/microsoft/vscode/issues/121224)

## Summary

The documentation gap persists: the http.proxy setting description doesn't clearly state it also configures Electron's session proxy (VS Code's own network requests), and the external docs page may still be misleading. Team-authored item, keeping open.

## Change summary

Document that http.proxy configures Electron's session proxy (not just extensions), so users know the behavior is intentional and supported.

## Best solution

Update the setting's markdownDescription in src/vs/platform/request/common/request.ts and coordinate with the docs team to update https://code.visualstudio.com/docs/setup/network to reflect that http.proxy applies to VS Code's own requests (via Electron session.setProxy) in addition to extensions.
