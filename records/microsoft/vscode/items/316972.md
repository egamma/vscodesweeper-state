# Issue #316972 — Shortcut to open the model json file from the language models view

[https://github.com/microsoft/vscode/issues/316972](https://github.com/microsoft/vscode/issues/316972)

## Summary

Team-authored issue requesting a shortcut to open the custom model JSON file from the Language Models view's gear icon. The 'Open Language Models (JSON)' command exists but is only surfaced in editor title menus, not from the per-entry gear in the models widget. No fix commit references this issue.

## Change summary

Add a way to open the custom model JSON configuration file from the gear icon on custom model entries in the Language Models view.

## Best solution

Add an 'Open in JSON' secondary action to the gear toolbar for custom model entries in `src/vs/workbench/contrib/chat/browser/chatManagement/chatModelsWidget.ts`, reusing the existing `workbench.action.openLanguageModelsJson` command. The action infrastructure is already in place — the `renderVendorElement` method (line 983) builds primary/secondary actions for the gear toolbar, and the command is registered in `chatManagement.contribution.ts` (line 166).
