# Issue #140131 — Allow ctrl+click/go to definition to work in settings.json split editor

[https://github.com/microsoft/vscode/issues/140131](https://github.com/microsoft/vscode/issues/140131)

## Summary

The split JSON settings editor still exists, but its settings keys have no definition-navigation path to the defaults pane. Keep this accepted Backlog request open: existing alternatives do not provide the requested jump, and no qualifying canonical or fixing commit was found.

## Change summary

Allow Ctrl+Click or Go to Definition on a settings.json key to navigate to its description and available options in the split editor's defaults pane.

## Best solution

If enhancements to the retained split editor are supported, make standard definition navigation reveal the corresponding default setting in its existing pane. The settings owner should first reconcile that enhancement with the earlier deprecation position; opening defaults manually or using IntelliSense is not equivalent.
