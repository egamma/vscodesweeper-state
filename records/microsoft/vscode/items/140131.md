Valid feature request — no definition provider exists for settings.json keys on current main, and no commits reference this issue. The capability remains unimplemented; keeping open for the community process.

## Change summary

Allow ctrl+click / Go to Definition on a setting key in settings.json to navigate to that setting's entry in the Settings UI (split editor left pane).

## Best solution

Register a DefinitionProvider (or DocumentLinkProvider) for the `jsonc` language in settings.json files that resolves setting keys to a reveal-in-settings-editor action. The implementation would likely live in `src/vs/workbench/contrib/preferences/` and use the existing `revealSetting` / `focusSearch` infrastructure in the settings editor.
