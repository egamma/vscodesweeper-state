# Issue #226737 — Properties of `FileSearchProviderOptions` should be marked `readonly`

[https://github.com/microsoft/vscode/issues/226737](https://github.com/microsoft/vscode/issues/226737)

## Summary

The declaration defect remains on current main: FileSearchProviderOptions exposes writable properties and mutable nested arrays despite representing editor-owned input. Keep this open for a bounded API declaration correction.

## Change summary

Mark FileSearchProviderOptions properties and nested option arrays readonly so providers cannot mistakenly treat editor-supplied options as mutable.

## Best solution

Make the proposed file-search provider input contract consistently readonly, including nested folder and ignore-file options and array collections, while preserving runtime behavior and provider result mutability.
