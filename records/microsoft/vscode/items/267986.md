# Issue #267986 — VS Code Microsoft account sync unexpectedly registers account in Windows

[https://github.com/microsoft/vscode/issues/267986](https://github.com/microsoft/vscode/issues/267986)

## Summary

Keep open as an upstream Microsoft authentication issue. The maintainer attributes the account sharing to the authentication library, and current source still enables native brokering by default; the browser-only option is a mitigation, not proof that the reported Windows behavior is fixed.

## Change summary

Prevent signing into Settings Sync with a personal Microsoft account from making that account available to other Windows applications.

## Best solution

Establish whether MSAL's Windows broker can support application-scoped sign-in without registering the account for other applications. Retain the existing browser-only authentication option as a mitigation while the authentication owner investigates the upstream behavior.
