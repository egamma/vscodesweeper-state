# Issue #302000 — Image Carousel: Show image file name and/or path

[https://github.com/microsoft/vscode/issues/302000](https://github.com/microsoft/vscode/issues/302000)

## Summary

Keep open: Images Preview still lacks a visible identifier for the currently selected image in general collections. The existing caption, section title, and accessibility text only partially cover this team-authored request; no verified canonical or issue-referencing fix was found.

## Change summary

Show the currently selected image's file name and/or path in the image carousel.

## Best solution

Provide a discoverable current-image identifier in Images Preview that updates during navigation while preserving captions and section context. Settle whether the visible identifier is the file name alone or also exposes the source path when available.
