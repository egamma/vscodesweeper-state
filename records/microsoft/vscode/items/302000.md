# Issue #302000 — Image Carousel: Show image file name and/or path

[https://github.com/microsoft/vscode/issues/302000](https://github.com/microsoft/vscode/issues/302000)

## Summary

A real gap remains on current main: the visible information bar shows a caption only when supplied, otherwise only the image counter; the filename is confined to accessibility text. This team-authored request should remain open.

## Change summary

Show the current image's filename or path visibly in Images Preview.

## Best solution

Update the Images Preview information bar in `imageCarouselEditor.ts` to show the current image name, or an appropriately shortened URI path, alongside its optional caption and counter.
