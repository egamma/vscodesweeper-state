# Issue #344068 — Git: history diffs fail for expanded git-toprepo directories listed in .gitmodules

[https://github.com/microsoft/vscode/issues/344068](https://github.com/microsoft/vscode/issues/344068)

## Summary

The reported failure is present in current main: retained .gitmodules entries exclude ordinary parent-tracked files from repository resolution, causing historical reads to fail. Keep this open and route it to the built-in Git area; the supplied local reproduction is sufficient.

## Change summary

Historical diffs should load parent-tracked files inside expanded directories even when those directories remain listed in .gitmodules.

## Best solution

Make Git repository ownership distinguish actual submodules from ordinary tracked directories with retained metadata, so historical files resolve to their parent repository without changing genuine submodule isolation.
