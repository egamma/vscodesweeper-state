# Issue #348291 — Reloading and resuming a saved draft creates an extra text-only copy

[https://github.com/microsoft/vscode/issues/348291](https://github.com/microsoft/vscode/issues/348291)

## Summary

Keep open: current source restores the resumed composition's input without its saved identity, then saves that input as another draft when the original is selected. The duplication path is confirmed; the attachment-pill loss still needs focused reproduction.

## Change summary

Reloading and reopening a resumed saved draft creates additional copies that lose its file attachment pill.

## Best solution

Preserve the association between restored composer content and its saved draft so reopening the same composition remains idempotent. Verify inline file references survive repeated reload/resume cycles without suppressing preservation of genuinely different unsent input.
