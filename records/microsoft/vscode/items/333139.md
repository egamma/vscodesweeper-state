## Summary

Real, multiply-confirmed regression on 1.135.0: several independent reporters across macOS and Windows say GitHub Copilot sign-in state isn't persisted across VS Code restarts, but I couldn't pin the root cause or a fix in the checkout, so this needs area-owner investigation rather than a close.

## Change summary

GitHub Copilot sign-in is not remembered between VS Code restarts, forcing repeated sign-ins.
