# Issue #224043 — "Notebook Find Filters" button shows in search when no notebook is active

[https://github.com/microsoft/vscode/issues/224043](https://github.com/microsoft/vscode/issues/224043)

## Summary

The visibility mismatch remains in current source: Search counts notebooks anywhere in the open editor stack, including notebooks hidden behind other editors. Keep this open while the explicitly linked fix PR is reviewed; it has not merged.

## Change summary

Hide the Search view's Notebook Find Filters button when no notebook editor is visible, even if a notebook remains open in the editor stack.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/309137, which targets the reported distinction between open and visible notebooks. The button should follow notebook visibility across editor groups without changing the notebook search filters themselves.
