[https://github.com/microsoft/vscode/issues/348532](https://github.com/microsoft/vscode/issues/348532)

## Summary

Keep open: Custom Endpoint still lacks configurable provider-executed tools. Existing Anthropic support and the related request-body proposal do not cover the requested cross-API declaration, response handling, and history behavior.

## Change summary

Support provider-executed tools in Custom Endpoint configuration, outgoing requests, streamed responses, and subsequent conversation turns.

## Best solution

Define an end-to-end Custom Endpoint contract for provider-executed tools across the supported API types, preserving client-function execution and conversation replay. Coordinate arbitrary body parameters with the existing proposal rather than treating body pass-through alone as completing this request.
