# Issue #348532 — Custom Endpoint (BYOK): support all provider built-in / server-executed tools, not just client-side function calling

[https://github.com/microsoft/vscode/issues/348532](https://github.com/microsoft/vscode/issues/348532)

## Summary

The general server-tool configuration capability remains missing from Custom Endpoint models. Existing client-side tool search and the related arbitrary-body proposal do not cover the requested cross-API tool declarations and conversation-history support.

## Change summary

Allow Custom Endpoint models to configure provider-executed tools and correctly handle their responses and subsequent conversation turns.

## Best solution

Define a supported Custom Endpoint contract for provider-executed tools across request construction, streaming, and conversation-history serialization. Coordinate arbitrary body parameters with the existing proposal, while deciding artifact presentation and session controls separately.
