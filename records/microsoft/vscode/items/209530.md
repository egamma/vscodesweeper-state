# Issue #209530 — Subword selection with shortcuts not working

[https://github.com/microsoft/vscode/issues/209530](https://github.com/microsoft/vscode/issues/209530)

## Summary

The invoked commands intentionally select to whole-word boundaries. Subword selection already has separate built-in commands; the Smart Select setting controls Expand Selection, not Ctrl+Shift+Arrow word navigation.

## Change summary

Select subwords rather than entire words when using Ctrl+Shift+Left/Right.

## Best solution

Keep the distinct word and subword navigation behaviors, and explain how to bind cursorWordPartLeftSelect and cursorWordPartRightSelect to the reporter's preferred shortcuts.

- **Proposed comment:**

  > Thanks for the report. `cursorWordEndLeftSelect` and `cursorWordEndRightSelect` select to whole-word boundaries by design. For subword selection, assign `cursorWordPartLeftSelect` and `cursorWordPartRightSelect` to Ctrl+Shift+Left and Ctrl+Shift+Right in Keyboard Shortcuts.
  > 
  > `editor.smartSelect.selectSubwords` applies to Expand Selection (`editor.action.smartSelect.expand`, Shift+Alt+Right on Windows), rather than the word-navigation commands.

## Evidence

- **Whole-word command semantics:** src/vs/editor/contrib/wordOperations/browser/wordOperations.ts defines CursorWordEndLeftSelect and CursorWordEndRightSelect with inSelectionMode: true and WordNavigationType.WordEnd. Their WordLeftCommand/WordRightCommand implementations delegate to WordOperations.moveWordLeft/moveWordRight, not subword operations. The reported log confirms cursorWordEndRightSelect was invoked successfully.
- **Existing subword selection capability:** src/vs/editor/contrib/wordPartOperations/browser/wordPartOperations.ts registers cursorWordPartLeftSelect and cursorWordPartRightSelect with selection mode enabled. They use WordPartOperations.moveWordPartLeft/moveWordPartRight. Both have primary: 0 outside macOS, so Windows users must assign their preferred shortcuts explicitly.
- **Setting applies to a different selection feature:** src/vs/editor/contrib/smartSelect/browser/smartSelect.ts reads EditorOption.smartSelect in SmartSelectController.run and passes selectSubwords to WordSelectionRangeProvider. Its editor.action.smartSelect.expand command uses Shift+Alt+Right on Windows. MoveWordCommand does not read this option.
