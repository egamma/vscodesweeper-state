# Issue #330395 — Keyword `$this` not correctly highlighted in interpolated php strings

[https://github.com/microsoft/vscode/issues/330395](https://github.com/microsoft/vscode/issues/330395)

## Summary

The inconsistent highlighting remains in the PHP TextMate grammar bundled on current main, but the affected grammar is imported from the upstream language-php project. Keep the issue open and track the upstream correction before updating VS Code's pinned grammar.

## Change summary

Make `$this` receive the same `variable.language.this.php` scope in braced and unbraced PHP string interpolation.

## Best solution

Correct the interpolation rule in https://github.com/KapitanOczywisty/language-php so unbraced `$this` uses the language-variable scope, then update VS Code's pinned PHP grammar through its existing grammar updater.
