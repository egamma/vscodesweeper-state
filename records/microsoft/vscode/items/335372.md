# Issue #335372 — Show MCP server startup errors in the MCP details view

[https://github.com/microsoft/vscode/issues/335372](https://github.com/microsoft/vscode/issues/335372)

## Summary

Real gap confirmed on main: the MCP server details editor (mcpServerEditor.ts) does not render connectionState/error info at all — errors currently only surface via notifications, quick-picks, and context keys (mcpCommands.ts, mcpElicitationService.ts). It's already correctly labeled `mcp`/`ai-customizations`; keeping open pending maintainer interest, since this is one of several self-generated companion issues around MCP error UX with no organic demand yet.

## Change summary

Add a persistent banner in the MCP server details view surfacing startup/connection errors, with access to the full raw error.

## Best solution

Extend mcpServerEditor.ts to read `IMcpServer.connectionState` (McpConnectionState.Kind.Error carries a `message`) and render a banner above the config editor when in an error state, with an expandable/raw-error affordance; coordinate with the narrower interim fix in #335366 and the broader tracking issue #333542 so the three don't overlap.
