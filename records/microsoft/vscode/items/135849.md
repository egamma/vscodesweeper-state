# Issue #135849 — [html] Unexpected "Declaration or statement expected" in HTML code

[https://github.com/microsoft/vscode/issues/135849](https://github.com/microsoft/vscode/issues/135849)

## Summary

The HTML language service mis-parses adjacent inline script blocks when a line comment in the first block shares a line with the next `<script>` tag. A maintainer confirmed this as a product bug, and the open Volar integration PR is already a linked implementation candidate, so the issue must remain open while that work is unresolved.

## Change summary

Prevent a JavaScript line comment in one inline HTML script block from causing false syntax diagnostics in a following script block on the same line.

## Best solution

Review and resolve the parser/language-service behavior through the linked Volar integration work in https://github.com/microsoft/vscode/pull/171547, ensuring each inline script region is parsed independently even when adjacent tags share a line.
