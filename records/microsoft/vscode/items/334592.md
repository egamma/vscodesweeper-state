# Issue #334592 — Local harness should honor `reasoning-effort` from custom `.agent.md` files

[https://github.com/microsoft/vscode/issues/334592](https://github.com/microsoft/vscode/issues/334592)

## Summary

The local custom-agent path still drops the declared `reasoning-effort`, producing execution semantics inconsistent with Agent Host. The report identifies a bounded, source-confirmed gap and should remain open.

## Change summary

Honor a custom `.agent.md` file's `reasoning-effort` when the agent runs directly or through the local `runSubagent` harness, with inheritance when absent.

## Best solution

Preserve the validated custom-agent reasoning effort in the local custom-agent representation and include it when resolving the request's model configuration, while retaining the documented fallback to session/model configuration.
