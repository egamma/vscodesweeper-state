# Issue #261427 — VSCode crashes when pressing Ctrl + Alt + Backspace

[https://github.com/microsoft/vscode/issues/261427](https://github.com/microsoft/vscode/issues/261427)

## Summary

Ctrl+Alt+Backspace is a Linux display-server shortcut that terminates the graphical session (X11/Wayland). The crash log points to Electron's shutdown path and X connection errors — this is the OS/compositor killing the session, not a VS Code defect. The root cause is upstream (Electron/Chromium behavior when the display server connection is severed).

## Change summary

VS Code crashes on Linux when the user presses Ctrl+Alt+Backspace, which terminates the display server session.

## Best solution

This is an OS/desktop-environment behavior (Ctrl+Alt+Backspace kills the graphical session on many Linux setups). If Electron should handle a severed display connection more gracefully (clean shutdown instead of FATAL), that belongs in Electron's issue tracker. The user can disable the key combo via their desktop's keyboard settings (e.g. `setxkbmap -option` or KDE System Settings). The issue should be tagged upstream and kept for tracking if the team wants Electron to improve here.
