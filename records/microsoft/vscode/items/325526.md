# Issue #325526 — Copilot Chat lacks paste as plain text shortcut/ability

[https://github.com/microsoft/vscode/issues/325526](https://github.com/microsoft/vscode/issues/325526)

## Summary

Confirmed on main: the `editor.action.pasteAsText` command exists (src/vs/editor/contrib/dropOrPasteInto/browser/copyPasteContribution.ts, line ~114) and works via the chat input editor too (CopyPasteController is included in the chat input's contribution list), but it has no default keybinding (Cmd/Ctrl+Shift+V) and no context/edit menu entry anywhere in the editor — this is an editor-wide gap, not something Copilot Chat itself broke.

## Change summary

Add a 'Paste as Plain Text' keyboard shortcut and/or context-menu entry so pasted rich text/HTML in the Chat input (and editors generally) can be inserted without Markdown conversion.

## Best solution

Give the existing `editor.action.pasteAsText` command (src/vs/editor/contrib/dropOrPasteInto/browser/copyPasteContribution.ts) a default keybinding (e.g. Cmd/Ctrl+Shift+V) and/or a context-menu entry, since the underlying capability already exists and only needs discoverability — this is an editor-wide fix, so it belongs in the core editor/dropOrPasteInto area rather than being chat-specific.
