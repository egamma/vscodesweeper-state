# Issue #321306 — Copilot Chat destroys edits to files done by other chats, and those reverts are not recorded in edit history (timeline)

[https://github.com/microsoft/vscode/issues/321306](https://github.com/microsoft/vscode/issues/321306)

## Summary

Keep open: current source still allows reopening an older chat to replace newer file contents with its persisted snapshot. Related reports independently confirm this data-loss path, but none of the verified older issues covers this report's full combination of session switching, prompt rollback, and missing Timeline recovery.

## Change summary

Prevent older Copilot chats from silently overwriting edits made by users or other chats, and preserve recovery history for destructive changes.

## Best solution

Make passive chat restoration preserve current workspace contents, and ensure explicit rollback does not silently discard intervening work from other sessions. Review the existing restoration fix candidate, then verify the prompt-edit and recovery-history cases separately before considering this report resolved.
