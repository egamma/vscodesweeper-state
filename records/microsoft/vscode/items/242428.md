# Issue #242428 — Finalize the VS Code Speech API

[https://github.com/microsoft/vscode/issues/242428](https://github.com/microsoft/vscode/issues/242428)

## Summary

Keep open: the speech API remains proposed, and its provider-registration contract does not expose the speech-consumption capability requested by third-party extension authors. The request has 39 upvotes and was accepted into Backlog; the related finalization issue is closed, not an eligible duplicate target.

## Change summary

Expose a stable speech API so third-party extensions can integrate dictation and transcript events into their own text-entry surfaces.

## Best solution

Have the API owners define a stable speech-consumption contract that supports extension-owned inputs, alongside any provider API finalization. Finalizing registerSpeechProvider alone would not satisfy the reporter's integration use case.
