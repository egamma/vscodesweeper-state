# Issue #237663 — How to fix Microsoft Visual studio code, language pack issue from English to French at first launch.

[https://github.com/microsoft/vscode/issues/237663](https://github.com/microsoft/vscode/issues/237663)

## Summary

Valid bug with an open fixing PR (#321909) that explicitly references this issue — keep open until that PR is reviewed and merged.

## Change summary

Installing a language pack via CLI and setting locale in argv.json does not take effect on the first launch; only on the second launch.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/321909 which initializes NativeLanguagePackService during CLI service setup so that `--install-extension` of a language pack updates `languagepacks.json` immediately, enabling first-launch locale switching.
