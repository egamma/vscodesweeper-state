# Issue #210759 — Find bar resize issue

[https://github.com/microsoft/vscode/issues/210759](https://github.com/microsoft/vscode/issues/210759)

## Summary

The usability gap remains on current main: the find widget exposes only a 2px resize target without a grip indicator. It is already correctly classified and routed as editor-find polish.

## Change summary

Make the editor find widget's left resize handle easier to acquire and visually identify.

## Best solution

Increase the find widget sash hit target in `findWidget.ts` and provide a consistent visible resize affordance in `findWidget.css`, without changing the widget's layout or resize behavior.
