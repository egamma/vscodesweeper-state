[https://github.com/microsoft/vscode/issues/215591](https://github.com/microsoft/vscode/issues/215591)

## Summary

Keep open: the reporter repeatedly confirmed misleading warnings after updating a running Linux installation and reloading a window. Current source still contains both warning paths, but does not establish that this update scenario has been fixed.

## Change summary

Avoid presenting a normal external package update as installation corruption when an existing VS Code process remains running.

## Best solution

Distinguish a running-process/on-disk version mismatch from actual installation corruption and give an accurate restart instruction. First establish which notification occurs on current Linux builds, preserving genuine integrity warnings and extension-host compatibility checks.
