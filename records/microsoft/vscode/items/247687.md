# Issue #247687 — Some labels are backwards during a rebase merge conflict

[https://github.com/microsoft/vscode/issues/247687](https://github.com/microsoft/vscode/issues/247687)

## Summary

The reported mismatch remains in current source: rebasing swaps the input roles, but focus announcements, bulk-accept labels, and accessibility help still assume Incoming is left and Current is right. Keep this correctly routed issue open; the older related reports do not establish the same observable defect required for a duplicate close on re-review.

## Change summary

Make merge-editor announcements and accept-all descriptions accurately identify their inputs during rebases and other custom-labeled merge operations.

## Best solution

Expose the actual input identities to screen-reader users and ensure bulk-accept descriptions accurately identify the input they affect, without changing Git's input ordering or merge semantics. Settle the command-label contract with the accessibility and merge-editor owners, preserving support for stash and extension-provided titles.
