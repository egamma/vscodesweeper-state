# Issue #251172 — Git extension: rebase -i skips commit message prompt

[https://github.com/microsoft/vscode/issues/251172](https://github.com/microsoft/vscode/issues/251172)

## Summary

The squash-message prompt is still suppressed in current source: the SCM continuation path unconditionally overrides the configured Git editor with `GIT_EDITOR=true`. Keep this accepted Git bug open; the related interactive-rebase issues do not own this specific failure.

## Change summary

Continuing an interactive rebase through SCM after resolving conflicts skips a later squash commit-message editor and accepts the concatenated default message.

## Best solution

Allow Git's required squash-message editing to complete through VS Code when continuing from SCM, while preserving noninteractive conflict continuation and avoiding background terminal-editor hangs.
