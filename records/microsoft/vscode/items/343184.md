# Issue #343184 — send_to_terminal tool text cut off. cannot see full command for approval

[https://github.com/microsoft/vscode/issues/343184](https://github.com/microsoft/vscode/issues/343184)

## Summary

The approval text is truncated in current source before rendering, while execution receives the complete command. Keep this open: the reporter's steps identify a concrete approval-visibility defect, not merely a layout problem.

## Change summary

Allow users to inspect the complete send_to_terminal input before approving its execution.

## Best solution

The send_to_terminal confirmation should expose all input that will be sent, including long command suffixes and multiline content. Preserve existing approval requirements and compact progress summaries; approval details must not lose executable content.
