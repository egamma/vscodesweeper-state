# Issue #339804 — [Error] unhandlederror-command 'workbench.extensions.installExtension' not found

[https://github.com/microsoft/vscode/issues/339804](https://github.com/microsoft/vscode/issues/339804)

## Summary

Confirmed source gap: the Agents/sessions window never registers 'workbench.extensions.installExtension', yet shared chat/recommendation/URL-handler code paths it loads call that command, so it throws. A companion analysis issue (#339815) has already diagnosed the same root cause but is not yet implemented as a PR.

## Change summary

Sessions (Agents) window throws 'command not found' when extension-install flows shared with the main workbench try to call workbench.extensions.installExtension.

## Best solution

Register the extension install/uninstall commands (or import the relevant parts of workbench/contrib/extensions/browser/extensions.contribution.ts) in src/vs/sessions/contrib/extensions/browser/extensions.contribution.ts so the sessions window has the command available to the chat/recommendation/URL-handler code paths it already loads.
