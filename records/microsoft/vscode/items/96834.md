## Summary

The completion gap remains in the current HTML data dependency: `autocapitalize` documents its valid values but has no value-set association, so the language service has nothing to suggest. This should stay open as an upstream data issue rather than being closed or treated as a duplicate.

## Change summary

Provide HTML value completions such as `none`, `sentences`, `words`, and `characters` for the `autocapitalize` attribute.

## Best solution
