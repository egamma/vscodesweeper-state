# Issue #332679 — Validate Medium and Small shadow tiers for Modern UI

[https://github.com/microsoft/vscode/issues/332679](https://github.com/microsoft/vscode/issues/332679)

## Summary

Keep open for an explicit design decision: current source confirms that Modern UI suppresses Small shadows while retaining Medium consumers, but does not establish Medium’s supported semantic role. This team-authored request is not completed merely because the tokens already exist.

## Change summary

Decide which Small and Medium shadow tiers Modern UI supports and align product usage with the Figma elevation documentation.

## Best solution

Document the supported shadow tiers and their semantic boundaries with the design owner. Then either document Medium’s approved uses in Figma or align its existing consumers with the chosen elevation treatment, while explicitly resolving Small’s exclusion.
