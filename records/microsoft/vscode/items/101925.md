# Issue #101925 — Zooming with Ctrl+MouseWheel doesn't update configuration

[https://github.com/microsoft/vscode/issues/101925](https://github.com/microsoft/vscode/issues/101925)

## Summary

Verified duplicate: this issue asks for Ctrl+MouseWheel zoom to update configuration and be observable by extensions, which is the same underlying gap as #80820 (editor font zoom does not persist). Both require making the transient EditorZoom singleton state a proper persisted/observable setting.

## Change summary

Ctrl+MouseWheel editor zoom changes the in-memory EditorZoom level but does not update any configuration setting, so extensions and persistence are unaware of the change.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/80820 — making editor font zoom persist as a configuration setting would also make it observable by extensions, resolving both issues. No distinct requirement here remains once that lands.
