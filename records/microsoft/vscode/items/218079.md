# Issue #218079 — Show the source of an entry as a separate column

[https://github.com/microsoft/vscode/issues/218079](https://github.com/microsoft/vscode/issues/218079)

## Summary

Keep open: object-setting entries still expose their contributing source through hover and accessibility text, not a separate visible column. This team-authored Backlog request remains distinct from the related settings issues inspected.

## Change summary

Display each object-setting entry's default-value source in a separate column instead of requiring a hover.

## Best solution

Make entry-level provenance visible alongside object-setting keys and values in the Settings editor, preserving accessibility and usability in narrow editors.
