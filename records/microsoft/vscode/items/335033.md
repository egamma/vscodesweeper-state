# Issue #335033 — Group header and session list item overlaps buggily

[https://github.com/microsoft/vscode/issues/335033](https://github.com/microsoft/vscode/issues/335033)

## Summary

Real, member-confirmed visual bug in the Agents Window session list (a maintainer attached their own reproduction screenshot); it also carries a real 1.140.0 milestone, which is a hard keep-open signal regardless of other evidence.

## Change summary

Hovering a session-list group header renders it transparently so the row below shows through, and hovering a session item with sub-chats shows its collapse chevron above the group header.

## Best solution

Fix the z-index/background layering between `.session-section` (group header) and `.monaco-list-row` hover/sticky states in sessionsList.css so the header stays opaque on hover and twisties don't render above the header row.
