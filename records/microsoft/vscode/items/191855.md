# Issue #191855 — Block cursor remains after switching to profile with enabled vim extension and back

[https://github.com/microsoft/vscode/issues/191855](https://github.com/microsoft/vscode/issues/191855)

## Summary

Confirmed lifecycle bug: an extension-set cursor style remains after switching profiles disables the extension and restarts its extension host. This is a team-authored issue with maintainer-confirmed diagnosis, so it should remain open until extension-owned editor option overrides are reverted on host teardown.

## Change summary

Reset an extension-provided block cursor style when switching back to a profile where that extension is disabled.

## Best solution

Track editor-option overrides by extension host or extension ownership and restore the effective configured/default cursor style when that owner is removed, without discarding user or surviving-extension settings.
