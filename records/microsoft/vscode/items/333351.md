# Issue #333351 — # selector in CSS is misinterpreted as color

[https://github.com/microsoft/vscode/issues/333351](https://github.com/microsoft/vscode/issues/333351)

## Summary

Real bug: the CSS language service's color decorator provider treats `#`-prefixed CSS selectors as hex color literals when CSS is embedded in a PHP document (but correctly ignores them when embedded in HTML) — an open PR already targets this exact scenario, so the fix should land there rather than being separately triaged.

## Change summary

Editing embedded CSS inside a `.php` file shows color-picker swatches next to `#id`/`#class`-style selectors, which should only apply to actual hex color values.

## Best solution

Land https://github.com/microsoft/vscode/pull/333359 ("fix(css): avoid color decorators inside non-CSS documents (php)"), which appears to address exactly this regression in the CSS color-decorator logic for embedded PHP documents; no separate fix is needed if that PR is reviewed and merged.
