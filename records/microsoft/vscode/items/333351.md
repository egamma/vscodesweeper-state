# Issue #333351 — # selector in CSS is misinterpreted as color

[https://github.com/microsoft/vscode/issues/333351](https://github.com/microsoft/vscode/issues/333351)

## Summary

Real bug in the CSS language server, already being addressed by an open, linked fix PR — keeping open until that PR is reviewed and merged rather than closing now.

## Change summary

The CSS color decorator (little color swatch) incorrectly appears for `#id` selectors when the active editor language is PHP, not just CSS/LESS/SCSS.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333359, which adds a languageId guard in extensions/css-language-features/server/src/cssServer.ts's onDocumentColor handler so the CSS server skips document-color parsing for non-CSS languageIds (e.g. php); close this issue once that PR merges.
