# Issue #287709 — For Background Agents, let me choose the branch name. For important for tracking tickets.

[https://github.com/microsoft/vscode/issues/287709](https://github.com/microsoft/vscode/issues/287709)

## Summary

Keep open: existing branch-prefix settings and generated names do not provide explicit control over a background session's complete branch name. Related requests cover automatic naming or prefix customization, not this ticket-tracking requirement.

## Change summary

Allow users to choose the branch name when creating a background-agent worktree, including ticket identifiers.

## Best solution

Provide an optional user-selected branch name in background-session creation, retaining automatic naming when no name is supplied. The product decision should establish whether explicit names retain the automatic copilot/agents namespace.
