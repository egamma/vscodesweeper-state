# Issue #145473 — Use source maps if extension ships one for error stack trace formatting

[https://github.com/microsoft/vscode/issues/145473](https://github.com/microsoft/vscode/issues/145473)

## Summary

Keep this accepted, well-supported request open: the default extension-host formatter still does not apply shipped source maps. Open implementation proposals exist, but the native-source-map proposal explicitly covers only local development hosts, not the production crash-reporting scenario.

## Change summary

Use source maps shipped by extensions to format exception stacks with original source locations while preserving extension attribution.

## Best solution

Review the existing implementation proposals and retain this issue until source-mapped error stacks work for installed, bundled extensions without requiring a process-wide formatter override. Development-host support is a useful first step, not completion of the broader request.
