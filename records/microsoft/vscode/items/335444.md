# Issue #335444 — Provide a stable, documented enterprise download package for on-device dictation

[https://github.com/microsoft/vscode/issues/335444](https://github.com/microsoft/vscode/issues/335444)

## Summary

Legitimate enterprise-deployment gap: the local-package import path exists (from the fix in #332537, released in 1.136.0), but there is still no documented, stable, first-party download URL/hash/integrity info for the CPU model package, which blocks locked-down corporate networks — this needs a product/infra decision (host a stable endpoint, document hashes and proxy allowlist details), not a code fix in this repo.

## Change summary

Request a stable, documented, first-party HTTPS distribution endpoint (with version/hash/license info and offline deployment guidance) for the on-device dictation CPU model package, instead of relying on Foundry Local's short-lived signed Blob URLs.

## Best solution

Belongs with the Chat/voice and docs owners: decide whether to stand up a stable Microsoft-hosted download endpoint for the nemotron-3.5-asr-streaming-0.6b CPU package (with published hash/version/license) and update the accessibility/voice docs and code.visualstudio.com page to reference it; the local-package import mechanism itself (src/vs/platform/localTranscription/node/foundryLocalModelImport.ts) already works and needs no change.
