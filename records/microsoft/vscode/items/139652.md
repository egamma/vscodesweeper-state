# Issue #139652 — Support no value for editorSuggestWidget.selectedIconForeground

[https://github.com/microsoft/vscode/issues/139652](https://github.com/microsoft/vscode/issues/139652)

## Summary

Implemented and shipped in VS Code 1.91: color customizations can now use `default` to remove a theme-provided color, allowing suggestion icons to retain their kind-specific colors.

## Change summary

Allow the selected suggestion icon color override to be disabled so each icon retains its completion-kind color.

## Best solution

Use the generic color-reset mechanism delivered by commit 28cbfce5e66c0713043612ab5d438a415bb9b716 rather than adding a token-specific nullable mode. Setting `list.activeSelectionIconForeground` to `default` removes the inherited selection override.

- **Reason:** A dedicated per-component toggle would add configuration sprawl; the shipped generic color-reset mechanism provides the customization without another special case.
