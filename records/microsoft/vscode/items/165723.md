# Issue #165723 — More intuitive naming during conflict resolution 

[https://github.com/microsoft/vscode/issues/165723](https://github.com/microsoft/vscode/issues/165723)

## Summary

The clarified request remains unmet: inline conflict-resolution actions still say “Accept Current Change” and “Accept Incoming Change” rather than identifying the branches. The older related issue discusses merge-editor labels, but does not clearly own this distinct inline-action surface.

## Change summary

Identify the relevant branches in inline conflict-resolution action labels, particularly during rebases where Current and Incoming can be counterintuitive.

## Best solution

Make inline conflict-resolution actions identify the source of each side accurately, including rebase semantics, while retaining understandable fallback labels when branch information is unavailable. Coordinate terminology with the related merge-editor work without treating existing branch names above its panes as coverage of inline actions.
