# Issue #337527 — Agents chat copy includes hidden Monaco CSS when pasted as Markdown

[https://github.com/microsoft/vscode/issues/337527](https://github.com/microsoft/vscode/issues/337527)

## Summary

Confirmed, well-diagnosed bug (author is a VS Code team member with a direct source-level reproduction), and an open PR (#337669) already targets the fix — this stays open for that PR to land, not for a parallel agent attempt.

## Change summary

Copying Agents-window chat text that crosses a file-changes summary widget leaks the hidden widget's embedded CSS/style content into the HTML clipboard flavor, which then shows up as stray text when pasted as Markdown.

## Best solution

Land https://github.com/microsoft/vscode/pull/337669, which reportedly prevents hidden chat UI from leaking into Markdown copies; verify it excludes `style`/`script` elements in htmlToMarkdown.ts and filters non-content widgets in chatListWidget.ts's copy handler.

## Evidence

- **copy handler:** src/vs/workbench/contrib/chat/browser/widget/chatListWidget.ts lines ~789-799: clones fragments via cloneSelectedContents/sanitizeChatClipboardFragment and writes selection.toString() to text/plain but holder.innerHTML (the cloned DOM, including hidden widget markup) to text/html — matches the reporter's cited line numbers.
- **no style exclusion:** src/vs/base/browser/htmlToMarkdown.ts has no handling for `style` or `script` tags (grep found none); unknown/unhandled elements fall through to text-node conversion, so an embedded <style> becomes Markdown text, as reported.
