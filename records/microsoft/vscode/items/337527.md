# Issue #337527 — Agents chat copy includes hidden Monaco CSS when pasted as Markdown

[https://github.com/microsoft/vscode/issues/337527](https://github.com/microsoft/vscode/issues/337527)

## Summary

The defect remains source-reproducible on current main, and the open draft PR https://github.com/microsoft/vscode/pull/337669 explicitly fixes this issue. Keep the issue open while that human-owned implementation is reviewed.

## Change summary

Copying an Agents chat selection across the file-changes summary leaks hidden summary text and embedded Monaco CSS into Markdown-aware paste targets.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/337669, which removes non-content chat UI from copied fragments, ignores style/script content during HTML-to-Markdown conversion, and adds regression coverage for the reported path.

## Evidence

- **current source path:** On current main, src/vs/workbench/contrib/chat/browser/widget/chatClipboard.ts sanitizes links and images but does not remove `.checkpoint-file-changes-summary`, `style`, or `script` elements; src/vs/base/browser/htmlToMarkdown.ts falls through to `convertChildren(el)` for unknown elements, converting stylesheet text into Markdown.
- **copy trigger:** src/vs/workbench/contrib/chat/browser/widget/chatListWidget.ts clones each selected range and writes the sanitized fragment's `innerHTML` to the HTML clipboard flavor. A selection touching the local resource link activates this path while retaining the hidden summary widget and its embedded stylesheet.
- **open fixing PR:** https://github.com/microsoft/vscode/pull/337669 is an open draft with `Fixes #337527`; its patch removes `.checkpoint-file-changes-summary`, style, and script nodes, makes HTML-to-Markdown ignore style/script contents, and adds targeted tests.
- **canonical confirmation:** The later report https://github.com/microsoft/vscode/issues/337662 confirmed the same observable CSS-copy symptom on macOS and in both Agents and Editor windows, then was closed by a maintainer as a duplicate of this issue. This issue is therefore the canonical report, not a duplicate candidate.
