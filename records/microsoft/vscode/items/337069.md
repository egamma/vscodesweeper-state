# Issue #337069 — Notebook NES: edits mispositioned when enhancedNextEditSuggestions is enabled

[https://github.com/microsoft/vscode/issues/337069](https://github.com/microsoft/vscode/issues/337069)

## Summary

Keep open for diagnosis of notebook NES range conversion. Current main explicitly maps notebook-wide coordinates back to cells, but that does not establish that the reported failure is fixed; the supplied trigger, trace excerpts, and setting comparison suffice to start retesting.

## Change summary

Enhanced notebook NES inserts suggestions at incorrect cell positions and can display a same-notebook jump instead of the intended inline edit.

## Best solution

Make enhanced notebook NES preserve the intended target cell, insertion position, and line breaks in large notebooks. First reproduce the reported setting-dependent failure and determine whether suggestion generation, coordinate conversion, or display targeting produces the incorrect result.
