# Issue #267905 — [Source Control]: not able to show diff/staged view of git lfs files

[https://github.com/microsoft/vscode/issues/267905](https://github.com/microsoft/vscode/issues/267905)

## Summary

Still reproduces on main: the git extension's `buffer()` method uses `git show --textconv` which may not properly retrieve LFS-tracked binary content (returning LFS pointer data instead of actual file bytes), causing image diffs in Source Control to fail for LFS files. No LFS-specific handling exists in the codebase and no fix has been committed.

## Change summary

Staged Git LFS image files show 'An error occurred while loading the image' in the Source Control diff view instead of rendering the image.

## Best solution

The git extension's `buffer()` method in `extensions/git/src/git.ts` needs LFS-aware content retrieval — either by invoking `git lfs smudge` on the pointer content or by using a different retrieval path for LFS-tracked files. The `getObjectDetails()` method could detect LFS pointer objects and route to an LFS-specific fetch.
