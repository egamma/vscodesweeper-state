## Change summary

A bundle of UI polish requests for the new MCP servers page in Chat Customizations: inconsistent fonts between Installed/Available, a nested scrollable list inside a collapsible tree causing double scrollbars, a possible redesign of Available as its own page with search, and unsorted server names.

## Best solution

Address the confirmed, bounded items first (sort installedEntries alphabetically as a secondary key; fix the double-scrollbar nesting in mcpListWidget.ts), and let a maintainer decide the larger layout question (separate 'Available' page with search) before implementing that part.
