# Issue #331845 — Add enterprise policies for dictation model and LLM cleanup

[https://github.com/microsoft/vscode/issues/331845](https://github.com/microsoft/vscode/issues/331845)

## Summary

Verified real gap: `dictation.model` and `dictation.experimental.llmCleanup` have no `policy` block on main, unlike the sibling `dictation.enabled` setting, so admins cannot currently enforce on-device-only transcription or disable LLM cleanup — routing to the chat/dictation area to add policies mirroring the existing pattern.

## Change summary

Add enterprise policies for `dictation.model` (enforce on-device transcription) and `dictation.experimental.llmCleanup` (disable transcript-to-LLM cleanup) so administrators can guarantee dictation audio/text never leaves the device.

## Best solution

Add `policy` blocks to the `dictation.model` and `dictation.experimental.llmCleanup` setting definitions in src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts, following the same `PolicyCategory.InteractiveSession` pattern already used for `DictationEnabled` (lines 287-297), each with its own policy name, minimumVersion, and localized description.
