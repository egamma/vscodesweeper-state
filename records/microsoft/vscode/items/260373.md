## Summary

Still open on main — the continuation prompt characters (e.g. `...` or `>>`) leak into the terminal tab description when `shellPromptInput` is used in the tab template. Team-authored, no fix commit found.

## Change summary

The continuation prompt string (e.g. `...`) from shell integration appears in the terminal tab description instead of being stripped.

## Best solution

When building the `shellPromptInput` for the tab description in `terminalInstance.ts`, the `getCombinedString()` output includes continuation prompt prefixes that should be stripped. The fix likely belongs in `promptInputModel.ts` (either in `getCombinedString` or `_value` construction) to ensure continuation prompt prefixes are removed from the display value, or in `terminalInstance.ts` where `shellPromptInput` is assembled.
