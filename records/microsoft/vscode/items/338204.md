## Summary

Visible, user-confirmed regression where the old UI briefly flashes during folder close/switch/exit while the new modernized UI is active; a second commenter independently confirms the same experience, but no fix exists on main and the root cause (likely Electron window reload / theme-application timing across main and renderer) isn't traceable from source alone.

## Change summary

The old (pre-modernization) UI briefly flashes or appears when closing a folder, switching folders, or exiting, instead of staying consistent with the new UI.

## Best solution
