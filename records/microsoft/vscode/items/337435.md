- **Proposed comment:**

  > Thanks for the feedback. The tab bar look changed intentionally as part of the 'connected document tabs' redesign (PR https://github.com/microsoft/vscode/pull/335605, tracked by https://github.com/microsoft/vscode/issues/331104), so this isn't a bug — it's the new default styling.
  > 
  > If you'd like the previous colors back, you can add this to your `settings.json`:
  > ```json
  > "workbench.colorCustomizations": {
  >   "editorGroupHeader.tabsBackground": "#F8F8F8",
  >   "tab.inactiveBackground": "#F8F8F8",
  >   "tab.inactiveForeground": "#868686"
  > }
  > ```
  > Closing as as-designed, but feel free to share more specific feedback on the new look if there's something concrete we should reconsider.
