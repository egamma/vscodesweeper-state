# Issue #304319 — Language Model selector retains removed API provider models after deletion

[https://github.com/microsoft/vscode/issues/304319](https://github.com/microsoft/vscode/issues/304319)

## Summary

The stale-model path was fixed after this issue was reopened: current main treats an empty resolved BYOK provider as authoritative, evicts its cached models, and resets a removed selection to an available default.

## Change summary

Removing a BYOK provider or API key should remove its models from the chat selector instead of retaining the selected model and silently falling back to Copilot Auto.
