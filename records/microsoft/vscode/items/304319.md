# Issue #304319 — Language Model selector retains removed API provider models after deletion

[https://github.com/microsoft/vscode/issues/304319](https://github.com/microsoft/vscode/issues/304319)

## Summary

The reopened issue was subsequently fixed by commit ec46e336fb6d309a992069ad4c8be09a1144041d, which removes cached BYOK models after their provider resolves with no models and resets a now-unavailable selection.

## Change summary

Removing a configured API provider should remove its models from the chat selector instead of retaining the selected model and silently falling back to Copilot Auto.

## Best solution

Keep the shipped cache-invalidation behavior from commit ec46e336fb6d309a992069ad4c8be09a1144041d: an authoritative empty provider result evicts its cached models, allowing the selected model to reset normally.
