# Issue #345247 — Remote Copilot edit entries open Linux files as local file:// URIs on macOS

[https://github.com/microsoft/vscode/issues/345247](https://github.com/microsoft/vscode/issues/345247)

## Summary

Keep open: the current Working Set conversion still loses remote filesystem context for an editor-remote connection. The source explains why clicking the file fails while opening its recorded diff succeeds.

## Change summary

Opening an agent-host Copilot edited-file entry should preserve the remote Linux filesystem context instead of targeting the macOS filesystem.

## Best solution

Ensure Working Set file identities follow the owning connection's host-to-client URI mapping, while recorded snapshots remain readable through their existing content-reference path. Preserve local sessions, standalone remote hosts, and Keep/Undo behavior.
