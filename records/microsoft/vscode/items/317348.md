# Issue #317348 — SSH to windows host: VS Code Server failed to start

[https://github.com/microsoft/vscode/issues/317348](https://github.com/microsoft/vscode/issues/317348)

## Summary

Fixed on main and shipped in 1.122.0 — the CLI's agent host supervisor startup was blocking the command-shell server, causing SSH connections to Windows hosts to fail. The reporter confirmed the fix in Comment 5.

## Change summary

SSH to Windows host fails with 'VS Code Server failed to start' because the agent host supervisor startup blocks the command-shell from accepting connections.

## Best solution

Keep the shipped fix (commit 2acbbb8026); no further change needed. Users on 1.122.0+ should no longer see this issue.

  > Thanks for the detailed bisect — that made this straightforward to trace. The root cause was that the agent host supervisor startup (`ensure_supervisor_running`) was running synchronously and blocking the `command-shell` from accepting connections, so the Remote SSH extension saw an exit before a listening port was reported.
  > 
  > This was fixed in https://github.com/microsoft/vscode/commit/2acbbb80269327825303bab57f2b82f71fe89438 (PR https://github.com/microsoft/vscode/pull/317874), which moves the supervisor startup to a background task. The fix shipped in **1.122.0**. If you're still seeing issues on 1.122.0+, please open a new issue with fresh logs.
