# Issue #348510 — Right clicking on a comment icon in the gutter should show a context menu offering a delete action

[https://github.com/microsoft/vscode/issues/348510](https://github.com/microsoft/vscode/issues/348510)

## Summary

Keep open: the gutter interaction does not expose the requested delete menu. This is a team-authored, accepted Backlog request already routed to comments; existing widget menus do not cover the requested entry point.

## Change summary

Offer a delete action when right-clicking an existing comment's gutter icon.

## Best solution

Expose applicable comment actions from the clicked gutter icon, respecting the owning provider's deletion permissions and action context rather than introducing unconditional deletion.
