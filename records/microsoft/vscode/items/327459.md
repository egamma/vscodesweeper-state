- **Behavior:**

  > A small local Git repository must remain usable without a remote. The reporter can make one commit after restarting the extension host, but subsequent edits stop appearing while Source Control progress continues indefinitely. Acceptance is repeated edit-and-commit cycles with timely change detection and terminating progress, without restarting the extension host or configuring origin. - **Trace:**

  > Repository.status, Repository.run, _updateModelState, and ProgressManager in extensions/git/src/repository.ts connect Git operations, resource-group refresh, and Source Control progress. Metadata is awaited before status and refs are published, so an outstanding operation can prevent both fresh changes and progress completion. In extensions/git/src/git.ts, getRemotes accepts an empty list, getHEADRef conditionally resolves upstream information, and getStatus is local; no conclusive remote-less failure was found. The uncertainty begins at which operation remains outstanding in the reporter's environment; capture Git output and extension-host diagnostics during the sequence. Preserve local-only repository support and existing remote synchronization behavior; the presence of installed extensions alone does not establish extension causation. Related discovery reports https://github.com/microsoft/vscode/issues/291281 and https://github.com/microsoft/vscode/issues/310224 do not establish the same root cause.
