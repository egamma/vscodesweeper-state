# Issue #290096 — Allow --ours and --theirs options for multiple files in large merge conflicts

[https://github.com/microsoft/vscode/issues/290096](https://github.com/microsoft/vscode/issues/290096)

## Summary

Keep open: existing commands support accepting current or incoming changes across selected files, but do not provide the requested Merge Changes group-header actions or bulk Accept Both. The older related reports concern different failures and do not fully own this request.

## Change summary

Add Source Control group-header actions to accept current, incoming, or both changes across all files in the merge-conflict group.

## Best solution

Provide consistent group-wide conflict-resolution actions in the built-in merge-conflict contribution, retaining existing selected-file behavior. Define these as conflict-region resolution rather than assuming they are equivalent to replacing entire files with git checkout --ours or --theirs.
