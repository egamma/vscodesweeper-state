# Issue #70656 — WebView doesn't close on extension (but not window) reload

[https://github.com/microsoft/vscode/issues/70656](https://github.com/microsoft/vscode/issues/70656)

## Summary

Keep open: extension-host-only restarts still lack the requested webview lifecycle handling, and an open PR explicitly targets this issue. Review that proposal against the maintainer's suggestion to support serialization on extension reload rather than automatically closing every webview.

## Change summary

Handle extension-host restarts so surviving webview panels do not remain disconnected from their backing extensions.

## Best solution

Define restart behavior that preserves intentionally standalone webviews while allowing extension-dependent panels to close or reconnect reliably. Review https://github.com/microsoft/vscode/pull/225979 against the serialization approach discussed here before landing a solution.
