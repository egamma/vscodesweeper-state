# Issue #70656 — WebView doesn't close on extension (but not window) reload

[https://github.com/microsoft/vscode/issues/70656](https://github.com/microsoft/vscode/issues/70656)

## Summary

Valid feature request with an open PR (#225979) proposing a solution via an `autoCloseWhenDispose` option. The issue remains relevant — webview panels still lack proper lifecycle handling on extension host restart. Keeping open pending PR review.

## Change summary

Webview panels remain open but non-functional after an extension host restart, with no way for extensions to reconnect or close them.

## Best solution

Review and land (or iterate on) the open PR https://github.com/microsoft/vscode/pull/225979, which introduces an `autoCloseWhenDispose` option in `WebviewPanelOptions`. Additionally, consider supporting webview panel serializer re-invocation on extension host restart (as the reporter and commenters suggest) for extensions that want to reconnect rather than close.
