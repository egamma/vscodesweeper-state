# Issue #332536 — Visual glitch: Focus outline border clipping in suggestion/completion widget

[https://github.com/microsoft/vscode/issues/332536](https://github.com/microsoft/vscode/issues/332536)

## Summary

Freshly filed, unconfirmed report, but the code plausibly explains the symptom: the suggest widget's rounded container has no overflow clipping, so a focused row's rectangular outline can visually clash with the rounded corner when that row sits at the top/bottom of the list.

## Change summary

The blue focus outline on a selected suggestion/completion item appears clipped/disconnected at the widget's rounded top-right corner.

## Best solution

In src/vs/editor/contrib/suggest/browser/media/suggest.css, either add overflow clipping to `.monaco-list` (which already carries `border-radius: var(--vscode-cornerRadius-large)` at line 105) or give the first/last `.monaco-list-row` a matching border-radius so a focused row's `outline` (line 122-126) doesn't overrun the rounded container corner.
