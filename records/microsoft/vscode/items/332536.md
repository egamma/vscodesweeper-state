# Issue #332536 — Visual glitch: Focus outline border clipping in suggestion/completion widget

[https://github.com/microsoft/vscode/issues/332536](https://github.com/microsoft/vscode/issues/332536)

## Summary

Traced in source: the suggestion list container has a rounded, overflow-hidden border (`.monaco-list` gets `border-radius` in suggest.css plus `overflow: hidden` from the base list.css), but the focused row's selection outline is a plain rectangle with no matching radius, so its corner gets clipped whenever the first/last row is focused — matching the reporter's screenshot exactly.

## Change summary

The blue focus outline on the selected suggestion/completion item is visibly clipped at the rounded corner of the widget.

## Best solution

Round the focused row's outline to match the list container's corner radius (e.g. via a first-child/last-child CSS rule or clip-path) in src/vs/editor/contrib/suggest/browser/media/suggest.css so the outline no longer collides with the parent's rounded, clipped edge.
