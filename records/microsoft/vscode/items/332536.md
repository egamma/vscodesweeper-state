# Issue #332536 — Visual glitch: Focus outline border clipping in suggestion/completion widget

[https://github.com/microsoft/vscode/issues/332536](https://github.com/microsoft/vscode/issues/332536)

## Summary

Real visual bug traced in current source: the suggest widget's `.monaco-list` container has rounded corners (`border-radius: var(--vscode-cornerRadius-large)`) but the focused row's outline in suggest.css has no matching radius, so when the top/bottom row is focused its square outline gets clipped by the container's rounded edge.

## Change summary

The blue focus outline on the selected suggestion/completion item doesn't follow the widget's rounded corners, appearing clipped at the top-right corner.

## Best solution

In src/vs/editor/contrib/suggest/browser/media/suggest.css, round the focused row's outline to match the container radius (e.g. apply border-radius on `.monaco-list-row.focused` for edge rows, or use a mask/overflow trick) so the outline follows the rounded corner cleanly.
