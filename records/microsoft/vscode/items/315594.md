# Issue #315594 — `npm.scriptRunner` should support deno

[https://github.com/microsoft/vscode/issues/315594](https://github.com/microsoft/vscode/issues/315594)

## Summary

Valid feature request: the `npm.scriptRunner` setting currently supports npm, yarn, pnpm, bun, node, and vp, but not deno. Deno's `deno task` command can run npm scripts, so adding it is a reasonable extension of the existing pattern. Already correctly labeled and milestoned; keeping open for community traction.

## Change summary

Add `deno` as a supported value for the `npm.scriptRunner` setting so Deno users can run npm scripts via `deno task`.

## Best solution

Add `deno` to the `npm.scriptRunner` enum in `extensions/npm/package.json` and handle the `deno task` command in `extensions/npm/src/tasks.ts`, following the same pattern used for bun/pnpm/node/vp. A small, well-scoped change — could be a good `help wanted` candidate.
