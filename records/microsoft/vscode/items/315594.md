# Issue #315594 — `npm.scriptRunner` should support deno

[https://github.com/microsoft/vscode/issues/315594](https://github.com/microsoft/vscode/issues/315594)

## Summary

Deno remains unsupported by the built-in npm script runner, so the requested capability is still missing. The older matching request is closed, not a valid duplicate target; retain this accepted Backlog item.

## Change summary

Allow npm scripts defined in package.json to run through deno task using npm.scriptRunner.

## Best solution

Support explicitly selecting Deno in the built-in npm extension and invoking package.json scripts through deno task, with compatible handling of runner-specific options. Keep dependency installation and automatic runtime detection outside this request unless separately agreed.
