# Issue #345519 — Inbox titles are not so helpful in my case

[https://github.com/microsoft/vscode/issues/345519](https://github.com/microsoft/vscode/issues/345519)

## Summary

Keep open as an Inbox presentation request: current rows emphasize the next action and retain the existing session title, but do not independently identify the underlying work goal. Repository and PR metadata already provide partial coverage; the remaining title hierarchy needs a product decision.

## Change summary

Make Inbox rows lead with the work goal, distinguish its current status, and show full repository identity and associated PRs.

## Best solution

Agree on a goal-first Inbox hierarchy that uses linked work context without requiring users to continually rename sessions. Preserve useful action/status information and full repository/PR metadata, while deciding separately whether work spanning multiple sessions changes the row model.
