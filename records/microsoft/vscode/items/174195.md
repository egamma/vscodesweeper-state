# Issue #174195 — Git - Commit Staged (Amend) doesn't change the commit message if there are no staged changes but there are changes

[https://github.com/microsoft/vscode/issues/174195](https://github.com/microsoft/vscode/issues/174195)

## Summary

The reported silent return is fixed on current main: staged amend can update the previous commit message with an empty index and outstanding working-tree changes. Propose closing as completed, rather than declining the behavior as designed.

## Change summary

Allow Commit Staged (Amend) to update the last commit message when there are unstaged changes but no staged changes.

## Best solution

Retain the amend exception implemented in commit 3c7cbd264e4313f236dbbad13303da54c23582d9. With git.enableSmartCommit disabled, git.commitStagedAmend updates the message without staging the outstanding working-tree changes.
