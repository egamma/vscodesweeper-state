## Summary

Keep open: current source still uses the panel background as text on independently colored branch chips, allowing insufficient contrast in custom themes. The linked high-contrast graph request is related, but does not establish a duplicate of this light-theme chip-text defect.

## Change summary

Ensure Source Control Graph branch-chip text remains readable when a light theme has a relatively dark panel background.

## Best solution
