[https://github.com/microsoft/vscode/issues/231030](https://github.com/microsoft/vscode/issues/231030)

## Summary

Keep open: the report provides sufficient steps to retest activity-bar clicks when a window extends beyond the display on KDE Wayland. The windowing stack has changed since VS Code 1.94.2, but source inspection does not establish that this environment-dependent failure is fixed.

## Change summary

Activity-bar icons stop responding to clicks when the VS Code window extends beyond the visible monitor area.
