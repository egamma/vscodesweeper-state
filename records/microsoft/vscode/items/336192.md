# Issue #336192 — MCP connection failures cancel the agent turn as if the user pressed Stop

[https://github.com/microsoft/vscode/issues/336192](https://github.com/microsoft/vscode/issues/336192)

## Summary

Well-diagnosed bug: current main's mcpServerRequestHandler.ts cancels all pending RPCs when the transport enters Error/Stopped (lines 210-211), and McpTool rethrows that CancellationError uncaught, which Copilot's toolCallErrorToResult treats as user cancellation — matching the reporter's traced code path exactly. An open PR from the same author already fixes it, so this should stay open pending that PR's review/merge rather than being closed.

## Change summary

An MCP connection failure (transport entering Error/Stopped) is misreported as user cancellation, silently ending the agent turn instead of surfacing an ordinary tool/connection error.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/336205, which converts a connection-caused CancellationError in McpTool._callWithProgress() into an ordinary McpConnectionFailedError while preserving genuine caller cancellation — that closes the gap described here.
