# Issue #336192 — MCP connection failures cancel the agent turn as if the user pressed Stop

[https://github.com/microsoft/vscode/issues/336192](https://github.com/microsoft/vscode/issues/336192)

## Summary

The current source still conflates MCP connection failure with user cancellation, terminating the agent turn. Keep this open while the explicitly linked fixing PR is reviewed; it has not merged.

## Change summary

Distinguish MCP connection-caused cancellation from genuine caller cancellation so a failed tool invocation does not prematurely end the agent turn.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/336205 if its boundary handling satisfies the report: connection failures become ordinary tool errors, interaction-required stops remain actionable, and genuine cancellation and existing retry semantics stay unchanged.
