# Issue #116614 — Allow to change double click select expand mode to whole word select

[https://github.com/microsoft/vscode/issues/116614](https://github.com/microsoft/vscode/issues/116614)

## Summary

Legitimate feature request for word-level selection expansion when shift+clicking after a double-click word selection. The behavior isn't implemented — current code in viewController.ts only uses word-level drag during the double-click gesture itself, not for subsequent shift+clicks. Low traction (2 upvotes) but a real gap; keeping open in Backlog.

## Change summary

Request to expand selection by whole words (not characters) when shift+clicking after a double-click word selection, matching Atom's behavior.

## Best solution

Implement a mode or setting so that after a double-click word selection, subsequent shift+clicks expand the selection by word boundaries rather than character positions. The change would likely live in `src/vs/editor/browser/view/viewController.ts` (the single-click-with-shift path at mouseDownCount=1) and possibly `src/vs/editor/browser/controller/mouseHandler.ts` to track the selection expansion mode. Related to https://github.com/microsoft/vscode/issues/3130 (mouse shortcut customization) but distinct enough to stand alone.
