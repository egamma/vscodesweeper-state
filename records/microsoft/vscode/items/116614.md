# Issue #116614 — Allow to change double click select expand mode to whole word select

[https://github.com/microsoft/vscode/issues/116614](https://github.com/microsoft/vscode/issues/116614)

## Summary

The requested whole-word expansion behavior is implemented on current main: selections started by double-click retain word granularity when subsequently extended with Shift+click.

## Change summary

Allow a selection started by double-clicking a word to expand by whole words when extended with Shift+click.

## Best solution

Keep the behavior implemented by commit eb2776f645da56bc83a7f66891932264f636cbc5, which makes word-granularity continuation the default and therefore satisfies the central request without another editor setting.
