## Change summary

Resolving the first conflicted file moves Source Control focus into Staged Changes rather than advancing through the remaining conflicts.

## Best solution

Preserve the user's place in Merge Changes when a resolved resource leaves that group, advancing to the next remaining conflict. First distinguish resource-removal focus handling from active-editor auto-reveal so the fix preserves normal editor-to-SCM synchronization.
