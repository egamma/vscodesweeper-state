# Issue #292379 — Custom editors: Allow setting different priorities for edit/diff/merge

[https://github.com/microsoft/vscode/issues/292379](https://github.com/microsoft/vscode/issues/292379)

## Summary

The per-editor-type priority contribution point is implemented on main as a proposed API (customEditorDiffs) and is actively being finalized. A team member (hediet) explicitly kept this open to track the API finalization. The issue carries `api-finalization` and milestone `1.132.0` — it should remain open.

## Change summary

Allow custom editors to declare separate priorities for text editor, diff editor, and merge editor modes instead of a single shared priority.

## Best solution

Finalize the `customEditorDiffs` proposed API — the contribution-point shape (`priority: { textEditor, diffEditor, mergeEditor }`) is already implemented and landed via PRs #315321, #316503, and #321503. Once the API graduates from proposal to stable, this issue can be closed.
