# Issue #292379 — Custom editors: Allow setting different priorities for edit/diff/merge

[https://github.com/microsoft/vscode/issues/292379](https://github.com/microsoft/vscode/issues/292379)

## Summary

The requested feature has been implemented as a proposed API (`customEditorPriority`) behind `enabledApiProposals`, with the contribution point shape `priority: { textEditor, diffEditor, mergeEditor }`. However, the API is not yet finalized — the `api-finalization` label is correct and the issue should stay open to track finalization so extensions can use it without opting into a proposal.

## Change summary

Allow custom editors to set different priorities for regular edit, diff, and merge editor contexts instead of a single shared priority.

## Best solution

Finalize the `customEditorPriority` proposed API so extensions can use the `priority: { textEditor, diffEditor, mergeEditor }` contribution point without needing `enabledApiProposals`. The implementation is already on main in `src/vs/workbench/contrib/customEditor/common/extensionPoint.ts` and `contributedCustomEditors.ts` — finalization requires removing the proposal gate and adding the types to stable `vscode.d.ts`.
