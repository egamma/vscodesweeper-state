# Issue #325318 — Profiles: Specify default profile per-machine

[https://github.com/microsoft/vscode/issues/325318](https://github.com/microsoft/vscode/issues/325318)

## Summary

A real profile-management gap remains: users can choose a default profile, but the issue requests a machine-local override that is not synchronized. No verified canonical issue or existing capability in the provided record fully covers that behavior.

## Change summary

Allow each machine to override the synchronized default profile used when opening folders and workspaces.

## Best solution

Define a machine-local default-profile preference that takes precedence over the synchronized default while preserving existing workspace-to-profile associations and profile sync behavior.
