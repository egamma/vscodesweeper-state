# Issue #342502 — MCP migrate: Migration should reveal the migrated server after completion

[https://github.com/microsoft/vscode/issues/342502](https://github.com/microsoft/vscode/issues/342502)

## Summary

Keep open: successful MCP migration currently returns to the migration dashboard rather than revealing the migrated server. The requested completion feedback remains missing; whether to restore a session-only migration log needs a maintainer decision.

## Change summary

Reveal the migrated MCP server after a single-server migration and consider restoring migration history that does not survive VS Code restarts.

## Best solution

Make a successful single-server migration lead to the corresponding server in the MCP management section. Resolve the separate request for a visible migration log, preserving the requested restart boundary if it is restored.
