# Issue #236329 — Notebook: Cannot move a markdown cell that is in edit mode

[https://github.com/microsoft/vscode/issues/236329](https://github.com/microsoft/vscode/issues/236329)

## Summary

Still reproduces on main: the MarkupCellRenderer never calls `registerDragHandle` on the dndController, unlike CodeCellRenderer, so markdown cells in edit mode have no drag handle registered and cannot be moved via drag-and-drop.

## Change summary

Markdown cells in edit mode cannot be dragged/moved because the drag handle is not registered in the markup cell renderer.

## Best solution

Register drag handles for markdown cells in `MarkupCellRenderer.renderTemplate()` (in `src/vs/workbench/contrib/notebook/browser/view/renderers/cellRenderer.ts`) the same way `CodeCellRenderer` does at line 377-378, using `focusIndicatorLeft.domNode` as the drag handle element.
