## Summary

The missing-resource failure remains explainable from current source: local marketplace plugins are copied without their repository siblings. Keep this open while maintainers settle the supported package boundary; the existing related reports do not own this specific failure.

## Change summary

Repository-relative imports disappear when installed plugins are materialized in the Agent Host cache, causing edit hooks to fail.
