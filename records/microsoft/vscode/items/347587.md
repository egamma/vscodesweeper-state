## Summary

Keep open: current source still copies client-local plugin directories without their repository-level dependencies, matching the reported missing-module failure. The supported packaging boundary needs a maintainer decision; the related reports do not own this specific problem.

## Change summary

Marketplace plugins with repository-relative hook dependencies fail after Agent Host materialization, blocking edit tools.

## Best solution

Define and enforce the resource boundary for marketplace subdirectory plugins so required hook resources are available or incompatibility is clearly reported before use. Preserve intentional hook denials rather than treating hook failures as permission to edit.
