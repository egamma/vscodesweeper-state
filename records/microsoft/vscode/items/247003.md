# Issue #247003 — vscode/proxy-agent uses untrusted certificates on macOS

[https://github.com/microsoft/vscode/issues/247003](https://github.com/microsoft/vscode/issues/247003)

## Summary

Valid bug confirmed by the assignee (chrmarti): the proxy-agent reads all macOS keychain certificates without checking trust settings, so untrusted certs are treated as trusted CAs. Still unfixed on main — the installed @vscode/proxy-agent v0.32.0 still uses the unguarded `find-certificate -a -p` call. Two potential fix paths have been identified in the discussion.

## Change summary

On macOS, vscode/proxy-agent loads all keychain certificates as trusted CAs regardless of their individual trust settings.

## Best solution

Fix `readMacCaCertificates` in microsoft/vscode-proxy-agent to either filter certs via `security verify-cert` or adopt Node.js 22+'s native OS certificate support (`--use-system-ca` / `NODE_USE_SYSTEM_CA`), which already respects per-cert trust settings on macOS. The fix lives in the upstream dependency repo, not in this checkout.
