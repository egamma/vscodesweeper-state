# Issue #320865 — FLAC files open as binary instead of Media Preview

[https://github.com/microsoft/vscode/issues/320865](https://github.com/microsoft/vscode/issues/320865)

## Summary

Confirmed on current main: the media-preview extension's audioPreview selector registers only `*.{mp3,wav,ogg,oga}` and omits `flac`, so FLAC files fall back to the binary-file text editor. The release notes and codec docs advertise FLAC support, making this a gap between documented and actual behavior.

## Change summary

FLAC audio files are not associated with the built-in Audio Preview editor despite FLAC being listed as a supported codec in VS Code's release notes.

## Best solution

Add `flac` to the `filenamePattern` glob in `extensions/media-preview/package.json` for the `vscode.audioPreview` custom editor selector, changing `*.{mp3,wav,ogg,oga}` to `*.{mp3,wav,ogg,oga,flac}`. This is a one-line fix in a JSON file.
