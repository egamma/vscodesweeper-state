# Issue #226719 — `FileSearchProviderOptions` isn't a good name for its purpose

[https://github.com/microsoft/vscode/issues/226719](https://github.com/microsoft/vscode/issues/226719)

## Summary

The naming concern remains on current main: FileSearchProviderOptions describes an individual search invocation. Keep this open for API-owner review because the suggested replacement, FileSearchOptions, already names a different legacy options contract.

## Change summary

Give the file-search invocation options type a name that does not suggest provider-registration options.

## Best solution

Use a clear invocation-oriented name in the proposed file-search API, with an explicit compatibility decision for the existing FileSearchOptions type. Preserve search behavior and legacy-provider compatibility.
