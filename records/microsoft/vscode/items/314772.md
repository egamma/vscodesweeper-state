# Issue #314772 — Agent plugins: skills appear in system prompt but `skill` tool fails with "not found"

[https://github.com/microsoft/vscode/issues/314772](https://github.com/microsoft/vscode/issues/314772)

## Summary

Confirmed known bug: plugin-sourced skills are discovered and rendered into the system prompt via `getSkills()`, but the `skill` tool's `resolveSkillUri` only finds skills whose URIs are recognized by `getSkillInfo()` — which depends on the extension prompt files cache being populated and matching the URI. A team member (pwang347) acknowledged the issue and recommended disabling the experimental `github.copilot.chat.skillTool.enabled` setting as a workaround. No fix has landed on main.

## Change summary

Plugin-provided skills appear in the agent system prompt's `<skills>` section but the `skill` tool fails to resolve them, returning 'skill not found'.

## Best solution

Fix the skill tool's `resolveSkillUri` in `extensions/copilot/src/extension/tools/node/skillTool.ts` to correctly resolve plugin-sourced skill URIs — likely by ensuring the `getSkillInfo` lookup in `CustomInstructionsService` covers plugin skill folder paths, or by adding a fallback path that resolves skills directly from the `_extensionPromptFilesCache` by name. The prompt-building path (`automaticInstructionsCollector.ts`) already discovers these skills correctly; the tool just needs parity.
