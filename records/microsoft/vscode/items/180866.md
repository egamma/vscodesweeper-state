# Issue #180866 — undo image paste in rendered notebook markdown will just remove the attachment

[https://github.com/microsoft/vscode/issues/180866](https://github.com/microsoft/vscode/issues/180866)

## Summary

Team-authored issue (MEMBER) — must keep open. The underlying bug is still present on main: the undo/redo groupOrder logic in `undoRedoService.ts` still picks only the highest-groupOrder element, skipping the cell text change when `notebook.undoRedoPerCell` is enabled, causing a broken image link on undo.

## Change summary

Undoing an image paste in a rendered notebook markdown cell removes only the attachment metadata but not the markdown text, leaving a broken image link.

## Best solution

Fix the undo/redo group traversal in `src/vs/platform/undoRedo/common/undoRedoService.ts` so that `_findClosestUndoElementInGroup` and `_continueUndoInGroup` correctly undo ALL elements in the group regardless of groupOrder differences across separate undo stacks (cell vs. notebook). As rebornix noted, this is conceptually similar to cross-file grouped edits and may need a design decision on how grouped undo interacts with the per-cell undo stack setting.
