# Issue #180866 — undo image paste in rendered notebook markdown will just remove the attachment

[https://github.com/microsoft/vscode/issues/180866](https://github.com/microsoft/vscode/issues/180866)

## Summary

Still reproduces on main: the undo/redo service's groupOrder-based lookup in `_findClosestUndoElementInGroup` skips the cell text edit when the notebook metadata edit has a higher groupOrder, causing only the attachment metadata to be undone while leaving the broken image link in the rendered markdown cell.

## Change summary

Undoing an image paste in a rendered notebook markdown cell only removes the attachment metadata but not the cell text reference, leaving a broken image link.

## Best solution

Fix the undo group resolution in `_findClosestUndoElementInGroup` (or the notebook undo integration) so that when `notebook.undoRedoPerCell` is enabled, a grouped workspace edit that spans both the cell text model and the notebook document model correctly undoes both parts regardless of groupOrder. The `_continueUndoInGroup` mechanism should find and undo all elements sharing the same groupId, not just the one with the highest groupOrder.
