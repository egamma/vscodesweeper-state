Keep open: the discussion confirms that undo can remove attachment metadata without removing the markdown reference. Current source warrants retesting, but no verified fix referencing this team-authored issue or qualifying duplicate was found.

## Change summary

Undoing an image paste after rendering a notebook markdown cell removes the attachment while leaving a broken image reference.

## Best solution
