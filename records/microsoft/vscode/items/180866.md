# Issue #180866 — undo image paste in rendered notebook markdown will just remove the attachment

[https://github.com/microsoft/vscode/issues/180866](https://github.com/microsoft/vscode/issues/180866)

## Summary

Keep open: a team-authored report and maintainer investigation confirm that undoing from a rendered markdown cell can revert attachment metadata without reverting the grouped text insertion. The related fix for https://github.com/microsoft/vscode/issues/181962 addressed snippet undo stops but did not close or explicitly fix this separate per-cell notebook-stack case.

## Change summary

Undoing an attached-image paste from a rendered notebook markdown cell removes the attachment metadata but leaves the image link behind.

## Best solution

A single undo should atomically revert both the markdown insertion and attachment metadata regardless of whether the cell is rendered and whether `notebook.undoRedoPerCell` is enabled. The notebook and undo/redo owners should decide whether that guarantee belongs in notebook edit composition or in cross-resource grouped-undo handling.
