# Issue #330987 — Editor patch tool bypasses agent sandbox write allowlist

[https://github.com/microsoft/vscode/issues/330987](https://github.com/microsoft/vscode/issues/330987)

## Summary

Security-sensitive report: the editor-integrated patch/edit tool appears to bypass the agent sandbox's write allowlist that shell commands otherwise respect. This must stay open for a human security review regardless of any other evidence.

## Change summary

Editor patch tool wrote a file to the user's home directory despite a sandbox policy restricting writes to the workspace and temp dir.

## Best solution

A maintainer with sandbox/tooling ownership should verify whether the editor-level apply-patch/edit tool path enforces the same allowlist as sandboxed shell execution, and if not, route writes through the shared sandbox write-check before landing changes. A commenter notes `chat.agent.sandbox.allowUnsandboxedCommands` may be relevant but that doesn't fully explain a tool-level bypass, so this needs deliberate investigation rather than a quick close.
