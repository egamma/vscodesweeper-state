## Summary

Verified duplicate: this asks for customizable reasoning effort in Copilot agent sessions, which is the same work tracked by #318592 (closed as completed). The model picker now generically supports per-model configuration properties including reasoning effort, and an explicit agent-host reasoning-effort override setting exists.

## Change summary

Allow customizing reasoning effort for Copilot Pro+ Codex agent sessions, which was not available in the model picker at the time of filing.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/318592 — reasoning effort is now configurable via the model picker's generic `configurationSchema` mechanism and the `chat.agentHost.reasoningEffortOverride` advanced setting. No distinct requirement remains here.
