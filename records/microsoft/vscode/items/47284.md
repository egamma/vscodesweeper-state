[https://github.com/microsoft/vscode/issues/47284](https://github.com/microsoft/vscode/issues/47284)

Keep open under discussion: current source still defaults telemetry to enabled, so the central opt-in request remains unmet. Transparency tools address part of the report, but neither satisfy prior consent nor establish grounds to close this well-supported request.

## Change summary
