# Issue #334121 — Multiple Agents Windows

[https://github.com/microsoft/vscode/issues/334121](https://github.com/microsoft/vscode/issues/334121)

## Summary

This is a real, currently unsupported multi-project workflow: VS Code forwards each originating folder to one shared Agents Window rather than allowing independently positioned windows. The issue is already routed to the Agents Window area and should remain open for a product decision.

## Change summary

Allow separate Agents Windows for different VS Code project windows so each can remain on its project's desktop.

## Best solution

If multiple top-level Agents Windows are accepted, give each window a distinct identity and workspace association while preserving shared session discovery, so invoking “Open in Agents” can reveal or create the window associated with that source project.
