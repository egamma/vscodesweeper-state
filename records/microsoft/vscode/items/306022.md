# Issue #306022 — Orca reads entire page content when navigating across accessibilityPageSize boundary

[https://github.com/microsoft/vscode/issues/306022](https://github.com/microsoft/vscode/issues/306022)

## Summary

The reporter confirmed that this is an Orca-side issue, and the upstream report documents the same reproduction and a verified fix. Keep this open for upstream release visibility as requested by the reporter; no VS Code code change is currently indicated.

## Change summary

Prevent Orca from speaking an entire accessibility page, then repeating the current line, when editor navigation or editing replaces the page content.

## Best solution

Use the Orca fix tracked at https://gitlab.gnome.org/GNOME/orca/-/issues/733, which distinguishes navigation-driven page replacement from actual text insertion. Retain this issue until the reporter confirms resolution with a stable Orca release, without changing VS Code's accessibility paging behavior.
