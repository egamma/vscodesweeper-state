# Issue #296186 — Clicking continue in background to start implementation of copilot agent plan causes session to disappear

[https://github.com/microsoft/vscode/issues/296186](https://github.com/microsoft/vscode/issues/296186)

## Summary

Confirmed bug: clicking 'continue in background' during agent plan implementation causes the session to vanish from the chat history UI, though it can be recovered from the archived list or workspace storage. Multiple users reproduced on 1.109.4. No fix commit referencing this issue was found on main.

## Change summary

Clicking 'continue in background' to delegate a Copilot agent plan to a background session causes the session to disappear from the visible chat history.

## Best solution

The delegation flow that moves a session to a background agent should keep the session visible (or clearly surfaced as 'running in background') rather than silently archiving it. The fix likely lives in the `chatContinueInAction.ts` delegation path and/or the agent sessions service's session-state management. The session should remain discoverable in the chat sidebar with a 'running in background' indicator.

- **Reason:** Agent sessions and background delegation are part of the current agent-experience focus; a broken delegation flow undermines that investment.
- **Evidence:** Aligns with current agent-host and agent-sessions priorities around reliable multi-session agent workflows.
