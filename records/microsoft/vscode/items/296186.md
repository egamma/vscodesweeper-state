# Issue #296186 — Clicking continue in background to start implementation of copilot agent plan causes session to disappear

[https://github.com/microsoft/vscode/issues/296186](https://github.com/microsoft/vscode/issues/296186)

## Summary

Keep open: several commenters confirmed the disappearing-session behavior, and two recovered their conversations from Archived rather than finding them deleted. Current delegation handling has changed, but neither a fix covering this report nor an older open canonical with the same symptom was established.

## Change summary

Starting background implementation from a completed Copilot plan hides the original session without leaving an apparent background session.

## Best solution

Ensure the plan remains recoverable and the background implementation session becomes discoverable after handoff; cancelled or unsuccessful delegation must not strand the conversation. Retest the supplied workflow on Windows with WSL before deciding whether further changes to delegation exit handling are needed.
