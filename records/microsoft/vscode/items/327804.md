# Issue #327804 — Provisional agent-host chat does not refresh customizations after changing the primary folder (same-URI recreate leaves stale subscription)

The stale customization state is conclusively traceable in the current source and should remain open for a localized subscription-refresh fix. It is also a team-authored issue, so the hard keep-open rule applies.

## Change summary

Refresh a live agent-host session subscription when a provisional session is recreated under the same backend URI.

## Best solution
