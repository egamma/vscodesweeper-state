# Issue #314317 — Proposal: Stable Preview channel + first-class feature gates for progressive rollout

[https://github.com/microsoft/vscode/issues/314317](https://github.com/microsoft/vscode/issues/314317)

## Summary

Well-articulated proposal for a Stable Preview channel and formalized feature gates infrastructure. No existing feature gate system exists in the platform layer today. The referenced issues are closed. Keeping open for community traction and maintainer input on whether this direction is worth pursuing.

## Change summary

Add a Stable Preview distribution channel and a first-class feature gates system with percentage-based rollout, cohort telemetry, and mandatory expiration policies.

## Best solution

This is a significant architectural investment that would need explicit buy-in from the VS Code team. The proposal covers build infrastructure, telemetry, and extension API surface — each of which is a multi-iteration commitment. A maintainer should weigh in on whether the current ad-hoc mechanisms (experimental settings, proposed APIs) are sufficient or whether formalization is warranted given the weekly release cadence. If pursued, starting with the internal feature gate service alone (without the new channel) would be a natural incremental step.
