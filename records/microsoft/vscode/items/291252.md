# Issue #291252 — Cannot enable authentication provider extension in a workspace

[https://github.com/microsoft/vscode/issues/291252](https://github.com/microsoft/vscode/issues/291252)

## Summary

The reporter's specific bug — a non-Settings-Sync auth provider extension (InterSystems Server Manager) being blocked from workspace enablement — was fixed on main by narrowing the restriction to only Settings Sync / default-account auth providers. The fix was authored by the reporter themselves.

## Change summary

Extensions contributing authentication providers could not be enabled or disabled at workspace scope, even when the auth provider was unrelated to Settings Sync.

## Best solution

The shipped fix in commit 72a51117ce2 resolves the reported scenario. The open PR #292340 (copilot-authored, different approach) can be closed as superseded. If the remaining edge case — inability to re-enable a Settings Sync auth provider at workspace scope — is worth tracking, it should be a separate, narrower issue.
