# Issue #305994 — execution_subagent doesn't have skill context

[https://github.com/microsoft/vscode/issues/305994](https://github.com/microsoft/vscode/issues/305994)

## Summary

Still unresolved on main: the execution_subagent tool does not receive or load skill context, so it lacks instructions on how to properly run project-specific CLIs. Team-authored issue with external user confirmation of impact.

## Change summary

The execution_subagent tool spawns a subagent without passing skill/instruction context, causing it to misuse project CLIs.

## Best solution

Pass computed automatic instructions (skills) into the execution subagent's system prompt in `extensions/copilot/src/extension/tools/node/executionSubagentTool.ts` and its prompt builder, so the subagent has the same skill context the outer agent would have. Related discussion in https://github.com/microsoft/vscode/issues/297437 about making subagents custom-agent-based, which would also solve this.
