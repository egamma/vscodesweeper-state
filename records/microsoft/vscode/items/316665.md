## Summary

The defect remains traceable on current main, but an open PR directly fixes both the HTML and native context-menu paths. Keep the issue open while that human-owned fix is reviewed.

## Change summary

Context menus triggered in an unfocused auxiliary or main window are incorrectly displayed over the currently focused window.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/316678, which preserves the originating window through the webview/custom-menu path and supplies the target BrowserWindow for native menus.
