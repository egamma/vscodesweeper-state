## Summary

Valid bug: context menus anchor to the focused window rather than the window where the right-click occurred, affecting multi-window (auxiliary window) scenarios. An open PR (https://github.com/microsoft/vscode/pull/316678) already targets this issue — the fix has not merged yet.

## Change summary

Right-clicking in an unfocused VS Code window opens the context menu over the focused window instead of the window where the click happened.

Review and land https://github.com/microsoft/vscode/pull/316678, which adds window-routing for both HTML and native context menus via a trigger-element helper and a `targetWindowId` IPC option. The area owner for auxiliary windows should evaluate the approach.
