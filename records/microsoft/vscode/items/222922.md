# Issue #222922 — Add `Report Issue...` option to gearwheel menus of extension in Extension view

[https://github.com/microsoft/vscode/issues/222922](https://github.com/microsoft/vscode/issues/222922)

## Summary

Valid feature request — the Extensions view gearwheel menu does not currently include a 'Report Issue' option. The capability exists in the Runtime Extensions editor but has not been surfaced in the Extensions sidebar's manage menu.

## Change summary

Add a 'Report Issue...' option to the gearwheel (manage) menu of extensions in the Extensions sidebar view, so users can report issues for a specific extension without navigating through the Issue Reporter dropdowns.

## Best solution

Register a new menu item in `MenuId.ExtensionContext` (in `src/vs/workbench/contrib/extensions/browser/extensions.contribution.ts`) that opens the issue reporter pre-targeted to the selected extension. The action already exists as `ReportExtensionIssueAction` in `src/vs/workbench/contrib/extensions/common/reportExtensionIssueAction.ts` — it just needs to be wired into the extension context menu, gated on the extension having a repository URL or being built-in.
