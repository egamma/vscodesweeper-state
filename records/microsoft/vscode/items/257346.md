# Issue #257346 — Checkpoint doesn't meet contrast requirements

[https://github.com/microsoft/vscode/issues/257346](https://github.com/microsoft/vscode/issues/257346)

## Summary

The contrast defect remains visible in current source: checkpoint dividers render with a roughly 1.3:1 default-dark contrast ratio, below the WCAG 3:1 requirement for graphical objects. The issue already has the appropriate accessibility and chat-undo routing labels.

## Change summary

Make chat checkpoint separators visually distinguishable from their background at the required contrast ratio.

## Best solution

Ensure checkpoint divider and icon colors meet at least 3:1 contrast in the default light, dark, and high-contrast themes while retaining theme customization and leaving ordinary chat request borders unchanged.
