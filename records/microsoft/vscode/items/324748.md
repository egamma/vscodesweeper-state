# Issue #324748 — `ELECTRON_GET_USE_PROXY` excluded from integrated terminal environments

[https://github.com/microsoft/vscode/issues/324748](https://github.com/microsoft/vscode/issues/324748)

## Summary

Valid bug — the blanket `/^ELECTRON_.+$/` regex in `sanitizeProcessEnvironment` strips `ELECTRON_GET_USE_PROXY`, which is an `electron/get` build-tool variable unrelated to the running Electron instance. An open PR (#324749) already addresses this; keeping open for that PR to land.

## Change summary

The integrated terminal strips `ELECTRON_GET_USE_PROXY` from the environment, breaking proxy-aware Electron downloads run inside VS Code's terminal.

## Best solution

Land the open PR (https://github.com/microsoft/vscode/pull/324749) which excludes `ELECTRON_GET_USE_PROXY` from the `ELECTRON_*` sanitization regex in `src/vs/base/common/processes.ts`. The fix is small and localized.
