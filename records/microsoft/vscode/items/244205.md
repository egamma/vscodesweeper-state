# Issue #244205 — Add workspace and user settings option to disable "Other Recommendations" from being recommended

[https://github.com/microsoft/vscode/issues/244205](https://github.com/microsoft/vscode/issues/244205)

## Summary

A real gap remains on current main: users can suppress all recommendation notifications or manually hide a view, but cannot disable only non-workspace recommendations while preserving workspace recommendations. This accepted Backlog request has 45 upvotes and should remain open.

## Change summary

Add user- and workspace-scoped control that hides Other Recommendations everywhere while preserving workspace recommendation views and prompts.

## Best solution

Provide a scoped extension-recommendation setting that excludes non-workspace recommendations from the Extensions view and recommendation notifications while leaving workspace recommendations unchanged.

- **Behavior:**

  > Users and workspace owners can disable Other Recommendations without disabling workspace recommendations. When enabled, the Other Recommendations section and non-workspace recommendation notifications are absent, while Workspace Recommendations and its install prompt continue to work. User and workspace configuration scopes both honor the setting, and the default behavior remains unchanged.
- **Trace:**

  > The current setting is registered in src/vs/workbench/contrib/extensions/browser/extensions.contribution.ts and is read by ExtensionRecommendationNotificationService.hasToIgnoreRecommendationNotifications; promptRecommendationsNotification applies it before branching on RecommendationSource, making the behavior all-or-nothing. The Extensions view separately registers `workbench.views.extensions.otherRecommendations` and WORKSPACE_RECOMMENDATIONS_VIEW_ID in extensionsViewlet.ts, but neither descriptor is tied to a recommendation-specific configuration key. Existing coverage in extensionRecommendationsService.test.ts confirms that `ignoreRecommendations` suppresses workspace prompts. Preserve that legacy setting's semantics and all default recommendation behavior; the new contract is limited to excluding non-workspace recommendations while retaining workspace recommendations. ## Evidence
