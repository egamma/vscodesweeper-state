# Issue #306702 — Updating extension to newly published version picks the universal VSIX instead of platform one

[https://github.com/microsoft/vscode/issues/306702](https://github.com/microsoft/vscode/issues/306702)

## Summary

Confirmed cross-platform extension-update bug with an open fixing PR. Keep the issue open while https://github.com/microsoft/vscode/pull/338132 is reviewed and either landed or closed.

## Change summary

Updating an extension can install its universal VSIX instead of the available platform-specific package, while reinstalling selects the correct package.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/338132, which resolves gallery results for each installation server's target platform and ensures a platform-package change extracts the correct VSIX rather than only updating metadata.
