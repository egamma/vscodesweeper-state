# Issue #343154 — Temporary virtual text causes line width to enlarge but does not shrinks properly util editor is resized.

[https://github.com/microsoft/vscode/issues/343154](https://github.com/microsoft/vscode/issues/343154)

## Summary

The editor's width cache explains the lingering scrollbar when the document extends beyond the rendered viewport: removing the overflowing decoration does not lower the cached maximum, while resizing resets it. Keep this open as an editor rendering bug; the report supplies actionable reproduction steps.

## Change summary

Recalculate horizontal overflow after temporary Git blame decorations move to a shorter line, without requiring an editor resize.

## Best solution

The wrapped editor should release horizontal space attributable to a removed decoration while retaining space required by remaining content. Address the editor's maximum-width tracking rather than changing Git blame text or hiding horizontal scrolling.
