# Issue #131410 — Allow F12 to be bound to both go to definition and open link

[https://github.com/microsoft/vscode/issues/131410](https://github.com/microsoft/vscode/issues/131410)

## Summary

The requested `linkAtCursor` context key has never been implemented — no such context key exists in current main, and the link contribution registers no keybinding-relevant context keys. The issue is distinct from #81520 (ctrl+click vs. keyboard F12) and remains a valid, unaddressed feature request.

## Change summary

Add a context key (e.g. `linkAtCursor`) so users can bind F12 to open link when no definition provider is available or when the cursor is on a link.

## Best solution

Add a `linkAtCursor` context key in the links contribution (`src/vs/editor/contrib/links/browser/links.ts`) that is set when the cursor position overlaps a detected link, enabling keybinding `when` clauses to distinguish links from definitions. Optionally ship a default keybinding for `editor.action.openLink` scoped to `!editorHasDefinitionProvider`.
