# Issue #131410 — Allow F12 to be bound to both go to definition and open link

[https://github.com/microsoft/vscode/issues/131410](https://github.com/microsoft/vscode/issues/131410)

## Summary

The issue remains a valid editor keybinding request: existing context keys cover Markdown or editors without a definition provider, but not the general case where a link and a definition provider coexist. The suggested duplicate concerns mouse navigation rather than F12 dispatch, so it does not absorb this keyboard-specific gap.

## Change summary

Allow F12 to open a link at the cursor when appropriate while retaining Go to Definition for symbols.

## Best solution

Expose an editor context key representing whether the cursor is currently on an openable link, then use mutually exclusive keybinding conditions so F12 opens that link and otherwise invokes Go to Definition.
