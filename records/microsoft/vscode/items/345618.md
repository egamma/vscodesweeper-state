# Issue #345618 — Disk usage unknown or empty

[https://github.com/microsoft/vscode/issues/345618](https://github.com/microsoft/vscode/issues/345618)

## Summary

Missing sizes are partly intentional, but the presentation does not clearly distinguish deliberately unmeasured worktrees from measurement failures. Keep this open for the cleanup owner to resolve that ambiguity rather than assuming every reported Unknown entry is expected.

## Change summary

Make disk usage available or explain why it is unavailable for entries in Worktree Cleanup.

## Best solution

Make deliberately unmeasured, failed, and removed worktree sizes understandable in the cleanup table. The owner should decide whether done and sessionless worktrees should support size measurement rather than treating all missing values as calculation defects.
