# Issue #338538 — Sticky session item is misaligned in scrolled list

[https://github.com/microsoft/vscode/issues/338538](https://github.com/microsoft/vscode/issues/338538)

## Summary

Team-authored bug report (with screenshot) testing PR #338224's subchat feature in the Agents Window sessions list — the sticky session header shifts left relative to its subchats when sticky-scrolled. This is real and open; author association alone would already bar a judgment close, and I found no cited fix commit referencing this issue, so it stays open.

## Change summary

When a session with subchats becomes 'sticky' at the top of a scrolled sessions list, the sticky header row renders shifted left compared to the subchat rows beneath it.

## Best solution

Needs a visual debugging pass comparing the DOM/CSS of a normal `.session-item` row vs. its cloned `.monaco-tree-sticky-row` counterpart in the sessions list — likely a row-inset (`left`/`right` spacing) or indent-guide computation that isn't mirrored identically for the sticky clone produced by the base tree's StickyScrollWidget (src/vs/base/browser/ui/tree/abstractTree.ts).
