# Issue #324126 — Standard (non-AI) suggestions menu doesn't trigger unless AI completions are snoozed

[https://github.com/microsoft/vscode/issues/324126](https://github.com/microsoft/vscode/issues/324126)

## Summary

Verified duplicate: the open canonical issue tracks this exact intentional interaction between inline completions and automatic IntelliSense suggestions.

## Change summary

Restore automatic display of the standard suggestions menu while Copilot inline suggestions are active.

## Best solution

Consolidate feedback on https://github.com/microsoft/vscode/issues/317863. Users wanting the former behavior can set `editor.quickSuggestions.other` to `on`.
