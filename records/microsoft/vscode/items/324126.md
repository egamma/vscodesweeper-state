# Issue #324126 — Standard (non-AI) suggestions menu doesn't trigger unless AI completions are snoozed

[https://github.com/microsoft/vscode/issues/324126](https://github.com/microsoft/vscode/issues/324126)

## Summary

The missing automatic suggestions while Copilot inline completions are enabled are already covered by an older, verified open issue. Consolidate this report there, preserving its Windows 11 and TypeScript reproduction.

## Change summary

Restore automatic identifier suggestions while Copilot inline completions remain enabled, without requiring snoozing.

## Best solution

Track the completion-coexistence feedback in https://github.com/microsoft/vscode/issues/317863. Users can retain inline completions and restore automatic identifier suggestions by setting editor.quickSuggestions.other to "on".
