# Issue #346044 — Agents window can't use a non-default profile

[https://github.com/microsoft/vscode/issues/346044](https://github.com/microsoft/vscode/issues/346044)

## Summary

Keep open: current source still forces the Agents window onto the internal agents profile with default-profile resources. The linked open PR explains configuration differences but does not provide non-default profile selection or resolve shared-state semantics.

## Change summary

Allow the Agents window to use a non-default profile and define how profile-scoped configuration and state are shared with editor windows.

## Best solution

Define whether the Agents window follows a workspace/editor profile or allows explicit selection, with consistent profile-scoped configuration and state. Review the existing notice PR as a partial improvement, and ensure profile commands do not silently offer unsupported operations.
