# Issue #346044 — Agents window can't use a non-default profile

[https://github.com/microsoft/vscode/issues/346044](https://github.com/microsoft/vscode/issues/346044)

## Summary

Keep open: the Agents window still selects its dedicated profile and inherits Default-profile resources, leaving non-default profiles unsupported. The linked open PR explains some differences but explicitly does not implement profile selection or shared-state semantics.

## Change summary

Allow the Agents window to use a non-default profile and define how profile-scoped state is shared with editor windows.

## Best solution

Resolve whether the Agents window follows an editor profile or supports explicit selection, with consistent resource and storage ownership. Review the linked notice PR as partial mitigation, and address the reported silently ineffective profile commands without treating that as completion of the broader request.
