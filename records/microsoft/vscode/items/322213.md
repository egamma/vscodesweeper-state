## Change summary

Previously open VS Code windows disappear, change monitors, or resize after restarting, with inconsistent results after Reload Window.

## Best solution

Establish a repeatable restart scenario that distinguishes window selection from geometry restoration, then address any confirmed failure in the desktop window-state lifecycle. The existing preserve setting may explain missing windows when launching a workspace explicitly, but does not establish why windows move or resize.
