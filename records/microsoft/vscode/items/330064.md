# Issue #330064 — Enable bypassing SSL validation and signature verification failures in integrated browser

[https://github.com/microsoft/vscode/issues/330064](https://github.com/microsoft/vscode/issues/330064)

## Summary

Real gap in the integrated browser (no handler for Electron's `select-client-certificate` event, so it auto-picks a client cert and there's no path to bypass TLS validation errors), but the request is explicitly about bypassing SSL/certificate validation — a security-sensitive ask that should stay open for a human maintainer's call rather than be triaged toward any close.

## Change summary

Add an opt-in way to bypass SSL validation/signature failures (and skip client-certificate auto-selection) in the integrated browser.

## Best solution

Belongs in src/vs/platform/browserView/electron-main/browserSessionTrust.ts and browserView.ts: today there's a per-host 'trust this certificate' flow for server cert errors, but no handler for Electron's `select-client-certificate` session event, so the client-cert dialog is auto-resolved instead of cancellable. A maintainer should weigh whether to extend the existing trust UI to cover client-cert selection/cancellation, scoped carefully (e.g. not exposed to agents) given the security tradeoffs.
