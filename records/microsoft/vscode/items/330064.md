[https://github.com/microsoft/vscode/issues/330064](https://github.com/microsoft/vscode/issues/330064)

## Summary

Keep open: the reporter clarified that declining client-certificate selection enables navigation in Edge, which is distinct from bypassing server-certificate validation. This security-sensitive request needs human review; the existing certificate exception UI does not establish that the reported workflow is covered.

## Change summary

Allow an integrated-browser user to navigate an enterprise site without presenting a client certificate, or otherwise explicitly handle the reported TLS failure.

## Best solution

Have the browser owner assess user-controlled client-certificate selection, including proceeding without a certificate, against the enterprise scenario. Preserve server-certificate validation defaults and distinguish this authentication choice from the existing server-certificate exception mechanism.
