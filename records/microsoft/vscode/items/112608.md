# Issue #112608 — Git - Allow configuring git to use current VS Code version for editing commits

[https://github.com/microsoft/vscode/issues/112608](https://github.com/microsoft/vscode/issues/112608)

## Summary

The requested integrated-terminal behavior is implemented by git.terminalGitEditor: Git opens commit messages in the running VS Code instance rather than invoking a hardcoded code executable. External terminals retain their separately configured Git editor, providing the requested fallback.

## Change summary

Allow Git commit editing to use the running VS Code version inside its integrated terminal while retaining a configured editor outside VS Code.

## Best solution

Use git.terminalGitEditor with git.useEditorAsCommitInput enabled, and retain core.editor configured to code --wait or code-insiders --wait for external terminals. Close as completed by https://github.com/microsoft/vscode/commit/88731bf6d68b97ee918b6afc13a79eed0d414106.
