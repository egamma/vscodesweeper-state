# Issue #344076 — Support a connection token file when launching with --remote host:port

[https://github.com/microsoft/vscode/issues/344076](https://github.com/microsoft/vscode/issues/344076)

## Summary

Keep open: the desktop direct-remote path still supplies no connection token, so the requested capability remains missing. A maintainer has settled ordinary reconnection semantics as a session snapshot; the remaining credential-lifecycle decisions need human review.

## Change summary

Allow desktop CLI direct remote connections to authenticate using a local token file without exposing or improperly sharing credentials.

## Best solution

Provide a supported desktop token-file input for direct remote connections, preserving existing remote-host confirmation and unauthenticated behavior when the option is absent. Follow the maintainer's snapshot decision and settle restart, restore, window reuse, and credential-sharing semantics in coordination with the reporter's existing prototype.
