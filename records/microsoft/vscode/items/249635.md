# Issue #249635 — TextModel got disposed before DiffEditorWidget model got reset

[https://github.com/microsoft/vscode/issues/249635](https://github.com/microsoft/vscode/issues/249635)

## Summary

The reported search-replace disposal ordering remains in current source: clearing a file match can destroy its preview model before the diff editor detaches. Keep this issue as the search-specific tracking item; the related multidiff fix does not address this path.

## Change summary

Prevent search replace-preview models from being disposed while a diff editor still uses them.

## Best solution

Make the search replace-preview lifecycle honor editor attachment and model ownership, while preserving cleanup when search results disappear. Establish a deterministic regression covering file-match disposal with an open replace preview before changing ownership or teardown behavior.
