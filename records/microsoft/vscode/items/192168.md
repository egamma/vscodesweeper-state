# Issue #192168 — "Preserve case" in search/replace defaults to caps if there is no case

[https://github.com/microsoft/vscode/issues/192168](https://github.com/microsoft/vscode/issues/192168)

## Summary

The defect remains on main: punctuation-only matches are misclassified as uppercase, causing preserve-case replacement text to be capitalized.

## Change summary

Preserve-case replacement should leave the replacement casing unchanged when the matched text has no cased characters.

## Best solution

Update `buildReplaceStringWithCasePreserved` to apply case conversion only when the match contains cased characters, preserving the replacement verbatim for punctuation-only matches.
