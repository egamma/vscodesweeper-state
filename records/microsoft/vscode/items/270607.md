# Issue #270607 — Can't attach an SVG to have the agent edit it

[https://github.com/microsoft/vscode/issues/270607](https://github.com/microsoft/vscode/issues/270607)

## Summary

The bug remains open and confirmed by the discussion: SVG files are rejected as unsupported images instead of being attached as editable text/code. The only directly linked fix PR was closed without merging, and the team-authored issue has no qualifying factual-close evidence.

## Change summary

Allow SVG files dropped into Chat to attach as text/code so an agent can inspect and edit their XML source.

## Best solution

Treat `.svg` attachments as text/code files through Chat's attachment pipeline while retaining the restriction against interpreting SVG content as a model image.
