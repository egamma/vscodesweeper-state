# Issue #270607 — Can't attach an SVG to have the agent edit it

[https://github.com/microsoft/vscode/issues/270607](https://github.com/microsoft/vscode/issues/270607)

## Summary

The bug remains on current main: SVG resources are unconditionally marked fully omitted, producing the reported unsupported-file warning, while drag feedback also classifies `image/svg+xml` as an image. The expected behavior is settled by maintainer comments: attach SVG as editable text/code, not as an image.

## Change summary

Allow SVG files dropped into Chat to be attached and sent as editable text/code instead of appearing as unsupported images.

## Best solution

Treat `.svg` resources as ordinary file attachments and exclude SVG MIME types from Chat's image-drop classification, while leaving raster-image handling unchanged.
