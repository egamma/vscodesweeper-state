# Issue #331863 — Generate Commit Message silently fails until a Copilot Chat request is made in the window

[https://github.com/microsoft/vscode/issues/331863](https://github.com/microsoft/vscode/issues/331863)

## Summary

Real, reproducible bug: on a cold window the endpoint request for the commit message generator gets rejected (a second reporter's logs show a 422 `promptFiltered` response), and the code path silently swallows any non-success `fetchResult` with no user-facing error, so nothing appears to happen — matching both reports exactly.

## Change summary

Generate Commit Message silently produces nothing on a fresh window until a Copilot Chat message has been sent once, after which it works normally.

## Best solution

Two things worth doing: (1) in `GitCommitMessageGenerator.generateGitCommitMessage` (extensions/copilot/src/extension/prompt/node/gitCommitMessageGenerator.ts), surface a notification instead of silently returning `undefined` when `fetchResult.type !== ChatFetchResponseType.Success`; (2) investigate why a cold-window request gets `promptFiltered`/422 before any chat turn has run — likely a session/auth/interaction warm-up gap between `IInteractionService`/`IEndpointProvider` and the first real chat turn — since that's the actual root cause of the failure, not the git code itself.
