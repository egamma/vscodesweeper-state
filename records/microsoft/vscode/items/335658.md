# Issue #335658 — Opening contributed notebook no longer activates its serializer extension

[https://github.com/microsoft/vscode/issues/335658](https://github.com/microsoft/vscode/issues/335658)

## Summary

Real regression from #331911: removing InteractiveDocumentContribution's eager INotebookService dependency means notebookExtensionPoint.ts (and its onNotebookSerializer activation-event generator) is no longer guaranteed to load before the extension-host activation snapshot is built, so contributed notebook serializers aren't activated on file open. A fix PR is already open, so this should stay open for that PR to land rather than be auto-fixed here.

## Change summary

Opening a file for a contributed notebook type (e.g. GitHub Issue Notebooks' *.github-issues) no longer activates the extension's serializer, because the generated onNotebookSerializer:<type> activation event is missing from the extension-host snapshot.

## Best solution

Land (or iterate on) the open fix PR https://github.com/microsoft/vscode/pull/335667, which restores eager registration of notebooksExtensionPoint's activation-event generator independently of NotebookService construction, per the reporter's suggested fix.
