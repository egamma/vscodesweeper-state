# Issue #297342 — completion speculative request never causes an NES speculative request

[https://github.com/microsoft/vscode/issues/297342](https://github.com/microsoft/vscode/issues/297342)

## Summary

Team-authored issue identifying a gap where completion speculative requests don't fall through to NES speculative requests when no suggestion is returned. No fix commit references this issue; keeping open.

## Change summary

When a completion speculative request returns no suggestion, no NES speculative or long-distance NES request is triggered as a fallback.

## Best solution

Modify the speculative request pipeline (likely in extensions/copilot/src/extension/inlineEdits/node/) so that a completion speculative request that yields no suggestion cascades into an NES speculative request, or consolidate all speculative requests to be NES requests as the author suggests.
