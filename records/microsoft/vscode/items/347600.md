# Issue #347600 — Session links get broken if a session is moved into another session or a chat's moved to a new session

[https://github.com/microsoft/vscode/issues/347600](https://github.com/microsoft/vscode/issues/347600)

## Summary

The current source still resolves these links through their original session, although moving a session ends that session and preserves its chat under another owner. Keep this open: the reported steps identify a real gap in link presentation and navigation after moves.

## Change summary

Existing session and chat pills stop resolving their conversations after those conversations move between sessions.

## Best solution

Preserve existing conversation links across ownership changes, with pill presentation and navigation resolving the same conversation in its current session. Cover both moving an independent session under another session and promoting a peer chat into a new session.
