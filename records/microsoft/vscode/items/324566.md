# Issue #324566 — Agents window detail panel: Should changes populate while on new session screen?

[https://github.com/microsoft/vscode/issues/324566](https://github.com/microsoft/vscode/issues/324566)

## Summary

Current main now defines workspace-backed New Session drafts as Files-first while also providing a managed Changes tab. This team-authored design question cannot receive an as-designed close; a maintainer should confirm whether the current behavior resolves the original test feedback.

## Change summary

Clarify whether a workspace-backed New Session should show a Changes surface when the selected repository already has local changes.

## Best solution

Keep the documented Files-first draft experience and its managed Changes tab, then have the Sessions owner clarify whether pre-existing local changes belong only in Files or should populate the session Changes view before submission.
