# Issue #319199 — Chat: add a setting to suppress or delay the sessions list hover preview

[https://github.com/microsoft/vscode/issues/319199](https://github.com/microsoft/vscode/issues/319199)

## Summary

Keep open: current source uses the global hover delays, but neither provides independent control over conversation previews nor exposes the renderer's internal disable option as a user setting. No verified older canonical owns this request.

## Change summary

Allow users to disable Chat session conversation previews or delay them independently of other workbench hovers.

## Best solution

Provide focused control over session conversation previews without changing unrelated tooltips; the Chat area should decide whether suppression, an independent delay, or both is appropriate.
