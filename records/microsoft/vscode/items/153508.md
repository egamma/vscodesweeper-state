# Issue #153508 — Git - SCM foldable regions like "Changes" should have their actions disabled when they do nothing

[https://github.com/microsoft/vscode/issues/153508](https://github.com/microsoft/vscode/issues/153508)

## Summary

The empty-group action enablement defect remains in current main. The previous fix was explicitly reverted because it disabled useful actions elsewhere, and this issue remains the canonical report for the unfinished work.

## Change summary

Disable SCM group actions when they have no applicable changes to operate on.

## Best solution

Make Git resource-group actions reflect whether their operations are applicable, while preserving working commands in the Command Palette and repository menus. Keep the Changes group and its twisty unchanged, consistent with the maintainer's stated direction.
