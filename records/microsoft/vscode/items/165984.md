# Issue #165984 — vscode.dev: webviews key shortcuts doesn't work as expected

[https://github.com/microsoft/vscode/issues/165984](https://github.com/microsoft/vscode/issues/165984)

## Summary

Still a valid issue on current main: when a webview has focus on vscode.dev, browser-reserved shortcuts like Ctrl+F4 are handled by the browser (closing the browser tab) rather than by VS Code's keybinding service. The keyboard event forwarding mechanism exists but certain browser shortcuts are intercepted before the iframe's keydown handler fires.

## Change summary

Keyboard shortcuts like Ctrl+F4 close the browser tab instead of the VS Code editor tab when a webview has focus on vscode.dev.

## Best solution

Investigate whether the webview iframe's keydown listener can call preventDefault() on browser-reserved shortcuts before they bubble to the browser chrome, or whether a keyboard shortcut remapping/warning for web-reserved keys is needed. This is partially a web platform limitation but may be mitigable for specific keys.
