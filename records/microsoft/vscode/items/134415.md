# Issue #134415 — Add `!`-prefix parsing to glob util

[https://github.com/microsoft/vscode/issues/134415](https://github.com/microsoft/vscode/issues/134415)

## Summary

Still unimplemented on main — the first-stab commit (efa5122689e) and PR #152225 were never merged, and glob.ts currently has no `!`-prefix negate support beyond `[!...]` character-range negation. The detailed team discussion (bpasero, roblourens, JacksonKearl) shows this is a real, thought-through proposal with open design questions around expression semantics. Keeping open as a valid feature request with meaningful technical groundwork.

## Change summary

Add `!`-prefix parsing to VS Code's glob utility so negated patterns can be used in `files.exclude` and `search.exclude` to re-include files matched by other exclude patterns.

## Best solution

Land the `!`-prefix negate support in `src/vs/base/common/glob.ts` using the two-pass approach discussed in the thread (positive patterns first, then negated patterns override). This would unblock the long-standing ask in https://github.com/microsoft/vscode/issues/869. The design questions around expression semantics (ordering, multi-pattern interaction) need a final decision from the area owner before implementation.
