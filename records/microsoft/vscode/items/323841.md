# Issue #323841 — In Paste Confirmation Dialog: "Cancel" Still Pastes, and "Paste" Pastes Twice

[https://github.com/microsoft/vscode/issues/323841](https://github.com/microsoft/vscode/issues/323841)

## Summary

The file-paste regression was fixed by reverting native clipboard integration that let one paste reach both the immediate and confirmation-controlled paths. Current source retains that fix and also restores external file pasting after a separate follow-up regression.

## Change summary

Canceling paste must insert nothing, and confirming paste must insert the copied content exactly once.

## Best solution

Close as completed by commit 26d36469b04868c3fc89d4bc3529808b9386b97f. Retain the subsequent external-file paste restoration rather than the earlier temporary guard.
