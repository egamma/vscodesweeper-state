## Summary

Valid team-authored feature request for surfacing extension provenance in the AI customizations editor and enabling per-extension disable. Partial infrastructure exists (extensionId tracking, extension group, 'from extension' labels) but the full UX as described — quickly identifying and turning off extension-contributed customizations — appears to still be in progress.

## Change summary

Show which customizations are extension-contributed and allow quickly disabling them per-extension.

## Best solution

Complete the UX in the AI customizations editor to clearly badge extension-contributed items with the contributing extension name and provide a one-click action to disable that extension's customizations. The infrastructure in `aiCustomizationItemSource.ts` and `aiCustomizationListWidget.ts` already tracks `extensionId`; the remaining work is surfacing it prominently and wiring a disable action.
