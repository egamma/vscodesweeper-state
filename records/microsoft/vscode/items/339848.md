# Issue #339848 — I miss the Plan and Ask mode selection

[https://github.com/microsoft/vscode/issues/339848](https://github.com/microsoft/vscode/issues/339848)

## Summary

Genuine feedback on an active rollout (the new Copilot/Agent-host harness becoming default, hiding the Ask/Plan mode picker that lives in the Local harness) — not a bug, and already the subject of a maintainer-run feedback thread, so this stays open as community discussion rather than being closed.

## Change summary

Reporter was switched into a new Copilot chat interface that dropped the Ask/Plan mode selector they relied on.

## Best solution

No close is warranted yet; the existing `chat.defaultToCopilotHarness`/`chat.editor.preferCopilotHarness` settings already let users opt back into the Local harness and its mode picker — surfacing that in a comment, and letting the team's existing meta-feedback thread (#339363) absorb the broader direction discussion, is the right near-term outcome.
