# Issue #344926 — Copilot harness: restore access to VS Code-aware explicit context items

[https://github.com/microsoft/vscode/issues/344926](https://github.com/microsoft/vscode/issues/344926)

## Summary

The requested explicit-context parity remains missing on current main: the Copilot harness does not advertise support for Source Control, Symbols, Problems, or Tools attachments. Related tool-picker requests cover only part of this issue, so retain it for the broader context-attachment work.

## Change summary

Restore Source Control, Symbols, Problems, and Tools as explicit context choices in the Copilot harness chat input.

## Best solution

Provide these explicit-context choices with end-to-end delivery of the selected context to Copilot, rather than only exposing additional picker entries. Coordinate tool selection and referencing with https://github.com/microsoft/vscode/issues/340041 while retaining the distinct diagnostics, symbols, and source-control requirements here.
