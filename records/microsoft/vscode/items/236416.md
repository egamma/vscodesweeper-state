# Issue #236416 — Jupyter notebook cell menu incorrect for new cells

[https://github.com/microsoft/vscode/issues/236416](https://github.com/microsoft/vscode/issues/236416)

## Summary

Still present on main: the cell toolbar shows stale actions for newly created cells because of a timing issue in how cell context keys and the overlay toolbar's menu change listener interact during the cell parts rendering lifecycle.

## Change summary

Notebook cell toolbar shows incorrect menu items (from the previous cell type) when a new cell is created; switching focus away and back forces the correct update.

## Best solution

Fix the timing between context key updates and toolbar action computation in `CellTitleToolbarPart`. The toolbar's `setupChangeListeners` handler captures actions computed before `CellContextKeyPart.didRenderCell` has set the new cell type. The deferred overlay rendering (`DOM.modify`) means context key changes fired synchronously during content part rendering may not propagate correctly to the toolbar's initial render or on insert. A targeted fix in `didRenderCell` that explicitly re-reads the menu actions after the toolbar view is set up (not relying solely on the initial `initActions`) would close the gap.
