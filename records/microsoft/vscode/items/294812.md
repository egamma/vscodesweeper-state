## Summary

Keep open and classify as a bug: Windows path normalization changes the slash in the search query, but workspace symbol names retain their literal slashes, causing matching results to be discarded. The newer related report cannot replace this re-reviewed issue.

## Change summary

Searching workspace symbols with '/', '/public', or 'public/sync' hides matching Spring endpoint symbols on Windows.

## Best solution

Workspace symbol filtering should match literal slashes in symbol names consistently across operating systems, while preserving file-search path normalization and existing symbol/container filtering semantics.
