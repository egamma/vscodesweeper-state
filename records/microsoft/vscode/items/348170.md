# Issue #348170 — Terminal of Agent is not avaialble anymore

[https://github.com/microsoft/vscode/issues/348170](https://github.com/microsoft/vscode/issues/348170)

## Summary

Keep open for terminal ownership review: the default Copilot shell path exposes output without an interactive terminal. An experimental terminal override offers a possible macOS workaround, but does not establish that the full shared-shell workflow is restored.

## Change summary

Restore user access to agent shells for interruption, live output, interactive authentication, and commands sharing the agent's environment.

## Best solution

Provide a discoverable way to inspect and intervene in agent-owned shell execution, with explicit guarantees about shared working-directory and environment state. Evaluate the existing PTY override against the reported workflows before deciding how the default runtime shell should reach parity.
