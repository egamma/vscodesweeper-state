# Issue #204488 — Zen mode no longer loads  nicely.

[https://github.com/microsoft/vscode/issues/204488](https://github.com/microsoft/vscode/issues/204488)

## Summary

Keep open for the layout-motion decision raised by the maintainer. Current Zen Mode settings do not provide the requested smooth layout transition, and neither a verified canonical nor a concrete fixing commit was found.

## Change summary

Make entering Zen Mode feel like a smooth transition rather than an abrupt layout switch.

## Best solution

Decide whether Zen Mode should use a short, functional transition consistent with other workbench layout changes, distinguishing workbench motion from native fullscreen animation. Any approved motion should respect reduced-motion preferences and preserve existing layout restoration and focus behavior.
