# Issue #336318 — Allow reordering queued chat requests

[https://github.com/microsoft/vscode/issues/336318](https://github.com/microsoft/vscode/issues/336318)

## Summary

Queued chat requests can already be reordered by dragging their gripper handle, so the central request is covered by the current product behavior.

## Change summary

Allow users to reorder queued chat requests through move actions or drag and drop.

## Best solution

Keep the existing drag-and-drop behavior: when at least two queued requests of the same kind exist, hovering a request exposes a gripper that can move it within that queue.

- **Reason:** Reordering queued prompts improves control over AI-assisted workflows without adding persistent UI.
