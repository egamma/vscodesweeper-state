# Issue #317807 — Copilot sessions missing

[https://github.com/microsoft/vscode/issues/317807](https://github.com/microsoft/vscode/issues/317807)

## Summary

Keep open: commenters independently confirm inaccessible sessions, including a repeatable Remote-SSH restart case with history still present on disk. Session discovery has changed since the report, but the discussion supplies enough steps to retest; neither a complete fix nor a canonical covering all reported cases was established.

## Change summary

Previously available Copilot conversations disappear from the session list after reopening VS Code or switching sessions.

## Best solution

Make persisted Copilot conversations reliably discoverable after restart and refresh, while preserving history when discovery fails. Diagnose the restart and refresh-recoverable cases separately before deciding whether they need one fix or separate tracking.
