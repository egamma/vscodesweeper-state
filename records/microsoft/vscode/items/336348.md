# Issue #336348 — Agent Host chat stays active after response completes while an attached async shell is running

[https://github.com/microsoft/vscode/issues/336348](https://github.com/microsoft/vscode/issues/336348)

## Summary

Confirmed Agent Host lifecycle bug: VS Code waits for whole-session idle to complete a foreground turn, so an attached asynchronous shell leaves completed responses active. Current main still contains the reported event-handling gap.

## Change summary

Complete Copilot Agent Host foreground turns after the root assistant becomes idle without waiting for attached asynchronous shell activity to stop.

## Best solution

Separate foreground turn completion from whole-session idle handling in the Copilot Agent Host adapter. Preserve cancellation, pending tool-result draining, stale-event protection, subagent isolation, and background-task lifetime while allowing each foreground response to complete exactly once.
