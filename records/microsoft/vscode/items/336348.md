# Issue #336348 — Agent Host chat stays active after response completes while an attached async shell is running

[https://github.com/microsoft/vscode/issues/336348](https://github.com/microsoft/vscode/issues/336348)

## Summary

Well-documented, freshly filed bug with a working standalone reproduction script and precise code citations — I confirmed on current main that CopilotSessionWrapper subscribes only to `session.idle` (never `assistant.idle`) and CopilotAgentSession's onIdle handler completes the foreground chat turn from that same event, so an attached async shell (which defers `session.idle`) does exactly what the report describes.

## Change summary

The Agent Host chat turn keeps spinning after the model's answer finishes whenever an attached (non-detached) async shell command from the built-in bash tool is still running, because turn completion is driven by whole-session idle rather than foreground idle.

## Best solution

Add a typed `assistant.idle` subscription in CopilotSessionWrapper and refactor CopilotAgentSession's idle handler (around the `wrapper.onIdle` registration near line 5652) to complete the foreground turn on `assistant.idle` while still using `session.idle` for whole-session cleanup, carefully preserving the existing abort/cancellation and pending-tool-completion guards already in that handler.
