# Issue #100717 — View undo/redo history visually or an indicator or a counter

[https://github.com/microsoft/vscode/issues/100717](https://github.com/microsoft/vscode/issues/100717)

## Summary

Keep this accepted Backlog request open: it has 79 community upvotes, and current VS Code still exposes no visual undo/redo history or compact state indicator. Related open issues cover narrower menu behavior rather than the full request.

## Change summary

Expose an editor's undo/redo state through a visual history, counter, or compact availability indicator.

## Best solution

Design a compact editor or workbench affordance backed by the existing `canUndo`/`canRedo` state, optionally exposing labeled stack entries from the undo/redo service. The Timeline should remain separate because it displays saved local-history entries, not the active undo/redo stack.

- **Fit:** aligned
- **Reason:** A clear undo/redo-state affordance improves a core editing workflow and helps prevent accidental loss of redo state.
- **Evidence:** Durable themes: Workbench & core UX and the developer inner loop; the public values also favor simple, uniform UI interactions.
