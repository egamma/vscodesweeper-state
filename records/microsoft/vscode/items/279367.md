[https://github.com/microsoft/vscode/issues/279367](https://github.com/microsoft/vscode/issues/279367)

## Summary

Current prompt invocation already preserves trailing arguments as natural-language input and `argument-hint` provides invocation guidance, but this member-authored feature request cannot receive a judgment-based *as-designed close. It should remain open until the author or owning team explicitly closes or reframes it.

## Change summary

Add deterministic positional substitution such as `$1`, `$2`, and `$3` to custom prompt files invoked with arguments.

## Best solution

Keep the existing free-form argument flow unless the chat-customizations owners decide deterministic positional substitution is needed; that product decision should explicitly distinguish structured replacement from the current model-interpreted arguments.
