# Issue #280363 — Terminal Intellisense breaks with PowerShell when using Starship

[https://github.com/microsoft/vscode/issues/280363](https://github.com/microsoft/vscode/issues/280363)

## Summary

Confirmed bug: terminal suggest/intellisense breaks when Starship uses a custom prompt character (e.g. Powerline U+E0B0) instead of the default ❯ (U+276F). The prompt detection in commandDetectionCapability.ts only matches U+276F for custom prompts, and the dynamic promptTerminator fallback doesn't reliably catch non-standard characters on Windows PowerShell. The issue is still present on main.

## Change summary

Terminal Intellisense fails to detect the prompt and provide suggestions when Starship is configured with a custom prompt character (Powerline/Nerd Font glyph) instead of the default ❯ character, specifically on Windows PowerShell.

## Best solution

Broaden prompt detection in `commandDetectionCapability.ts` (around line 970) to handle additional common prompt terminator characters beyond U+276F, or improve the dynamic `promptTerminator` detection path so it reliably captures custom Starship characters on Windows PowerShell. The reporter narrowed the root cause to the `[character]` section in their Starship config, and meganrogge's comment 6 points directly to the relevant code.
