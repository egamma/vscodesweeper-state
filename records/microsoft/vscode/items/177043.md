# Issue #177043 — Right click Copy/Paste doesn't work for a text given inside a vscode text field in a webview.

[https://github.com/microsoft/vscode/issues/177043](https://github.com/microsoft/vscode/issues/177043)

## Summary

The report is from VS Code 1.69.2 (over 3 years old) with no confirmation on a recent build. One commenter corroborated the issue but also in 2023. Given the age of the report and the many webview changes since then, the reporter should confirm on a current build before this stays actionable.

## Change summary

Right-clicking text inside a webview text field deselects the text, preventing copy via the context menu.

## Best solution

Request the reporter to reproduce on the latest VS Code version. The webview contextmenu handler in `src/vs/workbench/contrib/webview/browser/pre/index.html` calls `e.preventDefault()` and forwards to VS Code's context menu — if the selection-loss still occurs, the fix likely involves preserving the webview iframe's text selection when the host context menu gains focus.
