# Issue #297962 — Provide a way for custom test sessions to be re-run with commands like "Rerun last session"

[https://github.com/microsoft/vscode/issues/297962](https://github.com/microsoft/vscode/issues/297962)

## Summary

Valid, unaddressed feature request: the testing API still has no mechanism for extensions to attach replayable metadata to test runs created outside the normal run-handler flow. No proposed or stable API covers this on current main.

## Change summary

Allow extensions to attach custom serializable metadata to a TestRun so that "Rerun last session" can reproduce runs initiated outside the standard test runner (e.g. custom launch configurations).

## Best solution

Add a serializable metadata/context field to `TestRunRequest` (or `createTestRun`) that is stored with the result and fed back to the extension's run handler on rerun. The design discussion in https://github.com/microsoft/vscode/issues/144169#issuecomment-1071143185 between the reporter and Connor Peet is the starting point — profiles were suggested but don't cover the dynamic, user-configured launch.json scenarios described.
