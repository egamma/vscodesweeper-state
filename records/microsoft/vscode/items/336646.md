# Issue #336646 — Split installed MCP servers into user and workspace sections

[https://github.com/microsoft/vscode/issues/336646](https://github.com/microsoft/vscode/issues/336646)

## Summary

Real, well-scoped UI consistency request: the MCP list still shows one generic 'Installed' section (mcpListWidget.ts) while sibling customization pages (instructions/prompts) already split into User/Workspace groups — a maintainer flagged internal context for it, so this stays open for implementation.

## Change summary

Split the MCP 'Installed' section in the Chat Customizations editor into separate User and Workspace groups, using the scope info already surfaced in the server hover.

## Best solution

Extend McpServerListWidget's section rendering (renderCardSection/createMcpSectionList) to group installedEntries by scope (user vs workspace) the same way aiCustomizationListWidget.ts groups prompts/instructions by PromptsStorage.local/user, with a clear fallback bucket for builtin/session servers that have no file-backed scope.
