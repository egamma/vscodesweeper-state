# Issue #295292 — Model toggles are missing from Github Copilot Features

[https://github.com/microsoft/vscode/issues/295292](https://github.com/microsoft/vscode/issues/295292)

## Summary

The missing toggles are an intentional account-side change, not a VS Code defect: individual users now have all eligible models enabled by default. A model missing from a third-party client cannot be restored through a VS Code setting, so the account-enablement question has been answered.

## Change summary

Restore per-model Copilot feature toggles so a Copilot Pro user can expose GPT-5.3 Codex to third-party clients.

## Best solution

Keep the simplified model-enablement behavior and have third-party clients consume the models available to the account without relying on the retired toggles.
