# Issue #166615 — SCM - Create an event for when the value of a SourceControlInputBox changes

[https://github.com/microsoft/vscode/issues/166615](https://github.com/microsoft/vscode/issues/166615)

## Summary

Keep open as API proposal tracking: current source provides the document-based alternative behind scmTextDocument, but it has not been finalized into the stable API. The api-proposal protection applies even though the proposed capability addresses the requested scenario.

## Change summary

Let SCM extensions observe commit-input changes without polling, so they can update actions such as Create Commit versus Amend.

## Best solution

Have the SCM/API owners evaluate and finalize the document-based change-observation contract already provided by scmTextDocument, or explicitly decide its future. Preserve this issue as the proposal tracker until that decision is complete.
