# Issue #350488 — Add Search Editor to chat

[https://github.com/microsoft/vscode/issues/350488](https://github.com/microsoft/vscode/issues/350488)

## Summary

The existing chat actions do not cover attaching an unsaved Search Editor from its tab or choosing query-only versus query-and-results context. Keep this request open for consideration; no matching canonical was found.

## Change summary

Allow attaching a Search Editor to Copilot chat from its tab, with control over including the query and search results.

## Best solution

Integrate Search Editor context with the existing chat attachment actions, defining what query-only and query-plus-results attachments contain. Preserve existing file attachments and Search view behavior.
