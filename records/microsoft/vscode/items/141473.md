# Issue #141473 — Auto save behaviour might be unexpected here

[https://github.com/microsoft/vscode/issues/141473](https://github.com/microsoft/vscode/issues/141473)

## Summary

Team-authored polish request that remains valid: the debug memory editor does not call `disableAutoSave`, even though the per-editor API now exists and is used elsewhere (e.g. chat editing). Keeping open for maintainer judgment.

## Change summary

Auto-save should be disabled when editing memory during a debug session, since saving memory edits on a timer is unexpected.

## Best solution

Call `IFilesConfigurationService.disableAutoSave()` on the debug memory editor input in `src/vs/workbench/contrib/debug/browser/debugMemory.ts`, following the same pattern used by `chatEditingModifiedFileEntry.ts`. This is a small, localized change.
