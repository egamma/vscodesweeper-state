# Issue #141473 — Auto save behaviour might be unexpected here

[https://github.com/microsoft/vscode/issues/141473](https://github.com/microsoft/vscode/issues/141473)

## Summary

Keep open: per-resource autosave suppression now exists, but its availability does not establish that debugger memory editors use it. This team-authored, accepted request still needs a decision about how memory editing should differ from ordinary file editing.

## Change summary

Avoid unexpected automatic writes to debuggee memory when autosave is enabled for ordinary files.

## Best solution

Define intentional save behavior for debugger memory editors, using the existing per-resource autosave controls where appropriate while preserving ordinary-file autosave. Confirm the Hex Editor's save behavior before deciding whether any remaining work belongs in the debugger integration or the team-owned Hex Editor tracker.
