# Issue #340338 — Support Sign in with Chat GPT in Remote Agent Host

[https://github.com/microsoft/vscode/issues/340338](https://github.com/microsoft/vscode/issues/340338)

## Summary

Keep open: current ChatGPT sign-in targets the ambient Agent Host, not an independently selected remote host. The related BYOK tracking issue explicitly lists this request as unfinished work; it is not a duplicate canonical.

## Change summary

Allow users to authenticate Codex with ChatGPT on a remote Agent Host through the VS Code UI.

## Best solution

Provide host-targeted ChatGPT sign-in that completes authentication on the selected remote Agent Host and updates that host's account and model availability. Preserve existing local sign-in and avoid treating local authentication as proof that another host is authenticated.
