# Issue #286455 — documentSelector `json` for LSP-Connection will spam `textDocument/didOpen|didClose` request for all `package.json`

[https://github.com/microsoft/vscode/issues/286455](https://github.com/microsoft/vscode/issues/286455)

## Summary

The reported notification spam remains source-reproducible: npm task discovery still opens each discovered package.json as a text document. Both proposed fixes were closed without merging, so the issue remains necessary.

## Change summary

Prevent background npm task discovery from generating JSON document-open and document-close notifications for package.json files the user has not opened.

## Best solution

Make npm task discovery read unopened package.json files without creating editor document models, while preserving script discovery, source locations, and existing handling of already-open documents. Treat changes to debug's eager task enumeration as separate follow-up work rather than a prerequisite for fixing this notification spam.
