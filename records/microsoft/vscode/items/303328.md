# Issue #303328 — Allow un-rounding certain UI elements

[https://github.com/microsoft/vscode/issues/303328](https://github.com/microsoft/vscode/issues/303328)

## Summary

Keep open for a design decision: current settings do not provide selective square corners, and the discussion also reports notebook corner artifacts. Earlier maintainer reasoning rejects low-level radius settings, but does not resolve the rendering concerns raised here.

## Change summary

Provide a setting to remove rounding from selected UI elements, including notebook cell highlights.

## Best solution

Have the workbench design owner distinguish the customization request from the notebook rendering defects, then decide whether radius customization belongs in a shared theme mechanism. Correct mismatched notebook outlines independently of whether a square-corner preference is accepted.
