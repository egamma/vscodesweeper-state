# Issue #303328 — Allow un-rounding certain UI elements

[https://github.com/microsoft/vscode/issues/303328](https://github.com/microsoft/vscode/issues/303328)

## Summary

Valid feature request for a user-facing setting to disable or zero-out the workbench's corner-radius design tokens. No such setting exists on current main — the corner-radius tokens in baseSizes.ts are internal with no configuration surface. Low upvote count (2) means it has not yet reached the community threshold, but it stays open for the community process.

## Change summary

Add a user setting to disable or reduce border-radius rounding on workbench UI elements.

## Best solution

Either expose a global setting (e.g. `workbench.cornerRadius`) that zeroes all corner-radius design tokens, or document how theme extensions can override the `--vscode-cornerRadius-*` CSS variables. The design-token infrastructure in `src/vs/platform/theme/common/sizes/baseSizes.ts` already centralizes the values — a configuration surface that sets them all to 0 would be straightforward. However, this cuts against VS Code's value of simple/uniform UI, so it may belong in a theme extension rather than core.
