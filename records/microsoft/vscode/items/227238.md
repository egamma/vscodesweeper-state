# Issue #227238 — Zoom : The left commonly used section tree view content gets disappear when viewing the page at 200% browser zoom and a 1280-pixel viewport width. 

[https://github.com/microsoft/vscode/issues/227238](https://github.com/microsoft/vscode/issues/227238)

## Summary

Still reproduces on main: the Settings editor intentionally hides the TOC tree (via `display: none` on `.narrow-width .settings-toc-container`) when the editor width falls below 700px. At 200% zoom with a 1280px viewport the effective width triggers this, removing navigation for low-vision users. No fix has landed.

## Change summary

The Settings editor's left TOC/commonly-used tree disappears at 200% browser zoom with a 1280px viewport because the responsive narrow-width threshold hides it entirely.

## Best solution

Provide an alternative navigation mechanism (e.g. a collapsible dropdown or a keyboard-accessible 'jump to section' command) when the TOC is hidden due to narrow width, so low-vision users at high zoom still have access to category navigation. The fix lives in `src/vs/workbench/contrib/preferences/browser/settingsEditor2.ts` (layout logic around `NARROW_TOTAL_WIDTH`) and the accompanying CSS.
