# Issue #291933 — Default Trusted folders on various platforms

[https://github.com/microsoft/vscode/issues/291933](https://github.com/microsoft/vscode/issues/291933)

## Summary

Current main does not provide default platform-specific trusted folders, so the requested capability remains unimplemented. The request is already accepted into the Backlog and correctly routed to workspace trust, but automatically trusting an entire home directory has substantial security implications that require an explicit product decision.

## Change summary

Automatically trust common user and web-development folders on Windows and Linux.

## Best solution

Keep trusted roots explicit and user-controlled unless workspace-trust owners define narrowly scoped, security-preserving platform defaults or an opt-in onboarding mechanism. Any design must avoid implicitly trusting downloaded repositories and other unreviewed content under the user's home directory.
