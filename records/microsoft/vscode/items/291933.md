# Issue #291933 — Default Trusted folders on various platforms

[https://github.com/microsoft/vscode/issues/291933](https://github.com/microsoft/vscode/issues/291933)

## Summary

Valid feature request for platform-specific default trusted folders. No existing mechanism for this in current main — users must manually trust each folder. Low community signal (0 upvotes) and in Backlog; keeping open for the community process.

## Change summary

Automatically trust platform-specific default folders (e.g., user home directory) without requiring manual trust actions.

## Best solution

This could be considered as a configurable default in `src/vs/workbench/services/workspaces/common/workspaceTrust.ts`, but auto-trusting broad directories like the entire home folder would weaken the security model workspace trust provides. The team should weigh whether convenience here undermines the feature's purpose. If implemented, it would need careful scoping — perhaps only for enterprise/policy-driven scenarios.
