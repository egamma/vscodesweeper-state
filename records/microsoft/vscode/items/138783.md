# Issue #138783 — "Go to Definition" from hover popup

[https://github.com/microsoft/vscode/issues/138783](https://github.com/microsoft/vscode/issues/138783)

## Summary

Keep open: TypeScript hover signatures still render inferred types as code-block text, without navigation targets. The request has 60 upvotes, is accepted into Backlog, and no verified older canonical owns the same hover interaction.

## Change summary

Make type names displayed in symbol hovers clickable so users can navigate to their definitions without holding modifier keys.

## Best solution

Provide semantically resolved navigation for named types in hover signatures while preserving syntax highlighting and ordinary hover behavior. Plan the language-provider and renderer contract first; editor-position navigation and documentation links do not cover this interaction.

- **Behavior:**

  > Users can navigate from a named type displayed in a symbol hover to that type's declaration, including when its name is absent from the hovered source expression. Existing signature readability, syntax highlighting, and documentation links remain intact.
