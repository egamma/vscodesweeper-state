# Issue #138783 — "Go to Definition" from hover popup

[https://github.com/microsoft/vscode/issues/138783](https://github.com/microsoft/vscode/issues/138783)

## Summary

The requested navigation remains absent on current main, and this is the canonical backlog request with 60 community upvotes. Keep it open for an API and hover-rendering design.

## Change summary

Make type symbols displayed in editor hover popups clickable for Go to Definition navigation.

## Best solution

Provide structured, navigable symbol spans in hover results and render them as accessible definition links in the editor hover. Avoid language-specific parsing of presentation strings such as TypeScript's `displayString`.
