# Issue #162336 — Terminal hover positioning is unfriendly

[https://github.com/microsoft/vscode/issues/162336](https://github.com/microsoft/vscode/issues/162336)

## Summary

Still valid: the terminal link hover positions at the start of the link range rather than near the mouse cursor. The editor-side fix (PR #163970) landed but the terminal's CellHoverTarget was never updated to account for mouse position. Confirmed reproducible on current main.

## Change summary

Terminal link hover should appear near the mouse x-coordinate instead of left-aligning to the start of the link range.

## Best solution

Update `CellHoverTarget` in `src/vs/workbench/contrib/terminal/browser/widgets/terminalHoverWidget.ts` (and the `ILinkHoverTargetOptions` interface) to accept and use the mouse x-coordinate when positioning the hover, similar to how the editor hover was improved in PR #163970. The hover service's `showInstantHover` call could use a position hint or the target elements could be narrowed to the hovered region.
