# Issue #306227 — Copilot Agent Skill Validation Conflicts with "skill" Language ID (Cadence SKILL Programming Language)

[https://github.com/microsoft/vscode/issues/306227](https://github.com/microsoft/vscode/issues/306227)

## Summary

Still reproduces on main: the prompt validator in promptFileContributions.ts triggers on any editor model with language ID 'skill', not just SKILL.md files, causing false diagnostics for users of the Cadence SKILL programming language extension.

## Change summary

Opening .il files with the Cadence SKILL extension produces false 'Skill should provide a name' diagnostics because the Copilot prompt validator claims the generic 'skill' language ID.

## Best solution

Either rename the internal prompt language ID from 'skill' to something unambiguous (e.g. 'copilot-skill'), or add a file-path/filename guard in PromptValidatorContribution.acquire() so that only files named SKILL.md (or inside .github/skills/) get the skill validation. The fix is localized to promptFileContributions.ts and promptTypes.ts.
