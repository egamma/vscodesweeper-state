# Issue #316821 — Long-running "Run Playwright Code" should show the code it's running

[https://github.com/microsoft/vscode/issues/316821](https://github.com/microsoft/vscode/issues/316821)

## Summary

Keep open: current source exposes the Playwright snippet during approval and in returned results, but not while the initial invocation is running. No verified canonical or fixing commit was found; this team-authored request still identifies a distinct visibility gap.

## Change summary

Allow users to inspect the executing Playwright snippet from its in-progress chat tool invocation.

## Best solution

Provide on-demand code disclosure on the running Playwright tool row, consistent with existing expandable tool-input presentation, without requiring execution to finish or an approval prompt to remain visible.
