# Issue #316821 — Long-running "Run Playwright Code" should show the code it's running

[https://github.com/microsoft/vscode/issues/316821](https://github.com/microsoft/vscode/issues/316821)

## Summary

Valid feature request from a team member. The invocation message in runPlaywrightCodeTool.ts is a static 'Running Playwright code...' string with no visibility into the actual code being executed; the request for showing the running code is not yet implemented on main.

## Change summary

The 'Running Playwright code' progress indicator should show or link to the actual code snippet being executed so users can understand long-running executions.

## Best solution

Update `prepareToolInvocation` in `src/vs/workbench/contrib/browserView/electron-browser/tools/runPlaywrightCodeTool.ts` to include the code snippet in the `invocationMessage` (e.g. as a collapsible markdown code block), similar to how the confirmation dialog already renders it on line 77. This would let users inspect what's running without needing to scroll back to the confirmation.
