# Issue #233341 — Debt: Cleanup Tree Find (`FindController`, `FindFilter` and toggles)

[https://github.com/microsoft/vscode/issues/233341](https://github.com/microsoft/vscode/issues/233341)

## Summary

The team-authored cleanup remains necessary on current main: `AsyncFindController` still extends `FindController`, duplicates toggle synchronization, and carries the TODO described by the issue. The work is bounded internal debt and should remain open.

## Change summary

Decouple asynchronous tree find from the concrete synchronous find controller and consolidate filter-toggle state handling.

## Best solution

Give synchronous and asynchronous tree find a shared controller-level contract for mode, match type, toggle state, and filter synchronization while preserving their distinct pattern-application behavior and existing public tree APIs.
