# Issue #334228 — Make chat sessions available across workspaces (global chat history)

[https://github.com/microsoft/vscode/issues/334228](https://github.com/microsoft/vscode/issues/334228)

## Summary

Brand-new (same-day), well-researched feature request asking to make chat sessions global-per-profile instead of workspace-scoped; the checkout confirms the current workspace-scoped storage model the reporter describes, but no maintainer decision or canonical issue exists yet, so this belongs with the chat area team for a scope call rather than any close.

## Change summary

Store Copilot Chat sessions per-profile (globally) with workspace as metadata, instead of binding them to a single workspace storage folder, so sessions survive workspace-identity changes and are reachable across windows.

## Best solution

Route to the Chat area owners to weigh a design change in src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts (currently keyed by workspaceStorageHome/<workspaceId> with StorageScope.WORKSPACE for the index) toward a profile-scoped store with per-session workspace metadata and a picker filter, echoing the Agents window's cross-window session model; the related data-loss issue on untitled-workspace saves may be folded into the same investigation.
