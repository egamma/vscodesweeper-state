# Issue #334228 — Make chat sessions available across workspaces (global chat history)

[https://github.com/microsoft/vscode/issues/334228](https://github.com/microsoft/vscode/issues/334228)

## Summary

Well-documented feature request describing a real architectural gap (chat sessions are workspace-scoped, with a genuine data-loss risk for untitled multi-root workspaces), but it's brand new (1 day old, 0 upvotes) and only carries `triage-needed` — routing to the chat area rather than closing or leaving unlabeled.

## Change summary

Store chat sessions globally (per profile) instead of per-workspace, with a cross-workspace filter in the history picker and no purge of pinned/all chats when an untitled workspace's storage folder becomes obsolete.

## Best solution

Chat/session-storage team should weigh in: the workspace-scoped storage model (chatSessions/*.jsonl + chat.ChatSessionStore.index per workspaceStorage hash, see src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts) is confirmed on main, so this is a real product-direction question, not a bug — likely worth splitting into (a) the more urgent data-loss-on-obsolete-untitled-workspace bug and (b) the broader cross-workspace visibility feature.
