# Issue #118230 — Add "Copy Value" to the context menu in the Debug Console.

[https://github.com/microsoft/vscode/issues/118230](https://github.com/microsoft/vscode/issues/118230)

## Summary

Consolidate this request into the older, open issue about copying untruncated Debug Console values. That issue explicitly includes complex objects and documents the same truncated-copy symptom, meeting the stronger duplicate bar for this re-reviewed item.

## Change summary

Add a Debug Console context-menu action that copies the complete underlying logged object rather than its truncated display text.

## Best solution

Track complete-value copying in https://github.com/microsoft/vscode/issues/94937, preserving this report's requirement to copy console.log and logpoint objects without needing an in-scope expression at a breakpoint. Existing expression-copy support does not satisfy that requirement.
