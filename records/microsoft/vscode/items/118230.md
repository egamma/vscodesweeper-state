# Issue #118230 — Add "Copy Value" to the context menu in the Debug Console.

[https://github.com/microsoft/vscode/issues/118230](https://github.com/microsoft/vscode/issues/118230)

## Summary

Still a valid gap: "Copy Value" exists in Variables, Watch, and Hover context menus but is not registered for the Debug Console context menu. The feature remains unimplemented on current main.

## Change summary

Add a "Copy Value" option to the Debug Console right-click context menu to copy the full object value instead of the truncated description.

## Best solution

Register the existing `COPY_VALUE_ID` action in `MenuId.DebugConsoleContext` (in `debug.contribution.ts`) for REPL elements that are expandable objects, similar to how it is registered for Variables/Watch/Hover. The existing `debug.replCopy` action only copies truncated text; the DAP limitation noted in the code (comment referencing #187784) may constrain which element types support full value copying, but `ReplEvaluationResult` already has a `tryEvaluateAndCopy` path that could be extended.
