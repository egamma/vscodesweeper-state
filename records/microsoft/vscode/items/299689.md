# Issue #299689 — High CPU after update: cpptools repeatedly retries LanguageModelProxy model resolution in Remote-WSL extension host

[https://github.com/microsoft/vscode/issues/299689](https://github.com/microsoft/vscode/issues/299689)

## Summary

This is a duplicate of #318753 — both report unbounded CPU-pinning feedback loops caused by extensions repeatedly calling selectChatModels when models cannot be resolved. The root cause was fixed in PR #319097 (commit ca62bf6f0b5), which prevents onDidChangeChatModels from firing on metadata-only diffs and fixes re-entrancy in the model resolution path.

## Change summary

Extensions (cpptools, Python) trigger high CPU by repeatedly retrying language model resolution through LanguageModelProxy when models are unavailable, with no backoff.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/318753, which tracked the same feedback-loop root cause and was fixed via https://github.com/microsoft/vscode/pull/319097. The fix shipped; no further core change is needed.
