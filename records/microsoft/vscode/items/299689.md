# Issue #299689 — High CPU after update: cpptools repeatedly retries LanguageModelProxy model resolution in Remote-WSL extension host

[https://github.com/microsoft/vscode/issues/299689](https://github.com/microsoft/vscode/issues/299689)

## Summary

The CPU-pinning feedback loop described here was fixed in commit ca62bf6f0b5 (shipped in 1.123.0). The root cause was that `onDidChangeLanguageModels` fired on every metadata-only model update, causing extensions that call `selectChatModels` in their change handler to spin unboundedly. The fix deduplicates the event to fire only when the set of model identifiers actually changes.

## Change summary

Extensions calling `selectChatModels` in response to `onDidChangeChatModels` events caused an unbounded CPU-pinning feedback loop when model metadata changed frequently.

## Best solution

Keep the shipped fix in ca62bf6f0b5 (1.123.0). The `onDidChangeLanguageModels` bridge now only fires when the model-ID set changes, breaking the feedback loop. No further VS Code-side change is needed.
