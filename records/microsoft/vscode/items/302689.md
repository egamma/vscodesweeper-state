# Issue #302689 — Restore previous Ctrl Shift C behavior

[https://github.com/microsoft/vscode/issues/302689](https://github.com/microsoft/vscode/issues/302689)

## Summary

Valid feature request: the multi-root folder picker for Ctrl+Shift+C (introduced in PR #295073, implementing closed issue #279137) has no setting to restore the previous 'open first root directly' behavior. No such configuration exists on current main.

## Change summary

Request a setting to skip the workspace folder picker when opening an external terminal via Ctrl+Shift+C in a multi-root workspace, restoring the pre-1.111 behavior of opening the first/last-active root directly.

## Best solution

Add a setting (e.g. `terminal.external.multiRootBehavior` with values like `pick` vs `lastActive`) in the external terminal contribution so users who prefer the old single-folder-open behavior can opt out of the picker. The change lives in `src/vs/workbench/contrib/externalTerminal/electron-browser/externalTerminal.contribution.ts` around the `folders.length > 1` branch.
