# Issue #302689 — Restore previous Ctrl Shift C behavior

[https://github.com/microsoft/vscode/issues/302689](https://github.com/microsoft/vscode/issues/302689)

## Summary

Keep open as a feature request: the multi-root folder picker is intentional, but current source provides no option to restore opening the last-active workspace root directly. The original request is closed and asked for the opposite behavior, so it is not a duplicate target.

## Change summary

Allow Ctrl+Shift+C to open an external terminal at the last-active workspace root without a folder-selection prompt.

## Best solution

Offer an optional direct-opening mode for workbench.action.terminal.openNativeConsole while retaining the existing folder-selection behavior for users who prefer it. The terminal owner should decide whether this warrants a setting or a separate command.
