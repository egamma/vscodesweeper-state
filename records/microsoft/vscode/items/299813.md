# Issue #299813 — Regression: PDF Git diff original revision fails to load with PDF.js 401 in 1.110 (works in 1.109.5)

[https://github.com/microsoft/vscode/issues/299813](https://github.com/microsoft/vscode/issues/299813)

## Summary

Already fixed and shipped. The root cause — `localResourceRoots` retaining the query string from `git:` scheme URIs, causing a 401 on resource load — was fixed in commit f20ea1ceaf90 (PR #314581) and shipped in 1.120.0.

## Change summary

Git diff for binary files (PDFs, images) fails to load the original revision with a 401 error starting in 1.110.

## Best solution

Keep the shipped fix in commit f20ea1ceaf9049e1ec5e535edf4b7314d5b4daf7; no further change needed. Users on 1.120.0+ should no longer see the 401.
