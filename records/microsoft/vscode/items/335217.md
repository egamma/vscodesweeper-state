# Issue #335217 — Explorer must stay standalone when no folder is opened: "No Folder Opened" view is missing `canMoveView`

[https://github.com/microsoft/vscode/issues/335217](https://github.com/microsoft/vscode/issues/335217)

## Summary

Confirmed on current main: createEmptyViewDescriptor() in explorerViewlet.ts omits canMoveView while its counterpart createExplorerViewDescriptor() (and createOpenEditorsViewDescriptor()) both set it to true, so the 'No Folder Opened' view is rejected as both a drag source and drop target in viewPaneContainer.ts. Small, well-diagnosed, one-line fix.

## Change summary

The 'No Folder Opened' empty-explorer view cannot be dragged into another view container, unlike the Explorer's Folders view, because its view descriptor is missing canMoveView: true.

## Best solution

Add canMoveView: true to createEmptyViewDescriptor() in src/vs/workbench/contrib/files/browser/explorerViewlet.ts, matching createExplorerViewDescriptor() and createOpenEditorsViewDescriptor() in the same file.
