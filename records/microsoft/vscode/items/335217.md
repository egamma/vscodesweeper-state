# Issue #335217 — Explorer must stay standalone when no folder is opened: "No Folder Opened" view is missing `canMoveView`

[https://github.com/microsoft/vscode/issues/335217](https://github.com/microsoft/vscode/issues/335217)

## Summary

Confirmed on main: `createEmptyViewDescriptor()` in explorerViewlet.ts omits `canMoveView: true`, unlike its `createExplorerViewDescriptor()` counterpart, so the "No Folder Opened" view can't be dragged into other containers — this is a real, small, well-diagnosed bug.

## Change summary

The 'No Folder Opened' Explorer view lacks `canMoveView: true`, so it can't be dragged into other view containers the way the Folders view can.

## Best solution

Add `canMoveView: true` to `createEmptyViewDescriptor()` in src/vs/workbench/contrib/files/browser/explorerViewlet.ts, matching `createExplorerViewDescriptor()` — the reporter already supplied the exact one-line diff.
