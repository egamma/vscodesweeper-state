# Issue #292430 — Use agent status to indicate Copilot availability

[https://github.com/microsoft/vscode/issues/292430](https://github.com/microsoft/vscode/issues/292430)

## Summary

The one-time growth-session experiment is implemented, but the requested top-navigation click-to-install flow is not established: the attention badge opens a filtered sessions view, and the growth session opens chat with general welcome text. Keep this accepted, team-authored request open to settle and verify the remaining onboarding behavior.

## Change summary

Show anonymous users a one-time agent-status notification that opens chat, explains limited Copilot access, and triggers installation when clicked.

## Best solution

Complete the anonymous-user onboarding contract using the existing growth-session infrastructure, with an agreed entry-point interaction and explicit limited-access messaging. Preserve one-time dismissal and experiment gating rather than adding a second promotional mechanism.
