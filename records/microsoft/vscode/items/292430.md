# Issue #292430 — Use agent status to indicate Copilot availability

[https://github.com/microsoft/vscode/issues/292430](https://github.com/microsoft/vscode/issues/292430)

## Summary

Team-authored feature request for using the agent status indicator to drive Copilot awareness for anonymous/new users. Infrastructure work landed (chatSessions API, isReadOnly, NeedsInput status), and a POC growth provider was committed but later removed from main — the feature appears incomplete or still evolving.

## Change summary

Show an unread notification badge in the agent status indicator for anonymous users to drive Copilot awareness and onboarding.

## Best solution

Complete the growth chat session provider that uses the chatSessions API to surface a 'needs attention' indicator for anonymous/free-tier users, building on the existing `SessionAgentId.Growth` constant and the NeedsInput status infrastructure already on main. The PLG team (cwebster-99, eli-w-king, joshspicer) owns the design direction.
