# Issue #214216 — Accessibility Issue : Contrast Ratio of Buttons, Text Boxes and Combo Boxes.

[https://github.com/microsoft/vscode/issues/214216](https://github.com/microsoft/vscode/issues/214216)

## Summary

Still reproduces on main: the Solarized Light theme's button (white on #AC9D57 = 2.72:1) and input (#586E75 on #DDD6C1 = 3.71:1) foreground/background combinations fail WCAG AA 4.5:1. The theme file has not been updated to address this.

## Change summary

Solarized Light theme buttons and input boxes have insufficient contrast ratios, failing WCAG AA accessibility guidelines.

## Best solution

Darken the button background or adjust the input foreground/background in `extensions/theme-solarized-light/themes/solarized-light-color-theme.json` to meet WCAG AA 4.5:1 contrast ratios while staying within the Solarized palette.
