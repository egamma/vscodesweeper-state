# Issue #326838 — Allow excluding paths from Chat changed files pane and review workflow

[https://github.com/microsoft/vscode/issues/326838](https://github.com/microsoft/vscode/issues/326838)

## Summary

A real capability gap remains: Chat has no path-based exclusion for its changed-files summaries or review actions. No older open issue with the same observable request was found, so this re-reviewed feature request should remain open under discussion.

## Change summary

Add Chat-specific path exclusions that remove matching artifacts from changed-file lists, counts, and bulk review actions.

## Best solution

Provide a workspace-scoped Chat exclusion setting using glob patterns and apply one consistent filtered projection across response summaries, aggregate counts, multi-diff review, and bulk actions. Maintainers should first settle whether excluded pending edits are automatically kept, remain individually reviewable elsewhere, or are omitted only from presentation.

- **review workflow:** src/vs/workbench/contrib/chat/common/editing/chatEditingService.ts maps every entry into multi-diff data, while ChatEditingSession._operateEntry in src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingSession.ts applies bulk keep/undo to every modified entry when no URI list is supplied. Filtering bulk actions therefore requires an explicit product decision about the state of excluded edits.
