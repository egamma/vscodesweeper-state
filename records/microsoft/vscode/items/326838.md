# Issue #326838 — Allow excluding paths from Chat changed files pane and review workflow

[https://github.com/microsoft/vscode/issues/326838](https://github.com/microsoft/vscode/issues/326838)

## Summary

This is a valid, currently unsupported configuration request. Route it to Chat editing because exclusions must be applied consistently across the file list, counts, diffs, and review actions.

## Change summary

Add Chat-specific path exclusions for files shown and processed by the changed-files review workflow.

## Best solution

Add a resource-glob exclusion setting at the shared Chat changes layer, then apply it consistently to classic Chat editing and Agent Host changesets before computing counts, multi-diffs, and bulk review actions.
