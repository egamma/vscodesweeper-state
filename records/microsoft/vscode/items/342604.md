# Issue #342604 — Copilot Terminal Not Visible Anymore

[https://github.com/microsoft/vscode/issues/342604](https://github.com/microsoft/vscode/issues/342604)

## Summary

Keep open: another user confirms the loss of the Copilot terminal, and the reporter isolates it to the Copilot harness rather than Local. Current source distinguishes output-only Copilot shells from interactive terminals, but does not establish that the reported loss of command/output visibility is resolved.

## Change summary

Copilot-harness terminal commands no longer provide the discoverable terminal and output access available with the Local harness.

## Best solution

Ensure Copilot-harness users on Windows can discover and inspect executed commands and their output. First distinguish the missing Terminal-view entry from a failure of the existing inline output display, then address the remaining visibility gap without implying that output-only shells support interactive input.
