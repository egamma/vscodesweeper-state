## Summary

The requested filtering improvements remain absent: current code requires controller IDs, while controller labels appear only as completion details. Keep this accepted Backlog request open; no verified canonical issue covers both improvements.

## Change summary

## Best solution

Make Test Explorer tag filtering usable without knowing internal controller IDs, retaining existing qualified filters. Settle how unqualified tags and controller-label aliases behave with multiple controllers, duplicate labels, and reserved filter terms before implementation.
