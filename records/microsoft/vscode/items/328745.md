# Issue #328745 — Navigation Arrows from Automation Runs don't work as expected

[https://github.com/microsoft/vscode/issues/328745](https://github.com/microsoft/vscode/issues/328745)

## Summary

Traced in the checkout: opening an automation run calls sessionsService.openSession() just like any normal session open, so SessionsNavigation records it in the shared session-recency stack with no memory that it came from the Automations view — Back walks session history instead of returning to Automations. Team-authored and only 3 days old, so this stays open for a design/implementation decision.

## Change summary

Clicking Back after opening an automation run navigates through session history instead of returning to the Automations view it was opened from.

## Best solution

Give SessionsNavigation (src/vs/sessions/services/sessions/browser/sessionNavigation.ts) a notion of 'opened from the Automations view' so Back can return there instead of just walking the session-recency stack; automationsView.ts's openSession call at line 587 would need to signal that origin.
