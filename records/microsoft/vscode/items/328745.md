# Issue #328745 — Navigation Arrows from Automation Runs don't work as expected

[https://github.com/microsoft/vscode/issues/328745](https://github.com/microsoft/vscode/issues/328745)

## Summary

Team-authored request already has an active implementation in flight: open PR https://github.com/microsoft/vscode/pull/330779 carries 'Fixes #328745' and directly restores the Automations view on Back/Forward navigation, so this stays open pending that PR landing.

## Change summary

Clicking Back/Forward after opening an automation run from the Automations view should return to that view instead of jumping to another session.

## Best solution

Land (or iterate on) https://github.com/microsoft/vscode/pull/330779, which preserves a transient custom-view navigation entry so Back/Forward round-trips correctly between sessions and the Automations view; a prior attempt (https://github.com/microsoft/vscode/pull/330780, closed unmerged) flagged that the transient bridge may not be a durable long-term navigation model, so follow-up design work may still be needed after this lands.
