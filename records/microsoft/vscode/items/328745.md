[https://github.com/microsoft/vscode/issues/328745](https://github.com/microsoft/vscode/issues/328745)

## Summary

Keep open while the directly linked draft fix is reviewed. The current session-recency navigation intentionally omits custom views, but multiple maintainers now support returning to Automations and an open PR implements and tests that behavior.
