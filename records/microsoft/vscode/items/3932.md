# Issue #3932 — Support Elastic Tabstops

[https://github.com/microsoft/vscode/issues/3932](https://github.com/microsoft/vscode/issues/3932)

## Summary

A substantial editor-core gap remains: current main renders fixed-width tab stops and does not align tab-separated cells across adjacent lines. With 256 upvotes and a Backlog milestone, this should remain open.

## Change summary

Render tabs as elastic, content-dependent column delimiters across adjacent lines without modifying the document.

## Best solution

Implement elastic layout in the editor renderer together with consistent cursor positioning, hit testing, selection, wrapping, and accessibility behavior. Existing extensions are only partial approximations and cannot reliably replace editor-core support.
