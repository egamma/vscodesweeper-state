# Issue #343279 — overflow of icons of custom endpoints on github copilot chat

[https://github.com/microsoft/vscode/issues/343279](https://github.com/microsoft/vscode/issues/343279)

## Summary

Keep open: the endpoint-count threshold and model-picker shortcut provide sufficient steps to retest the reported overlap. Current main still renders provider tabs beside trailing actions in a fixed-width picker, but the exact layout failure has not been confirmed in a running workbench.

## Change summary

Prevent custom endpoint icons from overlapping the model picker's Add and Search controls when more than seven endpoints are configured.

## Best solution

Keep provider navigation and the Add/Search actions independently reachable as the provider count grows, within the chat model picker. Confirm the reported threshold in the current workbench before choosing and validating the overflow behavior.
