# Issue #343279 — overflow of icons of custom endpoints on github copilot chat

[https://github.com/microsoft/vscode/issues/343279](https://github.com/microsoft/vscode/issues/343279)

## Summary

The current model picker still allows provider tabs to overflow into its trailing actions. The report supplies a concrete trigger, and the source confirms an unbounded icon row inside a fixed-width picker.

## Change summary

Prevent custom-endpoint provider icons from overlapping the model picker's Add Models and Search controls.

## Best solution

Keep the provider navigation within its available space while preserving access to every endpoint and leaving Add Models and Search unobstructed.
