# Issue #344932 — Agent host: chat created while the remote host connection is down cannot be restored (Session identity was not advertised)

[https://github.com/microsoft/vscode/issues/344932](https://github.com/microsoft/vscode/issues/344932)

## Summary

Keep open: current source still allows a client-only session to materialize before remote creation succeeds, then rejects that resource during restoration. The report supplies concrete diagnostics; preserving the prompt and defining recovery after reconnect exhaustion remain necessary.

## Change summary

Prevent failed first sends to a disconnected remote agent host from leaving unrestorable chat editors and losing the submitted prompt.

## Best solution

Preserve a recoverable draft when remote session creation fails, and explain disconnected or unknown-session states without stranding the editor. Settle the recovery behavior after reconnect exhaustion before implementing the complete reconnect, first-send, and restoration flow.
