# Issue #318540 — Pass a session ID when using BYOM with OpenRouter.

[https://github.com/microsoft/vscode/issues/318540](https://github.com/microsoft/vscode/issues/318540)

## Summary

Keep this accepted feature request open: current OpenRouter integration does not establish the requested per-chat attribution, and 30 upvotes plus the multi-worktree use case demonstrate demand. Related open middleware PRs provide a possible foundation, but do not automatically send a session identifier to OpenRouter.

## Change summary

Include a stable, unique identifier for each Copilot chat session in OpenRouter inference requests so usage and spend can be grouped externally.

## Best solution

Deliver OpenRouter-recognized session attribution that remains consistent across requests within one chat and separates concurrent chats. Evaluate the session-context work in https://github.com/microsoft/vscode/pull/337203 and its prerequisite before choosing the OpenRouter-specific integration; middleware availability alone would not satisfy the automatic behavior requested here.
