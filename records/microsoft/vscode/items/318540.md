# Issue #318540 — Pass a session ID when using BYOM with OpenRouter.

[https://github.com/microsoft/vscode/issues/318540](https://github.com/microsoft/vscode/issues/318540)

## Summary

Valid feature request that passed the 20-upvote community threshold and was promoted to Backlog. No session ID is currently sent in OpenRouter BYOK requests — the `OpenRouterEndpoint.getExtraHeaders()` only adds Anthropic beta headers, and the base `OpenAIEndpoint.getExtraHeaders()` only sends auth and content-type. The feature is not implemented on main.

## Change summary

Pass a unique, consistent session ID (e.g. UUID4) per Copilot session in BYOK requests to OpenRouter, enabling per-session usage/spend analysis on the OpenRouter side.

## Best solution

Add a session-scoped identifier to OpenRouter requests — likely via an `X-Session-Id` or OpenRouter's documented extra headers — in `OpenRouterEndpoint.getExtraHeaders()` (`extensions/copilot/src/extension/byok/vscode-node/openRouterProvider.ts`). The session ID could come from the existing Copilot session lifecycle. This is a small, well-scoped enhancement to the BYOK/OpenRouter integration.
