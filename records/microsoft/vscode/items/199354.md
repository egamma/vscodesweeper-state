# Issue #199354 — Hold shift to drop into editor?

[https://github.com/microsoft/vscode/issues/199354](https://github.com/microsoft/vscode/issues/199354)

## Summary

The 'Hold Shift to drop into editor' prompt shows in scenarios where Shift-dropping isn't actually supported (empty groups, errored editors, or after specific drag sequences across windows). The logic in editorDropTarget.ts still only guards on `enableDropIntoEditor` computed once at overlay creation, which can be stale or incorrectly true.

## Change summary

The 'Hold Shift to drop into editor' hint shows even when Shift-dropping isn't functional, such as for empty editor groups or certain cross-window drag sequences.

## Best solution

The `toggleDropIntoPrompt(true)` call at line 491 in editorDropTarget.ts should additionally check whether the current active editor actually supports drop-into at the time the overlay is positioned (not just at construction time). This would suppress the prompt for empty groups and editors without the `CanDropIntoEditor` capability.
