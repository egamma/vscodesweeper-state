# Issue #240304 — Can't sign into Azure from VS Code with the new authentication. VPN blocking native auth flow

[https://github.com/microsoft/vscode/issues/240304](https://github.com/microsoft/vscode/issues/240304)

## Summary

The requested browser-login alternative now exists as msal-no-broker, and the discussion confirms it works. Keep this accepted upstream issue open: bypassing Windows native authentication does not establish that its VPN compatibility defect is fixed.

## Change summary

Allow Azure authentication through an external browser when Windows native authentication cannot use the company's VPN or browser-based corporate sign-in.

## Best solution

Retain microsoft-authentication.implementation="msal-no-broker" as the supported browser alternative, while the Windows WAM/native broker owner resolves the VPN compatibility problem. This issue remains the existing consolidation point for that upstream defect.
