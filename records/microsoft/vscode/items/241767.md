# Issue #241767 — Localise media paths in walkthroughs

[https://github.com/microsoft/vscode/issues/241767](https://github.com/microsoft/vscode/issues/241767)

## Summary

Valid feature request for a `{locale}` token in walkthrough media paths to support localized resources. Not implemented on main — the walkthrough extension point has no locale substitution for media paths. Low community traction (1 upvote in 516 days), but the design is reasonable and the related vscode-l10n issue shows cross-team awareness.

## Change summary

Support a `{locale}` token in walkthrough step media paths so extensions can ship locale-specific images and markdown documents.

## Best solution

Implement `{locale}` token substitution in `src/vs/workbench/contrib/welcomeGettingStarted/browser/gettingStartedService.ts` when resolving media paths from walkthrough step contributions. The l10n tooling (`vscode-l10n`) would also need awareness of this token to avoid incorrectly localizing path strings. Given low community demand, this could reasonably stay in backlog until more extension authors request it.
