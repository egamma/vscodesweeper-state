# Issue #158996 — "Follow link" hover is not linkified on markdown links

[https://github.com/microsoft/vscode/issues/158996](https://github.com/microsoft/vscode/issues/158996)

## Summary

Team-authored issue, still reproduces on main. The lazy-resolve path in `getHoverMessage` falls back to plain text when `link.url` is undefined, so "Follow link" is not rendered as a clickable link for markdown document links. The suggested fix (resolving on hover) was never implemented.

## Change summary

The "Follow link" hover message on markdown links with lazily-resolved targets is rendered as plain text instead of a clickable link.

## Best solution

Call `link.resolve()` before building the hover message (or eagerly resolve when computing decorations), so that `link.url` is populated by the time `getHoverMessage` runs. The fix is in `src/vs/editor/contrib/links/browser/links.ts` (the `getHoverMessage` function and/or the hover computation call site) and `src/vs/editor/contrib/links/browser/getLinks.ts` (the `resolve` method).
