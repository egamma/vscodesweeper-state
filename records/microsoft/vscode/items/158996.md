# Issue #158996 — "Follow link" hover is not linkified on markdown links

[https://github.com/microsoft/vscode/issues/158996](https://github.com/microsoft/vscode/issues/158996)

## Summary

Still present on main: when a link provider uses lazy resolution (no url until resolve is called), the hover message renders as plain text instead of a clickable link because resolve is only called on open, not on hover.

## Change summary

The 'Follow link' hover text is not rendered as a clickable link for markdown links that use lazy resolution via resolveLink.

## Best solution

Call `link.resolve()` before building the hover message (or when hovering), so that `link.url` is populated by the time `getHoverMessage` runs. The fix belongs in `src/vs/editor/contrib/links/browser/links.ts` — either resolve eagerly when computing the decoration hover, or update the decoration after resolve completes.
