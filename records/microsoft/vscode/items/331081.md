# Issue #331081 — Cannot edit a comment I did on a markdown document

[https://github.com/microsoft/vscode/issues/331081](https://github.com/microsoft/vscode/issues/331081)

## Summary

Traced conclusively in source: the new experimental Markdown editor's comment pipeline only implements add/delete, not edit, end-to-end (webview protocol, extension bridge, and the proposed API). This is a missing capability in a brand-new experimental feature, not an accidental regression, so it stays open for the feature to be completed.

## Change summary

In the new WYSIWYG Markdown editor, a comment the user left cannot be edited after creation — only added or deleted.

## Best solution

Add an edit/update path through the whole pipeline: a new `editComment`/`updateComment` method on `vscode.window.createAgentEditorComments()`'s result (vscode.proposed.agentEditorComments.d.ts), a `$editComment` on the MainThreadAgentEditorComments bridge, and an `editComment` postMessage handled in markdownEditorProvider.ts/editor.ts alongside the existing addComment/deleteComment wiring.
