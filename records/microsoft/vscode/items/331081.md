# Issue #331081 — Cannot edit a comment I did on a markdown document

[https://github.com/microsoft/vscode/issues/331081](https://github.com/microsoft/vscode/issues/331081)

## Summary

The Markdown editor still lacks a path to save changes to an existing comment, although the regular session editor supports editing. Keep this team-authored report open; no verified fixing commit or older same-symptom canonical was found.

## Change summary

Allow users to edit comments they previously added in the new Markdown editor.

## Best solution

Provide comment-editing parity with the regular session editor, persisting changes to the shared feedback store while preserving comment identity, anchoring, and existing edit eligibility. This requires an end-to-end update path through the Markdown renderer, extension bridge, and workbench comment provider.
