# Issue #272242 — Chat input doesn't relayout when changing models

[https://github.com/microsoft/vscode/issues/272242](https://github.com/microsoft/vscode/issues/272242)

## Summary

Fixed on current main: compact chat inputs now observe toolbar-size changes and relayout the editor when a mode or model picker changes width, preventing the reported screen cheese.

## Change summary

Changing the selected chat mode or model in quick or inline chat rerendered a picker without relaying out the input around its new width.

## Best solution

Keep the compact-toolbar ResizeObserver introduced by commit 68e1b20ce90dedaf48054b721dbe4b630ff6e143; it relayouts the shared editor width whenever picker rendering changes the toolbar size.
