## Summary

The missing relayout notification is addressed by a landed shared-input fix: toolbar size changes now recalculate the editor width in both Quick Chat and inline chat.

## Change summary

Changing the mode or model in Quick Chat or inline chat leaves the input layout stale after a picker changes size.
