# Issue #325208 — Agent host terminal preview is missing scrollbar

[https://github.com/microsoft/vscode/issues/325208](https://github.com/microsoft/vscode/issues/325208)

## Summary

Team-authored bug, still present on main: the terminal output preview in the chat terminal tool progress part creates its DomScrollableElement with `vertical: ScrollbarVisibility.Hidden`, so no vertical scrollbar ever renders. No fix commit references this issue.

## Change summary

The agent host terminal preview output container does not display a vertical scrollbar, preventing users from scrolling through terminal output.

## Best solution

Change the vertical scrollbar visibility in `ChatTerminalOutputContainer._createScrollableContainer()` from `ScrollbarVisibility.Hidden` to `ScrollbarVisibility.Auto` (or apply similar hover/focus show/hide logic already used for the horizontal scrollbar). The fix is localized to `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/chatTerminalToolProgressPart.ts` around line 1368.
