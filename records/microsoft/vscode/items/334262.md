# Issue #334262 — GitHub Copilot inline suggestions consistently fail in Jupyter notebooks

[https://github.com/microsoft/vscode/issues/334262](https://github.com/microsoft/vscode/issues/334262)

## Summary

Well-documented, cross-version report that Copilot's Next Edit Suggestion (NES) inline-completion path never fires in Jupyter notebook cells; the reporter ruled out extensions/workspace-state confounders across three VS Code/Copilot releases, so this looks like a real gap in notebook support for NES rather than local misconfiguration.

## Change summary

Copilot inline (NES) ghost-text suggestions never appear in .ipynb notebook cells, while the same code in a .py file triggers suggestions normally.

## Best solution

Have the NES/inline-edits team (extensions/copilot/src/extension/inlineEdits) trace why notebook-cell documents hit the `DocumentMissingInHistoryContext` error path in nextEditProvider.ts, and why some requests return an empty model completion (`noSuggestions`) specifically for notebook cells — the telemetry code already tags notebook docs (nextEditProviderTelemetry.ts), so the plumbing exists but the actual completion/history-tracking path for notebook cells appears broken or under-covered.
