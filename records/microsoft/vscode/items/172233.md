# Issue #172233 — [css] missing colon causes error to be placed on next rule

[https://github.com/microsoft/vscode/issues/172233](https://github.com/microsoft/vscode/issues/172233)

## Summary

Keep open: the maintainer-provided CSS-only reproduction identifies a parser-recovery defect that remains visible in the current CSS language service source. The fix belongs upstream in the CSS parser and should subsequently be consumed by VS Code.

## Change summary

Keep a missing CSS declaration separator from causing the diagnostic range and parser recovery to spill into the following rule.

## Best solution

Improve declaration-error recovery in microsoft/vscode-css-languageservice so a missing colon or semicolon stops at the containing rule boundary and reports the offending declaration, then update VS Code's bundled language-service dependency.
