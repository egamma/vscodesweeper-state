# Issue #341506 — Copilot chat includes a pointless summary of files changed

[https://github.com/microsoft/vscode/issues/341506](https://github.com/microsoft/vscode/issues/341506)

## Summary

Thanks for the report. The code suggests a likely cause: `chat.checkpoints.showFileChanges` only gates the classic `changesSummary` part, while the agent-host `turnPills` summary is gated only by `shouldShowTurnPillsSummary(isComplete, isAgentHostSession)` and ignores that setting. I did not run it, and the report doesn't say which session type was used. The steps are enough to retest.

## Change summary

The chat response shows a file-changes summary that includes unrelated and untracked files across repos, and the existing setting `chat.checkpoints.showFileChanges` cannot hide it.

## Best solution

Make the setting (or a new one) also hide the agent-host turn pills summary. Also scope the listed changes to files the turn actually edited, excluding untracked files and unrelated repos.
