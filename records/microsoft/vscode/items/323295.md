# Issue #323295 — Unicode support in embedded PowerShell terminal upon "git status" command

[https://github.com/microsoft/vscode/issues/323295](https://github.com/microsoft/vscode/issues/323295)

## Summary

The quoted octal sequences are Git's default filename-escaping behavior, not evidence of missing Unicode support in VS Code's terminal. Propose closing with an explanation of Git's core.quotePath option.

## Change summary

Display Devanagari filenames directly rather than as quoted octal escapes in integrated PowerShell's git status output.

## Best solution

Preserve terminal output verbatim and use Git's existing core.quotePath option to control filename presentation. The reporter can run git -c core.quotePath=false status without changing any persistent configuration.

- **Proposed comment:**

  > Thanks for the report. Those octal escapes are produced by Git's default `core.quotePath=true` behavior, rather than by VS Code's Unicode rendering. Run `git -c core.quotePath=false status` to display the Devanagari filename directly without changing your configuration. Git documents this option at https://git-scm.com/docs/git-config#Documentation/git-config.txt-corequotePath.
