# Issue #323295 — Unicode support in embedded PowerShell terminal upon "git status" command

[https://github.com/microsoft/vscode/issues/323295](https://github.com/microsoft/vscode/issues/323295)

## Summary

This is git's default behavior, not a VS Code issue. Git quotes non-ASCII characters in filenames using octal escape sequences by default (`core.quotePath=true`). The fix is a git configuration change, not a VS Code change.

## Change summary

Running `git status` in VS Code's integrated terminal shows Devanagari filenames as octal escape sequences instead of readable Unicode.

## Best solution

Close as a support question — the reporter needs to run `git config --global core.quotePath false` to make git display non-ASCII filenames verbatim. The terminal is faithfully rendering what git outputs; the Explorer shows correct names because it reads the filesystem directly.
