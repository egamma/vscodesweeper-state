# Issue #192664 — Feature Request: Typing enter to close an openning bracket

[https://github.com/microsoft/vscode/issues/192664](https://github.com/microsoft/vscode/issues/192664)

## Summary

Keep open: current Enter handling does not supply a missing closing brace for an existing opening brace, and the related inline-completion API only partially addresses the request. No verified older canonical owns the same Enter-triggered behavior.

## Change summary

Offer configurable closing of an existing unmatched opening bracket when Enter is pressed, including after accepting an inline completion.

## Best solution

Have the editor-autoclosing owner evaluate opt-in, language-aware bracket completion on Enter, preserving existing paired-bracket indentation and avoiding duplicate closing brackets. Provider-controlled completion preprocessing is not a substitute for handling an opening bracket already present in the document.
