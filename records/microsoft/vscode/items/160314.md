# Issue #160314 — Vertical mode not discoverable

[https://github.com/microsoft/vscode/issues/160314](https://github.com/microsoft/vscode/issues/160314)

## Summary

The discoverability gap remains: both merge-editor layout choices are still in the editor-title overflow menu. Keep this discussion open; changing the default layout is separate work, and the thread supports a top-level layout submenu.

## Change summary

Make the merge editor's column layout discoverable through a primary toolbar control rather than only through the overflow menu.

## Best solution

Expose an understandable top-level layout selector with the current choice indicated, retaining the existing layout behavior and persistence. Resolve its relationship to Split Editor with the maintainer rather than coupling discoverability to a default-layout change.
