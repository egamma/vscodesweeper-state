# Issue #180144 — Goto line picker should not announce the line content

[https://github.com/microsoft/vscode/issues/180144](https://github.com/microsoft/vscode/issues/180144)

## Summary

Keep open: current source still makes the navigation picker announce the full destination line independently of the editor. The discussion supports moving this responsibility into the editor while preserving the working Windows announcement; it does not support removing announcements outright.

## Change summary

Consolidate programmatic-navigation announcements in the editor instead of announcing unrestricted line content from the Go to Line picker.

## Best solution

Make editor-level programmatic navigation reliably expose the destination to screen readers, then retire the picker-specific announcement without regressing Windows behavior. Establish appropriate handling for very long lines and verify both NVDA and VoiceOver before removing the workaround.
