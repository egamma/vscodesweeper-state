# Issue #345291 — Workspaceless chats require a workspace switch before editing a named folder

[https://github.com/microsoft/vscode/issues/345291](https://github.com/microsoft/vscode/issues/345291)

## Summary

Keep open as a request to relax an intentional workspace-attachment requirement. Current prompt guidance still requires conversion before project edits; fixing the related conversion failure would not satisfy the request to keep the chat workspaceless.

## Change summary

Allow workspaceless chats to edit explicitly named folders without requiring a workspace switch.

## Best solution

Distinguish targeted work in a user-named folder from attaching a persistent workspace in Agent Host guidance. Preserve scratch defaults and runtime permission enforcement, while retaining workspace attachment for ongoing project work.
