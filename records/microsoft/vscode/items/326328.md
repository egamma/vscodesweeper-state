## Change summary

Requests reverting (or providing a permanent opt-out for) the new 'Modern UI' floating-card workbench style, disliking the added rounding/spacing.

## Best solution

Consolidate the discussion on https://github.com/microsoft/vscode/issues/326146, which carries the same request with much more engagement (59 comments, 143 👍); the design team already has a working opt-out via `workbench.experimental.modernUI: false`, and the open question of whether it stays permanently optional belongs to that thread.
