# Issue #326328 — revert modern ui update

[https://github.com/microsoft/vscode/issues/326328](https://github.com/microsoft/vscode/issues/326328)

## Summary

Legitimate, high-signal design-feedback thread on the experimental Modern UI (59 upvotes, dozens of comments) — this is a product-direction call for the design/UX team, not something to close; the opt-out setting already exists and is repeatedly surfaced in comments.

## Change summary

Revert (or provide a way to fully disable) the new 'Modern UI' visual redesign — rounded corners, added padding/margins between panels — which several users find wastes screen space and adds visual noise.

## Best solution

Keep this open as the active feedback thread for the Modern UI rollout; the team should weigh the accumulated critique (wasted screen space, broken workbench color customizations, scrollbar gap in comment #29) before the feature graduates from experimental, and ensure `workbench.experimental.modernUI: false` (or its eventual stable equivalent) remains a durable way to keep the classic layout.
