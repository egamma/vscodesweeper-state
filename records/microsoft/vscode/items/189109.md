# Issue #189109 — Polyglot Notebooks get code cells that are not editable

[https://github.com/microsoft/vscode/issues/189109](https://github.com/microsoft/vscode/issues/189109)

## Summary

Keep open: the malformed language-configuration path still reaches an unchecked editor operation in current source. Polyglot Notebooks worked around the trigger, but that does not complete the core robustness improvement requested by the maintainer.

## Change summary

Malformed autoclosing-pair data passed by Polyglot Notebooks leaves newly added code cells collapsed and unusable.

## Best solution

Reject malformed language configurations at the extension-host boundary with a clear diagnostic, or otherwise prevent them from breaking editor initialization. Preserve the distinction between the API's object-based pairs and the JSON configuration format's supported array shorthand.
