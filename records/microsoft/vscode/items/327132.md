# Issue #327132 — Prefered language is ignored

[https://github.com/microsoft/vscode/issues/327132](https://github.com/microsoft/vscode/issues/327132)

## Summary

Current Copilot completion code intentionally prioritizes a recognized filename extension over VS Code's selected language mode. Treat this as a behavior-change request and route it to the inline-completions maintainers.

## Change summary

Make Copilot inline completions prefer the manually selected language mode over the file extension.

## Best solution

Decide whether an explicit VS Code language selection should override filename-based detection for saved files, then update the completion language-detection policy and its tests without weakening handling for ambiguous extensions.
