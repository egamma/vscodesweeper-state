# Issue #327132 — Prefered language is ignored

[https://github.com/microsoft/vscode/issues/327132](https://github.com/microsoft/vscode/issues/327132)

## Summary

Keep open as a request to make Copilot inline completions honor the selected editor language over a recognized filename extension. Current source deliberately uses filename-based detection, and the related model-selection request does not cover this behavior.

## Change summary

Prefer the explicitly selected JavaScript language mode when generating inline completions for a file saved with a .rs extension.

## Best solution

Have the Copilot completions owner decide how explicit editor language selection should interact with filename-based detection, preserving existing template-language and related-language handling. The endpoint question is secondary and should not replace tracking the language-precedence request.
