## Evidence

- **canonical issue:** https://github.com/microsoft/vscode/issues/168671 is open, older, and explicitly tracks UI density from global modes through per-major-part customization; its discussion specifically considers Activity Bar density and how individual overrides should interact with a global mode.
- **current behavior:** src/vs/workbench/browser/workbench.contribution.ts registers `window.density.editorTabHeight` for editor tabs/title controls separately from `workbench.activityBar.compact`; the latter explicitly applies only when `workbench.activityBar.location` is `default`, so it does not cover the reported top-positioned Activity Bar alignment.
- **existing partial capability:** https://github.com/microsoft/vscode/pull/294881 added compact side-Activity-Bar sizing before this report, and https://github.com/microsoft/vscode/issues/297002 verified the 36px-wide/16px-icon mode while documenting that the size option is unavailable for top or bottom placement. The remaining request is therefore the broader density-coordination decision owned by the canonical issue.
