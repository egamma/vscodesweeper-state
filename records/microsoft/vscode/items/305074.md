# Issue #305074 — the activitybar should compact the same as tabbar

[https://github.com/microsoft/vscode/issues/305074](https://github.com/microsoft/vscode/issues/305074)

## Summary

The requested compact Activity Bar already has an independent built-in control, while `window.density.editorTabHeight` intentionally controls the editor header rather than all workbench chrome. This can close as designed with guidance to use the existing Activity Bar compact setting.

## Change summary

Make compact editor tabs automatically reduce the Activity Bar width and icon size as well.

## Best solution

Keep editor-tab and Activity Bar density independently configurable, and use `workbench.activityBar.compact` or Activity Bar Size > Compact for the requested layout.

- **Fit:** aligned
- **Reason:** Compact, consistent workbench chrome fits the project's workbench UX direction, and the existing independent density control already provides that outcome.
- **Evidence:** Value: simple, uniform UI and UI interactions; durable theme: Workbench & core UX.

  > Thanks for the report. Editor tab height and Activity Bar size are independent controls: set `workbench.activityBar.compact` to `true`, or right-click the Activity Bar and choose **Activity Bar Size > Compact**, to use the smaller icons and reduced width. Since the requested compact Activity Bar layout is already available separately, this is working as designed.
