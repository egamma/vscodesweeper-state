# Issue #316820 — API: expose Explorer view selection to extensions (read + change event)

[https://github.com/microsoft/vscode/issues/316820](https://github.com/microsoft/vscode/issues/316820)

## Summary

The request is covered by the verified open issue https://github.com/microsoft/vscode/issues/3553, which predates this report and describes the same Explorer-selection limitation for palette and keybinding commands. Its discussion also requests selection notifications and focused-item access, so the API sketches and additional use case should be consolidated there.

## Change summary

Expose built-in Explorer selection and selection-change events to extensions so commands and reactive integrations can use selected resources independently of context menus.

## Best solution

Resolve the Explorer selection API in https://github.com/microsoft/vscode/issues/3553, carrying forward this report's candidate API shapes, focus semantics, and agent-context use case rather than maintaining parallel requests.
