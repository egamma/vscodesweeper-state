# Issue #244745 — Issue Reporter: Maybe add a button to directly copy the extension info, system info and A/B experiment info into the clipboard

[https://github.com/microsoft/vscode/issues/244745](https://github.com/microsoft/vscode/issues/244745)

## Summary

Team-authored feature request for per-section copy buttons in the Issue Reporter — still not implemented on main. The existing clipboard support only writes the full issue body when it exceeds URL limits; there are no dedicated copy buttons for individual info sections (extensions, system, experiments). Keeping open.

## Change summary

Add copy-to-clipboard buttons next to extension info, system info, and A/B experiment info sections in the Issue Reporter, so users can grab individual sections without manual selection.

## Best solution

Add copy buttons (codicon clipboard icons) next to the extension data, system info, and experiment info sections in the issue reporter UI. The issue reporter page template is in `src/vs/workbench/contrib/issue/browser/issueReporterPage.ts` and the logic in `baseIssueReporterService.ts`. A comment from justschen indicates intent to add this alongside the existing download link.
