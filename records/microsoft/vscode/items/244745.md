## Summary

Keep open: the current reporter displays the requested diagnostic sections but still lacks direct copy controls. A maintainer welcomed the improvement, and the older clipboard-command request does not clearly cover this report’s section-level controls and A/B experiment data.

## Change summary

Add direct clipboard controls for issue-reporter extension information, system information, and A/B experiment information so they can be pasted into an independently created GitHub issue.
