# Issue #298673 — Feature: Anchor file names or folder names directly to chat while typing automatically

[https://github.com/microsoft/vscode/issues/298673](https://github.com/microsoft/vscode/issues/298673)

## Summary

This remains a real chat-input feature gap on current main: “Add File to Chat” creates a detached attachment rather than inserting a file or range reference at the prompt caret. Route it to chat input and keep it open while the existing implementation PR is reviewed.

## Change summary

Insert file, folder, and selected-line references into the chat prompt at the current caret position when using Add to Chat.

## Best solution

Land https://github.com/microsoft/vscode/pull/325949 or an equivalent implementation that inserts clickable file, folder, and line-range references at the caret while preserving attachment semantics, drafts, history, keyboard use, and chat accessibility help.
