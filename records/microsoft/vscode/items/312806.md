# Issue #312806 — Agents: Expose the collapse all button more prominently in the session list

[https://github.com/microsoft/vscode/issues/312806](https://github.com/microsoft/vscode/issues/312806)

## Summary

Keep open: collapsing groups exists, but current main still places the action behind the Sessions header overflow rather than exposing a direct button. The team-authored request concerns discoverability, and another reporter independently encountered the same difficulty.

## Change summary

Make collapsing all session-list groups easier to discover and invoke without closing or losing chats.

## Best solution

Provide a more discoverable collapse-all affordance in the Sessions header while preserving the existing collapse behavior and a calm, usable narrow sidebar. Agree on its visibility and placement before implementation.
