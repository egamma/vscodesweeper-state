# Issue #25895 — Stop rendering pseudo-italic fonts when italic is not available

[https://github.com/microsoft/vscode/issues/25895](https://github.com/microsoft/vscode/issues/25895)

## Summary

A real font-rendering gap remains, particularly for emoji fallback glyphs, and it is already classified as Chromium-owned upstream work. The available customization disables italics entirely rather than preserving real italic faces while suppressing synthetic ones.

## Change summary

Prevent Chromium from synthesizing italic or bold glyphs when the selected or fallback font lacks the requested face.

## Best solution

Keep tracking Chromium issue https://issues.chromium.org/issues/40257040, then apply `font-synthesis: none` in Monaco when Chromium reliably handles fallback glyphs, or make an explicit product decision about exposing that behavior as an editor option.
