# Issue #346885 — Agents Window: Submit comments from a child chat targets the parent and waits for its chat widget

[https://github.com/microsoft/vscode/issues/346885](https://github.com/microsoft/vscode/issues/346885)

## Summary

The child-chat targeting defect remains in current main: both Submit actions omit the target chat, causing submission to wait for or use the parent's widget. Keep this open; the related submission-mode request explicitly treats this as a separate bug.

## Change summary

Submit review comments to their originating chat without requiring parent-chat navigation, and visibly acknowledge acceptance or failure.

## Best solution

Preserve the originating chat as the submission destination across navigation, while keeping feedback ownership session-scoped. Both Submit surfaces should acknowledge acceptance independently of agent execution and surface unavailable-target or submission failures.
