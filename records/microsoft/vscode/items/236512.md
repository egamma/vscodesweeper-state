# Issue #236512 — Selected tab underline thickness is hard to see

[https://github.com/microsoft/vscode/issues/236512](https://github.com/microsoft/vscode/issues/236512)

## Summary

The customization gap remains on current main: active-selection indicator thicknesses are hard-coded across editor tabs, composite bars, and terminal tabs, while themes can configure only their colors. The request is already in the Backlog with meaningful support, and the older exact request was closed only by the historical upvote process rather than by a product decision.

## Change summary

Allow active tab and related selection underlines to use a more visible or user-configurable thickness.

## Best solution

Define a consistent accessibility-oriented thickness model for active indicators across editor tabs, top or bottom activity bars, panel titles, and terminal tabs, while preserving distinct keyboard-focus and high-contrast treatments. A maintainer should first decide whether this is a stronger default, one shared setting, or separate surface-specific settings.
