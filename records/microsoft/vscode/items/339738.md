# Issue #339738 — Clicking on pill of peer chat could take to relevant request in peer chat

[https://github.com/microsoft/vscode/issues/339738](https://github.com/microsoft/vscode/issues/339738)

## Summary

Keep open: peer-chat pills currently open the destination conversation without locating the specific request. The request-level navigation gap remains in current source, and the existing agents-window label already routes it appropriately.

## Change summary

Make a peer-chat pill navigate to the particular request sent from the originating chat.

## Best solution

Extend peer-chat link navigation to reveal the corresponding destination request rather than only opening its conversation. Define what the pill should reveal for messages that are still queued or delivered as steering before implementing the behavior.
