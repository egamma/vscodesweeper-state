# Issue #331654 — automations page isn't included in navigation steps

[https://github.com/microsoft/vscode/issues/331654](https://github.com/microsoft/vscode/issues/331654)

## Summary

Team-authored bug filed today with a real, traceable root cause in the Agents Window's session Back/Forward navigation; no fix exists yet on main, so this stays open (team-authored issues are only closeable with a cited fixing commit, which doesn't exist here).

## Change summary

In the Agents Window, opening the Automations page and then pressing Back skips over it and jumps straight to an older chat session instead of returning to the session that was active before Automations was opened.

## Best solution

In src/vs/sessions/services/sessions/browser/sessionNavigation.ts, make SessionsNavigation aware of the Automations view being active (similar to how it already special-cases the new-session view via `_beyondHistory`) so opening Automations doesn't leave the recency cursor stale — Back should first return to the session/chat that was active immediately before Automations was opened.

## Evidence

- **root cause file:** src/vs/sessions/services/sessions/browser/sessionNavigation.ts: the tracking autorun (lines ~98-123) only records recency entries when `_activeSession`/`activeChat` change; it has no notion of the Automations view, so navigating to Automations never updates `_currentKey`.
- **back/forward logic:** goBack()/goForward() (lines 154-175) walk the recency history purely from `_currentKey`'s last-recorded index; because opening Automations doesn't move that cursor, pressing Back from Automations jumps to whatever entry is next after the last real session (A), skipping the session that was open right before Automations (B) — exactly the reported symptom.
- **related pattern:** The same file already handles a similar 'non-session view' case for the new-session view via `_beyondHistory` (set when `!activeSession || sessionStatus === SessionStatus.Untitled`), suggesting Automations needs an analogous carve-out that hasn't been added.
