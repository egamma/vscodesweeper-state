# Issue #242448 — cursor moves to the wrong spot when `editor.quickSuggestions.other` is set to `"inline"` and completion includes a text edit that adds an import

[https://github.com/microsoft/vscode/issues/242448](https://github.com/microsoft/vscode/issues/242448)

## Summary

The cursor-position defect remains in current source: inline acceptance computes the final selection without accounting for the additional import edit. Keep this older report open; the closely matching TypeScript report is newer and cannot replace it under the re-review rules.

## Change summary

Accepting an inline quick suggestion with an auto-import should leave the cursor at the completed identifier, not inside the inserted import or on an earlier line.

## Best solution

Make inline-completion acceptance preserve the intended completion cursor or snippet position after all additional edits, while retaining existing suggestion-widget behavior, undo semantics, and multi-cursor handling.
