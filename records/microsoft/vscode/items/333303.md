# Issue #333303 — Modern UI: sidebar sash becomes too wide and off-center with maximized Panel

[https://github.com/microsoft/vscode/issues/333303](https://github.com/microsoft/vscode/issues/333303)

## Summary

The maximized-panel layout still misclassifies a single sidebar's panel-facing edge as an outer edge in current source. Keep this open while the explicitly linked fix candidate is reviewed; PR 333753 is open, not merged.

## Change summary

Showing either sidebar beside a maximized centered Panel produces an oversized separator gap and an off-center sash grip.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333753 after checking it against the current layout code, so sidebar margins and sash geometry are correct immediately after visibility changes without requiring a drag.
