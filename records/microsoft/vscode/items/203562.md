# Issue #203562 — `KeybindingLabel` should support hover delegate for richer hovers

[https://github.com/microsoft/vscode/issues/203562](https://github.com/microsoft/vscode/issues/203562)

## Summary

Keep open: KeybindingLabel now uses a managed hover, but still cannot accept a caller-provided hover delegate. The quick-pick integration therefore does not cover the central request, and no qualifying canonical duplicate or issue-referencing fix was found.

## Change summary

Allow KeybindingLabel consumers to supply a hover delegate so keybinding tooltips can participate in richer, context-specific hover behavior.

## Best solution

Let KeybindingLabel participate in the quick pick's supplied hover behavior while preserving the existing default for other consumers. Treat richer keycap rendering inside the tooltip as a separate scope decision rather than assuming managed text hovers fulfill it.
