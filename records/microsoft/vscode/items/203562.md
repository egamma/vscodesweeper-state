# Issue #203562 — `KeybindingLabel` should support hover delegate for richer hovers

[https://github.com/microsoft/vscode/issues/203562](https://github.com/microsoft/vscode/issues/203562)

## Summary

Still unimplemented on main: KeybindingLabel hardcodes getDefaultHoverDelegate('mouse') and does not accept a caller-provided hover delegate. The feature request remains valid.

## Change summary

Allow KeybindingLabel to accept a custom IHoverDelegate so callers can render richer hover content for keybindings.

## Best solution

Add an optional `hoverDelegate` parameter to `KeybindingLabelOptions` in `src/vs/base/browser/ui/keybindingLabel/keybindingLabel.ts`, falling back to the current default when not provided. Callers like the quick pick can then supply a delegate that renders keybindings nicely in the hover.
