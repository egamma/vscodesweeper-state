# Issue #225410 — Custom text editors do not handle extension host restarts or crashes which can lead to data loss

[https://github.com/microsoft/vscode/issues/225410](https://github.com/microsoft/vscode/issues/225410)

## Summary

Partially addressed by merged PR #225985 (aligns onWillStop handling), but the core problem — orphaned custom editors after extension host restart/crash leading to data loss — remains open. An open PR (#226069) for webview reconnection awaits maintainer review.

## Change summary

Custom text editors become orphaned and unresponsive after extension host restart or crash, silently preventing saves and causing data loss.

## Best solution

Land or iterate on the webview reconnection approach from https://github.com/microsoft/vscode/pull/226069 so that custom editor webviews survive extension host restarts and crashes without data loss. At minimum, surface a visible warning when an editor becomes orphaned.
