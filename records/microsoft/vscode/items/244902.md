# Issue #244902 — // MARK text in minimap is strechted when "Render Characters" option is checked

[https://github.com/microsoft/vscode/issues/244902](https://github.com/microsoft/vscode/issues/244902)

## Summary

Still present on main — the minimap section header (MARK) text stretching when 'Render Characters' is enabled has not been fixed. The related PR #254135 was closed without merging.

## Change summary

Minimap section header (MARK) text appears horizontally stretched when the 'Render Characters' minimap option is enabled, particularly noticeable with certain file sizes.

## Best solution

Fix the `minimapCharWidth` calculation in `MinimapOptions` (src/vs/editor/browser/viewParts/minimap/minimap.ts, line 145) — the current formula `Constants.BASE_CHAR_WIDTH * this.fontScale` does not account for pixel ratio correctly, causing section header text layout to stretch. The closed PR #254135 attempted `this.fontScale / pixelRatio` but was not merged; a correct fix should reconcile character-sheet width with canvas text rendering width.
