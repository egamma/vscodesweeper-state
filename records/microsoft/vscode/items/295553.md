# Issue #295553 — Error when switching to background session

[https://github.com/microsoft/vscode/issues/295553](https://github.com/microsoft/vscode/issues/295553)

## Summary

Still reproduces on main: `isInstructionAttachmentPath` crashes when an attachment has no `path` property during the `buildChatHistoryFromEvents` filter, causing the session switch to error.

## Change summary

Switching from a local session to a background/CLI session throws `Cannot read properties of undefined (reading 'replace')` when an attachment lacks a `path` property.

## Best solution

Guard `attachment.path` against undefined in the filter at line 613 of `copilotCLITools.ts` — either add a `typeof attachment.path === 'string'` check before calling `isInstructionAttachmentPath`, or make `isInstructionAttachmentPath` tolerate undefined input.
