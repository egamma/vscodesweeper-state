# Issue #109106 — Use safer test for Location in argument processor

[https://github.com/microsoft/vscode/issues/109106](https://github.com/microsoft/vscode/issues/109106)

## Summary

The argument processor still converts any object with matching uri and range properties into a Location, discarding additional properties. Keep this team-authored issue open: the reported defect remains in current source, and the thread's compatibility concern still needs resolution.

## Change summary

Preserve additional command-argument properties when an object also contains a URI and range.

## Best solution

Make renderer-to-extension argument conversion preserve application-specific fields while retaining supported URI, Range, and Location conversions. Establish the compatibility contract for structurally Location-shaped arguments before changing their delivered object type.
