This is an API proposal tracking issue authored by a VS Code team member, carrying the `api-proposal` label — per policy it stays open until the API is finalized into stable vscode.d.ts, regardless of implementation progress. ## Change summary

Expose the access token's remaining lifetime (expiresAfter, in ms) on AuthenticationSession so consumers can know when to refresh renewable credentials, avoiding clock-skew issues from an absolute timestamp.
