# Issue #335184 — API proposal: Expose AuthenticationSession access token lifetime

[https://github.com/microsoft/vscode/issues/335184](https://github.com/microsoft/vscode/issues/335184)

## Summary

Keep this API tracking issue open: token lifetime is implemented as a proposed API, but it has not been finalized in vscode.d.ts. The api-proposal protection applies regardless of the merged implementation PR.

## Change summary

Expose the remaining access-token lifetime through AuthenticationSession.expiresAfter in milliseconds, avoiding client/remote clock comparisons.

## Best solution

Have the authentication API owners complete review and finalization of the relative-lifetime contract, then expose the approved property in stable vscode.d.ts. Keep provider-specific offline_access support tracked separately.
