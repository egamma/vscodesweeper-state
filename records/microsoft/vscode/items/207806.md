# Issue #207806 — settings files.exclude does not recognize .vscode folder

[https://github.com/microsoft/vscode/issues/207806](https://github.com/microsoft/vscode/issues/207806)

## Summary

This is as-designed: in `files.exclude`, setting a pattern to `false` disables that pattern — it does not create a negation/override for other patterns. `*.*` matches `.vscode` (it contains a dot), and `".vscode": false` only means the `.vscode` pattern itself won't match, not that `.vscode` is exempt from `*.*`.

## Change summary

When `*.*` is set to true in `files.exclude`, setting `.vscode: false` does not unhide the `.vscode` folder because `*.*` still matches it.

## Best solution

Close as as-designed. The `files.exclude` expression treats each pattern independently — `false` disables a pattern, it does not create a negation. The user should restructure their exclude patterns to not use `*.*` (which matches folders with dots) or use more specific patterns that don't overlap.
