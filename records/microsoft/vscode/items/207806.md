# Issue #207806 — settings files.exclude does not recognize .vscode folder

[https://github.com/microsoft/vscode/issues/207806](https://github.com/microsoft/vscode/issues/207806)

## Summary

The requested exception behavior is already tracked by the verified open canonical issue. Setting a pattern to false currently disables that pattern; it does not override another matching exclusion.

## Change summary

Allow an explicit false entry for .vscode to override the broader *.* exclusion in the File Explorer.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode/issues/869, which explicitly requests false-valued exceptions to broader files.exclude patterns and fully covers this case.
