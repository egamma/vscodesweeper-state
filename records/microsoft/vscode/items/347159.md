# Issue #347159 — Dragging is inconsistent

[https://github.com/microsoft/vscode/issues/347159](https://github.com/microsoft/vscode/issues/347159)

## Summary

Keep open: current source still uses different drag sources for main-window headers and chat-window titles, but the reported flicker is unconfirmed. The linked test plan supplies sufficient setup to retest; no issue-referencing fix was established, and this team-authored report is protected from judgment closes.

## Change summary

Make chat dragging consistent between main and chat windows without causing chats to disappear or flicker.

## Best solution

Establish a consistent drag affordance across both hosts and preserve chat visibility during dragging, cancellation, and successful moves. Reproduce the native cross-window gesture before deciding whether the affordance mismatch and flicker share a cause.
