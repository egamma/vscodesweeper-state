# Issue #132776 — Display 2 spaces instead of 4 without changing the code or project settings

[https://github.com/microsoft/vscode/issues/132776](https://github.com/microsoft/vscode/issues/132776)

## Summary

Keep open in the Backlog: this is the canonical, strongly supported request for visually resizing space-based indentation without changing source text or project formatting.

## Change summary

Allow users to render space-based indentation at a preferred width while preserving the file's actual whitespace and indentation settings.

## Best solution

Add an editor rendering option that maps detected leading indentation to a configurable visual width while preserving text, editing semantics, cursor navigation, wrapping, and indentation guides.
