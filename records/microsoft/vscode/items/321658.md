# Issue #321658 — `${workspaceFolder}` not resolved in `js/ts.tsdk.path`

[https://github.com/microsoft/vscode/issues/321658](https://github.com/microsoft/vscode/issues/321658)

## Summary

Verified duplicate: variable substitution in settings (including `js/ts.tsdk.path`) is tracked by the canonical issue https://github.com/microsoft/vscode/issues/2809, which has 740+ upvotes and sits in the Backlog. The same specific request for `typescript.tsdk` was previously filed as https://github.com/microsoft/vscode/issues/182545 and closed by the community process.

## Change summary

The `${workspaceFolder}` variable is not resolved when used in the `js/ts.tsdk.path` setting value.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/2809 — implementing variable substitution in settings would deliver this. In the meantime, a relative path like `node_modules/typescript/lib` already works: the TypeScript extension resolves relative tsdk paths against workspace folders via `RelativeWorkspacePathResolver`.
