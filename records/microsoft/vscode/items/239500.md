- **Validation:** In a maintainer-run Windows session with extensions disabled, compare editor.editContext enabled and disabled while repeatedly selecting text, copying through Ctrl+C and the context menu, and pasting into both another editor and an external application. Capture timestamped copy and paste traces at failure; the diagnostic plan should end with a repeatable case and an executable regression check for the isolated cause.
- **Behavior:**

  > Clipboard commands intermittently fail during ordinary editing; some occurrences show a missing contributed-copy-command error, while one commenter reports failure with extensions disabled and relief from disabling editor.editContext. Copying selected text should update the clipboard and allow it to be pasted inside and outside VS Code without an unrelated extension-host command failure. Establish which reported failure remains reproducible on the current build before defining regression acceptance checks. Preserve normal cut, rich-text copy, and paste behavior.
- **Trace:**

  > The core CopyAction and clipboard implementations are registered in src/vs/editor/contrib/clipboard/browser/clipboard.ts, which includes an execCommand copy-event fallback and effectiveEditContext-specific handling. MainThreadCommands.$registerCommand in src/vs/workbench/api/browser/mainThreadCommands.ts forwards registered extension commands to ExtHostCommands.$executeContributedCommand in src/vs/workbench/api/common/extHostCommands.ts; the latter produces the exact reported missing-command error when its handler map lacks the ID. This establishes the error boundary, not the cause of its registration mismatch. Continue and UMLet explain individual commenters' failures, but the extensions-disabled EditContext report remains distinct evidence. https://github.com/microsoft/vscode/issues/252371 contains related investigation and attempted fixes, but is newer than this re-reviewed issue. The uncertainty starts at connecting a captured failing copy operation to one of these paths; do not assume all symptoms share an extension cause or prescribe a broad clipboard rewrite.
