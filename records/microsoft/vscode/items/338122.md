# Issue #338122 — Agent host: an automatic rename_chat overwrites a title the user set

[https://github.com/microsoft/vscode/issues/338122](https://github.com/microsoft/vscode/issues/338122)

## Summary

Confirmed on main: applyRenameChatTool reads `automatic` only to decide sync vs background execution and never forwards it to ISessionServerToolAccessor.renameChat, so AgentService._renameChatFromTool unconditionally overwrites a user-set title with source 'agent'. A fixing PR (#338123) from the same author is already open, so this stays open pending review/merge rather than an agent-authored fix.

## Change summary

An automatic rename_chat call from the agent overwrites a chat title the user explicitly set, both in the UI and in persisted session metadata.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/338123, which threads the `automatic` flag through to renameChat/_renameChatFromTool so an automatic rename is skipped once a user-authored title (source 'user') exists.
