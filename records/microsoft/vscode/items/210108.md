# Issue #210108 — Webview steals focus when I right click ont he Panel

[https://github.com/microsoft/vscode/issues/210108](https://github.com/microsoft/vscode/issues/210108)

## Summary

This is a duplicate of https://github.com/microsoft/vscode/issues/212679, which tracks the same webview-steals-focus-on-context-menu bug with 30 upvotes, a broader description, and community interest in fixing it. Both issues share the same root cause in the webview focus-polling mechanism.

## Change summary

Webview steals focus when right-clicking in the panel or other UI elements, caused by the focus-polling interval in the webview iframe misdetecting focus state during context menu interactions.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/212679, which has more traction (30 upvotes) and a broader description covering all context-menu and title-bar-menu scenarios. The fix likely involves the `trackFocus` polling in `src/vs/workbench/contrib/webview/browser/pre/index.html` — the 250ms interval incorrectly treats the focus change from opening a native context menu as the webview gaining focus.
