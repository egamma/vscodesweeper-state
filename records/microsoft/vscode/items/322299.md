# Issue #322299 — Bug: Custom endpoint crashes with "No lowest priority node found" under context limits and silently ignores plain-text apiKey

[https://github.com/microsoft/vscode/issues/322299](https://github.com/microsoft/vscode/issues/322299)

## Summary

Keep open: independent commenters confirm the small-context request failure and ignored plaintext keys, and current source still contains the silent secret-resolution path. Older reports cover the token-budget error, but not this issue's full authentication scope.

## Change summary

Custom models with small context limits fail during prompt rendering, while plaintext API keys silently resolve to missing credentials and disabling tool calling restricts model availability.

## Best solution

Handle exhausted prompt budgets with an actionable error rather than an internal pruning exception, following the existing maintainer direction. Make unsupported credential configuration explicit, and preserve the distinction between models usable in Ask mode and those requiring tool support in Agent mode.
