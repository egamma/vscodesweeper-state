# Issue #294676 — I set `chat.disableAIFeatures = true`, but it's still constantly requesting `https://api.github.com/copilot/mcp_registry` and it's still stuck on a 429 status. How can I disable it?

[https://github.com/microsoft/vscode/issues/294676](https://github.com/microsoft/vscode/issues/294676)

## Summary

The defect remains source-reproducible on current main: disabling built-in AI does not gate the default-account MCP registry request, and a 429 can still discard cached registry policy. This should remain open for a bounded fix in the account-policy fetch path.

## Change summary

Honor `chat.disableAIFeatures` by stopping MCP registry requests and preserve cached organization registry policy across transient 429 responses.

## Best solution

The default-account service should skip the Copilot MCP registry request while built-in AI features are disabled, without disrupting unrelated account or managed-policy refreshes. Transient failures such as 429 must retain the last accepted registry URL and access policy rather than treating them as an absent registry.
