## Summary

Already implemented on main: PR #324618 (merged Aug 3, 2026) adds auto-reload of the Integrated Browser when a previewed local file changes, gated by a new setting — this can be closed as completed.

## Change summary

Requested that the Integrated Browser preview auto-reload when the underlying HTML file changes, instead of requiring a manual reload.

## Best solution

Keep the shipped fix: BrowserAutoReloadWatcher in src/vs/workbench/contrib/browserView/electron-browser/features/browserAutoReloadFeatures.ts watches the previewed file:// URL via a correlated file watcher and reloads on change, controlled by workbench.browser.autoReloadOnFileChange (default on). Close as completed; no further action needed beyond confirming on the latest build.
