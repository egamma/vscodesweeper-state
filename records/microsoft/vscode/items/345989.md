# Issue #345989 — Opened file in Markdown Preview mode can not be easily attached to Copilot chat

[https://github.com/microsoft/vscode/issues/345989](https://github.com/microsoft/vscode/issues/345989)

## Summary

The attachment suggestion still disappears for Markdown Preview's custom-editor path: chat clears its context when neither navigation nor a context provider supplies a value. The report provides sufficient steps, and the current source confirms this gap.

## Change summary

Keep the active Markdown file available as a suggested chat attachment when switching from its editor to Markdown Preview.

## Best solution

Make the preview's underlying Markdown source available as suggested file context without requiring a switch back to the editor. Preserve existing selection handling, context-provider behavior, and ignored-file restrictions.
