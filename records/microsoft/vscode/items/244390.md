# Issue #244390 — Notebook Variables displays large number keys incorrectly

[https://github.com/microsoft/vscode/issues/244390](https://github.com/microsoft/vscode/issues/244390)

## Summary

The source trace identifies precision loss in Jupyter's variable-provider serialization, before VS Code renders the keys. Keep the report open and transfer it to microsoft/vscode-jupyter, a VS Code-team-owned tracker.

## Change summary

Preserve large Python integer dictionary keys exactly in Notebook Variables and allow their child values to expand.

## Best solution

Jupyter's variable provider should preserve arbitrary-size integer keys across the Python/JavaScript boundary for both display and subsequent child lookup. Retain this report's executable Python sample when transferring the issue to https://github.com/microsoft/vscode-jupyter.
