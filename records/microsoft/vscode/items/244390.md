# Issue #244390 — Notebook Variables displays large number keys incorrectly

[https://github.com/microsoft/vscode/issues/244390](https://github.com/microsoft/vscode/issues/244390)

## Summary

The detailed reproduction remains consistent with the current Jupyter variable-provider implementation: large Python integer dictionary keys cross the provider as JavaScript numbers, losing precision and producing an incorrect child expression. Because Jupyter is VS Code-team-owned, this should be transferred to microsoft/vscode-jupyter rather than closed as extension-caused.

## Change summary

Preserve arbitrarily large Python integer dictionary keys in Notebook Variables and allow their child values to expand.

## Best solution

Update the Jupyter variable-description and expression-building path to retain dictionary keys in a lossless representation and generate a valid Python subscript expression, with coverage for integers beyond JavaScript's safe-integer range.
