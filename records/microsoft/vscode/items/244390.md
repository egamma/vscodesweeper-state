# Issue #244390 — Notebook Variables displays large number keys incorrectly

[https://github.com/microsoft/vscode/issues/244390](https://github.com/microsoft/vscode/issues/244390)

## Summary

The display issue is caused by the Jupyter extension (ms-toolsai.jupyter), which is responsible for serializing Python variable names and values before passing them to VS Code's Variable API. Large Python integers exceed JavaScript's Number.MAX_SAFE_INTEGER and lose precision when the extension converts them to JS numbers before stringifying. VS Code's API correctly accepts and displays strings — the data is already corrupted when it arrives.

## Change summary

Large integer dictionary keys in Python are displayed as 64-bit floats in the Notebook Variables view, and expanding nested values under such keys fails.

## Best solution

Move this issue to https://github.com/microsoft/vscode-jupyter — the Jupyter extension's variable provider must serialize large Python ints directly to strings without going through JavaScript's Number type. The VS Code API surface (`Variable.name: string`) is correct and would display the value properly if the extension supplied it correctly.
