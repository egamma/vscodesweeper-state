# Issue #261007 — Bracket pair highlighting unreliable

[https://github.com/microsoft/vscode/issues/261007](https://github.com/microsoft/vscode/issues/261007)

## Summary

Real, confirmed bug: bracket-pair highlighting stops updating on cursor move in a freshly-opened, untouched document, and disabling `editor.experimental.asyncTokenization` (which is enabled by default) fixes it — pointing squarely at the async-tokenization background pipeline rather than the bracket-pair-colorization feature itself. The re-reviewed duplicate bar isn't met by either candidate, so this stays open alongside the related tracking issue rather than closing.

## Change summary

Bracket pair highlighting works on first load but silently stops updating after the first cursor move, until a character is typed, when `editor.experimental.asyncTokenization` is enabled.

## Best solution

Fix belongs in the async background tokenization pipeline (src/vs/workbench/services/textMate/browser/backgroundTokenization/*) so that cursor-triggered recompute of bracket pairs doesn't silently stall before the first edit; this is best tracked/consolidated under the existing asyncTokenization investigation (https://github.com/microsoft/vscode/issues/244225), which the same assignee (hediet) already owns.
