## Summary

The CSS TextMate grammar (sourced from microsoft/vscode-css) has no rule for the CSS `@scope` at-rule, so valid syntax is highlighted as an error. This is an upstream grammar issue already tracked at microsoft/vscode-css#9.

## Change summary

The fix belongs in the upstream CSS grammar at microsoft/vscode-css — once `@scope` support is added there and the grammar is pulled into this repo (via the periodic `Update grammars` PRs), the highlighting error resolves. Keep open as upstream.
