# Issue #251596 — Using `${activeRepositoryName}` inside the `window: title` while inside a worktree displays the current worktree branch

[https://github.com/microsoft/vscode/issues/251596](https://github.com/microsoft/vscode/issues/251596)

## Summary

Keep open: current source handles ordinary worktree repository names, but the reported bare-repository layout still produces '.bare' instead of the project name. A linked implementation PR remains open, and the maintainer explicitly reserved the naming decision for further feedback.

## Change summary

Make ${activeRepositoryName} identify the underlying project when a worktree is open, independently of its folder or branch name.

## Best solution

Resolve the repository-name semantics in SCM/Git and assess the existing implementation candidate at https://github.com/microsoft/vscode/pull/267692, including the bare-repository layout it explicitly excludes. Preserve separate title variables for the worktree folder and active branch.
