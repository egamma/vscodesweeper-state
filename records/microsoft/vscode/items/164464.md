# Issue #164464 — Windows: Context menu doesn't work in ARM64

[https://github.com/microsoft/vscode/issues/164464](https://github.com/microsoft/vscode/issues/164464)

## Summary

Thin, old report that's hard to verify as-is, but source history shows the relevant code changed substantially since 2022 and is worth asking the reporters to recheck before deciding anything further.

## Change summary

On Windows ARM64, right-clicking the custom title bar (the system context menu added alongside PR #151186) doesn't show a menu, while it works on x64.

## Best solution

Ask the original/latest commenters to retest on current Insiders: as of commit af87ab952e96f3d47cde4b70159d10d5b146030d (PR #250631, 2025-06-04), Windows no longer renders VS Code's custom title-bar context menu at all — it falls through to Electron's native OS system menu for every Windows architecture, as a workaround for the separate issue microsoft/vscode#250632 ("custom titlebar context menu issues"). That native fallback should behave the same on ARM64 as on x64, so the originally reported symptom (no menu at all) is plausibly gone, but this hasn't been confirmed by any reporter since the change landed, and the custom-styled menu itself remains disabled pending #250632 rather than truly fixed for ARM64.
