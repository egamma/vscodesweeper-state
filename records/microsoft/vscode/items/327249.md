# Issue #327249 — Allow "update when downloaded" button to "Downloading..." update UI

[https://github.com/microsoft/vscode/issues/327249](https://github.com/microsoft/vscode/issues/327249)

## Summary

Valid feature request from a team member: add an option in the 'Downloading...' update UI to auto-install once the download completes, so users don't have to watch and click manually.

## Change summary

Add a checkbox or button in the update downloading UI to automatically install the update when download finishes.

## Best solution

Add an 'Install when ready' action or checkbox to the downloading state UI in the update contribution (src/vs/workbench/contrib/update/browser/). This would transition from Downloaded → Updating automatically when the user opts in during the download phase, avoiding the need to watch and click.
