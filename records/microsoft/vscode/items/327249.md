# Issue #327249 — Allow "update when downloaded" button to "Downloading..." update UI

[https://github.com/microsoft/vscode/issues/327249](https://github.com/microsoft/vscode/issues/327249)

## Summary

The download UI still lacks a way to request automatic updating when the download finishes. Keep this team-authored request open in install-update; existing automatic-download settings do not cover the requested one-time opt-in.

## Change summary

Let users opt into completing an update while its download is still running, without returning to click the update action afterward.

## Best solution

Provide an explicit, cancellable per-update opt-in from the downloading UI, while retaining existing shutdown safeguards. Settle whether completion includes restarting the application, since that distinction determines whether the feature actually removes the reporter's wait.

- **Behavior:**

  > While an update downloads, users want to opt into completing it automatically rather than watching progress and returning later. The option must be explicit and reversible, with unchanged behavior for users who do not select it. Acceptance must distinguish background installation from restarting the application and preserve normal unsaved-edit protection.
- **Trace:**

  > In src/vs/workbench/contrib/update/browser/updateTooltip.ts, renderDownloading() displays progress but offers no completion action, while renderDownloaded() and renderReady() expose later stages separately. The downloading menu entry in src/vs/workbench/contrib/update/browser/update.ts is disabled, and update.restartToUpdate in update.contribution.ts requires Ready. AbstractUpdateService.quitAndInstall() in src/vs/platform/update/electron-main/abstractUpdateService.ts also requires Ready and preserves lifecycle shutdown vetoes. Existing update.mode and Windows background-update settings do not express this per-download intent. The uncertainty is product semantics, not whether a download-stage control exists: determine whether opting in authorizes a restart or only installation. Preserve default update behavior and shutdown safeguards; https://github.com/microsoft/vscode/issues/245767 concerns a separate check-without-download capability.
- **Open decisions:**
  - Does opting into 'update when downloaded' authorize an application restart once the update is ready, or only installation/preparation without restarting?
