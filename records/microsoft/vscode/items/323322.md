# Issue #323322 — Dragging a file from VSCode Explorer pane into a browser fails to open it

[https://github.com/microsoft/vscode/issues/323322](https://github.com/microsoft/vscode/issues/323322)

## Summary

Verified duplicate: the open, older canonical issue tracks native file transfer from VS Code into external applications, including browser upload targets. This report contributes a specific Windows 10 symptom—`about:blank#blocked` in Chrome, Brave, and Edge—with extensions eliminated as a cause.

## Change summary

Make files dragged from the VS Code Explorer appear to browsers as native files so they can be opened or uploaded.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/164 and implement native OS file drag transfer there; its remaining native-transfer work fully covers browser open and upload targets.
