# Issue #323322 — Dragging a file from VSCode Explorer pane into a browser fails to open it

[https://github.com/microsoft/vscode/issues/323322](https://github.com/microsoft/vscode/issues/323322)

## Summary

Verified duplicate: the open, older canonical issue tracks native file transfer from VS Code into external applications, including browser upload targets. This report contributes a current Windows reproduction across Chrome, Brave, and Edge but requires the same underlying work.

## Change summary

Dragging a local file from the VS Code Explorer into a browser should transfer the actual file instead of navigating to about:blank#blocked.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/164 and implement native OS file transfer for Explorer drags there; that capability would make browser drops receive a real file while preserving existing in-workbench drag behavior.
