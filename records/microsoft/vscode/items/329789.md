# Issue #329789 — '<' and '>' are not colored correctly in left shift assignment and right shift assignment

[https://github.com/microsoft/vscode/issues/329789](https://github.com/microsoft/vscode/issues/329789)

## Summary

Real, reproducible bug in bracket-pair colorization, and a PR already fixes it — keep open and let that PR merge rather than closing or auto-fixing.

## Change summary

In TSX (and other languages using `<`/`>` as colorized brackets), the shift-assignment operators `<<=`, `>>=`, `>>>=` have their `<`/`>` incorrectly treated as bracket characters, causing false unmatched-bracket coloring and false cross-statement pairing.

## Best solution

Land https://github.com/microsoft/vscode/pull/329810, which adds a lookahead-only exclusion in `prepareBracketForRegExp` (src/vs/editor/common/model/bracketPairsTextModelPart/bracketPairsTree/brackets.ts) so `<`/`>` are not matched as brackets when they unambiguously form `<<=`, `>>=`, or `>>>=`.
