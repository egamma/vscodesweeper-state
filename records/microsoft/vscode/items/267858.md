# Issue #267858 — Code executable, High GPU usage on Windows

[https://github.com/microsoft/vscode/issues/267858](https://github.com/microsoft/vscode/issues/267858)

## Summary

Multiple independent Windows and Linux reports confirm severe GPU utilization while Copilot Chat progress spinners animate. The issue remains current and should be routed to Chat and GPU performance owners.

## Change summary

Chat progress animations cause disproportionate GPU load and power consumption while agent operations are pending.

## Best solution

Profile Chat's animated progress paths and prevent spinner animation from invalidating or recompositing large workbench layers. Preserve an inexpensive progress indicator and reduced-motion behavior.
