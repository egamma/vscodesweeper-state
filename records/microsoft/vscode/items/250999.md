# Issue #250999 — Git - Unhelpful alert dialog when encountering pre-commit errors

[https://github.com/microsoft/vscode/issues/250999](https://github.com/microsoft/vscode/issues/250999)

## Summary

Team-authored issue (MEMBER) — keeping open. The git error handler's default case in commands.ts does not detect pre-commit hook failures, so the dialog shows a cryptic single-line excerpt with no indication that a hook caused the error.

## Change summary

When a git pre-commit hook fails, the VS Code error dialog shows a generic, unhelpful message with no indication the error came from a hook or how to debug it.

## Best solution

Add detection for hook failures in the error handler (extensions/git/src/commands.ts ~L5646 default case, or earlier via a new GitErrorCode in extensions/git/src/git.ts ~L329). Git stderr for hook failures typically contains 'hook' references — detect this pattern, show a targeted message explaining a pre-commit hook failed, include the hook's stderr output, and offer a 'Show Command Output' button (already wired) plus guidance about --no-verify.
