# Issue #250999 — Git - Unhelpful alert dialog when encountering pre-commit errors

[https://github.com/microsoft/vscode/issues/250999](https://github.com/microsoft/vscode/issues/250999)

## Summary

Keep open: the current Git error handler still reduces an unclassified commit failure to one output line without explaining the possible hook failure. Existing diagnostic buttons help, but do not fully address the report; neither related issue qualifies as a canonical duplicate under the re-review rules.

## Change summary

Make failed-commit dialogs explain the failure and clearly direct users to the complete diagnostics when a pre-commit check rejects their changes.

## Best solution

Improve failed-commit diagnostics in the built-in Git extension while retaining access to complete command output. Settle how the dialog should describe failures whose hook origin cannot be established reliably, rather than presenting arbitrary output as the explanation.
