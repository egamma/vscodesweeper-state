# Issue #276240 — When Copilot Code Review (CCR) no-ops, there's no notice to user as to why

[https://github.com/microsoft/vscode/issues/276240](https://github.com/microsoft/vscode/issues/276240)

## Summary

The silent no-op remains in current main: selection reviews return without feedback when there is no active editor or no enclosing scope can be resolved. The issue is already correctly routed to chat-review and should remain open for a bounded notification fix.

## Change summary

Copilot Code Review should explain why it cannot start when invoked without a usable editor selection or enclosing scope.

## Best solution

Preserve the existing enclosing-scope fallback, but provide a localized user-facing explanation when no review scope can be determined; intentional cancellation should remain silent.
