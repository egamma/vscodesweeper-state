# Issue #276240 — When Copilot Code Review (CCR) no-ops, there's no notice to user as to why

[https://github.com/microsoft/vscode/issues/276240](https://github.com/microsoft/vscode/issues/276240)

## Summary

Still present on main: when CCR selection resolution returns undefined (no editor, empty selection, no enclosing symbol), the code silently returns with no user feedback. PR #296444 attempted a fix but was closed without merging.

## Change summary

Invoking Copilot Code Review with no selection silently no-ops without informing the user why nothing happened.

## Best solution

Add a user-facing notification (information message or warning) in `doReview.ts` when the `resolveSelection` call returns `undefined` for a 'selection' group review, so the user understands they need to select code or open a file with reviewable content. The fix is localized to `extensions/copilot/src/extension/review/node/doReview.ts` around line 128-130.
