# Issue #345043 — Claude agent host: native (Anthropic-auth) models report no context window, so the context usage indicator can't show usage

[https://github.com/microsoft/vscode/issues/345043](https://github.com/microsoft/vscode/issues/345043)

## Summary

The missing native-Claude context limits remain visible in current source, and the widget can retain previously displayed usage when the next response has no usable limit. Keep this reopened report open for both accurate native context reporting and session-isolated display.

## Change summary

Show native Anthropic-authenticated Claude sessions' own context usage rather than no indicator or another session's retained usage.

## Best solution

Carry authoritative native-Claude context limits and current occupancy through the agent-host usage path, and ensure the indicator never retains another conversation's data when usage is unavailable. Establish the native SDK's context accounting semantics before treating cumulative turn-token totals as current context occupancy.
