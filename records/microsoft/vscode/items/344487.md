## Summary

The reported rendering and hover defects remain in current main: chat outline rows lack horizontal layout styling, and their labels receive no tooltip content. Keep this open as a bounded chat-outline bug.

## Change summary

Restore visible single-line prompt labels and full-prompt hovers in the Chat Outline while preserving request navigation.

## Best solution

Make Chat Outline rows consistently readable alongside their icons, with ellipsis for overflow and the full prompt available through the existing hover machinery. Preserve current label derivation, accessible names, and navigation behavior.
