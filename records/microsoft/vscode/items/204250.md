# Issue #204250 — Allow for sidebar panes to collapse downwards

[https://github.com/microsoft/vscode/issues/204250](https://github.com/microsoft/vscode/issues/204250)

## Summary

Valid feature request for configuring how sidebar pane collapse redistributes space. No implementation exists on main; the splitview has internal collapse-direction logic but no user-facing setting. Stays open under community discussion.

## Change summary

When a sidebar pane is collapsed, the freed space should go to the pane above (or a configurable 'primary' pane) rather than always to the pane below.

## Best solution

Add a configuration option (or change the default behavior) in the splitview/viewPaneContainer so that collapsing a pane redistributes space upward (to the first/primary pane) rather than downward. The relevant code is in `src/vs/base/browser/ui/splitview/splitview.ts` (resize distribution logic) and `src/vs/workbench/browser/parts/views/viewPaneContainer.ts`.
