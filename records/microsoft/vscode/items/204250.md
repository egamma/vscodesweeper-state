# Issue #204250 — Allow for sidebar panes to collapse downwards

[https://github.com/microsoft/vscode/issues/204250](https://github.com/microsoft/vscode/issues/204250)

## Summary

Verified duplicate: the older open #126523 tracks the same observable behavior—collapsing a view grows the lower pane instead of restoring space above—and already has an open fix PR specifically titled “Views should collapse downwards.”

## Change summary

Make collapsing sidebar panes restore space upward to the primary pane instead of enlarging panes below and gradually disturbing user-set heights.

## Best solution

Consolidate the sizing policy and implementation discussion on https://github.com/microsoft/vscode/issues/126523, then review and land or revise https://github.com/microsoft/vscode/pull/243558; this report's multi-pane size-drift scenario should remain part of that acceptance criteria.
