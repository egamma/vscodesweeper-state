# Issue #223383 — Debug console sticky scroll is much larger than its content

[https://github.com/microsoft/vscode/issues/223383](https://github.com/microsoft/vscode/issues/223383)

## Summary

Fixed on current main: tree sticky scroll now measures dynamically sized rows after rendering instead of retaining the debug console delegate's oversized word-wrap estimate.

## Change summary

Debug Console sticky scroll reserves substantially more vertical space than the wrapped content needs when displaying a large value.

## Best solution

Keep the generalized dynamic-height support added to tree sticky scroll in commit fdf686d3ea1ff5c371174e886962aa0a2ac4cdad; it addresses the debug console case without adding debug-specific rendering behavior.
