# Issue #223383 — Debug console sticky scroll is much larger than its content

[https://github.com/microsoft/vscode/issues/223383](https://github.com/microsoft/vscode/issues/223383)

## Summary

This remains a valid debug-console rendering bug: a maintainer confirmed that sticky scroll does not account for dynamically measured, word-wrapped row heights. The issue should stay open until sticky rows either support dynamic heights or deliberately render an equivalent compact representation.

## Change summary

Prevent a large, wrapped Debug Console value from producing a sticky-scroll row much taller than its visible content.

## Best solution

Make tree sticky scroll handle dynamically measured row heights, or define a Debug Console sticky-row rendering contract that disables wrapping without changing ordinary REPL row rendering. The user-visible choice between those behaviors should be settled before implementation.
