# Issue #295691 — Backspace deletes whole slash commands instead of single character

[https://github.com/microsoft/vscode/issues/295691](https://github.com/microsoft/vscode/issues/295691)

## Summary

Fixed on main: the aggressive token-deletion behavior was replaced in commit 0db3a09a296 (PR #307438, shipped in 1.115.0) with a narrower heuristic that only deletes the whole token on immediate backspace after a completion-based insertion — not when manually editing within a typed command.

## Change summary

Pressing backspace while typing a slash command in the Copilot chat input deleted the entire command instead of a single character.

## Best solution

Keep the shipped fix — the refactored ChatTokenDeleter in commit 0db3a09a296 now only triggers whole-token deletion on immediate backspace after an autocomplete insertion, so manually typed characters are deleted normally.
