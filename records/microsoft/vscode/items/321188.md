# Issue #321188 — `Detected unusual line terminators` should not pop up when cursoring through search results

[https://github.com/microsoft/vscode/issues/321188](https://github.com/microsoft/vscode/issues/321188)

## Summary

Real bug: navigating search results with arrow keys triggers the modal 'unusual line terminators' dialog for each file containing them, stealing keyboard focus and interrupting the workflow. The code in `unusualLineTerminators.ts` fires the check on every `onDidChangeModel` event, and search-result navigation changes the model for each result — the `readOnly` guard does not cover this path.

## Change summary

The modal 'Detected unusual line terminators' dialog fires disruptively when arrow-keying through search results that include files with unusual line terminators.

## Best solution

Suppress the dialog when the editor is in a transient/preview context (e.g. search result navigation) — either by checking whether the editor is a preview editor or by debouncing/skipping the check during rapid model changes. The reporter's suggestion to use a non-modal notification instead of a dialog is also worth considering. The fix belongs in `src/vs/editor/contrib/unusualLineTerminators/browser/unusualLineTerminators.ts`.
