# Issue #321188 — `Detected unusual line terminators` should not pop up when cursoring through search results

[https://github.com/microsoft/vscode/issues/321188](https://github.com/microsoft/vscode/issues/321188)

## Summary

The interruption remains possible in current source: previewing a search result can trigger the editor's modal unusual-line-terminator confirmation without checking editor focus. Keep this open as interaction polish; existing settings suppress the warning or automatically modify files, rather than providing the requested non-blocking warning.

## Change summary

Let users navigate search results without an unusual-line-terminator warning taking keyboard focus away from the results list.

## Best solution

Preserve uninterrupted search-result navigation while keeping unusual-line-terminator warnings discoverable and removal explicitly user-controlled. Decide whether warnings should become non-modal generally or remain deferred until the user enters the affected editor.
