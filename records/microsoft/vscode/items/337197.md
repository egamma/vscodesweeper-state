# Issue #337197 — Markdown editor: after Enter, the first CJK IME character is committed on the previous line and the caret jumps back

[https://github.com/microsoft/vscode/issues/337197](https://github.com/microsoft/vscode/issues/337197)

## Summary

Real, well-diagnosed defect, but the buggy code path (composition handling around `smartEnter`'s pending-paragraph materialization) lives inside the closed `@vscode/markdown-editor` npm package, not in this repo's vendored `editor.ts` wrapper — so it's an upstream dependency issue that needs the fix in that package before it can ship here.

## Change summary

In the built-in hybrid Markdown editor, pressing Enter and immediately typing with a CJK IME commits the first composed character (plus a line break) onto the previous line instead of the new one, with the caret jumping back.

## Best solution

Fix needs to land in the `@vscode/markdown-editor` package itself: guard `_handleTextUpdate`/`_handlePendingInput`/`materializePendingParagraph` against materializing the pending paragraph mid-composition (mirroring the existing `isComposing`/`_currentComposition` guards elsewhere in the same file), then bump the dependency version in `extensions/markdown-language-features/package.json`.
