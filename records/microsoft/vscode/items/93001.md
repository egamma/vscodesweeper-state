# Issue #93001 — resolving multiple tasks with type npm and same script fails

[https://github.com/microsoft/vscode/issues/93001](https://github.com/microsoft/vscode/issues/93001)

## Summary

Keep open for the earlier configuration diagnostic the maintainer committed to adding. Current source still silently overwrites npm task configurations with identical provider identities; the intentional identity model does not justify closing the accepted diagnostic work.

## Change summary

Explain conflicting npm task configurations before a task disappears from the picker or a dependency fails to resolve.

## Best solution

Report colliding provider-task identities during configuration loading, identifying the affected labels and explaining that different labels or execution options do not create distinct provider tasks. Preserve the existing identity contract; supporting independently runnable configurations of the same provider task would be separate design work.
