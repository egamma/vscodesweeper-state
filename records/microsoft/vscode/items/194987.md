# Issue #194987 — Merge editor should not trigger on save events (such as formatting)

[https://github.com/microsoft/vscode/issues/194987](https://github.com/microsoft/vscode/issues/194987)

## Summary

Complete Merge still invokes ordinary save participants, so the requested preservation of the reviewed result remains missing. Keep this accepted Backlog request open for the maintainer discussion about suppressing formatting alone versus other save-time transformations.

## Change summary

Prevent Complete Merge from introducing automatic formatting or other save-time edits that were not present in the reviewed merge result.

## Best solution

Complete Merge should persist the reviewed result without unexpected formatting changes while preserving normal save behavior outside merge completion. The merge-editor and text-file owners should settle whether this also excludes other save participants.
