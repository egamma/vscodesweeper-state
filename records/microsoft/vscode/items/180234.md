## Summary

Verified duplicate of the open canonical issue https://github.com/microsoft/vscode/issues/129178, which tracks the same macOS-specific iframe keyboard/clipboard shortcut problem in webviews. The reporter acknowledged the overlap in their first comment, and two other related issues (#212609, #236582) were already closed as duplicates of #129178.

## Change summary

Keyboard shortcuts (Cmd+C, Cmd+V, Cmd+A) and context menus do not work inside iframes embedded in WebviewPanel on macOS.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/129178, which is open with `help wanted` and tracks the identical macOS iframe-in-webview keyboard event problem. The context menu detail from this report is a symptom of the same root cause (events from the nested iframe never reach the outer webview/workbench on macOS) and is noted in #129178's discussion.
