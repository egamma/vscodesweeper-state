# Issue #311056 — When running tests, the pill icon background is rotating along with it's glyph

[https://github.com/microsoft/vscode/issues/311056](https://github.com/microsoft/vscode/issues/311056)

## Summary

The rotating pill background remains explained by current source: the testing activity badge applies the spinning icon classes and background to the same element. Keep this open; the older spinning-icon report concerns blurriness, not rotating badge backgrounds.

## Change summary

Running tests rotates the activity badge's pill background together with its loading glyph instead of rotating only the glyph.

## Best solution

Keep the activity badge's background and geometry stationary while its loading glyph animates, preserving existing badge colors, placement, and test-running state transitions.
