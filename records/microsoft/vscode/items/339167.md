# Issue #339167 — API for language model providers to supply a model icon

[https://github.com/microsoft/vscode/issues/339167](https://github.com/microsoft/vscode/issues/339167)

## Summary

Provider-tab icons are implemented, but the requested per-model identity icons remain unavailable on current main. Keep this open while the explicitly linked per-model implementation PR receives review.

## Change summary

Allow language model providers to supply per-model identity icons for model picker rows and the selected-model button.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/341579, including its proposed API and icon precedence, so aggregators can identify individual models without repurposing statusIcon. The merged provider-level contribution alone does not satisfy this request.
