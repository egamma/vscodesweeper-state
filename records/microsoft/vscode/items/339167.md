# Issue #339167 — API for language model providers to supply a model icon

[https://github.com/microsoft/vscode/issues/339167](https://github.com/microsoft/vscode/issues/339167)

## Summary

Thanks for the detailed proposal. This is a well-scoped extension-API request. I did not verify the current code, so this review rests on the issue text and the related-item context. A second extension author has confirmed the same need (OmniCopilot, 33 vendors and 186 models). No existing capability was verified. The linked issue 340979 is closed, so it cannot serve as a duplicate canonical. The issue should stay open and be routed to the chat/language model area for an API decision.

## Change summary

Let LanguageModelChatProvider extensions specify a per-model (and possibly per-vendor) icon for the chat model picker instead of always getting the generic sparkle.

## Best solution

Add an optional `iconPath` on `LanguageModelChatInformation` in the chatProvider proposed API, with precedence statusIcon > iconPath > vendor icon > built-in matching > sparkle. This needs `Uri` icon support in the picker's action list renderer. A vendor-level default on the `languageModelChatProviders` contribution point could follow.
