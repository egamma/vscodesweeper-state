# Issue #339167 — API for language model providers to supply a model icon

[https://github.com/microsoft/vscode/issues/339167](https://github.com/microsoft/vscode/issues/339167)

## Summary

Fresh, well-researched feature request with a concrete API proposal; current model-picker icon logic confirmed to only support `statusIcon` (for state) and built-in string matching, with no way for a provider to supply its own model icon.

## Change summary

Add an API (e.g. `iconPath` on `LanguageModelChatInformation`) letting language model providers supply a per-model icon for the chat model picker instead of relying on VS Code's hard-coded vendor-name matching.

## Best solution

Add an optional `iconPath` (or similar) property to `LanguageModelChatInformation` in the proposed `vscode.proposed.chatProvider.d.ts` API, with precedence `statusIcon` > `iconPath` > built-in matching > generic sparkle, as the reporter outlines; this is a new proposed-API surface so it should go through the API owners' design/finalization process.
