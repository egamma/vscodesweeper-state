# Issue #317168 — run_in_terminal async mode - thumbs up thumbs down / credit information shows mid session.

[https://github.com/microsoft/vscode/issues/317168](https://github.com/microsoft/vscode/issues/317168)

## Summary

Keep open: response feedback and credit details are gated on response completion, not completion of background terminal work, so the reported UX gap remains plausible on current main. This team-authored report has neither a verified fixing commit nor an eligible duplicate.

## Change summary

Defer response feedback and credit information while the associated async terminal job is still running.

## Best solution

Make response-footer presentation distinguish a finished model response from unfinished terminal work associated with it. Settle which background commands should delay the footer without making deliberately persistent servers hide feedback indefinitely.

- **Trace:**
