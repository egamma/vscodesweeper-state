# Issue #296895 — Bracket pair colourization pairs improperly for curly braces

[https://github.com/microsoft/vscode/issues/296895](https://github.com/microsoft/vscode/issues/296895)

## Summary

Verified duplicate: font ligatures merge adjacent braces into a glyph that cannot preserve each bracket's independent color. The open canonical issue tracks selective ligature control.

## Change summary

Preserve matching bracket-pair colors for consecutive curly braces when editor font ligatures are enabled.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/43440 to determine whether ligatures can be selectively disabled without harming editor performance. Disabling `editor.fontLigatures` is the current workaround.
