# Issue #269033 — Inline chat for a chat session model picker does not apply to delegated sessions

[https://github.com/microsoft/vscode/issues/269033](https://github.com/microsoft/vscode/issues/269033)

## Summary

Keep open: the inline controls should accurately describe the session receiving the request, and a maintainer acknowledged the need for better inline delegation treatment. Current inline chat has explicit session resolution and model-selection machinery, but the reported delegated-hunk mismatch remains unverified; the supplied scenario is sufficient to retest.

## Change summary

Make the inline model picker reflect the effective model when additional input is delegated to an existing chat session.

## Best solution

Ensure inline follow-up controls communicate the receiving session's effective model and do not offer ineffective choices. Preserve delegation to the existing session rather than changing request routing to accommodate the picker.
