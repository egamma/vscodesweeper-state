# Issue #296899 — Delegate to cloud agent always creates a PR to main/master, ignoring the currently checked-out branch

[https://github.com/microsoft/vscode/issues/296899](https://github.com/microsoft/vscode/issues/296899)

## Summary

Still reproduces on main: the no-confirmation delegation path calls `delegate()` without a `base_ref`, so the method falls back to the repo's default branch instead of the currently checked-out branch. The confirmation path correctly computes the base ref but the no-confirmation path does not.

## Change summary

When delegating to the cloud agent without a confirmation dialog, the PR always targets main/master instead of the user's currently checked-out branch.

## Best solution

In `chatParticipantImpl()`, compute `base_ref` via `checkBaseBranchPresentOnRemote()` before the no-confirmation `delegate()` call at line 2642 — the same way `handleConfirmationData()` does at lines 2146–2152 — so the current branch is used as the PR target.
