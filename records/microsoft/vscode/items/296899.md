# Issue #296899 — Delegate to cloud agent always creates a PR to main/master, ignoring the currently checked-out branch

[https://github.com/microsoft/vscode/issues/296899](https://github.com/microsoft/vscode/issues/296899)

## Summary

The no-confirmation delegation path still discards the checked-out branch and submits the repository's default branch on current main. Keep this report open; the matching newer report is related evidence, not a valid duplicate target for this re-reviewed issue.

## Change summary

Cloud delegation should use the current pushed branch as its base instead of silently targeting main or master.

## Best solution

Preserve the current repository's pushed branch through cloud task creation regardless of whether delegation requires confirmation. Retain the existing explicit default-branch fallback for an unpublished branch and avoid applying a local branch to a different selected repository.
