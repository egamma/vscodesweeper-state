# Issue #42544 — Support suppressing commit character from being inserted during completion

[https://github.com/microsoft/vscode/issues/42544](https://github.com/microsoft/vscode/issues/42544)

## Summary

A real API gap remains on current main: commit characters always accept the completion and are then typed. With 41 upvotes and a Backlog milestone, this established proposal should remain open.

## Change summary

Allow completion providers to accept a suggestion on a commit character without inserting that character.

## Best solution

Extend completion metadata with per-character insertion behavior and preserve it through the extension-host DTO and editor completion model; then make CommitCharacterController suppress typing when requested. Keep the broader conditional-edit request in https://github.com/microsoft/vscode/issues/70824 separate.
