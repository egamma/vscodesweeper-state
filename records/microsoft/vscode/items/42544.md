# Issue #42544 — Support suppressing commit character from being inserted during completion

[https://github.com/microsoft/vscode/issues/42544](https://github.com/microsoft/vscode/issues/42544)

## Summary

Keep open: the completion API still cannot accept a suggestion while suppressing insertion of its commit character. This is an API proposal tracking issue with 41 upvotes and an accepted maintainer direction, so closure belongs to the API owners.

## Change summary

Allow completion providers to specify commit characters that accept a suggestion without inserting the typed character.

## Best solution

Provide an explicitly opt-in completion API for suppressing commit-character insertion while preserving existing string-based behavior. Keep acceptance-dependent replacement text separate, as maintainers requested, and retain this tracking issue through API finalization.
