# Issue #183852 — New File: `alt+crtl+N` does not show that it requires `super` 

[https://github.com/microsoft/vscode/issues/183852](https://github.com/microsoft/vscode/issues/183852)

## Summary

Valid upstream Electron bug — native menus on Linux don't render the Super modifier in accelerator labels. VS Code's code correctly produces 'Super' in the ElectronAcceleratorLabelProvider, but Electron's GTK menu integration drops it. Team-authored, no fix found.

## Change summary

Native menus on Linux fail to display the Super key modifier in keybinding labels, while custom menus and Windows native menus render it correctly.

## Best solution

File or track an upstream Electron bug for GTK native menu accelerator rendering of the Super modifier. A VS Code-side workaround could fall back to isNative: false for keybindings involving Meta on Linux (showing the label inline rather than as an accelerator), but the proper fix belongs in Electron.
