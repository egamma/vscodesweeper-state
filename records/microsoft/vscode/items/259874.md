# Issue #259874 — setItemTree() is not consistent with the IQuickPick API that uses items

[https://github.com/microsoft/vscode/issues/259874](https://github.com/microsoft/vscode/issues/259874)

## Summary

The API inconsistency remains on current main: IQuickTree exposes setItemTree() and a readonly itemTree, whereas IQuickPick uses an assignable items property. Keep this maintainer-authored discussion open for the quick-input owner to settle the intended contract.

## Change summary

Align the QuickTree item-setting API with the property-based items API used by IQuickPick.

Settle a consistent item-assignment contract for IQuickTree and IQuickPick, including compatibility expectations for existing QuickTree callers. Keep this focused on API consistency rather than the separate selection, indentation, and separator requests.
