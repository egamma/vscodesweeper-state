## Change summary

For a newly added file, replace the current side-by-side diff view (empty left pane, green-highlighted right pane) with a single-pane view plus a small '(New file)' annotation next to the file name.

## Best solution

A maintainer on the SCM/diff-editor side should weigh in on whether added files should render as a single editor with an inline badge instead of a side-by-side diff with an empty original; likely touches the multi-diff editor's per-entry rendering (src/vs/editor/browser/widget/multiDiffEditor, src/vs/workbench/contrib/multiDiffEditor) and/or diffEditorOptions.ts for the renderSideBySide decision when the original model is empty.
