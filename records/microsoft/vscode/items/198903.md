# Issue #198903 — Changing actions.find's "when" to "editorFocus || !!editorIsOpen" creates a duplicate user shortcut that can't be removed

[https://github.com/microsoft/vscode/issues/198903](https://github.com/microsoft/vscode/issues/198903)

## Summary

Confirmed bug in the keybindings editor — modifying a default keybinding's 'when' clause creates a phantom negation entry that cannot be removed via the GUI. No fix has landed on main; the issue remains valid.

## Change summary

Editing a default keybinding's 'when' expression in the keyboard shortcuts GUI creates an undeletable duplicate user shortcut entry.

## Best solution

Fix the keybinding editing flow in `src/vs/workbench/services/keybinding/common/keybindingEditing.ts` so that the negation entry created by `removeDefaultKeybinding` (line 152) is properly tracked and removable/resettable through the keybindings editor UI. The `removeUserKeybinding` and `doResetKeybinding` methods need to handle this case where the entry is a negation (`-command`) paired with a new user override.
