# Issue #298406 — Add Remote Control Support to GitHub Copilot Chat

[https://github.com/microsoft/vscode/issues/298406](https://github.com/microsoft/vscode/issues/298406)

## Summary

Remote access to an ongoing local Agent Host chat is now implemented on main: VS Code can expose the local session through a tunnel for access from another machine or the configured Agents web surface.

## Change summary

Allow users to continue controlling a local Copilot Chat session from a browser, phone, or another machine while retaining its context.

## Best solution

Keep the shipped Remote Connections flow: users enable “Allow Remote Connections” from an Agent Host chat and connect through the configured Agents web surface or another machine.
