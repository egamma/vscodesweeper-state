# Issue #350479 — [Bug] `copilotConnectors` permanently hangs Agents UI

[https://github.com/microsoft/vscode/issues/350479](https://github.com/microsoft/vscode/issues/350479)

## Summary

Keep open: current source still blocks cold history restoration behind a deferred Connector startup restart. Related reports overlap, but do not fully cover the additional requirement that abandoned permission-waiting sessions cannot permanently prevent restart.

## Change summary

Opening idle, non-resident Copilot chats hangs indefinitely when Connector enablement changes while another chat remains awaiting permission.

## Best solution

Make idle conversation history readable independently of deferred runtime restarts, while preserving active turns and subagents. Establish safe abandonment handling for disconnected permission-waiting turns without treating every disconnect as cancellation.
