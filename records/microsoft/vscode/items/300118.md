# Issue #300118 — Feature Request: Mention Functions and Classes in Prompt Using @

[https://github.com/microsoft/vscode/issues/300118](https://github.com/microsoft/vscode/issues/300118)

## Summary

Legitimate, well-supported feature request (21 upvotes, promoted to Backlog) for a dedicated `@symbol` mention syntax in chat prompts; existing workarounds (drag-drop from breadcrumbs/outline, `#file` references, Add Context > Symbols) don't fully cover typing an inline mention, and the prior review's implemented-on-main claim was refuted by independent review, so this stays open.

## Change summary

Allow typing `@FunctionName` / `@ClassName` / `@Class.method` in chat input to directly attach that code symbol as context, instead of only describing it in plain text.

## Best solution

Keep tracking in Backlog; if pursued, extend the chat input's variable/attachment completion system (chatInputCompletions.ts, chatDynamicVariables.ts) to resolve workspace symbols by name for direct inline mention, complementing the existing `#file` and drag-drop symbol attachment flows — a maintainer should weigh this against existing `Add Context > Symbols...` coverage before committing to a new syntax.
