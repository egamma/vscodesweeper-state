# Issue #300118 — Feature Request: Mention Functions and Classes in Prompt Using @

[https://github.com/microsoft/vscode/issues/300118](https://github.com/microsoft/vscode/issues/300118)

## Summary

Basic @ symbol mentions are now implemented, but the requested class-qualified form remains unsupported by the inspected completion path. Keep this accepted, 21-upvote Backlog request open for the remaining symbol-disambiguation work rather than treating partial coverage as completion.

## Change summary

Allow prompt authors to reference functions and classes through @ mentions, including class-qualified methods that distinguish similarly named symbols.

## Best solution

Retain existing location-backed @ symbol references and support qualified discovery such as @MyClass.get_result, with enough containing-symbol information to distinguish methods with identical names in the same file.

- **Remaining qualified-name gap:** src/vs/workbench/contrib/chat/browser/widget/input/editor/chatInputCompletions.ts:1254-1308 builds symbol labels and filterText from symbolItem.name alone, with only the file URI as description. Consequently, a method named get_result inside MyClass is not offered through a MyClass.get_result filter, and identically named methods in the same file lack containing-class disambiguation.

The chat completion projection omits that information; the qualified example is therefore not covered merely by enabling the @ leader.
