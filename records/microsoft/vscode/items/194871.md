# Issue #194871 — Default context menu on IPad shows on top of the VSCode context menu

[https://github.com/microsoft/vscode/issues/194871](https://github.com/microsoft/vscode/issues/194871)

## Summary

Keep open: the evidence points to iPadOS Safari showing its pointer-device context menu despite cancellation, rather than an absent VS Code event guard. The older editor-only report is closely related but does not establish ownership of this report's workbench-wide, physical-right-click behavior.

## Change summary

Prevent the iPadOS system context menu from obscuring VS Code's context menu when using a mouse or keyboard-cover trackpad.

## Best solution

Resolve the Safari/WebKit native-menu cancellation behavior, then verify physical mouse right-clicks and trackpad secondary clicks across editor tabs and editor content. Preserve intentional native menus on input widgets; Escape remains a workaround, not a resolution.
