# Issue #280739 — `chat.tools.eligibleForAutoApproval` schema validation rejects legacy tool names

[https://github.com/microsoft/vscode/issues/280739](https://github.com/microsoft/vscode/issues/280739)

## Summary

Still open on main: the `_updateToolReferenceNames` method in `chat.shared.contribution.ts` only pushes `tool.toolReferenceName` into the schema enum, never `legacyToolReferenceFullNames`. The maintainer acknowledged this as a known limitation. Team-authored, On Deck — keep open.

## Change summary

Legacy tool names accepted at runtime by `chat.tools.eligibleForAutoApproval` are rejected by the JSON schema validator in the settings editor.

## Best solution

In `_updateToolReferenceNames()` (src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts ~line 2476), also push each tool's `legacyToolReferenceFullNames` entries into `toolReferenceNameEnumValues` (ideally with a deprecation-style description) so the settings editor validates them without error. Alternatively, relax the schema to allow additional string keys beyond the enum.
