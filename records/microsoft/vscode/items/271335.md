# Issue #271335 — Chat response: changes overview is counting wrong

[https://github.com/microsoft/vscode/issues/271335](https://github.com/microsoft/vscode/issues/271335)

## Summary

The incorrect file count remains source-reproducible on current main: finalized identical diffs stay in the displayed collection, so unchanged files contribute to the header count and receive list rows. The issue should remain open for a bounded fix and regression test.

## Change summary

Exclude unchanged files from the chat response changes overview so its file and line totals describe only actual edits.

## Best solution

The chat changes summary should omit finalized identical per-request diffs from both the header totals and expanded file list, while retaining genuinely changed files and appropriate in-progress behavior.
