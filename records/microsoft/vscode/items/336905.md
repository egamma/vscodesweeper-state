# Issue #336905 — Agents Web: Support workspace-less Quick Chats for remote Agent Hosts

[https://github.com/microsoft/vscode/issues/336905](https://github.com/microsoft/vscode/issues/336905)

## Summary

The web-client parity gap remains: remote providers support workspace-less chats, but the web composer excludes the No workspace option. Keep this request open; the related completed remote-host work does not cover the web entry point.

## Change summary

Allow starting a workspace-less Quick Chat on a remote Agent Host from the Agents web client.

## Best solution

Expose workspace-less chat creation for the selected remote host in the Agents web composer, preserving host scoping and existing folder-backed sessions. Reuse the provider's existing Quick Chat capability rather than introduce a separate remote session model.
