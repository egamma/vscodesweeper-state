# Issue #321636 — [Error] unhandlederror-Unexpected reasons: unknown,applyEdits

[https://github.com/microsoft/vscode/issues/321636](https://github.com/microsoft/vscode/issues/321636)

## Summary

Still present on current main and already has an open fix PR, so this stays open until that PR merges (or is closed); the `Unexpected reasons` assertion in ModelTracker still fires for any content-change event carrying more than one detailed reason.

## Change summary

Undo of an extension-applied edit produces a merged content-change event with reasons `unknown,applyEdits`, which trips the `Unexpected reasons` assertion in mainThreadDocuments and also means only the first detailed reason is forwarded to the extension host.

## Best solution

Land (or explicitly reject) https://github.com/microsoft/vscode/pull/321642 so merged multi-reason content changes are no longer reported as unexpected errors, and decide what `detailedReason` the extension host should receive for a merged event.
