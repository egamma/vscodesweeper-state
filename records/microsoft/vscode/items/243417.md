# Issue #243417 — [Shell Integration Error] bash: vsc_aa_env: bad array subscript

[https://github.com/microsoft/vscode/issues/243417](https://github.com/microsoft/vscode/issues/243417)

## Summary

The underlying bug — bash shell integration's env parsing breaks on exported multi-line bash functions — is still present on main but currently masked by `scopedDownShellEnvs` limiting reporting to a hardcoded set of env vars. A team member explicitly asked to keep this open until the env reporting is made general. The related fix PR #243673 was closed without merging.

## Change summary

Bash shell integration's `vsc_aa_env` array subscript errors when `env` output includes exported multi-line bash function definitions.

## Best solution

When `VSCODE_SHELL_ENV_REPORTING` is broadened beyond the current `scopedDownShellEnvs` set, the env parsing in `shellIntegration-bash.sh` must sanitize or skip multi-line entries (e.g. using `env -0` with NUL-delimited parsing, or filtering `BASH_FUNC_*` entries). The fix belongs in `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-bash.sh` around the `__vsc_update_env` / `__updateEnvCacheAA` functions.
