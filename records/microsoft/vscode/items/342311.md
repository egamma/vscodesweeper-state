# Issue #342311 — Agents Window: sticky tab-bar Add (+) button doesn't match tab pill styling

[https://github.com/microsoft/vscode/issues/342311](https://github.com/microsoft/vscode/issues/342311)

## Summary

Keep open as a bounded consistency improvement: current styling still gives the sticky Add control a separate visual treatment rather than matching adjacent tabs. The referenced earlier report concerns disappearing tabs, not this styling request.

## Change summary

Make the Agents Window Add tab control match the selected tab style, theme colors, and geometry while preserving its sticky positioning.

## Best solution

The Add control should use the same visual language as neighboring tabs in both pill and connected modes, including themed rest and hover states, without changing its menu behavior or horizontal-scroll availability.
