# Issue #341536 — "Automatic merge is on only while unchanged." is confusing

[https://github.com/microsoft/vscode/issues/341536](https://github.com/microsoft/vscode/issues/341536)

## Summary

Thanks for the report. The string "Automatic merge is on only while unchanged." is real and unclear: it describes the `ifUnchanged` merge policy, where Agent Merge merges only if it has not pushed changes itself. The wording reads as if merging is disabled, and "automatic merge" is not tied to Agent Merge. This is a copy/UX polish item that should stay open.

## Change summary

The Agent Merge summary and notice text is confusing: it is unclear whether Agent Merge is active, why a spinner is running, and what "automatic merge" refers to.

## Best solution

Reword the Agent Merge policy summaries in agentMerge.ts so each states plainly what Agent Merge does. For `ifUnchanged`, for example, "Agent Merge keeps monitoring and merges the pull request only if it hasn't made changes". Use consistent "Agent Merge" terminology, and make the default-settings-changed heading say what applies to the current session.
