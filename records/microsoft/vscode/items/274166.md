# Issue #274166 — Handle environment variables in file write detection

[https://github.com/microsoft/vscode/issues/274166](https://github.com/microsoft/vscode/issues/274166)

## Summary

Environment-variable destinations still are not resolved in file-write detection: current main conservatively requires approval instead. The linked merged PR explicitly implemented only part of this request, and no verified older canonical owns the remaining work.

## Change summary

Account for environment-variable expansion when detecting and classifying terminal file-write destinations such as `$HOME/file.txt`.

## Best solution

Make terminal file-write analysis classify destinations using trustworthy, shell-specific environment information while preserving explicit approval whenever the destination cannot be determined safely. Keep this issue separate from command-substitution support, which requires different evaluation semantics.
