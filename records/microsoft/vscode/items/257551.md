# Issue #257551 — Chat: Kept files are reset when switching back and forth via conversation history

[https://github.com/microsoft/vscode/issues/257551](https://github.com/microsoft/vscode/issues/257551)

## Summary

The lifecycle gap remains visible on current main: accepting all edits releases the model keepalive, but model disposal removes the editing session before the disposal listener can persist it. This team-authored bug must remain open, and no commit explicitly referencing https://github.com/microsoft/vscode/issues/257551 was found.

## Change summary

Keeping all agent-edited files is forgotten after switching to another conversation and back, causing the files to appear pending again.

## Best solution

Preserve each chat editing session's accepted/modified entry states before its model and editing session are disposed, then restore those states when conversation history reloads the session.
