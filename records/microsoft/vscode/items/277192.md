# Issue #277192 — Multiple diff editors for the same change

[https://github.com/microsoft/vscode/issues/277192](https://github.com/microsoft/vscode/issues/277192)

## Summary

Team-authored bug about duplicate diff editors opening for the same PR change when accessed through different entry points (chat, agent sessions, PR editor). Kept open per team-member policy; the underlying issue is likely an editor identity/deduplication problem in the PR file changes flow.

## Change summary

Opening the same PR file change from chat, agent sessions view, and the PR editor creates three separate diff editors instead of reusing one.

## Best solution

Ensure diff editors for the same `copilot-pr:` URI pair are deduplicated across entry points — likely by normalizing the editor input identity in the PR file changes service (`extensions/copilot/src/extension/chatSessions/vscode-node/pullRequestFileChangesService.ts`) or by using `revealIfOpened` / a shared editor input factory so that all three surfaces produce matching editor inputs for the same underlying change.
