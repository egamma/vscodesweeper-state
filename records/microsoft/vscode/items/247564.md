# Issue #247564 — Refine alt text: Corrupts the image tag

[https://github.com/microsoft/vscode/issues/247564](https://github.com/microsoft/vscode/issues/247564)

## Summary

Keep open: a maintainer reproduced the destructive edit, and current source still delegates the refinement to inline chat without constraining the edit to the Markdown alt-text brackets. The issue is team-authored, and the only same-symptom candidate is newer, so it cannot be the canonical duplicate for this re-review.

## Change summary

Refining existing Markdown image alt text can replace the complete image element with plain text.

## Best solution

Ensure the Copilot alt-text action can modify only the existing alt-text portion while preserving the Markdown image destination and syntax, with coverage for the reported Markdown input.
