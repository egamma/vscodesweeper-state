# Issue #126209 — Missed key presses and jumpy cursor in terminal when working remotely with high latency

[https://github.com/microsoft/vscode/issues/126209](https://github.com/microsoft/vscode/issues/126209)

## Summary

Keep this as the canonical local-echo reliability report. Disabling local echo by default mitigated the default experience, but the merged change explicitly addresses only part of this issue and does not repair prediction consistency; the reported command-display safety concern also rules out an automated close proposal.

## Change summary

High-latency remote terminal input can display missing characters, incorrect cursor positions, or command text that differs from what the shell executes when local echo is enabled.

## Best solution

Retain the off-by-default preview behavior until local echo reliably reconciles predictions with authoritative shell output. Keep this issue tracking the remaining correctness work, including fast typing, backspacing, and editing recalled commands.
