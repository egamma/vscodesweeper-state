# Issue #126209 — Missed key presses and jumpy cursor in terminal when working remotely with high latency

[https://github.com/microsoft/vscode/issues/126209](https://github.com/microsoft/vscode/issues/126209)

## Summary

The default-experience pain was mitigated by turning local echo off by default in 1.98 (commit 5c5cb3dc1fc, explicitly 'Part of #126209'), but the underlying local echo feature remains broken when enabled — the maintainer intentionally kept this open to track fixing local echo itself. With 42 upvotes and confirmed status, this should stay open.

## Change summary

Terminal local echo produces missed key presses, jumpy cursor, and buffer corruption on high-latency remote connections, potentially causing users to execute unintended commands.

## Best solution

The remaining work is to make local echo reliable enough to re-enable by default: implement eventual-consistency reconciliation (reconcile predicted state with server-acknowledged state), disable local echo automatically after prediction failures, and respect the ECHO termios mode. The fix area is `src/vs/workbench/contrib/terminalContrib/typeAhead/`. Until that work is prioritized, the current mitigation (off by default, preview tag) is adequate.
