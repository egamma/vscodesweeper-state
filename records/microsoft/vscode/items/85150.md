# Issue #85150 — Web: Comment View should listen to Gesture.Change event to scroll itself

[https://github.com/microsoft/vscode/issues/85150](https://github.com/microsoft/vscode/issues/85150)

## Summary

The touch-scrolling gap remains in current source: comment bodies support vertical scrolling but do not register for or handle `Gesture.Change` events.

## Change summary

Enable finger scrolling of comment threads in VS Code Web on iPadOS.

## Best solution

Register the comment body as a gesture target and translate `Gesture.Change` movement into its scroll position in `CommentNode.createScroll`, following the existing list-view implementation.
