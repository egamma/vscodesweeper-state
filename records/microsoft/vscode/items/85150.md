# Issue #85150 — Web: Comment View should listen to Gesture.Change event to scroll itself

[https://github.com/microsoft/vscode/issues/85150](https://github.com/microsoft/vscode/issues/85150)

## Summary

The built-in comment renderer still has a touch-scrolling gap: comment bodies use a custom scrollbar with native overflow hidden, but do not handle gesture changes. Keep this open for a bounded comments-widget fix; the related mobile Safari tracking issue is newer and is not a valid duplicate target for this re-reviewed report.

## Change summary

Finger gestures should scroll overflowing inline comment content in VS Code Web on iPadOS.

## Best solution

Make the built-in inline comment widget consume touch scrolling for its overflowing content while preserving wheel scrolling, comment editing, and surrounding editor navigation.
