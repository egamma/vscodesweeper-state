# Issue #275143 — Border offset error on clicking the pill of terminal command attached

[https://github.com/microsoft/vscode/issues/275143](https://github.com/microsoft/vscode/issues/275143)

## Summary

Still present on main. The terminal scroll-highlight-outline decoration uses character-cell-based width (`this._terminal.cols`) in `registerTemporaryDecoration`, but the actual rendered width may not reach the scrollbar due to how xterm.js decoration widths are computed relative to the viewport. The CSS has `right: 0` on `.terminal-scroll-highlight` but xterm decorations constrain element width to cell dimensions, so the CSS `right: 0` is overridden by the element's inline width.

## Change summary

The border outline for terminal command decorations (shown when clicking a terminal command pill in chat) stops short of the terminal scrollbar instead of spanning the full width.

## Best solution

In `registerTemporaryDecoration` in `markNavigationAddon.ts`, the decoration's rendered element width needs to be overridden to span the full terminal viewport width rather than relying on the character-cell-based `width: this._terminal.cols`. Either set the element's CSS width to `100%` or use `right: 0` positioning after ensuring the xterm decoration element allows it.
