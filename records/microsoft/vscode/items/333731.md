# Issue #333731 — [Weird design, Very Werid!!] This button is unclear, which leads to misunderstanding of whether I am archive or del. And they can absolutely be the independent buttons.

[https://github.com/microsoft/vscode/issues/333731](https://github.com/microsoft/vscode/issues/333731)

## Summary

The gray “Del” text is Archive’s keyboard shortcut, not a second delete button. Highlighting the action name and shortcut together is intentional menu behavior; permanent deletion is already a separate action with confirmation.

## Change summary

Make the chat-session Archive control clearly distinguish archiving from permanent deletion.

## Best solution

Keep Archive and Delete as separate commands and explain that “Del” identifies the key that invokes Archive. The existing “Delete...” context-menu action provides permanent deletion separately, so the reported row does not combine both operations.
