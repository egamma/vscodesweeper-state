Keep open: the supplied steps and worktree clarification suffice to retest unwanted startup saves. Remote-history restoration now uses a dedicated restorer and external-edit filtering, but the forced-save acceptance path remains; neither a complete current reproduction nor a fixing commit was established.

## Change summary

Restoring a past Copilot CLI worktree session triggers file saves, save participants, and unnecessary document activation without user action.

## Best solution

Restore historical worktree edits without treating them as newly accepted edits or invoking save participants. Preserve explicit acceptance behavior for local sessions, where running save participants is intentional.
