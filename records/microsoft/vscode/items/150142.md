# Issue #150142 — [CustomTextEditor extensions] Untitled document content is lost when doing "Reopen with..." custom text editor

[https://github.com/microsoft/vscode/issues/150142](https://github.com/microsoft/vscode/issues/150142)

## Summary

Fixed on main: commit 131fadee2b3 corrects the timing of the untitled text model revert so that untitled document data is properly delivered to the custom editor extension before reverting, shipped in 1.121.0.

## Change summary

Untitled document content is lost when using 'Reopen with...' to open it in a custom text editor.

## Best solution

Keep the shipped fix (commit 131fadee2b3, release 1.121.0). The revert of the untitled text model now happens after the extension receives the document data, preserving content during reopen-with.
