# Issue #306770 — Gituhb Copilot Chat: it's too easy to lose changes on ctrl+backspace

[https://github.com/microsoft/vscode/issues/306770](https://github.com/microsoft/vscode/issues/306770)

## Summary

Verified duplicate of the older open https://github.com/microsoft/vscode/issues/282004: both report that Ctrl+Backspace in an empty Chat input invokes the global undo flow and a subsequent typing key can confirm it, discarding pending file changes.

## Change summary

Prevent habitual Ctrl+Backspace use in an empty Chat input from triggering and accidentally confirming Undo All Edits.

## Best solution

Consolidate the reports on https://github.com/microsoft/vscode/issues/282004 and harden or remove the Ctrl+Backspace binding for `chatEditing.discardAllFiles` while focus is in the Chat input.
