# Issue #316528 — Option to open all links in Integrated Browser

[https://github.com/microsoft/vscode/issues/316528](https://github.com/microsoft/vscode/issues/316528)

## Summary

Keep open: current main still restricts automatic Integrated Browser link opening to localhost and all-interfaces addresses. The linked implementation was closed without merging, and no verified canonical issue absorbs this request.

## Change summary

Add an opt-in setting that automatically opens non-localhost HTTP(S) links in the Integrated Browser.

## Best solution

Provide explicit opt-in routing for non-localhost HTTP(S) links in the Integrated Browser opener, preserving existing localhost preferences and system-browser behavior when disabled.
