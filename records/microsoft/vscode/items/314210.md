# Issue #314210 — Changes should be closed when opening agentic browser to save space

[https://github.com/microsoft/vscode/issues/314210](https://github.com/microsoft/vscode/issues/314210)

## Summary

Current main hides Changes/Files while the integrated browser is active, giving the browser the requested space. The classic layout has been removed, making this behavior the desktop Agents window implementation rather than an optional layout.

## Change summary

Automatically hide the Changes panel when opening the agentic browser so the browser has more room.

## Best solution

Keep the current desktop behavior: browser tabs temporarily hide Changes/Files, while returning to a supported file or changes tab restores applicable details without overwriting explicit visibility preferences.
