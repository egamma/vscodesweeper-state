# Issue #176613 — Add a way back to OS file dialog from simple file dialog when possible

[https://github.com/microsoft/vscode/issues/176613](https://github.com/microsoft/vscode/issues/176613)

## Summary

Keep open: current main still lacks an in-dialog switch to the native OS picker for local files. A maintainer endorsed that direction, the reporter agreed, and an open PR already proposes the implementation.

## Change summary

Allow users to leave the simple file dialog for the native OS dialog when the filesystem and platform support it, without changing settings.

## Best solution
