# Issue #212720 — Illegal value for lineNumber

[https://github.com/microsoft/vscode/issues/212720](https://github.com/microsoft/vscode/issues/212720)

## Summary

This error-telemetry issue tracks the same 'Illegal value for lineNumber' crash in goToDefinitionAtPosition's preview-range code that was already fixed and verified via issue #205611. The fix (commit 8d21c9df9dc, validateRange call) clamps stale ranges before they reach getLineFirstNonWhitespaceColumn, and the caller's startLineNumber bounds check (lines 209–213) was already in place. Proposing as duplicate of the closed canonical.

## Change summary

Error telemetry: 'Illegal value for lineNumber' thrown in stripIndentationFromPreviewRange when a definition provider returns a range exceeding the target model's line count.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/205611 — the fix in commit 8d21c9df9dc validates the preview range against the model before iterating, which addresses exactly this crash path. If error telemetry still shows hits post-1.96, investigate whether a race between model changes and the async definition-result flow can bypass the guard.
