# Issue #229737 — repl multi-line input shrinks to 1 line after reloading editor

[https://github.com/microsoft/vscode/issues/229737](https://github.com/microsoft/vscode/issues/229737)

## Summary

Still reproduces on main: when the interactive editor is restored after switching tabs, the `setInput` layout path uses a hardcoded single-line height instead of the editor's actual content height, shrinking multi-line input.

## Change summary

Multi-line REPL input shrinks to 1 line after switching tabs and back because the restore layout uses a fixed single-line height.

## Best solution

In `interactiveEditor.ts` `setInput`, replace the use of `this.inputCellEditorHeight` at line 420 with the actual content height from the code editor widget (as `_layoutWidgets` already does at line 644), or simply call `_layoutWidgets` after the editor model is restored.
