# Issue #330385 — Markdown preview: code block copy button scrolls out of view on verticaly tall code blocks

[https://github.com/microsoft/vscode/issues/330385](https://github.com/microsoft/vscode/issues/330385)

## Summary

Real, well-diagnosed bug in the markdown preview's code-block copy button, and there's already an open PR from the same reporter fixing it — the right move is to review/land that PR, not close the issue yet.

## Change summary

In the Markdown preview, the code-block copy button (position: absolute, anchored to the pre) scrolls off-screen as soon as the top of a tall fenced code block scrolls past, leaving no way to copy without scrolling back to the top.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330494, which moves the scroll container from `pre` to `pre > code` and switches the button to `position: sticky` so it stays reachable while the block is on screen; once merged this issue closes as fixed.
