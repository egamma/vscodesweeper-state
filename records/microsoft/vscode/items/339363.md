# Issue #339363 — [Meta] Feedback on granular control over Copilot changes

[https://github.com/microsoft/vscode/issues/339363](https://github.com/microsoft/vscode/issues/339363)

## Summary

Thanks for collecting this. It is a team-authored feedback meta issue with heavy community engagement, parked in On Deck with the under-discussion label. It is a deliberately long-lived tracking item, so it stays open.

## Change summary

Central place to collect feedback on restoring granular per-change Keep/Undo controls for Copilot changes in chat.

## Best solution

Keep this open as the single feedback thread. The team should use it to decide whether to restore per-change Keep/Undo (for example in an editable diff or inline editor) in the Copilot harness. It should also decide whether to document the Local harness settings (chat.editor.localAgent.enabled, chat.defaultToCopilotHarness, chat.editor.preferCopilotHarness) as a supported opt-out. Enterprise admin blocking of the Local harness, raised in comment 25, also needs a decision.
