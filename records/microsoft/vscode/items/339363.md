## Summary

Keep this team-authored feedback umbrella open: it deliberately collects requirements for granular Copilot change review. The existing session working set improves file visibility but does not establish that incremental Keep/Undo and reviewed-state workflows are covered.

## Change summary

Collect requirements for inspecting, accepting, reverting, and tracking reviewed Copilot changes at granular and broader scopes.

## Best solution

Retain this central feedback thread while maintainers settle the review interaction and scope semantics, then track bounded implementation work separately. The resulting experience should support selective review and reversion without losing file context or obscuring which changes remain unreviewed.
