# Issue #349888 — Add Path Selection to Search

[https://github.com/microsoft/vscode/issues/349888](https://github.com/microsoft/vscode/issues/349888)

## Summary

Folder-scoped search already exists, but the requested folder-selection control within Search does not. Keep this open as a discoverability improvement rather than treating the existing Explorer action as full coverage.

## Change summary

Allow users to select, change, and clear a search directory directly from the Search interface.

## Best solution

Evaluate a folder-selection affordance that uses the existing Search include scope, without introducing a separate filtering model. Preserve typed include patterns and the Explorer's Find in Folder action.

- **Proposed comment:**

  > Thanks for the request. You can already restrict a search by expanding Search Details and entering a folder such as `./src` in **files to include**, or by right-clicking a folder in Explorer and choosing **Find in Folder...** (`filesExplorer.findInFolder`). Clearing **files to include** removes that restriction. A folder picker directly within Search would be an additional discoverability improvement.
