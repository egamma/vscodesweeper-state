# Issue #349888 — Add Path Selection to Search

[https://github.com/microsoft/vscode/issues/349888](https://github.com/microsoft/vscode/issues/349888)

## Summary

The central request is already supported: Search has a control exposing an editable folder scope, and Explorer provides Find in Folder. The scope can be changed or cleared without adding another search-bar control.

## Change summary

Provide a selectable folder scope for workspace search that users can change or clear.

## Best solution

Use the existing Toggle Search Details control and files to include field, or Explorer's Find in Folder command, to select and manage the search scope.

- **Fit:** aligned
- **Reason:** Discoverable folder-scoped search supports productive navigation of large projects using existing workbench controls.

- **Proposed comment:**

  > Thanks for the request. Folder-scoped search is already available through the **… (Toggle Search Details)** control (`workbench.action.search.toggleQueryDetails`): enter a path such as `./src/components` in **files to include**, change it to search another folder, or clear it to restore the workspace scope. You can also right-click any folder in Explorer and choose **Find in Folder…** (`filesExplorer.findInFolder`) to populate that scope without typing the path.

## Evidence

- **Existing search-bar control:** src/vs/workbench/contrib/search/browser/searchView.ts:505–550 creates Toggle Search Details (workbench.action.search.toggleQueryDetails), which exposes the files to include field and accepts directory patterns.
- **Folder selection command:** src/vs/workbench/contrib/search/browser/searchActionsFind.ts:260–288 registers filesExplorer.findInFolder in the Explorer folder context menu. searchWithFolderCommand resolves selected directories and passes their paths to SearchView.searchInFolders.
- **Changeable and clearable scope:** src/vs/workbench/contrib/search/browser/searchView.ts:1565–1586 populates the editable include field with selected folder paths and clears it for an unrestricted scope. src/vs/workbench/services/search/common/queryBuilder.ts:234–247 builds folder queries from supplied search paths instead of the workspace roots.
- **Documented capability:** https://code.visualstudio.com/docs/editing/codebasics#_advanced-search-options documents Toggle Search Details, directory paths such as ./example in files to include, and Explorer's Find in Folder command. These cover folder-scoped searching without a separate folder-picker dialog.
