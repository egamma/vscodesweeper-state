# Issue #189924 — Git - VScode force changes the locale to en_US.UTF-8 for git commit hooks in dev-container

[https://github.com/microsoft/vscode/issues/189924](https://github.com/microsoft/vscode/issues/189924)

## Summary

The built-in Git extension still overrides the subprocess locale with en_US.UTF-8, breaking hooks on systems without that locale. Keep this open while the existing fixing PR is reviewed.

## Change summary

Git commits from the Source Control UI force an unavailable locale into commit hooks, causing failures that do not occur when committing from the terminal.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/210506 so Git subprocesses use a supported locale while preserving predictable Git output and UTF-8 compatibility. Include minimal-container hook behavior and cross-platform locale availability in that review.
