# Issue #210990 — API to provide a terminal for use with `run-in-terminal` request

[https://github.com/microsoft/vscode/issues/210990](https://github.com/microsoft/vscode/issues/210990)

## Summary

Valid feature request from the Python debugger team for a debug terminal provider API. Not yet implemented — no proposed API, no commits referencing this issue, and no related work on main. Team-authored and milestoned On Deck; keeping open.

## Change summary

Allow debug extensions to provide a pre-configured (e.g. Python-activated) terminal for `runInTerminal` requests instead of relying on VS Code's default terminal creation.

## Best solution

Design and ship a proposed API such as `vscode.debug.registerDebugTerminalProvider(debugType, provider)` that lets debug extensions supply a terminal for `runInTerminal`. The implementation would live in `src/vs/workbench/contrib/debug/` (the `runInTerminal` path in `rawDebugSession.ts` and the debug adapter manager) and a new proposed API declaration in `src/vscode-dts/`. Gauge demand from other debug extension authors beyond Python before finalizing.
