# Issue #210990 — API to provide a terminal for use with `run-in-terminal` request

[https://github.com/microsoft/vscode/issues/210990](https://github.com/microsoft/vscode/issues/210990)

## Summary

Team-authored feature request for a debug terminal provider API — not yet implemented on main. Hard keep-open (MEMBER author).

## Change summary

Allow extensions to provide a pre-configured terminal (e.g. with Python environment activation) for use with DAP `runInTerminal` requests.

## Best solution

Implement an API like `vscode.debug.registerDebugTerminalProvider(debugType, provider)` that lets extensions supply a terminal for `runInTerminal` requests. The work belongs in the debug API surface (`src/vs/workbench/api/`) and the debug adapter host terminal integration. Python's complex environment activation is the motivating use case; the API design should be general enough for other debug adapters but may remain niche.
