# Issue #340690 — Markdown editor: Paste warning overlaps document content and remains after placing caret

[https://github.com/microsoft/vscode/issues/340690](https://github.com/microsoft/vscode/issues/340690)

## Summary

Thanks for the detailed report. The source matches it: the paste warning uses the shared bottom-anchored `.md-language-status` style, and a single message covers both read-only mode and a missing caret. Keeping it open as a bounded bug in the Markdown editor.

## Change summary

The Markdown editor's paste warning overlaps document content, stays visible after a caret is placed, and tells the user to switch to editing mode even when editing is already on.

## Best solution

Show the paste warning in reserved space instead of absolutely positioned over the document. Use separate wording for read-only mode and for a missing caret. Hide the warning when the caret is placed or the mode changes.
