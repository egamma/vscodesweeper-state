# Issue #185647 — Virtualize global viewport (not just the editor view port)

[https://github.com/microsoft/vscode/issues/185647](https://github.com/microsoft/vscode/issues/185647)

## Summary

Keep open: current editor virtualization still uses the editor's own dimensions, while stacked diff editors use specialized host-managed virtualization rather than general global-viewport support. No verified canonical or issue-referencing fix establishes completion of this team-authored request.

## Change summary

Virtualize content-height Monaco editors against their externally visible viewport, with coordinated parent scrolling and visible widget placement.

## Best solution

Define a supported editor-core contract for externally scrolling, stacked editors that bounds rendering to visible content and preserves scrolling, focus, and widget behavior. Reuse the multi-diff experience as design evidence without treating its specialized implementation as completion of the general Monaco capability.
