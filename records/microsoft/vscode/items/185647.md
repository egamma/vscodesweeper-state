# Issue #185647 — Virtualize global viewport (not just the editor view port)

[https://github.com/microsoft/vscode/issues/185647](https://github.com/microsoft/vscode/issues/185647)

## Summary

Current main implements viewport-aware virtualization for the multi-diff editor, but not as the general Monaco capability requested here. Because this is team-authored and no fixing commit or closing PR references this issue, it must remain open.

## Change summary

Let Monaco render only the lines visible in an enclosing global viewport, enabling performant stacked editors and diff editors.

## Best solution

Extract or formalize the multi-diff editor's viewport coordination as reusable editor-core support for externally scrolled Monaco editors, including widget placement and scroll propagation. If the bespoke multi-diff implementation is considered sufficient, a maintainer should explicitly resolve this issue.
