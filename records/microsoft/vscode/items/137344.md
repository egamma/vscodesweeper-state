# Issue #137344 — "Check for Update" does not behave as expected

[https://github.com/microsoft/vscode/issues/137344](https://github.com/microsoft/vscode/issues/137344)

## Summary

Valid feature request still unimplemented on main: when update mode is 'manual' on macOS, 'Check for Updates' immediately triggers Electron's auto-download rather than first presenting the user with a choice. The infrastructure to check without downloading exists (used for metered connections) but is not wired for the explicit manual-check path.

## Change summary

On macOS with update mode set to 'manual', clicking 'Check for Updates' should inform the user an update is available and let them choose to download, rather than immediately auto-downloading.

## Best solution

In `updateService.darwin.ts#doCheckForUpdates`, when `explicit` is true and update mode is 'manual', use the existing `checkForUpdateNoDownload` path (currently only used for metered connections) to transition to `AvailableForDownload` state instead of calling `electron.autoUpdater.checkForUpdates()`. The UI already handles `AvailableForDownload` with a 'Download Update' action.
