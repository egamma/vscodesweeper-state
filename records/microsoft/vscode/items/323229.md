## Summary

Keep open: the Markdown language service still extracts bracketed math as reference links, and an older upstream issue tracks the same diagnostic. The report supplies sufficient reproduction steps; upgrading alone is not evidence of a fix.

## Change summary

Prevent Markdown link validation from reporting missing reference definitions for square brackets inside math expressions.

## Best solution
