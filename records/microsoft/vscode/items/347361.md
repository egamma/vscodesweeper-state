# Issue #347361 — Can't drag text into rename textboxes

[https://github.com/microsoft/vscode/issues/347361](https://github.com/microsoft/vscode/issues/347361)

## Summary

Keep open: the report provides enough detail to retest text drops into Explorer naming inputs. Current main uses a shared inline input inside the Explorer tree; source inspection identifies competing drag handling but does not conclusively establish the runtime failure or a fix.

## Change summary

Dragging text into Explorer file and folder creation or rename inputs does not insert it.

- **Trace:**

  > Explorer naming inputs are constructed by FileRenderer.renderInputBox in src/vs/workbench/contrib/files/browser/views/explorerViewer.ts using InlineEditInputBox from src/vs/workbench/browser/parts/views/inlineEditInputBox.ts. The shared input handles input and blur events without dedicated drag/drop handlers. Its containing ListView handles bubbling dragover events in src/vs/base/browser/ui/list/listView.ts and delegates acceptance to FileDragAndDrop, whose native path requires file/resource transfer types. Inspection does not establish whether rejection, an ancestor handler, or focus changes prevent insertion; begin by reproducing and observing the actual event sequence.
