# Issue #127498 — Interactive window and debug console should use same widget for input

[https://github.com/microsoft/vscode/issues/127498](https://github.com/microsoft/vscode/issues/127498)

## Summary

The requested higher-level input component has not been consolidated: both surfaces share CodeEditorWidget but retain separate history, options, and layout integration. Keep this as debt pending a concrete reuse benefit; the discussion questions whether extraction is worthwhile and explicitly warns against changing history-navigation behavior.

## Change summary

Extract reusable input functionality shared by the Interactive Window and Debug Console while retaining their appropriate behavior.

## Best solution

Identify substantial duplicated input logic before introducing another shared abstraction, and preserve each surface's established history-navigation semantics. Any consolidation should remain narrower than the composite editor and output-viewer architecture suggested in the early discussion.
