# Issue #261897 — Find and Search/Find in Files with selection from Terminal doesn't do regex escaping

[https://github.com/microsoft/vscode/issues/261897](https://github.com/microsoft/vscode/issues/261897)

## Summary

Confirmed on current main: terminal selection is passed as-is to both the terminal find widget and Find in Files without regex escaping, while the editor paths properly escape via `strings.escapeRegExpCharacters()`. A maintainer acknowledged the bug and noted they'd work on a fix.

## Change summary

When regex mode is active, selecting text containing regex special characters in the terminal and pressing Ctrl+F or Ctrl+Shift+F populates the search input with an invalid regex, whereas the same flow from the editor properly escapes the selection.

## Best solution

Add `escapeRegExpCharacters()` guards in two places: (1) in `terminalFindWidget.ts` `reveal()` and `show()` methods when `_getRegexValue()` is true, escape `initialInput` before passing it to the find widget; (2) in `terminal.find.contribution.ts` line 251, escape `activeInstance.selection` before passing it as `query` to `findInFilesCommand` (or let the search view handle it, mirroring `updateTextFromSelection`).
