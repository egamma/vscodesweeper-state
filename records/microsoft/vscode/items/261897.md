# Issue #261897 — Find and Search/Find in Files with selection from Terminal doesn't do regex escaping

[https://github.com/microsoft/vscode/issues/261897](https://github.com/microsoft/vscode/issues/261897)

## Summary

The defect remains in current source: terminal selections bypass regex escaping in both Terminal Find and Find in Files. Keep this reopened issue open; the reporter's clarified reproduction identifies a bounded inconsistency with editor-selection search.

## Change summary

Escape regex metacharacters when terminal selections seed Terminal Find or Find in Files with regex mode enabled.

## Best solution

Make terminal-selection search preserve the selected text literally, matching editor-selection behavior while retaining the destination's regex mode. Preserve intentional regex input supplied by typing, pasting, or explicit command arguments.
