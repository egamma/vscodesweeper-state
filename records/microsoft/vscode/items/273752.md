# Issue #273752 — NES obscures cursor

[https://github.com/microsoft/vscode/issues/273752](https://github.com/microsoft/vscode/issues/273752)

## Summary

The cursor-obscuring behavior remains source-reproducible on main: deletion previews are overlay widgets rendered above the editor cursor layer. The existing Backlog placement and NES labels are appropriate.

## Change summary

Render the NES deletion border beneath the text cursor so the caret remains visible while a deletion preview is shown.

## Best solution

Preserve the current deletion-preview appearance while placing its border and background below the caret, without changing normal cursor stacking or the rendering of insertion and side-by-side previews.
