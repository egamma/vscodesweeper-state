# Issue #273752 — NES obscures cursor

[https://github.com/microsoft/vscode/issues/273752](https://github.com/microsoft/vscode/issues/273752)

## Summary

Keep open: the deletion preview still renders its border above the editor cursor, and the maintainer explicitly agrees that the cursor should remain on top. No fixing commit or eligible open duplicate was established.

## Change summary

A Next Edit Suggestion deletion border obscures the editor cursor where they overlap.

## Best solution

Preserve cursor visibility over NES deletion highlighting while retaining the preview's border, deletion indication, and scrolling behavior. Establish a rendering-level regression check before changing the layering; model-state tests alone cannot verify this outcome.
