# Issue #330693 — Experimental Modern UI enabled by default without user consent - unacceptable

[https://github.com/microsoft/vscode/issues/330693](https://github.com/microsoft/vscode/issues/330693)

## Summary

This is a legitimate policy complaint about the team's A/B-style experiment rollout mechanism (workbench.experimental.modernUI has `experiment: { mode: 'auto' }` in src/vs/workbench/browser/workbench.contribution.ts) silently flipping an experimental default for some Stable users — a deliberate maintainer-built mechanism, not a bug, and one only the team can decide to change.

## Change summary

Requests that experimental UI redesigns (specifically the Modern UI A/B experiment) stay opt-in on Stable rather than being silently enabled by default via an auto-experiment.

## Best solution

This is a product/process decision for the workbench team: whether the auto-experiment mechanism should require explicit opt-in for visually disruptive changes, and whether a one-click revert/notification should accompany such rollouts. It overlaps with several open Modern UI feedback threads and should be judged together with them rather than closed individually.
