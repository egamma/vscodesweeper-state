# Issue #330693 — Experimental Modern UI enabled by default without user consent - unacceptable

[https://github.com/microsoft/vscode/issues/330693](https://github.com/microsoft/vscode/issues/330693)

## Summary

Keep open for a product decision on Stable UI transitions: existing settings allow opting out, but do not satisfy the request for opt-in activation or an obvious transition-time choice. The 47 upvotes and supporting discussion demonstrate demand; the related interface roadmap does not resolve that remaining request.

## Change summary

Make experimental Stable UI redesigns opt-in and communicate major default changes with an obvious way to retain the previous interface.

## Best solution

Agree on a predictable Stable UI transition contract that preserves explicit preferences and makes significant changes and available alternatives discoverable. Resolve the consent and notification requirements alongside the announced Modern UI transition, rather than treating disabling the setting as full coverage.
