# Issue #326119 — Stuttering due to missing commit information.

[https://github.com/microsoft/vscode/issues/326119](https://github.com/microsoft/vscode/issues/326119)

## Summary

The request for guidance when committing without a message is covered by an older, verified open issue about the commit-message editor's unclear workflow. The source shows the commit deliberately waiting for that editor to close, rather than establishing a UI freeze.

## Change summary

Explain that submitting a commit with an empty message opens an editor where the message must be entered and the commit completed.

## Best solution

Consolidate the guidance request into https://github.com/microsoft/vscode/issues/199097, including this Windows report of the waiting operation appearing frozen. Make the editor's purpose and completion action clear without removing editor-based commit authoring.

- **Canonical discussion:** https://github.com/microsoft/vscode/issues/199097#issuecomment-1826424233 points to an editor-banner suggestion; https://github.com/microsoft/vscode/issues/199097#issuecomment-2043505205 independently confirms that the workflow is confusing.
- **Existing capability and intentional wait:** extensions/git/package.json registers git.useEditorAsCommitInput with default true. In extensions/git/src/commands.ts, commitWithAnyInput skips the message input prompt when that setting is enabled, and smartCommit permits the editor-based commit. GitEditor.handle in extensions/git/src/gitEditor.ts opens the message document and resolves its promise when its tab closes; git.commitMessageAccept closes that tab. This explains a pending commit but does not demonstrate a UI deadlock.
- **Partial workaround, not coverage:** Setting git.useEditorAsCommitInput to false makes commitWithAnyInput show an input box with 'Please provide a commit message'. The editor also exposes git.commitMessageAccept as 'Commit'. Neither supplies the requested explanation within the default editor-based workflow, so the capability check does not justify an as-designed close.
