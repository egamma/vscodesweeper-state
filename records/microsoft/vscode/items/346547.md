# Issue #346547 — Debugger does not auto-select source-less stopped frame unless stop reason enables instruction-pointer selection

[https://github.com/microsoft/vscode/issues/346547](https://github.com/microsoft/vscode/issues/346547)

## Summary

Current source confirms that ordinary stop reasons leave a source-less instruction-pointer frame unselected. Keep this correctly routed debugger issue open; automatic disassembly opening is a separate product-policy question.

## Change summary

Select a valid source-less stopped frame without requiring the adapter to misreport an instruction breakpoint.

## Best solution

Make stopped-frame context available while preserving existing source-frame preferences and accurate stop reasons. Decide separately whether source-less stops should automatically open disassembly or leave navigation explicit.
