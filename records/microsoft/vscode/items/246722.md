# Issue #246722 — Go to Symbol in Workspace: Add a new setting to exclude symbols provided by dependencies

[https://github.com/microsoft/vscode/issues/246722](https://github.com/microsoft/vscode/issues/246722)

## Summary

Keep open in the Backlog: the request passed the 20-upvote threshold, remains unimplemented generically, and affects workspace-symbol navigation across AL, C++, and generated TypeScript sources.

## Change summary

Add a workspace-symbol search mode or setting that excludes dependency, generated, or otherwise unwanted symbols.

## Best solution

Add a workspace-only or configurable exclusion mode to workspace-symbol quick access, and let providers receive that intent so they can avoid computing excluded results rather than relying solely on UI post-filtering.

- **Reason:** Making core symbol navigation usable in dependency-heavy projects advances the developer inner loop and workbench usability without adding always-on UI.

- **current source gap:** src/vs/workbench/contrib/search/common/search.ts returns symbols from every registered provider, while src/vs/workbench/contrib/search/browser/symbolsQuickAccess.ts applies no dependency or path exclusion in the dedicated workspace-symbol picker.
