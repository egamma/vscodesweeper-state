# Issue #154977 — onDidChangeTextEditorVisibleRanges shows strange behaviour!

[https://github.com/microsoft/vscode/issues/154977](https://github.com/microsoft/vscode/issues/154977)

## Summary

The report contains a concrete reproduction and independent extension impact, and no discussion establishes that the inconsistent missing, provisional, and duplicate visible-range events are intentional or fixed. It should remain open for current-version confirmation and editor API investigation.

## Change summary

Make onDidChangeTextEditorVisibleRanges report a consistent final visible range when opening or switching editors, without missing the initial change or emitting a misleading provisional range.

## Best solution

Define the event's activation and restoration semantics, then ensure the editor-to-extension-host bridge emits one stable notification when a newly opened or restored editor reaches its actual visible range; retain later notifications only for genuine range changes.
