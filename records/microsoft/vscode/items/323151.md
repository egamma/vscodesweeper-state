# Issue #323151 — Allow opening the Merge Editor for multiple selected files simultaneously

[https://github.com/microsoft/vscode/issues/323151](https://github.com/microsoft/vscode/issues/323151)

## Summary

Keep open as a feature request: the Merge Changes context menu still lacks a selection-aware action for opening merge-editor tabs. Existing merge-editor settings and commands provide pieces of the workflow, but do not fully cover the requested interaction.

## Change summary

Allow multiple conflicting files selected in Source Control to be opened together as separate Merge Editor tabs.

## Best solution

Provide a selection-aware Resolve in Merge Editor action in the Merge Changes context menu that opens each eligible selected conflict in a retained tab, preserving existing single-file behavior.
