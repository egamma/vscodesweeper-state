# Issue #318739 — Copilot inline suggestions override or slow down snippets

[https://github.com/microsoft/vscode/issues/318739](https://github.com/microsoft/vscode/issues/318739)

## Summary

Keep open to distinguish the intentional quick-suggestions default from the reported unresolved snippet suppression and delay. Independent confirmations include VS Code 1.140.0, and no verified fix or canonical issue fully covers the remaining report.

## Change summary

Copilot inline suggestions suppress automatic snippet suggestions or delay their appearance, including when no inline suggestion ultimately appears.

## Best solution

Establish whether the remaining failures occur with editor.quickSuggestions.other explicitly set to "on", then address any unintended suppression or delay in the editor suggest/inline-completion interaction. Preserve the configurable default behavior rather than treating its existence as proof that every reported failure is intentional.
