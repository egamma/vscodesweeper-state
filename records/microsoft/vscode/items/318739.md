# Issue #318739 — Copilot inline suggestions override or slow down snippets

[https://github.com/microsoft/vscode/issues/318739](https://github.com/microsoft/vscode/issues/318739)

## Summary

Verified duplicate: the broader open canonical issue tracks the intentional `editor.quickSuggestions.other` default change and its effect on automatically shown IntelliSense and snippets. This report adds useful snippet-delay evidence but no distinct remaining behavior.

## Change summary

Restore immediate snippet suggestions alongside Copilot inline completions instead of suppressing or delaying the suggest widget.

## Best solution

Consolidate feedback and any reconsideration of the default behavior in https://github.com/microsoft/vscode/issues/317863. Users who prefer simultaneous automatic suggestions can set `editor.quickSuggestions.other` to `on`.
