# Issue #264957 — Ctrl-P text navigation shortcut does not work inside webview on macOS

[https://github.com/microsoft/vscode/issues/264957](https://github.com/microsoft/vscode/issues/264957)

## Summary

Confirmed on current main: the `isPrint` function in the webview pre/index.html treats Ctrl+P as print on all platforms, but on macOS only Cmd+P should trigger print — Ctrl+P is the standard emacs previous-line shortcut. An open PR (#285015) exists.

## Change summary

Ctrl+P is swallowed by the webview iframe script on macOS instead of passing through for emacs-style text navigation.

## Best solution

Land a fix in `isPrint()` (src/vs/workbench/contrib/webview/browser/pre/index.html) to check `e.metaKey` only on macOS for the print shortcut, letting `Ctrl+P` pass through for text navigation. Review and merge PR #285015 or an equivalent.
