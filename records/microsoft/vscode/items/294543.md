# Issue #294543 — GPT models always read every instruction file

[https://github.com/microsoft/vscode/issues/294543](https://github.com/microsoft/vscode/issues/294543)

## Summary

The prompt wording that caused GPT models to eagerly read all instruction files was improved in commit 51d818fec64 (shipped in 1.118.0), explicitly instructing models to only load relevant files. A subsequent commit (fd7f7ce0e1d) further addressed GPT-specific behavior by disabling the readFile tool for GPT models. This can be closed as completed.

## Change summary

GPT models eagerly read every instruction file via tool calls regardless of applyTo patterns, wasting tokens and requiring unnecessary tool approvals.

## Best solution

Keep the shipped prompt improvements from commits 51d818fec64 and fd7f7ce0e1d; no further change is needed. The reporter should confirm on a current build (1.118.0+).
