# Issue #312749 — Can't copy text in integrated terminal on Safari (Code Server Web on VM)

[https://github.com/microsoft/vscode/issues/312749](https://github.com/microsoft/vscode/issues/312749)

## Summary

Still reproduces on main: on Safari over insecure origins (HTTP), the WebKit clipboard workaround sets `webKitPendingClipboardWritePromise` on every click/keydown, causing `writeText` to early-return at line 138 and never reach the `fallbackWriteText` textarea/execCommand path — so copy silently fails.

## Change summary

Copying text from the integrated terminal on Safari over insecure origins (HTTP code-server) silently fails because the WebKit clipboard workaround prevents the fallback clipboard path from executing.

## Best solution

Guard the WebKit workaround installation (`installWebKitWriteTextWorkaround`) so it is skipped when `navigator.clipboard` is unavailable (insecure origins), allowing `writeText` to fall through to `fallbackWriteText`. Alternatively, guard the early return at line 134–138 to check whether `navigator.clipboard` is actually available before completing the deferred promise. The reporter has a draft fix ready as a PR.
