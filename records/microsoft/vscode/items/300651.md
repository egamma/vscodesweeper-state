# Issue #300651 — [Feature Request] Copilot Chat: "New chat with context" command to recover from corrupted conversations

[https://github.com/microsoft/vscode/issues/300651](https://github.com/microsoft/vscode/issues/300651)

## Summary

Valid feature request with two parts: (1) a 'New Chat with Context' command to recover from corrupted conversations, and (2) auto-sanitization of broken messages on retry. Related to but distinct from #261978, which tracks selective message moving for context management — this issue's error-recovery angle (auto-stripping empty content blocks that cause 400 errors) is not covered there. Keeping open for triage.

## Change summary

Add a mechanism to recover from corrupted Copilot Chat conversations where empty content blocks cause unrecoverable 400 errors, either by sanitizing messages or starting a new chat pre-populated with valid history.

## Best solution

The auto-sanitize-on-retry part (stripping empty/whitespace-only content blocks before resending) is the highest-value, most self-contained fix — it would prevent the unrecoverable loop without requiring a new command surface. This likely belongs in the Copilot extension's request pipeline (extensions/copilot). The broader 'New Chat with Context' UX overlaps with https://github.com/microsoft/vscode/issues/261978 and could be consolidated there once that work is planned.
