# Issue #300651 — [Feature Request] Copilot Chat: "New chat with context" command to recover from corrupted conversations

[https://github.com/microsoft/vscode/issues/300651](https://github.com/microsoft/vscode/issues/300651)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/296370 tracks preserving accumulated session context when forking or sending a request to a new chat, which is the remaining capability requested here. The specific whitespace-only Anthropic payload defect was separately fixed, but current main still transfers only the pending input rather than conversation context.

## Change summary

Provide a recovery path that starts a clean chat while retaining valid context from a conversation whose persisted history causes every request to fail.

## Best solution

Consolidate the context-transfer design in https://github.com/microsoft/vscode/issues/296370, ensuring that transferred session memory cannot carry malformed historical content into the new session. Keep malformed-payload prevention in the endpoint serialization path.
