# Issue #291013 — Model picker should be aware of group concept

[https://github.com/microsoft/vscode/issues/291013](https://github.com/microsoft/vscode/issues/291013)

## Summary

Team-authored feature request (MEMBER). The model picker does not surface the group concept to disambiguate identical models configured in different groups (e.g. work vs personal API keys). The group data model exists in `languageModels.ts` and `languageModelsConfiguration.ts` but the picker UI in `modelPickerActionItem.ts` does not use it to distinguish entries. Still a real gap on current main.

## Change summary

The model picker should display group information so that identically-named models from different groups (e.g. two OpenRouter configurations with separate API keys) are visually distinguishable.

## Best solution

Surface the group name or a distinguishing label in the model picker quick-pick items (likely in `modelPickerActionItem.ts` and the picker's item rendering) so users can tell apart models that share a name but belong to different groups.
