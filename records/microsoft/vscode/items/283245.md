# Issue #283245 — Better support for GitHub code search in repos with custom remotes

[https://github.com/microsoft/vscode/issues/283245](https://github.com/microsoft/vscode/issues/283245)

## Summary

An open PR (#312494) with `Fixes #283245` addresses this issue by resolving SSH host aliases in the GitHub extension's remote classification. The issue stays open pending that PR's review and merge.

## Change summary

GitHub code search and Copilot indexed-repo detection fail when the repo uses a custom SSH alias for github.com instead of a literal github.com remote.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/312494, which adds SSH config parsing to resolve custom host aliases to github.com in `extensions/github/src/sshConfig.ts` and wires it into `getRepositoryFromUrl`.
