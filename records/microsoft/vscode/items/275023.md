# Issue #275023 — Terminal Completion is not place to fit in the window and not render above the current line

[https://github.com/microsoft/vscode/issues/275023](https://github.com/microsoft/vscode/issues/275023)

## Summary

Keep open: current terminal suggestion layout still permits off-screen positioning and description placement over the input line. The related clipping reports are newer than this team-authored issue and do not qualify as duplicate canonicals under the re-review rules.

## Change summary

Keep terminal completion suggestions readable within the window and prevent their description from covering the current input line.

## Best solution

Make the terminal suggestion list and description respect window bounds and the input-line exclusion boundary, matching the editor's placement behavior. Establish browser-level geometry coverage for narrow windows and suggestions displayed both above and below the cursor.

For example, a 500-wide widget at cursorLeft 300 in a 600-wide viewport is assigned left -200. This is a source-level reproduction of the window-fit defect; no runtime execution was performed.
- **Description placement lacks input-line protection:** SimpleSuggestWidget._positionDetails in src/vs/workbench/services/suggest/browser/simpleSuggestWidget.ts passes only the suggestion element to placeAtAnchor. SimpleSuggestDetailsOverlay._placeAtAnchor in src/vs/workbench/services/suggest/browser/simpleSuggestWidgetDetails.ts:401–499 considers East, South, North, and West against body bounds without the cursor or above/below preference. South placement can therefore occupy the input line when the list is above it. TerminalSuggestAddon._ensureSuggestWidget excludes only West placement.
