# Issue #275023 — Terminal Completion is not place to fit in the window and not render above the current line

[https://github.com/microsoft/vscode/issues/275023](https://github.com/microsoft/vscode/issues/275023)

## Summary

Still open on main: the terminal suggest widget lacks the editor suggest widget's smart positioning logic that ensures it fits within the viewport and avoids rendering details above the current line. No fixing commit references this issue.

## Change summary

Terminal suggest widget doesn't always position itself to fit in the window and can render its description on top of the current line.

## Best solution

Port the editor suggest widget's viewport-fitting and above/below placement logic to the terminal suggest widget in `src/vs/workbench/contrib/terminalContrib/suggest/browser/terminalSuggestAddon.ts`, ensuring the widget and its details pane respect available space above and below the cursor.
