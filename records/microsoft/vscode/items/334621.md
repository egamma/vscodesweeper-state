# Issue #334621 — Code Edit Pill File Icons are not aligned with text

[https://github.com/microsoft/vscode/issues/334621](https://github.com/microsoft/vscode/issues/334621)

## Summary

Fresh, team-authored visual-alignment bug in the chat code-edit pill; traced to the pill's icon/label CSS in chatCodeBlockPill.css, no fix has landed yet, so this should stay open for a real fix.

## Change summary

In the chat code-edit pill widget, the file icon renders vertically centered while the adjacent label text renders bottom-aligned, so they don't line up.

## Best solution

Align the `.icon` and `.icon-label` vertical alignment inside `.chat-codeblock-pill-widget` in chatCodeBlockPill.css so both use the same baseline/centering (the icon's `::before` uses a background-image mask with a 1px bottom margin and `top: 1px` offset while the label uses `vertical-align: middle`, which can produce a mismatch versus native codicon glyphs).
