# Issue #334621 — Code Edit Pill File Icons are not aligned with text

[https://github.com/microsoft/vscode/issues/334621](https://github.com/microsoft/vscode/issues/334621)

## Summary

Genuine visual misalignment in the chat code-edit pill's file icon vs. filename text, filed by a team member with a screenshot and independently confirmed by another contributor — stays open for a CSS fix in the chat widget styles.

## Change summary

In the chat edit pill (from a recently-added feature, referenced issue #334484), the file icon renders vertically centered while the adjacent filename text sits lower/bottom-aligned, so icon and text look misaligned.

## Best solution

Fix the alignment in .chat-codeblock-pill-widget (src/vs/workbench/contrib/chat/browser/widget/chatContentParts/media/chatCodeBlockPill.css) — likely by making the widget a flex container with align-items: center around .icon and .icon-label, rather than relying on vertical-align: middle for both, since the current rule already sets vertical-align: middle on both spans yet the visual bug persists per the screenshot.
