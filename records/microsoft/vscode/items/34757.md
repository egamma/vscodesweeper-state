# Issue #34757 — Delete matching parentheses, brackets, or braces

[https://github.com/microsoft/vscode/issues/34757](https://github.com/microsoft/vscode/issues/34757)

## Summary

The built-in Remove Brackets command implements the dedicated-shortcut option explicitly offered in the original request, preserving the enclosed content. Later discussion confirms this works; automatic deletion through ordinary Delete or Backspace is a separate enhancement, not required to satisfy that option.

## Change summary

Provide a single operation that removes matching parentheses, brackets, or braces without deleting their contents.

## Best solution

Close the original request as implemented by editor.action.removeBrackets in commit fa758a7cc52429139fb2a5fe5ee91c6182414d81. Retain ordinary deletion behavior; any automatic paired-deletion enhancement should have its own explicit behavior and opt-in requirements.
