# Issue #34757 — Delete matching parentheses, brackets, or braces

[https://github.com/microsoft/vscode/issues/34757](https://github.com/microsoft/vscode/issues/34757)

## Summary

The requested keymappable bracket-pair deletion is implemented and shipped as the built-in Remove Brackets command, so this can be closed as completed.

## Change summary

Provide an optional command or behavior that removes matching parentheses, brackets, or braces together without deleting their contents.

## Best solution

Keep the shipped `editor.action.removeBrackets` command and its Ctrl/Cmd+Alt+Backspace keybinding; it removes the highlighted bracket pair while preserving enclosed content.
