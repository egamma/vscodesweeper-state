# Issue #248733 — tasks with dependencies do not show prompt to restart/ terminate, do not respect `instanceLimit`

[https://github.com/microsoft/vscode/issues/248733](https://github.com/microsoft/vscode/issues/248733)

## Summary

Compound tasks without their own command still bypass instance-limit enforcement and cannot participate normally in the restart/terminate flow. Keep this accepted, team-authored bug open: the related merged PR does not fix it, and the directly targeted PR was closed after the maintainer rejected its behavior.

## Change summary

Tasks with dependencies should honor instanceLimit and provide the configured restart/terminate interaction even when the compound task has no terminal of its own.

## Best solution

Make compound-task executions participate consistently in task instance accounting and lifecycle controls, including while dependencies are running. Establish how restarting or terminating a compound execution affects dependencies shared with other executions before completing that behavior.

- **Behavior:**

  > A compound task with no command of its own is still a task execution while its dependencies run. Existing ordinary task behavior must remain unchanged; dependency-sharing cancellation semantics require a maintainer decision.
- **Trace:**
