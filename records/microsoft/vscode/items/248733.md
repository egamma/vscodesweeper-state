# Issue #248733 — tasks with dependencies do not show prompt to restart/ terminate, do not respect `instanceLimit`

[https://github.com/microsoft/vscode/issues/248733](https://github.com/microsoft/vscode/issues/248733)

## Summary

Still unfixed on main. The compound-task `_activeTasks` lifecycle bug remains: compound tasks are removed from `_activeTasks` too early, breaking `instanceLimit` enforcement and terminate prompts. PR #250785 attempted a fix but was closed without merging. Team-authored issue — keeping open.

## Change summary

Tasks with dependencies (compound tasks) do not show restart/terminate prompts and do not respect `instanceLimit` because they are prematurely removed from `_activeTasks`.

## Best solution

Land the fix from the closed PR #250785 (or the author's WIP in commit 648939539c6): make the `finally` block in `_executeTask` conditional so tasks with commands remain in `_activeTasks` until their terminal exits, rather than being removed when dependency resolution completes. The fix is localized to `src/vs/workbench/contrib/tasks/browser/terminalTaskSystem.ts`.

  > In src/vs/workbench/contrib/tasks/browser/terminalTaskSystem.ts, the `_executeTask` method's `finally` block (around line 600-604) unconditionally removes tasks from `_activeTasks` when dependency resolution completes. This is wrong for compound tasks that have their own command to execute — they get removed before their terminal exits, so `_getInstances()` can't find them for instanceLimit checks and `terminate()` can't find them either.
