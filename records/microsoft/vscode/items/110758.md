# Issue #110758 — Provide an error code for "User did not consent to login" error

[https://github.com/microsoft/vscode/issues/110758](https://github.com/microsoft/vscode/issues/110758)

## Summary

Keep this API proposal open: current source still reports declined login consent through a generic Error, without the requested stable identifier. The maintainer-supported API contract remains unresolved, and api-proposal issues are protected from cleanup closes.

## Change summary

Expose a stable authentication error code or type so extensions can recognize declined login consent without comparing message strings.

## Best solution

Define and finalize an extension-facing authentication error contract, following the maintainer's AuthenticationError direction, and preserve its machine-readable identity across the main-thread/extension-host boundary. Keep consent rejection distinguishable from provider failures without changing when authentication prompts appear.
