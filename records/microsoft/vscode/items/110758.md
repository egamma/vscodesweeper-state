# Issue #110758 — Provide an error code for "User did not consent to login" error

[https://github.com/microsoft/vscode/issues/110758](https://github.com/microsoft/vscode/issues/110758)

## Summary

Still unimplemented on main: the 'User did not consent' error is still thrown as a plain string in four places with no structured error code or AuthenticationError type. Team-authored feature request with an existing design direction (AuthenticationError modeled after FileSystemError) — keeping open.

## Change summary

Provide a structured error code (or AuthenticationError type) for the 'User did not consent to login' error so extensions can detect it programmatically without string comparison.

## Best solution

Introduce an `AuthenticationError` class (modeled after `FileSystemError` as suggested in the comments) with a code enum covering at least `UserDidNotConsent`, and throw it from the four call sites in `mainThreadAuthentication.ts`, `mainThreadMcp.ts`, `authenticationExtensionsService.ts`, and `authenticationMcpService.ts`. This would be an API proposal that needs finalization.
