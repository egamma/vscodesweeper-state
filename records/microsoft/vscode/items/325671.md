# Issue #325671 — "VS Code Synced Data" shows in slash completions

[https://github.com/microsoft/vscode/issues/325671](https://github.com/microsoft/vscode/issues/325671)

## Summary

Still reproduces on main: the internal artificial plugin name 'VS Code Synced Data' leaks into slash completions because the synced-customization bundler uses it as a display name visible to the SDK's command listing. Team discussion on the sibling issue (#325670) identifies the root cause but no fix has landed yet.

## Change summary

The internal 'VS Code Synced Data' plugin name appears in slash command completions shown to users.

## Best solution

Filter or hide the 'VS Code Synced Data' plugin name from user-facing slash completions. The fix likely involves either renaming/hiding the artificial plugin in `syncedCustomizationBundler.ts` / `sessionPluginBundler.ts`, or filtering it out in the slash-command completion provider. Related work is being coordinated in https://github.com/microsoft/vscode/issues/325670.
