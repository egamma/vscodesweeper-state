# Issue #169117 — [html] "Cannot redeclare block-scoped variable" in script type module

[https://github.com/microsoft/vscode/issues/169117](https://github.com/microsoft/vscode/issues/169117)

## Summary

This remains an open, confirmed HTML validation bug: separate `<script type="module">` blocks are combined without module-local scope and produce a false redeclaration diagnostic. A maintainer recently identified the responsible source path, and the open Volar integration PR means this issue must remain open.

## Change summary

Treat each inline module script as independently scoped when constructing the embedded JavaScript document for HTML validation.

## Best solution

Resolve the false diagnostic in the HTML language-feature pipeline, either through the pending Volar integration or by preserving independent scope for each module script in `embeddedSupport.ts`, while leaving classic scripts globally scoped.
