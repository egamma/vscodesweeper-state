# Issue #342834 — Don't show 'Review Migrations' bar in GitHub Copilot chat when they've already been ignored

[https://github.com/microsoft/vscode/issues/342834](https://github.com/microsoft/vscode/issues/342834)

## Summary

Keep open: ignoring migration groups currently hides them in the Customizations editor but does not exclude them from the chat notice. Existing dismissal controls also suppress future suggestions, so they do not satisfy the request to flag new migrations.

## Change summary

Hide the Review Migrations bar when all suggestions have been ignored, while continuing to flag new migration suggestions.

## Best solution

Make chat migration notices reflect suggestions that still need the user's attention, consistently with the Customizations editor's ignored state. Establish whether new candidates within an already-ignored group should trigger another notice, while preserving explicit workspace-wide dismissal.
