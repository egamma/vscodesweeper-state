# Issue #169485 — Document scroll width is not calculated when shortening lines

[https://github.com/microsoft/vscode/issues/169485](https://github.com/microsoft/vscode/issues/169485)

## Summary

This is covered by the older, currently open horizontal-scrollbar shrinking request. Both discussions identify the same grow-only width tracking for virtualized editor lines; consolidate the reports while preserving the decoration-related detail.

## Change summary

Recalculate horizontal scroll width downward when long lines are shortened or width-extending decorations are removed.

## Best solution

Track shrinking editor scroll width in https://github.com/microsoft/vscode/issues/13516, including decoration removal, while preserving the performance benefits of line virtualization.
