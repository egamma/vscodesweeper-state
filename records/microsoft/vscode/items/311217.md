# Issue #311217 — ^C When the copilot agent uses terminal tools

[https://github.com/microsoft/vscode/issues/311217](https://github.com/microsoft/vscode/issues/311217)

## Summary

The reporter describes spurious ^C injections into the terminal during Copilot agent tool execution on Windows/PowerShell. Commit 8eaab1c0893 (April 29, 2026) directly addresses this class of bug — only sending SIGINT when shell integration confirms a prior command is executing — but the reporter continued to observe the problem on May 12, possibly because shell integration fails to activate in their environment (triggering a different code path). Routing to terminal area for investigation.

## Change summary

Copilot agent terminal tools inject spurious ^C interrupts into the terminal, causing false SIGINT signals and incorrect agent reasoning about command success.

## Best solution

Investigate whether the spurious ^C path persists when shell integration fails to activate (noneExecuteStrategy or fallback paths). The fix in commit 8eaab1c0893 guards the basicExecuteStrategy path, but the reporter's environment has broken shell integration ('Injection failed to activate'), which may route through a different strategy that still sends ETX unconditionally or misdetects terminal state.
