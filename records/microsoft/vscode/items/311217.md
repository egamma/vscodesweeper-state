# Issue #311217 — ^C When the copilot agent uses terminal tools

[https://github.com/microsoft/vscode/issues/311217](https://github.com/microsoft/vscode/issues/311217)

## Summary

Keep open: current source still permits pre-command Ctrl+C cleanup to finish the terminal tool's completion race before the requested command finishes. Execution strategies have gained safeguards since the report, but the supplied PowerShell commands and follow-up observations suffice to retest the remaining case; no verified fix or qualifying older duplicate establishes closure.

## Change summary

Copilot terminal execution can return a cleanup Ctrl+C prompt instead of the requested command's output, causing false interruption reports and unnecessary retries.

## Best solution

Ensure terminal-tool results correspond to the requested command rather than a cleanup command, preserving its actual output and exit status. Confirm the local Windows/PowerShell case and its relationship to the closely matching Remote-SSH report before investing in the legacy execution path, given the maintainer's stated harness migration direction.
