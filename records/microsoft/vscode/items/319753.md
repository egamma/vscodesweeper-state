# Issue #319753 — API: Expose document tokenization with theme-resolved token colors

[https://github.com/microsoft/vscode/issues/319753](https://github.com/microsoft/vscode/issues/319753)

## Summary

A real extension-API gap remains: current main can theme raw TextMate-tokenized source, but cannot expose a document's final editor tokenization including semantic tokens. The Backlog Candidates voting period is still active, so this should remain open as under discussion.

## Change summary

Expose document tokenization and theme-resolved colors so extensions can render text consistently with the editor.

## Best solution

Evaluate a document-oriented addition to the proposed syntax-highlighting API that reuses the loaded text model, includes semantic-token overlays, supports cancellation, and clearly documents whole-document performance costs.
