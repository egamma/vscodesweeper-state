## Change summary

Preserve server-issued affinity cookies across MCP HTTP requests so stateful sessions remain on the same load-balanced instance.

## Best solution

First verify the failure through the native fetch stack; adding credentials to an SDK constructor is not an applicable fix for the current implementation.

- **Native fetch path:** McpHTTPHandle._fetch in src/vs/workbench/api/common/extHostMcp.ts:887–999 always requests redirect: 'manual' and ultimately calls global fetch. src/vs/workbench/api/node/extHostMcpNode.ts delegates ordinary HTTP URLs to that implementation; src/vs/workbench/api/node/proxyResolver.ts:186–213 routes manual-redirect requests through patchedFetch rather than Electron net.fetch.
