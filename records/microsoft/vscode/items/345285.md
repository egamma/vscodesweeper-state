# Issue #345285 — Agents window: no way to open a PR after committing in a folder session

[https://github.com/microsoft/vscode/issues/345285](https://github.com/microsoft/vscode/issues/345285)

## Summary

Keep open: current source confirms that committing on a never-pushed branch removes both PR and sync operations. This team-authored report identifies a distinct remaining defect, not work completed by the earlier feedback issue.

## Change summary

Committing in an Agents window folder session leaves a never-pushed branch without a PR or push action.

## Best solution

Preserve an explicit way to publish committed work and create a PR from folder sessions. Handle already-committed work on the base branch separately so restoring an action does not inadvertently push directly to main.
