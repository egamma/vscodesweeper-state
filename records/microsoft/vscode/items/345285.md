# Issue #345285 — Agents window: no way to open a PR after committing in a folder session

[https://github.com/microsoft/vscode/issues/345285](https://github.com/microsoft/vscode/issues/345285)

## Summary

The post-commit dead end remains in current main: folder sessions with outgoing commits lose Create PR, while branches without an upstream cannot offer Sync Changes. Keep this team-authored bug open; the related Git/worktree overview does not replace this specific report.

## Change summary

Preserve a usable publishing or pull-request path after committing in an Agents window folder session.

## Best solution

Ensure a committed feature branch without an upstream retains an actionable path to publishing and creating a PR in the Agents window. Preserve existing tracked-branch sync semantics, and handle the reported default-branch case deliberately rather than treating a push to main as equivalent to creating a PR.
