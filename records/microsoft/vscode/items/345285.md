# Issue #345285 — Agents window: no way to open a PR after committing in a folder session

[https://github.com/microsoft/vscode/issues/345285](https://github.com/microsoft/vscode/issues/345285)

## Summary

The post-commit dead end remains in current source: folder-session PR operations are suppressed while Sync requires an upstream. Keep this concrete regression open; the broader Git/worktree discussion does not replace it.

## Change summary

Committing in a folder session on an unpublished branch removes both PR creation and the available path to push.

## Best solution

Preserve an explicit continuation from a local commit to publication and PR creation in the Agent Host operation providers. Settle the already-committed default-branch behavior before extending availability there, since the current PR handler only creates a new branch for uncommitted changes.
