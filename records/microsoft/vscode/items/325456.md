# Issue #325456 — Copilot no longer explains terminal commands before approval

[https://github.com/microsoft/vscode/issues/325456](https://github.com/microsoft/vscode/issues/325456)

## Summary

Confirmed on main: the terminal-tool confirmation now only shows the model's explanation/goal via a delayed hover on the command editor, instead of as visible text, and a separate AI risk-assessment badge (not the same content) has replaced it as the visible element — this matches the report and the follow-up comment exactly.

## Change summary

Terminal tool approval prompts no longer display the model's explanation of the command inline; the text is now hover-only.

## Best solution

In chatTerminalToolConfirmationSubPart.ts, decide whether the explanation/goal text (built in runInTerminalTool.ts as `Explanation: {0}\n\nGoal: {1}`) should be rendered inline again (e.g. as a visible line below the command, similar to before), or keep it hover-only as an intentional compactness trade-off — either way this needs a maintainer/design call rather than an automatic fix, since the risk badge (`chat.tools.riskAssessment.enabled`) already occupies the same visual slot with different content (a risk rating, not the command's rationale).
