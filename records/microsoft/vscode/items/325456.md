# Issue #325456 — Copilot no longer explains terminal commands before approval

[https://github.com/microsoft/vscode/issues/325456](https://github.com/microsoft/vscode/issues/325456)

## Summary

Current main confirms the reported UX: the agent-provided explanation and goal are retained but exposed only through a delayed hover over the command. The inline risk assessment partially overlaps but does not explain why the command is needed, so a meaningful transparency gap remains.

## Change summary

Restore immediately visible context explaining what a proposed terminal command does and why the agent wants to run it before approval.

## Best solution

Show the concise command goal directly in the terminal confirmation while keeping any longer explanation available without relying on a delayed mouse hover. Preserve the separate risk assessment and ensure the rationale is reachable by keyboard and screen readers.
