# Issue #338199 — Font rendering and antialias problem

[https://github.com/microsoft/vscode/issues/338199](https://github.com/microsoft/vscode/issues/338199)

## Summary

Reproducible with a clean before/after: the only setting difference between the reporter's working and broken configs is `editor.experimentalGpuAcceleration` (off vs on), and the video/screenshots show the GPU-accelerated path rendering visibly blurrier text. This is a real, still-open quality gap in the experimental GPU editor renderer, not a duplicate of the unrelated Chromium-hardware-acceleration blur report or the terminal HiDPI request.

## Change summary

Enabling `editor.experimentalGpuAcceleration` makes editor font rendering blurry/less antialiased compared to the default DOM renderer.

## Best solution

Investigate the canvas-based glyph rasterizer (src/vs/editor/browser/gpu/raster/glyphRasterizer.ts) for antialiasing parity with the DOM text renderer — likely needs to match font-smoothing/subpixel behavior used by the CSS/DOM path when the experimental GPU renderer is enabled; route to the editor-gpu/font-rendering owners.
