# Issue #173259 — Incorrect Keyboard Shortcuts on Web Version of VSCode on Samsung Galaxy Tab S8 Ultra

[https://github.com/microsoft/vscode/issues/173259](https://github.com/microsoft/vscode/issues/173259)

## Summary

Still a valid open bug — keyboard layout detection on Android tablets with keyboard covers in VS Code web remains broken on current main. The AltGr and key-swap issues share a root cause (incorrect layout mapping). A related issue #197823 covers the same problem space; this is the broader/older report and should remain the canonical tracker.

## Change summary

Keyboard shortcuts are incorrectly mapped on VS Code web when using a German keyboard cover on Samsung Galaxy tablets — Ctrl+Z maps to Ctrl+Y (QWERTY/QWERTZ swap) and AltGr combos fail.

## Best solution

Fix the keyboard layout detection in `src/vs/workbench/services/keybinding/browser/keyboardLayoutService.ts` to correctly handle Android tablet keyboard covers that report layout information differently. Consider consolidating https://github.com/microsoft/vscode/issues/197823 as a duplicate of this issue since both describe the same root cause.
