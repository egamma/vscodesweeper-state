# Issue #214108 — Option to default editor view to "Zen Mode"

[https://github.com/microsoft/vscode/issues/214108](https://github.com/microsoft/vscode/issues/214108)

## Summary

A real capability gap remains: `zenMode.restore` restores Zen Mode only for a workspace where it was previously active, and does not make every new window or workspace start in Zen Mode. No older open issue reports this same observable request, so the stronger re-review duplicate bar is not met.

## Change summary

Allow users to configure VS Code so every newly opened window or workspace starts in Zen Mode.

## Best solution

Define an explicit startup preference for Zen Mode that works for newly encountered workspaces while preserving the existing per-workspace restoration semantics of `zenMode.restore`.

## Evidence

- **current setting:** `src/vs/workbench/browser/workbench.zenMode.contribution.ts` registers `zenMode.restore`, described as restoring a window only if it was exited in Zen Mode; there is no setting that defaults all new windows or workspaces to Zen Mode.
- **startup path:** `src/vs/workbench/browser/layout.ts` restores Zen Mode only when the workspace-scoped `zenMode.active` runtime state is already true, so a newly opened workspace does not satisfy the requested behavior.
- **related issue:** https://github.com/microsoft/vscode/issues/174677 is older and open, but requests suppression or relocation of suggestions, diagnostics, and other distractions while editing; it does not report the same startup-default behavior required for a re-reviewed duplicate close.
- **prior precedent:** https://github.com/microsoft/vscode/issues/103223 requested a command-line flag and was declined as out of scope; its maintainer discussion preferred reliable restoration through `zenMode.restore`, but that closed request does not decide the broader user/workspace default requested here.
- **existing partial capability:** `zenMode.restore: true` covers reopening a workspace that was previously left in Zen Mode, but not opening an unrelated or new workspace in Zen Mode by default.
