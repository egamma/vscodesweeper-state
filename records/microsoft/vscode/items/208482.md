Active feature request with 39 upvotes (above the 20-upvote backlog threshold) asking for icons in context menus. Prior issues were closed, making this the canonical tracker. Already labeled under-discussion — should stay open for a design decision.

## Change summary

## Best solution

The menu infrastructure already supports icons (icon: true in menu.ts, icon property in IAction). A design decision is needed on whether to expose this in context menus — the opt-in setting approach from comment 7 is a reasonable path.
