# Issue #324097 — minimum release age should not show badging for deferred updates

[https://github.com/microsoft/vscode/issues/324097](https://github.com/microsoft/vscode/issues/324097)

## Summary

Current main already does what's being asked: extensions delayed by the auto-update minimum-release-age setting are excluded from the activity-bar/Extensions-view update badge count, and each such row shows an explicit info-icon status explaining the delay and when it will auto-update.

## Change summary

Extensions deferred by the minimum-release-age (auto-update delay) setting still show as ordinary pending-update badges with no indication they are intentionally held back.

## Best solution

Treat as resolved on main: the badge/notification count in extensionsViewlet.ts already excludes delayed extensions via `isAutoUpdateDelayed`, and extensionsActions.ts already renders an explanatory 'autoUpdateDelayed' status message per row — no further core change needed for this specific ask.
