# Issue #251747 — Enable Auto-Attach for MCP Prompts / Embedded Resources

[https://github.com/microsoft/vscode/issues/251747](https://github.com/microsoft/vscode/issues/251747)

## Summary

Keep open as the established discussion for persistent inclusion of MCP-hosted instructions. Existing resource attachments and prompt completions do not cover automatic inclusion, and maintainers have supported explicit resource pinning while rejecting exhaustive per-request discovery.

## Change summary

Allow MCP-hosted resources or prompts to supply reusable chat instructions without repeated manual selection or local file copies.

## Best solution

Design an explicitly selected, persistent MCP instruction source integrated with chat customization discovery, following the maintainer-supported pinning direction without enumerating every server's resources on each request. Settle persistence, applicability, and parameterized-prompt behavior before implementation.

- **Open decisions:**
