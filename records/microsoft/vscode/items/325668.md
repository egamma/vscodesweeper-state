# Issue #325668 — Auto inline diff if all additions or subtractions

[https://github.com/microsoft/vscode/issues/325668](https://github.com/microsoft/vscode/issues/325668)

## Summary

Keep open as a feature request: ordinary diff editors do not expose an opt-in, content-based switch to inline layout for addition-only or deletion-only diffs. Existing automatic layout settings respond to editor width, not the requested change content.

## Change summary

Allow addition-only or deletion-only diffs to automatically use inline layout while retaining side-by-side as the default.

## Best solution

Provide an optional content-sensitive layout policy for ordinary diff editors, preserving existing defaults and manual layout controls. The internal compact-mode heuristic is relevant prior art, but its broader behavior and presentation changes should not be exposed wholesale as a substitute.
