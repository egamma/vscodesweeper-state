# Issue #325668 — Auto inline diff if all additions or subtractions

[https://github.com/microsoft/vscode/issues/325668](https://github.com/microsoft/vscode/issues/325668)

## Summary

This is a valid, currently unexposed diff-editor preference. Route it to the diff-editor area because main has similar internal smart-layout behavior, but no user setting applies it to normal diff editors.

## Change summary

Add an opt-in mode that automatically renders insertion-only or deletion-only diffs inline while retaining side-by-side layout for other diffs.

## Best solution

Expose the existing simple-diff layout decision as a dedicated diff-editor setting, independent of compact mode, and determine the layout after the initial diff calculation to avoid disruptive switching as writable models change.
