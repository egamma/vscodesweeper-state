# Issue #330880 — fix: prevent TreeError when focusing agent sessions list during async refresh (fixes #330875)

[https://github.com/microsoft/vscode/issues/330880](https://github.com/microsoft/vscode/issues/330880)

## Summary

This is an automated errors-fix analysis of a real, still-open crash (linked telemetry issue #330875, ~157 users on 1.133.0) — the ineffective try/catch and the unguarded focus-by-index path are confirmed present on current main, so the underlying defect is real and the proposed fix approach is sound.

## Change summary

AgentSessionsControl.focus() calls focusFirst() which sets focus by stale list-view index during an async tree refresh, throwing an uncatchable TreeError routed to telemetry via Emitter._deliver.

## Best solution

Land a small fix in agentSessionsControl.ts: source focus() from the tree model's own children (as already done elsewhere in the file via hasNode/getNode) instead of focusFirst() by list-view index, and drop the now-provably-dead try/catch.
