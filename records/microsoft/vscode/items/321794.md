# Issue #321794 — [Error] [GitHub.copilot-chat] unhandlederror-Provided value cannot be bound to SQLite parameter 2.

[https://github.com/microsoft/vscode/issues/321794](https://github.com/microsoft/vscode/issues/321794)

## Summary

Real regression in the Copilot Chat extension's external ingest index: `tryAddOrUpdateFile` passes `stat.size` / `stat.mtime` to a SQLite prepared statement without validating they are finite numbers, causing a bind error for some file system stat results. An open PR (#321799) already targets the fix — keep open until it merges.

## Change summary

File indexing in the Copilot external ingest index crashes with a SQLite bind error when `stat.size` or `stat.mtime` is not a bindable numeric type.

## Best solution

Land the open fix PR (https://github.com/microsoft/vscode/pull/321799) which validates that `stat.size` and `stat.mtime` are finite numbers before passing them to the SQLite bind call in `tryAddOrUpdateFile`. The guard belongs in `safeStat` or at the bind site in `externalIngestIndex.ts`.
