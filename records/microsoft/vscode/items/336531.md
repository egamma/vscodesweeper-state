# Issue #336531 — Support opening files inside VSCode in the embedded browser

[https://github.com/microsoft/vscode/issues/336531](https://github.com/microsoft/vscode/issues/336531)

## Summary

Keep open: the integrated browser still lacks explicit handling for opening vscode-insiders://file/ links in the editor, and the maintainer-linked implementation PR remains open. The existing browser-integration label already routes this correctly.

## Change summary

Allow file links using VS Code's application URI scheme to open editor files directly from the integrated browser.

Review and resolve the existing implementation candidate at https://github.com/microsoft/vscode/pull/289205, preserving confirmation and trust handling for application links. Keep this issue as the feature record until the requested behavior lands.
