# Issue #281154 — Unexpected conversion to `string` from `markdown` for `label`

[https://github.com/microsoft/vscode/issues/281154](https://github.com/microsoft/vscode/issues/281154)

## Summary

The contract inconsistency remains on current main: string-typed session labels are interpreted as Markdown, and extension-provided string descriptions also become Markdown during conversion. Keep this open to settle the intended text-versus-Markdown contract before changing behavior.

## Change summary

Clarify and consistently enforce plain-text versus Markdown semantics for chat session labels and descriptions.

## Best solution

Define explicit text-versus-Markdown semantics for session metadata across the provider API, conversion layer, and session renderers. Preserve Markdown-title presentation intentionally rather than relying on an undocumented interpretation of string fields.
