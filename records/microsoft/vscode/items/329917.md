# Issue #329917 — Selecting prompt and changing it makes the other onboarding prompts unselectable

[https://github.com/microsoft/vscode/issues/329917](https://github.com/microsoft/vscode/issues/329917)

## Summary

Keep open for a product decision: current main intentionally disables other onboarding prompt options after an arbitrary edit to prevent replacing user-authored text. This is a team-authored, already-routed discussion without a mechanical duplicate or explicitly referenced fix that would permit closing it.

## Change summary

Decide whether users should be able to select another onboarding prompt after editing the prompt currently in the input.

## Best solution

Settle the user-visible replacement behavior for edited prompts while preserving typed text; retain the current protective behavior until that decision is made, then capture the chosen interaction in the prompt-options tests and accessibility help.
