# Issue #258194 — Adding a screenshot to chat context fails because Blob.bytes() is unsupported in some browsers

[https://github.com/microsoft/vscode/issues/258194](https://github.com/microsoft/vscode/issues/258194)

## Summary

The defect remains on current main: the browser screenshot path unconditionally calls `Blob.bytes()`, so browsers without that API throw and return no screenshot. No fixing PR, canonical duplicate, or replacement compatibility path was found.

## Change summary

Adding a screenshot to chat context fails in browser-hosted VS Code when the browser does not implement `Blob.bytes()`.

## Best solution

Make the browser host screenshot conversion work without requiring `Blob.bytes()`, while preserving the returned `VSBuffer` and existing screenshot behavior in browsers that support the newer API.
