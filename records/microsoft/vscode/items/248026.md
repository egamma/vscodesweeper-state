# Issue #248026 — Can't move an empty markdown notebook cell

[https://github.com/microsoft/vscode/issues/248026](https://github.com/microsoft/vscode/issues/248026)

## Summary

Still reproduces on main: the MarkupCellRenderer never calls `registerDragHandle`, so markdown cells in editing mode have no drag handles. An unmerged fix exists on `origin/copilot/fix-130443` but has not landed on main yet.

## Change summary

Empty markdown notebook cells in editing mode cannot be moved via drag and drop because no drag handle is registered for markup cells.

## Best solution

Land the fix from branch `copilot/fix-130443` (commit 65ee1f582d0) which adds `registerDragHandle` for markdown cells in `MarkupCellRenderer`, or apply an equivalent fix to `src/vs/workbench/contrib/notebook/browser/view/renderers/cellRenderer.ts`.
