# Issue #262410 — Find Widget Lock

[https://github.com/microsoft/vscode/issues/262410](https://github.com/microsoft/vscode/issues/262410)

## Summary

Keep open: the Find Widget still gives Escape precedence over removing secondary cursors, and closing it clears the search scope. Existing find settings do not provide the requested lock or two-stage Escape behavior; no verified older duplicate was found.

## Change summary

Allow Escape to dismiss secondary cursors without closing the Find Widget or losing its Find in Selection scope.

## Best solution

Support preserving the Find Widget and selection scope while dismissing secondary cursors, with an explicit way to close the widget afterward. The editor-find owner should decide whether this is an optional lock or a change to Escape precedence.
