# Issue #262410 — Find Widget Lock

[https://github.com/microsoft/vscode/issues/262410](https://github.com/microsoft/vscode/issues/262410)

## Summary

Valid feature request for a way to keep the Find Widget open when pressing Escape. No existing setting covers this, and no duplicate was found. The use case (Find in Selection + multi-cursor workflows) is real but niche, and the issue has no community upvotes yet — keeping open for traction.

## Change summary

Request an option to prevent the Find Widget from closing on Escape, so multi-cursor workflows with Find in Selection aren't disrupted.

## Best solution

The most pragmatic path would be to note that the Escape keybinding for `closeFindWidget` can already be removed or rebound by the user via keybindings.json (removing the Escape binding from `closeFindWidget` when the find widget is visible). A built-in toggle or two-stage Escape (first deselect cursors, then close widget) could be considered if community demand grows. For now, a comment pointing the reporter to keybinding customization would likely resolve their immediate pain.
