# Issue #343077 — Large Codex chat restore stalls in JSON-RPC buffering and accessibility Markdown block counting

[https://github.com/microsoft/vscode/issues/343077](https://github.com/microsoft/vscode/issues/343077)

## Summary

Keep open: current source retains both reported expensive paths, and an independent Windows investigation confirms the buffering stall with the bundled runtime. Follow-up comments also establish oversized-response failures and identify history-loading behavior that needs consideration beyond a parser optimization.

## Change summary

Large Codex conversations stall during restoration because of repeated JSON-RPC buffering work, expensive accessibility Markdown lexing, and large full-history responses.

## Best solution

Make large-history restoration responsive without losing history or changing accessibility labels. Address transport and label-generation costs, and establish bounded history loading and explicit oversized-response failures rather than treating the diagnostic one-turn page size as a complete solution.
