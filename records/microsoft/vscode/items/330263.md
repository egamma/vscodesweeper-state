# Issue #330263 — [Error] unhandlederror-Unexpected end of JSON input

[https://github.com/microsoft/vscode/issues/330263](https://github.com/microsoft/vscode/issues/330263)

## Summary

Real regression traced to `deserialize()` in ipc.ts: `BufferReader.read()` slices without bounds-checking, so a truncated IPC frame causes `JSON.parse` to throw an opaque 'Unexpected end of JSON input' instead of a diagnosable error. An open PR already targets this exact issue, so it should stay open pending that PR landing rather than being closed now.

## Change summary

Truncated Agent Host Protocol IPC messages cause an unhandled `SyntaxError` in `deserialize()` when `JSON.parse` hits a partial payload.

## Best solution

Land https://github.com/microsoft/vscode/pull/330347 (or an equivalent fix) which enriches the `DataType.Object` deserialize path in src/vs/base/parts/ipc/common/ipc.ts to detect a short buffer before calling JSON.parse and throw a diagnosable error naming expected vs. received bytes; the underlying truncation source (new AHP-over-MessagePort transport) may also need investigation by the agent host owner.
