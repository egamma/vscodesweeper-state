# Issue #319360 — Tab shifting goes to unexpected element in integrated browser

[https://github.com/microsoft/vscode/issues/319360](https://github.com/microsoft/vscode/issues/319360)

## Summary

Keep open for a browser-specific keyboard-focus improvement. The maintainer explicitly accepted improving the unexpected title-bar transition while confirming that arrow keys, not Tab, are the intended way to navigate suggestions.

## Change summary

Make Tab navigation from the integrated browser's URL suggestions lead somewhere predictable instead of unexpectedly entering unrelated workbench controls.

## Best solution

Define a predictable Tab and Shift+Tab focus contract for the browser's anchored URL picker, preserving arrow-key suggestion navigation and access to picker actions. A maintainer should first decide whether traversal cycles within the picker or dismisses it into the browser.
