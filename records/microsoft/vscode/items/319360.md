# Issue #319360 — Tab shifting goes to unexpected element in integrated browser

[https://github.com/microsoft/vscode/issues/319360](https://github.com/microsoft/vscode/issues/319360)

## Summary

Still open on main: the integrated browser's URL bar / favorites picker does not trap Tab focus, causing it to escape into the VS Code workbench chrome instead of cycling within the picker. Confirmed by a team member as not-ideal behavior. No fix commit found.

## Change summary

Tab key in the integrated browser's quick pick navigates to VS Code workbench elements instead of staying within the picker.

## Best solution

Add focus trapping (or Tab-key handling) to the browser URL bar's quick pick so Tab cycles within the picker elements rather than escaping to the workbench title bar. The fix likely lives in the browser URL bar widget or the favorites/navigation feature code under src/vs/workbench/contrib/browserView/electron-browser/.
