# Issue #335041 — Misleading active tab background color

[https://github.com/microsoft/vscode/issues/335041](https://github.com/microsoft/vscode/issues/335041)

## Summary

Traced in source: the new modern tab style intentionally makes inactive editor tabs transparent (`modernEditorTab.inactiveBackground` = transparent) while active tabs get a subtle `listInactiveSelectionBackground`-derived fill, so the active tab can look no different from the surrounding editor background in some themes — this is working as coded, not a crash/bug, but the reported confusion is a legitimate design concern during the still-young modern UI rollout.

## Change summary

In the new 'modern UI' tab style, the active tab's background color is too close to the editor background, making it hard to visually distinguish from an inactive tab.

## Best solution

A design/theming decision for the workbench team: either give `modernEditorTab.activeBackground`/`modernTab.activeBackground` more contrast against `editorBackground` by default, or add a subtle border/underline cue, so the active tab clearly reads as 'connected' to the editor area the way the classic style did.
