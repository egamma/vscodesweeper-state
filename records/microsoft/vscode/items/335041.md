# Issue #335041 — Misleading active tab background color

[https://github.com/microsoft/vscode/issues/335041](https://github.com/microsoft/vscode/issues/335041)

## Summary

Valid design feedback on the modernized tab styling: the active tab background intentionally matches the editor background (tab.activeBackground defaults to editorBackground in src/vs/workbench/common/theme.ts), which is a deliberate 'flows into editor' design but does make it harder to tell active from inactive at a glance in the new floating-tab style — this is a design judgment call, not a bug.

## Change summary

In the modernized tab UI, the active tab's background color is indistinguishable from the editor area, making it hard to tell which tab is active compared to the classic style.

## Best solution

A workbench/theming maintainer should weigh in on whether the new tab visual language needs a stronger active/inactive contrast by default (e.g. adjusting tab.activeBackground/tab.inactiveBackground defaults or the tab border treatment); in the meantime users can already restyle via workbench.colorCustomizations for tab.activeBackground/tab.inactiveBackground.
