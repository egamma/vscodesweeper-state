# Issue #325598 — Copilot session rate limit error gives no reset time or duration

[https://github.com/microsoft/vscode/issues/325598](https://github.com/microsoft/vscode/issues/325598)

## Summary

The bug remains on current main: WebSocket rate-limit errors contain the retry duration in their message, but the chat fetcher discards it and the UI falls back to “a moment.” The maintainer-confirmed report should remain open for a bounded Copilot error-handling fix.

## Change summary

Show the server-provided reset duration when a Copilot session rate limit blocks a chat request.

## Best solution

Preserve the retry duration from `user_global_rate_limited` WebSocket errors through `ChatMLFetcher` so the existing rate-limit formatter can display a concrete wait such as “82 seconds,” covering both initial and mid-stream error paths.
