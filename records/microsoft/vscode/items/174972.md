# Issue #174972 — Run to Cursor and Add to Watch available in JSON settings file context menu 

[https://github.com/microsoft/vscode/issues/174972](https://github.com/microsoft/vscode/issues/174972)

## Summary

The bug remains on current main: four debug actions are shown based on debug state and editor focus without checking whether the active editor language supports breakpoints. The existing `debug` area label is correct, and no older canonical issue was found.

## Change summary

Hide Run to Cursor, Evaluate in Debug Console, Add to Watch, and Add Inline Breakpoint from editor context menus when the active language does not support breakpoints.

## Best solution

Make the debug editor-menu visibility follow the same per-model breakpoint capability used by breakpoint commands and gutter interactions, preserving the actions for supported languages and disassembly.
