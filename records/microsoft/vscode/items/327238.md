# Issue #327238 — Terminal bell sounds on every prompt when Shell Integration is enabled (OSC 633 BEL terminator appears to trigger bell)

[https://github.com/microsoft/vscode/issues/327238](https://github.com/microsoft/vscode/issues/327238)

## Summary

The issue already carries `info-needed` and a team member has asked for clarification on whether this is a regression and which version last worked. The reporter is on an outdated build (1.126.0 vs current 1.130.0). Keep open pending their reply.

## Change summary

Terminal bell sound triggers on every prompt when shell integration is enabled, because OSC 633 sequences use BEL (\a) as the string terminator.

## Best solution

Await reporter's reply on whether it reproduces on 1.130.0 and whether it's a regression. If confirmed on current, the fix would likely be in the shell integration zsh script (switching OSC terminators from BEL to ST `\e\\`) or in xterm.js's OSC parser not correctly suppressing bell for OSC-terminating BEL. The shell integration scripts at `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-rc.zsh` use `\a` exclusively as the OSC terminator.
