# Issue #332927 — VSCode Agents should not be a marketing tool for Copilot

[https://github.com/microsoft/vscode/issues/332927](https://github.com/microsoft/vscode/issues/332927)

## Summary

Keep open for product discussion: current main already supports provider-native Codex and Claude authentication without an active Copilot subscription, but the broader request for a consistently provider-neutral Agents experience and clearer UI boundaries remains unresolved.

## Change summary

Separate VS Code's Agent Host UI and capabilities from GitHub Copilot entitlements so independently authenticated agent providers can be used without Copilot-specific prerequisites or promotion.

## Best solution

Define a provider-neutral Agent Host contract in which each harness owns its authentication and service requirements, while the shared Agents UI remains usable whenever any provider is available. Copilot-only models, entitlements, upgrade prompts, and branding should be clearly scoped to the Copilot provider rather than presented as prerequisites for the overall experience.
