# Issue #307366 — Signed into multiple GH accounts

[https://github.com/microsoft/vscode/issues/307366](https://github.com/microsoft/vscode/issues/307366)

## Summary

Keep open for a focused decision on workspace-aware coding-agent account selection and actionable account-mismatch feedback. Existing workspace-scoped extension preferences partially address the request, but do not provide automatic repository-based selection or a workspace-wide default for all GitHub extensions; a maintainer already proposed improving the error experience.

## Change summary

Make coding-agent authentication understandable and usable when multiple GitHub accounts are signed in, including workspace-appropriate account selection.

## Best solution

Ensure cloud-agent authorization failures make the account choice understandable and offer a clear recovery path through existing account preferences. Decide whether repository-aware selection is also intended, without silently overriding explicit extension preferences or bundling unrelated extension defects into this work.
