# Issue #309962 — "detect indentation" has precedence over "change tab display size"

[https://github.com/microsoft/vscode/issues/309962](https://github.com/microsoft/vscode/issues/309962)

## Summary

Keep open: current source still contains the indentation-size decoupling described by the report. A linked, still-open PR explicitly targets this issue, so the next step is reviewing that candidate rather than closing the issue or starting competing implementation work.

## Change summary

After indentation detection, changing the tab display size to 1 can leave Tab and Shift+Tab using the previously detected four-space indentation size.

## Best solution

Review https://github.com/microsoft/vscode/pull/312515 to resolve the inconsistent relationship between detected indentation and subsequent tab-size changes, while preserving explicitly configured independent indentation sizes. Keep this issue open until the fix is merged.
