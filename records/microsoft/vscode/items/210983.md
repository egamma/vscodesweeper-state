[https://github.com/microsoft/vscode/issues/210983](https://github.com/microsoft/vscode/issues/210983)

## Summary

Keep open: project-shared terminal snippets remain a real gap, and the discussion explicitly accepted suggest-widget snippets instead of native shell alias injection. Existing alias discovery and pinned history do not cover that capability; no qualifying older canonical or landed implementation was established.

## Change summary

Allow projects to share named command shortcuts across shells through configurable terminal suggest snippets.

## Best solution

Provide project-configurable command snippets in terminal suggestions, following the direction accepted in the thread rather than injecting native aliases. Resolve the initial snippet syntax and placeholder behavior with the terminal owner before implementation.

- **Behavior:**

  > Projects should be able to share named command shortcuts that appear in terminal suggestions across supported shells. Accepting a shortcut inserts its configured command text; it does not install a native shell alias or change shell startup files. A workspace-defined gp shortcut should offer git push in both Bash and PowerShell, while ordinary suggestions remain unchanged. The initial syntax and any placeholder navigation must be agreed before the acceptance contract is finalized.
- **Trace:**

  > The discussion at https://github.com/microsoft/vscode/issues/210983 changes the goal from native alias injection to suggest-widget snippets, with explicit author agreement. Current configuration lives in terminalSuggestConfiguration.ts, provider aggregation in TerminalCompletionService, and terminal insertion in TerminalSuggestAddon; terminalSuggestMain.ts supplies bundled Fig specs and discovered shell commands. Existing alias discovery and pinned Run Recent Command history do not supply a project-owned snippet collection. The closed, unmerged prototype at https://github.com/microsoft/vscode/pull/236592 demonstrates a settings-based prefix/body model but does not settle a production contract. https://github.com/microsoft/vscode/issues/239244 tracks related history-suggestion infrastructure, while https://github.com/microsoft/vscode/issues/240240 tracks configurable Fig specs; neither replaces this request. Preserve native alias discovery, ordinary completion behavior, and execution controls; the uncertainty begins at the user-facing snippet definition and placeholder semantics.
