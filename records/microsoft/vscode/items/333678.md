# Issue #333678 — No status hover for nested chats

[https://github.com/microsoft/vscode/issues/333678](https://github.com/microsoft/vscode/issues/333678)

## Summary

Confirmed gap on main: the session row gets a rich `SessionSummaryHoverWidget` status hover, but the nested chat row template only wires a plain-text title tooltip — no equivalent status hover. It also carries the real milestone 1.140.0, so a close is barred regardless.

## Change summary

Nested/side-chat rows in the Agents window session list don't show the rich status hover that the top-level session row has.

## Best solution

Extend `SessionChatItemRenderer.renderElement` in sessionsList.ts to wire a `setupDelayedHover` with per-chat status content (mirroring the session row's `SessionSummaryHoverWidget` wiring at lines ~1204-1210), scoped to the individual chat rather than the whole session.
