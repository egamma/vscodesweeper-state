# Issue #171166 — Add a notion of pending / draft state to code review comments

[https://github.com/microsoft/vscode/issues/171166](https://github.com/microsoft/vscode/issues/171166)

## Summary

The proposed API (`commentsDraftState`) is implemented but still behind `checkProposedApiEnabled` — it has not been finalized into the stable API. The issue's remaining work is API finalization, and the area owner's most recent comment (Dec 2025) explicitly asks whether there is interest in finalizing. Stays open.

## Change summary

Add a draft/pending state to the Comment API so extensions can model unpublished code-review comments and VS Code can render draft indicators.

## Best solution

Finalize the `commentsDraftState` proposed API into the stable `vscode.d.ts` surface (move `CommentState` enum and the `Comment.state` property out of the proposal file, remove the `checkProposedApiEnabled` gate in `extHostComments.ts`). The area owner should gauge adoption interest and proceed with finalization when ready.
