# Issue #171166 — Add a notion of pending / draft state to code review comments

[https://github.com/microsoft/vscode/issues/171166](https://github.com/microsoft/vscode/issues/171166)

## Summary

Keep open as an API-finalization tracker: draft comment state and draft-aware icons exist, but the API remains proposed. The api-proposal label explicitly protects this issue from closure, and the latest maintainer comment asks about finalization.

## Change summary

Expose draft/published comment state to extensions and enable thread-level draft indicators, filtering, and navigation.

## Best solution

Have the API owners assess consumer experience and decide whether to finalize Comment.state and CommentState. Distinguish that API decision from the additional draft-specific filtering and expand/collapse capabilities suggested in the report.
