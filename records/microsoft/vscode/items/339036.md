# Issue #339036 — Regression - VS Code Secondary Sidebar Plugin Drop-down

[https://github.com/microsoft/vscode/issues/339036](https://github.com/microsoft/vscode/issues/339036)

## Summary

Thanks for the report. Several users confirm that drag and drop into extension webviews broke in 1.140.0. A maintainer traced it to the Electron 43.6.0 to 43.7.3 bump (#336697), where electron/electron#53750 restored the same-WebContents drag target check. The issue stays open while the Electron-side fix or a VS Code workaround is pending.

## Change summary

Dropping files from the Explorer into extension webviews, such as the Claude Code chat, is silently ignored since 1.140.0.

## Best solution

Resolve in Electron, or add a VS Code workaround for drags into cross-site webview iframes within the same WebContents. Keep this issue as the tracker until a fix ships and drag and drop into webviews is confirmed working.
