# Issue #292787 — Add Option to Control Automatic Worktree Creation in GitHub Copilot Background Sessions

[https://github.com/microsoft/vscode/issues/292787](https://github.com/microsoft/vscode/issues/292787)

## Summary

The requested choice already exists: new Copilot CLI background sessions offer Workspace and Worktree isolation modes and remember the selection. Propose closing this capability request as covered by the existing behavior, without dismissing the separate merge and discoverability concerns raised in the discussion.

## Change summary

Allow Copilot background sessions to work directly in the current repository instead of automatically creating a worktree.

## Best solution

Use the existing Isolation selector with Workspace selected; keep the remembered preference rather than add a redundant setting. Investigate file-state inconsistencies and worktree-management problems separately from this already-supported choice.

  > Thanks for the request. Copilot CLI background sessions already let you choose **Workspace** or **Worktree** in the **Isolation** selector before starting a new session.
