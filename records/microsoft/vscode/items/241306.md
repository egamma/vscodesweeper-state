# Issue #241306 — [Feature Request] Add clear history button in Cmd+F search widget

[https://github.com/microsoft/vscode/issues/241306](https://github.com/microsoft/vscode/issues/241306)

## Summary

Valid feature request with 25 upvotes, promoted to Backlog. The search panel (Ctrl+Shift+F) already has a clear-history command (`search.action.clearHistory`), but the editor find widget (Cmd+F) has no equivalent — the gap is real and the parity argument is strong.

## Change summary

Add a way to clear search/replace history in the Cmd+F editor find widget.

## Best solution

Add a clear-history command (and optionally a UI affordance) for the editor find widget, mirroring the existing `search.action.clearHistory` pattern from the search panel. The find widget already uses `HistoryInputBox` with `clearHistory()` support (`src/vs/base/browser/ui/inputbox/inputBox.ts`); the missing piece is wiring a command and/or menu item in `src/vs/editor/contrib/find/browser/findWidget.ts`.
