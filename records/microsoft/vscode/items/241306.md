# Issue #241306 — [Feature Request] Add clear history button in Cmd+F search widget

[https://github.com/microsoft/vscode/issues/241306](https://github.com/microsoft/vscode/issues/241306)

## Summary

Keep open: clearing editor Find history remains distinct from the existing Search history command. The request earned backlog acceptance with 25 upvotes, and the older dropdown request does not cover the same observable need.

## Change summary

Provide a discoverable action in the Cmd+F widget to clear its saved search history without deleting application files.

## Best solution

Provide an accessible clear-history action for editor Find that clears its persisted workspace history and updates active widgets. Choose a presentation consistent with existing Find controls; disabling history storage or clearing the separate Search view history does not satisfy this request.
