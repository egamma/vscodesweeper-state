# Issue #275096 — Expanding a language model provider makes the table jump

[https://github.com/microsoft/vscode/issues/275096](https://github.com/microsoft/vscode/issues/275096)

## Summary

The visual jump remains explainable on current main: expanding a provider rebuilds the entire flattened table instead of updating only that provider's rows, so this should stay open as a bounded table-widget bug.

## Change summary

Expanding or collapsing a language-model provider causes the Manage Language Models table to visibly jump instead of keeping the activated provider row anchored.

## Best solution

Keep the provider row at the same viewport position while its child model rows are inserted or removed, without changing grouping, selection, keyboard navigation, or ARIA-expanded behavior.
