Fresh, well-reasoned feature request for a brand-new WYSIWYG Markdown editor (still under active development in extensions/markdown-language-features); no zoom/wheel handling exists there yet, so the gap is real — routing to the markdown area to be considered alongside the rest of the WYSIWYG editor work.

## Change summary

Add Ctrl+scroll-wheel font-size zoom to the new Markdown WYSIWYG editing surface, matching the standard text editor's editor.mouseWheelZoom and the Markdown preview's Mermaid Alt+scroll zoom.
