# Issue #296532 — Background: asking to keep changes when archiving worktree session is weird

[https://github.com/microsoft/vscode/issues/296532](https://github.com/microsoft/vscode/issues/296532)

## Summary

The archive action still requires a keep-or-undo decision for pending edits, even in an isolated worktree. Keep this open to resolve archive semantics; the related reports do not clearly own the full request to leave worktree changes untouched.

## Change summary

Allow archiving a background worktree session without deciding whether to keep or undo its pending changes.

## Best solution

Make archiving an isolated worktree session preserve its changes without requiring an edit-review decision. Agree on whether that preserves the worktree itself or preserves recoverable changes through the existing cleanup lifecycle, while retaining appropriate safeguards for edits in the user's main workspace.
