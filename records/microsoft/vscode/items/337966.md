[https://github.com/microsoft/vscode/issues/337966](https://github.com/microsoft/vscode/issues/337966)

## Summary

Keep open: current source unconditionally converts native-dialog paths to NFC on macOS, which breaks access when an SMB share requires the original NFD spelling. The report provides concrete byte-level evidence and working CLI/Open Recent comparisons; the newer-version reminder does not establish resolution.

## Change summary

Opening an accented folder or file through the native dialog fails on an SMB share that distinguishes NFD and NFC path spellings.

## Best solution

Ensure native-dialog selections remain usable on normalization-sensitive filesystems without breaking existing local macOS path handling. Address the dialog result processing in DialogMainService, preserving CLI/Open Recent behavior and avoiding a blanket conversion of all filesystem paths.
