# Issue #329741 — Black Screen after 10 minutes

[https://github.com/microsoft/vscode/issues/329741](https://github.com/microsoft/vscode/issues/329741)

## Summary

Verified duplicate of the well-established canonical issue for this exact symptom (window goes solid black/blank after being idle a while, fixed by dragging/restoring the window) — that issue has 61 comments, a traced root cause in Electron's backgroundThrottling behavior, and an open fix PR.

## Change summary

The whole VS Code window turns black after about 10 minutes; dragging/restoring the window temporarily fixes it, then it recurs.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/261660, which fully owns this report's symptom and root cause. A community reproduction there traced it to Electron's dynamic `backgroundThrottling` causing a hidden-window frame-eviction bug (electron/electron#42378), and https://github.com/microsoft/vscode/pull/326557 proposes removing the dynamic throttling path as a mitigation. Landing that PR (or an equivalent fix) resolves this report too.
