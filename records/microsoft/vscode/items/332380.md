# Issue #332380 — Agents window: Can't create multiple sessions on same PR

[https://github.com/microsoft/vscode/issues/332380](https://github.com/microsoft/vscode/issues/332380)

## Summary

Keep open for a decision on repeated PR-session creation and clearer empty-picker feedback. Current source deliberately excludes PRs associated with existing sessions; no verified canonical or issue-referencing fix supports closing this team-authored report.

## Change summary

Allow another session to be created from an already-associated pull request, including after archiving, and explain when no selectable pull requests remain.

## Best solution

Define whether an existing PR association should prevent another independent session or offer a way to continue existing work, including the archived-session case. Make the picker explain unavailable results rather than leaving the user with an unexplained empty list.

- **Open decisions:**
