# Issue #332380 — Agents window: Can't create multiple sessions on same PR

[https://github.com/microsoft/vscode/issues/332380](https://github.com/microsoft/vscode/issues/332380)

## Summary

Team-authored report (hard keep-open) tracing a real gap: the pull-request picker filters out any PR that already has a session (including archived ones), and shows an empty list with no explanation instead of a message.

## Change summary

In the Agents window, 'New Session from Pull Request' excludes PRs that already have a session (even archived ones) and shows an empty quick pick with no explanatory message instead.

## Best solution

In createSessionFromPullRequestAction.ts / pullRequestPicker.ts, decide whether an archived session should still count in getExistingPullRequests (currently sessionsManagementService.getSessions() includes archived sessions, so isPullRequestAvailable keeps blocking the PR forever), and add an empty-state message in the quick pick when no PRs remain available instead of showing a blank list.
