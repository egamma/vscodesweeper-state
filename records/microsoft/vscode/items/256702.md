# Issue #256702 — Chat: Reflect multiple editor selections in current document bubble

[https://github.com/microsoft/vscode/issues/256702](https://github.com/microsoft/vscode/issues/256702)

## Summary

Still reproduces on main: the implicit context bubble only tracks the primary editor selection via `getSelection()` (singular), ignoring additional selections entirely. The design discussion (comment #3) proposed per-selection dismissable labels but no implementation has landed.

## Change summary

The chat input's current-document bubble does not reflect multiple editor selections — it only tracks the primary selection and ignores additional ones.

## Best solution

Update `ChatImplicitContextService.updateImplicitContext()` in `src/vs/workbench/contrib/chat/browser/attachments/chatImplicitContext.ts` to use `getSelections()` (plural) and propagate an array of ranges through `ChatImplicitContext`. The rendering side (`implicitContextAttachment.ts`) needs to display each selection as a separate dismissable label, per the design proposed in comment #3.
