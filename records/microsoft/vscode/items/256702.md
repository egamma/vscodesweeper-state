# Issue #256702 — Chat: Reflect multiple editor selections in current document bubble

[https://github.com/microsoft/vscode/issues/256702](https://github.com/microsoft/vscode/issues/256702)

## Summary

The multiple-selection gap remains: current implicit-context collection reads only the editor's primary selection, so additional selections never reach the attachment bubbles. Keep this open; the thread's unresolved presentation decision should be settled before implementation.

## Change summary

Make the current-document chat context reflect multiple simultaneous editor selections and update correctly when selections are removed.

## Best solution

Represent all active non-empty editor selections in chat's implicit context, with an agreed presentation and consistent attachment behavior. Preserve the existing single-selection experience and ensure removing one selection does not hide selections that remain.

## Evidence
