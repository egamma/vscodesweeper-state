# Issue #287011 — Decoration not applied to diff editors when "fontWeight" decoration is set

[https://github.com/microsoft/vscode/issues/287011](https://github.com/microsoft/vscode/issues/287011)

## Summary

The decoration disappearance is still explained conclusively by current source: diff editors disable variable fonts, and the resulting filter drops entire decorations containing fontWeight. Keep this reopened report open; the related report describes the same filtering defect but is newer and cannot replace it under the re-review rules.

## Change summary

Decorations containing fontWeight disappear in diff editors, including their otherwise working highlight styling.

## Best solution

Preserve font-weight decoration rendering on both sides of diff editors without discarding the decoration's other styling. Address the font-decoration filtering boundary while retaining existing restrictions on variable font sizes and line heights.
