# Issue #324147 — Remote Tunnel Access fails after a while

[https://github.com/microsoft/vscode/issues/324147](https://github.com/microsoft/vscode/issues/324147)

## Summary

The logs confirm that a healthy Remote Tunnel becomes inaccessible after a WebSocket reset because repeated Microsoft-account token refresh requests receive 401 responses. This team-authored report should remain open and be routed to Remote Tunnels and authentication; the available related issues do not conclusively establish an identical root cause.

## Change summary

Keep Remote Tunnel Access operational across long-running connections and transient disconnects instead of entering a persistent 401 token-refresh loop.

## Best solution

Determine why the tunnel host can initially authenticate but cannot refresh its host token after reconnecting, then make the CLI recover without requiring the user to restart VS Code. Correlate the service response with https://github.com/microsoft/vscode/issues/312113, while preserving this report unless the refresh-time and login-time 401 failures are proven to share a root cause.
