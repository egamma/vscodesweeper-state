# Issue #347250 — [Agents Window][SSH] Handshake times out over VPN despite successful Remote-SSH connection — request configurable timeout

[https://github.com/microsoft/vscode/issues/347250](https://github.com/microsoft/vscode/issues/347250)

## Summary

Keep open as a configurable-timeout feature request: current source deliberately limits noninteractive SSH handshakes to 30 seconds and exposes no override. The report provides useful VPN comparisons, but whether a longer deadline resolves that environment remains unverified.

## Change summary

Allow longer SSH handshake/authentication deadlines in the Agents window, with clearer timeout diagnostics and appropriate SSH-setting compatibility.

## Best solution

Support an explicitly configurable longer deadline for slow SSH authentication while retaining prompt failure for stalled connections by default. An area maintainer should settle configuration ownership and timeout semantics before implementation.
