# Issue #346008 — Improve workspaceFolder variable description

[https://github.com/microsoft/vscode/issues/346008](https://github.com/microsoft/vscode/issues/346008)

## Summary

The reference table and built-in completion still use the ambiguous description. Keep this documentation improvement open; the existing multi-root explanation supplies useful context but does not improve the table entry itself.

## Change summary

Clarify which workspace folder ${workspaceFolder} resolves to in multi-root workspaces.

## Best solution

Clarify the reference table in microsoft/vscode-docs and keep the built-in completion description consistent. Distinguish the configuration's workspace-folder context from the .code-workspace file's directory and the active file's folder, retaining the explicit ${workspaceFolder:Name} syntax.
