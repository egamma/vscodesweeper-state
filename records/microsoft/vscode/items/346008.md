# Issue #346008 — Improve workspaceFolder variable description

[https://github.com/microsoft/vscode/issues/346008](https://github.com/microsoft/vscode/issues/346008)

## Summary

The reference table still uses the reported ambiguous wording. A later section explains multi-root scoping, but that does not eliminate the value of clarifying the table entry.

## Change summary

Clarify that ${workspaceFolder} refers to the contextual workspace folder, not the directory containing the .code-workspace file.

## Best solution

Improve the table entry in microsoft/vscode-docs/docs/reference/variables-reference.md and link its multi-root explanation. Describe configuration context rather than implying automatic selection from the active file; preserve explicit ${workspaceFolder:Name} scoping and distinguish ${fileWorkspaceFolder}.
