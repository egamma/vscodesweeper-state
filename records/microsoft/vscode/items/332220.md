# Issue #332220 — Active tab is not visually dominant and can be mistaken for an inactive tab

[https://github.com/microsoft/vscode/issues/332220](https://github.com/microsoft/vscode/issues/332220)

## Summary

This is a subjective visual-design complaint about the default theme's active-tab styling, not a functional defect — the underlying colors (tab.activeBackground, tab.activeBorder, tab.activeBorderTop, etc.) are fully theme-customizable in src/vs/workbench/common/theme.ts, so nothing is broken, but there's no established maintainer precedent yet to call it *as-designed either.

## Change summary

Reporter feels the active editor tab isn't visually distinct enough from inactive tabs in the default theme, making it easy to misidentify the active file from the tab bar alone.

## Best solution

A design/maintainer call on whether the default theme's active-tab affordance (background contrast, border weight) should be strengthened; if no change is warranted, close as *as-designed pointing to the existing tab.activeBackground/tab.activeBorderTop customization options.
