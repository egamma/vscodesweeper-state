# Issue #141683 — editor.actions.findWithArgs 'findInSelection' false doesn't work on an already opened Find Widget

[https://github.com/microsoft/vscode/issues/141683](https://github.com/microsoft/vscode/issues/141683)

## Summary

The bug remains on current main: an explicit `findInSelection: false` never clears an existing search scope when the Find Widget is already open.

## Change summary

Make `editor.actions.findWithArgs` disable Find in Selection when explicitly passed `findInSelection: false`.

## Best solution

Preserve the argument's three states: `true` enables the current-selection scope, `false` clears it, and omission retains existing/default behavior.
