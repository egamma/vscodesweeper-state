[https://github.com/microsoft/vscode/issues/306948](https://github.com/microsoft/vscode/issues/306948)

## Summary

Keep open: the maintainer confirmed that approving an edited command still executed the original, including outside the Agents Window. Current main has an Agent Host read-only safeguard, but that does not deliver commit-message editing or establish that both reported paths are fixed.

## Change summary

Honor edits made to a proposed commit message or shell command before the user approves execution.

## Best solution

Ensure that any editable approval executes the user-approved command and preserves the chosen commit message. Retest both the worktree merge flow and the reported PowerShell example, distinguishing the built-in terminal tool from provider-owned command execution.
