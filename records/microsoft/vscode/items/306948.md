# Issue #306948 — Sessions: Unable to edit commit message

[https://github.com/microsoft/vscode/issues/306948](https://github.com/microsoft/vscode/issues/306948)

## Summary

The silent command-substitution failure was mitigated on main by making Agent Host terminal confirmations read-only, but the requested edit-and-execute behavior remains missing. This team-authored, accepted Backlog bug must stay open because the likely covering commit does not reference this issue and the broader tracking issue explicitly preserves it as a narrower report.

## Change summary

Edits made to an agent-proposed commit or shell command must be the command that executes after approval, rather than silently running the original command.

## Best solution

Complete the Agent Host confirmation round trip so an edited terminal command is returned through `chat/toolCallConfirmed.editedToolInput` and executed, with the editor enabled only when that contract is supported. Add coverage proving that approving an edited Git commit command executes the edited message rather than the original.
