# Issue #306183 — Change the default colorscheme

[https://github.com/microsoft/vscode/issues/306183](https://github.com/microsoft/vscode/issues/306183)

## Summary

The requested separate theme entries already exist: the refreshed themes do not remove Dark Modern or Light Modern. The previous colors can be restored through the built-in Color Theme picker without creating a custom theme.

## Change summary

Keep the previous color schemes selectable alongside the refreshed default themes.

## Best solution

Use Preferences: Color Theme to select Dark Modern or Light Modern and retain that selection in the theme settings. Broader feedback about automatically changing defaults is separately tracked at https://github.com/microsoft/vscode/issues/304791.
