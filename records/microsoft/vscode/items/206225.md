# Issue #206225 — SCM - Tree view versioned directories decorations ignored

[https://github.com/microsoft/vscode/issues/206225](https://github.com/microsoft/vscode/issues/206225)

## Summary

Keep open: current SCM tree rendering still discards provider decorations when a versioned directory participates in folder compression. Ordinary uncompressed directory rows already honor provider icons, so the remaining defect is specifically in the compact-folder path.

## Change summary

Preserve SCM provider decorations on versioned directories when displaying resource groups as a tree.

## Best solution

Make versioned directories retain their provider decorations and resource identity in tree mode, including when compact folders are enabled. Keep generated-folder rendering and ordinary file/list rendering unchanged.
