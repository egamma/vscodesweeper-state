# Issue #228111 — the placeholder container is too narrow, it looks like it allocates space for the vertical scrollbar

[https://github.com/microsoft/vscode/issues/228111](https://github.com/microsoft/vscode/issues/228111)

## Summary

Keep open: current source still reserves scrollbar width in the placeholder even when no scrollbar is shown. The related adoption issue does not establish a separate canonical for this layout problem, and no qualifying fix was found for this team-authored item.

## Change summary

Allow editor placeholder text to use the available content width when there is no vertical scrollbar.

## Best solution

Make placeholder sizing reflect the available editor content area without prematurely truncating text for an absent scrollbar. Keep this scoped to placeholder layout rather than changing editor-wide wrapping or scrollbar geometry.
