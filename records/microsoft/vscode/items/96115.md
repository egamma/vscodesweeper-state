# Issue #96115 — Moving a view into panel does not distribute size evenly

[https://github.com/microsoft/vscode/issues/96115](https://github.com/microsoft/vscode/issues/96115)

## Summary

The remaining sizing defect was explicitly confirmed by the layout maintainer: moving an expanded view does not produce the even distribution indicated by the drop feedback. The Backlog milestone does not block triage, but there is no verified fix or older canonical with the same observable symptom, so this should remain open.

## Change summary

Distribute view sizes evenly when a view is moved into a panel whose drop feedback previews an even split.

## Best solution

Make the view-container move/layout path apply an even split after insertion while preserving the already-fixed behavior that expands a collapsed view when it is dropped.
