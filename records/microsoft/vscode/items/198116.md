# Issue #198116 — Explore quick fixes and command decoration being attached to the previous command (with help of sticky scroll)

[https://github.com/microsoft/vscode/issues/198116](https://github.com/microsoft/vscode/issues/198116)

## Summary

Keep this exploration issue open: current source still anchors quick fixes at the cursor rather than the originating command, and sticky scroll does not expose command decorations. Maintainer discussion on related reports explicitly consolidates this work here.

## Change summary

Explore attaching terminal quick fixes and command decorations to the originating command, including its sticky-scroll representation.

## Best solution

Make command status and actions visibly associated with the command they describe, including when its prompt is displayed in sticky scroll. Preserve this issue as the exploration record for deciding that interaction.
