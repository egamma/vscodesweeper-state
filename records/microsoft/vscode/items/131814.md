# Issue #131814 — Is there a "Format Selection As ..." command?

[https://github.com/microsoft/vscode/issues/131814](https://github.com/microsoft/vscode/issues/131814)

## Summary

The requested capability remains absent on main, and this accepted Backlog request has 53 community upvotes. Keep it open as the canonical request for formatting a selection as a chosen language.

## Change summary

Add a command that formats selected mixed-language or fenced code using a user-selected or inferred language.

## Best solution

Extend the editor formatting flow to let users choose a language for the selected text and invoke that language's installed range formatter, with fenced-language inference as a possible follow-up. Alternatively, expose sufficient formatter-selection API for an extension to provide the complete workflow.
