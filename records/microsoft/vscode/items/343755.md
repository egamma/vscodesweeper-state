# Issue #343755 — Built-in Chat: timestamp tooltips should respect regional date and time preferences

[https://github.com/microsoft/vscode/issues/343755](https://github.com/microsoft/vscode/issues/343755)

## Summary

Keep open as a feature request: current Chat formatting explicitly follows the display language, not independent regional preferences. The requested English-interface/Latvian-format combination remains unsupported on this path.

## Change summary

Allow built-in Chat timestamp tooltips to follow regional date and time preferences independently of the interface language.

## Best solution

Provide regional formatting for Chat timestamps while retaining the chosen interface language. Establish whether this includes custom Windows short-date and short-time overrides, since selecting an OS locale alone does not establish support for those preferences.

- **Response timestamp path:** src/vs/workbench/contrib/chat/browser/widget/chatListRenderer.ts uses formatChatRequestTimestamp in renderChatResponseDetails and in the completion details that produce 'Completed: {0}'. The full date therefore inherits the formatter's display-language locale.
- **Independent locale exists but is not used here:** src/vs/base/common/platform.ts initializes language from resolvedLanguage and platformLocale from osLocale on desktop.
