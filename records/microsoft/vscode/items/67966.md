# Issue #67966 — List references: transition from history to results is not smooth

[https://github.com/microsoft/vscode/issues/67966](https://github.com/microsoft/vscode/issues/67966)

## Summary

The references view has been substantially refactored since 2019 (moved to extensions/references-view, new TreeDataProviderDelegate pattern, and a recent commit grouping setMessage with debounced refresh). It's unclear whether the original transition flicker still reproduces on current builds. Requesting confirmation before further triage.

## Change summary

Transitioning from references history to new results causes a visual flicker where old nodes briefly show before the new results appear.

## Best solution

If the issue still reproduces, the fix likely involves ensuring the tree clears old nodes atomically when switching from the history provider to the new results provider in `extensions/references-view/src/tree.ts` — the `TreeDataProviderDelegate.update()` fires `onDidChange` before the new provider resolves, which could still cause a flash of stale content.
