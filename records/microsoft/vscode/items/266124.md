# Issue #266124 — Hookup LanguageModelDataPart to chat ouput renderers

[https://github.com/microsoft/vscode/issues/266124](https://github.com/microsoft/vscode/issues/266124)

## Summary

Direct LanguageModelDataPart rendering remains missing from the chat response stream. Existing tool-output and Markdown code-block rendering cover related scenarios, but the linked implementation PR was closed without merging.

## Change summary

Allow extensions to emit LanguageModelDataPart content directly into chat responses and have its MIME type select a chat output renderer without a tool invocation.

## Best solution

Complete the direct data-part path through the chat response API, transport, model, and existing output renderer infrastructure. Preserve the maintainer's stated direction to reuse LanguageModelDataPart rather than introduce a new response-part class or stream method.
