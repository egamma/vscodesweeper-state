# Issue #266124 — Hookup LanguageModelDataPart to chat ouput renderers

[https://github.com/microsoft/vscode/issues/266124](https://github.com/microsoft/vscode/issues/266124)

## Summary

Still unimplemented on main: ChatResponseDataPart does not exist in the chat response stream API (stable or proposed), and the related PR #268098 was closed without merging. The feature request remains valid.

## Change summary

Allow extensions to push LanguageModelDataPart into chat response streams so that chat output renderers can render data (e.g. mermaid diagrams) directly without relying on tool calls.

## Best solution

Add a ChatResponseDataPart to the ExtendedChatResponseParts interface and wire it through the chat response stream to the existing IChatOutputRendererService.renderOutputPart pipeline, enabling extensions to stream mime-typed binary data for rendering.
