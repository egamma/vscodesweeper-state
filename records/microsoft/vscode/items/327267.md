# Issue #327267 — Active panel tabs are barely visible in Modern UI

[https://github.com/microsoft/vscode/issues/327267](https://github.com/microsoft/vscode/issues/327267)

## Summary

Confirmed reproducible on current main: `tabs.css` hardcodes the active panel/side-bar tab pill background via `--modern-ui-tab-active-background !important`, so no `panelTitle.activeBackground`/`activityBarTop.activeBackground` color customization reaches it — but the fix shape (fallback vs. new themable color) is a design call the maintainers haven't made yet, per the reporter's own unanswered question in the latest comment.

## Change summary

In the experimental Modern UI, the active panel/side-bar tab pill ignores `panelTitle.activeBackground`/`activityBarTop.activeBackground` theme customizations because the background is hardcoded in CSS, making the active tab hard to see with some color themes.

## Best solution

A maintainer should pick one of the two shapes proposed in the discussion — either fall back `var(--vscode-panelTitle-activeBackground, var(--modern-ui-tab-active-background))` to preserve default appearance, or formally register `panelTitle.activeBackground` as new theming API — then land it in src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css alongside the related Modern UI theming issue https://github.com/microsoft/vscode/issues/329642.
