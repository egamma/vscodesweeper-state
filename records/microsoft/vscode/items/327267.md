# Issue #327267 — Active panel tabs are barely visible in Modern UI

[https://github.com/microsoft/vscode/issues/327267](https://github.com/microsoft/vscode/issues/327267)

## Summary

Still reproduces on main: Modern UI hardcodes the active panel/side-bar tab background via `--modern-ui-tab-active-background` in tabs.css instead of a theme-customizable color token, and no `panelTitle.activeBackground` token exists in theme.ts — a real gap in the still-experimental Modern UI, worth routing to the area owner rather than closing.

## Change summary

In Modern UI, `workbench.colorCustomizations` (e.g. `panel.background`, `panelTitle.activeForeground/activeBorder`, `tab.activeBackground`) cannot change the active panel/composite-bar tab pill background, which is hardcoded, making the active tab nearly invisible in some themes.

## Best solution

Introduce a dedicated theme color (e.g. `panelTitle.activeBackground`, possibly reused/aliased for the auxiliary bar and top activity bar checked-icon variants per the follow-up comment) in src/vs/workbench/common/theme.ts, and reference it from src/vs/workbench/contrib/styleOverrides/browser/media/{tabs,activityBar}.css instead of the hardcoded `color-mix` value, so Modern UI tab backgrounds are themeable like the rest of the workbench.

## Evidence

- **no such color token:** src/vs/workbench/common/theme.ts only registers `panelTitle.border`, `panelTitle.activeForeground`, `panelTitle.inactiveForeground`, and `panelTitle.activeBorder` (lines 495-520); there is no `panelTitle.activeBackground` token to consume.
