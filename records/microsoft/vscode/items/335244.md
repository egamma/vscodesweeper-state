# Issue #335244 — GitHub Copilot: camelCase subagentStart hook is silently ignored

[https://github.com/microsoft/vscode/issues/335244](https://github.com/microsoft/vscode/issues/335244)

## Summary

Confirmed on main: the GitHubCopilot hook-name maps in hookTypes.ts and pluginParsers.ts omit 'subagentStart' and 'preCompact', so those documented camelCase hook events are silently dropped even though the corresponding HookType enum values and UI labels exist.

## Change summary

The documented GitHub Copilot camelCase hook event `subagentStart` (and likely `preCompact`) is silently ignored because it's missing from the hook-name mapping tables.

## Best solution

Add 'subagentStart' → HookType.SubagentStart and 'preCompact' → HookType.PreCompact entries to HOOKS_BY_TARGET[Target.GitHubCopilot] in hookTypes.ts and to HOOK_TYPE_MAP's camelCase section in pluginParsers.ts, matching the pattern already used for sibling camelCase keys.
