# Issue #330047 — Allow users to specify which plugin to install in "Install Plugin from Source" command

[https://github.com/microsoft/vscode/issues/330047](https://github.com/microsoft/vscode/issues/330047)

## Summary

Team-authored feature request; a real gap exists today — the Install Plugin from Source input box only takes a source (owner/repo/git URL/path), not a `plugin@marketplace`-style identifier, even though the underlying service already supports targeting a specific plugin via an internal options parameter. Kept open per the team-authored protection rule since no fix commit references this issue.

## Change summary

Let users specify which plugin to install (via `plugin@marketplace` syntax) directly in the 'Install Plugin from Source' command, mirroring Copilot CLI/Claude Code, instead of only via an after-the-fact quick-pick.

## Best solution

Extend `InstallFromSourceAction`'s input box (src/vs/workbench/contrib/chat/browser/actions/chatPluginActions.ts) and the marketplace reference parser (src/vs/workbench/contrib/chat/common/plugins/marketplaceReference.ts) to accept a `plugin@source` combined string, threading the parsed plugin name into the existing `IInstallPluginFromSourceOptions.plugin` parameter that `pluginInstallService.ts` already consumes.
