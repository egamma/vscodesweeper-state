[https://github.com/microsoft/vscode/issues/186361](https://github.com/microsoft/vscode/issues/186361)

The notebook scrolling leak has received partial fixes, but current source still contains an output-toolbar lifecycle defect and an open PR explicitly targets this issue. Keep it open until that PR is resolved and the original no-output reproduction is remeasured.
