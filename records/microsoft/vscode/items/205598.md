# Issue #205598 — Invoking deltaDecorations recursively could lead to leaking decorations.

[https://github.com/microsoft/vscode/issues/205598](https://github.com/microsoft/vscode/issues/205598)

## Summary

Keep open: current source still contains the reported re-entrant decoration path, and this team-authored telemetry issue has no referenced fix or verified canonical duplicate. The editor area should investigate the interaction between cursor auto-close cleanup and decoration-change delivery.

## Change summary

Accepting a suggestion or snippet can recursively invoke `deltaDecorations` while cursor auto-close decorations are being invalidated, risking leaked decorations.

## Best solution

Add regression coverage for suggestion acceptance or snippet insertion while auto-closed-character decorations are invalidated, then prevent cursor cleanup from re-entering `TextModel.deltaDecorations` during decoration-event delivery without suppressing legitimate decoration notifications.
