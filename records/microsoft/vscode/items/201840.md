# Issue #201840 — Changing selection of just after text insertion messes up the undo stack [jsx]

[https://github.com/microsoft/vscode/issues/201840](https://github.com/microsoft/vscode/issues/201840)

## Summary

The linked editing undo stack corruption is still present on main. The `popUndoStop()` grouping in linkedEditing.ts interacts poorly with intervening selection changes, causing undo to produce incorrect text. No fix commit references this issue.

## Change summary

Undo produces corrupted text (e.g. stray `div` appended) when linked editing is active in JSX and a selection change occurs between the original edit and the linked editing mirror edit.

## Best solution

The linked editing contribution's undo grouping (popUndoStop + executeEdits in linkedEditing.ts) needs to account for intervening selection changes so that undo restores the correct document state. The fix likely lives in `src/vs/editor/contrib/linkedEditing/browser/linkedEditing.ts` around the `_syncEdits` method.
