# Issue #224403 — Cloud (☁️) emoji not rendering in terminal or editor on macOS Monterey 12.3.1

[https://github.com/microsoft/vscode/issues/224403](https://github.com/microsoft/vscode/issues/224403)

## Summary

Confirmed rendering bug with the cloud emoji (U+2601 + U+FE0F variation selector) in both editor and terminal; a team member reproduced it on 1.96.0, and no fix has landed on main. Keeping open.

## Change summary

The cloud emoji (☁️) renders incorrectly in both the VS Code terminal and editor on macOS, despite rendering correctly in other apps with the same fonts.

## Best solution

Investigate how the editor and terminal DOM renderers handle the U+FE0F variation selector for emoji presentation; the GPU renderer got emoji work (#237897) but the core text layout path may still not request the correct emoji-presentation glyph when U+FE0F follows a text-default codepoint like U+2601. Likely involves font fallback or glyph selection in the editor's view layer and xterm.js rendering.
