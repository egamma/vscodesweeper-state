# Issue #284446 — /tests for python places new tests within last test's body

[https://github.com/microsoft/vscode/issues/284446](https://github.com/microsoft/vscode/issues/284446)

## Summary

Still reproduces on main: the `_findLastTest` function returns the `endIndex` of the Python `function_definition` node, which in Python's indentation-scoped grammar includes the body — so insertion happens inside the last test function rather than after it.

## Change summary

The /tests command for Python inserts generated tests inside the body of the last existing test function instead of after it.

## Best solution

In `extensions/copilot/src/platform/parser/node/testGenParsing.ts`, after obtaining the last test node's `endIndex`, advance past the trailing newline to place the insertion point on the next line at column 0 (or use the node's `endPosition.row` to compute a line-based insertion after the function). The Python `testInSuiteQueries` tree-sitter query correctly identifies `function_definition` nodes, but the offset consumer needs to account for Python's indentation-delimited scope ending at the same position as the last statement in the body.
