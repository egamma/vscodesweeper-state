# Issue #321556 — "Relaunch Terminal" and other actions are hidden when notification message is too long

[https://github.com/microsoft/vscode/issues/321556](https://github.com/microsoft/vscode/issues/321556)

## Summary

Legitimate UI bug: when an expanded notification toast has a very long message, the computed height exceeds the viewport and the action buttons (like 'Relaunch Terminal') get clipped with no way to reach them. The toast has no max-height constraint or scroll on the notification item itself. Already assigned to anthonykim1.

## Change summary

Notification toast action buttons become inaccessible when the notification message is long enough to push them below the visible viewport.

## Best solution

The `NotificationsListDelegate.getHeight()` should cap the expanded height so the notification (including its details/buttons row) never exceeds the available viewport height. If the message is too long, it should become scrollable within the notification rather than growing unbounded. The fix belongs in `src/vs/workbench/browser/parts/notifications/notificationsViewer.ts` (height computation) and possibly the CSS (`notificationsList.css` — add `overflow-y: auto` and a `max-height` on the message area when expanded).
