# Issue #338609 — Terminal shell integration: leading comment ends multiline execution before its output

[https://github.com/microsoft/vscode/issues/338609](https://github.com/microsoft/vscode/issues/338609)

## Summary

Keep open: the recorded reproduction shows premature completion of the returned execution, and current source still contains a multiline-tracking path consistent with that failure. The related stream-retention PR explicitly excludes this defect; no verified fix or older same-symptom canonical was found.

## Change summary

Keep a comment-leading multiline Bash script within the execution returned by executeCommand(), delivering all output and the final exit code.

## Best solution

Correct execution identity and multiline lifecycle tracking so the leading comment cannot detach subsequent commands from the requested execution. Coordinate with the author of the related stream-retention PR, which explicitly leaves this behavior unresolved, while preserving ordinary multiline and heredoc behavior.
