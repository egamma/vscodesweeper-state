# Issue #328430 — Github Copilot change from Agent to Plan Mode triggers "Start Implementation" 

[https://github.com/microsoft/vscode/issues/328430](https://github.com/microsoft/vscode/issues/328430)

## Summary

Same root cause as the earlier, open https://github.com/microsoft/vscode/issues/323274: switching chat modes (here Agent→Plan) auto-injects a synthetic "Start implementation" message and discards the user's own typed prompt. A maintainer already asked for logs here, but this is one of a large, well-established cluster of duplicate reports on the same defect, and the older issue already tracks the identical behavior.

## Change summary

Switching Copilot Chat back to Plan mode after an Agent-mode implementation step deletes the user's newly typed prompt and auto-triggers "Start implementation", executing unwanted changes.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/323274, which already tracks the mode-switch auto-injecting "Start implementation" without user consent; the chat mode-switch handler (in the Copilot Chat extension, not the OSS core) needs to stop synthesizing an implementation message on a mode change and instead preserve/restore the user's draft text.
