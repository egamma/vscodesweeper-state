## Change summary

Prefer a lowercase single-character snippet prefix over its uppercase counterpart when the user types the lowercase character.

## Best solution

Retain the shared fuzzy-ranking behavior documented in the discussion. Users can use distinct, longer prefixes or editor.tabCompletion to cycle through matching suggestions.
