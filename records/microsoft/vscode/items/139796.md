# Issue #139796 — Single-char-prefix snippet suggestion is not case sensitive

[https://github.com/microsoft/vscode/issues/139796](https://github.com/microsoft/vscode/issues/139796)

## Summary

The reported ordering follows the scoring behavior explicitly explained by the maintainer, and current source still gives these single-character matches equal scores. Propose closing as designed rather than treating this as an outstanding case-sensitivity defect.

## Change summary

Prefer the lowercase-prefix snippet when typing a lowercase character instead of ranking its uppercase counterpart first.

## Best solution

Retain the existing suggestion-scoring behavior documented in the discussion. The suggested editor.tabCompletion setting provides a way to cycle alternatives, although it does not change their ranking.

  > Thanks for the clear example. As explained above, suggestion ranking does not guarantee that a lowercase prefix ranks ahead of its uppercase counterpart; the single-character prefixes `r` and `R` receive equal scores, leaving `R` first in the tie-break order.
