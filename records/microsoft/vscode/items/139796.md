## Summary

A maintainer (jrieken) explained the behavior is by-design in the scoring algorithm — lower-case characters are treated as 'the default' and don't boost scoring the way upper-case matches do. The issue is already labeled under-discussion and the reporter seemed to accept the explanation. No code change has addressed this specific single-char-prefix case since the discussion.
