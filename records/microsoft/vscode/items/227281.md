# Issue #227281 — Git - support for SHA256 repository

[https://github.com/microsoft/vscode/issues/227281](https://github.com/microsoft/vscode/issues/227281)

## Summary

Still reproduces on main — all SHA commit-hash regexes in the git extension hardcode `{40}`, breaking SHA-256 (64-char) repos. An open community PR (#317363) exists; keeping open for maintainer review of that PR.

## Change summary

VS Code's built-in Git extension assumes 40-character SHA-1 hashes, breaking commit display, diffs, and copy-commit-ID for SHA-256 Git repositories.

## Best solution

Review and land (or supersede) the open PR https://github.com/microsoft/vscode/pull/317363, which updates the regex patterns to accept both 40-char and 64-char hashes. The fix touches `extensions/git/src/git.ts` and `extensions/git/src/blame.ts` — ideally centralizing the hash pattern into a shared constant. `build/lib/git.ts` and `build/lib/getVersion.ts` have similar hardcoded patterns that should also be updated.
