# Issue #238073 — terminal.integrated.defaultLocation: editor makes it impossible to open a normal 'pane' terminal as well

[https://github.com/microsoft/vscode/issues/238073](https://github.com/microsoft/vscode/issues/238073)

## Summary

The panel’s + button still follows the editor default instead of creating a panel terminal. The current source confirms the reported path, and the maintainer explicitly confirmed that this behavior is wrong.

## Change summary

Creating a terminal with the Terminal panel’s + button should target the panel even when terminal.integrated.defaultLocation is editor.

## Best solution

Make terminal creation initiated by the panel toolbar stay in the panel, while preserving the configured default for ordinary command and keyboard invocation. Cover the primary + button and its generic New Terminal dropdown action without changing existing profile or split behavior.
