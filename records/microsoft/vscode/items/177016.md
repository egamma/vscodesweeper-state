# Issue #177016 — Markdown link diagnostics incorrectly report missing file

[https://github.com/microsoft/vscode/issues/177016](https://github.com/microsoft/vscode/issues/177016)

## Summary

The bug — stale 'file not found' diagnostics persisting after Rename Symbol recreates the target file — has no fix commit referencing this issue on main, and the markdown diagnostic refresh logic does not appear to have been changed to handle this scenario. Keeping open.

## Change summary

Markdown link diagnostics still show 'file not found' after Rename Symbol creates/renames a file to that path, even though the file now exists.

## Best solution

The markdown language server's diagnostic recomputation needs to be triggered (or its file-existence cache invalidated) when Rename Symbol creates or renames files. The fix likely belongs in the `vscode-markdown-languageservice` package's diagnostic computer or the file-watcher integration in `extensions/markdown-language-features/server/`.
