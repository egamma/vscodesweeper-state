## Change summary

In the automations history list, a failed run's row shows the timestamp pushed to the far right instead of inline as '<workspace> - Failed - <time ago>'.

## Evidence

- **shared render path:** Automation history rows are rendered via SessionsFlatList (src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts), same as the main sessions list; status text and timestamp are appended in the same .session-details-row flex container (lines ~1404-1439).
