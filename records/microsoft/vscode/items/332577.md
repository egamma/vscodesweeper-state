# Issue #332577 — Extension API: Allow WebviewPanel to be programmatically pinned or unclosable

[https://github.com/microsoft/vscode/issues/332577](https://github.com/microsoft/vscode/issues/332577)

## Summary

Genuine extension-API gap: there is currently no way for an extension to programmatically pin a WebviewPanel's tab or prevent it from being closed by the user; this is a reasonable, narrow API addition worth routing to the webview/extension-API owners.

## Change summary

Add a `fixed`/pinned property to `WebviewPanel`/`WebviewPanelOptions` so extensions can pin or prevent closure of a webview tab.

## Best solution

Route to the webview/extension-API owners to weigh a small API addition (e.g. extending `WebviewPanelOptions`/`WebviewPanel`, likely surfaced via `src/vscode-dts/vscode.d.ts` and the corresponding webview editor input in `src/vs/workbench/contrib/webview/`) that lets an extension request a pinned or unclosable tab state, similar to the existing user-facing 'Pin' action.
