# Issue #34385 — XHR Failed on trying to install plugins via Visual Studio code

[https://github.com/microsoft/vscode/issues/34385](https://github.com/microsoft/vscode/issues/34385)

## Summary

This long-running catch-all issue collects diverse proxy/network failures when installing extensions. VS Code's proxy stack has been substantially reworked since 2017 (multiple @vscode/proxy-agent upgrades, Kerberos support, WebSocket proxy support), but new reports continue to trickle in (most recently Feb 2025), indicating that some proxy configurations still fail. With 108 upvotes it has strong community signal and should remain open.

## Change summary

Extensions marketplace requests fail with 'XHR failed' for users behind certain proxy configurations, preventing extension installation.

## Best solution

This issue has become an umbrella for many distinct proxy/network failure modes. The most actionable path is to keep it open as the canonical proxy-installation tracker under the `proxy` area, and encourage new reporters to file fresh issues with specific proxy type, OS, and network-tab diagnostics so individual root causes can be isolated and fixed. The open sister issue https://github.com/microsoft/vscode/issues/132026 covers similar ground and could be consolidated here.
