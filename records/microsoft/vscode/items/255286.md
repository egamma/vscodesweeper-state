# Issue #255286 — Language Model API doesn't allow system prompt

[https://github.com/microsoft/vscode/issues/255286](https://github.com/microsoft/vscode/issues/255286)

## Summary

The System role exists as a proposed API (`languageModelSystem`) but has not yet been finalized into the stable `vscode.d.ts`. A team member committed to pushing finalization; the issue correctly tracks that remaining work and should stay open.

## Change summary

Finalize the `LanguageModelChatMessageRole.System` role from the proposed API into the stable Language Model API so extensions can send system prompts without workarounds.

## Best solution

Finalize the `languageModelSystem` proposed API — the implementation already exists in `extHostTypes.ts` (System = 3) and the proposed d.ts file. The TODO comment in the proposal notes a design question (dedicated role vs. a `LanguageModelChatRequestOptions#system` property for Anthropic compatibility) that needs resolution before finalization.
