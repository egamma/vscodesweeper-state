# Issue #255286 — Language Model API doesn't allow system prompt

[https://github.com/microsoft/vscode/issues/255286](https://github.com/microsoft/vscode/issues/255286)

## Summary

The System role (value 3) exists in the implementation (`extHostTypes.ts`) and in the proposed API (`vscode.proposed.languageModelSystem.d.ts`) but has not been finalized into the stable `vscode.d.ts` API. A team member committed to pushing finalization in January 2026; this remains a valid tracked item.

## Change summary

Allow a System message role in the Language Model Chat API so extensions can pass system prompts natively instead of faking them as user messages.

## Best solution

Finalize the proposed `languageModelSystem` API — move `LanguageModelChatMessageRole.System = 3` from `src/vscode-dts/vscode.proposed.languageModelSystem.d.ts` into the stable `vscode.d.ts` declaration. The implementation in `extHostTypes.ts` already includes it; the remaining work is the finalization review and stable-API merge.
