# Issue #255286 — Language Model API doesn't allow system prompt

[https://github.com/microsoft/vscode/issues/255286](https://github.com/microsoft/vscode/issues/255286)

## Summary

System messages remain restricted to a proposed API on current main, so the stable extension API still does not cover this request. Keep this accepted finalization work open; the maintainer explicitly supported allowing it and subsequently committed to pursuing finalization.

## Change summary

Allow extensions using the stable Language Model API to supply system instructions separately from user messages.

## Best solution

Finalize a supported system-instruction contract for Language Model API consumers, preserving distinct user and assistant messages and accommodating providers with a top-level system parameter. Treat the Anthropic empty-system rejection as separate provider correctness work, not as a substitute for this API capability.
