# Issue #127226 — [json] create diagnostics text out of markdownDeprecationMessage

[https://github.com/microsoft/vscode/issues/127226](https://github.com/microsoft/vscode/issues/127226)

## Summary

The requested fallback is implemented on current main: Markdown deprecation messages are converted to plain text before being exposed to JSON diagnostics. The merged fix directly covers this issue's central request, so it can be closed as completed.

## Change summary

Generate a plain-text diagnostic message from `markdownDeprecationMessage` when an extension does not also provide `deprecationMessage`.

## Best solution

Keep the behavior merged in https://github.com/microsoft/vscode/pull/297570: derive `deprecationMessage` from `markdownDeprecationMessage`, normalize setting links, and strip remaining Markdown before registering the JSON settings schema.
