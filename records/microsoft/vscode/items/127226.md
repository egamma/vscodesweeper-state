# Issue #127226 — [json] create diagnostics text out of markdownDeprecationMessage

[https://github.com/microsoft/vscode/issues/127226](https://github.com/microsoft/vscode/issues/127226)

## Summary

Still an open gap: the JSON language service (`vscode-json-languageservice`) only uses `deprecationMessage` as plain text for diagnostics and has no awareness of `markdownDeprecationMessage`. When only `markdownDeprecationMessage` is provided, `configurationRegistry.ts` copies the raw markdown into `deprecationMessage`, so raw markdown syntax appears in the diagnostic squiggle. The request to render markdown in diagnostics text remains unimplemented.

## Change summary

JSON diagnostics for deprecated settings should render `markdownDeprecationMessage` as markdown instead of showing raw markdown syntax.

## Best solution

Either teach the `vscode-json-languageservice` upstream to support `markdownDeprecationMessage` and emit markdown-capable diagnostics, or strip/convert markdown to plain text when falling back `markdownDeprecationMessage` to `deprecationMessage` in `src/vs/platform/configuration/common/configurationRegistry.ts` (line ~791). The fuller solution requires upstream changes in `microsoft/vscode-json-languageservice`.
