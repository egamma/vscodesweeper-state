Keep open: a maintainer confirmed simultaneous diagram and conversation scrolling in both window types, and current source still forwards unconsumed webview wheel events without checking inner scrollability. No qualifying fix or older canonical reporting the same symptom was established.

## Change summary

Prevent a macOS trackpad gesture from scrolling both an embedded Mermaid diagram and its surrounding chat conversation while the diagram can still scroll.

## Best solution

Confirm the current inner scrolling mechanism before changing the shared webview-to-chat wheel forwarding path.
