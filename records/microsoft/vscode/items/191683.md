# Issue #191683 — Experience when having a lot of matches

[https://github.com/microsoft/vscode/issues/191683](https://github.com/microsoft/vscode/issues/191683)

## Summary

Quick Search already offers overflow links and an Open in Search View button, but it does not explain the overall result limit or summarize the result set. Keep this maintainer-authored request open for a focused UX decision; the related report was explicitly consolidated into this issue.

## Change summary

Make broad Quick Search queries easier to understand by communicating result volume or truncation and guiding users to the Search View.

## Best solution

Make Quick Search clearly communicate when its displayed results are incomplete, with an understandable handoff to the Search View. Settle whether counts and adaptive per-file limits are part of that experience before implementation.
