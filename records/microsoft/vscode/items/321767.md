# Issue #321767 — Feature Request for Markdown file review windows

[https://github.com/microsoft/vscode/issues/321767](https://github.com/microsoft/vscode/issues/321767)

## Summary

Keep open: current main has a rendered Markdown editor with agent-feedback comments, but that capability is session-scoped rather than established coverage for reviewing arbitrary project Markdown files in the normal workbench. The related request for broader availability is newer and cannot serve as this re-reviewed issue's duplicate canonical.

## Change summary

Provide a Markdown review surface where users can inspect AI edits and attach contextual comments instead of describing changes by line number.

## Best solution

Reuse the existing Markdown editor and agent-comment bridge rather than introduce a separate review implementation. Clarify whether their session-scoped availability meets this request or whether ordinary project Markdown files need the same feedback workflow.

- **Concrete partial implementation:** https://github.com/microsoft/vscode/commit/47ec96853f9339a3b04cb911dad0ae39690da25b, dated 2026-07-07, adds CommentsModel, VsCodeV2CommentsView and CommentModeController to extensions/markdown-language-features/markdown-editor-src/editor.ts and wires addComment/deleteComment in markdownEditorProvider.ts. This implements contextual Markdown commenting, but does not establish unrestricted availability for the report's project-file workflow.
- **Current scope boundary:** src/vs/sessions/contrib/agentFeedback/browser/agentEditorCommentsProvider.ts: AgentEditorCommentsProviderContribution.acceptsComments requires getFeedbackSessionResource(resource), and addComment returns without adding feedback when no session resource exists. The inspected path therefore does not prove that arbitrary Markdown files in the ordinary workbench support this workflow.
