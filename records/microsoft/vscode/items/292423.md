# Issue #292423 — bad soft wrap

[https://github.com/microsoft/vscode/issues/292423](https://github.com/microsoft/vscode/issues/292423)

## Summary

Keep open: the current simple wrapping algorithm can move a fitting word onto the continuation line when the following table-padding spaces overflow. Existing wrapping settings do not provide the requested table alignment, and the older related requests do not own this exact symptom.

## Change summary

Avoid premature word wrapping in padded Markdown table cells and preserve readable alignment of their trailing pipe delimiters.

## Best solution

Resolve the padding-induced premature wrap in the editor wrapping engine, while establishing how trailing table delimiters should align when rows wrap at different positions. Preserve source whitespace and ordinary text wrapping rather than treating disabling wrapping as a complete solution.
