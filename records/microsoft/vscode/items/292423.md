# Issue #292423 — bad soft wrap

[https://github.com/microsoft/vscode/issues/292423](https://github.com/microsoft/vscode/issues/292423)

## Summary

Keep open as a request to improve wrapping of padded Markdown tables. Current wrapping deliberately avoids preferred breaks before spaces and has no table-aware alignment; the older related requests do not cover this report's complete expected behavior.

## Change summary

Preserve table-cell text that fits within the wrapping width and keep trailing Markdown table delimiters visually aligned when rows soft-wrap.

## Best solution

Establish the intended treatment of table padding and cell boundaries before changing editor wrapping. The outcome should improve raw Markdown table readability without undoing the established avoidance of unwanted leading spaces in ordinary wrapped text.

## Evidence

- **Current wrapping behavior:** In src/vs/editor/common/viewModel/monospaceLineBreaksComputer.ts, canBreak explicitly excludes positions before a space. createLineBreaks retains an earlier preferred break while measuring subsequent padding, so overflow within a long padding run can move an earlier word onto the continuation line. The computation operates on characters and widths, not Markdown cells or shared table columns.
- **Established whitespace intent:** https://github.com/microsoft/vscode/issues/47990#issuecomment-579004849 explicitly instructs verification that wrapping points are not introduced immediately before spaces. This supports treating the requested table-specific behavior as an improvement to the existing contract rather than assuming the current character-break rule is accidental.
- **Existing-capability check:** src/vs/editor/common/config/editorOptions.ts registers editor.wordWrap, editor.wordWrapColumn, editor.wrappingIndent, and editor.wrappingStrategy. These control width, continuation indentation, or character measurement; none promises cell cohesion or aligned trailing table pipes. src/vs/editor/browser/view/domLineBreaksComputer.ts computes browser-measured breaks independently for each source line, without table-column coordination. Disabling wrapping avoids the symptom but does not satisfy the request on small screens.
