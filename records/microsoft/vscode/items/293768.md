# Issue #293768 — `chat.agentFilesLocations`, `chat.promptFilesLocations`, and `chat.agentSkillsLocations` resolve custom paths on remote host instead of local host during Remote SSH sessions

[https://github.com/microsoft/vscode/issues/293768](https://github.com/microsoft/vscode/issues/293768)

## Summary

Still reproduces on main: `PromptFilesLocator.toAbsoluteLocations()` calls `this.pathService.userHome()` without `{ preferLocal: true }`, so tilde paths in User settings expand to the remote home directory during SSH/WSL sessions instead of the local one.

## Change summary

Custom `chat.agentFilesLocations`, `chat.promptFilesLocations`, and `chat.agentSkillsLocations` tilde paths resolve on the remote host instead of the local host during Remote SSH/WSL sessions.

## Best solution

In `PromptFilesLocator.toAbsoluteLocations()`, when resolving tilde paths from User-scoped settings, use `this.pathService.userHome({ preferLocal: true })` so `~/` expands to the local user's home directory. Workspace-scoped tilde paths should continue resolving against the remote home. The related issue https://github.com/microsoft/vscode/issues/301167 (WSL variant) shares the same root cause and would be fixed by the same change.
