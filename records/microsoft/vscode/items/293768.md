# Issue #293768 — `chat.agentFilesLocations`, `chat.promptFilesLocations`, and `chat.agentSkillsLocations` resolve custom paths on remote host instead of local host during Remote SSH sessions

[https://github.com/microsoft/vscode/issues/293768](https://github.com/microsoft/vscode/issues/293768)

## Summary

Current main still follows the reported remote-home path: configured tilde locations use the remote-aware path service, while the built-in User Data folder retains its local profile URI. The issue is team-authored, no fixing commit references it, and the later deprecation does not resolve the behavior, so it should remain open and be routed to chat customizations and remote ownership.

## Change summary

User-configured agent, prompt, and skill locations resolve against the remote host instead of the local user environment in Remote SSH windows.

## Best solution

The chat-customizations and remote owners should decide the supported local-versus-remote semantics for user-scoped customization paths during the Local harness migration, then cover that contract with Remote SSH tests. If local locations remain supported until removal, tilde paths from local User settings should use the local home while workspace-relative paths continue to target the remote workspace.
