# Issue #194999 — "Delete Permanently" has misguiding description

[https://github.com/microsoft/vscode/issues/194999](https://github.com/microsoft/vscode/issues/194999)

## Summary

The misleading warning remains on current main: permanent deletion promises that every regular file can be restored with Undo, while the deletion path deliberately omits undo data for files larger than 5 MB. The issue should remain open as an accepted file-explorer bug.

## Change summary

Make the permanent-delete confirmation accurately describe when deleted files can and cannot be restored with Undo.

## Best solution

Ensure the permanent-delete confirmation never promises recoverability when the selected file data will exceed the undo limit, while retaining the existing Undo guidance for selections that can actually be restored.
