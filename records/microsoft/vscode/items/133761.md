# Issue #133761 — A second instance of a notebook is opened when debugging with two editor groups

[https://github.com/microsoft/vscode/issues/133761](https://github.com/microsoft/vscode/issues/133761)

## Summary

The exact fix discussed in this issue's comments — making NotebookEditorInput.matches() recognize cell URIs as belonging to the parent notebook — was implemented in commit 2c7408dac48 (shipped in 1.97.0). This resolves the duplicate notebook opening on debug/problems navigation.

## Change summary

A second notebook editor instance opens in another editor group when navigating to a notebook cell (via debug, problems panel, etc.) while focus is in a different group.

## Best solution

Keep the shipped fix (commit 2c7408dac48, 1.97.0). The NotebookEditorInput.matches() now correctly identifies cell URIs as belonging to the parent notebook, preventing the duplicate editor open.
