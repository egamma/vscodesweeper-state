## Change summary

An unhandled TypeError ('Cannot read properties of undefined (reading 'length')') is thrown from the diagnostics translation pipeline when VS Code reports diagnostics for a document.

## Best solution

Guard the diagnostics-to-offset translation (toDiagnosticData's translateRange callback / _createDiagnosticData in vscodeWorkspace.ts) against a stale/concurrently-edited TextDocument throwing from offsetAt, so a transient race during onDidChangeDiagnostics just drops that diagnostic instead of surfacing an unhandled error.
