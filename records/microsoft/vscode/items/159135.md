# Issue #159135 — Some global properties in tasks.json don't  take effect

[https://github.com/microsoft/vscode/issues/159135](https://github.com/microsoft/vscode/issues/159135)

## Summary

Global options and presentation still bypass inheritance for extension-provided task types such as cppbuild in the current source. Keep this accepted tasks bug open; the missing inheritance occurs in VS Code's configuration parser, not necessarily in the C/C++ extension.

## Change summary

Honor top-level tasks.json options and presentation for configured provider tasks without requiring repeated settings in every task.

## Best solution

Make configured provider tasks honor the applicable global defaults while preserving explicit per-task overrides and existing shell/process task behavior. Cover both parsing and conversion to executable tasks with focused regression tests.
