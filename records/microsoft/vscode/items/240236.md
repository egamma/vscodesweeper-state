# Issue #240236 — Terminal suggest: Support resolving completion items and pull in pwsh command help

[https://github.com/microsoft/vscode/issues/240236](https://github.com/microsoft/vscode/issues/240236)

## Summary

Lazy resolution now exists for language-server terminal completions, but the requested PowerShell Get-Help integration remains missing. Keep this accepted Backlog request open for the remaining provider integration.

## Change summary

Resolve terminal completion documentation on demand so PowerShell command help can appear without fetching help for every suggestion.

## Best solution

Extend on-demand documentation resolution to the built-in PowerShell completion provider, preserving fast initial suggestions and existing completion behavior. Treat --help and man-page enrichment as optional follow-up scope rather than prerequisites.

  > PowerShell terminal suggestions should display command documentation retrieved on demand through Get-Help. Initial completion enumeration must not retrieve documentation for every command. Navigating between suggestions must not attach late documentation to the wrong item, and unavailable help must leave suggestions usable. Existing suggestion insertion and language-server documentation behavior must remain unchanged.
