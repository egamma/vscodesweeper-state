# Issue #325826 — Auto-approve in Copilot multi-chat is session-scoped and applies across chats

[https://github.com/microsoft/vscode/issues/325826](https://github.com/microsoft/vscode/issues/325826)

## Summary

Keep open: current main still exposes approval configuration only at session scope, and the required per-chat protocol capability remains open in https://github.com/microsoft/agent-host-protocol/issues/335. This team-authored report also describes a security-sensitive permission-boundary concern, independently requiring human ownership rather than an automated close.

## Change summary

Scope auto-approve and permission-mode selections to an individual chat instead of sharing them across every chat in an Agent Host session.

## Best solution

Add the proposed per-chat configuration primitive to Agent Host Protocol, sync the generated protocol into VS Code, and route chat-scoped approval properties and picker updates through the active chat channel while retaining session scope for other configuration.
