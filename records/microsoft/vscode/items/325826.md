# Issue #325826 — Auto-approve in Copilot multi-chat is session-scoped and applies across chats

[https://github.com/microsoft/vscode/issues/325826](https://github.com/microsoft/vscode/issues/325826)

## Summary

Still open on main — auto-approve and permission mode are session-scoped, not chat-scoped, and the required protocol-level change (per-chat config in agent-host-protocol) has not landed yet. Team-authored; keep open.

## Change summary

Auto-approve and permission mode in multi-chat sessions apply across all chats in the session instead of being scoped per individual chat.

## Best solution

Land the ChatConfig protocol addition in microsoft/agent-host-protocol (issue #335) first, then flag `permissionMode`/`autoApprove` as `chatScoped` on the VS Code side and route the picker to the active chat channel. The VS Code work likely touches the session config picker in `src/vs/sessions/contrib/providers/agentHost/browser/agentHostSessionConfigPicker.ts` and the permission picker delegate in `agentHostPermissionPickerDelegate.ts`.
