# Issue #138727 — support theme icons in menus in the shadow dom

[https://github.com/microsoft/vscode/issues/138727](https://github.com/microsoft/vscode/issues/138727)

## Summary

The gap remains on current main: shadow-DOM menu styles still hardcode the default glyphs for selection and submenu icons instead of consuming the active product icon theme. This team-authored Backlog debt item should remain open.

## Change summary

Make menu selection and submenu icons inside shadow DOM menus honor product icon theme glyph and font overrides.

## Best solution

Have shadow-DOM menu styling consume the theme-resolved content and font-family information for `menu-selection` and `menu-submenu`, while preserving the default Codicon fallback and ordinary menu behavior.
