# Issue #138727 — support theme icons in menus in the shadow dom

[https://github.com/microsoft/vscode/issues/138727](https://github.com/microsoft/vscode/issues/138727)

## Summary

Still open on main: the hardcoded `formatRule` calls for menu codicons remain in `src/vs/base/browser/ui/menu/menu.ts` (lines 1029–1030), so product icon themes still cannot override menu icons in shadow DOM contexts. The debt is real and unresolved.

## Change summary

Remove hardcoded codicon format rules from menu widget CSS and support product icon theming for menus rendered in shadow DOM.

## Best solution

Pass icon definitions (font family + character code) from the platform icon theme service into the shadow DOM menu styling, so product icon themes can override the default menu selection/submenu icons. The `formatRule` function in menu.ts can then be removed.
