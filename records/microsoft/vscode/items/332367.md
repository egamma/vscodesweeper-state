# Issue #332367 — mismatch update info between agents and editor windows

[https://github.com/microsoft/vscode/issues/332367](https://github.com/microsoft/vscode/issues/332367)

## Summary

The mismatch remains on current main: the editor-window list displays the timestamp selected by its sort mode, while the Agents Window deliberately always displays the last-updated timestamp. This team-authored polish issue should remain open until maintainers choose one consistent cross-surface presentation.

## Change summary

Make session-row timestamp information consistent between the editor window and Agents Window when sorting by creation time.

## Best solution

Choose a shared timestamp-display contract for both session lists—either sort-sensitive timestamps or always-updated timestamps—and apply it consistently to visible labels and accessibility labels without changing ordering semantics.
