# Issue #283150 — Incorrect Copilot documentation

[https://github.com/microsoft/vscode/issues/283150](https://github.com/microsoft/vscode/issues/283150)

## Summary

The documentation remains incorrect: it still says Copilot uses the mac-ca package on macOS, while current VS Code uses its shared certificate-loading infrastructure and the obsolete @roamhq/mac-ca dependency has been removed. Keep this open until the documentation is corrected.

## Change summary

Correct Copilot's certificate troubleshooting documentation so its description of macOS certificate loading matches current VS Code behavior.

## Best solution

Update the GitHub Docs certificate guidance to describe the current VS Code certificate-loading mechanism rather than naming mac-ca, while distinguishing other Copilot clients if their implementations differ.
