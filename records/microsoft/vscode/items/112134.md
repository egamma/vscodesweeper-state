# Issue #112134 — Respect the system setting for mouse scroll speed

[https://github.com/microsoft/vscode/issues/112134](https://github.com/microsoft/vscode/issues/112134)

## Summary

This remains the canonical backlog request for honoring Windows mouse-wheel preferences. Current main offers manual per-surface sensitivity multipliers but does not automatically derive scrolling behavior from the system setting, and 49 upvotes support retaining it.

## Change summary

Make VS Code scrolling respect the operating system's configured mouse-wheel speed.

## Best solution

Investigate preserving the system-adjusted wheel delta in `StandardWheelEvent`, then apply it consistently across editor, workbench lists, and the integrated terminal while retaining explicit sensitivity settings as user overrides.
