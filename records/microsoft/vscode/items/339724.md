# Issue #339724 — Suggestions missing from /plugins disable

[https://github.com/microsoft/vscode/issues/339724](https://github.com/microsoft/vscode/issues/339724)

## Summary

The report is thin (one line plus two screenshots referencing another issue), but it matches a real asymmetry I traced in the slash-command completion provider: `/plugin update`/`uninstall`/`remove` accept non-marketplace ("direct") plugins, while `/plugin enable`/`disable` only ever suggest marketplace-sourced plugins — so a user whose plugin has no marketplace sees suggestions for update but none for disable, exactly as described.

## Change summary

Typing `/plugin disable <tab>` shows no completion suggestions, while `/plugin update <tab>` does.

## Best solution

Decide whether `/plugin enable`/`disable` completions should be extended to non-marketplace ("direct") plugins the same way `/plugin update`/`uninstall`/`remove` already are in copilotSlashCommandCompletionProvider.ts, for parity across subcommands.
