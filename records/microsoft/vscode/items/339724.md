# Issue #339724 — Suggestions missing from /plugins disable

[https://github.com/microsoft/vscode/issues/339724](https://github.com/microsoft/vscode/issues/339724)

## Summary

Thanks for the report. The bug is still present on current main: `/plugin enable` and `/plugin disable` completions only offer plugins that have a marketplace, so host-provided built-in plugins are never suggested. A maintainer comment says a fix is ready, but I found no commit on main that contains it, so this stays open until it merges.

## Change summary

`/plugin disable` (and `enable`) show no completion suggestions for host-provided built-in plugins, while `/plugin update` does.

## Best solution

In copilotSlashCommandCompletionProvider.ts, stop treating every plugin without a marketplace as a direct install. Identify direct installs with the SDK's `directSourceId` (carry it through `getInstalledPlugins` from copilotAgent.ts), offer built-in plugins by bare name for enable/disable, and keep excluding direct installs and managed plugins. Close the issue once that change lands.
