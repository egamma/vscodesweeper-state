# Issue #337511 — 标签页颜色不能修改

[https://github.com/microsoft/vscode/issues/337511](https://github.com/microsoft/vscode/issues/337511)

## Summary

Confirmed regression: the tab-color customization (workbench.colorCustomizations for tab backgrounds) stopped applying because the new 'connected tab' style makes the active tab background match the editor background, overriding user-set colors. The maintainer who introduced this (in a PR referenced as #335605) has acknowledged it in the thread and said they'll look into reconciling it — keeping this open for that fix.

## Change summary

Custom tab background colors set via settings.json (workbench.colorCustomizations) no longer have any visible effect on tab appearance.

## Best solution

Adjust the connected-tab-style rendering path in multiEditorTabsControl.ts / connectedTabClipping.ts so the continuous editor-background look for the active tab still respects explicit TAB_ACTIVE_BACKGROUND (and related) color customizations, rather than unconditionally overriding them.

Acceptance: a set tab.activeBackground (or equivalent) customization is reflected in the tab's rendered background under the connected style, without breaking the intended continuous look when no customization is set.
- **Trace:**

  > The connected tab style (introduced in the PR referenced by the maintainer as #335605) makes the active tab's background match the editor background for visual continuity, implemented via connectedTabClipping.ts and the background rules in multiEditorTabsControl.ts (search for TAB_ACTIVE_BACKGROUND usage and the CSS gradient rules around line 2895).
