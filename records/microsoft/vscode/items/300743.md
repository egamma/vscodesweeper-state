# Issue #300743 — Git - project with a lot of submodules take ages to sync

[https://github.com/microsoft/vscode/issues/300743](https://github.com/microsoft/vscode/issues/300743)

## Summary

This is a valid Git behavior request: sync currently delegates submodule recursion to Git, while repositories with many submodules need an explicit way to disable recursion during pull.

## Change summary

Allow Git sync to pull the root repository without recursively updating its numerous submodules.

## Best solution

Expose a resource-scoped pull/sync submodule-recursion setting in the built-in Git extension, passing `--no-recurse-submodules` when selected while preserving Git's inherited behavior by default.
