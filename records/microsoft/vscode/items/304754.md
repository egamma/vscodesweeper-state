[https://github.com/microsoft/vscode/issues/304754](https://github.com/microsoft/vscode/issues/304754)

## Summary

The attached transcript confirms that Autopilot continued after presenting completion text and retained autonomous behavior after switching to a read-only Ask agent. Current main has partial safeguards, but newer reports show the completion-loop failure still occurs, so this older issue should remain open rather than be closed against an unverified fix.

## Change summary

Prevent Autopilot from repeatedly continuing completed work or attempting unavailable actions after the user switches to a read-only chat mode.

## Best solution

Make Autopilot completion and mode transitions honor the effective mode and tool set consistently: a completed or substantive text-only response should terminate, and switching to a read-only agent must immediately discard stale action-oriented state. Cover both paths with regression tests around the tool-calling loop and mode-transition request state.
