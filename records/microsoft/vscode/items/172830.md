# Issue #172830 — Telemetry service has methods ending in `2` such s `publicLog2`

[https://github.com/microsoft/vscode/issues/172830](https://github.com/microsoft/vscode/issues/172830)

## Summary

The naming debt remains on current main: the typed, GDPR-classified APIs still use the `publicLog2` and `publicLogError2` names while their untyped predecessors remain deprecated. This should stay open as accepted telemetry debt, but completing it requires a cross-cutting migration rather than a small rename.

## Change summary

Remove numeric suffixes from the preferred typed telemetry logging APIs while clearly separating or eliminating their deprecated untyped predecessors.

## Best solution

Inventory and migrate the remaining untyped telemetry events to classified payloads, then make the typed APIs the canonical `publicLog` and `publicLogError` surface without weakening GDPR type checks or changing emitted event names and data.
