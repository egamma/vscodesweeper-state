# Issue #265744 — Have voice input in command palette/ settings search

[https://github.com/microsoft/vscode/issues/265744](https://github.com/microsoft/vscode/issues/265744)

## Summary

Team-authored accessibility feature request from a usability study — must stay open for maintainer judgment. Voice input for command palette and settings search is a reasonable extension of existing voice capabilities.

## Change summary

Allow users to use voice input to search in the command palette and settings, e.g. saying "Create a terminal" or "open a new file".

## Best solution

Extend the existing workbench-voice infrastructure to support voice-to-text input in the command palette (quick input) and settings search widgets, so users can discover and invoke commands or find settings by speaking naturally. The voice integration likely lives around `src/vs/workbench/contrib/chat/browser/actions/voiceChatActions.ts` and the quick-input service; the work would wire voice recognition into those input fields as an alternative input mode.
