# Issue #320055 — TypeScript: Select TypeScript Version rewrites js/ts.tsdk.path in .code-workspace incorrectly

[https://github.com/microsoft/vscode/issues/320055](https://github.com/microsoft/vscode/issues/320055)

## Summary

Confirmed on current main: when the user selects the workspace TypeScript version via the quick-pick, the code writes back `version.pathLabel` — which in a multi-root workspace is constructed via `path.join(root.name, relativePath)`, normalizing away leading `..` segments and corrupting the original setting value.

## Change summary

Selecting the workspace TypeScript version via the quick-pick rewrites `js/ts.tsdk.path`, corrupting relative paths that contain `..` segments in multi-root workspaces.

## Best solution

In `getLocalPickItems()` (versionManager.ts), instead of writing back `version.pathLabel`, read the original `js/ts.tsdk.path` setting from the workspace configuration and preserve it unchanged — the version selection should toggle the `useWorkspaceTsdk` memento without mutating the path. Alternatively, store the original setting value on the `TypeScriptVersion` object and write that back.
