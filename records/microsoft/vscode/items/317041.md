# Issue #317041 — Chat terminals are nowhere to be found

[https://github.com/microsoft/vscode/issues/317041](https://github.com/microsoft/vscode/issues/317041)

## Summary

The core discoverability problem — chat terminals are not visible in the terminal tabs and clicking the command in chat doesn't reveal them — remains unaddressed on main. PR #322121 only fixed disposal of user-revealed terminals on session switch (closing #321049), but the underlying UX gap persists: the default `outputLocation` is `'chat'`, so terminals stay hidden unless the user knows the workaround setting. No commit references this issue.

## Change summary

Chat terminals created by agent tool invocations are not discoverable — they don't appear in terminal tabs and clicking the command in chat doesn't open them.

## Best solution

Improve chat terminal discoverability: either make clicking the terminal command in the chat widget reveal the associated terminal, or surface hidden agent terminals more prominently in the terminal tab UI. The relevant code is in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/chatTerminalToolConfirmationSubPart.ts` and the terminal agent tools contribution under `src/vs/workbench/contrib/terminalContrib/chatAgentTools/`.
