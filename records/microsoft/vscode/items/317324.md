# Issue #317324 — Warning about restricted AI features shows up even with chat.disableAIFeatures=true

[https://github.com/microsoft/vscode/issues/317324](https://github.com/microsoft/vscode/issues/317324)

## Summary

Still reproduces on main: AccountPolicyGateContribution shows the enterprise restriction warning notification regardless of whether the user has set chat.disableAIFeatures=true. The apply() method never checks the AI-disabled setting before showing the notification.

## Change summary

When chat.disableAIFeatures is true, the enterprise account-policy restriction notification still appears on every launch/reload, despite AI features being fully disabled.

## Best solution

In AccountPolicyGateContribution.apply(), suppress the notification (and possibly the context key / setForceHidden call) when chat.disableAIFeatures is true. The notification is irrelevant when AI features are already disabled by the user. The fix lives in src/vs/workbench/services/policies/browser/accountPolicyGateContribution.ts.
