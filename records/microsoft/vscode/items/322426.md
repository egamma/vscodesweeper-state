# Issue #322426 — Agent host + welcome window starts a session but doesn't reveal it

[https://github.com/microsoft/vscode/issues/322426](https://github.com/microsoft/vscode/issues/322426)

## Summary

Keep open: the welcome page still compares submission events against its original session resource, while contributed sessions materialize to a different resource before the event fires. This leaves a concrete path where the session is created but the welcome page never opens it.

## Change summary

Reveal the newly created AHP Copilot conversation when submitting a chat from the welcome page in an empty window.

## Best solution

Make the welcome page recognize submission of its materialized contributed session and open that conversation, while ignoring submissions from other chat widgets. Investigate the comment's remote catalogue visibility report separately unless a shared cause is established.
