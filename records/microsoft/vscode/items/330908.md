# Issue #330908 — Extension command titles lose localization after installing/updating an extension until full restart (VS Code 1.133)

[https://github.com/microsoft/vscode/issues/330908](https://github.com/microsoft/vscode/issues/330908)

## Summary

Traced and confirmed on current main: `createExtensionScannerInput` stores the raw (possibly undefined) `language` on `ExtensionScannerInput` while `translations` correctly falls back to `platform.language`, so incremental scans (extension install/update) skip loading `package.nls.<locale>.json`. An open PR (#331626) already fixes this but hasn't merged — keep the issue open for that PR to land rather than closing.

## Change summary

After installing/updating an extension without a full VS Code restart, all extension-provided command titles lose localization until the app is fully restarted.

## Best solution

Land https://github.com/microsoft/vscode/pull/331626, which passes `language ?? platform.language` into `ExtensionScannerInput` (matching the `translations` fallback already used a line above) in src/vs/platform/extensionManagement/common/extensionsScannerService.ts so incremental scans behave like full scans.
