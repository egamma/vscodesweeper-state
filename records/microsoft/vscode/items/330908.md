# Issue #330908 — Extension command titles lose localization after installing/updating an extension until full restart (VS Code 1.133)

[https://github.com/microsoft/vscode/issues/330908](https://github.com/microsoft/vscode/issues/330908)

## Summary

Confirmed real bug in current source, and a fix is already up as an open PR (#331626) that references this issue with closing syntax — keep open until that PR lands rather than closing now.

## Change summary

After installing/updating an extension while VS Code is running, that extension's (and other extensions') command titles lose localization until a full restart, because the incremental extension scan doesn't pass a language.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/331626, which falls back to `platform.language` in `createExtensionScannerInput` so the incremental scan behaves like the full scan; close this issue once that PR merges.
