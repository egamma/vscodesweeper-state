Team-authored issues are protected from judgment closes, and this is genuinely fresh, actionable polish work — should stay open for the Model Management UX owners.

## Change summary

When VS Code auto-detects a Claude/BYOK API key (outside the signed-out flow), it silently contributes a model provider with no explainer, leaving users confused about where it came from and how to remove it.

## Best solution

Add an explainer or provenance indicator in the Model Management UI (chat model picker/manage models) for auto-detected BYOK providers, similar to the notification shown in the signed-out flow, so users understand why a provider appeared and how to disable detection.
