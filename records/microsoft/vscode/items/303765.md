# Issue #303765 — Synchronized scrolling in markdown preview

[https://github.com/microsoft/vscode/issues/303765](https://github.com/microsoft/vscode/issues/303765)

## Summary

Fixed on main by PR #312237 (which explicitly references this issue) and shipped in 1.124.0. The fix prevents the scroll feedback loop by guarding `scrollTo` calls with an `isScrolling` check in both `StaticMarkdownPreview` and `DynamicMarkdownPreview`.

## Change summary

Markdown preview jumps back unpredictably when scrolling with the mouse due to a scroll feedback loop between the editor and the preview.

## Best solution

Keep the shipped fix (commit dcd26d57169 in PR #312237, shipped in 1.124.0). No further change needed.
