[https://github.com/microsoft/vscode/issues/87565](https://github.com/microsoft/vscode/issues/87565)

## Summary

Custom chords already work, but they do not provide the requested user-only prefix guaranteed to remain free of built-in and extension bindings. Keep this request open for discussion; the matching open report is newer and cannot serve as the canonical duplicate for this re-reviewed item.

## Change summary

Reserve a keyboard shortcut prefix exclusively for user-defined chords so built-in commands and extensions do not occupy it.

## Best solution

Decide whether VS Code should establish a documented user-only chord namespace, including its cross-platform compatibility and extension expectations. Coordinate with the newer matching request at https://github.com/microsoft/vscode/issues/178686 while retaining this older report.
