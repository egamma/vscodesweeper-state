# Issue #87565 — Reserve shortcut prefix for user 

[https://github.com/microsoft/vscode/issues/87565](https://github.com/microsoft/vscode/issues/87565)

## Summary

A real product decision remains: custom chords work and override contributed bindings, but VS Code still provides no documented prefix guaranteed to remain reserved for users. Route this to the keybindings area for discussion rather than closing it.

## Change summary

Reserve a keyboard-chord prefix exclusively for user-defined shortcuts so future defaults and extensions cannot occupy it.

## Best solution

Decide on and document a cross-platform user leader chord, then prevent built-in and extension-contributed keybindings from claiming that prefix while preserving existing user-keybinding precedence.
