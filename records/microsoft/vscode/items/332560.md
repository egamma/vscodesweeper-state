# Issue #332560 — Code Agent Host client protocol and server protocol version mismatch (0.7.0 vs ^0.8.0)

[https://github.com/microsoft/vscode/issues/332560](https://github.com/microsoft/vscode/issues/332560)

## Summary

Verified duplicate: this is the exact same defect already tracked and reproduced in detail at https://github.com/microsoft/vscode/issues/326440 — the same 1.134.0 build, same error message (client 0.7.0 vs server ^0.8.0), with a root-cause writeup already posted there.

## Change summary

Running `code agent host` then `code agent ps` fails because the bundled CLI's Agent Host Protocol client version doesn't match the bundled standalone Agent Host server's required version.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/326440, which already has a root-cause analysis: the Stable CLI's Rust `ahp`/`ahp-types` Cargo dependency is pinned to protocol 0.7.0 while the TypeScript Agent Host server ships 0.8.0 in the same 1.134.0 build — the CLI's Cargo.toml pin needs to track the server's protocol bump in lockstep.
