# Issue #302644 — Light themes use widget border color for breadcrumbs control but dark themes don't

[https://github.com/microsoft/vscode/issues/302644](https://github.com/microsoft/vscode/issues/302644)

## Summary

Keep open as a valid visual/theming bug: current main still applies a light-theme-only breadcrumbs bottom border from `editorWidget.border`, which matches the reporter's traced regression and prevents using `editorGroupHeader.border` to control that border independently.

## Change summary

Light themes draw a breadcrumbs bottom border using `editorWidget.border`, unlike dark themes and unlike the expected editor group header border customization path.

## Best solution

Have the breadcrumbs/theme owner decide whether the light-theme border should be removed or tied to the editor group header border color instead of `editorWidget.border`, with the change localized to the breadcrumbs control styling.
