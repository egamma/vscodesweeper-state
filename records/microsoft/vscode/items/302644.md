# Issue #302644 — Light themes use widget border color for breadcrumbs control but dark themes don't

[https://github.com/microsoft/vscode/issues/302644](https://github.com/microsoft/vscode/issues/302644)

## Summary

The light-theme-only breadcrumb border remains in current source, but the same observable problem is already tracked by the older, open issue 301248. Removing that border, as a maintainer has endorsed in the related discussion, also resolves this report's inability to hide it independently of other widgets.

## Change summary

Eliminate the light-theme-only breadcrumb bottom border that uses editorWidget.border instead of editorGroupHeader.border.

## Best solution

Consolidate the remaining work on https://github.com/microsoft/vscode/issues/301248 and follow the maintainer-endorsed direction of removing the unnecessary breadcrumb border. Preserve this report's theme-token coupling and light-versus-dark comparison in the consolidation.
