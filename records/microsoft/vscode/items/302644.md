# Issue #302644 — Light themes use widget border color for breadcrumbs control but dark themes don't

[https://github.com/microsoft/vscode/issues/302644](https://github.com/microsoft/vscode/issues/302644)

## Summary

The light-theme-only breadcrumb border remains in current source, but the same observable regression is already tracked by the older, open issue https://github.com/microsoft/vscode/issues/301248. Consolidate there, preserving this report's finding that editorGroupHeader.border no longer controls the separator.

## Change summary

Light themes display a breadcrumb bottom border tied to editorWidget.border, unlike dark themes, preventing independent customization through editorGroupHeader.border.

## Best solution

Resolve the unwanted breadcrumb separator under https://github.com/microsoft/vscode/issues/301248, following the maintainer's stated direction to remove it rather than requiring users to change borders on unrelated editor widgets.
