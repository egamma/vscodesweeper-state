# Issue #322341 — SIGPIPE error in Remote SSH Extension Host on client disconnect

[https://github.com/microsoft/vscode/issues/322341](https://github.com/microsoft/vscode/issues/322341)

## Summary

Valid bug: the SIGPIPE handler in remoteExtensionHostAgentServer.ts logs an error on every graceful client disconnect because PersistentProtocol.sendDisconnect() flushes to an already-closed socket. An open PR (#322398) addresses this — keep open pending that PR's review.

## Change summary

Graceful Remote SSH client disconnect produces a spurious 'Unexpected SIGPIPE' error log on the server side.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/322398, which wraps the flush in sendDisconnect() with an EPIPE catch, matching the existing pattern in ProtocolWriter.dispose(). The fix is in src/vs/base/parts/ipc/common/ipc.net.ts (PersistentProtocol.sendDisconnect).
