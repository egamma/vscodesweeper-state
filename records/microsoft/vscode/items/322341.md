[https://github.com/microsoft/vscode/issues/322341](https://github.com/microsoft/vscode/issues/322341)

## Summary

The current IPC teardown path can flush a disconnect message after the client socket has closed, producing the reported non-fatal SIGPIPE log. Keep the issue open and route it to the remote connection area while the linked fix PR is reviewed.

## Change summary

Gracefully closing a Remote-SSH session logs an unexpected SIGPIPE error even though the extension host exits normally.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/322398 after confirming that it suppresses only expected EPIPE failures during disconnect while preserving all other socket errors.
