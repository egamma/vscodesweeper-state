## Summary

Multiple prior duplicates (#316265, #316342, #312654) were closed pointing to the same canonical.

## Change summary

Copilot CLI agent tools all fail when the working directory is a WSL UNC path (\\wsl.localhost\...), because the agent host cannot resolve the CWD on the Windows side.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/317380, which tracks full WSL (and Dev Container) support for the agent host. Initial WSL connection support landed in f4839fb2f09 and a1ffdd33f12, but the work is ongoing with active regressions still being reported there.
