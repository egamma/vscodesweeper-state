# Issue #333701 — Custom Endpoint wizard saves the endpoint as the group name and leaves models[].url empty

[https://github.com/microsoft/vscode/issues/333701](https://github.com/microsoft/vscode/issues/333701)

## Summary

Clear, reproducible bug in the Custom Endpoint wizard (empty models[].url leads to an unhandled TypeError), and a fix PR is already open referencing this issue, so the right move is to review/land that PR rather than propose an independent fix.

## Change summary

The Custom Endpoint model-picker wizard saves the endpoint URL as the group name and leaves the per-model `url` field blank, causing a `TypeError` in `createOpenAIEndPoint` on first chat request.

## Best solution

Land https://github.com/microsoft/vscode/pull/333702, which guards the empty URL in `resolveCustomEndpointUrl`/`createOpenAIEndPoint` (extensions/copilot/src/extension/byok/vscode-node/customEndpointProvider.ts) and surfaces a clear config error instead of throwing; also worth confirming the wizard itself is updated to populate `models[].url` and use a human-readable group `name` rather than the raw endpoint URL.
