# Issue #333701 — Custom Endpoint wizard saves the endpoint as the group name and leaves models[].url empty

[https://github.com/microsoft/vscode/issues/333701](https://github.com/microsoft/vscode/issues/333701)

## Summary

Still open and valid: the Custom Endpoint wizard persists the entered endpoint as the provider group `name` and leaves `models[].url` empty, and the endpoint construction path consumes that URL without a guard. A contributor reproduced it and opened https://github.com/microsoft/vscode/pull/333702, so this stays open until that PR lands or is declined.

## Change summary

The Manage Models Custom Endpoint wizard writes the typed endpoint into the group `name` and saves an empty `models[].url`, so the first request throws a TypeError instead of reaching the endpoint.

## Best solution

Review and land (or decline) https://github.com/microsoft/vscode/pull/333702: the wizard should write the entered endpoint into `models[].url` and use a readable provider label for the group `name`, and `resolveCustomEndpointUrl`/`createOpenAIEndPoint` in extensions/copilot/src/extension/byok/vscode-node/customEndpointProvider.ts should surface a clear configuration error for a blank URL rather than crashing.
