Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/280486 tracks the same 8000-pixel image error making subsequent chat requests fail because the oversized image remains in history.

## Change summary

Allow a chat to recover after an oversized image causes a 400 response instead of resending the invalid image on every subsequent request.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/280486 and make failed image-bearing requests recoverable by excluding or rolling back the invalid historical image before the next request.
