# Issue #224505 — terminal completion provider extension API

[https://github.com/microsoft/vscode/issues/224505](https://github.com/microsoft/vscode/issues/224505)

## Summary

Keep open: terminal completion providers remain proposed on current main, so stable extension adoption is still blocked. The earlier finalization was explicitly undone, and the subsequent maintainer feedback remains relevant.

## Change summary

Finalize an extension API for supplying terminal completions so published extensions can use it without proposed-API opt-in.

## Best solution

Complete the terminal completion API review, settle the recorded registration and shell-selection contracts, and expose the approved API through stable vscode.d.ts. Preserve the shell-integration requirement rather than treating unsupported subshells as the outstanding finalization problem.
