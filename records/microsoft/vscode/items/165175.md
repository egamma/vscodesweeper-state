# Issue #165175 — Switching between User and Workspace settings often selects a different entry

[https://github.com/microsoft/vscode/issues/165175](https://github.com/microsoft/vscode/issues/165175)

Current source uses category filtering and stable tree identities, so the original behavior needs verification against that implementation; neither a concrete fix nor an eligible canonical was established.

## Change summary

Switching settings scope unexpectedly changes the selected category and displayed settings even when that category exists in both scopes.

## Best solution

Preserve the selected category when switching between scopes where it remains available. First reproduce using extension categories and scope-dependent preceding groups, then determine whether the settings editor's model refresh still changes selection.
