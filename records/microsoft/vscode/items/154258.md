# Issue #154258 — Menu appears below quick pick

[https://github.com/microsoft/vscode/issues/154258](https://github.com/microsoft/vscode/issues/154258)

## Summary

The original z-index layering bug (menu rendering below quick pick) was fixed in commit a74adedba8f (z-index raised from 2500 to 2575), but the team discussion evolved into an unresolved UX question about whether the quick pick should dismiss when the menubar is interacted with. The `under-discussion` label reflects this open design question.

## Change summary

Menus from the menubar rendered behind the quick pick overlay, making them inaccessible.

## Best solution

The visual layering is resolved. The remaining question is whether to dismiss the quick pick when the menubar receives focus, or to draw a blocking element under it (as suggested by sbatten). A decision from the menus/workbench area owner would resolve this — if the current behavior (menu above quick pick, both interactive) is acceptable, this can be closed as fixed.
