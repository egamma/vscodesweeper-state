Keep open: repeated macOS updater authorization prompts remain reported after upgrading, and the ownership workaround failed for this non-admin user. The dialog originates in Electron’s updater runtime; neither a verified fix nor a canonical covering repeated prompts after cancellation was established.

## Change summary

Stop repeatedly requesting installation of the macOS update helper after a user without administrator privileges cancels.

## Best solution

Have the update integration and Electron/Squirrel runtime honor cancellation without repeatedly interrupting a standard user, while explaining when installation permissions prevent updates. Investigate the permission failure and retry lifecycle rather than treating privileged ownership changes as a universal solution.
