# Issue #306375 — Greater extensibility for hooks beyond shell scripts

[https://github.com/microsoft/vscode/issues/306375](https://github.com/microsoft/vscode/issues/306375)

## Summary

Still a valid open request — hooks today only support shell commands (`type: 'command'`); there is no mechanism to invoke a VS Code extension command as a hook action. The `ChatHookProvider` API lets extensions supply hook config files but the hooks themselves remain shell scripts.

## Change summary

Allow chat hooks to invoke VS Code commands contributed by extensions, not just shell scripts.

## Best solution

Extend the hook schema and executor to support a new hook type (e.g. `type: 'vscode-command'`) that calls `vscode.commands.executeCommand` with the specified command ID and arguments, alongside the existing shell-command type. The schema lives in `src/vs/workbench/contrib/chat/common/promptSyntax/hookSchema.ts` and execution in `extensions/copilot/src/platform/chat/node/hookExecutor.ts`.
