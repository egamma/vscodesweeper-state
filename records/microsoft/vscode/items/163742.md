# Issue #163742 — [html] Ignore html tag in sticky scroll and outline

[https://github.com/microsoft/vscode/issues/163742](https://github.com/microsoft/vscode/issues/163742)

## Summary

The requested filtering is not available on current main: HTML document symbols still include the structural tags, and Sticky Scroll consumes that same outline hierarchy. A newer issue covers inner-scope prioritization for Sticky Scroll, but it is not a valid canonical for this re-reviewed, older request and does not cover the Outline view.

## Change summary

Hide structural `<html>`, `<head>`, and `<body>` elements from HTML Sticky Scroll and the Outline view.

## Best solution

Decide whether HTML structural elements should be omitted from the language service's document symbols or hidden through a configurable symbol-filtering mechanism; coordinate the Sticky Scroll portion with https://github.com/microsoft/vscode/issues/208406 while preserving this issue's distinct Outline requirement.
