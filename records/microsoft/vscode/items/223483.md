## Summary

Verified duplicate of #32840 — the root cause is the same (default macOS font family lacks an emoji font, so variation-selector-16 emoji render as text glyphs). A contributor already identified this in the comments, and the workaround is the same.

## Change summary

Emoji characters with U+FE0F variation selector render as monochrome text glyphs instead of color emoji in the editor on macOS.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/32840 which tracks the long-standing emoji font-fallback problem. The fix — adding 'Apple Color Emoji' to the default macOS font family or improving font fallback for emoji sequences — belongs there.
