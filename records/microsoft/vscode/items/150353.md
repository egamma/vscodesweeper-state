# Issue #150353 — SCM - provide state information for a repository

[https://github.com/microsoft/vscode/issues/150353](https://github.com/microsoft/vscode/issues/150353)

## Summary

Keep this accepted, team-authored request open: current Git UI provides partial operation-state feedback, but not consistent, explicit repository-state information with discoverable abort actions. No verified older canonical or issue-referencing fix establishes completion.

## Change summary

Show when a repository is merging, rebasing, or cherry-picking, with an accessible way to abort the active operation.

## Best solution

Provide clear, repository-specific operation-state information in the SCM UI, with discoverable actions appropriate to that state. Build on the Git extension's existing operation detection and commands rather than treating its current icons, tooltips, and command-palette actions as complete coverage.
