# Issue #221873 — Add css variables with editor font settings

[https://github.com/microsoft/vscode/issues/221873](https://github.com/microsoft/vscode/issues/221873)

## Summary

Keep open as editor/workbench technical debt: the issue identifies repeated manual propagation of editor font settings and the resulting risk that auxiliary UI becomes stale after configuration changes. No related canonical issue or completed fix is established by the provided discussion.

## Change summary

Expose editor font settings as CSS variables so workbench UI that renders code can reuse them and update consistently when editor configuration changes.

## Best solution

Define a shared, editor-owned CSS-variable contract for relevant editor font properties, keep it synchronized with effective editor configuration, and migrate suitable workbench code-rendering surfaces away from one-off inline font styles.
