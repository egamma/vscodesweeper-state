# Issue #221873 — Add css variables with editor font settings

[https://github.com/microsoft/vscode/issues/221873](https://github.com/microsoft/vscode/issues/221873)

## Summary

The broader work requested here — exposing CSS variables for editor font settings to reduce duplicate manual fontInfo styling across the UX — remains largely undone. A narrow `--editor-font-size` variable was added for tokenization font sizing, but dozens of call sites still manually read fontInfo and set element styles imperatively.

## Change summary

Replace manual `fontInfo.fontSize`/`lineHeight`/`fontFamily` style assignments across UX code with CSS variables set once on the editor widget.

## Best solution

Expand the CSS variable approach started in `codeEditorWidget.ts` to include `--editor-font-family` and `--editor-line-height`, then migrate the ~30+ call sites that manually read fontInfo and set element styles (hover widget, suggest widget, rename widget, parameter hints, notebook cells, debug widgets, etc.) to use these variables via CSS instead. This eliminates duplicate code and fixes stale-styling bugs where config changes aren't watched.
