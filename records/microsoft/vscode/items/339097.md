# Issue #339097 — Agents window: Subagents menu replaces the active chat while subagent pills open to the side

[https://github.com/microsoft/vscode/issues/339097](https://github.com/microsoft/vscode/issues/339097)

## Summary

Team-authored bug report with a precise, source-confirmed root cause: the two entry points for opening a subagent chat call different ISessionsService methods, producing inconsistent placement. This stays open for a fix; it's a bounded, agent-ready change.

## Change summary

Opening a subagent chat from the Subagents menu replaces the active chat, while opening the same chat via the subagent pill opens it to the side — the two entry points should behave consistently.

## Best solution

Change the Subagents menu's `open` callback in sessionBackgroundActivitiesControl.ts to call `sessionsService.openChatToSide(currentSession, subagent.resource, { referenceChatResource: currentSession.resource })`, mirroring the pill opener in openSubagentChat.ts, so both paths open to the side.
