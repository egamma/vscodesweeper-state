# Issue #339366 — Should the simple "open file" picker auto-select the pre-filled text?

[https://github.com/microsoft/vscode/issues/339366](https://github.com/microsoft/vscode/issues/339366)

## Summary

Keep open for an initial-selection UX decision: current source explicitly places the caret at the end of the simple file picker's pre-filled directory. This team-authored accessibility item has neither a verified fixing commit nor a verified canonical duplicate.

## Change summary

Consider selecting the simple Open File picker's pre-filled path automatically so users can replace it without first selecting all.

## Best solution

Agree on an accessible initial-selection policy for the simple Open File picker, balancing immediate path replacement against appending to the suggested directory. Apply the chosen behavior within SimpleFileDialog without unintentionally changing Save dialog filename selection or subsequent directory navigation.
