# Issue #339366 — Should the simple "open file" picker auto-select the pre-filled text?

[https://github.com/microsoft/vscode/issues/339366](https://github.com/microsoft/vscode/issues/339366)

## Summary

Team-authored accessibility-sync observation posed as an open question ("should we reconsider..."), not a settled bug report — current code confirms the described behavior, but whether auto-select is the right fix is a design call for a maintainer, not an automated verdict.

## Change summary

The simple Open File picker (files.simpleDialog.enable) places the cursor at the end of the pre-filled path instead of selecting it all, unlike most other pre-filled search/quick-pick fields.

## Best solution

A maintainer should decide whether to set valueSelection to select the full pre-filled path in SimpleFileDialog's quick pick for consistency with other pickers, weighing any impact on the existing autocomplete/typing flow in that dialog.
