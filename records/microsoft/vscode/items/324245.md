# Issue #324245 — BYOK: Can't use local model when VS Code Window is started without internet

[https://github.com/microsoft/vscode/issues/324245](https://github.com/microsoft/vscode/issues/324245)

## Summary

Valid bug: BYOK local models fail when the VS Code window starts without internet. Prior offline BYOK work (commits 56582e6155f, 20ed2bc21d4) improved the scenario but didn't fully resolve it — the chat setup / entitlement resolution path still blocks local model usage on a cold offline start. No fix referencing this issue has landed on main.

## Change summary

Locally hosted BYOK models cannot be used when VS Code is started without an internet connection, even though they don't require network access.

## Best solution

The chat setup and entitlement resolution flow needs to allow local BYOK models to function independently of network-dependent sign-in/entitlement checks. The likely area is the interaction between `ChatEntitlementService` (sign-in gating), `HasByokModelsContribution`, and the chat setup providers in `src/vs/workbench/contrib/chat/browser/chatSetup/`. The `clientByokEnabled` context key defaults to `true`, but the broader chat UI enablement likely requires a successful entitlement resolution that can't complete offline.
