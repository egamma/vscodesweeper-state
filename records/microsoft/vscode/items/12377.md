# Issue #12377 — Mac: Provide a setting to hide the title bar and inline the window controls

[https://github.com/microsoft/vscode/issues/12377](https://github.com/microsoft/vscode/issues/12377)

## Summary

A substantial, still-unimplemented macOS workbench request with 350 community upvotes and a Backlog milestone; it should remain open as the platform-specific title-bar design issue.

## Change summary

Add a macOS setting that reclaims title-bar height by placing native window controls alongside existing workbench UI.

## Best solution

Design a supported macOS layout that combines the native traffic-light region with tabs or another workbench bar while preserving window dragging, tab reordering, zoom, fullscreen, and hidden-sidebar configurations. Coordinate the cross-platform tab/title-bar concept with https://github.com/microsoft/vscode/issues/107123 without losing this issue's macOS-specific requirements.
