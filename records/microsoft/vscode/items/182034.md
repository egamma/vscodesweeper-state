The reported horizontal-scrolling overflow is addressed by a merged fix that keeps custom tree action buttons aligned with the visible panel edge. The implementation remains present on current main; subsequent action-background problems are tracked separately.

## Change summary

Keep inline tree action buttons visible when horizontal scrolling is enabled and item labels exceed the panel width.
