# Issue #182034 — Right Overflow

[https://github.com/microsoft/vscode/issues/182034](https://github.com/microsoft/vscode/issues/182034)

## Summary

Verified duplicate: this reports the same bug as #251722 — tree view action buttons disappearing when `workbench.list.horizontalScrolling` is enabled. That issue was fixed in commit a102af468e4 and shipped in 1.110, so this can be closed as a duplicate.

## Change summary

Tree view inline action buttons overflow out of the viewport and become unreachable when `workbench.list.horizontalScrolling` is enabled and an item's text exceeds the panel width.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/251722, which tracked and fixed this exact bug — actions are now right-aligned to the viewport edge during horizontal scrolling. No further work needed.
