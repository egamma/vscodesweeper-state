# Issue #348567 — Screenshot editing: support Undo/Redo shortcuts

[https://github.com/microsoft/vscode/issues/348567](https://github.com/microsoft/vscode/issues/348567)

## Summary

Keep open: screenshot markup supports Undo and Redo through toolbar buttons, but its keyboard handler does not support either shortcut. This is a bounded keyboard-consistency improvement.

## Change summary

Support standard Undo/Redo shortcuts while editing screenshot annotations.

## Best solution

Make keyboard Undo and Redo operate on the screenshot annotation history while markup has focus, preserving native text-field editing and isolation from underlying workbench editors.
