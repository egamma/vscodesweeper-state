# Issue #270444 — Add a submenu to the snooze option

[https://github.com/microsoft/vscode/issues/270444](https://github.com/microsoft/vscode/issues/270444)

## Summary

Keep open: the NES gutter still dismisses its menu and opens a duration quick pick, so the requested interaction improvement remains missing. Maintainers support simplifying it, but have not chosen between a duration submenu and a five-minute default.

## Change summary

Allow users to snooze next edit suggestions directly from the gutter menu without switching to a separate duration picker for common choices.

## Best solution

Provide a direct, keyboard-accessible snooze interaction in the NES gutter while retaining the existing command for choosing longer or custom durations. Resolve the recorded submenu-versus-default choice before implementation.
