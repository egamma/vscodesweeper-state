# Issue #270444 — Add a submenu to the snooze option

[https://github.com/microsoft/vscode/issues/270444](https://github.com/microsoft/vscode/issues/270444)

## Summary

The gutter Snooze action still opens a separate quick pick, so the requested interaction improvement remains missing. Keep this team-authored, maintainer-supported request open; the unresolved choice is an in-place duration submenu versus immediate five-minute snoozing.

## Change summary

Let users snooze Next Edit Suggestions directly from the gutter menu without switching to a separate duration picker.

## Best solution

Provide a focused, consistent snooze interaction within the NES gutter workflow while retaining the standalone command for other durations. The area owner should settle whether the gutter offers duration choices or immediately applies five minutes, then define the displayed choices if a submenu is selected.
