# Issue #200896 — Restart button is often not visible

[https://github.com/microsoft/vscode/issues/200896](https://github.com/microsoft/vscode/issues/200896)

## Summary

Still an active, team-acknowledged bug with significant community interest (27 upvotes). The root cause was identified as a context key race condition in the Jupyter extension (multi-window scenarios), and the tracking issue in vscode-jupyter remains open. No fix has landed.

## Change summary

The notebook toolbar 'Restart' button intermittently disappears because Jupyter extension context keys (`jupyter.kernel.isjupyter`, `canrestartNotebookkernel`) are incorrectly cleared, especially in dual-window setups.

## Best solution

The fix belongs in the Jupyter extension's context key lifecycle management — specifically how `jupyter.kernel.isjupyter` and `jupyter.notebookeditor.canrestartNotebookkernel` are scoped across multiple VS Code windows. The canonical tracking issue is https://github.com/microsoft/vscode-jupyter/issues/16189 (still open). A team member (@Yoyokrazy) reproduced the issue and identified the failing context keys; the next step is a fix in vscode-jupyter that properly scopes these keys per window.
