# Issue #309436 — Artifact group labels should not have the word "Rules: " as a prefix

[https://github.com/microsoft/vscode/issues/309436](https://github.com/microsoft/vscode/issues/309436)

## Summary

Keep open: current source still prefixes rules-derived artifact groups with "Rules: " when multiple sources are present. The issue is already correctly routed and describes a bounded label cleanup, not the separate artifact-filename problem.

## Change summary

Show rules-derived artifact group names without the "Rules: " prefix.

## Best solution

Make the configured category name the primary label in the chat artifacts tree, including multi-source sessions, while preserving agent/subagent identification and existing artifact interactions. Any explanation of rules provenance should remain secondary rather than competing with the category name.
