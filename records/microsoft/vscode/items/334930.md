# Issue #334930 — Webview Find Widget does not work when panel is datached

[https://github.com/microsoft/vscode/issues/334930](https://github.com/microsoft/vscode/issues/334930)

## Summary

Plausible, architecturally-grounded bug: moving a webview to a detached/auxiliary window fully tears down and recreates the underlying webview (OverlayWebview.claim disposes and remounts on window-id change), which is exactly the kind of transition that could leave the find message channel or find-result wiring in a stale state; not conclusively pinned to one line, so this needs a live-repro trace rather than a close.

## Change summary

The webview Ctrl+F find widget opens but returns no matches once the editor/webview panel has been detached into its own window.
