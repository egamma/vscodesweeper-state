# Issue #162688 — Code action widget status bar border does not match editor hovers

[https://github.com/microsoft/vscode/issues/162688](https://github.com/microsoft/vscode/issues/162688)

## Summary

The visual inconsistency remains on current main: the code-action widget's status/action-bar divider uses the hover-border token at full opacity, while equivalent editor-hover separators use it at 50% opacity. This team-authored Backlog polish item should remain open.

## Change summary

Make the code-action widget status-bar separator visually match the softer separators used by editor hovers.

## Best solution

Use one consistent separator treatment for equivalent editor-hover and code-action-widget divisions, while retaining the full-strength outer widget border and appropriate high-contrast behavior.
