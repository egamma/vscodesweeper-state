# Issue #230406 — VSCode opens automatically when I plug in a mass storage device or click on "open with File Manager" (dolphin)

[https://github.com/microsoft/vscode/issues/230406](https://github.com/microsoft/vscode/issues/230406)

## Summary

Already fixed on main and shipped: commit f1c007109d0 removed `inode/directory` and `text/plain` from the desktop file's MimeType, preventing VS Code from registering as a directory/file-manager handler on Linux. The reporter was on 1.93 but likely had a stale desktop entry from a prior install.

## Change summary

VS Code registered itself as a handler for directories and plain text on Linux, causing it to open instead of the native file manager when plugging in storage devices or clicking 'open with file manager'.

## Best solution

Keep the shipped fix from commit f1c007109d0 (resources/linux/code.desktop no longer advertises inode/directory or text/plain). No further change needed. Users on older installs may need to run `xdg-mime default dolphin.desktop inode/directory` to reset their cached association.
