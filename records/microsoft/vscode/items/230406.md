# Issue #230406 — VSCode opens automatically when I plug in a mass storage device or click on "open with File Manager" (dolphin)

[https://github.com/microsoft/vscode/issues/230406](https://github.com/microsoft/vscode/issues/230406)

## Summary

Keep open: directory-handler registration has been removed from current packaging, but that change predates this report against VS Code 1.93 and does not establish that the reported behavior is resolved. The Kubuntu steps suffice to retest; whether the launch comes from retained associations, distribution packaging, or desktop handler selection remains unconfirmed.

## Change summary

Opening a mounted storage device through Kubuntu's file-manager action unexpectedly launches VS Code instead of Dolphin.

## Best solution

Establish which desktop entry and MIME association launch VS Code on the reported Kubuntu path, then address any remaining packaging defect without overriding explicit user associations. Preserve the existing removal of directory-handler advertising; a new clean installation and an upgraded installation should both leave Dolphin handling directories.
