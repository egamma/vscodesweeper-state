# Issue #230406 — VSCode opens automatically when I plug in a mass storage device or click on "open with File Manager" (dolphin)

## Summary

Verified duplicate of #114425, which was closed as upstream — VS Code's .desktop file does not register inode/directory; the directory-handling default is a desktop-environment configuration issue, not a VS Code bug.

## Change summary

VS Code opens when plugging in mass storage or clicking 'open with file manager' on Linux instead of the native file manager.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/114425 — the root cause is the same (DE/xdg-mime misconfiguration), and the fix is the same (`xdg-mime default dolphin.desktop inode/directory`). No VS Code code change is needed.

This is the same issue tracked in https://github.com/microsoft/vscode/issues/114425 — VS Code's `.desktop` file does not register itself as a handler for `inode/directory`; the root cause is the desktop environment's default-application configuration. The fix is to reset your directory handler:
  > 
  > ```
  > xdg-mime default dolphin.desktop inode/directory inode/mount-point
  > ```
  > 
  > or via KDE System Settings → Default Applications.
