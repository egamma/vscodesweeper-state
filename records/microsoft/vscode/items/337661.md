# Issue #337661 — SDK session authentication failed: Failed to fetch Copilot user info after successful auth with GHE

[https://github.com/microsoft/vscode/issues/337661](https://github.com/microsoft/vscode/issues/337661)

## Summary

Verified duplicate of the older, open https://github.com/microsoft/vscode/issues/330657, which tracks the same root cause (CopilotCLIModels/session auth falling back to a hardcoded github.com host for GHE users) and whose thread has comments from today describing this exact 'session.create failed... Bad credentials' failure.

## Change summary

After signing in via GitHub Enterprise (GHE.com), the Copilot sign-in dialog keeps reappearing and Copilot CLI/agent sessions fail with '401 Unauthorized: Bad credentials' when fetching Copilot user info/models.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/330657 — fix CopilotCLISDK.getAuthInfo()'s fallback branch (extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCli.ts, ~line 674) to use the configured GitHub Enterprise host instead of hardcoding 'https://github.com' when resolveAuthInfoFromToken doesn't return userInfo.
