# Issue #323578 — New Chat button is flaky

[https://github.com/microsoft/vscode/issues/323578](https://github.com/microsoft/vscode/issues/323578)

## Summary

Keep open: current main still permits concurrent New Session invocations to independently create drafts. This team-authored, re-reviewed issue has no issue-referencing fix commit or qualifying older canonical.

## Change summary

Rapidly clicking the Agents window New Chat button can stall the UI and create multiple chats, while some invocations appear to do nothing.

## Best solution

Coalesce repeated invocations while a New Session navigation is in flight so one user gesture sequence creates at most one draft. Preserve the documented no-op when the empty new-session placeholder is already active.
