# Issue #127932 — Custom keyboard layouts does not works properly on ozone wayland only mode

[https://github.com/microsoft/vscode/issues/127932](https://github.com/microsoft/vscode/issues/127932)

## Summary

Still reproduces on main: the `native-keymap` module lacks Wayland support (microsoft/node-native-keymap#17 is open), so keyboard layout detection falls back to incorrect data in pure Wayland sessions. Multiple users confirm the issue through 2025. This is an upstream dependency gap that VS Code cannot fix without changes to node-native-keymap.

## Change summary

Custom keyboard layouts are not correctly detected or applied when running VS Code in native Wayland mode (without XWayland), because the underlying native-keymap module has no Wayland-native keyboard layout query path.

## Best solution

Resolve by adding Wayland keyboard layout detection in `microsoft/node-native-keymap` (issue microsoft/node-native-keymap#17), then consuming the updated module in VS Code. This is a dependency-level fix — the VS Code keyboard layout service (`src/vs/platform/keyboardLayout/electron-main/keyboardLayoutMainService.ts`) delegates entirely to `native-keymap` and would automatically benefit. Tracks alongside https://github.com/microsoft/vscode/issues/207033 (defaulting to Wayland).
