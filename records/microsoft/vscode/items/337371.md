# Issue #337371 — Support Copilot CLI mcp-config.json as an MCP Add Server destination

[https://github.com/microsoft/vscode/issues/337371](https://github.com/microsoft/vscode/issues/337371)

## Summary

Fresh, well-scoped feature request from a team member describing a confirmed gap: current main discovers/reads `~/.copilot/mcp-config.json` for MCP servers but the Add Server destination picker has no write path to it, so users hand-edit the file and can corrupt it (wrong top-level key). No canonical issue owns this; it's new work.

## Change summary

Add Copilot CLI's `mcp-config.json` as a selectable write destination in the MCP Add Server flow, using the existing CLI schema/profile, with atomic merge-preserving writes.

## Best solution

Wire a new McpConfigurationDestination-style Copilot CLI target into mcpCommandsAddConfiguration.ts / mcpConfigurationDestination.ts that resolves COPILOT_HOME (reusing the existing discovery logic in nativeMcpDiscoveryAdapters.ts), selects the CLI generation profile, and performs a guarded merge-write under `mcpServers`.
