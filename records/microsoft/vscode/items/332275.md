# Issue #332275 — Pet: Go on the run is not hiding

[https://github.com/microsoft/vscode/issues/332275](https://github.com/microsoft/vscode/issues/332275)

## Summary

Real, code-traceable bug in the brand-new chat pet 'Go on the Run' feature: the CSS only translates the pet button down by a fixed spacing token instead of ensuring it's actually clipped out of view, so at normal scale it stays partially visible instead of fully hiding as intended.

## Change summary

Invoking the chat pet's 'Go on the Run' action leaves the pet partially visible instead of hiding it.

## Best solution

In src/vs/workbench/contrib/chat/browser/widget/media/chatPet.css, the `.chat-pet-button.on-the-run` rule (line ~270) only applies `transform: translateY(var(--vscode-spacing-size400))`; since `.chat-pet-host`/`.chat-pet-overlay` don't clip overflow, this offset isn't guaranteed to move the 48x48px button fully out of the visible area at normal scale. The related report https://github.com/microsoft/vscode/issues/332395 suggests only a shrunken pet ends up fully hidden — the fix likely needs either a larger offset, an overflow-clipping ancestor, or a scale-aware translate distance in chatPetWidget.ts/chatPet.css.
