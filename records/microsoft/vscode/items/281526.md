# Issue #281526 — Cropped text should have ellipises

[https://github.com/microsoft/vscode/issues/281526](https://github.com/microsoft/vscode/issues/281526)

## Summary

Keep open: the long-distance NES footer still lacks a reliable ellipsis treatment for cropped symbol names. Current source contains ellipsis declarations, but their placement on flex containers does not establish that the reported clipping is resolved.

## Change summary

Show an ellipsis when narrowing the long-distance NES widget truncates its footer symbol name.

## Best solution

Make truncated footer names visibly distinguishable from complete names while preserving the symbol icon and jump instruction. Establish a rendered-widget regression check before changing the footer layout.
