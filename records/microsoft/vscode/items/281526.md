# Issue #281526 — Cropped text should have ellipises

[https://github.com/microsoft/vscode/issues/281526](https://github.com/microsoft/vscode/issues/281526)

## Summary

Keep open as NES visual polish. Current main declares ellipsis styling, but the reported narrow-widget case demonstrates that the rendered outline text can still be clipped without a visible ellipsis, and no later commit clearly fixes that behavior.

## Change summary

Show an ellipsis when the NES long-distance jump widget is too narrow to display its full outline text.

## Best solution

Make the long-distance hint's outline section shrink within the lower flex bar and visibly ellipsize its text while preserving the fixed-size jump action and symbol icon.
