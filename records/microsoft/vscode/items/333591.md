# Issue #333591 — cancelling sign in causes "failure" pop-up

[https://github.com/microsoft/vscode/issues/333591](https://github.com/microsoft/vscode/issues/333591)

## Summary

Fresh, team-authored bug report from testing the new provider sign-in flow (referencing #333246). Traced the cause in chatSetupController.ts: canceling the account picker propagates a cancellation-style error that isn't distinguished from a real sign-in failure, so the generic 'Failed to sign in — Retry?' dialog fires and Retry just re-runs the same flow. No fix exists yet, so this stays open (and as a COLLABORATOR-authored issue it's protected from any judgment close anyway).

## Change summary

Cancelling the 'continue with Microsoft' account picker during Copilot sign-in surfaces a generic 'failed to sign in' error dialog instead of silently cancelling, and Retry loops back into the same picker.

## Best solution

In ChatSetupController.signIn() (src/vs/workbench/contrib/chat/browser/chatSetup/chatSetupController.ts), guard the 'Failed to sign in... Retry?' confirm dialog with an isCancellationError(signInError) check (the same pattern already used in doInstallWithRetry() and install() in the same file) so a deliberate cancel silently returns instead of showing a false failure/retry prompt.
