# Issue #333591 — cancelling sign in causes "failure" pop-up

[https://github.com/microsoft/vscode/issues/333591](https://github.com/microsoft/vscode/issues/333591)

## Summary

Team-authored bug report with no fix commit or duplicate found, so it stays open — but the defect is clearly confirmed on main: cancelling Microsoft sign-in during Copilot chat setup surfaces a generic 'failed to sign in, retry?' dialog instead of quietly cancelling.

## Change summary

Cancelling the Microsoft account sign-in flow during Copilot chat setup shows a 'something went wrong' failure/retry dialog instead of silently cancelling, and Retry just re-triggers the same flow.

## Best solution

In ChatSetupController.signIn(), skip (or reword) the 'Failed to sign in... would you like to try again?' confirm dialog when the underlying error is a user cancellation rather than a genuine failure.
