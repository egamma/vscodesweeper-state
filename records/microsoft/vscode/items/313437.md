## Summary

Keep open and classify the clarified report as a bug: the reporter demonstrated that question and todo UI work in default-agent CLI sessions but fail with the same instructions in a custom agent. Current source provides both UI integrations, but does not establish that the custom-agent failure is fixed; the younger parallel report cannot replace this re-reviewed issue.

## Change summary

Custom agents delegated to Copilot CLI lose interactive question and todo-list behavior that works locally and in default-agent CLI sessions.

## Best solution

Restore equivalent question and todo-list behavior for the supplied custom agent without requiring its instructions to be pasted into a default-agent prompt. Diagnose custom-agent tool availability and instruction handling at the VS Code–CLI SDK boundary, retaining the existing native CLI tools and UI integrations.
