# Issue #341007 — Copilot Connectors: new chat waits for shared-client restart while another chat is active

[https://github.com/microsoft/vscode/issues/341007](https://github.com/microsoft/vscode/issues/341007)

## Summary

Thanks for the detailed report. Current main still has the deferral path: a new chat waits for a shared-client restart while any other chat has an active turn, with no visible wait reason. Team-authored, so kept open.

## Change summary

A new Copilot chat blocks in prepareTurn waiting for a deferred shared-client restart after connector auth changes, while an unrelated chat is active.

## Best solution

Avoid restarting the shared CopilotClient for connector auth changes (refresh auth per session), or at minimum surface the real wait reason and a safe way to proceed instead of showing it as model reasoning.

## Plan brief

- **Likely files:** `src/vs/platform/agentHost/node/copilot/copilotAgent.ts`
- **Validation:** A copilotAgent test: with one chat holding an active turn and connector auth changed, a new session's launch completes (or reports a wait reason) without waiting for the other turn.
- **Behavior:**

  > After connector authentication changes, starting a new chat must not stall behind an unrelated chat's active turn, and any unavoidable wait must be visible to the user with a way forward. Acceptance: a new chat launches while another chat has an active turn.
- **Trace:**

  > _ensureClientForSession in copilotAgent.ts calls _requestClientRestart when connector auth differs; the restart is deferred while the busy-chat count is nonzero and is retried on chat completion. The new session's prepareTurn awaits that restart. Do not change restart behavior for non-connector reasons. Uncertainty: whether per-session auth refresh is possible without a client restart.
- **Open decisions:**
  - Refresh connector auth without restarting the shared client, or keep the restart and show an explicit wait state?
  - If waiting remains, should the user get an option to force the restart and interrupt other chats?
