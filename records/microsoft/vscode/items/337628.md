# Issue #337628 — Recognize MiniMax Code CLI for agent terminal tab titles

[https://github.com/microsoft/vscode/issues/337628](https://github.com/microsoft/vscode/issues/337628)

## Summary

MiniMax Code remains absent from the agent CLI recognition paths on current main. Keep this request open for a terminal maintainer to consider the focused contribution; the existing title-template workaround does not provide the requested selective default behavior.

## Change summary

Recognize MiniMax Code so its OSC session titles drive terminal tabs under terminal.integrated.tabs.allowAgentCliTitle while preserving opt-out, explicit overrides, and shell restoration.

## Best solution

Extend the existing terminal agent CLI recognition behavior to MiniMax Code, following the merged Command Code precedent, if the terminal maintainer accepts the contribution. Session renames should update the tab without requiring a title-template change for unrelated terminals.
