# Issue #337628 — Recognize MiniMax Code CLI for agent terminal tab titles

[https://github.com/microsoft/vscode/issues/337628](https://github.com/microsoft/vscode/issues/337628)

## Summary

Well-scoped request from the MiniMax Code CLI maintainer to extend the existing agent-CLI terminal-title recognition to their tool, following the exact precedent already merged for Command Code. It's already correctly labeled `terminal`; the remaining question is a maintainer product call on adding another vendor-specific CLI to the recognized list, not a technical blocker.

## Change summary

Add MiniMax Code CLI (`mcode` / process name `minimax-code`) to VS Code's recognized agent-CLI list so its OSC 0 title (including session renames) drives the terminal tab title when `terminal.integrated.tabs.allowAgentCliTitle` is enabled.

## Best solution

If accepted, add `GeneralShellType.MiniMax` (or similar) alongside Claude/Codex/CommandCode/Copilot/Gemini in terminal.ts, wire process-name detection in terminalProcess.ts (POSIX) and windowsShellHelper.ts (Windows), add an OSC-title regex to `agentCliTitlePatterns` and the `agentCliShellTypes` set in terminalInstance.ts, and add detection/label tests mirroring the existing Command Code tests — exactly the pattern the reporter already proposes to contribute.
