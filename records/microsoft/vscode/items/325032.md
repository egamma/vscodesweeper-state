# Issue #325032 — Reporting a bug from vscode is broken - Whoa there! Your request URL is too long.

[https://github.com/microsoft/vscode/issues/325032](https://github.com/microsoft/vscode/issues/325032)

## Summary

Verified duplicate of #247979, which tracks the same auth-related 'URL too long' issue in the issue reporter's 'Preview on GitHub' flow. When the user lacks a `githubAccessToken`, the reporter falls back to URL-based submission without the attachment-upload shortening, causing GitHub to reject the oversized URL.

## Change summary

The 'Preview on GitHub' action in Help > Report Issue produces a URL that exceeds GitHub's length limit, showing a 'Whoa there! Your request URL is too long' error.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/247979, which is assigned and tracks ensuring proper auth at issue-report time so the API path (with its much higher body-size limit and attachment-upload shortening) is used instead of the URL-based fallback.
