# Issue #303371 — Regression: Extension Host (Code 6) crash on macOS after updating to 26.4

[https://github.com/microsoft/vscode/issues/303371](https://github.com/microsoft/vscode/issues/303371)

## Summary

This is a known issue with the experimental `http.systemCertificatesNode` setting causing Extension Host crashes on macOS when enabled via A/B experimentation. The setting defaults to `false` but has `experiment: { mode: 'auto' }`, and the reporter's workaround of explicitly setting it to `false` confirms it. This is tracked by the open canonical issue #287739.

## Change summary

Extension Host crashes (exit code 6) on macOS 26.4 when the experimental `http.systemCertificatesNode` setting is enabled via A/B experimentation.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/287739, which tracks making Node.js-based system certificate loading reliable enough to enable by default. This report provides useful signal that the setting still crashes on macOS 26.4, which the tracking issue's telemetry gathering should capture.
