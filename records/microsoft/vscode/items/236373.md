# Issue #236373 — `editor.action.selectAll` gets triggered for webview editors, preventing them from overriding the keybinding behavior for ctrl/cmd+a

[https://github.com/microsoft/vscode/issues/236373](https://github.com/microsoft/vscode/issues/236373)

## Summary

Still reproduces on main: `editor.action.selectAll` is registered with `kbExpr: null`, so its fallback implementation steals focus from webview iframes. An open PR (#310056) proposes a fix; keeping open pending that PR's review.

## Change summary

Ctrl/Cmd+A triggers `editor.action.selectAll` in webview-based custom editors, stealing focus from the webview instead of letting it handle select-all.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/310056, which guards the fallback implementation against iframe-focused elements — or apply a similar minimal fix in `EditorOrNativeTextInputCommand`'s fallback path in `src/vs/editor/browser/editorExtensions.ts`.
