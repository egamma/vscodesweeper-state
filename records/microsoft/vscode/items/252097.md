## Change summary

The "Accept All Current" and "Accept All Incoming" merge conflict commands silently do nothing when invoked.

## Best solution

Investigate the command dispatch path in `extensions/merge-conflict/src/commandHandler.ts` — the `registerTextEditorCommand` wrapper (line 43-51) silently returns if `vscode.window.activeTextEditor` is falsy, and `acceptAll` (line 258-273) silently returns if the tracker finds no conflicts. Either the conflict tracker isn't detecting the markers, or the command isn't reaching the handler. Adding logging or surfacing a warning in both early-exit paths would make diagnosing future failures easier.
