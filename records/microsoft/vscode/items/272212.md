# Issue #272212 — Support terminal file line number jump for claude code and codex diff code

[https://github.com/microsoft/vscode/issues/272212](https://github.com/microsoft/vscode/issues/272212)

## Summary

The requested line-number navigation remains missing for the supplied Claude Code and Codex diff formats. Keep this accepted Backlog request open under terminal-links; existing Git diff support does not cover these examples, and no matching canonical was verified.

## Change summary

Make line numbers in Claude Code and Codex terminal diff output open the corresponding file at that line.

## Best solution

Extend terminal link detection to associate numbered diff rows with their preceding file header in both supplied formats, preserving existing ripgrep, ESLint, and Git diff navigation. Establish how removed lines should navigate when their old-file positions no longer exist in the current file.

- **Current capability gap:** At checkout 8571e6fd2f04a40dc0341c05897b93ff132b06f8, src/vs/workbench/contrib/terminalContrib/links/browser/terminalMultiLineLinkDetector.ts recognizes number prefixes only when followed by a colon, or Git hunk headers matching '@@ ... +line,count @@' associated with '+++ b/path'. Neither branch recognizes the supplied space-separated numbered rows or their agent-specific file headers.
