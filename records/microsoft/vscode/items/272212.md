# Issue #272212 — Support terminal file line number jump for claude code and codex diff code

[https://github.com/microsoft/vscode/issues/272212](https://github.com/microsoft/vscode/issues/272212)

## Summary

Valid feature request: the terminal multi-line link detector currently handles ripgrep and git-diff formats but has no matchers for Claude Code or Codex diff output. The gap is real on current main.

## Change summary

Add terminal link detection patterns for Claude Code (`⏺ Update(file)`) and Codex (`• Edited file`) diff output so users can click to jump to the referenced file and line.

## Best solution

Add new matcher patterns in `src/vs/workbench/contrib/terminalContrib/links/browser/terminalMultiLineLinkDetector.ts` for Claude Code and Codex diff formats, similar to the existing `gitDiffMatchers` — extract the file path and line number from their respective output patterns. These tools are increasingly popular in the terminal, making this a worthwhile addition to core.
