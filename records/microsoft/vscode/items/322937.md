# Issue #322937 — AI is making using VS Code very hard. I cannot do anything without it suggesting and making my code worse

[https://github.com/microsoft/vscode/issues/322937](https://github.com/microsoft/vscode/issues/322937)

## Summary

The requested chat-only workflow is already configurable: automatic inline suggestions and next-edit suggestions can be disabled without disabling Chat. The report does not describe those controls failing.

## Change summary

Allow using AI Chat on demand without unsolicited AI code suggestions.

## Best solution

Use the existing editor.inlineSuggest.enabled and github.copilot.nextEditSuggestions.enabled settings to disable automatic editor suggestions while retaining Chat and ordinary IntelliSense.
