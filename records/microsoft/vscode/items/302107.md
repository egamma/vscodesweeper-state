# Issue #302107 — Sessions: Cloud agent activity on GitHub.com (PR creation, review comments, follow-up commits) is not reflected in the originating session

[https://github.com/microsoft/vscode/issues/302107](https://github.com/microsoft/vscode/issues/302107)

## Summary

Keep open: current source supports task-level follow-up history and PR metadata, but does not establish that GitHub-triggered work in a separate session is reconciled with the originating session. This team-authored request has no verified same-symptom canonical or issue-referencing fix that would justify closing it.

## Change summary

Keep cloud-agent PR artifacts, completion state, and GitHub-triggered follow-up work visible and connected to the originating Agents Window session.

## Best solution

Establish reliable continuity between the originating cloud task and subsequent GitHub review-triggered work, showing either additional turns or explicitly linked follow-up sessions with current status and artifacts. First distinguish what the current Task API already groups under one task from work requiring additional correlation; local cloning should not be required to display remote results.
