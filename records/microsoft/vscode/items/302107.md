Partial progress exists (PR toolbar actions landed in June 2026), but the core ask — bidirectional session continuity across VS Code and GitHub.com — remains an open gap. ## Change summary

Cloud agent activity on GitHub.com (PR creation, review comments, follow-up commits) is not reflected back in the originating session in the Sessions window, forcing users to monitor two disconnected interfaces.

## Best solution

Implement session-level reconciliation so that GitHub.com-side events (review comments, agent follow-up commits, PR status changes) are streamed or polled back into the originating VS Code session. The remaining work likely lives in `src/vs/sessions/` and the cloud agent backend integration layer.
