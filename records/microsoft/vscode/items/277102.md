# Issue #277102 — Support array-based format for `github.copilot.chat.customOAIModels` to avoid key collisions

[https://github.com/microsoft/vscode/issues/277102](https://github.com/microsoft/vscode/issues/277102)

## Summary

Implemented on main: custom OpenAI-compatible models now use named provider groups containing model arrays, so separate providers can expose the same model ID without JSON key collisions.

## Change summary

Allow multiple OpenAI-compatible providers to configure the same model identifier without colliding in the custom-model setting.

## Best solution

Use separate named provider groups in `chatLanguageModels.json`, each with its own secret API key and `models` array; the legacy `github.copilot.chat.customOAIModels` object is migrated and deprecated.
