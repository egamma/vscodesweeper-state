# Issue #255500 — Reindent Lines doesn't work when the line has no initial indent

[https://github.com/microsoft/vscode/issues/255500](https://github.com/microsoft/vscode/issues/255500)

## Summary

The reported JSON case remains source-reproducible: reindentation skips any line whose first token is a string, including an unindented property key. Keep this open; the formatter exploration does not track the same observable defect.

## Change summary

Reindent Lines leaves an unindented JSON property unchanged while correcting the same property when it already has leading whitespace.

## Best solution

Make reindentation handle JSON property lines consistently regardless of existing whitespace, while preserving the protection against changing multiline string contents. Cover both whole-document and selected-line commands through their shared indentation implementation.

## Evidence

- **Current source defect:** In src/vs/editor/contrib/indentation/common/indentation.ts, getReindentEditOperations calls doesLineStartWithString before computing indentation edits and immediately continues when it returns true. That helper checks getStandardTokenType(0) === StandardTokenType.String, without distinguishing a string beginning on this line from multiline string content.
- **Exact JSON trigger:** extensions/json/syntaxes/JSON.tmLanguage.json assigns object keys the scope 'string.json support.type.property-name.json'. For the reporter's column-one '"level2": "foo"', the first token is therefore a string and the line is skipped; leading whitespace places a non-string token first, allowing indentation adjustment. extensions/json/language-configuration.json already defines increaseIndentPattern and decreaseIndentPattern, so missing indentation rules are not the cause.
- **Shared command path:** ReindentLinesAction and ReindentSelectedLinesAction in src/vs/editor/contrib/indentation/browser/indentation.ts both invoke getReindentEditOperations. The defect is in core rather than the extension that originally exposed it.
- **Discussion corroboration:** https://github.com/whitphx/vscode-emacs-mcx/issues/2162#issuecomment-3045649592 supplies the equivalent unindented JSON property example; https://github.com/whitphx/vscode-emacs-mcx/issues/2162#issuecomment-3065712369 confirms the symptom and agrees it is not specific to that extension.
