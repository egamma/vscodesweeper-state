# Issue #331484 — API and possibility to fully color the tabs (focused, unfocused, opacity, text, background)

[https://github.com/microsoft/vscode/issues/331484](https://github.com/microsoft/vscode/issues/331484)

## Summary

Real request for extra editor-tab styling controls (opacity, underline-only style), but a large part of the ask — separately coloring active/inactive/unfocused tab background, foreground, and border — is already covered by existing `workbench.colorCustomizations` theme keys, so this needs routing to the tabs area rather than a close.

## Change summary

Requests a fuller API/settings surface to color tabs (active/inactive/opacity/text/background) and an underline-only tab style.
