# Issue #331484 — API and possibility to fully color the tabs (focused, unfocused, opacity, text, background)

[https://github.com/microsoft/vscode/issues/331484](https://github.com/microsoft/vscode/issues/331484)

## Summary

Fresh (1-day-old, 0 upvotes) request for finer tab theming; VS Code already exposes a large set of `tab.*` color tokens (active/inactive/unfocused foreground, background, border, borderTop, hover, selected, modified) via `workbench.colorCustomizations`, which covers most of the ask, but there's no explicit opacity control and the request may want more than the existing tokens already provide.

## Change summary

Requests full theming control over editor tabs — separate colors/opacity for focused vs. unfocused tabs, text color, background, and an underline-only style.

## Best solution

Point the reporter to the existing `tab.activeForeground`/`tab.inactiveForeground`/`tab.unfocusedActive*`/`tab.unfocusedInactive*`/`tab.activeBorderTop`/`tab.unfocusedActiveBorderTop` color tokens in `src/vs/workbench/common/theme.ts`, which already let a theme or `workbench.colorCustomizations` differentiate focused/unfocused tabs and apply an underline-style top border; if a genuine gap remains (e.g. true alpha/opacity control) that should be scoped into a narrower, concrete ask.
