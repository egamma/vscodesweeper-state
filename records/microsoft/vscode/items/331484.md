# Issue #331484 — API and possibility to fully color the tabs (focused, unfocused, opacity, text, background)

[https://github.com/microsoft/vscode/issues/331484](https://github.com/microsoft/vscode/issues/331484)

## Summary

Existing theme settings cover active, inactive, and unfocused tab colors, but not independently styling individual tabs according to usage or importance. Keep the request open for product discussion; the related requests inspected do not own its full scope.

## Change summary

Expose per-tab styling controls or an API for foreground, background, opacity, and underline indicators across focus states.

## Best solution

Determine whether a theme-aware per-tab decoration API should let extensions distinguish frequently used or important tabs without overriding selection and accessibility cues. Reuse existing theme customization for global tab-state colors rather than introducing a parallel styling system.

## Evidence

- **Existing capability:** src/vs/workbench/common/theme.ts registers tab.activeBackground, tab.inactiveBackground, tab.unfocusedActiveBackground, corresponding foreground colors, and tab.activeBorder/tab.activeBorderTop. These provide global state-based customization through workbench.colorCustomizations, not independent colors based on each tab's usage or importance.
- **Modern tab customization:** src/vs/workbench/services/themes/browser/modernTabColorCustomizations.ts, collectModernTabColorCustomizations, maps legacy and modern tab color customizations into state-specific CSS variables. This preserves a global theming surface; it does not expose the requested per-tab styling API.
- **Extension API boundary:** src/vscode-dts/vscode.d.ts defines Tab with read-only label, input, group, and state properties, but no styling controls. FileDecoration provides a ThemeColor, badge, and tooltip; src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts:1852 applies file-decoration colors and badges to the resource label, not independent tab backgrounds, opacity, or underline styles.
- **Closest API precedent:** https://github.com/microsoft/vscode/issues/142300 requested an API for coloring all tabs, including borders. Its final bot comment, https://github.com/microsoft/vscode/issues/142300#issuecomment-1094163448, closed it for insufficient community upvotes, not implementation or a maintainer decision rejecting the capability. It is neither an open duplicate canonical nor grounds for declining this request.
- **Related requests are not canonicals:** https://github.com/microsoft/vscode/issues/31308 is open but concerns coloring tabs by workspace project or folder, not usage-based individual styling. https://github.com/microsoft/vscode/issues/263091 is open but its body and discussion concern reducing tab-bar size. Neither establishes the same observable request and full scope required for a duplicate close of this re-reviewed item.
