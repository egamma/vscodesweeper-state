[https://github.com/microsoft/vscode/issues/331022](https://github.com/microsoft/vscode/issues/331022)

## Summary

Keep open for a targeted Settings Sync retest: current Modern UI code responds to configuration changes without reloading, but that does not establish that first-time sync updates the reported decorations correctly. The Fedora KDE installation and sync steps suffice to retest; the modernization implementation has evolved since the report.

## Change summary

After enabling Settings Sync in a fresh Insiders installation, the expected window styling appears only after reinitializing the window.

## Best solution

Ensure synced Modern UI styling reaches an already-open workbench without requiring reinitialization. First distinguish that styling from native window-frame settings, whose documented behavior intentionally requires a full restart.
