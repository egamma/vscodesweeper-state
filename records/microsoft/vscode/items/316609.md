# Issue #316609 — Explorer view sorting keeps changing

[https://github.com/microsoft/vscode/issues/316609](https://github.com/microsoft/vscode/issues/316609)

## Summary

Current source intentionally preserves the order of folders in the `.code-workspace` file, so the reported move of the first root to the end would be a bug, but the intermittent trigger is not established. More detail is needed to distinguish an Explorer ordering defect from behavior during the failed Remote-SSH connection.

## Change summary

Explorer intermittently displays multi-root workspace folders in an order different from their `.code-workspace` entries.

## Best solution
