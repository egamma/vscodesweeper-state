# Issue #300089 — UI Space

[https://github.com/microsoft/vscode/issues/300089](https://github.com/microsoft/vscode/issues/300089)

## Summary

Keep open: current commands move the whole chat session, not the prompt input and askQuestions area independently. The requested shared input popout remains a distinct capability, and the verified related issues do not qualify as duplicate canonicals.

## Change summary

Allow the prompt input and askQuestions controls to share a separate popout so more of the original chat surface can display responses.

## Best solution

Have the chat UI owner evaluate an optional detached interaction surface that preserves the session connection while leaving the transcript in its original location. Whole-chat window movement is a useful alternative but does not fulfill this request.
