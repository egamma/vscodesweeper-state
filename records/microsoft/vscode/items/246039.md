# Issue #246039 — Adding an MCP Server from a private NPM doesn't work

[https://github.com/microsoft/vscode/issues/246039](https://github.com/microsoft/vscode/issues/246039)

## Summary

Keep open: assisted NPM setup still queries the public registry directly, so private-only packages remain unsupported on this path. The related custom-package-source request is newer and cannot replace this older, previously reviewed report under the duplicate rules.

## Change summary

Allow assisted MCP server setup to resolve NPM packages from private registries, including configured npm package sources.

## Best solution
