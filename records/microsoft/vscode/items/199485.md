# Issue #199485 — Support scrolling at the end of the file at the top of the editor in Multi diff editor

[https://github.com/microsoft/vscode/issues/199485](https://github.com/microsoft/vscode/issues/199485)

## Summary

Keep open: the multi-diff editor still does not provide the requested scroll-past-end behavior. The existing editor setting is overridden, and the older related reports cover different interactions rather than this remaining capability.

## Change summary

Allow scrolling the final file in a multi-diff editor until its last line reaches the top of the viewport.

## Best solution

Provide scroll-past-end behavior at the end of the overall multi-diff document, consistent with editor.scrollBeyondLastLine, without adding a viewport-sized gap between individual files.
