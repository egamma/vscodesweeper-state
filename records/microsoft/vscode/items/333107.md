# Issue #333107 — Copilot commit msg generation won't work if "github.copilot.chat.commitMessageGeneration.instructions" set

[https://github.com/microsoft/vscode/issues/333107](https://github.com/microsoft/vscode/issues/333107)

## Summary

Confirmed duplicate: this is the same 422 promptFiltered regression already tracked by the older, more-discussed open issue https://github.com/microsoft/vscode/issues/328072 — commit-message generation silently fails whenever `github.copilot.chat.commitMessageGeneration.instructions` is non-empty.

## Change summary

Setting `github.copilot.chat.commitMessageGeneration.instructions` to any non-empty value makes Copilot commit-message generation fail silently (server returns 422 promptFiltered).

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/328072 (open since 2026-07-29, 10 comments, same root cause and repro steps) rather than tracking three parallel reports; the fix belongs either server-side in the Responsible AI filtering of `GitCommitMessagePrompt` or client-side surfacing the `PromptFiltered` failure in `extensions/copilot/src/extension/prompt/node/gitCommitMessageGenerator.ts` instead of leaving the commit box empty.
