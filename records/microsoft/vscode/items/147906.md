# Issue #147906 — Text selection (with left click + drag down) does not scroll window up within notebook cells

[https://github.com/microsoft/vscode/issues/147906](https://github.com/microsoft/vscode/issues/147906)

## Summary

The issue remains valid: recent commits restructured notebook cell layout (limiting cell editor height to viewport, Oct 2025) and added pointer-drag state tracking (Nov–Dec 2025), but explicitly gate scroll propagation during drag-selection — the notebook still does not auto-scroll when the user drags a text selection past the bottom of the viewport inside a cell.

## Change summary

Text selection via click-and-drag in a notebook cell does not auto-scroll the notebook when the pointer moves below the viewport edge.

## Best solution

Implement an auto-scroll mechanism in the notebook list view (or the CodeCellLayout coordination) that detects when an active drag-selection moves the pointer past the viewport boundary and scrolls the notebook accordingly — similar to how list views and standalone editors handle edge-scrolling during drag. The fix likely belongs in `src/vs/workbench/contrib/notebook/browser/view/cellParts/codeCell.ts` in the `registerMouseListener` / `onMouseMove` path, where pointer-drag state is already tracked.
