# Issue #252464 — UI glitch when terminal is in secondary sidebar and env variables overridden

[https://github.com/microsoft/vscode/issues/252464](https://github.com/microsoft/vscode/issues/252464)

## Summary

The reported secondary-sidebar title-toolbar overlap is now covered by a targeted responsive-layout change and regression test, so this can be closed as completed.

## Change summary

A terminal title enlarged by an environment-variable status could overlap neighboring title actions when the terminal was placed in the secondary side bar.

## Best solution

Keep the responsive auxiliary-bar toolbar behavior introduced by commit 291bd409e8acd0128700bf48d97b45ddc4c25a66, which moves leading actions into overflow as space contracts and prevents title/action overlap.
