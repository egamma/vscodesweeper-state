# Issue #245540 — Disable the dependency extension installation

[https://github.com/microsoft/vscode/issues/245540](https://github.com/microsoft/vscode/issues/245540)

## Summary

Real bug: dependency extensions (Python, Pylance, debugpy) are uninstalled and reinstalled when a second extension sharing the same dependencies is installed in a remote (no-internet) environment, sometimes leaving extensions in an invalid state. The reporter has provided all requested info; the info-needed label is stale.

## Change summary

Installing a second extension with shared dependencies on a remote server causes the already-installed dependency extensions to be uninstalled and reinstalled, sometimes corrupting the Python extension.

## Best solution

The dependency resolution in `abstractExtensionManagementService.ts` (line 658 and line 410-414) should correctly skip already-installed dependencies regardless of the remote/local installation path. The `isApplicationScoped` check at line 412 may be causing a false mismatch in remote scenarios, triggering unnecessary reinstallation. The `info-needed` label should be removed since the reporter supplied all requested logs.
