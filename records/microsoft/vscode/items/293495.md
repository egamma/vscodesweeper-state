# Issue #293495 — Missing "continue in background" button

[https://github.com/microsoft/vscode/issues/293495](https://github.com/microsoft/vscode/issues/293495)

## Summary

Keep open: a second maintainer independently confirmed the missing background button, and neither a qualifying fix nor an older canonical reporting the same symptom was established. The current source identifies the action's visibility gates, but not which condition caused the reported failure.

## Change summary

The Continue in Background button sometimes disappears while a foreground terminal command is still running, preventing the user from releasing the agent without interrupting the command.

## Best solution

Make Continue in Background reliably available for an eligible running foreground terminal command, preserving the process when the agent resumes. Diagnose the terminal association and toolbar state first, then cover the identified failure in the chat terminal progress-part tests.
