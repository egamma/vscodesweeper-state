# Issue #322149 — Incorrect line numbers for CCR feedback

[https://github.com/microsoft/vscode/issues/322149](https://github.com/microsoft/vscode/issues/322149)

## Summary

Keep open as an upstream GitHub review-position defect: GitHub's API and its own file view identify the feedback as lines 160–164 even though that location does not contain the reviewed code. The Agents Window currently renders the coordinates supplied by GitHub.

## Change summary
