# Issue #330258 — The Modern UI went too far

[https://github.com/microsoft/vscode/issues/330258](https://github.com/microsoft/vscode/issues/330258)

## Summary

The requested gap-free Modern UI is now available through compact layout density. Current main removes both inter-panel gaps and outer gutters without requiring users to disable Modern UI, so this can be closed as completed.

## Change summary

Remove the distracting, space-consuming gaps and floating-card treatment between Modern UI workbench parts, or offer a compact alternative.

## Best solution

Use "window.density.layout": "compact" with Modern UI enabled. This provides connected, square-edged workbench surfaces while preserving internal separators and essential control padding.
