# Issue #277667 — October 2025 release breaks GitHub Copilot `Ctrl+Y` "Keep" shortcut.

[https://github.com/microsoft/vscode/issues/277667](https://github.com/microsoft/vscode/issues/277667)

## Summary

Keep open: the thread documents an incorrectly false hunk context key, independent confirmation, and a workaround that interferes with normal redo. Current main still uses that context key for Ctrl+Y; no verified fix or qualifying duplicate was found.

## Change summary

Ctrl+Y intermittently invokes redo instead of keeping the chat-generated change containing the editor cursor.

## Best solution

Make hunk-context enablement reliably reflect the focused editor's current chat change, including after accepting changes and switching files, while preserving normal redo outside changes. Diagnose the context-key ownership and update sequence before choosing a bounded fix.

The reported failure leaves the cursor visibly inside an inserted line but dispatches redo because the hunk context is false. Outside pending changes, Ctrl+Y must retain ordinary redo behavior. Acceptance must not depend on typing and undoing a character first or removing the cursor-in-change condition.
