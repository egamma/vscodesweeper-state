# Issue #331823 — Copilot `fetch failed` to send `google` apikey and to download `claud SDK`

[https://github.com/microsoft/vscode/issues/331823](https://github.com/microsoft/vscode/issues/331823)

## Summary

The Claude SDK download side was addressed by the merged Agent Host proxy work, but the distinct Gemini BYOK SOCKS5 failure remains source-reproducible on current main. The issue should remain open for the Gemini transport gap.

## Change summary

Gemini BYOK model discovery and requests bypass VS Code's proxy-aware fetcher, causing `fetch failed` when `http.proxy` uses SOCKS5; the report also captured an older Agent Host SDK-download proxy failure.

## Best solution

Make Gemini model discovery and chat requests honor VS Code's configured proxy transport, including SOCKS5, while preserving the Google SDK's streaming, cancellation, and error behavior. Treat the Claude SDK download as already addressed and keep the remaining work scoped to Gemini BYOK.
