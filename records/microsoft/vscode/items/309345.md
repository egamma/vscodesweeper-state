# Issue #309345 — Feature Request: Make "Terminal: Toggle Size to Content Width" persistent

[https://github.com/microsoft/vscode/issues/309345](https://github.com/microsoft/vscode/issues/309345)

## Summary

Valid feature request: the terminal's 'Toggle Size to Content Width' is a manual, non-persistent toggle with no setting to make it the default for new terminals. No existing setting or implementation covers this.

## Change summary

Request a setting to persist 'Size to Content Width' across terminal sessions so new terminals auto-expand to fit content width.

## Best solution

Add a terminal setting (e.g. `terminal.integrated.sizeToContentWidth`) that, when enabled, applies the content-width sizing by default on new terminal instances. The implementation would live in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts` around the existing `toggleSizeToContentWidth` logic.
