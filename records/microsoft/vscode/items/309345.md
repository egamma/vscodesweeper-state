# Issue #309345 — Feature Request: Make "Terminal: Toggle Size to Content Width" persistent

[https://github.com/microsoft/vscode/issues/309345](https://github.com/microsoft/vscode/issues/309345)

## Summary

The request for a remembered/default content-width mode matches an earlier request explicitly declined by the terminal maintainer. Propose closing on that documented scope decision, not because of age or lack of upvotes.

## Change summary

Allow new terminal sessions to inherit a persistent size-to-content-width preference instead of requiring the command each time.

## Best solution

Retain explicit per-terminal sizing under the existing maintainer decision, with Terminal: Set Fixed Dimensions as a manual alternative. Automatic content-width sizing would require reconsidering the decision documented in https://github.com/microsoft/vscode/issues/208779.
