# Issue #300819 — unable to customize the GIT `scm.providerCountBadge` color

[https://github.com/microsoft/vscode/issues/300819](https://github.com/microsoft/vscode/issues/300819)

## Summary

The provider count badge already supports color customization through the shared badge.background and badge.foreground theme colors, including in the reported build. Propose closing with the existing configuration rather than adding an SCM-specific color.

## Change summary

Customize the background and text colors of Source Control provider count badges.

## Best solution

Use badge.background and badge.foreground inside workbench.colorCustomizations; these shared theme tokens control the provider count badge and other count badges consistently.

- **Proposed comment:**

  > Thanks for the report. Source Control provider count badges use the shared `badge.background` and `badge.foreground` theme colors, which were already supported in the build you reported. You can customize them in settings.json:
  > 
  > ```json
  > "workbench.colorCustomizations": {
  >     "badge.background": "#806000",
  >     "badge.foreground": "#FFFFFF"
  > }
  > ```
  > 
  > These colors also affect other count badges; there is no separate SCM-specific color token. Closing as covered by the existing theme customization.
