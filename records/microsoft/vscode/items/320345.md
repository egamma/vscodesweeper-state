Valid feature request to auto-discover models from an OpenAI-compatible `/models` endpoint in BYOK configuration. Currently at 19 upvotes with the community process still running — keep open and let it complete.

## Change summary

Allow `chatLanguageModels.json` to auto-fetch available models from an OpenAI-compatible API endpoint instead of requiring manual per-model declarations.

## Best solution

If promoted to backlog, implement model list fetching via the standard `/models` endpoint in `languageModelsConfigurationService.ts` when a group specifies a `url` but no explicit `models` array.
