# Issue #293403 — GitHub Copilot breaks custom prompt link when editing

[https://github.com/microsoft/vscode/issues/293403](https://github.com/microsoft/vscode/issues/293403)

## Summary

The reported edit/resubmit failure was fixed on main by preserving the original custom-prompt slash command instead of replacing it with a raw Markdown link. The current source re-resolves and reattaches the prompt file when the edited request is submitted again.

## Change summary

Editing and resubmitting a request invoked through `/foo` should retain the custom prompt rather than expose an inaccessible `vscode-userdata` Markdown link.

## Best solution

Keep the behavior introduced by commit e2db4495b34a5bd799b29824fc8d12eb5082545f: retain `/foo` in the stored request and resolve its prompt-file attachment again on resubmission.
