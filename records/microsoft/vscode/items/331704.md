# Issue #331704 — Allow disabling GitHub Copilot as an Agent Host provider without disabling Chat

[https://github.com/microsoft/vscode/issues/331704](https://github.com/microsoft/vscode/issues/331704)

## Summary

Verified gap: Claude and Codex Agent Host providers have per-provider `.enabled` settings, but no `chat.agentHost.copilotAgent.enabled` equivalent exists in the source, so there's no way to fully disable the Copilot provider (models, sign-in prompts, upgrade nudges) while keeping Chat and other providers active. This is a real, well-scoped request that should be routed to the chat/agentHost area rather than closed.

## Change summary

Add a `chat.agentHost.copilotAgent.enabled` setting to fully disable the Copilot Agent Host provider (registration, model advertisement, sign-in/upgrade UI) without disabling Chat or other providers.

## Best solution

Add `chat.agentHost.copilotAgent.enabled` alongside the existing `AgentHostClaudeAgentEnabledSettingId`/`AgentHostCodexAgentEnabledSettingId` pattern in src/vs/platform/agentHost/common/agentService.ts and agentHostStarter.config.contribution.ts, gating Copilot provider registration and model-selector/sign-in UI the same way the Claude/Codex toggles do.
