# Issue #331704 — Allow disabling GitHub Copilot as an Agent Host provider without disabling Chat

[https://github.com/microsoft/vscode/issues/331704](https://github.com/microsoft/vscode/issues/331704)

## Summary

Genuine gap confirmed on main: `chat.agentHost.claudeAgent.enabled` and `chat.agentHost.codexAgent.enabled` exist (src/vs/platform/agentHost/common/agentService.ts:180,188) but there is no `chat.agentHost.copilotAgent.enabled` equivalent — only an unrelated `chat.agentHost.copilotAgent.multiRootEnabled`. The maintainer's suggested `chat.agentHost.allowSignedOutWhenUsable` only relaxes the sign-in requirement; it does not stop Copilot from being registered/offered, so it doesn't resolve this request.

## Change summary

Add a `chat.agentHost.copilotAgent.enabled` setting to fully disable the Copilot Agent Host provider (registration, model selector entries, sign-in/upsell UI) while keeping Chat and other providers (Codex, Claude, BYOK) enabled.

## Best solution

Add a per-provider `chat.agentHost.copilotAgent.enabled` setting mirroring the existing claudeAgent/codexAgent ones in src/vs/platform/agentHost/common/agentHostStarter.config.contribution.ts and agentService.ts, gating Copilot provider registration the same way; a maintainer should confirm scope (whether it also needs to suppress the sign-in/upsell notifications in agentHostSdkSetupNotification.ts) before implementation.
