# Issue #331704 — Allow disabling GitHub Copilot as an Agent Host provider without disabling Chat

[https://github.com/microsoft/vscode/issues/331704](https://github.com/microsoft/vscode/issues/331704)

## Summary

Verified gap: Claude and Codex agent-host providers each have a `chat.agentHost.<provider>Agent.enabled` toggle, but Copilot only has `chat.agentHost.copilotAgent.multiRootEnabled` — there is no equivalent enable/disable switch for the Copilot provider itself, matching the reporter's claim.

## Change summary

Add a `chat.agentHost.copilotAgent.enabled` setting so users can disable the Copilot Agent Host provider (registration, model selector entries, sign-in/upgrade prompts) while keeping Chat and other providers (Codex, Claude, BYOK) enabled.

## Best solution

Introduce `chat.agentHost.copilotAgent.enabled` in src/vs/platform/agentHost/common/agentHostStarter.config.contribution.ts and agentService.ts, mirroring the existing `claudeAgent`/`codexAgent` enabled settings and their registration gating, then thread it through Chat's model selector and provider-registration paths so disabled-but-signed-in Copilot doesn't surface prompts/upgrades.
