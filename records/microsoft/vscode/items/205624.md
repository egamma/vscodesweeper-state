# Issue #205624 — `Copy Image` command in markdown preview editor is invalid and an error is reported.

[https://github.com/microsoft/vscode/issues/205624](https://github.com/microsoft/vscode/issues/205624)

## Summary

PR #240508 partially addressed this by adding a fallback for CORS errors, but a team member (rzhao271) noted that the fallback only copies alt text, not the actual image — and suggested surfacing the CORS error to the user instead. The issue remains valid with `help wanted`; keeping open for further improvement.

## Change summary

Right-clicking an image in the markdown preview and selecting 'Copy Image' fails with an error for CORS-restricted images; after the partial fix, it silently copies only alt text instead of the image.

## Best solution

Improve the CORS fallback in `extensions/markdown-language-features/preview-src/index.ts` (`copyImage` function) to either properly copy the image via a proxy/fetch approach or surface a clear CORS error notification to the user, as suggested by rzhao271. The `help wanted` label is appropriate.
