# Issue #258071 — "m" appears when trying to run a command while another is in progress in powershell

[https://github.com/microsoft/vscode/issues/258071](https://github.com/microsoft/vscode/issues/258071)

## Summary

Team-filed bug about a stray 'm' character appearing in PowerShell when pressing Enter while another command is running. No fix commit references this issue, and it likely relates to the kitty keyboard protocol or PSReadLine interaction. Keeping open as a team-authored item with no verifiable fix.

## Change summary

Pressing Enter in PowerShell while a command is in progress inserts the character 'm' instead of executing the new command.

## Best solution

Investigate whether the kitty keyboard protocol's encoding of Enter (`\x1b[13;1u`) is being partially consumed when the shell is busy, leaking the trailing 'm'. The fix likely lives in the shell integration script (`src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.ps1`) or in how xterm.js/the terminal input handler serializes keystrokes under the kitty protocol when PSReadLine is not actively reading input.
