# Issue #341100 — Allow Collapse all for tools when configuring

[https://github.com/microsoft/vscode/issues/341100](https://github.com/microsoft/vscode/issues/341100)

## Summary

Thanks for the feedback from testing. Team-authored request for a Collapse All action, or collapsed-by-default groups, in the tools picker. The picker already collapses some groups by default, but not all of them, so a real gap remains.

## Change summary

The Configure Tools picker needs a way to collapse all tool categories at once, or to start with every category collapsed.

## Best solution

In src/vs/workbench/contrib/chat/browser/actions/chatToolPicker.ts, either collapse all top-level groups by default or add a collapse-all control to the quick tree.
