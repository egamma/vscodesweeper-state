# Issue #347221 — Agents window: let the agent start a PR review session from a pull request link (e.g. `open_pr_session` tool)

[https://github.com/microsoft/vscode/issues/347221](https://github.com/microsoft/vscode/issues/347221)

## Summary

Keep open: the UI supports isolated PR sessions, but the agent-facing session tools still lack a PR input. The assigned 1.148.0 milestone also requires deferring closure to the area owners.

## Change summary

Let an agent turn a pull request link into a PR-linked review session with the correct checkout and context.

## Best solution

Expose agent-accessible PR session creation using the existing PR worktree and context flow, preserving unrelated local changes. Settle whether it creates a separate session or continues the invoking conversation before implementation.
