# Issue #347221 — Agents window: let the agent start a PR review session from a pull request link (e.g. `open_pr_session` tool)

[https://github.com/microsoft/vscode/issues/347221](https://github.com/microsoft/vscode/issues/347221)

## Summary

Keep open: the UI supports PR-backed sessions, but the agent-facing session tools still cannot request one. The assigned 1.147.0 milestone independently bars closing; conversation continuity and remote-repository behavior need product decisions.

## Change summary

Let an agent turn a pull request link into a properly isolated, PR-linked review session with attached context and existing confirmation behavior.

## Best solution

Expose agent-accessible PR-session creation using the existing PR worktree and context facilities, without disturbing unrelated local work. Settle whether the operation creates a separate session or continues the current conversation before implementation.
