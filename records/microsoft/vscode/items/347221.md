# Issue #347221 — Agents window: let the agent start a PR review session from a pull request link (e.g. `open_pr_session` tool)

[https://github.com/microsoft/vscode/issues/347221](https://github.com/microsoft/vscode/issues/347221)

## Summary

Keep open: current source exposes PR-session creation through the UI, but not through the agent's session tools. The assigned 1.149.0 milestone also requires deferring closure to the owning maintainer.

## Change summary

Let an agent turn a pull request link into an isolated, PR-linked review session with attached PR context.

## Best solution

Provide agent access to the existing PR-session creation behavior, retaining worktree isolation, PR association, context attachment, and confirmation. The owner should first settle whether this creates a new session or continues the current chat, and define behavior when the repository is unavailable on the host.
