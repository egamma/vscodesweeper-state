# Issue #347221 — Agents window: let the agent start a PR review session from a pull request link (e.g. `open_pr_session` tool)

[https://github.com/microsoft/vscode/issues/347221](https://github.com/microsoft/vscode/issues/347221)

## Summary

Keep open: the UI supports PR-backed sessions, but the inspected agent session tools cannot request one. The assigned 1.148.0 milestone independently requires keeping this scheduled, team-authored request open.

## Change summary

Let an agent turn a pull request link into an isolated, PR-linked review session with the relevant context attached.

## Best solution

Expose agent-accessible PR session creation using the existing PR checkout and context behavior. First settle whether the operation creates an independent session or continues the current conversation, and define unsupported-repository behavior.
