# Issue #326663 — Agents window markdown editor: Links should not expand until a click has finished

[https://github.com/microsoft/vscode/issues/326663](https://github.com/microsoft/vscode/issues/326663)

## Summary

Keep open as a confirmed interaction-polish gap in the experimental Agents window Markdown editor. It is already routed to the markdown-editor area, and no subsequent fix is present on main.

## Change summary

Delay link expansion until pointer release so dragging from a link can select text normally.

## Best solution

Adjust the @vscode/markdown-editor link gesture handling to expand on a completed click rather than pointer-down, preserving click-and-drag selection, then update the bundled dependency in extensions/markdown-language-features.
