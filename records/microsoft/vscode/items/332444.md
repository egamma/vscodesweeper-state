# Issue #332444 — SCM: "Open Changes" hangs while a commit message is being generated with Copilot

[https://github.com/microsoft/vscode/issues/332444](https://github.com/microsoft/vscode/issues/332444)

## Summary

The blocking condition remains in current main: resolving an SCM multi-file diff waits for all SCM progress badges to disappear, including commit-message generation. Keep this open; the populated-resource case has a bounded diagnosis and an existing test harness.

## Change summary

Open Changes waits for Copilot commit-message generation to finish instead of displaying already-known changes immediately.

## Best solution

Allow the SCM multi-file diff to display available resources independently of unrelated SCM progress, while preserving correct loading behavior during initial repository discovery.
