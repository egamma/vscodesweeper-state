# Issue #328189 — Copilot reports tools are disabled by user even though I have them enabled in "Configure Tools"

[https://github.com/microsoft/vscode/issues/328189](https://github.com/microsoft/vscode/issues/328189)

## Summary

Keep open: multiple reporters confirm that enabled MCP tools can be rejected as user-disabled on current stable, and the discussion identifies category activation as a workaround rather than expected Configure Tools behavior. The team-authored issue is also protected from judgment closes.

## Change summary

Enabled MCP tools intermittently or selectively fail with a misleading "disabled by the user" error until their generated category activation tool is invoked.

## Best solution

Make tool availability and the Configure Tools state agree: either automatically activate an enabled tool's category before invocation or expose category activation clearly as part of the enabled state, while reserving the disabled-by-user error for tools the user actually disabled.
