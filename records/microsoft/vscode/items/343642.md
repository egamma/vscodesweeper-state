# Issue #343642 — Terminal output capture inserts a space where a wide character does not fit in the last column

[https://github.com/microsoft/vscode/issues/343642](https://github.com/microsoft/vscode/issues/343642)

## Summary

Keep open: both current output-extraction paths retain the empty padding cell before a wrapped wide character, inserting a space into captured text. The report includes a concrete reproduction and a retest on 1.143.1; this is a core extraction defect, not an extension-owned problem.

## Change summary

Terminal output capture inserts an unwritten space when a double-width character wraps from the final column.

## Best solution

Captured output should omit the unused wrap-padding cell while preserving actual printed spaces, logical-line joining, and explicit newlines. Cover both agent buffer extraction and TerminalCommand.getOutput() with wide-character boundary regressions.
