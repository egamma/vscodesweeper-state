# Issue #343642 — Terminal output capture inserts a space where a wide character does not fit in the last column

[https://github.com/microsoft/vscode/issues/343642](https://github.com/microsoft/vscode/issues/343642)

## Summary

The reported insertion remains source-reproducible: both core output readers serialize the unused final cell as a space before joining a wrapped continuation. Keep this open; the related newline report concerns a different capture path and does not absorb this defect.

## Change summary

Prevent terminal output capture from inserting an unprinted space when a wide character wraps from the final column.

## Best solution

Make both core output readers preserve logical text across wide-character wrap boundaries without serializing unused cells, while retaining printed spaces and explicit newlines.
