# Issue #201209 — When closing editors in the "Open Editors" view, the cursor should not move all the way up

[https://github.com/microsoft/vscode/issues/201209](https://github.com/microsoft/vscode/issues/201209)

## Summary

The scroll jump remains source-reproducible on current main: every editor close refreshes the entire Open Editors list and then reveals the active editor, moving the viewport away from the item being closed. This is the canonical open report and should remain open for a bounded fix.

## Change summary

Closing an inactive editor from a scrolled Open Editors list should remove that row without scrolling the list to the active editor.

## Best solution

Preserve the Open Editors viewport when an inactive editor is closed, while retaining active-editor reveal behavior for genuine activation changes. Cover both behaviors with a focused OpenEditorsView regression test.
