# Issue #207848 — [Accessibility] Cannot clear the SCM input history

[https://github.com/microsoft/vscode/issues/207848](https://github.com/microsoft/vscode/issues/207848)

## Summary

The SCM input still has no supported way to clear its saved message history; clearing the current input does not clear that history. Keep this already-routed issue open: no covering fix or eligible canonical duplicate was established.

## Change summary

Provide a keyboard-accessible way to clear previous SCM input messages so they cannot be recalled while reviewing a new commit message.

## Best solution

Provide a discoverable SCM input-history clearing action and document it in the input's accessibility help. Establish whether clearing applies to the current repository or the workspace, and preserve the current draft rather than treating history clearing as input deletion.
