# Issue #320899 — the issue of showing previous projects and folders on remote explorer

[https://github.com/microsoft/vscode/issues/320899](https://github.com/microsoft/vscode/issues/320899)

## Summary

The WSL targets and recent folders shown in Remote Explorer are provided by the WSL extension (ms-vscode-remote.remote-wsl), which lives in microsoft/vscode-remote-release — not in VS Code core. This issue should be moved to that tracker so the Remote Development team can evaluate whether stale distro entries should be pruned.

## Change summary

Remote Explorer continues to show WSL distros and their folders after the distro has been uninstalled from WSL, causing confusion and crashes when opening them.

## Best solution

Move this issue to https://github.com/microsoft/vscode-remote-release so the WSL extension team can decide whether to detect uninstalled distros and clean up stale entries from the Remote Explorer view.
