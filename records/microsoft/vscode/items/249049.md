# Issue #249049 — Removing glob from search.exclude in settings UI sets it to false instead of removing it

[https://github.com/microsoft/vscode/issues/249049](https://github.com/microsoft/vscode/issues/249049)

## Summary

Confirmed on current main: removing a default include/exclude entry writes a false override, which can suppress an inherited exclusion. Keep the issue open while the directly linked fixing PR is reviewed.

## Change summary

Make the Settings UI Remove action delete an exclude glob rather than persist a false override that changes inherited search behavior.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/316755, which distinguishes removal from editing and preserves the existing change/move behavior; if that approach is unsuitable, close or revise the PR before pursuing another fix.
