# Issue #149421 — Tooltip action to disable specific problems/linting rules

[https://github.com/microsoft/vscode/issues/149421](https://github.com/microsoft/vscode/issues/149421)

## Summary

A real gap remains: extensions can expose configuration changes as quick fixes, but VS Code has no unified diagnostic metadata or built-in CSS action for disabling a reported rule. This team-authored request should remain open because no explicitly linked implementation or canonical duplicate was found.

## Change summary

Offer a diagnostic-hover action for disabling or reconfiguring the specific lint rule that produced a problem.

## Best solution

Define a consistent diagnostic configuration-action convention, likely using diagnostic codes and CodeAction providers, then adopt it in the built-in CSS language extension and document it for extension authors.
