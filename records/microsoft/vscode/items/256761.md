# Issue #256761 — Install button should be first tab stop on extension page

[https://github.com/microsoft/vscode/issues/256761](https://github.com/microsoft/vscode/issues/256761)

## Summary

Still open and unfixed on main. PR #257353 was closed without merging, and the Install button is not prioritized as the first tab stop in the extension editor's action bar. Team-authored accessibility bug — keeping open.

## Change summary

The Install button on the extension detail page is not the first tab stop, making keyboard navigation harder for accessibility users.

## Best solution

Implement tab-stop ordering in `src/vs/workbench/contrib/extensions/browser/extensionEditor.ts` so the Install button receives focus first when tabbing into the extension action bar, without changing the visual DOM order. The closed PR #257353 attempted this via `setFocusable` manipulation on `ActionBar` view items — a similar approach (or the existing `focusOnlyEnabledItems` option) could be refined and landed.

  > In src/vs/workbench/contrib/extensions/browser/extensionEditor.ts, the Install button (InstallDropdownAction, id 'extensions.installActions') is not the first tab stop in the extension editor's action bar. Currently (line ~348) installAction is placed late in the actions array, and setFocusable(true) on the ActionBar makes all enabled items equally focusable with no priority. The fix should make the Install button the first tab stop without changing the visual DOM order. The closed PR #257353 (https://github.com/microsoft/vscode/pull/257353) attempted this by: (1) finding the install action view item in extensionActionBar's viewItems, (2) setting all other items non-focusable, (3) making only the install item focusable — and re-running this logic when action enablement changes. Adopt a similar approach but ensure it integrates cleanly with the existing focusOnlyEnabledItems option (line 384) and the enablement-change handler (lines 390-393). Do not change the visual order of buttons. Validate by tabbing through the extension detail page and confirming the Install button is the first focused action bar item.
