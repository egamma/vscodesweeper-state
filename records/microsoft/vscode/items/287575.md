# Issue #287575 — Unable to copy inline chat error message

[https://github.com/microsoft/vscode/issues/287575](https://github.com/microsoft/vscode/issues/287575)

## Summary

The bug remains visible in current source: inline-chat errors are rendered into a single-line, clipped, non-selectable status label. This team-authored issue should remain open until that error surface supports reading and copying the full message.

## Change summary

Allow users to view, select, and copy the complete inline-chat error message.

## Best solution

Render `errorDetails.message` in a wrapping or scrollable selectable surface, or provide an explicit copy action, within the inline-chat widget.
