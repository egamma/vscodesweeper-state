# Issue #236853 — JSON rendering: Crashing on arrays

[https://github.com/microsoft/vscode/issues/236853](https://github.com/microsoft/vscode/issues/236853)

## Summary

The JSON renderer for notebook outputs is provided by the Jupyter extension (microsoft/vscode-jupyter), not VS Code core — the built-in notebook renderer does not handle `application/json`. The corresponding issue in that tracker is already closed.

## Change summary

JSON arrays render as `[object Object]` in notebook output cells instead of displaying properly.

## Best solution

This was tracked and resolved in the Jupyter extension's own tracker (microsoft/vscode-jupyter#16315, now closed). The reporter should update to the latest Jupyter extension version to get the fix.
