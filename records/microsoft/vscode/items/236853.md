# Issue #236853 — JSON rendering: Crashing on arrays

[https://github.com/microsoft/vscode/issues/236853](https://github.com/microsoft/vscode/issues/236853)

## Summary

The failure remains in the current Jupyter extension output-conversion path: an `application/json` array of objects is incorrectly treated as a multiline string. Because Jupyter is VS Code-team-owned, this should be transferred to its tracker rather than closed as extension-caused.

## Change summary

Rendering an IPython JSON display containing an array of objects produces an invalid `[object Object]` output instead of JSON.

## Best solution

In `microsoft/vscode-jupyter`, handle JSON MIME data before the generic array path in `src/kernels/execution/helpers.ts`, serializing arrays with `NotebookCellOutputItem.json` or equivalent JSON encoding, and cover arrays of objects with an output-conversion test.
