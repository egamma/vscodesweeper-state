# Issue #318110 — Azure BYOK Should Support Sovereign Microsoft Auth Providers

[https://github.com/microsoft/vscode/issues/318110](https://github.com/microsoft/vscode/issues/318110)

## Summary

Sovereign authentication provider selection remains missing from current main. Keep this team-authored request open while the existing implementation candidate in PR 318118 is reviewed.

## Change summary

Allow Azure BYOK Entra authentication to use the configured Microsoft sovereign-cloud provider while retaining commercial authentication as the default.

## Best solution

Review and land the provider-selection portion of https://github.com/microsoft/vscode/pull/318118, with discoverable configuration and unchanged API-key and default commercial Entra behavior. Keep provider selection distinct from the separately tracked scopes and endpoint-handling requirements.
