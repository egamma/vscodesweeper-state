# Issue #349162 — WSL: Copilot harness cannot install MCP servers — “The selected agent does not support installation review”

[https://github.com/microsoft/vscode/issues/349162](https://github.com/microsoft/vscode/issues/349162)

## Summary

The reported failure is confirmed in current source: remote windows select a client without installation methods, while the marketplace provider permits installation and then throws the exact reported error. Keep this open as a core Agent Host customization bug.

## Change summary

MCP gallery installation fails before review in WSL when using the Copilot Agent Host harness.

## Best solution

Support the installation lifecycle on the selected remote host while preserving review, workspace trust, transaction ownership, and remote configuration targeting. Until supported, the marketplace should explain the limitation before offering an unusable installation action.
