## Summary

Keep open: the current SSH disconnect path hides cached sessions and removes the provider registration, matching the reported disappearance. This team-authored report has no verified fix or duplicate; the missing disconnected-chat indication still needs end-to-end investigation.

## Change summary

Disconnecting an SSH environment should preserve its session in the list and visibly indicate the open chat is disconnected.

## Best solution

Preserve existing SSH sessions and their identity across an explicit disconnect, while showing the disconnected state in both the session list and open conversation. Keep intentional disconnect distinct from deleting an environment and preserve suppression of automatic reconnection.
