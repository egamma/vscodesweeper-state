# Issue #346158 — Agents Window Chat: stop button looks out of place in a long terminal-command hover

[https://github.com/microsoft/vscode/issues/346158](https://github.com/microsoft/vscode/issues/346158)

## Summary

Keep open: current source deliberately places Stop beside the command and vertically centers it, explaining its detached appearance for tall previews. This is a bounded hierarchy improvement, not evidence of broken cancellation behavior.

## Change summary

Present the terminal-command hover's Stop action in its top bar rather than alongside multiline command content.

## Best solution

Keep Stop visibly associated with the whole background shell in the details header, independent of command height, while preserving cancellation behavior and keyboard access. Scope the refinement to background-shell details rather than changing all chat terminal toolbars.
