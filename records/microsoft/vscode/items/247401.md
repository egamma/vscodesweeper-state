# Issue #247401 — No way to accept individual change in merge editor using keyboard?

[https://github.com/microsoft/vscode/issues/247401](https://github.com/microsoft/vscode/issues/247401)

## Summary

Keep open: individual conflict actions remain inaccessible through keyboard focus and activation in the current source. Existing palette commands provide partial alternatives, but do not resolve the confirmed accessibility defect in the rendered controls.

## Change summary

Make individual merge-conflict actions operable using only the keyboard.

## Best solution

Provide keyboard-accessible, screen-reader-identifiable operation of the existing per-conflict controls in the merge editor, preserving their current resolution semantics. Document the available individual-conflict workflow in the merge editor accessibility help.

## Evidence

- **Confirmed source defect:** In src/vs/workbench/contrib/mergeEditor/browser/view/conflictActions.ts, ActionsContentWidget.setState creates actionable anchors with role='button' and onclick, but no href, tabindex, or keyboard activation handler. ActionsSource supplies the individual Accept, Accept Combination, Ignore, Remove, and Reset to base actions through this path. FixedZoneWidget in view/fixedZoneWidget.ts adds the overlay without supplying keyboard operation.
- **Independent confirmation:** https://github.com/microsoft/vscode/issues/247686 reports that Accept Current and Accept Combination cannot be reached with Tab, while accept-all buttons can. The maintainer explicitly closed that report in favor of this issue at https://github.com/microsoft/vscode/issues/247686#issuecomment-2839326060.
- **Existing capability is partial:** browser/commands/commands.ts registers merge.toggleActiveConflictInput1 and merge.toggleActiveConflictInput2 as command-palette actions; view/viewModel.ts implements them by toggling the active conflict's input state. These allow individual input selection, so the title's absolute claim is broader than current behavior. They do not make the rendered conflict controls keyboard-accessible or expose all their operations. mergeEditorAccessibilityHelp.ts describes navigation and accept-all commands, but omits these individual-input commands.
