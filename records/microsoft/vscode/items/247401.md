# Issue #247401 — No way to accept individual change in merge editor using keyboard?

[https://github.com/microsoft/vscode/issues/247401](https://github.com/microsoft/vscode/issues/247401)

## Summary

Still open on main: accepting an individual conflict change in the merge editor has no keyboard path. The toggle commands (`merge.toggleActiveConflictInput1/2`) exist in the command palette but lack keybindings, and the inline Accept/Combination links in the conflict view zones are mouse-only DOM elements. The partial accessibility fix in ca2881aa4f7 added keybindings for Complete Merge and Toggle Between Inputs but did not address individual change acceptance.

## Change summary

No keyboard-accessible way to accept an individual conflict change in the merge editor (only Accept All and Complete Merge have keyboard paths).

## Best solution

Add keybindings to `merge.toggleActiveConflictInput1` and `merge.toggleActiveConflictInput2`, and make the inline Accept Current / Accept Incoming / Accept Combination links in `conflictActions.ts` view zones focusable and operable via keyboard. The accessibility help dialog should document the new bindings.
