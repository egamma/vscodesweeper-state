# Issue #282885 — Editor GPU: Watermark when the GPU renderer is used

[https://github.com/microsoft/vscode/issues/282885](https://github.com/microsoft/vscode/issues/282885)

## Summary

Keep open: existing GPU diagnostics identify DOM fallback lines, but do not provide the requested watermark identifying an editor using GPU rendering. The request is already routed to editor-gpu and accepted into Backlog; no verified canonical or completed implementation was found.

## Change summary

Show a watermark when the editor uses GPU rendering so reports can be distinguished from non-GPU problems.

## Best solution

Provide a recognizable GPU-renderer indicator that helps identify the rendering mode in reports and screenshots. The editor-gpu owner should settle its visibility and presentation without treating the existing fallback-line marks as full coverage.
