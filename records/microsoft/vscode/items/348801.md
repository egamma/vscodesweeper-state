## Change summary

Copilot Harness repeatedly requests read permission for files beneath a folder already approved in the same session.

## Best solution

Make reusable folder approvals effective for subsequent covered reads, while preserving managed restrictions and Assisted review requirements. Diagnose whether the repeated prompts originate in grant persistence, path matching, or the runtime reviewer before changing authorization behavior.
