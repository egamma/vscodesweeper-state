# Issue #277875 — Disable all extensions on remote

[https://github.com/microsoft/vscode/issues/277875](https://github.com/microsoft/vscode/issues/277875)

## Summary

Feature request for a blanket setting to disable all extensions on remote machines. Existing controls (remote.defaultExtensionsIfInstalledLocally, remote.extensionKind, --disable-extensions) offer partial coverage but not a simple 'disable all remote extensions' toggle. The info-needed label seems stale — the reporter responded and the conversation moved on without resolution.

## Change summary

Add a configuration option to disable all extensions on remote machines to reduce resource usage on weak remote hosts.

## Best solution

The `remote.defaultExtensionsIfInstalledLocally` setting (set to `[]`) prevents auto-install of locally-installed extensions on remotes, and `remote.extensionKind` can force individual extensions to run locally. The remaining gap is a single toggle to prevent *all* extensions from running on the remote. The area owner should decide whether this warrants a new setting or whether the existing controls suffice. If the current controls are considered adequate, close as `*as-designed`; otherwise, this belongs in the remote extension management area.
