# Issue #189431 — Persistent background terminals (`hideFromUser = true`, `isTransient = false`) are killed on window reload

[https://github.com/microsoft/vscode/issues/189431](https://github.com/microsoft/vscode/issues/189431)

## Summary

Still reproduces on main: background terminals created via the extension API with `hideFromUser: true, isTransient: false` are killed 60 seconds after reload because they lack `forcePersist` and are not saved in the layout info for reattachment.

## Change summary

Non-transient hidden terminals created by extensions are killed after window reload because they are detached but never reattached.

## Best solution

Either auto-set `forcePersist` for non-transient `hideFromUser` terminals created via the API, or persist all non-transient background terminals in `_saveState` regardless of `forcePersist`. The fix lives in `src/vs/workbench/contrib/terminal/browser/terminalService.ts` — the `_saveState` method (line 733) filters background terminals to only those with `forcePersist`, which excludes API-created hidden terminals.

## Evidence

- **save state filter:** In src/vs/workbench/contrib/terminal/browser/terminalService.ts line 733, `_saveState` only persists background terminals with `i.shellLaunchConfig.forcePersist` set. API-created terminals with `hideFromUser: true, isTransient: false` do not have `forcePersist`.
- **forcePersist not in public API:** `forcePersist` is on `IShellLaunchConfig` (src/vs/platform/terminal/common/terminal.ts:616) — an internal interface — and is not exposed via the public `vscode.TerminalOptions` extension API.
- **grace timer still kills:** src/vs/platform/terminal/node/ptyService.ts lines 800-803: a 60-second `_disconnectRunner1` timer shuts down the process after detach. Since the terminal is not in the layout info, it is never reattached and gets killed.
