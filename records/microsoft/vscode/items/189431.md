# Issue #189431 — Persistent background terminals (`hideFromUser = true`, `isTransient = false`) are killed on window reload

[https://github.com/microsoft/vscode/issues/189431](https://github.com/microsoft/vscode/issues/189431)

## Summary

Keep open: extension-created, non-transient hidden terminals still fall outside the reload restoration path. Current background-terminal persistence supports an internal opt-in that the extension API does not supply, so it does not resolve this accepted bug.

## Change summary

Preserve non-transient hidden terminal processes across window reloads and make them available to extensions again without revealing them in the Terminal panel.

## Best solution

Restore eligible hidden extension terminals after reload, preserving their running process and visibility state so extensions can rediscover them through window.terminals. Cover both local and remote reconnection while retaining transient-terminal cleanup and existing persistence-setting behavior.
