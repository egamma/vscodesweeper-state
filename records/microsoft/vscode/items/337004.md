# Issue #337004 — Sandbox policy link styled differently than regular links

[https://github.com/microsoft/vscode/issues/337004](https://github.com/microsoft/vscode/issues/337004)

## Summary

Team-authored testing note (author is a COLLABORATOR) flagging that the new sandbox-policy link doesn't visually match other chat links; team-authored items are protected from judgment closes anyway, and this is a design question the tester themselves is unsure about, so it stays open for a maintainer/design call.

## Change summary

The 'Open Sandbox Policy' link produced by the new /sandbox-policy slash command renders differently (as a file-chip widget) than ordinary chat markdown links.

## Best solution

A maintainer should decide whether the sandbox-policy output should use the plain link-style rendering (`chat-inline-references-link-style` wrapper) applied elsewhere for markdown-preview links, or whether the chip/box styling for preview links is intentional and the test-plan wording should be adjusted instead.
