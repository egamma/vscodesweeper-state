# Issue #176402 — Settings editor doesn't support settings with very long descriptions well like terminal.integrated.commandsToSkipShell

[https://github.com/microsoft/vscode/issues/176402](https://github.com/microsoft/vscode/issues/176402)

## Summary

Still valid: the settings editor has no reveal/truncation mechanism for very long descriptions. The last comment (Dec 2024) proposes a 'See More' button but no implementation has landed.

## Change summary

Settings editor should gracefully handle settings with very long descriptions (e.g. terminal.integrated.commandsToSkipShell at ~7000 chars) via a reveal/collapse mechanism.

## Best solution

Add a 'See More' / reveal button in the settings editor that truncates long descriptions with an expand affordance, in src/vs/workbench/contrib/preferences/browser/settingsTree.ts. The description rendering path needs a max-height clamp with an overflow reveal.
