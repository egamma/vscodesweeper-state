# Issue #340182 — Restore the changed files (working set) list above the chat input box

[https://github.com/microsoft/vscode/issues/340182](https://github.com/microsoft/vscode/issues/340182)

## Summary

Fresh, well-evidenced feature request: the persistent working-set list above the chat input was tied to the legacy 'Edit' mode, which Agent mode replaced; Agent mode only shows a collapsible per-turn 'N files changed' summary instead. No maintainer has weighed in yet and no canonical issue owns this exact ask, so it stays open for discussion.

## Change summary

Restore (or add a setting for) a persistent changed-files/working-set list above the chat input for Agent mode, instead of only the collapsible 'N files changed' summary after each turn.

## Best solution

A maintainer should decide whether to extend `renderWorkingSet`/the working-set UI (currently gated to `ChatModeKind.Edit` in chatWidget.ts) to Agent mode, or offer a `chat.edits.showWorkingSet`-style setting — this is a product/UX call, not a mechanical bug fix.

- **Trace:**

  > The working-set rendering path (`renderWorkingSet` in chatInputPart.ts, gated by `viewOptions.enableWorkingSet === 'explicit'` in chatWidget.ts, and populated only for `ChatModeKind.Edit` at chatWidget.ts:3556) was never wired up for Agent mode; Agent mode's file changes instead flow through the separate `sessionFileChanges`/`sessionFiles` collapsible-list path (chatInputPart.ts:4920-4945).
