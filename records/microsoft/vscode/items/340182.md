# Issue #340182 — Restore the changed files (working set) list above the chat input box

[https://github.com/microsoft/vscode/issues/340182](https://github.com/microsoft/vscode/issues/340182)

## Summary

Still an open gap on main: the persistent working-set/changed-files list above the chat input is only wired for legacy Edit mode (ChatModeKind.Edit), not Agent mode, so Agent-mode users genuinely lost this at-a-glance view. The maintainers have an active, broader feedback thread covering exactly this kind of change-review friction, so this stays open rather than being folded into that umbrella as a duplicate.

## Change summary

Restore (or add a setting to restore) the persistent changed-files/working-set list above the chat input for Agent mode, which was removed in the chat UI rework.

## Best solution

Either re-enable the existing working-set rendering path for Agent mode (it's already implemented for Edit mode) or expose a setting like the requested `chat.edits.showWorkingSet`; in the meantime point reporters to the maintainer-run feedback thread https://github.com/microsoft/vscode/issues/339363 where the team is actively collecting input on exactly this kind of change-review regression.
