# Issue #342038 — Agent create lots of checkpoints in git repo

[https://github.com/microsoft/vscode/issues/342038](https://github.com/microsoft/vscode/issues/342038)

## Summary

Keep open: a second reporter confirms checkpoint refs appearing in Ask mode with both checkpoint and Agent Host settings disabled. Current source independently creates Agent Host baseline refs, but the exact path into that backend with those settings still needs diagnosis.

## Change summary

Copilot creates persistent Git checkpoint refs that clutter repository viewers even when checkpoint creation is reportedly disabled.

## Best solution

Establish and honor the checkpoint-disable contract across chat backends, including baseline creation, without silently breaking session diffs or restoration. Diagnose why the reported Ask-mode configuration reaches the ref-writing path before choosing the scope of the correction.
