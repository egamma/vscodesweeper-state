# Issue #342038 — Agent create lots of checkpoints in git repo

[https://github.com/microsoft/vscode/issues/342038](https://github.com/microsoft/vscode/issues/342038)

## Summary

Thanks for the report. The agent host writes `refs/agents/<session>/checkpoints/turn/<N>` git refs, and the `chat.checkpoints.enabled` setting appears to control only the chat UI. The git extension lists refs with no pattern filter, so these internal refs probably appear in its ref lists. I could not run the code to confirm. The report has the refs list and the steps needed to retest.

## Change summary

Agent-created checkpoint refs (refs/agents/*/checkpoints/turn/*) clutter the git extension, and disabling checkpoints in the agent configuration does not stop them.

## Best solution

Filter `refs/agents/*` (and `refs/agents/chats/*`) out of the git extension's ref listings, Source Control Graph and ref pickers. Separately, decide whether `chat.checkpoints.enabled` should also stop the agent host from creating these refs.
