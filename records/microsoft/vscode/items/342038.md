Keep open: multiple reporters observe checkpoint refs despite disabling checkpoints, and a maintainer explicitly confirmed reproduction. Current source contains Agent Host checkpoint capture paths without a checkpoint-setting guard; the exact Ask-mode routing still needs diagnosis.

## Change summary

Copilot creates persistent refs/agents checkpoint references in the user's Git repository even when checkpoint creation is disabled.

## Best solution

Make the checkpoint disable control effective on the path producing these refs, including the reported Ask-mode case, while preserving ordinary chat operation and supported change tracking. Establish how existing checkpoint refs are safely retired without requiring reporters to edit Git internals.
