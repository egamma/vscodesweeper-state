# Issue #342038 — Agent create lots of checkpoints in git repo

[https://github.com/microsoft/vscode/issues/342038](https://github.com/microsoft/vscode/issues/342038)

## Summary

Keep open: a maintainer confirmed that disabling checkpoints does not stop the reported behavior, and current source still writes matching refs without checking that setting. The Ask-mode report with Agent Host disabled needs its actual dispatch path traced before choosing the fix.

## Change summary

Copilot creates persistent checkpoint refs in the user's Git repository despite checkpoints being disabled, cluttering external Git history tools.

## Best solution

Make checkpoint disablement reliably govern repository checkpoint writes on the affected chat paths while preserving ordinary chat and change reporting. Address existing checkpoint retention through safe, ownership-aware cleanup rather than recommending manual Git database edits.
