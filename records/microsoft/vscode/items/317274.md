# Issue #317274 — Intent service returns decode_failed due to malformed JSON

## Summary

Legitimate low-volume bug report about the Copilot auto-mode router client occasionally sending malformed JSON to the server. Already triaged and assigned by a team member — keeping open for investigation.

## Change summary

The VS Code Copilot extension occasionally sends malformed or empty JSON bodies to the auto-intent-service predict endpoint, causing ~257 decode_failed errors/day (0.027% of requests).

## Best solution

Investigate race conditions or cancellation paths in `routerDecisionFetcher.ts` and `automodeService.ts` where the request body could be truncated or empty before reaching the server. The `JSON.stringify(requestBody)` at line 96 of `routerDecisionFetcher.ts` should always produce valid JSON, so the issue likely involves request cancellation mid-flight, network-layer truncation, or an edge case where the CAPI client sends an empty body.
