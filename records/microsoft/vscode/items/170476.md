## Summary

The reported telemetry path still exists on current main: resolving an unregistered browser file-system root throws the same `Unavailable` error, and the browser uncaught-error collector does not filter it. This team-authored, accepted bug has no referenced fixing commit or verified older canonical, so it should remain open.

## Change summary

Prevent the expected browser file-system error for an unregistered root handle from being reported as unexpected-error telemetry.

## Best solution

Treat this specific expected `Unavailable` condition as non-actionable telemetry while preserving the provider's failure semantics and reporting genuinely unexpected file-system errors.
