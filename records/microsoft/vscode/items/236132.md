## Summary

Confirmed on current main: the RPM %post scriptlet unconditionally removes /usr/local/bin/code even when it's a user-managed file. An open PR (#310054) proposes a fix but has not merged yet.

## Change summary

The RPM %post scriptlet deletes user-managed /usr/local/bin/code on every install/upgrade of the stable VS Code package.

## Best solution
