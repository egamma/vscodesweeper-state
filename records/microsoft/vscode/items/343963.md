# Issue #343963 — Consider saving state before esc

[https://github.com/microsoft/vscode/issues/343963](https://github.com/microsoft/vscode/issues/343963)

## Summary

Keep open: comparison setup still discards unfinished selections when dismissed. Done preserves completed selections, but does not cover this request to resume an initial selection after Escape.

## Change summary

Remember unfinished Compare Models selections when the user presses Escape and reopens setup.

## Best solution

Consider resumable comparison drafts in SessionComparisonModelSelection without activating a comparison until Done. Settle the draft's lifetime and how dismissal differs from explicitly clearing the selection before implementation.
