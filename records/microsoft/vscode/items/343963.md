# Issue #343963 — Consider saving state before esc

[https://github.com/microsoft/vscode/issues/343963](https://github.com/microsoft/vscode/issues/343963)

## Summary

Keep open as a feature request: comparison setup deliberately discards uncommitted selections when dismissed, so remembering them would change the current interaction contract. Done preserves a completed configuration, but does not cover resuming unfinished initial selections after Escape.

## Change summary

Remember unfinished comparison model selections after Escape so reopening comparison setup restores them.

## Best solution

Decide whether comparison setup should retain a resumable draft independently of the configuration used to send requests. If adopted, reopening should restore unfinished selections without Escape committing them or launching a comparison.
