# Issue #282541 — zsh themes that use `RPROMPT` seem to break suggest feature of integrated terminal

[https://github.com/microsoft/vscode/issues/282541](https://github.com/microsoft/vscode/issues/282541)

## Summary

Keep open: current source still includes right-prompt decoration in the input passed to terminal completion providers. The earlier ghost-text handling does not remove that decoration, and no verified open canonical absorbs this terminal-suggest report.

## Change summary

Zsh right prompts contaminate terminal input parsing, causing unrelated or missing terminal suggestions.

## Best solution

Terminal suggestions should receive only editable command input and legitimate shell ghost text, excluding right-prompt decoration without requiring users to change themes. Preserve cursor positions, editable text after the cursor, and existing multiline behavior.
