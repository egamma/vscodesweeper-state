# Issue #346523 — Remote agent host: session larger than 100 MB causes an endless reconnect loop (WebSocket 1009 "Max payload size exceeded")

[https://github.com/microsoft/vscode/issues/346523](https://github.com/microsoft/vscode/issues/346523)

## Summary

Keep open: current source retains the upstream payload limit and discards the failure reason before reconnecting. The report supplies concrete steps and logs; this team-authored issue has no verified fix or canonical duplicate.

## Change summary

Large remote agent sessions disconnect the agent-host transport repeatedly, leaving Chat spinning without an actionable error.

## Best solution

Ensure oversized agent-host messages cannot cause an indefinite reconnect cycle, and expose an actionable failure to the client. Separately establish whether large histories must load successfully through bounded transfers rather than merely fail gracefully.
