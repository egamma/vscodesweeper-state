# Issue #338330 — Test Explorer fails to show icons in descriptions

[https://github.com/microsoft/vscode/issues/338330](https://github.com/microsoft/vscode/issues/338330)

## Summary

Confirmed on current main: the test results tree renders icon markup for the label via renderLabelWithIcons but builds the description as a plain text node, so icon codes embedded in test item labels (used to build the breadcrumb description) show up as unrendered `$(icon)` text instead of codicons.

## Change summary

Test Explorer results tree shows raw unrendered icon syntax (e.g. `$(icon-name)`) in the description/breadcrumb area, while the same icon renders correctly in the main label.

## Best solution

In testResultsTree.ts's doRenderInner, build the description element with renderLabelWithIcons (like the label) instead of inserting the raw string, so icon markup in the breadcrumb description renders as codicons.
