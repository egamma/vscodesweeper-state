# Issue #239251 — Terminal resizing/repainting issue when using Zellij

[https://github.com/microsoft/vscode/issues/239251](https://github.com/microsoft/vscode/issues/239251)

## Summary

Keep open: the linked discussion contains independent confirmation and additional reproduction details, but neither a verified fix nor a canonical issue covers the complete Zellij symptom. Investigate remote terminal sizing versus application repainting before assigning the cause.

## Change summary

Zellij sessions in Remote-SSH terminals can remain constrained to approximately 80 columns and repaint only partially when the sidebar changes the terminal width.

## Best solution

Ensure Zellij receives the actual remote terminal dimensions after attachment, reconnection, and layout changes, and repaints the available area correctly. First distinguish a stale remote PTY size from Zellij rendering or multi-client session behavior; related sizing reports provide diagnostic leads, not a proven shared cause.
