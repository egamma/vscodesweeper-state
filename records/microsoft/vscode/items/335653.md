# Issue #335653 — Dev Container workspace picker needs clearer actions and location indication

[https://github.com/microsoft/vscode/issues/335653](https://github.com/microsoft/vscode/issues/335653)

## Summary

Legitimate, team-authored UX polish task; both concerns are confirmed in current source (the submenu/Remove action wiring and the `{0} - Dev Container` label suffix), and it already carries the right area labels — no reason to close, and it needs a design decision before implementation.

## Change summary

The Dev Container workspace picker's per-row Remove action feels visually disconnected from the submenu chevron, and appending `- Dev Container` to the workspace name won't scale as more execution locations are added.

## Best solution

Redesign the recent-workspace row so the Remove affordance sits adjacent to (or integrates with) the submenu trigger, and replace the `{0} - Dev Container` label concatenation with a distinct execution-location pill/badge rendered alongside the workspace chip.
