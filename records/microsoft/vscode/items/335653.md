# Issue #335653 — Dev Container workspace picker needs clearer actions and location indication

[https://github.com/microsoft/vscode/issues/335653](https://github.com/microsoft/vscode/issues/335653)

## Summary

Keep open: current source still combines the workspace name and Dev Container location in one label, and the action-placement concern remains relevant to ongoing picker design. Related open reports cover individual aspects but are newer and do not meet the duplicate bar for this re-reviewed, team-authored item.

## Change summary

Clarify recent-workspace Remove actions and distinguish execution location from workspace identity in the Agents Window picker.

## Best solution

Agree on a consistent presentation that keeps workspace identity primary, execution location separately readable, and Remove clearly associated with its row rather than submenu navigation. Coordinate with the environment-picker and action-alignment work without expanding this issue into a provider-model redesign.
