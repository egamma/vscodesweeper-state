# Issue #335653 — Dev Container workspace picker needs clearer actions and location indication

[https://github.com/microsoft/vscode/issues/335653](https://github.com/microsoft/vscode/issues/335653)

## Summary

Both UX concerns remain present on current main, and the issue is a team-authored design item whose broader workspace/environment model is still under active consideration. The newer related issues neither supersede nor qualify as canonical duplicates of this older, broader report.

## Change summary

Clarify workspace-row actions and represent the selected Dev Container execution environment separately from the workspace name.

## Best solution

Resolve this through the planned workspace-picker redesign: keep workspace identity separate from execution environment, provide a scalable and accessible environment indicator or picker, and make the Remove action read as compact secondary chrome without competing with the submenu affordance. Coordinate that design with https://github.com/microsoft/vscode/issues/337553 while retaining this issue's concrete Dev Container acceptance cases.
