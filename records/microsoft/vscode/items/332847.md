# Issue #332847 — Sticky scroll: When chat message is focused, sticky part doesn't have border color

[https://github.com/microsoft/vscode/issues/332847](https://github.com/microsoft/vscode/issues/332847)

## Summary

Traced a real, small CSS gap: the chat-specific focus outline for a focused chat request only targets `.monaco-scrollable-element > .monaco-list-rows > .monaco-list-row.focused.request`, which doesn't match the sticky-scroll clone row rendered inside `.monaco-tree-sticky-container` — so the border/outline is lost when the sticky part represents a focused request.

## Change summary

When a chat request row is focused and shown as the sticky-scroll header, the sticky clone doesn't get the focus border/outline that the real row gets.

## Best solution

Add a parallel selector in chat.css scoped to `.monaco-tree-sticky-container .monaco-list-row.focused.request` (mirroring the existing `:not(.monaco-tree-sticky-row)` handling nearby) so the `.interactive-item-container .value .rendered-markdown` outline also applies inside the sticky container.
