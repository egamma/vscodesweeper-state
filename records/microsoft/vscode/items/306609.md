# Issue #306609 — Copilot CLI non-responsive

[https://github.com/microsoft/vscode/issues/306609](https://github.com/microsoft/vscode/issues/306609)

## Summary

The terminal chat request path still contains a source-confirmed hang on current main: when the underlying chat widget returns no response, `TerminalChatWidget.acceptInput` waits forever and leaves the request-active state set. The related fix PR was closed without merging, so the issue remains necessary.

## Change summary

Copilot requests submitted through terminal chat can consume or reject a request without displaying a response, leaving the terminal chat interaction non-responsive.

## Best solution

Make terminal chat settle rejected or otherwise unaccepted submissions without remaining busy, while preserving normal completion, cancellation, and code-block toolbar behavior.
