## Summary

Keep open: the clarified report identifies diagnostic backgrounds that do not align with the editor line highlight, independently of Error Lens. Current source still renders these backgrounds through decoration overlays, but neither a current reproduction nor a post-reopen fix was established; the supplied customization and screenshots suffice to guide a retest beyond the reported 1.88.0 build.

## Change summary

Treat hint-background support separately unless reproduction establishes that it participates in the same defect.
