# Issue #174941 — Git - extension API gives repository remotes with aliases

[https://github.com/microsoft/vscode/issues/174941](https://github.com/microsoft/vscode/issues/174941)

## Summary

The built-in Git API still exposes literal remote aliases on its normal configuration-reading path. Downstream GitHub Pull Requests fixes mitigate individual consumers, but do not deliver the requested API behavior; keep this accepted, team-authored request open.

## Change summary

Expose fetch and push URLs resolved according to Git's insteadOf and pushInsteadOf rules through the built-in Git extension API.

## Best solution

Make repository.state.remotes expose effective fetch and push URLs consistently with Git, without requiring each consuming extension to implement URL rewriting. Preserve the remote-discovery hot path's performance and account for effective configuration and refresh behavior before implementation.
