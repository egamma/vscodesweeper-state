# Issue #174941 — Git - extension API gives repository remotes with aliases

[https://github.com/microsoft/vscode/issues/174941](https://github.com/microsoft/vscode/issues/174941)

## Summary

Still valid on main: the git extension's primary remote-fetching path (`getRemotesFS`) reads the raw config file and returns unresolved `insteadOf` aliases. The closed PR #238675 attempted a fix but was not merged. The issue remains actionable.

## Change summary

The git extension API returns raw `insteadOf` URL aliases (e.g. `gh:user/private`) instead of resolved URLs (e.g. `git@github.com:user/private`) for repository remotes.

## Best solution

Resolve `insteadOf` aliases when building remote URLs in `getRemotesFS()` (extensions/git/src/git.ts), either by parsing the `url.<base>.insteadOf` config entries and applying them, or by falling back to `git remote --verbose` (which already resolves aliases in `getRemotesGit()`). The closed PR #238675 explored the latter approach and could inform a new attempt.
