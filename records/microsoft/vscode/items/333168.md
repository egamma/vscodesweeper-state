## Summary

Verified duplicate: the older open panel-specific zoom request already covers independently enlarging Copilot Chat without scaling the editor or other UI. The existing chat settings cover message font size and family, while the canonical issue owns the remaining per-panel accessibility gap.

## Change summary

Allow users with low vision to adjust Copilot Chat's font size and font family independently from the code editor and global workbench.

## Best solution

Consolidate independent Chat scaling on https://github.com/microsoft/vscode/issues/320205, preserving this report's low-vision use case. Continue supporting `chat.fontSize` and `chat.fontFamily` for message typography while addressing chat surfaces such as the input that do not honor those settings.
