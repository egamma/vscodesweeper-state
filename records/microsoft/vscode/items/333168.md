# Issue #333168 — Resize font size in Copilot window

[https://github.com/microsoft/vscode/issues/333168](https://github.com/microsoft/vscode/issues/333168)

## Summary

The requested independent Copilot Chat font size and font family controls already exist. These settings cover chat messages and code blocks without changing the code editor or globally zooming VS Code.

## Change summary

Allow users with low vision to change Copilot Chat's font size and font family independently of the code editor.

## Best solution

Use chat.fontSize and chat.fontFamily for chat messages, and chat.editor.fontSize and chat.editor.fontFamily for embedded code blocks; no new capability is needed for the request as written.

- **Proposed comment:**

  > Thanks for the request. You can change Copilot Chat text independently in Settings: `chat.fontSize` controls the message text size, and `chat.fontFamily` selects its font. For code blocks inside chat, use `chat.editor.fontSize` and `chat.editor.fontFamily`. These do not change your code editor's font or the overall window zoom, so the requested controls are already available.
