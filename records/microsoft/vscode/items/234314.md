# Issue #234314 — Find & Replace in Files => Very Slow on Mac

[https://github.com/microsoft/vscode/issues/234314](https://github.com/microsoft/vscode/issues/234314)

## Summary

Keep open for a current-macOS performance investigation. The reported bulk-replace operation and scale are sufficient to attempt a retest, but inspection of today's search implementation does not establish whether the prolonged rg process buildup still occurs.

## Change summary

Replacing about 400 matches across 200 files reportedly leaves many rg processes running and slows macOS for 5–10 minutes.

## Best solution

Identify which component launches the lingering rg processes during bulk replacement, then address excessive concurrency or incomplete cancellation in that confirmed path. Preserve normal replacement, saving, and search-result behavior rather than assuming every saved file launches another search.
