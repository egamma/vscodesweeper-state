# Issue #260401 — github.copilot.nextEditSuggestions.enabled not toggling with keybinding

[https://github.com/microsoft/vscode/issues/260401](https://github.com/microsoft/vscode/issues/260401)

## Summary

This is as-designed: `github.copilot.nextEditSuggestions.enabled` is a configuration setting, not a command ID. Settings cannot be used directly as keybinding commands — VS Code correctly reports the command is not found. A dedicated toggle command could be a valid feature request for the Copilot extension.

## Change summary

User expects to toggle a boolean setting directly via a keybinding using the setting name as a command, which VS Code does not support.

## Best solution

Close as as-designed. If a quick-toggle for NES is desired, the Copilot extension team could register a dedicated `github.copilot.nextEditSuggestions.toggle` command — that would be a separate feature request.
