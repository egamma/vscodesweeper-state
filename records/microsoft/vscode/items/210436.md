[https://github.com/microsoft/vscode/issues/210436](https://github.com/microsoft/vscode/issues/210436)

## Summary

The reported unmatched-closing-brace case is addressed by the merged bracket-balancing fix, which is present in current main. Source tracing shows that typing the matching opener now suppresses the extra closing brace with beforeWhitespace.

## Change summary

Prevent an unwanted extra closing brace when typing an opening brace before the unmatched } in Python text such as foo = } with editor.autoClosingBrackets set to beforeWhitespace.

## Best solution

Close as completed by commit 90bbf3a626eddf1870fde872dd1dc8f36a40d622; retain the bracket-balancing behavior that reuses the existing unmatched closer.
