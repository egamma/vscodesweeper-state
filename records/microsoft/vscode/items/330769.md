# Issue #330769 — Submit button contrast very low in specific built-in themes

[https://github.com/microsoft/vscode/issues/330769](https://github.com/microsoft/vscode/issues/330769)

## Summary

Confirmed to be caused by the third-party Claude Code extension's own webview CSS (a `.sendButton_*` class keyed to `--app-error-foreground` in 'Auto' permission mode), not by VS Code core — closing as caused-by-extension and pointing to the extension's own tracker.

## Change summary

Submit button in the Claude Code chat sidebar has low contrast against certain built-in themes (Solarized Dark, Red) when the permission mode is set to Auto/'Edit automatically'.

## Best solution

Report/track this in anthropics/claude-code, since the low-contrast button is rendered by that extension's own webview UI (class `sendButton_gGYT1w`, mapped to `--app-error-foreground`) and is unrelated to VS Code's theming engine or core chat UI.
