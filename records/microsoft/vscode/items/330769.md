# Issue #330769 — Submit button contrast very low in specific built-in themes

[https://github.com/microsoft/vscode/issues/330769](https://github.com/microsoft/vscode/issues/330769)

## Summary

The contrast problem is in markup and CSS that isn't part of VS Code's own source — the reporter's own devtools inspection shows CSS-module-hashed classes (`sendButton_gGYT1w`) and custom properties (`--app-button-foreground`, `--app-error-foreground`) that only exist inside the Claude Code extension's own bundled webview UI, not in VS Code's chat/session send-button implementation.

## Change summary

In specific built-in themes (Solarized Dark, Red), the Claude Code sidebar's submit button has very low contrast when the permission mode is set to "Auto"/"bypass permissions".

## Best solution

This belongs with the Claude Code extension's publisher: its bundled UI maps a background color to `--app-error-foreground` and text to `--app-button-foreground` for the auto/bypass-permissions button state, and that combination happens to clash in themes with bright error colors. VS Code's own send-button implementation (`.sessions-chat-send-button .monaco-button` in src/vs/sessions/contrib/chat/browser/media/chatInput.css) uses standard `--vscode-*` tokens and is unaffected, so no core change is needed.
