# Issue #126610 — More obvious UI for output mimetype selector

[https://github.com/microsoft/vscode/issues/126610](https://github.com/microsoft/vscode/issues/126610)

## Summary

The discoverability gap remains on current main: changing presentation is still hidden in the output toolbar's overflow menu. The issue is correctly routed and should remain open as notebook UX polish.

## Change summary

Make the notebook output mimetype selector and the availability of alternative presentations more obvious.

## Best solution

Expose a recognizable presentation picker or indicator when an output has multiple trusted mimetypes, while retaining the existing quick-pick selection flow in the notebook output toolbar.
