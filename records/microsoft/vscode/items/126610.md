# Issue #126610 — More obvious UI for output mimetype selector

[https://github.com/microsoft/vscode/issues/126610](https://github.com/microsoft/vscode/issues/126610)

## Summary

Keep open: current source still places Change Presentation exclusively in the output toolbar's secondary menu, without a visible indication of alternative presentations. Existing MIME preferences do not resolve this discoverability gap, and the older related issue covers a narrower behavior.

## Change summary

Make notebook output presentation switching discoverable and indicate when alternative output formats are available.

## Best solution

Give outputs with alternative presentations a self-explanatory affordance in the notebook output UI, while keeping output content visually primary. Agree on the visible control and its reveal behavior before implementation; renderer preference configuration is a separate concern.

- **Behavior:**

  > Users should be able to recognize that a notebook output has alternative presentations and discover how to switch between them without guessing the meaning of an overflow icon. Acceptance should cover an output with two supported MIME types, an output with only one presentation, keyboard and screen-reader access, and preservation of existing output actions.
- **Trace:**
