- **Behavior:**

  > A proposed edit to a supported-language file outside the workspace should display syntax highlighting in the chat's embedded diff, consistent with the same file inside the workspace. Reproduce using Ask mode and compare the diff with the file's normal editor rendering. Preserve existing diff content, review actions, and behavior for plain-text files.
- **Trace:**

  > ChatTextEditContentPart delegates model creation to CodeCompareModelService.createModel in chatTextEditContentPart.ts, which copies the original model's language ID to the modified model. A separate path in ChatMarkdownContentPart.codeBlockRendererSync reads a diff fence's language and creates MarkdownDiffBlockPart, whose models use createById without inferring language from the file URI. CodeCompareBlockPart then attaches those models to the embedded diff editor. These paths identify where to inspect, not a confirmed root cause; first establish which path the reported Ask-mode response takes and inspect its model language IDs. Keep the investigation limited to highlighting for the reported external-file scenario.
