# Issue #312834 — Broken trust system on windows Dev Drive over ssh

[https://github.com/microsoft/vscode/issues/312834](https://github.com/microsoft/vscode/issues/312834)

Keep open: the report provides sufficient Windows/OpenSSH/PowerShell/Dev Drive steps to retest, but the repeated prompt could not be confirmed from source alone. Current trust handling includes remote URI normalization and persistence; neither a fixing commit nor a sufficiently established duplicate was found.

## Change summary

Trusting a remote Windows Dev Drive folder repeatedly reopens the trust prompt after reopening or reloading the window.

## Best solution

Make an explicitly granted trust decision remain effective when the same remote folder is reopened or reloaded, without weakening trust checks. First reproduce the Dev Drive case and determine whether it shares the restore-time failure reported in https://github.com/microsoft/vscode/issues/286384.
