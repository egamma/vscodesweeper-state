# Issue #348782 — [Remote SSH][Copilot Chat] Attached chat metadata references a Windows path and mismatched session ID

[https://github.com/microsoft/vscode/issues/348782](https://github.com/microsoft/vscode/issues/348782)

## Summary

Keep open: the attachment path still uses the client's Copilot home and the VS Code session ID rather than the owning host's SDK-backed log location. The WSL confirmation and current source substantiate both reported failures.

## Change summary

Resolve attached Copilot conversations to the correct host and SDK session log without confusing their distinct session identities.

## Best solution

Session attachments should reference the owning provider's actual events file, while preserving the original VS Code session identity for navigation and replay. Cover Remote SSH, WSL, and local sessions whose SDK IDs differ from their VS Code IDs.
