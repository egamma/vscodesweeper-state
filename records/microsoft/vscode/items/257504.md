# Issue #257504 — NES: Word Wrap not supported

[https://github.com/microsoft/vscode/issues/257504](https://github.com/microsoft/vscode/issues/257504)

## Summary

Keep open: current NES renderers still lack wrapping for replacement text, and existing settings do not cover the request. The older Agent-edit report concerns the opposite side of a different preview, so it is not a duplicate canonical.

## Change summary

Make Next Edit Suggestion previews respect word wrap so proposed changes on long lines remain readable before acceptance.

## Best solution

Support wrapping of modified text in the editor's NES replacement previews, with layout and highlighting based on the resulting visual lines. Preserve this issue as the NES tracking report, distinct from Agent-edit deleted-line wrapping.

Resizing or toggling wrapping must update the preview without clipping the changed suffix or overlapping surrounding content. Disabling wrapping must retain the existing unwrapped experience; accepting or rejecting an edit must not change semantics.

- **Current replacement-rendering gap:** src/vs/editor/contrib/inlineCompletions/browser/view/inlineEdits/inlineEditsViews/inlineEditsLineReplacementView.ts constructs each modified line using renderLines(new LineSource([tokens])) without line-break data.
