# Issue #185537 — Cannot select between a sequence of unicode flags

[https://github.com/microsoft/vscode/issues/185537](https://github.com/microsoft/vscode/issues/185537)

## Summary

This remains a source-reproducible editor bug: current grapheme segmentation merges an entire run of regional-indicator characters instead of pairing them into separate flag graphemes.

## Change summary

Allow cursor movement and selection between consecutive Unicode flag emoji while preserving each two-indicator flag as one grapheme.

## Best solution

Bring forward and backward grapheme iteration into conformance with Unicode GB12/GB13 parity rules, with coverage at both the string-iterator and editor-cursor levels.
