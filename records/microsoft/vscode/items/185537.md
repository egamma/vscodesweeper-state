# Issue #185537 — Cannot select between a sequence of unicode flags

[https://github.com/microsoft/vscode/issues/185537](https://github.com/microsoft/vscode/issues/185537)

## Summary

Still reproduces on main: the grapheme break logic in strings.ts is stateless and cannot implement Unicode GB12/GB13 rules, which require counting Regional Indicator pairs — so consecutive flag emoji are treated as one giant grapheme cluster.

## Change summary

Cursor navigation treats a sequence of consecutive flag emoji as a single grapheme cluster, making it impossible to select between them.

## Best solution

Implement proper GB12/GB13 stateful counting in `GraphemeIterator.nextGraphemeLength()` and `prevGraphemeLength()` in `src/vs/base/common/strings.ts`. The `breakBetweenGraphemeBreakType` function needs to be augmented with state (an RI count) so that it breaks after every pair of Regional Indicator code points rather than treating the entire RI run as one cluster. The related issue https://github.com/microsoft/vscode/issues/182422 (Arabic text selection) is a different UAX#29 rule but both stem from the same stateless simplification.
