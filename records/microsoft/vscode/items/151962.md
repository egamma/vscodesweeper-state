# Issue #151962 — Support SGR ANSI escape sequence in problem matcher messages

[https://github.com/microsoft/vscode/issues/151962](https://github.com/microsoft/vscode/issues/151962)

## Summary

Keep open: task problem matchers still receive plain terminal text, and Problems messages do not render SGR styling. The related helper request was closed as work to introduce when needed, not evidence that this capability shipped.

## Change summary

Preserve and display terminal SGR styling in problem matcher messages, including colored actual/expected assertion output.

## Best solution

Provide an end-to-end styling path from task terminal output to diagnostic message presentation while preserving existing plain-text matching, filtering, copying, and accessibility behavior. The scope should include diagnostic presentation beyond the Problems tree, rather than adding a renderer that receives already-stripped text.
