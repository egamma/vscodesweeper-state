# Issue #313051 — vscode.dev: extensions cannot programmatically commit or invalidate the GitHub Repositories provider's SCM cache

[https://github.com/microsoft/vscode/issues/313051](https://github.com/microsoft/vscode/issues/313051)

## Summary

Keep this request open and move it to the GitHub Repositories owner's tracker, microsoft/vscode-remote-release. The clarified requirement is a supported Commit & Push API with a completion signal, which a maintainer confirmed is missing.

## Change summary

Expose a documented GitHub Repositories commit-and-push operation that accepts a commit message, preserves SCM consistency, and reports completion.

## Best solution

Provide a supported provider-owned operation equivalent to the native Commit & Push action, with an explicit message argument and awaitable success or failure. Extensions should not need SCM input automation, direct cache manipulation, or GitHub REST polling to orchestrate the subsequent PR operation.
