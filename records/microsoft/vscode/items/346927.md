# Issue #346927 — Inbox mode: Done and Archived sections and their actions are confusing

[https://github.com/microsoft/vscode/issues/346927](https://github.com/microsoft/vscode/issues/346927)

## Summary

Keep open: current source still exposes separate Inbox Done and Archived sections, with overlapping completion terminology. Unifying them needs a product decision because Inbox dismissal deliberately differs from archival.

## Change summary

Give Inbox mode one understandable Done concept and consistently positioned dismissal, completion, and restore actions.

## Best solution

Agree on completion semantics across grouping modes, then make section names, row actions, context menus, and accessibility help express that contract consistently. Preserve the distinction between non-destructive attention management and archival unless changing it is explicitly approved.
