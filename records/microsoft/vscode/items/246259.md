# Issue #246259 — Discard changes of an Untracked file raise an error if no recycle bin option

[https://github.com/microsoft/vscode/issues/246259](https://github.com/microsoft/vscode/issues/246259)

## Summary

Still reproduces on main: the git extension ignores `files.enableTrash` when discarding untracked files, always passing `useTrash: true`. An open PR (#305686) already addresses it — keeping open pending that PR's review.

## Change summary

Discarding untracked file changes fails with an error when `files.enableTrash` is false because the git extension unconditionally uses `useTrash: true`.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/305686, which checks `files.enableTrash` alongside `git.discardUntrackedChangesToTrash` in both `repository.ts` (the actual delete) and `commands.ts` (the confirmation dialog text).
