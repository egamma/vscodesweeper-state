[https://github.com/microsoft/vscode/issues/348351](https://github.com/microsoft/vscode/issues/348351)

## Summary

Keep open: the report documents missing first-turn capabilities, and another user confirms missing client tools after conversation migration. Current source distinguishes autonomous automation execution from interactive client attachment; the tool-availability boundary and missing captured skills need separate diagnosis.

## Change summary

Automation-started sessions lack browser tools and plugin skills on their initial request, while migrated conversations can persistently lack client tools.

## Best solution

Ensure captured automation plugins reach the initial request and establish explicit behavior for automations requiring window-owned tools. Diagnose migrated-chat client attachment separately rather than assuming both triggers share a registration race.
