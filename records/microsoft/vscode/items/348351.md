# Issue #348351 — First request of an automation-started agent-host session is missing client-provided tools (integrated browser tools) and plugin skills

[https://github.com/microsoft/vscode/issues/348351](https://github.com/microsoft/vscode/issues/348351)

## Summary

Keep open: current source still starts automation sessions with a synthetic client that contributes no editor tools. Captured plugin support exists, but it does not establish a live tool executor or prove that the reported missing skills are resolved.

## Change summary

Make client-provided tools and configured plugin skills available before an automation session's first request.

## Best solution

Establish a supported first-turn capability contract for automation sessions, including an actual executor for editor tools and the saved plugin selection. Preserve unattended execution without advertising tools that no connected client can execute.
