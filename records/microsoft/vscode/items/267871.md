# Issue #267871 — [html] problem range in embedded content needs to be limited to embedded range.

[https://github.com/microsoft/vscode/issues/267871](https://github.com/microsoft/vscode/issues/267871)

## Summary

Confirmed VS Code HTML-extension bug: CSS diagnostics created for an embedded `<style>` document are returned without being constrained to the embedded range, allowing the CSS parser's recovery diagnostic to point into unrelated HTML. The maintainer confirmed the diagnosis and invited a contribution, and the issue remains necessary on current main.

## Change summary

Limit diagnostics produced for embedded CSS in HTML to the embedded stylesheet range so their reported line and column stay within `<style>` content.

## Best solution

Correct the HTML language feature's embedded-CSS validation path in `cssMode.ts` so diagnostics cannot escape the embedded document's valid range, and cover the malformed-style example with a mode unit test.
