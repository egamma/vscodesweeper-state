# Issue #278803 — Welcome: Applying inline style violates the following Content Security Policy directive

[https://github.com/microsoft/vscode/issues/278803](https://github.com/microsoft/vscode/issues/278803)

## Summary

Still present on main: the Getting Started webview renderer sets `element.style.marginTop` via JavaScript (line 139 of gettingStartedDetailsRenderer.ts), which violates the strict nonce-only `style-src` CSP policy declared in the same file. No fix has landed since the issue was filed.

## Change summary

The Welcome/Getting Started webview triggers CSP violations because inline styles are applied via JavaScript without a matching nonce or hash in the Content-Security-Policy.

## Best solution

Replace the inline `element.style.marginTop` assignment in `gettingStartedDetailsRenderer.ts` (line 139) with a CSS class or a nonce'd `<style>` block injected into the document, so the computed margin respects the declared CSP. Similar `.style.` assignments in `gettingStarted.ts` (lines 1307, 1732, 1744) may also need the same treatment.
