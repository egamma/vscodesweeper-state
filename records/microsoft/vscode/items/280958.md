# Issue #280958 — Inline chat widget work

[https://github.com/microsoft/vscode/issues/280958](https://github.com/microsoft/vscode/issues/280958)

## Summary

Keep open: current inline chat still constructs the full ChatWidget, so the architectural question remains unresolved. The linked reports were fixed individually; their closure does not establish that this redesign is complete.

## Change summary

Reconsider inline chat's dependence on the full chat widget while retaining necessary input components and tool confirmations.

## Best solution

Agree on a smaller inline-chat interaction contract, then reduce coupling to the full chat widget without losing required confirmations or established editor workflows. Decide explicitly whether model selection and other response UI remain available inline.

- **Fit:** aligned
- **Reason:** Reducing fragile coupling in an existing editor workflow supports a lightweight experience and consistent interactions.
