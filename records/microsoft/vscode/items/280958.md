# Issue #280958 — Inline chat widget work

[https://github.com/microsoft/vscode/issues/280958](https://github.com/microsoft/vscode/issues/280958)

## Summary

The architectural concern remains on current main: inline chat still constructs the full ChatWidget. The issue is already correctly classified and routed, so it should remain open for a design decision.

## Change summary

Reduce inline chat's dependency on the full chat widget while retaining input attachments, model selection, and tool confirmations.

## Best solution

Decide and implement a narrower reusable chat-input abstraction in src/vs/workbench/contrib/inlineChat and src/vs/workbench/contrib/chat, preserving confirmations and other required input capabilities without coupling inline chat to the complete response widget.
