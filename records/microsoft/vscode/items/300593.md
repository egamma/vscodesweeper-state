# Issue #300593 — Plan Mode "Start Implementation" button clears existing draft text in the chat input box

[https://github.com/microsoft/vscode/issues/300593](https://github.com/microsoft/vscode/issues/300593)

## Summary

The defect remains on current main: executing an auto-send handoff unconditionally replaces the chat input value with the handoff prompt, destroying any existing draft. The flow is source-reproducible and bounded enough for a targeted fix and regression test.

## Change summary

Starting implementation from Plan mode should submit the handoff prompt without discarding text already drafted in the chat input.

## Best solution

Auto-send handoffs should submit their generated prompt while preserving the user's existing draft input; ordinary user submissions and non-auto-send handoffs should retain their current behavior.
