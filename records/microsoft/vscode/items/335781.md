# Issue #335781 — Copilot Agent: If a agent creates a new session with create_session the new session should be aware of the parent session

[https://github.com/microsoft/vscode/issues/335781](https://github.com/microsoft/vscode/issues/335781)

## Summary

The Agent Host's living architecture spec explicitly documents that `create_session` provenance metadata (parent session/chat/turn) is recorded only as immutable placement/identification data and deliberately "does not define a hierarchy, grant communication privileges, or trigger lifecycle notifications" — exactly the capability requested here. This is a stated, current design boundary rather than an omission.

## Change summary

Requests that a child session created via `create_session` automatically be told which session is its parent (or auto-notify the parent on completion), instead of the agent having to pass a parent-session URI by hand.

## Best solution

Keep the current design: `create_session` provenance stays metadata-only. If cross-session awareness/notification is wanted, it should be a new, deliberately-scoped capability (e.g. an explicit opt-in notify-on-completion argument) proposed and designed by the Agent Host maintainers, not an implicit hierarchy grant.
