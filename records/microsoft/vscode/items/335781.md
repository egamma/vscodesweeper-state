# Issue #335781 — Copilot Agent: If a agent creates a new session with create_session the new session should be aware of the parent session

[https://github.com/microsoft/vscode/issues/335781](https://github.com/microsoft/vscode/issues/335781)

## Summary

Keep open: current main records creator provenance, but the inspected session tools do not expose that relationship to the child agent. Automatic creator notifications were explicitly removed, so historical coordination work does not establish that this request is implemented.

## Change summary

Let agent-created sessions reliably identify and report back to their creating session without manually copying its URI into prompts.

## Best solution

Provide a supported, model-visible way to identify the creating chat and address replies reliably while preserving independent session lifecycles. Maintainers should decide whether explicit replies suffice or completion should also generate an automatic notification.
