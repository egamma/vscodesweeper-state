# Issue #108757 — Git - Removing a folder from multi-root workspace does not remove repo

[https://github.com/microsoft/vscode/issues/108757](https://github.com/microsoft/vscode/issues/108757)

## Summary

Still reproduces on main: when a workspace folder is removed, its git repo is kept if any file from that folder is open in an editor, and there is no deferred cleanup when those editors close. Two community PRs are open attempting a fix.

## Change summary

Removing a folder from a multi-root workspace does not remove its git repository from the SCM pane when files from that folder are open in editors.

## Best solution

Land one of the open PRs (https://github.com/microsoft/vscode/pull/327124 or https://github.com/microsoft/vscode/pull/284139) after review. The fix should either unconditionally dispose the repo on folder removal, or defer disposal until the last editor from that folder closes — the current behavior silently leaks the repo and re-opens it on workspace reload.
