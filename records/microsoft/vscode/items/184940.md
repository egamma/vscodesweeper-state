# Issue #184940 — Shell integration run recent command shows an error when run in a remote

[https://github.com/microsoft/vscode/issues/184940](https://github.com/microsoft/vscode/issues/184940)

## Summary

The root cause — using the local `env['HOME']` instead of the remote environment's `userHome` when fetching shell history files — was fixed in commit 0ff7623f9b7 (Dec 2025), which closed #285505. This issue describes the same underlying defect in a tunnel scenario; proposing a duplicate close against the fixed canonical issue.

## Change summary

Run Recent Command (Ctrl+Alt+R) in the terminal throws an error when connected to a remote via `code tunnel`, because shell file history lookup uses the local HOME path instead of the remote's.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/285505, which is already fixed and verified. The fix in commit 0ff7623f9b7 replaced `env['HOME']` with `remoteEnvironment?.userHome?.fsPath ?? env['HOME']` across all shell history fetchers (bash, zsh, pwsh, fish, python), resolving the remote path mismatch for tunnels and other remote scenarios.
