# Issue #88178 — Copying text from a Markdown document inserts non-breaking spaces instead of regular spaces

[https://github.com/microsoft/vscode/issues/88178](https://github.com/microsoft/vscode/issues/88178)

## Summary

Still reproducible on current main: the rich-text copy path passes `platform.isWindows` as `useNbsp` to `tokenizeLineToHTML`, inserting non-breaking spaces on Windows even though the wrapping `<div>` already uses `white-space: pre` (making the nbsp hack unnecessary). This is the canonical issue — three other reports (#82844, #105000, #106077) were closed as duplicates of it. Keeping open as a valid, unresolved bug.

## Change summary

Copying syntax-highlighted text from the editor on Windows replaces regular spaces with non-breaking spaces in the HTML clipboard content.

## Best solution

Stop passing `platform.isWindows` as `useNbsp` in `viewModelImpl.ts:1129` — the `white-space: pre` CSS on the wrapping div already prevents browser whitespace collapsing, so the nbsp alternation is unnecessary. The fix touches `src/vs/editor/common/viewModel/viewModelImpl.ts` (pass `false` instead of `platform.isWindows`) and should be validated against `src/vs/editor/test/common/modes/textToHtmlTokenizer.test.ts`.
