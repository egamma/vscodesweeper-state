# Issue #344494 — Agent Bakeoff: compare workflows with and without a skill, or before and after skill changes

[https://github.com/microsoft/vscode/issues/344494](https://github.com/microsoft/vscode/issues/344494)

## Summary

Keep open: Bakeoff supports model/configuration comparisons and shared evidence, but its current attempt contract does not express independently isolated skill enablement or skill versions. The assigned 1.145.0 milestone also requires retaining this scheduled request.

## Change summary

Support controlled Bakeoff comparisons of enabled versus disabled skills and different skill versions, with reproducible conditions and per-attempt evidence.

## Best solution

Extend Bakeoff's comparison contract to represent and preserve each attempt's effective skill or plugin configuration, including genuine exclusion for disabled attempts, while holding the other inputs constant. Reuse the existing worktree isolation and evidence surfaces, but distinguish skill states and versions explicitly rather than treating a judged winner as proof of consistent improvement.
