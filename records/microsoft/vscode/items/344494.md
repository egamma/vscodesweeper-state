# Issue #344494 — Agent Bakeoff: compare workflows with and without a skill, or before and after skill changes

[https://github.com/microsoft/vscode/issues/344494](https://github.com/microsoft/vscode/issues/344494)

## Summary

Keep open: current comparison setup supports model and reasoning variants, but not isolated skill enablement or version snapshots. The assigned 1.146.0 milestone also protects this scheduled work from closure.

## Change summary

Allow controlled comparisons of a workflow with a skill enabled or excluded, or with different skill versions, while preserving reproducible conditions and per-attempt evidence.

## Best solution

Extend the provider-neutral comparison contract to capture and enforce per-attempt customization conditions, including actual skill exclusion and immutable version provenance. Preserve existing diff, validation, time, and token evidence without treating one Judge recommendation as proof of consistent improvement.
