# Issue #346849 — Tabs with horrible "..."

[https://github.com/microsoft/vscode/issues/346849](https://github.com/microsoft/vscode/issues/346849)

## Summary

Keep open as specific tab-readability feedback: Modern UI deliberately replaces fading with ellipsis, and existing sizing controls do not restore the previous dense overflow treatment. The verified related reports do not cover this request's full scope.

## Change summary

Restore space-efficient tab labels without ellipsis reducing filenames to a few characters when many tabs are open.

## Best solution

Have the tab UI owner evaluate overflow treatment that preserves useful filename prefixes in dense layouts. Treat restoring fading versus retaining ellipsis as a design decision, rather than assuming a general UI rollback is necessary.
