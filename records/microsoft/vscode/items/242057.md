# Issue #242057 — Pretty print for debugging appears in all editors when debugging

[https://github.com/microsoft/vscode/issues/242057](https://github.com/microsoft/vscode/issues/242057)

## Summary

Keep open: the bundled JavaScript debugger still exposes pretty-print through a global editor-title condition rather than checking the displayed editor's eligibility. A maintainer accepted narrowing its visibility, and the confirmed related report was closed into this issue.

## Change summary

Restrict the debugging pretty-print toolbar action to editors where pretty-printing is applicable.

## Best solution

Make the bundled JavaScript debugger's pretty-print title action reflect each editor's eligibility, preserving the ability to pretty-print scripts without pausing. Resolve the accepted JavaScript-only scoping first; restricting it further to minified sources remains a product decision.
