# Issue #334006 — add feedback widget in the settings json

[https://github.com/microsoft/vscode/issues/334006](https://github.com/microsoft/vscode/issues/334006)

## Summary

Keep open: current source still permits the agent-feedback affordance in settings JSON. This team-authored report identifies a settings-editor UX boundary that the current broad feedback eligibility does not address.

## Change summary

Avoid showing the agent-feedback input and gutter affordance when selecting text or hovering in the settings JSON editor.

## Best solution

Make ordinary settings JSON editing free of unsolicited agent-feedback affordances while preserving feedback on session files. Distinguish settings-editor resources from ordinary workspace JSON files rather than excluding JSON or all files outside the workspace.
