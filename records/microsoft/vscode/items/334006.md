# Issue #334006 — add feedback widget in the settings json

[https://github.com/microsoft/vscode/issues/334006](https://github.com/microsoft/vscode/issues/334006)

## Summary

Team-authored bug report (author is a VS Code collaborator) filed today for the still-in-development Agents Window "agent feedback" widget; I traced the leak to overly permissive eligibility gating in agentFeedbackService.ts, so this stays open pending a fix — no commit yet references it.

## Change summary

The inline "Add Feedback" gutter/hover widget from the Agents Window's agent-feedback feature appears in the plain settings.json editor, where it doesn't belong.

## Best solution

Tighten `_isFileEligibleForFeedback` in src/vs/sessions/contrib/agentFeedback/browser/agentFeedbackService.ts (currently only excludes `Schemas.outputChannel`) so it also excludes non-workspace/user-config editors like settings.json and keybindings.json, or otherwise scope `getFeedbackSessionResource` to files that are actually part of an agent-authored change set.
