# Issue #241976 — Support alternative suggest mode (insert/replace) for terminal suggestions

[https://github.com/microsoft/vscode/issues/241976](https://github.com/microsoft/vscode/issues/241976)

## Summary

Keep open: terminal suggestions already replace trailing word text in some cases, but still lack a selectable insert/replace mode or an alternative acceptance command. No verified older canonical owns this request.

## Change summary

Allow terminal suggestions invoked within a word to be accepted using an alternative insert/replace mode, including an appropriate keyboard shortcut.

## Best solution

Provide an explicit choice between preserving the word suffix and replacing the entire word, consistent with editor suggestion interactions. Establish the default behavior and alternative shortcut before implementation, preserving shell-specific completion behavior.
