# Issue #329556 — Level 4 Markdown heading gets duplicated in rendered preview

[https://github.com/microsoft/vscode/issues/329556](https://github.com/microsoft/vscode/issues/329556)

## Summary

Credible, well-documented bug: the reporter reproduced heading duplication in the Markdown preview across Windows, Linux, and vscode.dev with all extensions disabled, isolating it to core preview behavior rather than an extension. Root cause isn't conclusively traced, but it points at the new live-diff-highlighting feature in the Markdown preview.

## Change summary

Appending unrelated text to the end of a Markdown document while Preview to the Side is open causes an existing heading elsewhere in the document to render duplicated in multiple locations.

## Best solution

Investigate the newly-added live-diff preview pipeline (extensions/markdown-language-features/src/preview/lineDiff.ts computing changed line ranges, documentRenderer.ts#injectInnerChangeMarkers injecting <span> markers into raw markdown, and the morphdom-based DOM patch in preview-src/index.ts) for a case where an oversized or misaligned changed-line range, or a morphdom node-matching mismatch on `code-line` elements, causes unrelated content to be re-inserted/duplicated during a preview refresh.
