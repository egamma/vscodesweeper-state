# Issue #333337 — [WSL] VS Code 1.135.0 causes wsl.exe to consume one full CPU core after connecting to WSL

[https://github.com/microsoft/vscode/issues/333337](https://github.com/microsoft/vscode/issues/333337)

## Summary

This is a well-documented Remote WSL performance regression and should remain open while being moved to the VS Code team's Remote Development tracker.

## Change summary

Connecting VS Code 1.135.0 to WSL leaves its Windows-side wsl.exe launcher consuming one logical CPU core continuously.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release so the Remote WSL owners can investigate the server-startup process and the regression between VS Code 1.134.0 and 1.135.0.
