# Issue #283135 — Poor experience if you accidentally close the sign in window

[https://github.com/microsoft/vscode/issues/283135](https://github.com/microsoft/vscode/issues/283135)

## Summary

The pending sign-in path still prevents another setup attempt, and cancelling authentication can leave it waiting on a fallback prompt. Keep this accepted, team-authored report open: the older cancellation API issue covers related infrastructure but not the full Chat feedback and recovery experience.

## Change summary

Make an abandoned GitHub browser sign-in recoverable from Chat, with visible progress and no additional notification-dismissal requirement after cancellation.

## Best solution

Provide an explicit, discoverable pending-sign-in state in Chat and a recovery action that lets users retry or change authentication providers. Coordinate with the cancellation API work without losing this report's Chat-specific feedback and cancellation requirements.
