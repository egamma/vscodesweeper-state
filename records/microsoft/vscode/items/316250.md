# Issue #316250 — Copilot CLI agent panel: git worktree creation path defaults to inside workspace folder, causing silent duplicate loading in plugin-scan runtimes

[https://github.com/microsoft/vscode/issues/316250](https://github.com/microsoft/vscode/issues/316250)

## Summary

Keep open as a request for worktree placement control or collision avoidance. Current source deliberately creates sibling worktrees, matching the reported example, but that still places them under the host runtime's scanned directory; moving outside the workspace alone does not solve this case.

## Change summary

Allow agent-created worktrees to avoid a plugin runtime's discovery directory so isolated checkouts are not loaded as duplicate plugins.

## Best solution

Provide a supported worktree destination outside the runtime's scan root, with consistent behavior across background agents and the Agents window. Coordinate the location-control design with https://github.com/microsoft/vscode/issues/293884 while retaining this report's distinct duplicate-plugin-loading acceptance case.
