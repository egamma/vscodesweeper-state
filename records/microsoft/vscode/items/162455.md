# Issue #162455 — Add a specific panel for TODO-style comments

[https://github.com/microsoft/vscode/issues/162455](https://github.com/microsoft/vscode/issues/162455)

## Summary

Keep open as an accepted Backlog feature request with 227 upvotes. Current main still lacks a TODO diagnostic classification and dedicated filtering or view.

## Change summary

Add a native TODO diagnostic concept and an optional dedicated panel or filter separate from ordinary Problems.

## Best solution

Define a standardized TODO diagnostic tag or kind that language extensions can publish, then support independent, optional filtering or presentation without forcing an additional panel on every user.
