# Issue #27972 — Include support for system-wide mandatory/default settings

[https://github.com/microsoft/vscode/issues/27972](https://github.com/microsoft/vscode/issues/27972)

## Summary

Keep open: mandatory policies now exist across supported desktop platforms, but current main still lacks deployable system-wide defaults that users and workspaces may override. The Backlog request has 72 community upvotes and remains independently actionable.

## Change summary

Allow administrators to deploy system-wide mandatory settings and overridable default settings for all users.

## Best solution

Add an administrator-managed default configuration source below user, workspace, and folder settings, while retaining policy configuration as the mandatory highest-precedence layer. The implementation should integrate with the configuration model and use platform-appropriate deployment locations.
