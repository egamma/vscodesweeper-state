# Issue #191719 — Web typings file system triggers FS errors when clicking through breadcrumbs

[https://github.com/microsoft/vscode/issues/191719](https://github.com/microsoft/vscode/issues/191719)

## Summary

Still reproduces on main: the AutoInstallerFs doesn't handle parent-path resolution gracefully when breadcrumbs navigate up from a typings file, causing unhandled errors for paths that don't match the expected node_modules URI structure.

## Change summary

Clicking breadcrumbs in web typings files triggers FS resolution errors because the vscode-node-modules filesystem provider cannot handle parent directory paths outside node_modules.

## Best solution

AutoInstallerFs.stat (and readDirectory) should return graceful FileNotFound or a synthetic directory stat for ancestor paths above node_modules, so breadcrumb navigation doesn't surface unhandled errors to the user.
