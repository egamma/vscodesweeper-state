## Summary

The reported failure remains source-reproducible: breadcrumbs offer virtual ancestor directories that the web typings filesystem explicitly rejects. Keep this open in the existing TypeScript and breadcrumbs areas; no verified canonical or fixing commit was found.

## Change summary

Prevent filesystem errors when navigating package-typing breadcrumbs in web workspaces.

## Best solution

Make breadcrumbs and the web typings filesystem agree on which ancestor directories are navigable, so clicking a displayed breadcrumb does not produce a nonexistent-file error. Preserve navigation within acquired packages and normal error reporting for genuinely missing files.
