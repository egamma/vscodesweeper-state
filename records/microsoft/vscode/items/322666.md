# Issue #322666 — The follow-link copy button copies the `Follow link (ctrl + click)` text literally

[https://github.com/microsoft/vscode/issues/322666](https://github.com/microsoft/vscode/issues/322666)

## Summary

The reported clipboard result remains reproducible from current source: the link hover's copy button copies its visible instruction text rather than the link destination. Keep this open for a bounded editor-hover correction.

## Change summary

Make the copy button on a source-code URL's Follow Link hover copy the URL instead of the navigation instruction.

## Best solution

The dedicated Follow Link hover should copy its destination URL while retaining its existing navigation behavior and accessible description. Ordinary documentation and diagnostic hovers should continue copying their content.
