# Issue #324626 — Still waiting even after the download notification completes

[https://github.com/microsoft/vscode/issues/324626](https://github.com/microsoft/vscode/issues/324626)

## Summary

Team-authored feedback from test-plan verification of the agent-host download progress notification (issue #324229, PR #322919): the progress UI only spans download+extraction and goes silent afterward, so real gaps (extraction, agent process startup) remain invisible to users. Real, unfixed gap — route to the agent-host area rather than close.

## Change summary

Extend the agent-SDK download progress notification to cover post-download phases (extracting the archive, starting the binary) so users aren't left waiting with no feedback after 'download complete'.

## Best solution

In src/vs/platform/agentHost/node/agentSdkDownloader.ts, add explicit progress phases (or messages) for archive extraction and process startup, and have agentHostMain.ts's onDidDownloadProgress forwarding (around line 296-308) surface those phases instead of treating the entire download+extract+start sequence as done once bytes are 'completed'.
