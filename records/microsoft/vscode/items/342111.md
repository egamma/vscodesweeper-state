## Change summary

Extension-contributed tools in Copilot CLI manual permission mode stall without confirmation or invocation until a 30-minute timeout, while Allow All succeeds.

## Best solution

Diagnose the missing transition between SDK external-tool dispatch, permission handling, and client-tool readiness in the Copilot Agent Host integration. Extension tools should reach an actionable confirmation or an authorized invocation without requiring Allow All, while preserving permission enforcement.
