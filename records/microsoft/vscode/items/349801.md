# Issue #349801 — Worktree Cleanup lets you clean up a running session if it's the one open in the window

[https://github.com/microsoft/vscode/issues/349801](https://github.com/microsoft/vscode/issues/349801)

## Summary

The reported protection gap remains in current main: a shown, running session is classified as active, making it selectable for cleanup without a running-session warning.

## Change summary

Prevent ordinary worktree cleanup from unexpectedly stopping a session that is still working.

## Best solution

Running sessions should receive the existing running-session protection regardless of which window shows them. Preserve manual cleanup of non-running active sessions and sessions waiting for input.
