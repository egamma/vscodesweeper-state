# Issue #299227 — Make npm scripts panel order consider directory depth

[https://github.com/microsoft/vscode/issues/299227](https://github.com/microsoft/vscode/issues/299227)

## Summary

The npm Scripts view still lacks depth-aware package ordering, and existing settings do not cover the request. Keep this open under discussion; its age and three upvotes do not justify a cleanup close.

## Change summary

Order package.json entries by directory depth so root-level scripts appear before nested packages.

## Best solution

Consider shallow-first package ordering in the built-in npm Scripts view, retaining alphabetical ordering within each depth and consistent behavior inside each workspace folder. Treat filtering build outputs as a separate concern: deeper placement does not guarantee that generated packages appear last.

## Evidence

- **Current ordering:** extensions/npm/src/npmView.ts: PackageJSON.getLabel constructs the relative package.json path, and NpmScriptsTreeDataProvider.sortTaskTree compares labels using localeCompare without considering directory depth. getChildren invokes this sorting for the top-level task tree; workspace-folder children return element.packages directly.
- **Existing-capability check:** extensions/npm/package.json configuration and command registrations contain no package-order or depth-order control. npm.exclude removes packages from detection, npm.scriptExplorerExclude filters scripts, and npm.refresh rebuilds the same view; none supplies root-first ordering. extensions/npm/README.md documents these existing alternatives.
