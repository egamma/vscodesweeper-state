# Issue #337042 — New Session view spinner no longer showing spinning animation

[https://github.com/microsoft/vscode/issues/337042](https://github.com/microsoft/vscode/issues/337042)

## Summary

Confirmed on main: the New Session composer's loading spinner (`.sessions-chat-loading-spinner`, used for both the initialization and send/loading states in `newChatInput.ts`) renders a `codicon-loading-compact.codicon-modifier-spin` icon, but no CSS rule provides the spin animation for that container — the only rule that animates `.codicon-loading-compact.codicon-modifier-spin` is scoped to `.sessions-chat-stt-button`/`.sessions-chat-voice-toolbar` in `chatInput.css`, and the base codicon spin keyframes in `codicon-modifiers.css` only cover `.codicon-loading` (not the `-compact` variant) unconditionally.

## Change summary

The loading codicon shown in the Agents window's New Session composer (while initializing or sending) is static instead of spinning.

## Best solution

Add a `.monaco-enable-motion ... .sessions-chat-loading-spinner .codicon-loading-compact.codicon-modifier-spin { animation: codicon-spin ...; transform-origin: center center; }` rule in chatInput.css, mirroring the existing stt-button/voice-toolbar rule at lines 205-206, so the compact spinner actually animates wherever it's used.
