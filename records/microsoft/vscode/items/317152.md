# Issue #317152 — Agents window -- closed PR icon doesn't persist

[https://github.com/microsoft/vscode/issues/317152](https://github.com/microsoft/vscode/issues/317152)

## Summary

Keep open: current source still lets the draft flag override a closed PR's state, matching the reported incorrect icon. This team-authored report has neither a verified fixing commit nor an eligible canonical duplicate.

## Change summary

A closed draft PR continues to display the draft icon, including after reloading the Agents window.

## Best solution

Closed and merged PRs should display their terminal-state icons regardless of a retained draft flag, consistently across session references and the chat toolbar. Preserve existing open-draft presentation and verify that cached startup icons are not replaced with an incorrect draft icon when live data arrives.
