# Issue #52004 — Ignore `editor.insertSpaces` within strings

[https://github.com/microsoft/vscode/issues/52004](https://github.com/microsoft/vscode/issues/52004)

## Summary

A real editor capability gap remains: Tab insertion always follows the buffer-wide indentation setting and does not account for string tokens. The related open indentation issues do not fully cover literal tabs appearing mid-line inside strings.

## Change summary

Allow Tab to insert a literal tab character inside strings even when `editor.insertSpaces` is enabled.

## Best solution

Define an editor-core mechanism for inserting literal tabs independently of indentation, either contextually within string tokens or through a dedicated bindable command, without changing normal indentation behavior.
