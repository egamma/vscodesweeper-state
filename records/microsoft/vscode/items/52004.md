# Issue #52004 — Ignore `editor.insertSpaces` within strings

[https://github.com/microsoft/vscode/issues/52004](https://github.com/microsoft/vscode/issues/52004)

## Summary

The requested string-aware Tab behavior remains absent: current insertion follows editor.insertSpaces without checking string context. Neither related issue establishes a valid duplicate or a decision declining this request's full scope.

## Change summary

Insert literal tabs inside strings while retaining space-based indentation elsewhere.

## Best solution

Evaluate string-aware Tab insertion in the editor's tab operation, preserving existing indentation behavior outside strings. Explicit literal-tab insertion is a workaround, not equivalent to automatically recognizing string context.
