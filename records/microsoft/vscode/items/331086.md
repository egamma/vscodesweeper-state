# Issue #331086 — Commit messages garbled depending on Git settings

[https://github.com/microsoft/vscode/issues/331086](https://github.com/microsoft/vscode/issues/331086)

## Summary

Legitimate bug with a clear cause (Git's i18n.commitEncoding/i18n.logOutputEncoding user settings affecting the raw byte encoding of commit messages that VS Code parses as UTF-8), and the reporter has already opened a fixing PR — best to let that merge rather than close or route this now.

## Change summary

When a user sets Git's i18n.commitEncoding/i18n.logOutputEncoding to a non-UTF-8 encoding, commit messages shown in the Source Control Graph and Git blame decorations render garbled because VS Code reads Git's output as UTF-8 regardless of the configured encoding.

## Best solution

Land the reporter's own PR https://github.com/microsoft/vscode/pull/331087, which forces `i18n.logOutputEncoding=UTF-8` (via `-c`) when invoking git log/blame commands, with an added regression test using an EUC-JP-encoded repo.
