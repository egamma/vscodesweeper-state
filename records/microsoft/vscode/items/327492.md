# Issue #327492 — runTests tool description confuses agents

[https://github.com/microsoft/vscode/issues/327492](https://github.com/microsoft/vscode/issues/327492)

## Summary

Current main still describes the general Test Explorer runner as unit-test-only, which can incorrectly steer agents away from integration or end-to-end tests. This is a small testing-tool metadata bug and should remain open for correction.

## Change summary

Generalize the runTests tool descriptions so agents understand that it runs any tests registered with VS Code's Test Explorer.

## Best solution
