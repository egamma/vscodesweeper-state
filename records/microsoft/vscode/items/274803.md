- **Trace:**

  > The reporter isolated the AWS plugin and confirmed that a nested zsh changes the failure into success; see https://github.com/microsoft/vscode/issues/274803#issuecomment-3646335226. The plugin appends aws_prompt_info to RPROMPT, and shellIntegration-rc.zsh wraps RPROMPT with right-prompt escape sequences. PromptInputModel._doSync reads text after commandStartX, while its right-prompt heuristic concerns ghost-text classification; the existing right-prompt test retains RP as input.
