# Issue #316307 — Use artifacts for background terminals to improve accessibilty and stability

[https://github.com/microsoft/vscode/issues/316307](https://github.com/microsoft/vscode/issues/316307)

## Summary

Keep open: local background terminal commands still expose the inline Show action, while the newer Background Shells pill is wired to agent-host background work. This team-authored, accepted request remains distinct from the related terminal-output and general background-terminal UX issues.

## Change summary

Expose terminals that continue running after a chat turn through the artifacts area rather than relying on an inline Show action.

## Best solution

Provide a stable, keyboard- and screen-reader-accessible entry point for local background terminal commands outside collapsed transcript content. Agree whether the existing Background Shells pill should fulfill the original artifacts-area request, then cover local terminal lifecycle and session isolation.
