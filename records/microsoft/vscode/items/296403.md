# Issue #296403 — `Learn more about agent handoff...` link styling

[https://github.com/microsoft/vscode/issues/296403](https://github.com/microsoft/vscode/issues/296403)

## Summary

Keep open for a focused design decision: current source still presents the handoff documentation action as an ordinary, iconless menu row rather than a theme-colored link. This team-authored request has no verified fixing commit or qualifying duplicate.

## Change summary

Make the agent-handoff documentation entry clearly recognizable as a link and visually consistent with neighboring picker entries.

## Best solution

Agree whether the documentation entry should read as a distinct link or as a standard menu command, then apply that treatment consistently to the session pickers. Preserve theme-aware colors and keyboard navigation rather than hardcoding blue or adding an icon solely for decoration.
