# Issue #264731 — Chat - Can't change chat inline code font style

[https://github.com/microsoft/vscode/issues/264731](https://github.com/microsoft/vscode/issues/264731)

## Summary

Still reproduces on main: inline `<code>` in chat responses uses `--monaco-monospace-font` (the editor's monospace font) instead of `chat.editor.fontFamily`, so the chat font settings don't apply to inline code. The team discussion concluded `chat.editor.fontFamily` should be used but no fix has landed.

## Change summary

Inline code in chat responses ignores the `chat.editor.fontFamily` setting, using the editor monospace font instead.

## Best solution

In `src/vs/workbench/contrib/chat/browser/widget/media/chat.css` (around line 744), change the inline `code` rule's `font-family` from `var(--monaco-monospace-font)` to `var(--vscode-chat-font-family, var(--monaco-monospace-font))` so the chat editor font family applies, with the mono font as fallback. The font-size question (whether to also use `chat.editor.fontSize`) was flagged as problematic by the reporter and should remain as-is or be discussed separately.
