# Issue #264731 — Chat - Can't change chat inline code font style

[https://github.com/microsoft/vscode/issues/264731](https://github.com/microsoft/vscode/issues/264731)

## Summary

The customization gap remains on current main: inline Markdown code explicitly uses the workbench monospace font instead of the configured chat editor font. Keep this accepted bug open while the remaining font-size behavior is decided.

## Change summary

Make inline code in chat responses respect the appropriate configurable chat code font styling.

## Best solution

Inline code should use the resolved `chat.editor.fontFamily`, consistently with fenced chat code and webviews. A maintainer should first decide whether it also uses `chat.editor.fontSize` or retains a size relative to `chat.fontSize`.
