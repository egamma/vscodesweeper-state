# Issue #264731 — Chat - Can't change chat inline code font style

[https://github.com/microsoft/vscode/issues/264731](https://github.com/microsoft/vscode/issues/264731)

## Summary

Chat inline code still does not use chat.editor.fontFamily, so the requested typography improvement remains relevant. The discussion supports sharing the codeblock font family, but whether inline code should also adopt the codeblock font size remains an unresolved product decision.

## Change summary

Make chat inline-code typography respond to the appropriate chat font settings.

## Best solution

Let inline code use the configured chat codeblock font family while maintaining a coherent typography hierarchy within prose. Settle whether its size should remain proportional to chat text or follow chat.editor.fontSize before changing that behavior.
