# Issue #264731 — Chat - Can't change chat inline code font style

[https://github.com/microsoft/vscode/issues/264731](https://github.com/microsoft/vscode/issues/264731)

## Summary

Keep open: current chat font settings still do not provide chat-specific inline-code font-family handling. The maintainer proposed using the codeblock settings, but the discussion has not settled whether inline code should also adopt the codeblock font size.

## Change summary

Allow chat font configuration to control inline Markdown code without producing inconsistent typography within a response.

## Best solution

Make inline-code font-family configuration consistent with chat codeblocks in the chat widget, while preserving other Markdown surfaces. Settle whether inline code should inherit the surrounding text size or use chat.editor.fontSize before implementing the typography change.
