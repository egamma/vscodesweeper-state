# Issue #320912 — Feature Request: Sync chat history between VS Code IDE Chat and Agents view

[https://github.com/microsoft/vscode/issues/320912](https://github.com/microsoft/vscode/issues/320912)

## Summary

Keep open: current source supports continuity for eligible Agent Host sessions, but does not establish equivalent access to ordinary local Chat conversations. The closest matching report is newer, so it cannot be a duplicate target under the re-review rules.

## Change summary

Make chat history and conversation context available across the IDE Chat and Agents surfaces without manually recreating the conversation.

## Best solution

Provide a supported continuity path for existing local workbench conversations, while preserving shared-session behavior for Agent Host conversations. Coordinate the history and runtime semantics with the related session-porting work rather than treating cloud session indexing as equivalent functionality.
