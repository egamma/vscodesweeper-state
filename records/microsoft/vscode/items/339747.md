# Issue #339747 — Agents - do not show the table when there are no worktrees to clean up

[https://github.com/microsoft/vscode/issues/339747](https://github.com/microsoft/vscode/issues/339747)

## Summary

The requested empty state is still missing: the cleanup editor always renders table headers and leaves the cleanup button visible when no worktrees are eligible. Keep this maintainer-authored UI improvement open; no verified duplicate or fixing PR was found.

## Change summary

Show an informational banner instead of an empty worktree table and disabled cleanup button when nothing is eligible for cleanup.

## Best solution

The worktree cleanup editor should clearly explain that no worktrees qualify for the selected period, without presenting an empty table or unusable cleanup action. Keep the age selector and cleanup settings available, and restore the normal table and action when eligible worktrees become available.
