# Issue #227849 — ctrl+z / ctrl+shift+z (undo/redo) not working for input elements when a custom editor is open

[https://github.com/microsoft/vscode/issues/227849](https://github.com/microsoft/vscode/issues/227849)

## Summary

The command-routing defect remains in current source: an active custom editor consumes undo/redo before the handler for the separately focused webview view can run. Keep this accepted, team-authored bug open; the older related report concerns input inside the custom editor and does not establish the same cross-view symptom.

## Change summary

Undo and redo stop editing a webview view's input when a custom editor is active in the editor area.

## Best solution

Make undo/redo respect the focused webview view without changing custom-document undo/redo when the custom editor is the intended target. Pin the cross-view routing behavior with a focused regression test.
