# Issue #227849 — ctrl+z / ctrl+shift+z (undo/redo) not working for input elements when a custom editor is open

[https://github.com/microsoft/vscode/issues/227849](https://github.com/microsoft/vscode/issues/227849)

## Summary

Still reproduces on main: the custom editor's undo/redo handler (priority 105) intercepts Ctrl+Z/Ctrl+Shift+Z whenever a custom editor is the active editor, without checking whether a webview view's input element actually has focus — so undo/redo in webview view inputs is swallowed.

## Change summary

Ctrl+Z / Ctrl+Shift+Z stop working in webview view input elements when a custom editor is the active editor tab.

## Best solution

The custom editor undo/redo handler in `src/vs/workbench/contrib/customEditor/browser/customEditors.ts` (line ~128) should check whether the custom editor's own webview is focused before claiming the command. If a different webview (e.g. a sidebar webview view) holds focus, the handler should return `false` and let lower-priority handlers (like the webview handler at priority 100) take over.
