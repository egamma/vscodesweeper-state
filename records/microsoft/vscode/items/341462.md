# Issue #341462 — Copilot CLI (Copilot SDK) agent sessions can't use visible VS Code terminals, so the user can't complete interactive auth (SSH/sudo passwords)

[https://github.com/microsoft/vscode/issues/341462](https://github.com/microsoft/vscode/issues/341462)

## Summary

Keep open: current source still excludes Windows from the custom terminal integration, so the existing setting does not cover interactive authentication there. The discussion also raises credential exposure and privilege-approval concerns, requiring human review rather than a cleanup close.

## Change summary

Allow users to interact directly with Copilot SDK shells for authentication and let the agent continue in the same authenticated terminal session.

## Best solution

Provide a user-to-process input path and visible terminal access for Copilot SDK sessions, including Windows, while preserving command approval and sandbox enforcement. Credential entry must bypass model context; passwordless sudo is not equivalent coverage.
