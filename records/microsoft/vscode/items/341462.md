# Issue #341462 — Copilot CLI (Copilot SDK) agent sessions can't use visible VS Code terminals, so the user can't complete interactive auth (SSH/sudo passwords)

[https://github.com/microsoft/vscode/issues/341462](https://github.com/microsoft/vscode/issues/341462)

## Summary

Keep open: current source still excludes Windows from the Agent Host terminal override, and the background-shell preview provides output rather than interactive input. The discussion also raises credential-handling and privilege-escalation boundaries, requiring human review rather than a cleanup close.

## Change summary

Allow users to interact directly with Copilot SDK shell sessions for SSH and sudo authentication, then let the agent continue in the same authenticated process.

## Best solution

Provide a supported human-to-process terminal input path for Copilot SDK sessions, including Windows, with persistent shell identity and agent continuation after authentication. Agent Host, terminal, and runtime owners should establish credential isolation and approval semantics without requiring passwordless sudo or passwords in chat.
