## Evidence

- **Reported failure:** https://github.com/microsoft/vscode/issues/318951 records a crash while the workspace is idle on Linux with VS Code 1.122.1. V8 retains approximately 3.9 GB after garbage collection, reports 'Ineffective mark-compacts near heap limit', and the renderer exits with code 132. This establishes renderer heap exhaustion, not its allocation source.
- **Confirmed reproduction and isolation:** https://github.com/microsoft/vscode/issues/318951#issuecomment-4630736565 independently confirms renderer memory growth to approximately 4.5 GB after opening a Remote-SSH workspace across versions 1.121–1.123. Setting chat.disableAIFeatures prevents it; disabling Python and Dev Containers also prevents initialization-time crashes, although re-enabling them can allow recurrence.
- **Verified older canonical:** https://github.com/microsoft/vscode/issues/311239 was verified OPEN and was created on 2026-04-19, before this report's 2026-05-29 creation. Its reproduction explicitly opens a Remote-SSH workspace, enables AI features, observes renderer growth from approximately 100 MB to over 5 GB, and ends in a window crash; disabling AI features keeps it stable. This matches the confirmed reporter-observable symptom here, satisfying the stronger re-review duplicate bar.
- **Cross-platform canonical scope:** https://github.com/microsoft/vscode/issues/311239#issuecomment-4281238106 confirms the same issue on Ubuntu under WSL, and https://github.com/microsoft/vscode/issues/311239#issuecomment-4286113509 links memory growth to remote workspace file count. The canonical therefore is not limited to the original macOS configuration.
- **Source inspection and boundary:** src/vs/platform/windows/electron-main/windowImpl.ts:972–980 logs renderer termination in onWindowError; it does not identify the allocation responsible. src/vs/workbench/services/search/node/ripgrepFileSearch.ts:17–23 and ripgrepTextSearchEngine.ts:60–78 launch ripgrep for workspace searches, so the presence of an rg process alone does not establish a separate root cause. No fixing commit was established.
- **Other candidates distinguished:** https://github.com/microsoft/vscode/issues/285598 describes extension-host restarts during long conversations, rather than idle workspace renderer exhaustion. https://github.com/microsoft/vscode/issues/324188 principally describes remote-host resource growth and is newer than this report. Neither is the appropriate canonical.
