# Issue #275888 — Let me hide Ask & Edit modes

[https://github.com/microsoft/vscode/issues/275888](https://github.com/microsoft/vscode/issues/275888)

## Summary

Keep this team-authored feature request open: current main hides legacy Edit mode by default, but still provides no user control for hiding Ask. The remaining Ask behavior has active maintainer interest and is not owned by another open issue.

## Change summary

Allow users who prefer agentic workflows to hide the built-in Ask and Edit entries from the chat mode picker.

## Best solution

Provide a profile-scoped visibility control for built-in chat agents, with Ask removable from the mode picker and restorable later; retain support for existing Ask/Edit conversations and the policy-disabled fallback. Edit is already hidden by default on current main, so the remaining work should build on the existing custom-agent enablement and AI Customizations surfaces rather than add another unrelated setting.
