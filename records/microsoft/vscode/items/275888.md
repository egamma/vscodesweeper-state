# Issue #275888 — Let me hide Ask & Edit modes

[https://github.com/microsoft/vscode/issues/275888](https://github.com/microsoft/vscode/issues/275888)

## Summary

This is the canonical issue for hiding built-in Ask & Edit chat modes. Two duplicates (#278304 and #283615) were closed pointing here. The feature is not yet implemented — Ask and Edit are still hardcoded in `getBuiltinModes()` with no hide/disable mechanism. Team-authored; keeping open.

## Change summary

Allow users to hide or disable the built-in Ask and Edit chat modes from the mode picker.

## Best solution

Add a visibility/hide mechanism for builtin chat modes in `src/vs/workbench/contrib/chat/common/chatModes.ts` — either via a setting or by converting Ask into a custom agent (as discussed in comments). The `getBuiltinModes()` method currently hardcodes Ask and Edit with no opt-out. The discussion suggests Ask could become a normal custom agent, and Edit could go behind a setting (default off).
