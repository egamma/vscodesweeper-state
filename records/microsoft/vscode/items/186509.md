# Issue #186509 — Add a "Reload all windows" command

[https://github.com/microsoft/vscode/issues/186509](https://github.com/microsoft/vscode/issues/186509)

## Summary

This remains a valid Backlog feature request with 36 community upvotes. Current main only reloads the active window, and no open canonical issue owns the broader command.

## Change summary

Add commands to reload or reconnect all applicable VS Code windows at once.

## Best solution

Add a workbench-window command backed by the Electron main process that reloads all main windows, with careful handling of windows containing unsaved changes. The narrower prompt-only and reconnect variants can be evaluated separately.
