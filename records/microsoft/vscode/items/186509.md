# Issue #186509 — Add a "Reload all windows" command

[https://github.com/microsoft/vscode/issues/186509](https://github.com/microsoft/vscode/issues/186509)

## Summary

Keep this accepted Backlog request open: current reload behavior targets one window, and restarting the application does not cover the requested in-place bulk reload. The request has 36 upvotes, and no verified open canonical or implementation PR was found.

## Change summary

Provide one command that reloads all open VS Code windows without quitting and relaunching the application.

## Best solution

Provide a desktop bulk-reload command that preserves each window's existing reload semantics and shutdown safeguards without relying on window.restoreWindows. Decide the window scope and whether reconnect-only or prompt-filtered variants belong in the initial feature.

- **Behavior:**

  > Users should be able to invoke one command to perform the equivalent of Developer: Reload Window across eligible open windows without quitting the application. Reconnect-only and prompt-filtered variants are additional requested conveniences whose initial scope remains undecided.
