## Summary

Team-authored bug report (0 days old) with a specific, concrete repro (tab to the sandbox toggle in the permission picker, press Space, picker disappears) filed while testing an in-progress change (#335765); keep-open per the team-authored protection since no cited fix commit or duplicate exists yet.

## Change summary

Pressing Space while the sandbox toggle row is focused in the chat permission picker closes/hides the picker instead of flipping the toggle.

## Best solution

Trace the keyboard path for the sandbox toggle row: `toggleSectionCodeAction` (bound to Space) in src/vs/platform/actionWidget/browser/actionWidget.ts falls back to `acceptSelected()` when `toggleFocusedSection()` returns false, which re-enters `ActionList.onListSelection` in src/vs/platform/actionWidget/browser/actionList.ts; confirm whether the sandbox row (built with `standaloneToggle` in src/vs/workbench/contrib/chat/browser/widget/input/permissionPickerActionItem.ts, around the `chat.permissions.sandbox` action) is actually reaching the `element.standaloneToggle` branch there versus falling through to `onSelect`, which calls `actionWidgetService.hide()` in actionWidgetDropdown.ts. Best owned by whoever lands #335765.
