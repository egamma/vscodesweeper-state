# Issue #170799 — 'Open recent' menu takes up full width of the window when it contains an entry with very long path

[https://github.com/microsoft/vscode/issues/170799](https://github.com/microsoft/vscode/issues/170799)

## Summary

Still reproducible on main: the menu system applies no max-width or text-overflow constraint to action labels, so extremely long paths in Open Recent expand the menu to full window width.

## Change summary

The 'Open Recent' submenu stretches to the full window width when it contains an entry with a very long path.

## Best solution

Add a max-width and text-overflow:ellipsis constraint to menu action labels (in `src/vs/base/browser/ui/menu/menu.ts` CSS or via the context view layout logic) so that menus are clamped to a reasonable fraction of the viewport width.
