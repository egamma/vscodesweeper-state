# Issue #170799 — 'Open recent' menu takes up full width of the window when it contains an entry with very long path

[https://github.com/microsoft/vscode/issues/170799](https://github.com/microsoft/vscode/issues/170799)

## Summary

Fixed on current main by the merged implementation in PR https://github.com/microsoft/vscode/pull/329710, which explicitly references this issue and bounds Open Recent labels to 120 characters.

## Change summary

An extremely long recent-item path caused the File > Open Recent submenu to expand across the window.

## Best solution

Keep the landed middle-truncation behavior from commit d8dcf962241864c7a1631e3b8a8acb00e88a9d9d; it preserves identifying path segments while preventing an oversized menu.
