# Issue #279266 — showRange field regression: functionality lost during InlineCompletionsSource refactoring

[https://github.com/microsoft/vscode/issues/279266](https://github.com/microsoft/vscode/issues/279266)

## Summary

Confirmed regression on current main: the `showRange` field is defined in the API and passed through the extension host, but `InlineSuggestData` never stores or checks it — cursor position filtering is completely absent. An open PR exists to fix it.

## Change summary

The `showRange` field on `InlineCompletionItem` (proposed API) was silently broken during an `InlineCompletionsSource` refactoring — inline completions now display regardless of cursor position relative to `showRange`.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/279269 which restores the `showRange` cursor-position check. The fix should store `showRange` in `InlineSuggestData` (or read it from `sourceInlineCompletion`) and gate inline completion visibility on `showRange.containsPosition(cursorPos)` in `inlineCompletionsModel.ts`.
