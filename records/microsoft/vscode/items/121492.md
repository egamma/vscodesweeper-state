# Issue #121492 — ALT+SCROLL in .deb should to be disable and run none

[https://github.com/microsoft/vscode/issues/121492](https://github.com/microsoft/vscode/issues/121492)

## Summary

This issue describes ALT+SCROLL triggering both VS Code scrolling and XFCE desktop zoom simultaneously on Debian 10 — a classic window-manager key-grab conflict, already labeled `upstream`. The report is over 5 years old, filed against VS Code 1.56 on a now-EOL Debian release, with no reproduction details on current builds, no upvotes, and the author's account is deleted.

## Change summary

ALT+SCROLL in VS Code on Debian XFCE zooms the screen in addition to scrolling the editor, because the XFCE window manager intercepts ALT as its own modifier.

## Best solution

This is an XFCE desktop environment issue — XFCE uses ALT as its window-manager modifier by default, so ALT+SCROLL triggers XFCE's zoom accessibility feature alongside VS Code's scroll. The fix is to change the XFCE window-manager modifier key in XFCE settings (Settings → Window Manager Tweaks → Accessibility), not in VS Code. Since the author's account is deleted and cannot respond, and the report is against an EOL OS version with VS Code 1.56, this should be closed after the info-needed period expires.
