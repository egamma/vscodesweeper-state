## Change summary

PowerShell terminal commands with operators inside colon-attached quoted arguments unexpectedly require confirmation despite a matching full-command-line approval rule.

## Best solution

Make valid colon-attached literal arguments behave consistently with space-separated quoted arguments in terminal auto-approval. First establish whether the PowerShell grammar produces an erroneous parse or command capture, while preserving confirmation for genuinely executable nested syntax and explicit deny rules.
