# Issue #350181 — Agents window: marking a file reviewed runs 36 git commands, mostly repeating the same work

[https://github.com/microsoft/vscode/issues/350181](https://github.com/microsoft/vscode/issues/350181)

## Summary

Keep open: current source still forces a full Branch Changes recomputation after marking files reviewed and repeats review-context resolution and working-tree capture. Related optimizations reduce some Git work but do not remove this review-click path.

## Change summary

Avoid redundant Git work when marking Branch Changes files reviewed, including repeated snapshots within a multi-file action.

## Best solution

Review-only changes should update authoritative reviewed flags without recomputing unchanged branch diffs or recapturing the same working tree. Preserve full refreshes when repository inputs changed or review persistence could not establish the requested state, including correct reconciliation with in-flight computations.
