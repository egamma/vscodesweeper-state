# Issue #227892 — [regression] Increased typing lag with many word separators

[https://github.com/microsoft/vscode/issues/227892](https://github.com/microsoft/vscode/issues/227892)

## Summary

Confirmed regression from commit a5698e8 — the `_computeSnippetPositions` loop in `snippetCompletionProvider.ts` iterates character-by-character backward through the line, calling `getWordAtPosition` at each column, causing O(n) expensive calls on lines with many word separators. An open community PR (#244353) proposes a fix. Keeping open for the team to land a fix.

## Change summary

Triggering completions on a long single line with many word separator characters causes VS Code to freeze, regressed in 1.86.0.

## Best solution

Land a bounded backward search in `_computeSnippetPositions` (file: `src/vs/workbench/contrib/snippets/browser/snippetCompletionProvider.ts`, line ~209) — either cap the lookback distance as PR https://github.com/microsoft/vscode/pull/244353 proposes, or use a smarter algorithm that avoids per-character `getWordAtPosition` calls. Review and land the open PR or implement an equivalent fix.
