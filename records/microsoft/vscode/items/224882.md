# Issue #224882 — Custom title bar not hiding on startup in Zen mode

[https://github.com/microsoft/vscode/issues/224882](https://github.com/microsoft/vscode/issues/224882)

## Summary

Fixed on current main: restored Zen mode no longer overrides the configured custom-title-bar visibility, so a hidden title bar remains hidden after startup or window reload.

## Change summary

Keep the custom title bar hidden when VS Code starts or reloads with Zen mode restored.

## Best solution

Retain the title-bar restoration behavior from commit 788e7891eb72ae1dae9b8191d97455418bf44305, which makes restored Zen mode honor `window.customTitleBarVisibility` instead of imposing separate visibility.
