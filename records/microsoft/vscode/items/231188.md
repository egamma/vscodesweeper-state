# Issue #231188 — Feature request: Contribution point for context menus in shell integration command decorations

[https://github.com/microsoft/vscode/issues/231188](https://github.com/microsoft/vscode/issues/231188)

## Summary

Still a valid open feature request. A PR (#233115) was attempted to add a `MenuId.TerminalCommand` contribution point for shell integration command decorations, but it was closed without merging. The decoration context menu in `decorationAddon.ts` still uses hardcoded actions — no contributable menu exists on current main.

## Change summary

Allow extensions to contribute context menu items to shell integration command decorations in the terminal.

## Best solution

Add a contributable `MenuId` for the terminal command decoration context menu (in `src/vs/workbench/contrib/terminal/browser/xterm/decorationAddon.ts`) and register it as a menu extension point, picking up where the closed PR #233115 left off. The command context should include the terminal command details so extensions can act on execution results.
