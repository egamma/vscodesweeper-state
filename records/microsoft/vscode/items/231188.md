# Issue #231188 — Feature request: Contribution point for context menus in shell integration command decorations

[https://github.com/microsoft/vscode/issues/231188](https://github.com/microsoft/vscode/issues/231188)

## Summary

Keep this API proposal open: current extension contribution points do not cover shell-integration command decoration menus, and the linked implementation attempt closed without merging. The api-proposal label independently bars a cleanup close.

## Change summary

Allow extensions to contribute shell-integration command decoration menu actions with the selected terminal execution as context.

## Best solution

Have the terminal API owners settle the extension-host argument contract for the selected terminal and execution, then expose the decoration menu through a supported contribution point. Existing terminal-wide menus and internal action registration do not satisfy that contract.
