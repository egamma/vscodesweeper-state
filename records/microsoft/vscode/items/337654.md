# Issue #337654 — `window.title` setting has missing variables for autocomplete

[https://github.com/microsoft/vscode/issues/337654](https://github.com/microsoft/vscode/issues/337654)

## Summary

Confirmed on main: the settings.json autocomplete list for `window.title` is missing several valid variables (`${profileName}`, `${activeEditorLanguageId}`, `${focusedView}`), and an open PR already fixes exactly this, so this should stay open pending that PR merging.

## Change summary

Autocomplete suggestions for the `window.title` setting in settings.json don't include all documented template variables, e.g. `${profileName}`.

## Best solution

Land https://github.com/microsoft/vscode/pull/337655, which updates the completion list in extensions/configuration-editing/src/settingsDocumentHelper.ts to match the variables actually supported by WindowTitle (src/vs/workbench/browser/parts/titlebar/windowTitle.ts) and documented in workbench.contribution.ts.
