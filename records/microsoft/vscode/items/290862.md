# Issue #290862 — Open inline chat should be disabled when it cannot be opened

[https://github.com/microsoft/vscode/issues/290862](https://github.com/microsoft/vscode/issues/290862)

## Summary

Keep open: the current agent-status dropdown still snapshots menu actions without reacting to their availability changes. This matches the confirmed report in both directions: closing editors leaves Inline Chat enabled, and opening editors can leave it disabled.

## Change summary

Keep the title-bar dropdown's Open Inline Chat availability synchronized with editor eligibility without requiring a window reload.

## Best solution

Make the agent-status dropdown reflect current ChatTitleBarMenu action availability, including both enabled-to-disabled and disabled-to-enabled transitions. Preserve the existing inline-chat preconditions, primary Toggle Chat action, and keyboard behavior.
