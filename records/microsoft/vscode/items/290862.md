# Issue #290862 — Open inline chat should be disabled when it cannot be opened

[https://github.com/microsoft/vscode/issues/290862](https://github.com/microsoft/vscode/issues/290862)

## Summary

Still reproduces on main: the ChatTitleBarMenu dropdown never reacts to menu/context-key changes because `_chatTitleBarMenu.onDidChange` is not subscribed to in `agentTitleBarStatusWidget.ts`, unlike `_commandCenterMenu` which does listen.

## Change summary

The 'Open Inline Chat' item in the title bar dropdown stays enabled even when no editor is open, because the dropdown doesn't re-render on menu changes.

## Best solution

Add a `this._register(this._chatTitleBarMenu.onDidChange(() => { this._lastRenderState = undefined; this._render(); }))` listener in `agentTitleBarStatusWidget.ts`, mirroring the existing pattern for `_commandCenterMenu.onDidChange`.
