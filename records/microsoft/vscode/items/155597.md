# Issue #155597 — Allow users to choose which editor to use for editing variable binary data

[https://github.com/microsoft/vscode/issues/155597](https://github.com/microsoft/vscode/issues/155597)

## Summary

The requested choice remains missing: View Binary Data still explicitly installs and opens Hex Editor. Keep this accepted, well-supported request open; the related visualization investigation offers a direction, but its proposed API does not replace the hard-coded action.

## Change summary

Let users choose an alternative extension for inspecting and editing debug-variable binary data.

## Best solution

Provide supported extension-contributed memory viewers through the debug visualization work, with user choice among applicable providers rather than a mandatory Hex Editor path. Preserve discoverability without making the private debug-memory URI format a public contract.
