# Issue #327581 — Chats system model: Search bar with session title is redundant, session header needs simplification

[https://github.com/microsoft/vscode/issues/327581](https://github.com/microsoft/vscode/issues/327581)

## Summary

Keep open as team-authored Agents Window UX polish. Current source confirms the session title appears in both the titlebar session picker and session header, and the open tracker explicitly retains this simplification work.

## Change summary

Remove the redundant titlebar session search/picker and simplify the session header around one session title and a consolidated actions menu.

## Best solution

Retain one clear session identity in the session header, consolidate related actions into its dropdown, and rely on the searchable sessions sidebar for session discovery. Coordinate this with the broader session/chat model work tracked at https://github.com/microsoft/vscode/issues/327582.
