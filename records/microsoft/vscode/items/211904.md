# Issue #211904 — Enable Local Execution of Custom Models in GitHub VSCode Co-Pilot

[https://github.com/microsoft/vscode/issues/211904](https://github.com/microsoft/vscode/issues/211904)

## Summary

Implemented and shipped: VS Code supports local Ollama models in Copilot Chat through Bring Your Own Key and supports extension-contributed language model providers.

## Change summary

Allow Copilot Chat to use locally executed custom models such as Ollama, Llama, and Phi.

## Best solution

Use Manage Models to configure Ollama, or implement a provider through the finalized `vscode.lm.registerLanguageModelChatProvider` API; no additional core capability is required.
