# Issue #296890 — Agent mode: sending message mid-response sometimes forks session into two parallel agents, causing conflicting edits and JSONL corruption

[https://github.com/microsoft/vscode/issues/296890](https://github.com/microsoft/vscode/issues/296890)

## Summary

Keep open: the attached session evidence credibly confirms concurrent turns and malformed persisted JSONL, with conflicting edits and an unloadable session as concrete impact. The newer recovery issues and open serializer PR address consequences rather than the reported same-session concurrency race, so they do not supersede this re-reviewed issue.

## Change summary

Sending a steering message during an active agent response can leave both turns running, causing conflicting workspace edits and interleaved writes that corrupt the chat session.

## Best solution

Guarantee one active turn and one serialized persistence writer per chat session: a steering message must finish cancellation or otherwise isolate the prior turn before the replacement can execute tools, while persistence should remain valid even during cancellation and shutdown.
