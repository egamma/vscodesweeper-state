# Issue #202151 — Selecting while preview pane is selected as no effect.

[https://github.com/microsoft/vscode/issues/202151](https://github.com/microsoft/vscode/issues/202151)

## Summary

Still reproducible on main: the Save menu item in the menubar is enabled when a markdown preview webview is focused because its precondition only checks `ActiveEditorContext`, not whether the editor is readonly/webview. A maintainer confirmed the expected fix (disable Save for normal markdown previews). The `help wanted` label is appropriate — this is a valid, open contribution opportunity.

## Change summary

The File > Save menu item is enabled when a markdown preview pane is focused, but saving has no effect since the preview is a read-only webview.

## Best solution

Add a precondition to the Save menu item in the File menu (line ~692 of `src/vs/workbench/contrib/files/browser/fileActions.contribution.ts`) that excludes readonly or webview-only editors, similar to how the Open Editors context menu already gates Save behind `OpenEditorsReadonlyEditorContext`. The `help wanted` label is correctly set for a community contribution.
