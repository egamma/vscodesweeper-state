# Issue #202151 — Selecting while preview pane is selected as no effect.

[https://github.com/microsoft/vscode/issues/202151](https://github.com/microsoft/vscode/issues/202151)

## Summary

Keep open: the Save menu still enables for a normal Markdown preview even though that editor cannot save. The thread explicitly settles the intended behavior: disable Save for the preview rather than save its source document.

## Change summary

Disable the ineffective Save menu item while a normal Markdown preview is active.

## Best solution

Make File menu save enablement reflect whether the active preview supports saving, while preserving saving from editable source editors and Save All for other dirty documents.
