Related issue https://github.com/microsoft/vscode/issues/186511 overlaps but focuses on path creation capability rather than these specific UX improvements.

## Change summary

Improve the simple file dialog's folder creation UX: make the validation message hint that the folder can be created, and show the full multi-segment path in the confirmation prompt.

## Best solution
