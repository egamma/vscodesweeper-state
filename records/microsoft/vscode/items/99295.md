# Issue #99295 — Allow for "random access" undos

[https://github.com/microsoft/vscode/issues/99295](https://github.com/microsoft/vscode/issues/99295)

## Summary

Keep open: this team-authored Backlog request was explicitly split from the partial cross-file undo discussion, and current main still only undoes the closest stack element rather than safely traversing later non-conflicting edits.

## Change summary

Allow an older cross-file operation to be undone when newer edits do not overlap the ranges affected by that operation.

## Best solution

Define safe selective-undo semantics in the undo/redo service so a prior workspace edit can be reversed through later disjoint edits while preserving those edits, with overlapping or otherwise unsafe cases continuing to fail predictably.
