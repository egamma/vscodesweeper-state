## Summary

Real, already-diagnosed telemetry-classification bug: `ContactSupportError` still extends plain `Error` on current main, so it escapes as unhandled-rejection telemetry noise instead of being filtered like its sibling `GitHubLoginFailedError`. An open PR (#324982) already fixes it with `Fixes #324971`, so this should stay open until that PR lands rather than being closed now.

## Change summary

`ContactSupportError`, thrown by `_authShowWarnings` for expected Copilot auth failures, is not classified as `ErrorNoTelemetry`, so unobserved rejections are attributed as unhandled errors to the copilot-chat extension.

## Best solution
