# Issue #302261 — Terminal Issue: terminal.integrated.automationProfile.windows does not respect "env" object

[https://github.com/microsoft/vscode/issues/302261](https://github.com/microsoft/vscode/issues/302261)

## Summary

The current source drops profile environment variables when creating integrated debug terminals: it selects the automation profile's executable and arguments but omits its env. Keep this report open; neither the closed original report nor the related profile-design and Copilot issues establishes a valid duplicate close.

## Change summary

Integrated debug terminals should inherit the selected automation profile's environment, including the default profile's environment when no automation profile is configured.

## Best solution

Preserve the selected profile's environment through integrated debug-terminal creation, without changing debugger-request environment handling or unrelated extension terminal behavior. Validate the core terminal path independently of MSYS2 before checking the reporter's C++ configuration.
