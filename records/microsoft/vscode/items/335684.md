# Issue #335684 — Right clicking on background within a session should have "set background option"

[https://github.com/microsoft/vscode/issues/335684](https://github.com/microsoft/vscode/issues/335684)

## Summary

Current main already wires the same 'Set Background...' right-click context menu into the active session's chat view, not just the new-session composer — the capability the reporter asks for already exists.

## Change summary

Requests that right-clicking the empty background area of an existing (already-open) session's chat, not just the new-session composer, offer a 'Set Background' option.

## Best solution

No code change needed: chatView.ts (the widget used for an already-open session) registers the same context menu (`Menus.SessionChatBackgroundContext`) on its transcript background as newChatWidget.ts does for the new-session composer, gated only by color theme (not by session state). Close as already covering the request, and ask the reporter to confirm on the exact build/steps if they still see a gap.
