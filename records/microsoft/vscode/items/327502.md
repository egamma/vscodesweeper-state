# Issue #327502 — settings json file in modal overlay does not show change marker (black dot)

[https://github.com/microsoft/vscode/issues/327502](https://github.com/microsoft/vscode/issues/327502)

## Summary

The bug remains on current main: the modal editor's custom header displays the active editor label but never reflects its dirty state, so editing settings.json produces no unsaved-change marker.

## Change summary

Show the normal dirty-state marker when settings.json has unsaved changes while open in a modal editor.

## Best solution

Make the modal editor header track the active input's dirty-state changes and present an unsaved-change indicator consistent with ordinary editor tabs.
