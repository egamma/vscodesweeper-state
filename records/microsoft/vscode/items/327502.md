# Issue #327502 — settings json file in modal overlay does not show change marker (black dot)

[https://github.com/microsoft/vscode/issues/327502](https://github.com/microsoft/vscode/issues/327502)

## Summary

Confirmed in current source: modal editors hide the normal tab UI, while their replacement header never observes or renders the active editor's dirty state. The existing bug and workbench-tabs labels route this correctly.

## Change summary

Editing User Settings JSON in a modal overlay does not display the unsaved-change dot.

## Best solution

Make the modal editor header observe `EditorInput.onDidChangeDirty` and display the standard dirty indicator beside its resource label, clearing it after save or an active-editor change.
