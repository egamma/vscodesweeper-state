# Issue #267805 — Include a software statement in the dynamic client registration payload

[https://github.com/microsoft/vscode/issues/267805](https://github.com/microsoft/vscode/issues/267805)

## Summary

Keep open: current dynamic client registration does not obtain or include a software statement. CIMD support addresses a related authentication flow, but does not complete this team-authored request.

## Change summary

Include a publisher-issued software statement in VS Code's dynamic client registration payload, with official-build metadata and supporting vscode.dev endpoints.

## Best solution

Agree on the publisher-service and official-build metadata contract, including statement issuance and failure behavior, then carry that contract through initial registration and re-registration. Preserve the distinction between preventing accidental reuse by forks and authenticating a public client.
