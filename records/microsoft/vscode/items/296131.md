# Issue #296131 — [DEPRECATION FYI] Polyglot Notebooks extension - update recommendation to Jupyter extension

[https://github.com/microsoft/vscode/issues/296131](https://github.com/microsoft/vscode/issues/296131)

## Summary

The deprecated-extension recommendation remains in Jupyter's recommendation service, matching the attribution in the discussion. Transfer this team-authored cleanup request to microsoft/vscode-jupyter rather than closing it as extension-caused.

## Change summary

Remove Polyglot/.NET Interactive Notebooks recommendations and direct applicable notebook workflows toward Jupyter instead.

## Best solution

Jupyter should stop prompting users to install the deprecated Polyglot extension for C#, F#, and PowerShell notebooks. Preserve existing notebook compatibility, and avoid replacing the prompt with a recommendation to install Jupyter when Jupyter is already providing it.
