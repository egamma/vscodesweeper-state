# Issue #334767 — Markdown editor does not respect blinking cursor preference

[https://github.com/microsoft/vscode/issues/334767](https://github.com/microsoft/vscode/issues/334767)

## Summary

The Markdown editor still does not receive editor.cursorBlinking on current main, consistent with the reporter's steps and the commenter's diagnosis. Keep this open; no matching canonical issue or referencing fix PR was found.

## Change summary

The WYSIWYG Markdown editor blinks its caret despite editor.cursorBlinking being set to solid.

## Best solution

Honor the existing solid-cursor preference in the Markdown editor, both on opening a document and when the setting changes, without changing document editing or other cursor modes.
