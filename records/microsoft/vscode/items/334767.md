# Issue #334767 — Markdown editor does not respect blinking cursor preference

[https://github.com/microsoft/vscode/issues/334767](https://github.com/microsoft/vscode/issues/334767)

## Summary

Keep open: the discussion confirms the blinking caret, and current source still omits editor.cursorBlinking from both initial configuration and live updates. No matching canonical issue or open fixing PR was found.

## Change summary

The built-in WYSIWYG Markdown editor blinks its caret despite editor.cursorBlinking being set to solid.

## Best solution

Make the Markdown editing surface honor the existing document-scoped cursor-blinking preference on opening and after configuration changes, while preserving default caret behavior. Verify the actual rendered caret, not only delivery of configuration to the webview.
