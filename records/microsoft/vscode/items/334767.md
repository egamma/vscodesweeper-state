# Issue #334767 — Markdown editor does not respect blinking cursor preference

[https://github.com/microsoft/vscode/issues/334767](https://github.com/microsoft/vscode/issues/334767)

## Summary

Real gap, traced in source: the new WYSIWYG Markdown custom editor's contenteditable-based caret never reads `editor.cursorBlinking`, so users who disable blinking still see it blink there — routing to the markdown editor area rather than closing.

## Change summary

The new WYSIWYG Markdown editor ignores the `editor.cursorBlinking: solid` setting and always shows a blinking caret.

## Best solution

Wire `editor.cursorBlinking` (and likely `editor.cursorStyle`) through to the webview in extensions/markdown-language-features so the contenteditable caret respects 'solid' (e.g. via a CSS class toggling animation/caret-color), mirroring how the Monaco text editor honors this setting.
