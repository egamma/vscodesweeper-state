# Issue #334767 — Markdown editor does not respect blinking cursor preference

[https://github.com/microsoft/vscode/issues/334767](https://github.com/microsoft/vscode/issues/334767)

## Summary

Real, traceable bug: the new WYSIWYG Markdown editor's `InitialState`/webview wiring in `extensions/markdown-language-features` never reads or forwards `editor.cursorBlinking`, so the caret (rendered by the vendored `@vscode/markdown-editor` package) always animates regardless of the user's setting — matching the commenter's own diagnosis exactly.

## Change summary

The WYSIWYG Markdown editor's caret ignores the user's `editor.cursorBlinking: "solid"` setting and always blinks.

## Best solution

Thread `editor.cursorBlinking` (and likely other relevant cursor settings) from the extension host into the webview's `InitialState`/config so the vendored `@vscode/markdown-editor` caret respects it, similar to how `richLinksEnabled` is already passed in `extensions/markdown-language-features/src/preview/webviewInitialState.ts`. A community contributor (FiSSel72) has already found the cause and offered to submit a PR — best outcome is to let them land it.
