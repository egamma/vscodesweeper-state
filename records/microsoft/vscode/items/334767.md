# Issue #334767 — Markdown editor does not respect blinking cursor preference

[https://github.com/microsoft/vscode/issues/334767](https://github.com/microsoft/vscode/issues/334767)

## Summary

Confirmed gap on main: the markdown WYSIWYG editor's initial state and EditorView construction never forward `editor.cursorBlinking`, so its own caret always animates regardless of the setting. A contributor has already diagnosed the exact cause and offered a fix PR — route to the markdown area and let that land.

## Change summary

The WYSIWYG Markdown editor's caret ignores the `editor.cursorBlinking: "solid"` setting and always blinks.

## Best solution

Wire `editor.cursorBlinking` from configuration through `MarkdownEditorInitialState`/`encodeWebviewInitialState` into the `EditorView` options in markdown-editor-src/editor.ts, and have the `@vscode/markdown-editor` package's caret rendering respect it — ideally via the PR FiSSel72 has already offered to open.
