# Issue #327242 — Add expand/collapse events for folders in the built-in Explorer

[https://github.com/microsoft/vscode/issues/327242](https://github.com/microsoft/vscode/issues/327242)

## Summary

An earlier identical API request received an explicit maintainer decision not to expose Explorer navigation events and was closed as *extension-candidate. Existing recursive-collapse interactions cover the immediate workflow without adding API surface.

## Change summary

Expose built-in Explorer expansion and collapse events so extensions can implement automatic recursive folder collapse.

## Best solution

Keep the existing Alt+click recursive-collapse behavior and Ctrl+LeftArrow tree-collapse command rather than exposing built-in Explorer navigation events to extensions.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding niche Explorer-specific API and configuration surface conflicts with the lean-core and uniform-UI guardrails.
- **Evidence:** Values and guardrails: “The power lives in extensions,” while the default product should remain a lightweight, fast text editor with simple, uniform interactions.
