# Issue #127038 — Add "Show all results" button when hitting maxResults

[https://github.com/microsoft/vscode/issues/127038](https://github.com/microsoft/vscode/issues/127038)

## Summary

Still unimplemented on main. The search view currently shows only a warning message when limitHit is true — there is no button or link to rerun the search without the maxResults cap. The feature request remains valid and is complementary to the perf work tracked by #127621.

## Change summary

Add a 'Show all results' button/link in the search view when the maxResults limit is hit, allowing users to rerun the search without the limit.

## Best solution

Add a clickable action (button or link) in the search messages area (alongside the existing limitHit warning in `searchView.ts`) that reruns the current query with `maxResults` unset. The perf concern in https://github.com/microsoft/vscode/issues/127621 should be addressed first or in parallel so that removing the limit doesn't cause UI freezes from large result sets hitting `setChildren`.
