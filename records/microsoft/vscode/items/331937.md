# Issue #331937 — Multi‑line JSX attributes are not vertically aligned

[https://github.com/microsoft/vscode/issues/331937](https://github.com/microsoft/vscode/issues/331937)

## Summary

Keep open: HTML already has attribute-alignment options, but those do not cover JSX formatting or syntax-aware Tab alignment. A maintainer explicitly consolidated the earlier formatting report into this broader issue; no verified canonical or fixing commit supersedes it.

## Change summary
