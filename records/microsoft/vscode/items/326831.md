# Issue #326831 — Code formatting shouldn't happen during merge conflict resolution

[https://github.com/microsoft/vscode/issues/326831](https://github.com/microsoft/vscode/issues/326831)

## Summary

The exact request was previously declined because only the formatter can reliably decide whether conflict markers or other invalid syntax should prevent formatting. Current source still preserves that boundary, so the established *out-of-scope decision remains applicable.

## Change summary

Suppress format-on-save while a file contains unresolved merge conflicts.

## Best solution

Formatter providers should detect unsupported conflict markers or invalid syntax and return no edits; clang-format-specific behavior belongs in its formatter integration rather than a Git-aware exception in VS Code's generic save pipeline.

  > Thanks for revisiting this. As discussed in https://github.com/microsoft/vscode/issues/62862, the formatter is best placed to recognize conflict markers or other invalid syntax and return no edits. The current source still follows that boundary, so this remains out of scope for the core save pipeline.
