[https://github.com/microsoft/vscode/issues/235427](https://github.com/microsoft/vscode/issues/235427)

Keep open: the recording demonstrates toolbar actions changing or disappearing as focus moves between three visible notebook-backed editors. Toolbar rendering has changed since the report, but no verified fix covers this sequence; the recording provides enough detail to retest without requesting more information.

## Change summary

Notebook, interactive-window, and native-REPL toolbar actions disappear or change unexpectedly when focus moves between adjacent editor groups.

## Best solution

Make each visible notebook-backed editor retain the toolbar actions appropriate to its own document and kernel when another editor gains focus. First reproduce the recorded three-pane sequence and distinguish core menu/layout behavior from Jupyter-contributed action visibility.

- **Trace:**
