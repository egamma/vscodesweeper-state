## Plan brief

- **Likely files:** `extensions/git/src/repository.ts`, `extensions/git/src/commands.ts`, `extensions/git/src/watch.ts`
- **Validation:** In a Remote-WSL window on a controlled Git repository under /mnt/c, with git.autorefresh enabled and no status-limit warning, edit a tracked file and create a nonignored file both from the editor and from bash. Keep the window focused and allow the refresh debounce to settle; Source Control must match git status --short without staging or reloading. Capture Git trace logs and separately test Git: Refresh to distinguish automatic refresh failure from status publication failure.
- **Behavior:**

  > The reporter observes a stale Source Control changes list in a WSL2 workspace under /mnt/c/fvi/cfa even though Explorer reflects new files. Staging and reloading reveals the changes, and the reporter confirmed persistence on 1.127.0. With automatic Git refresh enabled and no documented suppression condition, tracked edits and nonignored new files should appear in Source Control without staging or reloading. Acceptance compares the changes list with git status --short after editor and shell changes in a focused Remote-WSL window.
- **Trace:**

  > Repository construction in extensions/git/src/repository.ts combines working-tree watcher events and DotGitWatcher events before invoking Repository.onFileChange. That method checks autorefresh, repository size, and running operations; its scheduled status update also waits for window focus. FileEventLogger provides event-level diagnostics, and git.refresh in extensions/git/src/commands.ts provides a separate manual refresh path. The reporter's Explorer confirmation narrows the observable defect to SCM but does not prove where Git's event-to-status pipeline fails. Diagnosis must first reproduce on a current build and inspect settings, Git event logs, status commands, and manual refresh behavior. Preserve intentional refresh suppression and debounce behavior; do not assume a WSL-wide watcher defect or change Remote-WSL ownership without evidence.
