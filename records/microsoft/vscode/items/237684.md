# Issue #237684 — VSCode claims no JSON formatter installed, but 5 seconds later formats the document just fine

[https://github.com/microsoft/vscode/issues/237684](https://github.com/microsoft/vscode/issues/237684)

## Summary

Still reproduces on main: the fallback format action in formatActionsNone.ts fires its 'no formatter installed' message whenever the extension host hasn't finished activating, because its precondition only checks hasDocumentFormattingProvider (which is false until extensions register). Team-authored, no fix found — keeping open.

## Change summary

Format Document shows 'no formatter installed' for JSON when invoked shortly after startup, before the extension host finishes activating and registering formatters.

## Best solution

The fallback action in `src/vs/workbench/contrib/format/browser/formatActionsNone.ts` should either wait briefly for extension activation before declaring no formatter exists, or check whether the extension host is still starting and show a different message (e.g. 'Extensions are still loading, please try again shortly') instead of the misleading 'no formatter installed' prompt.
