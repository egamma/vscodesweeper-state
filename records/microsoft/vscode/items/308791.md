# Issue #308791 — chat.pluginLocations: Support parent directory resolution to discover all plugins under a common root

[https://github.com/microsoft/vscode/issues/308791](https://github.com/microsoft/vscode/issues/308791)

## Summary

A distinct capability gap remains: current main resolves every `chat.pluginLocations` key as one plugin root and does not enumerate child directories. No older canonical issue owns the same request, so this should remain open and be routed to the chat plugin area for product discussion.

## Change summary

Allow one `chat.pluginLocations` entry to discover multiple plugins beneath a shared parent directory.

## Best solution

Define safe parent-directory semantics for `chat.pluginLocations`, likely shallow child discovery while preserving direct-plugin entries, workspace trust, symlink behavior, and bounded filesystem traversal.

- **setting contract:** `src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts` documents each `chat.pluginLocations` key as a path that points directly to a plugin folder, confirming that parent-directory discovery is not an existing capability.
