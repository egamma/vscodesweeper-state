[https://github.com/microsoft/vscode/issues/298976](https://github.com/microsoft/vscode/issues/298976)

## Summary

Keep open: Explorer auto-reveal already supports ordinary file diffs, but it does not select the focused constituent file of a multi-file diff. The Copilot review scenario may expose that remaining gap; no verified canonical or fixing commit was found.

## Change summary

Automatically select the relevant workspace file in Explorer when focus moves into its diff during Copilot change review.

Extend Explorer auto-reveal to follow the focused workspace file within multi-file change review, honoring explorer.autoReveal and its exclusions without stealing keyboard focus. Confirm whether the reporter means a single-file diff or the multi-file review surface before settling the scope.
