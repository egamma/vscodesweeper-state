# Issue #149091 — SCM - Sort by path does not work as expected for submodules

[https://github.com/microsoft/vscode/issues/149091](https://github.com/microsoft/vscode/issues/149091)

## Summary

The repository path-sort defect remains in current source: a file-oriented comparator places sibling repositories before another repository's descendants. Keep this accepted SCM bug open; the diagnosis is bounded enough for implementation.

## Change summary

Sort SCM repositories by their complete directory paths so nested submodules remain grouped with their parent repository.

## Best solution

Make SCM repository path sorting honor complete directory components, producing the hierarchy-like order in the report. Preserve discovery-time sorting, repository-name ordering, and the existing sorting of changed files.
