# Issue #43365 — [css] propose ids used in other selectors

[https://github.com/microsoft/vscode/issues/43365](https://github.com/microsoft/vscode/issues/43365)

## Summary

The requested completion remains missing: the current CSS language service collects reusable class selectors from the active stylesheet but explicitly omits ID selectors. Keep this canonical issue open and classify it as upstream work in the CSS language service.

## Change summary

Offer ID selectors already declared elsewhere in the same CSS file as completion suggestions, matching existing class-selector completion.

## Best solution

Extend selector completion in microsoft/vscode-css-languageservice to collect unique `#id` selectors alongside `.class` selectors, add focused completion tests, and then consume the updated language-service version in VS Code.
