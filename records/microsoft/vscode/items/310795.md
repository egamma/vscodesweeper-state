# Issue #310795 — Options label shows feature enabled and unchecked

[https://github.com/microsoft/vscode/issues/310795](https://github.com/microsoft/vscode/issues/310795)

## Summary

A team member has acknowledged this as a confusing aspect of the Settings editor UX and requested additional triage — keeping open as under-discussion.

## Change summary

Settings editor checkbox labels containing the word 'Enabled' (from setting key names like `chat.unifiedAgentsBar.enabled`) are confusing when unchecked, making it appear the feature is enabled when it is not.

## Best solution

Consider reformatting how boolean settings with 'enabled' in the key name are displayed in the Settings editor — e.g. drop the trailing 'Enabled' suffix from the rendered label and let the checkbox alone convey the on/off state, or add a visual cue distinguishing the setting name from the effective state.
