# Issue #323072 — Problems panel filter status chip blocks input area and makes debugging hard in Chinese locale

[https://github.com/microsoft/vscode/issues/323072](https://github.com/microsoft/vscode/issues/323072)

## Summary

The defect remains on current main and is confirmed in both Problems and Debug Console. The shared filter widget bases its compact state on the full panel width even when its title-bar container is only 150–200px wide, allowing long localized status text to cover the input.

## Change summary

Keep the Problems and Debug Console filter input usable when localized result-count text is wider than the available title-bar control.

## Best solution

Make the shared FilterWidget respond to its actual rendered width so localized status text cannot cover or consume the filter input, while preserving the count badge when sufficient space exists. The correction belongs in the shared view filter implementation and styling so Problems, Debug Console, and other consumers remain consistent.
