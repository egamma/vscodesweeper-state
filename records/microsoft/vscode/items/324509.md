# Issue #324509 — Background todo agent experiment silently disables `manage_todo_list`, breaking custom instructions and workflows

[https://github.com/microsoft/vscode/issues/324509](https://github.com/microsoft/vscode/issues/324509)

## Summary

Keep open for a product decision on transparent background todo management and compatibility with existing instructions. Current source deliberately removes the tool under the experiment; explicit tool references and the setting override provide partial workarounds, not coverage of the full request.

## Change summary

Make experimental background todo management transparent and preserve a predictable workflow for instructions referencing manage_todo_list.

## Best solution

Make effective todo ownership discoverable to users and understandable to the main agent, with a supported way to retain direct tool use. The Copilot agent owners should settle whether this requires explicit opt-in or whether clear disclosure and compatibility behavior suffice.
