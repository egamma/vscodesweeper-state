# Issue #343919 — Copilot Chat enumerates the entire workspace at startup to find `.copilotignore` in the root

[https://github.com/microsoft/vscode/issues/343919](https://github.com/microsoft/vscode/issues/343919)

## Summary

The unnecessary workspace enumeration remains in current source: discovering a root-level .copilotignore still invokes workspace file search. The reporter confirmed the problem on 1.143.1, and the related agent-discovery and external-ingest reports do not resolve this distinct caller.

## Change summary

Avoid recursively enumerating workspace contents to discover each workspace root's .copilotignore during Copilot Chat initialization.

## Best solution

Make root-level ignore-file discovery independent of workspace tree size while preserving ignore-rule enforcement, workspace-folder lifecycle behavior, and handling of missing versus unreadable files. Keep the separate Git repository discovery and external-ingest scans outside this bounded fix.
