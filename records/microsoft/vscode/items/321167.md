# Issue #321167 — Copilot Autopilot - Action Upon Completion

[https://github.com/microsoft/vscode/issues/321167](https://github.com/microsoft/vscode/issues/321167)

## Summary

Current settings already provide completion sounds and OS notifications, but configurable completion actions such as running a script remain unsupported. Keep this open for a product and security decision on broader completion hooks.

## Change summary

Allow Copilot Autopilot to trigger one or more configurable actions when a session completes.

## Best solution

Preserve `accessibility.signals.chatResponseReceived` and `chat.notifyWindowOnResponseReceived` for notifications, then evaluate a safe agent-completion hook for custom commands rather than adding separate media-control options.
