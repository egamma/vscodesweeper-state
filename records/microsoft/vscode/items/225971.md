# Issue #225971 — Symbol Not Highlighted After Navigation

[https://github.com/microsoft/vscode/issues/225971](https://github.com/microsoft/vscode/issues/225971)

## Summary

Valid feature request: after Go to Definition (F12) navigates to a symbol, word highlighting should trigger automatically so F7 (Go to Next Symbol Highlight) works immediately. The word highlighter's `_onPositionChanged` handler does respond to API-sourced cursor changes, but the timing or editor-switch flow after Go to Definition may not trigger it reliably. No duplicate found; low traction but reasonable ask. Already routed with area labels and in Backlog.

## Change summary

After using Go to Definition (F12), the symbol at the destination is not automatically highlighted, so Go to Next Symbol Highlight (F7) does nothing until the user manually triggers highlighting.
