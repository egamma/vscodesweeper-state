# Issue #214741 — VSCode disappear from candidate list to open text file in Linux

[https://github.com/microsoft/vscode/issues/214741](https://github.com/microsoft/vscode/issues/214741)

## Summary

Keep open for a decision on restoring plain-text discovery in Linux application choosers. Current packaging still omits text/plain, and the maintainer explicitly left that question open while declining directory association.

## Change summary

Restore VS Code as an application candidate for plain-text and source files recognized as text/plain on Linux.

## Best solution

Support plain-text application discovery without making VS Code the default handler or restoring inode/directory. The Linux integration owner should decide whether advertising text/plain can meet that compatibility requirement.
