# Issue #313546 — Support reasoning effort configuration in custom .agent.md files

[https://github.com/microsoft/vscode/issues/313546](https://github.com/microsoft/vscode/issues/313546)

## Summary

Valid, actively-discussed feature request with a team member comment seeking implementation guidance. Reasoning effort is not yet supported in .agent.md frontmatter on current main — the prompt file parser only handles `model` as a frontmatter attribute, not reasoning effort. The community PR #326516 was closed because the team is migrating to the Copilot SDK, but the underlying request remains unaddressed. Keeping open as On Deck with active team interest.

## Change summary

Allow .agent.md files to specify reasoning effort per model so custom agents can control cost/quality tradeoffs.

## Best solution

Add a `reasoning-effort` (or similar) frontmatter attribute to the prompt file parser in `src/vs/workbench/contrib/chat/common/promptSyntax/promptFileParser.ts` and wire it through to the model selection pipeline. The syntax should support per-model effort levels since `model` already accepts a list. The implementation path depends on the Copilot SDK migration — the team should decide whether this belongs in the SDK's agent host configuration or in the VS Code prompt file layer.
