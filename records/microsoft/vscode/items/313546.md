# Issue #313546 — Support reasoning effort configuration in custom .agent.md files

[https://github.com/microsoft/vscode/issues/313546](https://github.com/microsoft/vscode/issues/313546)

## Summary

Valid feature request with community traction (14 upvotes). No implementation exists on main — the community PR #326516 was closed without merging, and the prompt frontmatter parser has no reasoning-effort attribute. Active maintainer discussion (aeschli asked for design input). Stays open.

## Change summary

Allow .agent.md files to specify a reasoning effort level (e.g. low/medium/high) per model in the frontmatter, so custom agents can trade off quality vs. latency and cost.

## Best solution

Add a `reasoning-effort` (or similarly named) attribute to the prompt frontmatter schema in `src/vs/workbench/contrib/chat/common/promptSyntax/languageProviders/promptFileAttributes.ts`, plumbed through the prompt parser and into the language-model request. The per-model list syntax proposed in the discussion (comment 4/6) is worth considering since `model` already supports lists. Maintainer design decision is needed on naming and per-model-vs-global scope before implementation.
