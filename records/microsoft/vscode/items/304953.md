# Issue #304953 — The default theme color change in Visual Studio Code code is very ugly and terrible

[https://github.com/microsoft/vscode/issues/304953](https://github.com/microsoft/vscode/issues/304953)

## Summary

Keep open for a focused theme-default and readability decision: Dark Modern remains available, but manually restoring it does not address the unwanted upgrade experience or the reported loss of meaningful color distinctions. The older refresh discussion overlaps substantially, but does not clearly absorb the distinct Explorer warning-versus-modified-file complaint.

## Change summary

Preserve the familiar default-theme experience across upgrades and improve the refreshed theme's readability and status-color distinctions.

## Best solution

Preserve existing users' theme choices and retain an easily discoverable Dark Modern option. Resolve the refreshed theme's ambiguous status colors, with a maintainer deciding whether its palette should remain the default for new installations.
