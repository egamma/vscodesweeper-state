# Issue #327986 — Inline suggestions suppress the suggest widget entirely: no completion request is ever sent while typing

[https://github.com/microsoft/vscode/issues/327986](https://github.com/microsoft/vscode/issues/327986)

## Summary

Verified duplicate: the open canonical issue tracks the intentional 1.121+ behavior that suppresses automatic suggest-widget requests while inline completions are visible.

## Change summary

Allow automatic IntelliSense completion requests and the suggest widget while Copilot inline suggestions are active.

## Best solution

Consolidate this evidence on https://github.com/microsoft/vscode/issues/317863. Users preferring the previous behavior can set `editor.quickSuggestions.other` to `on` while the team evaluates the default there.
