# Issue #178107 — editor.actions.removeBrackets doesn't play well with Undo stack

[https://github.com/microsoft/vscode/issues/178107](https://github.com/microsoft/vscode/issues/178107)

## Summary

Keep open: the reporter isolated the extra Undo operation to after-delay Auto Save, but the current source does not establish which save-time edit causes it. Related undo reports do not conclusively own this bracket-removal case, and no concrete fixing commit was identified.

## Change summary

Removing a matching bracket pair requires two Undo operations to restore the brackets when after-delay Auto Save is enabled.

## Best solution

Establish which save participant adds the intervening undo entry, then make bracket removal and automatic saving cooperate so restoring the bracket pair does not require an apparently ineffective Undo. Preserve intentional save-time transformations and their undo behavior.
