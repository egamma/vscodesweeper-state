## Summary

Well-diagnosed, still-open crash: a collaborator already symbolized the dumps, and a second reporter (24 crashes in two days on 1.133 stable) traced the trigger to VS Code's own unresponsive-extension-host CPU profiler, which is confirmed present and unchanged on current main.

## Change summary

The Node utility/extension host crashes deterministically (0xC0000005) at the same address across many dumps, apparently triggered by VS Code's auto-profiling of an unresponsive extension host during Copilot agent runs.
