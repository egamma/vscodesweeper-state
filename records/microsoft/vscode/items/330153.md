## Summary

Multiple independent users (including a collaborator's symbolized stack) confirm identical-address crashes in the utility/extension-host process, and the trigger traces to real, current VS Code code (ExtensionsAutoProfiler forcibly attaching an inspector/WebSocket when the extension host is flagged unresponsive) — this is a genuine, high-severity, actively-worsening crash that needs core attention, not a close.

## Change summary

VS Code repeatedly crashes with a 0xC0000005 access violation in the Node utility/extension-host process while running the Copilot agent, at an identical fault address across many independent reports.

## Best solution
