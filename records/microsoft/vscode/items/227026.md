The missing-search-provider path still waits indefinitely in current source, leaving the file picker loading until cancellation or provider registration. Keep this team-authored issue open; the closely related findFiles2 report is newer and cannot replace it under the re-review rules.

## Change summary

File picker searches never finish when a workspace filesystem has no corresponding file search provider.

## Best solution

Ensure file picker searches reach a defined terminal outcome when no search provider is available, while preserving legitimate delayed provider registration and cancellation. Coordinate the shared search-service behavior with https://github.com/microsoft/vscode/issues/314285.
