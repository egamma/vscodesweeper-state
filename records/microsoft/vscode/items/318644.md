## Summary

Verified duplicate: the open Backlog issue https://github.com/microsoft/vscode/issues/210637 already tracks region section headers across HTML, CSS, and embedded Vue languages.

## Change summary

Recognize embedded-language #region markers as minimap section headers in Vue, Svelte, Astro, and HTML files.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/210637 and update section-header discovery to select folding markers using each line's embedded language rather than the document's outer language.
