# Issue #333685 — No affordance to scroll tab list

[https://github.com/microsoft/vscode/issues/333685](https://github.com/microsoft/vscode/issues/333685)

## Summary

Legitimate, freshly-filed gap in the new Agents tab well: the tab strip is horizontally scrollable in code but the scrollbar is configured with `ScrollbarVisibility.Hidden`, so there's no visible affordance (arrows, dropdown, or visible scrollbar) once tabs overflow — this stays open as a real UX gap in an actively developed area.

## Change summary

The Agents window's chat tab well has no visible way to scroll to or pick overflowed tabs when many are open.

## Best solution

Add a visible overflow affordance to `ChatCompositeBar` (e.g. a dropdown/list picker for hidden tabs, or switch the scrollbar visibility from Hidden to Auto with clickable end arrows) in src/vs/sessions/browser/parts/chatCompositeBar.ts, especially since subagent sessions aren't otherwise listed elsewhere.
