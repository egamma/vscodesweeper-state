# Issue #274428 — Chat response: revealing the last output sometimes stuck

[https://github.com/microsoft/vscode/issues/274428](https://github.com/microsoft/vscode/issues/274428)

## Summary

The reported code-block layout race is addressed on current main: chat rows are now measured by a ResizeObserver, and height changes preserve bottom-anchored autoscroll. This can be closed as completed.

## Change summary

Chat sometimes stopped following a streaming response when an embedded code editor changed the response row's height.

## Best solution

Keep the row-level measurement and persisted-autoscroll behavior introduced by commit 691296005d662a60579fbfb68a37e4f77cc3f013; it removes the out-of-sync per-content height notifications implicated in the report.
