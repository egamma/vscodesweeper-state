# Issue #274428 — Chat response: revealing the last output sometimes stuck

[https://github.com/microsoft/vscode/issues/274428](https://github.com/microsoft/vscode/issues/274428)

## Summary

The code-block layout race that could strand the final response height was fixed on main: height changes received during rendering are now deferred and reliably delivered to the chat tree, whose update path preserves bottom scrolling.

## Change summary

Keep a streaming chat response scrolled to its latest output when an embedded code editor changes the response row height.

## Best solution

Retain the fix in commit a816e1a9ae176eba4e3972e9884bed39c3f269d5, which prevents code-block height notifications from being swallowed during render and includes regression coverage for the stuck/clipped response path.
