# Issue #301905 — Support Updating from a Self-Managed/Internal Update Source

[https://github.com/microsoft/vscode/issues/301905](https://github.com/microsoft/vscode/issues/301905)

## Summary

Legitimate enterprise feature request. VS Code currently supports a build-time `updateUrl` in product.json but has no runtime-configurable setting or policy to redirect update checks to an internal server. The gap is real for air-gapped/restricted environments. The community process noted insufficient upvotes (7/20), but the issue is in the Backlog milestone and represents a valid unmet need.

## Change summary

Allow organizations to configure VS Code to fetch updates from a self-managed internal server rather than only from the public Microsoft update service.

## Best solution

Introduce an `update.url` setting (or policy-only configuration) that overrides the product.json `updateUrl` at runtime, enabling enterprise admins to point VS Code at an internal update mirror without rebuilding the product. The existing `update.mode` policy pattern in `src/vs/platform/update/common/update.config.contribution.ts` provides the model for adding a policy-backed URL override.
