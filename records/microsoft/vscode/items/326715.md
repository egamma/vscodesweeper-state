# Issue #326715 — Copilot Chat: Confusing error when BYOK utility model not configured

[https://github.com/microsoft/vscode/issues/326715](https://github.com/microsoft/vscode/issues/326715)

## Summary

Valid polish request: the error thrown at endpointProviderImpl.ts:196 when a BYOK model is selected without a utility model configuration is not actionable — it doesn't mention the settings the user needs to configure. The existing ByokUtilityModelNotificationContribution only fires for air-gapped (signed-out) scenarios, so signed-in BYOK users hit the raw error without guidance.

## Change summary

The error message shown when a BYOK utility model is not configured lacks actionable guidance about which settings to change.

## Best solution

Improve the error message in `extensions/copilot/src/extension/prompt/vscode-node/endpointProviderImpl.ts` (line 196) to reference the `chat.byokUtilityModelDefault` and `chat.utilitySmallModel` settings, and consider extending the `ByokUtilityModelNotificationContribution` to also fire for signed-in BYOK users who haven't configured utility models.
