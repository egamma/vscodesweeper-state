# Issue #149323 — Support for updatable/async menus and submenus

[https://github.com/microsoft/vscode/issues/149323](https://github.com/microsoft/vscode/issues/149323)

## Summary

The upstream Electron issue (electron/electron#528) was closed as wontfix in Jan 2025, but the need for async/updatable menus in VS Code remains valid. The issue is team-authored and in the Backlog with 19 upvotes; alternative approaches (e.g. #238095) may still deliver the effect.

## Change summary

Support dynamically populating or updating native context menu submenus (e.g. Refactor, Source Action) while they are displayed, so users can discover available code actions without a separate dialog.

## Best solution

Since the Electron upstream path is dead, explore alternative UX approaches — such as the custom menu surface hinted at in #238095, or a non-native overlay submenu that can load items asynchronously. The menus area owner should evaluate whether a custom renderer-side menu (bypassing Electron's native menu for these specific submenus) is viable.
