# Issue #149323 — Support for updatable/async menus and submenus

[https://github.com/microsoft/vscode/issues/149323](https://github.com/microsoft/vscode/issues/149323)

## Summary

Keep open: Refactor and Source Action still require invocation rather than exposing asynchronously populated submenus on hover. Electron's decision not to implement live menu updates does not retire this accepted, team-authored request or establish that an alternative solves it.

## Change summary

Expose asynchronously discovered refactorings and source actions in submenus that populate while the parent context menu remains open.

## Best solution

Provide discoverable, asynchronously populated action choices alongside the editor context menu without blocking menu display. Native menus need upstream support; a custom-menu alternative needs an explicit VS Code product decision and adoption on the refactor/source-action path.
