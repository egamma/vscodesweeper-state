# Issue #312638 — Installing plugin from custom marketplace fails as local git clone isn't updated

[https://github.com/microsoft/vscode/issues/312638](https://github.com/microsoft/vscode/issues/312638)

## Summary

The stale-clone installation failure remains traceable on current main: public marketplace discovery reads remote metadata, but installing a relative-path plugin reuses the existing clone without requesting a refresh. Keep this correctly routed issue open; the September maintainer reproduction confirms the same observable failure.

## Change summary

Installing a newly published marketplace plugin fails because its source directory is absent from an outdated cached repository.

## Best solution

Ensure installation uses repository contents consistent with the discovered plugin before reporting its source directory missing. Preserve local-marketplace and commit-pinned behavior, cancellation, and meaningful errors for genuinely absent directories.
