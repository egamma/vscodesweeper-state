# Issue #19621 — Copy line does not work properly with multi-cursor

[https://github.com/microsoft/vscode/issues/19621](https://github.com/microsoft/vscode/issues/19621)

## Summary

Keep open: current main partially supports copying lines from multiple empty cursors, but it still does not provide the requested line-wise paste behavior. An open PR addresses the remaining behavior, so the issue should remain open pending that work.

## Change summary

Make copying with multiple empty cursors collect each cursor's line and paste those lines using the same line-wise semantics as a single empty selection.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/286895, ensuring it covers both line-wise insertion and single-cursor paste without extra blank lines. Keep this older issue as the umbrella until the remaining cases in https://github.com/microsoft/vscode/issues/286892 and https://github.com/microsoft/vscode/issues/324290 are resolved.
