# Issue #281417 — Feature Request From Claude: Add replace_file_contents tool for Copilot Chat agent mode

[https://github.com/microsoft/vscode/issues/281417](https://github.com/microsoft/vscode/issues/281417)

## Summary

Keep open under discussion: the current Claude tool selection still lacks a direct whole-file replacement operation that avoids resending the original contents. The maintainer rejected the proposed tool set as-is but expressed interest in more efficient large-region replacements; the linked PR closed without merging.

## Change summary

Enable efficient whole-file or large-region rewrites through Copilot's tracked editing tools instead of terminal-based file replacement.

## Best solution

Provide a model-effective way to perform large rewrites within the existing tracked-edit experience, respecting the maintainer's concerns about tool overhead and line-number reliability. Decide the model-facing replacement contract before implementing another tool or extending an existing one.

- **Behavior:**

  > Large document rewrites and refactorings should remain within Copilot's tracked editing experience rather than requiring terminal replacement or deletion followed by recreation. Evaluate the resulting model workflow rather than treating tool availability alone as success.
- **Trace:**
