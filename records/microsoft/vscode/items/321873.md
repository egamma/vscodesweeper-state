# Issue #321873 — Internal Stop hook forces agent to continue indefinitely ("Keep working autonomously") — no setting to disable

[https://github.com/microsoft/vscode/issues/321873](https://github.com/microsoft/vscode/issues/321873)

## Summary

The unbounded seven-call loop is mitigated on current main, but the central request remains valid: Autopilot still has an internal continuation hook without a public control, and Advanced Autopilot can override a model's text-only conclusion. Keep this open for a product decision about Autopilot completion semantics and user control.

## Change summary

Provide control over the internal Autopilot stop check so completed conversational requests are not forced through unnecessary continuation calls.

## Best solution

Define an explicit Autopilot completion contract for conversational requests: either honor a substantive final response, provide a user-visible way to opt out of automatic continuation, or clearly require switching to a non-Autopilot permission level. Preserve bounded safeguards so a mistaken completion decision cannot generate repeated credit-consuming calls.
