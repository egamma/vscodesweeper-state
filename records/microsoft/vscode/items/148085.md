# Issue #148085 — Add a TabGroups.move() method

[https://github.com/microsoft/vscode/issues/148085](https://github.com/microsoft/vscode/issues/148085)

## Summary

Keep open while the directly related implementation in https://github.com/microsoft/vscode/pull/201885 remains under review. Current main contains the internal tab-moving operation but still does not expose it through the extension API.

## Change summary

Expose a TabGroups API for moving any tab to a chosen editor group and position without first activating it.

## Best solution

Review, test, and either land or close https://github.com/microsoft/vscode/pull/201885; landing it as a proposed API would expose the existing main-thread move operation to extensions, after which the API can follow the normal finalization process.
