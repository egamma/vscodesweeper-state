The initial implementation landed in commit baf257dafb1 (PR #169831), exposing the `comments/comment/editorActions` menu, but the API remains in `proposed` status (`contribCommentEditorActionsMenu`) and has not been finalized. ## Change summary

Allow extensions to set the body of the new comment editor and access the comment editor via a new menu contribution point.
