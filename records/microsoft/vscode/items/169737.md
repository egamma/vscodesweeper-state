# Issue #169737 — Allow extensions to set the body of the new comment editor

[https://github.com/microsoft/vscode/issues/169737](https://github.com/microsoft/vscode/issues/169737)

## Summary

Keep this API proposal open: current main still gates comment-editor actions behind a proposed API, and the latest maintainer feedback on its public shape remains unresolved. The api-proposal label explicitly protects this tracking issue from closure based on the merged implementation.

## Change summary

Allow extensions to append suggestion text to an in-progress comment through an action that leaves the comment editor open.

## Best solution

The API owners should settle and finalize the non-submitting comment-action contribution contract, accounting for the recorded preference for a special group in an existing menu rather than a separate menu. Preserve the draft and keep the editor open when an extension appends a suggestion.
