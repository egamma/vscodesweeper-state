# Issue #329521 — Internal reasoning text rendered below "Finished with N steps" in agent mode

[https://github.com/microsoft/vscode/issues/329521](https://github.com/microsoft/vscode/issues/329521)

## Summary

The model is provided by a third-party BYOK extension (vizards.deepseek-v4-for-copilot), not by microsoft/vscode or the Copilot Chat extension code in this repo — core's chat API cleanly separates reasoning from visible text via `vscode.LanguageModelThinkingPart`, so if reasoning leaks as plain visible text it means that extension isn't emitting a proper thinking part for DeepSeek's reasoning_content stream.

## Change summary

Internal model reasoning/thinking text is rendered as visible chat output directly under the "Finished with N steps" section, one word per line.

## Best solution

Point the reporter to the vizards.deepseek-v4-for-copilot extension's own repository — its language model provider needs to wrap DeepSeek's reasoning/thinking stream chunks in `vscode.LanguageModelThinkingPart` (see src/vs/workbench/api/common/extHostTypes.ts LanguageModelThinkingPart, and extensions/copilot/src/platform/thinking/common/thinkingUtils.ts for how core's own OpenAI-compatible BYOK path extracts reasoning_content/cot_summary/etc.) instead of yielding it as plain `LanguageModelTextPart` text.
