# Issue #316790 — Random chartacter on each command

[https://github.com/microsoft/vscode/issues/316790](https://github.com/microsoft/vscode/issues/316790)

## Summary

Verified duplicate of #320947: Copilot Chat's terminal execute strategies send Ctrl+U (\x15) to clear pending input before running commands, but PowerShell on Windows echoes this as a visible `^U` rather than interpreting it as a kill-line control character — causing command failures. Issue #320947 already tracks this with proper triage labels.

## Change summary

Copilot Chat agent mode prepends a visible `^U` character to terminal commands on Windows PowerShell, causing commands to fail.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/320947, which tracks the same `^U` echoing problem with proper `terminal-shell-pwsh` labeling. The fix should make the execute strategies use a PowerShell-appropriate line-clear mechanism (e.g. `[Console]::ReadKey()` suppression or `Escape` key) instead of Unix Ctrl+U when the shell is PowerShell.

## Evidence

- **root cause in source:** Both `noneExecuteStrategy.ts` (line 84) and `basicExecuteStrategy.ts` (line 207) send `\x15` (Ctrl+U) to clear pending input. Ctrl+U is a Unix readline kill-line shortcut; PowerShell does not interpret it and echoes it as `^U`.
- **canonical issue:** https://github.com/microsoft/vscode/issues/320947 is open, labeled `terminal-shell-pwsh`, and describes the identical symptom: Copilot Chat adds extra `^U` characters to terminal commands on Windows PowerShell, reliably after certain command sequences.
