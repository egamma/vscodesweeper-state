# Issue #336202 — Support searching across all customization types

[https://github.com/microsoft/vscode/issues/336202](https://github.com/microsoft/vscode/issues/336202)

## Summary

Brand-new feature request (filed hours ago, 0 reactions) asking for a unified search across the Chat Customizations editor's tabs. Checkout confirms each tab (agents, MCP, plugins, tools) currently has its own independent InputBox-based search with no shared/global entry point, so the gap is real — but it's too fresh to judge community traction or maintainer intent yet.

## Change summary

Add a single search box in the Customizations editor that searches across all customization types (skills, MCP servers, plugins, tools) instead of requiring per-tab search.

## Best solution

If pursued, likely lives in aiCustomizationManagementEditor.ts / aiCustomizationManagement.ts as a shared top-level search bar that queries across the per-type item providers (aiCustomizationItemSource.ts, aiCustomizationItemsModel.ts) rather than duplicating InputBox instances in each of aiCustomizationListWidget.ts, mcpListWidget.ts, pluginListWidget.ts, and toolsListWidget.ts.
