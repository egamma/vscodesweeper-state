# Issue #307429 — certain regexp became really really slow in the newest version

[https://github.com/microsoft/vscode/issues/307429](https://github.com/microsoft/vscode/issues/307429)

## Summary

Thanks for the report. The pattern `(?<=”([^“”]|\n)*)‘…’` has an ambiguous alternation, because `\n` is already matched by the negated class `[^“”]`. That gives exponential backtracking in a JS lookbehind. Whether a V8/Electron change between releases made it slower can't be confirmed without running it, so this stays open as a likely upstream engine behavior change.

## Change summary

A lookbehind regex in Find became very slow and froze the window after updating to 1.114.0.

## Best solution

Confirm on the previous Electron/V8 version whether the regex engine's behavior changed. If so, track it as upstream. In the meantime, suggest a non-ambiguous pattern such as `(?<=”[^“”]*)‘([^“‘’”]*)’`.
