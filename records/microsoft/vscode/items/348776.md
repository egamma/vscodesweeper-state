## Change summary

Preserve already displayed partial answers after stopping an Agents chat and reloading or restarting VS Code.

## Best solution

Ensure the Copilot Agent Host durably retains displayed response text when cancellation interrupts streaming, and restores it with the turn still marked cancelled. First establish whether text is missing from provider history or discarded during restoration.
