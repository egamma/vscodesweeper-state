# Issue #161242 — Dead debug state

[https://github.com/microsoft/vscode/issues/161242](https://github.com/microsoft/vscode/issues/161242)

## Summary

The reported stale debug state was fixed on main: extension-host shutdown now explicitly terminates its debug sessions, allowing the workbench to return to the inactive state.

## Change summary

Crashing or killing the extension host can leave VS Code showing an active debug session that stop and disconnect actions do not clear.

## Best solution

Keep the session-cleanup behavior introduced by commit ccbcba53e642136ce30465cd4f5605d60c760d7c; no additional change is indicated for this report.
