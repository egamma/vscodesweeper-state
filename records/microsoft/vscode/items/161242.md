# Issue #161242 — Dead debug state

[https://github.com/microsoft/vscode/issues/161242](https://github.com/microsoft/vscode/issues/161242)

## Summary

Keep this accepted debug bug open: two maintainers observed or identified a reproduction for a stale debugging UI after the extension host dies, and no valid fixing commit or canonical issue is established.

## Change summary

The workbench can remain in an active debugging state after the extension host crashes or is killed and the user stops or disconnects the debug session.

## Best solution

Ensure debug-session teardown clears all active-session UI and context state when the owning extension host terminates unexpectedly, while preserving normal stop and disconnect semantics.
