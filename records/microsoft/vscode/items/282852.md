# Issue #282852 — rg heavy disk I/O usage, rg does not like brackets and is too greedy

[https://github.com/microsoft/vscode/issues/282852](https://github.com/microsoft/vscode/issues/282852)

## Summary

Keep open: the discussion confirms excessive background file searches starting above a bracket-containing workspace, including a recent macOS report with the wrong working directory logged. The search implementation has evolved since the original report, but the supplied paths and steps suffice to retest; no concrete fix or qualifying canonical duplicate was established.

## Change summary

Opening a workspace beneath a directory containing square brackets launches repeated ripgrep searches outside the workspace, causing excessive CPU and disk I/O.

## Best solution

Ensure background file discovery preserves literal workspace roots and does not unintentionally expand searches into ancestor directories. Diagnose the incorrect root separately from repeated search scheduling before deciding whether additional resource controls are necessary.
