# Issue #337686 — GHE github account not working anymore

[https://github.com/microsoft/vscode/issues/337686](https://github.com/microsoft/vscode/issues/337686)

## Summary

Same underlying defect as the older, still-open https://github.com/microsoft/vscode/issues/330657: the Copilot CLI/Agent Host harness resolves Copilot user/model info against api.github.com instead of the configured GitHub Enterprise Cloud (`*.ghe.com`) host, so a valid GHE token gets a 401 and the sign-in loop repeats. Proposing consolidation there rather than tracking two threads for the same root cause.

## Change summary

GHE (github-enterprise.uri / authProvider: github-enterprise) sign-in works, but the Agents window/Copilot CLI runtime keeps rejecting the token with 401 Bad credentials and re-prompts for login indefinitely.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/330657, which already tracks the CopilotCLIModels/Agent Host 401 against GHE hosts with an active thread and more history; fixing the endpoint resolution there (so the harness honors COPILOT_GH_HOST / the enterprise host end-to-end instead of falling back to api.github.com) resolves both.
