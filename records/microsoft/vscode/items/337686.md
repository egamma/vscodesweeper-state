# Issue #337686 — GHE github account not working anymore

[https://github.com/microsoft/vscode/issues/337686](https://github.com/microsoft/vscode/issues/337686)

## Summary

Fresh, well-documented regression in 1.139.0: GitHub Enterprise Cloud (ghe.com) users can no longer authenticate the Agents/Copilot CLI runtime — two independent commenters gave detailed logs showing the correct COPILOT_GH_HOST env var is set but the bundled runtime's `models.list` RPC still calls api.github.com and gets a 401. This needs investigation by the agent-host/Copilot team, not a triage close.

## Change summary

After upgrading to VS Code 1.139.0, GHE.com Copilot authentication succeeds in the browser and in editor Chat, but the Agents window/Copilot CLI runtime keeps rejecting the token and re-prompting sign-in in a loop.

## Best solution

Confirm whether the bundled Copilot CLI/SDK's `models.list` RPC actually honors `COPILOT_GH_HOST` for GHE Cloud hosts; if not, this needs an upstream fix/bump in the vendored `@github/copilot-sdk` runtime (or an explicit host parameter passed by copilotAgent.ts if the SDK API supports one) before GHE Agents auth works again in 1.139.x.
