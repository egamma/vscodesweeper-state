# Issue #276030 — Error in dev console from issue reporter:  Cannot set properties of undefined (setting 'enabled')

[https://github.com/microsoft/vscode/issues/276030](https://github.com/microsoft/vscode/issues/276030)

## Summary

Still reproduces on main: in the constructor, `updateExtensionStatus` (line 207) calls `validateSelectedExtension` which accesses `this.publicGithubButton.enabled` before the button is initialized (that happens in `updateButtonStates` at line 214). The bug triggers when an extension is pre-selected via the command.

## Change summary

Opening the issue reporter with a pre-selected extension throws a TypeError because `publicGithubButton` is accessed before initialization.

## Best solution

Either move the `updateButtonStates()` call (which initializes `publicGithubButton`) above the `updateExtensionStatus()` call in the constructor, or add a null guard in `validateSelectedExtension` (e.g. `this.publicGithubButton?.enabled`).
