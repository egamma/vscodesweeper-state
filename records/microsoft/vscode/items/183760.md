# Issue #183760 — Unexpected text color on hover in quick-pick

[https://github.com/microsoft/vscode/issues/183760](https://github.com/microsoft/vscode/issues/183760)

## Summary

Still present on main: the quick pick list configures inactive selection foreground to white (via `quickInputListFocusForeground` → `listActiveSelectionForeground`) but does not set a `listHoverForeground`, so hovering a selected-but-not-active item in a light theme shows white text against a light hover background.

## Change summary

Hovering a selected-but-not-active quick pick item in light themes shows white text with low contrast against the hover background.

## Best solution

In `src/vs/platform/quickinput/browser/quickInputService.ts`, the `getListStyles()` call should set `listHoverForeground` (or adjust the inactive selection foreground) so that hovered items maintain readable contrast in light themes. The fix is small and localized to the list style overrides.
