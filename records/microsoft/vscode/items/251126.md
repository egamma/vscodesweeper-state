# Issue #251126 — Improve Cycle Detection

[https://github.com/microsoft/vscode/issues/251126](https://github.com/microsoft/vscode/issues/251126)

## Summary

Keep open: the current scanners do not distinguish harmless deferred-use cycles from load-time dependency cycles. This is team-authored, accepted tooling work, and the author explicitly requested that development happen outside the vscode repository.

## Change summary

Improve dependency-cycle analysis to detect load-time hazards without flagging cycles whose imported values are used only inside functions or methods.

## Best solution

Develop and test an incremental, load-time-aware analyzer as an external project, with the customized TypeScript language service as the suggested integration target. Preserve the author's distinction between dangerous mixed cycles and harmless deferred-use cycles, and clarify the conservative side-effect classification before integration.
