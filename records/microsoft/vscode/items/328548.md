[https://github.com/microsoft/vscode/issues/328548](https://github.com/microsoft/vscode/issues/328548)

## Summary

Current source explains the reported Debug Console noise: development extension hosts redirect every deprecation warning through `console.debug`, despite intending to silence them. This is distinct from the CLI-only report and should be routed to the extension-host/debug owners.

## Change summary

VS Code-owned Node deprecation warnings appear as red output in the parent Debug Console while debugging an extension.

## Best solution

Stop VS Code-internal deprecations at their request/proxy sources, and ensure development-host warning handling does not forward known internal warnings into the Debug Console while preserving actionable extension-originated warnings.
