## Change summary

In the Cloud Automations repo picker, choosing the Cloud harness doesn't limit the repo list to cloud repos, and choosing a local repo makes the Cloud option vanish. The reporter suggests picking the harness first and filtering the options afterward.

## Best solution

Make the picker filter repos by the selected harness (or choose the harness first and then limit the remaining options) so that picking Cloud doesn't allow local repos and picking a local repo doesn't remove Cloud unexpectedly.
