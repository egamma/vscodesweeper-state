# Issue #308266 — Copilot agent resets to default instead of selected custom agent on new conversation

[https://github.com/microsoft/vscode/issues/308266](https://github.com/microsoft/vscode/issues/308266)

## Summary

The requested new-conversation behavior is now covered by the shipped `chat.newSession.defaultMode` setting, which accepts custom agent names and applies them whenever a new chat session starts.

## Change summary

Keep a selected custom Copilot agent active when starting and sending the first request in a new conversation.

## Best solution

Use the shipped `chat.newSession.defaultMode` setting with the custom agent's name; current `ChatInputPart` resolves custom agents case-insensitively and applies the configured mode to each new session.
