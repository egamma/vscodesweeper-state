# Issue #325474 — TypeError: .pendingRequests[0].request.message.parts: Converting circular structure to JSON

[https://github.com/microsoft/vscode/issues/325474](https://github.com/microsoft/vscode/issues/325474)

## Summary

The defect remains in current main: queued `/fork` requests persist the live slash-command descriptor, whose context-key expression contains the exact circular `negated` references reported. Session serialization therefore fails and can lose the chat when the window closes.

## Change summary

Submitting `/fork` while an agent request is running can queue a request that cannot be serialized because its parsed message contains circular context-key state.

## Best solution

Persist parsed request parts as storage-safe data without runtime-only slash-command metadata, while retaining the fields needed to restore and display every supported request-part kind.
