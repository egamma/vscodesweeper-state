# Issue #344044 — Copilot Chat CLI server fails to start on Intel Mac (macOS x64) after VS Code update

[https://github.com/microsoft/vscode/issues/344044](https://github.com/microsoft/vscode/issues/344044)

## Summary

Keep this open as a bundled Copilot runtime compatibility regression on older macOS. Multiple confirmations remain unresolved; neither the reported workarounds nor current SDK changes establish a fix.

## Change summary

Copilot Chat cannot start its native CLI runtime on Intel Macs running macOS Ventura after updating VS Code.

## Best solution

Resolve the native runtime compatibility problem with the SDK/runtime owners and verify the adopted binaries on affected Intel Macs. Keep this VS Code report as the integration record rather than treating an alternate harness or OS upgrade as a completed fix.
