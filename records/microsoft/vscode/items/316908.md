# Issue #316908 — Switching to Agent mode from Plan erases prompt

[https://github.com/microsoft/vscode/issues/316908](https://github.com/microsoft/vscode/issues/316908)

## Summary

The destructive mode-switch path remains possible on current main: changing modes rerenders Plan handoffs, Autopilot can execute the auto-send handoff, and handoff execution replaces the unsent draft with "Start implementation". The report has multiple independent confirmations and should remain open as a bug.

## Change summary

Switching from Plan to Agent can discard an unsent prompt and automatically submit "Start implementation".

## Best solution

Mode changes must preserve the current draft and never submit a handoff solely because the mode picker changed; explicit Start Implementation actions should retain their existing submission behavior.
