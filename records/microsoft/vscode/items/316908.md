# Issue #316908 — Switching to Agent mode from Plan erases prompt

[https://github.com/microsoft/vscode/issues/316908](https://github.com/microsoft/vscode/issues/316908)

## Summary

Verified duplicate of the older open canonical issue tracking the automatic Plan-to-implementation handoff. Maintainers have explicitly consolidated later reports with the same mode-switch draft deletion into that canonical.

## Change summary

Changing chat modes after typing an unsent prompt discards the draft and submits the stored “Start implementation” handoff instead.

## Best solution

Resolve this in https://github.com/microsoft/vscode/issues/307385 by ensuring mode-picker changes cannot unexpectedly execute a stored handoff or destroy an unsent draft.
