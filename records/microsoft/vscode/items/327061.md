# Issue #327061 — Git extension logs expected ENOENT for common refs in linked worktrees

[https://github.com/microsoft/vscode/issues/327061](https://github.com/microsoft/vscode/issues/327061)

## Summary

The warning is source-reproducible on main and should remain open as a localized Git extension bug. Route it to the Git area.

## Change summary

Linked worktrees produce misleading ENOENT warnings when revParse probes shared refs in the private worktree git directory before successfully falling back to Git.

## Best solution

In `Repository.revParse`, suppress logging only for an ENOENT from the speculative direct read while preserving warnings for other filesystem failures and the existing `git rev-parse` fallback.
