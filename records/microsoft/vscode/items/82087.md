# Issue #82087 — Scrollbar in editor is off

[https://github.com/microsoft/vscode/issues/82087](https://github.com/microsoft/vscode/issues/82087)

## Summary

Still present on main: the overview ruler decoration positions and the scrollbar slider use different coordinate scales, causing decoration indicators to diverge from the actual viewport position — especially in long files. Well-diagnosed root cause, no fix committed.

## Change summary

Clicking a decoration indicator (e.g. error marker) in the scrollbar overview ruler navigates to the wrong position because the decoration and slider coordinate scales diverge due to the 20px minimum slider height clamp.

## Best solution

Align the decoration position mapping in `DecorationsOverviewRuler._render()` with the scrollbar slider's coordinate system by accounting for the MINIMUM_SLIDER_SIZE (20px) clamp in `scrollbarState.ts`. The slider ratio (`computedSliderRatio`) or equivalent needs to be exposed from the scrollbar state to the overview ruler so decorations are painted on the same scale as the slider.
