# Issue #283633 — Background Agents powered by Copilot CLI is a confusing design decision

[https://github.com/microsoft/vscode/issues/283633](https://github.com/microsoft/vscode/issues/283633)

## Summary

Active design discussion by team members about Background Agents architecture — the CLI-powered approach lacks VS Code extension/MCP integration that local agents have. Multiple contributors share the sentiment; no resolution yet.

## Change summary

Background Agents powered by Copilot CLI cannot use extension-contributed MCP servers or VS Code-specific tooling, creating a confusing gap versus local agents.

## Best solution

Converge on a design where background/worktree agent sessions can leverage the full VS Code agent host (extension MCP servers, tool discovery, etc.) rather than being limited to the CLI harness — or at minimum make the CLI limitation explicit in the UX so expectations are clear.
