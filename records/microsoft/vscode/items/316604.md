# Issue #316604 — Copilot VSCode Agents - not displaying submodule changes

[https://github.com/microsoft/vscode/issues/316604](https://github.com/microsoft/vscode/issues/316604)

## Summary

Keep open: the current Copilot CLI worktree changes path computes the parent repository's diff without collecting file changes inside submodules. An independent reporter also confirms that submodule entries disappear after a turn completes; the issue already has the appropriate agents-window routing.

## Change summary

Preserve and display file-level changes made inside initialized Git submodules in the Agents Window Changes view, including after a session turn completes.

## Best solution

Make the Copilot CLI session changes model account for initialized submodule repositories, with correct repository-specific comparison references and file diffs. Diagnose the completion refresh boundary before implementation so the solution covers persisted results rather than only live edit tracking.
