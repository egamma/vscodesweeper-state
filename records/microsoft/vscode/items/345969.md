# Issue #345969 — Copilot agent does not promptly acknowledge and queue new instructions during ongoing work

[https://github.com/microsoft/vscode/issues/345969](https://github.com/microsoft/vscode/issues/345969)

## Summary

Existing queue and steering controls cover message submission during ongoing work, but do not establish the requested guarantee of prompt assistant acknowledgement. Keep this open as a feature request; the report does not identify a specific failing queue operation.

## Change summary

Provide prompt acknowledgement and visible tracking of additional instructions without abandoning an ongoing Copilot agent task.

## Best solution

Make message receipt, pending delivery, and agent consumption distinguishable in the existing chat queue experience. Clarify whether the remaining requirement is immediate UI acknowledgement or an assistant-generated response during ongoing work before defining a runtime change.
