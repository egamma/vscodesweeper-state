# Issue #269114 — Add create issue from chat component feature

[https://github.com/microsoft/vscode/issues/269114](https://github.com/microsoft/vscode/issues/269114)

## Summary

Existing response-level issue reporting and prompt-log export partially address this request, but do not establish the requested integrated workflow for selecting where a problem began and attaching the relevant logs. Keep this team-authored request open for design of that remaining workflow.

## Change summary

Allow users to select a problem's starting point in chat and create a GitHub issue with the relevant logs attached.

## Best solution

Provide a chat-context reporting flow that preserves the selected session and starting point, collects a bounded diagnostic bundle, and carries it into issue creation. Reuse the existing reporting and export capabilities rather than requiring users to navigate raw request logs.
