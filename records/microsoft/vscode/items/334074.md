[https://github.com/microsoft/vscode/issues/334074](https://github.com/microsoft/vscode/issues/334074)

## Summary

The modifier-click shortcut is not supported by the current Commit button; existing no-verify commands do not cover this mouse interaction. Route to the Git area for consideration, with no verified duplicate or completed fix.

## Change summary

Provide an opt-in modifier-click shortcut that skips commit hooks while preserving the selected commit action and making the shortcut discoverable.
