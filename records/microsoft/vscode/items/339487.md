# Issue #339487 — WTF is this "Changes" pill supposed to be??

[https://github.com/microsoft/vscode/issues/339487](https://github.com/microsoft/vscode/issues/339487)

## Summary

Confirmed on main: the Changes pill is hardcoded non-hideable (sessionChatPills.ts), and its default baseline (ChangesetKind.Branch) is hardcoded per-provider with no user-facing setting — so it can show a branch-vs-merge-base diff instead of the session's actual changes, with no way to hide or reconfigure it. This is a real gap, but which fix (expose a setting, change the default, or allow hiding) is a product call, not mine to make.

## Change summary

The agent chat 'Changes' pill is forced always-visible and defaults to diffing against the branch merge-base rather than session/working-tree changes, with no setting to hide or change the baseline.

## Best solution

A maintainer should decide whether the Changes pill's default baseline should be session-scoped (ChangesetKind.Session, as already used by editorCloudSandboxContribution.ts) for local/agent-host chats instead of Branch, and/or whether the pill should become hideable like its siblings — the mechanism already exists in sessionChatPillMenu, it's just special-cased out for Changes in isSessionChatPillHideable().
