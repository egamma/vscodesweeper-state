# Issue #339487 — WTF is this "Changes" pill supposed to be??

[https://github.com/microsoft/vscode/issues/339487](https://github.com/microsoft/vscode/issues/339487)

## Summary

This bundles three distinct complaints. The clearest one — the 'Changes' pill is hardcoded non-hideable and defaults to diffing against the branch merge-base rather than the session's actual changes — is confirmed in current source, but it's an explicit design choice, not an accidental bug, so the fix here is a product decision (expose a setting, or at least make it hideable) rather than a mechanical patch. The other two complaints (Ask mode removal, custom agents silently vanishing) aren't verifiable from this review and would be better as separate, focused issues.

## Change summary

User reports the new 'Changes' pill above the chat input can't be hidden and shows a misleading branch-level diff instead of the session's actual changes, with no setting to change the baseline; same update also removed 'Ask' mode and silently dropped the user's custom `.agent.md` agents.

## Best solution

For the pill: either make `SessionChatPillKind.Changes` hideable like the others in src/vs/workbench/contrib/chat/common/sessionChatPills.ts, or expose `DefaultChangesetKind` (Branch/Uncommitted/Session) as a user setting consumed by `selectDefaultChangeset` in src/vs/platform/agentHost/common/changesetUri.ts instead of it being hardcoded per provider. The Ask-mode-removal and vanished-custom-agents reports should be split into their own issues with reproduction details (which VS Code version, exact agent file format/location) since they can't be confirmed from this thread alone.
