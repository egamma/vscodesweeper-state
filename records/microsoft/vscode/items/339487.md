# Issue #339487 — WTF is this "Changes" pill supposed to be??

[https://github.com/microsoft/vscode/issues/339487](https://github.com/microsoft/vscode/issues/339487)

## Summary

Confirmed on main: the "Changes" session chat pill is deliberately hardcoded as the one non-hideable pill (isSessionChatPillHideable in sessionChatPills.ts), and its diff baseline (ChangesetKind.Branch vs Uncommitted vs Session) is set per-provider in code, not exposed as a setting — multiple independent reporters hit the same confusion, so this is real product feedback needing a maintainer decision, not a code bug.

## Change summary

The agent-session "Changes" pill shows a branch-vs-merge-base diff (not the session's own edits), cannot be hidden like every other pill, and its baseline is not user-configurable.

## Best solution

A maintainer should decide whether the Changes pill should become hideable (removing the special case in sessionChatPills.ts) and/or whether the changeset baseline should be a user-facing setting — ChangesetKind.Session is already used by the cloud-sandbox provider, so plumbing it through as a configurable default for the regular agent-host path looks feasible.
