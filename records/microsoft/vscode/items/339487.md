# Issue #339487 — WTF is this "Changes" pill supposed to be??

[https://github.com/microsoft/vscode/issues/339487](https://github.com/microsoft/vscode/issues/339487)

## Summary

This bundles three distinct complaints in one rant-y report; the core technical claims check out against source (the Changes pill really is hardcoded non-hideable and really does default to a Branch-vs-merge-base diff with no setting), but the Ask-mode-removal and silently-vanished-custom-agents reports are separate problems that need their own investigation and shouldn't be triaged together.

## Change summary

Reports that the new 'Changes' chat pill is non-hideable and shows a misleading branch-vs-merge-base diff instead of session changes, that Ask mode disappeared without warning, and that user-created custom agent files silently stopped loading after an update.

## Best solution

Split into separate issues: (1) make the Changes pill's baseline configurable or at least correct for the 'what did this session change' framing, in src/vs/platform/agentHost/common/changesetUri.ts (selectDefaultChangeset defaults to ChangesetKind.Branch) and src/vs/workbench/contrib/chat/common/sessionChatPills.ts (isSessionChatPillHideable hardcodes Changes as non-hideable); (2) investigate why .agent.md files under the user prompts folder stopped being discovered after update, and whether that should log a visible warning; (3) treat the Ask mode removal as a separate feature/communication issue if not already tracked elsewhere.
