# Issue #313466 — Copilot Chat: Provide approval mechanism (and obvious denial notification) when fetching resources

[https://github.com/microsoft/vscode/issues/313466](https://github.com/microsoft/vscode/issues/313466)

## Summary

Still reproduces on main: blocked-by-network-filter URIs are lumped into the 'invalid URL' array in `prepareToolInvocation`, producing a misleading error message. The reporter's secondary ask — an approval UI to add blocked domains — is a valid feature enhancement on top of the bug.

## Change summary

The fetch tool displays 'invalid URL' for URLs that were actually blocked by the agent network filter, and provides no way to approve or add blocked domains after the fact.

## Best solution

Separate the 'blocked' case from 'invalid' in the `prepareToolInvocation` pastTenseMessage (line 180 of fetchPageTool.ts) so the user sees a 'blocked by network filter' message with guidance on how to allow the domain. The approval-after-the-fact UX is a broader feature request that could be tracked as a follow-up.
