# Issue #314032 — LLM Chat completions being used  for UI decoration / title generation/ Progress Messages

[https://github.com/microsoft/vscode/issues/314032](https://github.com/microsoft/vscode/issues/314032)

## Summary

Valid concern about Copilot Chat using the cloud `copilot-utility-small` endpoint for UI decoration (title generation, progress messages, summaries) even when the user selects a local model. This is current by-design behavior — these lightweight utility calls go through the Copilot service — but the transparency and cost implications for users expecting fully local operation are a legitimate product discussion.

## Change summary

Copilot Chat sends cloud LLM requests (gpt-4o-mini via copilot-utility-small) for title generation, progress messages, and summaries regardless of the user's selected model.

## Best solution

Either (a) allow these utility calls to respect the user's selected model/local endpoint, or (b) make it transparently documented that certain UI decoration calls always use the Copilot cloud service and do not count against usage quotas. The team should decide whether local-model users should have an opt-out or local fallback for these calls.
