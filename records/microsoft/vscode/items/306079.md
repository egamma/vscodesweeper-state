# Issue #306079 — STOP auto upgrade for mac 10.15 users, after they update, they can't even open vs code

[https://github.com/microsoft/vscode/issues/306079](https://github.com/microsoft/vscode/issues/306079)

## Summary

Thanks for the report. Offering an incompatible automatic update is a valid concern, but the missing version numbers and update method prevent distinguishing a VS Code update-feed defect from an external package-manager upgrade.

## Change summary

Prevent automatic updates from replacing a working VS Code installation on macOS 10.15 with an incompatible version.

## Best solution

The update feed should preserve the last compatible installation on unsupported macOS versions. Establish the original and replacement VS Code versions and whether the update came from VS Code or an external installer before diagnosing the compatibility filtering.
