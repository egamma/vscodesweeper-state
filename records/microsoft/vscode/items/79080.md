# Issue #79080 — Bring the "track changes" feature to VS Code

[https://github.com/microsoft/vscode/issues/79080](https://github.com/microsoft/vscode/issues/79080)

## Summary

This remains a valid, community-promoted Backlog request. Current main provides SCM-based diff decorations and Local History snapshots, but neither supplies saved-versus-unsaved line indicators for ordinary local files.

## Change summary

Show Visual Studio-style gutter indicators distinguishing unsaved lines from lines saved since the file was opened, without requiring source control.

## Best solution

Extend the editor's quick-diff infrastructure with a non-SCM baseline that tracks the opened and last-saved file contents, rendering distinct saved and unsaved decorations while preserving existing SCM decorations.
