# Issue #347164 — Second session does not open if vscode window is already open

[https://github.com/microsoft/vscode/issues/347164](https://github.com/microsoft/vscode/issues/347164)

## Summary

Keep open: the linked test plan supplies sufficient steps to retest the second-session handoff with Insiders already running. Current source implements this flow, but inspection alone does not confirm the reported failure or establish a subsequent fix.

## Change summary

A second Copilot CLI session fails to appear when handed off to an already-running VS Code Insiders window.

## Best solution

Reproduce the warm-window handoff and identify where session delivery or Chat activation fails. The imported session should become visible in the folder's existing window, or in a new window when that folder is not already open, without leaving empty editor groups.
