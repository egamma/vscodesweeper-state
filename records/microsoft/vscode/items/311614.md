# Issue #311614 — Integrated terminal rendering becomes corrupted after macOS lock/unlock

[https://github.com/microsoft/vscode/issues/311614](https://github.com/microsoft/vscode/issues/311614)

## Summary

Active, community-confirmed GPU rendering corruption bug on macOS Apple Silicon, triggered by sleep/wake or desktop switching. Multiple users reproduce it; disabling GPU acceleration is the only reliable workaround. The team is aware (meganrogge, anthonykim1 commented). Likely an upstream Chromium/Electron GPU compositing issue, but needs further investigation.

## Change summary

The integrated terminal renders corrupted/garbled text on macOS after lock/unlock, desktop switching, or extended use with GPU acceleration enabled.

## Best solution

Investigate whether Chromium's GPU texture handling after macOS compositor events (sleep, space-switch) has regressed in the current Electron version. If upstream, file against Electron/Chromium with the reproduction pattern and consider adding a macOS-specific GPU context-loss recovery path in xterm.js or the terminal renderer. Issue #288682 tracks the same root cause and should be consolidated with this one (this issue has more triage engagement and upvotes, so it's the better canonical).
