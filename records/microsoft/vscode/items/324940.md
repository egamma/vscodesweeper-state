# Issue #324940 — No way to understand the symbol meaning

[https://github.com/microsoft/vscode/issues/324940](https://github.com/microsoft/vscode/issues/324940)

## Summary

Current main still renders the remote-extension badge without explaining it in the Extensions list, while the extension editor gives the same badge a localized tooltip. This is a bounded Extensions view discoverability and consistency issue that should remain open.

## Change summary

Explain the green remote-extension badge in the Extensions list and ensure it does not obscure other extension metadata such as ratings or recommendations.

## Best solution

Expose the existing localized remote-location explanation from the Extensions list hover experience while preserving ratings and recommendation information when they apply.
