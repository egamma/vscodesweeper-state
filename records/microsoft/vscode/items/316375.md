# Issue #316375 — First copilot command always fails

[https://github.com/microsoft/vscode/issues/316375](https://github.com/microsoft/vscode/issues/316375)

## Summary

Keep open: multiple reporters confirm that a literal Ctrl+U corrupts agent-issued terminal commands, and current source still sends that character in fallback execution paths. The related same-symptom issue is newer, so it cannot replace this re-reviewed report as the canonical.

## Change summary

Prevent terminal preparation from prepending a literal Ctrl+U to the first Copilot command and causing misleading command failures.

## Best solution

Make agent command preparation safe for Windows PowerShell terminals without assuming Ctrl+U is bound to clear input. Diagnose the startup and shell-integration state that selects the affected execution path, while preserving pending-input cleanup and correct command-result attribution.
