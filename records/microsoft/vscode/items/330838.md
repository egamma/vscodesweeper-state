# Issue #330838 — Request: Option to revert activity bar selection style to the cleaner, minimal previous version （1.132.1）

[https://github.com/microsoft/vscode/issues/330838](https://github.com/microsoft/vscode/issues/330838)

## Summary

The requested background-free activity bar selection and adjustable selection intensity are already available through workbench.colorCustomizations. Disabling Modern UI alone does not remove theme-provided selection backgrounds, which explains why the suggested switch is insufficient without establishing a regression.

## Change summary

Allow a quieter activity bar selection indicator and less prominent selection backgrounds in Explorer and Settings.

## Best solution

Use the existing theme customization mechanism to remove the activity bar's active background while retaining its classic border indicator, and adjust list and Settings selection colors independently. A separate selectionStyle setting is unnecessary for the requested appearance.

  > Thanks for the clarification. Turning off Modern UI restores the classic activity bar indicator, but selection backgrounds can still come from the active color theme.
  > 
  > With "workbench.experimental.modernUI": false, add "activityBar.activeBackground": "#00000000" inside "workbench.colorCustomizations" to remove the activity bar selection fill while retaining the classic border indicator.   >
