# Issue #112362 — Snippet transformation does not work with nested snippets

[https://github.com/microsoft/vscode/issues/112362](https://github.com/microsoft/vscode/issues/112362)

## Summary

The defect remains explicitly reproduced by a skipped regression test on current main. This issue is the canonical report for nested snippet transformations and should remain open.

## Change summary

Accepting a completion inside an active snippet discards transformations attached to the replaced outer placeholder.

## Best solution

Define how an outer placeholder transformation applies after nested snippet insertion, then preserve that transformation in `OneSnippet.merge` and enable the existing regression test.
