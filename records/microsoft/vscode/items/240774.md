# Issue #240774 — Font renders badly on light background with Experimental GPU Acceleration enabled

[https://github.com/microsoft/vscode/issues/240774](https://github.com/microsoft/vscode/issues/240774)

## Summary

Still reproduces on main: the GPU glyph rasterizer's subpixel anti-aliasing clear pass only removes exact background-color pixel matches, leaving anti-aliased fringe pixels visible on light backgrounds where they stand out as thin/jagged rendering artifacts.

## Change summary

Font renders thin and jagged in light themes when experimental GPU acceleration is enabled, because anti-aliased fringe pixels are not properly cleared against light backgrounds.

## Best solution

The `_clearColor` method in `src/vs/editor/browser/gpu/raster/glyphRasterizer.ts` needs to handle near-background pixels (sub-pixel anti-aliased fringes) rather than only clearing exact matches. On light backgrounds, anti-aliased dark-to-light gradients at glyph edges are left opaque, creating the thin/jagged appearance. A proper fix likely involves computing alpha from the distance-to-background rather than a binary exact-match clear.
