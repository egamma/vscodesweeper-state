# Issue #173749 — Sets LANG environment variable to wrong value

[https://github.com/microsoft/vscode/issues/173749](https://github.com/microsoft/vscode/issues/173749)

## Summary

Still reproduces on main: `getLangEnvVariable` receives the VS Code app language (defaulting to `en-US`) rather than the macOS system locale, so users with non-US English or non-English system locales get the wrong LANG in the integrated terminal. Already labeled `mitigated` and `help wanted`.

## Change summary

The integrated terminal sets the LANG environment variable based on VS Code's UI language instead of the macOS system locale, producing incorrect locale values for users whose system locale differs from the VS Code display language.

## Best solution

Pass the actual macOS system locale (obtainable via Electron's `app.getSystemLocale()` or similar API) into `getLangEnvVariable` instead of the VS Code UI language. The fix is localized to `src/vs/workbench/contrib/terminal/common/terminalEnvironment.ts` (the `language` parameter at line 302) and the call site that supplies it. The `detectLocale: 'off'` setting serves as a workaround.
