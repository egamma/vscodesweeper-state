# Issue #173749 — Sets LANG environment variable to wrong value

[https://github.com/microsoft/vscode/issues/173749](https://github.com/microsoft/vscode/issues/173749)

## Summary

Keep open: current source still derives a missing terminal LANG from VS Code's UI language rather than the system locale, explaining en_US.UTF-8 on an en-GB system. The documented workaround mitigates this but does not fix automatic locale selection.

## Change summary

Preserve the system's regional locale when automatically generating LANG for a new integrated terminal.

## Best solution

Automatic terminal locale selection should retain the macOS system region independently of VS Code's display language, while preserving existing compatible LANG values and explicit environment overrides.
