# Issue #71025 — Enabled Text-Highlighting and Copying in Playground

[https://github.com/microsoft/vscode/issues/71025](https://github.com/microsoft/vscode/issues/71025)

## Summary

The central request remains relevant on current main: Interactive Playground documentation is nested under a globally non-selectable body, while its local `user-select: initial` rule does not explicitly restore text selection. No open canonical issue owns this work, so it should remain open for an explicit product decision.

## Change summary

Allow users to select and copy the explanatory documentation surrounding code examples in the Interactive Playground.

## Best solution

Make the rendered `.walkThroughContent` documentation explicitly selectable while preserving the existing interaction behavior of embedded code editors and other workbench surfaces.
