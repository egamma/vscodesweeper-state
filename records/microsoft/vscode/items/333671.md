# Issue #333671 — Rename command behavior for nested chats

[https://github.com/microsoft/vscode/issues/333671](https://github.com/microsoft/vscode/issues/333671)

## Summary

Confirmed in source: the nested-chat rename commands genuinely lack the polish described. Milestone 1.137.0 is assigned, so this is a scheduled fix — keep open regardless of the confirmed traceability.

## Change summary

In a multi-chat session, the tab-strip 'Rename' action has no ellipsis and no F2 binding, and the overflow-menu 'Rename...' action has no F2 binding shown, unlike the primary session rename which does bind F2.

## Best solution

Give the chat-tab rename actions (chatCompositeBar.ts's inline 'Rename' action and sessionsActions.ts's `sessions.list.renameChat`) a proper title with ellipsis and an F2 keybinding scoped to when a chat tab (not the session header) has focus, without regressing the existing session-level F2 rename precondition.
