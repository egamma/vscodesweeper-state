# Issue #335616 — Hide GDB/MI commands (-exec) in VS Code Debug Console

[https://github.com/microsoft/vscode/issues/335616](https://github.com/microsoft/vscode/issues/335616)

## Summary

The Debug Console only renders what the active debug adapter sends it; the raw GDB/MI (`-exec-...`) echoing described here comes from the C/C++ extension's cppdbg debug adapter, not from VS Code's core Debug Console implementation.

## Change summary

Request a setting to hide raw GDB/MI protocol commands (e.g. `-exec-next`) from the Debug Console when debugging with cppdbg/GDB.

## Best solution

This belongs in the C/C++ extension (ms-vscode.cpptools), which owns the cppdbg debug adapter and decides what gets echoed to the console for MI-mode GDB sessions; file the request at https://github.com/microsoft/vscode-cpptools.
