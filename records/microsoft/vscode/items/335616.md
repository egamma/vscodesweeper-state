# Issue #335616 — Hide GDB/MI commands (-exec) in VS Code Debug Console

[https://github.com/microsoft/vscode/issues/335616](https://github.com/microsoft/vscode/issues/335616)

## Summary

The `-exec-*` lines are GDB/MI protocol traffic echoed into the Debug Console by the C/C++ extension's cppdbg (GDB) debug adapter — VS Code's core Debug Console just renders whatever the adapter sends, so any option to suppress MI echoing belongs in cpptools, not core.

## Change summary

Request for a setting to hide raw GDB/MI (`-exec-next`, `-exec-step`, ...) protocol commands echoed in the Debug Console when debugging with cppdbg/GDB.

## Best solution

File this against microsoft/vscode-cpptools, which owns the cppdbg debug adapter and controls whether/how it echoes MI protocol commands into the console; VS Code core has no visibility into or control over what a debug adapter chooses to print.
