# Issue #193831 — Overflowing collapsed diff breadcrumbs aren't scrollable

[https://github.com/microsoft/vscode/issues/193831](https://github.com/microsoft/vscode/issues/193831)

## Summary

The requested horizontal scrolling remains absent from collapsed diff breadcrumbs on current main. Keep this accepted Backlog request open; the related timeline report is newer and describes missing breadcrumbs rather than clipped ones.

## Change summary

Allow overflowing collapsed diff breadcrumbs to scroll horizontally, like file breadcrumbs.

## Best solution

Make the full collapsed-region breadcrumb trail reachable through horizontal scrolling in the diff editor, while preserving breadcrumb navigation and unchanged-region reveal controls. Existing truncation and hover text do not provide the requested interaction.
