## Change summary

Chats connecting during an enterprise OTel-triggered Agent Host restart remain failed after the host reconnects.

## Best solution

Ensure interrupted chat restoration recovers when the local Agent Host reconnects, preserving conversation identity, history, and drafts without requiring the user to reopen the tab. Preserve enterprise telemetry enforcement and distinguish transient transport failures from permanent session-load errors.
