# Issue #176273 — Cannot highlight U+200B and unhighlight multiple languages at the same time

[https://github.com/microsoft/vscode/issues/176273](https://github.com/microsoft/vscode/issues/176273)

## Summary

Keep open: language-specific defaults explain the Markdown/plaintext difference, but current source also suppresses invisible-character highlighting inside some non-ASCII words. No fixing commit or qualifying older duplicate was established.

## Change summary

Allow U+200B to remain highlighted while ordinary multilingual text is not highlighted.

## Best solution

Separate the language-default configuration issue from the remaining word-context suppression in UnicodeTextModelHighlighter. Establish the intended treatment of U+200B within natural-language words before changing that suppression, while preserving normal language-specific setting precedence.

- **Proposed comment:**

  > Thanks for the additional context. Markdown and plaintext have language-specific defaults that disable invisible-character highlighting; enabling `editor.unicodeHighlight.invisibleCharacters` inside the corresponding `[markdown]` or `[plaintext]` settings overrides those defaults. Keep `editor.unicodeHighlight.nonBasicASCII` false to avoid highlighting ordinary multilingual text—`allowedLocales` affects ambiguous-character detection, not the all-non-ASCII mode.
  > 
  > There is also a separate remaining behavior: the current highlighter can suppress U+200B inside non-ASCII words even when invisible-character highlighting is enabled. That needs investigation independently of the language defaults, so this should stay open.
