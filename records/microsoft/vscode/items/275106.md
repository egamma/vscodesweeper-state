# Issue #275106 — Workspace/Session/Global approval view is not very clear

[https://github.com/microsoft/vscode/issues/275106](https://github.com/microsoft/vscode/issues/275106)

## Summary

The discoverability gap remains: current approval management still switches workspace/global scope through a folder-icon toggle, while session scope is opened separately. Keep this team-authored Backlog request open for a clearer scope-selection design; no verified canonical owns the same observable problem.

## Change summary

Make workspace, session, and global approval scopes easier to discover and distinguish in tool approval management.

## Best solution

Make the active approval scope and available alternatives explicit in the existing management surface, with consistent terminology and accessible navigation. Decide whether session scope belongs alongside workspace/global scope before selecting the presentation.
