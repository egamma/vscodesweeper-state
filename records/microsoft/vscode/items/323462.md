# Issue #323462 — Placeholder flickers when switching between peer chats

[https://github.com/microsoft/vscode/issues/323462](https://github.com/microsoft/vscode/issues/323462)

## Summary

The recorded flicker remains credible on current main: peer-chat switching updates input state before replacing the outgoing chat view model, allowing placeholder observers to render an intermediate mismatched state. This team-authored bug should remain open for a bounded synchronization fix.

## Change summary

Prevent the chat-input placeholder from briefly showing stale or mismatched text when switching between peer chats.

## Best solution

Make a peer-chat transition visually atomic from the placeholder renderer's perspective, so it renders only the incoming chat's agent or mode description while preserving independent per-chat agent, model, and draft state.
