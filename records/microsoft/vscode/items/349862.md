# Issue #349862 — Ask mode completely removed with  no replacement in latest update?

[https://github.com/microsoft/vscode/issues/349862](https://github.com/microsoft/vscode/issues/349862)

Ask remains available as a read-only agent. The screenshots show the model and execution-mode pickers rather than the agent picker, so this can be answered with navigation guidance.

## Change summary

- **Proposed comment:**

  > Thanks for the report. Ask is still available as a read-only agent; the menus in your screenshots select the model or Interactive/Plan/Autopilot behavior, rather than the agent.
  > 
  > With the chat input focused, press **Ctrl+.** to open the agent picker and select **Ask**. If the picker has moved off the toolbar, you can also find it under **+ (Add Context) > Agent**. The setting `sessions.chat.experimental.agentsPickerInAttachContextMenu` controls that placement.
  > 
  > Selecting **Local** alone does not make the chat read-only—you still need to select **Ask**. If Ask is missing from the agent picker itself, please share a screenshot of that picker so we can investigate.
