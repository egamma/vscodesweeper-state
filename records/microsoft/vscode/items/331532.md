# Issue #331532 — Agent plugins: reconcile partial storage and source migrations

[https://github.com/microsoft/vscode/issues/331532](https://github.com/microsoft/vscode/issues/331532)

## Summary

Confirmed on main: `_migrateDirectory()` in agentPluginRepositoryService.ts logs and returns without reconciling when both cache roots exist, leaving the marketplace index stale — matching the report. An open PR (#331533, "Fixes #331532") from the same author already implements the fix, so this should stay open pending review/merge rather than be auto-fixed or closed now.

## Change summary

Agent plugin storage can end up partially migrated — either with both legacy and current cache roots present (leaving a stale marketplace index) or when an installed marketplace plugin's source moves (leaving a dangling registry URI) — and VS Code doesn't reconcile either case.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/331533, which reconciles both cache roots (destination wins, no worktree merging) and handles marketplace source moves by provisioning the new source before replacing the installed URI/metadata.
