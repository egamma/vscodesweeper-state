## Summary

Still reproduces on main: the "Below" diff view position path creates a new editor group on every compare invocation without reusing an existing one, unlike the "Beside" path which uses ViewColumn.Beside's built-in reuse.

## Change summary

Setting `merge-conflict.diffViewPosition` to "Below" opens a new diff editor group for every conflict comparison instead of reusing the existing one.

## Best solution

In `extensions/merge-conflict/src/commandHandler.ts`, the "Below" path should either reuse an existing below group (check if one already exists before calling `newGroupBelow`) or use `revealIfOpened` in the show options to prevent duplicate diff editors accumulating.
