# Issue #130454 — [Bug] `"merge-conflict.diffViewPosition": "Below"` opens multiple diff editors

[https://github.com/microsoft/vscode/issues/130454](https://github.com/microsoft/vscode/issues/130454)

## Summary

The bug remains present on current main: every comparison with the Below setting unconditionally creates another editor group instead of reusing the existing lower group.

## Change summary

Using merge-conflict.diffViewPosition set to Below creates an additional diff editor group each time Compare Changes is invoked.

## Best solution

Keep a single lower editor group for merge-conflict comparisons and reuse it on subsequent invocations, matching the reuse behavior of the Beside setting without changing Current or Beside behavior.
