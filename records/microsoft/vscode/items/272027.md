# Issue #272027 — "Delete Permanently" window UI suggestion for more obvious warning

[https://github.com/microsoft/vscode/issues/272027](https://github.com/microsoft/vscode/issues/272027)

## Summary

The permanent-deletion dialog already uses a native warning with explicit irreversible-action copy, but the requested stronger visual or interaction distinction remains an unresolved UX proposal. The related open issue concerns misleading undo wording rather than the same observable symptom, so it does not meet the stronger duplicate bar for this re-review.

## Change summary

Make permanent deletion more visibly distinct from ordinary deletion to reduce accidental loss of files that cannot be recovered.

## Best solution

Decide on a platform-consistent warning affordance that native dialogs support, such as stronger concise copy or a deliberately distinct confirmation action, while avoiding username entry or other disproportionate friction. The built-in deletion confirmation has no public extension interception point, so changing that exact dialog belongs in the core Explorer UX.
