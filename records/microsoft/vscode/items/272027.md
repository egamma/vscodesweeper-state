# Issue #272027 — "Delete Permanently" window UI suggestion for more obvious warning

[https://github.com/microsoft/vscode/issues/272027](https://github.com/microsoft/vscode/issues/272027)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/194999 tracks the same reporter-observable problem in the same confirmation dialog—its permanent-delete warning does not communicate the destructive outcome clearly enough.

## Change summary

Make the permanent-delete confirmation more visually and textually distinct from ordinary deletion to reduce accidental data loss.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/194999 and improve the existing native warning dialog within platform constraints, preserving the distinction between undoable files and irreversible folders or oversized files.
