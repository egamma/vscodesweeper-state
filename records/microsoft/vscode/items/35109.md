# Issue #35109 — Allow to switch to folder/workspace without window reload

[https://github.com/microsoft/vscode/issues/35109](https://github.com/microsoft/vscode/issues/35109)

## Summary

A meaningful gap remains on current main, and maintainers explicitly reopened and marked this issue to keep. The existing workspace-entry mechanism only partially enables the requested experience; the normal Open Folder flow still does not use it.

## Change summary

Switch folders or workspaces in the current window without reloading the workbench and losing transient state.

## Best solution

Route the normal Open Folder/Open Workspace flows through a complete in-process workspace transition that preserves or restores editors, backups, storage, and UI state while restarting extension hosts when required. The remaining remote-authority reload should also be removed once extension-host restart works there.
