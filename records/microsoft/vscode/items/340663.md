## Summary

Thanks for the report. It asks for persistent visible labels on the Add Context quick pick filter and the Quick Chat input. Both use placeholder text as their visual hint, which is VS Code's general quick-input pattern. This needs an accessibility owner to decide whether a persistent label is wanted, so it stays open and gets routed.

## Change summary

Placeholder text is the only visible label for the Add Context search field and the Quick Chat input, and it disappears once the user types.

## Best solution

An accessibility/chat owner decides whether these inputs should keep a persistent visible label or title, or whether the existing aria-label plus placeholder is acceptable for quick-input style controls. Any change should be applied consistently across quick inputs rather than per control.
