# Issue #192847 — env.machineId will return vmware adapter's mac

[https://github.com/microsoft/vscode/issues/192847](https://github.com/microsoft/vscode/issues/192847)

## Summary

Still reproduces on main: getMac() in macAddress.ts does not filter virtual adapter MACs (VMware OUI 00:50:56), so machineId can be based on an unstable VM adapter. The code in id.ts already has OUI knowledge via virtualMachineHint but doesn't apply it during MAC selection.

## Change summary

env.machineId may be based on a VMware virtual adapter's MAC address instead of the physical adapter, causing instability.

## Best solution

Reuse the VM OUI list from virtualMachineHint in getMac() to skip virtual adapter MACs before hashing, falling back to a VM MAC only if no physical adapter is found. Additionally, sorting adapters deterministically would prevent machineId changes when adapter enumeration order shifts.
