# Issue #149019 — Allow cusomizing the hotkey that shows/hides inlay hints

[https://github.com/microsoft/vscode/issues/149019](https://github.com/microsoft/vscode/issues/149019)

## Summary

The customization gap remains: current source hard-codes Ctrl+Alt for temporary inlay-hint visibility. Keep this accepted Backlog request open; an existing open PR proposes a toggle command and should be reviewed for how much of the request it addresses.

## Change summary

Allow a customizable keyboard shortcut to show or hide inlay hints instead of requiring users to hold Ctrl+Alt.

## Best solution

Provide keyboard-configurable inlay-hint visibility without forcing the hard-coded modifier combination. Review https://github.com/microsoft/vscode/pull/240437 against both the original customizable hold shortcut and the persistent toggle requested in the discussion; a toggle alone may not cover the original interaction.
