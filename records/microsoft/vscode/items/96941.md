# Issue #96941 — Support /mnt WSL links in windows not using Remote WSL

## Summary

The requested functionality — making `/mnt/` WSL paths clickable in the terminal on Windows — has been implemented on main. The terminal link resolver explicitly detects `/mnt/[a-z]` paths on Windows and converts them via `getWslPath`, and there are tests covering this exact scenario.

## Change summary

Support clicking `/mnt/` WSL-style file paths in the integrated terminal when running on Windows without Remote WSL.

## Best solution

Close as implemented. The fix lives in `terminalLinkResolver.ts` (line 77) which matches `/mnt/[a-z]` paths on Windows and resolves them through `getWslPath`. Tests in `terminalLocalLinkDetector.test.ts` confirm the conversion (e.g. `/mnt/c/foo/bar` → `C:\foo\bar`).
