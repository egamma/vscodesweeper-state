# Issue #346012 — In Copilot chat - local mode, BYOK `chat-completions` reasoning models' CoT are not rendering correctly.

[https://github.com/microsoft/vscode/issues/346012](https://github.com/microsoft/vscode/issues/346012)

## Summary

Keep open: an independent reporter confirms that Local-mode BYOK Chat Completions reasoning renders each streamed fragment as a separate bullet. The source identifies the relevant streaming and grouping paths, but does not yet establish the exact cause or a landed fix.

## Change summary

Render consecutive reasoning deltas as continuous text instead of separate Thinking-list entries.

## Best solution

Preserve streaming reasoning as a coherent section in Local-mode BYOK chat, without merging genuinely separate reasoning sections or changing normal answer rendering. Diagnose where stream fragments become separate display items before choosing the correction.
