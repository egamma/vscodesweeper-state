# Issue #323642 — Cache breakpoint re-anchoring rewrites (instead of extends) the BYOK Anthropic prompt cache in long agent sessions

[https://github.com/microsoft/vscode/issues/323642](https://github.com/microsoft/vscode/issues/323642)

## Summary

Keep open and route to the BYOK area: the reporter captured historical whitespace anchors disappearing between requests, and the current BYOK converter still conditionally creates those blocks. The later reports identify additional, intermittent prefix mutations rather than establishing that this specific defect is fixed.

## Change summary

Prevent moving Anthropic cache breakpoints from adding or removing content inside previously cached conversation history.

## Best solution

Make the BYOK Anthropic serialization preserve unchanged historical content when cache boundaries advance, while continuing to cache the growing conversation. Diagnose marker-induced changes separately from legitimate context changes, tool membership changes, and the companion workspace-tree problem.
