# Issue #323642 — Cache breakpoint re-anchoring rewrites (instead of extends) the BYOK Anthropic prompt cache in long agent sessions

[https://github.com/microsoft/vscode/issues/323642](https://github.com/microsoft/vscode/issues/323642)

## Summary

Valid cost-regression bug on the BYOK Anthropic path: the cache breakpoint redistribution strategy in cacheBreakpoints.ts is not byte-stable across turns, causing full cache rewrites instead of extensions. The issue remains unfixed on main.

## Change summary

Cache breakpoint re-anchoring in long BYOK Anthropic sessions mutates the cached prefix, forcing expensive full cache writes instead of incremental extensions.

## Best solution

Make the cache breakpoint placement additive/monotonic so that previously-cached prefix bytes are never altered when the trailing breakpoint advances. The fix likely involves stabilizing the synthetic whitespace anchor in anthropicMessageConverter.ts (lines 47–48, 71) and making the allocation strategy in cacheBreakpoints.ts position-stable across turns.
