# Issue #250687 — Clicking cell output attachment creates tabs with numbered cells in the title

[https://github.com/microsoft/vscode/issues/250687](https://github.com/microsoft/vscode/issues/250687)

## Summary

Valid open bug filed by a team member. The notebook tab title shows a numbered 'Cell #' label when opening a notebook via a cell output attachment after the notebook has been closed. No fix has landed on main.

## Change summary

Clicking a cell output attachment in chat (after the notebook is closed) opens a notebook tab with a confusing numbered 'Cell #' title instead of the proper notebook filename.

## Best solution

When opening a notebook via a cell output URI, the editor should resolve to the notebook's filename as the tab title rather than a generic cell-numbered label. The fix likely involves how the notebook editor input resolves its title from a cell output URI — see `src/vs/workbench/contrib/notebook/common/notebookEditorInput.ts` and `src/vs/workbench/contrib/notebook/browser/outputEditor/notebookOutputEditorInput.ts`.
