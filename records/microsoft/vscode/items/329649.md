# Issue #329649 — send_message server tool does not block a chat from messaging itself (Codex + Claude)

[https://github.com/microsoft/vscode/issues/329649](https://github.com/microsoft/vscode/issues/329649)

## Summary

Confirmed still broken on main and carries the real 1.135.0 milestone, so this stays open per the assigned-milestone hard keep-open rule regardless of how clear the fix path is.

## Change summary

The `send_message` self-target guard in `sessionServerTools.ts` compares chat-URI strings directly, which only matches Copilot's channel shape — Codex and Claude pass a session URI instead, so their self-send never gets rejected.

## Best solution

Land the author's own proposed fix: normalize `currentChannel` to a chat URI (a new `currentChatUri`-style helper distinct from the existing rename-chat one, per the issue's design) inside `applySendMessageTool` in src/vs/platform/agentHost/node/shared/sessionServerTools.ts, then flip `supportsSelfSendRejection` to true for all providers in serverToolsSuite.ts and extend the unit test at test/node/sessionServerTools.test.ts beyond the Copilot-shaped channel.
