# Issue #252789 — Lose custom instructions I retry after a window reload

[https://github.com/microsoft/vscode/issues/252789](https://github.com/microsoft/vscode/issues/252789)

## Summary

The defect remains source-reproducible on current main: normal submissions request automatic instruction collection, while the retry path after session restoration does not provide the required instruction context. This team-authored issue should remain open for a bounded fix.

## Change summary

Retrying a restored chat request after reloading the window omits the custom instruction files that were included in the original request.

## Best solution

Make restored-request retries use the same automatic-instruction routing as normal submissions, recomputing applicable instructions from the current workspace and mode rather than depending on transient pre-reload state.
