# Issue #252789 — Lose custom instructions I retry after a window reload

[https://github.com/microsoft/vscode/issues/252789](https://github.com/microsoft/vscode/issues/252789)

## Summary

Team-authored bug, must keep open. The defect appears still present on main: on retry after window reload, custom instruction files attached to a chat request are lost because the serialized/restored request model filters out automatically-added prompt-text entries (line 1456 of chatServiceImpl.ts), and the resend path doesn't re-collect instructions for the retried request's original context.

## Change summary

Custom instruction files attached to a chat message are lost when retrying that message after a window reload.

## Best solution

Ensure the retry/resend path in `chatServiceImpl.ts` re-collects instruction files (via `collectInstructions()`) rather than relying solely on the serialized `attachedContext` from the original request, which intentionally omits automatically-added prompt-text entries. The fix likely involves `resendRequest` or `_sendRequestAsync` ensuring instructions are freshly gathered on retry, similar to the normal send path.
