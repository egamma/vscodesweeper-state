# Issue #188312 — Terminal tab home CWD is not handled correctly in remote workspaces

Keep open: the supplied remote-window steps suffice to retest the unwanted folder suffix, but current behavior was not confirmed. Current source has explicit folder-suppression logic and local-path tests; neither establishes that the reported remote case is fixed.

## Change summary

Suppress the redundant terminal tab folder name when a newly opened remote terminal is in its single workspace folder.

## Best solution

Make remote terminal tab descriptions follow the same single-folder suppression behavior as local terminals, while retaining folder descriptions after changing directory and in multi-root workspaces. First reproduce the remote case and identify where its detected cwd diverges from the workspace path comparison.
