# Issue #315979 — skill() tool fails for symlinked skills in ~/.agents/skills/

[https://github.com/microsoft/vscode/issues/315979](https://github.com/microsoft/vscode/issues/315979)

## Summary

Confirmed bug in the skill tool virtualization path: when `skillTool.enabled` is true, skills that exceed the character budget are listed as name-only in an 'Additional skills available' line, and the `skill()` tool cannot resolve them. Symlinked skills appear to consistently land in this truncated group. A team member (pwang347) acknowledged the issue and has pending work to improve it — keeping open.

## Change summary

The `skill()` tool in Copilot Agent mode fails to resolve skills that are truncated into the 'Additional skills available' name-only list, which disproportionately affects symlinked skill directories.

## Best solution

The skill tool's virtualization logic in `automaticInstructionsCollector.ts` (around line 498–535) needs to ensure that skills listed in the truncated 'Additional skills available' line are still resolvable by the `skill()` tool — either by expanding the budget, registering all skills in a lookup regardless of prompt truncation, or resolving symlinks earlier so they sort alongside real directories. pwang347 has pending work on this.
