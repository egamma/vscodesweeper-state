# Issue #282227 — relative worktrees are not detected

[https://github.com/microsoft/vscode/issues/282227](https://github.com/microsoft/vscode/issues/282227)

## Summary

Still reproduces on main: the worktree detection in `getWorktreesFS()` assumes `gitdir` content is an absolute path and does not resolve relative paths. An open PR (#321368) exists but has not merged.

## Change summary

Git worktrees created with `--relative-paths` are not detected because `getWorktreesFS()` treats the `gitdir` file content as absolute without resolving relative paths.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/321368 (or an equivalent fix) that resolves relative `gitdir` entries against their containing directory before stripping the `.git` suffix. The fix is small and localized to `extensions/git/src/git.ts` line ~3066.
