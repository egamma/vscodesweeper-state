# Issue #282227 — relative worktrees are not detected

[https://github.com/microsoft/vscode/issues/282227](https://github.com/microsoft/vscode/issues/282227)

## Summary

Relative-path worktree discovery remains broken in current main: the Git extension forwards relative metadata paths without resolving their base directory. Keep this issue open while the existing fix candidate is reviewed.

## Change summary

Detect worktrees created with Git's --relative-paths option when git.detectWorktrees is enabled, alongside absolute-path worktrees.

## Best solution

Review and land an adequate fix through https://github.com/microsoft/vscode/pull/321368 so worktree discovery resolves relative gitdir entries against their metadata directory while preserving absolute-path discovery.
