# Issue #138476 — Misleading free memory reporting on MacOS in Issue Reporter

[https://github.com/microsoft/vscode/issues/138476](https://github.com/microsoft/vscode/issues/138476)

## Summary

Keep open: the issue reporter has changed since the report, but current diagnostics still display Node's free-memory figure without accounting for reclaimable cache. The supplied steps suffice to retest on macOS; source inspection alone does not confirm the present-day numerical discrepancy.

## Change summary

The macOS issue reporter's system-memory statistic can understate usable memory by excluding reclaimable cached files.

## Best solution

Make the macOS diagnostic distinguish unused memory from memory available for applications, using an explicitly defined metric. Keep the issue reporter and textual system diagnostics consistent without changing other platforms' memory semantics.
