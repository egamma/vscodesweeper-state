[https://github.com/microsoft/vscode/issues/81038](https://github.com/microsoft/vscode/issues/81038)

## Summary

Keep open: VS Code still bundles the upstream SCSS grammar implicated in nested-property highlighting failures, and no replacement or relevant fix was found. The older report cited by the author was transferred upstream, not fixed, so it is not a valid duplicate-close target.

## Change summary

Correct SCSS syntax highlighting for nested properties with shorthand values and the declarations following them, potentially through a maintained replacement grammar.

## Best solution

Provide SCSS tokenization that correctly balances nested property blocks without corrupting subsequent declarations. Retain this issue as the VS Code integration record while maintainers evaluate a compatible grammar fix or replacement; the previously suggested indented-Sass grammar does not cover SCSS.
