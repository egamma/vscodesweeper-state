## Summary

Already fixed on main: the image-omission gate was incorrectly applied to BYOK/custom-endpoint and custom-model-provider requests too, not just first-party Copilot endpoints; the merged fix scopes the org-policy gate to CAPI endpoints only.

## Change summary

BYOK custom endpoint models and custom Language Model Provider extensions stopped receiving image attachments in chat requests starting in VS Code 1.132.

## Best solution

Keep the fix in commit c17ebb8b9c7 (merged via PR #329646) — canSendImage() in image.tsx now only applies the copilotToken.isEditorPreviewFeaturesEnabled() org-policy gate for CAPI endpoints, leaving BYOK/custom providers unaffected by that policy.
