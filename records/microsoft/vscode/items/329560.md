# Issue #329560 — BYOK model can not use vision in 1.132 version - Custom endpoint model or Custom Model Provider cannot receive image data part in messages

[https://github.com/microsoft/vscode/issues/329560](https://github.com/microsoft/vscode/issues/329560)

## Summary

Fixed by the merged PR that changed image-sending logic to bypass the Copilot editor-preview-features policy for non-CAPI (BYOK) endpoints while still enforcing vision support checks; the reporter confirmed the fix works in 1.133.0-insider.

## Change summary

BYOK custom endpoint models and custom model providers were not receiving image data in messages because the (CAPI-only) editor-preview-features policy check was incorrectly gating image sending for all vision-capable models, including BYOK ones.

## Best solution

Keep the shipped fix from commit c5d02f8db20fbd749c072b9fab817dec45a89933 (merged PR #329646); the current `canSendImage` in extensions/copilot/src/extension/prompts/node/panel/image.tsx now only applies the editor-preview-features gate to CAPI endpoints (`!isCAPIEndpoint(endpoint) || authService.copilotToken?.isEditorPreviewFeaturesEnabled()`), so BYOK/custom endpoints send images whenever `supportsVision` is true. No further change needed beyond it reaching a stable release.
