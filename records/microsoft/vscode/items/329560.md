## Summary

Already fixed and merged: PR #329646 (commit c5d02f8db20fbd749c072b9fab817dec45a89933, merged 2026-08-07T17:44:16Z) added a canSendImage helper that bypasses the Copilot editor-preview policy gate for BYOK (custom endpoint and extension-contributed custom model provider) endpoints while still enforcing the vision capability check — this is present on current main.
