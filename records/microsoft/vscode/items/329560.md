## Summary

A merged fix (PR #329646, commit c5d02f8d) already on main directly targets this scenario — it makes `canSendImage` in image.tsx bypass the CAPI-only editor-preview-features gate for non-CAPI (BYOK custom endpoint / custom model provider) endpoints, with new regression tests for exactly 'custom endpoint model' and 'custom model provider' — but the PR description itself says it only 'partially addresses' the issue, and the reporter's comments after the merge (Aug 8, Aug 10) still describe images not reaching the model, including for the built-in model, so I'm not confident the underlying problem is fully closed yet.
