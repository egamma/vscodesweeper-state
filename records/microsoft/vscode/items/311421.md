## Summary

Valid open bug filed during testplan testing: Gemini CLI on Bash/Fedora doesn't emit an OSC title sequence containing "gemini", so VS Code's agent CLI title detection never triggers and the tab shows "node". No fix has landed on main.

## Change summary

Gemini CLI's terminal tab title stays as "node" on Bash/Fedora instead of showing the Gemini CLI identity.

## Best solution
