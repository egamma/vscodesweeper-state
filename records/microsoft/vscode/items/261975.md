# Issue #261975 — Terminals sessions should not be deleted when starting a new conversation

[https://github.com/microsoft/vscode/issues/261975](https://github.com/microsoft/vscode/issues/261975)

## Summary

Keep open: multiple users confirm that completed Copilot-managed terminal sessions are still disposed when switching chats, and a maintainer explicitly planned a configurable option. The issue was reopened after the earlier fix claim, so the remaining lifecycle policy is still unresolved.

## Change summary

Allow users to retain Copilot-managed terminals and their command output when starting or switching to another chat session.

## Best solution

Add a chat-terminal lifecycle setting with clear retention choices such as never, when hidden, and always auto-close, while preserving safe isolation between agent sessions. Keep selecting arbitrary user-owned terminals as separate future work because it has different data-loss and environment concerns.
