# Issue #261975 — Terminals sessions should not be deleted when starting a new conversation

[https://github.com/microsoft/vscode/issues/261975](https://github.com/microsoft/vscode/issues/261975)

## Summary

Thanks for the report. Agent-run terminals are still disposed when their chat session is disposed or archived, and no setting controls this. The maintainer has acknowledged wanting an option. The issue was reopened after a prior close because later commenters still hit it, so it stays open as a backlog feature request.

## Change summary

Keep agent-run terminals alive when a new chat starts, and let the user decide when they are closed.

## Best solution

Add an opt-in setting for the lifetime of agent-run terminals (for example never, when hidden, or always), and optionally a way to promote a terminal to a user-owned one. A maintainer should decide the default and the semantics.
