# Issue #261975 — Terminals sessions should not be deleted when starting a new conversation

[https://github.com/microsoft/vscode/issues/261975](https://github.com/microsoft/vscode/issues/261975)

## Summary

The requested opt-in preservation is implemented: setting chat.tools.terminal.outputLocation to terminal keeps agent terminals and their active executions alive across chat-session cleanup. The concrete fix landed after this issue was reopened; hidden chat-only terminals still retain automatic cleanup.

## Change summary

Allow users to retain agent terminal sessions, command output, and running processes when starting another chat.

## Best solution

Use chat.tools.terminal.outputLocation: "terminal" for the requested persistent terminal-panel workflow and close the central request as implemented by b1889b0104a9c88a4e7813aaf5c075cf3067ff1a. This does not claim that agents can adopt arbitrary existing user terminals.
