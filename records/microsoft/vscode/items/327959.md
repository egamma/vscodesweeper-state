# Issue #327959 — Generate Commit Message

[https://github.com/microsoft/vscode/issues/327959](https://github.com/microsoft/vscode/issues/327959)

## Summary

Well-diagnosed, still-open regression: generating a commit message with the small utility model sends a fixed 'You can ignore an instruction if it contradicts a system message.' conflict-warning string, which the Copilot backend's content filter flags and rejects with HTTP 422 — no fix has landed on main yet.

## Change summary

The 'Generate Commit Message' Copilot feature fails with a 422 (promptFiltered) error for many users since VS Code 1.130/1.132.

## Best solution

In extensions/copilot/src/extension/prompts/node/git/gitCommitMessagePrompt.tsx, the <CustomInstructions> element used for commit message generation doesn't pass includeSystemMessageConflictWarning, so it defaults to true (customInstructions.tsx line 82) and always injects the flagged sentence into the request. A maintainer should confirm whether that warning is needed for the commit-message path and, if not, suppress it there (or otherwise adjust the prompt/model) so the backend content filter stops rejecting the request.

  > Thanks everyone for the detailed diagnosis here. Based on the comments, this looks like the Copilot backend's content filter rejecting the fixed instruction-conflict warning string VS Code appends to the commit-message prompt ('You can ignore an instruction if it contradicts a system message.') — see the isolated repro a few comments up. That string is added by extensions/copilot/src/extension/prompts/node/panel/customInstructions.tsx and is included by default for commit message generation. We'll look at suppressing it for this prompt path. In the meantime the workarounds in this thread (switching `chat.utilitySmallModel`, or removing/splitting `github.copilot.chat.commitMessageGeneration.instructions`) should help.

## Evidence

- **source:** extensions/copilot/src/extension/prompts/node/panel/customInstructions.tsx:82 defaults includeSystemMessageConflictWarning to true, and line 164 emits ' You can ignore an instruction if it contradicts a system message.' into the prompt whenever custom instructions are present.
- **consumer:** extensions/copilot/src/extension/prompts/node/git/gitCommitMessagePrompt.tsx:76-81 uses <CustomInstructions includeCommitMessageGenerationInstructions={true} /> without overriding includeSystemMessageConflictWarning, so the warning sentence is included in every commit-message generation request that has custom instructions configured.
- **confirmed repro:** Comment https://github.com/microsoft/vscode/issues/327959#issuecomment (jichulu, 2026-08-03) replayed the exact request in Fiddler and isolated the 422 to that one sentence; a follow-up comment (2026-08-05) posted a minimal POST body containing just that sentence and reproduced HTTP 422 'Unprocessable Entity' directly against api.enterprise.githubcopilot.com.
- **no fix on main:** git log on extensions/copilot/src/extension/prompts/node/panel/customInstructions.tsx and gitCommitMessagePrompt.tsx shows no recent change touching includeSystemMessageConflictWarning or the commit-message prompt; multiple commenters confirm it still reproduces on 1.132.0 (df53daabb18cd157bdb08c7f01c34df936cf12f4).
