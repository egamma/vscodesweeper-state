# Issue #327959 — Generate Commit Message

[https://github.com/microsoft/vscode/issues/327959](https://github.com/microsoft/vscode/issues/327959)

## Summary

Well-diagnosed, still-unfixed bug: current main still emits the system-message-conflict warning sentence whenever commit-message custom instructions are set, and community reproduction shows that exact sentence alone triggers a 422 promptFiltered from the Copilot backend — this belongs with the chat/git area owners, not stuck on info-needed.

## Change summary

Generate Commit Message fails with a 422 Unprocessable Entity / promptFiltered error whenever `github.copilot.chat.commitMessageGeneration.instructions` is set.

## Best solution

In extensions/copilot/src/extension/prompts/node/git/gitCommitMessagePrompt.tsx, pass includeSystemMessageConflictWarning={false} (or reword the sentence in customInstructions.tsx) so the commit-message prompt no longer sends the 'You can ignore an instruction if it contradicts a system message.' phrase that the backend's RAI/prompt-injection-style filter is rejecting when combined with user instructions.
