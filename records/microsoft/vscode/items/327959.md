# Issue #327959 — Generate Commit Message

[https://github.com/microsoft/vscode/issues/327959](https://github.com/microsoft/vscode/issues/327959)

## Summary

Real, still-reproducing bug: Generate Commit Message frequently fails with a 422 promptFiltered error. Community diagnosis (with a replayed request) traces it to the fixed system-message-conflict warning string injected into every commit-message prompt, which current main still includes unconditionally by default — this needs area-owner attention, not a close.

## Change summary

The built-in "Generate Commit Message" (Copilot) feature fails with a 422 Unprocessable Entity / promptFiltered error for many users, especially when custom commit-message instructions are configured.

## Best solution

Have the Chat/Copilot area owners investigate making `includeSystemMessageConflictWarning` (or the wording of that injected string) safer for the commit-message-generation prompt path, and/or handle `promptFiltered` 422 responses more gracefully (e.g. fallback prompt or clearer user-facing error) in extensions/copilot/src/extension/prompt/node/gitCommitMessageGenerator.ts.
