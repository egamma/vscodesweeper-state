# Issue #327959 — Generate Commit Message

[https://github.com/microsoft/vscode/issues/327959](https://github.com/microsoft/vscode/issues/327959)

## Summary

Traced in source: `Generate Commit Message` fails with a 422 `promptFiltered` whenever the user has any commit-message custom instructions configured, because `GitCommitMessagePrompt` renders `CustomInstructions` without overriding `includeSystemMessageConflictWarning`, so the appended sentence 'You can ignore an instruction if it contradicts a system message.' is sent and is apparently mis-flagged as prompt injection by the content filter for the small utility model used here.

## Change summary

Generate Commit Message consistently fails (422 Unprocessable Entity / promptFiltered) for users with commit-message custom instructions configured.

## Best solution

In extensions/copilot/src/extension/prompts/node/git/gitCommitMessagePrompt.tsx, pass `includeSystemMessageConflictWarning={false}` (or otherwise drop that sentence for commit-message generation) since a community member's minimal repro (comment by jichulu, https://github.com/microsoft/vscode/issues/327959#issuecomment-3241611924) shows that exact sentence alone triggers the 422 from the backend; multiple users confirm removing `github.copilot.chat.commitMessageGeneration.instructions` (which is the only thing that makes this component render, per the `chunks.length === 0` early return) resolves it.
