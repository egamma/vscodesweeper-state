# Issue #327959 — Generate Commit Message

[https://github.com/microsoft/vscode/issues/327959](https://github.com/microsoft/vscode/issues/327959)

## Summary

Generate Commit Message consistently fails with a 422 from the Copilot backend; a commenter replayed the exact failing request and traced it to the fixed sentence 'You can ignore an instruction if it contradicts a system message.' that's unconditionally appended to the commit-message prompt, and the code path is confirmed still present on main.

## Change summary

The built-in 'Generate Commit Message' action fails (server 422 'promptFiltered') for many users instead of producing a message.

## Best solution

The commitMessageGeneration prompt in extensions/copilot/src/extension/prompts/node/panel/customInstructions.tsx (systemMessageConflictWarning, appended when includeSystemMessageConflictWarning is true) or the model routing for gitCommitMessageGenerator needs a maintainer decision — either drop/reword that sentence for this flow or otherwise stop tripping the backend content filter; workarounds (switching chat.utilitySmallModel, removing commitMessageGeneration.instructions, splitting long instruction text) all point at the same prompt/model interaction.
