## Change summary

Slash commands such as /plugin disable render with chat command styling when typed out, but as plain text when built by accepting completions.

## Best solution

Have the agent host provide highlight (and likely hover) information for its slash commands so rendering no longer depends on how the text was entered, as the maintainer suggested in the thread.
