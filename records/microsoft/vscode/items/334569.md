# Issue #334569 — MCP tool calls intermittently rejected "disabled by the user" while cache shows enabled and server log shows execution

[https://github.com/microsoft/vscode/issues/334569](https://github.com/microsoft/vscode/issues/334569)

## Summary

The defect remains source-reproducible on current main, and an open PR directly referencing this issue proposes a server-scoped fix. Keep the issue open while https://github.com/microsoft/vscode/pull/334657 is reviewed.

## Change summary

Ask mode can reject late-discovered tools from a referenced MCP server as disabled because tool availability relies on an earlier static toolset snapshot.

## Best solution

Review and either land or explicitly close https://github.com/microsoft/vscode/pull/334657; its server-scoped approach is intended to include tools discovered after request parsing without exposing tools from unrelated MCP servers.
