# Issue #345479 — Copilot harness: every custom agent is listed twice in the subagent list, once by its own name and once as vscode-agent-<sha1>

[https://github.com/microsoft/vscode/issues/345479](https://github.com/microsoft/vscode/issues/345479)

## Summary

Keep open: the Windows confirmation and current source identify a remaining duplicate-registration path for runtime-discovered directory agents. Native plugin-agent handling does not cover that path.

## Change summary

Prevent the Copilot task tool from listing the same agent source under both its native identity and a forwarded vscode-agent hash identity.

## Best solution

Expose each runtime-loaded agent source once while preserving native selection, authored configuration, and genuinely distinct same-named agents. Retain forwarding for agents that the runtime does not otherwise load.
