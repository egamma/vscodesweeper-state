# Issue #211730 — Saving notebook files should happen on extension host by default

[https://github.com/microsoft/vscode/issues/211730](https://github.com/microsoft/vscode/issues/211730)

## Summary

The remote save setting is still experimental and only defaults to true in Insiders builds (not stable). The issue's goal of enabling it by default everywhere has not been completed.

## Change summary

Enable notebook saving on extension host by default for all builds, not just Insiders.

## Best solution

Once the referenced issue #209291 is resolved and telemetry from the experiment confirms stability, flip the default in `src/vs/workbench/contrib/notebook/browser/notebook.contribution.ts` line 1257 to `true` unconditionally and remove the `experimental` tag.
