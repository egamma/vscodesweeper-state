# Issue #330561 — Terminal background-completion turns are sent without instructionContext, so instructions/skills are dropped (regression in 1.131.0)

[https://github.com/microsoft/vscode/issues/330561](https://github.com/microsoft/vscode/issues/330561)

## Summary

Confirmed on current main: `_registerCompletionNotification` in runInTerminalTool.ts builds `sendOptions` without `instructionContext`, and `chatServiceImpl.ts`'s `collectInstructions` bails out entirely when that field is absent — matching the reported regression exactly. A fix PR already exists and is open, so this should stay open pending review/merge rather than being auto-fixed.

## Change summary

Background terminal-completion chat turns are sent without `instructionContext`, so repo instructions, AGENTS.md, and skills are silently dropped from that turn.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330570, which forwards `instructionContext` from the prior request in all three background-notification call sites (input-needed, completed, terminal-exited) and adds a regression test; close this issue once that PR merges.
