# Issue #202417 — [css] Outline doesn't show @layer 

[https://github.com/microsoft/vscode/issues/202417](https://github.com/microsoft/vscode/issues/202417)

## Summary

A real gap remains in the CSS language service: it parses `@layer`, but its document-symbol collector does not emit layer symbols. The issue is already correctly classified and routed, so it should remain open for the upstream language-service change.

## Change summary

Include CSS `@layer` rules in the Outline view alongside existing constructs such as `@media` and `@scope`.

## Best solution

Extend `CSSNavigation.collectDocumentSymbols` in `microsoft/vscode-css-languageservice` to emit a module symbol for each `nodes.Layer`, including its name and nested rules, add navigation tests, and then consume the updated language-service release in VS Code.
