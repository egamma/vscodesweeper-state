# Issue #347619 — Agent Bakeoff: Compare Custom Agent Instructions (.agent.md) in Agent Bakeoffs

[https://github.com/microsoft/vscode/issues/347619](https://github.com/microsoft/vscode/issues/347619)

## Summary

Keep open as a feature request: current comparison setup supports model/configuration variants, but not independently selected custom-agent instructions per attempt. The linked skill-comparison request is related, not a verified duplicate.

## Change summary

Allow Bakeoff attempts to use different .agent.md instructions while holding the model, prompt, and starting repository state constant and reusing the Judge.

## Best solution

Extend comparison setup to represent custom-agent identity independently from model configuration, preserving controlled starting conditions and identifying each attempt clearly in Judge results. Decide separately whether comparing worker-subagent models belongs in the initial scope.
