# Issue #177185 — Remove invalid entries from Recent Opened etc.

[https://github.com/microsoft/vscode/issues/177185](https://github.com/microsoft/vscode/issues/177185)

## Summary

This accepted Backlog request remains necessary: current main supports clearing everything or removing entries individually, but not pruning all invalid entries. Its 39 community upvotes also protect it from staleness-based closure.

## Change summary

Add a way to identify and remove nonexistent paths from recently opened lists without clearing valid entries.

## Best solution

Add a targeted prune command to the workbench history service and Open Recent picker, removing confirmed-missing local paths while retaining remote or temporarily inaccessible resources. Consider invalid-path decoration and Workspace Trust cleanup separately if their validation semantics differ.
