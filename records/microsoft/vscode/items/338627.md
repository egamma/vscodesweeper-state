# Issue #338627 — Placeholder text contrast is below 4.5:1 for “Enter Your Answer” input field in Light and Dark (2026) theme:A11y_VisualStudioCode_Improved UI for MCP elicitation_Keyboard

[https://github.com/microsoft/vscode/issues/338627](https://github.com/microsoft/vscode/issues/338627)

## Summary

Confirmed on current main: the shared `input.placeholderForeground` token in both 2026-dark.json (#555555 on #191A1B, ~2.34:1) and 2026-light.json (#999999 on #FFFFFF, ~2.85:1) is well under the required 4.5:1, which is exactly what drives the faint 'Enter Your Answer' placeholder in the MCP elicitation form. This is an internal accessibility (MAS) verification bug that explicitly should only be closed by the C+AI Accessibility tester, so it stays open regardless.

## Change summary

Placeholder text (e.g. the MCP elicitation form's 'Enter Your Answer'/'Enter custom answer' fields) is too low-contrast to read in the Dark (2026) and Light (2026) themes.

## Best solution

Bump `input.placeholderForeground` in extensions/theme-defaults/themes/2026-dark.json and 2026-light.json to values that reach ≥4.5:1 against `input.background`, ideally with theme-designer sign-off so the new shade still reads as visually de-emphasized and consistent with each theme's palette.
