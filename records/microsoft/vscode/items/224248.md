# Issue #224248 — search error

[https://github.com/microsoft/vscode/issues/224248](https://github.com/microsoft/vscode/issues/224248)

## Summary

Keep open: current source still constructs an inaccessible parent-directory search root for individually opened browser files, which explains the missing results and all-external-files error. The maintainer confirmed both reported bugs and explicitly rejected the suggested fix; the list/tree symptom still needs separate investigation.

## Change summary

Search only in Open Editors on vscode.dev omits files opened outside the workspace, can report an error when only those files are open, and reportedly leaves list/tree switching ineffective.

## Best solution

Make open-editor search include individually authorized browser files without requiring access to their parent directories, while preserving search filters and normal workspace searching. Retest the list/tree controls alongside both reported search scenarios to establish whether they share the cause.
