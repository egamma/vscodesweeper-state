# Issue #214615 — MSYS/Cygwin paths are not supported as terminal links

[https://github.com/microsoft/vscode/issues/214615](https://github.com/microsoft/vscode/issues/214615)

## Summary

Legitimate feature request — MSYS/Cygwin-style paths (e.g. `/d/file`, `/cygdrive/d/file`) are not translated to Windows paths for terminal link detection, and no implementation exists on current main. The related PR was closed because it touched a central component; a terminal-links-scoped approach is still needed.

## Change summary

Terminal links should recognize MSYS (`/d/…`) and Cygwin (`/cygdrive/d/…`) absolute paths on Windows and translate them to native Windows paths for Ctrl-click navigation.

## Best solution

Implement MSYS/Cygwin path translation in the terminal link detection layer (`src/vs/workbench/contrib/terminalContrib/links/`) rather than in the shared `path.ts` module — the original PR was rejected for touching a central component. The translation should handle both `/x/…` and `/cygdrive/x/…` patterns, ideally scoped to Windows terminals running under MSYS/Cygwin shells.
