# Issue #250750 — Search not always searching in open files outside of work folder

[https://github.com/microsoft/vscode/issues/250750](https://github.com/microsoft/vscode/issues/250750)

## Summary

Keep open: current source still omits unresolved out-of-workspace editors from text search. The query includes their resources, but disk text search processes only workspace folder queries; activating each restored tab makes its loaded model searchable.

## Change summary

Search should include pinned files outside the workspace after restart without requiring each tab to be activated.

## Best solution

Ensure text search includes explicitly enumerated out-of-workspace editor resources even when their text models have not been loaded, while preserving filters, result limits, and loaded-model precedence.
