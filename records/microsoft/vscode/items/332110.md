# Issue #332110 — Hover state conflicts with keyboard navigation

[https://github.com/microsoft/vscode/issues/332110](https://github.com/microsoft/vscode/issues/332110)

## Summary

The three highlight states the reporter sees (a prior click-selection, the row moved to by arrow-key focus, and a mouse-hovered row) are independently and deliberately styled in the shared list/tree widget, with hover explicitly suppressed on rows that are already selected or focused — this is intentional, long-standing behavior across every VS Code list/tree, not a defect.

## Change summary

Clicking a folder, then pressing Down, then hovering a different item highlights three rows at once (selection, keyboard focus, and mouse hover), which the reporter finds disorienting.

## Best solution

Keep the current design: selection persists independently of keyboard focus until Enter/click (standard explorer-style keyboard navigation), and hover is a separate, distinctly-colored affordance that CSS already excludes from selected/focused rows (src/vs/base/browser/ui/list/listWidget.ts:970, `:hover:not(.selected):not(.focused)`). If the reporter wants hover disabled entirely, that would need a new opt-out setting, which is a distinct, separate feature request.

  > Thanks for the report. Looking at the list/tree widget code, the three highlights you're seeing are actually three distinct, intentional states: the item you clicked stays "selected" until you click or press Enter elsewhere, the item you moved to with Down becomes keyboard-"focused" (arrow keys move focus without changing selection, similar to classic file-explorer navigation), and the item under your mouse gets a separate hover highlight. The hover style is explicitly written to skip rows that are already selected or focused (see the `:hover:not(.selected):not(.focused)` rule in listWidget.ts), so there's no overlap bug here — this is how every list/tree in VS Code behaves today. If you'd like an option to suppress hover highlighting altogether, that would be a good separate feature request to file.
