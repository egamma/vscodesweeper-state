# Issue #334728 — chat.useCustomizationsInParentRepositories does not discover customizations through Git worktree .git files

[https://github.com/microsoft/vscode/issues/334728](https://github.com/microsoft/vscode/issues/334728)

## Summary

Confirmed on main: findParentRepoFolders() in promptFilesLocator.ts only recognizes a repo root when `.git` is a directory and never resolves a `.git` file's `gitdir:` pointer, so it can never find the real `.git` directory for a git worktree (which lives outside the worktree's ancestor chain entirely). The submodule fix in #332893 doesn't help here since it only continues walking past a `.git` file, and worktrees have no ancestor `.git` directory to walk up to.

## Change summary

chat.useCustomizationsInParentRepositories fails to discover .github/agents, AGENTS.md, and instructions files from the enclosing repo root when the opened folder is a subfolder of a git worktree, because the worktree's `.git` is a pointer file, not a directory, and its target isn't an ancestor path.

## Best solution

Extend findParentRepoFolders() (and the mirrored extensions/copilot/src/platform/promptFiles/vscode-node/agentInstructionsLocator.ts) to detect a `.git` file, parse its `gitdir:` pointer, strip a trailing `/worktrees/<name>` segment to get the common repo's `.git` dir, and use its parent as the repo root — reusing the same resolution approach already implemented in chatContinueInAction.ts.
