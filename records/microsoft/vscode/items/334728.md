# Issue #334728 — chat.useCustomizationsInParentRepositories does not discover customizations through Git worktree .git files

[https://github.com/microsoft/vscode/issues/334728](https://github.com/microsoft/vscode/issues/334728)

## Summary

Confirmed on main: findParentRepoFolders in promptFilesLocator.ts only treats `.git` as a repo root when it is a directory, so worktree checkouts (where `.git` is a gitlink file) never get parent-repository customization discovery. There's already an open fixing PR (#338059) that a maintainer has approved in principle — this should stay open pending that PR landing, not be treated as unfixed work for an agent to pick up.

## Change summary

chat.useCustomizationsInParentRepositories fails to walk up to the repository root when the workspace folder is inside a Git worktree, because the worktree's `.git` is a file (gitdir pointer) rather than a directory.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/338059, which the reporter opened after the maintainer (aeschli) said 'go for it' in the thread; no separate fix is needed once that merges.
