# Issue #334728 — chat.useCustomizationsInParentRepositories does not discover customizations through Git worktree .git files

[https://github.com/microsoft/vscode/issues/334728](https://github.com/microsoft/vscode/issues/334728)

## Summary

The defect remains source-reproducible on current main: both customization locators recognize only `.git` directories, so traversal passes through a linked-worktree `.git` file and never recognizes the worktree root. This is a bounded bug with clear regression-test coverage and should remain open for implementation.

## Change summary

Parent-repository customization discovery omits a Git worktree root when VS Code opens one of its subfolders.

## Best solution

Recognize linked-worktree `.git` files as marking the current folder as a repository root while preserving the existing behavior that traverses through submodule `.git` files, with mirrored regression coverage in the core and Copilot locators.
