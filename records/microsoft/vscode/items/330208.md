# Issue #330208 — Cursor goes white (on white background)

[https://github.com/microsoft/vscode/issues/330208](https://github.com/microsoft/vscode/issues/330208)

## Summary

Real, reproducible rendering glitch (cursor renders white/invisible on light backgrounds) that the reporter and a community commenter narrowed down live in the thread to GPU hardware acceleration — disabling `disable-hardware-acceleration` fixed it immediately, and other GPU-overlay-changing tools (screen recorders, Windows Magnifier) also worked around it. This points to an Electron/Chromium GPU-compositor/hardware-cursor interaction with the AMD Radeon driver stack rather than a bug in VS Code's own cursor-rendering code, so it should be routed to the GPU area rather than closed.

## Change summary
