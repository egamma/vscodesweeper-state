# Issue #85682 — Api for editor insets

[https://github.com/microsoft/vscode/issues/85682](https://github.com/microsoft/vscode/issues/85682)

## Summary

Keep this API-proposal tracking issue open: editor insets remain implemented behind a proposed-API gate, not finalized in the stable extension API. The API owners should decide its future; neither the existing implementation nor its age completes that work.

## Change summary

Finalize an extension API for embedding webview content between lines in ordinary text editors.

## Best solution

Have the API owners settle the supported editor-inset contract and its lifecycle, sizing, and viewport behavior before considering stabilization. Preserve this issue as the finalization tracker rather than treating notebooks or internal view-zone features as equivalent public capabilities.
