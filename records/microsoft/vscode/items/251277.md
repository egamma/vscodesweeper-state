# Issue #251277 — Function of shortcut key of block comment in c/c++ not strong enough

[https://github.com/microsoft/vscode/issues/251277](https://github.com/microsoft/vscode/issues/251277)

## Summary

The requested removal of decorative leading asterisks remains unsupported. Keep this open as an enhancement to block-comment toggling: the current command removes comment delimiters, and no verified canonical covers the additional cleanup.

## Change summary

Make uncommenting a C/C++ block comment remove its decorative per-line asterisk prefixes while preserving content indentation.

## Best solution

Define a conservative recognition rule for decorated C/C++ comment blocks in the editor comment contribution, then support removing recognized decoration without deleting meaningful multiplication, pointer, or other content asterisks.
