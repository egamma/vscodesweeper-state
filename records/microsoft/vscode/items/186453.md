## Change summary

Dismissing authentication-related dialogs while opening a GitHub repository in vscode.dev should not cause the dialogs to alternate indefinitely.

## Best solution

Make cancellation terminate the automatic prompting sequence while clearly explaining that accessing the repository requires GitHub authentication. First reproduce the two-dialog interaction and determine whether renewed requests originate in Remote Repositories or the shared authentication flow; preserve the authentication requirement.
