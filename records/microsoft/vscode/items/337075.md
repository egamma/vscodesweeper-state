# Issue #337075 — GitHub Authentication loop

[https://github.com/microsoft/vscode/issues/337075](https://github.com/microsoft/vscode/issues/337075)

## Summary

Keep open: authentication recovery changed after the reported build, but the available evidence does not establish that this new-window sign-in loop is fixed. The report already supplies concrete steps and detailed logs sufficient to retest without requesting basic reproduction information.

## Change summary

Opening another VS Code window repeatedly requests GitHub sign-in despite successful browser authentication and stored GitHub sessions.

## Best solution

New windows should reuse a usable existing GitHub session without requiring another browser sign-in, while preserving interactive recovery when authentication genuinely cannot be restored. Reproduce this profile's startup flow and distinguish credential rejection from cross-window session replacement before selecting a fix or consolidating reports.
