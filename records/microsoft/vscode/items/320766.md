# Issue #320766 — Risk assessment should not show for `Ùncomitted Changes` prompt

[https://github.com/microsoft/vscode/issues/320766](https://github.com/microsoft/vscode/issues/320766)

## Summary

The defect remains on current main: the pre-agent worktree prompt is rendered as a tool confirmation and unconditionally receives an LLM risk-assessment badge. This team-authored issue should remain open until that app-orchestrated confirmation is distinguished from AI-requested tool actions.

## Change summary

Do not show an AI-generated risk assessment on the Uncommitted Changes prompt displayed before creating an isolated worktree.

## Best solution

Suppress risk assessment for the app-orchestrated modified-files confirmation used by worktree setup, while preserving risk badges for confirmations representing actions selected by an agent or model.
