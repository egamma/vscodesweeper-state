## Summary

Thanks for the request. Hidden Copilot models are currently stored only in profile storage, not in a settings file, so they can't be copied between environments. No existing setting covers this, so it stays open as a feature request.

## Change summary

Persist the list of hidden or disabled Copilot models in a settings file (workspace or user) so it can be copied between environments.

## Best solution

Back model visibility with a real setting, or sync it through Settings Sync. A maintainer should decide the mechanism and scope (user vs. workspace) before anyone implements it.
