# Issue #302259 — Confusing UX when you accidentally add args to `/yolo`

[https://github.com/microsoft/vscode/issues/302259](https://github.com/microsoft/vscode/issues/302259)

## Summary

The confusing behavior remains on current main: `/yolo say hi` executes the silent `/yolo` command while discarding the trailing text without explaining that outcome. This team-authored polish issue should remain open while the intended no-argument command UX is decided.

## Change summary

Make no-argument chat slash commands prevent accidental trailing text or clearly communicate that the command ran and the text was not submitted.

## Best solution

Define consistent behavior for no-argument immediate slash commands such as `/yolo` and `/models`: either reject trailing text before submission or execute the command with clear visible and accessible feedback that the trailing text was ignored.
