# Issue #161815 — Run Above/Below Cells should be disabled while debugging inside of cell

[https://github.com/microsoft/vscode/issues/161815](https://github.com/microsoft/vscode/issues/161815)

## Summary

Still unfixed on main: the Execute Above/Below cell actions' precondition (`executeCondition`) has no debug-state guard, so the buttons remain enabled during notebook cell debugging. Team-authored, Backlog milestone — stays open.

## Change summary

Run Above/Below cell buttons should be disabled while a cell is being debugged to avoid accidental execution.

## Best solution

Add `CONTEXT_IN_DEBUG_MODE.toNegated()` (or a more notebook-specific debug context key) to the `executeCondition` or to the `when` clauses of `ExecuteAboveCells` and `ExecuteCellAndBelow` in `src/vs/workbench/contrib/notebook/browser/controller/executeActions.ts`. As roblourens noted, the tricky part is that notebook debugging is an extension concept — a broader notebook-level debugging context key might be needed.
