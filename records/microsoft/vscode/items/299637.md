  > Foreground Copilot Chat skill loads should be identifiable in exported OTel traces rather than appearing only as ordinary file reads. - **Trace:**

  > ToolsService.invokeTool in extensions/copilot/src/extension/tools/vscode-node/toolsService.ts creates execute_tool spans and calls extractToolParameters with the original tool input. Provider-native Agent Host instrumentation is a separate pipeline and is not established as part of this request.
