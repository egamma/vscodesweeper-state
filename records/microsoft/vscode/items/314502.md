## Summary

Team-authored feature request for adding search/filter to context menus. No implementation exists on main; the menu system (`src/vs/base/browser/ui/menu/menu.ts`) has no search/filter input. Stays open as a valid backlog item.

## Change summary

Add a search/filter input to context menus so users can quickly find commands in long menus.

## Best solution

Implement a type-to-filter or search input in the base menu widget (`src/vs/base/browser/ui/menu/menu.ts`) that narrows visible menu items as the user types, similar to how quick pick filtering works.
