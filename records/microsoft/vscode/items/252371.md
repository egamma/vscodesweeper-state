# Issue #252371 — Copy and paste not working

[https://github.com/microsoft/vscode/issues/252371](https://github.com/microsoft/vscode/issues/252371)

## Summary

Active, high-impact clipboard bug with 107 upvotes, confirmed by multiple users across platforms. A workaround (PR #280300) was merged then reverted due to a double-paste regression; the team acknowledged a proper fix requires moving to the Clipboard API. Recent comments (March–July 2026) confirm the issue persists on current builds. Protected by the `important` label.

## Change summary

Copy/paste randomly stops working in the editor, with `execCommand('copy')` failing silently or producing a 'Contributed command does not exist' error, requiring a window reload to recover.

## Best solution

Implement the Clipboard API migration that the team identified as the proper fix path (replacing the EditContext/execCommand-based clipboard flow). The abstraction layer introduced in commit 91eeae05dd2 ('Abstract CopyPasteController from DOM clipboard APIs') is a step toward this, but the underlying race condition or state corruption in the EditContext copy path remains. The fix likely lives in `src/vs/editor/browser/controller/editContext/clipboardUtils.ts` and `src/vs/editor/contrib/clipboard/browser/clipboard.ts`.
