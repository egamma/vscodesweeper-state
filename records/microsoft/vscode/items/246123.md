# Issue #246123 — Internal HTML links jump to the wrong place after clearing output

[https://github.com/microsoft/vscode/issues/246123](https://github.com/microsoft/vscode/issues/246123)

## Summary

Still reproduces on main: internal markdown anchor links in notebooks jump to wrong positions after clearing outputs because the webview's scroll-to-reveal calculation uses element positions that become stale when output containers are removed but cell container top offsets aren't fully recalculated.

## Change summary

Internal HTML links between notebook markdown cells jump to wrong positions after clearing code cell outputs.

## Best solution

After outputs are cleared, the cell container elements in the webview need their `top` positions updated before anchor link scroll calculations use `getBoundingClientRect()`. The fix likely lives in the `clearOutput` flow in `webviewPreloads.ts` (the `OutputCell.clearOutput` method) or in `backLayerWebView.ts` where a layout update should be triggered post-clear to reposition remaining cells. The `scroll-to-reveal` handler at line ~264 of `webviewPreloads.ts` relies on accurate element positioning.
