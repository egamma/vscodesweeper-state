## Plan brief

- **Likely files:** `extensions/git/package.json`, `extensions/git/src/model.ts`, `src/vs/workbench/contrib/mergeEditor/browser/view/mergeEditor.ts`, `src/vs/workbench/contrib/mergeEditor/browser/view/editors/resultCodeEditorView.ts`, `src/vs/editor/contrib/floatingMenu/browser/floatingMenu.ts`, `src/vs/platform/contextkey/common/contextkey.ts`
- **Validation:** On Windows 11 with empty user-data and extensions directories and git.mergeEditor enabled, open a Git merge conflict and resolve every conflict. Compare 1.141.x, 1.142.0, and current VS Code: Complete Merge should remain visible in the result editor, and clicking it should complete and stage the merge. Verify Ctrl+Enter and the Command Palette command remain functional.
- **Behavior:**

  > A Git merge result editor should display Complete Merge after all conflicts have been handled. The reporter sees zero remaining conflicts but no button in 1.142.0, while 1.141.x displays it for the same repository. Acceptance requires the visible action to complete the merge without changing the existing keyboard or Command Palette completion behavior.
- **Trace:**

  > The visible button is git.acceptMerge contributed through editor/content in extensions/git/package.json, not a button constructed by ResultCodeEditorView. Its visibility depends on isMergeResultEditor, mergeEditorBaseUri, and mergeEditorResultUri membership in git.mergeChanges. ResultCodeEditorView sets the result-editor context; MergeEditor publishes the URI strings; the Git model publishes merge resource URIs after status updates. FloatingEditorToolbar creates a bottom-right overlay only when the menu has actions. These registrations remain present, but source inspection did not establish which predicate or rendering stage fails on the reporter's Windows setup. The earlier Windows membership fix at https://github.com/microsoft/vscode/commit/f0aed5f37d8198a230576a31468e7af602c65c39 predates this regression. Preserve completion, staging, and unresolved-conflict confirmation semantics; diagnose the visibility failure before choosing a bounded change.
