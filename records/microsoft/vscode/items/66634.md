# Issue #66634 — Disable Multiple Cursors

[https://github.com/microsoft/vscode/issues/66634](https://github.com/microsoft/vscode/issues/66634)

## Summary

Implemented and shipped: setting `editor.multiCursorLimit` to `1` prevents an editor from holding multiple cursors, including cursors requested through mouse gestures.

## Change summary

Provide a setting that disables multiple cursors to prevent accidental multi-location edits.

## Best solution

Use the shipped `"editor.multiCursorLimit": 1` setting; commit b954f5061a4cc3b2e23d3d9b1b0179b2105d1aac enforces the limit for every cursor-state update.
