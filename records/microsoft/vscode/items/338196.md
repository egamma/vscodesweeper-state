# Issue #338196 — Window renderer killed by macOS for Mach port exhaustion (EXC_RESOURCE PORTS), still on 1.139.1

[https://github.com/microsoft/vscode/issues/338196](https://github.com/microsoft/vscode/issues/338196)

## Summary

Thanks for the detailed report. Several users have confirmed it, including on 1.141.0 (a comment from 2026-10-13). The kill signature is consistent: the renderer hits macOS's Mach port limit of about 267.9k ports. The trigger isn't pinned down, though. A Windows commenter points at an extension flooding console.* output to the renderer. I could not verify this by running anything, and I found no cited fix commit or older canonical issue with the same symptom, so this stays open.

## Change summary

The window renderer is killed by macOS (EXC_RESOURCE PORTS, SIGKILL) after Mach port exhaustion during long Claude Code extension sessions.

## Best solution

Identify which renderer-side IPC path allocates ports in bursts, most likely extension-host-to-renderer messaging such as console.* forwarding, and then bound or throttle it. A maintainer would first need an extension host profile or a minimal repro from an affected session.
