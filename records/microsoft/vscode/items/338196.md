## Summary

Detailed, well-diagnosed report of a window renderer being killed by macOS for Mach port exhaustion during long Claude Code agent sessions, but no confirmed root cause in VS Code's own code — a commenter's Windows analog points to a third-party extension (`growthjack.claude-code-usage`) flooding the renderer via `console.warn` forwarding, which this reporter hasn't confirmed is present.
