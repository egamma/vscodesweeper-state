# Issue #290686 — Command Center foreground theme colors not applied correctly.

[https://github.com/microsoft/vscode/issues/290686](https://github.com/microsoft/vscode/issues/290686)

## Summary

The reported foreground mismatches remain directly traceable in current main: inactive Command Center text and search icons use the title-bar token, while the search icon retains its resting color on hover. Keep this open for a bounded theming correction.

## Change summary

Honor Command Center foreground customization consistently for text and search icons in inactive-window and hover states.

## Best solution

Make the Command Center search control respect its registered foreground tokens consistently: inactive-window text and icons use commandCenter.inactiveForeground, and active-window hover text and icons use commandCenter.activeForeground. Preserve unrelated title-bar controls, border behavior, and default theme fallbacks.
