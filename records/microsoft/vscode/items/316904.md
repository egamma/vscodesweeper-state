# Issue #316904 — AgentHost: Unnecessary tool details

[https://github.com/microsoft/vscode/issues/316904](https://github.com/microsoft/vscode/issues/316904)

## Summary

Still reproduces on main: agent host tool calls like `read_file` show expanded parameter details unnecessarily. The fallback paths in `stateToProgressAdapter.ts` attach `toolSpecificData: { kind: 'input' }` or generate `resultDetails` with full input/output for any tool that isn't terminal/search/subagent/mcpApp, causing the collapsible input/output widget to render parameters the user doesn't need to see.

## Change summary

Agent host tool calls (e.g. `read_file`) unnecessarily show expanded tool parameters/input details in the chat UI.

## Best solution

Add logic to suppress the input/output details for tools that don't benefit from showing parameters (like `read_file`). This likely involves gating the `toolSpecificData: { kind: 'input' }` assignment and `getToolInputOutputDetails` call in `stateToProgressAdapter.ts` — either by checking a tool-level opt-in/opt-out flag, or by suppressing the detail rendering for known simple tools that only need a one-line status message.
