# Issue #324145 — Wrong tool used in chat input when multiple MCP servers expose the same tool name

[https://github.com/microsoft/vscode/issues/324145](https://github.com/microsoft/vscode/issues/324145)

## Summary

The collision remains reproducible from current source: chat completions discard the selected tool's server identity, and the parser resolves identical names to whichever enabled tool was registered last. Keep this open; prompt-file qualification does not fix the chat-input path.

## Change summary

Preserve the selected MCP server's tool identity when chat-input completions contain tools with identical names.

## Best solution

Selecting either same-name tool in chat input should resolve to that exact tool ID, independent of tool registration order. Bring chat-input references into line with the existing qualified-reference capability while preserving unambiguous references and tool-set behavior.
