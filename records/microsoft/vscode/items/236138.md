# Issue #236138 — Incorrect indentation for TypeScript opening curly brace

[https://github.com/microsoft/vscode/issues/236138](https://github.com/microsoft/vscode/issues/236138)

## Summary

The extra indentation remains reproducible from current source when Enter moves an existing opening brace after an if condition or arrow function. The linked fix attempt was closed without merging; its maintainer feedback establishes a TypeScript/JavaScript-local solution rather than changing indentation for every language.

## Change summary

Pressing Enter immediately before an existing TypeScript opening curly brace should align it with its controlling statement instead of adding an indentation level.

## Best solution

Correct the TypeScript and JavaScript Enter behavior locally, preserving indentation for braceless statements and other languages, as requested in the review of the closed fix attempt.
