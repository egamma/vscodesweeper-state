# Issue #330591 — Agent Host (Codex Agent Harness) should discover and expose workspace customizations

[https://github.com/microsoft/vscode/issues/330591](https://github.com/microsoft/vscode/issues/330591)

## Summary

Fresh, well-scoped follow-up from the author's own recent PR (#330590) removing client→host customization sync; traced the cited code paths on main and they match the described gap, so this is a real, actionable engineering task, not something to close.

## Change summary

The Codex Agent Host needs to natively discover workspace customizations (custom agents/.agent.md, skills, hooks, MCP) and expose them via the Customizations surface, since the client no longer pushes them after PR #330590.

## Best solution

Implement host-side workspace `.agent.md` agent discovery in src/vs/platform/agentHost/node/codex/codexAgent.ts (currently `config.agents` is populated only from client-pushed roles around line 1488) and project the results into `DirectoryCustomization` containers in codexCustomizations.ts alongside the existing skills/hooks discovery, mirroring how Copilot Agent exposes customizations.
