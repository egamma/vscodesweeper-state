# Issue #191629 — Consider a keyboard shortcut for changing quick chat size

[https://github.com/microsoft/vscode/issues/191629](https://github.com/microsoft/vscode/issues/191629)

## Summary

Quick Chat still lacks keyboard-operated sizing: its explicit resize path is a pointer-driven sash, and existing view-size commands do not target this overlay. Keep the accepted Backlog request open for an accessibility-focused design decision.

## Change summary

Provide keyboard shortcuts to grow and shrink Quick Chat without using a mouse.

## Best solution

Make Quick Chat height adjustable through keyboard-invokable actions, preserving focus and existing size limits. Agree on default shortcuts and document the interaction in Quick Chat accessibility help.
