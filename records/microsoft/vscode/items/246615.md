# Issue #246615 — Add setting to disable punctuation and capitalization

[https://github.com/microsoft/vscode/issues/246615](https://github.com/microsoft/vscode/issues/246615)

## Summary

A real gap remains for VS Code Speech provider sessions: current core options expose only language, not punctuation, capitalization, or pause thresholds. The issue is already accepted into the Backlog and is the strongest canonical report.

## Change summary

Allow users to disable automatic punctuation and capitalization, or adjust the pause threshold, during speech dictation.

## Best solution

Expose a provider-independent dictation formatting option and pass it through the speech-session API so VS Code Speech can disable automatic punctuation/capitalization or adjust segmentation. The newer on-device cleanup toggle should remain available but does not replace provider-level control.
