## Change summary

Add an opt-in option to showTextDocument so an extension can reveal a document, including bringing a background tab to the front, without expanding or restoring its editor group and without moving focus.

## Best solution

A maintainer or API owner should decide whether this belongs as a new opt-in option, for example on TextDocumentShowOptions or an EditorActivation-style value that suppresses group restore. The existing preserveFocus default must stay unchanged. Check how EditorActivation.RESTORE is currently plumbed through the extension host and the editor service before settling on a shape.
