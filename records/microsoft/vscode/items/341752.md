# Issue #341752 — API: Allow revealing a text document without expanding its editor group while preserving focus

[https://github.com/microsoft/vscode/issues/341752](https://github.com/microsoft/vscode/issues/341752)

## Summary

A supported per-operation opt-out remains missing: preserveFocus intentionally restores minimized groups. Keep this request open for API-owner consideration; the related focus-driven resizing request does not cover the same observable behavior.

## Change summary

Allow extensions to reveal a foreground or background text tab while preserving keyboard focus and existing editor group dimensions.

## Best solution

Provide an explicitly opt-in public reveal capability that preserves group layout while selecting and revealing source locations, without changing existing preserveFocus defaults. API owners should decide whether this warrants a new option or a separate operation.
