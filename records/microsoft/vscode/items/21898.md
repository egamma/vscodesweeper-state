# Issue #21898 — Outline matching selections instead of highlight

[https://github.com/microsoft/vscode/issues/21898](https://github.com/microsoft/vscode/issues/21898)

## Summary

A meaningful gap remains: matching occurrences can have a configurable border, but the active editor selection still cannot. This 42-upvote Backlog request is the established canonical issue and should remain open.

## Change summary

Allow active selections to use a distinct outline and provide clearer control over case-sensitive selection matching.

## Best solution

Add an active-selection border theme color, rendered by the editor selections layer without changing existing selection backgrounds. Consider whether selection-highlight case sensitivity needs an explicit editor setting rather than relying on the Find widget's Match Case state.
