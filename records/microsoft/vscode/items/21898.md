# Issue #21898 — Outline matching selections instead of highlight

[https://github.com/microsoft/vscode/issues/21898](https://github.com/microsoft/vscode/issues/21898)

## Summary

Existing settings cover outlining matching occurrences, disabling selection-match highlighting, and case-sensitive matching, but not a supported border for the actual selection. Keep this accepted, well-supported request open for that remaining distinction.

## Change summary

Make actual selections clearly distinguishable from matching occurrences through supported outline styling and matching controls.

## Best solution

Provide theme-integrated outlining for actual selected regions, with correct multiline and multiple-selection geometry. Reuse the existing matching and highlight controls rather than adding overlapping settings; a maintainer should settle whether selection outlines are opt-in or enabled by default.
