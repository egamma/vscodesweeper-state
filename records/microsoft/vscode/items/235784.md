# Issue #235784 — "Clear All Output" is greyed out and doesn't clear execution count unless output is available

[https://github.com/microsoft/vscode/issues/235784](https://github.com/microsoft/vscode/issues/235784)

## Summary

Still present on main: the "Clear All Outputs" button precondition (`NOTEBOOK_HAS_OUTPUTS`) only checks for actual rendered outputs, not execution counts. Cells with execution counts but no output cannot trigger the clear action.

## Change summary

"Clear All Outputs" should be enabled when cells have execution counts even if they have no rendered output, so users can clear execution metadata for version control cleanliness.

## Best solution

Extend the `NOTEBOOK_HAS_OUTPUTS` context key (or create a companion key) in `notebookEditorWidgetContextKeys.ts` to also check whether any cell has a non-null `executionOrder` in its internal metadata, and update the precondition on `ClearAllCellOutputsAction` accordingly. This enables the button when there's execution state to clear.
