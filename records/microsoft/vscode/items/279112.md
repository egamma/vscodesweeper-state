# Issue #279112 — GitHub Copilot Chat incorrectly includes model enablement text in chat history

[https://github.com/microsoft/vscode/issues/279112](https://github.com/microsoft/vscode/issues/279112)

## Summary

The faulty inline model-policy confirmation path was removed after this report, and current main no longer creates the enablement confirmation or replaces the user's prompt with its saved confirmation data.

## Change summary

Enabling a previously unused Copilot model could insert the model-enablement text into the conversation as though the user had authored it.

## Best solution

Keep the removal from commit 5dc2d157a8d4c1f7ef7851c2bbc96c77d7ac9b76; model enablement should remain outside the participant prompt and conversation history.
