# Issue #305570 — Sessions: Unmatched brackets are highlighted red

[https://github.com/microsoft/vscode/issues/305570](https://github.com/microsoft/vscode/issues/305570)

## Summary

Still reproduces on main: the Sessions chat input editor does not disable bracket pair colorization, so unmatched brackets are highlighted red — unlike the regular chat input which explicitly sets `bracketPairColorization: { enabled: false }`.

## Change summary

Unmatched brackets in the Sessions (Agents window) chat input are highlighted red due to bracket pair colorization being active.

## Best solution

Add `bracketPairColorization: { enabled: false }` to the editor options in `src/vs/sessions/contrib/chat/browser/newChatInput.ts` (around line 472), matching what the regular chat input does in `chatInputPart.ts` at line 3248.
