# Issue #198287 — Add terminal highlighting support

[https://github.com/microsoft/vscode/issues/198287](https://github.com/microsoft/vscode/issues/198287)

## Summary

This remains an accepted Backlog feature request with 24 community upvotes. Current main provides transient find-result highlighting but no configurable persistent keyword highlighting, so a meaningful gap remains.

## Change summary

Add optional terminal output highlighting based on built-in and user-configured regular expressions.

## Best solution

Implement opt-in keyword decorations in the terminal renderer while defining precedence that preserves application-emitted ANSI colors. The terminal team should determine whether this belongs in core configuration or requires a new extension API.

## Vision fit

- **Fit:** unclear
- **Reason:** Highlighting important terminal output supports the developer inner loop, but regex-specific styling configuration adds customization and potential rendering overhead that cuts against uniform UI and performance guardrails.
- **Evidence:** Durable theme: developer inner loop. Values: “Performance trumps functionality” and “Simple, uniform UI and UI interactions.”
