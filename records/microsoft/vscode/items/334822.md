# Issue #334822 — Chat agent: prepareToolInvocation crashes with "Cannot read properties of undefined (reading 'replace')" when the model emits nested/malformed tool arguments

[https://github.com/microsoft/vscode/issues/334822](https://github.com/microsoft/vscode/issues/334822)

## Summary

Keep open and route to terminal chat tools: current source still passes a missing command into string-processing code without validating the model's arguments. This is a core tool-preparation defect, not an application-process crash or grounds for blaming the provider extension.

## Change summary

Reject malformed run_in_terminal arguments with an actionable tool error instead of throwing a string-method TypeError during preparation.

## Best solution

Malformed terminal-tool inputs should fail before command preparation or execution, with a clear error the model can use to correct its arguments. Preserve valid commands and existing confirmation behavior; do not silently unwrap nested arguments or execute an inferred command.
