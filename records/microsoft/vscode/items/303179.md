# Issue #303179 — FileSystemWatcher fires 2 onCreate and 2 onDelete events

[https://github.com/microsoft/vscode/issues/303179](https://github.com/microsoft/vscode/issues/303179)

## Summary

Confirmed current bug: overlapping recursive and non-recursive watchers can deliver duplicate matching events to extensions. Route it to the file-watcher area for a correlation-based fix.

## Change summary

Prevent FileSystemWatcher from emitting duplicate create and delete events when another VS Code service watches the same directory.

## Best solution

Use internally correlated delivery for extension-created relative-pattern watchers so each watcher receives only events from its own subscription, with regression coverage for overlapping workspace and `.vscode` watchers.
