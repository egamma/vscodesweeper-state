- **Trace:**

  > External CLI sessions are now excluded by CopilotCLISessionService and surfaced through Agent Host, so the original extension-host path cannot be assumed to remain current. CopilotAgent.chats.getMessages delegates to _getChatMessages in src/vs/platform/agentHost/node/copilot/copilotAgent.ts, which resolves a provider entry and reads its messages. The uncertainty starts at how the current Copilot SDK observes writes from a simultaneously running terminal client and whether reopening still refreshes that backing. The younger sidebar report https://github.com/microsoft/vscode/issues/327639 and discovery report https://github.com/microsoft/vscode/issues/335215 are related but not duplicate targets.
