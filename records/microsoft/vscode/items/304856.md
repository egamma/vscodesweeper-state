# Issue #304856 — Github Copilot Chat is not live-updated with integrated terminal with Github Copilot CLI

[https://github.com/microsoft/vscode/issues/304856](https://github.com/microsoft/vscode/issues/304856)

## Summary

Legitimate report about Copilot CLI sessions not live-updating in the chat panel — the area is under active development (sessions controller API migration tracked in #288457), labels are correctly applied, and no fix commit was found on main. Keeping open for the team to address.

## Change summary

When a Copilot CLI session runs in the integrated terminal, the corresponding chat session in the VS Code chat panel does not auto-refresh — the user must switch away and back to see updates.

## Best solution

The sessions infrastructure already uses observables (`updatedAt`, `_status`, etc. in `copilotChatSessionsProvider.ts`), so the likely gap is that the chat panel widget doesn't subscribe to change events from the CLI-originated session. The fix likely lives in the chat panel's session rendering or in how CLI session updates are propagated to the `ICopilotChatSession` observable properties. Related tracking: https://github.com/microsoft/vscode/issues/288457 (adopting the controller-based API for Copilot CLI sessions) may address this as a side effect.
