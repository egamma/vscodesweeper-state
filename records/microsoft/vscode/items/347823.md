# Issue #347823 — Unable to load your organization's manage

[https://github.com/microsoft/vscode/issues/347823](https://github.com/microsoft/vscode/issues/347823)

## Summary

Keep open: multiple reporters confirm a Snap-specific Copilot harness regression caused by incompatible host OpenSSL and core20 libc libraries. The failure extends beyond managed settings, and neither a fixing commit nor a verified same-symptom canonical was found.

## Change summary

Copilot harness requests fail in the Linux Snap installation when native certificate parsing loads host libcrypto.so.3 against incompatible core20 libc.

## Best solution

Restore compatible native certificate loading for the Copilot runtime in the Snap distribution, covering managed settings, model discovery, and built-in GitHub MCP requests. Establish whether packaging or runtime library selection owns the correction without bypassing TLS validation or managed policy.
