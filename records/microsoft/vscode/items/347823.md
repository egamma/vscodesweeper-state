# Issue #347823 — Unable to load your organization's manage

[https://github.com/microsoft/vscode/issues/347823](https://github.com/microsoft/vscode/issues/347823)

## Summary

Keep open: multiple users confirm that native OpenSSL loading fails under Snap and blocks Copilot managed-settings resolution. Current source retains the core20 packaging boundary; no verified fix or matching canonical was found.

## Change summary

Restore Copilot access when Snap's core20 libc cannot load the host's OpenSSL 3 library.

## Best solution

Establish a compatible native certificate-loading path for the bundled Copilot runtime under Snap, coordinating packaging and runtime ownership. Preserve certificate verification and managed-settings enforcement rather than bypassing either to restore access.
