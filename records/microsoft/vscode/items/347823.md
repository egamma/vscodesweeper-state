# Issue #347823 — Unable to load your organization's manage

[https://github.com/microsoft/vscode/issues/347823](https://github.com/microsoft/vscode/issues/347823)

## Summary

Keep open for the assigned 1.147.0 milestone. Multiple confirmations and maintainer diagnosis identify a Copilot SDK native-library incompatibility in the Snap build; the latest maintainer direction is to prevent SDK loading of incompatible host crypto libraries.

## Change summary

Restore Copilot harness operation in the Linux Snap package when host OpenSSL requires a newer glibc than core20 provides.

## Best solution

Resolve the SDK's host-crypto dependency incompatibility and adopt the corrected runtime in VS Code, then verify managed settings, model listing, and built-in GitHub MCP operation in the packaged Snap. Preserve compatible library loading rather than applying the rejected interpreter/RPATH exemption.
