# Issue #347823 — Unable to load your organization's manage

[https://github.com/microsoft/vscode/issues/347823](https://github.com/microsoft/vscode/issues/347823)

## Summary

Keep open: multiple users confirm that a native-library incompatibility blocks Copilot in Linux Snap installations. Switching to the .deb package reportedly works, but does not resolve the supported Snap installation's failure.

## Change summary

Copilot managed-settings resolution fails when host OpenSSL 3 requires a newer glibc than the Snap core20 environment provides.

## Best solution

Restore compatible native certificate loading for Copilot in Snap installations. Establish whether the incompatibility needs correction in VS Code packaging or the bundled runtime's library loading, without bypassing certificate verification or managed-settings enforcement.
