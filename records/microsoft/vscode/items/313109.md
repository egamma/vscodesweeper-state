# Issue #313109 — Error during VS Code Insiders installation: “Visual Studio Code - Insiders.app” is damaged and can’t be opened. You should move it to the Bin.

[https://github.com/microsoft/vscode/issues/313109](https://github.com/microsoft/vscode/issues/313109)

## Summary

Real, confirmed bug: macOS Insiders builds lack a stapled notarization ticket, causing Gatekeeper to report the app as 'damaged' when the online lookup fails. The fix PR (#313905) is open but unmerged, and users are still hitting this as of June 2026.

## Change summary

macOS Insiders .app/.dmg downloads are rejected by Gatekeeper as 'damaged' because the notarization ticket is not stapled onto the signed artifacts.

## Best solution

Land the stapling step in the macOS build pipeline (PR https://github.com/microsoft/vscode/pull/313905 or equivalent) so that `xcrun stapler staple` runs after notarization, eliminating the online-lookup dependency that causes Gatekeeper failures.
