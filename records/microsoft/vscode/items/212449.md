# Issue #212449 — Pty Host Issue since latest update (VSCode 1.89.1), SSH and Remote development functionality is broken

[https://github.com/microsoft/vscode/issues/212449](https://github.com/microsoft/vscode/issues/212449)

## Summary

Keep open: several users confirm that reinstalling the remote server restores connectivity, with another occurrence reported in February 2026. This supports an installation-integrity problem, but neither its cause nor a concrete fixing commit is established; the workaround is not proof of resolution.

## Change summary

Remote server startup fails when bootstrap-fork.js cannot load a required bootstrap module, exhausting PTY-host restarts and breaking remote development.

## Best solution

Establish how the remote server installation loses or mismatches its bootstrap files, then prevent that condition or recover from it without requiring deletion of the entire .vscode-server directory. Investigate the server installation/cache lifecycle before treating this as a terminal-process defect.
