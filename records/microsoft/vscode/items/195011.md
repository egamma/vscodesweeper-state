# Issue #195011 — Language specific settings for ipynb (jupyter-notebook) files [feature-request].

[https://github.com/microsoft/vscode/issues/195011](https://github.com/microsoft/vscode/issues/195011)

## Summary

The broader request for notebook-type-based language settings overrides (e.g. `[jupyter-notebook]` blocks in settings.json) remains unimplemented. The `notebook.insertFinalNewline` setting addressed one specific pain point, but the general feature request is still valid and has strong community support (48 upvotes, Backlog milestone).

## Change summary

Allow language-specific settings overrides for notebook types (e.g. `[jupyter-notebook]`) so users can configure editor behavior per-notebook-type in settings.json.

## Best solution

Implement notebook-type-based configuration overrides in the settings model, analogous to existing language overrides like `[python]`. This likely requires work in `src/vs/platform/configuration/` to recognize notebook document types as valid override identifiers, plus coordination with the notebook editor's cell-level configuration resolution.
