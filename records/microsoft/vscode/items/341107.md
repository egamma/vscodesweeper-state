# Issue #341107 — Markdown editor: Enter on an empty list item before a paragraph merges the next text into that paragraph

[https://github.com/microsoft/vscode/issues/341107](https://github.com/microsoft/vscode/issues/341107)

I could not locate the Markdown Editor sources in this checkout, so I could not confirm the defect from source. It stays open with the existing area label.

## Change summary

Pressing Enter twice on a list item before a paragraph in the Markdown Editor leaves the caret in the next block instead of a new paragraph between them.

## Best solution

After the empty list item is removed, the Markdown Editor should insert a new empty paragraph between the list and the following block and place the caret there, for bullet and task lists, including before a heading.
