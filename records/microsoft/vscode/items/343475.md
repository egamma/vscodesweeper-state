# Issue #343475 — Feature Request: Add hooks for confirmation prompt and response-received events in VS Code Copilot Agent

[https://github.com/microsoft/vscode/issues/343475](https://github.com/microsoft/vscode/issues/343475)

## Summary

The requested notification-gated script hooks remain missing from the inspected source. An existing open notification-hook PR is relevant, but its documented scope does not establish coverage of both requested events and their notification-setting semantics.

## Change summary

Allow custom scripts to run when confirmation or response notifications would fire, respecting each notification setting's always, windowNotFocused, and off modes.

## Best solution

Evaluate https://github.com/microsoft/vscode/pull/322839 against both requested notification moments and the existing focus/configuration gates before pursuing another implementation. Preserve this issue's explicit requirement that scripts run only when the corresponding OS notification would fire.
