# Issue #15135 — Remember undo history on hot-exit

[https://github.com/microsoft/vscode/issues/15135](https://github.com/microsoft/vscode/issues/15135)

## Summary

Keep open: this team-authored Backlog request remains unimplemented, has 41 community upvotes, and serves as the canonical issue for preserving undo history across hot-exit restarts.

## Change summary

Persist editor undo/redo history across hot-exit restarts and crashes.

## Best solution

Serialize bounded undo/redo state into hot-exit storage and restore it after restart when the file content still matches. This likely depends on the editor-level serialization tracked by https://github.com/microsoft/vscode/issues/7536 and must preserve performance and storage limits.

- **existing setting:** The `files.restoreUndoStack` setting in src/vs/workbench/contrib/files/browser/files.contribution.ts controls reopening files within the current process; it does not implement persistence across hot-exit restarts.
