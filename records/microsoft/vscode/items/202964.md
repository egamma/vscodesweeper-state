# Issue #202964 — Dynamic softwrap margin whilst retaining horizontal scroll.

[https://github.com/microsoft/vscode/issues/202964](https://github.com/microsoft/vscode/issues/202964)

## Summary

A real editor-wrapping capability gap remains: current wrap modes cannot vary the wrap column by each line's leading indentation while retaining buffer-wide horizontal scrolling. Route this to the editor-wrapping area for a product decision and keep it under discussion rather than closing it for age.

## Change summary

Add soft wrapping whose per-line width excludes leading indentation while preserving horizontal scrolling across the editor.

## Best solution

The editor-wrapping owners should decide whether the wrapping model should support a per-line effective column and horizontal extent independent of wrapping. If accepted, the behavior should integrate with the existing `editor.wordWrap`, `editor.wordWrapColumn`, and `editor.wrappingIndent` model rather than introduce a separate wrapping system.

## Evidence

- **current capability:** In `src/vs/editor/common/config/editorOptions.ts`, `editor.wordWrap` supports only `off`, `on`, `wordWrapColumn`, and `bounded`; the computed wrapping column is either viewport-based or one fixed `editor.wordWrapColumn`, not a per-line column offset by leading whitespace.
- **remaining gap:** `editor.wrappingIndent` controls indentation of continuation lines, but it does not make the available wrap width constant after each source line's leading indentation or preserve horizontal scrolling as an independent behavior.
- **related request:** https://github.com/microsoft/vscode/issues/312719 is open but asks only for a fixed continuation indent, so it does not own this request's dynamic wrap-width and horizontal-scroll requirements.
- **scope precedent:** https://github.com/microsoft/vscode/issues/202975 was declined because it asked VS Code to reproduce language-formatter output. That decision does not cover this editor-layout-only request, so it is not sufficient precedent for an out-of-scope close.
