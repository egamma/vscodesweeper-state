# Issue #312572 — Auto-detect language mode fails with LICENSE file without extension

[https://github.com/microsoft/vscode/issues/312572](https://github.com/microsoft/vscode/issues/312572)

## Summary

Keep open: the reporter confirmed that an extensionless MIT LICENSE file is still misclassified as Markdown in a fresh workspace on 1.131.0. The current source still sends such files through content-based detection, and neither a concrete fix nor a canonical meeting the re-review duplicate bar was established.

## Change summary

Opening a plain-text, extensionless LICENSE file selects Markdown and triggers an inapplicable markdownlint MD041 diagnostic.

## Best solution

Make automatic language detection preserve Plain Text for the reported license content while retaining detection for genuine Markdown and extensionless source files. First isolate whether the incorrect result comes from model inference, history-based detection, or VS Code's result-selection logic.
