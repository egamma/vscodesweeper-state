# Issue #158254 — Allow not automatically saving files when running a test

[https://github.com/microsoft/vscode/issues/158254](https://github.com/microsoft/vscode/issues/158254)

## Summary

Keep open: testing.saveBeforeTest lets users disable saving globally, but does not provide the requested extension-controlled, per-profile behavior. An open implementation candidate already references this issue and needs maintainer review.

## Change summary

Allow a testing extension to opt an individual TestRunProfile out of automatically saving dirty files before execution.

## Best solution

Provide a supported per-profile save policy while preserving existing behavior for other profiles. Review https://github.com/microsoft/vscode/pull/190427 against the current testing API before pursuing another implementation.
