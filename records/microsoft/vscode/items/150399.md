# Issue #150399 — Push users to file issues on extensions

[https://github.com/microsoft/vscode/issues/150399](https://github.com/microsoft/vscode/issues/150399)

## Summary

Keep open: the redesigned issue reporter offers an extension target, but its description guidance still does not remind users to select it for extension issues. This team-authored Backlog request has neither a verified duplicate nor an explicitly linked implementation that supports closing it.

## Change summary

Add a contextual reminder directing extension-related reports to the issue reporter's extension target.

## Best solution

Provide concise extension-routing guidance beside the description field in the current issue reporter, preserving the existing target selection and built-in extension routing. Treat automatic attachment of extension logs, suggested in the comment, as a separate enhancement.
