# Issue #335279 — Put `@devcontainers/cli` to remote/package.json

[https://github.com/microsoft/vscode/issues/335279](https://github.com/microsoft/vscode/issues/335279)

## Summary

Genuine, unaddressed packaging task: `@devcontainers/cli` is currently only in the root `package.json` (used for the desktop/asar build), not in `remote/package.json`, so it's missing from the server (reh) build's dependency set as requested.

## Change summary

Add `@devcontainers/cli` as a dependency in `remote/package.json` so it's included in the server build, not just the desktop build.

## Best solution

Add `"@devcontainers/cli": "0.88.0"` (matching the version pinned in the root `package.json`) to `remote/package.json`'s dependencies and regenerate the corresponding lockfile so the reh/server build carries the same devcontainers CLI the desktop build already unpacks in `build/gulpfile.vscode.ts` (`**/@devcontainers/cli/**`).
