# Issue #295256 — Power save block on active chat session should have an indicator

[https://github.com/microsoft/vscode/issues/295256](https://github.com/microsoft/vscode/issues/295256)

## Summary

Team-authored request for a UI indicator when VS Code is actively blocking system sleep (power save blocker). The power save blocking infrastructure exists (IPowerService, Copilot chat integration via de441dc1784), but no user-facing indicator has been implemented. Keeping open as a valid feature request.

## Change summary

Add a visible indicator (e.g. status bar item) when VS Code is actively blocking system power save / sleep, so users can identify which window is preventing sleep.

## Best solution

Add a status bar indicator (or similar UI surface) that appears when a power save blocker is active, showing which window/feature is preventing system sleep. The indicator should likely live in the workbench layer, consuming `IPowerService.isPowerSaveBlockerStarted()` or a new event for active blocker state changes. Similar to how browsers show a speaker icon on tabs playing audio.
