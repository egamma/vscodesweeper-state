# Issue #311901 — Missing macOS activity declaration causes agent to fail

[https://github.com/microsoft/vscode/issues/311901](https://github.com/microsoft/vscode/issues/311901)

## Summary

Already implemented: VS Code now has a power save blocker API (`environmentPower` proposed API) and the Copilot extension actively acquires a power save blocker during chat/agent requests to prevent macOS sleep. This shipped in 1.116.0, the version the reporter is on.

## Change summary

Request macOS activity declarations to prevent system sleep from interrupting long-running agent tasks.

## Best solution

Keep the shipped implementation — the `PowerService` in the Copilot extension acquires a power save blocker via the `environmentPower` proposed API during chat requests (commit de441dc1784). The reporter should update to the latest stable (1.119.0) and verify the blocker is active; the feature is experiment-gated via `ChatRequestPowerSaveBlocker`, which may explain why they didn't see it on 1.116.0.
