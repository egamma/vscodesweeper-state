The older, open sleep-prevention request covers the same observable failure: automatic system sleep interrupts a running agent with network errors. Consolidate this macOS report there; existing request-level power blocking does not establish that the entire agent activity is protected.

Prevent automatic macOS system sleep while a long-running agent activity is working so it can complete without sleep-induced network failures.
