# Issue #320926 — JSON Schema format for defining tools does not conform to OpenAI's specification

[https://github.com/microsoft/vscode/issues/320926](https://github.com/microsoft/vscode/issues/320926)

## Summary

Confirmed in source: the BYOK `interceptBody` in `openAIEndpoint.ts` only normalizes empty `parameters` for Chat Completions tools (`OpenAiFunctionTool` with nested `.function`), not for Responses API tools (`OpenAiResponsesFunctionTool` with flat schema). Custom endpoints using the Responses API send tools with `parameters: undefined` (or `{}`) instead of `{"type": "object", "properties": {}}`, which strict OpenAI-compatible providers reject.

## Change summary

Custom endpoint BYOK tools with no parameters fail on OpenAI-compatible Responses API providers because the tool schema is not normalized to a valid JSON Schema object.

## Best solution

Extend the `interceptBody` logic in `extensions/copilot/src/extension/byok/node/openAIEndpoint.ts` to also handle `OpenAiResponsesFunctionTool` (flat format): when `tool.parameters` is `undefined` or an empty object (`{}`), set it to `{ type: 'object', properties: {} }`. The same normalization should also cover the empty-object case for `OpenAiFunctionTool`.
