# Issue #303879 — Sessions App: Need a way to snooze inline suggestions

[https://github.com/microsoft/vscode/issues/303879](https://github.com/microsoft/vscode/issues/303879)

## Summary

Still open: the Sessions app brought over the Copilot status dashboard but explicitly sets `disableCompletionsSnooze: true`, so users still cannot snooze inline suggestions. The underlying capability exists in the shared dashboard component but is intentionally gated off in the Sessions window.

## Change summary

Provide a way to snooze inline completions in the Sessions (Agents) window, which currently lacks the UI controls available in VS Code proper.

## Best solution

Remove or conditionalize the `disableCompletionsSnooze: true` flag in `src/vs/sessions/contrib/accountMenu/browser/account.contribution.ts` (both call sites at lines ~580 and ~649), enabling the snooze UI that the shared `ChatStatusDashboard` already supports. The team should decide whether the Sessions app's lack of a status bar requires any UX adaptation for the snooze toggle.
