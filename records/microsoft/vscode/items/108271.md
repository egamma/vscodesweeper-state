# Issue #108271 — Add an explorer/title menu contribution point

[https://github.com/microsoft/vscode/issues/108271](https://github.com/microsoft/vscode/issues/108271)

## Summary

The request is partially addressed: a proposed `viewContainer/title` menu contribution point exists (commit 2b8881a7fd2, July 2024), but it is still proposed (not finalized) and currently restricted to the debug view container only — extensions cannot yet contribute to the Explorer's title menu. The issue's central ask remains unmet. With 60 upvotes and an On Deck milestone, this should stay open.

## Change summary

Allow extensions to contribute commands to the Explorer's title bar menu via a menu contribution point.

## Best solution

Finalize the proposed `contribViewContainerTitle` API and remove the debug-only restriction so extensions can contribute to the Explorer title menu (and other view containers). The machinery is already in place in `src/vs/workbench/services/actions/common/menusExtensionPoint.ts` — the guard that rejects non-debug `viewContainer/title` contributions needs to be relaxed, and the proposal needs to graduate from proposed to stable.
