# Issue #8050 — additional options for `editor.selectionHighlight` 

[https://github.com/microsoft/vscode/issues/8050](https://github.com/microsoft/vscode/issues/8050)

## Summary

A meaningful configuration gap remains on main: selection highlighting can be disabled, length-limited, or influenced by Find options, but it has no persistent mode for whole-word, identifier-only, or keyword-excluding matches. Keep this Backlog request open for product discussion.

## Change summary

Add finer controls over which selected text produces matching highlights, including whole-word and language-aware filtering.

## Best solution

Avoid several independent booleans; consider one selection-highlight matching mode in `editorOptions.ts` and `SelectionHighlighter` covering substring versus whole-word behavior. Language-aware identifier or keyword filtering should only be included if it can use existing semantic providers consistently across languages.
