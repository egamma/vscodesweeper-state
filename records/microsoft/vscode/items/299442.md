# Issue #299442 — Terminal font broken on latest stable

[https://github.com/microsoft/vscode/issues/299442](https://github.com/microsoft/vscode/issues/299442)

## Summary

Keep open: image support still forces the terminal's transparency rendering path, and the discussion confirms degraded text rendering on macOS light themes. An open PR explicitly targets this issue; review that implementation before considering closure.

## Change summary

Enabling terminal images changes font weight and text contrast, making light-theme terminal text difficult to read.

## Best solution

Review and, if suitable, land https://github.com/microsoft/vscode/pull/340776 so opaque terminals retain consistent text rendering with images enabled, while preserving image alpha and translucent-background behavior. Confirm the reported macOS light-theme scenario before closing.
