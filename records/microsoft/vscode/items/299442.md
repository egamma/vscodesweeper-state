# Issue #299442 — Terminal font broken on latest stable

[https://github.com/microsoft/vscode/issues/299442](https://github.com/microsoft/vscode/issues/299442)

## Summary

Confirmed on current main: commit f32f3306fd3 couples `allowTransparency` to `enableImages`, degrading font rendering on macOS when images are enabled. No fix or PR exists yet.

## Change summary

Terminal font rendering is broken (thin/poorly antialiased) when `terminal.integrated.enableImages` is true, because that setting now forces xterm's `allowTransparency` mode.

## Best solution

Decouple `allowTransparency` from `enableImages` in `src/vs/workbench/contrib/terminal/browser/xterm/xtermTerminal.ts` (lines 269 and 573). The image addon should work without forcing transparency mode; if transparency is truly needed for image rendering, it should be scoped to the image layer, not the entire terminal.
