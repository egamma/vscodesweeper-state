# Issue #282214 — Ctrl-C & Ctrl-V does not duplicate the whole line

[https://github.com/microsoft/vscode/issues/282214](https://github.com/microsoft/vscode/issues/282214)

## Summary

Keep open: a maintainer confirmed the Markdown-specific reproduction, and current source still loses whole-line paste semantics when plain text is applied alongside a Markdown paste alternative. The report contains sufficient steps; neither the earlier clipboard workaround nor the suggested duplicate accounts for this case.

## Change summary

Copying an unselected URL line in Markdown and pasting inserts the text at the cursor instead of duplicating the line separately.

## Best solution

Preserve ordinary whole-line copy/paste behavior when the paste-provider pipeline selects its default plain-text edit, while retaining Markdown link alternatives and their explicit selection behavior.
