# Issue #282214 — Ctrl-C & Ctrl-V does not duplicate the whole line

[https://github.com/microsoft/vscode/issues/282214](https://github.com/microsoft/vscode/issues/282214)

## Summary

Confirmed, still reproduces on main: when copying a line containing a URL with empty selection in a markdown file, the paste does not insert on a new line because the CopyPasteController's provider-edit path loses the `pasteOnNewLine` metadata. alexdima confirmed the reproduction in the discussion.

## Change summary

Ctrl-C with empty selection on a URL line in a markdown file, then Ctrl-V, does not duplicate the whole line — the pasted text is inserted inline instead of on a separate line.

## Best solution

Fix the interaction between `CopyPasteController.doPasteInline` and `DocumentPasteEditProvider` edits so that `pasteOnNewLine` metadata is preserved when the provider-edit path is taken. The root cause is that the markdown `PasteUrlEditProvider` matches on `text/plain` (the URL text), causing `handlePaste` to call `e.setHandled()` and route through the provider path at line 372 of `copyPasteController.ts`, which applies edits via `applyEditAndShowIfNeeded` without passing the `pasteOnNewLine` payload. Either the provider path should fall through to `applyDefaultPasteHandler` when the winning edit is the default text edit that yielded, or the `DefaultTextPasteOrDropEditProvider` edit should carry `pasteOnNewLine` context.
