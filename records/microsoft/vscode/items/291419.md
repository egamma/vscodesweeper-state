- **Current source path:** src/vs/workbench/browser/parts/titlebar/commandCenterControl.ts constructs the CommandCenter MenuWorkbenchToolBar with contextMenu: MenuId.TitleBarContext and HiddenItemStrategy.NoHide. agentSessionsExperiments.contribution.ts registers AgentsTitleBarControlMenu as a submenu, and AgentTitleBarStatusRendering in agentTitleBarStatusWidget.ts renders that SubmenuItemAction as the custom status widget containing the chat split button.
- **Source-confirmed missing menu:** In src/vs/platform/actions/browser/toolbar.ts, WorkbenchToolBar.setActions handles contextmenu by preventing default and stopping propagation, but excludes SubmenuItemAction from Configure Keybinding. With NoHide there are no hiding actions, so actions.length is zero and the handler returns before showContextMenu can include MenuId.TitleBarContext. This accounts for the reported difference from neighboring command actions without executing the application.
