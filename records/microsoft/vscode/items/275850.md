## Change summary

Switching a Codespace between VS Code Stable and Insiders can leave the Chat extension incompatible because both clients use the same remote extensions directory.

## Best solution

Codespaces should isolate or reconcile the remote Chat extension version by VS Code product channel so connecting from Stable or Insiders always activates a compatible version without disrupting the other client.
