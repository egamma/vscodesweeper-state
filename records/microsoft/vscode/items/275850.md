# Issue #275850 — Switching to Insiders or back to stable in codespaces should handle chat extension properly

[https://github.com/microsoft/vscode/issues/275850](https://github.com/microsoft/vscode/issues/275850)

## Summary

Keep this open in the Codespaces area: Stable and Insiders share remote extension storage, allowing one quality's Copilot extension version to become incompatible with the other. The team-author reopened the issue after an accidental duplicate close and explicitly indicated that the remaining action is outside the VS Code client.

## Change summary

Switching a Codespace between VS Code Stable and Insiders should retain a compatible Copilot Chat extension for each client quality.

## Best solution

Codespaces should isolate or reconcile remote extension versions by VS Code quality so connecting from Stable or Insiders cannot leave the other client with an incompatible Copilot extension.
