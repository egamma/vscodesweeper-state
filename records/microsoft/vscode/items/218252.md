# Issue #218252 — Missing theme variables for test coverage highlight background

[https://github.com/microsoft/vscode/issues/218252](https://github.com/microsoft/vscode/issues/218252)

## Summary

The reported highlights are rendered by the third-party Jest extension rather than VS Code's built-in coverage decorations, so their theming is outside this repository.

## Change summary

Allow themes to customize the uncovered and partially covered line highlights shown by the Jest: Toggle Coverage command.

## Best solution

Use the Jest extension's `jest.coverageColors` setting to customize these indicators; any remaining behavior gap belongs in https://github.com/jest-community/vscode-jest.

## Evidence

- **existing extension setting:** The same extension manifest contributes `jest.coverageColors`, described as a coverage-indicator color override, and its documentation at https://github.com/jest-community/vscode-jest#coveragecolors explains coverage color customization.
- **core distinction:** VS Code core separately registered `testing.coveredBackground` and `testing.uncoveredBackground` in commit 0e743a2d912fc41ec1326e98c9b9c722392ee782 before this report; current usage is in src/vs/workbench/contrib/testing/browser/theme.ts. Those tokens govern core coverage decorations, not decorations created by the Jest extension command.
