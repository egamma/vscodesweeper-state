# Issue #218252 — Missing theme variables for test coverage highlight background

[https://github.com/microsoft/vscode/issues/218252](https://github.com/microsoft/vscode/issues/218252)

## Summary

Decline close (out-of-scope) gated off: the issue sits in the Backlog milestone — the owner already triaged it as accepted work. Original assessment: The highlighted rows are produced by the third-party Jest extension rather than VS Code's built-in test-coverage decorations. Theme-token support for that command therefore belongs in jest-community/vscode-jest.

## Change summary

Allow themes to customize the covered, partially covered, and uncovered editor backgrounds shown by Jest: Toggle Coverage.

## Best solution

The Jest extension should expose theme color IDs for its coverage decorations, or otherwise integrate its existing `jest.coverageColors` configuration with theme-provided colors.

## Evidence

- **command ownership:** The Jest extension manifest defines `io.orta.jest.toggle-coverage` with title `Jest: Toggle Coverage`: https://github.com/jest-community/vscode-jest/blob/master/package.json.
- **extension-owned decorations:** jest-community/vscode-jest implements the overlay in `src/Coverage/CoverageOverlay.ts` and passes extension-configured colors to its formatter: https://github.com/jest-community/vscode-jest/blob/master/src/Coverage/CoverageOverlay.ts.
- **existing extension setting:** The extension already documents `jest.coverageColors` for overriding its covered, partially-covered, and uncovered colors: https://github.com/jest-community/vscode-jest#coveragecolors.
- **historical confirmation:** At the time of this report, jest-community/vscode-jest commit 6a3a7e7c621efa6ad782aea4f28b68652ae948fb already declared both the reported command and `jest.coverageColors`, confirming that this surface was extension-owned.
- **core distinction:** VS Code's native coverage decorations use `testing.coveredBackground` and `testing.uncoveredBackground` in `src/vs/workbench/contrib/testing/browser/theme.ts` and `media/testing.css`; those tokens were introduced by commit 0e743a2d912fc41ec1326e98c9b9c722392ee782 before this report, but they do not control decorations created independently by the Jest extension.
