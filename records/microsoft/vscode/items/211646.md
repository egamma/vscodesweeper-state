# Issue #211646 — Certain Edit menus should not be active without a selection (macOS)

[https://github.com/microsoft/vscode/issues/211646](https://github.com/microsoft/vscode/issues/211646)

## Summary

Still present on main: the Edit menu's Copy/Cut items are always enabled on macOS because the `enabled` state is never dynamically updated based on editor selection — the role-based Electron menu items don't auto-disable like native Cocoa apps.

## Change summary

On macOS, Edit > Copy and Edit > Cut menu items remain enabled even when there is no selection, breaking macOS conventions and automation tools like Keyboard Maestro.

## Best solution

Dynamically update the `enabled` state of the Cut/Copy menu items in the Electron main process based on the renderer's current selection state. This requires the renderer to communicate selection presence to the main process so the menu can be rebuilt or patched. Alternatively, investigate whether Electron's role-based items can be made to respect selection state natively (likely upstream).
