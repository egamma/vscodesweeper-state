# Issue #328942 — Copilot Chat content not readable because jumpy

[https://github.com/microsoft/vscode/issues/328942](https://github.com/microsoft/vscode/issues/328942)

## Summary

Verified duplicate: the same author (thgossler) already filed this exact request as issue #304608 (and again worded almost identically in #300099), including a follow-up comment on #304608 restating this issue's text verbatim — consolidating there.

## Change summary

Chat content jumps up and down as autonomous tool-call sections auto-expand and auto-collapse; the reporter wants collapse to leave empty space (never scroll content downward) and smooth upward-only scrolling.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/304608 (open, labeled ux/polish, with the reporter's own restated ask in the comments) — the fix belongs in src/vs/workbench/contrib/chat/browser/widget/chatListWidget.ts, where `_withPersistedAutoScroll` currently calls `scrollToEnd()` unconditionally on every height change while scrolled to bottom, causing abrupt snap-to-bottom jumps; only user-initiated toggles get anchor-preserving scroll restoration via `trackUserToggleResize`, while automatic expand/collapse (e.g. terminal tool progress) does not.
