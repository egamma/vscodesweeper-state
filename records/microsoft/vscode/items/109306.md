# Issue #109306 — Add ability for extensions to have "checked" commands

[https://github.com/microsoft/vscode/issues/109306](https://github.com/microsoft/vscode/issues/109306)

## Summary

The extension API gap remains on main and has strong community demand. Two open PRs reference this issue, so it must remain open while maintainers decide the API shape and review an implementation.

## Change summary

Allow extension-contributed commands to display a checked or toggled state controlled by a context-key expression.

## Best solution

Settle on the `checked` versus `toggled` API shape, review and land one of the existing implementation PRs, and close the superseded PR. The contribution schema and command registration in `menusExtensionPoint.ts` should expose the context expression through the existing menu toggle mechanism.
