# Issue #109306 — Add ability for extensions to have "checked" commands

[https://github.com/microsoft/vscode/issues/109306](https://github.com/microsoft/vscode/issues/109306)

## Summary

Keep open: extension-contributed commands still cannot declare a context-dependent checked state, despite native menu support. Two verified open implementation PRs reference this request; the next step is maintainer review of those candidates, not a competing implementation.

## Change summary

Allow extensions to declare a when-clause expression that controls a menu command's checkmark.

## Best solution

Expose context-dependent checked state through the command contribution contract, using the existing native menu behavior. Review https://github.com/microsoft/vscode/pull/214102 alongside https://github.com/microsoft/vscode/pull/165663 and settle the public contract before landing one implementation.
