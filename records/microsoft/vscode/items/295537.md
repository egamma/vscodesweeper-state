# Issue #295537 — Icons in autocomplete are not scaled when font-size is changed by user

[https://github.com/microsoft/vscode/issues/295537](https://github.com/microsoft/vscode/issues/295537)

## Summary

Keep open as a suggest-widget polish request: completion text follows the configured font size, but symbol icons retain the standard fixed size. Existing settings do not provide proportional icon sizing, and no verified canonical or fixing commit was found.

## Change summary

Keep autocomplete icons visually proportionate when users reduce the editor or suggestion font size.

## Best solution

Have the suggest UX owner establish a compact-icon policy for small suggestion text, consistent with the shared icon-size system. Any adjustment should remain local to suggestions rather than changing codicon sizing throughout VS Code.
