# Issue #295537 — Icons in autocomplete are not scaled when font-size is changed by user

[https://github.com/microsoft/vscode/issues/295537](https://github.com/microsoft/vscode/issues/295537)

## Summary

Still reproduces on main: codicon icons in the suggest widget are hardcoded to 16px via the global `.codicon` CSS rule and are never resized to match the suggest widget's computed font size, so they appear disproportionately large at small editor font sizes.

## Change summary

Autocomplete suggestion icons do not scale when `editor.fontSize` (or `editor.suggestFontSize`) is reduced, staying at 16px while text shrinks.

## Best solution

In `suggestWidgetRenderer.ts`'s `configureFont()` function, set the `iconContainer`'s font-size to match the computed suggest font size (same value applied to the root element), so the codicon glyphs scale alongside the text. The `.icon` element already has its dimensions set to `lineHeightPx`; the codicon container needs an analogous override.
