# Issue #207218 — Release notes - clicking on a setting link open setting as a new tab in current editor group

[https://github.com/microsoft/vscode/issues/207218](https://github.com/microsoft/vscode/issues/207218)

## Summary

Keep open: the cross-group duplication path remains in current source when modal editors are disabled and editor reuse retains its default setting. Settings now open modally by default, but the supported editor-group workflow still needs the reuse behavior endorsed by the maintainer.

## Change summary

Release-note setting links should reuse an existing visible Settings editor rather than open another Settings tab over the release notes.

## Best solution

Make release-note setting navigation reveal and filter the existing visible Settings editor across groups, while preserving deliberate multiple-Settings workflows and current modal-editor behavior.
