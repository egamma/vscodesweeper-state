# Issue #301648 — Empty linkified symbols for 'file://'

[https://github.com/microsoft/vscode/issues/301648](https://github.com/microsoft/vscode/issues/301648)

## Summary

The reported literal `file://` can still become an empty file-reference widget: the URI-resolution branch accepts the filesystem root, while the widget derives its text from an empty root basename. Keep this team-authored report open; no verified fix or older canonical reporting the same symptom was found.

## Change summary

Prevent a literal `file://` in chat response prose from being replaced by an empty linkified reference.

## Best solution

Preserve the readable `file://` literal when it describes a URI scheme rather than a file reference. Address this in Copilot's file-path linkification without changing valid file and directory links.
