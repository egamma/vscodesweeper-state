# Issue #301648 — Empty linkified symbols for 'file://'

[https://github.com/microsoft/vscode/issues/301648](https://github.com/microsoft/vscode/issues/301648)

## Summary

Still reproduces on main: the FilePathLinkifier matches `file://` URI text in chat responses and creates LinkifyLocationAnchor objects without a title, resulting in empty clickable links when the URI has no meaningful basename.

## Change summary

Chat responses that mention `file://` URIs render empty clickable link pills because the linkifier resolves them without preserving the original display text.

## Best solution

The FilePathLinkifier in `extensions/copilot/src/extension/linkify/common/filePathLinkifier.ts` should either skip URI-scheme-only matches (like bare `file://`) that have no meaningful path, or pass the original matched text as the `title` parameter to `LinkifyLocationAnchor` so the pill always has visible content.
