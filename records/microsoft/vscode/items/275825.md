# Issue #275825 — Issue reporter enforces more than 1 word to be in issue name

[https://github.com/microsoft/vscode/issues/275825](https://github.com/microsoft/vscode/issues/275825)

## Summary

Valid feature request to improve issue quality by requiring more than a single word in the issue title. The current validation in the issue reporter only checks for a non-empty title and max URL length — no word-count enforcement exists on main.

## Change summary

Require the issue reporter title field to contain more than one word to encourage more descriptive issue names.

## Best solution

Add a word-count validation check in the `validateInput` method in `src/vs/workbench/contrib/issue/browser/baseIssueReporterService.ts` (and the overlay variant) for the `issue-title` input, requiring at least two words. Add a corresponding validation error message in the issue reporter page template. The overlay-based reporter in `issueReporterOverlay.ts` would need the same logic applied to its title input widget.
