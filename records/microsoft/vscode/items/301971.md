# Issue #301971 — Copilot repeatedly ignores explicit instructions despite confirming it will follow them

[https://github.com/microsoft/vscode/issues/301971](https://github.com/microsoft/vscode/issues/301971)

## Summary

The request log confirms that the instructions reached the model, so the original symptom is not a custom-instruction delivery defect. The clarified request for deterministic, non-bypassable constraints remains only partially covered by the current experimental sandbox and should stay open as a feature request.

## Change summary

Provide enforceable repository- and session-scoped agent constraints so unsafe tool actions do not depend solely on model instruction-following.

## Best solution

Separate advisory model instructions from enforceable tool policy: retain diagnostics for whether instructions reached the model, while providing a clearly documented mode that prevents writes outside approved workspace paths and other configured actions regardless of model behavior.
