# Issue #55075 — Show Opening Tag when Closing Tag Selected

[https://github.com/microsoft/vscode/issues/55075](https://github.com/microsoft/vscode/issues/55075)

## Summary

This remains the canonical backlog request: Sticky Scroll provides useful context but does not reliably show the exact matching opening tag or bracket when the caret reaches its off-screen closing pair. With 57 community upvotes and confirmed distinct behavior, it should remain open.

## Change summary

Show an off-screen opening tag or bracket in an editor overlay when its closing pair is selected.

## Best solution

Extend the editor's bracket-matching contribution with a language-neutral overlay that displays the matching opening line when it is outside the viewport, while keeping Sticky Scroll as the broader nested-scope feature.
