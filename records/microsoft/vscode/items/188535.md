# Issue #188535 — Allow navigation between output cells in notebooks in the accessible view

[https://github.com/microsoft/vscode/issues/188535](https://github.com/microsoft/vscode/issues/188535)

## Summary

Still unimplemented: the notebook accessible view provider does not pass `provideNextContent`/`providePreviousContent` callbacks to `AccessibleContentProvider`, so users cannot navigate between output cells in the accessible view. The infrastructure already supports it — only the notebook-specific wiring is missing.

## Change summary

Allow navigating between notebook output cells using next/previous in the accessible view.

## Best solution

Wire `provideNextContent` and `providePreviousContent` in `getAccessibleOutputProvider` (src/vs/workbench/contrib/notebook/browser/notebookAccessibleView.ts) to iterate over notebook cells with outputs, updating the selected cell and returning its output text. The `AccessibleContentProvider` constructor already accepts these optional parameters.
