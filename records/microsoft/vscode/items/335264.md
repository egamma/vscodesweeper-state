# Issue #335264 — Feature request: Allow Copilot inline suggestions to use instruction files

[https://github.com/microsoft/vscode/issues/335264](https://github.com/microsoft/vscode/issues/335264)

## Summary

Keep open as a distinct feature request: current ghost-text prompting does not expose the requested opt-in instruction surface. Historical decisions about applying chat instructions do not settle this deliberately separate, completion-focused design.

## Change summary

Allow teams to opt short, file- or language-scoped instructions into Copilot ghost-text completions without automatically importing chat instructions.

## Best solution

Have the Copilot completions owners assess a dedicated opt-in instruction contract with explicit scoping and context limits. Preserve existing completion behavior by default and evaluate completion quality and latency before accepting the feature.
