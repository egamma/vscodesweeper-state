# Issue #208865 — Support filtering in builtin notebook variable view

[https://github.com/microsoft/vscode/issues/208865](https://github.com/microsoft/vscode/issues/208865)

## Summary

The notebook variable view still has no filtering support on current main — the feature request remains valid and unimplemented.

## Change summary

Add filtering capabilities to the built-in notebook variables view (filter by type, user-only variables, exclude built-in modules).

## Best solution

Implement a filter toolbar or tree filter in NotebookVariablesView (src/vs/workbench/contrib/notebook/browser/contrib/notebookVariables/notebookVariablesView.ts) to allow hiding non-user variables, filtering by type, and excluding built-in Jupyter modules. Alternatively, the Jupyter extension's variable provider could pre-filter or group variables before surfacing them to the built-in view.
