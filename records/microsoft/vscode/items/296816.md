# Issue #296816 — Turning local agent into background agent makes it disappear (=archived) if there are still open questions / answers to give

[https://github.com/microsoft/vscode/issues/296816](https://github.com/microsoft/vscode/issues/296816)

## Summary

The delegation flow ('Continue in…' / send-to-background) archives the source local session without checking for pending tool confirmations or questions. No fix found on main; the delegation handler in agentHostDelegation.ts creates the new session and inserts it but does not resolve pending confirmations on the source session first. Report is plausible but thin on exact reproduction steps.

## Change summary

Delegating a local agent session to a background agent archives the source session even when it has pending confirmations, making the session disappear and blocking the background session from progressing.

## Best solution

The delegation flow (in `src/vs/sessions/contrib/chat/browser/agentHostDelegation.ts` or the calling action in `chatContinueInAction.ts`) should check for pending tool confirmations on the source session before archiving it — either resolve/answer them first, or keep the source session visible until confirmations are handled. The archive-with-pending-edits confirmation dialog already exists in `agentSessionsActions.ts` (line 510–513) but isn't wired into the delegation path.
