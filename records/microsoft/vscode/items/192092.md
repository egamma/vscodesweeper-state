# Issue #192092 — Would it be possible and interesting to group some menus?

[https://github.com/microsoft/vscode/issues/192092](https://github.com/microsoft/vscode/issues/192092)

## Summary

The requested Go To submenu remains absent from current source. Keep this under discussion: the thread identifies a genuine keyboard-navigation tradeoff, and the directly related menu-cleanup proposal is newer, so it cannot serve as a duplicate target for this re-reviewed item.

## Change summary

Group related editor context-menu commands, particularly Go To actions, into submenus to reduce repeated arrow-key navigation.

## Best solution

Evaluate a Go To submenu alongside the context-menu cleanup in https://github.com/microsoft/vscode/issues/225411, comparing keyboard navigation effort with the existing flat layout. Agree on the grouping only after validating discoverability, submenu navigation, and the muscle-memory concerns raised in this thread.
