# Issue #242505 — SSH-Download Progress Bar

[https://github.com/microsoft/vscode/issues/242505](https://github.com/microsoft/vscode/issues/242505)

## Summary

Valid community-promoted feature request (22 upvotes, in Backlog) for download progress percentage when downloading files from remote SSH hosts. The download UI lives in core VS Code (`fileImportExport.ts`) and currently reports only "Downloading" without percentage or byte-level progress in the native path. No duplicate or existing implementation found.

## Change summary

Add percentage/byte-level progress reporting to the file download notification when downloading files from remote development sessions via SSH.

## Best solution

Enhance the native download path in `src/vs/workbench/contrib/files/browser/fileImportExport.ts` (`doDownloadNative`) to report byte-level progress similar to how the browser path tracks `totalBytesDownloaded`, and switch to `ProgressLocation.Notification` with `percentage: true` so users see how much of the download has completed. The `remote` and `explorer` area owners should evaluate the UX.
