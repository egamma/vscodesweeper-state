# Issue #331884 — Agents: Show All Terminals does not reveal hosted terminals when the panel is hidden

[https://github.com/microsoft/vscode/issues/331884](https://github.com/microsoft/vscode/issues/331884)

## Summary

Confirmed on current main: `showAllTerminals` in sessionsTerminalContribution.ts only iterates terminals not in `foregroundInstances`, so a terminal already attached to a group/editor (foreground) but hidden because the Terminal panel itself is closed is silently skipped — matching the reporter's exact diagnosis.

## Change summary

Agents Window's 'Show All Terminals' command is a no-op for terminals already marked foreground when the Terminal panel is hidden, leaving them invisible.

## Best solution

Fix showAllTerminals() (src/vs/sessions/contrib/terminal/browser/sessionsTerminalContribution.ts, around line 794) to also reveal the terminal panel/group for already-foreground instances (e.g. via the terminal group service's showPanel/reveal path) rather than treating 'foreground' as synonymous with 'visible', or rename the diagnostic/command semantics to be explicit that 'foreground' only means group membership.
