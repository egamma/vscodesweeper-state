# Issue #339352 — Automations show in editor window sessions list

[https://github.com/microsoft/vscode/issues/339352](https://github.com/microsoft/vscode/issues/339352)

## Summary

Confirmed gap on main: the editor-window chat sessions list (chatSessionsService/chatSessions.contribution.ts) has no concept of automation-created sessions at all, unlike the Agents Window which filters them via `session.isAutomation`. Related but distinct from the sibling issue #339350 (remote automations leaking into the Agents Window's own list), so not a duplicate.

## Change summary

Automation-created chat sessions appear in the regular editor-window chat sessions list/view, when they should be hidden there just as they already are in the Agents Window.

## Best solution

Thread an automation-provenance signal into IChatSessionItem (or equivalent) for the editor-window chat sessions provider and filter it out the same way sessions.contribution.ts does with `session.isAutomation`, after a maintainer confirms the exact session-item model to extend.
