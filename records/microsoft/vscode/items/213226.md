# Issue #213226 — In diff mode, user is forced to interact with a dialog instead of direct hitting the revert button

[https://github.com/microsoft/vscode/issues/213226](https://github.com/microsoft/vscode/issues/213226)

## Summary

The compact diff gutter still moves its only Revert Block action into an overflow menu. Keep this correctly routed issue open; the reported extra click follows directly from the current layout and toolbar overflow logic.

## Change summary

Expose Revert Block directly when a short diff hunk has only that action, rather than requiring a one-item overflow menu.

## Best solution

Keep the sole revert action directly accessible in compact diff hunks while preserving overflow access when multiple actions genuinely require it. Preserve existing revert semantics and avoid changing shared toolbar behavior for unrelated consumers.
