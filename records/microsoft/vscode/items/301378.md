# Issue #301378 — Terminal colours wrong from ANSI sequence

[https://github.com/microsoft/vscode/issues/301378](https://github.com/microsoft/vscode/issues/301378)

## Summary

The observed color change (bright white becoming black on a bright red background) is caused by the `terminal.integrated.minimumContrastRatio` setting (default 4.5), which adjusts foreground colors to meet WCAG accessibility contrast requirements. This is working as designed — identical reports have been closed as `*as-designed` previously.

## Change summary

Terminal renders bright white as black when used over a bright red ANSI background, due to the minimum contrast ratio enforcement.

## Best solution

Close as designed. The user can set `"terminal.integrated.minimumContrastRatio": 1` to disable the contrast adjustment and see raw ANSI colors. The 24-bit color concern is likely the same root cause — xterm.js supports truecolor but the contrast algorithm adjusts the rendered output.
