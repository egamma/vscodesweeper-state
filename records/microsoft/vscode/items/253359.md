# Issue #253359 — remote workspace index fails if license and github account are different

[https://github.com/microsoft/vscode/issues/253359](https://github.com/microsoft/vscode/issues/253359)

## Summary

Valid feature request: the remote workspace index authenticates with whatever GitHub session Copilot uses for its license, but when that account differs from the one with repo access, indexing fails. No existing mechanism separates the two; the auth service has a single GitHub session model. Stays open as a real gap.

## Change summary

Allow using a different GitHub account for remote workspace indexing than the one used for the Copilot license.

## Best solution

Support multiple GitHub sessions in the Copilot authentication layer so that the remote code search service can use a repo-access account distinct from the Copilot license account. The likely area is `extensions/copilot/src/platform/authentication/` (session management) and `extensions/copilot/src/platform/remoteCodeSearch/` (token selection). A recent commit (4091aadf060, 2025-06-27) added sign-in prompts on auth failures, which is a step toward surfacing the problem but does not solve the multi-account case.
