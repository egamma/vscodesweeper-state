# Issue #253359 — remote workspace index fails if license and github account are different

[https://github.com/microsoft/vscode/issues/253359](https://github.com/microsoft/vscode/issues/253359)

## Summary

Keep open: current remote-index authentication has no repository-specific account selection, so the requested separation remains unestablished. A newer open report describes the same account-mismatch symptom, but cannot replace this older, previously reviewed issue.

## Change summary

Allow remote workspace indexing when the Copilot entitlement and GitHub repository access belong to different accounts.

## Best solution

Establish whether remote indexing can authenticate repository access separately from Copilot entitlement, then provide a supported workflow without changing the account used for licensed Chat. Account selection and remote-service requirements need investigation before this is a bounded implementation task.
