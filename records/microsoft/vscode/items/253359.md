# Issue #253359 — remote workspace index fails if license and github account are different

[https://github.com/microsoft/vscode/issues/253359](https://github.com/microsoft/vscode/issues/253359)

## Summary

Keep this accepted Backlog request open: current remote-index authentication has no repository-specific account selection, and newer reports describe the same split-account limitation. No verified older canonical or concrete fixing commit establishes that this request is resolved.

## Change summary

Support workspace indexing when the Copilot-licensed account differs from the GitHub account authorized to access the repository.

## Best solution

Support repository access independently of the Copilot entitlement identity without changing the account used for Chat. Establish whether the remote indexing service supports that separation; local indexing or external ingest may provide alternatives, but they do not establish that the requested remote-index workflow is supported.
