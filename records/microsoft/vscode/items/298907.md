# Issue #298907 — lose history chat record

[https://github.com/microsoft/vscode/issues/298907](https://github.com/microsoft/vscode/issues/298907)

## Summary

This matches the session-list loading defect tracked in https://github.com/microsoft/vscode/issues/298507 and fixed on main: starting a new chat preserved the previous session, but a delayed or failing provider could prevent it from appearing in history. The current per-provider resolution path no longer lets that provider hide local sessions.

## Change summary

Starting a new conversation could make the previous Copilot Chat session disappear from the visible history.

## Best solution

Keep the per-provider session resolution shipped in commit 2d27541e2d69ab9d5dbaaab51db99472f06bc01d, which allows local history to remain visible while another provider is still setting up or fails to resolve.
