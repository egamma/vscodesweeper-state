# Issue #215449 — Go To Definition Ctrl + Left - Click Not Working

[https://github.com/microsoft/vscode/issues/215449](https://github.com/microsoft/vscode/issues/215449)

## Summary

The reported behavior is as-designed: when `editor.multiCursorModifier` is set to `ctrlCmd`, Ctrl+Click is reassigned to multi-cursor and go-to-definition moves to Alt+Click. Multiple commenters confirmed this resolves their issue (comment 11), and others had unrelated extension configuration problems (comments 15–16).

## Change summary

Ctrl+Click does not trigger Go To Definition when `editor.multiCursorModifier` is set to `ctrlCmd`.

## Best solution

Close as designed — the `editor.multiCursorModifier` setting intentionally swaps the Ctrl+Click and Alt+Click roles. Users who want Ctrl+Click for go-to-definition should set `"editor.multiCursorModifier": "alt"` (the default).
