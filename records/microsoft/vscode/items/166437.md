# Issue #166437 — Replace in files is buggy when multiple changes are made on same line of code

[https://github.com/microsoft/vscode/issues/166437](https://github.com/microsoft/vscode/issues/166437)

## Summary

Keep open: selected-match replacement still queues edits using stale match positions, allowing length-changing replacements to overwrite unrelated text. This issue already owns the work; maintainers have consolidated other reports here.

## Change summary

Replacing multiple selected search results on one line corrupts text when the replacement changes the match length.

## Best solution

Make selected-result replacement preserve the intended original occurrences and leave all unselected text unchanged, with regression coverage through the search-result model and actual text edits. Preserve working single-result and Replace All behavior.
