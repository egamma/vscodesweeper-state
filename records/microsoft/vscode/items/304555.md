# Issue #304555 — Copilot Chat: child_process ENOPRO when file:// URIs are passed to commands

[https://github.com/microsoft/vscode/issues/304555](https://github.com/microsoft/vscode/issues/304555)

## Summary

Plausible bug in Copilot Chat's hook executor: file:// URIs in the command string are not converted to filesystem paths before being passed to spawn. The code at extensions/copilot/src/platform/chat/node/hookExecutor.ts sanitizes cwd and stdin JSON URIs but not the command string itself. No fix found on main.

## Change summary

Copilot Chat hook commands fail with ENOPRO on Linux when file:// URIs are passed as arguments to child_process spawn.

## Best solution

Sanitize file:// URIs in the hook command string (or its arguments) before passing to spawn in extensions/copilot/src/platform/chat/node/hookExecutor.ts, similar to the existing uriToFsPath conversion already applied to cwd and stdin JSON values.
