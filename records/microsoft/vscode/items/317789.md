# Issue #317789 — Improve Agent Host shell integration and command detection parity

[https://github.com/microsoft/vscode/issues/317789](https://github.com/microsoft/vscode/issues/317789)

## Summary

Team-authored tracking issue for a real, well-documented gap between Agent Host terminal command detection and local workbench shell integration. No implementation has landed on main; the work remains open.

## Change summary

Agent Host terminals parse/strip OSC 633 sequences server-side and expose only a reduced command lifecycle model, causing lossy command-boundary detection compared to local terminals.

## Best solution

Incrementally close the shell-integration parity gap described in the issue: preserve OSC/data ordering around markers, expose richer shell-integration metadata over AHP events (prompt start, command start, continuation), and make AHP command objects closer to local ITerminalCommand — primarily in src/vs/platform/agentHost/node/agentHostTerminalManager.ts (server-side parsing) and src/vs/workbench/contrib/terminal/browser/ahpTerminalCommandSource.ts / agentHostPty.ts (client-side reconstruction).
