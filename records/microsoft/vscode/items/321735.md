# Issue #321735 — Webviews render unstyled in Firefox and Safari when resources are served cross-origin

[https://github.com/microsoft/vscode/issues/321735](https://github.com/microsoft/vscode/issues/321735)

## Summary

Confirmed on current main: webview stylesheet links lack the `crossorigin` attribute, so Firefox and Safari reject opaque cross-origin responses from the service worker. An open PR (#321736) addresses this; the issue should stay open until it lands.

## Change summary

Webview extension stylesheets fail to load in Firefox and Safari when resources are served cross-origin, leaving webviews completely unstyled.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/321736, which adds `crossorigin="anonymous"` to webview-resource stylesheet links and re-fetches them in CORS mode (Firefox/Safari only). The service worker already sends `Access-Control-Allow-Origin: *`, so the CORS request succeeds. Careful review needed to ensure no regressions on vscode.dev or same-origin setups.
