# Issue #302101 — Tooltip instability on UI Usage Statistics

[https://github.com/microsoft/vscode/issues/302101](https://github.com/microsoft/vscode/issues/302101)

## Summary

The behavior is confirmed but follows native browser tooltip semantics: after clicking a toggle, the pointer must leave and re-enter that DOM element before its tooltip can appear again. A maintainer confirmed that this is native-hover behavior VS Code cannot change, so this can close as designed.

## Change summary

Native tooltips for the UI Usage Statistics rating toggles appear inconsistently while moving between or clicking those controls.

## Best solution

Keep the native tooltip behavior; users must move the pointer out of the clicked toggle and back in to trigger the browser tooltip again.
