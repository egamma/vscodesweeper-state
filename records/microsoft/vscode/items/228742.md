# Issue #228742 — 'search' option in fileLocation of problemMatcher for Task does not work in Remote Development

[https://github.com/microsoft/vscode/issues/228742](https://github.com/microsoft/vscode/issues/228742)

## Summary

The defect remains in current main: search-mode problem matchers enumerate the local file-system provider even when the task supplies a remote URI provider. Keep this open in tasks and remote; the missing remote diagnostics have a bounded, source-confirmed cause.

## Change summary

Task problem matchers using fileLocation search should search the remote task's filesystem rather than interpreting remote Linux directories as local Windows paths.

## Best solution

Make search-mode file resolution honor the task's filesystem scheme and authority throughout directory traversal, exclusions, and returned diagnostic resources, while preserving local-task behavior.
