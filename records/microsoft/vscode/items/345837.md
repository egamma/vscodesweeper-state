- **Current source boundary:** src/vs/workbench/contrib/chat/browser/widget/input/chatSessionWorkingSet.ts routes filename clicks through _openFile, which directly opens diff.modifiedURI (diff.originalURI for deletions). Explicit diff actions use the separate _openFileDiff path, which can resolve an editing-session entry before opening its resources. This supports the reported difference between controls without establishing a completed fix.
- **Evidence to preserve:** https://github.com/microsoft/vscode/issues/345837 reports Windows 11 connected to Linux through Remote SSH, working individual/all-changes diff buttons, and persistence after upgrading from 1.144.0 to 1.144.1.
