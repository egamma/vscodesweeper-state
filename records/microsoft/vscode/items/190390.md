# Issue #190390 — Support search in notebook diff editor

[https://github.com/microsoft/vscode/issues/190390](https://github.com/microsoft/vscode/issues/190390)

## Summary

Keep open: notebook-wide Find remains unsupported in the side-by-side diff editor. The older search-related candidate does not establish the same observable request, while the clearly matching report is newer and cannot replace this re-reviewed, team-authored item.

## Change summary

Support finding text across cells in the notebook diff editor.

## Best solution

Provide notebook-wide Find and match navigation within notebook comparisons, consistent with ordinary notebook search. Establish which comparison sides and cell content participate before implementing the diff-editor integration.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/notebook/browser/diff/notebookDiffEditor.ts`, `src/vs/workbench/contrib/notebook/browser/notebookBrowser.ts`, `src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFind.ts`, `src/vs/workbench/contrib/notebook/browser/diff/inlineDiff/notebookInlineDiffWidget.ts`
- **Validation:** Compare two notebooks containing a repeated search term in multiple cells, invoke Ctrl/Cmd+F, and verify match counts and next/previous navigation across the agreed comparison scope, including offscreen cells. Verify ordinary notebook Find remains unchanged.
- **Behavior:**

  > Users should be able to invoke Find inside a notebook comparison and navigate matching text across cells without leaving the comparison. Search must not be limited to the currently focused cell. Acceptance should cover multiple matches in different cells, offscreen matches, no-match queries, and unchanged ordinary notebook Find behavior; the participating comparison sides and content types need agreement first.
- **Trace:**

  > NotebookTextDiffEditor in src/vs/workbench/contrib/notebook/browser/diff/notebookDiffEditor.ts exposes inlineNotebookEditor only in inline mode. getNotebookEditorFromEditorPane in src/vs/workbench/contrib/notebook/browser/notebookBrowser.ts consequently returns no notebook editor for a side-by-side diff. The notebook.find command in src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFind.ts depends on that helper and NotebookFindContrib; the inline widget also selects only its diff decoration contribution rather than the ordinary notebook contribution set. This establishes an integration gap, not a complete design for searching both notebook models. Preserve normal notebook search and diff rendering semantics. https://github.com/microsoft/vscode/issues/158496 was explicitly consolidated here, and https://github.com/microsoft/vscode/issues/237359 supplies a later Timeline-comparison example.
- **Open decisions:**
  - Should Find search both original and modified notebooks or only the modified notebook, and how should next/previous navigation order matches across the two sides?
  - Should comparison Find initially include only cell source text, or also rendered Markdown and cell outputs?
