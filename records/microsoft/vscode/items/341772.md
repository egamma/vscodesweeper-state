# Issue #341772 — MCP migration says an update is needed to keep working but drops registry auto-updates

[https://github.com/microsoft/vscode/issues/341772](https://github.com/microsoft/vscode/issues/341772)

## Summary

Keep open: current migration guidance better explains the runtime change, but registry auto-updates are still deliberately dropped without a concrete replacement update procedure. The related marketplace-installation issue does not cover this remaining gap.

## Change summary

Preserve registry-managed updates across MCP migration, or explain their loss, subsequent update management, and the implications of ignoring migration.

## Best solution

Define the supported update lifecycle for registry-installed servers in Copilot configuration. Reflect that contract in MCP migration warnings and documentation, distinguishing registry configuration updates from updates to a remotely hosted service and explaining what Ignore means.
