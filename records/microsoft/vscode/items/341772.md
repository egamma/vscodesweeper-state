# Issue #341772 — MCP migration says an update is needed to keep working but drops registry auto-updates

[https://github.com/microsoft/vscode/issues/341772](https://github.com/microsoft/vscode/issues/341772)

## Summary

Thanks for the detailed report. The warning is intentional: it is localized in customizationMigrationCategories.ts and covered by tests. The open question is whether the UX should explain the trade-off or preserve registry association, which needs a maintainer decision.

## Change summary

The MCP migration UI says migration is needed but warns it stops registry auto-updates, without explaining the scope, the consequences of ignoring it, or how to update afterward.

## Best solution

Clarify the migration warning (what stops updating, whether Ignore is safe, how to update afterward), or preserve the registry association across migration, in the AI customization migration UI.
