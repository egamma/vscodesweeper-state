[https://github.com/microsoft/vscode/issues/287568](https://github.com/microsoft/vscode/issues/287568)

## Summary

The report describes misleading highlighting in a Copilot command confirmation, but the current source supports quoted multiline heredocs and does not establish the reported failure. Request a current-build example and identify the affected chat session and tool before diagnosing or closing it.

## Change summary

Copilot's command confirmation incorrectly highlights apostrophes, backticks, and keywords inside a quoted heredoc as executable shell syntax.

## Best solution

Ensure the confirmation displays quoted heredoc contents as literal text while preserving shell highlighting outside the heredoc. First compare the same command in the current confirmation surface and a Shell Script editor to distinguish a chat presentation defect from a grammar defect.
