# Issue #329873 — Internal reasoning text rendered below "Finished with N steps" in agent host + BYOK mode

[https://github.com/microsoft/vscode/issues/329873](https://github.com/microsoft/vscode/issues/329873)

## Summary

Confirmed on main: the SSE bridge for BYOK reasoning models emits a full add/delta/done part sequence per raw streaming chunk instead of merging chunks into one summary part, exactly as the reporter traced — this is a real, well-localized bug that should stay open for a fix.

## Change summary

In agent host + BYOK (DeepSeek via customendpoint), streamed reasoning text renders as one word per line below "Finished with N steps" instead of as normal flowing text.

## Best solution

Fix `reasoningFrames` in src/vs/platform/agentHost/node/copilot/byokResponsesTranslation.ts to emit a single `reasoning_summary_part.added` … `reasoning_summary_part.done` cycle per reasoning item, with one `summary_text.delta` per accumulated chunk in between — instead of looping the full add/delta/done cycle for every element of `item.summary`. The existing test asserting two separate part.added/done cycles for `summary: ['first','second']` (byokResponsesTranslation.test.ts) encodes the buggy behavior and should be updated alongside the fix.
