# Issue #336142 — Allow seeing other versions changes in the release notes page

[https://github.com/microsoft/vscode/issues/336142](https://github.com/microsoft/vscode/issues/336142)

## Summary

Reasonable ask to let users viewing the in-app Release Notes editor see notes for versions between their currently-installed build and latest, not just the newest version — current source shows only a single version is loaded/rendered per view, so no existing surface covers this yet.

## Change summary

Users who skip several updates want to see release notes for all skipped versions (or a sidebar/history of past versions), not only the latest.

## Best solution

In src/vs/workbench/contrib/update/browser/releaseNotesEditor.ts, ReleaseNotesManager.show()/loadReleaseNotes() currently load and render exactly one version's markdown; extending this to optionally concatenate/list several versions (or add a version picker/sidebar) is the concrete change the request needs, gated behind a product decision on UX.
