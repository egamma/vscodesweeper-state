# Issue #336142 — Allow seeing other versions changes in the release notes page

[https://github.com/microsoft/vscode/issues/336142](https://github.com/microsoft/vscode/issues/336142)

## Summary

Keep open as a feature request: the release-notes viewer supports loading individual versions internally, but does not expose version-history navigation or a combined view of skipped releases. No verified older canonical was found.

## Change summary

Let users who update across several releases discover the intervening changes from the in-app release-notes page.

## Best solution

Provide discoverable access to previous release notes from the existing viewer, preserving its single-release reading experience. A maintainer should decide whether history navigation sufficiently addresses batch updates or whether an installed-to-latest range view is warranted.
