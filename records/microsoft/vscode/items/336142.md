## Summary

Genuine, still-unaddressed request: the in-app release notes view (ReleaseNotesManager in releaseNotesEditor.ts) only ever loads a single version's markdown, and 'Show Release Notes' falls back to opening the external site only when the in-app load fails — there's no way to see a combined changelog across multiple skipped versions or browse the last N releases in-app. Low engagement (0 upvotes, no comments, 7 days old) means this isn't urgent, but nothing here justifies a close.

## Change summary

Requester wants the in-app release notes view to show changes across all versions skipped during a batched update (or a sidebar listing the last ~20 versions), instead of only the current version's notes.
