# Issue #143244 — Allow for a supplementary notebook editor pane associated with a main notebook document for holding outputs

[https://github.com/microsoft/vscode/issues/143244](https://github.com/microsoft/vscode/issues/143244)

## Summary

The existing Output Preview covers opening an individual output beside a notebook, but not the requested live, reorderable collection of outputs. Keep this team-authored request open; the related preview tracker does not clearly absorb its full scope.

## Change summary

Provide a supplementary notebook output editor with independently arranged outputs that remain connected to the original notebook and update when cells execute.

## Best solution

Complete the notebook output editor's live-update and multi-output experience, coordinating with https://github.com/microsoft/vscode/issues/247965 while preserving this issue's requirements for rearrangement and shared widget communication.
