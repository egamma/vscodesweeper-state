## Summary

The editor-state-dependent scope defect remains traceable on current main: open-document filtering can accept an include glob without checking the selected workspace root. Keep this report open; the related reports address different search failures, not this observable symptom.

## Change summary

Make grep_search honor includePattern consistently for open documents and on-disk files in multi-root workspaces.

## Best solution

Ensure the text-search API preserves both folder containment and workspace-relative glob semantics when incorporating open-editor results. Cover the reported root-scoped and ancestor-directory cases without removing searches of unsaved document content.
