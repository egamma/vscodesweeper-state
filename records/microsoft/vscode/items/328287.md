# Issue #328287 — GitHub Copilot `grep_search` returns files outside `includePattern` when they are open in an editor

[https://github.com/microsoft/vscode/issues/328287](https://github.com/microsoft/vscode/issues/328287)

## Summary

The defect is present on current main: open-editor filtering applies include globs to absolute paths without consistently enforcing the selected workspace root. Route this confirmed bug to the search API and chat tools owners.

## Change summary

Make `grep_search` honor `includePattern` consistently for open documents in multi-root workspaces.

## Best solution

Match open-editor resources against each applicable folder query using workspace-relative paths, rejecting resources outside the scoped roots, while preserving existing on-disk search semantics.
