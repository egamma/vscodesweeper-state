# Issue #310807 — Feature Request: Allow user prompt files / skills / custom instructions to drive the SCM "Review Changes" button

[https://github.com/microsoft/vscode/issues/310807](https://github.com/microsoft/vscode/issues/310807)

## Summary

A real customization gap remains on main: SCM reviews consume only global/code-generation instructions, while prompt files, skills, applyTo-scoped instruction files, and a dedicated review binding are unsupported. Route this to the code-review and prompt-customization owners.

## Change summary

Allow SCM code-review commands to use a selected prompt file, instruction file, skill, or other agent customization.

## Best solution

Extend the review customization path in `extensions/copilot/src/extension/review/node/githubReviewAgent.ts` to resolve review-specific prompt, skill, and applyTo-scoped instruction resources for every reviewed file, with an explicit configuration or command binding. Coordinate the narrower `.instructions.md` gap tracked by https://github.com/microsoft/vscode/issues/299447.

## Evidence

- **existing partial capability:** `loadCustomInstructions` in `extensions/copilot/src/extension/review/node/githubReviewAgent.ts` loads global agent instructions and `github.copilot.chat.codeGeneration.instructions`; the dedicated `github.copilot.chat.reviewSelection.instructions` setting is included only for selection reviews, not SCM diff reviews.
- **remaining source gap:** `CustomInstructionsService.getAgentInstructions()` in `extensions/copilot/src/platform/customInstructions/common/customInstructionsService.ts` returns only workspace `.github/copilot-instructions.md` and personal instructions.
