# Issue #330402 — [Source Control] Feature Request: Identify commit hashes in commit descriptions in commit hover tips and make them link to the referenced commit

[https://github.com/microsoft/vscode/issues/330402](https://github.com/microsoft/vscode/issues/330402)

## Summary

Legitimate, unimplemented feature request: commit hover tips render the raw message text without linkifying commit hashes referenced in it, unlike GitHub's own commit view or VS Code's existing issue-number linkification for GitHub issues.

## Change summary

Detect commit hashes (short or full) inside commit messages shown in hover tips and turn them into clickable links to view that commit.

## Best solution

Extend the commit message rendering in extensions/git/src/hover.ts (appendContent) with a commit-hash regex similar in spirit to the existing GitHub issue-link pattern in extensions/github/src/historyItemDetailsProvider.ts (provideMessageLinks), turning matched hashes into command-uri links to git.viewCommit — the underlying 'Open Commit' command already exists and just needs to be reachable from inline text.
