# Issue #330402 — [Source Control] Feature Request: Identify commit hashes in commit descriptions in commit hover tips and make them link to the referenced commit

[https://github.com/microsoft/vscode/issues/330402](https://github.com/microsoft/vscode/issues/330402)

## Summary

Reasonable, well-scoped request: the commit hover renderer (extensions/git/src/hover.ts) appends the raw commit message as markdown with no hash detection, so referenced commit hashes in messages are never linkified today. No existing setting or command covers this, so it should be routed to the `git` area for consideration.

## Change summary

Detect commit hashes (short/full) inside commit messages shown in SCM hover tooltips and turn them into links to open that commit, similar to GitHub's behavior.

## Best solution

Extend `appendContent` in extensions/git/src/hover.ts to regex-match short/full SHA-like tokens in the message text and render them as `command:git.viewCommit` links (reusing the existing `getHoverCommitHashCommands` pattern), guarding against false positives on non-hex tokens.
