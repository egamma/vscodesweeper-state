# Issue #348848 — Copilot harness does not support agent plugin standard

[https://github.com/microsoft/vscode/issues/348848](https://github.com/microsoft/vscode/issues/348848)

## Summary

Keep open: the updated report identifies a concrete symlink-triggered plugin synchronization failure, distinct from general plugin-format support. Current source retains the copy and permission-check paths implicated; the supplied steps suffice to retest, but the Windows failure was not executed.

## Change summary

Plugins containing symlinked files or directories fail to synchronize from Windows to the Copilot agent host without a useful installation error.

## Best solution

Make plugin synchronization handle permitted symlink targets predictably and surface actionable failures when a target cannot be accessed, without weakening filesystem grants. Track this specific compatibility gap alongside the customization migration work.
