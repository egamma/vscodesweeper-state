# Issue #348848 — Copilot harness does not support agent plugin standard

[https://github.com/microsoft/vscode/issues/348848](https://github.com/microsoft/vscode/issues/348848)

## Summary

The screenshot's installation error matches a current source path in remote windows: the Copilot customization installer requires a management method that the remote client does not expose. Keep this open as a remote plugin-installation gap, rather than concluding that Copilot generally lacks agent-plugin format support.

## Change summary

Installing an agent plugin fails with the Copilot harness selected, while the Local harness succeeds.

## Best solution

Provide plugin installation through the selected remote Copilot host, with capability-aware installation controls. Preserve existing local installation behavior and distinguish unavailable remote management from unsupported plugin formats.
