# Issue #282672 — Changed file from background agent show with full file path

[https://github.com/microsoft/vscode/issues/282672](https://github.com/microsoft/vscode/issues/282672)

## Summary

The working-set label path still lacks session-specific worktree context: files outside the window's workspace fall back to full paths. Keep this older report open; the related report describes the same symptom but is newer and cannot be its duplicate canonical.

## Change summary

Display background-agent changed files relative to their worktree instead of showing home-qualified or absolute directory paths.

## Best solution

Make the background-agent working set display file locations relative to the session's worktree while retaining the actual worktree URIs for opening files and diffs. Preserve normal workspace-relative labels and full-path fallback for files outside the session root.
