# Issue #251592 — MCP servers removed from extension still show up in VS Code

[https://github.com/microsoft/vscode/issues/251592](https://github.com/microsoft/vscode/issues/251592)

## Summary

The stale-definition path remains in current source: an extension that stops registering its MCP provider can leave its cached servers visible even after activating for another reason. Keep this open for the cache reconciliation the maintainer accepted; returning an empty list through a registered provider already follows a replacement path.

## Change summary

Remove obsolete cached MCP server definitions after their contributing extension activates without registering the corresponding provider.

## Best solution

Reconcile cached extension MCP collections with the providers actually present after extension activation, including providers that are no longer registered. Preserve lazy discovery for inactive extensions rather than activating every extension merely to refresh the list.
