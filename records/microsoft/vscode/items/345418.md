# Issue #345418 — File sort order in Git graph panel differs from explorer panel

[https://github.com/microsoft/vscode/issues/345418](https://github.com/microsoft/vscode/issues/345418)

## Summary

The Git graph preserves provider ordering rather than applying Explorer's filename comparison, so the consistency gap remains on main. Keep this open as polish; no verified canonical or landed fix covers the reported ordering.

## Change summary

Make filenames and folders in expanded Git commits follow the same case and suffix ordering as Explorer.

## Best solution

Give the SCM history tree consistent filename ordering without changing commit chronology. Settle whether it follows Explorer's default comparison or its configured lexicographic options before implementation.
