# Issue #228977 — [themes] support sematic colorization for 'excludedCode'

[https://github.com/microsoft/vscode/issues/228977](https://github.com/microsoft/vscode/issues/228977)

## Summary

A real default-theme gap remains: current main has no `excludedCode` semantic-token style, although users can configure one themselves. With no canonical duplicate, maintainer decision, or community demand beyond the reporter, this should remain open under discussion rather than be closed.

## Change summary

Give inactive C# code reported as the `excludedCode` semantic token a visibly dimmed style in VS Code's default themes.

## Best solution

Theme owners should decide whether `excludedCode` warrants a consistent dimmed semantic style across the relevant default light, dark, and high-contrast themes; if accepted, preserve `editor.semanticTokenColorCustomizations` as the user override.
