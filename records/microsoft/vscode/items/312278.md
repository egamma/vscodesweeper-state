# Issue #312278 — execution_subagent internal "Execution query:" framing leaks into session turn logs

[https://github.com/microsoft/vscode/issues/312278](https://github.com/microsoft/vscode/issues/312278)

## Summary

Still present on main: the literal "Execution query: " prefix is prepended to the subagent turn and no downstream filtering or source-tagging exists, so it leaks into session transcripts as reported.

## Change summary

The execution_subagent tool prepends an internal "Execution query:" framing string that leaks into session turn logs, making subagent turns look like user prompts.

## Best solution

Either strip the framing prefix before persisting the turn to the transcript, or tag the turn with metadata (e.g. a source field) so downstream consumers can distinguish system-injected turns from user-authored ones. The fix lives in `extensions/copilot/src/extension/tools/node/executionSubagentTool.ts` around the `executionInstruction` construction and the `Conversation`/`Turn` creation.
