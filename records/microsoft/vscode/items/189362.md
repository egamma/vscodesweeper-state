# Issue #189362 — [Accessibility] Display cell index number in Accessible View for Jupyter Notebook output

[https://github.com/microsoft/vscode/issues/189362](https://github.com/microsoft/vscode/issues/189362)

## Summary

Valid accessibility feature request — the cell index is available in the view model but never surfaced in the Accessible View output content. Not yet implemented on main.

## Change summary

Display the cell index number in the Accessible View when viewing Jupyter Notebook output so screen reader users know which cell's output they are reading.

## Best solution

In `notebookAccessibleView.ts`, prepend the cell index (from `selections[0].start`) to the output content string returned by `getAllOutputsText`, e.g. "Cell 3 output: …". This is a small, localized change in the notebook accessibility layer.
