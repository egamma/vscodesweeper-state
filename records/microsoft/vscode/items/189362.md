# Issue #189362 — [Accessibility] Display cell index number in Accessible View for Jupyter Notebook output

[https://github.com/microsoft/vscode/issues/189362](https://github.com/microsoft/vscode/issues/189362)

## Summary

The requested notebook cell index is still absent from Accessible View content. Keep this accepted Backlog request open; the older navigation issue covers moving between outputs, not identifying their source cell.

## Change summary

Display the source notebook cell's index alongside its output in Accessible View.

## Best solution

Expose a localized source-cell identifier in the notebook Accessible View so screen reader users can associate output with its notebook position. Keep that identifier distinct from numbering multiple outputs within a single cell.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/notebook/browser/notebookAccessibleView.ts`, `src/vs/workbench/contrib/notebook/browser/viewModel/cellOutputTextHelper.ts`
- **Validation:** Use a notebook containing markdown cells and code cells with single and multiple outputs. Open each code cell's output with Alt+F2 and verify that its notebook cell position is readable and distinguishable from within-cell output numbering; confirm output text and focus restoration remain unchanged.
- **Behavior:**

  > Notebook output in Accessible View should identify the notebook cell that produced it, allowing screen reader users to relate output to its source. The identifier must remain distinguishable from the numbering of multiple outputs within one cell. Acceptance should cover code cells separated by markdown cells, single-output cells, and multiple-output cells without changing the output text or focus restoration.
- **Trace:**

  > src/vs/workbench/contrib/notebook/browser/notebookAccessibleView.ts:getAccessibleOutputProvider already resolves the selected view cell using selections[0].start, but its content callback returns only getAllOutputsText. In src/vs/workbench/contrib/notebook/browser/viewModel/cellOutputTextHelper.ts, the existing 'Cell output N of M' labels describe outputs within the selected cell and do not identify its notebook position. The shared helper is also used by NotebookAccessibilityProvider for REPL output announcements, so changes must not unintentionally alter that separate experience. https://github.com/microsoft/vscode/issues/188535 tracks navigation, not this identification requirement; adding cross-cell navigation is outside this request. The remaining product choice is the precise user-facing meaning of the cell reference number.
- **Open decisions:**
  - Should the identifier describe the cell's one-based position among all notebook cells, or the kernel execution count, which can differ after cells are reordered or rerun?

## Evidence

- **Existing-capability check:** src/vs/workbench/contrib/notebook/browser/notebookAccessibleView.ts:getAccessibleOutputProvider selects viewCells[selections[0].start], obtains getAllOutputsText(notebookDocument, viewCell), and returns that text unchanged through AccessibleContentProvider. It does not include the selected cell's notebook index.
- **Output numbering is not cell numbering:** src/vs/workbench/contrib/notebook/browser/viewModel/cellOutputTextHelper.ts:getAllOutputsText adds 'Cell output N of M' only when the selected cell has multiple outputs. N identifies an output within that cell, not the cell's position in the notebook; single-output cells receive no identifying prefix.
