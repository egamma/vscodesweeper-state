# Issue #344745 — Subchats' Changes view shouldn't use "session" instead of "branch" if the target dir is different from parent chat

[https://github.com/microsoft/vscode/issues/344745](https://github.com/microsoft/vscode/issues/344745)

## Summary

Keep open as a request to refine the existing nested-chat default: current source deliberately selects Session Changes without comparing the child and parent working directories. The directory-sensitive Branch Changes preference remains unimplemented.

## Change summary

Prefer Branch Changes for a subchat whose target directory differs from its parent's directory.

## Best solution

Make the default changeset selection sensitive to the subchat's workspace relationship to its parent, with consistent selection and statistics in the Changes view and chat input pill. Preserve explicit user selections and retain the existing default for chats sharing the parent's directory.
