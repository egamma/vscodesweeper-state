# Issue #344745 — Subchats' Changes view shouldn't use "session" instead of "branch" if the target dir is different from parent chat

[https://github.com/microsoft/vscode/issues/344745](https://github.com/microsoft/vscode/issues/344745)

## Summary

Keep open: current source still defaults all nested chats to Session Changes, without checking whether their target directory differs from the parent's. This team-authored request asks for a specific refinement of that intentional behavior; no matching canonical or fixing commit was found.

## Change summary

Prefer Branch Changes for subchats whose target directory differs from their parent chat's directory.

## Best solution

Make the default changeset and Changes pill consistently reflect a subchat's independent Git workspace, while preserving Session Changes for shared-directory subchats. Confirm the scope comparison and fallback behavior with the maintainer before implementation.
