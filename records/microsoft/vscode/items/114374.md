- **Behavior:**

  > When discarding an untracked CSV fails because Excel holds a Windows file lock, the notification should explain the failure in useful terms and guide the user toward releasing the file before retrying. Successful discard and existing recycle-bin confirmation behavior remain unchanged.
- **Trace:**

  > Repository.clean and Repository._clean in extensions/git/src/repository.ts distinguish untracked deletion from tracked checkout and select recycling or native Git clean. The command wrapper in extensions/git/src/commands.ts presents unclassified errors through its generic stderr-derived notification and preserves Show Command Output.
