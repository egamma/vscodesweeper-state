# Issue #248324 — cannot maximize bottom panel when viewing PR overview

[https://github.com/microsoft/vscode/issues/248324](https://github.com/microsoft/vscode/issues/248324)

## Summary

Still reproduces on main: the webview find widget unconditionally calls `_delegate.focus()` on hide, which re-activates the editor part and prevents panel maximization. An open PR (#305708) targets this fix.

## Change summary

Maximizing the bottom panel fails when a webview (e.g. PR overview) is open because hiding the find widget refocuses the webview, which reactivates the editor part.

## Best solution

Land or iterate on the open PR https://github.com/microsoft/vscode/pull/305708, which guards the focus call in `WebviewFindWidget.hide()` so it does not fire when the widget is hidden programmatically (not by user action).
