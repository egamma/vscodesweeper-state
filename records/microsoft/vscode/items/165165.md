[https://github.com/microsoft/vscode/issues/165165](https://github.com/microsoft/vscode/issues/165165)

## Summary

Keep open: current source still lacks an extension API for handling custom adapter-to-client requests, and maintainers expressed interest in the capability. The api-proposal label independently protects this issue from cleanup closure; API owners should settle the handler contract.

## Change summary

Allow extensions to handle custom reverse requests from debug adapters and return correlated responses.

## Best solution

Define an extension API for registering handlers for named custom reverse requests, including ownership and capability-negotiation semantics. Preserve built-in reverse-request handling and let API owners guide proposal adoption and eventual finalization.
