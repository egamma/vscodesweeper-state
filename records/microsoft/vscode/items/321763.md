# Issue #321763 — tcsh/csh shell integration

[https://github.com/microsoft/vscode/issues/321763](https://github.com/microsoft/vscode/issues/321763)

## Summary

Legitimate feature request for tcsh/csh shell integration, already promoted to backlog with 56 upvotes. No tcsh support exists in current main — the shell integration infrastructure only covers bash, zsh, fish, and pwsh. Keeping open.

## Change summary

Add terminal shell integration support for tcsh/csh shells, enabling command tracking, exit status detection, and correct agent interaction.

## Best solution

Implement a tcsh shell integration script (analogous to the existing bash/zsh/fish/pwsh scripts in `src/vs/workbench/contrib/terminal/browser/media/`) that injects the necessary hooks for command tracking, CWD detection, and exit code reporting. The shell type detection in `src/vs/workbench/contrib/terminal/common/` would also need updating to recognize tcsh/csh. Given the 56 upvotes and the EDA/HPC use case, this has clear community demand.
