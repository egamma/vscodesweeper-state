# Issue #272092 — `ref` auto-complete moves to top of list

[https://github.com/microsoft/vscode/issues/272092](https://github.com/microsoft/vscode/issues/272092)

## Summary

The full-match boost behavior is confirmed by-design in the current code (boostFullMatch in fuzzyScore), but a team contributor acknowledged the pain and suggested reconsidering or making it configurable — correctly labeled under-discussion.

## Change summary

Exact-prefix matches in IntelliSense (like `ref` matching the `ref` snippet) are boosted to the top of the completion list, causing unintended insertions.

## Best solution

Add a configurable setting (e.g. `editor.suggest.boostFullMatch`) to let users disable the full-match boost, or reconsider the boost heuristic so that rarely-used completions don't jump to the top solely on prefix equality.
