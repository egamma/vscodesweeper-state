## Change summary

Add an optional alternative command on TreeItem (mirroring menus.alt) that runs on modifier-click, instead of only a single TreeItem.command.

## Best solution

No existing API covers this — TreeItem only exposes a single `command?: Command` (src/vscode-dts/vscode.d.ts around line 5352), with nothing analogous to the `menus` contribution's `alt` key.
