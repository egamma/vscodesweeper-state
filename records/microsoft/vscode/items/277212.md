# Issue #277212 — Code review: Allow reviewing stacked commits and vs base branch

[https://github.com/microsoft/vscode/issues/277212](https://github.com/microsoft/vscode/issues/277212)

## Summary

Team-authored feature request for built-in code review against base branch and stacked commits, independent of the GHPRI extension. The related issue #277899 was closed as a duplicate of this one. Infrastructure exists (baseBranch fields in chatSessionsService) but the full UX is not yet shipped. Keeping open as the canonical tracker.

## Change summary

Allow reviewing the holistic diff of stacked commits against a base branch directly in VS Code's code review, without requiring the GitHub Pull Requests extension.

## Best solution

Implement a built-in 'review vs base branch' action in the chat/agent review surface that works independently of the GHPRI extension, covering AzDo and non-PR workflows. The baseBranch model fields in chatSessionsService.ts are a starting point; the UX needs a trigger in the review UI similar to the screenshot's changes panel.
