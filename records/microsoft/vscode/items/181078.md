# Issue #181078 — kernel quick pick flashes

[https://github.com/microsoft/vscode/issues/181078](https://github.com/microsoft/vscode/issues/181078)

## Summary

Keep open: current core kernel-picker code explicitly hides the picker between navigation steps, including before awaiting a provider command. The existing quick-pick routing is appropriate, and no verified canonical or fixing commit was found.

## Change summary

Keep the notebook kernel quick pick continuously visible while navigating its options and returning to previous steps.

## Best solution

Make the core notebook kernel-selection flow preserve a visible, focused quick-input surface across intermediate steps, including asynchronous provider handoffs. Preserve normal dismissal when the user cancels or completes selection.
