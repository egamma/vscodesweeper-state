# Issue #333607 — Agent Window: Add 'attach to chat' on session context menu

[https://github.com/microsoft/vscode/issues/333607](https://github.com/microsoft/vscode/issues/333607)

## Summary

Fresh, well-scoped feature request from a team member for the Agents Window session list — no such 'attach to chat' context-menu action exists yet, and there's nothing to close here.

## Change summary

Add an 'Attach to Chat' context-menu action on Agents Window sessions so a previous session can be referenced/attached as context in the current chat.

## Best solution

Implement as a new registerAction2 entry contributed to SessionItemContextMenuId in src/vs/sessions/contrib/sessions/browser/views/sessionsViewActions.ts, wiring the selected session as a chat attachment via the existing session-reference/attachment machinery (src/vs/sessions/services/sessions/browser/sessionReference.ts, src/vs/sessions/contrib/chat/browser/newChatContextAttachments.ts).
