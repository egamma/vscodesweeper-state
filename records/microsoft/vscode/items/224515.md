# Issue #224515 — Context menu gets too small depending on the cursor position

[https://github.com/microsoft/vscode/issues/224515](https://github.com/microsoft/vscode/issues/224515)

## Summary

The prior review's implemented-on-main close (citing commit 4e68b628, PR #249339 'Add window.menuStyle') was correctly refuted — that commit only added an opt-in, restart-gated setting; it did not change the default experience. On current main the default `window.menuStyle` is still `inherit`, and an explicit `// TODO@bpasero figure out the default` remains in the source, so users running with a native title bar (a common Linux/Windows configuration discussed throughout the thread) still get Electron's oversized Chrome-Refresh-styled native context menu out of the box.

## Change summary

Electron/Chromium's 'Chrome Refresh 2023' restyle made native (Electron) context menus render oversized/disproportionate on Windows/Linux, especially with a native title bar; the upstream Electron issue was closed as not planned.

## Best solution

Finish the unresolved default-value decision tracked by the `TODO@bpasero figure out the default` comment in desktop.contribution.ts — pick (or auto-detect) a `window.menuStyle` default that avoids the oversized native menu for native-title-bar configurations without requiring a manual, restart-gated setting change. There's already in-flight maintainer work in this exact area (see evidence).
