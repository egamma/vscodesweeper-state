# Issue #260659 — Only provide task output from `beginsPattern` when possible

[https://github.com/microsoft/vscode/issues/260659](https://github.com/microsoft/vscode/issues/260659)

## Summary

Keep open: current task-output retrieval does not consistently restrict output to the latest background build's beginsPattern boundary. The thread explicitly distinguishes this requirement from length-based truncation, and no verified fix or older canonical covers it.

## Change summary

Return task output from the latest identifiable build boundary so agents do not interpret historical build errors as current failures.

## Best solution

Make background-task output supplied to agents reflect the latest build cycle when its boundary is identifiable, while preserving useful output for tasks without such a boundary. Settle how terminal screen resets and problem-matcher beginsPattern boundaries interact before implementation.
