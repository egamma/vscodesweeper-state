# Issue #297044 — Metrics for AI Usage stats

[https://github.com/microsoft/vscode/issues/297044](https://github.com/microsoft/vscode/issues/297044)

## Summary

Keep this team-authored request open: the experimental statistics UI only partially covers the requested metrics, and no verified older canonical owns the full scope. Reconcile the proposed rollout with the newer proposal to remove the existing widget before implementation.

## Change summary

Expand AI usage statistics beyond time-based edit ratios to include model requests, accepted inline code, tool/MCP activity, weekday usage, and AI characters committed.

## Best solution

Agree on a small set of reliably attributable, clearly defined usage metrics and their presentation before expanding availability. Resolve whether those metrics should replace the existing gauge or live in a different surface alongside the removal proposal at https://github.com/microsoft/vscode/issues/340001.
