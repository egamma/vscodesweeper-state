# Issue #341659 — Stop "Agent host session" spam in git log --all

[https://github.com/microsoft/vscode/issues/341659](https://github.com/microsoft/vscode/issues/341659)

## Summary

Thanks for the report. The commits are intentional checkpoints that the agent host writes under hidden refs (`refs/agents/<session>/checkpoints/turn/N`). `git log --all` includes every ref, so they show up there. There is no setting to turn them off or to hide them from `--all`. The request is worth keeping open: checkpoint refs are clutter for users who run `git log --all`, and nothing cleans them up.

## Change summary

Stop agent-host checkpoint commits from appearing in `git log --all`, or provide a way to disable or clean them up.

## Best solution

Either store checkpoints in a way that `--all` does not list, or prune a session's checkpoint refs when the session is deleted. Also consider a setting to disable checkpointing, and document that `git log --branches` excludes these refs.
