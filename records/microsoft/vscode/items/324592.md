# Issue #324592 — Agents - you can delete a chat while in progress

[https://github.com/microsoft/vscode/issues/324592](https://github.com/microsoft/vscode/issues/324592)

## Summary

The defect remains source-reproducible: deleting the only running peer chat clears active-turn tracking but leaves the session's aggregate status as InProgress. This team-authored issue should remain open for a focused state-reconciliation fix.

## Change summary

Deleting an in-progress non-default chat can leave its parent session displayed as running even though no remaining chat is active.

## Best solution

Keep deletion available, but reconcile the session's aggregate status from the remaining chat catalog when a chat is removed, preserving InProgress when another chat is still running and returning to Idle otherwise.
