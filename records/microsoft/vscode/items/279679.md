# Issue #279679 — Failed to find pull request

[https://github.com/microsoft/vscode/issues/279679](https://github.com/microsoft/vscode/issues/279679)

## Summary

Still reproduces on main: the `findPR` method retries 7 times at 1500ms intervals, but a slow GitHub API response can still exceed that window, causing the 'Failed to find pull request' error even though the PR was created successfully. Multiple users confirm this race condition.

## Change summary

Delegating to the cloud coding agent shows 'Failed to find pull request' even though the PR was actually created, due to a race condition with GitHub API visibility.

## Best solution

Make the findPR failure non-fatal in the delegation flow — the PR exists, so the delegation succeeded; show the session with a 'PR details loading' state rather than throwing an error. Alternatively, increase the retry window or use exponential backoff. The fix belongs in `extensions/copilot/src/extension/chatSessions/vscode-node/copilotCloudSessionsProvider.ts` around line 2036.
