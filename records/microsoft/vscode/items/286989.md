## Summary

The original report (font distortion on resize with GPU acceleration in 1.108.0) was fixed upstream in xterm.js and shipped in 1.108.1 — confirmed by the reporter and multiple commenters. This is a duplicate of #286870.

## Change summary

Terminal font rendering becomes distorted/sharpened when resizing the terminal with GPU acceleration enabled on Windows.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/286870, which tracked and resolved the same xterm.js row-height rounding issue at 125% DPI.
