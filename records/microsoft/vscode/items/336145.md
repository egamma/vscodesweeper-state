# Issue #336145 — Support "on-delete rules" mirroring `onEnterRules`, to strip comment leaders on backward-merge

[https://github.com/microsoft/vscode/issues/336145](https://github.com/microsoft/vscode/issues/336145)

## Summary

Keep open as a language-configuration feature request: current deletion and joining behavior does not remove comment leaders, and no verified open canonical owns this declarative API request. The earlier extension-oriented decision concerned the Join Lines command, not the missing UI-process deletion hook.

## Change summary

Allow languages to declare comment-leader removal when Delete or Backspace merges adjacent lines, without intercepting keystrokes in the extension host.

## Best solution

An opt-in language-configuration contract for context-sensitive line merging, evaluated in the editor process while preserving ordinary deletion for unconfigured languages. Maintainers should first establish the public contract and Delete/Backspace semantics; existing whitespace trimming is not sufficient.
