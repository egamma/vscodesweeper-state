# Issue #156305 — [Bug] onDidAttemptReadOnlyEdit is not triggered by commands that edit

[https://github.com/microsoft/vscode/issues/156305](https://github.com/microsoft/vscode/issues/156305)

## Summary

Keep open: current source still suppresses Tab before it reaches the read-only edit notification path. This is a feedback-consistency improvement around intentionally disabled commands, and the existing editor-core routing is appropriate.

## Change summary

Provide read-only feedback when users invoke editing commands such as Tab in a read-only editor.

## Best solution

Establish which disabled editing commands should report an attempted read-only edit, then make their feedback consistent with ordinary typing. Preserve read-only protection and intentional Tab-based focus navigation.
