# Issue #312256 — bug: Custom agents duplicated in agent picker when same name exists in both org-synced and local paths

[https://github.com/microsoft/vscode/issues/312256](https://github.com/microsoft/vscode/issues/312256)

## Summary

Confirmed on current main: `computeAgentDiscoveryInfo` in `promptsServiceImpl.ts` collects agents from all source folders but has no name-based deduplication, unlike the skill discovery path which already deduplicates by canonical name with a defined precedence order. The bug is real and still present.

## Change summary

Custom agents with the same name from different sources (org-synced and local) appear as duplicates in the agent picker because agent discovery lacks name-based deduplication.

## Best solution

Add name-based deduplication to `computeAgentDiscoveryInfo` in `src/vs/workbench/contrib/chat/common/promptSyntax/service/promptsServiceImpl.ts`, mirroring the existing pattern used for skills: sort agents by source precedence (workspace > user/local > org-synced > extension), then skip subsequent agents with a name already seen. The skill dedup at lines 485–501 and the `getSkillPriority` helper at line 1297 are the template to follow.
