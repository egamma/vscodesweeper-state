# Issue #343933 — should we hide the ones that are already installed?

[https://github.com/microsoft/vscode/issues/343933](https://github.com/microsoft/vscode/issues/343933)

## Summary

Keep open for a product decision about whether Customizations Marketplace Browse should exclude installed items. Current source explicitly supports displaying installed cards, and the existing Installed filter does not provide the requested inverse filter.

## Change summary

Hide already-installed customizations from Marketplace Browse so discovery emphasizes items the user has not installed.

## Best solution

Decide whether Browse should exclude installed customizations by default or offer an explicit discovery filter, while retaining access to installed items through management and installed search. Apply the chosen behavior consistently across curated feeds and source-specific Browse sections.
