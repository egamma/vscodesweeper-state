# Issue #324401 — github issue reference not recognized as link

[https://github.com/microsoft/vscode/issues/324401](https://github.com/microsoft/vscode/issues/324401)

## Summary

The defect remains source-reproducible on current main: chat renders a fully qualified GitHub shorthand such as `microsoft/vscode#324399` as plain text rather than a clickable issue link. This team-authored report should remain open for a bounded chat-markdown fix.

## Change summary

Recognize fully qualified GitHub issue references in agent responses as clickable links.

## Best solution

Have the chat Markdown surface recognize `owner/repository#number` references outside code spans and render them as links to the corresponding GitHub issue, while preserving surrounding text and existing Markdown behavior.
