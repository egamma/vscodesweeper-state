# Issue #334722 — Welcome tab icon overlaps with default icon when using VS Code Modern Icons

[https://github.com/microsoft/vscode/issues/334722](https://github.com/microsoft/vscode/issues/334722)

## Summary

The screenshot and current source support a real visual bug in the built-in Modern Icons theme: the Welcome tab renders two offset file-icon treatments. The issue is unrouted and should remain open with the workbench tab/theme owners.

## Change summary

Activating VS Code Modern Icons causes the Welcome editor tab to show overlapping default and themed file icons.

## Best solution

Ensure editor tab labels render exactly one icon when a resource receives a file-theme icon, including synthetic resources such as the Welcome page, without changing normal file-tab icon behavior.
