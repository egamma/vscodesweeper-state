## Summary

Keep open: the discussion confirms a specific trigger—wrapping notebook Find from the last match to the first—after which scrolling an output also scrolls the notebook. No concrete fixing commit or eligible canonical duplicate was established.

## Change summary

Scrolling a cell output after notebook Find wraps between matches unexpectedly moves the notebook's outer scrollbar.

## Best solution

Preserve intentional notebook scrolling when navigating Find results, while ensuring subsequent scrolling inside an output does not unexpectedly move the notebook.
