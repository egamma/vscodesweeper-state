# Issue #177851 — Find in notebooks makes the notebook global scroll bar scroll when scrolling a cell output's scrollbar

[https://github.com/microsoft/vscode/issues/177851](https://github.com/microsoft/vscode/issues/177851)

## Summary

The bug remains unfixed on main: when notebook find wraps from the last match to the first, `revealCellOffsetInCenter` scrolls the notebook viewport, which conflicts with output scrollbar interaction. No commit addresses this issue.

## Change summary

Using Find in notebooks causes the notebook's global scrollbar to scroll when the user is scrolling a cell output's own scrollbar, particularly when wrapping from last to first match.

## Best solution

The reveal logic in `findModel.ts` should avoid scrolling the notebook viewport when the user is actively interacting with a cell output's scrollbar, or should use a less aggressive reveal strategy (e.g. `revealInView` instead of `revealCellOffsetInCenter`) when the target cell is already visible.
