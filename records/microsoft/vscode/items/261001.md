# Issue #261001 — Search Editor: typing on "files to include" does not respect the "Search on Type" setting

[https://github.com/microsoft/vscode/issues/261001](https://github.com/microsoft/vscode/issues/261001)

## Summary

The defect remains in current source: editing Search Editor file patterns starts searches without checking search.searchOnType, and those searches can move focus into results. The reporter supplied the requested recording, and the source confirms the described path.

## Change summary

Search Editor should respect the disabled Search on Type setting when users edit file inclusion or exclusion patterns.

## Best solution

Make Search Editor pattern typing honor search.searchOnType while preserving explicit Enter submission, enabled search-on-type debouncing, and the configured focus behavior for searches that actually run.
