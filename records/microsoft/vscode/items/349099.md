# Issue #349099 — Allow a separate model and reasoning effort for the Assisted Permissions judge

[https://github.com/microsoft/vscode/issues/349099](https://github.com/microsoft/vscode/issues/349099)

## Summary

The inspected configuration exposes reviewer instructions, but not independent Assisted Permissions model and effort selection. Keep this distinct feature request open for product consideration; neither suggested canonical owns this capability.

## Change summary

Allow a persistent provider, model, and supported reasoning-effort preference for Assisted Permissions reviews independently of the conversation model.

## Best solution

Consider runtime-supported reviewer selection with eligible provider/model discovery and a persistent user preference, preserving Copilot defaults when unset. Reviewer selection must remain separate from permission-mode activation, approval requirements, and enterprise enforcement.
