# Issue #113568 — Keep specific extension enabled while running Extension Bisect

[https://github.com/microsoft/vscode/issues/113568](https://github.com/microsoft/vscode/issues/113568)

## Summary

This remains the canonical request for keeping user-selected extensions active during Extension Bisect. Current main has special exclusions but no user-facing way to exclude an arbitrary required extension.

## Change summary

Allow users to keep selected extensions enabled throughout an Extension Bisect session.

## Best solution

Add an exclusion-selection step or equivalent configuration to Extension Bisect, then omit those extension IDs from its bisect state while leaving them enabled. The implementation belongs in `src/vs/workbench/services/extensionManagement/browser/extensionBisect.ts`.
