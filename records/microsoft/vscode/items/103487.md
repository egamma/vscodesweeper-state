# Issue #103487 — Text fails to drop after dragging a little too far to the left of the first column

[https://github.com/microsoft/vscode/issues/103487](https://github.com/microsoft/vscode/issues/103487)

## Summary

The defect remains visible in current source: dragging left can display a column-one drop indicator while mouse-up supplies a different or null target that the drop controller rejects.

## Change summary

Dropping selected text left of the editor boundary should honor the visible column-one insertion indicator.

## Best solution

Make the editor's drag and drop paths use one consistent target: preserve the computed outside-left position through mouse-up and accept it as a column-one drop, or hide the indicator when that target cannot be honored.
