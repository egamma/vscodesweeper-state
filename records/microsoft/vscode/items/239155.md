# Issue #239155 — terminal suggest: truncate beginning of long filepaths since they are all the same

[https://github.com/microsoft/vscode/issues/239155](https://github.com/microsoft/vscode/issues/239155)

## Summary

Keep open: current completion rendering still displays the repeated directory prefix rather than prioritizing the distinguishing path suffix. This team-authored Backlog request has maintainer interest, and no explicitly referencing fix or verified older canonical was found.

## Change summary

Shorten repeated leading directory paths in terminal suggestions so users can distinguish long file and folder completions.

## Best solution

Make distinguishing path suffixes readable in terminal suggestion rows while preserving full completion text, filtering, insertion, and access to complete path details. Treat quoted-path parsing as a separate concern rather than making it a prerequisite for this presentation improvement.
