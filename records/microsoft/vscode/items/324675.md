# Issue #324675 — Select on Find is delayed

[https://github.com/microsoft/vscode/issues/324675](https://github.com/microsoft/vscode/issues/324675)

## Summary

A second user confirmed the defect on a newer build with precise steps and a recording. Route this to the editor area to preserve native input selection when dragging beyond the Find input boundary.

## Change summary

Dragging to select text in the editor Find or Replace input stops updating when the pointer leaves the input boundary.

## Best solution

Adjust the editor Find widget or editor mouse-event handling so native input selection continues until mouse-up outside the input. Treat dragging an existing editor selection separately; users can disable that behavior with `editor.dragAndDrop`.
