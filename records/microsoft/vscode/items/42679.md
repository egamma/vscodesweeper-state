# Issue #42679 — [json] schema Validation/Intellisense very slow when JSON deep and Schema Complex

[https://github.com/microsoft/vscode/issues/42679](https://github.com/microsoft/vscode/issues/42679)

## Summary

This remains the canonical report for pathological validation and completion performance with deeply recursive, highly alternative JSON schemas. A maintainer diagnosed the exponential traversal, and a later report reproduced the same observable slowdown; no fixing commit or active PR was found.

## Change summary

Deep JSON documents backed by complex recursive schemas make validation and IntelliSense extremely slow or effectively unresponsive.

## Best solution

Optimize schema matching in microsoft/vscode-json-languageservice so alternatives known to have the wrong type are rejected before recursively validating their children, then consume the updated language-service version in VS Code.
