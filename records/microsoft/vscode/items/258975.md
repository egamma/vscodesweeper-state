## Summary

Valid feature request to visually distinguish static vs non-static members in the Outline view. The LSP SymbolTag enum currently only has `Deprecated`; a `Static` tag would need to be added upstream in LSP before VS Code could surface it. The related issues cited by a commenter are about tree performance, not about this feature. Keeping open as a feature request in the community process.

## Change summary

Visually distinguish static vs non-static properties/methods in the Outline view with icons or color differentiation.

## Best solution

This requires upstream LSP protocol work first — adding a `Static` tag to `SymbolTag` — before VS Code's outline tree renderer (`documentSymbolsTree.ts`) could consume and render it. The outline already handles `SymbolTag.Deprecated` with a CSS class; a similar pattern would work for a `Static` tag once it exists. Best tracked as a feature request; a maintainer may want to link to or file an LSP spec issue for the upstream protocol addition.
