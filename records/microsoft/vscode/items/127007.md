# Issue #127007 — Only sends a `textDocument/documentHighlight` request when on an identifier

[https://github.com/microsoft/vscode/issues/127007](https://github.com/microsoft/vscode/issues/127007)

## Summary

A real capability gap remains on current main: automatic document highlights are still restricted to word positions. The issue is already routed and accepted into the Backlog, with no canonical replacement found.

## Change summary

Request document highlights at non-word positions so language servers can highlight constructs such as Rust's `?` and `->` tokens.

## Best solution

Allow semantic document-highlight providers to run at arbitrary cursor positions while retaining word checks only for the textual fallback and request-reuse optimization. This belongs in the editor word-highlighter contribution.
