# Issue #146993 — Mouse flicking back and forth causing vscode to hang

[https://github.com/microsoft/vscode/issues/146993](https://github.com/microsoft/vscode/issues/146993)

## Summary

Keep open for targeted Linux reproduction and diagnosis: several users confirmed the activity-bar hover trigger, and neither hardware-acceleration changes nor desktop workarounds reliably resolve it. Later mitigation reports do not establish a fix for all affected configurations.

## Change summary

Approaching an activity-bar tooltip boundary can trigger persistent cursor flickering and leave VS Code unresponsive on Linux.

## Best solution

Establish whether current Linux builds still freeze at the activity-bar hover boundary, then isolate the failure between workbench hover handling and Electron/X11/compositor behavior. Preserve normal tooltips and supported zoom levels rather than requiring users to disable their compositor.
