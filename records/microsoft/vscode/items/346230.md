# Issue #346230 — Agents window: chat input text doesn't wrap when an attachment has a long file name

[https://github.com/microsoft/vscode/issues/346230](https://github.com/microsoft/vscode/issues/346230)

## Summary

Keep open: a maintainer confirmed that an attachment wider than the chat input causes horizontal scrolling and clipped text. Current source still gives inline pills a fixed maximum width rather than constraining them to the available input width.

## Change summary

Keep prompt text wrapping and truncate long attachment names within their pills in narrow Agents-window chat inputs.

## Best solution

Restore width-aware inline attachment layout in the shared chat input so oversized pills do not force horizontal scrolling, including when the chat column is resized. Preserve attachment identity, keyboard interaction, and prompt contents.
