[https://github.com/microsoft/vscode/issues/346230](https://github.com/microsoft/vscode/issues/346230)

## Summary

Keep open: a maintainer confirmed that an attachment wider than the chat input causes sideways scrolling and clipping. Current source still sizes inline pills independently of the available input width; no verified fix or canonical duplicate was found.

## Change summary

Long attachment filenames prevent prompt text from wrapping in a narrow Agents-window chat input.

## Best solution
