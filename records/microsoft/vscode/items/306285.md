# Issue #306285 — Custom Agent selection spontaneously resets to default when plugin auto update is enabled

[https://github.com/microsoft/vscode/issues/306285](https://github.com/microsoft/vscode/issues/306285)

## Summary

The reset remains source-reproducible on current main: refreshing a plugin agent temporarily publishes an empty agent list, causing the chat input to select and persist the default Agent before the refreshed definition returns. Route this to chat customizations for a bounded refresh-state fix.

## Change summary

Preserve the selected custom agent while an auto-updated plugin's agent definitions are asynchronously refreshed.

## Best solution

Keep the last resolved plugin components available while their replacement is being read, then publish the updated list atomically; genuine removals should still disappear once the refresh completes.
