# Issue #229511 — Chat file attachment - disambiguate when file name matches

[https://github.com/microsoft/vscode/issues/229511](https://github.com/microsoft/vscode/issues/229511)

## Summary

This issue (disambiguation of file attachments with the same name) is a specific case of #229572 (disambiguate links in chat with the same name), which is open, has the same labels, and was filed the same day by the same author to cover both input attachments and response links. Consolidating on #229572.

## Change summary

When attaching multiple files with the same filename to a chat message, the attachment labels are indistinguishable because the path is always hidden.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/229572, which covers the same disambiguation need for both input attachments and response links. The fix should conditionally show path segments in the label (or use `ResourceLabels` with `hidePath: false` / a `descriptionSuffix`) when duplicate basenames are detected among sibling attachments, in `src/vs/workbench/contrib/chat/browser/attachments/chatAttachmentWidgets.ts`.
