# Issue #207570 — Unable to update VS Code if authentication is previously canceled

[https://github.com/microsoft/vscode/issues/207570](https://github.com/microsoft/vscode/issues/207570)

## Summary

Still reproduces on main: canceling the macOS admin credential prompt during update download leaves the update service stuck in Downloading state because Electron's autoUpdater doesn't emit an error event for auth cancellation. No fix has been committed.

## Change summary

VS Code gets stuck in a 'Downloading Update' state with no recovery path when the macOS authentication dialog is canceled during an update.

## Best solution

Add a timeout or state-recovery mechanism in DarwinUpdateService that detects when the Downloading state has been active too long without progress, resets to Idle, and surfaces an actionable error message. Alternatively, investigate whether Electron exposes an event for auth cancellation. This may also require upstream Electron work to properly propagate the cancellation.
