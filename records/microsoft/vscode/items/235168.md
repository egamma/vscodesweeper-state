# Issue #235168 — Debugger hover doesn't work with parenthesized expressions

[https://github.com/microsoft/vscode/issues/235168](https://github.com/microsoft/vscode/issues/235168)

## Summary

The bug remains on current main: VS Code's fallback debug-hover heuristic splits at parentheses, so hovering a member of `(a).length` evaluates `.length` instead of the complete expression. The related issues do not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Debugger hovers fail to evaluate property or getter access when the receiver is enclosed in parentheses.

## Best solution

Teach the fallback evaluatable-expression selection to preserve a balanced parenthesized receiver when selecting member access, while retaining the existing boundaries for calls and unrelated expressions.
