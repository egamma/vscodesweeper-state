# Issue #324042 — On 'manageCheckboxStateManually', refreshing node with new checkbox state flips all parent checkbox states recursively

[https://github.com/microsoft/vscode/issues/324042](https://github.com/microsoft/vscode/issues/324042)

## Summary

The refresh path still performs automatic checkbox propagation without respecting manual checkbox management. This is a core tree-view API defect, not an extension-ownership issue, and should remain open for the tree-views area.

## Change summary

Refreshing extension-managed checkbox states unexpectedly overwrites ancestor checkbox states despite manageCheckboxStateManually being enabled.

## Best solution

Honor manual checkbox management consistently during tree refreshes, preserving extension-supplied ancestor and descendant states while retaining existing cascading behavior in automatic mode.
