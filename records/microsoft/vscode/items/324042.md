# Issue #324042 — On 'manageCheckboxStateManually', refreshing node with new checkbox state flips all parent checkbox states recursively

[https://github.com/microsoft/vscode/issues/324042](https://github.com/microsoft/vscode/issues/324042)

## Summary

Confirmed bug: `TreeView.updateCheckboxes` (line 1012) unconditionally calls `setCascadingCheckboxUpdates`, ignoring the `manuallyManageCheckboxes` flag — while the `TreeRenderer.updateCheckboxes` (line 1600) correctly gates on it. This causes parent checkboxes to be recursively flipped during refresh even when extensions opt into manual management.

## Change summary

When `manageCheckboxStateManually` is true, refreshing tree nodes with changed checkbox states still cascades parent checkbox state updates, overriding the extension's intended state.

## Best solution

Guard the `setCascadingCheckboxUpdates` call in `TreeView.updateCheckboxes` (src/vs/workbench/browser/parts/views/treeView.ts, line 1012) with a `manuallyManageCheckboxes` check, mirroring the pattern already used in `TreeRenderer.updateCheckboxes` (line 1600–1607).
