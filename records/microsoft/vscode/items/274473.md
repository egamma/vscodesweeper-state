# Issue #274473 — Generate Commit message not working

[https://github.com/microsoft/vscode/issues/274473](https://github.com/microsoft/vscode/issues/274473)

## Summary

Keep open: current source still allows commit-message generation to fail without actionable feedback. The discussion establishes several failure paths, and neither the remote-repository problem nor the broader silent-failure behavior is proven resolved.

## Change summary

Generate Commit Message leaves the SCM input unchanged without explaining repository, diff, or model-request failures.

## Best solution

Make the SCM generation action either produce a commit message or explain a non-cancellation failure, while diagnosing the reporter's remote-repository path separately. Preserve existing quota handling, content exclusions, and cancellation behavior rather than treating every empty result as the same defect.
