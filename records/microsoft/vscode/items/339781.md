# Issue #339781 — Support cron UI to address various scheduling needs

[https://github.com/microsoft/vscode/issues/339781](https://github.com/microsoft/vscode/issues/339781)

## Summary

Legitimate gap: the Automations UI only exposes manual/hourly/daily/weekly presets, with no monthly option or raw cron entry, even though the underlying scheduler already parses full 5-field cron expressions — a real but still-unscoped request, so it stays open for maintainer design input.

## Change summary

Add a cron-expression UI (and matching agent-tool support) to the Automations scheduling feature so schedules beyond daily/weekly (e.g. monthly, specific weekdays) can be configured.

## Best solution

Extend src/vs/sessions/contrib/automations/browser/automationDialog.ts's interval picker (and the automation creation tool schema) to accept cron expressions or at least a 'monthly'/custom-weekdays preset, reusing the cron parser already implemented in src/vs/platform/agentHost/node/automationCron.ts — but the exact UI shape (raw cron field vs. more presets) needs a maintainer decision first.
