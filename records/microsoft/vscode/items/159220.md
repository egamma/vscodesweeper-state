# Issue #159220 — Support empty workspaces edit sessions

[https://github.com/microsoft/vscode/issues/159220](https://github.com/microsoft/vscode/issues/159220)

## Summary

The capability remains explicitly unsupported on current main. This team-authored Backlog request should stay open until empty-workspace files can be represented and restored by Cloud Changes.

## Change summary

Allow edit sessions to store and resume files created in an empty web workspace.

## Best solution

Define an edit-session identity and serialization strategy for files outside workspace folders, then remove the empty-workspace resume guard in the Cloud Changes contribution and add store/resume coverage for that flow.
