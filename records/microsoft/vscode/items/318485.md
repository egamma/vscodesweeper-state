# Issue #318485 — Replying to a past conversation results in "Input item ID does not belong to this connection:

[https://github.com/microsoft/vscode/issues/318485](https://github.com/microsoft/vscode/issues/318485)

## Summary

This is a service-side Copilot API error (HTTP 400 from the Responses API backend) that occurs when replying to old conversations whose server-side connection context has expired. The error string does not appear in VS Code's codebase — it originates from the Copilot service. This is a specific instance of the request-failure pattern tracked by the open meta issue.

## Change summary

Replying to a past Copilot conversation returns a 400 error saying 'input item ID does not belong to this connection', with no way to recover by retrying or switching models.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/253136, which is the open meta-tracking issue for Copilot request failures. The root cause is service-side session/connection expiry in the Responses API — VS Code core could potentially improve the UX by detecting this specific error and offering to start a fresh conversation, but the underlying fix belongs to the Copilot service team. The reporter's note that retrying and model-switching don't help is useful context to carry over.
