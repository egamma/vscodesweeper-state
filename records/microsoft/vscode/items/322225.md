# Issue #322225 — Feature Request: Allow persistent Custom User-Agent in the Integrated Browser

[https://github.com/microsoft/vscode/issues/322225](https://github.com/microsoft/vscode/issues/322225)

## Summary

Confirmed gap: the integrated browser supports temporary user-agent overrides via device emulation but has no persistent setting. A team member (kycutler) acknowledged the gap and left this open as a feature request. It's in the Backlog Candidates 60-day community window with 4 upvotes so far — keeping open for the community process.

## Change summary

Allow configuring a persistent default User-Agent string for the integrated browser that survives tab changes and VS Code restarts.

## Best solution

Add a `browser.userAgent` setting (or similar) that feeds into `BrowserViewEmulator.setDevice()` as the default user-agent, applied automatically when new browser tabs are created. The implementation would touch `browserEditorEmulationFeatures.ts` and `browserViewEmulator.ts`. Let the community upvote process decide priority.
