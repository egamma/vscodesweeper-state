# Issue #347109 — Model compare: show original settings on hover of the parent chat

[https://github.com/microsoft/vscode/issues/347109](https://github.com/microsoft/vscode/issues/347109)

## Summary

The comparison parent currently shows progress rather than its original configuration, so the requested at-a-glance inspection remains missing. Keep this team-authored request open for design and implementation.

## Change summary

Show the original repository, branch/worktree, agent, and participant/reviewer model settings when hovering a comparison parent.

## Best solution

Provide a comparison-parent configuration summary using recorded launch metadata rather than current composer settings. Establish how original worktree selection and unavailable historical values should be represented before implementation.

- **Fit:** aligned
- **Reason:** An on-demand configuration summary improves clarity in the existing agent workflow without adding persistent interface clutter.
