[https://github.com/microsoft/vscode/issues/350766](https://github.com/microsoft/vscode/issues/350766)

## Summary

Keep open for investigation of writable Live Share guest editing in the Copilot harness. Current main already supports virtual-workspace writes, but the supplied steps need a Live Share retest to establish why this integration reports read-only files; they are sufficient to start that investigation.

## Change summary

Copilot Agent Host refuses edits in a writable vsls:// guest workspace where the Local harness succeeds.

## Best solution

Make Copilot harness edits honor the Live Share guest filesystem's actual write permissions through the existing virtual-workspace bridge, while preserving genuine read-only restrictions. First establish whether rejection originates in SDK tool execution, URI routing, or the client filesystem provider.
