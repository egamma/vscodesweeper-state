# Issue #184288 — Allow separate `when` clauses for each command in a keybinding with multiple commands

[https://github.com/microsoft/vscode/issues/184288](https://github.com/microsoft/vscode/issues/184288)

## Summary

Feature request remains unimplemented — the runCommands handler on current main only supports command+args per entry, with no per-command when clause evaluation. 18 upvotes and an On Deck milestone; keeping open.

## Change summary

Allow individual commands within a runCommands keybinding to have their own when clauses, so each command is conditionally executed.

## Best solution

Extend the RunnableCommand type in src/vs/workbench/contrib/commands/common/commands.contribution.ts to accept an optional `when` property, evaluate it via IContextKeyService before executing each command, and update the keybinding schema accordingly.
