# Issue #168389 — Add direct download link for GNU x64/arm builds

[https://github.com/microsoft/vscode/issues/168389](https://github.com/microsoft/vscode/issues/168389)

## Summary

The build infrastructure now produces both GNU (glibc) and musl (Alpine) CLI builds, but the download page still only surfaces musl CLI builds for x64/arm64 — the GNU variants are built but not linked. The maintainer explicitly accepted this as a tracking issue for adding those download links, so the remaining work is real and unfulfilled.

## Change summary

Provide direct download links for the GNU (glibc) x64/arm64 CLI builds alongside the existing musl/Alpine CLI builds.

## Best solution

The GNU CLI builds already exist in the pipeline (`x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu` in `build/azure-pipelines/linux/product-build-linux-cli.yml`). The remaining work is surfacing them on the download page (vscode-website) with clear labeling distinguishing GNU from Alpine/musl variants. Coordinate with https://github.com/microsoft/vscode-website/issues/2441.
