# Issue #75819 — [folding] Fold current level

[https://github.com/microsoft/vscode/issues/75819](https://github.com/microsoft/vscode/issues/75819)

## Summary

This remains a distinct, valid folding request: choose the fold level from the cursor instead of requiring users to count indentation levels. The existing commands and related issues do not clearly provide that cursor-relative operation.

## Change summary

Add a built-in “Fold Current Level” command that folds all regions at the fold level containing the cursor.

## Best solution

Define cursor-relative semantics for multiple cursors and boundary positions, then add an editor folding command that derives the enclosing region's level and folds regions at that level without requiring a selection.

- **Trace:**

  > The issue's central gap is between fixed numeric Fold Level commands and a cursor-derived level command.
