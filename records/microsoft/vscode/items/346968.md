# Issue #346968 — "Add folder to workspace" not working properly

[https://github.com/microsoft/vscode/issues/346968](https://github.com/microsoft/vscode/issues/346968)

## Summary

Keep open: independent commenters confirm the folder-navigation regression, and current source still separates checkbox selection from navigation poorly. A maintainer has accepted improving this flow; manually appending a separator is a workaround, not a resolution.

## Change summary

Restore discoverable navigation into nested folders while adding folders to a remote workspace.

## Best solution

The simplified folder picker should let users browse into directories without checking or submitting the parent, while retaining multiple-folder selection. Settle the navigation interaction before implementing the bounded dialog change.
