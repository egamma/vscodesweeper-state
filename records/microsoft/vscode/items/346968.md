# Issue #346968 — "Add folder to workspace" not working properly

[https://github.com/microsoft/vscode/issues/346968](https://github.com/microsoft/vscode/issues/346968)

## Summary

Keep open: the current multi-select folder picker suppresses ordinary folder-row navigation, matching the independently confirmed reports. The assigned 1.147.0 milestone also prohibits closing, and a maintainer has committed to improving this flow.

## Change summary

Restore discoverable navigation into nested directories when adding folders to a workspace through the remote folder picker.

## Best solution

Make folder navigation distinct from checkbox selection in the simplified file dialog, preserving multiple-folder selection and existing single-select behavior. Follow the maintainer's accepted UX improvement rather than treating manual path entry as resolution.
