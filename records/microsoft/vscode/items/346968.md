# Issue #346968 — "Add folder to workspace" not working properly

[https://github.com/microsoft/vscode/issues/346968](https://github.com/microsoft/vscode/issues/346968)

## Summary

Folder navigation conflicts with checkbox selection in the current simplified multi-select dialog. Keep this open: the source supports the reported failure, and two commenters independently confirm it.

## Change summary

Restore browsing into nested folders while adding folders to a workspace through the remote folder picker.

## Best solution

Make folder navigation available independently of checkbox selection in SimpleFileDialog, preserving the ability to add multiple checked folders and leaving other quick-pick consumers unchanged.
