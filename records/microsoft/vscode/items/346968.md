# Issue #346968 — "Add folder to workspace" not working properly

[https://github.com/microsoft/vscode/issues/346968](https://github.com/microsoft/vscode/issues/346968)

## Summary

Keep open: current source confirms that multi-select folder rows suppress click-to-navigate behavior, while checked folders are accepted immediately. The maintainer has committed to improving this flow; entering a trailing separator remains a workaround, not a resolution.

## Change summary

Restore intuitive browsing into nested folders in the remote Add Folder to Workspace picker while preserving folder selection.
