# Issue #346968 — "Add folder to workspace" not working properly

[https://github.com/microsoft/vscode/issues/346968](https://github.com/microsoft/vscode/issues/346968)

## Summary

The current source confirms a conflict between checkbox selection and folder navigation in the remote multi-select picker. Keep this open: clicking a selectable folder checks it rather than entering it, and accepting checked folders returns them before navigation runs.

## Change summary

Restore browsing into nested folders while using Add Folder to Workspace in a WSL window.

## Best solution

The simplified file dialog should distinguish browsing into a folder from selecting it for addition, preserving multi-folder selection and existing file-picker behavior.
