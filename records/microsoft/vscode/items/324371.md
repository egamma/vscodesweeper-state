# Issue #324371 — Cannot read properties of undefined (reading 'length') when built-in search tool returns 0 matches

[https://github.com/microsoft/vscode/issues/324371](https://github.com/microsoft/vscode/issues/324371)

## Summary

Confirmed real bug in the shipped Copilot Chat extension code (extensions/copilot), and an open PR already fixes it — keeping open pending merge rather than proposing any close.

## Change summary

The chat tool-result renderer crashes with 'Cannot read properties of undefined (reading length)' when a LanguageModelTextPart's value is undefined (e.g. a 0-match search result or a malformed MCP text part), showing red error text instead of the tool output.

## Best solution

Land https://github.com/microsoft/vscode/pull/329922, which coerces an undefined LanguageModelTextPart.value to '' in PrimitiveToolResult.render() before onText() reads content.length in extensions/copilot/src/extension/prompts/node/panel/toolCalling.tsx.
