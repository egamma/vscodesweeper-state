# Issue #324371 — Cannot read properties of undefined (reading 'length') when built-in search tool returns 0 matches

[https://github.com/microsoft/vscode/issues/324371](https://github.com/microsoft/vscode/issues/324371)

## Summary

The renderer defect remains present on current main, but an open PR directly fixes it and adds regression coverage. Keep the issue open while https://github.com/microsoft/vscode/pull/329922 is reviewed.

## Change summary

Prevent Copilot Chat tool-result rendering from throwing when a successful search result contains a text part whose value is undefined.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/329922, which normalizes an undefined tool-result text value at the shared rendering boundary and tests that the result renders as empty rather than throwing.
