# Issue #28636 — On highlight/select text - cannot unhighlight/deselect text on click - need to do ESC

[https://github.com/microsoft/vscode/issues/28636](https://github.com/microsoft/vscode/issues/28636)

## Summary

The accidental-drag path remains in current source: any pointer movement after pressing inside a selection starts drag-and-drop, preventing the expected deselection. This is the canonical, well-supported report and should remain open under discussion.

## Change summary

Allow clicking within selected text to collapse the selection despite slight unintended pointer movement.

## Best solution

Add a small movement hysteresis before editor text drag-and-drop activates, preserving ordinary click-to-deselect behavior without disabling `editor.dragAndDrop`.
