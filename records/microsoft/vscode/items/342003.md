# Issue #342003 — Sessions: PR refresh fails for PRs with auto-merge enabled, leaving stale "open" PR icons

[https://github.com/microsoft/vscode/issues/342003](https://github.com/microsoft/vscode/issues/342003)

## Summary

Confirmed on main: the strict auto_merge schema requires non-null commit_title/commit_message, which GitHub returns as null for default-message auto-merge, so the whole PR parse fails and the stale icon persists.

## Change summary

PR refresh fails schema validation when auto_merge has null commit_title/commit_message, leaving stale open PR icons in the Agents window.

## Best solution

Make commit_title and commit_message nullable in parsePullRequest's auto_merge schema and in the auto_merge type in core/pullRequests.ts, with a test for null values.
