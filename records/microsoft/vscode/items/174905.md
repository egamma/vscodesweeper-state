# Issue #174905 — Add a webview/title contribution point

[https://github.com/microsoft/vscode/issues/174905](https://github.com/microsoft/vscode/issues/174905)

## Summary

Valid feature request: no `webview/title` contribution point exists on current main. The workaround (`editor/title` + `activeWebviewPanelId`) is functional but can't identify which specific webview instance was clicked when multiple dynamic webviews share a viewType. The gap remains.

## Change summary

Add a `webview/title` contribution point so extensions can add buttons to webview editor title bars with proper per-instance context.

## Best solution

Introduce a `webview/title` menu contribution point that passes the webview panel identity (or a handle the extension can correlate to its `createWebviewPanel` call) as the command argument, closing the gap that `editor/title` leaves for multi-instance webview scenarios.
