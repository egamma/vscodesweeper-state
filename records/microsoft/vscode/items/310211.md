# Issue #310211 — Add an option to keep multiple remote repo accounts signed

[https://github.com/microsoft/vscode/issues/310211](https://github.com/microsoft/vscode/issues/310211)

## Summary

Both asks are already shipped: the GitHub authentication provider supports multiple simultaneously-signed-in accounts, and VS Code has a per-extension account preference picker so different tools (e.g. GitHub PRs, Copilot) can use different signed-in accounts without re-login — closing as already covered by current behavior.

## Change summary

Request to let VS Code keep more than one GitHub account signed in at once, with a way to choose which account is used where.

## Best solution

Point the reporter at `Accounts: Manage Accounts` (workbench.action.manageAccounts) to add a second GitHub account, and `Accounts: Manage Extension Account Preferences...` to pick which signed-in account each extension/feature uses — both already ship in core.
