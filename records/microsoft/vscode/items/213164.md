## Change summary

Notebook model reloads can trigger reentrant cell layout during a splice, dereferencing a null list row.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/319399, which marks notebook splices as rendering transactions so cell layout is deferred. The PR should reference this established canonical report, and https://github.com/microsoft/vscode/issues/319394 should be consolidated into it.
