# Issue #319373 — Digits become superscript in the hover tooltip in debug session with 'ss02' enabled as an option in editor.fontLigatures for any font

[https://github.com/microsoft/vscode/issues/319373](https://github.com/microsoft/vscode/issues/319373)

## Summary

Confirmed in source: the debug hover applies the full editor font info (including fontFeatureSettings like ss02) to its entire DOM node, causing digits to render as superscript when that OpenType feature is enabled.

## Change summary

Digits in the debug hover tooltip appear as superscript when editor.fontLigatures includes 'ss02'.

## Best solution

In debugHover.ts, after calling `this.editor.applyFontInfo(this.domNode)`, reset `fontFeatureSettings` to the default (or only apply font-family, size, and line-height without propagating fontFeatureSettings to the hover). The hover should show values in a readable form, not inherit stylistic OpenType features meant for the code editor.
