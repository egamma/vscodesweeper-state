# Issue #176665 — No diagnostics for the settings JSON split editor

[https://github.com/microsoft/vscode/issues/176665](https://github.com/microsoft/vscode/issues/176665)

## Summary

Team-authored bug that still reproduces on main: the Tab API returns `UnknownInput` for the settings JSON split editor (`PreferencesEditorInput`), so the JSON language server cannot determine the document URI and skips pull diagnostics. No fix commit found.

## Change summary

When `workbench.settings.openDefaultSettings` is true, opening user settings JSON in the split editor produces no JSON diagnostics (squiggles) because the Tab API cannot resolve the editor's input URI.

## Best solution

The `_editorInputToDto` method in `src/vs/workbench/api/browser/mainThreadEditorTabs.ts` needs to handle `PreferencesEditorInput` (or the underlying editor structure it wraps) so that the Tab API exposes the user settings JSON URI. The fix likely involves either making the preferences split editor expose its text resource inputs properly, or adding a specific case in `_editorInputToDto` for this editor type. @lramos15 was assigned to investigate in the last comment.
