# Issue #176665 — No diagnostics for the settings JSON split editor

[https://github.com/microsoft/vscode/issues/176665](https://github.com/microsoft/vscode/issues/176665)

## Summary

The diagnosed bug remains in current main: settings with `workbench.settings.openDefaultSettings` use a non-diff side-by-side input whose distinct resources are still reported to extensions as an unknown tab input, preventing diagnostics from tracking the editable settings document. This team-authored, accepted bug should remain open while the Tab API representation is designed.

## Change summary

Syntax errors in the editable half of the split JSON settings editor receive no diagnostics when default settings are shown alongside it.

## Best solution

Make the Tab API expose the editable settings resource, or both constituent resources, for non-diff side-by-side editors so diagnostic-pull clients can track the open document. The API owners should first settle the representation because choosing a primary-only input versus a dedicated side-by-side input changes the public contract.
