[https://github.com/microsoft/vscode/issues/107246](https://github.com/microsoft/vscode/issues/107246)

## Summary

The upstream behavior-changing fix is adopted by current main: Electron no longer overrides hidden-file visibility when configuring Linux file dialogs. Propose closing as completed, rather than duplicating the closed upstream reports.

## Change summary

Opening or cancelling a native file dialog must not reset the desktop's Show Hidden Files preference.

## Best solution

Keep the adopted Electron fix that leaves hidden-file visibility under desktop/user control; no VS Code-specific preference override or runtime preload workaround is needed.
