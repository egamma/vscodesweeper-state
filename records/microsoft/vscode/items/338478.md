# Issue #338478 — Support peer chats for quick chats

[https://github.com/microsoft/vscode/issues/338478](https://github.com/microsoft/vscode/issues/338478)

## Summary

Confirmed root cause on main: quick chats intentionally have `supportsMultipleChats` gated off, so peer chats created via the tool call flicker in and disappear, and clicking one does nothing. A maintainer already agreed in the thread that this restriction should be lifted, so this stays open as real, agreed-upon work.

## Change summary

Peer/side chats created from a workspace-less quick chat session don't render or open properly — they flicker into the Chats list and then vanish, and clicking one is a no-op.

## Best solution

Lift the `!isQuickChat` gate on `supportsMultipleChats` in baseAgentHostSessionsProvider.ts and fix whatever downstream assumption (likely folder/workspace assignment for a workspace-less session, or the list-item click handler) causes peer chats to disappear instead of opening — sandy081 already agreed on the direction in the thread.
