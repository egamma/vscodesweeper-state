# Issue #287844 — Copilot Agent create_file fails on NTFS data drive (D:) but works on C:\ and Dev Drive (ReFS)

[https://github.com/microsoft/vscode/issues/287844](https://github.com/microsoft/vscode/issues/287844)

## Summary

Keep open: two reporters observed Copilot incorrectly classifying accessible, non-ignored files as ignored, and the original reporter isolated a regression between Copilot Chat 0.33.5 and 0.36.1. The original drive-specific framing is likely incidental; repository metadata or ignore-policy resolution appears to be the stronger lead.

## Change summary

Copilot file tools reject writable workspace files as ignored, preventing file creation or reading despite no matching ignore configuration.

## Best solution

Diagnose the Copilot ignore-policy resolution path, especially repository-remote handling and Windows/WSL path normalization, then ensure file tools reject only paths matched by an actual configured policy or ignore rule.
