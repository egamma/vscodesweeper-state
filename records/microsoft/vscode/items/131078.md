Its body requests colored scrollbar indications for enclosing bracket ranges, explicitly to reveal where long code blocks start and end. This is the same missing overview-ruler visualization reported here, not merely another bracket-colorization feature.
- **Scope and re-review comparison:** The canonical covers whole enclosing bracket ranges, including their opening and closing boundaries. This report supplies refinements to that visualization—specified colors and left/middle/right ruler placement—and a Bracket Pair Colorizer 2 example. The older canonical therefore absorbs the central request; these details should accompany consolidation.
- **Existing capability is partial:** src/vs/editor/contrib/bracketMatching/browser/bracketMatching.ts defines bracket-match-overview decorations using editorOverviewRuler.bracketMatchForeground and OverviewRulerLane.Center. In _recomputeBrackets, direct bracket matches receive these markers, but enclosing brackets found while the cursor is inside a scope explicitly use decorations without overview-ruler markers.
- **Colorization and guides do not fill the gap:** src/vs/editor/common/model/bracketPairsTextModelPart/colorizedBracketPairsDecorationProvider.ts emits inlineClassName decorations without overviewRuler options. src/vs/editor/common/config/editorOptions.ts registers editor.bracketPairColorization.enabled and editor.guides.bracketPairs/bracketPairsHorizontal, but these provide inline colors and editor guides rather than the requested configurable ruler visualization.
