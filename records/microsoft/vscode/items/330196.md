# Issue #330196 — Incorrect tokens usage count in Agent Debug logs

[https://github.com/microsoft/vscode/issues/330196](https://github.com/microsoft/vscode/issues/330196)

## Summary

The reporter shows Agent Debug Logs sometimes reporting 0 input tokens while `/usage` shows correct numbers, and confirms the mismatch is intermittent across sessions (not always reproducible) — this looks like a real gap in how the debug log view derives token counts from OTel spans, but the exact trigger isn't pinned down yet.

## Change summary

Agent Debug Logs token usage counts sometimes don't match the numbers shown by the `/usage` command in the same session.

## Best solution

Investigate why `evt.inputTokens` in otelSpanToChatDebugEvent.ts (derived from `GenAiAttr.USAGE_INPUT_TOKENS` on the model-call span) is sometimes 0/undefined for a session while the `/usage` command — which likely reads from a different aggregation path — shows correct totals; likely a race or missing-attribute case when the span is captured before usage is set.
