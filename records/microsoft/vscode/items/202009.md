# Issue #202009 — ListError [codeActionWidget] Invalid start index: 2

[https://github.com/microsoft/vscode/issues/202009](https://github.com/microsoft/vscode/issues/202009)

## Summary

The stale-index race remains visible in current source: an asynchronous code-action hover can resume after the list has been hidden or rebuilt and splice using the obsolete event index. Keep this team-authored telemetry bug open and route it to the editor area.

## Change summary

The code-action widget can throw `ListError: Invalid start index` when an asynchronous hover result resumes after its list index is no longer valid.

## Best solution

Ensure a code-action hover result updates its row only while the widget is active and that row still represents the hovered element, with a regression test covering list replacement or teardown during the pending hover.
