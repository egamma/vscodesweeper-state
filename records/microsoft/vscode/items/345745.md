# Issue #345745 — Agents: Add group configuration's

[https://github.com/microsoft/vscode/issues/345745](https://github.com/microsoft/vscode/issues/345745)

## Summary

Group-specific defaults remain a real capability gap: creating a session from a group currently sets membership, not model or configuration defaults. Keep open as a feature request; the verified related issues do not own this specific behavior.

## Change summary

Allow custom session groups to supply model, settings, and scope defaults when creating a session through the group's plus button.

## Best solution

Evaluate group-level new-session presets in the Sessions area, defining supported defaults and their precedence relative to explicit choices, existing defaults, and managed policy before implementation.
