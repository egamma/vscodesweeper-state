# Issue #143533 — High contrast theme: activity bar hover only shown on bottom items

[https://github.com/microsoft/vscode/issues/143533](https://github.com/microsoft/vscode/issues/143533)

## Summary

Still open on main — the HC hover outline code applies uniformly via CSS (line 712 of activitybarPart.ts), but the `::before` pseudo-element's `padding: 6px` rule may not render correctly for extension-contributed `uri-icon` items whose label structure differs from native codicon items. Issue #245121 confirms this persists as of March 2025. No fix has merged.

## Change summary

In high contrast themes, hovering activity bar items shows a dashed outline inconsistently — some items (typically extension-contributed ones) lack the hover feedback.

## Best solution

The HC outline styling in `activitybarPart.ts` (lines 697–719) targets `.action-label::before`, but extension-contributed items using `uri-icon` class may not render the `::before` pseudo-element the same way as codicon items. The fix should ensure the hover outline applies regardless of icon type — either by targeting the action-item itself or by adding explicit `uri-icon` selectors to the HC outline rules. Issue https://github.com/microsoft/vscode/issues/245121 is a confirmed duplicate that could be consolidated here.
