# Issue #143533 — High contrast theme: activity bar hover only shown on bottom items

[https://github.com/microsoft/vscode/issues/143533](https://github.com/microsoft/vscode/issues/143533)

## Summary

Keep open: current code supplies hover outlines for codicon-based activity items, but URI/SVG-backed top items still lack the pseudo-element used to render that outline. The original consistency requirement remains incompletely satisfied; the newer related report is not an eligible duplicate target for this re-reviewed issue.

## Change summary

Make high-contrast hover feedback consistent across top view-container icons and bottom activity bar controls.

## Best solution

Provide equivalent high-contrast hover feedback regardless of an activity item's icon representation, while preserving selected-state, keyboard-focus, and drag-and-drop feedback. Retain this older issue as the consistency reference and coordinate the remaining URI-icon case with https://github.com/microsoft/vscode/issues/245121.
