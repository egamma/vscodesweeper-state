# Issue #227753 — Allow chat anchors to point to symbols

## Summary

The initial symbol-anchor proposal landed (commit 056fa7ada09, PR #227813) and the proposed API is in use, but it has not been finalized into the stable API — `vscode.d.ts` still only accepts `Uri | Location`, the proposed extension interface uses `value2`, and TODO comments remain. This issue tracks the full API lifecycle including finalization, so it should stay open.

## Change summary

Extend ChatResponseAnchorPart to accept SymbolInformation so chat anchors can render symbol-specific UX.

Finalize the proposed `ChatResponseAnchorPart` symbol anchor API: resolve the open TODOs (whether to use full `SymbolInformation`, whether to allow it without a location), merge `value2` into `value` in the stable API surface, and close this issue once the API is stable.
