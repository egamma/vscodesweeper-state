# Issue #227753 — Allow chat anchors to point to symbols

[https://github.com/microsoft/vscode/issues/227753](https://github.com/microsoft/vscode/issues/227753)

## Summary

Symbol-aware chat anchors are implemented in the proposed API, but the stable API still accepts only URI or location targets. Keep this api-proposal tracking issue open for the API owners to resolve the contract and finalization.

## Change summary

Allow chat response anchors to carry SymbolInformation and receive symbol-specific rendering and interactions.

## Best solution

Retain the existing symbol-anchor implementation while the API owners settle the symbol payload and resolution contract, then finalize the supported API in vscode.d.ts.
