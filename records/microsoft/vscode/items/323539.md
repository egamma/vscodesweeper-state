# Issue #323539 — Discoverability of #session

[https://github.com/microsoft/vscode/issues/323539](https://github.com/microsoft/vscode/issues/323539)

## Summary

Keep open: current main offers troubleshooting guidance and session autocomplete, but the inspected guidance does not explain how to select another session for troubleshooting. This team-authored Backlog request has neither a verified canonical duplicate nor an issue-referencing fix that would support closing it.

## Change summary

Make the /troubleshoot command and its use with #session discoverable without prior knowledge of either syntax.

## Best solution

Provide a discoverable path from troubleshooting guidance to selecting the session being investigated, building on the existing chat tips and session-reference completion. A maintainer should settle which user-facing entry point should teach or expose that workflow.
