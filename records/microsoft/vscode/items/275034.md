# Issue #275034 — Compare with main from GRAPH view claims the are no changes

[https://github.com/microsoft/vscode/issues/275034](https://github.com/microsoft/vscode/issues/275034)

## Summary

Keep open for the comparison-clarity improvement accepted by the maintainer. Current source still describes a directional comparison as symmetric, both in the empty-result notification and the editor title.

## Change summary

Make Git Graph comparison notifications and editor titles clearly convey the direction of the three-dot comparison.

## Best solution

Make the reference picker, empty-result notification, and comparison title consistently explain which reference supplies the changes and which is the comparison base. Preserve the existing directional Git comparison rather than changing it into a symmetric comparison.
