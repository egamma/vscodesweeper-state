# Issue #275034 — Compare with main from GRAPH view claims the are no changes

## Summary

Still open on main — the three-dot diff semantics and resulting UX confusion (misleading 'no changes' message and swapped editor labels) have not been addressed. Team-authored issue, keeping open.

## Change summary

The 'Compare with…' action from the Git graph uses three-dot diff, producing a misleading 'no changes' message and confusing editor labels when the selected commit is already reachable from the comparison ref.

## Best solution

Improve the information message at extensions/git/src/commands.ts:3267 to explain the three-dot semantics (e.g. 'All changes from A are already in B') and fix the editor label ordering in the multi-diff title at line 3276 so ref1/ref2 match what the user selected vs. picked.
