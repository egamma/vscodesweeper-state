# Issue #137502 — Markdown renderer unescape is not totally fixed

[https://github.com/microsoft/vscode/issues/137502](https://github.com/microsoft/vscode/issues/137502)

## Summary

Keep open: the reported trailing backslash remains explained by the bundled marked tokenizer removing punctuation before VS Code can unescape it. The earlier escape fixes do not cover this edge case, and no eligible canonical or concrete fixing commit was established.

## Change summary

Prevent JSON schema hover autolinks from retaining a stray backslash when a plain-text description ends its URL with a period.

## Best solution

Resolve escaped trailing punctuation handling at the marked tokenizer boundary and adopt that behavior in VS Code, preserving legitimate URL punctuation and the existing Markdown unescaping behavior.

## Evidence

- **Exact reproduction:** https://github.com/thw0rted/issue-examples/tree/vscode-json-schema contains data.jsonc referencing simple.schema.json. The value property's description is "Special word from the list at https://example.com/page."; hovering that property is the concrete trigger.
- **Confirmed tokenizer diagnosis:** https://github.com/microsoft/vscode/issues/137502#issuecomment-1167195996 traces the failure to marked's URL tokenizer: _backpedal drops the final period from an escaped URL, leaving its preceding backslash.
- **Current source retains the failing boundary:** src/vs/base/common/marked/marked.js:906-940 still applies _backpedal repeatedly and uses the resulting capture as the link href. Its _backpedal expression at line 1218 permits a backslash while excluding a terminal period. src/vs/base/browser/markdownRenderer.ts:118-130 subsequently calls removeMarkdownEscapes; src/vs/base/common/htmlContent.ts:211-215 only removes backslashes paired with punctuation, so it cannot remove the now-unpaired trailing backslash. This was inspected without executing code.
- **Description escaping path:** extensions/json-language-features/server/src/jsonServer.ts delegates hover generation to vscode-json-languageservice. The readable upstream JSONHover.doHover and toMarkdown in https://github.com/microsoft/vscode-json-languageservice/blob/main/src/services/jsonHover.ts escape periods in plain schema descriptions, supplying the escaped punctuation involved in this report.
- **Earlier fixes are not canonical targets:** https://github.com/microsoft/vscode/issues/14968 and https://github.com/microsoft/vscode/issues/16936 are closed reports about Markdown hover escaping. Neither is an open duplicate target, and their historical fixes do not establish that the trailing-backslash tokenizer case is resolved.
