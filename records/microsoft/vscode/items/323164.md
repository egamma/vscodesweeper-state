# Issue #323164 — Make sure Python auto activation work with agent host

[https://github.com/microsoft/vscode/issues/323164](https://github.com/microsoft/vscode/issues/323164)

## Summary

Active team-authored feature request tracking cross-repo work to ensure Python environment auto-activation functions correctly in agent host shell sessions. Related SDK APIs are in progress; nothing to close.

## Change summary

Python auto-activation (conda hooks, venv activation via shell startup scripts) does not run in agent host shell tool child processes because they bypass VS Code's shell integration and user rc/profile files.

## Best solution

Coordinate with the Copilot SDK team on the per-session shell initialization API (https://github.com/github/copilot-sdk/issues/1911, https://github.com/github/copilot-sdk/issues/2040) so that vscode-python-environments can inject its activation scripts into agent host terminal sessions. The VS Code side likely needs changes in `src/vs/platform/agentHost/node/agentHostTerminalManager.ts` or related terminal setup to pass init scripts through to the SDK shell tool.
