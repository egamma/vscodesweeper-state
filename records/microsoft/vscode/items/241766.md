# Issue #241766 — [Enhancement] In Watch panel: ability to see value on hover?

[https://github.com/microsoft/vscode/issues/241766](https://github.com/microsoft/vscode/issues/241766)

## Summary

Keep open: value hovers already exist over the value text, but hovering a typed Watch expression's name still shows its type. That does not fully address the reported narrow-panel workflow, where the long expression crowds out the value.

## Change summary

Make watched values accessible by hovering the expression name when long expressions leave little or no visible value text.

## Best solution

Let the debug area owner decide whether Watch name hovers should include the evaluated value alongside the existing type/name information. Preserve value-text hovers and avoid requiring panel resizing or clipboard use to inspect the reported case.
