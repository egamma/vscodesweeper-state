# Issue #241766 — [Enhancement] In Watch panel: ability to see value on hover?

[https://github.com/microsoft/vscode/issues/241766](https://github.com/microsoft/vscode/issues/241766)

## Summary

Valid enhancement: the Watch panel's name hover shows the expression type (not value), and the value portion has no hover at all, making it hard to read truncated values. The milestone is On Deck, so keeping open for maintainer judgment.

## Change summary

Request to show an expression's value (not its type) on hover in the Watch panel, so truncated values are readable without resizing.

## Best solution

In `watchExpressionsView.ts` `renderExpression()`, change the `title` on line 338 to show the value (or both type and value), and pass `hover: { commands }` to `renderValue()` on line 339 (as `renderVariable` already does in `debugExpressionRenderer.ts`) so the value portion also gets a full-text hover. This is a small, self-contained change in the debug area.
