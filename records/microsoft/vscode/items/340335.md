# Issue #340335 — BYOK Support for Copilot Agent Host Harness

[https://github.com/microsoft/vscode/issues/340335](https://github.com/microsoft/vscode/issues/340335)

## Summary

Keep open: current main still depends on client-provided BYOK inference and explicitly lacks remote BYOK support. This team-authored, multi-part architecture work remains necessary; local bridging and remote UI restrictions do not complete its host-owned provider lifecycle.

## Change summary

Provide plugin-configured BYOK models owned by the Copilot Agent Host, usable across sessions, client handoffs, and local or remote surfaces without requiring the originating extension host.

## Best solution

Complete the host-owned provider discovery, configuration, and lifecycle described in the issue, including local and remote configuration experiences. Evaluate the linked code-server implementation as reference work, while preserving the distinction between session-level provider registration and providers that remain available independently of any client or session.
