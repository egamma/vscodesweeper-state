# Issue #340335 — BYOK Support for Copilot Agent Host Harness

[https://github.com/microsoft/vscode/issues/340335](https://github.com/microsoft/vscode/issues/340335)

## Summary

Keep open: current source still supplies BYOK through client-owned renderer bridges, not session-independent model-provider plugins. This team-authored architecture work remains necessary; the related overview and remote-model reports do not replace its full scope.

## Change summary

Support Agent Host-owned BYOK model-provider plugins across Copilot SDK surfaces and local or remote clients, independently of individual sessions and client lifetimes.

## Best solution

Complete the runtime/plugin contract for session-independent provider lifecycle and manifest declarations, then integrate local and remote provider configuration in VS Code. Preserve client-independent inference and continuation without requiring credential roaming or broadly enabling unrelated extensions.
