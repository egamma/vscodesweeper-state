# Issue #334775 — API for extensions to register display-only keybinding hints

[https://github.com/microsoft/vscode/issues/334775](https://github.com/microsoft/vscode/issues/334775)

## Summary

A distinct API gap remains: extensions cannot supply runtime, context-dependent keybinding hints without registering dispatchable bindings. Keep this correctly routed request in community review; its 60-day Backlog Candidates window has not elapsed.

## Change summary

Allow extensions to register context-dependent display-only command shortcuts for mappings handled by their own input runtime.

## Best solution

Retain the request for community feedback and API-owner consideration. If accepted, provide a presentation-only contract that consistently represents extension-managed mappings across command surfaces without changing key dispatch, with explicit precedence and fallback semantics.
