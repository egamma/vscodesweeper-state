# Issue #331842 — VS Code update unexpectedly executes code-tunnel.exe tunnel kill, triggering endpoint security detections

[https://github.com/microsoft/vscode/issues/331842](https://github.com/microsoft/vscode/issues/331842)

## Summary

A VS Code collaborator confirmed the behavior is expected (the installer kills the running code-tunnel.exe to update it) but explicitly asked to keep this open to explore a less intrusive approach, so this should stay open rather than close as as-designed.

## Change summary

VS Code's auto-update kills code-tunnel.exe via `code-tunnel.exe tunnel kill`, which endpoint security tooling flags as suspicious SSH/lateral-movement activity (MITRE T1021.004).

## Best solution

Investigate whether the tunnel process can be terminated during update via a mechanism less likely to be misclassified by EDR heuristics (e.g. a different termination path/flag, or documenting the expected command line for security teams to allowlist) — likely in the install/update and tunnel CLI code (`cli/src/tunnels` or the Windows installer update scripts).
