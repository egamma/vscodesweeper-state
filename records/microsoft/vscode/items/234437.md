# Issue #234437 — Explorerer becomes empty when `package.json` is presented

[https://github.com/microsoft/vscode/issues/234437](https://github.com/microsoft/vscode/issues/234437)

## Summary

The bug remains source-reproducible on current main: a child nesting pattern containing multiple `*` characters reaches `SufTrie.add`, throws, and prevents the Explorer from producing its file list. The existing `file-explorer` routing is correct, and this issue is the canonical report for the same observable failure previously reported in the older, closed https://github.com/microsoft/vscode/issues/234423.

## Change summary

An invalid multi-wildcard file-nesting child pattern causes every file in the affected Explorer directory to disappear.

## Best solution

Keep the documented single-wildcard contract, but handle invalid child patterns defensively so they cannot abort Explorer enumeration; valid nesting patterns and ordinary files must continue to render normally.
