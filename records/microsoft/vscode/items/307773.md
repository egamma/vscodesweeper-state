# Issue #307773 — `workbench.action.tasks.runTask` or `Terminal` > `Run Task...` > `Configure Task` will force `tasks.json` file to be formatted in `JSON` format will cause all comments in the `tasks: []` to disappear

[https://github.com/microsoft/vscode/issues/307773](https://github.com/microsoft/vscode/issues/307773)

## Summary

This is a known limitation previously tracked and closed as *out-of-scope in issue #29453. The configuration service replaces the entire array value when writing, which inherently strips JSONC comments within that value. The team decided not to address this.

## Change summary

Configuring a task via the task quick pick UI strips JSONC comments from the `tasks` array in `tasks.json` because the configuration service replaces the entire array value.

## Best solution

Close as out-of-scope, consistent with the prior decision on https://github.com/microsoft/vscode/issues/29453. The root cause is that `IConfigurationService.updateValue` replaces the whole value for a key, losing any comments embedded inside the value's JSON structure. A fix would require path-level JSONC editing (e.g. using `jsonEdit` to insert/update individual array elements), which the team previously evaluated and declined to pursue.
