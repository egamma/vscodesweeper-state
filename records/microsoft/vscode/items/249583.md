# Issue #249583 — Add an option to open the Timeline view from the file's context menu in the Explorer and/or from the Source Control panel. This would make it easier to discover and use the Timeline feature for viewing file history.

[https://github.com/microsoft/vscode/issues/249583](https://github.com/microsoft/vscode/issues/249583)

## Summary

The Explorer already offers Open Timeline, but the requested shortcut from a file in Source Control remains missing. Keep this accepted Backlog request open for that remaining capability; no verified canonical issue covers it.

## Change summary

Make a file's Timeline accessible directly from its context menu in Explorer and Source Control.
