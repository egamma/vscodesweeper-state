# Issue #232113 — Allow relative paths in `typescript.tsserver.nodePath`

[https://github.com/microsoft/vscode/issues/232113](https://github.com/microsoft/vscode/issues/232113)

## Summary

The requested workspace-relative Node executable path remains unsupported on current main. Keep this accepted Backlog request open: it has 28 upvotes, and the linked implementation PR was closed without merging.

## Change summary

Allow workspace-relative paths in typescript.tsserver.nodePath without requiring a workspace-folder name prefix.

## Best solution

Support unprefixed workspace-relative Node executable paths in the TypeScript configuration provider, including the replacement js/ts.tsserver.node.path setting. Establish multi-root semantics while preserving existing explicit-folder paths and executable approval behavior.
