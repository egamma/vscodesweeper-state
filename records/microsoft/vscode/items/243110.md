# Issue #243110 — "Insert At Cursor" should be disabled when no text editor is opened

[https://github.com/microsoft/vscode/issues/243110](https://github.com/microsoft/vscode/issues/243110)

## Summary

The defect remains on current main: the chat code-block action is enabled without an eligible editor, while its operation then reports that a code or notebook editor must be opened. The issue has been explicitly triaged into the Backlog and should remain open for a bounded enablement fix.

## Change summary

Disable the chat code block's Insert At Cursor action when no text or notebook editor can receive the insertion.

## Best solution

Make the action's enabled state match the target-selection logic in InsertCodeBlockOperation, while preserving insertion into visible text editors and active notebook editors.
