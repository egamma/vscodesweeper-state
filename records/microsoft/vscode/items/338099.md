# Issue #338099 — Copilot Agent Window: BYOK custom models register in Chat but fail in agent sessions (session.model.switchTo 'not registered')

[https://github.com/microsoft/vscode/issues/338099](https://github.com/microsoft/vscode/issues/338099)

## Summary

Thanks for the detailed repro — this is the same root cause as microsoft/vscode#337742 (BYOK models not registered on a live Agent Host session, causing `session.model.switchTo ... is not registered`), which was fixed and merged in PR #338944 and shipped in milestone 1.141.0. Current main already has `CopilotAgentSession.setModel` sync its BYOK provider/model config via a single batch `rpc.provider.sync` call before switching models, exactly as the issue proposes.

## Change summary

BYOK custom models work in Chat but fail to register in Agent Window/agent-host sessions, producing `session.model.switchTo ... not registered` on model switch.

## Best solution

Keep the shipped fix from commit 08c674bd1a9ed2e84c5408e058361bd0f3e92377 (PR #338944, milestone 1.141.0): ask reporters still seeing this (especially over remote/Dev Containers) to confirm on the latest build, since the comments reporting it on Oct 1–6 may predate that fix reaching their stable/remote agent-host binary.
