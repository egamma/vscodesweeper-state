# Issue #209274 — Unicode character displayed as a question mark ?

[https://github.com/microsoft/vscode/issues/209274](https://github.com/microsoft/vscode/issues/209274)

## Summary

Confirmed Chromium upstream font-rendering issue on Linux — fullwidth Unicode characters render as tofu/question marks in all Chromium-based apps (Chrome, Edge, VS Code) but not in Firefox or native text editors. Already correctly labeled as `chromium`; no VS Code-specific fix is possible.

## Change summary

Fullwidth quotation mark U+FF02 (and likely other fullwidth Unicode characters) renders as a question mark or tofu box on Linux in VS Code.

## Best solution

This is a Chromium font fallback issue on Linux. The root cause is that Chromium's font fallback chain doesn't locate a font with the fullwidth glyph on certain Fedora configurations. The fix belongs upstream in Chromium's text rendering / font fallback logic. VS Code should keep this open as an upstream tracking issue until Chromium resolves it or an Electron update ships the fix.
