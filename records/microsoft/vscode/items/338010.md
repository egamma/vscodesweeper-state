# Issue #338010 — New Session from Pull Request cannot find draft pull requests

[https://github.com/microsoft/vscode/issues/338010](https://github.com/microsoft/vscode/issues/338010)

## Summary

Keep open: current source confirms that pasting a pull request URL cannot match the picker’s entries, although drafts themselves are not excluded. The reported draft-specific listing failure remains unconfirmed, and this team-authored report has neither a verified duplicate nor a citable fix.

## Change summary

Open draft pull requests should be discoverable and selectable when searching by text or pasting their URL into New Session from Pull Request.

## Best solution

Make eligible open draft pull requests discoverable through the Sessions pull request picker, including by URL. First distinguish the confirmed URL-filtering failure from any additional draft-specific listing problem; preserve existing fork and existing-session restrictions as separate work.
