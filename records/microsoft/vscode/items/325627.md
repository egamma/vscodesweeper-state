# Issue #325627 — Testing: Collapsible thinking close animation doesn't work during reasoning

[https://github.com/microsoft/vscode/issues/325627](https://github.com/microsoft/vscode/issues/325627)

## Summary

The missing active-reasoning transition remains visible in current source: fixed-scrolling thinking enables its collapse animation only after streaming completes. The issue should stay open for a bounded chat UI fix.

## Change summary

Collapsing a thinking section while reasoning is still streaming skips the close transition and changes state abruptly.

## Best solution

Apply the same short, interruptible transition to user-triggered expand and collapse actions during active reasoning that completed thinking uses, while retaining the streaming viewport behavior and reduced-motion opt-out.
