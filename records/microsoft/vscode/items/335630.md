# Issue #335630 — Toggling Sandbox for terminal should IMO not close the picker

[https://github.com/microsoft/vscode/issues/335630](https://github.com/microsoft/vscode/issues/335630)

## Summary

Real, confirmed bug in the new-session Agents Window picker: toggling the sandbox switch closes the permission/config picker instead of just flipping the toggle. It's also team-authored (dbaeumer) and freshly filed, so it stays open regardless.

## Change summary

The sandbox toggle inside the terminal-permission picker unexpectedly closes the whole picker on the new-session screen when clicked or activated with Space, unlike after a session has started.

## Best solution

Trace why the new-session-only full config re-resolve (noted in agentHostSessionConfigPicker.ts's own comment: 'In the new-session flow any property is changeable because changes trigger a full config re-resolve') tears down or re-renders the action widget's anchor while it's open; the fix likely needs to preserve the open picker across that re-resolve rather than letting the rebuild implicitly hide it.

## Evidence

- **confirmed repro:** Collaborator rzhao271 confirmed the picker closes both via Space and via mouse click, and specifically only on the main/new-sessions screen, not once a session has started.
- **toggle handling looks correct in general:** src/vs/platform/actionWidget/browser/actionList.ts:onListSelection (around line 2069) special-cases `element.standaloneToggle`: it flips the Switch and calls `onChange` without accepting the row, so the widget itself shouldn't close for standalone toggles like the sandbox switch.
- **likely differentiator:** src/vs/sessions/contrib/providers/agentHost/browser/agentHostSessionConfigPicker.ts (around line 468) documents that only the new-session flow triggers a 'full config re-resolve' on any property change, unlike the running-session flow where only mutable properties are editable — this re-resolve/re-render path is the plausible reason the picker unexpectedly disappears only pre-session-start.
- **sandbox toggle wiring:** src/vs/platform/agentHost/browser/agentHostSandboxToggle.ts and src/vs/sessions/contrib/providers/agentHost/browser/agentHostPermissionPickerDelegate.ts:224 (getSandboxToggle) build the standaloneToggle passed into both src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostChatInputPicker.ts and permissionPickerActionItem.ts.
