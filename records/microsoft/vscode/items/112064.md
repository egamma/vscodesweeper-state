# Issue #112064 — Pressing `shift-left/right` will exit multi-caret mode

[https://github.com/microsoft/vscode/issues/112064](https://github.com/microsoft/vscode/issues/112064)

## Summary

Still reproduces on main: when column selection mode is on and multi-cursors were created via alt-click, Ctrl+D, or after moving cursors from an initial column selection, shift+left/right collapses to a single cursor because `ColumnSelectCommand` only uses the primary cursor and reconstructs `columnSelectData` from it alone.

## Change summary

In column selection mode, shift+left/right exits multi-caret mode when cursors were created via alt-click, Ctrl+D, or after moving from an initial column selection.

## Best solution

Make `ColumnSelectCommand` (in `src/vs/editor/browser/coreCommands.ts`) multi-cursor-aware: when `_columnSelectData` is null but multiple cursors exist, derive the column select data from the full set of cursors (min/max line and visual column) rather than solely from the primary cursor. The fallback in `getCursorColumnSelectData()` (cursor.ts ~line 285) is the root cause.
