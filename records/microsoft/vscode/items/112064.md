# Issue #112064 — Pressing `shift-left/right` will exit multi-caret mode

[https://github.com/microsoft/vscode/issues/112064](https://github.com/microsoft/vscode/issues/112064)

## Summary

Keep open: current source still discards secondary cursors when Shift+Left/Right resumes column selection after ordinary movement, even when the cursors remain aligned. This is already correctly routed, with maintainer confirmation and no verified older same-symptom canonical.

## Change summary

Preserve aligned multi-cursor selections when restarting horizontal selection in Column Selection Mode after moving the cursors.

## Best solution

Make horizontal column selection retain the existing rectangular cursor span in the reporter's aligned-cursor case, while preserving box-selection semantics and ordinary multi-cursor behavior outside Column Selection Mode.
