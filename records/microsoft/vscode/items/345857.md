# Issue #345857 — Can't "Keep" or "Undo" chat file changes

[https://github.com/microsoft/vscode/issues/345857](https://github.com/microsoft/vscode/issues/345857)

## Summary

Keep open: current source rejects the reported sibling-fork editing sequence, leaving Keep and Undo unusable. The existing agent-host label is appropriate; the related reports do not establish an open canonical for this fork-specific defect.

## Change summary

Keep and Undo become permanently blocked after sibling forked chats sequentially modify the same file.

## Best solution

Make pending-change review work across sequential sibling-fork edits without losing accepted changes or overwriting unrelated edits. Establish consistent cross-chat edit ownership and baseline semantics across Working Set aggregation, acceptance, and discard.
