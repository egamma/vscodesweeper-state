# Issue #151284 — Dragging terminals tabs should group and ungroup them

[https://github.com/microsoft/vscode/issues/151284](https://github.com/microsoft/vscode/issues/151284)

## Summary

Still unimplemented on main. The terminal tabs DnD only reorders groups — it doesn't support dragging a tab onto another to group (split), or dragging out to ungroup. The list-widget infrastructure (ListViewTargetSector for between-vs-over drop targets) is now available (issue #200745 landed), but TerminalTabsDragAndDrop hasn't been updated to use it for grouping semantics. Author is a MEMBER, so keep-open regardless.

## Change summary

Allow dragging terminal tabs onto each other to group them (split view) and dragging tabs out of a group to ungroup them.

## Best solution

Update TerminalTabsDragAndDrop in src/vs/workbench/contrib/terminal/browser/terminalTabsList.ts to use the now-available ListViewTargetSector to distinguish between-item drops (reorder) from over-item drops (group/merge). The drop handler should call the appropriate terminal group service methods to join or split terminal instances. The blocking list-widget work (#200745) is complete.
