# Issue #195159 — TypeError: Failed to parse URL from /.vscode/extensions/rebornix.ruby-0.28.1/dist/server/tree-sitter.wasm

[https://github.com/microsoft/vscode/issues/195159](https://github.com/microsoft/vscode/issues/195159)

## Summary

The failure is caused by the deprecated third-party `rebornix.ruby` extension loading WASM generated by an outdated Emscripten version, not by VS Code's general WASM support. This is outside VS Code core and can be closed as caused by an extension.

## Change summary

Opening a Ruby project after upgrading to VS Code 1.82 causes the deprecated Ruby extension's language server to fail while loading `tree-sitter.wasm`.

## Best solution

The extension would need to rebuild its `tree-sitter.wasm` loader with the corrected Emscripten runtime; because `rebornix.ruby` is deprecated and archived, users should migrate to the maintained Ruby tooling.
