# Issue #195159 — TypeError: Failed to parse URL from /.vscode/extensions/rebornix.ruby-0.28.1/dist/server/tree-sitter.wasm

[https://github.com/microsoft/vscode/issues/195159](https://github.com/microsoft/vscode/issues/195159)

## Summary

The failure comes from the deprecated rebornix.ruby extension's bundled WASM loader, not VS Code's built-in Ruby support. Propose closing as caused by an external extension; the extension's own repository recommends migrating to Shopify Ruby LSP.

## Change summary

Opening a Ruby project after updating VS Code causes rebornix.ruby 0.28.1's language server to abort while loading tree-sitter.wasm.

## Best solution

Use the Ruby extension project's recommended Shopify Ruby LSP replacement and disable or uninstall rebornix.ruby. Any repair of the legacy extension's generated WASM loader belongs in https://github.com/rubyide/vscode-ruby, rather than changing VS Code's runtime globally.
