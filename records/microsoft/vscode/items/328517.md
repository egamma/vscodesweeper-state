# Issue #328517 — All prompts starting with / are highlighted

[https://github.com/microsoft/vscode/issues/328517](https://github.com/microsoft/vscode/issues/328517)

## Summary

Confirmed on current main: arbitrary slash-leading text is parsed as a prompt command and decorated in submitted requests. This team-authored issue should remain open for a targeted chat-input fix.

## Change summary

Slash-leading paths such as `/Users/...` are incorrectly highlighted as prompt commands in submitted chat requests.

## Best solution

Decorate a `ChatRequestSlashPromptPart` only when it resolves to an actual prompt slash command, while preserving asynchronous prompt discovery and valid command rendering.
