# Issue #328517 — All prompts starting with / are highlighted

[https://github.com/microsoft/vscode/issues/328517](https://github.com/microsoft/vscode/issues/328517)

## Summary

The highlighting defect remains source-reproducible on current main: any syntactically valid leading `/name` can be parsed and rendered as a prompt reference even when no such prompt exists. This team-authored issue should remain open for a bounded parser/rendering correction.

## Change summary

Only recognized slash commands and prompt-file commands should receive command-style highlighting; ordinary prompts beginning with `/` should remain plain text.

## Best solution

Distinguish discovered prompt slash commands from merely syntactically valid slash-prefixed text before producing the decorated request representation, while preserving existing behavior for registered commands and prompt files.
