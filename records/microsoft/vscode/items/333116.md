# Issue #333116 — New File or New Folder button on top of file explorer should ALWAYS create file/folder at or starting from cwd root instead of most recently selected/opened folder

[https://github.com/microsoft/vscode/issues/333116](https://github.com/microsoft/vscode/issues/333116)

## Summary

Traced on main: the New File/New Folder toolbar commands intentionally create relative to the currently selected explorer item (falling back to the workspace root only when nothing is selected), so a deeply nested selection changes where the new item lands — this is a real, reasonable ask for a way to always target the workspace root, not a bug.

## Change summary

Requests that the New File/New Folder toolbar buttons in the file explorer always create at the workspace root, instead of relative to the most recently selected item.

## Best solution

This is a product decision for the file-explorer owners: either change the toolbar buttons' default target to the workspace root, or add a setting/command variant for 'create at root' — the relevant logic is `openExplorerAndCreate` in src/vs/workbench/contrib/files/browser/fileActions.ts, which currently derives the target folder from `explorerService.getContext(false)`.
