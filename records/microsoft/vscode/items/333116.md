# Issue #333116 — New File or New Folder button on top of file explorer should ALWAYS create file/folder at or starting from cwd root instead of most recently selected/opened folder

[https://github.com/microsoft/vscode/issues/333116](https://github.com/microsoft/vscode/issues/333116)

## Summary

The toolbar actions intentionally create inside the selected folder, while clearing the Explorer selection targets the workspace root. A maintainer previously considered and rejected making these actions always target the root because that would break established contextual behavior.

## Change summary

Make the Explorer title-bar New File and New Folder actions always create at the workspace root rather than inside the selected folder.

## Best solution

Keep the context-sensitive toolbar behavior: create within the selected folder when one is selected, and create at the root after clearing the Explorer selection with Escape. This preserves both efficient nested creation and an existing path for root-level creation.
