# Issue #213045 — Webview scrollbars are seemingly unstyleable in Insiders

[https://github.com/microsoft/vscode/issues/213045](https://github.com/microsoft/vscode/issues/213045)

## Summary

Still reproduces on main: the webview's default styles set `scrollbar-color` (line 106 of index.html), which per Chrome 121+ behavior causes `::-webkit-scrollbar*` pseudo-elements to be ignored. PR #220121 is open but unmerged, so extensions cannot fully style webview scrollbars as before.

## Change summary

Webview scrollbars became unstyleable via `::-webkit-scrollbar*` pseudo-elements after Chrome 121 changed behavior when `scrollbar-color` is set.

## Best solution

Land https://github.com/microsoft/vscode/pull/220121 (or an equivalent approach) that avoids setting `scrollbar-color` in a way that blocks `::-webkit-scrollbar*` customization. The recent `@layer vscode-default` wrapper (commit 4791661313c) helps extensions override the default, but the root cause — the `scrollbar-color` declaration at line 106 of `src/vs/workbench/contrib/webview/browser/pre/index.html` — still disables webkit scrollbar pseudo-elements by default.
