# Issue #337058 — Electron 44 now supports system-themed window controls on Linux

Keep this request open through community review: current main still targets Electron 43.7.7, while the requested Linux window-control theming is implemented upstream. The Electron upgrade request is a dependency, not a verified duplicate of this user-visible requirement.

## Change summary

Use system-themed Linux window-control icons, including Breeze styling, while retaining VS Code's integrated custom title bar.

## Best solution

Adopt an Electron version containing the system-themed Window Controls Overlay implementation, then verify the existing custom-titlebar/native-controls configuration on KDE Plasma with Breeze. Preserve the integrated title bar and distinguish Electron's symbolic-icon support from full replication of arbitrary desktop decorations.
