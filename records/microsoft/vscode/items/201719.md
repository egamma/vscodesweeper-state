# Issue #201719 — Consider redesign of Search Editor ("search.action.openNewEditor")

[https://github.com/microsoft/vscode/issues/201719](https://github.com/microsoft/vscode/issues/201719)

## Summary

Keep open under discussion: Search Editor still embeds selectable line-number prefixes in its text, and existing settings do not distinguish their whitespace from source whitespace. The maintainer acknowledged a possible improvement, but the requested selection and presentation model remains undecided.

## Change summary

Distinguish Search Editor line-number metadata from source text during selection and whitespace rendering without removing the visible line numbers.

## Best solution

Decide whether Search Editor should support metadata-aware selection and whitespace rendering while preserving its intentional editable, saveable text workflow. A clipboard-only extension would address copying but not the full presentation request; a wholesale redesign is not yet justified.
