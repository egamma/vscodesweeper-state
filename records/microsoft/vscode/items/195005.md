# Issue #195005 — Auto-suggested '-->' doesn't overwrite when manually typing full HTML comment

[https://github.com/microsoft/vscode/issues/195005](https://github.com/microsoft/vscode/issues/195005)

## Summary

The requested multi-character overtyping remains unsupported on current main. Keep this accepted Backlog request open: existing settings do not deliver the requested behavior, and the verified related issues do not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Allow manually typed HTML comment terminators to consume the automatically inserted '-->', while preserving a terminator when typing diverges or continues on another line.

## Best solution

Extend the editor's multi-character auto-closing experience so typing the complete '-->' consumes the generated terminator without duplication, while divergent text and Enter retain a valid closing sequence. Preserve existing single-character overtyping behavior.
