# Issue #143962 — Replace `resourceUriProvider` web api with a descriptive/template variant

[https://github.com/microsoft/vscode/issues/143962](https://github.com/microsoft/vscode/issues/143962)

## Summary

The requested API redesign remains necessary: current main still retains the synchronous provider and explicitly rejects workers created by remote web extensions. This team-authored Backlog item should remain open.

## Change summary

Replace the function-based `resourceUriProvider` web API with a serializable descriptive or template form usable inside child workers.

## Best solution

Define a serializable URI-rewrite description in the web workbench API and propagate it into the web worker extension host, enabling remote extension resources to be translated without a main-thread callback.
