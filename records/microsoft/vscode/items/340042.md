# Issue #340042 — Agent Host retains customization listeners for tools that are not awaiting auth

[https://github.com/microsoft/vscode/issues/340042](https://github.com/microsoft/vscode/issues/340042)

## Summary

Confirmed on main: `_setupServerToolCall` registers an `onDidChangeCustomizations` listener for every server tool call regardless of state, kept alive by the response-part store until the turn ends. A draft fixing PR (#340043) already scopes this to the authentication-wait branch, so per policy this stays open for the human-owned PR to land rather than being closed now.

## Change summary

Agent Host keeps a customization-change listener alive for every tool call for the whole turn, even though only tools waiting on MCP authentication need it.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/340043, which moves the `onDidChangeCustomizations` subscription into the `AuthRequired` autorun branch so only auth-waiting tools hold a listener.
