# Issue #267864 — Restyle the tool overlay to use secondary colors

[https://github.com/microsoft/vscode/issues/267864](https://github.com/microsoft/vscode/issues/267864)

## Summary

Team-authored UX polish request. The 'X of Y' navigation bearing is now implemented, but the primary asks — secondary button colors and icon-only keep/undo buttons — remain unaddressed on current main. Part of the ongoing UI refresh effort.

## Change summary

Restyle the chat editing diff overlay toolbar to use secondary button colors and icon-only keep/undo buttons instead of primary-colored text buttons.

## Best solution

Update `chatEditingEditorOverlay.ts` and its CSS to use secondary button styling (remove the `primary` class or switch to `--vscode-button-secondaryBackground`) and switch to `icon: true, label: false` for keep/undo actions. This fits within the broader UI refresh tracked in https://github.com/microsoft/vscode/issues/295788.
