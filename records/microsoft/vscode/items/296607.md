# Issue #296607 — Navigate to next/previous changed file when reaching end of changes in current file (like IntelliJ)

[https://github.com/microsoft/vscode/issues/296607](https://github.com/microsoft/vscode/issues/296607)

## Summary

The remaining SCM navigation request is already tracked by an older, open issue covering the same observable limitation. Propose consolidating there while preserving this report's second-press/double-click interaction suggestion.

## Change summary

Allow repeated change-navigation actions at a file boundary to move to the adjacent changed file.

## Best solution

Resolve cross-file SCM change navigation in https://github.com/microsoft/vscode/issues/111596, carrying over the proposed boundary gesture. Preserve the existing multi-file navigation capability in the Multi Diff Editor.
