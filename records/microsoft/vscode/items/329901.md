# Issue #329901 — Native dialogs on Windows are auto-closing

[https://github.com/microsoft/vscode/issues/329901](https://github.com/microsoft/vscode/issues/329901)

## Summary

Active, well-traced bug: a contributor identified the root cause (Windows #32770 window class message collision between common file dialogs and task dialogs, mirroring electron/electron#52747) and a maintainer is actively engaging to confirm the diagnosis; an open fix PR already exists, so this should stay open pending investigation and landing of the fix.

## Change summary

On Windows, native dialogs (e.g. Help > About, sign-out) close immediately with a system ding instead of staying open, likely due to third-party software (DLP/endpoint agents) sending a conflicting window message that Electron misinterprets as a button click.

## Best solution

Land the fix in the open PR https://github.com/microsoft/vscode/pull/330128 ('dialogs: recover from unexpected native responses'), which appears to address the out-of-range button response id causing the dialog to close unexpectedly; this issue (and the several closed duplicates referencing it) should track that fix through to release.
