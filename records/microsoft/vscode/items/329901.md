# Issue #329901 — Native dialogs on Windows are auto-closing

[https://github.com/microsoft/vscode/issues/329901](https://github.com/microsoft/vscode/issues/329901)

## Summary

This is the canonical report for a cluster of "native dialog auto-closes" issues on Windows, root-caused by a collaborator to an Electron message-box response bug (electron/electron#52747, Windows message 0x0466 overloaded between CDM_GETFOLDERPATH and TDM_CLICK_BUTTON), and an open PR already targets it directly, so it should stay open pending that fix landing.

## Change summary

On Windows, native message boxes (About, confirmation dialogs, Delete, Sync Changes) close immediately with an invalid button response, apparently triggered by third-party software (e.g. DLP/endpoint agents) inspecting file/task dialogs.

## Best solution

Review and land the open fix in https://github.com/microsoft/vscode/pull/330128 ("dialogs: recover from unexpected native responses", which states `Fixes #329901`), which validates/logs native message-box responses and falls back to the custom dialog implementation for affected workbench dialogs; keep this open until that merges and ships.
