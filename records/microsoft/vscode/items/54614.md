# Issue #54614 — Rectangle commands for large file editing

[https://github.com/microsoft/vscode/issues/54614](https://github.com/microsoft/vscode/issues/54614)

## Summary

Keep open: the configurable cursor limit now permits editing more than 10,000 lines, but column selection still creates individual cursors rather than providing the requested cursor-independent rectangle operations. Neither maintainer-linked issue owns that remaining capability.

## Change summary

Provide efficient rectangle editing for large files without creating an active cursor for every affected line.

## Best solution

Evaluate cursor-independent rectangle operations in the editor, with explicit large-file performance requirements and a defined command scope. Preserve existing multicursor behavior; raising editor.multiCursorLimit is a useful workaround, not the requested alternative editing model.
