# Issue #169264 — zsh HISTFILE Hardcoded after #168396 fix

[https://github.com/microsoft/vscode/issues/169264](https://github.com/microsoft/vscode/issues/169264)

## Summary

Still reproduces on main: line 22 of shellIntegration-rc.zsh unconditionally sets HISTFILE=$USER_ZDOTDIR/.zsh_history before .zshrc is sourced, overwriting any custom HISTFILE set via terminal.integrated.env or .zshenv. An open PR (#314615) exists to fix it.

## Change summary

VS Code's zsh shell integration unconditionally overwrites the user's custom HISTFILE setting.

## Best solution

Land (or iterate on) the open PR https://github.com/microsoft/vscode/pull/314615 which preserves a custom HISTFILE. The fix should save any user-set HISTFILE before the override on line 22 of shellIntegration-rc.zsh and restore it after .zshrc sourcing, or skip the override when a custom value is detected.
