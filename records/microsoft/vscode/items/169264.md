## Evidence

- **Current source confirms the defect:** src/vs/workbench/contrib/terminal/common/scripts/shellIntegration-rc.zsh:21-23 unconditionally assigns HISTFILE=$USER_ZDOTDIR/.zsh_history when VSCODE_INJECTION is 1, before sourcing the user's .zshrc. A custom incoming HISTFILE is overwritten unless later startup configuration restores it.
- **Injected startup path:** src/vs/platform/terminal/node/terminalEnvironment.ts initializes VSCODE_INJECTION to 1 and its zsh branch installs shellIntegration-env.zsh as .zshenv and shellIntegration-rc.zsh as .zshrc. shellIntegration-env.zsh sources the user's .zshenv, so a HISTFILE established there is subsequently overwritten by the rc script. This was traced read-only; no shell execution was performed.
