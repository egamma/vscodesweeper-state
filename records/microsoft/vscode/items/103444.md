# Issue #103444 — Git - gutters don't show on filenames that have changed case

[https://github.com/microsoft/vscode/issues/103444](https://github.com/microsoft/vscode/issues/103444)

## Summary

Keep open: current source still carries cached filename casing into case-sensitive Git lookups, matching the confirmed reproduction and recent logs. The issue already has appropriate git and uri routing; resolving it should preserve editor identity while correcting Git pathname handling.

## Change summary

Case-only filename changes leave stale editor URIs that suppress Git gutter decorations and can misdirect selected-range staging.

## Best solution

Git operations should address the correctly cased tracked pathname even when an existing editor model retains another spelling. Cover case-only renames and restored editors without changing Git configuration or breaking case-insensitive model identity.
