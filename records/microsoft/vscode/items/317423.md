# Issue #317423 — AgentHost: characters rendered incorrectly in htop

[https://github.com/microsoft/vscode/issues/317423](https://github.com/microsoft/vscode/issues/317423)

## Summary

Valid visual rendering bug in the agent host terminal: box-drawing characters used by htop (and likely other ncurses apps) render incorrectly — a pipe/tee character shows as a backtick and vertical pipes appear disconnected. Filed by a team member with clear visual evidence comparing agent host vs. iTerm on the same target. No fix found on current main.

## Change summary

Box-drawing / line-drawing characters in htop render incorrectly (backtick, disconnected pipes) in the agent host terminal, while the same machine renders correctly via iTerm SSH.

## Best solution

Investigate the agent host terminal's handling of the DEC Special Graphics character set (or UTF-8 box-drawing codepoints) in `src/vs/platform/agentHost/node/agentHostHeadlessTerminal.ts` and the terminal rendering path. The headless xterm instance may not be forwarding charset-switching escape sequences correctly, or the font/glyph rendering on the client side may be losing box-drawing characters. Compare the data path with the regular VS Code integrated terminal, which renders htop correctly.
