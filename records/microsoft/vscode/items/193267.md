# Issue #193267 — Aux window: allow detaching views and panels

[https://github.com/microsoft/vscode/issues/193267](https://github.com/microsoft/vscode/issues/193267)

## Summary

Keep this canonical, strongly supported Backlog request open. Current main supports auxiliary editor windows and a few feature-specific paths, but not detaching arbitrary views or panel containers.

## Change summary

Allow sidebar views and bottom-panel content to remain attached to a workbench while being hosted in separate windows.

## Best solution

Extend the workbench view-container and layout infrastructure so movable views can be hosted in auxiliary windows while retaining the originating window's workspace, navigation, and command context. Preserve specialized editor-based workarounds without treating them as complete coverage.
