Keep open: current source can retain the pre-merge cloud repository tree even when returning to the Agents window triggers an Explorer refresh. No qualifying fix or verified older duplicate was established for this team-authored report.

## Change summary

A file deleted through a merged cloud-agent PR remains temporarily visible in the Files list and produces an unavailable-file error when opened.

## Best solution

Diagnose the reported open-file error alongside this refresh path without changing immutable revision browsing or local Explorer behavior.
