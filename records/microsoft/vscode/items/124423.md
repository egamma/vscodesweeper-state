# Issue #124423 — Allow defining save as file types for custom editors

[https://github.com/microsoft/vscode/issues/124423](https://github.com/microsoft/vscode/issues/124423)

## Summary

Still unimplemented on main: custom editors have no API to supply file-type filters for the Save As dialog. The `pickFileToSave` call in `customEditorInput.ts` passes no filters, and the `CustomEditorProvider` interface exposes no hook to define them. Keeping open as a valid, labeled feature request.

## Change summary

Allow custom editor extensions to define file-type filters shown in the Save As dialog.

## Best solution

Extend the custom editor API (likely `CustomEditorProvider` or a registration option) to let extensions supply `SaveDialogOptions.filters`, then thread those filters through `customEditorInput.ts`'s `saveAs` into `pickFileToSave`. The `help wanted` label is appropriate — this is a well-scoped API addition.
