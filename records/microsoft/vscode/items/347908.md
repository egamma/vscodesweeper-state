# Issue #347908 — Copilot command embeddings cache (16–19 MB) is rewritten on every window load, written twice on first load, and grows each time

[https://github.com/microsoft/vscode/issues/347908](https://github.com/microsoft/vscode/issues/347908)

## Summary

The current source confirms both redundant writes and loss of extension-cache provenance on reload. Keep open: the shared command/settings cache still needs a bounded correction.

## Change summary

Avoid redundant embeddings-cache downloads and writes while preserving extension ownership so removed extensions can be pruned.

## Best solution

Preserve the structured core/extension cache internally, expose flattened entries only to consumers, and persist once per actual cache change. Preserve standalone RemoteEmbeddingsCache behavior used by tool embeddings.
