# Issue #109959 — Horizonal Scrolling through pointer on scroll bar

[https://github.com/microsoft/vscode/issues/109959](https://github.com/microsoft/vscode/issues/109959)

## Summary

Reasonable but low-traction feature request: convert vertical scroll-wheel events to horizontal when the pointer hovers over the horizontal scrollbar track. The existing Shift+scroll mechanism and `scrollYToX` option already cover most of the need, but this specific UX refinement is not implemented. Only 2 upvotes in nearly 5 years — community interest is minimal.

## Change summary

When the mouse pointer is over the horizontal scrollbar, scroll-wheel events should scroll horizontally instead of vertically.

## Best solution

If pursued, add a wheel listener on the horizontal scrollbar's DOM node in `src/vs/base/browser/ui/scrollbar/horizontalScrollbar.ts` (or in `scrollableElement.ts` by detecting hover on the scrollbar track) that converts deltaY to deltaX. Given the low demand and existing Shift+scroll workaround, this is a valid keep-open but unlikely to be prioritized.
