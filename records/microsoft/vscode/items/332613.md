# Issue #332613 — CSS: var() fallbacks that contain commas are truncated to invalid CSS

[https://github.com/microsoft/vscode/issues/332613](https://github.com/microsoft/vscode/issues/332613)

## Summary

Confirmed real bug in asCssValueWithDefault: it splits the var() fallback on every top-level comma-containing function argument rather than only the first comma, truncating fallbacks like rgba(0, 0, 0, 0.5). A fixing PR is already open, so this should stay open pending review/merge rather than being closed or auto-fixed.

## Change summary

asCssValueWithDefault truncates var() fallback values that contain commas (e.g. inside rgba()), producing invalid/truncated CSS.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332623, which reportedly splits only at the first top-level comma and preserves the rest of the fallback, with regression tests, in src/vs/base/browser/cssValue.ts.
