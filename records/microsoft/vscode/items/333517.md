# Issue #333517 — `ctrl + enter` doesn't "create" in the New automation modal

[https://github.com/microsoft/vscode/issues/333517](https://github.com/microsoft/vscode/issues/333517)

## Summary

Confirmed real gap on main: the New Automation dialog binds plain Enter to insert a newline in the prompt editor (overriding the normal chat submit action), but no Ctrl+Enter (or any keyboard) path triggers the dialog's Save/Create button, so keyboard-only users have no way to submit once Enter is repurposed for newlines.

## Change summary

In the New Automation dialog, pressing Ctrl+Enter with focus in the Prompt field does not trigger the Create/Save action.

## Best solution

Add a Ctrl+Enter (Cmd+Enter on mac) handler scoped to the automations dialog that invokes the existing save button's click handler, mirroring how Enter is already special-cased for newline insertion in src/vs/sessions/contrib/automations/browser/automationDialog.ts.
