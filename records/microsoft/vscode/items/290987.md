# Issue #290987 — Surface setting for implement model in the split button

[https://github.com/microsoft/vscode/issues/290987](https://github.com/microsoft/vscode/issues/290987)

## Summary

The model used by Start Implementation remains undiscoverable in the handoff UI, and its dropdown offers continuation targets rather than model configuration. Keep this team-authored request open and route it to the plan-agent area.

## Change summary

Show the resolved implementation model on the Start Implementation button and provide model configuration through its split-button dropdown.

## Best solution

Have the plan handoff UI display the effective implementation model and expose a configuration action that clearly reconciles picker, setting, and custom-agent-file precedence. This likely spans the chat handoff widget and Copilot plan-agent model configuration.
