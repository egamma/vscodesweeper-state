# Issue #290987 — Surface setting for implement model in the split button

[https://github.com/microsoft/vscode/issues/290987](https://github.com/microsoft/vscode/issues/290987)

## Summary

The implementation-model setting exists, but the handoff button still neither previews the effective model nor offers model configuration. Keep this team-authored request open; the older settings-autocompletion request covers a different observable problem.

## Change summary

Show which model Start Implementation will use before invocation and provide model-configuration access from its split button.

## Best solution

Expose the effective implementation model at the handoff control and provide a discoverable configuration entry without changing model precedence or existing Continue In actions. Agree on how that entry handles settings-based versus agent-file overrides before implementation.
