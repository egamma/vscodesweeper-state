# Issue #247638 — side spacing on notebook output

[https://github.com/microsoft/vscode/issues/247638](https://github.com/microsoft/vscode/issues/247638)

## Summary

Valid polish request from a team member: the right-side padding on notebook output cells is visually excessive for image/chart outputs. No fix has landed on main; the layout values remain unchanged since the report.

## Change summary

Reduce the excessive right-side padding on notebook output cells, especially for image/chart content.

## Best solution

Investigate reducing `cellRightMargin` (currently 16px in `notebookOptions.ts`) or the `--notebook-output-node-padding` CSS variable for output containers in `backLayerWebView.ts` and `notebookEditorWidget.ts`. The output container's right margin is applied uniformly via `.notebookOverlay .output { margin: 0px ${cellRightMargin}px ... }` — the fix likely involves shrinking the right margin for output regions or making it context-aware for image outputs.
