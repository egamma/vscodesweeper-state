# Issue #174409 — File links in the error renderer are incorrect

[https://github.com/microsoft/vscode/issues/174409](https://github.com/microsoft/vscode/issues/174409)

## Summary

Still reproduces on main: the POSIX_PATH regex in the notebook-renderers linkify module includes trailing periods as part of the matched file path, because the `[\w\.-]` character class matches `.` without excluding it when it appears at the very end of the link.

## Change summary

Clicking a file link in notebook output that ends a sentence (path followed by `.`) opens an invalid path because the trailing period is included in the link.

## Best solution

Strip trailing punctuation (at minimum `.`) from the matched path in `extensions/notebook-renderers/src/linkify.ts`, analogous to how `WEB_LINK_REGEX` already excludes `,:;.!?` from the last character. A negative lookahead or a post-match trim would work.
