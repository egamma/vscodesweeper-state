# Issue #328730 — Add file context menu actions to the Agent Sessions Changes view

[https://github.com/microsoft/vscode/issues/328730](https://github.com/microsoft/vscode/issues/328730)

## Summary

Team-authored feature request describing a genuine gap: the Agent Sessions Changes tree has no right-click context menu at all, so a Discard/Revert action isn't reachable per-file the way it is in the standard SCM Changes view.

## Change summary

Add SCM-style file context-menu actions (especially Discard/Revert Changes) to files listed in the Agent Sessions Changes view.

## Best solution

Wire an `onContextMenu` handler on the Changes tree in src/vs/sessions/contrib/changes/browser/changesView.ts (createChangesTree) backed by a new context-menu MenuId, reusing the existing discard/revert MenuItemAction already available via MenuId.ChatEditingSessionChangesFileHeaderToolbar/AgentsChangeInlineToolbar and the ChangesViewActionRunner's discard-ref plumbing.
