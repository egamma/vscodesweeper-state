## Evidence

- **Verification protection:** The issue carries verification-found and was reopened. https://github.com/microsoft/vscode/issues/203857#issuecomment-5169291662 reports that only background1 appears at all indentation levels; the verification lifecycle requires keeping it open.
- **Existing configurable capability:** src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts assigns indentation-depth classes in getGuidesByLine and cycles the effective indentColorValues in its theming participant. src/vs/editor/common/core/editorColorRegistry.ts registers editorIndentGuide.background1 through background6 and corresponding activeBackground colors.
- **Important configuration boundary:** editorColorRegistry.ts defaults background2 through background6 and activeBackground2 through activeBackground6 to transparent. The indentGuides.ts theming participant excludes a level's color pair if either effective color is absent or transparent, so configuring only inactive colors without corresponding active colors can leave a one-entry palette. This explains a possible single-color path but does not establish the maintainer's exact configuration.
- **Earlier implementation is not a new fix:** https://github.com/microsoft/vscode/pull/178112 is merged and added indent-guide colorization options in July 2023. https://github.com/microsoft/vscode/issues/203857#issuecomment-5106117362 cited it when closing this report, but the subsequent reopening means that same implementation cannot justify another completed close.
