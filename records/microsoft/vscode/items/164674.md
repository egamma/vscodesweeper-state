# Issue #164674 — "Replace (Enter)" button breaks

[https://github.com/microsoft/vscode/issues/164674](https://github.com/microsoft/vscode/issues/164674)

## Summary

The bug remains on current main: disabling cursor movement while typing also prevents Replace from selecting the next match, causing alternating replace and navigation actions.

## Change summary

Make consecutive Replace actions replace the current match and select the next match when `editor.find.cursorMoveOnType` is false.

## Best solution

Decouple post-replacement navigation from `cursorMoveOnType` in the editor find model; that setting should govern typing behavior without changing consecutive Replace semantics.
