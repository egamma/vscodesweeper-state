# Issue #164674 — "Replace (Enter)" button breaks

[https://github.com/microsoft/vscode/issues/164674](https://github.com/microsoft/vscode/issues/164674)

## Summary

The defect remains in current source: disabling cursor movement while typing also prevents selection of the next match after replacement, requiring an extra Replace invocation each time. Keep this correctly routed issue open; the maintainer's comment establishes the expected post-replacement behavior.

## Change summary

With editor.find.cursorMoveOnType disabled, successive single replacements require two button clicks or Enter presses instead of one.

## Best solution

After an explicit single replacement, select the next match regardless of editor.find.cursorMoveOnType, while preserving the setting's suppression of navigation during search typing and the existing initial select-before-replace behavior.
