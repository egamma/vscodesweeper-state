# Issue #170868 — Adapt the bash of busybox.

[https://github.com/microsoft/vscode/issues/170868](https://github.com/microsoft/vscode/issues/170868)

## Summary

Still reproduces on main: the bash shell integration script uses `builtin`, `BASH_VERSINFO`, and other bash-specific constructs with no busybox detection guard. Three open PRs attempt to fix this but none have merged.

## Change summary

Shell integration errors when /bin/bash is actually busybox ash (common on Alpine Linux), because the script uses bash-only constructs without detecting busybox.

## Best solution

Land one of the open PRs (https://github.com/microsoft/vscode/pull/295061, https://github.com/microsoft/vscode/pull/300900, or https://github.com/microsoft/vscode/pull/320540) that adds an early-exit guard in `shellIntegration-bash.sh` when running under busybox ash. The guard should check for the absence of `BASH_VERSION` or presence of busybox indicators and return early.
