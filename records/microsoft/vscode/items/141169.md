# Issue #141169 — Trimming final newline is not POSIX standards compliant

[https://github.com/microsoft/vscode/issues/141169](https://github.com/microsoft/vscode/issues/141169)

## Summary

Keep open: this remains an active product-default discussion with substantial community demand, and the open implementation PR must be resolved before the issue can be closed.

## Change summary

Change VS Code's default behavior so text files, particularly LF files on POSIX systems, are saved with a terminating newline.

## Best solution

Decide the intended cross-platform semantics for final newlines, then review and either land or close https://github.com/microsoft/vscode/pull/175597. Any chosen default should preserve explicit user and workspace configuration while clearly distinguishing file mutation (`files.insertFinalNewline`) from visualization (`editor.renderFinalNewline`).
