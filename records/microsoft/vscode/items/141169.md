# Issue #141169 — Trimming final newline is not POSIX standards compliant

[https://github.com/microsoft/vscode/issues/141169](https://github.com/microsoft/vscode/issues/141169)

## Summary

The core request — defaulting `files.insertFinalNewline` to `true` on Linux (and possibly macOS) — remains unimplemented. PR #168220 only changed the *rendering* default (`editor.renderFinalNewline` to `dimmed` on Linux), which is a cosmetic step, not the substantive behavioral change. An open PR (#175597) by alexdima exists to turn on insertion but has not merged. With 37 upvotes and active discussion, this stays open.

## Change summary

Default `files.insertFinalNewline` to `true` on POSIX platforms (Linux/macOS) so saved files end with a newline without requiring manual configuration.

## Best solution

Land or close PR https://github.com/microsoft/vscode/pull/175597 (alexdima's open PR to enable `files.insertFinalNewline` on Linux). A maintainer decision is needed on whether to also include macOS and whether to change the default for all platforms. The 37 upvotes and recurring community friction justify resolving this.
