# Issue #337859 — Agent Host: chat URIs encode the owning session, contrary to AHP

[https://github.com/microsoft/vscode/issues/337859](https://github.com/microsoft/vscode/issues/337859)

## Summary

The reported protocol mismatch remains in current main: native chat identities encode session ownership, and the shared parser rejects the documented authority-less AHP form. Some advertised-resource handling now exists, but it does not complete the identity and compatibility work; keep this issue open.

## Change summary

Align Agent Host chat allocation and ownership resolution with opaque, server-allocated AHP chat identities while preserving existing persisted conversations and client compatibility.

## Best solution

Use independently allocated identities for new default, additional, and subagent chats, with ownership resolved through authoritative catalog state rather than URI decoding. Establish a compatibility contract for persisted legacy identities and older clients before changing allocation and restoration across the host and its consumers.
