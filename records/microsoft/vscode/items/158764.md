# Issue #158764 — Parallel tasks with INPUT selection does not run all tasks.

[https://github.com/microsoft/vscode/issues/158764](https://github.com/microsoft/vscode/issues/158764)

## Summary

The input-dialog race that skipped parallel dependencies was fixed by serializing interactive input requests in the shared configuration resolver. The reported 1.70.2 build lacks that queue; current main uses it for both local and remote tasks.

## Change summary

Parallel dependent tasks sharing a pickString input should all execute instead of earlier tasks being canceled by competing input dialogs.

## Best solution

Treat the skipped-task defect as completed by commit 0f2239fc7c2703312928b6f7ff9ce6642d2e3354. Keep the distinct enhancement to collect inputs once before dependency execution tracked in https://github.com/microsoft/vscode/issues/306748.
