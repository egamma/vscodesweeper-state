# Issue #158764 — Parallel tasks with INPUT selection does not run all tasks.

[https://github.com/microsoft/vscode/issues/158764](https://github.com/microsoft/vscode/issues/158764)

## Summary

Still reproduces on main: in parallel dependsOrder, all dependency tasks race to resolve the same input variable simultaneously via `resolveWithInteraction`, causing concurrent quick-pick prompts that cancel each other — only the last task's resolution succeeds.

## Change summary

When tasks with shared input variables run in parallel via dependsOn, only the last task executes because concurrent input resolution prompts cancel each other.

## Best solution

Pre-resolve all input variables needed by all dependency tasks before dispatching them in parallel, or serialize only the input-acquisition step while keeping execution parallel. The fix belongs in `terminalTaskSystem.ts` around the parallel dispatch loop (lines 535–583).
