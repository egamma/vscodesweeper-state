# Issue #129543 — Instruction breakpoints should maybe use a different breakpoint icon

[https://github.com/microsoft/vscode/issues/129543](https://github.com/microsoft/vscode/issues/129543)

## Summary

The requested distinction remains missing on current main: instruction breakpoints still use the regular circular breakpoint icon in both the Breakpoints view and disassembly gutter. The agreed red-square treatment is bounded and unimplemented, while the related discussions are newer and do not qualify as canonical duplicates for this re-reviewed issue.

## Change summary

Give instruction breakpoints a distinct red-square icon instead of the regular circular breakpoint icon.

## Best solution

Introduce a themed instruction-breakpoint icon based on the existing square codicon and use it consistently for enabled, disabled, and unverified instruction breakpoints in the Breakpoints view and disassembly gutter, without changing other breakpoint types.

- **Fit:** aligned
- **Reason:** Making breakpoint types distinguishable by shape improves accessibility while preserving the debugger's uniform visual language.
