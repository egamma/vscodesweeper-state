# Issue #193023 — "Format Notebook" damages LaTeX in Markdown cells

[https://github.com/microsoft/vscode/issues/193023](https://github.com/microsoft/vscode/issues/193023)

## Summary

The "Format Notebook" command delegates formatting to whatever DocumentFormattingEditProvider is registered for each cell's language. The user has prettier-vscode installed, which registers as a markdown formatter and is well-known to mangle LaTeX blocks. VS Code core does not modify the cell content — the damage comes from the extension's formatter.

## Change summary

Running "Format Notebook" corrupts LaTeX math in markdown cells of Jupyter notebooks.

## Best solution

The reporter should configure prettier to ignore markdown cells or LaTeX blocks (e.g., via prettier-ignore comments or disabling the markdown formatter for .ipynb). Alternatively, file against prettier-vscode to respect LaTeX fences. VS Code core correctly delegates formatting to the registered provider — no core change needed.
