# Issue #331655 — Cannot Log In to Github Copilot and Pull Requests with 2 Separate Enterprise accounts

[https://github.com/microsoft/vscode/issues/331655](https://github.com/microsoft/vscode/issues/331655)

## Summary

Verified duplicate of an existing, broader open feature request tracking the same architectural limitation (a single `github-enterprise.uri` setting/provider instance can't serve two different GHE servers for Copilot vs. Pull Requests at once).

## Change summary

User needs to sign into two different GitHub Enterprise servers simultaneously — one for Copilot, one for their internal GHE-hosted repos — but VS Code only supports a single `github-enterprise.uri`.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/277435 ("GitHub Enterprise should allow multiple servers"), which already describes this exact Copilot-vs-Pull-Requests scenario, is assigned to a maintainer, and sits in the Backlog milestone with active community support.
