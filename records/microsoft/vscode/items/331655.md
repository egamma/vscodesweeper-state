# Issue #331655 — Cannot Log In to Github Copilot and Pull Requests with 2 Separate Enterprise accounts

[https://github.com/microsoft/vscode/issues/331655](https://github.com/microsoft/vscode/issues/331655)

## Summary

Real architectural limitation, not a bug in the classic sense: the built-in `github-enterprise` auth provider is backed by a single global `github-enterprise.uri` setting and a single provider instance, so it cannot hold sessions for two different GHE hosts (one for Copilot, one for GitHub Pull Requests) at the same time.

## Change summary

User needs to sign in to two different GitHub Enterprise hosts simultaneously (one for Copilot at *.ghe.com, another internal GHE server for Pull Requests), but VS Code's `github-enterprise` auth provider only supports one configured host/URI at a time.

## Best solution

This belongs to the github-authentication extension (extensions/github-authentication/src/extension.ts and github.ts) and the auth-provider architecture more broadly — supporting multiple simultaneous GHE hosts would require either a per-host provider instance keyed by URI, or a way for the Pull Requests/Copilot extensions to request a session against a specific enterprise host rather than relying on the single global `github-enterprise.uri` setting. A maintainer/authentication-area owner needs to weigh in on the design.
