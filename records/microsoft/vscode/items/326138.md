# Issue #326138 — "Run C/C++ File" fails in PowerShell if path has spaces (missing & call operator)

[https://github.com/microsoft/vscode/issues/326138](https://github.com/microsoft/vscode/issues/326138)

## Summary

The failing command is generated by the C/C++ extension's Run C/C++ File action, not by VS Code core. C/C++ is owned by another Microsoft team, so this should be reported in its own tracker and closed here as caused by an extension.

## Change summary

Make the C/C++ extension prefix quoted executable paths with PowerShell's call operator when running a compiled file from a path containing spaces.

## Best solution

Update the C/C++ extension's run-command construction to emit `& "<executable path>"` for PowerShell, with regression coverage for workspace and executable paths containing spaces.
