# Issue #326138 — "Run C/C++ File" fails in PowerShell if path has spaces (missing & call operator)

[https://github.com/microsoft/vscode/issues/326138](https://github.com/microsoft/vscode/issues/326138)

## Summary

The "Run C/C++ File" button is provided by the ms-vscode.cpptools extension, which lives outside this repository — the command construction (including the missing `&` call operator) is owned entirely by that extension, not VS Code core.

## Change summary

The C/C++ extension's "Run C/C++ File" button sends paths with spaces to PowerShell without the `&` call operator, causing the path to be echoed as a string instead of executed.

## Best solution

This should be moved to https://github.com/microsoft/vscode-cpptools where the C/C++ extension team owns the task-running and command-construction logic for the play button.
