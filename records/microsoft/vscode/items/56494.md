# Issue #56494 — Add a context menu to entities listed in breadcrumbs

[https://github.com/microsoft/vscode/issues/56494](https://github.com/microsoft/vscode/issues/56494)

## Summary

Keep open: breadcrumb folders still lack the requested resource context menu, and this issue already serves as the canonical request. Its 38 upvotes and maintainer-directed duplicate consolidation support retaining it in the Backlog.

## Change summary

Provide context menus for breadcrumb entities, including creating a file in a selected folder without opening the Explorer.

## Best solution

Provide resource-aware breadcrumb context actions consistent with Explorer, with New File targeting the selected folder rather than the Explorer selection. Settle the initial action set and whether menus cover both breadcrumb segments and dropdown entries before implementation.

- **Trace:**

  > BreadcrumbsWidget in src/vs/base/browser/ui/breadcrumbs/breadcrumbsWidget.ts exposes selection and focus events; BreadcrumbsControl._onSelectEvent in src/vs/workbench/browser/parts/editor/breadcrumbsControl.ts routes these to navigation or BreadcrumbsFilePicker. - **Open decisions:**
