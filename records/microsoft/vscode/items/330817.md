## Summary

Thin, one-day-old report with no logs or confirmation from others; tracing the git extension's decoration pipeline (extensions/git/src/decorationProvider.ts, repository.ts) shows `onDidRunGitStatus` recomputes and fires decoration changes for the union of old/new decorated URIs whenever git status runs, which should normally clear the 'U' badge once a file is staged/committed — so the described flow isn't an obvious code-level bug, and more repro detail is needed to pin down the actual failure mode.
