# Issue #325356 — Pinned models don't follow model-family upgrades — new versions get buried in "Other Models"

[https://github.com/microsoft/vscode/issues/325356](https://github.com/microsoft/vscode/issues/325356)

## Summary

Well-reasoned feature request about the model picker's pinning UX; no family-aware 'latest' pin tracking or supersession-collapsing exists on main today, so the gap the author describes is real, but it's fresh (27 days), has 0 upvotes, and raises open design questions the maintainers haven't weighed in on yet.

## Change summary

Make pinned model entries track the latest version within a family instead of freezing to the exact pinned model, and collapse superseded versions out of the always-visible/'Other Models' areas.

## Best solution

Keep open under `model-picker` for maintainer input on how pin-bumping should interact with the existing server-driven 'Featured' mechanism (see the open question in the issue and the related umbrella https://github.com/microsoft/vscode/issues/317128); no design decision has been made yet.
