## Summary

Feature request for a search/filter to find sync-ignored settings and extensions remains unimplemented on current main. The milestone is On Deck (a holding bin), so it stays open on its merits.

## Change summary

Add a search filter (e.g. `@sync:ignored`) in the Settings editor and Extensions view to show which items are excluded from Settings Sync.

## Best solution

Implement a `@sync:ignored` filter query in both the settings editor and the extensions view, so users can quickly discover which items they've excluded from sync without inspecting `settingsSync.ignoredSettings` and `settingsSync.ignoredExtensions` arrays directly.
