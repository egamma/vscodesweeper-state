# Issue #340456 — Add chat archive button in the chat session

[https://github.com/microsoft/vscode/issues/340456](https://github.com/microsoft/vscode/issues/340456)

## Summary

Archiving a chat session currently exists only as an action on the Agent Sessions list item (agentSession.archive, registered on MenuId.AgentSessionItemToolbar / AgentSessionsContext) — there's no archive affordance inside the open chat session view itself. This is a genuine, not-yet-implemented gap rather than a duplicate of the nearby archive issues found.

## Change summary

Add a button inside the open chat session (near the thumbs-down/unhelpful control) to archive the current session without navigating back to the sessions list.

## Best solution

Surface the existing agentSession.archive command (src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsActions.ts) as a toolbar/inline action within the open chat session editor, reusing BaseArchiveAgentSessionAction's logic rather than building a new archive path.
