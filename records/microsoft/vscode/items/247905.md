# Issue #247905 — Improve UX for cell output -> chat dnd

[https://github.com/microsoft/vscode/issues/247905](https://github.com/microsoft/vscode/issues/247905)

## Summary

Team-authored polish issue requesting a visible drag-handle icon on notebook cell outputs to improve discoverability of output-to-chat drag-and-drop. The proposed UX change has not been implemented on current main — the existing drag overlay in webviewPreloads.ts is the transparent alt-key-driven mechanism, not the proposed visible icon. Stays open.

## Change summary

Add a visible drag icon to the upper-right corner of each notebook cell output element so users can discover output-to-chat drag-and-drop without needing to know about the alt-key modifier or direct-image dragging.

## Best solution

Implement the proposed drag-handle icon (per-output, upper-right corner) in the notebook output rendering layer — likely in the webview preloads output container setup and/or the cell output part. This would complement the existing alt-modifier text drag and direct image drag with a discoverable affordance.
