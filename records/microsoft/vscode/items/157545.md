# Issue #157545 — Hover indication can stuck on multiple submenu options in main menu

[https://github.com/microsoft/vscode/issues/157545](https://github.com/microsoft/vscode/issues/157545)

## Summary

The hover-stuck bug in deep submenus (3rd+ level) remains unfixed on current main — the MOUSE_OUT/MOUSE_OVER focus tracking in menu.ts has no guard against the race condition described. A team member acknowledged the report and it sits On Deck with a duplicate pointing here.

## Change summary

Hover indication can get stuck on multiple submenu items when moving the mouse in and out of 3rd+ level submenus.

## Best solution

Fix the race condition in `src/vs/base/browser/ui/menu/menu.ts` where the MOUSE_OUT handler clears `focusedItem` but re-entering during a submenu fade/disappear animation leaves stale `.focused` classes on multiple items. The MOUSE_OVER handler should ensure only one item carries the focused class at a time, regardless of animation timing.
