# Issue #110594 — Mouse positions influences initial selection on menus

[https://github.com/microsoft/vscode/issues/110594](https://github.com/microsoft/vscode/issues/110594)

## Summary

Still reproduces on main: the menu's mouseover handler focuses items when the menu appears under a stationary mouse, with no guard for initial mouse position vs. actual mouse movement. This is the canonical issue — three others were closed as duplicates of it.

## Change summary

When a menu is opened via keyboard, a stationary mouse pointer within the menu area causes incorrect item selection because the mouseover handler fires without requiring actual mouse movement.

## Best solution

Guard the MOUSE_OVER handler in `src/vs/base/browser/ui/menu/menu.ts` (line ~193) to ignore events until the mouse has actually moved after the menu opens — e.g., track the initial mouse position on menu creation and suppress focus changes until a mousemove delta is detected. This pattern is used by other UI frameworks to prevent 'phantom hover' on keyboard-opened menus.
