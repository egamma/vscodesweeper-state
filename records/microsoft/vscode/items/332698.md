# Issue #332698 — error message with remote-ssh: 0.126.0

[https://github.com/microsoft/vscode/issues/332698](https://github.com/microsoft/vscode/issues/332698)

## Summary

Multiple independent reporters confirm Remote - SSH 0.126.0 fails to activate due to a package.json#enabledApiProposals mismatch (missing `terminalRemoteResolver`), with downgrading to 0.124.x as a confirmed workaround. This is a defect in the Remote - SSH extension itself, which is Microsoft-owned but maintained and tracked in a separate repository (microsoft/vscode-remote-release), not in this one.

## Change summary

Remote - SSH extension version 0.126.0 fails to activate over SSH because its own package.json omits `terminalRemoteResolver` from `enabledApiProposals`, despite the API proposal check expecting it.

## Best solution

This needs to be tracked and fixed in microsoft/vscode-remote-release, where the Remote - SSH extension source and its release process live; the extension's package.json needs the missing API proposal restored (or the check reconciled) in the next release.
