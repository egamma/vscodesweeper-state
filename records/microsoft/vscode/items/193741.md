# Issue #193741 — gitlens doesn't set sideBarFocus, making sidbar keybindings difficult

[https://github.com/microsoft/vscode/issues/193741](https://github.com/microsoft/vscode/issues/193741)

## Summary

The bug remains source-reproducible on current main: sidebar focus is tracked through DOM events on the sidebar parent, while webview-view content is hosted in an overlay outside that DOM subtree. The newer related report confirms the same webview-view failure but cannot be the canonical duplicate for this previously reviewed older issue.

## Change summary

Focusing an extension-provided webview view does not set `sideBarFocus`, causing context-sensitive keybindings to run their editor commands instead.

## Best solution

Make focus entering or leaving a webview view update the focus context for the workbench part that contains the view, while preserving existing focus behavior for ordinary views and for webview views moved between the sidebar, panel, and auxiliary bar.
