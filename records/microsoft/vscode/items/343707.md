[https://github.com/microsoft/vscode/issues/343707](https://github.com/microsoft/vscode/issues/343707)

## Summary

Keep open: current main explicitly retains the route-attribution timing gap, and standard route-failure rows still lack usable correlation. The merged telemetry PR provides partial attribution, not the runtime contract requested here; this collaborator-authored item has no verified completing fix.

## Change summary

Provide deterministic runtime correlation so HydraFusion route and route-failure telemetry can be attributed to the owning Agent Host turn.

## Best solution

Have the Copilot SDK/runtime expose attempt_id on standard route and route-failure telemetry, then use the recorded attempt ownership in Agent Host to attribute both exactly. Preserve cancellation and steering ownership boundaries without timers or current-turn guesses.
