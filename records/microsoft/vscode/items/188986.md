# Issue #188986 — Navigation in notebook output matches always move the viewport

[https://github.com/microsoft/vscode/issues/188986](https://github.com/microsoft/vscode/issues/188986)

## Summary

Still reproducible on main: the output-match reveal path in notebook find unconditionally uses `revealCellOffsetInCenter` instead of a viewport-aware variant, causing unnecessary scrolling on every navigation step through output matches.

## Change summary

Navigating between notebook output find matches always scrolls the viewport to center, even when the match is already visible.

## Best solution

Add a `revealCellOffsetInCenterIfOutsideViewport` method (mirroring the existing `revealRangeInCenterIfOutsideViewportAsync` pattern) and use it on line 282 of `findModel.ts`, so output matches only scroll when necessary.
