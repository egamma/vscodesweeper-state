# Issue #188986 — Navigation in notebook output matches always move the viewport

[https://github.com/microsoft/vscode/issues/188986](https://github.com/microsoft/vscode/issues/188986)

## Summary

The output-match navigation path still unconditionally centers code-cell output matches, including matches already visible. Keep this open for a bounded notebook-find fix; the older related report concerns output scrolling and wraparound, not the same observable symptom.

## Change summary

Navigating notebook output search results should preserve the viewport when the next match is already visible.

## Best solution

Make notebook output-find navigation reveal matches only when necessary, consistent with input-match navigation, while preserving highlighting and navigation order.
