# Issue #302927 — To Do Tool items show unchecked on reload until you expand thinking block

[https://github.com/microsoft/vscode/issues/302927](https://github.com/microsoft/vscode/issues/302927)

## Summary

Keep open: current source still updates session todos when historical tool UI is materialized, making the reported expansion-dependent state plausible. The renderer has evolved since 1.113 Insiders, but the supplied steps suffice to retest; neither a qualifying fix nor a same-symptom canonical was verified.

## Change summary

Completed chat todos appear unchecked after reload until the thinking block containing their completion updates is expanded.

## Best solution

Restore the latest authoritative todo state independently of transcript rendering, so expanding historical thinking blocks cannot change current task status. First reproduce the reload sequence and establish which historical invocation overwrites the persisted state.
