[https://github.com/microsoft/vscode/issues/302927](https://github.com/microsoft/vscode/issues/302927)

## Summary

Team-authored visual bug where todo items inside collapsed thinking blocks lose their checked appearance on reload until the thinking block is expanded. No fix found on main referencing this issue; keeping open.

## Change summary

To Do Tool items inside collapsed thinking blocks display as unchecked on reload until the thinking block is manually expanded.

## Best solution

The todo list widget state (checked items) rendered inside a thinking content part needs to be restored from the serialized tool invocation output at load time, even when the thinking block is collapsed — likely requires the chatThinkingContentPart or chatTodoListWidget to eagerly process todo state from serialized data rather than deferring until DOM expansion.
