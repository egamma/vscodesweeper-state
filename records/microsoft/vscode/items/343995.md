# Issue #343995 — Escape doesn't close worktree cleanup dialog

[https://github.com/microsoft/vscode/issues/343995](https://github.com/microsoft/vscode/issues/343995)

## Summary

Keep open: the cleanup editor does not implement focus(), leaving a concrete path where opening its modal fails to move keyboard focus inside it and Escape cannot invoke the modal-scoped close command. This team-authored report has no verified fixing commit or canonical duplicate.

## Change summary

Escape should dismiss Worktree Cleanup after it opens in the Agents Window.

## Best solution

Make Worktree Cleanup honor the editor-pane focus contract so its existing modal Escape handling works immediately after opening. Preserve nested controls' Escape behavior and restore focus when the modal closes.
