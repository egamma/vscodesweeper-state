- **Behavior:**

  > An unrelated mapped network drive must not prevent enabling GitHub Environments for a project on a local disk. Registration should succeed without the absolute-local-directory error. Network-backed drives must remain excluded from automatic filesystem-root discovery, and ordinary local drives must remain available.
- **Trace:**

  > MissionControlSharingService._getFileSystemRoots enumerates Windows drives and filters UNC results returned by IFileService.realpath. DiskFileSystemProvider delegates that operation to the callback-based realpath wrapper in src/vs/base/node/pfs.ts, whereas MissionControlEnvironment._configure canonicalizes the resulting roots with fs/promises.realpath before rejecting UNC paths. The current sharing test supplies an already-UNC result and therefore does not exercise that implementation difference. Confirm the real Windows mapping results before choosing a change; preserve local-drive discovery and existing root authorization boundaries. The original enumeration change is https://github.com/microsoft/vscode/commit/1985b99ebff1c8873df128e58a6b2511cc0a627f.
