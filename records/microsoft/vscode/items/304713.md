# Issue #304713 — View References as Tree

[https://github.com/microsoft/vscode/issues/304713](https://github.com/microsoft/vscode/issues/304713)

## Summary

Legitimate, well-supported request (30 upvotes, already promoted to Backlog) asking the References view to group results in a nested folder tree like the Search view, instead of today's flat file-then-reference grouping; no implementation exists on main, so this stays open.

## Change summary

Add a tree/folder view mode to the References view (currently a flat list grouped only by file), matching the Search view's tree layout.

## Best solution

Extend extensions/references-view/src/references/model.ts (ReferencesModel/FileItem) to optionally nest FileItems under folder path segments, with a view-mode toggle mirroring the Search view's list/tree switch (as JayDi85's screenshot shows) — this is a product/UX decision for a maintainer to scope, not a one-pass bugfix.
