# Issue #111945 — Ligature incorrectly activated for 2 different tokens

[https://github.com/microsoft/vscode/issues/111945](https://github.com/microsoft/vscode/issues/111945)

## Summary

This is a duplicate of the open issue #231128, which tracks the same root cause — font ligatures incorrectly spanning across different TextMate token boundaries. The renderer emits each token as a separate <span>, but browsers still form ligatures across adjacent inline elements. No fix has landed on main.

## Change summary

Font ligatures are incorrectly rendered across characters belonging to different token categories, causing visual misrepresentation.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/231128, which tracks the general problem of ligatures spanning multiple TextMate scopes. The fix would involve breaking ligature context at token boundaries in the view line renderer (e.g. inserting a zero-width non-joiner or `<wbr>` between spans of different token types when ligatures are enabled).
