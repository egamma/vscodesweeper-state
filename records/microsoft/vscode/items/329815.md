# Issue #329815 — Custom Endpoint model is missing from Chats agent session model picker

[https://github.com/microsoft/vscode/issues/329815](https://github.com/microsoft/vscode/issues/329815)

## Summary

Traced on main: surfacing extension-registered BYOK models (including Custom Endpoint) into agent-host/Chats-Agent sessions is gated behind the experimental setting `chat.agentHost.byokModels.enabled`, which defaults to `false` and requires an agent host restart to take effect — so a model that only exists via the extension's LM API (used by regular `Chat: Open Chat`) won't show in the agent-host session picker until that flag is turned on.

## Change summary

A Custom Endpoint BYOK model, added and working in regular Agent-mode chat, does not appear in the Chats page's Agent session model picker.

## Best solution

Have the reporter enable `chat.agentHost.byokModels.enabled` and restart the agent host process; if the model still doesn't appear afterward, that would be a genuine follow-up bug distinct from this report.
