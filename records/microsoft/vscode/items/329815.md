# Issue #329815 — Custom Endpoint model is missing from Chats agent session model picker

[https://github.com/microsoft/vscode/issues/329815](https://github.com/microsoft/vscode/issues/329815)

## Summary

Same root cause as the open, earlier-filed https://github.com/microsoft/vscode/issues/329545: Agent Host BYOK/Custom Endpoint models are gated behind `chat.agentHost.byokModels.enabled`, which defaults to `false` and is tagged experimental/advanced so it isn't discoverable in Settings — that fully explains this report's missing model in the Chats Agent session picker.

## Change summary

A Custom Endpoint (BYOK) model configured via Manage Models doesn't appear in the Chats Agent session model picker, even though it works in the regular Chat/Agent-mode surface.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/329545, which already tracks the same `chat.agentHost.byokModels.enabled` gating/discoverability problem; that issue should also capture the second reporter's finding here that even with the setting enabled, extension-contributed BYOK models (e.g. via `smallmain.vscode-unify-chat-provider`) are visible but unusable in the Agent Host session — a possibly-distinct follow-on bug worth flagging separately if it persists once the setting is surfaced.
