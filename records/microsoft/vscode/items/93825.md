# Issue #93825 — Allow context key expression that compares object properties

[https://github.com/microsoft/vscode/issues/93825](https://github.com/microsoft/vscode/issues/93825)

## Summary

No new context-key operator for comparing/traversing object-property values exists on main, and the previously-cited fix commit was already refuted on re-review, so the underlying gap remains; with zero community upvotes after 5+ years this is better tracked as under-discussion than left to go quiet.

## Change summary

Request a context key expression operator/mechanism that can compare nested object-property values (e.g. `timeline.excludeSources.<id>`), since `ContextKeyChangeEvent.affectedKeys` only reports the top-level configuration key, not synthesized nested keys.

## Best solution

If pursued, add either a dedicated context-key operator for object-property access or a documented JSON-stringify-and-regex convention, plus make the context key change-event machinery aware of nested/synthesized keys derived from a single configuration key — this needs a maintainer design decision (jrieken floated two directions in the thread) before any implementation.
