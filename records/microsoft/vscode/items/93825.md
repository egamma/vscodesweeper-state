# Issue #93825 — Allow context key expression that compares object properties

[https://github.com/microsoft/vscode/issues/93825](https://github.com/microsoft/vscode/issues/93825)

## Summary

Implemented and shipped: the `in` context-key operator supports testing whether a context-key value is a property of an object, with changes to the object key triggering reevaluation.

## Change summary

Allow context-key expressions to react when a named property is removed from or added to an object-valued context key.

## Best solution

Use the shipped `<itemContextKey> in <objectContextKey>` expression, implemented by commit 8ca857a92eab6ea49210d032c510edbe3fabe4e1 and available since VS Code 1.49.0.
