# Issue #317118 — markdown diff markers bleed into preview

[https://github.com/microsoft/vscode/issues/317118](https://github.com/microsoft/vscode/issues/317118)

## Summary

The underlying rendering bug remains on main — diff markers bleed into the markdown preview when edits are inside code blocks. Mitigation has been added (a warning and making the preview opt-in for diffs) but the core issue is unresolved.

## Change summary

When viewing a markdown diff in the rendered preview, diff markers (added/removed line indicators) leak into code block rendering.

## Best solution

Fix the markdown preview's diff rendering to properly strip or handle diff markers before rendering code blocks. The rendering logic lives in extensions/markdown-language-features/src/preview/documentRenderer.ts.
