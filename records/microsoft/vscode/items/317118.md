# Issue #317118 — markdown diff markers bleed into preview

[https://github.com/microsoft/vscode/issues/317118](https://github.com/microsoft/vscode/issues/317118)

## Summary

The code-block marker leak remains in current source: diff spans are inserted before Markdown parsing and become visible escaped text inside fenced code. Keep this older report open; the related list and Mermaid reports do not provide an eligible canonical for this re-reviewed item.

## Change summary

Prevent internal Markdown diff markers from appearing as literal text when edits occur inside code blocks.

## Best solution

Rendered Markdown diffs should preserve code-block text and syntax highlighting while keeping internal diff metadata invisible. Address the code-block rendering path in the built-in Markdown extension without disabling existing prose diff highlighting.
