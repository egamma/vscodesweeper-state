# Issue #305597 — Bad contrast for search bar options in dark theme

[https://github.com/microsoft/vscode/issues/305597](https://github.com/microsoft/vscode/issues/305597)

## Summary

This appears to be a still-current visual accessibility regression in the built-in VS Code Dark theme: the active Search option buttons use low-emphasis default theme colors on main. It should be routed to Search/theming owners rather than closed without a design/accessibility decision.

## Change summary

Improve the contrast of active option buttons in the Search view input when using the VS Code Dark theme.

## Best solution

Have the Search and theme owners adjust the default dark theme token used by checked input option buttons, or otherwise update the Search widget styling so active option states are visibly distinguishable in VS Code Dark.
