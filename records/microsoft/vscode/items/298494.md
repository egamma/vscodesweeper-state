# Issue #298494 — User setup cannot be updated when running as admin user without UAC

[https://github.com/microsoft/vscode/issues/298494](https://github.com/microsoft/vscode/issues/298494)

## Summary

Still reproduces on main: the Windows update service unconditionally disables updates when running as admin with user setup (line 142 of updateService.win32.ts) without checking whether UAC is enabled. Team-authored, valid bug, no fix merged yet.

## Change summary

VS Code user setup cannot check for or apply updates when running as an admin user with UAC disabled on Windows.

## Best solution

Add a UAC-enabled check (e.g. via registry or Windows API) in the admin-detection path in `src/vs/platform/update/electron-main/updateService.win32.ts` so that when UAC is off, the user setup update flow proceeds normally even when the session is elevated.
