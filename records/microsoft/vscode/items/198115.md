# Issue #198115 — `explorer.fileNesting.expand` ignored for items with `capture` and wildcard usage

[https://github.com/microsoft/vscode/issues/198115](https://github.com/microsoft/vscode/issues/198115)

## Summary

Fixed on current main by commit a2f8ae87352b331acf15b158be871bd2011f49b6: Explorer refreshes no longer force-expand single-child file nests when `explorer.fileNesting.expand` is false.

## Change summary

Keep a wildcard/capture-based file nest collapsed when refocusing VS Code triggers an Explorer refresh.

## Best solution

Retain the compressed-child-only expansion behavior from https://github.com/microsoft/vscode/commit/a2f8ae87352b331acf15b158be871bd2011f49b6; it removes the refresh-time expansion that caused this report while preserving compact-folder behavior.
