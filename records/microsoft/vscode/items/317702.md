# Issue #317702 — Sticky Scroll doesn't handle multi-line function headers

[https://github.com/microsoft/vscode/issues/317702](https://github.com/microsoft/vscode/issues/317702)

## Summary

The older, open backlog issue already tracks the same missing function-header context, including multiline signatures and brace-only folding headers. Consolidate this report there while preserving its Python, PHP, and C++ diff-editor examples.

## Change summary

Keep meaningful function names or abbreviated signatures visible in Sticky Scroll when declarations span multiple lines.

## Best solution

Track the complete cross-language header-context requirement in https://github.com/microsoft/vscode/issues/238568, including the requested compact presentation. Its open implementation candidate covers only part of that requirement and should not be treated as a completed fix.
