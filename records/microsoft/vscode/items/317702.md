# Issue #317702 — Sticky Scroll doesn't handle multi-line function headers

[https://github.com/microsoft/vscode/issues/317702](https://github.com/microsoft/vscode/issues/317702)

## Summary

Keep this accepted feature request open: current Sticky Scroll does not synthesize abbreviated multi-line signatures or recover missing function headers from folding information. The thread supplies cross-language examples, and 31 upvotes exceed the backlog threshold; no verified canonical or landed fix covers the full request.

## Change summary

Keep enclosing function names and useful signature context visible in Sticky Scroll for multi-line declarations and Allman-style bodies, including in diff editors.

## Best solution

Preserve meaningful function context across outline, folding, and indentation providers without replacing it with isolated braces or preprocessor lines. Evaluate the related fold-header PR for the brace-based cases, while retaining the Python and diff-editor requirements that it does not establish coverage for.
