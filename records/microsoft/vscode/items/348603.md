# Issue #348603 — Windows Explorer "Open with Code" opens files in Agents window instead of existing Editor window

[https://github.com/microsoft/vscode/issues/348603](https://github.com/microsoft/vscode/issues/348603)

## Summary

Keep open: current source allows ordinary external file opens to select the Agents window. The fallback selects the last-focused window without excluding Agents windows when no workspace contains the file.

## Change summary

Files opened through Windows Explorer should target a regular Editor window rather than the Agents window.

## Best solution

Ensure ordinary external file routing selects an eligible Editor window, preserving workspace matching and explicit new-window preferences. Keep intentional Agents-window navigation separate from that routing.
