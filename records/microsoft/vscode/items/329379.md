Fresh, team-filed bug report with an attached video demo showing the chat input widget resizing disruptively when typing over selected text; no fix exists yet on main, so this stays open for investigation.

## Change summary

Selecting text in the chat input box and then typing causes the input widget to resize in a jarring/disruptive way instead of smoothly.

## Best solution
