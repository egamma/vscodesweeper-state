# Issue #331403 — Feedback on Experimental Modern UI

[https://github.com/microsoft/vscode/issues/331403](https://github.com/microsoft/vscode/issues/331403)

## Summary

Keep open for a concrete UX decision on active-tab clarity, activity-bar separation, and divider/status-bar prominence. The documented opt-out addresses using the legacy interface, but does not resolve the usability feedback about the modern interface itself.

## Change summary

Improve the modern interface’s visual hierarchy so active tabs remain clearly connected to their content and surrounding chrome does not compete for attention.

## Best solution

Review the modern workbench styling with emphasis on active-tab identification, high-contrast legibility, and space efficiency. Agree on observable design targets across tabs, activity-bar icons, dividers, and the status bar before treating this feedback as resolved.
