# Issue #325978 — WorkspaceEdit.entries() and get() are missing SnippetTextEdits

[https://github.com/microsoft/vscode/issues/325978](https://github.com/microsoft/vscode/issues/325978)

## Summary

Confirmed bug on current main: WorkspaceEdit.entries(), get(), and has() only check for FileEditType.Text, completely ignoring FileEditType.Snippet entries. Already assigned to alexdima.

## Change summary

WorkspaceEdit.entries(), get(), and has() silently omit SnippetTextEdits, making it impossible to inspect snippet-based changes in a WorkspaceEdit.

## Best solution

Update get(), entries(), has(), and size to also include FileEditType.Snippet edits. The return types of get() and entries() only declare TextEdit[], so the fix likely needs to widen those return types to include SnippetTextEdit (or convert snippets to TextEdit for backward compat). This is a public API change and needs careful design.
