# Issue #234032 — "Accept all changes from .." button in merge editor duplicates non-conflicting changes

[https://github.com/microsoft/vscode/issues/234032](https://github.com/microsoft/vscode/issues/234032)

## Summary

Keep open: the current bulk-accept path can turn an already accepted identical change into two concatenated copies. The issue is correctly routed to merge-editor, and no verified canonical or fixing commit was found.

## Change summary

Prevent bulk acceptance in the merge editor from duplicating identical changes already merged from both branches.

## Best solution

Bulk acceptance should preserve automatically merged identical changes while accepting the requested side of unresolved conflicts. Address the bounded bulk-accept path without changing intentional per-conflict Accept Both behavior or requiring the proposed button rename.
