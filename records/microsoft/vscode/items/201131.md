# Issue #201131 — Include reactor information in comment reaction information

[https://github.com/microsoft/vscode/issues/201131](https://github.com/microsoft/vscode/issues/201131)

## Summary

Reactor-name tooltips are implemented behind the commentReactor proposed API, but the API is not finalized. Keep this api-proposal tracking issue open for the API owners; the existing implementation does not complete that lifecycle.

## Change summary

Expose comment reactors through the extension API so reaction tooltips can identify who reacted.

## Best solution
