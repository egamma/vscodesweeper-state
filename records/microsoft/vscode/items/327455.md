# Issue #327455 — Can't update API key if I don't have more than one provider

[https://github.com/microsoft/vscode/issues/327455](https://github.com/microsoft/vscode/issues/327455)

## Summary

Thanks for the detailed writeup — updating the API key with only one provider group is already possible on current main, just via right-click (context menu) on any model row rather than the group-header cog icon that only appears with 2+ groups; the request is covered by an existing, if less discoverable, affordance.

## Change summary

The group-settings cog icon (used to update an API key, rename, or delete a provider group) is only shown in the models table header row when there are 2+ provider groups, so with a single group there's no visible way to reach those actions.

## Best solution

Point the reporter at right-clicking any model belonging to the single group in Manage Models — src/vs/workbench/contrib/chat/browser/chatManagement/chatModelsWidget.ts's table onContextMenu handler (around line 1531-1572) resolves `configureGroup`/`configureVendor` from the selected model's own provider (not the group-header row) and then calls `createProviderGroupActions`, which includes an 'Update API Key' action (languageModels.ts `updateLanguageModelsProviderGroupApiKey`, implemented and functional) whenever the vendor's JSON schema has an `apiKey` property. If maintainers want better discoverability they could consider also surfacing 'Update API Key' in the per-model gear/actions column (`ActionsColumnRenderer.renderModelElement`) for JSON-configured vendors, but the capability itself already exists.
