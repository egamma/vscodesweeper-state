# Issue #24400 — Support args for `editor.action.trimTrailingWhitespace` command

[https://github.com/microsoft/vscode/issues/24400](https://github.com/microsoft/vscode/issues/24400)

## Summary

The request was only partially implemented: the command accepts an auto-save reason, but current main still cannot target a document by URI. The remaining API design question should stay open for maintainer discussion.

## Change summary

Allow extensions to trim trailing whitespace in a specified document and identify why trimming was requested.

## Best solution

Define a typed argument object for `editor.action.trimTrailingWhitespace` that retains `reason` and optionally targets a document URI, including documents outside the active editor. Preserve the existing active-editor behavior when no URI is supplied.

- **Fit:** aligned
- **Reason:** Completing this API enables extensions to implement document workflows without requiring the target to be the active editor.
- **Evidence:** The public roadmap emphasizes that “The power lives in extensions”; addressing a concrete extension-API gap supports that guardrail.
