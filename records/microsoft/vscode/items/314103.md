# Issue #314103 — Disabled model by organization still appears the in model list

[https://github.com/microsoft/vscode/issues/314103](https://github.com/microsoft/vscode/issues/314103)

## Summary

The model picker intentionally shows org-disabled models as greyed-out with a 'Contact your admin' link (added in commit 104fa2a89c6 — 'Reflect why Chat models are unavailable in the model picker'). The reporter wants the option to fully hide them instead. This is a valid feature request for enterprise/managed environments.

## Change summary

Models disabled by organization policy appear greyed-out in the model picker; the user wants them completely hidden.

## Best solution

Consider adding a user-level or org-policy option to hide admin-disabled models from the picker entirely — the existing `isModelHidden`/`setModelHidden` infrastructure in `languageModels.ts` already supports per-model hiding and could be extended. Alternatively, an org policy could control whether unavailable models are shown or hidden. The change would live in `src/vs/workbench/contrib/chat/browser/widget/input/chatModelPicker.ts` (the `buildModelPickerItems` function) and possibly `src/vs/workbench/contrib/chat/common/languageModels.ts`.
