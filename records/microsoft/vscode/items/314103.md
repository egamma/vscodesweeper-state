# Issue #314103 — Disabled model by organization still appears the in model list

[https://github.com/microsoft/vscode/issues/314103](https://github.com/microsoft/vscode/issues/314103)

## Summary

Keep open as a request to hide organization-disabled model recommendations. Current source deliberately displays unavailable featured models, but the existing model-visibility controls do not cover those entries; the older related issues do not establish a duplicate with the same observable symptom.

## Change summary

Allow users to hide organization-disabled models such as Opus 4.7 from the model picker.

## Best solution

Provide a user-controlled way to hide unavailable model recommendations without changing organization policy enforcement. Preserve discoverability of policy-disabled models in Manage Language Models rather than requiring them to remain visible in the picker.
