# Issue #307605 — # reference picker should prioritize the active document at the top of the suggestion list

[https://github.com/microsoft/vscode/issues/307605](https://github.com/microsoft/vscode/issues/307605)

## Summary

Confirmed regression on current main: commit 6dffc1fcfae changed file completion filterText so it no longer starts with the leader character (#/@), causing files to score lower than tools when the user types '#'. A team member confirmed this. An open community PR (#308742) exists but has not merged.

## Change summary

The # reference picker demotes file completions (including the active document) below tools/other items because the filterText regression removed the leader-character prefix match.

## Best solution

Review and land the community PR (https://github.com/microsoft/vscode/pull/308742) or apply a similar fix in `chatInputCompletions.ts` to restore the leader-character prefix in `filterText` for file completions, ensuring files (especially the active file with its `boostPriority` sort) rank properly when the user types `#`.
