# Issue #144404 — File explorer mask won't disappear when creating file/folder in a nested folder

[https://github.com/microsoft/vscode/issues/144404](https://github.com/microsoft/vscode/issues/144404)

## Summary

The stale Explorer mask remains plausible on current main: switching creation actions can overlap the first input's asynchronous blur cleanup with creation of the second placeholder, while editable state and the highlight class are updated without stale-operation protection.

## Change summary

Starting New Folder while an unfinished New File input is active in a nested folder can remove the input but leave the Explorer dimming mask stuck.

## Best solution

Make overlapping Explorer create/edit transitions preserve only the latest operation's editable and highlight state, with a regression test covering New File followed immediately by New Folder.
