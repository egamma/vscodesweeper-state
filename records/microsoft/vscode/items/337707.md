# Issue #337707 — Responsive chat input fixture produces nondeterministic screenshot hashes

[https://github.com/microsoft/vscode/issues/337707](https://github.com/microsoft/vscode/issues/337707)

## Summary

Confirmed CI flake remains open: two Ubuntu runs produced inverse one-level pixel differences, and current main still uses native-time resize cycles without a condition-based paint-stability boundary. The merged mitigation only removed blocking coverage; it did not stabilize the fixture.

## Change summary

Stabilize the responsive chat-input component fixture so repeated Ubuntu captures produce an identical PNG hash and can block CI again.

## Best solution

Identify whether the variance comes from resize/layout completion, paint ordering, or Linux rasterization; make the fixture resolve only at a stable rendered state, verify exact hashes across repeated Ubuntu captures, and restore its `blocksCi` baseline.
