# Issue #50840 — Support folding ranges inside a line

[https://github.com/microsoft/vscode/issues/50840](https://github.com/microsoft/vscode/issues/50840)

## Summary

This remains the canonical request for inline folding, with 171 community upvotes and a real gap on current main. An open implementation PR references this issue, so it must remain open while that approach is reviewed or replaced.

## Change summary

Allow folding ranges to begin and end at character positions within lines, enabling extensions to collapse inline text such as Markdown URLs or type annotations.

## Best solution

Implement range replacement as editor view edits, then expose character-granular folding through the folding provider API. Review and land https://github.com/microsoft/vscode/pull/170447 or develop a successor following the maintainer's requested separation between content hiding and folding.
