# Issue #156423 — Smooth scrolling has limited upper speed and causes skipping to make up

[https://github.com/microsoft/vscode/issues/156423](https://github.com/microsoft/vscode/issues/156423)

## Summary

Still present on main: smooth scrolling animation speed is capped by fixed duration and easing curve. Rapid flywheel scroll events accumulate a growing gap between the animation position and the target, then snap when scrolling stops. No fix has landed.

## Change summary

Smooth scrolling with fast flywheel mouse scrolling caps the visual scroll speed, causing a growing lag followed by a jarring snap to the final position.

## Best solution

Adjust SmoothScrollingOperation.combine() in src/vs/base/common/scrollable.ts to scale the animation speed (or shorten the duration) when the delta between the current animated position and the target grows large, so the visual scroll keeps up with rapid input rather than capping and then snapping.
