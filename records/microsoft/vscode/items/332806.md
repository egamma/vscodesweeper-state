# Issue #332806 — Changing the chat mode picker (Agent → Ask/Plan)  resends "Start implementation" and discards chat draft

[https://github.com/microsoft/vscode/issues/332806](https://github.com/microsoft/vscode/issues/332806)

## Summary

Traced a real, source-confirmed defect in the just-landed Autopilot/handoff flow: `renderChatSuggestNextWidget` in chatWidget.ts re-runs the 'auto-send the first Autopilot handoff' branch on every call, including on `onDidChangeCurrentChatMode` (which the mode picker fires), with no guard limiting it to once per completed response — so switching the mode picker while in Autopilot silently overwrites the draft and resubmits the last handoff prompt.

## Change summary

Switching the chat mode picker (Agent → Ask/Plan) discards an unsent draft and silently resends the previous handoff prompt (e.g. 'Start implementation'), causing unintended agent actions.

## Best solution

In src/vs/workbench/contrib/chat/browser/widget/chatWidget.ts, gate the Autopilot auto-send branch inside `renderChatSuggestNextWidget` so it only fires once for a given completed response (e.g. track the last request id it auto-sent for), instead of re-triggering on every call including the `onDidChangeCurrentChatMode` listener added around line 2517.
