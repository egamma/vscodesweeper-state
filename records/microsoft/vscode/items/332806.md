# Issue #332806 — Changing the chat mode picker (Agent → Ask/Plan)  resends "Start implementation" and discards chat draft

[https://github.com/microsoft/vscode/issues/332806](https://github.com/microsoft/vscode/issues/332806)

## Summary

This exact Autopilot mode-switch defect was fixed after the report: current main resolves handoffs from the mode that produced the completed response, so selecting Plan or Ask no longer replaces the draft with Plan's auto-send handoff.

## Change summary

Changing from Agent to Ask or Plan after an implementation could discard an unsent draft and automatically resubmit “Start implementation.”

## Best solution

Keep the fix from commit 40ad4eed3e843bdece6d8f65a873f220dcb8dec8, which prevents a picker change from treating the newly selected mode as the source of the previous response and firing its handoff.
