## Summary

Keep open as a feature request: current source still lacks schedule-aware host lifetime and disconnected-target activation. Existing GitHub-environment hosting and active-turn keepalive do not cover the requested clientless SSH workflow.

## Change summary

Allow managed remote hosts to activate for messages and scheduled automations without requiring a connected window or GitHub-environment registration.

## Best solution

Have Agent Host maintainers define supported on-demand activation and unattended execution semantics, separating message-triggered reconnection from schedule-driven startup. Preserve managed version matching, credential ownership, execution permissions, and applicable organization policies.
