# Issue #308256 — Agents App: When I mark a session as done, I can't find it anymore

[https://github.com/microsoft/vscode/issues/308256](https://github.com/microsoft/vscode/issues/308256)

## Summary

Valid UX polish feedback from a team member: done/archived sessions render in a separate "Done" group at the bottom of the sessions list, which is unintuitive — users expect them to remain in their original workspace/group section with differentiated styling. The behavior is confirmed in current code and corroborated by an external user.

## Change summary

Marking a session as done moves it to a separate "Done" group at the bottom of the list, making it hard to find; users expect done sessions to stay in their original section with visual differentiation.

## Best solution

Rework the sessions list rendering so that done/archived sessions remain in their original group (workspace section) with a distinct visual treatment (e.g. dimmed styling, checkmark icon) rather than being relocated to a separate "Done" group. The relevant rendering logic is in `src/vs/sessions/contrib/sessions/browser/views/sessionsView.ts` and `src/vs/sessions/services/sessions/browser/visibleSessions.ts`. Related issues https://github.com/microsoft/vscode/issues/323450 and https://github.com/microsoft/vscode/issues/321324 report that the Done filter itself may not work correctly — those are likely separate bugs but should be considered together.
