# Issue #250042 — macOS: New setting for always opening new windows in native tabs

[https://github.com/microsoft/vscode/issues/250042](https://github.com/microsoft/vscode/issues/250042)

## Summary

Thanks for the request. A real gap remains on current main, and this accepted Backlog request has 44 community upvotes, so it should stay open with its existing routing.

## Change summary

Allow macOS users to make every newly created VS Code window join the active native tab group without changing the system-wide tab preference.

## Best solution

Add an application-scoped native-tab preference and consult it in `WindowsMainService.openInBrowserWindow` when creating any window, while preserving the explicit New Window Tab command and existing default behavior.
