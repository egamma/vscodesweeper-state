# Issue #319118 — Auto-completion disabled for languages with ID >= 256 due to LanguageID bits overlapping with TokenType bits

[https://github.com/microsoft/vscode/issues/319118](https://github.com/microsoft/vscode/issues/319118)

## Summary

Confirmed source-reproducible on main: `getDefaultMetadata` in `contiguousTokensStore.ts` shifts language IDs without masking to 8 bits, so IDs ≥ 256 overflow into the TokenType field, silently breaking auto-completion and potentially other token-type-dependent features. The related PR #319144 was closed without merging; no fix exists on main.

## Change summary

Languages with a numeric ID ≥ 256 get corrupted default token metadata because the language ID overflows into the TokenType bit field, silently disabling auto-completion.

## Best solution

Mask `topLevelLanguageId` to 8 bits (`& 0xFF`) before the shift in `getDefaultMetadata` (line 249 of `src/vs/editor/common/tokens/contiguousTokensStore.ts`). The same guard should be applied in `_massageTokens` (line 73). Ideally the `encodeLanguageId` path itself could clamp or warn, but the immediate fix is the mask at the metadata composition site.
