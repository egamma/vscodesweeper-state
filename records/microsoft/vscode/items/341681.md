# Issue #341681 — Copilot Agent Host: custom agent frontmatter hooks are dropped

[https://github.com/microsoft/vscode/issues/341681](https://github.com/microsoft/vscode/issues/341681)

## Summary

Confirmed in source: toSdkCustomAgents never reads or forwards a frontmatter `hooks` value, so agent-level hooks, including deny hooks, are dropped. An open PR already targets this, so the issue stays open until it merges.

## Change summary

Custom agent frontmatter hooks are not passed to the Copilot SDK CustomAgentConfig in the Agent Host, so they never run.

## Best solution

Land https://github.com/microsoft/vscode/pull/341712 so the converter forwards agent hooks while keeping trust, policy and working-directory semantics. Add tests for workspace, user and plugin agents and for isolation when switching agents.
