# Issue #350180 — Agents window: Merge, Commit and Sync wait for the Git state refresh's 5 s cooldown before returning

[https://github.com/microsoft/vscode/issues/350180](https://github.com/microsoft/vscode/issues/350180)

## Summary

The current source confirms that awaited Git refreshes include the five-second cooldown after publishing state. Keep this open while the explicitly linked fixing PR is reviewed and merged.

## Change summary

Merge, Commit and Sync unnecessarily remain busy while the Git refresh completes its post-publication cooldown.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/350229 so callers finish once their refresh publishes state, while subsequent refreshes retain the existing per-session cooldown.
