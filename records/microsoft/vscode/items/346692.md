# Issue #346692 — Allow creating child sessions from a chat with no workspace

[https://github.com/microsoft/vscode/issues/346692](https://github.com/microsoft/vscode/issues/346692)

## Summary

Keep open: current source and tests explicitly reject repository-backed children created from a workspace-less quick chat. This team-authored request seeks a supported capability beyond that existing contract; neither workaround preserves the requested planning relationship and workspace-less parent.

## Change summary

Allow a workspace-less planning chat to create linked children in different repositories, optionally using isolated worktrees, without acquiring a workspace itself.

## Best solution

Support repository-backed children beneath a workspace-less planning conversation while preserving the parent's workspace-less identity. Establish how their workspace and lifecycle ownership fit the existing currentSession contract before implementation.
