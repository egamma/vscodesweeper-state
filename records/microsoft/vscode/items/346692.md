# Issue #346692 — Allow creating child sessions from a chat with no workspace

[https://github.com/microsoft/vscode/issues/346692](https://github.com/microsoft/vscode/issues/346692)

## Summary

Keep open: current source explicitly rejects workspace-backed child creation from a workspace-less planning chat. Existing alternatives do not preserve both the planning chat's workspace independence and the requested child relationship.

## Change summary

Allow workspace-less planning chats to create linked children in different repositories, optionally using worktrees, without attaching a workspace to the planning chat.

## Best solution

Extend Agent Host child-chat workspace support to workspace-less planning chats while preserving the parent's identity, history, and workspace-less behavior. Include child-specific repository and worktree persistence and lifecycle handling.
