# Issue #235988 — Terminal ligatures have limited length even when the font supports longer ligatures

[https://github.com/microsoft/vscode/issues/235988](https://github.com/microsoft/vscode/issues/235988)

## Summary

Upstream xterm.js issue that is partially fixed (now supports up to max texture size) but still needs a larger refactor to support unlimited ligature width by splitting glyphs into cell sizes. Maintainer explicitly wants to keep this open to track that remaining work.

## Change summary

Terminal ligatures break or vanish beyond a certain character width, even when the font supports longer ligatures.

## Best solution

Track until xterm.js implements the full fix (splitting ligature glyphs into individual cell sizes for unlimited width support). The partial fix in xterm.js#5278 raised the limit to the max texture size, but the proper solution requires a larger refactor upstream.
