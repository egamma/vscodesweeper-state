# Issue #303444 — Large multi-file diff editor freezes entire workbench for seconds

[https://github.com/microsoft/vscode/issues/303444](https://github.com/microsoft/vscode/issues/303444)

## Summary

The older, open lazy-text-model-loading issue already documents large multi-file diffs making the entire instance unusable, excessive listeners, and seconds of main-thread saturation. Consolidate this report there, preserving its profile and the maintainer's proposed loading limit.

## Change summary

Opening a multi-file diff containing approximately 2,500 files freezes the workbench for seconds and floods the console with leak warnings.

## Best solution

Resolve excessive eager loading under https://github.com/microsoft/vscode/issues/240181 so large multi-file diffs remain responsive. Carry this report's six-second DocumentDiffItemViewModel profile and proposed configurable 100-model limit into that discussion.
