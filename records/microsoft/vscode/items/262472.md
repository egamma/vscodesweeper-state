# Issue #262472 — Perf: showing Chat view on startup is slow

[https://github.com/microsoft/vscode/issues/262472](https://github.com/microsoft/vscode/issues/262472)

## Summary

Still an active performance tracking issue — multiple merged PRs addressed parts of the startup cost but the Jan 2026 discussion identifies remaining optimization opportunities (markdown rendering, welcome view rendering) that haven't been fully resolved.

## Change summary

Showing the Chat view in the secondary sidebar on startup adds 200-300ms due to expensive welcome rendering, markdown parsing, and widget creation.

## Best solution

Continue optimizing the chat view startup path: consider deferring welcome view rendering (requestIdleCallback), replacing markdown with pre-sanitized HTML for static welcome content, or removing the welcome view entirely as bpasero suggested. The chat widget creation cost (~55-100ms in createChatControl) also warrants further profiling.
