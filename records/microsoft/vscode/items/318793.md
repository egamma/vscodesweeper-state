## Change summary

Consider hiding chat attachment, Explain, and vscode.dev sharing actions from file-review context menus in the Agents window.

## Best solution

Define which actions belong in Agents file-review menus, preserving useful session-context attachment workflows rather than hiding them solely because of routing defects. Resolve attachment functionality alongside the related bug reports, and make unsupported actions unavailable without changing ordinary editor-window menus.
