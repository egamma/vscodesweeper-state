# Issue #333123 — `cmd+backspace` to delete chat doesn't work

Keep open: the team-authored report provides precise steps and a recording, and current source still lacks coverage proving Cmd+Backspace dispatches correctly from a focused Agents Window response. No issue-referencing fix commit or qualifying duplicate was found.

## Change summary

Cmd+Backspace does not undo or delete the selected chat turn when focus is on a model response in the Agents Window.

## Best solution

Make the existing Undo Requests or Restore Checkpoint shortcut resolve the focused response in an Agents Window chat widget, while preserving normal Cmd+Backspace behavior in text inputs and the existing safeguards around destructive actions.
