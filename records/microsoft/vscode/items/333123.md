# Issue #333123 — `cmd+backspace` to delete chat doesn't work

[https://github.com/microsoft/vscode/issues/333123](https://github.com/microsoft/vscode/issues/333123)

## Summary

Fresh, well-documented report (with video) that cmd+backspace doesn't remove a request/response when focus is on the model response inside the Agents Window; tracing the source shows a plausible cause — the Agents Window sets the chat widget read-only whenever session interactivity isn't `Full`, which gates off the 'Undo Requests' cmd+backspace keybinding — but I can't execute the app to confirm the exact interactivity state at repro time.

## Change summary

In the Agents Window, pressing Cmd+Backspace while focus is on a chat response (not the input box) does nothing, unlike the equivalent chat panel behavior.

## Best solution

In src/vs/sessions/contrib/chat/browser/chatView.ts, verify whether `chat.interactivity` is unexpectedly non-Full during a normal, interactive session and, if so, either loosen the readOnly gate or make the 'Undo Requests' keybinding (src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingActions.ts, `workbench.action.chat.undoEdits`) tolerant of the Agents Window's interactivity model.
