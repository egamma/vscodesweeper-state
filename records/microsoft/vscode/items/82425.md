# Issue #82425 — Support for RHEL 8 in FIPS mode

[https://github.com/microsoft/vscode/issues/82425](https://github.com/microsoft/vscode/issues/82425)

## Summary

Still unresolved: the RPM spec template has no SHA-256 file-digest directive, so VS Code's RPM still fails to install on FIPS-enabled RHEL systems. Labeled help-wanted; remains a valid packaging improvement.

## Change summary

VS Code's RPM package uses MD5 file digests which are rejected by FIPS-enabled RHEL 8+ systems, preventing installation.

## Best solution

Add `%define _binary_filedigest_algorithm 8` (SHA-256) to `resources/linux/rpm/code.spec.template` and ensure the build environment's rpmbuild version (4.14+) supports it. This is a small, self-contained packaging fix suitable for a community contributor.
