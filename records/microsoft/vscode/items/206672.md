# Issue #206672 — Merge editor: TypeScript type errors do not appear

[https://github.com/microsoft/vscode/issues/206672](https://github.com/microsoft/vscode/issues/206672)

## Summary

Still reproduces on main: the merge editor sets text models directly via `editor.setModel()` without ensuring language services (diagnostics) are active for the result pane. No fix commit found.

## Change summary

TypeScript diagnostics do not appear in the merge editor's result pane until the file is opened in a regular editor.

## Best solution

Ensure the merge editor result pane's text model is properly registered as an open document so language services provide diagnostics. The fix likely involves the interaction between `resultCodeEditorView.ts` and the model/language service lifecycle.
