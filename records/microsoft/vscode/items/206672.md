# Issue #206672 — Merge editor: TypeScript type errors do not appear

[https://github.com/microsoft/vscode/issues/206672](https://github.com/microsoft/vscode/issues/206672)

## Summary

Keep open: current source excludes merge-editor tabs from TypeScript's diagnostic eligibility tracking, matching the reported absence of errors until the file opens in a regular editor. The issue already has the appropriate area labels.

## Change summary

TypeScript diagnostics should appear and update when editing a conflict resolution in the merge editor without opening the result in another editor.

## Best solution

Make the merge result participate in TypeScript's normal open-file diagnostic lifecycle while preserving existing validation settings and avoiding unintended diagnostics for historical merge inputs.
