## Change summary

Moving or resizing a native-titlebar window on Zorin OS Wayland exposes an opaque white rectangle behind it.

## Best solution

Native-titlebar windows should move and resize without exposing an opaque backing rectangle. Obtain a current-build reproduction and compare native Wayland with XWayland to distinguish VS Code window configuration from Electron or compositor behavior.
