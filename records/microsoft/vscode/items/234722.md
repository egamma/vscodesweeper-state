# Issue #234722 — Toggle comment doesn't work on new PHP file

[https://github.com/microsoft/vscode/issues/234722](https://github.com/microsoft/vscode/issues/234722)

## Summary

Keep this confirmed Windows commenting regression open. The related embedded-language issues provide useful diagnostic leads, but neither meets the stronger duplicate bar for this re-reviewed report, and no concrete fixing commit was established.

## Change summary

Toggle Line Comment does nothing in a fresh, empty PHP document until the user types and deletes a character.

## Best solution

Make commenting work on the first invocation in a fresh PHP document without requiring an edit or disabling asynchronous tokenization. Diagnose the embedded-language configuration initialization path while preserving language-appropriate comments in mixed PHP/HTML documents.
