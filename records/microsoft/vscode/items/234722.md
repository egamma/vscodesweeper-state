# Issue #234722 — Toggle comment doesn't work on new PHP file

[https://github.com/microsoft/vscode/issues/234722](https://github.com/microsoft/vscode/issues/234722)

## Summary

Verified duplicate: the open canonical issue tracks the same failure where commenting before tokenization determines the language does nothing.

## Change summary

Toggle Line Comment does nothing in a new empty PHP file until the file is edited.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/235344 and make the comment command await tokenization before resolving the language configuration.
