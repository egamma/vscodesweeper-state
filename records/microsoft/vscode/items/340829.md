# Issue #340829 — Copilot agent can overwrite newer workspace files from a stale chat session

[https://github.com/microsoft/vscode/issues/340829](https://github.com/microsoft/vscode/issues/340829)

## Summary

Thanks for the detailed report. Two other users describe silent loss of newer edits when an older session or an outside edit is involved, so the report is credible. The trigger isn't deterministic and I couldn't confirm it from source, so it stays open for an owner to look at the stale-file handling in agent edits and accept-changes.

## Change summary

An old chat session's agent edits overwrite newer workspace file contents without checking whether the file changed since the session last saw it.

## Best solution

Have agent edits and accept/keep apply against the file's current content, and warn or show a conflict diff when the file changed since the session last read it. If a separate canonical issue owns this, consolidate there.
