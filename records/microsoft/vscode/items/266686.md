# Issue #266686 — CSS properties inside a layer nested inside a selector produce a syntax error when using SCSS but works fine with CSS.

[https://github.com/microsoft/vscode/issues/266686](https://github.com/microsoft/vscode/issues/266686)

## Summary

The SCSS grammar shipped by VS Code comes from the archived atom/language-sass repo and lacks support for modern CSS features like @layer nesting inside selectors. This is a specific instance of the grammar limitation already tracked by the open canonical issue https://github.com/microsoft/vscode/issues/81038, which proposes switching to a new SCSS grammar.

## Change summary

SCSS syntax highlighting incorrectly flags CSS properties inside an @layer block nested inside a selector as a syntax error.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/81038 — replacing the archived atom/language-sass grammar with a modern SCSS grammar would resolve this @layer nesting issue along with other syntax highlighting gaps.
