# Issue #300295 — VSCode 1.111 regressed terminal background color on terminal editors

[https://github.com/microsoft/vscode/issues/300295](https://github.com/microsoft/vscode/issues/300295)

## Summary

The reported background regression appears resolved by the merged revert, consistent with the confirmation on 1.114.0 and current source. Keep this open under the linked-open-PR rule while maintainers resolve the existing opt-in background-setting proposal.

## Change summary

Moving a terminal into the editor area should preserve its configured terminal background rather than override it with the editor background.

## Best solution

Preserve the restored terminal.background precedence. Review and land or close https://github.com/microsoft/vscode/pull/302037, which proposes optional editor-background inheritance without changing the restored default.
