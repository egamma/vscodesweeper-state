# Issue #300295 — VSCode 1.111 regressed terminal background color on terminal editors

[https://github.com/microsoft/vscode/issues/300295](https://github.com/microsoft/vscode/issues/300295)

## Summary

Keep open and route to terminal: the current main source still contains terminal-editor background handling that can differ from panel terminals, and an open PR is already attempting a setting-based fix. The linked PR should be reviewed or closed by the terminal owners before this issue is resolved.

## Change summary

Moving an integrated terminal into the editor area changes its background to the editor background instead of preserving the terminal/panel background behavior.

## Best solution

Have the terminal owners decide whether to land the linked setting-based behavior in https://github.com/microsoft/vscode/pull/302037 or settle the intended terminal-editor background precedence in the terminal color provider/CSS.
