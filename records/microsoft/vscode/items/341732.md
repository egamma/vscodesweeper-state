# Issue #341732 — Copilot Harness approval system is dangerous

[https://github.com/microsoft/vscode/issues/341732](https://github.com/microsoft/vscode/issues/341732)

## Summary

Keep open for human review of approval scope and settings precedence: another user confirms the behavior, and current source grants tool-wide approval before evaluating command rules. This is a security-sensitive permission-boundary report, so a closing proposal is barred even if some session-wide behavior is intentional.

## Change summary

The Copilot harness reportedly turns an individual approval into permission for subsequent commands or web requests, with session approvals taking precedence over configured command restrictions.

## Best solution

Establish the intended precedence between explicit session grants and configured command restrictions, then ensure enforcement and approval wording communicate the same scope. Distinguish the reported single-command approval from the commenter's explicit session-wide selection; the former must not silently become the latter.
