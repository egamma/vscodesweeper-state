# Issue #341732 — Copilot Harness approval system is dangerous

[https://github.com/microsoft/vscode/issues/341732](https://github.com/microsoft/vscode/issues/341732)

## Summary

Keep open for human review: multiple commenters confirm that session approval bypasses configured command confirmations and cannot be revoked through the expected controls. Current source supports those concerns; this security-sensitive report must not be closed through cleanup triage.

## Change summary

Copilot harness session approvals grant broader, persistent execution and fetching permissions than reporters expect, with ineffective reset controls and inherited grants in forks.

## Best solution

Ensure approval scope is clearly communicated and revocable, with explicit command-confirmation settings honored consistently by Agent Host permissions. Investigate the reported unsandboxed-session escalation separately, because the inspected current paths distinguish one-command approval from disabling the sandbox for a session.
