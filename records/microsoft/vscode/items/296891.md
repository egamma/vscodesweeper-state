# Issue #296891 — Delegating from background worktree doesn't take changes from worktree

[https://github.com/microsoft/vscode/issues/296891](https://github.com/microsoft/vscode/issues/296891)

## Summary

The background-to-cloud delegation path still omits the session worktree's branch and changes, causing cloud work to start from the repository default branch. Keep this accepted, team-authored bug open; supporting changes that exist only locally needs further transport investigation.

## Change summary

Preserve background-session worktree changes when delegating its task to the cloud agent, including changes not pushed to GitHub.

## Best solution

Cloud delegation should continue from the originating background session's code state rather than the main workspace or default branch. Establish how the cloud backend can receive locally held changes, without requiring the reporter to push them manually.
