# Issue #346496 — Copilot *.instructions.md - Support negative path patterns and array syntax for applyTo

[https://github.com/microsoft/vscode/issues/346496](https://github.com/microsoft/vscode/issues/346496)

## Summary

The requested capability remains missing: current instruction handling accepts scalar, comma-separated inclusion patterns, not YAML arrays or exclusion rules. Keep this open as a feature request; no verified canonical owns both requirements.

## Change summary

Support YAML arrays and negative path patterns in instruction-file applyTo metadata while preserving existing string syntax.

## Best solution

Define backward-compatible inclusion/exclusion semantics across instruction parsing, validation, and automatic attachment, including requests containing both included and excluded files. Exclusions should control automatic scope matching, not imply that instruction content cannot influence other files.
