# Issue #338432 — Customizations: Search in plugins/servers searches in a single category?

[https://github.com/microsoft/vscode/issues/338432](https://github.com/microsoft/vscode/issues/338432)

## Summary

Filed by a VS Code collaborator while testing an in-progress feature (linked #338174); confirmed from source that each Customizations-editor tab (plugins, MCP servers, tools, agents/skills/etc.) has its own independent search box scoped only to that tab, so search never spans categories — this is the current design, but whether that's the intended final UX is exactly what the author is asking, so it stays open for the feature team to decide rather than being triaged as a settled bug or as-designed call.

## Change summary

In the new Customizations editor, the search box only searches within the currently active category tab (e.g. plugins/servers), not across all customization categories.

## Best solution

A maintainer on the Customizations editor feature should decide whether per-tab search is intentional (and if so, make the scoping more discoverable, e.g. a label or hint) or whether search should span all categories/tabs; either way this is a UX decision for the in-development feature, not an automatic close.
