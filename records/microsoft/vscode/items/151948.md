# Issue #151948 — Allow extensions to contribute Group Policy

[https://github.com/microsoft/vscode/issues/151948](https://github.com/microsoft/vscode/issues/151948)

## Summary

Valid feature request that remains partially unaddressed. Infrastructure exists (PolicyService, extensionConfigurationPolicy in product.json), but extensions still cannot self-declare policies in their package.json contributes section — the mapping is product-controlled, not extension-controlled. Keeping open as a real API gap.

## Change summary

Allow extensions to declare their configuration settings as Group Policy–manageable policies directly in their package.json contribution point.

## Best solution

Extend the `contributes.configuration` schema so an extension can declare a `policy` block on individual settings in its package.json, rather than requiring a product.json entry in `extensionConfigurationPolicy`. The plumbing in `configurationExtensionPoint.ts` and `configurationRegistry.ts` already supports attaching policies to settings — the gap is letting extensions declare them without product-side coordination.
