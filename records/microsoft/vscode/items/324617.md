# Issue #324617 — Only showing sessions that can be attached (just Copilot CLI) is confusing

[https://github.com/microsoft/vscode/issues/324617](https://github.com/microsoft/vscode/issues/324617)

## Summary

Keep open for a picker UX decision: current source still silently excludes unsupported sessions while presenting a generic “Sessions...” entry. This team-authored feedback concerns discoverability, not a failure of the intentionally limited attachment implementation.

## Change summary

Make the session attachment picker explain why sessions other than supported Copilot CLI sessions are unavailable.

## Best solution

Make attachment eligibility understandable in the picker without offering attachments the backend cannot consume. Coordinate with the broader session-reference support work, but preserve this issue's distinct UX requirement.
