# Issue #337281 — Agent Host Chat sidebar does not expose tools from connected OAuth-authenticated MCP servers

[https://github.com/microsoft/vscode/issues/337281](https://github.com/microsoft/vscode/issues/337281)

## Summary

Thanks for the detailed report. It is complete (steps, environment, MCP logs showing 7 and 38 tools discovered) but I could not confirm the defect from source without running it. A commenter on the Codex harness describes a similar symptom, and a related open issue covers MCP auth in Agent Host sessions, so this stays open for the Agent Host/MCP owners.

## Change summary

Tools from OAuth-authenticated MCP servers that VS Code shows as connected are missing from the Copilot Agent Host chat tool catalog in the editor-window sidebar.

## Best solution

Agent Host sessions should receive the tools of connected, OAuth-authenticated MCP servers (or show an explicit warning when they cannot). Likely consolidated with the Agent Host MCP authentication work.
