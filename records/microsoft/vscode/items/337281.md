# Issue #337281 — Agent Host Chat sidebar does not expose tools from connected OAuth-authenticated MCP servers

[https://github.com/microsoft/vscode/issues/337281](https://github.com/microsoft/vscode/issues/337281)

## Summary

This matches a known, already-tracked gap: the open MCP-migration tracking issue explicitly documents that OAuth-configured servers from user `mcp.json` are skipped when migrating into the Copilot Agent Host harness, which is exactly what the reporter observed (VS Code shows the server connected/authenticated, but its tools never reach the Agent Host tool catalog).

## Change summary

Remote MCP servers configured with an OAuth browser-auth flow in user `mcp.json` show as connected in VS Code but their tools never appear in the Copilot Agent Host chat sidebar's tool catalog, with no warning shown.

## Best solution

Consolidate into https://github.com/microsoft/vscode/issues/332782, which already tracks `<user data>/mcp.json` as only partially supported in the Copilot Agent Host and explicitly lists 'OAuth configuration' as one of the reasons a server config is skipped during migration into the harness; fixing that migration gap (or emitting an explicit warning when a server is skipped) resolves this report too.
