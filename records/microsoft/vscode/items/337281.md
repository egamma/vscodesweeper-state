# Issue #337281 — Agent Host Chat sidebar does not expose tools from connected OAuth-authenticated MCP servers

[https://github.com/microsoft/vscode/issues/337281](https://github.com/microsoft/vscode/issues/337281)

## Summary

Plausible, well-documented report of an Agent Host / MCP integration gap, but I can't independently confirm the exact failure point from source alone, so this needs a build-level confirmation before it can be routed as a confirmed bug.

## Change summary

Tools from remote MCP servers that require an OAuth browser authentication flow are not showing up in the Copilot Agent Host chat sidebar's tool catalog, even after the server reports as connected and successfully discovers tools in the MCP output log.

## Best solution

Trace end-to-end whether an OAuth-authenticated remote MCP server's discovered tools actually reach the Copilot Agent Host SDK's tool catalog (via src/vs/platform/agentHost/node/copilot/copilotPluginConverters.ts forwarding `oauthClientId`, and the tool broker in src/vs/workbench/contrib/mcp/common/mcpGatewayToolBrokerChannel.ts) versus stopping at an intermediate customization/auth state; if a gap exists it likely belongs in one of those two files.

- **oauth forwarding exists:** src/vs/platform/agentHost/node/copilot/copilotPluginConverters.ts:98 forwards `config.oauth.clientId` into the SDK's MCPServerConfig as `oauthClientId`, and src/vs/platform/agentPlugins/common/pluginParsers.ts:504-525 preserves `oauth`/`oauthClientId` when normalizing server configs — so OAuth config isn't unconditionally dropped on current main, meaning the reported gap (if real) is more subtle than a blanket exclusion.
- **generic tool broker has no auth filter:** src/vs/workbench/contrib/mcp/common/mcpGatewayToolBrokerChannel.ts's `_listToolsForServer` lists tools purely from `server.tools.get()` filtered by `McpToolVisibility.Model` with no OAuth-specific exclusion, so if a gap exists it likely lives elsewhere in the agent-host-side MCP customization/auth-state flow (`mcp.oauth_completed`, `McpServerStatus.AuthRequired` in src/vs/platform/agentHost/test/node/copilotAgentSession.test.ts) rather than in this broker.
