## Summary

Keep open: existing Git-backed checkpoints and Copilot CLI auto-commits provide partial coverage, but neither supplies the requested optional checkpoint commits with attached Git notes. The request remains accepted Backlog work, with no verified canonical covering it.

## Change summary

Offer agent checkpoints as Git-history commits with attached Git notes recording AI assistance, rather than relying on agent instructions to commit.

## Best solution

Decide whether to offer an opt-in Git-history checkpoint mode with durable assistance metadata, preserving the existing checkpoint mode and user control over commits. Existing session checkpoint and auto-commit infrastructure provides a starting point, but Git notes and their relationship to restore and squash operations need a product contract.
