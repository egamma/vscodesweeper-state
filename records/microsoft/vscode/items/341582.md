# Issue #341582 — Kernel is bloqued while running a jupyter file

[https://github.com/microsoft/vscode/issues/341582](https://github.com/microsoft/vscode/issues/341582)

## Summary

Thanks for the report. The Jupyter kernel crash comes from the Jupyter and Python extensions (Jupyter 2025.9.1 with Python 2026.7.x and Python Environments 1.39.x), not from VS Code core. The reporter says that downgrading to Python 2026.6.0 and Python Environments 1.37.x avoids it. This is a regression in the extension family, which is VS Code-team-owned, so a maintainer should move it to the owning tracker rather than close it.

## Change summary

Jupyter kernel dies (exit code 3228369023) when running a cell with a conda env after updating the Python and Python Environments extensions.

## Best solution

Move the issue to microsoft/vscode-python-environments or microsoft/vscode-jupyter. The conda activation failures in the Jupyter log ('Failed to get activated conda env vars') point at the Python Environments regression introduced after 1.37.
