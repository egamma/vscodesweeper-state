[https://github.com/microsoft/vscode/issues/343572](https://github.com/microsoft/vscode/issues/343572)

## Summary

Keep open: current source explicitly excludes hooks-only and MCP-only plugins from SDK-native plugin projection, and hook inventory still comes from filesystem discovery. The referenced open PR is an implementation lead, not evidence that this publication work is complete.

## Change summary

Publish Copilot hook and MCP customization inventory from SDK discovery while preserving provenance, enablement, refresh, and host context.

## Best solution

Make SDK discovery authoritative for Copilot-owned hook and MCP inventory without changing runtime execution or forwarding SDK-managed contributions back to Copilot. Review https://github.com/microsoft/vscode/pull/343596 for overlap and identify which inventory requirements remain before treating this issue as completed.
