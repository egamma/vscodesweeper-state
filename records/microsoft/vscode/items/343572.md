# Issue #343572 — Use SDK hooks.discover and mcp.discover for Copilot customization inventory

[https://github.com/microsoft/vscode/issues/343572](https://github.com/microsoft/vscode/issues/343572)

## Summary

Keep open: current main still lacks SDK-backed hook and MCP inventory publication, and the reporter supplied a concrete example of executing plugin hooks missing from the Hooks list. The merged installation-record change explicitly excludes this work, while the related open forwarding PR does not implement it.

## Change summary

Publish Copilot SDK-discovered hooks and MCP servers with authoritative ownership, enablement, source details, and refresh behavior, including hooks-only and MCP-only plugins.

## Best solution

Make the selected Agent Host's SDK discovery authoritative for hook and MCP inventory, preserving partial-discovery diagnostics and available provenance without conflating discovery with execution or connection state. Coordinate with the existing forwarding PR while preserving genuinely client-provided contributions and avoiding duplicate publication.
