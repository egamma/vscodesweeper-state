# Issue #345541 — Worktree cleanup: avoid nested scrollable sections

[https://github.com/microsoft/vscode/issues/345541](https://github.com/microsoft/vscode/issues/345541)

## Summary

Keep open: the cleanup editor still combines an outer scrolling pane with independently height-capped tables. A single vertical scrolling experience would make additional worktrees discoverable without first focusing a list.

## Change summary

Replace nested vertical scrolling in Worktree Cleanup with one scrollable pane.

Give the cleanup editor one coherent vertical scrolling experience while retaining bounded row rendering, keyboard navigation, selection, and narrow-layout column access.
