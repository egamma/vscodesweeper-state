# Issue #281476 — Chat editors have mutating `editor.resource` property

[https://github.com/microsoft/vscode/issues/281476](https://github.com/microsoft/vscode/issues/281476)

## Summary

The underlying identity mismatch remains on current main: a new ChatEditorInput starts with a synthetic immutable editor resource and later acquires a different, mutable sessionResource. No fixing commit or PR references this issue, so it should remain open for the chat-editor owners.

## Change summary

Ensure chat editors have stable editor identity while reliably associating and locating the real chat session after resolution.

## Best solution

Define one consistent identity contract for unresolved and resolved chat editors, then make editor matching, lookup, serialization, and session swaps follow it without changing EditorInput.resource after construction. Add lifecycle coverage for creating an unresolved editor, resolving its session, and finding or reopening that same editor.
