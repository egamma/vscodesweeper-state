# Issue #281476 — Chat editors have mutating `editor.resource` property

[https://github.com/microsoft/vscode/issues/281476](https://github.com/microsoft/vscode/issues/281476)

## Summary

The `important` label triggers a hard keep-open rule. The underlying concern — mutable editor identity — appears partially addressed (`.resource` is now `readonly` in the constructor), but `_sessionResource` still mutates during `resolve()`, which may cause editor-matching bugs. No commit explicitly references this issue.

## Change summary

ChatEditorInput's `editor.resource` property could mutate after construction, breaking the editor part's assumption that resources are immutable.

## Best solution

Ensure the session resource is known at construction time so neither `.resource` nor the internal `_sessionResource` mutates post-construction, or decouple editor identity from the session resource entirely. The mutable `_sessionResource` assignments on lines 244, 270, and 285 of `chatEditorInput.ts` are the remaining concern.
