# Issue #281476 — Chat editors have mutating `editor.resource` property

[https://github.com/microsoft/vscode/issues/281476](https://github.com/microsoft/vscode/issues/281476)

## Summary

Still reproduces on main: ChatEditorInput._sessionResource mutates post-construction (lines 244, 270, 285, 313) while `resource` stays fixed, violating the EditorInput contract that `resource` is immutable. The issue carries `important` and is authored by a contributor, so it must remain open.

## Change summary

ChatEditorInput starts with a synthetic `vscode-chat-editor:` URI as its `resource`, then acquires a real session resource later, causing a mismatch that breaks editor lookup and identity assumptions.

## Best solution

Refactor ChatEditorInput so that `resource` is always the real session URI from construction, or introduce a stable synthetic identity that never changes and decouple session resolution from the editor's identity URI. The fix lives in `src/vs/workbench/contrib/chat/browser/widgetHosts/editor/chatEditorInput.ts` and likely touches session creation/acquisition flows.
