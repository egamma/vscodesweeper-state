# Issue #332073 — Agent host: a Claude session shows nothing more once the parent resumes after a background subagent

[https://github.com/microsoft/vscode/issues/332073](https://github.com/microsoft/vscode/issues/332073)

## Summary

Well-diagnosed, source-confirmed defect in the Claude agent-host pipeline: a background subagent's parent turn ends before the SDK's follow-up messages arrive, so `peekParent()` returns undefined and the router silently drops the rest of the response. An open fixing PR already targets this, so it stays open pending that PR landing.

## Change summary

After a background subagent finishes, the Claude agent-host parent turn silently stops rendering further output because the message router drops messages once the prompt queue has no turn id to attach them to.

## Best solution

Land (or continue iterating) the open fix in https://github.com/microsoft/vscode/pull/332075 and its follow-up https://github.com/microsoft/vscode/pull/334072, which open/keep a turn for messages arriving after the parent's own turn ends, per the reporter's own root-cause trace in ClaudeSdkPipeline._processMessages / ClaudeSdkMessageRouter.handle.
