# Issue #332073 — Agent host: a Claude session shows nothing more once the parent resumes after a background subagent

[https://github.com/microsoft/vscode/issues/332073](https://github.com/microsoft/vscode/issues/332073)

## Summary

The defect remains directly visible on current main, and multiple live captures confirm the resulting lost output. Keep the issue open while the two PRs that explicitly fix it are reviewed; an issue must not close before its fixing PR merges.

## Change summary

Claude drops a resumed parent response after background subagents finish because the prompt queue no longer provides a protocol turn ID.

## Best solution

Review and consolidate the competing approaches in https://github.com/microsoft/vscode/pull/332075 and https://github.com/microsoft/vscode/pull/336753, then land the implementation that creates and preserves the correct protocol-turn boundary for SDK-initiated continuations, including restoration after an agent-host restart.
