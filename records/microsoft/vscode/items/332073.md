# Issue #332073 — Agent host: a Claude session shows nothing more once the parent resumes after a background subagent

[https://github.com/microsoft/vscode/issues/332073](https://github.com/microsoft/vscode/issues/332073)

## Summary

Well-diagnosed, source-confirmed bug in the Claude agent host: once a parent turn drains after spawning background subagents, the SDK message router silently drops all further output because turnId becomes undefined. A fixing PR is already open, so this should stay open pending review/merge rather than be closed.

## Change summary

After a background subagent settles and the parent Claude turn resumes, all further SDK messages are silently dropped because the prompt queue no longer has a turn id to attach them to, so the chat stops updating until the host is restarted.

## Best solution

Land https://github.com/microsoft/vscode/pull/332075 (parent resume-anchor fix) and https://github.com/microsoft/vscode/pull/334072 (keep observing a subagent whose chat outlives its spawning turn), and track the related terminal-path gaps in https://github.com/microsoft/vscode/issues/333931 and https://github.com/microsoft/vscode/issues/333174 rather than treating this as a single isolated fix.
