# Issue #332073 — Agent host: a Claude session shows nothing more once the parent resumes after a background subagent

[https://github.com/microsoft/vscode/issues/332073](https://github.com/microsoft/vscode/issues/332073)

## Summary

Thoroughly traced, reproducible defect in the Claude agent host with an open fixing PR already in flight; not yet merged, so this stays open pending review/landing of that PR rather than an automated close.

## Change summary

After a Claude agent-host parent turn spawns background subagents, once the subagents settle and the parent resumes output, the SDK messages are silently dropped because no turn id can be resolved, so the chat renders nothing further until the host restarts.

## Best solution

Land https://github.com/microsoft/vscode/pull/332075 and https://github.com/microsoft/vscode/pull/334072 (open a turn for post-drain SDK messages, akin to what ReplayBuilder already does) — the reporter's own comments show the first PR alone doesn't cover window-close/abandoned-turn cases, which are now tracked separately in https://github.com/microsoft/vscode/issues/333931 and https://github.com/microsoft/vscode/issues/333174.
