# Issue #332073 — Agent host: a Claude session shows nothing more once the parent resumes after a background subagent

[https://github.com/microsoft/vscode/issues/332073](https://github.com/microsoft/vscode/issues/332073)

## Summary

Well-diagnosed bug with a traced code path confirmed on main, and an open PR (#332075) already targets the core defect — this should stay open until that PR lands, especially since the author's follow-up comment shows the window-close variant isn't fully covered by it yet.

## Change summary

In the Claude agent host, once a parent turn ends after spawning a background subagent, the parent's later SDK messages arrive with `turnId === undefined` and are silently dropped by `ClaudeSdkMessageRouter.handle`, so the chat stops updating until the host is restarted.

## Best solution

Land (or iterate on) https://github.com/microsoft/vscode/pull/332075, which reintroduces an anchor so post-subagent parent output reattaches to its turn; the author's newest comment shows an additional window-close/reload case (in-memory subagent registry lost on host teardown) that the current PR can't fix, so the PR or a follow-up needs to also persist/reconstruct turn association across a host restart in claudeSdkPipeline.ts / claudeSdkMessageRouter.ts.
