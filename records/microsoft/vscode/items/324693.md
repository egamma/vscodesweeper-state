# Issue #324693 — Cannot create new profile from Python Template – Save does not work.

[https://github.com/microsoft/vscode/issues/324693](https://github.com/microsoft/vscode/issues/324693)

## Summary

Verified duplicate of #320154 — the same root cause (copilot deprecation redirect triggering a built-in downgrade error during profile template creation) is already tracked and assigned.

## Change summary

Creating a profile from the Python template silently fails because the deprecated github.copilot extension redirects to github.copilot-chat, whose marketplace version is older than the built-in version, causing a downgrade error that aborts profile creation.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/320154, which is assigned to sandy081 and tracks this exact failure. The fix likely belongs in the extension install path (skip or gracefully handle built-in extensions that are already at a newer version) or in the profile template definition (remove the deprecated github.copilot entry).
