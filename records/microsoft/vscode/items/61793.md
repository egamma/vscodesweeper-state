# Issue #61793 — MSIX installer

[https://github.com/microsoft/vscode/issues/61793](https://github.com/microsoft/vscode/issues/61793)

## Summary

The request for a full standalone MSIX installer remains unimplemented. Current main has only a sparse AppX package used for Windows 11 context menu integration (bundled within the existing Inno Setup installer), not a standalone MSIX distribution format.

## Change summary

Provide a standalone MSIX installer for VS Code as an alternative distribution/install format on Windows.

## Best solution

Ship a full MSIX package as a downloadable installer format (alongside .exe and .zip) to enable clean install/uninstall lifecycle, background updates, and enterprise deployment via Intune. The sparse AppX for context menus is groundwork but not the full ask.
