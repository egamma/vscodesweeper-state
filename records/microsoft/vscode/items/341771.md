# Issue #341771 — "Copilot" harness has non-TTY terminals - it is therefore not a safe alternative to Local

[https://github.com/microsoft/vscode/issues/341771](https://github.com/microsoft/vscode/issues/341771)

## Summary

Keep open for interactive-terminal parity: the default Copilot shell path still exposes output-only terminals. An experimental PTY-backed override exists on macOS, but its prompt-suppression behavior means source inspection alone does not establish that it supports the reported 2FA workflow.

## Change summary

Provide Copilot-harness terminals that support TTY-dependent tools and user-entered authentication codes without requiring a switch to Local.

## Best solution

Establish a supported interactive authentication workflow for Copilot shell commands, first evaluating the existing PTY override against the reporter's 2FA scenario. Decide whether that capability should be available by default or through an explicit supported interactive mode.
