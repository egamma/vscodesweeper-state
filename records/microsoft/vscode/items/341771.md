# Issue #341771 — "Copilot" harness has non-TTY terminals - it is therefore not a safe alternative to Local

[https://github.com/microsoft/vscode/issues/341771](https://github.com/microsoft/vscode/issues/341771)

## Summary

Keep open: the reported loss of interactive terminal input blocks authentication-dependent development tools. Current main has an experimental PTY-backed override alongside runtime-owned, output-only terminals, but that does not establish that the reported macOS flow is fixed; the supplied harness comparison is sufficient to guide a retest.

## Change summary

Copilot-harness shell execution does not provide the interactive TTY needed by development tools that prompt for a 2FA code.

## Best solution

Provide a supported interactive terminal path for Copilot sessions so users can complete terminal prompts, and preserve an explicit Local selection while terminal compatibility gaps remain. Establish which current execution backend handles the reported macOS session before choosing the implementation boundary.
