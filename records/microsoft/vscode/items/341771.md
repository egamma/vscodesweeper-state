# Issue #341771 — "Copilot" harness has non-TTY terminals - it is therefore not a safe alternative to Local

[https://github.com/microsoft/vscode/issues/341771](https://github.com/microsoft/vscode/issues/341771)

## Summary

Thanks for the report. Commands in Copilot-harness (Copilot SDK) sessions run without an interactive TTY, which blocks workflows that need prompts such as a 2FA code. This is a gap relative to the Local harness and should stay open for the chat/agent-host owners to weigh in.

## Change summary

Copilot harness sessions use non-TTY, non-interactive terminals, so tools that prompt for input (e.g. 2FA codes) cannot run, and Copilot is now the default harness.

## Best solution

Let Copilot harness sessions provide interactive, TTY-backed terminals where the user can respond to prompts, or give users a documented way to keep the Local harness as their default. The change would likely sit in the agent-host terminal tool override (`chat.agentHost.customTerminalTool.enabled`) and the harness picker.
