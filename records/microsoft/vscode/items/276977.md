# Issue #276977 — Add a `Chat: Perform Code Review` command

[https://github.com/microsoft/vscode/issues/276977](https://github.com/microsoft/vscode/issues/276977)

## Summary

Keep open. The issue was filed by a team member, so only a factual close would be allowed here. Main only partly covers the request: `Chat: Review` is in the Command Palette and reviews the current selection. The diff-review commands exist but are hidden from the palette, and there is no quick pick for choosing what to review, which is what the author asked for in the follow-up comment.

## Change summary

Make local Copilot code review easier to find from the Command Palette, with a command or quick pick that lets the user review the current selection, the current diff, or HEAD against main.

## Best solution

Extend the palette-visible `Chat: Review` command (`github.copilot.chat.review`) in extensions/copilot so it can show a quick pick of review scopes. Selection would use the existing behavior. Uncommitted, staged or unstaged changes would reuse the existing `github.copilot.chat.review.changes`, `.stagedChanges` and `.unstagedChanges` handlers. HEAD against main would be a new scope.
