## Summary

The reported cross-session attribution would be a correctness bug, but the current source scopes editing sessions and agent-host changes to session resources, so the described path cannot be confirmed without identifying the session type and exact card involved.

## Change summary

Prevent one concurrent Copilot Chat session from displaying or undoing file changes made by another session sharing its workspace.

## Best solution

First identify whether this is the input working-set card, a response-level changes summary, or an agent-host/background session card and reproduce it with two named session types. Then preserve session ownership through the responsible changes provider and ensure Undo only targets checkpoints or edits belonging to that session.
