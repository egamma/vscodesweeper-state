# Issue #342774 — Agent host permanently wedged after Copilot CLI process exits (SDK disconnect throws, no recovery, 250 ms retry spin)

[https://github.com/microsoft/vscode/issues/342774](https://github.com/microsoft/vscode/issues/342774)

## Summary

Keep open: current source confirms that disposed/disconnected-client failures bypass recovery and subagent completion failures retry indefinitely. The SDK teardown exception and suspected OOM trigger still need separate verification, but neither invalidates the confirmed host-side recovery defect.

## Change summary

Recover from unexpected Copilot CLI termination, settle affected active turns, prevent retry flooding, and retain useful process-exit diagnostics.

## Best solution

Make unexpected runtime loss a recoverable Copilot-provider lifecycle event, with affected turns settled, unusable clients replaced, and background retries bounded. Coordinate the SDK teardown correction with host-side recovery and exit diagnostics; do not make recovery depend on proving an OOM kill.
