# Issue #342774 — Agent host permanently wedged after Copilot CLI process exits (SDK disconnect throws, no recovery, 250 ms retry spin)

[https://github.com/microsoft/vscode/issues/342774](https://github.com/microsoft/vscode/issues/342774)

## Summary

Keep open: independent Linux and macOS reports confirm that a Copilot runtime exit leaves the host unusable, and current source still excludes the reported disconnect errors from recovery. This team-authored issue tracks missing host resilience, not merely the runtime crash that triggers it.

## Change summary

Recover from unexpected Copilot runtime exits, terminate stranded turns, prevent endless retry flooding, and record useful exit diagnostics.

## Best solution

Make unexpected runtime disconnection a recoverable Copilot provider lifecycle transition: affected turns terminate with an actionable error, subsequent requests acquire a healthy client, and background work cannot flood logs while disconnected. Address the SDK teardown exception separately without making host recovery depend on that exception occurring.
