# Issue #333514 — Can't focus on output view in Agents Window while in automations view

[https://github.com/microsoft/vscode/issues/333514](https://github.com/microsoft/vscode/issues/333514)

## Summary

Team-authored bug in the new Agents Window: the generic 'Focus on Output View' command (auto-registered per view in viewsService.ts via `openView`) silently no-ops while the Automations page is active, since that page doesn't host the Output view container. A contributor called it 'as designed', but the author (who filed it) pushed back and asked for the command to be hidden instead — that's an open design call, not a settled as-designed outcome, so per policy this stays open rather than closed on a contributor's judgment for a team-authored item.

## Change summary

Running 'Output: Focus on Output View' while viewing the Automations page in the new Agents Window does nothing — no output view appears and no error is logged.

## Best solution

Either make the Output view reachable from the Automations page, or (per the author's own suggestion) scope/hide the generic per-view 'Focus on {view} View' command's `when` clause so it doesn't appear/act when the Agents Window is on a page that can't host that view — likely in src/vs/workbench/services/views/browser/viewsService.ts (registerFocusViewAction) or in the Agents Window's automations view registration under src/vs/sessions/contrib/sessions/browser/.
