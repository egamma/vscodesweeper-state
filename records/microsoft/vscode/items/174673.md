# Issue #174673 — Uncompliant emmet abbreviation expansion in css

[https://github.com/microsoft/vscode/issues/174673](https://github.com/microsoft/vscode/issues/174673)

## Summary

Confirmed upstream issue in the emmet fuzzy-matching algorithm (emmetio/emmet#560). The abbreviation `jc:sa` matches `start` instead of `space-around` because the scoring function favors shorter keywords when they share the same first character. Still present on current main (emmet v2.4.11).

## Change summary

Emmet CSS abbreviation `jc:sa` incorrectly expands to `justify-content: start` instead of `justify-content: space-around`.

## Best solution

This is an upstream defect in the emmet fuzzy-matching algorithm (https://github.com/emmetio/emmet/issues/560). The fix belongs in the `emmetio/emmet` package's `scoreMatch`/`findBestMatch` logic, after which VS Code would pick it up via a dependency bump. VS Code could work around it by overriding the snippet data or pinning explicit keyword aliases, but the proper fix is upstream.
