[https://github.com/microsoft/vscode/issues/288972](https://github.com/microsoft/vscode/issues/288972)

## Summary

This is a real terminal bug where shell integration breaks dead key composition on US International keyboards on macOS. No fix found on current main; the issue has an On Deck milestone and terminal label, so it is correctly routed and should remain open for the terminal team.

## Change summary

Dead key combinations in the integrated terminal break after the first keystroke when shell integration is enabled, outputting the underlying digit instead of entering composition mode.

Investigate how the shell integration addon (ShellIntegrationAddon) interferes with xterm.js's IME/composition state after the first keypress.
