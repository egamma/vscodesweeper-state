# Issue #308656 — Copilot CLI: Pass SessionResource into `github.copilot.cli.sessions.commitToRepository` and similar commands

[https://github.com/microsoft/vscode/issues/308656](https://github.com/microsoft/vscode/issues/308656)

## Summary

The requested session identity is still absent from the customization commit commands on current main. The linked exploratory PR was closed without merging, so this team-authored backlog debt remains necessary.

## Change summary

Pass the originating session URI through customization commit and deletion commands so Copilot CLI can identify the session directly.

## Best solution

Preserve originating session identity across the Sessions customization service and Copilot CLI command handlers, retaining the optional-argument compatibility requested by the author. Preserve existing repository/worktree commit behavior and refresh semantics for other sessions sharing a worktree.
