# Issue #350522 — Filewatcher Consuming too much memory

[https://github.com/microsoft/vscode/issues/350522](https://github.com/microsoft/vscode/issues/350522)

## Summary

Keep open for investigation of agent-host watcher memory growth on Windows. Current source includes watcher limits and exclusions, but these do not establish that the reported empty-window failure is fixed; the supplied steps suffice to retest.

## Change summary

The agent-host fileWatcher grows to roughly 3 GB shortly after empty-window startup, accompanied by severe UI delays and stalled Copilot requests.

## Best solution

Identify which startup watch registrations cause the growth and make their memory usage bounded while preserving required file notifications. Establish separately whether the session errors share that cause rather than assuming they explain the watcher memory.
