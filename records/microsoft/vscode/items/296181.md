# Issue #296181 — Chat history synching between Claude Code and Github Copilot

[https://github.com/microsoft/vscode/issues/296181](https://github.com/microsoft/vscode/issues/296181)

## Summary

The requested visibility control is implemented on current main: setting `chat.agentSessions.showExternal` to `none` hides sessions discovered from external applications such as Claude Code while retaining VS Code-created chats.

## Change summary

Provide an option to prevent Claude Code sessions from appearing in VS Code's shared Copilot/agent session history.

## Best solution

Keep the shipped external-session visibility control and direct users to the session-list filter's External > None option or `chat.agentSessions.showExternal: "none"`. Provider-specific filtering remains separately tracked by https://github.com/microsoft/vscode/issues/327097 and is not required to satisfy this Claude-hiding request.
