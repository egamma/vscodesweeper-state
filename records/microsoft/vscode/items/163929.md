# Issue #163929 — Renames returning empty placeholders are not handled correctly

[https://github.com/microsoft/vscode/issues/163929](https://github.com/microsoft/vscode/issues/163929)

## Summary

The remaining empty-placeholder defect is confirmed in current source: the extension-host adapter discards an explicitly empty placeholder, causing rename preparation to fall back to the word under the cursor. Keep this open; the reporter confirmed that the original failure to invoke rename edits no longer occurs.

## Change summary

Preserve an explicitly empty rename placeholder so providers can request a blank input when introducing an alias or other previously unnamed identifier.

## Best solution

Honor the provider's explicit empty placeholder and supplied range throughout rename preparation, while preserving existing rejection, fallback, and nonempty-name submission behavior.
