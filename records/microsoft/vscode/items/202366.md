# Issue #202366 — Add options for closing Tab/TabGroup without saving 

[https://github.com/microsoft/vscode/issues/202366](https://github.com/microsoft/vscode/issues/202366)

## Summary

Keep open: the extension API still cannot close arbitrary tabs or tab groups without save confirmation. This accepted Backlog request has 25 upvotes; existing preview settings and the active-editor revert command do not cover its programmatic scope.

## Change summary

Allow extensions to close specified tabs or tab groups without saving or showing the save-confirmation dialog.

## Best solution

Define an explicit, opt-in non-saving close contract for the Tabs API, preserving confirmation for existing callers and ordinary user closes. API owners should settle how unsaved contents and editors with custom close handlers are handled before implementation.
