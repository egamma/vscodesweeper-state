# Issue #334573 — Unclear loading indicator when trying to send to a disconnected session

[https://github.com/microsoft/vscode/issues/334573](https://github.com/microsoft/vscode/issues/334573)

## Summary

Keep open: current main clears the local spinner after a failed disconnected send,
but the failure remains log-only and gives the user no clear, actionable indication. This is also a
team-authored issue without an issue-linked fixing commit, so the factual-close bar is not met.

## Change summary

Sending a new-session message through a disconnected tunnel produces an unclear
loading state instead of an explicit connection failure or recovery path.

## Best solution

Make disconnected sends visibly fail or enter an explicit recoverable state,
preserving the draft and preventing indefinite progress, duplication, or silent message loss. The
Sessions and remote Agent Host owners should first settle whether disconnected sends are rejected,
queued, or initiate reconnection.
