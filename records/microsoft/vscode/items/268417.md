# Issue #268417 — In chat-ask mode, a change in focus will cause the scrolling position to jump

[https://github.com/microsoft/vscode/issues/268417](https://github.com/microsoft/vscode/issues/268417)

## Summary

This remains the canonical open bug for chat code-block focus changing the outer chat scroll position. A later maintainer-confirmed report reproduced the same first-click jump and was explicitly consolidated here.

## Change summary

Focusing a code block in Ask mode can unexpectedly move the chat viewport, causing the click or selection to land at the wrong visible position.

## Best solution

Preserve the outer chat-list viewport anchor while a code block receives focus and completes any resulting editor or row-height layout. Add regression coverage for clicking a partially visible code block without changing the chat list's scroll position.
