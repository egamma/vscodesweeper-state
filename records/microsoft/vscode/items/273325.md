# Issue #273325 — Subagents: Limit read/write access to specific file globs

[https://github.com/microsoft/vscode/issues/273325](https://github.com/microsoft/vscode/issues/273325)

## Summary

Valid feature request from a team member. The `runSubagent` tool currently has no file-scoping mechanism — `IRunSubagentToolInputParams` accepts only `prompt`, `description`, `agentName`, and `model`, with no glob-based read/write restrictions. The capability remains unimplemented on main.

## Change summary

Allow subagent invocations to restrict read/write access to specific file globs for safer multi-agent delegation.

## Best solution

Extend `IRunSubagentToolInputParams` in `src/vs/workbench/contrib/chat/common/tools/builtinTools/runSubagentTool.ts` with optional `readGlobs`/`writeGlobs` parameters, and enforce those constraints in the subagent's tool-calling loop so file-editing tools respect the scoping. This aligns with agent-security priorities and the broader multi-agent safety model.
