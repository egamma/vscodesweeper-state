# Issue #271526 — RFC: TabInputCustomDiff

[https://github.com/microsoft/vscode/issues/271526](https://github.com/microsoft/vscode/issues/271526)

## Summary

Valid API feature request: there's no `TabInputCustomDiff` counterpart for custom editors in the Tab API, so extensions can't programmatically detect when their custom editor is rendered in a diff context. The gap is confirmed on current main. A team member has engaged but no resolution yet.

## Change summary

Add a `TabInputCustomDiff` type to the extension API so custom editors can detect when they are displayed in a diff view.

## Best solution

Expose a `TabInputCustomDiff` (or equivalent) in the extension API tab input types, paralleling `TextDiffTabInput`, so that custom editor extensions can detect diff-mode rendering. The implementation would live in `src/vs/workbench/api/common/extHostTypes.ts` and `extHostEditorTabs.ts`. Needs API design discussion with the custom editors area owner.
