# Issue #271526 — RFC: TabInputCustomDiff

[https://github.com/microsoft/vscode/issues/271526](https://github.com/microsoft/vscode/issues/271526)

## Summary

The requested diff awareness is implemented on main through the proposed customEditorDiffs provider API. Although it does not add the suggested TabInputCustomDiff class, it directly notifies custom-editor providers of inline or side-by-side diffs and supplies both documents and webview panels.

## Change summary

Expose when custom-editor webviews are rendering a diff so extensions can coordinate the original and modified sides.

## Best solution

Use resolveCustomEditorSideBySideDiff or resolveCustomEditorInlineDiff from the customEditorDiffs proposal; stable API finalization is separately tracked by https://github.com/microsoft/vscode/issues/333400.
