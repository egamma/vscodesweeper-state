# Issue #333306 — terminal.integrated.hideOnStartup: "always" shows, hides, then re-shows the terminal panel when a workspace with a folderOpen task is reopened while VS Code is frontmost

[https://github.com/microsoft/vscode/issues/333306](https://github.com/microsoft/vscode/issues/333306)

## Summary

Well-diagnosed timing/ordering bug: `TerminalViewPane._initializeTerminal` in `terminalView.ts` unconditionally calls `hidePanel()` for `hideOnStartup: always` before checking `shouldCreate`, so a panel already showing a `folderOpen` task's terminal gets hidden and then re-shown by the task's `reveal: always`, producing the flash. Confirmed the exact code path on current main; keeping open for a maintainer fix.

## Change summary

`terminal.integrated.hideOnStartup: always` causes a visible hide-then-reshow flash of the terminal panel when a `folderOpen` task reveals a terminal and the window is frontmost on open.

## Best solution

In `src/vs/workbench/contrib/terminal/browser/terminalView.ts`, reorder or gate the `hidePanel()` call in `_initializeTerminal` so it doesn't fire when a group already exists or is being created by an automatic (`folderOpen`) task — this interacts with the existing workaround for https://github.com/microsoft/vscode/issues/142796, so a maintainer should confirm the fix doesn't reintroduce that empty-terminal issue.
