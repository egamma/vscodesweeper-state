# Issue #333306 — terminal.integrated.hideOnStartup: "always" shows, hides, then re-shows the terminal panel when a workspace with a folderOpen task is reopened while VS Code is frontmost

[https://github.com/microsoft/vscode/issues/333306](https://github.com/microsoft/vscode/issues/333306)

## Summary

The startup hide still occurs after terminal connection, leaving a restored panel visible beforehand and allowing initialization to hide an already-revealed task terminal. Keep this distinct flashing report open; the related extra-shell issue does not cover the same observable symptom.

## Change summary

Prevent the terminal panel from showing, hiding, and showing again when reopening a workspace with hideOnStartup set to always and a revealing folderOpen task.

## Best solution

Honor startup hiding during terminal-view restoration, while preserving subsequent task-requested reveals and avoiding an extra empty shell. Establish a startup visibility regression check that covers both task/connection orderings and the reported macOS frontmost-window scenario.
