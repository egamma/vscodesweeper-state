# Issue #251629 — reference large interactive cell outputs in chat

[https://github.com/microsoft/vscode/issues/251629](https://github.com/microsoft/vscode/issues/251629)

## Summary

Team-authored feature request for screenshotting interactive notebook outputs as chat context. Not yet implemented on main — existing screenshot support is for window captures, not cell output rendering. Referenced in iteration plans but no fixing commit found.

## Change summary

Use screenshots of large interactive notebook cell outputs (HTML/JS) as chat context instead of raw content, to reduce tokens and better represent visual state.

## Best solution

Implement a mechanism in the notebook chat integration that captures a rendered screenshot of interactive cell outputs (via the webview layer) and attaches it as an image variable to the chat request, likely touching the notebook output rendering in `src/vs/workbench/contrib/notebook/` and the chat attachment system in `src/vs/workbench/contrib/chat/browser/attachments/`.
