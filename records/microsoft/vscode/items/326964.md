# Issue #326964 — Quick diff peek widget ignores editor.scrollbar.verticalScrollbarSize/horizontalScrollbarSize

[https://github.com/microsoft/vscode/issues/326964](https://github.com/microsoft/vscode/issues/326964)

## Summary

Confirmed on current main: the quick-diff widget overrides the inherited vertical scrollbar size with 14px. The horizontal size already inherits from the parent editor, so the required fix is narrower than reported.

## Change summary

Make the quick-diff peek editor honor configured editor scrollbar dimensions.

## Best solution

Remove the vertical scrollbar size override from `QuickDiffWidget._fillBody` while retaining its intentional scrollbar visibility and behavior overrides; `EmbeddedDiffEditorWidget` will then inherit both dimensions and configuration updates from the parent editor.
