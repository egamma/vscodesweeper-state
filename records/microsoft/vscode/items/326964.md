# Issue #326964 — Quick diff peek widget ignores editor.scrollbar.verticalScrollbarSize/horizontalScrollbarSize

[https://github.com/microsoft/vscode/issues/326964](https://github.com/microsoft/vscode/issues/326964)

## Summary

The vertical scrollbar defect remains in current main: the quick diff peek explicitly overrides the parent editor's configured width with 14. Keep this open for a bounded settings-inheritance fix; the horizontal scrollbar allegation is not established by the traced source.

## Change summary

Make the gutter quick diff peek honor the editor's configured scrollbar sizes.

## Best solution

Have the quick diff peek respect the parent editor's scrollbar dimensions at creation and after configuration changes, while retaining its existing inline-diff behavior. Preserve horizontal size inheritance rather than assuming both dimensions have the same defect.
