# Issue #153936 — Allow limited set of markdown in TreeView#message

[https://github.com/microsoft/vscode/issues/153936](https://github.com/microsoft/vscode/issues/153936)

## Summary

Keep open: Markdown messages and native buttons exist behind a proposed API, but stable TreeView.message still accepts only strings. The merged proposal partially addresses the request without making the capability available through the stable extension API.

## Change summary

Allow extensions to display limited Markdown, command links, and welcome-style buttons in dynamic tree-view messages.

## Best solution

Have the tree-view API owners evaluate finalizing treeViewMarkdownMessage with a documented supported subset and button behavior. Reuse the existing renderer rather than requiring extensions to recreate native tree-view interactions in webviews.

- **Reason:** A bounded extension API that reuses native view interactions supports powerful extensions and a consistent UI.

- **Behavior:**

  > Extensions need dynamic tree-view messages containing limited Markdown and actionable links, including native welcome-style buttons, without substituting a webview or dummy tree item. Stable TreeView.message currently accepts only strings, while richer messages require a proposed API. The finished capability should expose the agreed rendering subset to ordinary extensions and preserve plain-string messages and message-clearing behavior.
- **Trace:**

  > src/vscode-dts/vscode.d.ts declares TreeView.message as string-only, while src/vscode-dts/vscode.proposed.treeViewMarkdownMessage.d.ts supplies a separate TreeView2 interface accepting MarkdownString. The setter returned by createTreeView in src/vs/workbench/api/common/extHostTreeViews.ts checks treeViewMarkdownMessage before forwarding MarkdownString values. - **Open decisions:**

## Evidence

- **Stable API gap:** src/vscode-dts/vscode.d.ts:12179-12185 still declares TreeView.message as message?: string; the public stable contract does not support MarkdownString.
- **Existing capability is proposal-only:** src/vscode-dts/vscode.proposed.treeViewMarkdownMessage.d.ts declares TreeView2.message?: string | MarkdownString. In src/vs/workbench/api/common/extHostTreeViews.ts:118-123, assigning a MarkdownString explicitly requires checkProposedApiEnabled(extension, 'treeViewMarkdownMessage').
