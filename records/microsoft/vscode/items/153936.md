# Issue #153936 — Allow limited set of markdown in TreeView#message

[https://github.com/microsoft/vscode/issues/153936](https://github.com/microsoft/vscode/issues/153936)

## Summary

The markdown tree message capability exists as a proposed API (`treeViewMarkdownMessage` under `TreeView2`) but has not been finalized into the stable `TreeView` interface. The feature request remains valid — the work is partially done but not shipped to extension authors.

## Change summary

Allow extensions to set a MarkdownString as the TreeView#message, enabling links and formatted text.

## Best solution

Finalize the `treeViewMarkdownMessage` proposed API into the stable `TreeView` interface (promote `message?: string | MarkdownString` from `TreeView2` to `TreeView` in `vscode.d.ts`). The implementation already exists in `extHostTreeViews.ts` and `treeView.ts`.
