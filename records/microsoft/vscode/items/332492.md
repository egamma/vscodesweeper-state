# Issue #332492 — Instead of OS version commit Id is shown

[https://github.com/microsoft/vscode/issues/332492](https://github.com/microsoft/vscode/issues/332492)

## Summary

Confirmed real bug: the native About dialog's `nls.localize` call reuses the same message key (`aboutDetail`) as the browser About dialog, which has a differently-shaped template, causing the wrong value to be substituted into the OS field — but PR #332494 already fixes this and is open, unmerged, and explicitly says 'Fixes #332492', so this stays open pending that PR landing.

## Change summary

Native About dialog on Windows shows the commit hash instead of the OS version string, which breaks extensions (e.g. WSL) that parse the OS version from the About info.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/332494, which gives the native About dialog its own localization key (`nativeAboutDetail`) distinct from the browser dialog's `aboutDetail`, plus a regression test; close this issue once that PR merges.
