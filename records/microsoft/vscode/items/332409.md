# Issue #332409 — Integrated browser click times out on hidden agent-opened pages

[https://github.com/microsoft/vscode/issues/332409](https://github.com/microsoft/vscode/issues/332409)

## Summary

Freshly filed, well-diagnosed bug from a team member with a concrete reproduction and a working CDP-based workaround; current main code confirms the mechanism (`openBrowserPage` creates the CDP page with `preserveFocus: true`, and no lifecycle/focus activation exists in the main-process browser view service), so this stays open pending an area fix.

## Change summary

Pages created via openBrowserPage with preserveFocus:true stay hidden with a 0x0 viewport, so clickElement times out because rAF never fires in the unstable/hidden document.

## Best solution

In src/vs/platform/browserView/electron-main/browserViewMainService.ts (and the CDP page creation path used by openBrowserTool.ts), either force the page's web lifecycle/visibility state to active (e.g. via CDP Page.setWebLifecycleState or an equivalent focus/size activation) when creating a preserveFocus agent page, or have playwrightInvoke's click/stability wait tolerate hidden documents; the reporter's own CDP-activate-and-reload workaround shows the fix is about page lifecycle/visibility, not the click locator logic itself.
