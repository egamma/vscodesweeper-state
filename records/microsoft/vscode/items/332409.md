# Issue #332409 — Integrated browser click times out on hidden agent-opened pages

[https://github.com/microsoft/vscode/issues/332409](https://github.com/microsoft/vscode/issues/332409)

## Summary

Team-authored bug filed 1 day ago describing a real gap: pages opened via openBrowserPage with preserveFocus can stay hidden/0x0, so clickElement's stability wait (which relies on animation frames) never resolves; no fix exists on main and the issue already carries the correct area label.

## Change summary

clickElement times out on integrated-browser pages that openBrowserPage opened hidden/unfocused (as background tabs), because rAF-based stability checks never fire in a hidden document.

## Best solution

In the browserView agent tools (src/vs/workbench/contrib/browserView/electron-browser/tools), make clickElement (or the underlying stability wait) tolerant of hidden/backgrounded pages — e.g. detect visibilityState/zero-size and either activate the page or fall back to a non-rAF stability signal — so tool calls on preserveFocus-opened pages don't hang.
