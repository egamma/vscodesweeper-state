## Summary

Keep open: current source still orders the Git blame annotation before the folding placeholder when both occupy the same end-of-line position. The existing git label is appropriate; no verified older canonical owns this symptom.

## Change summary

Keep the folding placeholder adjacent to the source text, with Git blame metadata following it. Resolve the decoration-ordering interaction without changing blame content, folding behavior, or unrelated extension decorations.
