# Issue #328295 — Detached Agents window does not expose MCP servers from Remote (WSL) extension host

[https://github.com/microsoft/vscode/issues/328295](https://github.com/microsoft/vscode/issues/328295)

## Summary

The source confirms a real parity gap: the detached Agents window does not inherit MCP discovery from the originating WSL extension host. The detailed reproduction and working in-window workaround are consistent with that architecture.

## Change summary

Expose MCP servers discovered by a Remote WSL extension host to sessions opened in the detached Agents window.

## Best solution

Preserve the originating remote authority during the Agents-window handoff and source or synchronize MCP definitions from that remote extension host, rather than relying only on the detached window's own IMcpService.
