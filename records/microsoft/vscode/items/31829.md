# Issue #31829 — macOS: Copying text to clipboard does not preserve tabs

[https://github.com/microsoft/vscode/issues/31829](https://github.com/microsoft/vscode/issues/31829)

## Summary

Keep open: current macOS HTML copying no longer substitutes non-breaking spaces, but it still expands tabs into ordinary spaces. The existing steps and related rich-text reproductions suffice to retest the remaining tab-preservation problem; neither a complete fix nor an eligible older canonical was established.

## Change summary

Preserve tab characters when copying tab-indented code, including when the receiving application consumes the formatted clipboard representation.

## Best solution

Establish tab-preserving clipboard behavior that retains syntax coloring and indentation in macOS rich-text applications without regressing other clipboard consumers. First distinguish the original non-breaking-space symptom from the remaining HTML tab expansion and coordinate with the related tab-preservation request.
