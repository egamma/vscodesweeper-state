# Issue #6841 — Auto closing brackets should try to balance brackets

[https://github.com/microsoft/vscode/issues/6841](https://github.com/microsoft/vscode/issues/6841)

## Summary

This team-authored Backlog request remains necessary: current auto-closing logic considers adjacent characters and tokenization but does not balance existing brackets. It also exceeded the community promotion threshold with 53 upvotes.

## Change summary

Avoid inserting a closing bracket when an appropriate unmatched closing bracket already exists later in the document.

## Best solution

Design a performant, likely opt-in auto-closing strategy that consults the editor's bracket-pair model before inserting a closing delimiter, with behavior defined for malformed and partially edited documents.
