# Issue #315734 — Agents window should have icon in window picker

[https://github.com/microsoft/vscode/issues/315734](https://github.com/microsoft/vscode/issues/315734)

## Summary

The Agents window has no distinguishing icon in the Switch Window picker — confirmed in source: `IOpenedMainWindow` carries no window-type field, and the picker in `windowActions.ts` derives icons purely from workspace resource type. This is a valid polish issue for the Agents window surface.

## Change summary

The Agents window should display a distinct icon in the Switch Window picker so users can tell it apart from regular VS Code windows.

## Best solution

Add a window-type discriminator (e.g. `isSessionsWindow`) to `IOpenedMainWindow` in `src/vs/platform/window/common/window.ts`, populate it from the sessions window lifecycle, and use it in `BaseSwitchWindow.pickWindow()` in `src/vs/workbench/electron-browser/actions/windowActions.ts` to assign a dedicated icon (e.g. `Codicon.copilot` or a sessions-specific codicon) instead of the generic resource-based icon classes.
