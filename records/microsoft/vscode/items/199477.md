# Issue #199477 — Clicking inside editor and releasing the mouse button on a link outside activates the link (web/monaco)

[https://github.com/microsoft/vscode/issues/199477](https://github.com/microsoft/vscode/issues/199477)

## Summary

Still reproduces on main: the `pointerup` handler in `GlobalPointerMoveMonitor` does not call `preventDefault()`, so the browser synthesizes a click on whatever element is under the cursor when a drag/selection ends outside the editor. An open PR (#304955) already targets this fix.

## Change summary

Clicking inside the Monaco editor and releasing the mouse button on a link outside the editor activates that link, especially in Firefox.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/304955, which adds `e.preventDefault()` to the `pointerup` handler in `GlobalPointerMoveMonitor.startMonitoring()`. The fix is a one-liner consistent with the existing `pointermove` handler pattern.
