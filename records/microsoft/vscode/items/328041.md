# Issue #328041 — Timed out waiting for authentication provider 'github' to register

[https://github.com/microsoft/vscode/issues/328041](https://github.com/microsoft/vscode/issues/328041)

## Summary

This is the same 'Timed out waiting for authentication provider' startup race already tracked at scale on issue #321626 (open, `bug`/`error-telemetry`, hundreds of thousands of affected users through 1.131.0) — proposing a duplicate close so the report consolidates there.

## Change summary

GitHub sign-in fails on startup with 'Timed out waiting for authentication provider github to register' when launching via the desktop shortcut, but works when launched with --enable-proposed-api.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/321626, which already has engineering analysis pinning the throw site to `tryActivateProvider`/`getSessions` in src/vs/workbench/services/authentication/browser/authenticationService.ts (the 5s timeout at line 481, with a TODO at line 479 acknowledging it's a stopgap) — a systemic cold-start race between provider registration and early session requests, not something specific to this reporter's setup.
