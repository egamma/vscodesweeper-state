# Issue #332761 — Terminal: IME composition text is rendered a few pixels below the cursor line (Korean IME, Windows 11)

[https://github.com/microsoft/vscode/issues/332761](https://github.com/microsoft/vscode/issues/332761)

## Summary

Well-documented visual glitch in the terminal's IME composition overlay; VS Code's own terminal code contains no composition-positioning logic — that overlay is rendered entirely by the bundled `@xterm/xterm` package, so the root cause and fix live upstream in xterm.js, not in this repo.

## Change summary

On Windows 11 with the Korean IME, the terminal's in-progress composition text renders a few pixels below the cursor line until the character is committed.

## Best solution

Keep tracking in VS Code as an upstream defect; the fix belongs in `@xterm/xterm`'s CompositionHelper (the DOM overlay that positions the IME composition `<div>` over the terminal canvas/WebGL renderer). A maintainer should file/link the issue against https://github.com/xtermjs/xterm.js and bump the dependency once fixed there.
