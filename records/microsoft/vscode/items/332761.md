# Issue #332761 — Terminal: IME composition text is rendered a few pixels below the cursor line (Korean IME, Windows 11)

[https://github.com/microsoft/vscode/issues/332761](https://github.com/microsoft/vscode/issues/332761)

## Summary

This is a Korean-specific instance of the broader, already-tracked terminal IME composition-offset bug; the open canonical issue #331754 covers the same defect across Korean, Japanese, and Chinese IMEs and is already assigned to a maintainer, so this narrower report should be consolidated there.

## Change summary

In the integrated terminal on Windows, the in-progress (uncommitted) IME composition string renders a few pixels below the cursor baseline instead of on the cursor line; the finalized text is correct.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/331754 (already assigned to a VS Code maintainer) — fixing the composition-view vertical offset there resolves this Korean-specific report as well; the underlying positioning bug is in the composition-view element used by the terminal's xterm.js integration (see the `TODO: Composition position got messed up somewhere` comment in src/vs/workbench/contrib/terminal/browser/media/xterm.css).
