# Issue #340628 — Agents Window: workspace picker search should find older workspaces beyond visible recents

[https://github.com/microsoft/vscode/issues/340628](https://github.com/microsoft/vscode/issues/340628)

## Summary

Keep open: current source still truncates workspace history and picker candidates before search, so older known workspaces cannot be found. The assigned 1.144.0 milestone independently bars a cleanup close.

## Change summary

Make Agents Window workspace search find older known workspaces without expanding the compact default recent list.

## Best solution

Separate the searchable workspace catalog from the default display limit across the recent-workspaces service and workspace picker. Preserve eligibility, dismissal, deduplication, and remote-provider behavior; searching arbitrary filesystem directories remains outside this request.
