# Issue #340628 — Agents Window: workspace picker search should find older workspaces beyond visible recents

[https://github.com/microsoft/vscode/issues/340628](https://github.com/microsoft/vscode/issues/340628)

## Summary

Thanks for the detailed report. The ten-entry caps are still on current main, so search only sees the truncated list. This stays open, and a maintainer should choose how far the searchable catalog should reach.

## Change summary

Agents Window workspace picker search only matches the ten truncated recent workspaces, not older known workspaces.

## Best solution

Decouple history retention and loading from the display cap. Show the compact top ten for an empty query, and search the full known catalog (VS Code recents, workspace-file folders, session-derived workspaces) when a query is entered.
