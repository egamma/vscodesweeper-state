# Issue #340628 — Agents Window: workspace picker search should find older workspaces beyond visible recents

[https://github.com/microsoft/vscode/issues/340628](https://github.com/microsoft/vscode/issues/340628)

## Summary

The reported search gap remains directly traceable on current main: history is truncated before the picker filters it. Keep this scheduled issue open; its 1.145.0 milestone also explicitly bars a close proposal.

## Change summary

Workspace picker search misses older known workspaces because history retention, loading, and row construction apply the compact recent-list limits before filtering.

## Best solution

Make older eligible workspaces from VS Code history, saved workspace files, and agent sessions discoverable through search while retaining the compact default list. Preserve existing workspace eligibility, dismissal, deduplication, and provider-selection behavior.
