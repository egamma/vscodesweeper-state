# Issue #340628 — Agents Window: workspace picker search should find older workspaces beyond visible recents

[https://github.com/microsoft/vscode/issues/340628](https://github.com/microsoft/vscode/issues/340628)

## Summary

The reported search gap remains in current main: workspace history is truncated before the picker filters it. Keep this open to make older known workspaces searchable while preserving the compact default list.

## Change summary

Make workspace-picker search find eligible older workspaces from VS Code history, saved workspace files, and existing agent sessions beyond the visible recent-workspace limit.

## Best solution

Separate the searchable workspace catalog from the compact unfiltered presentation in the Sessions recent-workspaces service and workspace picker. Preserve existing eligibility, dismissal, deduplication, provider visibility, and workspace-file safety constraints.
