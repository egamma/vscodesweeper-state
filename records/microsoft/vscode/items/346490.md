[https://github.com/microsoft/vscode/issues/346490](https://github.com/microsoft/vscode/issues/346490)

## Summary

Current source explains the single-folder versus multi-root difference: the host deliberately withholds session/Working Set discard operations for multiple folders, while inline Undo can still reach an unsupported-operation error. Keep this report open; related reports do not establish a verified canonical for this specific limitation.

## Change summary

Copilot Harness multi-root sessions cannot undo generated changes, and inline Undo exposes an unavailable operation.

## Best solution

Provide safe, session-aware discard across workspace roots while preserving unrelated edits and existing conflict protections. Inline review controls should consistently reflect the host's advertised capabilities rather than offering an action that necessarily fails.
