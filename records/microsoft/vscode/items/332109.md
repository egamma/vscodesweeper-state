# Issue #332109 — Suggestion dropdown shows hover effect before mouse movement

[https://github.com/microsoft/vscode/issues/332109](https://github.com/microsoft/vscode/issues/332109)

## Summary

Keep open as suggestion-widget polish: current hover styling is based on pointer position, not movement after opening. Existing selection settings do not cover the request, and no matching canonical or concrete fix was identified.

## Change summary

Delay suggestion-row hover feedback until the user moves the mouse after the dropdown opens.

## Best solution

Have the editor area owner assess movement-gated hover feedback for the suggestion widget, preserving keyboard selection and explicit mouse clicks. Keep any eventual change scoped to this popup rather than changing hover behavior across all lists.
