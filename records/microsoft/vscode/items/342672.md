# Issue #342672 — Customizations shows "The plugin README could not be loaded" for plugins from git marketplaces not hosted on GitHub

[https://github.com/microsoft/vscode/issues/342672](https://github.com/microsoft/vscode/issues/342672)

## Summary

Confirmed in current source: the marketplace supplies a local README URI for these plugins, but the Customizations detail loader rejects every non-HTTPS scheme. Keep this open in agent-plugins; the related blank-README report does not establish the same defect.

## Change summary

Render cached READMEs for uninstalled plugins from non-GitHub git marketplaces in Customizations.

## Best solution

Make marketplace details display available local and remote-file READMEs before installation, consistent with installed-plugin details. Distinguish a missing README from a genuine read failure while preserving HTTPS loading and stale-render protection.
