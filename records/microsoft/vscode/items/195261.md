# Issue #195261 — Running extensions editor does not wrap content properly

[https://github.com/microsoft/vscode/issues/195261](https://github.com/microsoft/vscode/issues/195261)

## Summary

Still present on main: the Running Extensions editor's `.msg` container has no overflow or wrapping CSS, so long content (activation messages, feature usage strings, error counts) overflows horizontally instead of wrapping or truncating. Team-authored bug, keeping open.

## Change summary

The Running Extensions editor content overflows its container instead of wrapping or truncating when messages are long.

## Best solution

Add `overflow-wrap: break-word` or `word-break: break-word` (and possibly `overflow: hidden; text-overflow: ellipsis`) to the `.runtime-extensions-editor .extension > .desc > .msg` rule in `runtimeExtensionsEditor.css`, and ensure the `.desc` flex child has `min-width: 0` so it can shrink below its content size.
