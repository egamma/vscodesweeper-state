# Issue #341547 — onDidEndTerminalShellExecution never fires and read() never ends when the terminal is closed while a shell-integration command is running

[https://github.com/microsoft/vscode/issues/341547](https://github.com/microsoft/vscode/issues/341547)

## Summary

The terminal-close path still disposes shell integration without settling outstanding executions, leaving read() blocked and omitting the end event. Route this confirmed lifecycle bug to the terminal area.

## Change summary

Complete shell-execution streams and notify extensions when their terminal closes before execution finishes.

## Best solution

Make terminal teardown settle outstanding shell executions exactly once, complete their output streams, and report an undefined exit code when no result was received. Preserve normal command completion and document terminal-close behavior in the API.
