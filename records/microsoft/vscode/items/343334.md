# Issue #343334 — Migrate VS Code-installed agent plugins to Copilot SDK-managed installations

[https://github.com/microsoft/vscode/issues/343334](https://github.com/microsoft/vscode/issues/343334)

## Summary

Keep open: the existing migration registers marketplaces, but does not transfer ownership of previously installed plugins to the Copilot SDK. Current source still discovers and forwards VS Code-managed installations, so the requested compatibility-preserving migration remains necessary.

## Change summary

Provide an explicit, retry-safe migration from VS Code-managed plugin installations to Copilot SDK ownership while preserving enablement and other harness consumers.

## Best solution

Provide a migration that reconciles legacy installations with SDK inventory, preserves applicable enablement, and verifies SDK ownership before suppressing Copilot client forwarding. Resolve retention and cleanup semantics explicitly so migration does not remove plugins still needed by the Local harness.
