Keep open: current marketplace migration registers sources but does not adopt existing VS Code installations into SDK ownership. This team-authored request still needs a cross-harness compatibility contract; no verified fix or qualifying duplicate was found.

## Change summary

Migrate existing VS Code-managed agent plugins into Copilot SDK ownership without duplicate contributions, lost enablement decisions, or broken compatibility with other harnesses.
