# Issue #283533 — Strange white line at bottom of window after hiding taskbar

[https://github.com/microsoft/vscode/issues/283533](https://github.com/microsoft/vscode/issues/283533)

## Summary

The evidence points to a Windows/Chromium DirectComposition interaction rather than VS Code-rendered UI: the same taskbar-auto-hide artifact occurs in other Chromium applications and Windows Terminal, and disabling DirectComposition or changing ANGLE removes it. Keep this open as an upstream issue while deciding whether VS Code should support a persistent mitigation.

## Change summary

A light-colored line appears along a maximized VS Code window when Windows 11 taskbar auto-hide is enabled.

## Best solution

Track the underlying Windows/Chromium/Electron rendering behavior upstream, while the VS Code window/Electron owners consider whether `disable-direct-composition` is safe to permit in `argv.json` as a persistent workaround for affected users.

## Evidence

- **cross-application behavior:** Multiple commenters report the same edge line in Chrome, Edge, Brave, and Windows Terminal, making a VS Code status-bar or theme defect unlikely.
- **rendering workarounds:** Comments confirm that `--use-angle=gl` and `--disable-direct-composition` remove the artifact, directly implicating the Chromium/Windows graphics composition path.
- **upstream report:** https://github.com/microsoft/terminal/issues/12959 is open and documents the same observable symptom with Windows taskbar auto-hide; its windowing discussion identifies the reserved taskbar edge and related maximized-window behavior.
- **Windows precedent:** https://github.com/microsoft/terminal/issues/11474 records the same line on Windows 11 across maximized applications and attributes its color and presence to the auto-hidden taskbar/DWM behavior.
- **VS Code mitigation gap:** src/mainImpl.ts `configureCommandlineSwitchesSync` only persists an allowlist of Electron switches from `argv.json`; `disable-direct-composition` and `use-angle` are not currently in `SUPPORTED_ELECTRON_SWITCHES`.
