# Issue #338194 — "Signature verification failed with 'UnknownError' error" when installing any extension

[https://github.com/microsoft/vscode/issues/338194](https://github.com/microsoft/vscode/issues/338194)

## Summary

Thanks for the report. The issue was reopened after a second Fedora 45 user hit the same failure. A commenter found a likely cause: the signature verification tool needs the OpenSSL 3 runtime (libssl.so.3), which a minimal Fedora 45 install may not include. I could not run anything to confirm that, so this stays open. The report is complete enough to retest, and the failure message is unhelpful for a missing library.

## Change summary

Extension installs fail with 'Signature verification failed with UnknownError' on Fedora 45, apparently because a system library is missing.

## Best solution

Confirm the missing libssl.so.3 cause. Then either surface a clearer error when the signature verification tool cannot load, or add the dependency to the Linux rpm package requirements so that it is installed with VS Code.
