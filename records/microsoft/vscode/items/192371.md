# Issue #192371 — Enable support for notebooks at the "select language" mode

[https://github.com/microsoft/vscode/issues/192371](https://github.com/microsoft/vscode/issues/192371)

## Summary

Valid feature request with strong community support (35 upvotes), already in Backlog. The capability to create notebooks from the language mode picker does not exist on current main — the Change Language Mode command explicitly excludes notebook contexts, and no notebook type appears in the picker for new file creation.

## Change summary

Allow users to start/create a notebook (ipynb/dib) by selecting it from the 'Select Language Mode' picker.

## Best solution

Extend the language mode picker (in src/vs/workbench/browser/parts/editor/editorStatus.ts) to include notebook types as options, so selecting one converts the current untitled file into a notebook or opens a new notebook editor. Needs design work on how notebook types integrate with the existing language-mode quick-pick flow.
