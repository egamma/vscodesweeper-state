# Issue #206396 — Can not install vscode on Debian 10

[https://github.com/microsoft/vscode/issues/206396](https://github.com/microsoft/vscode/issues/206396)

## Summary

Keep open: the current Debian packaging still requires a libxkbfile1 version unavailable in the reported Debian 10 installation, while the published requirements still list Debian 10 as supported. The dependency regression is confirmed in source; no qualifying canonical or landed fix was identified.

## Change summary

VS Code's Debian package cannot install on Debian 10 because it requires libxkbfile1 >= 1:1.1.0 instead of the available 1:1.0.9.

## Best solution

Make the Debian package's native-library requirements consistent with the advertised Debian 10 support baseline, after establishing the actual ABI requirements of the shipped native modules. Do not merely lower the package metadata without verifying that the resulting installation launches and keyboard mapping works.
