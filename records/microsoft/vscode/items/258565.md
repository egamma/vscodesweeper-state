# Issue #258565 — SCM - dense source control view with work trees

[https://github.com/microsoft/vscode/issues/258565](https://github.com/microsoft/vscode/issues/258565)

## Summary

Keep this as the canonical SCM density discussion: the area maintainer explicitly consolidated two later reports here. Existing collapse and repository-selection controls help manage density, but do not fully address section separation or independently adjustable worktree containers.

## Change summary

Make adjacent worktree sections easier to distinguish and let users adjust how much space an individual section occupies.

## Best solution

Agree on clearer visual grouping between repository sections in the SCM Changes view, preserving access to publish actions and changes. Decide whether individual section sizing needs a new interaction beyond the existing collapse and repository-selection controls.
