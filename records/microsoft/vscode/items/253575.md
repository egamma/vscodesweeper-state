# Issue #253575 — NES - rendering glitch when suggestion is in collapsed code

[https://github.com/microsoft/vscode/issues/253575](https://github.com/microsoft/vscode/issues/253575)

## Summary

The collapsed-code rendering defect remains visible in current source. The linked draft PR diagnosed the relevant folding and gutter-layout paths, but it was closed without merging and its fix commit is not on `main`.

## Change summary

Next Edit Suggestions render incorrectly when their target edit falls inside a folded code region.

## Best solution

Ensure an edit hidden by folding uses the collapsed NES presentation, and reveal its containing folded regions when the user jumps to it, without changing normal inline-edit rendering or unrelated folding behavior.
