# Issue #290326 — [Unhandled Error] Cannot read properties of undefined (reading 'toString')

[https://github.com/microsoft/vscode/issues/290326](https://github.com/microsoft/vscode/issues/290326)

## Summary

Still reproduces on current main: the unguarded `.toString()` call in `inlineEditsLineReplacementView.ts:251` crashes when `getEditorBlendedColor` yields an undefined Color value — no fix commit references this issue and the vulnerable code path is unchanged.

## Change summary

Inline edits view throws 'Cannot read properties of undefined (reading toString)' when the blended border color observable resolves to undefined, affecting 42.7K users across all platforms.

## Best solution

Guard against undefined in `getEditorBlendedColor` (in `theme.ts`) so it returns a fallback Color when `observeColor` fails — or handle the undefined case in the `.map(c => c.toString())` callers across the inline-edits views. The same unguarded pattern exists in `inlineEditsSideBySideView.ts` as well.
