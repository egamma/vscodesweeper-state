# Issue #40613 — insertSnippet produces trailing spaces

[https://github.com/microsoft/vscode/issues/40613](https://github.com/microsoft/vscode/issues/40613)

## Summary

Keep open: current snippet insertion still adds indentation to empty lines, and keepWhitespace disables indentation adjustment altogether rather than selectively preserving blank lines. The older indentation-control issue is related but does not report the same blank-line symptom required for a duplicate close on this re-reviewed item.

## Change summary

Allow snippet insertion to leave empty lines free of automatically added indentation while retaining contextual indentation on nonempty lines.

## Best solution

Support blank-line-aware snippet indentation without requiring extension authors to disable contextual indentation for the entire snippet. Decide whether this changes the default behavior or is opt-in, while preserving placeholder positioning and existing line-ending semantics.

No tests were executed during this read-only review.
- **Behavior:**

  > Inserting a multiline snippet into indented code currently introduces whitespace on otherwise empty lines. The desired capability is to keep those lines empty while continuing to indent nonempty lines relative to the insertion position. Acceptance must cover an indented snippet with an empty intervening line, nonempty lines, and placeholders, together with unchanged keepWhitespace behavior. The maintainer must settle whether the capability is default or opt-in before implementation.
- **Trace:**

  > TextEditor.insertSnippet reaches MainThreadTextEditor.insertSnippet in src/vs/workbench/api/browser/mainThreadEditor.ts, which passes adjustWhitespace: !opts.keepWhitespace to the snippet controller. SnippetSession.adjustWhitespace in src/vs/editor/contrib/snippet/browser/snippetSession.ts prepends the insertion line's leading whitespace to subsequent marker lines, including empty strings. The existing keepWhitespace API preserves supplied whitespace wholesale and therefore does not selectively solve this request. src/vs/editor/contrib/snippet/test/browser/snippetSession.test.ts exercises normalization and disabled adjustment and provides the relevant validation surface. Keep placeholder positioning, nonempty-line indentation, and carriage-return normalization within the compatibility boundary; carriage returns are currently line separators, not unindent commands. https://github.com/microsoft/vscode/pull/55336 was an unmerged attempt; https://github.com/microsoft/vscode/issues/20112 concerns related but distinct per-line indentation controls.
- **Open decisions:**
  - Should avoiding automatically added indentation on ordinary empty snippet lines become the default, or be an opt-in capability that preserves existing insertion behavior?

## Evidence

- **Current insertion path:** src/vs/workbench/api/browser/mainThreadEditor.ts:513-550 routes TextEditor.insertSnippet through SnippetController2.apply with adjustWhitespace: !opts.keepWhitespace.
- **Remaining capability gap:** src/vs/editor/contrib/snippet/browser/snippetSession.ts:427-478, SnippetSession.adjustWhitespace, prepends lineLeadingWhitespace to every subsequent text-marker line without excluding empty lines. For an indented insertion of 'first\n\nlast', the middle line receives indentation as well.
- **Existing API is only a partial workaround:** src/vscode-dts/vscode.d.ts:1326-1338 exposes insertSnippet options.keepWhitespace. Its implementation disables contextual indentation for the whole snippet, not just blank lines; src/vs/editor/contrib/snippet/test/browser/snippetSession.test.ts contains the corresponding 'snippets, newline NO whitespace adjust' test.
- **Existing cleanup settings:** editor.trimAutoWhitespace is registered in src/vs/editor/common/config/editorConfigurationSchema.ts, and files.trimTrailingWhitespace in src/vs/workbench/contrib/files/browser/files.contribution.ts. Neither registration offers selective blank-line indentation during snippet insertion; save-time cleanup is not equivalent to avoiding those spaces on insertion.
- **Previous implementation attempt:** https://github.com/microsoft/vscode/pull/55336 proposed a setting to skip indentation on blank snippet lines and explicitly addressed this issue. It is closed with mergedAt null, so it does not establish a shipped fix or an active competing implementation.
- **Canonical search:** https://github.com/microsoft/vscode/issues/20112 is open and older, but its reported symptom is indentation of a nonempty PHP heredoc terminator and the absence of per-line unindent controls, not trailing spaces on blank lines. The maintainer's related link does not establish equivalence. https://github.com/microsoft/vscode/issues/49661 is newer and requests preserving whitespace-only lines during formatting, the opposite concern; neither qualifies as this re-reviewed item's canonical duplicate.
- **Carriage returns and inspection limits:** SnippetSession.adjustWhitespace splits text on CRLF, CR, or LF and rejoins using the model EOL; its 'normalize whitespace' test explicitly expects carriage returns to become newlines. This is separate from selectively skipping blank-line indentation. Inspection was source-only, the checkout remained clean, and shallow history did not establish a fixing commit.
