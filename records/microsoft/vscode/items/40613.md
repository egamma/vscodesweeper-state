# Issue #40613 — insertSnippet produces trailing spaces

[https://github.com/microsoft/vscode/issues/40613](https://github.com/microsoft/vscode/issues/40613)

## Summary

The issue remains valid on current main. The `adjustWhitespace` logic in `snippetSession.ts` still prepends indentation to blank lines, creating trailing whitespace. The `keepWhitespace` option added later is a coarse workaround (disables all adjustment), not a fix for the specific ask of skipping indentation on empty lines.

## Change summary

insertSnippet's whitespace adjustment adds indentation to blank lines in snippets, producing trailing whitespace.

## Best solution

In `SnippetSession.adjustWhitespace`, skip prepending `lineLeadingWhitespace` when a line is empty (or whitespace-only after normalization). This preserves indentation for non-blank continuation lines while eliminating trailing whitespace on blank separator lines — a narrow guard at line 466 of `src/vs/editor/contrib/snippet/browser/snippetSession.ts`.
