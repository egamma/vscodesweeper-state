# Issue #331422 — Splitting Chat Editor results in invalid Chat Input State

[https://github.com/microsoft/vscode/issues/331422](https://github.com/microsoft/vscode/issues/331422)

## Summary

Real, well-diagnosed bug with an open fixing PR already referencing it — keep open until that PR merges rather than closing preemptively; also carries a real release milestone (1.135.0), which independently blocks a close.

## Change summary

Splitting a Chat Editor with `View: Split Editor` produces a new pane with an invalid chat input state — the Agent Mode (Interactive/Plan) picker and related agent-host controls are missing.

## Best solution

Land and merge PR https://github.com/microsoft/vscode/pull/331424, which fixes `ChatEditorInput.copy()` to mint a same-session-type untitled URI so `ChatEditor.setInput()` locks the widget correctly before rendering; close this issue once that PR merges.
