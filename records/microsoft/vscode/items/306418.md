# Issue #306418 — Can't use Entra ID auth in integrated browser.

[https://github.com/microsoft/vscode/issues/306418](https://github.com/microsoft/vscode/issues/306418)

## Summary

Keep open: corporate Entra sign-in remains an unmet integrated-browser capability, with maintainer interest and multiple reports involving device-compliance requirements. Existing session-storage settings and external-browser opening do not establish support for device-bound authentication or a callback-preserving handoff.

## Change summary

Enable corporate Entra authentication in the integrated browser, including organizations that require device identity, compliance, or platform authentication.

## Best solution

Establish a supported enterprise sign-in path that preserves Conditional Access requirements and produces an authenticated integrated-browser session. Browser and Microsoft authentication owners should first determine native integration feasibility and whether a secure external-browser handoff can satisfy the same workflow.
