# Issue #327097 — Feature Request: Allow filtering/hiding chat sessions by specific agent/provider

[https://github.com/microsoft/vscode/issues/327097](https://github.com/microsoft/vscode/issues/327097)

## Summary

The existing Filter Agent Sessions menu already provides persistent per-provider exclusions without disabling those providers. This covers the central request without adding a separate setting.

## Change summary

Hide a provider's sessions from the shared Chat session list while keeping the provider usable elsewhere.

## Best solution

Use the existing provider toggles in Filter Agent Sessions to exclude Codex while retaining Claude/Copilot. Keep the separate menu-usability improvement tracked in https://github.com/microsoft/vscode/issues/291161.

- **Proposed comment:**

  > Thanks for the request. In the Chat session list, open **Filter Agent Sessions** and deselect Codex in the provider list. These selections are saved for your profile and filter both existing and newly discovered sessions without disabling the provider or its own panel.
  > 
  > The existing command family is `agentSessions.filter.toggleExclude:<providerId>.<menuId>`; no additional setting is needed for this workflow. Improving the menu so it stays open while selecting multiple providers is tracked separately in https://github.com/microsoft/vscode/issues/291161.

## Evidence

- **Existing provider-filter commands:** src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsFilter.ts:211–265 registers a toggle for Local and every contributed session provider/group. Command IDs follow agentSessions.filter.toggleExclude:<providerId>.<menuId>; invoking one changes only the excluded-provider list, not extension or provider enablement.
- **Persistent filtering of new and existing sessions:** AgentSessionsFilter.storeExcludes persists exclusions in profile storage under agentSessions.filterExcludes.agentsessionsviewerfiltersubmenu. Its exclude method at agentSessionsFilter.ts:383–400 checks each session's providerType or sessionListGroup against that list, so exclusion is not limited to existing history.
- **Wired into the requested Chat surface:** src/vs/workbench/contrib/chat/browser/agentSessions/agentSessions.contribution.ts:83–87 exposes Filter Agent Sessions in the session toolbar. src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatViewPane.ts:895–920 constructs AgentSessionsFilter with AgentSessionsViewerFilterSubMenu and passes it to AgentSessionsControl. agentSessionsViewer.ts:1303–1305 applies the filter, with an explicit exception for a deliberately revealed session.
