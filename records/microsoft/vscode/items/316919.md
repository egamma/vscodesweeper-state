# Issue #316919 — I want to attach file diff to AI Chat

[https://github.com/microsoft/vscode/issues/316919](https://github.com/microsoft/vscode/issues/316919)

## Summary

The per-file Graph action still attaches the revision's file content, not its diff. Keep this request open: existing commit-level context only partially covers it, and the verified older diff-editor request does not own the same observable workflow.

## Change summary

Offer separate file-content and file-diff attachments from commit history, with an additional option to attach individual diff-editor hunks.

## Best solution

Provide an explicit distinction between attaching a historical file's content and attaching its changes against the commit's parent, preserving the existing content option. Consider individual hunk attachments as a related extension of that context-selection workflow.
