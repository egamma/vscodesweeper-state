# Issue #344846 — Seti icon theme: no file icon for PowerPoint files (.pptx/.pptm/.potx/.pps)

[https://github.com/microsoft/vscode/issues/344846](https://github.com/microsoft/vscode/issues/344846)

## Summary

The missing PowerPoint icon remains in current main and originates in the upstream Seti icon assets, not Explorer rendering. Keep this open as upstream work; the repository explicitly requires icon improvements to land in Seti before importing them.

## Change summary

Provide a PowerPoint glyph and file-extension associations in the bundled Seti icon theme, consistent with Word and Excel.

## Best solution

Add the PowerPoint artwork, font glyph, and extension mappings in https://github.com/jesseweed/seti-ui, then import the accepted assets through extensions/theme-seti/build/update-icon-theme.js so the bundled dark and light definitions remain generated consistently.
