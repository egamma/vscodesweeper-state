# Issue #316869 — Agents: New session defaults to the wrong branch

[https://github.com/microsoft/vscode/issues/316869](https://github.com/microsoft/vscode/issues/316869)

## Summary

Confirmed in source: the default-branch logic in the Agents window hardcodes 'main' then 'master' as the preferred branch, ignoring the repository's actual default branch. This is a real bug affecting any repo whose default branch is neither 'main' nor 'master'.

## Change summary

New sessions in the Agents window default to the 'main' branch instead of the repository's actual default branch (e.g. 'develop').

## Best solution

In `_loadBranches` in `copilotChatSessionsProvider.ts` (line ~410), replace the hardcoded 'main'/'master' preference with the repository's actual default branch — either from the GitHub API's `defaultBranch` field (already available in `IGitHubRepoInfo`) or from the git remote HEAD. The current HEAD branch should also be considered as a stronger signal than the hardcoded names.
