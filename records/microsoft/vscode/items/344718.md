## Summary

Keep open: the report provides sufficient steps and comparative measurements to retest the idle compositor load. Current main explicitly disables background throttling for Agents windows, but source inspection cannot establish which frame producer accounts for the Linux/X11 behavior, particularly with reduced motion enabled.

## Change summary

An idle or minimized Agents window sustains compositor, GPU-process, and desktop CPU load that disappears when that window closes.

## Best solution

Identify and eliminate unnecessary idle frame production while preserving background agent execution and timely updates when the window becomes visible. Investigate the Agents-specific Electron throttling configuration alongside renderer animation lifecycles rather than assuming a GPU-driver or extension defect.
