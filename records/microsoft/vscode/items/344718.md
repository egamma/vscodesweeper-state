# Issue #344718 — Agents window keeps producing frames while idle (even minimized) → constant CPU/GPU load on Linux X11

[https://github.com/microsoft/vscode/issues/344718](https://github.com/microsoft/vscode/issues/344718)

## Summary

Keep open: a maintainer confirmed idle compositor activity and identified an infinite aquarium-button animation that still exists on main. The Linux steps are sufficient to retest; the animation is a confirmed contributor, not yet a complete explanation of the minimized-window load.

## Change summary

Stop unnecessary frame production and CPU/GPU activity while the Agents window is idle or minimized, including with reduced motion enabled.

## Best solution

Make decorative Agents-window motion respect reduced-motion preferences and avoid sustained idle rendering, then measure the remaining compositor activity on Linux/X11. Preserve background agent execution rather than assuming that globally enabling background throttling is safe.
