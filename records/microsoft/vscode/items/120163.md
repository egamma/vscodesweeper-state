# Issue #120163 — Debug: show welcome when while not debugging even if launch.json present

[https://github.com/microsoft/vscode/issues/120163](https://github.com/microsoft/vscode/issues/120163)

## Summary

A real gap remains on current main: an inactive workspace with a launch configuration still shows the session-oriented debug panes instead of the welcome experience. This older issue remains the best canonical item, while the broader related issue was filed later and cannot absorb this re-reviewed report.

## Change summary

Show the Run and Debug welcome view whenever debugging is inactive, alongside Breakpoints only when breakpoints exist, even if launch.json is present.

## Best solution

Separate inactive-session presentation from launch-configuration availability so the welcome action leads while idle, Breakpoints remains available when useful, and the session-oriented panes return when debugging starts. A maintainer should first settle how persisted Watch expressions and previous-debug state affect the inactive layout.
