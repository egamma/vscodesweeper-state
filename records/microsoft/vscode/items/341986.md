# Issue #341986 — `MCP: Open Remote User Configuration` configures itself in the incorrect location

[https://github.com/microsoft/vscode/issues/341986](https://github.com/microsoft/vscode/issues/341986)

## Summary

Keep open: current source confirms that the remote-user command still opens the VS Code profile file independently of the Copilot migration destination. Open User Configuration now offers Copilot Global, partially addressing discoverability, but the remote command and configuration distinctions remain inconsistent.

## Change summary

Make MCP configuration commands and migration guidance consistently distinguish Copilot configuration from VS Code profile configuration and identify the owning local or remote machine.

## Best solution

Provide a coherent configuration-opening experience that exposes the migrated remote Copilot configuration while preserving explicit access to VS Code profile configuration. Explain machine ownership and format limitations so users know which file to maintain without treating the two schemas as interchangeable.
