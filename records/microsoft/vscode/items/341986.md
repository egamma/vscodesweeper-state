# Issue #341986 — `MCP: Open Remote User Configuration` configures itself in the incorrect location

[https://github.com/microsoft/vscode/issues/341986](https://github.com/microsoft/vscode/issues/341986)

## Summary

Keep open: current main offers a Copilot configuration picker through Open User Configuration, but Open Remote User Configuration still opens only the remote VS Code profile file. That partially addresses discoverability without resolving the reported mismatch or clearly explaining the two formats and machine scopes.

## Change summary

Make MCP migration guidance and configuration commands clearly distinguish Copilot configuration from VS Code profile configuration, including local versus remote ownership and format compatibility.

## Best solution

Provide consistent, clearly scoped entry points for the migrated Copilot configuration and the still-supported VS Code profile configuration. Explain their different formats and when VS Code-specific capabilities require retaining profile configuration, without silently repurposing the existing remote-profile command.
