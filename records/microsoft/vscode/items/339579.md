# Issue #339579 — Insiders 1.141.0: "Cannot find package 'koffi'" - build/.moduleignore strips koffi now required by @microsoft/mxc-sdk 0.9.0

[https://github.com/microsoft/vscode/issues/339579](https://github.com/microsoft/vscode/issues/339579)

## Summary

Confirmed on current main: build/.moduleignore still strips koffi/** and @koromix/koffi-*/**, while package-lock.json shows @microsoft/mxc-sdk@1.0.0 depends on koffi@^3.2.1, so any shipped build still breaks mxc-sdk's bindings/run.js at runtime. Multiple independent reporters confirm this breaks agent terminal execution in 1.141 stable and insiders.

## Change summary

build/.moduleignore excludes koffi, which @microsoft/mxc-sdk now requires at runtime, breaking the agent run_in_terminal tool with "Cannot find package 'koffi'".

## Best solution

Narrow the koffi exclusion in build/.moduleignore so it still blocks the standalone copilot-sdk FFI transport bundle but allows the koffi copy required by @microsoft/mxc-sdk (or scope the exclusion path to @github/copilot-sdk/node_modules/koffi only), then verify mxc-sdk's bindings load from a packaged build.
