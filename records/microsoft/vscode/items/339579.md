## Summary

Thanks for the detailed report. Several users confirmed it on 1.141 stable and insiders. A maintainer says local-harness Windows sandboxing is removed in the latest Insiders, and current main no longer references @microsoft/mxc-sdk. ## Change summary

Windows agent shell commands fail with "Cannot find package 'koffi'" because build/.moduleignore strips koffi, which mxc-sdk 0.9.0 needs at runtime.

## Best solution

Confirm which commit removed the mxc-sdk dependency and which release shipped it, then close as fixed. If 1.141 stable needs a servicing fix, stop excluding koffi in build/.moduleignore.
