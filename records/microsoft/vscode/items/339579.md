# Issue #339579 — Insiders 1.141.0: "Cannot find package 'koffi'" - build/.moduleignore strips koffi now required by @microsoft/mxc-sdk 0.9.0

[https://github.com/microsoft/vscode/issues/339579](https://github.com/microsoft/vscode/issues/339579)

## Summary

Thanks for the detailed report. Several users confirmed on 1.141 stable and Insiders that agent terminal and sandbox tools fail with the missing koffi package. `build/.moduleignore` on main still strips `koffi/**` and `@koromix/koffi-*/**`, and I found no fix commit.

## Change summary

Product builds strip koffi, but @microsoft/mxc-sdk 0.9.0 imports it at runtime, so agent shell tools fail to load.

## Best solution

Narrow or remove the koffi exclusion in build/.moduleignore so the koffi packages ship (including the platform package, with native binaries unpacked from the asar where needed), then confirm on a packaged build that the mxc-sdk bindings load.
