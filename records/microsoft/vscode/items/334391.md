# Issue #334391 — Windows: CLI plugin discovery watchers block plugin install, update, and uninstall

[https://github.com/microsoft/vscode/issues/334391](https://github.com/microsoft/vscode/issues/334391)

## Summary

Confirmed on main: AbstractAgentPluginDiscovery creates non-recursive file watchers on the plugin root, manifest, and component directories, and CopilotCliAgentPluginDiscovery watches marketplace buckets — exactly the handle pattern the upstream investigation found blocking Windows CLI plugin install/update/uninstall. An open PR (#335136) already targets this, so it should stay open pending that fix landing.

## Change summary

On Windows, VS Code's persistent file watchers on CLI-installed plugin directories hold handles that block the Copilot CLI from renaming/replacing those directories during install, update, or uninstall.

## Best solution

Land https://github.com/microsoft/vscode/pull/335136 ("chat: avoid watching Copilot CLI plugin contents"), which appears to address the root cause by not placing persistent watchers inside CLI-owned plugin directories; verify it covers both the marketplace-bucket watchers in CopilotCliAgentPluginDiscovery and the per-plugin root/component watchers in AbstractAgentPluginDiscovery._toPlugin before merging.
