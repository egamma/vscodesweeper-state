# Issue #43671 — "Download Now" button should respect the used installation method on Linux

[https://github.com/microsoft/vscode/issues/43671](https://github.com/microsoft/vscode/issues/43671)

## Summary

Still unfixed on main — the Linux update service explicitly notes it doesn't detect the installed package type (line 78-79 of updateService.linux.ts). The request remains valid and has community traction (24 upvotes, promoted to Backlog).

## Change summary

The 'Download Now' button on Linux should respect the installation method (deb/rpm/snap/tarball) instead of always directing to the generic download page or tarball.

## Best solution

Detect the installation method at runtime (via dpkg, rpm, snap queries, or process path heuristics) in `src/vs/platform/update/electron-main/updateService.linux.ts` and either suppress the update notification for package-managed installs or route to the appropriate package-specific download URL. The `help wanted` label is appropriate — this is a well-scoped community contribution opportunity.
