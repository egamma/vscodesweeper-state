# Issue #321881 — VS Code can become stuck reopening the Agent login window and prevent access to the normal editor

[https://github.com/microsoft/vscode/issues/321881](https://github.com/microsoft/vscode/issues/321881)

## Summary

The lockout was confirmed across several releases and platforms, but current main now provides a targeted escape hatch from the Agents sign-in window. The merged fix opens a normal editor window before closing the Agents window, so this can be closed as completed.

## Change summary

Prevent a restored Agents sign-in window from trapping users without a way to return to the normal VS Code editor.

## Best solution

Keep the conditional “Return to VS Code Editor” action added by commit 3ff4448ac5321c04888dc5ac47b8fd8cd0af1709; it directly recovers users when the Agents window is the only open main window.
