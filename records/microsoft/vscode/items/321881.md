# Issue #321881 — VS Code can become stuck reopening the Agent login window and prevent access to the normal editor

[https://github.com/microsoft/vscode/issues/321881](https://github.com/microsoft/vscode/issues/321881)

## Summary

This is fixed on current main: the Agents sign-in dialog now offers a conditional “Return to VS Code Editor” action when no regular editor window remains, directly providing the missing recovery path.

## Change summary

Prevent users from becoming trapped in a restored Agents sign-in window with no way back to the normal editor.

## Best solution

Keep the escape path shipped by https://github.com/microsoft/vscode/commit/3ff4448ac5321c04888dc5ac47b8fd8cd0af1709: when the Agents window is the only main window, the sign-in dialog should offer an action that opens a regular editor before closing Agents.
