# Issue #343935 — Composer's pickers load is slow without indication on app start

[https://github.com/microsoft/vscode/issues/343935](https://github.com/microsoft/vscode/issues/343935)

## Summary

Keep open: a maintainer confirmed that the startup spinner disappears before the model picker arrives, and the related merged PR explicitly leaves this issue unchanged. Current source still separates session initialization progress from model-picker availability.

## Change summary

The Agents window composer reveals its pickers in stages at startup without indicating that additional controls are still loading.

## Best solution

Make composer readiness feedback cover pending picker initialization, including model discovery, until supported controls are available. Preserve intentional hiding for providers without model support and distinguish loading from sign-in or restricted-mode states.
