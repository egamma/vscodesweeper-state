# Issue #343935 — Composer's pickers load is slow without indication on app start

[https://github.com/microsoft/vscode/issues/343935](https://github.com/microsoft/vscode/issues/343935)

## Summary

Keep open: a maintainer confirmed that startup progress disappears before the model picker arrives. The linked merged PR explicitly leaves this issue unchanged, and current source still separates session initialization progress from model availability.

## Change summary

Make composer picker initialization apparent instead of allowing controls to appear in unexplained waves during startup.

## Best solution

Ensure the new-session composer communicates outstanding picker initialization without implying readiness prematurely. Diagnose model-discovery readiness separately from session loading, preserving legitimate no-model and authentication states.
