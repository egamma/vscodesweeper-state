## Summary

Keep this team-authored startup UX report open. Current source has a draft-initialization indicator, but it does not establish that asynchronous picker discovery is covered; no verified fix or canonical duplicate was found.

## Change summary

Make the new-session composer's startup understandable when its picker buttons become available in successive waves.

## Best solution

The Agents Window composer should distinguish picker initialization from genuinely unavailable controls without delaying usable input. Trace cold-start provider and picker readiness before deciding whether controls can appear immediately or need a loading presentation.
