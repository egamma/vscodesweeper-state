# Issue #343935 — Composer's pickers load is slow without indication on app start

[https://github.com/microsoft/vscode/issues/343935](https://github.com/microsoft/vscode/issues/343935)

## Summary

Keep open: a maintainer confirmed that the startup spinner disappears before the model picker arrives. Current source tracks session initialization separately from model availability, and the linked merged PR does not establish a fix for this remaining gap.

## Change summary

Show meaningful loading feedback while the Agents window's composer pickers are still initializing.

## Best solution

Ensure composer startup communicates pending picker availability through the final model-picker arrival, without treating providers that intentionally offer no models as perpetually loading.
