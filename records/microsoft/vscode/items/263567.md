# Issue #263567 — Hovering extension gear shows extension hover briefly before settings hover

[https://github.com/microsoft/vscode/issues/263567](https://github.com/microsoft/vscode/issues/263567)

## Summary

The hover conflict remains present on current main, and the open draft PR https://github.com/microsoft/vscode/pull/266166 is a direct implementation candidate that explicitly fixes this issue. Keep the issue open while that human-owned fix is reviewed.

## Change summary

Hovering the Manage gear in an extension list item briefly displays the extension-level hover before the gear action's own tooltip.

## Best solution

Review and either land or close https://github.com/microsoft/vscode/pull/266166; its targeted suppression of the parent extension hover over action-bar elements addresses the confirmed overlap without changing normal extension-content hovers.
