# Issue #275300 — Textual LanguageModelDataPart is not readable as tool result

[https://github.com/microsoft/vscode/issues/275300](https://github.com/microsoft/vscode/issues/275300)

## Summary

The bug remains source-reproducible on current main: non-image textual `LanguageModelDataPart` tool results reach `PrimitiveToolResult.onData`, which returns an empty string for every MIME type except linked resources. This accepted, team-authored Backlog bug should remain open for a bounded Copilot prompt-conversion fix.

## Change summary

Make UTF-8 textual and JSON `LanguageModelDataPart` values returned by tools readable by the model instead of silently dropping them.

## Best solution

Preserve the existing image and linked-resource handling while including safely decoded textual data parts in the tool message under the existing prompt token limits; genuinely binary non-image data should remain omitted.
