# Issue #122609 — Full remote label only shown for the current remote

[https://github.com/microsoft/vscode/issues/122609](https://github.com/microsoft/vscode/issues/122609)

## Summary

Still present on main: the workspace trust editor's host column relies on ILabelService.getHostLabel which depends on registered formatters — only the currently connected remote has a full formatter registered, so non-connected remotes fall back to the raw authority string.

## Change summary

Workspace trust manager shows abbreviated remote label (e.g. 'SSH') for non-connected remotes instead of the full host label.

## Best solution

Use the cached formatter data (registerCachedFormatter / storedFormatters memento) to resolve full labels for previously-connected remotes, or store the full label alongside trusted URI entries so it can be displayed without a live connection.
