# Issue #322481 — vscode.Uri drops hash information

[https://github.com/microsoft/vscode/issues/322481](https://github.com/microsoft/vscode/issues/322481)

## Summary

Current main still drops non-location fragments while resolving Markdown links, before the target extension receives the URI. This is a core Markdown link-opening bug and should be routed to the Markdown area.

## Change summary

Preserve fragments such as `#page=3` when a Markdown preview opens a local non-Markdown file.

## Best solution

Update the Markdown link-opening path in `extensions/markdown-language-features/src/util/openDocumentLink.ts` to retain arbitrary fragments for file targets while preserving the existing line/header navigation behavior.
