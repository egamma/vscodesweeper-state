## Evidence

- **Reporter investigation:** The March 23 and March 25 comments supplied in https://github.com/microsoft/vscode/issues/303236 report that disabling C# Dev Kit and C# changes the coloring, and show differently colored using statements in two .cs files in the same project. This implicates the interaction with extension-provided highlighting, but does not establish that the extension rather than the built-in theme is defective.
- **Current theme mappings:** extensions/theme-defaults/themes/2026-dark.json includes dark_modern.json, enables semantic highlighting, and assigns red to generic keyword and storage scopes. Its inherited dark_plus.json separately assigns purple to keyword.control, keyword.other.using, and keyword.other.directive.using. The current palette therefore contains distinct scope-dependent mappings; the report does not identify which scopes or semantic classifications produced each screenshot.
- **Semantic styling boundary:** src/vs/workbench/services/themes/common/colorThemeData.ts:getTokenStyle applies semantic rules and then probes TextMate scopes for default styling; _loadColorTheme loads inherited rules before appending theme-specific rules. Disabling a semantic token provider can change the resulting colors without proving an extension-owned defect.
- **CSS classes are not classifications:** src/vs/editor/common/languages/supports/tokenization.ts generates .mtk classes from color-map indices. The reported mtk12 and mtk22 demonstrate different resolved colors, not which token provider or theme rule caused the difference.
- **Canonical search:** Read https://github.com/microsoft/vscode/issues/295783 and https://github.com/microsoft/vscode/issues/293405. Both are open theme-wide tracking or feedback items, not verified duplicates owning this specific C# inconsistency; the latter explicitly invites separate bug reports. Additional searches found https://github.com/microsoft/vscode/issues/322000, but that concerns a later variable-coloring change rather than inconsistent C# using statements.
