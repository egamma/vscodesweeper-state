# Issue #303236 — New VSCode Themes - Syntax Coloring for C# files inconsistent

[https://github.com/microsoft/vscode/issues/303236](https://github.com/microsoft/vscode/issues/303236)

## Summary

This appears to be caused by the C# / C# Dev Kit extension's semantic token classifications rather than the core 2026 Dark theme, so it should be closed as extension-caused.

## Change summary

C# files show inconsistent syntax colors in the new 2026 Dark theme, including different colors for `using` statements across files.

## Best solution

Track this with the C# extension owners, since the distinguishing evidence is extension-provided token classification changing the theme result; VS Code core should keep the theme behavior unless the extension reports a missing semantic-token theming API.
