# Issue #263996 — Merge the task tool into the terminal tool

[https://github.com/microsoft/vscode/issues/263996](https://github.com/microsoft/vscode/issues/263996)

## Summary

The task tools (create_and_run_task, run_task, get_task_output) remain separate registrations from the terminal tools on current main. The work to merge them into a single unified terminal tool has not been done. Keeping open — this is a team-filed internal feature request with an On Deck milestone.

## Change summary

Merge the separate task-related chat tools (create_and_run_task, run_task, get_task_output) into the terminal tool so the model sees fewer, more cohesive tools.

## Best solution

Consolidate the three task tools into the terminal tool surface so the agent model has a simpler tool set. The task tool implementations already live under `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/task/` and share the `TerminalToolId` enum, so the merge is a natural next step. Needs a design decision on how the unified tool's input schema handles task-vs-terminal dispatch.
