# Issue #234866 — With the `Light+` theme,  the input area of Chat in Editor is indistinguishable from the background when out of focus

[https://github.com/microsoft/vscode/issues/234866](https://github.com/microsoft/vscode/issues/234866)

## Summary

Still reproduces on main: the Light VS theme (base of Light+) lacks an `input.border` color, so the chat input falls back to transparent when unfocused. An open PR (#304969) proposes the fix but has not merged.

## Change summary

In the Light+ theme, the Chat in Editor input area has no visible border when unfocused, making it indistinguishable from the editor background.

## Best solution

Land PR #304969 (or an equivalent change) adding `input.border: #CECECE` to `extensions/theme-defaults/themes/light_vs.json`, consistent with Light Modern and the existing `searchEditor.textInputBorder` in the same file.
