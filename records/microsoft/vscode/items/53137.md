# Issue #53137 — Snippet transform leaves conditional operator

[https://github.com/microsoft/vscode/issues/53137](https://github.com/microsoft/vscode/issues/53137)

## Summary

Keep open: VS Code supports conditional replacements, but current main still treats TextMate's (?1:...) insertion syntax as literal text. The Backlog assignment and author's explicit request for that capability preclude declining it merely because an alternative syntax exists.

## Change summary

Support TextMate-style conditional insertions in snippet transforms instead of inserting the conditional operator literally.

## Best solution

Have the snippets owner decide whether to support TextMate's conditional-insertion syntax alongside the existing replacement grammar. Preserve this compatibility request separately from the already-supported ability to generate conditional text using VS Code syntax.
