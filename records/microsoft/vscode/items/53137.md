# Issue #53137 — Snippet transform leaves conditional operator

[https://github.com/microsoft/vscode/issues/53137](https://github.com/microsoft/vscode/issues/53137)

## Summary

VS Code intentionally uses snippet-format conditional replacements rather than the TextMate/Oniguruma `(?1:...)` operator, and the existing syntax covers this request.

## Change summary

Support conditional insertion within a snippet transform instead of leaving the conditional operator as literal text.

## Best solution

Keep the existing `${n:+if}` and `${n:?if:else}` syntax and express this transform as `${1/(void$)|(.+)/${1:+\n\treturn nil;}$2/}`.

- **Proposed comment:**

  > Thanks for the report and follow-up. VS Code supports this through snippet-format conditionals rather than the `(?1:...)` replacement syntax. The equivalent is:
  > 
  > `${1/(void$)|(.+)/${1:+\n\treturn nil;}$2/}`
  > 
  > The supported forms are `${n:+if}`, `${n:-else}`, and `${n:?if:else}`, so this can be closed as designed.
