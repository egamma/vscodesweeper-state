# Issue #305356 — Improve PowerShell syntax highlighting in new VS Code Dark theme

[https://github.com/microsoft/vscode/issues/305356](https://github.com/microsoft/vscode/issues/305356)

## Summary

This is actionable theme feedback for the 2026/VS Code Dark default theme rather than a close candidate; it should be routed to the theme owners for a design/color-token decision.

## Change summary

Increase contrast between PowerShell variables, operators, parameters, and literals in the new VS Code Dark theme.

## Best solution

Have the themes area decide whether the 2026 dark theme's TextMate token colors should distinguish the relevant PowerShell scopes more strongly, likely in `extensions/theme-defaults/themes/2026-dark.json` without changing the PowerShell grammar unless the scopes are wrong.
