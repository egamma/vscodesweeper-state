# Issue #324962 — Copilot Chat side-panel input font is too small and cannot be independently resized

[https://github.com/microsoft/vscode/issues/324962](https://github.com/microsoft/vscode/issues/324962)

## Summary

Verified duplicate: the older open #298292 reports the same observable symptom—chat input text remains fixed at a small size because no independent input-editor font setting exists—and fully owns this request.

## Change summary

Allow the Copilot Chat side-panel input font size to be adjusted independently from message text, code blocks, and global UI zoom.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/298292 and add an independently configurable chat input-editor font size there, preserving the existing settings for response text and code blocks.
