# Issue #324962 — Copilot Chat side-panel input font is too small and cannot be independently resized

[https://github.com/microsoft/vscode/issues/324962](https://github.com/microsoft/vscode/issues/324962)

## Summary

Verified duplicate: the older open workbench-font issue tracks the same observable problem—non-editor UI text cannot be resized without globally zooming the window—and its discussion explicitly includes the chat input.

## Change summary

Allow the Copilot Chat side-panel input font to follow a chat font setting or be resized independently of the entire workbench.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/519 and ensure its workbench-font solution covers the chat input editor, which currently retains a fixed 13px font size.
