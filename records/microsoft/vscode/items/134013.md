# Issue #134013 — Code completion unexpectedly consumes closing paren (from auto-closing-brackets) that was inserted automatically when `(` triggered code completion

[https://github.com/microsoft/vscode/issues/134013](https://github.com/microsoft/vscode/issues/134013)

## Summary

Still reproduces on main: the `LineSuffix` tracking in `suggestController.ts` does not distinguish between auto-inserted closing brackets and user-typed text, so the `overwriteAfter` delta incorrectly consumes the closing paren when accepting a completion. Diagnosed by jrieken but unfixed due to design tension with #26012 and #3295.

## Change summary

Accepting a code completion triggered by `(` consumes the auto-inserted or manually typed closing `)` because suggest treats it as typed-ahead text to overwrite.

## Best solution

The `LineSuffix` mechanism in `src/vs/editor/contrib/suggest/browser/suggestController.ts` needs to distinguish auto-inserted closing brackets from user-typed text so `suffixDelta` excludes them from the overwrite range. jrieken noted in comment 12 that this is the approach under consideration, but it conflicts with the behavior wanted by https://github.com/microsoft/vscode/issues/26012 and https://github.com/microsoft/vscode/issues/3295, so it requires careful design.
