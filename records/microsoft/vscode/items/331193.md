# Issue #331193 — Minimap renders huge section-header text over LaTeX files for prose lines starting with the word region

[https://github.com/microsoft/vscode/issues/331193](https://github.com/microsoft/vscode/issues/331193)

## Summary

Confirmed on current main: the LaTeX folding-marker regex in extensions/latex/latex-language-configuration.json optionally allows a bare `region`/`endregion` word (no comment required), so any prose line starting with `region` in a `.tex`/`.sty` file gets treated as a folding region and rendered as a huge minimap section header. The reporter already has an upstream fix PR open, so this stays open pending that landing/sync rather than closing.

## Change summary

Bare prose lines starting with the word `region` in LaTeX files are misdetected as folding/section-header markers, producing a bogus huge minimap section header and gutter fold.

## Best solution

Land the upstream fix (jlelong/vscode-latex-basics#137) requiring the `%` comment prefix for `region`/`endregion` while keeping bare `\begingroup`/`\endgroup`, then sync extensions/latex/latex-language-configuration.json in this repo — or apply the equivalent regex change directly here if the upstream sync is slow.

## Evidence

- **current main regex:** extensions/latex/latex-language-configuration.json folding markers are `"start": "^\\s*%?\\s*(region|\\\\begingroup)\\b"` / `"end": "^\\s*%?\\s*(endregion|\\\\endgroup)\\b"` — the `%?` makes the comment character optional, so a bare prose line starting with `region` matches.
- **section header rendering:** src/vs/editor/common/services/findSectionHeaders.ts (shouldBeInComments: false for folding-marker-derived headers per the reporter's citation) does not filter out non-comment-based folding matches, so the rest of the line renders as a minimap section header.
- **upstream fix in flight:** Reporter opened https://github.com/jlelong/vscode-latex-basics/pull/137 ('Require % comment for region folding markers'), an open PR that would fix this at the source repo this file syncs from.
