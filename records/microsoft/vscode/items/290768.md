# Issue #290768 — Double rendering of same attachment when using background agent

[https://github.com/microsoft/vscode/issues/290768](https://github.com/microsoft/vscode/issues/290768)

## Summary

Still reproduces on main: pinning an implicit selection attachment adds a regular file attachment via `addFile()` but never disables or removes the implicit context entry, so both render simultaneously. Team-authored issue, no fix found.

## Change summary

Pinning an implicit selection attachment in a background agent session causes the same selection to render twice — once as the implicit context and once as the newly added file attachment.

## Best solution

In `implicitContextAttachment.ts`, the `pinSelection()` method should disable or remove the implicit context value after adding the pinned file attachment via `addFile()`. Likely needs to set `context.enabled = false` or clear the implicit context values for the pinned selection after the file is added to the attachment model.
