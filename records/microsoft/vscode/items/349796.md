# Issue #349796 — Remote Environments: Allow to add new connecttion

[https://github.com/microsoft/vscode/issues/349796](https://github.com/microsoft/vscode/issues/349796)

## Summary

Keep open: existing connection commands do not cover the request to add environments directly from Remote Environments. Current source offers Dev Container creation, but the SSH and Dev Tunnel entry-point gap remains.

## Change summary

Expose actions in Remote Environments to add SSH connections, connect to new Dev Tunnels, and create Dev Containers.

## Best solution

Make adding an environment discoverable within Remote Environments, using the existing connection workflows and preserving the available Dev Container creation actions. Track the fresh-profile tunnel authentication failure separately.
