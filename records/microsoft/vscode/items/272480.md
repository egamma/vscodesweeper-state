# Issue #272480 — Support showing longer setting descriptions in the UI

[https://github.com/microsoft/vscode/issues/272480](https://github.com/microsoft/vscode/issues/272480)

## Summary

Still present on main: settings descriptions longer than 20 lines are hard-truncated with no way to view the full text. The MAX_DESC_LINES cap in settingsTreeModels.ts has never been raised or made expandable.

## Change summary

Long setting descriptions (>20 lines) are truncated in the Settings UI with no way to view the full content.

## Best solution

Either raise the cap, make it expandable (e.g. a 'Show more' link that reveals the rest), or provide a hover/tooltip for the full description. The fix lives in `src/vs/workbench/contrib/preferences/browser/settingsTreeModels.ts` (the truncation logic) and likely the renderer in `settingsTree.ts` for a UI affordance.
