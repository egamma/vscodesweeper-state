# Issue #167818 — If I set focus back to Input 1, ctrl+z does nothing:

[https://github.com/microsoft/vscode/issues/167818](https://github.com/microsoft/vscode/issues/167818)

## Summary

Keep open: current source still makes Undo a no-op when a merge input has text focus, even though accepting a conflict changes the result. This team-authored, accepted request has no verified fixing commit or older canonical covering the same focus-dependent symptom.

## Change summary

Allow undoing a merge conflict acceptance without moving focus from Input 1 to the result editor.

## Best solution

Make undoing conflict acceptance available while a merge input remains focused, without making the inputs editable or changing ordinary editor Undo behavior. Agree on how this interacts with intervening manual result edits before implementing merge-specific command behavior.
