# Issue #337012 — Workspace picker flickers when enabling dev containers

[https://github.com/microsoft/vscode/issues/337012](https://github.com/microsoft/vscode/issues/337012)

## Summary

The flicker remains source-reproducible on current main: enabling Dev Containers invalidates availability while the tabbed picker is visible, and the refresh path forcibly hides and reopens the picker. This team-authored bug should remain open for a bounded workspace-picker fix.

## Change summary

Prevent the Agents Window workspace picker from flickering when Dev Container support is enabled.

## Best solution

Keep the visible workspace picker mounted while Dev Container availability is recomputed, then refresh its contents in place without losing focus, the active tab, or hover state.
