# Issue #275754 — Deleting a tab character using backspace doesn't work.

[https://github.com/microsoft/vscode/issues/275754](https://github.com/microsoft/vscode/issues/275754)

## Summary

The Backspace no-op remains reproducible from current source when a leading tab spans eight display columns but the indentation size is two. An open PR explicitly targets this issue, so keep it open while that implementation is reviewed.

## Change summary

Backspace fails to reduce leading tab indentation when the display tab size exceeds the indentation size.

## Best solution

Review https://github.com/microsoft/vscode/pull/300059 against the reported mixed-indentation scenario and land a verified correction so Backspace reduces indentation rather than doing nothing.

## Evidence

- **Exact failing source path:** In src/vs/editor/common/cursor/cursorDeleteOperations.ts, DeleteOperations.getDeleteLeftRange maps the position after a leading tab to visible column 8 and requests the previous indent stop at 6 when indentSize is 2. CursorColumns.columnFromVisibleColumn in src/vs/editor/common/core/cursorColumns.ts maps visible column 6 back to model column 2, because it is nearer the tab's end than its start. The resulting deletion range starts and ends at column 2; deleteLeft discards that empty range, producing no edit.
