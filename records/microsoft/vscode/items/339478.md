# Issue #339478 — Copilot Chat shows "Please try again" for a deterministic 400, and the image-specific error branch misses "unsupported image"

[https://github.com/microsoft/vscode/issues/339478](https://github.com/microsoft/vscode/issues/339478)

## Summary

Verified directly in current source: getErrorDetailsFromChatFetchErrorInner in src/platform/chat/common/commonTypes.ts gives the same 'Please try again' wording to every badRequest/failed response, and isVisionAttachmentInaccessibleError only special-cases a narrow substring match — exactly as the reporter traced from the bundled extension. This is a real, unfixed gap, not a duplicate of the generic failure-reporting meta issue.

## Change summary

Copilot Chat's generic 400/failed error message always says 'Please try again' even for deterministic request failures, and the image-specific error branch only matches a narrow substring so a clear 'unsupported image' rejection falls through to the generic message.

## Best solution

Rework getErrorDetailsFromChatFetchErrorInner (and isVisionAttachmentInaccessibleError) in src/platform/chat/common/commonTypes.ts so wording and image-specific detection don't rely solely on substring matching of free-text provider reasons; this likely needs a maintainer decision on wording per error subtype and on what structured signal (if any) is available across providers before implementation.
