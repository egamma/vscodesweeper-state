The underlying discovery flow was implemented and shipped: missing notebook outputs now offer a contextual Marketplace search for compatible renderers, while installing Jupyter automatically installs its renderer extension.

Recommend the Jupyter output-renderer extension when opening an .ipynb notebook, particularly in VS Code for the Web.
