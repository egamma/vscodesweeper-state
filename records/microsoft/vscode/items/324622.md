Team-authored bug report: Windows update gets stuck in 'installing...' state after switching update modes, with no resolution or progress. No fix found on main; keeping open.

## Change summary

After switching from manual to default update mode on Windows, the update shows 'installing...' indefinitely and never completes.

Investigate the Windows update state machine when switching between update modes at runtime — likely a state transition issue in the update service where the mode change leaves the updater in an inconsistent state.
