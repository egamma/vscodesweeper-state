Add a shared `pasteAttachmentConformance.ts` test suite so the workbench (`ChatInputPart`) and Agents window (`NewChatInputWidget`) paste-attachment lifecycles are asserted to agree, since only the paste-decision layer is currently shared while pill rendering, reference tracking, and reconciliation are duplicated and have already diverged into two shipped bugs.
