This is not an unconditional, persistent rejection or user-authored suppression rule, so the source does not establish that the request is completed.
- **Configuration boundary:** extensions/copilot/package.json registers github.copilot.nextEditSuggestions.enabled and controls for fixes, range, and whitespace-only changes. Disabling a suggestion category does not selectively suppress one unwanted edit while retaining useful suggestions.
