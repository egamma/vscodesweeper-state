# Issue #301424 — Sessions: seeing terminal error popping up when working with multiple sessions on `vscode`

[https://github.com/microsoft/vscode/issues/301424](https://github.com/microsoft/vscode/issues/301424)

## Summary

Keep open: current source still permits automatic task reveal to activate a terminal removed from the foreground by a session switch, reaching the exception in the reported stack. No verified older canonical or concrete fixing commit was found.

## Change summary

Prevent automatic task revelation from throwing a missing-terminal error when session switching has backgrounded the task's terminal.

## Best solution

Automatic handling of an already-running task should respect session-owned terminal visibility without throwing or bringing another session's terminal forward. Preserve explicit task-reveal behavior and normal task instance-policy handling.
