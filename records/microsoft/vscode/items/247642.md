Keep open: closing a detached notebook output preview should not unexpectedly move the source notebook's viewport. Preview availability changed after this report, but the linked test instructions provide enough context to retest; no verified fix or same-symptom canonical was found.

## Change summary

Closing a notebook output preview in a separate window unexpectedly scrolls the source notebook to a different section.

## Best solution

Preserve the source notebook's visible position when closing its detached output preview, while retaining normal explicit cell-navigation behavior. First reproduce the close-and-focus transition to establish whether focus restoration or notebook relayout causes the jump.
