# Issue #225916 — Surrounding with brackets doesn’t work in some cases

[https://github.com/microsoft/vscode/issues/225916](https://github.com/microsoft/vscode/issues/225916)

## Summary

Confirmed regression in auto-indent logic when surrounding a selection with brackets after arrow functions; an open community PR (https://github.com/microsoft/vscode/pull/321210) already addresses it with a targeted fix and regression test — keeping open pending PR review and merge.

## Change summary

Surrounding selected text with brackets deletes the selection and mis-indents instead of wrapping it, specifically after arrow function expressions in JS/TS.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/321210, which guards the previous-line indent-next-line inheritance so it only applies for empty-range (caret) insertions, not selection replacements. The fix is small and localized in `src/vs/editor/common/languages/autoIndent.ts`.
