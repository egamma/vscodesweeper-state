# Issue #345032 — Agent Host: steering a running session ends its turn, so clients see the agent as finished

[https://github.com/microsoft/vscode/issues/345032](https://github.com/microsoft/vscode/issues/345032)

## Summary

Keep open: both providers still emit an indistinguishable completion when steering transfers ongoing work into another turn. The protocol maintainer acknowledges that an explicit handover is warranted; the neighboring steering report describes a different failure.

## Change summary

Distinguish a steering handover from actual agent completion so AHP clients do not prematurely treat ongoing work as finished.

## Best solution

Agree on an interoperable handover contract in microsoft/agent-host-protocol, then implement it consistently in the Copilot and Codex providers while preserving steering history and ongoing execution.

- **Behavior:**

  > Sending steering during an active Copilot or Codex task must not produce an event that clients cannot distinguish from the agent actually finishing. Clients must identify continued execution without waiting an arbitrary debounce interval. Steering remains visible in conversation history, ongoing work continues, and genuine completion remains observable.
- **Trace:**

  > CopilotAgentSession._beginSteeringTurn calls _completeActiveTurn and then emits ChatTurnStarted with queuedMessageId; _completeActiveTurn publishes a plain completion. CodexAgent._beginSteeringTurn does the same while remapping the still-running native turn to a new host turn. The generated ChatTurnCompleteAction describes an idle assistant and contains no dedicated handover signal, and existing Copilot tests explicitly assert the split. https://github.com/microsoft/agent-host-protocol/issues/550 contains maintainer agreement that a handover is warranted, but does not settle its wire representation. Protocol changes originate in that repository and are synchronized into the generated VS Code copy. Preserve ordinary completion, cancellation, queued follow-ups, provider execution and steering history; do not treat https://github.com/microsoft/vscode/issues/336305 as the same delivery defect.
- **Open decisions:**
  - What interoperable protocol contract will distinguish steering handover from genuine completion, including what older clients observe when presentation turns remain separate?
