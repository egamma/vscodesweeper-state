# Issue #257122 — Embedded images copy paste from one notebook to another

[https://github.com/microsoft/vscode/issues/257122](https://github.com/microsoft/vscode/issues/257122)

## Summary

The attachment loss remains directly traceable on current main: cell paste preserves the Markdown reference but discards the metadata containing its image. Keep this open for a bounded notebook clipboard fix.

## Change summary

Copying Markdown cells between notebooks loses embedded image attachments and breaks their display.

## Best solution

Preserve content-bearing attachments when copying notebook cells, including after saving and reopening the destination, without copying execution bookkeeping or changing unrelated metadata semantics.
