# Issue #257122 — Embedded images copy paste from one notebook to another

[https://github.com/microsoft/vscode/issues/257122](https://github.com/microsoft/vscode/issues/257122)

## Summary

Confirmed in current source: `cloneNotebookCellTextModel` always sets `metadata: {}`, dropping cell metadata including Jupyter attachments (embedded images). This causes embedded images to be lost when copy/pasting markdown cells between notebooks.

## Change summary

Copy/pasting markdown cells with embedded images between notebooks loses the images because cell metadata (including attachments) is discarded during cloning.

## Best solution

Fix `cloneNotebookCellTextModel` in `src/vs/workbench/contrib/notebook/common/model/notebookCellTextModel.ts` to preserve `cell.metadata` (or at least non-transient metadata) when cloning, instead of hardcoding `metadata: {}`. Care is needed to avoid copying execution-related internal metadata that should be reset on paste.
