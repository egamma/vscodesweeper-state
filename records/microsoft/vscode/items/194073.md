# Issue #194073 — [Bug] “Save As…” isn't disabled on internal pages, yet doesn't do anything.

[https://github.com/microsoft/vscode/issues/194073](https://github.com/microsoft/vscode/issues/194073)

## Summary

The Settings editor still inherits a no-op Save As operation, while the File menu enables the command whenever an editor is active. Keep this accepted Backlog bug open; the maintainer discussion identifies a shared editor-contract concern, not a decision to decline the fix.

## Change summary

Disable File > Save As when the active internal page cannot meaningfully save a copy.

## Best solution

Make Save As availability reflect the active editor's actual support, so Settings and other non-saveable internal pages do not advertise an ineffective action. Preserve Save As for ordinary files, untitled documents, and other editors that support saving a copy.
