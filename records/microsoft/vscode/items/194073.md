# Issue #194073 — [Bug] “Save As…” isn't disabled on internal pages, yet doesn't do anything.

[https://github.com/microsoft/vscode/issues/194073](https://github.com/microsoft/vscode/issues/194073)

## Summary

Still reproducible on main: the 'Save As' menu item uses `ActiveEditorContext` as its precondition, which is true for internal editors like Settings, but those editors silently no-op on save-as. A narrower precondition or graceful handling is needed.

## Change summary

'Save As…' in the File menu is enabled on non-saveable internal pages (Settings, Keybindings, etc.) but does nothing when invoked.

## Best solution

Refine the precondition for the Save As menu entry (in `fileActions.contribution.ts`) to exclude editors that lack a meaningful save-as capability — either via an `EditorInputCapabilities` check or a dedicated context key that internal-only editors don't set.
