# Issue #155761 — Upstream find filter and replace improvements into workbench SimpleFindWidget

[https://github.com/microsoft/vscode/issues/155761](https://github.com/microsoft/vscode/issues/155761)

## Summary

The consolidation remains outstanding: notebook filters and replacement UI still live in a separate, notebook-coupled widget rather than the shared SimpleFindWidget. Keep this accepted backlog debt open; the related base-layer move does not own the same work.

## Change summary

Consolidate notebook find-filter and replacement infrastructure into the shared find widget so other consumers can reuse it.

## Best solution

Provide reusable, optional filter and replacement infrastructure shared with notebook find, while keeping notebook search semantics local and preserving find-only consumers. Coordinate with the base-layer relocation issue without treating relocation as completion of this consolidation.
