# Issue #155761 — Upstream find filter and replace improvements into workbench SimpleFindWidget

[https://github.com/microsoft/vscode/issues/155761](https://github.com/microsoft/vscode/issues/155761)

## Summary

The consolidation has not happened: the notebook find widget (`SimpleFindReplaceWidget` in notebookFindReplaceWidget.ts) is still a completely separate class from `SimpleFindWidget`, which still has zero replace support. The debt remains valid and the issue should stay open.

## Change summary

Upstream notebook-specific find filter and replace features into the shared SimpleFindWidget so terminal, webview, and browser-view consumers benefit from the same capabilities.

## Best solution

During a debt week, refactor `SimpleFindWidget` (src/vs/workbench/contrib/codeEditor/browser/find/simpleFindWidget.ts) to incorporate replace support and find filters from the notebook's `SimpleFindReplaceWidget` (src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFindReplaceWidget.ts), then migrate the notebook, terminal, webview, and browser-view find widgets to the unified base. Companion issue https://github.com/microsoft/vscode/issues/155762 (move SimpleFindWidget into base) should be coordinated with this work.
