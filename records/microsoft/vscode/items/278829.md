# Issue #278829 — Feature Request: Ignore specific folders/files in Copilot

[https://github.com/microsoft/vscode/issues/278829](https://github.com/microsoft/vscode/issues/278829)

## Summary

Keep open: this security-sensitive, well-supported Backlog request remains necessary because current `.copilotignore` enforcement is gated by an account token rather than exposed as ordinary workspace control. Maintainers have also treated this focused issue as the canonical report for the file-exclusion cluster.

## Change summary

Let users exclude selected files and folders from Copilot context gathering and agent file tools through workspace-controlled ignore rules.

## Best solution

Provide an officially supported workspace-level ignore mechanism, independent of enterprise token enablement, and enforce it consistently across file reads, searches, automatic context, attachments, and applicable write tools. Its pattern precedence, negation behavior, interaction with `.gitignore`, and blocked-access UX need explicit security review and product decisions.

## Evidence

- **existing enforcement foundation:** `extensions/copilot/src/extension/tools/node/toolUtils.ts` provides `assertFileNotContentExcluded()`, while `extensions/copilot/src/platform/search/vscode-node/searchServiceImpl.ts` filters ignored file and text-search results. These paths establish useful enforcement machinery but do not expose the requested user-controlled enablement.
- **no public setting:** `extensions/copilot/package.json` associates `.copilotignore` with the ignore language but registers no `github.copilot.ignoredPaths` or equivalent user setting.
