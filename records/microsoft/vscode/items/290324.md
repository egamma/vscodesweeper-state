## Summary

Already fixed on main and shipped in 1.119.0. The null-assertion crash on `this._editor.model.get()!` was guarded with a proper null check in commit 526381b4801.

## Change summary

Inline edits word replacement view crashes with 'Cannot read properties of null (reading getLineContent)' when the editor model is null.

## Best solution

Keep the shipped fix in commit 526381b4801 (1.119.0); no further change needed. The null guard on `this._editor.model.read(undefined)` prevents the crash path.
