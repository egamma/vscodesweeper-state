# Issue #304218 — Thinking effort UI dismisses main model picker UI on mouse move

[https://github.com/microsoft/vscode/issues/304218](https://github.com/microsoft/vscode/issues/304218)

## Summary

The underlying interaction bug — mouse movement over the main action list dismissing an open submenu/hover panel and potentially the entire widget — is still present in the action widget code on current main, though the model picker UI has been significantly redesigned since filing. The submenu hide/show logic in `onListHover` can race with focus tracking to dismiss the whole picker.

## Change summary

Moving the mouse around the model picker while the thinking effort submenu is expanded causes the entire model picker to dismiss.

## Best solution

Fix the focus/dismiss interaction in `ActionListWidget.onListHover` (src/vs/platform/actionWidget/browser/actionList.ts) so that mouse movement over the parent list while a submenu panel is open does not trigger the widget-level blur/dismiss. The submenu should close gracefully and focus should remain in the parent list without a blur event propagating to the `ActionWidgetService`.
