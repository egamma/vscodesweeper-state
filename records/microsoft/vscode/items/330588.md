# Issue #330588 — integrated browser doesn't automatic share new browse tab eg.  `target=_blank` or `window.open()`

[https://github.com/microsoft/vscode/issues/330588](https://github.com/microsoft/vscode/issues/330588)

## Summary

Keep open: agent-opened popup tabs still lose sharing in current source. A maintainer explicitly designated this issue as the canonical report, and the current popup creation path does not propagate the audiences required for agent visibility.

## Change summary

Tabs spawned through target="_blank" or window.open() from an agent-shared page should remain accessible to the agent.

## Best solution

Preserve agent access when an agent interaction opens a child tab from an already-shared page, while retaining existing storage, network-policy, and session-isolation restrictions. Keep this issue as the canonical report rather than duplicating it into the newer, closed reports.

- **Behavior:**

Cover both target="_blank" and window.open(). Unshared pages must not gain agent access as a side effect, and existing session isolation and network restrictions must remain effective.
