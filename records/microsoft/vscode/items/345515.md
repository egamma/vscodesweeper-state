# Issue #345515 — Info when opening an item from Inbox is too verbose

[https://github.com/microsoft/vscode/issues/345515](https://github.com/microsoft/vscode/issues/345515)

## Summary

Keep open as actionable Inbox UX feedback: generated context can compete with the command approval instead of supporting it. Current source includes brevity guidance, but that does not establish that the reported verbosity is resolved.

## Change summary

Reduce the information shown for an Inbox approval while retaining a minimal reminder of the session context.
