# Issue #331538 — Copilot external ingest falls back to memory when workspace storage directory is absent

[https://github.com/microsoft/vscode/issues/331538](https://github.com/microsoft/vscode/issues/331538)

## Summary

The missing-directory fallback remains present on current main, and the linked fix PR was closed without merging. Keep this older report open; the newer independently confirmed report describes the same cause and additional performance impact.

## Change summary

Ensure external-ingest workspace storage exists before opening its file-backed SQLite database, avoiding unintended in-memory fallback.

## Best solution

ExternalIngestIndex should create and reopen its persistent database when the declared file-scheme storage directory is initially absent, while preserving logged in-memory fallback for genuine storage failures. Revisit the closed implementation candidate and retain this older issue as the missing-directory tracking record.
