# Issue #199787 — Hover block highlight design consistency

[https://github.com/microsoft/vscode/issues/199787](https://github.com/microsoft/vscode/issues/199787)

## Summary

Keep open for UX design discussion: current source still defines different block indicators across Markdown preview, terminal, notebooks, and settings. Existing controls do not unify their appearance, and the canonical search found no verified older issue covering the same observable inconsistency.

## Change summary

Make comparable block hover and focus indicators visually consistent across Markdown preview, terminal commands, notebook cells, and settings while preserving meaningful state distinctions.

## Best solution

Agree on a consistent visual treatment for equivalent block indicators across the four surfaces, explicitly distinguishing hover, keyboard focus, and modified-state semantics. Preserve tree and editor indent guides, which the report excludes.

- **Behavior:**

- **Trace:**

  > Markdown preview defines hover and active-line pseudo-elements in extensions/markdown-language-features/media/markdown.css, gated by markdown.preview.markEditorSelection.
