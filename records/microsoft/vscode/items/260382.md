## Summary

The reported modify/delete conflict is already covered by the open canonical issue: Accept All Incoming does not resolve the incoming deletion, so staging still requires a separate resolution choice. Consolidate this report there, preserving its observation about contradictory staging feedback.

## Change summary

Accepting an incoming file deletion from the Source Control context menu should resolve that choice so staging does not ask the user to resolve it again.

## Best solution

Track the remaining deletion-resolution gap in https://github.com/microsoft/vscode/issues/72976: accepting the incoming deletion should remove the working-copy file and stage the resolution. Preserve the existing explicit Keep Our Version / Delete File staging flow for conflicts where no choice has been made.
