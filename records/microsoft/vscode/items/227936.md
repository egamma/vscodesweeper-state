# Issue #227936 — Closing a terminal that was reopen in a new window doesn't dispose the terminal object

[https://github.com/microsoft/vscode/issues/227936](https://github.com/microsoft/vscode/issues/227936)

## Summary

Plausible cross-window terminal lifecycle bug, but reported against 1.93.0 (nearly two years ago) and never confirmed — asking the reporter to verify on the latest build before investing triage time.

## Change summary

Closing a window that contains a terminal moved from another window does not properly dispose the terminal object in the originating window's extension API.

## Best solution

If still reproducible, the fix likely lives in the detach/shutdown flow in `src/vs/workbench/contrib/terminal/browser/terminalService.ts` (`_onWillShutdown` and `onDidRequestDetach`) — the originating window's extension host needs to receive a disposal or exit-code signal when the target window shuts down with the moved terminal. If no longer reproducible, close as `*not-reproducible`.
