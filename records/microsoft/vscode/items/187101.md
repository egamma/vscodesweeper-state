# Issue #187101 — DOM structure improvements for workbench toolbar actions

[https://github.com/microsoft/vscode/issues/187101](https://github.com/microsoft/vscode/issues/187101)

## Summary

The structural debt remains: notebook toolbar labels are still siblings of the focusable icon, and notebook-specific CSS still supplies the whole-action focus outline. Keep this team-authored cleanup open; the earlier visual fix did not complete the requested shared DOM and styling consolidation.

## Change summary

Unify labeled toolbar action structure so shared focus styling covers the icon and label without notebook-specific overrides.

## Best solution

Establish a reusable labeled-action focus structure in the shared action-bar implementation and adopt it in notebooks, preserving existing keyboard navigation, accessible names, and submenu behavior.
