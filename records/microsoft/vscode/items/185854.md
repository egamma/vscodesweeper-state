# Issue #185854 — TS/JS language features on PRs are completely off

[https://github.com/microsoft/vscode/issues/185854](https://github.com/microsoft/vscode/issues/185854)

## Summary

Still an open gap on main: the `pr` scheme is neither disabled (to suppress broken results) nor given proper single-file IntelliSense support in the TypeScript language features extension. The issue remains valid and unaddressed.

## Change summary

TS/JS language features (hover, occurrences) show incorrect/broken information when viewing PR diffs without checking out the branch.

## Best solution

Either add `'pr'` to `disabledSchemes` in `extensions/typescript-language-features/src/configuration/fileSchemes.ts` to suppress broken results, or better, provide proper single-file IntelliSense for the `pr` scheme (similar to how `walkThroughSnippet` and `vscode-notebook-cell` get semantic support). Coordination with the PR extension team (microsoft/vscode-pull-request-github) is likely needed.
