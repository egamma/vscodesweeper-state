# Issue #185854 — TS/JS language features on PRs are completely off

[https://github.com/microsoft/vscode/issues/185854](https://github.com/microsoft/vscode/issues/185854)

## Summary

Keep open: current source collapses distinct PR revisions into the same TypeScript buffer identity, allowing hovers to describe the wrong revision. This is a built-in TypeScript correctness defect, not merely missing project-wide IntelliSense.

## Change summary

Make TS/JS language information and ranges correspond to the displayed revision when reviewing a pull request without checking it out.

## Best solution

Preserve distinct PR revision identities throughout TypeScript buffer synchronization and language requests, so each diff side receives information for its own contents. Retain the existing single-file capability boundary rather than expanding this into project-wide PR IntelliSense.
