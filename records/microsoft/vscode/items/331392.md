## Change summary

In copilot-sdk-backed agent host sessions, the built-in github-mcp-server (with web_search) isn't available even though the extension's own GitHub MCP entry is intentionally excluded in favor of it.

## Best solution

An agent-host/Copilot CLI owner should confirm whether the SDK's built-in GitHub MCP server is actually being wired up for copilotcli sessions — the extension-side entry is deliberately excluded in `collectNonPluginMcpServers` (src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostLocalCustomizations.ts, `hasBuiltInGitHubMcpServer`) on the assumption the SDK supplies its own, so if `/env` shows neither, the SDK-side wiring or its web_search tool registration is the likely gap.
