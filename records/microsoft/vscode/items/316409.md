# Issue #316409 — Unneeded warnings

[https://github.com/microsoft/vscode/issues/316409](https://github.com/microsoft/vscode/issues/316409)

## Summary

The repeated per-percent warning behavior is fixed on current main: quota and rate-limit notifications now appear only when usage crosses the defined 50%, 75%, 90%, or 95% checkpoints.

## Change summary

Stop Copilot from showing another quota or rate-limit notification for every 1% of usage after 50%.

## Best solution

Keep the threshold-crossing logic introduced by commit 3016c0cd7e2239d82809f2f46af826b2ecae754b, which records the previous usage value and only notifies when a defined checkpoint is newly crossed.
