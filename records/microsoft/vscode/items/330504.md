# Issue #330504 — New tab (non-existing file) ignores User/Workspace settings

[https://github.com/microsoft/vscode/issues/330504](https://github.com/microsoft/vscode/issues/330504)

## Summary

Confirmed in source: `TextResourceEditor.onDidEditorPaste` in textResourceEditor.ts unconditionally calls `textModel.detectIndentation(...)` after auto-detecting a language on paste into an untitled/plaintext file, ignoring the `editor.detectIndentation` setting entirely — matching the reporter's exact scenario (new/untitled file only, existing files unaffected).

## Change summary

Pasting a code snippet into a new (untitled) file overrides the user's indentation settings (e.g. `editor.detectIndentation: false`) because the paste handler force-detects indentation after guessing the language.

## Best solution

In `onDidEditorPaste` (src/vs/workbench/browser/parts/editor/textResourceEditor.ts, around line 215-216), only call `textModel.detectIndentation(opts.insertSpaces, opts.tabSize)` when `opts.detectIndentation` is true, mirroring the guard already used in `modelService.ts` (`if (newOptions.detectIndentation) { model.detectIndentation(...) }`).
