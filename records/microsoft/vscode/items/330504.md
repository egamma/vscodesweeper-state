# Issue #330504 — New tab (non-existing file) ignores User/Workspace settings

[https://github.com/microsoft/vscode/issues/330504](https://github.com/microsoft/vscode/issues/330504)

## Summary

Traced conclusively in source: pasting whole content into a fresh untitled/plaintext editor triggers a language-guess-on-paste flow that unconditionally re-runs indentation detection, ignoring the user's `editor.detectIndentation: false` setting.

## Change summary

Pasting a code snippet into a brand-new untitled tab overrides the user's tabSize/insertSpaces settings even when `editor.detectIndentation` is set to false.

## Best solution

In `TextResourceEditor.onDidEditorPaste` (src/vs/workbench/browser/parts/editor/textResourceEditor.ts), guard the `textModel.detectIndentation(opts.insertSpaces, opts.tabSize)` call at the end of the method with `if (opts.detectIndentation) { ... }`, so the paste-triggered language switch doesn't force indentation re-detection when the user has disabled it.
