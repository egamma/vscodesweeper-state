# Issue #327010 — vscode_listCodeusages tool does not relay locations of references if the result set is too large

[https://github.com/microsoft/vscode/issues/327010](https://github.com/microsoft/vscode/issues/327010)

## Summary

The issue is valid and reproducible: when vscode_listCodeUsages returns a large reference set, the agent sees the total count but not the individual reference locations, preventing it from acting on the result.

## Change summary

Ensure vscode_listCodeUsages relays reference locations when more than 100 usages are found, ideally with batching or pagination.

## Best solution

Update the usages tool result serialization to return a bounded first batch of reference locations plus an explicit continuation mechanism for remaining references, while preserving the total count and definition information.
