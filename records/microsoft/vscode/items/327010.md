# Issue #327010 — vscode_listCodeusages tool does not relay locations of references if the result set is too large

[https://github.com/microsoft/vscode/issues/327010](https://github.com/microsoft/vscode/issues/327010)

## Summary

Current main confirms the large-result gap: the usages tool emits every reference as one unbounded text result and does not use its token budget. Keep this team-authored bug open and route it to chat tools.

## Change summary

Large List Code Usages results report the reference count but fail to relay usable locations to the agent.

## Best solution

Make `UsagesTool.invoke` honor the invocation token budget and return a deterministic, explicitly incomplete page with a continuation mechanism, while retaining locations for every included reference.
