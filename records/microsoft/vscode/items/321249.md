# Issue #321249 — MCP OAuth with Microsoft Entra fails in VS Code with AADSTS9010010 (resource/scope conflict), while manual token flow succeeds

[https://github.com/microsoft/vscode/issues/321249](https://github.com/microsoft/vscode/issues/321249)

## Summary

Keep open: multiple reporters confirmed the resource/scope rejection even with the broker disabled. The later reauthentication success is useful evidence, but does not establish that the original configuration now works or that a fix landed.

## Change summary

MCP authentication rejects an Entra-protected endpoint when its HTTPS resource identifier differs from the namespace of its advertised api:// scope.

## Best solution

Establish the supported Entra resource/scope handling in the built-in Microsoft authentication path and make valid MCP configurations authenticate consistently. Compare fresh and cached authentication for the original configuration before treating reauthentication as a complete resolution.
