## Summary

A meaningful accessibility gap remains on current main: read-aloud can stop and avoids concurrent sessions, but it still lacks pause/resume and semantic handling for lists and tables. This team-authored Backlog request should remain open as the earlier canonical report.

## Change summary

Improve chat response read-aloud with semantic narration of lists, tables, and syntax plus pause/resume and duplicate-playback protection.

## Best solution

Extend the chat synthesizer in `voiceChatActions.ts` with pause/resume controls and speech-oriented Markdown serialization for lists and tables, while retaining the existing stop and single-session behavior.
