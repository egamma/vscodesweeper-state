# Issue #340403 — Pasting into the Chat input freezes the window on Linux/X11 since 1.140.0 (1.139.1 works)

## Change summary

Pasting plain text (Ctrl+V) into the Chat input (or any webview-based input) on Linux/X11 freezes the whole window since 1.140.0; worked fine in 1.139.1.

## Best solution
