# Issue #340552 — Data loss: Agent Host restores existing Copilot CLI sessions with 0 turns and permanently deletes them via empty-session GC

[https://github.com/microsoft/vscode/issues/340552](https://github.com/microsoft/vscode/issues/340552)

## Summary

The reported build predates the landed protection against destructive GC of restored sessions. Current committed source explicitly protects restored zero-turn sessions, so the central data-loss defect can be closed as completed.

## Change summary

Prevent empty-session garbage collection from permanently deleting existing Copilot CLI conversations after an incomplete history restore.

## Best solution

Retain the unused-draft protection implemented in commit 4b2815878bc249c937a68b10a2abe15c93d4ed43. Cleanup-disable settings and recoverable deletion are separate enhancements, not prerequisites for protecting restored conversations.
