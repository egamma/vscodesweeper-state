# Issue #315252 — Clear Terminal "before that line"

[https://github.com/microsoft/vscode/issues/315252](https://github.com/microsoft/vscode/issues/315252)

## Summary

Keep open as a terminal feature request: existing clearing and scrollback controls do not preserve output from an arbitrary clicked line onward. No verified canonical issue or landed implementation was found.

## Change summary

Add a terminal context-menu action that removes output above a clicked line while preserving that line, subsequent output, and the running process.

## Best solution

Have the terminal owner evaluate selective scrollback trimming at a user-chosen line, including buffer and command-marker consistency. Treat the reported slowdown as motivation, not an established performance defect.
