## Summary

Keep open for the remaining Git-action consistency audit. The agentic-flow feedback has seen progress, but current source still restricts PR availability for some folder sessions, and the maintainer explicitly accepted the broader request.

## Change summary

Offer understandable, consistent commit, local merge, and pull-request choices across folder and worktree sessions without requiring agent-driven Git operations.

## Best solution

Preserve the distinction between local merging and PR creation, with labels and documentation accurately describing each operation.
