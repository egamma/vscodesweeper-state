# Issue #308442 — Feature Request: Native LM Studio Integration (like Ollama)

[https://github.com/microsoft/vscode/issues/308442](https://github.com/microsoft/vscode/issues/308442)

## Summary

Partially addressed by the existing BYOK custom endpoint support (LM Studio works via manual `chatLanguageModels.json` configuration), but the core request — Ollama-parity with automatic model discovery, CLI integration, and auto-detection — remains unimplemented. With 74 upvotes and Backlog status, this stays open.

## Change summary

Add native LM Studio integration with auto-detection, dynamic model discovery, and CLI support, mirroring the existing Ollama provider.

## Best solution

Implement an `LMStudioLMProvider` analogous to `extensions/copilot/src/extension/byok/vscode-node/ollamaProvider.ts` that auto-detects the `lms` CLI, discovers available models from the LM Studio API, and registers them in the model picker without manual JSON configuration. The custom endpoint provider already handles the OpenAI-compatible protocol, so the main work is discovery and lifecycle integration.
