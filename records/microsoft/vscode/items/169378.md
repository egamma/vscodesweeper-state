# Issue #169378 — Set plain text language mode when saving as plain text

[https://github.com/microsoft/vscode/issues/169378](https://github.com/microsoft/vscode/issues/169378)

## Summary

The requested behavior remains absent on current main, and this accepted Backlog feature request has the required 20 community upvotes. It should remain open under the existing workbench editor routing.

## Change summary

When an untitled editor inherits its language through `files.defaultLanguage`, saving it with a `.txt` extension should switch it to plain text.

## Best solution

Distinguish an inherited default language from a language explicitly selected by the user, then let Save As retain the filename-derived plain-text mode for inherited languages while preserving explicitly selected source modes. The likely boundary is `UntitledTextEditorModel` language provenance and the language-copy logic in `textFileService.ts`.
