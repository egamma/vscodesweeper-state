# Issue #169378 — Set plain text language mode when saving as plain text

[https://github.com/microsoft/vscode/issues/169378](https://github.com/microsoft/vscode/issues/169378)

## Summary

The requested behavior remains missing: saving an untitled JavaScript model as .txt still preserves JavaScript instead of adopting Plain Text. This accepted Backlog request has 20 upvotes and warrants a maintainer decision on language precedence, not a staleness close.

## Change summary

Automatically adopt Plain Text when an untitled file inherits the active editor's language and is then saved with a .txt extension.

## Best solution

Make saving to a recognized .txt destination honor Plain Text for an inherited default language, with an explicit policy for preserving user-selected language modes. Resolve the compatibility concern raised in the discussion before changing the shared Save As behavior.
