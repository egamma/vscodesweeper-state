# Issue #329947 — Integrated terminal makes characters after the line wrap invisible (when uzing `fzf`)

[https://github.com/microsoft/vscode/issues/329947](https://github.com/microsoft/vscode/issues/329947)

## Summary

Fresh, well-diagnosed report: the reporter isolated the trigger (fzf's Ctrl+R history search in Windows PowerShell) and confirmed it's specific to the local/native integrated terminal (not remote/WSL, not Windows Terminal), pointing to a real terminal-state corruption bug in VS Code's local terminal stack rather than fzf itself.

## Change summary

After using fzf's Ctrl+R history search in a local PowerShell integrated terminal on Windows, subsequent wrapped lines render with invisible text.

## Best solution

Terminal team should trace how fzf's PSReadLine Ctrl+R handler leaves terminal/SGR state (e.g. conceal/invisible attribute or wrap-mode) after it exits, and whether xterm.js (bundled as @xterm/xterm, an external dependency) or VS Code's ConPTY/renderer integration fails to reset it — reproduce locally on Windows with PowerShell + fzf installed.
