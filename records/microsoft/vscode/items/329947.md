# Issue #329947 — Integrated terminal makes characters after the line wrap invisible (when uzing `fzf`)

[https://github.com/microsoft/vscode/issues/329947](https://github.com/microsoft/vscode/issues/329947)

## Summary

Keep this open and route it to terminal owners: the reporter isolated the wrapping failure to invoking fzf through PSFzf in a fresh Windows Sandbox installation. Neither a concrete fix nor an older canonical reporting the same symptom was established.

## Change summary

After invoking fzf history search through PSFzf, wrapped PowerShell input becomes invisible in the integrated terminal.

## Best solution

Restore visible wrapped input after both accepting and cancelling fzf history search. Terminal owners should first isolate whether the incorrect state originates in PSFzf/fzf, ConPTY, or xterm.js, using the existing upstream report without assuming ownership from the trigger alone.
