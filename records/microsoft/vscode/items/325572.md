# Issue #325572 — Log Panel: Allow filtering AHP Log for content

[https://github.com/microsoft/vscode/issues/325572](https://github.com/microsoft/vscode/issues/325572)

## Summary

Valid feature request from a team member to add content-based filtering to the AHP Log panel. The existing debug event log has text filtering via `debugEventMatchesText`, but the raw AHP protocol log view apparently only filters by frame type/subtype, not by message content. Keeping open as a backlog item.

## Change summary

Allow keyword/content-based filtering in the AHP Log panel, not just filtering by frame type/subtype.

## Best solution

Extend the AHP Log panel's filter to search chat message content (similar to how `debugEventMatchesText` in `src/vs/workbench/contrib/chat/common/chatDebugEvents.ts` already matches against event content fields). The filter widget and plumbing in `chatDebugFilters.ts` already support text input — the gap is likely in how raw AHP frames are matched against the text filter.
