# Issue #330869 — Using `screenshot_page` tool without GitHub authentication provider stops chat

[https://github.com/microsoft/vscode/issues/330869](https://github.com/microsoft/vscode/issues/330869)

## Summary

The current source still requests GitHub authentication while rendering screenshot results for a vision-capable BYOK model, even though that endpoint cannot use the GitHub image-upload path. Keep this open as a confirmed, bounded chat image-handling bug.

## Change summary

A screenshot tool result aborts a BYOK agent conversation when the built-in GitHub authentication provider is disabled.

## Best solution

BYOK screenshot results should reach the selected vision-capable model without requiring GitHub authentication. Preserve authenticated Copilot image uploads, image-size limits, and existing behavior for models without vision support.
