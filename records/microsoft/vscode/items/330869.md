# Issue #330869 — Using `screenshot_page` tool without GitHub authentication provider stops chat

[https://github.com/microsoft/vscode/issues/330869](https://github.com/microsoft/vscode/issues/330869)

## Summary

Real bug in the BYOK / no-GitHub-auth-provider path: a GitHub authentication lookup times out and surfaces as a visible chat error even though the tool itself succeeded, matching the exact 5s timeout path in `authenticationService.ts` and confirmed by the reporter's working `$getSession`/`$getAccounts` patch.

## Change summary

With the `vscode.github-authentication` extension disabled and a BYOK model configured, using the `screenshot_page` browser tool in agent mode produces a correct screenshot but then a visible 'Timed out waiting for authentication provider github to register' error that stops the chat turn.

## Best solution

Guard whichever Copilot-side call triggers this (likely a `getCopilotToken()`/`getAnyAuthSession()`/`getAccounts('github')` path exercised on this turn) behind `hasCopilotTokenSource`/`anyGitHubSession` the way `languageModelAccess.ts` and `contextKeys.contribution.ts` already do elsewhere, or catch the 5s timeout from `AuthenticationService.tryActivateProvider` in `src/vs/workbench/services/authentication/browser/authenticationService.ts` so it doesn't propagate to the visible chat turn when no GitHub auth provider is registered.
