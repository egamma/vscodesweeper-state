# Issue #317386 — Why show "+1 more workspaces"

[https://github.com/microsoft/vscode/issues/317386](https://github.com/microsoft/vscode/issues/317386)

## Summary

Keep open as a team-authored Agents Window design discussion. Current main provides persistent recent-only/all-session modes and manual workspace ordering, but the default “+N more workspaces” presentation remains and no linked change explicitly resolves this issue.

## Change summary

Reconsider whether inactive workspace sections should be hidden behind “+N more workspaces” and how workspace sessions should be ordered without unstable movement.

## Best solution

Settle whether recent-only workspace capping should remain the default; if retained, ensure the affordance is understandable while preserving the persistent “Show All Sessions” option and user-managed workspace order.
