[https://github.com/microsoft/vscode/issues/339486](https://github.com/microsoft/vscode/issues/339486)

## Summary

Genuine feature gap confirmed from source — EditorZoom is a single global singleton, not per-group/per-editor state — but the issue is brand new (0 days old, 0 upvotes) with no maintainer or community traction yet, so it's too early to escalate; keeping it open as a plain feature request.

## Change summary

Let text zoom level be set independently per editor group/view instead of applying globally to all editors.

## Best solution

If pursued, zoom state would need to move from the global `EditorZoom` singleton (src/vs/editor/common/config/editorZoom.ts) into per-editor-group state threaded through editor configuration, font-info computation, and the pinch-zoom gesture handler — a cross-cutting design change a maintainer should scope before implementation.
