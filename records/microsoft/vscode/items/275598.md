# Issue #275598 — Shell Integration unwanted characters in files

[https://github.com/microsoft/vscode/issues/275598](https://github.com/microsoft/vscode/issues/275598)

## Summary

Still reproduces on main: the bash shell integration's `__vsc_command_output_start` writes OSC 633 escape sequences to stdout, which leaks into files when the user redirects output. An open community PR (#307552) proposes a fix. Keeping open pending that PR.

## Change summary

Bash shell integration escape sequences leak into files written via stdout redirection in the integrated terminal.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/307552, which redirects the two `builtin printf` calls in `__vsc_command_output_start` to `/dev/tty` instead of stdout, preventing leakage into user-redirected files.
