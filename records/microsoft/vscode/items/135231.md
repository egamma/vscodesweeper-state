# Issue #135231 — Troublesome focus behavior after Ctrl+Enter to stage/commit changes when multiple repos are open. Could also be avoided by adding a Git command to stage/commit tracked changes in multiple (all) open repos at once

[https://github.com/microsoft/vscode/issues/135231](https://github.com/microsoft/vscode/issues/135231)

## Summary

Keep open: explicit keyboard navigation between commit inputs exists, but automatic post-commit advancement and committing across repositories remain unsupported. The remaining work is a workflow enhancement, distinct from the historical unwanted-focus-switching bugs.

## Change summary

Support efficient keyboard-only staging and committing across multiple repositories through post-commit focus advancement or an explicit multi-repository command.

## Best solution

Define an explicit multi-repository commit workflow in SCM and the built-in Git extension, preserving focus during unrelated repository refreshes. Existing next/previous-input commands provide an interim keyboard workflow, but do not fully deliver the requested automation.
