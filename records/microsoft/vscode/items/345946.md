# Issue #345946 — Chat sessions: delete confirmation dialog should name the chat being deleted

[https://github.com/microsoft/vscode/issues/345946](https://github.com/microsoft/vscode/issues/345946)

## Summary

The shared delete confirmation still omits session titles on current main. Keep this open as a bounded usability improvement; identifying deletion targets does not require the optional undo or focus-policy changes.

## Change summary

Identify the selected chat sessions by title in single- and multiple-session deletion confirmations.

## Best solution

Make the shared Chat Sessions confirmation identify the actual deletion targets while retaining the irreversible-action warning. Keep soft deletion, recovery, and changes to default button focus outside this improvement.
