# Issue #345946 — Chat sessions: delete confirmation dialog should name the chat being deleted

[https://github.com/microsoft/vscode/issues/345946](https://github.com/microsoft/vscode/issues/345946)

## Summary

The shared delete confirmation still omits session titles on current main. Keep this bounded UX refinement open; the existing dialog confirms deletion correctly but does not help users recognize a mis-targeted selection.

## Change summary

Identify the selected chat session or sessions by title in the deletion confirmation.

## Best solution

Make the shared Chat Sessions confirmation identify the actual deletion targets, with a bounded title list for multiple sessions. Preserve deletion semantics and keep optional undo, metadata enrichment, and focus changes outside this refinement.
