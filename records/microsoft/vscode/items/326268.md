## Evidence

- **Complete discussion:** Read the full expanded request at https://github.com/microsoft/vscode/issues/326268#issuecomment-4998171579. It explicitly asks for bulk export, restore into another workspace, resumed conversations, and resolution of references after paths change; the later comment asks for an update, with no maintainer decision or linked implementation.
- **Existing individual-session capability:** src/vs/workbench/contrib/chat/browser/actions/chatImportExport.ts registers workbench.action.chat.export (Chat: Export Chat...) and workbench.action.chat.import (Chat: Import Chat...). Export serializes the last-focused session through model.toExport(); import reads one JSON file. src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts invokes registerChatExportActions(). These commands partially satisfy the request, but do not provide selected-session or workspace-wide backup.
- **Restore persistence boundary:** src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts:461-472 explicitly excludes imported sessions from normal local-session persistence through shouldStoreSession(). Opening an exported conversation is therefore not equivalent to the requested durable history restoration.
- **Workspace continuity boundary:** src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts selects workspaceStorageHome/<workspaceId>/chatSessions for nonempty workspaces. Its migration is wired to IWorkspaceEditingService.onDidEnterWorkspace; this is not a general discovery or recovery mechanism for a project renamed or moved outside that transition.
- **Verified older related requests:** https://github.com/microsoft/vscode/issues/312058 is open and requests bulk export of nonarchived sessions in the current workspace. https://github.com/microsoft/vscode/issues/305818 is open and requests discovery and recovery of history orphaned by workspace moves. https://github.com/microsoft/vscode/issues/283951 is open and requests portable file references. Each covers only a portion of this request, so none meets the full-scope duplicate bar.
- **Broader canonical search:** https://github.com/microsoft/vscode/issues/285106 is open but concerns centralized visibility, cleanup, and context merging, not portable backup and restore. https://github.com/microsoft/vscode/issues/291662 concerns full-history transcript export, while https://github.com/microsoft/vscode/issues/281284 concerns sharing through Gists. Searches for backup, bulk export, workspace moves, and history portability did not establish an older canonical owning the entire requested workflow.
