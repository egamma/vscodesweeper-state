# Issue #275727 — Make it easier for Playwright to write to a Monaco editor

[https://github.com/microsoft/vscode/issues/275727](https://github.com/microsoft/vscode/issues/275727)

## Summary

Valid team-authored feature request to improve Monaco editor's programmatic input surface for Playwright/automation. No implementation work has landed on main referencing this issue; the request remains open and actionable.

## Change summary

Make it easier for Playwright automation (and LLM-driven agents) to type into Monaco editors without fragile workarounds involving the internal textarea.

## Best solution

Expose a stable, DOM-discoverable entry point for programmatic text input into Monaco editors — e.g. a data attribute or aria hook that test harnesses and automation tools can target to invoke `executeCommand('type', …)` without needing to know Monaco internals. The work belongs in `src/vs/editor/browser/controller/` (the edit-context / textarea layer). Alex Dima's comment suggests the mechanism already exists internally (`executeCommand('type', …)`); the gap is making it discoverable from outside the JS context, which matters for LLM-driven tool use where prompting alone is unreliable.
