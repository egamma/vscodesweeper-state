# Issue #275727 — Make it easier for Playwright to write to a Monaco editor

[https://github.com/microsoft/vscode/issues/275727](https://github.com/microsoft/vscode/issues/275727)

## Summary

Keep open for Monaco automation design: current tooling provides specialized typing workarounds, not the discoverable, editor-wide interaction requested. Maintainer discussion and a report explicitly consolidated into this issue establish continuing demand; no qualifying fix or older open canonical was found.

## Change summary

Make writing to Monaco editors reliably discoverable through Playwright-driven automation without extensive prompting or per-surface tools, with reading as a possible extension.

## Best solution

Define a discoverable automation contract shared by Monaco-backed surfaces, covering reliable text entry without requiring an agent to remember custom JavaScript or surface-specific workarounds. Settle whether that contract supports ordinary Playwright interactions or explicitly exposed editor commands, while preserving native editing and accessibility behavior.
