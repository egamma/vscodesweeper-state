# Issue #251433 — copilot -- Copying notebook HTML output not working for some keyboard shortcuts.

[https://github.com/microsoft/vscode/issues/251433](https://github.com/microsoft/vscode/issues/251433)

## Summary

Still reproduces on main: the alt-key handler in webviewPreloads.ts unconditionally sets `draggable = true` on keydown, which prevents alt-based copy shortcuts from working on HTML notebook outputs. An open PR (#251434) exists but has not merged.

## Change summary

Alt-key-based copy shortcuts (e.g. Alt+C) fail to copy text from HTML notebook cell outputs because the alt keydown handler makes the element draggable, interfering with the copy operation.

## Best solution

Land the open fix PR (https://github.com/microsoft/vscode/pull/251434) after review — the fix should refine the alt-key handler in `webviewPreloads.ts` so that holding alt only enables drag when a drag gesture actually starts, rather than unconditionally setting `draggable = true` on every alt keydown.
