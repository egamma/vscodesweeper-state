# Issue #156013 — I can't scroll screen using Windows Ink

[https://github.com/microsoft/vscode/issues/156013](https://github.com/microsoft/vscode/issues/156013)

## Summary

A broader report covering pen-based scrolling, dragging, and selection was explicitly closed as out of scope, and this request is the scrolling subset of that same Windows Ink behavior. The request reached the Backlog through community upvotes, but the later maintainer decision provides clear scope precedent.

## Change summary

Support scrolling VS Code content by dragging with a Windows Ink pen.
