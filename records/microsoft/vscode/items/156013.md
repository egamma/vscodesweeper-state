# Issue #156013 — I can't scroll screen using Windows Ink

[https://github.com/microsoft/vscode/issues/156013](https://github.com/microsoft/vscode/issues/156013)

## Summary

Windows Ink pen scrolling is a real gap. VS Code's custom scrollbar widgets process wheel events, while Windows Ink pen gestures likely do not generate wheel events through Chromium's input pipeline. The issue has 24 upvotes and is in the Backlog — it should stay open.

## Change summary

Scrolling with a Windows Ink pen device does not work in VS Code.

## Best solution

Investigate whether VS Code's custom scrollbar implementation (src/vs/base/browser/ui/scrollbar/) can handle pen pointer events for scrolling, or whether this requires upstream Chromium/Electron changes to translate pen-based pan gestures into scroll/wheel events. The `touch-action: none` on the workbench and list views may also prevent native pen scrolling. A fix may require either translating pen pointer events into scroll deltas in the custom scrollbar, or adjusting `touch-action` for pen input.
