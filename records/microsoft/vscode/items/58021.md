# Issue #58021 — new settings UI: possible to undo a setting change?

[https://github.com/microsoft/vscode/issues/58021](https://github.com/microsoft/vscode/issues/58021)

## Summary

Valid feature request for undo/redo support in the Settings UI editor. Not implemented on current main — the settings editor has per-setting reset but no Ctrl+Z undo stack. Low traction (1 upvote over 6 years) but a reasonable ask; stays open in Backlog.

## Change summary

Allow undoing accidental setting changes in the Settings UI via Ctrl+Z/Cmd+Z.

## Best solution

Implement an undo stack in the settings editor (src/vs/workbench/contrib/preferences/browser/settingsEditor2.ts) that tracks setting value changes and allows reverting them with the standard undo keybinding. The per-setting 'Reset' action partially addresses this but doesn't cover the Ctrl+Z workflow users expect.
