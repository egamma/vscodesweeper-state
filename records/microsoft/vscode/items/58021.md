# Issue #58021 — new settings UI: possible to undo a setting change?

[https://github.com/microsoft/vscode/issues/58021](https://github.com/microsoft/vscode/issues/58021)

## Summary

Keep open: undoing an accidental settings-control change remains distinct from resetting a setting or undoing text inside an input. Source inspection found no settings-editor undo integration, and the older text-field undo issue does not cover this request.

## Change summary

Allow Ctrl+Z or Cmd+Z to restore the previous setting value after an accidental change in the Settings UI.

## Best solution

Provide undo for committed Settings UI changes, restoring the previous configured value in its original configuration scope rather than resetting to the default. Preserve native text-input undo behavior.

- **Existing capabilities do not cover the central ask:** src/vs/workbench/contrib/preferences/browser/settingsTree.ts registers settings.resetSetting by emitting value: undefined, which removes the configured value rather than restoring its previous value. workbench.action.openSettingsJson opens the JSON editor, but switching to JSON is not keyboard undo within the Settings UI. ConfigurationEditing.applyEditsToBuffer uses model.pushEditOperations in src/vs/workbench/services/configuration/common/configurationEditing.ts; underlying text-model edit history alone does not provide the requested Settings UI interaction.
