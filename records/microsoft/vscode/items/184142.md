# Issue #184142 — Custom editors should not allow to make edits after extension host restart

[https://github.com/microsoft/vscode/issues/184142](https://github.com/microsoft/vscode/issues/184142)

## Summary

Keep open: disconnected custom editors still need an explicit non-editable state, and an open PR already references this issue with a proposed fix. Review that implementation before considering completion; the later backup-veto report is related but not proof that preventing further edits also restores recovery.

## Change summary

Prevent custom editors from accepting unsaveable edits after their extension host restarts, and explain the disconnected state to users.

## Best solution

Review and, if suitable, land https://github.com/microsoft/vscode/pull/338098 so disconnected custom editors prevent further editing, explain the interruption, and preserve existing dirty state. Assess the reported backup-veto sequence separately rather than treating edit prevention as document recovery.
