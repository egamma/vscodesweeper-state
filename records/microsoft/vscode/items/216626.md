# Issue #216626 — Deleting lines when editor.linkedEditing is enabled leads to inconsistent results

[https://github.com/microsoft/vscode/issues/216626](https://github.com/microsoft/vscode/issues/216626)

## Summary

The defect remains source-reproducible on current main: linked editing treats a whole-line deletion that merely intersects the active tag-name range as an edit to mirror, causing the surviving tag name to be erased. This should remain open for a bounded editor fix and regression test.

## Change summary

Deleting an entire line containing one side of a linked HTML tag can incorrectly erase the name from the surviving tag.

## Best solution

Linked editing should abandon synchronization when an edit extends outside the active linked range, while retaining normal mirroring for edits confined to a tag name. Add a regression test covering whole-line deletion from either linked tag.
