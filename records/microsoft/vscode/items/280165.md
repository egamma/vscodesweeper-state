# Issue #280165 — GitHub Copilot Chat auto-links file/folder references in responses, breaking copy-paste to external systems

[https://github.com/microsoft/vscode/issues/280165](https://github.com/microsoft/vscode/issues/280165)

## Summary

Still reproduces on main: Copilot Chat's inline reference system converts backtick code to contentRef links that produce broken vscode-file:// URIs when copied externally, and sometimes links unrelated code spans to workspace files. A maintainer (mjbvz) acknowledged two sub-bugs in comment 3. The related issue #312422 appears to be a satellite duplicate of this one.

## Change summary

Chat auto-links backtick code references to workspace files and produces non-functional vscode-file:// URIs when the response is copied to external systems.

## Best solution

Fix the copy path (right-click copy and Ctrl+C rich-text copy) to strip or convert contentRef/vscode-file links back to plain inline-code markdown when targeting external clipboard consumers. The two sub-bugs mjbvz identified in comment 3 — (1) vscode-file: URIs leaking into text/html clipboard and (2) right-click copy dropping file/symbol links entirely — should be addressed in the chat copy actions and the markdown decorations renderer. #312422 and #313539 appear to be narrower duplicates of the copy-paste aspect and could be consolidated here.
