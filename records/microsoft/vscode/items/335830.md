# Issue #335830 — Don't see codex/claude download message when not signed in

[https://github.com/microsoft/vscode/issues/335830](https://github.com/microsoft/vscode/issues/335830)

## Summary

Keep open to verify the complete signed-out harness-selection flow on Windows. The banner logic already offers missing SDKs independently of sign-in, but that does not establish that the reporter can reach it; this team-authored report has no verified duplicate or issue-referencing fix.

## Change summary

Selecting Codex or Claude in a fresh signed-out Windows profile should expose the missing-SDK download offer rather than leave the user at a dialog without download guidance.

## Best solution

Make the signed-out selection flow expose the existing agent-specific Download banner when its SDK is missing, without requiring GitHub sign-in merely to obtain the SDK. First reproduce the reported dialog and determine whether selection availability, setup-state publication, or notification presentation prevents that flow.
