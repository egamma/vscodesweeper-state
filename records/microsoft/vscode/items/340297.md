# Issue #340297 — Add a command-line option to open files without focusing the window

[https://github.com/microsoft/vscode/issues/340297](https://github.com/microsoft/vscode/issues/340297)

## Summary

Brand-new, well-researched feature request (0 reactions, filed hours ago) asking for a CLI opt-in to open files in an existing window without focusing it. Verified on current main that no such option exists and the focus call is unconditional, so this is a real, unimplemented gap worth keeping open as a feature request rather than closing for lack of traction yet.

## Change summary

Add a command-line option (e.g. `--background`) so `code <file>` opens files in an existing window without focusing/activating that window.

## Best solution

Add a boolean CLI flag (argv.ts) threaded through to `doOpenFilesInExistingWindow` in windowsMainService.ts so it can skip the `focusMainOrChildWindow` call for that invocation, after a maintainer decides the flag's exact scope and name.
