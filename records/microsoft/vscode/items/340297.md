# Issue #340297 — Add a command-line option to open files without focusing the window

[https://github.com/microsoft/vscode/issues/340297](https://github.com/microsoft/vscode/issues/340297)

## Summary

Keep open as a feature request: current source still lacks an opt-in CLI mode that opens files without activating the existing window. The earlier request is closed, its implementation PR never merged, and the open startup-focus report does not cover the same observable scenario.

## Change summary

Provide a command-line option that opens files or diffs in an existing VS Code window without changing application focus or window stacking order.

## Best solution

Support an explicit non-activating CLI file-open mode in the native window-opening path while preserving ordinary CLI focus behavior and existing file/diff handling. The CLI contract should be accepted by the area owner before implementation.
