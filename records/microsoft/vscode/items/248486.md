# Issue #248486 — Add code to make the cursor always appear below the editor sticky scroll (especially on cursor jump)

[https://github.com/microsoft/vscode/issues/248486](https://github.com/microsoft/vscode/issues/248486)

## Summary

Keep open: current source still reserves space using the configured maximum sticky-line count rather than the widget's actual occupied height. Related reports document the consequences, but neither establishes an eligible canonical for this re-reviewed, team-authored request.

## Change summary

Keep the cursor visible below editor sticky scroll, including after cursor jumps, without relying on maximum-line-count padding.

## Best solution

Make cursor-reveal calculations account for the sticky widget's occupied space at the destination while preserving configured cursor-surrounding context. Coordinate this work with the related padding and variable-line-height reports.

## Evidence

- **Existing capability and remaining gap:** src/vs/editor/browser/viewParts/viewLines/viewLines.ts:693–799, ViewLines._computeScrollTopToRevealRange, computes surroundingLines as Math.max(cursorSurroundingLines, stickyScrollEnabled ? maxNumberStickyLines : 0), then multiplies by the editor line height. This remains the maximum-count heuristic described by the issue, not destination-specific sticky-widget clearance.
- **Additional padding consumer:** src/vs/editor/common/viewModel/viewModelImpl.ts:726–752, getViewRangeWithCursorPadding, likewise uses stickyScroll.maxLineCount to shrink the visible range. src/vs/editor/common/config/editorOptions.ts registers editor.stickyScroll.enabled, maxLineCount, defaultModel and scrollWithEditor; these settings do not provide actual-height-aware cursor clearance.
- **Widget computation boundary:** src/vs/editor/contrib/stickyScroll/browser/stickyScrollController.ts renders on scroll changes. findScrollWidgetState derives sticky lines from the current scrollTop, visible ranges and candidate geometry; _updateState awaits the folding model before applying widget state.
