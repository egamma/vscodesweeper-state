# Issue #135972 — The call hierarchy UI should have the ability to filter calls, or apply name filter patterns

[https://github.com/microsoft/vscode/issues/135972](https://github.com/microsoft/vscode/issues/135972)

## Summary

Keep open in the call hierarchy backlog. Built-in F3 filtering partially covers name matching, but path/name exclusion remains missing, and a team member recently confirmed this as the canonical issue.

## Change summary

Add call hierarchy filtering by caller name or file path so users can exclude tests and other noisy results.

## Best solution

Add a call-hierarchy filter control supporting generic name and path inclusion/exclusion while preserving provider-independent behavior. Test-aware semantic filtering may require richer hierarchy metadata or language-extension support.
