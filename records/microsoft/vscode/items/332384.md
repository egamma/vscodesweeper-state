# Issue #332384 — Agents window: Model changed when creating session on PR

[https://github.com/microsoft/vscode/issues/332384](https://github.com/microsoft/vscode/issues/332384)

## Summary

Keep open to verify model preservation in the PR-created session's first chat. This team-authored report has a specific reproduction and useful control cases, but current-source inspection does not conclusively establish either the failure or a qualifying fix.

## Change summary

Creating a session from a pull request unexpectedly changes the selected model, while ordinary new sessions and subsequent chats preserve it.

## Best solution

Ensure the first chat created through New Session from Pull Request preserves the applicable model preference, as ordinary session creation does. First reproduce on the current build and distinguish a picker-only mismatch from an actual change in the model used for requests.
