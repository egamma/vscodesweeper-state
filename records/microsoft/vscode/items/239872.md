# Issue #239872 — Error when installing extensions when using HTTP proxy

[https://github.com/microsoft/vscode/issues/239872](https://github.com/microsoft/vscode/issues/239872)

## Summary

Still reproduces on main: setting `http.proxyAuthorization` to a raw `user:pass` value causes Electron's network layer to reject the malformed `Proxy-Authorization` header with `ERR_INVALID_ARGUMENT`. The code in `requestService.ts` passes the value verbatim without validation or encoding. chrmarti (MEMBER) is already engaged, and the most recent commenter (Jan 2026) confirms the issue persists.

## Change summary

Setting `http.proxyAuthorization` to a raw credentials string causes `net::ERR_INVALID_ARGUMENT` in Electron's network layer when installing extensions or signing in behind an HTTP proxy.

## Best solution

Either validate/encode the `http.proxyAuthorization` value (detect raw `user:pass` and auto-wrap as `Basic <base64>`) in `src/vs/platform/request/node/requestService.ts`, or deprecate the setting in favor of embedding credentials in the `http.proxy` URL. The setting description should also clarify the expected format (`Basic <base64>`).
