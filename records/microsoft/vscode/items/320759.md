# Issue #320759 — Agents Window: Agent dropdown only shows “Agent” despite multiple agents being configured

## Summary

This remains a valid Agents Window bug: later reports confirm that configured agents or local options can still disappear from the picker, while current source intends to include them. Route this oldest report to the Agents Window owners as the canonical investigation.

## Change summary

The Agents Window agent picker shows only the default Agent entry even though configured custom agents are visible in the customization UI.

## Best solution

Make custom-agent discovery and picker refresh reliable for Agents Window sessions, including late or asynchronous registry updates, while retaining target and visibility filtering. Consolidate matching reports around this older issue unless diagnostics establish distinct root causes.
