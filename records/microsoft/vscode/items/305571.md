# Issue #305571 — Sessions: Terminal command approvals set at the workspace settings level do not get respected

[https://github.com/microsoft/vscode/issues/305571](https://github.com/microsoft/vscode/issues/305571)

## Summary

Fixed on main: the Agents window's configuration service was not loading workspace settings at all. Commit 57163fd2daf added full workspace settings support to the Agents window, which resolves the reported inability to respect workspace-level terminal command approvals.

## Change summary

Terminal command approvals configured at the workspace settings level were ignored in the Sessions (Agents) window, requiring manual approval even though the same approvals worked in the main VS Code workbench.

## Best solution

Keep the shipped fix in commit 57163fd2daf (1.120.0); no further change needed. The Agents window now loads workspace settings from the .code-workspace configuration file, so workspace-scoped terminal approval rules are respected.
