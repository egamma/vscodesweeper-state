# Issue #145674 — Limit length of InputBox validation message?

[https://github.com/microsoft/vscode/issues/145674](https://github.com/microsoft/vscode/issues/145674)

## Summary

Long InputBox validation messages remain unbounded in the current source and can extend below the window. Keep this accepted backlog bug open; the owner should decide how overflow content remains accessible.

## Change summary

Prevent long, wrapped InputBox validation messages from extending off screen.

## Best solution

Keep the validation surface within the available viewport while preserving ordinary wrapping, severity styling, and access to the diagnostic. Decide whether excess content is scrollable or explicitly expandable before implementing the containment behavior.
