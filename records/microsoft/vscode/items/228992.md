- **Trace:**

  > ExtHostTerminal.create in src/vs/workbench/api/common/extHostTerminalService.ts forwards options.message as initialText. TerminalInstance writes it during xterm initialization through _writeInitialText, which calls raw.writeln for string messages. TerminalInstance._open attaches the renderer through XtermTerminal.attachToElement, where raw.open precedes asynchronous WebGL addon initialization; renderer loading later requests dimension refresh. Attachment also refreshes existing terminals, making redraw and initial layout useful diagnostic boundaries, but source inspection does not prove which layer causes the corruption.
