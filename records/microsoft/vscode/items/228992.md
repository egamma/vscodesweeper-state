## Change summary

Terminal message set via `window.createTerminal({ message })` randomly renders as garbled text on first display (~20% of the time).

## Best solution

Investigate the race between `_writeInitialText` and xterm's initial layout/resize in `terminalInstance.ts`. The commit 022385d9b36 ("Use processReady and timeout to prevent initial resize events") may have helped but doesn't reference this issue. A targeted fix would ensure the xterm renderer is ready before writing initialText, or force a reflow after the write completes.
