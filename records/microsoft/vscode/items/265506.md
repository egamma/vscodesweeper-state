# Issue #265506 — Show File Size Infomation for Non-Binary files

[https://github.com/microsoft/vscode/issues/265506](https://github.com/microsoft/vscode/issues/265506)

## Summary

Keep open: the request earned 22 upvotes and was explicitly promoted to the Backlog after the earlier extension-candidate feedback. Current main still limits the built-in file-size status entry to media previews, so the requested text-file behavior remains absent.

## Change summary

Show an optional file-size indicator in the status bar when editing non-binary files such as JSON.

## Best solution

Maintainers should decide whether this accepted request belongs in core or should be satisfied by an extension. If kept in core, preserve the proposed optional status-bar behavior and avoid adding an always-on element for users who do not need it.
