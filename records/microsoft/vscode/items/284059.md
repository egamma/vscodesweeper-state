## Summary

The stale-reference path is fixed on current main: replacing or deleting text containing an inline reference removes its model entry and decoration rather than leaving the decoration attached to later text.

## Change summary

Deleting an edited chat prompt after adding inline file references left ghost reference highlights on newly entered text.
