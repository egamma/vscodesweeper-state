# Issue #314326 — Unescaped char for pending command in session list

[https://github.com/microsoft/vscode/issues/314326](https://github.com/microsoft/vscode/issues/314326)

## Summary

The pending-approval presentation still has both reported failure modes on current main: command labels are rendered without normalizing visible escape sequences, and provider activity such as “Running…” takes precedence over the input-needed fallback. The Backlog milestone also records this as accepted work, so it should remain open.

## Change summary

Display pending terminal commands without escape artifacts and describe the session as waiting for approval rather than actively running.

## Best solution

Give pending approvals an explicitly blocked presentation: show a display-safe command in the approval row and use input-needed wording instead of stale running activity, while retaining the exact command in an appropriate detailed view if needed.
