# Issue #253704 — Git - All lines in files with 400 lines and more are shown as modified in gutter while they are not

[https://github.com/microsoft/vscode/issues/253704](https://github.com/microsoft/vscode/issues/253704)

## Summary

Keep open: current source still renders whole-file fallback diffs after a quick-diff timeout, and multiple reporters confirm the problem with ordinary code files. Three open PRs address complementary parts of the failure; they need review rather than a competing implementation.

## Change summary

Prevent clean files from showing every line as modified and keep gutter decorations synchronized with actual changes when diff computation is expensive.

## Best solution

Review the complementary proposals in https://github.com/microsoft/vscode/pull/303517, https://github.com/microsoft/vscode/pull/332872, and https://github.com/microsoft/vscode/pull/314348. The finished behavior must avoid false whole-file modifications while still showing genuine edits; suppressing timed-out results alone does not satisfy the reported synchronization problem.
