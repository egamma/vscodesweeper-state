# Issue #253704 — Git - All lines in files with 400 lines and more are shown as modified in gutter while they are not

[https://github.com/microsoft/vscode/issues/253704](https://github.com/microsoft/vscode/issues/253704)

## Summary

Still reproduces on main — the quick diff model does not handle diff-computation timeouts, so files that exceed the 1000ms budget show every line as modified. Two open PRs (#303517, #314348) attempt fixes but neither has merged. Keeping open with existing labels.

## Change summary

Git gutter decorations incorrectly mark all lines as modified in files where the diff algorithm times out, even though git status is clean.

## Best solution

Land a fix that either (a) handles `quitEarly`/timed-out results in `QuickDiffModel._diff()` so bogus full-file diffs are discarded, or (b) offers a faster diff algorithm option (PR https://github.com/microsoft/vscode/pull/314348). Reducing the frequency of `Date.now()` calls in the DP inner loop would also help on systems with slow clocksources. The two open PRs should be reviewed and one path chosen.
