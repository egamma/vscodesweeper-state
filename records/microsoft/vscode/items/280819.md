# Issue #280819 — No vertical scrollbar for longer terminal outputs in panel chat

[https://github.com/microsoft/vscode/issues/280819](https://github.com/microsoft/vscode/issues/280819)

## Summary

Still present on main: the vertical scrollbar for terminal output in chat is explicitly hidden (line 1368 of chatTerminalToolProgressPart.ts) due to a technical limitation with xterm.js. The issue is a known usability/accessibility gap tracked here as the canonical item, with #306410 already closed as its duplicate.

## Change summary

Terminal output in panel chat lacks a vertical scrollbar, making it hard to know the scroll extent and creating an accessibility gap.

## Best solution

As Tyriar noted, a proper fix likely requires xterm.js API to control the scrollable viewport size independently of rows/cols, so the vertical scrollbar doesn't get displaced during horizontal scrolling. In the interim, a custom VS Code scrollbar overlay (using the existing DomScrollableElement with `vertical: ScrollbarVisibility.Auto` on hover/focus, mirroring the horizontal scrollbar pattern) could be explored in `chatTerminalToolProgressPart.ts`, but would need to handle the horizontal-scroll displacement issue described in https://github.com/microsoft/vscode/issues/281004.
