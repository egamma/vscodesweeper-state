# Issue #280819 — No vertical scrollbar for longer terminal outputs in panel chat

[https://github.com/microsoft/vscode/issues/280819](https://github.com/microsoft/vscode/issues/280819)

## Summary

Keep open: current source still hides both available vertical scrollbar surfaces for long chat terminal output. The maintainer explicitly reopened this issue to address the usability/accessibility gap, and subsequent reports were consolidated here.

## Change summary

Long terminal output embedded in chat is scrollable but lacks a visible vertical scrollbar indicating position and remaining output.

## Best solution

Provide a usable vertical scrollbar at the output container's edge, including when output is horizontally scrolled. Preserve the existing output sizing, scroll-follow behavior, and uncluttered terminal actions.
