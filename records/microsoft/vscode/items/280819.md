# Issue #280819 — No vertical scrollbar for longer terminal outputs in panel chat

[https://github.com/microsoft/vscode/issues/280819](https://github.com/microsoft/vscode/issues/280819)

## Summary

The missing vertical scrollbar remains directly traceable on current main: chat terminal output explicitly hides it even when output exceeds the viewport. Keep this accepted usability/accessibility issue open; the related reports do not supply an older canonical or a landed fix.

## Change summary

Provide a visible vertical scroll indicator for long terminal output embedded in chat.

## Best solution

Long chat terminal output should expose its scroll position and boundaries within the output preview, without adding toolbar clutter or requiring users to open the full terminal. Preserve existing output sizing, horizontal scrolling, and streaming scroll-lock behavior.
