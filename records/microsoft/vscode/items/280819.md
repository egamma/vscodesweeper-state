# Issue #280819 — No vertical scrollbar for longer terminal outputs in panel chat

[https://github.com/microsoft/vscode/issues/280819](https://github.com/microsoft/vscode/issues/280819)

## Summary

The missing vertical scrollbar remains identifiable in current source: chat terminal output explicitly hides both the outer vertical scrollbar and xterm's own scrollbar. Keep this accepted accessibility bug open; the maintainer's reopening supersedes the initial by-design comment, and the newer related reports are not eligible canonical targets.

## Change summary

Provide a vertical scrollbar for overflowing terminal output embedded in panel chat so users can discover its extent and navigate it directly.

## Best solution

Give the existing chat output scroll container a usable vertical position indicator and draggable scrollbar when its content overflows, without exposing a misplaced internal xterm scrollbar or adding another toolbar action.
