# Issue #330757 — Agents Window: "Create PR" title bar button remains visible when switching to Automations

[https://github.com/microsoft/vscode/issues/330757](https://github.com/microsoft/vscode/issues/330757)

## Summary

Confirmed as a real, source-traceable bug in the Agents Window title bar: the 'Create PR' anchor action's menu `when` clause is missing the `CustomViewVisibleContext` guard that sibling title-bar actions already use to hide when a custom view (like Automations) covers the sessions grid.

## Change summary

The title bar 'Create PR' action stays visible after switching to the Automations custom view, even though it no longer applies.

## Best solution

Add `CustomViewVisibleContext.negate()` to the `when` clause of `ChangesHeaderActionsAction`'s `Menus.TitleBarSessionMenu` menu entry in src/vs/sessions/contrib/changes/browser/changesViewActions.ts, mirroring the same guard already applied to the sibling 'Toggle Side Panel' title-bar entry in src/vs/sessions/contrib/layout/browser/baseSessionLayoutController.ts.
