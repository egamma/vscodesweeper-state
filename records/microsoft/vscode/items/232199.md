# Issue #232199 — Multi-diff editor is not screen reader accessible

[https://github.com/microsoft/vscode/issues/232199](https://github.com/microsoft/vscode/issues/232199)

## Summary

Keep open for an accessibility-owner assessment of original-line navigation. Current source contains relevant accessibility commands, but their existence does not establish that this team-authored request is completed, and neither related issue qualifies as a duplicate canonical.

## Change summary

Make original as well as modified lines navigable and readable with a screen reader in the multi-diff editor.

## Best solution

Provide a discoverable keyboard path to read both sides of each multi-diff change, reusing the embedded diff editor's accessibility facilities where they satisfy the workflow. First establish whether the remaining gap is navigation, discoverability, or screen-reader behavior rather than adding a separate viewer unnecessarily.
