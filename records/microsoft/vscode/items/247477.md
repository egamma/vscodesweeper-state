# Issue #247477 — incorrect append double slash text while onEnter called

[https://github.com/microsoft/vscode/issues/247477](https://github.com/microsoft/vscode/issues/247477)

## Summary

The defect remains on main: bracket stripping transforms the regular expression into text beginning with `//`, which incorrectly triggers TypeScript's comment-continuation rule. The existing broader proposal does not make this confirmed bug unnecessary.

## Change summary

Pressing Enter after a TypeScript regular expression containing bracket characters incorrectly inserts `// ` on the next line.

## Best solution

Determine comment continuation from semantic token context rather than regex-matching bracket-stripped text, likely through the planned tree-sitter auto-indentation path. Preserve compatibility with extension-provided onEnter rules.
