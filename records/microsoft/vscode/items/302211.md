# Issue #302211 — Chat agent debug log view: Response contains tools call as well

[https://github.com/microsoft/vscode/issues/302211](https://github.com/microsoft/vscode/issues/302211)

## Summary

Keep open: the current debug-log pipeline still includes model-generated tool calls in Agent Response content, alongside separate tool execution entries. This team-authored Backlog item raises an unresolved presentation question; no qualifying fix or canonical duplicate was established.

## Change summary

Clarify or remove tool-call content repeated in Agent Response details when tool calls already have separate debug-log entries.

## Best solution

Make Agent Response details clearly distinguish assistant text from tool invocation data without losing diagnostic information. Decide whether invocation data belongs only in separate entries or remains explicitly identified as part of the model response.
