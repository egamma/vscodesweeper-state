# Issue #244281 — Alt click across notebook cells doesn't work

[https://github.com/microsoft/vscode/issues/244281](https://github.com/microsoft/vscode/issues/244281)

## Summary

Keep open: arbitrary Alt-click cursors across notebook cells remain distinct from the existing find-match multicursor commands. A maintainer explicitly accepted this limitation as backlog work; neither a covering implementation nor a verified canonical duplicate was found.

## Change summary

Allow Alt-click to add cursors across notebook cells without discarding cursors in previously selected cells.

## Best solution

Extend notebook multicursor support to preserve and edit arbitrary mouse-added cursor positions across cells, while retaining ordinary click-to-exit behavior. Keep this accepted request in the notebook-cell-editor backlog until there is capacity or stronger demand.
