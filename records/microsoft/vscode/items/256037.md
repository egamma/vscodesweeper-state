# Issue #256037 — Auto indent is wrong when adding brackets sometimes

Keep open: a maintainer confirmed the double-deindent defect, and an explicitly linked fixing PR remains open. The current source still contains the search-bound calculation that the PR proposes to change.

## Change summary

Typing a closing bracket can incorrectly reduce indentation by matching the wrong enclosing bracket.

Review and resolve https://github.com/microsoft/vscode/pull/307271, checking that its bracket-search behavior addresses the reported double deindent without changing correct electric-character indentation. Keep this issue open until a verified fix lands.
