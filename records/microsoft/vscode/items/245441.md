# Issue #245441 — Add a way to customise the "Open Recent" labels, instead of path, like using a workspace's specified "window.title"

[https://github.com/microsoft/vscode/issues/245441](https://github.com/microsoft/vscode/issues/245441)

## Summary

A real capability gap remains on main, and the request earned 27 upvotes and promotion to the Backlog. It is already routed to the appropriate workbench-history area.

## Change summary

Allow recent workspace entries to display a stable, user-defined friendly name instead of their filesystem-derived label.

## Best solution

Populate the existing `IRecent.label` field from stable workspace metadata when a workspace enters history, using either an appropriate workspace name setting or a dedicated friendly-name setting rather than evaluating dynamic window-title placeholders.
