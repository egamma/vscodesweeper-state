# Issue #331138 — Slash commands never submit when the resolved command has no readable content

[https://github.com/microsoft/vscode/issues/331138](https://github.com/microsoft/vscode/issues/331138)

## Summary

Real, well-diagnosed bug with an open fixing PR (#331145) from the same reporter; per policy, an open linked PR means keep this open for review/merge rather than proposing a close or auto-fix.

## Change summary

Accepting a slash-command completion whose resolved command has unreadable content (e.g. a discovery-only agent-builtin skill) throws inside resolvePromptSlashCommand, breaking the input-decoration/parsedInput path so the chat message silently never submits.

## Best solution

Land https://github.com/microsoft/vscode/pull/331145, which makes `parsedPromptFile` optional in `resolvePromptSlashCommand` (src/vs/workbench/contrib/chat/common/customizationHarnessService.ts:634-646) so an unreadable command URI resolves without a body instead of rejecting and blocking submission.
