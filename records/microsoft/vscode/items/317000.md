# Issue #317000 — [Bug] Incomplete Sanitization in shared.ts: escapeBrackets() Omits Parentheses, Enabling Markdown Link Injection

[https://github.com/microsoft/vscode/issues/317000](https://github.com/microsoft/vscode/issues/317000)

## Summary

The `escapeBrackets()` function intentionally escapes only `[` and `]` because it operates on placeholder text inside the bracket portion `[text]` of a Markdown link, where parentheses are not syntactically significant. The URL/path portion is handled separately by `escapeMarkdownLinkPath()`, which already accounts for mismatched parentheses by wrapping in angle brackets.

## Change summary

Reporter believes `escapeBrackets()` should also escape parentheses to prevent Markdown link injection via filenames containing `(` or `)`.

## Best solution

No change needed. The existing design correctly separates concerns: `escapeBrackets()` escapes bracket characters for the link-text portion (`[text]`), and `escapeMarkdownLinkPath()` handles parentheses in the URL portion (`(url)`) via `needsBracketLink()` which detects mismatched parens and wraps in angle brackets. The reported injection scenario cannot occur because the path goes through `escapeMarkdownLinkPath`, not `escapeBrackets`.
