# Issue #329644 — Tab close icons are too large, need option to bring them in line with the text

[https://github.com/microsoft/vscode/issues/329644](https://github.com/microsoft/vscode/issues/329644)

## Summary

This is a real regression in the in-progress experimental Modern UI tab redesign (rolled out via the `workbench.experimental.modernUI` A/B experiment), not a stale request — a maintainer already closed a near-duplicate bug report (#329836, "tab close button is larger since 1.132.0") as a duplicate of this issue, confirming it's on the team's radar and being actively iterated on.

## Change summary

The tab close (×) icon renders disproportionately large relative to the tab label text, and there is no setting to shrink it back down.

## Best solution

This belongs with the ongoing Modern UI tab work in src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css (`.tab-actions`/`.action-label.codicon` sizing, currently a fixed 24px hit box around a 16px codicon) — the team member actively iterating on this area (commits 1f32dfe6453, d79ba7fe308, 0ecb507e9b0, all within the last week) should tune the icon-to-pill proportions rather than adding a new user-facing size setting.
