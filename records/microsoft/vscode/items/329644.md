## Summary

Legitimate design/feature request: the tab close-icon is rendered noticeably larger than the file-name text after the recent modern-UI redesign, and no setting currently lets users scale it down. Already correctly labeled (ux, workbench-tabs, icons-product); this stays open for a maintainer/design decision rather than closing.

## Change summary

Request to shrink the tab close ('X') icon relative to the tab label text, or add a setting to control its size, after it grew noticeably larger in a recent UI update.
