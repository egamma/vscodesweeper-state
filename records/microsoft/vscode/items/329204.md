# Issue #329204 — Chat: include selected subagent kind in runSubagent telemetry

[https://github.com/microsoft/vscode/issues/329204](https://github.com/microsoft/vscode/issues/329204)

## Summary

Keep open: the production tool-invocation schema still lacks a resolved subagent-kind field. Existing request-mode telemetry and diagnostic agent names provide partial coverage, but do not establish the requested stable, privacy-safe category for every runSubagent execution; this is also team-authored accepted work.

## Change summary

Record a stable, privacy-reviewed resolved subagent category for each runSubagent execution, preserving correlation with existing production telemetry.

## Best solution

Establish a production telemetry contract that distinguishes shipped subagent kinds while bucketing arbitrary custom agents and unavailable resolution as custom and unknown. Agree on the authoritative event and correlation contract across the workbench and Copilot telemetry paths before implementation.
