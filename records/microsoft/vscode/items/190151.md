# Issue #190151 — useInlineViewWhenSpaceIsLimited - only do this when there is horizontal scroll bar

[https://github.com/microsoft/vscode/issues/190151](https://github.com/microsoft/vscode/issues/190151)

## Summary

Keep open: automatic inline switching still depends on editor width, not whether the side-by-side content actually overflows. This team-authored Backlog request remains distinct from the related layout improvements.

## Change summary

Switch a narrow diff editor to inline mode only when side-by-side content would require horizontal scrolling, without toggling while typing.

## Best solution

Make automatic diff layout account for actual side-by-side overflow while keeping the layout stable during editing. Establish when rendered content measurements can safely influence layout without creating feedback between measuring and switching modes.
