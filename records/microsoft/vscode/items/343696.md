## Summary

Keep open: current main still discards include-custom-instructions when converting custom agents into SDK configuration. The missing projection is confirmed from source, but completing the fix requires establishing SDK/runtime support for the opt-in.

## Change summary

Custom Copilot subagents lose the frontmatter opt-in that should load repository instructions into their context.

## Best solution
