# Issue #343696 — Copilot harness drops the `include-custom-instructions` custom agent frontmatter, so custom subagents never get AGENTS.md

[https://github.com/microsoft/vscode/issues/343696](https://github.com/microsoft/vscode/issues/343696)

## Summary

The instruction opt-in is still discarded by the current Copilot custom-agent converter. Independent macOS confirmation corroborates the Windows report; the downstream skill workaround does not resolve the core gap.

## Change summary

Honor include-custom-instructions so opted-in Copilot custom subagents receive repository instructions.

## Best solution

Preserve the explicit instruction-inheritance opt-in through the Copilot agent conversion and SDK/runtime boundary, verifying the actual child context. Keep default inheritance behavior unchanged and treat other unsupported frontmatter fields separately.
