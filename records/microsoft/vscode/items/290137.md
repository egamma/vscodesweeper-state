# Issue #290137 — The keybinding "Github Copilot: Toggle (Enable/Disable)" should also hide/show inline suggestion on trigger.

[https://github.com/microsoft/vscode/issues/290137](https://github.com/microsoft/vscode/issues/290137)

## Summary

Keep open: the Copilot toggle changes completion enablement but does not explicitly dismiss or trigger the current inline suggestion. Existing command composition offers a workaround, not the requested integrated toggle behavior, and no verified duplicate owns this specific interaction.

## Change summary

Make the Copilot enable/disable toggle immediately hide inline suggestions when disabling and show an available suggestion when enabling.

## Best solution

Consider making the existing Copilot toggle synchronize enablement with the active editor's suggestion visibility. Define whether enabling should request a fresh suggestion, while preserving unrelated inline-completion providers and existing configuration scopes.

- **Proposed comment:**

  > Thanks for the request. The Copilot toggle currently changes whether completions are enabled; explicitly hiding or requesting a suggestion is a separate editor action. You can sequence commands in one keybinding using `runCommands` with an `args.commands` array, pairing `github.copilot.chat.completions.disable` with `editor.action.inlineSuggest.hide`, or `github.copilot.chat.completions.enable` with `editor.action.inlineSuggest.trigger`. That is a workaround rather than the integrated toggle behavior requested here.
