# Issue #322545 — Using env variable for BYOK configuration does not work

[https://github.com/microsoft/vscode/issues/322545](https://github.com/microsoft/vscode/issues/322545)

## Summary

Valid feature request: `${env:VAR}` substitution is not implemented in BYOK model configuration. The `_resolveConfiguration` method in `languageModels.ts` does not route values through any variable resolution service. This is in the backlog candidates process (3/20 upvotes, ~34 of 60 days elapsed) and should remain open for community voting.

## Change summary

Support environment variable substitution (`${env:VAR}`) in BYOK language model configuration, particularly in request headers and API key fields.

## Best solution

Add `${env:VAR}` resolution support in `LanguageModelsService._resolveConfiguration` (in `src/vs/workbench/contrib/chat/common/languageModels.ts`) by routing non-secret string values through `IConfigurationResolverService` or a similar variable substitution mechanism. This enables script-driven BYOK provisioning without requiring manual secret storage entry. Related issues https://github.com/microsoft/vscode/issues/326434 and https://github.com/microsoft/vscode/issues/325237 cover adjacent BYOK improvements but are not duplicates — this is a distinct, scoped request.
