# Issue #79631 — [html] don't validate custom event handlers as JavaScript

[https://github.com/microsoft/vscode/issues/79631](https://github.com/microsoft/vscode/issues/79631)

## Summary

The defect remains directly visible on current main: every attribute matching `on\w+` is treated as embedded JavaScript, so the reported custom attribute still receives an incorrect JavaScript diagnostic. The existing `html` area label is appropriate, and no canonical issue or fixing commit was found.

## Change summary

Custom HTML attributes whose names begin with `on` are incorrectly parsed and validated as JavaScript event handlers.

## Best solution

Restrict embedded JavaScript validation to recognized HTML event-handler attributes while preserving validation, completion, and hover behavior for standard handlers such as `onclick` and `onkeydown`.
