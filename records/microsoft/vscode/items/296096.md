# Issue #296096 — UI Crash/State Deletion in Plan Mode

[https://github.com/microsoft/vscode/issues/296096](https://github.com/microsoft/vscode/issues/296096)

## Summary

The Delete keybinding for `agentSession.archive` fires even when the user is typing in an input field inside the sessions view, because its `when` clause only checks `agentSessionsViewerFocused && !agentSessionIsArchived` without excluding `InputFocusedContext`. This causes the active chat session to be archived (disappearing from view) when the user presses Delete while editing text in Plan Mode's custom answer field. The bug is still present on current main.

## Change summary

Pressing the Delete key while typing in a custom text field during Plan Mode archives the entire chat session instead of deleting the selected text, causing the chat interface to vanish.

## Best solution

Add `InputFocusedContext.negate()` (or the appropriate text-input-focused context key negation) to the `when` clause of the `agentSession.archive` keybinding in `src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsActions.ts` (line ~484), so the Delete key only triggers the archive action when no text input has focus. The same guard should be considered for the Shift+Delete `agentSession.unarchive` binding.
