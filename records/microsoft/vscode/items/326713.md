# Issue #326713 — Allow custom device presets in integrated browser's "Emulate Device..." picker

[https://github.com/microsoft/vscode/issues/326713](https://github.com/microsoft/vscode/issues/326713)

## Summary

Valid feature request — the integrated browser's device preset list is hardcoded to 4 mobile/tablet entries with no extension point or setting for custom entries. The capability does not exist on current main.

## Change summary

Allow users to define custom named device presets (with width, height, scale factor, mobile flag) for the integrated browser's Emulate Device picker.

## Best solution

Add a `workbench.browser.customDevicePresets` array setting in `browserEditorEmulationFeatures.ts` and merge user-defined presets with the built-in `DEFAULT_BROWSER_DEVICE_PRESETS` in `PickBrowserDevicePresetAction.run()`. The `IBrowserDevicePreset` interface already fits the shape the reporter suggests.
