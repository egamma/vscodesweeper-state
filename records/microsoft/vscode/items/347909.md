# Issue #347909 — Claude agent host (1.146): a turn's response is silently dropped when the session is rebuilt twice before the turn, and the chat hangs on "This is taking a little longer than usual"

[https://github.com/microsoft/vscode/issues/347909](https://github.com/microsoft/vscode/issues/347909)

## Summary

Keep open: current source permits overlapping Claude query rebuilds that can strand a consumed prompt and discard its response. The macOS confirmation supports the reported regression; no verified fix or canonical issue absorbs the full report.

## Change summary

Prevent overlapping Claude session rebuilds from silently dropping responses and leaving turns indefinitely pending.

## Best solution

Maintain one authoritative query lifecycle per Claude chat, with every accepted prompt reaching a visible terminal outcome. Diagnose the separately reported browser-tool completion and transcript-parenting failures independently rather than assuming the rebuild fix resolves them.
