# Issue #347909 — Claude agent host (1.146): a turn's response is silently dropped when the session is rebuilt twice before the turn, and the chat hangs on "This is taking a little longer than usual"

[https://github.com/microsoft/vscode/issues/347909](https://github.com/microsoft/vscode/issues/347909)

## Summary

Keep open: independent reports confirm lost Claude responses and persistent working state across platforms, including Insiders. Current source still permits overlapping query rebuilds, and this issue already serves as the canonical for another report.

## Change summary

Prevent overlapping Claude SDK rebuilds from dropping responses and leaving an unsettled turn at the prompt queue head.

## Best solution

Make Claude query replacement preserve exclusive ownership of prompt consumption and turn settlement, so rebuilds cannot silently strand requests. Keep remote-host restart functionality separate from fixing this lifecycle defect.
