# Issue #347909 — Claude agent host (1.146): a turn's response is silently dropped when the session is rebuilt twice before the turn, and the chat hangs on "This is taking a little longer than usual"

[https://github.com/microsoft/vscode/issues/347909](https://github.com/microsoft/vscode/issues/347909)

## Summary

Keep open: independent Linux and macOS reports confirm missing Claude responses and stalled turns after rebuilds. Current source retains overlapping rebuild entry points, but the precise failing interleaving and the separate client-tool hang still need deterministic diagnosis.

## Change summary

Prevent Claude session rebuilds from silently orphaning responses or leaving consumed prompts pending indefinitely.

## Best solution

Make Claude query replacement preserve ownership of each admitted prompt and ensure every affected turn completes or visibly fails. Establish the double-rebuild regression independently of unnecessary customization rebuilds and the separately reported client-tool completion loss.
