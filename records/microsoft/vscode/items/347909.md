# Issue #347909 — Claude agent host (1.146): a turn's response is silently dropped when the session is rebuilt twice before the turn, and the chat hangs on "This is taking a little longer than usual"

[https://github.com/microsoft/vscode/issues/347909](https://github.com/microsoft/vscode/issues/347909)

## Summary

Keep open: the concurrent-rebind response-loss defect remains in current source, with breakpoint-confirmed reproduction on 1.148.0 and independent cross-platform confirmations. This issue already serves as the canonical report; related background-subagent work does not resolve its rebuild race.

## Change summary

Concurrent Claude query rebuilds can discard a completed response and leave its turn permanently pending.

## Best solution

Ensure Claude query replacement cannot supersede a runtime that has consumed the pending prompt without preserving or explicitly terminating that turn, while retaining stale-query isolation and cancellation behavior. Review the open background-subagent PR separately; reducing unnecessary customization rebuilds is complementary, not sufficient recovery.
