# Issue #347909 — Claude agent host (1.146): a turn's response is silently dropped when the session is rebuilt twice before the turn, and the chat hangs on "This is taking a little longer than usual"

[https://github.com/microsoft/vscode/issues/347909](https://github.com/microsoft/vscode/issues/347909)

## Summary

Keep open: current source still permits overlapping Claude query rebuilds that can discard a consumed prompt's response and leave its turn pending indefinitely. Independent reports confirm the symptom across Linux, macOS, and Windows.

## Change summary

Prevent overlapping Claude agent-host rebuilds from silently losing responses and permanently wedging the active turn.

## Best solution

Ensure each Claude turn retains valid query ownership through rebuild and recovery, with every consumed prompt completing or explicitly failing. Preserve stale-query isolation and cancellation semantics; investigate the separate parallel-tool hang independently.
