# Issue #94705 — Search does not respect `workbench.editor.revealIfOpen`

[https://github.com/microsoft/vscode/issues/94705](https://github.com/microsoft/vscode/issues/94705)

## Summary

Search still explicitly reveals files visible in another editor group, independently of workbench.editor.revealIfOpen. Keep this accepted request open: maintainers support making the behavior configurable, but the default and setting scope remain unsettled.

## Change summary

Allow search-result navigation to stay in the active editor group instead of redirecting to another group displaying the same file.

## Best solution

Provide a supported way to keep search-result clicks in the active editor group while preserving the existing default unless maintainers decide otherwise. Resolve the configuration scope identified in the discussion; the related Quick Open PR does not implement Search behavior.
