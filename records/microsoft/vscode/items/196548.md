# Issue #196548 — Test label not shown in Testing panel

[https://github.com/microsoft/vscode/issues/196548](https://github.com/microsoft/vscode/issues/196548)

## Summary

Keep open: selecting a test configuration and identifying the configuration used by the displayed run are different needs, and the existing selector does not establish the latter. No verified fix or older canonical was found; this team-authored request remains valid for Testing UX review.

## Change summary

Show the configuration label associated with the displayed test run, rather than exposing it only in the configuration selector.

## Best solution

Make the displayed run's originating configuration identifiable in the Testing UI, independently of whichever configuration is currently selected. Establish whether the extension test runner already supplies that identity before deciding whether the remaining work belongs in its integration or the core results presentation.
