# Issue #346319 — "Mark as done" is slow

[https://github.com/microsoft/vscode/issues/346319](https://github.com/microsoft/vscode/issues/346319)

## Summary

Keep open: the banner waits for onboarding before archiving, then revalidates against the displayed session. Navigating away during that wait can produce the exact reported error even though the original session remains eligible.

## Change summary

The merged-PR Mark as Done action responds slowly and can fail when the user switches sessions before it completes.

## Best solution

Make an accepted Mark as Done action independent of subsequent navigation while retaining checks for actual changes to the original session's eligibility. Review whether optional onboarding should delay the operation at all.
