# Issue #214277 — Disable notebook chat hint permanently when the user has triggered ctrl+i

[https://github.com/microsoft/vscode/issues/214277](https://github.com/microsoft/vscode/issues/214277)

## Summary

Still valid: the notebook chat hint does not permanently disappear after the user triggers inline chat (Ctrl+I). The equivalent fix was shipped for the terminal (#213820) but the notebook cell editor hint lacks the same permanent-dismiss-on-first-use behavior.

## Change summary

Permanently disable the notebook empty-cell chat hint once the user has triggered inline chat (Ctrl+I), so it never reappears after the session ends.

## Best solution

Add logic in `EmptyCellEditorHintContribution` (or its base class) to persist a flag (e.g. via storage or a configuration write) when the user first triggers inline chat in a notebook cell, and check that flag in `shouldRenderHint()` so the hint never comes back. The terminal fix (commits c1735c9422b / 47262beab72) is the direct model to follow.
