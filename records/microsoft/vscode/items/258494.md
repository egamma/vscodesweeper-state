# Issue #258494 — File changes summary - opening the same file from multiple turns

[https://github.com/microsoft/vscode/issues/258494](https://github.com/microsoft/vscode/issues/258494)

## Summary

The distinction problem remains on current main: change editors opened for different chat turns still receive the same generic title. This team-authored polish request should stay open while the user-visible turn-labeling scheme is decided.

## Change summary

Differentiate file-change editor tabs opened for the same file from different chat turns.

## Best solution

Give each chat-produced change editor concise, stable turn context in its tab title so editors from different turns are distinguishable without exposing opaque request IDs. Keep ordinary diff-editor naming and non-chat editor tabs unchanged.
