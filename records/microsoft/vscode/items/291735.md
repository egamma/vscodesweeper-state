# Issue #291735 — Delegate button shows background/cloud options when not in a git repository

[https://github.com/microsoft/vscode/issues/291735](https://github.com/microsoft/vscode/issues/291735)

## Summary

The issue remains valid on current main: the delegation UI registers cloud and background options based on agent availability and entitlement, without filtering them by whether the workspace has the Git/GitHub prerequisites needed to run them. It should remain open and be routed to the chat area.

## Change summary

Hide, disable, or clearly explain unavailable background and cloud delegation options when the workspace is not backed by an appropriate Git repository.

## Best solution

Keep delegation choices visible only when they can run in the current workspace, or render unavailable choices with an accessible explanation of the missing Git or GitHub prerequisite; the chat delegation UI should update when repository state changes.
