# Issue #291735 — Delegate button shows background/cloud options when not in a git repository

[https://github.com/microsoft/vscode/issues/291735](https://github.com/microsoft/vscode/issues/291735)

## Summary

Partially addressed on main: Cloud delegation is now grayed out with a 'Requires a Git repository' message in non-git workspaces (commits 6edd5669785 and 3e23d22f8b8), but Background delegation still shows and is enabled without a git check — the reporter's concern about Background remains valid.

## Change summary

The delegate button shows Background and Cloud agent options even when the workspace has no git repository, despite both requiring git.

## Best solution

Add a git-repository guard for the Background option in the delegation picker and Continue In action (matching the existing Cloud guard), or hide it entirely in non-git workspaces. The fix belongs in `src/vs/workbench/contrib/chat/browser/widget/input/delegationSessionPickerActionItem.ts` and `src/vs/workbench/contrib/chat/browser/actions/chatContinueInAction.ts`.
