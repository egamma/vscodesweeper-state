# Issue #315315 — copilot chat session errors

[https://github.com/microsoft/vscode/issues/315315](https://github.com/microsoft/vscode/issues/315315)

## Summary

The exact error reported — `Invalid string length` when persisting very large chat sessions — was fixed on main in a series of commits (eb308be, 7cc4a4c, e266aa4) that add a truncation safety net for V8's max string length during session serialization. Shipped since 1.123.0.

## Change summary

Very large Copilot Chat sessions (~51 MB) fail to persist with `RangeError: Invalid string length`, causing chat history to appear lost after restart.

## Best solution

Keep the shipped fix. The `stringifyEntryWithFallback` mechanism in `objectMutationLog.ts` now catches the V8 `RangeError` and retries with a truncating replacer, preserving the session at the cost of trimming oversized individual strings. No further change needed.
