# Issue #335316 — Agents window: Show confirmation after Commit and Sync actions complete

[https://github.com/microsoft/vscode/issues/335316](https://github.com/microsoft/vscode/issues/335316)

## Summary

Reasonable, freshly filed feature request for the Agents window: after Commit/Sync completes the button just disappears with no explicit success/failure confirmation or resulting-state indicator, and I don't see any such confirmation UI in the current changeset button-bar code.

## Change summary
