# Issue #329512 — Agent Host Codex file-read completions intermittently omit result text

[https://github.com/microsoft/vscode/issues/329512](https://github.com/microsoft/vscode/issues/329512)

## Summary

Fresh team-authored tracking issue for a real, only partially-mitigated Codex agent-host defect; a companion PR skipped the flaky E2E assertions and documented the gap in KNOWN_ISSUES.md, but the root cause (empty result text on successful file-read tool completions) is not yet fixed, so this must stay open regardless of author association.

## Change summary

Codex Agent Host file-read tool completions intermittently report success with an empty result `text`, even though the underlying turn response contains the file contents, breaking the `reads a file from a nested directory` / `reads a value from JSON` (and related `counts lines in a file`) E2E oracle checks.

## Best solution
