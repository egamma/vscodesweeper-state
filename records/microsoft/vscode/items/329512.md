# Issue #329512 — Agent Host Codex file-read completions intermittently omit result text

[https://github.com/microsoft/vscode/issues/329512](https://github.com/microsoft/vscode/issues/329512)

## Summary

This remains an active Codex Agent Host defect on current main: a later CI failure disproved the partial fallback, and the affected E2E assertions are still explicitly gated. The team-authored issue should remain open until the provider event-ordering gap is diagnosed and the gate can be removed.

## Change summary

Successful Codex shell-backed file reads intermittently publish an AHP tool completion without the command output text.

## Best solution

Make Codex command completion mapping retain the authoritative streamed or aggregated output across all observed event orderings, then remove `shellToolResultTextUnreliable` and re-enable the nine protocol-level E2E assertions.
