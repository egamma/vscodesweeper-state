# Issue #111616 — [theme icons] Include color class in ThemeIcon.asClassName()

[https://github.com/microsoft/vscode/issues/111616](https://github.com/microsoft/vscode/issues/111616)

## Summary

Still valid: ThemeIcon.asClassNameArray() in src/vs/base/common/themables.ts returns only codicon/id/modifier classes — no color class from icon.color is included. The parent issue #109460 also remains open. Team-authored and in Backlog; keeping open.

## Change summary

Include a CSS class for ThemeIcon.color in the result of ThemeIcon.asClassName() so consumers can support icon colors via class names alone.

## Best solution

Extend `asClassNameArray` in `src/vs/base/common/themables.ts` to append a color class (e.g. derived from `icon.color`) when present, and define corresponding CSS rules so the class actually applies the color. The parent issue https://github.com/microsoft/vscode/issues/109460 tracks the broader goal of supporting theme icon colour everywhere.
