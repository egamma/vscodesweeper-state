# Issue #133041 — MacOS CLI prof-startup results in hanging program

[https://github.com/microsoft/vscode/issues/133041](https://github.com/microsoft/vscode/issues/133041)

## Summary

The hang-on-restart aspect of --prof-startup on macOS remains unaddressed on main. The recent fix (72cfebb6ffa) resolved the 'FAILED to start profiling' errors but did not address the restart flow hanging. The processCallbacks await pattern combined with macOS's `open` spawning likely leaves the CLI process stuck when the user triggers a restart from the profiling dialog.

## Change summary

Running `code --prof-startup` on macOS and pressing 'Restart' in the profiling dialog causes VS Code to hang instead of restarting.

## Best solution

Investigate the interaction between the profiling `processCallbacks` (which await `whenDeleted(filenamePrefix)`) and the macOS `open`-based spawn path — when VS Code restarts, the spawned child process exits but the marker file may never be deleted, leaving the CLI process hung. The fix likely needs to handle the child-exit case gracefully in the profiling callback or ensure the marker file is cleaned up on restart.
