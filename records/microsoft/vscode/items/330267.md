# Issue #330267 — Agents: Highlighted file in the changes view does not match the file I'm looking at

[https://github.com/microsoft/vscode/issues/330267](https://github.com/microsoft/vscode/issues/330267)

## Summary

Keep open: the Changes list does not follow the file becoming visible through scrolling in the stacked diff editor. This is team-authored UX feedback, and no verified fix or older duplicate establishes that the remaining work is covered.

## Change summary

Keep the highlighted file in the Agents Changes list aligned with the file being reviewed in the stacked diff editor.

## Best solution

Provide a reliable current-file indicator in the Agents Changes list without moving keyboard focus or reopening editors. First settle whether that indicator follows the visible diff or the keyboard-focused diff when those differ.
