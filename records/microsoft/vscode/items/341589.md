# Issue #341589 — Harness Switching messes with Agent Selection

[https://github.com/microsoft/vscode/issues/341589](https://github.com/microsoft/vscode/issues/341589)

## Summary

The discussion identifies the remaining problem as Local being replaced by Copilot when changing chats, making the agent inventory appear to disappear. The older, open harness-persistence request explicitly covers this same observable behavior.

## Change summary

Preserve the user's selected harness across new chats so switching sessions does not unexpectedly change the available agents.

## Best solution

Consolidate harness-selection persistence in https://github.com/microsoft/vscode/issues/337676, retaining this report's Windows reproduction and custom-agent visibility consequence.
