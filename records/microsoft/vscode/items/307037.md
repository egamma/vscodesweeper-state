# Issue #307037 — Copilot: Duplicate file context sent to LLM when file is explicitly attached and also the active editor

[https://github.com/microsoft/vscode/issues/307037](https://github.com/microsoft/vscode/issues/307037)

## Summary

The duplicate request context remains source-reproducible on current main: explicit and implicit entries for the same URI or range are merged using incompatible IDs, so both survive. The issue should remain open for a bounded chat-input fix and regression test.

## Change summary

Avoid sending duplicate file or selection content when the same resource is present as both explicit and implicit Copilot Chat context.

## Best solution

Ensure request assembly treats explicit and implicit file context with the same URI and range as one attachment while preserving distinct ranges and unrelated implicit context.
