# Issue #247630 — concatenated output streams are not displayed in output preview

[https://github.com/microsoft/vscode/issues/247630](https://github.com/microsoft/vscode/issues/247630)

## Summary

Still present on main: the notebook output preview editor renders only the single resolved output, without concatenating adjacent stream outputs. Team-authored issue, no fix commit found.

## Change summary

Opening a cell's output in the notebook output preview only shows the first stream output when the cell produced multiple adjacent stream outputs (e.g. stdout + stderr).

## Best solution

Modify `NotebookOutputEditor.setInput()` in `src/vs/workbench/contrib/notebook/browser/outputEditor/notebookOutputEditor.ts` to detect and concatenate adjacent stream outputs when resolving the output to render, mirroring the concatenation logic already used in the inline cell output renderer.
