# Issue #334424 — BYOK Custom Endpoint: allow explicit Responses API tool search capability in chatLanguageModels.json

[https://github.com/microsoft/vscode/issues/334424](https://github.com/microsoft/vscode/issues/334424)

## Summary

The explicit custom-endpoint capability is still missing from current source; family aliasing does not provide the requested independent true/false override. Keep this feature request open: the related agent-host issue concerns a different execution path and does not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Allow custom Responses API models to explicitly enable or disable client-executed tool search while preserving heuristic behavior when the capability is omitted.

## Best solution

Provide an optional per-model capability in the custom-endpoint configuration that independently controls tool-search eligibility without changing model-family routing. Preserve existing tool availability, conversation-location, and subagent restrictions rather than treating the capability as unconditional activation.
