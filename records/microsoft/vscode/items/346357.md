# Issue #346357 — File path with apostrophe + parentheses gets double-quoted when running via Run button / integrated terminal

[https://github.com/microsoft/vscode/issues/346357](https://github.com/microsoft/vscode/issues/346357)

## Summary

The named Run command belongs to the VS Code-owned Python extension, so propose transferring this report to microsoft/vscode-python rather than closing it. Another reporter confirms literal quotes reaching Python even without apostrophes, suggesting the affected paths are broader than the title.

## Change summary

Running a Python file from the editor sends literal surrounding quotes as part of its filename and fails to open the script.

## Best solution

Preserve the report through a transfer to microsoft/vscode-python and diagnose command construction through its terminal execution pipeline. Python should receive the actual filename without literal wrapping quotes, including paths containing spaces, apostrophes, and parentheses.

This inspected path does not substantiate a core quoting defect.
