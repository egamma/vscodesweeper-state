# Issue #349497 — Browser Use in WSL session cannot reuse authenticated Windows Chrome session

[https://github.com/microsoft/vscode/issues/349497](https://github.com/microsoft/vscode/issues/349497)

## Summary

Keep open as a WSL-to-Windows Browser Use feature gap. Current source deliberately restricts external-browser integration to the local desktop Agent Host; enabling the remote setting does not provide the requested bridge.

## Change summary

Allow WSL-hosted Copilot sessions to use authenticated Windows Chrome pages, or clearly explain the unsupported setup before users attempt it.

## Best solution

Have the browser-integration owner decide whether to support an explicit WSL-to-Windows browser bridge. Until then, make setup clearly distinguish local external-browser integration from remote integrated-browser tools, without implying that the latter reuse Chrome authentication.
