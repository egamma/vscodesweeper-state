# Issue #184290 — Inconsistency in "Replace" between text files and notebooks

[https://github.com/microsoft/vscode/issues/184290](https://github.com/microsoft/vscode/issues/184290)

## Summary

Still valid on main: the notebook find widget lacks keybinding-registered replace actions (replaceOne/replaceAll) and has focus/tab-order inconsistencies compared to the editor find widget. The issue is properly labeled and milestoned (On Deck) — it should stay open.

## Change summary

Align the notebook find/replace widget's keyboard behavior (focus target on open, Escape to close, Tab navigation, replace keybindings) with the standard editor find/replace widget.

## Best solution

Register notebook-specific `replaceOne` and `replaceAll` keybinding actions (mirroring `editor.action.replaceOne` / `editor.action.replaceAll`), fix tab order to move from search input to replace input, and ensure consistent Escape-to-close behavior. Work lives in `src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFind.ts` and the widget file.
