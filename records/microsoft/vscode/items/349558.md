# Issue #349558 — Virtual workspace grep scans large repositories serially and leaves agent chat waiting for minutes

[https://github.com/microsoft/vscode/issues/349558](https://github.com/microsoft/vscode/issues/349558)

## Summary

Keep open: current source confirms serial virtual-filesystem searches without a search deadline or intermediate progress. Existing traversal and result caps do not prevent prolonged waits on large remote repositories.

## Change summary

Repository-wide virtual-workspace grep leaves agent chat waiting for minutes without results or progress.

## Best solution

Give Copilot virtual searches a bounded completion contract with explicit incomplete-search reporting and responsive cancellation, while preserving search filters and workspace confinement. Choose the timeout and partial-result semantics before implementation; indexed retrieval can remain a separate improvement.

- **Behavior:**

  > A repository-wide grep over a large virtual workspace must not leave the agent waiting indefinitely without useful status. It must complete or explicitly report that the search could not finish within the agreed budget, distinguishing incomplete searches from exhaustive no-match results. Cancellation must settle the invocation promptly even while remote filesystem work is pending. Existing matching, filtering, result limits and workspace confinement must remain intact.
- **Trace:**

  > createCopilotVirtualSearchTools.search in src/vs/platform/agentHost/node/copilot/copilotVirtualSearchTools.ts walks pending entries serially and awaits each filesystem operation before proceeding. Its entry, file-size and output caps do not limit elapsed time, and run publishes only the final result. CopilotVirtualSessionFs in src/vs/platform/agentHost/node/copilot/copilotVirtualSessionFs.ts forwards reads and directory resolution through IFileService to the current workspace client without the invocation cancellation signal. CopilotSessionLauncher explicitly installs these overrides for virtual sessions. Existing unit coverage in copilotVirtualWorkspace.test.ts tests ordinary results and already-aborted calls, not pending-I/O responsiveness. The precise reported duration was not executed or independently measured; the serial and deadline-free path is directly visible in source. Preserve policy withholding, SDK-path mapping, workspace confinement and local-workspace search behavior; external ingest tracked at https://github.com/microsoft/vscode/issues/313281 is related infrastructure rather than a canonical for this defect.
- **Open decisions:**
  - What elapsed-time budget should a virtual grep invocation guarantee before returning an incomplete outcome?
  - When that budget expires, should the agent receive explicitly marked partial matches or a timeout failure, including when no matches have yet been found?

## Evidence

- **Reported trigger:** https://github.com/microsoft/vscode/issues/349558 supplies concrete steps: search the microsoft/vscode virtual workspace root with case-insensitive computer.?use. The reporter observed a pending grep for 7 minutes 47 seconds; filesystem counts cover all workspace activity and cannot be attributed exclusively to grep.
- **Serial search and ineffective latency bounds:** src/vs/platform/agentHost/node/copilot/copilotVirtualSearchTools.ts:createCopilotVirtualSearchTools.search processes pending entries sequentially, awaiting directory enumeration, file stat and file reads. maxEntries=10000 bounds traversal entries, maxFileSize bounds individual files, and head_limit bounds output; none bounds elapsed time. The handler returns its result only after search finishes.
- **Cancellation boundary:** copilotVirtualSearchTools.ts checks invocation.signal between operations, but CopilotVirtualSessionFs.stat, readdirWithTypes and readFileBytes in src/vs/platform/agentHost/node/copilot/copilotVirtualSessionFs.ts await IFileService calls without receiving that signal. An outstanding filesystem operation therefore cannot be interrupted by these search-level checks.
- **Core ownership and adoption:** src/vs/platform/agentHost/node/copilot/copilotSessionLauncher.ts:1710-1713 excludes disk search built-ins for virtual workspaces; line 1744 constructs createCopilotVirtualSearchTools for virtual sessions when retrieval policy permits it. It does not cover slow or unresolved filesystem operations, elapsed-time limits, or cancellation during an outstanding read. No execution was performed in the read-only checkout.
