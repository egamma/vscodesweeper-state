# Issue #153267 — Cannot right click on command palette-like panels

[https://github.com/microsoft/vscode/issues/153267](https://github.com/microsoft/vscode/issues/153267)

## Summary

Keep open: this remains the canonical Backlog bug, and current source still hides a quick input when its text-field context menu takes focus. A 2025 report confirmed the same behavior on VS Code 1.104.1 and was consolidated here.

## Change summary

Right-clicking a command-palette or quick-pick input to use Cut, Copy, or Paste dismisses the surrounding panel.

## Best solution

Keep the quick input visible while its text-input context menu is open, then return focus to the input when the menu closes. The behavior should be consistent across Command Palette, file and branch pickers, desktop context-menu implementations, and VS Code for the Web.
