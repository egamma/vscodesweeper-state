# Issue #153267 — Cannot right click on command palette-like panels

[https://github.com/microsoft/vscode/issues/153267](https://github.com/microsoft/vscode/issues/153267)

## Summary

Keep open: custom input context menus still move focus outside the quick-input widget, triggering its dismissal. The linked merged PR changed menu stacking, not this focus-loss behavior, and later reports explicitly identify this issue as the tracker.

## Change summary

Right-clicking a Command Palette or similar quick-input field dismisses the panel before the user can paste.

## Best solution

Keep quick-input panels alive while users interact with their input context menus, including Paste and cancellation, without disabling normal dismissal when focus genuinely leaves the panel. Address the text-input context-menu integration with quick-input focus tracking.
