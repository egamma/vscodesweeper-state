# Issue #153267 — Cannot right click on command palette-like panels

[https://github.com/microsoft/vscode/issues/153267](https://github.com/microsoft/vscode/issues/153267)

## Summary

Still reproduces on main: the quick pick's focusTracker.onDidBlur handler hides the widget when a right-click context menu steals focus, with no special handling for context menus. The partial z-index fix in PR #155546 did not resolve the underlying focus-loss problem.

## Change summary

Right-clicking inside the command palette (or any quick pick) dismisses it because the context menu steals focus and triggers the blur-to-hide logic.

## Best solution

The quick pick's blur handler in `src/vs/platform/quickinput/browser/quickInputController.ts` (line ~332) needs to detect when focus moves to a context menu opened within or anchored to the quick pick container, and suppress the hide in that case — similar to how the file explorer fix in PR #169931 handled the same pattern for tree views.
