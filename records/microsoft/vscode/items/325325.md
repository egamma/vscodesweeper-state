# Issue #325325 — Terminal not open 

[https://github.com/microsoft/vscode/issues/325325](https://github.com/microsoft/vscode/issues/325325)

## Summary

The terminal requires ConPTY, which needs Windows 10 build 18309+. The reporter is on build 16299 (version 1709), which is below the minimum. Winpty was removed in VS Code 1.109, and the `windowsUseConptyDll` fallback also requires ConPTY support. This Windows version (2017, long out of Microsoft support) is too old for the current terminal backend.

## Change summary

Terminal fails to open on Windows 10 build 16299 with 'Cannot launch conpty' error after winpty removal.

## Best solution

Close as out-of-scope — Windows 10 build 16299 (version 1709) predates ConPTY support (build 18309+), and winpty was intentionally removed in VS Code 1.109. The reporter needs to update to at least Windows 10 version 1903 (build 18362) or later.
