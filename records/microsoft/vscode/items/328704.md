# Issue #328704 — Emphasize app and package subdirectories in monorepos

[https://github.com/microsoft/vscode/issues/328704](https://github.com/microsoft/vscode/issues/328704)

## Summary

Keep this Backlog Candidates request open while its community review finishes, classifying it as under discussion. Existing APIs provide extension-based color and badge decorations, but current settings and icon themes do not provide the requested workspace-scoped glob rules.

## Change summary

Allow monorepo application and package directories to be visually emphasized in the Explorer through configurable decorations or icons.

## Best solution

Prefer an extension using the existing file-decoration API to recognize monorepo paths and apply theme-aware badges or colors. If core support is pursued, the remaining gap is a workspace-scoped, glob-based Explorer decoration mechanism rather than another global decorations toggle.
