# Issue #328704 — Emphasize app and package subdirectories in monorepos

[https://github.com/microsoft/vscode/issues/328704](https://github.com/microsoft/vscode/issues/328704)

## Summary

Verified duplicate: the older open canonical issue already tracks styling Explorer entries by path or regular expression, including folder colors and font styling. The monorepo apps/packages example adds useful context but no distinct product requirement.

## Change summary

Allow monorepo application and package directories to be visually emphasized in the Explorer through configurable icons, colors, or font weight.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/31308 and preserve this report's monorepo path-pattern use case there. A general Explorer-decoration capability or extension API should support path-based styling rather than adding monorepo-specific configuration.

## Vision fit

- **Fit:** rejected
- **Reason:** A specialized core setting for per-path Explorer styling conflicts with the preference for uniform UI and extension-delivered customization.
- **Evidence:** Values and guardrails: “The power lives in extensions” and “UI consistency beats per-feature customization.”
