## Summary

Genuine, currently-unsupported request for per-folder visual emphasis in the Explorer (e.g. bold/colored monorepo app/package folders, workspace folder icons). It's only 3 days old with 1 upvote and just entered the Backlog Candidates 60-day upvote window, so it should stay open as under-discussion rather than be closed for being quiet.

## Change summary

Allow styling specific folders (e.g. via glob patterns like `explorer.folderDecorations` or `.code-workspace` folder icons) so monorepo app/package directories stand out in the Explorer.
