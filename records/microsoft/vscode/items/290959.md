# Issue #290959 — Agent sessions diff decoration doesn't disappear after undoing some changes

[https://github.com/microsoft/vscode/issues/290959](https://github.com/microsoft/vscode/issues/290959)

## Summary

The local-session path still permits stale sidebar diff counts after undo: editing statistics change without triggering a session-item update, and an undefined replacement summary retains the previous counts. Keep this open for a bounded fix to live diff tracking.

## Change summary

Undoing agent-generated edits should update the session sidebar's change counts and remove the decoration when no changes remain.

## Best solution

Make local-session sidebar statistics reflect the current editing-session diff, including partial undo and the transition to no changes. Preserve lazy summary retention for providers whose missing details mean not yet resolved rather than no remaining edits.
