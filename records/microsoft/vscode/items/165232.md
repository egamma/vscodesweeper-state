# Issue #165232 — Incorrect highlighting of tsx code inside Markdown code blocks (bracket token exclusion rules of embedded grammars are not considered)

[https://github.com/microsoft/vscode/issues/165232](https://github.com/microsoft/vscode/issues/165232)

## Summary

Keep open: the discussion confirms incorrect bracket colorization in embedded TSX, and current source still does not inherit embedded grammars' bracket exclusions. Markdown now duplicates some TypeScript exclusions, but that partial mitigation does not establish that the reported problem is fully resolved.

## Change summary

Valid TypeScript and TSX inside Markdown fences receive incorrect bracket colors because embedded grammar bracket exclusions are not consistently respected.

## Best solution

Make embedded-code bracket classification respect the applicable grammar's exclusions while preserving legitimate bracket colorization. Diagnose the remaining TSX case against today's Markdown exclusions before choosing the scope of the correction; the broader per-bracket configuration proposal is related work, not a prerequisite already agreed upon.

## Evidence

- **Confirmed reproduction and diagnosis:** In https://github.com/microsoft/vscode/issues/165232, mjbvz supplied a minimal fenced TSX example and confirmed that disabling bracket colorization removes the red sections, unlike normal .tsx files. Hediet identified root-grammar-only bracket filtering, and RedCMD reported continued failure when pasting and modifying code in October 2024. These are confirmed discussion reproductions, not a runtime reproduction performed during this review.
- **Current grammar-loading boundary:** src/vs/workbench/services/textMate/common/TMGrammarFactory.ts, TMGrammarFactory.createGrammar, passes balancedBracketSelectors and unbalancedBracketSelectors only from the root grammarDefinition to loadGrammarWithConfiguration. Its loadGrammar callback loads included grammar contents without forwarding their contribution-level bracket exclusions.
- **Partial mitigation, remaining configuration gap:** extensions/markdown-basics/package.json explicitly duplicates relational, arrow, shift, and compound-bitwise exclusions for TS and TSX. It does not duplicate punctuation.definition.tag, which extensions/typescript-basics/package.json excludes for standalone TypeScript/TSX. extensions/markdown-basics/syntaxes/markdown.tmLanguage.json includes source.tsx inside fenced_code_block_tsx. Therefore the historical arrow-only example may be mitigated, but embedded grammar exclusions still are not generally inherited.
- **Downstream bracket interpretation:** src/vs/editor/common/model/bracketPairsTextModelPart/bracketPairsTree/tokenizer.ts gates bracket scanning on TokenMetadata.containsBalancedBrackets and then selects bracket definitions using the token's language ID. Embedded language mapping and exclusion metadata must both be considered when validating the remaining JSX case.
