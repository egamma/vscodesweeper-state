# Issue #70118 — default run task

[https://github.com/microsoft/vscode/issues/70118](https://github.com/microsoft/vscode/issues/70118)

## Summary

A standard default Run task remains missing: current task groups and default-task commands cover Build and Test, not Run. Maintainers accepted the task-based direction, and no verified older canonical owns this request.

## Change summary

Provide a workspace-selectable default Run task and a reusable command/keybinding for build-and-execute workflows without requiring a debugger configuration.

## Best solution

Expose an existing project run script or task through a standard default Run task, analogous to default Build and Test tasks. Preserve task-defined execution and dependencies rather than introducing a language-specific runner or requiring launch.json.

A standard command usable from a reusable keybinding invokes that default without a task-specific shortcut, launch.json or debugger extension. The task remains responsible for its execution and build dependencies. Acceptance includes using the same command across workspaces with differently named Run tasks and preserving existing Build/Test defaults.
