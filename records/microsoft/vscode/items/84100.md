# Issue #84100 — Distinguish types of calls for call hierarchy?

[https://github.com/microsoft/vscode/issues/84100](https://github.com/microsoft/vscode/issues/84100)

## Summary

A real API and UX gap remains on current main, but the call-kind model and user value still require design agreement. Keep this open as under discussion.

## Change summary

Allow call-hierarchy providers and the UI to distinguish invocation kinds such as construction, accessor reads or writes, decorators, and tagged templates.

## Best solution

Design an optional, language-neutral call-kind API, then let the references view filter or group results by those kinds. The design must account for the existing grouping of multiple call-site ranges into one incoming or outgoing call.
