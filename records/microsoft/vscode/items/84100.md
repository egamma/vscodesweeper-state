# Issue #84100 — Distinguish types of calls for call hierarchy?

[https://github.com/microsoft/vscode/issues/84100](https://github.com/microsoft/vscode/issues/84100)

## Summary

Still an open API gap: the call hierarchy API on main has no way to classify a call (new / tagged template / decorator / getter vs setter), and the design was explicitly blocked on TypeScript proposing a kind taxonomy that never materialized. Keep open as a Backlog API discussion.

## Change summary

Add a way to distinguish call kinds (constructor, tagged template, decorator, accessor get/set, plain call) in the call hierarchy API and UX.

## Best solution

Keep this parked until a language service (TypeScript) proposes a concrete kind taxonomy; then add a `kind` property to `CallHierarchyIncomingCall`/`CallHierarchyOutgoingCall` in src/vscode-dts/vscode.d.ts (proposed first) and let the call hierarchy peek filter or group by it — mirroring the reference-classification request in https://github.com/microsoft/vscode/issues/74237.
