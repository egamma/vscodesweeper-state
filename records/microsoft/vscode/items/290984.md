# Issue #290984 — Implement model in the custom agent file is disjoint from the setting

[https://github.com/microsoft/vscode/issues/290984](https://github.com/microsoft/vscode/issues/290984)

## Summary

Keep open for a model-selection persistence decision: current source still distinguishes configured defaults from conversation selections, and the thread explicitly leaves synchronization versus temporary overrides unresolved. This team-authored request has maintainer support, with no verified fix or qualifying older duplicate.

## Change summary

Make model selection through the custom agent file, chat picker, and implementation-model setting consistent and understandable.

## Best solution

Establish a consistent precedence and persistence contract for Plan and implementation model choices, then make the picker, agent definition, and settings communicate that contract. Decide explicitly whether temporary selections should leave saved defaults unchanged rather than assuming every selection must update configuration.
