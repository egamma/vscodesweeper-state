# Issue #252762 — Cannot copy code that the AI wants to remove

[https://github.com/microsoft/vscode/issues/252762](https://github.com/microsoft/vscode/issues/252762)

## Summary

Keep open: current source still distinguishes selectable deletions in the standard diff editor from chat's inline deletion view zones, which lack that integration. The reporter supplied the requested recording after disputing the earlier resolution; the matching open report is newer and cannot replace this re-reviewed issue.

## Change summary

Allow selecting and copying original text displayed as deleted during review of AI edits, without accepting or undoing the change first.

## Best solution

Make deleted text directly selectable and copyable in chat's inline edit-review surface while preserving pending edits and existing Keep/Undo behavior. Opening a separate diff editor remains a useful workaround, not a replacement for this interaction.
