# Issue #334195 — Top-Right Menu Unresponsive After VS Code Update

[https://github.com/microsoft/vscode/issues/334195](https://github.com/microsoft/vscode/issues/334195)

## Summary

Fresh, credible regression report: multiple users confirm the top-right menu becomes unresponsive after 1.136.0, and a contributor found the workaround `workbench.experimental.modernUI: false` fixes it — pointing at the new Modern UI Update experiment, which is rolled out via `experiment: { mode: 'auto' }` (default false) so it can silently affect a subset of users. No confirmed canonical duplicate yet and I can't reproduce interactively, so this needs a maintainer/area owner to trace the actual click-handling regression.
