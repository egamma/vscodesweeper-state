# Issue #156811 — Activation event for a particular folder opened

[https://github.com/microsoft/vscode/issues/156811](https://github.com/microsoft/vscode/issues/156811)

## Summary

Valid feature request for a workspace-name-based activation event (e.g. `workspaceName:*-wiki`). Not implemented on current main — `workspaceContains` only checks file contents/existence, not folder names. No duplicate found. Team-authored, stays open.

## Change summary

Allow extensions to activate based on the opened workspace folder's name pattern, avoiding unnecessary `onStartupFinished` activations.

## Best solution

Add a new activation event (e.g. `workspaceName:<glob>`) or extend `workspaceContains` to also match the folder name. Implementation would touch `src/vs/workbench/services/extensions/common/workspaceContains.ts` and the activation event handling in `src/vs/workbench/api/common/extHostExtensionService.ts`. This would let extensions like GistPad activate only when a matching folder is open, reducing unnecessary startup overhead.
