# Issue #156811 — Activation event for a particular folder opened

[https://github.com/microsoft/vscode/issues/156811](https://github.com/microsoft/vscode/issues/156811)

## Summary

Verified duplicate: the open canonical issue already tracks activating extensions from directory names and explicitly includes matching the path of the folder being opened. Consolidating there preserves this report's concrete `*-wiki` use case.

## Change summary

Allow extensions to activate when an opened workspace folder's name matches a pattern such as `*-wiki`, without activating on every startup.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/2739 and design a folder/path-aware activation mechanism there that covers both directories within a workspace and the opened workspace folder's own name.
