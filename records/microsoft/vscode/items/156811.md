# Issue #156811 — Activation event for a particular folder opened

[https://github.com/microsoft/vscode/issues/156811](https://github.com/microsoft/vscode/issues/156811)

## Summary

Verified duplicate: the open canonical issue already tracks activation based on workspace directories and their full paths, which includes matching an opened workspace folder's name.

## Change summary

Allow an extension to activate only when the opened workspace folder name matches a pattern such as `*-wiki`.

## Best solution

Consolidate the API design in https://github.com/microsoft/vscode/issues/2739, including this report's specific requirement to match the root workspace-folder name rather than only files contained beneath it.
