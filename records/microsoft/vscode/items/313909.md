# Issue #313909 — Copilot Apply In Editor to New Untitled File Overwrites Existing Untitled File

[https://github.com/microsoft/vscode/issues/313909](https://github.com/microsoft/vscode/issues/313909)

## Summary

The defect remains source-reproducible on current main: selecting “New untitled editor” constructs the fixed URI `untitled:Untitled-1`, so an existing Untitled-1 is reused and edited instead of creating a new document. This should remain open and be routed to the chat response area.

## Change summary

Applying a Copilot response code block to a new untitled editor can modify an already-open untitled document instead.

## Best solution

Ensure Apply in Editor obtains a genuinely new untitled text resource without reusing any existing untitled model, while preserving the active-editor and named-file destination paths.
