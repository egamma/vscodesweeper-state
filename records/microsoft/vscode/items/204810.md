[https://github.com/microsoft/vscode/issues/204810](https://github.com/microsoft/vscode/issues/204810)

## Summary

Keep open: independent reports confirm that sequential commands can leave focus in the terminal instead of the editor. Current source still contains asynchronous terminal-focus work, but inspection alone does not establish the precise race or prove that it remains reproducible on current main.

## Change summary

Ensure a terminal-focus command followed by an editor-focus command in runCommands leaves focus in the editor.

## Best solution

Make command completion and deferred terminal focus respect the subsequent explicit editor-focus request, without requiring user-configured delays. First reproduce the reported sequences on current main and identify which pending focus operation outlives its command.
