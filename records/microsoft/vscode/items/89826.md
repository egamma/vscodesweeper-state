# Issue #89826 — Tab does not work as a trigger character for 

[https://github.com/microsoft/vscode/issues/89826](https://github.com/microsoft/vscode/issues/89826)

## Summary

Still an open design question on current main: Tab key presses go through a command path rather than the `onDidType` event, so they never reach the trigger-character listener in suggestModel.ts. The maintainer engaged and left it under-discussion; no code change has been made.

## Change summary

Tab (`\t`) registered as a trigger character for a CompletionProvider never fires completions because Tab bypasses the `onDidType` typing event.

## Best solution

A product decision is needed on whether to support Tab as a trigger character. If yes, the suggest model in `src/vs/editor/contrib/suggest/browser/suggestModel.ts` would need to also listen for Tab-induced text changes (which bypass `onDidType` in `codeEditorWidget.ts` because Tab is handled as a command, not a keyboard type). The use case (YAML indentation-sensitive completions) is legitimate but niche — the team should decide whether this complexity is warranted.
