# Issue #298966 — Chat history not visible in Copilot Chat panel after restart (Remote-WSL, v1.109)

[https://github.com/microsoft/vscode/issues/298966](https://github.com/microsoft/vscode/issues/298966)

## Summary

The failure remains possible on current main: persisted session files are not discovered when the workspace-scoped session index is absent or stale. This should stay open and be routed to the chat-session owners.

## Change summary

Persisted Copilot Chat sessions disappear from the Chat panel after restart even though their session files remain on disk and can be opened through the Agents Sessions window.

## Best solution

Ensure the Chat history index remains valid across local/remote restarts and recover same-workspace sessions whose valid files remain on disk when the index is missing or stale. Keep this bounded to active-workspace local chat history; broader cross-workspace orphan discovery remains tracked separately.
