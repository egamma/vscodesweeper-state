# Issue #116450 — Find widget focus movement could be improved

[https://github.com/microsoft/vscode/issues/116450](https://github.com/microsoft/vscode/issues/116450)

## Summary

A meaningful accessibility gap remains on current main: Find in Selection is now tabbable, but the find widget's action buttons remain separate tab stops without left/right arrow navigation. Keep this canonical request open under discussion.

## Change summary

Make the editor find widget's action buttons a single tab stop with arrow-key navigation within the group.

## Best solution

Convert the actions beside the find input into an ActionBar or equivalent roving-focus group in `findWidget.ts`, preserving Tab entry and exit while using Left/Right Arrow within the group.

## Evidence

- **partial coverage:** `src/vs/base/browser/ui/findinput/findInput.ts` already implements Left/Right Arrow navigation for the inline case-sensitive, whole-word, and regex toggles, but that behavior does not include the adjacent actions created by `findWidget.ts`.
