# Issue #182245 — Complete app for android 

[https://github.com/microsoft/vscode/issues/182245](https://github.com/microsoft/vscode/issues/182245)

## Summary

Keep this canonical Android-app request open in the Backlog. It exceeded the community threshold with 45 upvotes, and the available PWA and server workarounds do not provide the requested native storage, terminal, keyboard, touch, and offline integration.

## Change summary

Provide an official Android application that extends vscode.dev with native platform capabilities.

## Best solution

Retain this as the canonical product request and evaluate an Android shell around the web workbench, with workbench OS integration for files, input, offline use, and terminals. Narrow web UX defects can be tracked separately while this issue owns official Android distribution.
