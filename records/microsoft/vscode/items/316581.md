# Issue #316581 — BYOK models from Github org panel don't work

[https://github.com/microsoft/vscode/issues/316581](https://github.com/microsoft/vscode/issues/316581)

## Summary

Keep open as a confirmed org-managed BYOK integration bug. Multiple users report that valid Foundry deployments work directly but fail through GitHub-managed custom models because tool definitions reach the provider with `function.strict: null`.

## Change summary

Make GitHub organization-managed BYOK models work with Azure Foundry and OpenAI-compatible endpoints.

## Best solution

Update the GitHub-managed custom-model request layer to omit unset `function.strict` values or serialize them as `false`, and clarify the supported Foundry endpoint/API combinations in the documentation.
