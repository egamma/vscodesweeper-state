## Change summary

Questions whether the new experimental `sessions.editor.wordWrap` / `sessions.diffEditor.wordWrap` settings are redundant given the existing Agents Window tab in the Settings Editor UI, which can already override `editor.wordWrap` / `diffEditor.wordWrap`.

## Best solution

A sessions-team maintainer should decide whether to fold word-wrap control entirely into the Agents Window Settings Editor tab (removing the new `sessions.*.wordWrap` settings) or keep both with clearer, non-overlapping semantics; the relevant code is src/vs/sessions/contrib/editor/browser/diffEditor.sessions.contribution.ts and src/vs/sessions/contrib/editor/common/diffEditorOptionsService.ts.
