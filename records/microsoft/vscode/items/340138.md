# Issue #340138 — Agent Host BYOK bridge drops provider configurationSchema and statusIcon from the model picker

[https://github.com/microsoft/vscode/issues/340138](https://github.com/microsoft/vscode/issues/340138)

## Summary

The metadata-loss path remains in current main: Agent Host model projection carries the original BYOK identifier but does not preserve its provider configuration schema or presentation fields. Keep this open; the older context-size report covers only part of the requested behavior.

## Change summary

Preserve extension-provided configuration controls and model presentation when a BYOK model is displayed through Agent Host.

## Best solution

The bridged BYOK entry should retain the original provider's supported configuration controls and presentation without changing host routing or overriding host-specific warnings and capabilities. Provider-defined property names and existing picker groups should remain usable after conversation restoration.
