## Summary

Plausible crash report (exit code 0xC0000409 twice, matching an AVX-512 'HW capability requested' fatal error from a downloaded agent-SDK binary) but it's a single, day-old report with no confirmation that the extension host crash is actually caused by the same CPU-feature mismatch rather than a coincidental timing correlation — asking for more diagnostic detail before deciding next steps.

## Change summary

On an i5-12500H (no AVX-512), the bundled Copilot CLI/agent-SDK binary fails with a HW-capability fatal error, and shortly after Copilot Chat activates, the extension host itself crashes with the same exit code in a loop.

## Best solution

If confirmed, the fix likely belongs in the vendor SDK (Claude/Codex) binary selection logic in src/vs/platform/agentHost/node/agentSdkDownloader.ts — resolveSdkTarget() only distinguishes platform/arch/libc, not CPU microarchitecture/ISA level, so there is no fallback build for CPUs lacking AVX-512; that would need a non-AVX-512 SKU from the SDK vendor plus target-selection logic here, or at minimum the child process should fail gracefully instead of apparently destabilizing the extension host.
