# Issue #341683 — Installed MCP servers from a registry can appear disabled after restart

[https://github.com/microsoft/vscode/issues/341683](https://github.com/microsoft/vscode/issues/341683)

## Summary

Thanks for the detailed report. In current main, getMcpServer() in mcpGalleryService.ts still requests the detail URL with followRedirects: 0 and throws on any non-2xx status other than 404. A registry that redirects to a slash-terminated URL would therefore fail membership resolution, which matches the observation. A fix PR (#341691) exists but is reported as closed and unmerged; I could not confirm its state without GitHub auth.

## Change summary

Registry-installed MCP servers show as disabled after restart because the server detail request fails when the registry redirects (for example, GitHub Pages directory URLs).

## Best solution

Make getMcpServer() handle a redirect or opaque status-0 response on a registry detail URL with a single bounded retry against the slash-terminated URL. Keep redirects disabled and revalidate the retry URL against the registry origin and path. Leave the 404, 401/403, 429 and 5xx handling unchanged.
