# Issue #318417 — BYOK UI: Last model should not be selected after removing BYOK models

[https://github.com/microsoft/vscode/issues/318417](https://github.com/microsoft/vscode/issues/318417)

## Summary

Valid bug filed by a team member — after removing BYOK models and reloading, the model picker still renders the stale model name until clicked. No fix found on main; keeping open for the assignee (vritant24) to address.

## Change summary

After removing BYOK models and reloading the window, the chat widget still shows the last-used BYOK model name, but clicking it reveals only 'Auto'.

## Best solution

The model picker label rendering (`_renderLabel` in `chatModelPicker.ts`) and the model persistence/restoration logic in `chatInputPart.ts` should validate the persisted model ID against available models before rendering it. `shouldResetOnModelListChange` already handles resetting when the model isn't in the list, but the initial label render likely fires before the model list is populated post-reload, showing the stale persisted name.
