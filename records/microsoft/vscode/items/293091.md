# Issue #293091 — The menu bar after the last update got changed into a burger menu and cannot be set back to normal (menu bar visibility is set up as classic))

[https://github.com/microsoft/vscode/issues/293091](https://github.com/microsoft/vscode/issues/293091)

## Summary

The reporter identified that the Agent status icon in the titlebar causes the classic menu bar to collapse into a hamburger menu due to insufficient space. Filed against 1.109.0, and significant titlebar and agent-status layout changes have landed since — needs confirmation on the latest build.

## Change summary

The classic menu bar collapses into a hamburger/burger menu when the Agent status icon is enabled in the titlebar, because the overflow detection in MenuBar decides there is not enough space.

## Best solution

If still reproducible on current builds, the fix belongs in the titlebar layout (src/vs/workbench/browser/parts/titlebar/) — ensure the `.titlebar-left` container that hosts the menubar is allocated enough width when the command center with agent status is present, or adjust the MenuBar overflow threshold in src/vs/base/browser/ui/menu/menubar.ts to be less aggressive when visibility is set to 'classic'.

## Evidence

- **reporter diagnosis:** In a follow-up comment on 2026-02-27, the reporter identified the root cause: enabling the Agent status icon in the titlebar resizes the top layout enough to trigger the menu bar to collapse under the burger icon.
- **overflow mechanism:** src/vs/base/browser/ui/menu/menubar.ts lines 484-520: the MenuBar widget measures available container width and hides menu items that don't fit; line 512 has a threshold (≤ 1/4 of menus visible) that collapses everything into a hamburger.
- **titlebar layout:** src/vs/workbench/browser/parts/titlebar/media/titlebarpart.css lines 75-98: when `has-center` is set, titlebar-left gets `width: 20%; flex-grow: 2` — the agent status inside the command center could claim enough center space to squeeze the left region.
- **significant changes since report:** Commit 81a49feaf7a (2026-03-06) reworked agent status to be inline with the command center in compact mode; multiple other titlebar layout commits landed since the report. The issue may or may not still reproduce on current main.
