# Issue #203725 — LaTeX not rendering in cell text/html encoded outputs when embedded inside html

[https://github.com/microsoft/vscode/issues/203725](https://github.com/microsoft/vscode/issues/203725)

## Summary

The gap remains on current main: the markdown-math extension only hooks into the markdown-it renderer pipeline, so text/html notebook outputs that embed LaTeX are never processed by KaTeX. No fix references this issue. Keeping open as a valid feature request with 9 upvotes.

## Change summary

LaTeX expressions embedded inside HTML in notebook text/html cell outputs are not rendered by KaTeX, though they render correctly in JupyterLab.

## Best solution

Add a post-processing pass (or a notebook output renderer contribution) that runs KaTeX auto-render on text/html output elements after they are inserted into the DOM, matching JupyterLab's behavior. The work likely belongs in extensions/markdown-math or in a new notebook output renderer that extends the built-in HTML renderer.
