# Issue #292409 — show workspace / repo more clearly in sessions preview from welcome page

[https://github.com/microsoft/vscode/issues/292409](https://github.com/microsoft/vscode/issues/292409)

## Summary

Keep open: the welcome-page preview supports provider-supplied badges, but does not consistently surface workspace identity from available session metadata. This team-authored request has neither a verified canonical duplicate nor an explicitly linked fixing commit.

## Change summary

Make each recent session's associated repository or workspace recognizable from the welcome-page preview without relying on its title.

## Best solution

Provide consistent, secondary workspace or repository identification in welcome-page session previews, reusing existing session metadata and preserving title prominence. Settle the presentation and disambiguation behavior before implementation; changing what clicking a session opens is a separate scope decision.
