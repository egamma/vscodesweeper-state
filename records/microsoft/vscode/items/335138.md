# Issue #335138 — Codex Agent Host: recognize non-ChatGPT accounts (API key, Bedrock, Azure, local, custom providers) as usable

[https://github.com/microsoft/vscode/issues/335138](https://github.com/microsoft/vscode/issues/335138)

## Summary

Well-documented, accurate gap: Codex Agent Host only treats a ChatGPT login as a usable account, leaving API-key/Bedrock/Azure/local `model_provider` configs unrecognized — confirmed directly in current source. This is a legitimate follow-up to #329668's shipped work, not yet implemented.

## Change summary

Codex Agent Host should recognize non-ChatGPT accounts (API key, Bedrock, Azure, local, custom providers) as usable, not just ChatGPT logins.

## Best solution

Extend `codexAccountStateFromResponse()` in src/vs/platform/agentHost/node/codex/codexAccountState.ts to treat non-empty-catalog `apiKey`/`other` accounts as usable, and relax the `authType === 'chatgpt'` gating in `_toAccountInfo()` (codexAgent.ts) so non-ChatGPT providers surface a minimal account/model indicator, plus extend `resolveAgentAuthRequirement()` in baseAgentHostSessionsProvider.ts per the acceptance criteria in #329668.
