# Issue #305920 — Copilot Chat returns silently truncated responses without warning

[https://github.com/microsoft/vscode/issues/305920](https://github.com/microsoft/vscode/issues/305920)

## Summary

The incomplete response is credible, but the supplied steps are intermittent and do not identify whether the model hit its output limit, the stream lost chunks, or rendering omitted content. The requested language-model log is still needed to diagnose the responsible path.

## Change summary

Copilot Chat can display responses with missing passages or an abrupt mid-word ending without telling the user that the response is incomplete.

## Best solution

Capture the affected language-model request and response log and use its finish reason and streamed chunks to distinguish model length truncation from transport or rendering loss. For a length-limited response, Chat should retain the partial content while visibly marking it incomplete; dropped stream content needs correction at the layer where the log first diverges.
