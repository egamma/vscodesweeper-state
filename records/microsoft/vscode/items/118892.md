# Issue #118892 — Word wrapping incorrect for variable width font with formatting that changes the width of characters

[https://github.com/microsoft/vscode/issues/118892](https://github.com/microsoft/vscode/issues/118892)

## Summary

The underlying issue — DOM line breaks computation not accounting for decoration styling (bold, font size changes) — appears to still exist on current main. However, this report is over 4 years old against a very old Insiders build (1.55.0), with no community confirmation, and the wrapping infrastructure has seen significant changes since. Requesting confirmation on the latest build.

## Change summary

Word wrapping with the 'advanced' strategy does not account for decoration-induced font-weight changes (e.g. bold in markdown), causing incorrect wrapping and horizontal scroll with variable-width fonts.

## Best solution

The `renderLine` function in `src/vs/editor/browser/view/domLineBreaksComputer.ts` renders plain text spans without applying decoration CSS classes (bold, italic, font-size). To fix, the line breaks computer context would need decoration information passed through `ILineBreaksComputerContext`, and the DOM measurement spans would need to carry the corresponding CSS classes. This is a non-trivial change that touches the wrapping pipeline's contract.
