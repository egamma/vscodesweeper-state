# Issue #131746 — Workspace trust header shadow doesn't show up if you tab through file

[https://github.com/microsoft/vscode/issues/131746](https://github.com/microsoft/vscode/issues/131746)

## Summary

The bug remains source-reproducible on current main: keyboard focus can natively scroll the Workspace Trust body without updating the scrollable widget's internal position, leaving its top shadow hidden. The accepted On Deck polish bug should remain open for a bounded synchronization fix.

## Change summary

Tabbing through offscreen controls in Manage Workspace Trust scrolls the body but does not display the header's inset scroll shadow.

## Best solution

Keep the scrollable element's position and inset-shadow state synchronized when focus navigation causes native DOM scrolling, while preserving existing wheel, scrollbar, and programmatic scrolling behavior.
