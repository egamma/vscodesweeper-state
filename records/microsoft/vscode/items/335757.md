[https://github.com/microsoft/vscode/issues/335757](https://github.com/microsoft/vscode/issues/335757)

## Summary

The detailed protocol timeline and reload behavior confirm a real client-state synchronization bug: an authoritative input request was persisted but not surfaced live. This team-authored issue must remain open because no fixing commit or linked closing PR explicitly references https://github.com/microsoft/vscode/issues/335757.

## Change summary

Surface Agent Host input requests immediately in the Agents Window and replace the active Working state with Needs Input.

## Best solution

Make pending chat input requests recoverable from authoritative session state rather than dependent solely on observing the live turn action, and add a regression covering the remote Dev Container action ordering without a window reload.
