# Issue #228007 — Expose Walkthrough Media in Accessible view.

[https://github.com/microsoft/vscode/issues/228007](https://github.com/microsoft/vscode/issues/228007)

## Summary

The walkthrough accessible view (commit 66207ee7289) exposes step titles and text descriptions but does not yet surface image/SVG alt text or markdown media content — the specific gap this issue tracks remains open.

## Change summary

Expose walkthrough media (image/SVG alt text and markdown content) in the accessible view.

## Best solution

Extend `_getContent` in `src/vs/workbench/contrib/welcomeGettingStarted/browser/gettingStartedAccessibleView.ts` to read `step.media.altText` for image/SVG steps and render the markdown body for markdown-type steps, appending them to the accessible view output.
