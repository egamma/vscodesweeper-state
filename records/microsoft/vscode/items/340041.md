# Issue #340041 — Support tool selection and referencing in the Copilot harness like it is in the local harness

[https://github.com/microsoft/vscode/issues/340041](https://github.com/microsoft/vscode/issues/340041)

## Summary

Thanks for the feedback. This is a valid feature request with several independent confirmations in the thread. A maintainer has acknowledged the flow difference, and the Agent Customizations Tools tab only partly covers the ask, since it is not per-session and has no #tool referencing or in-chat picker. It stays open for the owning team.

## Change summary

Provide the in-chat tool picker and #tool referencing in the Copilot harness, as the local harness has, ideally with per-session tool selection.

## Best solution

Surface a per-session tool picker and #tool completion/reference in the Copilot harness chat input of the agent host. Persistent global toggles in the Customizations editor would then complement them rather than replace them.
