# Issue #340041 — Support tool selection and referencing in the Copilot harness like it is in the local harness

[https://github.com/microsoft/vscode/issues/340041](https://github.com/microsoft/vscode/issues/340041)

## Summary

Keep open: profile-wide tool management does not deliver the requested input-level picker and session-specific control. The broader related request explicitly preserves this issue rather than replacing it.

## Change summary

Provide convenient tool selection and discoverable tool references in Copilot harness sessions, comparable to the Local harness.

## Best solution

Provide a consistent, keyboard-accessible tool-selection and reference workflow from the Copilot chat input, with clearly defined selection scope. Preserve runtime permissions and distinguish unavailable capabilities from disabled tools.
