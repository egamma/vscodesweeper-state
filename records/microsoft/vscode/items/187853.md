# Issue #187853 — Truncate long terminal command lines by default

[https://github.com/microsoft/vscode/issues/187853](https://github.com/microsoft/vscode/issues/187853)

## Summary

Current main partially addresses this with executable-path shortening and a Show Details action, but still displays every argument, including long PowerShell shell-integration arguments, in the default hover. Keep the accepted backlog request open for the remaining command-line summarization design; no qualifying canonical or concrete completing fix was identified.

## Change summary

Summarize long terminal launch command lines in tab hovers by default while allowing users to reveal the full executable path and arguments.

## Best solution

Make long launch commands readable at a glance in the shared terminal hover, with the full diagnostic command available through Show Details. Settle the compact-summary trigger and treatment of injected arguments before implementation, preserving actual shell launch behavior.

- **Behavior:**

  > Long terminal launch commands should not dominate the default tab hover, particularly when PowerShell shell integration injects lengthy arguments. Users must still be able to reveal the complete executable path and arguments for diagnostics. The issue proposes an executable-name and argument-count summary with an explicit details action; current main provides disclosure but does not summarize arguments. Acceptance must cover long injected commands, short ordinary commands, full-detail recovery, and keyboard access.
- **Trace:**

  > src/vs/workbench/contrib/terminal/browser/terminalTooltip.ts centralizes this presentation in getInstanceHoverInfo and getShellProcessTooltip. getInstanceHoverInfo already exposes a persisted Show Details/Hide Details action, while getShellProcessTooltip only abbreviates long executable paths and appends the entire injectedArgs-or-configured-args string in both modes. TerminalInstance receives injectedArgs from process creation and relaunch, explaining why shell-integration details reach this hover. The shared helper feeds terminalTabsList.ts, terminalTabbedView.ts, and terminalView.ts; terminalTabsList.ts observes the detailed-state storage key. Preserve process execution, argument contents, existing status diagnostics, and full-detail availability: this is a presentation request, not a shell-integration change. https://github.com/microsoft/vscode/issues/177774#issuecomment-1649799446 identifies this issue as the follow-up for long-command readability. The remaining uncertainty is the compact presentation contract, not whether disclosure infrastructure exists.
- **Open decisions:**
  - What total command-line length should trigger the compact summary, and should short commands remain fully visible in the default hover?
  - Should compact mode summarize all arguments uniformly as a count, or distinguish shell-integration-injected arguments from user-configured arguments?
