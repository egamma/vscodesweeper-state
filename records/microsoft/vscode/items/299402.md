# Issue #299402 — confusing line termination status for single line files without a terminator

[https://github.com/microsoft/vscode/issues/299402](https://github.com/microsoft/vscode/issues/299402)

## Summary

Keep open for clarification of the desired EOL presentation. The status bar reports the editor's active newline mode, not detected terminator bytes; honoring EditorConfig and indicating that a file contains no terminators are distinct improvements.

## Change summary

Make the EOL status for an unterminated single-line file reflect its EditorConfig preference or distinguish the absence of line terminators.

## Best solution

Preserve the status bar's ability to select the active newline mode while deciding whether unterminated files need an explicit distinction between configured mode and on-disk contents. Coordinate EditorConfig-derived defaults with the existing native EditorConfig request rather than treating the current fallback as a proven core defect.
