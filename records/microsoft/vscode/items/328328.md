# Issue #328328 — Pressing `Win+Shift` hides context views in status bar

[https://github.com/microsoft/vscode/issues/328328](https://github.com/microsoft/vscode/issues/328328)

## Summary

Status-bar hovers intentionally dismiss on ordinary key presses unless focused; clicking into the hover makes it sticky for taking a Win+Shift+S screenshot.

## Change summary

Keep status-bar hovers visible while invoking Windows screen capture with Win+Shift+S.

## Best solution

Keep the existing transient-hover behavior and use the supported click-to-focus interaction when the hover must remain visible during keyboard input.
