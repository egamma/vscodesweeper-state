# Issue #333994 — Chat request edit input is translucent over Agents Window backgrounds

[https://github.com/microsoft/vscode/issues/333994](https://github.com/microsoft/vscode/issues/333994)

## Summary

Traced and confirmed in source: the Agents Window has no opaque-background override for the editing `.chat-input-container`, so custom chat backgrounds show through the edit surface. An open PR already targets this exact fix, so this should stay open pending that PR's review/merge rather than being closed now.

## Change summary

In the Agents Window with a custom chat background, clicking to edit a user request shows the background art through the translucent edit input instead of an opaque surface.

## Best solution

Land https://github.com/microsoft/vscode/pull/334021, which applies the same opaque-base-plus-tint composition (using `--session-view-background` plus `--vscode-chat-requestBubbleBackground`) to the editing `.chat-input-container` when `.has-chat-background` is active, matching the existing request-bubble treatment in src/vs/sessions/contrib/chat/browser/media/chatView.css.
