# Issue #309027 — Create new session from current worktree

[https://github.com/microsoft/vscode/issues/309027](https://github.com/microsoft/vscode/issues/309027)

## Summary

Feature request for easily starting a fresh new session in the same worktree after finishing agent work. The Agents window already supports creating new chats within a session and branching, but starting a fully fresh session pre-targeted at the current worktree may not be directly surfaced as a one-click action.

## Change summary

Add an easy way to start a new fresh chat session pre-scoped to the current worktree without re-selecting it.

## Best solution

The Agents window's session creation and workspace-picker flows should be evaluated to see if a 'New session in this worktree' shortcut is warranted — likely a small UX addition to the session list or title bar actions in `src/vs/sessions/contrib/sessions/browser/`.
