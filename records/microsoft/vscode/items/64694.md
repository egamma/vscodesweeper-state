# Issue #64694 — Allow to configure cursor keys for input fields

[https://github.com/microsoft/vscode/issues/64694](https://github.com/microsoft/vscode/issues/64694)

## Summary

The requested capability remains absent on current main, and this canonical Backlog request earned 36 community upvotes. Keep it open for implementation in the keybinding and shared input infrastructure.

## Change summary

Allow configurable cursor-navigation and text-editing commands to operate consistently in native input fields as well as editors.

## Best solution

Provide input-focused implementations of the generic cursor and editing commands for the active native input or textarea, while preserving existing editor behavior. Implement this centrally around the shared InputBox/keybinding infrastructure so find, search, Quick Open, and other inputs behave consistently.
