[https://github.com/microsoft/vscode/issues/343729](https://github.com/microsoft/vscode/issues/343729)

## Summary

The uncached-provider discovery gap remains in current main: Agent Host customization delivery reads existing MCP servers without activating lazy collections. The related management-UI issue and its open PR do not cover starting an Agent Host session without first opening MCP management.

## Change summary

Make extension-contributed MCP servers available to Agent Host sessions without requiring a native chat request or manual discovery command.

## Best solution

Ensure eligible extension MCP providers are discovered before Agent Host customization delivery, preserving access restrictions and server enablement. Coordinate with the existing management-UI PR, and decide separately whether the broader proposal to eagerly activate all agent-related extensions is warranted.
