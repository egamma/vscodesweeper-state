# Issue #343729 — Extension-contributed MCP servers are never activated in Agent Host (Copilot CLI) chat sessions

[https://github.com/microsoft/vscode/issues/343729](https://github.com/microsoft/vscode/issues/343729)

## Summary

The cold-start MCP discovery gap remains in current source: Agent Host customization delivery reads the existing server inventory without activating uncached extension collections. The related management-view issue and its open PR address a narrower entry point, not sessions started without opening that view.

## Change summary

Make extension-contributed MCP servers available to Agent Host sessions without first sending a local chat request or invoking a discovery command.

## Best solution

Ensure eligible extension MCP definitions are available for the first Agent Host customization delivery while preserving access controls and existing delivery rules. Coordinate with the management-view activation PR, and decide separately whether the requested blanket activation of all chat contribution types belongs in this change.
