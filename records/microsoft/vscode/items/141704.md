# Issue #141704 — Clipboard API parity

[https://github.com/microsoft/vscode/issues/141704](https://github.com/microsoft/vscode/issues/141704)

## Summary

This remains a useful clipboard-specific debt tracker: current main has gained image and custom-resource support, but substantial Electron parity and cross-browser limitations remain.

## Change summary

Track web clipboard permission workarounds, browser limitations, large-copy failures, and parity with Electron clipboard formats.

## Best solution

Keep this as the focused clipboard parity tracker under `editor-clipboard`, incrementally extending `IClipboardService` and `BrowserClipboardService` where web standards permit while retaining browser-specific fallbacks. The broader Chromium feedback issue should continue linking here rather than absorb its detailed clipboard work.

## Evidence
