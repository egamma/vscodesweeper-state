# Issue #274986 — Consolidate `ChatEditingSessionSubmitAction` and `ChatSubmitAction`

[https://github.com/microsoft/vscode/issues/274986](https://github.com/microsoft/vscode/issues/274986)

## Summary

The consolidation remains valid debt, but current main still uses the two actions for different chat modes. A maintainer explicitly deferred removal until participant detection and agentic Ask no longer require distinct submission behavior.

## Change summary

Consolidate the legacy editing-session submit action into the general chat submit action while retaining the old command ID as a keybinding compatibility alias.

## Best solution

Once Ask no longer needs distinct dispatch behavior, use one submit action across chat modes and preserve `workbench.action.edits.submit` only as a backward-compatible command alias.
