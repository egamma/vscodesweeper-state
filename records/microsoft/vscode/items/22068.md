# Issue #22068 — Investigate better UX for previewing things

[https://github.com/microsoft/vscode/issues/22068](https://github.com/microsoft/vscode/issues/22068)

## Summary

The central ask — an extension API for previewing derived content side-by-side within a single editor tab (with sync scrolling, shared lifecycle) — remains unimplemented on current main. SideBySideEditorInput exists internally but no public PreviewProvider-style API or extension surface has shipped. Keeping open.

## Change summary

Allow extensions to open a preview (webview or text) side-by-side with a source editor in a single tab, with synchronized scrolling and shared lifecycle.

## Best solution

Depends on progress in https://github.com/microsoft/vscode/issues/36700 (two distinct editors in one group). Once that lands, build a public extension API (e.g. PreviewProvider or a custom-editor variant) that lets extensions register a preview pane tied to a text document, supporting scroll sync and shared tab identity. The markdown extension would be the first consumer.
