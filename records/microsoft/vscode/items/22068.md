# Issue #22068 — Investigate better UX for previewing things

[https://github.com/microsoft/vscode/issues/22068](https://github.com/microsoft/vscode/issues/22068)

## Summary

Keep this preview-UX investigation open: current commands and custom-editor APIs do not deliver the requested native text editor plus synchronized preview in one logical tab. This is also a protected investigation/tracking item, with maintainer-supported work and 26 community upvotes.

## Change summary

Provide a unified source-and-preview editor with both views in one logical tab and coordinated scrolling, search, and restoration.

## Best solution

Define the supported composition and extension contract for a native text editor paired with a rendered or generated-resource preview in one logical workbench editor. Build on the existing side-by-side editor infrastructure without treating custom webviews or separate editor groups as equivalent coverage.
