# Issue #191688 — Current active presentation type is incorrect after changing display style 1st image.

[https://github.com/microsoft/vscode/issues/191688](https://github.com/microsoft/vscode/issues/191688)

## Summary

Keep open: current source can report a newly preferred presentation as “Currently Active” for an earlier image that has not been rerendered. This remains a concrete notebook-output state mismatch, and no verified older canonical or issue-linked fix was found.

## Change summary

Keep the notebook output presentation picker's active indicator consistent with the presentation actually rendered for each output.

## Best solution

In the notebook output view-model and presentation picker, distinguish each output's rendered MIME type and renderer from shared presentation preferences. Changing one output's presentation must not make another unchanged output claim that it is already using that presentation.
