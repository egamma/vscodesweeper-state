# Issue #248335 — Issues on vscode.typescript-language-features leaving spaces at the end of file

[https://github.com/microsoft/vscode/issues/248335](https://github.com/microsoft/vscode/issues/248335)

## Summary

The TypeScript formatter formats code structure (indentation, semicolons, braces) — it is not responsible for trimming trailing whitespace. That is a separate editor feature controlled by `files.trimTrailingWhitespace`, which defaults to `false` by design. The reporter identified this themselves in their comment.

## Change summary

Trailing spaces on the last line of a TypeScript file are not removed when formatting with the built-in TypeScript formatter.

## Best solution

This is working as designed: the TypeScript formatter handles code structure, not trailing whitespace removal. The existing `files.trimTrailingWhitespace` setting (set to `true`) is the correct mechanism for this. No code change is needed.
