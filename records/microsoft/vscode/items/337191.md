# Issue #337191 — Agent picker: cannot distinguish between custom agents sharing the same name across different scopes

[https://github.com/microsoft/vscode/issues/337191](https://github.com/microsoft/vscode/issues/337191)

## Summary

Real, well-scoped UX gap in the agent picker (identical entries for same-named agents in different scopes), and the reporter has already opened a matching draft PR implementing the fix — best next step is UX/maintainer review of that PR, not any triage close.

## Change summary

Custom agents with the same name from different scopes (workspace vs. user) appear as indistinguishable duplicate entries in the agent picker, with no scope grouping or label.

## Best solution

Review and land (or redirect) the author's draft PR https://github.com/microsoft/vscode/pull/326247, which groups agents in the picker by storage (Workspace/User/Plugins/Extensions) reusing the taxonomy from aiCustomizationListWidget.ts; the PR itself notes it is a draft awaiting UX/owner direction.
