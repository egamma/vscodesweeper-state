# Issue #333033 — Open Chat History and Sessions Together in a Separate Window

[https://github.com/microsoft/vscode/issues/333033](https://github.com/microsoft/vscode/issues/333033)

## Summary

The requested combination remains missing from the detached Chat editor: moving a conversation to another window does not bring its sessions/history pane along. The older related requests cover different observable workflows, so none establishes a duplicate under the re-review rules.

## Change summary

Allow the chat sessions/history pane and conversations to share a detached window for multi-monitor use.

## Best solution

Provide a detached Chat experience that retains the sessions list and opens selected conversations in that same window, without requiring interaction with the main window.

## Evidence

- **Existing command does not cover the request:** In src/vs/workbench/contrib/chat/browser/actions/chatMoveActions.ts, workbench.action.chat.openInNewWindow calls executeMoveToAction, which opens a session resource in AUX_WINDOW_GROUP with compact auxiliary-window options. It moves the conversation editor, not the containing Chat view or its sessions list.
- **Current host boundary:** src/vs/workbench/contrib/chat/browser/widgetHosts/editor/chatEditor.ts, ChatEditor.createEditor, constructs and renders a ChatWidget without an AgentSessionsControl. In contrast, src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatViewPane.ts creates the sessions control from renderBody at line 413, with createSessionsControl defined at line 877. The detached-editor path therefore does not deliver the central ask.
- **Older related request is a different workflow:** https://github.com/microsoft/vscode/issues/319877 is open and predates this report, but requests opening sessions from the dedicated Agents window in additional full Agents windows. It does not report the missing history pane in a detached workbench Chat editor, so it does not meet the same-observable-symptom requirement for this re-reviewed item.
- **General detachment request is related, not a verified canonical:** https://github.com/microsoft/vscode/issues/193267 is open and older, but its body explicitly scopes the request to detaching bottom panels. Its discussion mentions detached Chat as an existing capability rather than identifying the missing sessions/history pane; it does not establish ownership of this report's specific remaining work.
- **Other sessions-layout request differs:** https://github.com/microsoft/vscode/issues/293630 is open and older, but asks to retain the sessions bar while disabling or unlinking the Chat pane—the opposite layout relationship from taking both together into a detached window.
- **Historical history-menu issue is not coverage:** https://github.com/microsoft/vscode/issues/275398 concerned history selections opening in the main window. Its final comment, https://github.com/microsoft/vscode/issues/275398#issuecomment-3591123910, states that history was removed from chat editors; that does not implement a detached sessions/history pane.
