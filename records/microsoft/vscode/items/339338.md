# Issue #339338 — Comment widget code-range highlight obscures editor selection

[https://github.com/microsoft/vscode/issues/339338](https://github.com/microsoft/vscode/issues/339338)

## Summary

The defect remains in the checked-out source for the built-in Light 2026 theme: both comment-range backgrounds are opaque and paint over editor selections. Keep this open for a bounded theme correction.

## Change summary

Keep editor selections visible where they overlap an expanded comment thread's highlighted code range.

## Best solution

Ensure both inactive and active comment-range highlights in Light 2026 preserve the underlying selection while remaining distinguishable. Preserve existing comment interactions and editor overlay ordering.
