# Issue #339338 — Comment widget code-range highlight obscures editor selection

[https://github.com/microsoft/vscode/issues/339338](https://github.com/microsoft/vscode/issues/339338)

## Summary

The reported overlap is supported by current source: Light 2026 supplies opaque comment-range backgrounds, and those decorations render above editor selections. Keep this open for a bounded theme correction.

## Change summary

Keep editor selections visible when they overlap a comment widget's highlighted code range.

## Best solution

Make the built-in Light 2026 comment-range colors translucent while retaining distinguishable ordinary and active highlights. Preserve the editor's existing selection and decoration ordering.
