# Issue #327033 — `Try free` button does nothing without Stable installed

[https://github.com/microsoft/vscode/issues/327033](https://github.com/microsoft/vscode/issues/327033)

## Summary

Valid bug: the VS Code website 'Try Free' button only attempts the `vscode://` protocol handler, which fails silently when only Insiders is installed. The fix likely belongs on the website side (fallback to `vscode-insiders://`) or as a dual-scheme registration in the Insiders product.

## Change summary

The 'Try Free' button on the VS Code website does nothing when only VS Code Insiders is installed because it only invokes the `vscode://` protocol handler.

## Best solution

The website should attempt both `vscode://` and `vscode-insiders://` handlers (or detect which is available), or alternatively VS Code Insiders could additionally register the `vscode://` scheme. The website fix is likely owned by a different repo (vscode-website or similar).
