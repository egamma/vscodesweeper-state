# Issue #343918 — Both tabbing and arrow keys navigate to the `x` button in the workspace picker

[https://github.com/microsoft/vscode/issues/343918](https://github.com/microsoft/vscode/issues/343918)

## Summary

The current source confirms that Tab and horizontal arrow navigation both include the workspace clear button. Keep this team-authored report open: no referencing fix was found, and the related report does not cover the same full navigation expectation.

## Change summary

Tab should advance between picker controls without stopping on the workspace clear button, while horizontal arrows should retain access to that button.

## Best solution

Give the workspace picker distinct Tab and arrow navigation behavior in the Sessions composer, preserving keyboard access to clearing the workspace and existing focus restoration.
