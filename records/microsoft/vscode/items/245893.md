# Issue #245893 — Text to speech very verbose

[https://github.com/microsoft/vscode/issues/245893](https://github.com/microsoft/vscode/issues/245893)

## Summary

Still valid on main: when TTS reads chat responses referencing notebook cells, it reads verbose cell IDs and source code rather than just the concise visible text. A contributor acknowledged the issue but no fix has landed.

## Change summary

Text-to-speech reads verbose notebook cell IDs and source code from chat responses instead of just the visible summary text.

## Best solution

Improve the aria labels and/or TTS content extraction for notebook cell references in chat responses so that only the concise visible label (e.g. 'filename • cell 3') is read aloud, not raw cell URIs or source code. The fix likely involves `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatInlineAnchorWidget.ts` and possibly the TTS content extraction logic.
