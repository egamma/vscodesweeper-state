# Issue #305725 — auto-deny output to dev null

[https://github.com/microsoft/vscode/issues/305725](https://github.com/microsoft/vscode/issues/305725)

## Summary

Keep open: another user independently reports resolving the approval prompts with a /dev/null edit-approval override. Current source already exempts ordinary null-device redirections, but that does not establish that the reported approval path is fixed.

## Change summary

Prevent harmless terminal output redirection to /dev/null from requiring repeated approval solely because of its destination.

## Best solution

Identify which approval check produces the reported denial and ensure genuine null-device redirections honor the intended exemption without approving otherwise-denied commands. Preserve explicit file-write restrictions and distinguish informational destination notices from the actual reason approval is required.
