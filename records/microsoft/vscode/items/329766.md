# Issue #329766 — Markdown Preview - Extend options to Open Preview to the Left & Right (auto splitting the panes)

[https://github.com/microsoft/vscode/issues/329766](https://github.com/microsoft/vscode/issues/329766)

## Summary

Keep open as a feature request: opening a Markdown preview alongside the source already exists, but the requested context-menu choices for all four directions do not. No verified canonical issue owns this specific interaction.

## Change summary

Add left, right, above, and below Markdown preview actions to the open file's context menu, creating the adjacent pane automatically.

## Best solution

Provide directional preview placement through the Markdown editor-tab context menu, consistent with the workbench's existing split interactions. Preserve the existing in-place and Open Preview to the Side commands.

  > Thanks for the request. Markdown already offers Open Preview to the Side (`markdown.showPreviewToSide`) through the editor toolbar and Command Palette; `workbench.editor.openSideBySideDirection` selects right or below. Those options do not cover choosing all four directions from the editor-tab context menu, so this remains a feature request.
