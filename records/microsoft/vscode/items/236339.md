# Issue #236339 — Add option to ignore URL in link in text-to-speech

[https://github.com/microsoft/vscode/issues/236339](https://github.com/microsoft/vscode/issues/236339)

## Summary

Current text-to-speech already reads a Markdown link's visible label without its destination URL, so a separate option is unnecessary.

## Change summary

Add a text-to-speech option that suppresses hyperlink destination URLs.

## Best solution

Keep the existing plaintext conversion, which always excludes Markdown link destinations. Any current case that still speaks a hidden destination should be reported separately with the exact generated Markdown.

- **Proposed comment:**

  > Thanks for the request. Current chat text-to-speech converts Markdown to plaintext before synthesis, and hyperlink destinations are intentionally omitted: `[Go to Github Gists](https://gist.github.com/)` is spoken as “Go to Github Gists.” This is also covered by the Markdown plaintext-renderer test, and the latest investigation observes that behavior. A separate setting is therefore not needed. If a hidden destination is still spoken on the latest build, please open a focused bug with the exact Markdown response that triggers it.
