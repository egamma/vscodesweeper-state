## Summary

Keep this accepted Backlog request open: ordinary Markdown hyperlinks already speak only their labels, consistent with the contributor's observation, but links inside lists can still retain their URLs. Existing behavior therefore only partially covers the request, and no verified canonical or complete fix was found.

## Change summary
