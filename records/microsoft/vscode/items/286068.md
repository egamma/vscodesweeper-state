# Issue #286068 — Terminal suggest status doesn't respect keybindings customizations

[https://github.com/microsoft/vscode/issues/286068](https://github.com/microsoft/vscode/issues/286068)

## Summary

The terminal suggestion status still hardcodes Tab in its labels and tooltips on current main. The linked PR was closed without merging, and its review explicitly requires retaining useful keybinding hints rather than removing them.

## Change summary

Terminal suggestion status labels and help text should reflect customized acceptance keybindings instead of naming the default Tab binding.

## Best solution

Show the effective suggestion-acceptance keybindings in the terminal selection-mode status label and tooltip, preserving the explanatory distinction between selection modes. Honor the review direction on the closed PR without changing suggestion acceptance or selection semantics.
