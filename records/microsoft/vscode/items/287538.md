# Issue #287538 — Default node_modules glob for worktrees does not copy .bin

[https://github.com/microsoft/vscode/issues/287538](https://github.com/microsoft/vscode/issues/287538)

## Summary

Keep open pending a focused Windows/WSL retest: worktree inclusion now uses Git ignore syntax instead of the original glob matcher, so the reported pattern no longer has the same meaning. The supplied xterm.js scenario is sufficient to retest, but source inspection does not establish whether the missing .bin entries are resolved.

## Change summary

Copying ignored node_modules into a new worktree should include node_modules/.bin and its executable links or shims.

## Best solution

Establish whether the current Git-based inclusion path copies a complete node_modules tree, including usable .bin entries, on Windows and WSL with the supported node_modules/ pattern. If the omission remains, address the confirmed selection or copying defect in the built-in Git extension without changing tracked-file collision protection.
