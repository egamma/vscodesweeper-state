# Issue #90874 — Parameter hints should not use aria.alert

[https://github.com/microsoft/vscode/issues/90874](https://github.com/microsoft/vscode/issues/90874)

## Summary

Still open on main: parameterHintsWidget.ts line 261 still uses aria.alert() instead of activeDescendant. The prior PR #93606 was closed without merging due to an NVDA bug. The issue remains valid accessibility debt.

## Change summary

Parameter hints use aria.alert instead of activeDescendant, causing poor screen reader UX (duplicate filtering, no pauses, non-focusable).

## Best solution

Implement the activeDescendant approach (as prototyped in the closed PR #93606) in src/vs/editor/contrib/parameterHints/browser/parameterHintsWidget.ts, mirroring how the suggest widget handles it. The blocking NVDA issue (nvaccess/nvda#10887) about editor aria-label re-reading on widget close should be re-evaluated — it may be resolved in newer NVDA versions.
