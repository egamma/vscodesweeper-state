# Issue #90874 — Parameter hints should not use aria.alert

[https://github.com/microsoft/vscode/issues/90874](https://github.com/microsoft/vscode/issues/90874)

## Summary

Keep open: current parameter hints still announce through aria.alert, and the proposed replacement was never merged. The maintainer explicitly deferred it because dismissing an active descendant can cause disruptive editor re-announcements; that prerequisite remains open.

## Change summary

Replace parameter hints' alert-based announcements with an accessible active-descendant relationship, without introducing dismissal-related speech regressions.

## Best solution

Provide navigable parameter-hint content through the editor's accessibility relationship while preserving typing focus and avoiding editor title/content re-announcements on dismissal. First establish whether the blocker tracked in https://github.com/microsoft/vscode/issues/89098 can now be addressed across supported screen readers.
