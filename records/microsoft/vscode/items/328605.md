# Issue #328605 — [Bug] Custom AI models configured in Copilot Chat Agent interface are not selectable or persist incorrectly

[https://github.com/microsoft/vscode/issues/328605](https://github.com/microsoft/vscode/issues/328605)

## Summary

A VS Code team member (vritant24) confirmed the reported behavior is by design: BYOK/custom models work correctly in the Local harness (once `chat.agentHost.byokModels.enabled` is set), but are not yet supported when the Agent Host runs remotely, since the remote host currently has no extension host to serve BYOK model providers.

## Change summary

Custom (BYOK) models configured for the Copilot Agent chat don't appear or persist in the model dropdown when running in a remote (WSL) context.

## Best solution

Current behavior is intentional given the remote Agent Host's lightweight architecture (no extension host); the team is actively working on remote BYOK/custom-endpoint support as a future enhancement, but there's no concrete fix to point to yet, so close this report as as-designed and let the team track remote support separately when it lands.
