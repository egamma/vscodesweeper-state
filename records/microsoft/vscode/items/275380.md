# Issue #275380 — Chat Terminal Widget - Some of terminal input is sometimes unexpectedly shown together with terminal output

[https://github.com/microsoft/vscode/issues/275380](https://github.com/microsoft/vscode/issues/275380)

## Summary

Team-authored bug still open — no commit references this issue, and the underlying ConPTY marker-position race on Windows appears unresolved on current main. The chat terminal command mirror relies on `executedMarker` to separate input from output, but ConPTY can shift marker positions when the terminal starts hidden, causing input text to leak into the captured output range.

## Change summary

Chat terminal output widget sometimes includes parts of the terminal command input in its output display, particularly when the Copilot terminal panel starts hidden on Windows.

## Best solution

Investigate whether the `executedMarker` line position can be validated or adjusted when the terminal becomes visible after a command has already been executed while hidden. The fix likely lives in `src/vs/workbench/contrib/terminal/browser/chatTerminalCommandMirror.ts` around the output extraction logic using `executedMarker`. If ConPTY cannot be made reliable here, a heuristic to strip recognized command prefixes from the output range may be needed.
