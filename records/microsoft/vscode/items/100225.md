# Issue #100225 — Data corruptted when pasting large JSON in the terminal (or via sendText)

[https://github.com/microsoft/vscode/issues/100225](https://github.com/microsoft/vscode/issues/100225)

## Summary

Still reproduces on current main: the macOS PTY 1024-byte canonical-mode input buffer corruption remains unaddressed after the chunking fix (eb7e1c7cb89) was reverted (f144e450250). The most recent comment (July 2026) confirms the issue persists at 1.129.

## Change summary

Pasting multiline text >1 KB into the integrated terminal on macOS corrupts the data due to PTY canonical-mode buffer backpressure.

## Best solution

Re-implement chunked writes for multiline PTY input on macOS in `src/vs/platform/terminal/node/terminalProcess.ts` — the reverted approach (512-byte chunks with 5ms pauses) had the right diagnosis but presumably caused regressions that led to the revert. A more robust chunking or flow-control mechanism is needed, possibly gated on detecting non-bracketed-paste mode.
