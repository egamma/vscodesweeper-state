# Issue #331287 — Search doesn't start from where my view is

[https://github.com/microsoft/vscode/issues/331287](https://github.com/microsoft/vscode/issues/331287)

## Summary

Team-authored bug report from testing the new chat-transcript Find widget (issue #330953's test plan); traced in the current source and still open, so it stays open regardless of confidence — team-authored items are protected from judgment closes and there's no fix commit citing this issue.

## Change summary

When opening Find in the chat transcript and typing a query, the active match always jumps to match 1 instead of the match nearest the currently visible viewport.

## Best solution

In ChatFindModel.recompute() (chatFindModel.ts), when there is no previous anchor, pick the initial active match nearest the currently visible transcript range instead of hardcoding index 0 — this requires the IChatFindHost (chatFindWidget.ts) to expose the visible item range/scrollTop from ChatWidget (chatWidget.ts, which already tracks `scrollTop` and the underlying list) so the model can anchor to it.
