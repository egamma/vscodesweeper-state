# Issue #246197 — [‎KeybindingsSearchWidget‎] keybinding definition widget affected by IME

[https://github.com/microsoft/vscode/issues/246197](https://github.com/microsoft/vscode/issues/246197)

## Summary

Still reproduces on main: the keybinding recording widget in the Keyboard Shortcuts editor does not filter out IME composition events, so activating an IME records spurious 'keyincomposition'/'unknown' chords.

## Change summary

The keybinding definition widget records IME composition keydown events as keybinding chords instead of ignoring them.

## Best solution

Add an `event.isComposing` guard at the top of `_onKeyDown` in `src/vs/workbench/contrib/preferences/browser/keybindingWidgets.ts` (similar to the guard in `keyboardLayoutService.ts:355`) so that composition events are silently ignored by the recording widget.
