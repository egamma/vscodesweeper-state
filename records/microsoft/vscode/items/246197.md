# Issue #246197 — [‎KeybindingsSearchWidget‎] keybinding definition widget affected by IME

[https://github.com/microsoft/vscode/issues/246197](https://github.com/microsoft/vscode/issues/246197)

## Summary

The recording widget still treats IME composition events as shortcut chords, explaining the reported keyincomposition and Unknown output. Keep this open in keybindings-editor; no verified older duplicate or fixing commit was found.

## Change summary

Prevent switching into IME mode in the keybinding definition widget from recording composition markers as shortcut keys.

## Best solution

The keybinding recorder should leave the current shortcut unchanged for IME-owned composition events while continuing to record ordinary shortcuts and handle its existing confirmation and cancellation controls.
