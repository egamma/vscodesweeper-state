# Issue #297574 — Browser tools miss accessibility snapshot

[https://github.com/microsoft/vscode/issues/297574](https://github.com/microsoft/vscode/issues/297574)

## Summary

Still open on main: the `readPage` tool already uses Playwright's `ariaSnapshot` internally, but its name and model description don't surface its accessibility-snapshot capability, so agents asked to do a11y audits don't discover or use it. No commit references this issue.

## Change summary

Browser tools lack an explicitly named accessibility/aria snapshot tool, so agents don't use them for a11y audits even though the underlying `ariaSnapshot` call exists.

## Best solution

Either expose a dedicated `accessibilitySnapshot` / `ariaSnapshot` tool (or alias) alongside `readPage`, or update the `readPage` model description to explicitly mention aria/accessibility snapshot capabilities so agents discover it for a11y audit tasks. The relevant files are the tool registration in `src/vs/workbench/contrib/browserView/electron-browser/tools/readBrowserTool.ts` and the reference names in `src/vs/platform/browserView/common/browserChatToolReferenceNames.ts`.
