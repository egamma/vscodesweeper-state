# Issue #185696 — Saving creates "end of file" issues

[https://github.com/microsoft/vscode/issues/185696](https://github.com/microsoft/vscode/issues/185696)

## Summary

The supplied files identify automatic line-ending normalization as the cause: literal carriage returns inside comments become newlines, exposing unmatched shell quotes. The verified open issue https://github.com/microsoft/vscode/issues/127 already owns preserving mixed line endings and embedded carriage returns.

## Change summary

Preserve embedded carriage returns when editing and saving shell scripts so an unrelated comment edit does not break shell syntax.

## Best solution

Consolidate this concrete shell-script failure under https://github.com/microsoft/vscode/issues/127, preserving the attachments as evidence for the broader line-ending preservation work.
