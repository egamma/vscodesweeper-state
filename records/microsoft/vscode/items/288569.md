# Issue #288569 — Disabling Search on Type still allows search results to be updated when editing files containing results

[https://github.com/microsoft/vscode/issues/288569](https://github.com/microsoft/vscode/issues/288569)

## Summary

Keep open for a search-owner decision: disabling Search on Type controls query-input searches, while existing result files independently refresh on edits. The requested ability to stop those refreshes remains missing; the existing bug triage rules out an as-designed decline.

## Change summary

Allow search results to remain unchanged when matching files are edited and Search on Type is disabled.

## Best solution

Decide whether manual-refresh results should be supported in the Search view and whether that behavior belongs under search.searchOnType or a separate control. Preserve the existing live-update default and accurate result navigation and replacement behavior.
