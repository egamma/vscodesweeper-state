# Issue #340574 — @mentioning agent in chat keeps failing. Getting "The selected model 'agent-host-copilotcli:gpt-5.6-sol' is not available. Select a different model and try again."

[https://github.com/microsoft/vscode/issues/340574](https://github.com/microsoft/vscode/issues/340574)

## Summary

Thanks for the report. When an extension-contributed chat participant (@learn-authoring-assistant) receives a user-selected model with an agent-host vendor id, it fails with 'selected model ... is not available'. This is a real chat/extension-API gap that needs a chat owner to look at it, so it stays open.

## Change summary

A third-party chat participant fails with 'selected model agent-host-copilotcli:<id> is not available' when the agent-host model is selected, and the model choice does not persist across restarts.

## Best solution

Make getLanguageModelForRequest resolve agent-host vendor models, or fall back to a model that extension participants can use. Also fix persistence of the 'Auto' model selection across reloads, which is likely a separate issue.
