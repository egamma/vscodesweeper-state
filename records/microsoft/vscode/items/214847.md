# Issue #214847 — npm.runSelectedScript does not work as expected

[https://github.com/microsoft/vscode/issues/214847](https://github.com/microsoft/vscode/issues/214847)

## Summary

The `npm.runSelectedScript` command is designed to work from an active text editor (finding a script at the cursor in a `package.json`), not from the npm tree view — the error message is correct behavior. The tree view uses `npm.runScript` instead, which accepts a tree node argument.

## Change summary

User expects `npm.runSelectedScript` to run the focused item in the npm tree view, but it only works from a text editor cursor position in a package.json file.

## Best solution

The user should bind their key to `npm.runScript` scoped to the npm view, not `npm.runSelectedScript`. The command naming is admittedly confusing ('selected' sounds like it could mean 'selected in the tree'), but the implementation has been editor-based since its introduction. If improved UX is desired, a separate feature request for a tree-view-aware run-on-enter keybinding would be more appropriate.
