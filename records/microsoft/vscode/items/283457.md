# Issue #283457 — Restart extensions isn't properly updating extension configuration

[https://github.com/microsoft/vscode/issues/283457](https://github.com/microsoft/vscode/issues/283457)

## Summary

The bug remains present on current main: an extension update received while that extension is active is discarded, and Restart Extension Host does not retry the updated manifest, leaving newly contributed configuration unavailable until a window reload.

## Change summary

Restarting extension hosts after upgrading an extension should register new configuration settings and their defaults without requiring a window reload.

## Best solution

Preserve extension updates that cannot be applied while an extension is active, then apply their manifest and extension-point deltas after the hosts stop and before they restart.
