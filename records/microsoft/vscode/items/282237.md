# Issue #282237 — Cannot Fetch Extensions or Create Conda Environments – net::ERR_PROXY_CONNECTION_FAILED (Only on My User Profile)

[https://github.com/microsoft/vscode/issues/282237](https://github.com/microsoft/vscode/issues/282237)

## Summary

The diagnostic output identifies user-environment proxy variables pointing to an unresolvable proxy host, so this is a resolved configuration-support question rather than a VS Code defect.

## Change summary

Restore network access for Marketplace, Settings Sync, and environment creation when one Windows user profile forces an invalid proxy.

## Best solution

Remove or correct the user-scoped HTTP_PROXY and HTTPS_PROXY environment variables, then fully restart VS Code so its processes inherit the updated environment.
