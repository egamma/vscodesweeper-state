# Issue #205259 — RTL: WTF! Code is Reversed!

[https://github.com/microsoft/vscode/issues/205259](https://github.com/microsoft/vscode/issues/205259)

## Summary

This is a specific manifestation of RTL rendering problems — RTL text reversed when font ligatures are enabled — which is covered by the canonical RTL support tracking issue. Significant RTL rendering work has landed on main since the report (unicode-bidi:isolate, dir handling, RTL decoration support), though the exact interaction with ligatures may still be imperfect. The canonical issue absorbs this report.

## Change summary

RTL text (Persian/Arabic) in string literals is rendered reversed when `editor.fontLigatures` is enabled, affecting multiple ligature-capable fonts (JetBrains Mono, Fira Code).

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/86667, which tracks comprehensive RTL language support including rendering correctness. Multiple RTL rendering improvements have landed on main since this report (commits 4846a428224, 18554b91593, 0d821c6f640, 156feae740c) that may have improved or resolved this specific case.
