# Issue #345586 — Unable to exclude !bang.txt in files.exclude

[https://github.com/microsoft/vscode/issues/345586](https://github.com/microsoft/vscode/issues/345586)

## Summary

The escaped leading bang does not match in the Explorer's current glob parser, while an existing brace escape supports literal-bang filenames. Keep this team-authored report open to resolve the escaping discrepancy; the workaround does not establish a fix for the reported syntax.

## Change summary

Make literal leading-bang exclusions behave consistently between files.exclude and search.exclude.

## Best solution

Establish a consistent, documented literal-bang escaping contract for Explorer and Search exclusions. The existing "{!}bang.txt" pattern provides an Explorer workaround while maintainers decide whether backslash escaping should also be supported.
