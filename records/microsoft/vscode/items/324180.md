# Issue #324180 — Extension Signature Verification Failed: Vue (Official), Codex & Claude

[https://github.com/microsoft/vscode/issues/324180](https://github.com/microsoft/vscode/issues/324180)

## Summary

This is a NixOS packaging defect rather than a VS Code extension-signature bug: Nixpkgs modified the self-integrity-checked `vsce-sign` executable, causing error 159 for every extension. The downstream fix has merged, but upstream-owned issues stay open pending rollout and confirmation.

## Change summary

Installing or updating any Marketplace extension fails signature verification with `UnknownError`, internal code 159, in NixOS-packaged VS Code.

## Best solution

NixOS packages should include https://github.com/NixOS/nixpkgs/commit/0f60456d2f1964ffe4ad2d2a6e4d1bb1e4977441 and preserve the original `vsce-sign` executable except for the required OpenSSL linkage. No VS Code core change is indicated; confirm the corrected NixOS package resolves installation before retiring this report.
