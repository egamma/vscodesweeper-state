# Issue #339377 — `code --update-extensions` is a no-op in a remote SSH workspace

[https://github.com/microsoft/vscode/issues/339377](https://github.com/microsoft/vscode/issues/339377)

## Summary

Keep open: the current remote CLI accepts --update-extensions but drops the update operation before sending its IPC request, conclusively explaining the successful no-op and null output. This is a defect in VS Code's core remote CLI, not an issue to transfer to the Remote-SSH extension.

## Change summary

Make code --update-extensions update remote-installed extensions, report the outcome, and return a nonzero exit status when updating fails.

## Best solution

Complete the update operation across the remote CLI, extension-host pipe, and workbench extension-management command, using the existing extension update functionality. Preserve remote targeting and existing list/install/uninstall behavior while making update failures observable to scripts.
