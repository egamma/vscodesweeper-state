# Issue #339377 — `code --update-extensions` is a no-op in a remote SSH workspace

[https://github.com/microsoft/vscode/issues/339377](https://github.com/microsoft/vscode/issues/339377)

## Summary

The remote CLI explicitly accepts --update-extensions but drops the operation before sending its IPC request, conclusively explaining the successful no-op and null output on current main. Keep this open as a core extension-management bug; the existing extensions area label is appropriate.

## Change summary

Make code --update-extensions update remote extensions, report meaningful results, and return a nonzero exit status when the update fails.

## Best solution

The remote terminal CLI should provide the same bulk-update capability as the standalone extension-management CLI, targeting the remote installation and reporting success, no available updates, or failure accurately. Preserve existing list, install, and uninstall behavior.
