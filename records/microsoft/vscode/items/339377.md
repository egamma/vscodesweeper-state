# Issue #339377 — `code --update-extensions` is a no-op in a remote SSH workspace

[https://github.com/microsoft/vscode/issues/339377](https://github.com/microsoft/vscode/issues/339377)

## Summary

Thanks for the detailed report. This reproduces from source: the remote `code` CLI never forwards `--update-extensions` to the window that handles it, so nothing is updated.

## Change summary

`code --update-extensions` run from a remote SSH terminal does nothing and prints an empty result.

## Best solution

Forward an `update` flag through the remote CLI pipe, handle it in `_remoteCLI.manageExtensions` by calling `cliService.updateExtensions()`, and surface errors from that call in the returned output.
