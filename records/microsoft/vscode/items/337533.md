# Issue #337533 — Don't animate when asking a question

[https://github.com/microsoft/vscode/issues/337533](https://github.com/microsoft/vscode/issues/337533)

## Summary

Current main explicitly animates the ask-question and waiting-for-answer progress text, confirming the distracting motion remains. The requested static waiting state is bounded chat UI polish and should stay open.

## Change summary

Stop animating chat progress text while the agent is asking a question or waiting for the user's answer.

## Best solution

Keep ask-question and waiting-for-answer rows visually static while preserving progress animation for genuine model or tool activity outside that user-blocked state.
