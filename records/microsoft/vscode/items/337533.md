# Issue #337533 — Don't animate when asking a question

[https://github.com/microsoft/vscode/issues/337533](https://github.com/microsoft/vscode/issues/337533)

## Summary

Team-authored design feedback filed by a maintainer with a video showing the chat pet's 'clapping' animation firing while the agent is waiting on a confirmation/question — real UX concern, but stays open since it's a maintainer's own report and the exact replacement behavior isn't decided yet.

## Change summary

The chat pet plays an attention-grabbing 'clapping' animation while it's waiting for the user to answer a question/confirmation, which the reporter finds too distracting.

## Best solution

Have the pet settle into a calmer pose (or skip animating) for the pending-confirmation state in getChatPetBaseState, rather than immediately clapping — exact target pose/animation is a design call best paired with the chat-pet-sprite-creation work.
