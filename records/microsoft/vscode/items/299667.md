# Issue #299667 — "bypass approvals" should be per-session

[https://github.com/microsoft/vscode/issues/299667](https://github.com/microsoft/vscode/issues/299667)

## Summary

Current main reads and writes approval mode through the active session, but the report is team-authored and no explicitly linked fixing commit establishes completion. Keep it open until the remaining global default/remembered-value semantics are decided and session switching is regression-tested.

## Change summary

Changing one agent session to bypass approvals unexpectedly makes another session appear to use the same elevated approval mode.

## Best solution

Keep each existing session's approval value independent while treating any profile-level setting only as an explicit default for newly created sessions. Add a regression test that switches between sessions with different approval values, and settle whether an elevated selection should be remembered for future sessions given the enterprise-policy implications raised in the thread.
