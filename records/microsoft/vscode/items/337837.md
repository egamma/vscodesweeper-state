# Issue #337837 — Closing a folder changes profile

[https://github.com/microsoft/vscode/issues/337837](https://github.com/microsoft/vscode/issues/337837)

## Summary

The report describes a plausible profile-selection bug, but the stated steps do not identify the condition that makes it intermittent. Current source normally inherits the active window's profile, while multiple windows or `window.newWindowProfile` can affect that selection, so those details are needed before the failure can be confirmed.

## Change summary

Closing an opened folder intermittently switches the reused window away from its selected profile, often to the Default profile.

## Best solution

Confirm whether profile selection during Close Workspace is derived from the wrong window or overridden by `window.newWindowProfile`, then preserve the closing window's current profile when it is reused as an empty window.
