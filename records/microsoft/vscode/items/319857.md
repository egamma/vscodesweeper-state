## Summary

The requested discoverability improvement remains missing: the Repositories title menu offers reopening previously closed repositories, but not opening an arbitrary repository. Keep this request open for a Source Control UX decision; the older related menu requests do not cover the same behavior.

Expose the existing Git: Open Repository flow from the Source Control Repositories view title or its overflow menu.
