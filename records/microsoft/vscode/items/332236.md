# Issue #332236 — WebviewPanel: expose tooltip property on panel tab (like editor tabs for files)

[https://github.com/microsoft/vscode/issues/332236](https://github.com/microsoft/vscode/issues/332236)

## Summary

Legitimate, unimplemented API gap: WebviewPanel has no equivalent to the automatic full-path tooltip editors get, nor a description/tooltip property like TreeItem or StatusBarItem. Freshly filed with no maintainer response yet, so this stays open for area triage rather than any close.

## Change summary

Add a tooltip or description property to WebviewPanel so extensions can show extra context on tab hover, mirroring editor tabs' file-path tooltip.

## Best solution

Add an optional `description`/`tooltip` string property to the `WebviewPanel` API (vscode.d.ts) surfaced on the editor tab's hover text, alongside the existing `title`/`iconPath` properties — a small, additive API surface consistent with how `TreeItem`/`StatusBarItem` already expose description/tooltip.
