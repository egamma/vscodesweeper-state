# Issue #292392 — Open associated workspace / repo with recent session

[https://github.com/microsoft/vscode/issues/292392](https://github.com/microsoft/vscode/issues/292392)

## Summary

Keep open: the welcome page's recent-session click path opens chat history without opening the associated workspace or repository. No verified older canonical or issue-referencing fix was found; this team-authored request still identifies a meaningful workflow gap.

## Change summary

Clicking a recent agent session on the welcome page should reopen its associated workspace or repository alongside its chat history.

## Best solution

Make resuming a session from the welcome page restore both its development context and conversation. Settle window-reuse behavior and the treatment of unavailable or nonlocal repositories before implementing workspace restoration.
