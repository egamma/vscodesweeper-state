# Issue #254407 — Git - git.detectSubmodules is not honored

[https://github.com/microsoft/vscode/issues/254407](https://github.com/microsoft/vscode/issues/254407)

## Summary

Keep open: current workspace scanning still opens submodules without honoring git.detectSubmodules=false. The previously merged fix was reverted because it also prevented explicitly opened worktrees from appearing in Source Control.

## Change summary

Honor git.detectSubmodules=false when automatically discovering submodules while opening a saved workspace.

## Best solution

Make automatic workspace discovery respect the submodule detection setting while preserving explicitly opened repositories, including worktree workspace roots. Cover both the original saved-workspace reproduction and the regression that forced the revert.
