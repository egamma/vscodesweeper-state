# Issue #332732 — Markdown Editor (rich webview editor) ignores font size: uses var(--markdown-font-size) but never receives it

[https://github.com/microsoft/vscode/issues/332732](https://github.com/microsoft/vscode/issues/332732)

## Summary

Keep open: the rich Markdown editor still lacks configurable text size. The existing font settings explicitly target Markdown Preview, so the remaining work needs a decision about sharing those settings or exposing editor-specific controls.

## Change summary

Allow users to configure text size in the built-in rich Markdown editor without resizing the entire workbench.

## Best solution

Provide resource-scoped font-size configuration for the rich Markdown editor, applied when opening a document and when configuration changes. The Markdown owner should decide whether preview and editor typography share settings; custom stylesheet injection and mouse-wheel zoom remain separate requests.
