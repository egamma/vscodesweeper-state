# Issue #332732 — Markdown Editor (rich webview editor) ignores font size: uses var(--markdown-font-size) but never receives it

[https://github.com/microsoft/vscode/issues/332732](https://github.com/microsoft/vscode/issues/332732)

## Summary

Traced and confirmed on main: the Markdown Editor webview never receives the `--markdown-font-size` CSS variable its bundled stylesheet consumes, so `markdown.preview.fontSize` (and the preview) work but the rich editor is stuck at the hardcoded 14px fallback.

## Change summary

The built-in rich Markdown Editor ignores `markdown.preview.fontSize` (and font-family/line-height) because the CSS variable its stylesheet references is never injected into the webview.

## Best solution

Extend `MarkdownEditorInitialState` (extensions/markdown-language-features/src/preview/webviewInitialState.ts) and `#getHtml` in markdownEditorProvider.ts to inject `--markdown-font-size` (and ideally `--markdown-font-family`/`--markdown-line-height`) as an inline style on `#getHtml`'s root element, mirroring how documentRenderer.ts already does it for the preview — this makes the existing `markdown.preview.fontSize` setting apply to the editor immediately with no new setting needed.
