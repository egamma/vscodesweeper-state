# Issue #332732 — Markdown Editor (rich webview editor) ignores font size: uses var(--markdown-font-size) but never receives it

[https://github.com/microsoft/vscode/issues/332732](https://github.com/microsoft/vscode/issues/332732)

## Summary

Confirmed on main: the new Markdown Editor webview never injects `--markdown-font-size` (or `--markdown-line-height` / `--markdown-font-family`), while the sibling Markdown preview does the equivalent via `MarkdownPreviewConfiguration` + `#getSettingsOverrideStyles`, so `markdown.preview.fontSize` (and related settings) silently have no effect on the new editor.

## Change summary

The rich webview Markdown Editor ignores `markdown.preview.fontSize` (and line-height/font-family), always rendering at the CSS default because the HTML template never sets the `--markdown-font-size` variable its stylesheet consumes.

## Best solution

In `MarkdownEditorProvider#getHtml` (extensions/markdown-language-features/src/preview/markdownEditorProvider.ts), build the same settings-derived inline style used by `MarkdownContentProvider#getSettingsOverrideStyles` in documentRenderer.ts and apply it to the `<html>` tag, so the editor picks up the existing `markdown.preview.fontSize`/`fontFamily`/`lineHeight` settings the same way the preview does.
