# Issue #332732 — Markdown Editor (rich webview editor) ignores font size: uses var(--markdown-font-size) but never receives it

[https://github.com/microsoft/vscode/issues/332732](https://github.com/microsoft/vscode/issues/332732)

## Summary

Confirmed in source: the rich Markdown Editor's HTML builder never injects the `--markdown-font-size` (or `--markdown-line-height`/`--markdown-font-family`) CSS variables that its own stylesheet expects, unlike the Markdown preview which does this via `#getSettingsOverrideStyles`. Real, localized bug worth fixing.

## Change summary

The built-in rich Markdown Editor ignores `markdown.preview.fontSize` (and line-height/font-family) because it never passes those values into the webview, unlike the classic Markdown preview.

## Best solution

In `MarkdownEditorProvider#getHtml` (extensions/markdown-language-features/src/preview/markdownEditorProvider.ts), reuse `MarkdownPreviewConfiguration.getForResource(document.uri)` (as `documentRenderer.ts` already does) and inject the same `--markdown-font-size` / `--markdown-line-height` / `--markdown-font-family` custom properties (e.g. via an inline `<style>` or a `style` attribute on `<body>`), so the editor's `editor.css` variables get real values instead of falling back to the hardcoded 14px default.
