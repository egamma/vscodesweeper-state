# Issue #269452 — Copilot Chat: get_changed_files sourceControlState ignored

[https://github.com/microsoft/vscode/issues/269452](https://github.com/microsoft/vscode/issues/269452)

## Summary

Team-authored bug that is still open on main with an active fix PR (#324351). The root cause — `RepoContextImpl.changes` capturing git state once at construction time rather than refreshing before reads — is confirmed in the source. Hard keep-open due to MEMBER authorship.

## Change summary

The `get_changed_files` tool ignores the `sourceControlState` parameter because `repository.changes` captures stale git state at construction time, returning empty results for staged/unstaged queries.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/324351, which refreshes the git repository state before reading changes in the `get_changed_files` tool. The fix likely touches `extensions/copilot/src/extension/tools/node/scmChangesTool.ts` and the repository context implementation to ensure fresh state is read at invocation time.
