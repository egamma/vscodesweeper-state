# Issue #207492 — Extension-contributable top-level menus

[https://github.com/microsoft/vscode/issues/207492](https://github.com/microsoft/vscode/issues/207492)

## Summary

Valid feature request — VS Code has an internal `MenubarMainMenu` MenuId used to register top-level menus, but this is not exposed to extensions via `contributes.menus` in `package.json`. The capability genuinely does not exist for extension authors today.

## Change summary

Allow extensions to contribute new top-level menu bar entries alongside File/Edit/Go for better command discoverability.

## Best solution

Expose `MenubarMainMenu` (or a new dedicated menu location) as an extension-contributable menu in the `contributes.menus` extension point, with appropriate guardrails (ordering, naming constraints) to prevent menu-bar clutter. This is an API decision that needs maintainer discussion on scope and UX limits.
