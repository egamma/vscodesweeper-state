# Issue #343548 — MCP Marketplace installs still write user servers to legacy mcp.json instead of Copilot Global configuration

[https://github.com/microsoft/vscode/issues/343548](https://github.com/microsoft/vscode/issues/343548)

## Summary

The destination inconsistency remains in current source: both marketplace and gallery installs omit a destination, causing installation into the VS Code user profile rather than Copilot Global. Keep this open; the manual Add Server flow supports Copilot Global but does not cover marketplace installation.

## Change summary

Make user-level MCP marketplace installation consistent with the recommended Copilot Global destination, or explicitly explain and offer the destination choice.

## Best solution

Give marketplace and gallery installations an explicit, consistent destination contract alongside MCP: Add Server, preserving schema compatibility and registry lifecycle behavior. A maintainer should settle whether compatible installations default to Copilot Global or present a destination picker before implementation.
