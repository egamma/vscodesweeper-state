# Issue #343548 — MCP Marketplace installs still write user servers to legacy mcp.json instead of Copilot Global configuration

[https://github.com/microsoft/vscode/issues/343548](https://github.com/microsoft/vscode/issues/343548)

## Summary

The Extensions-view MCP gallery still silently installs into the deprecated user configuration on current main. Keep this open: manual Add Server offers Copilot Global, but the gallery path bypasses that destination selection.

## Change summary

Make user-level MCP gallery installation consistent with the recommended Copilot Global configuration or explicitly explain and offer its destination.

## Best solution

Give gallery users an explicit, consistent configuration destination, with Copilot Global supported where compatible. Settle the default and explain compatibility limitations without changing existing workspace or remote installation semantics.
