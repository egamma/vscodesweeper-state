# Issue #343548 — MCP Marketplace installs still write user servers to legacy mcp.json instead of Copilot Global configuration

[https://github.com/microsoft/vscode/issues/343548](https://github.com/microsoft/vscode/issues/343548)

## Summary

The gallery installation path still silently selects the VS Code user-profile configuration, while Add Server offers Copilot Global and labels the older destination deprecated. Keep this open: the inconsistency is confirmed in current source, with independent Windows and macOS reports.

## Change summary

Make personal MCP gallery installations consistent with the Copilot Global destination offered by Add Server, including explicit compatibility guidance.

## Best solution

Give personal gallery installations a clear, supported destination consistent with Add Server, preserving explicit workspace and remote installations. Settle whether compatible servers default to Copilot Global or use a destination picker, and explain any required legacy fallback without silently losing gallery update metadata or unsupported configuration features.
