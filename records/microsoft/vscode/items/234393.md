# Issue #234393 — Codes Crashes after about 15 Minutes

[https://github.com/microsoft/vscode/issues/234393](https://github.com/microsoft/vscode/issues/234393)

## Summary

Still unfixed on main. The main process OOM from unbounded PTY output buffering is confirmed and reproduced by multiple reporters. Three fix PRs are open but none merged yet. The `important` label also blocks any close proposal.

## Change summary

VS Code main process runs out of memory and crashes after ~15 minutes when a terminal produces high-volume output, because PTY data events accumulate unboundedly in an emitter listener array.

## Best solution

Land one of the open fix PRs — https://github.com/microsoft/vscode/pull/323980 or https://github.com/microsoft/vscode/pull/324044 — which address the unconsumed buffered pty host service events. The root cause is in `src/vs/platform/terminal/node/ptyHostService.ts` and the IPC buffering layer; the emitter array for `_onProcessData` grows without bound when the renderer hasn't consumed the events.
