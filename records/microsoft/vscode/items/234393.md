# Issue #234393 — Codes Crashes after about 15 Minutes

[https://github.com/microsoft/vscode/issues/234393](https://github.com/microsoft/vscode/issues/234393)

## Summary

Real OOM bug in the main process caused by unbounded PTY output string accumulation — confirmed by a team member, with open fix PRs (#323980, #285419) actively targeting it. The `important` label applies; keeping open.

## Change summary

VS Code main process crashes with OOM after ~15 minutes when terminal PTY output (especially from programs with heavy ANSI output like SimulRPi or tmux) accumulates unboundedly in the V8 heap.

## Best solution

Land https://github.com/microsoft/vscode/pull/323980 (or its predecessor https://github.com/microsoft/vscode/pull/285419) which fixes the unconsumed buffered pty host service events that cause unbounded string retention in the main process.
