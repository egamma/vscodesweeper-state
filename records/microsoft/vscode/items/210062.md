# Issue #210062 — #accessibility in Github Copilot chat: Screenreader announces all copilot's path references and links as URL encoded file paths

[https://github.com/microsoft/vscode/issues/210062](https://github.com/microsoft/vscode/issues/210062)

## Summary

The chat response's screen-reader label still includes raw Markdown command URLs, so the central defect remains. Accessible View now strips link targets in ordinary paragraphs, but that partial coverage does not resolve the response announcement or links inside lists.

## Change summary

Announce readable file references in Copilot responses instead of command identifiers and URL-encoded arguments.

## Best solution

Present readable link text or file paths in chat response accessibility labels and Accessible View, including list items, while preserving response content and link activation in the visual transcript.
