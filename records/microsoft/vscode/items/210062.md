# Issue #210062 — #accessibility in Github Copilot chat: Screenreader announces all copilot's path references and links as URL encoded file paths

[https://github.com/microsoft/vscode/issues/210062](https://github.com/microsoft/vscode/issues/210062)

## Summary

The accessible view now strips command-link targets, but the focused chat response's ARIA label still contains raw Markdown, so the reported screen-reader behavior remains partially reproducible on current main.

## Change summary

Copilot file references expose long URL-encoded command targets to screen readers instead of announcing readable link text or file paths.

## Best solution

Keep readable file-reference text while removing Markdown syntax and encoded command targets from the chat response ARIA label, without changing rendered links, code-block/table counts, or accessible-view navigation.
