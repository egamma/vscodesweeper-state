# Issue #332474 — The log filter input box will be obscured by the log page number display.

[https://github.com/microsoft/vscode/issues/332474](https://github.com/microsoft/vscode/issues/332474)

## Summary

Confirmed in source: FilterWidget.adjustInputBox() hardcodes the input's paddingRight to a fixed 150px whenever the badge is shown, instead of measuring the actual badge/controls width, so a long badge string (e.g. "Showing 1234 of 5678" once the debug console has 1000+ lines) overflows the reserved space and overlaps the filter text — worth routing to the debug/console area.

## Change summary

In the Debug Console's log filter box, the "Showing X of Y" badge overlaps/obscures the input text once the line counts get large (1000+).

## Best solution

In src/vs/workbench/browser/parts/views/viewFilter.ts, adjustInputBox() should size the input's paddingRight from the actual measured width of .viewpane-filter-controls (badge + toolbar), not a hardcoded 150px, so long badge text never overlaps the input.
