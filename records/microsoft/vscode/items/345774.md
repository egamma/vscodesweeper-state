# Issue #345774 — MCP OAuth refresh races across VS Code windows invalidate rotating refresh tokens

[https://github.com/microsoft/vscode/issues/345774](https://github.com/microsoft/vscode/issues/345774)

## Summary

Keep open: current source permits independent windows to refresh the same persisted OAuth grant without cross-window coordination. The related reports cover distinct failures, and no qualifying fix was found for this team-authored issue.

## Change summary

Prevent concurrent cross-window OAuth refreshes from invalidating rotating MCP refresh tokens or discarding usable authentication sessions.

## Best solution

Establish application-wide coordination for dynamic-auth grant refresh and conditional credential persistence, so a stale refresh cannot overwrite newer credentials or remove a renewed session. Preserve independent-window access to MCP authentication without changing server-specific OAuth behavior.
