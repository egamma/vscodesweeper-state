# Issue #167525 — Introduce setting for font size

[https://github.com/microsoft/vscode/issues/167525](https://github.com/microsoft/vscode/issues/167525)

## Summary

A meaningful accessibility gap remains: current main supports whole-window zoom but not independent workbench text scaling. The constrained preset design remains under legitimate UX discussion and should stay open.

## Change summary

Add a small set of workbench font-size presets that enlarge UI text without proportionally scaling every interface element.

## Best solution

Design and implement a limited, accessibility-focused workbench font scale using shared typography and layout tokens, preserving the editor's separate font configuration and avoiding arbitrary per-component settings.
