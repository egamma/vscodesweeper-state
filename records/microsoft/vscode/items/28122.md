# Issue #28122 — Activate extension with workspaceContains when a matching file is added to the workspace

[https://github.com/microsoft/vscode/issues/28122](https://github.com/microsoft/vscode/issues/28122)

## Summary

The requested dynamic activation remains absent on current main. This team-authored Backlog request should stay open and be routed to extension activation/API ownership.

## Change summary

Activate an inactive extension when a newly added workspace file matches its workspaceContains activation event.

## Best solution

Extend workspaceContains handling to react efficiently to file creation for inactive extensions, without repeatedly scanning the workspace or requiring extensions to activate onStartupFinished and implement their own watcher.
