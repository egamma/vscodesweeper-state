# Issue #214766 — Proposal: make the existing feature "auto-escape highlighted text for regex when triggering find in regex mode" work even when highlighted text spans multiple lines

[https://github.com/microsoft/vscode/issues/214766](https://github.com/microsoft/vscode/issues/214766)

## Summary

A real editor-find gap remains on current main: Ctrl+F deliberately ignores multiline selections even in regex mode. Keep this oldest, narrowly specified request open for product discussion.

## Change summary

Seed regex-mode editor Find from a multiline selection, escaping regex metacharacters and line breaks.

## Best solution

Extend the Ctrl+F selection-seeding path in `findController.ts` to accept multiline selections when regex mode is active, preserving the existing size limit and non-regex behavior.
