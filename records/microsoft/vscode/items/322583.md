## Change summary

Terminal sticky scroll overlay obscures the cursor after pressing Ctrl+L to clear the screen in a nested terminal session (e.g., SSH or PowerShell inside another shell).

## Best solution

If confirmed, the fix likely involves the sticky scroll overlay's refresh logic in `terminalStickyScrollOverlay.ts` not properly accounting for screen clears in nested shells where command detection may not track the inner shell's state. The overlay should hide or reposition when the viewport is cleared in a context without shell integration. A screenshot and clear repro steps are needed first.
