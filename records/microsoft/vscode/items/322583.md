## Evidence

- **verified open canonical:** https://github.com/microsoft/vscode/issues/283335 is open. Its reproduction includes an application clearing the terminal and producing content whose first lines are hidden under sticky scroll. Its discussion also documents interactive git log and git commit content being obscured: https://github.com/microsoft/vscode/issues/283335#issuecomment-3670047150 and https://github.com/microsoft/vscode/issues/283335#issuecomment-3679171267.
- **shared source path:** src/vs/platform/terminal/common/capabilities/commandDetectionCapability.ts:getCommandForLine returns the current partial command for lines at or below its prompt marker. In src/vs/workbench/contrib/terminalContrib/stickyScroll/browser/terminalStickyScrollOverlay.ts, _refreshNow renders that executing command when its start and execution markers exist. _updateContent keeps the overlay at the terminal's top for partial commands; its cursor-based end-marker positioning applies only to completed commands. Consequently, an executing nested shell whose outer command has scrolled offscreen can retain a header over a caret moved to the first visible row.
- **interactive exceptions do not cover nested shells:** TerminalStickyScrollOverlay._updateContent suppresses partial-command headers for specific bottom-row pager indicators, ':' and '(END)', but has no corresponding protection for a nested-shell prompt or caret at the top after Ctrl+L. This is the same normal-buffer overlay occlusion tracked by the canonical, not the separate alternate-buffer marker-loop failure described in https://github.com/microsoft/vscode/issues/309782.
- **corroborating nested-session report:** https://github.com/microsoft/vscode/issues/280025#issuecomment-3790593914 independently describes launching Julia inside the integrated terminal and pressing Ctrl+L, after which the outer launch command remains sticky above the nested prompt. That issue's original task-rerun scope is less suitable as the canonical than the interactive-content occlusion scope of https://github.com/microsoft/vscode/issues/283335.
