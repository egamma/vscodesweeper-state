# Issue #283249 — Bug reporter broken. GitHub query limit exceeded

[https://github.com/microsoft/vscode/issues/283249](https://github.com/microsoft/vscode/issues/283249)

## Summary

The bug reporter's similar-issue search uses unauthenticated GitHub API calls, which are capped at 60 requests/hour. This is still present on current main — both the legacy `baseIssueReporterService.ts` (line 921) and the new wizard `issueReporterOverlay.ts` (line 1149) hit the unauthenticated endpoint. No fix references this issue.

## Change summary

The issue reporter's similar-issue search breaks when the unauthenticated GitHub API rate limit (60 req/hr) is exceeded.

## Best solution

Authenticate the GitHub search API calls in the issue reporter — either pass the user's GitHub session token (if available via the built-in GitHub auth provider) or use VS Code's existing proxy/probot service as the primary search path and treat GitHub search as a fallback with graceful degradation. The new wizard's `searchGitHubIssues` in `issueReporterOverlay.ts` and the legacy `searchGitHub` in `baseIssueReporterService.ts` both need this.
