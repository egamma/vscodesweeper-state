# Issue #277536 — Share f5 keybinding for merge editor and editor with changes from agent

[https://github.com/microsoft/vscode/issues/277536](https://github.com/microsoft/vscode/issues/277536)

## Summary

Keep open: merge-conflict navigation still lacks the Alt+F5 shortcut already used for multi-diff and agent-edit navigation. Maintainers explicitly support alignment, and no verified fix or canonical duplicate was found.
