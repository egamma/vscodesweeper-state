## Summary

This accepted request belongs to the VS Code-owned Remote-SSH extension and should be transferred to microsoft/vscode-remote-release, not closed. Collapsible host groups remain distinct from the documented host aliases and config-file selection capabilities.

## Change summary

Allow SSH hosts to appear in collapsible application or environment groups in Remote Explorer.

## Best solution

Provide optional visual host grouping in Remote-SSH without introducing incompatible ssh_config syntax, preserving the existing flat-list experience when grouping is disabled.
