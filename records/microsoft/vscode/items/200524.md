# Issue #200524 — SSH Host File - Grouping several servers

[https://github.com/microsoft/vscode/issues/200524](https://github.com/microsoft/vscode/issues/200524)

## Summary

Legitimate feature request with 34 upvotes, already promoted to Backlog. The SSH host grouping capability is not implemented in current main. The feature belongs primarily in the Remote SSH extension (microsoft/vscode-remote-release), though it could also involve core Remote Explorer changes. The discussion has matured with concrete implementation suggestions (VS Code settings-based grouping, hostname-prefix-based grouping).

## Change summary

Allow grouping SSH hosts in the Remote Explorer into collapsible categories for better organization when managing many servers.

## Best solution

The SSH host tree presentation is owned by the Remote SSH extension. The most promising approach from the discussion is a VS Code setting (e.g. `remote-explorer.categories`) that defines named groups of SSH hosts, keeping the ssh_config format untouched. Implementation would primarily live in the Remote SSH extension's tree data provider. Consider whether this issue should be moved to microsoft/vscode-remote-release where the SSH host tree rendering lives, or kept here if a core Remote Explorer grouping API is needed.
