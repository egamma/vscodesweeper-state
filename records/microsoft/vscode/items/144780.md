## Evidence

- **Current source confirms the original discovery gap:** extensions/git/src/model.ts:361–445 routes scanWorkspaceFolders through traverseWorkspaceFolder, which reads entries with fs.promises.readdir({ withFileTypes: true }) and enqueues only entries satisfying dirent.isDirectory(). Windows junctions are symbolic-link entries, so C:/ws/j1 and C:/ws/j2 are excluded before openRepository is called. This directly matches the reporter's parent-workspace trigger.
