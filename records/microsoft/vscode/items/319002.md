# Issue #319002 — [Error] [GitHub.copilot-chat] unhandlederror-Cannot read properties of null (reading 'value')

[https://github.com/microsoft/vscode/issues/319002](https://github.com/microsoft/vscode/issues/319002)

## Summary

Still reproduces on main: the `references.map(ref => convertReferenceToVariable(ref, attachments))` call sites in both `copilotCLIChatSessions.ts` and `copilotCLIChatSessionsContribution.ts` do not guard against null elements in the references array. The high hit-to-user ratio (4,460 hits/user) confirms this fires in a hot path.

## Change summary

TypeError when mapping prompt references to variables because a null element exists in the references array and `.value` is accessed without a null guard.

## Best solution

Add a `.filter(Boolean)` (or explicit null check) before the `.map(ref => convertReferenceToVariable(ref, attachments))` calls in both `copilotCLIChatSessions.ts:1008` and `copilotCLIChatSessionsContribution.ts:2163`, and/or guard the `ChatVariablesCollection._getVariables()` loop at line 67 against null entries in `_source`. The defensive guard belongs at the earliest boundary where external data enters.
