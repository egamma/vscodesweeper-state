# Issue #312238 — Ten years and there are still no semantic plugin version rules?

[https://github.com/microsoft/vscode/issues/312238](https://github.com/microsoft/vscode/issues/312238)

## Summary

This is a valid extension-publishing request, but the required support belongs to the Visual Studio Marketplace infrastructure and is already tracked by its open canonical issue.

## Change summary

Support standard SemVer pre-release identifiers such as `1.0.0-alpha.1` for Marketplace extension versions.

## Best solution

Implement full SemVer handling in the Visual Studio Marketplace under https://github.com/microsoft/vsmarketplace/issues/50, after which VS Code and its publishing tooling can adopt the Marketplace capability.
