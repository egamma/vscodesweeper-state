# Issue #342861 — Agent host: session shows "Failed" while a turn is running (a failed subagent chat outranks InProgress)

[https://github.com/microsoft/vscode/issues/342861](https://github.com/microsoft/vscode/issues/342861)

## Summary

Confirmed in current source: a historical chat error replaces the session's running status, so the sessions list reports Failed during live work. Keep this team-authored bug open; the fix should reconcile the host aggregation with the protocol's documented error-promotion contract.

## Change summary

Prevent a failed historical subagent from making an actively running session appear Failed.

## Best solution

Make the session summary accurately expose ongoing work while preserving individual chat failures and input-needed priority. Settle the session-level error semantics with the protocol owner, and assess the separately reported reconciliation logging behavior independently.
