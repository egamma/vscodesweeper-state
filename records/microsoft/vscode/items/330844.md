# Issue #330844 — Modern UI: panelSection.border is not rendered between panel sections

[https://github.com/microsoft/vscode/issues/330844](https://github.com/microsoft/vscode/issues/330844)

## Summary

Traced conclusively in source: the Modern UI style-override module unconditionally strips the inline border that PaneView applies (border-left for horizontal orientation, fed by panelSection.border), and only redraws a replacement separator for the vertical/header-top case, leaving horizontal panel sections with no visible divider.

## Change summary

When Modern UI (workbench.experimental.modernUI) is enabled, panelSection.border is not rendered between horizontally-arranged panel sections (e.g. after moving Explorer into the panel), making sashes hard to locate visually.

## Best solution

Extend src/vs/workbench/contrib/styleOverrides/browser/media/paneHeaders.css to redraw a left-edge separator (using the same panelSectionHeader-border/panel-border fallback chain) for `.monaco-pane-view.horizontal .pane`, mirroring the existing `::before` top-separator handling for the vertical case, instead of only nulling the inline border.
