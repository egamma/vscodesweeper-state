# Issue #328613 — Agents Window SSH creates separate remote agent host under default home instead of existing Remote-SSH home, causing duplicate installs/processes

[https://github.com/microsoft/vscode/issues/328613](https://github.com/microsoft/vscode/issues/328613)

## Summary

Keep open for a compatibility decision: current Agents Window SSH still does not consume RemoteCommand or provide a dedicated remote-home override. Endpoint discovery now supports reusing existing hosts, but it does not establish that hosts started under a different effective HOME can be discovered.

## Change summary

Make Agents Window SSH bootstrap and discover agent hosts under the same customized remote home as Remote-SSH, or provide an explicit supported override.

## Best solution

Define the supported remote-home/startup contract for Agents Window SSH and apply it consistently to CLI installation, endpoint discovery, and host startup. Preserve intentional dedicated-host selection; eliminating accidental home divergence should not prohibit explicitly choosing a separate host.
