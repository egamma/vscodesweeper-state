# Issue #117822 — [product icon themes] theme icons support for vscode.show(Information|Warning|Error)Message

[https://github.com/microsoft/vscode/issues/117822](https://github.com/microsoft/vscode/issues/117822)

## Summary

This accepted Backlog request remains unimplemented on current main: the extension API still accepts plain-string messages, and notification rendering does not interpret theme-icon syntax. The desired behavior for OS-native modal dialogs remains an unresolved public-API decision.

## Change summary

Allow extension-host information, warning, and error messages to render product theme icons embedded with `$(icon-name)` syntax.

## Best solution

Define a consistent rich-message contract for these APIs: render supported Markdown/theme icons in workbench notifications and custom web dialogs while specifying safe plain-text degradation for native OS dialogs.
