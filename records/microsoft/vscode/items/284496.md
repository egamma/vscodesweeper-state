# Issue #284496 — Tree loses focus when expanding "github copilot results"

[https://github.com/microsoft/vscode/issues/284496](https://github.com/microsoft/vscode/issues/284496)

## Summary

The focus-loss path remains in current main: expanding uncached Copilot search results invokes addAIResults(), which explicitly clears the tree's focused row. Keep this open for a bounded keyboard-navigation fix.

## Change summary

Expanding the Copilot results heading clears row focus and interrupts keyboard navigation through search results.

## Best solution

Preserve the focused results heading while expansion starts semantic search, so keyboard navigation continues without re-focusing a row. Keep ordinary new-search reset behavior unchanged.
