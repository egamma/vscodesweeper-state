# Issue #298081 — Ability for an extension to contribute a slash command that invokes a real vscode command

[https://github.com/microsoft/vscode/issues/298081](https://github.com/microsoft/vscode/issues/298081)

## Summary

Valid feature request from a team member for an extension API to contribute slash commands that invoke VS Code commands. Not yet implemented — `IChatSlashData` has no `commandId` field and no commits reference this issue. Keeping open.

## Change summary

Allow extensions to declare slash commands in `contributes.chatSessions` that invoke real VS Code commands, passing an invocation token to associate the command with the originating chat session.

## Best solution

Add a `commandId` field (or a separate contribution point) to the slash command registration in `src/vs/workbench/contrib/chat/common/participants/chatSlashCommands.ts` and expose it through the extension API, enabling extensions like Claude to register UI-only slash commands that dispatch to `vscode.commands` with a session-scoped invocation token. This unlocks wizard-style configuration flows in chat without polluting chat history.
