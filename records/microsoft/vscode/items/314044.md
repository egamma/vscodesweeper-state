# Issue #314044 — Plan - implement with Autopilot should not be the default choice

[https://github.com/microsoft/vscode/issues/314044](https://github.com/microsoft/vscode/issues/314044)

## Summary

The default remains provider-controlled on current main, so the lower-cost “Implement Plan” preference is still unresolved. Route this to the Copilot CLI agent area for a product decision about whether VS Code should preserve or override that default.

## Change summary

Prefer “Implement Plan” over “Implement with Autopilot” as the primary plan-approval action to avoid unexpectedly higher token usage.

## Best solution

Choose a consistent, cost-sensitive default for Copilot CLI plan approval while retaining Autopilot as an explicit option. The owner should decide whether that policy is part of the protocol/provider contract or a VS Code presentation rule.
