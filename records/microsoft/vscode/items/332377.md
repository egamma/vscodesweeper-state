# Issue #332377 — Incorrect doc link provided

[https://github.com/microsoft/vscode/issues/332377](https://github.com/microsoft/vscode/issues/332377)

## Summary

Confirmed in source: `showNoFoldersDialog` in askForPromptSourceFolder.ts always opens `PROMPT_DOCUMENTATION_URL` regardless of the customization `type`, so the skills 'no source folders found' quick pick wrongly links to the prompt-files docs instead of agent-skills docs. Author is a repo collaborator (team-authored), so per policy this stays open rather than a judgment close.

## Change summary

The 'Learn how to configure skills' quick-pick link (shown when no skill source folders exist) opens the prompt-files documentation URL instead of the agent-skills documentation URL.

## Best solution

In showNoFoldersDialog (src/vs/workbench/contrib/chat/browser/promptSyntax/pickers/askForPromptSourceFolder.ts), pick the documentation URL per `type` (PROMPT_DOCUMENTATION_URL / INSTRUCTIONS_DOCUMENTATION_URL / AGENT_DOCUMENTATION_URL / SKILL_DOCUMENTATION_URL / HOOK_DOCUMENTATION_URL from promptTypes.ts) instead of hardcoding PROMPT_DOCUMENTATION_URL.
