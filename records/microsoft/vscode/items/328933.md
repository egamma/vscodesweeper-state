# Issue #328933 — Markdown editor: Undo groups typing one character at a time

[https://github.com/microsoft/vscode/issues/328933](https://github.com/microsoft/vscode/issues/328933)

## Summary

Team-authored, well-diagnosed bug in the experimental WYSIWYG Markdown editor — the root cause is traced into the `@vscode/markdown-editor` dependency's own source layout, and the vscode-side bridge just forwards per-character updates from it. Team-authored issues stay open regardless; this isn't a mechanical implemented-on-main or duplicate case.

## Change summary

In the experimental hybrid Markdown editor, each naturally-typed character becomes its own undo step instead of being grouped into one undo action for a contiguous typing burst.

## Best solution

Coalesce contiguous typing into a single undo group across the bridge, per the reporter's own fix direction: add typing-group metadata in the `@vscode/markdown-editor` model/bridge layer and flush the group at semantic boundaries (navigation, Enter, paste, blur, composition boundaries, undo/redo) before applying it via `vscode.workspace.applyEdit` in extensions/markdown-language-features/src/preview/markdownEditorProvider.ts.
