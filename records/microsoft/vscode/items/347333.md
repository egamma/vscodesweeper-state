# Issue #347333 — Agents window: nested chat does not inherit parent task context

[https://github.com/microsoft/vscode/issues/347333](https://github.com/microsoft/vscode/issues/347333)

## Summary

Keep open as a request to clarify or improve nested-chat context handoff. Current source distinguishes fresh nested chats from context-inheriting forks and side chats; the report does not establish a broken inheritance contract.

## Change summary

Make parent-task context available when continuing work in a nested chat, or clearly explain context independence and expose the continuation path.

## Best solution

Make the distinction between fresh nested chats and context-preserving continuations explicit at creation, with a discoverable way to continue the source investigation. Preserve independent conversations rather than automatically copying parent history without a product decision.
