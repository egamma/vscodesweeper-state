# Issue #347333 — Agents window: nested chat does not inherit parent task context

[https://github.com/microsoft/vscode/issues/347333](https://github.com/microsoft/vscode/issues/347333)

## Summary

New nested sessions currently start independent conversations; context inheritance is a separate fork operation. Keep this open for the remaining discoverability and handoff request rather than treating independent history as a confirmed propagation bug.

## Change summary

Make parent-task context available when continuing work in a nested chat, or clearly explain independence and expose a context-preserving alternative.

## Best solution

Make the distinction between a fresh nested session and a context-preserving fork explicit at creation, with an obvious continuation path. Preserve independent conversations unless maintainers choose to change their default context semantics.
