# Issue #293244 — `Esc` doesn't play well with search bar in new settings view

[https://github.com/microsoft/vscode/issues/293244](https://github.com/microsoft/vscode/issues/293244)

## Summary

Team-authored bug about Escape dismissing the entire settings view instead of just the search bar when Ctrl+F is used. No fix found on main referencing this issue — keeping open.

## Change summary

Pressing Esc while the settings Ctrl+F search bar is focused dismisses the entire settings editor instead of only the search bar.

## Best solution

The settings editor's Escape keybinding handler should check whether a transient overlay (Ctrl+F search bar, completion widget) is open and dismiss only that layer before propagating up to close the editor. Likely involves src/vs/workbench/contrib/preferences/browser/settingsEditor2.ts or the keybinding registration in preferences.contribution.ts.
