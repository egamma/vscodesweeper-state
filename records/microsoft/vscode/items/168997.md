# Issue #168997 — Emmet completions interfering with Fast Arrow completions

[https://github.com/microsoft/vscode/issues/168997](https://github.com/microsoft/vscode/issues/168997)

## Summary

Keep open: a maintainer confirmed the disappearing-snippet reproduction, and the original fix was explicitly reverted because it broke CSS completions. Current source retains incomplete Emmet results, but also contains snippet-preservation logic that needs checking against the reported JSX flow before selecting a fix.

## Change summary

Typing a second character in a JSX abbreviation causes Fast Arrow or React snippet suggestions to disappear when Emmet completions are enabled.

## Best solution

Preserve matching extension snippets while Emmet refreshes its abbreviation suggestions, without breaking incremental CSS expansion. First retest the confirmed f-to-fa sequence against current completion reuse behavior and establish a regression test for whichever interaction remains broken.
