# Issue #168997 — Emmet completions interfering with Fast Arrow completions

[https://github.com/microsoft/vscode/issues/168997](https://github.com/microsoft/vscode/issues/168997)

## Summary

Still reproduces on main: the initial fix (PR #169574) was reverted due to regression #172534, and the emmet completion list remains marked `isIncomplete: true`, which causes requery behavior that suppresses other extensions' snippets.

## Change summary

Emmet completions marked as incomplete suppress snippet completions from other extensions (e.g. Fast Arrow) when `emmet.includeLanguages` is configured.

## Best solution

Find an approach that marks Emmet's CompletionList as complete (`isIncomplete: false`) without regressing the case from #172534 — likely by ensuring re-expansion still works via a different mechanism. The fix lives in `extensions/emmet/src/defaultCompletionProvider.ts`.
