# Issue #348141 — Agents window: prompt timeline subscribes to every turn's changeset on each session open, and the agent host recomputes all turn diffs each time

[https://github.com/microsoft/vscode/issues/348141](https://github.com/microsoft/vscode/issues/348141)

## Summary

Keep open: current source confirms that the hidden gutter flyout observes every prompt's diffs and that resubscribing recomputes historical turn changesets. The issue is already correctly routed to the Agents window and agent host.

## Change summary

Avoid eagerly subscribing to every historical turn's diffs when opening a session, and avoid recomputing unchanged completed-turn results on subsequent subscriptions.

## Best solution

Make historical diff work proportional to the timeline content actually being presented, while preserving prompt navigation and review controls. Reuse completed-turn results only with a freshness contract that accounts for edits and snapshots arriving while no client is subscribed.
