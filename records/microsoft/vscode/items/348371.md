# Issue #348371 — Terminal panel fails to maximise when a webview enables both `enableFindWidget` and `retainContextWhenHidden`

[https://github.com/microsoft/vscode/issues/348371](https://github.com/microsoft/vscode/issues/348371)

## Summary

The retained-webview cleanup still unconditionally refocuses the webview on current main, undoing panel maximisation. Keep this open as a VS Code webview lifecycle bug; the extension discussion independently confirms the reproduction.

## Change summary

Maximising the bottom, centre-aligned terminal panel fails when an editor webview enables both built-in find and retained context.

## Best solution

Hiding a retained webview must preserve the user's maximised-panel layout without reactivating the hidden editor. Preserve built-in search, retained viewer state, and normal focus restoration when the user explicitly dismisses find.
