# Issue #348371 — Terminal panel fails to maximise when a webview enables both `enableFindWidget` and `retainContextWhenHidden`

[https://github.com/microsoft/vscode/issues/348371](https://github.com/microsoft/vscode/issues/348371)

## Summary

The retained-webview cleanup still unconditionally restores focus on current main, undoing panel maximization. An existing open PR targets this exact defect; keep the issue open while that implementation is reviewed.

## Change summary

Maximizing the terminal panel fails when hiding a retained webview with its built-in find widget enabled.

## Best solution

Review https://github.com/microsoft/vscode/pull/305708 and verify that programmatic webview hiding preserves panel maximization while explicit find dismissal retains its normal focus behavior.

## Evidence

- **Current source:** src/vs/workbench/contrib/webviewPanel/browser/webviewEditor.ts calls webview.release(this) when hidden. In src/vs/workbench/contrib/webview/browser/overlayWebview.ts, release() calls hideFind(false) when retainContextWhenHidden is enabled. WebviewElement.hideFind() forwards to WebviewFindWidget.hide(), whose unconditional _delegate.focus() in src/vs/workbench/contrib/webview/browser/webviewFindWidget.ts refocuses the webview even during programmatic hiding.
- **Layout interaction:** src/vs/workbench/browser/layout.ts implements toggleMaximizedPanel() by hiding the editor area. Its registerLayoutListeners() restores that area on editor-group activation, explaining why the cleanup-induced focus undoes maximization.
- **Independent confirmation:** https://github.com/REditorSupport/vscode-R/issues/1467#issuecomment-5790250969 confirms reproduction on Linux; https://github.com/REditorSupport/vscode-R/issues/1467#issuecomment-6886632387 identifies the same core find-widget cleanup path and both option-dependent workarounds.
- **Existing open implementation:** https://github.com/microsoft/vscode/pull/305708 is OPEN according to its GitHub page metadata. Its description explicitly identifies panel maximization being undone by OverlayWebview.release(), and its diff changes the unconditional focus call in WebviewFindWidget.hide(). That change is absent from the checkout, so this is not a completed fix.
- **Related issue is not a canonical:** https://github.com/microsoft/vscode/issues/307943 concerns the find widget reappearing after dismissal when switching tabs, rather than panel maximization failing. That different observable symptom does not satisfy this re-reviewed item's duplicate bar.
