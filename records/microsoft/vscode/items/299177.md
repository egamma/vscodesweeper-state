The reported dark-mode Mermaid rendering gap was addressed after filing: chat diagrams now use a Mermaid theme derived from the active VS Code color theme and rerender when that theme changes.

## Change summary

Make Mermaid diagrams generated through `renderMermaidDiagram` readable and visually appropriate in dark VS Code themes.
