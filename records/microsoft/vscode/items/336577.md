# Issue #336577 — Delay Sign in to ChatGPT entry until GitHub authentication state is resolved

[https://github.com/microsoft/vscode/issues/336577](https://github.com/microsoft/vscode/issues/336577)

## Summary

Confirmed on current main: the Accounts panel's ChatGPT sign-in section is rendered without checking whether GitHub auth resolution (isAccountLoading) is still in flight, so it can briefly appear as the only/primary sign-in option during startup.

## Change summary

The 'Sign in to ChatGPT' entry in the combined Accounts panel can render before the GitHub Copilot authentication state has finished resolving.

## Best solution

Gate the ChatGPT signed-out section in createCombinedPanelContent (src/vs/sessions/contrib/accountMenu/browser/account.contribution.ts) on `!this.isAccountLoading`, mirroring the existing `isAccountLoading` guard already used for the Copilot section, so both provider sections appear together once GitHub state resolves.
