# Issue #336577 — Delay Sign in to ChatGPT entry until GitHub authentication state is resolved

[https://github.com/microsoft/vscode/issues/336577](https://github.com/microsoft/vscode/issues/336577)

## Summary

The startup race is present on current main: the Accounts menu adds the ChatGPT action even while GitHub authentication initialization is still represented by the disabled Loading entry. This is a bounded authentication-menu bug that should remain open for a code fix.

## Change summary

Keep Sign in to ChatGPT out of the Accounts menu until the existing authentication-provider initialization has completed.

## Best solution

Use the Accounts menu's existing initialization state to present ChatGPT and GitHub authentication choices together, while preserving the current ChatGPT account actions after initialization.
