# Issue #307010 — Sessions: option to replace the chat UI with an integrated terminal running Copilot CLI

[https://github.com/microsoft/vscode/issues/307010](https://github.com/microsoft/vscode/issues/307010)

## Summary

Keep open for product discussion: current session-aware terminals do not provide the requested CLI-first new/resume experience. This is a team-authored proposal in community review, with unresolved surface and persistence decisions and no verified duplicate or completed implementation.

## Change summary

Allow an opt-in Copilot CLI terminal to replace the primary Sessions chat surface, with configurable launch commands and defined new-session and resume behavior.

## Best solution

Define a Sessions-owned, optional CLI-first experience that preserves provider/session organization and the existing chat default. Decide the primary surface, resume persistence, and command configuration contract before implementation; the author's suggested launch/create-in-CLI action could be an initial increment without replacing the full request.
