# Issue #326151 — Support writing to the local clipboard from Dev Containers and Remote SSH sessions

[https://github.com/microsoft/vscode/issues/326151](https://github.com/microsoft/vscode/issues/326151)

## Summary

Legitimate feature request for clipboard bridging from remote environments (Dev Containers / Remote SSH) to the local host. No existing mechanism reliably covers the non-interactive subprocess case (OSC 52 is interactive-terminal-only). The prior request (#181724) was closed for insufficient upvotes, so this is not a duplicate of an open canonical. Routes to the remote and terminal areas.

## Change summary

Allow scripts and Git hooks running inside Dev Containers or Remote SSH sessions to write to the local host clipboard reliably.

## Best solution

Evaluate whether OSC 52 forwarding can be made reliable for subprocesses spawned by the integrated terminal (Option B), or whether a lightweight IPC/CLI bridge (Option A/C) is warranted. The terminal and remote teams own the relevant forwarding paths. A prior closed request (https://github.com/microsoft/vscode/issues/181724) explored `code --clipboard` but didn't reach the upvote threshold; this report adds the Dev Container angle and the subprocess/hook reliability gap.
