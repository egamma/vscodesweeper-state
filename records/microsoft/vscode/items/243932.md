# Issue #243932 — `editor.action.clipboardCopyAction` command no longer works

[https://github.com/microsoft/vscode/issues/243932](https://github.com/microsoft/vscode/issues/243932)

## Summary

Confirmed bug reproduced by a team member — programmatic clipboard copy via `editor.action.clipboardCopyAction` fails in extension tests when no prior user interaction has occurred. No fix referencing this issue exists on main.

## Change summary

Running `editor.action.clipboardCopyAction` via `vscode.commands.executeCommand` in extension tests does not copy selected text to the clipboard when the window has had no prior user interaction.

## Best solution

The copy command path in `src/vs/editor/contrib/clipboard/browser/clipboard.ts` relies on `document.execCommand('copy')` (line 201) which requires a user gesture. A workaround exists for EditContext (commit 884364539d1, lines 194–208) that falls back to `clipboardService.writeText` when the copy event doesn't fire, but it may not cover the test-environment scenario where `hasTextFocus()` (line 223) returns false. The fix should ensure programmatic copy works even without prior user interaction — either by relaxing the focus gate for programmatic invocations or by consistently falling back to the clipboard service API.
