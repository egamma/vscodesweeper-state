# Issue #339900 — Install Plugin from Source reveals plugins in the legacy details UI

[https://github.com/microsoft/vscode/issues/339900](https://github.com/microsoft/vscode/issues/339900)

## Summary

Confirmed on current main: after a successful 'Install Plugin from Source', chatPluginActions.ts still reveals the result via the legacy Extensions viewlet instead of the new Chat Customizations Plugins view, even though the infrastructure to reveal it there already exists.

## Change summary

Install Plugin from Source opens the newly installed plugin in the legacy Extensions-based details modal instead of the current Chat Customizations Plugins view.

## Best solution

In InstallFromSourceAction.run (src/vs/workbench/contrib/chat/browser/actions/chatPluginActions.ts), replace the post-install `extensionsWorkbenchService.openSearch(...)` call with opening the AICustomizationManagementEditor and calling `showPluginDetail`/`pluginListWidget.revealAndSelectItemByUri`, mirroring the existing `aiCustomizationManagement.showPlugin` command.
