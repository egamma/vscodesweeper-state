# Issue #349165 — Sidebar webview focus is not recognized correctly, preventing Increase Current View Size from resizing the Codex sidebar

[https://github.com/microsoft/vscode/issues/349165](https://github.com/microsoft/vscode/issues/349165)

## Summary

The missing logical-parent relationship is confirmed in current source and prevents the resize command from recognizing sidebar focus. Keep this open as a core webview-hosting bug, not an OpenAI extension defect.

## Change summary

Recognize focus inside sidebar-hosted webviews so Increase Current View Size resizes their containing sidebar.

## Best solution

Restore logical ancestry between overlaid webview content and its containing view, including anchors without DOM IDs. Verify command targeting separately from shortcut-context evaluation while preserving iframe state.
