# Issue #346846 — `update.restartWhenIdle`: an idle terminal blocks the restart with `terminal.runningProcess`

[https://github.com/microsoft/vscode/issues/346846](https://github.com/microsoft/vscode/issues/346846)

## Summary

The idle-prompt blocker remains source-reproducible on current main. Keep open for the assigned 1.147.0 milestone; an idle shell is incorrectly classified as executing a command.

## Change summary

Allow unattended update restarts when a restorable terminal is idle at an empty shell-integrated prompt.

## Best solution

Make the terminal restart participant distinguish prompt input from actual execution, while retaining blockers for running commands, child processes, pending input, and non-restorable terminals. Cover the idle-prompt case using real command-detection lifecycle behavior rather than an independently mocked execution getter.
