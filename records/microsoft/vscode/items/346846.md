# Issue #346846 — `update.restartWhenIdle`: an idle terminal blocks the restart with `terminal.runningProcess`

[https://github.com/microsoft/vscode/issues/346846](https://github.com/microsoft/vscode/issues/346846)

## Summary

The idle-prompt blocker remains reproducible from current source. Keep this scheduled 1.148.0 issue open; the release milestone independently prohibits a cleanup close.

## Change summary

An idle shell with integration enabled incorrectly blocks unattended update restarts as terminal.runningProcess.

## Best solution

The terminal restart participant should distinguish accepting input from executing a command, allowing an empty idle prompt while preserving blockers for active commands, pending input, unknown state, and non-restorable terminals.
