# Issue #146167 — Undo is not passed to editor when input field is opened

[https://github.com/microsoft/vscode/issues/146167](https://github.com/microsoft/vscode/issues/146167)

## Summary

The behavior remains on main, but forwarding Undo from the focused rename input is an unresolved UX decision rather than a defect. Keep it open under discussion because the existing maintainer response acknowledged a possible rename-specific exception without approving or rejecting it.

## Change summary

Allow Undo to target the editor's completed refactoring while the rename input field has focus.

## Best solution

The rename area should decide whether an explicit refactoring-undo command or a consistent transient-input rule can address this without breaking native Undo inside edited input fields. Avoid silently forwarding every Cmd/Ctrl+Z because that would discard expected input-level undo behavior.
