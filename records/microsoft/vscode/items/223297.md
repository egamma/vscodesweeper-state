# Issue #223297 — Profiles editor is not accessible / usable by keyboard

[https://github.com/microsoft/vscode/issues/223297](https://github.com/microsoft/vscode/issues/223297)

## Summary

Still reproduces on main: the Radio component in `src/vs/base/browser/ui/radio/radio.css` has no `:focus` styles, making it impossible to visually distinguish the focused button from the active/selected one. Confirmed by team members as recently as Oct 2025.

## Change summary

Radio buttons in the Profiles editor (and elsewhere) use the active-border color for the selected item but have no distinct focus indicator, making keyboard navigation visually indistinguishable.

## Best solution

Add a distinct `:focus-visible` style to `.monaco-custom-radio > .monaco-button` in `src/vs/base/browser/ui/radio/radio.css` — likely using `--vscode-focusBorder` as an outline — so the focused button is visually distinct from the merely-active (selected) one. This affects the base Radio widget used in Profiles editor and Search view.
