# Issue #223297 — Profiles editor is not accessible / usable by keyboard

[https://github.com/microsoft/vscode/issues/223297](https://github.com/microsoft/vscode/issues/223297)

## Summary

Keep open: the discussion establishes a focus-visibility defect, not missing keyboard navigation. Current Profiles styling still places the focus outline directly over the selected option's border, leaving the two states indistinguishable when their theme colors match.

## Change summary

Make keyboard focus on Profiles resource radio options visibly distinguishable from selection.

## Best solution

Provide a distinct keyboard-focus indicator for Profiles resource options while preserving selection styling, theme customization, and existing keyboard behavior. Keep this issue as the focused accessibility report rather than folding it into the newer profile-design initiative.
