# Issue #347037 — Agents window: Inbox stays in a chat's side panel after leaving it and sticks to that chat's layout

[https://github.com/microsoft/vscode/issues/347037](https://github.com/microsoft/vscode/issues/347037)

## Summary

Keep open: the current source still allows opening Inbox to overwrite a chat's saved side-panel visibility, and returning to the same chat does not restore its previous composition. The report provides complete reproduction steps and is already correctly routed.

## Change summary

Visiting Inbox leaves its editor beside chats and changes their remembered side-panel layout.

## Best solution

Preserve each chat's saved side-panel composition across Inbox navigation, including returning to the already-active chat and creating drafts. Retain the documented window-canvas lifetime and independent restoration semantics.
