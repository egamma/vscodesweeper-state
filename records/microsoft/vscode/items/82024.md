# Issue #82024 — Implement token-based language service

[https://github.com/microsoft/vscode/issues/82024](https://github.com/microsoft/vscode/issues/82024)

## Summary

The requested token-based fallback is now owned by Microsoft's active Anycode extension, which provides configurable definition and reference providers, including PHP support. This should be transferred to the Anycode tracker rather than retained as VS Code core work.

## Change summary

Provide optional token-based definitions and references when a language's semantic service cannot resolve them.

## Best solution

Continue developing the fallback in https://github.com/microsoft/vscode-anycode, where language-specific Tree-sitter grammars and explicitly approximate results can evolve without adding indexing and language machinery to VS Code core.

## Vision fit

- **Fit:** rejected
- **Reason:** The capability is already implementable as a focused language extension and does not need to expand the core editor.
- **Evidence:** Value and guardrail: “The power lives in extensions,” while VS Code remains lightweight and fast out of the box.
