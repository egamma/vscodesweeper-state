# Issue #327368 — Modernize: Clipped list items in suggest widget

[https://github.com/microsoft/vscode/issues/327368](https://github.com/microsoft/vscode/issues/327368)

## Summary

Team-authored, concrete visual bug in the new suggest widget CSS — traced the missing overflow-clipping on main, so this stays open for a fix rather than being closed.

## Change summary

In the modernized suggest widget, the list's top/bottom rows (especially the focused row) visually clip past the widget's rounded corners because nothing clips content to the container's border-radius.

## Best solution

Fix in src/vs/editor/contrib/suggest/browser/media/suggest.css: pair the existing border-radius (var(--vscode-cornerRadius-large)) on `.suggest-widget`/`.monaco-list` with `overflow: hidden` (the pattern already used elsewhere in the same file, e.g. the `.suggest-details` block around line 375-376), so the focused row's background doesn't overhang the rounded corners.
