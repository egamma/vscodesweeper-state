# Issue #228818 — Multiple cursors + Word wrap

[https://github.com/microsoft/vscode/issues/228818](https://github.com/microsoft/vscode/issues/228818)

## Summary

Decline close (as-designed) gated off: the issue carries the `bug` label — the owner already triaged it as accepted work. Original assessment: Alt+Click is intentionally defined as exact mouse-position cursor placement, including multiple visual positions within one wrapped logical line. The requested logical-line filtering would be a different mouse interaction rather than a regression of the fix for the keyboard commands.

## Change summary

Make Alt+Click avoid adding multiple cursors to different wrapped portions of the same logical line.

## Best solution

Keep Alt+Click as exact visual-position placement and use Add Cursor Above/Below when logical-line semantics are required; broader customization of mouse shortcuts remains separately tracked by https://github.com/microsoft/vscode/issues/3130.
