# Issue #228818 — Multiple cursors + Word wrap

[https://github.com/microsoft/vscode/issues/228818](https://github.com/microsoft/vscode/issues/228818)

## Summary

Alt+Click is intentionally defined as exact visual-position placement, including wrapped portions of one logical line; changing it to logical-line behavior is therefore a feature request rather than a regression.

## Change summary

Make Alt+Click avoid adding multiple cursors to wrapped portions of the same logical line, or provide a logical-line mouse-placement mode.

## Best solution

Keep exact-position semantics for Alt+Click and use Add Cursor Above/Below when logical-line placement is required. Broader mouse-shortcut customization remains separately tracked by https://github.com/microsoft/vscode/issues/3130.
