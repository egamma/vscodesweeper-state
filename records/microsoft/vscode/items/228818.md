# Issue #228818 — Multiple cursors + Word wrap

[https://github.com/microsoft/vscode/issues/228818](https://github.com/microsoft/vscode/issues/228818)

## Summary

A team member (alexdima) has actively engaged and confirmed that Alt+Click placing cursors at visual positions in wrapped lines is intentional — the fix for #26393 only changed keyboard-based Ctrl+Alt+Up/Down. The reporter is now requesting a change to Alt+Click behavior for consistency; this is an active discussion between a maintainer and the reporter, so it should stay open for the maintainer to decide.

## Change summary

Alt+Click places multiple cursors at visual (wrapped) positions rather than logical line positions when word wrap is enabled, which is inconsistent with the keyboard-based Ctrl+Alt+Up/Down behavior.

## Best solution

The maintainer (alexdima) is already engaged. The natural resolution is either (a) adding a `logicalLine`-style option for Alt+Click mouse cursor placement (possibly tied to the broader mouse shortcut customization tracked in https://github.com/microsoft/vscode/issues/3130), or (b) closing as `*as-designed` if the team decides the visual-position behavior for mouse clicks is the correct default. Leave this for the engaged maintainer to decide.
