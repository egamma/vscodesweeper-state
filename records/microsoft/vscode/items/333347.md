# Issue #333347 — Highlighting text appears to unhighlighted when tooltip/pop up appear

[https://github.com/microsoft/vscode/issues/333347](https://github.com/microsoft/vscode/issues/333347)

## Summary

Real visual defect: the reporter demonstrates (with extensions disabled, on two VS Code versions) that an on-hover popup causes the selection highlight to fade to the 'inactive selection' color, and the CSS mechanism in the editor's selection rendering plausibly explains a global fade like this — but the exact trigger for why the editor's `.focused` state flips during a mouse-drag hover isn't pinned down from source alone.

## Change summary

While drag-selecting text, if a hover tooltip appears over the selection, the selected text's highlight color fades almost to the editor background instead of staying highlighted.

## Best solution

Investigate why `src/vs/editor/browser/view/viewOverlays.ts`'s `_isFocused`/`.focused` toggling (driven by `ViewFocusChangedEvent`) flips off when a mouse-triggered hover appears during an active drag-selection, since `.monaco-editor .selected-text` (no `.focused` ancestor) renders with `--vscode-editor-inactiveSelectionBackground` per src/vs/editor/browser/viewParts/selections/selections.css lines 14-20 — that CSS switch is the most likely source of the fade the reporter shows in the gif.
