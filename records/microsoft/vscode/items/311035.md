# Issue #311035 — We need more settings for modifying SystemPrompts and ReminderPrompts.

[https://github.com/microsoft/vscode/issues/311035](https://github.com/microsoft/vscode/issues/311035)

## Summary

A real customization gap remains: current main offers an experimental per-model override for Agent Host sessions, but no supported per-custom-agent control over Copilot Chat's built-in system and reminder sections. Route this to chat customizations and keep it open for a product decision.

## Change summary

Allow custom agents to replace, disable, or tune built-in system-prompt and reminder-instruction sections that conflict with their own instructions.

## Best solution

Define supported, structured per-custom-agent override points for behavioral and reminder sections while preserving mandatory safety and protocol contracts; avoid emitting empty reminder blocks. Treat token-cost observability raised in the later comment as adjacent scope rather than requiring raw unrestricted prompt replacement.

## Evidence

- **current Agent Host capability:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts registers `chat.agentHost.copilot.modelCapabilityOverrides` as an application-scoped experimental/advanced setting for Copilot Agent Host sessions; its YAML `systemPrompt` replacement is per model, not per custom agent, and replaces all Agent Host and SDK prompt sections and guardrails.
- **runtime boundary:** src/vs/platform/agentHost/node/copilot/copilotSessionLauncher.ts resolves `promptOverrideString`/`promptOverrideFile` by model at session launch or resume and applies the resulting whole system message independently of the selected custom agent.
- **extension prompt boundary:** extensions/copilot/src/extension/prompts/node/agent/promptRegistry.ts selects `SystemPrompt` and `ReminderInstructionsClass` through internal model-specific resolvers with default fallbacks; no user or custom-agent override surface is exposed there.
- **related narrower request:** https://github.com/microsoft/vscode/issues/291992 is older and open, but specifically requests custom system prompts for CAPI/BYOK model evaluation; it does not own per-custom-agent reminder controls across built-in models and therefore does not meet the re-review duplicate bar.
- **related specific symptom:** https://github.com/microsoft/vscode/issues/308669 reports one hardcoded `<memoryInstructions>` conflict. It is narrower than this request for general system/reminder customization and cannot serve as its canonical duplicate.
