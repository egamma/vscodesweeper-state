# Issue #168963 — Feature Request: Support collapsible markdown

[https://github.com/microsoft/vscode/issues/168963](https://github.com/microsoft/vscode/issues/168963)

## Summary

VS Code's markdown renderer already supports `<details>` and `<summary>` HTML tags as part of its HTML-in-markdown infrastructure. Both tags are in the allowed sanitizer list (`basicMarkupHtmlTags` in `domSanitize.ts`), and a team member confirmed this in December 2024. Extensions rendering comments need to set `supportHtml: true` on their `MarkdownString` to opt in.

## Change summary

Support collapsible `<details>`/`<summary>` HTML sections in markdown rendered within VS Code (e.g. PR comment bodies).

## Best solution

VS Code core already allows `<details>` and `<summary>` through its sanitized HTML-in-markdown support. If specific extensions (e.g. GitHub Pull Requests) don't render them collapsed, that's an extension-side issue — the extension must set `supportHtml: true` on the `MarkdownString` comment body. No core change needed.
