# Issue #168963 — Feature Request: Support collapsible markdown

[https://github.com/microsoft/vscode/issues/168963](https://github.com/microsoft/vscode/issues/168963)

## Summary

Keep open to establish whether GitHub PR comments now preserve interactive collapsible sections end to end. Core already supports the relevant HTML tags when the comment provider opts in, but that capability alone does not prove the reporter's workflow is covered, and no concrete fixing commit was identified.

## Change summary

Render collapsible HTML sections in PR comment markdown so verbose CI output remains collapsed until expanded.

## Best solution

Ensure PR comment bodies preserve sanitized <details>/<summary> sections and their interactive collapsed state through the existing MarkdownString HTML support. First establish whether the remaining gap is provider opt-in or comment-widget behavior; ordinary Markdown preview support does not settle this request.
