# Issue #340500 — Set agent Selector Missing "Ask", and "Plan" menu options

[https://github.com/microsoft/vscode/issues/340500](https://github.com/microsoft/vscode/issues/340500)

## Summary

Traced on current main: this is an in-progress migration of the old built-in "Ask"/"Plan" modes to new custom-agent-based replacements, gated by the `chat.showOldAskMode` experiment, and the replacement doesn't fully exist yet in this build — not a clean regression I can pin to a single bad commit, but a real functional gap for anyone not in the old-Ask treatment.

## Change summary

The Set Agent Selector dropdown only shows "Agent" and "Configure Custom Agents..." — no way to pick Ask or Plan mode.

## Best solution

Finish the Ask-mode migration: either ship the new "Ask" custom-agent prompt alongside the already-present `plan.prompt.md`, or widen the `chat.showOldAskMode` experiment until the replacement is ready, so users always have at least one of old/new Ask available.

## Evidence

- **Ask gating:** src/vs/workbench/contrib/chat/browser/widget/input/modePickerActionItem.ts shouldShowBuiltInMode(): the built-in ChatMode.Ask is shown only if assignments.showOldAskMode is true (or agent mode is policy-disabled); the new custom 'ask' mode is shown only when showOldAskMode is false. Default assignment value is `{ showOldAskMode: false }` until the async assignmentService.getTreatment('chat.showOldAskMode') resolves.
- **missing new Ask prompt:** extensions/copilot/assets/prompts/ only contains plan.prompt.md (which defines the 'Plan' custom agent, agent: Plan) — there is no ask.prompt.md shipping the replacement 'Ask' custom mode in this checkout, so for users with showOldAskMode=false there is currently no Ask option at all.
- **Plan not core builtin:** src/vs/workbench/contrib/chat/common/chatModes.ts getBuiltinModes() only ever returns Ask/Agent/Edit — 'Plan' is not a core builtin mode, it's the custom agent shipped via plan.prompt.md and depends on the harness service (customizationHarnessService.onDidChangeCustomAgents) successfully registering it; if that registration fails or the bundled Copilot extension predates the prompt file, Plan silently disappears from the picker too.
