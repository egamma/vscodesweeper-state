# Issue #349164 — Wrong translation for "Open changes" ("Offene Änderungen") in VSCode Source Code Management

[https://github.com/microsoft/vscode/issues/349164](https://github.com/microsoft/vscode/issues/349164)

## Summary

Keep open: current German translation catalogs still describe the SCM action as “Offene Änderungen,” while the source confirms that it opens changes. The report provides enough detail to retest; the installed language-pack rendering was not executed.

## Change summary

Translate the SCM “Open Changes” action as “Änderungen öffnen” rather than the noun phrase “Offene Änderungen.”

## Best solution

Correct the German localization entries for the SCM action through the localization pipeline, preserving the existing English labels and command behavior.

In src/vs/workbench/contrib/multiDiffEditor/browser/scmMultiDiffSourceResolver.ts, OpenScmGroupAction opens a multi-file diff editor.
