# Issue #298713 — Support loading agent skills from packages

[https://github.com/microsoft/vscode/issues/298713](https://github.com/microsoft/vscode/issues/298713)

## Summary

Valid feature request for discovering agent skills shipped inside package directories (npm, pip). The current path validation (`VALID_PROMPT_FOLDER_PATTERN`) explicitly rejects glob characters, confirming the reporter's experience. A team member (aeschli) expressed interest but noted it depends on whether package-shipped skills become a standard. Still open and worth tracking.

## Change summary

Allow `chat.agentSkillsLocations` to accept glob patterns (e.g. `node_modules/**/.agents/skills`) so agent skills distributed inside npm/pip packages can be discovered.

## Best solution

If package-shipped skills gain traction as a convention, extend the path validation in `promptFilesLocator.ts` to allow glob patterns in location settings and resolve them via the existing `IResolvedPromptSourceFolder.filePattern` infrastructure. Security implications (trusting skills from arbitrary packages) and context-window bloat (as raised in comment #2) need design consideration before implementation.
