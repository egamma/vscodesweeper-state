[https://github.com/microsoft/vscode/issues/342537](https://github.com/microsoft/vscode/issues/342537)

## Summary

Keep open: current source ties certificate notifications and management availability to session subscription state established during first-send processing, leaving new chats without the expected pre-send behavior. Because this concerns sandbox certificate trust and host targeting, a human maintainer should handle the disposition.

Make the sandbox trusted-CA alert and Manage Trusted CA available in a new Agent Host chat before its first message.
