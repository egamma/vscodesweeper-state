# Issue #240921 — Word Wrap breaks grapheme clusters

[https://github.com/microsoft/vscode/issues/240921](https://github.com/microsoft/vscode/issues/240921)

## Summary

The default `simple` wrapping strategy still splits extended grapheme clusters and overestimates their width on current main. The advanced-strategy workaround is useful but does not correct the confirmed default-path defect.

## Change summary

Word wrapping should treat an extended grapheme cluster as one indivisible rendered character instead of wrapping between its UTF-16 code points.

## Best solution

Make the fast monospace wrapping path preserve grapheme boundaries and approximate each cluster's rendered width consistently with the editor's existing cursor-column logic, while retaining the current performance distinction between `simple` and `advanced` wrapping.
