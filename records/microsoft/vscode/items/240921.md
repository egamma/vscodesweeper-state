# Issue #240921 — Word Wrap breaks grapheme clusters

[https://github.com/microsoft/vscode/issues/240921](https://github.com/microsoft/vscode/issues/240921)

## Summary

Still reproduces on main: the monospace line breaks computer iterates by UTF-16 code units and only groups surrogate pairs, but does not respect extended grapheme clusters (ZWJ emoji sequences), so word wrap can split a multi-code-point emoji mid-cluster. The 'advanced' wrapping strategy works around this by deferring to the DOM.

## Change summary

Word wrap in the default (simple) wrapping strategy splits extended grapheme clusters (e.g. family emoji) at internal code-point boundaries instead of treating them as atomic units.

## Best solution

Teach the monospace line breaks computer (`src/vs/editor/common/viewModel/monospaceLineBreaksComputer.ts`) to detect extended grapheme cluster boundaries (using the existing `GraphemeBreakTree` / `breakBetweenGraphemeBreakType` utilities in `src/vs/base/common/strings.ts`) and never insert a line break inside a grapheme cluster. This keeps the 'simple' strategy correct for emoji without requiring users to switch to 'advanced'.
