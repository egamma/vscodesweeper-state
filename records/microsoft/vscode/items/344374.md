# Issue #344374 — "Disable"/"Delete" has latency

[https://github.com/microsoft/vscode/issues/344374](https://github.com/microsoft/vscode/issues/344374)

## Summary

Keep open: automation Disable and Delete await provider mutations without showing an in-flight state on the affected card. This team-authored report identifies a concrete feedback gap that remains in the current source.

## Change summary

Provide immediate feedback while an automation Disable or Delete request is pending so users do not mistake latency for an ignored action.

## Best solution

The Automations card should visibly and accessibly acknowledge pending definition mutations and prevent repeated conflicting submissions until completion. Preserve authoritative provider updates, deletion confirmation, and existing error reporting.
