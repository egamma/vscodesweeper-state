# Issue #228522 — vscode.dev blocks simple browser

[https://github.com/microsoft/vscode/issues/228522](https://github.com/microsoft/vscode/issues/228522)

## Summary

Keep open: a maintainer confirmed the vscode.dev failure without any remote connection, and the linked discussion explicitly consolidated the report here. Current source still uses iframe embedding; server-header workarounds do not establish that the reported limitation has been fixed.

## Change summary

Simple Browser on vscode.dev blocks development pages that load in desktop VS Code, preventing embedded previews and hot reload.

## Best solution

Establish supported embedded-preview behavior on vscode.dev while preserving cross-origin isolation and respecting sites that prohibit framing. Coordinate that behavior with the planned core web-browser replacement, including useful guidance when a development server must supply compatible headers.
