# Issue #333320 — Copilot inline suggestion doesn't work when parent folder has space

[https://github.com/microsoft/vscode/issues/333320](https://github.com/microsoft/vscode/issues/333320)

## Summary

Fresh, well-documented regression: a second commenter independently confirmed Copilot inline suggestions fail whenever the file path contains a space (parent folder or filename), reproduced it outside any workspace/git repo, in a clean profile, and confirmed it worked on 1.125.1 but broke by 1.135.0 — strong signal of a real regression, but no fix or maintainer triage yet, so this stays open.

## Change summary

Copilot inline (ghost text) completions silently stop working for any file whose path contains a space, showing 'No inline suggestion available'.

## Best solution

Needs a maintainer/Copilot team investigation into how the local file: URI (likely the encoded %20 path segment) is passed to/matched against the inline completions provider — bisecting between 1.125.1 and 1.135.0 should narrow the regressing commit quickly given how clean the repro is.
