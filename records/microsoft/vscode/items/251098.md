# Issue #251098 — Warning message should mention extension in which profile depends on the extension that's being uninstalled

[https://github.com/microsoft/vscode/issues/251098](https://github.com/microsoft/vscode/issues/251098)

## Summary

The profile context is still omitted on current main: the uninstall flow discovers each dependent extension's profile but discards that association before constructing the warning. This team-authored Backlog item should remain open as a bounded extensions UX polish issue.

## Change summary

Include the owning profile when an uninstall warning names a dependent extension installed in another profile.

## Best solution

Make the dependent-extension warning identify each relevant profile while preserving the existing application-scoped confirmation, dependent discovery, and Uninstall All behavior.
