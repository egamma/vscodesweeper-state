# Issue #263226 — `TypeScript: Select TypeScript Version...` shows incorrect info

[https://github.com/microsoft/vscode/issues/263226](https://github.com/microsoft/vscode/issues/263226)

## Summary

Still reproduces on main: the version picker's active-version indicator logic in `getBundledPickItem()` checks `useWorkspaceTsdkSetting` (a memento key) rather than comparing against the actual `_currentVersion`, causing misleading UI when `typescript.tsdk` is configured. An open PR (#269527) exists but hasn't merged.

## Change summary

The TypeScript version picker shows the active bullet on 'Use VS Code's Version' even when a workspace TypeScript version is configured and in use via `typescript.tsdk`.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/269527 which addresses this picker UI confusion, or fix the active-indicator logic in `getBundledPickItem()` and `getLocalPickItems()` in `extensions/typescript-language-features/src/tsServer/versionManager.ts` to compare against `this.currentVersion` rather than relying solely on the `useWorkspaceTsdkSetting` memento.
