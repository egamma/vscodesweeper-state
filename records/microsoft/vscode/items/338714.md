# Issue #338714 — Sessions list doesn't show needs-input for a multi-chat Agent Host session while the title bar does

[https://github.com/microsoft/vscode/issues/338714](https://github.com/microsoft/vscode/issues/338714)

## Summary

Team-authored (lramos15, MEMBER) bug report with a precise, code-verified root cause; keep open — hard keep-open rule for team-authored issues applies anyway, but this is also a strong, actionable diagnosis worth an agent implement pass.

## Change summary

For a multi-chat Agent Host session, the sessions-list row keeps showing in-progress instead of needs-input after the session leaves the viewport for 30+s, even though the title bar correctly shows needs-input.

## Best solution

Extend the existing #333804 re-acquire-on-turn-complete fix in `_handleSessionSummaryChanged` (baseAgentHostSessionsProvider.ts) to also re-acquire session state when the aggregate status changes for a session whose default-chat status is overridden, so `_applyChatCatalog` refreshes `_defaultChatStatusOverride` on the root `sessionSummaryChanged` notification (not just on `ChatTurnComplete`).
