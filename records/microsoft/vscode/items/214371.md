# Issue #214371 — VSCode forces file type associations on macos

[https://github.com/microsoft/vscode/issues/214371](https://github.com/microsoft/vscode/issues/214371)

## Summary

Valid ongoing discussion about VS Code's macOS file type associations being too aggressive. The `under-discussion` label is appropriate; the behavior is standard for macOS apps but the lack of opt-in/out control is a legitimate UX concern that a team member flagged for review.

## Change summary

VS Code registers CFBundleDocumentTypes for many file extensions on macOS, causing it to become the default handler without user consent.

## Best solution

Provide a way to control which file type associations VS Code claims on macOS — either via a reduced default set, a post-install configuration step, or a setting that regenerates the Info.plist. The file type registration lives in the distro build layer (Info.plist generation), so any fix would touch the packaging/build pipeline rather than runtime code.
