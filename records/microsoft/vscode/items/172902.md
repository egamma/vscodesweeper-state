# Issue #172902 — Extra selection getting added when you Alt + click on a multiple selection to remove the selection

[https://github.com/microsoft/vscode/issues/172902](https://github.com/microsoft/vscode/issues/172902)

## Summary

The defect remains source-reproducible on current main: Alt+mousedown removes the selected cursor, but a subsequent pointer-move dispatch extends the last remaining cursor to the clicked position. The issue should stay open as a bounded multicursor input bug.

## Change summary

Alt-clicking an existing multicursor selection can remove it and then create an unintended selection from another cursor to the click position.

## Best solution

Make removal of an existing multicursor selection atomic for that pointer interaction, while preserving Alt+drag selection behavior when the interaction begins outside an existing selection.

- **Behavior:**

  > When multiple selections exist, Alt-clicking inside one removes that selection without creating or extending another selection during the same pointer interaction. Minor pointer movement while releasing the button must not change the remaining selections. Alt+drag beginning outside an existing selection must retain its current selection behavior.
- **Trace:**

  > On current main, MouseDownOperation.start in src/vs/editor/browser/controller/mouseHandler.ts dispatches the initial Alt+click with inSelectionMode=false and continues pointer monitoring. ViewController.dispatchMouse in src/vs/editor/browser/view/viewController.ts sends that initial event to CoreNavigationCommands.CreateCursor, whose implementation in src/vs/editor/browser/coreCommands.ts removes the selection containing the clicked position. Any subsequent pointer movement is dispatched with inSelectionMode=true and reaches LastCursorMoveToSelect, extending the last remaining cursor toward the click position. This directly explains why cursorUndo removes the extra selection reported in https://github.com/microsoft/vscode/issues/172902. The boundary is multicursor removal during one pointer interaction; ordinary multicursor creation and intentional Alt+drag selection must not change.
