# Issue #203804 — Add Shortcut for "Close to the Right" Command

[https://github.com/microsoft/vscode/issues/203804](https://github.com/microsoft/vscode/issues/203804)

## Summary

Keep open as the canonical accepted Backlog request. The command is customizable today, but the requested default shortcut remains absent and the proposed key combination conflicts with existing contextual bindings.

## Change summary

Assign a default keyboard shortcut to close all editors to the right of the active editor.

## Best solution

Workbench editor maintainers should decide whether this common tab-management command warrants a default binding and select a conflict-free key combination; users can meanwhile bind `workbench.action.closeEditorsToTheRight` themselves.
