# Issue #331979 — Alt-Tab away and back leaves a tab's Close button stuck showing "Close Other Editors"

[https://github.com/microsoft/vscode/issues/331979](https://github.com/microsoft/vscode/issues/331979)

## Summary

Mid-verification bug carrying the `verification-found` label plus a real milestone (1.135.0) — both hard keep-open rules apply, and the issue was already reopened once because the first fix attempt didn't fully resolve it (a maintainer confirmed on 2026-08-24 it still reproduces on Mac), so no close should be proposed here.

## Change summary

After an OS-level Alt-Tab away and back without moving the mouse, a tab's close button can stay stuck showing 'Close Other Editors' even though Alt is no longer held, causing an accidental mass-close on click.

## Best solution

Clear `hoveredTabIndex` in MultiEditorTabsControl (src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts) on window blur, mirroring how ModifierKeyEmitter already resets altKey on blur in src/vs/base/browser/dom.ts, and/or re-require a fresh Alt keydown while focused before allowing the swapped Close-Others icon; verification should specifically include the Mac trackpad/mission-control gesture path from the latest comment before this is closed again.
