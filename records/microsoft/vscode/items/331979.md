# Issue #331979 — Alt-Tab away and back leaves a tab's Close button stuck showing "Close Other Editors"

[https://github.com/microsoft/vscode/issues/331979](https://github.com/microsoft/vscode/issues/331979)

## Summary

This carries `verification-found`, so it is mid release-verification and must not be closed — and the discussion since reopening (Mac and Windows repro variants, comment on 2026-09-04) shows the fix hasn't fully landed yet anyway.

## Change summary

The Alt+click 'Close Others' tab affordance can stay visually and functionally armed after an Alt-Tab (or OS input-switch) round trip, so clicking a tab's close button closes all other tabs instead of just that one.

## Best solution

Keep open through verification; the swapped-state logic in `MultiEditorTabsControl.redrawTabActionAtIndex` (src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts, uses `modifierKeyEmitter.keyStatus.altKey` and `hoveredTabIndex`) needs to stop trusting stale Alt state across focus/window changes — commenters suggest clearing `hoveredTabIndex` on blur and/or re-reading `event.altKey` at click time, which would also cover the no-blur OS-hotkey case reported on Windows.
