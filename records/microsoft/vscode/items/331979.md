# Issue #331979 — Alt-Tab away and back leaves a tab's Close button stuck showing "Close Other Editors"

[https://github.com/microsoft/vscode/issues/331979](https://github.com/microsoft/vscode/issues/331979)

## Summary

Mid-verification bug (carries verification-found) with a real milestone assigned — must stay open regardless of other evidence. Tracing the source confirms the reported defect still exists on current main.

## Change summary

Alt+click 'Close Others' swap on a tab's close button can get stuck in the swapped state after an Alt-Tab/focus round-trip, because hoveredTabIndex isn't cleared on window blur while the modifier key state can also become stale.

## Best solution

Land a fix in multiEditorTabsControl.ts that clears hoveredTabIndex on window blur (mirroring ModifierKeyEmitter's blur->resetKeyStatus) and/or re-reads the live Alt state at click time in redrawTabActionAtIndex, then let verification re-confirm on 1.137.0 — the comments show it also needs to cover mission-control (blur) and OS input-hotkey (no-blur) cases.
