# Issue #183560 — Markdown: Paste image from clipboard - image filename

[https://github.com/microsoft/vscode/issues/183560](https://github.com/microsoft/vscode/issues/183560)

## Summary

The central request is implemented: markdown.copyFiles.destination supports timestamp-based filenames and regular-expression formatting through ${isoTime}. The latest comment supplies a configuration using this capability, and the implementation is present on current main.

## Change summary

Allow pasted Markdown images to use configurable date/time-based filenames instead of image.png and incrementing suffixes.
