# Issue #183560 — Markdown: Paste image from clipboard - image filename

[https://github.com/microsoft/vscode/issues/183560](https://github.com/microsoft/vscode/issues/183560)

## Summary

Keep open: current main now supports timestamp-based Markdown paste filenames through `markdown.copyFiles.destination`, but the broader request also asks for GUID/custom filename generation and optional runtime override, which are not covered. The issue is already in Backlog with 52 upvotes, so it should stay as the community-backed feature request rather than be closed for partial coverage.

## Change summary

Allow pasted Markdown clipboard images to use configurable filenames such as timestamps, GUIDs, custom templates, or a name chosen at paste time.

## Best solution

Keep the Markdown copy-files feature request open for the remaining naming-template gaps: a GUID/random variable and/or a runtime rename flow if maintainers want first-party support. The existing timestamp workaround should be documented in the thread so users can use it while the broader request remains tracked.
