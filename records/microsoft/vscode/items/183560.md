# Issue #183560 — Markdown: Paste image from clipboard - image filename

[https://github.com/microsoft/vscode/issues/183560](https://github.com/microsoft/vscode/issues/183560)

## Summary

The central ask (datetime-based filenames) is now partially addressed via `${unixTime}` and `${isoTime}` variables with regex transform support in `markdown.copyFiles.destination`. However, GUID support and an interactive runtime rename dialog remain unimplemented — keeping open for the remaining scope.

## Change summary

Allow customizable filenames (datetime, GUID, or interactive naming) when pasting images from clipboard into Markdown.

## Best solution

Add a `${uuid}` variable to the copy-destination resolver in `extensions/markdown-language-features/src/languageFeatures/copyFiles/copyFiles.ts`, and consider an optional interactive rename prompt on paste. The datetime portion is already shipped.
