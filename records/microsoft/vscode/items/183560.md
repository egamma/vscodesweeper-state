# Issue #183560 — Markdown: Paste image from clipboard - image filename

[https://github.com/microsoft/vscode/issues/183560](https://github.com/microsoft/vscode/issues/183560)

## Summary

Timestamp-based filenames and regex formatting are now supported, but GUID templates and a paste-time filename override remain unsupported in the inspected path. Keep this accepted, well-supported request open to settle the remaining scope rather than treating partial coverage as completion.

## Change summary

Allow configurable filenames for images pasted into Markdown, including timestamps or GUIDs and an optional paste-time override.

## Best solution

Retain the existing timestamp-template support and decide the remaining filename customization contract in the built-in Markdown extension, particularly GUID generation and an optional per-paste override.

Existing timestamp templates already satisfy the date/time portion and must continue working. The remaining requested capabilities are GUID-based names and an optional per-paste filename override, whose supported scope and interaction need agreement. Acceptance should verify that generated files and inserted Markdown links use the same destination and that ordinary paste remains unchanged.
- **Trace:**

  > resolveCopyDestinationSetting in extensions/markdown-language-features/src/languageFeatures/copyFiles/copyFiles.ts expands a fixed variable map and optional regex transformations; unixTime and isoTime exist, but GUID/UUID expansion does not. NewFilePathGenerator in newFilePathGenerator.ts matches document globs, resolves the configured destination, and handles collisions or overwrites. ResourcePasteOrDropProvider.createEditForMediaFiles in dropOrPasteResource.ts consumes that generated destination without a filename override interaction. Existing resolver tests are in src/test/copyFile.test.ts. Preserve destination matching, existing transformations, overwrite policy, and default noninteractive paste; notebook attachment naming is a separate path. https://github.com/microsoft/vscode/issues/193752 covers relative destination paths, while https://github.com/microsoft/vscode/issues/209500 concerns notebook attachments. The uncertainty is the remaining public template contract and whether paste-time naming belongs in this request's accepted scope.
- **Open decisions:**
