Thanks for the detailed report. The off-by-one is still present on main, and an open PR already references it, so the issue stays open until that PR lands.

## Change summary

Removing the last array element via jsonEdit's setProperty leaves the character before the closing bracket behind, which can corrupt compact or CRLF JSON.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/341687, which changes `parentEndOffset - 2` to `- 1` for the last-item removal in src/vs/base/common/jsonEdit.ts and adds tests.
