# Issue #153910 — Click on titlebar to close command center.

[https://github.com/microsoft/vscode/issues/153910](https://github.com/microsoft/vscode/issues/153910)

## Summary

Keep open: the discussion confirms that clicking the draggable titlebar does not dismiss quick input, and current source still exposes the relevant drag-region and focus-loss boundary. The related menu-layering issue does not absorb this report, and no concrete fixing commit was identified.

## Change summary

Dismiss an open command palette or quick pick when the user clicks outside it on the titlebar.

## Best solution

Make outside-click dismissal consistent across the editor and titlebar on Windows desktop, while preserving intended window-dragging behavior and quick inputs that explicitly ignore focus loss. Establish the native titlebar interaction contract before changing shared quick-input behavior.

- **Behavior:**

  > An open command palette or quick pick currently remains visible when the user clicks a blank draggable titlebar area, although clicking the editor dismisses it. Outside-titlebar-click dismissal should work whether the picker was opened through Command Center or the keyboard. - **Trace:**

  > QuickInputController in src/vs/platform/quickinput/browser/quickInputController.ts hides on focus-tracker blur unless focus loss is ignored. Preserve normal quick-input acceptance, Escape dismissal, explicit ignoreFocusOut semantics, and titlebar behavior when no picker is visible; uncertainty begins at native click-versus-drag handling while the picker is open.
- **Open decisions:**
