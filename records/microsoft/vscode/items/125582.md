The actual provider resolver is registered separately at lines 197–201; an uninstalled or disabled extension cannot register it.
- **Indefinite restoration wait:** In src/vs/workbench/contrib/webviewPanel/browser/webviewWorkbenchService.ts:375–389, resolveWebview enqueues an input when no resolver claims it. RevivalPool.enqueueForRestoration creates a DeferredPromise that waits for a matching resolver or cancellation, with no unavailable-provider failure path. This accounts for the reported uninstall-and-reload trigger without executing the application.
- **Open implementation candidate:** https://github.com/microsoft/vscode/pull/328185 is verified OPEN and unmerged, with 'Fixes #125582' in its body. It proposes awaiting activation, delegating to an available provider, and otherwise showing an editor error with an Open With Default Editor action. Its claimed validation is PR-author evidence, not independently executed here.
