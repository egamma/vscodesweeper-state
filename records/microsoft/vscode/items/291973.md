## Summary

The requested sampling-parameter overrides are implemented as modelOptions, including null to omit top_p. The linked merged implementation covers the reported compatibility problem, so this can close as completed rather than as a duplicate of the closed related issue.

## Change summary

Allow custom endpoint models to override temperature and omit top_p so strict backends accept requests without a stripping proxy.

## Best solution

Use per-model modelOptions with {"temperature": 0.5, "top_p": null}; the existing implementation delivers the requested behavior without introducing another configuration object.
