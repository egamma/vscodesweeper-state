[https://github.com/microsoft/vscode/issues/291973](https://github.com/microsoft/vscode/issues/291973)

## Summary

The requested compatibility control is implemented and shipped: custom endpoint models now accept `modelOptions.temperature` and `modelOptions.top_p`, with `null` explicitly removing either parameter from the request body.

## Change summary

Allow BYOM users to override or omit sampling parameters so strict OpenAI-compatible endpoints do not reject requests containing both `temperature` and `top_p`.

## Best solution

Keep the shipped `modelOptions` configuration from commit 398cd5b425a09d852f5cb58af2fb16a7ae71ccda and document it in the custom language-model configuration reference; the original compatibility gap no longer requires code work.
