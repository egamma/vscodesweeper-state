# Issue #208683 — Can delete another entry while adding entry to object widget in Settings editor

[https://github.com/microsoft/vscode/issues/208683](https://github.com/microsoft/vscode/issues/208683)

## Summary

Still present on main: the object setting widget's remove action buttons remain enabled while in 'create' editing mode, allowing deletion of other entries during an add operation, which leaves the view in an inconsistent state.

## Change summary

Deleting an existing entry while adding a new entry to an object widget in the Settings editor leaves an empty/inconsistent entry in the view.

## Best solution

Guard the remove action in `getActionsForItem` (in `src/vs/workbench/contrib/preferences/browser/settingsWidgets.ts`) to disable or hide delete buttons when the model's edit key is 'create', preventing mutation of existing items during an add operation.
