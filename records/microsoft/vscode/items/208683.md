# Issue #208683 — Can delete another entry while adding entry to object widget in Settings editor

[https://github.com/microsoft/vscode/issues/208683](https://github.com/microsoft/vscode/issues/208683)

## Summary

The reported sequence still has a concrete failing path: deleting an existing object entry while adding another promotes the unsaved placeholder into the widget's data. Keep this confirmed Settings editor bug open; the defect is bounded and suitable for an implementation session.

## Change summary

Prevent deleting an existing object-setting entry from turning an unfinished new entry into an empty data row.

## Best solution

Keep unfinished object-entry drafts separate from committed entries during removal, so the requested deletion cannot introduce a phantom empty entry. Cover the interaction through the Settings tree renderer.
