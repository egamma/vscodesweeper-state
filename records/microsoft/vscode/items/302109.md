# Issue #302109 — Sessions: Terminal and command output is not visible when the agent runs commands, showing "The terminal is no longer available"

[https://github.com/microsoft/vscode/issues/302109](https://github.com/microsoft/vscode/issues/302109)

## Summary

Keep open: terminal-output failure was confirmed by a maintainer, and subsequent reports extend beyond the identified rendering fix. Neither that partial fix nor the related terminal-cleanup issues establishes completion of this team-authored report.

## Change summary

Agent command output becomes unavailable instead of remaining inspectable after completion or streaming during long-running commands.

## Best solution

Ensure the Agents Window exposes command identity, execution status, live output, and retained completed output without requiring users to rerun commands manually. First isolate the remaining failure by provider and lifecycle transition, preserving resource cleanup where an independently inspectable output record remains available.
