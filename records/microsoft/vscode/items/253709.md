# Issue #253709 — SCM Graph - The height of the source control graph changes every time when some elements are enabled/disabled

[https://github.com/microsoft/vscode/issues/253709](https://github.com/microsoft/vscode/issues/253709)

## Summary

Still reproduces on main: toggling the Repositories section in the SCM ViewPaneContainer triggers `updateBodySize` which resets `minimumBodySize`/`maximumBodySize`, causing the sibling Graph pane to resize. The height persistence across restarts is also affected by `restoreViewSizes` not accounting for the explorerEnabled config state properly. No fix found in git history.

## Change summary

The SCM Graph pane height resets when toggling the Repositories section on/off and is not preserved across VS Code restarts.

## Best solution

The `updateBodySize` method in `scmRepositoriesViewPane.ts` (line ~800) changes `minimumBodySize`/`maximumBodySize` when `explorerEnabledConfig` toggles, which triggers a relayout of the split view and displaces the Graph pane's user-set height. The fix should preserve sibling pane sizes when the Repositories pane's body size constraints change — likely by saving and restoring the Graph pane's size around the toggle, or by having the ViewPaneContainer redistribute only the delta from the toggled pane.
