# Issue #326513 — Extension API to restart all language servers

[https://github.com/microsoft/vscode/issues/326513](https://github.com/microsoft/vscode/issues/326513)

## Summary

This is essentially the same generic "restart all language servers" request as the 2019 issue, which a language-tooling maintainer explicitly declined in favor of per-extension restart commands — the maintainer improved vscode-languageserver-node so `client.restart()` is trivial for any language server extension to expose, rather than adding a core generic API/command.

## Change summary

Add a core extension API (`vscode.languages.restartLanguageServers()`) or workbench command to restart all running language servers at once, motivated by AI-agent worktree switching causing stale/cross-worktree language results.

## Best solution

Keep the decentralized model: language server extensions (TypeScript, ESLint, Pylance, etc.) each expose their own `<Name>: Restart` command via the command palette, and worktree-switching extensions can invoke those directly rather than needing a single core API; no core change is needed for this to work today.
