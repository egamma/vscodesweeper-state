[https://github.com/microsoft/vscode/issues/265190](https://github.com/microsoft/vscode/issues/265190)

## Summary

The requested opt-out is now implemented: setting chat.tools.terminal.outputLocation to terminal preserves agent terminals and their active executions when chat sessions are cleaned up. The default remains chat, but the reporter's minimum request—keeping terminals until manually closed—is covered.

## Change summary

Allow users to prevent Copilot-created terminals and debugging output from being destroyed when starting or leaving a chat session.

## Best solution

Use chat.tools.terminal.outputLocation: "terminal" to retain terminals outside the chat session lifetime, and close this request as completed by b1889b0104a9c88a4e7813aaf5c075cf3067ff1a.
