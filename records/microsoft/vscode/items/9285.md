[https://github.com/microsoft/vscode/issues/9285](https://github.com/microsoft/vscode/issues/9285)

## Summary

Keep open: toolbar-action hiding is only a partial implementation and does not provide user-configurable context menus or a menus.json-style configuration. This accepted Backlog request has 284 community upvotes, well above the promotion threshold.

## Change summary

Allow users to add, hide, organize, and conditionally display commands in VS Code menus.

## Best solution
