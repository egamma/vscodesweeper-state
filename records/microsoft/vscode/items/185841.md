# Issue #185841 — Make grey "Hidden Lines" line less prominent

[https://github.com/microsoft/vscode/issues/185841](https://github.com/microsoft/vscode/issues/185841)

## Summary

Keep open for a contrast-aware design decision: the standard diff editor still renders a filled hidden-lines bar, although its colors are customizable. This team-authored request has no verified issue-referencing fix, and the related issue is newer and primarily concerns interaction behavior.

## Change summary

Reduce the visual prominence of the diff editor's hidden-lines bar so it does not compete with code, inlay hints, and change highlighting.

## Best solution

Agree on a quieter default hidden-lines treatment while keeping its text and controls legible and distinguishing it from expanded unchanged code. Evaluate the standard diff editor separately from the existing compact disclosure treatment, using the current theme tokens rather than introducing another per-feature color setting.
