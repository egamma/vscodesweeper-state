# Issue #191833 — Better distinguish overlapping arrows

[https://github.com/microsoft/vscode/issues/191833](https://github.com/microsoft/vscode/issues/191833)

## Change summary

Make overlapping moved-code arrows distinguishable so their intersections do not suggest a connection within the same editor.

## Best solution
