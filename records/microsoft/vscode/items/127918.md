# Issue #127918 — Make minimap slider visible when scrolling 

[https://github.com/microsoft/vscode/issues/127918](https://github.com/microsoft/vscode/issues/127918)

## Summary

Valid feature request for a third showSlider mode. The existing `showSlider` setting only supports `always` and `mouseover`; neither shows the slider during keyboard/wheel scrolling. The `autohide` setting controls the entire minimap's visibility, not the slider specifically. No existing capability covers this request.

## Change summary

When `editor.minimap.showSlider` is `mouseover`, the slider should also become visible while the user is actively scrolling (mouse wheel, scrollbar, keyboard).

## Best solution

Add a third `showSlider` enum value (e.g. `'mouseover+scroll'` or a separate boolean) that toggles the slider's `.active` class in `onScrollChanged` in `src/vs/editor/browser/viewParts/minimap/minimap.ts`, with a debounced hide — mirroring how the `autohide: 'scroll'` path already toggles the minimap's `active` class. The CSS already handles `.minimap-slider.active { opacity: 1 }`.
