# Issue #127918 — Make minimap slider visible when scrolling 

[https://github.com/microsoft/vscode/issues/127918](https://github.com/microsoft/vscode/issues/127918)

## Summary

A real gap remains on current main: scrolling can reveal an auto-hidden minimap, but it does not reveal the viewport slider when `editor.minimap.showSlider` is `mouseover`. The request is already accepted in the Backlog and should remain open.

## Change summary

Show the minimap viewport slider while the editor is scrolling, without requiring the pointer to hover over the minimap.

## Best solution

Provide transient slider visibility during editor scrolling while preserving the existing always-visible and hover-visible behavior. Decide whether this expands the semantics of `editor.minimap.showSlider: "mouseover"` or requires a separate configuration value.

- **Trace:**
