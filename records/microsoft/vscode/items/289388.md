# Issue #289388 — Interleaved thinking block descriptions are misleading

[https://github.com/microsoft/vscode/issues/289388](https://github.com/microsoft/vscode/issues/289388)

## Summary

The misleading mixed-tense thinking descriptions were addressed on main: finalized thinking summaries are now explicitly generated as completed, past-tense actions.

## Change summary

Make interleaved thinking-block descriptions distinguish completed reasoning from work that has not happened yet.

## Best solution

Keep the completed-summary behavior from https://github.com/microsoft/vscode/commit/fe82a76fecf3efc81a970fd7610813a43c9859a7, which requires finalized thinking titles to begin with a past-tense verb.
