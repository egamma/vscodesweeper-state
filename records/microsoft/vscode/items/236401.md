# Issue #236401 — remote-cli `code` command works in bash, but zsh or tmux

[https://github.com/microsoft/vscode/issues/236401](https://github.com/microsoft/vscode/issues/236401)

## Summary

Keep open for investigation of where remote-cli PATH entries disappear during zsh startup or tmux session creation. The discussion contains an independent confirmation, but current source inspection does not establish the exact cause or a completed fix.

## Change summary

Preserve access to the remote `code` command when opening zsh or tmux instead of bash in a Remote-SSH terminal.

## Best solution

Establish where the injected remote-cli directory is lost between terminal environment construction and shell startup, then address the confirmed cause without overriding unrelated user PATH configuration. Investigate tmux separately before assuming its environment handling has the same cause as zsh.
