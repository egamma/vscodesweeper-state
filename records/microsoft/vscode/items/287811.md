# Issue #287811 — edited file link widget opens a read-only file diff

[https://github.com/microsoft/vscode/issues/287811](https://github.com/microsoft/vscode/issues/287811)

## Summary

The historical diff is intentionally read-only, but the requested discoverable way to open its current editable file is still missing from the editor toolbar. Current source provides enough resource identity and an existing Open File command to make this a bounded polish change.

## Change summary

Expose an Open File action from a chat historical-edit diff so users can move directly to the current editable file.

## Best solution

Show an Open File action in the editor title toolbar for chat-editing snapshot diffs. It should open the recovered live resource while leaving activation of the inline edit pill unchanged so it continues showing the historical diff.
