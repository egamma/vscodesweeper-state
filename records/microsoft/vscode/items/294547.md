# Issue #294547 — Clicking on the Unread filter in Command Center filters in all opened VS Code windows

[https://github.com/microsoft/vscode/issues/294547](https://github.com/microsoft/vscode/issues/294547)

## Summary

Still reproduces on main: the unread filter state is stored with StorageScope.PROFILE, which is shared across all VS Code windows. Clicking the filter in one window propagates to all windows using the same profile.

## Change summary

Clicking the Unread filter in Command Center applies the filter to all open VS Code windows instead of only the active one.

## Best solution

Change the filter storage in agentTitleBarStatusWidget.ts from StorageScope.PROFILE to a window-scoped mechanism (e.g. in-memory state or StorageScope.WORKSPACE) so that toggling the unread filter only affects the window where the user clicked.
