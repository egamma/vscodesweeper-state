# Issue #349201 — Proposal: Sandbox profiles per agent host

[https://github.com/microsoft/vscode/issues/349201](https://github.com/microsoft/vscode/issues/349201)

## Summary

Keep open for maintainer design review: current source forwards the same client sandbox values to every connected host, without the proposed persistent profile assignment. This team-authored proposal concerns sandbox boundaries and is protected from judgment closes.

## Change summary

Support named sandbox snapshots explicitly assigned as shared, reconnect-stable defaults for individual agent hosts.

## Best solution

Provide explicit host-owned sandbox defaults that survive reconnects without client overwrites, while preserving existing-session settings and runtime-managed restrictions. Maintainers should review shared-host assignment authority and whole-session fallback semantics before implementation.
