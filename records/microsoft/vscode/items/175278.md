# Issue #175278 — Issue reporting fails silently when bugs url is invalid

[https://github.com/microsoft/vscode/issues/175278](https://github.com/microsoft/vscode/issues/175278)

## Summary

Keep open: the reporter now has separate legacy and wizard implementations, and the wizard still classifies GitHub discussions URLs as issue-creation targets. The supplied steps suffice to retest the original silent failure; no qualifying fix or older canonical was established.

## Change summary

Handle extension bug-report URLs that are not GitHub issue repositories without silently failing or constructing an invalid issue-creation URL.

## Best solution

Recognize supported GitHub issue targets and preserve other valid reporting destinations as direct links, with visible feedback when submission cannot proceed. Check both reporter implementations so the original discussions-URL scenario has consistent behavior.
