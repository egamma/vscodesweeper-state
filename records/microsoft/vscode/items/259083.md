# Issue #259083 — Worktree within worktree not showing in UI

[https://github.com/microsoft/vscode/issues/259083](https://github.com/microsoft/vscode/issues/259083)

## Summary

Team-authored bug, still reproducible on main. The worktree detection in model.ts explicitly skips repositories of kind 'worktree', so nested worktree creation is never discovered. An open community PR (#267692) is attempting a fix.

## Change summary

Creating a worktree from within an existing worktree does not show the new worktree in the SCM UI because worktree detection is skipped for worktree-kind repositories.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/267692 which addresses this. The fix needs to allow worktree discovery when the current repository is itself a worktree, likely by removing or adjusting the early-return guard at `extensions/git/src/model.ts` line 812–814.
