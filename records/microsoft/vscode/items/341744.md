# Issue #341744 — GitHub Copilot Chat: Multi-line command explanation hides last line of terminal confirmation

[https://github.com/microsoft/vscode/issues/341744](https://github.com/microsoft/vscode/issues/341744)

## Summary

Thanks for the report and screenshot. This is a plausible layout bug in the chat tool confirmation widget. I could not confirm it from source because the effect depends on rendering and flex sizing. The report has a screenshot and a clear trigger (long command plus a multi-line explanation), so it should stay open and go to the chat area owners.

## Change summary

In the chat terminal-command confirmation, a multi-line risk explanation at the bottom hides the last line of a scrollable long command, and scrolling cannot reveal it.

## Best solution

Make the scrollable message area in chatConfirmationWidget.ts size itself so that the whole command is reachable by scrolling when the footer banner wraps to multiple lines. That means the scroll area must shrink or rescan when the banner height changes. Keep the banner outside the scroll area.
