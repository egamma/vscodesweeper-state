[https://github.com/microsoft/vscode/issues/298762](https://github.com/microsoft/vscode/issues/298762)

## Summary

Team-authored debt item requesting removal of the simple-browser extension (moving iframe browser support into core for web). The extension still exists on main (scoped to web-only after b4018e320b8), so the work remains undone.

## Change summary

Remove the simple-browser built-in extension and move its iframe-based browser functionality into VS Code core for the web target.

## Best solution

Delete `extensions/simple-browser/` after migrating the iframe-based browser view into `src/vs/workbench/contrib/browserView/` (or the existing integrated-browser contribution), keeping old command IDs registered as aliases for backward compatibility. The recent integrated-browser work is the natural landing spot for the core replacement.
