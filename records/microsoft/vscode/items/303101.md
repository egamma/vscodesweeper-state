# Issue #303101 — Terminal link detection includes Chinese period (。) as part of URL

[https://github.com/microsoft/vscode/issues/303101](https://github.com/microsoft/vscode/issues/303101)

## Summary

The primary complaint (。 in URLs) appears already handled by FORCE_TERMINATION_CHARACTERS in linkComputer.ts on current main; however, an open PR #314618 references this issue for additional CJK characters (！, ？). Keeping open because the PR is an active fix attempt that a human owns.

## Change summary

Terminal link detection incorrectly includes CJK full-width punctuation (。, ！, ？) as part of detected URLs.

## Best solution

Land https://github.com/microsoft/vscode/pull/314618 which adds ！ and ？ to FORCE_TERMINATION_CHARACTERS. The core character 。 is already in the termination list on main — verify it actually works end-to-end before closing, as the reporter saw it fail on 1.112.0 despite the character being present.
