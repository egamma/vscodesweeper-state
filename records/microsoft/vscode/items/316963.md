# Issue #316963 — Signing in... stays when I cancel the auth flow

[https://github.com/microsoft/vscode/issues/316963](https://github.com/microsoft/vscode/issues/316963)

## Summary

Valid bug filed by a team member during testplan testing of #316711. The "Signing in…" dialog in the Agents welcome flow persists after canceling the auth flow. No fix commit found on main; the bug is still present.

## Change summary

Canceling the GitHub auth flow during Agents window sign-in leaves a "Signing in…" overlay dialog stuck on screen.

## Best solution

Fix the cancel path in `sessionsSetUpService.ts` `_showSignInDialog` so the "Signing in…" dialog is dismissed when the auth flow is canceled or denied. The likely cause is that the `executeCommand` promise does not resolve promptly on certain cancel paths (e.g., when the user denies the browser popup), leaving `signingInDialogRef.dispose()` (line 334) unreached. The fix should ensure the overlay is cleaned up in all cancel/error paths, possibly by also disposing in a `finally` block or by listening for cancel signals from the auth session.
