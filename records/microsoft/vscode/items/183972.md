# Issue #183972 — Nonce does not appear to work on fish shell

[https://github.com/microsoft/vscode/issues/183972](https://github.com/microsoft/vscode/issues/183972)

## Summary

Still reproduces on main: the fish shell nonce is set with `set -l` (block-local scope) inside an `if` block, so it's empty by the time `__vsc_cmd_executed` and `__vsc_cmd_clear` reference it. An open PR (#313195) fixes this with a one-character change (`-l` → `-g`). Issue #286505 is a duplicate of this one.

## Change summary

Fish shell integration nonce variable is scoped to the `if` block and unavailable to event handlers, causing the rerun-command confirmation dialog to always appear.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/313195 which changes `set -l __vsc_nonce` to `set -g __vsc_nonce` in `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.fish`. Close https://github.com/microsoft/vscode/issues/286505 as a duplicate of this issue.
