# Issue #322678 — Feature request: allow per-option descriptions in snippet choice placeholders (`${1|...|}`)

[https://github.com/microsoft/vscode/issues/322678](https://github.com/microsoft/vscode/issues/322678)

## Summary

Current main has no way to attach descriptions to snippet-choice options, and no canonical issue owns the request. Route it to the snippets area and keep it under discussion because the representation requires a compatibility-sensitive product decision.

## Change summary

Allow each snippet choice value to carry explanatory text displayed alongside the value in the suggestion widget.

## Best solution

Define a backward-compatible representation for choice display metadata, preserve the inserted value separately, and expose the description through the existing completion-item label/detail fields. The design should avoid reinterpreting valid TextMate choice text or breaking snippet portability.
