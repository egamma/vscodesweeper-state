# Issue #322678 — Feature request: allow per-option descriptions in snippet choice placeholders (`${1|...|}`)

[https://github.com/microsoft/vscode/issues/322678](https://github.com/microsoft/vscode/issues/322678)

## Summary

Valid feature request to extend snippet choice placeholders with per-option descriptions. No existing issue covers this; the current `Choice` model in `snippetParser.ts` only stores plain `Text[]` options with no description support. Routes to the snippets area.

## Change summary

Allow snippet choice placeholder options to carry descriptions shown in the dropdown, mirroring how snippet-level descriptions appear in IntelliSense.

## Best solution

This would require extending the snippet grammar and the `Choice` class in `src/vs/editor/contrib/snippet/browser/snippetParser.ts` to support per-option descriptions, plus updating the suggest widget rendering in `snippetSession.ts`. The syntax design (inline separator vs. richer JSON object form) needs a product decision from a maintainer before implementation.
