# Issue #227709 — Allow opening chat code block in full editor

[https://github.com/microsoft/vscode/issues/227709](https://github.com/microsoft/vscode/issues/227709)

## Summary

The existing 'Insert into New File' action opens code block content in a new untitled editor, but this request from a team contributor likely asks for a lighter-weight 'open in editor' experience (e.g. read-only preview or split view) distinct from creating a new file. The feature remains unimplemented on main.

## Change summary

Allow opening a chat code block directly in a full editor pane for exploration, as a distinct action from 'Insert into New File'.

## Best solution

Add an action to the code block `...` menu that opens the code block content in a temporary or read-only editor (similar to peek or preview), preserving context with the chat response rather than creating an untitled file. Likely touches `src/vs/workbench/contrib/chat/browser/actions/chatCodeblockActions.ts`.
