# Issue #217832 — Background selection expands as adding more text, but find results do not update

## Summary

The notebook find implementation has received subsequent changes, but the supplied steps suffice to retest this specific behavior; no qualifying fix or older same-symptom canonical was established.

## Change summary

Notebook Find in Selection omits matches inside the expanded selection background after text is inserted.

## Best solution

Keep the effective notebook search scope synchronized with its displayed selection while editing, following the maintainer's stated direction. Retest insertion within a multiline selection before changing behavior; automatically disabling Find in Selection is not the accepted direction in the discussion.
