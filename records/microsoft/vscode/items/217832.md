# Issue #217832 — Background selection expands as adding more text, but find results do not update

[https://github.com/microsoft/vscode/issues/217832](https://github.com/microsoft/vscode/issues/217832)

## Summary

Real bug confirmed by a team member — find-in-selection results don't update when text is added within the selection in notebooks. No fix on main yet; the Dec 2024 comment notes layering complexity.

## Change summary

Notebook find-in-selection does not update match results when new matching text is typed within the selected range.

## Best solution

Tie the find-in-selection decorations to the find filters so the range updates as the user edits within it, keeping match counts and highlights in sync. The fix lives in the notebook find contribution (src/vs/workbench/contrib/notebook/browser/contrib/find/) and requires coordinating the selection range tracking with the find model's match updates.
