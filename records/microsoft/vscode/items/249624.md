# Issue #249624 — [json] JSON Schema anyOf error reporting is misleading

[https://github.com/microsoft/vscode/issues/249624](https://github.com/microsoft/vscode/issues/249624)

## Summary

The current best-match behavior is understood, but equally failing `anyOf` branches produce a diagnostic that misleadingly singles out one property. The issue should remain open while the JSON language tooling owners decide how to present an aggregate failure without flooding users with branch errors.

## Change summary

Improve JSON Schema `anyOf` diagnostics when every equally ranked alternative fails so one arbitrary branch is not presented as the sole cause.

## Best solution

Preserve best-match diagnostics when one branch is clearly closest, but use an aggregate `anyOf` diagnostic at the containing value when multiple branches tie; schema-provided custom error text could be considered separately if supported by the applicable schema dialect.
