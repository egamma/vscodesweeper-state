# Issue #81616 — Better Touch using

[https://github.com/microsoft/vscode/issues/81616](https://github.com/microsoft/vscode/issues/81616)

## Summary

The touch-selection capability remains missing, but the older, open touch-selection request already owns this work. Consolidate this report there, preserving its proposal to distinguish selection from scrolling by the gesture's initial direction.

## Change summary

Support touchscreen text selection by treating initially horizontal drags as selection and initially vertical drags as scrolling.

## Best solution

Resolve touchscreen selection under https://github.com/microsoft/vscode/issues/47770, considering this report's direction-based gesture proposal alongside the interaction alternatives already discussed there.
