# Issue #324396 — Bug?: New Agents Window model picker does not show all enabled Copilot models (WSL/SSH)

[https://github.com/microsoft/vscode/issues/324396](https://github.com/microsoft/vscode/issues/324396)

## Summary

Keep open as an account-selection defect, not a general request for identical model catalogs. The reporter confirmed that removing other signed-in accounts restores the remote models, and current remote authentication still has an account-selection path consistent with that symptom.

## Change summary

Remote Agents Window sessions show a reduced Copilot model catalog despite the UI displaying the intended Business account.

## Best solution

Make remote Copilot authentication and model discovery use the account represented by the active Copilot account selection, while preserving legitimate harness-specific model restrictions. Establish how that account preference reaches each remote connection and is reconciled when accounts change.
