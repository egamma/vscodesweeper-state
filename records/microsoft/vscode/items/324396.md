# Issue #324396 — Bug?: New Agents Window model picker does not show all enabled Copilot models (WSL/SSH)

[https://github.com/microsoft/vscode/issues/324396](https://github.com/microsoft/vscode/issues/324396)

## Summary

The reporter isolated a remote-session account-resolution defect: the Agents Window can use a different Copilot account than the UI indicates, producing the wrong model catalog. The workaround restores models but does not eliminate the stale-account path, so this should remain open and route to Agents Window and remote ownership.

## Change summary

Ensure WSL/SSH Agents Window sessions use the active Copilot account and expose its enabled models.

## Best solution

Make Agent Host authentication follow the selected/default Copilot account consistently across local and remote windows, revoke stale forwarded credentials when that account changes, and republish the model catalog.
