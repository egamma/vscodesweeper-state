# Issue #330764 — Inline toolset reference is replaced by its first child tool in the model-facing chat request

[https://github.com/microsoft/vscode/issues/330764](https://github.com/microsoft/vscode/issues/330764)

## Summary

The defect remains source-reproducible on current main, and the open draft PR https://github.com/microsoft/vscode/pull/330767 explicitly fixes this issue. Keep the issue open while that human-owned implementation is reviewed.

## Change summary

Inline toolset references incorrectly give the toolset token's source range to every expanded child tool, causing the first child to appear explicitly referenced.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330767, which keeps the prompt range on the toolset while retaining its children as available tools without inherited ranges.
