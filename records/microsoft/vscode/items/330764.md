# Issue #330764 — Inline toolset reference is replaced by its first child tool in the model-facing chat request

[https://github.com/microsoft/vscode/issues/330764](https://github.com/microsoft/vscode/issues/330764)

## Summary

Verified real bug on current main, and an open PR from the same author already implements the fix with a closing reference — per policy this stays open until that PR merges rather than being closed now.

## Change summary

When a toolset (e.g. `#read`) is referenced inline, the model-facing chat request mislabels the reference as the toolset's first child tool instead of the toolset itself.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330767, which fixes ChatRequestParser.tryToParseVariable in src/vs/workbench/contrib/chat/common/requestParser/chatRequestParser.ts to stop copying the parent toolset's varRange/varEditorRange onto its expanded child tools.
