# Issue #309411 — Inconsistent naming of different artifacts

[https://github.com/microsoft/vscode/issues/309411](https://github.com/microsoft/vscode/issues/309411)

## Summary

Keep open as artifact-label polish: current source still permits screenshot filenames and artifact labels to differ. The reporter supplied the requested prompts, and the existing grouping setting only partially addresses the request.

## Change summary

Use consistent, distinguishable screenshot names in agent output and the Artifacts view.
