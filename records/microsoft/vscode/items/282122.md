# Issue #282122 — Expect `Apply Changes to Workspace` to then close file diff and hide worktree

[https://github.com/microsoft/vscode/issues/282122](https://github.com/microsoft/vscode/issues/282122)

## Summary

Current source already closes matching multi-file diffs after applying changes, but does not automatically hide the worktree or archive the session. Keep this team-authored request open for a decision on that remaining lifecycle behavior; neither a qualifying fix reference nor an older canonical covering the full request was found.

## Change summary

After applying background-agent changes, dismiss the diff and consider hiding the SCM worktree or archiving the session.

## Best solution

Retain the existing post-apply diff closure and decide whether applying changes should also offer explicit session/worktree cleanup while preserving the ability to continue the session. Coordinate that decision with the related cleanup request rather than treating application as an implicit destructive operation.
