# Issue #66148 — [html] code complete for href anchors

[https://github.com/microsoft/vscode/issues/66148](https://github.com/microsoft/vscode/issues/66148)

## Summary

The requested completion remains absent on current main and is owned by the upstream HTML language service. No verified older issue reports the same observable gap, so this Backlog item should remain open and be classified as upstream.

## Change summary

Offer completion suggestions for element IDs when typing a same-document fragment in an HTML href attribute.

## Best solution

Extend vscode-html-languageservice completion to collect IDs from the current HTML document and suggest them for applicable href values beginning with `#`, then consume that service update in VS Code.
