# Issue #46814 — Issue reporter - disable extensions should be a button and not a link

[https://github.com/microsoft/vscode/issues/46814](https://github.com/microsoft/vscode/issues/46814)

## Summary

The legacy issue reporter still presents the reload-with-extensions-disabled action as link-styled inline text, so the requested visual distinction remains missing. Keep this team-authored request open; the newer reporter wizard does not establish that the legacy path was fixed.

## Change summary

Present the issue reporter's disable-all-extensions action as a recognizable button rather than a documentation-like link.
