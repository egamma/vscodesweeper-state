# Issue #275347 — Chat: Insert into Terminal should not auto trigger Suggestion

[https://github.com/microsoft/vscode/issues/275347](https://github.com/microsoft/vscode/issues/275347)

## Summary

Keep open: the current source still allows Chat’s Insert into Terminal action to trigger automatic suggestions. Clipboard pastes suppress suggestions, but this programmatic insertion bypasses that suppression.

## Change summary

Inserting a command from Chat automatically opens terminal suggestions, obscuring the inserted text.

## Best solution

Make Chat command insertion leave the command visible and unexecuted without automatically opening terminal suggestions, while preserving suggestions for subsequent typing and explicit invocation.
