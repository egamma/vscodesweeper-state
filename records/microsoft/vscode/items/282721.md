# Issue #282721 — Notebook diff editor doesn't preserve scroll position when switching to another tab and then back

[https://github.com/microsoft/vscode/issues/282721](https://github.com/microsoft/vscode/issues/282721)

## Summary

Keep open: the current notebook diff pane clears its list when switching tabs without saving and restoring its scroll position. No eligible open canonical or issue-referencing fix was found; the closed related reports do not resolve this team-authored issue.

## Change summary

Preserve the scroll position of a notebook diff when switching to another editor tab and back.

## Best solution

Retain per-input notebook diff scroll state across the editor pane's clearInput/setInput lifecycle, including untitled notebook pairs. Returning to an existing diff should preserve the viewport without changing initial-open navigation or explicit cell-selection behavior.
