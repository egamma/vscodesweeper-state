# Issue #236799 — The new paste with imports feature broke line insertion

[https://github.com/microsoft/vscode/issues/236799](https://github.com/microsoft/vscode/issues/236799)

## Summary

Confirmed in source: when a paste provider (e.g. TypeScript auto-imports) handles a full-line paste, the `pasteOnNewLine` semantics are lost because `PostEditWidgetManager.applyEditAndShowIfNeeded` applies the edit via `createCombinedWorkspaceEdit` at the cursor ranges without adjusting for full-line insertion. An open PR (#306565) attempts a fix but hasn't merged.

## Change summary

Copying a full line (no selection) and pasting into a file where a paste provider activates (e.g. importable symbol) inserts text inline instead of inserting as a new line above the cursor.

## Best solution

Land the fix from https://github.com/microsoft/vscode/pull/306565 (or a similar approach) that propagates `pasteOnNewLine` through the paste-provider path in `copyPasteController.ts` so that `applyEditAndShowIfNeeded` adjusts the insertion ranges to match full-line semantics when the copy was from an empty selection.
