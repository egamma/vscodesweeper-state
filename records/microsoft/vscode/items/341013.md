# Issue #341013 — Pill tabs - HC hover outlines not consistent

[https://github.com/microsoft/vscode/issues/341013](https://github.com/microsoft/vscode/issues/341013)

## Summary

Thanks for the report. A fresh, team-tested HC visual glitch in the pill-tab work; I could not run it, but the video and tab hover CSS are enough to retest. It stays open.

## Change summary

In HC themes, hovering an inactive pill tab sometimes shows a solid outline around the close action instead of the dashed tab outline.

## Best solution

Make the HC hover outline on pill tabs consistently dashed, so the close action's own hover or focus outline does not show solid inside the dashed tab outline. Check the `modern-ui-tabs` and HC rules in multiEditorTabsControl.ts and the tab CSS.
