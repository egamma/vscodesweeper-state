# Issue #197160 — Git - Auto Stash handles submodules incorrectly

[https://github.com/microsoft/vscode/issues/197160](https://github.com/microsoft/vscode/issues/197160)

## Summary

Native Git autostash now avoids the reported path with Git 2.27 or newer, but the legacy fallback still pops a stash without establishing that it created one. Keep this open for the remaining submodule-only failure on older Git versions.

## Change summary

Synchronizing with auto-stash enabled and only a changed submodule checkout can incorrectly apply an existing stash or report that no stash exists.

## Best solution

Ensure automatic stash restoration only restores a stash actually created by that operation, including in the legacy Git fallback. Preserve the existing native --autostash behavior for Git 2.27 and newer.
