# Issue #218033 — RangeError: Maximum call stack size exceeded.

[https://github.com/microsoft/vscode/issues/218033](https://github.com/microsoft/vscode/issues/218033)

## Summary

The Safari stack overflow remains source-reproducible on current main: the issue reporter's `beforeunload` handler calls `close()` on the window that is already closing, matching the reported recursion. The issue should remain open for a bounded lifecycle fix.

## Change summary

Closing the web issue reporter in Safari recursively invokes the window close path until JavaScript exceeds the call-stack limit.

## Best solution

Make issue-reporter window teardown idempotent so `beforeunload` performs cleanup without calling `close()` again, while preserving disposal of the auxiliary window and reporter.
