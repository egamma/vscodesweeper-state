# Issue #339056 — Insiders 1.141.0 .deb: chrome-sandbox lost setuid bit, app aborts with SUID sandbox FATAL on Ubuntu

[https://github.com/microsoft/vscode/issues/339056](https://github.com/microsoft/vscode/issues/339056)

## Summary

Keep open: multiple users confirm a startup abort caused by missing sandbox-helper permissions, and current packaging source supports the reported regression. This concerns a privileged sandbox component and requires human review under the security-sensitive keep-open rule.

## Change summary

Insiders Debian packages lose chrome-sandbox's setuid bit, preventing startup when unprivileged user namespaces are unavailable.

## Best solution

Ensure the distributed Debian package installs chrome-sandbox with the required root ownership and mode 4755, without weakening sandboxing or requiring users to change system security settings. Verify the final package and installed application's startup on an affected Linux configuration; existing test-job permission repairs do not establish package correctness.
