# Issue #339056 — Insiders 1.141.0 .deb: chrome-sandbox lost setuid bit, app aborts with SUID sandbox FATAL on Ubuntu

[https://github.com/microsoft/vscode/issues/339056](https://github.com/microsoft/vscode/issues/339056)

## Summary

Thanks for the detailed report. This is a milestoned (1.143.0) regression with a second confirmation on Debian, and an open PR already references it. I did not inspect the checkout or the CI logs. The cause (the setuid bit lost in the decomposed Linux stage tarball extraction) is inferred from the report and is unverified. Keeping it open while the linked PR is reviewed.

## Change summary

The Linux .deb for 1.141.0 ships chrome-sandbox without the setuid bit, so code-insiders aborts at startup with a SUID sandbox FATAL error.

## Best solution

Land https://github.com/microsoft/vscode/pull/341292 so the setuid bit on chrome-sandbox is preserved or reapplied when the .deb is built, then confirm with `dpkg-deb -c` that the mode is -rwsr-xr-x.
