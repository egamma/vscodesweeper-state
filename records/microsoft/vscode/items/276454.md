## Summary

The required SOCKS5 support has landed in Undici and current VS Code main consumes a newer Undici release containing that implementation, so this can be closed as completed.

## Change summary

Support extension-host fetch requests when `http.proxy` is configured with a `socks://` proxy URL.

## Best solution

Keep consuming Undici's shipped SOCKS5-capable `ProxyAgent`; current main resolves Undici 7.29.0 through `@vscode/proxy-agent`, so no separate VS Code proxy implementation is needed.
