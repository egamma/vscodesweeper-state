# Issue #276454 — fetch fails with InvalidArgumentError when proxy is set to socks://... in settings

[https://github.com/microsoft/vscode/issues/276454](https://github.com/microsoft/vscode/issues/276454)

## Summary

Already correctly triaged by a team member as an upstream dependency gap — undici (Node.js HTTP client) does not support SOCKS proxies. Labels, milestone, and routing are appropriate; no action needed.

## Change summary

Using fetch with a SOCKS proxy configured in VS Code settings throws InvalidArgumentError because undici only accepts http/https URLs.

## Best solution

Wait for upstream resolution of https://github.com/nodejs/undici/issues/2224 (SOCKS proxy support in undici). Once undici ships support, VS Code's @vscode/proxy-agent can integrate it. No actionable change in this repo until the dependency lands.
