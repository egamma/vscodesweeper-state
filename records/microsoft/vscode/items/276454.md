## Summary

Verified duplicate: the older open issue reports the same `Invalid URL protocol` failure when Node.js `fetch` receives a SOCKS proxy, and its discussion already covers extension-host consumers beyond GitHub Authentication.

## Change summary

Support SOCKS proxies in extension-host `fetch`, or report the unsupported proxy protocol clearly instead of throwing Undici's `InvalidArgumentError`.

## Best solution
