# Issue #332526 — Improve visibility of current file

[https://github.com/microsoft/vscode/issues/332526](https://github.com/microsoft/vscode/issues/332526)

## Summary

Genuine, well-corroborated design feedback on the new Modern UI tab styling — several independent users confirm the active/inactive tab contrast is hard to read — but it's a design/color decision for the team, not a defined bug with a fix commit, so this stays open under the existing `modernization` label rather than being closed.

## Change summary

Increase the visual contrast/opacity between the active and inactive editor tabs in the new 'Modern UI' tab styling so the currently-edited file is easy to identify.

## Best solution

Have the Modern UI design owners revisit the default active/inactive tab background and border contrast in src/vs/workbench/contrib/modernUI/browser/media/tabs.css and the color mapping in src/vs/workbench/services/themes/browser/modernTabColorCustomizations.ts; multiple commenters independently confirm the current defaults make the active tab hard to distinguish, especially in light themes like Solarized Light.
