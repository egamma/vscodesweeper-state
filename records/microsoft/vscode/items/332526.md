# Issue #332526 — Improve visibility of current file

[https://github.com/microsoft/vscode/issues/332526](https://github.com/microsoft/vscode/issues/332526)

## Summary

This is the same complaint as the earlier, more-upvoted open issue #330802 ("New UI has a bad UX"): the modern UI's tab coloring makes it hard to tell which tab is active. A commenter already linked #330802 here, so I'm proposing to consolidate.

## Change summary

In the new modernized UI, the active/inactive tab colors don't provide enough contrast to tell which file is currently open.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/330802, which is older, has more reactions (12 vs 4), and asks for the identical fix (a clearer visual distinction between the active and inactive tab).
