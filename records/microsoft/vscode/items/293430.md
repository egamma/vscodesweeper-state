# Issue #293430 — GitHub Copilot `file_search` glob with `\**\` (backslash double-star) produces partial or no results where `/**/` succeeds

[https://github.com/microsoft/vscode/issues/293430](https://github.com/microsoft/vscode/issues/293430)

## Summary

The corrected July retest and current source confirm a distinct, still-open bug: backslash-delimited globstars are forwarded without normalization, although VS Code's GlobPattern contract requires forward slashes. The older linked fix addressed workspace-folder scoping but did not resolve this separator-specific behavior.

## Change summary

Make Copilot file-search glob patterns containing backslashes behave identically to their forward-slash equivalents, including globstars matching zero or multiple path segments.

## Best solution

Canonicalize model-supplied glob separators before slash-sensitive path interpretation and search dispatch, using the shared inputGlobToPattern path so file_search and grep_search remain consistent. Add regression coverage for workspace-folder-prefixed globstars at zero, one, and multiple directory depths.
