# Issue #179742 — Provide a global context menu to auto expand lazy variables

[https://github.com/microsoft/vscode/issues/179742](https://github.com/microsoft/vscode/issues/179742)

## Summary

The debug maintainer explicitly concluded that a Variables context-menu item should not persistently change workspace settings and that the existing setting is sufficient, so this can be closed as designed.

## Change summary

Expose a global Variables context-menu toggle that immediately expands lazy variables and persists the `debug.autoExpandLazyVariables` preference.

## Best solution

Keep `debug.autoExpandLazyVariables` as an explicit setting and avoid a contextual action that writes persistent workspace configuration.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding a persistent setting toggle to this context menu conflicts with the project's preference for simple, uniform, genuinely contextual UI interactions.
- **Evidence:** Value and guardrail: "Simple, uniform UI and UI interactions" and avoiding configuration sprawl in the default product.
