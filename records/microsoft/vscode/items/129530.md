# Issue #129530 — Disassembly view: do not piggy back on existing step commands, introduce new ones

[https://github.com/microsoft/vscode/issues/129530](https://github.com/microsoft/vscode/issues/129530)

## Summary

The requested cleanup remains necessary on current main: all four shared stepping commands still inspect disassembly focus inside their handlers instead of using dedicated instruction-step commands.

## Change summary

Separate disassembly instruction stepping from the existing source-level step commands and select the appropriate commands through context-key registrations.

## Best solution

Give instruction stepping dedicated command IDs and conditionally expose those commands when the disassembly view is focused, while preserving the existing step commands and behavior everywhere else.
