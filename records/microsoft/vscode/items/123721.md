# Issue #123721 — Git conflict resolution Accept Current Change "ignores" addition of a single empty line

[https://github.com/microsoft/vscode/issues/123721](https://github.com/microsoft/vscode/issues/123721)

## Summary

Still reproduces on main: the `replaceRangeWithContent` method in `documentMergeConflict.ts` explicitly strips newline-only content, discarding the user's chosen change when it is a single empty line.

## Change summary

Accepting Current or Incoming change in a merge conflict silently drops the content when it consists of a single empty line.

## Best solution

Remove or fix the `isNewlineOnly` guard in `replaceRangeWithContent` (extensions/merge-conflict/src/documentMergeConflict.ts, lines 91-94) so that newline-only content is preserved instead of replaced with an empty string. The guard was likely added to avoid a trailing blank line artifact, so the fix should ensure the conflict-marker lines themselves are fully consumed without eating the user's actual content.
