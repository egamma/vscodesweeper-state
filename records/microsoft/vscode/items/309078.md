# Issue #309078 — Agents App: Keyboard shortcuts not coming through from VS Code

[https://github.com/microsoft/vscode/issues/309078](https://github.com/microsoft/vscode/issues/309078)

## Summary

Keep open: current main imports user keybindings into the Agents Window only from the default profile, so customizations in another active VS Code profile still do not carry over. The issue is team-authored and no commit explicitly referencing #309078 was found, so the current partial coverage cannot support a completed close.

## Change summary

Make VS Code keyboard-shortcut customizations available in the Agents Window.

## Best solution

Define which VS Code profile the Agents Window should follow, then make its keybinding service consume and live-reload that profile's customized keybindings without changing unrelated profile resources.
