# Issue #267153 — Cannot accept suggestion from accessible view

[https://github.com/microsoft/vscode/issues/267153](https://github.com/microsoft/vscode/issues/267153)

## Summary

Keep open: current source treats focus on an Accessible View toolbar action as leaving the view, which clears the inline suggestion before it can be accepted. The existing accessibility and inline-completions labels already route this correctly.

## Change summary

Accepting an inline suggestion with Enter from the Accessible View toolbar should insert the suggestion into the originating editor.

## Best solution

Keep the Accessible View and pending suggestion alive while keyboard focus moves into its toolbar, so the accept action applies the inspected suggestion. Preserve cancellation when the view is genuinely dismissed.
