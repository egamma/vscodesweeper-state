# Issue #63534 — Support for global or project-level variables

[https://github.com/microsoft/vscode/issues/63534](https://github.com/microsoft/vscode/issues/63534)

## Summary

This remains a valid Backlog feature request with 20 community upvotes. Current main lacks configurable user/workspace snippet variables, while the open draft PR only addresses the narrower name-and-email use case.

## Change summary

Allow snippets to resolve user-defined values from global, workspace, or folder configuration, potentially including environment-backed values.

## Best solution

Add a synchronous, configuration-backed snippet resolver—such as an `editor.snippets.variables` mapping honoring settings scope—without exposing arbitrary process environment state. Review https://github.com/microsoft/vscode/pull/315156 for the narrower identity variables, but retain this issue for the broader configurable-variable requirement.
