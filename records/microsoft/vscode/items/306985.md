# Issue #306985 — Static index.html should be served by browser without the agent spinning a host server via terminal

[https://github.com/microsoft/vscode/issues/306985](https://github.com/microsoft/vscode/issues/306985)

## Summary

Valid feature request from a team member. The integrated browser already supports file:// URLs and the open_browser_page tool accepts file: scheme, but agents still default to spinning up terminal-based web servers for static HTML. The gap is in agent behavior/prompting, not the platform capability.

## Change summary

Agents should serve static index.html files via the integrated browser's existing file:// support instead of starting a terminal-based web server.

## Best solution

Update the agent tool instructions or model description for the open_browser_page tool to explicitly guide agents to use file:// URLs for static HTML files instead of launching a web server. The fix likely lives in the tool_instructions prompt wiring (see src/vs/workbench/contrib/browserView/electron-browser/tools/openBrowserTool.ts modelDescription) or in agent host prompt configuration.
