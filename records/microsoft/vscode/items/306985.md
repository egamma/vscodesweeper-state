# Issue #306985 — Static index.html should be served by browser without the agent spinning a host server via terminal

[https://github.com/microsoft/vscode/issues/306985](https://github.com/microsoft/vscode/issues/306985)

## Summary

Keep open: the integrated browser supports opening local HTML directly, but the inspected source does not provide browser-managed HTTP hosting or connect that preview to an agent-created localhost URL. This team-authored Backlog request remains distinct from the completed tab-deduplication work.

## Change summary

Preview static HTML through browser-managed local hosting without agent-run terminal servers or redundant browser tabs.

## Best solution

Provide a coherent static-preview workflow that agents can reuse without launching a terminal server or replacing an already-open preview. Browser ownership should first settle when direct file loading suffices and when managed HTTP hosting is required.

- **Fit:** aligned
- **Reason:** Reducing terminal setup and redundant browser tabs improves the integrated developer inner loop and makes human-agent interactions more consistent.
