# Issue #135591 — Support codicons in file decorations

[https://github.com/microsoft/vscode/issues/135591](https://github.com/microsoft/vscode/issues/135591)

## Summary

Still a valid open feature request: codicon support in file decoration badges is implemented behind the `codiconDecoration` proposed API but has not been finalized — the known blocker (only one decoration displays when a codicon is present) remains unresolved as of the last team comment (Oct 2024).

## Change summary

Allow extensions to use ThemeIcon (codicons) in file decoration badges instead of only plain strings.

## Best solution

Finalize the `codiconDecoration` proposed API by solving the rendering limitation where codicon decorations suppress co-existing text badges (the `::after` single-span constraint in `decorationsService.ts`). The proposed `FileDecoration2` class in `src/vscode-dts/vscode.proposed.codiconDecoration.d.ts` would then graduate to the stable API surface.
