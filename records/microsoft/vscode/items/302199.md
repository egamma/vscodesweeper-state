# Issue #302199 — Chat content flashes/scrolls oddly when first sending a steering message

[https://github.com/microsoft/vscode/issues/302199](https://github.com/microsoft/vscode/issues/302199)

## Summary

Keep open: the screenshots capture a transient chat scroll jump, and a maintainer confirmed that the scope likely includes regular chat rather than only Copilot CLI. Current source contains partial anchoring logic for pending rows, but there is no distinct, citable fix or end-to-end regression coverage proving the flash is resolved.

## Change summary

Sending a steering message during an active response temporarily scrolls chat content upward before the viewport settles back into the correct position.

## Best solution

Keep the active response and viewport anchor stable while steering rows are inserted, dispatched, or removed, for both regular chat and Copilot CLI sessions. Add coverage that exercises the complete pending-row and viewport-layout transition rather than only selecting the sticky response.
