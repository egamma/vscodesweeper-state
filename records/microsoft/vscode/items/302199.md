# Issue #302199 — Chat content flashes/scrolls oddly when first sending a steering message

[https://github.com/microsoft/vscode/issues/302199](https://github.com/microsoft/vscode/issues/302199)

## Summary

The scroll jitter when sending steering messages has been fixed on main by commit debbc28b7d5, which corrected scroll-follow behavior for queued/steering messages. The root cause was that scrollToEnd silently no-oped because pending rows were recreated with new instances, causing _lastItem to diverge from the tree.

## Change summary

Chat content flashes and scrolls oddly (jitter) when first sending a steering message, briefly showing the content scrolled up before settling.

## Best solution

Keep the shipped fix in commit debbc28b7d5 — it fixes scrollToEnd to reveal the tree's actual last node instead of a stale reference, and drops the min-height reservation that pushed pending rows down. No further change needed.
