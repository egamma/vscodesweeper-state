# Issue #339785 — Status bar items not vertically centered in modern ui with default density

[https://github.com/microsoft/vscode/issues/339785](https://github.com/microsoft/vscode/issues/339785)

## Summary

The default-density offset is present in current source, but the existing layout test intentionally centers items within a rail that includes the gap above the painted status bar. Keep this open for a design decision about centering when the status bar has a distinguishable background.

## Change summary

Center Modern UI status bar items within their visible background band at default layout density.

## Best solution

Make the default-density status bar read as consistently centered with neutral, debug, and customized backgrounds. The modernization owner should settle whether the centering reference is the painted band or the larger bottom rail before changing the existing layout contract.
