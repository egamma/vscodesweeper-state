# Issue #339785 — Status bar items not vertically centered in modern ui with default density

[https://github.com/microsoft/vscode/issues/339785](https://github.com/microsoft/vscode/issues/339785)

## Summary

Confirmed in source: for the Modern UI floating-panels layout at default (non-compact) density, two stylesheets disagree on status bar padding, and the more specific one wins, producing exactly the asymmetric top/bottom spacing the reporter measured — but a dedicated unit test asserts this exact asymmetry as intentional 'centered' behavior, so a maintainer needs to confirm whether it's a real regression or a deliberate (if confusing) perceptual-centering design.

## Change summary

In the Modern UI floating-panels layout at default density, status bar items sit visibly above the vertical center of the status bar's own background band instead of being centered.

## Best solution

A maintainer should resolve the conflict between src/vs/workbench/browser/media/floatingPanels.css (symmetric padding, comment says 'vertically center status bar items') and src/vs/workbench/contrib/modernUI/browser/media/statusBar.css (asymmetric 0/size40 override that wins by specificity): either confirm the asymmetry is intentional (and clarify/rename the misleading comment and test), or make the two stylesheets agree on simple symmetric centering and update the 'centers status bar items within the floating bottom rail' test in modernUI.contribution.test.ts to match.
