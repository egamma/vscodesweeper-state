# Issue #305153 — Git Files Changed Count badge changed functionality

[https://github.com/microsoft/vscode/issues/305153](https://github.com/microsoft/vscode/issues/305153)

## Summary

The aggregation gap remains on current main: `scm.countBadge: all` counts only repositories selected for display, despite promising all provider counts. Keep this report open as the oldest verified report of that symptom.

## Change summary

Restore the Source Control activity badge's total across ordinary workspace repositories independently of repository selection.

## Best solution

Make the `all` badge include every non-hidden workspace repository while preserving exclusion of hidden agent worktrees and the existing `focused` and `off` modes. Repository selection should not suppress pending changes from that total.
