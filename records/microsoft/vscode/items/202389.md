# Issue #202389 — MiniMap: Side = Left Breaks EditorGroup.Border

[https://github.com/microsoft/vscode/issues/202389](https://github.com/microsoft/vscode/issues/202389)

## Summary

The editor group border color does not extend the full height when the minimap is positioned on the left side. No fix has been committed on main, and a commenter confirmed the issue persists on v1.114 (April 2026). The bug is still valid and should stay open.

## Change summary

Setting `editor.minimap.side` to `left` causes the `editorGroup.border` color to stop rendering just below the breadcrumbs instead of extending to the status bar.

## Best solution

Investigate the interaction between the minimap-left layout and the grid separator sash rendering. The grid sash (drawn by the `SerializableGrid` / `SplitView` separator system) should extend the full height of each editor group view regardless of the minimap's position. The fix likely lives in the editor layout or the editor group view's container sizing when the minimap is on the left.
