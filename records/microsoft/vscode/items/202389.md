# Issue #202389 — MiniMap: Side = Left Breaks EditorGroup.Border

[https://github.com/microsoft/vscode/issues/202389](https://github.com/microsoft/vscode/issues/202389)

## Summary

The visual defect remains on current main and was independently confirmed in VS Code 1.114. The left minimap and editor-group separator share the same stacking tier, allowing the minimap to cover the separator below the group header.

## Change summary

Keep the themed editor-group border visible for the full group height when the minimap is positioned on the left.

## Best solution

Establish an editor-scoped stacking order in which the group separator remains visible above editor content, including a left-side minimap, without changing layering for every SplitView consumer or interfering with editor overlays.

- **Behavior:**

  > With multiple editor groups and a visible `editorGroup.border`, the separator must run continuously across the full editor-group height regardless of whether the minimap is on the left or right. The existing border color and thickness must remain unchanged. Acceptance should cover both minimap positions and confirm that editor overlays still render correctly.
- **Trace:**

  > EditorPart.updateStyles in src/vs/workbench/browser/parts/editor/editorPart.ts forwards `EDITOR_GROUP_BORDER` to the grid separator. The horizontal SplitView rule in src/vs/base/browser/ui/splitview/splitview.css paints the full-height separator pseudo-element at `z-index: 5`, while src/vs/editor/browser/viewParts/minimap/minimap.css assigns the minimap the same `z-index: 5`; when placed at the left edge, the later editor content obscures the separator below the header. This source path matches the report and the independent VS Code 1.114 confirmation at https://github.com/microsoft/vscode/issues/202389. The boundary is editor-group presentation: generic SplitView layering and unrelated editor widgets must not change unless their behavior is explicitly validated.
- **Open decisions:**

  - Which existing screenshot or browser-level harness should own the regression check for the themed border and left minimap?
