# Issue #202389 — MiniMap: Side = Left Breaks EditorGroup.Border

[https://github.com/microsoft/vscode/issues/202389](https://github.com/microsoft/vscode/issues/202389)

## Summary

The visual defect remains source-reproducible on current main: a left-side minimap occupies the same edge as the editor-group separator and can paint over it because both layers use z-index 5. A recent independent confirmation reports the same behavior in VS Code 1.114.

## Change summary

Keep the configured editor-group border visible for the full group height when the minimap is positioned on the left.

## Best solution

Preserve the split-view separator above editor content, including a left-side minimap, while leaving minimap rendering and editor-group layout unchanged. Cover the stacking invariant in the split-view browser tests.
