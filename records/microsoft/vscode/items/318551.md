# Issue #318551 — Agent mode stopped modifying the scripts in jupyter notebook

[https://github.com/microsoft/vscode/issues/318551](https://github.com/microsoft/vscode/issues/318551)

## Summary

The logs confirm that Agent mode attempts the notebook edit but rejects a stale or mismatched cell ID. A later independent report shows the same failure, so this remains a current notebook-agent bug needing area ownership.

## Change summary

Agent mode fails to modify existing Jupyter notebook cells because edit_notebook_file cannot resolve the supplied cell ID.

## Best solution

Route this to the chat notebook owners and make notebook editing recover from invalidated cell identities, either by refreshing notebook context and retrying or by preserving stable identities across notebook changes.
