# Issue #282251 — Allow Ctrl and Shift select functions when deleting breakpoints

[https://github.com/microsoft/vscode/issues/282251](https://github.com/microsoft/vscode/issues/282251)

## Summary

Keep open: the Breakpoints view still explicitly disables multiple selection, so selectively deleting several breakpoints remains unsupported. Existing per-file and remove-all actions do not cover arbitrary selections, and no matching open canonical was identified.

## Change summary

Allow Ctrl-click and Shift-click selection of breakpoints followed by Delete to remove only the selected breakpoints.

## Best solution

Support standard multi-selection and selection-aware deletion in the core Breakpoints view, preserving unselected breakpoints and existing single-breakpoint actions.
