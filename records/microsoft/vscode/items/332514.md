# Issue #332514 — Starting a new Copilot thread with pasted text always leads to "#attachment:Pasted text #1" as the chat title

[https://github.com/microsoft/vscode/issues/332514](https://github.com/microsoft/vscode/issues/332514)

## Summary

Traced on current main: when a pasted block is converted to a `Pasted text #N` attachment and the user types nothing else, `ChatModel.getDefaultTitle` derives the title from the raw parsed-message text, which is literally the placeholder token `#attachment:Pasted text #1` rather than any content-derived text — so every such chat gets the same indistinguishable title.

## Change summary

Starting a new chat by pasting text (with no other typed content) always produces the chat title '#attachment:Pasted text #1' instead of a distinct, content-based title.

## Best solution

In src/vs/workbench/contrib/chat/common/model/chatModel.ts, `ChatModel.getDefaultTitle` should detect when the first request's message text is just an attachment/variable reference (e.g. matches `^#attachment:`) and fall back to deriving the title from the underlying paste content (the `code`/`pastedLines` field of the matching `paste`-kind entry in `variableData.variables`, see `IChatRequestPasteVariableEntry` in chatVariableEntries.ts) instead of showing the raw reference token.
