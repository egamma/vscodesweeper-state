## Summary

This is the canonical tracking issue for GPT-5.2/5.2-codex/5.3-codex early-stopping behavior, confirmed by a team member as an upstream OpenAI model issue ('not VS Code specific'). Multiple duplicates (#283908, #283776, #283688, #285755, #286608) already point here. Still active — most recent report is from March 2026 with GPT-5.3-Codex.

## Change summary

GPT-5.2 and related OpenAI models frequently stop responding mid-task in Copilot agent mode, requiring manual 'continue' prompts to resume.

## Best solution

Continue tracking with OpenAI until the model-side early-stopping behavior is resolved. The team member confirmed an open issue exists with OpenAI. If VS Code can add client-side mitigations (e.g. auto-continue on clean mid-step stops, or better error surfacing for tool-call validation failures like the 'missing explanation' error in comment 8), those would be valuable interim improvements — but the root fix is upstream.
