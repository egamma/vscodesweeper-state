# Issue #309043 — Agents: Add model_reasoning_effort to custom agents and prompts.

[https://github.com/microsoft/vscode/issues/309043](https://github.com/microsoft/vscode/issues/309043)

## Summary

This remains a valid custom-agent configuration gap: custom agents and prompt files can select a model, but their metadata does not provide a stable way to request reasoning effort. The On Deck milestone does not block review, but no duplicate or completed implementation is established.

## Change summary

Allow custom agents and prompt files to declare the model reasoning effort used for chat requests.

## Best solution

Define a provider-neutral reasoning-effort metadata field for agent and prompt files, validate its supported values, and carry it through customization resolution into model invocation while preserving the existing UI/default selection when the field is absent.

- **Trace:**
