# Issue #309043 — Agents: Add model_reasoning_effort to custom agents and prompts.

[https://github.com/microsoft/vscode/issues/309043](https://github.com/microsoft/vscode/issues/309043)

## Summary

Valid feature request: custom agents and prompts support a `model` front-matter field but do not expose a `reasoningEffort` (or equivalent) field. The reasoning effort infrastructure exists in the agent host layer but is not wired into the prompt file parser or chat mode data model.

## Change summary

Allow custom agents and prompt files to specify a reasoning effort level (e.g. low/medium/high) alongside the existing `model` field.

## Best solution

Add a `reasoning-effort` header attribute to the prompt file parser (`src/vs/workbench/contrib/chat/common/promptSyntax/promptFileParser.ts`) and thread it through `ICustomChatModeData` / `IChatMode` in `chatModes.ts`, connecting it to the existing `ReasoningEffort` infrastructure in `src/vs/platform/agentHost/common/reasoningEffort.ts`. This would let `.prompt` and custom agent YAML files declare reasoning effort the same way they declare `model`.
