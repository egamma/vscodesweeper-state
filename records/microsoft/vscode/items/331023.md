# Issue #331023 — option to disable formatting after editing by Copilot

[https://github.com/microsoft/vscode/issues/331023](https://github.com/microsoft/vscode/issues/331023)

## Summary

Accepting ('Keep') a Copilot chat edit performs an explicit save specifically to run save participants, and the format-on-save participant already gates on the existing `editor.formatOnSave` setting — so turning that setting off (globally or per-language) already suppresses the formatting the reporter wants to avoid.

## Change summary

Add a setting to disable the automatic formatting that runs when a Copilot-edited file is kept/saved.

## Best solution

Point the reporter at `editor.formatOnSave` (and `editor.formatOnSaveMode`), which the Keep action's save already respects — no new Copilot-specific toggle is needed; if they want formatting on manual saves but not on Keep specifically, that's a finer distinction not currently supported and would need its own follow-up if there's real demand.

  > Thanks for the report. Accepting a Copilot edit ('Keep') triggers an explicit save specifically so save participants run — and formatting-on-save is one of those participants, gated by the regular `editor.formatOnSave` setting (see `editor.formatOnSaveMode` too). So turning `editor.formatOnSave` off (globally, or per-language via a language-specific settings override) already prevents the formatting you're seeing after Keep, since it's the same code path as a manual save. If what you actually want is formatting on normal saves but not specifically after a Copilot Keep, that's a narrower ask than what's here — feel free to open a fresh, more specific request for that if it's still needed.
