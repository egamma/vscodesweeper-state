# Issue #115403 — Feature Request : Mark files as sensibles (like files with passwords)

[https://github.com/microsoft/vscode/issues/115403](https://github.com/microsoft/vscode/issues/115403)

## Summary

Keep this accepted Backlog request open: existing file-exclusion and read-only settings do not provide confirmation before displaying sensitive contents. It has 25 upvotes, and the canonical search did not establish an older issue covering the same screen-exposure scenario.

## Change summary

Allow users to mark a file as sensitive and require explicit confirmation before revealing its contents whenever it is opened.

## Best solution

Have the editor and Explorer owners define an opt-in reveal-confirmation experience for sensitive files, including reopening and restored editors. Treat it as protection against accidental screen disclosure, not encryption or access control, and explicitly define which other content-display surfaces are covered.
