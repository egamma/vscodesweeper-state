# Issue #115403 — Feature Request : Mark files as sensibles (like files with passwords)

[https://github.com/microsoft/vscode/issues/115403](https://github.com/microsoft/vscode/issues/115403)

## Summary

This accepted Backlog request remains necessary: 25 community upvotes protect it from staleness closure, and current file-exclusion settings do not provide confirmation before displaying sensitive content. Route it to the workbench editor area for a product and implementation decision.

## Change summary

Allow users to mark files as sensitive so opening them requires confirmation before their contents are displayed.

## Best solution

Add a workspace-scoped sensitive-file pattern or resource list integrated with the workbench editor-opening path, showing a protected placeholder until the user explicitly reveals the file. The design should cover openings from Explorer, Quick Open, history, and links without treating `files.exclude` as equivalent protection.
