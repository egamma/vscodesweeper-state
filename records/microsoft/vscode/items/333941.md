# Issue #333941 — Chat: editing text before an inline #file: reference deletes the reference

[https://github.com/microsoft/vscode/issues/333941](https://github.com/microsoft/vscode/issues/333941)

## Summary

Confirmed on current main: the onDidChangeModelContent handler in chatDynamicVariables.ts only recovers a reference's range when a change fully encloses it, so an edit before the #file: reference falls into the else branch and deletes the reference text via executeEdits. An open PR already targets this fix, so the issue should stay open pending review of that PR rather than being auto-fixed or closed.

## Change summary

Land (or iterate on) the linked fix PR https://github.com/microsoft/vscode/pull/333965, which proposes to preserve the #file reference when editing text before it — review it against the described root cause in chatDynamicVariables.ts's onDidChangeModelContent handler.
