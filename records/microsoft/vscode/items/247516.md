# Issue #247516 — font is not reflected when updated in vscode setting 

[https://github.com/microsoft/vscode/issues/247516](https://github.com/microsoft/vscode/issues/247516)

## Summary

The confirmed Linux Snap user-font discovery problem is addressed by a landed change that stops overriding XDG_DATA_HOME. Propose closing as completed; the separate Windows font-size observation is not evidence of the same defect.

## Change summary

Fonts installed in ~/.local/share/fonts are not used by the Linux Snap installation when selected through editor.fontFamily.

## Best solution

Keep the host font-discovery behavior restored by commit 9dadd5ad1defcc3140bcdff44517284aeaf5bb91, allowing user-installed fonts to work without moving them into /usr/share/fonts.
