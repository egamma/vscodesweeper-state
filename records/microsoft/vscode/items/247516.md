# Issue #247516 — font is not reflected when updated in vscode setting 

[https://github.com/microsoft/vscode/issues/247516](https://github.com/microsoft/vscode/issues/247516)

## Summary

The confirmed Linux Snap failure to discover user-installed fonts is addressed by a landed launcher fix that stops overriding XDG_DATA_HOME. Propose closing as completed based on the matching source change; runtime behavior was not exercised.

## Change summary

Fonts installed under ~/.local/share/fonts are ignored by the Snap package even though system-wide fonts work.

## Best solution

Retain the launcher fix in 9dadd5ad1defcc3140bcdff44517284aeaf5bb91, allowing font discovery to use the user's normal data directory rather than a Snap-specific replacement.
