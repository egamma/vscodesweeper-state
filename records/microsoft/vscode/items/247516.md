# Issue #247516 — font is not reflected when updated in vscode setting 

[https://github.com/microsoft/vscode/issues/247516](https://github.com/microsoft/vscode/issues/247516)

## Summary

The snap font fix (b62b4161a0b, shipped in 1.96) should cover this, but reporters on 1.99.3 still cannot use fonts from ~/.local/share/fonts. The needs_update logic only runs on snap version changes, so the symlink may not be created in all cases. A team member already linked this to #232578; keeping open as the fix appears incomplete for some configurations.

## Change summary

Custom fonts installed in ~/.local/share/fonts are not picked up by the VS Code snap package, even after the 1.96 font-config fix.

## Best solution

Investigate why the font symlink fix from b62b4161a0b doesn't work for these reporters — likely the needs_update guard in resources/linux/snap/electron-launch prevents the symlink from being created when fonts are installed after the last snap revision change. The fix may need to always verify the symlink exists, not just on version bumps.
