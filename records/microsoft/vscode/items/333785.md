# Issue #333785 — Agents window sessions show in-progress despite being already done

[https://github.com/microsoft/vscode/issues/333785](https://github.com/microsoft/vscode/issues/333785)

## Summary

Fixed on main: the merged PR (referenced as related items) added a turn-completion refresh path that clears the stale main-chat status, and the current checkout has both the production fix and a matching regression test for exactly this scenario.

## Change summary

A session's row keeps showing Working/In Progress after its background subagent/hidden chat finishes, because the parent row's status is derived from a stale main-chat status once the session-state subscription has expired.

## Best solution

Keep the shipped fix: on `ChatTurnComplete`, `baseAgentHostSessionsProvider.ts` now calls `_keepChatSessionStateAlive(e.channel)` and `_refreshSessions()` so the aggregate/main-chat status is refreshed even after the background subscription lapses; the dedicated test covers the exact stale→Completed transition.
