# Issue #331371 — Agents window: '/' and '#' menus don't appear in omni bar but a black outline shows

[https://github.com/microsoft/vscode/issues/331371](https://github.com/microsoft/vscode/issues/331371)

## Summary

Real, confirmed bug in the Agents window omni input, already being addressed by an open fixing PR — keep open until it merges rather than closing now.

## Change summary

Typing `/` or `#` in the Agents window omni bar shows a black-outlined empty box instead of the expected suggest menu (or, per maintainer, should just hide the menu entirely).

## Best solution

Land https://github.com/microsoft/vscode/pull/331375, which sets `suggestOnTriggerCharacters = !isOmniInput` in chatInputPart.ts to hide the trigger-character suggest widget specifically for the omni input, matching the maintainer's stated expectation that it should be hidden entirely.
