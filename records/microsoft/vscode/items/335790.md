# Issue #335790 — The ✨ **Generate Commit Message** action is not available when a workspace is backed by a virtual file system

[https://github.com/microsoft/vscode/issues/335790](https://github.com/microsoft/vscode/issues/335790)

## Summary

Keep open as a feature request: Copilot's commit-message action and its implementation currently depend on the built-in Git provider. Supporting GitHub Repositories requires an integration capability, not a configuration change.

## Change summary

Make Copilot commit-message generation available for pending changes in GitHub Repositories virtual workspaces.

## Best solution

Provide commit-message generation that reads the virtual provider's pending changes and populates its SCM input without committing automatically. Coordinate the Copilot implementation with the provider's supported integration surface; removing the menu restriction alone would not deliver working generation.

In extensions/copilot/src/extension/conversation/vscode-node/conversationFeature.ts:306-315, the handler resolves a Git repository through IGitCommitMessageService and writes the result to that repository's inputBox.
- **Provider integration boundary:** extensions/copilot/src/platform/git/vscode/gitExtensionServiceImpl.ts obtains its API from vscode.git.
