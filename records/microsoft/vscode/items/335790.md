# Issue #335790 — The ✨ **Generate Commit Message** action is not available when a workspace is backed by a virtual file system

[https://github.com/microsoft/vscode/issues/335790](https://github.com/microsoft/vscode/issues/335790)

## Summary

Confirmed on main: the Generate Commit Message menu entry is gated to `scmProvider == git` and its service implementation (extensions/copilot/src/extension/prompt/vscode-node/gitCommitMessageServiceImpl.ts) is built directly on the built-in Git extension's API, so it structurally cannot appear for a GitHub Repositories virtual-fs SCM provider today — a real, undecided feature gap rather than a simple bug.

## Change summary

The Copilot Generate Commit Message action never appears for workspaces backed by a virtual file system (e.g. GitHub Repositories), because it is scoped only to the built-in Git provider.

## Best solution

Product decision needed: either extend the commit-message service to work against any SCM provider that can supply a diff (not just vscode.git), or explicitly scope this as Git-provider-only; either way the fix belongs in extensions/copilot's git commit-message contribution, not a one-line when-clause tweak.
