# Issue #335200 — Co-author Profile Picture Not  Displaying in Source Control Panel

[https://github.com/microsoft/vscode/issues/335200](https://github.com/microsoft/vscode/issues/335200)

## Summary

Traced in source: co-authors in the SCM commit hover are always rendered with a generic `$(account)` icon, never an avatar — the avatar lookup only queries the primary author/committer, not co-authors, so this is a real, still-open gap rather than a fixed or as-designed behavior.

## Change summary

Co-author entries in the Source Control commit hover show a generic account icon instead of the co-author's GitHub profile picture, while the primary author's avatar displays correctly.

## Best solution

Extend the avatar-fetching pipeline in extensions/git/src/historyProvider.ts (and extensions/git/src/blame.ts) to also query avatars for `commit.coAuthors`, and thread those avatar URLs into `appendContent` in extensions/git/src/hover.ts so co-authors render with `![name](avatarUrl|width=...,height=...)` like the primary author instead of the static `$(account)` icon.
