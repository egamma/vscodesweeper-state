# Issue #335200 — Co-author Profile Picture Not  Displaying in Source Control Panel

[https://github.com/microsoft/vscode/issues/335200](https://github.com/microsoft/vscode/issues/335200)

## Summary

Traced in the Git extension source: the avatar query built for the SCM history hover only includes the commit author's name/email, never co-authors', so co-authors always render with the generic `$(account)` icon rather than a fetched avatar — this is a missing capability, not a regression bug.

## Change summary

In the Source Control commit hover, a commit's co-author never shows a fetched profile picture, only the plain account icon, while the main author's avatar loads correctly.

## Best solution

Extend the avatar query in extensions/git/src/historyProvider.ts to also request avatars for `commit.coAuthors` (by email), and thread the results into getHistoryItemHover/appendContent in extensions/git/src/hover.ts so co-authors render an avatar image like the main author instead of the static account icon.
