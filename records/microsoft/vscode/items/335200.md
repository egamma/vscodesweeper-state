# Issue #335200 — Co-author Profile Picture Not Showing Up in Source Control Panel

[https://github.com/microsoft/vscode/issues/335200](https://github.com/microsoft/vscode/issues/335200)

## Summary

Traced in source: co-authors in the commit hover always render the generic `$(account)` icon and never an avatar image, unlike the primary author — this isn't a regression but a genuine capability gap in the avatar-fetch API, so it's an unrouted feature request rather than a simple bug.

## Change summary

Co-author entries in the Source Control commit/history hover don't show a GitHub profile picture, only the primary author does.

## Best solution

Extend the `vscode.git` extension API's avatar-fetch mechanism (`SourceControlHistoryItemDetailsProvider.provideAvatar` / `AvatarQuery`, keyed today only by commit hash + primary author) to also resolve avatars for co-author emails, and update extensions/git/src/hover.ts's `appendContent` to render them; the actual GitHub-avatar lookup lives in the externally-owned vscode-pull-request-github extension implementing this provider, so it needs coordinated design across both.
