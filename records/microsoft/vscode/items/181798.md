# Issue #181798 — punctuation echo issues under MacOS

[https://github.com/microsoft/vscode/issues/181798](https://github.com/microsoft/vscode/issues/181798)

## Summary

Keep open: the reporter repeatedly confirmed punctuation-specific VoiceOver typing failures, including a browser comparison that narrowed the problem. The editor now supports a different input path through EditContext, but neither a fixing commit nor an eligible canonical duplicate was established; the existing steps suffice for a current-build retest.

## Change summary

VoiceOver with punctuation echo enabled fails to announce certain quotes and opening brackets while typing in the editor, although cursor navigation can announce them.

## Best solution

Restore punctuation typing feedback without changing cursor-navigation announcements or VoiceOver verbosity preferences. First compare current desktop and web behavior with EditContext enabled and disabled against a plain textarea, then establish whether the remaining defect belongs to editor input synchronization or the Chromium accessibility bridge.
