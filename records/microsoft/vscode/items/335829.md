# Issue #335829 — Confgiure permissions should use a setting tag

[https://github.com/microsoft/vscode/issues/335829](https://github.com/microsoft/vscode/issues/335829)

## Summary

Current main still constructs Configure Permissions from a manually maintained list of setting IDs and wildcard prefixes. This team-authored cleanup remains valid and should stay open until the settings share a queryable tag.

## Change summary

Replace the manually enumerated Configure Permissions settings query with a shared setting tag.

## Best solution

Give every setting owned by the permissions configuration surface a common configuration tag and have Configure Permissions query that tag, preserving the current result set while allowing future permission settings to opt in at registration.
