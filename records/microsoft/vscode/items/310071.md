- **Proposed comment:**

  > Thanks for the suggestion! This is actually already supported via the `argument-hint` header attribute in `.prompt.md`, agent, and skill files. You can add it to your prompt's YAML front-matter like:
  > 
  > ```yaml
  > ---
  > description: Jira workflow helper
  > argument-hint: [start|refine|review] [issue-number]
  > ---
  > ```
  > 
  > The hint is shown during autocomplete in the chat input. This shipped in VS Code 1.106 (https://github.com/microsoft/vscode/commit/1c2e29a3c7a). Please reopen if this doesn't fully cover your use case.
