# Issue #310071 — Support subcommands for prompts and skills with argument-hint headers

[https://github.com/microsoft/vscode/issues/310071](https://github.com/microsoft/vscode/issues/310071)

## Summary

Existing argument-hint headers provide inline guidance, but they do not supply the structured, selectable subcommands requested here. Keep this open as a feature request; no verified older canonical issue was found.

## Change summary

Support structured subcommand and argument suggestions for a single prompt or skill slash command, such as /jira [start|refine] [args].

## Best solution

Have the chat customization owners evaluate a structured completion contract for prompt and skill arguments, preserving existing free-form argument-hint text. The remaining capability is selectable subcommands with their own descriptions, not another placeholder mechanism.
