# Issue #310071 — Support subcommands for prompts and skills with argument-hint headers

[https://github.com/microsoft/vscode/issues/310071](https://github.com/microsoft/vscode/issues/310071)

## Summary

Real gap: `argument-hint` in prompt/skill headers is still just a free-text placeholder string (chatInputCommandArgumentHint.ts, chatInputEditorContrib.ts) with no structured sub-command/argument syntax parsed or surfaced as selectable options. A prior review's implemented-on-main close (commit 1c2e29a3c7a) was refuted by a second review, and I found no later fix on main, so this stays open as a feature request.

## Change summary

Support a structured sub-command/argument syntax in `argument-hint` headers of .prompt.md/SKILL.md files so the chat UI can parse and present sub-commands as selectable options, similar to Copilot CLI's slash-command UX.

## Best solution

If pursued, extend the prompt header parsing (promptHeader / PromptHeaderAttributes.argumentHint) and the chat input completion/hint rendering (chatInputCommandArgumentHint.ts, chatInputEditorContrib.ts, agentHostInputCompletions.ts) to recognize a structured sub-command list and expose it as completion items — this needs a maintainer-defined syntax/contract before implementation.
