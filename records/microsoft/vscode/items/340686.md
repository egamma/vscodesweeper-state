# Issue #340686 — The color contrast ratio of the placeholder text “Generate code” is 3.592:1 against its background, which is below the required ratio of 4.5:1. : A11y_Visual Studio Code Copilot _Inline Chat_Color Contrast

[https://github.com/microsoft/vscode/issues/340686](https://github.com/microsoft/vscode/issues/340686)

## Summary

Thanks for the report. The inline chat placeholder color comes from the theme token `inlineChatInput.placeholderForeground`, which defaults to `input.placeholderForeground`. That default likely gives the reported 3.59:1 contrast in the default theme. Keeping this open as an accessibility contrast bug.

## Change summary

The placeholder text in the inline chat and Quick Chat inputs has contrast below 4.5:1 against its background.

## Best solution

Adjust the default `input.placeholderForeground` (or the inline chat override) so it reaches at least 4.5:1 in the default dark and light themes, and check the Quick Chat placeholder too.
