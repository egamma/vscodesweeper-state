# Issue #340686 — The color contrast ratio of the placeholder text “Generate code” is 3.592:1 against its background, which is below the required ratio of 4.5:1. : A11y_Visual Studio Code Copilot _Inline Chat_Color Contrast

[https://github.com/microsoft/vscode/issues/340686](https://github.com/microsoft/vscode/issues/340686)

## Summary

Thanks for the report. The shared placeholder color is `input.placeholderForeground`, which is the foreground at 50% opacity in the light and dark themes. That plausibly gives the roughly 3.6:1 contrast reported. This is an accessibility polish item in the shared input colors, not a close candidate.

## Change summary

Placeholder text in the Inline Chat and Quick Chat inputs has about 3.6:1 contrast, below the WCAG 4.5:1 minimum.

## Best solution

Raise the contrast of `input.placeholderForeground` in the default themes, or set a higher-contrast placeholder color for the chat inputs. Keep the change consistent across the other inputs that share the token.
