# Issue #347141 — chat tab context menu has editor window options in the chat window

[https://github.com/microsoft/vscode/issues/347141](https://github.com/microsoft/vscode/issues/347141)

## Summary

Chat tabs still inherit the generic editor context menu, exposing actions unrelated to chats. Keep this team-authored report open; the inappropriate menu is identifiable in source, while the complete intended chat action set needs agreement.

## Change summary

Remove inapplicable editor actions, including Reopen Editor With..., from chat-tab context menus in chat windows.

## Best solution

Provide a context menu appropriate to the clicked chat, preserving supported chat operations and ordinary file-editor menus. Agree which inherited editor actions belong on chat tabs before implementing the full cleanup.
