# Issue #94201 — Display Language doesn't update automatically

[https://github.com/microsoft/vscode/issues/94201](https://github.com/microsoft/vscode/issues/94201)

## Summary

The gap remains on current main: direct or synchronized locale changes update argv.json without prompting the running instance to restart.

## Change summary

Prompt running VS Code instances to restart after an external or synchronized display-language change.

## Best solution

Detect external locale changes, compare them with the active language, and offer a restart without duplicating prompts from the Configure Display Language command.
