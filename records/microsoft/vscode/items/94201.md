# Issue #94201 — Display Language doesn't update automatically

[https://github.com/microsoft/vscode/issues/94201](https://github.com/microsoft/vscode/issues/94201)

## Summary

Keep open: restart prompts cover changing language through the command, but not editing argv.json or receiving a synchronized locale change. The requested notification remains a distinct gap; no qualifying older canonical or concrete fixing commit was established.

## Change summary

Notify users that a restart is required when the display language changes through argv.json edits or Settings Sync.
