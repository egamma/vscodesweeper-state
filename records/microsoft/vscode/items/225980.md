# Issue #225980 — Cannot move cell when change the window.zoomLevel

[https://github.com/microsoft/vscode/issues/225980](https://github.com/microsoft/vscode/issues/225980)

## Summary

Still reproduces on main: the notebook DnD coordinate calculation in `toCellDragEvent` uses raw `event.clientY - getBoundingClientRect().top` without accounting for window zoom factor, causing incorrect drop target resolution at non-zero zoom levels.

## Change summary

Notebook cell drag-and-drop fails when `window.zoomLevel` is set to a non-zero value because coordinates are not adjusted for zoom.

## Best solution

Adjust the coordinate math in `cellDnd.ts` (`toCellDragEvent` and related methods) to account for the window zoom factor using `getDomNodeZoomLevel` or equivalent, similar to how other VS Code drag operations handle zoom.
