# Issue #234676 — Dynamically change run buttons to debug when breakpoints are placed

[https://github.com/microsoft/vscode/issues/234676](https://github.com/microsoft/vscode/issues/234676)

## Summary

A real discoverability gap remains: VS Code offers separate run and debug actions but does not dynamically switch based on breakpoints. This team-authored feature request is protected from judgment-based closure and should remain open.

## Change summary

Make run-file and run-test buttons start debugging when relevant breakpoints are present.

## Best solution

Define predictable breakpoint-to-action semantics, then update the testing gutter behavior in `testingDecorations.ts`; run-file providers may require separate coordination so the behavior remains consistent and does not unexpectedly override explicit user preferences.
