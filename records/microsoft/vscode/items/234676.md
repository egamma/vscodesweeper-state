# Issue #234676 — Dynamically change run buttons to debug when breakpoints are placed

[https://github.com/microsoft/vscode/issues/234676](https://github.com/microsoft/vscode/issues/234676)

## Summary

Keep open: existing test controls support explicitly choosing Debug, but do not automatically switch when breakpoints are added. This team-authored request identifies a distinct discoverability gap; the older related issues do not own the same behavior across file and test run buttons.

## Change summary

Automatically switch file and test run buttons to debugging when the user places breakpoints.

## Best solution

Define consistent breakpoint-aware behavior for test gutter actions and participating file-run contributions, including which breakpoints trigger the switch and how an explicit Run choice is preserved. Coordinate the testing UI with language-owned file-run actions rather than treating a fixed Debug preference as fulfillment.
