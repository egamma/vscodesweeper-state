# Issue #26338 — [html] Javascript intellisense in inline scripts from external references

[https://github.com/microsoft/vscode/issues/26338](https://github.com/microsoft/vscode/issues/26338)

## Summary

This long-standing, highly upvoted (126 👍) feature request for JS intellisense in inline <script> tags with external references remains unimplemented on current main. The HTML extension's JS language service host creates an isolated TS service per script block with no module resolution or external file awareness. Three related PRs are open but unmerged. The issue should stay open as a valid Backlog item.

## Change summary

Provide JavaScript intellisense in inline <script> blocks for symbols from external <script src="..."> references and imports.

## Best solution

The HTML extension's `javascriptMode.ts` language service host needs to be reworked to support module resolution and awareness of other <script> tags' exports. The open PR https://github.com/microsoft/vscode/pull/193590 (resolve JS imports from HTML script tags) and https://github.com/microsoft/vscode/pull/171547 (Volar integration) are the active implementation candidates — landing either would address the core ask. A related narrower issue https://github.com/microsoft/vscode/issues/114115 tracks import support specifically.
