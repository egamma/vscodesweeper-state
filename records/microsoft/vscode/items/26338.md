# Issue #26338 — [html] Javascript intellisense in inline scripts from external references

[https://github.com/microsoft/vscode/issues/26338](https://github.com/microsoft/vscode/issues/26338)

## Summary

The requested cross-file IntelliSense remains absent from current main, while multiple open PRs explicitly attempt to implement it. With 127 community upvotes, a Backlog milestone, and active implementation candidates, the issue should remain open while those PRs are reviewed.

## Change summary

Provide IntelliSense in inline HTML scripts and event attributes for symbols and typings supplied by externally referenced JavaScript files.

## Best solution

Review and consolidate the existing implementation work, particularly https://github.com/microsoft/vscode/pull/171547 and https://github.com/microsoft/vscode/pull/193590, then land an approach that lets the embedded TypeScript service resolve external scripts relative to the HTML document without regressing existing embedded-script support.
