# Issue #146670 — Inline suggestions are not displayed as ghosted text with HC themes

[https://github.com/microsoft/vscode/issues/146670](https://github.com/microsoft/vscode/issues/146670)

## Summary

Keep open for an accessible default-color design: the customization tokens already exist, but the requested high-contrast foreground defaults remain unset. A maintainer accepted considering a change, subject to contrast requirements; neither an existing capability nor a verified canonical fully resolves the request.

## Change summary

Give inline suggestions visually subordinate foreground defaults in high-contrast themes without requiring individual theme overrides.

## Best solution

Agree on high-contrast ghost-text defaults that distinguish suggestions from committed text while preserving readability. Evaluate both plain and syntax-highlighted suggestions before selecting the colors and contrast acceptance threshold.
