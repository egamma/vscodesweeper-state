# Issue #305344 — Show terminal tool explanation in UI

[https://github.com/microsoft/vscode/issues/305344](https://github.com/microsoft/vscode/issues/305344)

## Summary

Keep open: current terminal cards can display model-provided intention for Agent Host sessions, but the built-in terminal tool still exposes explanation and goal through a confirmation hover rather than the completed card. This partially addresses the request without establishing completion of the team-authored issue.

## Change summary

Surface the terminal tool's model-provided explanation or goal prominently so users can understand commands, including after execution.

## Best solution

Give terminal cards a consistent, readable statement of purpose across the built-in tool and Agent Host, while retaining access to the actual command. Settle which text leads and how much remains visible in completed cards before implementing the remaining built-in-tool coverage.
