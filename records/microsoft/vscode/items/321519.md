# Issue #321519 — Feature Request: Let extensions add custom options to the main "Session Target" dropdown menu

[https://github.com/microsoft/vscode/issues/321519](https://github.com/microsoft/vscode/issues/321519)

## Summary

Valid feature request for an extension API to register custom session types in the Agents Window's session-type picker dropdown. No such API exists today — the internal ISessionsProvidersService is not exposed to extensions.

## Change summary

Allow extensions to add custom options to the Agents Window session-type picker dropdown, enabling direct pass-through to custom local agent harnesses without double model invocation.

## Best solution

Expose a proposed extension API (e.g. `vscode.chat.registerSessionType`) that lets extensions register entries in the session-type picker, backed by the existing internal ISessionsProvidersService in src/vs/sessions/services/sessions/browser/sessionsProvidersService.ts. This would let custom CLI harnesses appear as first-class session targets without intermediary model interpretation.
