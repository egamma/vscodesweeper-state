# Issue #288471 — Add setting to disable automatic file reading - require explicit context sharing only in Copilot Chat

[https://github.com/microsoft/vscode/issues/288471](https://github.com/microsoft/vscode/issues/288471)

## Summary

Current main still silently auto-approves model-initiated reads inside the workspace, and the existing implicit-context setting only controls forwarding the active editor. This is a security-sensitive data-sharing control request, so it should remain open for a product and runtime-permissions decision.

## Change summary

Add an opt-in Copilot Chat mode that reads only explicitly shared files, or asks before every additional file read.

## Best solution

Provide a strict, opt-in runtime permission mode that requires one-time approval for model-initiated file reads or limits reads to explicitly attached resources, while preserving today's automatic workspace-context behavior as the default. Because enforcement belongs to the agent runtime, the control should be authoritative at the runtime permission boundary rather than only filtering context in the workbench UI.
