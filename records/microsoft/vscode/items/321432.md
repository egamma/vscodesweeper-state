# Issue #321432 — Agent turn hangs indefinitely when a streaming response stalls (no idle timeout in messagesApi/responsesApi SSE read loop)

[https://github.com/microsoft/vscode/issues/321432](https://github.com/microsoft/vscode/issues/321432)

## Summary

Still open on main: the telemetry-only watchdog (PR #321671) was merged then reverted the same day (#321842), leaving both messagesApi.ts and responsesApi.ts without any idle timeout or stream-stall guard. The underlying hang is confirmed and unmitigated.

## Change summary

Agent turns hang indefinitely when an Anthropic Messages API streaming response stalls because the SSE read loop has no idle timeout.

## Best solution

Re-land the idle watchdog (telemetry-only first pass, then an abort/reject follow-up) in `extensions/copilot/src/platform/endpoint/node/messagesApi.ts` and add the same to `responsesApi.ts`. Wire the request CancellationToken through so user cancellation can break a stuck body read.
