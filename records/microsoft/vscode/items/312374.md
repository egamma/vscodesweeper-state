# Issue #312374 — Wbt.clearMarks is not a function

[https://github.com/microsoft/vscode/issues/312374](https://github.com/microsoft/vscode/issues/312374)

## Summary

The error is caused by running Copilot Chat 0.45.1 against an older VS Code performance API. Current VS Code contains the required API, the extension declares VS Code 1.117.0 as its minimum version, and another reporter confirmed that upgrading resolved the identical error.

## Change summary

Copilot Chat fails with `Wbt.clearMarks is not a function` when used with an older VS Code release.

## Best solution

Keep the synchronized performance API shipped in commit 6afe18b48d11e7d12cfcd2174f859b7ee2319beb and enforce the extension's declared minimum VS Code version; affected users should upgrade VS Code.
