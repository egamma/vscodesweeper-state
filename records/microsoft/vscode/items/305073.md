# Issue #305073 — [SCM] Staging multiple selected ranges fail and corrupts source

[https://github.com/microsoft/vscode/issues/305073](https://github.com/microsoft/vscode/issues/305073)

## Summary

Keep open and route to Git: current source drops additional selections within the same changed hunk. The reported corruption needs further validation, and the older sequential-staging reports do not establish a duplicate of this simultaneous-selection defect.

## Change summary

Staging multiple selected ranges should stage every selected change without introducing unrelated changes or corrupting content.

## Best solution

Make the built-in Git range-staging path honor all selected portions of a changed hunk and preserve unselected content. Validate the resulting index contents independently of the diff display, including the reported corruption case.
