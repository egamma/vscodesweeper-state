# Issue #293427 — Queued UI could be nicer / smoother

[https://github.com/microsoft/vscode/issues/293427](https://github.com/microsoft/vscode/issues/293427)

## Summary

Keep open: queued prompts still render as transcript rows rather than a dedicated queue above the input. The UI refresh tracker explicitly lists this work as unfinished; it is newer and does not replace this report.

## Change summary

Present queued chat prompts above the input with a calmer, smoother layout.

## Best solution

Provide a compact queue associated with the chat composer, keeping pending prompts distinguishable from sent conversation turns. Settle its scrolling and steering presentation before implementation, while preserving existing queue operations.
