# Issue #76545 — Hyper modifier is unknown

## Summary

Still unimplemented on main: ScanCode.Hyper exists but maps to KeyCode.Unknown, so the Hyper modifier cannot be used in keybindings. A niche but valid feature request for power users who remap Caps Lock to Hyper (Mod3).

## Change summary

Support the Hyper (Mod3) modifier key in VS Code's keybinding system so users who remap Caps Lock to Hyper can create Hyper+Key shortcuts.

## Best solution

Add Hyper as a recognized modifier in the keybinding system — map ScanCode.Hyper to a real KeyCode in src/vs/base/common/keyCodes.ts, update the keybinding resolver and UI to treat it as a modifier. This is a non-trivial change touching the keybinding pipeline end-to-end and is Linux-specific (Mod3/Mod5).
