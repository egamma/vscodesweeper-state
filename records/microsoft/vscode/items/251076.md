# Issue #251076 — File protocol links in editor do not open in WSL

[https://github.com/microsoft/vscode/issues/251076](https://github.com/microsoft/vscode/issues/251076)

## Summary

The bug remains in current main: editor link handling passes an absolute `file:` URI through unchanged even when the containing model belongs to a Remote WSL workspace, causing the local Windows filesystem to receive the open request.

## Change summary

Absolute file-protocol links detected in editor-backed test output should open through the active WSL remote filesystem rather than the Windows host filesystem.

## Best solution

Make editor link resolution preserve the active remote model's scheme and authority when opening an absolute `file:` URI, matching the established terminal-link behavior while leaving links in local editors unchanged.

- **Trace:**
