# Issue #110218 — Allow extensions to contribute dynamic submenus

[https://github.com/microsoft/vscode/issues/110218](https://github.com/microsoft/vscode/issues/110218)

## Summary

This remains the canonical, well-supported request for dynamic extension-contributed menus. Current main still exposes only static contribution points, and the Backlog milestone plus 75 community upvotes strongly support keeping it open.

## Change summary

Allow extensions to populate menus and submenus dynamically when their entries cannot be declared in advance.

## Best solution

Design an extension API for precomputed or synchronously supplied dynamic menu contents, preserving context-menu responsiveness and disposal semantics. The implementation belongs in the extension API and workbench menu contribution bridge.
