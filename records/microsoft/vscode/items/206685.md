# Issue #206685 — Toggle between minimal / default size for VS Code sidebar and last custom size.

[https://github.com/microsoft/vscode/issues/206685](https://github.com/microsoft/vscode/issues/206685)

## Summary

A real layout capability remains missing: current main can hide or optimally resize the primary side bar, but cannot toggle between a compact width and the user's last custom width. The existing under-discussion classification is appropriate while the interaction and exact compact-size semantics are decided.

## Change summary

Add a quick way to toggle the primary side bar between a compact or default width and its last user-selected width.

## Best solution

Provide a keybindable layout command that preserves the last expanded primary-side-bar width and toggles between it and a defined compact width; avoid adding permanent UI unless design review finds a discoverability need.

## Evidence

- **current visibility behavior:** src/vs/workbench/browser/actions/layoutActions.ts registers `workbench.action.toggleSidebarVisibility`, whose implementation only calls `setPartHidden`; it does not toggle widths.
- **current double-click behavior:** src/vs/workbench/browser/parts/sidebar/sidebarPart.ts exposes `preferredWidth` as the active view's optimal width with a 300px floor, and src/vs/base/browser/ui/grid/grid.ts resizes to that preferred width on sash reset. This does not restore the user's preceding custom width.
- **current persistence:** src/vs/workbench/browser/layout.ts persists one `sideBar.size` value and restores it through `LayoutStateKeys.SIDEBAR_SIZE`; there is no second compact/custom width state.
- **related issue:** https://github.com/microsoft/vscode/issues/207837 is younger, closed, and reports width loss while moving between displays rather than the same requested two-state toggle, so it is not a valid canonical duplicate for this re-reviewed item.
- **older related request:** https://github.com/microsoft/vscode/issues/158603 is open and older but asks for default and per-view widths; it does not report the same observable need to toggle between compact and last-custom widths.
