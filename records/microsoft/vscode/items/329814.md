# Issue #329814 — No IntelliSense suggestions for rel attribute values in <link> element

[https://github.com/microsoft/vscode/issues/329814](https://github.com/microsoft/vscode/issues/329814)

## Summary

The missing suggestions are confirmed in the current HTML language-service data rather than caused by the editor integration. Keep this Backlog Candidates item open during its community-review window and track the required upstream metadata work.

## Change summary

Provide IntelliSense suggestions for standardized, space-separated values of the `rel` attribute on HTML `<link>` elements.

## Best solution

Add the standardized link-relation tokens to `@vscode/web-custom-data`, regenerate the HTML language service's built-in data, and cover both empty and partially populated `<link rel>` values with completion tests before consuming the updated service in VS Code.
