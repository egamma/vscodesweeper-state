# Issue #329814 — No IntelliSense suggestions for rel attribute values in <link> element

[https://github.com/microsoft/vscode/issues/329814](https://github.com/microsoft/vscode/issues/329814)

## Summary

Confirmed by tracing the language-service source: `rel` has no `valueSet` defined in the built-in HTML data, so `vscode-html-languageservice`'s `collectAttributeValueSuggestions` never offers value completions for it on any element (`<a>`, `<area>`, `<link>` alike) — it's a data gap, not a `<link>`-specific defect. It's already assigned to the HTML/CSS language-service owner but has no area label yet.

## Change summary

No IntelliSense value suggestions appear when typing `rel="` inside a `<link>` element.

## Best solution

Add a `valueSet` (e.g. common link types like `stylesheet`, `icon`, `preload`, `dns-prefetch`, `manifest`, etc.) for the `rel` attribute in the HTML data model — this lives in the `microsoft/vscode-html-languageservice` repo's `webCustomData.ts`/`@vscode/web-custom-data`, which is vendored into `extensions/html-language-features`, not authored directly in this repo.
