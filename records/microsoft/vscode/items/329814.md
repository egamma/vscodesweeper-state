# Issue #329814 — No IntelliSense suggestions for rel attribute values in <link> element

[https://github.com/microsoft/vscode/issues/329814](https://github.com/microsoft/vscode/issues/329814)

## Summary

Confirmed via the upstream `vscode-html-languageservice` custom HTML data: unlike attributes such as `crossorigin` (which has a `valueSet`), the `rel` attribute definition for `<a>`, `<link>`, and `<area>` has no `valueSet`, so no value completions are ever offered — this is a real, longstanding gap rather than a regression, already correctly labeled and assigned to the HTML maintainer.

## Change summary

Typing `<link rel="` in an HTML file offers no completion suggestions for link-type values (e.g. stylesheet, icon, preload).

## Best solution

Add a `linkTypes`-style `valueSet` (stylesheet, icon, preload, alternate, canonical, dns-prefetch, manifest, modulepreload, etc.) for the `rel` attribute in `vscode-html-languageservice`'s `src/languageFacts/data/webCustomData.ts`, mirroring the existing `xo` valueSet used for `crossorigin`; the fix lives upstream in that package, then flows into `extensions/html-language-features` on the next dependency bump.
