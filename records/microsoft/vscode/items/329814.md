# Issue #329814 — No IntelliSense suggestions for rel attribute values in <link> element

[https://github.com/microsoft/vscode/issues/329814](https://github.com/microsoft/vscode/issues/329814)

## Summary

Confirmed via source: the shared HTML data model (`webCustomData.ts` in the `vscode-html-languageservice` package consumed by the built-in HTML Language Features extension) defines a `rel` attribute for `<link>`, `<a>`, and `<area>` but never gives it a `valueSet`, so the completion provider has no enumerated values (`stylesheet`, `preload`, `icon`, `noopener`, …) to suggest — this is a real, narrow data gap, already assigned to a maintainer.

## Change summary

Typing `<link rel="` and invoking IntelliSense produces no attribute-value suggestions for the `rel` attribute.

## Best solution

Add a `valueSet` (or an inline enumerated `values` list) for the `rel` attribute on `link`/`a`/`area` in the HTML data model — the fix belongs upstream in `microsoft/vscode-html-languageservice`'s `src/languageFacts/data/webCustomData.ts`, then gets vendored into `extensions/html-language-features/server`'s dependency bump.
