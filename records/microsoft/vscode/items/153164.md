# Issue #153164 — Allow registerTextEditorCommand callbacks to return a value

[https://github.com/microsoft/vscode/issues/153164](https://github.com/microsoft/vscode/issues/153164)

## Summary

A real extension API gap remains on current main: text-editor command callback results are discarded. The accepted Backlog item is correctly classified and routed, with no canonical duplicate found.

## Change summary

Allow values returned by `registerTextEditorCommand` callbacks to propagate through `executeCommand`.

## Best solution

Design a backward-compatible API that propagates the callback result while preserving the existing guarantee that the text edit transaction completes before `executeCommand` resolves. Update the declaration, extension-host implementation, and API tests together.
