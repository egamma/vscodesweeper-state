# Issue #336092 — Agent Debug Logs Cache Explorer gets confused between multiple concurrent AI conversations/requests

[https://github.com/microsoft/vscode/issues/336092](https://github.com/microsoft/vscode/issues/336092)

## Summary

Keep open: current source groups requests by their debug name and compares adjacent filtered requests without checking conversation identity, allowing unrelated wrapper requests to produce misleading cache-break diagnoses. Existing agent filtering does not distinguish multiple conversations named copilotLanguageModelWrapper.

## Change summary

Distinguish main, subagent, and utility conversation streams when comparing requests in Agent Debug Logs Cache Explorer.

## Best solution

Make cache-break comparisons follow the same logical conversation stream, while keeping main, subagent, and utility requests distinguishable. Preserve provider-reported cache usage rather than interpreting a switch between unrelated streams as rewritten history.
