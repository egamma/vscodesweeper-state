# Issue #315431 — Copilot Agents (Insiders): "Mark as Done" no-op when session state is missing/stale

[https://github.com/microsoft/vscode/issues/315431](https://github.com/microsoft/vscode/issues/315431)

## Summary

Keep open: the reported missing-state scenario provides enough detail for a controlled retest, but its causal link to the silent no-op is not confirmed. Local Copilot sessions now use Agent Host providers, so the original flow needs retesting against that implementation; no verified fix or qualifying duplicate was established.

## Change summary

Mark as Done should archive an affected session or explain why it cannot, rather than silently ignoring the action when session bookkeeping is incomplete.

## Best solution

Establish how missing local session data affects the current Agent Host archive path, then ensure the action either reaches a persisted done state or presents an actionable failure. Preserve session history and existing worktree-cleanup safeguards.
