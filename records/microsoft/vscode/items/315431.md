# Issue #315431 — Copilot Agents (Insiders): "Mark as Done" no-op when session state is missing/stale

[https://github.com/microsoft/vscode/issues/315431](https://github.com/microsoft/vscode/issues/315431)

## Summary

Valid bug: the "Mark as Done" action silently no-ops when session state is missing because `archiveSession` in the Copilot provider falls through without feedback when neither a chat session nor an agent session is found for the given ID. No fix on current main.

## Change summary

Clicking "Mark as Done" on a session with missing/stale local state silently does nothing instead of showing an error or updating the UI.

## Best solution

Add user-facing feedback (notification or inline status) when `archiveSession` cannot locate the session to archive. The silent fall-through in `CopilotChatSessionsProvider.archiveSession()` (line ~1872–1876) should either surface a warning or attempt to reconcile the stale state. The action handler in `sessionsViewActions.ts` could also guard against this case.
