# Issue #333434 — Copilot plugin agents disappear after AgentPluginManager evicts stale nonce

[https://github.com/microsoft/vscode/issues/333434](https://github.com/microsoft/vscode/issues/333434)

## Summary

Freshly filed, well-diagnosed bug from a team member with concrete Agent Host log evidence; no fix exists on main yet, so this stays open for investigation.

## Change summary

Custom agents from an installed Copilot CLI plugin intermittently disappear because AgentPluginManager repeatedly evicts the plugin's nonce after failing to fully sync it, especially with multiple Insiders windows sharing one Agent Host.

## Best solution

Investigate why the plugin copy in AgentPluginManager._syncPlugin (src/vs/platform/agentHost/node/agentPluginManager.ts) intermittently fails to resolve the vscode-agent-client:// path for nested plugin files (e.g. .../evals), likely tied to client reconnection when multiple windows share one Agent Host; once the copy succeeds reliably, the nonce-eviction logic (already correct in isolation) will stop discarding good syncs.
