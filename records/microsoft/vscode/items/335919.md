# Issue #335919 — Cannot connect to remote agent host

[https://github.com/microsoft/vscode/issues/335919](https://github.com/microsoft/vscode/issues/335919)

## Summary

Keep open: a team member confirmed the repeated SSH folder-picker failure, and the issue was explicitly reopened to track the architectural correction in the open draft PR. The assigned 1.139.0 milestone and active fix PR independently bar closure.

## Change summary

Connecting to an SSH Agent Host succeeds initially but opening its remote folder picker a second time reuses an initialized transport with a new protocol client, causing the `initialize` request to fail.

## Best solution

Review, update, and land https://github.com/microsoft/vscode/pull/336330 so newly constructed protocol clients always receive fresh transports while live transports retain their existing clients; retain the merged narrow picker guard as immediate protection.
