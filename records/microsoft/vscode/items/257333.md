# Issue #257333 — Script ran from task no longer finds module in cwd

[https://github.com/microsoft/vscode/issues/257333](https://github.com/microsoft/vscode/issues/257333)

## Summary

The reporter answered the team member's November 2025 questions (modules are not in a venv, .env file at project root is not being loaded for task terminals) and confirmed the issue still reproduces. The issue needs a team follow-up, not more info from the reporter — keeping open.

## Change summary

Running a Python script via a VS Code task in Codespaces fails to find modules because the project-root `.env` file is not loaded into the task terminal's environment.

## Best solution

The Python area owner should determine whether `.env` file loading for task terminals is a Python extension responsibility (via `python.envFile`) or a gap in VS Code core's task system. If the Python extension should be loading `.env` for tasks and isn't, the fix belongs in `microsoft/vscode-python`. If VS Code core tasks should support an `envFile` option (analogous to the debug launch config), that's a core feature gap. The `info-needed` label can likely be cleared since the reporter answered.
