# Issue #328426 — [Error] unhandlederror-Cannot read properties of undefined (reading 'add')

[https://github.com/microsoft/vscode/issues/328426](https://github.com/microsoft/vscode/issues/328426)

## Summary

The dispose-during-load race remains in current main: output loading resumes after disposal and dereferences a cleared disposable store. The linked fix proposal is an issue created after a failed push, not an open or merged PR, so this report still owns unresolved work.

## Change summary

Loading a file-backed output channel can throw when the channel is disposed before its asynchronous content read finishes.

## Best solution

Make output-channel loading terminate cleanly when disposal occurs during the content read, without installing listeners or starting polling afterward. Use the diagnosis in https://github.com/microsoft/vscode/issues/328432 as implementation context and retain this issue until a fix lands.
