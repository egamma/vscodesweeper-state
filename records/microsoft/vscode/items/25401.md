# Issue #25401 — Drop cursor missing if drop location === current cursor location

## Change summary

Show the drop-location cursor instead of the regular caret when both occupy the same editor position.

## Best solution

Update the editor drag-and-drop presentation so the active caret cannot obscure the `dnd-target` decoration at the same position, while restoring normal caret rendering when dragging ends.
