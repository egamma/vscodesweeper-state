# Issue #316613 — Make the default code theme button and highlight darker/grayish shade.

[https://github.com/microsoft/vscode/issues/316613](https://github.com/microsoft/vscode/issues/316613)

## Summary

Keep open as a default-theme design request: current dark themes still use blue primary buttons and some selection accents. Color customization provides a personal workaround, but does not fulfill the requested change to the defaults.

## Change summary

Replace the default theme's bright blue button and selection accents with darker, grayish colors.

## Best solution

Have the theme owners decide whether quieter default accents improve visual hierarchy while preserving readable text and distinguishable selection and focus states. Any accepted change should use shared theme colors consistently; personal preferences can already be accommodated through workbench.colorCustomizations.
