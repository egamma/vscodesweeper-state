# Issue #316613 — Make the default code theme button and highlight darker/grayish shade.

[https://github.com/microsoft/vscode/issues/316613](https://github.com/microsoft/vscode/issues/316613)

## Summary

The default dark theme's blue accent color for buttons and highlights is an intentional design choice; this is a personal preference request that conflicts with VS Code's established visual identity and uniform UI principle.

## Change summary

## Best solution

The default theme colors are intentional branding and accessibility choices. Users who prefer different accent colors can customize via `workbench.colorCustomizations` in settings or install a community theme from the Marketplace. No core change needed.
