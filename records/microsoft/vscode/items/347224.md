# Issue #347224 — Copilot content exclusion spawns `git rev-parse` per file for non-git folders, pegging CPU

[https://github.com/microsoft/vscode/issues/347224](https://github.com/microsoft/vscode/issues/347224)

## Summary

Verified duplicate of the older, open issue https://github.com/microsoft/vscode/issues/265401: both report Copilot spawning repeated failing git processes for non-git folders, causing severe resource usage. This report adds a precise content-exclusion diagnosis and Windows ARM64 evidence worth preserving in that thread.

## Change summary

Prevent per-file repository discovery from flooding non-git workspaces with git processes during Copilot content-exclusion checks.

## Best solution

Consolidate the diagnosis under https://github.com/microsoft/vscode/issues/265401 and review the existing implementation candidate https://github.com/microsoft/vscode/pull/345758, preserving content-exclusion correctness when repository state changes.
