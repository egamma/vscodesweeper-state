# Issue #333520 — Asking in a chat to create an automation created a GitHub workflow instead of a VS Code automation

[https://github.com/microsoft/vscode/issues/333520](https://github.com/microsoft/vscode/issues/333520)

## Summary

Team-authored dogfooding report on the brand-new Automations feature (milestone On Deck): the reporter directly reproduced the agent choosing to write a GitHub Actions workflow file instead of invoking the built-in `configureAutomation` tool. No fix commit references this issue, so per the team-authored rule this stays open rather than being closed on judgment.

## Change summary

Asking chat to 'create an automation' with default settings caused the agent to create a GitHub Actions workflow instead of using the VS Code Automations feature.

## Best solution

Tighten the `configureAutomation` tool's description/registration conditions (src/vs/workbench/contrib/chat/common/automations/automationService.ts) and/or the automations toolset gating (src/vs/workbench/contrib/chat/browser/tools/clientToolSetsContribution.ts) so the model reliably prefers the native automation tool over generating a raw workflow file when the Automations view/session context is active.
