# Issue #332506 — Context key scanner rejects the d and v regex flags in when clauses

[https://github.com/microsoft/vscode/issues/332506](https://github.com/microsoft/vscode/issues/332506)

## Summary

Confirmed on current main: the scanner's `_regexFlags` whitelist (src/vs/platform/contextkey/common/scanner.ts:168) omits the `d` and `v` flags, so a when-clause regex using them fails to lex and silently deserializes to undefined. A fixing PR already exists, so this stays open pending that merge rather than being closed now.

## Change summary

The context key scanner rejects the `d` (hasIndices) and `v` (unicodeSets) regex flags in `when` clause regex literals, causing valid clauses to silently fail to deserialize.

## Best solution

Land https://github.com/microsoft/vscode/pull/332509, which extends the scanner's flag whitelist to include `d` and `v` with accompanying scanner/deserialize tests; no further core decision is needed beyond review and merge.
