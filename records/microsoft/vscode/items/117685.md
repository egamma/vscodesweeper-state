# Issue #117685 — Flutter apps crash due to old core16 gdk-pixbuf loaders in snap

[https://github.com/microsoft/vscode/issues/117685](https://github.com/microsoft/vscode/issues/117685)

## Summary

Still open on main — the snap remains on core20 base, and the gdk-pixbuf loader ABI mismatch persists. An open PR (#298237) upgrading to core22 explicitly targets this issue but has not merged yet.

## Change summary

Flutter (and other GTK apps launched from the snap) crash because the snap ships core16/core20 gdk-pixbuf loaders that are ABI-incompatible with the host system's libraries.

## Best solution

Land https://github.com/microsoft/vscode/pull/298237 which upgrades the snap to core22 base and resolves the ABI mismatch. No separate fix is needed — review and merge that PR.
