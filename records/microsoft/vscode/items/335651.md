# Issue #335651 — terminal extra details

[https://github.com/microsoft/vscode/issues/335651](https://github.com/microsoft/vscode/issues/335651)

## Summary

The `clear && python3 -u "..."` text the reporter sees comes from the Code Runner extension (formulahendry.code-runner), which prefixes run commands with `clear &&` by default — this is not VS Code core behavior, so it should be closed and pointed to that extension.

## Change summary

Reporter wants to remove the extra `clear && python3 -u "..."` text VS Code prints in the terminal when running a Python file.

## Best solution

Direct the reporter to the Code Runner extension's settings/repo — disabling `code-runner.clearPreviousOutput` (or unchecking 'Run In Terminal' clear behavior) removes the `clear &&` prefix; VS Code's built-in Python 'Run Python File' command does not add this text.
