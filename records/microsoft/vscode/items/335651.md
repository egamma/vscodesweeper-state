- **Proposed comment:**

  > Thanks for the report. The text you quoted is the shell command used to launch your Python file, rather than extra output from your program.
  > 
  > If you run it with Code Runner's **Run Code** command, set `"code-runner.runInTerminal": false` and `"code-runner.showExecutionMessage": false` to show program output in the Output panel without the launch and completion messages. You can also set `"code-runner.clearPreviousOutput": true` to clear that panel before each run. This mode does not support interactive input such as Python's `input()`; those programs still need the terminal. `showExecutionMessage` does not hide commands in terminal mode.
