# Issue #247999 — `"editor.fontLigatures"` should not apply to code lens (esp. when using a different font)

[https://github.com/microsoft/vscode/issues/247999](https://github.com/microsoft/vscode/issues/247999)

## Summary

Keep open in the CodeLens backlog. Current main still applies editor font features to CodeLens even when CodeLens uses a different font, and the request has surpassed the 20-upvote backlog threshold.

## Change summary

Decouple CodeLens font-feature settings from `editor.fontLigatures` so stylistic sets intended for the editor font do not alter CodeLens glyphs.

## Best solution

Give CodeLens an independent font-feature policy in `editorOptions.ts` and `codelensController.ts`, with a safe default that does not apply incompatible stylistic sets when `editor.codeLensFontFamily` differs from the editor font.
