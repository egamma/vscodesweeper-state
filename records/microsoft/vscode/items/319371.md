# Issue #319371 — cursoring down through Arabic letters in parenthesis is odd

[https://github.com/microsoft/vscode/issues/319371](https://github.com/microsoft/vscode/issues/319371)

## Summary

Valid bug with concrete repro steps. Cursor navigation through Arabic text inside parentheses (neutral bidi characters) behaves incorrectly because the cursor movement logic only checks the overall line direction, not the local bidi context around the cursor. Already has the right labels; part of the broader RTL editing effort tracked by #4994 but provides distinct, specific reproduction evidence.

## Change summary

Cursor up/down/left/right navigation flips around unexpectedly when moving through Arabic text enclosed in parentheses, due to incorrect handling of neutral bidi characters in cursor movement.

## Best solution

The cursor movement logic in `src/vs/editor/common/cursor/cursorMoveCommands.ts` needs to be aware of the local bidi embedding level at the cursor position rather than only the overall line direction. This is a specific, actionable piece of the broader RTL editing support tracked by https://github.com/microsoft/vscode/issues/4994. Fixing cursor movement through neutral characters (parentheses, brackets) in RTL text would address this specific report while advancing the broader RTL effort.
