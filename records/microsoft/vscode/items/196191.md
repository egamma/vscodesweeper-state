# Issue #196191 — Add variable support for keybindings.json

[https://github.com/microsoft/vscode/issues/196191](https://github.com/microsoft/vscode/issues/196191)

## Summary

Valid feature request — variable substitution (like ${selectedText}) exists for tasks.json and launch.json but is not wired into keybindings.json args. No implementation found on current main; the gap remains real.

## Change summary

Allow variable substitution (e.g. ${selectedText}, ${file}) in the 'args' field of keybindings.json, similar to tasks.json and launch.json.

## Best solution

Extend the keybinding resolution path to run args through the configurationResolver variable substitution service before passing them to the command handler. The entry point is likely in src/vs/workbench/services/keybinding/ and would reuse src/vs/workbench/services/configurationResolver/common/variableResolver.ts.
