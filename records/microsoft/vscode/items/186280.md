# Issue #186280 — Sharing links - improve discovery

[https://github.com/microsoft/vscode/issues/186280](https://github.com/microsoft/vscode/issues/186280)

## Summary

A real discoverability gap remains on current main, and this team-authored issue is explicitly marked `continue-working-on`; it should remain open for UX exploration.

## Change summary

Make line-sharing actions discoverable without requiring users to know they exist in the editor gutter context menu.

## Best solution

Add a lightweight contextual affordance when whole lines are selected, or otherwise expose the existing Share action near the selection without adding permanent gutter clutter. The implementation should integrate with the existing share-provider infrastructure under `src/vs/workbench/contrib/share`.
