- **Validation:** On an affected Linux/Wayland environment with extensions disabled and window.dialogStyle=native, close a modified untitled editor and download a remote SSH file. Both dialogs must appear without terminating VS Code; cancel must preserve the editor or abort the download, and accepting must save or download correctly. Compare confirmation behavior with custom dialogs and repeat on current Stable/Insiders while collecting native crash details if either trigger still fails.
- **Behavior:**

  > Affected Linux/Wayland users report that VS Code exits before presenting either an unsaved-editor confirmation or a remote-file download destination picker. Both interactions must present their dialogs without terminating the application. Cancelling must preserve unsaved content or abort the download, and accepting must complete the requested operation. Validate both triggers separately because the reported custom-dialog workaround covers confirmations, not necessarily file pickers.
- **Trace:**

  > FileDownload.doDownloadNative in src/vs/workbench/contrib/files/browser/fileImportExport.ts requests a local save destination through FileDialogService.showSaveDialog in src/vs/workbench/services/dialogs/electron-browser/fileDialogService.ts. NativeHostMainService forwards native dialog requests to DialogMainService in src/vs/platform/dialogs/electron-main/dialogMainService.ts, which calls electron.dialog. Confirmation and prompt selection runs through DialogHandlerContribution in src/vs/workbench/electron-browser/parts/dialogs/dialog.contribution.ts; window.dialogStyle=custom selects the browser handler there. Separate crash dumps are available at https://github.com/microsoft/vscode/issues/284211#issuecomment-3675063430, but they were not analyzed during this read-only review, and the GTK assertions alone do not identify the fatal frame. Diagnosis must establish whether the two triggers share a native defect and whether the fix belongs in VS Code or upstream before choosing an implementation. Preserve existing save, cancellation, remote transfer, and dialog-style semantics; do not assume that the newer related reports have the same root cause.
