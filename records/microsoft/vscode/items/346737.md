# Issue #346737 — Option to check for updates and install before actually loading interface on launch

[https://github.com/microsoft/vscode/issues/346737](https://github.com/microsoft/vscode/issues/346737)

## Summary

The requested pre-launch update option remains missing: startup update checks currently begin after the window opens. Related requests do not cover automatically updating and then opening the workbench on an ordinary launch.

## Change summary

Offer an independent opt-in to check for and install updates before loading the workbench and extensions.

## Best solution

Have the update/startup owners evaluate an opt-in pre-workbench update flow that preserves independently configured periodic checks, with explicit offline, failure, and platform behavior.

## Vision fit

- **Fit:** unclear
- **Reason:** Reducing repeated startup work fits developer workflow improvements, but blocking launch on network and installation work introduces a tradeoff with fast startup.
- **Evidence:** Public values: "Performance trumps functionality" and "Out of the box, VS Code is a text editor: lightweight and fast."
