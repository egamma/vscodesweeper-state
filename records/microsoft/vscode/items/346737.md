# Issue #346737 — Option to check for updates and install before actually loading interface on launch

[https://github.com/microsoft/vscode/issues/346737](https://github.com/microsoft/vscode/issues/346737)

## Summary

The requested pre-interface update option is not covered by current settings: startup checks run after the first window opens and do not guarantee an unattended update before extensions load. Keep this open for a product decision about opt-in startup blocking.

## Change summary

Add an independent option to check for and install updates before opening the workbench, without requiring a manual restart or disabling subsequent background checks.

## Best solution

Evaluate an opt-in pre-workbench update flow in the desktop update and launch lifecycle, preserving normal startup performance when disabled. Define offline, failed-update, and installation-permission behavior before implementation.
