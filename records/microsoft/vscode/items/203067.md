# Issue #203067 — Persist variable expansion state through variable update events in notebook variables view

[https://github.com/microsoft/vscode/issues/203067](https://github.com/microsoft/vscode/issues/203067)

## Summary

Still present on main: the notebook variables view uses `variable.id` (ext host reference number) as the tree identity, which changes on re-execution, causing the async data tree to lose expansion state. No fix has been committed referencing this issue.

## Change summary

Expanding a variable in the notebook variables view collapses after executing a cell because variable IDs are regenerated.

## Best solution

Preserve expansion state across variable updates by using a stable identity key (e.g. variable name path) instead of the ext host numeric ID, or by manually saving/restoring expansion state around `updateChildren()` calls in `notebookVariablesView.ts`.
