# Issue #203067 — Persist variable expansion state through variable update events in notebook variables view

[https://github.com/microsoft/vscode/issues/203067](https://github.com/microsoft/vscode/issues/203067)

## Summary

Keep open: current source still loses expanded variable nodes on refresh because their tree identities come from freshly allocated extension-host handles. The report has sufficient reproduction steps, and neither related closed item establishes that this defect was fixed.

## Change summary

Preserve expanded notebook variables and their children when cell execution or a variable-update event refreshes the view.

## Best solution

Preserve expansion for corresponding variables across refreshes in the notebook variables data source and view, while continuing to fetch current values and children using the latest provider handles.
