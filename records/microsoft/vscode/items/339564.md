# Issue #339564 — Agent Host: search_code_subagent child turns never complete and are reported as cancelled

[https://github.com/microsoft/vscode/issues/339564](https://github.com/microsoft/vscode/issues/339564)

## Summary

Confirmed from source: the Copilot Agent Host's `onSubagentCompleted`/`onSubagentFailed` handlers (copilotAgentSession.ts ~8758-8766) only log and seed display names — they never call `_completeSubagentTurn`. A subagent's turn is only closed via `_reconcileBackgroundTasks`, which requires the SDK task list to carry an `type: 'agent'` entry for that agentId; the reporter's telemetry evidence (near-100% `cancelled` outcomes, tens-of-minutes median duration, single-turn subagents) for `search_code_subagent` strongly suggests that child never appears as such a task, so its turn is only ever closed by a later abort/cancel.

## Change summary

search_code_subagent child turns are never completed through the normal path and linger open until something else cancels them, skewing subagent telemetry.

## Best solution

Complete the subagent turn directly from the SDK's `subagent.completed`/`subagent.failed` events (calling `_completeSubagentTurn(e.agentId)`-equivalent) instead of relying solely on the task-list reconciliation path, so a subagent whose task never surfaces as an `agent` task still closes its turn promptly and with the correct outcome.
