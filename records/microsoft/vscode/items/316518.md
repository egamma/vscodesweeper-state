# Issue #316518 — Regression: Custom OAI models still fail after duplicate issue was marked fixed, and previously working models now also break

[https://github.com/microsoft/vscode/issues/316518](https://github.com/microsoft/vscode/issues/316518)

## Summary

This remains a source-reproducible BYOK bug: current main deliberately omits provider-compatible reasoning history when `thinking` is false, even if the provider returned reasoning that must be replayed.

## Change summary

Custom OAI tool-call conversations fail with HTTP 400 when providers emit mandatory reasoning history despite the model being configured with thinking disabled.

## Best solution

Preserve and replay reasoning actually returned by Chat Completions providers independently of whether VS Code requested thinking, without enabling reasoning for requests that contain no returned reasoning.
