## Summary

Keep this regression open: current main has changed reasoning serialization, but those changes do not establish that the reported thinking-disabled OpenCode Go configuration works. ## Change summary

Custom OAI tool-calling requests fail with missing reasoning-history errors for Kimi, DeepSeek, and previously working MiMo models despite thinking being configured off.

## Best solution

Establish whether the thinking-disabled Custom OAI configuration and OpenCode Go relay agree on the model's reasoning mode, then ensure assistant tool-call history satisfies that mode without breaking non-thinking endpoints. Keep this in the built-in Copilot BYOK area rather than treating it as an external-extension problem.
