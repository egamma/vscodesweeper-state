# Issue #330732 — Agents: Remove Monaco grid padding to align sessions-list margins

[https://github.com/microsoft/vscode/issues/330732](https://github.com/microsoft/vscode/issues/330732)

## Summary

Traced a real 1px asymmetry in the Agents window shell CSS: the Monaco grid's left margin is hardcoded to 4px while the right/bottom margins use the 5px `--vscode-agents-layout-floatingPanelGap` token, which matches the reporter's observation that the left margin looks slightly wider. Already correctly labeled bug/ux/agents-window, so this just needs the fix applied.

## Change summary

The sessions-list left margin in the Agents window shell doesn't match the right/bottom floating-panel gap, making the layout look asymmetric.

## Best solution

In src/vs/sessions/browser/media/workbench.css (line 22), change the hardcoded `4px` left margin on `.monaco-workbench.agent-sessions-workbench > .monaco-grid-view` to `var(--vscode-agents-layout-floatingPanelGap)` (or otherwise align it with `AGENTS_FLOATING_PANEL_GAP`) so the left gutter matches the right/bottom ones per the LAYOUT.md convention that these gutters share one spacing tier.
