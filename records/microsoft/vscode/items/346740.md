# Issue #346740 — Agents window ignores dev.containers.dockerPath when creating Dev Container sessions with WSL Containers

[https://github.com/microsoft/vscode/issues/346740](https://github.com/microsoft/vscode/issues/346740)

## Summary

Current source confirms that Agents-window container startup ignores the configured container executable. Keep this in VS Code core; selecting the supported configuration contract and validating wslc compatibility remain necessary.

## Change summary

Respect the selected container CLI consistently when starting and managing Dev Container agent sessions.

## Best solution

Provide consistent executable selection across the bundled Dev Container CLI and direct container commands, preserving default Docker behavior. Settle whether the Agents window shares dev.containers.dockerPath or exposes an equivalent core setting, then validate the reported Windows/wslc workflow.
