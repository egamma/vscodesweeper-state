# Issue #316444 — [Error] [GitHub.copilot-chat] unhandlederror-Response stream has been closed

[https://github.com/microsoft/vscode/issues/316444](https://github.com/microsoft/vscode/issues/316444)

## Summary

Still reproduces on main: `trackEditIfNeeded` in permissionHelpers.ts does not forward the cancellation token to `editTracker.trackEdit()`, so the cancellation guard in externalEditTracker.ts never fires when the response stream is already closed. The try/catch at the call site logs the error, but the error still surfaces in telemetry as an unhandled error. No fix commit references this issue.

## Change summary

Copilot CLI session throws 'Response stream has been closed' when trackEditIfNeeded calls stream.externalEdit() after the response stream is already closed, because the cancellation token is not forwarded.

## Best solution

Thread the `CancellationToken` through `trackEditIfNeeded` to `editTracker.trackEdit()` so the existing cancellation guard at externalEditTracker.ts:51 fires before attempting `stream.externalEdit()`. The three call sites in `handleWritePermission` already have access to the `token` parameter.
