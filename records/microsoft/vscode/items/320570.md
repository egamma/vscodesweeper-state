## Summary

Confirmed on current main: the ADO auth-change handler at line 191–195 of codeSearchChunkSearch.ts fires updateRepoStatuses unconditionally, unlike the GitHub handler (lines 175–188) which dedupes by session id. This causes unnecessary network requests for every auth event when repos are already Ready.

## Change summary

ADO auth-change handler in CodeSearchChunkSearch fires redundant semanticsearchstatus network requests on every event because it lacks session-id deduplication.

## Best solution

Apply the same session-id dedup pattern from the GitHub handler (lines 175–188) to the ADO handler (lines 191–195) in codeSearchChunkSearch.ts, comparing `anyAdoSession?.id` before calling updateRepoStatuses.
