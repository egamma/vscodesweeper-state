# Issue #326519 — Silent Git auto-fetch can still open Git Credential Manager dialogs

[https://github.com/microsoft/vscode/issues/326519](https://github.com/microsoft/vscode/issues/326519)

## Summary

Silent auto-fetch still suppresses only VS Code AskPass, leaving GCM free to open authentication dialogs. Route this to the Git area; the separate GCM refresh-token race does not resolve this bounded VS Code defect.

## Change summary

Ensure silent background Git fetches prohibit interactive GCM authentication while preserving cached credentials and non-interactive token refresh.

## Best solution

Make the built-in Git extension's silent fetch contract effective for GCM without changing user-initiated authentication. Leave credential-refresh coordination and GitLab credential erasure to the separately tracked GCM work.
