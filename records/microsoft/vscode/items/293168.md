Still reproduces on main: when usedTokens exceeds totalContextWindow, the percentage is clamped to 100% but the token count label still shows the raw numerator > denominator (e.g. '280K / 272K tokens'), which is confusing. No fix referencing this issue has landed.

## Change summary
