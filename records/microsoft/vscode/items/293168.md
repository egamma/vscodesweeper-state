# Issue #293168 — Context Window widget displays 100% usage with nominator greater than denominator

[https://github.com/microsoft/vscode/issues/293168](https://github.com/microsoft/vscode/issues/293168)

## Summary

The reported inconsistency remains possible on current main: token counts can exceed the denominator while both percentage labels are capped at 100%. Keep this team-authored bug open; neither a qualifying fix nor an older canonical reporting the same observable symptom was established.

## Change summary

Make the context-window widget communicate usage above its displayed token limit without presenting a misleading exact 100% value.

## Best solution

Give over-limit usage a consistent, explicit presentation across the details, compact label, and accessible label while preserving bounded graphical fills and truthful token counts. The context-widget owner should settle the intended over-limit wording rather than concealing excess usage.
