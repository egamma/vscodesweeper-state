# Issue #66982 — Clear all problems in the 'Problems' pane with a button

[https://github.com/microsoft/vscode/issues/66982](https://github.com/microsoft/vscode/issues/66982)

## Summary

Keep open: this heavily supported Backlog request remains unimplemented, and current marker ownership requires a coordinated API design rather than a view-only clear action.

## Change summary

Add a Problems-pane action that safely clears stale diagnostics from extensions, tasks, and other marker owners.

## Best solution

Introduce an owner-aware clearing protocol across the marker service, extension-host diagnostics bridge, and task problem collectors, then expose it as a command and Problems-pane action without desynchronizing incremental diagnostic producers.

## Evidence
