# Issue #335921 — Auto Curly brackets cannot disable

[https://github.com/microsoft/vscode/issues/335921](https://github.com/microsoft/vscode/issues/335921)

## Summary

Reporter self-diagnosed and resolved this: the persistent auto-curly-bracket behavior was caused by the third-party 'Kotlin' extension (by JetBrains), which apparently overrides `editor.autoSurround`/auto-closing settings for curly braces; switching to the 'Kotlin' extension by fwcd fixed it. Not a VS Code core defect.

## Change summary

Reporter says `editor.autoSurround: never` (and related auto-closing-brackets settings) does not stop curly braces from being auto-inserted/surrounded in Kotlin files.

## Best solution
