# Issue #335921 — Auto Curly brackets cannot disable

[https://github.com/microsoft/vscode/issues/335921](https://github.com/microsoft/vscode/issues/335921)

## Summary

Reporter identified the root cause themselves: the persistent auto-curly-bracket behavior in Kotlin files was caused by the third-party 'Kotlin by JetBrains' extension overriding VS Code's editor.autoSurround/autoClosingBrackets settings, not by VS Code core; switching to the 'Kotlin by fwcd' extension resolved it, so this closes as caused-by-extension.

## Change summary

editor.autoSurround: never (and auto-closing-bracket settings) did not disable auto-inserted curly brackets in Kotlin files.

## Best solution

No core change needed — VS Code's bracket auto-closing settings work as intended; the JetBrains Kotlin extension's own language configuration/typing behavior overrode them. Reporter should file with microsoft/vscode's extension isn't the right home — the JetBrains extension repository is the right place if further follow-up is wanted.
