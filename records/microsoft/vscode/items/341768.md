# Issue #341768 — Define if font is monospace by measuring the font info widths

[https://github.com/microsoft/vscode/issues/341768](https://github.com/microsoft/vscode/issues/341768)

## Summary

Still present on main: `_actualReadFontInfo` sets `isMonospace` to false whenever font ligatures are enabled, so Fira Code with ligatures is never treated as monospace. An open PR (https://github.com/microsoft/vscode/pull/341778) already addresses it.

## Change summary

Fonts such as Fira Code are not detected as monospace when ligatures are on; detection should measure ligature sequences instead.

## Best solution

Land or review the linked PR so monospace detection measures ligature sequences (fi, ff, <=, =>) against twice the space width, instead of disabling detection whenever ligatures are on.
