# Issue #338342 — Worktree isolation option not shown in Agents when git repo is init'd but there are no commits

[https://github.com/microsoft/vscode/issues/338342](https://github.com/microsoft/vscode/issues/338342)

## Summary

Keep open: current source deliberately hides worktree isolation for repositories without commits, but does not explain that restriction. The team-authored request proposes two different user experiences that need a maintainer decision.

## Change summary

Make worktree isolation discoverable in newly initialized repositories, either by explaining why it is unavailable or by supporting creation of an initial commit.

## Best solution

Make the missing prerequisite explicit in the Agents new-session composer. Prefer a disabled control with an accessible explanation unless maintainers explicitly choose automatic initial-commit creation.
