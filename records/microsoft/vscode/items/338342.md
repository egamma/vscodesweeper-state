# Issue #338342 — Worktree isolation option not shown in Agents when git repo is init'd but there are no commits

[https://github.com/microsoft/vscode/issues/338342](https://github.com/microsoft/vscode/issues/338342)

## Summary

The unexplained disappearance remains in current source: repositories without commits receive folder-only configuration, which the Agents picker hides. Keep this team-authored UX improvement open; choosing between an explanatory disabled control and user-triggered repository initialization needs a product decision.

## Change summary

Make worktree isolation discoverable when the selected Git repository has no commits, either by explaining its unavailability or supporting an initial commit when isolation is selected.

## Best solution

Make the no-commit prerequisite visible in the Agents isolation UI while preserving ordinary folder sessions. Prefer a disabled control with an explanation unless maintainers explicitly choose a flow that creates an initial commit.
