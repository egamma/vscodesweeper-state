# Issue #321758 — Customizations: Built-in skills are readonly with agents host

[https://github.com/microsoft/vscode/issues/321758](https://github.com/microsoft/vscode/issues/321758)

## Summary

Keep open: current main now groups Agent Host built-ins separately and contains partial override handling, but same-name skill resolution still has first-match paths and the post-fix runtime behavior has not been confirmed. This is also a team-authored issue, and none of the related fix commits or PRs explicitly references https://github.com/microsoft/vscode/issues/321758.

## Change summary

Agent Host built-in skills should appear as built-ins and yield to user or workspace skills with the same name, including direct slash-command invocation.

## Best solution

Define and enforce one effective-skill precedence across Agent Host publication, the Customizations editor, completions, and direct slash-command resolution: workspace and user overrides should take precedence over same-name built-ins, while unoverridden built-ins remain visible in the Built-in group.
