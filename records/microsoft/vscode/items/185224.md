[https://github.com/microsoft/vscode/issues/185224](https://github.com/microsoft/vscode/issues/185224)

## Summary

Valid, unimplemented feature request for a structured Fix All experience with scope selection (document/project/solution) in the code actions UI, requiring both LSP protocol additions and new VS Code UI. Team interest is evident from internal backlog references and a MEMBER comment; keeping open.

## Change summary

Add a Fix All code action experience with scope selection (document, project, solution) to VS Code, backed by new LSP protocol support.

## Best solution

Design and implement a Fix All UI in the code actions menu (with scope selection) and the corresponding LSP protocol extension (FixAllScope, codeAction/fixAll request). This requires coordination with the LSP spec. The existing `source.fixAll` kind is a flat mechanism; this request is for a richer, scoped experience akin to Visual Studio's. The work belongs in the `editor-code-actions` area with LSP spec involvement.
