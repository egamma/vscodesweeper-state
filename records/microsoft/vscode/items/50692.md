# Issue #50692 — QuickPick API is no longer type safe

[https://github.com/microsoft/vscode/issues/50692](https://github.com/microsoft/vscode/issues/50692)

## Summary

The API already uses intersection-type overloads (`QuickPickOptions & { canPickMany: true }`) to provide type-safe returns when callers pass a literal. The residual debt is that callers who pre-declare an options variable typed as `QuickPickOptions` lose the narrowing — a TypeScript language limitation. The `debt` label is appropriate; keeping open as a known rough edge.

## Change summary

When `canPickMany: true` is passed via a variable typed as `QuickPickOptions`, TypeScript cannot narrow the return type to `T[]`.

## Best solution

The intersection-overload pattern is the best available solution today. A future TypeScript feature (e.g. dependent types or improved narrowing from properties) could enable a cleaner API. Until then, the workaround is for callers to pass options inline or use `as const` / the `createQuickPick` API. This remains valid tech debt.
