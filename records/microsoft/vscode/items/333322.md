# Issue #333322 — Add an interactive "human-assist" mode for GUI/emulator actions in Copilot Agent Mode (VS Code)

[https://github.com/microsoft/vscode/issues/333322](https://github.com/microsoft/vscode/issues/333322)

## Summary

This is a coherent human-in-the-loop feature request for agent-driven GUI workflows. It is only 21 days old, has no discussion or established scope decision, and no verified older issue with the same observable request is identified, so it should remain open for product design.

## Change summary

Add an opt-in Copilot agent mode that pauses before GUI or emulator actions and asks the user to perform each action, confirm completion, or request clarification.

## Best solution

Define a provider- and tool-neutral human-action request contract in the chat/agent lifecycle, then render it through the existing structured confirmation UI so GUI automation tools can request Done/clarify input without transferring control of the whole task. Product owners should first decide whether this is an explicit task-level mode or a tool-initiated prompt shown only when automation cannot proceed reliably.
