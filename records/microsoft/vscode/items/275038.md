# Issue #275038 — Inline chat V2 speech support

[https://github.com/microsoft/vscode/issues/275038](https://github.com/microsoft/vscode/issues/275038)

## Summary

The gap remains on main: inline chat V2 uses a dedicated execute menu that does not include the existing microphone action. The request should stay open for inline-chat UI parity.

## Change summary

Show speech controls in the inline chat V2 input when a speech provider is installed.

## Best solution

Contribute the existing start/stop voice-chat actions to `MenuId.ChatEditorInlineExecute`, preserving the current speech-provider and recording-state conditions.
