# Issue #224460 — auto-import not working when completing in a linked editing range

[https://github.com/microsoft/vscode/issues/224460](https://github.com/microsoft/vscode/issues/224460)

## Summary

Still reproduces on main: when linked editing is active and a completion is accepted, the linked editing sync edit to the closing tag fires an additional content change that causes the async additional-text-edits guard in suggestController.ts to bail out, suppressing auto-imports. No fix commit found.

## Change summary

Auto-import does not fire when accepting a completion inside a linked editing range (e.g. JSX/HTML tags with editor.linkedEditing enabled).

## Best solution

The async additional-text-edits path in `suggestController.ts` (line ~382–412) tracks all content changes after the completion insert and bails if any occur before the additional edit's range. The linked editing sync in `linkedEditing.ts` fires a secondary edit (closing tag update) that triggers this guard. The fix should either filter out `linkedEditing`-sourced edits from the position tracker, or the linked editing controller should defer its sync until after the suggest controller finishes applying additional edits.
