# Issue #319112 — workbench.action.findInFiles: accept file URIs to bypass argv-length limits

[https://github.com/microsoft/vscode/issues/319112](https://github.com/microsoft/vscode/issues/319112)

## Summary

The commands still lack an argument for arbitrary URI-scoped searches, and no verified canonical issue covers this request. Keep it open, but correct the technical premise: the existing internal file-list path still expands relative includes into ripgrep glob arguments, so exposing it alone would not establish the promised argv-limit relief.

## Change summary

Allow extensions to supply an explicit file set to Find in Files and Search Editor without fragmenting large searches across multiple tabs.

## Best solution

Provide a supported exact-file search scope shared by both commands, preserving a single refinable result set. Evaluate argument-size handling end to end rather than assuming the existing SCM file-list query path avoids glob expansion.
