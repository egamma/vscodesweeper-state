# Issue #188823 — SVGs don't seem to work for `iconPath` in `QuickPickItem`

[https://github.com/microsoft/vscode/issues/188823](https://github.com/microsoft/vscode/issues/188823)

## Summary

Still present on main: SVG URLs passed as `iconPath` in QuickPickItem render via CSS `background-image`, which may fail for external SVGs due to CSP or MIME-type handling in Electron. No fix has landed. Team-authored, keeping open.

## Change summary

SVG URIs used as `iconPath` in `QuickPickItem` don't render, while PNG URIs work fine.

## Best solution

Investigate whether the issue is CSP-related (Electron blocking external SVG in `background-image`) or a missing content-type inference. The rendering path in `src/vs/platform/quickinput/browser/quickInputList.ts` (line ~484) and the tree renderer counterpart both use `asCSSUrl` for `background-image` — may need an `<img>` element fallback for SVG, or CSP adjustments to allow inline SVG rendering.
