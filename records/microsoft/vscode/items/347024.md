# Issue #347024 — Selective Git stage-all commands stage unrelated files when their selection is empty

[https://github.com/microsoft/vscode/issues/347024](https://github.com/microsoft/vscode/issues/347024)

## Summary

Both selective staging commands still stage unrelated files when their filtered category is empty. Keep this open while the existing fixing PR is reviewed and merged.

## Change summary

Make Stage All Tracked Changes and Stage All Untracked Changes leave the index unchanged when their category is empty.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/347025, preserving ordinary whole-repository staging and eligible-file staging while making empty selective staging a no-op.
