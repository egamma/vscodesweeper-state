# Issue #228067 — Improper processing of the key modifiers (Ctrl, Alt, Shift, Win)

[https://github.com/microsoft/vscode/issues/228067](https://github.com/microsoft/vscode/issues/228067)

## Summary

This is Windows UIPI (User Interface Privilege Isolation) behavior, not a VS Code defect. When VS Code runs elevated (as Administrator), non-elevated processes like keyboard switchers cannot hook into its key events — the reporter confirmed this themselves by noting the issue disappears when not running as Administrator.

## Change summary

Pressing and releasing RightCtrl in VS Code running as Administrator does not propagate to a non-elevated keyboard switcher utility.

## Best solution

Close as designed — Windows security isolation prevents lower-privilege keyboard hooks from intercepting keystrokes sent to elevated windows. This is OS-level behavior VS Code cannot and should not override. The workaround (don't run VS Code as Administrator) is the correct resolution.
