# Issue #139485 — Cannot show full file path for long symbol signature in Go To Symbol

[https://github.com/microsoft/vscode/issues/139485](https://github.com/microsoft/vscode/issues/139485)

## Summary

The current source still leaves file-path information inaccessible when a long workspace-symbol label clips its description. Keep this issue as the canonical report: a maintainer explicitly consolidated two matching reports here.

## Change summary

Make a workspace symbol's complete file-path information discoverable even when its signature leaves no visible description to hover.

## Best solution

Provide a reachable hover containing the file-path information for workspace-symbol results regardless of label length, while preserving existing filtering, navigation, and explicit tooltips. A signature-only tooltip would not solve the reported ambiguity between files.
