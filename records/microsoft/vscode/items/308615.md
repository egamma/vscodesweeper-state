# Issue #308615 — Setting for update frequency

[https://github.com/microsoft/vscode/issues/308615](https://github.com/microsoft/vscode/issues/308615)

## Summary

Valid backlog feature request with 92 upvotes and a concrete team-proposed design (configurable update reminder period of 2–4 weeks). Not yet implemented on main — the update configuration still only offers mode/channel, with no frequency or reminder-period setting.

## Change summary

Add a setting to configure how frequently VS Code reminds users about available updates, allowing deferral of non-security updates for 2–4 weeks.

## Best solution

Implement the approach dmitrivMS proposed: an `update.reminderPeriod` setting (default/2 weeks/3 weeks/4 weeks) that suppresses non-security update notifications for the configured period, while still surfacing security/recovery releases immediately. The implementation would live in `src/vs/platform/update/` (config contribution + service logic) and `src/vs/workbench/contrib/update/` (notification gating).
