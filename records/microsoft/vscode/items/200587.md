# Issue #200587 — Option to disable inlay hints when in diff mode

[https://github.com/microsoft/vscode/issues/200587](https://github.com/microsoft/vscode/issues/200587)

## Summary

A real configuration gap remains: current main supports globally toggling inlay hints but not disabling them specifically in diff editors. Keep this Backlog request open under discussion pending a product decision on adding a diff-specific option.

## Change summary

Allow users to disable inlay hints in diff editors without disabling them in normal editors.

## Best solution

Decide whether diff editors should suppress inlay hints by default or expose a diff-specific setting, then wire that decision through the existing `EditorOption.inDiffEditor` path without changing normal-editor behavior.
