# Issue #200587 — Option to disable inlay hints when in diff mode

[https://github.com/microsoft/vscode/issues/200587](https://github.com/microsoft/vscode/issues/200587)

## Summary

Keep open: current configuration does not provide a supported diff-only inlay-hint switch, and disabling hints globally does not satisfy the request. The existing inlay-hints label is appropriate; the related alignment report does not own this configuration capability.

## Change summary

Allow users to disable inlay hints in diff editors while retaining them in ordinary editors.

## Best solution

Provide a supported diff-specific inlay-hint preference for both inline and side-by-side comparisons, preserving ordinary-editor behavior. Settle the preference's default and interaction with existing inlay-hint visibility modes before implementation.
