# Issue #279671 — Allow local terminal to open in empty workspace

[https://github.com/microsoft/vscode/issues/279671](https://github.com/microsoft/vscode/issues/279671)

## Summary

Valid team-authored debt item: local terminals are blocked in empty workspaces because the trust check fires even when there is no workspace to distrust. The code path at terminalInstance.ts:1595–1600 confirms the gap remains on current main — no fix has landed.

## Change summary

Allow local terminal processes to open in an empty workspace without requiring a workspace trust prompt.

## Best solution

In `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts`, adjust the `_createProcess` trust gate (around line 1595–1599) to skip the trust prompt when the workspace is empty (no folders). An empty workspace has nothing to distrust, so the local terminal should be allowed to launch with cwd set to userHome.
