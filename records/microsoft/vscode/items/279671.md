# Issue #279671 — Allow local terminal to open in empty workspace

[https://github.com/microsoft/vscode/issues/279671](https://github.com/microsoft/vscode/issues/279671)

## Summary

Keep this team-authored follow-up open: local terminal creation still has no empty-workspace exemption from the trust request. The ordinary empty-window default already permits terminals, so the remaining work needs to distinguish an untrusted empty workspace from a default trusted empty window.

## Change summary

Allow a local terminal to open in an empty workspace without requiring the reported trust confirmation.

## Best solution
