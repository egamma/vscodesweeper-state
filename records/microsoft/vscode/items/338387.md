## Change summary

MCP enablement changes made through the Copilot runtime (such as `/mcp disable` or `/mcp enable`) do not update the scoped customization decision or the Agent Customizations switch.

## Best solution

Have the Agent Host reconcile `session.mcp_server_status_changed` transitions, both disabled and re-enabled, into the scoped customization enablement. Tag host-initiated reconciliation so it is not mistaken for an external change and does not loop.
