# Issue #299515 — Cmd+C with no selection leaks bare "c" into TUI input on 1.110.0 (selection path works)

[https://github.com/microsoft/vscode/issues/299515](https://github.com/microsoft/vscode/issues/299515)

## Summary

The reported Cmd+C input-leak path is addressed by the landed change that intercepts resolved Meta shortcuts before xterm processes them. A separately reported modifier-only selection-clearing problem remains tracked elsewhere.

## Change summary

Prevent Cmd+C from inserting a literal c into terminal applications when Kitty keyboard reporting is enabled, with or without a terminal selection.

## Best solution

Retain the Meta-shortcut interception implemented in commit 7b17c65f78d7c39e4e06fb924a2002949b9861c4 and close this input-leak report as completed. Keep the distinct modifier-only selection-clearing behavior tracked in https://github.com/microsoft/vscode/issues/336506.
