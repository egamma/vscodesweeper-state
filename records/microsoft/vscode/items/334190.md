# Issue #334190 — Agents Sessions window: new-session chat input placeholder no longer rotates through random prompts

[https://github.com/microsoft/vscode/issues/334190](https://github.com/microsoft/vscode/issues/334190)

## Summary

Confirmed on current main: `NewChatWidget` always passes an explicit `placeholder: localize('newSessionPromptPlaceholder', "Pitch your idea")` option, and since `NewChatInputWidget` only falls back to `getRandomChatInputPlaceholder()` via `??` when no explicit placeholder is given, the random rotation logic is permanently dead code for the primary new-session composer.

## Change summary

The new-session chat input placeholder is stuck on "Pitch your idea" instead of rotating through the RANDOM_PLACEHOLDERS list.

## Best solution

Drop (or make conditional) the fixed `placeholder` option passed from `NewChatWidget` in src/vs/sessions/contrib/chat/browser/newChatWidget.ts so the widget falls through to `getRandomChatInputPlaceholder()` in src/vs/sessions/contrib/chat/browser/newChatInput.ts, restoring the intended rotation.
