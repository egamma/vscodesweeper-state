# Issue #334190 — Agents Sessions window: new-session chat input placeholder no longer rotates through random prompts

[https://github.com/microsoft/vscode/issues/334190](https://github.com/microsoft/vscode/issues/334190)

## Summary

The reported fixed-placeholder path still exists on current main: the new-session composer bypasses the documented per-instance random selection. Later work adds rotating welcome headings, but does not change the input placeholder, so it does not resolve this report.

## Change summary

Restore variation between friendly placeholder prompts when creating new-session composer instances.

## Best solution

Make the primary new-session input honor the documented per-instance placeholder selection while preserving explicit placeholders for other composer contexts. Keep this separate from the newer rotating welcome-heading feature.
