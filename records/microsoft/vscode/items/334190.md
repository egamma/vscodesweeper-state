# Issue #334190 — Agents Sessions window: new-session chat input placeholder no longer rotates through random prompts

[https://github.com/microsoft/vscode/issues/334190](https://github.com/microsoft/vscode/issues/334190)

## Summary

Confirmed on main: NewChatWidget always passes an explicit `placeholder` option to NewChatInputWidget, and NewChatInputWidget only calls `getRandomChatInputPlaceholder()` when no explicit placeholder is supplied (`this.options.placeholder ?? getRandomChatInputPlaceholder()`), so the fallback path is unreachable for the primary new-session composer and the placeholder is permanently stuck.

## Change summary

The new-session chat input's placeholder should rotate randomly through `RANDOM_PLACEHOLDERS`, but always shows the fixed string "Pitch your idea".

## Best solution

In src/vs/sessions/contrib/chat/browser/newChatWidget.ts, stop passing the hardcoded `placeholder: localize('newSessionPromptPlaceholder', "Pitch your idea")` option (or make it conditional) so newChatInput.ts's `this.options.placeholder ?? getRandomChatInputPlaceholder()` fallback in src/vs/sessions/contrib/chat/browser/newChatInput.ts actually engages and rotates through the full list.
