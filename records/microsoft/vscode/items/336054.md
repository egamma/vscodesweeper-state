# Issue #336054 — Git diff fails at a SUBST drive root but works at the underlying local folder

[https://github.com/microsoft/vscode/issues/336054](https://github.com/microsoft/vscode/issues/336054)

## Summary

Confirmed via source trace: `normalizePath` in extensions/git/src/util.ts strips the trailing separator from a drive root like "r:\\" before calling Node's `path.normalize`, which turns it into drive-relative "r:." instead of the root "r:\\" — this breaks `isDescendant`'s startsWith check so `Model.getOpenRepository` can't match the git URI to the open repository when the workspace is a SUBST drive root.

## Change summary

Opening a Git diff fails with "file was not found" when the workspace folder is the root of a Windows SUBST drive (e.g. R:\), even though the same repository works fine from its underlying real path.

## Best solution

Fix `normalizePath` in extensions/git/src/util.ts so it doesn't strip the trailing separator on a bare drive root before normalizing (or special-case drive roots), so `isDescendant`/`pathEquals` correctly treat "R:\\" as a root rather than a drive-relative path.
