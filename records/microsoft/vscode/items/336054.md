# Issue #336054 — Git diff fails at a SUBST drive root but works at the underlying local folder

[https://github.com/microsoft/vscode/issues/336054](https://github.com/microsoft/vscode/issues/336054)

## Summary

Traced and confirmed the reporter's own root-cause hypothesis in current-main source: `normalizePath()` in extensions/git/src/util.ts strips a drive root's trailing separator before calling Node's `path.normalize`, which turns `"r:\\"` into the drive-relative path `"r:."` instead of `"r:\\"`, so `isDescendant()` then fails to match any file under a SUBST/drive-root repository and the Git filesystem provider reports 'Repository not found' for diffs.

## Change summary

Opening the diff view for a modified file fails with 'file was not found' when the workspace is a SUBST drive root (e.g. R:\), while the same repository opened via its real path works fine.

## Best solution

Fix `normalizePath()` in extensions/git/src/util.ts so drive-root paths (e.g. `R:\`) are not collapsed into Node's drive-relative form (`R:.`) when the trailing separator is stripped — e.g. skip trailing-separator removal (or re-append the separator after `normalize`) when the remaining string is a bare drive letter.
