# Issue #344252 — cloud automation: how can I see the current run

[https://github.com/microsoft/vscode/issues/344252](https://github.com/microsoft/vscode/issues/344252)

## Summary

Keep open for cloud-automation startup and run discoverability. Current source supports opening and stopping runs from History, but an accepted request can remain at “Starting run...” before a history entry exists; the maintainer’s question about whether the conversation eventually appeared remains unanswered.

## Change summary

Make the progress, conversation entry point, and available controls discoverable after manually starting a cloud automation.

## Best solution

Make the transition from an accepted cloud request to its accessible History conversation understandable without implying that a session already exists. Establish whether this run eventually appeared in History before treating the report as a session-loading defect or promising cancellation during provisioning.
