## Summary

Team-authored, same-day bug report (with video evidence) about the new WYSIWYG markdown editor dropping/misordering rapid keystrokes after a backspace; hard keep-open rule applies to collaborator-authored issues, and the likely root cause sits in the external `@vscode/markdown-editor` webview library rather than code in this checkout, so it needs diagnosis before any fix.

## Change summary
