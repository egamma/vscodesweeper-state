## Change summary

Rapid Backspace presses followed by typing in the Markdown preview can execute out of order and produce incorrect text.

## Best solution

## Plan brief

- **Likely files:** `extensions/markdown-language-features/package.json`, `extensions/markdown-language-features/src/extension.shared.ts`, `extensions/markdown-language-features/src/preview/markdownEditorProvider.ts`, `extensions/markdown-language-features/markdown-editor-src/editor.ts`
- **Validation:** In an editable Markdown preview, place the caret after 'ne', rapidly press Backspace twice, then type 'en'; repeated trials must consistently leave 'en'. Establish a failing baseline and an automated rapid-input regression before accepting a fix; also verify ordinary deletion, customized deletion bindings, and undo/redo remain functional.
- **Behavior:**

  > The editable Markdown preview must process deletion and text insertion in the order the user performs them. With the caret after 'ne', two rapid Backspaces followed by 'en' must leave 'en', not delete a newly inserted letter or leave 'nn'. Acceptance requires repeated rapid-input trials and a regression check that demonstrates the failure before the change and correct ordering afterward. Existing deletion shortcuts, user keybinding customizations, and document undo/redo behavior must remain intact.
- **Trace:**

  > The Backspace binding in extensions/markdown-language-features/package.json targets markdown.editor.deleteLeft. Generated command registration in src/extension.shared.ts calls MarkdownEditorProvider.executeCommand in src/preview/markdownEditorProvider.ts, which asynchronously forwards to renderer.command. The renderer handler in markdown-editor-src/editor.ts invokes EditorController.executeCommand, while that controller is configured with separate vscodeLocalKeyboardProfile and vscodeHostKeyboardProfile values from @vscode/markdown-editor. This identifies a plausible ordering boundary but does not establish where later text insertion overtakes deletion; reproduce and inspect the controller/input dispatch before choosing the implementation boundary. https://github.com/microsoft/vscode/issues/270731 provides related normal-editor ordering evidence, not a verified duplicate of this preview report. Preserve custom keybindings and the backing TextDocument's authoritative undo stack; unrelated modifier mappings and keybinding inheritance are outside this report.
