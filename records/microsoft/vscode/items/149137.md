# Issue #149137 — Problem matcher network path bug

[https://github.com/microsoft/vscode/issues/149137](https://github.com/microsoft/vscode/issues/149137)

## Summary

Keep open: the current local task URI provider still rejects UNC paths, preventing matched diagnostics from reaching Problems. The linked drive-mapping workaround avoids the defect but does not resolve it.

## Change summary

Task problem matchers should publish diagnostics when the workspace and matched files reside on a Windows UNC share.

## Best solution

Ensure task diagnostic resource construction preserves the UNC server as the file URI authority, while retaining existing local-drive and remote-task URI behavior.
