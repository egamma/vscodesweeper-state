# Issue #314118 — Hoolk postTooluse not working as sync (seems ASYNCRONOUS?¿)

[https://github.com/microsoft/vscode/issues/314118](https://github.com/microsoft/vscode/issues/314118)

## Summary

Confirmed on current main: the PostToolUse hook is fired without `await` in toolCalling.tsx, so the agent continues before the hook completes. This is the missing-await bug at line 331.

## Change summary

PostToolUse hooks run asynchronously (fire-and-forget) instead of blocking the agent until the hook completes, so hook results like lint blocks are ignored.

## Best solution

Add `await` to the `appendHookContext(...)` call at line 331 of `extensions/copilot/src/extension/prompts/node/panel/toolCalling.tsx`. This will make the agent wait for the PostToolUse hook to finish and honor its block/continue decision before proceeding. The related issue https://github.com/microsoft/vscode/issues/315926 (file not flushed before PostToolUse) is a separate timing problem.
