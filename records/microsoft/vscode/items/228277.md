# Issue #228277 — vscode.dev type acquisition fails if project has a `GitHub` dependency

[https://github.com/microsoft/vscode/issues/228277](https://github.com/microsoft/vscode/issues/228277)

## Summary

Still reproduces on main: `@vscode/ts-package-manager` (v0.0.2, unchanged) panics in orogene's WASM when a project's package.json has a git dependency, killing type acquisition entirely. No fix or version bump has landed.

## Change summary

Web type acquisition (ATA) crashes with a WASM panic when the project has a git dependency in package.json, blocking all IntelliSense loading on vscode.dev.

## Best solution

The orogene WASM needs to gracefully skip or resolve git dependencies instead of panicking. As zkat outlined in the comments, the fix in orogene is small (skip the pack step and feed the tarball directly). This would require a new release of `@vscode/ts-package-manager` and a version bump in `extensions/typescript-language-features/package.json`. Alternatively, the typingsInstaller could pre-filter git dependencies from the resolved package graph before passing them to orogene.
