# Issue #265433 — Be smarter about errors from edits

[https://github.com/microsoft/vscode/issues/265433](https://github.com/microsoft/vscode/issues/265433)

## Summary

Team-authored feature request to improve how the agent editing flow tracks and reports lint errors across sequential edits in a session. Keeping open — author is a team member, and the request targets a real gap in the current error-diffing logic.

## Change summary

The agent editing flow should persist awareness of errors introduced by earlier edits in the session rather than only diffing errors before/after each individual edit.

## Best solution

Extend the edit-error tracking in the agent editing hooks (likely around `extensions/copilot/src/extension/intents/node/editCodeIntent.ts` and related lint-error infrastructure in `extensions/copilot/src/extension/xtab/common/lintErrors.ts`) to maintain a session-scoped set of introduced errors. After each edit, surface both newly introduced errors and previously introduced but still-unfixed errors, so the agent has full visibility into accumulated technical debt from its own edits.
