Keep this discussion open: native SCM history supports some provider metadata already, but the requested richer identifiers and node semantics remain incomplete. An open linked PR addresses identifiers only and should be reviewed before pursuing overlapping work.

## Change summary

Extend native SCM graph APIs to represent provider-specific history information, including jj change and commit IDs, working-copy and immutable nodes, and bookmarks.
