# Issue #323388 — Feature Request: Native support ${num:$Snippet(prefix)} to nest other code snippets & trigger snippets inside quotes/brackets

[https://github.com/microsoft/vscode/issues/323388](https://github.com/microsoft/vscode/issues/323388)

## Summary

The central request for declarative snippet composition was previously considered, promoted to the backlog, and explicitly closed as not planned in https://github.com/microsoft/vscode/issues/106132. Existing settings and interactive nested insertion cover triggering snippets within placeholders and strings, while automatic `$Snippet(prefix)` expansion remains outside the planned core surface.

## Change summary

Add declarative snippet references that expand another snippet with independent tab stops, plus automatic snippet suggestions inside quotes and brackets.

## Best solution

Keep declarative snippet composition in an extension, while using VS Code's existing nested insertion flow: enable `editor.suggest.snippetsPreventQuickSuggestions: false`, enable `editor.quickSuggestions.strings`, or explicitly invoke suggestions inside an active placeholder. The current snippet session already merges interactively inserted snippets and orders their tab stops independently.
