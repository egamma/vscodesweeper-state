# Issue #323388 — Feature Request: Native support ${num:$Snippet(prefix)} to nest other code snippets & trigger snippets inside quotes/brackets

[https://github.com/microsoft/vscode/issues/323388](https://github.com/microsoft/vscode/issues/323388)

## Summary

Legitimate feature request for native snippet composition (referencing one snippet from another). Part 2 of the request (triggering snippets inside strings) is already possible via `editor.quickSuggestions.strings`, but the core ask — a native `$Snippet(prefix)` syntax — is genuinely not supported and has no canonical tracking issue.

## Change summary

Add native snippet composition syntax allowing one snippet to reference/embed another snippet by its prefix, eliminating reliance on third-party extensions.

## Best solution

Keep open as a feature request in the snippets area. The snippet engine lives in `src/vs/editor/contrib/snippet/`. A native composition mechanism would need changes to snippet parsing (`snippetParser.ts`) and session management (`snippetSession.ts`). Note in any response that triggering snippets inside strings is already configurable via `editor.quickSuggestions: { strings: true }`.
