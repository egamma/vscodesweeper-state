# Issue #110391 — Reveal comments in diff editor when navigating with the keyboard

[https://github.com/microsoft/vscode/issues/110391](https://github.com/microsoft/vscode/issues/110391)

## Summary

Still a valid feature request — keyboard-driven comment navigation via tab key moves focus mode doesn't auto-reveal out-of-viewport comments. The next/previous comment commands do reveal, but the tab-focus path does not. Keeping open as a reasonable accessibility-adjacent improvement.

## Change summary

When navigating between comments using Shift+Tab in 'tab key moves focus' mode, out-of-viewport comments should be scrolled into view.

## Best solution

Add scroll-into-view behavior when comment widgets receive focus via keyboard tab navigation in the diff editor. The fix would likely live in the comment zone widget focus handling in `src/vs/workbench/contrib/comments/browser/commentThreadZoneWidget.ts` — on focus, ensure the widget's range is revealed in the editor viewport. This is a small, localized improvement that aligns with accessibility goals.
