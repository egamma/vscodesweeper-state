## Change summary

Reveal an off-screen comment in the diff editor when keyboard tab navigation moves focus into it.

Ensure ordinary Tab and Shift+Tab navigation keeps the focused comment control visible in its containing diff-editor viewport, without requiring a separate navigation command. Confirm the original two-thread scenario against the current UI before choosing the implementation boundary.
