[https://github.com/microsoft/vscode/issues/271052](https://github.com/microsoft/vscode/issues/271052)

## Summary

This is the same Skia Graphite rendering corruption on macOS after sleep/resume that was tracked and fixed in the canonical issue #284162. The fix (disabling the Skia Graphite backend) shipped in VS Code 1.108.2.

## Change summary

VS Code UI renders with visual corruption (grey squares, missing content) on macOS after system sleep and wakeup.

## Best solution

Already resolved — the Skia Graphite backend was disabled in commit ae524952a1de76a3cc4d612775536bfd4cde7e97 (VS Code 1.108.2). The upstream Chromium/Skia fix is tracked separately. Updating to any version ≥ 1.108.2 resolves the issue.
