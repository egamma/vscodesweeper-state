# Issue #336319 — Chat-history sort order: most recent message/activity

[https://github.com/microsoft/vscode/issues/336319](https://github.com/microsoft/vscode/issues/336319)

## Summary

The sessions list already offers Sort by Updated, but the history picker still sorts by creation time. The remaining capability is covered by the verified open issue about honoring session sorting choices in pickers.

## Change summary

Order chat history by the most recent message or activity rather than session creation time.

## Best solution

Use the existing Sort by Updated choice for the sessions list and consolidate the remaining history-picker work into https://github.com/microsoft/vscode/issues/303430, which explicitly covers applying updated-time sorting wherever sessions are presented.
