## Summary

This is already shipped: the Chats/Agent Sessions view (which replaced the old chat-history list) has a built-in filter menu with 'Sort by Created' and 'Sort by Updated' (most recent activity) options, so proposing an as-designed close pointing the reporter to the existing toggle.
