# Issue #341055 — Chat code change Keep/Undo buttons cover/block code

[https://github.com/microsoft/vscode/issues/341055](https://github.com/microsoft/vscode/issues/341055)

## Summary

Thanks for the report. The per-hunk Keep/Undo overlay is placed over the first line of the changed hunk at the right edge of the editor, so it can cover code by design. This is a UX improvement request rather than a defect, and no duplicate was verified.

## Change summary

Move the per-hunk Keep/Undo buttons so they sit above or below the diff chunk instead of covering code.

## Best solution

Reposition the hunk widget so it does not overlap hunk content, for example by reserving space with a view zone or placing it above the hunk. Alternatively, keep it as a hover-only overlay that is easy to move out of the way.
