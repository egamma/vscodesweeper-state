# Issue #211112 — Large notebook trigger very many leak warnings 

[https://github.com/microsoft/vscode/issues/211112](https://github.com/microsoft/vscode/issues/211112)

## Summary

Still reproduces on main: each CellOutputElement independently subscribes to menu.onDidChange via _attachToolbar (line 349 of cellOutput.ts), so notebooks with many outputs exceed the listener threshold on the shared PersistedMenuHideState emitter. The June 2025 comment confirms the leak warning persists.

## Change summary

Large notebooks trigger listener leak warnings because each cell output independently subscribes to shared event emitters, scaling linearly with cell/output count.

## Best solution

Refactor the per-output menu listener pattern in CellOutputElement._attachToolbar so that a single notebook-level listener dispatches menu changes to visible outputs, rather than each output subscribing independently. The same pattern should be audited across other per-cell contributions (cellDiagnostics, outline, etc.).
