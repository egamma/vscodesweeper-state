# Issue #207578 — Support controlling whether edits are pre-ticked in WorkspaceEdits with needsConfirmation=true

[https://github.com/microsoft/vscode/issues/207578](https://github.com/microsoft/vscode/issues/207578)

## Summary

The extension API still cannot force a workspace-edit preview independently of confirmation and its unchecked defaults. Keep this accepted, well-supported request open while the existing implementation candidate is reviewed.

## Change summary

Allow extensions to request a workspace-edit preview with changes selected by default without requiring per-edit confirmation.

## Best solution

Review https://github.com/microsoft/vscode/pull/210175, which proposes exposing independent preview control through WorkspaceEditMetadata. Preserve the explicit opt-in semantics of needsConfirmation while allowing ordinary edits to appear selected in a forced preview.
