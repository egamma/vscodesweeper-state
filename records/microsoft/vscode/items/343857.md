# Issue #343857 — [marketplace] Clean up old MCP detail pages and redirect legacy links

[https://github.com/microsoft/vscode/issues/343857](https://github.com/microsoft/vscode/issues/343857)

## Summary

Keep open: current source still sends legacy MCP links to the standalone MCP details editor rather than the customization connector experience. The report provides a sufficient flow to retest; the newer customization URL handler coexists with, but does not replace, that legacy routing.

## Change summary

Retire obsolete MCP marketplace detail entry points and preserve provider links by routing them to the corresponding customization connector where possible.

## Best solution

Make supported legacy MCP links reach the matching connector in the customization experience, while preserving legitimate MCP installation flows. Agree on the user-visible outcome for unmatched or obsolete links before retiring their detail pages.
