# Issue #95493 — Add support for `font-stretch`

[https://github.com/microsoft/vscode/issues/95493](https://github.com/microsoft/vscode/issues/95493)

## Summary

A real editor-font capability remains missing on current main. This accepted Backlog request has 126 upvotes and should remain open under the community feature-request process.

## Change summary

Allow users to select condensed or expanded font faces through an editor font-stretch setting.

## Best solution

Add a validated editor font-width/stretch option and propagate it through font measurement and DOM styling. Preserve `editor.fontVariations` for variable-font axes while supporting CSS font face selection for static condensed and expanded families.
