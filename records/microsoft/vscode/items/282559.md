# Issue #282559 — Model Picker: Show Full Model Tags (e.g. mistral:7b) to Avoid Duplicates

[https://github.com/microsoft/vscode/issues/282559](https://github.com/microsoft/vscode/issues/282559)

## Summary

Current main still discards Ollama's distinguishing tag from the visible model name, while retaining it only as the model identifier. This accepted Backlog request remains necessary, and no older open issue reports the same observable symptom.

## Change summary

Show complete Ollama model tags such as `qwen2.5-coder:14b` in the Chat model picker so variants do not appear as indistinguishable duplicate names.

## Best solution

Preserve the exact provider model identifier in the picker presentation when a friendly name omits distinguishing information, preferably through a provider-neutral secondary label or collision treatment that keeps compact names readable while making every selectable variant unambiguous.
