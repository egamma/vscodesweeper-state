# Issue #108131 — Incorrect syntax error highlighting in workspace folder list

[https://github.com/microsoft/vscode/issues/108131](https://github.com/microsoft/vscode/issues/108131)

## Summary

Keep open under discussion: current source still bubbles diagnostics from Explorer-hidden files, and the maintainer explicitly left the desired semantics unresolved. Existing controls do not selectively suppress those files' ancestor decorations.

## Change summary

Prevent diagnostics in excluded files or folders from coloring their visible ancestor folders in the Explorer.

## Best solution

Settle whether Explorer visibility should influence diagnostic bubbling independently of diagnostic collection. If accepted, provide selective suppression in the marker-decoration path while preserving diagnostics and decorations for nonexcluded files.
