# Issue #108131 — Incorrect syntax error highlighting in workspace folder list

[https://github.com/microsoft/vscode/issues/108131](https://github.com/microsoft/vscode/issues/108131)

## Summary

The behavior remains intentional but debatable: Explorer exclusions control visibility, while diagnostics independently bubble through file decorations. Keep this correctly routed issue under discussion because the requested exclusion semantics remain unresolved.

## Change summary

Stop diagnostics from hidden files or folders from coloring their visible Explorer ancestors.

## Best solution

Decide whether `files.exclude` should also suppress diagnostic bubbling; if accepted, filter excluded descendants when aggregating problem decorations without removing their diagnostics from the Problems view.
