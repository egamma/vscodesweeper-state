# Issue #299387 — Theme colors for `VS Code Dark Experimental Dark` are not nice (this is just my personal preference/opinion)

[https://github.com/microsoft/vscode/issues/299387](https://github.com/microsoft/vscode/issues/299387)

## Summary

Keep this open as actionable theme-design feedback: maintainers accepted that dimmed syntax colors can imply unused code and agreed to iterate. Existing theme selection and color overrides provide alternatives, but do not resolve the requested improvements to Dark 2026 itself.

## Change summary

Improve Dark 2026 syntax colors so active code remains distinguishable from subdued editor annotations and retains useful token distinctions.

## Best solution

Have the theme owners settle the syntax hierarchy for Dark 2026, particularly active members and variables versus unused code, comments, ghost text, and CodeLens. Preserve Dark Modern as an alternative without treating switching themes as completion of the accepted design feedback.
