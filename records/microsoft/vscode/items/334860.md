# Issue #334860 — Markdown Preview search does not work when preview is moved to a separate window

[https://github.com/microsoft/vscode/issues/334860](https://github.com/microsoft/vscode/issues/334860)

## Summary

Real, well-specified bug: Markdown Preview find does not work once the preview webview is detached into its own window. A second, independently-filed issue (https://github.com/microsoft/vscode/issues/336063) reaches the same diagnosis — 'Find in the preview's webview is tied to the wrong window' — and is already assigned to a webview-area maintainer, corroborating the defect.

## Change summary

Cmd/Ctrl+F search in the Markdown Preview finds nothing once the preview tab has been moved into a separate VS Code window.

## Best solution

Fix belongs in the webview/editor multi-window plumbing (src/vs/workbench/contrib/webviewPanel/browser/webviewCommands.ts and src/vs/workbench/contrib/webview/browser/webviewElement.ts's focus/find routing) so find commands and keyboard focus target the webview's own auxiliary window rather than the main window; track alongside https://github.com/microsoft/vscode/issues/336063 which a maintainer is already looking at.
