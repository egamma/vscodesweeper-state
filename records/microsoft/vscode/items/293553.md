# Issue #293553 — Code highlighting doesn't have option for Kusto (KQL)

[https://github.com/microsoft/vscode/issues/293553](https://github.com/microsoft/vscode/issues/293553)

## Summary

Kusto/KQL syntax highlighting is a niche language support that belongs in an extension, not in VS Code core. An existing extension already provides this, and VS Code's values explicitly place language-specific features in extensions.

## Change summary

Add built-in Kusto Query Language (KQL) syntax highlighting to VS Code core.

## Best solution

Use the existing Marketplace extension (e.g. rosshamish/kuskus-kusto-syntax-highlighting) for KQL syntax highlighting. For corporate environments that restrict extension installs, the right path is an IT policy change or a custom VSIX sideload — not bundling a niche language grammar into core. If the extension API is insufficient for this use case, a concrete API gap would be an actionable core request.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding a niche language grammar to the core product conflicts with VS Code's foundational value that the power lives in extensions and the default experience stays lightweight.
- **Evidence:** Values: "Out of the box, VS Code is a text editor: lightweight and fast. Users may install extensions that impact the appearance and nature of VS Code." and "The power lives in extensions."
