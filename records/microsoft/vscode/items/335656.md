# Issue #335656 — Folder picker search: Also search in parent folders of current folders

[https://github.com/microsoft/vscode/issues/335656](https://github.com/microsoft/vscode/issues/335656)

## Summary

Team-authored feature idea from a maintainer, already scheduled in milestone 1.141.0 — a real (non-holding-bin) milestone, so this stays open regardless of anything else; it's also a COLLABORATOR-authored request, which is protected from judgment closes.

## Change summary

Make the folder-picker search field in the Agents Window also match against parent directories of the currently listed folders, not just the folders themselves.

## Best solution

Extend the workspace/folder picker's filtering in src/vs/sessions/contrib/chat/browser/sessionWorkspacePicker.ts (and/or the recent-workspace ranking it builds on) so a search term can match a common parent path segment, surfacing folders under that parent even when the parent itself isn't a listed entry.
