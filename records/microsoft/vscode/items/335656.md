# Issue #335656 — Folder picker search: Also search in parent folders of current folders

[https://github.com/microsoft/vscode/issues/335656](https://github.com/microsoft/vscode/issues/335656)

## Summary

Keep open: the workspace picker searches known entries but does not discover folders under their common parents. The related full-history search request explicitly excludes filesystem discovery, so it does not absorb this team-authored request.

## Change summary

Let the Agents Window folder picker discover matching folders under parents of current folders without opening Choose Folder.

## Best solution

Support bounded, query-driven folder discovery around known workspace parents while preserving the compact initial picker and existing folder-selection behavior. Agree on discovery depth and local-versus-remote scope before implementation.
