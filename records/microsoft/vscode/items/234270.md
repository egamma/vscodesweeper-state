# Issue #234270 — Horizontal scroll position resets in file when seek peek definition called

[https://github.com/microsoft/vscode/issues/234270](https://github.com/microsoft/vscode/issues/234270)

## Summary

A real editor UX gap remains on current main: opening Peek Definition reveals a column-1 range horizontally, discarding the user's horizontal viewport. The issue is already routed and accepted in the Backlog, so it should remain open.

## Change summary

Preserve the outer editor's horizontal scroll position when opening Peek Definition on a long line.

## Best solution

Reveal the peek anchor vertically without changing the outer editor's horizontal scroll position, preferably in the peek-specific widget path rather than changing every ZoneWidget consumer.
