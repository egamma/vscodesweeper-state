# Issue #53666 — Use code editor for rename input box

[https://github.com/microsoft/vscode/issues/53666](https://github.com/microsoft/vscode/issues/53666)

## Summary

Still valid: the rename widget on current main uses a plain HTMLInputElement (InputWithButton class), not a code editor widget — sub-word navigation and other editor keybindings remain unavailable in the rename input. With 36 upvotes this has solid community interest and belongs in Backlog.

## Change summary

Replace the plain HTML input in the rename widget with a code editor widget so that editor keybindings (sub-word navigation, etc.) work during symbol rename.

## Best solution

Replace InputWithButton's HTMLInputElement in src/vs/editor/contrib/rename/browser/renameWidget.ts with a CodeEditorWidget (similar to how the find widget or other inline inputs use embedded editors), enabling sub-word navigation, block cursor, and consistent editor keybindings in the rename flow.
