# Issue #307161 — `This setting is deprecated. Use js/ts.updateImportsOnFileMove.enabled instead.`

[https://github.com/microsoft/vscode/issues/307161](https://github.com/microsoft/vscode/issues/307161)

## Summary

The legacy setting is intentionally retained as a fallback rather than rewritten automatically, and a maintainer explicitly documented that design for the same JS/TS settings migration. The replacement setting is already rendered as inline code and a settings link on current main.

## Change summary

Automatically migrate deprecated JavaScript and TypeScript settings to their unified replacements and make replacement IDs visually distinct.

## Best solution

Keep honoring legacy JavaScript and TypeScript settings as fallbacks while prompting users to migrate manually, avoiding unsolicited edits to user or workspace settings. Continue presenting replacement IDs as linked inline code.
