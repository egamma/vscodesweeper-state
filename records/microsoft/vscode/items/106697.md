# Issue #106697 — editor.renderWhitespace should have option for selection+trailing

[https://github.com/microsoft/vscode/issues/106697](https://github.com/microsoft/vscode/issues/106697)

## Summary

The requested combination remains unsupported on current main, and this accepted Backlog request has 86 community upvotes. It should remain open for editor-option design and implementation.

## Change summary

Allow trailing whitespace to remain visible while also rendering all whitespace inside selected text.

## Best solution

Make selection rendering composable with the existing whitespace mode, likely through a separate boolean editor option while preserving the current `selection` value for compatibility. Update both whitespace rendering paths consistently.
