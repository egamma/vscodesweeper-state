# Issue #293306 — Extending the stream for BYOK to include usage data

[https://github.com/microsoft/vscode/issues/293306](https://github.com/microsoft/vscode/issues/293306)

## Summary

The requested BYOK usage-data stream extension is implemented on current main. Commit 2e3f347c80edcd93738b39071ef9fa93394c7656 adds both provider emission and consumer decoding, so this can be closed as completed.

## Change summary

Carry BYOK token-usage data through the language-model response stream instead of relying solely on provider-side logging.

## Best solution

Keep the implemented LanguageModelDataPart usage channel and its consumption by ExtensionContributedChatEndpoint. Request-log correlation is a separate concern and does not need to be removed to satisfy this request.
