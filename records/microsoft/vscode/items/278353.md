# Issue #278353 — Word Wrap turns off when switching files in Explorer panel

[https://github.com/microsoft/vscode/issues/278353](https://github.com/microsoft/vscode/issues/278353)

## Summary

The Explorer-versus-tab difference needs clarification: preview replacement can dispose the model holding the temporary wrap override, whereas switching between retained tabs should preserve it. Request current-build confirmation and distinguish preview replacement from switching between already-open files before proposing a fix or close.

## Change summary

Word Wrap reportedly resets after switching files through Explorer, including when returning to the original file, but not when switching through tabs.

## Best solution

Establish whether Explorer navigation loses the wrap override while the original document remains open. If so, correct the editor wrapping/model-switch path; if preview replacement closes the document, have the area owner assess that lifecycle behavior against the accepted report.
