# Issue #325068 — Single Detail Panel: List toggle isn't needed to all tab types

[https://github.com/microsoft/vscode/issues/325068](https://github.com/microsoft/vscode/issues/325068)

## Summary

Team-authored polish issue for the Agents window single-pane detail toggle. PR #325137 was merged to hide the toggle for tabs without a detail panel, but the author reported on July 15 that the list icon still appears on maximized browser tabs — indicating the fix is incomplete or a follow-up is needed. Hard keep-open: MEMBER author.

## Change summary

The single-pane detail-panel list toggle icon appears unconditionally on all tab types, including browser and search tabs that don't have a detail panel, and its position causes the always-present icons (maximize, '...') to shift.

## Best solution

Extend the `when` condition on the Toggle Details menu item (registered in `singlePaneResponsiveSidebarStrategy.ts`) to also check a per-editor-type context key indicating whether the active tab supports a detail panel. The author's July 15 comment confirms the browser-tab case is still broken after PR #325137 — a follow-up fix is needed in the same area.
