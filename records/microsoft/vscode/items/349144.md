# Issue #349144 — Agents window: make the idle Copilot session release delay configurable

[https://github.com/microsoft/vscode/issues/349144](https://github.com/microsoft/vscode/issues/349144)

## Summary

Keep open as a feature request: current source still uses a fixed 10-second idle-release delay, with no user-facing control to extend or disable it. Configurable retention is distinct from making released sessions faster to restore.

## Change summary

Allow users to extend or disable idle session release to avoid repeated SDK restoration when switching among Copilot sessions.

## Best solution

Provide a host-owned retention preference that works for remote agent hosts, with explicit disable semantics and documented memory and cross-client session-ownership tradeoffs. Preserve independent capacity-based eviction and active-work protections.
