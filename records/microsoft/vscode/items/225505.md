# Issue #225505 — Multi diff editor screen cheese

[https://github.com/microsoft/vscode/issues/225505](https://github.com/microsoft/vscode/issues/225505)

## Summary

The Timeline title path now strips commit-message newlines before constructing the multi-diff editor name, addressing the broken two-line title shown in the screenshot. Propose closing as completed based on the concrete implementation change.

## Change summary

Opening a commit from Timeline produces a multi-diff editor title whose embedded newline pushes the file count onto a clipped second line.

## Best solution

Keep the subject-only Timeline title behavior implemented in commit 597148770d28029af9746d70edf64bb9e020e161; the editor title retains the complete commit subject without including message-body or trailing newlines.
