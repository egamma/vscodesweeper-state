# Issue #318351 — `Ctrl`+`Alt`+`C` doesn't work for files opened outside of the opened folder

[https://github.com/microsoft/vscode/issues/318351](https://github.com/microsoft/vscode/issues/318351)

## Summary

The default Linux Copy Path shortcut depends on focus, not whether the file belongs to the opened folder. With text-editor focus, the shortcut is Ctrl+K followed by Ctrl+Alt+C; the reported command-palette success is consistent with that intentional distinction.

## Change summary

The reporter expects Ctrl+Alt+C to copy the path of an externally opened file while editing it.

## Best solution

Keep the existing focus-dependent bindings and explain the editor chord, or use Ctrl+K followed by P to copy the active file's path regardless of focus.

  > Thanks for the report. On Linux, `Copy Path` (`copyFilePath`) uses Ctrl+Alt+C outside text-editor focus, but Ctrl+K followed by Ctrl+Alt+C while the text editor is focused. This distinction does not depend on whether the file is inside the opened folder.
  > 
  > For the active file, you can also use Ctrl+K followed by P (`workbench.action.files.copyPathOfActiveFile`), which has no focus condition.
