# Issue #206041 — Native hover in folding control

[https://github.com/microsoft/vscode/issues/206041](https://github.com/microsoft/vscode/issues/206041)

## Summary

The folding arrow still uses a native tooltip rather than the editor hover. Keep this under discussion: maintainers proposed editor-hover adoption, and the later report of the same behavior was deferred, not fixed.

## Change summary

Replace the folding control's native tooltip with an editor hover.

## Best solution

Provide the existing expand/collapse hint through the editor hover at the folding control's actual position, preserving folding behavior and avoiding simultaneous native and editor tooltips. The editor owner should reconsider the gutter limitation documented in the later report before scheduling this work.
