# Issue #334495 — Agents Window should respect git.enableCommitSigning

[https://github.com/microsoft/vscode/issues/334495](https://github.com/microsoft/vscode/issues/334495)

## Summary

The signing-setting gap remains in current source: Source Control explicitly requests signing, while agent shell execution does not translate the setting into Git behavior. Keep this team-authored issue open; the policy needs to cover agent-created and rewritten commits, not only host-managed commit actions.

## Change summary

Make commits created or rewritten through the Agents Window observe the user's commit-signing preference consistently with Source Control.

## Best solution

Establish a repository-scoped signing contract for agent execution, preferably honoring git.enableCommitSigning while preserving Git-configured signing when the setting is disabled. Cover ordinary commits and rebase-created commits without changing global Git configuration or leaking one workspace's preference into another.

- **Behavior:**

- **Open decisions:**
