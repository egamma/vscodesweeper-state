# Issue #334495 — Agents Window should respect git.enableCommitSigning

[https://github.com/microsoft/vscode/issues/334495](https://github.com/microsoft/vscode/issues/334495)

## Summary

Confirmed on main: the Agents Window's git service never passes a signing flag when it creates commits, so `git.enableCommitSigning` is silently ignored for agent-authored commits — this is a real, localized gap worth fixing.

## Change summary

Commits created by an agent in the Agents Window are not signed even when git.enableCommitSigning is enabled, because the agent's Git operations don't observe that setting.

## Best solution

Inject IConfigurationService into AgentHostGitService (src/vs/platform/agentHost/node/agentHostGitService.ts) and append `--gpg-sign`/`-S` to the `commit` and `commit-tree` invocations in `commitAll` and `commitTree` when `git.enableCommitSigning` is true for the relevant resource, mirroring how extensions/git/src/commands.ts sets `opts.signCommit`.
