# Issue #171153 — [html] validation error on JavaScript block comment with arrow in HTML script

[https://github.com/microsoft/vscode/issues/171153](https://github.com/microsoft/vscode/issues/171153)

## Summary

Still reproduces on main: the `updateContent` function in embeddedSupport.ts naively replaces `<!--`/`-->` with `/* `/` */`, which corrupts valid JS containing `-->` in comments or regex literals, producing spurious diagnostics. An open PR (#240932) exists but has not merged.

## Change summary

JavaScript block comments or regex containing `-->` in HTML `<script>` tags produce spurious validation errors because the HTML language server's naive string replacement corrupts the JS content.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/240932, or implement the approach @aeschli suggested (blank out HTML comment markers instead of replacing them with `/* */`). The fix lives in `extensions/html-language-features/server/src/modes/embeddedSupport.ts`, line 200.
