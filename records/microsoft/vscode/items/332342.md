# Issue #332342 — Custom agents in multi folder workspace are not distinguishable when named the same

[https://github.com/microsoft/vscode/issues/332342](https://github.com/microsoft/vscode/issues/332342)

## Summary

Team-authored (dbaeumer, MEMBER) bug report confirmed by another reporter and used as the canonical for a duplicate close (#332429); no fix commit found in the picker/customization discovery code, so it remains open and unresolved.

## Change summary

In a multi-root workspace, two custom agents (.github/agents) sharing the same name across different roots collapse into a single entry in the agent picker, so users can't tell them apart or pick the right one.

## Best solution

Disambiguate same-named custom agents in the picker by workspace folder (e.g. group/label by root, similar to how the model picker groups by provider) — likely in the mode/agent picker rendering (src/vs/workbench/contrib/chat/browser/widget/input/modePickerActionItem.ts) and the customization aggregation that merges per-folder agent definitions (agentCustomizationItemProvider.ts).
