# Issue #224569 — Auto indent when move line up or down

[https://github.com/microsoft/vscode/issues/224569](https://github.com/microsoft/vscode/issues/224569)

## Summary

Keep open: Python's built-in language configuration still supplies on-enter rules without indentation rules, and MoveLinesCommand rejects that configuration before attempting automatic indentation. This matches the maintainer's confirmed diagnosis; enabling editor.autoIndent does not resolve the missing path.

## Change summary

Moving Python lines with Alt+Up or Alt+Down should honor available automatic-indentation rules instead of requiring manual indentation afterward.

## Best solution

Make line movement honor Python's existing on-enter indentation behavior when editor.autoIndent is full, while preserving existing behavior for other languages and lower auto-indent settings. This belongs in the built-in language configuration/editor command path, not a transfer to the external Python extension tracker.
