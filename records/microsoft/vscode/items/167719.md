# Issue #167719 — Explore using `ArrayBuffer` as backend for editor text contents

[https://github.com/microsoft/vscode/issues/167719](https://github.com/microsoft/vscode/issues/167719)

## Summary

Keep this architectural exploration open: current main still uses strings for the PieceTree backing store, while the merged safeguards mitigate only specific large-file heap operations.

## Change summary

Explore an ArrayBuffer-backed editor text buffer to permit safer editing of files beyond V8 string-heap limits.

## Best solution

Retain this as the large-file text-buffer design investigation. Benchmark whether an ArrayBuffer-backed change buffer materially improves large-file editing beyond the existing heap-operation guards before changing PieceTree.
