# Issue #332502 — Git: getRemoteRefs returns remote head refs with name and commit swapped

[https://github.com/microsoft/vscode/issues/332502](https://github.com/microsoft/vscode/issues/332502)

## Summary

Confirmed on current main: `getRemoteRefs` swaps `name`/`commit` for head refs (name gets the SHA, commit gets the ref name), while the tags branch three lines below does it correctly. An open PR (#332508) already fixes this, so it should stay open for that PR to merge rather than being closed now.

## Change summary

Git.getRemoteRefs() returns head refs with `name` holding the SHA and `commit` holding the branch ref name instead of the reverse.

## Best solution
