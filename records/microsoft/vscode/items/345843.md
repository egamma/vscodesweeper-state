## Summary

Keep open as a feature request for composable agent definitions. Existing instruction references and Local tool sets provide partial reuse, but do not fully cover extending the built-in Plan agent or reusable tool-set composition across harnesses.

## Change summary

Allow agent files to compose reusable named instructions and tool sets instead of copying complete agent definitions.

## Best solution

Evaluate the remaining agent-composition gap against existing instruction links, skills, and harness-specific tool configuration. Establish whether extending built-in agents is supported product behavior before introducing another configuration mechanism.
