# Issue #89751 — Untitled file title gets in my way when trying to save

[https://github.com/microsoft/vscode/issues/89751](https://github.com/microsoft/vscode/issues/89751)

## Summary

Still reproduces on main: the simple file dialog re-inserts the content-derived untitled filename into the path input every time a folder is navigated, making it painful to save with a custom name. Team-authored, On Deck milestone — keeping open.

## Change summary

When saving an untitled file via the simple file dialog, the auto-generated filename (derived from first-line content) is re-inserted into the input box on every folder navigation, blocking the user from typing their own path.

## Best solution

Change the simple file dialog's save behavior so that once the user clears or modifies the suggested filename, the `trailing` value is not forcibly re-appended on folder navigation. The fix lives in `src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts` around the `onDidAccept` and `updateItems` paths that use `this.trailing`. One approach (from comment #1) is to only re-insert the suggested name on click-based folder selection, not on typed input; another (from comment #2) is to show a dedicated 'Save as <name>' row.
