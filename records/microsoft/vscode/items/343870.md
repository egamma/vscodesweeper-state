# Issue #343870 — Add 'Open on GitHub' button

[https://github.com/microsoft/vscode/issues/343870](https://github.com/microsoft/vscode/issues/343870)

## Summary

Keep open: existing repository links provide partial coverage, but the plugin-specific detail view links to the marketplace rather than necessarily to the plugin's own source. This team-authored request remains valid; no issue-referencing fix or verified duplicate was established.

## Change summary

Provide a discoverable way to open a plugin's source repository before installing it.

## Best solution

Make the actual plugin source repository directly accessible from plugin details, distinguishing it from the marketplace repository. Reuse the repository-link behavior already present in the unified marketplace detail view where possible.
