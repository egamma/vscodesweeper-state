# Issue #333684 — Back link is missing in subagent transcript

[https://github.com/microsoft/vscode/issues/333684](https://github.com/microsoft/vscode/issues/333684)

## Summary

The navigation gap remains on current main: Agent Host preserves a subagent's parent chat, but that provenance is not bridged into the request origin rendered by the transcript. This team-authored report should remain open and route to the Agents Window/subagent owners.

## Change summary

Show an accessible back link in a subagent transcript that opens the chat which spawned it.

## Best solution

Expose the subagent chat's existing `ChatOriginKind.Tool.parentChat` provenance through the first transcript request so the shared request-origin control can identify and open the spawning chat, without changing ordinary chat or side-chat presentation.
