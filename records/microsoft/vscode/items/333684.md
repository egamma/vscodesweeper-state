# Issue #333684 — Back link is missing in subagent transcript

[https://github.com/microsoft/vscode/issues/333684](https://github.com/microsoft/vscode/issues/333684)

## Summary

Team-authored polish request filed same day: the subagent transcript view has no affordance to navigate back to the session that spawned it, unlike side chat which does. Checked the source and found no such back-link/parent-navigation UI wired into the subagent transcript rendering, so the gap is real and unaddressed on main; team-authored issues stay open absent a citable fix commit referencing this issue.

## Change summary

Subagent chat transcripts lack a visible link back to the parent session that started them, unlike side chat which has this affordance.

## Best solution

Add a parent-session back-link to the subagent transcript header/toolbar, likely in chatSubagentContentPart.ts / chatSubagentOpenChat.ts, reusing the parentSessionResource plumbing already used to open subagent chats from the parent.
