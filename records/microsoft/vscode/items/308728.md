# Issue #308728 — Chinese is not supported when creating a skill

[https://github.com/microsoft/vscode/issues/308728](https://github.com/microsoft/vscode/issues/308728)

## Summary

The skill name restriction to lowercase letters, numbers, and hyphens is intentional — it follows the agentskills.io specification and the name doubles as the folder name on disk. This is working as designed.

## Change summary

Request to allow Chinese characters in skill names when creating a skill via the VS Code UI.

## Best solution

Keep the current validation. Skill names follow the agentskills.io specification (1–64 chars, lowercase alphanumeric + hyphens, no leading/trailing/consecutive hyphens) and serve as filesystem folder names. The `name` frontmatter field inside SKILL.md or the `description` field could carry a localized display name, but the identifier itself is spec-constrained. Close as designed.
