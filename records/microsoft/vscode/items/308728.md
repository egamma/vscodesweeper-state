# Issue #308728 — Chinese is not supported when creating a skill

[https://github.com/microsoft/vscode/issues/308728](https://github.com/microsoft/vscode/issues/308728)

## Summary

Chinese skill names remain blocked in current source. Keep this open under the existing upstream classification: the contributor reports that the Copilot SDK also rejects Unicode names, so relaxing the creation UI alone would not deliver working skills.

## Change summary

Support Chinese names when creating and loading agent skills.

## Best solution

Establish Unicode skill-name support across the Copilot SDK and VS Code's creation and frontmatter validation paths before lifting the restriction. Retain this issue as the VS Code integration tracker rather than asking the reporter to re-file it.
