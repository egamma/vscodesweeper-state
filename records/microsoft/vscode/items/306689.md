# Issue #306689 — Profile icon selection does not have development platforms and languages.

[https://github.com/microsoft/vscode/issues/306689](https://github.com/microsoft/vscode/issues/306689)

## Summary

This is a valid, currently unmet profile-customization request that should be routed to the profiles and icon-picker owners. The older extension-contributed-icons issue is related but does not meet the stronger re-review duplicate bar because it reports a different observable limitation.

## Change summary

Expand profile icon choices to cover mainstream programming languages and development platforms.

## Best solution

Avoid permanently bundling a large catalog of language and platform brands in core; enable profile icon contributions through the existing icon-picker work at https://github.com/microsoft/vscode/issues/194276, with only a small curated core set if maintainers find that useful.

## Vision fit

- **Fit:** rejected
- **Reason:** Bundling an expansive catalog of specialized development-brand icons adds core assets and maintenance better supplied through extensions.
- **Evidence:** Values and guardrails: “The power lives in extensions” and the default product should remain a lightweight, fast text editor.
