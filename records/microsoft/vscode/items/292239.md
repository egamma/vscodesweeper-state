# Issue #292239 — When I have a git changes editor open, if I change files in git, the editor steals focus

[https://github.com/microsoft/vscode/issues/292239](https://github.com/microsoft/vscode/issues/292239)

## Summary

Still reproduces on main: when git status changes while the multi-diff changes editor is open, the autorun that initializes the first-change selection re-fires with `focusEditor: true`, stealing focus from wherever the user is working (e.g. the terminal).

## Change summary

The multi-file git changes editor steals keyboard focus from other panes (e.g. terminal) whenever git status updates cause the editor's item list to change.

## Best solution

Guard the first-change navigation autorun in `multiDiffEditorWidgetImpl.ts` so it only moves focus on the true initial load, not on subsequent item-list updates. One approach: track whether the initial navigation has already fired and skip focus stealing on re-triggers; another is to check whether the editor pane currently has DOM focus before calling `editor.focus()`.
