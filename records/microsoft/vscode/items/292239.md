[https://github.com/microsoft/vscode/issues/292239](https://github.com/microsoft/vscode/issues/292239)

## Summary

Keep open: current source still allows a Git change-list refresh to move keyboard focus into the multi-diff editor after its active file disappears. The existing multi-diff-editor label is appropriate; On Deck is a holding milestone, not evidence of a fix.

## Change summary

Refreshing an open Git multi-file diff after terminal Git operations must not steal focus from the terminal.

## Best solution

Keep background multi-diff resource updates from taking keyboard focus away from another control, while preserving intentional editor opening and explicit change navigation. Cover active-file replacement and empty-to-populated refreshes in the multi-diff widget tests.
