# Issue #55718 — API to retrieve a dimensions from a given Terminal instance

[https://github.com/microsoft/vscode/issues/55718](https://github.com/microsoft/vscode/issues/55718)

## Summary

Keep open for API finalization: terminal dimensions and resize notifications are implemented, but remain proposed on current main. The existing implementation does not complete the stable extension API work tracked here.

## Change summary

Expose the current dimensions of an arbitrary Terminal instance and notify extensions when those dimensions change.

## Best solution

Have the terminal API owners evaluate finalizing Terminal.dimensions and window.onDidChangeTerminalDimensions for stable extension consumption. Preserve the distinction between observing existing terminals and overriding their dimensions.
