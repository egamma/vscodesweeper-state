# Issue #316587 — Open file from editor without navigating into other scopes

[https://github.com/microsoft/vscode/issues/316587](https://github.com/microsoft/vscode/issues/316587)

## Summary

A real editor capability gap remains: built-in link detection recognizes URL-shaped `http(s)` and `file` links, but not bare absolute or workspace-relative paths. The request is technically suitable for a document-link extension, but without maintainer scope precedent it should remain open for editor-area discussion rather than be closed as an extension candidate.

## Change summary

Recognize bare absolute, workspace-relative, and out-of-workspace file paths in editor text and open them with Ctrl/Cmd+click.

## Best solution

Prefer an extension using the existing document-link provider API to recognize the required path formats and resolve workspace-relative paths, unless editor maintainers decide that universal bare-path detection is sufficiently unambiguous and broadly useful for the default provider.

## Evidence

- **current behavior:** src/vs/editor/common/languages/linkComputer.ts defines the default state machine specifically for `http://`, `https://`, and `file://`; bare paths such as `/usr/include/stdlib.h` and `llvm/analysis/Pass.cpp` are not recognized.
- **editor path:** src/vs/editor/browser/services/editorWorkerService.ts registers that default link provider for all editor languages, while src/vs/editor/contrib/links/browser/links.ts renders and opens only links returned by registered providers.
- **extension capability:** src/vscode-dts/vscode.d.ts exposes `languages.registerDocumentLinkProvider`, allowing an extension to recognize bare paths and provide resolved file targets in normal text editors.
- **canonical search:** The supplied candidate https://github.com/microsoft/vscode/issues/20530 concerns restricting Search to selected files, while https://github.com/microsoft/vscode/issues/139845 concerns normalization after a relative path has already been recognized; neither owns universal bare-path detection in editor documents.
