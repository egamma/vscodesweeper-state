# Issue #316587 — Open file from editor without navigating into other scopes

[https://github.com/microsoft/vscode/issues/316587](https://github.com/microsoft/vscode/issues/316587)

## Summary

Valid feature request: the editor's link detection (`editor.links`) only surfaces links from registered LinkProviders (language extensions, URL patterns), but does not detect bare absolute file paths the way the terminal does. No existing setting or built-in capability covers this; the request remains a real gap.

## Change summary

Request Ctrl+click on absolute file paths in editor text (like terminal link detection) to open the file directly.

## Best solution

A built-in or opt-in LinkProvider that detects local file-system paths in editor content and makes them clickable, similar to the terminal's file-link detection in `src/vs/workbench/contrib/terminalContrib/links/`. This could be scoped to specific file types (log files, build output) or made general with a setting. An extension could also deliver this today via the `DocumentLinkProvider` API.

## Evidence

- **editor link system:** The editor's LinkDetector (src/vs/editor/contrib/links/browser/links.ts) relies on registered LinkProvider extensions to surface links. It does not have a built-in provider for detecting bare file-system paths.
- **terminal comparison:** The terminal has dedicated file-link detection (src/vs/workbench/contrib/terminalContrib/links/browser/terminalLinkManager.ts) that recognizes absolute and relative file paths and makes them clickable — this is the behavior the reporter wants in the editor.
- **related closed issue:** https://github.com/microsoft/vscode/issues/238812 requested similar relative-path detection in log files and was closed as not-planned, though it focused on relative paths specifically.
- **existing setting:** editor.links (EditorOption.links) enables/disables link detection but only controls whether registered LinkProvider results are shown — it does not add file-path detection.
- **extension API alternative:** The DocumentLinkProvider API allows extensions to detect and provide arbitrary links in editor documents, so this could be delivered as a Marketplace extension today.
