## Summary

Valid team-authored feature request for contextual onboarding nudges in the integrated browser. This is the canonical issue (https://github.com/microsoft/vscode/issues/291208 was already duped to it), and it aligns with current integrated-browser priorities. Stays open for implementation.

## Change summary

Implement a context-aware, non-sequential onboarding system that shows just-in-time nudges in the integrated browser based on user actions and milestones.

## Best solution

Implement the nudge framework in the integrated browser contribution area (`src/vs/workbench/contrib/browserView/`), with a condition-based trigger system, dismiss/shown tracking via storage, and priority-based display logic. The team comment from @cwebster-99 recommends optimizing for 'next useful feature given current state' nudges rather than generic welcome messages — that feedback should shape the implementation.
