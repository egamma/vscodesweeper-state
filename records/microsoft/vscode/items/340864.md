## Summary

Thanks for the detailed report. The autofs log does tie the /home/auto/node_modules lookup to the agentHost process, but I couldn't find the specific code path that makes it. The version field in the report is also incomplete.

## Change summary

The remote agent host process triggers a lookup of node_modules above the user's home directory, which causes autofs lookups and log noise.

## Best solution

Identify which agentHost code (Node module resolution walking up from the cwd, or an explicit probe) stats the parent directory. Then avoid probing above the home directory, or set the cwd or resolution base so the walk doesn't cross it.
