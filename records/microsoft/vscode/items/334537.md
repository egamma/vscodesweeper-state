## Summary

Team-authored report of an auth desync between the local model harness and the Copilot/agent-host harness after signing in on an updated install — already carries correct bug/authentication/agent-host labels and sits in the Backlog holding bin, but no fix commit exists on main, so it stays open for investigation.

## Change summary

After updating an old VS Code install, the account profile picture and the Copilot chat harness stayed stuck (Copilot showed only 'Auto', local showed all models) until an unrelated GH MCP sign-in prompt was answered and a message was sent, which silently repaired both.
