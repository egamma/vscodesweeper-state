[https://github.com/microsoft/vscode/issues/318773](https://github.com/microsoft/vscode/issues/318773)

## Summary

Keep open: this team-authored UX audit is a protected process/design artifact, and its central questions about banner eligibility and ordering remain broader than the precedence currently encoded in the chat input. No older canonical issue with the same observable concern was found.

## Change summary

Establish UI and UX guidance for when tips, UBB, notifications, and other banners may appear above the chat input and how competing surfaces are ordered.

## Best solution

Define a shared UX policy for eligibility, precedence, concurrency, dismissal, and focus behavior, then ensure every producer above the chat input uses that policy through the shared notice-host and input-stack infrastructure.
