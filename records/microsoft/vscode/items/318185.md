# Issue #318185 — Add a chat.fontWeight setting

[https://github.com/microsoft/vscode/issues/318185](https://github.com/microsoft/vscode/issues/318185)

## Summary

This is a valid, currently unmet Chat typography request rather than a bug or duplicate. Route it to the Chat and workbench-font owners for a product decision on whether another per-surface typography setting is warranted.

## Change summary

Add a `chat.fontWeight` setting equivalent to `editor.fontWeight` so users can select lighter weights without relying on weight-specific font-family names.

## Best solution

Have the Chat owners decide whether configurable body-text weight fits the shared typography model; if accepted, preserve intentional semibold emphasis while applying the selected weight to ordinary chat text across Chat surfaces.
