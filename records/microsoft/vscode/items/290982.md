## Change summary

Carry the selected local custom agent into the Cloud custom-agent picker when the same agent is available there.

## Best solution

Switching execution location should retain the same available, compatible custom agent without requiring reselection. Preserve Cloud availability and partner-agent restrictions rather than selecting an agent that cannot run there.
