## Summary

Valid feature request for full-text search across chat session content in the Agents window. The sessions list has a tree filter for session titles but no content-level search. Related to but distinct from https://github.com/microsoft/vscode/issues/324984 (which covers navigation/outline). Routing to the agents-window and chat areas.

Implement a search facility in the Agents window that searches across chat message content (not just session titles).
