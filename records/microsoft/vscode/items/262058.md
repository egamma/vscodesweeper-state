- **Additional evidence to preserve:** https://github.com/microsoft/vscode/issues/262058 adds reproduction after clicking Save rather than canceling, Insiders 1.104.0 with --disable-extensions, and 100% CPU that subsides while switching to a Linux virtual console. Its sole comment says Windows does not appear affected. These details extend the canonical scenario without establishing a distinct defect.
- **Current source and workaround:** src/vs/workbench/services/dialogs/electron-browser/fileDialogService.ts:67-75,134-140 selects the simplified dialog when files.simpleDialog.enable is true; otherwise saving uses the native host dialog. src/vs/platform/dialogs/electron-main/dialogMainService.ts:171-193 delegates to electron.dialog.showSaveDialog. A canonical commenter reports avoiding the freeze by enabling the simple dialog at https://github.com/microsoft/vscode/issues/195196#issuecomment-2072516025. Source inspection establishes this boundary, not the underlying hang's root cause or a current-main fix.
