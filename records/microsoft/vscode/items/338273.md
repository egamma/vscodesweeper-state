# Issue #338273 — /remote on fails in Agent Host Copilot session with "Failed to get authentication token" (works in standalone Copilot CLI)

[https://github.com/microsoft/vscode/issues/338273](https://github.com/microsoft/vscode/issues/338273)

## Summary

A credible, independently-confirmed regression: `/remote on` (Mission Control-brokered remote control) started failing with 'Failed to get authentication token' after an update to VS Code 1.139.1, while the standalone Copilot CLI with the same account keeps working — so this is VS Code's side of the credential/token hand-off, not account entitlement. Root cause can't be pinned down from this checkout because the actual `/remote` command and its token exchange execute inside the external `@github/copilot-sdk`/`copilot-cli` package, not in `src/vs`.

## Change summary

## Best solution
