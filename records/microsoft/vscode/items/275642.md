# Issue #275642 — make it easier to fix global mcp config

[https://github.com/microsoft/vscode/issues/275642](https://github.com/microsoft/vscode/issues/275642)

## Summary

The defect remains on current main: installing a server with malformed user MCP JSON produces a plain parse error without an action to open the affected file. This team-authored, accepted bug should remain open.

## Change summary

When adding an MCP server fails because the global MCP configuration is malformed, offer a notification action that opens the affected configuration file.

## Best solution

Preserve the safe refusal to modify malformed JSON, but surface the failure as an actionable notification whose primary action opens the exact MCP configuration resource for correction.
