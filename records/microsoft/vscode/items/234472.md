# Issue #234472 — Editor GPU: Ignore token foreground color when there is a decoration with a foreground color

[https://github.com/microsoft/vscode/issues/234472](https://github.com/microsoft/vscode/issues/234472)

## Summary

Keep this protected plan-item open. Current source still retains token foreground bits in glyph cache keys even when a decoration replaces that foreground, so the requested atlas optimization remains necessary.

## Change summary

Avoid duplicate GPU atlas glyphs caused by token foreground colors that are overridden by inline decoration colors.

## Best solution

Make GPU atlas cache identity reflect the effective glyph appearance: otherwise-identical glyphs with the same decoration foreground should share an entry regardless of their overridden token foreground. Preserve distinctions that still affect rasterization, including font style, background and subpixel position.
