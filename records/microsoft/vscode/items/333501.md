# Issue #333501 — Continue with Microsoft: Using live id stops at dead end

[https://github.com/microsoft/vscode/issues/333501](https://github.com/microsoft/vscode/issues/333501)

## Summary

Keep open: the later Microsoft sign-in test plan explicitly lists this personal-account dead end as a remaining known issue. Hiding the option for personal accounts in automatic mode mitigates exposure but does not provide the requested explanation and recovery path.

## Change summary

Signing in through Continue with Microsoft using a personal Live ID reaches a cryptic error without a back link.

## Best solution

Make the unsupported personal-account path understandable and recoverable, allowing the user to return to sign-in choices or select an eligible account. First establish whether the blocking page is controlled by Microsoft authentication configuration or requires recovery in VS Code's surrounding sign-in flow.
