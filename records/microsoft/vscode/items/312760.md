# Issue #312760 — Copilot CLI writes outside of workspace without asking

[https://github.com/microsoft/vscode/issues/312760](https://github.com/microsoft/vscode/issues/312760)

## Summary

Team-authored bug report (testing #312653) identifying that the Copilot CLI can write files outside the workspace without prompting the user for confirmation. The permission infrastructure exists in sessionPermissions.ts but appears to have a gap for this code path. No fix commit references this issue.

## Change summary

Copilot CLI executes shell commands that write files outside the workspace (e.g. ~/Downloads/) without requiring user approval.

## Best solution

The shell command auto-approval flow in `src/vs/platform/agentHost/node/sessionPermissions.ts` and `commandAutoApprover.ts` should ensure that write redirections to paths outside the workspace directory are never auto-approved and always surface a confirmation prompt. The `_isShellWriteDestApproved` → `_checkWritePath` → `_isPathInWorkingDirectory` chain exists but may not be reached for all CLI execution paths — the gap likely lives in how the Copilot CLI session routes tool confirmations through `agentSideEffects.ts`.
