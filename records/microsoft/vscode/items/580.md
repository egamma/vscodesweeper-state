# Issue #580 — Can I get scope / scopeRange at a position?

[https://github.com/microsoft/vscode/issues/580](https://github.com/microsoft/vscode/issues/580)

## Summary

A real API gap remains on current main: extensions still cannot retrieve TextMate scopes and their ranges. With 89 upvotes and an accepted Backlog milestone, this should remain open.

## Change summary

Expose syntax-token scope and range information for a document position through the extension API.

## Best solution

Design a stable API/tokenization abstraction that returns token classification and ranges without requiring extensions to re-tokenize documents or depend directly on TextMate grammar internals.
