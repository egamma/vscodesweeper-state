# Issue #340568 — Feature Request: Rich, Expandable, Nested and Editable Todo UI for Chat and Agent

[https://github.com/microsoft/vscode/issues/340568](https://github.com/microsoft/vscode/issues/340568)

## Summary

Keep open as a feature request: current Todos support whole-list expansion and clearing, but not hierarchical tasks, per-item details, or direct editing. Earlier maintainer reasoning against descriptions addresses only part of this broader proposal, and no same-scope canonical was verified.

## Change summary

Provide hierarchical, individually expandable and editable agent Todos with full-content inspection, deletion controls, and consistent behavior across Chat and agent experiences.

## Best solution

Have the Chat owners decide which inspection and editing capabilities belong in the compact progress widget versus the existing planning experience. Any accepted hierarchy or description support needs an explicit data contract, not only a richer renderer; preserve the lightweight flat-list experience.

- **Current data contract:** src/vs/workbench/contrib/chat/common/tools/chatTodoListService.ts defines IChatTodo with only id, title, and status. createManageTodoListToolData in src/vs/workbench/contrib/chat/common/tools/builtinTools/manageTodoListTool.ts advertises those same fields and concise titles, with no description or parent/child schema. The request therefore requires new capabilities rather than merely displaying an already-supported hierarchy.

The registered setting chat.tools.todos.showWidget controls visibility, and workbench.action.chat.focusTodosView changes focus; neither delivers the requested richer task model.
