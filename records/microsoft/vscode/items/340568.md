## Summary

Thanks for the detailed proposal. The todo data model on main is flat (id, title, status), so nesting, long descriptions and editing need model and tool changes as well as UI. The request is new and has no upvotes yet, so it stays open for community feedback.

## Change summary

Redesign the chat/agent Todo UI into an expandable, hierarchical, scrollable and editable task viewer that shows full todo content.

## Best solution

Decide first whether the todo tool schema should gain parent/child and description fields. Then add expand/collapse and a full-content view to the todo list widget. Treat editing and reordering as a separate follow-up.
