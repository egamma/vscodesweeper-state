# Issue #311735 — Chat session with /clear as last command cannot be deleted from history

[https://github.com/microsoft/vscode/issues/311735](https://github.com/microsoft/vscode/issues/311735)

## Summary

The reported delete-no-op is fixed on current main: local session deletion now marks the live model deleted, immediately removes it from the session list, and prevents later persistence from recreating it.

## Change summary

Deleting a chat session after `/clear` should remove it permanently instead of leaving it stuck in history.

## Best solution

Keep the deletion lifecycle implemented by commit 9b7643f90393b9ad2c5d5cbbdad70fa928090009, which makes deletion authoritative even while the session still has a live model.
