# Issue #334407 — Add macOS Touch Bar status and quota display features.

[https://github.com/microsoft/vscode/issues/334407](https://github.com/microsoft/vscode/issues/334407)

## Summary

This asks VS Code core to surface a specific third-party extension's (Claude Code) status/quota on the macOS Touch Bar — VS Code already exposes a generic Touch Bar contribution point that extensions can use, so the actual gap (if any) belongs to that extension, not core. No maintainer precedent found yet, so keeping open rather than closing outright.

## Change summary

Show task status and quota usage for the Claude Code extension on the macOS Touch Bar.

## Best solution

If Claude Code (or any extension) wants Touch Bar presence, it should register commands/menu items against the existing `MenuId.TouchBarContext` (see src/vs/workbench/electron-browser/window.ts and updateTouchBar in src/vs/platform/window/electron-main/window.ts) rather than VS Code core building bespoke UI for one extension's status/quota.
