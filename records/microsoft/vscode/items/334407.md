# Issue #334407 — Add macOS Touch Bar status and quota display features.

[https://github.com/microsoft/vscode/issues/334407](https://github.com/microsoft/vscode/issues/334407)

## Summary

VS Code already exposes a `touchBar` menu contribution point (`contributes.menus.touchBar`, backed by `MenuId.TouchBarContext`) that any extension — including the third-party Claude Code extension the request references — can use to add Touch Bar items and status; there's nothing missing in core to build.

## Change summary

Add built-in macOS Touch Bar integration showing task status and quota usage for the Claude Code extension.

## Best solution

No core change needed — the Claude Code (or any) extension can already register Touch Bar buttons/status via `contributes.menus.touchBar` (see `src/vs/workbench/services/actions/common/menusExtensionPoint.ts` line 44-49, backed by `MenuId.TouchBarContext` in `src/vs/platform/actions/common/actions.ts`). If a specific extension-API gap blocks a richer Touch Bar display (e.g. a progress/quota widget type), that would need a separate, concrete API-gap report.
