# Issue #157408 — Add `selectionGroup` to TreeItem to allow for multiselect restrictions

[https://github.com/microsoft/vscode/issues/157408](https://github.com/microsoft/vscode/issues/157408)

## Summary

Valid feature request for constraining multi-selection in tree views by item type. Not implemented on current main — no `selectionGroup` property or equivalent exists in the TreeItem API. The issue reached the 20-upvote threshold and was promoted to Backlog; it should remain open.

## Change summary

Allow extensions to restrict multi-selection in TreeViews so only items of the same type/group can be selected together.

## Best solution

Add an optional `selectionGroup` (or similar) string property to `TreeItem` in the extension API, with selection logic in the tree view widget that constrains shift/ctrl-click to items sharing the same group. Start as a proposed API for iteration with extension authors like GitLens.
