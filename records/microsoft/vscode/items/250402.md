# Issue #250402 — Chat continues progress in background when sending empty message.

[https://github.com/microsoft/vscode/issues/250402](https://github.com/microsoft/vscode/issues/250402)

## Summary

The empty-message path on current main returns before starting accessibility signals. A concrete landed change moved request sounds and progress initialization after actual response creation, so this can be closed as completed.

## Change summary

Submitting an empty chat message should not announce a sent request or leave accessibility progress signals running indefinitely.

## Best solution

Keep the response-gated accessibility lifecycle introduced in commit dac39ff893cdc8b64a6e5a210a666e62308763e4; empty submissions without explicit attachments or participant commands should remain rejected without starting progress.
