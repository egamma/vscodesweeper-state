# Issue #285010 — Chat model selection text clipping when a scrollbar is present (MacOS)

[https://github.com/microsoft/vscode/issues/285010](https://github.com/microsoft/vscode/issues/285010)

## Summary

Keep this open under discussion: the reported clipping is credible with opaque scrollbars, while the maintainer response establishes that overlay transparency is an intentional convention but does not resolve the accessibility concern. The model picker has since been substantially redesigned, so current behavior should be checked before choosing between picker-specific and shared action-list treatment.

## Change summary

Keep model pricing or cost text visually clear of the model picker's vertical scrollbar, including when scrollbar transparency is disabled.

## Best solution

Ensure trailing model metadata remains unobscured whenever the picker has a vertical scrollbar, without depending on scrollbar transparency. If the same problem affects other action lists, establish the clearance in the shared action-list layout rather than creating model-picker-only behavior.
