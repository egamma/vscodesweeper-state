# Issue #307601 — Daily terminal relaunch warning for Git auth provider on Windows

[https://github.com/microsoft/vscode/issues/307601](https://github.com/microsoft/vscode/issues/307601)

## Summary

Still reproducible on main: revived persistent terminals detect a stale environment diff (particularly Git auth variables with per-session IPC handles) and show the relaunch warning on every startup. No fix has been applied to the diff logic or to the Git extension's variable contribution pattern. Issue #327443 is a duplicate of this one.

## Change summary

Persistent terminals show a recurring relaunch warning for Git auth provider environment changes on every VS Code startup on Windows.

## Best solution

The terminal process manager should either suppress the stale-environment warning for built-in extensions whose env vars are expected to change per session (e.g. `VSCODE_GIT_IPC_HANDLE`), or the diff logic in `_onEnvironmentVariableCollectionChange` should treat variables that are inherently per-process (IPC handles, PIDs) as non-actionable changes. The `terminal.integrated.environmentChangesRelaunch` auto-relaunch setting partially mitigates this, but the warning icon still appears. Likely fix area: `src/vs/workbench/contrib/terminal/browser/terminalProcessManager.ts` around the diff/stale logic.

- **no fix on main:** git log since 2026-04-01 shows no changes to environmentVariableInfo.ts or to the diff/stale logic in terminalProcessManager.ts.
