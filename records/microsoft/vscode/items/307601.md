# Issue #307601 — Daily terminal relaunch warning for Git auth provider on Windows

[https://github.com/microsoft/vscode/issues/307601](https://github.com/microsoft/vscode/issues/307601)

## Summary

Keep open in terminal-env-collection: another reporter confirms recurring startup warnings, and current source excludes restored terminals from automatic environment-change relaunch. The related reports do not establish an older canonical with the same symptom or a fix for this recurrence.

## Change summary

Built-in Git authentication environment contributions repeatedly require manual relaunch of restored PowerShell terminals across VS Code startups.

## Best solution

Identify which Git environment contributions change across otherwise unchanged startups and prevent unnecessary recurring relaunch requests while preserving terminal sessions. Retain accurate warnings when a running shell genuinely needs updated contributions; do not hide the warning or indiscriminately restart restored processes.
