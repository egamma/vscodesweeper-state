# Issue #36490 — [theming] editor.selectionForeground is not working

[https://github.com/microsoft/vscode/issues/36490](https://github.com/microsoft/vscode/issues/36490)

## Summary

The requested capability remains absent on current main: selection foreground rendering is still restricted to high-contrast themes. With 48 upvotes and a Backlog milestone, this established feature request should remain open.

## Change summary

Honor `editor.selectionForeground` in every color theme so selected text can retain sufficient contrast.

## Best solution

Implement a performant Monaco editor rendering path that applies the configured selection foreground in all themes without repainting every visible line on each selection change.
