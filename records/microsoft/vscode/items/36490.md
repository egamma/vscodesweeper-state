# Issue #36490 — [theming] editor.selectionForeground is not working

[https://github.com/microsoft/vscode/issues/36490](https://github.com/microsoft/vscode/issues/36490)

## Summary

Keep open: current source still restricts selection foreground rendering to high-contrast themes, and the maintainer explicitly welcomed an opt-in solution that protects default rendering performance. The extension workaround does not cover Monaco and has reported painting delays and artifacts.

## Change summary

Allow explicitly opted-in users to apply editor.selectionForeground in ordinary light and dark themes, including Monaco.

## Best solution

Provide a Monaco-compatible editor option for selection foreground rendering outside high-contrast themes, with the performance tradeoff explained and ordinary-theme rendering unchanged unless explicitly enabled. Preserve existing high-contrast behavior and evaluate selection-rendering performance before landing.

- **Behavior:**

  > Users who explicitly opt in can use editor.selectionForeground to make selected text readable in ordinary light and dark themes, including standalone Monaco. Selected syntax tokens use the configured foreground while selected and recover their normal colors when deselected. Installing a theme or changing its selection color alone must not enable the costly rendering behavior in ordinary themes. Existing high-contrast behavior must remain intact. Acceptance includes selection changes and scrolling without delayed or disappearing text, plus performance comparison with the existing default path.
- **Trace:**

  > ViewLine.onSelectionChanged and ViewLine.renderLine in src/vs/editor/browser/viewParts/viewLines/viewLine.ts gate text invalidation and inline-selected-text decorations on isHighContrast; selection-whitespace rendering does not remove the foreground gate. The earlier color-presence-based implementation was reverted for selection paint regressions; https://github.com/microsoft/vscode/issues/36490#issuecomment-1344022506 settles the direction as an explicit editor-setting opt-in, not automatic theme activation.
