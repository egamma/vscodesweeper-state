# Issue #332185 — Web Agents omits remote SDK sessions as unsupported or missing client name

[https://github.com/microsoft/vscode/issues/332185](https://github.com/microsoft/vscode/issues/332185)

## Summary

Real, well-diagnosed bug — confirmed still present on current main — with an open PR (#332188) already addressing it, so the right move is to review/land that PR rather than propose any close.

## Change summary

Copilot Agent Host's external-chat discovery drops remote SDK sessions by discarding their clientName whenever isRemote is true, so remote sessions are miscounted as having an unsupported/missing client name and don't show up in the Web Agents session list.

## Best solution

Land (or iterate on) the open PR https://github.com/microsoft/vscode/pull/332188 ("agentHost: Discover remote Copilot sessions"), which appears to target exactly this classification gap in copilotAgent.ts.
