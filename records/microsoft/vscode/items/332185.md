# Issue #332185 — Web Agents omits remote SDK sessions as unsupported or missing client name

[https://github.com/microsoft/vscode/issues/332185](https://github.com/microsoft/vscode/issues/332185)

## Summary

Confirmed on current main: `copilotAgent.ts` still discards `clientName` for any `isRemote` session before checking `COPILOT_EXTERNAL_SESSION_CLIENT_NAMES`, so remote SDK sessions are always classified as having an unsupported/missing client name and dropped from Web Agents discovery. An open PR (#332188) already targets this, so it should stay open pending that fix landing.

## Change summary

Remote agent-host SDK sessions are incorrectly filtered out of the Web Agents session list because their client name is unconditionally treated as missing when `isRemote` is true.

## Best solution

Land https://github.com/microsoft/vscode/pull/332188 (or an equivalent fix) that preserves/validates the SDK-provided client name for remote sessions in src/vs/platform/agentHost/node/copilot/copilotAgent.ts instead of discarding it whenever `isRemote` is true, then close this issue when that merges.
