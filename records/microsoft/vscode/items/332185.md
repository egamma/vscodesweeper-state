# Issue #332185 — Web Agents omits remote SDK sessions as unsupported or missing client name

## Summary

Confirmed defect in current main: `copilotAgent.ts` unconditionally discards `clientName` for remote sessions, so supported remote-producer sessions are miscounted as 'unsupported or missing client name'. An open PR already targets this exact fix, so it stays open pending that PR landing.

## Change summary
