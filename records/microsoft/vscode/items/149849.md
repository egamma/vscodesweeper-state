# Issue #149849 — Scrollbar Minimap and visible code are out of sync when CodeLens is used

[https://github.com/microsoft/vscode/issues/149849](https://github.com/microsoft/vscode/issues/149849)

## Summary

Still reproducible on main: the minimap code has zero awareness of CodeLens-injected whitespace, so in fit/fill modes the slider position and highlighted region desynchronize from the visible editor content. No fix has been committed.

## Change summary

Minimap slider and highlighted region get out of sync with the visible editor code when CodeLens lines are present and minimap size is set to 'fit' or 'fill'.

## Best solution

The minimap layout computation in `src/vs/editor/browser/viewParts/minimap/minimap.ts` needs to account for CodeLens-injected whitespace when calculating the slider position and visible region in non-proportional modes. The MinimapLayout should incorporate the whitespace offset that CodeLens adds between lines, either by rendering placeholder space for CodeLens lines or by adjusting the scroll-to-line mapping.
