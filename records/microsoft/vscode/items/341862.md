# Issue #341862 — [AgentPluginManager] Failed to sync plugin (WSL)

[https://github.com/microsoft/vscode/issues/341862](https://github.com/microsoft/vscode/issues/341862)

## Summary

Keep open: independent reports confirm remote plugin synchronization failures across WSL and Remote Tunnels, with missing skills and sustained retry traffic. Current source retains the implicated client-copy and failed-sync retry paths; the exact cause of the four-minute prompt delay still needs isolation.

## Change summary

Remote-host plugins fail synchronization with an access-denied error, remain unavailable to Copilot, and repeatedly retry alongside reported multi-minute prompt delays.

## Best solution

Preserve plugin filesystem provenance through customization publication and synchronization so remote-host plugins load successfully without being mistaken for client-local files. Failed synchronization should remain visible and retryable without sustained retry traffic or multi-minute prompt delays, while genuine client-file permission checks remain intact.
