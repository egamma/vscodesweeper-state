# Issue #341862 — [AgentPluginManager] Failed to sync plugin (WSL)

[https://github.com/microsoft/vscode/issues/341862](https://github.com/microsoft/vscode/issues/341862)

## Summary

Thanks for the detailed report. Plugin sync of ~/.copilot/installed-plugins fails with a resource permission error in a WSL remote window, and the reporter links a ~4 minute prompt stall to it. The report has the log line, version and setup, so it is complete, but I couldn't execute the WSL flow to confirm it. Keep open for the Agent Host owners.

## Change summary

In a WSL remote window, AgentPluginManager fails to sync an org-required plugin because file access is not granted, and each Copilot Chat prompt stalls for about 4 minutes.

## Best solution

Make the plugin sync path obtain or auto-grant read access for plugin directories already installed under ~/.copilot/installed-plugins in remote windows. A denied sync should also fail fast, so it doesn't stall prompts for minutes. Check the related report in https://github.com/microsoft/vscode/issues/341863 for the stall's root cause.
