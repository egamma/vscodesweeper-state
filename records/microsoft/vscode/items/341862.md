# Issue #341862 — [AgentPluginManager] Failed to sync plugin (WSL)

[https://github.com/microsoft/vscode/issues/341862](https://github.com/microsoft/vscode/issues/341862)

## Summary

Keep open: an independent report confirms the same plugin-sync access denial over Remote Tunnels, with repeated retries and empty sync targets. Current source contains the suspected client-file routing and awaited retry paths, but neither the URI-origin defect nor its contribution to the four-minute delay is fully established.

## Change summary

Remote Copilot sessions fail to synchronize installed plugins with an access-denied error and reportedly delay each prompt by approximately four minutes.

## Best solution

Make remote plugin synchronization preserve the actual filesystem owner of each plugin while retaining resource-access protections. Establish whether failed synchronization causes the reported prompt delay, and ensure persistent failures do not repeatedly stall otherwise usable chats.

## Evidence

- **Independent confirmation:** https://github.com/microsoft/vscode/issues/341862#issuecomment-6255447165 confirms the identical access-denied failure on VS Code 1.142.0 with a macOS client and Linux arm64 Remote Tunnel host. All ten CLI-installed plugins fail; reinstalling does not help, sync targets remain empty, and approximately 1,700 failures are logged per session. Client-local plugins sync successfully, while directory-marketplace plugins and the standalone CLI work.
- **Current synchronization boundary:** src/vs/platform/agentHost/node/agentPluginManager.ts:141-166 short-circuits only AGENT_HOST_FILE_SCHEME; other plugin URIs pass through toAgentClientUri before fileService.copy. src/vs/platform/agentHost/common/agentClientUri.ts identifies this wrapper as access to the connected client's filesystem. This supports the commenter's routing hypothesis, but does not establish where the reported host-local file URI entered the client customization list.
- **Retry and permission paths:** src/vs/platform/agentHost/node/copilot/copilotAgent.ts:10172-10191 waits for existing client syncs and retries failed client customizations; _sessionRefreshReasonWithAnchor awaits this path at line 6622. src/vs/platform/agentHost/common/agentHostResourceService.ts:77-83 defines the exact access-denied message, and browser/agentHostProtocolClient.ts:2251-2268 grants implicit reads for outgoing customization URIs. The interaction between URI ownership, those grants, and prompt timing requires further diagnosis.
