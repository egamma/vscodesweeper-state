Keep open: multiple reporters confirm remote plugin synchronization fails with the same access denial across WSL, Tunnels, and Dev Containers. The reported SDK improvement restores some runtime-installed plugins but explicitly leaves the synchronization failure unresolved.

## Change summary

Remote-host plugins fail synchronization with an access-denied error, leaving customizations unavailable and accompanying repeated retries and long prompt delays.
