# Issue #341862 — [AgentPluginManager] Failed to sync plugin (WSL)

[https://github.com/microsoft/vscode/issues/341862](https://github.com/microsoft/vscode/issues/341862)

## Summary

Keep open: multiple reporters confirm remote plugin synchronization failures across WSL, Tunnels, and Dev Containers. Newer SDK behavior reportedly restores native plugin loading in some cases, but does not resolve the synchronization errors.

## Change summary

Remote Copilot plugin synchronization rejects plugin paths and repeatedly retries, leaving customizations unavailable and delaying prompts.

## Best solution

Correct plugin resource ownership and URI handling across the client/agent-host boundary while preserving access controls. Verify successful remote plugin loading separately from retry-related prompt delays; an SDK upgrade alone does not establish that both are fixed.
