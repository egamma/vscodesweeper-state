# Issue #330941 — Session list change counts show the whole branch divergence, not the session's changes

[https://github.com/microsoft/vscode/issues/330941](https://github.com/microsoft/vscode/issues/330941)

## Summary

The reported folder-session counting behavior has been corrected on main: session-list summaries now use Session Changes, while worktree sessions retain Branch Changes. The fixing change covers both summary production and the list fallback, rather than only the separate editor Changes pill.

## Change summary

Session-list counts attributed an existing shared branch's accumulated divergence to each individual session.

## Best solution

Close as completed by 6fd2d2e178f1d98c534809cf63236f7d8f040412, retaining the isolation-based source selection established by the subsequent worktree change. Previously cached counts for unopened sessions can remain until recomputation; they are not evidence that new folder-session summaries still derive from branch divergence.
