# Issue #335816 — titlebar does not show the correct number

[https://github.com/microsoft/vscode/issues/335816](https://github.com/microsoft/vscode/issues/335816)

## Summary

Keep open for a maintainer decision: current main deliberately limits the title-bar count to the selected host, reproducing a count of one when blocked sessions span hosts. A later merged change codifies that behavior but does not reference this team-authored issue, so it does not meet the factual-close bar.

## Change summary

Make the Agents Window title bar report the expected number of sessions requiring input when those sessions belong to different agent hosts.

## Best solution

Define whether the title-bar indicator represents global attention across all hosts or only the selected host, then keep its count, dropdown contents, wording, and host-filter behavior consistent with that contract.
