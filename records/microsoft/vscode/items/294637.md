# Issue #294637 — You should be able to attach files that aren't in the workspace

[https://github.com/microsoft/vscode/issues/294637](https://github.com/microsoft/vscode/issues/294637)

## Summary

Valid feature request from a team member: the chat attach-file flow currently relies on the AnythingQuickAccessProvider, which surfaces workspace files, open editors, and recently opened files — but does not offer a general filesystem browser for picking arbitrary files the user has never opened. No duplicate found. Routing to the chat area for triage.

## Change summary

Allow attaching files from anywhere on the filesystem to Copilot chat, not just files in the current workspace or recently opened.

## Best solution

Add a filesystem-browse option (e.g. a native open-file dialog via IFileDialogService) to the chat attach-context flow in `chatContextActions.ts`, so users can pick arbitrary files (like external build logs) without first adding them to the workspace. The `isSupportedChatFileScheme` in `constants.ts` already permits `file://` URIs, so the main work is in the picker UI.
