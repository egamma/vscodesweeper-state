# Issue #294637 — You should be able to attach files that aren't in the workspace

[https://github.com/microsoft/vscode/issues/294637](https://github.com/microsoft/vscode/issues/294637)

## Summary

Current source supports attaching an external file through its editor or drag-and-drop, but the Add Context flow has no general filesystem browse entry. Keep this team-authored request open for the owner's assessment: no issue-referencing fix or verified duplicate establishes a factual close.
