# Issue #324903 — UX: Inability to switch between Microsoft and GitHub accounts without first turning off Settings Sync is highly unintuitive

[https://github.com/microsoft/vscode/issues/324903](https://github.com/microsoft/vscode/issues/324903)

## Summary

This exact account-switching UX was previously considered and declined because Settings Sync already supports switching providers by turning sync off and back on. Current main still intentionally retains that provider while sync remains enabled, so the established *out-of-scope decision applies.

## Change summary

Add a direct Settings Sync account-provider switch action or show the provider picker again after signing out.

## Best solution

Keep the existing Settings Sync lifecycle: use “Settings Sync is On” → “Turn Off,” then enable sync again and select the other provider. A direct switch action was explicitly declined in https://github.com/microsoft/vscode/issues/104934.
