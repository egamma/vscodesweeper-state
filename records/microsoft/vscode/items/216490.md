# Issue #216490 — Windows Taskbar Jump List repeats same labels because of workspace file

[https://github.com/microsoft/vscode/issues/216490](https://github.com/microsoft/vscode/issues/216490)

## Summary

A real gap remains on current main: Windows Jump List titles use only the workspace filename, while the distinguishing path is confined to the tooltip. The request is correctly routed and accepted into the Backlog, with no open canonical issue found.

## Change summary

Disambiguate Windows Jump List entries for identically named workspace files in different parent directories.

## Best solution

When Jump List workspace titles collide, append the shortest distinguishing parent-path segment in `WorkspacesHistoryMainService`, while preserving concise titles for unique entries and the full path as the description.
