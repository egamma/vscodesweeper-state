# Issue #216490 — Windows Taskbar Jump List repeats same labels because of workspace file

[https://github.com/microsoft/vscode/issues/216490](https://github.com/microsoft/vscode/issues/216490)

## Summary

The requested disambiguation remains missing: current jump-list titles discard parent paths, so identically named workspace files in different sandboxes receive identical labels. Keep this accepted Backlog request open; the inspected related issues do not own the same observable problem.

## Change summary

Distinguish same-named multi-root workspaces from different sandbox directories in Windows taskbar jump-list labels without requiring tooltips.

## Best solution

Provide concise distinguishing directory context for colliding workspace names in the Windows jump list, including cases where several immediate parent directories are identical. Preserve workspace launch targets and avoid changing unrelated workspace naming surfaces.
