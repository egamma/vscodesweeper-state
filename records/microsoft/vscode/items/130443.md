# Issue #130443 — Can't drag markdown cells in edit mode

[https://github.com/microsoft/vscode/issues/130443](https://github.com/microsoft/vscode/issues/130443)

## Summary

Still reproducible on main: MarkupCellRenderer never calls registerDragHandle, so markdown cells in edit mode cannot be dragged despite showing the grab cursor. An open PR (#251155) exists but has not merged.

## Change summary

Markdown cells in notebooks show a grab cursor in edit mode but cannot actually be dragged, unlike code cells.

## Best solution

Land the fix in `src/vs/workbench/contrib/notebook/browser/view/renderers/cellRenderer.ts` by adding a `registerDragHandle` call in `MarkupCellRenderer.renderTemplate()`, mirroring the pattern already used in `CodeCellRenderer` at line 377–378. Review and iterate on the open PR https://github.com/microsoft/vscode/pull/251155 which targets exactly this.
