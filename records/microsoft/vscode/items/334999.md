# Issue #334999 — Race condition between large PreToolUse hook and cmd output.

[https://github.com/microsoft/vscode/issues/334999](https://github.com/microsoft/vscode/issues/334999)

## Summary

The race remains source-reproducible on current main: large command output and appended PreToolUse context are processed concurrently and target the same per-tool `content.txt`, allowing one result to replace or suppress the other.

## Change summary

Large hook context can collide with a large command result on disk, causing the model to read hook text instead of the command output.

## Best solution

Preserve every large text part of a tool result in a distinct, stable disk resource so the command-output reference always resolves to the command output and hook context remains independently available.
