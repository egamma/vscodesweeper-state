# Issue #331769 — Agents window incorrectly parses SSH config

[https://github.com/microsoft/vscode/issues/331769](https://github.com/microsoft/vscode/issues/331769)

## Summary

Confirmed in the checkout: the Agents window's SSH host-list parser splits quoted `Host` values on raw whitespace, unlike its sibling path-list parser which already honors quotes — a small, well-localized fix with an existing test suite to extend.

## Change summary

The Agents window's Remote/SSH host picker splits a quoted `Host "Dev Instance (EU)"` config entry on spaces into multiple bogus host names instead of treating it as one alias, while the Remote-SSH extension parses the same file correctly.

## Best solution

Fix `parseSSHConfigHostEntries` in src/vs/platform/agentHost/common/sshConfigParsing.ts to tokenize the Host line with quote-awareness (reusing the same quoting logic as `parseSSHPathList` in the same file) so a quoted alias with spaces survives as one host.
