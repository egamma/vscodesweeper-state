# Issue #331769 — Agents window incorrectly parses SSH config

[https://github.com/microsoft/vscode/issues/331769](https://github.com/microsoft/vscode/issues/331769)

## Summary

Confirmed in source: `parseSSHConfigHostEntries` in sshConfigParsing.ts splits the `Host` directive's value on plain whitespace (`hostValue.split(/\s+/)`) without honoring double-quoting, so a quoted alias like `Host "Dev Instance (EU)"` is split into three separate bogus host entries instead of one.

## Change summary

The Agents window's SSH host picker splits quoted SSH config Host aliases containing spaces into multiple entries instead of treating them as one host.

## Best solution

Make `parseSSHConfigHostEntries` (src/vs/platform/agentHost/common/sshConfigParsing.ts) quote-aware when splitting a Host line's value, mirroring the existing quote-aware `parseSSHPathList` helper in the same file, so a `Host "Name With Spaces"` entry produces a single host alias.
