[https://github.com/microsoft/vscode/issues/341619](https://github.com/microsoft/vscode/issues/341619)

## Summary

Thanks for the detailed investigation. This describes permission-gate behavior (default edit auto-approve, session-wide shell approval, plan mode not gating shell), so it is security-adjacent and stays open for a maintainer. The edit auto-approve default is documented and intentional, but the session-grant and plan-mode findings need owner review.

## Change summary

In Manual permission mode, agent-host file edits are auto-approved by default, one shell approval overrides global deny rules for the whole session, and plan mode does not gate shell commands.

## Best solution

Have the agent host owners decide whether Manual mode should honor chat.tools.edits.autoApprove defaults. Session-scoped approvals should also not override explicit terminal deny rules, and plan mode should gate state-mutating shell commands. Consider splitting the three findings into separate issues.
