## Summary

Keep open: current code has an ADO authentication prompt, but semantic-search availability checks can prevent callers from reaching it. The search implementation has evolved since the report; the supplied steps suffice to retest, and no verified fix or older same-symptom canonical was found.

## Change summary

Asking a #codebase question in an Azure DevOps repository needing index authentication should offer sign-in rather than silently bypass remote search.

## Best solution

Ensure an explicit codebase search can offer ADO sign-in when missing authentication is what prevents remote semantic search. Preserve silent background availability checks and respect cancellation without repeatedly prompting.
