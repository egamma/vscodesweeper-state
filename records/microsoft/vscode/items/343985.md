# Issue #343985 — Let's support deleting environments

[https://github.com/microsoft/vscode/issues/343985](https://github.com/microsoft/vscode/issues/343985)

## Summary

Keep open: current source explicitly disallows removing environments, so the requested capability remains missing. This team-authored request needs investigation of backend deletion semantics before implementation.

## Change summary

Allow users to delete accumulated environments from the Remotes management UI, including obsolete environments created by isolated OSS launches.

## Best solution

Provide an accessible environment-deletion action in Remotes management backed by the environment service, with clearly defined effects on running hosts and associated sessions. Establish whether an owning application can recreate a deleted environment before deciding how the action should behave.

  > Users accumulate environments in Environment → Manage… and currently cannot delete them there. The requested end state is an accessible action that deletes an eligible environment through the backend rather than merely disconnecting or hiding it locally. Acceptance should cover persistence after refresh, visible failure handling, and the agreed effects on connected hosts and associated sessions. Repeated isolated OSS launches are a motivating case, but automatic cleanup is not an established requirement.
- **Trace:**

MissionControlEnvironmentService refreshes inventory from ICloudSandboxApiService.listEnvironments(); the API contract's deleteTask operation concerns tasks, not environments. The missing capability is confirmed from source, but backend environment deletion behavior, effects on existing sessions, and recreation by a running owner remain unverified. Preserve unrelated remote-removal behavior and existing account/availability boundaries. The motivating request is https://github.com/microsoft/vscode/issues/343985, arising from https://github.com/microsoft/vscode/issues/343790; check for a newly linked implementation PR before starting work.
- **Open decisions:**
