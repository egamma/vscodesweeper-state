# Issue #348841 — Missing License file

[https://github.com/microsoft/vscode/issues/348841](https://github.com/microsoft/vscode/issues/348841)

## Summary

The published packages genuinely lack a license file. VS Code supplies its own copyright-bearing license override, but that does not resolve the omission for downstream package consumers.

## Change summary

Include the MIT license and copyright holder in published @vscode/fs-copyfile packages.

## Best solution

Have the package owner include the copyright-bearing MIT license in the published tarball and provide repository metadata. Preserve VS Code's existing notices override until supported package versions no longer need it.
