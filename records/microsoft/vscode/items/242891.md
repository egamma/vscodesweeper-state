# Issue #242891 — Killing tasks does not actually kill them

[https://github.com/microsoft/vscode/issues/242891](https://github.com/microsoft/vscode/issues/242891)

## Summary

The root cause was the legacy Windows conpty not properly killing child process trees. The fix — enabling the newer conpty DLL shipped with VS Code by default — landed in commit cfebe6aeafb and shipped in 1.121.0. Multiple commenters confirmed the workaround (setting `windowsUseConptyDll: true`) resolved the issue before it became the default.

## Change summary

Killing tasks on Windows via the terminal kill button or 'Terminate Task' command leaves child processes running, occupying ports.

## Best solution

Keep the shipped fix (conpty DLL enabled by default since 1.121.0); no further core change needed. The macOS report in comment 27 should be tracked as a separate issue if it persists.
