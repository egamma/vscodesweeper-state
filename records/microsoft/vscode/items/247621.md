# Issue #247621 — scrollable output in separate editor

[https://github.com/microsoft/vscode/issues/247621](https://github.com/microsoft/vscode/issues/247621)

## Summary

Keep open: the standalone notebook output editor still inherits notebook output-scrolling preferences rather than providing the preview-specific behavior requested. This team-authored design feedback has no verified fix or qualifying duplicate.

## Change summary

Disable cell-style internal output scrolling when displaying a single notebook output in a separate editor.

## Best solution

Let a single output use the standalone editor's available space without a notebook-cell-sized internal scrollbar, while keeping long output reachable and preserving scrolling preferences inside notebooks. Coordinate this with the output-preview layout work tracked in https://github.com/microsoft/vscode/issues/247965.
