# Issue #247621 — scrollable output in separate editor

[https://github.com/microsoft/vscode/issues/247621](https://github.com/microsoft/vscode/issues/247621)

## Summary

Valid polish item from a team member: the separate notebook output editor inherits the global outputScrolling setting via computeDiffWebviewOptions(), but scrolling is unnecessary when rendering a single output in its own editor pane. The issue is still open and unfixed on main.

## Change summary

Disable output scrolling when a notebook output is rendered in the separate output editor, since the editor pane itself is scrollable.

## Best solution

In `notebookOutputEditor.ts`, override `outputScrolling: false` in the options spread from `computeDiffWebviewOptions()` when constructing the BackLayerWebView at line 135–138, so the output renders without its own scroll container when shown in the dedicated editor pane.
