# Issue #269828 — Render counts next to collapsed toolsets

[https://github.com/microsoft/vscode/issues/269828](https://github.com/microsoft/vscode/issues/269828)

## Summary

The requested count remains absent from the current tools picker: collapsed tool-set and MCP-server rows expose labels and descriptions but not their number of tools. This team-authored Backlog request should remain open, with the count semantics settled before implementation.

## Change summary

Show tool counts beside collapsed tool sets and MCP-server groups so users can identify which groups contribute heavily to the model tool limit.

## Best solution

Display a localized count on collapsed tool-set and MCP-server rows, representing the tools that contribute to the active model's limit and updating when the picker or server tool inventory changes.

- **Trace:**

  > The active implementation is showToolsPicker in src/vs/workbench/contrib/chat/browser/actions/chatToolPicker.ts. createToolSetTreeItem sets collapsed: true and uses toolset.description, while createBucket builds MCP rows with server label metadata; computeItems subsequently fills their children but never derives a count for either row type.
