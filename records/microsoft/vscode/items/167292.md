# Issue #167292 — New Color customization option editor.codeBackground 

[https://github.com/microsoft/vscode/issues/167292](https://github.com/microsoft/vscode/issues/167292)

## Summary

Keep open as an accepted Backlog feature request. Current main still exposes only `editor.background`, which is reused across code editors and other editor/workbench surfaces, so the requested selective code-editor background remains missing.

## Change summary

Add a theme color that changes code-editor backgrounds without changing Settings, extension details, README previews, and similar editor panes.

## Best solution

Introduce a narrowly scoped code-editor background color while retaining `editor.background` as the compatible fallback, and coordinate it with the related settings/webview theming request at https://github.com/microsoft/vscode/issues/74342.
