## Summary

The requested separation is already tracked by an older open issue reporting the same symptom: editor.background also changes Settings and extension information pages. Consolidate this request into that canonical issue, preserving the additional Jupyter Interactive window example.

## Change summary

Allow code-editor backgrounds to be customized independently of Settings, extension README pages, and other non-code editors.

## Best solution

Resolve background-color separation through https://github.com/microsoft/vscode/issues/74342, which explicitly covers retaining custom code-editor colors without applying them to Settings and informational editors. The eventual token design should preserve existing themes while allowing these surfaces to differ.
