# Issue #290904 — Expanding thinking container is disorienting

[https://github.com/microsoft/vscode/issues/290904](https://github.com/microsoft/vscode/issues/290904)

## Summary

Thanks for the detailed UX feedback. A real gap remains for large completed thinking blocks, and the maintainer discussion already supports a bounded, scrollable presentation; as a team-authored and maintainer-accepted direction, this should remain open and route to chat UI.

## Change summary

Keep users oriented when expanding a large thinking container by preserving its header position and avoiding an unbounded full-height expansion.

## Best solution

Long completed thinking blocks should expand without moving the activated header out of view, using a viewport-bounded scroll region with an accessible, persistently reachable collapse control. The chat list and nested thinking scroller should coordinate so bottom anchoring does not override this user-initiated expansion.
