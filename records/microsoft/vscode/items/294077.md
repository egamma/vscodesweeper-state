# Issue #294077 — copilot via remote ssh use read_file failed

[https://github.com/microsoft/vscode/issues/294077](https://github.com/microsoft/vscode/issues/294077)

## Summary

Likely a user-configuration issue (`remote.extensionKind` forcing Copilot to run locally instead of on the remote host). A commenter already confirmed the known resolution works, and the reporter has been inactive for over four months. Requesting info to confirm.

## Change summary

Copilot's `read_file` tool fails to read files on a Remote SSH host, producing a 'nonexistent file' error with a local `file:///` URI.

## Best solution

This is almost certainly the same root cause as https://github.com/microsoft/vscode/issues/265804: the Copilot extension is being forced to run locally via `remote.extensionKind` settings instead of on the remote host (the default). The reporter should check their settings and remove any override forcing Copilot local. If the issue persists on the latest build without such overrides, it would be a new bug worth investigating.
