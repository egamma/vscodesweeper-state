# Issue #300855 — Failed to load native module: pty.node

[https://github.com/microsoft/vscode/issues/300855](https://github.com/microsoft/vscode/issues/300855)

## Summary

The copilot prebuilds packaging was fixed to strip non-target platform binaries for both desktop and remote/server builds, shipping in 1.113.0. The exact scenario — wrong-platform prebuilds (win32-x64) landing on a Linux remote — is addressed by getCopilotExcludeFilter applied in gulpfile.reh.ts.

## Change summary

Copilot Chat native module pty.node fails to load on WSL/remote Linux because Windows prebuilds are installed instead of Linux ones.

## Best solution

Keep the shipped fix (cb1bf5f3514 and follow-ups through 68b23cbdfe5); no further change is needed. Users on 1.113.0+ should not see this. Close as completed.
