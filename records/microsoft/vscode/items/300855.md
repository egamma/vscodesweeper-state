# Issue #300855 — Failed to load native module: pty.node

[https://github.com/microsoft/vscode/issues/300855](https://github.com/microsoft/vscode/issues/300855)

## Summary

The reported remote-install failure was fixed on main: Copilot Chat now copies VS Code's platform-correct node-pty binaries into the separately installed SDK before importing it.

## Change summary

Copilot Chat installations on remote Linux environments could contain Windows native binaries and fail because `prebuilds/linux-x64/pty.node` was missing.

## Best solution

Keep the runtime node-pty shim introduced by commit 17c5c32122f71707abd6ea0f8f3265fd5f161680, which materializes the native binaries for the extension host's actual platform before loading the Copilot CLI SDK.
