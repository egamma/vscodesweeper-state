# Issue #258836 — Should secret storage allow using empty key?

[https://github.com/microsoft/vscode/issues/258836](https://github.com/microsoft/vscode/issues/258836)

## Summary

Keep open for an API-contract decision: current source still accepts empty secret keys, but the discussion does not establish that this is incorrect. A maintainer raised consistency with Memento and possible legitimate uses, so rejecting empty keys needs an explicit compatibility decision.

## Change summary

Consider rejecting empty-string SecretStorage keys and notifying extension authors of invalid use.

## Best solution

Have the extension API owners explicitly decide and document whether empty keys are supported, considering Memento consistency and existing extensions. If rejection is chosen, preserve access to previously stored secrets and define the compatibility policy before changing validation.
