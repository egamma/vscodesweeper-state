# Issue #302562 — Stale output from MCP tool / App in chat window

[https://github.com/microsoft/vscode/issues/302562](https://github.com/microsoft/vscode/issues/302562)

## Summary

Decline close (as-designed) gated off: the issue carries `under-discussion` — the owner has not decided yet. Original assessment: The original output intentionally records what the model received, not the app's latest state. The area maintainer explicitly declined both hiding that record and replacing it after the agent continues.

## Change summary

Allow MCP Apps to suppress or refresh the original tool output when subsequent app interactions produce different results.

## Best solution

Preserve the original model-visible tool result as an inspectable transcript record, separate from the app's mutable UI. App authors can consider the deferred-result interaction pattern linked by the maintainer.
