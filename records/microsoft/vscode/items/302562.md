# Issue #302562 — Stale output from MCP tool / App in chat window

[https://github.com/microsoft/vscode/issues/302562](https://github.com/microsoft/vscode/issues/302562)

## Summary

The maintainer explicitly confirmed that chat preserves the tool result supplied to the model and declined both hiding it and retroactively replacing it. The App's subsequent results are separate from that historical result, so this can close as designed.

## Change summary

Allow an MCP App to suppress or refresh the original tool output displayed in chat after the App invokes the tool again.

## Best solution

Preserve the model-visible tool result as an inspectable historical record. For interactions that must determine that result, use the maintainer-linked deferred-response pattern rather than rewriting an already-completed tool call.
