# Issue #322888 — Claude Agent fails with "Error during execution" when Claude Code is configured via Amazon Bedrock

[https://github.com/microsoft/vscode/issues/322888](https://github.com/microsoft/vscode/issues/322888)

## Summary

The reported Bedrock failure has been addressed on current main: Claude now supports native credentials, routes provider-qualified models through the native transport, and explicitly recognizes Bedrock as a configured third-party backend.

## Change summary

Claude Agent failed instead of using the Amazon Bedrock configuration that worked in Claude Code.

## Best solution

Keep the shipped native Claude transport and Bedrock-aware setup detection, allowing a Bedrock-backed model selected from the Claude model catalog to bypass the Copilot proxy.
