# Issue #126694 — Register a quickAccessProvider for debug sources

[https://github.com/microsoft/vscode/issues/126694](https://github.com/microsoft/vscode/issues/126694)

## Summary

The requested quick-access provider for debug loaded sources has not been implemented. The only debug quick-access provider on current main is StartDebugQuickAccessProvider (for launch configurations). This is a valid, small feature request from a team member, parked in Backlog with no community traction — keeping open.

## Change summary

Add a quick-access provider (e.g. `ds ` prefix) to search and open debug loaded sources, instead of manually filtering the Loaded Sources tree view.

## Best solution

Implement a new PickerQuickAccessProvider in `src/vs/workbench/contrib/debug/browser/debugQuickAccess.ts` that queries the debug session's loaded sources and lets the user fuzzy-search and open them. Low effort, but low demand — keep open until more users request it or a team member picks it up.
