# Issue #126694 — Register a quickAccessProvider for debug sources

[https://github.com/microsoft/vscode/issues/126694](https://github.com/microsoft/vscode/issues/126694)

## Summary

Current VS Code provides “Debug: Open Loaded Script...” with a searchable picker, covering the central workflow but not the requested dedicated quick-access prefix. This team-authored request remains open because the implementing PR references a different issue, and the discussion explicitly defers the additional provider pending user demand.

## Change summary

Register a dedicated quick-access provider and prefix for searching and opening sources loaded by active debug sessions.

## Best solution

Retain the existing loaded-script command and picker unless stronger demand emerges for direct prefix access; if adopted, the provider should expose the same multi-session source search without duplicating its behavior.
