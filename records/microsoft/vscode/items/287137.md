# Issue #287137 — Pasting multiline in terminal when more than 1k characters in version 1.108.0 gets mangled

[https://github.com/microsoft/vscode/issues/287137](https://github.com/microsoft/vscode/issues/287137)

## Summary

This is the same macOS PTY 1024-byte canonical-mode buffer corruption that affected #296955. Two fix attempts (PTY chunking and bracketed paste for executed text) were both reverted. The underlying issue remains unfixed on current main for the user-paste path, and a May 2026 commenter confirms it persists.

## Change summary

Pasting multiline text exceeding ~1024 characters into the terminal on macOS gets garbled due to PTY canonical-mode input buffer overflow.

## Best solution

The terminal team needs to implement a durable fix for the macOS PTY 1024-byte buffer limit when writing multiline data. The two prior approaches (512-byte chunking with delays in `terminalProcess.ts`, and wrapping in bracketed paste mode) were reverted. A robust solution likely involves either reliable chunking that doesn't regress performance, or using xterm.js's bracketed paste in a way that survives shell configurations where the shell hasn't enabled bracketed paste mode. The fix belongs in `src/vs/platform/terminal/node/terminalProcess.ts` or the xterm.js paste path.
