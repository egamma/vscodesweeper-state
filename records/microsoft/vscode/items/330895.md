# Issue #330895 — Please ensure the "Modern" UI doesn't become the only option in the future

[https://github.com/microsoft/vscode/issues/330895](https://github.com/microsoft/vscode/issues/330895)

## Summary

This is a forward-looking request that the legacy UI (or at least the classic tab styling) remain an option rather than a critique of a current defect; the setting to disable Modern UI exists today (`workbench.experimental.modernUI`, implemented in src/vs/workbench/contrib/styleOverrides/browser/styleOverrides.contribution.ts), so there's nothing to fix right now, but no maintainer has committed to keeping a permanent opt-out.

## Change summary

Requests that VS Code commit to keeping a non-'Modern' UI option available long-term, rather than eventually forcing Modern UI on everyone.

## Best solution

No code change needed today — the toggle already exists. This is really a request for a maintainer statement of intent about the eventual fate of the classic UI once Modern UI matures; best tracked alongside the broader Modern UI feedback threads (e.g. https://github.com/microsoft/vscode/issues/331403, https://github.com/microsoft/vscode/issues/328757) until the team clarifies its plan.
