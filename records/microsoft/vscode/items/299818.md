# Issue #299818 — Critical Error 400: Unsupported value 'xhigh' for model 'gpt-5-mini-2025-08-07' (ARM64/WSL)

[https://github.com/microsoft/vscode/issues/299818](https://github.com/microsoft/vscode/issues/299818)

## Summary

Still reproduces on main: the Copilot request path passes the user-configured reasoning effort (e.g. `xhigh`) directly to the API without validating it against the model's supported levels. The BYOK path has the guard (line 336 of openAIEndpoint.ts) but the main Copilot path in defaultIntentRequestHandler.ts does not. A later duplicate (#304771) covers the same bug.

## Change summary

Copilot Chat sends an unsupported `xhigh` reasoning effort value to gpt-5-mini, causing a 400 error from the API.

## Best solution

Add reasoning-effort validation/clamping in the main Copilot request path (similar to the BYOK guard in `extensions/copilot/src/extension/byok/node/openAIEndpoint.ts` line 336) so that unsupported effort values are either clamped to the highest supported level or dropped. Also close https://github.com/microsoft/vscode/issues/304771 as a duplicate of this issue.
