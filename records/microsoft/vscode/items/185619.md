# Issue #185619 — Math is not rendered inside of html in markdown notebook cells

[https://github.com/microsoft/vscode/issues/185619](https://github.com/microsoft/vscode/issues/185619)

## Summary

Valid feature request confirmed by a maintainer (mjbvz). Math inside raw HTML elements in notebook markdown cells is not supported by the markdown-it + KaTeX pipeline. Two related issues (#185795, #197427) were closed as duplicates of this one, making it the canonical tracker. Stays open in Backlog.

## Change summary

Support rendering math (LaTeX) expressions inside HTML elements in notebook markdown cells.

## Best solution

Extend the notebook markdown rendering pipeline (likely in `extensions/markdown-math` and/or `@vscode/markdown-it-katex`) to detect and render math expressions nested inside HTML blocks. This is non-trivial since markdown-it treats HTML blocks as opaque content — a post-processing pass over rendered HTML to find and replace math delimiters with KaTeX output may be needed.
