# Issue #323421 — Slash command completions don't appear when / is not at the start of an empty input

[https://github.com/microsoft/vscode/issues/323421](https://github.com/microsoft/vscode/issues/323421)

## Summary

Keep open for the maintainer-accepted whitespace improvement: current main supports whitespace-delimited skill completions, but executable slash commands still require `/` at offset zero. The thread rejects interleaving standalone commands with prose, so the original request should not be implemented wholesale.

## Change summary

Allow standalone slash-command completions with surrounding whitespace while preserving the distinction between commands and in-message skill references.

## Best solution

Make standalone command completion and execution consistently tolerate leading whitespace, without offering executable commands inside ordinary prose. Preserve intentional in-message skill references and use the later discussion to distinguish those from unwanted command suggestions.
