# Issue #298646 — Customize Code Review Model in Source Control

[https://github.com/microsoft/vscode/issues/298646](https://github.com/microsoft/vscode/issues/298646)

## Summary

A real capability gap remains: Source Control code review uses its dedicated review request path without exposing or honoring a user-selected model. No open canonical issue was found, so this should remain open as an under-discussion feature request.

## Change summary

Allow users to choose which language model runs the Source Control “Code Review - Uncommitted Changes” command.

## Best solution

Define whether Code Review should use an independently configured model or the active Chat model, then carry that selection through the dedicated code-review request path with clear quota implications.
