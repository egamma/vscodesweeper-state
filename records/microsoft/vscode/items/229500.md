# Issue #229500 — SCM Graph - Picked wrong repo not from active editor

[https://github.com/microsoft/vscode/issues/229500](https://github.com/microsoft/vscode/issues/229500)

## Summary

Keep open: current source still permits Auto selection to remain on the first discovered repository even when the active editor belongs to another repository. The issue is correctly routed to SCM, and no verified canonical or fixing commit was found.

## Change summary

The Source Control Graph automatically selects the first repository instead of the repository containing the active editor in a multi-repository workspace.

## Best solution

Make initial automatic repository selection converge on the active editor's repository as repositories become available. Preserve explicit graph selections, pinned active repositories, and subsequent intentional repository-focus changes.
