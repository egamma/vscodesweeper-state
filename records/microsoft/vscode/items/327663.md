# Issue #327663 — Testing: Pet persistence / notifications across sessions

[https://github.com/microsoft/vscode/issues/327663](https://github.com/microsoft/vscode/issues/327663)

## Summary

Keep open: this is team-authored testing feedback with unresolved product choices, and current main only partially covers the request. VS Code now maintains one pet across chat hosts within a window, but the pet still observes only its active host and cannot identify another session requiring input.

## Change summary

Make the VS Code pet optionally persistent across sessions and let it identify and navigate to sessions requiring attention.

## Best solution

Retain one persistent pet per window, aggregate actionable states from all sessions, and let the pet indicate and navigate to the session needing attention with concise, localized, accessible messaging. A maintainer should first settle whether per-session pets remain a configurable alternative and what notification details the pet exposes.
