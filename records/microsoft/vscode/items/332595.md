# Issue #332595 — Agent session list and opened default chat show different titles

[https://github.com/microsoft/vscode/issues/332595](https://github.com/microsoft/vscode/issues/332595)

## Summary

Team-authored bug report with a precise code-level trace showing the sessions list and default-chat title intentionally read different fields, causing a divergent title to appear when opening a session's default chat; needs routing to the agent-sessions area, no evidence yet of a fix on main.

## Change summary

The Agent Sessions list title (SessionSummary.title) and the opened default chat's header title (ChatModel._customTitle) can diverge for the same underlying session, confusing navigation.

## Best solution

Reconcile the two title sources in agentHostSessionListController.ts / agentHostStateManager.ts (e.g. have the default chat's displayed title fall back to or stay synced with the session title, or visually distinguish parent-session vs child-chat titles) so the list and opened view agree on which title identifies the item.
