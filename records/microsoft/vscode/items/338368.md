# Issue #338368 — Repository-scoped Copilot content exclusions affect unrelated files in multi-repository workspaces

[https://github.com/microsoft/vscode/issues/338368](https://github.com/microsoft/vscode/issues/338368)

## Summary

Confirmed real bug in Copilot's content exclusion: path globs from all cached repositories are flattened into one shared matcher, so a nested repo's broad exclusion rule leaks onto unrelated files elsewhere in a multi-root workspace. An open PR already targets this issue directly, so it stays open pending merge rather than closing.

## Change summary

A Copilot content-exclusion rule configured for one nested repository in a multi-repo workspace incorrectly blocks unrelated files in sibling/outer repositories.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/339415 (open, authored by a reporter who confirmed a before/after fix), which scopes compiled path globs per repository fetch URL instead of flattening them globally.
