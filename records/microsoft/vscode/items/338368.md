# Issue #338368 — Repository-scoped Copilot content exclusions affect unrelated files in multi-repository workspaces

[https://github.com/microsoft/vscode/issues/338368](https://github.com/microsoft/vscode/issues/338368)

## Summary

Real, well-diagnosed bug in Copilot's content-exclusion matcher (path globs from one repository leak across repositories in a multi-root workspace), and an open PR already targets this exact issue — keep open until it merges.

## Change summary

Content exclusion path rules (e.g. `**/*`) configured for a nested repository incorrectly apply to unrelated files in other repositories within the same multi-root workspace.

## Best solution

Land https://github.com/microsoft/vscode/pull/339415 ("Scope content exclusion path rules to their repository"), which appears to directly fix the cross-repository glob leak described here and in the corroborating comment.
