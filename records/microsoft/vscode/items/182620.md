# Issue #182620 — Changes lost in python notebook on undo

[https://github.com/microsoft/vscode/issues/182620](https://github.com/microsoft/vscode/issues/182620)

## Summary

Notebook-level Undo intentionally reverses the last structural operation, including cell creation; Redo restores the cell and its content. This exact UX was previously reviewed as designed.

## Change summary

Avoid unexpectedly removing a previously added notebook cell when Undo is invoked outside a focused cell editor.

## Best solution

Keep structural notebook operations in the undo stack and use Redo to recover a cell removed by Undo; any further work would be discoverability polish rather than a correctness fix.
