[https://github.com/microsoft/vscode/issues/182620](https://github.com/microsoft/vscode/issues/182620)

This is a duplicate of the older open notebook undo issue https://github.com/microsoft/vscode/issues/200291, which owns the same failure to restore a deleted cell. The macOS focus context and accidental cell removal reported here should be preserved on that canonical issue.

## Change summary

Using Cmd+Z while the notebook container rather than a cell editor has focus can remove a cell, after which the cell cannot be restored.
