# Issue #334183 — Reversed output in Hebrew

[https://github.com/microsoft/vscode/issues/334183](https://github.com/microsoft/vscode/issues/334183)

## Summary

Real, reproducible gap: the integrated terminal (built on @xterm/xterm) has no bidirectional-text (RTL/bidi) rendering support, so Hebrew/Arabic output appears visually reversed. This is a known architectural limitation of the terminal emulator, not a VS Code core logic bug, and is already the subject of long-standing open discussion — routing to the terminal area rather than closing.

## Change summary

Terminal output containing Hebrew text is rendered with reversed (visual, non-logical) character order.

## Best solution

Track as a terminal/xterm.js bidi-rendering limitation under the terminal area; VS Code's editor already implements a bidi renderer (src/vs/editor/common/viewLayout/viewLineRenderer.ts) but the integrated terminal has no equivalent — any real fix has to land in xterm.js (or a VS Code-side bidi post-processing layer for the terminal) rather than a small localized patch.

  > Thanks for the detailed report and for confirming it still reproduces on 1.136.0. There are related open discussions about RTL/bidi support at https://github.com/microsoft/vscode/issues/11770 and https://github.com/microsoft/vscode/issues/83365 — worth checking those for overlap.
