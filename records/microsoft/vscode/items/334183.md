# Issue #334183 — Reversed output in Hebrew

[https://github.com/microsoft/vscode/issues/334183](https://github.com/microsoft/vscode/issues/334183)

## Summary

This is the well-known lack of BiDi/RTL reordering support in the integrated terminal (xterm.js), which reverses Hebrew/Arabic character order on output — already tracked by the broad, open umbrella issue for RTL language support.

## Change summary

Hebrew (and likely Arabic) text printed to the built-in terminal is displayed with reversed character order instead of correct visual/logical BiDi ordering.

## Best solution

Consolidate under https://github.com/microsoft/vscode/issues/11770 ("Support for RTL languages"), which is the long-standing tracker for RTL/BiDi support across VS Code including the terminal; implementing BiDi reordering there (likely via xterm.js's addon ecosystem or a custom renderer) would resolve this report too.
