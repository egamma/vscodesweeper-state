# Issue #334183 — Reversed output in Hebrew

[https://github.com/microsoft/vscode/issues/334183](https://github.com/microsoft/vscode/issues/334183)

## Summary

The built-in terminal (xterm.js) does not implement Unicode bidirectional (BiDi) text reordering, so RTL scripts like Hebrew print in logical rather than visual order — this is a known, long-standing rendering gap rooted in the terminal engine, not a specific regression to fix locally.

## Change summary

Hebrew text printed to VS Code's built-in terminal (e.g. via a Go program's fmt.Println) appears with reversed letter order instead of correct right-to-left rendering.

## Best solution

Track under the existing broader RTL/bidi terminal-rendering discussion (e.g. the open RTL-support tracking issues) rather than as a standalone bug — a real fix requires either an xterm.js BiDi addon/reordering support or a VS Code-side BiDi layer added to xtermTerminal.ts, which is a substantial terminal-area feature decision.
