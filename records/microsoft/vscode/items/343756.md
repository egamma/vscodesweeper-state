# Issue #343756 — Copilot Chat Agent fails when accumulated image context exceeds the model’s 20-image limit

[https://github.com/microsoft/vscode/issues/343756](https://github.com/microsoft/vscode/issues/343756)

## Summary

Keep open: current source reproduces the reported failure when image-producing tool calls accumulate within one agent turn. Existing filtering removes older-turn images but explicitly throws when the current turn exceeds the model limit; the reporter also confirmed persistence on 1.143.1.

## Change summary

Allow an agent task to continue inspecting images without accumulated tool-result payloads exceeding the selected model's per-request image limit.

## Best solution

Bound the image payloads sent during a continuing agent turn while retaining filenames, textual analysis, and displayed conversation history. Older tool images should remain reloadable without making subsequent requests exceed the model limit.
