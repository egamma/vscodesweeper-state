# Issue #343756 — Copilot Chat Agent fails when accumulated image context exceeds the model’s 20-image limit

[https://github.com/microsoft/vscode/issues/343756](https://github.com/microsoft/vscode/issues/343756)

## Summary

Keep open: current source reproduces the failure when image-viewing tool results accumulate within one agent turn. Existing image filtering only evicts images from earlier user turns, so it does not cover the reported workflow.

## Change summary

Allow image-heavy agent tasks to continue within the model's image-count limit without losing displayed history or previous textual analysis.

## Best solution

Make outgoing-context image budgeting cover accumulated tool-result images within an ongoing agent turn, preserving textual context and the ability to reload omitted images. Retain existing handling of oversized explicit user attachments and avoid changing stored chat history.
