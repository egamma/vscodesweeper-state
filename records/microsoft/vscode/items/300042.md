# Issue #300042 — Steering obliterates applied patch from GPT-5.4

[https://github.com/microsoft/vscode/issues/300042](https://github.com/microsoft/vscode/issues/300042)

## Summary

Steering intentionally asks the active request to yield before continuing in the new direction, so unexecuted tool calls may be discarded. Queueing is the existing path for preserving the current request through completion.

## Change summary

Preserve and apply a generated patch when a steering message arrives before the patch tool call executes.

## Best solution

Keep the current distinction between steering and queueing: steering abandons unfinished work to change direction, while queueing lets the active request and its tool calls complete before sending the next message.
