# Issue #3684 — Ctrl-K must cut up to the end of the line into the clipboard

[https://github.com/microsoft/vscode/issues/3684](https://github.com/microsoft/vscode/issues/3684)

## Summary

The requested macOS behavior remains missing on main. This Backlog request has 40 community upvotes, so it should remain open rather than be closed for age.

## Change summary

Make macOS Ctrl+K cut from the cursor through the line end instead of deleting that text without preserving it.

## Best solution

Add a dedicated cut-to-line-end editor command and bind macOS Ctrl+K to it, while retaining `deleteAllRight` for users who want deletion without changing the clipboard. Coordinate its clipboard or kill-ring semantics with https://github.com/microsoft/vscode/issues/72630.
