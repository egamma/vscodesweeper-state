## Evidence

- **Current source confirms the trigger:** src/vs/workbench/api/common/extHostFileSystemEventService.ts:76-124 parses the relative path pattern and matches create/change/delete events using only uri.fsPath or lowerCaseFsPath. Relative patterns bypass the string-pattern workspace check, and none of these branches compares the event URI's scheme or authority with baseUri. Thus right:/root/file.txt can match a watcher rooted at left:/root, as reported.
- **URI information is available but not enforced:** src/vs/workbench/api/common/extHostTypes.ts:1904-1910 derives RelativePattern.base from baseUri.fsPath. The watcher constructor uses baseUri to determine path casing at extHostFileSystemEventService.ts:66-69, but not to constrain event namespaces.
