# Issue #307046 — Don't use red color in syntax highlighting

[https://github.com/microsoft/vscode/issues/307046](https://github.com/microsoft/vscode/issues/307046)

## Summary

Keep this open for a theme-design decision: current source still assigns red to ordinary syntax, and the available customization settings do not change the default palette. The older theme discussions provide relevant feedback, but do not establish a canonical specifically owning this request.

## Change summary

Reserve red syntax highlighting for errors rather than valid keywords and types in the refreshed default dark theme.

## Best solution

Have the default-theme owners decide whether ordinary syntax should avoid colors that readers associate with diagnostics, then apply any agreed palette change consistently across the affected token categories. Preserve existing theme selection and personal customization options.
