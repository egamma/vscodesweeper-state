## Summary

The report describes a plausible customization-discovery defect, but current main already resolves configured skill locations against parent-repository roots and forwards discovered skills to Copilot CLI. The reproduction does not specify whether the parent repository or the submodule itself is opened as the workspace, so current behavior cannot be confirmed without updated details.
