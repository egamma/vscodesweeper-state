# Issue #309922 — [Unhandled Error] potential listener LEAK detected, popular — notebook/codeCellRunToolbar / menuService

[https://github.com/microsoft/vscode/issues/309922](https://github.com/microsoft/vscode/issues/309922)

## Summary

Still reproduces on main: RunToolbar eagerly subscribes to menu onDidChange in the constructor (lines 46–56) for every cell template, causing listener accumulation on the singleton PersistedMenuHideState emitter. @jrieken's suggestion to defer to didRenderCell has not been implemented.

## Change summary

Notebook code cell run toolbar creates menu listeners eagerly per cell template, exceeding the 175-listener threshold on the shared menu service emitter.

## Best solution

Move the menu creation and onDidChange subscriptions from the RunToolbar constructor into didRenderCell (using cellDisposables so they are cleaned up on unrender), as suggested by @jrieken in the discussion. This limits active listeners to only the currently-rendered cells.
