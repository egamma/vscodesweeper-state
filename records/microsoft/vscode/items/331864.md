# Issue #331864 — Preserve per-conversation model configuration for extension-provided models

[https://github.com/microsoft/vscode/issues/331864](https://github.com/microsoft/vscode/issues/331864)

## Summary

Well-diagnosed report with a deterministic reproducer showing extension-provided chat models receive schema defaults instead of the conversation's selected reasoning-effort/context-size configuration; an open PR (#331865) already proposes the fix, so this should stay open for that PR to land rather than being auto-fixed or closed.

## Change summary

Extension-provided language model providers (via LanguageModelChatProvider) receive their configuration schema defaults instead of the per-conversation selected settings (e.g. reasoning effort, context size) on initial and continuation requests.

## Best solution

Land the linked PR https://github.com/microsoft/vscode/pull/331865, which propagates per-conversation model configuration to extension providers in src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostLanguageModelProvider.ts; the fix should ensure the selected configuration is merged over schema/configured defaults and reused across continuation requests (agent, inline chat, notebook, test-setup, codebase, summarization) while independently resolved utility/search/execution endpoints keep their own configuration.
