# Issue #266067 — Chat: Invalid/failed tool calls are never shown to the user

[https://github.com/microsoft/vscode/issues/266067](https://github.com/microsoft/vscode/issues/266067)

## Summary

Valid feature request from a team member. The current code handles tool errors in some cases (e.g., `isError` flag in `ChatInputOutputMarkdownProgressPart`) but still hides many failed/invalid tool calls entirely via the `Hidden`/`HiddenAfterComplete` presentation modes. No comprehensive fix has landed.

## Change summary

Failed or invalid tool calls (e.g., MCP calls with invalid JSON, failed edit_file) are sometimes hidden from the user instead of being shown with an error state.

## Best solution

Ensure that tool invocations with a `toolResultError` are never fully hidden — even when their `presentation` would normally be `Hidden` or `HiddenAfterComplete`, a failed tool call should render a visible error indicator in the chat UI so users understand the agent is self-correcting. Design input is needed (per connor4312's comment).
