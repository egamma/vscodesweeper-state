# Issue #266067 — Chat: Invalid/failed tool calls are never shown to the user

[https://github.com/microsoft/vscode/issues/266067](https://github.com/microsoft/vscode/issues/266067)

## Summary

Team-authored feature request for consistently surfacing failed/invalid tool calls in the chat UI. Significant partial progress has been made (AutoExpandToolFailures setting, isError rendering in tool invocation parts), but no commit explicitly references this issue, and the request covers multiple failure modes that may still have gaps.

## Change summary

Failed or invalid tool calls (MCP schema errors, failed edits) are sometimes hidden from the user in chat, eroding trust in agent self-healing.

## Best solution

Audit all tool-call failure paths (MCP invalid JSON schema, edit failures, confirmation rejections) to ensure every one surfaces a visible error indicator in the chat UI via the existing `chatToolInvocationPart` and `AutoExpandToolFailures` infrastructure. The relevant rendering logic lives in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/toolInvocationParts/` and the model tracking in `src/vs/workbench/contrib/chat/common/model/chatModel.ts`.
