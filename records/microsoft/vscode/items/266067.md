# Issue #266067 — Chat: Invalid/failed tool calls are never shown to the user

[https://github.com/microsoft/vscode/issues/266067](https://github.com/microsoft/vscode/issues/266067)

## Summary

Keep open for a consistent design for failed tool-call visibility. Current source supports displaying some execution errors, but that does not establish coverage of validation and preparation failures; the team-authored request has explicit maintainer interest and no verified fix or canonical duplicate.

## Change summary

Show failed MCP and file-edit tool attempts consistently in chat so users can understand the agent's retries and recovery.

## Best solution

Give validation, preparation, and execution failures a consistent, discoverable representation in the chat transcript without overwhelming successful recovery. Settle the error presentation with the chat area owners; treat the suggested reduction in agent apologies as a separate product decision.
