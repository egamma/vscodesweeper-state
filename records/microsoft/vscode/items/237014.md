# Issue #237014 — Some sidebar items, such as Copilot Edits, select colors from unrelated elements

[https://github.com/microsoft/vscode/issues/237014](https://github.com/microsoft/vscode/issues/237014)

## Summary

The contrast defect remains source-reproducible on current main: the changed-files container uses the editor background while its list foreground is sourced from the sidebar. This accepted chat theming bug should remain open for a bounded fix.

## Change summary

The chat changed-files list can combine an editor-derived background with a sidebar-derived foreground, producing unreadable contrast in themes whose editor and sidebar palettes differ.

## Best solution

Make the changed-files surface use the chat host's paired location-based background and foreground tokens, preserving consistent contrast in sidebar, editor, and other chat hosts.
