# Issue #350588 — TaskExecution.terminate() before the task has started is dropped ("Task to terminate not found"), and the task runs on

[https://github.com/microsoft/vscode/issues/350588](https://github.com/microsoft/vscode/issues/350588)

## Summary

The startup race remains in current source: executeTask returns an execution before startup completes, while termination searches only tasks with an attached terminal. Keep this open for a task API lifecycle fix.

## Change summary

Immediate TaskExecution.terminate() requests are lost before a CustomExecution task becomes active.

## Best solution

Honor termination of a returned execution throughout startup, so it either never starts or promptly ends without requiring another terminate call. Preserve existing task event ordering, execution identity, and normal termination behavior.
